# Fusion 360 手机客户端能做什么、不能做什么

> 手机端是 Fusion 360 的查看与协作工具：能看模型、提意见，不能建模。本篇按「能 / 不能」两栏讲清楚，帮你决定什么活儿放手机上干。

## 一、能做的事

| 能做 | 具体是什么 |
| --- | --- |
| 查看 3D 模型 | 在手机或平板上打开云端项目里的设计，转动、放大、逐个看装配里的构件 |
| 看属性与零件清单 | 查看设计属性和完整的零件清单，跟进项目动态更新 |
| 隔离与隐藏构件 | 把装配里不关心的构件临时隐藏或单独显示，看局部的首选做法 |
| 提评论 | 直接在项目里留言，同事在电脑端就能收到 |
| 截图与标注 | 把当前视图截下来、画上标记再发出去 |
| 传现场照片 | 把现场拍的照片传到项目里当补充材料 |
| 看多种格式 | 官方称支持 100 多种设计与工程文件格式，具体清单见 [能打开哪些文件格式.md](能打开哪些文件格式.md) |
| 离线看图 | 提前缓存设计，没网也能看和批注（做法见 [离线查看与批注方法.md](离线查看与批注方法.md)） |

适用场景不用复杂化：车间里对着机器看图、见客户时当场调出模型、出差路上翻项目、审批人没装电脑版也能看图提意见。

## 二、不能做的事

官方支持文档的口径很明确：**移动端只是查看器和标记工具，不能建模**（见 [官方支持文章](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Cannot-create-3D-model-in-Fusion-360-mobile-application.html)）。画草图、拉伸、出工程图这些 CAD 操作都得回电脑上的桌面版，或用浏览器版做。

所以「手机改图」这条路不用试了 —— 你在手机上能做的是把问题找出来、说清楚，改动本身回电脑做。

## 三、手势怎么用

看 3D 模型常用的几个手势：

| 想做什么 | 手势 |
| --- | --- |
| 缩放 | 双指捏合或张开 |
| 平移 | 双指按住往任意方向拖 |
| 旋转 | 双指绕一点转动 |
| 环视 | 一根手指按住不动、往某个方向移动 |

不同版本的查看器界面会有调整，以你装的应用内实际显示为准。

## 四、屏幕小看着费劲怎么办

手机屏看大装配容易看漏，两个办法：

- 优先用平板（官方移动端同时覆盖手机和平板）；
- 把关键部位截图放大后标注再发，比在屏幕上反复缩放省时间，对方看着也直观。

有些设计还是要在电脑上看的，两端怎么分工见 [与电脑版怎么配合.md](与电脑版怎么配合.md)。
