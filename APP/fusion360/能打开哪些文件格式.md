## 一、常见格式对照表

官方应用说明里点名的格式：

| 来源软件 | 常见格式 |
| --- | --- |
| Fusion 自己 | F3D |
| AutoCAD | DWG、DXF |
| SolidWorks | SLDPRT |
| Inventor | IPT、IAM |
| CATIA | CATPART |
| 通用三维交换 | STEP、IGES、STL、OBJ |
| 其他 | SAT、SMT |

100+ 是官方口径，完整清单与各版本增减以官方应用页面为准。

## 二、文件怎么进手机

两条路：

- **走云端项目**：电脑端把文件传到项目里，手机端登录同一个账号后直接看 —— 推荐，两边都有记录，评论也有处落（流程见 [与电脑版怎么配合.md](与电脑版怎么配合.md)）；
- **手机上传**：应用支持从手机上传文件再查看，适合临时从聊天工具收到一个模型要马上看的场景。

## 三、打不开或显示不全怎么办

- 先确认扩展名在上面的清单里；不在就回电脑端转成 STEP 这类通用交换格式再看；
- 大装配加载慢时等它加载完，别急着重进；
- 手机端只看不能改，要编辑回电脑端（分工见 [与电脑版怎么配合.md](与电脑版怎么配合.md)）；还没装客户端的话，装法见 [下载与安装教程.md](下载与安装教程.md)。
