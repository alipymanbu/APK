# 换手机聊天记录怎么迁移

> 换手机、恢复出厂前必做的一套备份与恢复动作，以及三星 Smart Switch 这条特殊通道的条件和坑。

## 一、先记住这个前提：聊天记录不在服务器上

KakaoTalk 出于隐私设计**不在服务器保存聊天内容**，记录只存在每台手机本地。这意味着：旧手机丢了、恢复出厂了、应用卸载了 —— 没提前备份，几年聊天记录就真的没了，任何找回手段都救不回来。

所以迁移这件事必须赶在**旧手机还能正常开机**的时候做，下面的顺序不要反。

## 二、旧手机上：做一次免费对话备份

入口在「更多 → 设置 → 聊天 → 对话备份」（不同版本措辞略有差异）。动手前知道这几条限制，别做完了才发现白做：

| 事项 | 实际情况 |
| --- | --- |
| 备份内容 | **只有文字消息**；图片、视频、文件不在内 |
| 不备份的房间 | 密聊（加密聊天）和公开聊天室的内容整个不在备份里 |
| 有效期 | 备份文件只保留 **14 天**，过期自动清掉 —— 备份完别拖半个月才换机 |
| 备份密码 | 必须设 4~10 位密码，**忘了这个密码备份就作废**，官方也找不回来，单独记在备忘录里 |
| 自动备份 | 较新版本可以设自动备份周期（每日 / 每周，以应用内实际显示为准），长期开着最省心 |

点备份后等它跑完（记录多可能要几分钟），回到同一页面能看到备份日期，确认状态是「已备份」再进行下一步。

## 三、新手机上：登录后按提示恢复

1. 新手机装好 KakaoTalk（包从哪来见 [下载与安装教程.md](下载与安装教程.md)）；
2. 用原来的 Kakao 邮箱账号登录（这就是注册篇里强调绑定邮箱的原因），确认原手机号；
3. 应用检测到备份文件会自动弹提示，输入备份密码；
4. 点恢复，等进度跑完（记录多可能要十几分钟），期间别杀应用。

两个容易翻车的点：**恢复完成前别在旧手机上登出或卸载应用** —— 登出会清掉本机数据，万一新手机恢复失败，退路就没了；新手机上还没恢复就急着点「开始使用」，之后补恢复要走更多步骤，顺序别乱。

## 四、安卓和 iPhone 之间互迁

安卓换 iPhone、iPhone 换安卓，对话备份的恢复是支持的（2022 年起开放，**以官方说明为准**），流程和上面完全一样：旧手机备份 → 新手机登录恢复。仍然受「只有文字」的限制 —— 跨系统搬家时图片视频一样不跟着走。

## 五、三星手机：Smart Switch 这条通道的条件

三星 Galaxy 换 Galaxy 可以用官方的 Smart Switch 直接搬 KakaoTalk 数据，**但条件卡得很死**，逐条对：Smart Switch 版本 3.7.54.7 以上、KakaoTalk 版本 10.5.5 以上、安卓 12 以上、只在 Galaxy 之间搬、新机恢复前**不能先装 KakaoTalk**（先卸载再恢复）。恢复的内容也有限制：过期没下载的媒体、支付钱包等需要设备认证的数据不会跟着过去；用电脑版 Smart Switch 或 SD 卡备份时，KakaoTalk 的聊天记录不在支持范围。

条件全满足的话这条通道体验最好（连应用设置一起搬）；差任何一条，就老老实实走第二、三节的备份恢复流程。

## 六、想连图片视频一起保住怎么办

免费备份只有文字，媒体文件两条路：

1. **手动保存**：换机前把重要的图片视频在旧手机里逐个存到相册（长按消息 → 保存），相册本身用系统自带的换机工具迁；
2. **官方云服务**：KakaoTalk 有订阅制的云端存储服务，媒体文件随订阅自动备份（**价格与档位以官方页面为准**）—— 常年换机、记录值钱的人可以考虑，偶尔换一次机的不值得为它开订阅。

迁移完成后在新手机上别急着重装系统换号，先确认好友列表、聊天记录、群组都在，再处理旧手机；之后碰到的收发异常按 [常见问题与故障排查.md](常见问题与故障排查.md) 逐条排查。
