## 一、把界面换成中文

默认装出来的界面多半是英文或韩文，改法在应用内：

| 系统 | 路径 |
| --- | --- |
| Android | 右下角「更多」→ 设置 → 通用 → 语言 → 选中文 → 应用 |
| iOS | 右下角「更多」→ 设置 → 通用 → 语言 → 选中文 → 保存 |

界面支持包括简体中文在内的多种语言，选完即时生效，不用重启应用。不同版本菜单措辞可能略有出入，但「更多 → 设置 → 通用 → 语言」这条线是稳定的。改完发现个别页面还是韩文，属于个别未翻译的内容，不影响使用；大面积没生效再查应用版本是否过旧（见 [常见问题与故障排查.md](常见问题与故障排查.md)）。

## 二、通知：总开关、单房间静音、免打扰

三个层级，从粗到细：

1. **全局开关**：设置 → 通知。这里管消息提醒的总闸，声音、振动可以分开 —— 想只留振动就把声音关掉、振动留着。
2. **单个聊天室静音**：在聊天列表**长按**要静音的房间选「关闭聊天室提醒」；或者进到房间里点右上角菜单，把房间里的**铃铛图标**划掉。被静音的房间名字旁会挂一个灰色小铃铛。几百人的大群、只发广告的频道，都建议这样处理，全局通知留着不用关。
3. **免打扰时段**：设置 → 通知里有免打扰时段设置，睡觉、开会的时间段自动全部静音，不用每天手动切。

一个容易漏的点：开了**关键词提醒**的话，就算全局静音了，命中关键词的消息照样会响 —— 「怎么静音了还响」先查这里（设置 → 通知 → 关键词提醒），不需要就把里面的关键词清掉。

## 三、表情、主题和聊天背景

- **表情**：聊天输入框旁的表情入口进商店，免费和付费贴图都在里面，下载后就能用；发送时从已下载列表里选。
- **主题与背景**：设置里的主题项可以整体换肤，单个聊天室还能单独设背景图 —— 你想让哪个房间看起来不一样，就在那个房间里点背景设置，不用全局换。

## 四、隐私相关的两个开关

「好友推荐允许」和「允许 ID 搜索」这两个开关决定别人能不能通过通讯录、ID 找到你，位置和用法在 [添加好友的几种方式.md](添加好友的几种方式.md) 的第二、四节里写过了，装完应用建议先按自己的偏好把它们定下来再开始加人。

设置都理顺之后，剩下的日常问题基本集中在登录、收码、消息收发这几类，逐条排查的清单见 [常见问题与故障排查.md](常见问题与故障排查.md)。
