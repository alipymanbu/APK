# 添加好友的几种方式

> 通讯录同步、ID 搜索、二维码、摇一摇、群聊里加人 —— 每种方式的前提条件和适合的场景。

## 一、先认下这张对照表

| 方式 | 前提 | 适合场景 |
| --- | --- | --- |
| 通讯录同步 | 手机里存了对方号码 | 联系人本来就多，最省事 |
| 手机号直加 | 知道对方号码 | 不想把号码存进通讯录的一次性联系 |
| ID 搜索 | 双方都开了「允许 ID 搜索」 | 不想暴露手机号 |
| 二维码 | 两人见面，屏幕对屏幕 | 线下聚会、当面交换 |
| 摇一摇 | 双方都开着摇动功能 | 当面、懒得扫码 |
| 群聊 / 公开聊天室 | 在同一个聊天室里 | 顺藤摸瓜加认识的人 |

## 二、通讯录同步（最省事的一种）

把对方的手机号存进手机通讯录，回到 KakaoTalk 的「好友」标签刷新一下（下拉列表或点刷新图标），对方用这个号注册过就会出现在好友列表里。

不想让「存了你号码的人」在对方那边收到你的好友推荐，去 **设置 → 好友 → 好友推荐允许** 关掉；已经自动加进来、暂时不想理的联系人，长按头像选「隐藏」，藏起来但没删，以后在好友管理里能再翻出来。

## 三、手机号直加

「好友」标签右上角的添加入口里选「联系人添加」，直接输对方号码加好友 —— 号码不用存进手机通讯录。适合临时对接一个客户、只加这一次的场合。

## 四、ID 搜索（不想暴露手机号时）

每个账号可以设一个 KakaoTalk ID，别人拿这个 ID 搜到你、加上你，全程不用交换手机号。两个开关都在**个人资料编辑页**里：

1. 「我的资料 → 编辑」里先把自己的 KakaoTalk ID 设好 —— **ID 一旦设定就不能改**（以官方说明为准），起名前想清楚；
2. 同一页把「允许 ID 搜索」打开，不开的话别人搜不到你。

加别人的时候，在添加入口选「ID 添加」，输对方的 ID 检索。注意对方也得开了允许搜索，搜不到先问一句对方开关有没有开，别先怀疑自己输错了（ID 不区分大小写，但字母数字要一个不差）。

## 五、二维码和摇一摇（当面用）

- **二维码**：添加入口选「二维码」，下方切到「我的资料」就把自己的码亮给对方扫；切到「扫二维码」就对准对方屏幕上的码。扫完点「添加好友」完成。中途别把自己的码一直亮在屏幕上晾着，加完就收。
- **摇一摇**：双方都开着摇动功能时，两台手机同时摇动就能互相出现在列表里，选中确认即可。人多的时候周围人的手机都会出现，看清楚头像和昵称再点。

## 六、从聊天室里加人

在群聊或公开聊天室里长按某个成员的头像，可以直接把这个人加为好友 —— 聊天室也是认识新朋友的入口之一，公开聊天室按兴趣分类，进什么样的室就能遇到什么样的人。

加完好友只是开始：把界面换成中文、调通知声音、管理会打扰你的群提醒，这些设置项的路径都在 [常用设置与界面语言.md](常用设置与界面语言.md)。
