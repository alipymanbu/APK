## 一、先分清两个安装包

TC Games 不是单个软件，而是「电脑端客户端 + 手机端 App」两件套：游戏本体始终在手机上跑，电脑只负责显示画面和键鼠控制。两个安装包分别装在两侧：

| 安装包 | 装在哪 | 获取途径 | 系统要求 |
| --- | --- | --- | --- |
| 电脑端客户端 | Windows 电脑 | 官网 [www.sigma-rt.com.cn](https://www.sigma-rt.com.cn/tcgames/) 下载安装程序 | Windows 7 及以上（当前为 64 位安装包） |
| 手机端 App（Android 安装包） | 安卓手机 | 通常由电脑端在首次 USB 连接时自动推送安装；也可以单独下载安装包手动装 | Android 6.0 及以上（开发者在应用商店信息里建议 Android 9.0 及以上体验更好） |

官方支持范围是 Android 手机 + Windows 电脑，未提供 iOS 版；电脑端不依赖安卓模拟器。它和模拟器怎么取舍，见 [与模拟器有什么区别.md](与模拟器有什么区别.md)。

## 二、安装前确认三件事

1. 电脑系统是 Windows 7 及以上，低配集显电脑也可以运行（官方定位是不依赖模拟器，游戏在手机上运行）。
2. 手机系统是 Android 6.0 及以上；部分厂商手机需要先开启「开发者模式」，见下文第三节。
3. 准备一根可传数据的 USB 数据线（最好用手机原装线），只供电不传数据的线连不上电脑。

## 三、电脑端下载安装

1. 打开官网下载页 [www.sigma-rt.com.cn/tcgames](https://www.sigma-rt.com.cn/tcgames/)，下载电脑端安装程序（64 位）。
2. 双击运行安装包，按安装向导的提示依次完成。
3. 安装完成后在桌面打开 TC Games 客户端。

## 四、手机端安装

手机端 App 一般不用你手动找：第一次用 USB 数据线把手机连到电脑后，电脑端会自动把手机端 App 推送到手机上，在手机上按提示允许安装即可。安装包文件名是 MobileAgent.apk（官方常见问题页口径），推送或手动装时都可以用这个名字认出它；电脑端 3.0.46 系更新后，连接时还可以勾选是否自动安装手机端 App（以官方更新日志为准）。

如果你的电脑端推送不顺利，或者想先把手机端装好再连接，可以直接用安装包手动安装——TC Games 安装文件资源（夸克网盘）里就是这份手机端安装包：[https://pan.quark.cn/s/ac40c1184edf](https://pan.quark.cn/s/ac40c1184edf)，转存后下载到手机上安装。

手动安装前可以核对的版本信息（以本文资源包为准，官方最新版可能更新，以官网页面为准）：

安装时手机会提示「未知来源应用」之类的确认，允许即可；不同品牌的设置入口不同，多数在安装弹窗里直接给开关。

电脑端若在安装或启动时报「缺少 .Net Framework」或 TCGames.exe 无法启动，官方常见问题页的「安装问题」类目有对应处理条目：[www.sigma-rt.com.cn/tcgames/qa](https://www.sigma-rt.com.cn/tcgames/qa/)。

## 五、注册登录

打开电脑端客户端，点击左上角的灰色小人图标，在弹出的窗口里用手机号注册并登录。登录后才正常使用连接、键位等功能；免费版与 VIP 版的差别见 [免费版与VIP功能区别.md](免费版与VIP功能区别.md)。

## 六、装好之后的第一步

1. 手机开启 USB 调试（开发者模式里打开），这是连接的前提。
2. 用 USB 数据线连接手机和电脑，在客户端里按提示完成连接，手机端 App 会在这时自动推送安装。
3. 连接成功后手机画面出现在电脑窗口里，再去配置键位和画质。

连接的完整步骤（USB / WiFi 扫码 / HDMI 三种方式）见 [手机连接电脑投屏步骤.md](手机连接电脑投屏步骤.md)；连接不上、键盘没反应这类问题见 [常见问题排查.md](常见问题排查.md)。
