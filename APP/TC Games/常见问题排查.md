## 一、连接类：电脑识别不到手机 / 连接失败

1. **先跑「诊断」**（官方）：点电脑端右上角的红色「诊断」按钮自查——诊断显示没有设备时，换一根能传数据的线（官方建议原装线，不少线只能充电）或换电脑后置 USB 口；电脑必须先正常识别手机，连接才可能成功。
2. **USB 调试没开**：设置 → 关于手机 → 连点 7 次版本号 → 开发者选项里打开 USB 调试。MIUI 等系统还要同时打开「USB 调试（安全设置）」（官方 FAQ：该选项需要手机插着 SIM 卡才能开）。
3. **之前正常、现在突然连不上**（官方）：重启手机再试；连接过程中弹过异常提示的，重连一次，或在手机上卸载手机端 App 后重新插拔连接。
4. **接口没插对**：台式机优先插机箱后置 USB 口；有条件的换 USB 3.0 接口（蓝色舌片）。
5. **软件冲突**：退出电脑上其他占用手机调试通道的助手类、投屏类软件再连。
6. **5037 端口被占用**（进阶）：识别不到设备、换线换口都无效时，检查安卓调试通道（ADB）的默认端口 5037 有没有被别的软件占住——这是安卓工具的通用排查手段，手机助手类软件是常见占用方：

   ```
   netstat -ano | findstr 5037      # 找出占用 5037 的进程号
   tasklist | findstr <进程号>       # 看它是什么程序
   taskkill -PID <进程号> -F         # 结束它（若是别的工具的 adb 进程，结束后重连即可）
   ```
7. **个别手机需要更多设置**：客户端里有「如何打开设置」入口，里面列了各品牌手机需要额外打开的开关。

## 二、键鼠类：键盘鼠标不生效

- **WiFi 连接时误选了「直播投屏」**（官方）：直播投屏只投画面不能控制，键鼠要生效就得用普通连接模式。
- **输入法抢占键盘**：按 `Ctrl + 空格` 切回英文输入法再操作——中文输入法开着时，按键会被输入法吃掉。
- **触屏一次唤醒**：连接后先用手指在手机屏幕上点一下，再回电脑操作（不少用户反馈这一步能恢复控制）。
- **鼠标只控制走路、或彻底失灵**（官方）：游戏内操作模式选错了，官方推荐用「左固定移动、右固定开火」那一档；改完再看鼠标表现。
- **鼠标有反应但打不准**（官方）：把「射击准星」挪到游戏界面里无弹窗遮挡的空白区域（官方推荐左上角），或把准心改成区域模式；原理与摆放细节见 [键位设置与鼠标调节.md](键位设置与鼠标调节.md)。
- **WASD 走不了路**（官方）：多是手机三指手势抢操作，按 [键位设置与鼠标调节.md](键位设置与鼠标调节.md) 第五节关闭三指截屏 / 三指长按。
- **`~` 键状态不对**：视角控制要在鼠标隐藏状态下进行，按 `~` 切换；`~` 键被游戏占用时可改绑其他键。
- **射击游戏里鼠标与移动键打架**：有用户反馈打开准星兼容设置、把准星区域设到屏幕右侧可解；仍冲突时重启手机再连。

## 三、画面类：卡顿、延迟、只有 60 帧

- **逐项过稳定性清单**：USB 3.0 通道、带供电的集线器、散热背夹、5GHz WiFi——对照 [画质帧率与延迟优化.md](画质帧率与延迟优化.md) 第三节。
- **游戏内也要调帧率**：只调软件不调游戏没用，两处都要开。
- **鼠标卡顿**（官方）：游戏鼠标按 DPI 1050、回报率 500Hz 调，软件帧率设 60FPS。
- **NVIDIA 显卡锁 60 帧**：N 卡控制面板 → 管理 3D 设置 → 最大帧速率设为显示器刷新率。
- **鸿蒙设备**：系统层面锁帧，设置解不开，属于系统限制。

## 四、声音类：电脑上没声音

在客户端右侧工具栏打开「传音」功能（软件传音），手机声音才会转发到电脑——默认不开。软件传音的音质受手机系统与机型影响，不同手机听感有差异。

## 五、直播类：怎么把画面推进直播间

用「直播投屏」方式连接（USB 或 WiFi，步骤同普通连接），它只投画面、不能键鼠控制。投出来之后在直播软件里做窗口捕获，选择 TC Games 的投屏窗口即可推流。注意直播投屏的画面上，免费版带水印。

## 六、多开类：同时控多台手机

免费版只支持 1 台设备。要同时连接并同步控制多台手机（VIP 最多 5 台），需要 VIP 版；多台手机可以并行投屏，键位方案按每台设备的分辨率分别配置。
