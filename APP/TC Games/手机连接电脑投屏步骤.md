> 本篇把 USB、WiFi 扫码、HDMI、直播投屏四种连接方式一次讲清：每种怎么做、需要什么、适合谁。

## 一、连接前准备

不论用哪种方式连接，都先做这三件事：

1. **打开 USB 调试**：手机「设置 → 关于手机 → 连续点 7 次版本号」进入开发者模式，再到「开发者选项」里打开 USB 调试。个别品牌的手机（如 MIUI）还需要同时打开「USB 调试（安全设置）」。
2. **用手机原装数据线**：只充电不传数据的线识别不了手机；传数据不稳的线会反复掉线。
3. **关掉电脑上其他不必要的软件**：官方说明里专门提到要避免连接冲突；占用手机调试通道的工具（如其他投屏、助手类软件）先退出。

## 二、四种连接方式对照

| 连接方式 | 延迟与画质 | 需要什么 | 适合场景 |
| --- | --- | --- | --- |
| USB 数据线 | 低延迟，稳定 | 数据线，手机开 USB 调试 | 日常玩游戏的首选 |
| WiFi 扫码 | 受网络影响 | 手机与电脑在同一局域网；首次需先用 USB 连一次 | 不想插线的轻度使用 |
| HDMI | 官方标注画质最高、延迟最低 | Type-C 转网卡 HDMI 拓展坞等一整套硬件 | 对画质延迟有硬要求的进阶用户 |
| 直播投屏 | 仅投屏 | USB 或 WiFi 连接，步骤同上 | 往直播平台推手机画面；**不能键鼠控制** |

新用户建议从 USB 或 WiFi 开始。

## 三、USB 连接（推荐）

1. 手机开启 USB 调试后，用数据线把手机接到电脑。
2. 在 TC Games 客户端上方选择连接设备，客户端识别到手机后点「连接」。
3. 连接过程中电脑端会自动把手机端 App 推送到手机，在手机上按提示允许安装。
4. 推送安装完成，手机画面自动投到电脑窗口。

手机第一次连上后，电脑会记住这台设备，之后插线即可直接连。

## 四、WiFi 扫码连接

1. **先用 USB 连接一次**——首次使用 WiFi 连接前必须走一遍 USB，否则扫不上。
2. 把手机和电脑接入**同一个 WiFi 网络**（同一局域网），确认网络畅通稳定。
3. 打开手机端 TC Games，点右上角「扫一扫」，扫描电脑端显示的二维码。
4. 扫码成功后自动投屏，可以拔掉数据线。

WiFi 方式的流畅度取决于路由器与信号：条件允许就用 5G 频段的 WiFi（不是手机套餐的 5G，是路由器的 5GHz 频段），避免用 2.4GHz；无线干扰多、画质卡顿时，换回有线 USB 更稳。

用过 WiFi 之后又被反复要求「重新用 USB 连接」的，官方常见问题页给了两条处理：把手机 USB 连接模式从「文件传输（MTP）」改成「仅充电」再试 WiFi；华为手机在开发者选项里打开「仅充电模式下允许 ADB 调试」。

## 五、HDMI 连接

HDMI 方式的画质与延迟表现最好，但需要一整套硬件，成本最高：

- Type-C 转网卡 HDMI 拓展坞
- 支持 HDMI/MHL 的显示器
- HDMI 切换器（二进一出）
- 支持有线 HDMI 输出的手机（WiFi 方式则要求手机支持 5G WiFi 和双频 5G 路由器）
- 网线、电脑

步骤：先用 USB 连接一次 → 按官方连接图把设备全部接好（部分手机需要设置 HDMI 模式）→ 在客户端填写手机 IP 地址或从已发现设备列表里选 → 连接成功即可使用。拓展坞需要单独购买，具体型号与连接图以官方页面为准。

## 六、直播投屏

直播投屏用 USB 或 WiFi 连接，步骤与上文一致，区别是它**只把手机画面投到电脑、不能键鼠控制**。投出画面后，在直播软件里把 TC Games 的窗口作为采集源即可。有用户用 OBS 做窗口捕获时，选择窗口列表里的 TC Games 投屏窗口，再按直播平台常规设置推流。

连接通了之后，接着就是配置键位与画面：键位见 [键位设置与鼠标调节.md](键位设置与鼠标调节.md)，画质帧率见 [画质帧率与延迟优化.md](画质帧率与延迟优化.md)。连接中卡在某一步，见 [常见问题排查.md](常见问题排查.md)。
