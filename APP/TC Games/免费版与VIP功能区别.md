## 一、免费版能完成的事

安装并登录后，免费版就能完成「手机投屏到电脑 + 键鼠玩手游」这条主线：USB/WIFI/HDMI 连接投屏、渲染与解码模式设置、电脑输入文字到手机、游戏键位下载、投屏快捷键自定义。只玩一两款热门手游、对画质不挑剔的话，免费版够日常用。

## 二、免费版与 VIP 的差别

按官方页面（截至 2026-09 查看，以后可能调整，以官网对比表为准）整理读者最常关心的几项：

| 功能 | 免费版 | VIP 版 |
| --- | --- | --- |
| 连接设备数量 | 1 台 | 5 台 |
| 分辨率 | 640P | 1080P |
| 帧率 | 60FPS | 120FPS |
| 码率 | 16M | 60M |
| 游戏按键自定义 | 部分支持（键盘行走、射击、开火、普通点击等） | 全部支持（拖拽滑动、滑动攻击、方向滑动、视角控制、虚拟准心、宏按键、智能施法、视野扩展等） |
| 手机息屏控制 / 暗屏投屏 | 不支持 | 支持 |
| 软件传音 | 不支持 | 支持 |
| 投屏/录屏去水印 | 不支持 | 支持 |
| 同步控制多台设备 | 不支持 | 支持 |
| 手机和电脑共享剪贴板 | 不支持 | 支持 |
| 游戏按键云存储 | 不支持 | 支持 |
| 鼠标侧键、滚轮绑定 | 不支持 | 支持 |
| 游戏动态画质修正、色彩调节、横屏拉伸去黑边、极简模式等显示增强 | 不支持 | 支持 |

对多数人影响最大的三项：**1080P 画质、进阶键位映射（尤其虚拟准心与宏）、手机息屏后台继续玩**。

## 三、订阅方式与购买流程

VIP 采用订阅制，包月、包季、包年三种，支持微信和支付宝支付。截至 2026-09 官网价格页显示：包月 ¥36、包季 ¥88、包年 ¥258；官网不定期做促销活动（当时页面同时挂着更低的活动价），实际金额以软件内购买页为准。做任务攒的积分可在购买或续费时直接抵扣。

购买流程（官方说明）：

1. 下载并安装 TC Games 电脑客户端；
2. 启动软件、登录账户，点「购买 VIP」；
3. 选择包月 / 包季 / 包年；
4. 微信或支付宝扫码支付，付款完成后生效。

付款遇到问题，官方价格页留的联系邮箱是 support@sigma-rt.com。

## 四、先试免费版还是直接上 VIP

不用纠结顺序：免费版装上就能用，把连接与键位跑通之后，再判断 640P 分辨率和基础键位是否够用——不够、且你玩的游戏吃视角控制或宏，再考虑订阅。版本信息与安装入口见 [下载与安装教程.md](下载与安装教程.md)。
