## 一、会员在哪开、怎么买

按应用内的固定路径走：

1. 登录后进入**「我的」**界面；
2. 点**「升级会员」**；
3. 在套餐列表里选要买的档位，按提示完成支付；
4. 支付返回后刷新「我的」，确认会员状态已变更。

几件购买前该弄清的事：

- **价格与档位**以应用内实时显示为准，界面会随活动调整，本篇不写死数字；
- **哪些功能要会员**同样以界面标注为准——没标锁的功能通常免费可用，具体边界装完自己过一遍最准；
- 付款前看清是否勾选了自动续费。若套餐含自动续费，会在支付前标明；事后要关，**别在 app 里翻入口（路径常藏得深），直接去支付渠道关**：
  - 微信：「我 → 服务 → 钱包 → 支付设置 → 扣费服务」，找到该项目点「关闭扣费服务」；
  - 支付宝：「我的 → 设置 → 支付设置 → 免密支付/自动扣款」，点「关闭服务」。
- **付了钱会员没到账**：先别重复付款。截图支付订单号与「我的」界面状态，用订单号找应用内客服处理——重复支付只会多一笔要退的账。

关不掉、被重复扣费、或扣费前没收到提醒的处理办法，以及这个品牌下另一类花钱的地方（付费课程），见 [付费课程与退费纠纷怎么办.md](付费课程与退费纠纷怎么办.md) 第四节。

## 二、登录相关问题

**收不到验证码**：先看手机信号与短信拦截（骚扰短信箱是重灾区）；隔一两分钟没收到就重发一次，别连点五六回触发频控。还不行就改用微信一键登录绕过去。

**换手机了**：直接在新机上用原手机号收验证码登录（或原微信授权），数据跟账号走，不需要额外迁移操作。前提是同一个手机号 / 同一个微信。

**忘记用哪种方式注册的**：两种方式都试一遍，哪个能进就用哪个——它们在应用里是两条独立的登录通道。

## 三、和「讯飞星火」是不是一个东西

不是。这是搜这个名字时最容易踩的混淆点：

| | 本应用（星火ai） | 讯飞星火 |
| --- | --- | --- |
| 开发者 | 成都元印科技有限公司 | 科大讯飞股份有限公司 |
| 包名 | `com.xznawq.sparkai` | `com.iflytek.spark` |
| 形态 | 对话 + 绘画 + AI市场工具 + 商单板块 | 对话、办公、翻译、智能体等综合助手 |

两者除了名字都带「星火」外没有关系，教程、账号、会员也互不通用。判断手上装的是哪个，看「我的」里的开发者信息或包名即可。

## 四、装不上 / 打不开 / 闪退

按命中率从高到低排：

1. **安装时被拦**：提示「不允许安装来自此来源的应用」时，去设置里为当前来源打开允许开关（步骤见 [下载与安装教程.md](下载与安装教程.md) 第三节）；
2. **解析包错误 / 安装包损坏**：多半是下载中断了，重新下一次，下完核对 MD5 是否为 `f46a28c4917df923bfa738813e07f052`；
3. **空间不足**：安装包 87.59M，安装解压还要更多，先清理出几百 MB 再装；
4. **装完闪退**：先重启手机；仍闪退就卸载后重装一次（账号跟手机号走，卸载不丢）；
5. **页面一直加载不出来**：换个网络试试（Wi-Fi 和流量互切），能进说明是网络侧的问题，不是应用坏了。

## 五、生成的内容能不能直接用

不能原样直接用，界面上「内容由AI生成，仅供参考」那行字就是这个意思：事实要复核、图片注意使用场景、重要文书当底稿改。详细展开在 [AI对话和绘画怎么用.md](AI对话和绘画怎么用.md) 第五节。

另外，网盘里那份安装包的版本是 2.3.1.5（信息记录于 2026-09-21），网上能搜到的版本号可能与之不同；遇到与本目录文档描述不一致的界面，以你手机上实际装的版本为准。
