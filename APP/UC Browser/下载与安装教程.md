## 一、安装前先核对你的设备

| 项目 | 要求 / 数值 |
| --- | --- |
| 操作系统 | Android 8.0 及以上（以官方页面当时显示为准） |
| 安装包版本 | 15.1.7.1393 |
| 安装包大小 | 232.95 MB（存储空间建议再留出一倍以上余量，安装过程会产生解包文件） |
| 安装包 MD5 | `e7209b7adeed9511563c8a64c96deba9` |
| 包名 | `com.UCMobile.intl`（国际版标识） |

你的手机如果是 Android 8.0 以下，安装时会被系统直接拒绝，提前看一眼系统版本可以省一次白下载。

## 二、获取安装文件

两种途径，按你设备的情况选：

1. **Google Play**：在 [Play 商店页面](https://play.google.com/store/apps/details?id=com.UCMobile.intl) 点安装，适合带谷歌服务的手机，后续更新也由商店接管。
2. **APK 安装**：设备没有 Google Play（部分国产手机、平板、盒子）时，用 APK 文件手动装，也就是本篇后面第三、四节的内容。

APK 文件从这里拿：**UC Browser 安装文件资源（夸克网盘）**：<https://pan.quark.cn/s/f90684698de2>。夸克网盘的分享链接需要先「转存」到你自己的网盘，再从你的网盘里下载到手机；下载完成后是一个 `.apk` 文件。

## 三、校验安装包完整性（可选但建议）

大体积文件经网盘转存、多次下载后偶有损坏，装之前花一分钟核对 MD5，能避免「装不上又找不到原因」。

在电脑上执行：

```powershell
# Windows（PowerShell）
certutil -hashfile "UC Browser_v15.1.7.1393.apk" MD5
```

```bash
# macOS / Linux
md5sum "UC Browser_v15.1.7.1393.apk"
```

输出结果与第一节表格里的 MD5 完全一致即为完整；不一致就重新下载一次再装。

## 四、APK 安装步骤

1. 用手机自带的「文件管理」找到刚下载的 `.apk`，点它。
2. 系统会提示「出于安全考虑，禁止安装未知应用」，这是 Android 8.0 起的按应用授权机制：你点「设置」，给**你正在用的这个文件管理器**（或浏览器）勾选「允许安装未知应用」。
3. 回到安装页，点「安装」，等进度走完（这份包超过 200 MB，低配手机上多等十几秒是正常的）。
4. 装完点「打开」，第一次启动会有条款与数据收集说明，同意后进入主界面。

装好之后建议先做两件事：把界面换成你看得懂的语言（见[界面语言设置.md](界面语言设置.md)），以及需要的话把它设成系统默认浏览器（见[设为默认浏览器.md](设为默认浏览器.md)）。

## 五、两种途径怎么选

| 对比项 | Google Play | APK 安装 |
| --- | --- | --- |
| 适用设备 | 带 Google 服务的手机 | 任意 Android 8.0+ 设备 |
| 版本更新 | 商店自动更新 | 官方出新版后需重新下载安装包覆盖安装 |
| 前置条件 | 可访问 Play 商店 | 需授权「安装未知应用」 |

两条途径装出来是同一个包名 `com.UCMobile.intl`，数据互通；哪条顺手用哪条。装不上、装完闪退之类的问题，汇总在[常见问题与故障排除.md](常见问题与故障排除.md)。
