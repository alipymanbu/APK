# 把 UC Browser 设为默认浏览器的方法

> 你想让微信、短信、邮件里点到的链接都用 UC Browser 打开，光装上不够，得在系统层把「浏览器应用」指给它。本篇给两条路径（应用内开关、系统设置手动指定），外加「点了链接还是用旧浏览器打开」的处理办法。

## 一、路径一：应用内开关（最快）

1. 打开 UC Browser，点底部菜单 → **Settings**（设置）。
2. 在设置列表里找到**设为默认浏览器**（英文界面下是 **Set as default browser** 一类的条目）。
3. 打开这个开关，系统会自动跳到手机的「默认应用」配置页。
4. 在**浏览器应用**（Browser app）列表里选 **UC Browser**，确认即可。

这条路的入口名称在不同版本里措辞略有出入，找不到就换下面的系统设置路径，效果一样。

## 二、路径二：系统设置手动指定

1. 退出应用，打开手机的**系统设置**。
2. 进**应用**（Apps / 应用管理）。
3. 找到**默认应用**（Default apps；部分品牌叫「默认应用管理」）。
4. 点**浏览器应用**（Browser app）。
5. 在列表里选 **UC Browser**。

不同品牌的入口措辞略有差异，但结构都是「应用 → 默认应用 → 浏览器应用」三层；找不到时在系统设置顶部的搜索框里搜「默认应用」或「default」最快。

## 三、点了链接还是用旧浏览器打开

系统记住了旧的默认浏览器时，新设置可能不生效，按下面顺序处理：

1. 进系统设置 → 应用，找到当前默认的那个浏览器（比如 Chrome）。
2. 进它的应用信息页 → **打开方式**（Open by default）。
3. 点**清除默认设置**（Clear defaults）。
4. 回到任意应用点一个 `http` 开头的链接，系统会重新弹出「选择应用」对话框。
5. 选 **UC Browser**，并勾选**始终 / Always**，绑定完成。

做完第 5 步后再点链接，就会固定走 UC Browser 了。

## 四、验证是否生效

最简单的验证：在微信或短信里找一个网页链接点开，看拉起的是不是 UC Browser；也可以在它里面打开几个页面试试加载与返回手势是否顺手。如果你想把界面也换成中文，先看[界面语言设置.md](界面语言设置.md)；安装或启动本身出问题的，翻[常见问题与故障排除.md](常见问题与故障排除.md)。
