# UC Browser 国际版界面语言设置（改成中文的方法）

> 国际版 UC Browser 默认英文界面，语言列表里**没有简体中文、有繁体中文**，这是很多读者装完后的第一个疑问。本篇讲改语言的具体路径、重启生效的机制，以及找不到中文选项时怎么排查。

## 一、先确认你装的是国际版

只有包名 `com.UCMobile.intl` 的国际版才有「语言列表里没有简体中文」这件事；面向国内市场的 UC浏览器是简体中文界面，不存在这个问题。两个版本的区别对照在[国际版与国内版的区别.md](国际版与国内版的区别.md)，不确定自己装的是哪版就先看那篇。

## 二、改语言的步骤

1. 打开 UC Browser，点底部中间的**菜单按钮**（三横线图标）。
2. 在菜单面板里点**Settings**（设置；左下角）。
3. 在设置列表里点**Language**。
4. 在语言列表里选**繁體中文**（Traditional Chinese），或你需要的其他语言。
5. 应用会弹窗提示需要重启，点**Restart**，重新打开后界面就是你选的语言。

整个过程只改 UC Browser 自己的界面语言，不影响手机的系统语言。

## 三、为什么找不到「简体中文」

这是国际版的产品划分，不是你的操作问题：国际版面向海外市场发布，界面语言列表长期不包含简体中文，中文用户对应的是**繁體中文**一项。多个渠道的资料口径一致；你设备上的实际列表以 Settings → Language 显示为准。如果你的使用场景绕不开简体中文，那条路是装国内版 UC浏览器（从官网 [uc.cn](https://www.uc.cn/) 获取），两者可以在同一台手机上并存，互不覆盖。

## 四、改完又变回英文 / 列表里没有中文

按顺序排查：

1. **改完没点重启**：语言变更必须等它提示重启后才生效，直接退出再开不算数，会退回原语言。
2. **进错了设置页**：手机系统设置里也有「语言与输入法」，改那里不会影响 UC Browser 的界面，要改就得在应用内 Settings → Language。
3. **列表确实没有中文项**：个别旧版本或特殊渠道包的语言列表不同，以你设备上实际显示的选项为准；需要中文界面时按第三节的方法换国内版。

换语言之外，初次上手还常用到「把链接都用它打开」的设置，步骤在[设为默认浏览器.md](设为默认浏览器.md)。
