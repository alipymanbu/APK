## 一、高频问题速答

| 问题 | 答案 |
| --- | --- |
| 卸载 Aurora Store 会影响已装的应用吗 | 不会，已装的应用原样保留；只是之后没法用它更新 |
| 需要 Root 吗 | 不需要，普通设备直接用 |
| 需要谷歌服务或 microG 吗 | 不需要，有没有都能跑 |
| 它安全吗 | 开源（GPL v3）、F-Droid 可验签；它拉取的就是 Play 商店的应用本体 |
| 为什么匿名登录找不到某些入口 | 应用库、购买历史、Beta、评论等功能只对登录账号开放 |
| 和 Play 商店最大的区别 | 无 Play Protect、不受设备未认证标记影响、不需要谷歌服务框架（官方 wiki 口径） |

## 二、安装报错排查

| 现象 | 先查什么 | 处理 |
| --- | --- | --- |
| 提示「不允许安装未知应用」 | 打开安装包的那个应用（浏览器/文件管理器）有没有拿到安装权限 | 设置 → 应用 → 特殊应用权限 → 安装未知应用，给对应应用放行 |
| 点安装后卡住不动 | 是否开了会话安装以外的安装方式但没配好 | 切回默认 Session 安装再试 |
| 提示「未安装应用」 | 是不是设备上有同名包（比如装过 FakeStore 或旧版） | 卸掉冲突包再装；不确定就先重启设备 |
| 装上就闪退 | 系统版本是否达到 Android 6.0+ | 系统太老装了也跑不动；满足版本仍闪退，换官方渠道的包重装 |

安装方式（Session / Shizuku / Root）的选择依据见[下载与安装教程](下载与安装教程.md)第五节；对着具体报错文字找办法（含「Server busy」、MIUI 优化、启动页卡死）见[安装失败与报错处理](安装失败与报错处理.md)。

## 三、登录失败排查

1. **匿名登录一直失败**：官方说明令牌分发服务不算稳定，宕机时登录会失败。等一段时间再试；急着用，先切个人账号登录。
2. **个人账号登录报错**：先完成 Google 弹出的安全验证（新设备、新网络常见），再回来登录；密码没错仍失败，换网络试一次。
3. **登录成功但列表空白**：多为分发服务的临时故障（匿名模式），重启应用或过段时间再进。

怀疑自己被限流拉黑、或想区分「只有我登不上」和「所有人都登不上」，[安装失败与报错处理](安装失败与报错处理.md)第四节有官方自检入口。

## 四、下载与更新排查

| 现象 | 原因与处理 |
| --- | --- |
| 下载中途失败 | 网络切换或限速，到下载管理器里点重试 |
| 大型游戏装完进不去 | OBB 扩展数据没下全，确认存储权限已给、重新触发一次下载 |
| 某应用永远提示有更新/永远没有 | 检查是否把它加进了忽略更新（黑名单）；匿名会话的地区也会影响更新可见性，见[设备与地区伪装](设备与地区伪装.md) |
| 大型游戏无法更新 | Play Asset Delivery 分发的应用不支持，官方明确列为限制 |
| 更新反复失败 | 换安装方式（Session 失败可试 Shizuku/Root），或确认设备剩余空间 |

## 五、FakeStore 是什么、要不要装

部分应用会检测设备上有没有 Play 商店，检测不到就罢工。FakeStore 是 Aurora OSS 出的一个占位应用，占用的包名与 Play 商店相同（`com.android.vending`），装上它只为让这类检测通过、防止应用闪退，不提供任何商店功能。**普通设备上不用装**——你设备上有真的 Play 商店，装 FakeStore 反而冲突；它是给无谷歌服务设备准备的后备手段。

## 六、什么情况该怀疑是它自己的问题

- 接口临时失效：谷歌调整接口后，搜索、下载可能整体异常，等版本更新即可，反复重装无效。
- 分发服务器宕机：匿名登录全军覆没但个人账号能登，就是这个原因。
- 其他异常先到官方仓库的 Issue 区搜关键词（[gitlab.com/AuroraOSS/AuroraStore/-/issues](https://gitlab.com/AuroraOSS/AuroraStore/-/issues)），确认是不是已知问题，别急着降级重装。

排查完还是不行，重装一遍干净包是最省事的兜底：[AuroraStore 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8a2c0f937348)。
