## 一、两种方式怎么选

| 对比项 | 匿名登录 | 个人账号登录 |
| --- | --- | --- |
| 需要输入账号密码 | 否，一键进入 | 是，Google 账号 + 密码 |
| 搜索、下载、安装应用 | 可以 | 可以 |
| 查看自己的应用库 / 购买记录 | 不可以 | 可以 |
| 写或改评论 | 不可以 | 可以 |
| 加入 Beta 计划 | 不可以 | 可以 |
| 付费应用的购买 | 不可以 | 按界面提示走购买流程 |
| 风险点 | 分发服务器忙时会登录失败 | 账号在大厂有登录记录，介意就用小号 |

结论很直接：**只是找应用、下应用，匿名就够**；要用到「自己账号里已有的东西」（已购应用、愿望单、评论），才登录个人账号。

## 二、匿名登录：怎么用、有什么限制

首次启动或添加账号时选「匿名」，不需要填任何东西，应用会替你从公共的令牌分发服务取一个临时会话，之后你就能搜和下 Play 商店里的应用了。

匿名模式明确用不了的功能（官方 README 列出的限制）：

- 应用库（Library）
- 购买历史
- 编辑推荐（Editor's choice）
- Beta 计划
- 新增或修改评论

另外两点实际影响不小：

1. **分发服务器不算稳**。官方自己写明「Token dispenser server is not super reliable, downtimes are expected」。登录失败、搜索一直转圈时，多半是它临时挂了，过段时间再试，别急着删应用重装。历史上还发生过**整段匿名登录不可用**的时期（2023 年分发服务曾因谷歌大规模封禁临时下线，见[安装失败与报错处理](安装失败与报错处理.md)的背景说明）；「所有人都登不上」时只能等官方恢复。
2. **匿名会话带的地区不由你决定**。分发池里的临时账号来自不同国家，所以不同时间进匿名会话，看到的应用可见性和更新提示可能不一样。想锁定某个地区，用设备与地区伪装设置，见[设备与地区伪装](设备与地区伪装.md)。

## 三、个人账号登录：要注意什么

选「Google 账号」登录，输入你的谷歌账号密码即可。几点经验：

- **可以添加多个账号**。4.8.4 起支持多账号，账号之间切换后，库和更新列表跟着换。
- **可能触发安全验证**。新设备、新网络环境登录时，Google 可能弹出安全提示（异地登录提醒、二次验证等），按提示在手机或网页上完成验证后再回来登录。
- **介意账号关联就用小号**。登录后你的下载与搜索行为会挂在这个账号下，这是谷歌那边能看到的事；用常用号还是专门注册一个号，自己权衡。
- **已购应用**：在 Play 商店买过的应用，登录同一账号后能重新下载；没买过的付费应用无法从这里直接买断下载（4.8.4 起加入了购买流程入口，以应用内实际显示为准），详见[搜索下载与更新应用](搜索下载与更新应用.md)的付费应用一节。

## 四、登录后数据都发到哪

官方 wiki 有明确说明，第三方转述如下：

- **发给谷歌**：你设备上已装应用的包名列表（用来查更新）、搜索词、下载行为、IP 地址。想减少包名上报，可以在设置里把不想让它代查更新的应用加进忽略更新（黑名单）列表，见[搜索下载与更新应用](搜索下载与更新应用.md)。
- **匿名登录时发给分发服务器**：一次获取令牌的请求，令牌在服务器侧生成；官方说明其不记录日志，仅在限流需要时记录 IP。
- 应用本体不嵌广告、不向你收费，收入与数据链路见官方隐私政策页面。

## 五、登录失败先看这三处

1. 分发服务器状态（匿名模式）：等几分钟再试。
2. 网络出口：部分网络下连 Play 接口不通，换个网络试试。
3. 账号验证：个人账号登录被弹安全提示时，先去完成验证。

更细的报错对照，见[常见问题与排查](常见问题与排查.md)。
