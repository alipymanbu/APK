## 一、安装前先确认三件事

| 检查项 | 要求 | 说明 |
| --- | --- | --- |
| 系统版本 | Android 6.0 或更高 | 截至 2026-09，官方 4.8.4 版要求 Android 6.0+，以官方发布页为准 |
| 存储空间 | 预留安装包体积的数倍 | 安装包约 8.93M，装完还要给下载的应用留空间 |
| 谷歌服务 | 不需要 | 没有 Google Play 服务、没有 microG 的设备同样能装能跑 |

Aurora Store 本身不是从谷歌应用商店分发的，所以走的是「安装包直接安装」这条路，安装时系统会提示你放行，下面第三节会写具体操作。

## 二、从哪拿安装文件

两个来源，任选其一：

1. **网盘转存**：[AuroraStore 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8a2c0f937348)，转存后下载到手机即可。这份安装包信息：版本 4.8.4-preload、大小 8.93M、包名 `com.aurora.store`。
2. **官方渠道**（以官方当时显示为准）：
   - 官网下载页：[auroraoss.com/aurora-store](https://auroraoss.com/aurora-store)
   - GitLab Releases：[gitlab.com/AuroraOSS/AuroraStore/-/releases](https://gitlab.com/AuroraOSS/AuroraStore/-/releases)
   - F-Droid：[f-droid.org/packages/com.aurora.store](https://f-droid.org/packages/com.aurora.store/)（由 F-Droid 签名）
   - IzzyOnDroid 源：[apt.izzysoft.de/fdroid/index/apk/com.aurora.store](https://apt.izzysoft.de/fdroid/index/apk/com.aurora.store)（可复现构建）

从网盘这类渠道拿到安装包后，想核对是不是官方包，可以对官方公布的签名证书指纹（官方 README 里公布的 SHA-256 为 `4C:62:61:57:AD:02:BD:A3:40:1A:72:63:55:5F:68:A7:96:63:FC:3E:13:A4:D4:36:9A:12:57:09:41:AA:28:0F`，以官方页面为准）；F-Droid 渠道的包由 F-Droid 自己签名，指纹另见其页面说明。

## 三、安装步骤

1. 把安装包传到手机（或直接在手机上下载）。
2. 打开安装包时，系统会提示「不允许安装未知应用」，按提示跳到设置里，给**你用来打开安装包的那个应用**（浏览器、文件管理器）勾上「允许安装未知应用」。各家系统的入口不完全一样，常见路径：设置 → 应用 → 特殊应用权限 → 安装未知应用。
3. 回到安装包点「安装」，等进度走完。
4. 点「打开」进入首次启动配置。

如果第 3 步反复失败或报「未安装应用」，跳到[常见问题与排查](常见问题与排查.md)对照处理，多数是安装方式与系统限制的匹配问题，不是包坏了。

## 四、首次启动会问什么

第一次打开 Aurora Store 会有几步引导：

1. **语言与外观**：选界面语言、明暗主题。
2. **服务条款**：需要同意 Aurora OSS 的服务条款才能继续。
3. **登录方式**：匿名登录，或者用你的 Google 账号登录。两者差别与选择依据见[匿名登录与账号登录](匿名登录与账号登录.md)——只想先把应用装上，选匿名即可，之后随时能换。

## 五、安装方式（Installer）怎么选

装好之后，Aurora Store 里装的每一个应用还要经过一个「安装器」落到系统里。设置里可以切换，常见选项如下（截至 4.8.4，以应用内实际显示为准）：

| 安装方式 | 前提 | 特点 |
| --- | --- | --- |
| Session（会话安装） | 无，默认方式 | 调用系统安装会话，每次安装可能要你手动点一下确认 |
| Shizuku | 设备上跑着 Shizuku，Android 8.0+ | 支持后台静默安装；安装来源显示与 Play 商店一致 |
| Root | 设备已 Root | 支持静默安装，能力最全 |
| App Manager | 装了 App Manager 这款工具 | 借用它的安装接口 |
| Native（原生安装） | 无 | 走系统传统安装流程；split/bundled 拆分格式的应用装不了 |

普通使用保持默认的 Session 就够；想让它像 Play 商店一样在后台自动把更新装好，才需要去折腾 Shizuku 或 Root。MIUI 设备注意：Session 安装器要求先在开发者选项里关闭「MIUI 优化」并重启，否则会话安装可能报错，对照处理见[安装失败与报错处理](安装失败与报错处理.md)。
