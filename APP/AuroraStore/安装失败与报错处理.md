## 一、安装时提示「Server busy, please try again later」

这是 2026 年 9 月起大量用户报告的问题（官方仓库 [issue #1566](https://gitlab.com/AuroraOSS/AuroraStore/-/work_items/1566)），截至 2026-09 仍处于未解决状态。特征：

- 主要发生在**匿名账号**上，点安装就报「Server busy, please try again later（服务器忙，请稍后再试）」；
- 清缓存、强停应用、换 VPN、重启设备**都不一定管用**（多条用户反馈互相印证）；
- 属于服务端对匿名会话的限流或封锁，不是你设备坏了。

按有效程度排序的处理办法（来自 issue 区与社区讨论，属用户经验而非官方结论）：

1. **刷新匿名账号后多试几次**。有用户第 5、6 次尝试才成功——这是一场碰运气的重试，不是一次性的修复。
2. **从应用详情页单点重试**，别从批量更新队列里跑。有用户反映单点重试成功率更高。
3. **等几个小时再试**。有用户观察到早上报错、晚上恢复的时段性。
4. **急用的应用换渠道**：开发者自己发布到 F-Droid 或其官方仓库的包，直接从那边装，不经过 Play 这条链路。

追进度可以订阅上面的 issue，或到[常见问题与排查](常见问题与排查.md)看其他报错的区分方法。

## 二、提示「解析包出现问题」（There was a problem parsing the package）

开发者本人在官方 issue 里给过的口径：**split/bundled 格式的应用（按需拆分的安装包）不能用 Native 安装器装**，要换成 Session 安装器。在 MIUI 上还有一层：Session 安装器要求**关闭 MIUI 优化**（设置 → 更多设置 → 开发者选项里），关完重启再试。

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| 解析包出现问题 | 用了 Native 安装器装 split 应用 | 换 Session 安装器 |
| 关了 MIUI 优化还是报 `INSTALL_FAILED_INTERNAL_ERROR: Permission denied` | MIUI 对会话安装的权限限制（MIUI 12 时代的记录） | 关闭 MIUI 优化并重启仍不行的话，换 Shizuku / Root 方式，或用系统安装器装导出的 APK |

安装方式在哪切换、各方式的前提，见[下载与安装教程](下载与安装教程.md)第五节。

## 三、卡在启动页转圈进不去

官方 issue 区有对应记录（4.2 时代的 [#899](https://gitlab.com/AuroraOSS/AuroraStore/-/issues/899)，界面名称以你手上版本为准）：设置 → Networking（网络）分组里有一个「Insecure anonymous session（不安全匿名会话）」开关，开着它会导致应用卡在启动页。处理顺序：

1. 卡在启动页时，点右上角「···」菜单还能进设置；
2. 到 Networking 分组把「Insecure anonymous session」关掉；
3. 退出重进，用普通「匿名」方式登录。

## 四、反复被限流：先确认是不是 IP 被拉黑

官方 wiki 提到：令牌分发服务会给匿名登录发凭证，**频繁触发 rate-limit（限流）报错时**，可以用官方提供的自检地址确认自己的出口 IP 是不是被临时拉黑：`https://auroraoss.com/api/amiblocked`（以官方 wiki 当前说明为准）。确认被拉黑的，按官方指引提交机密 issue（附 IP）申请解除。

背景补充：匿名登录历史上发生过**整段不可用**的时期（2023 年分发服务曾因谷歌大规模封禁临时下线，见 [issue #912](https://gitlab.com/AuroraOSS/AuroraStore/-/work_items/912)）。所以「所有人都登不上」和「只有你登不上」是两种问题：前者等官方恢复，后者按本篇第三节、第四节自查。登录方式本身的取舍见[匿名登录与账号登录](匿名登录与账号登录.md)。
