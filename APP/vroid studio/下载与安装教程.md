## 一、先分清：安卓上的它叫 VRoid Mobile

在搜索引擎里搜「vroid studio 安卓版」，能装到安卓手机上的那个应用（包名 `net.pixiv.vroid.android`）官方名字是 **VRoid Mobile**，是 pixiv 出品的手机头像相机应用：捏 3D 角色、换装、拍照。而叫 **VRoid Studio** 的那款是 Windows / macOS / iPad 上的桌面建模软件，两者不是同一个应用，工程数据也不通用，具体差异见 [与桌面版有什么区别.md](与桌面版有什么区别.md)。

本篇讲的安装对象是手机版 VRoid Mobile。

## 二、安装包事实与系统要求

网盘资源里这份安装包的信息如下：

| 项目 | 值 |
| --- | --- |
| 应用名称 | VRoid Mobile（安卓手机版） |
| 版本 | 1.16.3 |
| 包名 | net.pixiv.vroid.android |
| 安装包大小 | 98.32 MB |
| MD5 | 29774CA4813F96B6ED1FD704FB6F0582 |

系统要求（以官方帮助中心与商店页面当时标注为准）：

- Android 6.0 或更高，且设备支持 OpenGL ES 3.0；
- 想用 AR 拍摄，设备需支持 ARCore（苹果端对应 ARKit）；不支持 ARCore 也能用虚拟相机拍摄，见 [AR拍摄与虚拟相机教程.md](AR拍摄与虚拟相机教程.md)；
- 官方说明不保证在所有设备上都能正常运行，发售较久、内存较小的机型体验可能受限。

安装包本身约 98 MB，安装与运行还需要额外空间，装之前留出几百 MB 余量比较稳妥。

## 三、途径一：Google Play

官方在 Google Play 上架了安卓版：[https://play.google.com/store/apps/details?id=net.pixiv.vroid.android](https://play.google.com/store/apps/details?id=net.pixiv.vroid.android)

商店里的版本号通常比网盘里这份更新，两者不是同一个文件。如果你的网络环境访问不了 Google Play（一直转圈或提示无法连接），就走下面途径二。

## 四、途径二：安装包直接安装

从 **VRoid Mobile 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/56c782aa129f](https://pan.quark.cn/s/56c782aa129f) 转存并下载 APK 文件，然后：

1. 在手机上点开下载好的 APK，系统会提示「出于安全考虑，已禁止安装未知来源应用」；
2. 按提示进入设置，找到「安装未知应用」权限（部分品牌的入口在「设置 → 应用 → 特殊应用权限」下），给浏览器或文件管理器勾选「允许从此来源安装」；
3. 返回安装界面点「安装」，等进度走完；
4. 装完打开应用。用到账号相关功能（把模型传到 VRoid Hub、跨设备找回形象等）时需要登录 pixiv 账号，见 [模型数据转移与VRoidHub使用.md](模型数据转移与VRoidHub使用.md)。

不同品牌安卓手机（小米、OPPO、vivo、华为等）的权限入口名称略有差别，流程都是「点开 APK → 给发起安装的应用授权 → 安装」。

## 五、装不上时的排查

| 现象 | 先查什么 |
| --- | --- |
| 提示「解析包时出现问题」 | 下载不完整（重新下载，必要时核对 MD5）；或安卓版本低于要求 |
| 提示存储空间不足 | 清出空间再装，安装过程需要的余量比安装包本身大 |
| 安装按钮一直灰色 | 检查是否给了「安装未知应用」授权 |
| 装上后打开就闪退 | 机型偏旧或内存偏小（官方明说不保证所有设备），先把系统升到最新再试 |

装好后，从 [捏脸与形象定制入门.md](捏脸与形象定制入门.md) 开始做你的第一个 3D 形象；使用中碰到 AR 入口不见、照片保存失败之类的问题，见 [拍摄问题排查.md](拍摄问题排查.md)。
