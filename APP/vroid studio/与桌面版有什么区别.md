# VRoid Mobile 与 VRoid Studio 桌面版有什么区别

> 两个名字都出自 pixiv 的 VRoid 项目，搜索时极易搞混；本篇用一张对照表分清它们，并说清数据在两者之间怎么流动。

## 一、一张表分清两者

| | VRoid Mobile（本套文档的主角） | VRoid Studio（桌面版） |
| --- | --- | --- |
| 平台 | Android / iOS 手机 | Windows / macOS / iPad |
| 定位 | 头像相机应用：捏形象、换装、拍照 | 3D 建模软件：像画画一样精细建模 |
| 捏法 | 部件组合 + 滑杆调参 | 部件与滑杆之外，还有纹理画笔（带图层、支持压感）等编辑工具 |
| 模型导出 | 应用内不导出文件；模型经 VRoid Hub 可下载为 VRM | 直接导出 VRM 0.0 / 1.0 文件 |
| 工程文件 | 无，模型存在应用内、经 Hub 中转 | .vroid 文件 |
| 价格 | 免费 | 免费 |

判断该装哪个的依据：想在手机上捏形象、拍照发社交平台 → Mobile；想精细建模、把模型文件拿去 VRChat 等平台用 → Studio。安卓手机上装的那个（包名 `net.pixiv.vroid.android`）是 Mobile，安装见 [下载与安装教程.md](下载与安装教程.md)。

## 二、数据怎么流动

- 手机版捏的形象存在应用内。想拿到 **VRM 文件**（很多 VR / 3D 应用使用的模型格式），路径是：把模型上传到 VRoid Hub，再从 Hub 下载 VRM。官方限定 1.14.4 及以后版本上传的模型才支持下载，条件细节见 [模型数据转移与VRoidHub使用.md](模型数据转移与VRoidHub使用.md)；
- 从 Hub 召回到手机版的模型**不能再编辑**；
- 桌面版的 .vroid 工程文件手机版打不开；
- VRM 是导出格式，不是工程格式：官方明确说明 VRM 文件不能直接导入 VRoid Studio 编辑，手机版同理。

## 三、常见误会

- 「手机上装 VRoid Studio」：VRoid Studio 没有安卓版；安卓上那个应用是 VRoid Mobile，只是常被叫成「VRoid Studio 手机版」。
- 「手机捏的形象发到 VRChat」：可行，走「上传 Hub → 下载 VRM」这条路，但要留意模型里道具的下载许可与付费道具的限制。
- 「两边形象通用」：模型数据不互通，各是各的存法，只有经 VRoid Hub 中转才能跨端使用。
