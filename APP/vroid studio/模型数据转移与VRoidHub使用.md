## 一、换手机：没有设备间的直接转移

官方明确：目前没有把模型数据从旧设备直接搬到新设备的功能。账号侧的东西会跟着 pixiv 账号走——**硬币（应用内货币）与已购的付费道具可以转移**。

模型本身要走 VRoid Hub 中转：

1. 在旧设备上把模型上传到 VRoid Hub；
2. 新设备装好应用并登录同一个 pixiv 账号；
3. 在新设备上从 VRoid Hub 召回该模型。

两点注意：

- **召回的模型不能再编辑**：手机版只能使用从 Hub 召回的形象，不能改它的脸和发型；
- 所以换机前最好在旧设备上把想改的都改完、想传的都传完。

## 二、上传与召回

上传在应用内完成，发布时按提示填写模型信息即可。召回则是在拍摄等场景里从 VRoid Hub 调取角色，召回的形象可用于拍照，包括多人合影场景（见 [AR拍摄与虚拟相机教程.md](AR拍摄与虚拟相机教程.md)）。

「召回的模型不动」「Hub 上的角色不显示」都属于官方帮助中心有专门条目的已知问题，逐步排查见 [拍摄问题排查.md](拍摄问题排查.md)。

顺带一提：在电脑浏览器里打开 VRoid Hub 的模型页面，可以使用 Face Tracking 功能，让模型跟随你的头部表情与上半身动作；该功能截至 2025 年 2 月不支持手机端，效果依设备与环境而定。

## 三、VRM 文件怎么拿

VRM 是 3D 人形模型的通用格式，VRChat 等应用都使用它。手机版的应用内不能直接导出 VRM，正确路径是：

1. 把模型上传到 VRoid Hub（官方限定：通过 1.14.4 或更高版本的应用上传的模型）；
2. 在 VRoid Hub 的模型页面下载 VRM。

拿不到 VRM 的几种情况：

- 模型是其他用户创建的；
- 模型里包含不允许下载的道具；
- 下载后也不允许做的事：改造付费道具、把模型与纹理再分发（无论是否改造过），以及把它们以「允许下载」的条件再传上 Hub。

模型与纹理仅限自己使用的场景（如上传到 Hub 或 VR 社交平台但不对他人开放下载）不在禁止之列。

## 四、拿模型能做什么：使用条件

按官方帮助中心，用 VRoid Mobile 自带预设（pixiv 持有权利的发型、服装等）做出来的模型，创作者可以这样使用（以官方页面当时标注为准）：

| 用途 | 是否允许 |
| --- | --- |
| 当头像使用 | 允许 |
| 暴力表现 | 允许 |
| 性内容表现 | 允许 |
| 企业商用 | 允许 |
| 个人商用（含赠送活动等营利行为） | 允许 |
| 改造 | 允许（付费道具与纹理除外） |
| 再分发 | 不允许 |
| 署名 | 不需要 |

pixiv 不持有权利的内容（例如来自第三方的素材）另有单独条款，使用前到官方帮助中心核对对应条目。

## 五、登录与账号

Hub 上传、召回、硬币与付费道具转移，前提都是登录 pixiv 账号。登录遇到问题时，官方帮助中心有专门条目（[I can't log in to VRoid Mobile](https://vroid.pixiv.help/hc/en-us/articles/360000648821-I-can-t-log-in-to-VRoid-Mobile)），可按条目逐步排查。

还没安装应用的，从 [下载与安装教程.md](下载与安装教程.md) 开始；两代产品怎么分清，看 [与桌面版有什么区别.md](与桌面版有什么区别.md)。
