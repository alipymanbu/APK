# ProMovie 打不开闪退与拍不了怎么办

> 启动闪退、按了没反应、拍完找不到文件——按这几条排查，多数是权限、存储或版本问题。

## 一、按了红点拍不了

依次检查这五项，查到哪项不对就停在哪项修：

| 检查 | 怎么做 | 表现 |
| --- | --- | --- |
| 相机权限 | 系统设置 → 应用 → ProMovie → 权限，确认「相机」已允许 | 取景黑屏、按红点无反应 |
| 存储权限 | 同上，确认「照片与视频 / 存储」已允许 | 能拍但相册里没有 |
| 存储空间 | 清出至少 1~2GB 空余再试 | 拍摄中断、保存失败 |
| 系统版本 | 系统过低可能装不上或功能缺失，看安装时的系统要求 | 装不上、功能灰着点不了 |
| 版本本身 | 确认装的是最新可用版本，旧版可能带已知问题 | 各种莫名其妙的失灵 |

权限这一项最常见：当初安装时点了个「拒绝」，后面所有功能都跟着瘸，先查它。

## 二、打开就闪退

1. **先补权限**：相机、存储、麦克风三项都允许，再重新打开；
2. **清后台重开**：把应用从最近任务里划掉，重新点图标启动；
3. **看版本**：应用的历史更新日志里修过「部分安卓机型启动闪退」的问题——如果你这台机型一直闪退，优先确认手上这版是不是够新；
4. **看兼容性**：系统版本太低跑不动新版时，能升级系统就升级，升不了就只能停在能用的那版。

## 三、拍完找不到文件

- 确认保存路径：录像回放在拍摄界面左侧的**播放入口**里；照片一般进系统相册。两处都没有，就是存储权限没给或空间满了；
- 相册里等一下刷新：刚拍完立刻去翻有时还没扫描到，退出相册重进。

## 四、画面异常的几类情况

| 现象 | 处理 |
| --- | --- |
| 画面方向不对、转手机不跟随 | 检查系统自动旋转是否被锁；再不行清后台重启应用，见[水印开关与镜像翻转设置.md](水印开关与镜像翻转设置.md) |
| 录 4K 卡顿、掉帧 | 降到 1080p 再录，高规格对性能与散热要求高，见[拍摄参数调节教程.md](拍摄参数调节教程.md) |
| 画面偏色、发黄 | 白平衡没对，回参数栏调白平衡，见[拍摄参数调节教程.md](拍摄参数调节教程.md) |
| 美化完保存失败 | 存储权限被关，见[图片美化与拼图使用教程.md](图片美化与拼图使用教程.md) |

以上都试过还是不行，把应用卸载后重新装一遍（包从[ProMovie 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d37ba7cad650)取，步骤见[下载与安装教程.md](下载与安装教程.md)），多数环境问题重装后会消失。
