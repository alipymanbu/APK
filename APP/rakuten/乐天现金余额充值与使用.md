# 乐天现金余额（楽天キャッシュ）充值与使用

## 一、它是什么，和积分有什么区别

楽天キャッシュ（乐天现金余额）是乐天集团的在线电子货币，1 余额按 1 日元使用，先充值后消费。能在乐天市场的下单页、街边支持楽天ペイ的店铺、乐天旅行等服务里用。

它和乐天积分是两个东西：积分是消费后返还、攒着下次抵扣的；现金余额是你先充进去的钱。下单时两者按你设置的优先顺序依次抵扣，互不冲突。

## 二、充值渠道与上限

官方规则页列出的充值渠道：

| 渠道 | 说明 |
| --- | --- |
| 楽天カード | 本人名义的乐天信用卡充值 |
| 楽天銀行口座 | 银行账户扣款，需先完成乐天会员链接登记（ハッピープログラム加入） |
| セブン銀行ATM / ローソン銀行ATM | 现金充值；注意经 ATM 充值不产生乐天积分 |
| ラクマ売上金 | 二手平台卖货所得转入 |
| 楽天ウォレット | 从账户内资产转入 |

三条硬规则：

- **上限**：单次与单月各 50 万日元，充值单位 1,000 日元以上、以 1 日元为单位。
- **充值完成后不可取消**——无论什么原因都不撤回，金额输错也只能把它花掉。充之前把金额看清。
- 信用卡账单上的名目显示为「楽天キャッシュ」。

以上数字与规则以[官方规则页](https://cash.rakuten.co.jp/Guidance/GuidanceCashRule/)的实时说明为准。

## 三、能提现的「プレミアム型」

现金余额分两种形态：**基本型**（充值、支付、送出、接收）和**プレミアム型**（多一项提现，提现可能收手续费）。

关键区别在充值来源：プレミアム型只能从ラクマ卖货所得、楽天ウォレット资产、服务报酬这类「挣来的钱」充值；用信用卡、银行账户或 ATM 充进去的部分**不在可提现范围**——官方帮助中心把两张清单分开列了。只是购物的人碰不到这个区分；在ラクマ卖东西的人会用到：卖货款进的是可提现额度。

## 四、下单时怎么和积分配合

在乐天市场订单确认页点「ポイント利用」旁的「変更」，设置优先顺序：

1. 默认是「楽天キャッシュから優先して使う」——先扣现金余额，扣完才动积分。
2. 手上有即将过期的限时积分时，改成「楽天ポイントから優先して使う」更划算。
3. 勾选「次回もこの設定を使う」可记住本次顺序，下次下单不用重调。

限时积分先扣的逻辑与会员等级见[积分获取与使用.md](积分获取与使用.md)；下单与取消订单的整体流程见[购物下单与支付方式.md](购物下单与支付方式.md)。

## 五、用现金余额付款的返还率

走楽天ペイ（在线结算）支付时的返还规则：楽天カード支付部分为 100 日元 1 点（1%）；现金余额支付部分为 200 日元 1 点（0.5%）；乐天卡以外的信用卡不参与返还。这层是结算通道的返还，与店铺积分分开计算，具体以官方积分规则页为准。
