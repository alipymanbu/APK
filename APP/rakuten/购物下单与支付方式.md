## 一、找到想买的商品

应用内主要有三种搜索方式：

- **关键词搜索**：首页顶部搜索框直接输入。乐天市场是日本站，用日语关键词命中率最高，中文或英文词经常搜不到东西。
- **图片搜索**：有实物图或截图时，用图片搜索能绕过「不会打日语」的问题。
- **条形码搜索**：点底部「探す」，再点搜索框右侧的条形码图标，对准商品条码即可发起搜索（部分机型或商品可能识别不了）。

商品页面上还有两个省事的按钮：「类似商品查找」和「按价格查看相同商品」，用来横向比价；配合商品评价区的评分和反馈，基本能判断一家店铺靠不靠谱。

## 二、下单前值得用的三个功能

| 功能 | 位置 | 对你的实际用处 |
| --- | --- | --- |
| 收藏夹（お気に入り） | 商品页收藏按钮 | 收藏的商品降价或积分加倍时会收到通知 |
| 店铺收藏 | 店铺页 | 把常逛的店攒成自己的清单，优惠券也能在清单里看 |
| 优惠券 | 商品页 / 「我的优惠券」 | 乐天市场券和店铺券都有，仅限乐天会员使用，快到期会提醒 |

另外商品页有聊天入口，可以直接问店铺运费、库存、发货时间这类问题，回复以日本时间工作时段为准，别卡着深夜发消息等秒回。

## 三、支付方式有哪些

乐天市场本身不统一收款，每家店铺各自决定支持哪些支付方式，商品页和下单页会标注。平台层面常见的方式如下：

| 支付方式 | 说明 |
| --- | --- |
| 信用卡 | 最普遍的方式，部分店铺也接受海外发行的国际卡 |
| 银行转账（前払） | 先汇款后发货 |
| 货到付款（代金引換） | 收货时付现金，通常有金额上限并收手续费 |
| 便利店付款 | 7-11、罗森、全家等便利店或邮局 ATM 付款 |
| 后払い（先买后付） | 商品到手后按寄来的账单在便利店或银行付款 |
| 楽天ペイ / 积分・楽天キャッシュ抵扣 | 用乐天生态里的余额与积分抵扣，见 [积分获取与使用.md](积分获取与使用.md) |

其中楽天キャッシュ（现金余额）是先充值后消费的电子货币，充值渠道、单次与单月 50 万日元上限、「充值后不可取消」的规则单独成篇，见[乐天现金余额充值与使用.md](乐天现金余额充值与使用.md)。

### 卡被拒时先查三件事

- **3D Secure（本人认证）**：多数发卡行要求先在卡片渠道注册这项目前的免费认证服务，没注册的卡在网络付款时会被拦。按发卡行的指引开通后再试。
- **安全码**：卡片背面签名栏旁的 3 位数字（美国运通卡印在正面、4 位），输错一次就会被拒。
- **店铺是否支持你的卡**：每家店铺收卡范围不同，下单页支付方式列表里没列的卡就是不支持，换支付方式或换店铺。

## 四、下单之后的三条规则

1. **30 分钟内可自助取消**：下单 30 分钟内，从「购买历史」里自己操作取消；超过 30 分钟就要看店铺的取消政策、直接联系店铺了，平台不会代为取消。
2. **支付方式下单后不能改**：订单确定后支付方式改不了，付款前确认清楚。
3. **配送进度在「购买历史」或推送通知里看**：店铺发货与物流状态更新后会有提醒；个别店铺的处理节奏不同，没有显示不代表没发货。

## 五、两个容易踩的细节

- **用什么下单会影响归类**：在平板上用浏览器买，订单被算作「PC 购买」；用应用买才算「应用购买」。部分活动只认其中一种，参加活动前看清规则。
- **地址和收货人信息**：日本国内地址直接填；人在海外需要转运用法的话，整个流程见[海外转运收货指南.md](海外转运收货指南.md)。
- **付款环节卡住**：多数是店铺不支持你选的方式或卡片被拒，逐项排查见[常见问题排查.md](常见问题排查.md)。
