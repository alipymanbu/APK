# rakuten（乐天市场）常见问题排查

> 本篇汇总 rakuten（楽天市場）日常使用中高频出现的问题：收不到通知、搜索无结果、证书报错、订单查询等，逐项给出排查步骤。

## 一、收不到推送通知

1. 打开系统「设置 → 应用 → 楽天市場 → 通知」，确认通知总开关是开的。
2. 在省电策略严格的品牌系统（部分国产系统）里，把该应用的后台运行权限放开，否则进程被杀就收不到推送。
3. 应用内也有消息接收设置，检查是否被关。

## 二、条码扫描没反应

入口是：底部「探す」→ 搜索框右侧的条形码图标。识别失败时先对准、光线放亮；部分机型和部分商品的条码确实扫不出来，这时直接手输关键词搜索。

## 三、搜索结果为零

- **关键词问题（最常见）**：乐天市场是日本站，用中文或英文词经常搜不到。换成日语词，或用商品的日文片假名/汉字写法重试。
- **条件太苛刻**：价格区间、分类、评分等筛选叠加后可能把结果清空，逐项放宽试。
- 拿不准日语写法时，用图片搜索或条码扫描绕过去。

## 四、提示「セキュリティ証明書のエラー」（安全证书错误）

官方帮助中心确认过这是系统 WebView 组件版本过旧引发的：打开 Google Play，更新「Android System WebView」后重启应用即可。装不上 WebView 更新的老设备，考虑升级系统。

## 五、页面卡住、购物车点不动

官方给出的通用处置：先重启设备（电源关开一次）；不行再确认应用是否为最新版本。这两个动作能解决大部分界面无响应问题。

## 六、查不到自己的订单

- **用乐天 ID 下的单**：应用内「购买历史（購入履歴）」里看，配送状态更新也会走推送。
- **没用乐天 ID 下的单**：在订单详情查询页输入受注番号（订单号）和下单邮箱查询。
- **30 分钟内想取消**：购买历史里自助操作；超过时限要联系店铺，见[购物下单与支付方式.md](购物下单与支付方式.md)。

## 七、在 iPad / 平板上用

用浏览器（Safari 等）买，订单按「PC 购买」归类；用应用买才按「应用购买」算。部分活动只认其中一种来源，对不上时先检查这一条。

## 八、付款被拒

先按顺序查三件事：3D Secure（本人认证）是否已按发卡行要求开通、卡片安全码是否输对（背面 3 位，美国运通卡在正面 4 位）、店铺是否支持你这张卡。逐项的判据与处理见[购物下单与支付方式.md](购物下单与支付方式.md)的「卡被拒时先查三件事」；用现金余额和积分抵扣时被拦，多半是余额不足 50 点门槛或优先顺序设置问题，见[乐天现金余额充值与使用.md](乐天现金余额充值与使用.md)。

## 九、以上都解决不了

- 官方帮助中心：[ichiba.faq.rakuten.net](https://ichiba.faq.rakuten.net/)，有 English / 简体中文 / 繁体中文分区。
- 订单、发货、支付这类**店铺层面**的问题，直接从商品页或订单页联系店铺，平台客服不会代替店铺回复。
- 账号、积分这类**平台层面**的问题走乐天市场客服中心（页面提供聊天、电话、邮件通道，官方标注的响应时间以页面显示为准）。
- 应用装不上或打开报错的问题，先回[下载与安装教程.md](下载与安装教程.md)的排查清单过一遍；涉及账号登录的见[注册与登录教程.md](注册与登录教程.md)。
