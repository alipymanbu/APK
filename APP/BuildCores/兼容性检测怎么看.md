## 一、它到底检查什么

你每加一件配件，应用会拿它和清单里已有的件交叉比对，检查的是装机时真实会翻车的那几类硬约束：

| 检查维度 | 典型的翻车场景 |
| --- | --- |
| CPU 与主板插槽 | CPU 是 AM5、主板却是上一代插槽，装不上 |
| 内存类型与主板支持 | 主板只认 DDR4，你选了 DDR5 内存条 |
| 显卡与机箱空间 | 显卡太长，机箱装不下 |
| 电源功率与整机功耗 | 整机功耗超过电源额定值 |
| 散热器与机箱 | 散热器太高，机箱侧板盖不上 |

此外主板芯片组与 CPU 的搭配、内存代数这类规格约束也在比对范围内。检测是实时的——加一件查一次，不用等你配完才报错。

## 二、提示冲突了怎么处理

选中某件配件后如果弹出「不合适」的提示，或者某件死活加不进配置单，按这个顺序排查：

1. **先看提示指向哪一条**：应用会说明冲突的原因（插槽不对、内存类型不支持之类），按它说的换对应那一件，不要连着换一堆。
2. **换主板或换 CPU 时回头复查整单**：改一件会连锁影响后面的判断（换了 CPU，散热器和内存的结论可能跟着变），改完把清单从头到尾再过一遍。
3. **功耗类冲突看电源**：如果提示的是功率不够，去 Wattage Details 看整机功耗到了多少，再决定换更大功率的电源还是降一档显卡——方法在[功耗计算与电源选择.md](功耗计算与电源选择.md)。

## 三、检测结果要打个折的地方

- **冷门与老旧型号可能查不到**：配件库覆盖的是主流且持续更新的型号，非常小众的品牌、停产多年的老件可能存在数据缺失。库里没有的件，应用没法帮你查，其规格与兼容性需要你对照主板说明书等资料手动确认。
- **它是装配前的预检，不是实测**：它按规格参数判断「配不配」，不替代你装机时的实际动手验证。参数以各配件官方规格为准。
- **3D 视图里的空间检查同样只是参考**：显卡与机箱、散热器与侧板这类「装不装得下」的视觉提示有明确边界（线材、公差它管不到），详见[3D预览与实物差在哪.md](3D预览与实物差在哪.md)。
- **价格、配件库联网更新**，数据刷新有延迟；以应用内当时显示的规格为准。
