## 一、睡眠定时：到点自动停

睡前听广播最烦的是半夜自己还在响，睡眠定时就是干这个的：

1. 打开你想听的内容，进入**正在播放页**；
2. 点右下角的**菜单（Menu）按钮**，选「设置睡眠定时」（Set Sleep Timer）；
3. 选一个时长，倒计时开始；
4. 想查看剩余时间或取消，再次点菜单 → 设置睡眠定时即可。

倒计时结束播放会自动停止，不用再伸手关。

## 二、用电台当闹钟

TuneIn 可以让指定电台在指定时间响起来当闹钟：

1. 先打开你希望早上听到的那个电台（必须先在播放界面选好内容）；
2. 点**三点菜单** →「设置闹钟」（Set Alarm）；
3. 勾选「启用闹钟」，依次设好**播放时间、重复（哪几天）、具体时刻、音量**；
4. 点「保存」。

**两个前提条件，缺一个闹钟都不会响**（官方帮助中心明确说明）：

- 在系统设置里**允许 TuneIn 发送通知**：设置 → 通知 → TuneIn Radio → 允许通知；
- 把屏幕**自动锁定设为「永不」**：设置 → 显示 → 自动锁定 → 永不。

不满足这两条时闹钟功能形同虚设——这是用户反馈里闹钟「没反应」最常见的原因，更多排查见 [常见问题与故障排查.md](常见问题与故障排查.md)。另外注意：闹钟响之前的整晚如果手机处于省电状态掐了后台，播放也起不来——相关开关见 [锁屏后声音总断怎么办.md](锁屏后声音总断怎么办.md)。

## 三、备用闹钟声，防电台哑火

高级设置里有一项**「备用闹钟声音」**：万一你选的电台因为断网、停播等原因没响，闹钟会改用一声蜂鸣把你叫醒，不会静默错过时间。在意准点起床的话建议开着。

## 四、几个和播放行为有关的高级设置

这些开关在设置 → 高级设置里，和日常收听直接相关：

| 设置项 | 作用 | 什么时候调它 |
| --- | --- | --- |
| 自动重启播放器 | 打开应用时自动接着播上次的流 | 想一开 App 就出声 → 开 |
| 智能跳转 | 快进快退按内容智能定位（听歌时可回到歌曲开头）；关掉则固定跳 30 秒 | 觉得快进不准 → 关掉它退回固定 30 秒 |
| 后台停止播放 | 控制播放进入后台后是否继续 | 想省电省流量 → 关；想锁屏继续听 → 按需设 |
| 首选流质量 | 高音质更吃流量且加载更慢，低音质加载快更稳 | 信号差老缓冲 → 调低 |
| 蜂窝数据 | 允许在移动网络下播放 | 只想 Wi-Fi 下听 → 关掉 |
| 自动播放 | 播放落后直播超过一定时间后自动跟上直播 | 想追实时节目 → 开 |

流量敏感的读者重点看**「蜂窝数据」与「首选流质量」**两项：电台是持续流媒体，长时间听消耗不小，出门前先确认这两项的设置。

## 五、退出应用

想彻底退出 TuneIn：在安卓上用系统手势上滑关闭即可，也可以在应用的设置菜单里选「退出」（Exit）。退出前如果闹钟还在启用状态，注意第二、三节的两个前提条件仍然要保持满足。
