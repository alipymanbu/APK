## 一、电台点开没声音？先看是哪种情况

官方帮助中心把「某个电台连不上」的原因归为几类，对照你的情况：

| 现象 | 可能原因 | 你可以做什么 |
| --- | --- | --- |
| 一直连不上、加载失败 | 该台的流出错或已停用 | 搜一个同类电台先听着 |
| 连上但没声 / 声音时断时续 | 电台访问量过大、服务器不稳 | 过几分钟再试 |
| 提示播放器/格式不兼容 | 该台用的流格式与当前设备不匹配 | 换同类台，此问题在你这端解决不了 |
| 手机网络其他 App 正常、只有 TuneIn 不行 | 网络到 TuneIn 链路不稳 | 切换 Wi-Fi / 移动数据重试 |
| 部分体育/节目时段突然没声 | 版权限制，电台在该时段不在线播 | 换节目或等该时段结束 |

## 二、提示「该电台在你所在国家/地区不可用」

这是**地区授权限制**，不是你操作错了：电台按 IP 判断听众所在地区，只在获得授权的地区分发内容。官方 FAQ 也说明，电台可能因版权授权限制不对某些地区提供信号。两个事实供参考：

- 英国曾因版权问题有约 1000 个频道被下架（据 TorrentFreak 2020 年报道）；
- 同一时间不同人听到的内容也可能不同——电台在不同市场播不同节目。

解决思路（合规范围内）：**换一个对所有地区开放的同类电台**，或者听播客——播客不受这类地区限制影响。用网络工具伪装位置属于规避授权限制，不在本篇范围内。

## 三、一直缓冲、卡顿

按顺序试：

1. 切换网络：Wi-Fi 和移动数据互切一次，确认不是当前网络的问题；
2. **换低码率的流**：正在播放页 → 菜单 →「选择流 / Choose Stream」，选该台提供的最低一档——加载更快更稳，流量也省（数值见 [听一小时电台要多少流量.md](听一小时电台要多少流量.md)）；
3. 调低流质量：设置 → 高级设置 → 首选流质量，选低一档——对所有台生效的默认值；
4. 检查「蜂窝数据」开关：只想 Wi-Fi 听就关掉，防止切到移动网络时莫名卡住；
5. 后台被系统杀掉、锁屏后断流：这是另一类问题，电池权限、省电模式、厂商后台管理逐项排查见 [锁屏后声音总断怎么办.md](锁屏后声音总断怎么办.md)。

## 四、闪退、打不开、界面卡死

1. **清缓存**：设置 → 应用 → TuneIn → 存储 → **清除缓存**（先别点「清除数据」，那会把登录和收藏配置一起清掉）；
2. 清完还闪退，再考虑清除数据或重装；
3. 重装时用 [下载与安装教程.md](下载与安装教程.md) 里的安装包重装一遍，注意系统需 Android 5.2 以上、包名是 `tunein.player`；
4. 老设备上的偶发崩溃与卡顿，官方与媒体的公开反馈都有提及——升级到最新版本通常有改善（以商店当时版本为准）。

## 五、登录不上 / 忘记密码

- 入口：右上角头像 → 登录 → 登录页底部「忘记密码」→ 输入注册邮箱 → 按邮件重置；**邮件没收到先翻垃圾箱**。
- 提醒：**下载或安装应用不会自动创建账号**——如果你从没注册过，自然登不上，先去注册一个（见 [下载与安装教程.md](下载与安装教程.md) 第四节）。
- 收藏丢了多半是没登录账号，登录同一账号即可找回（见 [怎么搜索和收藏电台.md](怎么搜索和收藏电台.md) 第四节）。

## 六、闹钟不响、定时不生效

九成是权限没给全，对照 [睡眠定时与闹钟设置.md](睡眠定时与闹钟设置.md) 第二节核对：**通知已允许 + 自动锁定设为「永不」**，两条都得满足；另外开着「备用闹钟声音」能兜底电台没响的情况。
