## 一、免费版已经覆盖的部分

按官方说明，基础功能完全免费，官方的定位是「足以满足大多数使用场景」。具体指：

- 内置订阅的全部订阅动作；
- 事件的创建、重复规则（含农历）、提醒；
- 时间线视图；
- 深色模式、趣味事件图标。

日常「记事 + 提醒」这条主线，免费版走完没有障碍。

## 二、会员解锁的功能清单

官方各渠道列出的会员专属功能略有出入，合并如下（截至 2026-09，以应用内会员页实际显示为准）：

| 功能 | 出处 |
| --- | --- |
| 月日历视图 | 安卓版应用商店说明、官网会员页 |
| 生活盘点 | 安卓版应用商店说明 |
| 事件备注笔记 | 各渠道均列 |
| 应用锁 | 各渠道均列 |
| 专属壁纸 | 各渠道均列 |
| 在菜单栏单独显示日历 | 各渠道均列（桌面端入口） |
| 隐藏订阅栏 | 各渠道均列 |
| 免广告 | 官网会员页 |
| 强提醒 | iOS 版 App Store 说明列它为会员功能；安卓版说明未列 |

注意那条两端口径差异：iOS 版说明把「强提醒」放进会员清单，安卓版说明没这么列。你在安卓上遇到的实际口径，以应用内显示为准。

## 三、价格（截至 2026-09，以购买页当时显示为准）

- **iOS 版 App Store 内购标注**：月高级会员 ¥15、年高级会员 ¥88、终身高级会员 ¥198；
- **官网会员页**：月订购 ¥15/月、年订购 ¥88/年（折合每月约 7.3 元）、永久会员 ¥168（当时标注为限时特惠、限量 1000 份）。

同一档「终身/永久」两处标价不同（¥198 与 ¥168），官方带时限与数量的活动随时会变，下单前以你打开的购买页当时显示为准。

## 四、开通前确认两件事

1. **你要的到底是不是第二节表里的功能**：表里没有你缺的，就没有开的必要；官方列表里排在前面的是月日历视图和生活盘点。
2. **在哪个端买**：安卓、iOS、桌面端的支付方式与定价可能不同，在各端应用内分别查看；会员权益是否跨端通用，以官方说明与应用内标注为准。

开通入口在应用内的会员页。
