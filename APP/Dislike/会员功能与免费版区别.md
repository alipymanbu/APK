## 一、免费版已经覆盖的部分

按官方说明，基础功能完全免费，官方的定位是「足以满足大多数使用场景」。具体指：

- 内置订阅的全部订阅动作；
- 事件的创建、重复规则（含农历）、提醒（含重要事项的持续提醒）；
- 时间线视图；
- 深色模式、趣味事件图标。

日常「记事 + 提醒」这条主线，免费版走完没有障碍。

## 二、会员解锁的功能清单

官方渠道列出的会员专属功能如下（截至 2026-09，以应用内会员页实际显示为准）：

| 功能 | 说明 |
| --- | --- |
| 月日历视图 | 免费版用时间线，会员才能按月历查看 |
| 生活盘点 | 对过往事件做统计回顾 |
| 事件备注笔记 | 给事件挂更长的备注内容 |
| 应用锁 | 打开应用时需要验证 |
| 专属壁纸 | 会员外观 |
| 在菜单栏单独显示日历 | 桌面端的日历快捷入口 |
| 隐藏订阅栏 | 不想看到订阅栏时收起来 |

## 三、开通前确认两件事

1. **你要的到底是不是上表里的功能**：表里没有你缺的，就没有开的必要；官方列表里排在前面的是月日历视图和生活盘点。
2. **价格与订阅周期**：以应用内会员页当时显示为准；安卓、iOS、桌面端的支付方式与定价可能不同，在各端应用内分别查看。

开通入口在应用内的会员页。
