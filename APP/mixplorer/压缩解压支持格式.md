# 压缩解压支持哪些格式

> 用 MiXplorer 处理压缩包前，先查清哪些格式能打包、哪些只能解开。这篇把官方公布的格式清单列成表，并说明 Silver 版的插件关系。

## 一、能打包也能解开的格式

这些格式你既能压缩生成、也能解压读取：

| 格式 | 说明 |
| --- | --- |
| `7z` | 7-Zip 原生格式 |
| `Zip` / `Zip64` | 支持分卷与加密包 |
| `TAR`、`TAR.GZ`、`TAR.BZ2` | Linux 常见归档 |
| `GZIP`、`BZIP2`、`XZ` | 单文件压缩 |
| `WIM` | Windows 映像格式 |
| `Lizard`、`LZ4`、`LZ5`、`Zstandard` | 新一代高压缩比/高压缩速度算法 |

## 二、只能解开的格式

下面这些只能解压读取，不能反向打包——需要产出这类格式时，换专门的工具：

`AR`、`ARJ`、`CAB`、`CHM`、`CPIO`、`CramFS`、`DMG`、`EXT`、`FAT`、`GPT`、`HFS`、`IHEX`、`ISO`、`LZH`、`LZMA`、`MBR`、`MSI`、`NSIS`、`NTFS`、`QCOW2`、`RAR` / `RAR5`、`RPM`、`SquashFS`、`UDF`、`UEFI`、`VDI`、`VHD`、`VMDK`、`XAR`、`Z`

日常场景大多落在这张表里：游戏包 `ISO`/`DMG`、Windows 安装镜像 `MSI`/`NSIS`、虚拟磁盘 `VHD`/`VMDK` 都能直接拆开看内容。

## 三、Silver 版和插件的关系

Silver 版（`com.mixplorer.silver`）已经捆绑官方 **Archiver** 插件，装完即有上面的完整能力，不用再装东西。免费版 `com.mixplorer` 则要自己补插件：三个点 → **Settings** → **Addons** → 点加号，按链接去下载对应插件装回。

除压缩包外，Silver 版还捆绑 Image、Tagger、PDF 三个插件，分别对应图片查看、文件标签、PDF 阅读。

## 四、版本不同，清单会有出入

上面两张表是官方长期公布的能力总表，具体到某个版本要看更新日志（截至官方 6.70.0 的变化）：

- **6.69.1**：单文件压缩列表里加入了 `Brotli`。
- **6.70.0**：**打包选项里移除了 `WIM`**——你照旧教程找 WIM 打包却找不到，多半就是版本比教程新。
- 你手上的 6.68.4-Silver 仍在打包列表里保留 `WIM`。

版本号会继续往前走，遇到清单对不上的情况，以官方 XDA 主帖当时的更新日志为准。

## 五、日常操作怎么点

- **解压**：选中压缩包，菜单里会出现解压相关选项，选目标目录确认即可；带密码的包会提示输入密码。
- **打包**：多选文件 → 菜单里选压缩 → 选格式与目标位置。
- **直接改包内容**：进到压缩包内部后，可以像普通文件夹一样往里加文件、删文件——这是官方列出的能力（针对 zip 类）。
- **加密打包**：用 `Zip`/`7z` 的加密选项；若你要的是跨工具通用的加密格式，官方另支持 Aescrypt 文件格式的加密与解密。

操作路径按你界面上实际出现的菜单为准；菜单项找不到时先对照 [怎么设置中文.md](怎么设置中文.md) 确认语言，再看 [常见问题排查.md](常见问题排查.md)。
