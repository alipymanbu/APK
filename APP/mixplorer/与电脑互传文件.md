# 与电脑互传文件（SMB 与内置服务器）

> 手机电脑不在一根数据线旁边时，MiXplorer 自带两条路：主动连电脑的共享文件夹，或在手机上开个服务器让电脑来取。这篇两条都给步骤。

## 一、先确认两个前提

无论走哪条路，这两条都成立才连得上：

1. 手机和电脑在**同一个局域网**（同一路由器，别一个走流量一个连 Wi-Fi）。
2. 电脑侧的共享或服务**已经开着**，防火墙没拦局域网访问。

## 二、访问电脑的共享文件夹（SMB 客户端）

电脑上先把共享开好（Windows 10/11）：

1. 设置 → 网络和 Internet → 以太网，把网络配置文件设为**专用网络**。
2. 控制面板 → 网络和共享中心 → 更改高级共享设置：
   - 专用网络：启用**网络发现**和**文件共享**；
   - 所有网络：按你的账户情况选——有开机密码就保持「启用密码保护共享」，没密码就关掉它。
3. 右键你要共享的文件夹 → 属性 → 共享 → 共享给指定用户，记下共享名。

手机这侧（MiXplorer 里添加一个网络书签）：

1. 左滑或点左上角汉堡图标打开**书签抽屉**。
2. 点抽屉里的汉堡 → **Add storage** → **Custom**。
3. 点 **Search local** 搜索局域网内的共享；搜到后点进去，输入电脑的用户名和密码。
4. 搜不到可以手动填地址，格式形如 `smb://192.168.1.10/共享名`（电脑 IP 在 `ipconfig` 里看）。

添加成功后它会自动存成书签，下次从抽屉直接点开。MiXplorer 支持的客户端协议不止 SMB（含 SMB1、SMB2.0/2.1、SMB3），还有 FTP(S)、SFTP、WebDAV——同一入口里按类型选即可。

## 三、在手机上开服务器，让电脑来取（反向）

不想在手机上翻文件夹，也可以让电脑直接访问手机：

1. 三个点 → **Servers**（服务器）。
2. 点 **Start FTP Server**（开始 FTP 服务器），界面会显示地址，形如 `ftp://192.168.1.5:2121`。
3. 电脑浏览器或文件管理器输入这个地址，就能浏览并下载手机上的文件；HTTP 服务器那条用浏览器就行，门槛最低。

同一台局域网里另一台手机也装了 MiXplorer 的话，对端走「Add storage → Custom」填这个 FTP 地址即可直接互拷，账号密码照服务器页面上显示的填。除此之外，HTTP 服务器设置里还带 **DLNA** 选项（6.66.4 起），局域网内的电视、播放器可以直接放手机里的音视频。

MiXplorer 还内置一个 TCP 接收服务：两台设备都装了 MiXplorer 时，用「Send to」把文件直接推到对方设备，适合两台手机之间倒腾。

## 四、连不上的排查顺序

按这个顺序过一遍，多数情况在前两条就能解决：

1. 手机和电脑 IP 是不是同一网段（都 `192.168.1.x`）？
2. 电脑共享是否真的开了、账户密码输对没有？
3. Windows 防火墙是否放行了「文件和打印机共享」。
4. 用 SMB 的话，注意开发者答复过：Android 在 API 37 之前不允许应用绑定 1024 以下端口，所以 MiXplorer **自带的 SMB 服务端**在这些系统上没法用默认的 445 端口（详见 [常见问题排查.md](常见问题排查.md) 的端口一节）——你连电脑这个方向是纯客户端，不受这条影响。
5. 还不行就绕开 SMB：改用上面第三节的 HTTP 服务器，只要浏览器能开就能传。
