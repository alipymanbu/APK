## 一、这是什么应用

MiXplorer 是一款安卓文件管理器，开发者是 XDA 上的 Hootan Parsay（帖子署名 HootanParsa），闭源，官网在 [mixplorer.com](https://www.mixplorer.com/)。它按包名分成两个发行版：

| 发行版 | 包名 | 怎么分发 |
| --- | --- | --- |
| 免费版 MiXplorer | `com.mixplorer` | 开发者在 XDA 主帖提供下载 |
| Silver 版 | `com.mixplorer.silver` | Google Play 与 Galaxy Store 的付费应用，全名 MiXplorer Silver File Manager |

Silver 版是一个捆绑包：MiXplorer 主程序加上 Archiver、Image、Tagger、PDF 这几个官方插件，以及最新语言资源。免费版与 Silver 版核心功能相同，区别主要在插件是内置还是要自己另外装。Silver 版在商店里的售价以商店页面为准，官网只写「购买 Silver 版可以支持这个项目」。

## 二、网盘里这份包的事实

网上搜到的多是官方最新版，和网盘里这份未必是同一个版本。你手里这份的本地记录如下，核对版本就以它为准：

| 项目 | 值 |
| --- | --- |
| 版本 | 6.68.4-Silver |
| 包名 | `com.mixplorer.silver` |
| 大小 | 17.51M |
| MD5 | `D652629A01CD2B7FDACF4A1AC3166447` |
| 记录时间 | 2026-09-23 |

[MiXplorer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b820157fbf57)

下载后想核对文件没损坏，可以在电脑上算一遍 MD5（Windows 自带工具即可）：

```powershell
certutil -hashfile mixplorer_v6.68.4-Silver.apk MD5
```

算出来和上表一致，就是同一份文件。

## 三、安装步骤

1. 把 APK 从网盘转存并下载到手机（或先下到电脑再传过去，传法见 [与电脑互传文件.md](与电脑互传文件.md)）。
2. 点击 APK 安装。系统会拦「未知来源应用」，按提示允许本次安装即可——这是系统对一切侧载应用的常规提示。
3. 首次启动会问「允许访问照片、媒体和文件」，选允许。这一步不给，你进去后什么都看不到。
4. 装完先按 [怎么设置中文.md](怎么设置中文.md) 把界面切成中文，再开始折腾其他设置。

## 四、系统要求

- 本地记录标注：需要安卓 5.2 以上。
- 官网对免费版写的是支持 Android 2.2+，两个口径并列在这里，以你设备上实际能否装上为准。
- root 相关的功能（改系统目录、`/data` 下操作）默认关闭，需要时在设置里手动开，见 [常见问题排查.md](常见问题排查.md)。

## 五、版本号怎么读

MiXplorer 的版本号形如 `6.68.4-Silver`：前半段是版本序号，后缀标明发行分支——`-Silver` 是商店付费版，另外还有 `-API29` 这类按目标系统版本出的构建，以及 `-BETA` 测试版。版本号会随时间变化，你在官网或 XDA 主帖看到更新的数字时，以官方页面当时显示为准；网盘里这份始终按第二节的表核对。
