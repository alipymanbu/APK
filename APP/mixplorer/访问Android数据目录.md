# 怎么访问 Android 的 data 和 obb 目录

> 打不开 `/Android/data` 不是 MiXplorer 坏了，是系统从 Android 11 起加的限制。这篇讲清楚原因，并给你三条实际走得通的路。

## 一、为什么打不开

安卓从 Android 11 开始执行分区存储：`/Android/data` 与 `/Android/obb` 这两个目录，即使你在系统设置里给了 MiXplorer「所有文件访问权限」，它也读不了。这不是权限没给对，是系统对外部存储访问加的硬限制，各家文件管理器一样受影响。

Android 13 又收紧了一次：此前文件管理器可以借存储访问框架（SAF）逐级点进受限目录，这个口子在 Android 13 上被关掉了。所以你会看到三种现象：

| 你的系统 | 现象 |
| --- | --- |
| Android 10 及以下 | 正常浏览，给到存储权限即可 |
| Android 11 / 12 | 进 `Android/data` 时会弹系统授权页，点允许后能进 |
| Android 13 及以上 | 直接路径进不去，要走下面第二节的办法 |

（各厂商 ROM 的弹窗时机与文案略有差异，以你屏幕上实际出现的为准。）

## 二、三条实际可行的路

### 1. 走系统弹窗逐级授权（Android 11/12 最省事）

进 `Android` 目录再点 `data`，系统会弹「选择文件夹」的授权页，点「使用此文件夹」确认；`obb` 目录同样操作一次。授权是按目录记的，授过一次以后就能直接进。

### 2. 用 Shizuku（Android 13/14 无 root 的主力方案）

Shizuku 让应用借到更高等级的文件访问能力，不需要 root。大致流程：

1. 装好 Shizuku 并按它自己的说明启动（无线调试或连电脑激活）。
2. 在 Shizuku 里把权限授给 MiXplorer。
3. 回到 MiXplorer 进入 `Android/data`，此时会走 Shizuku 的访问通道。

XDA 上维护的用户手册专门提到：部分 Android 14 设备**即使有 root** 也要靠 Shizuku 才能进 `/Android/data`——所以别默认 root 一定好使。

### 3. 已 root：打开应用内的 root 开关

三个点 → **More Settings** → 勾选 **Allow root** → 重启 MiXplorer，再导航到根目录 `/` 触发一次超级用户授权请求，选允许并记住。之后 `/data`、`/Android/data` 这类目录就能直接读写。

## 三、注意事项

- 这三条路都只用于访问**你自己设备上**的文件，前提都是系统正规给出的授权方式。
- 授权弹窗一定认准系统界面，别在不明页面上确认。
- 某些应用把缓存放在 `data` 下自己的包名目录里，只想导出聊天记录、下载文件这类内容的话，先想清楚目标路径，能少授一级目录就少授一级。
- 授完权还是空目录或报错，按 [常见问题排查.md](常见问题排查.md) 里的权限一节逐项核对。
