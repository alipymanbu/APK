# 怎么连接网盘

> 想把百度网盘、Google Drive、OneDrive 这些云盘挂进 MiXplorer 统一管理，这篇给你支持范围、添加步骤，以及「登录成功却看不到文件」的解释。

## 一、支持哪些云

官方与 XDA 主帖公布的内置支持（各版本间略有出入，最终以你应用内 Add storage 列表为准）：

Mega、Mail.ru、Dropbox、Box、Yandex、HiDrive、百度网盘、Mediafire、IDrive、Hubic、4Sync、4Shared、Google Drive、Meo、OneDrive、OneDrive Business、pCloud、SugarSync、VDisk

另外，凡是**支持 WebDAV 协议**的网盘和自建服务（OwnCloud、MyDrive.ch、DriveHQ、CloudMe、CloudSafe 等）都能按 WebDAV 类型接入——家里的 NAS 或服务器也走这条。

## 二、添加步骤

主流走法（XDA 用户手册帖的路径）：

1. 打开书签抽屉（点左上角汉堡图标，或从屏幕左缘往右滑）。
2. 点抽屉里的汉堡 → **Add storage**。
3. 列表里选你的服务商（如 OneDrive、Dropbox）；不在列表里的自建服务选 **Custom** 或 WebDAV 类型。
4. 可以改一个显示名，点保存。
5. 自动跳转到该网盘的登录页，登录自己的账号。

两点补充：

- 中文教程里还给出另一个等价入口：**底部加号 → 存储器**，滑到列表底部选服务商。两个入口进的是同一个配置页，以你界面上实际有的为准。
- 有教程提到保存时可以设置一个加密密钥、也可以直接跳过——不想折腾就跳过，它不影响能不能连上。

## 三、登录成功了却看不到文件

这是最常撞上的一堵墙，原因因服务商而异：

- **Google Drive**：官方 6.66.4 更新日志写明 Google 调整了授权 scope，只有**用本应用创建/上传的文件**才能被完整访问到。这不是你操作错了，是 Google 侧对免费 API 的限制（官方原话也提到本应用不支持付费 API）。想让某个文件夹在 MiXplorer 里可见，用它上传一次。
- **百度网盘**：有中文教程反馈，登录成功后只看得到应用自己创建的目录（形如 `/我的应用数据/MiFileExplorer`），网盘里的其他文件不显示——把要管理的文件移进这个目录，就能在 MiXplorer 里看到。
- **其他服务商**：先退出书签重新添加一次；还不行就对照 [常见问题排查.md](常见问题排查.md) 第六节，先排除版本太旧的问题。

（以上按 2026-09 前后的公开教程与官方日志整理，各云盘的授权政策会变，以官方页面当时说明为准。）

## 四、管理已添加的云书签

- **删除 / 编辑**：在抽屉里把书签名**向右滑**，出现操作项后选删除或编辑。
- **排序**：在书签菜单的 Options 里勾选「Reorder by icon」后，按住图标上下拖动即可重排。
- **分组**：书签列表支持加「Section」小标题分组，点一下展开/收起；注意移动 Section 只挪标题本身，下面的书签要手动跟着挪。
- 连接建立后会**自动存成书签**，下次从抽屉直接点开，不用重新走一遍添加流程。

网络共享（SMB）与手机电脑互传不在本篇范围，见 [与电脑互传文件.md](与电脑互传文件.md)。
