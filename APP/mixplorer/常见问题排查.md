## 一、外置 SD 卡只能看不能写

第一次往 SD 卡里写东西时，MiXplorer 会弹「Attention: Please select Ext SD...」之类的授权提示——这是系统把 SD 卡写权限交给应用的正规通道，按提示选中 SD 卡根目录确认一次即可。没弹的话，手动进 SD 卡并尝试新建一个文件夹，通常能把提示触发出来。

## 二、root 相关开关在哪

root 功能默认关闭，需要时自己开：

1. 三个点 → **More Settings** → 勾选 **Allow root**。
2. 重启 MiXplorer。
3. 导航到根目录 `/`，触发超级用户授权弹窗时选**允许**并**记住**。

没弹授权窗或一直失败，先确认设备本身已 root、授权管理器里 MiXplorer 没被禁。

## 三、`/Android/data` 打不开

这是系统限制不是故障，Android 11 起的分区存储把这类目录管起来了。三条路（系统弹窗授权 / Shizuku / root）在 [访问Android数据目录.md](访问Android数据目录.md) 里有完整步骤。

## 四、插件怎么装、装在哪

三个点 → **Settings** → **Addons** → 点加号，会跳到对应插件的下载页。Silver 版已内置 Archiver 等四个官方插件，缺什么先在 Addons 列表里看是不是已经有了再决定装不装。

## 五、自带 SMB 服务端连不上（端口问题）

开发者在论坛答复过：Android 在 API 37 之前不允许应用绑定 1024 以下端口，所以没 root 的设备上，自带 SMB 服务端用不了默认的 445 端口（截至 2026-09 的答复，以官方最新说明为准）。对策：

- 给服务端配一个 1024 以上的自定义端口，客户端连接时也填这个端口；
- 或在已 root 且服务端配置为 445 的情况下使用默认端口。

只是**连电脑共享**（你在手机上当客户端）的话不受这条影响，照 [与电脑互传文件.md](与电脑互传文件.md) 操作即可。

## 六、云盘账号登录失败或传不上文件

6.68.4 这个版本的更新说明里修过 Mail.Ru 上传、Mega.nz 登录的问题，并给 Mail.Ru 加了两步验证（2FA）支持。你手上若是更早版本又正撞上这两个服务，先升级到 6.68.4 或更新版本再试；升级包在 [MiXplorer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b820157fbf57) 里取，版本号对照 [下载与安装教程.md](下载与安装教程.md) 第二节核对。Google Drive 则是另一回事：官方 6.66.4 更新日志写明 Google 调整了 scope，只有用本应用上传的文件才能全部访问到——这是 Google 侧的限制，进不去全部文件时按 XDA 用户手册帖里 Google Drive 专帖的方法处理。

## 七、删除时不再弹确认框

开启「撤消（Undo）」功能、且存储支持回收站时，文件会直接移入回收站而不弹删除确认——这是预期行为，删错了去回收站捞回来。想恢复每次弹窗的，回设置里关掉对应的撤消/回收站选项。

## 八、换机、重装前怕丢配置

设置、书签、皮肤都能整体导出：设置里导出会生成 `.micfg` 文件，新设备上用 MiXplorer 打开这个文件选导入即可还原。换机、清数据、重装之前都建议先导一份。

## 九、还是解决不了时

- 先确认问题能复现，记下：设备型号、安卓版本、是否 root、MiXplorer 版本号。
- 版本看 [下载与安装教程.md](下载与安装教程.md) 第五节；界面看不懂先按 [怎么设置中文.md](怎么设置中文.md) 切中文再排查。
- 带着上面这些信息去 MiXplorer 的 XDA 主帖反馈（[forum.xda-developers.com](https://forum.xda-developers.com/threads/app-2-3-mixplorer-v6-x-released-fully-featured-file-manager.1523691/)），能省掉来回追问。
