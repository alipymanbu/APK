# nPlayer 手势操作与倍速播放怎么设置

> 播放画面上能直接比划出来的操作，加上倍速、弹窗、后台、锁屏、续播、AB 复读这几项，都在这一篇里。

nPlayer 把大部分日常操作放在播放画面上：不退回列表、不翻菜单，手指在屏幕上滑几下就能调亮度、音量、进度和字幕。下面按「手势 → 倍速 → 弹窗与后台 → 锁屏 → 画面与声音 → 续播与复读 → 播放列表与播放记录」的顺序讲，每一项都写明在哪个位置、调完会怎样。

## 一、手势可以按自己的习惯改

进「设置 → 手势」，里面分成 **单指手势** 与 **双指手势** 两组，逐项勾选你要用的动作。默认那套覆盖了最常用的几个：

| 手势 | 作用 |
| --- | --- |
| 播放画面上下滑动 | 调音量与亮度（左右两侧各对应一项，哪一侧是哪项以你机器上实测为准） |
| 播放画面横向滑动 | 拖动播放进度 |
| 双击屏幕 | 进入弹窗播放（见第三节） |
| 双指捏合 | 缩放画面；在字幕区域捏合则调字幕字号 |
| 长按屏幕 | 锁定屏幕（见第五节的锁屏） |

如果你觉得某一项容易误触，比如看片时手一晃就把进度拖走了，进「手势」把对应项关掉即可，不影响其他手势。同一处还能调「菜单自动隐藏」的时间——控制条多久自己收起来，也是在这里设。

## 二、倍速播放（-0.5x ~ 4.0x）

1. 轻触屏幕调出控制条；
2. 用画面右侧的 **+** 和 **–** 调整速度；
3. 想立刻回到正常速度，点一下 **+** 与 **–** 中间显示当前倍速的那个数字，会重置为 1.0x。

可调范围是 **-0.5x 到 +4.0x**，负数即慢放。两点实践提醒：

- 高倍速考验音频与画面能否跟上。原片码率高、分辨率高时，4.0x 可能出现音画发飘，降到 2.0x 左右通常更稳；
- 如果你希望换下一集后仍保持当前倍速，到播放相关设置里打开 **保持播放速度**，否则每换一个文件都会回到 1.0x。

## 三、弹窗播放：一边看一边用别的应用

在 nPlayer 内部同时做两件事时用它。两种进入方式：

- 在播放画面上**双击**；
- 轻触屏幕 → 右上角**更多菜单** → **弹窗播放**。

画面会从全屏变成一个小窗浮在列表或其他界面上，小窗可以拖动挪位置；想回到全屏，点一下小窗即可。

需要留意的是，弹窗播放是应用内部的浮层，不是系统级画中画：退出 nPlayer 之后，这个小窗不会留在别的应用上面。如果你要的是切出去还能继续听声音，用下面这一节。

## 四、后台播放：锁屏或切出去也不停

进「设置 → 播放 → 视频播放」，打开 **后台播放**。开了之后，切到别的应用或者直接按电源键灭屏，画面停掉但声音继续。

配合这项的三个习惯：

1. 想控制播放要靠通知栏的播放控制条，所以第一次启动时**通知权限要允许**（见 [下载与安装教程.md](下载与安装教程.md)）；
2. 部分定制系统会限制后台应用的唤醒与联网，锁屏后声音断掉的话，去系统设置里把这个应用加入「不受限制」的省电白名单；
3. 这项主要适合听音频内容。视频长时间在后台解码没有意义，也更费电。

## 五、锁定屏幕，避免误触

播放中**长按屏幕**，或点左下角的锁定按钮，屏幕会被锁定；锁定期间所有手势都不生效，只有点一下那个锁图标才解锁。把手机揣兜里听、或者给小孩看的时候，这一项比什么都管用。

## 六、画面与声音的临场调整

这些都在播放画面的「设置」按钮里，按分类排好：

| 想解决的问题 | 分类 | 可调项 |
| --- | --- | --- |
| 比例不对、黑边太多 | 视频 | 屏幕大小、画面比例、视频平移 |
| 画面偏亮偏暗、颜色奇怪 | 视频 | 亮度、色彩、肤色、后处理 |
| 上下或左右反了 | 视频 | 水平翻转 / 垂直翻转 |
| 躺着看时画面自己转 | 设置 | 屏幕方向（可锁定只横屏或只竖屏） |
| 声音偏小 | 音频 | 音量增益（Boost） |
| 口型对不上 | 音频 | 音频延迟，可按秒直接输入 |
| 想换另一条语言的音轨 | 音频 | 多音轨 |

画面缩放也用得上：双指在画面上捏合，可以放大看细节，配合前面的「视频平移」把想看的区域移到画面里。

## 七、续播、AB 复读与播放记录

**续播**：进「设置 → 播放」，在「视频播放」和「音频播放」里各有一项 **继续播放**，三个选项是「是 / 否 / 询问」。音频默认是「否」——音乐一般从头放；视频按你的习惯设成「是」最省事，没看完的片子下次打开会接着上次的位置。

**AB 复读（重复某一段）**：

1. 播放时点控制条上的**重复播放**按钮；
2. 在要反复看的那一段开头，点底部的**重复起点**按钮；
3. 到这一段末尾，点**重复终点**按钮。

设好后这段会循环播放，区间位置会显示在屏幕上方。再点一次重复播放按钮即取消。学语言、跟唱、看教程时最常用。

播放相关设置里还有两个常用项：**自动播放下一个** 和 **随机播放**，按需打开即可。

## 八、播放列表与播放记录怎么管

播放列表里有**四个默认列表**：收藏、转向 URL、最近访问、最近播放。这四个是固定的，删不掉——所以想整理内容，就是在它们里面增删条目，而不是删列表。

| 想做的事 | 操作 |
| --- | --- |
| 新建自己的列表 | 播放列表页右上角 **+** → 新建播放列表 → 起名 |
| 改名 | 长按该列表 → 改名 |
| 删除自建列表 | 长按该列表 → 删除；或在列表上向左滑动 |
| 把某个文件/文件夹加进列表 | 在该列表里点右上角的选择，勾选后使用复制到其它列表 |
| 从列表里删掉或复制条目 | 同上，勾选后点删除或复制 |

**清除播放记录**：进「设置 → 播放 → 清除播放历史」。它会同时清掉两样东西——列表里「最近访问」的字样与加粗标记，以及**能续播的进度记录**（清完之后同一个视频会从头开始播）。不想留下「看过什么」的痕迹时，这是该动的那一处，配套的几处缓存见 [文件夹锁定与隐私文件怎么保护.md](文件夹锁定与隐私文件怎么保护.md)。

播放列表的路径、条目删除这些操作对网络位置与云盘文件同样适用。
