把用起来最容易卡住的几类问题按症状排开，每条都给出判断依据和下一步动作。按症状找，不用从头读。

## 一、文件列表是空的、扫不到视频

**判断依据**：能打开应用、界面正常，但「文件」页里看不到手机里明明存在的视频。

按这个顺序查：

1. **先看权限**：「设置 → 应用 → nPlayer → 权限」，确认 **所有文件访问权限**（管理所有文件）是打开状态。这项最容易在系统升级后、或手机管家清理后被动关掉；
2. **再看媒体分项**：Android 13 及以上把媒体权限拆成「照片和视频」「音乐和音频」，逐项允许；
3. **重启一次手机**：权限变更有时要重启才完全生效，这一步别省；
4. **确认文件位置**：放在 Download、Movies、Pictures、DCIM 这类共享目录里的文件能扫到；别的应用的私有目录（路径里带 `Android/data` 的那种）系统不允许读取，扫不到是正常的；
5. **隐藏文件**：列表设置里有「显示隐藏文件」，开了还看不到，说明系统确实把它隐藏了；
6. **锁定的文件夹**：被锁定的文件夹在列表里可能是不显示的（由列表设置里「显示锁定的文件夹」这一项决定），别把它当成文件丢了，见 [文件夹锁定与隐私文件怎么保护.md](文件夹锁定与隐私文件怎么保护.md)；
7. **刚传进去的文件**：从电脑传过来的文件放在哪，决定了它会不会出现在列表里，排查办法见 [把电脑上的电影传进手机播放.md](把电脑上的电影传进手机播放.md) 最后一节。

缩略图不出、列表滚动很卡是另一回事，在列表设置里清一次缩略图缓存即可。

## 二、有画面没声音

**先排除最简单的**：手机没静音、音量不在 0、连接的蓝牙设备没被别的应用占用。这些都排掉之后，按下面的顺序试：

1. **换一条音轨**：同一部片子常常同时带多声道与双声道两条轨道，音频菜单里切到能出声的那条；
2. **改音频输出方式**（接了 HDMI 才相关）：输出方式选 PCM；具体原因与两种模式的区别见 [投屏到电视与HDMI输出怎么用.md](投屏到电视与HDMI输出怎么用.md) 的第四节；
3. **音量增益**：声音确实出来了但偏小，在音频里把 Boost 抬一档；
4. **已知限制**：官方 FAQ 里写明，**TrueHD** 这类 Dolby 音轨由于 Dolby 目前不开放移动端授权，在移动设备上不出声。碰到这种片源，换一条非 TrueHD 的音轨是最直接的办法；
5. 到这里还不出声，按下一节换解码器再试一次。

## 三、卡顿、掉帧、机身发烫、花屏绿屏

这四种现象根子是同一个：**解码由谁来做**。

切换位置：播放画面 → 右上角**更多菜单** → **解码器** → 选 **硬件** 或 **软件**。

| 现象 | 先试哪个 | 为什么 |
| --- | --- | --- |
| 高分辨率掉帧、机身明显发烫、耗电快 | 硬件解码 | 由专用解码单元干活，省电且流畅，多数设备默认就是它 |
| 花屏、绿屏、色块，或者有声音没画面 | 软件解码 | 芯片不支持该编码时硬解会出错，改用 CPU 解码通常立刻正常 |
| 切到软解反而更卡 | 换回硬解，并降低片源码率 / 分辨率 | 软解全靠 CPU，老机器上 4K 这类负载它扛不住 |

三条补充判断：

- **先确认是哪个编码在闹**：列表里「显示视频信息」能看到这个文件的实际视频与音频编码，把编码和上一张表对照，就能判断该不该切软解；
- 硬件解码只有在**芯片支持该编码**时才生效，不支持的编码会自动退回软件解码——所以「同一部片子在 A 机上流畅、在 B 机上卡」是正常差异，不是故障；
- 关掉视频里的后处理、画质增强类选项，能明显减轻解码压力，画面差异肉眼往往看不出来。

## 四、音画不同步

分两种情况处理，方向完全不同：

- **只有某一个文件不同步**：先分清错的是声音还是字幕。声音对不上口型用**音频延迟**，调法见 [手势操作与倍速播放怎么设置.md](手势操作与倍速播放怎么设置.md) 的「画面与声音的临场调整」一节；字幕对不上画面用**字幕延迟**，调法见 [字幕加载与乱码同步怎么解决.md](字幕加载与乱码同步怎么解决.md) 的「字幕和画面不同步」一节——两者不在同一处，别找错地方；
- **每个文件都不同步**：切一次解码器（上一节）。另外用蓝牙耳机时本身会有延迟，先用有线耳机或外放确认一次，避免把蓝牙延迟当成播放器的问题。

差得非常离谱、整段对不上时，先怀疑片源本身：在电脑播放器里打开同一个文件对照，那边也错位就不是应用的问题。

## 五、连不上电脑或 NAS

先回到 [局域网与NAS播放设置.md](局域网与NAS播放设置.md) 的排查顺序走一遍，那里是按「同一网段 → 地址 → 共享开关 → 账号密码 → 端口 → 防火墙」排的，覆盖绝大多数情况。三条最常被忽略的补在这里：

- Windows 高级共享设置里，「所有网络」下的**密码保护的共享**没开；
- 共享用的账号**必须有密码**，空密码账号在 SMB 里经常直接被拒；
- 路由器开了**访客网络或 AP 隔离**，同网段设备互相不可见。

## 六、装不上、装完闪退

| 提示或现象 | 原因 | 动作 |
| --- | --- | --- |
| 应用未安装 | 手上这份比已装的版本低，或包名冲突 | 先卸载旧版再装；确认包名是 `com.newin.nplayer.pro` |
| 解析包错误 | 安装包没下完整，或传输过程中被改名 | 重新下载一次，别用会改后缀的下载工具 |
| 装到一半失败 | 存储空间不足 | 清出空间后重装 |
| 打开就闪退 | 数据损坏或版本冲突 | 清应用缓存 → 重启手机 → 仍闪退则卸载重装 |
| 只在打开某个文件时闪退 | 解码路径出错 | 按第三节切解码器 |

包名核对的方式见 [下载与安装教程.md](下载与安装教程.md) 的第二节。

## 七、云盘登不上、网页视频打不开、投屏搜不到设备

- **云盘**：授权会过期，重新登录一次。这些服务多数在境外，能不能连上先看当前网络能否访问对应服务，见 [连接云盘与网页视频怎么播.md](连接云盘与网页视频怎么播.md)；
- **网页视频**：先确认在系统浏览器里能正常播放，再放到内置浏览器里试；
- **投屏**：同一 Wi-Fi、关 AP 隔离、唤醒电视、确认电视侧投屏服务已开，完整清单见 [投屏到电视与HDMI输出怎么用.md](投屏到电视与HDMI输出怎么用.md) 的最后一节。

## 八、在线播放一直缓冲

先做一个判断：**同一个文件下载到本地后播放不卡，只有在线播卡，问题多半在网络上，不在应用**。

对应动作：把「设置 → 网络」里的**缓冲大小**调大一档（起播稍慢，但缓冲次数明显减少）；目录刷不出来时用「清除网络缓存」；Wi-Fi 优先连 5GHz 频段。片源码率特别高时，下载到本地再看是最省事的办法。

## 九、都排查完还是不行：重装一遍

前面八节都试过仍然不对，重装是成本最低的一招，因为它会一并重置权限状态、缓存与设置。顺序别搞反：

1. **卸载**应用；
2. **重启**手机（这一步是为了清干净残留的权限与进程状态）；
3. 从 [nPlayer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7561e2224bfe) 重新取一份包装回；
4. 装完按 [下载与安装教程.md](下载与安装教程.md) 第四节把权限重新给全。

注意重装会清掉本地的播放记录与设置，之前调好的字幕样式、播放列表都要重设一遍。
