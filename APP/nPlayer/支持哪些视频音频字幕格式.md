多数人挑这款播放器就是为了一件事：从网上存下来的文件，不用先转码就能直接播。下面按官方列出的格式范围整理，并说明这些清单该怎么读——只看后缀名，很容易得出错误结论。

## 一、视频格式

| 类别 | 格式 |
| --- | --- |
| 主流容器 | MP4、MOV、MKV、AVI、WMV、ASF、FLV、OGV |
| 早期网络视频 | RMVB、RM、TP |
| 官方明确支持硬解的编码 | H.264、MPEG4 |

## 二、音频格式

| 类别 | 格式 |
| --- | --- |
| 常见有损 | MP3、WMA、WAV |
| 常见无损 | FLAC、APE |
| 影视多声道音轨 | DTS（含 DTS HD）、Dolby AC3、E-AC3，官方明确支持 |

音频不只是「听歌」用途：视频里的音轨用的就是这套编码。影视片源里的 AC3、DTS、E-AC3 音轨是「有画面没声音」的高发区，遇到时看 [字幕加载与乱码同步怎么解决.md](字幕加载与乱码同步怎么解决.md) 里的音轨与输出方式两节。

## 三、字幕格式

| 类别 | 格式 |
| --- | --- |
| 文本字幕 | SRT、SMI（SAMI）、SSA、ASS、LRC |
| 图形字幕 | IDX + SUB（两个文件必须成对） |
| 其他 | SUP、MLP2 |
| 内嵌字幕 | 已封装进视频文件的字幕轨道，自动识别 |

SSA/ASS 支持完整样式与内嵌字体调用；字体缺失、中文变方块时的处理见 [字幕加载与乱码同步怎么解决.md](字幕加载与乱码同步怎么解决.md)。

## 四、图片与播放列表

| 类别 | 格式 |
| --- | --- |
| 图片 | JPG、PNG、BMP、GIF、TIFF |
| 播放列表 | CUE、M3U、PLS |

CUE 通常配合整轨无损音频使用，M3U/PLS 也常用于网络直播源；直播源怎么加进播放列表，见 [连接云盘与网页视频怎么播.md](连接云盘与网页视频怎么播.md)。

## 五、网络协议与云盘

| 协议 / 服务 | 典型用途 |
| --- | --- |
| SMB/CIFS | 播电脑或 NAS 共享目录里的文件 |
| WebDAV | 连支持 WebDAV 的网盘或服务器 |
| FTP / SFTP | 连家里的 FTP 或 SSH 服务器 |
| HTTP | 直连媒体地址 |
| UPnP/DLNA | 自动发现局域网内的媒体服务器 |
| 云盘 | Google Drive、OneDrive、Dropbox、Box、Yandex.Disk、Amazon Cloud Drive |

局域网播放的完整配置步骤在 [局域网与NAS播放设置.md](局域网与NAS播放设置.md)，云盘与网页视频在 [连接云盘与网页视频怎么播.md](连接云盘与网页视频怎么播.md)。

## 六、这份清单该怎么读

**第一，容器和编码是两件事。** MKV 只是一个「盒子」，里面装的可能是 H.264，也可能是 H.265——两种情况在低端机型上表现完全不同。清单里写支持 MKV，指的是这个盒子能打开，不代表里面装什么编码都流畅。

**第二，能播和播得流畅是两种结论。** 硬件解码依赖芯片支持的具体编码，芯片不支持时会退回软件解码。软件解码能出声出画，但高分辨率下会掉帧，耗电与发热也明显上升。同一部 4K 高码率文件，在中端机上可能流畅、在几年前的老机器上只能一格一格走，这属于正常差异。解码器怎么切换见 [常见问题与排查.md](常见问题与排查.md)。

**第三，清单覆盖的是常见格式，不是全部。** 官方口径是「几乎所有视频和音频格式」，但遇到冷门封装或冷门编码仍然可能打不开。这类文件先在电脑上转成 H.264 + MP4，成功率最高。

**第四，老格式要留个预期。** RMVB 这类早期网络视频格式能播是能播，但片源本身分辨率普遍不高，别按高清的标准去要求画面。

**第五，H.265（HEVC）要单独留意。** 官方在硬解口径里明确列出的只有 H.264 与 MPEG4，H.265 不在其中——它能不能硬解完全取决于你手机上那颗芯片。现在 4K 片源大量是 H.265，所以「手机能播 1080p 却不流畅地播这部 4K」很常见。判断与处理见 [常见问题与排查.md](常见问题与排查.md) 的「卡顿、掉帧、机身发烫、花屏绿屏」一节。

## 七、判断某个文件能否直接播的步骤

1. **看后缀**：在上面的清单里能找到，基本可播；
2. **看编码**：用电脑上的媒体信息工具查一下视频流与音频流，重点确认音频是不是 AC3 / DTS / E-AC3 这类；手机端不想动用电脑，列表里也有**显示视频信息**的入口，能直接看到一个文件的实际视频与音频编码；
3. **直接试播一分钟**：拖动进度条、切换音轨、挂上字幕，都正常就说明这一份文件在你的这台设备上没问题。

连打开都失败时，先怀疑装错包：确认手机里那份安装包来自同一处，避免两条包名线的版本混装后行为不一致，包名核对见 [下载与安装教程.md](下载与安装教程.md)。
