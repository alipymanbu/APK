看外语片能不能看下去，往往就卡在字幕上：挂不上、出来是方块、或者慢半句。这篇把字幕从「放哪」到「怎么调」按顺序理一遍，最后一段专门处理看了有画面没声音的多声道片源。

## 一、字幕放在哪才会被自动认出来

播放器找字幕的顺序是固定的：

1. 先在**视频所在的同一个文件夹**里找同名的字幕文件；
2. 同目录没有，才去你指定的**字幕文件夹**里找。

第二步要自己设：进「设置 → 字幕 → 字幕文件夹」，选一个专门放字幕的目录。这样零散下载的 SRT 都丢进去，也不用每次跟视频放一起。

两个容易踩的点：

- **同名的定义**是主文件名相同，扩展名不同。`电影名.mkv` 配 `电影名.srt` 会被认出来，`电影名.chs.srt` 这类带语言后缀的一般也认，但名字对不上就不会自动挂；
- **图形字幕 IDX 与 SUB 必须成对**放在一起，缺一个就挂不上。

格式清单见 [支持哪些视频音频字幕格式.md](支持哪些视频音频字幕格式.md)。

## 二、手动挂一个字幕

自动没认出来时手动加：

1. 轻触播放画面，点左侧的**设置**按钮；
2. 选 **字幕** 标签，打开**字幕显示**；
3. 点 **添加字幕**，列表默认列出当前文件所在目录里的字幕；
4. 选一个即可。也可以选别的目录里的字幕文件。

如果手上完全没有字幕，可以切到 **OpenSubtitles.org** 这一项在线找：选好语言下载加载，需要有网络。（这条只在联网时可用。）

## 三、中文变方块或乱码：改默认文本编码

乱码的来源几乎都是编码对不上——字幕文件本身是某一种中文编码，播放器按另一种去读，字就成了方块或奇怪的符号。

修法：

1. 进「设置 → 通用 → **默认文本编码**」；
2. 在列表里换成与字幕文件匹配的那一种（中文常见的分歧就是 GBK / Big5 与 UTF-8 之间）；
3. 回到播放画面**重新加载一次字幕**，改编码不会自动作用在已经加载的那条上。

如果换了一轮还是乱码，说明这个字幕文件本身的编码比较特殊。最稳的办法是在电脑上用任意文本编辑器打开它、另存为 UTF-8，再放回手机——这一步不改内容，只改存储编码，之后任何播放器都不会再认错。

## 四、字幕和画面不同步

差得不多时，直接在播放界面微调：

1. 轻触屏幕，点左侧设置按钮；
2. 进 **字幕** 标签，找到**字幕延迟 / 同步**；
3. 用 **+ / –** 前后移动，直到口型对上。

规律很简单：字幕比声音**早**出现就把时间往**后**推，字幕比声音**慢**就往**前**提。调整是作用在当前这个文件的，换个文件要从头来。

差得很离谱（整段错位、上下句完全对不上）时，通常是对应了错误版本的字幕文件——同一部片子不同发行版的剪辑点不一样，换一份字幕比硬调更省事。

## 五、字体、大小、位置与样式

**位置与大小**两种调法：

- 手势：在画面上**拖动字幕**挪位置，**双指捏合**改字号（见 [手势操作与倍速播放怎么设置.md](手势操作与倍速播放怎么设置.md)）；
- 菜单：「设置 → 字幕 → 显示字幕」里有位置模式可选——**屏幕内**模式可以把字幕挪到画面任何地方，**视频内**模式只能在画面范围内调整。

**样式**在同一层的字幕设置里，可调项包括字体、字号、文字颜色、描边、阴影、行高、背景和模糊。字幕压在看不清的背景上时，加一层描边或阴影，比一味调大字号有效。

**加字体**：想要字幕用指定字体，先把字体文件拷进 nPlayer 自己的 Documents 目录（用 Wi-Fi 传输或走局域网共享拷入都行，办法见 [把电脑上的电影传进手机播放.md](把电脑上的电影传进手机播放.md)），再到「设置 → 字幕 → 字体」里选中它。这一项对文本形式的字幕（SRT、SMI、SUB、MLP2、LRC、TXT）生效。字体显示不对、或者字体列表里看不到刚放进去的，用同一层设置里的 **清除字体缓存** 清一次再重来。

## 六、多音轨与多字幕

**换音轨**：播放中轻触屏幕 → 设置 → **音频** → 多音轨，列出现有轨道直接切换。字幕与音频的语言偏好还可以提前设好：进「设置 → 音频 → 首选语言」和「设置 → 字幕 → 首选语言」，把常用语言排到最上面，以后打开多语言片源会自动选对的那条。

**同时挂多条字幕**：支持一次显示多条字幕轨道，学外语时把原文和译文并排显示很实用；不需要时逐条关掉即可。

## 七、有画面没声音：多声道音轨怎么办

AC3、DTS、E-AC3 这类影视音轨是「有画面没声音」的高发区，原因是设备或输出链路解不出来。三条路，按成本从低到高：

1. **换一条音轨**：同一部片子常常同时带多声道和双声道两条，直接在音频菜单里切到能出声的那条；
2. **改音频输出方式**（接了 HDMI 才相关）：播放画面设置 → 音频 → **HDMI 输出**，两种模式的含义是——
   - **PCM**：由手机先解码，再把声音送给输出设备；
   - **Bitstream（源码输出）**：把原始码流原样交给输出设备去解。
   普通显示器本身没有解码器，用 Bitstream 就会没声音，要选 PCM；只有接到功放或回音壁这类带解码的设备时，Bitstream 才是正确选择；
3. **调音量增益**：确实在播但声音偏小，用音频里的 **Boost** 抬一档。

三条都试过仍不出声，就不是字幕相关的问题了，转到 [常见问题与排查.md](常见问题与排查.md) 里按「有画面没声音」那一节排查，重点看解码器设置。在局域网共享目录里播片时字幕的额外限制（网络字幕要先下载到本地），见 [局域网与NAS播放设置.md](局域网与NAS播放设置.md)。
