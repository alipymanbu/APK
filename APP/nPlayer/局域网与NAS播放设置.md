把片库放在电脑或 NAS 上、手机直接在线看，是这个播放器最实用的一块。前提是手机和那台设备在同一个局域网里，而且共享那侧开了对的服务。这篇讲的就是这两头分别要做什么。

## 一、先选协议

| 协议 | 什么时候用它 | 要注意的点 |
| --- | --- | --- |
| SMB/CIFS | Windows 共享文件夹、绝大多数家用 NAS | 端口 445；Windows 侧要开网络发现与文件和打印机共享 |
| WebDAV | 支持 WebDAV 的网盘、部分 NAS 套件 | 一般走 80 / 443 或自定义端口 |
| FTP / SFTP | 家里的 FTP 服务、Linux 服务器 | SFTP 走 SSH 端口，通常 22 |
| UPnP/DLNA | 已开 DLNA 的媒体服务器、电视盒子 | 免填地址，但字幕能不能出来取决于服务器有没有一并提供 |

不确定选哪个就先试 SMB——Windows 与 NAS 默认支持，填的东西最少。

## 二、在应用里添加一个网络位置

1. 进底部 **网络** 标签，点右上角的 **+**（新建服务器）；
2. 选协议类型；
3. 填两项：**标题**（列表里显示的名字，随便起）与 **主机**（必填，服务器的 IP 或主机名）；
4. 填 **用户名 / 密码**。官方建议务必设置账号密码，留空共享在多设备网络里风险更高；
5. 服务器改过端口、共享目录在子路径、或者要指定工作组时，展开底部的 **高级** 填端口、路径、工作组；
6. 保存。之后在「网络」列表里点开这个条目，就能像本地文件夹一样浏览。

**不想手填地址**的话，用同一处的 **网络搜索…**：它会扫描手机周边所有能连的网络服务器，把找到的列出来，点一个就连。前提是那侧的服务已经开着、且广播没有被路由器拦掉。

## 三、电脑那侧的共享怎么开

**Windows**

1. 控制面板 → 网络和 Internet → 网络和共享中心 → 更改高级共享设置；
2. 「专用（当前配置文件）」里打开 **启用网络发现** 与 **启用文件和打印机共享**；
3. 「所有网络」里打开 **启用密码保护的共享**；
4. 保存更改；
5. 右键要共享的文件夹 → 属性 → **高级共享** → 勾选「共享此文件夹」，再点权限，给对应用户读（或读+写）的权限。

**macOS**

系统设置 → 通用 → 共享 → 打开 **文件共享**，再在「共享文件夹」里添加目录，并在「用户」里给对应账号设置读写权限。

两边都要确认一点：共享用的那个账号要有密码。没有密码的账号在 SMB 里常常直接被拒。

## 四、连上之后：在线播还是先下载

- **在线播**：直接点开文件就是流式播放，不占手机存储，但对网速和 Wi-Fi 稳定性有要求；
- **下载到本地**：在列表里长按该文件或文件夹，选下载，指定保存目录，之后可以在下载队列里看进度。下载队列还能调整顺序。

片源码率高、家里 Wi-Fi 一般的时候，先下载再看通常比在线播更省心。

如果你只是想临时从电脑上拷几个文件进手机，连共享都不用开——应用自带一条 Wi-Fi 传输通道，电脑用浏览器就能把文件推进来，见 [把电脑上的电影传进手机播放.md](把电脑上的电影传进手机播放.md)。

还有一条和字幕有关：**播网络文件时**，「添加字幕」里会多出一个网络标签，可以直接从同一个服务器上挑字幕文件；反过来，本地文件想配服务器上的字幕，得先把那个字幕文件下载到本地才行。字幕的其他调整见 [字幕加载与乱码同步怎么解决.md](字幕加载与乱码同步怎么解决.md)。

## 五、缓冲与缓存怎么调

进「设置 → 网络」：

| 项目 | 调整方向 |
| --- | --- |
| 缓冲大小 | 调小：起播更快，但网络一抖就容易反复缓冲；调大：起播要多等一会儿，缓冲次数明显减少 |
| 缓存大小 | 控制本地留多少临时数据；空间紧张时调小 |
| 清除网络缓存 | 网络路径访问异常、目录刷不出来时清一次 |

在线看高清片源频繁缓冲时，先把缓冲大小调大一档试试，通常比反复折腾 Wi-Fi 有效。

## 六、连不上的排查顺序

按这个顺序查，能覆盖绝大多数情况：

1. **同一网段**：手机是不是连在同一个 Wi-Fi 上，而不是移动数据或访客网络；路由器开了「AP 隔离」的话，同网段的设备之间也互相看不见；
2. **地址填对**：主机填的是局域网 IP 还是主机名。主机名解析失败时，换成 IP 再试；
3. **共享开关**：回到第三节，确认那三个开关都开了、文件夹也确实共享了；
4. **账号密码**：不要留空。密码里带特殊符号时确认输入法没有自动转换；
5. **端口**：SMB 默认 445，改过就在「高级」里填实际端口；
6. **防火墙**：Windows 防火墙要放行「文件和打印机共享」；
7. **服务器侧在线**：NAS 是否处于休眠、Mac 是否已经睡眠。

上面都查过还是连不上，看 [常见问题与排查.md](常见问题与排查.md) 里对应的一节；如果只是目录能进、播放卡，那是网速与缓冲的问题，看上一节。想看的文件格式支不支持在线播，对照 [支持哪些视频音频字幕格式.md](支持哪些视频音频字幕格式.md)。
