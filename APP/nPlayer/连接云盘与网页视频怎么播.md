不想把片子拷进手机、又想直接看，这个播放器提供了三条路：连云盘、播一条网络地址、用内置浏览器打开网页。三条路的入口不一样，能看的片源也不一样，这篇分开说。

## 一、能连的云盘与网络服务

| 类型 | 具体服务 |
| --- | --- |
| 云盘 | Google Drive、OneDrive、Dropbox、Box、Yandex.Disk、Amazon Cloud Drive |
| 服务器协议 | WebDAV、FTP、SFTP、HTTP |
| 局域网协议 | SMB/CIFS、UPnP/DLNA（配置步骤见 [局域网与NAS播放设置.md](局域网与NAS播放设置.md)） |

添加方式：底部 **网络** 标签 → 右上角 **+** → 选 **连接到 Web 服务器** → 在列表里挑你要的服务 → 输入账号信息后连接。连接成功后，这个云盘会作为一条网络位置留在列表里，点开就能像本地文件夹一样浏览目录。

有一件事得先说清：上面这些云盘服务大多在境外，**能不能连上取决于你当前网络能不能正常访问对应服务**。连不上时先确认这一点，再去怀疑应用——这不是换个设置能解决的事。

## 二、播一条网络地址（直链 / 直播源）

手上已经有一条媒体地址时，不用下载：把它存进播放列表里的 **转向 URL** 列表，之后点开就能播。播放列表里有四个默认列表——收藏、转向 URL、最近访问、最近播放，网络地址就归到「转向 URL」这一条下面，具体怎么增删见 [手势操作与倍速播放怎么设置.md](手势操作与倍速播放怎么设置.md) 的播放列表一节。

常见两类地址：

- **以 `.m3u8` 结尾的 HLS 地址**：直播源、切片点播都是这一类，是电视直播与网络频道最常见的形式；
- **常规 `http` / `https` 直链**：指向一个完整的媒体文件。

两个实践提醒：

1. 地址要带完整的协议头，从浏览器地址栏复制来的**页面地址**通常播不出画面——页面地址指向的是网页，媒体地址要另取；
2. 直播源本身由第三方维护，地址失效、频道改址都是常事。这条不行就换一条，不是播放器的毛病。

## 三、用内置浏览器看网页视频

有些站的视频确实只能在线看，这时候用播放器自带的浏览器：

1. 进底部 **浏览器** 标签；
2. 在顶部地址栏输入网址并打开；
3. 页面上找到视频，点播放。

视频会被播放器接管，于是手势调音量亮度、改画面比例、挂字幕、切倍速这一整套都能用上——这也是用内置浏览器看网页视频的主要理由，比在浏览器里点全屏强得多。相关操作见 [手势操作与倍速播放怎么设置.md](手势操作与倍速播放怎么设置.md)。

顺带一提，云盘和网页里的片源同样受格式与编码的限制，能不能播先对照 [支持哪些视频音频字幕格式.md](支持哪些视频音频字幕格式.md)；网络流地址的稳定性还取决于对方服务器。

## 四、把网络上的文件存到本地

在线播吃的是网速、不占存储，代价是网络一抖就卡。想稳定看，可以先把文件拉到本地：

- 在文件列表里**长按**该文件或文件夹，选下载；
- 指定保存目录后开始，进度在下载队列里看，队列顺序还能调整。

这条路和局域网共享目录里的下载是同一套操作，细节见 [局域网与NAS播放设置.md](局域网与NAS播放设置.md)。用移动数据时要注意流量，设置里有一项「蜂窝数据」开关，可以在非 Wi-Fi 环境下限制这类联网行为。

## 五、云盘播放最常碰到的三个问题

1. **登录失效**：云盘的授权会过期，表现为目录刷不出来或提示重新登录，重新登一次即可。这一版的更新日志只有「改进 Google Drive 登录」一句，说明云盘登录正是这个版本重点修的地方；
2. **能进目录、点开播不动**：多数是这条服务的带宽限制或网络绕行太远，换成本地下好再播；
3. **字幕不在云盘里**：播网络文件时，「添加字幕」里会多出一个网络标签，可以直接从同一个服务器上挑字幕；但本地文件想用服务器上的字幕，必须先把字幕文件下载到本地。字幕的编码、同步、字体等问题见 [字幕加载与乱码同步怎么解决.md](字幕加载与乱码同步怎么解决.md)。

三条都排查过还是不行，转到 [常见问题与排查.md](常见问题与排查.md) 按症状找对应的一节。
