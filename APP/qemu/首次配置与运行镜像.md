## 一、主界面分区速览

主界面是一个长表单，从上到下分成几块，每块管虚拟机的一个部分：

| 分区 | 里面有什么 | 作用 |
| --- | --- | --- |
| 选择配置文件 | 下拉框 + 删除文件 / 保存配置 | 每台虚拟机一份 `.sh` 配置，切换下拉框即切换虚拟机 |
| 核心环境 | CPU架构 / CPU类型 / CPU核数 / 虚拟运存 | 决定虚拟电脑的「CPU 与内存」 |
| 主磁盘 | 硬盘A / 硬盘B / 硬盘C / 硬盘D | 挂虚拟硬盘镜像，系统一般装在硬盘A |
| 可移动设备 | 只读光盘 / 软盘A / 软盘B | 挂 ISO 光盘镜像、软盘镜像 |
| 启动设置 | 启动方式 / 内核 / 初始RAM磁盘 / 追加 | 从哪个设备引导，以及 Linux 直启参数 |
| 其余设置 | 图形界面选择 / VNC端口 / 额外参数 | 画面输出方式、端口与追加的 QEMU 参数 |

右下角的圆形播放键是启动键。

## 二、第一步：新建配置文件

- 在「选择配置文件」处新建一份配置，给虚拟机起个名字。默认自带的 `kolibri.sh` 是示例配置，可以参考它的写法，别直接覆盖它。
- 配置改完**一定要点「保存配置」**：所有栏位的修改都先停留在界面上，不保存，下次打开就丢了。这是新手最常踩的一个坑。

## 三、第二步：核心环境

- **CPU架构**：与镜像位数对应。跑 32 位系统选 `i386`，跑 64 位系统选 `x86_64`；拿不准镜像位数就先试 `x86_64`（它也能启动不少 32 位系统）。ARM、MIPS 等其他架构在列表里也有，用于对应架构的镜像。
- **CPU类型**：QEMU 模拟的 CPU 型号。`qemu64` 是 QEMU 的默认型号、兼容性最稳；也有教程推荐 `IvyBridge`、`core2duo`——不同口径都存在，普通使用选 `qemu64` 或保持默认，遇到系统不认 CPU 再换。
- **CPU核数**：软件模拟下没有真正的多线程，核数调大反而互相抢资源拖慢整体。从 1 核开始，最多试到 2 核。
- **虚拟运存**：给虚拟机的内存。经验值是**手机总内存的四分之一**；调得比这更大，安卓会杀后台、虚拟机直接崩。轻量小系统给 64~256M 就够，Windows 这类桌面系统 512M~1G 起步（以手机内存余量为准）。

## 四、第三步：挂镜像

- **硬盘A~D**：挂硬盘镜像。刚装好时都是「无」，点开选择放在手机里的磁盘镜像文件。手头没有磁盘镜像的话，先用菜单里的「镜像工具箱」创建一个空磁盘，见 [镜像工具箱与磁盘管理.md](镜像工具箱与磁盘管理.md)。
- **只读光盘**：挂 ISO 光盘镜像，装系统用的安装盘通常挂这里。
- **软盘A / 软盘B**：挂软盘镜像（`.img`），轻量小系统和老系统走这里。
- 镜像文件建议统一放在手机存储的 `Qemu` 目录（界面默认路径就是 `/sdcard/Qemu/`），配置时下拉列表能直接选到。
- 不用的设备保持「无」即可——比如只用光盘装系统时，软盘A/B 留空，免得引导顺序混乱。

## 五、第四步：启动设置

- **启动方式**：决定从哪里引导。用安装盘装系统时选对应介质（软盘/光盘），系统装进硬盘后改成**硬盘**。装完系统后引导还停在安装盘上，重启会又进安装程序——记得回头改。
- **内核 / 初始RAM磁盘 / 追加**：这三栏是给 Linux 直启准备的（直接指定内核镜像，并在「追加」里写 `root=/dev/...` 这类内核参数）。跑 Windows 或常规 ISO 安装流程的不用碰。

## 六、第五步：其余设置

- **图形界面选择**：默认 `VNC`；1.1.0 起也支持 `SDL`（本机直接渲染，不用再开 VNC 客户端，但各设备兼容表现不一）。第一次用建议保持 VNC。
- **VNC端口**：默认 `0`，对应 VNC 客户端连接时的显示编号 `:0`。想同时开多台虚拟机，每台用不同端口（0、1、2…）。
- **额外参数**：原样追加给 QEMU 的命令行参数，比如回放快照的 `-loadvm s0`。不熟悉 QEMU 参数就留空。

网卡、声卡、显卡这类设备，在部分版本里通过独立菜单或「额外参数」指定，社区常用的组合：

| 设备 | 推荐值 | 说明 |
| --- | --- | --- |
| 网卡 | `user` 模式 + `rtl8139` | user 是用户态网络，虚拟机借手机的网络上网，不需要 root |
| 声卡 | `es1370` | 老式声卡，兼容面广 |
| 显卡 | `vmware` | 社区教程里的常用选择 |

以你手上版本界面实际提供的选项为准；列表里没有的项就不用管。参数背后的取舍见 [性能参数怎么调.md](性能参数怎么调.md)；联网模式的含义与上不了网的排查，专门写在 [虚拟机联网怎么设置.md](虚拟机联网怎么设置.md)。

## 七、第六步：保存、启动、连画面

1. 点「**保存配置**」。
2. 按右下角**播放键**启动虚拟机。启动成功后，1.1.0 支持自动关联图形端软件；没有自动跳的话，手动打开 VNC 客户端。
3. 在 VNC 客户端里新建连接：地址写 `127.0.0.1:0`（冒号后是显示编号，与「VNC端口」对应；端口填 1 就写 `127.0.0.1:1`）。
4. 连上后看到的就是虚拟机画面：BIOS 自检、引导、装系统都在这个窗口里完成，直接点按操作即可。

装完系统、重启之前，把「启动方式」改成硬盘，再保存一次配置。

## 八、多开与快照

- **多开**：1.1.0 支持同时运行多台虚拟机——给每台各建一份配置文件、各用各的 VNC 端口即可。两台共享手机的内存与 CPU，各自都别给大内存。
- **快照**：QEMU 支持保存运行状态、下次还原。启动时在「额外参数」里写 `-loadvm 标签名` 可以直接回到某个快照。属于进阶用法，先跑通基本流程再玩。

跑起来之后卡、崩、画面出不来，去 [常见问题排查.md](常见问题排查.md) 按现象排查。
