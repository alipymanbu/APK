## 一、联网模式选 user

多个社区教程对这一项的口径完全一致：**一定要选 `user`**。user 是 QEMU 的用户态网络：虚拟机通过手机的网络栈出去，不需要 root，也不动系统网络设置。启动器界面里这一栏在联网/网络设置处（不同版本位置略有差异，栏位说明见 [首次配置与运行镜像.md](首次配置与运行镜像.md)）。

## 二、user 模式下网络长什么样

- 虚拟机拿到的是 QEMU 内部网段的地址（常见为 `10.0.2.x`），网关常是 `10.0.2.2`——它是「手机本身」的别名，不是路由器地址。
- 虚拟机里看到的 IP 与手机实际 IP 不同是正常的，不是连错了。
- 这种模式天然与外部隔离：外部设备主动连虚拟机里的服务是连不进来的，反过来虚拟机上网一般开箱即用。

（以上是 QEMU 用户态网络的通用行为；具体数值以虚拟机系统里实际拿到的为准。）

## 三、网卡型号

| 型号 | 说明 |
| --- | --- |
| `rtl8139` | 本应用社区教程里最常用的选择，老式百兆网卡，兼容面广 |
| `e1000` | 另一部分教程（含其他 QEMU 前端）里出现的口径，Intel 千兆型号 |

两种都是 QEMU 支持的仿真网卡，社区口径不统一就并列对待：先试 `rtl8139`，虚拟机里认不出网卡再换 `e1000`。

## 四、虚拟机里上不了网，按这个顺序查

1. **手机本身有没有网**：先在手机浏览器开个网页确认——手机断网，虚拟机必然断网。
2. **联网模式是不是 user**：选了别的模式（或留空）是最常见的翻车点。
3. **网卡型号**：`rtl8139` 与 `e1000` 换着试；换完保存配置、重启虚拟机。
4. **虚拟机系统里的网络**：进虚拟机看网卡有没有认到、IP 是否是内部网段；Windows 里看设备管理器与 `ipconfig`，认不出网卡就是型号问题。
5. **DNS 问题**：能 ping 通 IP 但打不开网页，多半是 DNS——把虚拟机的 DNS 手动填成公共 DNS 试试。
6. 都不行就重启一遍虚拟机（先在启动器里停止，再按播放键），user 网络随虚拟机进程一起重建。

还查不出，去 [常见问题排查.md](常见问题排查.md) 按现象对号入座。

## 五、进阶用法在哪折腾

端口转发、给虚拟机开服务等玩法，QEMU 层面都支持，但这个启动器没有给独立界面，要通过「额外参数」写 QEMU 原生参数实现。不熟悉 QEMU 命令行的，先把 user 模式下的基本上网跑通就够用了。
