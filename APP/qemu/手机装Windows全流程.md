## 一、先把预期定准

手机上的 QEMU 是纯软件模拟。同类方案（Limbo、Bochs 这类同样跑完整系统的模拟器）的第三方评测普遍记录：启动 Windows 7 这类桌面系统以**小时**计，装好后基本只能跑系统自带的小程序，浏览网页、联网都不能保证可用。想要「手机上当电脑用」的，这篇帮不了你；想在手机上验证一遍装系统流程、怀旧跑跑老系统、折腾学习为目的的，往下看。

另外想清楚需求：如果目标只是**运行某个 Windows 程序**而不是整个系统，文末第六节有更合适的路子。

## 二、准备三样东西

1. **Windows 安装镜像（ISO）**：通过你自己的正规渠道获取授权与安装介质——启动器不附带任何系统安装包，授权问题也要自己解决。
2. **一块空磁盘镜像**：用「镜像工具箱」→「创建空磁盘」，容量给 4 GB 起步，创建方法见 [镜像工具箱与磁盘管理.md](镜像工具箱与磁盘管理.md)。
3. **VNC 客户端**：安装与连接准备见 [下载与安装教程.md](下载与安装教程.md)。

镜像文件统一放进 `/sdcard/Qemu/` 目录。

## 三、参数怎么给

完整栏位说明在 [首次配置与运行镜像.md](首次配置与运行镜像.md)，这里只列装 Windows 的关键几项：

| 栏位 | 建议值 | 说明 |
| --- | --- | --- |
| CPU架构 | 32 位镜像 `i386`；64 位镜像 `x86_64` | 位数必须与镜像一致，错了直接起不来 |
| 虚拟运存 | 512M~1G | 不超过手机内存的四分之一 |
| CPU核数 | 1 | 软件模拟多核是负收益 |
| 硬盘A | 刚创建的空磁盘 | 系统装这里 |
| 只读光盘 | Windows 安装 ISO | 安装程序从这里引导 |
| 启动方式 | 光盘 | 装完改回硬盘 |
| 显卡 / 声卡 / 网卡 | `vmware` / `es1370` / `user` + `rtl8139` | 社区常用组合 |

## 四、安装过程

1. 保存配置，按播放键启动，VNC 连上后看到安装程序引导。
2. 像在电脑上一样走安装流程：分区、格式化、把系统装进硬盘A。安装程序里慢是正常的，每一步都在软件模拟下执行。
3. **耗时以小时计**，期间把手机插上电、屏幕常亮（系统设置里临时关掉自动锁屏），别让安卓杀后台。
4. 装完重启前，「启动方式」改成硬盘，保存配置。之后每次开机直接从硬盘引导。

## 五、装完之后的提速清单

社区里跑同类方案沉淀下来的几条经验（效果因设备而异）：

- **关掉索引服务**：虚拟机里运行 `services.msc`，把 Windows Search 停掉并设为禁用——后台索引在模拟环境里是持续的负担。
- **关视觉特效**：性能选项里调到最佳性能，关掉动画与主题特效。
- **用轻量浏览器**：真要联网的话，选 K-Meleon 这类轻量浏览器，别装现代重型浏览器。
- **少装驱动与常驻软件**：每多一个后台程序，模拟开销翻一倍不止。
- 参数层面的取舍见 [性能参数怎么调.md](性能参数怎么调.md)。

## 六、不想装整个系统？

- **只想跑某个 Windows 程序**：社区还有 Wine / Winlator 这类兼容层方案，直接在安卓上跑 x86 程序，不用装系统；兼容性与性能因程序而异，可以作为替代路线去了解。
- **想正经干活**：远程桌面连一台真电脑，体验远好于在手机上模拟整个系统。

## 七、跑不起来的时候

按现象去 [常见问题排查.md](常见问题排查.md)：黑屏 / No bootable device 多是启动方式与挂载不对应，闪退多是内存给大了，反复要装 QEMU 是初始化没走完。装系统过程中卡住但没崩，多数情况就是慢——确认手机侧没被杀后台、没降频，再等等。
