## 一、申请了哪些权限

官方渠道公示的敏感权限说明如下，每项都对应一个具体用途：

| 权限 | 官方说明的用途 |
| --- | --- |
| 通讯录 | 一键登录需要读取联系人权限 |
| 存储 | 读取存储卡上的照片、媒体内容和文件，以便上传 |
| 电话 | 一键登录、获取通话状态以及获取拨打的号码 |
| 摄像头 | 拍摄照片或视频 |
| 读取视觉媒体 | 修改或删除存储卡上的照片、媒体内容和文件 |

公示口径以官方「用户权限」页当时显示为准。

## 二、哪些可以不给

- 只看资讯、逛论坛：摄像头、存储这类权限可以拒绝，不影响浏览。
- 不想用一键登录：通讯录、电话权限可以拒绝，改用手机号验证码方式登录。
- 要发图、传截图：这时候才需要给存储或「读取视觉媒体」权限。
- 控制后台流量：有用户反馈它后台流量消耗较多，介意的话可以在系统的流量管理里限制它的移动数据权限。

安卓对权限是逐项授权的，系统设置里随时可以改。
