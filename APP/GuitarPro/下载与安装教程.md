## 一、装机前先核对这几项

| 项目 | 网盘里这份的信息 |
| --- | --- |
| 版本 | 1.7.4 |
| 包名 | `com.arobasmusic.guitarpro` |
| 安装包大小 | 约 35.14 MB |
| MD5 | `7F9B334ED2C123FC8A26883A04856124` |
| 系统要求 | 安卓 5.2 及以上 |

三点提醒：

- 认准包名 `com.arobasmusic.guitarpro`，这是 Arobas Music 的 Guitar Pro **手机版**；电脑上的 Guitar Pro 7 / 8 是另一套软件，名字相近，装之前别认错。
- 最低安卓版本在不同渠道有 4.3 与 5.2 两种标注，以你安装时的实际提示为准；装不上先查系统版本。
- 手机至少留出 100 MB 以上空闲空间——安装包 35 MB，解压安装还要再占一些。

## 二、把安装文件拿到手机

1. 打开上面的 **GuitarPro 安装文件资源（夸克网盘）** 链接，把文件**转存到自己网盘**，再在手机夸克 App 里下载到本机，得到一个 `.apk` 文件。
2. 下载完成后在网盘 App 的下载列表里点这个文件，系统会弹出安装确认。

不想用手机下载也可以：在电脑上下好，再用数据线、QQ / 微信文件传输助手等任意方式把 `.apk` 传进手机存储（放「下载」文件夹最好找）。

## 三、安装步骤

1. 用手机自带**文件管理器**找到 `.apk`，点它。
2. 第一次装会提示「允许安装未知应用」，按提示给**文件管理器**这个授权（只影响从文件管理器发起的安装，不给装不了）。
3. 点「安装」，等进度走完，点「打开」。

## 四、装不上的常见原因

| 现象 | 先查这里 |
| --- | --- |
| 点安装没反应 / 一闪而过 | 存储空间是否不足；文件管理器有没有拿到「安装未知应用」授权 |
| 提示「应用未安装」 | 手机里残留过旧版本或同包名应用——对照 `com.arobasmusic.guitarpro` 卸载干净再装；或安装包传输中损坏，重新下载一次 |
| 提示系统版本过低 | 安卓版本低于要求，回看第一节 |
| 被手机管家 / 杀毒拦下 | 这类拦截只看「未知来源」，确认文件是你自己从网盘转存的再放行 |

怀疑安装包本身坏了，可以核对文件 MD5 是否为 `7F9B334ED2C123FC8A26883A04856124`（不少文件管理器在文件详情里能看到 MD5）。

## 五、装完先做这两件事

1. 该版本带简体中文界面；启动后若是英文，一般跟随系统语言，把系统语言切到中文或到应用内设置里换语言（以应用内实际选项为准）。
2. 手上还没有 `.gp` 谱子的话，先看[导入曲谱文件的方法.md](导入曲谱文件的方法.md)把谱子弄进去；想直接试播放，跳[播放与练琴设置.md](播放与练琴设置.md)。

装得上、但一打开就闪退这类装完才冒出来的问题，整理在[常见问题与排错.md](常见问题与排错.md)。
