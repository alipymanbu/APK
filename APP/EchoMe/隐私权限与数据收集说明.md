## 一、先给结论

官方隐私政策（生效日期 2025-07-01，运营方杭州昵享信息技术有限公司）披露的收集范围包括：账号信息（邮箱等）、设备信息（含 IMEI、OAID、Android ID、MAC 地址等标识符）、你主动上传的内容，以及为统计与广告接入的多家第三方 SDK 数据。你能在系统侧控制的开关是权限，在应用侧控制的开关是注销账号。逐项怎么核对，看下面几节；完整原文见官网 [隐私政策](https://www.aiechome.com/privacy_policy.html)。

## 二、权限：哪几项可以不给

六项权限的用途与拒给后果在 [下载与安装教程.md](下载与安装教程.md) 第五节列了表，这里只补「在哪儿改」：

- 路径：系统设置 → 应用 → EchoMe → 权限，逐项改成「允许 / 拒绝 / 仅在使用中允许」；
- **麦克风与相册是刚需**（语音聊天、发动态要用），摄像头、剪切板可以放心拒；
- 拒绝后再出现功能异常，先回想是不是刚拒过对应权限，不用先清缓存。

## 三、它收集哪些信息（政策原文口径）

| 类别 | 具体项 | 用途 |
| --- | --- | --- |
| 账号信息 | 注册邮箱、联系方式，可能经短信/邮件验证身份 | 建号、登录、找回 |
| 设备信息 | IMEI、设备序列号、OAID、MEID、Android ID、IMSI、GUID、MAC 地址、SIM 卡序列号 | 安全与运营统计 |
| 使用行为 | 页面访问、点击等统计 | 配合友盟等 SDK 分析 |
| 主动上传 | 相册图片、拍摄内容、语音 | 实现你发起的功能 |
| 剪切板 | 仅在你主动分享时读取口令/链接 | 跳转与分享 |

两点值得注意：

- 政策声明收集的设备标识种类相当宽（含 IMEI、MAC 等），这是国内 Android 应用的常见做法，但如果你介意，可以在系统里限制「电话/设备标识」权限并关闭广告个性化；
- 政策写明数据会做脱敏存储、关键数据加密，且**不与第三方分享**（法律要求或安全必需的除外）。

## 四、接入的第三方 SDK

政策披露的 SDK 分四类，各自的收集项与用途以政策内清单为准，这里点名便于你自己核查：

- **统计与崩溃分析**：友盟 SDK（收集崩溃信息、Android_id、位置、运营商信息，用于分析崩溃原因）；
- **广告类**：优量汇（腾讯）、快手广告联盟、穿山甲（巨量引擎）、百度百青藤、Sigmob、Funlink——这类 SDK 会收集设备标识、IP、传感器甚至应用安装列表，用于广告投放与反作弊；介意的话在系统「广告 ID / 个性化推荐」设置里关闭个性化；
- **一键登录**：uni-app 一键登录模块（DCloud 联合个推），收集本机号码识别码与 SIM 卡信息，用于免验证码登录；
- **自启动**：政策声明为接收推送存在自启动与关联启动，收不到提醒的处理见 [常见问题与解决方法.md](常见问题与解决方法.md) 第五节。

## 五、注销账号 = 删数据的唯一正门

- **入口**：我的 → 安全中心 → 账号注销，登录状态下确认即可；
- **效果**：政策写明收到注销请求后立即删除账户信息，且主动注销后所有信息将被完全删除；
- **注意**：注销不可恢复、无法反悔，且与「退出登录」「取消续费」是三件不同的事——只想停扣费别走这里，见 [自动续费怎么取消.md](自动续费怎么取消.md)；
- 服务条款另注明**不提供账号暂停**，想停用只有退出登录或注销两条路。

## 六、未成年人与 AI 内容标识

- 政策写明本软件**主要面向成年人**，未成年人使用须经监护人同意并通知官方；
- 涉及实名认证与青少年模式的过法，见 [常见问题与解决方法.md](常见问题与解决方法.md) 第四节；
- 政策要求对 AI 生成合成内容加标识，对话界面会持续显示「内容由AI生成，请注意甄别」——这是合规标识，不是你的账号出了问题。
