## 一、板块速览

| 板块 | 里面是什么 | 典型场景 |
| --- | --- | --- |
| 广播剧 | 小说、漫画改编的多集声音剧，按季更新 | 追更、睡前连听 |
| 听书 | 有声书、有声剧类的长篇内容 | 通勤、做家务时挂后台 |
| 有声漫画（Vomic） | 给漫画配上配音和音效的版本 | 想补剧情又不想看字 |
| 音乐 | 翻唱、角色歌、同人曲、OST | 找某部作品的相关曲 |
| 声音恋人 | 头像音、to 音、情书类互动向短音频 | 定向陪伴内容 |
| 播客 | 聊天、日常类谈话节目 | 当背景音 |
| 日抓 | 日语广播剧（Drama CD）相关内容 | 找日抓资源 |
| 铃声 | 短音频、铃声素材 | 挑手机铃声 |
| 助眠（ASMR 专区） | 雨声、耳语、睡前故事 | 睡前、失眠时 |
| 直播 | CV 与主播的语音直播，可连麦、送礼物 | 实时互动 |

板块入口在首页底部的分类里，也可以直接用搜索框搜作品名或 CV 名。铃声板块里的短音频可以设成手机铃声或闹铃（设置入口以界面为准）；直播间的具体玩法与贵族身份单独讲，见 [语音直播与贵族玩法.md](语音直播与贵族玩法.md)。

## 二、免费与付费的分界

- 免费内容（UP 主投稿、部分剧集）点开就能听，不登录也行。
- 付费广播剧是买断制：详情页会标「全季共 N 集、前 N 集免费试听、共 N 钻石」，试听之外的集数要用钻石买整季，购买后才能听。
- 直播间的送礼、提问等互动也用钻石结算，与主站剧集的钻石通用。
- 会员买付费剧集有折扣，具体差多少见 [会员与钻石怎么算.md](会员与钻石怎么算.md)。
- 想不花钱追剧：详情页标「本作品为免费广播剧」的整季都能听；付费剧只听「免费试听」的那几集；还有一类「限时免费」的剧，简介里会写免费收听的截止日期，看到了要趁早。

## 三、怎么找内容

1. **搜索**：顶部搜索框输入作品名、原著名或 CV 名，结果会同时覆盖剧集与单条音频。
2. **分类页**：进「广播剧」「听书」等分类后，内部还有题材细分（纯爱、悬疑、古风、治愈等）。
3. **排行榜**：广播剧有打赏周榜、月榜，适合看当前热度高的作品；各类目另有播放量排序。
4. **音单**：别人整理好的合集，适合找「同一部剧的全集串烧」这类聚合内容。

## 四、听的过程中能做什么

- 发弹幕、评论、收藏、点「喜欢」，这些操作需要先登录。
- 收藏过的内容、听过的历史记录，都从底部「我听」里进去看；缓存也在这同一个页签下管理。
- 对剧集加追更或订阅（入口与提示方式随版本变化，以界面为准），有更新时更方便找到。
- 想离线听，走缓存流程，见 [缓存与离线收听方法.md](缓存与离线收听方法.md)；想听着入睡，用定时关闭，见 [定时关闭与睡前收听.md](定时关闭与睡前收听.md)。
