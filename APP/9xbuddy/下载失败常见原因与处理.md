# 下载失败常见原因与处理

> 下载不动、列表为空、额度用尽、找不到文件——按报错信息对号入座的排查清单，三个恢复按钮的区别也在这篇。

## 一、先升级，再看报错

下载失败的第一个动作永远是**升级到最新版**：视频网站会改版，解析规则要跟着更新，官方也把「先更新」写在排障指南第一条。商店版随商店更新，APK 版要重新装新包。升级后还失败，再往下对号入座——失败的任务会留在 **Downloads** 页并附一句原因，那句话决定你该用下面哪个办法。

## 二、失败行上的三个按钮，别按错

每一行失败的任务带三个恢复动作，它们不是一回事：

| 动作 | 干什么 | 什么时候用 |
| --- | --- | --- |
| **Retry** | 接着传同一个任务 | 网络断过、被限流、服务器报错 |
| **Restart** | 重新解析源链接、拿新地址再传 | 提示链接过期或该格式没了 |
| **Browser** | 用内置浏览器打开源页面，借用页面建立的会话 | 有登录墙或人机验证 |

三个按钮都不行时，回到源头检查：把链接用普通浏览器打开，确认视频还在、能正常播放。私享、已删除、区域限制、带 DRM 保护或必须登录的内容，即使页面能打开也可能下不了——这是内容本身的限制，换工具也没用。

## 三、链接解析不出、或列表是空的

链接贴进去没反应、或显示解析成功但格式列表为空，按这个顺序试：

1. 确认媒体在普通浏览器里真的能播；
2. 换**规范的帖子或视频链接**：去掉分享短链、嵌入页和搜索页地址，去掉 `?utm_` 这类跟踪参数；
3. 在源页面让媒体先播放起来，再用内置浏览器里的下载控件；
4. 页面需要登录的，先在内置浏览器里登录一次，再走下载；
5. 批量列表里失败的，把链接单独拿出来试一次。

还有一种特殊情况：页面只是**嵌入**了别处的视频，自己不存文件——这时贴媒体真正所在那个页面的链接才有结果。

## 四、队列走到一半不动了

三种最常见的原因，先查免费额度，再查后台限制：

- **免费额度用完了**：免费账号一天 5 次，按「发起下载」计数。批量排队时前排正常、后排迟迟不启动，多半是这个。打开侧边栏底部的 **Account** 看当前额度，第二天自动恢复，详见 [免费版与Pro的区别.md](免费版与Pro的区别.md)；
- **后台被安卓掐了**：长时间大文件传输依赖后台运行。通用路径是「设置 - 应用 - 9xBuddy - 电池」里选**无限制 / 不优化**（Pixel、原生系机型叫 Unrestricted，有的机型叫「不受限」）。再按品牌查一层厂商设置：三星在「设备维护 - 电池 - 应用程序电源管理」里把应用移出休眠；华为在「设置 - 应用启动管理」里把它改为手动管理并允许后台运行；小米、OPPO、vivo 这类定制系统限制普遍更狠，除了电池优化还要单独开**自启动**权限；
- **批量任务后半段老失败**：不稳定的目标站点可以在「设置 - Extraction - Bulk」里调三样东西：Bulk Retries（整批重试次数）、Retry Delay（重试间隔毫秒数）、Hold at most（一次最多压进多少条）。批量清单里失败的行，保留成功的、只重试失败那几条就行，不用整批重来。

## 五、下载慢、或下到一半失败

- **慢**：先看有没有别的应用在抢带宽；到「设置 - Performance」里把 Parallel Downloads（并行下载数）调小反而可能更稳；如果设置过 Speed Limit（限速），限速状态下连接数再多也没用；开了代理的，除非视频网站必须，否则关掉再试；
- **下到一半失败**：检查手机剩余存储；进行中的文件先写在临时目录（「设置 - Downloads - Temporary storage」），临时目录所在的空间也要够；
- **提示磁盘或存储**：换一个保存位置再试，位置怎么改见 [下载的视频保存在哪里.md](下载的视频保存在哪里.md)。

高分辨率的视频体积可能远比列表里预想的大，下之前用 Get size 现查一次文件大小，心里有数。

## 六、其他几种「找不到/下不了」

- **下载完成但找不到文件**：完成的文件在 **Library**，不在 Downloads——Downloads 是队列，传完就清空了。在 Library 行上用 Show in folder 直接跳到文件所在位置；
- **完成的文件打不开或没法编辑**：文件多半在应用之外被移动或删除了。先用 Show in folder 确认它还在不在；原文件没了就在那一行上用 **Extract again** 从源头重新取一份，再进行剪辑或转码（Library 与文件本体的关系见 [下载的视频保存在哪里.md](下载的视频保存在哪里.md)）；
- **想要的那行画质没有**：列表只反映源页面提供的格式，源没有 4K 就不会有 4K；换媒体直接所在的页面再解析一次；
- **UID 校验失败**：重新粘贴一遍（UID 形如 `1234-5678-9012`，别带首尾空格）；确认设备联网；提示设备数上限说明 UID 有效但已绑满，去 **Account - Manage license** 看绑了哪些设备；提示与时间相关时校对手机时钟——本地时间与服务器偏差太大，签名请求会被拒。逐项展开的版本见 [UID丢了怎么找回.md](UID丢了怎么找回.md)。

以上都解决不了，再找官方支持（应用内 support 或邮箱 hello@123sudo.com），附上系统版本、应用版本、出问题的视频页面地址和报错原文；**不要**把 UID、Cookie、自定义请求头发过去，官方文档明确说这些不需要。
