## 一、先记住一句：完成的文件在 Library，不在 Downloads

9xBuddy 里有三个容易混的页面，分工是死的：

| 页面 | 装的是什么 | 清掉它会怎样 |
| --- | --- | --- |
| **Downloads** | 传输任务：进行中的在 Queue，传完的进 Completed | 只删任务记录，**不动文件** |
| **Library** | 已完成的文件本体（带缩略图，可播放） | 移除条目也不删文件，点 **Move file to Trash** 才真删 |
| **History** | 你解析过的每个页面和链接 | 只删解析记录 |

找文件最快的路径：**Downloads - Completed**，在对应行上点 **Folder** 动作，直接跳到文件落在手机里的位置；或者进 Library，在卡片菜单里用 **Show in folder**。下载历史只记录在本机，官方口径是不上传、不追踪。

## 二、文件写到哪个目录

默认是系统的**下载（Downloads）目录**，下完的文件在系统文件管理器和媒体播放器里直接能看到。想换地方：

1. 打开「设置」；
2. 进 **Files & Folders**（或 Downloads 分组下的 Location）；
3. 选一个新的保存目录。

注意两件事：改位置只影响**以后**的下载，之前下的文件不会搬家；进行中的传输还有一份临时文件写在**临时存储**目录（「设置 - Downloads - Temporary storage」），传完才改成正式文件名落到保存目录——排查「空间不够」时这两个目录都要算进去。

## 三、Library：找到之后能干什么

Library 按时间倒序列出你下过的所有文件：

- 点卡片直接**播放**；
- 用菜单**分享**给其他应用（发微信、投到电视上都走这里）；
- 按名字**搜索**；
- **合集（collections）与收藏（favourites）**：把下好的内容归类，这组整理功能免费账号就能用；
- 想删文件时认准 **Move file to Trash**——只把 Library 里的条目划掉，文件本体还在原地。反过来也一样：条目还在、文件却打不开，多半是文件在应用之外被移动或删除了，补救办法见 [下载失败常见原因与处理.md](下载失败常见原因与处理.md)里「完成的文件打不开」那条；

Pro 账号在这里还能对已完成的文件**剪辑片段**、**转 MP3**，处理的是已下载的本体文件，原文件不动。

## 四、换设备不会有「云盘」

UID 是授权凭证，不云同步内容：换手机、换电脑登录同一个 UID，**文件和历史都跟不过去**，新设备从零开始下。所以换机前要带走下载的东西，只能用文件管理器或分享功能自己搬。免费版与 Pro 在设备数上的差别（1 台与 3 台）见 [免费版与Pro的区别.md](免费版与Pro的区别.md)。

下载完的文件打不开、或想重新下一份的情况，处理方法写在 [下载失败常见原因与处理.md](下载失败常见原因与处理.md)；日常怎么把链接发进来，见 [用分享菜单下载视频的步骤.md](用分享菜单下载视频的步骤.md)。
