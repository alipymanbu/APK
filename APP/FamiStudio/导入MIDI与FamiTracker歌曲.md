## 一、先分清：手机上能导什么、电脑上能导什么

导入的操作方式是「打开一个文件」，但各格式的支持平台不一样，官方文档里写得明确：

| 格式 | 平台 | 你要知道的 |
| --- | --- | --- |
| `.fms`（FamiStudio 工程） | 手机 / 桌面都行 | 通用工程文件，手机上收到的 .fms 直接打开 |
| FamiTracker（FTM / TXT，仅官方 0.4.6） | 未限定平台，入口以你界面上实际显示为准 | 只认官方 0.4.6 存的格式，魔改版 FamiTracker 的文件大概率打不开 |
| MIDI（.mid） | 桌面版专属 | 手机上没有这个入口 |
| NSF / NSFe | 桌面版专属 | 手机上没有这个入口 |
| VGM / VGZ | 入口以你界面上实际显示为准 | 偏冷门的芯片音乐格式，新版桌面支持把它当音源导入 |

所以手机上的现实路径是：外部格式先在电脑版导成 `.fms`，再用[导出格式与分享方法.md](导出格式与分享方法.md)里的 Share 传回手机。手头只有手机的话，除了 `.fms` 之外的外部格式基本无解。

## 二、FamiTracker 文件导进来会「变样」

FamiTracker 和 FamiStudio 处理音乐的方式差异不小，导入是一个**有损**过程，官方文档明说了这几点：

- **效果码只认一小部分**：琶音（0xy）、滑音（1xx / 2xx / 3xx / Qxx / Rxx）、颤音（4xy）、音量滑动（Axx）、跳转（Bxx）、停止（Cxx）、速度（Fxx）等常用码能转，其余一律忽略。VRC7 上的滑音类效果转过来基本不对味，要手动修。
- **滑音全部转成「滑动音符」**，转换机制天生不完美，官方直接标注这是有损过程。
- **同时挂音高包络和琶音包络的乐器**，导进来声音会不一样（两边对包络的处理逻辑不同）。
- 导入完成后，工程会处于 **FamiTracker 节奏模式**，见下一节。

## 三、两种节奏模式：FamiStudio 与 FamiTracker

新建的工程默认是 **FamiStudio 模式**：逐帧控制（NTSC 每帧 1/60 秒），每个音符起止位置看得见、拖得动；想精确到帧就选它，代价是变速只能在 pattern 开头改。

**FamiTracker 模式**是导入 FamiTracker 文件后自动进入的模式：用 speed / tempo 两级参数控制速度，帧级精度要靠「延迟切音」这类效果码实现，好处是兼容 FamiTracker、支持歌中途平滑变速。

| 你的需求 | 选哪种 |
| --- | --- |
| 手机上写歌、想要直观的帧级控制 | FamiStudio 模式（默认） |
| 要和 FamiTracker 互相倒文件 | FamiTracker 模式 |
| 歌中途要平滑变速（pattern 中间变速度） | FamiTracker 模式 |

已有歌曲的模式切换虽然可行，但官方明说转换很粗糙，别指望无损互换。

## 四、MIDI 导入：只搬音符，别指望音色

MIDI 导入（桌面版）搬过来的只有音符、拍号和速度变化，乐器全是按 GM 乐器名起的**空乐器**，官方原话就是「别指望导进来的歌听起来和原来像」。还有一条硬限制：NES 每个通道同时只能发一个音，MIDI 里的复调会被折掉——导入前先用别的软件把每个轨道拆成单旋律。

导入对话框里最有用的是底部的**通道映射表**：每个 NES 通道可以指定吃 MIDI 的哪个通道或哪条轨道，MIDI 通道 10 按惯例是鼓，映射到 Noise 通道。策略参考：钢琴 / 吉他类放 Pulse，贝斯和铺底放 Triangle。

## 五、NSF 导入：一团乱麻，但适合逆向学习

NSF 本质是给真机跑的程序，不含乐器、不含包络、没有循环的 pattern，导进来后所有音量音高变化都堆在效果轨里，**看起来极其混乱**——这是格式本性，不是导入坏了。官方演示歌里的大多数，就是从游戏 NSF 逆向导入做出来的。

导入对话框里常用的几个选项：

- **Duration**：抽取多少秒。
- **Pattern Length**：一个 pattern 装多少帧。
- **Remove intro silence**：去掉开头静音段，等出声了才开始录。
- **Tuning**：歌用了非标准音高调律时校正用。

## 六、把另一首歌并进当前工程

同一个工程里可以合并别的工程的歌：在工程区歌名那一行点文件夹图标。两个前提：两边工程用了**相同的扩展音源**和**相同的节奏模式**；乐器、样本、琶音是**按名字匹配**的——两个工程里都叫「Piano」的乐器会被当成同一个，重名前先想清楚。

## 七、手机上看不到报错详情

导入 / 导出出错时会产生一份错误日志（哪些效果被忽略、哪里转换失败都在里面），但**手机版不显示这份日志**。导出来的歌行为诡异、声音不对，又看不出原因时，把 `.fms` 传到电脑用桌面版做同样操作，日志里会写明白。安装与渠道问题去[下载与安装教程.md](下载与安装教程.md)，其他常见故障在[常见问题与排查.md](常见问题与排查.md)。
