## 一、先确认你要装的是哪个版本

FamiStudio 是一个面向 NES / Famicom（红白机）芯片音乐的编辑器，作者 BleuBleu，源码公开在 [GitHub](https://github.com/BleuBleu/FamiStudio) 上，安卓版免费。它同时有桌面版（Windows / macOS / Linux），两边共用同一种工程文件（`.fms`），本套文档只讲安卓版。

官方更新比较勤，官网首页挂的版本号通常比你手里的安装包新。你这份安装包的信息如下，装完后核对、写说明、排查问题时都以这份为准：

| 项目 | 值 |
| --- | --- |
| 版本 | 4.2.2 |
| 包名 | org.famistudio |
| 安装包大小 | 40.12 MB |
| MD5 | 83AEFCD10FCBD06691D04C5BDF594F2F |
| 信息核对日期 | 2026-09-27 |

安卓版对图形接口的要求是支持 OpenGL ES 2.0（官方更新日志口径）；具体最低 Android 系统版本以[官方安装文档](https://famistudio.org/doc/install/)当时显示为准。4.2.2 与最新版在细节界面上会有差异，遇到对不上的按钮时以你手机上实际显示为准。

## 二、两种安装途径

| 途径 | 适合谁 | 说明 |
| --- | --- | --- |
| Google Play | 能正常访问 Play 商店的设备 | 搜 FamiStudio 直接装，免费，随商店自动更新 |
| APK 安装包 | 没有 Play 商店、或想固定在某个版本 | 用下面的网盘资源，或从 GitHub Releases 下载 |

想留在 4.2.2 这个版本、不想被自动升级的，走 APK 途径即可。获取 [FamiStudio 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ceffd74b9b12)后转存到自己的网盘，把 APK 下载到手机就能装；GitHub Releases 页面（仓库 [BleuBleu/FamiStudio](https://github.com/BleuBleu/FamiStudio)）也有官方 APK，文件名形如 `org.famistudio.apk`，两个来源拿到的都是官方包。

## 三、APK 安装步骤

1. 把 APK 文件下载到手机存储（或通过微信 / 数据线等方式传过去）。
2. 在文件管理器里点开这个 APK。系统会提示「不允许安装未知来源应用」，按提示允许该来源安装即可（不同品牌手机入口不同，一般在弹窗里点「设置 → 允许」就能解决）。
3. 安装完成，桌面出现 FamiStudio 图标，点开。
4. 想核对包完整性，可以把安装包的 MD5 与上面表格里的值比对，一致说明文件没损坏。

**如果点开 APK 提示无法安装或「存在冲突的应用」**：常见原因是手机上已经装了同包名（org.famistudio）但来自另一个渠道的 FamiStudio（比如 Play 版），Android 不允许不同签名的包互相覆盖。处理办法是先备份工程（见下一节），再卸载旧的那个，然后装新包。

## 四、第一次打开前：先把工程备份的习惯建立起来

安卓版把工程文件存在应用自己的内部目录里，手机上其他应用（包括文件管理器）访问不到。这意味着卸载应用 = 工程一起没了。所以第一次正式做歌之前，建议先知道怎么把工程导出来：用导出对话框里的 **Share**（分享）功能，可以把 `.fms` 工程文件存到手机存储或直接发给别的应用。具体操作在[导出格式与分享方法.md](导出格式与分享方法.md)里写清楚了，换机、重装、清理手机前都先做这一步。

## 五、装完之后从哪开始

打开应用后你会看到一个工程列表，官方自带几首演示歌，可以点开播放听听这是不是你想要的声音。接下来做自己的第一首歌，直接看[界面与做歌流程入门.md](界面与做歌流程入门.md)；装好之后遇到闪退、没声音之类的问题，去[常见问题与排查.md](常见问题与排查.md)对号入座。
