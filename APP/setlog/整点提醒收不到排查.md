# setlog 整点提醒收不到排查

> 本篇专治「别人的整点提醒都响、就我的不响」：从应用内开关到 iPhone / Android 的系统设置，按顺序逐层排查。

setlog 的提醒要穿过四道闸门才会响：应用内开关 → 系统通知权限 → 专注 / 勿扰模式 → 后台限制，任何一道关着都收不到。先别急着重装（那会把设置全部重置），按下面的顺序查，多数两分钟内能定位。

## 一、先做一个判断

**朋友收得到、只有你收不到**：基本可以排除服务器故障，问题在你手机上，按下面二、三、四节排查。
**所有人都收不到**：可能是服务端问题，等官方修复即可，不用折腾手机。

## 二、先查应用内：两段开关都要开

setlog 自己有两层通知设置，只开一层不响：

1. **通知允许**：应用设置里总的通知开关，确认是开着的；
2. **日志通知频率**：设置里的「日志通知」（Log 通知）项，确认选的是**每小时一次**。有个常见的坑：界面上看起来是开的，内部状态却卡在旧值——把它**先关掉、彻底退出应用再打开、重新选回每小时**，不少人做完这一步就恢复了。

改完别急着下结论，提醒要等下一个整点才来，观察十几分钟再看下一段。

## 三、iPhone 的四个检查点

| 检查点 | 路径 | 要确认成什么样 |
| --- | --- | --- |
| 即时配送 | 设置 → 通知 → setlog | 选**即时配送**；若在「预约的摘要」里，提醒会被攒到固定时间集中展示，整点就不响 |
| 专注模式 | 设置 → 专注模式 | 把 setlog 加进当前模式的**允许通知的应用**（工作、睡眠等每个在用的模式都要加） |
| 后台刷新 | 设置 → 通用 → 后台 App 刷新 | 总开关与 setlog 都是开 |
| 时间同步 | 设置 → 通用 → 日期与时间 | 设为**自动**，时间有偏差提醒会乱 |

另外，低电量模式会限制通知，充电时可以关掉它验证一次。

## 四、Android 的三个检查点

1. **通知权限**：设置 → 应用 → setlog → 通知，确认允许（有的机型叫「应用和通知」）；
2. **电池后台**：把 setlog 的电池策略设为**不受限制 / 无限制**，省电模式开着的先关掉验证——国产系统的激进省电是「提醒时有时无」的头号原因；
3. **勿扰模式**：确认没有把 setlog 挡在外面。

改完这些仍不响，就把应用从最近任务里划掉重开一次。

## 五、最后的手段：重启后重装

上面全部做过还是不行：

1. 先按 [成片导出与保存方法.md](成片导出与保存方法.md) 把还想留的成片导出；
2. 卸载应用，**重启手机**（这一步别省），再重装；
3. 装好登录后，第一时间把第二节的两个开关重新设一遍。

重装后依然只有自己收不到，就只剩服务端账号层面的问题了，只能等官方修复；期间可以用应用内相机手动拍，不影响记录本身。
