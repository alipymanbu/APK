# setlog 成片导出与保存方法

> 本篇讲怎么把 setlog 一天的 Vlog 导出成视频文件存进手机相册，导出设置各选项是什么，保存失败时先动哪个开关。

## 一、先分清你要保存的是什么

| 你想存的东西 | 有没有入口 |
| --- | --- |
| 某一天的完整 Vlog（当天所有片段自动拼好的成片） | 有，走本篇的流程 |
| 过去某一天的 Vlog | 有，打开对应 Log 翻到那个日期，流程相同 |
| 单条 2 秒片段 | 没有普遍确认的单独导出入口；个别版本的单条预览页若有保存 / 共享按钮可以直接用，没有就别找隐藏功能 |
| 所有天数一键批量导出 | 没有公开确认的批量导出，只能一天一天来 |

## 二、导出四步

以保存某天的完整 Vlog 为例（iPhone 与 Android 操作一致）：

1. 打开对应的 Log，进入**当天成片**的画面（能从头连播一整天的那种，别停在相机页）；
2. 点画面**右上角的共享图标**（方框加向上箭头那个，它启动的是导出，不是再拍一条）；
3. 等应用逐页渲染——界面会显示类似「第 1 页 / 共 9 页渲染中」的进度，当天拍的条数越多等得越久；**渲染期间让应用留在前台**，切走或锁屏可能打断生成；
4. 渲染完底部出现「关闭 / 编辑 / 保存 / 共享」菜单，点**保存**；首次保存系统会弹「请求添加到照片」之类的授权，允许后文件就进了手机相册。

保存完别急着删东西，先去相册（Android 上可能在相册或 Google 相册的单独文件夹里）把视频完整放一遍再收工。

## 三、导出设置里四个选项的含义

在第 4 步之前点「编辑」可以改导出参数：

| 选项 | 默认值 | 什么时候动它 |
| --- | --- | --- |
| 画质 | 标准 | 保存失败时先把它调低，成功率高很多（大量用户的实测反馈） |
| 宽高比 | 9:16 | 想发横屏平台时改 |
| 背景 | 黑色 | 介意上下黑边时换颜色 |
| 未拍摄时段的占位 | 一个睡觉表情的图标样式 | 不想让空白时段出现在成片里时改 |

选项名称与位置以你手上的版本实际界面为准。

## 四、保存失败怎么办

按命中率从高到低试：

1. **把画质调低再导**——「无法渲染此导出」「黑屏不动」多数是这一招解决的；
2. 确认 setlog 有**照片 / 存储权限**（系统设置 → 应用 → setlog → 权限），手机剩余空间够不够；
3. 应用升级到最新版，重启手机后**隔一会儿再试一次**；
4. 「保存」一直不行就改点旁边的「共享」，从分享面板里选「存储到文件」或直接发给自己的聊天工具再存。

顺序错乱、个别片段没进成片这类导出异常，同样先更新应用再重新导一次，多数会自愈。

## 五、导出之后

「共享」菜单可以直接把成片送进 Instagram、TikTok 等应用，不用先落相册。成片、片段在应用内时间线的留存与删除逻辑，见 [注意事项与隐私设置.md](注意事项与隐私设置.md)；「什么时候能导出当天成片」取决于凌晨 4 点的自动合成，见 [群组共创拍摄玩法.md](群组共创拍摄玩法.md)。
