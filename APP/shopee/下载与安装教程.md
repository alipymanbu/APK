## 三、安装前核对安装包

如果你是在电脑上下载、再传到手机安装的，建议先核对一下文件完整性，尤其是传输过程可能中断的情况。在 Windows 上用命令行校验 MD5：

```powershell
certutil -hashfile "shopee_v3.74.31.apk" MD5
```

输出与本文表格里的 MD5 一致，说明文件是完整的。对不上就重新下载一份。

**Shopee 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/a3ecaad0c859](https://pan.quark.cn/s/a3ecaad0c859)，转存后下载对应的 apk 文件即可。

## 四、安装步骤

1. 把 apk 文件传到手机存储（或直接在手机上下载）；
2. 在手机文件管理器里点开这个 apk；
3. 系统会提示「不允许安装未知来源应用」，按提示跳转到设置页，允许**浏览器或文件管理器**安装应用（不同品牌叫法略有差异，见下表）；
4. 返回安装页点「安装」，等待完成；
5. 装完点「打开」，首次启动会引导你登录或注册，操作见 [注册与登录教程.md](注册与登录教程.md)。

常见品牌允许安装未知应用的入口：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装未知应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 应用安装 |
| 三星 | 设置 → 生物识别和安全性 → 安装未知应用程序 |

## 五、系统要求与装不上的常见原因

官方帮助中心对现行版本的口径：**Android 6.0 以下的设备无法安装或使用**（不同版本要求可能不同，以官方页面显示为准）。如果你安装的是本资源对应版本（3.74.31），对系统要求更低一些。

安装失败时按这个顺序排查：

1. **存储空间不足**——安装包 67M，加上安装过程的空间占用，手机剩余空间最好留出 1G 以上；
2. **安装包不完整**——回到第三节核对 MD5；
3. **系统版本过旧**——低于 Android 6.0 基本装不上现行版本，可以改用浏览器访问 [shopee.com.my](https://shopee.com.my) 网页版；
4. **与已装版本冲突**——手机里已经装过别的 Shopee 站点版本（比如 com.shopee.sg）不影响，两者包名不同可以共存；但若装过同包名的旧版本且签名不一致，需要先卸载旧的再装。

装好之后从哪一步继续，见 [注册与登录教程.md](注册与登录教程.md)。
