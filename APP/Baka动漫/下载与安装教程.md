## 一、Baka动漫 是什么

Baka动漫（官方英文名 Baka / AniBaka，中文渠道也叫「巴卡动漫」）是一款安卓端的番剧播放应用：你搜一部番，它会去多个番剧源里找播放地址并播放，支持弹幕、倍速、字幕、投屏和离线缓存。它的源码在 GitHub 公开（GPL-3.0 许可），官方主页是 [app.anibaka.com](https://app.anibaka.com/)，开发者文档在 [docs.anibaka.com](https://docs.anibaka.com/)，代码仓库在 [github.com/AniBakaBaka/AniBaka](https://github.com/AniBakaBaka/AniBaka)。

适合你，如果你：手上有一份安装包想装起来用、想知道装哪个版本对、或者装完打不开想找原因。

## 二、装哪个版本

网盘里这份安装包的固定信息如下（以这份为准，不要拿网上搜到的版本号对照）：

| 项目 | 值 |
| --- | --- |
| 版本 | 4.5.2 |
| 包名 | `ani.baka` |
| 大小 | 33.83M |
| MD5 | `11a2429041de633da27f1487e2712498` |

官方下载走 GitHub 的 Releases 页面（[github.com/AniBakaBaka/AniBaka/releases](https://github.com/AniBakaBaka/AniBaka/releases)），那里的版本号通常比 4.5.2 新，具体以页面当时显示为准。两个版本怎么选：

- 想要稳定、和本篇描述的操作流程一致 → 用网盘里这份 4.5.2；
- 想要新功能（官方后续版本新增了更多源与播放器改进）→ 去 Releases 拿最新版，但界面和选项可能和本篇说的有出入。

系统要求方面，各渠道页面标注不一（有的标注「安卓 5.2 以上」，更新的版本要求更高），以官方 Release 说明当时写的为准。判断自己手机能不能装，最直接的办法是直接点安装包——系统会告诉你能不能装，不用先去查参数。

## 三、安装步骤

1. 打开 [Baka动漫 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d1e9bbdd67e3)，把安装包转存到自己的网盘或直接下载到手机；
2. 下载完成后在文件管理器里点这个 `.apk` 文件；
3. 系统弹出「是否允许安装未知应用」时，给浏览器或文件管理器授一次权，返回继续安装；
4. 装完打开。首次启动会申请存储等权限——想用离线缓存就允许，只在线看可以先拒绝。

如果你从网上别的渠道下载了安装包，可以先用 MD5 核对再装：文件名改成 `.zip` 解出里面的 apk，或用任意 MD5 校验工具比对上面表格里的值，一致才是同一份包。

## 四、首次打开先做三件事

1. **确认主要页面都能打开**：首页、更新时间表、搜索、「我的」这几个页面来回切都正常，说明安装没坏；
2. **随便搜一部番点开**：详情页会自动搜索播放源，能看到播放列表就说明源是通的（源不出内容怎么处理见 [播放源设置与切换.md](播放源设置与切换.md)）；
3. **进「我的」页看一眼登录入口**：看番不用登录，但离线下载、历史记录跨设备同步需要登录后才能用（详见 [怎么下载动漫到本地.md](怎么下载动漫到本地.md)）。

装好了但打不开、闪退、或者番剧加载不出来，按 [常见问题与排查.md](常见问题与排查.md) 逐条试。
