## 一、装不上 / 装上闪退

| 症状 | 先查什么 |
| --- | --- |
| 点安装包没反应、提示解析错误 | 安装包没下完整——重新下；或系统版本低于应用要求（各渠道标注不一，以官方 Release 说明为准） |
| 提示禁止安装未知应用 | 去系统设置给文件管理器/浏览器授一次「安装未知应用」权限 |
| 打开就闪退 | 清缓存：设置 → 应用 → Baka动漫 → 存储 → 清除缓存（先别清数据）；再不行重启手机 |
| 装新版报签名冲突 | 先卸载旧版再装（自定义源、设置会丢，卸载前截图记好，见 [播放源设置与切换.md](播放源设置与切换.md) 第五节） |

## 二、搜不到番 / 没有播放源

九成是源的问题，按顺序做：

1. 详情页**换一个源**再看（[播放源设置与切换.md](播放源设置与切换.md)）；
2. 去「我的 → 设置 → 内置源管理」**刷新/更新规则**，社区规则没拉到最新时会整片搜不到；
3. 换个关键词——有的源里番名是罗马音或译名，搜中文名对不上很正常；
4. 都搜不到这部番，说明各源确实没收录，不是你的应用坏了。

## 三、能搜到但播不了 / 一直加载

1. **先播另一部番**：别的能播 → 只是这部在当前源上挂了，换源；全都不能播 → 往下走；
2. **换网络试**：Wi-Fi 切移动数据。视频域名被当前网络干扰时，换网是最快的判别法；
3. **清缓存重启**：设置里清缓存（别清数据），强杀应用重开；
4. **看源状态**：单源服务器故障等会儿自己好；持续几天不行，等规则更新或到官方仓库提 issue（附规则名、搜索词、失败阶段——这条是官方仓库贡献说明里写明的反馈格式）。

## 四、登录与历史同步

- 离线下载、跨设备历史同步、评论要登录；纯看番不用（[怎么下载动漫到本地.md](怎么下载动漫到本地.md)）；
- 登录入口路径（有渠道教程给出的步骤）：**「我的」页 → 点圆形头像框 → 注册登录**；注册支持的方式以应用内实际提供的为准（有渠道页面称可用手机号或邮箱，仅供参照）；
- 登录后换设备，登录同一账号即可接上历史——历史跟着账号走；
- 同步不生效时：确认网络通、退出重登一次，再不行等服务恢复（社区服务器由官方维护，可到 [GitHub 仓库](https://github.com/AniBakaBaka/AniBaka) 看公告与 issue）。

## 五、版本差异：4.5.2 和最新版

网盘里是 **4.5.2**（包名 `ani.baka`、33.83M），官方 Releases 上的版本更新，界面可能不同。4.5.2 当次更新内容（第三方渠道页面列出）：删除 aowu 源、新增 mgnacg 源；优化播放器加载与集数切换；重构分类；适配系统媒体组件；支持 WebDAV；支持 TV 端并重做 TV 版页面；重新设计源管理页、支持关内置源；新增 BGM 聚合搜索。

按本篇与配套几篇操作时对不上界面，先确认自己装的是哪个版本：设置里的「关于/版本号」，或对照 [下载与安装教程.md](下载与安装教程.md) 第二节的表格。

## 六、网络请求与隐私（官方仓库写明的口径）

- 应用每次启动会向 `https://dau.anibaka.com/track` 上报一个**匿名安装标识**（格式 `install_<平台>_随机数`，首启本地生成）；官方说明称不含账号 Token、用户名和设备硬件标识；
- 社区 API 默认 `www.anibaka.com`，可在应用的服务器设置里换成别的；Bangumi 元数据走 `bgm.anibaka.com`；
- 规则文件默认从 GitHub 加速节点拉取，失败依次回退 jsDelivr、GitHub。

介意启动统计的话，知道它存在、并且这些都写在开源仓库里可以自己核（[github.com/AniBakaBaka/AniBaka](https://github.com/AniBakaBaka/AniBaka)，GPL-3.0）。
