## 一、播放源是什么

Baka动漫 本身不存视频：你搜到的每一部番，都是靠「源」去对应站点取播放地址再播出来。源失效、被改版、或者某部番在那个源里没有，都会表现为「搜不到」「播放失败」。所以遇到内容问题，第一反应应该是**看源、换源**，而不是重装应用。

源分三类：

| 类型 | 来源 | 说明 |
| --- | --- | --- |
| 内置源 | 随安装包打包 | 装好即有，可在源管理里启用/关闭 |
| 社区规则源 | 规则中心拉取 | 由开源社区维护（规则仓库 [AniBakaRule](https://github.com/AniBakaBaka/AniBakaRule)），应用内可更新 |
| 自定义源 | 你自己填 | 手动填源名称与基础域名 |

## 二、平时怎么换源

1. 点开一部番进入详情页，应用会**自动搜索各源**并列出可用播放集数；
2. 播放页里点集数列表旁的源切换入口，会在几个可用源之间切；
3. 某个源卡、加载慢或干脆没集数，就切下一个——同一个源在这部番上挂了，不代表它在别的番上也挂。

判断标准很简单：**能列出集数、点了能播的源就是活源**。一个源全部番都出不来，再考虑去源管理里处理它。

## 三、内置源管理（开关与新建源）

4.5.2 版本重新设计了源管理页，路径是：**「我的」页 → 右上角齿轮（设置）→ 内置源管理**。在源管理页里你可以：

- 看到当前所有内置源的列表，把不再想用的源**关闭**（4.5.2 起支持关内置源）；
- **新建源**：点页面右下角的「新建源」，依次填：

| 字段 | 填什么 |
| --- | --- |
| 源名称 | 起个你能认出的名字 |
| 基础域名 | 该源站点的根地址 |
| 描述 | 备注，可留空 |
| 是否启用 | 打开开关 |

填完点保存，新源就会出现在搜索与播放的候选里（前提是它确实活着）。

## 四、社区规则源怎么更新

内置规则跟包走，社区规则走「规则中心」：应用启动后会去拉最新规则文件（默认走 GitHub 加速节点，失败会依次回退到 jsDelivr 和 GitHub 官方地址——这条链路写在官方仓库的说明里）。你不需要手动配置；**搜不到新番时，先想到去规则中心/源管理里刷新一次规则**，很多「突然全挂了」的问题就是规则没更新。

## 五、源相关的一条边界

源挂不挂不受你控制——第三方站点随时可能改版，这是这类应用的常态。单个源失效不影响整体使用；如果所有源都出不来，问题多半在网络或版本本身，转到 [常见问题与排查.md](常见问题与排查.md) 按顺序查。装新版本或换设备前，想保留自己填过的自定义源信息，先在源管理页截图记下基础域名。
