## 一、本地阅读能做什么

Cimoc 的功能列表里有一项「本地漫画（Local Reader）」：不看图源、不联网，直接读你手机里已有的漫画文件。两个典型场景：

1. **读自己攒的漫画文件**：之前下载、购买或整理的漫画压缩包与图片文件夹，不用再单独装一个本地阅读器；
2. **管理应用内下载的章节**：通过图源下载到本地的漫画，也归「本地」入口统一管理。

## 二、导入本地漫画的步骤

1. 先把漫画文件放到手机存储里（网盘下载、数据线拷贝均可）；
2. 打开 Cimoc，进入**「本地」**页面（入口在侧边栏的主界面栏目里，个别版本位置略有不同）；
3. 点**右下角的「+」**，进入文件选择页面；
4. 如果没看到你的文件，点文件选择器左上角的菜单切换存储位置；
5. 选中漫画文件或文件夹，导入完成后回「本地」列表点开即可阅读。

导入时需要应用有**文件访问权限**——如果弹授权就允许；权限没给足时文件选择器会一片空白（处理办法见 [下载与安装教程.md](下载与安装教程.md) 的安装步骤一节）。

## 三、支持哪些格式

多个来源互相印证的口径如下（具体以你手上的版本实际支持为准）：

| 格式 | 说明 |
| --- | --- |
| ZIP / CBZ | 最常见的漫画压缩包；CBZ 本质就是改了扩展名的 ZIP |
| RAR / CBR | RAR 系压缩包，CBR 是漫画常用的 RAR 变体 |
| PDF | 可直接打开阅读 |
| 图片文件夹 | 整个文件夹按页码顺序当一章读，不用打包 |

实践建议：优先用 ZIP/CBZ 打包图片再导入，比零散图片文件夹更不容易出顺序问题。

## 四、下载的漫画存放在哪

- 旧版本的下载目录是 `/storage/emulated/0/Cimoc`；
- 安卓 11 之后因为系统收紧了存储权限，应用改用了新的存储路径；
- 想固定或找回下载位置，去 **设置 → 存储路径（自定义存储路径）** 里查看与修改，以你设备上的实际显示为准。

用文件管理器直接翻这些目录时要留意：安卓 11+ 的应用私有目录在文件管理器里可能看不到，这是系统行为，不是文件丢了。

## 五、安卓 11：下载后看不了的已知情况与处理

安卓 11 机型上，社区反馈存在「下载完成的漫画打不开」的情况。两类无害的解决办法，按顺序试：

1. 从**收藏界面**打开那部漫画，再进「已下载」的章节观看（这条路径通常能正常进入）；
2. 任意**重新下载其中一个章节**，之后全部已下载章节一般都能观看了。

如果还不行，回到 [搜索不到漫画的原因与解决.md](搜索不到漫画的原因与解决.md) 的下载失败一节排查权限与空间；本地整理好的收藏与进度，用 [备份与恢复教程.md](备份与恢复教程.md) 里的方法先存一份再折腾。
