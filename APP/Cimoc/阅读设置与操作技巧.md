## 一、阅读模式有哪几种

Cimoc 支持两大类阅读模式，1.6.37 起细分出三种、可在阅读界面快捷切换：

| 模式 | 适合的漫画类型 |
| --- | --- |
| 翻页模式（Page Reader） | 日漫等单页横图，一页一页翻 |
| 卷纸模式 / 卷轴模式（Scroll Reader） | 条漫、长图，上下连续滑动 |
| 日漫模式 | 按日漫排版习惯翻页 |

切换方式有两处：

1. **阅读界面内快捷切换**（推荐）：阅读时呼出菜单直接换；
2. **设置里自定义长按点击事件**为「切换阅读模式」，读图时长按屏幕即可换模式，不用退出菜单。

另有一个**自动翻页**功能，适合解放双手的横屏阅读。

## 二、点击区域与翻页行为

设置里可以定义点击事件：默认口径是**左上角点击 = 上一页、右下角点击 = 下一页**。其他常用开关：

- **启用快速翻页（减少）**：翻页动画更干脆，适合追求速度的用户；
- **禁止双击放大**：读条漫时误触双击会放大图片，关掉它省心；
- **自动裁剪白边**（官方设置项写作「自动裁剪百边」）：把扫描版漫画四周的空白裁掉，屏幕利用率更高；
- **启用通知栏**：下载或在后台时在通知栏显示状态。

阅读界面里还有**亮度调节**（1.6.37 加入）和**快捷章节切换**，追长篇时不用退回详情页选章节。

## 三、界面入口速查

主界面从左上角三横菜单拉出侧边栏，常见入口：

| 入口 | 用途 |
| --- | --- |
| 历史 / 收藏 | 继续上次阅读、管理追漫列表 |
| 下载 / 本地 | 管理已缓存章节、读本地漫画文件（用法见 [本地漫画导入与格式支持.md](本地漫画导入与格式支持.md)） |
| 分类 | 按图源的分类浏览找书 |
| 图源 | 管理漫画源（见 [图源添加与导入方法.md](图源添加与导入方法.md)） |
| 备份 | 本地备份与 WebDAV 云备份（见 [备份与恢复教程.md](备份与恢复教程.md)） |
| 夜间模式 | 深色界面，晚上看漫刺眼感更轻 |

## 四、电子墨水屏（文石 BOOX 等）推荐配置

官方 README 给了一组针对 eink 设备（以 BOOX 为例）的优化参数，在设备端设置里照抄即可：

| 配置项 | 推荐值 |
| --- | --- |
| DPI | 424 |
| 字体加粗 | 开 |
| A2 刷新 | 打开 |
| 动画过滤 | 200 |
| 全刷触发 | 20 |
| 全屏 | 关闭 |

这组参数的目标是减少墨水屏残影与闪烁频率；普通手机屏幕不需要照搬。调好这些设置后，建议顺手做一次备份，换机或重装时能直接恢复（见 [备份与恢复教程.md](备份与恢复教程.md)）。
