> 本篇按出现频率排序列出 Cimoc 搜索不到漫画（或漫画加载失败）的常见原因，给出对应的排查顺序。

## 一、先按这个顺序排查

| 顺序 | 检查什么 | 怎么处理 |
| --- | --- | --- |
| 1 | **导没导图源** | 刚装完就搜索 = 必然搜不到。先进「图源」页确认里面有启用的图源，没有就按 [图源添加与导入方法.md](图源添加与导入方法.md) 导入 |
| 2 | **图源还活着吗** | 图源接口会随时间失效（站点改版、下线都会导致）。换一个启用的源再搜同一个关键词试试 |
| 3 | **该漫画在不在源里** | 换关键词（用作品常见译名）再搜；个别漫画也会因为版权原因在某些站点不存在或仅限特定地区访问 |
| 4 | **网络通不通** | 切一下 Wi-Fi / 流量再试；某些源站对网络环境有要求 |
| 5 | **缓存与进程** | 重启应用；仍不行就在系统设置里清除 Cimoc 缓存后重开 |
| 6 | **版本太旧** | 图源解析逻辑随版本更新，老版本对改版后的站点会失效，升级到新版再试 |

## 二、加载失败与下载失败

**在线阅读加载失败**：最有效的动作是**切换图源**——同一部漫画常被多个源收录，阅读界面里就能换线；其次检查网络、清缓存。这类失败多数是单个源的问题，不代表应用坏了。解决之后想调翻页与显示效果，见 [阅读设置与操作技巧.md](阅读设置与操作技巧.md)。

**章节下载失败**：按顺序检查存储空间是否充足、是否授予了文件访问权限（个别机型没给权限还会闪退）、单章失败时切源重下。批量下载整部漫画时，把应用保持在后台运行（别从最近任务里划掉），下载不容易中断。安卓 11 机型上「下载完成却打不开」的情况是另一个已知问题，处理办法见 [本地漫画导入与格式支持.md](本地漫画导入与格式支持.md) 第五节。

## 三、报源问题去找谁

某个图源坏了属于正常现象（官方在 GitHub 看板与 issues 里跟踪各源的工作状态）。报问题前先搜一下 issues 别重复提，提交时按官方的漫画源问题模板填写，标题带 `[CS]` 前缀，方便作者定位。官方渠道入口见 [版本更新与官方渠道说明.md](版本更新与官方渠道说明.md)。

## 四、官方口径，引用给你看

有两句官方 README 里的原话，能帮你建立正确预期：

- 「仅仅作为网页浏览器显示网站免费浏览部分」——官方明确本程序不含获取网站 VIP 内容的功能，所以付费内容你在 Cimoc 里同样看不了，这不是故障；
- 「所有漫画均来自用户在第三方网站上的手动搜索」——内容完全依赖你启用的图源，源的状态决定你能搜到什么。

因此「某个源搜不出某些书」时，换源是最合理的解法；给应用本身怎么设置都解决不了源站的问题。收藏与进度的备份方法见 [备份与恢复教程.md](备份与恢复教程.md)。
