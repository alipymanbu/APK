## 一、为什么装完什么也搜不到

Cimoc 本身不带任何漫画内容，它只是一个聚合阅读器：**所有能看的漫画都来自你导入的图源**（即各家漫画网站的接口配置）。官方 README 也写明了免责口径——所有漫画均来自你在第三方网站上的手动搜索。所以第一次使用的关键动作就是：把图源配好。

## 二、两种添加方式

### 方式 1：导入图源列表（推荐，一次一批）

1. 打开 Cimoc，点左上角的三横菜单，进入**图源**页面；
2. 点右上角的菜单（三点图标），选择**导入图源**；
3. 在弹出的输入框里粘贴一个图源列表地址（JSON 格式），点确定；
4. 底部提示导入成功后，回到图源页就能看到一整批站点条目。

新版本还支持**二维码扫描**添加（1.7.20 的更新说明里加入该功能），别人发你二维码时直接扫即可。

### 方式 2：手动添加单个图源

1. 同样进入 **图源** 页面，点右上角菜单选**手动添加图源**；
2. 依次填写**图源 ID**、**图源名称**、**图源网址**三项；
3. 点右上角的对勾保存。

手动添加适合你手里只有单个站点接口地址的情况；批量导入则适合从社区拿一整份列表。

## 三、图源列表地址去哪找、为什么会失效

这是用 Cimoc 绕不开的坑：**图源列表地址会过期**。历史上有过两次典型的失效：

- 作者曾在 Gitee 上维护的源列表仓库，后来整个仓库被封禁，地址打不开；
- 更早发布在 Release 说明里的 `gitcode.net` 源列表地址，随着该域名被改作他用也失效了。

所以不要收藏任何一个「别人给的固定地址」长期用，正确的做法是：

1. 以**官方渠道最新发布**为准：GitHub Release 的更新说明、官方 Telegram 频道、微信公众号（渠道入口见 [版本更新与官方渠道说明.md](版本更新与官方渠道说明.md)）；
2. 图源能不能正常工作，官方在 GitHub 的看板和 issues 里跟踪，发现某个源坏了可以去提 issue（按官方的漫画源问题模板，标题带 `[CS]` 前缀）。

## 四、启用、停用与切换

- **图源页管理**：图源页右上角菜单里还有全选、反选等选项，勾选状态就是启用状态；搜索时只在你启用的图源里进行。启用的源越多，一次搜索要等的结果也越多，建议只留几个常用的。
- **长按单个源**：社区整理的操作经验里，长按图源条目可以编辑或删除、启停某个源——发现某个源失效了，先停用或删掉它，避免每次搜索都白等它返回（具体交互以你手上的版本为准）。
- **阅读时切源**：同一部漫画常被多个图源收录。搜索结果的条目上会标出它来自哪个漫画站；阅读界面里也能唤出菜单切换图源线路——某个源加载慢或解析失败时，换一个源是最直接的解法。
- **主界面顶部**也有图源下拉，可以快速切换当前浏览的源。

配好图源、搜到漫画之后，阅读翻页与显示相关的调整见 [阅读设置与操作技巧.md](阅读设置与操作技巧.md)；收藏和进度想换手机也不丢，见 [备份与恢复教程.md](备份与恢复教程.md)。
