## 一、装之前先知道的两件事

1. **Cimoc 是一个「阅读器」**：装好它本身并不能直接看漫画，还需要导入图源（漫画站点的接口配置）才能搜索和阅读。这是新用户最容易卡住的一步，装完直接看 [图源添加与导入方法.md](图源添加与导入方法.md)。
2. **它是开源项目**，官方发布渠道是 GitHub（作者 Haleydu 维护）。社区里还存在包名不同的第三方打包版本，安装前建议按本篇第三节核对包名。

## 二、安装步骤

1. 获取 APK 安装包：可用本文提供的 [Cimoc 安装文件资源（夸克网盘）](https://pan.quark.cn/s/40aa5024669b)，也可走官方渠道（见 [版本更新与官方渠道说明.md](版本更新与官方渠道说明.md)）。
2. 手机上打开安装包。系统首次会提示「不允许安装未知来源应用」，按提示允许你的文件管理器或浏览器「安装未知应用」权限后再继续。
3. 等待安装完成，打开 Cimoc。
4. 首次进入后先去导入图源，再用右上角的搜索找漫画——没图源时搜索不会有结果。
5. 部分机型在第一次下载或使用本地漫画功能时，会再弹一次「文件访问权限」的授权，允许即可；权限没给足时，本地文件导入和下载都会出问题（本地阅读的用法见 [本地漫画导入与格式支持.md](本地漫画导入与格式支持.md)）。

想在电脑或 iPhone / iPad 上用 Cimoc：官方只发布安卓版，电脑要走模拟器方案、iOS 暂无官方版本，具体见 [在电脑和苹果设备上使用.md](在电脑和苹果设备上使用.md)。

## 三、核对安装包（版本 / 包名 / 大小 / MD5）

本文提供的 Cimoc 安装文件资源对应的安装包信息如下，安装后可以在系统「设置 → 应用」里对照包名确认：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.7.275 |
| 包名 | `com.cimoc.haleydu` |
| 安装包大小 | 44.91M |
| MD5 | `63205F64BCE28BE0587CD13AA81A33EC` |

几点说明：

- 包名是区分「谁打的包」最可靠的依据。`com.cimoc.haleydu` 是 Haleydu 维护的原版包名；如果你手上拿到的包名是别的（例如第三方站自己打包的 `com.jinyi.cimochhb` 之类），那不是这个包。
- 版本号以你实际拿到的安装包为准，官方各发布渠道的版本号并不总是同步的，具体见 [版本更新与官方渠道说明.md](版本更新与官方渠道说明.md)。
- 对 MD5 的方法：Windows 上可用 `certutil -hashfile 文件名.apk MD5`，安卓上可用文件管理器的文件信息页查看。

## 四、安全软件报毒怎么办

官方 README 里明确写过「报毒问题已解决」。如果安装时仍被手机管家或安全软件拦截：

1. 先核对第三节里的包名与 MD5，确认安装包来源可靠；
2. 确认无误后，在安全软件的拦截提示里选择「信任」或「仍要安装」即可；
3. 如果来源不明的安装包反复报毒，更稳妥的做法是换官方渠道重新获取，而不是关掉安全软件。

## 五、pre-release 版本的一个提示

官方 Release 页区分正式版与 pre-release（预发布）版：**pre-release 版每次启动都会弹出检查更新的提示**，这是它的正常行为，不是故障。只想安静用的话，装正式版即可。
