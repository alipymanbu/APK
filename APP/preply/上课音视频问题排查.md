# Preply 上课音视频问题排查

> 课开始了却没声音、没画面、进不了教室？本篇按「先分清谁的问题 → 查权限 → 查网络 → 应急改工具」的顺序排查。

## 一、先分清是谁的问题

进教室后没声音没画面时，先在聊天框问一句「你能看到/听到我吗」，同时自查：

- 你这边黑屏无声 → 按第二、三节查自己设备；
- 对方黑屏无声 → 让对方查 TA 的权限和设备（把官方帮助的排查思路发给 TA 即可）；
- 双方都正常但画面卡顿 → 跳到第四节查网络。

## 二、权限：最常见的「没声音没画面」原因

安卓设备（官方帮助中心给的路径）：

1. 打开系统「设置」→「应用与通知」；
2. 找到 Preply →「权限」；
3. 把禁用状态的**麦克风、摄像头**权限全部允许；
4. 重新打开应用再进教室。

iOS 设备：设置 → 隐私 → 在摄像头、麦克风两个权限列表里找到 Preply 打开；或在进入教室时按弹窗提示授权。

耳机中途插拔后没声音，官方给的办法是：关掉应用 → 重新连耳机 → 再进教室重试。

## 三、课前先测一次设备与连接

上课前用官方推荐的测试页跑一遍摄像头、麦克风和网络：[sa-utils.agora.io](https://sa-utils.agora.io/agora_webrtc_troubleshooting/)

测试结果里官方给的参考线（达不到就先换网络再上课）：

| 指标 | 参考值 | 低于会怎样 |
| --- | --- | --- |
| 视频/音频丢包率 | 0~2% | 画面冻结、声音断续 |
| 视频码率 | ≥ 500 kbps | 画面模糊 |
| 音频码率 | ≥ 16 kbps | 声音含糊难懂 |

手机流量不稳时，切到 Wi-Fi 再上课；反过来也一样，哪个稳用哪个。

## 四、公司或校园网络进不了教室

公司、学校的网络常把视频服务拦在防火墙外。官方的处理方式是把视频相关域名加进白名单（`*.agora.io`、`*.sd-rtn.com`），你没有网络管理权限的话，最省事的办法是：

1. 用手机流量热点替代办公/校园网络；
2. 或者换到家用网络上课。

## 五、课开不了时的应急办法（官方认可的流程）

教室进不去又马上要到上课时间，别干等：

1. 在 Preply 聊天里告知导师设备或网络出了问题；
2. 双方同意的话，**换一个通用视频工具（如 Zoom、Skype）把这节课上完** —— 这是官方帮助中心明确给出的应急做法；
3. 课后回到应用里，对这节课用「Report an issue（报告问题）」说明情况，涉及课时不该扣的部分走这个流程处理。

## 六、华为设备提示

官方帮助中心明确写过：**没有官方 Google Play 服务的华为设备上，应用可能无法正常运行**，这种情况建议改用电脑浏览器打开 Preply 网页版上课。装了应用却反复闪退或黑屏的华为设备用户，先考虑这条路径（相关安装说明见《下载与安装教程.md》）。

## 七、以上都试过还不行

按顺序做：重启应用 → 重启手机 → 检查应用是否为最新版本 → 卸载重装（安装包获取见《常见问题与问题排查.md》）。仍然不行，通过应用内或官网的联系入口找官方客服，把出现问题的环节、报错提示、试过的步骤一并写上，处理会快很多。
