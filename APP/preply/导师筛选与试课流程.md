## 一、用筛选条件缩小范围

官方页面显示平台有 10 万多名导师、来自 180 多个国家和地区、教授 90 多种语言（数字随时间变化，以官方页面为准）。选定要学的语言后，按这几类条件过滤：

| 筛选条件 | 用途 |
| --- | --- |
| 价格区间 | 先定预算，避免在远超预算的导师页面上浪费时间 |
| 可约时间 / 即时可上 | 按你的空档筛，时差大的导师尤其要看这一项 |
| 母语 / 国籍 | 想练特定口音或考试（如雅思、托福）时用得上 |
| 教学特长 | 商务、少儿、应试、口语等方向各有人专攻 |

每个导师主页有自我介绍视频和学员评价。先把简介视频看完，再翻两三条带文字的评价，比只看星级更容易判断合不合拍。

主页上通常还挂着几项数据：评分、评价数、已上课时数、回复速度（以页面实际显示为准）。已上课时数高，说明对方长期在做教学、稳定性可参考；回复速度快的导师，约课改期都省心。价格方面不必预设「便宜没好货」—— 每位导师自主定价，跨度很大，先按预算设价格上限再挑人。

### 短名单比课法

别一口气约五六个试课，按这个顺序筛：

1. 用上面的过滤条件圈出 5~7 个候选人；
2. 给每人发一条同样的消息：你的水平、目标、想要的上课频率 —— 回复的速度和用心程度，本身就是上课体验的预演；
3. 挑 1~2 位约试课，用同一张表打分：是否贴合你的目标、难度是否合适、课上有没有实质性反馈、聊得来不来；
4. 试完尽快定下来订阅（订阅规则见《订阅计划与计费规则.md》），把决定拖过一周，节奏就断了。

## 二、在 App 里预订试课

1. 打开选中的导师主页，点「Buy trial lesson」（购买试听课，以应用内实际显示为准）；
2. 选择支付方式，或使用课时余额；
3. 选时长：25 分钟或 50 分钟；
4. 挑日期与时间，确认下单。

两个下单前必做的检查：

- **时区**：预约界面显示的是你个人资料里的时区，错了会约到半夜（改法见《常见问题与问题排查.md》）；
- **提前量**：部分导师对试课设置了最短提前时间，太临近的时段约不了，换一个稍晚的时间即可。

试课是**付费课**，价格以你下单时页面显示的金额为准，不需要先订阅。每位导师对每个学员只提供一次试课，但你可以约多位不同导师的试课来互相比较。

## 三、试课的几条硬规则

| 规则 | 说明 |
| --- | --- |
| 时长 25 / 50 分钟 | 下单后不能再改时长，选之前想清楚 |
| 开课前 12 小时 | 12 小时以上取消或改期，课时退回余额；不足 12 小时，课时不退 |
| 导师可拒单 | 导师按自己的档期和教学方向决定接不接；被拒后课时留在余额里，可另约他人 |
| 每位导师一次 | 换导师再试是允许的，试课机会按导师逐个计 |

规则细节以官方帮助中心的试课说明为准：[help.preply.com](https://help.preply.com/en/articles/4179487-how-to-book-a-trial-lesson)。

## 四、试课会发生什么、不满意怎么办

一节典型的试课：互相认识 → 聊学习目标 → 简单摸底 → 一小段示例教学 → 导师给出学习计划建议。上完后由你决定要不要订阅这位导师（订阅规则见《订阅计划与计费规则.md》）。

试课不满意时，官方给两条出路：**免费换一位导师再试一次**，或**全额退款** —— 具体申请入口以应用内和官方帮助中心当时的流程为准。

## 五、换导师是正常操作

随时可以换导师，也可以多个导师的课并行。注意课时余额是**绑定在导师名下**分开记的，换导师前先在官方帮助中心查「把课时转到另一位导师」的处理方式，避免余额搁置在不再上课的导师那里。
