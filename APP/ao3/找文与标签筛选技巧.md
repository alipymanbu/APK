## 一、先分清两种找法：搜索和筛选

AO3 上「找文」有两套入口，做的事不一样：

- **搜索（Search）**：输入关键词，全站匹配。快，但结果杂——它不区分你输入的词是标题、作者名还是标签。
- **筛选（Filters / Sort and Filter）**：先进入某个标签或某个圈的作品列表，再用条件把列表收窄。找文主要靠这一套。

常见路径：先在搜索框输入作品圈名或角色名 → 在结果里点中你要的那个标签（比如某对 CP 或某个 fandom）→ 进入该标签的作品列表页 → 打开筛选面板（网页端右侧的 Sort and Filter 方框；移动端和客户端里通常是一个 **Filters** 按钮）。

一个前提要知道：作者设为「仅登录用户可见」的作品，**未登录时连搜索结果里都不会出现**，你会以为它不存在。搜不到某个确定存在的文，先想想是不是这一类（注册见[账号注册与登录.md](账号注册与登录.md)）。

## 二、Filters 面板里真正常用的几项

筛选面板项目很多，日常高频用到的就这几组：

| 条件 | 怎么用 |
| --- | --- |
| Include（包含标签） | 勾选或输入你想看的标签，结果必须带它 |
| Exclude（排除标签） | 勾选你不想看的标签，结果一律不带 |
| Complete（完成状态） | 勾上只看已完结的作品，避开没写完的连载 |
| Word Count（字数区间） | 比如只看 5 万字以上的长篇 |
| Language（语言） | 选中文只看中文文；选 English 只看英文文 |
| Rating（分级） | 只勾 G/T 等于把成人向内容挡在结果外，字母含义见[分级与警告标签解读.md](分级与警告标签解读.md) |
| Crossover（跨界作品） | 关掉可排除多个原作混合的文 |
| Sort by（排序） | 按更新时间、kudos 数、字数等排 |

三个实操结论：

1. **语言筛选值得随手设**。不设的话，中文搜索词也可能翻出英文文，反之亦然。
2. **Include/Exclude 支持手打任意规范标签**，不局限于面板里列出的热门项。开始输入时会弹出候选，选弹出来的那一个——它保证你用的是站点的「规范标签」，手打的近似词可能匹配不到任何作品。
3. **拿不准开哪篇时，看结果里的数字**。每篇作品下方会显示 kudos 数、点击数、书签数，不少读者用 kudos 数（或 kudos 与点击之比）来当开文的参考——数字是全站读者用互动攒出来的，比标题党可靠。

## 三、只看只写某对 CP 的文：otp:true

大圈里常见的问题是：某对 CP 只是别篇里的背景板，也被作者打进了标签，筛出来一大堆不合意的。解决办法是在筛选面板的 **Search within results**（在结果中搜索）框里输入：

```text
otp:true
```

它的含义是：结果里只保留**仅标注了这一对 CP**的作品，凡是把你的 CP 当背景提一嘴的都会被滤掉。冷门 CP（俗称 rarepair）用这个语法体验提升最明显。

## 四、中文 CP 名怎么对上站内标签

AO3 的标签以英文为主，中文圈叫法要对译成英文标签才能稳定命中。几个例子：

| 中文叫法 | 站内标签写法 |
| --- | --- |
| 德哈 | Draco Malfoy/Harry Potter |
| 盾冬 | James "Bucky" Barnes/Steve Rogers |

记不住拼写时的省力做法：先手头随便打开一篇这个 CP 的中文文，点它头部 Relationship 标签，就跳到了该 CP 的作品总列表，再按第二节的方法筛——比输入框里硬拼英文快得多。搜不到时的其他原因见[常见问题排查.md](常见问题排查.md)。

## 五、筛选条件没法保存，怎么办

AO3 站点本身不提供「保存筛选条件」的功能，每次重新设一遍是常态。两个替代办法：

- 把筛好之后的结果页**加入浏览器书签**，下次从书签进入，结果会按最新数据刷新；
- 登录账号后使用站内的订阅与收藏体系（与筛选是两回事，区别见[账号注册与登录.md](账号注册与登录.md)）。

客户端是否会记住上次筛过的条件，取决于客户端本身，以你手上版本的实测为准。
