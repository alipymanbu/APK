## 一、打开就一直转圈、刷不出内容

客户端里的所有内容都来自 AO3 站点服务器，所以第一步是**把「客户端坏了」和「连不上站点」分开**。判断顺序：

1. 换个网络（比如 Wi-Fi 换流量）再刷新一次；换了就好，说明是原先那个网络环境连不上站点。
2. 用手机浏览器直接访问 `https://archiveofourown.org`，看网页能不能开。网页也开不了，就是当前网络到站点不通，与客户端无关；客户端再怎么重装也不会好。
3. 网页能开、客户端不行 → 清一次客户端缓存或重启 App；仍不行，卸载重装最新安装包（获取方式见[下载与安装教程.md](下载与安装教程.md)）。

另外站点本身也有维护和故障时段，官方状态账号是 X（Twitter）上的 `@AO3_Status`，大规模打不开时先看它，别人也打不开就不用折腾自己手机了。

## 二、确定某篇文存在，却搜不到

按命中率从高到低排查：

| 可能原因 | 处理 |
| --- | --- |
| 作者设为「仅登录用户可见」 | 登录后再搜（注册流程见[账号注册与登录.md](账号注册与登录.md)） |
| 作品被作者删除或隐匿 | 站内没有就是没有了，除非作者恢复 |
| 输入的词不是规范标签 | 用弹出的候选标签，或从已知一篇的标签页进去（见[找文与标签筛选技巧.md](找文与标签筛选技巧.md)） |
| 筛选条件太紧 | 检查 Filters 里的语言、完成状态、字数、排除项，逐项放宽验证 |
| 站点搜索索引延迟 | 新发布的文偶尔晚几分钟进索引，稍后再搜 |

中文关键词的另一个常见坑：中文圈的叫法（CP 名、梗名）与站内英文标签对不上号，对译思路见[找文与标签筛选技巧.md](找文与标签筛选技巧.md)第四节。

## 三、App 闪退或卡死

按顺序试，一般在前两步就能解决：

1. **清缓存**：系统设置 → 应用管理 → ao3 → 存储 → 清除缓存。缓存是临时数据，清除不影响账号与收藏。
2. **重启手机**：排查系统层面的资源占用。
3. **重装**：卸载后用安装包重装（顶部网盘链接可再取）。重装会丢掉客户端本地的阅读记录，账号里的收藏、订阅等云端数据不受影响。
4. 还闪退的话，对比一下是不是只有某一个页面触发——是的话绕开该入口并等客户端更新，比反复重启更省事。

## 四、登录不上或提示错误

- 先确认账号密码没输错：AO3 密码区分大小写，客户端里的键盘偶尔会自动纠错干扰输入，换系统输入法试一次。
- 忘记密码走官网的密码重置（`archiveofourown.org` 域名下的 Reset Password 页面），邮件几分钟内会到，也翻翻垃圾箱。
- 账号问题（被锁、收不到邀请邮件）都归 AO3 官方 Support 管道处理，客户端内没有对应入口。

## 五、安装与更新类问题

装不上、解析失败、未知来源被拦这类问题出在安装环节，处理步骤在[下载与安装教程.md](下载与安装教程.md)第三节；版本相关说明（你现在这份是 3.1.0）也在那一篇。

## 六、怎么确认自己打开的是真 AO3

AO3 的真身只有一个域名：`archiveofourown.org`。输密码、改邮箱、注册，只认它。核对方法：

1. **看地址栏域名**：`archiveofourown.org` 之外的一切变体（多一个连字符、换了后缀、前面加了别的词）都按假冒处理。OTW 名下确实持有 `.com` / `.net` 等域名，但它们只会跳转回 `.org`，停留在原域名的登录页一律不碰。
2. **警惕「免验证注册」「一键登录」「付费代注」**：官方注册只有免费邀请队列一条路（见[账号注册与登录.md](账号注册与登录.md)第五节），承诺更快入口的基本都是钓鱼。
3. **社区流传的镜像站、备用入口**：只能当「只读」的临时浏览用，**绝不在上面输入账号密码**——镜像站不归 OTW 管，你没法知道对面是谁；登录类操作等回到官方域名再做。
4. 拿不准时，从本文第一节的方式先确认官方域名可达，再从官方首页导航进去，不抄别人转给你的链接。
