## 一、AO3 是个什么地方

Archive of Our Own（AO3，意为「我们自己的档案馆」）是一个非营利的同人作品托管网站，由再创作组织 OTW 运营，2009 年上线。全世界的人把基于影视、动漫、游戏、小说等既有作品创作的二次创作——主要是同人小说——上传到这里，任何人都能免费阅读，站内没有广告，运营经费来自捐款。

几个对你有用的基本盘：

| 你关心的 | 实际情况 |
| --- | --- |
| 要不要钱 | 免费，站内无广告，也没有会员体系 |
| 作品量 | 千万篇量级，覆盖大大小小几乎所有 fandom（作品圈） |
| 语言 | 作品本身用什么语言写就是什么语言，中文作品数量不小；界面也支持切换中文（[中文界面设置方法.md](中文界面设置方法.md)） |
| 内容尺度 | 全年龄到成人内容都有，靠分级和警告标签区分（字母含义见[分级与警告标签解读.md](分级与警告标签解读.md)） |
| 官方 App | 不存在。OTW 只做网站，你现在用的 ao3 是第三方客户端 |

## 二、客户端和网站是什么关系

ao3 这个客户端读的就是 AO3 网站的数据：你在客户端里看到的作品列表、正文、标签，和用浏览器打开 `https://archiveofourown.org` 看到的是同一份。因此：

- 网站上的找文方法、标签规则，在客户端里同样适用；
- 你在网页上收藏过的作品，登录同一账号后在客户端里也能看到；
- 客户端的功能完整度由它的开发者决定，遇到某个按钮找不到时，换个思路想「这在网站上叫什么」，多半能对上。

## 三、认识一篇作品页

在 AO3 上点开任何一篇作品，最先看到的不是正文，而是作品头部的一组信息。读懂它们，你就能在点进正文前判断这篇要不要看：

| 信息 | 作用 |
| --- | --- |
| 分级（左上角色块字母 G/T/M/E） | 内容尺度，决定适不适合你 |
| 档案警告（加粗条目） | 主要角色死亡、激烈暴力等硬雷提醒 |
| Relationship 标签（`A/B` 形式） | 这篇写哪对 CP；`/` 是恋爱关系，`&` 是朋友或家人 |
| Character 标签 | 出场角色 |
| Additional Tags（自由标签） | 设定、梗、文风等细节说明 |
| fandom（作品圈名） | 属于哪部原作 |
| Stats（统计） | 字数、章节数、kudos 数等 |

标签是一篇一篇积累经验的：看到喜欢的梗就记住它的标签写法，以后直接按标签找文（方法见[找文与标签筛选技巧.md](找文与标签筛选技巧.md)）；踩到雷同样记下来，下次筛选时排除。

## 四、读完第一篇的最短路径

1. 打开客户端，确认能刷出内容（打不开先看[常见问题排查.md](常见问题排查.md)）。
2. 首页通常有作品流或作品圈入口，随手进一个你认识的原作的圈。
3. 挑一篇分级为 G 或 T 的作品点进去——这两级没有成人内容，适合先熟悉版式。点开时若先弹出一页「可能包含成人内容」的确认提示，说明这篇不是全年龄，退回换一篇即可（分级字母怎么读，见[分级与警告标签解读.md](分级与警告标签解读.md)）。
4. 看一遍头部标签，没雷就往下拉读正文。
5. 单章作品读到底即是完；多章作品页面顶部有章节目录，可以跳章。

读完觉得好，想给作者点个赞或收藏起来慢慢看，需要先有账号，流程和等待时间见[账号注册与登录.md](账号注册与登录.md)。
