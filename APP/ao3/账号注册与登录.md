## 一、不注册能用到什么程度

AO3 的公开作品对未登录访客完全开放，所以不注册也能：

- 浏览和搜索所有公开作品并读正文；
- 按标签、分级、字数等条件筛选（方法见[找文与标签筛选技巧.md](找文与标签筛选技巧.md)）；
- 把作品下载成文件离线看（见[离线阅读与作品下载.md](离线阅读与作品下载.md)）。

纯阅读的话，账号不是必需品。需要注册的是下面这些动作：点赞（kudos）、评论、收藏（bookmark）、订阅作者或作品，以及阅读作者设为「仅登录用户可见」的作品。

## 二、注册为什么要点邀请：流程与等待时间

AO3 采用邀请注册制，账号数量按服务器能力控制增长，这是官方明说的运营策略，不是针对谁。流程如下：

1. 打开 AO3 首页（`https://archiveofourown.org`，客户端里一般也有 Get Invited 或注册入口，指向同一流程）。
2. 点 **Get Invited**，填入你的邮箱，提交申请。
3. 等邀请邮件——官方 FAQ 的口径是**通常一周左右**，实际从一两天到更久都有，取决于排队人数，以官方页面当时的说明为准。
4. 收到邮件后点里面的链接，进入开户页面，设用户名和密码，完成注册。

两个提醒：

- 邀请邮件偶尔会掉进垃圾箱，等的时候翻一翻；
- 邮箱要填你能长期收信的，之后找回密码靠它。

也可以向已经注册的用户要一个现成的邀请码——AO3 会给老用户发放可分享的邀请名额，用邀请码开户可以跳过排队。

## 三、登录后多了什么

登录之后，除了第一节列出的互动功能，还有几项对长期读者很实用：

| 功能 | 作用 |
| --- | --- |
| Bookmark（收藏） | 把作品收进自己的书签页，可打私有备注，换设备不丢 |
| Subscribe（订阅） | 作品、系列或作者更新时站内提醒（可选邮件），追连载不用手动翻 |
| History（历史记录） | 自动记下你读过的文，想找回「之前看过但忘了名字」的那篇靠它；可单条删除、一键清空或整体关闭 |
| Mark for Later（稍后读） | 作品页上的一颗按钮，点过之后在 History 页里能单独列出「稍后读」清单，读完点 Mark as Read 划掉 |
| 收件箱 | 别人回复你的评论会进站内收件箱，不用回到原文页翻找 |
| 仅登录可见作品 | 能读作者限制登录可见的作品，这类作品未登录时搜索里根本不出现 |
| 界面偏好 | 语言、显示设置等跟着账号走，语言改法见[中文界面设置方法.md](中文界面设置方法.md) |

kudos 相当于「点赞」，一个账号对一篇作品只能点一次，点了不能撤；未登录则按 IP 计，同样一次。评论直接留在作品页，作者看得到。收藏还有个容易忽略的细节：**私有书签只有你自己可见**，作者和其他人都看不到，想低调收藏就勾私有。

## 四、注册和登录时的两个坑

1. **用户名定了就改不了**。开户时想好，别用一时兴起的名字。
2. **分不清「登录 AO3」和「登录客户端」**：账号是 AO3 网站的账号，与客户端开发者无关。你在客户端里登录的是你的 AO3 账号；如果某个客户端要求你再注册一个「它自己的」账号，那是客户端自有体系，不是 AO3 的，用不上可以不填。

密码找回、账号被锁等问题要在官网处理（Support 与密码重置页面都在 `archiveofourown.org` 域名下），客户端里通常没有这些入口。其他疑难见[常见问题排查.md](常见问题排查.md)。

## 五、账号安全：三条值得照做的

AO3 官方处理过大量因「密码在别的网站泄露后被拿来撞库」而失窃的账号（官方通报过一批上万个涉险账号的清理与通知）。落到你身上就三条：

1. **密码不要与其他网站复用**，长度放开到长一些（站点支持最长 72 位），记不住就交给手机自带的密码管理器；
2. **邮箱必须是长期在用的**——改邮箱、找回密码都靠它；站点在你改用户名、密码、邮箱时会发确认邮件，收到「不是你操作的改动」通知要立刻处理；
3. **别人借你手机看完要退出登录**，公共设备上尤其如此。

任何声称「付费代注册」「免邀请秒开账号」的服务都是骗局——官方注册只有一个渠道：邀请队列，免费。
