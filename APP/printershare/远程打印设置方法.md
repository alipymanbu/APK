## 一、两条路径怎么选

打印机不直接连手机时，让电脑当中间人。中转分两种，差别在「手机和电脑要不要在同一个网络」以及「要不要花钱」：

| | 同一局域网（Nearby Printers） | 互联网远程（Remote Printers） |
|---|---|---|
| 手机和电脑 | 同一 WiFi / 局域网 | 各在各地，都联网 |
| 电脑端要装 | PrinterShare 桌面版 | PrinterShare 桌面版 + 登录账户 |
| 收端要订阅吗 | 不要 | **要**（见第四节） |
| 典型场景 | 在家打家里电脑接的打印机 | 在外把文件打回家里/办公室的打印机 |

## 二、电脑端先装好

桌面版从官方安装页下：[printershare.net 安装页](https://www.printershare.net/install.php)。截至 2026-09，该页显示 Windows 版 2.4.10（2024-01-16 发布）、macOS 版 1.6.2（2026-02-27 发布），系统要求是 Windows 7 及以上 / macOS Sierra (10.12) 及以上，512 MB 内存、50 MB 磁盘 —— 具体以官网当时显示为准。

安装完打开桌面程序，它会自动列出这台电脑上能用的打印机。两个系统上的注意点：

- **Windows**：装的时候会弹「Windows 已保护你的电脑」，因为程序没用微软商店证书签名 —— 点「更多信息 → 仍要运行」即可；杀毒软件或防火墙要放行它，否则手机连不进来。
- **macOS**：去「系统设置 → 隐私与安全性」给 PrinterShare 打印机权限；防火墙开启时允许它接收连接。

## 三、同一局域网中转（不要钱）

1. 电脑装好并运行 PrinterShare，点「共享打印机」（Share Printer），选要共享的那台，范围选「仅本地网络」，点开始共享；
2. 手机上装好 PrinterShare（[PrinterShare 安装文件资源（夸克网盘）](https://pan.quark.cn/s/441c97f0969a)），连上和电脑**同一个 WiFi**；
3. 打开应用，点「选择打印机」→「附近打印机」（Nearby Printers）；
4. 电脑共享的打印机出现在列表里，选中它，选文件、设选项、打印。

这条路全程不出局域网，也不用注册账户。

## 四、互联网远程打印

适合人不在家、要把文件打回家里的打印机。链路是：手机 → PrinterShare 官方服务 → 家里那台电脑 → 打印机，两端都走加密连接。

**接收端（家里接打印机的电脑）：**

1. 装好桌面版并登录 PrinterShare 账户；
2. 选中要共享的打印机，开启「互联网访问」（Internet Access）；
3. 配置访问控制 —— 可以设成任何人、指定用户或按邮箱授权，防止陌生人往你打印机发任务；
4. 保持程序运行、电脑不关机（用睡眠代替关机），任务才收得到。

**发送端（手机）：**

1. 手机上用同一个账户登录 PrinterShare；
2. 点「选择打印机」→「远程打印机」（Remote Printers）；
3. 共享的打印机会列出来，选中即可打印。

**订阅要求（重点）**：发送端（手机）不需要订阅，**接收端那台电脑要有有效订阅**才能收到远程任务。官网企业页截至 2026-09 的方案是：Basic 每月 19.99 美元、500 页/月、最多 3 个账户；Business 每月 79.99 美元、不限页数、最多 20 个账户；更大规模走 Enterprise 定制。价格与额度会变，以下单前官网显示为准。

## 五、远程打印收不到任务时

九成是这四个原因，按顺序对一遍：

1. 接收端电脑在线、桌面版**正在运行**（最小化到托盘也算运行，关掉就不收）；
2. 该打印机的「互联网访问」开关是开着的；
3. 两端登录的是**同一个账户**；
4. 接收端订阅还在有效期内 —— 订阅过期是远程任务发不出去最常见的原因。

其余症状（找不到打印机、任务发了没动静）归到 [打印不出来怎么排查.md](打印不出来怎么排查.md)。
