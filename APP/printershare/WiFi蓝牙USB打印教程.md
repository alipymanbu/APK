## 一、先判断该用哪种方式

三种方式的前置条件不一样，选错那步就白忙。按下表对号入座：

| 你的情况 | 用哪种 | 前置条件 |
|---|---|---|
| 打印机接路由器、有 WiFi | WiFi | 手机和打印机在**同一个 WiFi** |
| 小型热敏机、标签机、便携机 | 蓝牙 | 打印机有蓝牙，先在系统设置里配对 |
| 打印机只有 USB 口，或想线连稳定打印 | USB（OTG） | 手机支持 OTG + 一根 OTG 线 |
| 打印机接在电脑上 | 都不用 | 走电脑中转，见 [远程打印设置方法.md](远程打印设置方法.md) |

不确定打印机属于哪类，看 [支持哪些打印机和文件格式.md](支持哪些打印机和文件格式.md)。

## 二、WiFi 打印

**前置**：手机和打印机连在同一个 WiFi 下；打印机开机且网络就绪。

1. 打开 PrinterShare，选要打的文档或照片；
2. 点「选择打印机」（Select Printer）；
3. 选「WiFi 打印机」（WiFi Printers）；
4. 应用扫描网络里的打印机，等列表出来；
5. 点中你的打印机，进打印设置页；
6. 确认份数、页码等选项后点打印。

**扫不到时按顺序查三件事**：打印机是不是开着且连上网、手机是不是同一个 WiFi、安卓的位置权限给没给 PrinterShare（系统扫描 WiFi 设备依赖它）。三项都对还搜不到，重启打印机再扫一次；排查细节见 [打印不出来怎么排查.md](打印不出来怎么排查.md)。

## 三、蓝牙打印

蓝牙方式主要面向热敏打印机、标签打印机、便携打印机这类小型设备，步骤和 WiFi 不同 —— **配对要先在系统设置里做**，应用里只负责连：

1. 打开手机蓝牙，在「设置 → 蓝牙」里搜到打印机并配对成功；
2. 打开 PrinterShare，选文件；
3. 点「选择打印机」→「蓝牙」（Bluetooth）；
4. 列表里选中已配对的那台，确认选项后打印。

配对过一次以后，只要蓝牙开着，一般直接能选到。

## 四、USB（OTG）打印

**前置**：手机支持 OTG 功能，外加一根 OTG 线（手机接口转打印机 USB 口）。老式打印机只有 USB 口、又不接网络时，这是最直接的路。

1. 用 OTG 线把手机和打印机连起来；
2. 打开 PrinterShare，选文件；
3. 点「选择打印机」→「USB」；
4. 应用识别到直连的打印机，选中后打印。

连不上先换一根 OTG 线试（线的毛病比手机多），再确认手机 OTG 开关（部分机型要在开发者选项或设置里手动打开）。个别机型官方提示可能需要特定驱动支持，遇到识别不了的先记入排查清单。

## 五、打印设置页里有什么

选中打印机后会进设置页：份数、页码范围、纸张尺寸这类选项都在这里调（不同机型可调项不同，以实际界面为准）。确认无误再点「打印」，任务就发给打印机了。

如果点了打印却没动静，或者打出来不对劲，转 [打印不出来怎么排查.md](打印不出来怎么排查.md) 按症状分诊。
