## 一、这是个什么应用

PrinterShare 是 Mobile Dynamix（Dynamix Software）出的安卓打印应用，包名 `com.dynamixsoftware.printershare`。你先在手机上选一份文档、照片或网页，它再把内容发到打印机打出来 —— 打印机可以是同一 WiFi 下的网络打印机、蓝牙打印机、USB 线直连的打印机，也可以是另一台电脑上共享出来的打印机（同一局域网或异地都行）。

适合两类人：手边只有手机，要打证件照、合同、资料的；以及打印机接在电脑上、想从手机把文件丢过去打的。装完怎么连打印机，见 [WiFi蓝牙USB打印教程.md](WiFi蓝牙USB打印教程.md)。

## 四、安装步骤

1. 把 APK 文件传到手机（下载、数据线拷贝、网盘转存都行），用文件管理器点开它。
2. 如果系统弹出「禁止安装未知应用」，点「设置」，给你的浏览器或文件管理器打开「允许安装此应用」的开关，返回再点一次安装。
3. 装完打开 PrinterShare，首次启动会要权限：**存储**（读要打印的文件）和**位置**（安卓系统扫描 WiFi 打印机要位置权限，不给就搜不到网络打印机）。
4. 进入主界面后点「选择打印机」，看能否扫到你的打印机。扫不到先别急，多半是网络或权限问题，按 [打印不出来怎么排查.md](打印不出来怎么排查.md) 查。

不需要 root，官方明确说明在所有安卓设备上无需 root 即可运行。

## 五、免费版和 Premium 差在哪

| | 免费版 | Premium |
|---|---|---|
| 页数 | 有试用页数上限，可打有限页数 | 不限页数 |
| 连接方式 | WiFi / 蓝牙 / USB / 远程都能试 | 全部可用 |
| 收费方式 | 免费 | 一次性买断，无订阅 |

官方口径是：免费版用来试用全部打印功能，页数有限；Premium 解除全部限制，买断制、不收月费。购买入口在应用内（Google Play 内购）或官方直装渠道；机构批量部署 15 套起有阶梯折扣，授权以激活密钥形式发放（官网企业页按新加坡元标价，截至 2026-09，以下单时页面为准）。具体价格以 [printershare.net](https://www.printershare.net) 当时显示为准。

## 六、装完建议先做的事

- 到系统设置里确认位置权限给了 PrinterShare，否则 WiFi 打印机永远搜不出来；
- 想打短信、通话记录的话，用直装 APK 版本 —— Google 的政策把这两项权限从商店版里移走了，直装版保留了这个功能（详见 [支持哪些打印机和文件格式.md](支持哪些打印机和文件格式.md)）；
- 打印机和手机先连到同一个 WiFi，再打开应用搜索，一次就中的概率高很多。
