## 一、打印机按连接方式分四类

| 类型 | 覆盖范围 | 对应连接步骤 |
|---|---|---|
| WiFi 打印机 | HP、Canon、Epson、Brother、Samsung 等品牌的大多数网络打印机 | [WiFi蓝牙USB打印教程.md](WiFi蓝牙USB打印教程.md) 第二节 |
| 蓝牙打印机 | 热敏打印机、标签打印机、便携/移动打印机 | 同上 第三节 |
| USB 打印机 | 经 OTG 线直连的大多数 USB 打印机 | 同上 第四节 |
| 远程 / 中转打印机 | 电脑上能打的任何打印机，经桌面版共享 | [远程打印设置方法.md](远程打印设置方法.md) |

官方公开资料的口径是「支持数千种机型」，但**具体到某个型号能不能直连，官方没有给逐台对照表** —— 拿不准就以实际搜索结果为准：搜得到、选得中、打得出来，就是支持。

## 二、型号不在支持列表里怎么办

还有兜底路径：打印机接在 Windows / Mac 电脑上、电脑能正常给它打印，那就装桌面版把它共享出去，手机走中转打印（局域网或远程都行）。这条路不依赖手机端认不认得这台机型。

另有官方提示：对未明确支持的打印机，应用可能给出「或许可用」的候选驱动，选中后能不能稳定工作要实测；个别 USB 机型也可能需要特定驱动支持。这些属于试错范围，不保证。

## 三、手机里哪些内容能打

| 内容 | 说明 |
|---|---|
| 照片与图像 | 相册里的图直接选 |
| PDF | 文档类主力格式 |
| 网页 | 浏览器页面 |
| 联系人 | 通讯录条目 |
| 剪贴板内容 | 复制后走「粘贴打印」 |
| 其他应用发来的内容 | 通过系统共享菜单（Share）丢给 PrinterShare 打 |
| 短信、通话记录 | 需要直装 APK 版本，见下节 |

不能直接打的：需要先转成上述格式才行 —— 比如某些 Office 文档，先在对应应用里导出成 PDF 再发过来，是通用做法。

## 四、商店版和直装版差在哪

Google 政策变更后，**Google Play 商店版被移除了短信与通话记录权限**，这两项打印功能只在**直装 APK 版本**里保留（官方帮助页明确说明了这一点，并给了直装下载路径）。除此之外两个版本功能一致，已购的 Premium 授权也照常有效。

想打短信或通话记录，就装直装版：[下载与安装教程.md](下载与安装教程.md) 里有安装步骤与网盘入口。官方对权限的说明是：应用只在你主动选择打印它们时才读取，不发消息、不拨电话。

## 五、免费版的限制范围

免费版对**所有连接方式**都开放试用，但页数有限；页数上限针对的是「打了多少页」，与连的是哪种打印机无关。不限页数要升级 Premium（一次性买断）。详见 [下载与安装教程.md](下载与安装教程.md) 第五节。
