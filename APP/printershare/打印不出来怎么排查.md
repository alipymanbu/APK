## 一、先按症状对号入座

| 症状 | 看哪节 |
|---|---|
| 打印机列表里搜不到我的打印机 | 二 |
| 选到了打印机，点了打印没反应 / 任务卡住 | 三 |
| 打出来空白、缺色、质量差 | 四 |
| 远程打印发不出去 / 找不到远程打印机 | 五 |
| 提示页数用完 / 功能受限 | 六 |

## 二、搜不到打印机

WiFi 方式按这三件事的顺序查，多数问题停在前两条：

1. **打印机本身**：开机、网络就绪（有的机器网络断开会自动休眠，看面板指示灯）；
2. **同一个网络**：手机和打印机必须在同一个 WiFi。手机连了 5G 频段、打印机只在 2.4G 上时，两边其实是两个网，搜不到 —— 让它们在同一网段；
3. **位置权限**：安卓扫描 WiFi 设备依赖位置权限，到系统设置里确认 PrinterShare 的位置权限是允许。

三项都对仍搜不到，继续按网络层往下挖（下面几条是无线打印搜不到的常见原因，多个网络排障资料互相印证）：

1. **双频路由器的频段陷阱**：手机连了 5 GHz、打印机只在 2.4 GHz，即使两边显示的 WiFi 名字一样，也可能不在同一网段。把手机临时切到 2.4 GHz 再扫一次 —— 无线打印搜不到，最常栽在这一条上；
2. **访客网络 / AP 隔离**：路由器的「访客网络」或「AP 隔离（客户端隔离）」会拦掉设备之间的互相发现，打印机本身好好的、就是谁都看不见它。让手机接主网络，或到路由器后台关掉隔离再试；
3. **打印机休眠**：网络打印机会断网休眠。按打印机面板上任意键唤醒，10 秒内重新扫描；
4. **重启再扫**：打印机断电重启一次再扫；走电脑中转的，顺手检查电脑防火墙有没有放行 PrinterShare。

蓝牙方式先回系统设置确认配对成功，USB 方式先换一根 OTG 线；没有路由器的场合可以走 WiFi Direct，见 [WiFi蓝牙USB打印教程.md](WiFi蓝牙USB打印教程.md) 第二节。

## 三、点了打印没反应

1. **先确认打印机自己能不能打**：用打印机面板打一张自检页。自检页都出不来，问题在打印机（缺纸、卡纸、没墨/碳带、脱机），不在手机；
2. **看文档格式**：换一份 PDF 或照片试打 —— 个别格式渲染不了，换文件就恢复；
3. **重启两端**：完全退出 PrinterShare 再打开，打印机也断电重启一次，然后重发任务；
4. **查接收端（电脑中转时）**：桌面版是否在运行、打印队列里有没有堆积的旧任务。

## 四、打出来不对劲

- **空白页**：先按第三节第 1 条排除没纸没墨；再换一份文件打，只有一份空白就是源文件的问题（比如白底白字、隐藏内容）；
- **颜色淡 / 断线**：墨量或碳带问题居多，打印机自检页上也能看出来；
- **排版错乱**：在打印设置页里把纸张尺寸改成和打印机里实际纸张一致的规格再试。

打印机从别的应用（比如系统相册）能正常打，唯独 PrinterShare 不行时，问题多半在连接或设置这侧，回到第二节逐项核对。

## 五、远程打印发不出去

按 [远程打印设置方法.md](远程打印设置方法.md) 第五节的四项清单查：接收端在线且桌面版在运行、该打印机开了「互联网访问」、两端是同一账户、接收端订阅有效。另有一项：如果共享时把访问控制设成了「指定用户」，你的账户得在授权名单里。

## 六、提示页数用完 / 功能受限

免费版有试用页数上限，打到提示出现就是试用额度用完了 —— 这不是故障，官方设计如此。两条路：等换新任务时把文件拆得更省着用，或者在应用内升级 Premium 解除页数限制（一次性买断，无订阅）。付费口径见 [下载与安装教程.md](下载与安装教程.md) 第五节。

## 七、还不行的兜底办法

- 打印机不被直连支持时，改走电脑中转：只要 Windows / Mac 能给它打，就能共享给手机打；
- 用同一根线、同一个网络、同一份文件，只换变量地复测，能快速定位是手机、网络还是打印机的锅；
- 官方支持渠道是 `support@printershare.net`（邮件工单），把机型、手机型号、症状写清楚一起发过去。
