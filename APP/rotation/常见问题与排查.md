# Rotation 常见问题与排查

> 方向不生效、服务自己停了、反向竖屏切不了——按现象逐条查，多数问题出在权限或系统限制上。

## 一、选了强制横屏，屏幕却不动

按顺序查这四处，查到哪层算哪层：

1. **服务启动了吗**：回主界面看状态，是「停止」就点启动。服务没跑，任何模式都是空设；
2. **权限批全了吗**：「修改系统设置」缺了核心功能直接失效，「悬浮窗」缺了按应用定向不工作。安装篇的权限表列了每一项的用途，对着补（见[下载与安装教程.md](下载与安装教程.md)）；
3. **目标应用是不是写死了方向**：个别应用会顶掉外部指令。官方建议对这类应用在条件里改用「自动旋转开 / 关」，让它走系统默认，其余应用不受影响（做法见[按应用设置自动旋转.md](按应用设置自动旋转.md)）；
4. **换个模式试**：从「强制」换到「全传感器」或「传感器横屏」再观察。不同 ROM 对个别方向的支持程度不一样，换个模式往往就通了。

## 二、反向竖屏切不过去（小米 / MIUI）

这是系统限制不是配置错误：部分小米设备在**默认桌面启动器**下禁用了反向竖屏方向。官方给的解法是换一个第三方桌面启动器再试，换完在 Rotation 里重新选一次反向竖屏。反向横屏不受这条影响。

## 三、重启手机后方向规则失效了

Rotation 是常驻型服务，重启后需要有人把它拉起来：

- 进设置，找到「开机时运行 / Start on boot」一类开关并打开（入口在主界面的菜单里）；
- 部分品牌还要在系统层面允许它的自启动权限，后台耗电白名单里也把它加上，否则杀后台会连服务一起带走。

## 四、服务用着用着就停了（Android 13 及以上）

Android 13 起，前台服务需要通知权限才能在各类系统限制下保持运行。安装时若拒绝了通知，去系统设置里把它的通知允许打开；常驻通知会一直挂在通知栏，属于正常现象，也是它维持运行的方式。

同理，华为、荣耀等设备的「悬浮窗权限」要进系统设置手动允许，没批的话悬浮球与按应用定向都不会工作。

## 五、想完全恢复系统默认

在 Rotation 主界面点「停止服务」即可，屏幕方向交还给系统原来的逻辑，下拉开关也恢复正常。要彻底卸载前先停一次服务，避免卸载瞬间还挂着一个异常方向。

## 六、其他零碎问题

| 现象 | 说明 |
| --- | --- |
| 界面是英文 | 设置里可切换语言，内置含简体、繁体中文 |
| 开机后没反应 | 见第三节的「开机时运行」开关与系统自启动权限 |
| 提示版本装不上 | 官方近年持续抬高最低系统版本（先后停止过 Android 4.4、5.x 等），以[谷歌应用商店页面](https://play.google.com/store/apps/details?id=com.pranavpandey.rotation)当时显示为准 |
| 想核对手上这份安装包 | 版本 29.3.4、包名 com.pranavpandey.rotation、大小 6.58M，详见[下载与安装教程.md](下载与安装教程.md) |

锁屏方向不生效是另一回事，要单独开无障碍服务，路径与说明见[按应用设置自动旋转.md](按应用设置自动旋转.md)。
