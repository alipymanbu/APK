## 一、两套账号别搞混

用 OurPlay 时你会碰到两种账号，作用完全不同：

| 账号 | 用在哪 |
| --- | --- |
| OurPlay 账号 | App 本身的账号体系，与会员/增值服务相关 |
| 谷歌账号 | 游戏登录用的就是它——外服游戏让你「使用 Google 登录」时，填的是这一套 |

两边不是一回事：注册了 OurPlay 账号不等于有了谷歌账号。你如果本来就有谷歌账号，直接在游戏登录页登录即可，不需要重新注册。

## 二、谷歌账号怎么弄

- **已有账号**：游戏登录界面选 Google 登录，输入你自己的账号即可；
- **没有账号**：第三方教程提到应用内提供注册引导（路径大致在「我的」页面内，具体菜单位置以你手机上实际显示为准）；注册过程需要用到手机号验证，应用会要求短信与联系人读取权限，缺权限会导致校验失败——这是第三方教程与商店权限说明互相印证的说法；
- 注册引导的连接时间可能较长，等它跑完，别中途退出。

账号只在你自己的设备上操作，不要把账号密码交给任何代注册服务。

## 三、App 会用到哪些权限

应用商店的敏感权限说明与第三方教程提到的用途，整理如下（不同版本可能有出入，以系统弹窗为准）：

| 权限 | 用途 |
| --- | --- |
| 存储权限 | 读写安装包、游戏资源 |
| 读取已安装应用列表 | 导入本机已装游戏（不同意就扫不到，见 [导入游戏与加速教程.md](导入游戏与加速教程.md)） |
| 短信 / 联系人 | 谷歌账号注册时的验证与校验 |
| 电话 | 商店标注为「账号注册使用凭证」 |
| 位置 | 商店标注为「定位游戏战区」 |

其中短信、联系人在你不注册新谷歌账号时通常用不到；不放心的话，先按最小需要授权，注册时再补。

## 四、账号相关的两个坑

1. **先绑定，再动手**：清数据、卸载重装之前，确认游戏账号已绑定（游客登录的尤其要紧），否则进度从头再来——社区里有不少这样的反馈，[常见问题与解决方法.md](常见问题与解决方法.md) 第四节有展开；
2. **登录卡住不一定是账号问题**：游戏停在登录页转圈时，先排查运行环境（框架没装完、没从 OurPlay 内启动），见 [谷歌框架与闪退处理.md](谷歌框架与闪退处理.md)，账号本身没问题的别急着折腾账号。
