## 一、先对一眼版本信息

本篇配套的安装包来自夸克网盘资源，版本与体积以下表为准。网上下载页给的是官方最新版，版本号往往已经往前走了，两边不是同一份文件很正常：

| 项目 | 数值 |
| --- | --- |
| 版本 | 8.6.5 |
| 包名 | com.excean.splay |
| 安装包大小 | 82.31 MB |
| MD5 | E7AA40D4B808A38AF0BAA3AF0B85D642 |
| 系统要求 | 安卓 5.0 以上（不同渠道标注略有差异，以安装时的系统提示为准） |

想核对下载下来的文件是否完整，可以把文件的 MD5 值与上表比对：安卓上用文件管理器自带的「文件校验」类功能，电脑上用 `certutil -hashfile 文件名 MD5`。

## 二、从哪拿安装包

两条途径，装出来的都是 OurPlay，区别在版本新旧：

- **夸克网盘资源**：[OurPlay 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a3f9fb397b56)，转存到自己网盘后下载，拿到的是上面表格里那份 8.6.5；
- **官网与各应用商店**：[OurPlay 官网](https://m.ourplay.net/) 与主流安卓应用商店都在分发，版本随官方更新走——写这篇时商店页面显示最新为 8.7.0，你看到时可能更新，以官方页面为准。

只想尽快装上用，直接走网盘资源；想追新版本，去官网或应用商店。

## 三、安装步骤

1. 从上面任一途径把 `.apk` 文件下到手机；
2. 点开安装包，系统第一次会拦「未知来源应用」——在弹窗里允许，或到系统设置的「安装未知应用」权限里给浏览器/文件管理器放行（不同品牌叫法略有差异）；
3. 等安装完成，打开 OurPlay；
4. 第一次启动会提示下载/安装谷歌框架组件，首次耗时可能较长，让它完整跑完再进游戏——这一步的作用见 [谷歌框架与闪退处理.md](谷歌框架与闪退处理.md)。

游戏要登录谷歌账号的，账号从哪来、和 App 自己的账号怎么区分，见 [谷歌账号注册与权限说明.md](谷歌账号注册与权限说明.md)。

安装包 82 MB，加上框架组件与后续游戏本体的占用，建议手机留出至少 2~3 GB 空闲存储再开始。

## 四、装不上时的排查顺序

| 现象 | 先做什么 |
| --- | --- |
| 提示「解析包时出现错误」 | 多半是文件没下完整，重新下载一次再装（网盘资源转存后重下即可） |
| 提示「应用未安装」且手机上已装过 OurPlay | 已装版本与这次的签名不同时会冲突，先卸载已装的那份再装（应用内的数据会一起没，先备份） |
| 提示存储空间不足 | 清出足够空间再装 |
| 提示系统版本过低 | 系统低于安卓 5.0 装不了，只能先升级系统 |

装好之后，下一步是把游戏弄进来并启动加速，见 [导入游戏与加速教程.md](导入游戏与加速教程.md)；卡在别的报错上，去 [常见问题与解决方法.md](常见问题与解决方法.md) 对一下。
