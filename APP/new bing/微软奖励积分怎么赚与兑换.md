## 一、这是什么、怎么加入

微软积分商城（Microsoft Rewards）是微软的免费会员计划：你用必应搜索、用 Edge 浏览器等产品，它给你记积分，积分换礼品卡、抽奖资格或捐给公益组织。要点三条：

- **免费**，只需要一个微软账号（登录 Bing 应用用的那个就是）；
- **加入即生效**：登录后访问积分商城的仪表板（[rewards.bing.com](https://rewards.bing.com/)）就算开通，无需另外申请；
- **积分没有现金价值**，也不能转让，只能在积分商城体系内用。

## 二、怎么赚：日常任务一览

| 途径 | 积分规则（截至检索时） |
| --- | --- |
| 必应搜索 | 每次搜索 3 积分，有每日上限（等级不同上限不同，见下节） |
| 手机端搜索 | 在必应应用里搜索可得分；把必应设为默认搜索引擎、或用微软启动器，也计入移动端积分 |
| 每日任务集 / 小测验 | 仪表板里每天刷新的一批任务，点开完成即得 |
| Edge 浏览器 | 用 Edge 上网有额外积分（具体额度因地区而异） |
| 商店消费 | 在微软商店买游戏、影视、硬件按消费额返积分（等级越高倍率越高） |

两个容易踩的坑：

- **不是所有国家和地区的搜索都给积分**，以你账号所在地区的仪表板实际显示为准；
- 搜索积分有**每日上限**，到了上限当天再搜也不加 —— 想刷满的人要分时段搜，而不是一口气搜完。

## 三、等级：普通 / 银牌 / 金牌

等级按**每月赚到的积分**自动评定（数字为公开规则，随地区略有差异，以官方页面当时显示为准）：

| 等级 | 每月要求 | 必应搜索每日积分上限（每次 3 分） |
| --- | --- | --- |
| 普通 | 加入即有 | 15 |
| 银牌 | 每月赚满 500 积分 | 30 |
| 金牌 | 每月赚满 750 积分 + 完成 2 项升级活动 | 60 |

**升级活动**（升金牌需要每月完成其中 2 项，可选的有）：

1. 连续 7 天用必应搜索；
2. 连续 7 天登录必应应用；
3. 连续 7 天完成每日任务集；
4. 把必应设为默认搜索引擎并保持 14 天；
5. 持有 Xbox Game Pass Ultimate 订阅（该项因地区而异）。

等级掉下去的原因通常是某个月没赚够 —— 想保住金牌，每月月初先把每日任务和搜索上限过一遍。

## 四、怎么兑换、能换什么

登录后进积分商城的兑换页，公开的兑换档位大致是：

| 积分档位 | 可兑换 |
| --- | --- |
| 200 积分起 | 抽奖资格 |
| 1,000 积分起 | 公益捐赠 |
| 1,600 积分起 | 部分礼品卡 |
| 5,000 积分起 | 常见零售商礼品卡（官方支持页说法：换 5 美元的东西通常约需 5,000 积分） |

- 兑换项**因地区不同而不同**，你页面上能看到什么以当时显示为准；
- 积分到账有延迟，搜索分一般几分钟到隔天之间刷新；
- **12 个月内没有任何赚取活动，积分会过期** —— 偶尔登录搜一次就能保住。

## 五、在手机上把这套流程跑顺

1. 装好应用并登录微软账号（见 [下载与安装教程.md](下载与安装教程.md)）。
2. 每天打开应用，先在仪表板把「每日任务集」点完。
3. 把日常搜索都换到必应里做（顺手用用 [搜索技巧与高级语法.md](搜索技巧与高级语法.md) 的写法），把当日上限搜满。
4. 每周看一眼有没有断签的连续任务（连续 7 天类的断了要重头来）。

积分不到账、兑换页打不开这类问题，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
