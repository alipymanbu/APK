## 一、先分清两件事：关闭 ≠ 删除

按微软支持页的口径：

- **关闭搜索历史**：只是停止记录**新**的搜索，**已有的记录还在**。想让旧记录消失必须另外清除。
- **清除历史**：才是真正把记录删掉，且分「本机」和「账号」两层（见下节）。

开关位置：打开搜索历史设置页（必应页面右上角 `...` → 历史记录 / 设置里的「搜索历史记录」），把「在此处显示新搜索」关掉。关不掉时官方给的排查是：浏览器要启用 JavaScript 和 Cookie 再试。

## 二、怎么清：按登录状态选路径

| 你的情况 | 清除路径 | 删的是哪一层 |
| --- | --- | --- |
| 未登录 | 搜索历史页 → 活动列表里逐条点「清除」；或「管理或清除搜索历史记录」→「全部清除」 | 本设备 |
| 登录个人微软账号 | 微软**隐私仪表板** → 「浏览和搜索」 → 搜索历史下「清除所有活动」 | 该账号的全部记录（跨设备） |
| 登录工作/学校账号 | 搜索历史页 →「管理或清除搜索历史记录」→「全部清除」 | 该账号关联的记录 |

要点：

- 想**只删一条**（比如搜过一次的敏感词），在活动列表里点那条旁边的清除即可，不用整库清空；
- 清完**新搜的还会继续记**（只要开关还开着）—— 隐私敏感的搜索配合下一节的开关做；
- 账号层清除会跨设备生效，本机清只管本机，两者不互相替代。

## 三、让搜索更「干净」的三个设置

都在必应的设置里（网页版与应用内入口可能不同，按实际界面找）：

1. **SafeSearch（安全搜索）**：设置里把级别调到「严格」，屏蔽成人内容 —— 家里有小孩共用设备时先做这一步。
2. **个性化结果**：设置 → 更多，关闭「个性化结果」，结果不再按你的历史口味排序（配合关历史开关效果最好）。
3. **地区（Region）**：确认设置里的地区是你的实际所在国 —— 地区错了，本地的店、本地的新闻都搜不出来。

这三项都是账号/设备本地设置，改完立即生效，不需要重装应用（应用本身出问题才需要走 [常见问题与故障排查.md](常见问题与故障排查.md)）。

## 四、应用这一侧还要清什么

搜索历史是账号层面的，应用层面还有两处独立的数据：

- **搜索建议与输入残留**：应用设置里可清搜索建议记录；彻底一点就到系统 **设置 → 应用 → Bing → 存储 → 清除缓存**（注意：清除数据会退出登录，见 [下载与安装教程.md](下载与安装教程.md) 的登录说明）。
- **聊天记录**：与搜索历史**分开存**。要删某段对话，在聊天历史里打开那条对话 → 右上角 `...` → 删除；不想让对话用于个性化，可在聊天历史设置里整体关闭（入口以应用内实际界面为准）。

## 五、一个现实预期：搜索结果里的广告

结果页里的赞助位**没法按设置彻底关掉**（微软社区答复的口径是：安卓版必应的广告属于应用商业模式，无完全移除开关）；能做的只有减少「被个性化投喂」——关个性化结果、清历史，广告相关度会降。别去装声称能去广告的第三方改版包，来源不明的包风险自负。
