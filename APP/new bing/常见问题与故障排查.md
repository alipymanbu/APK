## 一、先做的三件通用事

任何症状都先过一遍这三步，能省掉后面大半无效尝试：

1. **强制停止再重开**：设置 → 应用 → Bing → 强制停止，然后重新打开。
2. **确认网络能到微软服务**：同一 Wi-Fi 下打开 [bing.com](https://www.bing.com/) 网页版试试；网页也打不开就是网络问题，不是 App 问题。
3. **确认版本**：应用商店有没有可用更新，先更到最新再看问题还在不在（网盘那份是 33.0.440325004，装完后商店再更新会覆盖，见 [下载与安装教程.md](下载与安装教程.md)）。

## 二、打不开 / 闪退 / 白屏

按顺序试，每做一步测一次，好了就停：

1. **清缓存**：设置 → 应用 → Bing → 存储 → **清除缓存**（只清缓存，不动数据，登录状态还在）。
2. **更新系统 WebView 组件**：应用内的网页内容靠 Android System WebView 渲染，它过旧会导致白屏和闪退 —— 去应用商店搜 `Android System WebView` 更新（部分国产系统没有独立组件，跳过此步即可）。
3. **清数据**：上一步无效再 **清除数据**（注意：会退出登录，需要重新登录微软账号）。
4. **安全模式排除干扰**：长按电源键 → 长按「关机」进入安全模式，此时第三方应用全部停用。安全模式里 Bing 正常，说明是某个最近装的第三方应用（清理大师、护眼、Xposed 类）在干扰，回想最近装了什么卸掉试试。
5. **重装**：卸载后重新安装（重装前确认网盘里那份还在，或直接从商店装最新版）。

如果闪退时弹「出错了，应用稍后将重启」并且**同一时段很多人都在报**（多设备、多网络都出现），那是微软服务端的问题，本地怎么折腾都修不好 —— 等一段时间自己恢复即可。

## 三、点了没反应 / 链接打不开

- **搜索建议点不开、网页跳不过去**：多半是默认应用设置冲突。检查 **设置 → 应用 → 默认应用 → 浏览器应用**，确认只指定了一个浏览器；再进 Bing 的应用信息页 →「打开默认设置」→ 清除默认值，然后重试一次。
- **只有某类链接打不开**（如二维码、文件下载）：换个浏览器作为目标打开方式测试，能定位是哪个环节拦的。
- **小窗 / 分屏下界面显示不全**：这是部分机型的适配问题（有用户反馈），退回全屏使用即可，等版本更新修复。

## 四、聊天用不了 / 一直转圈

对照症状查：

| 症状 | 先查什么 |
| --- | --- |
| 输入框上方显示未登录 / 点聊天就让登录 | 先登录微软账号，聊天功能挂在登录态上 |
| 一直转圈、超时报错 | 网络到微软服务不通（见第一节第 2 步）；换 Wi-Fi / 数据流量对比测一次 |
| 提示当前地区不可用 | 部分功能按地区开放；有用户反馈在大陆网络下聊天需要能正常访问微软服务的网络环境，普通搜索则通常可直接用 |
| 提示今天次数用完 | 每日上限到了，明天恢复，规则见 [AI聊天怎么用.md](AI聊天怎么用.md) |
| 回答弹「此内容有问题」 | 触发内容策略，换个措辞重新提问 |

## 五、登录不上

- **提示「多次输入密码错误，账号被阻止」**：这是连续输错触发的保护（有用户反馈遇到后只剩「重置密码」可点）。走重置密码流程改掉密码再登；重置前先确认不是别人在试你的账号 —— 去网页版 [account.microsoft.com](https://account.microsoft.com/) 检查登录活动。
- **开了两步验证收不到验证码**：改用验证器应用或备用邮箱收码；确认手机时间是自动时区（时间不准会导致一次性验证码校验失败）。
- **重装 / 清数据后要重新登录**：属正常现象，不是账号丢了 —— 清数据只清本机登录态，账号与积分都还在服务器上。

## 六、积分不到账、兑换出问题

按 [微软奖励积分怎么赚与兑换.md](微软奖励积分怎么赚与兑换.md) 的规则逐项对：

1. **当日搜索积分没加满**：先看是否已达当日上限（普通 15 / 银牌 30 / 金牌 60），到了上限再搜也不加。
2. **完全没积分**：确认登录的是微软账号（工作/学校账号可能不计入个人积分）；确认你所在地区支持搜索积分（并非所有地区都给）。
3. **到账延迟**：搜索分常见几分钟到隔天之间刷新，隔天再看，别当天就判「丢了」。
4. **兑换页点开就刷新 / 兑换失败**：这是应用内兑换页的已知问题（有用户反馈），换用网页版积分商城兑换可以绕开。
5. **积分快过期**：12 个月无任何赚取活动会清零，保持偶尔登录搜索即可续期。

## 七、还没解决怎么办

把这三样准备好再去微软官方支持渠道反馈，响应会快很多：**应用版本号**（设置里的关于页）、**出问题的具体步骤**（第几步、点了什么）、**截图或报错原文**。同一件事同时段多人出现的，优先搜一下是否为服务端故障，省得白折腾本机。
