## 二、下载与安装步骤

1. 打开 [Bing 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9db5d5625446)，用夸克 App 或浏览器打开分享链接，把 `new bing（先保存再下载）` 文件夹转存到自己的网盘。
2. 在网盘里下载 `new bing_v33.0.440325004.apk` 到手机存储（先下到电脑再传到手机也一样）。
3. 安卓 8.0 及以上系统安装非商店来源的 APK 时，系统会要求你给「安装未知应用」权限：打开 **设置 → 应用 → 特殊权限 → 安装未知应用**，对你用来点开 APK 的那个应用（文件管理器 / 浏览器 / 夸克）打开允许。
4. 点开 APK 文件 → 安装 → 等待完成。安装包本身 98.26M，安装时还要解压占用空间，建议给手机预留几百 MB 余量，太满会提示安装失败。
5. 装完先别删安装包，确认能正常打开、能进主界面之后再清理。

> 换手机或重装系统后不用重新找链接，转存过的网盘里那份随时可以再下。

## 三、首次启动与登录

- 首次启动**必须联网**，应用的首页资讯、搜索和聊天都实时走网络，离线状态下什么都出不来。
- 打开后会先看到引导页，跳过引导也能用普通搜索；但要使用**聊天、图片生成、积分**这些功能，需要登录微软账号（Microsoft 账号，Outlook / Hotmail / Xbox 账号都算）。
- 登录入口在应用的头像 / 账号图标里，输入账号密码后按提示完成验证即可。没有账号可以在登录页选择注册一个，注册免费。
- 登录状态会记住在本机，换设备登录同一账号可以接上你的积分与设置。

登录遇到「多次输入密码错误被阻止」「验证码收不到」这类问题，按 [常见问题与故障排查.md](常见问题与故障排查.md) 里的办法处理。

## 四、要不要更新到最新版

- 网盘里这份是记录于 2026-09-22 的 33.0.440325004 版；官方商店的版本会持续往前走，两者不是同一个东西。
- 想要新功能（比如界面改版、新的聊天能力）就去应用商店更新；商店更新会覆盖安装，聊天记录与积分跟着账号走，不受影响。
- 更新后如果出现异常（打不开、聊天报错），优先按 [常见问题与故障排查.md](常见问题与故障排查.md) 的清缓存流程处理，多数情况清一次缓存就能恢复。
