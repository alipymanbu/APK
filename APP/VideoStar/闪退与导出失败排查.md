## 一、按现象对号入座

| 现象 | 先查这一条 |
| --- | --- |
| 点安装没反应 | "安装未知应用"权限 |
| 提示解析包失败 | 安装包没下完整，重下 |
| 打开就闪退 | 存储权限、后台内存 |
| 导出一直卡在最后 | 剩余存储空间 |
| 导出完找不到视频 | 相册没刷新 |

先对着表挑中你的现象，再去对应小节按顺序试；试过一轮还不行的，看第六节。

## 二、安装环节的问题

- **权限没给到位**：设置 → 应用 → 特殊应用权限 → 安装未知应用，给你用来下载的那个 App（夸克、浏览器或文件管理器）开"允许安装"。这个开关是按应用一个个授权的，换了下载渠道就要再开一次。
- **安装包完整性**：重下之前先看文件大小是否约 11.26M；对得上还装不上，再用工具比对 MD5（`448BA638EC2F9C057CEC321B8B7E25E5`），不一致就是文件损坏，重新转存下载。
- **系统版本过低**：各渠道对这款包的系统要求标注在安卓 4.3 到 5.2 之间有出入，老设备装不上多半是版本问题，以安装时系统弹的提示为准。

## 三、打开就闪退

1. **重启手机**再开一次，能解决一大半"刚才还好好的"。
2. **清后台**：剪辑应用吃内存，后台挂着大应用时先清掉再开。
3. **查权限**：存储/照片权限被拒的话，有的应用一进选素材页面就直接退——去系统设置里把它需要的权限补上。
4. **卸载重装**：前三步都无效就重装，安装文件重新从 [VideoStar 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d3d1e011d7d3)转存下载即可，重装不会丢你手机里已有的素材。
5. **反复闪退**：确认手机系统版本是否达标；公开渠道收录的这款包版本号长期停在 1.0.x 一带，个别机型的兼容性问题未必等得到修复，长期无解就换一款剪辑工具。

## 四、导出卡住或失败

- **看剩余存储**：导出要在本地再写一份完整成片，空间不足会一直卡在最后的进度上——先清出空间再导。
- **降规格重试**：成片裁短一截，或清晰度降一档，能显著降低导出压力；先保证能出片，再逐步往上调。
- **导出期间别切走应用**，也别锁屏太久，部分机型后台限速会让导出变慢甚至中断。

## 五、导出的视频找不到

- 打开系统相册，按时间倒序翻最新的视频——最常见的原因只是相册没刷新，下拉刷新或重进一次。
- 相册里确实没有，就用文件管理器按修改时间搜当天的视频文件，找到后看它落在哪个目录，你就知道去哪认了。
- 还有一个常被忽略的落点：有开发者实测这款包导出的成片会落在应用缓存目录 `Android/data/com.marvhong.videoeditor/cache/small_video/` 下，文件名形如 `VIDEO_日期_时间.mp4`。新系统通常限制文件管理器直接进这个目录，连电脑用 USB 传输方式查看最稳。
- 用第三方相册应用的注意它可能不自动刷新媒体库，先换系统自带相册确认。

## 六、都试过还不行

安装与首次打开的完整流程回[下载与安装教程](下载与安装教程.md)再核一遍；如果问题只出在剪法上（切点不齐、节奏乱），那不是故障，去[卡点视频怎么做](卡点视频怎么做.md)对方法；确认能出片后，导出与分享的设置在[滤镜文字与导出分享](滤镜文字与导出分享.md)。
