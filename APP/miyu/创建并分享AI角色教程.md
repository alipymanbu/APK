## 一、创建入口在哪

自建角色的入口一般有两个位置，随版本不同二选一：

- 首页/角色页的**加号（+）**按钮；
- 首页左上角菜单 →「角色」→ 页面上方的「创建角色」。

点进去先给角色起个名字，确认后进入详细的设定页面。自定义角色属于登录后才解锁的功能，游客状态下可能看不到入口（见 [注册与登录方法.md](注册与登录方法.md)）。

## 二、一项一项填设定

设定项是「填得越具体，角色越稳」的逻辑。可以按下面这张表逐项过一遍：

| 设定项 | 写什么 | 写不好的后果 |
| --- | --- | --- |
| 角色名称 | 你想怎么称呼它 | 名字太泛，后续不好找 |
| 形象 / 头像 | 角色的外观 | 群聊时辨识度低 |
| 性格 | 温柔、毒舌、傲娇、沉稳等基调 | 前后性格跳变，像换了个角色 |
| 说话习惯 | 口头禅、句长、是否用语气词 | 千人一面，没有辨识度 |
| 背景故事 | 身世、职业、与你的关系 | 剧情缺铺垫，聊起来空 |
| 语音声线 | 与性格匹配的音色 | 声音与性格违和 |
| 场景 / 开场 | 初次见面所处的环境 | 开场生硬，要自己找话题 |

新手不必一次写满，先给「名称 + 性格 + 一句背景」，聊几轮觉得哪里不对再回来补。老手可以精细打磨，把说话习惯写全。

## 三、导入别人做好的角色卡

miyu 有角色卡机制：别人分享出来的角色卡，你可以直接导入使用，不用重复设定。一般流程是：

1. 从分享来源拿到角色卡（可能是一段文本、一个文件或一张分享图）；
2. 在应用内找「导入角色卡 / 添加角色卡」入口（通常在创建角色的页面里）；
3. 粘贴或选择对应的角色卡内容，确认导入；
4. 导入后在角色列表里就能看到并使用它开聊。

导入的角色卡**不代表由官方提供**，用之前看一眼人设是否合适，尤其在群聊里与其他角色互动时。

## 四、把自己的角色卡分享出去

同一个机制反过来用：

1. 进入你创建的角色详情页；
2. 找到「分享 / 导出角色卡」一类的按钮；
3. 选择生成分享内容或保存角色卡文件；
4. 把内容发给朋友，或发到你愿意发布的公开渠道。

注意分享之前确认人设里没有夹带你的个人隐私信息（真实姓名、电话、住址等），角色卡是给别人看的。

## 五、让角色不「崩人设」的几个做法

- **设定要自洽**：性格、背景、说话习惯三者别互相矛盾，否则角色会在不同轮次里反复横跳。
- **在开场里立规矩**：把称呼、关系、它的态度写进设定，比聊到一半再纠正有效得多。
- **不要用新会话做实验**：想试不同剧情，另建会话；在同一会话里反复改设定，会把上下文弄乱。
- **控制角色数量**：同屏角色越多，越容易互相带跑人设，群聊建议 2~4 个。

## 六、常见问题

- **创建按钮点了没反应**：先确认已登录，再看网络；部分版本创建入口只在「角色」页出现。
- **设定改了但角色好像没变**：已存在的会话仍沿用旧上下文，新设定通常对**新会话**生效。
- **导入失败**：角色卡内容不完整或被截断最常见，让分享方重新发一份完整内容。
- **导入后设定不全**：角色卡里没写到的项（比如声线、场景、开场白）会留空，需要你自己补上，这属于正常现象，不是导入出错。
- **创建是否需要消耗金豆**：基础创建不消耗，部分高级模板/素材会用到金豆，详见 [金豆与免费权益说明.md](金豆与免费权益说明.md)。
