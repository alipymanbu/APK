## 一、先弄清这份安装包是什么版本

miyu 是安卓手机应用，以 APK 安装包的形式分发。网盘里这一份的版本、包名与体积如下，安装前后都可以拿它对照，确认没有下错文件：

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.0.0 |
| 包名 | `im.miyu.app.xrbskzr` |
| 安装包大小 | 27.99 MB |
| MD5 | `613AB112E6C3ACFC82302EB85959D690` |
| 信息核对日期 | 2026-09-23 |

包名（`package_name`）是判断「是不是同一个应用」最可靠的依据，版本号则会随更新变化。拿到文件后，可以在手机的文件管理器里查看安装包信息核对包名，版本号对不上也不影响安装，只要包名一致即为同一应用。

想确认文件有没有下坏，可以在电脑上对安装包算一次 MD5，和上表比：

```text
certutil -hashfile miyu_v1.0.0.apk MD5
```

算出来一致，说明文件完整、没被篡改；手机上多数文件管理器不显示 MD5，核对不了也不影响安装。

## 二、从夸克网盘取包

拿到安装包有两条路：直接在网盘里下载，或先转存再下载。手机端建议**先转存**，避免分享链接后续调整后取不到文件。

1. 打开 [miyu 安装文件资源（夸克网盘）](https://pan.quark.cn/s/58ce6f344595)，链接指向该应用的安装文件目录；
2. 点「转存」把文件保存到自己的夸克网盘账号下；
3. 用手机夸克 App 打开转存后的文件，选择下载到本机；
4. 记下下载完成后的存放位置（一般在「下载」或「夸克下载」目录）。

## 三、在安卓手机上安装

1. 打开手机「文件管理」，进入上面的下载目录，找到后缀为 `.apk` 的文件；
2. 点击安装。首次安装第三方安装包时，系统会拦一下，提示「不允许安装未知来源应用」；
3. 按提示进入「设置 → 应用 → 特殊应用权限 → 安装未知应用」（不同品牌路径名称略有差异），把当前文件管理器或浏览器的开关打开；
4. 返回安装界面，继续安装，完成后点「打开」即可进入应用。

安装完成、确认能正常打开之后，可以把这个「安装未知应用」权限重新关掉，减少后续误安装的风险。

各品牌常见路径：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / Redmi | 设置 → 应用设置 → 应用管理 → 权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 外部来源应用下载 |
| OPPO / 一加 | 设置 → 安全 → 安装外部来源应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 生物识别和安全 → 安装未知应用 |

## 四、系统要求

本地这份安装包标注的系统要求是「安卓系统 5.2 以上」，另有部分公开页面标注为 Android 6.0 及以上。两处口径不完全一致，**以你安装时系统给出的提示为准**。

其它需要注意的：

- 应用需要联网使用，角色回复、语音、账号数据都依赖网络；
- 预留至少 100 MB 可用空间比较稳妥（安装包本身 27.99 MB，安装后占用会更大）；
- 安装过程中若系统提示「此应用专为旧版 Android 打造」，说明系统版本高于应用编译目标，通常仍可继续安装。

## 五、装不上 / 打不开时的处理

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析软件包时出现问题」 | 安装包没下完或被截断 | 删除后重新从网盘下载，别用浏览器中途暂停的残包 |
| 提示「应用未安装」 | 旧版本包名相同但签名不一致 | 先卸载手机上已有的旧版，再装这一版 |
| 被系统安全扫描拦截 | 纯净模式 / 应用安全检测 | 在拦截弹窗里选择「继续安装」或临时关闭纯净模式 |
| 安装键是灰的、点不动 | 存储空间不足 | 清理空间后重试 |
| 装好后闪退、停在闪屏 | 系统版本过低或安装包不完整 | 先用另一台设备交叉验证；确认是安装包问题就重新下载 |

如果重新下载、换设备测试都失败，大概率不是安装方式的问题，可以换一份来源再试。这类现象与账号无关，用同一账号登录不会受影响。

## 六、后续版本更新

应用通常会在启动时提示有新版本，按引导更新即可。也可以回到网盘目录，重新取一份较新的安装包，直接覆盖安装——覆盖安装不需要先卸载，使用同一账号登录后，自定义角色与会话数据随账号同步恢复（数据同步的具体表现见 [聊天记录保存与多设备同步.md](聊天记录保存与多设备同步.md)）。

卸装重装前，务必确认自己记得账号的登录方式，否则本机未同步的数据可能无法找回。
