## 一、本篇怎么用

按现象对号入座，每条都是从「代价最小」的动作开始试：先查权限和设置，再考虑清缓存，最后才动文件。**排查期间不要卸载重装**——保险库与扫描索引都在应用数据里，卸载可能把它们一起清掉（见 [隐藏照片与保险库功能教程.md](隐藏照片与保险库功能教程.md) 第四节）。换了新手机之后出现的整批异常，不走本篇，直接看 [换新手机后照片和保险库怎么迁移.md](换新手机后照片和保险库怎么迁移.md) 第五节的检查清单。

## 二、安装阶段

| 现象 | 原因与处理 |
| --- | --- |
| 点 APK 没反应 / 「解析包时出现问题」 | 文件没下载完整，回 [下载与安装教程.md](下载与安装教程.md) 第二节重新核对大小后重下 |
| 「不允许安装来自此来源的应用」 | 安装第三方 APK 的正常拦截，按提示给文件管理器开「安装未知应用」 |
| 「应用未安装」 | 手机里已有**同包名但签名不同**的 Aves（常见于 Play 版与第三方包混装），先卸载旧的再装 |

## 三、相册里看不到照片

按顺序查，查到哪条对上就停：

1. **权限**：系统设置 → Aves → 权限 → 照片与视频，必须是**允许全部**；选了「仅允许选中的照片」就只会显示你勾过的那批。
2. **扫描是否完成**：通知栏有没有还在跑的扫描进度；没跑完时分类导航、地图、统计都是空的。
3. **文件夹里有没有 `.nomedia`**：有的话系统与应用都会跳过整个目录（文件管理器开「显示隐藏文件」查看，非自己放的可删掉再重启手机重扫）。
4. **SD 卡 / 外置存储**：卡没挂载、被设成「手机内部存储」格式，都会让那部分照片消失；拔插一次或用读卡器在电脑上确认卡没坏。
5. **刚升级完系统**：安卓 13 起照片权限是细粒度的，系统大版本升级后常被系统重置回「仅允许选中的照片」——昨天还齐全、升级完突然少一半，第一件事就是回权限页改回「允许全部」（多份厂商与第三方排查文档口径一致）。
6. **云相册删过本地文件**：开过 Google 相册一类的「释放空间 / 已备份则删除本地」功能时，本地副本已被删、只剩云端，Aves 只认本地文件，这类照片它永远显示不出来——去对应云相册的回收站找回并下载回本地。
7. **照片其实不在了**：去系统相册或回收站对照——Aves 只显示存在的文件，不负责恢复。

## 四、扫描慢或卡在某个进度

- 扫描在前台服务里跑，**别从最近任务里划掉它**；几万张照片首次扫描几分钟属正常。
- 手机开了「省电模式 / 后台限制」会把扫描拖得很慢，跑扫描时先插上电、把省电关掉。
- **国产 ROM 的后台管理是重灾区**：华为/荣耀在「设置 → 应用 → 应用启动管理」里关掉 Aves 的自动管理、勾选允许后台活动，并在多任务界面对卡片加锁；其他品牌在「省电 / 后台运行管理」里把 Aves 设为允许后台。不放行的典型表现是：扫描通知栏走走停停、切个应用回来进度归零。
- **新照片要过很久才出现**：系统媒体扫描本身可能被电池优化推迟（有排查资料建议把系统的 Media Storage 设为「不优化」），电量过低时也会暂停扫描。最省事的触发方式就是**重启手机**，开机后会自动补扫一遍。
- 长期不更新的超大媒体库可考虑清一次缓存重建索引（设置 → 应用 → Aves → 存储 → **清除缓存**；清缓存不删照片，但索引要重扫一遍）。数据库随照片量增长会变大，照片特别多的机器上占几百 MB 属可观察到的量级，空间紧张时清缓存即可。

## 五、缩略图空白或加载慢

1. 先看手机剩余存储——空间快满时缩略图生成会失败或反复重做，腾出几个 GB 再试；
2. 清一次 Aves 缓存（同上），重启应用让它重建缩略图；
3. 单张图空白而其他正常 → 多半是这个文件损坏，换个应用打开对照（[支持哪些图片与视频格式.md](支持哪些图片与视频格式.md) 第五节）。

## 六、地图打不开 / 一片空白

- 底图是**在线瓦片**，没网就是白的；先确认网络，再试切换图层（用户反馈 Play 版的 Google 底图在国内加载不出，切 OSM 类图层可用；Libre 版本身就是 OSM）。细节见 [照片地图与EXIF信息查看.md](照片地图与EXIF信息查看.md) 第二节。
- 有照片点位、没底图 → 只是瓦片问题，照片数据没丢。

## 七、播放与显示异常

| 现象 | 处理 |
| --- | --- |
| 某个视频播不了 | 先用系统播放器对照，能播说明 Aves 对该编码支持不全，换个封装格式导出再看 |
| 动态照片只显示静止图 | 确认原机的实况开关是开着拍的；其他应用能播而 Aves 不能，去 GitHub 反馈页提 issue |
| 照片方向不对 | 单张进入编辑旋转保存；批量的去多选菜单处理 |

## 八、耗电与后台

- 正常使用时 Aves 不应在后台耗电列表里排前；**扫描期间**耗电上升是暂时的，扫完即止。
- 若它持续出现在耗电榜首：多半是媒体库频繁变更（微信自动存图、云同步一直下图）触发反复扫描，去系统电池设置里限制其后台，或清一次缓存观察。
- 提醒一下：Play 版含统计上报组件、Libre 版不含，介意的可选后者（区别见 [下载与安装教程.md](下载与安装教程.md) 第五节）。

## 九、还有问题

Aves 是开源项目，问题与需求都走 GitHub：先搜一遍 [现有 issue 与讨论](https://github.com/deckerst/aves/issues) 有没有同款，没有再按仓库的 bug 模板提交，附上机型、系统版本、应用版本（本篇安装包为 1.14.9）与复现步骤，开发者响应比较活跃。
