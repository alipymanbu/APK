## 一、本篇能解决什么

装相册前你最想知道的往往是「我手机里这些奇怪格式它打得开吗」。结论：Aves 的定位就是「什么都能看」的相册，除了日常的 JPEG、MP4，多页 TIFF、SVG、老式 AVI 这类冷门格式也在支持范围内。本篇给出完整的格式清单与几个例外情况。

## 二、图片格式支持清单

| 格式 | 说明 |
| --- | --- |
| JPEG / PNG / WebP / GIF / BMP | 日常最常见的一批，全部支持 |
| HEIC / HEIF | 新安卓机默认拍摄格式，支持 |
| TIFF（含多页 TIFF） | 每页都能翻着看，这是 Aves 明确主打的能力 |
| SVG | 矢量图，按缩略图与渲染显示 |
| AVI（老式视频） | 能识别并播放 |
| GeoTIFF | 自带地理坐标的大图，Aves 会把它当特殊媒体识别 |
| RAW | 不做原生解码，但会读出内嵌的 JPEG 预览图来看 |

以上清单中，JPEG/MP4/TIFF/SVG/AVI/GeoTIFF 是官方 README 写明的能力；BMP、GIF、WebP 的显示有实测记录；RAW 只显示内嵌预览这一点来自第三方评测，你手里的冷门格式建议直接装上试。

## 三、视频格式支持清单

| 格式 | 情况 |
| --- | --- |
| MP4 | 支持，包括 360° 全景视频 |
| AVI | 支持 |
| MOV / FLV | 有用户实测可播放 |
| WMV / MPG | 缩略图能出来，但点开播放不了（有用户反馈） |

播放能不能出声、流不流畅，跟你手机自带的解码器有关——同一文件在不同手机上表现可能不同，播不了先换个播放器（如系统相册）对照一下，确认是文件问题还是 Aves 的问题（见 [常见问题与排查.md](常见问题与排查.md)）。

## 四、识别为「特殊媒体」的类型

Aves 扫描媒体库时会额外识别这几类，识别到的会带相应标记、可直接按类型筛选：

- **动态照片**（各厂牌的 Live Photo / 实况照片）
- **全景照片**（也叫照片球、Photo Sphere）
- **360° 视频**
- **GeoTIFF**

怎么看这几类，见 [动态照片与全景照片查看方法.md](动态照片与全景照片查看方法.md)。

## 五、遇到打不开的格式怎么办

1. **先确认文件本身没坏**：换个应用（系统相册、文件管理器预览）打开同一个文件，别的应用也打不开就是文件损坏，不是 Aves 的问题。
2. **确认扩展名没写错**：`.jpg` 被改成 `.txt` 之类，系统与应用都会认不出真实类型。
3. **确实不支持的格式，先转一道**：Aves 自带把选中的图片导出转换为 BMP / JPG / PNG / WEBP 的功能（在多选后的操作菜单里），可以先把文件转成通用格式再看。

## 六、它不做的事

- 不做云端同步与备份——照片只在你手机本地，备份要自己用系统工具或电脑做。
- 不做人脸识别分类。
- 编辑能力只有旋转、裁剪、亮度调节这一档，没有滤镜、曲线之类的修图功能（这是第三方评测的口径，以应用内实际菜单为准）。

需要把照片转格式、批量改名，接着看 [隐藏照片与保险库功能教程.md](隐藏照片与保险库功能教程.md)。
