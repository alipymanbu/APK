## 一、这是什么应用

Aves（全称 Aves Gallery）是一款开源的安卓相册与元数据浏览应用，作者是 Thibault Deckers，代码以 BSD 3-Clause 许可证公开在 GitHub 上。它不依赖云服务，照片全部留在你的手机本地，界面无广告。适合想把手机里上万张照片按相册、标签、地点、日期快速翻找的人，也适合需要查看照片 EXIF 元数据、需要打开冷门图片格式的人。

本篇对应的安装包版本为 **1.14.9**，包名 `deckers.thibault.aves`，安装包大小 148.70M，该包信息记录于 2026-09-23。网上能搜到的多是官方最新版，可能与这份不是同一版；版本号、包名、体积一律以本篇开头记录的信息为准。

## 二、从网盘获取安装文件

1. 打开 [Aves相册 安装文件资源（夸克网盘）](https://pan.quark.cn/s/596ef257c8ac)。
2. 登录夸克后选择转存到自己的网盘，再从网盘下载到手机（或先下到电脑再传手机）。
3. 文件名形如 `Aves相册_vv1.14.9.apk`，下载完成后核对一下大小是否接近 148.70M，差距太大说明没下完整，重新下载。

## 三、安装步骤

1. 在手机文件管理器里点击该 `.apk`。
2. 系统会提示「不允许安装来自此来源的应用」——这是安装第三方 APK 的正常拦截，点提示进入**安装未知应用**权限，给文件管理器（或浏览器）开启允许，返回继续安装。
3. 安装完成后先别急着打开，看第四节把权限准备好。

> 如果点了没反应、或提示「解析包时出现问题」，一般是文件没下载完整，参照 [常见问题与排查.md](常见问题与排查.md) 处理。

**进阶：核对安装包签名**（可选）。官方 GitHub 仓库公布了签名证书指纹（证书主体 `CN=Thibault Deckers`，有效期 2016-12 至 2041-12）：

```text
SHA1:  59:A5:00:13:FA:7A:2F:97:91:1B:52:D6:81:CA:FA:EB:F8:35:05:E8
SHA256: F4:79:47:27:E4:54:16:D8:7C:48:71:38:29:2B:70:9F:11:D1:CD:7D:AB:55:84:D8:C6:85:7D:92:E0:66:60:4B
```

用 Android SDK 里的 `apksigner print-certs` 读出手中 APK 的指纹与上面比对，一致才是官方签名的包；对不上的来源别装。指纹本身也以官方仓库当时公布的内容为准。

## 四、首次启动与权限

1. 打开应用，先是一屏欢迎页，需要勾选同意使用条款后才能继续；页面上的「应用事件统计」「匿名错误上报」可以先不勾，以后随时能在设置里改。
2. 接着会请求**照片、媒体与文件访问权限**，点允许——不给这个权限，Aves 一张照片也读不到。
3. 进入主界面后它会自动在后台扫描媒体库，通知栏能看到扫描进度。**首次扫描要等它跑完**，分类导航、照片地图、统计这些功能才有数据（几万张照片的机器要多等几分钟）。

各权限的用途（来自官方仓库的权限说明）：

| 权限 | 用途 |
| --- | --- |
| 读取图片/视频、媒体位置 | 读取你的媒体库与照片里的定位信息 |
| 修改/删除共享存储内容 | 在应用内删除、移动照片 |
| 前台服务、通知 | 后台扫描时显示进度 |
| 网络 | 地图底图加载与地名反查 |
| 设置壁纸、生物识别 | 分别用于「设为壁纸」与保险库解锁 |

## 五、Play 版与 Libre 版的区别

同一份代码官方打包了两个版本，装之前先分清：

| 对比项 | Play 版（本篇安装包） | Libre 版 |
| --- | --- | --- |
| 包名 | `deckers.thibault.aves` | `deckers.thibault.aves.libre` |
| 分发渠道 | Google Play，以及各软件站 | F-Droid |
| 地图 | 集成 Google 地图 | 换成 OpenStreetMap |
| 统计组件 | 含 Firebase 统计 | 无任何统计组件 |
| 最低系统 | 有用户反馈为 Android 5.0+（以渠道页显示为准） | F-Droid 页标注 Android 7.0 及以上 |

两个版本功能基本一致，可按需选择；但**同一台手机上装哪个就用哪个**，两个包名不同，会当成两个应用，各扫各的媒体库。表里最低系统那一栏的口径来自渠道页面与用户反馈，装不上时先核对系统版本。

## 六、覆盖安装与更新

- 手里已有旧版 Aves 的话，直接安装本包即可覆盖升级，照片与设置都保留（包名相同才会覆盖，即 `deckers.thibault.aves` 盖 `deckers.thibault.aves`）。
- 从 Play 版换到 Libre 版（或反过来）属于两个不同应用，不能覆盖，得先装一个再装另一个，且媒体库会重新扫描一次。
- 版本号命名就是常见的三段式 `x.y.z`，更新节奏不定，以 [官方 GitHub 仓库](https://github.com/deckerst/aves) 的更新记录为准。
- **换新手机**不属于覆盖安装，照片与保险库要单独搬，见 [换新手机后照片和保险库怎么迁移.md](换新手机后照片和保险库怎么迁移.md)；拿不准要不要从系统相册换过来，先看 [和系统相册有什么区别.md](和系统相册有什么区别.md)。
