# GloryFit 消息提醒收不到的排查

> 手表不震、来电不提醒、App 消息推不过去，按这篇从 App 内到系统逐层查。
> **相关文档**：[手表绑定与连接.md](手表绑定与连接.md) · [数据同步问题怎么解决.md](数据同步问题怎么解决.md)

---

## 一、先建立一个判断口径

手表只会转发**手机通知栏里出现了的**消息。你在聊天软件里正开着那个会话、或在电脑端挂着同一账号，手机状态栏不弹通知，表就不会震 —— 这不是表坏了。所以排查永远是三段：**App 内开关 → 手机系统通知权限 → 蓝牙与后台**。

## 二、App 内的开关（第一层）

1. 设备页进你已连接的手表，找「消息通知 / App 提醒」，总开关打开。
2. 在列表里把要提醒的 App 逐个勾上（微信、QQ 等要单独开，开了总开关不等于全开）。
3. 来电、短信提醒另外要**联系人权限、电话权限、通话记录权限、短信权限**都已允许 —— 安卓安装时若点了「禁止」，就去系统「设置 → 应用 → GloryFit → 权限」里逐项改开。
4. 有的表走辅助功能读通知：如果装的时候权限没给全，公开 FAQ 给的建议是**卸载重装、安装时权限全给**，再进「辅助功能」里把 GloryFit 的消息通知开关打开。

## 三、手机系统这一层（第二层）

**安卓**：
- 「设置 → 通知」里找到对应聊天软件，「允许通知」打开，并把横幅、锁屏通知都勾上；
- 同一设置页里找到 GloryFit，也确认它的通知权限没被关。

**iPhone**：
- 「设置 → 通知」逐个 App 打开「允许通知」与「在通知中心显示」；
- iOS 13 及以上若把「显示预览」设成了「从不」，系统就不再把内容下发给表，改成「始终」或「打开 App 时」；
- 「设置 → 蓝牙」里确认这块表是已连接状态、名字后面没有感叹号。

## 四、勿扰与振动（最容易白查的一层）

- 表上「设置 → 勿扰模式」开着的话，来消息只静默不提醒 —— 关掉。
- 表的「设置 → 振动设置 → 振动强度」关着时，收到推送不震；有的提醒只震动不亮屏，属于正常表现。
- 正在电脑上挂着微信 / WhatsApp 等：手机端不出通知栏横幅，表侧自然没反应。

## 五、安卓后台保活（长期根因）

安卓 6.0 起系统会主动清理后台应用，App 被清后来电提醒、通知转发、定位运动都会失灵。要给 GloryFit 做两组设置（公开 FAQ 给出的路径，各品牌菜单名略有差异）：

**省电保护**：

| 品牌 | 路径 |
| --- | --- |
| OPPO | 设置 → 电池 → 省电保护 → GloryFit → 允许后台运行 |
| 华为 | 设置 → 电池 → 锁屏后清理应用 → GloryFit → 不清理 |
| 三星 | 设置 → 常规 → 电池管理 → 不受监控的应用 → 添加 GloryFit |

**自启动**：

| 品牌 | 路径 |
| --- | --- |
| OPPO | 设置 → 应用管理 → GloryFit → 允许后台运行 → 开 |
| 华为 | 设置 → 应用管理 → GloryFit → 权限 → 单项权限设置 → 自启动 |
| 三星 | 设置 → 电池 → 智能管理器 → 自动运行应用程序 → GloryFit |

另外把 GloryFit 在「最近任务」里下拉加锁（有的品牌是点锁形图标），手机重启后这把锁会失效，需要重新加。

## 六、还是不行的兜底顺序

1. 关蓝牙再开，确认设备页显示已连接（连接状态先看 [手表绑定与连接.md](手表绑定与连接.md)）。
2. 杀掉 GloryFit 后台重开。
3. 重启手机，重新连接手表。
4. 数据不同步与提醒失效常同时出现，若伴随步数、心率不更新，接着查 [数据同步问题怎么解决.md](数据同步问题怎么解决.md)。
