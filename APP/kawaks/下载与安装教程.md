## 一、这是个什么应用

Kawaks 是一套街机模拟器的名字：Windows 上的桌面版由 Kawaks 团队维护（官网 [winkawaks.org](https://winkawaks.org/)），而你在手机上装的这个是**安卓版街机模拟器**（包名 `com.kawaks`），界面是中文的，游戏按「对打格斗 / 动作过关 / 飞行射击 / 益智休闲」四类整理。它本身是个运行环境，**不带游戏文件**——游戏要另外准备，做法见 [导入游戏ROM教程.md](导入游戏ROM教程.md)。

先把版本事实摆清楚（以手头这份安装包为准，网上各下载页写的最新版未必是它）：

| 项目 | 值 |
| --- | --- |
| 版本号 | 5.2.7 |
| 包名 | `com.kawaks` |
| 安装包大小 | 38.93M |
| MD5 | `DADBEC7E63306771AB92B926C56865D2` |
| 界面语言 | 简体中文 |

系统要求各下载页标注不一（有写安卓 4.5 以上、有写安卓 5.2 以上），**以你实际下载页面当时显示为准**；5.2.7 的更新说明里明确写了「兼容安卓 9」，所以安卓 9 及以上的手机优先装这个版本。

## 二、从网盘拿到安装包

1. 打开 [Kawaks 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4023d23a5d58)，把分享内容转存到你自己的网盘（不转存直接下载也行，转存后文件更不容易失效）。
2. 在网盘里找到安装包下载到手机或电脑，文件名带版本号（形如 `kawaks_v5.2.7.apk`）。若分享里的文件名与这个有出入，以下面的 MD5 为准。
3. 只认 MD5，不认文件名——不同渠道的包同名不同料很常见，核对方法见下一节。

## 三、核对 MD5（建议做，30 秒）

MD5 是文件的「指纹」，对上了才说明你下到的就是这份 5.2.7。手机上可用任意校验类 App；在电脑上用 PowerShell：

```powershell
(Get-FileHash -Algorithm MD5 .\kawaks_v5.2.7.apk).Hash
```

输出应为 `DADBEC7E63306771AB92B926C56865D2`（不区分大小写）。对不上就别装了，换份重新下。

## 四、安装步骤

1. 把 APK 传到手机（数据线、网盘 App 下载都行），用文件管理器点它开始安装。
2. 系统会拦「未知来源应用」——这是正常的安全提示。按提示进入设置，允许**这个文件来源**安装应用（安卓 8 以上是按来源逐个授权，不是以前的一个总开关）。
3. 装完首次打开，会索要文件/存储权限。**这一步建议允许**：模拟器要靠它读你放在存储里的游戏文件，拒绝后大概率扫不到游戏，得回设置里手动补授权。
4. 进入主界面是横屏布局，游戏分成四类，右侧带下载按钮，底部或角落是导入与设置入口。

## 五、首次启动后先确认两件事

- **权限**：设置里看一眼存储权限是否给了；
- **版本**：设置或「关于」里能看到版本号，确认是 5.2.7。

装好之后，下一步是让应用能找到游戏文件，见 [导入游戏ROM教程.md](导入游戏ROM教程.md)；按键和手柄见 [手柄与按键设置教程.md](手柄与按键设置教程.md)。

## 六、安装失败的三种常见原因

| 现象 | 原因与处理 |
| --- | --- |
| 点安装后提示「无法安装」 | 手机里已有同包名但**签名不同**的旧版（来自别的渠道）。先卸载旧版再装；注意卸载会清掉旧版的应用数据 |
| 提示解析错误 / 文件损坏 | 下载不完整或中途改名，重新下并核对 MD5 |
| 提示存储空间不足 | 先清理空间再装；安装过程需要临时解压，留出比 38.93M 更宽裕的余量 |

装不上且反复重试无效时，先按 [常见问题与故障排查.md](常见问题与故障排查.md) 逐条排；安装包本身损坏就回到第二节重新下。
