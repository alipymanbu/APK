## 一、装不上 / 安装失败

| 现象 | 处理 |
| --- | --- |
| 提示无法安装 | 手机里有同包名、签名不同的旧版，先卸载再装（卸载会清旧版数据） |
| 提示解析错误 | 安装包下载不完整，重新下并核对 MD5（步骤见 [下载与安装教程.md](下载与安装教程.md)） |
| 空间不足 | 清出比 38.93M 宽裕的余量再装 |

## 二、打开就闪退

按顺序试，多数能命中：

1. **先看版本**：5.2.7 的更新说明明确包含「兼容安卓 9」——安卓 9 及以上系统用老版本闪退的反馈很集中，装 5.2.7 即可；
2. **给存储权限**：系统设置 → 应用 → 该应用 → 权限，把存储/文件访问打开；首次安装时拒绝过就会这样；
3. **关掉后台省电限制**：部分机型的省电策略会杀掉模拟器进程（表现是切出去回来就没了、或启动瞬间退出），把该应用设为不优化/允许后台；
4. **清缓存而不是清数据**：设置里清缓存是安全的；清数据会连键位与即时存档一起清掉（后果见 [存档与游戏进度保存.md](存档与游戏进度保存.md)）。

## 三、游戏列表是空的 / 扫不出游戏

这条几乎全是路径问题，排查顺序：

1. ROM 文件是不是**原样 zip**——解压过就识别不了，压回去（见 [导入游戏ROM教程.md](导入游戏ROM教程.md) 第二节）；
2. 路径里**有没有中文**——换成纯英文路径再扫；
3. 路径指对没有——列表界面右下角两个箭头 →「更改 rom 路径」→ 指到放 zip 的文件夹 → 重新扫描；
4. 存储权限给了没——没权限应用读不到任何文件；
5. 文件在不在**内置存储**——外部 SD 卡上的路径更容易出权限问题。

## 四、提示缺少 BIOS / 进不去游戏

只有 **NeoGeo 类游戏**（拳皇、合金弹头、侍魂等）需要：把 `neogeo.zip` 放进**与游戏 zip 同一目录**，不解压不改名。CPS1/CPS2 的游戏不需要它，扫不出它们是别的原因，回第三节查。提示缺的是**游戏自身的某个文件**（不是 BIOS）时，多半是区域版依赖的主版本缺失，处理办法见 [能玩哪些街机游戏.md](能玩哪些街机游戏.md) 第三节。

## 五、游戏能进但卡顿 / 发热

1. 关掉后台应用，释放 CPU 与内存；
2. 在设置里切换**渲染模式**、调低渲染分辨率——低配机上收益明显（具体选项名以 5.2.7 界面为准）；
3. 跳帧/帧率限制类选项按默认即可，乱调容易造成不同步；
4. 高刷屏机型若画面撕裂，把帧率限制在 60 帧更稳。

## 六、黑屏但有声音

多为渲染模式与机型不兼容：进设置把渲染模式换一个（如在硬件渲染与兼容/软件渲染之间切换），**完全退出应用再重进**——只切设置不重启常不生效。反复黑屏的，结合第二节查权限与版本。

## 七、手柄不识别 / 按键错乱

1. **先配对再进应用**，顺序反了常识别不到；
2. 个别品牌手柄默认映射对不上，在键位设置里**逐键重新映射**；
3. **双人手柄打架**（抢输入、串键）：5.2.7 更新说明写了「修复双手柄冲突」，确认两台设备/两个手柄都跑在 5.2.7；
4. 改乱了先恢复默认布局再小幅调（见 [手柄与按键设置教程.md](手柄与按键设置教程.md)）。

## 八、联机失败、房间进不去

联机的前提、房间密码、观战规则与逐步排查都在 [联机对战与游戏大厅.md](联机对战与游戏大厅.md)；本篇第五节的卡顿处理同样影响联机手感。

## 九、游戏没有声音

先排除与模拟器无关的四种情况，多数无声到这一步就解决了：

1. **媒体音量**：按音量键把滑块调到媒体那一档——很多机型铃声音量和媒体音量是分开的，响铃正常不代表游戏有声；
2. **勿扰/静音模式**：系统处于勿扰或静音会直接吞掉游戏声音，关掉再试；
3. **蓝牙抢占**：连着蓝牙耳机或音箱时，声音被输出到那个设备上了——关掉蓝牙或断开设备，回放游戏确认；
4. **应用内音量**：模拟器菜单里若有独立的音量/声音开关，确认没被静音。

以上都正常仍无声：完全退出应用再进（临时的音频通道故障重启就好）、按第二节第 4 条清一次缓存；只有耳机有声或只有外放没声，则是设备侧问题，与模拟器无关。

## 十、拿不准版本时怎么核对

各下载页写的版本号、大小五花八门，**以文件本身为准**：对 MD5（`DADBEC7E63306771AB92B926C56865D2`）与包名 `com.kawaks`（设置 → 应用信息里可看）。对得上就是这份 5.2.7、38.93M 的包；对不上就按 [下载与安装教程.md](下载与安装教程.md) 第三节重新核对。
