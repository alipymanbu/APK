## 一、为什么会有两个「pubmed」

混淆的来源很直接：

1. 官方 PubMed（`https://pubmed.ncbi.nlm.nih.gov`）是美国国家医学图书馆（NLM）旗下 NCBI 运营的文献检索站，是医学领域最常用的公共检索入口。
2. 而你手上这份安装包（网盘与不少下载站把它命名为「pubmed 手机版 / pubmed 中文版」）的实际产品是 **Info X Med**，开发者是医赋知识（北京）科技有限公司，包名 `com.example.infoxmed_android`。

两者是不同公司的不同产品，只是都做医学文献检索。「pubmed 手机版」是渠道侧沿用的叫法，不代表它是官方 PubMed 的官方手机客户端——官方 PubMed 没有授权过任何一款叫这个名字的 App。

## 二、官方 PubMed 是什么

- 运营主体：美国国家医学图书馆 NLM / NCBI。
- 内容：收录 MEDLINE、生命科学期刊与在线图书的文献引文，规模在 4000 万条以上（官方页面口径，随时间增长）。
- 访问：浏览器打开官网即可检索，免费、无需登录；提供高级检索、临床查询（Clinical Queries）、单一引文匹配器、MeSH 主题词表等工具。
- 全文：引文页面可能带有 PubMed Central 全文或出版社站点链接，但拿不拿得到全文取决于文献本身的开放情况。

## 三、Info X Med 是什么

- 运营主体：医赋知识（北京）科技有限公司，定位是面向医疗从业者的中文医学知识平台。
- 数据面：官方页面标注 4000 万+ 医学数据、15 万+ 指南、8 万+ 循证数据、80 万+ 自然基金、50 万+ 药典数据（截至 2026-09 核对）；高校图书馆的介绍里还提到聚合 Elsevier、Ovid、SpringerLink、Wiley 等出版社资源。
- 功能面：中文界面里集成检索、标题与摘要翻译、段落译文、AI 工具（AI 解读、PDF 对话、科研助手等）。
- 形态：App（安卓 / iOS）+ 网页端 `https://www.infox-med.com` + 微信小程序。
- 收费：基础功能注册可用，会员与全文服务走内购或机构授权（见[免费与会员权限对照.md](免费与会员权限对照.md)）。

## 四、并排对照

| 维度 | 官方 PubMed | Info X Med（pubmed 安装包对应产品） |
| --- | --- | --- |
| 主体 | 美国 NLM / NCBI | 医赋知识（北京）科技有限公司 |
| 访问形态 | 网站为主 | App + 网页端 + 小程序 |
| 界面语言 | 英文 | 中文为主 |
| 检索免费 | 是，无需登录 | 注册后可用基础检索 |
| 全文获取 | 取决于文献开放情况与链接 | 平台侧提供 PDF 服务，权限随账号状态 |
| 翻译 | 无（自己复制去翻） | 标题 / 摘要 / 段落翻译内置 |
| AI 工具 | 无 | AI 搜索、AI 解读、科研助手等（见[AI工具与科研智能体用法.md](AI工具与科研智能体用法.md)） |
| MeSH 支持 | 有专门的 MeSH 主题词表 | 支持 MeSH 搜索方式 |
| 额外数据库 | 无（纯文献引文） | 题库、药典、国自然基金、指南等 |
| 权威用途 | 引文核对、投稿引用的出处 | 日常中文阅读与辅助 |

## 五、按你的需求选

- 要写论文、需要**权威的引文出处**：去官方 PubMed 核对，引文信息以它为准。
- 要**中文界面**读英文文献、要翻译、要 AI 辅助：对照第三节的清单，看它的功能是否覆盖你的场景。
- 两者可以配合使用：App 用来日常读，官方站用来核对与导出引文。
