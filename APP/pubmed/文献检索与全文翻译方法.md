## 一、搜索框支持哪几类输入

| 输入内容 | 适合的场景 |
| --- | --- |
| 中英文关键词 | 只有大概方向，想看某个主题下有什么文献 |
| 英文标题 | 手上已有标题原文，想找这一篇 |
| DOI | 精确定位某一篇，结果最准 |
| PMID | 从 PubMed 等渠道抄来的编号，直达同一条记录 |
| 自然语言问题 | 用 AI 搜索问一句完整的话，让系统替你拆解 |
| MeSH 主题词 | 按医学主题词表检索，查全比裸关键词稳 |
| 检索式 | 把多个条件组合成式子一次执行，进阶用法 |

关键词、标题、DOI、PMID 是平台明确的检索条件；高校图书馆的产品介绍里还列出了中英文搜索、AI 搜索、检索式搜索与 MeSH 搜索等搜索方式。不确定功能入口在你这个版本里叫什么名字时，以 App 内搜索框旁的选项为准。

## 二、高级检索怎么用

当你需要把范围收窄时，从搜索入口旁的高级检索（Advanced）进入，按字段组合条件：

1. 选择要限定的字段（如标题、作者、摘要、期刊）。
2. 填入对应内容，多个字段组合可明显缩小命中范围。
3. 执行检索，再在结果里筛选。

已知某篇文献的期刊名与发表年份时，用「期刊 + 关键词」的组合通常比裸关键词快得多。

## 三、结果页每个字段是什么意思

一条检索结果通常包含：

- **英文标题 + 中文标题**：平台会给出自动翻译的中文标题，先看中文标题能快速判断是否相关。
- **期刊名**：来源期刊，注意正规期刊名（如 JAMA、BMJ）。
- **作者列表**：超出展示数量的作者会折叠。
- **摘要**：可直接读英文摘要判断是否值得拉全文。
- **DOI**：需要精确引用或去别处核对时用。
- **影响因子（IF）与中科院分区**：官方检索结果页会直接标注，例如某条 JAMA 文献标注 IF 65.4、医学 1 区。

## 四、全文 PDF 怎么拿

1. 结果列表里带 **PDF 标记**的文献，说明平台侧有 PDF 可看。
2. 点进文献详情，滑到页面末尾，右下角是文献下载图标（多个渠道的使用说明口径一致）；阅读中支持在线分屏浏览与按段翻译。
3. 下载的 PDF 可存到本地再看。

两点提醒：

- 没带 PDF 标记的条目，不一定能直接拿到全文，这与该篇文献的收录情况有关。
- 原文下载这类涉及版权内容的功能，与你的账号权限有关——免费注册账号与 VIP、机构授权拿到的可下载范围不同，详见[免费与会员权限对照.md](免费与会员权限对照.md)。

## 五、翻译功能在哪里

| 位置 | 作用 |
| --- | --- |
| 检索结果页 | 英文标题自动带中文翻译 |
| 文献详情页 | 摘要一键翻译成中文 |
| 正文阅读中 | 按段落翻译（段落译文） |
| 详情页 AI 翻译 | 整篇全文翻译，译后可与原文对照阅读 |

常用的顺序是：先看中文标题筛掉不相关的，再对剩下的读中文摘要，最后只对真正要精读的那几篇拉全文。翻译没反应或报错时，看[常见问题排查.md](常见问题排查.md)里的对应条目。
