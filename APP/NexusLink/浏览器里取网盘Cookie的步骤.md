# NexusLink 登录用的网盘 Cookie 获取步骤

> 本篇讲怎么从浏览器里把网盘 Cookie 取出来，供 NexusLink 的 Cookie 导入登录使用；不想折腾凭据的，直接用账号密码方式登录。
> **相关文档**：[网盘账号登录与Cookie导入.md](网盘账号登录与Cookie导入.md) · [解析失败与下载问题排查.md](解析失败与下载问题排查.md)

> **NexusLink 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/e3767fd79f86](https://pan.quark.cn/s/e3767fd79f86)

Cookie 导入是 NexusLink 两种登录方式里不用填密码的那种，两种方式的差别见 [网盘账号登录与Cookie导入.md](网盘账号登录与Cookie导入.md)。取 Cookie 最顺手的工具是电脑上的 Chrome 或 Edge，手机浏览器一般没有查看入口。下面的步骤以 Edge 为例，Chrome 的菜单名称基本一致。

## 一、准备：先在浏览器里登录网盘

1. 电脑上打开 Chrome 或 Edge，访问你要接入的那家网盘网页版并登录；
2. 登录成功、能看到自己的文件列表后再进行下一步 —— 没登录成功，取到的 Cookie 是无效的。

## 二、从开发者工具里取 Cookie

1. 在网盘页面按 `F12` 打开开发者工具；
2. 切到「网络 / Network」标签，按 `F5` 刷新页面，让页面自己发出请求；
3. 点开列表里第一条指向该网盘域名的请求，在「请求标头 / Request Headers」里找到 `Cookie:` 开头的那一行；
4. 选中冒号后面的整串内容复制（一长串用分号隔开的键值对），这就是要导入的 Cookie。

也可以走「应用 / Application → 存储 → Cookie」的分类目录按域名逐条查看。两个入口取到的内容一致，网络标签的方式一步能拿整串，不容易漏。不同版本浏览器的菜单位置略有差异，找不到时按名称搜一下设置。

## 三、导入与验证

1. 回到手机上的 NexusLink，把 Cookie 粘贴进对应网盘的登录入口；
2. 随便解析一条该网盘的分享链接，验证登录是否生效；解析不出来时先按 [解析失败与下载问题排查.md](解析失败与下载问题排查.md) 排除链接本身的问题；
3. 据下载站介绍，Cookie 有效期约 30 天，到期后按上面步骤重新取一次。

两点提醒：部分网盘会校验登录环境，取出来的 Cookie 不保证家家都能导入成功，失败就退回账号密码方式；Cookie 等同于你账号的钥匙，只导入给自己的设备，来路不明的不碰，自己的也别外传。
