## 一、无法发布影评，点发布没反应

按顺序查这四处：

1. **网络是否正常**：影评要提交到服务器，先确认联网稳定；
2. **内容是否合规**：带违规词汇的内容发不出去，精简措辞再试；
3. **重启应用**：退出再进，重新编辑一次；
4. **清缓存再试**：还不行就去系统设置 → 应用 → SeedHub → 存储里清缓存；清的是临时数据，若之后要重新登录，登录一次即可。

## 二、剪辑时导入不了视频片段

1. **先看格式**：确认视频在支持范围内 —— SeedHub 支持 MP4、MOV 等常见格式，其他格式先转成 MP4 再导；
2. **再看权限**：系统设置 → 应用 → SeedHub → 权限，确认存储/照片与视频权限已开（补权限步骤见[下载与安装教程.md](下载与安装教程.md)）；
3. 权限和格式都正常还是导不进，重启应用后重试；v1.0.4 的更新说明提到修复过「部分视频片段导入后无法剪辑」的问题，低版本先升级再试。

## 三、视频无法保存或分享

按这三层查：

1. **存储空间**：保存前先确认手机剩余空间够放成片；
2. **分辨率**：按设备性能挑合适的导出分辨率，一味拉最高可能超出设备负荷导致失败；
3. **重启再导**：前两步都排除后，重启应用重新导出一次（导出速度受版本影响，见[视频剪辑与导出教程.md](视频剪辑与导出教程.md)）。

## 四、社区里搜不到想看的作品

1. 核对片名是否打对；
2. 换**别名**或**外文原名**再搜一次 —— 同一部片的叫法经常不止一种；
3. 还是没有，到社区反馈板块提交这部片的名称，等影视库补充。

## 五、装不上 / 打开闪退

| 现象 | 处理 |
| --- | --- |
| 提示不允许安装此来源 | 按安装弹窗引导打开该来源的允许开关，返回重装（详见[下载与安装教程.md](下载与安装教程.md)） |
| 提示应用未安装 | 手机剩余空间不足，或与已装版本签名冲突 —— 先卸载旧版再装 |
| 装完一点就闪退 | 先重启手机；再看存储是否见底、系统是否过旧；仍闪退则重新下载安装包 |
| 怀疑安装包没下完整 | 核对版本 v1.0.4、包名 com.qlbkru.hajisdvwx、大小 115.95M、MD5 542AE28818CFEF38A1C0704F0EF2A310，与[下载与安装教程.md](下载与安装教程.md)里的表一致才算对 |

闪退若只发生在某一步（比如每次导入素材就退），转到对应功能篇按步骤定位：剪辑类看[视频剪辑与导出教程.md](视频剪辑与导出教程.md)，内容加载类看[新手使用教程.md](新手使用教程.md)。

## 六、页面刷不出来 / 加载慢

1. 先换网络试一次（Wi-Fi 与移动数据互切），排除当前网络问题；
2. 检查是不是开了会拦截广告或请求的工具，关掉再试；
3. 清一次缓存后重启应用；
4. 若你的版本带省流量模式，注意它可能压低了画质，造成「画面糊」的错觉而非加载失败。

## 七、意见反馈与举报入口

遇到违规内容或想反馈问题，一般路径是：【我的】→【意见与反馈】，在帮助中心里选对应分类提交；举报违规内容选「违规举报」一类的条目，填文字描述、附截图并留联系方式后提交。入口名称随版本可能微调，找不到时在【我的】页面里找「反馈」「帮助」字样。注意部分功能需联网才能提交。

## 八、导出提示成功，相册里却找不到成片

保存没报错但相册刷不出来，按这个顺序找：

1. **换个相册分类看**：不少导出的视频不进「相机」相册，而落在「视频」「其他相册」或某个新建相册里，把相册切到「全部」滑一遍；
2. **用文件管理器按时间找**：打开文件管理器 → 内部存储，按修改时间倒序看 `Movies`、`DCIM`、`Pictures` 这几个文件夹 —— 应用导出的视频通常落在其中一处；
3. **还没找到就重启手机**：安卓的媒体库需要重新扫描一次，重启后新落盘的文件才会出现在相册里；
4. 以上都试过仍没有，说明导出实际失败了，回到第三节按「视频无法保存或分享」重查。
