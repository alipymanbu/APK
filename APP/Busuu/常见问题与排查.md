# Busuu 常见问题与排查

> 这篇把 Busuu 用起来最常碰到的几类问题按「现象 → 先做什么 → 还不行做什么」整理成清单：课程打不开、进度不同步、装了打不开、订阅没生效、设备不兼容、找客服时要带什么。

## 一、先看结论

Busuu 官方给的排查思路基本是两条：**帐号类问题（进度、订阅）先重新登录一次**，**异常行为（闪退、卡住、白屏）先卸载重装一次**。下面按具体现象展开，每一条都先给最省事的动作。做完仍不行的，第八节有找客服前要准备的东西。

## 二、课程打不开 / 卡住 / 白屏

按顺序做：

1. **先确认网络**，切一次 Wi-Fi 与移动数据再看；
2. **完全关闭应用再打开**（从后台划掉，不是退回桌面）；
3. **检查系统版本**：把手机系统更新到官方支持的最新版本，见 [下载与安装教程.md](下载与安装教程.md) 第二节；
4. **卸载重装**：卸载 → 强制重启手机 → 重新安装 → 登录同一帐号。这一步不会丢进度（进度在帐号上，见 [注册登录与多设备同步.md](注册登录与多设备同步.md)）。

⚠️ 卸载重装会清掉已下载的离线课程，需要重新下载，见 [离线下载与省流量.md](离线下载与省流量.md)。

## 三、进度不同步 / 记录对不上

这是最容易被误判成「丢数据」的一类。实际成因通常是三选一：登错帐号、还没同步、页面没刷新。

| 现象 | 最可能的原因 | 先做什么 |
| --- | --- | --- |
| 换设备后进度是空的 | 登录方式或帐号和原来不一样 | 按 [注册登录与多设备同步.md](注册登录与多设备同步.md) 第二节确认登录方式 |
| 刚学完切设备没看到 | 同步尚未完成 | 等一会儿，下拉刷新首页 |
| 离线学的内容没上去 | 还没恢复联网同步 | 联网后打开一次应用 |
| 电脑网页版显示旧进度 | 页面挂着没刷新 | 刷新页面或重新登录网页版 |

手机端的标准动作是：**「我的 → 设置 → 退出登录」→ 完全关闭应用 → 重开 → 重新登录**。做完仍对不上，再进第八节。

## 四、装了打不开 / 提示解析包错误

对应到安装环节的基本是三类问题：

- **解析包错误、应用未安装**：安装包下载不完整，或包与系统版本不匹配。按 [下载与安装教程.md](下载与安装教程.md) 第三节核对体积、MD5 后重下一遍；
- **提示已存在更高版本**：手机上已有更新的一版，先卸载旧的再装；
- **打开就闪退**：先重启手机；仍闪退就卸载重装一次；重装还是闪退，说明这台设备的系统版本可能不在支持范围内，去商店页面核对。

## 五、订阅没生效

付了钱但功能还是锁着的，按这个顺序查：

1. **确认付款用的帐号 = 当前登录的帐号** —— 这是绝大多数情况的原因；网页端下单、手机端用另一个帐号登录，就会出现「付了没生效」；
2. **在新设备上点「恢复购买」**，或确认登录的是当初付款的那个商店帐号（Apple / Google）；
3. **重启一次应用**，订阅状态有时要重新拉取；
4. **检查是不是已经取消了**：取消后会用完已付期限再降级，见 [免费版和订阅有什么区别.md](免费版和订阅有什么区别.md) 第五节；
5. 都不行，带付款凭证找客服，见第八节。

## 六、提示设备不支持 / 功能找不到

- **提示设备不兼容**：官方要求 iOS / iPadOS 走 App Store、安卓走 Google Play 上的配置要求页，电脑端用 Chrome、Firefox 或 Safari 的最近两个版本。系统太旧是主因，先更新系统。
- **某项功能在应用里找不到**（离线模式、AI 对话、发音反馈等）：先确认当前帐号是否包含该权益（见 [免费版和订阅有什么区别.md](免费版和订阅有什么区别.md)），再确认这门语言 / 这个等级是否已经上线该功能 —— 部分功能只在特定语言和平台上提供。

## 七、打不出对应语言的字母

学日语、韩语、俄语、阿拉伯语这类非拉丁字母的语言时，练习要求你输入对应文字，手机自带的键盘默认打不出来。这不是应用的问题，需要**先在系统里添加这门语言的键盘 / 输入法**：

1. 进手机「设置 → 系统 → 语言和输入法 → 键盘」；
2. 添加你要学的语言对应的键盘（安卓上常见是添「日语」「韩语」等输入法，iOS 上是在「键盘」里添加对应语言）；
3. 回到应用，在输入框里切换到刚加的键盘，按发音拼写输入。

两点补充：

- **系统没自带输入法时**，从应用商店装一个对应语言的输入法即可；
- **有些练习允许用英文拼写或选择题作答**，具体看题目要求，不必每个练习都手打目标语言文字。

## 八、要找客服，先准备好这些

走完上面的步骤仍解决不了，再联系官方客服。客服入口是官方帮助中心的联系表单，邮箱是 [team@busuu.com](mailto:team@busuu.com)。为了让一次沟通就解决问题，把下面这些一起给出去：

- **注册用的邮箱**（即帐号标识）；
- **问题的具体位置**：哪门语言、哪一等级、哪一章的哪一节出的错；
- **设备信息**：手机品牌型号、系统版本、应用版本；
- **问题描述与截图**：能截到报错或异常画面的就附上。

网页端的问题按官方说明，还应附上浏览器控制台的报错截图（在出错页面右键 → 检查 → 控制台标签，把红色报错一起截进去）。准备好这些再发，比来回追问快得多。

**另外三件事也只能走客服**：删除某门语言的进度、帐号注销、付款后帐号未升级的核对 —— 删除进度的流程见 [换课程和同时学几门语言.md](换课程和同时学几门语言.md) 第六节，订阅未生效的排查见第五节，帐号注销见 [注册登录与多设备同步.md](注册登录与多设备同步.md) 第七节。

## 九、几条别踩的坑

- **进度不同步时不要想着删掉重来**：删除某门语言的进度要单独联系客服申请，而且只能整门语言删、不可恢复，它并不会修复同步问题，见 [换课程和同时学几门语言.md](换课程和同时学几门语言.md) 第六节；
- **不要用「清除缓存」当省空间手段**：会把离线课程一起清掉，要省空间请用「清除课程数据」，见 [离线下载与省流量.md](离线下载与省流量.md)；
- **卸载重装前先记下登录方式**：第三方注册的帐号如果忘了当初用哪种方式，重装会进不去，见 [注册登录与多设备同步.md](注册登录与多设备同步.md) 第三节。
