## 一、先弄清免费版的限制

抖度AI 免费下载，注册就能试，但生成类功能的完整体验要付费。第三方下载页的常见问题栏目给过这些口径（以 App 内实际显示为准）：

- 免费版生成的视频**默认带水印**、导出分辨率受限；
- 部分数字人形象**需要开通权限或消耗积分**才能用；
- 积分/会员是消耗型额度，用完要再买。

应用宝页面有用户评论直言「使用任何功能都要钱」—— 也就是说别指望免费版能持续量产内容，先想清楚用不用得上再掏钱。

## 二、价格：不同渠道标价不一致

官方没有统一的公开价目表，各渠道页面显示的套餐不一样：

| 渠道 | 页面/记录显示的价格 |
| --- | --- |
| 苹果 App Store（自动订阅说明） | 年订阅 198 元/年、季订阅 168 元/季、月订阅 98 元/月；页面注明「以 IAP 内购信息为准」 |
| iOS 端另一处订阅说明（第三方页面转述） | 198 元/年、68 元/月、38 元/周 |
| 安卓端 | 页面不标统一价格，需登录后在「我的 → 立即开通」里看当期套餐 |
| 投诉记录里出现过的实际扣费（非官方价目） | 98 元/月、68 元/周、48 元、39.9 元、19.9 元 |

同一份 iOS 说明都能查到两种价格组合，投诉里又出现过好几种金额 —— 说明**标价随投放渠道与时期变**。一切以你 App 内支付页面当时显示的为准，付款前把「订阅周期、每期金额、自动续费规则」三项看清再确认。

## 三、9.9 元三天试用：看清再开

黑猫投诉平台上乐点科技 2026-07-28 的一条投诉回复（商家本人出具）写明了套餐结构：**注册后可付 9.9 元开通 3 天试用，试用结束按 98 元/月自动续费** —— 该投诉中的用户 2026-03-11 付 9.9 元试用，从 03-14 起连续每月被扣 98 元。这种「低价试用 → 到期转正价」的结构是投诉集中的场景，两边口径并列给你：

- **商家口径**（同一条回复）：开通前显著提示、用户主动勾选《自动续费协议》《会员服务协议》、续费前提前发短信提醒、App 内提供取消通道；
- **投诉者口径**（平台上多条）：扣费前没有显著提醒、试用转正不醒目、找不到关闭入口。

不替你选边，只给动作：**开通任何「低价试用」之前，先在付款页找到「试用结束后按多少钱、多久扣一次」；付款成功后立刻按第五节把自动续费关掉**，别等扣费了再走第六节的维权流程。商家页面见 [黑猫投诉的乐点科技页面](https://ah.tousu.sina.com.cn/company/view/?couid=4060600269)（截至 2026-09，页面显示累计 43 条投诉、38 条已回复）。

## 四、安卓端开通步骤

1. 用手机号 + 验证码注册登录（登录是前提，套餐跟着账号走）。
2. 进「我的」页面，点「立即开通」。
3. 选要买的套餐（周/月/季/年），页面会列出价格与权益。
4. 用支付宝或微信完成支付，支付成功后权益即时到账。

新用户在部分渠道能领到首单优惠券（第三方下载页提到「新用户首次使用可领 20 元优惠券」），领不领得到以 App 内活动页为准。

## 五、怎么取消自动续费

订阅默认自动续费，**不关的话到期会自动扣款**。按你的系统关：

**iPhone（App 内购订阅）**
「设置 → iTunes Store 与 App Store → App ID → 查看 Apple ID → 账户设置 → 订阅」，找到抖度AI 点取消。这是官方协议里写的路径，iOS 版本不同入口名称略有差异，进「设置 → 订阅」也能直达列表。

**安卓（支付宝代扣）**
支付宝「设置 → 支付设置 → 免密支付/自动扣款」，找到对应商户关掉。

**安卓（微信代扣）**
微信「我 → 服务 → 钱包 → 支付设置 → 自动续费/扣费服务」，找到对应项目关闭。

**其他代扣渠道**
投诉记录里出现过的扣款通道还有京东支付、网银在线、宝付、中金支付 —— 说明部分订单不走支付宝/微信。扣过款的账单里能看到扣款方名称，打开该通道的 App，在支付设置里找「代扣 / 免密支付 / 自动扣款」一类的签约管理入口关掉；找不到入口就把扣款方名称连同「关闭代扣」诉求发给客服邮箱。

关完建议过一个计费周期确认没再扣款 —— 黑猫投诉平台上有不少关于该主体「自动续费提醒不显著」「找不到关闭入口」的投诉，自己动手关干净比等提醒可靠。

## 六、被扣费了怎么办

按你在用的支付方式选路，从快到慢：

1. **先止血**：按第五节把自动续费关掉，止住后续扣款。
2. **iOS 内购扣的费**：在 [Apple 的报告问题页面](https://reportaproblem.apple.com) 用 Apple ID 登录申请退款。有投诉者反馈「申请两次未通过」—— 能不能退、退几笔因个案而异。
3. **联系客服邮箱**：官方协议页留的联系邮箱是 `ledian166@163.com`，把扣费时间、金额、扣款方名称、订单号发过去要求退款。投诉平台的商家回复显示，协商后原路退回多笔款项的案例存在。
4. **商家的退款立场要有预期**：同一类投诉回复里商家明确表示 —— 数字化服务「支付即交付」，已使用周期不支持退款；试用转正的那几笔，往往只退协商范围内的部分。协商不成走第 5 步。
5. **支付渠道投诉**：在扣款通道（京东支付/支付宝/微信等）的账单里对该笔交易发起投诉，要求撤销代扣。
6. **平台投诉**：[黑猫投诉](https://ah.tousu.sina.com.cn/company/view/?couid=4060600269) 页面显示该主体的投诉大部分能得到回复；提交扣费截图、订单号、协商记录，处理效率比只发邮件高。结果因个案而异，别当退款承诺。
