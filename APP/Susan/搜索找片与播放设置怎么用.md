## 一、本篇讲什么

Susan 除了粘链接解析（见[视频链接解析怎么用.md](视频链接解析怎么用.md)），还能直接搜片名。本篇讲搜索怎么用、搜出来怎么挑，以及播放界面里能调的那些设置。

## 二、搜索入口与步骤

1. 在首页点右上角的**放大镜**按钮，进入搜索页；
2. 输入片名关键字（比如剧名的前两个字就够）；
3. 结果列表会列出匹配的影片，点任意一部；
4. 进入后选集数，直接开始播放。

搜索结果来自应用内置的资源库 —— 搜得到就能播，搜不到说明库里没有这个资源，改用链接解析那条路（回原平台复制分享链接）。

## 三、播放界面能调什么

以手上的 v1.0.9 与官方说明为准，常用的是这几项：

| 功能 | 怎么用 |
| --- | --- |
| 选集 | 播放页里点集数切换；连播下一集需手动点，不会自动跳 |
| 倍速 | 播放控制条里的倍速入口，按需选档 |
| 后台播放 | 退出 Susan 或锁屏后声音继续，回应用恢复画面 |
| 全屏 | 点播放画面的全屏按钮，横屏自动铺满 |
| 深色模式 | 跟随系统深色模式开关（官方特性，Android 系统设置里切） |

应用还内置了一个影视库入口（首页的信息流），可以直接点封面进播放 —— 与搜索是同一套资源，只是省了输入这一步。

## 四、搜不到 / 播不动时

1. **换关键字**：只输片名本身，别带「第 3 季」「全集」这类后缀；
2. **搜到了但点开没集数**：资源不全，换一部同名条目（结果里可能有多个同名条目）；
3. **播放卡顿**：先退出重进一次，再不行换集数或走链接解析（不同入口走的源不一样）；
4. **整个搜索页没反应**：网络问题优先排查，能开网页就等一会儿再试，或看[版本更新与开源地址怎么看.md](版本更新与开源地址怎么看.md)有没有新版。

按症状完整排查见[常见问题与排查.md](常见问题与排查.md)。
