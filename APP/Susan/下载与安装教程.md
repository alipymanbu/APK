## 一、这是什么软件

Susan 是一款安卓端的视频链接解析播放工具：你在视频平台里复制一条剧集的分享链接，粘贴进 Susan 解析后就能直接在应用里播放；它也支持直接搜片名找资源。应用开源、界面是中文、不需要注册账号。本篇只管「怎么把它装到手机上」，装好后怎么用见[视频链接解析怎么用.md](视频链接解析怎么用.md)。

## 二、把安装包拿到手

1. 打开 Susan 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/5c8500377bdf](https://pan.quark.cn/s/5c8500377bdf)。
2. 转存到你自己的网盘，在里面找到 APK 文件 `Susan_v1.0.9.apk`。
3. 用手机上的夸克网盘直接下载到本地存储；或者先下到电脑再用数据线/微信文件助手传到手机。
4. 下载完成后核对一下大小是否为 9.06M —— 对不上说明没下完整，重新下一次。

## 三、安装步骤

1. 手机上点开这个 APK，系统会弹「是否允许安装来自此来源的应用」—— 因为它不是从应用商店装的，这个授权每个手机只问一次：去 `设置 → 安全/更多设置 → 安装未知应用`，给你的文件管理器或浏览器开一次权限，返回再点安装。
2. 等安装进度走完，点「打开」。
3. 首次启动会直接进主界面，没有登录、注册环节。
4. 装完先别急着删下载的安装包 —— 想核对版本可以对照上面表格的版本号、大小与包名（在 `设置 → 应用 → Susan → 应用信息` 里能看到版本号与包名）。

**以后升级**：拿到新版本安装包后直接覆盖安装即可，不需要先卸载，Android 的覆盖安装会保留数据（Susan 本身不存账号数据，覆盖更无影响）。新旧版本怎么选见[版本更新与开源地址怎么看.md](版本更新与开源地址怎么看.md)。

## 四、系统要求

- **系统版本**：本地这份安装包标注需要**安卓 5.2 以上**。各处口径不一致，你按自己的实际情况判断：
  - 网盘里这份（v1.0.9）标注：安卓 5.2 以上；
  - 官方开源仓库 README 当前写的是 **Android 8.1 及以上**；
  - 第三方应用站对新版（v1.2.x）标注的是 Android 7.0 以上。
  版本号越高要求越严 —— 装不上时先看[常见问题与排查.md](常见问题与排查.md)的「闪退 / 打不开」一节。
- **设备**：面向安卓手机；没有账号体系，换手机也不用迁移数据。平板上也能装，官方新版对平板屏幕做了适配。

## 五、提示「有风险 / 不允许安装」怎么办

这类提示是手机系统对「非商店来源」安装包的统一拦截，不是针对 Susan。按顺序试：

1. 在安装拦截弹窗里点「仍然安装 / 继续安装」（有的机型藏在「更多」里）；
2. 去安全中心（手机管家）里关掉「安装包安全检测」或对该安装包选「信任」；
3. 换个入口安装：用系统「文件管理」App 里直接点 APK，而不是在下载通知栏里点；
4. 以上都不行再走 `adb install`，属于进阶操作，自行搜索你机型的 adb 打开方法。

装不上、装完打不开的其余情形，统一按[常见问题与排查.md](常见问题与排查.md)排查。
