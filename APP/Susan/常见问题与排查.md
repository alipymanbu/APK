## 一、点了「开始解析」没反应 / 一直转圈

按顺序试：

1. **先确认链接本身**：必须是从视频平台「分享 → 复制链接」拿到的播放页地址，口令文本、短链、浏览器地址栏链接都可能解析不了（详见[视频链接解析怎么用.md](视频链接解析怎么用.md)第四节；各平台按钮在哪见[各平台分享链接怎么复制.md](各平台分享链接怎么复制.md)）；
2. **换一条链接试**：新链接能解析、老链接不能 —— 老链接那条资源或平台接口变了，不是应用坏了；
3. **换网络**：WiFi 和流量各试一次，能排除本地 DNS 问题；
4. **都失败**：大概率是解析服务侧波动或平台改版，等新版修复（见[版本更新与开源地址怎么看.md](版本更新与开源地址怎么看.md)）。

## 二、搜索结果是空的 / 搜不到想看的

- 搜索走的是应用内置资源库，**库里的才有**：先换更短的关键字（只留片名）再搜一次；
- 搜不到的片改走链接解析，两条路的资源不重合；
- 搜索页完全不出结果、连常见热门片都没有 → 网络或服务侧问题，隔段时间重试。

## 三、播放卡顿 / 画面黑屏 / 没有声音

1. **卡顿**：先退出播放重进；持续卡就换集数 —— 不同集走的源不同；
2. **黑屏有声音**：通常是该条源在你的设备上解不动，退出换另一条结果再播；
3. **没声音**：先查手机媒体音量（不是铃声音量），再看有没有被蓝牙耳机/音箱接管；
4. **锁屏后声音停了**：后台播放是开关行为，在播放界面确认开着（见[搜索找片与播放设置怎么用.md](搜索找片与播放设置怎么用.md)）。

## 四、闪退 / 打不开 / 装完没反应

按顺序走一遍（前两步能解决大多数情况）：

1. **清一次缓存**：长按桌面 Susan 图标 → 应用信息 → 存储占用 → **清除缓存**，然后重新打开；缓存清完还闪退就再点一次**清除数据**（Susan 没有账号和云端记录，清空不损失东西）；
2. **清后台 / 重启手机**：后台堆太多应用时系统会杀掉新装的应用，重启后再试一次；
3. **核对系统版本**：本地这份标注安卓 5.2 以上，系统太老会装不上或秒退；官方新版对系统要求更高（见[下载与安装教程.md](下载与安装教程.md)第四节）；
4. **安装时提示解析错误**：安装包没下完整，重新下载核对大小 9.06M；
5. **换网络 / 存储空间**：剩余存储只剩几十 MB 时应用起不来，清出几百 MB；网络类异常换 WiFi/流量各试一次；
6. **只在更新后开始闪退**：新版引入问题的概率大 —— 卸载后重装网盘里的 v1.0.9 回退（无账号数据，回退无代价，见[版本更新与开源地址怎么看.md](版本更新与开源地址怎么看.md)第五节）；
7. **以上都无效**：卸载重装一次，排除安装包损坏。

## 五、提示「有风险 / 不允许安装」

系统对非商店来源安装包的统一拦截，处理办法见[下载与安装教程.md](下载与安装教程.md)第五节。

## 六、有没有广告、要不要登录、要不要收费

以手上的 v1.0.9 实际表现与官方公开说明为准：

- **登录**：不需要，装完即用，没有账号体系；
- **收费**：应用本身免费、无内购入口；
- **广告**：官方说明其无弹窗广告；若你在使用中看到弹窗，注意甄别是否来自手机管家的推广或误装的山寨包 —— 认准包名 `dev.letconst.susan`（见[下载与安装教程.md](下载与安装教程.md)的表格）。

## 七、换了新手机 / 卸载重装后记录没了

Susan 没有账号体系，播放记录、搜索历史只存在本机：卸载即清空、换机不迁移。重装后重新搜片即可，资源不依赖本地数据。
