# 各平台分享链接怎么复制

## 一、本篇解决什么问题

Susan 解析失败的头号原因是**链接拿错了**（详见[视频链接解析怎么用.md](视频链接解析怎么用.md)第四节）。本篇把主流平台的复制入口逐个列出来，照着拿就不会错。总原则只有一条：**在剧集播放页里点「分享」，选「复制链接」**，别从聊天记录里转发、别从浏览器地址栏里手抄。

## 二、各平台入口对照

| 平台 | 入口路径 | 复制出来长什么样 |
| --- | --- | --- |
| 腾讯视频 | 播放页 → 分享（右上角或播放控制条）→ 复制链接 | `https://m.v.qq.com/x/play?vid=…&cid=…` |
| 爱奇艺 | 播放页 → 分享/右上角三个点 → 复制链接 | `https://m.iqiyi.com/v_….html` 一类的网页地址 |
| 优酷 | 播放页 → 分享 → 复制链接 | `https://m.youku.com/v_show/id_….html` 一类 |
| 芒果 TV | 播放页 → 分享 → 复制链接 | `https://mgtv.com` 开头的网页地址 |
| 哔哩哔哩 | 播放页右下角（或右上角三个点）→ 分享 → 复制链接 | 常是 `b23.tv` 开头的短链 |

入口文案各版本略有差异，认准**「分享」**和**「复制链接」**两个词即可；找不到「复制链接」就选「分享到微信」前一步里的复制选项。

## 三、复制出来不是纯网址怎么办

有两类常见形态，都能直接粘：

1. **中文 + 链接混排**（形如 `【某剧】https://xxx` ）—— 聊天软件里转发过来的都是这种。直接整段粘进 Susan 一般能自动识别；识别不了就手动只留网址部分再粘一次。
2. **短链**（如 B 站的 `b23.tv/xxx`）—— 短链本身就是播放页地址的压缩形式，直接粘即可。若这条短链解析不了，回平台重新走一次「分享 → 复制链接」，或改用电脑浏览器打开视频、复制地址栏的完整地址。

**不要**拿这些当解析输入：App 内部跳转口令（没有网址、只有一串编码的那种）、纯文字口令、直播间的房间号。

## 四、链接拿对了还是解析不出来

那就不是链接的问题了，按[常见问题与排查.md](常见问题与排查.md)第一节往下走：换网络 → 换一条别的剧的链接试 → 都不行等新版本修复（见[版本更新与开源地址怎么看.md](版本更新与开源地址怎么看.md)）。

只想找片不想折腾链接的话，直接用站内搜索也一样能播，见[搜索找片与播放设置怎么用.md](搜索找片与播放设置怎么用.md)。
