## 一、先看清这份安装文件是什么版本

Root Explorer 由 Speed Software 开发，中文圈里常被叫「RE 管理器」。它是一个偏系统层的文件管理器：整理普通存储里的文件只是基础功能，被老用户最看重的是拿到 root 权限之后能进入系统目录。要装进手机的这份是安卓版 APK。

| 项目 | 值 |
| --- | --- |
| 应用名 | Root Explorer |
| 版本 | 2.16 |
| 包名 | `com.speedsoftware.rootexplorer` |
| 安装包大小 | 0.38 MB |
| MD5 | `19835F1B6329C55E644A4F9FFA8E6854` |
| 开发者 | Speed Software |
| 商店页面 | [play.google.com/store/apps/details?id=com.speedsoftware.rootexplorer](https://play.google.com/store/apps/details?id=com.speedsoftware.rootexplorer) |

有两点要先说清楚：

1. **版本以本页为准。** 你在搜索引擎里搜到的通常是官方现在的最新版本，和这份 2.16 不是同一个版本。版本号、包名、安装包体积都以上表为准；商店页面只用来核对开发者与应用名（版本以官方页面为准）。
2. **2.16 是较早的版本。** 菜单里的英文措辞与新版有差异，下文提到菜单位置时，以你装上的那一版实际界面为准。较新的系统上可能需要系统版本适配，具体见 [安装与使用问题排查.md](安装与使用问题排查.md)。

## 二、装之前确认三件事

1. **系统版本。** 这类系统层工具面向的是 Android 用户存储与系统分区。在 Android 10 及以上的机型上，安装和浏览用户存储一般没问题，但涉及系统分区写入的操作可能被系统本身拦住，原因见 [系统分区挂载读写与权限设置.md](系统分区挂载读写与权限设置.md)。
2. **要不要 root。** 没有 root 也能装、也能用，只是能做的事少一大圈，分界线见 [没有root权限能用哪些功能.md](没有root权限能用哪些功能.md)。
3. **存储空间。** 安装包不到 1 MB，装完占用也不大；但你要拿它复制、解压大文件时，目标分区得先留出足够空间——复制和移动失败里，空间不足是很常见的一条。

## 四、安装步骤（APK 方式）

1. 在手机上打开夸克，把上面那份分享转存到自己账号，再下载 APK 到手机存储。
2. 到系统设置里允许安装来源。Android 8 及以上是按「哪个应用发起安装」逐个授权的：设置 → 应用 → 找到你用来打开 APK 的那个文件管理器 → 安装未知应用 → 允许。
3. 用文件管理器找到刚下载的 APK，点开，按提示安装。
4. 如果弹出「已阻止安装」或安全提醒，说明第 2 步那一项没开；不要点「取消」，回到设置授权后重新点 APK。
5. 装完在桌面或应用列表里找到 Root Explorer 启动。

如果下载下来的文件打不开、或者提示「解析包时出现问题」，先看 [安装与使用问题排查.md](安装与使用问题排查.md)，多数是传输过程中文件不完整，重新下一份再试即可。

## 五、第一次打开：先把这几项设好

**1. 处理 root 授权弹窗。** 有 root 的手机会在启动后弹出授权请求，出现时选允许（多数授权管理工具提供「记住选择」）。这一步只在第一次出现；以后想改，去 Magisk / SuperSU 之类的授权管理里找 Root Explorer 的条目。没弹窗不代表没 root，也可能只是这一版没有在启动时主动申请。

**2. 认清界面上的几个关键位置。**

| 位置 | 作用 |
| --- | --- |
| 顶部路径栏 | 显示当前所在目录，可长按复制路径 |
| 路径栏下方的容量条 | 当前分区的已用 / 剩余空间 |
| 路径栏右侧的 `r/w` | 当前分区是只读（r/o）还是可读写（r/w），动系统目录前先看它 |
| 列表区 | 显示当前目录内容，长按一项会弹出操作菜单 |
| 菜单键 / 溢出菜单 | 新建文件夹、新建空文件、搜索、全选、排序、视图切换都在这里 |

**3. 打开「显示隐藏文件」。** 系统目录里大量文件以 `.` 开头，设置里不打开这一项，你会以为目录是空的。

**4. 想清楚起始目录。** 如果每次打开都要从根目录一路点回去，就在常去的目录上长按、加进书签，书签入口在菜单里。较早的版本里也能在设置中指定启动目录。

**5. 视图与排序。** 文件多的目录建议切到详细列表、按大小排序，一眼能看出谁在占空间；只想找某个具体文件时用搜索更快（具体做法见 [文件与文件夹常用操作.md](文件与文件夹常用操作.md)）。
