## 一、操作入口只有两处

较早版本的界面很朴素：**一处是列表里的长按菜单**，绝大多数文件操作都在里面；**另一处是菜单键 / 溢出菜单**，新建、搜索、全选、排序、视图切换在这里。记住这两处，剩下的只是熟悉词汇。

| 动作 | 怎么做 |
| --- | --- |
| 进入文件夹 | 点它 |
| 返回上一级 | 列表里的 `..` 项，或按返回键 |
| 切到根目录 | 顶部路径栏逐级上翻，或直接点路径中的 `/` |
| 新建文件夹 | 菜单 → 新建文件夹，输入名称后确认 |
| 新建空文件 | 菜单 → 新建文件（默认 `.txt`），建完可直接进编辑器写 |
| 重命名 | 长按目标 → 重命名 |
| 删除 | 长按目标 → 删除 |
| 复制 / 剪切 | 长按目标 → 复制或剪切 |
| 粘贴 | 进到目标目录 → 菜单 → 粘贴 |
| 多选 | 先长按一项进入多选状态，再逐项点选；也能全选当前目录 |
| 搜索 | 菜单 → 搜索，输入文件名关键词；会向下递归子目录 |
| 查看属性 | 长按 → 属性，能看到大小、修改日期和 MD5 |
| 用别的应用打开 | 长按 → 打开方式，再选具体应用 |
| 发送文件 | 长按 → 发送，走蓝牙或邮件等 |
| 建桌面快捷方式 | 长按 → 创建快捷方式 |
| 加书签 | 长按 → 添加书签，之后从菜单里的书签直接跳回 |
| 排序 / 视图 | 菜单里切换按名称、日期、大小、类型排序，以及列表 / 图标视图 |

## 二、复制和移动的稳妥顺序

跨目录搬东西最容易出错，按这个顺序不容易翻车：

1. **先复制、确认到位后再删原件。** 剪切 + 粘贴在目标分区空间不足时会留下半截结果，复制不会。
2. **复制前看一眼目标分区的剩余空间**（路径栏下方那条容量条）。移动是「写新 + 删旧」，目标分区要能装下整份。
3. **同名冲突时会问你怎么处理**，默认选项看清再确认；覆盖是不可撤销的。
4. **批量操作前先拿一个不重要的文件走一遍流程**，确认路径和结果都对，再对整批动手。

## 三、搜索比一层层点更快

层级深的时候，搜索是省时间的那一步。几点经验：

- 关键词用文件名里确定会出现的片段，别用「那个文档」之类的描述。
- 从当前目录搜会带上子目录；从根目录搜范围最大、也最慢。
- 搜出来的结果点进去就是它所在的目录，可以直接接着操作。

搜索结果里既能定位用户存储的文件，也能定位系统目录里的文件——能不能打开后者，取决于你是否有 root，见 [没有root权限能用哪些功能.md](没有root权限能用哪些功能.md)。

## 四、把常去的目录做成书签

书签解决的是「每次打开都要从根目录一路点下去」这件事。对常去的目录长按 → 添加书签，之后从菜单里的书签一次跳到位。书签多了可以删掉重加，按自己的习惯命名。

一个很省事的用法：把外置卡、`/sdcard/Download`、以及你经常在它们之间搬文件的那几个目录一起加进书签。之后搬东西就是「书签跳到源目录 → 复制 → 书签跳到目标目录 → 粘贴」，中间那几步一层层翻目录的操作全省掉了。

## 五、目标落在系统目录时先停一下

上面这些操作在用户存储里是安全的。一旦目标落在 `/system`、`/data` 这类系统目录，先要解决「分区还在只读挂载」的问题，而且误删的代价完全不同——见 [系统分区挂载读写与权限设置.md](系统分区挂载读写与权限设置.md)。压包、解包和改文本文件的入口是另一套，见 [压缩包解压与文本文件编辑.md](压缩包解压与文本文件编辑.md)。
