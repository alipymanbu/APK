# Root Explorer 没有root权限能用哪些功能

> Root Explorer 不 root 也能装、也能用，只是能碰到的范围只剩用户存储那一圈。本篇划清有 root 与没 root 的分界线，并给出判断自己是否真的拿到 root 的办法。

## 一、分界线在「系统给的权限」，不在功能开关

Android 给普通应用划了一条线：用户存储（`/sdcard`，也就是相册、下载、文档这些）可以碰，系统分区和应用私有数据不行。Root Explorer 能力清单里那些「读整个文件系统」「删预装应用」「改文件权限」的条目，全都压在这条线后面。没有 root 时，菜单不是不出现，就是点了报权限错误。官方对它的定位也是「为 root 用户准备的文件管理器」——整个文件系统都能访问，前提是设备已经 root。

## 二、逐项对照

| 你想做的事 | 没 root | 有 root |
| --- | --- | --- |
| 浏览相册、下载、文档、安装包等用户存储文件 | 可以 | 可以 |
| 复制、移动、重命名、删除用户存储里的文件 | 可以（Android 11 及以上要先给存储 /「所有文件访问」权限） | 可以 |
| 新建文件夹、编辑文本文件、压缩解压 | 可以 | 可以 |
| 搜索用户存储里的文件 | 可以 | 可以 |
| 打开 `/data`、`/system`、`/` 根目录 | 列表为空，或提示无权限 | 能看到真实内容 |
| 挂载分区为读写（r/w） | 菜单不给，或切换后立刻弹回 r/o | 可以切换 |
| 修改文件权限、所有者、用户组 | 不可用 | 可用 |
| 删除系统预装应用 | 不可用 | 可用 |
| 修改 `build.prop` 一类系统配置 | 不可用 | 可用，风险自负 |
| 创建符号链接、以 root 身份执行脚本 | 不可用 | 可用 |

最后三行要补一句：**有 root 并不等于一定能成功**。Android 10 及以上的机型常有额外的启动校验与 SELinux 限制，会直接拒绝写入系统分区。这是系统层面的限制，不是你没 root，判断办法见 [系统分区挂载读写与权限设置.md](系统分区挂载读写与权限设置.md)。

## 三、怎么判断自己已经拿到 root

按可靠性从高到低：

1. **进 `/data` 目录看列表。** 里面是一堆以 `com.` 开头的应用数据目录，就说明有 root；一片空白并弹权限提示，就是没有。
2. **看授权管理工具里的记录。** Magisk / SuperSU 这类工具会列出哪些应用申请过、什么时候申请、有没有被允许。Root Explorer 出现在里面且状态是允许，才是真的授过权。
3. **在系统目录里试一次写操作。** 比如在 `/system` 下点一次新建文件夹。成功说明读写也通了；失败会明确报错，正好能区分是「没 root」还是「挂载仍是只读」。

**常见误判**：文件管理器能把 `/` 路径画出来不算有 root——很多应用会先把根目录列出来，点进去才发现内容读不出来。

## 四、没 root 时能争取到的额外空间

**先要「所有文件访问」权限（Android 11 及以上）。** 路径是 设置 → 应用 → Root Explorer → 权限 → 文件与媒体 → 允许管理所有文件。它在系统里的正式名称是「所有文件访问权」，能给到和给不到的范围是固定划好的：

| 有了它才能做 | 有了它仍然做不到 |
| --- | --- |
| 读写共享存储（相册、下载、文档等）里的所有文件 | 其他应用的私有目录，也就是 `Android/data/` 下面一个个的应用文件夹 |
| 访问 SD 卡与 OTG 存储的根目录 | 系统分区，例如 `/system`、`/` |
| 按真实路径直接读写文件，不必逐个目录走选择器 | — |

**`Android/data` 和 `Android/obb` 要单独看。** 这两个目录装的是各家应用的私有数据。从 Android 11 起，系统在文件选择器里就不再开放它们了，所以「授权一次就能长期访问」的做法在新系统上基本行不通；少数定制系统另给了按目录授权的入口，弹什么提示就按什么处理。想稳定进这两个目录，前提是 root。

这一节讲的都只是把用户存储内的权限要全，跨不进系统分区。想要那一圈，只有 root。

## 五、什么时候才需要 root

root 只在你要做这三类事时才有必要：改系统文件、删预装应用、把某个目录挂成读写。它同时意味着保修、系统更新和误操作代价上的额外风险——拿不定主意就按没 root 的方式用，普通文件整理、解压、阅读需求它一样能满足（日常操作的做法见 [文件与文件夹常用操作.md](文件与文件夹常用操作.md)）。
