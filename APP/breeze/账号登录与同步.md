# Breeze 账号登录与同步设置

> 讲 Breeze 怎么登录哔咔、JM 账号，注册与资料修改在哪做、自动签到怎么开，以及收藏与阅读记录怎么跟着账号走。

Breeze 本身不发账号 —— 你登录的是自己在哔咔（PicACG）、JM 上已有的账号，收藏、点赞、阅读记录都存在平台侧，换设备登同一账号就能接上。本篇以 2.13.7 版界面为准，入口位置与你装的版本可能略有差异。

## 一、先确认你有账号

Breeze 支持两类账号：

- **哔咔（PicACG）账号**：在哔咔官方渠道注册；
- **JM 账号**：在 JM 官方渠道注册。

两类账号互相独立，可以只登一个，也可以都登。注册与找回密码在各平台自己的渠道完成，Breeze 里只做「登录」这个动作。

注册哔咔账号时有两点容易踩（据哔咔侧常见问题整理）：登录 ID 必须用**小写字母**，且登录 ID 与昵称是两个东西，提示「被占用 / 重复」时先分清是哪种冲突；登录 ID 忘记后基本找不回，注册完把账号信息记在可靠的地方。

## 二、登录步骤（2.13.7 版界面）

1. 打开 Breeze，进入首页后点【更多】；
2. 进入个人中心，这里有哔咔和 JM 两个账号入口；
3. 点【未登录哔咔账号】（或对应的 JM 入口）进入登录页；
4. 输入用户名和密码，提交登录；
5. 登录成功后返回首页，刷新即可加载对应平台的内容。

登录后如果一直弹「登录过期」、反复跳登录页，处理办法见 [常见问题排查.md](常见问题排查.md) 的第一条。

## 三、注册、改密码与个人资料

登录入口里能一并处理账号事务：

- **注册**：没有账号时在登录页选注册入口，按平台要求填写资料；
- **修改密码**：个人中心对应账号的设置项里；
- **修改签名 / 头像**：个人资料页直接编辑，改动在平台侧同步生效。

具体选项名称随版本略有变化，找不到就先登录再看个人中心。

## 四、自动签到

哔咔账号有每日签到，Breeze 提供自动签到功能：在对应账号的设置里开启后，不用每天手动签到。开关位置随版本可能不同，在账号设置附近找即可。

## 五、收藏与阅读记录同步

- 收藏、点赞、阅读记录跟随账号存储；换手机、重装应用后登同一账号即可找回；
- 两类账号的收藏各自独立，不会互相合并；
- 未登录时浏览产生的本地数据，登录后不一定并入账号 —— 建议装好先登录，再开始收藏；
- 收藏进来之后的日常用法（追更、检索维度）见 [阅读与收藏使用技巧.md](阅读与收藏使用技巧.md)。
