## 二、安卓安装步骤

1. 把 apk 传到手机：网盘转存后下载，或手机上直接访问网盘链接；
2. 点开 apk，系统首次会询问「是否允许安装未知来源应用」，给对应的安装入口（浏览器 / 文件管理器 / 网盘客户端）开一次允许；
3. 安装完成后在桌面打开 Breeze，首次进入是未登录状态，登录方法见 [账号登录与同步.md](账号登录与同步.md)。

装不上时的几种情况：

- **提示未审核应用被系统拦截**：部分国产安卓系统会拦未上架应用市场的安装包，换一个安装入口（如系统自带文件管理器）再试；官方 README 也提到可用 GBox、出境易、GSpace 这类容器方案运行，具体见 [项目仓库](https://github.com/deretame/Breeze) 的说明；
- **安装包损坏报错**：重新下载一遍并核对上表的 MD5，下载中断是这类报错最常见的原因；
- **装上了却打不开、闪退**：处理办法见 [常见问题排查.md](常见问题排查.md)。

另外提醒：Breeze 连接的漫画平台含成人向内容，官方分发页对此有明确标注，18 岁以下不适合使用，请遵守你所在地的法规。

## 三、其他平台的安装方式

官方 Releases 页面对每个平台都发了安装包（文件名以页面当时显示为准）：

| 平台 | 方式 |
| --- | --- |
| Windows | 下载 `windows-installer.exe` 直接运行 |
| macOS | 推荐 `brew tap deretame/breeze` 后 `brew install --cask breeze`；也可手动下载 DMG 拖入 Applications。首次打开若提示「已损坏 / 无法验证开发者」，在终端执行 `xattr -cr /Applications/Breeze.app` 放行 |
| Linux | Debian / Ubuntu 用 DEB 包：`sudo apt install ./breeze_*.deb`；其他发行版装 Flatpak 包，运行命令 `flatpak run io.github.windy.breeze` |
| iOS / iPadOS | 未上架 App Store，需下载无签名 IPA 后用 AltStore、Sideloadly 等工具自签安装 |
| 鸿蒙 | Releases 页提供对应包；系统拦截时参考官方 README 的容器方案 |

## 四、升级与数据备份

- **跨大版本升级前先备份数据**。官方在 3.0.0 的更新说明里明确提醒「本次为大版本更新，存在较大改动，请先备份好数据以避免数据丢失」；3.x 起来源改为插件式机制（beta），与 2.x 的内置来源用法不同，升级后先确认收藏与阅读记录都在；
- 近期版本改动不小（如 3.0.32 重构了下载功能，收藏与下载支持按观看时间排序），升级后相关入口位置可能变化，来源机制的差异见 [漫画来源切换与插件安装.md](漫画来源切换与插件安装.md)；
- 小版本一般直接覆盖安装；升级后若要求重新登录，用原账号再登一次即可，收藏跟着账号走；
- 每个版本改了什么，进 [Releases 页面](https://github.com/deretame/Breeze/releases) 看更新日志。
