# 常见闪退与无法登录怎么办

## 一、先做这三件通用的事

不管哪种症状，动手排查前先花一分钟：

1. **重启手机** —— 清掉临时故障，很多「突然坏了」到这一步就好了；
2. **清后台** —— 内存被占满时应用会无响应甚至被系统杀掉；
3. **看存储空间** —— 剩余空间不足会导致应用运行异常，先腾出几个 GB。

问题还在，再往下按现象走。

## 二、打开就闪退 / 无响应

按命中率从高到低逐项试：

| 步骤 | 操作 |
| --- | --- |
| 清缓存 | 长按桌面 YY 图标 → 应用信息 → 存储占用 → 清理缓存（先别清「清除数据」，那会退出登录） |
| 查权限 | 应用信息 → 应用权限，把麦克风、存储等常用权限打开 |
| 换网络 | Wi-Fi 和移动数据切一下，排除当前网络的问题 |
| 升级应用 | 官网下载最新版覆盖安装（见[下载与安装教程.md](下载与安装教程.md)） |
| 清除数据 | 仍不行再「清除数据」—— 注意这会清掉本地登录状态，重新登录即可 |
| 卸载重装 | 最后一招：卸载后重新安装；**先确认账号能登回去**（绑过手机最稳，见[账号绑定手机与找回教程.md](账号绑定手机与找回教程.md)） |

如果是**刚升级到新版之后才开始闪退**，大概率是新版本本身的问题：先用着旧版，等官方下一次更新修复；或者卸载后装回网盘里那份稳定版本（[YY语音 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b205d1081795)），并在应用商店里关掉「自动更新」，防止它又升上去。

## 三、安装包装不上

- **提示解析错误 / 不是有效的安装包**：下载中断导致文件不完整 —— 删掉重下；网盘文件建议转存后再下载，别用在线预览。
- **提示与现有应用冲突 / 版本不兼容**：先卸载旧版再装；装完立刻闪退则换 32 位/64 位另一种包（官网两种都提供，选择口径见[下载与安装教程.md](下载与安装教程.md)）。
- **点了没反应**：多半是没给「安装未知应用」权限，按安装教程第四节授权后重试。

## 四、登不进去

- **收不到验证码**：按[账号绑定手机与找回教程.md](账号绑定手机与找回教程.md)第三节逐条排查（拦截软件、停机、运营商延迟是常见原因）；
- **忘了密码**：走安全中心 [aq.yy.com](https://aq.yy.com) 找回，验证通道与绑定的密保手机相关；
- **账号被限制 / 申诉**：同样在安全中心发起，或走客服中心 [kf.yy.com](http://kf.yy.com) 提交工单。

## 五、登录正常但语音不通

1. **麦克风权限**被拒了 —— 应用信息 → 应用权限 → 打开麦克风；
2. **静音状态** —— 看房间界面的麦克风按钮是否被你关了；
3. **网络** —— 切一下 Wi-Fi/移动数据；语音对网络抖动敏感，换网往往立竿见影；
4. 还不行，退房重进一次（对照[游戏开黑连麦怎么用.md](游戏开黑连麦怎么用.md)）。

以上全试过仍解决不了，把现象（哪一步、什么提示）带到 [kf.yy.com](http://kf.yy.com) 提交，或进 YY 内的 YY客服10频道咨询 —— 自查的价值到此为止，剩下的交给客服。
