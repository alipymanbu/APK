# MusicFree 常见问题排查

> 收集 MusicFree 安卓版用起来最容易碰上的问题：搜不到歌、播不出声、插件装不上、后台播一半停了，每条都给出判别办法。插件怎么装的看[插件安装与音源配置.md](插件安装与音源配置.md)，基础操作看[基础使用与个性化设置.md](基础使用与个性化设置.md)。

## 一、搜不到某首歌，是不是软件不行？

先分清责任在哪边：MusicFree 自己不带音源，搜索结果完全由插件决定。同一首歌，插件 A 搜得到、插件 B 搜不到，很正常。判定顺序：

1. 换一个插件搜同一个词，有结果就是原插件的问题。
2. 如果用的是官方示例插件：官方明确说明示例插件**过滤掉付费、试听歌曲**，热门新歌搜不到是设计如此，以后也不会变。
3. 所有插件都搜不到，检查插件是不是失效了，回插件页点【更新订阅】试试。

官方对「能不能支持付费歌曲」的态度是明确的：软件里没有会员体系，也不打算提供这类功能。

## 二、某首歌放不出来，或者只放一半

按现象对号：

| 现象 | 多半的原因 | 处理 |
| --- | --- | --- |
| 点了没声音、直接暂停 | 音源链接是死链，或开了「播放失败时自动暂停」 | 换首歌试试；其他歌正常就是这一首的音源失效了 |
| 只能播放前面一小段 | 该歌曲是付费/试听内容且插件没过滤干净 | 换插件或换版本，软件侧无解 |
| 偶尔中途断 | 音源链接带时效，放一会儿就过期 | 重新点一次播放即可 |
| 每首都是插件的问题 | 插件接口变了 | 更新订阅；长期不行就等插件作者修 |

总原则一句话：**歌曲层面的问题找插件，播放器本身没问题**。另外设置里有一个「自动换源」选项可以救急：打开后，当前插件拿不到播放链接时，会自动尝试用其他插件播放同名歌曲，插件半死不活时能明显减少「这首歌放不了」的情况。

## 三、装不上，或者一打开就闪退

先查系统版本：官方从 v0.5.0 版本起的更新说明写明仅支持 Android 7.0 及以上设备，老手机（6.0 及以下）装不上、或装上就闪退，基本都是这个原因，换设备或找更老的安装包。其次检查安装包本身——MD5 对不上就重新下载（核对方法见[下载与安装教程.md](下载与安装教程.md)）；如果手机上装过同名仿冒品，签名不同会导致覆盖安装失败，先卸载旧的。

## 四、后台播完一首就停

手机系统把应用后台杀掉了。两个方向都检查一遍：

- **应用内**：侧边栏里有「权限管理」，其中提供忽略电池优化的开关，总被杀后台的话先打开它试试（界面入口以你手上的版本为准）。
- **系统侧**：去系统设置里找到 MusicFree，打开「允许后台运行」/「不限制省电策略」这类选项（不同品牌叫法不同）。

两边都放开之后，锁屏就能连续播放了。

## 五、音质切了没区别，或者切不了

音质档位是软件预定义的 4 档，但**有没有对应音质的音频文件由插件决定**。插件只给一种音质时，你在设置里切哪档都一样；缺的档位软件会自动拿高一档或低一档补位。所以这不算故障，换支持高音质的插件才是办法。

## 六、插件安装失败

三个检查点，按顺序来：

1. 链接结尾必须是 `.json` 或 `.js`，检查有没有复制进多余的空格、换行。
2. 填的得是 MusicFree 插件地址，普通网页或普通 JSON 接口装不上。
3. 链接没错但一直转圈失败，是网络问题：等会儿重试，或者先用浏览器把插件文件下载到手机，改走【从本地安装插件】。

详细的安装步骤和官方示例插件地址在[插件安装与音源配置.md](插件安装与音源配置.md)第二节。

## 七、下载的歌曲文件名很乱，能改吗

暂时不能在应用里改。官方的解释是歌曲信息没有写进音频文件，应用按歌名规则生成文件名来区分。介意文件名的，把文件拷到电脑上批量重命名；下载时可选音质、本地歌曲怎么播这类操作集中在[本地歌曲与下载管理.md](本地歌曲与下载管理.md)。

## 八、怎么确认我装的是正版

两个硬指标：

- 包名是 `fun.xwj.musicfree`（在系统设置 → 应用信息里看）。
- 应用市场里那些同名软件与官方无关，官方只在 GitHub 发布页和公众号「一只猫头猫」发布；网上流传的收费版、会员版都是仿冒，遇到直接卸载。

核对安装包版本和 MD5 的方法见[下载与安装教程.md](下载与安装教程.md)。
