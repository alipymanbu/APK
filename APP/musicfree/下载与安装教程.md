## 一、先分清官方渠道和仿冒品

MusicFree 是开发者 maotoumao（猫头猫）维护的开源项目，代码在 GitHub 仓库 `https://github.com/maotoumao/MusicFree`，按 AGPL 3.0 协议开源。官方明确说明发布渠道只有两个：

- GitHub 的发布页：`https://github.com/maotoumao/MusicFree/releases`
- 微信公众号「一只猫头猫」

官方仓库特别提醒过两类「同名但无关」的东西，遇到别下载：

| 你看到的 | 实际情况 |
| --- | --- |
| 小米 / 华为 / vivo 等手机应用市场里的「MusicFree」 | 官方声明与本项目无关，是套用名称和图标的广告软件 |
| 各种站点上的「收费版」「会员版」MusicFree | 项目本来就开源免费，收费版本身就是仿冒 |

另外，网上有一些基于它二次开发、改了名字的音乐播放器（比如「速悦音乐」），官方已声明这类项目未遵守开源协议。想用原版，认准上面的官方渠道，或者用本篇给的网盘资源。

## 二、获取安装文件

如果你从 GitHub Releases 下载，页面里会按版本列出 apk 安装包，选最新版本下载即可，具体文件名以发布页当时展示为准；打不开 GitHub 时，官方也说可以把地址里的 `github` 换成 `gitcode` 再访问。

不想折腾网络问题的，直接转存这份 **MusicFree 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/ba6bf76bd98f](https://pan.quark.cn/s/ba6bf76bd98f)，转存到自己的网盘后下载 apk 文件安装。这份安装包的信息如下，下载后可以核对一遍：

| 项目 | 值 |
| --- | --- |
| 版本 | 0.7.77 |
| 包名 | fun.xwj.musicfree |
| 安装包大小 | 26.78 MB |
| MD5 | 6948A7AB7F29ED98A3C48C7174C059E0 |

核对 MD5 的办法：手机上可以用带校验功能的文件管理器，电脑上用 PowerShell 敲：

```powershell
Get-FileHash "下载路径\musicfree_v0.7.77.apk" -Algorithm MD5
```

算出来的值和表中一致（不区分大小写）就说明文件没坏。包名是 `fun.xwj.musicfree`，装完在系统应用信息里看到这个名字，才说明装的是这个版本。官方一直在更新，发布页上可能出现比 0.7.77 更新的版本，上面的表格描述的只是这份网盘安装文件资源本身。

## 三、安装步骤

1. 把 apk 文件传到手机（网盘客户端直接下载，或数据线拷贝）。
2. 在文件管理器里点开 apk。第一次装会提示「不允许安装未知来源应用」，按提示允许你的文件管理器「安装未知应用」即可。
3. 等安装完成，打开应用。鸿蒙系统（Harmony OS）同样适用这套流程。

系统版本别太老：官方从 v0.5.0 版本起的更新说明写明仅支持 Android 7.0 及以上设备，老手机装不上或装上闪退先核对系统版本。如果安装时提示包损坏或签名冲突，多半是下载不完整，或者手机上已经装过一个同名仿冒品（签名不同无法覆盖安装）——先把旧的卸载再装。装完搜不到歌不是坏了，是因为软件本身不带音源，接着看下一篇装插件就行：[插件安装与音源配置.md](插件安装与音源配置.md)。

## 四、手机版之外还有什么

同一个作者还有一个独立的桌面版项目 MusicFreeDesktop（仓库地址 `https://github.com/maotoumao/MusicFreeDesktop`），界面和操作方式与手机版不同，插件管理在主界面左侧。本套文档其余几篇以安卓版为准；使用中的具体问题集中在[常见问题排查.md](常见问题排查.md)。
