# MusicFree 插件安装与音源配置

> MusicFree 装好之后搜索是空的，这不是故障——它本身不带任何音源，搜歌、播放、导歌单全靠插件。本篇讲插件怎么装、怎么更新、装不上怎么处理。还没装应用的先看[下载与安装教程.md](下载与安装教程.md)，装好插件后的日常操作看[基础使用与个性化设置.md](基础使用与个性化设置.md)。

---

> [!IMPORTANT]
> **MusicFree 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/ba6bf76bd98f](https://pan.quark.cn/s/ba6bf76bd98f)

## 一、为什么必须装插件

打开 MusicFree，界面上有搜索框、歌单页、排行榜这些入口，但你输入歌名什么也搜不出来。原因很简单：软件只是一个播放器，所有音源（搜歌、放歌、歌词、歌单）都由插件提供。装了什么插件，你就能搜到什么；没装插件，它就是个空壳。

插件在软件里的形态就是一个文件，后缀是 `.json` 或 `.js`。装插件就是把这个文件的地址（或文件本身）交给 MusicFree。

## 二、从网络安装（最常用）

1. 打开 MusicFree，点左上角按钮呼出侧边栏。
2. 点【插件设置】。
3. 点右下角的「+」号。
4. 选【从网络安装插件】。
5. 粘贴插件链接，确认。

链接必须是**以 `.json` 或 `.js` 结尾的网址**，贴网页地址、贴一段 JSON 文本都会失败。官方维护了一个示例插件仓库（GitHub 地址 `https://github.com/maotoumao/MusicFreePlugins`），官方文档里给出的示例订阅链接是：

```text
https://gitee.com/maotoumao/MusicFreePlugins/raw/master/plugins.json
```

官方仓库的说明文档里另给过一个 gitcode 的地址：`https://raw.gitcode.com/maotoumao/MusicFreePlugins/raw/master/plugins.json`，两个都是官方给的入口，哪个装得上用哪个；插件源后续可能变化，以官方站点 `https://musicfree.catcat.work/usage/mobile/install-plugin.html` 当时展示的为准。

安装完成后，插件列表里会多出若干插件，每个对应一个音源平台。回到首页搜索任意歌名，结果会按插件分组展示。

两点提醒：

- 示例插件来自网络公开接口，并且官方说明**过滤掉了所有付费、试听歌曲**，所以热门新歌搜不到是正常现象，不是你操作错了。
- 第三方插件和示例插件不是一回事。装别人做的插件前自己掂量一下来源是否可靠，来路不明的插件不要装。

## 三、从本地文件安装

如果你手里已经有插件文件（比如朋友发你的、自己下载的 `.json` / `.js` 文件）：

1. 同样进入【插件设置】→ 右下角「+」号。
2. 选【从本地安装插件】。
3. 在文件选择器里选中那个文件即可。

网络安装一直失败时，也可以先用浏览器把插件文件下载到手机，再走本地安装，绕开网络问题。还有一条更省事的路：在文件管理器里直接点开手机里的 `.js` 插件文件，选择用 MusicFree 打开，它会被当作插件装进去——这个打开即装的行为对音频文件是另一回事（`.mp3` 打开是直接播放），见[本地歌曲与下载管理.md](本地歌曲与下载管理.md)第一节。

## 四、用订阅保持插件更新

订阅地址和「从网络安装」填的地址是同一个东西。把上面的 `plugins.json` 链接添加为订阅后，插件列表页会出现【更新订阅】按钮，点一下就能拉取订阅源里所有插件的最新版本。音源接口经常变，插件失效时先试试更新订阅，很多「突然不能用」靠这一步就能解决。

## 五、装不上怎么办

按顺序核对：

1. **看链接结尾**：是不是 `.json` 或 `.js` 结尾，复制的时候有没有带上多余的空格或中文标点。
2. **确认指向的是 MusicFree 插件**：普通网站的 JSON 数据不是插件。
3. **换个时间再试**：官方说明插件安装失败常见于网络错误，等一会儿重试，或者改走本地安装（先用浏览器把文件下载下来）。
4. 装上了但搜不到歌、搜到的歌播不了，属于另一类问题，去[常见问题排查.md](常见问题排查.md)对号入座。
