## 一、为什么会困惑

你在应用商店搜这个系列会出来两个官方应用：名字一个带 Player、一个只有三个字母，图标风格相似，都说自己免费无广告。它们不是重复上架——官方在 [kmplayer.com](https://kmplayer.com) 上给两者各开了独立页面，是**一条产品线里的两档**：KMPlayer 是全功能版，KMP 是精简版。你两个都装也没冲突（包名不同，可共存），但多数人只需要一个。

## 二、对照表

信息取自两个官方页面（截至 2026-09，以官方页面当时显示为准）：

| 维度 | KMPlayer（com.kmplayer） | KMP（com.kmp.video） |

| 体积 | 大（本文档所依据的安装包 195.86M） | 小（官方以「轻量」描述，具体以商店显示为准） |

| 云盘（Dropbox/OneDrive） | 有 | 无 |
| 网络协议（FTP/SMB/UPnP 等） | FTP、FTPS、SFTP、UPnP、SMB、WebDAV、NFS | 页面未列，只有 URL 播放 |
| Wi-Fi 与电脑互传 | 有 | 未列 |

| VIP 订阅功能（磁力、GIF、裁剪、MP3 转换） | 有 | 无 |

## 三、怎么选

按你的实际用途对号入座：

- **只在手机上看下载好的视频**，不碰网盘、NAS、投屏 → KMP 够用，界面更干净、占资源少。
- **片库在电脑共享、NAS 或网盘里** → 选 KMPlayer，KMP 页面没列这些能力。
- **要投电视、要字幕搜索、要小窗之外的完整功能集** → 选 KMPlayer。
- **手机存储紧张、只要个能播的** → KMP；它同样内置常见编解码器，主流格式直接播。

一条实用判断：**拿不准就先装 KMPlayer**——它覆盖 KMP 的全部基础播放能力，功能只多不少；先用着，觉得太重再换 KMP 也不迟。
