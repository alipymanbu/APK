## 一、怎么用这篇

先对症状，再看对应小节，别从头读到尾。同一个症状有多个成因时，按文内顺序试——排在前面的命中率最高。动手前先确认你的安装包没问题：对照 [下载与安装教程.md](下载与安装教程.md) 的 MD5 校验一遍，排除文件损坏。

## 二、有画面、没声音

1. **先排除音量与静音**：右侧上下滑手势调音量，看是不是误触静音；再试耳机/外放切换。
2. **多半是音轨编码不支持**：最常见的是 **EAC3（Dolby Digital Plus）音轨**——画面正常、声音全无，基本就是它。此时 KMPlayer 自带解码器啃不动这条音轨，需要外部解码器支持（见下节的获取方式）。要注意：官方外部解码器是 32 位构建，**64 位机型加载不了**，报错会原样返回。
3. **换一个音轨**：MKV 常有多条音轨，菜单里切到另一条（如 AAC 轨）确认是否单轨问题。
4. 两条路都走不通时，这部片在当前环境下就播不出声音——转码成 AAC 音轨，或换一个原生支持该编码的播放器。

## 三、弹出「外部解码器 / libvlcjni.so / arm64-v8a」之类的报错

这条报错的意思是：**KMPlayer 想加载外部解码库，但没找到能用的**。常见触发场景与处理：

| 原因 | 处理 |
| --- | --- |
| 从未放过外部解码器 | 只在遇到特定音视频编码时才需要；能正常播就无视它 |
| 解码库放错位置 | 从官方解码器页面下载对应构建，解压后放到 KMPlayer 指定的解码器目录（应用内会提示路径） |
| 机型不匹配（32/64 位） | 官方构建为 32 位，64 位机型加载不了——别反复重装同一个包 |
| 存储权限没给 | 见 [下载与安装教程.md](下载与安装教程.md) 的权限表 |
| 想绕开外部库 | 播放设置里把解码方式切回**内部解码器**，多数片源不需要外部库 |

官方解码器下载入口在 [kmplayer.com](https://kmplayer.com) 的 Android codec 页面；第三方来历不明的 `.so` 文件不要装。

## 四、MKV 打开黑屏 / 只有声音没画面

MKV 是容器，里面装的编码（H.265、AV1 等）你手机未必硬解：

1. 播放设置 → 解码器，把视频解码方式在**硬件解码**与**软件解码**之间切换试——硬解黑屏就换软解，软解卡就换硬解；
2. 仍黑屏，试另一条字幕/音轨都正常的片源，确认是单文件问题还是全文件问题；
3. 全文件问题 → 更新应用到新版，或对照格式清单确认编码是否在支持范围内（[支持的视频格式与系统要求.md](支持的视频格式与系统要求.md)）。

## 五、4K / 高码率视频卡顿

- **开硬件解码**：播放设置 → 解码器，视频解码选硬件加速。手机 SoC 支持的格式硬解后 CPU 占用大幅下降，这是第一步。
- **关掉吃性能的叠加项**：外挂特效字幕（ASS 大量特效）、画面色彩微调、倍速播放都会加负担，先关再试。
- **码率超能力**：同为 4K，蓝光原盘码率可能是流媒体版的几倍。硬解开了还卡，说明这段文件超出你机型的解码规格，换低码率版本。
- 同时检查是否边传边播（Wi-Fi 传输中）——网络瓶颈也会表现成卡顿，见 [网络与云盘播放教程.md](网络与云盘播放教程.md)。

## 六、音画不同步、字幕抢台词

- **跳转后偏了几秒**：属常见现象，播放中用字幕/音轨同步的偏移设置微调（操作见 [字幕设置与乱码解决.md](字幕设置与乱码解决.md)）。
- **越播越偏**：多为片源本身时间轴有问题，用同步设置给一个固定偏移量校正。
- 先分清偏的是**字幕**还是**声音**：字幕问题调字幕偏移，声音问题换音轨或转码，两者设置不在一处。

## 七、闪退 / 打开一片空白 / 文件列表缺文件

按顺序试，多数到第 2、3 步就好：

1. **存储权限没给**：系统设置 → KMPlayer → 权限，开文件访问（详见 [下载与安装教程.md](下载与安装教程.md)）。
2. **清缓存**：系统设置 → 应用 → KMPlayer → 存储 → 清除缓存（先别点「清除数据」，那会删掉你的播放列表与书签设置）。
3. **文件所在目录太偏**：确认文件管理器能看到它，再到主页用「导入外部文件」手动定位。
4. **安装包损坏**：校验 MD5，不一致就重新下载。
5. 仍闪退 → 记下闪退发生在哪个操作（开某个文件、开小窗、连网络），这是排查时唯一有用的信息。
