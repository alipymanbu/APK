## 一、本篇解决什么

看剧碰上外挂字幕，最常见的三个坑：字幕压根不显示、显示出来是乱码、比台词快半拍。这三个在 KMPlayer 里都有对应设置，全部在播放界面右上角的**菜单 → Subtitle（字幕）**里。支持的字幕格式清单见 [支持的视频格式与系统要求.md](支持的视频格式与系统要求.md)，本篇只讲操作。

## 二、让字幕显示出来

按命中率从高到低排查：

1. **文件名是否一致**。把 `video.mkv` 和 `video.srt` 放同一目录、改成同名，多数情况下打开视频字幕就自动挂上了。
2. **有没有被手动关掉**。播放中点屏幕调出控制栏 → 右上角菜单 → Subtitle，看字幕轨道是否选到了「关闭」，切到你的字幕轨。
3. **内封多字幕轨的切换**。MKV 里常塞了多条字幕轨（英文/中文），同一菜单里换轨道即可。
4. **手动载入**。文件名对不上时，在 Subtitle 菜单里选择从存储中挑选字幕文件，定位到那个 `.srt` / `.ssa`。

## 三、中文字幕乱码

乱码的根源几乎都是**编码不对**：字幕文件是 GBK/GB2312 存的，播放器按 UTF-8 读，中文就成了问号或方块。

1. 播放界面菜单 → Subtitle → 字幕编码，先试 **UTF-8**；
2. 还乱就换 **GBK**（老字幕、国内压制组早期作品常用）；
3. 两个都试了仍乱，说明文件本身的编码声明有问题——用手机上的文本编辑器（或电脑记事本）打开那个字幕文件，另存为 UTF-8 编码，再放回原位。

另有一类「乱码」是**字体缺字**：字幕内容能读但汉字显示成空白方框。同样在 Subtitle 菜单里换一个中文字体即可。

## 四、字幕不同步（慢半拍 / 抢台词）

外挂字幕的时间轴偶尔会偏，KMPlayer 允许播放中直接校正：

- 在 Subtitle 菜单找**同步 / 偏移（Sync / Delay）**设置，按秒或毫秒把字幕整体提前或推后；
- 偏得不多时逐次微调，边调边看，对齐一句台词即停；
- 若字幕是视频内封的多轨之一，先确认选对了轨再调偏移，别对着英文字幕轨去修中文的错位。

## 五、字幕的显示样式

同一菜单里可调三项，改完即时生效：

| 设置 | 常见用法 |
| --- | --- |
| 大小 | 屏幕小（手机）调大、平板调小 |
| 颜色 | 画面亮时改白字黑边，画面暗时改黄字 |
| 位置 | 往上挪，避开视频平台的水印或全面屏手势条 |

字幕挡脸、压水印这类问题，调位置比调大小管用。

## 六、没有字幕文件时

官方版带**字幕下载搜索**：在 Subtitle 菜单里发起搜索，按当前影片找匹配字幕。搜到的结果要自行核对版本（导演剪辑版与流媒体版时间轴常常对不上，对不上就用第四节的偏移去修）。网络受限时这个功能可能搜不出结果，属正常，换个字幕站点下载后走第二节的手动载入。

## 七、还是搞不定

字幕类问题九成在编码与轨道上；如果同一部片**画面或声音也不对**（无声、卡顿、黑屏），那不是字幕的问题，转 [播放无声与卡顿问题解决.md](播放无声与卡顿问题解决.md)。
