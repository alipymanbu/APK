## 一、先说结论

KMPlayer 安卓版内置常见编解码器，MKV、MP4、AVI、RMVB、TS、FLV 这类主流容器基本都能直接播，音频覆盖 MP3、AAC、FLAC、OGG 等；字幕这块列出的格式最多——SRT、ASS、SSA、VobSub 这些都能读。你下载前可以用本篇清单核对：自己的文件在不在列表里，不在就先换播放器或转码，装了也白装。

## 二、视频格式

官方页面与商店信息列出的视频容器与编码（版本更新可能调整，以[官方页面](https://kmplayer.com/mobile)当时显示为准）：

| 类别 | 支持 |
| --- | --- |
| 容器格式 | MKV、MP4、AVI、MOV、WMV、RMVB、TS、MPG、FLV、M4V、3GP、WebM、OGM |
| 视频编码 | H.264/AVC、H.265/HEVC、VP8/VP9、MPEG-1/2/4、WMV7/8/9、RealVideo、DivX/XviD、MJPEG |
| 高规格 | 4K、UHD、Full HD、60FPS 播放 |

两点说明：

- **HEVC（H.265）** 播放支持，但能否流畅取决于你手机的硬件解码能力，放不动时的处理见 [播放无声与卡顿问题解决.md](播放无声与卡顿问题解决.md)。
- 8K 播放在官方 PC 版页面有列，手机端以实测为准。

## 三、音频格式

| 类别 | 支持 |
| --- | --- |
| 常见 | MP3、AAC、WAV、WMA、OGG、M4A |
| 无损 | FLAC、ALAC、APE、WavPack |
| 其他 | AC3、Vorbis、DTS（视音轨而定）、AMR、Opus、PCM/LPCM、ADPCM |

把视频当音乐听也是常见用法：打开视频文件，切到音频播放模式即可；提取成独立 MP3 属于 VIP 功能（见第五节）。

## 四、字幕格式

| 类别 | 支持 |
| --- | --- |
| 文本字幕 | SRT（SubRip）、SSA/ASS（含样式）、SAMI、MicroDVD、SubViewer、MPL2、TMPlayer、WebVTT、PJS |
| 图形字幕 | VobSub（SUB+IDX）、DVD、DVB、PGS |
| 内挂字幕 | MKV、MP4 容器内的内封字幕轨 |

文本字幕的**编码**（UTF-8 / GBK）和显示样式都能调，中文字幕乱码、不显示的处理步骤在 [字幕设置与乱码解决.md](字幕设置与乱码解决.md)。

## 五、免费版与 VIP 的分界

播放器本体免费，官方页面标注无广告。**VIP 是单独的订阅**，覆盖的是「剪辑加工」类功能：

| 功能 | 免费 | VIP |
| --- | --- | --- |
| 本地/网络/云盘播放、字幕、投屏、小窗 | 有 | - |
| 手势、倍速、A-B 循环、书签、均衡器 | 有 | - |
| 磁力链客户端（边下边播） | - | 有 |
| GIF 制作（GIF Toast） | - | 有 |
| 视频/音频裁剪（Crop Media） | - | 有 |
| 视频转 MP3（MP3 Converter） | - | 有 |
| 自定义主题 | - | 有 |

官方页面标注 VIP 有 3 天免费试用，试用到期会自动续费——只是想看片的话，不订阅不影响任何播放功能；打算订阅则注意在试用结束前手动取消。

关于订阅本身，官方服务条款给出的事实：

- **订阅周期可选 1 个月、6 个月、12 个月**，通过应用内支付开通，按所选周期自动续订；
- **价格与具体条款以商店结算页当时显示为准**，官方页面与条款都不写死金额，网上抄的价目表未必是你的地区价；
- **取消在商店侧操作**：Google Play → 点右上角头像 → 付款和订阅 → 订阅 → 选 KMPlayer → 取消订阅。取消后当前周期仍可用到已付费的到期日，之后不再扣费；
- 试用次数有第三方指南提到「每个 Google Play 账号限一次」，此说法未见官方页面确认，以商店结算页当时显示为准；想避免误扣，**在试用结束前一天取消**最稳。

同一开发方还有个轻量版 KMP（无 VIP、无云盘），两者怎么选见 [和KMP播放器怎么选.md](和KMP播放器怎么选.md)。

## 六、系统要求与版本对照

- **安卓**：Android 5.0 及以上；**iOS**：iOS 11 及以上（两处均为官方标注）。
- 包名 `com.kmplayer`（Google Play 与本篇安装包一致）。
- 本篇所依据的安装包：**版本 46.04.235、195.86M**（记录于 2026-09-21）。官方与商店的最新版本会随时间变化，拿不准时以官方页面当时显示为准；网盘里那一版以 [下载与安装教程.md](下载与安装教程.md) 表格中的信息为准。
