## 一、什么时候用得上

片库放在 NAS、电脑共享文件夹或网盘里，手机存储装不下时，你有两个选择：先下载到本地，或者让 KMPlayer **直接连过去播**。官方页面列出的联网能力覆盖三类：局域网协议、云盘账户、URL 流。三类都能在主界面右上角的**菜单**里找到入口，本篇挨个讲。

顺带一提：按官方服务条款，**拒绝存储权限后网络播放仍然可用**（HTTP、HTTPS、FTP、FTPS、SMB、WebDAV 等协议照常）——所以只看网络内容的机器，可以不给文件访问权限，见 [下载与安装教程.md](下载与安装教程.md) 的权限表。

## 二、局域网播放（SMB / FTP / UPnP 等）

官方标注支持的协议：**FTP、FTPS、SFTP、UPnP、SMB、WebDAV、NFS**——基本覆盖了家用 NAS 与 Windows 共享文件夹。

以最常见的「播电脑里共享的视频」为例（SMB）：

1. 电脑上先把视频文件夹设为共享（Windows：文件夹右键 → 属性 → 共享）。
2. 手机与电脑连**同一个 Wi-Fi**。
3. KMPlayer 主界面菜单 → 网络 / 外部媒体 → 添加 → 协议选 **SMB**，填电脑的局域网 IP 和共享文件夹名。
4. 连上后该目录会出现在你的媒体列表里，点开即播。

其他协议同理，只是填的参数不同：FTP 填地址与账号密码；UPnP（DLNA）一般自动发现局域网设备，不用填 IP。NAS 用户多用 SMB 或 UPnP，按自己设备文档给的来。

**常见连不上**：手机和电脑不在同一网段（一个 5G Wi-Fi 一个有线）、电脑防火墙拦了文件共享、共享没给读权限。逐条核对，比换协议快。

## 三、云盘播放（Dropbox / OneDrive）

1. 主界面菜单 → **云（Cloud）** → 添加云。
2. 选 Dropbox 或 OneDrive，登录你的账号。
3. 授权返回后，云盘目录会进主页的媒体列表，视频直接**边下边播**，不必先整份下载。

国内网盘（百度网盘等）不在官方支持列表里，只能下载到本地后再播。

## 四、URL 播放（直播流 / 直链）

菜单里选 **URL 播放（URL Stream）**，粘贴一个视频直链或直播流地址（`.m3u8`、`.mp4` 直链等），确定即播。用途：

- 看自己服务器上的监控、录像回放；
- 播放网盘「直链下载」导出的地址；
- 官方页面还列了 URL 播放 YouTube 的能力，能否用受所在网络环境影响，不作保证。

地址失效、404、只有声音没画面，多半是链接过期或编码不被支持，前者换新地址，后者对照 [支持的视频格式与系统要求.md](支持的视频格式与系统要求.md)。

## 五、手机与电脑互传（Wi-Fi 传输）

不插数据线传文件的办法，官方叫 Sharing via Wi-Fi：

1. 手机与电脑连同一个 Wi-Fi，在 KMPlayer 里开启 Wi-Fi 传输。
2. 界面会给出一个地址，在**电脑浏览器**里打开它。
3. 网页上可双向操作：把电脑的视频传进手机、把手机的视频传到电脑，音乐和字幕文件同样适用。

它是传输功能不是播放功能——传完的文件回到本地列表里播，权限与导入见 [下载与安装教程.md](下载与安装教程.md)。

## 六、投屏到电视（Chromecast）

手机与 Chromecast 设备在同一 Wi-Fi，播放界面找投屏图标，选中电视后画面转到大屏，手机变遥控器。没有 Chromecast 时，电视盒子自带的 DLNA/投屏协议是否可用取决于电视端，官方页面明确列出的只有 Chromecast。

## 七、网络播放的边界

- 网络路径上的文件**能否播**，仍受格式清单约束，同本地文件（[支持的视频格式与系统要求.md](支持的视频格式与系统要求.md)）。
- 网络卡、缓冲多，先分清是 Wi-Fi 弱还是片源码率太高；本机解码卡顿则见 [播放无声与卡顿问题解决.md](播放无声与卡顿问题解决.md)。
- 手势、倍速、书签在网播时同样生效，见 [手势与播放控制技巧.md](手势与播放控制技巧.md)。
