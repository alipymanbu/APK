# 各版本彩蛋触发方法

> 本篇讲怎么把安卓历代系统彩蛋一个个点出来：系统里手动触发的路径，以及在 Easter Eggs 里直接触发的操作。

## 一、先搞清楚两种触发方式

彩蛋原本是**藏在系统设置里**的，标准路径是：

```
设置 → 关于手机 → 版本号（连点多次）
```

连点几下「安卓版本号」那一栏，彩蛋界面就出来了。问题是：你的手机停在哪个安卓版本，就只有那一个彩蛋，想看别的版本得换手机或者刷系统。

Easter Eggs 干的事就是**把这些彩蛋的代码整份收进一个应用**：你打开它，列表里从 Android 2.3 一路排到最新版，点进哪一条就能触发哪一条，不用动系统设置、不用 root。

## 二、在 Easter Eggs 里怎么触发

1. 打开应用，往下滑，会看到按安卓版本排好的菜单列表。
2. 点你想看的那个系统条目，进入它的彩蛋界面。
3. 不同版本的玩法不一样，常见就三种：**长按**、**滑动**、**点按后等待**。每个条目里都带文字说明，照着提示做即可。
4. 以 Android 15 为例：进去后是一个三角符号，**长按它不动**，等它加载，彩蛋画面就出来了。

触发过程中界面可能短暂黑屏或停顿一两秒，那是彩蛋本身在加载，不是卡死——多等一会儿，判断依据见 [常见问题与排查.md](常见问题与排查.md)。

## 三、历代彩蛋都是什么、怎么玩

下表是各版本彩蛋的形态与触发要点。**你手机系统版本不同，路径可能有细微差别**（不少厂商改过设置页的层级），以你自己机器上看到的为准。

| 版本 | 彩蛋形态 | 触发/玩法要点 |
| --- | --- | --- |
| 2.3 Gingerbread | 一张「僵尸姜饼人」静态插画 | 连点版本号直接出现，没有互动 |
| 3.0 Honeycomb | 蜜蜂标志 + 一行提示文字 | 连点出现，静态 |
| 4.0 Ice Cream Sandwich | 复古机器人 + 满屏飞行的机器人动画 | 连点出第一层，**反复长按**那个机器人，它会变大，再进到飞行画面（第二层） |
| 4.1–4.3 Jelly Bean | 一颗大果冻豆，点开后弹出满屏小豆子 | 点一下变笑脸，**长按**进入小游戏，用手指把豆子甩来甩去 |
| 4.4 KitKat | 可旋转的「K」→ KitKat 标志 → 历代标志拼图 | 先连点出 K 并旋转，再长按进到拼图层 |
| 5.0 Lollipop | 一个 Flappy Bird 玩法的小游戏 | 点棒棒糖换色，长按进入游戏，操控小机器人穿过糖果 |
| 6.0 Marshmallow | 同款小游戏，障碍换成棉花糖 | 操作方式与 5.0 一致 |
| 7.0 Nougat | 养猫玩法 | 进入后长按出猫咪表情，配合快捷设置里的「空碗」等选项喂猫 |
| 10 | 「Android 1 0」几个可拖动的字符 | 把 `1` 拖进 `0` 里拼成 `Q`，再点几下进到数字绘图小游戏 |
| 11 | 转盘 + 云养猫 | 按住白色旋钮顺时针转到头，转过 `10` 出现 `11` 与猫头像，再去电源菜单的控制项里加「猫控制」 |
| 12 | 时钟 | 把表盘指针拨到 **12:00**，界面炸开成彩蛋 |
| 13 | 时钟 + 表情包 | 拨到 **13:00**（即 1 点整的位置），长按屏幕换一批表情 |
| 14 | 太空探索小游戏 | 连点出徽标后**长按不放**，徽标发射进入太空，用手势控制推进器飞向最近的恒星 |
| 15 | 三角标志 | 长按三角等待加载，进入彩蛋 |

**几个通用技巧**：

- 连点版本号时要**快**，间隔太长系统不会响应；
- 第一层画面出来后没反应，先**长按**图形再说——大部分彩蛋的第二层都靠长按解锁；
- 12 之后的版本普遍多一道「拨时钟 / 长按标志」的工序，直接连点只到第一层。

## 四、只想快速体验某个彩蛋

- 想玩**能玩起来的小游戏**：优先 5.0 / 6.0 的穿障碍、11 的云养猫、14 的太空飞行。
- 想看**纯画面**：2.3、3.0 这类早期版本就是一张图，点开即走。
- 想**对比同一彩蛋在不同版本的差异**：12 与 13 都是时钟，只有拨到的时刻与后续互动不同，连着看差别最明显。

设置项怎么配合着调（主题、图标形状、时间线），见 [主题与图标形状设置.md](主题与图标形状设置.md)。
