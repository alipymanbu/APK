## 一、30 秒先跑起来

第一遍照这个顺序走（界面按钮的叫法随版本略有差异，以你装的这版为准）：

1. 打开应用，点 **创建脚本**（主界面没有就点右下角的 **+**）；
2. 填一个脚本名，选**情景类型**：`简单` 或 `智能`——先选 `简单`；
3. 点右上角**保存**，脚本会出现在场景列表里；
4. 点列表里这条脚本右边的**开始**，把上一节要的权限放行（见 [下载与安装教程.md](下载与安装教程.md) 第四节）；
5. 画面跳到桌面后，用悬浮控制条进入动作设置，把要点的位置录进去（第三节），再点开始。

跑通一遍之后再回头调参数，比先啃设置页快得多。

## 二、简单模式和智能模式怎么选

| | 简单模式（Regular） | 智能模式 |
| --- | --- | --- |
| 触发方式 | 固定位置、按设定循环 | 看屏幕内容满足条件才动 |
| 要不要截屏 | 不要 | 要（会弹屏幕捕获授权） |
| 适合什么 | 固定按钮反复点、匀速滑动 | 按钮会变位置、有弹窗、要等某个画面出现 |
| 上手成本 | 低，建完就能跑 | 要先学会条件与触发器（见 [图像检测触发条件使用指南.md](图像检测触发条件使用指南.md)） |

拿不准就先用简单模式；发现「点早了/点空了」再换智能模式。

## 三、把点击位置录进去

1. 在脚本界面进入**动作设置**（一般是一个设置/编辑图标）；
2. 点**记录手势**按钮，回到目标应用的屏幕上；
3. 直接在你想让脚本点的地方点一下、或划一下，屏幕上会留下一个**圆圈标记**，那就是脚本将来动手的位置；
4. 回到动作设置，新录的动作已经排进列表，可以继续加下一个。

一条脚本就是一串按顺序执行的动作：录三个标记，它就依次点三下。位置录错了删掉重录即可，不会影响脚本里其他动作。

## 四、动作类型有哪些

一个动作不只能是「点一下」，可选类型包括：

- **点击**——指定位置按下与抬起；
- **滑动**——指定起点、终点与滑动时长；
- **暂停**——插一步等待，用来卡节奏；
- **通知**——触发一条系统通知，常用来标记脚本跑到哪一步；
- **写入文本 / 系统操作**——自 3.4.0 起加入，往输入框填文字、执行系统级操作（你手里 3.5.0 已包含；界面里叫什么以实际显示为准）。

智能场景里还有几种只在条件满足时起作用的联动动作（改计数器、切换条件状态、发 Intent），放在 [图像检测触发条件使用指南.md](图像检测触发条件使用指南.md) 里讲。

## 五、参数在哪调、怎么设

进入动作的编辑页，能调的核心参数就这几个：

| 参数 | 管什么 | 怎么估 |
| --- | --- | --- |
| 按压时长 | 手指按下到抬起的间隔 | 按钮吃单击就短按；要触发长按菜单就拉长 |
| 滑动时长 | 一次滑动花的时间 | 拉列表用长一点（稳），翻页用短一点（快） |
| 位置 | 动作落在屏幕哪一点 | 第三节录制后可微调圆圈位置 |
| 执行前最小延迟 | 这个动作完成后至少歇多久再走下一个 | 目标应用反应慢就加大，否则容易点空 |

脚本层面还有两处总控（一般在脚本的设置页）：

- **计数**：整套动作循环执行多少次；
- **持续时间**：整套脚本最多跑多久，到点自动停。

另外可以调整场景里各动作的**优先级/顺序**，先跑谁后跑谁在动作列表里拖动调整。

## 六、开始、暂停与悬浮控制

场景启动后会回到桌面，控制权在悬浮条上：**开始**让脚本跑起来，**暂停**随时打断，改完脚本再继续。脚本在跑的时候你自己的手指仍然能操作屏幕，所以发现点歪了，先暂停再回应用里改位置，比让它继续空点安全。

两个容易踩的点：

1. 悬浮条不见了 = 悬浮窗权限被系统收走了，去 [常见问题与故障排查.md](常见问题与故障排查.md) 第一节捞回来；
2. 设了「持续时间」的脚本到点会自己停，别误以为是卡死了。
