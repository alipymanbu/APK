## 一、先确认这是哪个应用

Klick'r 是一款开源的安卓自动点击器，**以前叫 Smart AutoClicker**，所以你在不少下载站看到的还是旧名或「klickr 连点器」这类写法，指的都是同一个应用。开发者是 Buzbuz Software（作者 Kevin Buzeau），代码以 GPL-2.0-or-later 许可开源在 [GitHub 仓库](https://github.com/Nain57/Smart-AutoClicker) 上，包名是 `com.buzbuz.smartautoclicker`。

网上搜到的往往是官方最新版，而网盘里发出去的是当时留存的那一版，两者常常不是同一个版本。**涉及版本号、包名、体积，以下面这份本地安装包的事实为准**：

| 项目 | 值 |
| --- | --- |
| 版本 | 3.5.0 |
| 包名 | `com.buzbuz.smartautoclicker` |
| 安装包大小 | 28.32M |
| MD5 | `A2CF698422BAFDE049042588A1C51FA2` |
| 开发者 | Buzbuz Software |

官方最新版以 [GitHub Releases 页面](https://github.com/Nain57/Smart-AutoClicker/releases) 当时显示为准（截至 2026 年 9 月，官方已发布到 4.0.5）。装哪个版本都行，但别混着装——同一个包名直接覆盖安装即可。

## 二、从哪里拿安装包

三条路，选一条就够：

1. **网盘这份（3.5.0）**：打开 [Klick'r 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8c05e65ded78)，把 `klickr_v3.5.0.apk` 转存或直接下载到手机。文件 MD5 与上表一致才是完整包。
2. **Google Play**：认准开发者 Buzbuz Software 的 [Klick'r - Smart AutoClicker 页面](https://play.google.com/store/apps/details?id=com.buzbuz.smartautoclicker)，好处是以后自动更新。
3. **开源渠道**：[F-Droid 页面](https://f-droid.org/packages/com.buzbuz.smartautoclicker/) 或 [GitHub Releases](https://github.com/Nain57/Smart-AutoClicker/releases)，两者都给官方构建的 APK；GitHub 上还另有一个[混淆版发布页](https://github.com/Nain57/Smart-AutoClicker/releases/tag/obfuscation-start)，是官方专门给「被某个应用拦住了」的场景准备的（详见 [常见问题与故障排查.md](常见问题与故障排查.md)）。

三条路装的是同一个应用（包名一致）。**只选一条**，别把商店版和 APK 版来回叠加装。

## 三、安装步骤

1. 把 APK 文件放到手机上（下载目录即可），点击开始安装。
2. 系统弹「禁止安装来自此来源的应用」时，是浏览器或文件管理器还没拿到「安装未知应用」权限——去设置里对该应用打开开关，再回来点一次。
3. 装完先别急着玩，把下一节的权限开齐再启动，否则点开始也不会有任何反应。

安装包 MD5 与第一节表格对不上，说明文件在传输里变了，重新下一次再装。

## 四、首次启动要开的三项权限

Klick'r 靠系统能力在别的应用上出控制条、替你执行点击，所以首次启动会连续找你要权限：

| 权限 | 干什么用 | 没给会怎样 |
| --- | --- | --- |
| 显示在其他应用上层（悬浮窗） | 在其他应用上方显示悬浮控制条 | 开始后看不到控制条，无法暂停/停止 |
| 无障碍（辅助功能） | 执行你配置好的点击与滑动 | 脚本「开始」了但屏幕上什么都没发生 |
| 屏幕捕获（投屏/录屏授权） | 图像检测要读取屏幕内容 | 用到图像条件的场景直接不触发 |

按提示一路点允许即可。屏幕捕获那一步系统会弹一个「立即开始 / 立即开始录屏」的确认框，这是安卓系统自己的弹窗，点「立即开始」才拿得到。官方在商店页的说明是：无障碍服务只用于执行你配置的点击与滑动，不需要注册账号。

只想用固定位置连点（简单模式）的话，前两项开了就能用；图像检测要等你创建智能场景时才会要第三项。

## 五、装完先做这三件验证

1. 打开应用能进主界面、能点「创建脚本」——说明包本身没问题；
2. 启动一个简单场景后，屏幕上方出现悬浮控制条——说明悬浮窗权限到位；
3. 点控制条的开始，屏幕上出现你录好的点击标记并真的点了下去——说明无障碍到位。

三条里哪条卡住，直接对号进 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 六、系统要求

- 本地这份 3.5.0 标注**需要安卓 5.2 以上**（以安装时的系统提示为准）；
- 官方最新版对系统的要求更高——F-Droid 页面上 4.0.5 标注**最低安卓 7.0**，旧手机装新版本前先看一眼 [F-Droid 页面](https://f-droid.org/packages/com.buzbuz.smartautoclicker/) 当时的说明；
- 手机系统过旧导致装不上、闪退的排查，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
