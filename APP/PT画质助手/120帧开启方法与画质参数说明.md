## 一、开 120 帧的前提

解锁只是把被隐藏的帧率选项放出来，**能不能真跑 120 帧取决于硬件**：

1. **屏幕刷新率要够** —— 选的帧率超出设备屏幕刷新率（超过硬件上限）时会弹提示，按实际情况选；
2. **性能要够** —— 帧数与分辨率都是「设备性能要足够高」才有效果，性能跟不上会卡顿、发热、耗电加剧，反而是降画质更流畅；
3. **进对局后再开** —— 由于游戏侧限制，建议每次进入对局后再开启 120FPS 帧率选项；
4. **重启生效** —— 改完手动关掉游戏再打开（流程见[解锁画质帧率使用教程.md](解锁画质帧率使用教程.md)）。

另外，游戏内画质设置里的帧率选项有时会被还原成默认显示，但**实际帧率不受影响**，以对局内的实际表现为准。找不到 120 选项、或只有 90 帧的，是画质档位与选项显示的问题，对照[解锁后没生效与帧率不显示排查.md](解锁后没生效与帧率不显示排查.md)处理。

## 二、普通版 vs 会员版

两版主流程一样（选版本 → 解锁 → 重启），差别在可调项：

- **普通版**：一键「解锁画质帧率」，把画质与帧率选项放开，不细调参数；
- **会员版/Pro**：解锁前可以逐项调整画质、帧率、画面风格、分辨率等，调完点「保存并启动游戏」。

## 三、会员版可调选项一览

| 选项 | 可选值 |
|---|---|
| 画质 | 流畅 / 均衡 / 高清 / HDR高清 / 超高清 / 极清 |
| 帧率 | 按目标帧率选择（超出屏幕刷新率会弹提示） |
| 画面风格 | 经典 / 鲜艳 / 写实 / 柔和 / 电影 |
| 分辨率 | 480P ~ 4K |
| 抗锯齿 | 关闭 / 开启 |
| 阴影 | 关闭 / 开启 |
| 画面修复 | 关闭 / 修复1 ~ 6 |
| 配置文件 | EC 或 UC 模式 |
| 音质 | 低 / 高 / 超高（仅 UC 模式可选） |

注意两点：**部分选项只在中国服、体验服里出现**，选了其它版本会自动隐藏；配置文件异常时点解锁会提示「文件修复」，点「修复」自动处理即可。

## 四、参数怎么选

- **想更清晰**：分辨率选高，前提是设备性能扛得住；
- **想更流畅**：帧数往 120FPS 方向调，同样看性能，否则效果相反；
- **改分辨率会让游戏内按键大小、位置变化** —— 这是正常现象，想恢复默认键位就在软件里选「默认分辨率」；
- 画质或帧率开高后如果卡顿、发热、掉电快，回到软件里把对应项降一档。

开完之后游戏重启不掉设置是它的正常表现；若出现闪退或选项异常，按[常见问题与闪退排查.md](常见问题与闪退排查.md)处理。
