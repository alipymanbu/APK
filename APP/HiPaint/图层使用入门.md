## 一、图层数不是固定的：看画布和设备

新建图层会碰到上限，这个上限由**画布尺寸**和**设备性能**共同决定——画布越大上限越低，设备越强上限越高。新建画布的界面上会直接显示当前设置下的最大图层数，建之前看一眼就有数。

真的不够用时两条路：

- 新建时把画布尺寸定小一档；
- 把已经定稿的部分合并成一层，给后续绘制腾位置。

这是防崩溃的保护机制，不是付费门槛——换更强的设备，上限会跟着涨。

顺带说明口径：官方页面写「支持上千个图层」，应用商店的旧描述里出现过「最多 100 个图层」的说法——两个数都对不上你手上的实际情况时，以新建画布界面显示的那个为准，页面文案更新明显滞后于版本。

## 二、混合模式：数量以你设备里列出的为准

官方页面标 24 种图层混合模式，应用商店的更新描述里出现过 27、28 种的说法——版本不同口径有出入，以你图层面板里实际列出来的为准。

上色最常用的是这几档：

| 模式 | 典型用法 |
| --- | --- |
| 正片叠底 | 压暗、上阴影 |
| 滤色 | 提亮、做发光 |
| 叠加 | 叠材质与纹理 |

## 三、图层编辑功能对照表

| 操作 | 什么时候用 |
| --- | --- |
| 复制图层 | 想在原稿基础上试一版改法，不动底稿 |
| 合并 / 栅格化 | 定稿收层；文字、形状要直接用笔刷画时先栅格化 |
| α 锁定 | 只在这一层已有像素的范围内落笔——上阴影不画出界靠它 |
| 剪辑蒙版 | 挂一层在下一层之上，效果只作用于下层有内容的部分，调色、贴纹理常用 |
| 图层组 | 几十上百层的作品整组移动、整组开关 |
| 多选图层 | 把多个元素同时挪位置、做变换 |

## 四、一个版本相关的提醒

图层界面的布局在 6.1.x 版本做过一次改版（版本说明里原话是「全新的图层界面」），网上找的老教程截图可能和你的界面对不上——按**功能名**找入口，别照截图上的按钮位置找。

图层多了之后，导出时想连图层结构一起带走，见 [导出与备份方法.md](导出与备份方法.md) 里 PSD 那一行。
