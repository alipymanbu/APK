## 一、画布上的多指手势

| 手势 | 作用 |
| --- | --- |
| 双指轻点 | 撤销 |
| 三指轻点 | 重做 |
| 双指捏合 | 缩放画布，同时可旋转 |
| 双指快速并拢（捏合复原） | 画布复位到适应屏幕 |
| 长按屏幕 | 吸管取色 |
| 画的时候另一根手指轻点屏幕 | 画出正圆、正方形或固定角度的直线 |

这套手势来自官方应用介绍的「多点触控手势」条目（iOS 与安卓两端描述一致）；个别手势在旧版本里可能没有，以你设备上的实际表现为准。

## 二、撤销总误触怎么办

双指轻点撤销用不惯可以关：「设置 → 绘画设置」里关掉双指撤销。关掉之后，撤销走撤销按钮或手绘板快捷键。

## 三、快速滑块与径向菜单

- **快速滑块**：画布上直接拖，改笔刷粗细与不透明度，不用进笔刷设置；
- **径向菜单**：官方手册的「界面与手势」里有专门章节，手绘板按键也能映射成呼出径向菜单，一触直达常用功能。

## 四、手绘板按键映射

绘王、高漫等手绘板接上手机或平板后，板子上的按键可以自定义映射成撤销、重做、调整画笔大小、呼出径向菜单。映射在应用的设置里改；能映射几个键，取决于你手绘板本身有几个可编程按键。

手势与图层操作叠着用最顺手——缩放找细节时配合 [图层使用入门.md](图层使用入门.md) 里的多图层编辑，不用来回放大缩小。
