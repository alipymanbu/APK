## 一、三条主线

先把大账记住，细节在后面各节：

1. **生成歌曲扣积分**（付费积分），具体单价以应用内充值页为准；
2. **下载成品不另外收费**——收钱的是生成那一步，不是保存那一步；
3. **官网（应用）与 API 平台是两套独立计费**，两边的会员和积分互不通用，别想着一边充值两边花。

以上为官方发布稿与官方 FAQ 的口径（截至 2026-09，以官方页面当时显示为准）。

## 二、会员与生成量

据 36 氪 2026 年 6 月的行业报道：Mureka 走「B 端开放 API + C 端会员订阅」的模式，**C 端会员 88 元/月、最多生成 180 首**，付费用户直接享有商业使用权；同一报道称其定价高于部分海外同类产品。

价格与额度随时可能调整，充值前以应用内充值页显示为准，别按上面这个数直接付钱。

## 三、哪些操作要另花钱

| 操作 | 收费口径（官方） |
| --- | --- |
| 生成歌曲 | 扣积分 |
| 下载成品歌曲 | 不另外收费 |
| 分轨导出 | 单独付费 |

**分轨**是把一首成品歌拆成独立音轨的功能：官方接口文档里，基础档拆 5 条（伴奏、人声、鼓组、贝斯、其他乐器，输出 WAV），进阶档最多拆 12 条（细到吉他、钢琴、弦乐、合成器，部分模型还输出 MIDI）。做混音、翻唱垫音、剪视频只留伴奏，都靠它——但也正因为它是进阶功能，得单独掏钱。

## 四、API 平台的账（开发者口径）

你在应用里用不到这些，但官方 FAQ 里写的「充值、余额」常常被混着理解，这里划清边界：

- 余额自**最后一次充值起 12 个月内有效**，每次新充值会给全部现有余额续期；
- 扣费顺序：**先扣充值金额，再扣赠送金额**；多笔未用完的充值按先进先出扣；
- **不支持退款**：余额到期、或任何其他情况都不退，API 服务一经付费即视为已使用；
- 官网会员 / 积分不能在 API 平台用，API 积分也不能在官网用。

（以上为官方 FAQ 截至 2026-09 的口径，以官方页面为准。）

## 五、商用与版权的边界

- 官方 FAQ：通过**付费**调用生成的内容，你拥有完整的使用权和商业授权，可用于商业产品、平台发布、广告、视频；
- 36 氪报道引述用户协议原文提醒：**生成内容能否进行版权登记存在法律不确定性，相关风险由用户承担**——要拿去做必须版权登记的用途（如上架音乐平台发行），先把这条掂量清楚；
- 作品上架官方商店出售时，平台按既定比例抽佣（2024 年官方发布稿口径），具体比例以协议与页面为准。

商用相关的更多问答见 [常见问题.md](常见问题.md) 第一节。

## 六、出问题找谁

- API 调用问题：官方技术支持邮箱 [api-support@mureka.ai](mailto:api-support@mureka.ai)，官方承诺 24 小时内回复；
- 应用内问题：走应用界面里的客服入口（位置以当前版本界面为准）。
