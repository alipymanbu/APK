DuckStation 是 Sony PlayStation（PS1/PSX）模拟器，本篇面向第一次在安卓手机上安装它的你，从获取安装包走到游戏列表出现为止。装完之后想调画面、接手柄，去「相关文档」里对应的两篇。

## 一、安装前先核对这五样

| 项目 | 说明 |
| --- | --- |
| 系统版本 | 第三方资料普遍提到需要 Android 9.0 及以上，以官方应用页面为准 |
| 处理器 | 官方说明支持 32 位/64 位 ARM 与 64 位 x86；32 位设备建议 CPU 至少 1.5GHz |
| 存储空间 | 安装包约 66.66 MB，游戏镜像每款通常还要几百 MB |
| BIOS 文件 | 模拟器不带 BIOS，必须从你自己拥有的 PS1 主机转储，见 [BIOS与游戏格式说明.md](BIOS与游戏格式说明.md) |
| 游戏镜像 | 只认 cue / iso / img / ecm / mds / chd / 未加密 PBP 等镜像，格式细节见 BIOS 与格式说明篇 |

本地这份安装包信息：版本 `0.1-8969-g611bb8fb4`，包名 `com.github.stenzek.duckstation`。如果手机上曾装过同名应用，覆盖安装前先核对包名是否一致。

## 二、安装步骤

1. 打开页首的 [DuckStation 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7979960c52a9)，转存到自己网盘后把 APK 下载到手机。
2. 点开 APK 安装；系统提示「允许安装未知来源应用」时按提示允许一次。
3. 装完打开应用，进入首次启动向导。

## 三、首次启动向导只做两件事

第一次打开不会直接进主界面，它会引导你：

1. **导入 BIOS**：选择你提前准备好的 BIOS 文件。还没准备的话先停下，去看 BIOS 与游戏格式说明篇——没有 BIOS，任何游戏都启动不了。
2. **添加游戏目录**：选一个存放游戏镜像的文件夹，应用会自动扫描出列表。

向导被跳过或想事后修改也不难，都在设置里：

- BIOS：设置 → BIOS → 导入 BIOS
- 游戏目录：设置 → 游戏列表 → 添加搜索目录

## 四、把游戏装进列表

1. 把游戏镜像放进手机存储里一个你记得住的文件夹，建议单独建目录。
2. 设置 → 游戏列表 → 添加搜索目录，勾选它。
3. 回主界面，列表出现扫描到的游戏，带封面与地区信息。

列表空着不出来？多半是格式或目录没选对，排查思路见 [常见问题排查.md](常见问题排查.md)。

## 五、装完建议先做三件事

1. 调一次操作方式：触屏布局或外接手柄映射，见 [触屏与手柄设置.md](触屏与手柄设置.md)。
2. 按手机档位调一次画面：默认设置偏保守，内部分辨率和 PGXP 打开与否，肉眼差距很大，见 [画面与性能设置.md](画面与性能设置.md)。
3. 跑通一条完整链路：进游戏 → 暂停 → 即时存档 → 退出 → 重新读取，确认存取没问题，相关操作见 [暂停菜单与存档管理.md](暂停菜单与存档管理.md)。
