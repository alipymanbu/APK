DuckStation 的默认设置以忠实还原为先，画面增强全部要你手动打开。本篇按「先选渲染后端 → 再开增强 → 卡了再降」的顺序过一遍，每一步都给出具体选项名。

## 一、渲染后端：先三选一

设置 → 显示里先选渲染器（Renderer）：

| 渲染器 | 适合谁 | 特点 |
| --- | --- | --- |
| Vulkan | 近几年的主流机型 | 首选，性能与兼容性都好 |
| OpenGL | Vulkan 出问题的机型 | 备选，兼容面广 |
| 软件 | 老旧或低端设备 | 不依赖 GPU，速度最稳，但下文所有增强都不可用 |

注意：内部分辨率放大、纹理过滤、24 位真彩只在 Vulkan / OpenGL 这两个硬件渲染器下生效。

## 二、四个见效最快的开关

1. **内部分辨率**：默认 1x 是原生 PS1 分辨率，在现代手机屏幕上偏糊。中端机建议 2x，旗舰机可以上 4x 甚至更高；数值越高越吃 GPU。
2. **PGXP**：PS1 游戏的画面抖动（wobble）与多边形错位是原机特性，PGXP 几何修正专门治这个。把「PGXP 几何修正」和「PGXP 纹理修正」都打开；还有深度缓冲相关选项可按游戏效果增减。
3. **纹理过滤**：Nearest 保留原始像素颗粒感，其余过滤算法让贴图更平滑，按口味选。
4. **24 位真彩**：带过场动画或渐变丰富的游戏，开了之后色彩明显更正。

## 三、进阶增强选项

- **宽屏渲染**：在支持的游戏里输出宽屏画面，是修正过的宽屏而非简单拉伸两侧。
- **着色器链**：可叠加 GLSL 后处理；Reshade FX 支持目前是实验性。
- **自适应降采样**：高倍内部分辨率下让 2D 元素边缘更干净。
- **模拟 CPU 超频**：部分游戏原机帧率就低，超频能提高帧数；代价是耗电与发热增加。
- **PAL 游戏满速**：支持的 PAL 版游戏可跑到 60fps。
- **倒带（Rewind）与 Runahead**：官方标注不建议在慢速设备上使用。

## 四、卡顿了按什么顺序降

1. 内部分辨率降到 1x~2x；
2. 关 PGXP（尤其 CPU 模式分支）；
3. 渲染器在 Vulkan 与 OpenGL 之间换一次；
4. 依次关掉宽屏、着色器、真彩等增强；
5. 还不行就换软件渲染器——所有增强失效，但速度最稳。

第三方社区的通行参考：骁龙 660 级别的机型跑 1x 无压力，骁龙 765 以上可以尝试 4x。仅供起步参考，实际以你设备的表现为准，一档一档试比背参数可靠。

调参时可以在显示设置里打开 FPS/速度的叠加显示（部分版本支持，以你的版本为准），改动前后的帧数变化一目了然，比凭感觉猜快没快靠谱。

调完之后如果某个游戏反而出问题，记得优先怀疑「单游戏设置覆盖了全局」：游戏长按（或游戏属性）里可以为单个游戏单独保存一套设置，互不影响，排查思路见 [常见问题排查.md](常见问题排查.md)。
