装好 DuckStation 之后卡住新手的基本就两件事：没有 BIOS、游戏格式不对。本篇把这两件事的来龙去脉讲透，装包入口在页首的安装文件资源里。

## 一、BIOS 是什么，为什么绕不开

BIOS 是 PS1 主机的底层启动程序，模拟器要用它来引导游戏。出于版权原因，DuckStation 不随应用分发 BIOS，所以启动或进游戏时会向你索要一份；拿不出来，整个模拟器就停在门口。

官方口径很明确：从你自己拥有的 PS1 主机上转储 BIOS，社区常用 Caetla、Unirom 等转储工具完成。本篇只说明来源方式，不涉及具体获取渠道——自己手边没有主机的话，这道门槛没有绕行的办法。

## 二、BIOS 放到哪

两种方式任选其一：

1. 首次启动向导里直接选择 BIOS 文件；
2. 事后补充：设置 → BIOS → 导入 BIOS，从文件管理器选中转储出的 .bin 文件。

导入成功后再开应用，不再提示 BIOS 缺失即可。如果导入后仍然报错，通常是文件本身不对，排查思路见 [常见问题排查.md](常见问题排查.md)。

## 三、支持的游戏镜像格式

官方支持的镜像格式如下：

| 格式 | 说明 |
| --- | --- |
| .cue + .bin | 最常见的转储形态；cue 是索引文件，必须与 bin 同名同目录成对出现 |
| .iso / .img | 常见光盘镜像 |
| .chd | 压缩镜像格式，同一游戏占用的空间比 bin+cue 小，手机存储紧张时优先用它 |
| .ecm / .mds | 官方列表里也支持 |
| .pbp | 仅支持未加密的 PBP（索尼官方数字版游戏的封装形态） |

官方说明：以上之外的格式需要重新转储，模拟器读不了。

## 四、单轨 bin 没有 cue 怎么办

只有一个 .bin、没有配套 .cue 时，游戏扫描不出来。官方提供了一个网页小工具：[duckstation.org/cue-maker](https://www.duckstation.org/cue-maker/)，在浏览器里打开、选中那个 bin，就能生成配套的 cue 文件，放回同一目录再刷新列表。

## 五、把 bin+cue 转成 CHD 省空间

手机存储紧张的话，可以在电脑上把镜像批量转成 CHD：

1. 准备 chdman（MAME 项目附带的命令行小工具，社区通用）；
2. 单款游戏一条命令完成转换：

   ```bash
   chdman createcd -i "游戏名.cue" -o "游戏名.chd"
   ```

3. 转完先在 DuckStation 里试运行：能进游戏、音轨正常，再决定删除原始 bin+cue；
4. cue 本身残缺的镜像转出来也会有问题，转换前先确认原镜像完整。

## 六、多碟游戏怎么备

多碟游戏的每一张碟都是一组独立镜像（各有一份 cue 或 chd）。两个实用做法：

- 把各张碟的 cue（或 chd）文件路径写进一个 .m3u 索引文件，游戏列表会把整组碟显示成一款游戏，列表更干净；
- 玩到换碟节点时不用退出重开：暂停菜单里选「更换光盘」直接切换，操作见 [暂停菜单与存档管理.md](暂停菜单与存档管理.md)。

## 七、游戏镜像的来源口径

DuckStation 只用于运行你合法购得并自行转储的游戏，官方页面对这一点写得直白。从自己的光盘转储镜像属于你自己设备的正当使用；页首那份安装文件资源只提供模拟器本身，不含任何游戏与 BIOS。
