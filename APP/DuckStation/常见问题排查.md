按症状对号入座：先看现象，再照着做。多数问题集中在 BIOS、镜像格式、性能三类，对应的细节在 BIOS 与格式说明篇、画面与性能设置篇里。

## 一、提示需要 BIOS / BIOS 无效

- 确认已经导入：设置 → BIOS → 导入 BIOS，选那个 .bin 文件；
- 报「无效」通常是文件不对：转储不完整、文件损坏，或拿了别的机型的固件；
- 换一份从自己主机转储的 BIOS 再试，来源与导入方法见 [BIOS与游戏格式说明.md](BIOS与游戏格式说明.md)。

## 二、游戏列表是空的

1. 检查目录：设置 → 游戏列表 → 添加搜索目录，确认勾选的是放游戏的那个文件夹；
2. 检查格式：只认 cue / iso / img / ecm / mds / chd / 未加密 PBP；散装 bin 缺 cue 扫不出来，用官方 cue-maker 网页工具补一个；
3. 文件路径里尽量不要有下载管理器留下的 .tmp、.part 之类半成品。

## 三、进游戏黑屏或白屏

按可能性从高到低：

1. BIOS 问题：换了 BIOS 还黑，基本排除；
2. 镜像问题：重新转储或换一份镜像验证；
3. 渲染器问题：显示设置里在 Vulkan 与 OpenGL 之间切换一次；
4. 单游戏设置问题：游戏属性里为它单独保存过设置的话，先恢复默认。

## 四、运行卡顿掉帧

照 [画面与性能设置.md](画面与性能设置.md) 第四节的顺序降设置：先降内部分辨率，再关 PGXP，再换渲染器。32 位 ARM 设备按官方说明至少需要 1.5GHz CPU 才有像样的速度，这类设备建议直接用软件渲染器起步。

## 五、手柄按键没反应

- 外接手柄连上后必须先映射：设置 → 控制器设置，逐项绑定，方法见 [触屏与手柄设置.md](触屏与手柄设置.md)；
- 换了手柄型号要重新映射；
- 触屏误触的朋友注意：游戏中双指点击或从边缘滑动唤出的是暂停/控制层，别和游戏操作混淆（不同版本手势略有差异）。

## 六、成就（RetroAchievements）不生效

- 成就功能基于 [retroachievements.org](https://retroachievements.org/)，先在设置的成就页登录该站账号；
- 只有关注的游戏在支持列表里才有成就；
- 登录后需要重新进入游戏才会开始追踪；
- 硬核模式（Hardcore）会停用即时存档、金手指这类辅助，开了就拿不到对应成就（规则以该服务说明为准）。

## 七、个别游戏画面错乱或卡死

1. 查官方维护的游戏兼容表：[兼容表（Google 表格）](https://docs.google.com/spreadsheets/d/1H66MxViRjjE5f8hOl5RQmF5woS1murio2dsLn14kEqo/edit?usp=sharing)；
2. 在该游戏的属性里单独调设置（比如关掉宽屏或 PGXP），不影响其他游戏；
3. 换一份该游戏的镜像验证是不是转储问题。

## 八、启用补丁码后游戏异常

先全部关码再逐个开启定位；版本对不上的码直接不用。导入与开关方法见 [金手指与补丁码.md](金手指与补丁码.md)。

## 九、还没解决的

回官方渠道核对：官网 [www.duckstation.org](https://www.duckstation.org/) 与 GitHub 仓库 [github.com/stenzek/duckstation](https://github.com/stenzek/duckstation)，发布页与 issue 区能看到新版本修复了什么。安装本身没走通的，从 [下载与安装教程.md](下载与安装教程.md) 重来一遍。
