## 一、支持的网络来源一览

SVPlayer 基于 mpv，网络能力是内置的，不用装任何插件。文件浏览器的「Locations」（位置）里能挂这些来源：

| 来源 | 典型场景 | 要准备什么 |
| --- | --- | --- |
| SMB（Samba） | Windows 共享文件夹、NAS | 主机地址、共享名、账号密码 |
| WebDAV | Alist、坚果云、部分 NAS | 服务器地址、账号密码；同一主机可配多个账号 |
| FTP | 老 NAS、路由器共享 | 服务器地址、账号密码 |
| DLNA | 电视盒、路由器 media server | 同一局域网内自动发现 |
| Plex | Plex Media Server | Plex 账号的 X-Plex-Token（不是登录密码，见第三节） |
| Emby / Jellyfin | Emby Server | API Key（32 位字符串，见第四节） |
| SVPcast | 电脑版 SVP 4 串流已插帧视频 | 电脑装 SVP 4 并开 SVPcast 扩展，同一局域网，配置见 [SVPcast电脑串流配置](SVPcast电脑串流配置.md) |

手机和这些服务器要在**同一个局域网**里，这是所有连接问题的第一排查项。

## 二、SMB / WebDAV / FTP 直连

在文件浏览器里添加对应来源，填地址和凭证即可。几个实测容易踩的点：

- **带特殊字符的密码连不上 SMB**：1.6.3 这版专门修了「密码含特殊符号时 SMB 失效」的问题；如果你手里是更早的版本，遇到强密码连不上，先升到这个版本再说；
- **中文或特殊字符的文件名**：同样在 1.6.x 系列里修过一批（1.6.3 修 SMB 特殊字符路径）；
- **长时间暂停后断连**：1.5.x 起对 SMB 加了断线自动重连，暂停很久回来不用手动重连；
- **WebDAV 多账号**：同一台主机可以配多个 WebDAV 账号（比如 Alist 上不同权限的账号各配一条）；
- **Jellyfin 当外部播放器调用**：在 Jellyfin 等第三方应用里选「用外部播放器打开」指向 SVPlayer 是官方明确优化过的路径（1.5.x 版本改进项）。

## 三、连 Plex：要的是 Token 不是密码

SVPlayer 连 Plex 用的是 X-Plex-Token，**这不是你登录 Plex 的密码**，是 Plex 给每个账号发的一个标识串。取法：

1. 电脑浏览器打开 Plex Web App 并登录你的 Plex 账号；
2. 随便找一个媒体条目，点右下角「三个点」→「Get info」→「View XML」；
3. 在弹出的 URL 里找 `X-Plex-Token=` 后面那串字符，就是 Token。

偷懒取法：把整条 XML 的 URL 复制下来直接粘进 SVPlayer，它会自己把 Token 提取出来。

## 四、连 Emby：要的是 API Key

Emby 这边对应的是 API Key，同样不是登录密码：

1. 电脑浏览器登录 Emby；
2. 进设置 →「高级（Advanced）」→「API 密钥（Api Keys）」；
3. 新建一个 API Key，或复用已有的；
4. 复制那串 32 位的字符串，粘进 SVPlayer。

## 五、直接播网络视频链接

「Open URL」（打开链接）窗口可以直接粘视频页面的地址播放，播放过的链接有历史记录可回看（1.6.0 加入）。能不能播视频网站链接，取决于你装的是哪个发行版：

- **APK 版**（无谷歌服务渠道）：内置 yt-dlp，视频网站的页面地址直接解析出流来播；yt-dlp 本身支持在应用内更新（1.6.2 起）。网站一改版解析就失效，所以播不了时先在应用里把 yt-dlp 升到最新；
- **Google Play 版**：谷歌政策不允许播视频网站链接，应用本体做不了这件事；官方的方案是另装一个配套应用 SVPtube（从官网下 APK），由它解析后再交给 SVPlayer 播。

局域网里更省事的玩法是把 NAS、Plex、Emby 接进来当资料库（第二到四节），字幕怎么配外挂、音轨怎么切换，见[字幕与音频设置](字幕与音频设置.md)。
