## 一、会员是增值服务，基础功能不依赖它

Jicco 免费下载，注册后匹配、聊天、发动态这些基础功能按官方口径免费使用；会员（VIP）属于增值服务，提供的是专享权益——附近的人、精确筛选、动态曝光、无痕访问这些都在会员侧。要不要开，取决于你用下来觉得免费额度够不够；权益逐项说明见 [会员权益有哪些.md](会员权益有哪些.md)。

## 二、参考价格（安卓 / 鸿蒙渠道）

官方《增值服务条款》给出的安卓端参考价如下（截至 2026 年 9 月，实际以购买页展示为准）：

| 订阅方式 | 价格 |
| --- | --- |
| 1 个月 | 40 元 |
| 1 个月自动续费 | 30 元 |
| 3 个月 | 120 元 |
| 3 个月自动续费 | 60 元 |
| 12 个月 | 480 元 |
| 12 个月自动续费 | 188 元 |

iOS 端走 Apple App Store 内购，价格、订阅周期、退款路径都以 App Store 页面展示为准，通常与安卓渠道不一致。

条款里还有一条值得知道：已购买且在有效期内的会员不受后续调价影响，调整后的价格只对新购与续费生效。

## 三、会员状态在哪看

App 内路径：「我的」→ 会员入口 → 进入 Jicco 会员页面，有效期就显示在那里。自动续费扣款成功后，时长会自动累加到同一有效期上。

## 四、自动续费怎么取消

关键是**在下一个扣费周期开始前操作**——苹果渠道会在到期前 24 小时内扣款：

- **iOS（Apple ID 订阅）**：设置 → 点顶部 Apple ID → 订阅 → 选 Jicco → 取消订阅。取消后，已扣费的会员权益继续有效到本期结束，下期不再扣。
- **安卓（微信 / 支付宝开通）**：去对应支付渠道关闭——微信在「我 → 服务 → 钱包 → 支付设置 → 自动续费」里找到 Jicco 解约；支付宝在「我的 → 设置 → 支付设置 → 免密支付 / 自动扣款」里关闭。入口名称以渠道当前版本为准。
- 想换套餐：先取消旧的自动续费，再重新购买想要的档位。

## 五、付款相关的两个提醒

1. 官方条款明确：取消自动续费之前已经委托扣款的指令仍然有效，这笔钱不退。所以要取消就趁早，别拖到扣款当天。
2. 退款诉求走官方渠道：iOS 通过 App Store 的「报告问题」申请；安卓端联系官方客服邮箱 `cs@jiccos.com` 说明订单情况，能否退以官方答复为准。
