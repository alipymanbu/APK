## 一、本篇对应的是哪一版

Jicco 官方一直在更新，各应用市场收录的版本也不一样。本篇以 2026 年 9 月整理的一份安装包为基准，涉及版本号与体积的地方都以它为准：

| 项目 | 内容 |
| --- | --- |
| 版本 | 3.4.2 |
| 安装包大小 | 156.24 MB |
| 包名 | com.jiccos.jicco |
| MD5 | 67025f8b04b6d0071fe53d2c289079d7 |
| 开发者 | 武汉吉格斯科技有限公司 |
| 系统要求 | Android 7.0 以上（第三方应用市场标注，以官方页面为准） |

写作时官方最新版已高于 3.4.2。新旧版本在安装步骤上没有差别，界面细节以你装到的版本为准。

## 二、安装前检查三件事

1. **系统版本**：设置 → 关于手机，确认 Android 版本在 7.0 以上。低于 7.0 会装不上，或者装上就闪退。
2. **存储空间**：安装包本身就有 156.24 MB，安装后占用更大，建议至少留 2 GB 空闲。
3. **允许安装未知来源应用**：不从应用市场直接装的话，系统默认会拦。常见机型入口：
   - 小米 / 红米：设置 → 隐私保护 → 特殊权限 → 安装未知应用
   - 华为 / 荣耀：设置 → 安全 → 更多安全设置 → 安装外部来源应用
   - 其他机型：点安装包时按弹窗提示进入对应设置即可

## 三、下载与安装步骤

1. 打开文首的 [Jicco 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9638b8011e94)，转存到自己网盘后，把 APK 下载到手机存储。
2. 打开文件管理器，找到下载好的 APK（文件名形如 `jicco_v3.4.2.apk`），点击它。
3. 弹出「是否允许此来源安装应用」时选允许，回到安装界面点「安装」。
4. 等进度条走完，点「打开」，或回桌面点 Jicco 图标。

装好之后先做注册登录，步骤见 [注册登录与账号设置.md](注册登录与账号设置.md)。

## 四、想核对安装包怎么办

如果怀疑下载的包不完整或被替换，可以核对 MD5：把上文的 MD5 值与自己手里 APK 的校验值比对，一致就是同一份包。电脑上用 certutil 校验：

```powershell
certutil -hashfile "jicco_v3.4.2.apk" MD5
```

手机端部分文件管理器（如 MT 管理器）也自带校验功能。

## 五、iPhone 用户怎么办

Jicco 在 iOS 上架了 App Store（应用名「Jicco - 基友的兴趣同好圈子」，年龄分级 18+），iPhone 用户在 App Store 里搜 Jicco 直接安装即可，不走安卓安装包这条路径。

## 六、第一次打开会要哪些权限

首次启动同意用户协议后，App 会陆续申请这些权限，各有用途，不给的话对应功能用不了：

| 权限 | 用在哪 |
| --- | --- |
| 定位 | 同城推荐、附近的人 |
| 相机 | 拍头像、拍摄照片视频上传 |
| 麦克风 | 语音消息、语音聊天 |
| 存储 / 媒体 | 发图片视频、保存图片 |
| 电话 | 读取短信验证码自动填充 |
| 通知 | 私信与互动提醒 |

暂时不想给也可以跳过，之后在系统设置里随时补开。

装不上、打开闪退这类情况，处理思路整理在 [常见问题与使用注意.md](常见问题与使用注意.md)。
