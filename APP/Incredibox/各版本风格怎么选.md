## 一、先弄清「版本」指的是什么

Incredibox 里的「版本」不是更新号，而是**一套独立的音乐风格包**：每套有自己的主题画面、自己的 20 个声音、自己的 3 段奖励动画。你在版本列表里看到的 Alpha、Brazil、Dystopia 这些名字，指的就是风格包——它们是并列关系，不是新旧覆盖关系。

官方从 2009 年做到现在共推出 **9 套**，列表如下：

| 版本 | 首发年份 | 曲风关键词 | 想要什么感觉从它开始 |
| --- | --- | --- | --- |
| V1 Alpha | 2009（2018 重制） | 老派 beatbox、爵士味 | 想听最原始的「纯人声打拍子」 |
| V2 Little Miss | 2012 | 纽约嘻哈、切分鼓点 | 想要纯正 B-Boy 嘻哈底子 |
| V3 Sunrise | 2013 | 电子流行、明亮轻快 | 想要顺耳、适合循环听的流行调 |
| V4 The Love | 2014 | 法式 House、俱乐部电子 | 想要能当派对背景的电子乐 |
| V5 Brazil | 2016 | 桑巴、巴图卡、嘉年华 | 想要热带打击乐的热闹感 |
| V6 Alive | 2018 | 二次元 × 嘻哈 × 日系电音 | 想要低音重、带迷幻感的电子 |
| V7 Jeevan | 2019 | 印度风、宝莱坞律动 | 想要神秘、转音多的异域节奏 |
| V8 Dystopia | 2020 | 赛博朋克、暗色电子 | 想要冷、暗、带失真的科幻氛围 |
| V9 Wekiddy | 2023 | 90 年代复古嘻哈 | 想要怀旧、色彩跳脱的复古派对 |

（年份取自官方公开的时间线；风格描述按官方对各版本的介绍改写。具体每版开放哪些内容，以你装的这版实际显示为准。）

## 二、按口味挑的三条捷径

- **第一次玩**：先开 V1 Alpha 或 V3 Sunrise。Alpha 是一切的起点、声音结构最直白；Sunrise 走明亮的电子流行，层次分明，适合先用它建立耳朵。
- **想要整首歌有戏剧性**：V8 Dystopia 与 V6 Alive 的层次最厚，适合录制长一点的作品。
- **想换心情**：V5 Brazil 管热闹、V7 Jeevan 管神秘、V9 Wekiddy 管怀旧——这三版彼此差异最大，从哪个开始都和前一版反差明显。

挑版本这事没有标准答案：**每个版本都是 7 个站位、20 个声音**，够你录出完整的一首；风格不合口味就换下一套，不用强迫自己在某一版里挖到底。

## 三、你的系统决定你能看到几个版本

官方 FAQ 给过一张兼容表，直接决定列表长度：

| 系统 | 能拿到的版本 |
| --- | --- |
| Android 7.0 及以上 | 全部 9 个版本 |
| Android 7.0 以下 | V1 Alpha 到 V8 Dystopia |
| iOS 15.6 及以上 | 全部 9 个版本 |
| iOS 15.6 以下 | V1 Alpha 到 V8 Dystopia |

也就是说，**旧安卓机可能压根看不到 Wekiddy**，先别急着找是不是隐藏了——升级系统才是正解。网盘这份 1.0 记录的门槛是安卓 5.2 以上（见 [下载与安装教程.md](下载与安装教程.md) 第五节），但「装得上」与「版本列表齐全」是两回事，别混为一谈。

## 四、还有一类：社区 Mod

官方从 2025 年 3 月起把社区作者做的 **Incredimods** 内置进了正式版，另外也支持从 [mod.io 的 Incredibox 分区](https://mod.io/g/incredibox)下载后用「导入 Mod」装进来。Mod 是玩家自制的风格包，好坏参差、风格激进，**和官方九版是两套体系**——先玩熟官方版再折腾它。是否已内置、入口在哪，以你装的这版实际显示为准。社区模组里名气最大的 Sprunki、「节奏盒子」这个中文叫法到底指什么，单独拆了一篇讲，见 [节奏盒子和Sprunki模组是什么.md](节奏盒子和Sprunki模组是什么.md)。
