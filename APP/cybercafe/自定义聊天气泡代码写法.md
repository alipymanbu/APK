## 一、气泡自定义是什么形式

先说清它和其他应用的区别：cybercafe 的聊天气泡自定义**不是拖拽式的可视化编辑，而是写 HTML + CSS 代码**。入口按用户分享的路径在「设置 → 聊天界面」，你可以选择现成样式，也可以把自己的代码填进去，让气泡的颜色、形状、位置完全按你的想法来。

如果你完全没写过代码也不用慌 —— 社区里通行做法就是拿现成模板让 AI 助手帮你改（见本文第五节），本篇的模板可以直接抄。

## 二、模板里每个占位符是什么意思

自定义代码里会看到几个 `{{...}}` 形式的占位符，它们不是让你照抄的文本，而是应用渲染时自动替换的位置：

| 占位符 | 含义 |
| --- | --- |
| `{{side}}` | 气泡方向，渲染时会替换成 `left` 或 `right`，决定这条消息显示在对话的哪一侧 |
| `{{text}}` | 消息正文，渲染时替换成实际聊天内容 |
| `{{bg-color1}}` | 左侧气泡的背景色 |
| `{{bg-color2}}` | 右侧气泡的背景色 |

看懂这四个，任何模板你都知道该改哪里：想换颜色改 `bg-color`，想改气泡形状改 CSS 里的 `border-radius`，想调内边距改 `padding`。

## 三、一份可以直接抄的参考模板

下面是社区里流传的一份「伪微信风格」气泡模板，HTML 结构与 CSS 样式分开：

HTML 部分：

```html
<div class="chat-bubble {{side}}">{{text}}</div>
```

CSS 部分：

```css
.chat-line .chat-bubble {
  position: relative;
  padding: 10px 15px;
  line-height: 1.5;
  border-radius: 5px;
  display: inline-block;
}
.chat-line .chat-bubble.left {
  background-color: {{bg-color1}};
}
.chat-line .chat-bubble.left::before {
  content: "";
  position: absolute;
  top: 12px;
  left: -6px;
  width: 0;
  height: 0;
  border-right: 7px solid {{bg-color1}};
  border-top: 7px solid transparent;
  border-bottom: 7px solid transparent;
}
.chat-line .chat-bubble.right {
  background-color: {{bg-color2}};
  float: right;
}
.chat-line .chat-bubble.right::before {
  content: "";
  position: absolute;
  top: 12px;
  right: -6px;
  width: 0;
  height: 0;
  border-left: 7px solid {{bg-color2}};
  border-top: 7px solid transparent;
  border-bottom: 7px solid transparent;
}
```

效果：左右两侧各自带一个小三角指向，颜色由 `{{bg-color1}}` 和 `{{bg-color2}}` 两处（每处出现两次，要一起改）控制，是最接近微信观感的基础款。想改成圆角更大的气泡，把 `border-radius: 5px` 调大即可。

## 四、三条限制，踩过的人最多

1. **不支持 `font-family` 和第三方字体**。写了也会被无视，别在字体上浪费时间；
2. **单引号要写成双引号**。CSS 里 `content: ''` 这类写法要换成 `content: ""`，这是模板代码出错的高发点；
3. **HTML 与 CSS 要分开提交**。不要把两段混在一个输入框里，按应用的输入位分别粘贴。

另外两条经验：改动一次只改一处，改完立刻看效果，出问题好回退；颜色值直接用十六进制（如 `#4a90d9`）最稳，个别写法可能不被支持。

## 五、不会写代码怎么办

把本文第三节的模板整段复制给任意 AI 助手，用一句明确的话描述你要的效果，例如「把气泡改成深色背景、圆角 20px、去掉小三角」。**记得把第四节的这三条限制一并写进你的要求里**（不支持 font-family、单引号改双引号、HTML 与 CSS 分开）—— 不写这三条，AI 很可能给你一段带自定义字体的代码，填进去等于没改。社区玩家基本都用这个方法迭代气泡样式，你只需要负责挑效果。

气泡之外，角色本身的人设与世界观同样影响聊天体验，两件事可以并行：[角色创建与羁绊切片玩法.md](角色创建与羁绊切片玩法.md) 讲怎么把角色调教到位。改气泡改到界面异常时，先恢复默认样式再排查，实在不行的通用排查思路在 [常见问题与解决办法.md](常见问题与解决办法.md)。
