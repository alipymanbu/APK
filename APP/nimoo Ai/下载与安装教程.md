## 一、先确认这份安装包是什么

nimoo Ai 是一款安卓端的 AI 角色聊天应用：首页是角色广场，可以和现成角色对话，也能自己捏角色。这里这份资源是安卓 APK 安装包，适合想在手机上直接安装的人；iOS 之类其他平台不在本篇范围内。

安装包信息以采集当时为准：

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.0.0 |
| 体积 | 7.16 MB |
| 包名 | `com.chat.nimoo.ai.app` |
| MD5 | `59D4074476D5CFADB86C7456847B48A4` |
| 平台 | 安卓 |

两点提醒：

- 网上搜到的可能是官方后来发的新版，版本号未必和上表一致，装之前先想好要哪一版；
- 装完可以用 MD5 校验工具核对一下文件是否完整，避免下了一半的包装出各种怪问题。

另外，收录站对这份包标注的适龄范围是年满 16 周岁，给未成年人装机前留意一下这一条。

## 二、从夸克网盘取安装包

1. 打开 [nimoo Ai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/83bad34c9a64)；
2. 把文件转存到自己的夸克网盘；
3. 在手机上的夸克网盘客户端里找到转存后的 APK，下载到本机。

下载完成后，手机通知栏一般会直接给出"打开/安装"的入口，点进去就能开始装。

## 三、安装：允许这个来源

APK 走的是网盘渠道，不属于应用商店安装，系统第一次会拦一下：

1. 点下载好的 APK，弹出"是否允许安装"时选允许；
2. 如果提示"禁止安装未知来源应用"，按提示跳到系统设置，允许夸克网盘（或你打开文件用的应用）安装应用；
3. 回到安装页继续，等进度走完。

各品牌安卓的入口不一样，常见位置是"设置 → 应用管理 → 特殊应用权限 → 安装未知应用"；找不到就别手动翻设置了，直接用安装弹窗里的"去设置"按钮更快。

## 四、第一次打开：邮箱注册与登录

nimoo Ai 需要用邮箱注册账号后才能聊：

1. 打开应用，进右下角的个人中心；
2. 选择"去登陆"，再点下方的注册；
3. 填邮箱，获取验证码，设置密码，提交后即注册完成；
4. 用这组邮箱和密码登录。

验证码迟迟收不到时，先等一两分钟，再翻一下邮箱的垃圾邮件、订阅邮件目录，并核对邮箱拼写有没有错；还是收不到，就换一个邮箱再试。

## 五、装不上、打不开怎么办

按出现顺序排查：

| 现象 | 先做什么 |
| --- | --- |
| 安装到一半失败 | 确认手机剩余空间够用（安装包虽小，安装过程也需要余量）；重新下载一次 APK |
| 提示解析包出错 | 安装包大概率没下完整，核对 MD5 后重下 |
| 提示版本冲突 | 手机里如果装过别的来源的 nimoo Ai，先卸载再装 |
| 打开就闪退 | 重启手机再开一次；还不行就清一下应用缓存 |
