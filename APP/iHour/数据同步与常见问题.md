## 一、账号与云端同步

官方对 iHour 的介绍里写明数据云端存储，安卓端同样有账号登录。建议装好后的第一件事就是登录账号：只用本地数据，换机或重装时就没有可恢复的来源。

登录入口一般在「我的」或设置页顶部。同步在联网时进行；如果发现两台设备数据对不上，先确认两边登录的是同一个账号，再确认都联网打开过应用（部分版本要打开一次应用才触发同步）。同步还是不动，按这个顺序排查：账号一致 → 网络（换 Wi-Fi / 流量各试一次）→ 省电策略没拦后台 → 应用更新到该渠道最新版 → 都不行再走第二节的重装流程。

另外，应用自带本地备份/恢复，备份文件是 `.ihbak` 格式。有用户反馈它只能用于本应用恢复、导不出表格数据，想二次整理只能手动誊。换机时稳妥的做法是云同步为主、本地备份为辅。隐私政策与用户协议见官方渠道：[ihour.clover.ly](https://ihour.clover.ly/)、[clover.ly/privacy](https://clover.ly/privacy)、[m.icity.ly/tos](https://m.icity.ly/tos)。

## 二、换手机 / 重装前的三步

1. 旧手机打开 iHour，确认登录状态正常，停在首页让数据完成一轮同步。
2. 新手机安装 iHour——安装包可从开头的 **iHour 安装文件资源（夸克网盘）** 链接获取，装好后登录同一个账号。
3. 等同步完成，核对项目数量与累计时长没问题，再卸载旧手机上的应用。

跳过第 1 步直接卸载是最容易丢数据的做法：只存在本地、还没同步上去的记录，卸载后就找不回来了。

## 三、统计图表

统计页提供按天、周、月维度的投入时长图表，能看出每个项目的时间分配和投入趋势。学生用它核对「这周自习到底够不够数」，比翻记录列表直观得多；配合 [项目创建与时间记录.md](项目创建与时间记录.md) 里的补录，把漏记的日子补上，图表才算数。

## 四、免费与 iHour Pro

iHour 免费下载，记录、统计、成就这些核心功能免费可用；免费版的主要门槛是可建项目数量。要不要上 Pro、订阅和买断怎么选、怎么取消续费与恢复购买，单独见 [订阅与恢复购买.md](订阅与恢复购买.md)。

## 五、高频问题速查

| 问题 | 处理 |
| --- | --- |
| 提醒不准点 / 收不到 | 查通知与精确闹钟权限，见 [每日提醒与长期目标.md](每日提醒与长期目标.md) |
| 专注计时悬浮窗不显示 | 给「显示悬浮窗」权限，见 [专注计时功能详解.md](专注计时功能详解.md) |
| 想补昨天的记录 | 手动添加时选过去日期，见 [项目创建与时间记录.md](项目创建与时间记录.md) |
| 降级安装失败 | 已装更高版本导致，见 [下载与安装教程.md](下载与安装教程.md) |
| 换机后数据没过来 | 核对两台设备是否同一账号、是否联网触发过同步，见本文第一节 |
| 会员权益没了 / 想取消续费 | 先核商店账号再恢复购买，见 [订阅与恢复购买.md](订阅与恢复购买.md) |
