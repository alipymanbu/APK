## 一、先认清你要装的是哪一版

CONFIRMED 是 adidas 面向运动潮流人群的官方应用，中国大陆版与海外版是**两个独立的应用**，安装包不通用。你手里这份安装包的基本信息如下，装之前可以先对一眼：

| 项目 | 信息 |
| --- | --- |
| 应用名 | CONFIRMED |
| 版本 | 3.10.0 |
| 包名 | `cn.adidas.confirmed.app` |
| 安装包大小 | 119.54 MB |
| MD5 | `5AEEC295D5244299CA745EE54F2EF283` |
| 开发者 | 阿迪达斯体育（中国）有限公司 |
| 信息核对日期 | 2026-09-23 |

两点提醒：

- 中国大陆版的包名是 `cn.adidas.confirmed.app`；海外版（adidas AG 面向支持 Google Play 的地区发布）包名是 `com.adidas.confirmed.app`。包名不同，两个版本可以同时装在一台手机上，互不覆盖。
- 网上商店展示的是官方最新版，和上面这份安装包很可能不是同一个版本号。安装包信息以你实际拿到手的那份为准；想用最新版，可在官方应用商店渠道（如应用宝搜索 CONFIRMED）另行获取。

## 二、把安装包从网盘拿下来

安装包通过夸克网盘分享，不能直接点链接就下，要先转存到自己的网盘：

1. 打开 [CONFIRMED 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7d15cd0f302c)；
2. 登录夸克账号后点「转存」，把文件存到自己网盘；
3. 打开夸克网盘客户端（手机或电脑版均可），找到刚转存的 `CONFIRMED_v3.10.0.apk`，下载到手机存储。

安装包约 120 MB，建议在 Wi-Fi 环境下下载；下载过程中不要锁屏中断（部分机型后台断网会导致下载不完整）。

## 三、允许安卓安装这个包

安卓默认只允许从应用商店装应用，从文件管理器点开 APK 时会被拦下来，这是系统安全机制，手动放行一次即可：

1. 在文件管理器里点开下载好的 APK，系统弹出「禁止安装未知来源应用」的提示时，点提示里的「设置」；
2. 打开「允许来自此来源」的开关（授权的是你刚才用的那个文件管理器或浏览器，不是应用本身）；
3. 返回安装界面，继续点「安装」。

不同系统的入口略有差别：

- **Android 8.0 及以上**：设置 → 应用 → 特殊访问权限 → 安装未知应用，给文件管理器授权（也可以等弹窗引导时再开）。
- **鸿蒙系统（华为/荣耀旧款）**：设置 → 安全 → 更多安全设置 → 允许安装来自未知来源的应用；新机型若提示「纯净模式」，按提示选择继续安装。
- **安装过程中弹出 Play Protect 或「应用安全检测」警告**：确认安装包来源可信后选「仍要安装」/「忽略」继续。

## 四、校验安装包完整性（可选但推荐）

如果安装时提示「解析包出现问题」，先怀疑下载不完整。这份安装包的 MD5 是 `5AEEC295D5244299CA745EE54F2EF283`，核对方法：

- **电脑上**：PowerShell 执行 `Get-FileHash -Algorithm MD5 "下载路径\CONFIRMED_v3.10.0.apk"`，对比输出的哈希值；
- **手机上**：部分文件管理器的文件详情页直接显示 MD5，或使用带校验功能的第三方文件工具。

校验一致还装不上，多半不是包的问题，转去 [常见问题与故障排除.md](常见问题与故障排除.md) 对症排查。

## 五、装好之后先做这几件事

1. 打开 CONFIRMED，用手机号或邮箱注册/登录 adidas 账号（已有账号直接登录），详见 [账号注册与adiClub会员.md](账号注册与adiClub会员.md)；
2. 在个人资料里预填尺码、收货地址、支付方式——参与限量发售时这些信息要现填，提前备好才来得及；
3. 允许应用发送通知，发售提醒和中签结果都靠通知送达——设备权限不会默认开启，首次用到时系统会弹窗询问，点了拒绝之后再想开，要去系统设置里手动补；
4. 想参与限量鞋款发售的，接着看 [抽签与购买流程.md](抽签与购买流程.md)。
