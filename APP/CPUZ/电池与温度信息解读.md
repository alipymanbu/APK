## 一、电池标签页逐项说明

字段名以实机界面为准，不同版本略有差异：

| 项目 | 含义 |
| --- | --- |
| 电量 | 当前电量百分比 |
| 状态 | 充电中 / 放电中 / 未充电 / 已充满 |
| 电源 | 当前供电来源（交流、USB、电池） |
| 技术 | 电池类型，通常是锂离子或锂聚合物 |
| 温度 | 电池温度，摄氏 |
| 电压 | 电池电压，毫伏 |
| 容量 | 电池容量（毫安时），默认可能不显示，见下一节 |
| 健康 | 系统上报的电池状态（良好、过热等） |

## 二、容量不显示或显示不对

这是 CPU-Z 被问得最多的问题之一，官方 FAQ 给过明确答复：

- CPU-Z 的电池容量**来自操作系统的上报**，系统报错它就跟着错；
- 因为上报值经常不可靠，**从 1.10 版起默认不再显示容量**，想看的话到设置页勾选 Battery Capacity 恢复显示。

交叉核对的建议：拿厂商参数页标称的毫安时数对照；若 CPU-Z 显示值与标称差得远，优先怀疑系统上报的数不准，而不是电池本身有问题。设置项的具体位置见 [常见问题与设置项说明.md](常见问题与设置项说明.md)。

## 三、热量标签页：温度从哪里看

热量（Thermal）页列出设备各热区的实时温度。读这页的关键是**对比同一台机器自己的变化**——不同机型的热区数量与定义不一样，没有通用的「正常范围」：

- 空闲与重负载（游戏、长时间录像）各读一次，记住自己这台机器的基线；
- 充电时整机温度偏高属常见现象，边充边玩会更高；
- 温度持续异常升高时，到系统设置的电池页看耗电排行，找后台高耗电的应用。

这一页不是所有版本都有：有第三方资料称 Thermal 页是 1.41 版才新增的，老版本找不到这一页时，升级官方最新版即可。

电池标签页里也有一项电池温度，两个数值可以互相印证。

## 四、配合重负载观察降频（烤机）

CPU-Z 不做压力测试，但可以配合游戏或跑分软件观察降频：

1. 空闲时在 SOC 页与热量页各读一次，记下基线频率与温度；
2. 开一局大型游戏或跑一轮跑分软件，持续 10 分钟以上；
3. 切回 CPU-Z：SOC 页看大核频率是否明显低于基线，热量页看温度爬到了多少；
4. 两相印证：温度高但频率没降，说明散热扛得住；频率大幅回落，就是撞上了温控降频。

想全程不切屏盯着数据看，监控向的工具更合适，选型见 [硬件检测工具怎么选.md](硬件检测工具怎么选.md)。

## 五、耗电快的排查顺序

官方 FAQ 对「CPU-Z 耗电」的答复是：耗电来自传感器页的持续读取，到设置页取消勾选 Sensors 即可。如果你是开着传感器页放着不动，先做这一步；关掉后仍然耗电明显，按系统电池统计排查其它应用。
