## 一、SOC 标签页：芯片平台

SOC（System On Chip）页是打开应用后默认的一页，回答「这台手机用的是什么芯片、跑在什么频率上」。

| 参数 | 含义 | 怎么用 |
| --- | --- | --- |
| SoC 名称 | 芯片平台的具体型号（骁龙 / 天玑 / 麒麟等） | 判断手机性能档位最直接的一项，验机时先看它 |
| 架构 | 核心的指令集与大小核布局 | 看这台机器是「大核 + 小核」还是全小核设计 |
| 每核频率与利用率 | 每个核心的实时频率、当前占用 | 空闲时小核低频、负载上来大核提速，属正常波动 |
| GPU 供应商 / 型号 | 图形芯片的供应商与型号 | 关注游戏性能时和 SoC 名称一起参考 |

两个容易误读的点：

- **显示 unknown 不等于芯片有问题**。芯片比安装包版本新时，老版本认不出新型号；官方每个版本的更新说明都在补新芯片支持（1.46 之后的版本陆续补入了天玑 9400+、骁龙 8 Elite Gen 5 等型号，以官方版本历史为准）。
- **实时频率会一直跳**。频率按当前负载动态调整，不是固定值；想看某个核心能到多高频率，让它跑一阵负载再读。

想知道它和 AIDA64、DevCheck 这类工具怎么分工，见 [硬件检测工具怎么选.md](硬件检测工具怎么选.md)。

## 二、设备标签页：品牌、屏幕、内存与存储

| 参数 | 含义 | 注意 |
| --- | --- | --- |
| 品牌 / 型号 | 设备品牌与具体型号 | 与系统设置「关于手机」里的一致 |
| 屏幕分辨率 | 屏幕的分辨率 | 部分机型默认渲染分辨率低于物理分辨率，以实机显示为准 |
| RAM | 内存容量 | 比厂商标称略小是换算口径与系统保留造成的，差一大截才需要警惕 |
| 存储 | 内置存储容量 | 同上，系统分区会占掉一部分；总容量与可用容量是两个数 |

## 三、系统标签页：安卓版本与底层信息

- **安卓版本与 API 级别**：与「关于手机」一致；二手交易里商家声称的系统版本，拿这页核对最直接；
- **内核架构与版本**：底层信息，日常用得少，排查刷机或移植问题时才需要；
- **Root 状态**：显示设备是否已获得 Root 权限，验机时这一项值得看一眼（见 [手机验机对照清单.md](手机验机对照清单.md)）。

## 四、传感器标签页：设备有哪些传感器

这一页列出设备支持的传感器清单与实时读数（加速度、陀螺仪、光线、接近等）。两点提醒：

- 读数持续刷新，**这一页比其它页更耗电**（官方 FAQ 明确提到传感器读取是耗电来源），看完建议到设置里把 Sensors 读取关掉，操作见 [常见问题与设置项说明.md](常见问题与设置项说明.md)；
- 传感器缺项（比如没有陀螺仪）多半是硬件本身没配，不是应用故障。

电池与温度相关的读数不在这一页，单独整理在 [电池与温度信息解读.md](电池与温度信息解读.md)。
