## 一、先分清它能查什么、不能查什么

**能核对**：芯片型号与核心布局、内存总量、存储容量、屏幕分辨率、系统版本、Root 状态、电池信息。

**不能核对**：是否进水或拆修、摄像头等模组是否原装、序列号与保修状态、网络锁。这些要走厂商官方的保修查询与售后检测。CPU-Z 读的是「设备自己上报的信息」，正常使用的机器它读得准，被深度改动过的机器未必能暴露。

## 二、逐项对照清单

先把商家页面的参数抄下来，再按下表逐项对：

| 核对项 | 在 CPU-Z 哪里看 | 对不上时怎么判 |
| --- | --- | --- |
| 芯片型号 | SOC 页 | 型号对不上 = 配置虚标；显示 unknown 先换最新版工具确认，再下结论 |
| 核心数与架构 | SOC 页 | 与该芯片型号的公开规格对照 |
| 内存总量 | 设备页 | 比标称略小属正常（换算与系统保留），差一大截才要警惕 |
| 存储容量 | 设备页 | 同上；注意区分总容量与可用容量 |
| 屏幕分辨率 | 设备页 | 与官方参数页的分辨率对照 |
| 安卓版本 | 系统页 | 与商家声称不符 = 描述错误或刷过机 |
| Root 状态 | 系统页 | 商家没提而显示已 Root，值得追问 |
| 电池 | 电池页 | 电量、温度、状态是否正常；容量默认不显示，见 [电池与温度信息解读.md](电池与温度信息解读.md) |

## 三、操作顺序

1. 装好应用：安装包在 [CPU-Z 安装文件资源（夸克网盘）](https://pan.quark.cn/s/99cd38b3fa20)，安装步骤见 [下载与安装教程.md](下载与安装教程.md)；
2. 把商家参数抄成一张对照表（照上面清单的行来抄）；
3. 按顺序打开 SOC → 设备 → 系统 → 电池四页，逐项核对并记下实机值；
4. 关键页拍照留档，万一后续走平台维权用得上；
5. 有对不上的项，先排除「容易误判的情况」（下一节），再与卖家交涉。

当面交易时，让买卖双方的手机都装上同跑一遍——实机读数比口头描述与截图都可信。

## 四、三种容易误判的情况

- **SOC 显示 unknown ≠ 假机**：芯片比工具版本新时认不出，先用支持该芯片的新版本确认；
- **内存 / 存储偏小 ≠ 缩水**：换算口径（1000 与 1024）与系统保留都会让显示值低于标称；
- **电池容量看不到 ≠ 电池被换过**：从 1.10 版起默认就不显示，要在设置里手动开启 Battery Capacity；显示出来以后也可能因系统上报不准而失真。

## 五、厂商自带的检测入口别浪费

手机厂商大多内置了隐藏的硬件测试菜单，在拨号盘输入即可打开，验机时可以先跑一遍再上第三方工具：

| 输入内容 | 适用 | 打开什么 |
| --- | --- | --- |
| `*#*#4636#*#*` | 多数安卓机 | 信号网络与电池信息页 |
| `*#0*#` | 部分三星 Galaxy 机型 | 屏幕、触摸、传感器、摄像头等整套测试 |
| `*#*#6484#*#*` 或 `*#*#64663#*#*` | 小米 / Redmi 机型常见 | 引导式硬件测试菜单 |

个别运营商或地区会禁用这些菜单，输入没反应就换第三方工具或走官方售后检测；入口随机型与系统版本变化，以实机为准。
