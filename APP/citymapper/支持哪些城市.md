## 一、覆盖范围概览

官方口径：截至 2025 年底覆盖全球 430 个城市，美国与欧洲的大部分地区已铺开，完整名单以官方城市页为准：[citymapper.com/cities](https://citymapper.com/cities)。

主要地区与代表城市（截至 2026-09，名单持续扩充）：

| 地区 | 覆盖情况举例 |
| --- | --- |
| 英国与爱尔兰 | 伦敦、曼彻斯特、伯明翰、爱丁堡、格拉斯哥、都柏林，英格兰多郡已连片覆盖 |
| 欧陆 | 巴黎、柏林、汉堡、慕尼黑、罗马、米兰、马德里、巴塞罗那、阿姆斯特丹、布鲁塞尔、瑞士全境、奥地利因斯布鲁克等 |
| 东亚 | 东京圈（含更广的大东京范围）、首尔、香港、台湾全境 |
| 东南亚 | 新加坡 |
| 北美 | 纽约、洛杉矶、旧金山、芝加哥、华盛顿、波士顿、多伦多、魁北克城、墨西哥城 |
| 大洋洲 | 悉尼 |

## 二、中国大陆城市能用吗

截至 2026-09，官方城市列表里没有中国大陆城市。它对你有用的场景主要是**出境**：香港、东京、首尔、新加坡、伦敦、巴黎这些目的地的数据完整，实时到站、换乘指引都能正常用。

官方城市页提供「投票求新城市」的入口，你想去的地方没覆盖可以去投一票；但投票到上线通常以年计，短期内出行别指望它。

## 三、怎么切换城市

- 应用按你的定位自动切换到已覆盖的城市，在覆盖区之间移动基本不用手动操作。
- 想提前为行程做准备：在城市选择器里手动添加目的地城市，出发前在家就能先查当地路线、存好行程。
- 未覆盖的城市里，应用只剩一张普通地图，查不出公交方案——这不是故障，是数据范围如此，别在那里反复重试。

## 四、同一个功能在不同城市不一样

Citymapper 的数据按城市逐个接入，同一功能并非处处都有：

| 功能 | 城市间差异 |
| --- | --- |
| 实时到站 | 大城市普遍有实时数据，小城市可能只有时刻表 |
| 票价显示 | 部分城市才接入票价数据 |
| 应用内购票 | 封闭试点中（如英国西米德兰兹、美国迈阿密），多数城市不能买票 |
| 网约车 / 共享单车聚合 | 取决于当地是否接入对应服务商 |
| 无台阶路线 | 覆盖 20 多个地区并持续增加 |

落地后第一次查询时，先看方案里标的是「实时」还是「按时刻表」，对准确度就有数了。到站时间怎么看、离线怎么准备，见[离线使用与实时到站.md](离线使用与实时到站.md)；在覆盖城市里它和谷歌地图各管一段，搭配用法见[与谷歌地图怎么搭配.md](与谷歌地图怎么搭配.md)。
