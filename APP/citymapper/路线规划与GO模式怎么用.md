## 一、规划一条路线

1. 打开应用，在顶部输入框分别填起点与终点（默认以当前定位为起点，点一下可以改成任意地点）。
2. 出发时间有三种切法：「现在」「设定出发时间」「设定到达时间」——赶早班机、赶火车时用「到达时间」倒推更实用。
3. 结果是一列可选方案：公交地铁组合、纯步行、骑行、打车混在一起，每条标注总耗时、换乘次数、步行距离，有票价数据的城市还会标票价。
4. 点开一条方案看分段明细：每段坐什么线、坐几站、在哪换乘、步行多久；地铁段会提示最佳车厢与就近出口。

同一目的地查过一次后会留在首页最近查询里，通勤时段基本就是两次点击的事。

## 二、筛路线：不同处境挑不同方案

结果页顶部有一排筛选，按你当下的处境选：

| 筛选 | 适用场景 |
| --- | --- |
| 混合路线（Mixed） | 公交 + 共享单车 / 滑板车 / 打车拼一段，各取所长 |
| 少走路（Walk Less） | 下雨、高温、拎行李 |
| 简单路线（Simple） | 少换乘、少决策，第一次去某个区域 |
| 按速度 / 按价格排序 | 赶时间或精打细算时把对应方案顶到最前 |
| 无台阶路线（Step-free） | 轮椅、婴儿车、大件行李，需要全程电梯通道 |

这些筛选原本是 CLUB 会员专属，Citymapper 11 起对所有用户开放，订阅的现状见[CLUB会员与收费.md](CLUB会员与收费.md)。

## 三、GO 模式：上车之后再点它

选定路线后按 **GO** 进入逐步导航：

- **每一段跟着走**：该走哪、上哪节车厢、在哪儿下，屏幕逐步给出；步行、骑行、滑板车段都有转向指引。
- **下车提醒**：快到下车站时推送提醒，公交上打瞌睡也不怕坐过站。
- **最佳车厢与出口**：部分地铁城市会提示停靠哪节车厢，下车后离换乘口或出口最近；出口繁多的站点（香港、伦敦这类）尤其省事。
- **语音播报**：点耳机图标开启后，按你当前的移动速度在需要的时机播报，不必一直盯屏幕。
- **实时改道**：错过一班、临时改步行，方案会跟着你的实际位置重新调整后续步骤与时间。
- **手表联动**：Wear OS 手表装上应用后，GO 行程的逐步提示会出现在表盘上。

GO 模式全程联网效果最好；网络不稳时先按[离线使用与实时到站.md](离线使用与实时到站.md)把行程存下来再出发。

## 四、把常用路线固定下来

- **收藏站点与线路**：站点收藏后首页直接显示该站实时到站；订阅某条线路后，延误、停运、罢工等消息会主动推送。
- **家与公司**：设好之后，首页一键查「回家 / 到公司」。
- **日程同步**：绑定日历后，当天的日程地点可以直接拿来规划怎么去。
- **行程分享**：进行中的 GO 行程可以分享给亲友，对方点开链接就能看到你的实时进度与预计到达时间，不需要也装一个。

规划本身免费、会看到广告；要不要为免广告付订阅，见[CLUB会员与收费.md](CLUB会员与收费.md)。它和谷歌地图各管哪一段，见[与谷歌地图怎么搭配.md](与谷歌地图怎么搭配.md)。
