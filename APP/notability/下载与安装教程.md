## 一、这份安装包是什么

这是一份安卓平台的 Notability 笔记应用安装包，界面为简体中文。装之前先核对参数，和下面对得上就说明拿的是同一份：

| 项目 | 数值 |
| --- | --- |
| 版本号 | 7.0.0 |
| 包名 | `com.xmnotability.ggg` |
| 安装包大小 | 6.68M |
| MD5 | `E5899702460210EB0FAC29ADDCF8A94C` |
| 系统要求 | 安卓 5.2 及以上 |
| 采集时间 | 2026-09-23 |

包名可以在一些应用信息页里核对，也可以安装后用任意「应用信息」工具查看。如果你要找的是苹果 App Store 里那款 Notability，先看[安卓版和苹果版的区别.md](安卓版和苹果版的区别.md)，别装错。

## 二、从网盘获取安装包

1. 打开 [Notability 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cc07425ca2c7)。
2. 登录夸克后选择转存到自己的网盘，再从网盘里下载到手机（或先下到电脑再传手机）。
3. 网盘里的文件名形如 `notability_v7.0.0.apk`，文件夹里还有一份说明 txt，留着即可。
4. 下载完成后核对大小是否约 6.68M，明显偏小说明没下完整，重新下一次。

## 三、安装步骤

1. 在手机文件管理器里点这个 `.apk`。
2. 系统会提示「禁止安装未知来源应用」——这是安卓对非商店安装的默认拦截。到设置里允许**当前来源**（浏览器或文件管理器）安装应用后返回重试。
3. 如果手机自带的安全中心弹出「风险提示」或「纯净模式」拦截，要不要继续由你自行判断，选择继续/信任即可进入安装。
4. 安装提示「签名冲突」或「已存在同名应用」时，说明手机上已有另一款同名应用：**先卸载旧的再装**，两个包名不同也可能共用桌面图标名，别指望覆盖安装。
5. 装完打开，首次会请求存储、麦克风等权限：存储用于保存笔记与导出文件，麦克风用于语音备忘录录音。只在要用对应功能时给权限也行，之后可随时在系统设置里改。

## 四、装完打不开怎么办

装上了但闪退、卡在启动页的处理见[常见问题与处理.md](常见问题与处理.md)，最常见的原因是系统版本低于安卓 5.2，或安装包没下完整。
