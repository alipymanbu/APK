## 一、安装类

**提示「禁止安装未知来源应用」**
安卓对非商店安装的默认拦截。到设置里允许当前来源（浏览器/文件管理器）安装应用，返回重试，步骤见[下载与安装教程.md](下载与安装教程.md)。

**提示签名冲突 / 已存在同名应用**
手机上装过另一款同名或同包名应用。先卸载旧的再装这份；覆盖安装行不通。分不清装的是哪一款，对照包名 `com.xmnotability.ggg`，详见[安卓版和苹果版的区别.md](安卓版和苹果版的区别.md)。

**解析包出错 / 安装包损坏**
多为下载不完整。这份包应约 6.68M，明显偏小就重新下；在电脑上可核对 MD5 是否为 `E5899702460210EB0FAC29ADDCF8A94C`（Windows 自带命令）：

```powershell
certutil -hashfile notability_v7.0.0.apk MD5
```

**安装按钮是灰的 / 装完提示不兼容**
确认系统为安卓 5.2 及以上；低于该版本装不上，属设备限制，无解。

## 二、启动与稳定性

**打开就闪退 / 反复停止运行**
按下面的顺序排查（华为、vivo、realme 三家官方支持页给出的口径一致，截至 2026-09）：

1. **重启与清后台**：杀掉后台重开，或直接重启手机，先排掉临时故障。
2. **清缓存**：长按应用图标 → 应用信息 → 存储 → **清除缓存**。注意只清缓存，别上来就清数据——缓存是临时文件，清了不丢笔记；**清除数据会删掉本地笔记**。
3. **看存储空间**：系统可用空间不足会引发异常，华为官方建议可用存储至少保留 20%。
4. **查权限**：应用信息 → 权限，确认相机、麦克风、存储没有被禁。
5. **强制停止后再启动**：应用信息 → 强制停止，回到桌面重新打开。
6. **核对安装包**：系统低于安卓 5.2、或安装包没下完整（核对大小 6.68M / MD5），重下重装。
7. **卸载重装**：以上都无效再走这步——卸载会清空应用私有数据，重要笔记先想办法备份（见下方「升级/重装」一条）。

**手机清理工具误杀**
部分手机管家/清理工具会限制后台自启，把 Notability 加入白名单后重试。

**升级/重装后原笔记还在不在**
笔记数据存在应用私有存储里，正常覆盖更新不会丢；**卸载**会清掉私有数据。想保留内容，先看应用内有没有导出功能，把笔记导出存到网盘或文件管理器，再动安装包。

## 三、权限类

**录音键没反应 / 语音备忘录录不了**
没给麦克风权限。系统设置 → 应用 → Notability → 权限 → 开启麦克风，回到应用重试。权限弹窗只在首次出现，当初点了拒绝就只能进设置手动开。

**OCR 扫描打不开相机 / 识别完没保存**
相机权限没开导致无法取景，存储权限没开导致读不了相册、存不了结果，两个都在同一处补开。

**通知或后台被限制**
部分国产系统的「省电策略」会杀后台。若应用切后台再回来总是重新加载，把它的电池策略改为「无限制」。

## 四、功能效果类

**OCR 识别错字多**
先改环境再怀疑应用：光线均匀无反光、纸张拍正拍平、识别框只圈一小段分次识别。改完仍差，看[OCR扫描与语音备忘录怎么用.md](OCR扫描与语音备忘录怎么用.md) 的操作细节。

**录出来的声音小、杂音大**
录音质量取决于手机麦克风与环境，离声源近一点、安静环境再录；它是备忘用途，不按专业录音笔衡量。

**找不到某个功能 / 界面和截图不一样**
这份文档针对版本 7.0.0（6.68M）编写，你若装的是其他同名应用（比如包名 `com.r.learnnote` 的「Notability学习笔记」，或苹果那款），界面自然对不上——回到[安卓版和苹果版的区别.md](安卓版和苹果版的区别.md) 认包名。
