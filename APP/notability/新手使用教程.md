## 一、先认清主界面

这版 Notability 不是单一的记事本，底部一排就是它的全部主功能，从左到右大致是：

| 入口 | 干什么 |
| --- | --- |
| 笔记 | 所有文字笔记的列表与编辑，最常用的入口 |
| 记账 | 日常收支记录，按账本分类 |
| 存钱 | 与记账配套的储蓄目标记录 |
| 我的 | 个人设置、主题样式等 |
| 中间加号 | 快速新建（笔记等） |

日常记录就待在「笔记」里，要管钱切到「记账」。

## 二、新建一篇笔记

1. 点底部中间的加号（或笔记页里的新建按钮）进入「新建笔记」。
2. 上面一栏填**笔记标题**，下面大面积区域是**笔记备注**正文，点进去直接打字。
3. 正文工具栏里有几个高频按钮：
   - **待办勾选框**：插入一条可勾选的事项，适合清单；
   - **列表/缩进**：把段落变成有序、无序列表，做层级；
   - **字体样式（A）**：调字形、加粗一类的基础格式。
4. 标题右侧有**星标**和**标签**两个图标：星标把这篇标成收藏，标签给它归类，方便以后筛。

写完返回列表即可；若界面弹出保存提示，记得点一下（配合下文的分类整理，别都堆在默认列表）。

## 三、怎么整理已有笔记

- **靠标签分组**：给笔记打上如「工作」「课程」的标签，之后按标签筛，比翻列表快。
- **靠收藏提重点**：临时要反复翻的那几篇点星标，从收藏入口直达。
- **靠标题命名规范**：标题写清主题（如「9月26日 周会纪要」），列表里一眼能认。
- 主题样式在「我的」里切换，界面配色与笔记底色会跟着换。

## 四、记账：九种账本分开记

1. 切到「记账」，顶部会显示**结余、支出、收入**三个合计数。
2. 账本横向排列，常见的有**默认账本、工作账本、旅行账本**等共九种——把不同场景的钱分开记，月底看分类才不混。
3. 下方「本月记账」按日期列出每笔流水，每笔带分类图标与金额（餐饮、工资、住房这类）。
4. 点新建逐笔填：金额、分类、备注，收支方向别记反。

「存钱」是单独一个入口，进去后按它的表单记录存入，与记账的收支流水分开。

要往笔记里塞图片、录音或把纸质资料变文字，见[OCR扫描与语音备忘录怎么用.md](OCR扫描与语音备忘录怎么用.md)。
