## 一、这是什么应用

MG渲染器的官方名字是 **MobileGlues**（社区习惯叫它 MG 渲染器），它不是游戏，也不是启动器，而是一个给《我的世界》Java 版用的**图形兼容层**：手机上的游戏发出桌面 OpenGL 的绘图指令，它把指令转成安卓 GPU 认识的 OpenGL ES 再交给显卡执行，光影、Sodium 这类依赖桌面 OpenGL 的模组才跑得起来。官方核心代码在 GitHub 的 [MobileGL-Dev/MobileGlues](https://github.com/MobileGL-Dev/MobileGlues) 开源，中文介绍页在 [ues.mobilegl.top](https://ues.mobilegl.top/)，英文站在 [mobileglues.com](https://mobileglues.com/)。

装它的前提：手机上已经有一个能跑 Java 版的安卓启动器，社区里最常见的是 FCL（Fold Craft Launcher）与 ZL2（ZalithLauncher 2），Pojav 系启动器也有用户在用；游戏版本需 **1.17 及以上**（社区教程口径）；显卡驱动至少要支持 OpenGL ES 3.0，官方推荐 ES 3.2。

本篇对应的安装包是 **1.3.4**，包名 `com.fcl.plugin.mobileglues`，大小 10.71M，MD5 `6AB4C76A0769303EE09D9FD19580A487`，信息记录于 2026-09-21。网上各软件站给的多是官方更新版，可能与这份不是同一版；版本号、包名、体积一律以上面这段为准。

## 二、从网盘获取安装文件

1. 打开 [MG渲染器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0a1079283369)。
2. 登录夸克后转存到自己的网盘，再下载到手机（或先下到电脑传手机）。
3. 文件名形如 `MG渲染器_v1.3.4.apk`，下载完核对大小是否接近 10.71M，差太多说明没下完整，重新下。

**核对 MD5（推荐）**：官方在 GitHub Releases 里为每个版本公布了 APK 的 md5，v1.3.4 公布的值是 `6ab4c76a0769303ee09d9fd19580a487`，与上面记录的一致。用手机上的校验工具（或电脑 `certutil -hashfile 文件.apk MD5`）算一下你手里这个包，对得上才说明下完整、且与官方发布的是同一个文件；对不上的来源不要装。

## 三、安装 APK

1. 在手机文件管理器里点击该 `.apk`。
2. 系统提示「不允许安装来自此来源的应用」时，点提示进入**安装未知应用**权限，给文件管理器（或浏览器）开启允许，返回继续安装。
3. 装完先别急着打开游戏，按下一节把启动器里的渲染器切过来。

> 点了没反应或提示「解析包时出现问题」，一般是文件没下完整，回第二节重新下载；进游戏后起不来的问题统一看 [光影黑屏与启动失败排查.md](光影黑屏与启动失败排查.md)。

## 四、装完在启动器里选中它

**这一步不做，游戏不会用上它** —— 有用户反馈「装了 FCL 里看不到这个渲染器」，几乎都是装完没有完全退出启动器。正确顺序是：**先装好本插件 APK → 把启动器从多任务里彻底划掉 → 重新打开启动器**，让它重新扫一遍已安装的渲染器插件。

**FCL（Fold Craft Launcher）**：

1. 启动 FCL，点界面**左下角的齿轮**进入「全局游戏设置」。
2. 向下滚动找到「**渲染器**」这一项，点它右侧的齿轮按钮。
3. 在弹出的列表里向下翻，找到 **MobileGlues** 点选，设置自动保存。

**ZL2（ZalithLauncher 2）**：

1. 完全退出 ZL2 后重开，点**右上角的齿轮**进设置。
2. 找到「**全局渲染器**」，展开下拉列表。
3. 向下翻到 **MobileGlues** 点选即生效。

选完后启动一次游戏，日志或渲染器信息里能看到 `MobileGlues` 字样就说明挂上了。

## 五、插件本身的界面能做什么

这个 APK 装在手机上会有一个自己的图标，打开后主要做两件事：

1. **授权**：首次进入按提示勾选文件访问授权（v1.3.5 起改为「所有文件访问」权限，本包 1.3.4 还是按旧的授权流程走）。不授权它读写不了配置文件，启动器里也读不到你调过的参数。
2. **改参数**：主页下方的「**修改渲染器设置**」进入设置页，里面有 MultiDraw 模拟、ANGLE、OpenGL 目标版本、各扩展开关等选项，具体每一项怎么选看 [渲染器设置项怎么调.md](渲染器设置项怎么调.md)。

配置文件默认落在手机存储的 `MG` 目录下（日志里显示为 `/sdcard/MG`）。改完设置回启动器直接启动游戏即可生效，不需要重启手机。

## 六、覆盖升级与版本核对

- 手里已有旧版的话直接安装本包即可覆盖升级，调过的设置保留在 `MG` 目录里，不受覆盖安装影响。
- 包名固定是 `com.fcl.plugin.mobileglues`，同包名才能覆盖；下载站上偶尔会出现改了包名的同名软件，装之前核对一下包名。
- 版本号是三段式 `x.y.z`，官方更新不定期，当前官方最新版已到 2.0.0（截至 2026-09，以 [官方 Releases 页面](https://github.com/MobileGL-Dev/MobileGlues-release/releases) 当时显示为准）；要不要升、升了改了什么，见 [版本更新记录与升级方法.md](版本更新记录与升级方法.md)。
