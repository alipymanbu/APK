## 一、设置从哪进

打开手机上的 MG渲染器（MobileGlues）插件 → 首次使用先按提示完成文件授权 → 主页下方点「**修改渲染器设置**」。所有改动写进手机存储的 `MG` 目录，回启动器直接开游戏就生效。本篇按 1.3.4 的设置页写；2.0.0 官方把设置改版成分页布局、MultiDraw 选项也重做过，你手上若是新版，选项名与分组会略有出入（以界面实际显示为准）。

## 二、先看懂三件事，再动开关

1. **模拟方案决定下限**：MultiDraw 模拟的四个方案对 OpenGL ES 的要求不同（见第三节），选了设备达不到的方案，轻则没效果，重则进不去游戏。
2. **扩展开关决定兼容性**：`ARB_compute_shader`、`timer_query`、`direct_state_access` 这类开关打开能解锁一部分模组/光影的特性，但驱动实现不完整时反而会花屏、崩溃。
3. **一次只改一项**：改完进游戏验证再改下一项，一次改三样，出问题你不知道是哪样引起的。

## 三、MultiDraw 模拟方案怎么选

MultiDraw 是 Sodium 与 OptiFine「区域渲染」用到的批量绘制技术，在 PC 上能减少 CPU 与 GPU 的通信开销。手机 GPU 大多不提供这个硬件扩展（几乎全部 Mali、Adreno 都没有，部分 PowerVR 有），所以 MobileGlues 要**模拟**它——模拟的效果直接关系到帧数。以下口径来自官方开发者 BZLZHH 的说明文章：

| 方案 | 需要的 OpenGL ES 条件 | 怎么用 |
| --- | --- | --- |
| 自动（Auto） | 按设备实际能力选 | **默认选它**。无扩展的设备自动落到 Indirect，个别设备落到 Indirect 不是最快，可手动换 BaseVertex 试 |
| Indirect | ES 3.1 | 大多数设备的自动结果 |
| BaseVertex | ES 3.2 | 部分设备用它才能到最佳帧率 |
| MultiDraw Indirect | ES 3.1 + `EXT_multi_draw_indirect` | 设备真有该扩展时效率最高，自动模式会命中它 |
| DrawElements | ES 3.0 | 效率极低，**不建议使用** |

判断自己该停在哪一档：先用「自动」跑一趟，帧数不满意再手动试 BaseVertex；只有这两步都试过，才需要去动别的开关。设置页里的说明与内置测速（2.0.0 起内置了自动选最快方案的基准测试）可作为参考，最终以你自己机器的实测帧数为准。

## 四、三个扩展开关

| 开关 | 作用 | 什么时候动它 |
| --- | --- | --- |
| `ARB_compute_shader`（计算着色器） | 打开后可用 compute shader，部分光影与模组（如 AcceleratedRendering 类优化）依赖它 | 默认开；花屏、崩溃时先关掉试 |
| `timer_query`（计时查询） | 让游戏能读 GPU 耗时，用于性能统计类显示 | 默认开；出现渲染异常时可关 |
| `direct_state_access`（DSA） | 1.3.0 加入的扩展，能简化部分模组的绘制调用 | **1.3.1 起默认关闭**。开过之后某些模组（例如 Create）渲染不对，就把它关回去 |

升级注意：官方修过一次「从旧版升级时 `timer_query` 被错误禁用」的问题（1.3.0 修复）。升级后如果发现这些开关状态不对，进设置页重看一眼再开游戏。

## 五、ANGLE 驱动开关

ANGLE 是把 OpenGL 调用转到另一套驱动路径的可选方案，官方把它列为「按需开启的替代驱动路径」。实际怎么选，社区的通行经验是：

- **先保持关闭**，用设备原生驱动跑，多数机型这是默认可用的状态；
- 出现「同一光影在别人手机能开、你这黑屏/报错」、或驱动对某个扩展支持残缺时，**打开 ANGLE 再测一轮**——部分路径追踪类光影（如 SEUS PTGI 系列）有用户反馈需要 ANGLE 才能运行；
- 开了 ANGLE 后帧数明显下降也属常见，画质能出来但不流畅时，回到关闭状态并在光影侧降档。

是否开启没有标准答案，按「能不能出画面 + 帧数」两条实测结果定。

## 六、OpenGL 目标版本与「忽略着色器报错」

- **OpenGL 目标版本**：告诉游戏「你可以按哪个版本的桌面 OpenGL 来写指令」。调高会解锁更多模组/光影特性，但设备驱动未必都实现；调低兼容性更好。建议先用默认值，遇到某个光影/模组明确要求更高版本再上调，上调后出问题就退回。
- **忽略着色器/程序报错（Ignore shader/program error）**：开启后，光影包里个别编译报错的着色器会被跳过而不是中断加载。官方在 1.3.5 的更新说明里写明：**运行 Minecraft 26.3 snapshot-3 及更高版本必须开启它**。平时遇到「光影加载到一半报 shader error 退不回去」，也可以开它先进游戏，再考虑换光影。

## 七、改完不生效、想恢复默认

1. 改完设置确认插件提示保存成功，回启动器**直接启动**即可，不用重启手机。
2. 游戏里没变化，先核对启动器的「全局渲染器」确实选的是 MobileGlues（见 [下载与安装教程.md](下载与安装教程.md) 第四节）。
3. 想全部推倒重来：删掉 `MG` 目录下的配置文件后重开插件授权即可恢复默认（v1.3.2 修过删除配置后误要求重新授权的问题）。删之前记住自己改过哪几项，否则排查黑屏时会失去参照。
4. 排查不出原因时，用 [光影黑屏与启动失败排查.md](光影黑屏与启动失败排查.md) 的顺序走一遍——多数「改坏了」的表现最终落在光影或模组上，不在设置页。
