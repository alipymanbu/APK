# Kwai 常见问题与排查

> 打不开、一直加载、收不到验证码、空间被缓存占满，是这类短视频应用最常遇到的几类问题。本篇按现象分条，每条给出先动哪一步、该看什么现象，避免一来就卸载重装。

## 一、打开就闪退，或者卡在启动页

按这个顺序试，多数情况在前两步就能定位：

1. **先确认版本和包名**：进 设置 → 应用 → Kwai → 应用信息，包名应为 `com.kwai.video`，版本应为 `13.6.10.545500`。包名不对说明装的不是这一份，按 [同名应用与版本怎么认.md](同名应用与版本怎么认.md) 重装。
2. **清一次缓存再看**：设置 → 应用 → Kwai → 存储 → 清除缓存。清缓存不动账号数据，比直接卸载重装安全。
3. **确认系统版本是否满足要求**：系统过旧时可能在启动阶段就被直接终止，表现就是闪一下退回桌面。安装前以官方应用商店页面标注的要求为准。
4. **重装前先确认安装包完整**：重新校验一次 MD5 再装，包不完整时同样会启动失败，校验方法见 [下载与安装教程.md](下载与安装教程.md) 第三节。

## 二、能打开，但视频一直转圈、加载不出来

这类现象基本都是网络路径的问题，不是应用坏了：

| 现象 | 先查什么 |
| --- | --- |
| 首页完全刷不出内容 | 当前网络能否正常访问该服务；Wi-Fi 与移动数据来回切一次 |
| 图片能出、视频不出 | 视频流的域名被网络环境限制，换一个网络再试 |
| 个别视频不加载，其它正常 | 那是该条内容的问题（已被删除、有地区限制），不是你的账号或设备 |
| 只有直播卡 | 直播对带宽更敏感，切到更稳的网络，或等高峰过去 |

先用浏览器打开任意网页确认网络本身是通的，再排查应用。国内部分网络环境访问海外服务会不稳定，这一点靠重装应用解决不了。

## 三、登录不上、收不到验证码

- 号码和地区码要配对（中国大陆手机号选 `+86`），地区码错了短信到不了；
- 请求过密会被临时冷却，隔十分钟再试，别连续点；
- 系统把验证码短信拦进了骚扰箱，或者开了短信过滤，先去这些目录里找；
- 用第三方账号登录时，先确认那个账号在浏览器里能正常登录，跳转授权失败通常是它本身的问题；
- 登录后马上又掉回游客状态，检查系统有没有限制 Kwai 的后台运行与自启动，被强杀时登录态容易丢。

更细的注册方式与前提见 [注册登录与账号设置.md](注册登录与账号设置.md) 第二节。

## 四、手机空间被占满，怎么清

短视频应用的空间占用分三块，处理方式不同：

1. **缓存**：设置 → 应用 → Kwai → 存储 → 清除缓存，这部分随时可以清，清了不影响登录与作品；
2. **应用数据**：清除数据会把账号、草稿、本地设置一并抹掉，只有在彻底卡死时才用，用完要重新登录；
3. **下载到本地的东西**：看过并保存过的视频在相册里，要在相册或文件管理器里删，清应用缓存管不到它。

平时在应用内的设置里也可以关掉自动缓存一类选项，减少长期占用；刷得更久、看得更高清，占用就会更大，这是正常的。

动手清理之前，先看一眼草稿箱里有没有还没发出去的素材——第 2 项会把它一起抹掉，导出方法见 [草稿箱在哪会不会丢.md](草稿箱在哪会不会丢.md) 第四节。

## 五、账号安全：这几件事不要做

- **不要把短信验证码给任何人**。自称平台客服、说账号异常要帮你处理的，都不要理会，正规渠道不会索要验证码；
- **不要装来路不明的包**。要求先装「下载器」「加速器」再给安装包的，直接放弃，按 [同名应用与版本怎么认.md](同名应用与版本怎么认.md) 的三条依据判断；
- **不要用第三方工具代登录**。把账号密码或授权码交给第三方工具，等于把账号交出去；
- **收到陌生私信里的链接要谨慎**，尤其是自称能帮你涨粉、解封、退款的。

## 六、想更新，或者想退回旧版本

- **更新**：官方应用商店（Google Play、App Store）会自动推送，也可以在官网 [kwai.com](https://kwai.com) 找官方入口。更新后版本号会往上走，网盘里这一份 `13.6.10.545500` 不会跟着变；
- **从新版退回网盘里这一份**：安卓上要先卸载当前版本再装旧包，直接覆盖装通常会被拒绝（签名相同但版本号更低）；卸载前确认账号能重新登录，卸载会清掉本地的草稿与缓存；
- **不要为了留在旧版而不更新**，语言支持、兼容性与安全修复都在新版里，只有在旧版上确实遇到无法绕开的问题时才考虑退回。
