# Kwai 拍摄剪辑与发布作品

> 从按拍摄键到点发布，中间有几处最容易被忽略：素材授权、音频与特效、可见范围、下载与转发开关。本篇按实际操作顺序把这些逐个说清，并给出发布后想改动时的对应入口。

## 一、开拍前先给权限

拍摄会用到相机和麦克风，从相册导入素材还可能用存储权限。第一次点拍摄时会依次弹出来：

- 相机：不给就没法现场拍，只能从相册导入已有素材；
- 麦克风：不给会录成静音，后期配乐仍有声；
- 存储 / 照片和视频：不给就选不到相册里的素材。

这些权限在手机的系统设置里可以随时改，改完回到 Kwai 重新点一次拍摄即可生效。

## 二、拍摄，或者从相册导入

底部导航中间那个加号就是拍摄入口，走两条路：

1. **现场拍**：按住或点按录制按钮，松开结束一段；可以一段一段地拍，拍完再拼；
2. **导入已有素材**：在拍摄页切换到相册入口，选好照片或视频片段，进入下一步编辑。

导入的视频如果原来比例不是竖屏，会被加边或裁切，先在预览里看一眼构图再往下走。

## 三、配乐、滤镜、特效与文字

编辑页是横向的工具栏，常用的几项：

| 工具 | 用在哪 |
| --- | --- |
| 配乐 / 音乐 | 从曲库里挑，也可以用自己的音频文件 |
| 滤镜 | 整体色调，选中后可以再调强度 |
| 特效 | 转场、分屏、动态贴纸这一类的效果 |
| 文字 / 贴纸 | 加标题、说明文字、表情贴纸 |

配乐和特效都可以叠加，但层次越多渲染越慢，导出前先预览一遍最稳妥。曲库里的音乐标注了使用范围，商业用途要另看授权说明。

## 四、剪切、拼接与时长

- **剪切**：选中片段后拖动两端的把手，去掉开头结尾多余的部分；
- **拼接**：多个片段按顺序排好，之间可以加转场，顺序在编辑页直接拖动调整；
- **变速**：把片段调快或调慢，带声音的片段变速后音调也会跟着变，需要单独处理的先关掉原声再配音；
- **时长**：短视频作品传得越长，观看完成率通常越低，先把要讲的事压缩到最短是更省事的做法。

## 五、发布前三项一定要设

这三项决定了作品发出去之后别人能对它做什么，都在发布页里：

| 设置项 | 可选项 | 影响 |
| --- | --- | --- |
| 谁可以看 | 公开 / 仅好友（部分可见）/ 私密（仅自己） | 私密作品不进推荐流，只有你自己在主页看得到 |
| 允许合拍 | 开 / 关 | 关掉后别人不能拿你的作品做合拍 |
| 允许下载与转发 | 开 / 关 | 关掉后别人保存与转发你的作品的入口会消失 |

默认值通常是公开加允许，涉及私人场景（家里、孩子、工牌）时先把「谁可以看」改成私密或仅好友，再补上描述，最后发布。

## 六、发布之后还能改什么

- **改可见范围**：进自己主页打开该作品，在更多菜单里能切换公开 / 仅好友 / 私密，改完立即生效；
- **改文案与封面**：多数版本支持修改描述，封面可以重新挑一帧；
- **删除**：从主页删除即从平台移除，删之前若想留档，先把它保存到本地；
- **保存自己的作品**：用作品页的保存入口可以存到相册，成品会带平台水印，这是正常现象。

## 七、没发完的作品会进草稿箱

编辑到一半退出、或者拍完没点发布，作品会留在本机的草稿箱里，不会自动同步到账号。由此有两个后果：

- 换手机、卸载重装之后，草稿不会跟着回来；
- 清理手机空间时，「清除缓存」和「清除应用数据」对草稿的影响完全不同。

草稿箱的入口、导出方法和丢失后的处理，单独写在 [草稿箱在哪会不会丢.md](草稿箱在哪会不会丢.md)。素材比较重要时，发布前后都先导出一份到相册。

## 八、想开直播要先满足什么

直播入口在拍摄页附近，但能不能开播取决于账号状态，不是装上就有：

1. **绑定手机号**：没有绑定手机号的账号通常看不到开播入口，先在设置里把手机号补上，注册方式见 [注册登录与账号设置.md](注册登录与账号设置.md) 第三节；
2. **粉丝量门槛**：不同地区、不同时间的门槛不一样，公开说法从几百粉到数千粉都有，且会随平台政策调整，以应用内开播入口给出的提示为准；
3. **账号记录**：有过违规处理的账号，门槛会更高，甚至暂时不给开播权限。

开播之后画质与码率不是越高越好：码率越高，对上行网络的要求越高，网络一抖观众端就会卡顿甚至掉线。用手机开播先在 Wi-Fi 下试一场，确认自己这边和观众那边都稳定，再考虑往上调画质。

## 九、作品没有推荐量或者被下架时先看什么

- **审核**：新作品一般会先过一遍审核再进推荐流，审核期间只有你自己可见，等一会儿再看；
- **原创性**：搬运他人的视频、只改背景音乐或镜像翻转，容易不被推荐，甚至被下架；
- **重复内容**：同一素材反复发、删了再发，平台会识别为重复；
- **可见范围**：作品设成了私密或仅好友，自然不会有公开推荐量，先回第六节确认这一项。

账号层面的问题（登录异常、消息收不到、打不开）不在这一节，去 [常见问题与排查.md](常见问题与排查.md)。
