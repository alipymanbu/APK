# Kwai 草稿箱在哪会不会丢

> 拍完没发的作品会留在本机草稿箱，不在账号云端，所以换手机或清理数据时容易丢。本篇说清草稿箱的入口、哪些操作会把草稿清掉，以及发布前怎么先导一份到相册留档。

## 一、草稿箱的入口

草稿箱不在底部导航里，一般收在左上角的菜单中：

1. 打开 Kwai，点首页左上角的横线图标（三条横线的菜单按钮）；
2. 在侧边菜单里找「草稿箱」（部分界面写作 Drafts）；
3. 进去后能看到尚未发布的作品列表，点任意一条可以回到编辑状态继续。

各版本的入口位置会有差别，如果菜单里没有，可以从「我的」页面向下找作品区，草稿通常和已发布作品分开列。

## 二、什么会被存成草稿

两种情况会留下草稿：

- 拍完或导入素材、编辑到一半退出应用，会自动留一份；
- 编辑完成但在最后一步没有点发布，作品按草稿留在本地。

已经点过发布的作品不再是草稿，它属于账号内容，见 [拍摄剪辑与发布作品.md](拍摄剪辑与发布作品.md) 第六节。

## 三、哪些操作会把草稿清掉

草稿存在这台手机的应用数据里，不跟着账号走。按影响范围排一下：

| 操作 | 对草稿的影响 |
| --- | --- |
| 清除缓存 | 一般只清临时文件，草稿通常还在；不确定时先按第四节导出一份再动手 |
| 清除应用数据 | 会一并抹掉草稿，等同于把应用恢复成刚装好的状态 |
| 卸载应用 | 同上，草稿随应用数据一起删除 |
| 换手机、重装系统 | 草稿不会跟过去，新设备上是空的 |
| 一边编辑一边被系统清理后台 | 通常还剩一份自动保存的草稿，重新打开应用进草稿箱确认 |

越是重要的素材，越不要长期只放在草稿箱里。

## 四、发布前先导一份到手机本地

草稿箱里的作品可以单独导出，这是最稳妥的留档方式：

1. 进草稿箱，找到那条作品；
2. 点作品旁边的更多入口（一般是三个点）；
3. 选「下载到本地」，把成片存进相册；
4. 到相册里确认能正常播放，再决定要不要继续在应用里编辑。

导出后的文件和草稿是两份，删掉草稿不影响导出的那份。

## 五、草稿删掉之后还能找回来吗

以目前的机制，找回的可能性很低：

- 草稿没有随账号同步到云端，删掉之后应用内没有回收站可还原；
- 卸载或清除应用数据后重装，草稿箱里不会出现旧内容；
- 已经发布过的作品不受影响，它挂在账号上，重新登录就能看到；
- 确实有内容误删时，可以通过应用内的意见反馈或官方客服渠道说明情况，但不要指望一定能恢复。

所以判断标准很简单：这条素材还只存在于草稿箱里，就先按第四节导出。

## 六、和「删除已发布作品」的区别

| | 草稿 | 已发布的作品 |
| --- | --- | --- |
| 存放位置 | 本机应用数据 | 账号上 |
| 别人能看到吗 | 不能，不进推荐流 | 取决于作品可见范围 |
| 换手机还在吗 | 不在 | 在，重新登录即可见 |
| 删除后能恢复吗 | 基本不能 | 删除即从平台移除，同样不可恢复 |

清空间时最容易被误伤的是草稿，清理前对一遍 [常见问题与排查.md](常见问题与排查.md) 第四节的三类占用，别把「清除数据」当成「清除缓存」点。
