## 一、先对一遍版本和包名

Kwai 是面向海外市场的短视频应用，官方应用商店里的版本一直在往前走，同一时间能搜到的教程、评测多半写的是另一个版本号。下面这张表是网盘里这一份包的实际信息，装完在手机里核对也对得上。

| 项目 | 值 |
| --- | --- |
| 应用名 | Kwai（中文常称「快手国际版」） |
| 包名 | `com.kwai.video` |
| 版本 | 13.6.10.545500 |
| 安装包大小 | 6.85M |
| 安装包 MD5 | `9bd45c582a116554d5434e19977f4969` |
| 界面语言 | 默认跟随设备与地区，可切换为简体中文 |
| 系统要求 | 以官方应用商店页面标注的为准 |

三条判断：

- 网上搜到的版本号通常会比 13.6.10.545500 更高，那是官方商店的最新版；本篇与网盘里的包都按 13.6.10.545500 说话，不要拿商店最新版来对照。
- 识别这一份包最可靠的办法是看包名：装完后在系统里查到的包名应该是 `com.kwai.video`。名称、图标都可能被仿冒，包名不容易对。辨别方法见 [同名应用与版本怎么认.md](同名应用与版本怎么认.md)。
- 安装时会先解压一份文件再复制，手机剩余空间要比安装包本身宽裕一些，别在只剩几十兆的时候硬装。

## 二、从网盘把安装包取到手机

1. 打开 [Kwai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9cd8de08b354)。
2. 先点「保存到我的网盘」，再从自己的网盘里下载。直接下载也能用，但转存一份之后，原分享链接以后失效了也不影响你。
3. 等文件下载完，记下它在手机里的位置，多数浏览器会放在「下载」或 `Download` 目录。
4. 文件名通常形如 `Kwai_v13.6.10.545500.apk`，以网盘里实际显示的名字为准。

如果打开链接提示失效或需要提取码，说明这条分享已经不是当前状态，换最新的一条再试。

## 三、动手装之前校验一下包

安装包从网络传到手机，中间出过错的话，装的时候会报「解析包错误」。花半分钟校验一次，能省掉后面一堆莫名其妙的排查。

用电脑校验最省事：把 APK 拷到电脑上，在文件所在目录执行：

```powershell
certutil -hashfile "Kwai_v13.6.10.545500.apk" MD5
```

输出的十六进制串去掉空格后，应该和第一节表里的 `9bd45c582a116554d5434e19977f4969` 完全一致（大小写不敏感）。手机上也可以用带 MD5 校验功能的文件管理器做同样的事。对不上就重新下载一次，别将就着装。

## 四、先去系统里放行「未知来源」

网盘里的包不是从应用商店装的，安卓默认会拦一次。要先给下载它的那个应用（浏览器或夸克）开安装权限，各品牌路径不一样：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 权限管理 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装外部来源应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 生物识别和安全 → 安装未知应用 |
| 原生安卓 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

路径记不住没关系，在设置顶部的搜索框里搜「未知应用」或「外部来源」，基本都能跳到同一页。找到负责下载的那个应用，把开关打开。

## 五、安装与第一次打开

1. 从通知栏点刚下载完的文件，或者打开文件管理器找到那个 `.apk` 点它。
2. 弹出安装界面点「安装」，等进度走完，桌面出现图标。
3. 首次启动会依次弹权限申请，真正影响功能的是这几项：

| 权限 | 不给会怎样 |
| --- | --- |
| 相机、麦克风 | 不能拍摄、不能开直播，刷视频不受影响 |
| 存储 / 照片和视频 | 不能从相册选素材，下载的作品也存不进来 |
| 网络 | 打不开内容 |
| 通知 | 只影响消息与互动提醒 |
| 位置 | 影响「附近」这类内容；不给也能正常刷 |

具体弹哪几项、叫什么名字，以你手机上实际弹出的为准，上面只是它们各自的用途。

4. 第一次进入会让你选语言和地区。这一步建议直接选好，推荐流会跟着这个走；想改成简体中文的路径见 [界面语言怎么切换成中文.md](界面语言怎么切换成中文.md)。
5. 不登录也能先刷，但关注、评论、私信、发作品都要账号，见 [注册登录与账号设置.md](注册登录与账号设置.md)。

## 六、装不上或者装完打不开

按这个顺序自查，比反复重装有效：

- 提示「解析包错误」「应用未安装」→ 回到第三节重新校验 MD5，文件多半没下完整。
- 提示「已被阻止安装」→ 第四节的未知来源权限没开，或开了但给错了应用。
- 装好后点图标闪一下退回桌面 → 先看系统版本是否满足第一节表里的要求；仍不行的，到 [常见问题与排查.md](常见问题与排查.md) 第一节按「闪退」一条排查。
- 装完能打开、但内容一直加载不出来 → 不是安装的问题，按 [常见问题与排查.md](常见问题与排查.md) 第二节排查网络环境。
