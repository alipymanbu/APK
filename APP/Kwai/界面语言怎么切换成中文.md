# Kwai 界面语言怎么切换成中文

> Kwai 面向全球用户，界面语言默认跟着设备和地区走，装完不一定是中文。本篇给出切成简体中文的完整路径，以及切完仍有外文、或语言列表里找不到中文时的检查顺序。

## 一、切成简体中文的路径

Kwai 的设置不放在底部导航里，而是收在左上角。按下面顺序点，一般五步内就能到位：

1. 打开 Kwai，在首页左上角点横线图标（三条横线的菜单按钮）；
2. 在侧边菜单里找「Settings」或「设置」，点进去；
3. 进入「General」或「通用设置」；
4. 找到「Language」或「语言」；
5. 在语言列表里选「简体中文」，界面会立刻刷新成中文。

如果当前界面是英文，第 4 步找不到时，可以按这个顺序对：Settings → General → Language，位置在同一层级，只是名称随版本略有差别。

## 二、刚装完为什么不是中文

语言不是按账号定的，而是按这台设备定的：

- 系统语言是英文、或系统地区设在海外，Kwai 首次启动就会给英文或当地语言；
- 只有部分语言做了完整翻译，界面语言列表里能选到的才是已支持的语种；
- 首次启动弹的语言/地区选择只影响这一次的初始值，之后在设置里改，会覆盖它。

所以同样一个安装包，在不同手机上首次打开可能是英文、西班牙语或葡萄牙语，这都算正常，不是包装错了。

## 三、切完还剩下外文的地方

有三处文字不会跟着「界面语言」变，属正常现象：

| 位置 | 为什么不跟着变 |
| --- | --- |
| 别人发布的作品标题、评论、私信内容 | 那是用户自己写的，不参与翻译 |
| 创作者主页的简介、话题标签 | 同上，原文显示 |
| 部分运营活动页、新功能的说明 | 上线节奏晚于界面语言包的更新 |

判断标准很简单：只要你点进「设置」看到的是中文，说明界面语言已经切换成功，剩下的外文都属上面三类。

## 四、列表里没有中文，或改了又变回去

按这个顺序排查：

1. **先确认版本**。网盘里这一份是 `13.6.10.545500`，语言列表里没有简体中文时，先看系统里查到的版本号是不是这一串，装成了别家的包或更旧的包会导致选项不全。
2. **重启一次应用**。语言切换偶发不立即生效，从后台清掉 Kwai 再打开，设置项会落到新语言上。
3. **检查系统语言有没有反过来覆盖**。把手机系统语言临时切到中文再看一次，可以区分「应用设置没生效」和「系统在覆盖」这两种情况。
4. **仍不对就更新**。官方应用商店里的版本比这一份新，新版本对语言的支持通常更全；更新后仍要按第一节的路径重新确认一次。

语言之外的问题（打不开、内容加载不出来）归 [常见问题与排查.md](常见问题与排查.md) 管，和语言设置无关。
