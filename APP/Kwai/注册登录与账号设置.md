# Kwai 注册登录与账号设置

> Kwai 不登录也能刷，但要关注、评论、私信、发作品就得有账号。本篇讲清几种登录方式各自的前提、手机号怎么填地区码、资料能改哪些，以及换手机之后怎么接着用同一个账号。

## 一、先判断要不要登录

Kwai 允许游客状态先把内容刷起来，登录是可选的，但两条路能做的事差很多：

| 能做 / 不能做 | 游客状态 | 登录后 |
| --- | --- | --- |
| 看推荐流、搜索、看直播 | 多数可以，部分内容会提示先登录 | 可以 |
| 点赞、评论、关注 | 不可以 | 可以 |
| 私信 | 不可以 | 可以 |
| 发作品、开直播 | 不可以 | 可以 |
| 看自己关注的人的新动态 | 不适用 | 可以 |

先刷两天再决定登不登录也来得及，账号是从「我的」入口进去建的。

## 二、几种登录方式，各自的前提

入口都在底部导航最后一个标签（「我的」/「Profile」），点进后再点登录。选哪种，取决于你手上有什么：

| 方式 | 前提 | 备注 |
| --- | --- | --- |
| 手机号 | 能收短信验证码 | 最通用，换手机后也最好找回 |
| 邮箱 | 能收邮件 | 部分版本要求之后补绑手机号 |
| Google 账号 | 设备上已登录过 Google 账号 | 手机没装谷歌服务框架时这个入口用不了 |
| Facebook 账号 | 有 Facebook 账号 | 跳转授权后可登录 |
| Apple ID | iPhone 上部分版本可见 | 安卓上一般没有这一项 |

可选项会随版本和所在地区变化，你的界面上没看到某一项是正常的，用其它方式即可。

## 三、手机号注册的步骤

1. 进入登录页，选择手机号方式；
2. 先点国家/地区那一栏，选到 `+86`（中国大陆），再输入手机号；地区码填错会一直收不到验证码；
3. 勾选同意隐私政策与用户协议；
4. 点获取验证码，把收到的短信数字填进去；
5. 首次注册可能还会要求设置昵称或生日，按提示填完即可进入。

验证码有有效期，收到后尽快填；短时间反复请求会被冷却一段时间，等冷却过去再试。

## 四、收不到验证码时按顺序查

- 号码与地区码是不是配对的（`+86` 对 11 位手机号）；
- 手机有没有把该应用的短信拦到骚扰箱，或者开了短信过滤；
- 同一号码请求太频繁会被暂时冷却，隔十分钟再试一次；
- 运营商的国际短信通道在某些号段下延迟偏大，换成邮箱或第三方账号先登进去，之后在账号设置里再补绑手机号。

这些之外的情况，一并归到 [常见问题与排查.md](常见问题与排查.md) 第三节。

## 五、账号资料能改哪些

登录后在「我的」里可以编辑的资料，基本都是公开可见的：

| 项目 | 说明 |
| --- | --- |
| 昵称 | 别人搜你、在评论区看到的名字 |
| 头像 | 建议用自己拍的照片，别用侵犯他人肖像的图 |
| 个人简介 | 一句话介绍，会出现在主页 |
| 账号 ID | 注册时生成，是别人准确找到你的凭据，改动的余地很小 |

昵称和头像修改后，主页会同步更新，但历史评论里显示的还是当时的名字，这是正常表现。

## 六、换手机接着用，以及退出登录

- **同一台手机重装**：用原来的方式重新登录即可，关注、作品、私信都在账号上，不在手机里。
- **换到新手机**：优先用手机号或邮箱登录，这两种方式不依赖旧设备；只绑了第三方账号的，要先确保那个第三方账号还能登。
- **退出登录**：在「我的」→ 设置里找退出入口。退出后不会删除账号，只是这台设备回到游客状态，作品仍留在账号上。
- **别把验证码告诉任何人**，包括自称平台客服的人。任何正规渠道都不会索要你收到的短信验证码，详见 [常见问题与排查.md](常见问题与排查.md) 第五节。
