# Kwai 收不到消息提醒怎么办

> 点赞、评论、私信都进来了，手机却不响，多数时候不是应用坏了，而是系统把它的通知或后台运行掐了。本篇按「应用内 → 系统权限 → 后台与网络」三层给出可执行的排查顺序。

## 一、先分清是哪种「收不到」

三种表现的原因不同，先对号入座，能省掉一半无用操作：

| 表现 | 更可能的原因 |
| --- | --- |
| 完全没有任何提示，打开应用才看到 | 系统层把通知权限或后台运行掐了 |
| 锁屏时不响，屏幕点亮后一口气全冒出来 | 休眠时断网，或电池优化把后台冻结了 |
| 部分提醒有、部分没有 | 应用内的通知分类设置，或那条内容本身没有推送 |

## 二、应用内先检查一遍

在 Kwai 的设置里找通知相关项，确认同类提醒没有被单独关掉：

1. 左上角横线菜单 → 设置；
2. 找通知一类的选项，检查互动、私信、关注这几类是否都开着；
3. 顺便看一眼免打扰相关开关，有没有被设成整段时间静音。

这一步做完还是没提醒，问题基本在系统侧。

## 三、系统里要放行的四项

这四项是国产安卓最常见的断点。路径名称各品牌不同，最快的方式是在设置的搜索框里直接搜关键词：

| 要放行的项 | 搜索关键词 | 设置目标 |
| --- | --- | --- |
| 通知权限 | 通知、应用通知管理 | 允许通知打开，关闭「静默通知」 |
| 自启动与后台活动 | 应用启动管理 | 关掉「自动管理」，打开允许自启动、允许后台活动 |
| 电池优化 | 电池优化 | 把 Kwai 设为「不允许」优化 |
| 休眠时保持网络 | 休眠时始终保持网络连接 | 打开（关掉后省电模式或锁屏可能直接断网） |

顺带检查两件事：省电模式（低电量模式）开着时后台会被限制，收到提醒的时间会明显延迟；系统管家类软件的「一键清理」也会把 Kwai 从后台清掉。

## 四、联网权限与省流量模式

提醒要推得进来，应用得有网：

- 在流量管理里找到应用联网，确认 Kwai 的移动数据与 WLAN 两项都勾着；
- 打开「智能省流量」后，后台应用联网会被限制，把 Kwai 加入不受限制的名单，或临时关掉这个开关；
- 只在 WLAN 下愿意联网的话，锁屏切到移动数据的那一瞬间消息就会丢，改成自动切换更稳。

## 五、让系统别把它清掉

设置改完还偶发不提醒，可以在多任务界面给 Kwai 加个锁：进入多任务（最近任务）视图，下拉该应用卡片，或点卡片上的加锁图标。加锁后系统在清理后台时会跳过它。

这一步是可选的，但用了几天仍偶尔收不到提醒时，加上去最省心。

## 六、还是收不到时的顺序

按这个顺序排，每一步都能排除一类原因：

1. 从后台彻底关掉 Kwai 再打开，看新消息是否立刻进来；
2. 重启一次手机（开机后应用未启动的这段时间是收不到提醒的，重启后要先手动打开一次 Kwai）；
3. 确认没有在电脑端或其它设备同时登录，多端登录时移动端不提醒的情况是存在的；
4. 检查系统有没有开免打扰；
5. 以上都正常，但只有纯互动的提醒收不到，可以在应用内的意见反馈里说明机型与系统版本。

登录本身异常、内容加载不出来属于另一类问题，去 [常见问题与排查.md](常见问题与排查.md) 第一、二节。
