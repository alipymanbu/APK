# Excel在手机上不能做的功能

## 一、一句话结论

安卓上的 Excel 是功能裁剪过的版本，**不少在电脑上理所当然的功能，手机上根本没有入口** —— 这不是你没找到按钮，也不是订阅没生效。下面这些是查证过的清单，遇到缺功能先对着查，查不到再去排查别的。

## 二、数据透视表：能看不能建

微软社区的答复说得明确：**在 Android 设备上新建数据透视表属于设计如此（by design），不是故障**。实测口径是：

- 手机上**已经建好的透视表可以查看**；
- 但**不能新建**，也**不能改透视表的字段、布局**；
- 要动透视表，去电脑端或网页版改好，手机端拿来查看。

订阅了 Microsoft 365 也不会解锁这一条 —— 它和 [免费功能和订阅版的区别.md](免费功能和订阅版的区别.md) 里那张订阅表是两回事，订阅管的是编辑深度，这类属于平台裁剪。

## 三、官方功能表里标「不支持」的

微软官方有一张跨平台功能对照表（[What's New in Excel on Mobile Platforms](https://support.microsoft.com/en-US/Excel/what-s-new-in-excel-on-mobile-platforms)），安卓一栏里标为「不支持 / 即将推出」的包括：

| 功能 | Excel for Android（截至检索时，以官方页面为准） |
| --- | --- |
| 插入和编辑超链接 | 即将推出 |
| 插入和编辑 SmartArt | 即将推出 |
| 从相机插入图片 | 即将推出 |
| 漏斗图 | 即将推出 |
| 新函数（IFS、TEXTJOIN、CONCAT、SWITCH 等） | 标为即将推出（Windows Mobile 版已支持） |
| 画笔 / 墨迹标签页、墨迹转形状 | 标为不支持或即将推出 |

同一张表里，**条件格式只列了「查看」一行且标为支持**，编辑那一侧没给入口；而微软社区另有答复称安卓版找不到条件格式功能。两处口径不完全一致 —— 你手机上的实际表现以你装的版本为准，编辑入口翻不到时按「这项做不了」处理，别在菜单里反复找。

## 四、宏与 VBA：留着也跑不了

`.xlsm`（启用宏的工作簿）在手机上**能打开、能编辑单元格，但 VBA 函数不会运算**；依赖宏的计算会显示为未求值的结果。这不是文件坏了 —— 宏的执行环境移动端就不提供，得在电脑上跑完再把结果存成 `.xlsx` 带过来（格式对照见 [支持哪些文件格式.md](支持哪些文件格式.md)）。

## 五、缺功能时的三条出路

1. **换地方做**：透视表、条件格式、宏、复杂公式这些回电脑端处理；手机端只用来查数、改几个值、填个表。
2. **试网页版**：浏览器打开 [www.office.com](http://www.office.com)，网页版的功能集合与安卓应用不完全一样，有的功能网页版有。
3. **先确认不是账号问题**：菜单里整块功能灰着、点了弹订阅提示，那是订阅或屏幕尺寸的事，走 [免费功能和订阅版的区别.md](免费功能和订阅版的区别.md)；整个应用都异常，走 [打不开文件或闪退的排查方法.md](打不开文件或闪退的排查方法.md)。
