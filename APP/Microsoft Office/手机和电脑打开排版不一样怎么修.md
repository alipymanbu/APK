# 手机和电脑打开排版不一样怎么修

> 同一个文档，电脑上好好的、手机上换行错乱分页跑偏，八成是字体问题，按这篇处理。

## 一、你看到的现象是怎么来的

Word 类文档里只写了「这一段用的是某某字体」，**字体文件本身不打包进文档**。电脑上排版时用的字体手机上没有，打开时系统会拿一款字形接近的字体顶替；顶替字体的字宽与原字体不同，一段话累积下来就多折一行、少折一行，后面的换行与分页全部跟着偏移 —— 于是标题跑偏、结尾多出一页、落款位置对不上。

所以这不是文件损坏，也不是手机版渲染出了问题（文件损坏的判断走 [打不开文件或闪退的排查方法.md](打不开文件或闪退的排查方法.md)）。手机和电脑字体库不同，跨端打开 Office 文档就会有这层差异。

## 二、三十秒判断是不是字体问题

1. 同一个文件在电脑上打开，版式是正常的 → 问题在手机侧的字体，不在文件。
2. 看文档用了什么字体：电脑上装了、手机上大概率没有的（各类方正、汉仪、造字工房等第三方字库）最容易出事；用了系统通用字体的文档在手机上通常没事。
3. 换个文件对照：另一份文件手机上显示正常，更能说明是这份文档的字体在作怪。

## 三、按你的目的选处理办法

| 你的目的 | 做法 |
| --- | --- |
| 只是拿手机上看一眼 | 缩放着看，别改它。版式偏移不影响内容阅读 |
| 要发给别人、保证两边看到的一模一样 | 在电脑上导出 PDF 再发。PDF 把字体一起打包了，任何设备打开版式都不变（代价是对方不能直接编辑） |
| 必须在手机上接着改 | 打开文档后，把出问题的段落换成手机和电脑都装有的通用字体（「开始 → 字体」里选，安卓端需要先点右下角的箭头展开功能区，见官方说明 [在移动设备上的 Office 应用中更改字体](https://support.microsoft.com/zh-cn/office/fonts/change-the-font-in-office-apps-on-a-mobile-device)）。换完再检查换行和分页 |
| 还要回电脑继续改 | 手机上改完存回原位置，回电脑后把字体重新设回你原来要用的那款（[文件保存位置与跨设备同步.md](文件保存位置与跨设备同步.md) 讲两条存法的取舍） |

## 四、表格和图片轻微挪位怎么办

复杂表格、大图在小屏上常常有轻微错位，先用「打印」里的预览缩放检查一遍（[文档怎么打印出来.md](文档怎么打印出来.md)），确认关键位置（签字栏、盖章处、表格边线）没被压掉。要给对方看关键版式的场合，优先发 PDF，理由同上。

## 五、什么时候才轮到排查应用

版式差异只出现在**某几份文档**上 → 是字体，回到本篇第三节。**所有文档**在手机上都显示异常、连菜单都变形、或者干脆打不开 → 那是应用侧的问题，走 [打不开文件或闪退的排查方法.md](打不开文件或闪退的排查方法.md)。只是单纯的只读、格式不支持 → [支持哪些文件格式.md](支持哪些文件格式.md)。
