## 一、为什么「打开」不等于「能编辑」

安卓上的 Office 对老格式的态度是**能看不给改**：`.doc`、`.xls` 这些 2007 年前的二进制格式只读，`.docx`、`.xlsx` 这些新格式才能编辑。所以你收到同事发来的老文件显示只读，多半不是文件坏了，也不是你的操作问题，是这个版本的移动端就不支持编辑它 —— 想编辑就另存成新格式（见第四节）。

本篇只列微软给出对照表的 Word 与 Excel 两类；PowerPoint 的 `.pptx` / `.ppt` 支持情况以打开时的提示为准，没查到官方对照表就不在这里下结论。另外，格式之外还有一类「功能没有入口」的情况（透视表、条件格式这些），那是另一篇的事：[Excel在手机上不能做的功能.md](Excel在手机上不能做的功能.md)。

## 二、Word（安卓）文件格式对照

| 文件类型 | 打开和编辑 | 只读打开 |
| --- | --- | --- |
| Word 文档 `.docx` | 可以 | 可以 |
| 二进制文档 `.doc` | 不可以 | 可以（更新到 `.docx` 才能编辑） |
| Word 模板 `.dotx` | 可以 | 可以 |
| 二进制模板 `.dot` | 不可以 | 不可以 |
| 启用宏的文档 `.docm` | 不可以 | 不可以 |
| OpenDocument 文本 `.odt` | 不可以 | 可以（更新到 `.docx` 才能编辑） |
| 打开密码保护 | 可以 | 可以 |
| 修改密码保护 | 不可以 | 可以 |
| PDF `.pdf` | 不可以 | 可以（更新到 `.docx` 才能编辑） |
| RTF `.rtf` | 不可以 | 可以（更新到 `.docx` 才能编辑） |
| Word XML、Word 2003 XML 等 `.xml` | 不可以 | 不可以 |
| 网页 `.htm`、`.html`、`.mht`、`.mhtml` | 不可以 | 不可以 |
| 纯文本 `.txt` | 不可以 | 可以（更新到 `.docx` 才能编辑） |
| Works 6-9 文档 `.wps` | 不可以 | 不可以 |

出处：[为什么我无法打开 Office for Android 文件](https://support.microsoft.com/zh-cn/word/why-can-t-i-open-my-office-for-android-file)。

**宏**：`.doc`、`.docm` 里的宏会被保留下来，但你在安卓上**既不能编辑也不能执行**它们 —— 依赖宏的文档要在电脑上处理。

## 三、Excel（安卓）文件格式对照

| 文件类型 | 打开和编辑 | 只读打开 |
| --- | --- | --- |
| Excel 工作簿 `.xlsx` | 可以 | 可以 |
| Excel 工作簿 `.xls` | 不可以 | 可以 |
| 启用宏的工作簿 `.xlsm` | 可以，但 VBA 函数无法运行 | 可以 |
| 逗号分隔 `.csv` | 不可以 | 可以 |
| OpenDocument 表格 `.ods` | 不可以 | 可以 |
| Excel 模板 `.xlt` | 不可以 | 可以 |
| Excel 模板 `.xltx` | 不可以 | 不可以 |
| 启用宏的模板 `.xltm` | 不可以 | 不可以 |
| 增益集 `.xla`、`.xlam` | 不可以 | 不可以 |
| `.xml`、`.dif`、`.htm`、`.html`、`.mht`、`.prn`、`.slk`、`.txt` | 不可以 | 不可以 |

出处：[为什么不能打开我的 Excel 文件](https://support.microsoft.com/office/why-can-t-i-open-my-excel-file-2daa6bd6-8db5-4521-9f37-7e23b3e4bdab)，选该页的 Android 一栏。

## 四、只读文件怎么变成可编辑

1. 打开这个文件，用「另存为 / 保存副本」把它存成 `.docx` 或 `.xlsx`（PDF 则是「更新到 Word 文档格式」）。
2. 之后编辑、保存都用这个新文件，老格式那份当原稿留着即可。
3. 如果文件根本打不开、弹出「请尝试在另一台设备上的 Word 应用中打开」—— 文件本身没坏，是安卓版读不出里面的某些元素。按提示在 Word for Windows、Word 网页版或 Word for iOS 里打开它，让它修复并保存一份副本，副本再拿到手机上就能正常打开。

## 五、格式问题还是故障问题

按下面这条线分流，别把两件事混在一起：

- 文件**打得开但只读** → 是格式，回到本篇第二节、第三节查表。
- 文件**完全打不开、应用闪退** → 是运行问题，走 [打不开文件或闪退的排查方法.md](打不开文件或闪退的排查方法.md)。
- 文件打得开也编辑得了，却提示功能要订阅 → 是屏幕尺寸或账号，走 [免费功能和订阅版的区别.md](免费功能和订阅版的区别.md)。
- 文件能正常编辑，但换行、分页和电脑上对不上 → 是字体差异，走 [手机和电脑打开排版不一样怎么修.md](手机和电脑打开排版不一样怎么修.md)。

另外，存到哪里、换台设备怎么接着看，见 [文件保存位置与跨设备同步.md](文件保存位置与跨设备同步.md)；改完要打成纸质版，见 [文档怎么打印出来.md](文档怎么打印出来.md)。
