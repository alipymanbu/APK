# 文档怎么打印出来

## 一、先确认三件事

1. **手机和打印机在同一个 Wi-Fi**。无线打印靠局域网发现设备，手机走流量、打印机在别的网段，永远搜不到。
2. **手机有可用的打印服务**。多数安卓设备出厂就预装了 Mopria 驱动的默认打印服务（[Mopria 官方说明](https://mopria.org/zh-cn/print-from-android)），Mopria 联盟把 Chrome、Gmail、Microsoft Office、Adobe Reader 等列为已提供打印入口的应用。没预装的，按第三节装一个。
3. **文件能正常打开**。打不开的文件先走 [打不开文件或闪退的排查方法.md](打不开文件或闪退的排查方法.md)。

## 二、正常打印的步骤

1. 在应用里打开要打印的文档。
2. 点右上角的**更多（三点）菜单**，找「打印」；有的版本在「共享与导出」下一级。**入口名称随版本与机型变化，以你界面上显示的为准**，找打印关键字即可。
3. 进入打印预览后，左上角一般先停在「保存为 PDF」，点它切换到**所有打印机**列表。
4. 选中你的打印机 → 按需调份数、单双面、纸张尺寸、颜色 → 点打印。

## 三、列表里找不到打印机

按顺序过一遍：

1. 打开手机**设置 → 打印**，确认「默认打印服务」或 Mopria 打印服务处于开启状态；关着就打开，打开后再回应用重进打印菜单。
2. 确认打印机开机、没处于脱机或缺纸缺墨状态，且与手机在同一个 Wi-Fi（这条占了「搜不到」的绝大多数）。
3. 同一网络下仍搜不到 → 用 **Wi-Fi Direct** 让手机直连打印机（打印机面板上一般有 Wi-Fi Direct 按钮或热点信息），Mopria 官方把这条列为网络发现失败时的备选。
4. 老打印机不支持标准打印协议 → 装你打印机品牌对应的**打印服务插件**（各品牌都有，如 HP、Canon、Epson、Brother 系列），装完再试。

## 四、能搜到但打不出来

| 现象 | 先查什么 |
| --- | --- |
| 一直排队不出纸 | 打印机是否离线、卡纸、缺墨；手机和打印机是否被切到了不同 Wi-Fi |
| 只能打黑白、灰掉不能选彩色 | 打印参数能力受打印机本身限制，颜色/单双面选项要连上对应打印机后才会解锁 |
| 预览里版式错乱、字压字 | 是文档在手机上的显示问题，见 [手机和电脑打开排版不一样怎么修.md](手机和电脑打开排版不一样怎么修.md) |
| 点打印没反应 | 先清打印服务的缓存（设置 → 应用 → 打印服务 → 存储 → 清除缓存），再重启手机与打印机各一次 |
| 选项整个缺失 | 应用或系统版本太旧，先更新应用；仍没有就见第五节的替代路径 |

## 五、打不出来的替代路径

- **先出 PDF**：打印菜单里选「保存为 PDF」，拿到 PDF 后发到电脑上再打 —— 版式由 PDF 锁定，不受手机端字体差异影响。
- **文件发电脑**：手机只当查看端，文档传到电脑（[文件保存位置与跨设备同步.md](文件保存位置与跨设备同步.md) 讲了最省事的传法）再用电脑打印。
- **换浏览器打网页版**：浏览器登录 [www.office.com](http://www.office.com) 打开同一文件，浏览器的打印通道与应用是两套，有时应用打不出、浏览器能出。

如果连应用本身都打不开文件（更前置的问题），先看 [打不开文件或闪退的排查方法.md](打不开文件或闪退的排查方法.md)；只读打不动的格式则见 [支持哪些文件格式.md](支持哪些文件格式.md)。
