## 一、先分清是「文件打不开」还是「应用打不开」

这两件事的处理路径完全不同，先对号入座：

| 现象 | 去哪篇 |
| --- | --- |
| 应用能打开，某个文件打开后是只读、或提示格式不支持 | [支持哪些文件格式.md](支持哪些文件格式.md) |
| 文件弹「请尝试在另一台设备上打开」 | [支持哪些文件格式.md](支持哪些文件格式.md) 第四节 |
| 点图标闪退、黑屏、卡在启动画面、一直转圈 | 本篇第二节 |
| 登录页打不开、输入账号后卡住 | [登录账号和订阅不生效的解决办法.md](登录账号和订阅不生效的解决办法.md) |
| 打得开但功能被锁、要订阅 | [免费功能和订阅版的区别.md](免费功能和订阅版的区别.md) |

## 二、应用打不开/闪退的排查顺序

从最省事的开始，每做一步就试一次，能开就停：

1. **看安装包是否完整**。网盘里那份应为 123.31M，下少了会装出个坏应用（表现常是点开就退）。对不上就按 [下载与安装教程.md](下载与安装教程.md) 重下重装。
2. **确认设备达标**。系统要落在 Android 最后四个主要版本内、内存 1GB 以上；系统太旧的，先升级系统再谈别的（见 [下载与安装教程.md](下载与安装教程.md) 第二节）。
3. **给权限**。设置 → 应用 → 找到该应用 → 权限，把存储/文件与媒体、相机（要扫描或插入图片时）等它要的权限都允许。部分机型上权限没给全就表现为打不开或立刻退出。
4. **清缓存再试**。设置 → 应用 → 该应用 → 存储 → 先「清除缓存」；仍异常再「清除数据」（**清除数据会退出登录、丢掉本地未同步的改动**，先确认文件已经保存）。
5. **更新或重装**。应用商店里有更新就更新；不行就卸载后重装。卸载前确认文件已保存在本机或云端 —— 未同步的本地改动会随卸载消失。
6. **查重复安装**。用三星等带「安全文件夹」或工作资料的机型，老的 Office 应用可能藏在那个空间里和主空间的打架，把那里面的旧副本卸掉；微软社区答复里提到这类重复应用会让正常的应用打不开。
7. **系统时间、网络**。日期时间改为自动设置，网络换一个（Wi-Fi 与流量对调），有 VPN 或广告拦截的临时关掉。

## 三、卡在某个文件上打不开

- 先查 [支持哪些文件格式.md](支持哪些文件格式.md) 的对照表：只读格式就另存成 `.docx` / `.xlsx`；完全打不开的按那篇第四节，在电脑或网页版上修复后另存副本。
- 文件在云盘或网络位置上 → 先把它下载到本机再开，网络共享路径打不开很常见。
- 判断文件本身好坏的土办法：同一文件在电脑上能不能开。电脑也开不了就是文件的问题，与手机无关。

## 四、应急：先用网页版顶上

应用一时修不好，又急着看文件：手机浏览器打开 [www.office.com](http://www.office.com)，用同一个微软账号登录，文档照样能查看和编辑。网页版能用、应用不能用，就进一步确认问题出在应用侧，账号和文件都没事 —— 继续按第二节往下排即可。
