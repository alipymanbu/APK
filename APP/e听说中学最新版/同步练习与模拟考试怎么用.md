## 一、练习前的三件事

1. **联网**：手机版采用在线评分技术，练习时手机要保持联网，网络不稳会影响评分速度，甚至评不出分；
2. **下载资源包**：练习前应用会把对应的学习资源下载到本地，会占一定内存，首次进一个新单元会多等一会儿；
3. **戴耳机或离麦克风近一点**：收音质量直接影响口语得分，环境噪音和离麦太远都会拉低评测结果。

## 二、单元同步：平时跟着课上

| 模块 | 你实际在做什么 |
| --- | --- |
| 音标学习 | 闯关式练发音基础，适合起步阶段 |
| 同步词汇 | 按单元练课本单词，形式多样 |
| 课文朗读 / 跟读 | 逐句模仿课文，系统给朗读评分 |
| 听说 / 听力同步 | 与教材单元主题同步的听力口语训练 |
| 读写同步 | 跟着单元话题和语法练阅读写作 |
| 趣味配音 | 给英语原声视频配音，话题分级 |
| 单元测验 | 与单元主题同步的套题测试 |
| AI 对话（较新版本才有） | 跟着大模型就单元主题实时英语对话，以应用内实际菜单为准 |

## 三、阶段复习：考前集中刷

- **听说专项**：针对主流听说考试的不同题型分题型练，哪类题弱攻哪类；
- **智能作文**：把手写作文拍下来上传，系统输出拼写、语法、用词、篇章结构等维度的分析报告（需要相机和相册权限）；
- **听说模拟**：流程和界面与考试一致，用模拟试题完整走一遍人机对话考试，练的是考试习惯（题型怎么拆、分怎么算，另有一篇专门讲：[听说模拟考试题型与评分怎么看.md](听说模拟考试题型与评分怎么看.md)）；
- **读写模拟**：按考试题型做阶段性诊断；
- **听力模拟**（较新版本才有）：按考试题型练听力，提供近年听力真题试卷——你手里这版有没有，以应用内实际菜单为准。

## 四、寒暑假：分级阅读与寒暑作业

- **分级阅读**：按蓝思等级和常见考试话题分级的阅读课程，由浅入深；
- **寒暑作业**：按「巩固复习 + 新课预习」组织，穿插配音和课外读物；
- **时文阅读**（较新版本才有）：贴合时事热点的选题阅读素材，同样以应用内实际菜单为准。

## 五、练完去哪看结果

- **单次练习**：做完当场出分，口语题给逐词标注的发音反馈，作文题给多维度分析报告；
- **一段时间的学情**：应用会把你的学练测数据汇成评测报告与学情分析，定位薄弱点、记录学习轨迹——找不到入口时先翻「我的」或头像菜单里的「学情 / 报告」类入口，名称以应用内为准；
- **家长视角**：官方产品页介绍家长可实时查看孩子作业、动态掌握学情，具体入口以应用内与官方页面为准；
- **老师视角**：你在班级里做的练习，老师端能回听录音、看作答详情（见 [绑定老师与提交班级作业.md](绑定老师与提交班级作业.md)）。

## 六、评分是怎么回事

口语练习用的是科大讯飞智能语音评测技术——官方资料显示，这套技术已在全国中高考英语听说考试的正式评分环节大规模使用，所以练习评分的口径与正式考试一致，发音问题会逐词标注反馈。你要做的是按提示作答、录清楚音，评分维度和丢分点会在结果页直接给你。

练习记录在电脑端和手机端之间云端同步，换设备登录同一账号就能接着练。
