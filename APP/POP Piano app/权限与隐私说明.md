## 一、先看清楚主体是谁

两个官方文件抬头写的公司不一样，这不是你看错了：

- APP 商店页与《付费会员用户协议》里的开发者/协议方是**音乐梦想（北京）科技有限公司**；
- 《泡泡钢琴隐私政策》正文里自称的运营方是**音悦生活（北京）科技有限公司**。

两份都是官方页面，本篇照抄两边口径、不替你判断谁对。隐私政策全文在 `https://www.abcpiano.cn/privacy`，以页面最新版本为准。

## 二、它收集哪些信息

按隐私政策的表格，与你日常使用直接相关的几项：

| 场景 | 收集什么 | 为什么要 |
| --- | --- | --- |
| 手机号账号登录 | 手机号、登录密码 | 服务端验证身份 |
| 社交账号登录 | 由第三方 SDK 提供 | 同上，具体见政策里的第三方清单 |
| 钢琴连接与弹奏（基本功能） | 钢琴名称、钢琴编号、MIDI 数据、设备信息 | 适配你这台琴的通信协议 |
| 常见问题与反馈 | 你输入的文字、钢琴名称、设备信息 | 定位你遇到的问题 |
| 昵称头像设置 | 昵称、头像 | 排行榜展示 |
| 节奏学习 | 打鼓声音 | 判断你是否按节奏打 |
| 启动时 | 运营商国家代码 | 区分国家与地区 |
| 浏览曲目与弹奏 | 网络信息 | 提供联网服务 |

另有两项**由你主动上传**才发生：自定义弹奏背景/头像的图片、以及你自行上传的曲目文件。不碰这两项功能，就不产生对应上传。

## 三、权限：哪些不给就连不上

隐私政策把权限与后果写得很直白，关键区别是「拒绝即不可用」还是「拒绝只影响该功能」：

| 权限 | 用在哪 | 拒绝的后果 |
| --- | --- | --- |
| 蓝牙、USB、手机定位 | 连接钢琴（基本功能）；部分安卓手机要求开定位才能用蓝牙 MIDI | **无法使用基本服务**——琴连不上 |
| 相机、相册 | 换头像、自定义弹奏背景 | 该功能不可用，其余不受影响 |
| 麦克风 | 泡泡语音助手、节奏学习 | 对应功能不可用 |
| 读写外置存储 | 使用指南与课程视频、更换钢琴音色、上传曲目 | 对应功能不可用 |
| 加速度传感器 | 问题反馈页适配横竖屏 | 对应功能不可用 |

所以装完第一次打开，**蓝牙与定位这两个建议直接放行**——它们卡的是能不能连琴这条主路；其余权限可以按你用不用得上来逐个决定。权限怎么给，见 [下载与安装教程.md](下载与安装教程.md)；连琴本身的操作见 [蓝牙连接钢琴教程.md](蓝牙连接钢琴教程.md)。

## 四、未成年人这条线

隐私政策要求：**使用产品前确认你已是成年人；若你是未成年人，需要监护人同意**你使用本产品与相关服务条款。给孩子装之前，先自己过一遍政策与会员协议（会员协议同时声明该产品非教育培训、不提供考级承诺，见 [会员收费与订阅规则.md](会员收费与订阅规则.md)）。

## 五、想少留点数据，能做什么

- 登录方式在手机号与社交账号里二选一，换用其中一种就少一条第三方共享链路；
- 不用语音助手、节奏学习，就不必给麦克风；
- 不换自定义背景与头像，就不必给相机相册；
- 不上传曲目文件，就不产生该类上传。

蓝牙与定位没有替代方案——不给就练不了连接模式的琴，这一点在 [常见问题与排查.md](常见问题与排查.md) 的连接排查里是同一结论。
