## 一、这是个什么应用

泡泡钢琴（英文名 POP Piano，官方与社区里也常直接叫 POP Piano）是音乐梦想（北京）科技有限公司出的钢琴自学 APP，面向完全不懂五线谱的零基础用户：你跟着屏幕上的瀑布流提示和指法数字按键就行。它既可以配合 POP Piano 智能钢琴的灯条跟灯练习，也支持连接其他品牌的智能电钢琴、电子琴、手卷钢琴。

本篇只解决「装上」这件事；装好之后怎么连琴、怎么练，见 [蓝牙连接钢琴教程.md](蓝牙连接钢琴教程.md) 和 [曲目学习与闯关玩法.md](曲目学习与闯关玩法.md)。

## 三、系统要求

官方**首页**写的支持范围是 **安卓 6.0 及以上、iOS 9.0 及以上**，手机和平板都支持；但官方**下载页**顶部标注的又是 **iOS 12.0+ / Android 9.0+**。两处都是官方自己的页面，本篇并列照写、不替你选边——实际能否安装取决于你的设备系统版本，系统过旧装不上时，先对照这两条看是不是低了。第三方下载站标注的系统要求各不相同（有的写 Android 4.5+、4.0+），一律不作依据。

装不上时按 [常见问题与排查.md](常见问题与排查.md) 里的表格逐条对；装完要给哪些权限、为什么，见 [权限与隐私说明.md](权限与隐私说明.md)。

## 四、下载与安装步骤

1. 打开 [POP Piano app 安装文件资源（夸克网盘）](https://pan.quark.cn/s/de8dfe1f7550)，把分享内容转存到自己的夸克网盘（没登录的话先登录夸克账号）。
2. 在网盘里找到该应用的文件夹，点开 `.apk` 文件下载到手机；用手机浏览器直接打开网盘链接也可以走同样的转存流程。
3. 点击下载好的 APK 启动安装。安卓会弹「禁止安装来自此来源的应用」——这是系统的未知来源拦截，点提示进入**安装权限设置**，允许当前浏览器或文件管理器安装应用，再返回重新安装。
4. 安装完成后打开应用。首次启动会申请蓝牙、存储等权限，**蓝牙与定位建议直接允许**，否则 [蓝牙连接钢琴教程.md](蓝牙连接钢琴教程.md) 里的连接步骤走不下去；各权限分别管什么、拒了会怎样，见 [权限与隐私说明.md](权限与隐私说明.md)。
5. 用手机号或社交账号登录后即可进入主界面。

## 五、装不上或装完打不开

| 现象 | 先查这几项 |
| --- | --- |
| 提示「解析包时出现问题」 | 下载没完成或文件损坏，重新下载；比对第二节的 MD5 |
| 提示「应用未安装」 | 存储空间不足、与已有同包名版本签名冲突，先卸载旧版再装 |
| 提示「未知来源」拦住 | 按第四节第 3 步给当前安装来源开权限 |
| 装完一闪就退 | 系统版本低于安卓 6.0；或厂商后台限制了自启动 |
| 找不到安装入口 | 网盘 App 内点 APK 会直接调起安装；纯浏览器下载则去「下载管理」里点开文件 |

更多运行中的问题（连不上琴、没声音、判错等）集中在 [常见问题与排查.md](常见问题与排查.md)。
