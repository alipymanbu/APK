## 一、连接类

### 1. 乐器列表里什么都没有 / 没有 MIDI 设备

按顺序对：

1. 钢琴开机了吗（左上角开关单击，灯亮红）；
2. 手机系统蓝牙开了吗；
3. APP 的蓝牙权限给了吗，**安卓还要开系统定位**——部分手机不开定位就用不了蓝牙 MIDI；
4. 是不是跑去了系统蓝牙设置里找——连接必须在 **APP 的「学习」界面左上角钢琴设置图标**里发起，见 [蓝牙连接钢琴教程.md](蓝牙连接钢琴教程.md)。

### 2. 连上了但很快断开

先看钢琴是不是进入了省电关机：**开机 30 分钟无弹奏会自动关机**，这是设计行为。另外把手机离琴近一些、中间别隔金属物体；断开后按上一条重新连一次。官方帮助里没有更细的断连排查，若稳定复现，用界面里的问号入口反馈。

### 3. 提示「未找到琴」/ 蓝牙连上了但弹奏没反应

官方帮助没有覆盖这两种提示，**第三方资料的口径**（百科条目与软件下载页的连接教程，两处说法一致）是：

- 显示「未找到琴」且走的是有线连接：确认琴与手机的数据线插牢、重启手机与琴、安卓检查 **OTG 是否开启**；
- 蓝牙显示已连但按琴没反应：该琴的蓝牙协议可能不被支持，资料给的替代路径是**改用 MIDI 数据线连接**。

这些是第三方口径、不是官方承诺，先试官方的蓝牙流程（见 [蓝牙连接钢琴教程.md](蓝牙连接钢琴教程.md)），不行再拿这套去试有线。

### 4. 想用有线方式连接

官方使用帮助只给出了蓝牙连接流程。你的琴若是其他品牌，有线连接方式（MIDI 线、是否需要 OTG 转接、部分安卓手机要手动开 OTG）以**那台琴自己的说明书**为准；第三方资料的通用说法见上一条。

## 二、发声与练习类

### 1. 连上了却没声音

- 没接耳机音箱、也没连 APP 时，琴本身不响是正常的，红灯状态就该这样；
- **接入耳机或音箱时 APP 会自动禁音**，声音从外接设备出——别再回头找手机音量；
- 检查钢琴上的音量 +/- 按钮，可能被调到最低；
- 练习过程需要设备网络正常，断网时曲目加载不出来，也会表现成「没声」。

### 2. 弹对了系统却不给过 / 判错

先自查两项：是不是跟着灯条与瀑布流的红蓝提示按的、网络是否稳定。自己确认按键无误仍判错的，点**曲目详情或学习界面的问号**直接反馈给官方——官方说明会修正曲目与指法错误，这类问题的根源常在曲谱数据本身。

**有用户反馈**（应用宝评论区）过两类现象，供你对照：一是蓝牙连上了、键也弹完了，但软件不给过；二是分数较高时的**回放听起来比实际弹得更流畅**（节奏、速度像是被优化过），该用户认为回放与真实弹奏不完全一致。这两条都是单一用户口径、未经官方证实，遇到同类现象可一并反馈。

### 3. 曲目或指法明显标错了

同上，用问号入口反馈，官方说明会尽快修正。玩法层面的说明见 [曲目学习与闯关玩法.md](曲目学习与闯关玩法.md)。

## 三、安装与账号类

| 现象 | 处理 |
| --- | --- |
| 装不上 / 提示未知来源 / 解析包失败 | 按 [下载与安装教程.md](下载与安装教程.md) 第五节逐条排查 |
| 系统版本够不够 | 官方首页写安卓 6.0+ / iOS 9.0+，官方下载页写 Android 9.0+ / iOS 12.0+，两处并列、以能装上为准 |
| 权限被拒导致功能不可用 | 蓝牙与定位被拒就连不了琴，其余权限按功能对应，见 [权限与隐私说明.md](权限与隐私说明.md) |
| 忘记用哪个账号登录 | 支持手机号账号与社交账号两种登录方式，先试常用手机号；会员在购买账号下，见 [会员收费与订阅规则.md](会员收费与订阅规则.md) |
| 换新手机后数据 | 用原账号登录；账号数据资产可跨端互通，具体以登录后实际显示为准 |
| 会员买了想退 | 协议口径为购买即时生效、不退费，详见 [会员收费与订阅规则.md](会员收费与订阅规则.md) |
