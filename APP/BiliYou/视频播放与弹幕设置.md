## 一、播放相关设置都在哪

从首页点右上角头像 → **设置** → **通用** → 最下面的**视频**一段，这里集中了播放行为与画质偏好。下面按「改了有什么效果」列一遍：

| 设置项 | 默认值 | 作用 |
| --- | --- | --- |
| 启用硬解 | 开 | 关掉之后改用软解。如果某个视频出现花屏、绿屏、声音画面不同步，可以关掉它试试 |
| 后台播放 | 开 | 切到后台后继续播；只想听声音（比如听长视频、听直播）时很有用 |
| 详情页直接播放 | 开 | 进详情页就自动开始播，不用再点一次 |
| 直接全屏 | 关 | 视频加载完成后直接进全屏，适合只想看画面的场景 |
| 偏好画质 | 8K 超高清 | 播放时优先选这一档，取不到就自动降到可用的最高档 |
| 偏好视频编码 | hev(h265) | 可在 `hev(h265)`、`avc(h264)`、`av1` 之间选 |
| 偏好音质 | Hi-Res 无损 | 播放时优先选这一档，取不到就自动降档 |
| 默认播放速度 | 1.0X | 可在 0.25X 到 4X 之间按档调节 |

## 二、画质、音质、编码怎么选

**画质**从低到高一共十二档可选：240P 极速、360P 流畅、480P 清晰、720P 高清、720P 高帧率、1080P 高清、1080P+ 高码率、1080P60 高帧率、4K 超清、HDR 真彩色、杜比视界、8K 超高清。

需要说明的是，偏好画质只是「优先选」——**某一档能不能真的用上，取决于当前这个视频本身有没有那一档，以及你的账号权限够不够**。碰到没有的档位，播放器会自动落到可用的最高档。所以把偏好设成 8K 并不会让所有视频都变 8K。

**编码**的选择看设备而不是看画质：

- `hev(h265)` 默认选项，同画质下体积更小，中高端机型基本都支持；
- `avc(h264)` 兼容性最好，老设备上出现解码异常时改这个；
- `av1` 体积最小，但对芯片解码能力要求最高，较老的机器容易卡顿。

**音质**可选 64K、132K、192K、杜比全景声、Hi-Res 无损。后两档同样受视频源和账号权限限制，普通视频通常只有前三档。

## 三、播放页上的手势

BiliYou 播放器的手势比较固定，记住下面这一组就够用：

| 手势 | 作用 |
| --- | --- |
| 单击画面 | 显示 / 隐藏控制面板 |
| 双击画面 | 暂停 / 继续播放 |
| 长按画面 | 临时切到二倍速播放（会弹一条「正在二倍速播放」的提示，松手恢复原速） |
| 在画面上横向拖动 | 快进 / 后退，拖动距离决定跳转幅度 |
| 在画面**右半边**纵向拖动 | 调音量 |
| 在画面**左半边**纵向拖动 | 调亮度 |

另外几条和画面有关的：

- **横屏时自动旋转屏幕**（1.1.4 起），不用手动转；
- 支持**双指缩放与旋转**画面（1.0.7 起加入视频旋转缩放）；
- 全屏播放时退出页面，**屏幕亮度会恢复成系统原值**（1.1.2 起），不会把播放器里调的亮度带到桌面；
- 进度条拖动不顺的问题在 1.1.3 里修过，现在拖动是正常的。

详情页下方是简介、评论区和**相关视频**。评论支持楼中楼、图片评论和评论点赞；视频本身可以点赞、投币和分享（点赞在 1.0.6 加入，投币与分享在 1.0.7 加入）。

**画中画**：应用声明支持画中画，从系统侧把 BiliYou 切进画中画模式后，可以一边看视频一边操作别的应用。是否生效取决于你的系统设置里给 BiliYou 开没开画中画权限。

## 四、弹幕怎么调

弹幕的设置分两层：一层是「新视频进来时用什么参数」，一层是「当前这个视频里临时改」。

**通用设置 → 弹幕** 里的六项决定默认行为：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 默认打开弹幕 | 开 | 进视频时弹幕是开着的 |
| 记住弹幕开关状态 | 关 | 开启后，切换下一个视频时沿用上一个视频的弹幕开/关状态 |
| 记住弹幕设置 | 开 | 切换视频后沿用字体大小、不透明度、滚动速度 |
| 默认字体大小 | 1.00X | 可在 0.25X 到 4X 之间调 |
| 默认不透明度 | 60% | 可在 1% 到 100% 之间调 |
| 默认滚动速度 | 1.0X | 可在 0.25X 到 4X 之间调 |

实际看片时觉得弹幕太挡画面，最直接的两个改法：把**默认不透明度**降到 30% 上下，或者缩小**默认字体大小**。这两项都按滑动条调，没有固定档位，调完对之后打开的视频生效。

如果弹幕干脆不显示，先确认播放器面板里弹幕开关是开着的，再看[常见问题与排查.md](常见问题与排查.md)的「弹幕不见了」。

## 五、1.1.5 上已知的播放问题

官方在 1.1.5 的更新说明里自己写明：**播放器界面还有一些问题待修复**。这不是你设备的问题，项目在 2024 年 4 月归档后就没人再修了。遇到播放界面上的小毛病，能绕就绕 —— 比如换个编码、关掉硬解、重新进一次详情页；排查思路见[常见问题与排查.md](常见问题与排查.md)。

另外要分清一种情况：如果**不是界面小毛病，而是所有视频都放不出来**，那多半属于站方接口那一侧的变化，改本地的编码、画质都没用，判断方法见[常见问题与排查.md](常见问题与排查.md)的「某天开始突然整批页面失效」一节。
