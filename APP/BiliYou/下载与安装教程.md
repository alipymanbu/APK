## 一、先认清这份包

网上的下载页常把同一个包标成不同版本号，所以下面这张表才是你该对的依据 —— 它是网盘里这份文件的信息：

| 项目 | 值 |
| --- | --- |
| 应用名 | BiliYou |
| 版本号 | 1.1.5 |
| 包名 | `com.lucinhu.bili_you` |
| 安装包体积 | 14.01 MB |
| MD5 | `59556062F41482F22F8C0501581B3C6D` |
| 适用平台 | 安卓手机 / 安卓平板 |

有两件事要先知道：

- **1.1.5 就是这个项目的最后一版。** 作者在 2024 年 4 月 14 日把 GitHub 仓库归档成了只读状态，之后再没有提交。所以别处若写着 1.1.6、1.2.0 甚至更高的版本号，那不是这个项目发出来的东西，判断是不是同一个应用只看包名 `com.lucinhu.bili_you`。
- **同名应用不止一个。** 「BiliYou」「Bili You」「biliyou」在下载站里混在一起，其中一部分是改了名字的壳子，包名完全不同。装之前进「设置 → 应用 → BiliYou → 应用信息」看一眼包名，对得上才是本文说的这个；完整的识别办法（包名、体积、关于页三样对照）见[同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 二、装之前核对两件事

**第一，确认你手上是安卓设备。** BiliYou 的官方发布页给出的是安卓安装包（按 CPU 架构分成了几个文件），iPhone 和 iPad 上装不了。电脑上想用只能借助安卓模拟器：装好模拟器后，把手上这个 APK 直接拖进模拟器窗口（或右键选「安装 APK」）即可，快捷键、窗口尺寸这类差异不影响应用本身。模拟器是另一台「安卓设备」，如果只是试用，用副账号登录更稳妥。

**第二，别被「最低系统版本」绕进去。** 这个项目在工程里设定的最低系统版本是 Android 5.0（API 21），1.1.4 那一版还专门修过 Android 5 到 6 上的闪退。按这个口径，**Android 5.0 及以上的机器都在支持范围内** —— 5.1、6、7 一直到 14 都可以装，不需要额外找什么「低版本专用包」；真正要当心的是 Android 4.4 及更早的机器，那一档装上打不开的概率较高，没必要反复折腾。

如果你看到有下载页写「需要 5.2 以上」，那个数字并不存在对应的安卓版本号，不用当回事。最终判断标准还是这一条：装上能正常打开就说明你的设备可以用。

## 三、安装步骤

1. **先转存再下载**：打开 [BiliYou 安装文件资源（夸克网盘）](https://pan.quark.cn/s/eb718ecebfc8)，把 APK 转存到自己的网盘里，再从网盘下载到手机。转存这一步别省，分享链接失效后文件还在你自己的网盘里。
2. **给安装来源放行**：手机「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，找到你用来打开安装包的那个应用（文件管理器、浏览器或网盘客户端），把开关打开，然后再点 APK。
3. **签名冲突先卸载旧版**：手机里如果已经装着同包名、但签名不同的 BiliYou（多见于从别的下载站装的），覆盖安装会失败并提示「应用未安装」。先把旧的卸掉再装这份。
4. **不想丢数据就别乱降级**：同包名的应用系统只认一个，装这份会覆盖你现有的 BiliYou。如果旧版本用着顺手，装之前先想清楚要不要换。

装不上时的现象与对应处理，集中列在[常见问题与排查.md](常见问题与排查.md)的「装不上」一节。

## 四、第一次打开会看到什么

启动后进入的是首页，底部只有两个入口：**首页**和**动态**；屏幕较宽的设备（比如平板横屏）会改成左侧竖排导航栏。首页顶部是搜索框和头像，下面四个标签依次是**直播、推荐、热门、番剧**，默认停在「推荐」。

这时候你还没登录，能正常翻推荐、热门、搜索和播放；但历史记录、动态、评论这类和账号绑定的内容需要登录之后才有内容。登录方式与差别见[登录与账号同步.md](登录与账号同步.md)。

## 五、装完做一次最小验证

挑一个热门视频，走一遍「搜索 → 点进详情页 → 播放」，能出画面、能拖进度就说明安装没问题。

如果卡在这一步，按现象分开处理：

- 能搜到、点进去一直转圈或报错 → 见[常见问题与排查.md](常见问题与排查.md)的「能打开，但视频放不出来」；
- 一打开就闪退、或者界面文字大得离谱 → 见[常见问题与排查.md](常见问题与排查.md)的「打开就闪退」，字体问题另见[主题外观与字体缩放.md](主题外观与字体缩放.md)；
- 装不上、提示「解析包出错」→ 见[常见问题与排查.md](常见问题与排查.md)的「装不上」。
