## 一、登录入口在哪

打开应用后，**首页右上角那张头像是登录入口**。点它会弹出一个菜单，里面有**登录、关注、历史记录、设置、关于、退出登录**几项。没登录时头部显示的是默认灰头像，菜单里的「关注」和「历史记录」点了会提示「用户未登录」；登录之后这里会显示你的头像、昵称和会员等级（LV 几），并带上经验进度条。

头像是默认的灰头像时，就说明当前没有登录态。

## 二、用哪种方式登录

BiliYou 里能走到四条登录路径，但它们的维护状态差别很大，选之前先看清楚：

| 登录方式 | 怎么进 | 现在的状态 |
| --- | --- | --- |
| **网页登录** | 头像菜单 → 登录 | 默认走的就是它，官方长期维护 |
| **扫码登录** | 网页登录页右上角「二维码登录」按钮 | 1.1.3 加入，可用 |
| 密码登录 | 需先进隐藏的测试页 | 自 1.0.8 起官方已不再维护 |
| 短信登录 | 需先进隐藏的测试页 | 自 1.0.8 起官方已不再维护 |

**两条推荐路径，按你的习惯选：** 想最省事就用**扫码登录**（点了「登录」之后，在打开的页面右上角切过去），全程不用手输密码；习惯在页面里操作就用**网页登录**（默认打开的那个页面），里面就是 B 站自己的 H5 登录页，你在那里填手机号、验证码或账号密码，流程和网页版一致。官方更新日志里写过，网页登录这条路「现在登录没有任何问题了」，1.1.3 还专门修过平板因 UA 不同而进不了登录页的问题。无论走哪条，登录成功后页面都会自动跳回首页，并弹一条「网页登录成功」。

**扫码登录**的具体操作：用手机上的 B 站 App 扫一下页面上的二维码即可。扫完之后如果界面没自动跳转，点页面右上角的「手动检查登录状态」就能确认结果。

密码登录和短信登录这两页虽然还留在代码里，但官方在 1.0.8 的更新说明里写明**已不再维护**，入口也挪到了长按搜索框才会出现的测试页里。它们能不能用取决于 B 站的接口有没有变，不建议把它当成常规登录方式。

## 三、登录前后差在哪

先用一张表把差别说清楚，再决定要不要登录：

| 内容 | 未登录 | 已登录 |
| --- | --- | --- |
| 首页推荐、热门、搜索、播放 | 可用 | 可用 |
| 番剧搜索与播放 | 可用 | 可用 |
| 观看历史记录 | 无 | 有 |
| 动态（关注的 UP 主更新） | 无 | 有 |
| 关注列表 | 无 | 有 |
| 评论、点赞、投币 | 不可用 | 可用 |

简单说：只想「随便刷刷视频」，不登录完全够用；想把使用痕迹留下来、要看自己关注的人，就必须登录。

## 四、退出登录与数据归属

退出入口在头像菜单里：点头像 → 「退出登录」→ 确认。

有三点需要提前知道：

- **退出登录不会删掉你在这个应用里的界面设置**（主题、字体缩放、弹幕参数这些和账号无关），但历史记录、动态这类内容会立刻看不到。
- **登录状态存在应用自己的本地数据里**，清除应用数据或卸载重装之后需要重新登录。BiliYou 没有做云端同步，也就没有「换手机自动带过去」这回事。
- **登录凭证就是你的 B 站账号身份。** 第三方客户端登录时用的仍是你自己的账号，所以别在别人的设备上登录；公共设备上用完之后，记得退出并清除应用数据。

## 五、账号安全：登录方式怎么选、遇到风控怎么办

**登录方式就选扫码登录或网页登录这两种，扫码更省事、网页更直观，没有第三种推荐。** 扫码登录全程不用手输密码；网页登录是在内嵌的站方页面里操作，密码也只交给站方页面。密码登录和短信登录那两页官方已不维护，本身也不该再往里填密码。

**登录凭证是存在应用本地的。** 所以第一条原则是别在不属于你的设备上登录；公共设备上用完之后，除了退出登录，最好再清除一次应用数据（见上一节）。第二条原则是只装能认出原版的包 —— 一个被重新打包过的客户端同样能拿到你的登录状态，识别方法见[同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

**关于风控。** 站方对接口访问设了风控：同一接口被同一用户、同一 IP 或同一客户端在短时间内反复请求，或者请求特征异常，就会触发校验。触发后接口会返回「风控校验失败」这类错误码，需要完成一次人机验证才能恢复；如果拦截发生在 IP 层面，返回的会是「请求被拦截」，这一档通常要等一段时间才自己解除。

用到风控时，正确的做法只有三条：

1. **先停下来**，别连续重试。短时间内反复请求正是触发条件之一，一直点只会让状态持续更久；
2. **换一次网络**（移动数据与 Wi-Fi 互换），再隔一会儿重试；
3. **出现验证提示就按提示完成验证**，验证通过后原操作能正常继续。

也有用户反馈过一种情况：登录之后视频打不开，退出登录反而能正常播放。这类现象多与账号侧状态或风控有关，先退出登录验证一下能不能复现，再决定要不要重新登录，比在设置里反复改参数有效。

## 六、登录不上去时的顺序

按下面顺序试，基本能定位到是环境问题还是账号问题：

1. **先换网络**：流量与 Wi-Fi 互换一次，再重进登录页。第三方客户端登录失败里，网络与接口状态占很大比例。
2. **网页登录页打不开或一直是空白页** → 见[常见问题与排查.md](常见问题与排查.md)的「登录相关」一节。
3. **提示需要人机验证或短信验证** → 这是 B 站账号侧的风控，按页面提示完成验证再回来重试，不需要在 BiliYou 里做额外设置。
4. **扫码一直显示未扫码** → 确认手机上的 B 站 App 已经登录、并且扫的是 BiliYou 展示的那张二维码；扫完停几秒，再点右上角「手动检查登录状态」。
5. **所有方式都失败** → 检查手机时间是否准确（系统时间偏差会导致请求校验失败），再重启一次应用。
