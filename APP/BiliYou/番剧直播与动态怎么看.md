# 番剧直播与动态怎么看

> 首页推荐之外，BiliYou 还有三条线：番剧、直播和动态。这三块的状态并不一样，本篇把「哪条线能用、入口在哪、哪里还是半成品」说清楚。

## 一、番剧：入口在搜索里，不在首页标签

先说最容易踩的坑：**首页那个「番剧」标签目前点进去只显示「该功能暂无」**。它是留的位置，不是坏了，也不是你少装了什么。找番要走搜索这条路：

1. 点首页顶部的搜索框，进搜索页；
2. 输入番剧名或关键词；
3. 结果页切到番剧类标签，点开想看的那一部；
4. 进入番剧详情页后选集播放，播放操作和普通视频一致。

播放画面、清晰度、弹幕这些沿用同一套设置，怎么调见[视频播放与弹幕设置.md](视频播放与弹幕设置.md)。

**能看哪一集、能看哪一档清晰度，取决于你的账号状态和这部剧集在站内的权限设定**。看不成的剧集，页面会给出相应提示，这类限制来自内容方，任何客户端都改不了。

## 二、直播：能看，但官方标注「未完善」

直播入口是首页第一个标签，里面是直播房间卡片列表。点卡片进入直播间即可观看。

官方在 1.1.4 的更新说明里把直播标为「未完善」，这是目前最准确的状态描述。实际使用上的含义是：

- 直播的基本观看能用；
- 播放器上那些为点播设计的功能（进度条、倍速、选集等）在直播场景下不一定有意义；
- 遇到画面卡住或一直载入，优先换网络，其次退出直播间重进，不要指望在设置里找到「直播专属」的开关。

直播相关的卡片排列会跟着**推荐列数**一起变，改列数的方法见[首页推荐与视频搜索.md](首页推荐与视频搜索.md)。

## 三、动态：入口在底部第二个标签

底部导航的第二项就是**动态**。它和首页是并列关系，不是子页面。

登录之后，这里能看到你关注的 UP 主的更新，并且支持三种形态的内容：**图片动态、转发动态、文章动态**（1.1.0 加入）；每条动态可以点进评论区、点开其中的视频直接播放，列表拉深了也能一键回到顶部（1.0.8 加入）。1.1.4 还加了一个「最常访问」的 UP 主面板，方便直接跳到常看的几个人主页。

未登录时这里没有内容可看 —— 动态依赖你的关注关系，必须先登录，登录方式见[登录与账号同步.md](登录与账号同步.md)。

和直播一样，动态同样是**官方标注「未完善」**的模块：能看能点，但结构相对简单，不要指望它把官方客户端的动态功能都补齐。

## 四、观看历史与关注列表

这两项都在**头像菜单**里，也都需要登录：

| 功能 | 入口 | 里面有什么 |
| --- | --- | --- |
| 历史记录 | 头像 → 历史记录 | 你在 BiliYou 里看过的视频记录，用来接着上次继续看 |
| 关注列表 | 头像 → 关注 | 你关注的 UP 主列表，1.1.5 加入 |

两点提醒：

- **历史记录是 1.1.5 修过的问题项**。官方在这一版的更新说明里专门写了「修复历史记录失效的问题」，所以如果你从更早的版本升上来发现历史能用了，是这一版的改动；反过来，早期版本历史不显示并不代表账号有问题。
- **未登录点这两项会直接提示「用户未登录」**，不会进页面，这是设计如此，不是报错。

## 五、看某个 UP 主的所有投稿

从搜索结果切到用户分类进 UP 主主页，或者从动态里点作者头像，都能进个人主页。主页里能看到他的投稿列表，点任意一条就能进详情页播放，并继续通过「相关视频」串着往下看。

关注列表能让你看到自己关注了哪些 UP 主；如果你要批量调整关注关系，用官方客户端或网页版会更顺手。
