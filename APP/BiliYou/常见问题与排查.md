# 常见问题与排查

> 汇总 BiliYou 上最容易遇到的一批问题：装不上、闪退、登不上、放不出来、弹幕不见了。每条都按「现象 → 原因 → 怎么做」写，能自己动手解决的就不必再折腾。

## 一、先说清一件事：这个项目已经停了

不管后面遇到什么问题，这个背景都得先知道：**作者在 2024 年 4 月 14 日把项目仓库归档成只读，1.1.5 是最后一版，之后不会再有任何修复。**

这带来两个后果：

- 报错、界面上的小毛病，等不到新版本修；
- 有些问题**不属于客户端 bug**，而是站方接口变了导致的，任何版本都修不了。

所以下面的排查思路都是「怎么绕过、怎么换条路走」，而不是「等更新」。

## 二、装不上

| 现象 | 多半是什么原因 | 怎么做 |
| --- | --- | --- |
| 提示「解析包出错」 | 安装包下载不完整，或传输中被改坏 | 删掉这个文件重新下一遍，回到 [BiliYou 安装文件资源（夸克网盘）](https://pan.quark.cn/s/eb718ecebfc8)重新转存下载 |
| 提示「应用未安装」 | 手机上已有同包名但签名不同的 BiliYou | 先把旧的那个卸掉，再装这一份 |
| 点安装没反应、卡在安装页 | 没给当前这个来源「安装未知应用」权限 | 手机「设置 → 应用 → 特殊应用权限 → 安装未知应用」里找到你用来打开 APK 的那个应用，把开关打开 |
| 装完出现两个图标 | 装的是包名不同的两个应用 | 认准包名 `com.lucinhu.bili_you`，另一个卸掉 |
| 想装到电脑上 | 官方发布页给的是安卓安装包 | 装一个安卓模拟器，把 APK 拖进去安装，步骤同手机 |

更完整的安装步骤和版本信息在[下载与安装教程.md](下载与安装教程.md)；名字相同但包不同的那些包怎么识别，见[同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 三、打开就闪退

- **老系统设备**：Android 5 到 6 上的闪退在 1.1.4 修过一批，如果你装的版本比 1.1.4 还旧，先换成 1.1.5 再看。Android 5 以下的设备装上打不开属于可预期情况，不建议继续折腾。
- **改过系统或装过框架的设备**：这类环境下的闪退未必和 BiliYou 有关，先用其他应用对比一下。
- **重启后再试一次**：清掉后台、重启手机，再打开应用；如果只是偶发，通常这样就好了。
- **界面文字大到按钮点不到**：不是闪退，是字体缩放被调到了 2 倍，去[主题外观与字体缩放.md](主题外观与字体缩放.md)把它调回来。

## 四、登录相关

| 现象 | 怎么做 |
| --- | --- |
| 点「登录」后网页一直空白或加载不完 | 换个网络重进；网页登录页依赖站方页面，网络不通时它就是白屏 |
| 登录页能打开，登完没反应 | 点页面右上角的「手动检查登录状态」，让它重新判定一次 |
| 扫码后一直显示未扫码 | 确认手机上的 B 站 App 自己已登录，扫完停几秒再去检查状态 |
| 提示需要人机验证 / 短信验证 | 这是账号侧的风控，按页面提示完成验证再回来 |
| 所有方式都失败 | 检查手机系统时间是否准确（时间偏差会导致请求校验失败），再重启应用 |

**注意**：密码登录和短信登录这两页从 1.0.8 起官方就不维护了，别把它们当成备选方案反复试，直接用网页登录或扫码登录。详见[登录与账号同步.md](登录与账号同步.md)。

## 五、能打开，但视频放不出来

按这个顺序排查，多数情况第一二步就能解决：

1. **先换一个视频试**。别的视频能放、只有这一个不行，那是这个视频或它的来源有问题，不是客户端的问题。
2. **换网络**：Wi-Fi 与流量互换一次，再重进详情页。
3. **换编码**：设置 → 通用 → 视频 → 偏好视频编码，从 `hev(h265)` 换成 `avc(h264)`，再重进视频。
4. **关掉硬解**：设置 → 通用 → 视频 → 启用硬解，关掉后改用软解，重进视频。花屏、绿屏、声音画面不同步基本都靠这一步解决。
5. **降低画质偏好**：设置 → 通用 → 视频 → 偏好画质，选一个中档的（比如 720P 高清）。偏好画质只是「优先选」，但设备解码能力不足时高码率档位最容易出问题。
6. **清一次缓存**：设置 → 其他 → 缓存管理，长按体积最大的那项删掉。

补充两点：

- **应用里没有「缓存视频离线看」这个功能**，缓存管理页管的是图片等临时数据。看视频必须联网，这一点别抱期待。
- **1.1.5 官方自己在更新说明里写明「播放器界面还有一些问题待修复」**。播放页上的界面瑕疵属于这一类，绕过去用即可。

播放相关设置的完整说明见[视频播放与弹幕设置.md](视频播放与弹幕设置.md)。

## 六、弹幕不见了

按顺序确认：

1. 播放器面板里的弹幕开关是不是被关掉了（某个视频关掉后，如果开了「记住弹幕开关状态」，下一个视频会继续关着）；
2. 设置 → 通用 → 弹幕，看**默认不透明度**是不是被拉到了 1% 附近 —— 拉得太低，弹幕技术上「在显示」但肉眼看不见；
3. 弹幕字体大小如果被调到 0.25 倍，也会小到几乎看不到；
4. 换一个视频试。热门视频弹幕量大，加载会慢一点，别只看开头两秒就下结论。

参数怎么调见[视频播放与弹幕设置.md](视频播放与弹幕设置.md)。

## 七、首页或列表空着、刷不出来

- 先换网络，再下拉刷新一次；
- 下拉刷新是有效的 —— 再点一次当前所在的导航项（首页 / 动态）也会回到列表顶部并重新加载；
- 如果整个应用所有页面都空，去设置 → 其他 → 缓存管理清一次缓存再重启应用；
- 仍不行，就是站方接口那侧的问题，这种情况下客户端没有可改的地方。

## 八、检查更新没有新版本

这是正常结果，不是更新功能坏了。1.1.5 已是最后一版，项目的发布页不会再出新版本。既然不会再有更新，可以把「设置 → 通用 → 自动检查更新」关掉，省掉每次启动时那次联网比对。

## 九、后台播放容易被系统杀掉

设置里的「后台播放」是开着的，但切出去之后声音还是停，通常不是 BiliYou 的问题，而是系统的省电策略：

- 把 BiliYou 加入电池优化的**白名单 / 不受限制**列表；
- 关掉该应用的「省电模式」「智能省电」这类开关；
- 在最近任务里给 BiliYou **加锁**（下拉卡片上的小锁图标），避免一键清理时被清掉。

## 十、画中画不生效

BiliYou 声明支持画中画，但要不要生效由系统决定：进手机「设置 → 应用 → BiliYou → 画中画（或特殊应用权限里的画中画）」，确认开关是打开的；部分系统还需要在「多任务」里手动把应用切进画中画模式。

## 十一、还有哪些功能是「半成品」，别再找设置

项目已归档，以下这些不会再有改进，遇到时直接换条路走，不要怀疑自己没找对设置：

| 模块 | 状态 | 建议 |
| --- | --- | --- |
| 首页「番剧」标签 | 显示「该功能暂无」 | 从搜索页的番剧分类找番，见[番剧直播与动态怎么看.md](番剧直播与动态怎么看.md) |
| 直播 | 官方标注「未完善」 | 能看基本观看，卡住就换网络或重进 |
| 动态 | 官方标注「未完善」 | 能看能点，部分动态类型可能不可用 |
| 密码 / 短信登录 | 1.0.8 起不再维护 | 改用网页登录或扫码登录 |
| 离线缓存视频 | 没有这个功能 | 只能在线看 |

## 十二、某天开始突然整批页面失效：站方的接口签名

有一种失效方式和前面几条都不一样，值得单独说：**应用一直用得好好的，某天起搜索、播放、评论等一批页面同时开始报错或返回空白，但换个账号、换个视频、换张卡都一样。**

这通常不是你的设备或网络出了问题，而是站方给网页接口加了新的签名校验。站方从 2023 年 3 月开始给这类接口加上了一层签名参数，而且签名用的密钥大约每天换一次；客户端必须跟着实现这套签名，请求才会被正常受理。第三方客户端的这种做法只有一条路能跟上 —— **发新版本**。BiliYou 的更新记录里就有过「修复 wbi 鉴权问题」这一条，说的正是这类修补。

问题在于：**项目 2024 年 4 月已经归档，站方之后再改，就没人能修了。**

所以判断和处理的顺序是：

1. 先按第五节排除本地原因（换视频、换网络、换编码、关硬解、清缓存）。如果只有一个视频不行，那和本条无关；
2. 如果**整批页面同时失效、且各种视频都一样**，基本可以判定是这一类，客户端设置里没有能改的地方；
3. 这种时候继续做的只有一件事：换用网页版或官方客户端。反复重装 BiliYou、清数据、换版本号，都改变不了结果。

另外提醒一句：遇到这种情况**不要去找别人重新打包过的版本**。这类包无法核对来源，又要拿你的账号登录，风险比失效本身大得多；识别原版的方法见[同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 十三、提示「风控校验失败」或「请求被拦截」

这两条是站方风控给出的判断，不是安装包损坏，也不是登录失败：

- **风控校验失败**：请求特征不符合要求（短时间内同接口请求过多、签名校验没过、缺少设备标识等），按提示完成一次人机验证即可恢复；
- **请求被拦截**：拦截发生在 IP 层面，通常要等一段时间自行解除。

处理原则是**先停手**：别连续重试、别反复退出再登录，换个网络隔一会儿再试。完整说明见[登录与账号同步.md](登录与账号同步.md)的「账号安全」一节。
