# LeviLauncher 同名应用与官方渠道怎么认

> 搜「LeviLauncher」会同时碰到安卓版和 Windows 桌面版两套东西，本篇给两条硬标识用来认包，并说明第三方下载页上的坑。

名字是搜出来的，也是最容易误导人的线索：「LeviLauncher」底下挂着两套完全不同的东西，一套跑在安卓手机上，一套跑在 Windows 上。它们由同一个团队维护，但安装包、系统要求、界面都不一样。本篇先帮你分清自己要看哪一套，再给认包的办法，最后列第三方下载页的常见问题。

## 一、同名的是两个产品

| | 本文这套（安卓版） | Windows 桌面版 |
| --- | --- | --- |
| 项目仓库 | [LiteLDev/LeviLaunchroid](https://github.com/LiteLDev/LeviLaunchroid) | [LiteLDev/LeviLauncher](https://github.com/LiteLDev/LeviLauncher) |
| 装在哪 | Android 手机、平板 | Windows 10/11 |
| 安装包形态 | APK | Windows 安装程序，不是 APK |
| 系统要求 | Android 9.0 及以上、ARM64 设备 | Windows 系统，另需系统上具备 Gaming Services 等前置组件 |
| 面对的哪种游戏 | 安卓上的《Minecraft》基岩版 | Windows 上的《Minecraft》基岩版（GDK） |
| 官方文档 | 项目仓库的 README | 独立文档站 [levilauncher.levimc.org](https://levilauncher.levimc.org/) |

两个项目都由 LeviMC 团队（仓库在 LiteLDev 组织下）维护。**手机和平板装的是左列这一套**：如果你照着 Windows 版的教程在手机上找设置项，多半第一步就找不到对应按钮。反过来，桌面版的下载页给出的安装程序也没法装进手机。

## 二、认这套包，只看两条

包装上写的名字可以随便叫，下面两条改不了：

| 标识 | 值 | 在哪看 |
| --- | --- | --- |
| 包名 | `org.levimc.launcher` | 装完后在「设置 → 应用 → LeviLauncher → 应用信息」里 |
| 版本 / 体积 / MD5 | 1.0.14 / 18.44 MB / `BE6C756717393DF7F458AA25B55D9F86` | 版本在同一个应用信息页；体积与 MD5 看网盘里那个文件 |

包名要装完才看得到。装之前想先把关，用 MD5 比对，命令和比对方法在 [下载与安装教程.md](下载与安装教程.md) 里。

## 三、官方渠道有哪几个

- **安卓版的源码与发布**：[github.com/LiteLDev/LeviLaunchroid](https://github.com/LiteLDev/LeviLaunchroid)，安装包在它的发布页里。
- **问题反馈**：[Issues 页](https://github.com/LiteLDev/LeviLaunchroid/issues)。提问题前先确认自己用的是最新一版，并准备好机型和复现步骤。
- **Windows 桌面版**：[github.com/LiteLDev/LeviLauncher](https://github.com/LiteLDev/LeviLauncher)，使用说明看官方文档站。

除官方发布页之外，本项目的文档不背书任何第三方镜像或下载站，网上能找到的所谓镜像都请自行判断。

## 四、第三方下载页上的三个坑

搜索前排几乎全是各类软件下载站，它们的介绍文字多为互相拼凑，实际容易踩到的是这三类：

- **版本号与体积对不上**。同一个版本号，不同页面给出的安装包大小能差出好几倍；大小对不上，基本可以判断不是同一个文件。
- **系统门槛写得比官方低**。有些页面写「安卓 5.2 以上」甚至更低，而官方要求是 Android 9.0；按低门槛去装，结果就是装上打不开。
- **包被重新打包过**。这类包的签名与官方不同：一是来路不明，二是以后想换回官方那份，会因为签名冲突装不上，必须先把旧的卸掉。

还有一类页面会给它加一串查不到出处的功能描述，当广告看就行，不要拿它们判断能不能装。

## 五、能做和不能做的边界

- 这套启动器面向的是**持有正版授权**的玩家，官方明确说明它不替代游戏授权，也不提供绕过授权的做法。
- 本文档只覆盖安装、导入版本、账号与存档管理这些正常使用环节；遇到要求你改动游戏授权校验的所谓教程或工具，一律不采纳。
- 使用中出现的具体报错，按 [常见问题与排查.md](常见问题与排查.md) 的现象表定位，仍解决不了再去官方仓库反馈。
