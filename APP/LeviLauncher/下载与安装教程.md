LeviLauncher 是安卓设备上的《Minecraft》基岩版启动器。它自己不带游戏，作用是把你自己那份官方基岩版安装包导进来直接启动，并给每个版本单独留一份数据空间。本篇先帮你判断设备够不够用，再把网盘里这一份装好，最后把第一次启动前该准备的东西准备齐。

## 一、设备先过这五条

| 项目 | 官方要求 | 不满足会怎样 |
| --- | --- | --- |
| 系统版本 | Android 9.0（API 28）及以上 | 低于 9.0 的系统，装上也没法正常跑起来 |
| 设备架构 | ARM64（arm64-v8a） | 官方只提供 64 位包，32 位机型（armeabi-v7a）不在支持范围内 |
| 可用内存 | 最少 1 GB，建议 2 GB 以上 | 内存紧张时启动过程容易被系统中断 |
| 可用存储 | 至少 2 GB，官方建议留 5 GB 空闲 | 空间不足会在解包或创建实例那一步失败 |
| 游戏授权 | 持有从 Google Play 购买的正版《Minecraft》基岩版 | 启动器只负责启动，不替代游戏授权 |

官方另外写明一条前置条件：**这台设备要先通过 Google Play 安装过官方《Minecraft》基岩版客户端**。启动器启动游戏时要能找到它，从来没装过官方客户端的设备，先用官方渠道装一次再回来。

系统要求以这张表为准。网络上有不少下载页把门槛写得比官方低，出现过「安卓 5.2 以上」「安卓 4.3 以上」这类说法，和官方仓库里的 9.0 对不上，别按那些页面判断自己的设备能不能装。

## 二、网盘里这份是哪一版

各下载站登记的数字，和网盘里这份常常不是同一个文件。判断是不是同一份，看**包名 + MD5**，不要看名字旁边的版本号：

| 项目 | 值 |
| --- | --- |
| 应用名 | LeviLauncher |
| 版本号 | 1.0.14 |
| 包名 | `org.levimc.launcher` |
| 安装包体积 | 18.44 MB |
| MD5 | `BE6C756717393DF7F458AA25B55D9F86` |
| 形态 | 安卓 APK |
| 本文核对时间 | 2026-09-23 |

官方仓库的发布页会持续更新，网上搜到的通常是更新的版本，与网盘里这份不是同一版很正常。系统要求、安装步骤这些不随版本变化的内容按本文走；具体版本号以官方发布页当时显示的为准。

## 三、装到手机上

1. **先转存，再下载**。打开 [LeviLauncher 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1a3dd9d1328f)，把 APK 转存到你自己的网盘再下载到手机。这一步别省：分享链接失效后，只有转过存的那份还在。
2. **允许这一来源安装应用**。在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，允许你用来打开安装包的那个应用（文件管理器、浏览器或网盘客户端），再点 APK 安装。
3. **提示「应用未安装」就先卸载旧版**。设备上若已存在同包名但签名不同的 LeviLauncher，覆盖安装会直接失败，先卸载再装这份。
4. **首次打开按提示授予权限**。启动器会申请「所有文件访问权限」（有的系统写作「管理所有文件」）和读取已安装应用列表的权限：前者用于读写它自己管理的游戏数据，后者用于找到本机上的官方客户端。存储类权限给不全时，导入安装包与创建实例会直接失败；安卓 11 及以上的存储设置怎么处理，见 [游戏数据存在哪与安卓11存储限制.md](游戏数据存在哪与安卓11存储限制.md)。

装完可以先验一下文件有没有下全。把 APK 拷到电脑上，在文件所在目录执行：

```powershell
certutil -hashfile "LeviLauncher_v1.0.14.apk" MD5
```

把输出里那串十六进制去掉空格，和 `BE6C756717393DF7F458AA25B55D9F86` 逐位比一遍（大小写不影响结果）。对得上说明是本文对应的那一份；对不上说明文件被改过或者没下完，别装。

## 四、第一次打开前先准备两件事

1. **官方客户端仍能在本机正常登录**。启动游戏时的授权校验走的是这台设备上的官方客户端和你的微软账号，账号掉线或官方客户端被卸载，启动会卡在验证那一步。
2. **把要导入的官方安装包放到手机能访问的位置**。比如手机的 `Download` 目录。导入时启动器会让你在系统文件选择器里指到它，放在哪儿不关键，能被选到就行。

## 五、装好之后走一遍最小流程

导入一份安装包 → 创建实例 → 启动，能进到游戏主界面，说明安装这一环通了，具体操作见 [导入游戏版本与创建实例.md](导入游戏版本与创建实例.md)。

装不上、一打开就退、导入卡住，先看 [常见问题与排查.md](常见问题与排查.md)；不确定手里这份是不是这套官方项目出的，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
