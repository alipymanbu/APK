> 本篇讲怎么用 iMuseum 找身边的展览、看懂展览详情页里的信息，以及把想看的展加进观展计划并设置提醒。

iMuseum 的核心用法是「先找展、再排程」：打开应用按城市浏览正在进行的展览，把感兴趣的加进观展计划，让它在开展、闭展时提醒你。本篇把这条链路上每一步能点的东西、每个字段的意思讲清楚。

## 一、两种找展方式

- **同城**：应用首页的「同城」标签，按你的定位列出附近正在进行的展览和博物馆。第一次使用需要允许定位权限；在异地旅行时打开它，就能看到旅行目的地周边正在展出的内容。
- **世界**：环球博物馆与展览资讯，每日更新，覆盖国内外主要城市（北京、上海、纽约、芝加哥、迪拜等都有独立的城市页）。计划出国看展时，提前在这里翻目标城市的展讯比到了再找高效得多。

网页版（[art.icity.ly](https://art.icity.ly)）与 App 内容对应，每个城市页提供「全部 / 最新 / 热门 / 即将结束 / 即将开始 / 已结束」几类筛选，适合在电脑前长列表翻找；手机上则以 App 内的入口为准。

## 二、展览详情页有哪些信息

点开任意一个展览，详情页的字段就是安排行程要用的全部关键信息：

| 字段 | 用途 |
| --- | --- |
| 时间 | 展期起止 + 每日开闭馆时间，注意「周一闭馆」「提前 30 分钟停止入馆」这类备注 |
| 展馆 / 地址 | 博物馆名称与详细地址，用于导航 |
| 费用 | 免费或票价；不少免费展标注「需预约」「需持身份证件」，别只看到 Free 就出发 —— 预约手续怎么办见 [热门展馆预约渠道与入馆规则.md](热门展馆预约渠道与入馆规则.md) |
| 展厅 | 大馆常分多个展厅，进门先看这个字段少走冤枉路 |
| 展览现场 | 其他用户上传的实拍照片，展品规模、人流密度都能参考 |

## 三、把展览加进观展计划

在展览页选择「想去 / 加入计划」类的操作后，这个展览就进了你的观展列表。「开始/结束」时间提醒是官方介绍里明确列出的功能：临近开展、闭展时推送通知，限时特展只展出几周，靠它提醒比记在脑子里可靠。提醒的具体形式（通知、震动等开关）在应用的设置里调整，不同机型与版本的可选项略有差别，以你手机上显示的为准。

## 四、提醒没响时查哪里

观展提醒依赖一条完整的链路：应用内开关 → 系统通知权限 → 通知不被静音。提醒没响时按这个顺序排查：

1. **应用内**：确认这个展览还在你的观展计划里、对应的提醒开关是开的（入口名称与位置以应用内显示为准）。
2. **系统通知权限**：安卓到「设置 - 通知 - 应用通知」里找到 iMuseum，允许通知；iPhone 到「设置 - App」里选中应用后打开「允许通知」。权限被关时，应用端怎么设都没用。
3. **勿扰 / 专注模式**：这类模式开着时通知会被静音或延迟，可以把应用加进模式的白名单，或看展当天关掉。
4. **省电与后台限制**：省电模式、电池优化会延迟甚至拦下后台推送，把应用设为「不受限制 / 不优化」；部分国产手机还要在自启动管理里放行。
5. **兜底习惯**：重要展览别只依赖提醒，出发前夜打开计划列表扫一眼，30 秒的事。

## 五、几个实际场景

- **周末临时想看展**：直接开「同城」，优先看即将结束的那批 —— 再不去就没了的先安排。
- **外地旅行做攻略**：出发前用「世界」切到目标城市，把想看的展都加进计划，剩下的时间节点交给提醒。
- **带家人逛馆**：先看详情页的「费用」与备注，确认要不要预约、带不带证件，再看「展览现场」照片判断孩子是否感兴趣。

看完展之后怎么打卡、怎么和朋友共享计划，见 [观展记录与好友分享.md](观展记录与好友分享.md)。
