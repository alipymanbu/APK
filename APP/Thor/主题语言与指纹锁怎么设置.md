# Thor 主题语言与指纹锁怎么设置

> 本篇讲清 Thor 的界面外观、语言和指纹锁怎么调，哪些设置只是换皮、哪些会真的影响功能。

Thor 的设置项分两类：一类只改界面长相和语言，改错了顶多看着不顺眼；另一类直接决定功能能不能用（工作模式就是这一类，单独写在 [Shizuku授权与工作模式怎么选.md](Shizuku授权与工作模式怎么选.md)）。本篇只讲前一类里常被问到的几项。

## 一、主题与深色模式

外观相关的选项通常集中在一个「外观 / 主题」分区里：

| 选项 | 作用 | 怎么选 |
| --- | --- | --- |
| 浅色 / 深色 / 跟随系统 | 决定基础配色 | 想跟系统节律一致就用「跟随系统」 |
| AMOLED 深色 | 把深色模式下的背景压成纯黑 | OLED 屏机型可选，纯黑区域的像素不发光，夜里看着更沉 |
| 静态主题 | 换一套固定的配色与字体观感，不随系统变 | 想要固定风格、不想被系统主题牵动时选它 |
| 动态颜色（Material You） | 配色取自你的壁纸 | 系统版本支持时才有这一项，换壁纸配色跟着变 |

深色模式与纯黑是两个层级——先确定是浅色还是深色，再决定深色要不要用纯黑。改完之后整个界面即时生效，不重启应用。

## 二、界面语言怎么切

Thor 自带语言切换器，可以在应用内部单独选语言，不影响系统语言：

1. 进设置，找「语言」分区；
2. 从列表里选一种语言，界面会立刻切换；
3. 想恢复成跟随系统，就选列表里的「系统默认」那一项。

这个版本内置的语言包括英语、中文、法语、西班牙语、阿拉伯语等，后续版本会增加，**以你手机里列表实际给出的为准**。列表里没有你要的语言时，换不了——只能等官方加上，或者让界面跟着系统语言走（系统语言若也没有，界面会落到官方默认的那一种）。

顺带说明一个常见误解：切的是**应用界面的语言**，系统其他部分不受影响；调整它也不需要任何权限。

## 三、指纹锁怎么开、锁住了什么

设置里有一个指纹（生物识别）锁的开关，打开后进入 Thor 需要先过指纹：

1. 确认手机里已经录入了指纹，Thor 会直接调用系统已有的指纹数据；
2. 打开开关。之后每次打开 Thor，先验证指纹再进清单；
3. 想关掉时回到同一个开关关掉即可，不会残留什么状态。

关于它的边界要说清楚：**它锁的是「打开 Thor 这个界面」这一件事**，不是给你手机里的应用上锁。别人绕过 Thor、直接从桌面点开应用，照样能用；已经冻结的应用也不会因为这个开关变得更安全。它防的是「别人拿起你手机翻你的应用清单」，仅此而已。

指纹验证不通过或指纹被系统删掉后进不去，最实际的办法是去系统的应用管理里清除 Thor 的应用数据，让它回到初始状态。**这是重置而不是找回密码**，代价是 Thor 自己的界面设置与已缓存的清单要重建；不过你已经冻结或卸载过的应用状态记在系统里，不会因为清 Thor 的数据而被改回去，重新打开后清单会再同步一次。

## 四、列表怎么排布

应用清单支持网格与列表两种排布，切换入口在清单页上方。选过的排布会被记住，下次打开还是你选的那一种，不用每次重设。

网格适合靠图标认应用，一屏能放更多；列表适合看清楚名称、体积、安装来源这些文字信息。清理预装应用这类要逐项核对文字的场景，用列表更顺手。

## 五、哪些设置改了不影响功能

把这几项列清，省得每次改完都要怀疑一遍功能是不是坏了：

| 设置项 | 改动后会不会影响已做的操作 |
| --- | --- |
| 主题、深浅模式、动态颜色 | 不会，纯界面 |
| 界面语言 | 不会，纯界面 |
| 网格 / 列表排布 | 不会，纯界面 |
| 指纹锁 | 不会改变应用状态，只是多一道开门检查 |
| 工作模式（Root / Shizuku / Dhizuku） | **会**，它是功能开关，改错了操作会全部失败 |

也就是说，本篇里的选项都可以随便试；唯独工作模式那一项别乱动，改之前先读 [Shizuku授权与工作模式怎么选.md](Shizuku授权与工作模式怎么选.md)。界面本身出现异常（例如列表空白、图标不刷新）时，处理办法在 [常见问题与排查.md](常见问题与排查.md)。
