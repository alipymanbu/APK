Thor 是一个安卓手机上的应用管理器：它把手机里已安装的应用列成一张清单，让你在清单上直接卸载、冻结、结束进程、清除数据、导出安装包，也支持一次勾选多个应用做同一件事。它面向的是想清理预装应用、整理应用权限与状态的用户；真正动到系统应用时需要额外的权限（见下文第四节）。本篇只解决一件事：把网盘里这份包装进手机，并让第一次打开能正常用起来。

## 一、先弄清网盘里这份包是哪一版

网上能搜到的版本信息多数是发布时的最新版，而网盘里这份是整理文档时核对过的那一版，两者未必是同一个版本号。下面这些值以网盘里那份包为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Thor |
| 版本号 | 1.80.6-foss |
| 包名 | `com.valhalla.thor` |
| 安装包体积 | 4.40 MB |
| MD5 | `300E41FB8512E6FC8400D4F43F7F65CE` |

版本号结尾的 `-foss` 是官方给自家分发包起的后缀，表示它出自开源渠道那一支构建；官方另有商店渠道的构建，两者界面功能基本一致。这个后缀不代表它是「精简版」，也不影响包名。

安装包本体就在头部那条夸克网盘分享里，转存到自己的网盘后下载即可。装之前可以顺手核对一次 MD5：在电脑上用校验工具算一遍，与上表一致再装，能避开下载被截断或被人换包的情况；手机端下的包不方便校验，那就只看体积是否与 4.40 MB 接近。

## 二、装之前先确认两件事

**第一，能装它的前提是系统版本够。** 官方工程在这个版本里设定的最低系统是 Android 9（API 28），也就是说 Android 8 及更早的机型装不上。真机确认方式有两种：一是打开官方的应用商店页面看「关于此应用」里标注的最低版本，与手机「设置 → 关于手机」里的系统版本对照；二是直接装——安卓在设备不兼容时会拒绝安装并提示「应用未安装」或「与你的设备不兼容」，不会给你装上一个半残的版本。

**第二，认包名，不要认名字。** 应用市场上叫 Thor 的应用有好几个，图标、名字都可能撞车，系统区分它们靠的是包名。下面这套文档对应的只有一个：`com.valhalla.thor`。装完可以在应用详情里回看一眼包名，确认装的是它。这一条展开写在 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 三、安装步骤

1. **转存并下载**：从 [Thor 安装文件资源（夸克网盘）](https://pan.quark.cn/s/352fe68d2d8c) 把 APK 转存到自己的网盘，再下载到手机。
2. **把包送到手机上**：手机端直接下载最省事；在电脑上下载的话，用数据线或任意传输工具拷进手机存储即可。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统通常把这项收在「安全」或「隐私」分类下面。
4. **点击 APK 完成安装**：系统若提示「应用未经过安全检测」，选择继续安装即可。
5. **手机里已有同包名的版本时先卸载**：如果之前装过商店渠道的同一款应用，换上这一份可能报「应用未安装」，原因是两份包的签名不同。先卸载旧的那份，应用内的设置会一并清掉。
6. **装完先别急着清理应用**：先跟着下一节把权限与工作模式定下来，否则清单能看到，动到系统应用的操作会一直失败。

## 四、第一次打开要做的三件事

Thor 本身不申请一个「超级权限」就完事，它的能力来自你在应用里选定的权限引擎，所以第一次打开有几项要定：

| 要做的事 | 在哪做 | 不做的后果 |
| --- | --- | --- |
| 选工作模式（Root / Shizuku / Dhizuku） | 设置里的工作模式选项 | 只能看清单，冻结、卸载系统应用这类操作会失败 |
| 把 Shizuku 或 Dhizuku 跑起来 | 各自的 App 里，见 [Shizuku授权与工作模式怎么选.md](Shizuku授权与工作模式怎么选.md) | Thor 里显示权限不可用 |
| 可选：打开指纹锁 | 设置里的锁屏选项 | 不影响功能，只是别人拿到你手机就能翻应用清单 |

没有 root 的机型，通常走 Shizuku 这一路：先在手机上装好 Shizuku 并启动它，回到 Thor 里授权，再在设置里把工作模式切到 Shizuku。整套流程、以及每次重启后 Shizuku 会失效这件事，都写在 [Shizuku授权与工作模式怎么选.md](Shizuku授权与工作模式怎么选.md)，这里不重复。

## 五、装完做一次最小验证

1. 打开 Thor，等应用清单加载出来——正常情况下会带图标、名称、体积这些信息；
2. 用搜索框搜一个你确定装了的应用，看能否搜到；
3. 点进它的详情页，看有没有「分享 APK」这类按钮，以及有没有显示安装来源；
4. 回到清单，用筛选把「系统应用」和「用户应用」分开看一次，确认筛选能生效。

前三步能过，说明安装与基础读取都没问题；第 4 步只是筛选，既不冻结也不卸载，是安全的试手动作。真要去动预装应用之前，请先读 [冻结和卸载预装应用怎么做.md](冻结和卸载预装应用怎么做.md)，那里写了哪些应用不能碰、以及怎么留退路。

## 六、以后出了新版本怎么升级

网盘那份分享是长期有效的：换版本时替换的是里面的安装包文件，**分享链接本身不变**，所以升级不用重新去找地址。

1. 回到本文头部那条分享，看里面是不是已经换成比 1.80.6-foss 更新的包；
2. 直接下载新包点安装。包名相同、签名相同、版本号更高时，安卓允许覆盖安装，应用内的设置会保留；
3. 若覆盖安装报「应用未安装」，说明新包的签名与手机里那份对不上，或版本号反而更低。这种情况只能先卸载再装，代价是设置要重配一遍。

有两点要自己留意：它不是从手机自带应用商店装的，商店通常不会替第三方来源的应用检查更新，想保持新版得隔一段时间回网盘看一眼；另外，如果你的手机里同时存在商店渠道的同包名版本，两者只能留一个——签名不同，装第二个会被系统直接拒绝。想跟官方最新的版本进度，看官方的发布页与更新日志即可，地址列在 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
