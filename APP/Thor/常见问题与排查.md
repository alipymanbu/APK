Thor 的绝大多数「坏了」，其实是权限引擎没在跑，而不是应用出错。排查时先按下面这张表定位，再去对应小节看细节。

| 现象 | 先去查 |
| --- | --- |
| 按钮变灰、操作提示权限不足 | 第一节：权限与工作模式 |
| 刚重启过手机就什么都做不了 | 第一节，Shizuku 重启后失效 |
| 冻结、解冻点了没反应或报错 | 第二节：冻结与解冻 |
| 清单里的应用和实际装的对不上 | 第三节：应用清单 |
| 安装包提示「应用未安装」 | 第四节：安装与包的问题 |
| 进不去 Thor 界面 | 第五节：指纹锁与界面 |

## 一、权限与工作模式

**刚重启手机，所有操作都失败。** 这是最常见的一种，也最容易被误判成应用坏了。没 root 时，Shizuku 服务在每次重启后都会停，Thor 拿不到权限，自然什么都做不了。处理方式：打开 Shizuku 重新启动一次服务（Android 11 及以上走无线调试那条路，不需要电脑），回到 Thor 再操作。手机里被冻结的应用不会因为这次中断被改回去。

**Shizuku 显示没在运行，但刚启动过。** 按顺序查三件事：一是开发者选项与无线调试是否还在开着（有的系统会自动关）；二是启动 Shizuku 那一步是否真的成功了，而不是停在配对页；三是系统有没有把 Shizuku 的后台掐掉（省电策略、清理类工具做「一键优化」都可能掐）。把无线调试关掉再打开一次、重新启动服务，通常能恢复。

**配对时一直停在「正在搜索配对服务」，或点「输入配对码」立刻失败。** 官方给出的第一个处理动作是把无线调试禁用后重新启用，然后再试一次配对。这两条还各有一个系统侧的成因：前者多半是 Shizuku 退到后台后立刻被厂商断掉本地网络权限，需要给它开放后台运行；后者在小米 / POCO 上要把系统通知样式切成「原生样式」。各家系统要额外改哪几项，见 [Shizuku授权与工作模式怎么选.md](Shizuku授权与工作模式怎么选.md) 第三节那张厂商对照表。

**启动后提示 adb 权限受限。** 这是系统把调试通道管得更严，同样是系统侧设置问题：小米 / POCO 要另开「USB 调试（安全设置）」（与「USB 调试」是两个选项），OPPO / 一加要关掉「权限监控」，魅族要关掉「Flyme 支付保护」。逐项对照那张厂商表处理。

**系统是 Android 10 及以下。** 这些系统没有无线调试，只能连电脑用 ADB 启动 Shizuku，这一步没法规避。所用命令以 Shizuku 官方说明页当时给出的为准，不要从第三方教程里抄。

**授权弹窗一直没出现。** 确认 Shizuku 当时在运行，然后完全关掉 Thor 再打开一次——授权状态变化后，应用有时要重新读一次才能刷新出授权入口。

**想在 Dhizuku 模式下用某个功能，提示当前模式不支持。** 设备所有者能做的事比 root 和 shell 权限窄，Thor 里会有一部分功能在这个模式下不可用，这是正常的，不是配置错误。需要那些功能就换成 Root 或 Shizuku 模式。

## 二、冻结与解冻

**冻结点了没反应。** 先看工作模式是否为「无权限」；权限正常时，再确认你冻的是不是带设备管理员身份的系统应用——这类应用会拒绝被停用。换一个普通预装应用试一次，能成功就说明是应用本身的限制。

**解冻失败、提示操作被拒绝。** 九成是权限引擎换了：用 Shizuku 冻的，重启手机后 Shizuku 已停，此时去解冻就会失败。把 Shizuku 重新启动起来，用同一个模式解冻。用 Root 冻的不要切到别的模式去解，反过来也一样。

**冻结之后在哪儿找它。** 桌面上通常已经看不到图标了，但 Thor 的清单里还在，状态标为已冻结；冻结列表也可以直接找到。所以「找不到它」不等于「被卸载了」。

**冻结过的应用在系统自带的设置里还能看到。** 冻结只是停用，安装记录仍然存在，系统设置里看得到很正常。

**想确认某个冻结到底有没有生效。** 看三处：桌面图标是否消失、它是否不再发通知、Thor 里的状态标记。三处都符合就是生效了。

## 三、应用清单

**刚装的应用没出现在清单里，或刚卸载的还在。** Thor 会缓存应用元数据来加快加载，所以清单可能比实际状态慢一拍。办法是回列表下拉刷新一次、切一下筛选再切回来，或直接重开 Thor 让它重新读一遍。

**筛选到系统应用后，反而看不到想找的那个。** 先确认筛选是不是还停在别的条件上；再确认目标应用是不是装在别的用户空间里（部分机型的「应用分身」「多用户」会把它装到另一个用户下，当前用户看不到）。

**同一个应用出现两条记录。** 通常是多用户或分片安装造成的显示差异，不是重复安装。按包名搜索确认一下实际有几条安装记录。

**详情页里某个按钮不见了。** 按钮的可用性跟着当前权限模式走：没有对应权限的功能会被隐藏或置灰，不是功能被删掉了。

**处理过的预装应用在系统更新之后又出现了。** 系统更新会整体替换系统分区，固件预置的应用连同出厂启用状态一起回来，这是正常结果，不是你的操作没生效。复查顺序见 [系统更新后预装应用又回来了怎么办.md](系统更新后预装应用又回来了怎么办.md)。

## 四、安装与包的问题

**装上提示「应用未安装」。** 按下面顺序排除：

| 可能原因 | 怎么确认 |
| --- | --- |
| 手机里已有同包名、签名不同的版本 | 先卸载旧的再装（商店渠道与其它渠道的包签名往往不同） |
| 新包版本号比手机里的低 | 安卓不允许降级覆盖，只能先卸载再装 |
| 目标设备系统版本低于该应用要求 | 对照官方商店页标注的最低版本 |
| 拆分应用只带了部分文件 | 回到导出方把整套分片都取过来 |

**导出的包在别的手机上装不上。** 见上一节同样的清单；另外，金融、支付类应用对自身安装包常做保护，导出的包在其它设备上可能装不回，这属于应用本身的限制，不是导出步骤错了。

**导出后找不到文件。** 导出时会走系统的分享面板，如果当时选了「发送给某人」而没有落盘，本地就不会有文件。重新导一次，这次选保存到本地，再去文件管理器确认文件存在且体积不为零。

**修复安装来源（Fix Store）用不了。** 这个功能需要 Root 或 Shizuku 权限，权限不到位时不可用；修完记录后一般还要去商店更新一次才看到效果。

## 五、指纹锁与界面

**指纹验证不过，进不去界面。** 确认系统里还留有已录入的指纹（换过指纹或删过指纹都会导致验证不上）。都不行时，去系统设置的应用管理里清除 Thor 的应用数据，让它回到初始状态——这是重置，Thor 里的界面设置会丢，但被冻结、被卸载的应用状态记在系统里，不会因此被改回来。

**界面语言不是我要的那一种。** 应用内的语言选项是独立于系统语言的，进设置的语言分区里手选一次。列表里没有你要的语言时，只能跟着系统语言走或等官方更新。

**主题改完看不出变化。** 深色模式与纯黑是两个层级，选了纯黑但基础模式还是浅色，看起来当然没变。先确定深浅模式，再看纯黑是否生效。这几项设置的入口与边界统一写在 [主题语言与指纹锁怎么设置.md](主题语言与指纹锁怎么设置.md)。

**清单加载比平时慢。** 刚装完、刚更新完一批应用之后出现属正常，元数据缓存要重建一次；之后会恢复。

如果上面的表里没有你的现象，先在应用里核对一遍包名是不是 `com.valhalla.thor`——装成另一个同名的 Thor，界面长得像但功能对不上，排查方向会完全不同，详见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。确认是同一个应用之后，还可以去官方仓库的 issue 区与官方频道里看有没有人报过同样的现象——官方仓库的地址列在那篇的渠道表里。
