## 一、先对身份：你装的是哪一版

出问题之前先确认装的是什么，很多「功能没有」其实只是版本旧：

| 渠道 | 版本情况 |
| --- | --- |
| 网盘（本仓库提供的那份） | 1.0.0，包名 `com.zhjj.blacklyte`，99.94M，2026-09-24 采集 |
| 小米应用商店 / App Store | 截至 2026 年 4 月显示 2.0.13 |
| 应用宝 | 截至 2026 年 1 月显示 2.0.12 |

2.0.0（2025 年 7 月）是一次整体重构，之后的 2.0.7 加了 NFC 绑保修与手动兑换积分、2.0.8 加了活动竞猜与抽奖——**这些新功能在 1.0.0 里没有属正常**，不是坏了。要看新功能就去商店渠道装最新版（核对包名 `com.zhjj.blacklyte`，见 [下载与安装教程.md](下载与安装教程.md)）。

## 二、逐条排查

| 现象 | 按顺序做这几步 |
| --- | --- |
| 启动动画慢、打开要等 | 官方在应用商店简介的「已知问题」里写明：**首次版本部分低端设备在启动动画时可能略有延迟**，官方标注正在优化。等进主界面即可；升级到商店最新版看是否改善 |
| 装不上、提示解析错误 | 机身空间留够 500M 以上重装；重新下载 APK 后校验 MD5 是否与 [下载与安装教程.md](下载与安装教程.md) 表里一致 |
| 闪退、卡到没反应 | 清后台重开；系统设置 → 应用 → Blacklyte → 存储里清缓存（清缓存不等于清数据，先只清缓存）；再不行就重装 |
| 收不到赛事/活动通知 | 系统设置 → 应用 → Blacklyte → 通知，确认总开关与各分类都开着（安卓 13+ 还需允许 POST_NOTIFICATIONS） |
| 签到/任务/兑换的积分对不上 | 按 [签到积分与商城兑换教程.md](签到积分与商城兑换教程.md) 的表逐项查；2.0.8 改过积分规则，以当前版本页面为准 |
| NFC 贴卡没反应 | 手机 NFC 开关是否打开、贴卡位置是否贴住卡片感应区；手机本身不支持 NFC 则此功能不可用（见 [产品百科与NFC绑定查保修怎么看.md](产品百科与NFC绑定查保修怎么看.md)） |
| 登录不上 | 首次打开要先点「同意并继续」；用页面提供的账号方式一键登录，网络不稳时切流量重试 |
| 椅子/桌子部件坏了要修要换 | 不是 App 的问题，按 [电竞椅保修与退换货怎么办.md](电竞椅保修与退换货怎么办.md) 的材料清单走官方申请 |

## 三、反馈问题走哪个入口

官方在商店简介里给的渠道是：**「我的 → 帮助与反馈」提交，会优先处理上线首批问题**。提交时把这几样带上，回复会快很多：

1. 手机型号与系统版本；
2. App 版本号（在「我的」或设置页里看）；
3. 问题截图与复现步骤（是每次都这样，还是偶发）。

涉及账号、兑换、订单类的问题，一并附上账号标识与兑换记录时间。

## 四、账号、隐私与设置

- 账号管理、主题皮肤、语言切换、隐私与反馈都在「我的」里的设置区；语言支持简体中文与英语（iOS 端页面显示为「简体中文 + 1 种语言」）。
- 隐私政策在 App Store 页面有直达链接（挂在 `arcushome.cn` 的文档页），App 内设置里也有入口——想看它到底要哪些权限、存哪些数据，读那份为准。
- 系统权限的逐项作用与「不给会怎样」，见 [下载与安装教程.md](下载与安装教程.md) 第四节。

## 五、还是解决不了

先升级到商店最新版再复现一次（很多问题新版本已修，更新日志持续写着「已知问题修复优化」）；升级后依旧，就走「我的 → 帮助与反馈」提工单，别去非官方渠道找「改包版」「精简版」的安装包——那类包来源不明，与官方包名一致也不可信。
