## 一、Blacklyte 是什么

Blacklyte 是电竞椅与电竞桌品牌 BLACKLYTE（逐夜）出的官方 App，包名 `com.zhjj.blacklyte`，安卓端开发者与运营者都是杭州智华家居科技有限公司，iOS 端开发者显示为 Blacklyte Inc.。你在里面能看电竞赛事资讯与赛程、查产品百科、每日签到攒积分换周边，还有会员成长任务。品牌官网是 [blacklyte.com](https://blacklyte.com/)，App 内的隐私政策挂在 `arcushome.cn` 的文档页上（App Store 页面有直达链接）。

它不是游戏本体，也不是游戏辅助工具——是品牌做的「资讯 + 福利 + 产品」助手类应用。装好之后怎么逛资讯见 [赛事资讯与赛程怎么用.md](赛事资讯与赛程怎么用.md)，积分怎么攒怎么花见 [签到积分与商城兑换教程.md](签到积分与商城兑换教程.md)。

网盘里存的是**打包时那一版**的安装包，事实如下（以这份为准，别拿商店页面的数字来对）：

| --- | --- |
| 版本 | 1.0.0 |

| 安装包大小 | 99.94M |
| MD5 | `05E6E846E46671CB9A36C1C217345E0A` |
| 采集于 | 2026-09-24 |

从这里取 [Blacklyte 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6c23ab994f9e)：打开分享页 → 转存到自己的网盘 → 在网盘里下载 `blacklyte_v1.0.0.apk`。文件夹里附了一份说明 txt，跟着它操作可以避免分享失效后找不到文件。

两点提醒：

- 商店渠道后来已经上架更高版本（截至 2026 年 4 月，小米应用商店与 App Store 都显示 2.0.13，应用宝页面显示 2.0.12），**核对身份看包名 `com.zhjj.blacklyte`**，别只看名字——名字对不上包名就不是这个应用。
- 下载完可以校验 MD5 是否与上表一致，不一致说明文件在传输中损坏了，重新下载。**这个 MD5 只对网盘这一份有效**——商店渠道的包是各自打包的，字节数和 MD5 都不同，属正常现象。

## 三、安装步骤

1. 在手机浏览器或网盘 App 里下载 APK 文件；
2. 点击 APK，系统会弹「禁止安装未知来源应用」——这是安卓对非商店来源安装的默认拦截；
3. 按提示进入设置，允许该来源（浏览器或网盘）安装应用，返回后继续安装；
4. 等进度走完，点「打开」进入启动页，按提示点「同意并继续」进入登录页。

装完可以把「安装来源允许」关回去，下次装别的包再开即可。安装失败或提示解析错误的处理见 [常见问题与排查.md](常见问题与排查.md)。

## 四、首次启动要给的权限

应用商店页面公示的权限清单里，与你日常使用直接相关的几项：

| 权限 | 不给会怎样 |
| --- | --- |
| 通知（POST_NOTIFICATIONS） | 赛事提醒、活动通知收不到 |
| 摄像头 | 反馈问题时拍不了照片 |
| 相册/媒体读写 | 反馈时选不了图，图片缓存受影响 |
| 位置 | 与定位相关的辅助功能受限 |
| NFC | 无法用 NFC 卡片绑定产品查保修（见 [产品百科与NFC绑定查保修怎么看.md](产品百科与NFC绑定查保修怎么看.md)） |

看资讯、签到、查百科这些核心功能不需要摄像头和位置，可以先拒绝，之后在系统设置里随时补开：设置 → 应用 → Blacklyte → 权限。

## 五、系统与空间要求

- 安装包 99.94M，装上后连数据缓存会占更多，**机身可用空间最好留出 500M 以上**，空间不足会装到一半失败。
- 本地采集信息记的系统门槛是「需要支持安卓系统 5.2 以上」，实际以能否正常装上、跑起来为准；iOS 端要求 iOS 15.6 或更高（iPhone/iPad 同），苹果 Silicon 的 Mac 需要 macOS 12.5 以上。
- 装上后闪退、启动慢的排查见 [常见问题与排查.md](常见问题与排查.md)。
