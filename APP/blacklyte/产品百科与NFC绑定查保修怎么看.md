## 一、产品百科里有什么

产品百科是给「买之前做功课」用的：每个产品条目下通常有这几类内容——

| 内容 | 你能看到什么 |
| --- | --- |
| 图片 | 多角度实物图与配色 |
| 规格 | 尺寸、材质等参数 |
| 使用教程 | 装配、调节类的步骤说明 |
| 视频 | 演示与讲解 |
| FAQ | 常见疑问的官方解答 |

对的品类是电竞椅（Athena Pro、Kraken Pro 等系列）、升降桌（Atlas 系列）与配件，价格区间在官网 [blacklyte.com](https://blacklyte.com/) 能对到（不同配色、不同版本价格不同，**以官网当时显示为准**）。百科条目帮你决定买哪款，实际下单走官网或你常用的渠道，App 里不承担交易。

## 二、用百科做选购判断的顺序

1. 先按品类圈范围：要椅子还是桌子；
2. 看规格页对尺寸——桌椅都要匹配你的房间和身高，教程与视频里有调节范围的演示；
3. 翻 FAQ 看有没有你在意的点（材质保养、承重、调节方式这类）；
4. 还有疑问，进详情页看视频，或去 [赛事资讯与赛程怎么用.md](赛事资讯与赛程怎么用.md) 里提到的活动页看官方活动说明。

官方 FAQ 里几条能直接拿来当判据的数（截至 2026 年 9 月官网 FAQ 页，**以官网当时显示为准**）：

| 判据 | 官方口径 |
| --- | --- |
| 适用体重 | 椅子建议承重不超过 330 磅（约 150 kg） |
| 适用身高 | 建议 165~190 cm，超出这个区间支撑位置对不准 |
| 布面选项 | Athena 系列有布面可选；Kraken 系列只有皮面 |
| 椅轮 | 各型号轮子通用；只有 Athena X 用的刀轮带锁定，其余型号的轮子不能锁 |
| 椅子怎么选 | 要顶级支撑选 Athena Pro；要均衡选 Athena；要升级材质选 Kraken Pro |
| 桌子怎么选 | Atlas 带灯控、面向带灯效的桌面搭建；Atlas Lite 是双电机 + 记忆档位的实用向 |

和积分的关系：商城里能换的周边与产品（见 [签到积分与商城兑换教程.md](签到积分与商城兑换教程.md)）也是同一套产品体系，百科里的规格描述通用。买完之后的保修与退换走 [电竞椅保修与退换货怎么办.md](电竞椅保修与退换货怎么办.md)。

## 三、NFC 绑定产品查保修（2.0.7 起）

2.0.7 版本（2025 年 11 月）加了一个实用功能：**用 NFC 卡片绑定产品并查看保修期限**。你实际操作时的注意点：

- 前提是手机支持 NFC 且已开启，并且产品包装里带了可感应的 NFC 卡片/标签；
- 绑定入口在 App 的产品/设备相关页面里，按页面提示把手机贴到卡片上完成绑定；
- 绑定成功后，保修期限在该产品的详情里能直接看到，不用翻纸质凭证；
- 手机不支持 NFC 就用不了这个功能——保修信息仍可走客服渠道查询（见 [常见问题与排查.md](常见问题与排查.md)）。

「贴卡没反应」的排查也放到了 [常见问题与排查.md](常见问题与排查.md) 里，这里不重复。

## 四、百科内容和实际产品对不上时

百科、教程与 FAQ 都由官方维护，随型号迭代更新。如果你手里那台是更早批次，参数对不上：

- 以**产品机身铭牌/包装上的型号**为准，再去百科里找对应型号那一条；
- 仍对不上，把型号和问题发到「我的 → 帮助与反馈」，官方答复比二手帖子可靠（见 [常见问题与排查.md](常见问题与排查.md)）。

二手渠道的参数说明、第三方评测只能当参考，别拿来覆盖百科里的官方规格。
