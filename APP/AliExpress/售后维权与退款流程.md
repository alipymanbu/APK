## 一、买家保障是什么

每一笔订单都自带「买家保障（Buyer Protection）」，核心是两条：

1. **保障期内没收到货** → 可以申请全额退款；
2. **收到货与描述明显不符** → 可以申请退货退款或部分退款。

保障期有时长上限，到期后平台不再受理，所以整篇的关键动作只有一个：**在保障期内处理问题**。具体剩余天数在订单详情页看倒计时；快到期还没收到货，先去申请「延长买家保障」（操作见 [物流跟踪与收货时间.md](物流跟踪与收货时间.md) 第三节）。

## 二、没收到货怎么申请退款

1. 打开「Account → 我的订单」，进入问题订单。
2. 确认订单仍处于保障期内。
3. 点「Open Dispute（开启纠纷）」，类型选「仅退款」，理由选「包裹未送达 / 无物流信息」。
4. 按提示填写期望的退款金额（未收到货一般选全额），提交后等待卖家响应。

按官方帮助中心的规则，提交纠纷后**卖家有 5 天时间响应**：5 天内不处理，钱自动原路退回；5 天内谈不拢，AliExpress 平台介入裁决。协商期间你可以接受卖家的方案，也可以等平台给出的方案，任意一方被接受，纠纷即结束、退款进入处理。全程不用付任何费用。

## 三、货不对板怎么开纠纷

商品与描述不符、有质量问题、数量短缺，都走同一条路：

1. **先拍照留证**：商品整体、问题细节、外包装面单，一次拍全；衣物类连吊牌和尺码实测量一起拍。
2. 进订单详情 →「Open Dispute」→ 类型选「退货退款」或「部分退款」。
3. 理由如实选（Not as described / 质量问题等），上传照片或视频，写清「收到的」与「页面描述」差在哪。
4. 提出你接受的方案：全额退货退款、部分退款留下商品，或补发。

卖家可能给出还价（比如只退 30%）。觉得不合理就拒绝并补充证据，协商不成升级平台裁决；平台会按双方提交的材料判，判你赢就按裁定的金额退款。

## 四、纠纷的几种结果

| 结果 | 钱怎么退 | 要做的事 |
| --- | --- | --- |
| 协商达成 | 按协议金额原路退回 | 等退款到账，选退货的按页面给的地址寄回并填单号 |
| 升级后平台判退款 | 按裁定金额原路退回 | 无需再操作，到账周期以支付渠道为准 |
| 升级后平台判不退 | 不退款 | 对结果不服可在期限内申诉一次 |
| 一直不处理到保障期结束 | 平台视同放弃 | 所以别拖，问题出现就动手 |

注意两点：退货退款的运费分担看纠纷裁定，谁的责任谁承担；纠纷期间确认收货按钮会消失，本来就不该在纠纷中确认收货。

纠纷结束后，退款到账时间取决于支付渠道，官方帮助中心给的参考区间：

| 退款去向 | 参考到账时间 |
| --- | --- |
| 电子钱包（PayPal、支付宝等） | 约 1~3 个工作日 |
| 国际银行卡（信用卡/借记卡） | 约 3~10 个工作日 |
| 银行转账 | 约 5~15 个工作日 |

以你的支付渠道实际到账为准；超过区间还没到，先查支付渠道侧的退款记录，再联系平台客服。

## 五、显示「已签收」却没收到怎么办

物流显示妥投但手里没有包裹，按这个顺序处理：

1. **先物理排查**：问一遍同住的家人、邻居、前台或物业，翻门口、快递柜、车棚这类「代收点」，很多所谓丢件最后都在这里。
2. **找承运方要投递凭证**：按跟踪信息里的最后一段承运商，索要签收照片或签收人记录；查不到投递细节就直接说明「非本人签收」。
3. **带着证据尽快开纠纷**：在订单详情里开纠纷、选「未收到货」，把跟踪记录和承运方的答复一起传上去。有渠道提到显示签收后的申诉窗口比普通纠纷短（一种说法是 15 天内），官方口径以订单页提示为准——总之别拖。

## 六、下单时就能做的止损动作

1. **贵重商品录开箱视频**：从带面单的包裹外观一直录到拆开，一镜到底不剪辑，开纠纷时这是最硬的证据。
2. **确认收货前完成验收**：确认收货 = 解冻货款给卖家，之后平台不再受理纠纷，只剩与卖家私下协商。
3. **别接受「私下退款」**：卖家引导你取消纠纷、走站外转账的，一律拒绝——脱离平台保障后，钱货两空没有任何救济渠道。
4. **大促订单尽早查物流**：大促后包裹量激增，问题越早发现越容易在保障期内解决，时间线参考 [物流跟踪与收货时间.md](物流跟踪与收货时间.md)。
