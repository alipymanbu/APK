## 一、为什么要自己配 API

这是这类「酒馆」客户端与传统聊天应用最大的差别：应用只负责界面、角色卡和对话管理，真正生成回复的是你在设置里接入的 AI 模型服务。也就是说——

- **模型费用走你自己的账号**：用哪家模型，就在哪家注册并获取 API 密钥，费用、额度、限流都由该服务商决定；
- **密钥只保存在本地**：密钥填进应用后保存在你手机本地，用于直接调用模型接口；
- **可以配多个连接**：不同角色可以用不同的模型，聊天时切换连接即可。

还没装好应用的，先看 [下载与安装教程.md](下载与安装教程.md)。

## 二、配置步骤

1. 打开应用，点主界面的「API连接」按钮（找不到就从左上角的三横线菜单按钮里进）；
2. 点「新建」；
3. 依次填写：
   - **API密钥**：你在这家服务商后台拿到的 Key；
   - **模型平台**：下拉选择对应服务商；
   - **模型**：选择要用的具体模型；
   - **API地址**：一般留空即可，走服务商默认端点；有自建端点或中转地址时才填；
4. 点「保存」。

保存时应用会自动测试一次连接：「保存成功」表示可以开始用了；「连接失败」按下面第四节的思路排查。

## 三、支持哪些模型平台

官方帮助文档目前列出的平台如下（平台列表会随版本增加，以官方文档当时显示为准）：

| 平台 | 类型 | 说明 |
| --- | --- | --- |
| OpenAI | 商业 | GPT-4、GPT-4o 及 o 系列等 |
| Claude | 商业 | Claude 3 / 3.5 系列 |
| Gemini | 商业 | Google AI Studio 提供的密钥 |
| DeepSeek | 商业 | 深度求索官方 |
| OpenRouter | 聚合 | 一个 Key 调用多家模型 |
| 火山引擎 | 商业 | 字节跳动豆包系列 |
| Ollama | 本地 | 模型跑在你自己的电脑上 |
| KoboldCpp | 本地 | 模型跑在你自己的电脑上 |

商业平台需要在其官网注册并生成 API 密钥（各家的「API Keys」后台页面都有生成入口和计费说明）；本地方案则是在电脑上装 Ollama 或 KoboldCpp 跑模型，手机端连过去，不产生按量费用，但吃电脑配置。

## 四、保存时「连接失败」怎么办

按出现概率从高到低排查：

1. **海外模型没走代理**：OpenAI、Claude、Gemini 这类服务在国内网络环境下直连不通。官方文档明确提示：保存时显示连接失败，请确认网络代理已正确配置后重新保存。代理配在系统层面，或使用你自己的中转地址填在「API地址」里；
2. **密钥填错**：多空格、少字符、拿了错误的 Key 类型，重新复制粘贴一遍；
3. **模型名没选对**：平台选了 A 却填了 B 家的模型，回到「模型」下拉重新选；
4. **账户余额或额度问题**：新注册账号没充值、免费额度用完，也会被服务端拒绝。

改完之后重新保存，看到「保存成功」即可。其他使用中的报错集中在 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 五、怎么选第一家用哪家

官方文档给的建议可以这样理解：

| 你的情况 | 建议 |
| --- | --- |
| 第一次玩，想少花钱 | Gemini 或 DeepSeek，注册门槛低、价格实惠 |
| 追求角色扮演的回复质量 | Claude 或 OpenAI 系列，长对话与角色一致性更好 |
| 有高配置显卡、在意隐私 | Ollama / KoboldCpp 本地跑模型，不依赖外部服务 |

先用便宜模型把流程跑通，之后再按角色需要加配其他连接，是最省事的路径。配好之后，下一步就是给它找个角色：见 [角色卡导入与创建.md](角色卡导入与创建.md)；聊起来之后的进阶玩法在 [聊天功能使用技巧.md](聊天功能使用技巧.md)。
