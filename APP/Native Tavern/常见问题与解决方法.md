## 一、保存 API 配置时提示「连接失败」

最高频的问题，九成与网络有关。官方文档明确说过：使用 OpenAI、Claude 这类海外大模型时，保存显示连接失败，需要确认网络代理配置正确后重新保存。完整排查顺序（密钥、模型选择、余额）见 [API配置与密钥获取.md](API配置与密钥获取.md) 第五节。

## 二、导入 PNG 提示「PNG图片内不包含任何文本块」

这不是应用坏了，是那张图里根本没有角色数据。SillyTavern 体系的角色卡是一张嵌入了设定数据的 PNG 图片，外表看和普通插画没区别，但只有前者能导入。处理办法：

1. 确认下载的确实是「角色卡」文件，而不是角色立绘、头像图片；
2. 换一张来源可靠的角色卡重试；
3. 卡片是 JSON 格式的话，改用「从文件导入」。

角色卡格式与导入方式的对照见 [角色卡导入与创建.md](角色卡导入与创建.md)。

## 三、URL 导入角色失败

官方文档列了三种原因：角色被作者设为私有、平台未授权、链接格式不正确。另外提醒一点：社区站点的「页面链接」不总是「卡片文件链接」，用站点提供的下载/导出功能拿到卡片本身再导入，成功率更高。

## 四、用这个应用要花多少钱

应用本体不收费，真正的开销在你接入的模型服务上：

- **云端 API**：按用量计费，各平台价格与政策自行权衡；Gemini 有免费额度，火山引擎有新用户额度，具体以各平台当时公告为准；
- **本地模型**（Ollama / KoboldCpp）：没有按量费用，代价是电脑硬件与电费。

想完全不花钱，走本地方案，见 [Ollama本地模型连接.md](Ollama本地模型连接.md)。

## 五、手机连不上电脑上的本地模型

最常见的两个原因：手机和电脑不在同一个 Wi-Fi、Ollama 没有开放局域网访问（它默认只接受本机连接）。完整的配置流程与排查表见 [Ollama本地模型连接.md](Ollama本地模型连接.md)。

## 六、数据存在哪里，换手机怎么办

应用的对话记录、角色、密钥等数据都保存在手机本地，不上传到某个账号体系。两点随之而来：

- **卸载应用 = 清空这些数据**，动手前先导出：角色可以逐个长按导出（PNG V3 / CharX / JSON），应用内也提供备份导出功能；
- **换机迁移**靠备份文件，不靠「登录账号」，新手机装好后把备份导回去即可。

因此养成定期备份的习惯，尤其是剧情长了之后。

## 七、网盘这份和官方最新版有什么差别

本文档对应安装包是 **v0.1.4**（2026-09-23 核对，包名 com.miaomiaoxworld.nativetavern，大小 89.75 MB）。官方更新很快，根据官方发布记录，v0.1.10 之后的版本陆续加入了 Live2D 角色互动、长期记忆、RPG 剧本、语音输入与朗读等功能——这些在你手上这份 v0.1.4 里未必存在，遇到「教程里有、界面里没有」的情况先核对版本号。

想用新功能可以去官方发布页取最新版（版本号以官方页面为准）；想用与本文一致的这份，走 [Native Tavern 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2562e010ac57) 即可。
