## 一、先说清楚：装完不等于能直接聊

Native Tavern 本身不内置 AI 模型，它是一个「客户端」：装到手机之后，你还要做两件事才能开始对话——

1. 配置一个 AI 模型的 API 连接（用你自己的密钥）；
2. 导入或新建至少一个角色。

所以本篇只负责把应用装好；装完请接着看 [API配置与密钥获取.md](API配置与密钥获取.md)，再按 [角色卡导入与创建.md](角色卡导入与创建.md) 准备角色。

## 三、下载安装包

从 [Native Tavern 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2562e010ac57) 进入，转存到自己网盘后即可下载 APK 文件。用手机浏览器直接下载最省事；如果是在电脑上下载的，把 APK 传到手机（数据线、局域网传输、云盘中转都可以）再安装。

## 四、安装步骤

1. 在文件管理器或通知栏里点开下载好的 APK 文件；
2. 系统弹出「是否允许安装未知来源应用」之类的提示时，选择允许本次安装（不同品牌手机的入口叫法略有差异，一般在弹窗里直接给「仍要安装 / 允许」按钮）；
3. 等待安装完成，点「打开」或回到桌面点应用图标。

可能遇到的情况：

| 提示 | 处理 |
| --- | --- |
| Play Protect / 安全扫描警告 | 这是安卓对非商店渠道 APK 的例行提示，确认来源可信后选择继续安装 |
| 解析包出错 | 下载不完整或传输损坏，重新下载一次并核对 MD5 |
| 存储空间不足 | 清理出足够空间后重试 |

安装后如果打开闪退、或者需要卸载重装，去 [常见问题与解决方法.md](常见问题与解决方法.md) 对照排查。

## 五、装完第一件事：配 API、备角色

首次打开会进入主界面。按官方帮助中心的推荐路径，上手顺序是「设置 API → 导入角色 → 配置自己的人设 → 开始聊天」。前两步分别对应这两篇：

- API 密钥与连接地址怎么填：见 [API配置与密钥获取.md](API配置与密钥获取.md)；
- 角色从哪来、怎么导入：见 [角色卡导入与创建.md](角色卡导入与创建.md)。

另有一点提前说明：官方要求年满 18 岁并同意相关服务条款后再使用本应用。
