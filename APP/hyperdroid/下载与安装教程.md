## 一、装之前先确认这几件事

| 事项 | 说明 |
| --- | --- |
| 系统版本 | Android 7.0 及以上（第三方商店页面标注的最低版本，实际兼容性以你的设备为准） |
| 屏幕方向 | 手机上不支持竖屏，要在横屏下使用；平板是更合适的设备 |
| 是否需要 root | 不需要。它只是一个启动器应用，普通安装即可 |
| 它不是真 Windows | 你装的是 Windows 11 风格的桌面界面，里面跑的仍是安卓应用，不涉及刷机或装系统 |

## 三、安装步骤

1. 把 APK 下载到手机或平板的存储里。
2. 点开 APK，系统会提示「不允许安装未知来源应用」。到 系统设置 → 应用 → 特殊应用权限（不同机型叫法略有差异）里，给你的文件管理器或浏览器开「允许安装未知应用」。
3. 回到安装界面点「安装」，等待完成。
4. 打开应用。第一次打开时它还像一个普通应用：屏幕切到横屏，出现 Windows 11 风格的桌面、任务栏和开始菜单。

## 四、设为默认桌面（关键一步）

不设默认的话，每次按 Home 键还是会回到原来的安卓桌面，所以这一步建议做。HyperDroid 自己带了设置入口：

1. 点任务栏面板上的齿轮图标，打开 HyperDroid 的 Settings 窗口。
2. 确认在 System 分区，点 Default Launcher。
3. 打开 Enable as launcher 开关。
4. 点 Choose as Default，在系统弹出的「主屏幕应用」选择界面里选 HyperDroid。

不同版本的菜单位置可能略有出入；如果应用内找不到这个入口，走系统设置也一样：系统设置 → 应用 → 默认应用 → 主屏幕应用（Home app），选 HyperDroid。

设好之后，按 Home 键或解锁屏幕就会直接进入 Windows 风格桌面。

## 五、想换回原来的桌面

临时切回去：系统设置 → 应用 → 默认应用 → 主屏幕应用，选回原来的桌面即可，HyperDroid 的设置不会被清掉。彻底不用了：先切回原桌面，再正常卸载 HyperDroid。装完之后碰到小组件不刷新、界面显示异常之类的问题，看[常见问题与解决方法](常见问题与解决方法.md)。
