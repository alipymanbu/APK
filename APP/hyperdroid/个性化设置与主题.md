## 一、设置入口在哪

点任务栏面板上的齿轮图标，打开 HyperDroid 自己的 Settings 窗口。它的分区模仿 Windows 11 设置的样子，常用的几个分区：

| 分区 | 管什么 |
| --- | --- |
| System | 默认桌面开关等系统行为选项 |
| Display（显示） | 缩放、状态栏与导航栏的显隐 |
| Bluetooth & Devices | 蓝牙与外设相关 |
| Personalize | 壁纸、主题、颜色、模糊效果 |
| Apps | 应用管理 |
| Accounts | 账户 |
| Privacy & Security | 隐私与安全 |

改外观主要待在 **Personalize** 里；**Display** 分区管缩放和状态栏的显隐，具体见[隐藏状态栏与导航栏的方法](隐藏状态栏与导航栏的方法.md)；System 里也有影响观感的开关（比如任务栏行为）。

## 二、壁纸、主题色与模糊效果

在 Personalize 分区里逐项调：

1. **壁纸**：换成你自己的图片，桌面整体感觉立刻不一样。
2. **主题**：深色或浅色，配合壁纸选一个。
3. **强调色（accent color）**：开始菜单、任务栏高亮处跟它走，选一个和壁纸协调的颜色。
4. **透明模糊效果**：打开后任务栏和菜单背景带毛玻璃感，和 Windows 11 的观感最接近；设备性能一般时关掉它，滑动会更流畅。

这几项改完即时生效，不用重启应用；不满意就一项项改回去。

## 三、任务栏与开始菜单样式

- **任务栏对齐**：图标居中还是靠左，看你习惯。
- **系统托盘项**：托盘里显示哪些状态图标可以管理，只留你看得懂的，托盘更清爽。
- **开始菜单样式**：菜单的配色与排布风格可以调，配合主题色一起看效果。
- **图标包与日夜模式**：据第三方页面介绍，还支持换图标包、在日间/夜间模式间切换；你的版本里有没有这些选项，以设置里实际显示的为准。

## 四、显示缩放

屏幕小的手机上，默认缩放会让任务栏和窗口显得局促；在 Display（显示）分区里把缩放（scale）往小调一点，同屏能容纳的内容会多不少。平板上则可以把缩放调大，图标和文字更好点。

调缩放时顺手把设备横过来，所有预览都是在横屏状态下看的，手机上竖屏本来就不支持。缩放和状态栏显隐是同一分区的两个选项，搭配着调效果最完整，见[隐藏状态栏与导航栏的方法](隐藏状态栏与导航栏的方法.md)。

## 五、调乱了想恢复

个性化选项没有单独的「恢复默认」按钮，逐项改回默认值即可；实在乱到不想收拾，卸载重装也是一条路——重装会回到初始外观，但你自己加的桌面图标和固定项也没有了。切换回原桌面、卸载的完整步骤写在[常见问题与解决方法](常见问题与解决方法.md)。
