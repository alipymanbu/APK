## 一、这是一份什么安装包

## 二、核对 MD5（可选，但值得做）

APK 体积小、渠道多，校验一次能排除下错包或文件损坏。电脑上用 PowerShell：

```powershell
certutil -hashfile .\HXAudio_v6.0.1001.apk MD5
```

输出的十六进制串与上表一致就没问题。手机上也可以用任意带哈希校验的文件管理器查看。

## 三、安装步骤

1. 把 APK 传到手机（数据线、网盘客户端下载均可）。
2. 用手机自带的文件管理器点开这个 APK。
3. 系统会弹「禁止安装来自此来源的应用」——这是所有侧载安装都会遇到的提示。你只需在弹窗里进入「允许此来源」的开关把它打开（不同厂商叫法略有差别：有的叫「安装未知应用」），再返回继续安装。
4. 安装完成后先别急着点开，先把下一节的权限准备好。

安装不需要 Root，也不需要卸载任何已有应用；升级安装同理，直接覆盖装即可，已调好的参数会保留。

## 四、首次启动要给的两个权限

打开 HXAudio 后会先进入一个权限引导页，按提示把权限授予后点「我已设置完成」进入主界面。它要的权限是这两项：

- **修改音频设置**（`MODIFY_AUDIO_SETTINGS`）—— 用来调整系统音频参数，是音效生效的基础；
- **悬浮窗**（`SYSTEM_ALERT_WINDOW`）—— 用于在后台保留一个窗口让音效服务持续运行。

不同手机的授予路径：

| 手机系统 | 操作 |
| --- | --- |
| 小米 / Redmi（MIUI、澎湃） | 设置 → 应用设置 → 应用管理 → HXAudio → 权限管理，两项都允许；另在「自启动」里打开 |
| 华为 / 荣耀 | 设置 → 应用 → 权限 → 悬浮窗，找到 HXAudio 允许 |
| OPPO / vivo / 一加 / realme | 设置 → 权限隐私 → 悬浮窗管理，允许 HXAudio |
| 原生类（三星、Pixel 等） | 设置 → 应用 → HXAudio → 权限，把「显示在其他应用上层」打开 |

授完权限回到应用，点「我已设置完成」，就能进主界面了。若这一步卡住或授权后闪退，按 [常见问题与无效排查.md](常见问题与无效排查.md) 处理。

## 五、装完之后做什么

进主界面只是第一步，音效不会自己生效——你还要开总开关，并按需把它加入控制中心磁贴，步骤都在 [全局音效开启方法.md](全局音效开启方法.md)。想直接调声音，看 [音效预设与均衡器调节.md](音效预设与均衡器调节.md)。
