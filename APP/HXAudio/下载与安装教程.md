## 一、装之前先弄清楚的两件事

HXAudio 是一款安卓端的全局音效增强工具，原名 HubeRSoundX，开发者是 HuberHaYu。它不需要 Root 权限，装上之后对音乐、视频、游戏等应用的输出统一做音效处理，耳机和扬声器两条通道都管。

在装之前，建议先确认两件事：

1. **手机系统版本**。本地这份安装包的记录标注「需要支持安卓系统 5.2 以上」；公开资料里多提到它面向较新的安卓系统（安卓 11 及以上）做适配。系统偏旧的话能不能正常用，以你实际安装后的表现为准。
2. **版本对应关系**。官方一直在更新，网上能搜到的往往是最新版，而网盘资源里放的是下面这一版。功能界面以你手上装的版本为准。

## 四、安装步骤

1. 在手机上找到下载好的 `.apk` 文件，点它开始安装。
2. 系统弹出「是否安装」确认框时，点继续。
3. 等安装进度走完，点「打开」或回到桌面从图标进入。
4. 第一次打开会进入权限引导流程，照着做完才能正常生效 —— 具体见 [权限设置与首次启动.md](权限设置与首次启动.md)。

## 五、安装时常见的系统提示

不同品牌的安卓系统在装第三方安装包时会给不同的拦路提示，处理思路都一样：确认来源可信后手动放行。

| 系统提示 | 处理方式 |
| --- | --- |
| 禁止安装未知来源应用 | 在弹出的设置页里，允许「来源应用」（浏览器或文件管理器）安装应用，再返回重试 |
| 应用未通过安全检测 / 风险提醒 | 确认 MD5 与上文一致后，选择「仍要安装」（小米澎湃系统常在「纯净模式」里拦，可先关闭纯净模式） |
| 解析包时出现问题 | 安装包没下完整，重新下载后再装，并核对文件大小 |
| 存储空间不足 | 清出至少几倍于安装包体积的空间（安装过程会产生临时文件） |
| 提示「应用未安装」或装完出现两个 HXAudio | 旧版本的包名和现在不同，装新版不会覆盖旧版，先把手机上已有的 HXAudio / HubeRSoundX 卸载干净再装，详见 [版本升级注意事项.md](版本升级注意事项.md) |

装好之后先别急着调音，第一次打开的权限设置决定了它能不能真正生效，继续看 [权限设置与首次启动.md](权限设置与首次启动.md)；装完发现异常的话，直接翻 [音效不生效排查.md](音效不生效排查.md)。
