## 一、这是一款什么应用

装上它之后，你能看到手机里每个应用内部的 Activity（也就是应用的各个界面入口）清单，直接启动其中任何一个，还能给它建桌面快捷方式。它是一款开源的安卓工具（Apache 2.0 协议，源码在 [github.com/sdex/ActivityManager](https://github.com/sdex/ActivityManager)），适合想直达某个深层设置页、或想打开应用里没有按钮入口的页面的进阶用户。

## 二、先核对安装包信息

| 项目 | 值 |
| --- | --- |
| 版本 | 5.4.11 |
| 包名 | com.activitymanager |
| 大小 | 3.54 MB |
| MD5 | 69FC8E24586583A6F51DCFF1861D4421 |

两点提醒：

- 网上能搜到的是官方最新版（F-Droid 渠道已到 5.5.x），与网盘里这份不一定是同一个版本。版本号、体积一律以上表为准，别拿网上的新版本截图对照功能。
- 安装时若提示「解析包出现问题」，先核对文件完整性（电脑上可用 `certutil -hashfile 文件名.apk MD5` 算出值与上表比对），对不上就重新下载。

## 三、安装步骤

1. 从「Activity Manager 安装文件资源（夸克网盘）」（[https://pan.quark.cn/s/dc74ec1165ee](https://pan.quark.cn/s/dc74ec1165ee)）把 apk 转存到自己网盘后下载到手机，或直接下载到本机存储。
2. 在手机上点开 apk。安卓 8.0 之后系统会问「是否允许这个来源安装应用」，选择允许；如果你是用某个文件管理器打开的，就给那个文件管理器授权。
3. 装完点打开。第一次启动会请求「查看所有已安装应用」之类的权限，允许后应用列表才会加载出来。

## 四、系统要求

- 手机、平板都能用。相近版本的官方元数据显示：5.4.15 要求 Android 5.0 以上，5.4.16 起要求 Android 6.0 以上；你手上这份 5.4.11 更早，具体以安装时的系统提示为准。
- 官方渠道的包覆盖 arm64-v8a / armeabi-v7a / x86 / x86_64 四种架构（以渠道页实际标注为准），常见手机（arm64）都在覆盖范围内。

## 五、以后想用新版本怎么办

官方渠道有三个，都能拿到最新版：

- GitHub Releases：[github.com/sdex/ActivityManager/releases](https://github.com/sdex/ActivityManager/releases)（作者推荐的方式）
- F-Droid：[f-droid.org/packages/com.activitymanager](https://f-droid.org/packages/com.activitymanager/)
- 用 Obtainium：装好 Obtainium（从它的 GitHub 发布页安装）后添加仓库地址 `github.com/sdex/ActivityManager`，它就会盯着 Releases，出新版时自动装到手机（以应用内提示为准）

新版本的主要变化（截至 2026-09，以官方页面为准）：5.4.16 起要求 Android 6.0+；5.5.0 起支持用 Shizuku 免 root 启动未导出 Activity——配套的 Shizuku 搭建另见 [Shizuku 免 root 启动方法.md](Shizuku%20免%20root%20启动方法.md)，版本差异对使用的影响见 [启动隐藏 Activity 的方法.md](启动隐藏%20Activity%20的方法.md)。
