# 常见问题与故障排查

> 本篇把 Activity Manager 用起来最常见的几类问题按现象排好：点了没反应、报安全异常、快捷方式建不出来、安装报错、同名应用分不清。

## 一、点了 Activity 没反应或秒退

最常见的现象，原因几乎都是「这个页面需要调用方传参数」：

- 直接启动等于不带任何参数的「裸启动」，需要账号状态、条目 ID、网址之类参数的页面拿不到就自己退出。
- 判断办法：同一个应用里大多数点得开、唯独个别打不开，基本就是缺参数。
- 出路：要么放弃这个入口，要么用 Intent Builder 补上参数再启动，做法见 [自定义 Intent 与 Manifest 查看.md](自定义%20Intent%20与%20Manifest%20查看.md)。

## 二、报 SecurityException（安全异常）

- 未导出 Activity 被系统拦下时就会报这个。5.4.x 这一代只有 root 一条路，授权弹窗记得允许；不想 root 就更新到 5.5.0 以上用 Shizuku，搭建步骤见 [Shizuku 免 root 启动方法.md](Shizuku%20免%20root%20启动方法.md)，两种路线的取舍见 [启动隐藏 Activity 的方法.md](启动隐藏%20Activity%20的方法.md)。
- root 之后仍报异常：先确认 root 授权管理器里没有永久拒绝；再确认 ROM 没有额外限制（部分厂商系统对系统应用组件有白名单）。

## 三、快捷方式建不出来或消失

- 建的时候没弹窗也没图标：去系统设置的权限页找「桌面快捷方式 / 创建快捷方式」，部分国产系统默认拒绝，手动允许后重试。
- 重启或换启动器后图标没了：快捷方式由启动器保管、不随应用迁移，重新建一次即可。
- 图标在但点了没反应：多半是第一节说的缺参数问题，或该入口需要 root（旧版快捷方式不带 root 启动，5.4.22 起才可选）。

## 四、安装环节的问题

- 提示「解析包出现问题」：先核对 MD5（安装包信息与校验命令见 [下载与安装教程.md](下载与安装教程.md)），对不上就重新下载；核对无误仍报错，再确认系统版本满足要求。
- 安装后应用列表是空的：首次打开时拒绝了「查看所有应用」权限，去系统设置里允许后重新打开应用。

## 五、搜出来的同名应用分不清

叫 "Activity Manager" 的安卓应用不止一款，认包名最可靠：

- **Activity Manager（开源版）**：包名 `com.activitymanager`，GitHub 项目 sdex/ActivityManager，就是本套文档讲的这款。
- 另有一款同名应用由 André Ferreira de Sousa 开发，包名 `com.andrefrsousa.tools.activitymanager`，同样是隐藏 Activity 启动器但不是同一款，界面与设置互不通用。
- 还有更早的 Activity Launcher（包名 `de.szalkowski.activitylauncher`），走「列出并启动 Activity」思路的工具，名字里没有 manager 但常被一起搜到。

认准包名 `com.activitymanager` 再对号入座，别拿另一款的教程硬套。

## 六、权限与隐私

官方渠道（F-Droid）的权限元数据里列的是查看应用列表、创建快捷方式这类本地权限（以你安装版本的实际申请为准）。5.5.0 起，渠道页的权限清单里另出现 Shizuku 接口、重排任务与写入安全设置几项，对应的是免 root 启动与扩展设置功能（以渠道页为准）。代码开源，介意的可以自己审：[github.com/sdex/ActivityManager](https://github.com/sdex/ActivityManager)。
