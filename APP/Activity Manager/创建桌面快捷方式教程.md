## 一、为什么要做快捷方式

直启一个深层页面，每次都要：打开 Activity Manager → 搜应用 → 翻清单。做成桌面图标后一步直达，适合每天都用的入口，比如某个打卡页、某项常用设置。

## 二、创建步骤

1. 在应用列表里点进目标应用，找到要做成图标的那个 Activity。
2. 选择创建快捷方式（长按条目或点条目右侧菜单，以你手上的版本界面为准）。
3. 起一个你认得出的名字——默认名是 Activity 的技术名称，建议改成中文或好认的说法。
4. 图标二选一：从手机存储里选一张图片，或直接用内置的 Material 图标。
5. 确认后图标会加到桌面。没出现的话先看是不是桌面没有空位、或启动器没刷新。

## 三、快捷方式的几个限制

- 旧版本的快捷方式走的是普通启动（不带 root），所以未导出 Activity 做成图标后点了多半打不开，只能在应用内启动；5.4.22 起官方加了「快捷方式里用 root 启动」的选项。
- 部分国产系统的启动器对「创建桌面快捷方式」有独立权限开关，第一次弹窗被拒过就一直建不出来，去系统设置里把 Activity Manager 的这项权限打开再试。
- 换了启动器（桌面）之后旧图标可能消失——快捷方式由启动器保管，不随应用迁移，回到 Activity Manager 重新建一次即可。
