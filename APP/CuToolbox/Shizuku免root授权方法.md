# CuToolbox 免 root 授权：Shizuku 配置方法

> 没有 root 的手机打开 CuToolbox 会提示设备未 root，本篇讲怎么用 Shizuku 绕开这道门槛：通过安卓的无线调试或电脑 ADB 把权限借给它。装应用本身的步骤在 [下载与安装教程.md](下载与安装教程.md)，配完还报错的去 [常见问题与报错排查.md](常见问题与报错排查.md)。

## 一、两条授权路线，先选一条

| 路线 | 前提 | 适合谁 |
| --- | --- | --- |
| 真 ROOT | 已刷入 Magisk / KernelSU 等并解锁了 root | 已经刷过机的设备，直接在弹窗里允许即可，不用看本篇 |
| Shizuku | 无需 root；安卓 12 以上可全程在手机上完成 | 不想解锁 Bootloader、或机型根本无法 root 的设备 |

Shizuku 是一个独立的第三方工具（与 CuToolbox 不是同一开发者），它的作用是借安卓的调试通道拿到接近 root 的执行能力。你需要在手机上另外安装 Shizuku 的 APK，从它的官方页面或应用商店获取。

## 二、无线调试配对（安卓 12 以上，全程手机操作）

1. 打开系统设置，进入「关于手机」，连点版本号七次开启开发者选项；这一步本来就开过的跳过。
2. 进「系统 → 开发者选项」，找到并打开「无线调试」，注意这一页不能关，Shizuku 运行期间它得保持开启。
3. 点「使用配对码配对设备」，屏幕会弹出一组配对码和一个「IP 地址与端口」。
4. 打开 Shizuku，选择无线调试配对，把上面的 IP、端口和配对码填进去确认。
5. 配对成功后回到 Shizuku 主界面点「启动」，状态变成运行中就绪了。
6. 这时再打开 CuToolbox，它会通过 Shizuku 拿到权限，不再报未 root。

## 三、电脑 ADB 方式（老系统或无线配对失败时）

安卓 12 以下的设备走不了无线配对，需要一台电脑：

1. 手机开启 USB 调试（同样在开发者选项里），用数据线连上电脑，并在弹窗里允许调试。
2. 电脑上装好 ADB 工具后，按 Shizuku 应用内「通过连接电脑启动」页面给出的指引执行对应的启动命令——Shizuku 各版本的具体命令写法有差异，以你手上那个版本的应用内说明为准，不要照抄网上旧帖。
3. Shizuku 显示运行中后，拔掉数据线也可以，再打开 CuToolbox 授权。

## 四、配好之后要知道的几件事

- **手机重启后 Shizuku 不会自己爬起来**：重启一次就要重新点一次「启动」。无线调试的配对关系一般会保留，不用重新配对码那一套；个别系统重启后连「无线调试」开关本身都会复位，需要重新打开。以 Shizuku 应用内的提示为准。
- **Shizuku 没在运行时 CuToolbox 也用不了**：两者是依赖关系，用之前瞄一眼 Shizuku 状态。
- **想免 Magisk 开机自启**：CuToolbox 自带这个选项，见 [下载与安装教程.md](下载与安装教程.md) 第五节。
- **授权配好后功能不生效**：先确认处理器在 [支持的处理器型号清单.md](支持的处理器型号清单.md) 里，再按 [常见问题与报错排查.md](常见问题与报错排查.md) 逐项排查。
