# CuToolbox 支持的处理器（SoC）型号清单

> CuToolbox 是按处理器平台做适配的，你的芯片不在列表里，调度装上也白装。本篇收录各平台支持的具体型号、教你怎么确认自己手机的芯片，以及不在列表内时的替代思路。机型能不能装本体见 [下载与安装教程.md](下载与安装教程.md)；芯片确认没问题后去 [调度模式怎么选.md](调度模式怎么选.md) 挑模式；装完不出效果按 [常见问题与报错排查.md](常见问题与报错排查.md) 排查。

## 一、先确认你手机用的什么芯片

任选一种：

- 系统设置 → 关于手机 → 看「处理器」一栏，会写明平台与型号（如 Qualcomm Snapdragon 870）。
- 装一个 CPU 检测类小应用，读 SoC、核心布局最准，还能顺带确认是不是 arm64。
- 直接拿机型去搜参数页，看 SoC 字段。

## 二、支持型号一览

以下清单为社区广泛流传的适配范围，覆盖六大平台；官方后续会随版本更新增删，**以官方仓库当时发布的说明为准**。

| 平台 | 支持型号 |
| --- | --- |
| 联发科 曦力（Helio） | P60、P65、P70、P90、X10、G80、G85、G90、G90T |
| 联发科 天玑（Dimensity） | 700、720、800U、820、900、920、1000+、1000L、1100、1200、8100、9000 |
| 高通 骁龙（Snapdragon） | 4xx 系未收录；625、626、636、650、652、660、662、665、675、710、720、730、750、765、778、780、820、821、835、845、855、865、870、888、8 Gen1、8+ Gen1 |
| 海思 麒麟（Kirin） | 650、655、658、659、710、950、955、960、970 |
| 紫光展锐（UNISOC） | SC9863A、T618 |
| 三星 猎户座（Exynos） | 9820、9825、990、1080、2100、2200 |

从表里能看出的大致规律：中端与上一代旗舰覆盖最全；骁龙 8 Gen2 之后的最新旗舰、麒麟 970 之后的型号不在这份清单里。

## 三、不在清单内怎么办

- **先别装**：调度不匹配时轻则不生效，重则出现异常行为，装了也是浪费时间，直接回 [常见问题与报错排查.md](常见问题与报错排查.md) 看有没有对应说明。
- **等更新**：官方会随版本扩展适配范围，关注官方仓库的 Releases 页面，出新版后再回头看这份清单。
- **确认无误会更准**：同一颗芯片在不同品牌机型上表现未必一样，有用户反馈个别机型即使 SoC 在列表内也可能遇到兼容性问题，最终以你设备上的实际运行为准。

芯片确认没问题后，下一步就是挑模式：去 [调度模式怎么选.md](调度模式怎么选.md)。
