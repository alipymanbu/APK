## 一、建歌单与加歌

1. 播放任意一首歌，打开播放页。
2. 点菜单（三横线），在歌曲旁找到 **+** 号。
3. 选「加入播放列表」→ 已有歌单直接点，没有就选「新建播放列表」起个名字。
4. 确认，歌就进去了。

菜单入口的图标随版本略有差异，认不准就对照文末的图标表。

## 二、排序与队列

- **歌曲列表排序**：点歌曲数旁的小箭头，单击 = 升序/降序切换；**长按**箭头 = 换排序类别（标题、艺人、最常听、加入顺序等），排序会应用到该菜单的所有标签页。
- **专辑内排序**：点箭头切升降序，点箭头旁的当前类别名换排序方式。
- **艺人列表排序**：与歌曲列表一致，点艺人数量旁的箭头操作。
- **播放队列**：队列是**持久**的——退出应用再回来，队列还在；歌序可拖动调整；不想接着上次就一键清空队列。

## 三、导入 Spotify 歌单（官方 FAQ 给的流程）

1. 打开 [exportify.app](https://exportify.app/)，界面语言**切到 English**（官方 FAQ 特意强调这一步，导出格式与之相关）。
2. 导出你要的歌单，下载得到 `.csv` 文件。
3. 在 RiMusic 里导入该 csv。
4. 打开导入后的歌单，**等它把歌匹配完**——匹配结束前列表可能不完整，属正常。

## 四、RiMusic 歌单的导入导出与分享

RiMusic 支持导入在线歌单，也支持把自己的歌单导出分享给别人（README 的 Import/Export online 功能）。另外两种 csv 格式供手动处理时对照：

```text
# 通用歌单 csv（字段用分号分隔）
Track Name;Artist Name(s);Album Name;Track Duration (ms);Explicit

# Library 导入 csv（首行为字段名）
PlaylistBrowseId;PlaylistName;MediaId;Title;Artists;Duration;ThumbnailUrl
```

csv 是纯文本，用记事本或表格软件都能编辑。

## 五、从 ViMusic 搬过来

老 ViMusic 用户：在 ViMusic 里先建一份备份，再进 RiMusic 的**设置 → Database（数据库）**用恢复功能导入，歌单与收藏都能带过来（官方 FAQ 确认的路径）。

## 六、换手机前的备份（最重要的一节）

RiMusic 没有云同步，歌单、收藏、播放统计**全存在这台手机里**，清数据或换机就是清零。导出路径：

**右上角菜单 → Settings（设置） → Data（数据） → Save a backup（保存备份）**

生成的备份文件存到手机存储里，拷到新设备后同样在 Data 里用恢复导入。备份的内容不只歌单——播放历史与统计也一并带走，恢复完接着记。养成隔段时间导一次的习惯，比出事再补救强。

## 七、菜单图标对照

官方 Wiki 给了一张图标含义表，认不准的菜单项查这里：

| 图标 | 含义 |
|---|---|
| 实心下载箭头 | 全部下载 |
| 描边下载箭头 | 移除全部下载 |
| 入队图标 | 加入队列 |
| 洗牌图标 | 随机播放 |
| 锁形图标 | 锁定/解锁歌单排序 |
| 三点图标 | 歌单菜单 |
| 放大镜 | 在歌单内搜索 |
| 加号 | 加入歌单或导入歌单 |
| 书签 | 收藏艺人/专辑 |
| 定位图标 | 跳回正在播放的那首 |

自 0.6.22 起，原先分散的「按最近播放/按标题/按最常听」等排序图标统一并入了排序菜单，老教程里的那几个箭头图标可能已经找不到，属正常。
