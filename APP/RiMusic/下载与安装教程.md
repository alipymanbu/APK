## 一、RiMusic 是什么

RiMusic 是一款开源的安卓音乐播放器（GPL-3.0 许可），曲库来自 YouTube Music，在 ViMusic 的基础上发展而来，开发者是 GitHub 上的 fast4x。它不设账号体系，歌单、收藏与播放记录都存在手机本地。下表是**网盘里那一份**的事实，官方最新版可能与它不是同一版（官方发布以页面当时显示为准）：

| 项目 | 值 |
|---|---|
| 版本 | 0.6.70 |
| 包名 | it.fast4x.rimusic |
| 安装包大小 | 17.56M |
| MD5 | `9F8F83F868CF9BD3A7F6110D39BDC9B6` |
| 系统要求 | Android 5.2 及以上（部分资料写作 Android 5+，以安装时提示为准） |
| 记录于 | 2026-09-24 |

**项目现状（装之前先知道）**：官方仓库 [github.com/fast4x/RiMusic](https://github.com/fast4x/RiMusic) 的 README 已标注项目关闭，官方不再发布新版本（截至 2026-09 查询，以官方页面为准）。这不影响已装好的应用继续使用，遇到异常先按 [常见问题与排查.md](常见问题与排查.md) 处理。

## 二、从网盘拿到安装包

1. 打开 [RiMusic 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9822c0485bd7)，把文件夹转存到自己的网盘。
2. 在网盘里下载 `RiMusic_v0.6.70.apk` 到手机（或先下到电脑再传到手机）。
3. 下载完成后核对 MD5 是否与上表一致，防止传输中文件损坏。

## 三、安装

1. 点击 APK 文件开始安装。
2. 系统会提示「禁止安装来自此来源的应用」——所有商店外应用都会遇到。你在用哪个应用打开 APK（浏览器、文件管理器），就在设置里允许**那个应用**安装未知应用（Android 8.0 起按应用单独授权）。
3. Google Play Protect 可能弹「有害应用」警告并阻止安装。RiMusic 不在 Play 商店上架，开源项目只通过自有渠道分发，这类警告对商店外应用是常态；确认安装包来源没问题后选择继续安装即可。
4. 装完打开应用。首次启动不需要登录，直接进主界面。

## 五、装完先知道的三件事

- **不用登录，数据都在本机**：换手机或清掉应用数据前要先做备份，步骤见 [播放列表导入与备份恢复.md](播放列表导入与备份恢复.md)。
- **在线播放取决于你的网络**：能不能在线播，取决于你当前网络能否正常访问 YouTube Music；已下载与已缓存的内容不受影响，见 [离线缓存与歌曲下载.md](离线缓存与歌曲下载.md)。
- **升级**：设置里有「检查更新」开关，项目关闭后已无新版本，可以关掉省得每次联网空查；手动升级就是下载新 APK 覆盖安装，包名一致、数据保留。版本号按 `0.6.x` 递增，项目停止维护前的发布节奏是每周五一版（历史口径，以官方页面为准）。两个历史坑顺带说明：自 0.6.46 起官方按分发渠道出了不同构建（如 Accrescent 版没有「检查更新」按钮），**0.6.46 及更早版本无法用应用内更新升上去**（APK 改名导致，官方 FAQ 与 issue #3066 有记载）——手里是这类老版本就直接用新 APK 覆盖装；网盘这份 0.6.70 在该分界之后，不受影响。
