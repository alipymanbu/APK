## 一、把界面切成中文

RiMusic 自带数十种语言，含**简体中文**与**繁体中文**（自 0.6.16 版起加入中文翻译）。切法：

1. 打开应用，进右上角的菜单 → **Settings（设置）**。
2. 在设置里找到界面相关的分页（菜单名随版本略有差异，一般标着 `UI` 或带有语言字样的条目）。
3. 选 **Language / 语言**，列表里挑 `Chinese Simplified`（简体中文）或 `Chinese Traditional`（繁体中文）。
4. 界面文字即时切换，不用重启。

设置项旁边会标注当前系统语言代码，方便你确认有没有改对。语言列表取自官方 README 的翻译清单，具体选项以你的版本实际显示为准。

## 二、换主题与界面风格

主题与界面风格在同一块设置区域里：

| 想要的效果 | 怎么设 |
|---|---|
| 浅色界面 | 主题选 **Light** |
| 深色界面 | 主题选 **Dark** |
| 跟随系统取色 | 主题选 **Dynamic**（动态取色） |
| 纯黑界面 | 主题选 **PureBlack** |
| ModernBack 风格 | 主题选 **ModernBack** |
| 换回老 ViMusic 的界面布局 | **UI Mode** 在 RiMusic 风格与经典 ViMusic 风格之间切换 |

UI Mode 只改布局与视觉风格，歌单、下载、设置项都保留——切过去不满意随时切回来。

## 三、几个值得顺手调的开关

- **播放时保持屏幕常亮**：设置里名为 Keep Screen On 的开关。打开后播放中屏幕不灭（手机会因此更耗电，走路听歌再开）。
- **音频可视化效果**：默认关闭。它要用到麦克风权限，只有你主动在设置里打开才会申请录音权限——不开就完全不涉及麦克风，权限说明见 [常见问题与排查.md](常见问题与排查.md)。
- **检查更新**：设置里的 Check for Updates 开关。项目已停止维护、不会再出新版本，关掉可以省掉每次启动的联网检查。
- **睡眠定时**：设置里可自定义时长的 Sleep timer，到点自动停止播放，睡前听歌定个 30 分钟就不用半夜起来关。
- **桌面挂件**：官方标注为实验性功能，在系统的桌面挂件列表里找 RiMusic 添加即可；加不上属正常，不影响应用内使用。

## 四、界面操作先认这几个入口

- 右上角**三横线菜单**是设置与各类管理入口的总闸门，语言、主题、数据备份都在里面（备份做法见 [播放列表导入与备份恢复.md](播放列表导入与备份恢复.md)）。
- 播放页底部是常驻播放器，**长按播放/暂停键**会打开音频控制面板：应用音量、设备音量、播放倍速、音调都在里面，默认值是 1.0x（100%），改完即时生效。
- 找不到某个功能时优先翻设置的各个分页，RiMusic 把开关类选项都收在设置里，界面上不单放按钮。
