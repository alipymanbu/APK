## 一、暂停一会儿，应用就被系统关掉了

这是安卓的后台回收机制在起作用，官方 FAQ 给的对策两步：

1. 在 RiMusic 设置里打开 **Invincible Service**（常驻服务）。
2. 到系统「设置 → 应用 → RiMusic → 电池」里**取消电池优化**（不同厂商菜单名可能是「省电策略」「后台运行」，选不限制）。

两步都做完，长时间暂停后再回来应用还在内存里。

## 二、在线播放失败 / 提示没有网络

按顺序排查：

1. **先确认网络本身能访问 YouTube Music**——RiMusic 的在线曲库就是它，网络侧不通时应用内怎么点都没用；这属于网络环境问题，本文不展开解法。首页推荐内容变空、只剩本地内容，通常也是同一原因的伴随症状。
2. 网络没问题的话，**有用户反馈**：试着点一首非下载的歌让它失败一次，然后把应用完全关闭再打开，能恢复正常（论坛里多人反馈这个「重启应用」的做法有效）。
3. 也有用户反馈：清掉应用缓存后恢复——两种做法都试一遍，哪个管用用哪个。
4. 只有已下载的歌能播、在线内容全失败的情况，对照上一条仍无效时，先确认应用没被限制联网（系统「流量使用」里允许它用 WLAN/数据）。

## 三、播放到 60 秒左右自己停了

官方仓库有同类反馈（[issue #5758](https://github.com/fast4x/RiMusic/issues/5758)），不同机型上表现不一。项目已停止维护（见 [下载与安装教程.md](下载与安装教程.md)），没有官方修复；可先试第二节的重启与清缓存办法，仍无改善就把歌下载下来离线听（见 [离线缓存与歌曲下载.md](离线缓存与歌曲下载.md)）。

## 四、锁屏上没有专辑封面（Android 11 及以上）

不是 RiMusic 的 bug：安卓 11 起系统移除了锁屏专辑封面的展示能力（Android 5~10 一直有），应用层面补不回来。官方 FAQ 引用了 9to5Google 的相关报道说明此事，可自行检索核对。

## 五、Android Auto 里看不到 RiMusic

最快的三步：① RiMusic 设置 → Miscellaneous 里确认 Android Auto 开关已开；② 手机 Android Auto 设置开开发者模式并勾选 **Unknown sources**；③ Customize launcher 里勾上 RiMusic。完整步骤与连不上时的排查顺序，见专门的 [AndroidAuto连接车机教程.md](AndroidAuto连接车机教程.md)。

## 六、能播视频吗

不能。官方 FAQ 明确：RiMusic 不支持视频播放，只有音频。搜索结果里出现视频条目属于正常，点播放也只会出声音。

## 七、崩溃了怎么取日志

应用自带日志开关，**必须先打开才能录到崩溃**：

1. Settings → Miscellaneous → Debug。
2. 打开 **Enable debug logs**。
3. 重启应用。
4. 复现一次问题。
5. 回到同一位置，用按钮把日志复制到剪贴板。

开关打开之前发生的崩溃取不到，别跳过第 1、3 步。

## 八、它要的权限都是干什么的

常见几项（完整表在官方 Wiki 的 FAQs 页）：

| 权限 | 用途 |
|---|---|
| 网络 / 网络状态 | 联网播放与连接检查 |
| 前台服务 | 灭屏、切后台后继续放歌 |
| 通知 | 前台服务需要通知栏常驻 |
| 开机启动 | 重启手机后恢复服务 |
| 电池优化豁免 | 配合上面第一节，防止被杀 |
| 读取音频媒体 | 读取手机里的本地歌曲 |
| 录音 | **只在你打开音频可视化时才申请**，默认不启用 |

官方声明 RiMusic 不收集任何个人数据；数据都存在本机，备份方法见 [播放列表导入与备份恢复.md](播放列表导入与备份恢复.md)。界面语言和主题相关问题不在本篇，见 [设置中文界面.md](设置中文界面.md)。
