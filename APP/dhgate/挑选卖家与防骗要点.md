## 一、DHgate 是集市，不是自营店

先建立正确认知：平台本身不卖货，货是第三方卖家发的——**同一款商品，不同卖家的品质与履约差别可以非常大**。你买到的东西取决于你选的卖家，这句话比任何功能介绍都重要。

## 二、下单前三步筛选

1. **看卖家等级与交易量**。官方博客给出的分级（截至 2025 年 4 月口径，具体等级名称以商品页当时显示为准）：

   | 等级 | 交易量区间 |
   | --- | --- |
   | New | 0–50 笔 |
   | Bronze | 50–500 笔 |
   | Silver | 500–5,000 笔 |
   | Gold | 5,000–50,000 笔 |
   | Platinum | 50,000 笔以上 |

   金额较高的单（官方博客举例 $100+）优先选 Gold / Platinum 且开店时间久的店铺。

2. **读评价，重点读差评**。翻**近 3 个月**的评价看当前状态；优先看**带图带视频**的；差评里找规律——多人反馈「没收到货」是物流问题，「货不对板」是库存/诚信问题，「卖家不回」是售后问题。官方防骗指南同样把评价与评分列为第一判断依据。
3. **核验证照与商品页**。DHgate 允许核验卖家的营业执照与资质（店铺页有蓝色认证标识的可去国家企业信用信息公示系统对一下）；商品页描述详尽、图为高清实拍的更可信，图模糊、文案错漏连篇的要警惕。

拿不准就先问——商品页或订单里的 Chat / Message 把材质、发货时间、退换政策问清楚再下单，可靠卖家通常 24 小时内给详细答复（官方博客口径，实际仍以对方响应为准，参考窗口 48 小时）。

## 三、四类常见骗术与对策

| 骗术 | 长什么样 | 你的对策 |
| --- | --- | --- |
| 假商品页 | 商品根本不存在或与描述完全不符 | 只在站内下单；下单前用以图搜图核对商品照是否盗自别家 |
| 以次充好 | 页面是高配、发来是低配 | 收货开箱录视频；不符立即在 21 天窗口内开纠纷 |
| 钓鱼邮件/消息 | 冒充 DHgate 索要账号、卡号 | 官方不会邮件要你的卡号与密码；可疑链接先核对域名 |
| 站外交易诱导 | 卖家/陌生人要求加私下转账拿「更低价」 | 一律拒绝——脱离平台付款等于放弃买家保护 |

另外两条硬规则：

- **支付只走平台结算页**（DHpay 或卡通道），这是托管式付款：确认收货前钱不放给卖家；
- **警惕不现实的低价**——同款比别家低得离谱，通常就是上面几种情况的入口。

## 四、出事后的止损顺序

先按 [退款申请与纠纷处理.md](退款申请与纠纷处理.md) 的时限发起纠纷，再慢慢交涉；发货迟迟不动的对照 [物流跟踪与订单查询.md](物流跟踪与订单查询.md) 判断是延迟还是压根没发。所有与卖家的沟通留在站内 Message 里——纠纷仲裁时，站内聊天记录就是证据。
