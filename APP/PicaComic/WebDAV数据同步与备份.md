## 一、它管什么、什么时候需要它

WebDAV 同步解决的是「应用数据只存在本机」的问题。开启后，收藏、阅读历史这类数据会上传到你指定的一个 WebDAV 空间，换手机、重装应用、双机使用时都能拉回来。

适合配它的场景：

- 准备换手机或刷机，想先把数据保住；
- 手机和平板都想用，希望收藏与阅读进度两边一致；
- 单纯想把本地收藏定期备份一份，防手滑。

注意边界：**已下载的漫画文件不参与 WebDAV 同步**，能同步的是收藏、历史这类轻量数据（以应用内同步项的实际显示为准）。

## 二、准备一个 WebDAV 空间

WebDAV 是一种网盘访问协议，你需要一个支持它的网盘或自建服务，拿到三样东西：

1. **服务器地址**：形如 `https://dav.example.com/dav/` 的 URL；
2. **账号**；
3. **密码（或应用专用密码）**。

不少网盘服务对第三方应用要求使用「应用密码 / 授权密码」，而不是网页登录密码，这一点配置失败时十有八九是它引起的，先去服务商的账号安全设置里确认要不要单独生成。

## 三、在 PicaComic 里配置

1. 打开应用，进入设置，找到数据同步 / WebDAV 相关选项（版本不同入口名称略有差异，以应用内实际界面为准）；
2. 依次填入服务器地址、账号、密码；
3. 先做**连接测试**，通过了再执行一次「上传 / 推送」，把当前设备的数据完整推上去；
4. 换到另一台设备装好后，填同样的三项，执行「下载 / 拉取」，数据就回来了。

双向使用时记住方向别搞反：旧设备做上传、新设备做下载；两边都改过数据再互相同步，后写的一方可能覆盖先写的一方，同步前想清楚哪边是最新。

## 四、连不上 / 同步失败，按报错对号入座

| 现象 | 先查什么 | 处理 |
| --- | --- | --- |
| 连接测试直接失败 | 地址拼写、是否漏了 `https://` 或结尾路径 | 按服务商给的原始地址一字不差地填，别自己拼 |
| 提示 401 / 认证失败 | 密码类型用错 | 该用应用密码的服务别填登录密码，重新生成一个 |
| 能连上但上传失败 | 空间是否已满、目录权限 | 清理空间或换个目录再试 |
| 一台能同步另一台不行 | 两台设备的配置是否一致 | 逐字符核对三项配置，注意首尾空格 |

排查完仍然失败的，把地址换到另一个 WebDAV 服务试一次就能区分是配置问题还是服务问题。配置成功但数据「不对」的（比如收藏少了），多是你没做「先上传、后下载」的顺序，重做一遍即可。

不依赖 WebDAV 的替代方案也有一个：应用自带数据导入 / 导出功能（4.0.4 更新日志里有相关修复记录），适合换机时一次性整包搬走，但平时防手滑还是同步更省心。其他应用层的问题汇总在[常见问题与解决办法.md](常见问题与解决办法.md)。
