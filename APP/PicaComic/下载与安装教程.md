## 一、先弄清楚这是个什么应用

PicaComic 是一个开源的漫画阅读应用，源码托管在 [GitHub 仓库](https://github.com/wgh136/PicaComic)，采用 MIT 许可证。它的特点是聚合多个漫画源：内置了 picacg、E-Hentai、JM Comic、Hitomi 等源（以应用内实际列表为准），从 3.0.0 版本起还支持添加自定义漫画源。除了安卓，它也有 Windows、iOS 等其他平台的版本；本套文档以及网盘里的安装包，对应的都是**安卓版**。

两件与「装不装」直接相关的事，先摆在前面：

- **项目维护状态**：截至 2026 年 9 月，官方仓库页面已标注项目不再继续维护，作者推荐使用新项目 venera（[https://github.com/venera-app/venera](https://github.com/venera-app/venera)）。官方的最后一次正式发布就是 v4.0.4（2024 年 9 月），你拿到的这份即是官方最终版——装上正常用没问题，只是后续不会有新版本。
- **官方发布页长什么样**：官方渠道是 GitHub 仓库的 [Releases 发布页](https://github.com/wgh136/PicaComic/releases)，上面列着历次发布的版本；注意 v4.0.4 这个发布并没有附带现成的 APK 附件，安装包要么自己从源码构建，要么用你已拿到的网盘资源。

## 三、把安装包拿到手

1. 打开开头的 PicaComic 安装文件资源（夸克网盘）链接；
2. 把文件转存到自己的夸克网盘（首次会提示登录）；
3. 在手机上打开夸克网盘客户端，找到转存的 APK 文件点下载；或者先在电脑上下载，再用数据线、局域网传输等方式传到手机。

到手的东西是一个 `.apk` 文件，文件名里通常带版本号。放在手机「下载」目录里即可，下一步直接安装。

## 四、安装：要过「未知来源」这一关

安卓不允许应用商店之外的应用直接安装，第一次装时会遇到拦截，这是系统机制，不是安装包坏了：

1. 在文件管理器里点开 APK，系统会问「是否允许从此来源安装应用」；
2. 选择允许该来源（一般是你的文件管理器或浏览器）安装；
3. 回到安装界面点「安装」，等待完成。

不同厂商的设置入口叫法不一样，卡住了就去这些地方找：

| 厂商 | 常见入口 |
| --- | --- |
| 小米 / 红米 | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用；鸿蒙系统的「纯净模式」可能需要先关闭 |
| OPPO / vivo | 设置 → 安全 → 安装未知应用（或「权限与隐私」里） |
| 三星 | 设置 → 应用程序 → 右上角菜单 → 特殊权限 → 安装未知应用 |

装完首次打开如果闪退、卡白屏，或安装过程本身报错，看[常见问题与解决办法.md](常见问题与解决办法.md)里的对应条目。

## 五、（可选）校验一下安装包没被调包

如果你对文件完整性有要求，可以核对 MD5 值，应等于第二节表格里的 `40c7013496a11f87578bc183dfad2356`：

- **在电脑上**（Windows）：按 `Win+R` 输入 `cmd` 回车，执行下面的命令，路径换成你实际的文件位置：

  ```powershell
  certutil -hashfile "C:\Users\你\Downloads\PicaComic_v4.0.4.apk" MD5
  ```

- **在手机上**：部分文件管理器（如 MT 管理器）自带「校验 / 属性」功能，长按文件即可查看 MD5。

对不上就重新下载一遍再校验；还对不上就别装这个文件。

## 六、第一次打开

装好打开后，建议按这个顺序做两件事：

1. **选一个漫画源**：PicaComic 的内容来自各个漫画源，你需要在应用内切换或选择当前使用的源；部分源（例如 picacg）需要先注册账号并登录才能浏览、收藏。具体操作看[漫画源管理与切换.md](漫画源管理与切换.md)。
2. **顺手配好同步**：如果你打算换手机或重装系统，先在设置里配好 WebDAV 同步，把收藏和阅读记录备份起来，后面迁移会省事得多。

之后日常用得最多的就是「找漫画 → 下载 → 离线看」这条链路，见[离线下载与收藏管理.md](离线下载与收藏管理.md)。
