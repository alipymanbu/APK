# iPhone 投屏到电视怎么弄

> 接收端装好 AirScreen 之后，iPhone、安卓手机、Windows 电脑分别怎么把画面投上去。

## 一、投屏前先满足两个条件

不管你用哪台设备发起投屏，这两条不满足就一律连不上：

1. **接收端已经开着 AirScreen 并处于就绪状态**（主界面能看到设备名 `AS-xxxx`）。没装的话先看 [下载与安装教程.md](下载与安装教程.md)。
2. **发送端和接收端在同一个 Wi-Fi 下**。注意是同一个网段 —— 手机连 5GHz、盒子连 2.4GHz 但都从同一台路由出去没问题；一个连路由一个连手机热点就搜不到。路由器开了「AP 隔离 / 访客网络」也要先关掉。

## 二、iPhone / iPad 投屏（AirPlay 镜像）

AirScreen 提供的就是 AirPlay 接收能力，所以 iPhone 这头用的是系统原生流程：

1. iPhone 拉下控制中心，点**「屏幕镜像」**（两个矩形叠一起的图标；iPhone X 及以后从右上角下拉，带 Home 键的机型从底部上拉）；
2. 列表里找 `AS-xxxx`（或你在 AirScreen 里改过的设备名），点它；
3. 若电视上显示一串 AirPlay 配对码，把它输进 iPhone；
4. 连上后 iPhone 的画面就实时出现在大屏上；要停就回控制中心点「停止镜像」。

想只投一个视频而不镜像整个屏幕的话，在支持 AirPlay 的 App（视频、照片）里点播放器上的 **AirPlay 图标**再选设备即可 —— 这种方式大屏只显示内容，iPhone 还能干别的。

## 三、安卓手机 / Windows 电脑投屏（Cast）

带 Cast（Chromecast）功能的 App 走这条路：

1. 打开 YouTube、支持投送的浏览器等带投送按钮的 App；
2. 点播放器或工具栏上的**投送（Cast）图标**；
3. 列表里选中你的 AirScreen 设备，内容就会推到大屏，且**投送的是内容本身**，手机可以锁屏、切别的 App。

Windows（Win 7~11）用系统自带的「投屏 / 无线显示器」也能镜像到 AirScreen，路径一般是：设置 → 系统 → 投影到此电脑 —— 不过那是把电脑当接收端；反过来把电脑画面投到装了 AirScreen 的电视上，用 Chrome 的 Cast（投送整个标签页）或在支持 Cast 的应用里点投送图标更省事。

## 四、DLNA：老应用里的「投放到电视」

不少本地播放器和视频 App 里只有「DLNA」「投放」「TV 标志」这类入口而没有 Cast 图标 —— 它们走 DLNA 协议，同样能被 AirScreen 收到：在 App 里点投放 → 选中 AirScreen 设备 → 从这一起，播放、暂停都在手机上控制，大屏只负责放。

## 五、投的时候能干什么、不能干什么

- **镜像模式**下你投的是整个屏幕：切 App、来通知都会跟着上屏，给别人演示时建议先开勿扰。
- **受版权保护的内容**（部分流媒体 App 的付费影片）可能只允许投内容、不允许镜像，甚至直接黑屏 —— 这是版权保护机制，不是你连错了，排查思路见 [搜不到设备连不上怎么解决.md](搜不到设备连不上怎么解决.md)。
- 投屏卡顿、声音画面对不上时，优先在 AirScreen 设置里把清晰度调低、打开硬件加速 —— 协议之间的延迟差异见 [支持哪些协议和设备.md](支持哪些协议和设备.md)，具体排查步骤见 [搜不到设备连不上怎么解决.md](搜不到设备连不上怎么解决.md)。
