## 一、发送端列表里根本看不到设备

按命中率从高到低逐条试，每做一条就回去刷新一次列表：

1. **确认同一个 Wi-Fi**。最常见的原因。手机连了蜂窝数据、或连了另一个 SSID（比如路由的 5GHz 和访客网络是两个名字）都会导致看不见。
2. **2.4GHz / 5GHz 频段拉齐**。路由器双频合一但设备被自动分到不同频段时，部分设备间互相发现不了 —— 临时把两台设备都手动连到同一个频段验证。
3. **关掉 VPN / 代理**。发送端开着 VPN 时局域网发现包发不出去，这在手机上很常见。
4. **关路由器的 AP 隔离 / 访客网络**。这个开关的作用就是禁止连在同一台路由下的设备互相通信，开着就一定搜不到。
5. **接收端重启三件套**：杀掉 AirScreen 重开 → 重启盒子 / 电视 → 重启路由器。局域网发现依赖组播，路由长期不重启后经常失灵。
6. **核对 AirScreen 确实处于就绪状态**：主界面能看到 `AS-xxxx` 设备名且没有弹窗挡着。

## 二、看到了但一直连不上

- **Windows 防火墙拦截**（发送端或接收端涉及 Windows 时）：有用户反馈重装 / 更新后 Windows 弹过「已阻止 AirScreen 访问网络」，勾选允许专用 + 公用网络后恢复。若当时点了阻止，去「Windows 安全中心 → 防火墙 → 允许应用通过防火墙」把 AirScreen 勾上。
- **权限没给全**：接收端首次启动时若拒绝了网络 / 后台权限，会表现得像「开着但连不上」。去系统设置 → 应用 → AirScreen → 权限，把网络、后台运行、电池「不限制」补齐。
- **配对码输错**：AirPlay 要求输配对码时，输错会直接退回列表 —— 重选一次设备重新输。
- **版本太旧**：发送端系统升到最新、接收端 AirScreen 还是很老的版本时，握手协议可能对不上。先升级 AirScreen 再试；升级包见 [下载与安装教程.md](下载与安装教程.md)。

## 三、连上了，但黑屏 / 卡顿 / 声音对不上

| 症状 | 判断 | 动作 |
| --- | --- | --- |
| 连上就黑屏，只有声音或什么都没有 | 多半是**版权保护内容**在拦截，或清晰度超出网络承载 | 换一个非 DRM 的视频试：能放说明是版权机制；都黑屏就往下调清晰度 |
| 画面一顿一顿 | Wi-Fi 带宽不够或信道拥挤 | AirScreen 里清晰度调低一档；发送端靠 5GHz / 6 路由近一点 |
| 声音比画面慢半拍 | 镜像链路延迟累积 | 打开硬件加速、关掉接收端后台其他应用，优先用 Cast 投内容而不是镜像 |
| 投一会儿自动断 | 接收端被系统杀后台 | 电池优化选「不限制」、打开后台服务（见 [支持哪些协议和设备.md](支持哪些协议和设备.md)） |
| 竖屏内容方向乱转 | 镜像跟随发送端方向，部分 App 不上报方向 | 锁定发送端方向，或改用 Cast 投内容 |

## 四、还连不上时的取舍

- 换协议试一遍：AirPlay 不通试 Cast，Cast 不通试 DLNA —— 四协议边界见 [支持哪些协议和设备.md](支持哪些协议和设备.md)，Miracast 在安卓 8+ 停用那条不值得耗时间。
- 换发送端试：iPhone 不行换安卓手机试。**iPhone 也搜不到**指向网络问题，**只有某台发送端搜不到**指向那台设备的系统 / 防火墙设置。
- 接收端型号本身不被支持：官方下载页写明部分安卓手机 / 平板 / 安卓电视型号可能无法被当前版本完整支持，可把设备型号与 AirScreen 应用 ID 发到 `support-as@ionitech.cn` 反馈。
