# 投屏没有声音怎么调

> 画面正常、电视不出声时按哪几步查：先查音量与耳机占用，再查输出设备与协议差异。

## 一、先做三个一分钟检查

画面投上去了却没声音，九成是下面三类情况之一，按顺序排：

1. **电视这头的音量与静音**。按遥控器音量键看指示条有没有动、有没有按过静音；部分盒子接了外接音箱后输出被切走，去设置 → 声音确认输出设备是电视扬声器。
2. **手机连着蓝牙耳机 / 音箱**。发送端连着蓝牙外设时，声音会优先走外设而不投出去 —— 断开蓝牙再试一次。这条在手机投屏场景里最常见。
3. **音量被投在发送端**。镜像模式下手机音量键控制的是链路音量，把它调高再试。

## 二、还是没声音：按投屏方式分开查

| 你用的方式 | 常见原因 | 动作 |
| --- | --- | --- |
| AirPlay 镜像 | 内容本身无声（比如静音播放的视频） | 先在手机上单独放一遍这个视频，确认源有声 |
| Cast 推流 | 部分 App 默认音频留在手机端 | 在该 App 播放界面找「声音输出 / 投屏音频」类选项切到电视 |
| Windows 投屏 | 系统输出设备没切过去 | 投屏进行中去「设置 → 系统 → 声音 → 输出」，选中电视 / 无线显示器那个设备 |
| 任意方式 | 音频格式不被接收端支持 | 把接收端的环绕声 / 数字输出关掉，改成立体声（PCM） |

第三条有官方支持渠道的答复佐证：Windows 在投屏时会临时生成一个单独的音频输出设备，不手动选过去就会出现「音量条在动、电视没声」的现象。

## 三、有画面没声音的另两种可能

- **投的是非媒体音**。通话、闹钟、通知铃声这类声音按系统规则留在手机上，只有视频、音乐、游戏这类媒体音会上屏 —— 这不是故障。
- **单个文件的问题**。本地视频本身没有音轨，或那个在线视频的播放器被静音了 —— 换一个片源 30 秒就能验证。

## 四、确认不是设置问题之后

三条都排除仍然无声，方向就回到兼容性本身：换一个投屏协议试（AirPlay 不行换 Cast，见 [支持哪些协议和设备.md](支持哪些协议和设备.md)），或先重启两端设备再连一次。连不上、频繁断这类问题的排查在 [搜不到设备连不上怎么解决.md](搜不到设备连不上怎么解决.md)；投屏的发起方式（镜像还是推流）在 [iPhone投屏到电视怎么弄.md](iPhone投屏到电视怎么弄.md)。
