## 一、先分清是哪种「装完不对」

XAPK 装完出问题的表现就三种，原因都指向同一批地方 —— 包里的数据文件（OBB）没就位或不匹配：

| 你看到的现象 | 最可能的原因 |
| --- | --- |
| 点开图标立刻闪退，或黑屏一下退回桌面 | OBB 文件夹是空的、路径不对，或 OBB 与程序版本不匹配 |
| 启动后开始「下载数据 / 校验资源」，下完才能玩 | OBB 完全缺失，游戏以为要从网上重下 |
| 能进游戏但贴图、音频缺失，报资源错误 | OBB 只拷了一部分（比如只拷了 main 漏了 patch） |
| 启动即提示「安装包不完整」类信息 | 拆分 APK 没装齐，程序本体就不完整 |

排查之前先确认一件事：你是用 ApkInstaller 装的还是手动装的。工具装的会自动摆放 OBB（见 [XAPK文件怎么安装.md](XAPK文件怎么安装.md)），出问题多半是版本不匹配；手动装的，先按下面的路径核对摆放位置。

## 二、核对 OBB 路径与文件名

OBB 的正确位置只有一个：手机内部存储的 `Android/obb/<包名>/`。三个具体判据：

1. **文件夹名 = 包名**，一个字符都不能差。比如包名是 `com.example.game`，那文件夹就必须叫 `com.example.game`，与 APK 里的包名不一致游戏就找不到数据；
2. **文件名有固定格式**：`main.[版本号].[包名].obb` 是主数据，`patch.[版本号].[包名].obb` 是补丁数据。两者都在时必须**一起**留在同一个文件夹里，只拷 main 漏 patch 就会出现「能启动但资源缺一块」；
3. **别改名**：除非来源处明确要求，OBB 文件名保持原样 —— 程序是按这个命名规则去找文件的。

核对方法：文件管理器进入 `Android/obb/`，看目标包名文件夹是否存在、点进去看文件是否非零大小。`Android/obb/` 打不开或列表为空时，先给文件管理器授予「所有文件」访问权限（安卓 11 起对 `Android/` 目录有单独限制）。

## 三、OBB 版本对不上也会闪退

OBB 文件名里的版本号要与装好的程序版本匹配。XAPK 是「程序 + 数据」成套打包的，从别处拼来的组合（新版程序配旧版 OBB）就会启动即崩。

处理办法很直接：**整包重装**。把当前应用卸掉，用同一份完整的 XAPK 重新走一遍 [XAPK文件怎么安装.md](XAPK文件怎么安装.md) 的流程 —— 工具会把匹配的程序与数据一次装齐。重装前确认 XAPK 文件完整（大小与来源页标称一致），下了一半的包解出来的东西永远配不齐，判别与重下的入口见 [安装失败解决办法.md](安装失败解决办法.md)。

## 四、排查顺序（照做即可）

1. 文件管理器查 `Android/obb/<包名>/` 是否存在、是否为空；
2. 文件夹名与包名逐字符比对；`main` 与 `patch` 是否都在；
3. 都在还闪退 → OBB 与程序版本不匹配，卸载后整包重装；
4. 装的是拆分包 → 确认分包全部装齐（缺分包的表现见 [安装失败解决办法.md](安装失败解决办法.md)）；
5. 以上都排除仍然打不开 → 是工具本身打不开而不是数据问题，按 [使用常见问题.md](使用常见问题.md) 查 GMS 与系统版本。
