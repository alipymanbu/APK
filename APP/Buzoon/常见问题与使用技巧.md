## 一、能量不够了怎么办

和角色的互动会消耗能量，能量不足时点界面上的「+」按钮，可以用宝石兑换能量继续。具体消耗数值与兑换规则以应用内实际显示为准。

应用本身免费下载，宝石属于应用内购买项目；要不要买、买多少，看自己的玩法节奏，标价与规则以应用内实际显示为准。

## 二、聊天记录怎么留档

Buzoon 支持把和角色的对话**导出为文本**保存。喜欢某段剧情，或者自建角色跑出了满意的桥段，随手导出一份，之后即使换设备或重装，创作内容也还在你手里。

关于记录存放在哪，不同来源的说法不完全一致：有用户反馈聊天记录默认存在设备本地、卸载应用后会被清除；而世界进度是跟着账号走的。无论哪种口径成立，换机或重装前先把想留的对话导出来，都是最稳妥的做法。

导出入口在聊天相关界面里，找不到的话留意消息列表的菜单项（应用是半汉化状态，个别菜单仍是外文，见[中文设置与半汉化说明.md](中文设置与半汉化说明.md)）。

## 三、账号与进度

- 游客进度绑定设备，卸载或换机后难以找回；想长期玩就用 Google 或 LINE 账号登录，详见[注册登录与账号找回.md](注册登录与账号找回.md)；
- 不同账号的进度互不相通，固定用一个账号登录最省心。

## 四、安装与启动故障

| 现象 | 先试这些 |
| --- | --- |
| 解析包错误 / 安装中断 | 多半是安装包没下完整，删掉重新下载再装（获取入口见[下载与安装教程.md](下载与安装教程.md)） |
| 安装被系统拦截 | 在系统弹窗里允许「安装未知来源应用」后重试 |
| 打开后一直转圈 | 检查网络，切换 Wi-Fi 与移动数据再试；首次启动还要确认已允许联网与存储权限 |
| 闪退 | 清理应用缓存、重启手机后再试；仍不行就卸载重装 |
| 界面显示异常 | 先确认语言已切到简体中文，再清一次缓存 |
| 收不到私信提醒 | 逐项检查通知权限与后台清理设置，见[通知权限与私信提醒设置.md](通知权限与私信提醒设置.md) |

## 五、使用上值得注意的几点

- **隐私**：AI 对话需要联网处理，不要在聊天里发身份证号、银行卡号这类敏感信息；
- **题材口味**：世界内容以女性向恋爱剧情为主，挑世界时留意题材描述，不合口味直接跳过即可；
- **系统要求**：不同渠道对系统版本的标注并不一致（从 4.3 到 7.0 的说法都有），以你手机安装时给出的提示为准；
- **版本**：网盘资源里的安装包为 1.0.5 版，后续新版本以官方发布渠道为准。

## 六、它和通用 AI 助手有什么区别

| | Buzoon | 通用 AI 助手 |
| --- | --- | --- |
| 定位 | 角色扮演、剧情互动 | 问答、写作、查资料等工具场景 |
| 对话形式 | 模拟社交网络：发帖、评论、私信 | 单纯一问一答 |
| 角色 | 每个角色有人设、记忆，关系会变化 | 通常没有长期人设 |

两者不冲突：要办事用通用助手，想进入故事里当主角，才用得上 Buzoon 这类应用。
