## 一、先确认你要装的是哪个包

「AI伴侣」这个名字的同名应用不止一个，网上也搜不到唯一的官方下载页，所以装之前先用包名和 MD5 对一遍，避免装成另一个同名软件。你要装的这一份，各项事实如下：

| 项目 | 数值 |
| --- | --- |
| 应用名称 | AI伴侣 |
| 版本 | 1.4.3 |
| 包名 | `com.DigitalAIFriend.chatapp` |
| 安装包大小 | 68.38M |
| MD5 | `776506a4966108ce3d90b027c6c1acfd` |
| 平台 | Android |

两点提醒：

- 网上各下载站显示的「最新版」可能已经不是 1.4.3，但**网盘里发出去的就是上表这一份**；两处版本号对不上时，以本页表格为准。
- 开发者信息在不同下载站标注不一致（有的标「武汉江上科技有限公司」，有的标「深圳市智能伴侣科技有限公司」）。拿不准的时候别看厂商名，**看包名和 MD5**，这两个不会变。

## 二、从网盘获取安装文件

打开 [AI伴侣 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f5b7c09dd3f2)，转存到自己的网盘后下载到手机（或先下到电脑再传手机）。文件名形如 `AI伴侣_v1.4.3.apk`，文件夹里会附一个说明 txt，不用管它。

下载完别急着装，先做一步核对：用任意一款支持 MD5 校验的文件工具算一下下载到的 `.apk` 的 MD5，和 `776506a4966108ce3d90b027c6c1acfd` 比对。一致说明包完整没下错；不一致说明传输中出了问题，重新下一次即可。

## 三、安装步骤

1. 在手机上找到下载好的 `.apk` 文件（浏览器下载目录或文件管理器的 Download 目录）。
2. 点击安装。如果系统弹出「禁止安装来自此来源的应用」，这是「未知来源」权限没开：按提示进入**设置 → 允许安装来自此来源的应用**（不同品牌手机路径略有差异，一般在设置里搜「未知来源」或「安装未知应用」就能找到），授权给你的浏览器或文件管理器，再返回继续安装。
3. 安装包 68.38M，安装后占用空间会更大，装之前确认手机存储还有富余空间，空间不足是安装中途报错最常见的原因。
4. 装完点「打开」，或回到桌面找图标启动。

装不上、装完打不开的排查见 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 四、首次启动该看什么

首次进应用，建议先做三件事：

1. **把版本对一遍**：进「我的」（底部最右一个标签）看版本号是不是 1.4.3，防止装到别的同名包。
2. **过一遍权限与隐私设置**：聊天类应用通常会要通知、麦克风等权限；你可以按需授予，麦克风不给也能用文字聊天。
3. **决定要不要给人用**：这类虚拟角色应用内容由 AI 生成，家里有未成年人的话，先看应用内有没有未成年人保护 / 使用时长相关设置，再决定是否交给孩子（步骤与监管要求见 [未成年人模式与防沉迷设置.md](未成年人模式与防沉迷设置.md)，其他注意点见 [常见问题与解决办法.md](常见问题与解决办法.md)）。
