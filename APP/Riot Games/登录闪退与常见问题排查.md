## 一、装不上或更新失败

按这个顺序排查：

1. **看系统版本**：网盘里这份 5.5.0 要求安卓 5.2 及以上，低于它装不上；
2. **看存储空间**：安装包 109.08M，解包安装还要额外空间，剩余空间不足会表现为「解析包错误」或装到一半停住；
3. **看安装来源权限**：侧载 APK 提示禁止安装时，给当前安装入口授权（见 [下载与安装教程.md](下载与安装教程.md) 第三节）；
4. **商店更新卡住**：Google Play 更新到一半不动，先在商店里取消这次更新、清掉 Play 商店的缓存再重试；仍不行就卸载重装（卸载不会丢账号数据，聊天记录跟账号走）。

## 二、闪退、卡顿、打开就转圈

官方对「安装/更新出问题、应用变慢、卡死、闪退」给的是同一套通用处理，逐条做：

1. **强制停止再打开**：设置 → 应用 → Riot Mobile → **强制停止**，再从桌面打开（比从最近任务里划掉杀得干净）；
2. 重启手机 —— 大量「一打开就退」重启后就好；
3. **手机系统也更到最新**：设置 → 系统 → 系统更新 —— 系统停在旧版时，应用新版本容易出现兼容性闪退；
4. 确认装的是最新版：商店有更新就先更新，旧版本在新系统上容易闪退；
5. **检查存储权限**：设置 → 应用 → Riot Mobile → 权限，确认存储/文件权限开着 —— 首次安装时点了「拒绝」，之后读写数据的环节就会异常；
6. 清一次应用缓存：设置 → 应用 → Riot Mobile → 存储 → 清除缓存（**先别点「清除数据」**，那会把本地状态一起清掉）；
7. 都无效时卸载重装，用 [Riot Mobile 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ac8e2a316061) 里那份包或商店版覆盖装回。

闪退如果只在打开某个页面时出现（比如进直播间就退），先记下是哪个页面，报 bug 时写清楚比笼统说「会闪退」有用得多。

## 三、登录不进去

| 症状 | 处理 |
| --- | --- |
| 还没有账号 | 先去注册，流程见 [账号注册与邮箱验证方法.md](账号注册与邮箱验证方法.md) |
| 密码不对 | 走 [账号找回页](https://recovery.riotgames.com/) 重置，别反复试错 |
| 收不到验证邮件 | 按 [账号注册与邮箱验证方法.md](账号注册与邮箱验证方法.md) 第二节排（先搜发件人、翻垃圾箱） |
| 收不到验证码 | 确认注册邮箱能正常收信、翻垃圾箱；验证码是 6 位，注意别输成旧的那条 |
| 一直转圈/超时 | 先走 [连不上服务器的网络设置.md](连不上服务器的网络设置.md)：换网络 → 换 DNS，两步能解决大半 |
| 提示账号被封 | **永久封禁的账号无法登录这个应用** —— 这不是应用故障，去官方支持页查申诉流程 |
| 换新设备首次登录 | 必须先填邮箱验证码，见 [扫码登录与双重验证教程.md](扫码登录与双重验证教程.md) |

## 四、数据看起来「没更新」

- **对局记录缺最新一局**：刷新是间歇性的，等一会儿再看，不是丢数据；
- **好友列表顺序跟预期不同**：Social 设置里改显示方式；
- **聊天提醒延迟或收发异常**：先按 [连不上服务器的网络设置.md](连不上服务器的网络设置.md) 排网络（延迟大半是网络）；网络没问题还偶发延迟的，有用户反馈过这类问题（单一来源，非官方结论）—— 去 Help & Feedback 提一笔，附上发生时间；
- **收不到任何通知**：系统侧也要放行 —— 设置 → 通知 → 找到 Riot Mobile → 允许通知，并确认各通知类别没被单独关掉（应用内开关只是一层，见 [好友聊天与资料设置教程.md](好友聊天与资料设置教程.md) 第四节）。

## 五、自己修不好时：反馈与提单

**应用内报 bug** 的固定路径：

1. 右下 **Profile** → 右上 **Settings**；
2. 选 **Help & Feedback** → 提交反馈；
3. 选一个功能分类（选对了才会分给对应的处理人）；
4. 写清「什么操作、什么现象、什么时间」，提交。

**要人工处理**（账号、登录这类）：走官方支持页底部的提交工单入口。官方要日志时，按其支持文档里的 Android/iOS 取日志文章操作，把生成的日志文件附进工单 —— 没有日志，多数「应用侧故障」只能停在猜测。

**账号类操作不在应用里做**：改 Riot ID、查绑定服务、注销前的资料核对，都在浏览器的 [账号管理页](https://account.riotgames.com/) 完成。
