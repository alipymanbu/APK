## 一、好友与聊天

你的好友列表跟着 Riot 账号走，不区分游戏：好友在玩英雄联盟还是 VALORANT，你在手机上都能看到，聊天也是一条列表打通。

- **加好友**：进入好友区，用对方的 Riot ID 搜索或接受请求 —— 这个 ID 是「游戏名#标签」两段式写法（如 `Summoner#KR1`），两段都对上才算一个人；应用里有专门的「添加/接受好友」分区，不用翻聊天记录找请求。
- **复制自己的 ID 给别人**：个人资料页可以直接复制游戏名与标签，发给对方就能被搜到 —— 比口头报名字少打错一个字符的概率。
- **聊天设置**：Settings → **Social** 里能改好友列表的显示方式（排序、分组）与聊天选项，比如不想在列表里看到某类会话就在这里收。

## 二、个人资料页有什么

右下角 **Profile** 是你自己的页面，两块主要内容：

- **状态（Status）**：发一句话让好友知道你现在想玩什么、在不在 —— 不想发就不发，它不是必填项。
- **对局记录（Match History）**：显示你最近常用的英雄/特工、各游戏的排位进度摘要。

对局记录有个特点要知道：**数据是间歇性刷新的**，刚打完的一局可能过一会儿才出现。别因为「刚赢的那把没显示」就以为没记录上 —— 等它刷。

## 三、Settings 全部设置项清单

入口固定：**右下 Profile → 右上 Settings**。各选项的用处：

| 设置项 | 你能改什么 |
| --- | --- |
| Social | 好友列表显示方式、聊天选项（含屏蔽敏感词显示的开关） |
| Esports | 赛事掉落开关、剧透开关 |
| Notifications | 哪几类通知收、哪几类不收（好友消息/赛事/资讯分开控） |
| Language | 应用界面语言 |
| Legal | 隐私政策与服务条款入口 |
| Help & Feedback | 报 bug、提建议、给应用打分 |
| Delete Account | 发起 Riot 账号注销流程 |
| Sign Out | 退出当前账号 |

几点注意：

- **语言**改的是这个应用的界面语言，跟着应用内提供的语种列表走，没有「简体中文」选项时说明该语种暂未提供，以列表实际内容为准。
- **Delete Account** 是注销整个 Riot 账号，不是退出登录 —— 手滑点进去先看清楚再确认。
- 改 Riot ID、查个人信息、看绑定了哪些第三方服务，这些**不在应用里做**，要在浏览器打开 [账号管理页](https://account.riotgames.com/) 操作。

## 四、收不到消息通知时

聊天提醒依赖系统通知权限：应用内 Settings → Notifications 打开对应开关只是第一层，手机系统的通知权限（设置 → 应用 → Riot Mobile → 通知）也得放行，两层都开才会推。通知开了但消息本身来得慢，那是网络问题，按 [连不上服务器的网络设置.md](连不上服务器的网络设置.md) 排；其余故障见 [登录闪退与常见问题排查.md](登录闪退与常见问题排查.md)。
