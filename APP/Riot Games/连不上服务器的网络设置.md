## 一、先判断：是网络还是应用

症状是「连不上、一直转圈」时，别急着重装应用 —— 先做两个判断：

1. **同一网络下，浏览器能开别的网页吗？** 能 → 网络本身通，问题可能在 DNS 或应用侧；不能 → 先修网络，与这个应用无关；
2. **Wi-Fi 下不行、切到流量就行吗？**（或反过来） → 换网络后立刻恢复，说明就是当前这条网络的问题。

这两步能把范围砍掉一大半：**换一条网络能解决的，不用动任何设置**。

## 二、换网络测试（成本最低）

官方移动连接排查给的第一条就是它：

- 在 Wi-Fi 与移动数据之间互切，每切一次等页面实际刷新一遍再判断；
- 连着的 Wi-Fi 信号弱（两格以下）、走公司/校园网代理时，先换个正常热点试；
- 家里多台设备只有这一台连不上 → 查这台设备的网络配置（往下看 DNS）；所有设备都连不上 → 查路由器或联系宽带客服。

## 三、换公共 DNS

网页能开、但这个应用（或部分域名）解析不出来，通常是 DNS 的问题。把 DNS 换成公共 DNS 后再测：

**Android 9 及以上**：

1. 设置 → 网络和互联网 → 高级 → **私人 DNS**；
2. 选「私人 DNS 提供商主机名」，填 `dns.google`；
3. 保存后重开应用测试。

**Android 9 以下**：

1. 在 Wi-Fi 网络设置里找到 DNS（先把原来的记下来）；
2. 主 DNS 填 `8.8.8.8`，备 DNS 填 `8.8.4.4`；
3. 保存退出，测试。

**iOS**：

1. 设置 → Wi-Fi → 点已连网络旁的 **i**；
2. 下滑到 DNS → **配置 DNS** → 选「手动」；
3. 添加 `8.8.8.8` 与 `8.8.4.4`，可把列表里其他条目删掉；
4. 保存测试；要还原就把配置 DNS 改回「自动」。

## 四、DNS 也换了还不行

按顺序收尾：

1. 重启手机再测 —— 网络配置的改动常常要重启才生效；
2. 检查是不是被系统「省流量 / 限制后台网络」拦了：设置里查该应用的联网权限（不同品牌在「流量管理」「联网控制」里）；
3. 确认应用是最新版（旧版接口失效表现为突然连不上，见 [下载与安装教程.md](下载与安装教程.md)）；
4. 以上都做过 → 这条网络环境确实到不了它的服务器，换一条能正常访问国际服务的网络再试；
5. 还不行 → 走 [登录闪退与常见问题排查.md](登录闪退与常见问题排查.md) 第五节的工单入口，把「哪个网络、试过哪几步、什么报错」写清楚。

看赛事直播、刷资讯对网络更敏感 —— 网络通了但直播仍卡，属于带宽问题，先关掉后台占流量的应用再测，入口见 [资讯与电竞赛事观看方法.md](资讯与电竞赛事观看方法.md)。
