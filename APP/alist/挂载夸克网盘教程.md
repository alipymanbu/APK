# AListFlutter 挂载夸克网盘教程

> 从抓 Cookie、找根目录 ID 开始，把你的夸克网盘加进 AListFlutter 的存储列表并能看到文件。

## 一、本篇要做什么

夸克网盘在 AList 里的驱动名就叫「夸克」，它认的凭证是**网页版 Cookie** 和**根目录 ID**，不像阿里那样扫个码就行。本篇把这两样东西怎么拿、怎么填、填完怎么确认成功走一遍。前提：AListFlutter 已装好且服务处于运行状态（见 [下载与安装教程.md](下载与安装教程.md)）。

## 二、先抓 Cookie（电脑浏览器最省事）

Cookie 要从**夸克网盘网页版**的请求里抄，手机浏览器上不好操作，建议用电脑：

1. 电脑浏览器打开夸克网盘并登录：`https://pan.quark.cn/`。
2. 按 `F12` 打开开发者工具，切到**网络（Network）**页签，点一下清除按钮清掉旧记录。
3. 在网盘页面里点进「全部文件」（哪怕你已经在列表里，也要重新点一次），让页面发出请求。
4. 在网络列表里找 `list` 或 `sort` 开头的请求，点开它的**标头（Headers）**，向下滚动找到 `Cookie`，把整串值完整复制出来 —— 它很长，缺一段都会认证失败。

这串 Cookie 就是你夸克账号的登录凭证，等于账号密码：不要发给任何人、不要贴到公开的地方。

## 三、找根目录 ID

根目录 ID 是你夸克网盘「全部文件」根文件夹的 ID，两个拿法任选：

- 在网页版里进入目标文件夹，浏览器地址栏里 `folder/` 之后的那串长字符就是文件夹 ID（页面版本不同地址格式略有差异，以当时地址栏实际显示为准）；根目录就取根文件夹那一串。
- 部分场景下 Cookie 里本身就带根目录 ID，AList 文档提示它也可以直接从请求或地址栏获取，以你当时页面实际显示为准。

不想限定范围就留空/用默认（挂整个网盘）；只想挂某一个子文件夹，就填那个文件夹的 ID。

## 四、在管理后台添加「夸克」存储

1. AListFlutter 里点左下角**网页**，用 `admin` + 密码登录管理后台。
2. 底部点**管理** → 左上角三杠菜单 → **存储** → 顶部**添加**。
3. 驱动选 **夸克（quark）**，表单里只动这几项：
   - **挂载路径**：填 `/quark`（也可用英文/拼音，必须以 `/` 开头且不与已有路径重名）；
   - **Cookie**：粘贴第二步抓到的整串；
   - **根目录 ID**：按第三步拿到的填；
   - **WebDAV 策略**：默认即可，其他保持默认；
   - **移除方式**：随便选一个（有教程选「回收站」，删文件时多一层保险）。
4. 点底部**保存/添加**。成功的话会回到存储列表，新条目显示为正常状态；失败会给出具体报错，按第五节对症处理。

回到**主页**，就能看到 `/quark` 下面的目录树了：视频、图片、文档可以直接点开在线看，apk、exe 这类打不开的给下载入口。

## 五、几个一定会碰到的坑

- **夸克下载必须带 Cookie 走代理中转**：AList 官方文档明确说明，受夸克网盘限制，下载只能通过 AList 的代理功能中转（`alist-doc.nn.ci` 的夸克驱动页）。表现为在线看视频正常、下载或某些播放器拉流失败时，先确认这项没有被关掉。
- **Cookie 会过期**：夸克网页端重新登录、在其他设备退出登录、改密码、长时间不用，都可能让 Cookie 失效 —— 有教程建议**约 1~2 个月主动换一次**（教程口径，实际以你的失效速度为准）。症状是存储列表报错、主页目录变空，接口类错误会提示 401 一类的认证失败。照第二节重新抓一份、覆盖保存即可。
- **粘贴时别带 `Cookie:` 字样**：复制的必须是纯值，开头留着 `Cookie:` 前缀会直接报格式错误 —— 多篇教程都把这一条列为高频翻车点。抓完先看一眼开头是不是 `__kps=`、`__ktd=` 这类字段名。
- **怀疑 Cookie 泄露就立刻作废**：Cookie 等同你的登录态，在夸克网页版**退出登录**即可让旧 Cookie 立即失效，改密码同理；作废后重新登录、重新抓一份填回 AList。
- **挂载路径重复**：提示路径已存在时，说明你之前加过同名路径，把旧的删掉或换个路径名。
- **下载限速**：有用户反馈夸克经 AList 下载会限速（论坛帖），在线播放受影响较小；这属于夸克侧的策略，截至 2026-09 没有确定的规避说法，故不展开。

挂上之后想在 nPlayer、Kodi、PotPlayer 里直接播这些文件，接 [WebDAV接入播放器与文件管理器.md](WebDAV接入播放器与文件管理器.md)；其他网盘（阿里、百度）的凭证拿法不一样，见 [阿里云盘与百度网盘挂载方法.md](阿里云盘与百度网盘挂载方法.md)。
