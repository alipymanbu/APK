# AListFlutter 挂载阿里云盘与百度网盘

> 阿里云盘要刷新令牌、百度网盘要三件套凭证，两者的获取入口与填法各走一遍，附各网盘凭证类型对照。

## 一、为什么两家的填法完全不同

AList 挂每个网盘用的是该网盘开放给它的凭证：有的是一段 Cookie（夸克，见 [挂载夸克网盘教程.md](挂载夸克网盘教程.md)），有的是一个刷新令牌（阿里），有的是三个参数（百度）。管理后台的入口都一样 —— **管理 → 存储 → 添加**，差别只在「驱动」下拉和下面要填的字段。下面两节各自从零走一遍，凭证都从官方渠道拿，别用任何来路不明的「一键获取」页面。

## 二、阿里云盘：拿刷新令牌

1. 驱动选 **阿里云盘Open**。
2. **挂载路径**填 `/alipan`（以 `/` 开头、不与已有路径重名即可）。
3. **刷新令牌**去官方工具页拿：`https://alistgo.com/tool/aliyundrive/request.html`（旧域名 `https://alist.nn.ci/tool/aliyundrive/request` 也指向同一工具，以页面当时显示为准）。打开后两条路：
   - 桌面浏览器：点页面上的前往登录，用阿里云盘账号授权；
   - 手机：点生成二维码，用手机上的阿里云盘 App 扫码，再点页面上的「我已扫码」。
   授权完成页面会给出一整串 token，复制粘进**刷新令牌**字段。
4. 需要限定范围就填**根目录 ID**：进阿里云盘网页版 `https://www.alipan.com/` 的文件夹，地址里 `folder/` 后面那串就是文件夹 ID。
5. 移除方式选「回收站」，其余默认，点**保存**。

## 三、百度网盘：要三个参数

百度的凭证不是一个字符串，是 `client_id`、`client_secret`、`refresh_token` 三样：

1. 驱动选 **百度网盘**。
2. 按 AList 官方百度驱动文档的指引完成授权页操作（入口在 AList 文档的百度网盘驱动页，`https://alistgo.com/zh/guide/drivers/baidu`，页面里有获取 refresh token 的跳转按钮），授权后得到上面三个值。
3. 在存储表单里分别填入对应字段，挂载路径照例以 `/` 开头（如 `/baidu`），保存。

注意：百度的 token 同样会过期，失效时表单会报错，重新走一遍授权拿新值覆盖即可。

## 四、各网盘凭证类型对照

避免每次都翻文档，常见网盘挂到 AList 要交出什么，一张表看全（以 AList 官方驱动文档当时显示为准）：

| 网盘 | 驱动名 | 你要提供的凭证 |
| --- | --- | --- |
| 夸克网盘 | 夸克 | 网页版 Cookie + 根目录 ID |
| 阿里云盘 | 阿里云盘Open | 刷新令牌（扫码/登录授权获得） |
| 百度网盘 | 百度网盘 | client_id + client_secret + refresh_token |
| 123 云盘 | 123 云盘 | 账号密码 |
| 迅雷网盘 | 迅雷 | 登录授权（流程相对繁琐，有教程称其为空间大但配置麻烦） |
| 天翼云盘 | 天翼云盘 | 账号密码/授权 |

两个通用规律：

- **凭证都是账号级权限**：填进去等于把整个网盘交给这个服务读写，所以第一节说的改管理员密码、别把后台口令外传，不是可选项。
- **路径别重名**：一个挂载路径只能有一个存储，重名会直接报错。

## 五、保存后怎么确认成功

回**主页**刷新，左侧目录树里出现你刚填的路径（`/alipan`、`/baidu`）就成功了；点进去能看到文件、视频能直接播才算完事。如果存储列表里那一条显示的是错误状态，多半是凭证失效或参数填错，对照 [常见问题与故障排查.md](常见问题与故障排查.md) 逐条排。

不同网盘在 WebDAV 下的能力不一样（有的支持上传建目录、有的只能列目录和下载），这会直接影响你在播放器、文件管理器里能做什么，细节见 [WebDAV接入播放器与文件管理器.md](WebDAV接入播放器与文件管理器.md)。
