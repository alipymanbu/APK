## 一、这是什么、适合谁

AListFlutter 是一个让你在安卓手机、安卓电视上直接跑起 AList 服务端的 APK：装上、点运行，就能把夸克、阿里、百度这些网盘挂到同一个文件列表里浏览，还能通过 WebDAV 让播放器、文件管理器直接读它们。它适合想在手机或电视上集中访问多个网盘、又不想折腾软路由或 NAS 的人。本篇只讲拿到安装包、装上并完成首次启动，挂载网盘见 [挂载夸克网盘教程.md](挂载夸克网盘教程.md)。

先厘清身份：AList 官方项目本身没有手机安装包，AListFlutter 是社区开发者 jing332 基于 AList 做的安卓版，用 Flutter 做界面，GitHub 项目地址是 `https://github.com/jing332/AListFlutter`，也被 AList 官方生态页收录过。一个需要先知道的情况：**该项目主页 README 顶部已标注「本项目已停止更新」并推荐了其他开源替代**，历史 APK 仍可下载使用，是否继续维护以项目页当时显示为准（截至 2026-09 的观察）。

## 二、安装包从哪拿、怎么核对

两条获取渠道：

1. **网盘留存版**：[alist 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d020182cd848)，转存后按下面的清单核对，确认拿到的就是这一份。
2. **GitHub Releases**：`https://github.com/jing332/AListFlutter/releases`。该项目曾由每日构建自动发版，页面上具体有哪些版本、是否还在更新，以官网当时显示为准。

网盘里那一份的固定事实（凡涉及版本号、包名、大小都以这几行为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.25.022810 |
| 包名 | `com.github.jing332.alistflutter` |
| 大小 | 37.64M |
| MD5 | `7EB9F284A493906F15E8121BAFC21EB8` |

下载完用 MD5 校验一遍再安装：Windows 上 `certutil -hashfile 文件名.apk MD5`，手机上用任意支持 MD5 的文件管理器算，结果对不上 `7EB9F284A493906F15E8121BAFC21EB8` 就重新下载。

## 三、安装步骤

1. 把 APK 拷到手机（或 U 盘插电视），用文件管理器点开安装。
2. 系统若弹出「禁止安装未知来源应用」，在该弹窗上允许一次（不同品牌路径略有差异，一般在 设置 → 安全 里给文件管理器开「安装未知应用」）。
3. 装完桌面会出现 AListFlutter 图标，点开即用，不需要 Root，也不需要 Termux。

系统要求：安卓 5.2 以上（以安装包信息页当时标注为准）。低版本系统存在已知问题 —— 项目 issue 记录过 Android 4.4 上闪退（[#5](https://github.com/jing332/AListFlutter/issues/5)），4.x 设备基本可以判定跑不了。

## 四、首次启动：把服务跑起来

装好后按这个顺序走一遍，两分钟能完成：

1. 点右下角的**运行**按钮，把 AList 服务启动起来（按钮变成停止状态就说明在跑）。
2. 点右上角的**菜单**（三个点），先把管理员密码改掉 —— 管理员账号固定是 `admin`，不改密码等于把网盘目录敞开给同局域网的人。
3. 底部切到**设置**页：需要开机自动运行的（比如电视上常驻），在这里打开开机启动选项。
4. 点左下角的**网页**，进入管理后台，用 `admin` + 你刚设的密码登录。

登录后是空列表属正常 —— 这时候一个网盘都还没挂。下一步就是往里加存储：常见做法是先加自己的夸克网盘，见 [挂载夸克网盘教程.md](挂载夸克网盘教程.md)；阿里、百度的凭证获取方式不同，见 [阿里云盘与百度网盘挂载方法.md](阿里云盘与百度网盘挂载方法.md)。

## 五、启动相关的小设置

几个首次使用就会碰到的开关，都在应用里：

- **开机自启**：设置页里打开后，电视/手机重启会自动把 AList 服务拉起来，不用每次手动点运行。
- **服务端口**：默认 `5244`，管理后台与 WebDAV 都走它。同一台设备上有别的程序占用时才会需要改，改完访问地址要跟着换。
- **检查更新**：应用内提供检查更新入口；由于项目已标注停止更新，收到的更新提示可能停在某个历史版本，以页面实际显示为准。

装好、跑起来之后，想让电视上的播放器、电脑上的 PotPlayer 直接读这些网盘，往下看 [WebDAV接入播放器与文件管理器.md](WebDAV接入播放器与文件管理器.md)；遇到网页打不开、闪退之类的问题，先翻 [常见问题与故障排查.md](常见问题与故障排查.md)。
