## 一、先确认最基础的几件事

十次故障里多半是这几条没满足，排任何问题前先过一遍：

1. **服务在运行吗**：打开 AListFlutter，看右下角按钮是否显示为「停止」（那正是正在运行的状态）。没运行时网页和 WebDAV 都是打不开的。
2. **网络在同一个 WLAN 吗**：手机和访问方（电视、电脑）必须在同一个局域网；连了访客网络或手机开了热点就对不上。
3. **地址与端口对吗**：默认 `http://<手机IP>:5244`，端口改过就换新的；别的设备访问**不能**写 `127.0.0.1`（那只会指向访问方自己）。
4. **手机把服务杀了吗**：系统省电策略会在锁屏后清理后台，服务随之停掉。把 AListFlutter 加入电池优化白名单/允许后台运行，电视与常驻手机再关掉省电模式（有用户实测卡在这一步）。
5. **开了代理或 VPN 吗**：手机上的代理软件（尤其 tun 模式）会拦截局域网互访，表现为本机能开、别的设备连不上。关掉代理再试，确认通了再决定怎么放行（有用户在同类问题里定位到这个原因）。

## 二、应用与启动类问题

| 症状 | 原因与处理 |
| --- | --- |
| 点开 APK 就闪退 | 项目 issue 记录过 Android 4.4 闪退（[#5](https://github.com/jing332/AListFlutter/issues/5)），4.x 系统基本无解；换更高版本系统或换设备 |
| 桌面版系统装不上 / 提示解析错误 | 确认下的是安卓 APK 而不是别的包；包名应为 `com.github.jing332.alistflutter` |
| 重启后服务没起来 | 应用**设置**页里打开开机自启，或手动进应用点运行 |
| 部分设备添加本地存储失败 | 已知问题（[#2](https://github.com/jing332/AListFlutter/issues/2)），网盘挂载不受影响；本机目录的排查步骤见 [挂载手机本机文件教程.md](挂载手机本机文件教程.md) 第四节 |

## 三、管理后台与网页类问题

- **网页打不开**：先按第一节自查三条；手机本机测试用 `http://127.0.0.1:5244`，能开说明服务正常、问题出在网络或地址填写。
- **忘记 admin 密码**：不用重装 —— 回到 AListFlutter 应用，右上角菜单里有更改管理员密码的入口，改完用新密码登录后台；同一入口也用于**首次设置**密码。
- **登录提示账号或密码错误**：用户名固定是 `admin`（全小写）；密码是你自己设的那一串，区分大小写。
- **后台界面是英文**：AList 后台支持界面语言切换，一般跟随浏览器语言，也可在后台设置里手动选中文。

## 四、挂载网盘类问题

| 症状 | 原因与处理 |
| --- | --- |
| 夸克存储报错、目录变空 | Cookie 过期：按 [挂载夸克网盘教程.md](挂载夸克网盘教程.md) 第二节重新抓一份覆盖保存；顺带核对根目录 ID |
| 保存存储时提示路径已存在 | 挂载路径重名，删掉旧条目或换个路径 |
| 阿里/百度令牌失效 | 凭证都会过期，重新走一遍授权拿新值（[阿里云盘与百度网盘挂载方法.md](阿里云盘与百度网盘挂载方法.md)），覆盖保存 |
| 挂载成功但主页看不到文件 | 回存储列表看该条是否为错误状态；确认挂载路径没有拼错，主页按路径刷新 |

## 五、播放与下载类问题

- **在线看视频正常，下载或部分播放器拉流失败**：夸克网盘受其限制必须带 Cookie 走 AList 的代理中转（官方夸克驱动文档口径），确认该存储的 WebDAV 策略是**本地代理**（策略含义见 [WebDAV接入播放器与文件管理器.md](WebDAV接入播放器与文件管理器.md) 第四节）。
- **播放器报 403 / 无法播放**：多半是 302 重定向后播放器不认带凭证的跳转，切到本地代理再试；仍不行就换一个支持 WebDAV 的播放器对照测试。
- **播放卡顿**：先换 302 策略减轻手机转发负担；仍卡则是网盘侧限速或局域网带宽问题 —— 有用户反馈夸克经 AList 下载会限速，截至 2026-09 没有确定说法，故不展开。
- **RaiDrive / PotPlayer 连不上**：这类桌面客户端常把地址拆成主机与端口两项填，确认少了 `/dav/` 后缀或端口写错这两种低级错误。
- **地址、密码都对还是连不上**：回后台查两处开关 —— WebDAV 服务总开关是否打开、`admin` 用户是否勾了 WebDAV 读取权限，两项都开在 [WebDAV接入播放器与文件管理器.md](WebDAV接入播放器与文件管理器.md) 第二节有写。
- **连接时好时断**：先按第一节第 4 条关掉省电与后台清理，常驻设备上这比网络问题更常见。

## 六、项目维护状态（决定要不要继续投入）

AListFlutter 的 GitHub 项目页 README 顶部标注**本项目已停止更新**，并列出了两个官方给出的替代项目：`https://github.com/LeoHaoVIP/AListLiteAndroid` 与 `https://github.com/OpenListApp/OpenListApp`；它曾由每日构建自动跟进 AList 上游版本。含义是：历史 APK（包括 1.25.022810 这一版）依旧可用、可从 [下载与安装教程.md](下载与安装教程.md) 给出的渠道获取，但不会再有新版本与 Bug 修复，遇到上表未覆盖的新问题，做好「没有官方响应」的准备。要不要换到替代项目、替代项目选哪个，以 GitHub 项目页当时显示为准。
