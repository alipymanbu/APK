授权环境就绪后（见 [Root与Shizuku授权准备.md](Root与Shizuku授权准备.md)），日常使用就是三步：找到应用、选中组件、关掉开关。本篇把每一步里你会碰到的选项讲清楚。

## 一、找到目标应用

打开 Blocker 就是已装应用的列表，顶部搜索框按应用名过滤；点某个应用进入它的组件页。想处理系统应用时，先到设置里打开「显示系统应用」之类的开关，否则列表里看不到它们（改系统应用的组件风险高，动之前想清楚后果）。

## 二、看懂四类组件

一个应用的组件分四类，关掉后的影响各不相同：

| 类型 | 是什么 | 关掉后的典型影响 |
| --- | --- | --- |
| Activity | 一个界面页面 | 对应页面打不开 |
| Service | 后台服务 | 后台任务跑不起来 |
| Receiver | 广播接收器 | 收不到对应广播（如开机完成、网络变化触发的逻辑） |
| Provider | 内容提供者 | 其他应用读不到它共享的数据 |

组件页顶部分类切换；每个组件行右侧就是总开关。不确定某个组件是干什么的，先点开看它的类名与说明再决定动不动——关掉承担核心功能的组件，应用会直接报错或闪退。误关了也不怕，同一个开关再点一次就恢复。

## 三、切换控制器

应用的菜单里可以切换控制方式（PM / IFW / IFW+PM / Shizuku）。什么时候用哪个：

- 想让禁用「钉死」、不在乎应用检测得到检测不到 → Intent Firewall；
- 想和 MyAndroidTools 时代的备份互通、或需要导出规则给别人用 → Package Manager；
- 无 root 设备走 Shizuku（shell 权限的限制见授权准备篇）。

切换不会丢规则，同一应用可以随时换控制器再禁一遍。

## 四、按 SDK 处理广告相关组件

Blocker 内置了按 SDK 维度整理的组件规则库：在规则页直接检索常见广告 SDK 的名字（例如腾讯广告、穿山甲、快手广告联盟、百度移动推广等），结果会列出装了对应 SDK 的应用与具体组件，并附带禁用后有无副作用的说明。操作路径：

1. 进入规则页，搜索 SDK 名称；
2. 逐个查看命中的应用与组件说明；
3. 确认副作用可接受后再关开关。

不用内置规则库也可以自己动手：在该应用的组件列表里按类名关键词（如 `ad`、`push`）过滤，自己判断哪些是广告与推送组件——这种做法副作用要自己担，关之前先记住回退方法。常见 SDK 的类名前缀对照表与证据边界，见 [广告SDK组件识别与处理.md](广告SDK组件识别与处理.md)。

## 五、验证与回退

- **验证**：打开被处理的应用，确认对应行为确实消失（某个弹窗、某条推送、某个后台唤醒）；
- **回退**：同一个开关再点一次就恢复；应用出现异常时，把最近关掉的组件逐个开回来，完整恢复路径见 [组件误禁用后的恢复步骤.md](组件误禁用后的恢复步骤.md)；
- **组件自己弹回去**（PM 控制器的特性）：把该组件换到 IFW 控制器再禁一次。

做过一批配置之后建议导出一份规则存底，方法见 [规则导出导入与备份.md](规则导出导入与备份.md)；开关点了没反应、弹出异常、装不上，去 [常见问题与报错处理.md](常见问题与报错处理.md) 对号入座。
