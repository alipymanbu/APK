Blocker 是一款开源的安卓组件控制器，用来查看和管理已装应用里的 activity、service、receiver、provider 四类组件，适合想关掉应用里用不到的后台行为、又不想直接卸载的用户。本篇按「核对版本 → 选渠道 → 安装 → 装完准备」的顺序讲。

## 一、先核对你要装的版本

本文对应的安装文件信息如下，拿到包之后可以逐项核对：

| 项目 | 值 |
| --- | --- |
| 版本号 | 2.0.4044 |
| 包名 | com.merxury.blocker |
| 安装包大小 | 6.63M |
| MD5 | 0D1618797EA6BCA7FF36A62F322B1402 |
| 系统要求 | 安卓 5.2 及以上（按本文件的收录记录；更高版本的要求以官方发布页当时显示为准） |

Blocker 的官方更新比较频繁，网上搜到的最新版版本号通常比上表高。版本号、包名、体积一律以你实际拿到的那份安装包为准，装错了版本排查起来会绕远路。

## 二、官方获取渠道

Blocker 的代码与发布页都在 GitHub：[github.com/lihenggui/blocker](https://github.com/lihenggui/blocker)。官方分发渠道主要有三个：

| 渠道 | 地址 | 说明 |
| --- | --- | --- |
| GitHub Releases | [github.com/lihenggui/blocker/releases](https://github.com/lihenggui/blocker/releases) | foss 与 market 两种包都能下 |
| F-Droid | [f-droid.org/packages/com.merxury.blocker](https://f-droid.org/packages/com.merxury.blocker/) | foss 版 |
| Google Play | [play.google.com/store/apps/details?id=com.merxury.blocker](https://play.google.com/store/apps/details?id=com.merxury.blocker) | market 版 |

foss 版与 market 版的差别（官方 FAQ 给出的口径）：

| | foss 版 | market 版 |
| --- | --- | --- |
| 统计与崩溃上报（Firebase 等闭源组件） | 不带 | 带 |
| 获取位置 | GitHub Releases、F-Droid | Google Play |

不想让应用带统计上报组件的，选 foss 版。两种变体的包名相同（都是 `com.merxury.blocker`），互相覆盖安装，不会同时存在两个。本仓库网盘里那份属于哪个变体，用上表的 MD5 核对即可。

## 三、安装步骤

1. 从上面任一官方渠道拿到安装包，或直接取 [Blocker 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cae4ed240f23)。
2. 点开安装包，系统会提示「未知来源应用」——在弹窗里允许对应来源（一般路径：设置 → 应用 → 特殊应用权限 → 安装未知应用，具体随系统略有差异）。
3. 回到安装器点「安装」，等待完成。
4. 装完先别急着用：Blocker 需要高权限环境才能真正生效，接着做下一篇的准备。

## 四、装完之后

Blocker 的全部功能都建立在「能改其他应用的组件状态」之上，普通应用权限做不到这件事，所以第一次启动前要先备好 Root 或 Shizuku 环境，两条路线的步骤见 [Root与Shizuku授权准备.md](Root与Shizuku授权准备.md)。

装好后打不开、或组件开关点了没反应，多半是授权环境这一步没做到位，排查思路在 [常见问题与报错处理.md](常见问题与报错处理.md)；环境就绪后怎么用，见 [组件禁用操作指南.md](组件禁用操作指南.md)。
