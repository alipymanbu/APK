# Blocker 规则的导出导入与备份

在 Blocker 里逐个应用调好的组件开关，都可以整理成规则文件带走。换新手机、重装系统、把一套配置复制到另一台设备，靠的都是导出与导入——不用再逐个开关点一遍，也不用凭记忆回忆当初关了哪些。

## 一、导出与导入

- **导出**：进入目标应用的组件页，从菜单里选择导出，Blocker 会把该应用的当前组件配置保存成规则文件；
- **导入**：在同一处选择导入，选中之前保存的规则文件，配置即恢复。

建议：大批量调整前先导出一份存底；误操作或应用更新后状态错乱，直接整批恢复，比逐个开关找回快得多。规则文件与应用一一对应，A 应用的规则导给 B 应用没有意义。

## 二、与 MyAndroidTools 备份互通

如果你以前用 MyAndroidTools 管理过组件，它生成的备份文件可以直接在 Blocker 里导入，不用重新整理。官方说明也明确：两者互通，并且可以把这些备份转换成 Intent Firewall 规则。

## 三、转换成 Intent Firewall 规则

导出的规则可以转成 Intent Firewall（IFW）规则。什么时候需要这一步：

- 某些组件用 Package Manager 禁掉后总被应用自己打开（两种控制器的行为差异见 [Root与Shizuku授权准备.md](Root与Shizuku授权准备.md)）；
- 想把拦截做成更「钉死」的形式。

转换在应用内完成，不用手工改文件。注意 IFW 规则依赖 root 环境才能生效，设备未 root 的话先看 [Root与Shizuku授权准备.md](Root与Shizuku授权准备.md)。

## 四、换机迁移的完整流程

1. **旧设备**：逐个应用导出规则文件，统一放进一个文件夹，拷贝到新设备（或经电脑中转）；
2. **新设备**：安装 Blocker（渠道与步骤见 [下载与安装教程.md](下载与安装教程.md)），并完成授权准备；
3. **恢复**：逐个应用导入规则文件；
4. **抽查**：挑三五个应用确认开关状态与旧设备一致。两边应用版本不同步时，个别组件可能对不上号，把应用更新到同一版后再核对一遍即可。

换机后 Shizuku 需要重新启动与授权（它无法开机自启），遇到开关没反应先查这一层，再回 [常见问题与报错处理.md](常见问题与报错处理.md) 对号入座。
