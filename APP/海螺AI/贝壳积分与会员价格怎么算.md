## 一、贝壳就是这个应用里的积分

海螺AI里的积分，官方叫法是**贝壳**（付费服务协议原文：「"贝壳"即积分」）。你生成一条视频，系统按模型、分辨率、时长扣对应数量的贝壳，扣完为止。规则以《海螺AI付费服务协议》为准，其中三条最容易被忽略：

1. **按月发放**：订购订阅计划后，贝壳在订阅期内按月度发放；
2. **有效期一个月**：每次发放的贝壳用不完，过期直接作废；
3. **过期不退**：有效期届满无论是否用完，已支付的费用不予退还。

所以**别一次囤几个月的量**——会员贝壳是当月发当月清零的。想留着慢慢用的量，走单独购买的贝壳（见第四节）。

贝壳只限个人使用，不能转让、出售或拿去营利，也不具备货币价值、不能换钱。

## 二、免费和付费，实际差在哪

| 项目 | 免费 | 付费 |
| --- | --- | --- |
| 生成队列 | 排在后面 | 队列优先 |
| 同时排队的任务 | 最多 3 个 | 最多 5 个 |
| 同时并行生成 | 1 个 | 2 个 |
| 下载视频 | 带水印 | 去水印 |
| 每月贝壳 | 不发放 | 按档位发放 |

这张表来自官方订阅服务条款，具体数值以产品页面当时展示为准。**结论是**：你只是偶尔试几条、不介意水印，免费档够用；要出片发出去用，至少得有去水印和队列优先，否则高峰期会明显变慢（排队问题另见 [生成排队与失败怎么排查.md](生成排队与失败怎么排查.md)）。

## 三、会员档位与价格

官方付费协议只写明「付费服务包括基础会员、标准会员等多项付费订阅计划」，**具体档位、价格、权益以产品页面实际展示为准**。可查到的公开信息是 2025 年 6 月的报道，四个档位每月发放的贝壳分别是：

| 档位 | 每月贝壳（2025 年 6 月公开报道） |
| --- | --- |
| 基础版 | 1000 |
| 标准版 | 4500 |
| 大师版 | 10000 |
| 至臻版 | 12000 |

同一轮报道里，至臻版标价 10788 元/年（折合 899 元/月）、2697 元/季，当时曾因定价引发大量讨论。**这些数字只是历史参考**，官方后续多次调整过贝壳数量与价格，你充值前一律以 App 内付费页显示的为准，不要照抄任何旧教程里的金额。

升降级规则（付费协议原文）：

- **升级**：随时可升，确认后立即生效；当期已发的贝壳在升级页怎么结算，以页面提示为准；
- **降级**：只能在当前订阅到期时降，降级在订阅期结束后生效；
- **终止**：终止付费服务在下一个计费周期开始时生效，**已支付的费用不予退还**。

## 四、贝壳不够了怎么办

除了订阅，官方也支持单独加购贝壳。加购的贝壳与会员贝壳是两套有效期——付费协议只对「订阅计划发放的贝壳」明确了「有效期一个月」，单独购买的有效期以购买页面当时标注为准。买之前先看清页面上的有效期与单价，再决定买多少。

另外注意：**套餐内某一档的权益（如无限量生成）可能限定在特定模型上**。官方订阅条款里的旧版「Unlimited」计划就写明无限量只适用于 Hailuo01 模型。看到「无限」两个字，先确认它针对的是哪个模型，别默认全模型通用。

## 五、自动续费怎么关

订阅时勾了自动续费，到期会从你的支付账户自动扣下一周期的钱。《海螺AI自动续费服务规则》给了三条退订路径，都在**支付渠道**那一侧关，不在这个 App 里：

| 支付方式 | 关闭路径 |
| --- | --- |
| iOS 内购 | App Store → 点账户头像 → 账户 → 订阅 → 选海螺AI → 取消订阅 |
| 支付宝 | 支付宝 → 我的 → 右上角设置 → 支付设置 → 免密支付/自动续费 → 海螺AI → 关闭服务 |
| 微信 | 微信 → 我 → 服务 → 钱包 → 页面底部支付设置 → 自动续费 |

**关的时机比关本身更重要**：官方规则写明，退订前已授权的扣款指令仍然有效，**基于该指令扣掉的钱不予退还**。也就是说在扣款日之后才去关，这一期的钱要不回来。按月订阅的，尽量在下个扣款日**前几天**关掉。

## 六、想更省一点的用法

- 先用 768p + 短时长把提示词试对，满意了再上高分辨率出成品——同样一条片，档位选低一档能省下可观的贝壳；
- 生成结果不满意时，先改提示词再重抽，不要原样连点，每点一次就是一次扣费；
- 每月的会员贝壳月底清零，把当月要用的量排进计划，别留到最后一周。
