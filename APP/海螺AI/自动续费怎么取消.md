## 一、先搞清楚：关的地方不在这个 App 里

订阅时勾了「自动续费」，钱是从你的**支付渠道**（Apple ID 余额/绑定的支付账户、支付宝、微信）里代扣的，所以关闭入口也在支付渠道那一侧。在海螺AI的 App 内翻会员页找「关闭续费」是找不到的——《海螺AI自动续费服务规则》第 8 条明确写的就是「请在支付渠道完成退订操作」。

## 二、三条关闭路径

| 你的付费方式 | 关闭路径 |
| --- | --- |
| iOS 内购（App Store 扣款） | 打开 App Store → 点右上角账户头像 → 账户 → 订阅 → 选海螺AI → 取消订阅 |
| 支付宝 | 支付宝 → 我的 → 右上角设置 → 支付设置 → 免密支付/自动续费 → 海螺AI → 关闭服务 |
| 微信 | 微信 → 我 → 服务 → 钱包 → 页面底部「支付设置」→ 自动续费 → 海螺AI |

iOS 12 以下的老系统路径不同：设置 → iTunes Store 与 App Store → Apple ID → 账户设置 → 订阅 → 选海螺AI → 取消。**取消成功后，「订阅」列表里那一条会显示到期日而不是「将续订」**，看到到期日才算真的关掉。

安卓端用支付宝或微信付的，就走表里对应那两行；如果你是在应用内直接绑卡支付的，先在 App 会员页确认扣款方式，再按对应渠道关。

## 三、什么时候关，比关本身更重要

官方规则写明两条，合起来就是「**关晚了要不回来**」：

1. 已授权的代扣指令在你退订前**仍然有效**，基于该指令扣掉的费用**不予退还**；
2. 你没有在订阅期内明确取消的话，系统会照常发出下一周期的代扣指令。

所以按月订阅的，**在下个扣款日的前几天关**。用支付宝、微信的，扣款通常发生在到期当天，别等到收到扣款通知才动手。不确定哪天扣，就去对应的「自动续费」列表里看那条记录的续费日期。

## 四、已经扣了，能退吗

- **还在当期、没用过**：先按上一节把续费关掉，再看当期剩余贝壳能不能用掉。付费协议写明「终止付费服务的，付费服务将在下一个计费周期开始时终止，**已支付的费用不予退还**」——所以官方侧的常规结果是不退，重点是别让它再扣下一期。
- **iOS 内购扣的**：可以走 Apple 自己的退款流程，打开 [reportaproblem.apple.com](https://reportaproblem.apple.com/) 用你的 Apple ID 登录，找到那笔扣款申请退款，是否批准由 Apple 判定。
- **支付宝、微信扣的**：先看是不是你自己忘了关。若确认是异常扣款，在对应支付渠道的账单里发起投诉/申诉，同时给官方邮箱 [feedback@hailuoai.com](mailto:feedback@hailuoai.com) 发一封说明（写清账号手机号、扣款时间、金额）。

## 五、几个容易踩的细节

- **改套餐要先关再开**：官方规则第 7 条写明，换了订阅计划想改自动续费的，先取消本服务，选好新计划后再重新开通。
- **余额不足不等于续费取消了**：扣款失败时，等你账户恢复正常、余额充足后，支付渠道可能**继续把这一期补扣上**，一旦扣成功会员就恢复了。想彻底停，还是得手动关。
- **关了不等于立刻失效**：当期已支付的权益用到期为止，期内的贝壳照常按月发放、当月过期（详见 [贝壳积分与会员价格怎么算.md](贝壳积分与会员价格怎么算.md)）。
- **调价不通知也算通知**：规则写明价格调整会以站内公告、短信等方式事先通知，你没取消就按新价扣。嫌贵就在调价生效前关掉。
