## 一、三种方式先分清

视频生成一共有三个入口，选错入口会白填一遍提示词：

| 方式 | 你给它什么 | 适合做什么 |
| --- | --- | --- |
| 文生视频 | 只有一段文字描述 | 从零造一个画面，风景、概念片、抽象创意 |
| 图生视频 | 一张图（可再加首帧/尾帧） | 让已有的照片、海报、草图动起来 |
| 主体参考 | 1~3 张人物/主体照片 + 文字剧情 | 多个镜头里保持同一张脸、同一只宠物不变 |

页面上还能看到模板类入口：选一个热门模板 → 传一张照片 → 按模板提示补一句描述 → 一键生成同款。模板本质是预置好的提示词与参数，仍然走上面三种方式。

## 二、文生视频：从一句话到成片

1. 进 App 首页，点底部的**创作**，选**文生视频**；
2. 在输入框里写提示词。信息量决定成片质量，按「主体 + 动作 + 场景 + 光影 + 画质 + 镜头」这一层写，越具体越不容易跑偏：

   ```
   一个孩子在公园里放风筝，金色阳光，镜头缓缓上移
   ```

   ```
   木质桌面上的青瓷茶具缓慢转动，夕光斜照，特写镜头，浅景深
   ```

3. 选分辨率与时长（见下一节），确认本次会扣多少贝壳；
4. 点**生成**，任务进队列。生成期间可以退出页面，任务在后台继续；
5. 完成后在作品/资产列表里点开预览。

**提示词的两个坑**：写「明亮的暗调」这种自相矛盾的描述，模型只能二选一；一句里塞太多互不相干的动作，容易每个都只做一半。一次只让它干一件事，效果更稳。

## 三、图生视频：让一张图动起来

1. 在创作页选**图生视频**，从相册挑一张图（JPG / PNG 都行，别用糊图和纯文字截图）；
2. 写一句你想让它**怎么动**——图里已有的元素模型会自动延续，你要补充的是运动方向和镜头：

   ```
   镜头由远推近，女人转头看向左侧，风吹动她的头发
   ```

3. 选分辨率、时长，点生成。

**首尾帧**是图生视频的进阶玩法：同时给首帧和尾帧两张图，模型负责补中间的过渡。官方公告里的支持范围是——768p 与 1080p 支持首尾帧和**仅尾帧**，512p 只支持首帧（2025 年 8 月上线公告，具体以 App 页面当时显示为准）。首尾帧适合做换装转场、logo 定格、镜头推进到某个结果这类「有明确起点和终点」的镜头；两张图跨度太大时，中间过程模型会自己发挥，出片前先预览。

## 四、主体参考：多镜头不换脸

1. 选**主体参考**，上传 1~3 张同一人物或宠物的照片，再配一段文字描述剧情；
2. 模型会锁定参考图里的长相与造型，生成过程中切换镜头也不换脸；
3. 同一组参考素材重复使用，可以做成系列短片里同一个人物。

用人脸做参考时，用的是你有权使用的人（比如你自己、自己的孩子、自己的宠物）。用户协议明确要求不得输入、生成违法违规内容——这条在实操里最常见的触发点就是未经授权的真人肖像。

## 五、分辨率与时长怎么选

- 常见档位是 **512p / 768p / 1080p**；首尾帧的档位支持见上一节；
- 档位越高、时长越长，扣的贝壳越多。先用 768p + 短时长把画面和动作试对，再上 1080p 出成品，比一次到位省贝壳；
- 具体可选档位以 App 生成页当时显示为准，不同模型上线后档位会有变化。

## 六、生成完在哪看、怎么存

生成的视频统一收在 App 的**作品 / 资产**列表里，那不等于手机相册。要存到相册得再点一次下载，步骤、水印选项和保存失败的排查都在 [生成的视频怎么保存到相册.md](生成的视频怎么保存到相册.md)。

## 七、公开发布与商用的边界

这几条协议层面的限制，等你要把片子发出去时才用得上，但提前知道能省掉一次返工：

- **公开发布 ≈ 连提示词一起公开**。依据官方用户协议整理的第三方汇总明确提示：你一旦选择公开发布，其他用户不只能看到成片，还能看到你写的提示词、并直接拿去生成。提示词里有不想外传的配方（产品细节、内部流程、个人信息），就别走公开发布，改成私下分享（以产品页面当时显示为准）。
- **「能生成」不等于「能商用」**。官方用户协议没有对免费档生成的视频能否商用作出明确表述；协议里明确写了的是另一件事——音频/音乐类服务中，只有标注「商用授权」的订阅档，其订阅期内生成的内容才可用于商用。要拿去接单、投广告，先去付费页确认你那一档的授权条款，别默认免费档就能商用。
- 附带一条：你上传的参考图，须是你自有或已获授权的素材，责任在你自己（用户协议第 1.9 条同义）。

出片不理想先别急着加钱，多半是提示词或参数问题，按 [生成排队与失败怎么排查.md](生成排队与失败怎么排查.md) 里的方式定位。
