## 一、排查前的三项基础检查

连不上时先在电脑上确认这三件事，多数问题到这一步就能定位：

1. **电脑醒着吗**：没在睡眠 / 休眠状态。睡眠中的电脑从外面永远连不回来。
2. **Server 在跑吗**：电脑上 RealVNC Server 的状态对话框里是绿色对勾、无报错；红叉或报错就先解决它。
3. **Server 授权了吗**：未授权的 Server 不接受连接——官方提供 14 天免费试用，试用结束后需要订阅才能继续用。

三项都正常还连不上，再往下对照具体报错。

## 二、报错对照表

VNC Viewer 抛出的错误信息是英文的，对照下表处理：

| 报错 | 含义 | 怎么处理 |
| --- | --- | --- |
| The connection was refused by the host computer | 电脑上的 Server 没跑，或端口不对 | 确认 Server 已启动；直连时确认端口是 5900（或按规则写对端口） |
| Either the username was not recognized or the password was incorrect | 认证信息不对 | 填**电脑账户**的用户名和密码（平时登录 Windows 那套）；域账户要写成 `域名\用户名` |
| Too many security failures | 密码连错太多次，被临时拉黑 | 等待 Server 设定的秒数（默认 10 秒）再试，别连续猛敲 |
| Access is Denied | 这个账户没权限连 | 换有权限的账户，或在 Server 的 Users & Permissions 里给自己授权 |
| Access denied to VNC Server; please sign in to connect | 手机端账号掉线了（改过密码等情况） | 点 Sign in again 重新登录，右上角出现绿色对勾后再连 |
| VNC Server is not currently listening for cloud connections | 云端方式走不通 | 检查电脑网络、Server 是否登录同一账号、Server 状态 |
| Connection rejected by VNC Server computer user / did not respond | Server 开了「需人工确认连接」，对面没人点允许 | 在 Server 的 Options 里关掉接受提示，或为你的账户配置自动放行 |
| Too many existing concurrent sessions | 超出订阅允许的并发会话数 | 先结束一个正在跑的会话，再发起新的 |
| Account locked / Password must be changed | 电脑账户被锁或密码过期 | 到那台电脑上解锁账户或改密码，这与 VNC 本身无关 |

## 三、连上了但黑屏 / 白屏

- **对方电脑锁屏了**：先让人在电脑上解除锁屏，确认桌面能正常显示后再连；锁屏状态本身就可能让画面出不来。
- **连的是 Mac**：RealVNC 官方对「连接 Mac 黑屏」有单独的帮助条目，按其指引在 Mac 那侧检查系统权限与 Server 设置。
- **画面质量被调得过低**：连接详情里把画质调回自动或高档。
- **只有画面没反应**：那是交互问题不是黑屏，看[手势和鼠标键盘怎么操作.md](手势和鼠标键盘怎么操作.md)。

## 四、局域网能连、出门连不上

直连方式（填 IP）走的是内网地址，出了那个局域网就路由不到。解决方向有两条：换用云端方式（手机与电脑登录同一 RealVNC 账号，走官方中转）；或者自己给电脑配公网入口（端口映射 / 内网穿透）——后者要自己承担暴露端口的风险，普通用户建议走云端方式。

## 五、连上但卡、糊、点不准

| 现象 | 优先试 |
| --- | --- |
| 操作延迟明显 | 连接详情里调低画质；换更稳的 Wi-Fi |
| 画面糊到看不清字 | 调高画质；手机横屏、两指张开放大 |
| 点击位置偏 | 适应「光标跟随手指」的鼠标模式，或改用鼠标模式按钮点虚拟键 |
| 隔一会儿就断 | 关掉手机的省电限制，允许该应用后台运行（各品牌路径不同，在系统设置的应用管理里找） |

## 六、还是解决不了

官方帮助中心（`help.realvnc.com`）的 Troubleshooting 区按错误信息分好了条目，把你屏幕上的英文报错原样搜进去，通常能命中对应文章。搜索时注意用报错的完整英文原句。
