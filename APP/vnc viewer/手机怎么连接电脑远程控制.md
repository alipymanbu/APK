## 一、先弄清一件事：手机这边只是「遥控器」

VNC Viewer 装在手机上，真正被连的是电脑。电脑上必须先跑起 RealVNC Server（下载在官网 [www.realvnc.com](http://www.realvnc.com) 的下载区），否则你填什么地址都连不上。这一步在电脑上做，一次配置长期有效。

完整链路是：**电脑装 Server 并开好权限 → 手机装 Viewer → 两边同一套账号或同一局域网 → 连上**。

## 二、电脑侧要准备什么

1. 在电脑上下载安装 RealVNC Server（Windows、macOS、Linux 都有对应版本）。
2. 装完启动它，状态对话框里显示绿色对勾、没有报错，才算正常在跑。
3. 想让电脑**不用人守着也能随时连**（无人值守），两件事要做：让 Server 随系统启动并登录好；把睡眠关掉——Windows 在控制面板的电源选项里把「使计算机进入睡眠状态」设为「从不」，macOS 在系统设置里勾上「显示器关闭时防止电脑自动进入睡眠」。
4. 记下电脑的局域网 IP：Windows 下在命令提示符里敲 `ipconfig` 回车，看「IPv4 地址」一行（形如 `192.168.x.x`）。

## 三、两种连法怎么选

| | 云端方式（登录账号） | 直连方式（填 IP） |
| --- | --- | --- |
| 前提 | 手机与电脑都登录同一个 RealVNC 账号 | 手机和电脑在同一局域网，或电脑做了端口映射 |
| 手机上怎么找电脑 | 登录后电脑自动出现在列表里 | 点 `+` 手动填 `IP:端口` |
| 跨网络（在外面用流量） | 可以 | 一般不行，除非自己配好公网入口 |
| 断网时 | 走不通（依赖官方中转） | 局域网内依然能连 |

同一局域网（家里、办公室同一 Wi-Fi）用直连最省事；要出门在外连家里电脑，用云端方式。两种都试不通时看[连不上电脑或黑屏的排查方法.md](连不上电脑或黑屏的排查方法.md)——云端那条路失败另有完整清单，见[云连接失败怎么排查.md](云连接失败怎么排查.md)（办公网代理、防火墙拦出站连接是最常见的坑）。

## 四、首次连接步骤（以登录账号为例）

1. 手机上打开 VNC Viewer，点左上角菜单按钮，用 RealVNC 账号登录（没有就先注册一个，注册即送 14 天试用，不需要绑卡）。
2. 电脑侧的 Server 也用同一个账号登录。完成后，那台电脑会自动出现在 Viewer 主界面上。
3. 点这台电脑，进入连接。首次会要你认证——默认的认证方式是 System Authentication，即填**电脑上那个账户的用户名和密码**（就是你平时开机登录 Windows 用的那套），不是 RealVNC 账号。
4. 认证通过就进到远程桌面了。横屏看电脑屏幕更合适，竖屏能用但视野窄。

## 五、不登录账号的直连方式

1. 确认手机和电脑在同一局域网，且电脑 Server 正在跑。
2. VNC Viewer 里点右上角 `+` 新建连接，地址填 `192.168.x.x`（你的电脑 IP），默认 VNC 端口是 5900，端口是默认值时可以只写 IP。
3. 端口不是默认值时要按规则补：5901~5999 端口写成 `IP:序号`（如 `192.168.5.127:80` 实际表示 5980 端口），其他端口写 `IP::端口号`。
4. 保存后点它连接，同样要过一次认证。

## 六、连上之后能干什么、不能干什么

- 能：看到电脑画面、用手机触屏移动鼠标点击、打字、按快捷键——手势细节在[手势和鼠标键盘怎么操作.md](手势和鼠标键盘怎么操作.md)。
- 能：复制粘贴文字（剪贴板互通）。
- 不能：用它传文件。文件传输功能在 RealVNC 的移动端（安卓 / iOS）上不可用，要传文件请用网盘、数据线或局域网共享。
- 息屏后连接还在不在：取决于手机的省电策略，后台被杀就会断——把该应用加入允许后台运行的名单更稳，见排查篇。

## 七、常见卡点提前说

- 连的时候报「拒绝连接」「找不到主机」→ 电脑侧 Server 没跑或端口不对，见[连不上电脑或黑屏的排查方法.md](连不上电脑或黑屏的排查方法.md)。
- 能连上但一闪就断、提示密码错 → 大概率填错了认证那一步：System Authentication 要的是电脑账户，不是 RealVNC 账号。
- 电脑在睡眠 → 先把电脑设成不睡眠，否则外面永远连不回来。
- 想反着来——用电脑操作手机（远程看家里人的手机）→ 装的东西对调，步骤在[电脑怎么远程控制手机.md](电脑怎么远程控制手机.md)。
