## 一、先建立一个心智模型

VNC Viewer 在安卓上默认是**鼠标交互模式**：你的手指移动的是一个悬空的鼠标光标，点击落在**光标所在的位置**，而不是你手指按的位置。光标会刻意偏移在手指下方一点，让你始终看得见它。刚上手最容易不适应的就是这一点——先练两分钟「拖着光标走位」，后面就顺了。

## 二、手势对照表（鼠标模式）

| 手势 | 对应操作 |
| --- | --- |
| 单指拖动 | 移动鼠标光标（光标跟着手指走，略有偏移） |
| 单指点一下 | 左键单击（点在光标处） |
| 单指点两下 | 双击 |
| 两指同时点一下 | 右键单击 |
| 三指同时点一下 | 中键单击 |
| 两指上下拖动 | 滚动当前窗口 |
| 两指捏合 / 张开 | 缩小 / 放大画面（缩小到整屏来看全局） |
| 点一下按住不放，再拖动 | 拖动窗口、图标，或选中一段文字 |

右键和中键靠「两指 / 三指同时点」实现，第一次容易点成两下——两指要**同时**落下，不是先后。

## 三、工具栏怎么用

会话界面顶部有一条工具栏，主要入口都在上面：

- **自动收起**：20 秒没操作工具栏会自动最小化，点它展开；想让它一直露着，点工具栏上的锁定按钮把它钉住。
- **帮助按钮**：里面就是上面那套手势说明，忘了随时点开看。
- **连接详情**（`i` 图标）：看当前连的是哪台机器、调整画质与交互设置。画面卡顿时把画质调低一档，延迟会明显改善。
- **鼠标模式按钮**：见下一节。
- **键盘按钮**：见第五节。

屏幕顶端同时受安卓系统状态栏与手势条影响，横屏全屏时留意别把系统手势条误触出来。

## 四、鼠标模式：不想记手势就用它

点工具栏上的鼠标模式按钮，画面上会叠加出虚拟的**左、中、右三个鼠标键**和一条**竖向滚动条**，手指点这些虚拟键就是点鼠标键，不用再记「两指点右键」。适合：右键菜单用得多、或者手势总点不准的时候。

## 五、打字与特殊键

1. 点工具栏的键盘图标，弹出虚拟键盘；键盘上方还有一条**可横向滚动的特殊键条**，里面是 F1~F12、Ctrl、Alt、Shift 这类电脑键。
2. **按住修饰键**：双击 Ctrl / Shift 这类修饰键就等于「按住不放」，再去点别的键就组成组合键（如 Ctrl+C）；具体松开方式以应用内帮助的说明为准。
3. 有些键在移动端给不出来，比如 Scroll Lock——需要它时没有别的办法，只能到电脑跟前操作。
4. 手机接了实体键盘时，虚拟键盘不会弹出，但点键盘图标仍能打开那条特殊键条。

## 六、把电脑桌面「装进」手机的实用习惯

- **横屏优先**：竖屏只能看到电脑画面的一竖条，横屏才接近原始比例。
- **先缩小看全局，再放大干活**：两指捏合缩小到整屏，找到目标窗口后张开放大，比拖着找快得多。
- **快捷键照电脑习惯按**：通过特殊键条与修饰键配合，Ctrl+C 这类组合的按法与坐在电脑前一致。
- **画质按网络调**：网络一般时把画质调低，操作会跟手很多；画质选项在连接详情里。

## 七、画面点不准、键盘弹不出来时

手势失灵、点击偏移、虚拟键盘不出现，多半是交互设置或输入法冲突的问题，排查步骤在[连不上电脑或黑屏的排查方法.md](连不上电脑或黑屏的排查方法.md)。
