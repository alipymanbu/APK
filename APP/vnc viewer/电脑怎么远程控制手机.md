# 电脑怎么远程控制手机

> 反向场景：用电脑上的 Viewer 生成 9 位码，让手机变成被控端——远程帮家人看手机、指导操作。

## 一、先分清方向

前面几篇讲的都是「手机控制电脑」。方向反过来也成立，但**两边装的东西对调**：电脑上装 VNC Viewer（发起方），手机上装 RealVNC Server（被控方）。最实用的场景是人在外面，用电脑远程看家里人的手机屏幕、手把手教他操作。

官方把这条链路叫 On-Demand Assist（按需协助）：**不用提前在手机上装好任何东西，靠一次性的 9 位码建连**，会话结束码即作废。

## 二、前提条件

- 电脑端 Viewer 能看到 `On-Demand Assist` 按钮：该功能包含在订阅里——如果你的 Viewer 里没有这个按钮，说明你当前的订阅不含它，需在官方渠道加购（试用期内可用，以官方页面当时显示为准）。
- 手机侧要装 RealVNC Server（应用商店搜 `RealVNC Server`，包名与 Viewer 不同，别装反）。
- 手机能联网即可，不要求和电脑在同一局域网。

## 三、连接步骤

1. **电脑上**：打开 VNC Viewer，登录你的 RealVNC 账号，点 `On-Demand Assist` 按钮，界面会给出一个 **9 位会话码**。
2. **把码告诉对方**：电话、短信、聊天工具念给对方都行——官方说明 Viewer 里没有自动发送机制，必须你自己传。
3. **手机上**：装好并打开 RealVNC Server，输入这 9 位码，点 `Connect`，然后点 `Start Now` 开始会话。此时电脑上已能看到手机屏幕。
4. **要能操作，还差一步**：手机端点 `Remote Input` → `Go to Settings` → 在系统设置里打开 **RealVNC Server 的无障碍服务**（各品牌路径不同，一般在「设置 → 无障碍 / 辅助功能」里）→ 切回 RealVNC Server 确认远程控制已启用。不开这个服务，电脑端只能看画面、点不动。
5. **结束**：手机端在 RealVNC Server 里点 `Disconnect`，或电脑端主动断开；9 位码是一次性的，关掉即失效。

## 四、安全上必须说的一条

官方在协助页面挂了醒目的隐私警告：**远程访问可以被用来诈骗**——如果你是被要求「配合检查」的一方，先确认连接发起者身份、确认自己信任对方；协助期间对方对你手机的屏幕内容有完整可见性，建议先关掉含敏感信息的窗口（聊天、相册、支付类页面）。反过来，你自己发起协助时也一样：只在对方明确求助、知情的前提下连他的手机。

会话中对方仍然握着自己手机的完全控制权，退出应用即结束——这是官方对被控端的设计口径。

## 五、连不上时

- 电脑上没有 `On-Demand Assist` 按钮 → 订阅不含该功能，见[账号登录与免费版付费版区别.md](账号登录与免费版付费版区别.md)。
- 输码后手机端连不上 → 检查手机网络、确认码没输错（9 位、一次性）；云连接类故障的通用查法在[连不上电脑或黑屏的排查方法.md](连不上电脑或黑屏的排查方法.md)。
- 能看到画面但点不动 → 手机端的无障碍服务没开，回到第三节第 4 步。

同理，「手机连电脑」那套完整准备在[手机怎么连接电脑远程控制.md](手机怎么连接电脑远程控制.md)。
