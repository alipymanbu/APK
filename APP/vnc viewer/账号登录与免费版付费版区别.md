## 一、一句话结论

手机上的 VNC Viewer 本身免费（首次启动接受许可协议即可用）；花钱的地方几乎都在**电脑那侧的 Server**，以及你要不要用「云端账号」这类便利功能。你只是偶尔连自己一台电脑，免费路径就够走通。

## 二、RealVNC 账号到底是什么

账号（在 RealVNC 的管理后台注册）在整套体系里承担两件事：

1. **认设备**：手机和电脑登录同一账号后，电脑会自动出现在 Viewer 列表里，你不用记 IP；
2. **管权限**：团队场景下，谁能发现、谁能连接哪台机器由账号侧的权限配置决定。

不登录也能用——手动填 IP 的直连方式完全不依赖账号，见[手机怎么连接电脑远程控制.md](手机怎么连接电脑远程控制.md)。

## 三、免费与收费的分界线

按官方口径整理（具体以后台与官方页面当时显示为准）：

| 项目 | 情况 |
| --- | --- |
| VNC Viewer（手机 / 桌面客户端） | 免费，接受 EULA 即可使用 |
| 注册账号 + 14 天试用 | 免费领取，无需绑信用卡 |
| 试用到期后 | Server 侧需订阅才能继续提供连接；Viewer 本身仍可用 |
| 会话录制、远程打印、实时聊天、文件共享 | 属订阅功能，且**移动端不支持文件传输** |
| 端到端加密、云端 + 直连双通道、多因子认证 | 与 VNC Server 配套使用时提供的能力 |

同一张表在官方下载页也有对照：**Viewer 配第三方 VNC 服务端**与**Viewer 配 RealVNC 自家 Server**，功能集不一样——想要完整能力，电脑上得装 RealVNC Server。

## 四、认证用的是哪套密码

连的时候弹的用户名密码框，问的是**电脑上那个账户**（System Authentication，即开机登录那套），不是 RealVNC 账号。这两套凭据最容易混，报「用户名或密码不正确」时先分清自己在填哪一套，对照表在[连不上电脑或黑屏的排查方法.md](连不上电脑或黑屏的排查方法.md)。

部分配置下 Server 也可能要求填它自己设置的 VNC 密码——那是在 Server 侧开的另一种认证方式，向管理那台电脑的人要。

## 五、版本号那些事

- 手机端这套版本号形如 `4.9.3.60175`；网盘里整理的是 2026-09-22 的这一版（6.02M）。
- 官方更新后版本会往前走，**别拿版本号判断能不能连**——手机端与电脑端的版本号本来就不是一套，能否连上以实际连接结果为准。
- 换新手机时，装上 App 登录同一账号，账号下的电脑会重新出现在列表里；走直连方式的话，地址得手动再填一遍。

## 六、隐私与安全上你该知道的

- 会话在传输中是加密的，官方称公共 Wi-Fi 下也保持加密——但**认证密码别在公共场合明着敲**。
- 账号就是这套系统的钥匙：改了 RealVNC 账号密码，手机端可能被登出，重连前先重新登录（报错原文见排查篇）。
- 别把能连你电脑的账号密码随手给别人；临时给别人看一次电脑，用完在 Server 侧收回该账户的连接权限。
