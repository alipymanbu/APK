VPlayer 是安卓上的一款视频播放器，开发方是炫一下（北京）科技有限公司（对外的英文主体是 YIXIA INC.），特点是靠硬件解码直接放 MKV、RMVB、FLV 这类系统自带播放器打不开的文件。本篇只做一件事：把网盘里这份 3.2.6 的包装进手机，并把第一次打开要用到的权限配齐。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本信息通常是当时的最新发布版，而网盘里这份是制作文档时核对过的版本，两者未必是同一个版本号。下面这张表是本篇的唯一口径：

| 项目 | 值 |
| --- | --- |
| 应用名 | VPlayer |
| 版本号 | 3.2.6 |
| 包名 | `me.abitno.vplayer.t` |
| 安装包体积 | 6.57 MB |
| MD5 | `7274F41739139A3197CA74A3548C9C31` |
| 标注的系统要求 | Android 5.2 及以上 |
| 开发方 | 炫一下（北京）科技有限公司 |

关于版本号：VPlayer 用的是 `3.x.y` 三段式，主版本号停在 3 很久了 —— 2012 年的 3.1.4、2013 年的 3.2.2、以及这份 3.2.6 都属于同一条 3.x 线。也就是说，网上如果出现看起来更大的版本号，先确认它是不是另一个叫 VPlayer 的软件（见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)），不要默认「新版本一定在同一个更新线上」。

关于系统要求：下载页标注的最低系统要求写作「Android 5.2 及以上」。安卓公开过的正式版本号里只有 5.0 和 5.1，并没有 5.2 —— 这个数字更像发布方填写时的近似写法，不必当成精确门槛。它管的是「系统太老装不了」，属于下限，安卓 5.0 及以上的设备通常都在它的覆盖范围内，最终以你装机时的实际提示为准。装的时候如果系统提示「应用与你的设备不兼容」，要分两种情况看：手机系统版本低于这条下限，属于这一节说的原因；手机系统本身是安卓 14 或 15 及以上，则更可能是被「目标 API 级别过低」这条新规矩拦下的，处理办法见 [高版本安卓装不上怎么办.md](高版本安卓装不上怎么办.md)。

## 二、装之前要核对的两件事

**第一，确认包名是 `me.abitno.vplayer.t`。** 安卓上叫 VPlayer 的程序不止一个，包名是最靠得住的身份标识。装之前可以在下载下来的 APK 属性里看包名，或者装完在系统「应用」列表里核对。包名对不上，说明你装的不是本文说的这个。

**第二，留出足够的空间。** 安装包本身 6.57 MB，属于很小的一类，装完的占用也不会比它大多少。真正吃空间的是你要看的片子本身，以及播放时产生的缩略图和缓存 —— 安卓播放器在列出本地视频时通常会先给每个文件生成一张缩略图，视频多的时候这部分缓存会明显涨上来。存储接近满的时候，列目录和生成缩略图都会变慢。

## 三、安装步骤

1. **转存并下载**：从 [VPlayer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/615296deb124) 把 APK 转存到自己的网盘，再下载到手机或电脑。
2. **把包送到手机上**：手机端直接下载最省事；在电脑上下载的话，用数据线、文件传输助手或任意传输工具拷进手机存储均可。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统的这项开关通常收在「安全」或「隐私」分类下面。
4. **点击 APK 完成安装**：系统若提示「应用未经过安全检测」，选择继续安装即可，这是第三方渠道安装包的常规提示。
5. **回装低版本要先卸载**：安卓一般不允许用更低版本的安装包覆盖更高版本，通常会直接报「应用未安装」。手机里如果已经装了比 3.2.6 更高的版本，先卸载再装，本地播放记录与设置会一并清掉。
6. **装完先别急着打开**：先把下一节的权限过一遍，否则首屏可能停在扫不到文件的空白列表上。

## 四、首次启动要给的权限

VPlayer 在官方商店描述里逐条列过它申请哪些权限、各自用来干什么。对照下表，启动时按顺序弹出的授权逐项给全即可：

| 权限 | 官方说明的用途 | 不给会怎样 |
| --- | --- | --- |
| 读取外部存储 / 文件与媒体 | 扫描并播放设备上的视频文件 | 列表一直是空的，扫不到本地片子 |
| 写入外部存储 | 在应用内重命名或删除文件 | 改名、删除这类操作会失败 |
| 网络访问 | 播放在线视频与流媒体 | 网络来源的视频打不开 |
| 读取手机状态 | 来电时暂停播放 | 来电话时声音不会自动停下来 |
| 唤醒锁 | 播放期间保持屏幕不熄灭 | 看着看着屏幕自己灭掉 |
| 修改音频设置 | 调整音效相关选项 | 音效类的开关不生效 |

Android 11 之后系统对存储访问收得更紧，有的机型在权限页里看到的是「照片和视频」「音乐和音频」分项，而不是笼统的「存储」。把媒体相关的几项都允许即可；这类播放器一般不需要你额外开「管理所有文件」这类总开关。

Android 13 及以后还多出一项**通知权限**，而且系统默认是关着的，要你点了允许才会开。这项不给的后果是：播放时通知栏里不会出现控制条，暂停、切轨都要切回应用里操作 —— 后台播放本身不受影响。如果发现通知栏少了控制条，去「设置 → 应用 → VPlayer → 通知」把它打开。

## 五、装完做一次最小验证

1. 打开 VPlayer，按上一节把权限给全；
2. 让它列一遍本地视频。列表里能看到手机里已有的视频文件，说明存储权限真正生效了；
3. 随便点一个 MKV 或 FLV 播放几秒，确认画面和声音都正常 —— 找一个系统自带播放器打不开的文件来试，更能说明解码这条路通了；
4. 播放时按一下电源键熄屏，或者切到别的应用，确认声音还在。如果一熄屏就断，去 [常见问题与排查.md](常见问题与排查.md) 看后台限制那一节。

装不上或者列表一直空着，先看 [常见问题与排查.md](常见问题与排查.md)；想确认手上这份能不能放你要看的那个文件，对照 [支持哪些格式与编码.md](支持哪些格式与编码.md) 里的编码清单。装之前如果还不确定自己下的是哪一个 VPlayer，先读 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
