VPlayer 是安卓上一款老牌本地视频播放器，3.x 系列发布于 2013 年前后，至今仍有人拿它放 RMVB、XVID 这类新播放器不爱处理的老编码。而安卓 14 与 15 会直接拦住「目标 API 级别过低」的安装包，于是出现旧手机装得上、新手机一装就失败的情况。这篇讲清这道闸门卡在哪、报错长什么样，以及被拦之后还有哪几条路可走。

## 一、先确认你的手机是哪个安卓版本

三种查法，任选一种：

- 「设置 → 关于手机 → Android 版本」；
- 「设置 → 系统 → 系统更新」里通常也会写明当前版本；
- 在拨号界面输入 `*#*#4636#*#*`，部分机型能进系统信息页看到版本号。

记住这个数字，它是后面所有判断的前提。安卓 14 对应 API 34，安卓 15 对应 API 35 —— 版本名和 API 级别是同一件事的两种叫法。

## 二、系统拦的是「目标 API 级别」，不是「能装的最低版本」

这是最容易混淆的一点，先分清这两个概念：

| 概念 | 含义 | 本文这份包的情况 |
| --- | --- | --- |
| 最低系统要求 | 系统低于它就不能装，是下限 | 标注为 Android 5.2 及以上 |
| 目标 API 级别 | 这个应用是按哪一代安卓开发、测试过的 | 属于安装包内部信息，本文无法从资料层面确认 |

安装包上标注的「Android 5.2 及以上」属于第一行，它管的是「太老的系统不行」；顺带说一句，安卓的公开版本号里并没有 5.2，这一栏本身就不是精确写法，具体见 [下载与安装教程.md](下载与安装教程.md) 第一节。而新系统拦人看的是第二行，管的是「这个包太老了」。两件事方向相反，所以会出现「标着 5.2 以上，装在安卓 15 上反而被拦」这种看起来矛盾的情况。

## 三、这条闸门具体卡在哪

按 Android 官方行为变更说明：

| 系统 | 拦截条件 |
| --- | --- |
| Android 14（API 34）及以上 | 目标 API 级别低于 23 的安装包不能安装 |
| Android 15（API 35）及以上 | 门槛再提高一档，目标 API 级别低于 24 的安装包不能安装 |

被拦住时的报错通常是这两种之一：界面上显示「应用未安装」或者「应用与你的设备不兼容」；用命令行安装的话会看到更明确的一行，形如 `INSTALL_FAILED_DEPRECATED_SDK_VERSION`，后面跟着「必须至少以 SDK 24 为目标，实际发现的是 7」这类说明。

另外还有一条相关的变化：从 Android 10（API 29）起，如果一个应用的目标 API 级别不高于 22，第一次启动时系统会额外弹一个「此应用专为旧版 Android 打造」的提示。这不影响安装和使用，只是提醒你它年代久。

## 四、怎么判断你手上这份会不会被拦

判断依据只有一个：**这份包的目标 API 级别**。它写在安装包内部，本文拿不到，所以有两条替代办法：

1. **最直接的：装一次试试。** 装不上且报的是上面第三节那两种提示，基本就是被拦了，不必反复重试，重复装不会有不同结果。
2. **看包的年份。** 这条线是 3.x 系列，公开记录里 3.1.4 是 2012 年底、3.2.2 是 2013 年秋、3.2.6 属于同一条线。那个年代的应用，目标 API 级别普遍偏低。所以在新系统上装不上是大概率事件，而不是小概率意外。

顺带说一句：**这份包本来是给旧系统那一代准备的**，被拦下是新系统的新规矩所致，不代表包本身损坏 —— 这一点决定了下一节的判断方向。

## 五、被拦住了，还有哪几条路

按成本和收益排序：

1. **换一台系统版本较低的设备来用。** 老手机、旧平板、闲置的电视盒子都是合适的载体；这份包在那类设备上本来就能跑，格式支持也不会因为换设备而变。如果你手上正好有闲置设备，这是最省事的一条。
2. **只有新手机时，改用仍在维护的播放器。** 同一个文件在别的播放器里能不能放，取决于它对编码的支持范围 —— 对照 [支持哪些格式与编码.md](支持哪些格式与编码.md) 里列的那几类编码（尤其是只走软解的 RMVB、XVID、VP6 这些）去挑，比看软件介绍页的宣传词靠谱。
3. **接受「手机负责放常见格式、老播放器留在旧设备上」这套分工。** 很多人最后就是这么一个用法：`MP4` 这类常见格式交给系统自带或新播放器，需要老编码的片子拿去旧设备上放。

有一条路这里不推荐也不展开：靠调试命令强行跳过系统的目标 API 拦截。它绕过的是系统一层实实在在的安全设计，装上去的东西也没经过新系统的兼容性验证，出问题的概率不低。

不管最后走哪条路，安装文件都从同一个地方取：[VPlayer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/615296deb124)。想先确认自己手上这份是不是本文说的那个 VPlayer，看 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 里的包名核对方法。

## 六、装上了但一开机就崩，属于另一类问题

被闸门拦住是「装不上」；装上了却黑屏、闪退、闪一下就没，是另一回事 —— 那是这份老包在新系统上跑不起来，常见诱因是新系统收紧了老应用依赖的一些接口。这类情况先按 [常见问题与排查.md](常见问题与排查.md) 第一节逐条试；试完仍旧启动不了，说明它和你这台设备的组合就是不成立，第五节第 1、2 条是更实际的选择。
