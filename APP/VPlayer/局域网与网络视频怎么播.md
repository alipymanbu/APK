# VPlayer 局域网与网络视频怎么播

> 除了放手机里的文件，VPlayer 也能接手局域网共享和网络流。这篇讲清「局域网媒体服务器」「直接填地址」「NAS」三条路各怎么走，以及连不上时按什么顺序查。

手机存储再大也放不下整套片库。把片子留在电脑或 NAS 上、用手机直接看，是这类播放器最常见的用法之一。官方在描述里列出的网络来源包括 NAS、局域网、UPnP、DLNA、DVR 等，传输方面则列了 HTTP、RTP/RTSP/RTMP、MMS 和多码率 HLS。下面按「哪种接法」来拆，不按协议名拆，因为你要做的动作差别很大。

## 一、先分清你要走哪条路

| 接法 | 适合什么 | 你要在服务端准备什么 |
| --- | --- | --- |
| 局域网媒体服务器（DLNA / UPnP） | 电脑或 NAS 上有一堆片子，想直接在列表里点开就看 | 在电脑 / NAS 上开启媒体共享，让它把自己广播出去 |
| 直接填地址 | 你手上已经有一个明确的视频链接或共享地址 | 知道地址本身，服务器能对外提供文件 |
| 网络共享挂载 | 想按目录浏览 NAS 上的文件夹，像操作本地文件一样 | NAS 上的共享目录已建好、有账号密码 |

三条路可以同时用，不冲突。选哪条只取决于你的服务端能提供什么。

## 二、DLNA / UPnP：把片库变成播放器里的一个列表

这是最像「相册式浏览」的一条路，服务端工作一次，之后手机上点开就能看。

1. **先在服务端开共享。** Windows 自带的「媒体流」功能、群晖等 NAS 上的媒体服务器套件、以及各种开源媒体库软件都能充当这个角色，打开后在设置里选中要共享的视频目录；
2. **确认手机和服务器在同一个网络下**，并且不是访客网络 —— 访客网络一般禁止设备之间互访，这条最容易踩；
3. **在 VPlayer 里找局域网 / UPnP 类的入口**，它会把同一个网络里广播出来的服务器列出来，进去按目录一层层点；
4. 点开就播，不需要先把文件拷到手机上。

这条路有个特点：**能不能播由服务端和播放器两边共同决定**。有些媒体服务器会按自己的判断转码后再送出去，这时你实际拿到的画质和文件本身可能不一样；如果你更在意原画质，就让服务端直接送原文件，或者改走下一节。

## 三、直接填地址：拿到什么播什么

当你手上已经有一个地址时，就不必依赖自动发现。官方清单里支持的传输类型包括：

| 类型 | 典型用途 |
| --- | --- |
| HTTP / HTTPS | 服务器上放着的普通视频文件、网页直链 |
| HLS（多码率） | 后缀为 `.m3u8` 的流媒体，常见于直播和在线课程 |
| RTSP | IP 摄像头、部分流媒体服务器 |
| RTMP | 直播推拉流 |
| MMS | 较老的流媒体地址，现在少见 |

做法就是新建一个网络地址条目，把地址粘进去回车。几点提示：

- **地址里的空格和换行要清掉**，从网页或聊天里复制粘贴时很容易带进来；
- **`https` 的地址如果对方证书不规范，可能连不上**，此时换 `http` 试一次再判断；
- **HLS 的多码率是服务器侧提供的**，播放器会在其中挑合适的一档，所以同一个 `.m3u8` 在手机和电脑上清晰度不同是正常的，不是画质被压了；
- 想确认某个协议到底在不在支持范围内，回 [支持哪些格式与编码.md](支持哪些格式与编码.md) 的传输那一节对照。

## 四、NAS 上的片子怎么放

NAS 上通常三种服务都有，按你的习惯挑一种：

1. **媒体服务器套件 + DLNA**：最省事，手机上当作一个列表来点，适合懒得记地址的人；
2. **共享目录（SMB / 网络共享）**：如果你习惯按文件夹浏览、需要按目录找片子，走这条路；在 NAS 上建好共享目录和账号，手机端连过去后就像浏览本地目录一样；
3. **网页文件服务**：某些型号的 NAS 自带文件浏览网页，点开视频会给出一个地址，把地址丢进上一节的方式播放即可。

一条实用建议：**先在电脑上验证同一份内容能不能正常访问**，再去折腾手机端。电脑能访问说明服务端是好的，问题就锁定在网络或播放器上；电脑也访问不了，那手机这边怎么调都没用。

## 五、连不上时按这个顺序查

按从大范围到小范围的顺序排查，每一步都能排除一批可能：

1. **看是不是同一个网络。** 手机连的是不是同一个路由器的同一个频段 / 同一网段，有没有不小心连到访客网络或手机数据。这一步排掉的问题最多。
2. **换一台设备试同一个地址。** 用别的手机或电脑访问同一个共享目录或同一个链接：能访问，说明服务端正常，问题在播放器这边的地址写法；不能访问，说明是服务器或网络设置的问题。
3. **看服务器有没有休眠。** 播放到一半突然中断，多半是电脑进了睡眠或者账号被注销，把电脑的睡眠改成「从不」。
4. **看带宽。** 能连上但一直转圈，通常是无线带宽跟不上片源的码率 —— 高码率的 1080p 原盘在拥挤的 2.4G 频段上很容易跑不动。换成有线，或者先拿一个低码率的文件测试，就能确认是不是这个原因。
5. **看文件的编码。** 网络通了、地址对了，还是黑屏或者只有声音，问题就不在网络，回到 [支持哪些格式与编码.md](支持哪些格式与编码.md) 判断编码。

放网络上的片子时，外挂字幕放在服务端的同一个目录、和视频同名即可被自动匹配，规则和本地一致。字幕乱码、时间轴对不上这类问题不属于网络这一节，见 [字幕加载与乱码解决.md](字幕加载与乱码解决.md)；如果排查到怀疑是播放器本身的问题，[常见问题与排查.md](常见问题与排查.md) 里有按现象分节的处理办法。
