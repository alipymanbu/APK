## 一、本篇怎么用

下面按「症状 → 先查什么 → 怎么处理」组织。先自查，自查解决不了再找客服（入口在最后一节）。涉及安装包本身的（下载不完整、MD5 对不上）先回 [下载与安装教程.md](下载与安装教程.md) 核对。

## 二、安装与启动

| 症状 | 先查什么 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 下载的文件是否完整 | 重新下载，核对 MD5 为 `331D66CFC2709C21BD06802E4900CB3E`、大小 102.22M |
| 提示「禁止安装未知应用」 | 点开安装包用的那个应用有没有授权 | 按 [下载与安装教程.md](下载与安装教程.md) 第三节开一次权限 |
| 装完一点就闪退 | 系统版本、剩余存储 | 本地记录标注安卓 5.2 以上（以安装提示为准）；清理出几百 MB 再试；仍闪退换官方商店渠道的版本对照 |
| 桌面找不到图标 | 图标是否被隐藏 | 「设置 - 应用」搜「录咖」或 `com.wangxutech.reccloud` |

**闪退 / 无响应的通用排查顺序**（多家手机厂商官方支持页给出的步骤，与具体机型无关）：

1. 重启手机 —— 清掉临时故障，成本最低；
2. 清缓存：长按录咖图标 - 应用信息 - 存储占用 - 清理缓存（**清数据会删掉本地登录态与设置**，云端文件不丢，重新登录即可）；
3. 检查权限：应用信息 - 权限，把麦克风、存储等需要的权限打开；
4. 升级：系统设置里更到最新系统，商店里更到最新版录咖 —— 闪退常出现在某次更新之后，官方修掉后升级即可；
5. 以上都试过还闪退：卸载重装（重装前确认云端文件都已同步，见下文「换手机了数据还在吗」）。

## 三、上传与转写

**文件传不上去** —— 先对上限表（网页端口径，以页面当时显示为准）：

| 项目 | 限制 |
| --- | --- |
| 视频 | ≤ 4GB |
| 音频 | ≤ 500MB |
| 时长 | ≤ 5 小时 |
| 免费转写 | 每日 1 次，限 20 分钟内文件 |
| 免费用户可处理文件 | 100M 以内（权益页口径） |

超限就先拆分或压缩文件；手机端处理大文件建议改到网页端（[录音转文字怎么用.md](录音转文字怎么用.md) 第三节）。

**转写结果不准**：官方说明明确「转录质量可能受背景噪音及说话人口音影响」。可自查的变量：录音是否离声源太远、背景音乐是否过响、是否选对了转写语言；通读改一遍人名与数字比反复重跑省钱 —— 重新生成智能总结会再扣 1 算粒/分钟。

**一直转圈 / 任务没动静**：任务是排队处理的，免费与普通会员同时处理 2 个任务；先确认不是同时塞了太多任务，再刷新结果页看任务状态。

**任务失败了但看不出原因**：官方 [API 文档](https://reccloud.cn/status-api-doc) 公布了任务失败的状态码含义，App 与网页端报的错也对应这几类，可按表自查：

| 状态 / 提示 | 含义 | 你该做什么 |
| --- | --- | --- |
| 未识别到有效语音内容 | 整段没听出人声 | 检查文件是否静音、音量过低，或换一段有清晰人声的 |
| 处理超时 | 任务没在官方时限内跑完 | 先等一会重试；反复超时就把文件分段后再传 |
| 无效文件 | 文件损坏或格式不对 | 换 MP3 / WAV / M4A 等常见格式重新导出再传 |
| 超出大小 | 超过该功能的大小限制 | 对上文的上限表，压缩或拆分 |
| 上传失败 / 下载失败 | 网络原因 | 换网络（Wi-Fi 与流量互切）重试 |

**网页端页面打不开或按钮没反应**：录咖网页端明确提示 Safari 不支持相关页面，换 Chrome 或 Edge 打开；公司 / 校园网若拦截了上传，切到手机热点再试。

## 四、额度与账号

- **算粒不够用**：账号页看余额；各功能消耗见 [会员算粒与自动续费说明.md](会员算粒与自动续费说明.md) 第四节。免费用户只有 10 算粒，转写一分钟就扣 1 算粒，很快就见底。
- **云存储满了**：免费用户 2G、最多 5 个文件；把不再需要的文件删掉，或升级会员（10GB 起）。
- **换手机了数据还在吗**：文件与处理结果在账号云端，新手机登录同一账号即可找到；会员账户官方口径为跨平台通用。
- **重复扣费 / 想退订**：取消自动续费的路径（微信、支付宝、App Store）在 [会员算粒与自动续费说明.md](会员算粒与自动续费说明.md) 第六节；退款规则在同篇第五节；**钱已经被扣走的追回顺序与投诉渠道**，走 [自动续费扣费怎么追回.md](自动续费扣费怎么追回.md)。
- **注销账号**：App 内「个人头像 - 我的账号 - 设置 - 删除账户」，或联系客服代办。**注销不可逆，一切数据无法恢复**，注销前先把需要的文稿导出。

## 五、找不到处理结果 / 导出失败

- 网页端结果页支持复制、下载 Word、生成分享链接；下载按 6 算粒/GB 计费 —— **余额不足会导致下载失败**，先看算粒；
- 文件在「我的空间」里，按上传时间找；免费用户最多存 5 个文件，旧文件可能已被清理；
- 分享链接打不开：确认链接没有过期或被删除，重新生成一次（分享按 8 算粒/分钟计费）。

## 六、自己查不到的，找官方

- 购买、退款、技术问题：[录咖联系页面](https://reccloud.cn/contact) 提交工单；
- 隐私与账号数据问题：官方协议公布的邮箱 `privacy@wangxutech.com`；
- 政策细节先读 [退款政策](https://reccloud.cn/refund-policy) 与购买方案页的常见问答，再提交工单会更快。
