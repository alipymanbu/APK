# V380 Pro 添加摄像头配网教程

> 本篇讲怎么把 V380 系列摄像机添加进 V380 Pro App：先认清你该用哪种配网方式，再按步骤操作。

## 一、配网前必须知道的三件事

1. **摄像机只支持 2.4GHz Wi-Fi**。现在多数路由器是双频的（2.4GHz 和 5GHz 发同一个名字或两个名字），摄像机连不上 5GHz 那一路。如果家里 2.4GHz 和 5GHz 是两个名字，配网时一定选 2.4GHz 那个。
2. **Wi-Fi 必须设密码**，加密方式用 WPA2-PSK 或更低级别；Wi-Fi 名字里带中文、空格或特殊符号时，部分机型会配网失败，遇到问题可以先临时改成纯英文数字的名字。
3. **配网只需要做一次**。成功之后摄像机记住这个 Wi-Fi，除非换网络或重置，不用反复配。

开始前把摄像机**放在路由器旁边**（一两米内），信号越强配网越快；成功后再装到想装的位置。

## 二、先重置，听语音提示定方式

不管哪台摄像机，配网前都建议先恢复到「等待配网」状态：接通电源，等它说完开机提示，**长按机身上的 reset（复位）键几秒**，听到「恢复出厂设置」、接着「等待 Wi-Fi 智能配网」之类的语音后松手。

这时注意听它接下来怎么说：

| 摄像机的语音提示 | 你该用的方式 | 对应章节 |
| --- | --- | --- |
| 「等待 Wi-Fi 智能配网」 | Wi-Fi 智能配网（快配） | 第三节 |
| 「热点已建立」/「接入点准备就绪」 | AP 热点连接 | 第四节 |
| 「蓝牙准备就绪」 | 蓝牙配对 | 第五节 |
| 「请扫描机身上的二维码」 | 二维码配网 | 第六节 |

语音措辞随机型和固件有差异，以你机器实际说的为准。不同方式互相不冲突——一种试不过关就重置换下一种，这是最省时间的路子。

## 三、方式一：Wi-Fi 智能配网（快配）

这是最常见的方式，前提是手机已经连上家里 2.4GHz Wi-Fi。

1. 打开 V380 Pro，点设备列表右上角的 **「+」**，选「添加设备 / Wi-Fi 智能配网」（部分安卓版本上叫「Wi-Fi 快速配置」）。
2. 确认界面上显示的 Wi-Fi 名字就是你手机正在用的那个，输入 Wi-Fi 密码，点下一步。
3. 把手机拿到摄像机旁边等。App 会把 Wi-Fi 名字和密码「喊」给摄像机，摄像机依次播报「已收到配置信息」→「Wi-Fi 连接中」→「Wi-Fi 已连接」。
4. App 提示完成，摄像机出现在设备列表里。

**安卓 10 及以上的手机**在配网时可能会要求连接设备热点（名字形如 `MV` + 数字），按提示允许即可。整个过程手机别切走 App。

## 四、方式二：AP 热点连接

摄像机自己发一个热点，手机去连它。在没有可用路由器、或快配一直失败的场合用这个。

1. 长按 reset 听到「等待 Wi-Fi 智能配网」后，**再长按 1~2 秒**，直到听到「热点建立中」→「热点已建立」。
2. 打开 App，点「+」；机身有二维码就直接扫，没有就点「在设备上找不到二维码？」，选「Wi-Fi 智能摄像机」→「AP 热点连接」。
3. 选好要给摄像机配的 Wi-Fi 并输入密码，然后按 App 提示去手机系统设置连**摄像机的热点**——名字是 `MV` 加一串数字（如 `MV12345678`）。安卓可能弹「此网络无法访问互联网，仍要连接吗」，选**仍然连接**。
4. 连上热点后返回 App 等提示音，成功后给设备起个名字，点完成。

配网完成后摄像机还停在「只跟手机直连」的状态——要出门也能远程看，把它接回路由器：在 App 里进设备**设置 → 网络**，选「Station 模式（连接路由器使用）」，从附近 Wi-Fi 列表里选你家 2.4GHz 网络、输密码、保存，摄像机播报「Wi-Fi 已连接」即完成。

**只有热点、没有路由器的用法**：一直让手机连着摄像机热点也能看画面，但手机此时上不了别的网，而且人一离开热点范围画面就断——只适合临时近距离查看。

## 五、方式三：蓝牙配对

部分较新的机型支持蓝牙配网（开机语音会说「蓝牙准备就绪」）：

1. 打开手机蓝牙，进 App 点「+」添加设备，选蓝牙方式，App 会搜到附近的摄像机。
2. 选中你的设备，选 Wi-Fi、输密码，剩下的按界面提示走，摄像机播报「Wi-Fi 已连接」即成功。

蓝牙方式的好处是 App 和设备直接对话，不依赖 Wi-Fi 信号强弱，快配失败时值得一试。

## 六、方式四：二维码配网

开机语音说「请扫描机身上的二维码」的机型用这个：

1. 手机连上 2.4GHz Wi-Fi，进 App 点「+」扫**机身上贴的二维码**。
2. 选摄像机要连的 Wi-Fi，输密码确认。
3. App 会生成一个**动态二维码**，把它举到摄像机镜头前 15~25 厘米，等它说「已收到配置信息」→「连接中」→「网络已连接」。
4. App 提示完成。

二维码对不上时稍微换个距离和角度，屏幕亮度调高一些。

## 七、没有二维码、没有语音提示怎么办

二手摄像机、贴纸磨损的机器，用**手动添加**：

- 机身上找不到二维码：在添加界面点「在设备上找不到二维码」，选「手动添加 / 局域网搜索」。
- 设备 ID 就印在机身底部标签上，格式是 `MV` 开头加一串数字（如 `MV12345678`）。手动输入这个 ID，确认后按提示继续。

4G 版摄像机不走 Wi-Fi 配网：装好 SIM 卡（nano 卡）、插卡开机后按 App 提示激活即可，注意物联网卡要在 App 里设置好 APN 才能上网。详细的插卡步骤、指示灯含义与报错处理见 [4G款插卡上网与流量排查.md](4G款插卡上网与流量排查.md)。

## 八、配网失败先查这几条

反复失败时按顺序过一遍，多数问题出在前三条：

1. **手机和摄像机是不是都站在 2.4GHz 上**——手机自己连 5GHz 时，快配会把这个错误频段喊给摄像机。
2. **Wi-Fi 密码输错**是最常见的低级失误，重新输一遍。
3. **摄像机离路由器太远**——挪到路由器旁边再试。
4. Wi-Fi 名字带中文或特殊字符——改纯英文数字。
5. 上面都正常还失败：重置摄像机换一种配网方式（见第二节），仍不行再看 [常见问题排查.md](常见问题排查.md) 的设备离线一节。
