## 一、4G 款不连 Wi-Fi，插卡开机就能用

4G 款走运营商蜂窝网络，没有 Wi-Fi 配网这一步：

1. 装好天线（天线没拧等于没信号源，先拧紧）。
2. 插入 nano SIM 卡（物联网卡或手机卡均可，注意方向和卡槽类型）。
3. 上电开机，等指示灯变**黄**——黄灯就是联网成功。
4. 打开 App 点「+」，扫机身二维码或手动输入设备 ID 添加。

所以 4G 款适合没有 Wi-Fi 的场合：果园、鱼塘、工地、门口没有路由器的院子。代价是流量持续花钱。

## 二、指示灯对照表

| 指示灯 | 含义 |
| --- | --- |
| 灭 | 关机，或太阳能款在待机睡觉 |
| 红灯常亮 | 已开机，但网络不可用 |
| 黄灯 | 已连上网，正常 |
| 红灯连续快闪 | 读不到 SIM 卡——检查卡有没有插好 |
| 红灯连闪两下循环 | 能读到卡，但连不上网——查套餐还有没有流量 |

## 三、两个典型报错的处理

**「拨号超时，请确认 SIM 卡状态」**——联网失败。按顺序查：卡是否可用、套餐是否还有剩余流量、天线是否接好、卡是否插对方向；都没问题就挪到信号好的地方再连一次。

**「SIM 卡未识别」**——机器读不到卡。断电、拔卡重插、再上电；仍然不识别就重置摄像机重来。卡槽接触不良在户外机器上很常见，重插一次往往就好了。

## 四、流量消耗：官方给的参考口径

按官方说明（截至本文写作时的口径，以官方页面为准）：

| 使用方式 | 流量消耗 |
| --- | --- |
| 不预览、不用云录像 | 只耗少量流量 |
| 24 小时持续预览 | 约 2~4GB（每天） |

实际账单主要取决于你盯实时画面的时长和是否开了云存储。选物联网卡套餐时按这个口径估算：只在有报警时点开看几眼的用法，小流量套餐就够；习惯全天挂着预览的，别用小套餐，避免产生高额流量费用。

## 五、信号差、常掉线的排查

1. **先测信号**：把同运营商的手机卡装进手机、拿到安装位置看信号格数——手机也弱就是位置问题，考虑挪机器或加长天线。
2. **换卡测试**：有别的运营商卡就换上试，部分位置恰好某家信号差。
3. **查供电**：太阳能 4G 款要求 5V/2A 供电，电压电流异常会连不上网甚至启动不了（见 [电池与太阳能款工作模式设置.md](电池与太阳能款工作模式设置.md) 第四节）。
4. 以上都正常还掉线，回到通用排查流程：[常见问题排查.md](常见问题排查.md) 第一节。
