# Gmail 收不到邮件怎么解决

> 新邮件不来、收件箱一直转圈、提示无法同步——本篇按出现概率从高到低排一遍排查顺序，多数情况五分钟内能定位。

## 一、先分清两种「收不到」

- **App 里能看到旧邮件，新邮件迟迟不来** → 多半是同步或后台问题，按第三、四节查；
- **App 里一直转圈、提示无法连接** → 当前网络到 Google 的链路不通，重点查第二节。

还有两种容易被误判的情况：**存储空间满了**（界面会有「存储空间已满」的横幅，直接看[存储空间满了怎么办.md](存储空间满了怎么办.md)）；**账号被移出设备**（登录与账号状态先确认一遍，见[登录与多账号管理.md](登录与多账号管理.md)）。

## 二、网络环境（最常见的原因）

Gmail 的收发与同步都要直连 Google 的服务器。在中国大陆的常规家庭与办公网络下，这些服务器无法直接访问，表现就是一直转圈、「无法连接服务器」、新邮件永远不来。**这不是安装包或账号的问题**——重装 App、换账号、换手机都不会有变化；同一部手机能否收到邮件，只取决于当前网络能否直连 Google。

做个对照测试：手机浏览器打开 `https://www.google.com`。能打开，说明当前网络环境没问题，转去查手机设置；打不开，就是网络环境本身，换一个能直连的网络（例如漫游或境外的网络）再试。

## 三、同步设置

1. Gmail 侧边栏 → 设置 → 点你的账号 → 确认「同步 Gmail」开着；
2. 「要同步的天数」默认只同步近 30 天——这只影响本地保留多少旧邮件，不影响新邮件到达；想翻更早的邮件可以改成 90 天或「全部」；
3. 下拉收件箱手动刷新一次，看能否触发同步；
4. 系统设置 → 账户 → Google → 点进账号 → 确认「Gmail」这一项的同步开关没被关掉。

## 四、后台被系统查杀（国产系统常见）

省电策略激进的品牌（小米、华为、OPPO、vivo 等）会在锁屏后掐掉 Gmail 的后台，推送就断了。逐项处理：

- 设置 → 应用 → Gmail → 电池 / 省电策略 → 改为「无限制」（不同品牌叫法略有差异）；
- 同一页面把「自启动」打开；
- 设置 → 通知 → Gmail，确认通知权限开着；
- 系统若有「纯净模式 / 深度休眠 / 神隐模式」这类开关，把 Gmail 加入白名单。

判断方法：把 Gmail 开在前台不锁屏，请人发一封测试邮件——能到；锁屏几分钟后就断——基本就是后台查杀，按上面四条处理。

## 五、其他检查点

| 检查点 | 怎么查 |
| --- | --- |
| 垃圾邮件 | 侧边栏打开「垃圾邮件」；确认不是垃圾的邮件点「报告非垃圾邮件」，以后同类邮件会正常进收件箱 |
| 过滤器 | 网页版 Gmail（`https://mail.google.com`）→ 设置 → 查看所有设置 → 过滤器和屏蔽的地址——过滤器可能把邮件自动归档或转发走了，App 里看不到这项设置 |
| 发件地址 | 让发件人核对地址有没有拼错（尤其是句点、下划线） |
| 服务故障 | 打开 `https://www.google.com/apps/status/dashboard` 看 Gmail 状态条；大面积故障时只能等恢复 |

反过来，你是发件方、对方说没收到：先看这封信是不是被定时了（「已定时」标签里能看到），附件超过 25 MB 也会发不出去——这两件事的处理见[定时发送与撤回邮件.md](定时发送与撤回邮件.md)。
