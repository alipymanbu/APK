## 一、CosZ 是什么

CosZ 简称「C站」，是一个面向二次元爱好者的社区类安卓应用：你能在这里看 Cosplay 作品、手绘插画、JK / 洛丽塔 / 汉服等服饰板块，也能自己发图、写文字、参与讨论。本篇只讲怎么把安装包装到手机上；装好之后怎么注册、怎么逛，看另外两篇。

## 二、下载安装包

1. 打开 **[CosZ 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c0477ba6d425)**，转存到自己的网盘后下载；
2. 网盘里是一整个应用文件夹，里面除了安装包还有一个说明 txt，一起留着即可；
3. 安装包文件名带版本号（形如 `CosZ_v1.1.1.apk`），下载时认准这个命名，别拿成别的 apk。

## 三、下载前核对包信息

网上各下载站给的 CosZ 信息互相能对上，装之前你可以用下表核对手里这份是不是同一个包：

| 项目 | 值 |
| --- | --- |
| 应用名 | CosZ |
| 版本 | 1.1.1 |
| 包名 | `com.g1050403222.bei` |
| 大小 | 3.47M |
| MD5 | `95EB51D8586A7C1B35E9F21D94E22A50` |
| 系统要求 | 安卓 5.2 以上 |

MD5 可以用手机上的校验工具算一遍，一致再装。各下载站标注的版本也都是 1.1.1，与这份包一致；以后官方发了新版，以官方渠道当时显示的版本为准。

## 四、安装步骤

1. 从网盘把 apk 下载到手机（用浏览器或网盘客户端下载均可）；
2. 点击 apk 开始安装，系统若弹出「禁止安装来自此来源的应用」，是没给浏览器/文件管理器开安装权限，去 `设置 → 安全/安装未知应用` 里给对应的来源打开开关，再回来装；
3. 等安装完成，桌面会出现 CosZ 图标。

安装包只有 3.47M，安装本身很快；装完可以到 `设置 → 应用 → CosZ → 应用信息` 里看版本号是不是 1.1.1。

## 五、首次启动注意什么

- 首次打开会进首页，底部有「社区」等入口，各板块的位置见[社区板块与日常使用.md](社区板块与日常使用.md)；
- 浏览不一定要登录，但签到、领每日任务、发作品、评论互动都需要登录，注册方式见[注册与登录方法.md](注册与登录方法.md)；
- 如果打开就闪退、卡在白屏，或者装的时候报错，按[常见问题与排查.md](常见问题与排查.md)逐条排查。
