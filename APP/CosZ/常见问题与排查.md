## 一、安装时报「禁止安装未知来源应用」

安卓默认只允许从应用商店装。去 `设置 → 安全/安装未知应用`（不同品牌叫法略有差异），给你下载 apk 的那个来源（浏览器或网盘客户端）打开开关，再回到安装界面重装。装完可以顺手把开关关回去。

## 二、安装包解析失败 / 装到一半失败

按顺序排查：

1. **包没下完整**：3.47M 的包下到一半断网就会损坏，重新下载一次；
2. **包不是这个版本的**：核对文件名与大小，对照下表确认是同一份：

   | 项目 | 值 |
   | --- | --- |
   | 包名 | `com.g1050403222.bei` |
   | 版本 | 1.1.1 |
   | 大小 | 3.47M |
   | MD5 | `95EB51D8586A7C1B35E9F21D94E22A50` |

3. **系统版本太低**：CosZ 要求安卓 5.2 以上，低于这个版本装不上。

## 三、打开就闪退 / 白屏

1. 先确认手机系统符合要求（安卓 5.2 以上）；
2. 部分机型的省电模式会限制后台与网络，把 CosZ 加入省电白名单再试；
3. 还不行就卸载重装——包很小，从[下载与安装教程.md](下载与安装教程.md)重新走一遍即可；
4. 闪退反复出现时，注意自己装的是否为 1.1.1 这份包（MD5 见上表），来路不明的包可能被改过。

## 四、登录不上

1. 选错入口是最常见的：邮箱账号要在邮箱入口登、QQ 账号要在 QQ 入口登，两者是不同账号（详见[注册与登录方法.md](注册与登录方法.md)）；
2. 密码注意大小写与输入法（中文输入法状态下容易多敲字符），重新输一遍点「快速登录」；
3. 网络不稳也会表现为「点了没反应」，切一下 Wi-Fi / 流量再试；
4. 以上都排除了，卸载重装后重新登录（重装会清掉本地登录态，但账号数据在服务端，不影响已有作品）。

## 五、页面空白 / 内容刷不出来

1. 先看手机网络：换个网络环境试，社区内容全靠联网加载；
2. 若只是某个板块空白，可能是该分区当下内容少或服务波动，退出重进、稍后再看；
3. 一直空白就清一次应用数据：`设置 → 应用 → CosZ → 存储 → 清除数据`，再打开重新登录。

## 六、版本与更新

- 当前这份安装包是 **1.1.1**（包名 `com.g1050403222.bei`），公开渠道看到的最新版也是 1.1.1，更新日志大意是「优化社区体验、修复部分已知问题」；
- 版本会随时间变化，**以官方渠道当时显示的版本为准**；换新版本前建议先核对包信息，方法见第二节。
