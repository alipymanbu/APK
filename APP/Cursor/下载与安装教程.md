## 一、先分清你要装的是哪个「Cursor」

搜索引擎里叫 Cursor 的东西不止一个。本篇讲的是 Anysphere 出品的 AI 代码编辑器 Cursor：基于 VS Code 代码库改造，内置 AI 对话与代码智能体，只有 **Windows / macOS / Linux 桌面版，没有手机客户端**。如果你要找的是浏览器鼠标指针美化之类的小工具，那不是本篇的对象。

## 二、两种获取渠道

| 渠道 | 版本 | 适合谁 |
| --- | --- | --- |
| 官网下载页：[cursor.com/cn/downloads](https://www.cursor.com/cn/downloads) | 官方当前最新版 | 想直接用最新版的 |
| [Cursor 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f93c90fccd10) | 固定 v0.50.5，安装包约 109.85 MB | 官网下载慢、或想装 0.50 系列固定版本的 |

两种渠道拿到的都是同一个安装文件，装出来没有区别。登录、订阅、更新这些账号相关的事一律走官方，网盘资源只负责把安装包送到你手上。装上 v0.50.5 之后编辑器会提示自动更新，跟着更到新版即可。

## 三、系统要求（以官方下载页当时标注为准）

| 系统 | 要求 |
| --- | --- |
| Windows | Windows 10 及以上，64 位安装包（.exe） |
| macOS | macOS 12（Monterey）及以上，.dmg 镜像，Apple Silicon 与 Intel 都支持 |
| Linux | 官方提供 deb / rpm 软件源与 AppImage，Debian/Ubuntu 推荐 |

## 四、Windows 安装步骤

1. 从上面任一渠道拿到安装包（.exe）；
2. 双击运行，按安装向导一路「下一步」，安装路径默认即可；
3. 装完启动 Cursor，首次启动会出现引导页（选键位、主题，不确定就一路默认）；
4. 弹出登录窗口时完成登录——AI 功能必须登录后才能用，见下一节。

macOS 的差别只在第 2 步：打开 .dmg 后把 Cursor 拖进「应用程序」文件夹。

## 五、首次启动：先登录再干活

Cursor 的 AI 能力跑在云端模型上，**不登录就基本只是一个普通编辑器**。登录窗口支持直接用 Google 或 GitHub 账号授权，也可以用邮箱注册；没有账号先去官网免费注册一个（不需要信用卡）。注册方式、免费额度边界与付费档位，统一写在 [注册登录与免费额度.md](注册登录与免费额度.md)。

## 六、从 VS Code 换过来：一键导入旧配置

Cursor 与 VS Code 同源，旧配置可以整包搬过来：

1. 按 `Ctrl+Shift+J`（macOS 为 `Cmd+Shift+J`）打开 Cursor Settings；
2. 进入 **General → Account**；
3. 在 **VS Code Import** 一栏点 **Import**，扩展、主题、设置、快捷键会一起迁过来。

两个注意点：

- Cursor 的扩展走 Open VSX 市场而不是微软官方市场，个别扩展可能搜不到或行为有差异；
- Cursor 和 VS Code 是两个独立程序，可以并存，同一个项目两边都能打开。

装完默认是英文界面，想把菜单换成中文，见 [中文界面设置方法.md](中文界面设置方法.md)。

## 七、装完先做这三件事

1. 打开一个项目文件夹（`File → Open Folder`），按 `Ctrl+L` 唤出 AI 对话问一句「这个项目是干嘛的」，能正常回答说明 AI 已在工作；
2. 在设置里确认版本号：v0.50.5 属于 2025 年 5 月发布的 0.50 系列，建议让编辑器保持自动更新；
3. 遇到登录转圈、报错之类的问题，先翻 [常见问题排查.md](常见问题排查.md)，不要急着删了重装。
