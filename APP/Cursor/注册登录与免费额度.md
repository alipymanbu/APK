## 一、注册：三种方式任选

第一次启动 Cursor 会弹出登录窗口，也可以先在官网注册好再装。三种方式：

1. **Google 账号授权**——点登录页的 Google 选项，用现有的 Google 账号确认即可；
2. **GitHub 账号授权**——同上，日常用 GitHub 的开发者顺手；
3. **邮箱注册**——填邮箱、收验证邮件完成注册，适合没有前两者的。

注册免费，全程不需要信用卡。

## 二、免费版（Hobby）能用到什么程度

| 项目 | 说明 |
| --- | --- |
| 价格 | 0 元，无需信用卡 |
| 智能体请求 | 有限次数，用完当月只能等刷新或升级 |
| Tab 补全 | 有限次数 |
| 模型 | 可访问官方提供的模型（含自家 Composer 系列的有限访问） |

具体额度数值官方会调整，以 [官方定价页](https://cursor.com/cn/pricing) 当时显示为准。判断标准很简单：偶尔试水够用；如果每天都靠 Agent 干活，免费额度撑不满一个工作日，升级才实际。

参考一下历史口径：网盘这份 v0.50.5 所在的 0.50 时代（2025 年年中），免费版是每月约 2000 次 Tab 补全加 50 次慢速高级请求（官方当时定价页；0.50 更新说明确认配额不变）。现在的额度结构与当时不同，别拿这个数对现在的账。

## 三、付费档位一览（截至 2026-09 查看，以官方页面为准）

| 档位 | 价格 | 相比免费版多什么 |

额度用尽也不一定非要升级档位：官方支持按用量后付费，包含额度用完后继续用、按实际用量结算（入口与计费细节以官方定价页与 dashboard 说明为准）。偶尔超量用的人，这笔账通常比升一档划算。

## 四、用量在哪里查

- 网页后台：`https://cursor.com/dashboard`，能看到各模型、各功能的用量明细与剩余额度；
- 编辑器内：`Ctrl+Shift+J` 打开 Cursor Settings，账户页里也有用量入口。

提示额度用完但用量对不上时，先去 dashboard 看明细，确认是哪个模型消耗的，再决定升级还是调使用习惯。

## 五、隐私模式：不想让代码进训练就打开

Cursor Settings 里可以开启 **Privacy Mode**，开启后你的代码不会被存储或用于模型训练；团队版可以由管理员强制全员开启。处理公司代码或涉密项目前，建议先确认这一项已经打开。

## 六、换电脑、退出登录

同一个账号可以在多台电脑上登录使用；退出登录在 Cursor Settings 的账户页。换新电脑不需要任何「迁移工具」，登录同一账号，订阅与额度自动恢复。
