## 一、三种 AI 模式怎么选

| 你想干什么 | 用哪个 | 说明 |
| --- | --- | --- |
| 问问题、让人解释代码，不改文件 | Ask | 只对话，不动你的代码 |
| 按你的要求改指定范围的代码 | Edit | 你描述改法，它给出改动让你确认 |
| 整段任务直接丢给它 | Agent | 自己找上下文、改多个文件、跑终端命令，每一步你都能看到并确认 |

刚上手记住一条就行：**拿不准就用 Agent**，它自己会判断该读哪些文件；想保持控制感就用 Ask / Edit。Agent 默认在执行终端命令前会征求你确认，不放心就保持默认。

## 二、Tab 补全：打了开头让它续

正常打字时 Tab 补全一直在工作：你写到一个函数的开头，它会以灰色虚影给出后续整段建议，按 `Tab` 采纳、继续打字则忽略。它给的不是单行补全，常常是跨几行甚至跨文件的改动建议——0.50 系列起这点明显增强，重构、连续编辑时尤其好用。

## 三、Ctrl+K：选中就改，不选就生成

- **选中一段代码按 `Ctrl+K`**：输入你想怎么改（比如「加上参数校验」），它原地给出 diff，确认后生效；
- **不选中直接按 `Ctrl+K`**：在光标处从零生成一段代码；
- 0.50 系列起内联编辑界面重做，新增了整文件编辑与「发送给 Agent 继续处理」的选项，单文件大改动不用再手动切模式。

终端里也能按 `Ctrl+K`，用自然语言描述你想要的命令，它帮你转成实际的 shell 命令。

## 四、对话里的 @ 引用：把上下文喂准

AI 答非所问，八成是上下文没喂对。对话输入框里用 `@`：

- `@文件名` / `@文件夹`——精确指定让它看哪些内容；
- `@Web`——让它先搜网再回答，适合问新版本、新用法；
- `@Docs`——引用官方文档库；
- 对整个代码库提问用 `Ctrl+Enter`，它会先检索仓库再回答；
- 0.50 起支持 `@folders` 把整个代码库塞进上下文（需在设置里开启 Full folder contents）。

大仓库第一次用全库问答前会先建索引，索引没建完时回答会不准，等它完成再试。想让某些文件永远不进上下文、或让 AI 默认按你项目的规范干活，配法见 [项目规则与忽略文件配置.md](项目规则与忽略文件配置.md)。

## 五、你手里这版（0.50 系列）的新东西

网盘资源是 v0.50.5，属于 2025 年 5 月发布的 0.50 系列。这一系列相对更早版本的主要变化：

- 计费统一为按请求计费（影响的是账号额度怎么算，与安装包本身无关）；
- Max 模式开放给各顶级模型；
- 后台智能体（Background Agent）以预览形式引入，任务可以在远端环境并行跑；
- Tab 补全模型升级，能跨文件给建议，补全预览加了语法高亮；
- 内联编辑（`Ctrl+K`）重做：整文件编辑、发送给 Agent；
- 支持多根工作区（一个窗口挂多个项目目录）；
- 对话可以导出与复制。

0.50.x 的各个小版本修的都是细节，比如 0.50.5 修的是「切换文件时聊天窗口的文件标签不刷新」。这些不影响安装方式，装完保持自动更新即可。

## 六、快捷键速查（Windows / macOS）

| 动作 | Windows / Linux | macOS |
| --- | --- | --- |
| 打开 AI 对话 | `Ctrl+L` | `Cmd+L` |
| 打开 Agent | `Ctrl+I` | `Cmd+I` |
| 行内编辑 / 生成 | `Ctrl+K` | `Cmd+K` |
| 对整个代码库提问 | `Ctrl+Enter` | `Cmd+Enter` |
| Cursor Settings | `Ctrl+Shift+J` | `Cmd+Shift+J` |
| 命令面板 | `Ctrl+Shift+P` | `Cmd+Shift+P` |

键位与 VS Code 一脉相承；如果你从 VS Code 导入过自定义键位，以你自己那套为准。版本更迭后个别键位可能调整，以编辑器内实际显示为准。
