# Cursor 中文界面设置方法

> Cursor 默认是英文界面。本篇讲怎么把菜单换成简体中文，以及为什么装完后一部分界面仍然是英文——这是目前正常现象，不是装坏了。

## 一、两步切换：命令面板装语言包

1. 按 `Ctrl+Shift+P`（macOS 为 `Cmd+Shift+P`）打开命令面板，输入 `display`，选 **Configure Display Language**；
2. 列表里选 **中文(简体)**；没装过语言包会提示安装 Chinese (Simplified) Language Pack，装完按提示 **Restart** 重启，菜单就变中文了。

也可以走扩展面板：点左侧扩展图标，搜 `Chinese (Simplified)`，安装 Chinese (Simplified) Language Pack，然后按提示重启。

## 二、哪些地方不会变中文（预期管理）

语言包只翻译 VS Code 那一层——菜单、右键菜单、通用设置、命令面板。Cursor 自家的界面**大部分保持英文**：Cursor Settings 页、AI 对话与 Agent 面板等。官方论坛的答复也明确这一点：Cursor 自有界面的本地化还没做全，这是现状，不是你的安装出了问题。别因为「装了没全变中文」就反复重装。

## 三、装了不生效的常见原因

- **没完全重启**：要退出整个程序再开（Windows 关掉所有窗口；macOS 用 `Cmd+Q` 退出），只重开窗口不够；
- **语言包与内置 VS Code 版本不匹配**：Cursor 基于 VS Code，但内置版本通常略旧，语言包最新版可能要求更高的 VS Code 版本，装上不生效。官方支持在论坛给过的处理办法：在扩展页给语言包选 **Install Another Version**，装一个与内置版本匹配的旧版（哪个版本匹配，以扩展页提示为准）；
- **确认当前语言**：命令面板再跑一次 Configure Display Language，看选中的是不是中文(简体)，不是就选中它再重启。

## 四、AI 回答的语言跟界面无关

界面汉化不影响 AI 输出语言。想让 AI 全程用中文回答，直接在对话里说「用中文回答」，想一劳永逸就写进规则——全局偏好放用户规则，项目约定放项目规则，配法见 [项目规则与忽略文件配置.md](项目规则与忽略文件配置.md)。
