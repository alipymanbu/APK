## 一、登录一直转圈 / 转完登录页客户端没反应

浏览器里明明登录成功了、回到客户端还是没登录，是最常见的一类。按顺序试：

1. **先排除网络**：公司内网、代理、安全网关都可能拦登录请求。浏览器能打开官网不代表客户端网络是通的，两者走的链路不同；
2. **测协议跳转**：在浏览器地址栏输入 `cursor://anysphere.cursor/test`，正常会弹出「打开 Cursor」的询问并把客户端带到前台；毫无反应说明 cursor:// 协议注册出了问题，用最新安装包重装一次再登录（官方支持给过的判别步骤）；
3. **给客户端配代理**：`Ctrl+,` 打开设置搜 `proxy`，在 **Http: Proxy** 填你本机代理地址（如 `http://127.0.0.1:7890`），并把 **Http: Proxy Support** 打开；
4. **关 HTTP/2**：设置里搜 `http2` 勾选 Disable HTTP/2（或在 settings.json 加 `"cursor.general.disableHttp2": true`）后重启。客户端的流式请求走 HTTP/2，不少公司代理与安全网关（ZScaler 类）会拦它，官方把这一项列为连接问题的标准解法，社区反馈对登录卡住也常有效；
5. **换登录方式**：Google 授权不行就换 GitHub 或邮箱注册；遇到「suspicious activity」提示时先关 VPN 再试，或过几分钟新开对话重试；
6. **清会话重登**：登录 `https://cursor.com/settings` 撤销全部会话，然后回客户端重新登录。

补充两条：

- 公司防火墙环境需要放行域名的话，官方列的常用域包括 `*.cursor.sh`、`*.cursorapi.com`、`*.cursor-cdn.com`（完整清单以官方网络配置文档为准）；
- 大陆网络直连能不能用，社区口径并不一致：有用户反馈直连可用，也有用户反馈遇到连接失败、或选模型时提示 `Model not available ... doesn't serve your region`。两种情况都存在，遇到连接不稳时，按上面第 3、4 步给你自己的客户端配代理是通行做法；较新版本在 Cursor Settings 的 Network 页自带 Run Diagnostics 连通性自检（v0.50.5 时代还没有这个入口，疑难杂症建议先升级）。

## 二、提示额度用完 / 想升级

- 免费版的智能体请求是有限次数，用完只能等刷新或升级；
- 用量明细在 dashboard：`https://cursor.com/dashboard`，先看是哪个模型消耗的；
- 订阅只在官方直售、不授权第三方卖家，购买前先读 [注册登录与免费额度.md](注册登录与免费额度.md) 第三节。

## 三、AI 回答不看我的项目 / 答非所问

- 用 `@` 把具体文件、文件夹喂进上下文，对整个仓库提问用 `Ctrl+Enter`（用法见 [常用功能与快捷键.md](常用功能与快捷键.md) 第四节）；
- 大仓库首次打开会先建代码库索引，索引没完成时全库问答不准，等右下角索引状态结束再试；
- 一个窗口挂了多个项目目录（多根工作区）时，确认对话引用的是你实际想问的那个目录。

## 四、更新相关问题

- 查当前版本：Cursor Settings 或「关于」页；
- 网盘那份 v0.50.5 是 0.50 系列的补丁版（2025 年 5 月），之后的正式版有大量新功能，建议保持自动更新；
- 自动更新失败：去官网 [cursor.com/cn/downloads](https://www.cursor.com/cn/downloads) 重新下载最新安装包覆盖安装，用户配置与扩展会保留。

## 五、卸载与重装

- Windows：系统「设置 → 应用」里卸载；macOS：把 Cursor 从「应用程序」拖进废纸篓；
- 卸载**不会**删除你的用户配置与缓存：Windows 一般在 `%APPDATA%\Cursor`，macOS / Linux 一般在 `~/.cursor`，想彻底清干净再手动删这些目录；
- 账号数据在云端，重装后登录同一账号即可恢复订阅与额度，不需要任何恢复操作。

## 六、上面都没解决

- 官方论坛搜报错关键词：`https://forum.cursor.com/`；
- 账号与订阅类的私密问题，发邮件到 `hi@cursor.com`。
