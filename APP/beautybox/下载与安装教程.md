## 一、下载前先确认：你要装的是哪个 beautybox

在搜索引擎或应用站里搜 `beautybox`，出来的往往是好几个完全不同的应用：有同名的本地视频播放器（包名 `jian.ping.beau`），也有相机美颜类工具。本篇讲的是常被称为「绿盒子」的影视聚合播放应用，认准包名 `com.secret.prettyhezi` 才是它。几款同名应用的详细对照见 [版本与同名应用区分.md](版本与同名应用区分.md)。

本篇对应的版本为 **5.1.3**，安装包约 **4.48M**。

## 二、从哪里下载

- **夸克网盘**：[beautybox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e2b14e7232e0)，转存到自己的网盘后即可下载 apk 文件，对应的就是上面 5.1.3 这一版。
- **第三方应用收录站**：手机乐园、聚侠网等站点收录了它的页面，但这些站的直链经常随时间失效，且同名包混杂，动手装之前建议核对包名与文件大小。
- **主流手机应用商店**：这类聚合影视应用一般不上架，在商店里基本搜不到，搜到的大概率是前面说的同名应用。

## 三、安装步骤

1. 把 apk 文件下载到手机存储（网盘转存后下载，或浏览器直接下载）；
2. 在文件管理器里点开 apk，系统会提示「出于安全考虑，已禁止安装未知来源应用」；
3. 按下面表里对应你手机的路径，给刚才下载用的那个应用（浏览器或文件管理器）授权；
4. 返回重新点开 apk，等安装完成。

常见系统的「安装未知应用」授权路径（各品牌菜单名略有出入，找不到就进设置搜「未知」）：

| 系统 | 常见路径 |
| --- | --- |
| 原生 / 类原生 Android | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |
| MIUI / HyperOS | 设置 → 隐私保护 → 特殊应用权限 → 安装未知应用 |
| ColorOS / OriginOS / HarmonyOS | 设置里直接搜「安装未知应用」，进入后按应用逐一授权 |

## 四、安装时提示「病毒应用 / 恶意应用」

有第三方收录站提到，部分手机的安全组件会拦下这个包。处理前先做一步：**核对文件**——5.1.3 版 apk 的 MD5 为 `E989F0AA62E483D1728D9CD08C3F9D6E`，大小 4.48M。来源可信、校验一致，再自行决定是否继续；具体做法是在拦截提示里选择「仍要安装」，或在系统安全设置里暂时关闭「禁止安装恶意应用」类的开关，装完建议把开关恢复原状。拿不准就放弃，这类提示不是每次都值得硬闯。

## 五、安装失败的其他常见原因

| 提示 | 多半是 | 处理 |
| --- | --- | --- |
| 解析包时出现问题 | 文件没下完整 | 重新下载，装完核对文件大小是否约 4.48M |
| 存储空间不足 | 手机剩余空间不够 | 清出至少几百 MB 再装 |
| 系统版本过低 | Android 版本不满足要求 | 安装包标注需要 Android 5.2 及以上（不同收录站标注从 4.0 到 5.2 不等，以实际安装为准） |
| 已存在签名不一致的应用 | 装过别处来的同名旧版 | 先卸载旧版再装 |

装好之后怎么上手，看 [功能与使用入门.md](功能与使用入门.md)；装不上或者装完打不开，去 [常见问题排查.md](常见问题排查.md) 对一遍。另外提前说一句：第一次打开它可能会要求注册码或邀请码，这是应用本身的注册机制，详见 [邀请码与注册机制说明.md](邀请码与注册机制说明.md)。
