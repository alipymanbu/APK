## 一、先分清卡在哪一侧

联机是三方关系：**房主的工具 → 网络通道 → 你的工具**。排查顺序固定为：

1. 房主侧有没有真正拿到邀请码（工具里生成、可复制）；
2. 访客侧有没有显示「已加入房间」；
3. 显示已加入后，游戏多人列表里能不能刷出房间。

**卡在哪一步，就只查那一步的上游** —— 比如工具都没显示「已加入」，先别去动游戏里的设置。

## 二、按现象排查

| 现象 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| 访客点「加入房间」一直转 | 房主是否还开着房、邀请码是不是旧的 | 房主重开一次房、重新发码；关房后的旧码不可用 |
| 提示邀请码无效 | 复制时是否带了空格或少字符 | 让房主从通知栏或软件里重新复制整段，重新粘贴 |
| 显示已加入，游戏里刷不出房间 | 房主是否已点「对局域网开放」 | 房主确认存档内已开放局域网，再让访客刷新列表 |
| 房主拿不到邀请码 | 是否先扫描、后开放，顺序反了 | 按顺序重来：工具「开始扫描」→ 游戏内「对局域网开放」→ 等码 |
| 能连上但卡顿、频繁掉线 | 双方是否异地却选了局域网方案 | 异地改用蒲公英 / cpolar 内网穿透方案（房主侧切换） |
| 进房后因模组/版本报错 | 双方版本号与模组清单是否一致 | 对齐游戏版本；按同步提示装同版本模组，见 [模组整合包怎么装.md](模组整合包怎么装.md) |
| 启动游戏就没反应 | 运行环境是否装完整 | 回 [下载与安装教程.md](下载与安装教程.md) 重跑一次运行环境安装 |
| 扫描不到房间、加入不了房间 | 工具是不是旧版 | 1.2 的发布页更新说明写了修复这两类 bug，换新版包再试（见 [下载与安装教程.md](下载与安装教程.md) 第二节） |

## 三、最容易踩的两个顺序坑

- **房主侧**：必须「先点开始扫描，再去游戏里开对局域网」。反过来做，扫描抓不到刚开放的端口，邀请码自然出不来。
- **访客侧**：必须「等工具显示已加入房间，再启动游戏」。先开游戏再操作工具，多人列表是空的 —— 这不是连接失败，是步骤早了。

实际遇到「连不上」时，先对照这两条查顺序，比先去怀疑网络设置更快。

## 四、版本与登录相关的确认项

- **版本一致**：双方在启动器里看到的游戏版本号要相同；工具会自动匹配版本与模组，但开房前自己核对一遍更稳妥。
- **登录方式**：联机建议双方都用微软账号登录；离线账户在部分场景可用，若只有你一侧是离线登录且反复失败，换成微软登录再试。
- **方案可用性以当时界面为准**：蒲公英、cpolar 这类方案的入口与可用状态会随版本变化，以软件当时显示为准，不必对照旧教程逐字找按钮。

## 五、能连上但卡、频繁掉线

连接建立后仍卡顿 / 掉线，是另一类问题，按这个顺序处理（综合了一个发布页的处理建议与官方支持文档的通用排查）：

1. **换联机方案**：该页建议优先用蒲公英联机，网络条件差时换 cpolar 内网穿透；你和好友不同网时，别停在局域网方案上。
2. **给设备减负**：关掉游戏里的光影和多余的模组 —— 手机跑 Java 版本来就吃力，负载降下来帧率和稳定性都会改善。
3. **换网络**：连稳定的家庭 Wi-Fi 或蜂窝网络，避开公共 Wi-Fi；同时确认后台没有其他程序在大量占网（更新、云备份之类先暂停）。
4. **重启再试**：重启软件、重启手机 —— Minecraft 官方支持文档在排查多人连接问题时也是把「重启游戏、重启设备」放在最前面的。

## 六、都试过还是不行

让房主把房间彻底关掉重开、双方都重启一次软件（运行环境异常时，重启后重装环境是常见解法），再走一遍 [房主创建联机房间步骤.md](房主创建联机房间步骤.md) 与 [访客输入邀请码加入房间.md](访客输入邀请码加入房间.md) 的原始顺序。若始终卡在同一步，把那一步的界面提示原样记下来 —— 报错文字比「连不上」三个字更能定位问题。
