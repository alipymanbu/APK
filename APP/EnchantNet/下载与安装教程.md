## 一、这是什么软件

EnchantNet 是安卓手机上的《我的世界》Java 版辅助工具：你可以在它里面启动游戏、装模组和整合包，也可以用它和好友联机 —— 房主开一局，把邀请码发出去，好友输入邀请码就能进房，不用碰 IP、端口这些网络设置。多个发布页把它标注为 FCL 启动器的联机工具，它的包名 `org.fcl.enchantnet` 也与 FCL 同系；你装的这个包可以独立运行，不依赖另外装一个启动器，界面已汉化、菜单都是中文。

本篇只讲「装好并进入主界面」。装好之后怎么开房间、怎么进房间，见另外两篇。

## 二、先核对版本信息

从 [EnchantNet 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bf106e44123b) 拿到的这份包，事实信息如下（以这份为准，网上发布页写的最新版未必是它）：

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.2 |
| 包名 | `org.fcl.enchantnet` |
| 安装包大小 | 42.97M |
| MD5 | `80db090d3e9496b558ced5800fe270ba` |

下载完成后如果想确认包没损坏，可以校验一下 MD5 是否与上表一致（文件管理器或校验工具都能做）。公开发布页上出现过 1.1、1.2 等版本，具体以当时页面显示为准。

关于 1.2 这个版本，一个发布页的更新说明写的是「修复了部分房间扫描不出来的 bug 和加入不了房间的 bug」—— 如果你之前用旧版遇到过扫不出房间、进不了房，装这份 1.2 就对了（更新说明以该页当时显示为准）。

**系统要求**两边口径不一致，如实并列给你：一处标注「无最低系统要求」，另一处标注「支持 Android 8.0 及以上、建议 4GB 内存与中端以上处理器」。你的手机近两年买的大概率都能跑，装上试比对参数更直接；以官方页面当时显示为准。

## 三、安装步骤

1. 在手机上打开上面的网盘链接，把安装包转存或下载到手机。
2. 点击 APK 开始安装。安卓会弹「不允许安装未知来源应用」的提示 —— 这是安装第三方 APK 的正常拦截，按提示对该来源开启「允许」即可（不同品牌手机的入口略有差异，一般在 设置 → 安全/应用安装 里）。
3. 装完打开应用，首次会弹权限请求，点【授权】进入。

## 四、首次运行：先装运行环境

进入软件后，你多半会先看到一个「安装 / 更新运行环境」的提示 —— 这一步是在补全运行《我的世界》Java 版所需的组件，**点右下角对应的按钮让它跑完**，不要跳过。环境没装好就直接启动游戏，是新手最常遇到的起不来的原因。

环境装完就到主界面了，此时已经可以正常浏览与设置。

## 五、建议先改的几项设置

这几项都在首次进入时顺手做掉，后面联机会省事：

- **打开版本隔离**：在游戏启动相关设置里把它打开。多个整合包 / 多个版本混在一起时，不隔离容易出现文件互相覆盖导致的报错；开了之后每个实例各用各的环境。
- **选择登录方式**：单机游玩不登录也能玩；要联机的话，推荐用微软账号登录（部分联机场景需要），工具也支持离线账户。按你的实际需要选，不必两个都填。
- **字体不合适就换**：在「设置」里可以改字体 —— 手机屏幕上默认字体太小或太挤时，这一项能明显改善可读性。

## 六、装好之后

主界面里左侧是功能入口（游戏版本、模组、整合包等分类），点进去可以浏览和下载游戏本体、模组、整合包 —— 装模组整合包的通用做法是：进对应分类 → 挑一个点进详情 → 选版本 → 选下载目录 → 等下载完成。

真正要和好友一起玩时，你只需要分清两种角色：开房间的人走 [房主创建联机房间步骤.md](房主创建联机房间步骤.md)，进房间的人走 [访客输入邀请码加入房间.md](访客输入邀请码加入房间.md)；连不上了按 [联机连不上排查方法.md](联机连不上排查方法.md) 逐条查。
