# 快速编辑与克隆应用教程

## 一、快速编辑能改什么

选中应用 → 弹出菜单选「快速编辑」，不用反编译就能：

- 查看应用信息与权限列表（权限也能在这里启停）；
- 改应用显示名称；
- 改包名——改完就得到一个可以和原版共存的克隆；
- 换图标、提取图标；
- 改最低 SDK / 目标 SDK；
- 勾选「适配 Android TV」；
- 去掉清单里的 `isSplitRequired`、`debuggable`、`testOnly` 标记。

它只动清单和资源表这两项数据，不碰代码，所以保存几秒就出结果；成品文件和原文件放同一目录，文件名末尾带 `mod` 标记。

## 二、改名与克隆

1. 选中应用 → 快速编辑。
2. 改名称；或者改包名（比如在末尾加两个字母）来做克隆。
3. 第一次用会要你选一个签名文件，没有就先建一个（见 [签名与密钥管理.md](签名与密钥管理.md)）。
4. 保存，成品在同目录，文件名带 `mod`。

两个注意点：

- **名称栏点不动（灰色）**：多半是应用的最低 SDK 要求比你的系统版本还高，编辑被锁了。先把这个应用的最低 SDK 降到你的系统版本以下，名称和其他项就都能改了。
- **克隆的边界**：改包名能让两个版本共存，但应用内部如果硬校验自己的包名或签名，克隆版可能功能残缺——遇到这种情况就不是克隆能解决的了。

## 三、换图标与提取图标

**换图标：**

1. 准备一张 png 图，建议不超过 192×192；
2. 快速编辑里点左上角的图标，选你准备的图；
3. 按需勾「替换自适应图标」「高质量图标」；
4. 选签名文件，保存。

**提取图标：** 快速编辑里长按图标即可，导出的图和成品放同一目录。

顺带：PNG、JPEG、WebP、SVG 都能转成矢量图（产物文件名形如 `{原文件名}_vector.xml`），图形简单的效果还行，几何复杂的位图转出来会走样。

## 四、其他几项的用法

| 想做的事 | 怎么做 | 说明 |
| --- | --- | --- |
| 装「缺拆分」的包 | 勾掉 `isSplitRequired` | 提示需要拆分组件而装不上的包，去掉这个标记常能装上；更彻底的办法是先把拆分包合并，见 [拆分包合并教程.md](拆分包合并教程.md) |
| 老设备装新应用 | 降最低 SDK | 降完能装，但应用要求的新系统能力设备上没有，缺功能是正常现象 |
| 适配 Android TV | 勾「适配 Android TV」 | 直接拿应用图标当 TV 横幅图 |
| 排查权限 | 「权限」项查看 | 也能在这里把不需要的权限关掉 |

## 五、保存后装不上，先看签名

快速编辑保存时默认「不签名」，没选签名文件就直接保存的话，出来的包是装不上的。这是「改完装不上」里最常见的一种，重做一遍选上签名即可；其余装不上的情况按 [常见问题与报错排查.md](常见问题与报错排查.md) 排查。
