## 一、这份安装包是什么

Hay 是一款随机视频匹配的社交应用（中文圈常叫「小鳄鱼 Hay」）：把你和另一位在线用户接进同一间 1 对 1 实时视频通话，内置实时翻译与贴纸特效。装之前先核对手上这份包的参数：

| 项目 | 数值 |
| --- | --- |
| 版本号 | 8.53.0 |
| 包名 | com.hay.android |
| 安装包大小 | 115.98 MB |
| MD5 | `85163091FF796BC40F6419067DCEA98F` |
| 系统要求 | 安卓 5.2 及以上 |
| 包信息核对日期 | 2026-09-24 |

同一包名的版本一直在迭代，网上下载站显示的版本号常常比这份新，两者不是同一个文件。本文凡涉及版本号、包名、安装包体积，一律以上表为准。

## 二、系统与年龄门槛

- **系统**：安卓 5.2 及以上。系统版本低于这条线，安装或启动都可能失败。
- **年龄**：官方服务条款写明本产品仅面向 18 周岁以上成年人，注册时的出生年月日就是校验依据（详见 [注册与登录方法.md](注册与登录方法.md)）；苹果 App Store 对这款应用给出的年龄分级是 16+。两处口径不同，以各自页面为准 —— 未达到注册年龄线的话，包装得上，账号注册不了。
- **iOS 用户**：不走这个安卓包，在 App Store 搜索 Hay（开发者显示为 TURNED E PTE. LTD.）。

## 三、获取安装包

1. **网盘获取**：打开 [Hay 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f2edf3c58e35)，转存到自己的网盘后在手机端直接下载；也可以先下到电脑，再传到手机安装。
2. **官方渠道**：官网 [www.hay.fun](https://www.hay.fun/)（有中文页面 [www.hay.fun/zh](https://www.hay.fun/zh/)）；iOS 走 App Store。

从非官方商店的链接下载时，装之前先核对 MD5（命令见下一节），对不上就别装。

## 四、安装步骤（安卓）

1. 在手机上点开下载好的 `.apk` 文件。
2. 若系统提示「不允许安装未知来源的应用」，按提示跳到 设置 → 安全 / 隐私 → 允许该来源安装应用（各品牌路径略有差异），返回后继续安装。
3. 等进度走完，点「打开」。
4. 首次启动按提示逐项授权（见第五节）。

电脑上核对 MD5（在安装包所在目录执行，结果应与第一节表格一致）：

```powershell
Get-FileHash .\Hay_v8.53.0.apk -Algorithm MD5
```

## 五、首次启动要给的权限

| 权限 | 不给会怎样 |
| --- | --- |
| 摄像头 | 无法出镜，匹配根本不会开始（你的脸要出现在镜头里） |
| 麦克风 | 对方听不到你，等于只能单方面看 |
| 网络 / 入网 | 官方协议明确使用本应用需要在设备端开启入网权限，由此产生的流量费由用户自担 |

视频通话非常吃流量，长时间匹配建议挂在 Wi-Fi 下用。授权路径：设置 → 应用 → Hay → 权限，随时可以改；给出去的授权之后怎么撤回、人脸数据怎么处理，见 [人脸与隐私保护说明.md](人脸与隐私保护说明.md)。

## 六、装不上、或装完就闪退

- **存储空间**：留出比安装包体积（115.98 MB）更大的空闲空间，太满会导致解析失败或安装中断。
- **版本覆盖**：新版盖旧版没问题；拿旧版去覆盖装机上的新版会被安卓系统拒绝 —— 这种情况先卸载再装（卸载会清掉本地登录状态与数据）。
- 闪退、黑屏、没声音的完整排查顺序在 [常见问题与排查.md](常见问题与排查.md)。
