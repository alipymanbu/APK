## 一、匹配一直转圈 / 匹配不到人

按顺序查，命中一条就先解决那条：

1. **脸在不在镜头内** —— 脸没入画匹配不会开始，这是硬条件，很多人以为是卡住了。
2. 摄像头、麦克风权限有没有授予（路径：设置 → 应用 → Hay → 权限）；担心摄像头画面怎么被处理，先看 [人脸与隐私保护说明.md](人脸与隐私保护说明.md)。
3. 网络是否稳定 —— 官方排查口径就是「最新版本 + 稳定网络」两条。
4. 筛选条件是否收得太窄（性别、地区同时限定会显著拉长匹配时间）。有教程建议把地区放宽到「全球」，并按对方所在时区挑时段 —— 想匹配欧美用户，国内晚上到凌晨对方刚下班或还没睡，在线的更多。
5. 账号若正处于限制状态也匹配不了，见本文第四节。

## 二、没画面 / 没声音

- 设置 → 应用 → Hay → 权限，确认**摄像头、麦克风**都已允许；
- 有画面没声音：确认没开静音、媒体音量不是 0；
- 手机的省电策略会挂起后台麦克风，把该应用的省电限制关掉（各品牌路径不同）；
- 换个网络再开一次通话，排除带宽不足导致的单向无声。

## 三、闪退、黑屏、卡顿（安卓通用排查）

官方帮助没有针对闪退的专门条目，按安卓通用顺序处理：

1. 升级到最新版本；
2. 设置 → 应用 → Hay → 存储 → **先清缓存**，无效再清数据（清数据会退出登录）；
3. 手机留足可用存储；
4. 重启手机后重开应用；
5. 仍闪退 → 卸载重装，安装包见 [下载与安装教程.md](下载与安装教程.md)。

## 四、账号被举报 / 被限制怎么办（官方口径）

- **触发原因**：官方明确列出 —— 色情、裸露、涉及未成年人、辱骂、暴力、骚扰。
- **限制时长**：由人工审核判定，官方特别说明**没有**「10 分钟 / 30 分钟 / 永久」这种固定阶梯，别按传闻估时间。
- **认为误判**：给 `support@hay.fun` 回信，附上 App、你的 user ID 和事情经过，会有人复核。

配套的合规提醒与界面操作见 [视频匹配与聊天使用教程.md](视频匹配与聊天使用教程.md)；登录异常优先按 [注册与登录方法.md](注册与登录方法.md) 的三步排查，再考虑是否属于被限制。

## 五、删除账号（官方路径）

- **安卓**：Profile → Settings → About Hay → Delete account，输入大写的 `DELETE` 确认。
- **iOS**：Me → About Hay → Delete account，同样输入 `DELETE`。
- 删除后**约 30 天内重新登录可以撤销**；超过 30 天账号被永久移除。
- 删号**不会**取消商店订阅 —— 订阅必须去 Google Play / App Store 单独取消，步骤见 [金币获取与订阅取消.md](金币获取与订阅取消.md)。

## 六、找官方

- 帮助中心：[support.hay.fun](https://support.hay.fun/hc/en-001)，分「Common Questions」与「How to use Hay」两个分区；
- 邮箱：`support@hay.fun`，联系时带上 user ID（登录、扣款、封号申诉都要求提供它）。
