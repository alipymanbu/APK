## 一、输入方式有哪几种，怎么切

Simeji 的日语输入至少给你两种布局：

| 布局 | 长什么样 | 适合谁 |
| --- | --- | --- |
| フリック（拨号盘式） | 一个键管一段假名，按住往四个方向滑出不同假名 | 安卓上打日语的主流方式，单手好够 |
| 全键盘（QWERTY） | 罗马字/英文字母布局 | 习惯罗马字打日语、或主要打英文的人 |

切换入口有三处，改完立即生效、不用重启：

1. 键盘上的布局切换按钮（部分版本在键盘上方控制条里）；
2. 键盘左上的**蘑菇图标**（简易设置菜单）里的布局快捷项；
3. 应用内 `设置 → 键盘`——官方手册的口径是「Simeji の設定 → キーボード」里设置日语键盘的输入方式（可选フリック、ケータイ等），具体文案以你装的版本当时界面为准。

## 二、官方 FAQ 给出的几个实用操作

这些都来自官方常见问题页，直接照做即可：

| 想要 | 操作 |
| --- | --- |
| 打出全角空格 | 键盘处于テンキー（十键）模式时，把空白键（安卓上是空格键）**向左滑** |
| 连续输入同一个字 | 点蘑菇图标 → 切到「フリックのみ」 |
| 调键盘高度 | 点蘑菇图标 → 「キーボード高さ（键盘高度）」拖动调整 |
| 键盘矮一点 | 蘑菇菜单 →「片手入力（单手输入）」，比默认低一些 |
| 键盘高一点（全面屏） | 蘑菇菜单 →「全画面ディスプレイ最適化（全屏显示优化）」，比默认高一些 |

## 三、转换与候选词

- **预测转换**：打字过程中候选拓展后半段——输入「わたし」时候选里出现「私たち」「私の場合」这类，选一次就能省掉后面的输入。
- **云转换候选**：候选栏里的「花活」来自云上词典——输入歌名出歌词片段、输入动漫名出作品里的热门台词、时事热词也会进候选。商店描述口径是云词典 200 万语；这类候选依赖网络，云相关的开关在 `设置 → 变换设定` 里（以版本当时界面为准）。候选突然变少、颜文字不出来，按[常见问题与排查.md](常见问题与排查.md)第二节排查。
- **みんなの辞書（大家的词典）**：用户投稿的趣味转换与颜文字共享池，你也可以把自己得意的转换投进去（商店描述口径）。

## 四、日英与多语言

一个键盘里可切的语言按商店描述包括日语、英语、韩语、中文、印尼语，不用装多个输入法。切换靠键盘上的语言键（地球仪图标，或「あA」这类中英切换键，随布局不同）；从别的输入法切回 Simeji 的方法见[下载与安装教程.md](下载与安装教程.md)第五节。

## 五、竖屏与横屏的布局分开设

官方版本公告说明过：横屏此前只给全键盘，后来十键/フリック也能在横屏选用，路径是 `设置 → 键盘 → 「日・英」` 点你要改的那个键盘进入设置。竖屏调好了不等于横屏也跟着变，两个方向要分别确认（以版本当时界面为准）。

调完布局，下一步通常就是打点颜文字装点门面，见[颜文字与表情怎么打.md](颜文字与表情怎么打.md)；输入行为本身出问题时回到[常见问题与排查.md](常见问题与排查.md)。
