## 一、先分清两种商品：直充与代充

Kardz 里同一款游戏的充值商品通常分两类，商品标题里会写明是哪种，下单前先看清：

| 对比项 | 直充类商品 | 代充类商品 |
| --- | --- | --- |
| 发货方式 | 全自动，类似充话费 | 人工发货，客服登录你的账号操作 |
| 需要提供什么 | 只需游戏 ID（UID） | 游戏账号、密码、角色 ID |
| 到账时长 | 自动到账，一般几分钟 | 一般 15~30 分钟，活动期可能排队 |
| 填错了会怎样 | ID 不存在会在 3~10 分钟内自动返回失败并退款 | 信息错误会导致无法充值，需重新对接 |
| 充值期间要做什么 | 等 5~10 分钟后进游戏核实 | 不要登录游戏，配合客服验证 |

官方帮助中心 FAQ 的综合口径是订单一般约 30 分钟内处理完成；上表是两类商品各自的典型区间，高峰期都可能延长。

怎么选：不想交账号密码、只想快点到账的优先直充；直充没有的面额或区服（比如部分限定礼包），再考虑代充。代充要提供账号密码，风险与注意事项整篇见 [账号安全注意事项.md](账号安全注意事项.md)，下单前务必先读那篇。

## 二、直充怎么下单

直充是全自动发货，流程和充话费差不多：

1. 首页顶部搜索框输入游戏名（比如「原神国际服」），进入商品页；
2. 选面额与数量，核对商品页标注的适用区服（美服 / 欧服 / 亚服 / 港台等，见 [支持的游戏与支付方式.md](支持的游戏与支付方式.md)）；
3. 填写游戏 ID（UID），提交前再核对一遍；
4. 选支付方式付款；
5. 等 5~10 分钟，登录游戏查看到账情况。

UID 在哪里找：各游戏入口不同，但套路一致——进游戏，点头像 / 个人资料，找 UID / 玩家 ID，复制。官方商品页给过两个例子：鸣潮是点主界面左上角头像进个人资料页，昵称下方的 UID 旁有复制按钮；原神国际服是在游戏内点屏幕右下角，直接显示角色 ID。找不到时看商品页详情里的说明，或直接问客服。

直充卡单的三种常见情况（官方帮助中心的口径）：

- **游戏 ID 填错**：系统识别不了，一般 3~10 分钟内自动返回充值失败并自动退款，核实 ID 后重新下单即可；
- **网络波动导致订单状态没回调**：提交 5~10 分钟后去游戏里看，到账了就是成功，只是状态页没刷新；没到账就联系客服；
- **库存不足**：连续两单以上都卡在处理中，多半是缺货，第一时间联系客服补货。

官方对直充卡单的处理原则：优先帮你充到账，确认是账号问题的会自动退款，最迟 24 小时内处理完毕。所以直充卡单先按上面的时长等一等、查一查，不用急着重下一单。

## 三、代充怎么下单

代充是客服人工登录你的游戏账号充值，比直充多几步，也多几条规矩：

1. 选好商品、付款；
2. **下单后第一时间联系客服**（商品页或客服入口）——官方明确说明，代充到账快慢很大程度上取决于你联系得早晚、资料填得对不对；
3. 按客服要求提供游戏账号、密码、角色 ID（UID）；
4. 配合客服完成登录验证（可能需要验证码）；
5. 等 15~30 分钟，到账后客服会通知你；
6. 到账后**立即修改游戏密码**。

代充超过 15 分钟没动静的四种原因（官方帮助中心口径）：

| 情形 | 表现 | 你该做什么 |
| --- | --- | --- |
| 没联系上客服 | 下单后一直没人对接（缺验证码、账号密码错误都算） | 主动联系客服，把缺的信息补齐 |
| 活动期排队 | 客服入口有排队公示，客服会主动告知 | 耐心等，勤看订单状态 |
| 缺货 | 订单状态标注库存不足 | 联系客服确认，24~48 小时内处理；超 48 小时可按你的意愿退款或继续等 |
| 资料有误 | 客服反馈账号、密码或验证码不对 | 核对后重新提供 |

上号方式分两种（官方代充提速攻略的划分）：**直接上号型**——客服有账号密码就能登录充值；**验证码型**——客服登录时会触发短信 / 邮箱 / 令牌验证码，需要你实时转发给客服。买之前不确定的，先问客服这款游戏属哪种。验证码怎么配合最快、高峰期怎么排队，整篇见 [游戏代充提速攻略.md](游戏代充提速攻略.md)。

## 四、订单进度在哪看

付款后进订单中心（首页的订单入口或「我的」页里），订单详情页能看到这些：

- **充值进度卡片**：从「正在分配充值客服」走到「已为您分配充值客服」，会显示分配单号，可以复制；
- **催单按钮**：等得久可以直接催一下；
- **刷新按钮**：隔几秒刷一次看最新状态；
- **平台提示**：代充进行中会提示「充值客服正在登录您提交的账号」「请不要登录您的游戏账号，避免充值失败」——这两句不是客套话，照做就行。

## 五、到账之后做两件事

1. **进游戏确认**：直充等 5~10 分钟、代充等客服通知后再登录，别提前；
2. **立即改密码**：代充的账号密码刚在客服手里过一遍，到账第一件事就是改密码。

到账金额不对、或一直没到账，先按 [退款与售后指南.md](退款与售后指南.md) 的自查表过一遍，再决定找客服还是走退款。想搞清楚 K 宝值怎么攒、会员等级有什么用，见 [会员等级与K宝权益.md](会员等级与K宝权益.md)。
