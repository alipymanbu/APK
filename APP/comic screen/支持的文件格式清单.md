## 一、压缩包与文档格式

官方商店列出的支持范围如下：

| 格式 | 实质 | 常见来源 |
| --- | --- | --- |
| zip | 普通压缩包 | 自己打包的扫描图 |
| rar | 压缩包 | 下载的打包资源 |
| cbz | zip 改了扩展名的漫画包 | 漫画站的标准打包格式 |
| cbr | rar 改了扩展名的漫画包 | 同上 |
| pdf | 文档 | 官方电子书、扫描合集 |

几点使用上的差别：

- **cbz / cbr 本质就是 zip / rar**，只是扩展名不同。手上是 zip 的可以直接改成 cbz，也可以不改名，ComicScreen 两者都认。
- **pdf 按文档页处理**，翻页体验与压缩包不同；以整本扫描为主的合集用压缩包打包通常翻起来更顺。
- **zip 里可以再放子文件夹**：zip 内出现文件夹时可以呼出章节抽屉，一部多卷漫画打成一个 zip、按卷建子文件夹，翻起来最方便（见[阅读模式与翻页操作](阅读模式与翻页操作.md)第四节）。

## 二、图片格式

| 格式 | 说明 |
| --- | --- |
| jpg | 扫描图最常见的格式 |
| png | 无损，清晰度高 |
| gif | 支持动图 |
| bmp | 无压缩，文件偏大 |
| tiff | 扫描仪直出常见 |
| webp | 较新的格式，体积小 |
| avif | 更新的格式，体积更小 |

散装图片放进同一个文件夹就能按顺序连看，不必打包。

## 三、怎么整理最顺手

1. **一部作品一个单位**：要么一个压缩包，要么一个文件夹，别把几部作品混在一个文件夹里按文件名排。
2. **文件名带卷号**：`第01卷.cbz`、`第02卷.cbz` 这样命名，文件浏览器里按名称排序就是阅读顺序。
3. **多卷合集打一个 zip**：卷做子文件夹，用章节抽屉直接跳卷。
4. **别套太深的目录**：超过两三层的嵌套在手机上来回点很费劲。
5. **在应用里直接改**：文件浏览器支持搜索、重命名、删除，发现卷号命名不对，不用回电脑，当场改就行。

## 四、打不开时的检查顺序

1. 扩展名在不在上面两张表里；不在的话先在电脑上转成 zip（或直接把扩展名改成 cbz）再放回手机。
2. 查文件完整性——传输中断的压缩包会打不开，重新传一次。
3. 换一本书试，排除是不是单个文件损坏。

格式整理完想马上试手感，看[阅读模式与翻页操作](阅读模式与翻页操作.md)；文件存在电脑或 NAS 上的，看[SMB与FTP远程看漫画](SMB与FTP远程看漫画.md)；反复打不开排查不出原因的，去[闪退打不开怎么办](闪退打不开怎么办.md)。
