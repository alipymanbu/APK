# ComicScreen 闪退、打不开怎么办

> 按现象分三种情况排查：装不上、打开就闪退、能打开但某本书看不了。多数问题出在安装包不完整、系统版本或权限上。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [支持的文件格式清单.md](支持的文件格式清单.md) · [SMB与FTP远程看漫画.md](SMB与FTP远程看漫画.md)

## 一、装不上

先按[下载与安装教程](下载与安装教程.md)第三节的检查表走一遍，最常见的三条：

1. **解析包失败** → 安装包不完整。用 MD5 核对（本地这份应为 `b0e3d6d091e123e32dbb6c1bf087d306`），不一致就重下。
2. **系统版本不够** → 近期版本要求 Android 11 以上，老设备装新包会直接失败。
3. **存储空间不足** → 清出空间再装。

## 二、打开就闪退

按顺序试，多数在前两步就能解决：

1. **清后台重开**——后台堆太满时，打开大图或大压缩包容易崩。
2. **重启手机**再开。
3. **清缓存**：系统设置 → 应用 → ComicScreen → 存储 → **清除缓存**。注意**不要点「清除数据」**，那会把书签和设置一并清掉。
4. **卸载重装**：重装前先备好安装包，从 [ComicScreen 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8bcb5446f7fe)转存下载即可。

## 三、能打开，但某本书看不了

1. **先换一本书试**——单本打不开多半是文件本身的问题，不是应用的问题。
2. **对照格式**：扩展名不在支持列表里的先转换，对照[支持的文件格式清单](支持的文件格式清单.md)。
3. **查文件完整性**：传输中断的压缩包打不开，重新传一次。
4. **远程目录的书连不上**：这是网络问题不是闪退，去[SMB与FTP远程看漫画](SMB与FTP远程看漫画.md)第六节的检查点。

## 四、两个容易误会的现象

- **打开有广告**：官方商店页面标注该应用含广告、含应用内购买，属正常现象。
- **界面是英文**：在设置里切语言，步骤见[下载与安装教程](下载与安装教程.md)第五节。

上面几步都试过仍闪退、且每次都在同一本书或同一个操作上复现，可以去官方商店页面看看近期版本的其他用户反馈，确认是不是已知的版本问题。
