## 一、装之前先弄清三件事

1. **它是一款本地阅读器，不提供漫画内容。** 官方商店的功能清单里写明了「应用内不含图片与压缩文件」。你需要在电脑、NAS 或手机本机上先有自己的漫画文件（zip / rar / cbz / cbr / pdf 或整文件夹图片），它负责打开和翻阅这些文件。手上还没有文件的话，先看[支持的文件格式清单](支持的文件格式清单.md)。
2. **免费安装，含广告与应用内购买。** 开发商是 InstSoft，官方商店页面标注了「含广告」「含应用内购买」，属于这款应用的常规形态，不影响安装。
3. **版本说明。** 网盘里这份安装包为 **2258 版**（2026-09 整理，包名 `com.viewer.comicscreen`，大小 39.62M）。官方一直在更新，商店里的版本号会持续往前走；想用最新版就去官方商店装，想用这一份就按下面步骤来，安装方式完全相同。

## 二、下载安装包

从 [ComicScreen 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8bcb5446f7fe) 转存后，把 APK 下载到手机。

如果下载后装不上，先核对文件是否完整：这份安装包的 MD5 应为 `b0e3d6d091e123e32dbb6c1bf087d306`。在电脑上核对：

```powershell
certutil -hashfile "comic screen_v2258.apk" MD5
```

macOS / Linux 用 `md5sum 文件名`。比对不上就重新下载一次，MD5 不一致的安装包要么装不上，要么装上后异常。

## 三、安装步骤

1. 点开下载好的 APK 文件。
2. 系统提示「不允许安装未知来源应用」——这是安卓对所有非商店安装的正常拦截。点「设置」，打开「允许来自此来源的应用」开关（部分系统在 **设置 → 应用 → 特殊应用权限 → 安装未知应用** 里，按你用来打开 APK 的那个应用逐个授权）。
3. 返回安装界面，点「安装」，等进度走完。
4. 提示「已安装」后点「打开」。

### 装不上时的检查点

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 解析软件包时出现问题 | 安装包下载不完整 | 按上面的 MD5 核对后重下 |
| 安装按钮灰着点不动 | 存储空间不足 | 清出至少 200M 空间再装 |
| 提示与已安装应用冲突 | 设备上有同包名的旧版本 | 先卸载旧版再装 |

## 四、系统要求

ComicScreen 近几个版本对安卓系统的最低要求在 **Android 11 到 12** 一带（不同商店页面标注略有差异），以[官方商店页面](https://play.google.com/store/apps/details?id=com.viewer.comicscreen)当时显示的为准。老设备装不上新包时，只能升级系统或换用其他阅读器。

## 五、装好后的第一批设置

1. **放开文件权限**：首次打开会请求访问照片和文件（部分系统是「所有文件访问」）。不允许它就看不到本机漫画，这一步必须同意。
2. **切语言**：界面默认可能不是中文。点右上角的三个点（部分版本是扩展菜单图标）→ **设置（Settings）** → **语言（Language）**，选「中文」后确认。不同版本菜单叫法略有出入，认准 Settings / Language 两个词即可。
3. **找到漫画目录**：主界面就是文件浏览器，定位到你存放漫画的文件夹，之后从这里往下翻最省事。
4. **换深色主题**（可选）：有第三方介绍提到界面提供深色、浅色两套主题，夜里看更省眼；切换入口以你手上的版本设置里实际显示的为准。

语言和界面弄顺之后，去[阅读模式与翻页操作](阅读模式与翻页操作.md)把双页、书签这些习惯调好；如果漫画存在电脑或 NAS 上，直接看[SMB与FTP远程看漫画](SMB与FTP远程看漫画.md)。
