# ComicScreen 用 SMB 与 FTP 看电脑、NAS 上的漫画

> 漫画存在电脑、NAS 或 U 盘上也能直接看：本篇讲怎么把 SMB / FTP 共享目录和 USB OTG 设备接进 ComicScreen。

## 一、能接的三类位置

| 位置 | 协议/方式 | 典型场景 |
| --- | --- | --- |
| Windows 共享文件夹 | SMB | 漫画存在自己的电脑上 |
| NAS、路由器共享 | SMB | 家里有群晖、威联通这类设备 |
| FTP 服务器 | FTP | 路由器挂载的硬盘、自建 FTP |
| U 盘、读卡器 | USB OTG | 手机直接插外接存储 |

前提：手机和电脑 / NAS 要在**同一个局域网**里（同一个 Wi-Fi）。

## 二、Windows 这边先把文件夹共享出去

1. 右键漫画文件夹 → **属性** → **共享** → **共享**，把你的 Windows 账号加进去（或选 Everyone）。
2. 记下电脑的局域网 IP：`ipconfig` 命令输出里的 IPv4 地址。
3. 确认网络位置是「专用」且文件共享已开启：**设置 → 网络和 Internet → 高级网络设置 → 高级共享设置**，当前配置文件里打开「网络发现」和「文件和打印机共享」。公用网络会挡住共享。

## 三、在 ComicScreen 里添加远程目录

打开应用，点主界面顶部的「**+**」，在弹出的对话框里选远程连接方式（SMB 或 FTP），按提示填：

| 字段 | 填什么 |
| --- | --- |
| 地址 | 电脑或 NAS 的局域网 IP（SMB 也可填计算机名） |
| 账号 / 密码 | 共享文件夹授权的那个 Windows 账号；匿名 FTP 留空或按服务器要求 |

不同版本的入口措辞略有差别，找不到就认准顶部「+」号。连上之后远程目录和本机目录一样翻，阅读操作见[阅读模式与翻页操作](阅读模式与翻页操作.md)。有评测提到应用对 rar / cbr 的网络读取做过优化，大文件可以先直接从共享里翻，卡顿明显再复制到本机看。

## 四、FTP 从哪来

不少路由器和 NAS 自带 FTP 服务，在管理后台打开就能用。纯 Windows 环境优先走 SMB，不必为看漫画另搭一个 FTP。

## 五、USB OTG 直插 U 盘

1. OTG 转接头（或 Type-C 直插的 U 盘、读卡器）接上手机。
2. 打开 ComicScreen 的文件浏览器，外接存储会出现在目录列表里。
3. 直接翻里面的压缩包即可，不必先复制进手机。

## 六、连不上时的检查点

1. 手机和主机是否在同一 Wi-Fi——访客网络经常互相隔离，连了也看不到对方。
2. Windows 网络位置是不是「专用」，公用配置下共享会被挡。
3. IP 变了——路由器重启后电脑 IP 可能变化，在主机上重新 `ipconfig` 确认，或在路由器后台给电脑绑个固定 IP。
4. 大文件夹首次加载慢属正常，等目录读完再翻。

格式认不全的时候先对照[支持的文件格式清单](支持的文件格式清单.md)；装应用本身见[下载与安装教程](下载与安装教程.md)。
