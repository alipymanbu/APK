## 一、把手机里的文件传上去

在应用里找到「一键上传」入口（各版本入口位置略有差异，多在文件列表页的操作栏），选好文件后确认上传，手机本地的文件就会被传到云端。适合的场景：

- 换手机前，把相册里的照片、文档先传上去，新手机登录后直接取；
- 手机存储吃紧时，把占空间的大视频移到云端，本地删掉留出空间。

上传前留意两点：一是确认网络环境（大文件建议在 Wi-Fi 下传），二是传完在列表里点开核对一遍文件能不能正常打开，再决定要不要删本地副本。

## 二、分类、搜索与整理

文件多了之后，靠这几样保持有序：

| 操作 | 入口与用法 |
| --- | --- |
| 建文件夹分类 | 在文件列表里新建文件夹，按「文档 / 照片 / 视频」或项目名分门别类 |
| 重命名 | 长按或点文件旁的菜单，选重命名；命名带上日期或来源，日后好找 |
| 移动 / 删除 | 选中文件后在菜单里操作；删除前确认没有唯一副本 |
| 批量处理 | 支持一次勾选多个文件做统一操作，清理或搬运时比一个个点快得多 |
| 关键词搜索 | 顶部搜索框输入文件名关键词，直接定位 |

按第三方介绍，它还会按文件类型对资源分批归类显示；具体分几类、按什么规则，以你界面上实际看到的分组为准。

## 三、不下载先预览

文档、图片、视频等常见类型支持在线预览——列表里直接点文件就能看，不用等整个文件下载完。预览覆盖的格式随版本变：按第三方介绍，较新版本专门新增了图片、PDF、文本预览，并优化了视频播放体验（版本对照见 [版本区别与更新脉络.md](版本区别与更新脉络.md)），你手上这份支持到什么程度，以实际点开的结果为准。什么时候用得上：

- 不确定某个文件是不是你要的那份，先点开看一眼再决定下不下载；
- 只是查一眼文档里的某个信息，预览足够，没必要占用存储。

预览打不开时的处理思路（换网络、换类型判断）见 [解析失败与常见问题排查.md](解析失败与常见问题排查.md)。

## 四、把文件分享给别人

在文件或文件夹的菜单里选分享，可以生成分享链接发给他人；部分版本能对分享设置访问权限（只查看 / 可编辑，以你界面上的选项为准）。两条提醒：

- 分享出去的链接，接收方拿到后就能取文件，发之前确认内容没有发错对象；
- 用完可以到对应入口关闭分享，链接随即失效，避免扩散。

下载这一侧的完整流程在 [网盘链接解析与下载.md](网盘链接解析与下载.md)，两篇配合着用。
