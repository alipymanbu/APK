# Sound Assistant 每个应用单独设置音量

## 一、这个功能解决什么问题

系统原生的音量条只有一个：所有应用共用同一档媒体音量。你把视频调小，游戏、音乐也跟着小；把音乐调大，突然进来的提示音也跟着震耳。

Sound Assistant 的做法是给每个应用单独立一份音量：**同一个手机上，游戏用 30%、音乐用 80%、短视频用 50%**，互不影响。立过清单的应用会记住自己的音量，没进清单的应用继续跟随系统总音量。

## 二、把应用加进独立音量清单

1. 打开 Sound Assistant；
2. 找到「每个应用单独的音量」（英文界面叫 *Individual app volumes*）进入；
3. 点右下角的 **+** 号；
4. 在应用列表里勾选要单独控制的应用，确认添加；
5. 回到清单页，每个应用右侧都有一条滑块，直接拖到你要的音量。

想取消某个应用的单独控制，回到同一个清单把它移除即可——移除后该应用重新跟随系统总音量，不影响其他应用。

**实操建议**：先只加你真会冲突的两三个（比如一个游戏、一个音乐），清单拉太长反而每次都要翻。

## 三、播放中随时调：浮动音量面板

清单只是预先授权，真正的日常操作在浮动面板上：

1. 正在放声音时按一下手机的音量键；
2. 音量条下方会出现一个小圆点，点它；
3. 屏幕侧边展开一个面板，列出**此刻正在发声的所有应用**，每个应用一条独立滑块；
4. 拖哪条就只改哪个应用的音量，别的应用不动。

这个面板上还有两个手势（官方说明里的功能）：

- **点**应用的音量图标：对该应用静音 / 取消静音；
- **长按**音量图标：直接跳进那个应用。

## 四、双应用音量视图（One UI 5 起）

One UI 5 及以上有一个辅助显示：当某个应用的音量不是 100% 时，它自己的音量值会**显示在系统主音量条旁边**（应用音量、媒体音量并排）。你不用展开浮动面板，按一下音量键就能看到「哪个应用被单独调过、调到了多少」。

它的意义是让你随时知道当前是不是处于「有人被单独压低了」的状态——很多「怎么这个游戏声音特别小」的疑惑，答案就在这条并排显示上。

## 五、和多应用同时发声的关系

独立音量管的是「多大声」，不管「谁先谁后」——两个应用同时出声、互不打断，是另一个开关，见 [多应用同时发声与输出切换.md](多应用同时发声与输出切换.md)。两个功能经常一起用：先让导航和音乐同时响，再把导航压到 40%。

音量键本身的行为（按一下跳多少格、控制媒体还是铃声）在 [音量面板与均衡器设置.md](音量面板与均衡器设置.md) 里调。
