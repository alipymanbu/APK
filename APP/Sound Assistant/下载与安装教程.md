## 一、先确认你的手机能不能用

Sound Assistant 不是通用的安卓应用，它是三星 Good Lock 系列里的声音模块，只能跑在三星 Galaxy 手机的 One UI 系统上。装之前对一下这几点：

- **品牌**：三星 Galaxy（手机、折叠屏、平板都在支持范围内，但官方注明「部分设备可能不支持」）；
- **系统**：One UI。官方更新日志用版本对应关系标注支持范围——7.x.x 版对应 One UI 7、8.x.x 版对应 One UI 8，9.0.00.11 起支持 One UI 9.0 及以上（截至 2026-09 的官方更新日志，具体以商店页面当时显示为准）；
- **区域**：Good Lock 系列各模块的可用性随国家/地区、机型不同，有的区域商店里搜不到（对策见 [常见问题与解决方法.md](常见问题与解决方法.md)）。

手机不是三星、或系统还停在很旧的 One UI 上，装了也大概率打不开或缺功能，先别急着装。

## 二、从官方渠道安装（推荐）

官方渠道有三个，任选其一：

1. **Galaxy Store**：打开商店搜索 `Sound Assistant`（中文系统里显示为「声音助手」），直接安装；
2. **Google Play**：Sound Assistant 是少数几个同时上了 Google Play 的 Good Lock 模块，搜索同名即可；
3. **Good Lock 应用内**：先装 Good Lock 主应用，在模块列表里找到 Sound Assistant 点安装。

官方提供了一段使用教程视频：[youtu.be/Z5mrB4ryKjE](https://youtu.be/Z5mrB4ryKjE)。

三个渠道拿到的都是同一款应用，包名一致（`com.samsung.android.soundassistant`），区别只在更新速度与区域可见性。

两点提醒：

- 这份包的版本号与体积都明显小于官方商店当前版本（官方 2026-05 发布的版本为 8.5.00.2、28.22 MB），也就是说它是较早的一个版本。功能集合与新版本有差异，想要最新功能就走第二节的官方渠道；
- 下载完先核对 MD5 再安装。Windows 上可以这样查：

```powershell
Get-FileHash -Algorithm MD5 ".\Sound Assistant_v2.0.03.0.apk"
```

输出与上表一致再继续。安装 APK 需要在系统设置里允许「安装未知应用」，装完建议把这个权限关回去。

## 四、首次打开注意什么

- 首次进入会请求相关权限，按提示允许，否则音量面板、悬浮窗这类功能不会生效；
- 装完后按音量键，系统音量条样式可能就变成 Sound Assistant 的自定义面板了——这是它的接管行为，不是系统坏了，想换回去见 [音量面板与均衡器设置.md](音量面板与均衡器设置.md)；
- 打不开、闪退或功能缺一块，通常是 One UI 版本对不上或缓存问题，按 [常见问题与解决方法.md](常见问题与解决方法.md) 逐条排查。
