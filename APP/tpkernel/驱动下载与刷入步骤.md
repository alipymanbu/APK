# tpkernel 驱动下载与刷入步骤

> 装好 tpkernel 之后还需要在应用内下载对应游戏的驱动并刷入，这一步没做完进游戏是没有效果的。本篇按实际点击顺序把整条流程走一遍。

## 一、流程总览

整条链路是：打开应用完成初始化 → 选游戏 → 下载驱动 → 选触摸方案与刷入方式 → 刷入 → 确认启动进游戏。全程都在手机上完成，不需要连电脑。如果你还没安装应用本身，先看[下载与安装教程](下载与安装教程.md)。

## 二、逐步操作

1. **打开应用，等待初始化**：首次打开会做环境初始化加载，然后弹出版本更新公告，读完点确认即可。公告不只是走形式：里面的驱动更新条目通常带编号，开头两三个字标明针对哪款游戏哪个服（如暗区国服、和平、瓦），后面跟着日期段——想知道你等的那个适配出没出、是哪天发的，看公告比反复刷驱动靠谱。
2. **在首页选择游戏**：首页按游戏分入口，例如「暗区-国服」「暗区-国际服」、和平精英、无畏契约等，点你实际要进的那个（入口列表以应用内显示为准）。
3. **进入驱动页面，下载驱动**：点「下载驱动」，等进度走完。驱动文件是从应用内下载的，这一步需要网络畅通，也需要此前给过的文件管理权限。
4. **选择触摸方案和刷入方式**：这一步是按机型做适配的。不同手机对方案的反应不一样，没有普适的「最佳选项」——先按默认试，后面出问题再换。
5. **点「刷入驱动」**：等待部署完成，期间不要切走应用、不要锁屏。
6. **确认启动**：部署完成后会弹窗，点「确认启动」直接进入游戏。

## 三、进游戏之后

游戏界面里通过悬浮窗操作：呼出面板，里面是各类功能的开关和参数项（敌人位置与轮廓显示、瞄准辅助、准星样式等），按需开启即可。悬浮窗调不出来，多半是最初的悬浮窗权限没给，回手机系统设置里补上。

几点实操提示：

- 悬浮窗面板的窗口大小、透明度可以调，遮挡视野时把它调小或调淡；
- 压枪倍率这类参数项建议进训练场先试，再进对局；
- 玩一局退出后想再进，重新从悬浮窗开开关就行，不用每次重刷驱动。

## 四、出问题了怎么定位

按现象对号入座：

| 现象 | 先做什么 |
| --- | --- |
| 点功能没反应 | 确认悬浮窗已呼出、对应开关已打开 |
| 功能闪退或失效 | 换一个触摸方案重新刷入 |
| 游戏更新后全失效 | 属正常情况，等新驱动补丁，见[适配游戏与版本更新说明](适配游戏与版本更新说明.md) |
| 驱动下载不动 | 检查网络与存储空间，重试下载 |

更完整的排查清单和风险说明都在[常见问题与风险须知](常见问题与风险须知.md)里，卡住超过十分钟建议直接翻那篇。
