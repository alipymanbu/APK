## 一、首页先看什么

登录后首页就是设备列表，一台摄像头一张卡片，卡片上直接显示当前画面和在线状态。点进去才是单台设备的大画面。大画面里常用的几个动作：

| 你想做的事 | 在哪里操作 | 注意点 |
| --- | --- | --- |
| 换清晰度 | 画面上的清晰度/画质入口 | 越高越费流量，用手机流量看时先降一档 |
| 横屏看大图 | 画面右下角的全屏按钮 | 部分手机系统横屏锁定要先解开 |
| 听现场声音 | 画面上的声音开关 | 默认常常是关的，听不到别以为是设备坏了 |
| 对讲（说话给现场听） | 画面上的对讲/麦克风按钮 | 按住说话，松开送出；同一时间一般只能一方说 |
| 转动镜头（云台机型） | 画面上的方向盘 | 只有支持转动的机型才有；固定机型没有这个控件 |
| 截一张当前画面 | 画面上的截图/拍照按钮 | 直接存进手机相册，比录屏省事，适合「留个证明」 |
| 看多路画面 | 设备列表的多宫格/多路预览 | 同看路数越多，手机和网络压力越大 |

## 二、回放：按时间轴找那一段

进设备后切到回放/录像那一栏，界面是一条时间轴，拖动或点日期就能定位。回放页通常还有一个**「卡录像 / 云录像」的切换**——卡录像看的是机身存储卡上的内容，云录像看的是云端存的那部分。录像是从哪来的，决定你能回看多久：

- **本地卡回放**：录像存在摄像头里的存储卡上，一般能翻到比较近的一段时间，具体取决于卡的容量和清晰度。
- **云回放**：开了云存储服务才有，按套餐保留最近若干天，见 [SD卡录像与云存储怎么选.md](SD卡录像与云存储怎么选.md)。

**时间轴是空的、或者只有一小段**，通常是下面几种情况：

1. 摄像头刚装、还没录上；
2. 存储卡没插好或没被识别（卡的问题见 [设备离线与连不上怎么排查.md](设备离线与连不上怎么排查.md)）；
3. 云服务已到期 —— 到期后云端录像不再回放，此时如果机身里也没有可用的卡，就没有任何可回看的录像；
4. 摄像头这段时间断电或断网。

## 三、把片段存到自己手机里

看到要留的那一段，用回放画面上的**录屏/录制**按钮：开始录，录完点一次停止，文件就存进手机相册或 App 的本地文件里。只想要一帧证据的，直接用**截图**按钮更快。这两种都是把「某个时刻」带走的最直接办法 —— 本地卡和云端都是给回看用的，想长期留证据、要发给别人的，一律先截图或录屏存出来。

## 四、画面一直转圈、加载不出来

转圈就是**还在加载**，不是卡死。按这个顺序判断：

1. 换个网络再看（切到 WiFi，或换一台手机比对）—— 同一个摄像头在别的手机上流畅，问题就在原手机的网络；
2. 降一档清晰度，或用手机流量看时先切回 WiFi；
3. 家里宽带本身是不是有人在占满带宽；
4. 时间轴上能拖动但画面黑，多是云端/网络这一侧的问题；连时间轴都拉不动，先看 [设备离线与连不上怎么排查.md](设备离线与连不上怎么排查.md)。

想在电脑大屏上看，做法和限制单独写在 [在电脑上看监控.md](在电脑上看监控.md)。
