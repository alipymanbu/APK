## 一、先认准你手里的是哪一份包

网盘里放的是安卓安装包（`.apk`）。装之前把下面这张表对一遍，对得上，后面的步骤才适用。

| 项目 | 内容 |
| --- | --- |
| 应用名 | iCam365 |
| 开发者 | 深圳市探鸽智能科技有限公司 |
| 包名 | com.tange365.icam365 |
| 版本 | 3.52.6 |
| 安装包大小 | 123.44 MB |
| MD5 | 14CE2D06B58BB1D50C33A2403711CDC6 |

三点要留意：

- **版本号说的是这一份包**。应用商店里的 iCam365 已经更新到 3.57.x 一档（具体数字随时间变化，以商店页当时显示为准），和网盘里这一份不是同一个版本。本文档里的版本号、包名、安装包大小一律按上表理解，别拿商店页的数字来对。
- **包名 `com.tange365.icam365` 是它和别的监控 App 的分界线**。同一家厂商还给别的摄像头产品线做过配套 App，名字、图标都不太一样，清理手机时别只看图标像就删错 —— 认包名最准。
- **它只是「看摄像头的那一端」**。装上 App、登录账号并不会自动出现画面，还得把摄像头加进来，见 [添加摄像头与WiFi配网.md](添加摄像头与WiFi配网.md)。

## 二、装之前要确认的三件事

- **系统版本**：这一份安装包的说明页标注的是「需要支持安卓系统 5.2 以上」，而安卓并没有 5.2 这个正式版本号，稳妥起见**按 Android 5 以上准备**；系统还停在 Android 4.x 的就别折腾了。
- **存储空间**：安装包 123.44 MB，装完之后占用更大，留出 400 MB 以上比较省事。
- **安装权限**：不是从应用商店装的包，需要先允许「安装未知应用」（部分系统叫「未知来源」）。这个开关是给**你用来点开安装包的那个应用**（文件管理器或浏览器）开的，不是给 iCam365 本身，装完可以关回去。

## 三、安装步骤

1. 打开 [iCam365 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ec86aeea2883)，先转存到自己网盘再下载到手机，也可以在手机上直接打开这条链接下载。
2. 下载完的包后缀是 `.apk`。用手机自带文件管理器在「下载」目录里找到它，点一下开始安装。
3. 如果弹出「出于安全考虑，已禁止安装未知来源的应用」，点提示里的设置入口，把当前这个文件管理器的开关打开，返回后重新点安装。
4. 桌面出现图标即安装成功。第一次打开会走注册/登录，官方说明里注册方式是**用邮箱收验证码再设密码**，所以先准备一个能收信的邮箱；忘记密码、换手机的常见问题见 [注册登录与忘记密码.md](注册登录与忘记密码.md)。

## 四、装完核一下 MD5

从网盘拿的包，花半分钟核一下校验值，能直接排除「下载断流导致装不上」这类问题。把包拷到电脑上（或者直接用电脑下一份），执行（文件名以你实际下载到的为准）：

```powershell
certutil -hashfile "D:\Downloads\icam365_v3.52.6.apk" MD5
```

算出来的 32 位十六进制串应该与 `14CE2D06B58BB1D50C33A2403711CDC6` 完全一致；不一致就删掉重新下载一次。手机上也可以用能显示文件哈希的文件管理器核。

## 五、装不上、打不开怎么办

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现错误」 | 安装包下载不完整 | 删掉重新下载，下完先按第四节核 MD5 |
| 提示「应用未安装」 | 手机里已有同包名但签名不同的 iCam365 | 先卸载原来的再装 |
| 点了安装没有反应、不弹安装界面 | 没给「安装未知应用」权限 | 按第三节第 3 步开权限后重试 |
| 装上了一打开就闪退 | 系统版本过低，或系统对新装的旧版本包不兼容 | 换一台系统版本较新的手机试，或改用应用商店里的当前版本 |
| 打开后一直转圈、进不去主界面 | 多数是网络或账号问题，不是安装问题 | 见 [设备离线与连不上怎么排查.md](设备离线与连不上怎么排查.md) |

装好并登录之后，下一步是拿二维码把摄像头加进来，接着看 [添加摄像头与WiFi配网.md](添加摄像头与WiFi配网.md)。
