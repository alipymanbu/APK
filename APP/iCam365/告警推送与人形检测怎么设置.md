# iCam365 告警推送与人形检测怎么设置

> 「有人经过要提醒我」这件事，实际由三层拼起来：手机有没有放行通知、摄像头把什么算成事件、提醒发不发得出去。任一层没配好，都会表现为「明明有人走过，手机却没响」。

## 一、第一层：先把通知权限放行

官方说明里明确点出，收不到告警先查两处：

1. **手机系统设置**里，iCam365 的「消息通知 / 通知」权限有没有被关掉（很多系统管家、省电模式会顺手关掉）；
2. **App 内这台摄像头的设置**里，有没有把消息推送关掉。

另外有个容易误判的点：**你正开着实时画面看这台摄像头时，App 不会另外再推一条通知** —— 因为画面就在你眼前，它判定没有必要。所以「我盯着看的时候不推」是正常的，不是故障。

## 二、第二层：让摄像头认对「什么算事件」

在摄像头的侦测/报警设置里，通常有这几项可调：

| 设置项 | 作用 | 调法建议 |
| --- | --- | --- |
| 侦测开关 | 总闸 | 关了就什么事件都不产生 |
| 灵敏度 | 多大的动静才触发 | 对着马路的往低调；对着安静院子可往高调 |
| 侦测区域 | 只盯画面里的某块区域 | 把马路、树枝、邻家窗户排除掉，是减少误报最有效的一步 |
| 人形检测 | 只把「人」当目标，过滤小动物和光影 | 想减少猫狗/车灯误报就开它 |
| 智能追踪（云台机型） | 人动镜头跟着转 | 只在需要跟拍时才开，常开会显著耗电 |

**误报太多的处理顺序**：先缩侦测区域 → 再开人形检测 → 最后降灵敏度。反过来调往往把该报的也一起压掉了。

两个和你的机型直接相关的点：

- **宠物、车辆这类「非人」目标的识别，多款型号要求开通云存储才可用**。官方型号说明里在宠物检测那一行就标注了这个前提，所以「选项是灰的 / 找不到」多半不是你不会设，而是没开云存储，见 [SD卡录像与云存储怎么选.md](SD卡录像与云存储怎么选.md)。
- **户外电池 / 太阳能机型**通常是 **PIR 人体感应 + AI 人形检测**两层配合：PIR 负责把设备从待机中唤醒，AI 再判断是不是人。感应范围与角度按型号不同（有的型号标明 0~12 米、110° 一类数值），**以你手上那台的说明书标注为准**。部分户外机型还内置警报器，检出后可联动声光报警，开关同样在侦测设置里。

## 三、AI 哨兵与场景模式

官方对「AI 哨兵」的说明是：它不止判断「有人」，而是**描述人在做什么**（例如「小女孩在遛狗」「宠物在吃狗粮」这类行为级描述），事件列表里直接给你一句人话，省掉从头翻录像的时间。

配套的是**场景模式**：一键切到宠物看护、老人看护、家庭安防等场景，摄像头会按场景自动调整识别目标，不需要逐项去配。注意官方在说明里标注了 **AI 哨兵属于收费服务**，具体套餐与购买方式以 App 内页面为准。

## 四、第三层：告警消息能留多久

**告警消息在 App 里最多保留 7 天**，过期的通知会消失。要靠某条告警做凭据的，当天就把对应录像录屏存进手机（做法见 [实时画面与回放怎么看.md](实时画面与回放怎么看.md)）；要长期保留事件录像的，靠云存储或本地卡，见 [SD卡录像与云存储怎么选.md](SD卡录像与云存储怎么选.md)。

## 五、快速自查表

| 现象 | 先查 | 再查 |
| --- | --- | --- |
| 完全收不到推送 | 手机系统里 iCam365 的通知权限 | App 内该设备的推送开关 |
| 白天推、晚上不推 | 手机是否进了免打扰/省电模式 | 摄像头夜视切换时事件是否被判定为噪音 |
| 有人走却不推 | 侦测区域是否正好把那一块排除了 | 灵敏度是否过低 |
| 猫走过也推 | 是否开了人形检测 | 灵敏度是否过高 |
| 只在看实时画面时不推 | 这是正常行为，不用改 | —— |
