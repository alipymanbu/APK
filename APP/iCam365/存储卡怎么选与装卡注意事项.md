## 一、官方给的卡规格

多数 iCam365 摄像头的官方说明里，存储卡要求是这几项：

| 项目 | 要求 |
| --- | --- |
| 卡型 | microSD（TF）卡 |
| 容量 | 8GB ~ 128GB（多款型号标注上限为 128GB） |
| 速度等级 | Class 10 |
| 文件格式 | FAT32 |

**容量上限是「型号级」的**——不同型号（室内云台、户外太阳能、4G 机型）说明书上写的上限可能不一样，买卡前翻一下你手上那台的说明书或包装，以它为准。

## 二、买卡按这三条挑

1. **容量：先想清楚是报警录像还是全天录像。** 只在有人有动静时录，64GB 通常够用；要整天不停录，直接上到型号允许的上限（多数是 128GB）。
2. **速度：认 Class 10。** 低于这个等级的卡在写高清视频时容易掉帧、断录，表现为「时间轴上有洞」。
3. **用途：优先选标注「监控 / 行车记录仪」用途的卡。** 这类卡是按长时间连续写入设计的，普通手机卡长期挂机写更容易坏。

**别贪大**：超出型号上限的卡，轻则不被识别，重则插进去后连卡槽都要多试几次才认。256GB 及以上在很多型号上是不支持的。

## 三、装卡三步

1. **先断电**。这类摄像头**不支持热插拔**，带电插卡是最常见的「认不出卡」原因。
2. **按方向插入**。卡槽旁边一般有方向示意图，插反了会把卡卡住、甚至损坏卡槽。
3. **通电重启**。开机后在 App 的设备设置里确认卡状态已变成正常，再去看回放时间轴。

## 四、卡满了会怎样

不需要手动清理。**当卡上剩余容量降到 500MB 及以下时，摄像头会自动覆盖最旧的录像文件**，继续录下去。也就是说卡满了不是「停止录像」，而是「老的被顶掉」。

## 五、卡不认、录像消失，按这个顺序查

| 现象 | 先做什么 | 还不行 |
| --- | --- | --- |
| 显示「未插入存储卡」 | 断电、确认插卡方向、重插后通电重启 | 换一张**新卡**试；新卡也不认，多半是卡槽或内部排线，找卖摄像头的商家处理 |
| 卡是认的，但时间轴没内容 | 在 App 里看卡状态；确认录像模式是否开着 | 在 App 里格式化一次卡；仍不行就换卡 |
| 前几天有、现在没了 | 想想是否正好到 500MB 阈值，旧录像被自动覆盖 | 这是正常行为；要留证据就及时把片段录屏存进手机，见 [实时画面与回放怎么看.md](实时画面与回放怎么看.md) |
| 卡在电脑上能读、在摄像头里不认 | 卡的速度等级或格式不对（见第一节） | 换成 Class 10 的卡，并在电脑上格式化为 FAT32 |

## 六、在电脑上格式化时别选错

用电脑给卡重新格式化时，**文件系统选 FAT32**，不要选 NTFS 或 exFAT。容量较大的卡在 Windows 上有时不直接提供 FAT32 选项，这种情况直接用摄像头 App 里的格式化功能，比在电脑上折腾工具省事。
