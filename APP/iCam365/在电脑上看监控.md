# iCam365 在电脑上看监控

> 想在电脑上盯着画面是常见需求，但这一端有明确的能力边界：**摄像头必须先由手机 App 加好**，电脑端只负责看。这一篇说清能做什么、怎么装、以及 Mac 用户的实际情况。

## 一、电脑端能做什么、不能做什么

| | 手机 App | 电脑端（Windows） |
| --- | --- | --- |
| 看实时画面 | 可以 | 可以 |
| 回看录像 | 可以 | 可以 |
| 云台转动、语音对讲 | 可以 | 可以 |
| 添加设备、配网 | 可以 | **不行** |
| 改侦测、告警、云存储等设置 | 可以 | **不行** |

所以正确顺序是：**先用手机 App 把摄像头加好、该配的都配好，再在电脑上登录同一个账号看画面**。没在手机端加过设备，电脑上登录进去会是空的。

## 二、Windows 客户端怎么装

1. 从官方渠道获取 Windows 客户端安装程序（官方软件分发的下载页在官方站点上，文件名形如 `Install_iCam365_Player_...exe`；**具体版本号以官方下载页当时显示的为准**）。
2. 双击安装，按向导下一步，装完启动。
3. 用**手机 App 上那个账号**登录（注册、登录方式与手机端一致）。
4. 登录成功后，手机上已加好的摄像头会出现在电脑端列表里，点开即可看画面。

## 三、Mac 用户怎么办

**官方提供的是 Windows 客户端，Mac 没有对应版本。** 可行的替代是在 Mac 上直接安装手机版 iCam365 —— 苹果 M 系列芯片的机型支持直接装 iOS 应用（能不能装、装了之后界面如何，以你机器上的 App Store 实际显示为准）。至于虚拟机装 Windows 再跑客户端，属于绕路方案，界面和流畅度都不会和原生体验一致。

## 四、电脑端常见的两个疑问

- **电脑端和手机端能同时登录吗？** 官方快速指南里写明**一个账号同一时间只能在一台手机上登录**（账号安全措施）；电脑端是否算作同一条登录、能否与手机同时在线，官方资料没有写明，**以你实际登录时看到的情况为准**。要让两个人同时在两台设备上看，最稳妥的做法是分享给两个账号，见 [分享给家人一起看.md](分享给家人一起看.md)。
- **电脑端看不到某台设备？** 先在手机上确认这台设备是**当前登录账号**下的、并且手机端能正常出画面；只有手机端能看到，电脑端才看得到。手机端本身就连不上的，先按 [设备离线与连不上怎么排查.md](设备离线与连不上怎么排查.md) 处理。
