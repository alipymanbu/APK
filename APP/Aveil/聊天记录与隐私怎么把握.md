# 聊天记录与隐私怎么把握

> 本篇讲清 Aveil 里的对话记录存放在哪、会话怎么管理、登录与不登录有什么区别，以及哪些内容不该写进剧情里。

这份文档讨论的是「你聊过的东西会去哪」和「你能拿它怎么办」。官方的更新说明里有一句关键交代：AI 角色会依照你和它的互动，记录你们的故事。也就是说，你和角色之间的来往是会被留下来的，下面按这个前提来给操作和边界。

## 一、记录存在哪

| 内容 | 大致归属 | 你要知道的 |
| --- | --- | --- |
| 对话内容与人设 | 账号下的会话记录 | 官方说明里明确会记录你与角色的互动 |
| 角色偏好、金币余额 | 账号数据 | 个人中心可查看金币数量与互动记录 |
| 自建角色的设定 | 账号数据 | 会参与对话并被保存，写法边界见 [怎么创建自己的AI角色.md](怎么创建自己的AI角色.md) |

运营方的隐私政策页面在官方站点上（[aveil-ai.app](https://aveil-ai.app/) 下有协议入口），里面会写明收集范围与用途；**具体条款以该页面当前版本为准**，本篇不复述、也不替它做承诺。

## 二、会话怎么管理

- **置顶 / 拉黑 / 举报**：一般都在会话内。有页面提到入口在角色聊天页头像右上角的「三」图标里，实际位置以应用内显示为准，这三项的作用分别是把会话排到前面、不再接收该角色内容、把问题提交给平台；
- **删除会话**：官方的版本更新里出现过「新增删除隐藏会话功能」这一条，也就是说被收起来的会话也能清掉，不必先取消隐藏再删；
- **想彻底从列表里消失**：先删会话，再清掉角色管理里的自建角色（如果你建过），两步都做完列表才会干净。

**删除是不可逆的**，动手前想清楚这条会话里有没有你还想翻回去看的内容。

## 三、登录与不登录的区别

| | 不登录 | 登录后 |
| --- | --- | --- |
| 进首页、翻角色与剧本 | 可以 | 可以 |
| 聊天记录跟着账号走 | 不保证 | 换设备后仍在 |
| 自建角色、金币余额 | 存疑，以应用内为准 | 随账号保存 |

登录入口在「我的」里，官方的版本更新提到优化了性别设置并增加了编辑用户资料的入口，也就是说**登录后可以补全自己的资料**。第三方页面提到的登录方式有邮箱、手机号、谷歌和 Facebook 几种，口径并不一致，**以应用内当时给的可选项为准**。

有一条判断很实用：**如果你在意记录能不能跟着自己走，就先登录再开始聊。** 攒了一堆会话才去登录，前面的内容未必能并进账号里。

## 四、哪些内容别写进剧情里

角色扮演类应用最容易放松警惕的就是这一点——聊得投入时，人会不自觉地把真实信息当成设定交代出去：

- 真实姓名、住址、单位、学校、证件号；
- 手机号、邮箱、社交账号；
- 银行卡、支付信息，任何形式的转账与代付请求。

人设里也不要填这些。填进去之后它会参与对话、跟着记录一起被保存，删会话不等于删干净。

## 五、内容分级与使用边界

- **分级**：iOS 版在商店里标注为 18+；安卓侧第三方页面的口径是 16+ 或「年满十六周岁以上」。两边不一致时**以官方渠道页面为准**；
- **题材**：应用里有悬疑、恐怖一类强情节剧本，未成年人不宜；
- **用法**：这是休闲与陪伴类的对话产品，别把它当成情感或心理问题的替代方案，也别按角色给出的建议去做现实里的重要决定；
- **遇到不当内容**：用会话内的举报入口提交，同时可以直接删掉该会话。

## 六、换手机前要做的事

1. **先确认登录的是同一个账号**，不然新机上打开会是空白；
2. **想留的自建角色先记下设定**，角色与记录跟着账号走，账号不对齐就找不回来；
3. **旧机上退出登录之前别急着卸载**，卸载清的是本机数据，账号里的内容以服务端为准（是否保留以官方说明为准）。

有一条容易踩的坑：**安卓各家自带的换机工具（互传、手机搬家之类）通常搬不走这类应用里的内容。** 它们搬的是安装包和部分应用数据，而账号类应用的角色、会话、金币大多挂在服务端账号上——换机后起作用的是「用原账号登录」，不是搬家工具。跨品牌换机时更不该指望它。

换机后的正确顺序是：装好应用 → 联网 → 登录原账号 → 打开列表确认内容回来了。第三方页面提到这类应用有跨平台账号系统、安卓与 iOS 之间的账号数据可以互通，**这一点以应用内实际表现为准**，迁移前别把旧机上的记录先删了。
