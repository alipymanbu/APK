Aveil 的毛病看着花样多，其实大多落在四个圈里：网络链路、账号状态、版本新旧、系统权限。先判断属于哪一圈，能省掉大量反复重装的时间——**重装通常只对「版本新旧」这一圈有效**，其余三圈做了也白做。

## 一、先分清是哪一圈的问题

| 症状 | 大概率是哪一圈 | 第一步做什么 |
| --- | --- | --- |
| 打开后一直转圈、进不去首页 | 网络 | 换个网络重开一次 |
| 卡在登录页、验证码收不到 | 账号 | 见第三节 |
| 消息发出去，角色不回 | 网络或服务端 | 等十几秒再发一句短的 |
| 语音输入点了没反应 | 系统权限 | 见第五节 |
| 界面卡死、打开就闪退 | 版本或系统环境 | 见第六节 |

判断网络是不是元凶最快的办法，是**同时用浏览器打开一个网页**：网页能开、Aveil 不出内容，问题在应用或服务端；网页也打不开，先把网络修好再谈别的。

## 二、打不开、一直转圈

按顺序试，每步做完重开一次应用：

1. **换网络**：Wi-Fi 与移动数据互换，这是最常一步解决的问题；
2. **确认手机能上外网正常**：角色列表和剧本内容都要联网取，浏览器打不开就与 Aveil 无关；
3. **清一次应用缓存**：进「设置 → 应用 → Aveil → 存储」，清缓存不会删账号里的记录；
4. **看是不是只卡在某个页面**：只有某个角色或剧本点不动，多半是那一条内容本身的问题，换一个试；
5. **以上都正常仍然打不开**：把应用更新到较新版本再试，官方更新说明里多次出现过修复体验问题的条目。

**别用「反复杀后台强开」的办法**，出不来就是出不来，反复重开多半也解决不了。

## 三、登录与验证码

- **先确认是不是必须登**：基础浏览和对话在未登录状态下通常就能用，具体以应用内为准，相关范围见 [聊天记录与隐私怎么把握.md](聊天记录与隐私怎么把握.md) 第三节；
- **验证码收不到**：先看短信有没有被系统安全中心拦进垃圾箱；再确认手机号填的是带区号的正确格式；连点几次收不到就隔几分钟再试，频繁点反而会被限制；
- **第三方登录打不开**：官方更新说明里出现过修复第三方登录问题的条目，走不通时先更到较新版本，再换一种登录方式；
- **页面能打开但授权后回到原处**：多半是系统浏览器组件的问题，换个默认浏览器后重试，或改用应用内的其他登录方式。

## 四、对话不回或回得很慢

先区分「完全不回」和「回得慢」：

| 情况 | 可能原因 | 处理 |
| --- | --- | --- |
| 一直转圈、始终不出字 | 网络中断或服务端排队 | 等 10~15 秒；仍不出就重新发送 |
| 要等十几秒才出字 | 网络延迟高，或赶上高峰时段 | 换网络或换个时段再聊 |
| 回了但明显跑题 | 会话太长、话题太散 | 新开一条会话，把要说的事讲清楚 |
| 只在这个角色上不回 | 该角色或该章节本身有异常 | 换一个角色试，正常的话问题在内容侧 |
| 点了发送没反应 | 当前回合用完了 | 见 [金币和钻石怎么获得怎么用.md](金币和钻石怎么获得怎么用.md) 第三节 |

**别用连发十条催它的办法**，发一句短的探路更有效。

## 五、语音输入没反应

语音转文字失灵，绝大多数不是应用故障。按下面顺序自查，前三条最常见：

1. **麦克风权限没给**：进「设置 → 应用 → Aveil → 权限」，把麦克风设为「仅在使用该应用时允许」。国产定制系统里这一项也可能收在「隐私 → 权限管理」或「应用权限」下；
2. **系统里麦克风被全局关闭**：有的系统有全局麦克风开关或隐私模式，关着的时候任何应用都拿不到音频，先确认它是开着的；
3. **麦克风被别的应用或设备占着**：正在通话、录屏、语音助手在听、蓝牙耳机连着——都会把输入抢走。断掉蓝牙耳机、关掉占用中的应用再试一次；
4. **系统更新后权限被重置**：升级系统后应用权限可能回到默认，回头再确认一次第 1 条；
5. **还不行就清一次应用数据**：进「设置 → 应用 → Aveil → 存储 → 清除数据」，注意这一步会清掉本机未同步的内容，动手前先看 [聊天记录与隐私怎么把握.md](聊天记录与隐私怎么把握.md)；
6. **最后用录音机做对照**：手机自带录音机也录不上，说明问题在系统或硬件（麦克风孔被保护壳挡住、进灰也算），不在 Aveil，不必再折腾应用。

## 六、卡顿、闪退、发热

按影响面从大到小排：

1. **可用存储空间**：剩余空间过低（比如不足 1 GB）时，读写缓存容易失败，先清空间；
2. **后台应用太多**：内存紧张时长时间会话更容易被系统回收，表现为切回来要重新加载；
3. **系统版本偏旧**：应用对系统版本有要求，长期不更新系统的设备更容易出问题；
4. **应用版本偏旧**：官方更新说明里修过多次体验问题，更到较新版本是第一优先动作；
5. **收不到消息提醒**：进「设置 → 应用 → Aveil → 通知」确认通知权限已开；长时间没打开应用时提醒延迟属常见表现；
6. **发热异常**：聊天本身负载不高，边充边用或别的应用在跑更可能是主因。

## 七、金币与付费相关

| 现象 | 多半是什么情况 | 处理 |
| --- | --- | --- |
| 金币不够、次数用完 | 日常行为攒的金币没兑或不够 | 见 [金币和钻石怎么获得怎么用.md](金币和钻石怎么获得怎么用.md) 第三节 |
| 找不到关闭扣费的地方 | 收款方不在应用里 | 去应用商店或支付渠道的账户页处理 |
| 付了钱权益没到账 | 付款账号与应用内登录账号不是同一个 | 换成付款时那个账号登录；仍不对就带订单信息联系开发者客服 |
| 换了手机付费权益丢了 | 新机上登错账号 | 用付款时的账号重新登录 |
| 页面说「完全免费」，应用里却有付费提示 | 第三方页面的说法与官方口径冲突 | 以应用内和商店标注为准 |

## 八、这份排查不管的情况

- **装不上、安装报错**：属于安装环节，见 [下载与安装教程.md](下载与安装教程.md) 第五节；
- **搞不清两条玩法怎么用**：见 [角色剧本和预设剧本有什么区别.md](角色剧本和预设剧本有什么区别.md)；
- **删不掉的会话、看不明白的数据范围**：见 [聊天记录与隐私怎么把握.md](聊天记录与隐私怎么把握.md) 第二节；
- **怀疑装错了包**（界面、体积、包名都对不上）：先按 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 第一节核一遍，很可能一开始就不是这个应用。

如果只有某一条会话彻底不正常、新开的会话一切正常，**最省事的做法是放弃那一条**，别在它上面反复试——你翻得到内容，重建一条新会话的成本比修它低得多。
