# 角色剧本和预设剧本有什么区别

> 本篇把 Aveil 的两条主线拆开讲：一条是你自由聊的角色剧本，一条是跟着台词点按推进的预设剧本，附带各自怎么操作、什么时候该选哪条。

Aveil 把玩法分成两条线：角色剧本给你一个有人设的 AI 角色，你说什么它接什么；预设剧本给你一段别人写好的对白，你按输入框里的提示点发送把故事推下去。两者的操作手感差别很大，本篇帮你先认清再选，省得进了错的那条还以为是应用不好用。

## 一、一张表看清两条线

| 维度 | 角色剧本 | 预设剧本 |
| --- | --- | --- |
| 谁在主导 | 你，往哪个方向聊由你决定 | 写好的剧情，你负责往下推 |
| 你的输入 | 自由打字，或语音转文字 | 输入框会给出下一句台词，点「发送」推进 |
| 结构 | 章节化，剧情在限定回合内展开 | 章节式，每章配有与剧情相关的动态背景影片 |
| 陪伴感来自 | 角色的世界观、背景与剧情限定 | 台词节奏与画面，更接近「沉浸式对话小说」 |
| 适合的场景 | 想自己发挥、想找人随口聊 | 不想想话题，想被情节带着走一段 |

两条线共用同一个账号与同一套资源口径，聊天机会的消耗见 [金币和钻石怎么获得怎么用.md](金币和钻石怎么获得怎么用.md)。

## 二、角色剧本怎么聊

进入方式是先从角色库里挑一个角色（首页怎么翻、搜索框怎么写，见 [怎么找角色和剧本.md](怎么找角色和剧本.md)），进到对话页之后直接输入。几个实际会碰到的点：

1. **每个角色带着自己的设定。** 它有明确的世界观、背景和剧情边界，你说的话它会照着自己的身份来回，所以同一个问题问两个角色，答案的口气不一样是正常的。
2. **剧情按章节走，回合是有限的。** 设定里写明了在限定回合内展开剧情与情感互动，也就是说它更偏向「一段有开头有推进的戏」，而不是无限续聊的问答。
3. **打字和语音二选一。** 不方便打字的时候用语音转文字，说的内容会转成文字再发出去，输入方式不影响剧情本身。
4. **不想按剧本走也行。** 你完全可以跳出角色的预期，说些它没设想过的话，它依然会照着人设接——这一点是角色剧本和预设剧本最大的不同。

## 三、预设剧本怎么点按推进

这条线的输入框里不是空的，而是显示着下一句台词：

1. 进入某个剧本，选好章节；
2. 看输入框给出的台词，点「发送」推进剧情；
3. 每一章配有与剧情氛围呼应的动态背景影片，画面跟着章节走；
4. 想快就一路点下去，想慢就停在那里看画面，节奏由你掌握。

它的体验更接近一本「你会参与进去的对话小说」——你在看，也在推。

## 四、什么时候选哪条

- **刚装好、想先看看应用长什么样**：先在预设剧本里挑一个短章节点几屏，成本和理解门槛都最低。
- **想聊天但不知道聊什么**：选角色剧本，从角色库里挑一个顺眼的人设开始。
- **想要一段完整的情绪起伏**：选预设剧本，走完一整段章节。
- **想试自己捏的角色**：见 [怎么创建自己的AI角色.md](怎么创建自己的AI角色.md)。

## 五、两条线都会碰到的几个点

| 现象 | 说明 |
| --- | --- |
| 聊着聊着提示要更多次数 | 聊天机会与金币、钻石相关，见 [金币和钻石怎么获得怎么用.md](金币和钻石怎么获得怎么用.md) |
| 同一句话翻来覆去地问 | 对话变长后话题太散，换个新会话、把要说的事讲清楚更有效 |
| 角色答得明显不对题 | 先确认自己有没有在预设剧本的章节里跳着点；角色剧本里则可以换一种说法再试 |
| 某个角色或剧本点进去转圈 | 属于加载问题，按 [常见问题与排查.md](常见问题与排查.md) 第四节走一遍 |
| 不想让某条会话留在列表里 | 见 [聊天记录与隐私怎么把握.md](聊天记录与隐私怎么把握.md) 第二节 |

## 六、两个容易绕晕的说法

- **「预设剧本」和「角色剧本」不是两个应用，也不是两套账号。** 它们只是同一份安装包里的两种进入方式，随时可以切。
- **「章节」和「回合」也不是一回事。** 章节是剧情的一段划分，回合是这一章里你还剩多少次输入或推进的机会；章节用完了要等更新或解锁下一章，回合用完了则和聊天机会有关。
