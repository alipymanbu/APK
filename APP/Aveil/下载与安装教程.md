Aveil 是安卓端的 AI 剧本对话应用：一头是带完整人设的 AI 角色，你自由打字或语音输入和它聊；另一头是写好的剧本，你跟着台词提示点按往下推。本篇只做一件事——把网盘里这份安装包装进手机并正常打开。

## 一、先确认网盘里这份包是哪一版

应用商店和下载站页面上显示的是它们当时拿到的那一版，跟网盘里这份往往对不上。本篇出现的版本号、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Aveil |
| 版本号 | 1.3.3 |
| 包名 | `com.jjaa.mind` |
| 安装包体积 | 11.96 MB |
| MD5 | `B2E516743D1D022DD47DCFCD3A0D5B09` |
| 适用平台 | Android（手机端 APK） |
| 界面语言 | 简体中文 |
| 运营主体 | 星语智能有限公司（英文主体名 Stellario Intelligence Limited，见应用商店的开发者一栏） |

装之前先弄清三件事：

- **认包名，别只认名字。** 搜「Aveil」会同时冒出一批近名条目：AveilAI、aveilai、Aveil AI 等等，其中不少包名是 `app.aveil.aichat`，体积四五十兆起步，跟这一份不是同一个包。这份包的包名是 `com.jjaa.mind`，装好后在「设置 → 应用 → 应用管理」里点进 Aveil 的应用信息页能看到；对不上就先按 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 核一遍再决定装哪个。
- **这是安卓包，iPhone 和 iPad 装不了。** App Store 上有 iOS 版，但那份只能用 Apple ID 在商店里装，和网盘里这个 APK 不是一回事。
- **系统要求以官方页面为准。** 这份包的登记信息写的是「安卓系统 5.2 以上」——安卓的正式版本号里并没有 5.2，这一条更像是站点之间互相抄出来的口径，不必当成准数。装机前在「设置 → 关于手机」里看一眼自己的系统版本，再对照官方渠道页面上登记的要求；版本过低的表现通常是装不上，或者装上打开即退。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [Aveil 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0415e27502e7)，用手机上的夸克 App 打开最省事。
2. **先转存再下载**：把安装包转存到自己的网盘目录，再从那里下载到本机。分享链接以后可能失效，转存过的那份不受影响。
3. **核对体积**：下载完成后看一眼文件体积，应当约 11.96 MB。中途断网重连拉下来的包常常不完整，安装时多半直接报「解析包错误」。
4. **想校验完整性**：在电脑上把包算一遍 MD5，结果应与上表一致（大小写不敏感）。

```cmd
certutil -hashfile Aveil_v1.3.3.apk MD5
```

文件名里的版本号会随包变化，以实际拿到的那个为准。

## 三、安装步骤

1. **给文件管理器开「安装未知应用」权限**：进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把用来打开 APK 的那个应用（文件管理器或浏览器）的开关打开。国产定制系统这一项常收在「安全」或「隐私」分类里。
2. **点击 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续，这是侧载安装包的常规提示，不代表包有问题。
3. **手机上已有更高版本时先卸载**：安卓不允许用低版本覆盖高版本，会直接报「应用未安装」。卸载会一并清掉本机上和角色聊过的记录，动手前先想清楚要不要留，相关范围见 [聊天记录与隐私怎么把握.md](聊天记录与隐私怎么把握.md)。
4. **报「签名不一致」说明包名撞了**：手机里已装过同包名、不同来源的版本，按第五节表格处理。
5. **留出安装空间**：安装过程中系统还要展开一份文件，建议预留 500 MB 以上可用空间，别卡在 100 MB 出头那种紧张状态。

## 四、第一次打开要确认的三件事

1. **能联网**：角色列表、剧本内容和对话回复都要联网才能拿到，应用本身不能离线聊。打开后一直停在加载状态，先用浏览器确认手机能正常上网。
2. **能进到首页**：这份包不登录也能进入首页翻角色和剧本（是否要求登录以应用内当时显示为准，相关口径见 [聊天记录与隐私怎么把握.md](聊天记录与隐私怎么把握.md)）。如果卡在登录页过不去，按 [常见问题与排查.md](常见问题与排查.md) 第三节走。
3. **能发出一句话**：随便点进一个角色或一个剧本，发一句「你好」，能正常收到回复就算装好了。想先弄清两种玩法各自是什么，见 [角色剧本和预设剧本有什么区别.md](角色剧本和预设剧本有什么区别.md)。

## 五、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整 | 核对体积与 MD5，按第二节重新取一份 |
| 提示「应用未安装：签名不一致」 | 手机里已有同包名、不同来源的版本 | 先在应用管理里卸载旧包，再装这份 |
| 安装被安全中心拦下 | 侧载包被系统安全策略拦了 | 在安全中心的拦截记录里选「继续安装」 |
| 点安装没反应 | 「安装未知应用」权限没给 | 回到第三节第 1 步补上权限 |
| 装完打开就闪退 | 系统版本过低、存储不足或包残缺 | 见 [常见问题与排查.md](常见问题与排查.md) 第六节 |
| 装完发现界面和截图对不上 | 装的其实是另一个同名包 | 按 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 第一节核包名 |

以后换版本或者重装，按第二节重新取一份即可，安装动作与这次相同。

## 六、装完之后顺手做两件事

- **在应用管理里记一眼包名**：点进 Aveil 的应用信息页，确认包名是 `com.jjaa.mind`。以后再碰到一个叫 Aveil 或 aveilai 的应用，拿这条一对就知道是不是同一个。
- **把网盘里的包留着**：这类应用的版本更新比文档快，某个新版用着不对劲时，能退回旧版的前提是手上还留着旧包；网盘里转存过的那份是干净的原始文件。
