## 一、装不上或装完打不开

| 现象 | 处理 |
| --- | --- |
| 点安装提示「禁止安装来自此来源的应用」 | 按提示给下载用的应用开「安装未知应用」权限，步骤见 [下载与安装教程.md](下载与安装教程.md) |
| 安装包解析失败 | 包没下完整，重新下一次并核对 MD5（对照表在 [下载与安装教程.md](下载与安装教程.md)） |
| 装完一点就闪退 | 先确认系统版本是否满足要求（安卓 5.2 以上）；再在系统设置里清一次它的存储后重开 |
| 打开后白屏、一直转圈 | 多半是网络问题：切到稳定的 WiFi 重开一次应用 |

装不上、闪退反复出现时，换成网盘里那份已核对过的包再试一次——网上同名的包很多，装错包的表现就是怎么都跑不起来。

## 二、播放类问题

**无法播放**：先看网络通不通（打开别的网页试试）；再刷新页面或重启应用；个别片源的问题就等一会儿再试，或换下一条线路。

**加载缓慢**：

1. 换更稳的 WiFi，避开信号弱的角落；
2. 暂停后台正在下载、上传、更新的应用，把带宽让出来；
3. 播放页里降一档清晰度，或切换播放线路（操作见 [搜索与播放使用教程.md](搜索与播放使用教程.md)）。

**找不到想看的片**：

- 换关键词再搜一次（简称、别名、演员名都试试）；
- 从分类页按类型、地区、年份筛；
- 都没有就是这部片当前没有收录，不是你操作错了。

## 三、登录与账号问题

- **登录不上去**：先核对手机号和密码是否输错；再清一次应用缓存后重试；还是不行就等网络恢复后过一会儿再试。
- **收不到验证码**：检查手机信号与短信拦截列表，稍后重新获取。
- **登录的目的是同步**：只是自己在本机看片的话，不登录也能用，播放记录照常保存在本机（见 [播放记录怎么查看.md](播放记录怎么查看.md)）。

## 四、投屏连不上

投屏问题九成在网络侧：手机和电视是否同一 WiFi、电视是否弹了授权、是否被数据流量接管。完整的排查表在 [投屏到电视上怎么看.md](投屏到电视上怎么看.md)。

## 五、一个通用的自检顺序

多数问题都能按这个顺序排掉，从上往下试、哪步解决了就停：

1. **网络**：切一次 WiFi / 开关一次飞行模式；
2. **重启应用**：上滑关闭再重新打开；
3. **换线路 / 换清晰度**：播放类问题专用；
4. **清缓存**：系统 设置 → 应用 → FreeOK → 存储 → 清缓存（注意「清数据」会连播放记录一起清，见 [播放记录怎么查看.md](播放记录怎么查看.md)）；
5. **重装**：兜底手段，先确认手上有已核对的安装包（见 [下载与安装教程.md](下载与安装教程.md)），再卸载重装。
