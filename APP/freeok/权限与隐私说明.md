## 一、装的时候要的权限，各是干什么的

freeok 系列应用公开的权限说明（截至 2026 年 9 月）里列出的申请项与用途，和各下载页标注的权限清单能对上：

| 权限 | 用途（按其隐私政策文本） | 关掉会怎样 |
| --- | --- | --- |
| 网络 | 请求影片数据、上传必要的运行数据 | 直接没法用——播放全靠网络 |
| 存储（读写手机内部/外部） | 把图片、缓存文件存到手机上 | 离线缓存存不了，看过的记录可能异常 |
| 电话（读取手机状态） | 取设备 ID，用于账号与网络安全、防欺诈、统计安装与活跃 | 一般不影响看片；个别版本的登录或防刷校验可能受影响 |
| 定位 | 说明里写的是「根据位置匹配相应的广告」 | 不影响播放与搜索，可以放心关 |
| WLAN / 网络状态 | 判断当前网络是否可用、排查请求失败原因 | 影响网络状态判断，别关 |

两条实用判断：

- **和看片直接相关的只有网络、存储两项**，其余关掉通常不影响核心功能——存储权限对应的是离线缓存那套功能，具体见 [搜索与播放使用教程.md](搜索与播放使用教程.md)；
- **定位权限的用途写的是广告**，不是功能——你在系统里拒绝它，搜索、播放、投屏都不受影响。

## 二、注意：同名 freeok 有多个主体

上表来自 freeok 系列某运营主体（隐私政策文本里标注为长沙梵雨信息技术有限公司）公开的政策文本。但这个名字下的下载包不止一个、运营主体也不止一家（各包的包名与厂商标注差异见 [下载与安装教程.md](下载与安装教程.md) 的版本对照表）。

所以正确的读法是：**上表说明的是这一类应用通常申请什么、为什么申请；你手上那份包实际申请哪些、政策怎么写，以应用内展示的隐私政策为准**——装好后在应用的设置或关于页里能找到原文。两边对不上时，以你实际看到的为准，不要拿别家的政策当自家的。

## 三、怎么看、怎么关这些权限

安卓通用路径（各品牌菜单名略有出入）：

1. **设置 → 应用 → 找到 FreeOK → 权限**；
2. 列表里逐项看：已允许 / 已拒绝，点进去可改；
3. 改完直接回应用试——不用重启，立即生效。

按需求关的建议：

- **只想看片**：留网络、存储，其余全关；
- **在意广告追踪**：关定位；再在 **设置 → 安全与隐私 → 隐私 → 广告** 里删除或重置广告 ID（菜单名以你的系统为准）；
- **全部拒绝**：应用大概率播不了——别一步全关，按上面第一行的取舍来。

关了某个权限导致功能异常（缓存失败、提示无权限），回来把它重新打开即可，处理流程见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、隐私政策里值得知道的一点：第三方 SDK

其政策文本列了接入的第三方 SDK，主要两类：

| 类型 | 用途 | 收集的信息（按政策文本） |
| --- | --- | --- |
| 统计分析类 SDK | 运行数据统计 | 设备标识符、平台与固件信息、运营商、粗略位置等 |
| 广告投放类 SDK | 广告投放 | 设备标识符、设备序列号，个别 SDK 还涉及剪切板、传感器、软件安装列表 |

政策同时写明：第三方 SDK 的数据处理类型可能随版本升级变化，以其公示的官方说明为准。

你能做的三件事，都在系统侧完成，不需要应用配合：

1. 拒绝定位权限（广告类 SDK 的位置信息来源之一）；
2. 删除或重置广告 ID；
3. 不给不必要的权限——安卓的权限模型下，拒绝只影响对应功能，不会导致应用整体不可用（网络权限除外）。
