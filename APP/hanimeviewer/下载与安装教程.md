## 一、装之前先确认三件事

**这是什么形态的应用**：HanimeViewer 是装在安卓手机上的第三方视频客户端，用来浏览、搜索和播放 hanime 相关视频网站（`hanime1.me` 一系）上的公开内容。它不在应用商店上架，一般通过 APK 安装包分发，安装方式与普通应用略有不同。

**成年内容提示**：这款应用面向成年用户，未满 18 岁不应下载和使用；是否适合安装，还取决于你所在地区的法律法规——自行确认后再往下走。

## 二、从哪里获取安装包

**途径一：网盘资源（本篇配套资源）**。如果你拿到的就是本文头部的 [HanimeViewer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/df04085ab120)，先转存到自己网盘，再把 APK 文件下载到手机，然后走第三节的安装步骤。这种方式不依赖任何商店，装的就是本文口径对应的那个版本。

**途径二：认准渠道再看包名**。这类客户端在 GitHub 上有多个维护分支，经历过分叉与维护权变更，不同渠道分发的安装包**包名和版本号并不一致**（例如有的渠道包名是 `com.yenaly.han1meviewer`，有的是 `com.han1meviewer.remastered`）。所以：

- 升级前先确认新包的包名——**同包名**可直接覆盖安装，保留本地数据；**不同包名**会作为两个独立应用并存，占双份空间，建议二选一后卸掉另一个；
- 各渠道的版本号写法不同（`2.2.6`、`v0.25.0-release26051916` 这种都存在），不能直接比大小，以各自渠道的更新说明为准。

## 三、安装步骤

1. 把本文头部网盘资源里的 APK 文件下载到手机存储（转存后用夸克网盘客户端下载即可）；
2. 在手机上点开这个 APK。第一次装会弹「禁止安装未知应用」的提示，点「设置」→ 允许「来自此来源的应用」→ 返回重新点安装；
3. 等进度走完，点「打开」；首次启动如果弹出年龄确认或隐私提示，按提示确认后进入首页。

装完进不去或首页一直加载，多半是网络层面的事，直接翻 [网络设置与加载失败排查.md](网络设置与加载失败排查.md)。

## 四、装不上时的排查顺序

| 现象 | 原因与处理 |
| --- | --- |
| 提示「无法解析安装包」 | 文件没下完整，或手机安卓版本低于 5.2。重新下载一次，仍不行就核对 MD5 是否为 `A4677418DB2922AE3174A6E04813016F` |
| 提示「与已安装的应用冲突」 | 手机里已有一个同包名但签名不同的旧版本（比如早前从别的渠道装过 `com.nenya.hani`）。先卸载旧版再装 |
| 安装到一半空间不足 | 32.66 MB 只是安装包体积，装完加上缓存会更大，清理出至少 1 GB 再试 |
| 被手机管家拦截 | 部分机型的安全软件会对商店外的 APK 提示风险，确认来源后选择「仍要安装」；不确定来源就不要强行放行 |
