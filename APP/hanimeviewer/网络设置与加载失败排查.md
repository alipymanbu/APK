# HanimeViewer 网络设置与加载失败排查

> 首页转圈、搜索加载不出、提示网站被加固——这类问题九成出在网络链路上。本篇按现象给出排查顺序，从应用内就能解决的开关开始。

## 一、先分清是哪种失败

| 现象 | 大概率原因 | 先做哪一步 |
| --- | --- | --- |
| 首页、搜索一直转圈，内容出不来 | 访问链路不通 | 做第二节：开应用内置 Hosts |
| 提示「网站被加固」或跳验证页 | 目标站点开了防护（Cloudflare 一类） | 做第三节：换备用域名；验证页过不去另见 [Cloudflare验证过不去怎么办.md](Cloudflare验证过不去怎么办.md) |
| 能刷列表，一点播放就卡死或黑屏 | 播放链路不稳 | 第四节：代理与 IP；再不行降画质 |
| 昨天还好好的，今天突然全挂 | 目标站点改版或换域名 | 先试第三、四节，不行升级新版（第五节） |

所有开关都在同一个地方：**首页左上角三条横线 → 设置 → 网络设置**。

## 二、开启应用内置 Hosts

网络设置页里找到**应用内置 Hosts**（内置加速）开关，打开后按提示**确认并重启应用**再试。

这是最值得先试的一步：开启后部分地区可以不借助任何其他工具直接访问。但它不是对所有地区、所有运营商都有效——开了没变化属正常，往下走。

## 三、切换备用域名

还在网络设置页，页面下方有**备用网站（备用域名）**列表：

1. 当前域名加载失败时，点开备用列表换一个域名；
2. 有的版本会显示各域名的延迟情况，选延迟低、能连通的那个；
3. 换完同样重启应用生效。

目标站点会不定期更换可用域名，列表里哪个能用以当次实测为准，选完记得开一次首页确认。

## 四、代理与 IP 的注意事项

- 手上本来就有可用代理网络的，在网络设置里选**手动填代理**，输入地址和端口，确认后重启应用；代理生效后应用内不必再叠加开内置 Hosts；
- **IP 归属地有讲究**：有用户反馈日本 IP 会被目标站点拦截，把出口 IP 切到非日区后恢复正常。排除法时可以先换一个地区的出口试；较新的维护版本在检测到这类拦截时会直接把原因显示在加载失败的提示里，遇到笼统的「加载失败请重试」就说明你的版本还不会报原因，只能手动换出口排查；
- **直连失败先看提示**：部分版本检测到当前网络环境需要代理才能访问时，会直接提示开启代理——照提示开就行，不用再逐个试开关；
- 反过来，如果你在直连就能用的网络环境里，就别叠加代理，多一层链路多一层卡的可能。

## 五、上面都试过还不行

按这个顺序收尾：

1. **重启路由器、换网络**（比如从 WiFi 切到流量），排除本地网络波动；
2. **升级应用版本**：目标站点改版后，旧版本的解析逻辑会失效，表现就是所有页面都加载不出。用新安装包覆盖升级（同包名）即可，操作见 [下载与安装教程.md](下载与安装教程.md) 第二节；
3. 装的是很老的版本且本地有重要数据（收藏、下载），先备份数据再卸载重装。

网络通了之后，界面怎么逛看 [首页浏览与搜索筛选.md](首页浏览与搜索筛选.md)，下载离线看见 [播放控制与离线下载.md](播放控制与离线下载.md)。
