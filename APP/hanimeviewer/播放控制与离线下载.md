## 一、播放界面能调什么

点开任意视频进入播放页后，常用的控制有这几样：

| 控制 | 说明 |
| --- | --- |
| 倍速 | 可调快可调慢，具体档位以你的版本播放菜单为准 |
| 画质 | 在画质选择里切换不同清晰度；卡顿先降一档画质 |
| 播放内核 | 设置里可切换播放内核，一种内核播不了的片子换另一种常能解决 |
| 画中画 | 退出应用后以小窗继续播，边干别的边放 |
| 本地播放 | 支持直接播放下载到本地的视频文件 |

看一半退出的位置一般会被记住，下次从详情页续播即可。

## 二、把视频下载到本地

在详情页或播放页把视频加入下载后，任务会进入**下载管理**（侧边栏里进）。这一块有几个对你有用的设定：

- **后台下载**：任务排上之后可以退出界面干别的，下载在后台继续；
- **自动分组**：下载属于某个系列的作品时，可按系列名自动建分组，不用手动归类；
- **自定义目录**：在下载设置里可以指定保存位置，想存到存储卡就在这里改；
- **下载后播放**：开这个选项后，下完的任务点开直接进播放，不用再找文件。

流量有限的场景，看看下载设置里有没有「仅 WiFi 下下载」一类的开关，先开了再排任务。

## 三、导入手机里已有的视频

下载管理里有**导入本地文件**的入口，可以把手机存储里已有的视频导进来统一管理、用它自带的播放器播。适合手里存了一批视频、想换一个界面干净点的播放器的情况。

## 四、下载卡住或失败先查两处

1. **网络**：加载都费劲的环境下载必然失败，先按 [网络设置与加载失败排查.md](网络设置与加载失败排查.md) 把访问问题解决，再重试下载；
2. **存储**：目录所在的分区满了会静默失败，检查下载设置里指向的那个位置剩余空间。报「文件不存在」的多半是系统存储限制在作怪，改法见 [下载失败提示文件不存在怎么办.md](下载失败提示文件不存在怎么办.md)。

还没装应用的，从 [下载与安装教程.md](下载与安装教程.md) 开始；找片的方法见 [首页浏览与搜索筛选.md](首页浏览与搜索筛选.md) 的高级筛选一节。
