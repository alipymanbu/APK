## 三、安装步骤（以 Android 8 及以上为例）

1. 在文件管理器里找到下载好的 APK，点它。首次安装会提示「不允许安装未知来源应用」；
2. 点弹窗里的「设置」，打开「允许来自此来源的应用」，返回继续安装；
3. 等进度条走完，点「打开」或回桌面点图标；
4. 首次启动如弹出存储/音频相关权限请求，选「允许」——导入本地歌曲伴奏要靠它，见[导入本地歌曲与循环伴奏.md](导入本地歌曲与循环伴奏.md)。

部分国产手机（小米、OPPO、vivo 等）还会额外要求关闭「纯净模式」或加白名单，按系统提示放行一次即可。

## 四、安装失败对照表

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 解析包时出现问题 | 下载不完整 | 重新下载一次，核对 MD5 是否为 `3F96E5812D53777995466B0F3A57AC2C` |
| 签名冲突 / 无法覆盖安装 | 手机里已有不同来源的 Real Drum | 先卸载旧版再装；自定义套件与录音是本地数据，卸载前先确认要不要保留 |
| 存储空间不足 | 安装包加上解压空间不够 | 清出至少 1 GB 再装 |
| 一直转圈装不上 | 系统安装器被限制 | 重启手机再试；或改用系统自带文件管理器打开 APK |

## 五、核对 MD5 的方法

把 APK 传到电脑后，在 PowerShell 里执行（文件名以实际为准）：

```powershell
certutil -hashfile "RealDrum_v11.15.14.apk" MD5
```

输出第二行就是 MD5 值，与上表一致说明文件完整。手机端用带校验功能的文件管理器也能做同样核对。

装好之后先从[新手入门教程.md](新手入门教程.md)打出第一段节奏；装不上、装完闪退这类问题去[常见问题排查.md](常见问题排查.md)对表。
