## 一、遥控器基本操作

界面按大屏设计，全部功能遥控器都能完成：

| 操作 | 遥控器按键 |
| --- | --- |
| 在分类之间移动焦点 | 方向键上下左右 |
| 打开选中的影片 | OK 键 / 确认键 |
| 播放中暂停、继续 | OK 键或播放暂停键 |
| 快进、快退 | 左右方向键 |
| 调音量 | 音量键 |
| 返回上一级 | 返回键 |

选好剧集后按 OK 键即开始播，播放中可以随时用方向键拖动进度。

## 二、语音搜索

语音搜索是找内容最省事的方式，特别是找维吾尔语 MV 的时候——按歌手名或 MV 名说一句就能定位到。

用法：按住遥控器上的**语音键**（麦克风图标）说内容，松开后出结果。前提是电视或遥控器本身带语音功能，纯按键遥控器没有这个入口。支持按歌手名搜，也支持按影片名搜。

没有语音遥控器的话，除了搜索框手动输入，还可以走分类浏览：内容按**风格、场景、情感、主题**这几个维度组织（这也是官方推荐功能的分类口径），顺着分类点下去，不看名字搜也能找到想听的类型。首页的推荐位会按观看行为变化，看得越多推得越像你的口味。

## 三、收藏与最近播放

- **收藏**：看过的节目可以保存下来，下次从收藏列表直接进，不用再搜一遍。入口在影片详情页和「我的」区域里。
- **最近播放**：观看记录自动保留，没看完的剧集从「最近播放」里点开就能接着看。找「上次看到一半的那部剧」，先来这里。

这两处跟着账号走，换设备登录同一微信后记录还在。

## 四、离线下载

想把内容存下来在没有网络的时候看，可以提前缓存到本地：

1. 进入想保存的影片详情页，选「下载」。
2. 选清晰度，确认后开始缓存。
3. 缓存完成后，断网状态也能从已下载列表里点开看。

下载在 Wi-Fi 环境下进行比较稳妥；缓存占的是电视本机存储，空间紧张时优先删掉看完的缓存。

## 五、画质与语言切换

- **画质**：播放中可以切清晰度，网络好选高清，卡顿就降一档。下载缓存时同样要选一次清晰度。
- **语言**：界面和片源都支持中文、维吾尔语两种，在设置里切换。部分片源本身分语言版本，选片时注意封面对应的语种。

## 六、投屏

应用带投屏功能（官方产品页里叫「智能投放」），入口在播放界面或影片详情页里，具体位置以你手上的版本显示为准。投屏需要手机和电视处在同一网络下，从手机端发起。投屏不动或搜不到设备，优先查这两端是不是不在同一个网段——双路由、访客网络都会造成这种问题。

还有一点值得知道：开发方对投屏做过专项修复（手机端 iOS 版的更新日志里专门修过投屏功能）。两端都更新到较新版本再试，能排除掉一类「旧版本的已知毛病」。

播放、下载、投屏任何一环出问题，按 [播放加载失败怎么办.md](播放加载失败怎么办.md) 的对应小节排查。
