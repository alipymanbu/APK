# POEM 电脑版怎么用

> POEM 没有官方 Windows / macOS 版；想在电脑上读诗，要么走应用宝电脑版，要么自己用安卓模拟器装网盘里的 APK。本篇讲这两条路。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [注册登录与常见问题.md](注册登录与常见问题.md)

## 一、先确认：没有官方电脑版

POEM 是纯移动应用（Android / iOS），开发者没有发布过 Windows 或 macOS 版本。你在搜索时看到的「POEM 电脑版下载」，基本都是「安卓模拟器 + APK」的打包方案 —— 本质还是在电脑里跑一个安卓环境。

## 二、途径一：应用宝电脑版

腾讯应用宝给 POEM 的详情页自带了电脑版使用指引（应用宝电脑版内置 Android 13 运行环境）。步骤照抄如下：

1. 在电脑浏览器访问应用宝官网，下载应用宝电脑版安装程序并完成安装；
2. 打开应用宝电脑版，搜索「POEM」进入应用详情页；
3. 点详情页的「安装」按钮，等它下载并装好；
4. 打开 POEM 按提示使用；
5. 下次使用时，从桌面图标、系统栏或开始菜单里再启动。

这条路的优点是全程在应用宝渠道内完成，不用自己找安装包；缺点是先得装下应用宝这个壳，它的硬盘占用与常驻情况自己掂量。

## 三、途径二：模拟器 + 网盘 APK

1. 任选一个主流安卓模拟器，装到电脑上；
2. 从 [POEM 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b46766696a53) 把 APK 转存到自己的网盘，再下载到电脑；
3. 在模拟器里选「本地 APK 安装」，指向刚下载的 APK；
4. 装完打开 POEM。

装之前先核对 [下载与安装教程.md](下载与安装教程.md) 第一节的参数（版本 1.5.5、6.46MB、MD5）：对得上再用。各类下载站打包的「电脑版」通常动过包，MD5 对不上就不要装。POEM 本体只有 6.46MB、无广告，对模拟器性能几乎没有要求。

## 四、值不值得在电脑上读诗

POEM 的使用场景本来就是碎片时间一屏一诗，手机端基本够用；电脑端更适合「开着文档写东西、顺手读一首」的用法。收藏与账号在手机和模拟器之间是否通用，取决于你是否登录了同一账号，以应用内实际表现为准。
