# POEM 与西窗烛有什么区别

> 同一个开发者（西窗文化）做了两款诗词应用：POEM 主打现代诗、极简轻量；西窗烛主打古典诗词、大而全。本篇给对照表与选型建议。

## 一、先说结论

- 只想安静读现代诗、嫌应用臃肿 → 装 POEM；
- 要查唐诗宋词古文、要注释译文赏析、要社区与朗诵 → 装西窗烛；
- 两头都要 → 两个都装不冲突，加起来体积也不到 90MB。

## 二、对照表

| | POEM | 西窗烛 |
| --- | --- | --- |
| 内容定位 | 中外**现代**诗歌 | 中国**古典**诗词（唐诗宋词古文等） |
| 文库规模 | 600 位中外诗人作品（官方简介口径） | 约 100 万首诗词文库（官方简介口径） |
| 安卓包体积 | 6.46MB（1.5.5） | 约 80MB（7.6.x） |
| 功能形态 | 读诗、收藏、搜索、创作，一屏一诗 | 文库、朗诵、练字、话题社区、游戏、学习计划 |
| 账号与社区 | 无社区；账号环节轻（1.5.5 才涉及短信验证码） | 有社区与账号体系（话题、发布、朗诵作品） |

两边都是「无广告」取向，但形态完全不同：POEM 是把一件事做小（打开就读），西窗烛是把一个领域做全（文库加社区）。

## 三、同一个开发者

两款应用都出自北京西窗文化传媒有限公司（2016 年成立，北京）。POEM 的包名是 `com.xcz.modernpoem`，西窗烛的包名是 `com.hustzp.com.xichuangzhu`。同门还有几款：

- **诗词之美** —— 古典诗词的精简形态（无社区），带会员订阅（iOS 页面列明 6 元/月、50 元/年，价格以官方页面为准）；
- **给孩子的古诗词** —— 面向孩子的讲诵版；
- **汉字的故事**、**古书之美** —— 同一文化方向的其他应用。

所以「西窗烛系」不是一款应用，而是一组按人群与形态分工的诗词应用，POEM 负责的是现代诗这一格。

## 四、按场景选

- 每天睡前随手读一首现代诗 → POEM；
- 学生背课本古诗、查注释译文 → 西窗烛（有课本分类）；
- 想发自己的作品、找同好交流 → 西窗烛（有话题社区）；POEM 的创作更像「写下自己的诗」，没有社交层；
- 给孩子做诗词启蒙 → 看西窗烛或「给孩子的古诗词」。
