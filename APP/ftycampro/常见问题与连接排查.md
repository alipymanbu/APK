## 一、设备一直显示离线

App 列表里设备灰着，先分清是「App 连不上」还是「摄像头自己不在线」：

1. **摄像头供电**：电源松脱是最常见原因，机身指示灯全灭基本就是没供电；
2. **摄像头网络**：远程查看要求摄像头接入了路由器（网线或 WiFi）。路由器重启过、家里 WiFi 改过密码，摄像头都会掉线——改密码后不用重置，在 App 的设备设置（齿轮图标）→「Wi-Fi Setting」里选新 WiFi、填新密码即可；保存后设备会离线约一分钟再重新上线；
3. **手机网络**：手机自己断网或在弱信号区，画面同样出不来；
4. **近场验证**：拿手机直连摄像头热点（设备直连方式）能打开画面，说明设备没坏，问题出在它的联网环节；
5. **反复掉线救不回来**：恢复出厂再重配一遍，重置步骤见 [忘记密码与恢复出厂设置.md](忘记密码与恢复出厂设置.md)。

## 二、热点配网时搜不到设备热点

按这几条排：

- **确认进了热点模式**：按「Mode」键后机身指示灯应当慢闪；快闪或常亮都不是热点模式；
- **看 WLAN 列表**：找不到形如 `XXXnnnnnnYYYYY` 的热点，多半是设备没进模式或距离太远，把手机凑到设备一米内再刷新；
- **手机悄悄断开了热点**：有些手机会自动断开「连不上外网」的 WiFi——明明选了摄像头热点，回 App 时已经切回流量。重进 WLAN 列表手动再连一次，并留意是否弹过「此网络无法访问互联网，是否保持连接」的提示；
- **位置权限**：部分安卓版本不给 App 位置权限时，系统不返回周围 WiFi 列表，配网页面就点不到那个热点——到系统设置里把 FtyCamPro 的位置权限放开再试；
- **关掉移动数据**：有些手机在移动数据与设备热点并存时优先走流量，配网阶段先把流量关掉，成功后再开；
- **核对名字与密码**：WiFi 名称、密码填错一个字符都连不上；名称或密码里带中文、特殊符号的，说明书明确说不支持，先改成英文数字再配（5GHz 与公共认证路由同样不可用，见 [添加摄像头与配网步骤.md](添加摄像头与配网步骤.md) 的前提清单）。

## 三、指示灯状态对照

随机型说明书整理的状态表（不同型号灯位可能不同，以你的设备实物为准）：

| 灯的表现 | 通常含义 |
| --- | --- |
| 开机后蓝灯常亮 | 设备处于 AP（热点）模式待配网 |
| WiFi 指示灯每 0.5 秒慢闪一次 | 热点已就绪，可以配网 |
| 红灯常亮、蓝灯快闪 | 正在尝试连接路由器 |
| 蓝灯由快闪转为常亮 | 配网成功，已连上路由器 |
| 蓝灯一直快闪不转常亮 | 多半是 WiFi 密码填错了 |
| 红灯亮起、充满后熄灭 | USB 供电状态 |
| 绿灯亮起、充满后自动熄灭 | 电池充电中 |

连不上时先看灯：蓝灯快闪卡着不动，就回「Wi-Fi Setting」重填密码；灯全灭，先解决供电。

## 四、设备 ID 或二维码标签丢了

设备 ID、默认密码与二维码一般只印在机身标签和包装上。有用户反馈标签丢失后无法添加设备。两个方向补救：

- 翻购买订单，联系卖家确认设备信息；
- 设备还能近场连上时（热点直连），先在 App 的设备信息页把 ID 抄下来存好。

别把这件事拖到设备重置之后——重置后要重新添加，全靠这些信息。

## 五、回放里找不到录像

录像存在设备的存储卡里，App 只是去读。看不到录像按这个顺序查：

1. **存储卡状态**：在 App 的 SD 卡管理入口看卡是否被识别、剩余容量多少；
2. **卡有没有插好、兼不兼容**：卡没插紧、容量超出设备支持范围或卡不兼容时，设备根本没在录；
3. **录像计划**：定时录像要有对应时段的计划，报警录像要等触发——当天没触发就没有这段；
4. **回放日期**：回放按日期选，确认选的是实际有录像的那天。

## 六、画面卡顿或花屏

- 在预览界面把**码流/分辨率**调低一档，远程看时最立竿见影；
- 摄像头用 WiFi 联网时，隔两堵墙就会明显掉帧，把设备挪近路由器或改用网线；
- 夜视（红外灯）开启时画面是黑白的、噪点偏多，这是红外成像的特性，不是故障。

排到这里还没解决，多半与具体设备型号有关：先确认 App 版本不是太旧（版本核对方法见 [下载与安装教程.md](下载与安装教程.md)），再到购买渠道问设备侧的支持。
