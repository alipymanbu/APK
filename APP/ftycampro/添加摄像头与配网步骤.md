## 一、先选对添加方式

三种方式的差别在「摄像头现在处于什么网络」：手边有设备、还没联网的，走热点直连或蓝牙；设备已经接上路由器、或者你正与它处在同一网络里的，走在线添加。对照着选：

| 方式 | 适用场景 | 前提 |
| --- | --- | --- |
| 设备直连（AP 热点） | 新设备首次配置，人就在设备旁边 | 摄像头能开机、能进热点模式 |
| 蓝牙配网 | 设备硬件带蓝牙时 | 较新款摄像头 |
| 在线添加 | 设备已联网，或与手机同一网络 | 知道设备 ID，或能扫到设备二维码 |

应用内的「设备直连」页自带四步操作指南（设备上电 → 热点模式 → 连接热点 → 自动绑定），下面按这个顺序走。

## 二、方式一：设备直连（热点配网）

这是新摄像头最常用的第一次配置路径：

1. **设备上电**：轻触设备机身的「On/Off」按键开机；
2. **切到热点模式**：新开箱的设备按「Mode」键切到 AP（热点）模式，此时机身指示灯慢闪——慢闪就是在提示热点已就绪；
3. **连接热点**：回到 App 的设备直连页，点「前往 WiFi 设置，连接设备热点」，系统跳到 WLAN 列表后，选择摄像头发出的热点（名称形如 `XXXnnnnnnYYYYY`）；
4. **自动绑定**：手机状态栏出现这个热点后切回 FtyCamPro，设备会被自动添加，App 直接跳到监控画面。

整个过程不需要输入摄像头密码；配网这一次做完，设备就长期留在你的列表里了。

动手前先确认路由器这一侧的三个硬前提，不少「配不上网」在开机前就已经注定了：

- 摄像头**不支持 5GHz WiFi**，只连得上 2.4GHz——家里是双频路由时，选名字不带 5G 的那个频段；
- **WiFi 名称与密码目前不支持中文和特殊符号**，说明书里写明只认英文与数字，名称带中文的路由要先改掉再配；
- **需要网页登录认证的公共路由**接不了（酒店、商铺的 WiFi 多是这种），给设备用的是家用路由。

## 三、方式二：蓝牙配网

摄像头硬件带蓝牙时，添加页里会出现蓝牙连接入口，选中后按提示走即可。蓝牙在这里承担的是「手机与设备交换 WiFi 信息」这一步：摄像头拿到家里 WiFi 的名称和密码后自己联网上线，不再依赖手机直连它的热点。

添加页里没有蓝牙入口，就说明这台硬件不支持，退回方式一或方式三。

## 四、方式三：在线添加

设备已经联网（比如接进了路由器）时走这路，具体有三个入口：

- **自动搜索**：手机连到与摄像头相同的网络，App 在该网络里搜索在线设备；
- **扫二维码**：扫机身或包装上的设备二维码；
- **手动输入**：把设备 ID 与密码逐项填进去。

手动输入会遇到 **P2P 密码**这一项：随机型说明书，默认值是 `admin`，但也有资料写「用户名 camera0、密码重置后随机」——两种口径并存，以你机身标签为准；默认值改法与对不上时的处理见 [忘记密码与恢复出厂设置.md](忘记密码与恢复出厂设置.md)。设备配置完成后建议尽快改掉默认密码。

设备 ID 与二维码通常印在机身标签或包装盒上。有用户反馈标签丢失后既找不到 ID 也对不上默认密码，添加就很被动——所以机身标签和包装值得留好。

## 五、添加不上时往哪查

三个方向按顺序排：机身指示灯的状态（有没有进入慢闪的热点模式）、手机 WLAN 列表里有没有设备热点、App 的位置权限给了没有（部分安卓版本不给位置权限就拿不到周围 WiFi 列表）。逐条排不动，直接看 [常见问题与连接排查.md](常见问题与连接排查.md)，那里按故障现象分类。
