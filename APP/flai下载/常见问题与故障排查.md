## 一、打开卡在绿屏 / 启动页不动

有用户反馈的处理办法，按顺序试：

1. **先等一等**：确认手上的 FLAI 是最新版本后，启动页多等一会儿 —— 有反馈说这样通常就能进去。
2. **换个网络环境**：有反馈指出一直打不开与所在网络环境有关 —— 从 Wi-Fi 切到移动数据（或反过来）再试。
3. **清缓存重启**：长按图标进入应用信息 → 存储占用 → 清理缓存（注意是缓存，不是「清除数据」—— 清数据会把本地记录抹掉），然后重新打开。
4. 仍不行就卸载重装（先确认账号能登回去，聊天记录存在账号里，本地主要是缓存）。

## 二、应用登不进去 / 用不了

- **是否在停机维护**：有资料显示，FLAI 阶段性会出现停机维护，期间谁都登不进 —— 过段时间再试，或留意官方渠道公告。
- **版本太低**：版本过旧会直接导致无法正常使用，先升到最新版再试（安装与升级见 [下载与安装教程.md](下载与安装教程.md)）。
- **邮箱或密码错**：账号是邮箱 + 密码，确认没把注册邮箱拼错；密码不对就走找回流程，用注册邮箱收重置邮件。

## 三、注册收不到验证邮件

1. 先翻邮箱的 **垃圾邮件 / 垃圾箱 / 推广** 文件夹 —— 验证邮件被归类进去是最常见原因。
2. 核对邮箱地址有没有拼错，错了就重新注册一次。
3. 等待一两分钟后点重新发送，别连续高频点获取（部分平台有频率限制，反复点反而触发限制）。
4. 换个邮箱试：国内常见邮箱服务对海外发信的拦截程度不同，QQ/163 收不到时，换个邮箱往往直接解决。
5. 都不行，可能是服务端异常，稍后再试或联系官方客服。

## 四、闪退 / 无响应

按厂商官方支持文档给的通用顺序排查即可：

1. **重启应用**：清掉后台再重新打开。
2. **清缓存**：应用信息 → 存储占用 → 清缓存；「清除数据」会删本地数据，放在后面一步再用。
3. **检查权限**：设置 → 应用管理 → 找到 FLAI → 应用权限，把存储、网络等必要权限打开。
4. **切网络**：Wi-Fi 与移动数据互换一次，排除网络栈问题。
5. **升级 / 重装**：确认已是最新版；仍闪退就卸载后重新安装最新包。
6. **看剩余空间**：手机可用存储不足也会让应用无响应，清出一定余量再试。

若闪退发生在某次升级之后，可回退思路：先清数据再开，仍复现就等下一个版本修复，或换一台设备交叉验证是不是机型兼容问题。

## 五、AI 回复发一半就断 / AI 替你说话

这不是故障，是人设写法问题，去 [人设编辑与模板使用技巧.md](人设编辑与模板使用技巧.md) 改：删掉人设里「大量描写、详细描写」这类规则句，开场白不要分段换行；AI 替你发言则检查人设是否让它扮演了世界/系统这类全知角色。

## 六、对话生图等很久

有用户反馈（Google Play 评论区）：FLAI 会根据对话内容生成图片，但生成速度不稳定、期间没有取消按钮，描述得再细也可能不如预期。现状下你的选择是：等它出图，或换话题绕开触发；官方未提供取消入口的话，只能退出该次生成等待。这是功能现状而非你的操作问题，以官方后续版本为准。

## 七、充值后资产没到账

1. 先核对自己登的是不是充值时那个账号（邮箱拼写最容易差一个字母）。
2. 到「我的 → 订阅 / 钻石」看余额与记录，截图留存。
3. 点数卡类储值有延迟的可能，稍等再刷新；确认支付已成功却长期不到账，带着订单截图联系官方客服。
4. 具体路径与注意事项见 [会员订阅与充值说明.md](会员订阅与充值说明.md)。

## 八、官网打不开

官方中文站是 [getflai.cn](https://www.getflai.cn)。有用户反馈用 Edge 浏览器打开成功率更高；若换了浏览器仍打不开，多半与网络环境有关，换个网络再试。官网只是查版本、公告的入口 —— 安装包本身走 [下载与安装教程.md](下载与安装教程.md) 里的网盘地址即可，不依赖官网在线。

顺带提醒：搜「FLAI 官网」时你会遇到好几个域名（如 [getflai.cn](https://www.getflai.cn)、[flaiweb.cn](https://flaiweb.cn/) 等，其他资料还提到过别的入口），**它们是否都属官方无法从外部核实** —— 本篇以自述为官方下载入口、且与应用包名对应的 `getflai.cn` 为准；无论打开哪个站，下载动作仍以核对过包名的安装包为准，别在陌生页面上登录你的账号。

## 九、换手机、清数据导致的「记录不见了」

先看 [换手机与数据同步说明.md](换手机与数据同步说明.md)：确认登的是注册邮箱、核对同步状态，多数「记录消失」是登错了账号或新设备状态尚未同步，不是数据真丢了。
