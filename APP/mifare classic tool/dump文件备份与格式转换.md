## 一、为什么备份这件事在 MCT 里特别重要

MCT 的 dump 和密钥文件都放在应用私有目录，**卸载即清空**，换机、重装、恢复出厂都会带走全部数据。备份的入口只有一条：主菜单 → Tools → Import/Export/Convert Files，把文件导出到手机公共目录，再从文件管理器复制到电脑或网盘。

## 二、四种格式分别是什么

导出和导入时 MCT 支持下面几种格式（以官方帮助页 Help & Info 的 Import/Export 一节为准）：

| 格式 | 是什么 | 适合什么场合 |
| --- | --- | --- |
| `.mct` | MCT 自家的文本格式，文件里按 `+Sector: 0` 这样的行分扇区 | 用 MCT 互传；想用文本编辑器直接看内容 |
| `.keys` | MCT 的密钥文件格式 | 备份你整理的密钥清单 |
| `.bin` / `.mfd` / `.dump` | 原始字节流格式，Proxmark、libnfc、mfoc 等电脑端工具通用 | 拿到电脑上用其他分析工具处理 |
| `.eml` | 每行一个块的文本格式（Proxmark 模拟器使用的格式） | 与 Proxmark 类工具交换数据 |
| `.json` | JSON 格式（Proxmark、Chameleon Mini GUI 使用） | 与这些硬件工具配合时用 |

三份密钥文件（std.keys 等）的改动不会被保留，你自己建的密钥文件同样要导出备份——重读一张卡时，密钥文件丢了就得重新整理。

## 三、换手机的标准流程

1. 旧手机：Export 所有 dump 与自建密钥文件（格式选 `.mct` 最省事，MCT 自己认）；
2. 把导出的文件复制到电脑或网盘中转；
3. 新手机装好 MCT（安装步骤见[下载与安装教程](下载与安装教程.md)）；
4. Import 导入，之后在 Edit/Analyze Tag Dump File 里就能看到原来的 dump，不需要重新读卡。

## 四、电脑上怎么看 dump

`.mct` 和 `.eml` 都是纯文本，记事本、VS Code 直接打开就能看十六进制内容；`.bin`/`.mfd` 是二进制，需要十六进制编辑器或专门的工具读。只是在手机上整理数据的话，不用碰电脑——MCT 内置的编辑、对比、解码工具已经够用（见[内置工具用法一览](内置工具用法一览.md)），读出来的数据怎么分析见[读取卡片数据教程](读取卡片数据教程.md)。
