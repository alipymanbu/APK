## 一、先弄明白：为什么不能直接读

MIFARE Classic 卡的每个扇区都被两组 6 字节密钥（A 钥与 B 钥）保护着，手机贴上去不会自动吐数据。MCT 的做法是：**把你已有的密钥整理成清单（密钥文件），逐个拿去和每个扇区比对**，哪把钥匙对得上就读哪个扇区。清单里没有的扇区它读不了，也不会帮你推算出来。

所以读卡前先回答一个问题：这张卡的密钥你手里有没有？常见来源：

- 大量卡片出厂用的是公开的默认密钥（如 `FFFFFFFFFFFF`），MCT 自带的密钥文件里已经收了这类常见值；
- 卡是自己单位发行的，发行方把密钥交给了你；
- 同一套系统的卡你之前读过，密钥通用。

## 二、认识密钥文件

MCT 自带三份：

| 文件 | 内容 |
| --- | --- |
| std.keys | 最常见的默认密钥 |
| extended-std.keys | 更多公开已知的密钥 |
| hotel-std.keys | 酒店卡系统的常见密钥 |

这三份自带的文件改动不会被保留，**自己的密钥要新建文件存**：

1. 主菜单 → Edit or Add Key File；
2. 新建一个密钥文件；
3. 逐条添加密钥：每条 6 字节密钥写成 12 位十六进制（如 `A0A1A2A3A4A5`）；
4. 保存。

密钥文件支持导入导出——在电脑上把密钥整理成一行一条的文本再导进来也可以。

## 三、Read Tag 读卡步骤

1. 主菜单 → Read Tag；
2. 勾选要用的密钥文件（第一次可以先全勾上）；
3. 可选：指定扇区范围。1K 卡共 16 个扇区（0~15），只想看某几个扇区就限定范围，映射明显更快；
4. 点 Start Mapping，把卡贴在手机背面 NFC 天线位置；
5. 等映射跑完。每把钥匙都要对每个扇区试一遍，密钥文件越大越慢，几十秒到几分钟都正常；
6. 成功后进入十六进制编辑界面，读得动的扇区会显示数据。

**贴卡要点**：映射过程中手机一挪开就会中断。天线位置一般在摄像头下方到手机背部中段这一带，找不到就在背面慢慢滑。

## 四、看懂读出来的数据

- 界面里全是十六进制是常态，MCT 没有「把卡内容翻译成人话」的功能。想看文本切 ASCII 视图，想看数值块用 Value Block 解码（见[内置工具用法一览](内置工具用法一览.md)）；
- 读不出来的扇区没有数据——多半是密钥不在清单里，拿到新密钥加进自己的密钥文件重读即可；
- 每个扇区最后一行是尾块（trailer），里面的访问条件决定这个扇区哪些块能读能写，直接看权限字节看不懂就用 Access Condition 解码工具转成表；
- 读完记得 Save 存成 dump 文件。之后从主菜单 Edit/Analyze Tag Dump File 随时打开分析，不用再贴一次卡；dump 的备份与格式说明见[dump文件备份与格式转换](dump文件备份与格式转换.md)。

## 五、读出来之后能干什么

- 原地分析：ASCII 查看、访问条件解码、值块换算、两份 dump 对比；
- 把数据写到另一张卡上：流程在[写入与克隆卡片方法](写入与克隆卡片方法.md)；
- 拿不准手里这张是不是 MIFARE Classic 卡：先用 Tools 里的 Display Tag Info 看卡片类型与容量，MIFARE Classic 1K 最常见（16 扇区），4K 卡是 40 扇区。
