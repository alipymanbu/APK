## 一、先分清「不兼容」的两层原因

1. **手机不支持**：一部分手机的 NFC 控制器根本不支持 MIFARE Classic 协议。这类机型 App 一切正常，就是贴卡永远没反应或直接提示不支持——这个限制在硬件上，软件解决不了。
2. **卡读不全**：手机没问题，但部分扇区读不出来——那是密钥不在你的密钥文件里，属于正常现象，见[读取卡片数据教程](读取卡片数据教程.md)的密钥部分。

## 三、常见问题排查表

| 现象 | 原因与处理 |
| --- | --- |
| 贴卡 App 完全没反应 | NFC 没开；或贴的位置不对（手机背面上半部找天线区）；或这张卡不是 13.56 MHz 频段的卡（125 kHz 的低频卡手机读不了） |
| 提示不支持 MIFARE Classic | 手机的 NFC 控制器不支持该协议，对照第二节名单 |
| Read Tag 跑完全是空扇区 | 密钥文件里没有这张卡的密钥；先把自带的几份密钥文件全勾上再试，仍不行就得从发卡方拿密钥 |
| 只有部分扇区读得出 | 正常现象。哪个扇区的密钥你有就能读哪个；拿到新密钥加进自建密钥文件重读 |
| 写入总是失败 | 用来写的密钥没有写权限——先解码访问条件确认写权限在哪把钥匙上；或该块本身不允许写 |
| 数据看起来是乱码 | 卡里存的本来就是十六进制原始数据；切 ASCII 视图看文本、用值块解码看数值 |
| 重装或卸载后 dump 全没了 | MCT 的数据存在应用私有目录，卸载即清空。重装前用 Import/Export 导出（见[内置工具用法一览](内置工具用法一览.md)） |
| 映射过程特别慢 | 密钥文件太大，每个扇区都要挨个试；限定扇区范围能明显提速 |
| 想把门禁卡「刷进手机」里用 | MCT 没有卡片模拟功能，装它达不到这个目的；可行途径与判断方法见[手机模拟门禁卡误区](手机模拟门禁卡误区.md) |

## 四、它做不了的事

三条边界，免得在里面浪费时间：

- **不能推算密钥**：MCT 只逐条尝试你密钥文件里已有的值，没有任何推算或恢复未知密钥的能力；
- **没有图形化的「写网址 / 写名片」界面**：所有写入都是原始十六进制，想要易用的写标签体验得换别的 NFC 应用；
- **只认 MIFARE Classic**：Ultralight、NTAG 这类卡不归它管。
