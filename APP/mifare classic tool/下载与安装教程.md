## 一、装之前先确认三件事

1. **手机有 NFC**：MCT 只做一件事——通过 NFC 与 MIFARE Classic 卡片通信。设置里搜「NFC」，找不到开关的机型基本可以直接放弃（部分机型的开关藏在「连接与共享」之类的二级菜单里）。
2. **系统版本**：官方渠道对 4.3.1 版的要求是安卓 4.4 及以上。本文对应的安装文件正是 4.3.1 版。
3. **机型不在不兼容名单里**：一部分手机的 NFC 硬件天生不支持 MIFARE Classic 协议，装了也读不到卡。装之前先翻一下[不兼容设备与常见问题](不兼容设备与常见问题.md)里的官方名单，省得白装一次。

## 二、安装文件信息

安装文件从「MIFARE Classic Tool 安装文件资源（夸克网盘）」获取，转存后把 apk 下到手机就能装。这份包的关键信息如下：

| 项目 | 值 |
| --- | --- |
| 版本 | 4.3.1 |
| 包名 | de.syss.MifareClassicTool |
| 大小 | 3.85 MB |
| MD5 | D9ECBE8A2DEDC4EA3EA9ED47E2338A8F |

MCT 是开源软件（GPLv3），官方发布渠道有三个：[Google Play](https://play.google.com/store/apps/details?id=de.syss.MifareClassicTool)、[F-Droid](https://f-droid.org/en/packages/de.syss.MifareClassicTool/) 与官网直装包页面（[icaria.de/mct](https://www.icaria.de/mct/)）。官方渠道的版本号可能已经高于 4.3.1，功能差异以官方更新日志为准。

## 三、安装步骤

1. 从网盘资源转存并下载 apk 文件到手机。
2. 点开 apk。第一次安装会弹「未知来源」提示：各品牌入口叫法不同，但动作都一样——在「设置 → 安全 / 更多设置 → 安装未知应用」里，给文件管理器或浏览器勾上「允许从此来源安装」。
3. 装完打开。MCT 只申请 NFC 一项权限，不联网、无账号体系、没有引导流程，进来就是主菜单。

## 四、第一次打开：主菜单怎么认

主菜单六个入口，各自管什么：

| 入口 | 用途 |
| --- | --- |
| Read Tag | 读卡（配合密钥文件） |
| Write Tag | 写卡、克隆、恢复出厂 |
| Edit/Analyze Tag Dump File | 打开已保存的 dump 数据查看、编辑 |
| Edit or Add Key File | 管理密钥文件 |
| Tools | 十来个小工具（BCC 计算、权限解码等） |
| Help & Info | 应用内离线帮助手册（英文），内容与官网一致 |

界面的语言跟随手机系统：中文系统下菜单显示为「读标签」「写标签」这类中文，与本文用的英文菜单一一对应。

**一个必须提前知道的坑**：MCT 的 dump 与密钥文件都存在应用私有目录里，**卸载 MCT 会把这些文件全部清掉**，重装救不回来。换机或重装前，先把数据导出备份（完整流程见[dump文件备份与格式转换](dump文件备份与格式转换.md)）。

装完第一步建议拿一张卡把读卡流程走一遍：见[读取卡片数据教程](读取卡片数据教程.md)。另外，如果你装它是为了「把门禁卡刷进手机」，先看一眼[手机模拟门禁卡误区](手机模拟门禁卡误区.md)——MCT 做不到这件事，别白折腾。
