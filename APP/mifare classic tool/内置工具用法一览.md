## 一、Tools 里的工具对照表

主菜单 → Tools：

| 工具 | 干什么 | 什么时候用 |
| --- | --- | --- |
| Display Tag Info | 显示卡的 UID、SAK、ATQA、容量、扇区/块数 | 拿到一张卡先看它是什么类型、多大 |
| BCC Calculator | 算 UID 前 4 字节的异或校验值（块 0 第 5 字节） | 在 CUID 卡上手写块 0 时核对校验位 |
| Access Condition Decoder/Encoder | 权限字节与逐块权限表互转 | 判断某块能不能读写、归哪把钥匙管 |
| Value Block Decoder/Encoder | 值块原始字节与整数互转 | 卡里存的是余额型值块时换算着看 |
| Diff Tool | 两份 dump 逐块对比，标出差异 | 对比改卡前后的变化 |
| Clone UID | 把一张卡的 UID 写到另一张 CUID/gen2 卡 | 只想换 UID、不搬数据 |
| Data Conversion | 十六进制 ↔ ASCII、字节序转换等 | 看懂块里的文本内容 |
| UID Log | 记录贴过的卡的 UID | 做登记用 |
| Import/Export/Convert Files | 数据进出 MCT、dump 格式转换 | 备份、跨设备搬家 |

## 二、Import/Export：备份与搬家的唯一通道

MCT 的 dump 与密钥文件都在应用私有目录里，**卸载即清空**，所以换机、重装、刷机之前：

1. Tools → Import/Export/Convert Files；
2. 把需要的 dump 和密钥文件导出到手机公共目录，再复制到电脑或其他存储；
3. 装回后从同一入口导入。

导出时可以顺带转格式：dump 支持 JSON、BIN/MFD、EML、MCT 四种格式互转——每种格式分别适合什么场合见[dump文件备份与格式转换](dump文件备份与格式转换.md)。想在电脑上用其他分析工具选 BIN/MFD；想用文本编辑器直接看选 EML。

## 三、两个最常被忽略的小工具

**Access Condition 解码**最值得先学会。每个扇区尾块里那几字节权限位直接看是天书，解码成表格后一眼能看出：这个扇区的哪一块能读、能写、靠 A 钥还是 B 钥。写入失败时先来这里查权限，比反复换密钥试省时间。

**Display Tag Info** 是判断卡类型的入口。1K 卡 16 扇区、4K 卡 40 扇区、Mini 卡 5 扇区；如果显示的类型根本不是 MIFARE Classic，后面所有读写操作都不适用，排查思路见[不兼容设备与常见问题](不兼容设备与常见问题.md)。

## 四、外接读卡器

手机没有 NFC、或 NFC 行为被系统限制时，MCT 支持通过外接读卡器（如 ACR 122U 这类）操作卡片，接法在应用内 Help & Info 的 External NFC 一节有说明。配合它读卡、写卡的流程与内置 NFC 一致：先备密钥文件再动手，参见[读取卡片数据教程](读取卡片数据教程.md)与[写入与克隆卡片方法](写入与克隆卡片方法.md)。
