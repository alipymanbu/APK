## 一、先记住一条主逻辑：按你的屏幕筛图

Wallcraft 会识别设备的屏幕分辨率与机型，浏览时只给你看尺寸匹配的那部分图，你不会在列表里遇到「下载回来填不满屏幕」的图。常见档位对应关系如下：

| 档位 | 典型像素 | 适合的设备 |
| --- | --- | --- |
| HD | 720x1280 | 入门机型、旧手机 |
| 全高清 Full HD | 1080x1920 | 目前大多数主流手机 |
| 2K QHD | 1440x2560 | 各家旗舰机 |
| 4K UHD | 2160x3840 | 支持 4K 屏的新旗舰 |
| 6K / 8K | 更高 | 专属内容，需订阅与金币（见 [免费版与PRO区别.md](免费版与PRO区别.md)） |

两个由此带来的实际好处：列表加载更快（不传输用不上的大图），也更省流量与电。每张壁纸都经过人工裁剪处理，设置时一般不需要你再手动调整裁剪框。

## 二、七种壁纸形态，差别在哪

首页里同一张图可能标着不同类型标签，它们的含义与适用场景如下：

| 类型 | 表现 | 适合场景 |
| --- | --- | --- |
| 静态 | 普通图片 | 追求省电、省流量 |
| 3D | CG 渲染的立体感图片 | 喜欢立体视觉效果，但仍是一张静态图 |
| 视差（Parallax / 4D） | 随手机倾斜或滑动时产生位移景深 | 想要「动」的感觉又不想耗太多电 |
| Live 动态 | 持续播放的动态效果 | 锁屏展示，耗电高于视差 |
| 视频 | 以视频形式播放 | 短循环场景、氛围感强，最耗资源 |
| Double | 锁屏与主屏两张图成对设计 | 想要解锁前后画面衔接统一 |
| 24h | 随一天时间变化呈现不同画面 | 喜欢早晚屏幕有差异的玩法 |

选择建议按「耗电从低到高」排序就是：静态 / 3D → 视差 → Live → 视频。给主力机当日常壁纸，静态或视差是稳妥的选择；Live 与视频更适合锁屏或短期换着玩。动态类型的耗电来源与省电设置另有一篇细讲，见 [动态壁纸与耗电控制.md](动态壁纸与耗电控制.md)。

两个类型上的冷知识，选图时用得上：

- **视差图吃传感器**：4D 效果依赖陀螺仪，个别关掉传感器或皮套模式的机型上效果会打折，图不动了先查系统传感器设置；
- **Double 与 24h 是「组合型」内容**：Double 是成对的两张静态图，24h 是按时间段切换的一组图，它们不需要持续渲染，耗电特征接近静态图，却比单张静态图更有变化。

## 三、分类与筛选怎么用

找图的入口主要靠这几层：

- **分类浏览**：3D、抽象、动物、动漫、艺术、汽车、城市、暗色 / 黑色、幻想、食物、女孩、节日、爱情、微距、男性、极简、音乐、自然、新年 / 圣诞、太空、运动、科技、纹理、矢量、视频壁纸、文字 / 引言等。
- **排序筛选**：列表里有热门（Popular）、最新（New）、随机（Random）、畅销（Best-sellers）几种过滤方式，切换就能换一批。
- **搜索**：顶部搜索框支持按关键词找图，搜不到想要的主题时换个英文关键词往往比中文更准（库里的标签以英文为主）。

新图更新很勤：官方口径是每小时都有新壁纸上架，所以隔几天再进同一分类，内容经常不一样。

## 四、下载与设置一张壁纸的完整动作

1. 点开任意一张图进入预览，先看全屏效果。
2. 预览页里选「下载 / 设置」，部分图会给出多档画质供选（档位越高文件越大），选与你屏幕匹配的那档即可。
3. 选择作用位置：主屏、锁屏，或两张都设。
4. 回桌面看效果；不满意就换下一张。免费图本身不额外花钱，但部分下载动作会伴随广告，机制见 [免费版与PRO区别.md](免费版与PRO区别.md)。

成对设计的 Double 图下载时会把锁屏与主屏两张一起拿到，需要分别设到对应位置。

## 五、壁纸的另一种用法：聊天背景与键盘背景

从应用里下载的图不只能当系统壁纸。按官方说明，你可以把下载的壁纸图片设成聊天工具的对话背景（如 WhatsApp、Telegram、Snapchat 等支持自定义背景的应用），也能用作键盘背景。操作路径都是通用的：图先下载到相册，再去对应应用里选这张图当背景——聊天应用侧的设置入口在各家自己的「聊天背景 / 壁纸」选项里。

对这类用途，选图时反过来考虑可读性：消息气泡叠在图上，画面太花会影响文字辨认，浅色或低对比度的图当聊天背景比高对比大场景图更实用。

## 六、配合自动更换使用

单张设置熟悉之后，更省心的用法是开定时更换：让 Wallcraft 从你的收藏或某个分类里按间隔自动换图，不用每天手动挑。具体设置步骤与间隔档位见 [自动换壁纸设置.md](自动换壁纸设置.md)。还没装应用的话，先看 [下载与安装教程.md](下载与安装教程.md)。
