## 一、安装前先了解这份包

Wallcraft 是一款安卓壁纸应用，主要用途是从壁纸库里挑图并设成主屏或锁屏壁纸，支持静态、3D、视差、动态、视频等多种形态。安装之前建议先核对下面这份安装包信息，确认与你手里那份一致：

| 项目 | 数值 |
| --- | --- |
| 安装包版本 | 3.57.03 |
| 安装包大小 | 63.24 MB |
| 包名 | com.wallpaperscraft.wallpaper |
| MD5 校验值 | 86028D1C76EC0CB1313495F24464A088 |
| 对应平台 | Android |

几点说明：

- 这是 2026-09 收入网盘资源的版本；官方商店在架版本更新很快（截至 2026 年 9 月已到 3.66.0），功能细节可能与本包略有差异，以你实际打开的界面为准。
- 商店在架的新版本最低系统要求为 Android 8.0（以商店页面显示为准）；旧一些的机型如果装不了最新版，可以先用这份 3.57.03。
- 想先弄清各版本免费与付费的差别，可以看 [免费版与PRO区别.md](免费版与PRO区别.md)。

## 二、从网盘拿到安装包

这份安装包放在夸克网盘里，按下面步骤取：

1. 打开 [Wallcraft 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b51c94f84ccc)。
2. 选择「转存」把文件存到自己网盘（也可以先保存再下载，避免分享链接失效后拿不到）。
3. 手机上装好夸克网盘客户端，登录同一账号，找到刚才转存的 `Wallcraft_v3.57.03.apk` 下载到手机存储。
4. 下载完成后直接在通知栏或「下载」列表里点它即可进入安装；也可以先用文件管理器核对文件大小是否约 63.24 MB。

## 三、开启「安装未知应用」权限

从网盘下载 APK 属于商店外安装，安卓会默认拦下。以 Android 8.0 及以上的系统为例：

1. 手机「设置」→「应用管理 / 应用」→ 右上角菜单里的「特殊访问权限」。
2. 找到「安装未知应用」（部分系统叫「安装其他应用」）。
3. 在列表里找到**你用来下载和打开 APK 的那个应用**（夸克网盘或文件管理器），打开它的「允许安装未知应用」开关。
4. 装完后建议把开关关回去，保持系统默认的拦截状态。

不同品牌系统（MIUI、ColorOS、OriginOS 等）的菜单位置略有出入，找不到时直接在系统设置里搜「未知」两个字最快。

## 四、安装步骤

1. 点开下载好的 `Wallcraft_v3.57.03.apk`。
2. 弹出安装确认页时点「安装」，等进度条走完。
3. 出现「应用已安装」后选择「打开」直接进入，或先点「完成」回到桌面再从图标进。
4. 如果系统提示「此应用未适配最新安卓版本」之类的兼容性提醒，仍可选择继续安装，装完能正常启动即可；装完闪退就说明系统兼容不满足，换更新的版本或更新系统。

## 五、首次启动流程

第一次打开 Wallcraft 大致会经过这几步，照着界面走就行：

1. **选择年龄段**：应用启动时会询问年龄段，用来过滤不适合未成年人的壁纸内容，如实选择即可。
2. **兴趣与引导页**：可能让你勾选喜欢的壁纸风格（如动漫、风景、暗色等），这些会决定首页推荐内容，之后也能改。
3. **权限请求**：设置壁纸本身不需要额外授权；如果用到保存图片、下载等功能，按需允许「照片和视频 / 存储」权限即可。
4. **进入首页**：首页按「热门 / 最新 / 随机」等入口展示壁纸，点开任何一张都能预览并设置。

首次启动后建议先做两件事：把喜欢的一两张图设为壁纸试试效果（操作见 [壁纸类型与分辨率适配.md](壁纸类型与分辨率适配.md)），再决定要不要开自动更换（见 [自动换壁纸设置.md](自动换壁纸设置.md)）。

## 六、装不上或启动不了时的处理

按出现顺序排查：

| 现象 | 处理 |
| --- | --- |
| 提示「无法安装 / 解析包出现问题」 | 先确认下载是否完整（文件约 63.24 MB），不完整就重新从网盘下载一次 |
| 提示「存储空间不足」 | 清出至少安装包体积两倍以上的空闲空间再装 |
| 安装按钮置灰、提示被拦截 | 回到「安装未知应用」里，确认给下载来源应用开了允许（见第三节） |
| 装完打开就闪退 | 多为系统版本过旧或与该包不兼容，尝试更新系统，或改用商店里适配你系统的版本 |
| 下载速度很慢 | 网盘高峰期限速较常见，换个时段再下 |

装好之后如果对壁纸类型、清晰度怎么选有疑问，先看 [壁纸类型与分辨率适配.md](壁纸类型与分辨率适配.md)；想了解免费版能用哪些功能、要不要上 PRO，看 [免费版与PRO区别.md](免费版与PRO区别.md)；用起来碰到设置变黑、下载失败这类问题，看 [常见问题排查.md](常见问题排查.md)。
