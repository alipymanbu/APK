## 一、先说结论

注销入口在应用内，官方隐私政策（2025-08-26 更新）写了明确路径与处理时限，不用绕客服。但注销是**不可逆**的——动手前先把自动续费关掉（见 [BUFF会员价格与自动续费取消.md](BUFF会员价格与自动续费取消.md)），否则账号没了、扣款还可能继续。

## 二、注销账号的具体路径

按官方隐私政策公示的流程：

1. 进「我的」→「设置」→「安全设置」→「注销帐号」；
2. 提交前平台会**验证你的个人身份、安全状态、设备信息**——收不到验证短信或换了手机号，先按 [常见问题与客服联系方式.md](常见问题与客服联系方式.md) 把登录问题解决了再销号；
3. 提交后平台在 **15 个工作日**（或法律要求的时限）内回复你的请求；
4. 确认注销后**不可逆**：与你账号相关的信息会被删除或匿名化，账号与历史数据无法恢复。

注销前的检查清单：

- [ ] 自动续费已关（最重要，路径见 [BUFF会员价格与自动续费取消.md](BUFF会员价格与自动续费取消.md)）；
- [ ] 记下注册手机号——后续想确认处理结果，客服要靠它定位账号；
- [ ] 想留的聊天内容提前留——注销后按政策口径会被删除或匿名化；
- [ ] 有未消费的会员时长，先发邮件问清折算规则再动手（联系方式见 [常见问题与客服联系方式.md](常见问题与客服联系方式.md)）。

## 三、隐私设置：谁能看我、谁能私信我

不注销、只想少被打扰时，用这几项（按公开教程整理，具体选项名以应用内为准）：

| 想达到的效果 | 去哪调 |
| --- | --- |
| 不想让主页被随意翻 | 设置里的隐私项：「谁可以查看我的主页」 |
| 不想被陌生消息轰炸 | 「谁可以给我发消息」，收紧到互相关注 |
| 不想暴露距离与同城 | 拒掉位置权限，只影响按距离的推荐（影响面见 [下载与安装教程.md](下载与安装教程.md)） |
| 不想被推送失焦 | 回 [注册登录与基因库设置.md](注册登录与基因库设置.md) 重搭基因标签 |

设置改完即时生效。权限这一层（相机、麦克风、位置各自管什么）在 [下载与安装教程.md](下载与安装教程.md) 有完整对照表。

## 四、官方收集哪些信息（隐私政策口径）

按官方隐私政策公示的内容，与你直接相关的几条：

- **注册必须给手机号**——政策写明用于账号注册与网络实名制要求，不给就用不了；性别、生日、昵称、头像是**自愿填**的；
- 应用运行时（含后台）会收集设备标识、机型、操作系统版本、位置相关（IP、GPS、WLAN 接入点）等信息；
- 这些设备信息的用途之一是**安全风控**：政策写明可通过设备标识、IP 等对违规用户做锁定、封号处理——也就是说封号判定不只看你发了什么（账号异常的处理见 [常见问题与客服联系方式.md](常见问题与客服联系方式.md)）；
- 你有查阅、复制、更正、补充、删除个人信息以及注销账号的权利，注销是其中的正式通道（路径见第二节）。

政策全文挂在官方服务器上：[用户隐私协议](https://oss.tagoo.club/html/app/privacy_agreement.html)、[用户服务协议](https://oss.tagoo.club/html/app/user_service_agreement.html)。想删数据又不想销号，先读政策里「如何管理您的个人信息」那一节，按它给的入口操作。
