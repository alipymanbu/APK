## 一、登录收不到验证码

按顺序排除，多数到第 3 步就解决：

1. 看手机**拦截短信/骚扰拦截**里有没有被收走的验证码；
2. 等 60 秒再点「重新获取」——**短时间连点会被限流**，越点越收不到；
3. 确认手机号没输错、当前区域有信号；信号弱时短信延迟很正常；
4. 换网络（Wi-Fi 与流量互切）再试，短信网关偶尔会卡；
5. 还不行就改用微信登录这条路先进去（登录方式见 [注册登录与基因库设置.md](注册登录与基因库设置.md)），进去后再处理手机号问题。

## 二、装不上、闪退、打不开

| 症状 | 先查什么 |
| --- | --- |
| 安装时提示解析错误 | 安装包没下全，重新下载；校验 MD5 是否与 [下载与安装教程.md](下载与安装教程.md) 里那张表一致 |
| 提示禁止安装未知来源 | 按系统提示允许该来源（浏览器/网盘）安装，装完可关回 |
| 装到一半失败 | 机身可用空间不足，清出 500M 以上再装 |
| 打开就闪退 | 系统版本过老（网传门槛 Android 8.0 以上）、或安装包损坏——先重装，不行就换商店渠道同包名的包 |
| 用着卡 | 清应用缓存（设置 → 应用 → Tagoo → 清理缓存），后台挂着的清理/省电软件把它杀掉了也会表现为卡 |

安装包版本比商店新版本旧是正常的（网盘那份是 2.3.0），不影响使用；核对身份永远看包名 `club.spss.tagoo`。

## 三、同城/定位不准、刷不到附近的人

1. 先确认**系统定位服务**开着：设置 → 安全与隐私（或「位置信息」）→ 定位服务 → 打开；
2. 再确认给了 Tagoo **位置权限**（设置 → 应用 → Tagoo → 权限 → 位置），只给「仅使用期间」就够；
3. 室内 GPS 漂移会让距离偏差大，走到窗边或切 Wi-Fi/流量辅助定位后下拉刷新；
4. 权限给了仍不出同城，退出登录重进一次（登录见 [注册登录与基因库设置.md](注册登录与基因库设置.md)）。

位置权限只影响按距离的推荐，不给也能用按标签的匹配，只是刷不到同城（影响面见 [下载与安装教程.md](下载与安装教程.md)）。

## 四、匹配与账号类问题

- **怎么加好友**：互相点赞开聊、或闪聊亲密度刷满解锁头像后成为好友，完整规则见 [闪聊与心动匹配玩法说明.md](闪聊与心动匹配玩法说明.md)；
- **取消喜欢的人**：「我的」→「我喜欢」→ 对应的人 → 取消；
- **会员被扣费想关**：按 [BUFF会员价格与自动续费取消.md](BUFF会员价格与自动续费取消.md) 关，扣款前关最省事；
- **账号被封/内容被删**：违规内容（含在动态、评论里放联系方式）会被处理，申诉走客服邮箱，写清注册手机号、大致时间与页面截图。

## 五、识别正版与官方渠道

- **认准包名 `club.spss.tagoo`**：网上名字带「tagoo」的页面不少，包名对不上就不是这个应用；
- 官方下载与公告看官网 [tagoo.fun](https://tagoo.fun/)；商店渠道见应用宝收录页 [sj.qq.com/appdetail/club.spss.tagoo](https://sj.qq.com/appdetail/club.spss.tagoo)；
- 自己要存的安装包从 [Tagoo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/efb76b072dac) 取（事实与校验方法见 [下载与安装教程.md](下载与安装教程.md)）。
