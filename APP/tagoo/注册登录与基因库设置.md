## 一、先说结论

Tagoo 的账号就是你的手机号。装好打开（安装见 [下载与安装教程.md](下载与安装教程.md)）后，登录入口给了两种路子；进去先把「基因库」的标签填了——你后续刷到谁、谁刷到你，靠的就是这套标签。收不到验证码、登不进去这类问题统一放在 [常见问题与客服联系方式.md](常见问题与客服联系方式.md)。

## 二、登录方式

按公开教程整理，登录页大致两种走法（以你手里版本的实际界面为准）：

1. **手机号 + 验证码**：输入手机号 → 点「下一步」→ 填收到的短信验证码，首次登录会自动注册；
2. **微信登录**：走微信授权，省去输手机号。

登录之外还能补填的资料字段是**性别、生日、昵称、头像**——官方隐私政策写明这几项自愿提供，不填也能用；但资料空一截，右滑你的人会少（影响见 [闪聊与心动匹配玩法说明.md](闪聊与心动匹配玩法说明.md)）。

协议类文件在登录页都能点到，官网也挂了同一套：[用户服务协议](https://oss.tagoo.club/html/app/user_service_agreement.html)、[用户隐私协议](https://oss.tagoo.club/html/app/privacy_agreement.html)。同意后才能进，介意的话先读完再点。

几个登录环节的常见状况与处理（详细排查见 [常见问题与客服联系方式.md](常见问题与客服联系方式.md)）：

- 验证码收不到：先看短信是不是被拦截软件收走了，再等一会儿点「重新获取」，别连点；
- 换了手机号：优先用微信登录这条路进，进去后在设置里找换绑入口；找不到就走客服（联系方式见 [常见问题与客服联系方式.md](常见问题与客服联系方式.md)）；
- 不想用了：销号路径与注销前的准备见 [注销账号与隐私设置.md](注销账号与隐私设置.md)——**先关自动续费再注销**，顺序反了可能继续扣款。

## 三、基因库：被推荐给对的人的关键

「基因库」是 Tagoo 给你打的一组自我描述标签（兴趣、性格、生活方式这类），匹配与推荐按它来对人。按公开教程的路径：

1. 进「我的」页面，找到「我的基因」；
2. 点「搭建基因库」，在标签池里勾选贴合自己的标签；
3. **标签最多填 50 个**（按第三方教程口径，以应用内实际计数为准），填完返回；
4. 标签不是填完就固定——想调整随时回去改，改完推荐方向会跟着变。

填标签的实用建议（按玩法逻辑，不是官方规则）：

- **宁可准不要多**：乱勾一堆不相干的标签，推过来的人反而不匹配；
- 核心爱好（在追的剧、常玩的游戏、运动）优先勾，这类标签最容易撞上同好；
- 填完可以配合个人主页的资料与动态一起看——标签说你是谁，动态展示你真实在做什么，两者对得上，右滑你的人质量更高（匹配玩法见 [闪聊与心动匹配玩法说明.md](闪聊与心动匹配玩法说明.md)）。

## 四、个人主页与找人

- 主页资料、头像、动态都挂在「我的」下；动态怎么发见 [派对房与动态广场使用说明.md](派对房与动态广场使用说明.md)。
- 找人除了系统按标签推，还可以**按关键词搜**：输入对方昵称里的一个字就能搜到；每个用户的 ID 唯一，知道 ID 可直接定位到人（按第三方教程口径，以实际界面为准）。
- 想取消已经点过的心动：进「我的」→「我喜欢」→ 找到对应的人 → 取消，操作可逆（匹配与喜欢的完整规则见 [闪聊与心动匹配玩法说明.md](闪聊与心动匹配玩法说明.md)）。
