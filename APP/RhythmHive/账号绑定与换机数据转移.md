## 一、先分清两种账号

| | 游客账号 | 已绑定的账号 |
| --- | --- | --- |
| 数据存在哪 | 只在当前这台手机里 | 跟着你绑定的那个平台账号走 |
| 卸载重装后 | **找不回来** | 重新登录即可恢复 |
| 换手机后 | **无法转移** | 新手机登录同一平台账号即可 |
| 清缓存 / 恢复出厂 | 数据可能丢失 | 登录即可恢复 |

官方 FAQ 对此的口径很明确：未绑定的游客账号，游戏数据只存在当前设备上，重装、清数据、换机、恢复出厂之后都无法找回；换机时游客账号也接不回旧数据。**第一次进游戏就先把绑定做掉，别等存档丢了再补救。**

## 二、支持哪些绑定平台

官方支持以下五个平台：

1. Google Play
2. Apple ID
3. Facebook
4. Twitter
5. Weverse

## 三、怎么绑定

两个入口，对应两种情况：

- **装完第一次进游戏**：在登录屏直接选上面五个平台之一登录，登录即绑定。
- **已经用游客身份玩了一段时间**：进入大厅 → 右上角菜单 → 设置 → 账号绑定（Link Account）→ 选一个平台登录。

绑定成功后，你的存档就挂在那个平台账号名下。**绑定用哪个平台要想好** —— 以后换机、恢复数据都得用同一个平台登录，换平台等于换一个存档。

## 四、换新手机怎么恢复

1. 在旧手机上确认已经完成绑定（没绑先别换，见下一节的顺序）。
2. 新手机上装好游戏，启动。
3. 在登录屏选择**当初绑定的那个平台**，登录同一账号。
4. 进入游戏后旧进度会随账号一起拉回来。

反过来说：如果你当初绑的是 Google，新手机上却用 Facebook 登录，登进来的是一个全新存档，与旧数据无关。

**登录成功但存档是空的**，几乎都是登错了入口：换过绑定平台、或同一个邮箱当初用 Google 注册、这次用 Facebook 登，都会进到另一个空账号。排查办法只有一个 —— 想起当初绑定时用的是哪个平台、哪个账号，退出后原样重登一次；有排查资料称这是「换机后存档不见」最常见的原因，其次才是真的没绑。

## 五、卸载重装的正确顺序

官方 FAQ 特别提醒：卸载或重装前，务必先完成账号绑定。整理成顺序就是：

1. 进设置确认账号已绑定；
2. 再卸载 / 重装 / 清除数据；
3. 重装后用原平台账号登录。

排查故障时经常要「清数据 + 重装」（见 [常见问题与故障排查.md](常见问题与故障排查.md)），这一步没做，照着排查就会把存档一起清掉。

## 六、绑 Weverse 的额外奖励

如果你玩的是某个艺人的 Weverse 社区成员，把游戏账号与 Weverse 账号绑定后可以领取官方公布的会员奖励（具体奖励与发放频率以官方当期公告为准）。绑定方式：先在 Weverse App 内登录你的社区成员账号，再回到游戏里走「设置 → 账号绑定」选 Weverse 登录。若你的 Weverse 是用 Google / Twitter / Apple 等快捷登录注册的，需要先在 Weverse 的设置 → 关联账号里把这些账号关联上，再回游戏绑定。
