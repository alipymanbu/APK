## 一、开局四步

按新手引导走完这四步就进入主界面了，每一步的要点如下：

1. **选登录方式**。第一屏会让你选用哪种账号进游戏：Google、Apple、Facebook、Twitter、Weverse，或者游客。**这一步直接决定你的存档以后能不能找回来** —— 选游客等于把数据只存在这台手机里，详细风险见 [账号绑定与换机数据转移.md](账号绑定与换机数据转移.md)。
2. **选偶像组合**。游戏会先让你挑一支要一起玩的组合。选错了不要紧，之后可以在设置里换。
3. **选一名成员**。在所选组合里挑一位一起打歌的成员，这只影响互动内容的展示，不影响玩法本身。
4. **起昵称**。输入昵称确认后，就正式进入主界面。

收录的艺人来自 HYBE 旗下：BTS、TOMORROW X TOGETHER、ENHYPEN、SEVENTEEN、LE SSERAFIM、NewJeans、BOYNEXTDOOR、ILLIT、TWS 等（以游戏内实际曲库为准）。

## 二、主界面怎么走

主界面（大厅）是所有功能的入口，右上角菜单里有设置，右下角是打歌入口（不同版本按钮名称叫「音乐游乐场」「Music Arcade」等，认位置不认名字）。常用入口：

| 你想做什么 | 去哪 |
| --- | --- |
| 打歌 | 右下角打歌入口 → 选模式 → 选曲 → 选难度 |
| 抽卡、养卡 | 卡片 / 抽取相关入口 |
| 每日任务、活动 | 任务 / 活动入口 |
| 改语言、绑账号 | 右上角菜单 → 设置 |

## 三、三个主要模式

| 模式 | 你要做的事 |
| --- | --- |
| 章节舞台（Chapter Stage） | 按章节完成指定任务条件的演奏，通关拿奖励，曲目随章节推进解锁 |
| 录音室（Studio） | 自由选曲反复演奏，平时练歌、刷成绩都在这 |
| Catch Live | 最多 8 人实时同台演奏，也可以开只有朋友能进的私人场 |

此外还有按周指定曲目比高分的排名玩法（规则以游戏内当期公告为准）。第一次上手建议先在录音室把一首简单的歌打熟，再去章节舞台推任务。

## 四、新手期的资源从哪来

- **新手任务**：按 STEP1 到 STEP6 依次做完新手任务，能拿到 UR 票券，可以换一张本命的 UR 卡 —— 这是开局最有价值的一笔资源，优先做完。
- **签到与活动任务**：每天登录、完成活动任务会给金币、抽卡券一类的资源。
- **抽卡**：卡片直接决定你打歌的分数上限，怎么养见 [卡牌养成与抽卡攻略.md](卡牌养成与抽卡攻略.md)。

## 五、语言与画面设置

国际服支持简体中文与繁体中文，如果首次进入不是中文，在游戏内设置里可以切换（以游戏内实际选项为准）。账号绑定的入口也在同一个设置菜单里 —— 进游戏后先花一分钟把设置过一遍，比打到一半再翻菜单省事。
