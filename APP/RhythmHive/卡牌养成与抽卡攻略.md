## 一、卡片在玩法里干什么

你打歌时会带上一组卡片，卡片提供分数加成 —— 同一首歌、同样的准度，卡片不同分数就不同。反过来，章节任务、每周排名这类玩法又要求你有足够分数，所以这个游戏的实际循环是：打歌攒资源 → 抽卡 / 养卡 → 卡组变强 → 挑战更高要求的曲目。

## 二、稀有度与升级

- 有玩家攻略把六个等级明确列为 **B、A、S、R、XR、UR**，UR 最高（以游戏内图鉴显示为准）。
- 高等级卡片（XR / UR）显著抬高分数上限，是中后期提分的主要来源。
- 普通升级消耗金币加节奏方块（Rhythm Cube）；**XR 升 UR 要用奇迹节奏方块（Miracle Rhythm Cube），成功率较低，但每失败一次会累计提高成功率**（有攻略称每次 +5%，以游戏内为准）。
- 用卡片当升级材料时有经验加成：**同艺人 2 倍、同主题 2 倍，两者兼备叠加到 4 倍** —— 同艺人同主题的狗粮最划算。
- 回收多余卡片会得到 Memory Charm 与 Memory Catcher 两种代币，有攻略称只有卖 R、XR、UR 才给 Memory Catcher，并建议**只卖 R 卡换代币**、把商店里每周限量的奇迹节奏方块买满囤着（以游戏内商店实际规则为准）。

## 三、卡牌主题：Live 最金贵

卡片除了等级还有**主题**之分。有攻略列出六种主题：Album、Cheer、Season、FX、Special、Live：

- **Live 主题分数加成最高，同时掉率最低** —— 钻石类资源攒着留给 Live 主题卡池，比见卡就抽划算；
- 有攻略提到：Live 主题抽卡活动期间通常开「活动兑换」，可以用 **3 张 XR 卡 + 5000 金币**保底换一张指定艺人的 Live 主题 XR 卡，所以多余的 XR 卡别卖（规则以当期活动公告为准）；
- 不确定抽哪个池时的通用原则：先看当期有没有兑换活动，再决定资源往哪投。

## 四、开局资源优先给谁

按玩家攻略的通行做法：

1. **先做完新手任务 STEP1–STEP6**，拿到 UR 票券换一张本命 UR 卡 —— 开局最高性价比的一笔投入。
2. **有高级卡直接养高级卡**，不要从低级卡一层层往上练。玩家实测的结论是：低级卡逐级培养的资源开销并不划算，直接定向培养抽到的高稀有度卡更省。
3. **不为某个赛季关卡专门临时养卡**：同一专辑里的歌未必吃同一套卡加成，定向养成要看「歌曲要什么卡」，而不是看这首歌属于哪张专辑。

## 五、两种「Hive 点数」别搞混

玩家攻略里特别强调，界面上有两个都叫 Hive 点数的东西，进度互不相通：

| | 主页 / 排行榜的 Hive 等级 | 活动里的 Hive 点数进度 |
| --- | --- | --- |
| 怎么涨 | 长期累积，抽卡涨得最快（玩家经验：抽一张卡 +10 点，金币抽的普通卡也算） | 只看你在活动里的进度 |
| 上限 | 无明确上限 | 攒到 30 级可拿保底 XR，满级后可继续刷 |
| 重置 | 长期保留 | **每月清空** |
| 排名 | 参与排行榜排名 | 单人进度，无排名 |

想拿保底 XR，盯的是活动那一栏，别盯着主页等级白刷。

## 六、不同阶段的养成重点

- **前期**（手上没卡）：有什么养什么，高级优先；把新手任务和签到资源拿满，这阶段不氪也能起步。
- **中期**（有几套卡组到中高档）：停止全面铺开，转向定向补强 —— 缺哪类卡补哪类，为每周排名与章节任务服务。
- **中后期**（XR 成组）：分数瓶颈基本解除，养卡转为随抽随养，把资源留给活动保底和新卡池。
