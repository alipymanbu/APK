## 一、把界面换成中文

Neo Store 出厂界面是英文，但自带中文翻译，切换不用装任何附加包：

1. 打开 Neo Store，进入设置（Settings / 偏好设置）；
2. 找到「语言 / Language」一项；
3. 在语言列表里选「中文（简体）」（有的版本显示为 Chinese 或 zh-Hans，命名以你看到的列表为准）；
4. 返回后界面立即变中文，不用重启应用。

两个常见状况：

- **列表里没有中文** → 你这版应用的翻译还没覆盖，或版本太老。翻译由社区在 [Weblate 平台](https://hosted.weblate.org/engage/neo-store/)上持续补充，升级到新版本后再看；
- **只有部分条目是中文** → 翻译按条目逐步合入，个别新功能可能仍显示英文，属正常现象。

## 二、主题与显示

主题相关的可调项（具体名称与数量随版本变化，以应用内设置为准）：

| 设置项 | 你能调什么 |
| --- | --- |
| 主题模式 | 浅色、深色；深色另有更高对比度的变体，夜间看更清楚 |
| 动态取色 | 较新的版本支持跟随系统壁纸取色（Material You 一类），开关在主题设置里 |
| 字体与显示尺寸 | 跟随系统无障碍设置，应用内一般不单独提供 |

1.3.0 版把主题选项重做了一轮（官方更新日志原话「New comprehensive theme preference」），旧版本的设置项可能比新版本少。

## 三、几个让你用得更顺手的开关

都在设置里，按需开关：

- **自动更新**：开了之后源里有新版本就自动装；怕它半夜偷偷跑流量就关掉，改成手动点更新；
- **不兼容更新拦截**：1.2.5 起可以设置「不自动更新到暂无可复现构建的版本」「不自动更新到新增敏感权限的版本」，这两项对在意安全的你有实际用处；
- **按应用忽略更新**：不想被某个应用的更新打扰，在应用详情页里单独忽略；
- **搜索历史**：1.3.0 起搜索框会记住你的历史关键词并给建议，隐私敏感的话可以在设置里清掉或关闭。

界面设置到这里就齐了。如果打开应用发现列表一直空着，多半不是界面问题，去[常见问题与解决方法](常见问题与解决方法.md)查同步一节；第一次安装还没完成的，回到[下载与安装教程](下载与安装教程.md)从头走。
