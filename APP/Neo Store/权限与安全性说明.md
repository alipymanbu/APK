## 一、为什么它的权限列表看着比普通应用「吓人」

Neo Store 本质上是个应用商店客户端，替你下载并安装别的应用，所以它需要一组普通应用用不到的系统能力。它的权限在 F-Droid 的官方发布页上有完整清单，逐条解释最关键的几条：

| 权限 | 用在哪 |
| --- | --- |
| 请求安装文件包 / 安装软件包 | 你点「安装」时，由它替你调起系统安装器。不给这个权限，应用商店的基本功能就没法用 |
| 请求删除文件包 | 你在它里面卸载应用时用 |
| 查询所有软件包 | 列出手机上已装的应用、比对源里有没有新版本。没有它就做不了更新检查 |
| 显示通知、开机启动 | 同步与下载进度、更新提示靠通知送达；开机后恢复同步任务 |
| 请求忽略电池优化 | 保证后台同步与下载不被系统提前杀掉 |
| 读取 / 写入共享存储 | 导出、导入你的应用清单与软件源配置时用 |
| 使用生物特征硬件 | 你开启指纹 / 生物识别锁这类保护功能时用 |

权限清单里还带一条与 Shizuku 相关的条目（`moe.shizuku.manager.permission.API_V23`），对应免 root 静默安装这类进阶玩法；你不用 Shizuku 的话它不会被触发。1.3.0 起的版本权限略有增减，以官方发布页当时列出的为准。

## 二、怎么判断这份安装包是干净的

三层校验，从弱到强：

1. **MD5 比对**：把下载到的 APK 用工具算一遍 MD5，与[下载与安装教程](下载与安装教程.md)里给出的值比对，确认文件在传输中没被改动、没下载半截；
2. **签名校验**：Android 安装时会验包的数字签名，签名对不上系统的既有记录会拒绝安装；
3. **渠道可信度**：本指南配套的安装文件资源来自固定网盘链接，包信息（版本 1.2.4、包名 com.machiav3lli.fdroid、大小 5.41 MB）在下载页有明确标注，装错包的概率很低。

## 三、开源与发布渠道意味着什么

- **代码公开**：源码在 [github.com/NeoApplications/Neo-Store](https://github.com/NeoApplications/Neo-Store)（Codeberg 有镜像），GPL-3.0+ 许可证，任何人可以审阅它干了什么、没干什么；
- **多渠道分发**：F-Droid 官方源与 IzzyOnDroid 都收录了它，两个渠道各自从源码构建安装包并公示构建信息，你可以不依赖任何一个渠道交叉验证；
- **F-Droid 的构建公示**：F-Droid 每个版本都附带构建日志与签名说明，源码与安装包的一致性可以核对 —— 这是它比来路不明的「搬运 APK」站点可靠的地方；
- **社区与反馈**：项目有公开的问题追踪与讨论组（Telegram、Matrix），出问题能找到人。

## 四、Play 保护机制警告怎么理解

它不从 Play 商店分发，所以安装或运行时 Play 保护机制（Play Protect）可能弹出「未验证的应用」提示。这个提示的含义是「此应用未经过 Play 商店审核流程」，不等于「查出恶意行为」。你手上有 MD5 与开源代码两层依据，自己拿主意即可；选择「仍要安装」后一般不会再反复拦截。

## 五、用它的过程中你还能锁紧的几道闸

- 只勾选你真正需要的软件源，少一个源少一份第三方清单与安装包入口（见[添加软件源与镜像设置](添加软件源与镜像设置.md)）；
- 给第三方源填上官方主页公示的指纹，防止源被冒名顶替；
- 应用内若提供指纹 / 生物识别锁（隐私面板相关功能），按需开启；
- 系统层面保持「安装未知应用」只对它单独放行，不要全局面开 —— 这正是默认设置的行为，别改。

遇到拿不准的报错与警告，先去[常见问题与解决方法](常见问题与解决方法.md)查一遍，再决定要不要装。
