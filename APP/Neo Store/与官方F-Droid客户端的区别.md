## 一、先说清楚：它们装的是同一批应用

官方 F-Droid 客户端（包名 `org.fdroid.fdroid`）和 Neo Store（包名 `com.machiav3lli.fdroid`）都是「客户端」——它们本身不是应用来源，只是帮你连上 F-Droid 软件源、列清单、下载安装的工具。同一个软件源，用哪个客户端连，能搜到、能装的应用是同一批。所以「换客户端」不会让你多出几个应用可装，改变的是你操作这套源的方式。

出身方面有两种说法并列放着：官方 README 说 Neo Store 是 Foxy-Droid 的直接改编；社区讨论里也有人把它归为 Droid-ify 的分支，而 Droid-ify 同样源自 Foxy-Droid。两说不矛盾 —— 它们都出自 Foxy-Droid 一系。

## 二、对照表

| 维度 | 官方 F-Droid 客户端 | Neo Store |
| --- | --- | --- |
| 维护方 | F-Droid 项目官方 | Antonios Hazim（NeoApplications），个人维护的开源项目 |
| 许可证 | GPL | GPL-3.0+ |
| 界面 | 传统样式，多年未大改 | Material 风格，浅色 / 深色 / 高对比度主题 |
| 内置软件源 | 默认只有 F-Droid 官方源，其他源要手动加 | 预置了一批社区源（README 提到内置约一百个，随版本变化，以应用内列表为准），IzzyOnDroid 无需手动添加 |
| 源同步速度 | 常被用户抱怨偏慢 | 官方定位就包括快速同步，多源可同时刷新 |
| 自动更新 | 主客户端长期没有完善的自动更新；官方另有 F-Droid Basic 简化版，在较新系统上支持静默更新（以官方页面为准） | 支持自动更新，可按应用忽略 |
| 镜像支持 | 最完善（2023 年起社区就有「只有官方客户端镜像支持最完整」的说法，现状以官方文档为准） | 1.2.5 起失败时自动轮换镜像，也可手动固定 |
| 系统要求（最新版） | 较宽 | 1.3.0 起要求 Android 8.0+ |

表中「界面」「速度」一类是社区与媒体的普遍反馈，属于体验评价；功能类条目（内置源、镜像机制、系统要求）有官方渠道可查。

## 三、按什么标准挑

- **你想最少折腾** → 官方客户端。它是 F-Droid 项目自己的软件，与官方源的兼容性由同一拨人保证，出问题官方文档也最全；
- **你要装 IzzyOnDroid 这类社区源、不想手动配置** → Neo Store 或 Droid-ify，这两个客户端出厂就预置了 IzzyOnDroid 源（IzzyOnDroid 的官方上手页也是这么推荐的）；
- **你在意界面与更新体验** → 第三方客户端普遍界面更新、支持按应用忽略更新；官方客户端胜在稳；
- **你的系统版本较老** → 注意各客户端最新版对 Android 版本的要求（Neo Store 1.3.0 要 8.0+），老系统可能得装旧版；
- **你就想先用起来** → 两个都装也不冲突，同一个软件源可以在两个客户端里同时连，试完留一个。

## 四、换客户端时要注意的事

1. 已经通过官方客户端装好的应用，换到 Neo Store 后能被识别并接管更新 —— 首次同步后它会提示你确认；
2. 但如果一份应用当初是用不同签名装的（比如直装 APK 与商店构建签名不同），接管时会报签名冲突，需要卸载重装，见[常见问题与解决方法](常见问题与解决方法.md)；
3. 软件源不会自动跟过去：官方客户端里手动加过的第三方源，要在 Neo Store 里重新加一遍，步骤见[添加软件源与镜像设置](添加软件源与镜像设置.md)；
4. 两个客户端别同时开自动更新，否则同一个应用可能被两边轮流装。

还没装的话，从[下载与安装教程](下载与安装教程.md)拿安装包开始；装完想先把界面换成中文，看[怎么设置中文与界面个性化](怎么设置中文与界面个性化.md)。
