## 一、装之前先知道的三件事

1. **Bilby 是一个第三方 B 站客户端**，覆盖的是看视频、追动态这类核心场景：首页展示的是你关注 UP 主的更新动态，没有推荐流、商城这类板块（以 0.11.1 版本的实际界面为准）。
2. **登录靠扫码**：装好后打开会出现二维码，用官方哔哩哔哩 App 扫一扫即可登录，全程不需要输账号密码。具体流程见 [扫码登录与账号数据同步.md](扫码登录与账号数据同步.md)。
3. **它只有安卓版**，安装包只有 7.45M，对中低端机型比较友好；iPhone / iPad 上没有对应的安装包。

## 二、安装步骤

1. 获取 APK 安装包：用本文提供的 [Bilby 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6cb7af2504dc)，转存到自己网盘后下载 APK 文件。
2. 在手机上点开下载好的 APK。系统首次会提示「不允许安装未知来源应用」，按提示允许你的文件管理器「安装未知应用」权限后再继续。
3. 等待安装完成，打开 Bilby。第一屏就是登录二维码，直接进入扫码登录即可。

## 三、核对安装包（版本 / 包名 / 大小 / MD5）

本篇网盘资源对应的安装包信息如下，安装后可以在系统「设置 → 应用」里对照包名确认：

| 项目 | 值 |
| --- | --- |
| 版本 | 0.11.1 |
| 包名 | `dev.bilby` |
| 安装包大小 | 7.45M |
| MD5 | `2D817F564F56AB23C5D6DA37335A7584` |

几点说明：

- 以上是网盘里这一份安装包的信息。网上应用市场介绍的往往是官方最新版，与你实际拿到的那份未必是同一版，核对时以上表为准。
- 不同渠道分发的安装包 MD5 可能不同（打包渠道不同），**包名 `dev.bilby` 是更通用的核对依据**。
- 包名与官方哔哩哔哩客户端不同，两者通常可以在同一台手机上并存安装，互不覆盖；个别厂商系统的兼容限制以实际安装结果为准。
- 对 MD5 的方法：Windows 上用 `certutil -hashfile 文件名.apk MD5`，安卓上在文件管理器的文件信息页查看。

## 四、装好后先做什么

1. 先扫码登录：首页展示的是「你关注的 UP 主的动态」，不登录就没有这份内容，正常使用需要先登录（见 [扫码登录与账号数据同步.md](扫码登录与账号数据同步.md)）。
2. 刚登录时首页如果是空的，不是故障——你还没有关注任何 UP 主。先用搜索找到几个常看的 UP 主并关注，首页就会开始出现他们的更新动态（搜索用法见 [订阅动态与搜索使用.md](订阅动态与搜索使用.md)）。
3. 想锁屏听视频里的音频，提前把后台权限设置好，省得中途被打断，见 [后台播放中断排查.md](后台播放中断排查.md)。
