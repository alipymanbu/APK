## 一、为什么用扫码登录

Bilby 的登录方式是扫码：你打开 Bilby 会出现一个二维码，用官方哔哩哔哩 App 扫一扫、在手机上确认即可。对你来说有两个直接的好处：

- 不用在第三方客户端里输入 B 站的账号密码；
- 登录的就是你自己的 B 站账号，后面发弹幕、投币、评论都落在这个账号上。

二维码有时效，放久了会失效，刷新一个再扫就行。

## 二、扫码登录步骤

1. 打开 Bilby，出现登录二维码。
2. 打开官方哔哩哔哩 App，点右上角「扫一扫」。
3. 对准 Bilby 上的二维码扫描，官方 App 会弹出确认页。
4. 在官方 App 里点确认登录，回到 Bilby，首页能看到你关注 UP 主的动态就说明登录成功了。

如果 Bilby 上的二维码已经过期，先刷新二维码再扫，不要拿旧码反复试。

## 三、登录后哪些数据会同步

登录的是同一个 B 站账号，数据分两类看待：

| 数据 | 是否跟着账号走 | 说明 |
| --- | --- | --- |
| 关注列表 | 是 | 首页动态就来自这份列表，官方 App 里的关注直接生效 |
| 投币、点赞、评论 | 是 | 操作直接发生在你的账号上，官方 App 里同样可见 |
| 收藏 | 是 | 长按点赞一键三连收藏的也是你账号里的默认收藏夹 |
| 播放设置、后台保活开关等本地配置 | 否 | 只存在这台手机上，换手机要重新设置 |

简单记：**你「做过什么」跟账号走，你「怎么设置的」只跟手机走**。以实际使用为准，个别数据的表现可能随版本变化。

## 四、登录常见问题

- **扫码后一直没反应**：先确认网络正常，然后退出 Bilby 重新打开，生成一个新二维码再扫；官方 App 扫码后必须在确认页点过「确认登录」才算完成。
- **首页一片空白**：多数情况是你还没关注任何 UP 主，而不是登录失败。用底部放大镜搜索几个常看的 UP 主并关注，动态就会出现（见 [订阅动态与搜索使用.md](订阅动态与搜索使用.md)）。
- **换手机后设置全没了**：这是正常的，本地设置不随账号同步，按 [后台播放中断排查.md](后台播放中断排查.md) 重新把后台保活那几个开关打开即可。
- **登录环节之外的问题**：播放、更新日志类的疑问汇总在 [版本更新与常见问题.md](版本更新与常见问题.md)。
