## 二、系统要求与安装前检查

- **系统版本**：安卓 8.0 及以上。低版本系统打开安装包会直接提示解析失败，这不是包坏了。
- **剩余空间**：安装包 100M 出头，安装后应用本体加数据还要再占一截，建议预留 1GB 以上。
- **下载完整性**：从网盘转存或下载时等进度走完再动文件，`.part` 这类未完成的文件无法安装。
- **来源提示**：应用不在你手机的品牌应用商店里时，系统会弹「禁止安装未知来源应用」，这是系统的通用拦截，按提示给浏览器或文件管理器授权即可（见下节）。

## 三、安装步骤

1. 打开 [Qing 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b3fb3684ceed)，把安装包转存到自己的网盘后下载到手机；也可以在电脑上下载好再传到手机。
2. 用手机自带的「文件管理」找到这个 `.apk` 文件，点它。
3. 若弹出「不允许安装未知来源应用」，按提示进入设置、允许当前应用（浏览器或文件管理器）安装，然后返回继续。
4. 等安装进度走完，点「打开」。
5. 首次启动会依次请求权限，见下一节；建议先把权限看清再决定给不给。

## 四、首次启动会要哪些权限，各自干什么

以下是官方商店公示的权限用途说明，你可以在系统设置里随时改：

| 权限 | 官方说明的用途 |
| --- | --- |
| 位置（大概/精确） | 查找好友、附近的人与同城功能 |
| 存储 / 媒体读写 | 保存图片、更换头像、发送相册内容 |
| 摄像头 / 麦克风 | 拍摄发布内容、发语音消息 |
| 电话 | 联系客服 |
| 通知 | 消息推送 |
| 读取联系人相关 | 通讯录好友发现 |

拿不准的权限可以先拒绝 —— 拒绝位置就用不了附近与同城，拒绝通知就收不到消息提醒，其余的用到时系统会再次询问。

## 五、安装后怎么确认装对了

进系统「设置 → 应用管理」找到 Qing，看详情页：版本号应与你下载的包一致（本地留存的这份为 1.4.0），包名显示 `com.qing2000.android` 即为正版包。装完建议顺手做两件事：允许通知、允许自启动（国产系统还要在电池设置里允许后台运行），否则消息可能收不到 —— 具体症状对照见 [常见问题与故障排查.md](常见问题与故障排查.md)。
