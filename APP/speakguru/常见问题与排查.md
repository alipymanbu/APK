# 咕噜口语常见问题与排查

> 本篇按「症状 → 处理」整理咕噜口语（SpeakGuru）的高频问题：识别不到说话、安装失败、登录收不到验证码、额度用完、换手机丢进度等。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [发音纠正与语法批改怎么用.md](发音纠正与语法批改怎么用.md) · [注册登录与首次使用流程.md](注册登录与首次使用流程.md)

---

练习类应用的问题八成出在权限、网络和账号上，先对照本篇排查，多数不用卸载重装。解决不了的再按最后一节的思路处理。

## 一、说话 AI 没反应 / 评分乱跳

1. 查两层开关：应用权限（「设置 → 应用 → 咕噜口语 → 权限」，麦克风设为「仅在使用中允许」）和安卓 12 及以上的**全局麦克风访问开关**（一般在「设置 → 隐私」里，部分机型下拉面板也有麦克风快捷开关）——后者一关，所有应用都收不到声音，而且**没有任何报错提示**；
2. 用系统录音机录一句回放，确认手机麦本身正常；手机壳错位挡住底部麦孔也会让声音发闷变小，取下壳再试一次；
3. 戴蓝牙耳机时识别乱跳，多半是耳机在后台接管了录音——先断开蓝牙用手机麦测一次，恢复正常就是耳机麦的问题；
4. 离噪声源远一点——官方称支持方言口音，但背景音大时识别照样失准；
5. 语速放回正常水平，音量保持日常对话大小。

权限、收音都没问题还是不行，重启应用再试一次。另外系统大版本更新或卸载重装后，麦克风权限可能被重置，按第 1 条再核对一遍。

## 二、安装失败

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「解析包出错」 | 下载不完整 | 删掉重下安装包（见 [下载与安装教程.md](下载与安装教程.md)），下完比对文件大小 |
| 提示空间不足 | 剩余空间少于包体加缓存 | 清出 1GB 以上再装 |
| 点开没反应 | 未授权「安装未知应用」 | 给文件管理器 / 浏览器授权后重试 |
| 装完秒退 | 系统版本过低或安装包不完整 | 换应用商店渠道装最新版对照 |

## 三、收不到验证码 / 登录不上

1. 等 60 秒再点重发，连续多发会被限流；
2. 检查短信拦截与骚扰过滤（手机管家的拦截记录里常有）；
3. 换**邮箱登录**通道，避开短信链路；
4. 换网络（Wi-Fi 与流量互换）再试；
5. 都不行就联系应用内客服，渠道问题客服能查提交记录。

## 四、免费额度用完了

- 当天额度用完只能等次日刷新，额度规则以应用内提示为准；
- 福利中心通常可以领试用会员，先把试用用完再考虑付费；
- 长期不够用再对照 [免费版与会员价格区别.md](免费版与会员价格区别.md) 决定是否上会员。

## 五、换手机 / 卸载重装会丢进度吗

进度挂在账号上：新设备装好后用**同一个登录方式**登录（手机号登录的就用手机号，别换成邮箱，那是两个账号），练习记录、生词本、会员状态会同步回来。卸载前如果换了登录方式找不到原来的记录，先试回原来的登录方式再确认。

## 六、以上都不管用的时候

按这个顺序处理，能少走弯路：

1. 确认是最新版本（应用内「关于」或商店页面看版本号）；
2. 完全退出应用后重开（清后台不算，要杀进程）；
3. 手机重启；
4. 卸载重装——**先确认记得原来的登录方式**（见上一节）；
5. 应用内客服反馈，附上机型、系统版本和问题截图。
