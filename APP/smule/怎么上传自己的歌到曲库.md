## 一、先知道这几条规则

按官方帮助中心的说明：

- 有 Smule 账号就能传歌，**不要求 VIP**（VIP 的差别见 [VIP会员与免费版区别.md](VIP会员与免费版区别.md)）；但只能在电脑上用网页端操作，手机 App 里没有这个入口。
- 传的歌对全站公开，不能设为私有。
- 你传的是「无人声的伴奏（backing track）」，别人在 App 里对着它唱。
- 和官方制作的歌有两点差别：官方歌按字词对齐歌词、带音高提示线；用户传的歌按「行」对齐、没有音高线。

## 二、伴奏文件的规格

不符会被直接拒收，先按这张表处理：

| 项目 | 要求 |
| --- | --- |
| 文件大小 | ≤ 20MB |
| 时长 | 30 秒 ~ 10 分钟 |
| 格式 | m4a / mp3 |
| 采样率 | 44100 或 48000 Hz，16 bit |
| 声道 | 单声道或双声道 |
| 压缩码率 | 单声道 ≤ 64kbps，双声道 ≤ 128kbps |

超标就用 Audacity、VLC 这类免费工具重新压缩或剪短（Audacity 导出 mp3 需要另装 LAME 编码器）。伴奏里必须没有人声——那是留给歌手的演唱位。

## 三、网页端上传步骤

1. 电脑浏览器打开 [www.smule.com](https://www.smule.com) 并登录账号；
2. 点右上角 **Upload**，选 Songbook（上传歌曲到曲库）；
3. 从电脑里选伴奏文件上传，通常几分钟内完成；
4. 填歌名、歌手、流派和情绪标签——系统里已有同款会提示你匹配；
5. 粘贴歌词，并为对唱/组唱分配声部：对唱分 2 个声部，组唱可分 3~8 个；只设了对唱声部的话，组唱会自动套用；
6. 逐行打时间点：播到某句歌词该出现在屏幕上时，按空格键或点鼠标标记，页面上的喇叭图标可以试听当前进行到哪一行；
7. 标注歌曲结构（前奏/主歌/副歌/桥段等），方便别人选段落开唱；
8. 点 Save，这首歌会出现在你主页的 Songs 和曲库的 Community 区。

## 四、传完之后

- **看数据**：主页 Songs 里点进这首歌，能看到被唱了多少次、歌手的评分和改进建议。
- **改歌**：登录后进 Songs → 点这首歌 → 右上 Edit Song。
- **删歌**：同一个 Edit Song 入口里有删除选项。
- 歌传上去后别人就能搜到并开唱，合唱的玩法见 [独唱对唱与合唱怎么玩.md](独唱对唱与合唱怎么玩.md)；上传被拒、播放异常等问题的排查见 [常见问题与故障排查.md](常见问题与故障排查.md)。
