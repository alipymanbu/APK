# Clue 常见问题排查（消息、头像、相册与定位故障）

> 本篇收录 Clue 用起来最常撞上的几类故障：消息发不出、头像变灰、相册卡顿、定位不准，按「现象 → 先查什么」的格式给出排查顺序。安装和注册环节的问题分别见 [下载与安装教程.md](下载与安装教程.md) 与 [注册与真人认证流程.md](注册与真人认证流程.md)。

## 一、排查通用三步

不管什么故障，先走这三步，能解决一大半：

1. **看版本**：设置里查当前版本号，能升级就升级——官方更新日志里反复修的正是消息发送失败、头像变灰这类问题，你踩的坑可能已经修了。升级包可用本页的 Clue 安装文件资源（夸克网盘）或官方渠道获取。
2. **看网络**：弱网络环境是官方更新日志里点过名的问题来源，切 Wi-Fi / 流量互换试一次。
3. **重启 App**：杀掉进程重开，别小看这一步。

## 二、按现象排查

### 消息发送失败

| 检查项 | 说明 |
| --- | --- |
| 网络 | 弱网下发送失败概率最高，先换网络 |
| 版本 | 官方更新日志里有「修复消息发送失败」的记录，老版本先升级 |
| 图片/视频消息 | 视频文件名带特殊符号时出过发送失败（官方修过），重命名后重发或改发文字 |
| 仍不行 | 等一会儿再试；持续失败联系微信客服 AppClue |

### 头像变灰 / 头像更新不生效

- 官方更新日志明确修过「弱网络环境下提交头像可能导致头像变灰」——出现这个现象大概率是提交时网络断了半截，换稳定网络后重新上传头像。
- 认证相关的头像问题（被驳回、审核中）不算故障，处理方式见 [注册与真人认证流程.md](注册与真人认证流程.md)。

### 相册打开慢 / 加载卡

- 官方更新日志里有「优化打开相册的加载逻辑，手机内存不足也能丝滑操作」的记录——手机存储或内存吃紧时会明显卡，先清后台、腾存储，再升级到新版本。
- 相册里图特别多（几千张起）的设备，第一次打开慢是正常的，等索引完成。

### 视频动态卡在上传中 / 闪退

- 编辑视频时文件名带特殊符号出过闪退（官方修过），把视频文件重命名成纯英文数字再试；
- 发布视频动态卡进度的问题在旧版本更新日志中出现过，升级版本是最直接的解法；
- 视频体积大就先压缩，移动网络下上传成功率更高。

### 收不到消息推送

1. 系统设置 → 通知 → 找到 Clue，确认通知权限是开的（权限对照表见 [隐私保护与账号注销.md](隐私保护与账号注销.md)）；
2. 国产系统的「省电策略」把 App 设成允许后台运行，否则进程被杀推送就断了；
3. 进 App 手动刷新能刷出新消息、只是收不到推送 → 就是通知链路的问题，按上面两条处理。

### 地图 / 定位不准

这类反馈不算少见：应用宝评论区就有用户问过「为什么开了位置，无法定位」，历史版本更新日志里也专门优化过「定位权限索取和定位失败时的交互」。按这个顺序查：

1. 确认系统定位服务（GPS）开着，且 Clue 的位置权限是「使用期间允许」而不是「仅本次」；
2. 国产系统的省电策略或「模糊定位」选项会削弱精度，把 Clue 设为不受省电限制、给精确位置；
3. 在室内时定位漂移正常，走到窗边或开阔处刷新；
4. 杀进程重开 App，仍不行重启手机再试；
5. 想看别的城市用 App 内的城市切换，不是靠挪动手机定位；
6. 附近显示「没人」有时不是故障——是当前位置确实没人在线，切城市就能验证。

全试过仍定位失败的，直接走文末的官方反馈渠道，描述里写清「系统定位正常、其他地图应用正常、只有 Clue 定位失败」，客服排查会快很多。

### 账号登不上 / 被封

- 密码忘了走登录页的找回流程，细节以 App 内为准；
- 协议约定的处罚形态包括警告、账号封禁、设备封禁、功能封禁——如果你违规过，登录异常可能是处罚而不是故障；
- 申诉走邮箱 cs@jiccos.com，写清账号信息与事情经过。

## 三、什么情况该联系官方

自查两轮没解决的，带上这些信息找官方，一次沟通就能说清楚：

- 手机型号与系统版本；
- App 版本号（设置里看）；
- 问题现象描述 + 出现时间；
- 必要时附截图。

渠道：邮箱 cs@jiccos.com、微信客服 AppClue，官方还有微信服务号「Clue官号」和微博、抖音账号 @Clue彩虹地图 可查公告。

付费相关的争议另走 [会员订阅与自动续费管理.md](会员订阅与自动续费管理.md) 里的路径，别混在功能故障里报。
