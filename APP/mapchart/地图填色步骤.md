# MapChart 地图填色完整步骤

> 从选底图到导出一张成品的完整流程。官方把核心玩法概括成三步：点国家/州填色、填图例、导出图片，本篇按手机上的实际操作顺序展开。

## 一、先记住两个功能按钮的位置

手机版的主要操作集中在两个按钮上（不同版本位置可能略有差异，以应用内实际为准）：

| 按钮 | 位置 | 管什么 |
| --- | --- | --- |
| Customize | 左下角 | 背景色、边框、图例样式这类整体自定义 |
| Actions | 右下角 | 下载地图、保存等收尾动作 |

## 二、选一张底图

1. 打开应用点 Create Map；
2. 在 Select map 列表里按分组翻，挑一张底图。分组怎么对应用途，看 [地图模板一览.md](地图模板一览.md)；
3. 选定后地图会加载出来，可双指缩放、拖动查看不同区域。

## 三、点哪填哪

- 点任意一个国家（或州、省等可填单位），它会立刻被当前颜色填满；
- 想改某块区域的颜色，先在调色板（Select Color）里换成目标色，再点那块区域；
- 小国家、小州先双指放大再点，避免误触相邻区域；
- 与本图主题无关的国家或州可以隐藏掉，画面会干净很多，隐藏入口在 Customize 的编辑选项里，具体位置以你手上的版本为准。

填色本身没有难度，真正决定成品观感的是颜色分组和图例，这块单独开了一篇：[图例与配色设置.md](图例与配色设置.md)。

## 四、给每种颜色配一个图例条目

每种颜色对应图例里的一组，填上组名或一句描述，比如「同盟国」「协约国」「中立国」，或者「GDP 高于 3 万美元」「1 万至 3 万美元」「低于 1 万美元」。

- 图例不要留空：没有说明的填色图，别人（包括一个月后的你）看不出颜色代表什么；
- 组数控制在四五个以内，太多颜色读起来会累；
- 图例的字体、颜色、大小、位置都能调，详见 [图例与配色设置.md](图例与配色设置.md)。

## 五、预览、导出、分享

1. 点 Preview Map 看整体效果，不满意返回继续改；
2. 确认后点右下角 Actions，选 Download map，地图会导出成一张图片；
3. 导出后可以直接发到社交平台，或者当素材贴进报告、博客。

导出格式、保存位置和文件去向的细节，单独写在 [保存与导出地图.md](保存与导出地图.md)。

## 六、一次完整流程的对账单

| 你想做 | 去哪点 |
| --- | --- |
| 换底图 | Create Map → Select map |
| 换填充色 | 调色板（Select Color） |
| 改图例文字 | 图例编辑区 |
| 换背景、边框、隐藏区域 | Customize（左下角） |
| 导出图片、分享 | Actions（右下角） → Download map |
