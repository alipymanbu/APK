## 一、装之前先确认这几点

| 项目 | 说明 |
| --- | --- |
| 系统版本 | 商店页面对较新版本标注 Android 11 及以上；再早一些的版本要求更低。具体以你设备上的商店页面为准 |
| 存储空间 | 本篇对应的安装包约 92.55 MB，装完加上地图数据与缓存还会再占一些，建议预留 300 MB 以上空余 |
| 安装包版本 | 6.12.3，包名 com.whidev.mapchart，开发者 whidev |
| 网络 | 安装不需要联网；应用支持离线做图，联网主要用于分享和商店更新 |

版本号会随官方更新往前走，上面写的是网盘里这一份安装包的事实；想知道官方最新版到哪了，去应用商店看即可。

## 二、拿到安装文件

1. 打开上面的 **MapChart 安装文件资源（夸克网盘）** 链接，把里面的安装包转存到你自己的网盘；
2. 在网盘客户端里把安装包下载到手机存储，文件名一般形如 `mapchart_v6.12.3.apk`；
3. 如果想核对下载是否完整，可以用文件校验类工具读取安装包的 MD5 值，与 `36ea87444908f0137abd0195d8905bd9` 比对，一致即说明文件没下坏。

## 三、安装步骤

1. 在手机文件管理器里找到刚下载的 APK，点开；
2. 系统首次会提示「不允许安装未知来源应用」，按提示进入设置，允许你的文件管理器（或网盘客户端）安装应用；
3. 回到安装界面点「安装」，等进度走完；
4. 点「打开」直接进入，或回桌面从图标启动。

## 四、首次打开怎么走

- 启动后看到的就是地图列表，挑一张感兴趣的点进去就能开始填色，不需要注册账号；
- 想照着做第一张图，直接看 [地图填色步骤.md](地图填色步骤.md)；
- 界面语言有两种口径：商店资料标注英语，但多家教程提到应用内可切简体/繁体中文。以你手上版本实际显示为准，切换路径见 [界面语言与中文设置.md](界面语言与中文设置.md)；
- 想先弄清楚免费版能用多少、付费版多花在哪，见 [免费版与付费版区别.md](免费版与付费版区别.md)。

## 五、装不上时的排查

| 现象 | 常见原因与处理 |
| --- | --- |
| 提示「解析包出现问题」 | 安装包没下完整，重新下载再装；或系统版本低于该版本要求，换更低版本或升级系统 |
| 提示存储空间不足 | 清出一部分手机存储后重试 |
| 提示与已安装应用冲突 | 之前装过别的渠道来的同包名版本时，先卸载旧的再装 |
| 安装完成后点图标闪退 | 重启手机再试一次；仍然闪退多半是系统版本过旧或机型兼容问题，去商店看该版本的系统要求 |

装好之后从 [地图模板一览.md](地图模板一览.md) 挑底图，就能开始做第一张了。
