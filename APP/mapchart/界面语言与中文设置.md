# MapChart 界面语言与中文设置

> 装好应用第一件事往往是「界面能不能中文」。本篇把商店口径与各家教程口径并列摆出来，给出多数教程一致的切换路径，再附一份常用英文按钮对照。

## 一、两种口径，先摆在桌面上

| 口径来源 | 说法 |
| --- | --- |
| 商店资料 | 应用商店的语言栏标注为英语（English） |
| 多家第三方教程 | 应用内设有语言选项，可切换简体/繁体中文 |

两边说法不一致，本篇不替你选边：**以你手上版本的应用内实际显示为准**——找得到语言选项就切，找不到说明这一版没有，后续版本可能补上。

## 二、多数教程给出的切换路径

各家教程对入口位置的描述略有出入（有的写左上方菜单，有的写右下角选项），但步骤主干一致：

1. 打开应用，进入 options（选项/设置）；
2. 打开里面的菜单；
3. 点击「语言」（Language）选项；
4. 在语言列表里选「简体中文」或「繁体中文」。

如果你的版本界面对不上，别硬找：在 options 里翻一遍，语言项通常叫 Language 或 Languages；实在没有就参考下一节。

## 三、找不到语言选项时

- 先确认版本：语言选项随版本变动，旧版可能没有。商店或应用内检查更新，升到新版再看；
- 再看商店页面：商店资料的语言栏是官方标注，如果只写英语，多半当前版本没有内置中文；
- 不要为中文去装来源不明的「汉化包」：换非官方安装包等于换掉整个应用，安全与更新都没有保障，装包认准 [下载与安装教程.md](下载与安装教程.md) 里的正规渠道。

## 四、界面是英文时的按钮对照

就算保持英文界面，常用的也就这几个词：

| 界面英文 | 意思 | 用在哪 |
| --- | --- | --- |
| Create Map | 创建地图 | 首页入口 |
| Select map | 选择地图 | 挑底图 |
| Select Color | 选择颜色 | 调色板，换填充色 |
| Customize | 自定义 | 背景、边框、隐藏区域 |
| Preview Map | 预览地图 | 导出前检查整体效果 |
| Actions | 操作 | 右下角，收尾动作的入口 |
| Download map | 下载地图 | 导出成图片 |

按钮的具体用法在 [地图填色步骤.md](地图填色步骤.md) 里有完整流程，对照着做第一张图即可。
