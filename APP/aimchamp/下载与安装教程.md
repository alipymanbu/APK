## 一、先核对版本信息

Aim Champ 是 Acmore Apps 出品的安卓端 FPS 瞄准训练器，在 Google Play 上的上架名为 `Aim Champ : FPS Aim Trainer`，官方商店页：`https://play.google.com/store/apps/details?id=com.acmore.aimchamp`。本篇对应的安装包信息如下：

| 项目 | 内容 |
| --- | --- |
| 版本号 | 3.0.4 |
| 包名 | `com.acmore.aimchamp` |
| 安装包大小 | 164.34 MB |
| MD5 | `EFC46CDF18F2700483ADCC2334F9203D` |
| 系统要求 | Android 5.2 及以上 |

如果你在官方页面看到更高的版本号，那说明官方后来又更新了，以页面当时显示为准；上面这组数值只对网盘里这一份安装包负责。装之前最值得做的一步是校验 MD5（见第三节），它能直接排掉「下到残缺文件」这类最麻烦的问题。另注：各渠道对最低系统的标注不完全一致（有的标 4.4+，有的标 6.0+），系统版本接近临界值且安装失败时，先升级系统再试。

## 二、从网盘获取安装包

安装包从这里的 **[Aim Champ 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cdcb402af5e0)** 获取，文件名形如 `aimchamp_v3.0.4.apk`：

1. 打开链接后先「转存到我的网盘」，再从自己的网盘把文件下载到手机或电脑；
2. 电脑端拿到文件后，可以直接传给手机（数据线、局域网工具都行），也可以先留在电脑上校验 MD5 再传；
3. 手机浏览器直接下载的话，去文件管理器的 `Download` 目录找 apk，留意别点成名字带 `(1)` 的重复副本。

## 三、校验 MD5（建议做）

MD5 对上了，就说明这份安装包完整、没有被改动过。电脑上最省事的办法：

```powershell
certutil -hashfile "aimchamp_v3.0.4.apk" MD5
```

输出里那串十六进制，忽略大小写后等于 `EFC46CDF18F2700483ADCC2334F9203D` 就没问题。对不上就不要装，回到第二节重新拿一份。

## 四、安装步骤

1. 在手机上点开 apk，系统若提示「禁止安装未知来源应用」，按提示允许浏览器或文件管理器安装，装完可以把该权限关回去；
2. 等安装进度走完，点「打开」；
3. 如果手机上装过旧版且签名不一致导致安装失败，需要先卸载旧版再装——卸载会清掉应用内的训练数据与自定义任务，动手前想清楚；
4. 首次启动若申请存储、网络这类常规权限，按需允许即可。

## 五、装好之后先做什么

1. 把手机横过来——训练场景是横屏画面；
2. 到设置里过一遍灵敏度与准星，具体步骤见 [灵敏度与准星设置指南.md](灵敏度与准星设置指南.md)；
3. 选一个最基础的任务打几把熟悉界面，然后再看 [练枪任务与模式详解.md](练枪任务与模式详解.md)。

装完打不开、闪退这类问题，直接翻 [常见问题与排查.md](常见问题与排查.md)。
