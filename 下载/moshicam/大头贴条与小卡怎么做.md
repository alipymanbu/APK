# Moshicam 大头贴条与小卡怎么做

> 竖版大头贴条（photobooth strip）和 K-pop 风小卡（photocard）是 Moshicam 用户做得最多的两种成品，官方指南对两者各有一套流程。本篇把做法合在一页讲清。

## 一、大头贴条：把几张照片连成一条

大头贴条的成败在选照片，不在装饰。官方指南给出的做法：

1. **选同一时刻的照片**：同一天、同一套衣服、同一群人、同一个桌面摆设，或同一场演出的截图。四张照片如果各来自不相干的日子，成品就不像机器吐出来的那条纸。
2. **先选竖版框再装饰**：开贴纸之前，先从素材库挑一个大头贴（Photo Booth）、胶片条（Film Strip）或复古窗口样式的竖版框，让框承担「机器感」。
3. **最好的一张放最上面**：第一格是整条的钩子，放最清晰的脸、最有趣的表情或最干净的照片，中间几格可以随意些。
4. **只挑一个贴纸家族**：爱心、蝴蝶结、小宝石、相机贴纸选一类，重复使用；每格换一个贴纸包会变成手账页而不是大头贴条。贴纸避开眼睛和脸。
5. **按竖版导出**：这种长条图最适合发限时动态、当锁屏或做轮播图里的一页。想发方形 feed，导出时在四周留些空白，别硬裁。

社区里常见的选题可以直接套：宠物入镜条、桌面物件条（不用露脸）、演唱会暗色调条（配小宝石贴纸）、旅行条（照片共享一个颜色线索，比如蓝天或暖色花）。

## 二、小卡：一张照片做成卡片

K-pop 风格的小卡适合用一张好看的照片做成「能当壁纸、能发粉丝帖」的成品，官方流程：

1. **裁切干净**：先把照片裁到能突出人物的程度，别带杂乱背景。
2. **套卡片式边框**：选照片卡（photo card）类边框，让一张普通照片变成设计过的卡面；素材库里有星星表情、蝴蝶结等卡片风模板。
3. **贴纸点缀一两处**：小卡的空间小，贴纸只起点缀作用，两三件就停。
4. **导出两个用途**：一版发粉丝帖，一版当锁屏。当壁纸的那版注意留出手机状态栏的位置。

## 三、photo dump：一组照片的合集封面

如果想发的是「周末流水账」式多图，官方指南叫 photo dump：做一张带边框的封面图，配上几张原样照片，封面负责定调，素图保持随意感。封面用上面第一节的竖版或方版框做都行，碎图越多，封面越要简单。

## 四、两种成品怎么选

| 你手里的照片 | 更适合做 |
| --- | --- |
| 同一刻的三四张连拍、镜像自拍 | 大头贴条 |
| 单张画质好的人物照 | 小卡 |
| 不同场景的十几张日常照 | photo dump 配封面 |
| 演唱会、展会的截图组 | 大头贴条（暗色框） |
