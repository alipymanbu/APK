## 一、这是个什么应用

MyBoy 模拟器（官方英文名 My Boy! - GBA Emulator，开发者 Fast Emulator）是安卓上的 GBA 模拟器：装上它，再配合你自己准备的游戏文件，就能在手机上玩 Game Boy Advance 的游戏。它自带高层 BIOS 模拟，**不需要你另外去找 BIOS 文件**，装好就能直接载入游戏。

两点先说清楚，免得下错东西：

- **它只模拟 GBA**。更早的 GB / GBC 游戏它不认，同一开发者的 My OldBoy! 才是管那一段的。
- **应用本身不带任何游戏**，游戏文件需要你自己放到手机存储里。

## 二、先核对手上这份安装包

各下载站给的版本号与体积常年对不上，**你实际要装的以拿到手的这份为准**。下面这张表是本篇依据的那一份：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.0.9 |
| 包名 | `com.fastemulator.gba` |
| 安装包大小 | 10.49M |
| MD5 | `ef476cb8b0c333c10fcc0ee4c8dd6b60` |
| 保存日期 | 2026-09-23 |

**包名值得单独留意**：应用商店里还有一个免费版，包名是 `com.fastemulator.gbafree`，跟这份不是同一个包，功能也有差别（见第五节）。装完想确认装的是哪个，查包名最直接。

系统要求各渠道标注不一（有标 Android 5.0 以上、也有标更高的），实际以你的设备能不能正常安装、启动为准；装不上先看 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 三、把安装包取到手并装上

**MyBoy 模拟器 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/32eb1c72e82d](https://pan.quark.cn/s/32eb1c72e82d)

1. 打开上面的分享链接，转存到自己的网盘，再把安装包下载到手机（也可以先下到电脑再传手机）。
2. 下载完先核对大小是不是 10.49M 左右——差得多说明拿的不是这份。要更严格的校验，在 Windows 上算一次 MD5：

```powershell
certutil -hashfile "Myboy模拟器_v2.0.9.apk" MD5
```

算出来的值与表格里的 `ef476cb8b0c333c10fcc0ee4c8dd6b60` 一致（不区分大小写），说明文件完整没下残。

3. 在手机上点开这个 `.apk` 安装。系统弹「禁止安装来自此来源的应用」时，按提示进入设置，给**你用来打开这个文件的那个应用**（文件管理器、浏览器等）放行安装权限，再返回继续。
4. 装完先打开一次，能进到文件浏览界面就算装好了。

之后想升级：直接拿新版本的 apk 覆盖安装即可，应用数据与存档不会因此丢失（存档位置见 [存档怎么导入与备份.md](存档怎么导入与备份.md)）。

## 四、载入第一个游戏

**支持的文件格式**：文件名以 `.gba`、`.bin`、`.zip` 结尾的都认。`.zip` 会加载压缩包里**第一个能识别的文件**，所以不用先解压。

1. 建议在手机存储里建一个固定文件夹（例如 `GBA游戏/`）专门放游戏文件，以后管理、备份都省事；
2. 打开应用，界面就是一个文件浏览器，逐级进到你放游戏的那个文件夹；
3. 点游戏文件，直接载入运行。

几个首次使用会碰到的点：

- 提示 `Unrecognized GBA file`？多半是文件本身的问题，四条原因逐条排查见 [常见问题与解决方法.md](常见问题与解决方法.md)；
- 想横屏玩、想挪虚拟按键的位置，见 [横屏与按键布局怎么调.md](横屏与按键布局怎么调.md)；
- 退出应用的干净方式是：调出菜单（游戏画面**左上角**的 MENU 按钮，或设备的菜单键）→ 选 `Close`，而不是直接按 Home 甩出去。

## 五、免费版和完整版差在哪

商店里的免费版（`com.fastemulator.gbafree`）与完整版是两个包。官方在免费版页面列过完整版多出来的东西，整理如下（以[官方商店页面](https://play.google.com/store/apps/details?id=com.fastemulator.gbafree)当时显示为准）：

| 能力 | 免费版 | 完整版 |
| --- | --- | --- |
| 广告 | 有 | 无 |
| 从模拟器菜单存/读多个即时存档槽、自动存读 | 不提供（用游戏内建存档） | 提供 |
| 存档同步到 Google Drive | 不提供 | 提供 |
| 快进速度 | 受限 | 超过 2x、最高 16x |
| 一条金手指里写多行代码 | 不提供 | 提供 |
| 陀螺仪 / 倾斜传感器模拟 | 不提供 | 提供 |
| 联机时作为服务器端 | 不提供（只能作客户端接入） | 提供 |
| 多套屏幕布局配置档 | 不提供 | 提供 |

本篇依据的这份安装包包名是 `com.fastemulator.gba`。两边的界面与核心玩法一致，你先用哪个都能把游戏跑起来；功能上具体哪几项会碰到，用到了再回头查这张表即可。

## 六、长按游戏列表：补丁与桌面快捷方式

游戏列表里**长按**某个游戏会弹出操作菜单，两件有用的事在这里：

- **打补丁（IPS / UPS）**：把补丁文件（`.ips` / `.ups`，**大小写要与文件名一致**）放进游戏文件所在的目录，且**主文件名与游戏文件完全相同**——游戏是 `ABCD.gba`，补丁就得叫 `ABCD.ips` 或 `ABCD.ups`，之后正常载入游戏即可生效。不想每次都临时比对，可以在长按菜单里选 `Patch`，直接生成一个已打好补丁的新游戏文件，之后启动更快；
- **建桌面快捷方式**：官方功能列表里含「给常玩的游戏建桌面快捷方式」，长按弹出的菜单里找对应项（不同版本菜单项名略有出入）。建好后从桌面一点直达游戏，不用每次进文件浏览器翻目录。

玩起来发卡、掉帧的，调法不在这里，见 [游戏卡顿掉帧怎么调.md](游戏卡顿掉帧怎么调.md)。
