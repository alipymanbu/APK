# MyBoy 模拟器常见问题与解决方法

## 一、载入游戏时提示 Unrecognized GBA file

按四条查，命中哪条改哪条：

1. **文件根本不是 GBA 游戏**——比如那是 GB / GBC 时代的文件。MyBoy 模拟器只认 GBA，GB/GBC 要用同厂的 My OldBoy!；
2. **`.zip` 带了密码**——压缩包加密的它打不开，去掉密码重新打包；
3. **文件损坏或不完整**——常见于用手机浏览器下载中断留下的半截文件，重新下一次、或核对体积与 MD5（见 [下载与安装教程.md](下载与安装教程.md) 第二节）；
4. **文件其实不存在**——开过 USB 存储（MTP）拷文件后忘了关，目录看着在、实际已卸载，关掉 USB 存储模式再进。

## 二、以前能玩的游戏现在进不去

官方给的两条原因都在「设置 → 杂项」里，逐个关掉再试：

1. **金手指把它搞崩了**：关掉 `启用金手指`（Enable cheats）开关再启动；需要的话回头检查码本身，见 [金手指怎么用.md](金手指怎么用.md) 第三节；
2. **损坏的即时存档**：如果你开了 `启动时快速读档`（Quick load on start），坏快照会把游戏带崩——关掉它再启动，坏档的处理见 [存档怎么导入与备份.md](存档怎么导入与备份.md)。

两条都关掉就能进的话，说明问题出在对应的那份数据上，不是应用装坏了。

## 三、闪退、随机崩溃

- 先到手机的**系统设置 → 应用 → MyBoy 模拟器**里清一次缓存，再重启应用；
- 检查应用有没有**存储读写权限**（读游戏、写存档全靠它）；
- 装完就闪退、连界面都进不去：多半是安装包不完整，按 [下载与安装教程.md](下载与安装教程.md) 第二节核对体积与 MD5 后重装；
- 老旧机型上的随机崩溃，官方结论是部分早期 CPU/系统固件自身的缺陷，属于机型问题，能做的就是上面几条缓解。

## 四、没声音，或声音卡顿、有杂音

1. 确认没把手机调成静音、也没被勿扰模式压住；
2. 到应用的**设置 → 声音**里调整音频缓冲 / 延迟档位——缓冲偏小容易爆音，偏大则延迟明显，逐档试到画面与声音对得上；
3. 游戏过程中有系统通知音、其它应用在放声音，也会打断音频流，玩的时候留意关掉；
4. 声音总在画面卡顿时一起断的，症结其实在帧率，改看 [游戏卡顿掉帧怎么调.md](游戏卡顿掉帧怎么调.md)。

## 五、黑屏或花屏

- 先回到 [下载与安装教程.md](下载与安装教程.md) 第四节核对文件格式：只认 `.gba` / `.bin` / `.zip`，且 `.zip` 取的是包里第一个可识别的文件；
- 格式没问题就是文件本身坏了，换个来源重新获取；
- 只在某一个游戏上黑屏、别的游戏正常，优先怀疑那个游戏文件，而不是全局设置。

## 六、即时存档读不出来

即时存档是模拟器内部快照，**跨版本不保证兼容**：升级应用、换了游戏文件后旧快照可能失效。长期进度请以游戏内存档（`.sav`）为准，两类存档的区别与迁移办法见 [存档怎么导入与备份.md](存档怎么导入与备份.md)。

## 七、按键按不动、只能同时按两个键

这是触摸屏触点识别数量的限制，不是模拟器故障。缓解办法（斜向错开按键、映射实体键、接手柄）集中写在 [横屏与按键布局怎么调.md](横屏与按键布局怎么调.md) 第四节。

## 八、联不上的几条常见原因

服务器/客户端角色选反（免费版当不了服务器）、两台设备一条走了蓝牙一条走了 Wi-Fi、Wi-Fi 模式下 IP 端口输错、不同游戏联机时设备上缺另一个游戏文件——逐条对照 [联机对战怎么连.md](联机对战怎么连.md)。连上后周期性卡顿，按该篇第六节处理。

## 九、界面全是英文，能改成中文吗

有教程给出的路径是：`Settings` → `System` → `Language` → 选 `Chinese`。**这是单一来源的说法**——如果你的版本里没有这一项，说明这版没有内置中文界面，属正常现象；菜单是英文不影响任何功能，各项菜单的中文对照可以对照本目录下各篇的写法认（如 `Cheats` = 金手指、`Link remote` = 远程联机、`Close` = 退出）。

## 十、玩一阵之后才开始卡

多半是机身发热降频，不是应用坏了。清后台、摘手机壳、别边充边玩，再按 [游戏卡顿掉帧怎么调.md](游戏卡顿掉帧怎么调.md) 逐项调帧跳过与渲染。
