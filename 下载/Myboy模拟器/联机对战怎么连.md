## 一、开始前先确认三件事

1. **两台设备都装好并能各自跑起游戏**，做法见 [下载与安装教程.md](下载与安装教程.md)；
2. **角色分工**：联机要一台当服务器、一台当客户端。完整版两种角色都能当；**免费版只能作为客户端接入，当不了服务器**（这条列在官方免费版页面的功能差异里）；
3. **链路二选一**：蓝牙（近距离、无需网络）或 Wi-Fi（可跨房间）。两台设备走的必须是同一种。

## 二、蓝牙连法

1. 服务器端：调出菜单 → `Link remote` → `Bluetooth (server)`，弹出「等待传入连接」的对话框；
2. 客户端：菜单 → `Link remote` → `Bluetooth (client)`，会出现附近设备列表；
3. 列表里没看到对方？在服务器端点 `Make discoverable`（使本机可被发现），再到客户端点 `Scan for devices`（搜索设备），对方就会出现，选中它；
4. 没配对过的设备中途会弹配对请求，确认即可。连上后回到游戏，触发联机剧情（如交换、对战）就能通。

## 三、Wi-Fi 连法

1. 服务器端：菜单 → `Link remote` → `Wi-Fi (server)`，对话框会显示**本机的 IP 与端口号**；
2. 客户端：菜单 → `Link remote` → `Wi-Fi (client)`，在弹窗里**手动输入服务器显示的 IP 和端口**；
3. 输入无误即连接成功。

两台设备都支持 Android Beam 的话有个捷径：各自打开游戏后，把两台手机**背靠背贴一下**，会直接建连，省掉手输 IP。

## 四、两人不在同一个 Wi-Fi 下怎么办

让其中一台开「便携式 Wi-Fi 热点」，另一台连上这个热点。注意角色选择的细节：**在「没有开热点」的那台选 `Wi-Fi (server)`，开热点的那台选 `Wi-Fi (client)`**，后续步骤与普通 Wi-Fi 相同。

## 五、连不同的游戏（比如两个版本互换）

可以，但有个常见误解要澄清：**两台设备上都得同时存在这两个游戏文件**。比如你的 A 版要和对方的 B 版交换，你的手机里要有 A 和 B，对方手机里也要有 A 和 B。缺哪个，联机时模拟器会提示你去定位这个文件。

## 六、连上了却每隔几秒卡一下

Wi-Fi 联机时若「卡一下、又顺一阵」地周期性出现，优先关掉系统设置里的**后台同步**（联系人、日历、账号同步那一类），把无线资源让给联机链路。仍不稳再排查：两台设备距离、路由器是否开了省电模式、蓝牙链路是否被其它设备干扰。

联机中交换到的进度是写进存档的，想确认或备份，见 [存档怎么导入与备份.md](存档怎么导入与备份.md)；连接类的其它异常汇总在 [常见问题与解决方法.md](常见问题与解决方法.md)。
