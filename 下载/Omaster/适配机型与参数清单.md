OMaster 管理的是相机「大师模式」的调色参数，而大师模式本身是各品牌相机里的一个拍摄模式，所以它的适配情况直接取决于你用的是什么手机。装机之前先确认这一篇，能避免「装好了却套不上参数」的情况。

## 一、机型适配情况

| 机型 | 适配情况 |
| --- | --- |
| OPPO（ColorOS） | 主要适配对象，参数与大师模式逐项对应 |
| 一加（OxygenOS） | 主要适配对象，参数与大师模式逐项对应 |
| realme | 主要适配对象，参数与大师模式逐项对应 |
| 其他安卓手机 | App 能装、能看参数、能用悬浮窗，但相机里未必有同名调节项，参数可能套不全 |
| iPhone | 截至 2026-09，公开渠道只有安卓安装包，没有 iOS 版 |

两点补充：

- 一加与 OPPO 的系统同源（ColorOS / OxygenOS），相机专业模式的调节项基本一致，所以这三类机型是同一套参数体系。
- 其他品牌的安卓机用悬浮窗对照参数这一步没问题，只是相机里找不到对应滑杆时，那部分数值就用不上。

另外要知道：OPPO 官方自己也带一套类似的东西——新版 ColorOS 在「使用技巧」App 里有「大师影调库」，还支持用 AI 一键闪记把看到的大师参数存进相机（截至 2026-09 的系统功能，以你的系统版本为准）。两边可以并存：官方影调库走系统相机内置路径，OMaster 走悬浮窗对照，用哪个看你的拍摄习惯。

## 二、支持的大师模式参数清单

OMaster 的预设与悬浮窗里出现的参数，包含以下两类：

| 类别 | 参数项 | 说明 |
| --- | --- | --- |
| 基础参数 | 滤镜 | 风格滤镜的选择与强度 |
| 基础参数 | 柔光 | 画面柔化程度 |
| 基础参数 | 影调 | 明暗基调 |
| 基础参数 | 饱和度 | 色彩浓淡 |
| 基础参数 | 冷暖 | 色温倾向 |
| 基础参数 | 青品 | 青色与品红倾向 |
| 基础参数 | 锐度 | 轮廓锐化程度 |
| 基础参数 | 暗角 | 四角压暗程度 |
| 专业参数 | ISO | 感光度 |
| 专业参数 | 快门速度 | 曝光时长 |
| 专业参数 | 曝光补偿 | 整体曝光加减 |
| 专业参数 | 色温 | 色调偏冷偏暖 |
| 专业参数 | 色调 | 绿色与品红方向的微调 |

多数日常场景的预设只用基础参数；夜景、灯光这类场景的预设才会带 ISO、快门速度这类专业参数。你的相机里有哪几项滑杆，就照着悬浮窗设哪几项，缺的那项跳过即可。

## 三、参数怎么在相机里对上号

以 OPPO 系手机为例，套用一条预设的完整动作是：

1. 打开相机，切到**专业模式**（部分机型的入口在「更多」里，名称可能显示为大师模式或 PRO）。
2. 对照 OMaster 悬浮窗里的数值，逐项调：先设滤镜、影调、饱和度这些画面风格的项，再设 ISO、快门速度这类曝光的项。
3. 取景确认效果，不满意就回悬浮窗左右滑动换一条预设再对一遍。

不同系统版本的专业模式入口和参数排布略有差异，找不到某一项时，先在相机设置里确认专业模式是否开启。每个滑杆具体怎么调、哪些参数在相机里能精确复刻、哪些只能靠后期补，在 [相机专业模式怎么调参数.md](相机专业模式怎么调参数.md) 里有逐项对照。

## 四、版本与参数范围的对应关系

参数清单会随预设更新慢慢扩，新的风格预设可能带新的参数组合；App 本身的预设库支持云更新，参数范围以你实际用到的版本为准。这份清单对应的是安装包 1.2.0，之后新增了什么风格与参数，可以在 [更新日志与新版本说明.md](更新日志与新版本说明.md) 里对版本号确认；具体用法走 [悬浮窗与预设参数用法.md](悬浮窗与预设参数用法.md)，安装包从 [下载与安装教程.md](下载与安装教程.md) 拿。
