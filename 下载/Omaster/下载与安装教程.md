OMaster 是一款安卓相机辅助工具，主要面向 OPPO、一加、realme 手机的摄影爱好者，用来管理相机大师模式的调色参数，拍摄时可以开半透明悬浮窗对照参数。它通过 APK 安装文件分发，应用商店里不好找，安装前需要先把安装文件拿到手，再手动安装。本篇按「转存 → 下载 → 安装 → 首次打开」的顺序走一遍。

## 一、安装包基本信息

下面这份信息对应网盘资源里的那个安装包，以它为准（网上能搜到的最新版可能编号更高，但不是同一份文件）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.2.0 |
| 包名 | com.silas.omaster |
| 大小 | 40.75M |
| MD5 | 798C7F827A33D790017256383B476A4F |
| 系统要求 | 安卓 5.2 及以上（以安装包信息为准） |

装之前可以核对一下文件大小，确认下载完整；对 MD5 有需要的话，可以用文件管理器或校验工具算一遍，与上表比对。

## 二、从网盘拿到安装文件

1. 打开 **OMaster 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/2ef64daf0e39](https://pan.quark.cn/s/2ef64daf0e39)。
2. 手机上装了夸克 App 的话，点链接会直接跳到分享页；电脑上则可以在浏览器打开。
3. 把文件**转存到自己的网盘**，再从网盘把它下载到手机存储里。直接在线预览是装不了的，必须先落地成手机里的 APK 文件。
4. 下载完成后记住存放位置，一般在 `Download`（下载）目录。

## 三、安装步骤

安卓对「应用商店之外的安装包」有授权门槛，OMaster 的 APK 属于这一类，第一次装会碰到提示，按下面的路子处理：

1. 用手机自带的文件管理器找到刚下载的 APK，点它。
2. 系统弹出「是否允许安装」或「未知来源」提示时，选择**允许/仍然安装**；部分系统会跳到设置页，把「允许此来源安装应用」的开关打开后返回重试。
3. 安装中途如果出现「未经过安全检测」之类的风险提示，这是安卓对商店外安装包的常规提示，确认继续即可；卡住不动的多是还在等你点确认。
4. 等安装进度走完，点「完成」或「打开」。
5. 如果点 APK 没反应，检查文件是否下载完整（对照上面的大小），或换一个文件管理器再试。

装好之后，桌面会出现 OMaster 的图标。它本身不联网也能用大部分功能（收藏、本地参数都在本机），预设内容的更新才需要网络。

## 四、装好之后先做两件事

1. **开悬浮窗权限**：OMaster 的核心用法是拍摄时悬浮显示参数，这个权限默认是关的。路径一般是「设置 → 应用 → 应用管理 → OMaster → 悬浮窗/显示在应用上层」，打开开关。如果打开时被系统拦，去看 [悬浮窗无法开启怎么解决.md](悬浮窗无法开启怎么解决.md)，那里有按机型系统的处理步骤。
2. **浏览一遍预设**：打开 App 后先在「全部」界面翻一翻有哪些风格，遇到喜欢的点右上角收藏，后面拍摄时用悬浮窗调出来最方便。具体操作见 [悬浮窗与预设参数用法.md](悬浮窗与预设参数用法.md)。

你的手机是不是 OPPO / 一加 / realme 系，会直接影响参数能不能在相机里逐项套用，装完后可以先对照 [适配机型与参数清单.md](适配机型与参数清单.md) 确认一下。
