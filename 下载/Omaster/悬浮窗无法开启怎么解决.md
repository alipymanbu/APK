# OMaster 悬浮窗无法开启怎么解决

> 悬浮窗是 OMaster 的核心用法，开不起来就等于白装。本篇按两种最常见的失败情形给出处理步骤。
> **相关文档**：[悬浮窗与预设参数用法.md](悬浮窗与预设参数用法.md) · [下载与安装教程.md](下载与安装教程.md)

OMaster 的悬浮窗依赖系统「显示在应用上层」的授权，而 ColorOS / OxygenOS 这类系统对这类权限管得比较紧，所以最常见的翻车点不是 App 本身，而是权限被拦。先对号入座：你是**权限开关都开不了**，还是**开了但悬浮窗盖不到相机上面**，两种情形的处理完全不同。

## 一、情形一：悬浮窗权限开不了

部分 ColorOS / OxygenOS 系统会把 OMaster 识别为「未知来源应用」，从而限制悬浮窗权限的授予，表现为开关点了没反应或直接弹提示。处理步骤：

1. 打开手机**设置 → 应用 → 应用管理**。
2. 在列表里找到 OMaster，点进去。
3. 进入**权限管理**。
4. 点右上角的菜单图标，选择**解除所有授权限制**。
5. 返回 OMaster，重新去开悬浮窗权限。

这一步做完，绝大多数「开不了」的情况就通了。如果解除限制后开关仍然置灰，重启一次手机再试；还不行就把系统设置里「纯净模式/安装来源管控」相关开关也检查一遍，这类管控有时会连带限制悬浮窗授权。

## 二、情形二：悬浮窗显示不到相机上面

权限开了，但回到相机取景时悬浮窗不出现。这是另一回事：部分定制安卓系统在系统层面限制第三方应用的悬浮窗显示在相机应用上方，这个限制不在 App 的权限里，App 侧没有开关可解。

能试的替代路子：

- 关掉相机再试一次，有的系统只拦「正在前台运行的相机」，先切出再切入偶尔能挂上。
- 不追求悬浮窗的话，改用分屏或者把参数页截屏，拍摄时对照截图设参数，效果一样，只是少了个能滑动切换的窗口。
- 如果你的机型就是属于系统底层限制的那一类，这些办法都无效，只能换一台没有这条限制的手机。

## 三、其他排查点

上面两种情形都对不上时，按顺序过一遍：

1. **悬浮窗权限确实开了吗**：路径是「设置 → 应用 → 应用管理 → OMaster → 悬浮窗/显示在应用上层」，开关要是打开状态。
2. **省电策略**：把 OMaster 从省电限制里放出来（允许后台运行），部分机型的省电策略会顺带杀掉悬浮窗。
3. **从正确的入口开**：悬浮窗是在预设详情页点**右上角分享按钮**开启的，不是在设置里，入口走错了自然出不来。具体操作见 [悬浮窗与预设参数用法.md](悬浮窗与预设参数用法.md)。
4. **重启**：权限改完不生效时，重启是最省事的收尾动作。

都试过还不行，说明你的系统版本对悬浮窗管得死，悬浮窗这条路走不通，参数本身还是能看的——只是要手动在 App 和相机之间来回切换。
