# OMaster 相机专业模式怎么调参数

> 悬浮窗里的数值要落到相机的专业模式里才会变成照片。本篇讲这个模式在哪、每个滑杆什么意思、以及 OMaster 的参数哪些能逐项对上、哪些对不上。

用 OMaster 最常见的中途卡点不是 App 本身，而是拿着悬浮窗里的一串数值进了相机，找不到地方设。这一篇把「相机侧」这一半讲清楚：入口在哪、滑杆各管什么、哪些参数能直接对上号。以下以 OPPO 系机型（ColorOS / OxygenOS）的相机为准，其他品牌的相机布局不同，但参数含义是一样的。

## 一、专业模式的入口

1. 打开「相机」。
2. 在拍摄模式那一排**右滑到「更多」**。
3. 找到并点选**「专业」**，进入专业模式。

不同系统版本的叫法和位置有差别：有的显示为「大师模式」或「PRO」，有的机型把它放在模式转盘上直接滑动切换。找不到时先在相机设置里确认专业模式有没有被隐藏。

## 二、每个滑杆是什么意思

进入专业模式后，能手动设的主要是下面这几项。点击其中一项，再左右滑动下方的滑条调数值；点 AUTO 类按钮可以在自动和手动之间切换。

| 滑杆 | 含义 | 调节效果 |
| --- | --- | --- |
| ISO（感光度） | 传感器对光的敏感程度 | 低 ISO 画面细腻；高 ISO 亮但容易出噪点 |
| S（快门速度） | 一次曝光的时长 | 拍奔跑、宠物这类动态要调快，否则糊 |
| EV（曝光补偿） | 在自动曝光上加减 | 画面整体偏暗加 EV，过亮减 EV |
| WB（白平衡） | 色温冷暖 | 日光灯下画面偏蓝、白炽灯下偏黄，调 WB 纠正或故意带色调 |
| AF / MF（对焦） | 自动 / 手动对焦 | MF 拧到近处拍前景虚化、拧到远处拍后景虚化 |

## 三、OMaster 的参数哪些能对上号

悬浮窗里的两类参数，落到相机滑杆上是「部分对得上」的关系，先有这个预期：

| OMaster 参数 | 相机里的落点 | 对得上吗 |
| --- | --- | --- |
| ISO、快门速度、曝光补偿、色温 | ISO、S、EV、WB 滑杆 | 直接对应，照着数值设 |
| 滤镜 | 相机的滤镜选项 | 对应，但滤镜名可能不同，选最接近的风格 |
| 饱和度 | 多数机型在滤镜的强度里 | 部分机型可调 |
| 冷暖、色调 | WB 的细分方向 | 部分机型只给一个 WB 滑杆，设个大概 |
| 柔光、影调、青品、锐度、暗角 | 相机里多半没有独立滑杆 | 对不上，留到后期 App 里调 |

所以实际套用一条预设时，**曝光类的四项（ISO / 快门 / EV / 色温）是能精确复刻的，风格类的项目主要靠滤镜和后期补**。这也是为什么同一条预设，不同人拍出来会有差别。

## 四、实操顺序

1. 先设风格：滤镜选好，WB 按预设的冷暖方向定。
2. 再设曝光：ISO 和快门按悬浮窗数值设；拍夜景用低 ISO 配长快门时，手一定要稳，最好靠着支撑物，否则长快门会把画面抖糊。
3. 试拍一张，看亮度和噪点，按需微调 EV。
4. 拍动态主体时优先保证快门够快，ISO 高一点比拍糊了强。

悬浮窗在拍摄时被系统拦掉、盖不到相机上的情况另有一套排查路子，见 [悬浮窗无法开启怎么解决.md](悬浮窗无法开启怎么解决.md)；预设与悬浮窗的日常操作回 [悬浮窗与预设参数用法.md](悬浮窗与预设参数用法.md) 看。你的机型在不在适配名单里、参数范围有多大，见 [适配机型与参数清单.md](适配机型与参数清单.md)。
