## 一、三步读懂任何一个图标

不用背整张表，先看三个维度：

1. **形状**：箭头 = 你发出的东西；方块 = 对方发给你的东西。
2. **填充**：实心 = 还没被打开；空心（描边） = 已经被打开。
3. **颜色**：红 = 无声音的照片 Snap；紫 = 带声音的 Snap（视频或带音频的照片）；蓝 = 文字聊天；灰 = 有状况（待发送、已过期）。

三步组合起来，任何图标都能当场推出来。

## 二、你发出的（箭头，出现在对方名字旁）

| 图标 | 含义 |
| --- | --- |
| 红色实心箭头 | 你发了无声音 Snap，对方还没开 |
| 红色空心箭头 | 对方已打开你的无声音 Snap |
| 紫色实心箭头 | 你发了带声音 Snap，对方还没开 |
| 紫色空心箭头 | 对方已打开你的带声音 Snap |
| 蓝色实心箭头 | 你发了文字消息，对方还没看 |
| 蓝色空心箭头 | 对方已读你的文字消息 |
| 灰色实心箭头 | **待发送** —— 常见原因是对方还没加你为好友，或对方把你删了；箭头带小钟形则是发送卡住 |
| 红/紫/蓝空心圆箭头 | 对方**重播**（replay）了你发的那条 Snap |
| 双箭头（红/紫/蓝） | 对方**截屏**了你发的对应类型内容 |

## 三、你收到的（方块，出现在对方名字旁）

| 图标 | 含义 |
| --- | --- |
| 红色实心方块 | 收到无声音 Snap，你还没看 |
| 红色空心方块 | 你已看过这条无声音 Snap |
| 紫色实心方块 | 收到带声音 Snap，你还没看 |
| 紫色空心方块 | 你已看过这条带声音 Snap |
| 蓝色实心方块 | 收到文字消息，你还没读 |
| 蓝色空心方块 | 你已读这条文字消息 |
| 灰色空心方块 | 内容在你打开前就**过期**了（Snap 有有效期，没及时看就没了） |

## 四、好友名字旁的 emoji：关系与里程碑

这些 emoji 按你们的互动数据自动变化，常见几个：

| emoji（文字描述） | 含义 |
| --- | --- |
| 黄心 | 你们互为对方的第一好友 |
| 红心 | 互为第一好友已连续两周 |
| 粉色双心 | 互为第一好友已连续两个月（目前最高档） |
| 笑脸 | 对方是你的好友之一，但不是第一好友 |
| 墨镜 | 你们有共同的好友 |
| 金色星星 | 近 24 小时内有人重播了这个人的 Snap |
| 火焰 / 沙漏 / 数字 100 | Streak 进行中 / 快断了 / 已到 100 天 —— 规则见[Snapstreak规则与恢复.md](Snapstreak规则与恢复.md) |
| 蛋糕 | 这天是对方的生日 |

几点注意：

- 这套 emoji 是**自动升降档**的，掉了红心不能找客服恢复，客服也改不了；
- 个别 emoji（撇嘴、婴儿等）的准确含义**各版本与各来源说法不一致**，以你界面上的实际提示为准；
- 想换样式：`Settings` → `Additional Services` → `Manage` → `Friend Emojis`，可以逐个自定义 —— 换的只是图案，含义不变。

## 五、图标与状态不一致时

图标讲的是服务器记录的状态，偶尔会与实际对不上（比如显示已送达但对方说没收到）。判断真假：

- 看**图标旁边的文字**（`Delivered`、`Opened` 之类）与图标是否一致；
- 单条消息卡在灰色箭头，先按[常见问题与故障排除.md](常见问题与故障排除.md)排查网络；
- 图标含义本身会随版本微调，本文口径截至 2026 年 9 月的公开资料，以你当时版本的界面为准。
