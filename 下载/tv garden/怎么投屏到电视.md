# TV Garden 怎么投屏到电视上看

> 本篇讲把 TV Garden 的直播画面弄到电视大屏上的三条路线：应用内投屏、网页版加浏览器投屏、直接镜像手机屏幕，以及电视搜不到时的排查。

## 一、先选路线

| 路线 | 适合你，如果 | 需要的东西 |
| --- | --- | --- |
| 应用内投屏按钮 | 播放画面上本来就有投屏图标 | 支持 Cast 的电视或电视盒子 |
| 网页版 + 浏览器投屏 | 家里电视能联网，不想折腾安装 | 电视上的浏览器，或电脑/手机 + Chrome |
| 屏幕镜像 | 电视支持无线投屏，前两条都走不通 | 手机与电视支持同一套镜像协议 |

三条路线都要求**手机/电脑和电视连在同一个 WiFi** 下，这是绝大多数「搜不到设备」的根源。

## 二、先看看应用里有没有投屏按钮

打开 TV Garden 播一个频道，在播放画面上找找有没有投屏样式的图标（一个带波纹的小屏幕）。有站点称这个应用支持向 Chromecast 类设备投屏，投屏时手机可以当遥控器继续用——但这一说法未经过多方印证，你的版本里有没有这个入口，以实际界面为准。找不到就走第三、四节的路线。

## 三、网页版 + 浏览器投屏

网页版（见[手机版与网页版的区别](手机版与网页版的区别.md)）在 Chrome 里打开后，可以直接用浏览器的投送功能：

1. 电脑 Chrome 打开你收藏的 TV Garden 网页版地址，播一个频道。
2. 点右上角三点菜单 →「投送、保存和共享」→「投送」（菜单名随 Chrome 版本略有差异，认「投送/Cast」字样）。
3. 从列表里选你的 Chromecast 或内置投屏功能的电视。
4. 画面上电视后，手机/电脑只当遥控器。

安卓手机上的 Chrome 也有同样的「投送」菜单项。这条路对电视的要求最低——老电视插个 Chromecast 类的盒子就行。

## 四、直接镜像手机屏幕

镜像和投送不同：镜像把手机整个屏幕原样复制到电视上，手机上有什么电视就有什么：

- **安卓手机**：下拉快捷设置找「无线投屏」「Smart View」「多屏互动」（名称随品牌不同），选你的电视。
- **iPhone**：控制中心 →「屏幕镜像」→ 选 AirPlay 设备（Apple TV 或支持 AirPlay 的电视）。

镜像的代价是画面经过手机转一道，延迟和画质都不如原生投送，操作手机时电视也会跟着显示。应急看球够用，长期看建议走第二、三节。

## 五、电视没出现在列表里

按命中率排序：

1. **确认两边连的是同一个 WiFi**：路由器常有「主网络」和「访客网络」之分，2.4G 与 5G 一般不影响，访客网络通常会隔离设备。
2. **部分路由开了 AP 隔离**：网页都能上但设备互相看不见，进路由设置关掉「AP 隔离/访客隔离」。
3. **iPhone 先给本地网络权限**：iOS 需要在设置里允许相关应用访问本地网络，否则发现不了投屏设备。
4. **重启电视与路由**：投屏设备的发现服务卡住时最有效的一招。

## 六、投上去了但卡顿

- 镜像路线的卡顿多半在 WiFi：手机离路由器近一点，或关掉其他在占带宽的下载/设备。
- 直播高码率频道（体育赛事）比新闻台吃带宽，投屏时尤其明显。
- 有线网口能给电视或盒子稳定的回程带宽，条件允许就插网线。

装到盒子上直接看而不是投屏，是另一条更彻底的路，见[装到电视盒子上的步骤](装到电视盒子上的步骤.md)。
