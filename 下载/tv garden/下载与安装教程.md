## 一、装之前先对一遍信息

TV Garden 是一款免费的安卓直播电视应用，打开后通过 3D 地球仪选国家、看频道，不需要注册账号。动手安装前，先核对手上这份安装包的关键信息：

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.0 |
| 包名 | `com.tvgarden` |
| 安装包大小 | 约 5.72 MB |
| MD5 | `93FD10E00E13EB61893226EFB7F5B99F` |
| 系统要求 | 安卓 5.2 以上 |
| 安装包整理日期 | 2026-09-23 |

几点说明：

- 网上不同站点对 TV Garden 的版本号说法不一（有写 1.0.0 的，也有写更高版本的），本文以你实际拿到的安装包为准，别被「最新版」字样带偏。
- 安装包只有 5.72 MB，对存储空间基本没有压力，老手机也能装。
- 装完想确认是不是这一份，在系统的应用信息里看包名是不是 `com.tvgarden` 就行。

## 二、从哪拿到安装文件资源

安装包放在夸克网盘里。打开 **[tv garden 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ec401e3c1700)** → 转存到自己的网盘（页面会提示先登录夸克账号）→ 在自己的网盘里找到 `tv garden_v1.0.apk` 下载到手机。转存和下载都是常规网盘操作，没有夸克账号的话按页面提示注册一个即可。

## 三、在安卓手机上安装的步骤

1. 把上面那份 `tv garden_v1.0.apk` 下载到手机（记住下载位置，一般在「下载」文件夹）。
2. 打开手机「设置」→「安全」（部分机型在「更多设置」或「应用管理」里），找到「安装未知应用」/「未知来源」这一项。
3. 给你用来打开安装包的那个应用（文件管理器或浏览器）授予「允许安装未知应用」的权限。
4. 用文件管理器找到 APK，点它 → 点「安装」，等进度走完。
5. 装完点「打开」，第一次启动会直接进到地球仪界面。

安卓 8.0 以后的系统按「按应用授权」管理未知来源安装：只授权给文件管理器这一个应用即可，不用全局放开。

## 四、安装时容易碰到的提示

| 提示 | 通常的原因 | 怎么处理 |
| --- | --- | --- |
| 「安装包解析失败」/「解析包时出现问题」 | 文件没下完整，或下载中途被改名 | 重新下载一遍；有条件的话核对 MD5 是否为 `93FD10E00E13EB61893226EFB7F5B99F` |
| 「安装」按钮是灰的点不了 | 后台有清理/拦截类应用在干扰 | 关掉那类应用再装 |
| 提示「存在风险」/停止安装 | 这是应用商店以外安装 APK 时的系统提示，不针对这个应用 | 自行判断来源后选择「仍要安装」；拿不准先读[常见问题解答](常见问题解答.md) |
| 提示与已安装应用冲突 | 手机里已有同包名的旧版本 | 先卸载旧的再装 |
