## 一、为什么会有两个「TV Garden」

你搜到的结果里，一类是**安卓安装包（APK）**——装进手机、有独立图标的那种，也就是本套文档讲的那份；另一类是**网页版**——不装任何东西，用浏览器打开网站就能看，有的网站还会引导你「添加到主屏幕」，装出来一个长得像应用的快捷方式。

两边是同一类服务：都能看全球直播频道、都有按国家或地球仪选台的玩法、都不用注册。区别在于载体和更新方式。

## 二、逐项对照

| 对比项 | 手机版（APK） | 网页版 |
| --- | --- | --- |
| 获取方式 | 下载安装包安装（见[下载与安装教程](下载与安装教程.md)） | 浏览器打开网站即可 |
| 设备要求 | 安卓 5.2 以上的手机/盒子 | 不限设备，手机/电脑/平板都行 |
| 独立图标 | 有 | 可手动「添加到主屏幕」生成快捷方式 |
| 更新 | 换新版本要重新下载安装包 | 打开就是当前版本，无需操作 |
| 打开速度 | 装好后点图标即开 | 依赖浏览器，首次加载要联网 |
| 权限 | 按 APK 的权限申请来 | 浏览器沙箱内运行，权限最小化 |
| 电视盒子/电脑 | 盒子可侧载，步骤见[装到电视盒子上的步骤](装到电视盒子上的步骤.md)；电脑要模拟器 | 有浏览器就能看，大屏更省事 |

## 三、怎么选

- **主力在手机上看**：装 APK 版。装好就有图标，点开就用，不用先开浏览器。
- **主要在电脑或电视上看**：用网页版，省去模拟器和侧载的折腾；想在电视上看的三条路线（投屏/镜像/侧载）见[怎么投屏到电视](怎么投屏到电视.md)。
- **两个都要**：也常见——手机装 APK 出门用，家里大屏开网页版，频道体验一致。

## 四、把网页版装成应用的样子

网页版在各设备上都能生成一个「像应用」的入口，方法以浏览器实际菜单为准：

| 设备 | 做法 |
| --- | --- |
| 安卓手机（Chrome） | 三点菜单 →「安装应用」/「添加到主屏幕」 |
| iPhone/iPad（Safari） | 分享按钮 →「添加到主屏幕」 |
| Windows（Edge） | 三点菜单 →「应用」→「将此站点作为应用安装」 |
| Mac（Safari，较新系统） | 菜单栏「文件」→「添加到程序坞」 |

装出来的入口打开时没有浏览器地址栏，观感与普通应用接近，但本质上还是网页——更新、频道列表都不需要你手动维护。

## 五、不管用哪边都要知道的事

1. **频道可用性两边一样会变**：黑屏、下线、地区限制在哪边都存在，排查思路见[频道加载失败怎么办](频道加载失败怎么办.md)。
2. **认准入口**：两类站点里都有互相矛盾的「官方」说法。安装包固定从你信任的入口拿并留存记录，网页版认准你验证过能正常播的域名、自己收藏，别每次重新搜。
3. **流量消耗**：直播看久了流量跑得快，用流量看的话心里有数。
