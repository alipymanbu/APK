## 一、离线缓存：先把剧集下到手机

适合通勤、出差、地铁信号差这些场景 —— 提前缓存，路上不费流量也不卡。

**缓存步骤**：

1. 进入想看的那部番的**播放页**。
2. 点下载/缓存图标（向下箭头），弹出集数列表。
3. 勾选要下的集数，可多选，点开始下载。
4. 想看进度，点**查看下载列表**，能看到每集的下载状态；下载在后台进行，你可以退出页面继续干别的。

**管理缓存**：回到**我的 → 离线缓存**，已下载的剧集都在这里，可以直接播放，也能删除不需要的。

几点实在提醒：

- 缓存前算下空间：几十集下来占的体积不小，先在「我的 → 离线缓存」里清掉看过的。
- **用文件管理器找不到这些视频**：缓存存在应用的私有目录里，外部文件管理器一般翻不到，这是系统限制不是出错 —— 想看、想删，只走「我的 → 离线缓存」这一条路。
- **删了找不回**：缓存文件误删不能恢复，只能重新下载，所以清理前看一眼有没有还没看的集数。
- 缓存的是**视频文件、存在手机本地**，不跟账号走 —— 换手机或卸载重装就没了，见 [注册登录与账号使用.md](注册登录与账号使用.md)。
- 下载不动、卡在 0%，多半是网络或线路问题，处理办法在 [播放卡顿与常见问题排查.md](播放卡顿与常见问题排查.md)；下载时想指定清晰度，见 [画质倍速与弹幕怎么调.md](画质倍速与弹幕怎么调.md)。

## 二、投屏到电视

投屏是把画面从手机推到电视上放，手机当遥控器。

**操作步骤**：

1. 手机和电视**连同一个 WiFi**（这一步最关键，不在同一网络根本搜不到设备）。
2. 打开 mifun，进入播放页。
3. 点右上角的**投屏/TV**按钮。
4. 等列表里出现你的电视或投屏设备，点它就连上了，之后画面在电视上播。

**连不上时按顺序查**：

1. 手机和电视是不是**同一个 WiFi**（连了蜂窝数据或另一个访客网络都不行）。
2. 电视那侧的投屏功能有没有开、是否处于**可被发现**的状态（电视自带的投屏/镜像开关要在设置里打开）。有资料提到，部分电视还得先装一个投屏协议插件才会出现在设备列表里 —— 列表一直空着时，去电视的应用商店或投屏设置里找找这类插件。
3. 路由器离得远、隔了承重墙 —— 手机和电视都往路由器靠一靠，或改用 5GHz 频段，带宽更稳。
4. 同一网络里有别的设备在大流量下载（后台更新、网盘同步），先暂停，让带宽让给投屏。
5. 还不行就重启路由器和电视，再从第 3 步重试一次。

投屏本身卡、画面断续，通常不是 mifun 的问题，而是网络带宽不够，直接看 [播放卡顿与常见问题排查.md](播放卡顿与常见问题排查.md) 里的卡顿条目。

## 三、缓存 vs 投屏，什么时候用哪个

| 场景 | 用缓存 | 用投屏 |
| --- | --- | --- |
| 地铁 / 飞机上一个人看 | 适合 | 不适合 |
| 家里客厅大屏看 | 不需要 | 适合 |
| 流量紧张 | 适合（WiFi 下提前下） | 不适合（占带宽） |
| 手机电量告急 | 适合（下完再看） | 不适合（投屏时手机全程亮着） |

两件事都在播放页完成，找番与追番的安排则见 [找番与追番时间表怎么用.md](找番与追番时间表怎么用.md)。
