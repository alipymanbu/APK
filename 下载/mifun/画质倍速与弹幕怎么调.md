## 一、先说在哪调：都在播放页

mifun 的播放相关开关基本都收在**播放页**：点一下画面出控制条，清晰度、倍速、弹幕、字幕、来源、投屏、缓存都在那一条上（不同版本按钮排序略有差异，找图标即可）。全局层面的开关（比如默认设置、清除缓存）在**我的 → 设置**里。

具体按钮位置随版本会挪动，以你手机上看到的为准；下面讲的是每项**怎么选**，这部分不会变。

## 二、清晰度怎么选

| 网络环境 | 建议档位 | 理由 |
| --- | --- | --- |
| 家里 WiFi 稳定 | 超清 / 高清 | 带宽够，画面细节最好 |
| 一般 WiFi、多人共用 | 高清 | 高清与超清在手机屏上差距有限，加载更稳 |
| 移动数据 | 流畅 / 标清 | 先保证不断，再谈清晰度 |
| 播放卡、一直转圈 | 直接降到流畅 | 见 [播放卡顿与常见问题排查.md](播放卡顿与常见问题排查.md) |

切换是即时生效的，不用退出重进。看番时手动切一档，比等它自己卡住强。

## 三、倍速播放

倍速入口在播放控制条里，选好档位即可，**切换不会打断当前进度**，调回 1.0 倍也一样。补旧番、赶进度时开 1.25~1.5 倍比较合适；战斗作画、配乐重要的段落建议调回原速。

倍速只影响当前播放，不会改掉你下一集的默认速度。

## 四、弹幕开关与调节

- **关弹幕**：播放页里找**气泡/弹幕图标**，点一下即可关闭；再点开回来。
- **默认关掉**：部分版本在设置里有「默认关闭弹幕」的选项，设一次以后新打开的视频都不带弹幕。
- **调节显示**：有用户反馈可调弹幕的**透明度、显示区域、滚动速度** —— 具体有没有这些选项、在哪个菜单，随版本不同，你在设置里翻一下便知；没有就是这个版本没做，不必找偏方。

想发弹幕时也在同一处入口，输入后发送；不想露脸就只关发送、留着看。

## 五、字幕与语言

部分番剧带字幕轨，播放页里有字幕入口就能切语言；**没入口说明这部没有字幕**，不是你操作错了。字幕是跟着单部作品走的，A 部能切不代表 B 部也有。

## 六、清理本地缓存（越用越卡时先做这个）

在线播放也会在本地攒临时文件，攒多了会挤占空间、拖慢应用。清理路径：

```
我的 → 设置 → 清除缓存
```

三点注意：

- **清的是缓存，不是你缓存下载的剧集** —— 下载的视频在「我的 → 离线缓存」里单独管，见 [离线缓存与投屏电视.md](离线缓存与投屏电视.md)。
- 清理会弹确认框，确认后再点，误点了也只是要重新加载，不丢账号数据。
- 路径以你版本里的实际菜单为准，找不到「设置」就逐个点开「我的」页面下的入口。

## 七、设置改不动、选项找不到

同一部手机上找不到某项开关，通常是版本差异：网盘里那份是 5.1.7（见 [下载与安装教程.md](下载与安装教程.md)），官网还会更新，功能多少不完全一样。先把应用升到最新再看；仍没有就是这版没做，别为了一个开关反复重装。
