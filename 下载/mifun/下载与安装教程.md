## 一、先确认手机能不能装

mifun 是安卓应用，装之前对一下这几项，能省掉一半「装不上」的麻烦：

| 项目 | 本篇对应的安装包 |
| --- | --- |
| 系统要求 | 安卓 5.2 及以上 |
| 版本 | 5.1.7 |
| 包名 | `com.mifunto.lanmao` |
| 安装包大小 | 64.82M（下载前先确认手机有 200MB 以上可用空间，安装时还要额外占一份） |

版本号会随官方更新变化，官网页面显示的才是当时的最新版；本篇表格里的 5.1.7 是网盘里那份包的实际版本。

## 二、从哪里拿安装包

两条路都可以，任选其一：

1. **夸克网盘**：打开 [mifun 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4a21e76c4c51)，把 `mifun_v5.1.7.apk` 转存或直接下载到手机。文件夹里还有一份说明 txt，照着放着就行。
2. **官网**：[www.mifun.net.cn](http://www.mifun.net.cn/) 首页有「立即下载 Android 版」按钮，点了直接拿官方当前版本。

两条路拿到的不一定同一版：网盘那份固定在 5.1.7，官网会一直更新。你想跟着官网走就用官网，想用固定版本（比如手机上一直跑得很稳）就用网盘那份。

下载尽量用手机浏览器或网盘 App 完成，别在电脑上下完再用微信、QQ 传过去 —— 传输工具偶尔会把 `.apk` 后缀改掉或截断文件，装的时候会报「解析包出错」。

## 三、安装步骤

1. 在手机上点开下载好的 `.apk` 文件（文件管理器的「下载」目录里一般能找到）。
2. 系统会弹「不允许安装来自此来源的应用」—— 这是安卓对未知来源安装的默认拦截。点提示里的**设置**，打开「允许来自此来源的应用」（有的系统叫「安装未知应用」），再返回。
3. 回到安装界面点**安装**，等进度条走完。
4. 点**打开**，或回桌面找 mifun 图标。

Android 8.0 以后这个权限是**按应用授权**的：你在哪个浏览器里点的安装包，就给那个浏览器开权限；换个入口又要重新开一次，属正常现象。

## 四、装完核对一下版本

装好后建议核对一次，避免下到被替换过的包：

- 路径一：手机「设置 → 应用 → mifun → 版本」，看是不是 5.1.7（官网下载的会更高）。
- 路径二：想校验完整性，用任意 md5 校验工具对安装包算一遍，网盘那份的 MD5 是 `2E19433BD20AE2D600160D50D32DC2CA`，对不上说明文件在传输中坏了，重新下一次。

## 五、装不上的常见原因

按出现频率排，逐条对：

1. **解析包出错 / 打开就闪退**：九成是下载不完整。文件大小对不上 64.82M 就重下；微信、QQ 等工具传文件时容易截断。
2. **存储空间不足**：安装时系统需要临时解压，可用空间最好留到安装包大小的 3 倍以上。
3. **提示与已有应用冲突**：手机里装过另一个签名不同的 mifun（比如来自不同渠道），同包名装不上去。先卸载旧的再装，注意卸载会清掉该应用本机数据，收藏和历史如果绑了账号，重新登录即可找回。
4. **系统版本太低**：安卓 5.2 以下装不了，先在「设置 → 关于手机」里确认系统版本。
5. **点安装没反应**：部分系统需要在「安全设置」里临时放开安装权限，装完可以再关掉。

排查到哪一步卡住，可以对照 [播放卡顿与常见问题排查.md](播放卡顿与常见问题排查.md) 里更细的条目。
