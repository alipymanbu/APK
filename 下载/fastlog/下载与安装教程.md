## 一、你将装上的是什么

FastLog 是嘉兴乐炫网络科技有限公司出品的轻量记录工具，装在安卓手机上，用来做习惯打卡、日常事件记录和小目标管理。安装包只有 4MB 左右，对机型要求很低。

本文对应安装包的具体信息如下。你在官方商店看到更高的版本号是正常的——商店版本会持续更新，网盘里这版是固定的：

| 项目 | 值 |
| --- | --- |
| 应用名 | FastLog |
| 版本 | 1.0.2 |
| 包名 | com.lexuan.fastlog |
| 安装包大小 | 约 4.01MB |
| MD5 | 3DDEAE57EC5D9565B8775544485B8498 |

几个版本节点的主要变化（完整历史以官方商店当时显示为准）：

| 版本 | 主要变化 |
| --- | --- |
| 1.0.2 | 网盘里这一版 |
| 1.0.4 | 新增周 / 月 / 分组样式的小组件 |
| 1.2.6 | 中间版本（2026-08 前后收录）：目标与周期设置、Excel 导出、解锁密码等在此阶段已具备 |
| 1.3.0 | 官方商店当前版本（2026-09 更新）：新增日历功能、今日 Todo 与连续打卡小组件、按时 / 分 / 秒计时的事件类型等 |

也就是说，如果你想要日历视图、连续打卡小组件这些后加的能力，需要通过官方渠道更新；只用基础的记录、打卡和桌面小组件，1.0.2 已经够用。另外，截至本文所查，小米应用商店上这个应用的页面标着「维护中」，不一定随时能装上——这也是网盘里备一份安装包的意义，商店状态以当时显示为准。

要不要花钱、会员怎么买，见 [收费情况与会员说明.md](收费情况与会员说明.md)。

## 二、把安装包拿到手机上

1. 打开 [FastLog 安装文件资源（夸克网盘）](https://pan.quark.cn/s/85fa4a8e8b4d)；
2. 转存到自己的夸克网盘，再从网盘把 APK 下载到手机存储；
3. 也可以在电脑网页上转存，用客户端下载后，把 APK 传到手机（数据线、微信文件传输助手都可以）。

## 三、安装：允许「未知来源」

APK 不经过应用商店，安卓会先拦一道：

1. 在文件管理器里点这个 APK；
2. 系统提示「禁止安装未知应用」时，跟着弹窗进设置，允许你用来打开它的那个应用（文件管理器或浏览器）「安装未知应用」；
3. 返回继续安装。

各厂商的叫法略有差别：小米叫「安装未知应用」，华为叫「允许安装未知应用」，vivo / OPPO 的入口在「应用与权限」附近——但都会在安装弹窗里直接给跳转入口，跟着提示走即可。

安装前想核对文件完整性，可以用任意 MD5 校验工具算一遍 APK 的 MD5，应等于 `3DDEAE57EC5D9565B8775544485B8498`。

## 四、首次启动会弹什么

第一次打开 FastLog，通常会遇到几类授权弹窗（具体条目因系统版本而异），各自对应的功能不同：

| 授权 | 对应功能 | 不给会怎样 |
| --- | --- | --- |
| 通知权限 | 定时提醒的推送 | 收不到打卡提醒 |
| 闹钟和提醒（精确闹钟） | 提醒准点触发 | 提醒可能延迟或不响 |
| 自启动 | 后台按时发出提醒 | 提醒可能要等你打开 App 才补发 |

前两项建议开，第三项看你对提醒的依赖程度，随时可以在系统设置里改。装好后的第一步是建一条你自己的记录：步骤见 [习惯创建与打卡步骤.md](习惯创建与打卡步骤.md)；提醒设好了却不响，按 [提醒收不到排查方法.md](提醒收不到排查方法.md) 逐条排查。
