Ridibooks 的阅读体验集中在应用自带的阅读器和书柜里：排版可以在阅读页随时调，长篇可以用朗读功能听，买过的作品能下到本机离线看。本篇按「读的时候调什么 — 听的时候选什么 — 不联网时靠什么 — 读完之后怎么整理」的顺序讲一遍。

## 一、阅读页里能调的四项

打开一部作品进入阅读页后，点屏幕唤出控制层即可调整。官方列出的可调项是这四类：

| 设置项 | 调什么 | 什么时候值得动 |
| --- | --- | --- |
| 亮度 | 阅读页的显示亮度 | 夜间只想调阅读页、不想动整机亮度时用 |
| 字号 | 正文字号大小 | 小屏手机上默认字号偏小，调大一档更省眼 |
| 字体 | 正文使用的字体，也可以导入自己的字体 | 习惯某种字体时，把字体文件放进手机再导入 |
| 背景色 | 正文底色 | 暗光环境下换成深色或暖色底 |

导入自定义字体会用到「文件和媒体」权限，权限清单见 [下载与安装教程.md](下载与安装教程.md)。这些排版偏好**只在本机保存**，换设备或重装后要重新调一遍；进度和笔记则会跟账号同步，见本文第六节。

## 二、朗读（TTS）：三条路，按需求选

官方把朗读分成三种用法，差别在音色数量、语速范围和设备要求上：

| 方式 | 可选音色 | 语速范围 | 额外要求 |
| --- | --- | --- | --- |
| 基础朗读 | 민준、수진 两个 | 0.5 ~ 4.0 倍速 | 无，装上就能用 |
| AI 音色 | 민재、진우、유정、이나 四个 | 0.5 ~ 2.0 倍速 | Android 12 及以上；同时只能保留一个音色 |
| 系统 TTS | 用手机系统里已装的语音引擎 | 由系统引擎决定 | 需要先在系统里把 TTS 引擎与语音包装好 |

几个实际会碰到的点：

- **基础音色的发音偏韩语腔调**，读夹杂外语的作品时会不太自然，这是官方自己说明过的限制。
- **AI 音色听起来更接近真人**，但对系统版本有要求，且一次只能下一个、不能只删一个——想换音色要连带处理。
- **系统 TTS 调得最细**，音高、音量、效果都能跟着手机系统走；但 OneUI 7.0 及以上、Android 15 及以上的三星系统音色受限制，需要换其他引擎。
- **想让朗读在通话结束后自动继续**，需要授予「电话」权限。

## 三、把作品下到本机离线看

1. 打开「구매목록（购买列表）」，或进「내 서재 → 모든 책」找到作品；
2. 在作品上执行下载（作品页上通常是下载按钮或箭头图标），等下载完成；
3. 下好的内容在**没有网络时也能打开**，官方把这个状态称为离线模式。

三点注意：

- **存储权限要放行**，否则下载无法落盘，见 [下载与安装教程.md](下载与安装教程.md)；
- **卸载应用、清理应用数据都会删掉已下载的内容**，重新下载即可，购买记录在账号里不会丢；
- **占用空间差别很大**：漫画以图片为主，体积明显大于同样篇幅的文字作品。手机空间紧张时，在书柜里按作品清掉看过的下载。

### 下载完第一次打开要解压，这时最需要空间

官方说明里有一条容易被忽略：下好的作品**第一次打开时会做解压**，如果这一刻手机可用空间不够，就会出现「文件损坏」「字串编码错误」这类提示，甚至整页空白。所以下载前最好留出比作品体积更宽裕的空间，别卡着剩余容量下最后一部。

### 文件下到哪、怎么改位置

| 平台 | 默认存储位置 |
| --- | --- |
| Android | `Android/data/com.initialcoms.ridi/files/books` |
| Windows | `C:/Users/用户名/Downloads/새 폴더/ridibooks/登录的账号` |
| macOS | `/Users/用户名/Library/Application Support/Ridibooks/library/登录的账号` |

安卓上可以在「MY → 设置 → 다운로드 위치 변경（更改下载位置）」里换一个位置（比如换到容量更大的存储卡）。官方明确不建议把这套路径手动改到别处，改了之后应用可能找不到已下载的文件。

### 想清空间时，先删下载文件而不是删作品

应用里区分「删下载文件」和「从列表删除」两件事：

- **单本清理**：在「내 서재」右上角进「편집（编辑）」→ 勾选作品 → 左下角「파일 삭제（删除文件）」，作品会保留在购买列表里，只是不再占本机空间；
- **批量清理**：在「내 서재」里**长按**任意作品会弹出菜单，其中有「다운로드된 파일 전체 삭제（删除全部已下载文件）」，适合一次性腾空间；
- **顺手清临时数据**：「MY → 设置 → 임시 데이터 파일 삭제（删除临时数据文件）」可以再清掉一部分缓存。

删除文件不影响购买记录，想重看时回「구매목록（购买列表）」重新下载即可。租来的作品下载即开始计租期，这条规则见 [租赁作品怎么用与到期怎么办.md](租赁作品怎么用与到期怎么办.md)。

## 四、阅读笔记、书签与分享

- 阅读过程中可以划重点、写笔记、加书签，这些内容统一收在「독서노트（阅读笔记）」里，方便回头整理；
- 喜欢的句子或画面可以做成图片分享出去，这类分享走的是系统分享面板；
- 笔记与书签**跟着账号同步**，换设备登录同一账号后能看到。

## 五、书柜（내 서재）怎么整理

- 可以**自建书架分组（책장）**，按自己的标准把作品分类；
- 自建的分组在同一账号的其他设备上**也会同步**，换设备不用重新建；
- 购买列表里不想一直看到的作品，可以做**隐藏或删除**处理。这类操作只影响列表显示，**不影响购买记录**，需要时还能再找回来；
- 「최근 본（最近看过）」能看到最近打开过的作品，接着读最省事。

## 六、哪些设置跟账号走、哪些只在本机

| 项目 | 是否跟账号 |
| --- | --- |
| 阅读进度 | 跟账号 |
| 书柜分组 | 跟账号 |
| 阅读笔记、书签 | 跟账号 |
| 已下载的离线文件 | 只在本机 |
| 阅读页的排版偏好 | 只在本机 |
| 朗读音色 | 只在本机（AI 音色同时只能一个） |

想在电脑上接着读同一批作品，先确认 PC 也占设备名额，见 [电脑和网页版怎么用.md](电脑和网页版怎么用.md)；朗读没声音、离线内容不见了，见 [常见问题与排查.md](常见问题与排查.md)。
