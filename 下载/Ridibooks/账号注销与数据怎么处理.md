# Ridibooks 账号注销与数据怎么处理

> 注销 RIDI 账号之前先看清代价：已购买的内容会一起失效，余额也会清零，账号 ID 永久不能复用。本篇讲注销入口、注销后拿不回什么，以及长期不登录会怎样。

注销是不可逆的操作：账号一旦注销，买过的作品、下载好的内容、书柜与笔记都会一起失去。本篇按「入口在哪 — 会失去什么 — 哪些信息还能用 — 长期不登录会怎样」的顺序讲一遍，最后给一份注销前的确认清单。

## 一、注销入口

官方给出的两条路径都要**先通过本人确认流程**：

| 入口 | 路径 |
| --- | --- |
| 网页端 | 我的 RIDI → 信息变更 → 会员注销 |
| 手机应用 | MY → 设置 → 账号信息 → 会员注销 |

两条路径指向同一个账号，用哪个入口注销都一样。

## 二、注销后会失去什么

| 项目 | 注销后的状态 |
| --- | --- |
| 已购买、已下载的内容 | 不可再使用（官方条款写明：注销时既有的购买与下载内容不可用） |
| RIDI Cash 余额 | 失效；且 RIDI Cash 本身不能转让给他人 |
| 书柜分组、阅读笔记、阅读进度 | 随账号一起消失 |
| RIDI Select 订阅 | 账号不存在后无法继续使用 |
| 已提交的成人认证资料 | 按官方隐私政策，会员注销后即时销毁 |

也就是说，注销不是「退出登录」：退出登录只是换台设备，注销是把账号连同里面的资产一起清掉。只想换设备或换登录方式的话，先看 [注册登录与设备管理.md](注册登录与设备管理.md)。

## 三、注销后哪些信息还能再用

- **账号 ID 永久不能重复使用**——官方说明注销完成后的 ID 不可再次使用。
- **邮箱要等 30 天**：注销后原邮箱地址需**满 30 天**才能重新注册。
- 所以打算「注销重来」的话，要么等满 30 天，要么换一个邮箱注册。

## 四、长期不登录会怎样：休眠会员

官方条款里对「休眠会员」有明确定义和一条附带影响：

- **连续 1 年以上未登录** RIDI 的账号会转为休眠会员（휴면회원）；
- **解除方式很简单**：用同一个账号登录一次即可自动解除；
- **附带影响**：账号转为休眠时，**正在订阅的 RIDI Select 会被自动解约**。这条可以当兜底，但别拿它代替正常解约，正常解约路径见 [作品购买与付款方式.md](作品购买与付款方式.md)。

## 五、注销前的确认清单

1. **订阅是否还在续费**：先按正常路径解约，再考虑注销，避免订阅关系与账号状态纠缠在一起。
2. **余额还剩多少**：RIDI Cash 与 RIDI Point 在注销时失效、也不能转让，把余额用在需要的作品上更划算，顺便确认赠送的 Point 是否还在有效期内。
3. **有没有想留下的笔记**：阅读笔记与书柜都挂在账号下，注销后无法找回，需要保留的内容请在注销前自行记录。
4. **是不是只想换账号**：第三方快捷登录与邮箱注册可能对应两个不同账号，也许不用走到注销这一步，见 [注册登录与设备管理.md](注册登录与设备管理.md)。
5. **异地登录与被盗风险**：怀疑账号被人使用、想靠注销来止损的，先改密码并把不认识的设备从设备管理里解绑，比直接注销更稳，见 [注册登录与设备管理.md](注册登录与设备管理.md)。

注销与账号相关的疑问（如注销后订单记录、退款进度）通过官方客服确认最快，联系方式见 [常见问题与排查.md](常见问题与排查.md)。
