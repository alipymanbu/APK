# Ridibooks 注册登录与设备管理

Ridibooks 用的是 RIDI 统一账号：购买记录、租赁记录、书柜分类、阅读进度、阅读笔记、订阅状态都挂在同一个账号下面，换设备只要登录同一个账号就能接着用。本篇把注册方式、成人认证、设备上限和换机时的处理一次讲完。

## 一、注册有两条路

- **第三方账号快捷登录**：支持 Kakao、Naver、Google、Apple 四家。在登录页选对应的按钮授权即可，注册和登录是同一个动作。
- **邮箱注册**：填邮箱与密码，**必须完成邮件里的验证链接**才算注册成功。收不到验证邮件时，先翻一下垃圾邮件或广告邮件目录再重发。

注册入口在应用里和网页上都有，两边建出来的是同一套账号，用哪个入口注册都行。

## 二、成人向作品要单独做认证

- **普通作品不需要认证**，注册完就能买、能读。
- **成人向作品需要先通过「성인 인증（成人认证）」**才能购买与阅读，认证入口与所需材料以官方页面为准。
- **海外居住者另有一条认证通道**：按官方隐私政策里列出的收录项，海外用户做成人认证需要提交姓名、出生日期、**海外身份证件的种类、签发国家与有效期**，并可以附上证件文件；这些资料在会员注销时即时销毁。认证能否通过与需要几天，**以官方客服答复为准**。
- 应用里**能不能搜到**成人向作品还分版本：普通版应用不提供成人作品搜索，网页端可以搜，OneStore 上的「완전판（完整版）」也可以。也就是说，用这份普通版 APK，成人向作品要么从网页端找到再回到应用里读，要么装完整版。

## 三、一个账号最多 5 台设备

RIDI 按设备数授权，截至 2026-09 的规则是：

| 设备类型 | 上限 |
| --- | --- |
| 普通设备（手机、平板、PC 阅读器） | 5 台 |
| Paper 电子阅读器 | 在 5 台之外，另加 5 台 |

举例说明这个 5 台是怎么算的：家里的 Windows 电脑、公司的 Windows 电脑、安卓手机、安卓平板、iPad，正好占满 5 台。网页端浏览器阅读**不算**在这个名额里，需要登记的是应用与 PC 阅读器这类客户端。

## 四、换设备登录被拦下来怎么办

在新设备上登录时，如果已经用满 5 台，应用会弹出「기기 대체하기（替换设备）」提示：

1. 在弹出的列表里**勾选一台要登出的旧设备**；
2. 确认之后，新设备就能正常登录，被选中的那台会被登出。

也可以提前腾位置：在网页端进「我的 RIDI → 设备管理」，把不再使用的设备解绑，再回手机登录。这个页面同样能用来看「现在到底登记了哪几台」，怀疑名额被占满时先来这里核对。

两个容易踩的点：

- **同一台设备登出再登录，有可能被当成新设备重复登记**，白占一个名额。发现列表里有重复的旧记录，直接在设备管理页删掉。
- **卖掉的旧手机、刷过机的旧设备不会自动解绑**，会一直占着名额。换机前顺手清一次，比事后被拦在门外省事。

## 五、买了作品却看不到，先确认这三件事

1. **是不是登录了买书时的那个账号**。第三方快捷登录和邮箱注册可能建出两个不同的账号，看着名字一样也不代表是同一个。
2. **让账号数据重新拉取一次**。退出登录再登入，然后到「구매목록（购买列表）」里核对。
3. **换个入口找**。「내 서재 → 모든 책」里能看到账号下的全部已购内容，网页端买的、应用内买的都在这里。

这三步走完还是看不到，再走 [常见问题与排查.md](常见问题与排查.md) 里的排查顺序。

## 六、哪些东西跟着账号走

| 项目 | 说明 |
| --- | --- |
| 购买与租赁记录 | 跟账号走，换设备登录同一账号即可看到 |
| 书柜分组与阅读进度 | 同一账号在新设备上同步 |
| 阅读笔记、书签 | 跟账号走，换设备后能看到 |
| 已下载的离线文件 | 只在本机，换设备要重新下载 |
| 朗读音色 | 只在本机；AI 音色同时只能保留一个，换设备要重新处理 |
| RIDI Select 订阅 | 跟账号走，新设备登录订阅中的账号即可继续用 |

这张表也解释了注销为什么不可逆：上面所有内容都挂在账号上，账号一注销就一起失去，代价清单见 [账号注销与数据怎么处理.md](账号注销与数据怎么处理.md)。

离线与朗读的具体用法见 [阅读设置与离线下载.md](阅读设置与离线下载.md)，订阅与付款见 [作品购买与付款方式.md](作品购买与付款方式.md)。如果你打算把 PC 也算进这 5 台里，先看 [电脑和网页版怎么用.md](电脑和网页版怎么用.md) 里的名额说明。
