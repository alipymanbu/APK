Ridibooks 是韩国 RIDI Corporation 运营的电子书与网络漫画平台的安卓客户端，作品以网络小说、网络漫画和单行本电子书为主，账号内用 RIDI Cash 充值后按话或按本购买，支持离线下载与阅读进度同步。本篇讲网盘里这份包是哪个版本、怎么装进你的安卓手机。

## 一、先核对网盘里这份包是哪一版

各下载站登记的版本号与网盘里这份常常对不上。本文出现的版本、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Ridibooks |
| 版本号 | 26.4.1 |
| 包名 | `com.initialcoms.ridi` |
| 安装包体积 | 104.09 MB |
| MD5 | `b8eab1a693de3d4df6959b370cba8af4` |
| 形态 | 安卓 APK |
| 本文核对时间 | 2026-09-22 |

判断是不是同一个包，看**包名 + MD5**，不要看名字旁边的版本数字。两点容易混：

- 应用商店里显示的名称是**「리디」（RIDI）**，Ridibooks 是它此前更常见的叫法。在 Google Play 里搜 Ridibooks 未必搜得到，搜「리디」更稳；最准的核对方式是看包名是不是 `com.initialcoms.ridi`。
- 网上搜到的多是官方最新版，与网盘里这份不一定是同一版；版本号不同是正常的，本文只认上表。

## 二、系统要求：这份包要安卓 10 及以上

官方帮助中心按系统版本给过一份可安装版本对照，截至 2026-09 是这样：

| 系统版本 | 可安装的 RIDI 版本 |
| --- | --- |
| Android 10.0 及以上 | v26.3.1 及之后 |
| Android 9.0 及以上 | v25.8.1 ~ v26.3 |
| Android 8.0 及以上 | v24.10.6 ~ v25.8 |

网盘里这份是 **26.4.1**，落在第一行，也就是**你的手机需要 Android 10 或更高**。系统版本可以在「设置 → 关于手机 → 软件信息 → Android 版本」里确认。

官方同时说明：低于最低支持版本的系统无法继续更新，出问题也不再提供支持；这张表会随新系统和新版应用调整，**以官方帮助中心当页为准**。

## 三、安卓：装网盘里这份 APK

1. **先转存再下载**。打开 [Ridibooks 安装文件资源（夸克网盘）](https://pan.quark.cn/s/29cd5a8f8f1b)，把 APK 转存到你自己的网盘，再下载到手机。这一步别省：分享链接失效后，只有转过存的那份还在。
2. **允许安装未知来源应用**。在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，允许你用来打开安装包的那个应用（文件管理器、浏览器或网盘客户端），再点这个 APK 安装。
3. **提示「应用未安装」就先卸载旧版**。手机里已有同包名但签名不同的版本时，覆盖安装会直接失败，先卸掉再装。
4. **同一包名无法共存**。装着旧版再装这份，旧版会被覆盖；想保留旧版就别装这一份。
5. **装完先别急着删安装包**。首次启动如果出现异常需要重装，手边留着原包更省事。

如果中国大陆网络下装不上商店版本，官方给出的做法是用官方下载页提供的 APK 安装，入口是 `https://ridibooks.com/support/app/download`。网盘里这份同样是 APK，走上面第 1~4 步即可，不必再去下载页取包。

## 四、装完会要哪些权限

| 权限 | 用途 | 是否必需 |
| --- | --- | --- |
| 存储 | 保存已下载的作品与阅读记录 | 商店说明里标为必需 |
| 文件和媒体 | 导入自定义字体、导入电子书文件、分享图片 | 可选 |
| 电话（通话状态） | 通话结束后自动继续朗读 | 可选 |
| 通知（Android 13 及以上） | 新话更新、活动、下载完成提醒 | 可选 |

以上按官方商店的应用说明整理。系统版本不同，权限条目的名称会不一样；Android 6 以下额外会请求「设备状态与身份」，但这份包本身要求 Android 10 以上，通常见不到这一条。不授予可选权限不影响基本阅读，只是对应功能用不了。

## 五、第一次打开先做三件事

1. **登录或注册账号**。不登录只能浏览，购买与下载都要账号，注册方式与设备上限见 [注册登录与设备管理.md](注册登录与设备管理.md)。
2. **接受「界面只有韩语」这件事**。应用与阅读器的界面语言是韩语，先有个预期，再决定要不要借用浏览器翻译或改用网页端，见 [界面语言与中文阅读.md](界面语言与中文阅读.md)。
3. **先看免费内容，再决定要不要充值**。连载作品通常有可免费解锁的章节，摸清内容后再考虑付费，付费路径见 [作品购买与付款方式.md](作品购买与付款方式.md)。

## 六、装完做一次最小验证

拿手边的操作走一遍就能确认装好了：

- 能打开应用、看到首页的排行与分类入口 → 安装本身没问题；
- 能进「내 서재（我的书柜）」看到已购作品 → 账号与同步正常；
- 能下好一部作品并断网打开 → 离线阅读与存储权限正常。

装不上、提示解析包错误、一打开就闪退，见 [常见问题与排查.md](常见问题与排查.md)。想换设备接着看同一批作品，先确认设备名额，见 [注册登录与设备管理.md](注册登录与设备管理.md)。
