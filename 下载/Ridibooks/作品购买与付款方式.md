# Ridibooks 作品购买与付款方式

Ridibooks 是正版付费内容平台：连载按话卖、单行本按本卖，也有租赁和月付订阅。本篇按「哪些内容不用花钱 — 钱怎么进账户 — 付款走哪个入口 — 买和租怎么选 — 退款能退到什么程度」的顺序讲一遍。价格与活动力度都会变，具体数以官方页面当时显示为准。

## 一、先分清：哪些不要钱、哪些要钱

- **免费章节**：连载作品通常设有「기다리면 무료（等待即免费）」的免费话，按官方规则等待一段时间后可免费解锁一话。哪几话免费、要等多久，作品页上会写明，以页面显示为准。
- **每周优惠券**：官方每周发放的「위클리 쿠폰（Weekly Coupon）」，按官方说明每人每周可领 3 张、用于结算时享 10% 折扣。领取入口与折扣力度以官方活动页为准。
- **其余内容需要付费**：按话（连载）或按本（单行本）购买或租赁。免费章节与优惠券只是官方给的试用与优惠途径，不代表整体免费。

## 二、钱怎么进账户：RIDI Cash 与 RIDI Point

| 名称 | 是什么 | 从哪来 |
| --- | --- | --- |
| 리디캐시（RIDI Cash） | 账户内的余额，用来买或租作品 | 自己充值 |
| 리디포인트（RIDI Point） | 与现金等值使用的积分 | 充值赠送、活动发放 |

充值时有两条官方写明的规则值得记：

- 充 RIDI Cash 会**按比例赠送 RIDI Point**，所以同样的钱充进去，实得比面额多一点；
- 在**每月 1~3 日充值**，或者开启**自动充值**，赠送的 Point **翻倍**。

赠送比例、活动时间与积分有效期都会变，充之前先看官方充值页与条款页写的当时规则。RIDI Point 一般不能直接用来付订阅费，这一点见下面第五节。

## 三、付款走哪个入口：分应用内和网页端

官方把两条付款路径分得很清楚：

| 入口 | 支持什么支付方式 |
| --- | --- |
| 应用内充值 | 安卓走 Google Play 的支付；OneStore 上的完整版走 OneStore |
| 网页端结账 | 支持海外发行的信用卡，走 Paygate，可用的卡组织为 Visa、Master、JCB、Amex |

网页端结账时要在支付方式里选**「해외 발행 신용카드（海外发行信用卡）」**这一类，才会出现上面这几个卡组织。

把这两条放在一起看，对大陆用户的现实结论是：**手机上通常装不上 Google Play，应用内付款这条路基本走不通；可行的做法是先在网页端用海外信用卡把 RIDI Cash 充进账号，再回到应用里用余额买作品。** RIDI Cash 是账号级的余额，应用、网页、PC 阅读器通用，只是付款那一步要在网页完成。

要提醒的是：官方列出的支付方式里没有支付宝、微信这类渠道。遇到声称「帮你代充、代付」的第三方，等于把账号交给别人操作，不建议走这条路。

## 四、买和租怎么选

| | 소장（买断） | 대여（租赁） |
| --- | --- | --- |
| 使用权 | 长期留在账号里，随时可读 | 有期限，到期后需重新租或买 |
| 价格 | 高 | 低 |
| 适合 | 会反复翻、想长期留着的作品 | 只想看一遍的作品 |

同一部作品往往两种都提供，价格与租期长度按作品不同，作品页上会写明，以页面显示为准。买了之后想整理购买列表，可以用隐藏或删除功能，见 [阅读设置与离线下载.md](阅读设置与离线下载.md)。

租赁的计时规则与买断不一样（付费租赁从下载那一刻起算，免费券则从结算那一刻起算），下单前值得先看一眼 [租赁作品怎么用与到期怎么办.md](租赁作品怎么用与到期怎么办.md)。

## 五、订阅：RIDI Select

RIDI Select 是官方推出的月付订阅，订阅期内可无限阅读 Select 专区里的作品；专区之外的作品仍要按上面的方式单独买或租。

- **价格**：首次订阅为 4,900 韩元（海外卡按 4.99 美元结算），官方说明会在订阅时**立刻返还 4,900 RIDI Point**；续费与档位以官方订阅页为准。
- **怎么开通**：登录后在国内或海外信用卡的订阅页申请，也可以先拿到兑换券再注册；入口是 [select.ridibooks.com](https://select.ridibooks.com/)，应用首页顶部的「셀렉트」标签也能进。
- **怎么用**：在作品页点「마이 셀렉트에 추가（加入我的 Select）」，加入后该作品页的按钮会变成下载或阅读；加入的作品会出现在购买列表与「내 서재 → 모든 책」里。
- **三个边界**：订阅费不能用 RIDI Cash、RIDI Point 或韩国的文化消费卡（문화누리카드）支付；海外卡订阅按美元计价，汇率走高时实际扣款可能高于 4,900 韩元；订阅绑定账号，换新设备登录订阅中的账号即可继续用。
- **怎么解约**：官方路径是「셀렉트 → 设置 → 订阅管理 → 预约解约（구독 해지 예약）」。预约解约后，**在已付费的当前订阅期内仍可正常使用**，到期后不再扣款。另一个判断依据：如果在「셀렉트 → 设置」里根本看不到「订阅管理」这一项，说明当前并不在订阅状态。
- **被动解约的一条**：账号连续 1 年以上未登录转为休眠会员时，订阅会被自动解约。这可以当兜底，但别当正常解约手段，见 [账号注销与数据怎么处理.md](账号注销与数据怎么处理.md)。

## 六、退款能退到什么程度

官方的退款规则写得比较具体，值得在付款前先记下来（细节以官方条款当前版本为准）：

| 情形 | 能否退款 |
| --- | --- |
| 买下后**没下载过、也没打开过**的内容 | 结算日起 **7 天内**可申请全额退款 |
| **已下载（含开始下载）或已打开**的内容 | 视为已使用，不可退款 |
| 套装书里**只要有一本**被下载或打开过 | 整套都不可退款 |
| 自己操作失误导致看不了（如误用错误设备） | 不在可退范围内 |
| 官方更新本可解决问题、自己拒绝更新 | 不在可退范围内 |

RIDI Cash 这一侧另有一套规则：

- 付费充值的 Cash **完全没用过**，可在 7 天内撤销充值并退款；
- 已经用过一部分再申请退款，会**先扣掉因这笔充值免费获得的 RIDI Point**，再按剩余余额的 **90%** 退还（比例以官方条款为准）；
- 官方免费发放的 Cash / Point 只能在其有效期内使用，**不予退款**；
- RIDI Cash **不能转让给他人**，账号会员注销时会一并失效。

## 七、几个容易踩的点

- **先确认账号再付款**。第三方快捷登录与邮箱注册可能建出两个账号，付错账号再想挪回来很麻烦，见 [注册登录与设备管理.md](注册登录与设备管理.md)。
- **想退就先别下载**。7 天窗口只对「没下载、没打开」的内容成立；一旦开始下载或打开，退款通道就关了。买之前先在作品页试读更稳妥。
- **别长期囤积余额**。RIDI Cash 与 RIDI Point 的使用范围与有效期由官方条款规定，充值时按近期要看的量来充；注销账号时余额会失效，见 [账号注销与数据怎么处理.md](账号注销与数据怎么处理.md)。
- **赠品积分会被追溯**。退款时官方会扣回当初因充值而赠送的 Point，所以「退款金额小于实付」是规则使然，不是算错。
- **网页端能搜到应用里搜不到的内容**（成人向作品就是典型），所以搜不到某部作品时，去网页端确认一次，见 [电脑和网页版怎么用.md](电脑和网页版怎么用.md)。
