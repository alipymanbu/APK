## 一、先分类逛还是先搜

两条路径，按你手头有没有明确目标选：

- **目标明确**（就想找某个具体应用）：直接用搜索栏输名字，最快；
- **没有明确目标**（就想找点能玩的）：走分类列表，按板块一层层翻，靠详情页的介绍决定要不要。

## 二、搜索的几个实用做法

- 名字记不全时，输你记得的那几个字母或词根就够了，结果会跟着输入实时变；
- 搜出来的条目多时，优先点和你输入完全一致的那个；遇到同名的多个条目，进详情页核对版本号和体积再下；
- 搜不到时先检查拼写有没有多打空格，再换个更短的关键词重试 —— 输得越全反而越容易搜空。

## 三、下载是怎么走的

5play 的下载不自己做一套，而是交给安卓系统的下载管理器：

1. 在详情页点下载，任务进入系统下载队列；
2. 进度和状态在**通知栏**里看，不在应用内的某个页面里 —— 这是很多人「以为没在下」的原因；
3. 下载可以在后台继续，中途切走、锁屏都不影响；
4. 下完的文件在系统的「下载」目录里，点通知栏的完成提醒可以直接调起安装；安装时被「未知来源」拦下，按 [安装未知应用权限怎么开.md](安装未知应用权限怎么开.md) 放行。

有用户反馈过「应用里看不到下载进度、也不知道下到哪了」—— 多半就是去错了地方：回通知栏看，或进系统设置的下载列表里找，任务其实在那里跑。

## 四、顺手好用的几个操作

- 左边缘右滑：返回上一页，不用去够左上角的箭头；
- 下拉刷新：列表看着不对劲、想拉最新内容时用；
- 长按链接：弹出菜单，可以复制、分享或换个方式打开；
- 一键分享：把当前内容丢给系统分享面板，发给朋友或存进笔记；
- 字号调节：详情页文字太小时调大一档，读起来省劲。

以上以实际界面为准；不同版本的入口位置可能微调，功能本身都在。

## 五、下载不动的常见原因

| 现象 | 先查什么 |
| --- | --- |
| 点了下载没反应 | 通知栏有没有新任务；应用的网络权限是否被禁 |
| 进度卡在中间 | 切到网络好的环境，系统下载器会自动续上 |
| 下完了找不到文件 | 系统下载目录里按时间排序找最新的 apk |
| 反复失败 | 按 [下载失败与常见问题排查.md](下载失败与常见问题排查.md) 逐条对 |
| 大型游戏装完闪退 | 可能带数据包（OBB），按 [游戏带数据包怎么装.md](游戏带数据包怎么装.md) 补装 |

安装包本身从哪来、怎么装，见 [下载与安装教程.md](下载与安装教程.md)。
