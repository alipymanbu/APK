## 一、先记住通用路径（Android 8.0 及以上）

安卓从 8.0 起把「未知来源」改成了**按来源放行**：不再是一个总开关，而是允许「某个应用」（比如你的浏览器或文件管理器）安装 apk。通用路径：

```text
设置 → 应用 → 特殊应用权限（部分系统叫「特殊访问权限」） → 安装未知应用
  → 选中给你 apk 的那个应用 → 打开「允许来自此来源的应用」
```

最省事的办法是**安装时处理**：点 apk 被拦时，弹窗上一般直接带「设置」按钮，点进去就是对应来源的开关，开完返回继续装，不用自己翻菜单。

## 二、各品牌常见入口

路径随系统版本会变，下面是常见位置（以实际界面为准；找不到就回第一节走通用路径）：

| 品牌 | 常见入口 |
| --- | --- |
| 小米 / 红米（MIUI） | 设置 → 隐私保护 → 特殊权限 → 安装未知应用；旧版本在「更多设置 → 系统安全」 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 | 设置 → 安全 → 安装未知应用（部分版本收在「其他设置」里） |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 应用 → 特殊权限 → 安装未知应用（部分版本在「生物识别和安全性」里） |
| 原生 / Pixel 及其他 | 直接走第一节的通用路径 |

## 三、开完还是装不上的两种情况

- **权限给了，提示还是拦截**：你放行的「来源」和实际点 apk 的应用不是同一个 —— 比如放行了浏览器，apk 却是从文件管理器里点的。把实际点装的那一个也放行；
- **企业管控或儿童模式的设备**：管理员策略可能统一禁止外部安装，这类限制不归应用管，需要先解除对应的设备管控。
