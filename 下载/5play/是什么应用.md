## 一、一句话定位

5play 是一款国外的安卓游戏/应用资源市场类应用：打开就是分类好的游戏与软件列表，搜到、看介绍、直接发起下载，不用再开浏览器在多个网页之间来回跳。安装包 2MB 出头，装上不占地方。

## 二、日常用到的模块

它的界面就围绕「找资源、下资源」组织，你实际会碰到的就这几块（以手机上的实际界面为准）：

| 模块 | 你用它做什么 |
| --- | --- |
| 分类列表 | 没有明确目标时按板块翻，靠介绍页决定要不要 |
| 搜索栏 | 目标明确时直接输名字，最快 |
| 详情页 | 下之前看一眼介绍，核对版本和体积 |
| 站内下载 | 点下载后交给系统下载管理器跑，进度在通知栏看 |
| 通知 | 下载完成、内容更新时提醒，不想看的类别可单独关 |
| 登录保持 | 登录一次后状态留在应用内，下次不用重输 |

操作上没有学习成本：左边缘右滑返回、下拉刷新、长按链接出菜单、内容一键分享、正文字号可调。

2MB 出头的体积也说明了它的形态：应用自己不内置任何资源，列表和内容全部联网取 —— 所以网络条件直接决定体验。

## 三、怎么和网上同名的东西区分

搜「5play」出来的结果很杂：有巴西、菲律宾等地的同名博彩平台，也有多个同名资源站，和本文档说的不一定是一回事。可靠的办法只有一个 —— 核对包名：

- 本文档对应的应用：包名 `com.wplay.hw`、版本 2.0.23、安装包 2.12M —— 包名和版本这两项在「设置 → 应用管理 → 5play」的应用信息页里都能直接看到；
- 装完在「设置 → 应用管理 → 5play」里看到的包名对不上，说明装的是别的来源的同名应用，别混着按教程操作。

## 四、适合谁用

- 适合：想在应用商店之外找游戏和应用安装包、不想为个入口装个大体积市场应用的人；
- 不适合：指望它带评论社区、排行榜运营、应用自动更新管理的人 —— 它没有这些，定位就是轻快的资源入口。
