# 5play 游戏带数据包怎么装

> 大型游戏常是一个 apk 外加一个数据包（OBB），只装 apk 进游戏就闪退或一直要求下载数据；这篇把 apk 加 obb 的完整装法走一遍。

## 一、先判断你下的游戏带不带数据包

两个信号，中一个就按下面走：

- 下载列表里除 apk 外还有一个 `.zip` 或 `.rar` 压缩包；
- 游戏装完首次打开，提示「需要下载附加数据 / 资源文件」。

## 二、安装顺序（先 apk 后数据包）

1. **先装 apk**：点 apk 安装；被「未知来源」拦下按 [安装未知应用权限怎么开.md](安装未知应用权限怎么开.md) 放行。装完先别急着打开游戏；
2. **解压数据包**：用带解压功能的文件管理器（如 ZArchiver 这类）打开压缩包，里面是一个以包名命名的文件夹（形如 `com.xxx.xxx`）；
3. **放到固定位置**：把整个文件夹复制或移动到手机存储的 `Android/obb/` 目录下；没有 `obb` 文件夹就手动新建一个。放完的完整路径应形如 `Android/obb/com.xxx.xxx/`；
4. **再打开游戏**：这时游戏会直接读本地数据，不再要求联网补数据。

以实际文件结构为准：个别游戏的数据包目录名或层级不同，压缩包里附了说明就按说明放。

## 三、装完还是闪退，按这三步查

| 现象 | 先查什么 |
| --- | --- |
| 打开就闪退/黑屏 | `Android/obb/` 下有没有那个包名文件夹；层级有没有多套一层（正确是 `obb/com.xxx.xxx/数据文件`，不是套了两层同名文件夹） |
| 提示数据损坏 | 解压不完整，重新解压一遍再试 |
| 找不到 Android/obb 目录 | 用文件管理器手动新建；部分系统要在文件管理器里授予「所有文件访问」权限才看得到这个目录 |

排查无果再回 [下载失败与常见问题排查.md](下载失败与常见问题排查.md) 对一遍其他环节；apk 从哪来、怎么装，见 [下载与安装教程.md](下载与安装教程.md)。
