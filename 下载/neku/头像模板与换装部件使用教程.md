## 一、这条路怎么走

Neku 的玩法是**在别人的模板上换部件**，而不是从零画一张脸。你先从模板库里挑一个顺眼的底子，然后在编辑界面里逐个部位替换：脸型、眼睛、眉毛、嘴、刘海、发型、服装、配饰、手部姿势、背景——官方描述里说可自由组合的换装部件超过 3000 件。

部件数量一大，最容易犯的错是「一上来就瞎点」。合理的顺序是：先定人物性别与大致风格 → 再定脸和发型（观感主要看这两处）→ 最后才是服装与配饰。反过来做，换一套衣服就得回头重调一次脸。

## 二、从模板开始

1. 在首页的模板列表里挑一个。模板按主题分组（新上线、每日热门、热门、万圣节、圣诞这类），比翻全部列表快得多；
2. 点进模板详情，能看到这个模板包含哪些部件、以及别的用户拿它捏出来的成品，先扫一眼再决定用不用；
3. 进入编辑界面，你点一个部件，预览立刻换上——各个部位依次换到满意为止。

模板的部件是成套的，不是每个部位都能随意换：有些模板只开放发型和服装，脸型是锁死的。遇到某个部位点不动，是模板本身限制的，不是你操作错了，换一个开放度更高的模板即可。

## 三、部件分区怎么切

可改的部位被分成若干分区，你切到哪个分区、下面就列出那个分区下的可选件，点一个换一个。常见分区（各版本的入口排布可能略有差别，以你装的这版界面为准）：

| 分区 | 你能改什么 |
| --- | --- |
| 脸 | 脸型、肤色、五官细节 |
| 眼睛 | 眼型、瞳色、眼神方向 |
| 眉 / 嘴 | 造型与表情 |
| 刘海 / 发型 | 发型款式、发色 |
| 服装 | 上装、下装、连体装 |
| 配饰 | 眼镜、帽子、首饰 |
| 手部 | 手势与手持物 |
| 背景 | 纯色、图案、场景 |

**调色**：官方商店页的口径是「调色板可修改大多数元素」——大部分部件能换颜色，但不是全部。能换的会给出一块色板让你挑，**颜色是给定的，不能自由取色**；某个部件找不到调色入口，就是它只提供固定配色，换一个同部位的其它款式才有得选。

## 四、成品怎么存下来

捏满意之后：

1. 用界面里的**保存**把图导出到手机相册——这一步必须给应用存储权限，没给权限会保存失败（权限怎么开见[常见问题与排查.md](常见问题与排查.md) 第三节）；
2. 要发出去就用**分享**，直接调起社交应用或聊天工具；
3. 想改之前的稿子，去**我的作品**列表里找，能继续编辑、删除或重新分享。

导出的是普通图片文件，之后拿去做头像、发朋友圈都行，不需要再开应用。

**但导出的只是成品图，不是能再拆开改的稿子。** 所以「以后还要改」的角色，别只留一张导出图——稿子留在应用里的作品列表中才能继续编辑，导出图只当成品用。成品图存进相册这一份，是不依赖应用的那一份，见[隐私与账号数据说明.md](隐私与账号数据说明.md) 第一节。

**注意导出图带不带水印**：官方有单独的「去水印」档位，免费版的成品会带应用水印，取舍见[PRO订阅与金币价格说明.md](PRO订阅与金币价格说明.md)。

## 五、免费版的边界在哪

免费版能走完上面整条流程，代价是**广告密度非常高**——多个渠道的用户评价都集中抱怨这一点：点什么之前先看一段广告、领成就奖励也要看广告、切页面时也会插。这是免费版的既定形态，换安装渠道也一样（你装的这份和商店版是同一个包）。

想去广告、去水印，走的是订阅或一次性内购，档位与价钱见[PRO订阅与金币价格说明.md](PRO订阅与金币价格说明.md)。**先免费用几天再决定要不要付**，是这里更划算的做法。

## 六、卡顿或者越点越慢

老机器上部件加载慢、预览掉帧是常见情况。可做的事按顺序试：

1. 关掉后台其它应用，腾出内存；
2. 清一次应用缓存（**清缓存不删作品**，清「存储 / 数据」才会把本地记录一起清掉，别点错）；
3. 换个网络——模板图是在线拉的，网差时会一直转圈。

反复闪退、或者一进编辑页就崩，见[常见问题与排查.md](常见问题与排查.md)。
