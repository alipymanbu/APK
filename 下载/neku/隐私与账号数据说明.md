## 一、不注册能不能用

能。官方隐私政策里的措辞是「**如果你创建账号**，你会提供……」——账号是可选项，不是用应用的前提；第三方评测也提到不用先过注册墙就能开始做图。

区别在于：不登录时你的东西只跟你这台设备走，登录后才谈得上换设备、跨端一致。**官方没有公开说明作品的云端同步机制**（公开资料里查不到相关证据），所以「换手机作品还在不在」这件事，别指望账号兜底——真正保险的做法是把成品图导出到相册，见[头像模板与换装部件使用教程.md](头像模板与换装部件使用教程.md) 第四节。

## 二、官方会收什么

照官方隐私政策（[avatar.zthd.io/Privacy-Terms/](https://avatar.zthd.io/Privacy-Terms/)）与 App Store 隐私标签，分两类：

**与你身份关联的：**

| 类别 | 具体内容 |
| --- | --- |
| 账号信息 | 邮箱、密码；以及你愿意填的昵称、个人简介、年龄与性别、频道描述、网站或社交账号链接 |
| 联系方式 | App Store 标签列为 Contact Info，与身份关联 |
| 第三方登录 | 用社交账号登录时，会拿到该平台公开给你的用户 ID、邮箱、姓名、头像 |
| 你发布的内容 | 图片、文字、链接等；政策写明这类内容**可能在你注销账号或停止使用后仍被保留** |

**不与身份关联的：**

| 类别 | 说明 |
| --- | --- |
| 标识符 | App Store 标签列为 Identifiers |
| 使用数据 | Usage Data |
| 诊断数据 | Diagnostics |

第三方登录那条值得单独看一眼：你拿社交账号一键登录时，拿到的是**该平台愿意公开给它的字段**，范围由你那边的授权页决定，不是官方自己去翻你的社交资料。

## 三、政策管不到的地方

官方隐私政策明确写了两条边界，读的时候别漏：

1. **不适用于第三方服务**——你从应用里点出去的网页、你分享到的社交平台，各有各的隐私政策，官方对它们不负责；
2. **分享工具会把数据传给对应平台**——你点「分享」发到某个社交应用时，内容与相关信息会按那个平台的规则走。

所以：**只想本地做图，就别登录、别点分享**，这两条路径一关，能被收集的就只剩使用数据与诊断数据那一类。
