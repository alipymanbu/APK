## 一、触屏手势速查

2.2.2 版给触屏补齐了一组手势，日常画图基本可以不碰工具栏。默认的手势如下，全部可以在「首选项（Preferences）」的「触摸（Touch）」标签页里改：

| 手势 | 作用 |
| --- | --- |
| 单指点按并按住 | 唤出取色器，从画布上取色 |
| 双指点按 | 撤销一步 |
| 三指点按 | 重做一步 |
| 双指拖动 | 平移画布 |
| 双指捏合/张开 | 缩放画布 |
| 双指旋转 | 旋转画布 |

旋转画布有个默认行为：转回接近 0 度时会自动吸附摆正，画布不会停在歪着的角度。对旋转精度的口味可以在设置里调——触摸旋转在「首选项」→「触摸」标签里改，快捷键旋转在「快捷键（Shortcuts）」标签的 Canvas 分组里改：改成「自由旋转（free rotate）」彻底关掉吸附，改成「棘轮旋转（ratchet rotate）」则按固定角度一档一档转。

刚从别的绘画应用转过来的话，注意两件事：一是按住取色是「点按后不松手」，不是长按菜单；二是手势失灵时先检查是不是有手掌握住了屏幕边缘，误触会让手势识别变迟钝。开关都对、手指或笔就是不出墨的情况不属于手势问题，去[笔压与触屏绘制排查](笔压与触屏绘制排查.md)对排查顺序。

## 二、压感笔与倾斜

Drawpile 安卓版主要按压感笔的使用习惯设计，手指画只是备选。2.2.2 版在安卓上支持了笔的倾斜（tilt）输入——笔尖立着和斜着下笔，笔迹形态会随倾斜角度变化，配合支持倾斜的触控笔（如主动式电容笔、原装触控笔）能画出更接近真实笔刷的收尾。

没有压感笔也能用：普通手指画出来的线条没有粗细压力变化，画草图、涂色不受影响。要求写实的压感手感，就得配一支带压感的笔。

## 三、桌面布局与紧凑布局怎么切

Drawpile 在同一套界面里做了两种布局：

- **桌面布局**：工具和面板像电脑软件一样环绕画布，功能全，适合平板横屏。
- **紧凑布局（小屏模式）**：面板收拢，画布占屏更大，适合手机竖屏。

应用默认按窗口大小自动在两种布局间切换（动态模式），手机竖屏自动收紧、平板横屏自动铺开，一般不用管。想固定某一种，或者切换时机不合心意，去「首选项」的用户界面设置里改；画布显示比例不对时，「视图（View）」菜单里还有「适应屏幕（Fit to Screen）」可以一键复位。

布局和画布都调顺之后，联机开画看[多人联机绘画入门](多人联机绘画入门.md)；画完想存下来或导成视频，看[保存画布与导出格式](保存画布与导出格式.md)。
