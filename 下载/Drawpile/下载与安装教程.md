## 二、系统要求

Drawpile 的安卓版同时支持手机与平板，为压感笔设计，用手指画也可以。官方给 2.2.2 准备了两档安卓安装包：面向较新系统的 64 位包要求安卓 11 及以上，兼容包最低支持到安卓 6.0——网盘里这份按安卓 6.0 及以上的口径准备，装不上时先核对自己手机的系统版本（见[常见问题排查](常见问题排查.md)）。

| 项目 | 要求 |
| --- | --- |
| 操作系统 | 安卓 6.0 及以上 |
| 设备形态 | 手机、平板 |
| 输入方式 | 压感笔（支持倾斜），手指触摸亦可 |
| 网络 | 联机绘画需要网络，单机画画不需要 |

安装时系统会申请几类权限，都属正常：完全的网络访问（联机画布要联网）、读写共享存储（保存和打开画布文件）、防止手机休眠（绘画过程中保持亮屏）。

## 三、安卓安装步骤

1. 先把安装包拿到手：打开 [Drawpile 安装文件资源（夸克网盘）](https://pan.quark.cn/s/125bb62987a1)，转存到自己网盘后下载 `Drawpile_v2.2.2.apk`。
2. 点开下载好的 APK，系统大概率弹出「不允许安装未知来源应用」的拦截提示——Drawpile 没有上架 Google Play，从 F-Droid、网盘等渠道拿到的安装包都走这一步。选择「设置」→ 允许来源应用（你的浏览器或文件管理器）安装。
3. 回到安装界面点「安装」，等进度走完。
4. 打开应用。第一次启动会看到绘画界面，直接新建一块画布就能画；想跟朋友同画一块布，看[多人联机绘画入门](多人联机绘画入门.md)。

几点提示：

- 不同品牌的手机「未知来源」入口位置不同，一般在「设置」里搜「未知来源」或「安装未知应用」能找到；只给浏览器或文件管理器授权，比全局放开更稳妥。
- 用完想收回授权，同样在那个页面关掉开关即可。

## 四、核对安装包是否完整

下载中断可能导致安装包损坏，装不上或装上闪退时可以核一下 MD5。在电脑上打开 PowerShell，执行：

```powershell
certutil -hashfile "Drawpile_v2.2.2.apk" MD5
```

输出的哈希值与本篇第一节表格里的 MD5 一致，说明文件完整；不一致就重新下载一遍再装。

## 五、其他平台的 Drawpile 从哪拿

Drawpile 是跨平台的，同一个软件在电脑、浏览器里也有版本，且各端之间可以联入同一个房间：

| 平台 | 获取方式 |
| --- | --- |
| Windows 7~11 | [官方下载页](https://drawpile.net/download/)的安装包或免安装 ZIP |
| macOS | 官方下载页的 DMG；因尚未通过 Apple 公证，首次打开需按[官方安装说明](https://docs.drawpile.net/help/tech/installation)放行 |
| Linux | Flathub 的 Flatpak，或官方下载页的 AppImage |
| 浏览器 | 直接打开 [web.drawpile.net](https://web.drawpile.net/)，不装任何东西；iPad 与 iPhone 只有这一种途径 |
| 安卓（F-Droid 渠道） | [F-Droid 页面](https://f-droid.org/packages/net.drawpile/)，装了 F-Droid 客户端可以自动收更新 |

各平台的系统要求与安装包形态会随版本变化，以官方页面当时显示为准。装好之后想了解界面操作，接着看[手机触屏手势与压感笔设置](手机触屏手势与压感笔设置.md)。
