## 一、首次打开与界面导航

打开应用后是横屏的电视布局：首页按推荐位排片，第三方介绍里提到会根据观看历史做推荐，用得越久推荐越贴合你的口味。遥控器的基本逻辑：

| 按键 | 作用 |
| --- | --- |
| 方向键 | 在内容块之间移动焦点 |
| OK / 确认键 | 进入选中的内容 |
| 返回键 | 回上一级、退出播放 |
| 菜单键 / 设置键 | 呼出设置、播放选项 |

不同版本界面会有差异，本篇按 1.2.0 的常见布局描述，以你电视上实际显示的界面为准。

## 二、搜片：拼音与关键词

首页找搜索框，遥控器打字慢，两个实测有效的技巧：

1. **用拼音或拼音首字母**：打「kyrh」比一个个选字快得多；
2. **精简关键词**：搜「狂飙」而不是「狂飙电视剧全集免费」，词越长越搜不准。

搜不到的时候先换一种拼法再试——这也是各下载站 FAQ 里出现频率最高的建议。如果遥控器带语音键，可以先试试系统级的语音输入；应用内是否支持语音搜索，以实际界面为准。

## 三、播放控制

- 播放中按 OK 暂停 / 继续，方向键快进快退，部分版本的进度条可以直接拖动；
- 播放页里可以调清晰度和倍速，有的片源还带多语言字幕可选；
- 能调什么取决于片源本身——不是每一部片都有多档清晰度或字幕，选项是灰的就说明这条源没得调。

## 四、换线路（播放源）

播放页里一般有多条线路 / 播放源可选。这是这类聚合应用最常用的一项操作：**卡顿、加载失败时，先换一条线路再试**，大多数「放不出来」的情况靠这一步就能解决。

换线路解决不了的，按 [播放卡顿与常见问题处理.md](播放卡顿与常见问题处理.md) 里的顺序逐项排查。

## 五、收藏、历史与离线观看

- **收藏**：看到一半的剧点收藏，下次从「我的 / 收藏」直接进，不用重新搜；
- **观看历史**：自动记录，接着上次的进度看；
- **离线下载**：支持下载的片源可以先存到设备里，断网也能看。下载失败的排查见 [播放卡顿与常见问题处理.md](播放卡顿与常见问题处理.md)；
- **更新提醒**：第三方介绍提到，收藏想追的内容后有更新会提醒——入口和实际表现随版本不同，以你手上的 1.2.0 为准；
- **反馈 / 求片**：实在搜不到的片，部分版本的设置或个人页里有「反馈 / 求片」入口，可以主动提交想看的内容。

## 六、青少年模式

设置里有青少年模式开关。开启后部分内容会被隐藏，搜索也会受影响——如果你怎么都搜不到某部片，先检查是不是开着这个模式再下结论。

## 七、从手机投屏到电视

想把手机上正在看的视频投到电视上，前提有两个：手机和电视连着**同一个局域网**，且电视端应用处于打开状态。投不出来的情况（找不到设备、连接后黑屏等）按 [播放卡顿与常见问题处理.md](播放卡顿与常见问题处理.md) 第五节处理。

另外提醒两句：投屏功能依赖设备支持相应的投屏协议，个别电视 / 盒子本身不带，这种情况下换 HDMI 线直连是最省事的替代方案；部分版本的投屏还依赖第三方投屏组件（第三方 FAQ 提到的是乐播投屏），提示组件不可用或过期时，按应用内的说明更新组件再试。
