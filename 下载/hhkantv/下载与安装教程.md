## 一、先分清你要装到哪类设备

好好看TV 是一个安卓 TV 应用，主要给智能电视和电视盒子用；安卓手机、平板也能装。两条路线不一样：

| 设备 | 装法 |
| --- | --- |
| 智能电视 / 电视盒子 | 电视上一般没法直接下载 apk，主流做法是**先在电脑或手机上拿到安装包，用 U 盘拷到电视上装**（见第三节） |
| 安卓手机 / 平板 | 直接下载 apk 点开安装即可（见第四节） |

你的设备是不是安卓系统、版本够不够，先去 [电视盒子适配与系统要求.md](电视盒子适配与系统要求.md) 核对一遍再动手，免得拷完 U 盘才发现装不了。

## 二、拿到安装包

从 [好好看TV（hhkantv） 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a64441f538e6) 获取，步骤：

1. 打开上面的分享链接，登录夸克账号；
2. 选「保存到我的网盘」，转存到自己网盘后再下载（分享链接可能随时失效，转存一份最稳）；
3. 电脑端用网页或夸克客户端下载，得到一个 apk 文件（对应 1.2.0 版，约 21.68M）。

想核对下载是否完整，可以在电脑上算一下 MD5（Windows 自带命令，在 apk 所在目录打开终端执行）：

```powershell
certutil -hashfile ".\安装包文件名.apk" MD5
```

结果与 `8F738C285BD104FE3095D219B367691E` 一致（比对时忽略大小写）就说明文件完整。对不上多半是下载中断，重新下载一次。

## 三、用 U 盘装到电视 / 盒子

**第 1 步：把 apk 拷进 U 盘。** U 盘建议用 FAT32 格式，兼容性最好；部分老电视对 exFAT / NTFS 支持不全，认不出来就重格成 FAT32（单个 apk 远小于 4G，FAT32 够用）。

**第 2 步：允许安装未知来源应用。** 这是安卓系统对外来 apk 的统一限制，开关藏在系统设置里，各品牌叫法不同：

- 小米电视 / 小米盒子：设置 → 账号与安全 → 允许安装未知来源应用；
- 其他品牌：进系统设置，在「安全」「更多设置」一类目录里找「未知来源」「允许安装未知应用」等字样，找不到就用设置页的搜索功能搜「未知来源」。

各品牌入口差异不小（华为、TCL、荣耀等的具体位置各不相同），逐品牌的入口对照、找不到开关和「开了还被拦」的处理，单独整理在 [电视未知来源设置与安装被拦处理.md](电视未知来源设置与安装被拦处理.md) 里，装之前建议先看一眼。

**第 3 步：在电视上打开 apk。** 把 U 盘插到电视 / 盒子的 USB 口，用电视自带的文件管理器（或「电视管家」类的自带工具）打开 U 盘，找到 apk 确认安装。以小米为例：电视管家 → U盘安装包 → 找到 apk → 安装。电视上没有文件管理器的，先在电视自带应用商店里装一个文件管理类工具，再用它打开 U 盘。

**第 4 步：打开应用。** 装完后回到桌面，在「全部应用 / 我的应用」里找到好好看TV 的图标。上手操作见 [遥控器操作与常用功能.md](遥控器操作与常用功能.md)。

## 四、装到安卓手机 / 平板

1. 手机上用夸克 App 打开分享链接，转存后直接下载该 apk；
2. 下载完点开 apk，系统会提示「是否允许此来源安装应用」，允许后继续；
3. 安装过程中弹出的「风险提示」是安卓对应用商店之外的安装包的常规提醒，自己拿到的包自己确认即可。

装好后你会看到横屏的电视布局界面——这套界面本来就是给大屏设计的，手机上能用但不是最佳体验，手机端追剧建议还是找它对应的手机版应用。

## 五、装不上时的检查清单

- **提示「解析包出现问题 / 解析错误」**：apk 没下载完整（最常见），回第二节重新下载，最好顺手校验一次 MD5；
- **提示存储空间不足**：清一下电视 / 盒子的存储再装；
- **安装被系统拦截、提示不允许安装未知来源应用**：去 [电视未知来源设置与安装被拦处理.md](电视未知来源设置与安装被拦处理.md) 按品牌找开关、按提示对症处理；
- **提示系统版本过低**：这份安装包要求安卓 5.2 及以上，核对方法见 [电视盒子适配与系统要求.md](电视盒子适配与系统要求.md)；
- **U 盘认不出来**：换 FAT32 重格、换个 USB 口、或换一个 U 盘再试；
- **装上了但打不开 / 闪退**：去 [播放卡顿与常见问题处理.md](播放卡顿与常见问题处理.md) 看故障处理。
