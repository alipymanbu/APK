## 二、能装哪类设备

它是一个安卓 apk，只认安卓系设备：

| 设备类型 | 能否安装 | 说明 |
| --- | --- | --- |
| 安卓智能电视（Android TV / 国产智能电视） | 能 | 主要目标设备，遥控器直接操作 |
| 电视盒子（小米盒子、当贝盒子等安卓系盒子） | 能 | 同上；非安卓系统的盒子装不了 |
| 安卓手机 / 平板 | 能 | 界面按电视横屏设计，手机上只是应急用 |
| 非安卓系统的电视（如 webOS / Tizen 系统的部分外资品牌机型） | 不能 | 安卓 apk 无法安装；想用只能外接一个安卓盒子 |

华为智慧屏（HarmonyOS）比较特殊：它官方支持 U 盘安装第三方 apk（入口在「智慧屏管家 → 应用管理 → 安装未知应用」），也在可装之列，具体设置见 [电视未知来源设置与安装被拦处理.md](电视未知来源设置与安装被拦处理.md)。

## 三、动手前自查三件事

1. **系统**：电视 / 盒子上进「设置 → 关于」，看系统是不是安卓、版本号是否 ≥ 5.2。部分第三方页面标称支持更低的安卓版本，以你设备上的实际安装结果为准。
2. **存储**：安装包 21.68M，安装展开后占用更大，剩余空间留出几百 MB 比较稳妥。另外多条电视使用经验都提到：电视可用存储所剩无几（不到 1G）时，应用极易闪退——装之前先把不用的应用和缓存清一清。
3. **安装许可**：电视上装 apk 需要先打开「未知来源应用」许可，具体入口见 [下载与安装教程.md](下载与安装教程.md) 第三节。

三项都过了，就可以照教程篇的步骤装了；装完之后的核对方法见下一节。

## 四、名字相近、包名不同的几款应用

网上同时流传着好几个名字相近的应用，检索到的包名就至少有三种：

| 名字（各下载站写法不一） | 包名 |
| --- | --- |
| 好好看TV（本套文档对应的这份） | com.hhk.tv1 |
| 好好看TV版 | com.hhk.tvd1 |
| 好好看影视TV | com.hhk.dt1 |

它们不是同一个安装包，界面与内容可能都有差异。几点实用结论：

- **认包名，别认图标和名字**：装机多了容易分不清哪个是哪个，在「设置 → 应用管理 → 应用信息」里看包名最准；
- 不同包名的版本可以共存于同一台设备，但没必要装一堆，留一个顺手的即可；
- 从别处下载到的「好好看TV」如果版本号与本文档写的 1.2.0 不同，属正常情况——那不是同一份安装包；
- 有用户在电视论坛反馈：这类聚合 TV 应用不同名字、不同版本之间界面与内容高度相似，某个版本闪退或不好用时，换一个版本（哪怕名字不同）常常就正常了。这是单个用户的反馈，仅供参考。

## 五、版本更新怎么处理

- 网盘里是 1.2.0；如果之后拿到了更新的版本，用新 apk 重新走一遍安装流程即可。**同包名覆盖安装一般会保留原来的数据**（收藏、历史等），不用先卸载；
- 如果装到的是**不同包名**的版本，它会作为独立应用出现，原来那个不会自动被替换，注意别混着用；
- 升级后界面与功能可能变化，本套文档的操作说明以 1.2.0 为准，其他版本以实际界面为准。
