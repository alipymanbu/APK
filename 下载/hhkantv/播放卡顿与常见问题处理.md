## 一、播放失败或一直缓冲

按这个顺序处理，多数在前两步就解决：

1. **换线路**：播放页里换一条播放源。这类聚合应用每部片往往有多条线路，某一条挂了很常见；搜同名资源时留意有没有多个条目，不同条目带的线路组也不一样；
2. **换网络环境**：Wi-Fi 换有线、或临时用手机热点对比。第三方 FAQ 提到个别线路对某些运营商的宽带不友好，换网就能判断是不是网络的问题；
3. **重启应用**，还不行就重启电视 / 盒子；
4. 都不行说明这条线路暂时失效，过一段时间再试，或换同名资源下的其他线路。

## 二、有声音没画面、音画不同步

进播放器的设置，把「硬件加速」关掉再播（这是第三方页面 FAQ 给出的解法）。注意关掉硬解后改走 CPU 软解，配置较低的设备可能会变卡——两种设置各试一次，选画面和声音都正常的那种。

## 三、搜不到想看的片

依次检查：

1. **青少年模式**：设置里看它是否开着，开着会隐藏一部分内容，搜不到片时先关掉它再试；
2. **换关键词**：用拼音、拼音首字母或更短的词再搜一遍，确认片名没有错别字；
3. **换叫法**：同一个片常有不同译名或简称，换一种写法搜；
4. 都搜不到，就是片源暂时没收录，这类聚合应用的片库随线路更新，过段时间再看；部分版本提供「反馈 / 求片」入口，可以主动提交想看的片名。

## 四、离线下载失败

- 先确认这一集**在线能正常播放**——在线都放不出来的线路，下载同样会失败；
- 换一条线路，再对同一集重新发起下载；
- 检查设备剩余存储空间是否充足；
- 若是刚升级的新版本下载总失败，可在设置里清一下应用缓存后重试（清缓存不影响收藏和历史）。

## 五、投屏失败

按顺序核对：

1. 手机和电视确认连着**同一个 Wi-Fi**——很多路由器的 2.4G 和 5G 是两个网络名，连岔了就互相找不到；
2. 路由器开了「AP 隔离 / 访客网络」的先关掉，这类设置会阻断设备互访；
3. 先把电视端应用打开，再从手机发起投屏；
4. 部分版本的投屏依赖第三方投屏组件（第三方 FAQ 提到的是乐播投屏），提示组件不可用或过期时，按应用内说明更新组件再试；
5. 设备本身不支持投屏协议的话，怎么调都不会出来——改用 HDMI 线直连（手机需要转接头）最省事。

## 六、整个应用打不开或全部内容加载不出来

1. 先判断是不是网络问题：电视上打开其他联网应用看看能不能用；
2. 只有这个应用加载不出，多半是它的内容接口阶段性失效——这类聚合应用的接口随时间变动是常态，等应用更新或过几天再试；
3. 第三方页面还建议过更换 DNS（如 `223.5.5.5` 或 `180.76.76.76`），属于进阶操作，路由器和电视上都可改，改完重启网络再试；
4. 应用一打开就闪退的，按这个顺序处理：
   - 清缓存、清应用数据后重新打开（设置 → 应用管理 → 好好看TV → 清除缓存 / 清除数据）；
   - 拔掉电视电源等半分钟再通电，做一次完整的冷启动——直接拔电重启是电视使用中很伤系统的操作，只在必要时做；
   - 看剩余存储：多条电视使用经验都提到，可用空间所剩无几（不到 1G）时应用极易闪退，卸载几个不用的应用再试；
   - 有用户反馈过旧版本（1.1.0）存在打开即闪退的问题、换新版本后恢复正常——清缓存无效的话，换一份版本号更新的安装包覆盖安装试试（安装包获取见 [下载与安装教程.md](下载与安装教程.md) 第二节，同包名覆盖安装一般保留收藏和历史）；
   - 配置很低的老电视跑新版仍闪退，多半是设备与版本不兼容，外接一个电视盒子是通用解法。

## 七、安装与更新相关的问题

- **提示解析包错误**：安装包没下载完整，重新拿一份 [好好看TV（hhkantv） 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a64441f538e6) 再装，完整性的校验方法见 [下载与安装教程.md](下载与安装教程.md) 第二节；
- **系统版本过低装不上**：去 [电视盒子适配与系统要求.md](电视盒子适配与系统要求.md) 核对系统要求；
- **重装会不会丢观看记录**：同包名覆盖安装一般保留收藏和历史；先卸载再装就有清空的风险，介意的话优先用覆盖安装。

## 八、对这类应用有个预期

聚合类影视应用的线路与片库会随时间变动：某段时间部分线路失效、个别片临时搜不到，属于这类应用的常态，不是你设备坏了。遇到时优先用本篇第一、三节的顺序排查，剩下的交给时间——等线路恢复或应用更新。
