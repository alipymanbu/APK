## 一、这道开关是干什么的

安卓系统默认不允许安装应用商店之外的 apk，「未知来源」就是给侧载放行的总开关。好好看TV 这类从网盘拿安装包装进电视的应用，都必须先开它。开关位置各品牌不统一、菜单名也不一样——先按第二节的表对号入座，找不到再看第三节。

## 二、各品牌入口对照

以下整理自各品牌官方支持页与公开资料（截至 2026-09）；系统升级后菜单经常变动，以你电视上实际显示为准。

| 品牌 | 常见入口 |
| --- | --- |
| 小米电视 / 小米盒子 | 设置 → 账号与安全 → 允许安装未知来源应用 |
| 华为智慧屏 | 全部应用 → 智慧屏管家 → 应用管理 → 安装未知应用，授权后执行安装；部分型号在 设置 → 系统 → 开发者选项 里 |
| TCL / 雷鸟 | 设置 → 应用 → 安全与限制（Security & Restrictions）→ 允许安装未知来源 |
| 荣耀智慧屏 | 与华为相近；安装时若弹「未经安全审核」提示，选「允许本次安装」即可继续 |
| 其他品牌 | 进设置，在「安全」「更多设置」一类目录里找「未知来源」「允许安装未知应用」，有设置搜索框的直接搜 |

两点补充：

- 华为智慧屏官方还支持两种不用 U 盘的方式：手机通过「华为分享」把安装包分享到智慧屏，或用「智慧生活」App 推送安装（需连同一 Wi-Fi 且完成设备绑定）；
- 华为官方同时提醒：非应用中心安装的应用可能存在适配问题。这属于侧载应用的普遍情况，遇到个别界面不适配，换个版本或换台设备是常规处理。

## 三、找不到开关 / 开关是灰的

1. **先升级系统**：设置 → 系统更新。老版本系统可能根本没有这个选项；
2. **试试激活开发者模式**：部分品牌在 设置 → 关于（或「关于本机」）里对着「版本号」连点 7 次，激活后返回安全设置就能看到「未知来源」「USB 调试」等选项；
3. **还是找不到**：在设置页的搜索功能里搜「未知来源」；搜不到的机型看第五节，判断系统是不是被深度定制过。

## 四、开了开关还是装不上

按系统提示对号入座：

- **提示「暂不支持未知来源应用安装」**：多半是系统版本过旧，先升级系统再装；
- **弹出「安全审核 / 未经安全审核」警告**：这不是拒绝，是提醒——选「允许本次安装」继续即可；
- **提示「解析包出现问题」**：跟权限无关，是 apk 文件没下载完整，重新拿一份再装，完整性的核对方法见 [下载与安装教程.md](下载与安装教程.md) 第二节；
- **全都试过仍失败**：少数深度定制系统内置「白名单」机制，只放行官方认证的应用——开关开了照样拦。这类设备只能从自带商店装应用，想用第三方应用可以外接一个安卓电视盒子。

## 五、动手前先判断自家电视的「开放度」

装之前花一分钟判断，能省下后面所有折腾：

- 进自带应用商店看一眼：应用丰富、带搜索功能 → 大概率能自由安装第三方 apk；
- 商店里只有寥寥几个精选应用、连搜索都没有 → 系统可能受限，能不能装以实际测试为准；
- 非安卓系统的机型（判断方法见 [电视盒子适配与系统要求.md](电视盒子适配与系统要求.md)）直接装不了安卓 apk，外接安卓盒子是唯一解。
