## 一、什么时候用网页版接收

电脑端客户端只覆盖 Windows 和 macOS；除此之外的三种情况，网页版是最顺手的接收方式：

- **公司或图书馆的电脑**：没有权限装软件，浏览器打开就能收投屏。
- **Linux 电脑**：官方没有桌面客户端，网页版是唯一接收途径。
- **临时借用的机器**：不想装东西、用完即走。

网页版地址是 `webcast.airdroid.com`，支持的浏览器包括 Chrome、Microsoft Edge、Safari、Yandex 等。

## 二、网页版接收的步骤

1. 在接收的电脑浏览器里打开 `webcast.airdroid.com`，页面会显示一个投屏码。
2. 手机端打开 AirDroid Cast，进入屏幕投射，输入这个投屏码（同一 Wi-Fi 下免费直连，跨网络走远程投屏需要会员）。
3. 电脑浏览器里确认投屏请求，画面就出现在网页里。

网页版与客户端的能力有差异：多设备同时接收、USB 连接、AirPlay 这些只有桌面客户端支持，网页版以基本的画面接收为主。官方建议用较新版本的 Chrome 或 Edge 打开，体验最稳；这个页面要常用，直接存成浏览器书签。

### 网页版还能接收电脑屏幕

方向反过来也成立：想把一台电脑的画面投到另一台没装软件的电脑，在发送端的 AirDroid Cast 桌面客户端里点**「分享此电脑屏幕」**，输入网页端显示的投屏码即可。另外，Windows / macOS / Linux 的浏览器自己也能当发送端，把本机屏幕按网页端提示共享出去。

### 网页打不开的排查顺序

- 先确认接收端能正常上网；
- 清一下浏览器缓存再刷新；
- 检查浏览器是否拦截了 Cookie，允许后重试；
- 换一个支持的浏览器打开。

这些仍解决不了、或投屏中途断开，去[连接失败与画面卡顿排查](连接失败与画面卡顿排查.md)对症状找原因。

## 三、投到 Android TV 电视上

电视端是独立的应用 **AirDroid Cast TV**，与手机版、电脑版是三个东西，别装错：

1. 在电视上安装 AirDroid Cast TV（要求电视系统为 Android 5.0 及以上）。
2. 打开后电视上会显示投屏码。
3. 手机端 AirDroid Cast 输入电视上的投屏码，发起投屏。

支持的机型以官方说明为准：主流安卓智能电视如小米、康佳、海信、TCL、创维、华为等都有覆盖，具体到某个型号能不能装，以电视应用市场里搜不搜得到为准。

## 四、反向投：电脑画面投到手机

AirDroid Cast 不只是「手机投出去」一个方向：电脑屏幕也能反过来投到手机 / 平板上——在手机端显示接收用的投屏码，电脑客户端扫码或输码连接即可。演示时把手机当第二块屏用，或躺着用平板看电脑上的资料，都是这个用法。同样地，跨网络反向投需要会员。
