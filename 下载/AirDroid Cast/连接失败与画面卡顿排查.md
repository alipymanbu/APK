# AirDroid Cast 连接失败与画面卡顿排查

> 本篇按症状排查 AirDroid Cast 投屏的常见问题：连不上、频繁断开、黑屏、没声音、画面卡顿，以及网页版打不开。多数问题出在手机后台被杀和网络，不用重装。

## 一、先对症状，再动手

| 症状 | 最可能的原因 | 直接跳到 |
| --- | --- | --- |
| 输了码连不上 | 网络不通 / 码输错 | 第二节 |
| 能连但频繁断开 | 手机后台被系统杀 | 第三节 |
| 画面黑屏但有声音 | 视频类 App 的版权保护 | 第五节 |
| 画面正常没声音 | 没开共享设备音频 | 第六节 |
| 画面卡顿延迟高 | Wi-Fi 信号弱 / 带宽被占 | 第七节 |
| 网页版页面打不开 | Cookie / 缓存 / 浏览器 | 第八节 |

## 二、连不上

按顺序过一遍：

1. **确认两端在同一个 Wi-Fi**（免费投屏的前提；跨网络投屏需要会员账号登录，见[免费版和会员功能区别](免费版和会员功能区别.md)）。
2. **重新核对 9 位投屏码**——这是最高频的出错点，投屏码每次打开接收端可能会变。
3. 两端都关掉 AirDroid Cast 再重开一次；还不行就重启手机和电脑。
4. 用手机浏览器随便开个网页，确认手机网络本身是通的。

第一次连接时，电脑端弹「允许设备投屏」要点**允许**，手机端还要在系统授权页点**立即开启**——任何一端卡住不确认，连接都不会完成。

## 三、频繁断开：把后台留住

无线投屏时，系统省电机制会杀后台应用，这是断连的头号原因。USB 连接不受此影响，断了就考虑换 USB（需会员）。无线方式按四步设置（不同品牌入口名称略有差异）：

1. **休眠时保持 WLAN 连接**：「设置 → WLAN → 高级 / 高级设置」里开启。
2. **允许后台运行**：「设置 → 应用管理 / 权限管理」或手机管家的「内存清理 / 锁屏清理」里，把 AirDroid Cast 设为不清理或加入白名单。
3. **关闭省电模式、忽略电池优化**：「设置 → 电池 / 电池管理」。
4. **锁定后台**：最近任务（多任务）界面里，下拉 AirDroid Cast 卡片，出现锁形图标即锁定成功。

Vivo、华为等品牌的后台策略更激进，官方帮助中心对两个品牌有分机型专文。另外两个立竿见影的做法：**投屏时给手机插着电**、**把自动息屏关掉**。

### 华为 / 鸿蒙手机的额外四项

华为手机（EMUI / Harmony 各版本）离线、连不上、频繁断开，官方口径基本都指向同一件事：进程在后台被杀。除上面的通用四步外，华为机型还要多做几项（不同版本入口略有差异）：

1. **应用启动管理改手动**：「设置 → 应用 → 应用管理 → AirDroid Cast → 应用启动管理」，关闭自动管理，把**允许自启动、允许关联启动、允许后台活动**三项全部打开。
2. **流量使用情况全允许**：移动数据、WLAN、后台数据、漫游数据都勾上；「智能省流量」关闭（在「设置 → 移动网络 → 流量管理」）。
3. **电池更深一层**：省电模式和**超级省电**都关；「更多电池设置 → 休眠时始终保持网络连接」开启。
4. **多任务锁定**：最近任务里把 AirDroid Cast 卡片往下滑，右上角出现锁图标才算锁上。

HarmonyOS 5 及以上版本收紧了后台策略：下拉加锁能保证卡片不被「一键清理」，但**系统内存紧张时锁定应用仍可能被清**，长时间投屏前关掉省电模式、插上电源最稳。

## 四、投屏权限被误关

投屏中断、重新连也弹不出授权页时，去「设置 → 应用管理 → AirDroid Cast → 权限」逐项检查：摄像头（扫码）、麦克风（传声音）、「显示在其他应用上层 / 投屏」这类权限被关了都会导致功能失效，重新允许即可，不需要重装 App。

## 五、画面黑屏但有声音

部分视频类 App（Netflix 这类流媒体最典型）出于版权保护（DRM），画面本身禁止被截取，投出去就是一块黑屏，声音反而正常。这不是 AirDroid Cast 的故障，换普通应用投屏即可验证；版权 App 的内容只能在它自己允许的设备上看。

## 六、没声音

三处都开了才有声音：

1. 投屏界面上**「共享设备音频」开关**打开；
2. 首次启动时**录音权限**给过（没给的去应用权限里补）；
3. 电脑端音箱本身能正常出声（放首歌试试）。

## 七、卡顿、延迟高

- 手机和电脑**离路由器近一点**，或换 5GHz Wi-Fi；
- 减少同一网络里占带宽的其他设备（下载、网盘同步等）；
- 在投屏界面**降低画质设置**，数据量小了会流畅很多；
- 对延迟敏感的场景（游戏、直播）直接换 **USB 连接**，稳定性完全不同。

## 八、网页版打不开

按顺序：确认接收端能上网 → 清浏览器缓存 → 允许 Cookie → 换 Chrome / Edge / Safari / Yandex 试试。页面能打开但收不到投屏，回到[手机投屏到电脑步骤](手机投屏到电脑步骤.md)核对投屏码与网络。

排查下来发现是版本太旧导致的兼容问题，从[下载与安装教程](下载与安装教程.md)的网盘资源重装对应版本，或到官网取最新版。
