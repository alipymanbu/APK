# 直播与录屏采集投屏画面

> 本篇讲怎么把 AirDroid Cast 投到电脑上的手机画面，进一步喂给 OBS、抖音直播伴侣这类直播或录屏软件，做手游直播、网课录制。还没把画面投上电脑的，先看[手机投屏到电脑步骤](手机投屏到电脑步骤.md)。

## 一、原理：直播软件采集的是电脑屏幕

AirDroid Cast 不直接对接直播软件。你要做的是两步接力：

1. 手机画面投屏到电脑（AirDroid Cast 负责这一步）；
2. 直播 / 录屏软件在电脑上**采集这块屏幕**（OBS、抖音直播伴侣等负责这一步）。

直播观众看到的，就是投屏窗口里那份实时画面。

## 二、配合 OBS 直播或录制

1. 在 [obsproject.com](https://obsproject.com/) 下载并安装 OBS，打开。
2. 「来源」面板点 **+**，选**显示器捕获**（投屏窗口全屏时）或**窗口捕获**（只采集 AirDroid Cast 那个窗口），确认后画面就进了 OBS 场景。
3. 直播：在 OBS「设置 → 推流」里填直播平台给的推流地址，点「开始推流」。
4. 录屏：直接点「开始录制」，输出文件在「设置 → 输出」指定的目录。

手游直播推荐用 USB 线投屏：延迟低、不受 Wi-Fi 波动影响，画面在直播里更稳（USB 投屏需要会员，见[免费版和会员功能区别](免费版和会员功能区别.md)）。

## 三、配合抖音直播伴侣

手机投屏到电脑后，在电脑上装抖音直播伴侣并登录，点左上角「+」把投屏画面加进场景，拖到合适大小即可开播。注意：直播伴侣需要先开通直播权限，没权限时加不了场景、开不了播。

## 四、声音怎么进直播

OBS 采集显示器画面时不会自动带上手机的声音。让手机声音进直播的路子：

1. 投屏时在 AirDroid Cast 界面开**「共享设备音频」**，手机声音从电脑音箱 / 耳机出来；
2. OBS 里加一个**音频输出捕获**来源，采集电脑正在输出的声音。

这样游戏音效、语音都会随画面一起进直播间。要边直播边听手机麦克风说话，检查首次启动时录音权限是否给过，排查见[连接失败与画面卡顿排查](连接失败与画面卡顿排查.md)。

## 五、卡顿与画质取舍

直播对延迟比单纯投屏更敏感，几个此消彼长的点提前想清楚：

- 画质调低一档，直播流畅度明显上升（投屏界面里就能调）；
- 无线投屏省事但吃网络，电脑尽量走有线网、手机离路由器近一点；
- 黑屏问题在直播里同样存在——版权类 App 的画面投出来就是黑的，别安排进直播内容。
