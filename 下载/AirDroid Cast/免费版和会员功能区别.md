## 一、免费版能做到哪一步

免费账户的能力集中在「同一 Wi-Fi 下的无线投屏」，具体是：

- 手机（安卓 / iOS）和电脑（Windows / macOS）在**同一个局域网**内，扫码或输投屏码互投；
- 一台电脑同时接收**最多 5 台设备**的画面（无线方式）；
- **双向语音**：电脑和手机互相说话；
- 浏览器网页版接收（`webcast.airdroid.com`）。

免费版不需要登录账号即可做局域网投屏。超出这个范围——跨网络、USB 线、AirPlay、电脑控制手机——都要会员。

## 二、各档会员解锁什么（截至 2026-09 的官方口径）

官方把会员分成「远程投屏」和「投屏 & 控制」两类，各分月付与年付；中国区参考价为基础版约 130 元/年、标准版约 180 元/年（国际区 19.99 / 29.99 美元一年），**以官方价格页当时显示为准**：

| 功能 | 免费账户 | 基础版（远程投屏） | 标准版（投屏 & 控制） |
| --- | --- | --- | --- |
| 同一 Wi-Fi 无线投屏 | 有 | 有 | 有 |
| USB 线投屏 | 无 | 有 | 有 |
| AirPlay 服务（iOS 投电脑） | 无 | 有 | 有 |
| 跨网络远程投屏 | 无 | 有 | 有 |
| 电脑控制安卓设备 | 无 | 无 | 有（安卓 7.0+，需装控制插件） |
| 电脑控制 iOS 设备 | 无 | 无 | 有 |
| 可同时登录的接收端数 | 1 | 1（年付 3） | 1（年付 3） |
| 桌面端同时接收投屏数 | 5 | 5 | 5 |

几条容易踩的口径：

- **年付和月付在登录设备数上不同**：年费会员可同时在 3 台电脑登录同一账号（客户端 1.1.2.0 及以上版本支持），月付只能 1 台。
- **USB、AirPlay、多设备接收、设备控制只在桌面客户端里可用**，网页版接收端不具备这些。
- **控制安卓要走插件**：标准会员在电脑端控制安卓手机时，会提示在手机上装一个控制插件，手机系统要求 Android 7.0 以上；USB 连接对控制更稳。
- USB 投屏一次只能投一台设备（最多一台安卓加一台 iOS 同时各占一路）。

## 三、AirDroid Cast 和 AirDroid 个人版的区别

两者是同一家的两条产品线，选错会白折腾：

| | AirDroid 个人版 | AirDroid Cast |
| --- | --- | --- |
| 定位 | 手机管理全家桶：文件传输、通知、短信、镜像等 | 专注投屏与控制 |
| iOS 支持 | 不支持控制与镜像 iOS | 支持投屏与控制 iOS |
| 发起方式 | 需要两端绑定 AirDroid 账号，从控制端直接发起 | 手机扫码 / 输码发起，电脑端确认 |
| 适合谁 | 想在电脑上管手机的日常用户 | 只想投屏、开会演示、教学的人 |

如果你只需要「把手机画面弄到电脑上」，装 Cast 就够；要文件传输、桌面通知那些，才用个人版。
