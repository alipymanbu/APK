## 一、装不上：应用未安装 / 解析包出现问题

最常见的原因是 **CPU 架构对不上**：网盘这份 Pydroid 3 安装文件资源是 x86_64 构建，适合模拟器与 Intel / AMD 处理器的设备；arm64 的实体手机装它会直接被拒绝。先用 CPU 信息工具确认自己设备的 ABI，再决定装哪份，判断方法与核对步骤见[下载与安装教程.md](下载与安装教程.md)。

排除了架构还装不上，按顺序检查：

- 安装包下载完整吗？MD5 对得上吗（安装教程里给了核对命令）；
- 之前装过别的来源的同包名版本——先卸载再装；
- 内置存储剩余空间够不够（至少 250 MB）。

## 二、pip 装库报错

**`No matching distribution found`**：PyPI 上没有适配 Android 或你这个 CPU 架构的包。优先确认 Pydroid 的预编译库仓库有没有这个包——科学计算类覆盖最全，系统相关的库移植优先级低。装库的完整排查表在[pip安装第三方库.md](pip安装第三方库.md)。

**下载慢、超时**：换国内镜像源：

```bash
pip install 包名 -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**装到一半失败**：多半是空间不足，清理后重装。

## 三、import 报 ModuleNotFoundError

按顺序核对：

1. 库真装上了吗——在终端 `pip list` 看一眼有没有它；
2. 名字对不对——装的名字和 import 的名字经常不一样（比如装 `beautifulsoup4`、import 的是 `bs4`；装 `pillow`、import 的是 `PIL`）；
3. 都对还是报错——重启 Pydroid 3 再试，个别库要重启后才被识别。

报错里带 `dlopen failed: library "xxx.so" not found` 的另算：它说明这个库（或其依赖）要加载一个 Android 系统里不存在的原生库。典型是 pyttsx3（文字转语音库），Stack Overflow 上的采纳结论是它在 Android 上没法用。碰到这类报错，先搜「库名 + Android」确认有没有可用的替代实现，别反复重装指望它自己好。

文件打不开、保存失败这类问题很多是存储权限没给到位，权限的授予路径见[文件保存与存储权限.md](文件保存与存储权限.md)。

## 四、matplotlib 图弹不出来

matplotlib 默认按 GUI 模式跑，弹窗等图是正常行为；如果你看到程序「停在」那里，关掉图窗口就会继续。反过来只想看终端输出不弹图，在文件里加 `#Pydroid run terminal`。运行模式与魔法注释的完整说明见[写代码运行与调试.md](写代码运行与调试.md)。

## 五、内置的 Python 是什么版本

在解释器或脚本里跑一行就知道：

```python
import sys
print(sys.version)
```

官方介绍里长期写的是 Python 3.8；2026 年 9 月的版本更新日志提到解释器已升级到 Python 3.13 系列。不同时期、不同渠道的安装包内置版本可能不同，以你设备上这行命令的输出为准，别照抄教程里的版本号去装库。

## 六、跑长任务时被系统杀掉

Android 对后台应用限制严格，长时间计算或挂着的服务中途消失，一般是系统省电机制干的。三道措施一起做：

- 把 Pydroid 3 从电池优化里放行（设置 → 应用 → 电池）；
- 任务期间保持屏幕亮着；
- 在 Pydroid 3 自己的设置里找省电相关的开关（社区教程里提到关闭「不在使用时暂停」一类选项），一并关掉。

挂着的服务被杀的具体场景（比如把手机当 Web 服务器用），见[手机上跑Web服务.md](手机上跑Web服务.md)。

## 七、还有同名应用别认错

iOS 的 App Store 上另有一个同名「Pydroid 3」，与本文讲的 Android 版（开发者 IIEC）不是同一家的产品；搜资料时认准 Android 版的包名 `ru.iiec.pydroid3`。
