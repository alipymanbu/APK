## 一、装 Flask

先在 Pydroid 3 里装库：

```bash
pip install flask
```

装库的两条路（Pip 界面或终端命令）与排错见[pip安装第三方库.md](pip安装第三方库.md)。

## 二、最小 Flask 应用

新建脚本写入：

```python
from flask import Flask

app = Flask(__name__)

@app.route('/')
def hello():
    return 'Hello from Pydroid 3'

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=8080)
```

注意 `host='0.0.0.0'` 这一项：不写它，服务只对本机开放；写了它，同一网络里的其他设备才连得进来。

运行后，用手机自己的浏览器打开 `http://localhost:8080` 就能看到页面。

## 三、同一 Wi-Fi 下的其他设备访问

想让电脑、平板或另一部手机打开手机上的服务：

1. 确保两台设备连着同一个 Wi-Fi；
2. 在手机「设置 → WLAN → 当前网络详情」里查到本机 IP（形如 `192.168.x.x`）；
3. 其他设备的浏览器打开 `http://192.168.x.x:8080`（换成你查到的 IP）。

安全提醒：`0.0.0.0` 意味着同一网络里的任何人都能访问这个服务，家里网络无所谓，公共 Wi-Fi 下别这么开。

## 四、不装任何东西的最简版

只是想临时分享几个文件或试一下服务长什么样，标准库就够了。在终端里切到目标目录，执行：

```bash
python -m http.server 8080
```

当前目录就成了网站根目录，浏览器访问 `http://localhost:8080` 会列出文件清单。

## 五、两个绕不开的限制

- **外网访问**：上面两种方式只覆盖本机与局域网。想让互联网上的设备访问，需要内网穿透工具（如 `pip install pyngrok` 后用它生成公网地址）或路由器端口转发，属于另一个话题。
- **后台被杀**：服务挂着不动时，Android 的省电机制可能把它杀掉。应对办法（电池优化放行、保持屏幕亮着）见[常见问题与报错解决.md](常见问题与报错解决.md)。

性能上限由手机硬件决定，拿来练手、测试接口、局域网小工具都现实；拿它当正式线上服务跑就不合适了。调试这个应用本身的方法（断点、日志定位）见[写代码运行与调试.md](写代码运行与调试.md)。
