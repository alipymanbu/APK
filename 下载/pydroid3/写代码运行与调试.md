## 一、编辑器里你会用到的功能

- **多标签页**：同时开多个文件来回切。
- **扩展键盘条**：键盘上方一排 Python 常用符号（括号、冒号、下划线、Tab 之类），手机上少切很多次输入法。
- **语法高亮与主题**：配色在设置里换。
- **代码导航**：从调用处跳到定义或赋值处，再跳回来。
- **保存**：编辑器里保存 / 另存为，选好目录再起名；要打开手机里已有的 `.py` 文件，第一次会要求授予存储权限。放哪个目录、公共目录与私有目录的差别，见[文件保存与存储权限.md](文件保存与存储权限.md)。

代码预测、自动缩进、实时代码分析这三项在官方列表里标了星，属于 Premium 功能，划分见[免费版与Premium区别.md](免费版与Premium区别.md)。

## 二、运行程序与看报错

写完点运行按钮，输出显示在控制台。程序报错时会弹出日志窗口：

- **红色那行是关键**：错误类型和提示都在里面；
- 定位不到问题时**往红色行的上面多看一两行**，出错的调用链通常在前面；
- 语法错误会直接标出有问题的行，改完再跑。

## 三、断点调试（PDB）

Pydroid 3 内置 PDB 调试器，用法：

1. **点行号**下断点（再点一次取消）；
2. 点调试运行，程序停在断点处；
3. 单步执行、查看变量，支持监视（watch）特定表达式。

比起在代码里到处插 `print()`，断点适合排查「变量在哪一步开始不对」这类问题。

## 四、终端与交互模式

Terminal 标签是一个完整的终端模拟器（支持 readline，pip 里可装）。你可以：

- 直接敲 `pip` 命令装库；
- 敲 `python` 进交互式解释器，一行一行试语法；
- 跑命令行脚本。

## 五、`#Pydroid run` 魔法注释：控制程序怎么跑

Pydroid 3 会根据你 import 了什么自动选择运行方式（GUI 还是终端），也可以在文件第一行用注释强制指定：

| 写法 | 作用 |
| --- | --- |
| `import kivy` / `from kivy` / `#Pydroid run kivy` | 按 Kivy（SDL2）GUI 模式跑 |
| `import PySide6` / `from PySide6` / `#Pydroid run qt` | 按 Qt GUI 模式跑 |
| `#Pydroid run sdl2` / `#Pydroid run tkinter` / `#Pydroid run pygame` | 对应的 GUI 模式 |
| `#Pydroid run terminal` | 强制在终端模式跑 |

最后一行对 matplotlib 特别有用：matplotlib 默认自动按 GUI 模式运行，如果你只想在控制台输出计算结果而不弹图，加 `#Pydroid run terminal` 就不会弹窗口；反过来，想让图正常弹出来，就不要加。画图的具体写法见[图形界面与绘图.md](图形界面与绘图.md)。

## 六、从自带示例开始改

应用内置了一套开箱即用的示例，涵盖基本语法和常用库。改示例比自己空着写快：先跑通一份现成代码，再一点点换成你的逻辑。运行中卡住的现象多半能对上[常见问题与报错解决.md](常见问题与报错解决.md)里的条目。
