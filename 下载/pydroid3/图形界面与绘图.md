## 一、Tkinter：最快出窗口的路

Tkinter 是标准库，Pydroid 3 完整支持，装都不用装。一个最小窗口：

```python
import tkinter as tk

root = tk.Tk()
root.title("hello")
tk.Label(root, text="在手机上跑起来的窗口").pack(padx=40, pady=20)
root.mainloop()
```

保存后直接运行即可。如果你 import 了 tkinter 它还是按终端模式跑，参考[写代码运行与调试.md](写代码运行与调试.md)里的魔法注释一节，加 `#Pydroid run tkinter` 强制指定。

## 二、Kivy 与 PySide6：做正经一点的界面

两个框架都要先装，怎么装见[pip安装第三方库.md](pip安装第三方库.md)：

- **Kivy**：Pydroid 3 为它配了 SDL2 后端。装好后运行一个 `import kivy` 的脚本，Pydroid 会自动按 Kivy 模式启动。
- **PySide6（Qt）**：在 Quick Install 仓库里提供；matplotlib 的 PySide6 后端也做了适配，画图不需要额外代码。
- **Kivy 版 matplotlib**：同样在 Quick Install 仓库里，想在 Kivy 界面里嵌图用它。

框架怎么检测、怎么强制指定运行模式，那张魔法注释表在[写代码运行与调试.md](写代码运行与调试.md)里。

## 三、pygame：写小游戏

pygame 2 可用，和桌面端写法一致，装好后 `import pygame` 即会按对应模式运行。跑循环时注意手机屏幕方向和触控输入和桌面键盘的差异，改示例比从零写省事。

## 四、matplotlib 画图

装好 matplotlib 后，普通脚本默认按 GUI 模式运行，图会直接弹出来：

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [1, 4, 9, 16]
plt.plot(x, y)
plt.show()
```

两个常撞的点：

- 图弹出来了但程序好像「卡住」——那是 `plt.show()` 的窗口在等关闭，正常现象；
- 只想要终端输出、不想弹图——文件里加 `#Pydroid run terminal`。

**中文显示成方块**是另一类高频问题：matplotlib 默认字体不含中文字形（官方文档明确写 DejaVu 默认字体不覆盖中日韩文字），所以中文标签全变成「豆腐块」。桌面上的惯用解法（设 `SimHei`）在手机上不管用，因为设备里没有这个字体。可行做法是找一个带中文的 `.ttf` 字体文件放进公共目录，在画图前注册并指定：

```python
import matplotlib.pyplot as plt
from matplotlib import font_manager

font_manager.fontManager.addfont('/sdcard/Documents/Pydroid3/某中文字体.ttf')
plt.rcParams['font.sans-serif'] = ['该字体的名称']
plt.rcParams['axes.unicode_minus'] = False  # 负号正常显示
```

字体文件的存放位置见[文件保存与存储权限.md](文件保存与存储权限.md)；`font.sans-serif` 里要填字体注册后的名称（不是文件名），装好后可以先 `print(font_manager.fontManager.ttflist)` 对照。

## 五、这些图形库要 Premium

官方列表里标了星、只有 Premium 用户能用的库：

- **OpenCV**（且要求设备支持 Camera2 API）；
- **TensorFlow**；
- **PyTorch**。

做机器学习、计算机视觉方向会用到它们；纯画图与常规 GUI 用免费版就够。划分与原因见[免费版与Premium区别.md](免费版与Premium区别.md)。
