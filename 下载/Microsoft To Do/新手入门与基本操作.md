## 一、这是什么

Microsoft To Do 适合想把「要做的事」集中到一处的人：购物、家务、工作事项都建成任务，按天推进。安卓版装好、登录 Microsoft 账号后（安装见 [下载与安装教程.md](下载与安装教程.md)），你面对的核心概念只有两层：**列表**（装一类事的容器）和**任务**（列表里的一条条待办）。本篇按上手顺序讲这两层怎么用。

## 二、列表：先把容器建出来

- 左侧菜单点 **+ 新建列表**，输入名字回车即可。列表可以改名、换颜色背景（列表右上角「…」里选颜色或图片）。
- 列表多了可以用**列表组**归拢：新建列表按钮旁边有组图标，建组后把列表拖进去；手机上长按列表拖动，或点组名右侧「…」选「添加/删除列表」。
- 系统自带若干**智能列表**（如「我的一天」「重要」「计划」「全部」「已完成」「分配给我」「今天到期」），它们不是你建的容器，而是按规则自动聚合各列表里的任务，点开就能看。

## 三、任务：一条待办怎么写完整

在任意列表底部的「添加待办事项」输入文字回车，任务就建好了。点开任务可加四类信息：

| 你想要的效果 | 在任务详情里点 | 说明 |
| --- | --- | --- |
| 今天要做 | 添加到「我的一天」 | 「我的一天」是每天清零的日计划页 |
| 别忘了做 | 添加截止日期 / 提醒我 | 截止日期管「哪天到期」，提醒管「几点弹通知」 |
| 每周都做 | 重复 | 可选每天、工作日、每周、每月、每年或自定义 |
| 拆成几步 | 添加步骤 | 大任务拆成小勾选项，任务名下方会显示完成进度 |
| 记点背景 | 添加备注 / 添加文件 | 备注随便写；附件单个上限 25MB |

- **标星 = 重要**：任务右侧的星标点亮后，它会出现在「重要」智能列表里；列表内可按重要性排序，标星任务自动置顶。
- **任务名里写 `#标签`**（如 `#家务`）：之后在搜索框搜这个标签，就能把散落在多个列表里的同类任务一次捞出来。
- 勾选任务即完成；误点了可以进「已完成」列表找回。

## 四、「我的一天」怎么用出习惯

「我的一天」每天自动清空，需要你把今天要推进的任务放进去：在别的列表里点任务详情的「添加到我的一天」，或在「我的一天」页直接从建议里挑。一个实用节奏是：早上花两分钟挑 3~5 条，晚上勾完收工，这样每天只需盯这一屏，不用逐个翻列表。

## 五、提醒与重复的搭配

- 一次性的事：设**截止日期 + 提醒**，到期那天通知你。
- 周期性的事（交周报、倒垃圾）：设**重复**，完成后自动生成下一条，不用每天重建。
- 只有截止日期**不会弹通知**，只有到了那天它会出现在「计划」列表里；想要响铃提醒必须单独设「提醒我」。
- 如果设了提醒却收不到，是安卓系统通知设置的问题，按 [提醒收不到怎么排查.md](提醒收不到怎么排查.md) 逐层查。

## 六、常用入口速查

| 你想做的事 | 位置 |
| --- | --- |
| 换主题 / 深色模式 | 设置 > 主题 |
| 开关提醒通知 | 设置 > 通知 |
| 加另一个 Microsoft 账号 | 点用户名 > 添加账户（安卓、Windows 支持多账号切换） |
| 与别人共享某个列表 | 列表右上角共享图标，见 [共享列表与协作怎么用.md](共享列表与协作怎么用.md) |
| 跨设备找回数据 | 同一账号登录即可，见 [账号与同步问题排查.md](账号与同步问题排查.md) |
