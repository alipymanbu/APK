# 提醒收不到怎么排查

> 安卓上设了提醒却不弹通知，按这四层顺序查：系统通知 → 应用内开关 → 后台与省电 → 第三方清理。
> **相关文档**：[新手入门与基本操作.md](新手入门与基本操作.md) · [账号与同步问题排查.md](账号与同步问题排查.md) · [共享列表与协作怎么用.md](共享列表与协作怎么用.md)

## 一、这是什么问题

提醒通知依赖安卓系统设置，系统与后台管理工具都可能把它压下去。本篇按微软官方排障文档的顺序，给你一套从上到下的检查清单 —— 逐层做，多数情况做到第二层就恢复了。先确认一件前提：任务上确实设了「提醒我」而不只是截止日期（两者区别见 [新手入门与基本操作.md](新手入门与基本操作.md) 第五节）。

## 二、第一层：系统通知开关

1. 打开 `设置 > 应用`，搜到 **Microsoft To Do**（或显示为「待办事项」），进入**通知**。
2. 确认总开关是开的，并且没有整类通知（如「提醒」类别）被单独关掉。
3. 顺手把「横幅 / 锁屏」也打开，否则通知只在状态栏静默出现。

不同品牌设置页叫法不同（有的在「应用管理」、有的在「通知管理」），以你能找到通知开关为准。

## 三、第二层：应用内开关

1. 打开 Microsoft To Do，进 **设置 > 通知**。
2. 确认 **提醒** 选项是启用状态。

系统给了权限、应用自己没开，通知照样不发 —— 这两层是最常见的原因。

## 四、第三层：后台与省电限制

安卓的电池优化会杀后台应用，提醒到点时应用被冻结就发不出通知。把 Microsoft To Do 加入省电白名单：

| 品牌 | 官方排障文档给的路径 |
| --- | --- |
| 三星 | `设置 > 应用 > 待办事项 > 应用设置 > 通知` 打开「设置为优先级」；`设置 > 设备维护 > 电池 > 不受监控的应用` 加入待办事项 |
| 华为 / 荣耀 | 在「设置 > 电池」里关闭对该应用的省电优化，并允许自启动 |
| 小米 | `设置 > 应用设置 > 应用管理 > Microsoft To Do > 省电策略` 选「无限制」，并开启自启动 |
| 一加 / OPPO | 在系统「电池」里关闭对该应用的耗电优化，允许后台活动 |

路径随系统版本有出入，照「省电白名单 / 自启动」这两个关键词找即可。

## 五、第四层：第三方工具拦截

- 手机管家类、清理加速类、专注模式类应用可能拦截通知以「省流量/省电」，在它们的拦截与通知记录里放行 Microsoft To Do。
- 国产系统的「通知使用权 / 通知整理」若把应用归进静默分组，手动改成「重要通知」。

## 六、检查清单（逐条勾）

- [ ] 任务设了「提醒我」，不是只设了截止日期
- [ ] 系统设置里该应用通知总开关打开
- [ ] 应用内 设置 > 通知 > 提醒 已启用
- [ ] 应用已加入电池优化白名单 / 允许后台与自启动
- [ ] 第三方管家、清理工具没有拦截它的通知
- [ ] 手机未处于勿扰模式

以上全做完仍不弹，换一台设备登录同一账号对照测试：新设备能弹说明原手机是系统策略问题，两台都不弹则可能是账号侧没同步到位，见 [账号与同步问题排查.md](账号与同步问题排查.md)。
