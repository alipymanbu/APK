# 账号与同步问题排查

> 登不上、列表不同步、「同步数据时遇到问题」报错，先分清是账号类型问题还是网络问题。

## 一、这是什么

Microsoft To Do 的数据全部存在微软云端（Exchange Online），客户端只是个显示器：你在哪台设备登录同一账号，列表就在哪出现。所以「同步问题」几乎总是两类之一 —— **账号不被支持**，或**网络到不了微软服务器**。本篇帮你先定位是哪一类。

## 二、支持哪些账号

| 账号类型 | 能否使用 |
| --- | --- |
| 个人 Microsoft 账号（Outlook.com / Hotmail 等活跃账号） | 可以，功能完整 |
| 工作或学校账号 | 可以，但所在订阅需含 To Do 许可，并有 Exchange Online 邮箱 |
| 本地部署 Exchange Server 托管的账号 | 不支持 |
| 由世纪互联运营的 Microsoft 365 中国区账号 | 不支持（官方系统要求页明确列出） |
| 部分政府云订阅 | 不支持（政府社区云中等级账号可用网页版） |

工作/学校账号的具体许可要求（哪些 Microsoft 365 订阅含 To Do 许可、需哪种 Exchange Online 计划）以 [Microsoft 支持页](https://support.microsoft.com/zh-cn/todo/microsoft-to-do-system-requirements)当时显示为准；不确定自己组织的账号属于哪种，直接问 IT 管理员。

## 三、跨设备同步怎么才正常

- **每台设备登录同一个账号** —— 这是同步的唯一开关。手机登个人号、电脑登公司号，两边列表永远对不上。
- 官方口径：应用大约**每 5 秒**刷新一次，改动应该自动出现，不需要手动下拉刷新。
- 由于任务存在 Exchange Online，同一账号的 Outlook 任务会跟着一起变 —— 在 Outlook 里改了，To Do 这边也会动。
- 想在一台设备上同时挂工作号和个人号：安卓与 Windows 版支持多账号，点用户名 > 添加账户，之后点用户名即可切换。

## 四、报「同步你的数据时遇到问题」

这是官方有明确答复的报错，原因通常是 **VPN、代理或防火墙挡住了到微软的连接**。排查顺序：

1. 关掉 VPN / 代理再试一次 —— 能好就是它。
2. 公司网络则让 IT 把微软相关域名加入允许列表，官方给的清单包括 `*.microsoft.com`、`*.live.com`、`graph.microsoft.com`、`*.office.com`、`*.office365.com`、`login.microsoftonline.com`、`todo-web-endpoint.azureedge.net` 等（完整列表见官方支持页）。
3. 网络放行后仍报错，通过应用里的支持入口联系微软支持。

## 五、快速定位表

| 现象 | 更可能是哪类 | 去哪处理 |
| --- | --- | --- |
| 登录直接被拒 / 提示组织策略 | 账号类型不支持 | 本篇第二节，换个人号验证 |
| 换了新手机列表空白 | 没登同一账号 | 本篇第三节 |
| 所有设备都报同步错误 | 网络被拦 | 本篇第四节 |
| 只是提醒没弹、列表本身是新的 | 通知问题，不是同步 | [提醒收不到怎么排查.md](提醒收不到怎么排查.md) |
| 装完打不开 / 登录闪退 | 安装包问题 | [下载与安装教程.md](下载与安装教程.md) |

另：有用户反馈旧账号曾出现「共享/同步失效」的提示，社区答复指向账号不在 Exchange Online 上；这类情况属于第二节的账号边界，换号即可，与客户端版本无关（社区答复口径，以实际账号情况为准）。
