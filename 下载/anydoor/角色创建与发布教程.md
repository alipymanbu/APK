# Anydoor 角色创建与发布教程

> 本篇讲怎么在 Anydoor 里从零做出一个自己的 AI 角色，设置哪些字段、怎么发布到广场。

除了和现成角色聊天，Anydoor 允许你自己造角色：定形象、定音色、写性格和背景故事，做好后可以发布到公共广场给别人聊。本篇按「找到入口 → 逐项设置 → 发布 → 后期修改」的顺序讲。

## 一、找到角色创作入口

登录后，在主界面找「创建」或「角色创作」入口（不同版本的按钮位置可能有差异，一般在底部导航或「我的」页面里）。点进去就是一个空的角色编辑页。

## 二、逐项设置角色

创建一个角色主要填这几样东西，建议按下面的顺序来，前面的项会影响后面：

| 设置项 | 填什么 | 建议 |
| --- | --- | --- |
| 头像 / 形象 | 上传图片，或用内置生成工具做一张（生成方法见 [图片生成与风格选择.md](图片生成与风格选择.md)） | 先定形象再写故事，风格会统一 |
| 名字 | 角色名 | 短一些，聊天列表里好认 |
| 音色 | 挑一种语音声线 | 想用语音聊天的角色才需要细挑 |
| 性格标签 | 选几个描述性格的词 | 标签越具体，聊起来越不容易「千人一面」 |
| 背景故事 | 角色的来历、身份、和你的关系 | 这是决定对话质量的一项，写具体场景比堆形容词有用 |
| 开场白 | 角色说的第一句话 | 写一句能自然接话的开场，比「你好」更容易进入状态 |

背景故事不用长，三五行说清楚「他是谁、在哪、和你什么关系、说话什么风格」就够了。你之后聊天时角色会围绕这个设定回应，也会记住你们聊过的内容。

## 三、发布到公共广场

1. 所有字段填完，检查一遍头像和开场白；
2. 点「发布」（或类似按钮），角色就会出现在公共广场；
3. 别人可以在广场里看到并和你的角色聊天，作品会保存在你的账号下，随时能回来调整。

不想公开发布的话，可以先不点发布，自建角色自己聊（不发布能否直接开聊以应用内实际流程为准）。

## 四、发布之后还能改吗

可以。从创作入口或个人页面找到你创建的角色，进入编辑页就能改设定、换头像、调音色（具体入口位置以应用内实际显示为准）。已经发生的聊天记录不受修改影响。

## 五、几个实用建议

- **开场白别写太满**：留一半信息让对话去补，比一次交代完更有得聊；
- **性格标签宁少勿多**：三四个互相不矛盾的标签，比七八个互相打架的好用；
- **想练外语就建外教角色**：背景故事里写明「用某语言回复、纠正我的表达」，就是一个随叫随到的口语陪练；
- 做好角色后遇到聊天上的问题（比如回复不像设定），去 [常见问题解答.md](常见问题解答.md) 里对一对原因。
