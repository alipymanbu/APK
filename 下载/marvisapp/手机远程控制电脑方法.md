## 一、手机端能对电脑做什么

按官方文档口径，安卓端在跨端这件事上有四类用法：

| 用法 | 你能做的事 |
| --- | --- |
| 远程查看 | 实时看电脑屏幕画面，了解交给它的任务跑到哪一步 |
| 远程接管 | 在手机屏幕上点击、滑动、输入，键鼠动作映射到电脑，人不在电脑前也能操作 |
| 锁屏解锁 | 电脑锁屏时用手机输密码解锁（需提前授权，不可强制连接） |
| 跨端索取文件 | 在会话里说一声，让电脑上某个文件发到手机，不用提前传网盘 |

另外，电脑上没跑完的任务，换到手机上可以接着看进度，跨端续做。

## 二、连接前要满足的条件

远控不是手机单方面能发起的，逐条核对：

1. **电脑装了 Marvis 桌面版**（Windows 或 Mac），并且登录了账号。
2. **两端登录同一个账号**——QQ 和微信算两个体系，别一边登 QQ 一边登微信。
3. **电脑端保持运行**，不在后台被退出。
4. **授权给过**：远控属于敏感操作，第一次连接时电脑端会要你确认；锁屏状态下的唤醒与操控也需要事先授权过。
5. 两端网络都可用。

不同体系之间可交叉远控：手机远控 Windows、安卓远控 Mac 都支持（截至 2026-09 官方文档口径）。

## 三、查看与接管电脑

1. 打开手机上的 Marvis，确认已登录。
2. 从远程协助入口进入（不同版本入口位置可能有差异，以你手上的版本界面为准），选择要连的电脑。
3. 电脑端弹出授权确认时，在电脑前点允许；之后手机上就能看到电脑屏幕的实时画面。
4. 想直接操作时，在手机画面上点、滑、打字，动作会映射到电脑上。

如果只是想让电脑「替你干活」，不必远控画面——直接在对话框里说需求，让它自己执行，你用远程查看盯着进度就行。两种方式怎么选，结合你要做的事参考[日常任务与指令示例](日常任务与指令示例.md)。

媒体实测过一条完整的跨端链路：手机下指令，让它在电脑桌面找到指定文件、解读后生成文档放回桌面，两端同步推进。结论是完成度高、速度偏慢——适合不赶时间的活，急事还是自己动手。

## 四、锁屏状态与取文件

- **锁屏远程解锁**：电脑锁屏不影响被远控，前提是你之前在电脑端授权过；没授权过的设备无法强制连接，这是产品有意设计的边界。媒体实测也印证了锁屏状态下手机依然可以接管。
- **跨端索取文件**：在手机会话里用自然语言描述文件位置或内容（比如「把电脑桌面上那份报价单发我」），由电脑端定位后传输。记不得文件名也能找，靠的是内容检索，参考[效率模式与本地模式区别](效率模式与本地模式区别.md)里对本地索引的说明。
- **外接键鼠**：有用户反馈远控画面里外置鼠标键盘用不上，需要精细操作时回到电脑本机做。

## 五、连不上先查这几条

最常见的三类原因：两端账号不一致、电脑端没在运行、授权没给过。逐项排完还连不上，看[连不上电脑与常见问题](连不上电脑与常见问题.md)的排查清单。
