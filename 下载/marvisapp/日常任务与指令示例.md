## 一、怎么下指令

直接用日常说法把需求说完整即可，不需要写提示词模板、不需要手动配置技能。几点口径先说清：

- 它拆解任务后由多个分工的 Agent 执行（文件、电脑、应用、浏览器、搜索等方向），你不用指定找谁。
- **涉及隐私、安全、支付的关键环节会交回你确认**，删除类操作也会先给计划再动手。
- 按《Marvis 软件许可及服务协议》口径：所有输出内容执行的操作视为你本人的行为，后果由你承担——所以高权限授权（远控、文件读写、支付相关）别随手给。
- 用量按 Token 计，免费额度的统一口径见[效率模式与本地模式区别](效率模式与本地模式区别.md)第四节。

## 二、高频场景与说法示例

下面这些是官方文档里给过的典型说法，你可以照这个句式组织自己的需求：

| 场景 | 你可以这么说 |
| --- | --- |
| 清理磁盘 | 「C 盘空间不够了，看看哪些文件能清」 |
| 整理表格 | 「把这个文件夹里所有发票按时间整理成 Excel 表格」 |
| 找图 | 「图片里有 2026 字样的图都找出来」 |
| 找文件 | 「找一下我上个月和小王签的那份 PDF 合同」 |
| 改设置 | 「帮我把开机自启动里没用的应用关掉」 |
| 查配置 | 「我的电脑配置能不能玩 XX 游戏」 |
| 排网络 | 「Wi-Fi 突然连不上了，帮我排查」 |
| 盯价格 | 「定时监控这趟机票的价格，便宜了告诉我」 |
| 抓网页 | 「把这个网页里的产品列表抓下来」 |

手机端的用法一样：在对话框里说需求；想亲眼盯着电脑执行过程，就用远控画面（见[手机远程控制电脑方法](手机远程控制电脑方法.md)）。

## 三、定时与自动化任务

- **定时提醒 / 监控类**：喝水提醒、机票降价监控这类任务，设置一次到点自动执行。
- **文件类的定时任务先试跑**：媒体实测里出现过定时邮件准时发出、附件却不对也打不开的情况。涉及文件操作的任务设好后，先手动触发一次核对结果；纯推送类可以放心。
- **App 操作类**：能让它代做日常任务、查限时福利、比价等。注意这类操作有**授权名单**——截至 2026-09，官方口径是已授权应用包括同花顺、什么值得买、汽车之家、唯品会、飞常准等，名单在持续扩充，不在名单里的应用不一定能替你操作。
- 官网还列了追星（资讯搜索、物料整理）、游戏（福利监控、日常任务托管）、情报监控等场景，是否好用取决于具体任务，建议先拿不重要的任务试。

哪些任务实测表现稳、哪些要留心，媒体与用户的公开反馈整理在[真实体验与能力边界](真实体验与能力边界.md)。

## 四、技能广场

技能广场是个技能商店，页面按图文卡片展示，点一下就能装上，不用去别处下载配置。装好的技能会扩展它能做的事；不装也行，出厂预置的能力已经覆盖上面大部分场景。
