## 一、打开成功通知能直接进应用（旧版）

有版本存在一个安全相关的 bug：**点开「操作成功」的通知会绕过身份验证直接进入应用**。官方已在 **2.3.5** 版本修复（2026-01 上架 F-Droid）。你还在用 2.3.2 或更早版本就会碰到它——修法是升级，不要把重要文件长期放在带此问题的版本里。升级路径见第五节。

## 二、相机拍出来发绿

部分手机上用应用内相机拍摄会出绿色画面，官方在 **2.3.4** 版本修复。当前手里的 2.3.2 若遇到，先升级；升级后仍出现的话，改用系统相机拍完再导入即可（导入方式见[导入导出与文件管理.md](导入导出与文件管理.md)）。

## 三、HEIC 图片打不开、文件顺序乱

- **打不开 `.heic`**：HEIC 是 **2.3.6** 才加入支持的格式，旧版本打不开属正常，升级即可；
- **文件排序不符合直觉**：自然排序问题同样是 2.3.6 修复的。

以上版本节点以官方发布页当时显示为准。

## 四、其他已知问题对照表

下列条目来自官方 issue 列表（截至 2026-09 查看），按「症状 → 处理」给结论；标注「开放中」的官方还没修，别等它，先用绕法：

| 症状 | 处理 |
| --- | --- |
| 笔记/文本打开再退出变 0 字节 | 旧版本缺陷，2.2.1 已修复；2.3.2 不该再遇到，出现了先升级 |
| 升级到 2.0.4 后文件全没 | 该版本的已知问题，官方答复升到 2.0.5 解决（issue #92）；停在此版本的尽快升 |
| 应用内相机点了没反应 | 小米 HyperOS 等机型有反馈（issue #109 官方未修、issue #64 开放中）——改用系统相机拍完再导入 |
| 拍照声音特别大 | 有反馈，处理中（issue #145 开放中） |
| 打开带密码的 PDF 闪退 | issue #151 开放中——先导出，用其他阅读器打开 |
| 部分视频在应用内播不了 | issue #148 等同类反馈开放中——导出后用系统播放器看 |
| 长按「固定」却直接打开文件 | issue #149 开放中的 bug，暂无绕法 |

判断新问题要不要报：先升级到官方最新版再复现，还在就带上版本号与机型去 [github.com/aashishksahu/SafeSpace/issues](https://github.com/aashishksahu/SafeSpace/issues) 反馈。

## 五、怎么升级 / 从哪拿新版本

两个官方渠道（开源 GPL-3.0）：

- [github.com/aashishksahu/SafeSpace/releases](https://github.com/aashishksahu/SafeSpace/releases)
- [f-droid.org/en/packages/org.privacymatters.safespace](https://f-droid.org/en/packages/org.privacymatters.safespace/)

升级前留意两件事：

1. **签名要一致**，同签名 APK 才能覆盖安装；若系统提示签名不一致需先卸载——**千万别直接卸**，卸载会清空保险箱里全部文件，先按[导入导出与文件管理.md](导入导出与文件管理.md) 导出，装完再导入；
2. F-Droid 上 2.3.3 及之后的构建要求 Android 10 及以上，旧机型未必升得上去，以渠道当时显示为准。

## 六、文件「不见了」先查这几种情况

| 现象 | 先想什么 |
| --- | --- |
| 应用刚重装过，里面空了 | 应用专属存储随卸载被清，官方无法恢复；有导出的副本就重新导入 |
| 手机恢复过出厂 / 刷过机 | 同上，只能靠事先导出的备份 |
| 换了新手机 | 无云同步，系统搬家工具也带不走——按[换新手机与备份迁移.md](换新手机与备份迁移.md) 的步骤手工迁 |
| 只是列表里找不到 | 确认进的是同一个目录；文件在保险箱内支持复制/移动，可能被挪了位置 |

## 七、root 管理器弹权限请求

启动时 Magisk 之类的 root 管理器弹授权，是因为应用做了环境检测的询问——官方说明它**不需要也不使用 root**，拒绝即可，不影响正常使用（另见[隐私保护与安全边界.md](隐私保护与安全边界.md)）。

## 八、这个项目还在维护吗

开发者已在项目页声明**暂停开发新功能**，但承诺继续提供关键 bug 修复并参与讨论（截至官方仓库页面所示）。也就是说：安全类修复还会发（2.3.5 就是一例），新功能别指望。版本号按 `x.y.z` 递进、发布节奏不定期，装哪个版本以官方发布页当时显示为准。怎么判断自己该不该升级，回到第五节的两条注意事项。
