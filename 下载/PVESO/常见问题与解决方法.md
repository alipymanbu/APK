## 一、装不上、打不开

重装一律从 **PVESO 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/cb885cd437d8](https://pan.quark.cn/s/cb885cd437d8) 拿包。完整安装步骤见 [下载与安装教程.md](下载与安装教程.md)，这里只列速查：

| 现象 | 处理 |
| --- | --- |
| 解析包时出现问题 | 重新下载完整安装包，核对大小为 1.14M；安卓版本过低也会这样报 |
| 禁止安装未知应用 | 给文件管理器或浏览器授「安装未知应用」权限 |
| 打开就闪退 | 先重装一次；仍闪退换台设备试，排除机型与系统版本问题 |

## 二、账号与计费

- **没账号怎么注册**：登录窗口下方有「注册账号」入口，邮箱加密码即可，流程见 [注册登录与账号设置.md](注册登录与账号设置.md)；
- **token 能退吗**：第三方商店资料提到 token 一经购买通常不支持退款，拿不准就先用免费模型试效果（以应用内当时的规则为准）；具体省 token 的做法见 [token消耗太快怎么省.md](token消耗太快怎么省.md)；
- **免费模型有次数限制吗**：商店资料称基础功能无隐藏限制条款，个别高级功能才消耗 token，具体以模型详情页说明为准；
- **换手机数据还在吗**：同一账号重新登录，token 余额、使用记录与 API 配置会跟随账号同步。

## 三、聊天排版乱、显示异常

| 现象 | 处理 |
| --- | --- |
| 卡里的 HTML 原样显示 | 内容可能写进了三反引号代码块，去掉围栏再写 HTML |
| HTML 标签里的 Markdown 不生效 | HTML 内部不解析 Markdown，两种语法别嵌套 |
| 排版时好时坏 | 一张卡只用一种标记风格 |
| 开场白带着样式代码 | 把 HTML/CSS 从开场白里挪出去，样式放美化环节 |
| 卡上的交互按钮点了没反应 | 平台出于安全移除了 JavaScript 执行，依赖 JS 的交互不可用，改造思路见 [世界书与预设玩法.md](世界书与预设玩法.md) |

## 四、导入的卡表现不对

- **人设没生效**：确认卡自带的世界书是否随导入一起加载、角色卡有没有正确绑定，见 [世界书与预设玩法.md](世界书与预设玩法.md)；
- **文风不对劲**：先换模型再怀疑卡——同一张卡在不同模型下表现差异很大，见 [聊天玩法与模型选择.md](聊天玩法与模型选择.md)；
- **回复里混着样式代码**：多半是卡的排版代码过重，按第三节的表格逐条排查。

## 五、搜 PVESO 搜出一堆 Proxmox

搜索时看到 PVE、Proxmox VE、虚拟机之类的内容，那是另一款开源虚拟化平台（名字缩写与 PVESO 接近，搜索时容易混在一起），与这款 AI 角色扮演应用无关。认准包名 `com.pveso.app` 与官网 [pveso.com](https://pveso.com/) 即可区分。

## 六、网络与可用性

- 有商店资料提到 PVESO 面向国内用户、无需特殊网络环境即可使用——以你的实际网络表现为准；
- 加载慢或内容刷不出来：先确认手机网络正常，退出重新登录再试；应用版本过旧也可能有兼容问题，先更新到最新版。
