# PVESO token 消耗太快怎么省

> token 消耗快通常是参数、内容、模型三处没对上，逐项排查一遍就能把消耗压下来。

## 一、先弄清 token 花在哪

每次对话发给模型的不只是你那句消息：角色设定、世界书条目、历史对话、开场白都会一起进入上下文。消耗快通常出在三处——**记忆长度开得大**、**世界书条目堆得多**、**内容里混着排版代码**。对照下面几步逐项收一遍。

## 二、把参数调省

| 参数 | 调法 | 效果 |
| --- | --- | --- |
| 回复字数上限 | 调小，够用就好 | 回复更短，直接少花 |
| 对话记忆长度 | 调小 | 往回喂的历史变少，长对话省得多 |
| 消息记忆标记 | 无用剧情标「隐藏记忆」 | 不再重复喂给模型 |

入口都在聊天设置里（见 [聊天玩法与模型选择.md](聊天玩法与模型选择.md) 第二节），具体选项以应用内实际为准。

## 三、给内容减负

- **开场白与对话示例里不写 HTML/CSS**：官方教程特别标注过，样式代码会带来「理解困难 + 大量 token 消耗」双重代价；排版放到美化环节去做（见 [角色创建与发布.md](角色创建与发布.md) 第三节）；
- **世界书条目按剧情需要写**：只留当前故事真正用得到的设定，拆细但别堆量（写法见 [世界书与预设玩法.md](世界书与预设玩法.md) 第二节）。

## 四、选对模型与缓存

- **测试期全用免费模型**，确认对话质量满意再考虑付费档（免费与计费口径见 [注册登录与账号设置.md](注册登录与账号设置.md) 第四节）；
- 选模型时看模型详情页的说明，不同模型单价差别很大；
- 部分模型提供商支持**会话缓存**，命中缓存能省 token，同一会话连续聊通常比频繁重开对话更容易命中；各模型的缓存机制（TTL）以对应官方说明为准。

## 五、充值前把规则看清

- token 一经购买通常不支持退款（第三方商店资料口径，以应用内当时的规则为准），先用免费模型测效果再决定充值；
- 商店资料提到会员除直接付费购买外，还可通过优质角色卡获得打赏兑换、参与平台赠送活动——属于单一来源说法，以应用内当时的活动规则为准；
- 价格与面额会随版本变化，**以应用内当时显示为准**。
