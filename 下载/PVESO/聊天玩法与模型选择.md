## 一、找一个角色开聊

1. 首页顶部有**最新 / 最热 / 日榜 / 周榜 / 月榜**几个标签，最热与榜单页适合找人气高的角色；
2. 有明确目标就用顶部**搜索框**，按名称或标签搜；
3. 点角色封面进详情页，能看介绍，也可以先点赞、收藏；
4. 点**「开始对话」**进入聊天界面，底部输入框打字发送即可。

应用还没装好的话，先从 **PVESO 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/cb885cd437d8](https://pan.quark.cn/s/cb885cd437d8) 拿安装包，步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 二、聊天中可以调的参数

- **回复字数上限**：嫌回复太长或太短，直接调这个；
- **对话记忆长度**：控制 AI 往前回看多少内容；往回喂的内容越多，「记得住」的同时 token 消耗一般也越高；
- **消息记忆标记**：可以把某条消息标为「永久记忆」长期保留，或标为「隐藏记忆」不再喂给 AI（入口以应用内实际为准）。

## 三、300+ 模型怎么选

PVESO 聚合了 300 多个主流模型，经 OpenRouter 路由到各模型官方或其授权服务商。挑的时候按需求对号入座：

| 需求 | 怎么选 |
| --- | --- |
| 不想花钱 | 用免费模型，先把基本盘跑起来（计费口径见 [注册登录与账号设置.md](注册登录与账号设置.md)） |
| 追求对话质量 | 换用列表里的旗舰级模型，单价与 token 消耗更高 |
| 控制成本 | 看模型详情页的说明；部分模型提供商支持会话缓存，命中缓存能省 token |
| 有自己的 API | 高级用户支持自定义 API 配置，接入自己的模型渠道 |

同一张角色卡换个模型，文风与理解力可能完全不同——觉得角色不对劲时，先换模型再怀疑卡。想压低消耗，见 [token消耗太快怎么省.md](token消耗太快怎么省.md)。

## 四、换设备接着聊

换手机或再登一台设备，用同一账号登录即可；token 余额、使用记录与自定义 API 配置会跟账号走。对话记录是否完整同步以应用内实际表现为准，在意的内容先在旧设备上确认。
