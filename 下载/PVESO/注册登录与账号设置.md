## 一、不登录能先做什么

打开应用后不登录也能逛：首页的**最新 / 最热 / 日榜 / 周榜 / 月榜**榜单、按名称或标签**搜索**、点开角色看介绍，这些都不需要账号。真正开始**对话**、**创建角色**、管理自己的内容时才需要登录——商店资料显示登录后即可使用这些功能，具体以应用内的提示为准。

还没安装的话，先从 **PVESO 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/cb885cd437d8](https://pan.quark.cn/s/cb885cd437d8) 拿到安装包，步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 二、注册与登录

1. 点首页**右上角的「登录」**；
2. 已有账号：输入邮箱和密码，点登录；
3. 没有账号：点登录窗口下方的**注册账号**，按提示填基本信息完成注册。

注册用邮箱加密码即可（以应用内当时的表单为准）。界面右上角还有深色模式开关，偏好暗色界面可以顺手切上。

## 三、多设备与数据同步

第三方商店资料提到：同一账号支持多设备登录，token 余额、使用记录、自定义 API 配置会跟随账号同步。换手机时直接用原来的邮箱密码登录即可；换机前如有在意的内容，先在应用内确认会话是否已跟随账号保存，以实际体验为准。

## 四、免费模型、token 与计费口径

PVESO 的模型用法分几层，花钱的边界在哪先分清：

| 档位 | 能干什么 | 花不花钱 |
| --- | --- | --- |
| 免费模型 | 平台提供的基础模型，直接选用开聊 | 免费（商店资料称无隐藏限制条款，具体限制以模型详情页为准） |
| token 消耗 | 更多模型与高级功能按 token 计费 | 按量消耗，token 在应用内购买 |
| VIP / 自定义 API | 高级用户可配置自己的第三方 API 接入 | 见应用内说明 |

几点提醒：

- **先用免费模型试**，确认对话质量与功能满足需要，再考虑要不要充值 token；
- 第三方商店资料提到 **token 一经购买通常不支持退款**，充值前把面额与规则看清（以应用内当时的规则为准）；
- 商店资料提到会员除直接付费购买外，还可通过优质角色卡获得打赏兑换、参与平台赠送活动——属于单一来源说法，以应用内当时的活动规则为准；
- 模型列表、价格这类信息会随版本变化，**以应用内当时显示为准**。

具体省 token 的做法见 [token消耗太快怎么省.md](token消耗太快怎么省.md)。
