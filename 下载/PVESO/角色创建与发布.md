# PVESO 角色创建与发布

> 从侧边栏入口到保存发布，把一个自己的 AI 角色从零捏出来；嫌麻烦也可以直接导入现成的 SillyTavern 角色卡。

## 一、入口在哪

打开应用，点**左上角的侧边菜单**（三条横线），进**创意工坊**里的**创建角色**。还没装应用的话，先从 **PVESO 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/cb885cd437d8](https://pan.quark.cn/s/cb885cd437d8) 拿安装包。以下步骤综合自商店收录的使用教程，不同版本的叫法可能略有出入，找不到入口就先把应用更新到最新版。

## 二、填基础信息

| 项目 | 怎么填 |
| --- | --- |
| 角色名称 | 想好名字；这是别人在社区里认出你角色的第一眼 |
| 角色封面 | 可随机生成，也可本地上传图片（需要相册权限，被拦就去系统设置放行）；有商店教程推荐 512×768 比例，竖版封面在信息流里显示最完整 |
| 性别 / 年龄 / 职业标签 | 按人设选；标签会帮别人搜到你 |
| 性格与背景 | 用几句话把性格特质和核心经历写清楚，写得越具体，对话越贴人设 |

## 三、对话规则细节

基础信息之后是让角色「像那么回事」的部分，逐项都是可选填：

- **描述 / 设定 / 场景**：角色的世界观与他当前所处的处境；
- **对话示例**：给 AI 看的「他平时怎么说话」的样本，口癖、句式都靠它带；
- **第一条消息 / 多条开场白**：你点开角色时他说的第一句话，可以备几条不同的开场换着用；
- **回复字数上限与记忆长度**：在细节配置里调，决定回复多长、往前记得多少。

**注意**：**开场白里不要写 HTML 标签和 CSS 样式**——商店教程特别标注过这一点，排版代码混进开场白会让模型理解困难，还白白消耗 token。美化是下一步的事；token 的系统省法见 [token消耗太快怎么省.md](token消耗太快怎么省.md)。

## 四、美化角色卡

到了美化界面才轮到排版出场：用 **Markdown** 语法就能给角色卡做基础的格式效果，进阶可以用正则表达式优化展示样式。建议一张卡只用一种标记风格——Markdown 与 HTML 混排嵌套容易出渲染问题，常见坑与处理见 [世界书与预设玩法.md](世界书与预设玩法.md)。

## 五、直接导入现成角色卡

PVESO 兼容 SillyTavern 角色卡格式，卡里带的**世界书与正则脚本**会一并导入：

1. 在创建 / 细节配置页点**「导入角色卡」**，上传拿到的卡文件；
2. 系统自动识别并填入信息，再手动补齐不满意的项；
3. 导入后如果显示异常，多半是两边渲染标准的差异，处理办法见 [常见问题与解决方法.md](常见问题与解决方法.md)。

动手前的几条经验（SillyTavern 生态通用）：

- 卡文件通常是一张 PNG 图片或一个 JSON 文件；下载与传输别走会压缩文件的路径——截图、某些聊天工具的图片传输会把卡压坏，导入就废了；
- 导入报错时，先确认拿到的是**角色卡文件本身**，而不是作者贴在帖子里的封面图；
- 卡的来源自行甄别，来路不明的文件不要往里装。

## 六、保存与发布

确认基础信息、互动规则、美化效果无误后点**保存角色**，之后随时可以用它开聊。想让社区里其他人也玩到，就按应用内流程**发布**——商店资料提到作品需经平台审核后上架，审核规则以应用内说明为准。发布后别人能对你的角色点赞、收藏，这些反馈会显示在角色详情页。
