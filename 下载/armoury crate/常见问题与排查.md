## 一、问题速查表

| 现象 | 高概率原因 | 处理方向 |
| --- | --- | --- |
| 打开后一直显示加载，进不了界面 | 组件加载失败、缓存异常 | 见第二节 |
| 反复提示下载/更新组件，同意了也没用 | 更新通道连不上 | 见第三节 |
| 手机连不上电脑 | 网络不通、登录方式问题 | 见第四节 |
| X 模式 L3 置灰或找不到 | 没接酷冷风扇 | 见第五节 |
| 肩键没反应 / 映射失灵 | 按压姿势、保护壳、映射点位 | 见第五节，硬件排查见[肩键映射与手感调校.md](肩键映射与手感调校.md) |
| 普通手机功能很少 | 功能依赖 ROG 硬件 | 见第六节 |
| ROG 手机上想卸载它 | 预装系统应用 | 见第七节 |

## 二、一直加载、进不了主界面

这是应用商店反馈里最集中的问题：打开应用后停在加载页，或反复提示要下载什么东西，同意几次都没变化。按这个顺序处理：

1. **清缓存重启应用**：系统设置 → 应用 → Armoury Crate → 清除缓存（先不要点清除数据，避免丢已配对信息），重新打开。
2. **换网络环境**：从 Wi-Fi 切到流量或反过来再试；该应用的组件加载对某些网络环境敏感。
3. **检查系统时间**：手机时间不准会导致证书校验失败，表现为永远加载中，校准时间后重开。
4. **卸载重装**：前几步无效再走重装；安装包来源与版本口径见[下载与安装教程.md](下载与安装教程.md)。
5. **等版本修复**：如果某个版本上线后大批用户同时反馈此问题（应用商店评论区可查证），属于官方侧故障，重装解决不了，等官方更新即可。

## 三、反复提示更新组件

- 说明当前版本依赖的在线组件拉取失败，多与网络有关，处理同第二节第 2 步。
- 若每次打开都重复提示，先确认系统存储空间充足（安装包 91M 量级，运行时还需要额外空间），空间不足会让组件反复下载失败。
- 用本文开头的 armoury crate 安装文件资源里的 6.0.13 版本重装可绕开某些版本的更新循环，但属于绕过官方更新通道，后续仍建议跟进官方修复版本。

## 四、手机连不上电脑

完整配对步骤在[连接电脑远程控制教程.md](连接电脑远程控制教程.md)，这里只列排查要点：

1. 双方应用都处于打开状态，电脑端不要最小化到托盘就不管了；
2. 手机与电脑在同一网络下（同一 Wi-Fi 或热点），避开有设备隔离的网络；
3. ROG ID 登录报错就改二维码扫码，用户实测扫码成功率更高；
4. 电脑端 PC 版 Armoury Crate 版本太旧时，手机端新版可能不兼容，先更新电脑端。

## 五、X 模式高档位用不了

- **L3 置灰/缺失**：接上对应代数的酷冷风扇再进设置，L3 或额外高性能档随配件解锁，见[性能模式与X模式怎么用.md](性能模式与X模式怎么用.md)。
- **X 模式开关找不到**：非 ROG 设备上没有这个开关；部分老机型上它在游戏中心里而不是快速设置里。
- **肩键按压没反应**：先分清是映射问题还是硬件问题——键位点了没动作多半是游戏更新后界面变了，重新拖一次映射点；按压完全无反馈才是硬件排查，姿势因素（保护壳没贴合、握持太紧）与官方五步排查见[肩键映射与手感调校.md](肩键映射与手感调校.md)。

## 六、普通安卓手机装了「没什么用」

不是安装出错。性能档位、风扇、灯效、肩键这些功能全部依赖 ROG 手机硬件，普通设备上只保留「连接电脑当遥控器」这一部分功能。你的设备是普通安卓机且有华硕/ROG 电脑，直接看[连接电脑远程控制教程.md](连接电脑远程控制教程.md)；两者都没有的话，这个应用对你基本没有可用功能，不必安装。

## 七、ROG 手机上能卸载吗

它是 ROG 游戏手机的预装系统应用，不能普通卸载。在系统设置里可以「停用」，但停用后 X 模式、游戏中心联动、场景配置这些系统级功能会一并失效。正确做法是保持启用、跟随系统更新；嫌它后台活跃，在应用设置里限制其自启动与后台活动即可，不要停用。

## 八、其他高频小问题

- **图标/app 名称显示为小写 armoury crate**：部分渠道的显示差异，不影响功能，以包名 `com.asus.rog.roggamingcenter3` 为准判断是否官方应用。
- **升级后场景配置丢失**：重大版本更新可能重置部分配置，重新进场景配置页核对一遍各游戏的档位与映射即可。
- **耗电偏高**：检查是否长期开着 X 模式或最高档灯效；日常关掉 X 模式、灯效调低，续航差异明显。
