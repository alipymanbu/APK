## 一、什么情况下需要这一篇

手机上的 Armoury Crate 在 ROG 手机之外最常见的用途，是给华硕/ROG 游戏笔记本、台式机当一块「第二屏幕」：人在沙发上或床上，游戏跑在电脑上，你用手机看温度、切性能档、调风扇转速，不用打断电脑上的画面。

前提条件：

- 电脑上已安装 PC 版 Armoury Crate（华硕官网或微软商店提供，以官方页面为准）；
- 手机与电脑网络连通（同一 Wi-Fi 环境最省事，官方也支持蓝牙方式）；
- 手机上装有安卓版 Armoury Crate（安装方式见[下载与安装教程.md](下载与安装教程.md)）。

## 二、配对连接步骤

1. 电脑上打开 PC 版 Armoury Crate。
2. 手机上打开安卓版 Armoury Crate，在电脑端右上角找到「Mobile Connect」（移动连接）入口，按界面指引进入配对流程。
3. 两种配对方式任选其一：
   - **二维码**：电脑端显示二维码，手机扫码完成连接；
   - **ROG ID**：双方登录同一 ROG 账号配对。
4. 配对成功后，手机端会出现电脑的可控制面板。

从应用商店的实际反馈看，**扫码方式的成功率明显高于 ROG ID 登录**——有用户反馈 ROG ID 登录会报错。配对一直失败时优先走二维码路线。

## 三、连上之后能控制什么

| 手机端操作 | 作用在电脑上的效果 |
| --- | --- |
| 切换 Turbo / Performance / Silent 三档 | 一键在最高性能、游戏平衡、安静低载三档间切换，几秒内生效 |
| HyperFan 风扇控制 | 调整电脑风扇策略，三档模式分别对应全力散热、游戏降噪、低噪音轻载 |
| System Info 硬件监控 | 查看 CPU/GPU 频率、占用率、温度、风扇转速、电压 |
| Aura Sync 灯效 | 远程调整电脑端 Aura Sync 灯光设置 |

三档的实际差异：Turbo 用最高频率与风扇转速顶满 CPU/GPU，适合视频渲染、3D 处理这类重负载；Performance 为游戏优化，风扇策略压低噪音、保证帧率；Silent 更安静，适合看片、浏览、办公。

这套组合对两类场景特别顺手：跑分或烤机时，手机屏幕正好当监控面板，不用在电脑上额外开窗口；直播或联机时，切静音档降噪不用退出全屏游戏。

## 四、连接断开或连不上的排查

1. **先确认双方应用都在前台运行**：电脑端 Armoury Crate 最小化到后台后，手机端可能直接失去目标。
2. **核对网络**：手机用流量、电脑用有线时不在同一网段，是连不上的最常见原因；公司/学校 Wi-Fi 的设备隔离（AP 隔离）也会导致互相发现不了，换热点或家用网络测试。
3. **二维码优先**：ROG ID 登录报错时改扫码，这是用户反馈里最有效的替代路径。
4. **配对成功但面板空白/一直加载**：属于应用本身的加载故障，处理思路见[常见问题与排查.md](常见问题与排查.md)的加载卡住一节。

电脑端版本过旧也会导致功能面板缺失，把 PC 版更新到官网当前版本再重连。
