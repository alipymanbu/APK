## 一、肩键的两种用法

AirTriggers 是机身边框上的超声波按压区域，同一套硬件在两种场景下工作方式不同：

| 用法 | 触发方式 | 设置入口 |
| --- | --- | --- |
| 游戏映射 | 横握时食指自然搭住的机身两侧按键 | 游戏内从屏幕左侧边缘滑出 Game Genie，点 AirTriggers |
| 系统握压 | 竖握时握压边框下方 | 系统设置 → 高级功能 → AirTriggers，绑定打开相机、截屏等快捷动作 |

游戏映射是肩键的主要用途；系统握压则把肩键变成日常快捷键。两套手势相互独立，互不影响。

## 二、游戏内怎么映射键位

1. 进入游戏，从屏幕左侧边缘向内滑出 Game Genie 面板，点「AirTriggers」。
2. 选择手势类型：点击、单侧双键、滑动（长滑）、速滑（拨滑）、体感（抖一抖，部分机型）。
3. 把对应颜色的圆圈拖到游戏技能按钮上：左肩键对应蓝色圆圈、右肩键对应红色圆圈、体感键位对应黄色圆圈。
4. 同一个游戏可以保存多组肩键配置，切换英雄或场景时调出对应的一组即可。

映射的前提依旧是技能按钮位置固定。以射击类游戏为例的常见搭配：左侧单侧双键分别映射开镜与开火，右侧速滑映射起跳与蹲下，体感「抖一抖」映射换弹——这是 ROG 官方手册举过的参考组合，你按自己的操作习惯调整即可。

## 三、手感参数在哪里调

统一入口：Armoury Crate → 控制台 → AirTriggers → 偏好与手感设定。可调项：

| 参数 | 作用 |
| --- | --- |
| 点击手感 | 调按压力道，重按防误触、轻按省力 |
| 单侧双键手感 | 拖动图标设定单边两个触发区域的分界位置 |
| 长滑手感 | 「滑动距离加成」决定边框上滑一段对应屏幕滑多远；「触发距离」决定滑多长才开始触发 |
| 拨滑手感 | 调速滑的触发速度阈值 |
| 震动反馈 | 触发时是否振动提示 |
| 触发视觉 | 游戏内触发时是否显示视觉提示 |

调手感的原则：先按默认玩一局，哪个动作容易「按不出来」就把对应阈值调灵敏，哪个动作容易「误触发」就调迟钝；每改一项单独验证，不要一次全调。

## 四、按压不灵的姿势因素

ROG 官方对按压触控键给过专门的操作建议，这几条直接决定触发稳定性：

- 用指腹或指尖集中按压小面积区域，整只手攥压力度反而不稳定；
- 按肩键的同时轻触屏幕下半部的按键，避免手指同时压到肩键旁的屏幕角落；
- 握持稳定，不要大力摇晃或紧攥机身——感应元件就在边框上，用力握压会让检测不稳；
- 装保护壳时确认四个角落完全贴合，壳没装正会给边框持续施加压力，导致需要更大力度才能触发或直接误触；拆装保护壳前先退出游戏。

## 五、肩键失灵的排查顺序

按华硕官方支持页给的步骤走：

1. 确认功能已启用：系统设置 → 智能辅助 → AirTriggers，检查开关与配置；
2. 把系统更新到最新版本，肩键相关修正常随系统更新下发；
3. 用干净软布擦拭机身侧边触控区域，灰尘与油脂会干扰检测；
4. 重启手机；
5. 以上都无效，联系华硕官方客服或售后服务中心。

映射层面的问题（键位点了没反应、位置对不上）与硬件层面的失灵（按压毫无反馈）要分开看：前者回到第二节重新拖圆圈，多数是游戏更新改了界面；后者按本节顺序排查。
