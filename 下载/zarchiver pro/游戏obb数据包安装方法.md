# 游戏obb数据包安装方法

> 大型安卓游戏常以「apk + OBB 数据包」一起发：apk 装程序本体，OBB 装素材。本篇讲怎么用 ZArchiver Pro 把 OBB 解压出来、放进正确路径，装完能正常进游戏。

## 一、OBB 是什么，为什么放不对就进不了游戏

OBB 是安卓大型游戏的附加数据文件，里面是贴图、音频、地图这类大块素材；apk 本体不含这些。游戏首次启动会去固定路径找它：

`内部存储/Android/obb/<游戏包名>/`

三个硬性条件，缺一条就会提示「需要下载额外数据」或直接闪退：

1. **文件夹名与游戏包名逐字一致** —— 包名形如 `com.xxx.xxx`，游戏的发布页或 OBB 文件名里能找到；
2. **.obb 文件保持原文件名**，不要重命名，启动时校验的就有文件名；
3. **apk 与 OBB 必须是同一版本**，版本错开游戏不认。

## 二、完整步骤

1. 在 ZArchiver Pro 里找到游戏压缩包（多为 zip/rar/7z），解压出里面的 .obb 文件（或包含 obb 的文件夹）。解压方式见 [压缩与解压操作步骤.md](压缩与解压操作步骤.md)；
2. 在应用里进入 `Android/obb/`；没有这个文件夹就新建一个；
3. 在 obb 下新建以游戏包名命名的文件夹，比如 `com.gamedevstudio.mygame`；
4. 长按 .obb 文件 →「移动」或「复制」→ 导航到刚建的包名文件夹 → 粘贴；
5. 安装游戏 apk（步骤见 [下载与安装教程.md](下载与安装教程.md)）；
6. 首次启动前确认 OBB 已就位——先放 OBB 再装 apk、或先装 apk 再放 OBB 都可以，别在 OBB 缺位时先启动游戏。

**安卓 11 及以后**：系统挡住了大多数应用往 `Android/obb` 写文件的常规路径。ZArchiver Pro 粘贴时会弹出「特殊文件夹访问」的授权请求，同意后即可继续，无需 root。

**安卓 13 起**：data/obb 的限制进一步收紧，官方说明是解压与粘贴通常只能落在这些目录的**子文件夹**里，且进入子文件夹还需要单独确认——操作时把目标直接选到包名子文件夹一级，别试图直接往 obb 根目录里塞文件。

## 三、装完还是提示「需要额外数据」或闪退

| 现象 | 大概率原因 |
| --- | --- |
| 启动提示下载额外资源 | OBB 不在 `Android/obb/<包名>/` 下，或包名文件夹拼写有误（多一个空格、大小写不同都算错） |
| 位置看着正确仍不认 | .obb 文件被重命名过；或 apk 与 OBB 不是同一版本 |
| 首次启动就闪退 | OBB 还没放就先开过游戏。放好 OBB 后，到系统设置里**清除该游戏的存储数据**，再重新启动让它重新校验 |
| 解压 OBB 时报错 | 游戏压缩包没下完整或已损坏，重新下载一份（排查见 [常见问题与报错处理.md](常见问题与报错处理.md)） |

一个常见的坑：从网盘转存时只下了一半，解压出的 .obb 比发布页标注的体积小。放进去游戏照样不认。放 OBB 前先核对一眼文件大小，与发布页标注一致再动手，能省一轮反复。
