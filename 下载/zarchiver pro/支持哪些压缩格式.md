## 一、能解压（打开）的格式

| 格式 | 常见来源 |
| --- | --- |
| ZIP、7z、RAR、RAR5 | 网上下载的资源、别人发来的附件 |
| TAR、GZIP、BZIP2、XZ、LZMA | Linux 包、源码分发包 |
| ISO、DMG、WIM | 系统镜像、光盘镜像，可像浏览压缩包一样查看内容 |
| CAB、ARJ、LZH/LHA | Windows 安装介质、老式归档与日系软件常用包 |
| ZIPX、CPIO | zip 的新版变体与 Unix 系统归档 |
| DEB、RPM | Linux 发行版的安装包，可查看里面的文件 |
| APK、JAR、MTZ | 本质是 zip 系容器，可以点开查看，部分格式还支持直接编辑里面的文件 |

碰到列表里没有的扩展名，先点开试试：ZArchiver 对不少冷门格式（如 `lha`、`zst` 一类）也有支持，以你安装的版本实际表现为准。

## 二、能创建的格式

创建压缩包时可以选的格式主要是：

- **7z** —— 压缩率最高，支持 AES-256 加密，推荐做备份时用；
- **ZIP** —— 兼容性最好，手机、电脑、对方用什么工具都能打开；
- **TAR、GZIP、BZIP2、XZ** —— 需要给 Linux 环境传文件时用。

**RAR 只能解压、不能创建。** RAR 的压缩算法有专利限制，任何第三方工具都做不出真正的 RAR 文件，只有官方 RAR/WinRAR 可以。需要发给别人一个「能压得比较小」的包时，用 7z 代替，除非对方明确要求 RAR。

## 三、哪些格式支持密码

| 场景 | 支持情况 |
| --- | --- |
| 创建加密包 | 7z 与 ZIP 支持设置密码（7z 走 AES-256），详见[加密压缩与密码设置.md](加密压缩与密码设置.md) |
| 解压带密码的包 | ZIP、RAR、7z 的加密包都能解，过程中会弹密码输入框 |
| 加密文件名 | 7z 可以连文件名一起藏起来，ZIP 一般只加密内容 |

## 四、分卷压缩包

- **解压**：把同一组分卷（`xxx.zip.001/.002…`、`xxx.part1.rar/part2.rar…`、`xxx.7z.001…`）放进同一个文件夹，点第一个分卷即可，后面的自动接上；
- **创建**：压缩对话框里可以把包切成指定大小的分卷，方便分次传输。

具体操作与分卷大小的选择见 [压缩与解压操作步骤.md](压缩与解压操作步骤.md)。

## 五、中文文件名乱码

老 ZIP 常出这问题：Windows 上打包时文件名用的是本地编码（简体中文环境就是 GBK），包里又没标注编码，解出来的中文就成了「瀹夊崜」式的乱码。处理路子：

1. 打开 ZArchiver Pro 的设置，找「默认代码页 / 文件名编码」类选项，改成简体中文（GBK / GB2312），回头重新解压这份包；
2. 应用对 UTF-8 / UTF-16 文件名有原生支持，新近打包的 zip、7z、rar 一般不会出这问题；
3. 已经解出来的乱码文件，重命名一遍即可，文件内容本身不受影响。

不同版本的设置入口位置可能不同，以应用内实际设置为准。
