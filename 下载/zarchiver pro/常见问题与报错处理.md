## 一、报错对照与「操作完成，但出现错误」

解压时弹出「操作完成，但出现错误」，通常是两类原因：

1. **存储空间不足** —— 看手机剩余空间是否小于压缩包解压后的大小（不是 apk 的大小，是内容展开后的大小），清出空间重试；
2. **压缩包本身有问题** —— 下载不完整或源文件已损坏。在应用里点开这个包，菜单里找「测试」功能跑一遍，能列出具体哪里出错。

小警告可以忽略着用，大面积报错的包只能找源重新下载一份完整的。测试通过却依然解压失败的，换一个解压目标路径（个别目录写入受限）再试。

其他高频报错，按官方错误说明的口径对照处理：

| 报错提示 | 含义与处理 |
| --- | --- |
| Cannot find volume（找不到分卷） | 分卷不全，或几个分卷没放在同一个文件夹；补齐后从第一个分卷重新解压 |
| CRC 错误 / 意外的压缩包结尾 / 数据错误 | 包已损坏或没下完整。发布页若给了体积或 MD5，先核对再决定重下；损坏包在手机端基本无法修复 |
| 磁盘空间不足 | 清出比解压后体积更大的空间再试 |
| 密码错误 | 密码不对。检查空格、全半角与输入法状态（更多见[加密压缩与密码设置.md](加密压缩与密码设置.md)） |
| 无法打开文件作为压缩包 / 未知格式 | 这个文件本身不是压缩包——从网页下载时常下到的是网页文件。核对扩展名与文件大小，重新下载真正的压缩包 |

## 二、看不到 Android/data 和 Android/obb

安卓 11 起，系统限制了所有应用对 `Android/data`、`Android/obb` 这两个目录的直接访问，不是 ZArchiver Pro 的问题。处理顺序：

1. 确认已开启「允许管理所有文件」权限（路径见 [下载与安装教程.md](下载与安装教程.md) 第五节）；
2. 开了权限后能进入的目录会变多；仍进不去的目录属于系统级限制。安卓 13 起限制更细：往 data/obb 里解压、粘贴通常只能落在**子文件夹**，进入子文件夹还要单独确认一次。要把游戏 OBB 数据包放进 `Android/obb` 的完整步骤与排错，单独见 [游戏obb数据包安装方法.md](游戏obb数据包安装方法.md)；
3. 不同品牌系统对这个限制的宽严不一，个别机型上确实无解，属正常现象。

## 三、解压完找不到文件

按解压时的选择对号入座：

| 当时选的方式 | 文件在哪 |
| --- | --- |
| 解压到当前目录 | 压缩包所在的那个文件夹 |
| 解压到…（自选路径） | 你选的那个路径，常见是 `Download` 下自建的文件夹 |
| 只解压了某个文件 | 同上两种，取决于当时用的方式 |

找不到就在应用内列表里逐级回退，或用系统文件管理器搜解出来的文件名。建议养成固定解压到某个文件夹的习惯，之后好找也好清理。

## 四、能不能装在电脑或 iPhone 上

- **iPhone/iPad：没有 iOS 版。** 这是纯安卓应用，App Store 上搜不到；
- **电脑：不能直接装，要借助安卓模拟器**（如常见的几款模拟器软件），在模拟器里装这份 apk 后按手机上的用法操作。电脑上其实用不到它——Windows 自带 zip 支持，7z 用 7-Zip 这类桌面工具更直接；
- **平板与安卓电视盒子**：系统是安卓就能装，界面在大屏上同样可用。

## 五、怎么更新版本

它不会自己检查更新。商店版在 Google Play 里更新；apk 版重下新版覆盖安装（数据保留）。当前这份安装包是 1.0.11 版，之后想确认有没有新版，去官方渠道看版本号即可。

## 六、它需要联网吗

不需要。ZArchiver Pro 不申请网络权限，压缩、解压、加密全部在本地完成，这也是它适合处理私密文件的原因之一。随之而来的边界：

- 网盘里的文件要先下载到本机才能操作，它没有内置云盘支持；
- 有独立的 ZArchiver Cloud Plugin 插件（Google Play 提供）可以补上 Google Drive、OneDrive 等网盘的直连，国内网络环境下实用性有限，不装也完全不影响核心功能。

## 七、其他小问题

- **图标点开没反应**：确认存储权限已给足；仍无反应就重启手机再试；
- **界面是英文**：设置里找 Language 选项切换到中文；
- **压缩包里的视频播放卡顿**：大媒体文件建议解压出来再看，「查看」模式只适合预览；
- **装了免费版还能装 Pro 吗**：两者包名不同（`ru.zdevs.zarchiver` 与 `ru.zdevs.zarchiver.pro`），可以共存，互不影响。
