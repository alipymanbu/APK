## 一、界面地图

应用内主要入口按官方说明整理如下（不同版本措辞可能微调，以你手上这版界面为准）：

| 入口 | 你在这里做什么 |
| --- | --- |
| 首页 | 看当下的热门曲与 Melon 原创内容 |
| For You | 快速起播的 DJ「DJ말랑이」与个性化推荐 |
| 탐색（探索） | 按推荐标签、曲风、心情找歌 |
| 음악서랍（音乐抽屉） | 收藏与播放记录的仓库，你的歌单都在这管理 |
| 멜론차트（榜单） | TOP100、HOT100、曲风榜、主题榜 |
| 핫트랙（热门单曲） | 榜单之外的新歌趋势 |
| 멜론TV | 音乐视频、节目，高清播放 |
| 아티스트채널（艺人频道） | 单个艺人的专辑、视频、照片、动态 |
| 음악검색（听歌识曲） | 哼唱或外放一段，它帮你找歌 |

**从哪开始**：第一次用先去「音乐抽屉」建一个歌单，把想听的先囤进去；日常刷歌走 For You 和榜单。

## 二、播放器：手势与迷你模式

- **左右滑动切歌**：播放页上滑动即可上一首 / 下一首，这是官方设计的主手势。
- **迷你播放器**：播放中收起成底部小条，你继续浏览其他内容，歌不停。点它展开回全屏播放页。
- **歌词**：流媒体播放与下载播放都带歌词，播放页里开。
- **音效**：设置里有 EQ（均衡器）和 **AI Master** 自动音效——AI Master 是开了就自动调的那种，不想折腾就用它，想自己控制就进 EQ 手调。

## 三、榜单怎么看

Melon 榜单分几类：**TOP100**（周期性排名）、**HOT100**（热度向）、曲风榜、主题榜。看榜本身是免费的，不需要买利用权。两个使用提示：

- 榜单页面能直接点歌进播放器；未购票时听到的多半是试听，能放多久以曲目页面提示为准（原因见 [会员价格与免费听歌.md](会员价格与免费听歌.md)）。
- 「핫트랙」是榜单之外的新歌区，找还没上榜的新发行从这里翻比较快。

## 四、收藏、歌单与音乐抽屉

- **音乐抽屉**是收藏的总容器：你在任何页面点收藏的歌都进这里，播放记录也沉淀在这。
- **歌单支持文件夹分层**，长列表可以按文件夹分组播放——歌多了以后靠这个找歌，比翻长列表快。
- 抽屉里的记录会随时间变淡是官方设计的视觉效果，收藏本身不受影响。

## 五、桌面小组件

支持四种尺寸：**2×1、2×2、4×1、4×2**。添加方式是常规安卓操作：长按桌面空白处 → 小组件 → 找到 Melon → 拖到桌面。

一个官方点名的坑：**升级应用前先把旧小组件移除**，带着旧组件升级会报错。步骤见 [下载与安装教程.md](下载与安装教程.md) 第五节。

## 六、手表与电脑怎么用

- **Wear OS 手表**：Melon 有手表版，两种用法——连着手机当遥控器用，或者手表独立听（手表上得先存好歌）。
- **PC 端**：官方有 Melon 播放器（PC Player），电脑上装好后用同一账号登录。你在手机上买利用权后，PC 播放器能不能播取决于你的利用权是否含 PC 档——手机专用档（如 모바일 스트리밍클럽、Lite）在 PC 上放不了，具体见 [会员价格与免费听歌.md](会员价格与免费听歌.md) 的价格表。
- 手机应用里的「电话」权限有一项用途就是「PC 播放器联动」，联动不上先检查这个权限有没有被拒。

## 七、搜索的两个姿势

1. **打字搜**：探索页的搜索框，支持按推荐标签缩小范围。
2. **听歌识曲**：播放页或搜索页的识曲入口，对着声源哼或外放即可——这项要给**麦克风权限**（可选权限，不给就用不了识曲，打字搜不受影响）。
