## 一、先确认装的是哪个应用

Melon 是韩国 Kakao Entertainment Corp. 出的音乐流媒体应用，安卓包名是 `com.iloen.melon`。你在应用商店或第三方商店里看到的标题一般是「멜론(Melon)」—— 멜론 就是它的韩文名，指同一个东西。

网上能搜到的最新版往往比你手里这份新，所以下面这些**以本地这份安装包的事实为准**：

| 项目 | 值 |
| --- | --- |
| 版本 | 6.24.0.1 |
| 包名 | `com.iloen.melon` |
| 安装包大小 | 89.60M |
| MD5 | `761798e6b2829f0d5e552eff493243ee` |
| 官方开发者 | Kakao Entertainment Corp. |

版本号会随官方更新持续变化，官方最新版以 [Google Play 的 Melon 页面](https://play.google.com/store/apps/details?id=com.iloen.melon) 显示为准。第三方商店页面标注过「最低 Android 11+」，你手上这台机器如果系统较旧，装之前先确认一下能不能装。

## 二、拿到安装包

两条路，按你的情况选：

1. **装网盘里这份**：打开 [Melon 安装文件资源（夸克网盘）](https://pan.quark.cn/s/fab10023b411)，把 `melon_v6.24.0.1.apk` 转存或直接下载到手机。这份就是上表那版，MD5 可以自己校验。
2. **走官方商店**：Google Play 搜「멜론」，认准开发者 Kakao Entertainment Corp.。好处是以后自动更新；坏处是有些地区商店搜不到，或者商店版版本与网盘这份不同。

两条路装的是同一个应用（包名一致），账号通用。**只需要选一条**，别两个都装。

## 三、安装步骤

1. 把 APK 文件放到手机上（下载目录即可）。
2. 点击 APK 文件开始安装。如果系统弹出「禁止安装来自此来源的应用」，是浏览器或文件管理器还没拿到「安装未知应用」权限 —— 去设置里对该应用打开这个开关，再回来点一次。
3. 等安装完成，先别急着打开，把权限这关过了再说（下一节）。
4. 首次打开会要你同意条款并登录，流程见 [注册与登录账号.md](注册与登录账号.md)。

安装包 MD5 与上表对不上的，说明文件在传输中变了，重新下一次再装。

## 四、它要的权限，给还是不给

官方商店页列了四项，前两项是必需的：

| 权限 | 干什么用 | 必需性 |
| --- | --- | --- |
| 电话 | 登录、设备注册、下载与流媒体播放、结算、PC 播放器联动、音乐缓存模块初始化 | 必需 |
| 存储空间 | 写入媒体库、下载内容与歌词、生成本地播放列表、客服排障日志 | 必需 |
| 麦克风 | 「听歌识曲」功能 | 可选 |
| 位置 | For U 的天气信息推荐 | 可选 |

两条实际建议：

- **电话权限别随手拒**。它不是「打电话」的意思，登录、播放、下载这一整条链都依赖它，拒了应用基本用不了。
- 麦克风、位置这两项**不用就不给**。系统是 Android 6.0 以上可以随时在设置里改；6.0 以下的机器不能按应用单独控权限，只能整体给或不给。

## 五、更新前的一个坑（官方点名的）

官方更新日志里专门写了一条：**更新前先卸掉桌面上已有的 Melon 小组件**。带着旧小组件直接升级，小组件会报错。顺序是：

1. 长按桌面小组件 → 移除；
2. 再安装新版 APK（或等商店自动更新）；
3. 装完重新添加小组件。

小组件支持 2×1、2×2、4×1、4×2 四种尺寸，装回去见 [功能与界面使用指南.md](功能与界面使用指南.md)。

更新走完后你的账号登录态与收藏都还在；万一内容对不上，见第六节的排查顺序。

## 六、装完打不开、装不上怎么办

按这几条顺序排查，能覆盖绝大多数情况：

- **安装时解析错误** → APK 没下完整，重新下载；或系统版本低于应用要求，先升级系统。
- **装上了但闪退 / 提示错误** → 先确认小组件是否按第五节卸干净了；再试「设置 → 应用 → Melon → 清除缓存」（**别点清除数据**，会掉登录态）。
- **播放、下载、登录相关功能全部异常** → 检查电话与存储两项必需权限有没有被安全软件拦掉。

更细的症状对照（只播 1 分钟、支付后不能播、掉线等）在 [常见问题与故障排查.md](常见问题与故障排查.md)。
