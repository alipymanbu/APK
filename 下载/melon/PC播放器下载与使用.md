## 一、先确认你要的东西

Melon 的电脑端叫 **PC 播放器（Melon 플레이어 / PC Player）**，是独立于手机应用的一个程序，免费安装，**但能不能播歌取决于你的利用权含不含 PC**：手机专用档（모바일 스트리밍클럽、스트리밍 라이트）在 PC 上放不了，不限设备的档（如 스트리밍클럽）才可。对照表见 [会员价格与免费听歌.md](会员价格与免费听歌.md)。

系统与体积（有用户整理的资料，截至 2026 年年中，以官方下载页当时显示为准）：支持 Windows 10/11 与 macOS，安装包约 80 多 MB。

## 二、从哪下载（只走这三个渠道）

1. **官方站点**：[melon.com](https://www.melon.com) 页面底部的「PC 플레이어 다운로드（PC 播放器下载）」入口，进去选 Windows 版或 Mac 版；
2. **Microsoft Store**：Windows 版可直接从微软商店装；
3. **Mac App Store**：macOS 版。

一个有用户反复反馈的坑：**搜索结果顶部那些「某某安装文件立即下载」的广告页大多不是官方分发点**，从那里拿的安装包可能捆了广告程序或版本陈旧。判断标准很简单——认准上面三个渠道，其余链接不点。

安装过程中如果出现额外组件的勾选框（工具栏、附带程序之类），**逐个取消勾选再继续**，这也是社区里最常见的翻车点。

## 三、装完之后

1. 启动播放器，用**与手机同一个 Kakao 账号**登录（Melon 登录只走 Kakao，见 [注册与登录账号.md](注册与登录账号.md)）。
2. 顶部菜单里 榜单 / 搜索 / 播放列表 与手机端逻辑一致，界面怎么用参考 [功能与界面使用指南.md](功能与界面使用指南.md)。
3. 音质在 **设置 → 音质** 里选（高码率档需要利用权），档位含义见 [音质与流量设置.md](音质与流量设置.md)。
4. PC 上下载的歌在播放器的「我的音乐」里管理；想把手机下载的文件经 USB 弄到电脑，属于老式传文件流程，需要装好手机的 USB 驱动并按提示注册设备，现在的用法已经很少走这条线。

## 四、常见卡点

| 症状 | 先查什么 |
| --- | --- |
| PC 上点播放提示无权限 | 利用权是不是手机专用档；在 [会员价格与免费听歌.md](会员价格与免费听歌.md) 里对号 |
| 手机买了票，PC 显示未登录 / 没票 | 两边登录的是否同一 Kakao 账号；退出重登一次触发同步 |
| 手机与 PC 联动不上 | 手机应用的「电话」权限（含 PC 播放器联动用途）有没有被拒，见 [下载与安装教程.md](下载与安装教程.md) 权限表 |
| 下载中断、设备报错 | 官方帮助中心的 Windows 播放器条目有对应错误码说明，按码查 |

再遇到别的症状，汇总入口在 [常见问题与故障排查.md](常见问题与故障排查.md)。
