## 一、App 搜不到 / 添加不了摄像头

按命中率从高到低查：

1. **权限没给全** —— 位置服务与蓝牙必须开启、App 的位置与蓝牙权限必须允许。安卓扫描周边 Wi-Fi / 蓝牙设备是系统级依赖位置权限的，这是搜不到设备的第一大原因；
2. **摄像头不在待配状态** —— 看指示灯：红灯慢闪才是待配。不是就长按 `MODE/RESET` 约 5 秒恢复出厂，等红灯重新慢闪；
3. **热点没连对** —— 手动方式下要连的是摄像头自己的热点（`DGK` / `DGB` / `DGC` / `DGO` / `DBG` 开头，格式 `DGXX-XXXXXX-XXXX`，无密码），不是你家路由器；连上后手机弹「网络无法上网是否切换」时别切；
4. **连热点后忘了回 App** —— 连完热点必须切回 HDWiFiCamPro 继续，停在设置页是配不上的。

## 二、配网失败 / 摄像头反复离线

先读指示灯定性，再对症：

| 灯态 | 症状定性 | 处理 |
|---|---|---|
| 红灯慢闪 | 压根没配上 | 检查 Wi-Fi 是否 2.4G、密码是否输对 |
| 红灯快闪且长时间不停 | 连接失败 / 密码错误 | 重置摄像头后重新配；确认密码无误 |
| 红灯常亮但 App 显示离线 | 网络侧不通 | 检查路由器、把摄像头挪近路由器再试 |

配网本身的要求再核一遍：

- **只支持 2.4G Wi-Fi，不支持 5G** —— 双频合一的路由要确认手机连的是 2.4G 信号；
- **Wi-Fi 名称与密码别含中文或特殊符号**（`#`、`*`、`&`、`=` 等），改成纯字母数字再试；
- 公共 Wi-Fi（需要网页登录认证的那种）用不了；
- 加密方式用 WPA，别用老旧的 WEP；
- 改了路由器密码后，摄像头会因密码不对掉线 —— 重置并重新配网一次即可。

## 三、要用户名密码时怎么办

摄像头端的默认用户名是 `Camera`、默认（P2P）密码是 `6666`。忘记密码不重装 App 也没用 —— **长按 `MODE/RESET` 约 5 秒恢复出厂**，密码即回到默认值，再重新添加设备。恢复出厂会删掉已有的连接数据，配网得重做一遍。

## 四、画面模糊 / 看不清

1. 先撕掉镜头保护膜（新摄像头常忘）；
2. 还糊就**旋转镜头手动对焦**，对焦后画面变清晰；
3. 远程观看卡顿则与网络有关：把分辨率从 1080P 降到 720P，或靠近路由器。

## 五、回放没有录像 / SD 卡不工作

按这个顺序排，每排除一项再看下一项：

1. 实时画面能否正常预览；
2. 设置 → SD 卡页能否读出卡的容量（读不出 = 卡没插好或卡坏了）；
3. **首次使用必须在 App 内格式化一次**，没格式化过基本不会录像；
4. 64GB 及以上的卡需先在电脑上格式化为 FAT32，建议 Class 10；
5. 插拔卡前先关机，热插拔可能损坏文件；
6. 都正常仍无文件 —— 取下重插一次，再不行换张新卡重走设置。

## 六、收不到报警推送

- 手机侧：「设置 → 应用管理 → HDWiFiCamPro → 通知」必须开启，且别开免打扰拦截；
- 摄像头侧：报警设置里移动侦测要打开、布防时间段要覆盖你要的时段；
- 误报太多就调低灵敏度、调整监控区域，避开风口、树叶、飞虫多的位置。

## 七、功能异常 / 闪退 / 没声音

- 首次启动弹权限时点过「拒绝」的，逐项到系统设置里补开 —— 存储、麦克风、通知缺哪个就出哪类毛病；
- 部分小型摄像头**机身没有扬声器**，对讲时对方听不到画面那侧的声音是硬件限制，不是 App 故障；
- App 本身装不上（解析错误、版本冲突），核对安装包版本与包名，见[下载与安装教程.md](下载与安装教程.md)。
