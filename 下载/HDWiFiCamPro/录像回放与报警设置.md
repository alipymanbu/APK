## 一、视频页上的按钮都是干什么的

点开一个在线摄像头进入实时画面页，常用操作都摊在画面上：

| 操作 | 说明 |
|---|---|
| 滑动画面 | 转动云台（需要摄像头本身带云台） |
| 按住对讲 / 音频 | 双向语音，你能听到画面里的声音、也能说话过去 |
| 录像 / 拍照 | 手动录制视频、抓拍截图 |
| 画面翻转 | 上下、左右翻转画面，装倒了靠它扶正 |
| 亮度 / 对比度 | 调画面明暗 |
| 红外开关 | 夜视模式切换 |
| 分辨率 | 1080P / 720P 切换；网络差时降到 720P 更流畅 |
| 回放（Playback） | 看 SD 卡里已存的录像 |

页面下方的标签页分工：`Camera` 是实时画面，`Photo` 是你抓拍的图，`Video` 是手机本地录的视频，`Event` 是报警事件记录，`Recorded Videos` 汇总手动录像与 SD 卡录像。

## 二、插卡与录像设置

1. **关机再插卡** —— 带电插拔 TF 卡容易损坏文件，这是最容易踩的坑；
2. 卡的规格：Class 10、FAT 格式，**容量上限 128GB**（官方手册口径；买卡别贪大）；
3. **64GB 及以上的卡要先在电脑上格式化成 FAT32**；
4. **首次使用必须在 App 里格式化一次**，否则录像可能根本不落盘；
5. App 读不到卡时，先把卡取下再重新插一次 —— 手册明确「重插一次」就是首选动作，仍不识别再换卡；
6. 进齿轮设置 → 录像（Record / SD 卡），能看到卡的容量，确认 App 能正常读到卡；
7. 设置录像模式：`定时录像`（到点就录）与`报警录像`（有动静才录），可分别设置画面尺寸。

设置完可以故意在摄像头前走动触发一次，再进回放确认有文件 —— 比等出事才发现没录上强。

## 三、回放怎么看

- **SD 卡回放**：实时画面页点 `…` → 回放（Playback），按时间轴找录像；
- **手机本地录像**：在 `Video` / `Recorded Videos` 标签里；
- **报警片段**：在 `Event` 标签里。

回放为空时按顺序查三件事：实时画面是否正常 → 设置里能否读到 SD 卡（能读到容量）→ 把卡取下重新插一次。三项都正常还没有文件，多半是卡没格式化或卡本身有问题，换张新卡重试，详见[常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、移动侦测报警怎么设

1. 进摄像头设置 → 报警设置，打开移动侦测，调灵敏度 —— 调低可以减少飞虫、树叶、灰尘引起的误报，调高则不容易漏报；
2. **手机侧必须给 HDWiFiCamPro 通知权限**，否则摄像头拍到了你也收不到推送（安卓在「设置 → 应用管理 → HDWiFiCamPro → 通知」里开）；
3. 需要的话设置布防时间段，只在需要的时段报警；
4. 报警消息在 `Event` 页面查看。

两点口径说明：`Event` 页面的云录制（云端存报警视频）目前不支持，报警录像存在 SD 卡里；想永久留存某段报警视频，进回放找到后录屏或另存。

## 五、把摄像头分享给家人

在摄像头设置里找到「二维码 / Camera ID」（分享设备）：

1. 主设备手机 A 与摄像头连好（摄像头当前不连 Wi-Fi 时走二维码分享，具体以界面提示为准）；
2. 让对方手机 B 扫你的二维码，或输入 Camera ID 添加；
3. 添加成功后 B 也能看这台摄像头。

注意：**同一台摄像头不能被两台手机同时在线观看**，冲突时一边会掉线 —— 家里轮流看没问题，两个人长时间同看会互相挤。

## 六、画面时间不对，录像白存

回放时时间戳错了，找文件与留证都会出问题。两种常见表现与处理：

- **画面时间与实际差一整段（差几小时）**：差固定小时数通常是时区问题 —— 先把手机的时区与「自动确定时间」校准，再进摄像头设置看时间选项，按界面提供的时区/校时方式设对；
- **时间退回出厂日期（如 2000 年或很久以前）**：摄像头断电久了内部时钟复位。重新上电、确认它在线后会自行同步；不放心就在设置里手动校一次时间。

时间没校准不只是显示难看：录像会存到错误的时间点上，回放按日期找会找不到、录像覆盖顺序也会乱。改完时间后录一小段验证时间戳再走开。
