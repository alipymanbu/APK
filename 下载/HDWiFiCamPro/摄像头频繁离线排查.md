## 一、先按掉线规律对号入座

掉线不是一种病，规律不同、病根不同。先观察两天再动手，别急着恢复出厂（会把配网一起清掉）：

| 掉线规律 | 最可能的根因 | 从哪查起 |
|---|---|---|
| 一天掉几次、时间随机 | Wi-Fi 信号弱或受干扰 | 见第二节 |
| 每天在同一时间点掉 | 路由器定时重启 / 宽带维护 | 路由器管理页的定时重启设置 |
| 掉几小时后自己又上线 | 路由器 IP 分配冲突 | 见第四节 |
| 掉线前指示灯会灭一下再亮 | 供电不稳导致重启 | 见第三节 |
| 换季、天气极端时掉得多 | 摄像头超出工作温度范围 | 挪离热源 / 检查散热 |
| 全屋其他设备同时断 | 路由器或宽带的问题，与摄像头无关 | 重启路由、查宽带 |

## 二、信号弱是第一大原因

摄像头要 24 小时挂着流，手机刷网页「勉强能用」的信号对它来说往往不够。判断与处理：

- **把手机拿到摄像头安装位置**，看 Wi-Fi 信号格 —— 只有一两格就基本是信号问题；
- 官方与通用经验的参考线：信号强度 **低于约 -70 dBm 就难以稳定推流**（可用任意 Wi-Fi 分析类 App 在安装位置实测）；
- 处理顺序：先把摄像头临时挪近路由器测试 → 掉线消失就说明是距离/墙体问题 → 长期方案是加中继或 mesh 节点、或换个安装位；
- 摄像头只走 **2.4G**，它穿墙比 5G 好，别因为「5G 快」把它往 5G 上引（引不了）；
- 家里微波炉、蓝牙设备、无绳电话都挤在 2.4G 频段，摄像头别贴着这些电器装。

## 三、供电不稳会伪装成网络问题

「掉线前灯会灭一下再亮」= 摄像头在重启，多半是电的问题而不是网的问题：

- 换一个插座试试，避开插排 —— 插排接点多了会压降；
- 用原装或规格匹配的电源适配器（这类小型摄像头常见 5V 输入），劣质适配器用一两年后输出会漂；
- 家里有冰箱等大功率电器共用一路电时，电压波动会把摄像头打重启；
- 停电来电后如果摄像头再也没上线：路由器往往比摄像头先启动完成，摄像头错过了联网窗口 —— 给它断电重启一次，或按[摄像头配网连接教程.md](摄像头配网连接教程.md)重新配网。

## 四、路由器侧的几个设置

- **设备数量**：老路由器带 20 来个设备（手机 + 电视 + 智能家电）就会吃力，拥堵时摄像头这类「一直挂着」的设备最先被挤掉 —— 进路由器管理页清掉不用的设备；
- **IP 冲突**：摄像头拿到的 IP 被别的设备抢走时，会掉几小时又自己回来；在路由器里给摄像头按 MAC 地址绑定固定 IP 可根治；
- **信道拥挤**：2.4G 只有 1、6、11 三个互不重叠的信道，邻居的路由都挤在同一信道上会又卡又掉 —— 在路由器里手动换到最空的那个信道；
- **防火墙 / MAC 过滤**：路由器开过 MAC 白名单或严格防火墙的，把摄像头放行；
- **改过 Wi-Fi 密码**：改密码当天摄像头必掉线，重置后重新配网即可，见[常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、什么时候才该恢复出厂

长按 `MODE/RESET` 5 秒会**清掉配网数据，全部重来**，所以放在最后：

1. 前四节都排除了，摄像头仍然反复掉线；
2. 或它已经彻底不广播热点、连 AP 模式都进不去；
3. 恢复出厂后重新走一遍配网，若配好后稳定了，说明之前是配置数据坏了；若依旧掉线，问题在环境（信号 / 供电）或硬件本身。
