## 一、这是什么，装之前先确认两件事

KiliKili 是给智能手表用的第三方 B 站客户端：在表盘上浏览推荐视频、搜索、看关注 UP 主的更新，也能直接播放。它不替代手机版 B 站，界面是按手表的小屏幕做的。

装之前确认两件事：

| 检查项 | 这份包的要求 | 在哪儿看 |
| --- | --- | --- |
| 系统版本 | Android 5.0（API 21）及以上 | 手表「设置 → 关于 → 系统版本」 |
| CPU 架构 | 只含 32 位 ARM（armeabi-v7a） | 见 [手表上装不上怎么排查.md](手表上装不上怎么排查.md) 第二节 |

系统版本这一条来自项目在代码仓库里的构建配置；这份安装包本身只打包了 32 位 ARM 的原生库，能执行 32 位应用的手表可以装，纯 64 位、已不再兼容 32 位应用的设备会被系统直接拒绝，安装时报「与您的设备不兼容」这类提示。

另外两点，先说清楚免得走冤枉路：

- **没有机型白名单。** 项目没有给「支持哪些型号」的清单，能不能装就取决于上表那两条门槛，用 [手表上装不上怎么排查.md](手表上装不上怎么排查.md) 第二节、第三节里的命令自查即可；
- **它是给 Wear OS 手表做的应用。** 这份文档只覆盖 Wear OS 手表上的用法；装到平板、手机或其他穿戴系统上，界面与操作不在本文范围内。

## 三、把安装包送进手表的三条路

三条路都能用，按你手边的条件挑一条即可。

### 3.1 手表自己下载安装

前提是手表能连 Wi-Fi，并且装了能打开网盘的浏览器或文件管理器。

1. 在手表上打开 **KiliKili 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/37157b70cd7b](https://pan.quark.cn/s/37157b70cd7b)；
2. 转存到自己网盘后下载，或者直接下载这一份包；
3. 下载完成后用文件管理器点这个 `.apk` 安装。

手表上操作的两个注意点：表盘上不一定能看全下载进度，等系统通知栏出现「下载完成」再动手；安装按钮通常在列表最底部，记得滑到底。

### 3.2 用手机配套应用推送到手表

部分手表厂商的配套手机应用提供「安装应用到手表」这类入口，把 APK 先传到手机再推过去即可。这条路依赖厂商应用的功能，不是每块表都有，找不到入口就换 3.3 或 3.1。

### 3.3 用 ADB 安装（最稳，适合反复重装）

这条路要先过两道：配对与连接，用的是不同的端口，顺序不能颠倒。

准备：电脑与手表在同一个 Wi-Fi 网络，电脑上的 `adb` 版本不低于 30.0.0。

在手表上：设置 → 关于 → 连点「版本号」进入开发者选项 → 打开「ADB 调试」→ 打开「无线调试」→ 弹窗选「允许」。

```bash
# 1) 首次配对（一部电脑只需一次）：手表上进入「无线调试 → 与新设备配对」
adb pair 192.168.1.23:37821        # 换成手表显示的 IP 与配对端口，随后输入配对码

# 2) 连接：回到「无线调试」页取 IP 与连接端口（不是配对端口）
adb connect 192.168.1.23:5555
adb devices                        # 列表里出现手表即已连上

# 3) 安装
adb install -r "KiliKili_v0.3.2.apk"
```

`-r` 表示覆盖安装、保留已有数据，装第二次会用到。手表重启无线调试或换了 Wi-Fi 之后，只需要重做第 2 步。

配对不成功、`adb devices` 里看不到手表、连上却报错 —— 这三类分别对照 [手表无线调试连不上怎么排查.md](手表无线调试连不上怎么排查.md) 与 [手表上装不上怎么排查.md](手表上装不上怎么排查.md)。

## 四、安装时容易被挡的两个地方

- **未知来源权限**：手表上要允许「安装未知应用」，并且授权对象是**你用来点安装的那个应用**（文件管理器或浏览器）。没开的时候点安装要么没反应，要么弹「已阻止安装」。用 ADB 装的话，还要在开发者选项里打开「通过 USB 安装」这类开关。
- **剩余空间**：包本身不到 19 MB，加上安装后的运行数据，建议手表剩余空间留 100 MB 以上，避免装到一半失败。

## 五、第一次打开会看到什么

1. 启动后先出现登录页，这一步可以跳过 —— 不登录也能浏览推荐和搜索，跟账号绑定的内容要登录后才出现，具体见 [登录与账号同步.md](登录与账号同步.md)；
2. 确认手表已经连上网络：没网时界面会一直停在加载状态，那不是卡死；
3. 首页给的是推荐／热门列表，向下滑动浏览；部分支持旋转表冠的机型，转动表冠也能滚动列表。

安装过程报错、或者装好之后打不开，分别对照 [手表上装不上怎么排查.md](手表上装不上怎么排查.md) 与 [常见问题与排查.md](常见问题与排查.md)。
