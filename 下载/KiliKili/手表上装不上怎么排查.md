## 一、先按提示对号入座

| 手表上的提示 | 多半是 | 看哪一节 |
| --- | --- | --- |
| 与您的设备不兼容 / 无法安装此应用 | 架构或系统版本不满足 | 第二节、第三节 |
| 解析软件包时出现问题 | 文件没下完整 | 第四节 |
| 应用未安装 / 存在同名的已安装应用 | 签名冲突 | 第五节 |
| 已阻止安装，或者点了完全没反应 | 未知来源权限没开 | 第六节 |
| 存储空间不足 | 空间不够 | 第七节 |

## 二、架构不匹配

这份 0.3.2 的安装包里只有 `armeabi-v7a`（32 位 ARM）的原生库，能不能装取决于手表是否还兼容 32 位应用。用 ADB 查一下最准：

```bash
adb shell getprop ro.product.cpu.abilist
```

- 输出里出现 `armeabi-v7a` 或 `armeabi` → 能跑 32 位应用，这份包可以装；
- 输出只有 `arm64-v8a` 一个值 → 这台设备只跑 64 位应用，这份包装不上，换别的设备或者等带 64 位库的版本。

只知道自己手表是 64 位处理器不代表装不了 —— 关键看系统还留不留 32 位兼容，上面这条命令给的才是最终答案。

## 三、系统版本不够

这份包要求 Android 5.0（API 21）及以上。手表没开 ADB 时，在「设置 → 关于」里能直接看到系统版本；开了 ADB 的话：

```bash
adb shell getprop ro.build.version.release
adb shell getprop ro.build.version.sdk
```

`ro.build.version.sdk` 小于 21 就装不上，这一条没有绕开的办法。

## 四、包没下完整

手表或网盘客户端把没下完的临时文件当成品留在本地，是「解析软件包时出现问题」最常见的原因。核对长度：

- 正确大小是 18.96 MB（19,885,627 字节）；
- 在电脑上算一遍 MD5 更稳：

```powershell
certutil -hashfile "KiliKili_v0.3.2.apk" MD5
```

比对上 `BD559E6837E616CE7A5022F70622417B` 说明文件是完整的；对不上就重新下一份，仍然从 **KiliKili 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/37157b70cd7b](https://pan.quark.cn/s/37157b70cd7b) 获取。

## 五、签名冲突

同一个包名在同一台设备上只能存在一份，且必须同签名。以前装过别的来源的同包名版本时，新包会被系统拒绝覆盖，提示通常是「应用未安装」。

处理顺序：

1. 卸载旧版（设置 → 应用 → 找到 KiliKili → 卸载）；
2. 再装这一份包；
3. 记住卸载会一并清掉本地设置与登录状态，装好后要重新扫码登录，步骤见 [登录与账号同步.md](登录与账号同步.md)。

不要用第三方工具「保留数据强装」，签名不一致时它能装上去，但应用随时会异常。

## 六、未知来源权限被挡

用文件管理器安装时，要授权的是**文件管理器**这个应用，而不是 KiliKili：

设置 → 应用 → 特殊应用权限 → 安装未知应用 → 选中你点安装用的那个应用 → 允许。

用 ADB 安装被挡时，另外确认开发者选项里的「通过 USB 安装」「ADB 安装应用」是打开的。如果连 `adb devices` 都看不到手表，那还没进到安装这一步，先看 [手表无线调试连不上怎么排查.md](手表无线调试连不上怎么排查.md)。

## 七、空间不够

包 18.96 MB，安装后再算上运行数据，总量通常是几十 MB。手表剩余空间建议不少于 100 MB，查看位置在「设置 → 存储」。空间紧张时先删掉用不到的表盘和离线音乐再装。

## 八、用 ADB 安装时的报错码怎么读

命令行给出的报错码比表盘上的中文提示更精确，直接按这张表对上原因：

| adb 报错 | 对应原因 | 看哪一节 |
| --- | --- | --- |
| `INSTALL_FAILED_DEPRECATED_SDK_VERSION` / `INSTALL_FAILED_OLDER_SDK` | 系统版本低于这份包的下限 | 第三节 |
| `INSTALL_FAILED_NO_MATCHING_ABIS` | 手表不兼容这个架构 | 第二节 |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` / `INSTALL_PARSE_FAILED_INCONSISTENT_CERTIFICATES` | 已装的同包名版本签名不一致 | 第五节 |
| `INSTALL_FAILED_INSUFFICIENT_STORAGE` | 空间不足 | 第七节 |
| `INSTALL_PARSE_FAILED_...` 一类解析失败 | 安装包本身不完整 | 第四节 |

## 九、装上了但一打开就退

这已经不是安装环节的问题了：先按 [常见问题与排查.md](常见问题与排查.md) 里的闪退处理顺序走一遍（清缓存、重启手表、重装）。如果是纯 64 位设备，第二节已经说明这份包装不上，也不需要再试其他安装途径。
