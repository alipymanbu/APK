## 一、不登录能用多少

首页推荐、热门、搜索、排行榜这类公开内容，不登录也能浏览。收藏夹、追番、观看历史、关注 UP 主的动态这些是账号维度里的数据，登录之后才会出现。

能看什么内容取决于你自己的 B 站账号权限：大会员内容仍然要有大会员，这份客户端不会改变账号本身的权限范围。

## 二、扫码登录的步骤

1. 在手表上打开登录页（入口一般在首页或设置里）；
2. 页面显示一个二维码；
3. 用手机上的 B 站客户端扫这个二维码；
4. 在手机上点「确认登录」；
5. 回到手表，确认已经进入登录状态（首页出现关注动态、头像等）。

手表屏幕小，二维码有时显示不全：把手表亮度调高一档，手机摄像头靠近、对准再扫；扫不出来就退出登录页重新进一次，二维码本身也有有效期。

## 三、登录之后，手表和手机是什么关系

- 账号数据都在 B 站服务端，手表端登录后看到的是同一份收藏、追番与观看历史，不是各存一份；
- 手表上做的关注、收藏、点赞会写回账号，手机端刷新后能看到；
- 两边的显示偶尔会有一小段时间差，取决于各自的刷新时机，不等于数据丢了。

## 四、退出登录与本地数据

| 操作 | 结果 |
| --- | --- |
| 应用内退出登录 | 回到未登录状态，账号相关数据失效，应用本身与设置项还在 |
| 找不到退出入口，只想断开账号 | 在系统里对这个应用执行「清除数据」，账号状态一定被清掉；代价是界面与播放器偏好一起重置（见下一行） |
| 系统里「清除数据」 | 本地设置（界面、播放器偏好）与登录状态一起重置 |
| 卸载后重装 | 同「清除数据」 |
| 覆盖安装（`adb install -r`） | 保留数据，前提是签名一致，见 [手表上装不上怎么排查.md](手表上装不上怎么排查.md) 第五节 |

## 五、登录之前值得想一下的事

- 登录等于把这个账号的登录态交给这个应用；
- 这个项目在 GitHub 上开源（GPL-3.0），代码可以自己看，但「开源」不等于「你该用主力账号登录」—— 介意的话用小号，或者干脆不登录只看公开内容；
- 装包只从你信任的来源拿。同一个应用名在不同站点可能是不同的包，先按 [同名应用与版本怎么认.md](同名应用与版本怎么认.md) 里的办法核对包名和 MD5，再考虑登录；
- 如果账号出现异常提示，先用官方客户端登录一次，确认是账号本身的问题还是这个客户端的问题。

## 六、扫码没反应时怎么排查

| 现象 | 先试这个 |
| --- | --- |
| 二维码一直转不出来 | 确认手表网络可用，退出登录页重进 |
| 手机扫了，手表没变化 | 检查手机上是否真的点了「确认登录」，再等几秒刷新 |
| 登录完仍显示未登录 | 退出应用重进；仍不行就重新扫一次 |
| 反复失败 | 先在官方客户端确认账号能正常登录，再回来试 |
| 换过安装包来源后登录异常 | 大概率是签名/版本变了，按 [手表上装不上怎么排查.md](手表上装不上怎么排查.md) 第五节处理 |
