## 一、打开就闪退，或者停在启动界面

按这个顺序试，前面能解决就不用往后走：

1. 确认系统版本达标：Android 5.0 及以上，见 [下载与安装教程.md](下载与安装教程.md) 第一节；
2. 清一次应用数据：设置 → 应用 → KiliKili → 存储 → 清除缓存（仍有问题再清数据，清数据会丢登录态与本地设置）；
3. 重启手表，再打开；
4. 重装这一版：保留数据用 `adb install -r`，彻底重来就先卸载再装（见 [手表上装不上怎么排查.md](手表上装不上怎么排查.md) 第五节）。命令本身连不上手表的话，看 [手表无线调试连不上怎么排查.md](手表无线调试连不上怎么排查.md)。

## 二、装完在应用列表里找不到图标

装的过程没报错，但手表应用列表里翻不到，通常是这两件事：

- **装到了别的设备上**：如果电脑上同时连着手机和手表，`adb install` 会打到默认那台上。先 `adb devices` 看列表，多台设备时用 `adb -s 192.168.1.23:5555 install -r "包名"` 显式指定手表；
- **列表缓存没刷新**：重启一次手表，再看应用列表。

如果手表上确实装了、但点开图标没反应，回到第一节按闪退的顺序处理。

## 三、首页一直转圈，什么也刷不出来

- 先用系统浏览器打开任意一个网页，确认手表真的能上网；
- 换网络再试（Wi-Fi 与 eSIM／手机共享网络互换）；
- 如果**所有网络下都转圈**，而同一账号在手机端一切正常，那多半是服务端接口层面发生了变化 —— 这类客户端要靠自身更新去适配接口，重装和清数据都不会解决，等新版本即可；
- 只是偶尔转圈、过一会儿自己好了，属于网络抖动，不用处理。

## 四、能进界面，但视频播不了

- **只有某个视频不行，别的好好的**：多半是这个视频本身的清晰度或权限限制，换一个视频验证即可；
- **全部视频都不行**：先按 [播放卡顿与耗电怎么调.md](播放卡顿与耗电怎么调.md) 第二节把清晰度降到最低档再试一遍；
- **有画面没声音**：检查手表是否处于静音、是不是误连了蓝牙耳机或音箱（声音跑到那边去了）；
- **画面卡住、声音还在继续**：回到播放卡顿那篇的第二节，从降清晰度开始调。

## 五、登录相关的问题

二维码扫不出来、扫了没反应、登录后仍显示未登录，逐条对照 [登录与账号同步.md](登录与账号同步.md) 第六节的现象表。

## 六、怎么知道有新版本

- 版本号会带一段 8 位提交号，新版本发布时这段号会变（例如 `0.3.2+xxxxxxx`）；
- 发布记录与更新说明看项目的 GitHub 仓库：[Re-BiliTerminal/BiliZepam-Compose](https://github.com/Re-BiliTerminal/BiliZepam-Compose) 的 Releases 页，具体版本号以页面当时显示的为准；
- 更新方式：用 `adb install -r` 覆盖安装；换了来源的包会因签名不一致装不上，那就只能先卸载再装（会清数据）。

## 七、反馈问题时要带上什么

项目的 Issues 是它收集问题的入口。提问前先把这几项准备好，缺了基本没法定位：

- 手表型号；
- 系统版本；
- 当前的 KiliKili 版本号；
- 复现步骤，以及能体现问题的截图或录屏。

这三条命令可以一次把机型、系统版本、版本号取全：

```bash
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release
adb shell dumpsys package com.huanli233.bilizepam.compose | findstr versionName
```

## 八、卸载之前要先知道的事

卸载或者在系统里「清除数据」，会一并清掉本地设置与登录状态，重新装好之后需要重新扫码登录；网盘里的安装包不受影响，随时可以再装回来。
