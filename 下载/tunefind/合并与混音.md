# tunefind 合并与混音操作指南

> 合并和混音是两件不同的事：合并是把几段音频首尾拼成一条，混音是把两段叠在一起同时播放。本篇分别讲怎么做，以及衔接处的处理。

## 一、先分清「合并」和「混音」

- **合并**：A 放完接 B，时间上是排队的。典型用途：把几段录音拼成一条、串烧、把剪好的多段素材连起来。
- **混音**：A 和 B 同时响。典型用途：人声配伴奏、给干音垫背景音乐。

两种操作在 tunefind 里是不同入口，动手之前先想清楚你要的是哪一种，选错了入口做出来的效果完全不对。

## 二、合并：几段拼成一条

1. 在功能列表里选「合并」，把要拼接的音频**按顺序**加进来；
2. 调整顺序——合并结果严格按列表顺序排，加错了顺序就拖动重排，别指望导出后再挪；
3. 需要过渡的两段之间，分别给前段加淡出、后段加淡入（做法见[音频剪切与淡入淡出.md](音频剪切与淡入淡出.md)第三节），接缝会顺很多；
4. 试听整条，重点听接缝处有没有爆音或突然的音量跳变；
5. 保存导出。

### 合并前建议先统一格式

两段比特率、采样率差别很大的音频直接拼，接缝处可能出现一小段杂音。稳妥的做法是先把格式统一（比如都转成 MP3），转换方法在[格式转换与人声分离.md](格式转换与人声分离.md)，再回来合并。

## 三、混音：两段叠在一起播

1. 选「混音」功能，分别指定主轨和叠加轨——比如主轨放你录的人声，叠加轨放背景音乐；
2. **调两轨的音量比例**，这是混音成败的关键：背景音乐压到人声的一半以下，人声才听得清；反过来做纯背景乐就把主轨压低；
3. 试听时挑人声最轻的那几句听——背景乐有没有盖住人声，轻的地方最容易暴露；
4. 保存导出。

如果主轨是现场录的干音，先做一遍降噪（方法见[格式转换与人声分离.md](格式转换与人声分离.md)）再混，成品会干净不少。

## 四、导出之后

- 导出的文件在哪个目录、找不到文件怎么办，见[常见问题排查.md](常见问题排查.md)；
- 拼好的成品想留几个不同版本对比，导出时换文件名即可，覆盖保存会把上一版顶掉。
