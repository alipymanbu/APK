## 一、安装前先确认三件事

1. **系统版本**：安卓 5.2 及以上。低于这个版本，系统会直接提示「无法解析安装包」，装不上。
2. **存储空间**：安装包约 58.76M，剪辑过程还会产生缓存和导出文件，建议手机再留出 1GB 左右的空闲空间。
3. **认清你要装的是哪个 tunefind**：搜索「tunefind」时排在前面的多是同名的国外网站 `tunefind.com`（一个查影视配乐的网站，官方帮助中心明确说明它没有 App）。你要装的是一款安卓端的音频编辑工具，中文名在应用商店里写作「tunefind音乐」或「tunefind音乐剪辑」，安装包核对信息见下一节。

## 二、拿到安装文件并核对

安装文件资源在上面头部的夸克网盘链接里。要点是**先转存到自己网盘、再下载到手机**，转存和下载的完整步骤（含手机 / 电脑两条路、失败提示对照）单独写在[夸克网盘转存与下载.md](夸克网盘转存与下载.md)里。下载完成后核对一下拿到的是不是这一版：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.1 |
| 包名 | com.tunefind.ljhsafa |
| 安装包大小 | 58.76M |
| MD5 | 666CEF7C7C9947938ABAA94BD16C6DFB |

版本号、包名、体积都以这份本地采集信息为准——网上能搜到的「最新版」和网盘里这份不一定是同一版。

MD5 的核对在电脑上最快：把 APK 传到电脑，在那个目录下打开 PowerShell 执行：

```powershell
certutil -hashfile "tunefind_v1.1.apk" MD5
```

（文件名以你实际下载到的为准。）输出的哈希值与上表一致就是原包；对不上就重新下载一次，装一个来源不明的包不值得。不想动电脑的话，部分手机文件管理器也内置「文件校验 / MD5」功能，长按文件就能找到。

## 三、安装步骤（含「未知来源」放行）

从网盘装的 APK 不经过应用商店，安卓默认会拦一道，这是正常现象：

1. 在文件管理器里点开刚下载的 APK；
2. 系统弹出「为了您的安全，已禁止安装未知来源应用」→ 点「设置」→ 打开**允许此来源安装**（有的品牌叫「安装未知应用」）→ 返回；
3. 点「安装」，等进度走完 → 点「打开」或「完成」。

各品牌入口略有差异，找不到时去 **设置 → 应用管理 → 特殊权限 → 安装未知应用**，给你用的那个文件管理器放行即可。装完建议把刚才的放行开关关回去，减少误装风险。

## 四、第一次启动要给的权限

tunefind 首次启动会陆续要几个权限，作用和给不给如下：

| 权限 | 用在哪 | 建议 |
| --- | --- | --- |
| 存储 / 音频文件 | 读取手机里的音乐、保存剪好的文件 | **必须给**，不给无法选文件也无法导出 |
| 麦克风 | 用录音功能时才需要 | 不用录音可以拒绝，之后要用再补开 |
| 通知 | 导出完成、任务结束的提醒 | 可给可不给，不影响剪辑本身 |

权限当时手快点错了也没关系：**设置 → 应用管理 → tunefind → 权限**，逐项改回来就行。

## 五、装好之后

装完打开，主界面里选一个音频文件就能进波形编辑。接下来按你想做的事跳转：想剪一段做铃声看[音频剪切与淡入淡出.md](音频剪切与淡入淡出.md)，想把几段拼成一条看[合并与混音.md](合并与混音.md)，要转格式或分人声看[格式转换与人声分离.md](格式转换与人声分离.md)。
