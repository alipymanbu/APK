> 拿到一条夸克网盘分享链接（形如 `pan.quark.cn/s/xxxx`）之后，怎么把它变成手机里的文件：转存、找到转存结果、下载到本地，以及链接失效、容量不足这几个拦路情况的处置。

## 一、为什么要先「转存」而不是直接下载

分享链接里的文件不属于你。直接在线预览或临时下载都可能受限，而且原分享一旦被取消，你手里就没有任何副本。**先转存到自己网盘，再从自己的网盘下载**，是稳妥的两步走：转存完成后，这份文件就进了你的账号，跟原分享的存亡无关了。

## 二、手机上操作（App / 浏览器）

1. 点开 tunefind 安装文件资源的分享链接；
2. 页面提示登录时，用一个夸克账号登录（没注册过就用手机号现场注册一个，免费）；
3. 勾选文件 → 点 **保存到我的网盘**（有的版本叫「转存」）→ 选一个保存位置 → 确认；
4. 打开夸克 App 底部的 **网盘 → 我的文件**，进入刚才选的位置就能看到它；
5. 点文件旁的 **下载**，选好存储路径，等进度条走完，文件就落在手机本地了。

如果页面要求输入提取码，填分享方给你的那串再继续；没给过提取码的链接会直接进到文件列表。

## 三、电脑上操作

电脑端有两条等价的路：

- **网页版**：浏览器打开 `https://pan.quark.cn` 并登录 → 点开分享链接 → 转存 → 在「我的文件」里勾选 → 下载；
- **客户端**：装夸克网盘的 Windows 客户端，登录后操作一样，大文件下载比网页稳。

APK 这类几十 MB 的文件，网页版完全够用。

## 四、转存 / 下载失败对号入座

| 提示 / 现象 | 原因与处理 |
| --- | --- |
| 「分享已取消」或「文件不存在」 | 原分享失效了，链接救不回来，只能找分享方重新给一条 |
| 转存时提示空间不足 | 你的网盘容量满了，删掉不要的旧文件再转存；APK 约 58.76M，留出这个量级的空间就够 |
| 下载到一半失败 | 换网络（移动数据 ↔ Wi-Fi）重试；电脑端换客户端下通常更稳 |
| 找不到转存到哪了 | 在 App 网盘页顶部用搜索框输文件名，或按时间排序看最新文件 |

转存、下载都搞定了，接下来装到手机上的步骤见[下载与安装教程.md](下载与安装教程.md)；装不上、装完打不开之类的问题去[常见问题排查.md](常见问题排查.md)。
