## 一、安装前先核对这几项

Cyberchat 是一款安卓端的 AI 虚拟角色聊天应用：注册后可以和预设的 AI 角色对话，也可以自己创建角色。你手里这份安装包的基本信息如下：

| 项目 | 数值 |
| --- | --- |
| 应用名称 | Cyberchat（cyberchat） |
| 版本 | 1.0 |
| 包名 | `com.cyberchat.www` |
| 安装包大小 | 0.14 MB |
| MD5 | `EFF5E5D67F00F247C4B06393F0F7D119` |
| 适用系统 | 安卓手机（采集记录标注为安卓 5.2 以上） |

安装包只有 0.14 MB，对手机配置几乎没要求，下载和安装都很快。想核对文件是否完整，可以用电脑端的校验工具对 APK 算一次 MD5，与表中对照。另外，App **需要联网**才能用（对话在云端完成），第三方页面同时标注了它无广告弹窗。

## 二、从网盘把安装文件拿到手

[Cyberchat 安装文件资源（夸克网盘）](https://pan.quark.cn/s/391bbe04c1de)里就是这份 APK。打开链接需要登录夸克账号（没有就现场注册一个），然后三步：

1. 打开链接，先把资源转存到自己的夸克网盘（转存后下载更稳）；
2. 从网盘下载，得到 `cyberchat_v1.0.apk`（以网盘内实际文件名为准）；
3. 按下一节开始安装。

## 三、安装步骤

1. 在文件管理器里点开下载好的 APK；
2. 首次安装安卓会提示「未知来源应用」，按提示允许浏览器或文件管理器安装应用（各品牌叫法不同：小米是「特殊应用权限」，OPPO/vivo 在安装时直接弹窗勾选）；
3. 等进度条走完，点「打开」直接进入，或回桌面点图标进入。

## 四、装不上 / 打不开，按这个顺序排查

| 现象 | 先做什么 |
| --- | --- |
| 提示「解析包出错」 | 多半是下载不完整，回网盘重新下载一次再装 |
| 安装按钮一直灰着 | 关掉手机上正在跑的安装类工具，重启手机再试 |
| 提示与已装应用冲突 | 说明手机里已经装过同包名但签名不同的版本，先卸载旧的再装这份 |
| 能装但一打开就闪退 | 检查网络连接，切换 Wi-Fi / 流量再试 |
| 存储空间不足 | 0.14 MB 的包本身不占地方，清的是系统缓存和运行空间 |

装好后的第一件事是注册账号，流程见[注册与登录指南.md](注册与登录指南.md)。

## 五、注意：网上的介绍可能对应另一个构建

网上第三方下载站里的 Cyberchat 介绍与截图，多数标注为 v1.0.0、包名 `com.cyberchat.ai`、体积 3 MB 以上 —— 那是另一个构建，和你手里这份（版本 1.0、包名 `com.cyberchat.www`、0.14 MB）**不是同一个包**。玩法与功能的介绍可以互相参考，但版本号、包名、体积一律以你手里这份安装包为准。

另外有第三方页面给出官网地址 `https://cyberchat.vip`，是否仍在维护、是否官方渠道无法核实，仅供参考；注册与使用都在 App 内完成，一般用不到它。
