## 一、为什么打开是空的

喵影视TV 属于「壳 + 配置地址」这类应用：安装包里本身不带片源列表，片源来自你填进去的一个**配置地址**（一个指向 json 或 txt 文件的网络链接）。没填地址时，首页可能空白、或提示「拉取失败 / 提取失败」——这属于正常状态，不是安装包坏了。取消那个提示就能进设置界面。

## 二、填配置地址的完整路径

用遥控器一步步走：

1. 进入应用后打开 **设置**（有的版本是首页顶部的齿轮图标）；
2. 选择 **设置其他**；
3. 点 **配置地址**；
4. 在输入框里粘贴你的配置地址，点 **确定**；
5. 返回首页，等几秒让数据加载——加载成功后首页会换上片源内容，设置里的「首页数据源」也会多出可选项。

地址输入用的是遥控器逐字输入会很痛苦，多数版本支持**扫码上传**：设置界面会显示一个二维码，用手机扫码后在手机上粘贴地址提交，比遥控器敲字快得多。

## 三、配置地址要满足什么

不是随便一个网页链接都行，合格的地址长这样：

- 直接指向一个 **`.json` 或 `.txt` 文件**，打开它能在浏览器里看到代码文本，而不是一篇图文介绍页；
- 是**原始数据地址**：在 Gitee、GitHub、Pastebin 这类站点上，要点「原始数据 / Raw / raw」之后再复制浏览器地址栏的链接，直接复制预览页地址会加载失败；
- 开头是 `http://` 或 `https://`，前后**没有空格、没有换行**——多一个空格就会报「加载配置文件失败」；
- 地址在浏览器里能打开、能看到内容，再填进应用。

配置地址的公开列表网上有很多（搜索「喵影视TV 配置地址」「TVBox 接口」都能找到），但这类地址的存活时间取决于维护者，**本篇不写死某个具体地址**——写进来大概率过几个月就失效了。你拿到的地址是否还能用，用上面三条自测一遍即可。

## 四、加载失败怎么排查

按出现频率排：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「加载配置文件失败」 | 地址前后有空格或换行 | 重新粘贴，删干净首尾字符再确定 |
| 提示失败，地址看着没问题 | 复制的是预览页而非原始数据地址 | 回网页点「Raw / 原始数据」重复制 |
| 一直转圈，首页没变化 | 地址已失效 | 换一个还能在浏览器打开的地址 |
| 填了几次都没反应 | 输入框里有历史残留 | 全选清空输入框后重新粘贴 |

改完地址后回首页等几秒；还是不行就退出应用重进一次，让配置重新拉取。

## 五、切换线路与首页数据源

配置地址加载出来后，通常包含多组片源（首页数据源 / 线路）。切换方式各版本略有差别：

- **较新版本**：在首页或设置里点一下某个线路就直接切换，无需额外确认；
- **较旧版本**：要对着某个线路**按确认键选择「设为首页数据」**才算切换完成，光点进去浏览不算。

首页数据源只决定你打开应用时先看到哪一家的内容；**搜索时会跨全部数据源检索**，所以选哪个当首页不影响能不能搜到片（详见 [搜索与播放设置.md](搜索与播放设置.md)）。

## 六、本地接口模式

不想依赖网络地址，可以把配置文件放到设备本地用：

1. 先给应用开存储权限：设置 → 其他设置 → 获取存储权限；
2. 把接口文件夹放进设备内部存储的**根目录**（文件管理器里看到的最外层，路径形如 `emulated/0`）；
3. 回到「配置地址」，选择扫描二维码或从本地路径选择该文件确认。

本地模式的好处是不依赖对方服务器在线，代价是文件更新要你自己重新拷一遍。网络地址挂了的时候，这是一条现成的退路（见 [常见问题与解决方法.md](常见问题与解决方法.md) 里「接口失效」那条）。
