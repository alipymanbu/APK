## 一、先核对你手上这份是哪个版本

喵影视TV 是给智能电视、电视盒子用的安卓应用，界面按遥控器操作设计。各下载站给的版本号常年不一致（3.5.0、3.6.0、3.8.0 都有人在发），**你实际要装的以拿到手的这份安装包为准**，下面这张表是本篇依据的那一份：

| 项目 | 值 |
| --- | --- |
| 版本 | v3.1.0 |
| 包名 | `com.meowtv.live` |
| 安装包大小 | 15.46M |
| MD5 | `6C7E0EE05CBEB37B8341761D656C629D` |
| 保存日期 | 2026-09-23 |

**包名值得单独留意**：网上叫「喵影视TV」的安装包至少有 `com.meowtv.live`、`com.meowtv.lives`、`com.meowtv.box` 三种包名，它们不是同一个构建，体积也差很多（有的标 15M 上下，有的标 36M）。装完想确认装对没有，查包名最直接（见本篇第五节）。

系统要求各渠道标注不一，有标 Android 4.0 以上的，也有标 Android 5.2 以上的——实际以你的设备能不能正常安装、启动为准，装不上先看 [常见问题与解决方法.md](常见问题与解决方法.md)。

打开上面的分享链接，转存到自己的网盘后，把安装包下载到电脑或手机。下载完顺手核一下大小是否为 15.46M 左右——差得多说明拿的不是这份。需要更严格的校验，在 Windows 上可以这样算 MD5：


算出来的值与表格里的 `6C7E0EE05CBEB37B8341761D656C629D` 一致（不区分大小写），说明文件完整没下残。

## 三、用 U 盘装到电视（最通用的方式）

绝大多数电视和盒子没有浏览器可以直接装 APK，U 盘是成功率最高的路径：

1. 把下载好的 `.apk` 复制到 U 盘**根目录**（不要放进多层文件夹，也不要改文件名，保持 `.apk` 结尾）；
2. U 盘插到电视或盒子的 USB 口——优先插设备**机身自带**的口，插在延长底座上有时读不出来；
3. 电视上打开「文件管理 / U 盘管理 / 外接存储」，找到这个 apk，确认安装；
4. 安装过程中系统若弹「禁止安装来自此来源的应用」，按提示进入设置打开对应开关（见第四节），再返回继续；
5. 装完先别拔 U 盘，打开应用确认能进主界面，再拔。

## 四、打开「未知来源」安装权限

电视默认拦截 U 盘安装，需要你手动放行。不同品牌路径略有差别，常见三种：

| 设备 | 常见路径 |
| --- | --- |
| 小米 / Redmi 电视 | 设置 → 账号与安全 → 安全 → 允许安装未知应用 |
| 华为 / 荣耀智慧屏 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| 当贝盒子等盒子 | 设置 → 系统 → 安全 → 允许未知来源 |

放行的对象是**你用来打开安装包的那个应用**（文件管理器、当贝桌面等），不是全局开关——弹窗上写的是哪个应用，就给哪个应用开。

## 五、手机或盒子上直接装

如果盒子自带应用市场或文件管理，也可以不用 U 盘：把 apk 传进设备（通过盒子的「远程安装 / 投屏安装」功能，或手机与盒子在同一局域网内用文件传输工具投过去），再用设备上的文件管理器点开安装。这条路省了拔插 U 盘，但对不认 U 盘的设备更友好。

装完核对包名：在盒子的「设置 → 应用 → 已安装应用 → 喵影视TV」里查看应用信息，包名应显示为 `com.meowtv.live`。对不上说明装的是另一个分支，卸载后按第二节重新取包。

## 六、装好之后做什么

首次打开时主界面可能是空的，或提示拉取数据失败——这不是安装坏了，是这类应用需要你填一个配置地址才会有片源，做法见 [配置地址与线路切换.md](配置地址与线路切换.md)。配好之后怎么找片、怎么换线路，见 [搜索与播放设置.md](搜索与播放设置.md)。
