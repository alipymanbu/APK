## 一、板块都有哪些

论坛主页往下滑就是板块列表。按官方站点当时的公示，板块有这么几个（板块会增删调整，具体以首页当时显示为准）：

| 板块 | 里面是什么 |
| --- | --- |
| 手游 | 游戏资源帖最集中的板块，体量也最大（官方首页当时显示 8 万多个话题） |
| 实用软件 | 软件分享帖；板块规则写明优质帖子要通过审核 |
| 游戏许愿 | 发帖许愿想玩的游戏，官方会从这里挑游戏发布 |
| 谈天说地 | 日常聊天、闲聊灌水 |
| 逆向交流 | 技术向的资料与讨论帖 |
| GG 专区 | 只发与 GG 修改相关的内容 |

上表的数字只说明体量，不是实时值；真要确认，以你打开时首页显示的为准。

## 二、怎么逛

1. 首页往下滑，点进想看的板块；
2. 板块里是帖子列表，往下翻；首页的「最新帖子」能看到全论坛刚发布的内容；
3. 点进帖子看正文与回复，想回复要先登录（见[注册登录与发帖教程.md](注册登录与发帖教程.md)）；
4. 别人回复了你的帖子，登录后在「最新消息」里能看到。

## 三、游戏许愿怎么发

论坛里没有你想玩的游戏时，用许愿板块发帖：

1. 先登录账号 —— 许愿要发帖，必须有账号；
2. 进「游戏许愿」板块，点发帖；
3. 标题写清游戏名，正文里补上你想玩的平台（安卓或其他）；
4. 提交后等回复。按板块的说法，支持的人多了，游戏有被发布的可能；板块里另有一个「定制 MOD」的发帖入口，具体规则以板块内说明为准。

## 四、发帖的三条硬规矩

- **别发广告**：官方公示发现广告帖直接永久封号，正文和回复里塞引流链接一样算；
- **按板块发**：GG 相关发 GG 专区，软件帖发「实用软件」，聊天发「谈天说地」，串了版容易被删；
- **发完可能要等审核**：至少「实用软件」板块明确要过审，帖子没立刻出现先刷新看看，别重复发。

想找具体某款游戏的下载与更新方法，见[游戏怎么下载与更新.md](游戏怎么下载与更新.md)；页面刷不出来、发帖没反应这类故障，见[常见问题与排查.md](常见问题与排查.md)。
