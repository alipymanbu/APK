# 电视猫（云视听MoreTV）和电视节目单网站是一回事吗

> 搜"电视猫"或"tvmao"会同时撞到两个产品：一个是装在智能电视上的视频应用（云视听MoreTV），一个是查频道节目预告的网站（tvmao.com）。这篇帮你分清两者，并判断你该找哪个。

## 一、两个"电视猫"对照

中文名撞车了，但确实是两个不相干的产品：

| | 电视猫视频（云视听MoreTV） | 电视猫节目单网站 |
| --- | --- | --- |
| 是什么 | 智能电视 / 机顶盒上的影视应用 | 电视频道节目预告查询网站 |
| 在哪用 | 装在电视、盒子上，用遥控器操作 | 电脑或手机浏览器直接打开 |
| 入口 | 官网 `www.moretv.com.cn` | `www.tvmao.com` |
| 能干什么 | 看点播剧集电影、赛事与节目轮播 | 查各卫视/有线频道今天明天几点播什么 |
| 开发方 | 上海千杉网络（应用包署名常见广东南方新媒体） | 与前者无关联 |

这套文档讲的是**左边那个**——安装在电视上的视频应用。

## 二、为什么容易混

三个原因叠在一起：

1. 两者中文名都叫"电视猫"；
2. 这款应用在日常写作里也常被写成 **tvmao、TV猫**——正好和网站域名同名；
3. 搜索引擎对两个词不做区分，搜"电视猫 下载"既会给你应用的安装页，也会给你节目单网站。

所以如果你搜到的"电视猫"界面是密密麻麻的频道时间表，那不是本文说的应用——你到了节目单网站去了。

## 三、怎么判断你该找哪个

问自己一个问题：**你想干嘛？**

- 想在电视上看剧、看电影、看赛事轮播 → 你要的是**应用**，装到电视或盒子里，从[怎么安装到电视上](怎么安装到电视上.md)开始。
- 想知道中央一台今晚八点播什么、某部剧在哪个台重播 → 你要的是**节目单网站**，浏览器打开 `www.tvmao.com` 就行，不需要安装任何东西。

两件事也可能你都要：先在节目单网站查到"某剧 19:30 在某卫视播"，再用电视猫轮播或点播里找相关内容——它们功能互补，只是别在安装包里找节目表，也别指望网站能给你放视频。
