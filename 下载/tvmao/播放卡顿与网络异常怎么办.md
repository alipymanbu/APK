# 电视猫（云视听MoreTV）播放卡顿与网络异常怎么办

## 一、先对号入座

| 你遇到的现象 | 看哪一节 |
| --- | --- |
| 提示网络异常 / 加载速度 0kb/s / 服务器连接失败 | 第二节 |
| 卡顿、回播、跳播 | 第三节 |
| 有画面没声音、有声音没画面 | 第四节 |
| 黑屏、蓝屏 | 第五节 |
| 播放中自动退回详情页、数据获取失败、影片看一半没了 | 第六节 |

## 二、网络异常、加载 0kb/s、服务器连接失败

这三个现象官方归为同一类原因：**网络运营商服务不稳定**（多为瞬间异常）。按顺序做：

1. 检查电视上**其他软件**能不能正常联网。都不能 → 是网络本身的问题，换个时间再试或直接联系你的宽带运营商；
2. 其他软件正常 → 把**路由器和电视（盒子）都断电**，几分钟后重新通电开机再试；
3. 还不行 → 在电视（盒子）的网络设置里把 **DNS 改回默认，或改为 114.114.114.114**，改完拔电源重启设备再打开电视猫。

第三步是官方FAQ给的具体数值，DNS 改错会导致全网都打不开，改之前记一下原值。

## 三、卡顿、回播、跳播

官方口径：网络不稳定、设备性能不足时，**偶尔**出现这类现象属正常，不等于应用坏了。两个动作：

- 播放中按遥控器**菜单键**，手动把清晰度调低一档（这是官方FAQ点名的第一处置）；
- 清除电视猫的应用缓存、卸载掉不常用的软件给电视腾内存，然后断电重启设备。

反复卡顿、降清晰度也没用的，多半是带宽跟不上当前档位，见[常见问题排查](常见问题排查.md)第三节的网络自查顺序。

## 四、有画面没声音（或反过来）

音画不同步多发生在**播高清视频**时——设备性能或网速扛不住高画质。处置与卡顿相同：菜单键降清晰度，再清缓存、断电重启。

## 五、黑屏、蓝屏

先分清是**应用内**还是**整个电视**：

- **看视频时黑屏/蓝屏，退出应用后电视正常** → 处置应用：退出电视猫，清缓存，断电重启电视或盒子；
- **退出后整个电视蓝屏，任何软件都用不了** → 这是设备层的问题，联系电视或盒子厂商，和应用无关。

## 六、节目本身的异常

- **播放中自动退回详情页**：官方归因于节目源不稳定，重启 APP 或换个时间再看，同一部片过段时间可能就正常了；
- **影片看了一半，后面播不了**：官方口径是**节目资源已下线**，你能看到的那半可能是服务器缓存——这种情况没有修复办法，只能换片；
- **提示数据获取失败**：网络波动导致，重启 APP、换时间再试。

## 七、进度不记录，每次从头播

官方给的解法分两步：

1. **升级到最新版本**再试（升级路线见[版本更新与升级方法](版本更新与升级方法.md)）；
2. 已是最新版还这样 → **恢复出厂设置后重新安装**电视猫。恢复出厂会抹掉电视上的全部应用和数据，动手前把你电视上其他重要设置记一下，这是最重的一档操作，别一上来就用。

## 八、港澳台、海外 IP 看不了会员视频

官方明确：受版权限制，会员视频服务**只面向中国大陆**，用港澳台或海外 IP 访问会出现无法播放，官方建议海外用户谨慎购买会员。这是地区限制不是故障，国内网络环境回国访问则不受影响。会员相关的其他规则见[会员与账户登录](会员与账户登录.md)。
