## 一、这份应用申请了哪些权限

以下清单来自小米应用商店的权限公示（以你安装时系统实际弹出的为准）：

| 权限 | 说明 |
| --- | --- |
| 查看网络状态 | 判断当前网络是否可用 |
| 完全的互联网访问权限 | 联网同步数据的基础权限 |
| 读取/写入文件与文档 | 读写手机上的照片及文件 |
| 读取媒体图片 / 读取媒体视频 | 访问相册中的图片与视频 |
| 拍摄照片和视频 | 调用相机 |
| 录音 | 调用麦克风 |
| 控制媒体音量 | 调整媒体音量 |
| 修改系统设置项 | 允许应用修改系统设置 |

## 二、哪些必须给、哪些看用不用

- **联网**：账号数据同步的前提，要跨设备同步就得给。
- **通知**：不在上面的公示清单里，但到点提醒要能响，全靠系统通知权限——装完在「系统设置 → 通知」里把它打开。开了还不响的话，见[提醒到点不响怎么排查.md](提醒到点不响怎么排查.md)。
- **存储与媒体类**：在「往备忘录里插图、拍照」这类操作时才真正用到；平时只记账、设提醒的话可以不给。
- **相机与录音**：对应拍照、语音类功能，不用这些功能就保持关闭，不影响记账和提醒。

逐项开关的路径：系统「设置 → 应用 → Reminder随手备忘 → 权限管理」，每一项都可以单独设成「仅在使用中允许 / 每次询问 / 拒绝」。改完回到应用里点一下对应功能，验证还能不能用即可。

## 三、账号与数据同步

- 注册登录支持手机号绑定，账号是数据云端同步的载体；
- 应用内有数据同步与备份相关的设置项，入口在账号或设置页（以 1.0 版界面为准）；
- 换手机时在新设备上登录同一账号即可恢复数据，不需要手动搬文件。

## 四、两个注意点

1. **隐私政策**：官方隐私政策见 [remindnote.ai-solution.com.cn/privacy](https://remindnote.ai-solution.com.cn/privacy)，里面有官方对数据收集与使用的完整说明，介意数据去向的话先读它再决定要不要登录。
2. **维护状态**：开发者为济南明途网络科技有限公司；截至 2026-09，小米应用商店页面显示该应用处于「维护中」状态。对使用者的现实影响是：重要备忘不要只存在这一处，定期把关键内容复制导出或另存一份，比等一个不确定的更新实在。
