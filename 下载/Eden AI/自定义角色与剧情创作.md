## 一、两条创作路线

预设角色满足不了的时候，应用里有两条路可以自己动手：

- **捏角色**：定一套人物属性，得到一个专属的聊天对象；
- **建剧情**：用内置创作工具搭故事背景与角色，做成属于自己的互动剧情。

两条路不冲突——先捏好角色，再把它放进你的剧情里，就能组合出预设角色给不了的搭配。入口都在应用内的「创建」类功能区，具体位置随版本有调整，以应用内实际显示为准。

## 二、捏角色：可以调哪些属性

按应用市场页面的介绍，自定义角色可以设定的属性包括外貌、服装、职业、年龄这类基本项。实际操作时建议一次定齐，而不是边聊边改——人设中途大改，对话里已经形成的记忆和回应风格会跟新设定脱节。

几个实操建议：

- **性格与说话风格比外貌更影响体验**：外貌决定第一眼，说话方式决定你后面几百轮聊得下去聊不下去；
- **背景写具体**：职业、经历这类设定写得越具体，角色在对话里引用时越不容易前后矛盾；
- **改动从简**：先用最少的属性跑起来，哪里不满意再回来补哪一项。

## 三、自选 API 接口是怎么回事

应用介绍里提到，创建专属 AI 伴侣时可以自选 API 接口。对使用者的意义是：不同接口下，同一个角色的回复风格与质量会有差别。至于具体可选哪些接口、切换入口在设置里的哪个位置，公开资料没有给出完整清单，以应用内创建流程实际显示的选项为准——这一项不用提前纠结，进到创建页自然能看到。

## 四、建剧情：从背景到对话

剧情创作走的是另一条路：先搭世界观与故事背景，再把角色放进去。应用市场页面的说法是「从零开始自由构建专属的故事背景与角色」。如果你没有写作习惯，从这三个问题下手就够了：

1. 故事发生在哪（一个场景就够，不必宏大）；
2. 角色和你的关系是什么；
3. 你希望剧情往哪个方向走。

搭好之后进入对话，角色会在这个框架里和你推进情节。想看现成的剧情长什么样，回 [核心玩法与角色互动.md](核心玩法与角色互动.md) 看首页动线那部分。

## 五、角色的成长与记忆

自定义角色和预设角色一样带记忆机制，而且会随互动逐步适配你的聊天习惯。两点直接影响体验的预期：

- 新捏的角色初期表现平淡是正常的，记忆和默契靠对话轮次堆出来；
- 记忆跟着账号走，账号信息见 [注册登录与账号问题.md](注册登录与账号问题.md)，换设备登录后角色的「对你的了解」能否完整延续，以应用内实际表现为准。
