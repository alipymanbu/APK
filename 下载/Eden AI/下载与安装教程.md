## 一、先确认这份包的基本信息

Eden AI 是一款安卓端的 AI 虚拟角色聊天应用（中文名「伊甸园AI」），界面为简体中文。动手安装前，先对一下你要装的这份包的参数：

| 项目 | 数值 |
| --- | --- |
| 版本 | 1.22 |
| 安装包体积 | 16.95 MB |
| 包名 | `app.ydyai.top` |
| MD5 | `A4F79E4628313660A46ADA65FDDFF917` |
| 系统要求 | 安卓 5.2 及以上 |
| 信息核对日期 | 2026-09-23 |

版本号、体积这类信息会随官方更新变化，以上是本资源那份包的实际参数；想装更新的版本，以官方渠道当时发布的为准。

## 二、从夸克网盘拿到安装包

这款应用的安装文件资源放在夸克网盘里，获取分三步：

1. 打开上面的网盘链接，选中文件后点「保存到网盘」，把它转存到你自己的夸克账号里；
2. 转存完成后，打开夸克网盘 App（手机端或 PC 端都行），在你的网盘里找到刚才保存的 APK 文件；
3. 手机端直接点文件即可开始下载并进入安装；PC 端下载后把文件传到手机上再装。

如果你还没有夸克账号，注册一个即可，转存与下载都不需要付费。

## 三、安装步骤

1. 点开 APK 文件，系统会提示「是否允许安装」，首次安装时手机会拦一道；
2. 按「设置」进入该来源应用的安装权限页，打开「允许安装未知应用」的开关（安卓 8 及以上是按来源逐个授权的，只放行网盘这一个来源即可）；
3. 返回安装页，点「安装」，等待完成；
4. 装完点「打开」，或从桌面图标进入。

如果安装到一半提示「解析包错误」，多半是文件没下完整：核对一下文件体积是不是 16.95 MB（或用 MD5 工具比对上面那串值），对不上就删掉重下。

## 四、装不上时的对照排查

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 点安装没反应或闪退到桌面 | 安装来源权限没给 | 重新走一遍第三节的授权步骤 |
| 提示解析包错误/损坏 | 文件下载不完整 | 核对体积与 MD5 后重新下载 |
| 提示存储空间不足 | 手机剩余空间小于安装包加解压所需 | 清出至少几百 MB 再装 |
| 提示系统版本过低 | 安卓版本低于要求 | 该应用要求安卓 5.2 及以上，老设备先升级系统 |
| 能打开但用着闪退、卡顿 | 后台占用高或缓存堆积 | 清理后台应用；或在系统设置的「应用管理」里清除该应用的缓存（第三方使用指南页给出的口径，通用做法） |
| 首次启动弹出权限请求 | 应用申请存储与麦克风权限 | 见下一节说明，可自行决定是否授予 |

## 五、装好之后先做什么

首次进入应用需要用邮箱注册账号并登录，具体注册步骤、忘记密码怎么处理，见 [注册登录与账号问题.md](注册登录与账号问题.md)；登录完成后从首页挑一个剧情或角色开始对话，操作动线见 [核心玩法与角色互动.md](核心玩法与角色互动.md)。

另外提醒一句：如果你是从搜索引擎搜「Eden AI」进来的，先确认你要找的就是这款中文的角色聊天应用——这个名字下还有好几款完全不同的产品，辨别方法见 [同名应用辨别.md](同名应用辨别.md)。

## 六、首次启动的权限与检查更新

有第三方使用指南页提到，这款应用首次启动会请求**存储**和**麦克风**两项权限，用途分别是保存聊天记录与语音输入。权限请求是系统的常规提示，授予与否由你决定：不用语音功能的话，麦克风权限保持关闭也不影响文字聊天；存储权限则建议允许，否则聊天记录的本地保存可能受影响。

想确认自己装的是不是最新版本，该页面给出的检查入口在「我的 - 设置 - 关于」（菜单位置随版本可能有调整，以应用内实际显示为准）。本套文档资源里的版本是 1.22，装好后在关于页看一眼版本号即可对上。
