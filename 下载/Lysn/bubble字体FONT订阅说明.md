## 一、FONT 是什么

买了 bubble 订阅后，艺人消息默认用标准字体显示。FONT 是一层附加订阅：付了钱，这位艺人发来的消息会换成他/她的手写字体显示，观感上更像真人手写。几个边界要清楚：

- **只作用于消息显示**，不改变消息内容本身，也不影响回复功能。
- **不是所有艺人都有**：STORE 菜单横幅或艺人个人页里出现了 FONT 专属销售横幅的才有；没显示横幅的就是暂不提供。
- **语言限制**：官方 FAQ 口径支持韩语、英语与指定特殊符号；中文等其他语言的消息不套用手写体，仍按标准字体显示。

## 二、怎么买

前提：你已经订阅了这位艺人的 bubble。购买路径（官方 FAQ 口径）：

1. 应用内「更多(MORE)」→「STORE」。
2. 选中要买 FONT 的艺人（必须与已订阅 bubble 的艺人是同一位）。
3. 点该艺人页面里的 bubble FONT 横幅，按提示付款。

FONT 券是独立的月度订阅，从付款日起算一个月，到期通过应用市场（Google Play / App Store）自动续费；想停掉续订，要在续期日前 24 小时以上去应用市场的订阅管理里取消，应用内关不掉。

## 三、买了不生效的排查

按官方 FAQ 给的两条查：

| 检查项 | 说明 |
| --- | --- |
| 应用市场是否真的扣款成功 | 支付方式异常会导致实际没扣上，FONT 自然不生效 |
| FONT 的艺人与 bubble 订阅的艺人是否同一位 | FONT 只对已订阅 bubble 的同一位艺人生效，跨艺人无效 |

两项都正常仍不显示手写体，重启应用再看；确认用的是支持 FONT 的版本。

## 四、退订与退款的连带关系

FONT 与 bubble 券是两笔独立的订阅，处理时不自动联动，最容易在这里踩坑：

- **取消 bubble 订阅不会自动取消 FONT**，FONT 会继续按月扣款，要单独去应用市场退订（官方 FAQ 口径）。
- **申请退 bubble 券时，FONT 券不会跟着退**：网页商店条款写明，退 bubble 利用券后 FONT 即使还在期内也无法使用，退款要单独申请 FONT 那一份。
- 想连 FONT 一起退，就把两份券的退款申请分别提交，流程与 [bubble订阅价格与购买方式.md](bubble订阅价格与购买方式.md) 第四节一致。

## 五、要不要买

这条只给判断依据，不做推荐：FONT 的使用条件是「先订 bubble、再叠 FONT」，等于同一位艺人每月两笔钱；它改变的只有显示字体这一件事，消息内容、数量、回复规则都和标准订阅完全一样。STORE 里没挂横幅的艺人买不了，也没有免费试用的说法——付款前想清楚这一层就够了。
