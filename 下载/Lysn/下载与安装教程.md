## 一、安装前先确认三件事

1. **手机系统**：这是一款安卓应用，本篇安装包信息标注的系统要求为 Android 5.2 以上（以你实机的安装提示为准）。苹果手机要用 App Store 搜 Lysn，与本篇无关。
2. **存储空间**：本篇对应的安装包约 60M，再留出聊天图片视频的缓存空间，建议剩余空间 1G 以上。
3. **安装包版本**：本篇安装包的事实如下，网上应用市场搜到的可能是更新的版本，两者不冲突——你想跟着本篇的口径核对，就用这份表。

| 项目 | 值 |
| --- | --- |
| 版本 | 1.5.19 |
| 包名 | com.everysing.lysn |
| 安装包大小 | 60.49M |
| MD5 | 8F79587230EF1808232317F7FA71874E |

包名里的 `everysing` 是开发公司的前身名（EverySing，2020 年更名为 Dear U），属于正常现象，不是装错了包。

## 二、把安装包拿到手

安装包从 [Lysn 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b69de6354b66) 获取：打开链接转存到自己网盘，再从网盘客户端下载到手机存储。下载完成后先别急着点开，可以顺手做一次 MD5 校验（见下一节）。

## 三、安装步骤

1. 在手机文件管理里找到下载好的 APK 文件（文件名形如 `Lysn_v1.5.19.apk`，以你下载到的实际文件名为准），点它。
2. 系统弹出「未知来源/允许安装」提示时，允许本次安装；部分机型要在 设置 → 安全 里先打开「允许安装未知来源应用」。
3. 等安装进度走完，点「打开」。
4. 想核对包有没有下坏，可以在电脑上对文件算一次 MD5：

```powershell
certutil -hashfile Lysn_v1.5.19.apk MD5
```

算出的值与第一节的 MD5 一致，说明文件完整；不一致就重新下载一遍再装。

## 四、装完第一次打开

1. **选语言**：首次启动会让你选界面语言，有简体中文可选，选完界面就是中文的。
2. **注册或登录**：没有账号就先注册一个，注册细节和收不到验证邮件的处理写在 [注册登录与语言设置.md](注册登录与语言设置.md)。
3. **权限**：应用会申请照片/视频权限（Android 13 及以上用于发送图片视频），麦克风、相机、通知属于可选权限，不给也能正常使用，只是发语音、拍照片、收推送这三类功能用不了。
4. **想收艺人的消息**：进入应用后要订阅对应艺人才会收到 bubble 消息，订阅渠道和价格见 [bubble订阅价格与购买方式.md](bubble订阅价格与购买方式.md)。

## 五、装不上或打开就闪退

- 提示「解析包出错/无法安装」：多半是安装包没下完整，回第二节重新下载并校验 MD5。
- 提示系统版本过低：确认手机 Android 版本是否达到第一节的要求，老机型换装旧版本无意义，建议换设备。
- 装好但闪退：清一下后台重新打开；还不行就卸载重装一次。
- 装好但收不到消息、通知不响：这些不属于安装问题，按 [收不到消息与通知排查.md](收不到消息与通知排查.md) 的顺序逐项检查。
