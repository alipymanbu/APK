## 一、装之前先核对这几件事

| 项目 | 内容 |
| --- | --- |
| 系统要求 | 安卓 5.0 及以上（以官方发布页标注为准） |
| 安装包大小 | 约 12.31 MB |
| 版本 | 1.4 |
| 包名 | `com.tharunbirla.fetchit` |
| 软件性质 | 开源软件（MIT 许可），源码见 GitHub 仓库 [github.com/tharunbirla/FetchIt](https://github.com/tharunbirla/FetchIt) |

FetchIt 不在 Google Play 上架，官方发布渠道是 F-Droid 与 GitHub Releases。如果你拿到的是第三方网盘或镜像站的包，核对下一节的 MD5 再装。

## 二、获取安装文件并核对 MD5

你可以直接取 **FetchIt 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/3d4d720cb7b3](https://pan.quark.cn/s/3d4d720cb7b3)，转存后下载 APK 到手机。

下载完成后建议核对一次 MD5，确认文件在传输中没有损坏：

| 校验方式 | 操作 |
| --- | --- |
| 电脑端 | 用校验工具（如 Windows 的 `certutil -hashfile 文件名 MD5`）算出 MD5 |
| 手机端 | 部分文件管理器自带"文件校验"功能 |

网盘这份 1.4 版安装包的 MD5 为 `5BC93DF13BF15812AAD696FF283ABBAB`（大小写不敏感）。算出来的值对不上，说明文件不完整，重新下载即可，不要强行安装。

## 三、允许"安装未知来源应用"

因为不是从应用商店装的，安卓会要求你单独授权。通用路径：

1. 打开系统**设置**；
2. 找到**应用**（或"应用管理"）；
3. 进入**特殊应用访问权限**（部分机型叫"更多设置"或"安装未知应用"）；
4. 选择**安装未知应用**；
5. 找到你用来打开 APK 的那个应用（浏览器、文件管理器、网盘客户端），允许它"安装未知应用"。

各厂商叫法略有差异：小米在"隐私保护"相关设置里，华为在"更多设置 → 安全"里，找不到就直接在设置里搜"未知"。

## 四、安装步骤

1. 在文件管理器里找到下载好的 APK；
2. 点它，系统弹出安装确认；
3. 点**安装**，等进度条走完；
4. 点**打开**直接进入，或回桌面找图标。

整个过程不需要注册账号，也不需要联网激活。

## 五、第一次打开要给的权限

| 权限 | 用途 | 不给的后果 |
| --- | --- | --- |
| 存储读写 | 保存下载下来的媒体文件 | 无法保存文件，下载必然失败 |
| 通知 | 在通知栏显示下载进度与状态（1.4 版起） | 进度只能回到应用内看 |

两个权限都可以事后在 **设置 → 应用 → FetchIt → 权限** 里修改。第一次下载文件时系统会再弹一次存储授权，选"允许"即可。

顺带说明版本差异：1.3 及更早版本申请的是"所有文件访问"这类大权限，1.4 起精简为按需的存储与通知权限——如果装旧版时见过夸张的权限提示，装 1.4 就不用在意了。

## 六、装不上时的对照表

| 现象 | 常见原因 | 处理办法 |
| --- | --- | --- |
| 提示"无法解析安装包" | 文件下载不完整或传输中损坏 | 重新下载，按第二节核对 MD5 |
| 提示签名冲突 / "存在同名应用" | 手机里装过其他渠道的同包名版本 | 先卸载旧版本再装（会清掉旧版数据） |
| 点安装没反应或按钮置灰 | 没有授予"安装未知应用"权限 | 回到第三节把来源应用授权 |
| 提示存储空间不足 | 剩余空间小于安装包所需 | 清理空间后重试 |
| 安装到一半卡住 | 系统安装器临时异常 | 重启手机后再装一次 |
