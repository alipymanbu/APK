## 一、为什么先查回收站

回收站里找回的是**原片原样还原**：画质不掉、不依赖 root、点一下就回来。而 DiskDigger 扫出来的（尤其没 root 时）多半是缩略图缓存，画质有损（见[没root能恢复什么.md](没root能恢复什么.md)）。所以合理的顺序是：**相册回收站 → 云端回收站 → 都落空了再开扫描**。多数「误删照片」停在第一步就解决了。

## 二、各家回收站入口与保留窗口

窗口期随时间与地区会变，下表是多个公开来源的口径，**以你机器上应用里当时显示的规则为准**：

| 入口 | 怎么找 | 保留时间（参考） |
| --- | --- | --- |
| Google 相册 | 底部「资料库」→ 回收站 | 已备份的照片约 60 天（多个来源一致）；未备份的本地文件保留更短，有说法称 30 天，以官方帮助页当时说明为准 |
| 三星相册 | 相册 → 菜单 → 回收站（没看到就在相册设置里开启） | 各来源说法在 15~30 天之间不一致，以机器上为准 |
| 小米相册 | 相册 → 回收站 | 以机型与系统版本为准 |
| OPPO / Realme 相册 | 照片 → 最近删除 | 以机型为准 |
| 一加 / 华为相册 | 收藏 → 最近删除 | 以机型为准 |
| Google 云端硬盘 | 左侧菜单 → 回收站 | 约 30 天（多个来源一致） |

## 三、云端别漏了

照片开了自动备份的，云端通常还留着副本：

- **厂商云**：三星云、小米云等，用手机账号登录后在相册同步里找「回收站 / 已删除」；也可以用电脑浏览器登网页端翻；
- **OneDrive / Google 云端硬盘**：有同步相册习惯的，去对应服务的网页端回收站看；
- **聊天软件里发过的图**：微信、WhatsApp 等会话里原图还在的话，重新保存一份比什么都快。

## 四、都落空了，再开扫描

回收站过了窗口期就是**永久删除**、云端也没有副本——这时候才轮到 DiskDigger，而且越早扫越好（删除后继续用手机会覆盖数据，见[恢复删除照片操作步骤.md](恢复删除照片操作步骤.md) 第一节）。扫描流程从那篇接着看；扫出来大量陌生小图、结果为空等问题，对照[常见问题排查.md](常见问题排查.md)。
