## 一、扫描前先做三件事

1. **立刻停手**：照片删了之后，继续拍照、录视频、下载文件都会往存储里写新数据，新数据可能把被删文件原来占的块盖掉——盖掉就真找不回来了。删完到开始扫，隔得越久、找回率越低。
2. **回忆一下文件原来在哪**：内置存储还是 SD 卡、大概在哪个目录。这决定你等下选哪个分区、也决定值不值得先拿读卡器插电脑（SD 卡的场景见[没root能恢复什么.md](没root能恢复什么.md) 最后一节）。
3. **装好应用**：安装与首次启动见[下载与安装教程.md](下载与安装教程.md)。

## 二、启动扫描

打开 DiskDigger，按设备状态选入口：

- **没 root 的手机**：点 `Start basic photo scan`，不用选分区，直接开始；
- **root 过的手机**：点 `Full scan` → 选分区（内置存储 `/data`、SD 卡 `/mnt/sdcard`）→ 弹出 Superuser 授权时点 `Allow` → 接着会问你要找哪些文件类型，**只勾你真正要的那几种**——勾得越多扫得越慢，官方明确建议按需勾选。

扫描开始后，主列表会一边扫一边把找到的可恢复文件填进来，不用等进度走完就能先看前面扫出来的结果。

## 三、扫描中怎么筛掉垃圾

列表里往往混着大量浏览器缓存、应用缩略图之类的杂图。点左上角的**齿轮图标（Options）**过滤：

| 过滤项 | 作用 |
| --- | --- |
| Minimum file size（最小文件大小） | 只显示超过指定字节数的文件。恢复照片时这个默认就是开的，目的正是滤掉缓存小图 |
| 文件类型 | 只显示某一类文件（如只看 JPG、只看视频） |

数值自己按需要调：想找大图就把最小值调高（比如 100KB 以上），想找连拍小图就调低或关掉。

## 四、勾选并恢复

1. 点文件左侧的**勾选框**批量选中；也可以点单个文件右上角的**三点菜单**，里面是只针对这一个文件的恢复选项；
2. 选完点顶部工具栏的**对勾按钮（Recover）**；
3. 接着选恢复到哪——三个去向的取舍见[恢复的文件保存到哪里.md](恢复的文件保存到哪里.md)。

恢复出来的图不清晰、或只找到视频的缩略图没找到视频本体，是没 root 的正常现象，原因和对策在[没root能恢复什么.md](没root能恢复什么.md)；扫描结果为空等问题见[常见问题排查.md](常见问题排查.md)。
