## 一、先看结论

只找回误删的照片 → 免费版够用；要恢复文档、音频、压缩包等其他类型，或要按文件类型恢复视频、用 FTP 上传导出 → 需要 Pro。但有一个前提先说清楚：**手机没 root 时，免费版和 Pro 的差距基本体现不出来**——两者都只能从缩略图缓存里捞图，详见[没root能恢复什么.md](没root能恢复什么.md)。功能差异对照如下（口径来自官方 [www.diskdigger.org](http://www.diskdigger.org) 的安卓版页面）：

| 能力 | 免费版 | Pro 版 |
| --- | --- | --- |
| 恢复照片 | 支持 | 支持 |
| 恢复视频 | 支持（需 root） | 支持（需 root） |
| 恢复其他类型（文档、音频、压缩包等） | 不支持 | 支持（需 root） |
| FTP 上传导出恢复的文件 | 不支持 | 支持 |
| 更高效地删除 / 擦除剩余空间里的文件 | 不支持 | 支持 |
| 非 root 设备上的实际效果 | 只有缩略图 | 只有缩略图 |

## 二、你手里这版是免费还是 Pro

网盘里的安装包（版本 1.0-2026-03-28，见[下载与安装教程.md](下载与安装教程.md)）装完是哪个版本，**以安装后界面上实际出现的功能为准**：启动后如果只有基础照片扫描、恢复时没有 FTP 上传选项，就是免费版。这里不替你断言，因为免费 / Pro 的差异是应用内购买解锁的，同一个 APK 装出来可能是不同状态。

## 三、升级前先确认两件事

1. **设备是否 root**：没 root 的机器，Pro 多出来的「恢复其他类型」全都要 root 才生效，不 root 买 Pro 也只多一个 FTP 导出；
2. **要恢复的东西是不是照片**：只是照片误删，免费版的扫描、筛选、导出流程完全一样（见[恢复删除照片操作步骤.md](恢复删除照片操作步骤.md)）。

价格与购买渠道随时间变化，以 Google Play 商品页当时显示为准。
