## 一、DiskDigger 是什么

DiskDigger 是 Defiant Technologies, LLC 出品的文件恢复工具，电脑端（Windows）和安卓端是两个独立的程序。本篇讲的是**安卓版**——你搜到官网 [www.diskdigger.org](http://www.diskdigger.org) 时会看到 Windows 版的介绍，别下错平台。安卓版的用途是：手机照片、视频误删后，把还能找回的文件扫出来、导出去。

本篇的信息以网盘里那份安装包为准（网上只有官方最新版，常常不是同一个）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0-2026-03-28 |
| 包名 | `com.defianttech.diskdigger` |
| 大小 | 5.41M |
| MD5 | `0FEB39B5F221FF4F2A997B901BFC8CA0` |
| 采集时间 | 2026-09-23 |

包名与 Google Play 商店里的一致（[play.google.com/store/apps/details?id=com.defianttech.diskdigger](https://play.google.com/store/apps/details?id=com.defianttech.diskdigger)），也就是说网盘这份和商店是同一个应用。版本号形如 `1.0-日期`，每次更新都改日期，你手里的这版是 2026-03-28 那版。

系统要求注意一个差异：官方页面写「兼容 Android 2.2 及以上」，而本地采集记录标注「需要安卓 5.2 以上」。装的时候以手机实际提示为准——装不上再看[常见问题排查.md](常见问题排查.md)。

## 二、拿安装包

1. 打开 [https://pan.quark.cn/s/64898963cf98](https://pan.quark.cn/s/64898963cf98)（DiskDigger 安装文件资源，夸克网盘分享链接）；
2. 转存到你自己的网盘，或直接在浏览器 / 夸克 App 里下载；
3. 下完核对文件名应为 `diskdigger_v1.0-2026-03-28.apk`，大小约 5.41M，对得上就没下错。

## 三、安装步骤

1. 把 APK 传到手机（数据线、网盘、微信文件传输均可）；
2. 点开文件开始安装。如果系统弹出「禁止安装未知来源应用」，点提示里的设置项，给当前安装来源（文件管理器或浏览器）打开「允许安装」，退回继续装；
3. 装完先别急着扫——先看下一节把扫描模式选对，模式选错会白扫一轮。

## 四、首次启动：两个入口怎么选

打开应用，主界面只有两个按钮：

- **Start basic photo scan**（基础照片扫描）：手机**没有 root** 就点这个，任何机器都能跑；
- **Full scan**（完整扫描）：**只有 root 过的设备才有**，点了会让你选要扫的分区（内置存储一般是 `/data`，SD 卡一般是 `/mnt/sdcard`）。

root 过的机器启动后可能弹出 Superuser 授权窗，点 **Allow**（允许）——点成 Deny 它就拿不到权限，什么都扫不出来。没 root 能扫到什么、root 后差多少，见[没root能恢复什么.md](没root能恢复什么.md)。

拿不准免费版和 Pro 版的功能边界，先看[免费版与Pro版区别.md](免费版与Pro版区别.md)；扫描、筛选、导出的完整流程见[恢复删除照片操作步骤.md](恢复删除照片操作步骤.md)。
