## 一、列表里一堆不认识的照片

那多半不是你的照片，是**浏览器缓存**（逛过的网页图片）和**社交应用缓存**（头像、资讯图、广告）。官方 FAQ 就是这么解释的。处理办法：打开齿轮图标（Options）把「Minimum file size」最小文件大小调高、或直接调低它显示的图片数量，大图基本就是你真正拍的那些（见[恢复删除照片操作步骤.md](恢复删除照片操作步骤.md) 第三节）。

## 二、恢复出来的照片模糊 / 只有视频缩略图

没 root 的正常现象：只能从缩略图缓存里捞，拿不到原片；视频同理，只找得到缩略图。这是产品限制，免费版 Pro 版一样。root 后用完整扫描、或把 SD 卡拔下来用读卡器接电脑扫，才有机会拿回原文件，细节见[没root能恢复什么.md](没root能恢复什么.md)。

## 三、恢复出来的文件打不开

典型原因是**文件被部分覆盖**：删除后又有新数据写进存储，原文件一部分块已经不在了，捞回来的就是残缺的。官方 FAQ 也明确说过——即使 root 了也不保证能恢复，文件可能已碎片化或被覆盖。判断与处理：

- 只有少数几个打不开、其余正常 → 就是这几个被覆盖了，放弃即可；
- 大面积打不开 → 扫描前是否继续重度用了手机（下载、拍照、录屏都算）；下次趁早，先看[扫描前先查相册回收站.md](扫描前先查相册回收站.md) 再尽快扫。

## 四、扫了好久结果是空的 / 少得可怜

按顺序排查：

1. **删除后是否继续用了手机**：每写入一批新数据就可能覆盖一块被删文件，删完越久、结果越少；
2. **是否选对了分区**：root 完整扫描时，内置存储选 `/data`、SD 卡选 `/mnt/sdcard`，选错盘自然扫空；
3. **文件类型是否勾窄了**：启动扫描时只勾了某一种类型，别种就不会出现在列表里；
4. **照片在 microSD 卡上**：这种场景官方建议拔卡接电脑用 Windows 版扫，比在手机里折腾有效；
5. 即便全做了也没结果，说明数据确实已被覆盖——**被覆盖的文件任何工具都恢复不了**，这是物理层面的限制。

## 五、扫描过程中存储显示 100% 占满

官方 FAQ 给过一个具体原因：如果你在 SuperSU（root 授权管理应用）里开了详细日志，扫描期间日志会疯狂写盘。去 SuperSU 的设置里把日志级别调到最低即可。

## 六、root 了但完整扫描用不了

依次确认：

- 设备**真的 root 成功**了吗（装个 root 检测应用看一眼）；
- Superuser 弹授权窗时是不是**误点了 Deny**——去 Superuser 管理里找到 DiskDigger 改成允许，再重开应用；
- 用的是不是 Magisk / SuperSU 之类的管理器且没给它 root 本身——管理器自己没权限也就弹不出授权窗。

## 七、安装与入口相关的疑问

装不上、找不到扫描按钮、想确认手里是哪版，归到[下载与安装教程.md](下载与安装教程.md)；免费 / Pro 功能边界造成的「按钮不见了」，对照[免费版与Pro版区别.md](免费版与Pro版区别.md)；恢复完保存报错、找不到落盘文件，见[恢复的文件保存到哪里.md](恢复的文件保存到哪里.md)。
