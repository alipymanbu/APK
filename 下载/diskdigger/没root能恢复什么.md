## 一、两种状态的差别

「root」就是给应用开管理级权限，让它能绕过安卓的目录隔离直接读整块存储。DiskDigger 的所有深度能力都建立在这上面：

| 状态 | 能用的扫描 | 实际能捞到什么 |
| --- | --- | --- |
| 没 root | 只有基础扫描（Basic scan） | 缩略图缓存里的图；仍留在文件系统上的视频 |
| 已 root | 基础 + 完整扫描（Full scan） | 按分区扫全盘，可按类型恢复照片、视频、文档等原始文件 |

没 root 时主界面上根本没有完整扫描入口，这不是坏了，是设计如此。

## 二、为什么恢复出来的照片是糊的

官方 FAQ 的解释：**没 root 时，DiskDigger 只能从缩略图缓存（thumbnail cache）里恢复图片**——那是系统看图时预先生成的小图，不是你拍的原片，所以放大后发糊、分辨率低。免费版、Pro 版都绕不开这个限制。想拿回全分辨率原片，只有两条路：

1. 手机 root 后用完整扫描，且原文件所在的块还没被新数据覆盖（**即使 root 了也不保证能恢复**——文件可能已经碎片化或被覆盖，官方明确说了这一点）；
2. 照片存在**外置 microSD 卡**上：把卡取出，用读卡器接到电脑，用 DiskDigger 的 Windows 版扫卡。这条路不依赖手机 root，官方 FAQ 点名推荐。

视频同理：只找到视频缩略图、找不到视频本体，就是没 root 在缓存里翻的结果（见[常见问题排查.md](常见问题排查.md)）。

## 三、要不要给手机 root

这是你自己的决定，只摆事实：

- root 后 DiskDigger 才会弹 Superuser 授权窗，点 `Allow` 才有完整扫描权限；点过一次 Deny 后它就一直没权限，可在 Superuser 管理里重新授权；
- 找 root 教程时**认准一条底线：root 过程不能清空设备存储**。任何要先「恢复出厂 / 双清」才能 root 的教程都会把你正要恢复的数据一次性抹掉，直接放弃；
- root 本身有风险与门槛（保修、部分银行应用、机型差异），官方 FAQ 也只给了通用指引，具体机型搜对应教程。

日常只是偶尔误删照片、能接受缩略图画质，不 root 也能用——照[恢复删除照片操作步骤.md](恢复删除照片操作步骤.md) 走基础扫描即可；介意画质或要恢复其他文件类型，再考虑 root 或换电脑端方案。
