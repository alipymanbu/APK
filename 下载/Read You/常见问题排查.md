# Read You 常见问题排查

## 一、添加订阅源时提示找不到

先分清手里拿的是不是 RSS 地址：

- 直接拿网站首页地址去订阅，很多站识别不出来 —— 要找的是站点专门提供的订阅地址（常见名字：RSS、Feed、订阅、`feed.xml`、`rss.xml`、`atom.xml`）；
- 找法：翻网站页脚的 RSS 链接；博客平台的站通常在域名后加 `/feed`；技术博客常在「关于 / 订阅」页面里给出；
- 还是不确定：用浏览器打开那个地址，能看到成片的 XML 代码才是有效 RSS；打开是普通网页或 404，就换地址。

## 二、文章不更新 / 同步不动

按顺序排查：

1. 先手动刷新一次，排除只是同步间隔还没到；
2. 本地账户：源站改版或 RSS 地址失效会导致长期无更新 —— 用浏览器打开该 RSS 地址确认还有新内容；
3. 云端账户：客户端只是从服务端拉数据，源站层面的问题要看服务端（如 FreshRSS 自建服务的网页端里该源是否正常）；
4. 定时同步本身不触发：是后台被系统限制，处理顺序见 [同步频率与文章通知](同步频率与文章通知.md) 第四节。

## 三、收不到更新通知

- 通知权限没开或被关了：系统设置 → 应用 → Read You → 通知；
- 同步没在跑：通知依附于同步，先按上一节把同步弄正常；
- 通知渠道被单独关了：系统的通知管理里按渠道逐个核对。

## 四、卸载重装 / 换渠道后数据没了

本地账户的订阅与文章存在手机本地，卸载即清空。两件事提前做：

- 卸载前先做备份：应用自带的 JSON 整包备份在 设置 → 故障排查 里，订阅清单再导一份 OPML 保底，完整流程见 [订阅数据备份与搬家](订阅数据备份与搬家.md)；
- 换渠道（F-Droid 版与其他渠道互转）必然要卸载重装 —— 这是签名机制决定的，详见 [下载与安装教程](下载与安装教程.md)。

重装后用 JSON / OPML 导入恢复；接了云端账户的话，订阅与已读状态在服务端，登录账户即可拉回来，不受卸载影响。

## 五、关于版本

- 网上搜到的「最新版本」与本文网盘资源里的版本可能不是同一个 —— 网盘里那份以资源页说明为准；
- 想追最新版：官方 GitHub 发布页（[github.com/ReadYouApp/ReadYou/releases](https://github.com/ReadYouApp/ReadYou/releases)）；
- 记住渠道签名规则：只在同一渠道内升级；跨渠道要先卸载，数据先备份。

## 六、仍未解决

官方仓库的 issue 区（[github.com/ReadYouApp/ReadYou/issues](https://github.com/ReadYouApp/ReadYou/issues)）可以搜别人报过的同类问题。开源应用更新节奏快，你手上的版本与资料描述有出入时，以应用内实际显示为准。
