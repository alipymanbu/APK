# Read You 同步频率与文章通知设置

## 一、同步是怎么回事

RSS 是「拉」模式：文章不会自己找上门，要由 Read You 去订阅源那里取。取的动作（同步）发生在三种时刻：

- 你打开应用下拉刷新或手动触发时；
- 应用按你设定的间隔在后台定时同步时；
- 接了云端账户时，由客户端向服务端拉取（源站更新由服务端负责抓）。

本地账户与云端账户的差别见 [云端账户与同步源配置](云端账户与同步源配置.md)。

## 二、把定时同步设起来

同步间隔的入口在不同版本里位置不同：先翻 设置 → 账户 里对应账户的设置，没有的话在设置的各分区里找同步相关项（以你手上的版本实际提供的选项为准）。按你对时效的要求定：

| 你看 RSS 的习惯 | 建议间隔 |
| --- | --- |
| 一天看一两次 | 默认或几小时一档即可 |
| 想第一时间看到更新 | 最短一档，并配合下面的通知与后台设置 |

间隔越短越耗电耗流量，按需取舍。

## 三、文章更新通知

- 首次启动时授权过通知权限，文章更新通知才能弹出来；
- 当时点了拒绝：到系统设置 → 应用 → Read You → 通知里打开；
- 通知出现后不想要了：关掉系统通知管理里对应的渠道即可，订阅与同步不受影响。

## 四、后台同步不生效的排查顺序

定时同步设了却不触发，多数是系统把后台活动拦了。按这个顺序查：

1. 系统设置里确认 Read You 的通知权限是开的（通知依赖同步先跑起来）；
2. 电池 / 省电策略：把 Read You 从「深度休眠 / 严格限制」名单里放出来，允许后台运行；
3. 国产 ROM 的自启动管理：允许自启动；
4. 以上都开了仍不触发：先手动刷新用着，并翻 [常见问题排查](常见问题排查.md)。

不同品牌的设置入口叫法不同（电池优化、省电策略、后台运行权限……），找不到就按你的手机品牌搜「应用后台运行 设置」。
