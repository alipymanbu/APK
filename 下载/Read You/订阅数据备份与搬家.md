## 一、两套备份机制，各管一件事

Read You 的数据备份有两条路，别混用：

| 机制 | 装的是什么 | 适用场景 |
| --- | --- | --- |
| OPML | 订阅清单（源地址与分组结构） | 换阅读器、换平台、分享订阅 |
| JSON | 应用内数据 | Read You 自己的备份与恢复，换手机 / 重装前整包备份 |

- **OPML** 是 RSS 圈的通用格式，几乎所有阅读器都认，但只包含订阅源，不包含已读状态、星标这类使用记录；
- **JSON** 是 Read You 自己的格式，别的阅读器不认。入口在 设置 → 故障排查 里（「从 JSON 导入」/「导出 JSON」，以实际版本显示为准）。

已读、星标这类记录不属于 OPML；纯本地使用时，它们只能指望应用自带的 JSON 备份（能恢复到什么程度以实际版本为准）。接了云端账户（FreshRSS 等）的话，已读状态在服务端，重装后登录即回 —— 配置见 [云端账户与同步源配置](云端账户与同步源配置.md)。

## 二、换手机 / 卸载重装的完整流程

1. 旧机上：设置 → 故障排查 → 导出 JSON，把文件传到新机（或经电脑 / 网盘中转）；
2. 再导出一份 OPML 保底：JSON 负责恢复应用内数据，OPML 是任何阅读器都能读的订阅清单；
3. 新机上装好 Read You（渠道怎么选见 [下载与安装教程](下载与安装教程.md)，注意跨渠道要先卸载的签名规则）；
4. 新机：设置 → 故障排查 → 从 JSON 导入，选中备份文件；
5. 导入后缺源的话，再用 OPML 补导入一次（入口与步骤见 [订阅源添加与分组整理](订阅源添加与分组整理.md) 第三节）。

导出菜单位置以你手上的版本实际显示为准；找不到时优先在设置的「故障排查」类分区里翻。

## 三、从别的 RSS 阅读器搬进来

1. 在旧阅读器里导出 OPML（绝大多数都支持），把文件传到手机；
2. Read You 右上角「+」→ 从 OPML 导入 → 选中文件；
3. 分组结构会随文件一起进来；导入完去「全部」标签核对一遍源的数量。

反过来要把订阅搬去别的应用，同样走 OPML：从 Read You 导出，到目标应用导入。

## 四、长期省心方案：把订阅放到云端

本地备份终究要手动做、手动恢复。把订阅交给 FreshRSS 这类服务端后，订阅与已读状态在云端，手机丢了、重装了都只需重新登录。云端与本地备份不冲突，在乎数据的话两样都做。
