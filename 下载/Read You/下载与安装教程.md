## 一、这是一款什么应用

Read You 是一款安卓端的 RSS 阅读器，界面按 Material You 风格设计，源代码以 GNU GPL v3.0 许可证公开在 GitHub 上。你用它把常看的博客、新闻站、播客的 RSS 地址聚合到一个应用里，新文章集中更新、集中阅读，不用在一堆资讯应用里来回切换。只在一台手机上用，装完就是本地账户；想把订阅放到服务端多设备同步，见 [云端账户与同步源配置](云端账户与同步源配置.md)。

本篇讲怎么把它装到手机上。装好之后第一步是加订阅源，做法见 [订阅源添加与分组整理](订阅源添加与分组整理.md)。

## 二、安装包从哪来

Read You 是开源应用，官方 README 列出的获取渠道有四个，各有差别：

| 渠道 | 入口 | 特点 |
| --- | --- | --- |
| GitHub 发布页 | [github.com/ReadYouApp/ReadYou/releases](https://github.com/ReadYouApp/ReadYou/releases) | 官方发布的正式版 APK |
| F-Droid | [f-droid.org/packages/me.ash.reader](https://f-droid.org/packages/me.ash.reader/) | 由 F-Droid 统一编译、签名、分发 |
| Telegram 频道 | [t.me/ReadYouApp](https://t.me/ReadYouApp) | 官方 README 列出的分发渠道之一 |
| 本页顶部的网盘资源 | 见页面顶部 `IMPORTANT` 块 | 转存后即可下载 APK，不需要访问上面任何站点 |

**换渠道升级前必读**：官方 README 明确说明，F-Droid 版由 F-Droid 统一编译并签名，**不能从其他渠道的版本直接升级**；反过来，从 F-Droid 版换成 GitHub 版也一样。渠道不同 = 签名不同 = 直接覆盖安装会失败。要换渠道只能先卸载再装，本地订阅与文章数据会丢 —— 卸载前先备份（OPML 与 JSON 两套备份的用法见 [订阅数据备份与搬家](订阅数据备份与搬家.md)）。

## 三、安装步骤（以网盘资源的 APK 为例）

本页顶部的 [Read You 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3a904647f4a2)里是一份可直接安装的 APK：

- 版本：0.15.0（包名 `me.ash.reader`）
- 体积：约 7.78 MB
- MD5：`C23F9F965DA17C2FF02F2E974B7E67E0`

安装步骤：

1. 打开网盘链接，把资源转存到自己的网盘，再下载 APK 文件到手机；
2. 在手机文件管理里点开这个 APK；系统提示「禁止安装未知来源应用」时，按提示允许来自该来源的安装；
3. 点「安装」，完成后打开。

对安卓系统版本的要求以官方页面显示为准。安装或首次运行遇到报错，先翻 [常见问题排查](常见问题排查.md)。

## 四、第一次打开要做的事

- **通知权限**：首次启动会弹「是否允许 Read You 发送通知」。想收文章更新通知就点允许；当时拒绝过后想再开，去系统设置的应用通知里打开，详见 [同步频率与文章通知](同步频率与文章通知.md)。
- **欢迎页**：确认使用条款与隐私政策后点「同意」，进入主界面。
- **主界面长什么样**：默认停在「未读」标签；右上角的「+」用来加订阅源，左上角的齿轮进设置 —— 想调外观与排版，见 [阅读排版与主题调整](阅读排版与主题调整.md)。
