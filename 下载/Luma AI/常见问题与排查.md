## 一、一点注册就闪退

0.5.7 的官方更新说明里明确写着「Fix registration crash」（修复注册崩溃）—— 这个 bug 是在这一版修掉的。对照处理：

- 手里的版本低于 0.5.7 → 换新版装（覆盖安装即可，不用先卸载）。
- 已经是 0.5.7 还闪退 → 先清一次应用数据（设置 → 应用 → Luma AI → 存储 → 清除数据）再试；仍闪退则卸载后重装，并核对安装包 MD5 是否为 `ceb00cf49b841337710edfc532ed9c55`（校验方法见 [下载与安装教程.md](下载与安装教程.md)）。

## 二、收不到验证码 / 登不上

1. 确认手机号或邮箱没输错（国际区号容易漏）。
2. 邮箱注册的，翻一下垃圾邮件箱。
3. 换网络试试：蜂窝数据与 Wi-Fi 走的出口不同，有一条通了就是网络侧的问题。
4. 都不行就过十几分钟再试 —— 验证接口偶发延迟属于服务端问题，你这边没有可操作的绕过手段，只能重试或稍后再来。

## 三、拍照按钮点不动 / 提示没有权限

相机和相册权限缺一个都会卡住。处理路径：系统设置 → 应用 → Luma AI → 权限 → 把「相机」「照片和视频」都改为允许，回到 app 重新进拍摄界面。部分品牌还有「后台弹出界面」「后台运行」类的额外开关，权限给了仍点不动时，一并打开。

## 四、上传卡住或特别慢

按顺序排查，命中即停：

1. **素材体积**：拍摄时长直接决定上传量。绕拍两三分钟的高清视频是几十上百 MB，先确认不是在用很差的网络硬传 —— 换到稳定 Wi-Fi，或先传一小段验证链路。
2. **前台运行**：上传时把 app 留在前台，锁屏或切到后台后被系统杀掉，传输就断了。
3. **手机存储**：剩余空间不足会导致缓存写不进去，先清出至少与素材体积相当的空间。
4. **反复失败**：删掉这次未完成的任务，重新拍摄上传一次，比在坏任务上反复点重试有效。

上传成功之后就换了一类问题：云端处理要多久、多久算卡死、服务故障时怎么办，单独一篇讲透 —— 见 [场景处理要等多久.md](场景处理要等多久.md)。

## 五、处理完的场景是糊的、有破洞

这不是 bug，是素材问题 —— 重建只能用画面里有的信息，处理这一步没有可调的参数能救。对照 [拍摄3D场景的技巧.md](拍摄3D场景的技巧.md) 逐条检查：

- 是不是绕太快或原地站着没动（角度覆盖不足）；
- 光线是否中途变化（没锁曝光）、有没有开 HDR；
- 失败那块是不是反光面/纯黑面，或当时被你自己挡住了；
- 场景里有没有走动的人、晃动的东西。

定位到原因后新建一次捕捉重拍，旧任务可以直接删。同一个物体拍三次成功一次是正常节奏，先小后大。

## 六、分享链接别人打不开

1. 先自己在无痕窗口里点一遍 —— 你自己也打不开，多半是场景已删除或账号登录态异常。
2. 确认场景处理完成状态：还在排队处理的场景，链接分享出去对方看到的是等待页。
3. 对方打不开而你能打开 → 让对方换浏览器或换个网络再试，交互式 3D 页面对 WebGL 有要求，过旧的浏览器/设备渲染不出来。

链接长期有效的前提是场景不被删除，详见 [模型导出与分享教程.md](模型导出与分享教程.md)。

## 七、导出入口找不到或导出失败

- 不同版本界面里导出入口的叫法与位置有差别（Export / 导出），在场景详情页与分享菜单里都找一遍。
- 网页预览正常但导出失败 → 属于服务端生成文件的环节，先看一眼 [场景处理要等多久.md](场景处理要等多久.md) 判断是不是服务侧故障，等几分钟重试一次；连续失败就先做一次新的捕捉测试是否复现。
- **有用户反馈**近期版本出现过导出功能报错、导出产物缺失的情况（第三方评论汇总，非官方口径）。若你这边稳定复现、而网页预览一直正常，等状态页恢复后重试一次即可 —— 导出是可重复触发的动作，失败不消耗素材，删任务重拍才是错误应对。
- 导出的格式选项与你预期的对不上：各版本提供的格式不一致，以你设备上的选项为准，能选到的才是可用的。

## 八、装不上、装了闪退

| 症状 | 处理 |
| --- | --- |
| 解析包错误 | 安装包不完整，重新下载；核对 MD5 |
| 提示禁止安装 | 按系统提示给该来源打开「允许安装」开关后重装 |
| 覆盖安装失败 | 新旧包签名不一致，先卸载再装（登录态会清，云端作品不受影响） |
| 打开即闪退（非注册时） | 清应用数据 → 仍闪退则重装；确认系统版本满足要求 |
| 系统版本不够 | 第三方商店标注最低 Android 10 及以上（以官方商店页面当时显示为准），低于它无法安装 |

## 九、关于去水印、Pro 之类的说法

有第三方资料整理提到：捕捉类功能免费，另外存在一种需要联系官方开通的 Pro 状态，用于去掉导出内容上的 Luma 标识。这类开通方式与条件**属于会变的信息，以官方渠道当时的答复为准** —— 任何声称能在 app 里直接买到或绕过它的说法都不要采信，遇到相关页面直接离开。收费与功能边界同样以官网为准。
