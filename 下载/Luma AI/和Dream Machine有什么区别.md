## 一、一句话分清

| | 这个 app（Luma AI: 3D Capture） | Dream Machine |
| --- | --- | --- |
| 你给它什么 | 手机绕拍的一段视频或几张照片 | 一段文字描述，或一张图 |
| 它给你什么 | 可拖动的 3D 场景、可导出的模型文件 | 一段生成的视频 |
| 主要在哪用 | 手机 app（安卓/iOS） | 网页，浏览器打开官网使用 |
| 典型用途 | 扫商品、扫房间、扫手办做展示和资产 | 做短片素材、创意视频 |

同一个公司（Luma AI, Inc.）的两条产品线，账号体系相通，但**功能互不替代**：app 负责「把真实世界搬进电脑」，Dream Machine 负责「凭空生成视频」。

## 二、为什么你会装错

两个原因叠加：

1. **名字都叫 Luma AI**。Dream Machine 是 Luma 家的视频生成服务，对外常以「Luma AI 的视频生成」被提到；而 Google Play 里叫 `Luma AI`、包名 `ai.lumalabs.polar` 的这个 app，本职是 3D 捕捉。
2. **app 里确实有 Dream Machine 的入口**。0.5.7 这一版的官方更新说明里第一条就是「Dream machine redirect banner」—— 界面上有一条指向 Dream Machine 的跳转横幅。所以装完 app 看到视频生成的入口，不代表生成动作在这个 app 里完成。

**判断你该用哪个**：想把自己拍的东西变成 3D → 用 app；想输入一句话拿到一段视频 → 去官网的 Dream Machine。

## 三、账号、收费与权限

- **这个 app**：注册即用，捕捉与上传按第三方整理的资料为免费，官方介绍里也没有列出付费墙。
- **Dream Machine**：属于 Luma 的生成式服务，实行免费加付费的分层 —— 免费档有每月生成次数上限，付费档拿到更高的输出分辨率与更靠前的排队位置（第三方价格汇总页 2026-09 的口径：免费档每月约 30 条、付费档从每月 120 条起）。这类额度与价格变化很快，**一律以官网当时显示为准**，本文数字只当量级参考。
- **排队也会分档**：高峰期（有第三方监测记录为美国东部晚间）免费档可能要多等十几分钟，付费档优先；判断是排队还是故障，看 [场景处理要等多久.md](场景处理要等多久.md)。
- **两者共用 Luma 账号**：在 app 里注册的账号，去官网登 Dream Machine 通常直接能用，不需要另注册一个。

## 四、Luma 还有第三个东西：Genie

官网历史资料里还出现过 Genie（文字生成 3D 模型）。它和上面两个的区别同样是「输入输出」：

- 3D Capture：真实影像 → 3D 场景
- Genie：文字 → 3D 模型
- Dream Machine：文字/图片 → 视频

如果你是冲着「生成视频」来的，这篇的结论再重复一次：app 装的是捕捉工具，视频生成去官网。官网入口与各功能的可用状态，以 [lumalabs.ai](https://lumalabs.ai/) 当时页面为准。

## 五、一个需要知道的背景

有第三方长期跟踪资料提到，Luma 的研发重心已明显偏向生成式视频（Dream Machine），并对其 3D 捕捉功能是否仍积极开发提出疑问；同时该资料也记录了官方表态 —— 3D 捕捉会继续提供。两边说法并列给你：**app 目前能正常注册、拍摄、导出**（0.5.7 的更新日志里还修着注册崩溃），但如果你打算把它纳入长期工作流，重要项目建议随时保留导出的原始文件，别只依赖云端场景。操作层面的影响见 [常见问题与排查.md](常见问题与排查.md)。
