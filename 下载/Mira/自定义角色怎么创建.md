# Mira 自定义角色怎么创建

> 广场里的角色不合口味时，自己捏一个：入口在哪、要填什么、建完去哪聊。

## 一、创建入口在哪

有第三方下载站页面介绍过这条路径：进入 **我的** 页面 → 点 **创建角色**。入口的具体位置以你手上的版本实际菜单为准，找不到时在「我的」页里翻一遍就能看到。

## 二、要填哪些内容

按第三方页面的说法，创建时填写角色名称、性格、头像等，保存后角色就会出现在你的聊天列表里。把这几项当作一个整体来填：

| 项目 | 建议怎么填 |
| --- | --- |
| 名称 | 好认就行，聊天列表里靠它区分多个角色 |
| 性格 | 决定说话方式的字段，写得越具体越贴预期（如「话少、毒舌但心软」比「高冷」好控制） |
| 外貌 / 头像 | 列表与对话里的形象 |
| 背景故事 | 交代角色与你的关系、常聊的话题范围 |

填得具体，角色接话越贴设定；描述越模糊，回复越容易泛。

## 三、建完去哪聊

保存后在聊天列表里找到它，点开就能聊，用法与广场角色一致：发消息、续聊、长按消息操作。自建角色的对话同样走应用内的模型与积分机制，规则见 [积分获取与模型选择.md](积分获取与模型选择.md)，具体以应用内显示为准。

## 四、什么情况下值得自建

- 常聊的话题方向固定（比如每天复盘、固定某类话题的陪聊），捏一个专门的角色省得每次重新交代；
- 广场里翻不到对味的人设；
- 想要的角色关系在广场角色里没有现成的。

建好之后如果发现回复总不对味，先回头改角色设定，比在对话里反复纠正快，调整思路见 [角色挑选与聊天上手.md](角色挑选与聊天上手.md)。
