## 一、收费模式：7 天预览从安装那一刻开始算

这是新用户最容易踩的点，单独拿出来说：

- 安装免费，装上后有一段 **7 天全功能预览**；
- 预览期**从安装完成时开始计时，不是从你第一次打开应用开始**。装完先放着不打开，预览期照样在走；
- 预览结束后要继续使用，需要选**订阅**（按月/按年）或**一次性买断**（lifetime），具体价格按地区不同，在应用内以当地货币显示；
- 官方页面把它标为「early access」：应用还在持续迭代，已购的解锁在后续版本继续有效。

## 二、购买与许可的几个常见问题

- **换手机还能用吗**：能。同一 Google 账号下安装后即可，必要时在应用内恢复；
- **怎么恢复购买**：打开 AppDash → 设置 → 「Restore purchase」，它会向 Google Play 重新核验许可。前提是登录的还是当初购买用的那个账号；
- **恢复购买没反应**：官方 FAQ 给的处理办法是清一次 Google Play 商店的数据再重启手机，等许可同步。

## 三、root 和 Shizuku 分别解锁什么

普通设备上 AppDash 已经够用；root 或 Shizuku 是给想更进一步的人的增量选项：

| 进阶能力 | 需要的权限 |
| --- | --- |
| 强制停止任意应用 | root 或 Shizuku |
| 按应用切换电池优化开关 | root 或 Shizuku |
| 静默安装/卸载（跳过系统弹窗，批量操作快很多） | root 或 Shizuku |
| 禁用系统应用（不卸载，隐藏后可恢复） | root 或 Shizuku |
| 备份应用数据、外部数据、OBB | 仅 root |

Shizuku 是一种不需要完整 root、通过调试授权给应用提升权限的方案，比 root 门槛低。只要 AppDash 检测到任一种权限可用，对应的进阶操作就会出现在界面里。没有授权时这些按钮不可用，其余功能不受影响。

## 四、系统要求与语言

- **系统**：官方 FAQ 目前标注需要 Android 8.1 或更新版本，具体以官方页面为准；
- **平台**：只有 Android 版，没有 iPhone、Windows 或 macOS 版；
- **语言**：内置 23 种语言，含简体与繁体中文，一般随系统语言自动切换；
- **版本差异**：AppDash 迭代较快，不同版本的功能和界面会有出入——你手头那份包是 2.05 版（约 6.43M，包名 `flar2.appdashboard`），文中提到的个别新功能（如任务管理器）只在更新的版本里出现，以实际界面为准。

## 五、隐私：它收集什么

- 应用本身**无广告、无跟踪**；
- 唯一的联网数据口是 Enhanced App Info（增强应用信息）：开启后，你的已安装应用**包名列表**会被发送到 AppDash 的服务器，用于匹配更新日志、评分这类元数据；官方说明该数据**不保存、不与身份关联**；
- 在设置里关闭 Enhanced App Info 后，没有任何信息离开设备，损失的只是联网增强那一部分功能；
- 备份、标签、备注、批量操作、APK 工具都是本地功能，与这个开关无关。

## 六、安装/使用问题速查

| 现象 | 处理 |
| --- | --- |
| APK 装不上 | 先看是否已给文件管理器「安装未知应用」授权；再看系统版本是否达标（见 [下载与安装教程.md](下载与安装教程.md)） |
| 提示 Play 保护机制警告 | 等扫描完成再继续，不要在扫描时反复重试 |
| 预览期「提前」结束 | 多半是安装后隔了几天才打开——计时从安装时开始 |
| 恢复购买失败 | 核对 Google 账号；清 Play 商店数据并重启，再试一次 |
| 收不到关注列表通知 | 检查系统通知权限与 AppDash 内的通知设置，两者都要开 |
| 批量强制停止/禁用按钮是灰的 | 需要 root 或 Shizuku 授权，普通设备上不可用，属正常 |

还有没覆盖到的问题，去官网 [appdash.app](https://appdash.app/) 的 FAQ 页看完整版本。需要重新获取安装包时，用这份 **AppDash 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/989583a6dc76](https://pan.quark.cn/s/989583a6dc76)。
