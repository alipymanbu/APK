## 一、创建入口

打开应用后，点底部导航的「+」图标，在弹出菜单里选 **Create a Character**，就进入角色创建窗口。创建数量目前没有上限（官方 FAQ 口径），但角色违反社区规则时，官方可能限制你的创建功能。

## 二、快速创建要填的八个字段

创建窗口里的字段一共八项，各自的作用如下：

| 字段 | 填什么 | 注意点 |
| --- | --- | --- |
| Name | 角色名 | 起一个能代表角色的名字 |
| Avatar | 头像 | 新画一个或从相册导入；要公开的角色不能用 NSFW 头像 |
| Description | 一句话简介 | 用一句话说清这个角色是什么 |
| Greeting | 开场白 | 别人打开你的角色时收到的第一条消息 |
| Chatbot Visibility | 角色可见性 | Public：出现在首页与搜索结果里；Private：只有你能看到 |
| Definition Visibility | 人设可见性 | 决定别人能不能看到你写的人设，想保密就选 Private |
| Memory | 角色记忆 | 角色的性格、好恶、行为习惯都写在这里，是决定角色像不像「人」的核心字段 |
| Prompt | 示例对话 | 几段示例问答，用来给角色的说话方式定调 |

八项填完点 Create，角色就建好了，之后随时可以回来改。

## 三、公开还是私有

- 只有自己玩的角色，选 Private，最省心；
- 想让社区里的人搜到、用到，选 Public，但要满足两个前提：**角色是你原创的**（从别处搬来的角色要保持 Private），且**内容不踩红线**。不合规的公开角色会被下架，或被官方强制设为 Private；
- Greeting 是公开角色的门面，官方明确禁止在 Greeting 里出现露骨词汇。

具体哪些内容不能写，见 [社区规则与账号安全](社区规则与账号安全.md) 第二节的清单。

## 四、人设写多长合适

Hi Waifu 的 AI 模型单次可用的总上下文是 4096 token，你的输入、人设、对话历史和生成的回复都挤在这条预算里。官方文档给出的经验值：

- 人设描述（性格、背景等设定）控制在 **900～2000 token**；
- 人设加示例对话合计控制在 800～2000 token；
- 语言尽量精炼：重复、啰嗦的描述会挤占对话历史的空间，表现是聊久了角色「忘记」前面的设定。

token 没有直观显示，用「写得越精炼越省预算」的体感控制长度即可，宁可精炼，不要堆砌。

## 五、Memory 与 Prompt 的分工和写法

两个最容易被填错的字段，先把分工分清：

- **Memory 放「事实」**：身份、背景、性格、好恶、关系——第三方评测的实测口径也是这样：Memory 里写过的事实，隔几天再问角色还能记得；
- **Prompt 放「语气」**：放几段示例对话，让角色模仿这种说话方式；人设事实不要堆进 Prompt。

写 Memory 用短句、声明式写法，一行一条，第三方教程里常见这样的结构：

```text
名字：艾拉；年龄：25；职业：图书管理员
性格：好奇心强、谨慎、重感情（3~5 个特质，不要写满）
喜欢：古籍、安静的下午、茶
讨厌：被打断、仓促的决定
背景：在小城图书馆工作，正在整理一批旧信件
```

注意两条边界：角色必须设定为成年人（年龄不写就放进人设里注明）；token 预算有限，这份清单控制在第四节的 900～2000 token 内，写完可以在新对话里问几个细节，检验角色是否记住了。
