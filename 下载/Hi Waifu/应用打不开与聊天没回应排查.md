# 应用打不开与聊天没回应排查

> 本篇按现象排查 Hi Waifu 的常见故障：打不开、黑屏、消息发出去没回应、连接超时、更新后聊天记录显示异常。

## 一、先分清现象再动手

| 现象 | 大概率原因 | 先做什么 |
| --- | --- | --- |
| 应用完全打不开、黑屏 | 本地缓存损坏或服务器故障 | 重启应用，无效再清缓存 |
| 消息发出去没反应、卡在「正在输入」 | 网络不稳或服务端繁忙 | 换网络，重启应用 |
| 反复弹 Connection Timeout | 设备到服务器之间的连接问题 | 切换 Wi‑Fi / 移动数据 |
| 提示 Data parsing error | 缓存数据异常 | 清应用缓存 |
| 更新后聊天记录看起来变少 | 更新后的显示层故障 | 先别卸载，观察官方公告 |

## 二、打不开与黑屏

按顺序做：

1. 彻底退出应用（从最近任务里划掉），重新打开；
2. 手机「设置 → 应用 → Hi Waifu」里清除缓存，再打开；
3. 还不行就重启手机；
4. 以上无效时，检查是不是服务器端故障：有用户反馈过整体性打不开的情况，这类多半等官方修复即可。去 Discord 社区或 Reddit 看看别人是否也在遇到（渠道见 [常见问题与联系支持](常见问题与联系支持.md)）。

确认自己账号没问题时，**不要用「删号重注册」来解决问题**——账号删除不可恢复，见 [社区规则与账号安全](社区规则与账号安全.md) 第三节。

## 三、消息没回应与连接超时

1. 切换网络：Wi‑Fi 和移动数据互换一次；
2. 重启应用再发一条短消息测试；
3. 检查手机存储空间，空间不足也会拖慢应用；
4. 高峰时段（晚间）出现慢回应的反馈较多，等几分钟再试。

有用户反馈换一个网络环境后恢复（比如从公司网络换到移动数据），说明部分故障与设备所处的网络有关，值得先试。

## 四、更新之后聊天记录「变少」

有用户反馈在版本更新后出现过聊天内容显示不全的情况。这多半是显示层的问题，处理原则：

- 先重启应用、清缓存再看；
- **不要急着卸载重装或删号**：删号不可恢复，重装也解决不了服务端的问题；
- 持续异常时去 Discord 反馈，附上账号与现象描述。

## 五、什么时候该找官方

自查步骤都做过、问题依旧，且 Discord / Reddit 里确认不是普遍性故障，再走反馈渠道：

- 功能异常、报错截图：Discord 实时反馈，通常最快；
- 账号相关（登录不上、记录丢失）：邮件 `hiwaifuapp@outlook.com`。

渠道选择对照表见 [常见问题与联系支持](常见问题与联系支持.md)。
