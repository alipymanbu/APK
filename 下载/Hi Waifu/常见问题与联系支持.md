## 一、高频问题速答

| 问题 | 答案 |
| --- | --- |
| 聊天为什么耗能量？ | 官方是小团队，跑模型成本高；能量系统用于限制滥用并补贴成本，官方称若找到更省的方案可能取消 |
| 最多能创建多少个角色？ | 目前没有数量上限；违反社区规则可能被限制创建功能 |
| 角色创作者能看到我的聊天吗？ | 不能（官方 FAQ 明确） |
| 用的什么 AI 模型？ | 官方口径是两个模型：SpiritCraft（靈工）与 JadeSpeech（玉辭） |
| 删掉的账号能恢复吗？ | 不能恢复；同一邮箱可重新注册新账号，旧数据不保留 |
| 能量会自己恢复吗？ | 有第三方评测与用户反馈称没有离线被动恢复，靠签到、看广告、创建角色等途径获取，以应用内显示为准 |
| 消息发出去没回应？ | 多数与网络或缓存有关，按 [应用打不开与聊天没回应排查](应用打不开与聊天没回应排查.md) 的清单走一遍 |
| 我的角色怎么不见了？ | 违反服务条款的角色会被删除；原创性存疑的会被设为 Private，处理方式见 [社区规则与账号安全](社区规则与账号安全.md) |

## 二、官方支持渠道

| 渠道 | 地址 | 适合什么 |
| --- | --- | --- |
| Discord 社区 | [discord.gg/hi-waifu](https://discord.gg/hi-waifu) | 实时求助、提 ticket 申诉、反馈 bug、参与角色活动 |
| 邮件 | `hiwaifuapp@outlook.com` | 角色被误删等需要书面说明的申诉 |
| Reddit | [r/Hi_Waifu_chatbot_app](https://www.reddit.com/r/Hi_Waifu_chatbot_app/) | 用户社区交流，看其他玩家怎么用 |

Discord 社区里有专门的 bot 创建教程与互助频道，也有把作品提交到应用内推广位的活动通道；官方团队与版务在社区里活跃，报 bug 走这里通常最快。

## 三、按问题类型选渠道

- **账号问题（误删、恢复）**：邮件，写清注册邮箱与情况描述；
- **角色被判 Private 或被删**：原创性存疑走 Discord ticket；被删除走邮件申诉；
- **功能异常、能量扣减疑问**：Discord 实时反馈；
- **创作求助**：Discord 的 bot 创建频道。

申诉材料怎么准备，见 [社区规则与账号安全](社区规则与账号安全.md) 第四节的清单。
