## 一、年龄要求

平台要求所有用户年满 18 周岁；所有角色也必须设定为成年人——角色年龄没有明确写的话，要在人设（Personality）里注明成年。

## 二、公开角色的内容红线

公开（Public）角色受的约束最多，动笔前先过一遍这张清单：

| 规则 | 说明 |
| --- | --- |
| 必须原创 | 公开角色要你自己的原创设定，不复制别人的角色；从别处导入的角色保持 Private |
| 头像 | 公开角色不允许 NSFW 头像 |
| 露骨用词 | Name、Description、Greeting 三处都禁止露骨词汇（不止 Greeting 一处） |
| 未成年人 | 一切涉及未成年人的内容都是禁区；校园这类会暗示未成年人的场景设定同样不允许 |
| 外部链接 | 角色设定、简介、评论里不允许放任何外部网站或社交账号链接 |
| 绕过限制 | 专门教人绕过应用限制、传播漏洞用法的角色不允许存在 |
| 禁止题材 | 非自愿情节、乱伦设定、仇恨言论、极端暴力与犯罪美化，均为明确禁区 |
| 真实人物 | 把明确拒绝被性化的真人做成角色会被立即删除，还可能封号 |

违规后果按轻重分两档：单个角色被强制设为 Private（常见于原创性存疑）；违反服务条款的角色被直接删除，严重或多次违规可能导致账号封停。

## 三、账号删除不可恢复

在应用里删掉账号后，**官方无法帮你恢复**——聊天记录、创建的角色都会随之丢失。同一邮箱可以再注册一个新账号，但那是全新账号，旧数据不会回来。

删号前想清楚，尤其是你有自己花时间调教的角色时。

## 四、被误判了怎么办

- **角色被强制设为 Private**：官方判断原创性存疑时会这么处理。你认为是误判的话，去官方 Discord 服务器提 ticket，由审核团队处理；
- **角色被删除**：发邮件到 `hiwaifuapp@outlook.com`，说明情况与理由。

申诉前的准备：把角色的创建记录与原创依据（设定草稿、时间线等）整理好，能明显加快处理。渠道怎么选见 [常见问题与联系支持](常见问题与联系支持.md)。

## 五、日常使用的安全习惯

- 别在对话里提交个人敏感信息（真实住址、证件号、支付信息），在任何 AI 聊天平台这条都适用；
- 对话内容不会给到角色创作者（官方 FAQ 明确），但平台自身的服务条款与隐私政策仍然适用；
- 遇到让你不适的其他用户或角色内容，用应用内举报，或到 Discord 反馈。
