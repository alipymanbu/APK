## 一、先分清三种文件形态

在应用内点下载之后，落到手机上的可能是三种东西之一：

| 形态 | 特征 | 怎么装 |
| --- | --- | --- |
| 普通 APK | 单个 `.apk` 文件，体积不大 | 下载完直接弹安装 |
| XAPK | `.xapk` 后缀，本质是个 ZIP 打包，里面装着 APK 和可能的数据文件 | 由商店客户端处理；第三方资料称 BlackMod 兼容 XAPK |
| OBB 数据包 | `.obb` 后缀，大体积游戏的数据文件 | APK 装完后放到固定目录 |

体积大的游戏几乎都是后两种——安卓对单个安装包有体积上限，游戏会把地图、音频、视频拆出来放在数据文件里，跟着安装包一起分发。

## 二、最省事：让客户端自己装

BlackMod 自带下载与安装处理，从应用内下载的条目装完会自动接手，不用你碰文件。要保证的只有一件事：**给 BlackMod 本身授予「安装未知应用」权限**。

这是安卓 8.0 之后的按应用授权：你的文件管理器有这个权限，不代表 BlackMod 也有。下载完不弹安装、点安装没反应时，先查这里：

设置 → 应用管理 → BlackMod → 安装未知应用 → 打开「允许来自此来源」

## 三、手动兜底：OBB 数据包放哪

如果资源下成了散文件（一个 APK 加一个 `.obb`），或者客户端装完后游戏提示缺数据，按安卓的通用规则手动处理：

1. 先安装 APK，方法同 [下载与安装教程.md](下载与安装教程.md) 第三节；
2. 用文件管理器把 `.obb` 文件放进这个目录：

```
/sdcard/Android/obb/<该游戏自己的包名>/
```

注意 `<该游戏自己的包名>` 是那个游戏自己的包名，不是 BlackMod 的；OBB 文件名形如 `main.版本号.包名.obb`。目录不存在就手动新建一个；
3. 放好再打开游戏。仍提示缺数据，逐字核对目录名与包名是否一致——差一个字符就读不到。

这套路径是安卓系统层面的通用规则，与从哪个商店下载无关；个别游戏还有自己的额外校验，按它给出的提示处理即可。

## 四、空间要留够

- XAPK 安装期间，「下载的原始包 + 解开的 APK + 数据文件」会同时占空间：装一个 2G 的资源，实际需要 4~5G 余量（这是有经验用户给出的经验值，供参考）；
- 装完确认游戏能进，再把下载目录里的原始 `.xapk`/`.obb` 文件删掉腾空间；
- 大文件尽量在 Wi-Fi 下下载。该客户端支持暂停续传，中断了可以接着下，但别在中途强杀应用进程。

## 五、装完打不开或提示缺数据

游戏启动卡在加载、闪退，或提示「正在下载额外的数据文件」，多数是数据包没到位：回到第三节核对 OBB 的目录与文件名。文件确认无误还闪退，按 [安装失败与常见问题.md](安装失败与常见问题.md) 第五节排查。
