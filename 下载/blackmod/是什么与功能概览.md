## 一、定位：它是一款什么应用

BlackMod 是一款安卓端的第三方游戏与应用资源商店客户端。据第三方资料，它由 BlackMod 团队维护，与同名社区站点配套，面向不想只依赖常规应用商店、希望直接在手机上翻找游戏资源的用户。装上它之后，它本身就是一个「商店」：里面按类别摆着大量游戏和应用条目，你可以浏览、搜索、下载，也能管理已经装过的那些。

需要说明的是，它不在 Google Play 等常规商店上架，获取方式是直接安装 APK 安装包——这也是安装前要开启「未知来源」权限的原因，具体步骤见 [下载与安装教程.md](下载与安装教程.md)。

名字上有个容易混淆的点：这套应用在不同渠道有两个叫法——BlackMod 与 BlackMarket，多个第三方资料将两者视作同一套东西（同一团队的社区站与商店客户端）。搜资料、找版本时两个名字都值得试；本文统一用 BlackMod。

## 二、界面与主要功能

综合第三方页面对该应用的介绍，它的功能集中在「找资源、下资源、管资源」三件事上：

| 功能 | 你能做什么 |
| --- | --- |
| 分类浏览 | 游戏与应用按类别摆放（如动作、街机、卡牌、休闲等），从分类入口逐层往下找 |
| 手动搜索 | 知道名字时直接搜，不必一层层翻分类 |
| 推荐与建议 | 会给出较热或新上架的条目，没有明确目标时可以逛一逛 |
| 下载管理 | 支持暂停、续传下载任务，网络不稳时不用从头再来 |
| XAPK 兼容 | 部分资源以 XAPK 格式分发，客户端可以直接处理 |
| 已装应用管理 | 查看自己装过哪些条目、是否出了新版本 |
| 免注册 | 据第三方资料，基础功能不需要注册账号就能用 |

界面语言方面，第三方资料称内置多种可选语言，装好后可以在设置里切换；具体支持哪些语言以你手上这一版的设置页为准。

表格里提到的 XAPK 是什么、大体积游戏的数据包怎么落地，单独整理成了 [XAPK与数据包怎么装.md](XAPK与数据包怎么装.md)。

## 三、什么场景下会用到它

- 想在手机上直接翻游戏资源、不想在多个网页之间跳来跳去；
- 常规商店里搜不到某些应用，想换个入口找找看；
- 需要下载暂停/续传，或想把下载过的条目集中管理起来。

反过来说，如果你只从 Google Play 获取应用、也不打算开启「未知来源」，那这款应用对你没有用武之地——它的全部功能都建立在「直接装 APK」这个前提上。
