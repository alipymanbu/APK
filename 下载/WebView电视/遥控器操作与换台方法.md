## 一、按键先对上：遥控器上的四个常用操作

WebView电视把屏幕和遥控器都按区域分工，装好后先记住这张表（以你装的版本界面为准，不同版本措辞可能略有差异）：

| 按键 | 作用 |
| --- | --- |
| OK（确认）键 | 呼出**频道列表**，用来选台 |
| MENU（菜单）键 | 呼出**频道设置**（画面比例、换源等） |
| 长按 OK 键 | 同样呼出频道设置 —— 给没有菜单键的遥控器用 |
| 返回键 | 弹出退出确认，也是进入全局设置的入口 |

也就是说，最常用的两个入口是「选台」和「频道设置」，一个在 OK 键上、一个在菜单键上；遥控器缺键就用长按 OK 代替。

如果你用的是手机或平板（触屏），逻辑一致但换成了点屏幕：点左侧 2/3 出频道列表、点右侧 1/3 出频道设置、长按屏幕进设置中心。蓝牙手柄则是 A 键出列表、X 键出设置、B 键退出。三套按键的对应关系都能在「设置 → 操控设置」里自己改。

## 二、换台的四种方式

1. **频道列表选台**：按 OK 键呼出列表，上下移动选中频道按确认。这是最基本的路子，任何设备都能用。
2. **数字键直选**：在播放界面直接按遥控器数字键输频道编号跳台。版本不支持时不会有反应，界面上也未必有提示。
3. **左右键换源**：2.1.2 加入的功能，但默认没开 —— 要去 **设置 → 左右键功能** 里开启，开完左右键就在「换台」和「换源」之间分工。
4. **手势**：触屏设备上下滑动可以换台，也可以调亮度或音量，具体调什么在设置的滑动逻辑里改。电视遥控器没有触屏，用不上这条。

换台速度要先放平预期：这软件是加载网页再识别视频，换台必然比纯直播源的软件慢，快慢取决于设备性能，官方明确说过这条无法优化。低性能设备可以在设置里打开「无图模式」减轻负载。

## 三、画面比例、网速与收藏都在菜单键里

按菜单键（或长按 OK）出来的频道设置里，你能做这些事：

- **切换画面比例**：16:9 与 4:3 两档，看老节目或觉得画面被拉伸时切一下。
- **看状态信息**：当前时间、实时网速、正在播放的源链接。
- **收藏频道**：把常看的台收进收藏列表，之后选台少翻几层。
- **换播放源**：同一频道有多个源时在这里切，当前源卡了就换下一个。

画面尺寸在部分版本里是固定高清、不给选，别在设置里翻找清晰度开关 —— 官网直播页本身提供什么清晰度，你就只能看什么。

## 四、需要登录才能看的频道，从这里进源网页

有些电视台官网要你登录才让看、或者登录后才给更高清晰度。这时点播放界面右侧（或按菜单键）打开右侧边栏，点**地球图标**，就会进到这个频道的源网页 —— 在那上面正常完成登录，再退回播放界面即可。应用本身不代替你登录，它只是把官网页面打开给你操作。
