# WebView电视打开只有CCTV-1怎么处理

## 一、这个症状说明什么

WebView电视的频道列表不随安装包一起分发，而是**托管在网络端、打开时在线拉取**。本地只保留一个兜底的默认台 —— 所以「打开只有 CCTV-1」或列表空着，几乎总是同一件事：**线上列表这次没加载成功**，不是你的包坏了，也不是频道被删了。

先分清另一个容易混淆的情况：列表是全的、但**点了台播不出来或不全屏**，那不是本篇的问题，去 [无法自动全屏怎么调.md](无法自动全屏怎么调.md) 和 [内核与闪退卡顿排查.md](内核与闪退卡顿排查.md)。

## 二、处理顺序：从轻到重

1. **先重试一次**：退出应用再进。线上拉取偶尔失败，多数情况第二次就好了。
2. **清缓存**：进「设置 → 应用」找到 WebView电视，先只**清除缓存**，重启应用 —— 缓存脏了会让它一直拿旧的失败结果。
3. **清数据**：还不行就**清除数据**重来。注意这一步会把你做过的设置、收藏一并清掉，清完要重新调（包括 [无法自动全屏怎么调.md](无法自动全屏怎么调.md) 里那两个全屏开关）。
4. **隔一段时间再试**：如果连续多次、隔了几天都只有 CCTV-1，说明你这边的网络持续访问不到列表地址，别再反复清数据了，往下看网络自查。

## 三、网络自查：问题多半在这一层

列表要从网络端拉，加载不出来就查这条链路：

- **设备本身能不能上网**：随便打开一个别的、同样依赖在线加载的应用试试；都不行就是设备网络不通，先修网络。
- **代理与 DNS**：电视和盒子上装过代理、改过 DNS 的，临时关掉或换回自动获取再试 —— 这类设备上最常见的坑就在这里。
- **访问受限**：列表地址所在的网络服务在你当前网络下可能访问不稳定，换个网络环境（比如手机开热点给电视试一次）能快速定位是不是链路问题。

## 四、什么时候该找开发者

网络自查没问题、清过数据也重试过，问题仍连续存在几天 —— 这已经超出你这台设备能处理的范围，去官方 GitHub 项目的 Issues 区反馈（[hxh19950701/WebViewTvLive](https://github.com/hxh19950701/WebViewTvLive)）。反馈时写清设备型号、系统版本、已做过的步骤，别人复现得快，你也就快。
