剪辑完成后从 amls 里把成片拿出来的最后一步是导出。工程做得再好，导出参数没选对，轻则文件巨大，重则导出失败。

## 一、导出入口

1. 编辑页右上角是生成按钮；
2. 点它后弹出导出模式选择；
3. 选你想要的格式与参数，开始导出；
4. 导出完成后按提示保存，成片会出现在手机相册或应用的导出目录里。

除了在编辑页里导出，也可以回到工程列表对工程长按再导出，这条路占用的资源更少，工程复杂时更稳。

## 二、四种导出物

| 导出物 | 用途 | 说明 |
| --- | --- | --- |
| 视频 | 发平台、存档 | MP4，常规选择，分辨率与帧率在导出时选 |
| GIF | 表情包、动图 | 短片段、无音轨 |
| PNG 图像序列 | 逐帧素材、后期加工 | 把工程按帧导成一张张图片，交给电脑软件继续处理 |
| 项目包 | 给别人继续编辑 | 打包工程与素材，对方导入后接着改，适合交接工程或分享模板，流程见[模板导入与元素复用.md](模板导入与元素复用.md) |

## 三、导出参数怎么选

amls 的视频导出常见 540p 与 1080p 两档，日常发布选 1080p；帧率 30 够用，拍的是舞蹈、游戏这类高速画面再考虑 60。导出页若提供码率等高级参数，参考下面的常用值（同源编辑器的社区经验值，以你安装版本的导出页实际显示为准）：

| 参数 | 常用值 | 说明 |
| --- | --- | --- |
| 分辨率 | 1080p（竖屏 1080×1920） | 与工程比例一致 |
| 帧率 | 30 | 高动态内容用 60 |
| 视频码率 | 8~12 Mbps | 低于 8 容易出马赛克感，盲目拉高只是文件变大 |
| 音频 | 192 kbps / 44.1 kHz | 常规解说、配乐足够 |

平台上传时会二次压缩，成片文件大小控制在几十 MB 量级即可，没必要追求超大文件。参数选低了导出后画面糊，重新用更高参数导一遍就行，工程本身不受影响。

## 四、点导出前检查这几件事

- **时长**： GIF 只适合短片段，长视频选视频格式；
- **分辨率**：参数定得比手机硬件能扛的高，是导出失败最常见的原因，拿不准就用默认值；
- **存储空间**：导出过程会先写临时文件，手机存储见底时导出会在中途失败；
- **后台应用**：导出时尽量关掉游戏、视频类后台应用，把内存让出来。

导出失败、卡在某个百分比、或导出后文件打不开，按[常见问题排查.md](常见问题排查.md)里的对应条目处理。

## 五、导出慢不等于卡死

图层多、效果多、分辨率高的工程，导出几分钟到十几分钟都正常，进度条在走就别杀后台。等导出这段时间，可以顺手把下一个工程的素材在[创建工程与导入素材.md](创建工程与导入素材.md)说的入口里备好。
