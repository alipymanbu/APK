amls 的剪辑从「建一个工程」开始：先建工程、再往里加图层素材。还没装好的先看[下载与安装教程.md](下载与安装教程.md)，本篇默认你已经能打开应用首页。

## 一、创建工程

1. 在首页点底部中间的蓝色添加按钮；
2. 在创建工程页输入工程名称，并设置比例、帧率、分辨率等参数；
3. 点「创建工程」，进入编辑页。

比例按发布平台选，建工程时就定好（后期改要重排版面）：

| 你要发的平台 | 比例 |
| --- | --- |
| 竖屏短视频（抖音 / 快手 / Shorts） | 9:16 |
| 横屏 vlog（B站 / YouTube） | 16:9 |
| 方形图文 | 1:1 |

分辨率与帧率日常用 1080p、30 起步就够；选低了导出画面糊，重选分辨率意味着重剪。背景色默认浅灰即可，不影响成片。

## 二、导入视频（六步）

1. 进入编辑页后，点右下角的「笙」图标；
2. 弹出插入素材编辑区，面板分「媒体、音频、形状、手绘、矢量图层」几类；
3. 手机里的视频和图片走「媒体」入口（部分版本默认停在「音频」标签，切一下或直接在文件选择器里挑视频文件都可以）；
4. 首次导入会弹出「允许访问」提示，点允许，让应用读取手机存储；
5. 在文件选择器里找到要导入的视频；
6. 点选后视频出现在时间线上，导入完成。

原始素材在成片导出之前先别急着删，免得工程里的素材出问题。

## 三、其他能加的东西

同一个「笙」入口里可以添加的图层类型不止视频：

- **图片 / 形状**：做封面、边框、背景板，导入后可拉伸改大小，圆角、填充色都能调；
- **音频**：背景音乐、音效（详细用法见[字幕配音与背景音乐.md](字幕配音与背景音乐.md)）；
- **文本**：字幕、标题（见[字幕配音与背景音乐.md](字幕配音与背景音乐.md)）；
- **手绘 / 矢量图层**：直接在画面上涂写标记，或画矢量图形；
- **元素**：现成模板组件，不用自己导入，详见[模板导入与元素复用.md](模板导入与元素复用.md)。

## 四、点「允许访问」没用或根本不弹

存储权限是导入一切素材的前提，弹窗被拒后应用一般不会再主动弹第二次。补救路径：

1. 系统设置 → 应用管理 → 找到 amls；
2. 权限 → 存储 / 照片和视频 → 改为「允许」；
3. 回到应用重新走一遍导入。

改完仍选不到文件，多半是文件本身的问题（格式不识别、文件损坏），换一个视频试一下就能区分是权限问题还是文件问题。

## 五、素材库和本地文件的关系

amls 内置了音乐、贴纸、特效、滤镜等素材库，不占用你的存储也不需要导入，直接在对应面板里点选即可；只有你自己拍的视频、下载的音乐这类内容才需要走上面的导入流程。两层素材在时间线里用法完全一样，之后怎么编排它们，见[图层与关键帧动画.md](图层与关键帧动画.md)。
