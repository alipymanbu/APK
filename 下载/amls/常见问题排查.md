> 本篇按症状归拢 amls 的高频问题：无响应闪退、导不出视频、素材导不进、操作找不到入口，先对症状再动手。

amls 的故障大多能按「什么时候出的问题」归到四类：打开就崩、编辑中卡、导出失败、素材导不进。逐条对症状处理。

## 一、打开就无响应或闪退

常见原因有两个：

| 原因 | 判断 | 处理 |
| --- | --- | --- |
| 版本过旧 | 用的不是近期版本，或旧版在部分机型上有已知闪退 | 更新到新版本再打开 |
| 设备不兼容 | 系统版本或硬件低于要求 | 核对系统版本；依然崩溃就换一台设备验证 |

另外两件值得先做的事：重启手机（清掉被占死的内存），以及关掉全部后台应用再单独打开 amls。装不上、装完打不开这类安装阶段的问题，见[下载与安装教程.md](下载与安装教程.md)。

## 二、编辑中卡顿、预览掉帧

图层式剪辑的卡顿基本都和「同时在算的东西太多」有关：

- 特效叠了很多层（模糊、发光这类最吃性能），先关掉几个看预览是否恢复；
- 图层多、工程长，把做好的片段合并或拆成多个工程分段剪；
- 后台挂着重型应用，清后台；
- 手机发热明显时性能会主动降档，凉一会儿再剪。

## 三、导出失败

先按这个表对症状：

| 症状 | 最可能的原因 | 先做什么 |
| --- | --- | --- |
| 进度卡在开头就失败 | 存储空间不足，或工程里有素材文件已失效 | 清存储；检查时间线上有没有缺素材的占位 |
| 中途闪退 | 工程太重、内存不够 | 清后台、重启手机、减特效、降分辨率 |
| 提示编码 / 格式错误 | 导出参数超出设备能力 | 换默认参数或降低分辨率、帧率 |
| 特别慢，最后失败 | 分辨率或时长超出设备负荷 | 降参数，或分段导出再拼 |
| 导成功了但画面糊 | 分辨率或码率选低了 | 用更高参数重导一遍，参数参考[导出视频与GIF.md](导出视频与GIF.md) |

反复失败的工程，换个思路：先把参数降到最低档导一次，能成说明是参数问题，再逐档往上调，找到你这台设备的上限。崩溃反复出现时，还可以在系统设置的应用信息里「清除缓存」再试——注意只清缓存，别点「清除数据」，工程会跟着没。

## 四、素材导不进

- **点导入没反应 / 提示无权限**：存储权限被拒过，到系统设置 → 应用 → amls → 权限里补开，详见[创建工程与导入素材.md](创建工程与导入素材.md)；
- **选了文件但加不进时间线**：换个视频试，能加说明原文件格式或编码不识别，先转码再导；
- **素材在时间线上黑屏 / 花屏**：源文件损坏，重新取一份原文件。

## 五、找不到某个设置在哪

| 想做的事 | 入口 | 详细步骤 |
| --- | --- | --- |
| 改中心点（旋转缩放的锚点） | 选中片段 → 移动和转换 → 中心点 | [图层与关键帧动画.md](图层与关键帧动画.md) |
| 改字体大小 | 选中文字 → 右上角滑块 | [字幕配音与背景音乐.md](字幕配音与背景音乐.md) |
| 抠图 | 复制图层 → 效果 → 搜「复制背景」 | [图层与关键帧动画.md](图层与关键帧动画.md) |
| 导入别人分享的模板 / 元素 | 右下角加号 → 元素，或点开工程链接 | [模板导入与元素复用.md](模板导入与元素复用.md) |
| 画面推拉运镜 | 插入相机图层 → 给相机打关键帧 | [图层与关键帧动画.md](图层与关键帧动画.md) |

界面里找不到的功能，多半藏在「笙」图标的插入面板或图层的效果浏览器里，这两个入口的用法见[创建工程与导入素材.md](创建工程与导入素材.md)。
