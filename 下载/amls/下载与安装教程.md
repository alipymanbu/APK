amls（常见写法还有 AMLs、amls剪辑、amls凉笙版）是一款安卓端视频剪辑应用，界面为中文，走图层式剪辑的路子。本篇以 2026-09-27 核对过的 5.5.7 版安装包为准，讲从拿到安装包到装好打开的完整过程。

## 一、安装包从哪拿

本篇使用的安装包放在夸克网盘：**[amls 安装文件资源（夸克网盘）](https://pan.quark.cn/s/81e811098cb0)**。

1. 打开上面的链接，把文件转存到自己的夸克网盘（推荐转存，原链接失效时不影响你已转存的文件）；
2. 在夸克网盘手机客户端里找到转存后的 `amls_v5.5.7.apk`，下载到手机本地；
3. 下载完成后，从通知栏或客户端的下载列表点开该文件，进入安装流程。

安装包体积 174.36 MB，建议在 Wi-Fi 环境下下载。

## 二、安装前核对包是不是这一份

网上同名安装包很多，版本号相近但内容可能不同。动手安装前，可以先对一眼下面这张表：

| 项目 | 值 |
| --- | --- |
| 版本号 | 5.5.7 |
| 包名 | com.AM.LiangSheng |
| 大小 | 174.36 MB |
| MD5 | C988EEE03AE89A0F6E9A888285B8B6D2 |

MD5 的用法：用文件管理器的「属性 / 校验」功能算出下载到的 apk 文件的 MD5，与表中比对。一致说明文件完整；不一致说明下载过程中文件损坏，重新下载即可。各下载渠道对开发者的标注并不统一，以你安装后应用内「设置 / 关于」页显示的为准。

## 三、安装步骤

1. 点开下载好的 `amls_v5.5.7.apk`；
2. 若系统提示「禁止安装未知来源应用」，按提示跳转到系统设置，允许当前来源（浏览器或网盘客户端）安装应用，再返回继续；
3. 等待安装进度走完，点「打开」直接进入，或稍后从桌面图标进入。

若首次打开提示登录，按界面提示注册或登录即可，流程走到编辑页之后不再有账号环节。

## 四、装不上时的排查

按提示关键词对号入座：

| 系统提示 | 多半是什么 | 处理办法 |
| --- | --- | --- |
| 解析包失败 / 安装包损坏 | 文件没下完整 | 对 MD5，不一致就重新下载 |
| 已存在同名应用、签名不一致 | 手机里装过别处下载的 amls | 先卸载旧的再装，工程数据会一并清掉，先导出重要项目 |
| 存储空间不足 | 安装包 174 MB，安装过程还需要额外余量 | 清出空间再装 |
| 一直转圈 / 卡在安装中 | 后台占用或安装器临时故障 | 重启手机后再装一次 |

各下载渠道对最低安卓版本的标注不一致（从 4.0 到 5.2 都有），能不能装以系统安装时的提示为准；能装但跑不动的情况，见[常见问题排查.md](常见问题排查.md)。

## 五、装好后的第一件事

第一次打开 amls 会请求存储访问权限。这个权限直接决定你能不能把手机里的视频、音乐导进工程，建议在弹窗时直接允许；当时点了拒绝，也可以到系统设置的应用权限里补开。具体怎么用它导入素材，见[创建工程与导入素材.md](创建工程与导入素材.md)。
