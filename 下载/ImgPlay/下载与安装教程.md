## 一、ImgPlay 是什么

ImgPlay 是 ImgBase, Inc. 出品的 GIF / 动图制作应用：把相册里的视频片段或多张照片转成 GIF，也能对已有的 GIF 再编辑。官网在 [app.imgplay.net](https://app.imgplay.net/)，同一套玩法还有 iPhone / iPad 版（App Store 搜 ImgPlay，官方标注「App 内购买」）。

本篇对应的是这份安卓安装包，它的信息如下（是这份包自己的事实；官方渠道后来更新的版本可能与此不同）：

| 项目 | 内容 |
| --- | --- |
| 应用名称 | ImgPlay - GIF Maker |
| 安装包版本 | 1.3.20 |
| 包名 | me.imgbase.imgplay.android |
| 安装包大小 | 约 107.47M |
| MD5 | 3B060F8636C5CED3EAF3A41AC8945118 |
| 开发者 | ImgBase, Inc. |

对系统版本的要求：第三方渠道对相近版本的标注从 Android 5.0 到 7.1 不等，以你设备实际安装为准；装不上时优先检查剩余存储空间（安装包本身就有一百多 MB，安装过程还要额外占一份临时空间）。

## 二、下载步骤

1. 打开 [ImgPlay 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a8501940dd77)；
2. 转存到自己的夸克网盘后用手机端下载，或直接在网盘内点开 APK 文件选择下载；
3. 下载完成后从通知栏，或夸克 App 的「传输 / 下载」列表里点开这个 APK。

## 三、安装步骤与可能遇到的拦截

1. 点开 APK 后系统会询问是否安装，点「安装」；
2. 部分手机先弹「禁止安装未知来源应用」：按提示跳到系统设置，给夸克 App（或你用来下载的浏览器）开「允许安装未知应用」，再返回重试；
3. 装完桌面会多一个 ImgPlay 图标，首次打开会依次申请权限（下一节）。

如果安装包被手机管家标记，先核对上表的 MD5 与你下载到的文件一致（用文件管理器自带或第三方的校验工具），一致再决定是否继续。

## 四、第一次打开要给的权限

按官方权限说明，这几项都会用到：

- **相机**：拍视频来做 GIF 或视频；
- **麦克风**：录音用（导出带声音的视频时需要）；
- **存储空间**：读相册里的照片 / 视频 / GIF，成品也保存回相册。

其中存储权限最不能省：拒绝它会导致素材列表为空、成品存不进相册。误拒了也不用手忙脚乱，到系统设置 → 应用 → ImgPlay → 权限里补开即可（更多权限相关的问题见 [常见问题解答.md](常见问题解答.md)）。

## 五、装好之后从哪开始

最常用的两条路：拿一段视频截出精彩几秒做成 GIF，或多张照片连播成动图，分别见 [视频转GIF图文步骤.md](视频转GIF图文步骤.md) 与 [照片合成GIF方法.md](照片合成GIF方法.md)；保存时的格式、分辨率、水印等设置集中在 [导出格式与画质设置.md](导出格式与画质设置.md)。

先说清免费与付费的边界，免得用起来意外：免费版能完成从导入到导出的全流程，导出内容带 ImgPlay 水印；去水印等增强项在 Pro 订阅里，是否值得买见 [导出格式与画质设置.md](导出格式与画质设置.md) 的说明。
