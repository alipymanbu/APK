## 一、GIF 还是视频：先看发到哪

| 去向 | 建议 | 原因 |
| --- | --- | --- |
| 微信 / QQ 聊天窗口、表情收藏 | GIF | 收藏为表情后能循环播放 |
| 朋友圈 / 抖音 / 小红书 | 视频 | 这些平台把 GIF 当静态图处理 |
| Twitter / 微博 | GIF 或视频都行 | 两者都能动 |
| 论坛、博客的贴图位 | GIF | 直接贴上去就动 |

官方帮助中心明确说明：**去掉水印的功能只在 ImgPlay Pro（订阅版）里提供**，免费版导出的 GIF 和视频会带 ImgPlay 标识。iOS 端的 Pro 按周 / 月 / 年订阅，也有一次买断的档位（价格以应用内页面为准）；安卓端的内购表现以你手头版本实际显示为准。Pro 还解锁自定义贴纸、文字与贴纸动画、更多滤镜和异形画布等，但**不改变 GIF 画质上限**（下一节）。

先导一张看水印位置和大小再决定要不要付费；处理「发出去不动」的问题不需要 Pro，见 [GIF发微信不动的解决办法.md](GIF发微信不动的解决办法.md)。

## 二、分辨率三档怎么选

官方描述里保存到相册支持低、中、高三档分辨率：

| 档位 | 体积 | 适合 |
| --- | --- | --- |
| 低 | 最小 | 表情包、贴图 |
| 中 | 居中 | 日常发聊天软件的默认选择 |
| 高 | 最大 | 发微博 / Twitter 这类压缩不狠的平台 |

同样内容三档导出来的体积可能差好几倍，表情包类选低或中即可。

## 三、对画质的预期：GIF 格式有上限

官方帮助中心有一篇专门的说明：把视频转成 GIF 后清晰度不如原视频，**这是 GIF 格式本身的限制**（颜色数与压缩方式所致），Pro 订阅也改变不了。所以：

- 素材尽量选画面简单的（人物动作、纯色背景）——复杂纹理场景的 GIF 糊得最明显；
- 别拿高清视频转 GIF 再抱怨画质，要求清晰就导出视频格式；
- iOS 版还支持导出 APNG、WebP 两种动图格式（官方 App Store 描述），画质与色彩表现比 GIF 好，但只在支持这两种格式的场景里用得上；安卓版可选哪些格式以实际导出界面为准。

## 四、文件体积的取舍

GIF 的体积随三件事涨：分辨率、帧数（时长 × 速度）、画面颜色复杂度。压体积按这个顺序动：

1. 先降分辨率；
2. 再缩短时长 / 减少照片数；
3. 还超就改导出视频——GIF 本身不是省体积的格式，超得厉害时视频格式对同等内容友好得多。

官方帮助中心 [imgplay.zendesk.com](https://imgplay.zendesk.com) 有「按目标体积保存 GIF」的说明（面向 iPhone / iPad 版，提到 250KB、500KB、1MB、2MB、5MB、10MB、20MB 等目标档位）；安卓版有没有对应入口，以你手头版本的实际界面为准。

## 五、「重复保存成视频」的用法

官方描述里有个专门选项：保存为视频时可把同一内容重复若干遍。用途是——某些平台不支持 GIF 但支持视频，把内容重复 3~5 遍存成视频发过去，看起来就像循环播放的动图。发微信不动、朋友圈发 GIF 定住的场景都用得上它，具体排查见 [GIF发微信不动的解决办法.md](GIF发微信不动的解决办法.md)。

## 六、循环次数与播放方向

导出前的设置里还能控制循环行为：无限循环或固定次数（次数选项以你版本的界面为准），以及正向 / 倒放 / 来回三种方向，具体调法见 [视频转GIF图文步骤.md](视频转GIF图文步骤.md) 第五节。

发出去之后发现不动、变形或被压得没法看，对照 [常见问题解答.md](常见问题解答.md) 逐条排查。
