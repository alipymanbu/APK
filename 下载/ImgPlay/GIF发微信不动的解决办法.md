# GIF 发微信不动的解决办法

> 微信里发 GIF 变静态图、对方看不到动画的几种原因与对应做法：收藏成表情、勾原图、压体积、朋友圈改发视频。

## 一、先分清是哪种「不动」

- **发到微信才不动**：相册里预览是好的，发出去变静态图——多数是微信的处理方式问题，往下看；
- **相册里就不动**：导出的文件本身就只有一帧——回到 [视频转GIF图文步骤.md](视频转GIF图文步骤.md) 检查导出时选的是不是 GIF 格式。

## 二、最稳的办法：收藏成表情再发

多位用户验证过的路径，从聊天窗口的表情入口走，不走图片发送：

1. 聊天窗口点输入框旁的笑脸图标，切到红心（收藏）页签；
2. 点「+」，从相册里选做好的 GIF，点「使用」；
3. 回到表情页签点它发送。

这样发出去的就是可循环播放的表情动画，不经过图片压缩链路。自己常发的动图都建议走这条。

## 三、直接当图片发：记得勾「原图」

不收藏、直接在聊天窗口用「+」发图片时，选中后注意勾上**「原图」**选项再发送：

- 有第三方应用的帮助文档提到，通过系统分享面板直接发出去的 GIF，微信会把它当静态图处理、还会放大模糊；
- 勾原图能把文件原样送达，动画保留的概率大得多；
- 代价是原图体积大、费流量，文件本来就大时反而更容易触发压缩。

## 四、文件太大被压成静态图

微信对体积超限的动图会压缩或直接转静态。有用户经验给出的参考是把 GIF 控制在小几百 KB 以内，虽然具体阈值随微信版本变化，但方向一致：**越小的 GIF 越容易活着动起来**。

压体积的完整做法（降分辨率、缩时长、改视频）见 [导出格式与画质设置.md](导出格式与画质设置.md) 第四节；表情包类素材的取材建议见 [照片合成GIF方法.md](照片合成GIF方法.md)。

## 五、朋友圈不支持 GIF 动画

这是微信的既定行为：朋友圈把 GIF 收进相册图片流程，发上去就是一张静态图，不是你做错了。想在朋友圈看到动的：

- 把内容**导出成视频**再发朋友圈；
- ImgPlay 导出里有「重复保存成视频」选项，把动图重复几遍存成视频，发出来接近循环播放的效果（详见 [导出格式与画质设置.md](导出格式与画质设置.md) 第五节）。

## 六、顺手检查微信的动图开关

部分微信版本里有动图自动播放的开关：我 → 设置 → 通用 → 「照片、视频、文件和通话」，确认动图相关的自动播放选项开着。接收方如果看不到动画，也可以让对方查这一项。

## 七、还不行时的快速排查

- 对方微信版本太旧不支持大体积 GIF——让对方升级或走表情收藏路径；
- 传输中断文件不完整——删掉重发一次；
- 换 QQ 或 Telegram 发同样的 GIF 对比，QQ 对 GIF 的宽容度普遍更高，能快速判断问题在文件还是在微信。

其他常见问题（水印、闪退、权限）见 [常见问题解答.md](常见问题解答.md)。
