## 一、两者的关系

手机上只有一个 app：eDrawings 本体免费，Pro 的功能通过**应用内购买**解锁，不用装第二个应用。价格按地区不同，以 Google Play 商店内页显示为准。

## 二、功能边界

| 功能 | 免费版 | Pro |
| --- | --- | --- |
| 打开查看 2D/3D 文件 | 有 | 有 |
| 多点触控缩放、平移、旋转 | 有 | 有 |
| 动画 3D 标准视图 | 有 | 有 |
| 浏览 2D 工程图 | 有 | 有 |
| 全屏查看、双击适配屏幕 | 有 | 有 |
| 测量（距离、角度、长度、点对点等） | 无 | 有 |
| 横截面（XY / YZ / ZX 方向，可拖动） | 无 | 有 |
| 创建标记（文字注释、手绘符号） | 无 | 有 |
| 共享带标记的文件（标记历史存进文件） | 无 | 有 |

只收图看图（车间对照、给客户展示）的场景，免费版就够；需要自己量尺寸、做剖切检查内部结构、在图上圈改再发回去的人，才用得上 Pro。

## 三、升级路径

1. 打开 eDrawings；
2. 点菜单图标（右上角三个点）；
3. 选 **Upgrade to Pro**，跳转 Google Play 完成购买。

付费、退款、换机迁移都走 Google Play 的订单机制，规则以商店当时政策为准。

## 四、几个常见疑问

- **买了 Pro 换手机怎么办**：登录同一 Google 账号在商店里恢复购买，具体以商店流程为准。
- **iOS 上一样吗**：iPhone/iPad 版同样分免费与 Pro，购买走 App Store，与安卓的购买互不通用。
- **桌面版呢**：Windows/Mac 的 eDrawings Viewer 免费，Professional 单独收费，与手机版的购买互不相干。

## 五、买了 Pro 还是量不了？

测量还有一道**文件级开关**：eDrawings 文件在电脑端发布或另存时没勾「允许测量」，拿到手谁打开都量不了，跟你买没买 Pro 无关。排查步骤见 [测量功能用不了怎么办.md](测量功能用不了怎么办.md)。

反过来也有一种省钱的可能：别人用桌面版 Professional 发布的「审阅启用」文件，你用免费版就能测量和标注，先试文件再决定升级。
