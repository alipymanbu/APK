## 一、格式支持差一截

桌面版 eDrawings Viewer 除了手机版那份格式清单，还支持一批工业格式：Autodesk Inventor（.ipt / .iam）、CATIA V4 / V5（.CATPart、.CATProduct 等）、Creo / Pro/ENGINEER、ACIS（.sat）、3DXML 等，各有版本上限，以官方桌面版清单为准。

实操结论：**Inventor、CATIA、Creo 的文件手机版打不开**。想在小屏上看这类文件，先在电脑端用桌面版转成 eDrawings 文件（.easm / .eprt / .edrw）或 STEP，再传手机。手机版能开什么见 [支持哪些CAD文件格式.md](支持哪些CAD文件格式.md)。

## 二、能力对照

| 事项 | 手机版 | 桌面版 |
| --- | --- | --- |
| 常见格式看图 | 支持 | 支持 |
| Inventor / CATIA / Creo 等工业格式 | 不支持 | 支持 |
| 保存 / 转格式 | 除 SOLIDWORKS 原生格式外 | 同样不含 SOLIDWORKS 原生格式 |
| 测量 / 剖切 / 标记 | Pro（应用内购买） | Professional 单独授权 |
| 发布带密码的 eDrawings 文件 | 无 | Professional 才能发布 |
| 嵌入查看器的单文件发送 | 无 | 支持（Windows） |

两边的付费互不通用：手机版买的是 Google Play 应用内购买，桌面版 Professional 走达索渠道授权。

## 三、什么时候用哪个

- 现场核对、随手转发、给非技术同事演示 → 手机版；
- 收到冷门 CAD 格式、要把大装配转成 eDrawings 文件分发、要给文件加密码 → 桌面版（免费）或 Professional（需要密码保护、审阅启用这类发布功能时）。

桌面版同样有免费版本可下载，官方页面见 `https://www.edrawingsviewer.com`。
