## 一、能直接打开的格式清单

下表整理自官方帮助文档（SOLIDWORKS Help 的 eDrawings for Android 章节），个别格式的版本上限可能随 app 更新变化，以官方页面为准：

| 类别 | 扩展名 | 版本 / 限制 |
| --- | --- | --- |
| eDrawings 文件 | .eprt / .easm / .edrw | — |
| SOLIDWORKS 原生 | .sldprt / .sldasm / .slddrw | 零件、装配体、工程图 |
| DXF / DWG | .dxf / .dwg | — |
| STEP | .step / .stp / .stpz | AP 203 E1/E2、AP 214、AP 242 |
| IGES | .iges / .igs | 5.1 / 5.2 / 5.3 |
| JT | .jt | v10.0 及更早；不支持 PMI（产品制造信息） |
| IFC | .ifc | 建筑信息模型常用 |

其中 .stpz 是 STEP 的压缩形式，同样支持。

注意这份清单是**手机版**的：桌面版 eDrawings 支持的格式比这多一批（Inventor、CATIA、Creo、ACIS 等），所以「电脑上能开、手机上开不了」是正常现象，详见 [手机版与桌面版的差别.md](手机版与桌面版的差别.md)。

## 二、几条容易踩的版本限制

- **JT 不带 PMI**：官方明确 .jt 文件不支持产品制造信息（PMI），需要看 PMI 的别用 JT 传。
- **IGES 只列到 5.3**：5.1 / 5.2 / 5.3 之外的变体没有官方支持说法。
- **SOLIDWORKS 原生文件有版本问题**：用老版本查看器打开「更新版本 SOLIDWORKS 保存」的原生文件可能失败；遇到打不开，先核对文件的保存版本。通用格式的兜底做法见下一节。

## 三、文件从哪些渠道进手机

官方说明的打开来源覆盖了日常大部分场景：

- 电子邮件附件；
- 云存储服务（Dropbox、Google Drive、OneDrive 等）；
- 网站直链与 FTP 站点；
- 网络文件夹（局域网共享）。

实操里最稳的一条路：电脑端把模型另存为 STEP 或 IGES 这类通用中性格式再传手机，绕开原生文件的版本问题。走邮件附件的，发送前留意别让邮箱或传输工具改掉扩展名，改回去就能打开。

## 四、打不开时的核对顺序

1. 扩展名在不在上面的清单里（传输过程有时会把扩展名弄丢或改掉）；
2. 文件是否完整传到了手机（大模型传输中断并不少见）；
3. 原生文件的话，核对保存它的 SOLIDWORKS 版本是否比查看器新；
4. 都没问题还打不开，换 STEP 通用格式重转一遍再试。

安装与首次启动的问题见 [下载与安装教程.md](下载与安装教程.md)。
