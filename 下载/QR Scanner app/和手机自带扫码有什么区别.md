## 一、先说结论

自带相机解决的是「偶尔扫一下」：餐厅菜单、WiFi 连网这种一次性的 QR 码。一旦你要扫的是条形码、要把结果留档、或在暗光/远距离下扫，专用应用（如 QR Scanner app 这类）补的就是这几块。下面的对照按第三方实测口径整理。

## 二、自带相机能干什么、干不了什么

| 能力 | 自带相机 | 说明 |
| --- | --- | --- |
| 扫普通 QR 码 | 能 | 对准出通知，点开即走 |
| 扫商品条码（EAN/UPC） | 多数不行 | 部分厂商只在自家地区或特定机型开放，型号差异大 |
| 扫 Code 39、Data Matrix、PDF417 等工业码 | 基本不行 | 这些是专用扫描器的主场 |
| 历史记录 | 无 | 扫完关掉就没了 |
| 导出整理 | 无 | 更谈不上 CSV |
| 褪色/倾斜/低对比度的码 | 容易失败 | 专用应用有补光、缩放和更强的解码兜底 |
| 打开链接 | 需要联网 | 离线场景（仓库、地下室）不适合 |

以上为第三方整理的普遍口径；各品牌相机集成程度不同，你的手机实际支持哪些，拿一张条码试一下最直接。

## 三、专用应用补上的几件事

1. **码型覆盖**：QR 之外还有 Data Matrix、Aztec、EAN、UPC、Code 39/93/128、ITF、PDF417、GS1 DataBar，完整清单见[扫码方法与支持的码型.md](扫码方法与支持的码型.md)；
2. **记录与整理**：每扫必记，可搜索、可加备注、可导出 CSV，具体用法在[扫描历史导出与库存管理.md](扫描历史导出与库存管理.md)；
3. **扫码后的动作**：连 WiFi、存联系人、加日历这类一步到位，不用再手动转一道；
4. **链接安全**：专业扫码器普遍在内置标签里打开网址并接入安全检查（QR Scanner app 用的是带 Google Safe Browsing 的 Chrome Custom Tabs）；
5. **环境适应性**：手电筒补光、双指缩放，暗光与小码的成功率明显高于裸相机。

## 四、怎么选

- 每月扫码不到几次、只扫菜单和 WiFi：不用装，自带相机够了；
- 每周都要扫、或扫完要找回记录：值得装一个专用的；
- 要扫商品条码查价、做盘点台账：直接上专用的，历史与导出是刚需。
