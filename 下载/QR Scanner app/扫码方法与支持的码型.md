## 一、先说结论

你有两条路把码喂给它：对着摄像头扫，或者把已有图片交给它识别。常规的二维码和商品条码都能处理，扫码内容不同，它会给出对应的后续动作——网址就打开、WiFi 码就问你要不要连、名片码就能存联系人。

## 二、摄像头扫码

1. 打开应用，默认就是取景界面，把镜头对准码即可，识别成功会自动出结果，不需要按快门。
2. **距离**：条码贴太近反而难对焦，离 10~20 厘米更容易一次成功。
3. **暗处**：点手电筒图标补光，反光的塑封码可以稍微斜一点角度避开反光。
4. **远距小码**：双指捏合缩放镜头，把码放大到取景框中央，识别成功率明显提高。

## 三、从相册图片识别

朋友发来的截图、拍下来的海报码，不用再对着屏幕翻拍：

1. 在应用里选从图片/相册识别的入口；
2. 选中那张图，它会自动找出图里的码并给出内容；
3. 截图分辨率太低、码只占画面一角时识别率会下降，可以先把截图裁剪一下再试。

## 四、扫码后会给你什么动作

扫出内容的类型不同，界面上给出的可执行动作也不同：

| 扫到的内容 | 你能直接做的事 |
| --- | --- |
| 网址（URL） | 打开网页；链接在内置的安全浏览标签中打开，见常见问题篇的安全说明 |
| WiFi 热点信息 | 弹出该网络的名称与密码，确认后直接连入 |
| 联系人（MeCard / vCard / vcf） | 存入通讯录 |
| 日历事件 | 添加到系统日历 |
| 地理位置 | 打开地图查看位置 |
| 电话号码 | 直接拨打 |
| 邮箱 / 短信 / MATMSG | 唤起邮件或短信编辑 |
| 商品条码（EAN、UPC 等） | 查商品与价格信息，也可在自定义的网站里搜 |

## 五、它认得哪些码

**二维码（2D）：**

- QR 码：网址、文本、联系人（MeCard、vCard、vcf）、日历事件、WiFi 接入信息、地理位置、电话、邮箱、短信（SMS、MATMSG）

**条形码（1D）与其他二维码：**

| 类型 | 常见用途 |
| --- | --- |
| EAN-13 / EAN-8、UPC-A / UPC-E、JAN、GTIN、ISBN | 商品条码、书号 |
| Code 39 / Code 93 / Code 128 | 物流与工业标签 |
| Codabar | 图书馆、血库标签 |
| Interleaved 2 of 5（ITF） | 包装箱外箱条码 |
| PDF417 | 火车票、证件上的堆叠式码 |
| GS1 DataBar（RSS-14） | 生鲜与优惠券条码 |
| Data Matrix | 零部件小码 |
| Aztec Code | 登机牌、电子票 |

- 扫完的历史都留在记录里，隔天要回查或者要导出表格，看[扫描历史导出与库存管理.md](扫描历史导出与库存管理.md)。
- 想把自己的一条链接、一张名片变成二维码让别人扫，不用另装生成器，见[生成二维码与分享方法.md](生成二维码与分享方法.md)。
- 反复扫不出某一种码时，对照[扫码失败与常见问题排查.md](扫码失败与常见问题排查.md)逐项排查，先确认是不是码型本身超出了上表范围。
