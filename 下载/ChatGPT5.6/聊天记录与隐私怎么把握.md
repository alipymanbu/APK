隐私相关的选项不止一个，而且分散在不同位置，很容易只关了一半。下面按「默认是什么 → 怎么改 → 改完有什么后果」三层写，开关位置以官方帮助中心的说明为准，你机器上的入口位置可能略有差异。

## 一、默认状态是什么

先分清自己属于哪一类账号，两类账号的默认口径不一样：

| 账号类型 | 默认是否用你的内容改进模型 |
| --- | --- |
| 个人版：免费版、Plus、Pro | 默认开启数据共享，也就是会用于改进模型，需要自己关 |
| Business、Enterprise、Edu 与 API | 默认不用于训练 |

所以个人版用户要主动做一次设置，企业或学校发的账号通常不用管这一项。

## 二、关掉「用于改进模型」

个人版关掉数据共享的路径（官方帮助中心给出的写法）：

- **移动端**：打开侧边栏 → 点个人资料图标 → 数据控制 → 关闭「为所有用户改进模型」；
- **网页端**：点个人资料图标 → 设置 → 数据控制 → 关闭同一个开关。

三个要注意的点：

1. **改一次全设备生效**。这是账号级设置，不必在每台手机上重复关。
2. **只对之后的新对话生效**。已经发生的对话不会因为你现在关了就退出训练范围，介意的话要连同历史一起处理。
3. **语音是单独的一项**。语音模式下的数据用于训练的开关，是独立设置项，别只关文字那一个。语音侧的完整说明见 [语音对话与实时翻译怎么用.md](语音对话与实时翻译怎么用.md)。

## 三、临时聊天：不留在记录里的那一种

需要聊敏感内容时，与其事后清理，不如一开始就用临时聊天。它的行为是明确的：

| 项目 | 临时聊天的行为 |
| --- | --- |
| 是否进聊天历史 | 不进，侧边栏里找不到 |
| 是否用于训练模型 | 不用于训练 |
| 是否创建记忆 | 不创建，也不会读取已有记忆（你可以在开始时选择用或不用） |
| 保留多久 | 30 天后从系统中删除 |
| 会不会被人看 | 仅在被用于监控滥用时会审查 |
| 想留住怎么办 | 手动把它保存为普通对话，保存后就按普通对话的规则处理 |

一句话：**要留档就用普通对话，不想留就用临时聊天**，别用普通对话聊完再想着删干净。

## 四、记忆：它记住了什么，能查到吗

记忆功能会让它在不同对话之间记住你的偏好与背景，好处是不用每次重复交代。可控的部分有三项：

- **能查**：已保存的记忆条目可以逐条查看；
- **能改能删**：对记错的内容直接删掉或改掉；
- **能整体关闭**：不想让它跨对话记忆，把功能关掉即可。

需要提醒的是：关闭记忆不等于关闭安全机制。在高风险场景下，系统仍可能使用有限的安全相关上下文来给出更稳妥的回答，这与记忆是两回事。

## 五、位置权限要不要给

分享精确位置的作用是让回答更贴合你所在地（本地天气、附近地点这类）。不给也能正常用，只是本地化建议会变粗。在系统权限里随时可以关掉，应用内的位置开关也独立存在。

## 六、导出、删除与注销的后果

| 你要做的事 | 在哪做 | 后果 |
| --- | --- | --- |
| 导出全部数据 | 个人资料 → 数据控制 → 导出数据 | 压缩包发到注册邮箱，下载链接 24 小时后失效 |
| 删除单个对话 | 打开该对话 → 竖向三点 → 删除 | 只删这一条，其它记录不受影响 |
| 删除全部对话 | 数据控制里选择删除全部对话 | 本机与账号下的记录一并清掉，不可恢复 |
| 注销账号 | 数据控制 → 删除账号 | 不可逆：该账号不能再登任何服务，同一邮箱也不能再注册，数据 30 天内删除 |

注销之前，先按上一节把要留的数据导出拿到手，再动手。注销与找回的具体入口在 [登录与账号问题排查.md](登录与账号问题排查.md) 里另有说明。

## 七、给敏感内容的四条实操建议

- **合同、病历、身份证号这类内容**：用临时聊天，且不要上传原始扫描件，能描述就描述；
- **公司内部资料**：先用公司账号的规则确认能不能传，个人版账号上传工作文件要格外谨慎；
- **想彻底不复现**：删对话之外，还要把「用于改进模型」关掉，两件事是分开的；
- **设备层面的保护**：给应用加一道系统级的应用锁或生物识别，比只在应用内退出登录更实在。

聊天记录突然不见了、换机之后对不上，这类属于数据同步问题，不在隐私设置里，走 [常见问题与排查.md](常见问题与排查.md)。
