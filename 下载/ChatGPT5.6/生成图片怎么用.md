生成图片不需要另开一个应用，就在同一个对话里说清楚要什么。它出的图可以直接保存到相册；真正决定成败的是描述够不够具体，以及你有没有按「一次改一点」的节奏去改。

## 一、让它出图的最小写法

一句话就够，但要包含三样东西：**画什么 + 什么风格 + 什么比例**。例如：

```text
画一只橘猫趴在窗台上晒太阳，插画风格，横构图 16:9
```

想更接近你想要的样子，可以再加参考：直接把一张图发给它，说「照这个构图，把主体换成……」。文字可以描述的东西里，下面这几项对结果影响最大：

| 要交代的 | 可以怎么写 |
| --- | --- |
| 主体 | 画的是什么、在做什么、几个人或几只 |
| 场景 | 室内还是室外、什么时间、什么天气 |
| 风格 | 插画、写实照片、水彩、像素风、3D 渲染 |
| 光线 | 逆光、暖色调、影棚光、黄昏 |
| 构图与比例 | 全身还是特写、横构图 16:9 还是竖构图 9:16 |
| 尺寸用途 | 手机壁纸、公众号头图、头像（方形） |

比例一定要写。同一段描述，横构图和竖构图出来的可用性完全不同，尤其是要当壁纸或封面用时。

## 二、改图：一次只改一个点

出图很少一次就完全满意，稳妥的做法是**在上一张的基础上迭代**，而不是重写一整段新描述：

1. 先对整张图说一句总体评价，例如「整体可以，但背景太满」；
2. 只提**一处**要改的，例如「把背景换成纯色浅灰，主体不动」；
3. 改好再提下一处。

一次提五处修改，结果往往是整张图重画、之前满意的部分也没了。如果确实需要大改，直接开一段新描述更省事。

## 三、保存与分享

- 生成完成后长按图片保存到相册；**存不下来多半是应用没有存储权限**，去系统设置里补上再试；
- 用微信、飞书之类的应用分享时，注意对方看到的压缩版本会掉画质，需要原图就用文件方式发送；
- 生成的图要用于公开场合之前，自己核一遍有没有问题 —— 文字、手部、物体数量这几处最容易出错。

## 四、图出不来的常见原因

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示无法生成、被拒绝 | 请求触碰了内容限制（例如涉及真人肖像、他人作品、品牌标识） | 换成不涉及这些元素的描述再试 |
| 一直停在生成中 | 网络中断或服务端忙 | 确认网络正常，隔几分钟重试，别连着点 |
| 生成成功但保存失败 | 存储权限没给，或空间不足 | 补权限、清空间后重新保存 |
| 出来的图跟描述差距大 | 描述太笼统，或一次塞了太多要求 | 按第一节的表格把主体、风格、比例分开写清 |
| 反复失败后一直失败 | 短时间内重试太密 | 停一会儿再试，连着重试通常只会继续失败 |

生图与对话的消耗不是同一个口径，反复失败时先把描述改好、再发一次，比按原样重发三次更省。

## 五、用之前先知道的几点

- **它不是绘图软件的替代品**：需要精确尺寸、精确排版、可控图层的活，仍然要放到专业工具里做；
- **文字渲染会出错**：要求图里出现具体文字时，拼错、多字、少字都很常见，重要的文字建议生成后自己贴上去；
- **同一段描述每次结果都不一样**：这是正常的，想复现某一次的效果，最好把当时那段描述和你发过的参考图一起保存下来；
- **涉及真人肖像与版权素材**：生成前先确认你对该素材有使用授权，涉及可识别真人的请求容易被拦下。

图片保存、权限这类操作层面的问题如果反复出现，按 [常见问题与排查.md](常见问题与排查.md) 往下排；回答本身很慢、等待时间太长，先看 [模型怎么选与思考级别.md](模型怎么选与思考级别.md) 里的档位说明。
