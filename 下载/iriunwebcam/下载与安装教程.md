## 一、先弄清：为什么要装两个东西

你在手机上装的那个 Iriun Webcam App 负责采集摄像头画面，电脑上装的客户端负责把画面变成一个系统能识别的虚拟摄像头设备。Zoom、OBS 这些软件认的其实是电脑端虚拟出来的那个摄像头，所以两端缺一不可。

两端都来自同一个开发者（Iriun）。手机端 App 在 Google Play 和 App Store 上叫 Iriun Webcam；电脑端客户端从官网下载。

## 二、电脑端：按系统下载对应客户端

官网（`https://iriun.com`）提供三个平台的安装包，版本号各自独立更新，下表是各平台当前的版本与系统要求（以官网当时显示为准）：

| 平台 | 安装包 | 系统要求 |
| --- | --- | --- |
| Windows | `IriunWebcam-x.x.x.exe` | Windows 7 及以上 |
| macOS | `IriunWebcam-x.x.x.pkg` | macOS 12.3 及以上（旧版 macOS 有单独的旧驱动包，官网有链接） |
| Linux | `iriunwebcam-x.x.x.deb`（另有 Beta 版 RPM 包） | Ubuntu 22.04 及以上 |

安装注意两点：

1. Windows 客户端安装时会装一个虚拟摄像头驱动，Windows SmartScreen 或杀毒软件可能弹提示（虚拟摄像头软件的常见情况），在安装包上选「更多信息 → 仍要运行」即可继续。
2. 装完先打开一次 Iriun Webcam 客户端，让它保持在后台运行——手机连不上时第一件事就是检查电脑端是不是没开。

## 三、手机端：两种安装途径

### 途径 A：应用商店直接装

- **Android**：Google Play 搜 Iriun Webcam（开发者 Iriun），安装后约 6 MB 量级，占用很小。
- **iOS**：App Store 搜 Iriun Webcam for PC and Mac。

手机端对系统版本要求不高：Android 5.0 及以上、iOS 11 上下即可（不同资料的口径略有出入，以应用商店页面标注为准）。商店版会随官方更新自动升级，是大多数人的选择。

### 途径 B：用网盘里的安装包（适合手机没有 Google 服务的情况）

国内 Android 手机大多没有预装 Google Play，这时可以从网盘直接拿 APK 安装。本文提供的 iriunwebcam 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/536793716745](https://pan.quark.cn/s/536793716745) 里是 Android 端 APK，转存后下载到手机安装即可。

这份 APK 的核对信息如下，供你确认下到的是哪一版：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.9.1 |
| 包名 | com.jacksoftw.webcam |
| 大小 | 6.16 MB |
| MD5 | 99CD9856B7A527A4BF0E92C4B36D49C3 |

安装前在系统设置里允许「从此来源安装应用」（各品牌手机的叫法略有差异，一般在安装时弹窗里直接授权）。安装完成后首次打开会请求摄像头、麦克风和局域网权限，都允许掉，否则连不上电脑。

## 四、装完后的第一次连接自测

1. 电脑上打开 Iriun Webcam 客户端，让它开着。
2. 手机打开 Iriun Webcam App。
3. 两台设备在同一个 WiFi 下时，手机画面会自动出现在电脑客户端窗口里——不用手动配对、不用输 IP。
4. 看到画面后，在 Zoom 或 OBS 里把摄像头切到 Iriun Webcam 验证一下（具体设置路径见 [OBS与视频会议软件调用教程.md](OBS与视频会议软件调用教程.md)）。

如果第 3 步没反应，大概率是网络环境问题而不是安装问题，按 [画面延迟与连接失败排查.md](画面延迟与连接失败排查.md) 的顺序排查；不想走 WiFi 的也可以直接插 USB 线连，操作见 [WiFi与USB连接方法.md](WiFi与USB连接方法.md)。
