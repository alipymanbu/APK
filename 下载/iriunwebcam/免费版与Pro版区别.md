> Iriun Webcam 手机端分免费版和 Pro 版，核心功能（连接、传输、4K）两个版本都有，差别集中在水印、手动参数和广告上。本篇列出具体分界，帮你判断要不要买 Pro。

## 一、功能分界对照表

按官方应用商店页面的说明（以商店当前显示为准）：

| 功能 | 免费版 | Pro 版 |
| --- | --- | --- |
| WiFi / USB 连接电脑 | 有 | 有 |
| 最高 4K 分辨率（上限取决于手机机型） | 有 | 有 |
| 息屏继续输出画面 | 有 | 有 |
| 双指变焦、镜像 | 有 | 有 |
| 画面水印 | 有 | 无 |
| 手动调 ISO、曝光、白平衡 | 无 | 有 |
| 在电脑端远程控制手机摄像头 | 无 | 有 |
| 广告 | 有 | 无 |

也就是说，免费版已经能完成「手机变摄像头」的全部基本动作；Pro 买的是画质控制和干净的输出。

顺带提醒一句网上流传的分辨率说法：部分第三方资料写「免费版限 720p / 480p」，这与官方应用商店页面「免费版即支持最高 4K」的口径对不上，而且这类对比内容不少出自竞品的推广站。装好后以你手机端设置里实际能选到的分辨率选项为准。

## 二、免费版的两条限制，什么场景下会硌手

1. **水印**：免费版输出的画面带水印。自己开会、网课基本无感；但要是把画面录进课程、直播推流给观众，水印就一直挂在画面上。
2. **广告**：手机端 App 内有广告，连接过程偶尔会被打断一下，不影响已经建立的画面传输。

## 三、Pro 版买回来的三样东西

- **去水印、去广告**：输出画面干净，适合录课、直播、做视频素材。
- **手动参数**：ISO、曝光、白平衡可以在手机端手动调。逆光场景锁定曝光、灯光偏色时校白平衡，画面可控性明显不同——这是 Pro 对画质影响最大的部分。
- **电脑端远程控制**：手机架在远处当机位时，不用走到手机跟前，在电脑上就能调整摄像头。

## 四、按场景判断要不要买

| 你的用法 | 建议 |
| --- | --- |
| 偶尔开会、网课用一下 | 免费版够用 |
| 拿它监看（比如盯 3D 打印机、看门口） | 免费版够用，水印无影响 |
| 直播推流 / 录制课程视频 | 值得买 Pro，水印会一直出现在成品里 |
| 逆光、复杂灯光环境下追求画质 | Pro 的手动参数是主要卖点 |

Pro 是一次性买断制，在手机端 App 内升级，价格以应用商店当时显示为准（有用户 2025 年 10 月的购买记录为 5.49 美元一档，仅供参考）。买断意味着后续更新不用再付费，区别于按月订阅的那类摄像头应用。

## 五、升级前先确认的一件事

Pro 是手机端 App 内的升级，与电脑端客户端无关。先按 [下载与安装教程.md](下载与安装教程.md) 把两端跑通、确认你的手机型号在电脑端能正常出画面，再决定要不要付费——画质上限取决于手机摄像头本身，App 侧的付费改变不了硬件。
