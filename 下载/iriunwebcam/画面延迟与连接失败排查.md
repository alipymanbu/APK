# Iriun Webcam 连不上、没画面、卡顿的排查方法

> 手机和电脑互相搜不到、软件列表里没有 Iriun Webcam、画面卡顿掉帧——这三类是使用中最常碰到的问题，本篇按「从哪查起」的顺序给出排查步骤。

## 一、手机和电脑互相搜不到

按这个顺序查：

1. **电脑端客户端开了没有**。它必须在运行中，手机才连得上。这是最常见的原因，先开客户端再看。手机端如果报「Please start Iriun Webcam」，说的就是这件事——先开电脑端、等它进入等待连接状态，再开手机 App。
2. **两端在不在同一个网络**。手机用移动数据、电脑用宽带，这种组合连不了；手机和电脑必须同处一个局域网（WiFi 或手机开热点给电脑都行）。
3. **路由器有没有开 AP 隔离**。公司网络、酒店 WiFi、路由器的访客网络常开「AP 隔离 / 客户端隔离」，设备之间互相不可见——表现就是永远搜不到。换手机热点或家庭网络验证。
4. **Windows 防火墙**。第一次运行客户端时如果点了「取消」拦截，局域网连接会被挡。到 Windows 防火墙的「允许应用通过防火墙」列表里勾上 Iriun Webcam（专用和公用都勾）。
5. 都不行就把两端 App / 客户端都关掉重开一次，或把手机 WiFi 断开重连。

另一种表现是**能连上但几秒内就断开**：多为 WiFi 不稳，先挪近路由器、连 5GHz 频段试一次，还不行就直接换 USB。

急用时直接改走 USB：插线 + 开 USB 调试，绕开所有网络问题，步骤见 [WiFi与USB连接方法.md](WiFi与USB连接方法.md)。

## 二、软件摄像头列表里没有 Iriun Webcam

手机明明连上了，Zoom / OBS 的摄像头下拉里却找不到 Iriun Webcam：

1. **先开客户端、再开会议软件**。设备列表在软件启动时加载，顺序反了就刷不出来——把 Zoom / OBS / Teams 关掉重开一次。
2. **重启电脑**。刚装完客户端驱动的情况下，虚拟摄像头有时要重启一次才完成注册。
3. **确认连接还活着**。电脑客户端窗口里能看到手机画面，才说明链路是通的；看不到画面说明断在连接层，回到第一节排查。
4. **列表里有、点开却是黑屏**：先查 Windows 相机隐私权限——设置 → 隐私 → 相机，把「允许应用访问相机」打开；再排查是不是被其他正在用摄像头的程序占用（见 [OBS与视频会议软件调用教程.md](OBS与视频会议软件调用教程.md) 第五节）。

## 三、USB 连接异常

- **插了线没反应**：检查数据线是否支持数据传输（纯充电线不行），换一根线试；Android 手机的 USB 调试开了没有。
- **连接断断续续**：有用户反馈把手机 WiFi 彻底关掉后 USB 连接就稳定了，两个通道同时在线会互相干扰；换 USB 3.0 级别的线也有帮助。
- **手机反复弹授权**：开发者选项里关闭「撤销 USB 调试授权」再重新插拔，重新授权一次。

## 四、画面卡顿、延迟高

1. **WiFi 场景先换频段**：2.4GHz 拥挤时延迟波动大，手机和电脑都连 5GHz 频段；路由器太远就拉近。
2. **降低分辨率**：分辨率越高对传输带宽要求越高，卡顿时在手机端把分辨率调低一档。
3. **直接换 USB**：USB 传输不占网络带宽，延迟通常更低也更稳，长时间使用推荐。
4. **关掉电脑上的其他大流量任务**（网盘同步、下载），它们挤占 WiFi 带宽。

## 五、画质相关问题

| 现象 | 原因与处理 |
| --- | --- |
| 画面比预期模糊 | 检查手机镜头有没有脏污/贴膜起泡；对焦模式切换一下（点一下手机屏幕触发对焦） |
| 分辨率到不了 4K | 4K 上限取决于手机机型，不是所有手机都支持，属于硬件限制 |
| 画面偏色、逆光死黑 | 免费版没有手动参数，只能调整拍摄角度或环境光；Pro 版可手动调 ISO / 曝光 / 白平衡（见 [免费版与Pro版区别.md](免费版与Pro版区别.md)） |
| 画面镜像反了（写字反着） | 在手机端设置里开/关镜像翻转即可 |
| 手机掉电特别快 | 持续传视频本身耗电就大；插着线用（USB 模式边传边充），不用时把 App 退干净 |

## 六、还不行的兜底动作

按顺序做一遍：两端都退出重开 → 换一种连接方式（WiFi 换 USB 或反之）→ 重启电脑。三步之后仍不行的，去官网（`https://iriun.com`）看看版本更新说明——个别版本组合存在已知 bug，更新到两端最新版往往直接解决。
