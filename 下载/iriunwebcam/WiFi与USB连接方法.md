# Iriun Webcam 的 WiFi 与 USB 两种连接方法

> 手机和电脑之间走 WiFi 还是插 USB 线，两种方式 Iriun Webcam 都支持，操作和适用场景不同。本篇分别讲清两种连法的步骤、前提条件和怎么选。

## 一、两种连法共同的前提

不管走 WiFi 还是 USB，都要满足两条：

1. 电脑端 Iriun Webcam 客户端**已经打开**并在运行——它是接收画面的一端，没开手机连什么都没用。
2. 手机端 App 的摄像头权限已授予。

满足之后，两种方式都是**自动连接**，没有手动输 IP、扫码之类的步骤。

## 二、WiFi 无线连接（默认方式）

1. 确认手机和电脑连的是**同一个路由器**下的网络（家庭宽带、手机热点都行）。
2. 电脑打开 Iriun Webcam 客户端。
3. 手机打开 Iriun Webcam App，它会自动扫描局域网并连上电脑，几秒内电脑端窗口就会出现手机摄像头的画面。

WiFi 方式下手机不占数据线，可以摆到离电脑很远的位置当独立机位，直播时俯拍桌面、当第二机位都很方便。

需要注意的坑：

- 办公室或公共网络里，很多路由器开了「AP 隔离 / 访客网络隔离」，设备之间互相不可见，这种情况 WiFi 永远搜不到，只能换 USB 或换网络。
- 2.4GHz 频段拥挤时画面会卡，路由器支持的话把设备挪到 5GHz 频段。

## 三、USB 有线连接

### Android 手机

1. 用数据线把手机插到电脑上（建议用手机原装线或标明支持数据传输的线，纯充电线不通数据）。
2. 手机上开启 **USB 调试**：设置 → 关于手机 → 连点「版本号」7 次打开开发者选项 → 在开发者选项里打开 USB 调试。
3. 插线后下拉手机通知栏，把 USB 的用途选成**文件传输 / MTP** 模式；弹出 USB 调试授权时选允许。
4. 打开手机端 App 和电脑端客户端，走 USB 自动连接。

### iPhone

插线后手机上弹出「信任此电脑」时选信任，其余步骤与上面相同。

### USB 方式的两个实测经验

- 有用户反馈 USB 连接异常时，把手机 WiFi **彻底关掉**再连就正常了——WiFi 和 USB 同时在线时，App 偶尔会优先走 WiFi 通道造成冲突。
- 线材质量影响很大，充电慢、连接断续时换一根 USB 3.0 级别的数据线。

## 四、两种方式怎么选

| 对比项 | WiFi | USB |
| --- | --- | --- |
| 布置自由度 | 高，远离电脑也能放 | 受线长限制 |
| 画面稳定性 | 受路由器负载与频段影响 | 稳定，不受网络影响 |
| 延迟 | 波动较大 | 低且稳定 |
| 长时间使用 | 手机耗电快 | 边用边充电 |
| 前置条件 | 同一局域网、无 AP 隔离 | 数据线 + USB 调试（Android） |

简单结论：当固定机位、追求不卡，插线；当需要机位自由、或电脑附近没插座，走 WiFi。长时间直播或录像建议 USB，画面和供电都更稳。

另外手机持续传视频本身比较耗电，长时间使用务必插着线（USB 模式边传边充电），或至少接个电源；手机过热会触发降频，画面清晰度随之下降。

## 五、连上之后的手机端画面操作

- **变焦**：在手机屏幕上双指捏合缩放，电脑端画面同步变焦。
- **镜像**：画面方向不对时在手机端设置里开镜像翻转。
- **息屏拍摄**：手机端支持息屏后继续出画面，长时间使用时可以锁屏省电、只留电脑端显示。
- 手机屏幕亮度调低一些也能省电，不影响输出画面。
