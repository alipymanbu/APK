# Iriun Webcam 手机麦克风的音频设置

> Iriun Webcam 除了传画面，还能把手机的麦克风一并变成电脑的音频输入设备（免费版就有这个功能）。本篇讲怎么开启、各软件里在哪选、以及没声音 / 回声 / 音画不同步的处理。

## 一、先在电脑客户端里打开音频开关

音频不是默认开启的，要先动一下电脑端的设置：

1. 打开电脑端 Iriun Webcam 客户端，点右上角的设置（齿轮）图标。
2. 在设置里找到 Audio（音频）一栏，开启「Stream audio from phone（从手机传输音频）」并保存。
3. 手机连上之后，系统的音频输入设备列表里会多出一个叫 Iriun Webcam 的麦克风（Windows：设置 → 系统 → 声音 → 输入）。

前提是手机端 App 的麦克风权限已经允许——第一次打开 App 时的权限弹窗如果点了拒绝，后面怎么设都没声音。

## 二、各软件里把麦克风切到 Iriun Webcam

| 软件 | 麦克风设置路径 |
| --- | --- |
| Zoom | 设置 → 音频 → 麦克风 → 选 Iriun Webcam |
| Microsoft Teams | 设置 → 设备 → 麦克风 → 选 Iriun Webcam |
| Discord | 用户设置 → 语音和视频 → 输入设备 → 选 Iriun Webcam |
| OBS | 添加来源 → 音频输入采集 → 选 Iriun Webcam |
| Windows 系统默认 | 设置 → 系统 → 声音 → 输入 → 选 Iriun Webcam |

画面与声音可以不同源：摄像头选 Iriun Webcam、麦克风用电脑自带的，或者反过来，按你的设备条件组合即可。电脑没有麦克风、或想离嘴更近收音更清楚时，手机麦的收益最明显。

## 三、没声音的检查顺序

1. 电脑客户端的音频开关开了没有——系统的输入设备列表里连 Iriun Webcam 麦克风都没有，就是没开。
2. 手机端 App 的麦克风权限是否允许。
3. 手机和电脑是否处于已连接状态（电脑客户端窗口里看得到画面）。
4. 安装时若报过「Initialization failed, problems with audio driver」（音频驱动初始化失败）：卸载客户端 → 重启电脑 → 重新安装一次。
5. 会议软件里确认麦克风选的是 Iriun Webcam 而不是「默认设备」——默认设备有时指向别的输入源。

## 四、三个常见的声音问题

- **回声或啸叫**：手机麦克风把电脑音箱放出来的声音又收了回去，越收越大。给电脑插上耳机，或把音箱音量调低，回声立即消失。
- **音画不同步**（多见于 OBS 推流）：把音频作为单独的「音频输入采集」来源添加，别依赖摄像来源自带的音轨；仍不同步时在 OBS 的高级音频属性里用「同步偏移（Sync Offset）」微调对齐。
- **手机麦收音发闷、噪音大**：手机麦克风是全向的，房间噪音照收。离嘴近一点、关窗关门能明显改善；或给手机插一副带麦克风的耳机，用耳机的麦替代手机内置麦。
