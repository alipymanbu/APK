# Iriun Webcam 在 OBS、Zoom、Teams 里怎么调用

> 手机连上电脑后，Iriun Webcam 会以一个普通摄像头设备出现在系统里，任何能选摄像头的软件都能直接用它。本篇给出 OBS 和常用会议软件里的具体设置路径，以及多台手机同时接入的做法。

## 一、原理一句话：它就是一个摄像头设备

电脑端客户端装好驱动后，系统里多出一个叫 Iriun Webcam 的摄像头。所以不存在「某软件专用版」的说法——只要手机那端连着、电脑客户端开着，哪个软件都能选它。反过来说，如果软件的摄像头列表里根本没有 Iriun Webcam，先去看电脑客户端开没开，再按 [画面延迟与连接失败排查.md](画面延迟与连接失败排查.md) 处理。

## 二、OBS Studio 里的设置

1. 来源面板点「+」→ 选**视频采集设备（Video Capture Device）**。
2. 新建一个来源，设备（Device）下拉里选 **Iriun Webcam**。
3. 需要麦克风声音的话，再点「+」添加一个音频输入采集，选 Iriun Webcam——前提是已在电脑客户端设置里开启音频传输，具体步骤见 [麦克风音频设置.md](麦克风音频设置.md)。

手机端支持息屏后继续输出画面，OBS 长时间推流时把手机锁屏即可。

## 三、会议与聊天软件的设置路径

各家软件的位置不同，按下面这张表找：

| 软件 | 设置路径 |
| --- | --- |
| Zoom | 设置 → 视频 → 摄像头 → 选 Iriun Webcam |
| Microsoft Teams | 设置 → 设备 → 摄像头 → 选 Iriun Webcam |
| Skype | 设置 → 音频和视频 → 摄像头 → 选 Iriun Webcam |
| Discord | 用户设置 → 语音和视频 → 视频设置 → 摄像头 → 选 Iriun Webcam |
| Chrome 浏览器（网页版会议） | 网站权限弹窗里选 Iriun Webcam，或在浏览器地址栏的摄像头图标里切换 |

一个细节：**改完摄像头设置后，部分软件需要重启才能刷新设备列表**。如果刚装完驱动就打开 Zoom 发现列表里没有 Iriun Webcam，先把 Zoom 关掉重开一次。

## 四、多台手机同时接入

有用户反馈电脑端客户端可同时连接 3 台手机，连接后分别作为 Iriun Webcam、Iriun Webcam 2、Iriun Webcam 3 出现在设备列表里（具体上限以你手上的客户端版本为准）。在 OBS 里给每台手机各加一个视频采集设备来源、各选一个 Iriun Webcam，就能搭出多机位。

同一批反馈还提到：多台手机连接时的编号分配是随机的，同一台手机这次可能是 1 号、下次可能变成 3 号，所以多机位开播前先看一眼每路画面对应哪台手机，再调整 OBS 里的布局。

## 五、调用时的几个常见状况

- **列表里有但点开是黑的**：先看是不是 Windows 相机隐私权限没放开（设置 → 隐私 → 相机），再确认手机端 App 还活着。另一个常见原因是摄像头被占用——Windows 摄像头同时只能给一个应用用，关掉其他正在用摄像头的程序再试。
- **手机端 App 被关掉或切到后台被系统杀掉了**：回手机重新打开 App。
- **画面方向不对（竖屏）**：手机横过来拿，或在 OBS 的来源属性里把分辨率/旋转设置改成与画面匹配的方向；会议软件里一般直接把手机横放最省事。
