## 一、免费版的边界在哪

日常文件管理**不需要会员**：双窗口、复制移动、压缩解压、文本编辑、图片查看这些都是免费的（多方口径一致）。收费从 2016 年就存在——官方更新记录当时注明「开始实行收费功能」，首批是 Xml 反编译、RAR 解压。

免费与付费的分界线，官方 VIP 页写得很直白：免费用户**反编译 xml 时有长度限制、速度也慢**，VIP 无此限制。也就是说，**轻度用免费版就够，深度动 APK 才需要会员**。

## 二、VIP 解锁什么（官方 VIP 页清单）

官方介绍页 [mt.cc/vip](https://mt.cc/vip/) 列出的会员功能，与文件管理相关的主要是这些：

| 类别 | 功能 |
|---|---|
| 资源编辑 | 完整 AXml 编辑（不限文件大小、反编译更快）、AXml 代码搜索、Arsc 编辑器++、Arsc 资源查询 |
| 代码阅读 | Smali 转 Java（多款反编译引擎可选）、Dex 编辑器++ 代码流程图、Dex 修复、Dex 对比、Arsc 对比 |
| 编辑器 | 文本对比、Hex 编辑器 |
| 签名密钥 | 自定义 APK 签名密钥（导入 `.jks` / `.keystore` 或生成新密钥） |
| 备份与云 | 用户数据云备份、文件编辑器快捷功能本地备份 |
| 扩展 | 插件功能（自定义翻译引擎）、多种网络存储、创建快捷方式时自定义图标 |

官方页还列有若干面向 APK 深度编辑的功能，完整且最新的清单**以 [mt.cc/vip](https://mt.cc/vip/) 与应用内提示为准**。另外「双端登录」（多端同时登录同一账号）按官方更新记录是**单独收费**的项目。

## 三、价格与开通方式

**价格会变，别按记忆里的数字付钱。** 公开可见的参考（均来自论坛公开帖，仅作量级参考）：

- 论坛卡密活动页标注的永久会员**市价 ¥186**（2026-07 的十周年庆活动，5210 金币兑换、已抢购完）；
- 有用户 2026-06 发帖称更早时候是 168 元、PayPal 渠道 25 美元折算约 168 元。

**以应用内开通页面当时显示的价格为准。** 开通路径（官方论坛卡密帖与第三方教程口径一致）：

1. 侧边栏 → **用户信息**；
2. 点**开通/续费会员**；
3. 按页面选支付方式（国内教程提到支付宝/微信；用卡密的选「卡密充值」填入卡密）。

## 四、要不要开：按你的用法判断

- 只做文件整理、压缩解压、看文本——**免费版没有功能墙**，不用开；
- 只是偶尔反编译看一眼 xml——免费版有长度限制也能凑合，能忍就不用开；
- 经常做资源编辑、要文本对比/Hex 查看、要云备份与网络存储——这几项在 VIP 清单里，按需开通；
- 想省钱：论坛不时有折扣活动（如十周年庆），蹲折扣比原价买划算（论坛反馈）。

价格与政策随时会调整，付款前以**应用内开通页**显示为准。
