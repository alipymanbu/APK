# 手机电脑互传文件远程管理

> 不插线、不装电脑端软件，同一 WiFi 下用浏览器或 FTP 客户端直接管理手机文件，看这篇。

## 一、这是什么

MT管理器 内置了「远程管理」：手机端开一个服务，电脑在同一 WiFi 下用**浏览器**（HTTP 模式）或 **FTP 客户端**（FTP 模式）连上来，直接浏览、上传、下载手机文件——不用数据线，也不用在电脑上装手机助手。前提是**手机和电脑连在同一个 WiFi**。

入口：点左上角三条横线打开侧边栏 → 找到**远程管理**（不同版本可能叫「远程管理」或在侧边栏工具分组里）。

## 二、HTTP 模式：浏览器直接用（推荐）

HTTP 模式是 2.26.5 加入的，官方更新说明写的是「可在网页浏览器上管理手机文件」。步骤：

1. 侧边栏 → 远程管理 → 启动 HTTP 服务；
2. 界面会显示一个地址（IP + 端口）。**2.26.6 起支持查看该地址的二维码**，电脑手机都能扫；
3. 电脑浏览器输入这个地址 → 回车，就能像网盘页面一样浏览手机目录、上传和下载文件。

几个版本相关的细节（官方更新记录）：

- 远程管理会**记住上次用的是 HTTP 还是 FTP**（2.26.6 起）；
- HTTP 模式带**设备管理**功能（2.26.6 起）；
- 2.26.9 修复了「手机与浏览器时间不一致导致无法使用」的问题——连不上先对一下两边的时间（见 [常见问题与排查.md](常见问题与排查.md)）；
- 2.26.9 起主设置里有**自动启动服务**选项，可以把远程管理设为随应用启动。

## 三、FTP 模式：用电脑上的 FTP 客户端

启动 FTP 服务后会显示 `ftp://IP:端口` 形式的地址。电脑端用任意 FTP 客户端（FileZilla、Xftp 等）新建连接：

- 地址、端口按手机上显示的填；
- 论坛教程的走法是**匿名登录**即可连上；
- 连上后拖拽文件即完成上传/下载。

FTP 模式还有个衍生用法（论坛用户分享）：**两部手机之间传文件**——一部开远程管理，另一部用 MT管理器 侧边栏里的 FTP 客户端功能连上去，互相上传下载，同样要求在同一 WiFi。

## 四、连不上时查这几项

| 现象 | 先查什么 |
|---|---|
| 浏览器打不开地址 | 手机与电脑是否同一 WiFi；手机上服务是否还开着 |
| 提示无法使用 | 手机与浏览器时间不一致（2.26.9 已修复，老版本先升级，见 [下载与安装教程.md](下载与安装教程.md)） |
| FTP 客户端连不上 | 端口号有没有输错（地址里冒号后面那段）；重启一次远程管理再连 |
| 电脑防火墙拦截 | 允许该连接通过，或换 HTTP 模式用浏览器试 |

## 五、安全边界

远程管理监听的是**局域网地址**，只在同一 WiFi 内可达。两条自我约束：

1. 只在家庭/办公这种可信 WiFi 下开启，**公共 WiFi 不要开**；
2. 用完随手关掉服务（侧边栏进远程管理页面停止），别让文件服务一直挂着。
