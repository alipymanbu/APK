## 一、你拿它能做哪些事

按官方说明与实际用途，NotTiled 主要服务这几类操作：

- **画游戏地图**：在手机上新建或修改 `.tmx` 地图（Tiled 生态的通用地图格式），配合使用这类地图的游戏；
- **改现成游戏的地图**：比如 Rusted Warfare（应用内可以直接把地图发过去，完整步骤见 [铁锈战争地图导入与存放路径.md](铁锈战争地图导入与存放路径.md)）、Remixed Dungeon，以及走 Tiled 工作流的星露谷物语模组等；
- **跑团战棋图**：画一张 2D 战斗地图，导出成 PNG 直接投屏或打印用；
- **画像素小图**：内置了一个简易像素编辑器，可以画图标、精灵和动画表；
- **随手看效果**：3D 模式可以把平面地图看出立体感。

它不要求你会编程，但「图块尺寸」「图层」这两个概念要懂，不然画出来会错位——这两个概念在 [地图制作入门教程.md](地图制作入门教程.md) 里有展开。

## 二、主界面结构（1.8.8 实际布局）

打开一张地图后，屏幕分成四个区域：

| 区域 | 位置 | 上面有什么 |
| --- | --- | --- |
| 顶栏 | 屏幕最上方 | Undo（撤销）、Layer（新建/管理图层）、当前图层名（如 Ground）、Visibility（图层显隐）、Redo（重做） |
| 左侧竖列 | 屏幕左边 | Play（试玩）、Save（保存）、Map（地图信息）、Menu（主菜单） |
| 右侧竖列 | 屏幕右边 | Brush（笔刷）、Picker（吸色）、Fill（填充）、Eraser（橡皮）、Rectangle（矩形）、Rotate（旋转，显示当前角度） |
| 底栏 | 屏幕最下方 | Run Macro（运行宏）、Tile（图块模式）、Macro Tiles（宏图块）、Layer（图层入口） |

画布占中间整块，双指缩放、单指拖动；点击图块区域会弹出图块选择面板，从里面挑要铺的图块。

新手最常点的几个：**Brush** 铺图块、**Eraser** 擦掉画错的、**Fill** 一键填满整层、**Play** 进试玩看效果。

## 三、把界面换成中文

1. 点左侧竖列的 **Menu**；
2. 进入 **Preferences**（首选项）；
3. 点开最上方的 **Language** 下拉框，选「Chinese / 中文」；
4. 滑到页面最底部，点 **Save** 保存这次修改；
5. 应用会提示语言修改需要重启——手动重开一次应用，界面才会变成中文。

注意两件事：一是不少人卡在第 4 步，不点 Save 直接退出，重启后自然没变；二是中文覆盖的是常用界面，个别按钮可能仍显示英文，不影响使用。菜单项名称在不同小版本里略有调整，对不上时在 Preferences 里逐项翻。

## 四、功能对照表：想做什么，点什么

| 你想做的事 | 入口 | 说明 |
| --- | --- | --- |
| 铺地形 | 右侧 **Brush** | 先在图块面板选块，再到画布上涂抹 |
| 填满整片区域 | 右侧 **Fill** | 注意会填满相连的同色区域，别在地形复杂时误触 |
| 取画面上已有的图块 | 右侧 **Picker** | 不用去面板翻，直接从画布上吸 |
| 擦除 | 右侧 **Eraser** | 只作用于当前图层 |
| 画矩形块 | 右侧 **Rectangle** | 批量铺规则区域（房间地板、围墙）比笔刷快 |
| 换图层 | 顶栏图层名或底栏 **Layer** | 每层独立绘制，先选对层再下笔 |
| 隐藏/显示某一层 | 顶栏 **Visibility** | 检查层与层之间的遮挡时用 |
| 运行宏 | 底栏 **Run Macro** | 宏是把一组操作存下来重复用的机制，配合 **Macro Tiles** 使用 |
| 试玩地图 | 左侧 **Play** | 平台类地图会给出 Up / Left / Right / Down 触屏方向键，直接试跳 |
| 保存 | 左侧 **Save** | 养成随时按的习惯，手机切后台应用可能被回收 |

## 五、Preferences 里值得先看的几项

- **语言**：上面第三节说的中文设置；
- **显示坐标**：在画布上显示当前格坐标，对齐时有用（1.6.3 版本起加入的选项）；
- **文件选择器**：应用提供系统原生文件选择器的选项（1.6.7 起加入），访问存储里的地图文件更省事；
- 其余项按需开关，改错了随时可以改回来，都不会破坏地图文件。
