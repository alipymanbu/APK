## 一、动手前的三分钟：搞懂两个概念

NotTiled 画的是「图块地图」：地图由一个个小方格拼成，每个格子放一块图块（草、水、墙）。所以只有两个概念必须先懂：

- **图块尺寸**：一块图块的边长（像素）。常见的有 16、24、32。整张地图的所有图块集必须与之一致，不一致就会出现切分错位；
- **图层（Layer）**：地图是分层的透明胶片。一般地表铺一层、装饰（树、花）叠一层、再叠一层放碰撞或物件。修改只影响当前选中的层。

如果你目标明确——给某个游戏做地图——先去看那个游戏的说明，确认它要求的地图尺寸、图块尺寸和方向，再回来新建。

## 二、新建地图：参数怎么填

在菜单里新建地图时，会碰到这几项：

| 参数 | 填什么 | 注意 |
| --- | --- | --- |
| 方向 | 正交（Orthogonal）或 等距（Isometric） | 俯视角像素游戏选正交；斜 45° 视角（如部分策略/RPG）选等距。选错画出来全是斜的，只能重建 |
| 宽 × 高 | 地图的格子数，不是像素数 | 100×100 的格子数是「100 块图块宽」，按目标游戏的要求填；拿不准先建小的练手 |
| 图块尺寸 | 与你图块集图片里单块的像素边长一致 | 之后导入图块集时必须用同一尺寸 |
| 背景色 | 可选 | 铺满前画布露出的底色 |

新建后你会得到一张空格子画布，顶部图层名显示当前层（默认如 Ground）。

## 三、导入图块集：画之前得有「料」

图块集（tileset）是一张把很多小块拼在一起的图片（精灵表）。NotTiled 内置了一些示例图块集可以直接用；要用自己的素材：

1. 把素材图片放进手机存储；
2. 打开图块集面板，点添加（+），从文件管理器选中那张图；
3. 设置切分尺寸——即这张图里每个小图块的像素边长，要与地图的图块尺寸一致；
4. 确认后面板里会出现按格切好的图块，点选即可用。

素材来源可以是公开素材站（如 itch.io、OpenGameArt 上的免费图块包），下载时留意作者标注的使用许可。

切出来错位、花屏，基本都是第 3 步尺寸填错了，具体现象与修法见[常见问题与故障排除.md](常见问题与故障排除.md)。

## 四、铺第一张地图

以「草地上一条河」为例，整个流程是：

1. 选中地表层（如 Ground），点 **Brush**，在图块面板选草块，把整片区域涂满——纯色大面积用 **Fill** 更快；
2. 换选河块，沿路线涂出河的走向；转角和边缘用面板里的过渡图块衔接；
3. 新建一层放装饰（+Layer），选树、石头这类图块叠上去——放错了擦除也不伤底层；
4. 用 **Visibility** 关掉地表层，只看装饰层查漏；
5. 随手按左侧 **Save** 保存。

顺手用到的工具：**Picker** 从画布上直接吸当前图块（免得回面板翻）、**Rectangle** 拉矩形批量铺（房间、道路）、**Rotate** 旋转图块方向。

想验证地图能不能玩：点左侧 **Play** 进内置试玩，平台类地图会出现 Up / Left / Right / Down 方向键，直接试跳试走。

## 五、图层与对象层

- **图块层**：铺格子用的层，可以建很多层，上下顺序决定遮挡关系（上层盖住下层）；
- **对象层**：不放格子，放「对象」——单个的标志点、触发区、敌人位置这类非网格元素。给游戏做地图时，很多游戏用对象层读出生成点；
- 重命名图层（地表 / 装饰 / 碰撞 / 物件）会让后面的工作轻松很多，尤其把图交给别人的时候。

## 六、保存与导出：格式怎么选

**Save** 保存的是工程文件（`.tmx`），这是 Tiled 生态的通用格式，大部分用 Tiled 风格地图的游戏都直接认。需要别的格式时，从菜单导出：

| 格式 | 拿去干什么 |
| --- | --- |
| TMX | 通用选择。Tiled 风格游戏、绝大多数游戏引擎工具链都认 |
| JSON | 适合交给网页游戏框架（如 Phaser 一类）或需要程序读图的场景 |
| Lua | 交给用 Lua 脚本的游戏/引擎（如部分 LÖVE 作品） |
| CSV | 纯文本的格子数据，方便自查或导入表格处理 |
| PNG | 导出成品图。跑团战棋图、预览图用这个 |

导出后文件在你指定的存储目录里，交给游戏时按那个游戏要求的路径放进去。

## 七、把地图交给游戏

- **Rusted Warfare**：不用手动搬文件，应用内可以直接把地图发送过去（前提是手机上装了它）；发送失败或要给电脑版用，手动放 `maps` 文件夹的完整步骤在 [铁锈战争地图导入与存放路径.md](铁锈战争地图导入与存放路径.md)；
- **其他 Tiled 风格游戏**（Remixed Dungeon、星露谷模组工作流等）：把导出的地图文件放进该游戏指定的目录，具体路径以游戏自己的说明为准；
- 交给别人之前，先自己 **Play** 一遍或用 PNG 导出看一眼成品，比在电脑上发现问题再返工省时间。

图块集切分不稳、想用自动地形让边缘自动衔接，这两件事单独写在 [图块集与自动地形设置.md](图块集与自动地形设置.md)；做出来的图哪里不对劲，先翻 [常见问题与故障排除.md](常见问题与故障排除.md)。
