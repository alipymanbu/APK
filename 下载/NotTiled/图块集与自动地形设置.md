# NotTiled 图块集导入与自动地形设置

> 本篇只讲两件最容易卡住的事：把图块集（精灵表）正确切分进 NotTiled，以及用自动地形（autotile）和 Macro 让铺图效率翻倍。基础绘制流程不在本篇展开。

## 一、图块集从哪来

两条路：

- **用内置的**：应用自带示例地图和图块集，新装完先拿这些练手，不用操心切分；
- **自己导入**：从公开素材站（itch.io、OpenGameArt 等）下载图块包，或用应用内置的像素编辑器自己画（见第五节）。第三方素材注意看作者的使用许可，再决定能不能用进你的作品。

导入的关键动作只有一个：**告诉应用每一小块的像素尺寸**。这个数必须与你新建地图时填的图块尺寸一致（或成倍数关系），对不上的典型症状见[常见问题与故障排除.md](常见问题与故障排除.md)。

## 二、导入精灵表：逐步操作

一张精灵表（sprite sheet）长这样：一整张图片里排满了等大的小块。导入步骤：

1. 把图片放进手机存储（好找的目录即可）；
2. 打开图块集面板，点添加（+），选「从图片导入」一类入口，选中该图；
3. 填单块尺寸：比如表里每块是 32×32，就填 32；
4. 确认后应用按网格切块，面板里逐块可选。

三个易错点：

- 表里块与块之间**没有留缝**（无间距）时最简单；如果素材带 1px 间隔线，切分设置里要对应留出间距，否则会切出「错半个块」的花图；
- 图片如果是多行多列，尺寸填对即可，行列不用你管；
- 切错了直接删掉这个图块集重新导一次；已铺到画布上的块引用的是旧索引，重导时用同一张图、同一尺寸，已铺的内容就不会跑偏。

## 三、自动地形（autotile）：让边缘自动衔接

铺地形最烦的是边缘：草地接水面要一块块换「过渡块」。自动地形解决的就是这个——你把一整套带过渡关系的图块登记成一个地形组，之后用笔刷画的时候应用自动挑正确的过渡块。

1.8.x 这一代的注意事项（来自该版本的更新记录，实际以你设备为准）：

- 自动地形**只在自动地形选择器里生效**（1.6.9a 起）：普通图块面板里选同一块图不会触发自动衔接，要切到自动地形选择器去选；
- 1.6.8 之前的版本里自动地形在部分操作下会崩掉应用，画之前确认你的版本（1.8.8 已包含这些修复）；
- 地形工具配合矩形工具在个别旧版本下不生效，遇到就改用笔刷画。

## 四、Macro：把重复操作录下来

底栏的 **Macro Tiles** 与 **Run Macro** 是一对：Macro 把一组图块/操作存成一个「宏」，之后 **Run Macro** 一键重放。适合的场景：

- 一整套固定搭配（比如「围墙 + 门 + 火把」每次都一起放）；
- 重复的地形模板（同一种房间布局要用很多次）。

注意两点（1.6.9a 更新记录里修过的坑）：删除 Macro 时低版本可能卡住；Macro 的原点在左上角，放置时以此对位。1.8.8 已包含这些修复。

## 五、用像素编辑器自己造图块

NotTiled 内置一个简易像素编辑器，官方定位是画图标、精灵和动画表：

1. 从菜单进入像素编辑器，按图块尺寸建新画；
2. 逐格上色，画完导出为图片；
3. 按第二节的流程把这张图作为图块集导回来用。

多帧素材（流水、火焰这类循环效果）可以画成动画表再导入；图块动画的设置入口在不同小版本里位置有差异，以应用内实际菜单为准。你的目标是给游戏用的话，先确认那个游戏是否读图块动画，不读就别在这上面花时间。

## 六、把画好的选区存成图块集

1.6.7 起可以把画布上的选区直接导出为图块集：框选一块区域 → 导出选区为图块集 → 之后它就能像普通图块集一样被引用。适合「从成品地图里抠一块常用结构」复用。

图块集就绪后回到 [地图制作入门教程.md](地图制作入门教程.md) 继续铺图；界面按钮位置对不上号时查 [功能一览与界面入门.md](功能一览与界面入门.md) 第二节的对照表；导入后显示异常优先翻 [常见问题与故障排除.md](常见问题与故障排除.md)。
