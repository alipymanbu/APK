## 一、不登录能用，登录后更全

Pixiv Viewer 打开就能直接浏览公开内容，不需要注册，也无需先做任何配置。两种状态的区别：

| 能做的事 | 不登录 | 登录后 |
| --- | --- | --- |
| 浏览公开插画 / 漫画 / 小说、排行榜 | 可用 | 可用 |
| 搜索、ID 直达 | 可用 | 可用 |
| 收藏、关注画师 | 不可用 | 可用 |
| 评论 | 不可用 | 可用 |
| 个性化推荐、关注动态 | 不可用 | 可用 |
| 查看收藏夹、下载历史 | 不可用 | 可用 |

结论很简单：只逛不收藏，不登录够用；想追画师、存收藏、留浏览记录，就需要登录自己的 Pixiv 账号。

## 二、三种登录方式怎么选

设置里提供三种登录方式：

| 方式 | 稳定性 | 适用情况 |
| --- | --- | --- |
| RefreshToken 登录 | 最稳，官方也推荐 | 首选方式 |
| OAuth 登录 | 可用 | 备选 |
| Cookie 登录 | 容易失效出错 | 不推荐，仅在拿不到 Token 时应急 |

选 RefreshToken 的操作思路：先取得 Pixiv 的 RefreshToken，再粘贴进应用的登录设置。完整获取步骤单独整理在[RefreshToken获取步骤.md](RefreshToken获取步骤.md)——其中最省事的一种，就是用 Pixiv Viewer 自己的 `App API (OAuth)` 登录完成，不用装任何额外东西。如果 Cookie 或 SessionID 登录一直报错，别反复试，直接换 RefreshToken 方式，这是官方 FAQ 里给出的标准答案。

登录遇到问题（比如提示超限），去[常见问题与加载失败排查.md](常见问题与加载失败排查.md)查对应条目。

## 三、内容开关与浏览偏好

设置页里这几组开关和你的日常观感直接相关：

- **R18 开关**：控制成人内容是否显示。默认关闭；开启后能否看到，还取决于你 Pixiv 账号侧的年龄与地区设置，两边都开了才生效。
- **AI 作品开关**：单独控制 AI 生成作品是否出现在信息流与排行里，对 AI 图敏感的话直接关掉。
- **本地黑名单**：把不想再看到的标签或用户拉黑，支持标签化管理，可单独移除。刷到不想看的内容时长按也能快速屏蔽用户。
- **语言**：简繁中文、英、日、韩、俄等 14 种界面语言。
- **外观与布局**：深色模式、自定义主题色；信息流布局在瀑布流、网格、两端对齐、虚拟列表、轮播之间切换；图片画质可选 Medium / Large / Large(WebP)，流量紧张就选 WebP。

## 四、备份与换机

- **设置备份**：应用的各项设置可以导出备份，重装或换机后导入还原，不用重新调一遍。
- **浏览记录备份**：看过的作品历史同样支持备份与还原。
- **云端同步**：设置支持加密同步（带冲突检测与智能合并），多台设备间保持一致。
- **导出 RefreshToken**：应用支持把当前登录的 Token 导出，给其他同类工具复用，省得再取一次。

登录态相关的设置弄好之后，剩下的就是日常刷图与下载了，操作见[浏览与搜索用法.md](浏览与搜索用法.md)。
