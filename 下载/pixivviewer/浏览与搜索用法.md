## 一、首页能看什么

打开应用后，底部导航在首页、搜索、排行榜、设置几个页面之间切换。首页提供这几类内容入口：

| 入口 | 内容 |
| --- | --- |
| 插画 / 漫画 / 小说 | 按作品类型分开浏览 |
| 排行榜 | 各类型的热门作品排行 |
| 特辑 | 官方精选专题 |
| 热门 / 推荐 | 全站热门与个性化推荐 |
| 随便看看 | 随机给你捞一些作品，没头绪时用来逛 |
| 珍藏册 | 用户整理的作品合集 |

图片流的排版可以在设置里换：瀑布流、网格、两端对齐、虚拟列表、轮播等多种布局，喜欢哪种用哪种。首页刷出来的内容与是否登录有关——登录后会有"基于你的收藏"的个性化推荐，未登录时以公开热门内容为主。

## 二、搜索的几个实用技巧

搜索页支持插画/漫画、小说、用户、珍藏册四个对象。除了直接输关键词，这几个技巧更省事：

1. **用热词和补全**：搜索框会给出热门搜索词（长按可预览该标签的封面），输入时也有自动补全建议，不确定标签全名时靠它。
2. **数字 ID 直达**：直接输入作品 ID（pid）或用户 ID，跳过搜索结果页直达对应页面。从别处看到"作品号 123456789"这种信息时就这么用。
3. **以图搜图**：上传一张图片找相似作品，走 SauceNAO 的接口，手里只有图、不知道出处时用它反查。
4. **按条件筛**：搜索结果可以按收藏数、投稿时间等条件过滤，避免热门词下面几千张图翻不完。
5. **搜用户**：想追某个画师，直接搜名字进 TA 的作者页，再点关注（需要登录）。

## 三、排行榜怎么用

排行榜分综合、插画、漫画、动图、小说几个维度，另有按日期回看的历史排行，可以翻某一天的作品榜。R18 与 AI 生成作品是否出现在排行和推荐里，可在设置里用对应开关控制（详见[登录与账号设置.md](登录与账号设置.md)）。

## 四、作品页与作者页操作

打开一张作品后，你能做的事：

- **收藏 / 取消收藏、评论、分享**（登录后可用）
- **下载**：单张图片或整套多图，具体见[插画与动图下载方法.md](插画与动图下载方法.md)
- **跳转 Pixiv 原页面**：一键在浏览器里打开这个作品的 pixiv.net 页面，方便核对评论区等第三方端看不到的内容
- **复制 ID**：作品 ID 和作者 ID 都可以一键复制
- **动图播放**：Ugoira 动图可以在应用内直接播，还能控制帧

在作者页可以浏览 TA 的插画、漫画、收藏、小说和系列（漫画系列、小说系列），查看常用标签，还能看到相似风格的推荐用户；关注后的更新会进"动态"页。

## 五、图片加载慢的即时处理

刷图卡在加载，多半是图片镜像线路的问题，最快的办法：进「设置 → 图床」换一个图片反代源，再回首页刷新。更系统的排查步骤见[常见问题与加载失败排查.md](常见问题与加载失败排查.md)。

## 六、看不懂日文漫画：内置翻译

遇到日文原版漫画，Pixiv Viewer 内置了翻译功能：在作品页发起翻译后，文字识别与图像处理在你的设备本地完成，不用排队、不用装额外插件；译文会嵌回原来的对话气泡，可以一键在原图与译文之间切换对照。翻译引擎支持接入 OpenAI 兼容的大模型服务（如 SiliconCloud）或自建服务端，在设置里按提示配置即可。小说的文字翻译则更简单，阅读器里自带在线翻译，不用额外操作。
