## 一、各版本一览

| 版本 | 获取方式 | 说明 |
| --- | --- | --- |
| 网页版 / PWA | 直接打开 [pixiv.pictures](https://pixiv.pictures) | 无需安装，浏览器即用；支持作为 PWA 安装 |
| 安卓 | APK 安装包 | 获取与安装见[下载与安装教程.md](下载与安装教程.md) |
| Windows | EXE / MSI 安装包 | 从 GitHub Releases 下载 |
| macOS | DMG（Apple Silicon 与 Intel 分开两个包） | 同上 |
| Linux | deb / rpm / AppImage / Arch 包 | 同上 |
| iOS | 未签名 IPA | 需自行签名后侧载，门槛最高 |

所有客户端版本的统一入口是 [GitHub Releases 页](https://github.com/asadahimeka/pixiv-viewer-app/releases)，更新很频繁，下载前看一眼发布日期，别拿几个月前的旧包。

## 二、网页版与客户端版怎么选

- **只想偶尔看看**：网页版，浏览器打开就能用，什么都不装。
- **长期使用、经常下载**：客户端版（安卓或桌面端）。官方 FAQ 明确说客户端版本对图片线路的处理更省心；网页版想直连原图服务器还得额外配浏览器辅助脚本，麻烦不少。
- **功能面**：两端基本一致——三种登录方式、下载、动图导出、设置备份都有，差别主要在图片线路的省心程度。

## 三、桌面端安装的两个提醒

桌面端构建目前**均未签名**，装的时候系统会拦一下，属正常现象：

- Windows：SmartScreen 弹窗时点「更多信息 → 仍要运行」。
- macOS：Gatekeeper 可能拦截，到「系统设置 → 隐私与安全性」里允许运行。

## 四、iOS 的情况

官方分发的 IPA 未签名，需要你自行签名后侧载（官方 FAQ 列了爱思助手、AltStore 等途径，各有教程）。没有签名条件的 iPhone 用户，用网页版是最省事的替代方案。
