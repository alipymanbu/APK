## 一、提示 API 超限 / Rate Limit

应用走的是公共 API 实例，热门时段用的人多就会触发限流。处理顺序：

1. 进「设置 → API」，切换到另一个 API 实例，回来刷新。
2. 登录自己的账号（RefreshToken 或 OAuth 方式），登录态的请求配额比匿名访问宽松。
3. 还不行就过段时间再用，限流是按时间窗口放的。

登录方式本身选哪种，见[登录与账号设置.md](登录与账号设置.md)里的对照表。

## 二、图片加载慢或刷不出来

这是使用中最高频的问题，根源在图片走哪个镜像。按顺序试：

1. 「设置 → 图床」换一个图片反代源，回首页刷新，立竿见影的情况占多数。
2. 换 API 实例（同上一节的第一步），部分实例的图片出口也受影响。
3. 用客户端版本而不是网页版（各版本差异见[网页版与电脑版获取途径.md](网页版与电脑版获取途径.md)），应用版对图片线路的处理比网页端省心。
4. 清一次缓存（设置里有入口）再刷。

## 三、列表图片和详情对不上、搜索结果驴唇不对马嘴

症状：列表缩略图和点进去的大图不是同一张、搜索"风景"出来一堆无关结果。官方 FAQ 给的解释是 API 实例的 CDN 缓存串了。处理：

- 切换其他 API 实例；
- 登录后再用，登录态下命中缓存的路径不同，基本能避开。

## 四、"尚无此页" / "尚无权限浏览该作品" / "您的访问权限被限制了"

这组提示通常**不是应用坏了**，而是作品本身的状态变了：

- 作品已被作者删除；
- 作品被设为仅自己可见或限定公开范围；
- 作品因违规被平台下架。

换一篇作品验证一下：别的能打开，就只有这一篇打不开，那基本就是上面这些情况，无解，只能找作者的其他作品。

## 五、部分地区 IP 看不了某些作品

Pixiv 官方有公告：来自美国、英国 IP 的访问看不到部分作品（官方公告页 `https://www.pixiv.net/info.php?id=10837`）。Pixiv Viewer 这类第三方端同样受此影响。官方给出的建议是两条：登录自己的账号，并在 Pixiv 官网页面的账号设置里把地区设为日区等非美英地区。这一条属于账号侧设置，应用内改不了。

## 六、登录相关报错

| 现象 | 处理 |
| --- | --- |
| Cookie / SessionID 登录报错 | 别再试 Cookie，换 RefreshToken 方式（官方明确说它更稳） |
| 拿不到 RefreshToken | 五种获取途径与逐步说明见[RefreshToken获取步骤.md](RefreshToken获取步骤.md) |
| 登录成功但收藏列表为空 | 退出重登一次；仍为空则确认网页端 Pixiv 里确实有收藏 |

## 七、其他高频小问题

- **点下载就闪退** → 给存储权限 + 更新版本，详见[插画与动图下载方法.md](插画与动图下载方法.md)第四节。
- **安装失败 / 解析包出错** → 重新下载安装包、核对 MD5，见[下载与安装教程.md](下载与安装教程.md)第四节。
- **界面变卡、缓存膨胀** → 设置里一键清除缓存；浏览记录本身不占多少空间，不必清。
- **想反馈 Bug** → 项目开源，开发者收反馈的入口在 GitHub 仓库 `https://github.com/asadahimeka/pixiv-viewer/issues`。
