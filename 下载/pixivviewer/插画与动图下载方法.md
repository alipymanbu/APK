## 一、下载一张插画的三种途径

1. **作品页下载**：打开作品详情，点下载按钮，单图直接保存，多图（漫画风分页作品）会整套下载。
2. **列表长按下载**：在首页信息流或搜索结果的缩略图上长按，弹出快捷菜单直接下载，不用进详情页——批量刷图时这一下最省事。同一个长按菜单里也有"屏蔽用户"选项。
3. **下载原图**：详情页里可以查看并下载原图尺寸，放大缩小看细节后再决定存不存。

下载的文件名格式可以在设置里自定义模板（比如带上标签、作者、标题这类信息），方便事后在相册或文件夹里按名字整理。下载历史在应用内可以查（需登录）。

## 二、动图（Ugoira）的播放与导出

Pixiv 的动图格式叫 Ugoira，在 Pixiv Viewer 里的处理方式：

- **播放**：详情页内直接播放，支持帧控制。
- **导出格式**：按需选 ZIP / GIF / WebM / APNG / MP4 / AVIF。

怎么选：

| 你的用途 | 建议格式 |
| --- | --- |
| 只想存原图帧和帧间隔数据，以后自己处理 | ZIP |
| 发到聊天群、表情包场景 | GIF |
| 想要高画质、小体积的现代格式 | WebM 或 AVIF |
| 剪辑、需要时间轴的后期场景 | MP4 |

## 三、小说下载

小说作品支持整篇导出，格式覆盖 TXT / HTML / Markdown / DOC / PDF / EPUB。想导入阅读器就选 EPUB，纯存档选 TXT，要排版就 PDF 或 DOC。应用内置小说阅读器，支持字体、颜色、阅读方向的自定义，自动记住阅读进度，下次接着读。

## 四、下载失败与闪退排查

按现象对号入座：

- **点下载就闪退**：九成是没给存储权限。去系统「设置 → 应用 → Pixiv Viewer → 权限」里允许存储（文件）权限；仍闪退就换最新版安装包再试——官方 FAQ 给出的两条建议就是"授予存储权限"和"下载最新版本"。
- **一直转圈下不动**：通常是图片线路问题，先按[常见问题与加载失败排查.md](常见问题与加载失败排查.md)把图床/API 实例调通，再回头下载。
- **提示无权限浏览该作品**：作品本身已被作者删除或设为非公开，这不是下载功能的问题。

还没装应用的话，先从[下载与安装教程.md](下载与安装教程.md)把安装包拿到手。
