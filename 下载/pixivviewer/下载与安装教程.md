## 一、安装包基本信息

先核对你要装的这份包，避免拿到别的版本：

| 项目 | 信息 |
| --- | --- |
| 应用名称 | Pixiv Viewer |
| 版本 | 1.33.0 |
| 包名 | `org.eu.cocomi.pxvek` |
| 安装包大小 | 约 18.52 MB |
| MD5 | `F507D2620A48A5F0CF9263EA782E9A84` |
| 系统要求 | 安卓 5.2 及以上 |
| 采集时间 | 2026-09-27 |

几点说明：

- 版本以本地这份安装包为准。Pixiv Viewer 是开源项目，官方在 GitHub 上的更新很勤（几乎隔几天就出一个新版本号），网上搜到的"最新版"往往和这里不是同一个版本。想知道官方最新发到几了，可以去 [GitHub Releases 页](https://github.com/asadahimeka/pixiv-viewer-app/releases)看一眼。
- 装之前如果不确定包是否完整，可以用手机的文件管理器或电脑上的工具算一下 MD5，与上表比对。
- 除安卓外，官方还提供网页版与 Windows / macOS / Linux 桌面端，差异与获取方式见[网页版与电脑版获取途径.md](网页版与电脑版获取途径.md)；只想在手机上用的话，装这一份就够了。

## 二、获取安装文件资源

安装包放在夸克网盘里，转存到自己网盘后再下载到手机即可：

[Pixiv Viewer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f98ba6b68ced)

操作路径：手机或电脑打开链接 → 选择转存（电脑端也可直接下载）→ 把 APK 文件放进手机存储。如果你还没用过夸克网盘，注册一个免费账号就够转存用。

## 三、安装步骤

1. 在手机上找到下载好的 APK 文件（一般在 `Download` 目录），点它。
2. 系统会提示"未知来源应用"或"是否允许安装"，按提示允许即可——这是安卓对非应用商店安装的正常提醒，不是异常。
3. 等待安装完成，点"打开"。
4. 首次打开会进入应用主界面；部分系统会再弹一次存储权限申请，用于保存你之后下载的插画，建议允许（不授权的话，下载功能会闪退，详见[插画与动图下载方法.md](插画与动图下载方法.md)）。

## 四、安装失败怎么办

按提示的不同对症处理：

| 现象 | 原因与处理 |
| --- | --- |
| 提示"解析包出现问题" | 安装包没下完整，重新下载一次；必要时核对 MD5 |
| 提示与已安装应用冲突 | 手机里装过别的来源的同名应用，先卸载旧的再装 |
| 提示系统版本过低 | 这份包要求安卓 5.2 及以上，老设备（安卓 4.x、5.0）装不上属于正常 |
| 安装按钮灰色不可点 | 后台有安装会话未结束，重启手机再试 |
| 装完打不开、秒退 | 先重启手机；还不行就清理应用缓存后重开 |

装好之后建议先看[登录与账号设置.md](登录与账号设置.md)：不登录也能直接浏览公开内容，登录后才能用收藏、关注、下载历史这些功能。

## 五、更新与卸载

- **更新**：直接用新版安装包覆盖安装即可，一般不需要先卸载旧版。若更新后出现异常，卸载重装前先在应用内做一次设置与数据备份（方法见[登录与账号设置.md](登录与账号设置.md)），重装后导入还原。
- **卸载**：与普通应用一样，长按图标卸载即可。想连下载的图片一起清掉，再去文件管理器里删掉应用目录下的图片文件夹。
