## 一、注册前要准备的东西

按官方帮助中心的说法，创建 Uber 账号需要三样东西，缺一个流程就走不完：

| 准备项 | 说明 |
| --- | --- |
| 可用的电子邮箱 | 用来接收账号确认邮件、行程收据 |
| 可用的电话号码 | 用来接收短信验证码，注册时必填 |
| 一张信用卡或借记卡 | 注册流程会要求填支付信息；官方明确**不接受预付卡** |

填的资料包括：姓名（名和姓分开填）、电话号码、首选语言。语言选「简体中文」后，应用内的官方邮件与收据会是中文。

## 二、注册步骤

1. 打开 Uber 应用，在欢迎页点「注册」。
2. 填写姓名、电话号码（先选区号）与首选语言。
3. 输入收到的短信验证码，完成手机号验证。
4. 设置密码，并同意条款与隐私声明。
5. 按提示添加支付方式（卡号、有效期、CVV、账单地址）；这一步也可以先跳过，之后在「账户 → 钱包」里补，但没有可用支付方式时无法叫车。
6. 去邮箱点开 Uber 发来的确认邮件，账号正式生效。

## 三、+86 手机号能不能注册

可以。Uber 注册时区号列表里有 +86，中国大陆手机号能收到验证码，这一点与很多海外应用不同。实际用起来有两个注意点：

- 注册不挑你人在哪，但**叫车挑位置**：Uber 没有在中国大陆提供网约车服务，账号里定位在大陆时找不到可叫的车。适用场景是出境后使用，服务覆盖情况可在[优步服务城市页面](https://www.uber.com/global/en/cities/)查询。
- 部分用户反馈 +86 号码偶尔收码慢或收不到，排查方法见下面第五节；实在不行可以先在网页版 [auth.uber.com](https://auth.uber.com/) 尝试注册，或换一个邮箱重走流程。

另一个对大陆用户友好的入口：微信里的「优步」小程序，供大陆用户到访香港或日本期间直接叫车，支持微信支付人民币，无需另装应用（截至本文撰写，仅限这两个地区，以官方页面为准）。这适合不想折腾注册的短期出行，但如果你常出境，独立账号的应用功能更全。

## 四、登录方式

装好应用后（安装步骤见[下载与安装教程](下载与安装教程.md)），登录有两种常用入口：

- **手机号 + 短信验证码**：输入号码、收码、输码即登录，不用密码。
- **邮箱 + 密码**：输入注册邮箱与密码。

常用补充操作：

- 忘记密码：登录页点「忘记密码」，按邮件链接重置。
- 换了手机号：登录旧账号后在「账户 → 设置」里更新电话号码；旧号已停用收不到验证码时，通过官方帮助页面的「联系我们」提交身份信息处理。
- 登录新设备时，Uber 可能要求额外验证（邮箱确认或短信验证），属正常安全流程。

## 五、收不到验证码怎么排查

按命中概率从高到低：

1. **信号与漫游**：人在境外时确认手机已开通国际漫游并能收短信（发不了短信没关系，能收就行）。
2. **短信拦截**：查看手机管家的拦截记录，海外号码发的验证短信常被误判为骚扰。
3. **欠费停机**：停机状态的号码收不到任何短信。
4. **重发与等待**：验证码有时延迟几分钟，别连续狂点重发，等 2~3 分钟再触发一次。
5. **换网络环境**：极少数情况下切换 Wi-Fi 与流量会改善，可能与运营商短信路由有关。

反复收不到时，改用邮箱+密码方式登录已有账号；新账号注册绕不开手机验证，可换一个号码再试。验证过了但应用仍有问题，去[常见问题排查](常见问题排查.md)找同类案例；接下来把支付方式配好，见[支付方式与费用明细](支付方式与费用明细.md)。
