# Uber 常见问题排查

> 本篇把用 Uber 时最常见的故障汇成一张排查清单：叫不了车、扣款失败、验证码收不到、应用打不开。按现象找小节，逐条对照处理。

## 一、点了确认却叫不了车

官方帮助把「无法叫车」归为六类原因，按顺序自查：

| 现象提示 | 处理 |
| --- | --- |
| 有未付款项 | 按应用内提示结清上一单的欠款，结清后立即恢复 |
| 付款遭拒 | 去「账户 → 钱包」更新或更换支付方式，见[支付方式与费用明细](支付方式与费用明细.md) |
| 所在区域无服务 | 输入上下车点后应用会明示该区域是否服务；换到服务区内再叫 |
| 暂无司机接单 | 换一个车型档位再试，或开启「找到司机时通知我」 |
| 邮箱或电话未验证 | 补完账号设置里的验证 |
| 应用需要更新 | 升级到较新版本；太旧的系统版本装不了新版，换设备或装本文档提供的这版安装文件 |

还有一类容易忽略：**未完成身份或年龄验证**。部分城市会随机要求上传证件验证，完成前叫不了车。

行程已经结束、东西落在车上了？直接看[东西落在车上怎么找回](东西落在车上怎么找回.md)；在机场落地后叫不到车、或想提前把接机车约好，见[机场接机与预约用车](机场接机与预约用车.md)。

## 二、验证码收不到

注册与登录都依赖短信验证码，收不到时按命中概率排查：

1. 人在境外先确认**国际漫游能收短信**（只收不发也算正常）。
2. 查手机管家的**拦截记录**，海外号码常被误判。
3. 号码**欠费停机**收不到任何短信。
4. 等 2~3 分钟再点重发，别连点。
5. 换 Wi-Fi 与移动数据试试。

已有账号但收不到码，改用邮箱+密码登录绕开短信；新注册卡死在验证这一步的完整流程，见[注册与登录流程](注册与登录流程.md)第五节。

## 三、定位不准 / 上车点漂移

- 地图上的图钉可以**长按拖动**微调，比重新输地址快。
- 室内、高架下、密集楼宇间 GPS 漂移是正常现象，走到路边开阔处再刷新。
- 确认系统设置里给 Uber 的是「精确定位」权限；只给模糊定位时上车点偏差会很大。

## 四、应用闪退 / 打不开

1. 先重启手机（多数「打不开」到这一步就好了）。
2. 系统设置 → 应用 → Uber → 存储，**清除缓存**后重开。
3. 仍闪退就卸载重装，安装包从[下载与安装教程](下载与安装教程.md)里的网盘资源拿。
4. 安装时提示「解析包出现问题」，是上次下载不完整，删掉重下并核对 MD5。

## 五、中国大陆境内能用吗

**不能叫车。** Uber 没有在中国大陆提供网约车服务，账号定位在大陆时地图上约不到车，这不是故障。可用场景与替代入口：

- **出境使用**：香港、日本、东南亚、欧美等均有服务，覆盖城市以[优步服务城市页面](https://www.uber.com/global/en/cities/)为准。
- **微信小程序**：大陆用户到访香港或日本期间，可在微信里搜「优步」小程序直接叫车，支持微信支付人民币，无需注册独立账号（截至本文撰写，以官方页面为准）。

账号、支付这些出境前的准备工作，分别见[注册与登录流程](注册与登录流程.md)与[支付方式与费用明细](支付方式与费用明细.md)。
