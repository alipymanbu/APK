## 一、登录相关

**收不到验证码**，按这个顺序试：

1. 确认手机号没输错、没多空格；检查短信是否被拦截进垃圾箱。
2. 等一分钟再点一次发送，连续快速重发容易被限流。
3. 还不行就切到登录页的**账号密码登录**方式，绕开短信通道。
4. 换网络环境（Wi-Fi 换流量）再试，个别网络出口会拖慢短信网关。

**登录后提示异常或被登出**：先确认没有在另一台设备上改动密码；重新打开应用再登录一次。账号问题通过应用内「设置 - 反馈中心」提交，或发邮件到 [contact@bajoseek.com](mailto:contact@bajoseek.com)。

## 二、免费还是收费

两个口径都如实摆在这：

- 官方与商店介绍都称**核心功能免费**：AI 搜索、深度问答、拍照解题、文档解析等日常使用不收费。
- 应用商店的资费一栏标注**含应用内购买**，即部分用量或能力可能需要付费，具体以你打开应用后「设置 / 个人中心」里显示的为准。

也就是说：装上就能用，日常问答大概率碰不到付费墙；真用到需要付费的功能时，应用内会有明确提示，按提示决定即可。价格与额度这类信息会随版本变化，本文不写死数字，以应用内当时显示为准。

## 三、使用中的常见状况

| 现象 | 先做什么 |
| --- | --- |
| 回答一直转圈不出来 | 检查网络；切换 Wi-Fi / 流量再发一次；复杂问题等它思考完，别中途退出 |
| 搜索结果明显过期 | 把时间范围写进问题里（「最近一周」），重新问；时效类内容以官方来源为准 |
| 回答到一半断了 | 直接发「继续」，它会接着上文输出 |
| 新建会话找不到 | 加号按钮位置随版本不同（右上角或右下角），认准「新建对话」含义的那个 |
| 文件解析失败 | 先确认格式（PDF / Word / Excel）没损坏；超大文件拆开后分段上传 |
| 数据、图片加载慢 | 刷新或退出重进会话；有用户反馈过偶发加载慢，重试后恢复 |
| 手机发指令电脑没反应 | 电脑端 BajoClaw 没启动或没配好，按 [BajoClaw电脑端安装与连接教程.md](BajoClaw电脑端安装与连接教程.md) 第四节排查 |

所有回答都是 AI 生成、仅供参考；拿它做决策前，重要数据自己再核一遍来源。

## 四、版本差异与更新

网盘里那份是 **1.5.0**，商店最新是 **1.6.0**（2026-06 发布）。差异集中在两处：1.6.0 给生图/P 图加了图像模型选择，给 AI 回答加了朗读。联网搜索、深度思考、文件解析、生图这些主干功能两个版本都有。

- 想要新功能：从应用商店更新，覆盖安装即可，对话历史跟着账号走。
- 保持 1.5.0 也没问题：包名一致（`com.bajoseek.app`），后续换商店版可无缝覆盖。

版本核对方法与安装包信息见 [下载与安装教程.md](下载与安装教程.md) 第五节。
