## 一、先核对这份包是哪一个版本

Zoom 是一款视频会议应用，你在应用商店里看到的正式名称叫 **Zoom Workplace**（更早的版本叫 ZOOM Cloud Meetings），安卓手机上装的就是它。动手前，先对着下表确认手上这一份是不是你要的：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | Zoom（应用全名 Zoom Workplace） |
| 开发者 | Zoom Communications Inc. |
| 包名 | `us.zoom.videomeetings` |
| 版本号 | 7.1.0.41065 |
| 安装包大小 | 150.25 MB |
| 安装包 MD5 | `7EFB0A566A8A3EECC573E074DD58FA14` |
| 适用设备 | 安卓手机、安卓平板 |
| 是否需要联网 | 是，开会、登录、同步日程都要网络 |

网上搜到的版本号是官方当前最新版，和这一份未必相同 —— 这一份的版本信息截止 2026-09-27。判断"装的对不对"只看两项：包名是不是 `us.zoom.videomeetings`，版本号是不是 `7.1.0.41065`。

**系统要求不写死。** 官方支持文档显示，Zoom 手机版从 6.3.0 起不再支持 Android 8.0 以下的系统（见 [官方系统要求页](https://support.zoom.us/hc/en-us/articles/201179966-System-requirements-for-iOS-iPadOS-and-Android)），其后门槛又有提高，这台设备装不装得上以官方页面当时显示为准。真装不上时系统会直接拦下来并提示原因，不会装到一半坏掉。另有一条老设备要注意：官方从 6.0 版起不再支持 x86 芯片的安卓设备，用这类老平板装不了新版本。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享，转存到自己账号再下载，链接固定、文件不会被中途替换。

1. 在手机上打开 [Zoom 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ae9b87389e14)。浏览器和夸克 App 都能打开，**建议用夸克 App**，大文件不容易被切后台打断。
2. 点"保存到我的网盘"转存，之后再下载就不再依赖原分享链接。
3. 进自己的网盘找到这个文件，点下载，等它落到手机存储。
4. 下完核对两件事：文件名是不是 `.apk` 结尾（这一份形如 `zoom_v7.1.0.41065.apk`）；大小是不是 150.25 MB 上下。差得多多半是没下完整，删掉重来。

习惯电脑操作的话：电脑端网盘下载，再用数据线把 apk 拷进手机的 `Download` 目录，效果一样。手边有校验工具的话，顺手算一遍 MD5 和上表比对，不一致就重下一遍；不查也不影响安装，这只是多一层保险。

## 三、安装：系统会拦一次，放行即可

这一份是通过网盘分发、手动安装的，不是从应用商店点"安装"装的，所以点开时安卓会拦一下，提示"不允许安装来自此来源的应用"。这是系统对非商店来源的常规限制，不代表文件有问题。

1. 打开"文件管理"，进 `Download`（下载）目录，点刚下好的 apk。
2. 出现拦截提示时，点提示里的"设置"，打开**允许安装此来源的应用**开关。部分机型要去"设置 → 应用 → 特殊应用权限 → 安装未知应用"里，给你打开文件用的那个 App（文件管理或浏览器）单独放行。
3. 回到安装界面点"安装"，等进度条走完。
4. 出现"打开 / 完成"时先点"完成"，把权限理顺再首次启动，省得进去之后反复弹窗。

安装失败最常见的原因是**存储空间不足**：这份包 150 MB，装完展开后占用更大，动手前留出 1 GB 以上空余。其他装不上的情况见[常见问题与排查](常见问题与排查.md)。

## 四、首次打开要给的权限

第一次启动和第一次进会时，系统会依次弹权限申请，对照下表决定给不给：

| 权限 | 什么时候要 | 不给会怎样 |
| --- | --- | --- |
| 麦克风 | 第一次进会 | 你说的话别人听不到，只能看和打字 |
| 相机 | 第一次开视频 | 别人看不到你，看别人不受影响 |
| 通知 | 首次启动后 | 收不到会议提醒，得自己记时间 |
| 日历（可选） | 你用日程同步时 | 预约的会不出现在系统日历里 |
| 显示在其他应用上层 / 悬浮窗 | 共享屏幕或用小窗时 | 开会时没法把会议缩成浮窗 |
| 投射 / 屏幕录制确认 | 共享屏幕时 | 屏幕共享发不出去 |

前三个建议都给上；后面几个等到用到时再弹再给也一样，不影响装完就用的基础功能。

## 五、装完先花两分钟自检一次

1. 打开 Zoom，不登录也能用 —— 参会本来就不需要账号。
2. 首页能出现"新会议 / 加入 / 日程 / 聊天"几个入口，界面不闪退。
3. 点"加入会议"，输入框正常弹出，就算装好了。

真开会时怎么进会，见[加入会议的几种方式](加入会议的几种方式.md)；账号要不要注册、免费版能开多长的会，见[免费版会议时长与人数限制](免费版会议时长与人数限制.md)。
