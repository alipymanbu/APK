## 一、听不到声音 / 别人听不到我

1. 先看入会时选的是不是"设备音频"：选错了点左下角的音频图标重选一次。
2. 麦克风图标上有红色斜杠就是被静音了，点一下取消。
3. 蓝牙耳机没声音：音频输出可能还挂在手机扬声器上，会议里点扬声器图标切换输出设备。
4. 只有你一个人听不到：退出会议再进一次；还不行就摘掉耳机用扬声器试，先分清是耳机的问题还是会的问题。

## 二、画面卡、延迟高

开会卡不卡，主要看上行带宽（你发出去的那一路）。官方给出的参考值如下：

| 场景 | 推荐带宽（上行 / 下行） |
| --- | --- |
| 高清画质视频 | 1.0 Mbps / 600 kbps |
| 720p 高清 | 2.6 Mbps / 1.8 Mbps |
| 1080p 高清 | 3.8 Mbps / 3.0 Mbps |
| 画廊视图（接收方） | 2.0 Mbps（25 画面）/ 4.0 Mbps（49 画面） |

数值出自[官方系统要求页](https://support.zoom.us/hc/en-us/articles/201179966-System-requirements-for-iOS-iPadOS-and-Android)；App 会按网络状况自动调画质，你只需要在网络不够时主动降需求。

**把带宽换算成流量**：上表数值 × 开会时长就是理论上限。比如 720p 一路 2.6 Mbps，开一小时理论上限约 1.1 GB，实际会低于这个数 —— 画面静止时码率会自动往下降。流量套餐紧张时，关掉视频只留语音这一路，消耗比开视频低得多。

提速的顺序：先关自己的视频（最省上行），再把画廊视图换成演讲者视图，还不行就离路由器近一点或换网络。共享屏幕时更卡是正常的 —— 共享对上行要求更高，见[屏幕共享与虚拟背景](屏幕共享与虚拟背景.md)。

## 三、注册 / 登录收不到验证邮件

1. 先翻垃圾邮件文件夹，验证邮件被分过去的概率不小。
2. 核对注册邮箱有没有敲错 —— 收不到多半是这一步。
3. 等几分钟再点"重新发送"，连续狂点反而会被限流。
4. 换个网络（流量 ⇄ WiFi）再试一次。
5. 还不行就换个邮箱重新注册；参会本来也不需要账号，见[加入会议的几种方式](加入会议的几种方式.md)。

## 四、40 分钟到点被断开

免费版单场最长 40 分钟，到点整场结束，这不是故障。处理办法见[免费版会议时长与人数限制](免费版会议时长与人数限制.md)：主持人重开一场即可，不限次数。

## 五、安装失败 / 提示升级

| 现象 | 处理 |
| --- | --- |
| 解析包出错 / 安装中断 | 包没下完整，删掉重下；对照[下载与安装教程](下载与安装教程.md)里的大小与 MD5 核对 |
| 存储空间不足 | 清出 1 GB 以上再装 |
| 不允许安装未知来源的应用 | 按[下载与安装教程](下载与安装教程.md)第三节的步骤放行 |
| 打开就提示"版本过旧，请升级" | 官方会强制旧版本升级，照提示更新即可 |
| 反复闪退 | 先重启手机；不行就卸载重装；再不行多半是系统版本低于官方要求 |

## 六、带编号的报错怎么查

App 弹出的报错有时带编号（形如 Error code: xxxx）。别到处问"这个编号什么意思" —— 拿着编号去 [Zoom 官方支持站](https://support.zoom.com) 的搜索框直接搜，多数常见编号都有对应的官方文章，比任何第三方汇总都准。

## 七、卸载重装会丢什么

- **账号不丢**：账号在云端，重装后用原邮箱密码登录即可。
- **预约的会议不丢**：会议跟着账号走，不在手机里。
- **会丢的只有本地痕迹**：聊天里下载过的文件、最近输入过的会议号记录。重装前有要留的东西先存走。
