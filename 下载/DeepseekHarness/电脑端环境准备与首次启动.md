# DSH Mobile 电脑端环境准备与首次启动

> 手机端只是「遥控器」，真正干活的是电脑上的 DeepSeek Harness（DSH）。电脑上还没装 DSH 的，先按本篇把它跑起来，再回去装手机端。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [常见问题与连接诊断.md](常见问题与连接诊断.md) · [安全设置与设备管理.md](安全设置与设备管理.md)

## 一、先判断要不要装

在电脑浏览器里打开 `http://127.0.0.1:3080`：

- 能打开 DSH 界面 → 已经装好，直接跳到第 3 步配 API Key 或回 [下载与安装教程.md](下载与安装教程.md) 装手机端插件。
- 打不开 → 电脑上没有在运行的 DSH，按第二节装。

## 二、把 DSH 跑起来的两条路

**方式 A：npx 一键启动（最省事）**

1. 装 Node.js，版本要求 22.19.0 或更高（24.x 也可以），以官方页面说明为准：[nodejs.org](https://nodejs.org/)。
2. 打开终端执行：

   ```powershell
   npx @deepseek-ai/dsh web
   ```

3. 首次运行会自动下载文件，随后在 `http://127.0.0.1:3080` 启动 Web UI 并自动打开浏览器。不想自动开浏览器可以加 `--no-open`。

注意：这种方式 DSH 活在终端里，窗口关了服务就停；下次要用重新执行同一条命令。想常驻的话用官方桌面端（Desktop），或在系统里自行配置开机启动。

**方式 B：从源码运行（想跟进最新代码时）**

```powershell
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web
```

源码方式要求 pnpm，构建产物就绪后 `pnpm dsh web` 直接使用已构建产物。仓库地址：[github.com/deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)。

## 三、首次启动后必做的两件事

1. **配模型密钥**：进 **设置 → Models**，在 DeepSeek 卡片里填入 API Key 保存，即时生效不用重启。密钥在 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建；它只保存在你电脑本机的用户数据目录里，界面上只显示脱敏引用。除 DeepSeek 外也支持其他内置厂商与 OpenAI 兼容接口。
2. **选工作区**：按界面提示选择一个电脑上的文件夹作为工作区，手机上看到的任务就在这个范围里干活。

## 四、数据都存在哪

- DSH 默认本地优先：会话内容、工具调用记录、模型服务地址与密钥都只存本机，未经同意不上传；用于排障的匿名化信息可以关闭。
- 用户数据目录默认是 `$DSH_HOME`，Windows 下通常是 `C:\Users\<你的用户名>\.dsh`。dsh-mobile 插件的数据（证书、配对记录、自定义界面）在其下的 `mobile-access/` 子目录。
- 卸载插件时用 `purge` 才会清掉 `mobile-access/`，具体命令见 [安全设置与设备管理.md](安全设置与设备管理.md)。

## 五、版本节奏要知道的一件事

DSH 处于开发者预览阶段，版本号变化快，官方明确提示未来会有破坏性变更。手机端 dsh-mobile 插件对 DSH 版本有验证过的组合要求，DSH 升级后手机端异常时，先核对 [常见问题与连接诊断.md](常见问题与连接诊断.md) 里的兼容表再排查。
