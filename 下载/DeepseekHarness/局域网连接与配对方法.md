# DSH Mobile 局域网连接与配对方法

> 手机和电脑在同一 Wi-Fi 下时，用局域网方式连接 DSH Mobile 最简单、延迟最低。本篇讲电脑端怎么开、手机怎么扫码配对、端口怎么改。

## 一、什么时候用局域网方式

- 手机和电脑连的是同一个 Wi-Fi、同一个路由器（电脑走网线也算），或者手机开热点给电脑用。
- 局域网是默认且最省事的连接方式，日常在家、在办公室优先用它；出门在外才需要远程通道（见相关文档）。

## 二、电脑端开启局域网访问

1. 打开 DeepSeek Harness，点左下角 **移动访问 → 局域网**。
2. 尚未开启时，点 **开启局域网访问**。首次配置时面板会列出电脑当前的网络，确认网卡后由插件生成私有证书。
3. 点 **生成并复制密钥**，面板上会出现配对二维码。
4. 部分操作完成后可能要求重启一次 DSH，按提示重启即可。

电脑端每次只保留一套局域网配置；配置、证书和配对记录都保存在 DSH 的用户目录 `mobile-access/` 下，界面上可以清理。

## 三、手机 App 扫码配对

1. 手机连到与电脑相同的网络，打开 DSH Mobile App，进入 **局域网访问**。
2. App 会自动发现同一网络里的电脑，点击对应设备。
3. 扫电脑端显示的二维码，或把 **生成并复制密钥** 得到的密钥粘贴进去。
4. 配对成功后建立持久信任：以后打开 App 会自动发现并连上电脑，切换 Wi-Fi、热点或路由器重新分配 IP（DHCP）通常都不需要重新配对。

配好之后手机上看到的就是电脑那份 DSH 界面：会话列表、工作区、任务输入、工具面板与电脑端实时同步。

## 四、不装 App，用手机浏览器临时访问

- 在电脑端「移动访问」卡片上点 **复制配对链接**，把链接发到手机浏览器打开即可，功能与 App 里看到的是同一个页面。
- 局域网入口用的是插件自签的私有证书，浏览器第一次打开会提示「不受信任」——这属于预期现象。确认地址确实是自己的电脑后，再按浏览器指引继续访问。
- 远程通道的公开证书由系统验证，正常情况下不应出现证书警告；如果出现了，先检查通道和证书，不要直接忽略（处理思路见 [常见问题与连接诊断.md](常见问题与连接诊断.md)）。

## 五、端口与地址

| 端口 | 用途 | 怎么改 |
| --- | --- | --- |
| 3080 | DSH Web 上游（电脑本机访问的那个界面） | `dsh web --port` |
| 3443 | 手机走的独立 HTTPS 入口 | `dsh-mobile setup --port` |

配对二维码里包含实际端口，改过端口后重新生成二维码即可，手机端不用手动填。

- 电脑有多块网卡（比如同时连了有线和 Wi-Fi）而自动选择不对时，重新执行 `dsh-mobile setup --address 192.168.x.x` 指定网卡。
- 用「手机热点 + 电脑连热点」的组合也能配对，思路与家用 Wi-Fi 完全一样。
- 防火墙：Windows 上插件会自动创建并管理所需的放行规则（卸载时 `purge` 会一并删除）；Linux 上防火墙自理，连不上时先查入站规则。

## 六、换网络之后连不上怎么办

- 插件会记住配置时的网卡。换 Wi-Fi、换热点后一般自动恢复；如果 App 一直连不上，先在电脑端 **移动访问** 里确认局域网访问仍是开启状态。
- 电脑日志里若出现「保存的网卡当前未连接」类提示，说明网卡换成了另一个（比如从 Wi-Fi 换成了网线）：重新完成一次局域网配置，或重跑 `dsh-mobile setup` 即可。
- 反复失败时跑一次 App 内的 **连接诊断**，按报告处理，具体见 [常见问题与连接诊断.md](常见问题与连接诊断.md)。

## 七、安全提醒（一句话版）

局域网入口等于把 DSH 操作权交给了配对的手机：只在家庭、办公室这类可信网络里开启；不用了就在面板上关掉。手机丢失时立即在电脑端撤销设备，完整说明见 [安全设置与设备管理.md](安全设置与设备管理.md)。
