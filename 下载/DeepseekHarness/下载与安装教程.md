# DSH Mobile 下载与安装教程

> 本篇讲怎么把 DeepseekHarness（开源项目名 DSH Mobile，DeepSeek Harness 的手机端）装到安卓手机上，并在电脑端装好配套插件，为首次配对做准备。

## 一、这套东西是什么、由几部分组成

你在手机上想用的其实是一套组合：

| 部分 | 装在哪 | 作用 |
| --- | --- | --- |
| DeepSeek Harness（简称 DSH） | 电脑 | DeepSeek 官方开源的智能体运行环境，平时你在电脑上就是用它干活 |
| dsh-mobile 插件 | 电脑（DSH 里） | 给 DSH 加一个「移动访问」入口，负责局域网/远程连接与配对 |
| DSH Mobile App（即本 APK） | 安卓手机 | 打开电脑上那份 DSH 界面，会话、工作区、消息实时同步 |

两点先说清楚：

- DSH Mobile 是社区开发者维护的第三方开源项目（Apache-2.0 许可），不是 DeepSeek 官方出品。
- 插件不修改 DSH 本体，安装卸载都走插件机制；DSH 仍按默认监听本机 `127.0.0.1:3080`，不向公网开放。

## 二、安装前要准备什么

- 一台已经装好并能正常打开 DSH 的电脑（Web UI 默认地址 `http://127.0.0.1:3080`）。
- 一台安卓手机；项目当前标注需要 Android 10 及以上（以官方发布页说明为准）。
- 第一次配对建议让手机和电脑连同一个 Wi-Fi（或电脑网线 + 手机连同一路由器），局域网配对最简单、延迟最低。
- 手机上允许「安装未知来源应用」，因为 APK 不在应用商店分发。

## 三、获取安装包

本篇开头的网盘链接里是 **DeepseekHarness 安装文件资源（夸克网盘）**，转存后取出 APK 即可。这份包的版本事实如下，与网上能搜到的最新版可能不同：

| 项目 | 值 |
| --- | --- |
| 版本 | 0.2.0（2026 年 8 月底发布） |
| 包名 | `io.github.sayach.dshmobile` |
| 大小 | 约 1.59 MB |
| MD5 | `A2900B0E068A80B7C4A1081AFC30DBB2` |

装之前可以核对一下文件完整性，Windows 上在 APK 所在目录打开终端执行：

```powershell
certutil -hashfile .\dsh-mobile-android-v0.2.0.apk MD5
```

算出的值与上表 MD5 一致即为原包。

注意版本差异：DSH Mobile 迭代很快，多设备列表、任务通知等是 0.4.0 才加入的，cloudflared、自有反向代理等远程通道也是 0.2.0 之后陆续出现的。网盘里这份 0.2.0 能满足基础的手机连接需求；想要这些新功能，可以到项目发布页取最新版：[github.com/saya-ch/dsh-mobile/releases](https://github.com/saya-ch/dsh-mobile/releases)。

## 四、手机端安装 APK

1. 把 APK 传到手机（转存网盘后手机端下载，或数据线拷贝）。
2. 在文件管理器里点开 APK，系统弹出「未知来源」提示时，按提示允许该来源安装。
3. 装完打开 App，此时还没有可连接的电脑，先去装电脑端插件。
4. （可选）用第三节命令核对 MD5，确认安装包没有被改动过。

## 五、电脑端安装 dsh-mobile 插件

按你装 DSH 的方式三选一。

**方式 A：用 npm 安装的 dsh 命令**

```powershell
dsh plugin --profile web add dsh-mobile@latest
dsh plugin --profile web exec dsh-mobile setup
dsh --profile web
```

`setup` 会自动选择并记住当前局域网网卡；只有自动选错时才需要手动指定，例如 `dsh-mobile setup --address 192.168.1.20`。

**方式 B：DSH 官方桌面端（Desktop）**

在应用的 **插件** 页面搜索并启用 `dsh-mobile`，然后打开 **移动访问** 面板完成配置。桌面端的 profile 由应用自己管理，不适用方式 A 里的 `--profile web` 参数。

**方式 C：插件市场**

```powershell
dsh plugin --profile web add dshmarket
```

重启 DSH 后，在 **设置 → 插件市场** 里搜索 `dsh-mobile` 并安装，首次打开「移动访问」时按提示确认网卡并重启一次 DSH。

装好后 DSH 界面左下角会出现 **移动访问** 入口，这是后面所有配对操作的控制台。

## 六、装完先做什么

- 电脑上其实还没装 DeepSeek Harness 本体（`127.0.0.1:3080` 打不开）：先看 [电脑端环境准备与首次启动.md](电脑端环境准备与首次启动.md)。
- 人在电脑旁边：走局域网配对，步骤见 [局域网连接与配对方法.md](局域网连接与配对方法.md)。
- 人要出门、想在外面继续用：先看 [远程访问通道选择与配置.md](远程访问通道选择与配置.md) 挑一种通道再配对。
- 连不上、提示证书警告、版本对不上：绝大多数情况在 [常见问题与连接诊断.md](常见问题与连接诊断.md) 里有对应处理办法。
- 想改手机端界面、加电脑监控面板之类的自定义能力：见 [手机界面定制与扩展.md](手机界面定制与扩展.md)。
