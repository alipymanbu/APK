## 一、从图库到第一张画布

打开应用先看到的是**图库（Gallery）**：你的所有工程按缩略图排在这里，右上角或底部的「+」就是新建入口。

新建画布时你要做两个决定：

- **尺寸**：直接选预设（A4、正方形、屏幕分辨率等）最省事。免费版受「设备分辨率」的图层规格约束，HD 大尺寸画布属于 PRO 能力（对照见 [免费版与PRO版区别.md](免费版与PRO版区别.md)）；
- **分辨率/画布大小**：打算打印就往大里选，只在手机上看就选屏幕级尺寸——图层能开多少层数和画布大小直接挂钩，画布越大层数越少。

选完进入画布界面，直接选支笔就能落笔。

## 二、主界面分块认识

界面的设计思路是「画布占满，工具收在边上」：

| 区域 | 在哪 | 放着什么 |
| --- | --- | --- |
| 工具栏 | 画布边缘的竖条/横条 | 当前工具、图层面板入口、颜色入口 |
| 图层面板 | 从工具栏展开 | 图层增删、混合模式、不透明度 |
| 色轮 | 双指从画布拉出（或点颜色入口） | 取色、色环、色板 |
| 笔刷设置 | 选中笔刷后调出 | 笔刷参数、可以停靠在画布侧面 |
| 顶部/侧边动作区 | 界面边缘 | 撤销、重做、变换、导出等 |

工具栏上的工具**可以自定义停靠**：把常用的工具/动作钉在主界面上，用不到的收起来。这是它界面上最值得花两分钟设置的地方——每个人的绘画流程不同，钉什么完全看你顺手。

## 三、先记住这几个手势

| 手势 | 效果 |
| --- | --- |
| 双指拖动 | 平移画布 |
| 双指捏合/张开 | 缩放画布 |
| 双指旋转 | 旋转画布角度 |
| 双指点画布 | 快速取色（吸管） |
| 轻扫图层面板 | 快速展开/收起图层 |
| 捏合图层 | 把选中图层捏合成一组 |

画布转歪了不用慌：手势旋转画布后，界面上有「重置视图」的动作，一键回正。

用手写笔时手掌蹭出杂线？设置里有把「手指功能」与笔分开安排的选项（禁用手指、或只让它移动画布），具体设置位置与排查见 [手写笔压感与防误触设置.md](手写笔压感与防误触设置.md)。

## 四、三种工作模式

顶部可以把工作区切成三种模式，对应绘画的三个阶段：

1. **Paint（绘制）**：Sketch / Paint / Blend 三类笔刷，起稿、上色、混色都在这里；
2. **Clone（克隆）**：把导入的照片当成绘画基底，用笔刷「画」出照片效果；
3. **Edit（编辑）**：调整颜色、液化变形、填充图案、加滤镜，类似修图工具的那一层能力。

新手常用的路径是：Paint 起稿上色 → Edit 微调颜色 → 导出。导入照片做参考图的用法在 [画笔与图层使用技巧.md](画笔与图层使用技巧.md) 里讲。

## 五、把「小课堂」用起来

**设置 → 小课堂**（部分版本叫 Tutorial / Lessons）是应用内置的分步教学，从建画布到混合模式一篇一篇带你点。比文字教程直观的地方在于它是**边讲边让你在真实画布上操作**。

一个从评论区反复被验证的经验：不少「上手觉得别扭」的反馈，过一遍小课堂后就消掉了——比如取色手势怎么触发、图层怎么展开，这些靠猜容易猜错方向。

小课堂之外还有一层「说明书级」的学习资源：官方参考手册按界面结构逐个功能讲参数级细节，查具体功能时比视频快，地址在 [常见问题与故障排查.md](常见问题与故障排查.md) 第六节。

## 六、上手路径小结

1. 新建一张屏幕尺寸的画布（层数宽裕，随便画）；
2. 钉 2~3 个你最常用的工具到主界面；
3. 过一遍小课堂前两课；
4. 开画。之后往深处走：笔刷与图层的玩法看 [画笔与图层使用技巧.md](画笔与图层使用技巧.md)，画完怎么导出看 [导出格式与PSD互通.md](导出格式与PSD互通.md)。
