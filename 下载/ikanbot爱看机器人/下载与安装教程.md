## 一、先把安装包拿到手

ikanbot 没有统一的官方应用商店页，你在各下载站看到的「爱看机器人」条目版本五花八门（第四节细说）。省事的做法是直接从上面的网盘取包——里面的版本信息是固定的，你知道自己装的是哪一份：

| 项目 | 值 |
| --- | --- |
| 版本 | 2 |
| 包名 | `iKanBot.com` |
| 大小 | 3.38M |
| MD5 | `d2c0972fb59192b69f0f290febe4e52f` |

下载完别急着装，先对照上表核一遍 MD5——尤其当你从别的渠道也拿过同名安装包时，两份文件 MD5 不同就说明不是同一个东西，别混着装。[ikanbot 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3dece4b865ea)

## 二、手机上怎么装

安卓手机装第三方 APK 的步骤是固定的：

1. 在手机浏览器里打开网盘链接，下载这个 3.38M 的 APK 文件。
2. 点击下载好的文件，系统多半会弹「不允许安装未知应用」或「检测到风险」之类的提示。
3. 按提示进入设置，把「允许安装未知来源应用」授权给你的浏览器或文件管理器，再回到文件列表点一次安装。
4. 装完打开图标，能进主界面就算成功。
5. 确认能正常打开后，可以把刚才那个安装来源开关关回去——它是「装完这个包就不再需要」的东西，关掉能降低误装别的 APK 的概率，下次升级再临时打开。

几个容易卡住的点：

- **存储空间**：安装包只有 3.38M，但安装后解压需要几倍空间，提示空间不足时先清一清手机存储。
- **安全软件拦截**：部分手机自带的安全中心会拦「非商店来源」的安装，按提示选「仍要安装」即可；不确定来源是否可信时，对照第一节的 MD5 再决定。
- **安装包下载不完整**：文件大小对不上 3.38M 说明没下完整，删掉重下，别硬装。

## 三、装完先核对再用

- **核对包名与版本**：在手机的「设置 → 应用管理」里找到已装的 ikanbot，看包名是否为 `iKanBot.com`；版本信息在应用内的设置或关于页（以你手上这版界面为准），应显示 2。
- **确认网络已连通**：ikanbot 的搜索与播放都靠网络拉内容，首次打开前先确认手机能正常上网，否则打开就是一直加载，容易误判成软件坏了。
- **不用先注册**：直接进主界面就能搜片用起来，若你那版界面弹出登录框，跳过即可。

装好之后怎么找片，见 [搜索找片与榜单使用.md](搜索找片与榜单使用.md)；打不开、闪退、卡住不动，见 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 四、网上同名条目很多，怎么确认装的是哪一份

搜「爱看机器人」会冒出一堆条目：版本号有 v1.5、v1.6、2、6.34 等等，体积从 3.38M 到 177M 都有，页面标题还带「官网版」「免费追剧」各种后缀。这不是你搜错了——同名应用在不同渠道就是各发各的版，标题与体积都对不上很正常。

辨别方法只有一条：**认包名和 MD5，不认标题**。

1. 下载前看渠道页标注的包名，是不是 `iKanBot.com`；
2. 下载后核对文件大小是否为 3.38M、MD5 是否与第一节表格一致；
3. 装完再到「应用管理」里确认一次包名。

三项都对上，装的就是本文档说的这一份；任何一项对不上，就是另一个包，功能与界面可能完全不同，别拿本文档的说明去套。
