# Reqable 独立模式与协同模式怎么选

> 手机端 Reqable 有两种工作模式：独立模式不依赖电脑，协同模式把手机流量转到电脑端的 Reqable 上处理。本篇讲这两种模式各能干什么、在哪里切换、协同模式怎么配对，以及连不上时先查什么。

## 一、两种模式差在哪

手机端 Reqable 支持两种工作模式：

- **独立模式**：不需要电脑，直接在手机上分析应用流量、做接口测试。
- **协同模式**：把手机流量转发到电脑端的 Reqable，在电脑上做拦截和处理。

| 对比项 | 独立模式 | 协同模式 |
| --- | --- | --- |
| 是否需要电脑 | 不需要 | 需要电脑上同时开着 Reqable 桌面端 |
| 流量在哪里看 | 手机屏幕上 | 电脑端 Reqable |
| 数据视图 | 应用内提供多种视图（JSON、HEX、图片等） | 桌面端的完整功能 |
| 根证书 | 用手机端自己生成的那张 | 扫码连接后，电脑端根证书自动同步到手机 |

手动在 Wi-Fi 里填一个代理、把手机流量转给电脑端，是更早的常见做法，但它有四件绕不开的麻烦：代理要手动配置、调试完还得改回去；部分应用框架和网络库不读系统代理（Flutter 是典型）；把根证书倒进手机很麻烦；Wi-Fi 代理是全局的，没法只针对某个应用生效。协同模式正是冲着这四条来的：

- 不用设置手机 Wi-Fi 代理，直接在电脑上拦截和操作手机流量。
- 走 VPN 机制，流量拦截更全面。
- 自动把电脑端的根证书同步到手机，省掉「浏览器输地址下载证书」那一步。
- Android 上还能拿到流量所属的应用信息。

## 二、在哪里切换

- 初始化引导里选过一次，之后仍可改。
- **回到独立模式**：侧边栏选「调试」Tab，就是本机独立调试。
- **切到协同模式**：侧边栏 →「远程设备」→ 右上角 `+` 添加电脑端设备；或者直接用扫码。

## 三、协同模式配对（三步）

1. 电脑端 Reqable 打开二维码页面。
2. 手机端安装好 Reqable 并启动，初始化时选协同模式，扫电脑端那个二维码。如果手机和电脑在同一个局域网里，手机端还会自动发现可协同的设备，点一下就能直接添加。
3. 连接成功后，电脑端的根证书会自动同步到手机。Reqable 会记住电脑的 IP 和端口，下次启动自动连接。

注意同步和安装是两件事：证书同步过来只省掉了手动传输，**安装仍然要在手机上完成**。手机端会自动检查安装状态，没装好会在证书页显示红色的「证书未安装」提示，并附上对应平台的安装指引。

电脑的 IP 或端口变了，重连方式是在侧边栏点扫码图标重新扫一次。

## 四、连不上时先查这四项

| 现象 | 检查点 |
| --- | --- |
| 扫码连不上 | 手机和电脑是否在同一个局域网下 |
| 同一网络里也连不上 | 有些局域网禁止跨网段通信，确认两端在同一网段 |
| 始终握手失败 | 电脑防火墙是否拦了 Reqable 代理端口的进出流量 |
| 换个网络就通了 | 让电脑连手机热点，再用手机扫码连电脑 |

## 五、设备管理在哪

**电脑端**：打开「设备」面板，可以看已连接的协同设备，也会自动发现可协同的移动端；点 `+` 能直接在手机端把当前设备加为协同设备。对本机设备点 `...`，可以改设备名称、改设备令牌（令牌相同的设备之间才能自动发现）、开关协同控制、开关设备发现。

**手机端**：侧边栏 →「设备管理」，可以删除设备、添加新设备、编辑当前设备；点已保存的设备还能看它的详细信息。

协同模式的远程设备数量，社区版是 1 个。

## 六、什么时候选哪个

- 只想看看某个 App 发了哪些请求、当场确认一下 → 独立模式。
- 要看大 JSON、要做对比、要把抓到的请求转成接口测试案例 → 协同模式。
- 手边没有电脑，或电脑和手机不在同一个网络里 → 只能用独立模式。

不管哪种模式，只要目标是 HTTPS 流量，都先要把根证书装好。装在哪个目录、装完还解析不了怎么办，见 [证书安装与SSL握手失败排查.md](证书安装与SSL握手失败排查.md)。设置都对了却还是没流量，按 [抓不到流量怎么排查.md](抓不到流量怎么排查.md) 的三种情况表对号入座。
