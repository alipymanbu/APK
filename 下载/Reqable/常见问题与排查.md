## 一、装不上或装完打不开

| 现象 | 常见原因 |
| --- | --- |
| 提示「解析包错误」或「应用未安装」 | 安装包与手机 CPU 架构不符，或系统版本低于 Android 5.0 |
| 提示「禁止安装未知来源应用」 | 没给当前用的文件管理器或浏览器开安装权限 |
| 装完点开就闪退 | 先核对系统版本与架构；仍闪退就把日志带上反馈 |

排查顺序建议先架构、再系统版本——这两项对不上，后面怎么折腾都没用。怎么看自己的架构，见 [下载与安装教程.md](下载与安装教程.md) 第二节。

## 二、要给它哪些权限

- **通知权限**：调试状态通过通知展示。不给也能抓包，但看不到当前状态。
- **VPN 权限**：记录模式选 VPN 时必须给，否则建立不了本机 VPN，流量不会经过 Reqable。
- **安装未知应用**：只在安装那一步需要，装完可以收回。

## 三、手机连不上电脑（协同模式）

| 检查点 | 说明 |
| --- | --- |
| 同一局域网 | 手机和电脑要在同一个网络下 |
| 同一网段 | 有些局域网禁止跨网段通信 |
| 电脑防火墙 | 是否放行了 Reqable 代理端口的进出流量 |
| 换一种连法 | 让电脑连手机热点，再用手机扫码连电脑 |

完整的配对步骤与设备管理入口，在 [独立模式与协同模式怎么选.md](独立模式与协同模式怎么选.md)。

## 四、证书类问题

证书没装、装错目录、装完某几个 App 仍然解析不出来、Chrome 和 Firefox 要额外开关——这几类统一整理在 [证书安装与SSL握手失败排查.md](证书安装与SSL握手失败排查.md)。打开开关、浏览器能开网页但列表里没有请求，那种属于另一类问题，走 [抓不到流量怎么排查.md](抓不到流量怎么排查.md)。

浏览器能抓、某个 App 抓不到，多半是那个 App 不走系统代理，两种流量捕获模式的差别见 [常规模式与增强模式有什么区别.md](常规模式与增强模式有什么区别.md)。

## 五、访问境外站点

官方的说法很直接：**Reqable 本身不具备访问受限网站的能力**。它能做的是把流量转给你配置的线路，不解决线路本身可达不可达。

如果你所在的环境允许访问这些站点，官方 FAQ 给的做法是三步：电脑端装好对应的网络代理工具，把 Reqable 的二级代理指向它，然后手机端扫码走协同模式。二级代理在社区版有 1 条规则可用。

## 六、日志在哪看

侧边栏 → **长按顶部的 Logo** → 选择日志文件查看。反馈问题时把日志一并附上。

## 七、数据存在哪，怎么带走

- 抓包记录、API 集合、环境变量默认保存在本机的应用数据里，不登录也能用。
- 历史记录默认保留 30 天，订阅版保留更久。
- 想长期保存或换机带走：把会话导出成 HAR 或会话文件，把请求导出成 cURL。
- 卸载应用会清掉本机数据。卸载前先把要留的内容导出去。

想让多台设备的数据自动对齐，得用订阅版的云端同步，具体差别见 [免费版与订阅版有什么区别.md](免费版与订阅版有什么区别.md)。

## 八、发现 Bug 或想提需求

官方在 GitHub 的 `reqable/reqable-app` 仓库受理问题与建议。反馈时把这四项写全：Reqable 版本号、手机型号与系统版本、记录模式（VPN 还是代理）、日志文件。信息齐了，对方基本能直接复现。
