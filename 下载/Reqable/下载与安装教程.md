## 一、网盘里这份安装包是哪一版

Reqable 的桌面端和手机端是分开打包的，网盘里这份是**安卓端**安装包，属性如下（2026-09 核对）：

| 项目 | 值 |
| --- | --- |
| 版本 | 3.0.30 |
| 包名 | `com.reqable.android` |
| 安装包大小 | 30.80 MB |
| MD5 | `E18F7C834D3DB21A7971E2A3156658A6` |

官方下载页上显示的版本号会随时间往前推进，与这份包不一定相同。想确认手机上装的是不是这一版，进 `设置 → 应用 → 应用管理 → Reqable` 就能看到版本号。

## 二、装之前先确认两件事

### 系统版本

官方对安卓端的要求是 **Android 5.0 及以上**。低于这个版本的设备装不上。

### CPU 架构

官方安卓包按三种架构分发：

| 架构 | 常见于 |
| --- | --- |
| `arm64-v8a` | 近几年绝大多数手机 |
| `armeabi-v7a` | 2016 年前后的老设备 |
| `x86_64` | 基本只出现在模拟器上 |

不确定自己是哪种，可以用电脑执行（需已开启 USB 调试）：

```shell
adb shell getprop ro.product.cpu.abi
```

装错架构的典型表现是安装时提示「解析包错误」，或装完打不开。网盘里这份是其中一种架构；如果你这台设备装不上，可以到[官方下载页](https://reqable.com/zh-CN/download/)按自己的架构重新取一个包。

## 三、安装步骤

1. 手机上打开 [Reqable 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3413aaf4ef46)，进入分享页后先把文件**转存**到自己的网盘，再从网盘里下载——直接从分享页下载有时会中断。
2. 下载完成后，在文件管理器里点开这个 apk。
3. 系统提示「禁止安装未知来源应用」时，按提示到 `设置 → 应用 → 特殊应用权限 → 安装未知应用`，给当前用的文件管理器或浏览器放行。
4. 回到安装界面点安装。部分系统会要求校验锁屏密码或指纹，按提示验证即可。

## 四、第一次打开要处理的三件事

启动后会依次遇到三件事：

1. **通知权限**——调试状态是通过通知展示的。不给也能抓包，但状态就看不到了。
2. **VPN 权限**——记录模式选 VPN 时必须给。不给的话建立不了本机 VPN，流量不会经过 Reqable。
3. **工作模式选择**——独立模式（只用手机）还是协同模式（配合电脑）。这个选择之后可以改，拿不准就先选独立模式。两种模式的差别见 [独立模式与协同模式怎么选.md](独立模式与协同模式怎么选.md)。

## 五、装完建议先做的两件事

- **装根证书**：只要要分析的是 HTTPS 流量，这一步绕不开。装哪个目录、Chrome 和 Firefox 为什么要单独处理，都写在 [证书安装与SSL握手失败排查.md](证书安装与SSL握手失败排查.md) 里。
- **把记录模式改成 VPN、并确认增强模式开着**：进调试设置，把「记录模式」从代理改成 VPN；增强模式在 Android 上默认就开，装完顺手确认一眼。留在代理模式时，不少自带网络栈的应用流量根本不会进 Reqable——这是「开关开了却一条都没有」最常见的原因。两个开关各管什么，见 [常规模式与增强模式有什么区别.md](常规模式与增强模式有什么区别.md)；判定方法见 [抓不到流量怎么排查.md](抓不到流量怎么排查.md)。

## 六、更新与旧版本

- **更新**：官方下载页按平台给最新包。官方提醒过，用协同模式时手机端与电脑端要一起更新，只升一端可能连不上。旧版本还会带着后来才修掉的问题，比如抓个别站点报「服务器 SSL 握手失败」，撞上了先升级再排查，细节见 [证书安装与SSL握手失败排查.md](证书安装与SSL握手失败排查.md) 第七节。
- **旧版本**：官方在 GitHub 的 `reqable/reqable-app` 仓库 Releases 页保留历史版本，需要旧版可以从那里取。
- **卸载**：抓包记录、API 集合、环境变量都保存在本机应用数据里，卸载会一并清掉。要留的内容卸载前先导出成 HAR 或会话文件。
