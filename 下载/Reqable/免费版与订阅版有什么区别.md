## 一、三个版本

| 版本 | 价格 | 适合谁 |
| --- | --- | --- |
| 社区版 | 免费 | 只需要基础功能的个人用户 |
| 订阅版 | 国内站 ¥99/年，海外站 $49.9/年 | 需要在多台设备之间同步的个人或小团队 |
| 企业版 | 按需报价 | 需要团队协作、私有化部署的团队 |

价格与权益会调整，付款前请以官方定价页当时显示的为准。年付之外还有月付与永久授权可选，永久授权通常带折扣。

## 二、社区版免费能给到什么

- **全平台可用**——桌面端和手机端都包含在内，不是只给桌面端。
- HTTP(s) 抓包调试。
- API 测试与管理。
- 云端存储（有额度，见下表）。
- 通过官方 GitHub 社区获得支持。
- **可以商用**。官方 FAQ 里明确写了这方面没有任何限制，商业场景也能直接用。

对多数个人用户来说，抓包调试和接口测试这两件核心事情，社区版就能做完。

## 三、订阅版多了什么

在社区版的基础上：

- 多设备数据同步。
- 解锁全部特性，放开下表里的各项额度。
- 同一个邮箱账号最多可同时授权 **6 台设备**，超出后最先登录的那台会被自动登出。
- 新功能优先体验、优先技术支持。
- 国内站购买还赠送 IShell 会员（30 天），并可以申请开发票。

## 五、3.0 起的账号体系

从 3.0 版本开始，Reqable 改成了账号体系：购买订阅版后**用邮箱登录就解锁高级功能**，不再需要输入许可证序列号。社区版则依然不需要登录、不需要注册，装完即可用。

## 六、退款与旧许可证迁移

- **退款**：在有效退款周期内可以自助退款，也可以发邮件到官方支付邮箱 `payment@reqable.com` 申请。
- **迁移**：以前买过专业版许可证的，登录账号后进「个人中心」，点「绑定许可证」，输入旧的许可证密钥即可完成迁移。
