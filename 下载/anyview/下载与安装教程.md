## 一、装之前先分清你要哪个端

AnyViewer 是多端软件，Windows、iOS、Android 各有一个客户端，作用不一样：

| 你想做的事 | 需要装哪个端 |
| --- | --- |
| 用手机控制电脑 | 安卓版（本篇）+ 电脑上的 Windows 版 |
| 用电脑看/控制手机 | 安卓版（本篇）+ 电脑上的 Windows 版 |
| 只在两台电脑之间远程 | 只需两台电脑装 Windows 版 |

安卓版的包名是 `com.aomei.anyviewer`，与 AOMEI 官方在 Google Play 上发布的一致。装完后可以在系统「应用信息」里核对一下包名，确认拿到的是官方客户端。

## 三、安卓手机上的安装步骤

1. 在夸克网盘客户端里把安装包转存到自己的网盘，再从网盘下载到手机存储。
2. 在手机文件管理器里找到这个 `.apk` 文件，点开。
3. 系统会提示「不允许安装未知来源应用」，按提示允许当前文件管理器（或浏览器）安装应用；不同品牌的入口名称略有差异，一般在「设置 - 安全」或安装时的弹窗里。
4. 回到安装界面，点「安装」，等待完成。
5. 打开 App，首次启动会请求网络、通知等基础权限，按需允许。

如果安装时提示「解析包出错」或「安装失败」，多数是下载不完整——重新下载一次安装包，或先核对文件大小是否约 60.25 MB 再装。

## 四、装完第一件事：注册并登录账号

AnyViewer 的核心玩法是「两端登录同一个账号」，这样手机端的「我的设备」列表里才会出现你的电脑，才能一键发起控制：

1. 打开 App，注册一个 AnyViewer 账号（邮箱即可）。
2. 电脑端装好 Windows 版后登录**同一个**账号。
3. 手机端「设备」页刷新，能看到自己的电脑就说明两端已打通。

具体的电脑端准备与连接操作，见 [手机控制电脑的设置步骤.md](手机控制电脑的设置步骤.md)；如果登录或连接环节出问题，按 [连接失败与卡顿排查.md](连接失败与卡顿排查.md) 的清单逐项检查。
