# AnyViewer 连接失败与卡顿排查

> 手机连不上电脑、连上后黑屏或卡顿，是 AnyViewer 使用中最常遇到的三类问题。本篇给一个从易到难的排查顺序，多数情况按清单走一遍就能定位。

## 一、连不上：先按这个顺序查

| 检查项 | 怎么确认 |
| --- | --- |
| 电脑端在运行吗 | 被控电脑上 AnyViewer 窗口是否开着（或已设开机自启并在后台运行） |
| 两端是同一账号吗 | 手机「我的设备」列表里能不能看到这台电脑；看不到多半是账号不一致 |
| 目标设备在线吗 | 设备列表里该电脑是灰色/离线状态，说明电脑关机、断网或软件被退出了 |
| 登录设备超限吗 | 免费版一个账号只能登录 3 台设备，第 4 台会登录失败，先去账号里移除一台（见 [免费版限制与付费计划.md](免费版限制与付费计划.md)） |
| 网络环境放行吗 | 公司/校园网络可能限制远程桌面流量，换手机热点试一次即可分辨 |
| 安全码还有效吗 | 临时安全码默认每次重启软件都会变，拿旧码连不上；固定码被改过同理（见 [无人值守访问与安全码设置.md](无人值守访问与安全码设置.md)） |

手机端自带**设备连接诊断**功能，连接异常时先跑一次诊断，它会指出问题出在网络还是设备状态。

另外一个容易忽略的点：走「一键控制」要求两端都登录账号；如果你是想临时控制一台没登录你账号的电脑，应该改用按设备 ID 发起控制请求的方式，由对方当场确认。

## 二、连上但屏幕是黑的

按出现原因分两种情况：

- **被控端开了隐私模式**：隐私模式会把被控电脑的物理屏幕变黑并禁用其键鼠，属于功能本身的行为，不是故障。你这边仍可正常操作，别人在电脑前看不到画面。反过来说，如果你是被「客服」要求装软件、让对方连进来的那一方，屏幕自己变黑就要警惕了，先按 [远程控制诈骗的识别与止损.md](远程控制诈骗的识别与止损.md) 核对。
- **画面长时间加载不出来**：多见于被控端刚锁屏、或显卡输出异常。先在被控端按一下键盘唤醒，或在操作菜单里尝试重新建立会话；也可以开启「隐藏桌面壁纸」减少一层数据量再试。

## 三、卡顿、画质差的改善办法

- 在会话设置里把**画质调低一档**，流畅度会明显改善；网络好时再调回来。
- 开启**隐藏桌面壁纸**：静态桌面内容减少，画面更新更轻快。
- 让**智能帧率**保持开启，它会按带宽自动取舍，弱网下比固定高帧率稳。
- 换网络：手机与电脑任何一端在弱 Wi-Fi 下都会拖慢整体，优先保证被控电脑一侧走有线或稳定 Wi-Fi。

远程场景下画质与延迟互相牵制，先保流畅再谈清晰，是更省事的调法。

## 四、登录与账号问题

- 开了**双因素认证**的账号，换新手机登录时需要输入验证码，确认接收渠道（邮箱）能正常收信。
- 密码找回走官网登录页的忘记密码流程，不要在第三方页面输入账号信息。

## 五、最后再查版本

两端版本过旧可能带来连不上或功能缺失（例如新功能旧客户端没有）。安卓版可对照官方渠道检查更新——本文配套网盘里那份为 4.3.0 版，若官方已有更新版本，建议两端都升到最新再试；安装与升级方式见 [下载与安装教程.md](下载与安装教程.md)。

排查顺序总结：先确认设备在线与账号一致，再查额度与网络，最后看版本——从左到右，逐项排除。
