# AnyViewer 手机控制电脑的设置步骤

> 第一次用安卓手机控制 Windows 电脑，需要先把电脑端准备好、两端登录同一账号，然后在手机上点目标电脑发起控制。本篇按顺序讲完整流程，以及连上之后你会用到的那些操作。

## 一、先搞清楚两种控制方式

AnyViewer 手机控制电脑有两种路径，选哪种取决于电脑旁边有没有人：

| 方式 | 适用场景 | 前提 |
| --- | --- | --- |
| 账号一键控制（无人值守） | 控制自己家里/公司的电脑，旁边没人 | 两端登录同一个 AnyViewer 账号 |
| 向对方发起控制请求 | 帮别人修电脑，对方在电脑旁能点确认 | 知道对方的设备 ID，对方当场同意 |

对自己常用的电脑，建议一开始就把账号方式配置好，之后每次连接只要点一下。

不登录账号的电脑也能无人值守：走「临时安全码」或「固定安全码」。临时码默认每次重启软件就换、固定码怎么设，见 [无人值守访问与安全码设置.md](无人值守访问与安全码设置.md)。

## 二、电脑端准备（Windows 版）

1. 在官网 [www.anyviewer.com](https://www.anyviewer.com/) 下载 Windows 版并安装。
2. 启动后注册一个 AnyViewer 账号并登录。
3. 保持 AnyViewer 在电脑上运行。想让电脑重启后也能随时被连上，可以在设置里开启开机自动运行——无人值守场景建议开。

登录后电脑会出现在你这个账号的「我的设备」列表里，这是下一步手机能一键连上的基础。

## 三、手机端发起连接

1. 手机上打开 AnyViewer，登录**与电脑相同的**账号（还没装的话，先看 [下载与安装教程.md](下载与安装教程.md)）。
2. 底部切到「设备」页，在「我的设备」里找到目标电脑。
3. 点这台电脑，选「远程控制」（或「一键控制」），稍等片刻即可看到电脑桌面。
4. 在安卓上用手指点按、拖动即可操作鼠标；也可以在操作菜单里切换成虚拟鼠标模式，用滑动代替点按，习惯哪种用哪种。

如果你要走「帮别人修电脑」的临时模式，则在手机端选择按设备 ID 发起控制请求，对方在其电脑上点同意后连入；这种方式不需要对方登录账号。

## 四、连上之后的常用操作

连接建立后，从屏幕边缘唤出操作菜单，常用的有这些：

- **电源管理**：远程锁定、关机、重启电脑——出门前忘了关机时很实用。
- **快捷入口**：一键打开被控电脑的「此电脑」、任务管理器、CMD，省去自己找图标。
- **多显示器切换**：电脑接了多个屏幕时，在几个显示器之间切换查看。
- **自定义热键**：把常用命令绑到自定义键盘按键上，操作更快。
- **隐私模式**：开启后被控电脑的物理屏幕会变黑、键鼠被禁用，适合你在公共场所操作含隐私内容的电脑。
- **隐藏桌面壁纸**：画面更清爽、可见度更高，弱网时也有帮助。
- **聊天窗口**：与被控端文字沟通，适合远程支援场景。

## 五、免费版够不够用

手机控制电脑的功能在免费版里就能用，但账号能登录的设备数、可同时控制的会话数有限额。如果你有几台电脑、或想两台手机同时连，先对照 [免费版限制与付费计划.md](免费版限制与付费计划.md) 里的限额表再决定要不要付费。

连接不上、黑屏、画面卡顿这些情况，按 [连接失败与卡顿排查.md](连接失败与卡顿排查.md) 的顺序排查，多数问题一两分钟能定位。
