# AnyViewer 把安卓屏幕投到电脑的方法

> 除了手机控制电脑，AnyViewer 也支持反过来的方向：把安卓屏幕镜像到电脑上观看，或直接用电脑操作安卓设备。本篇讲这两个场景怎么设置、需要哪些权限、分别适合什么用途。

## 一、安卓端 App 承担的两个角色

安卓版 AnyViewer（包名 `com.aomei.anyviewer`）是双向的：

- **当遥控器**：控制你的 Windows 电脑——这是多数人的主用途，见 [手机控制电脑的设置步骤.md](手机控制电脑的设置步骤.md)。
- **当被看/被控端**：把这块屏幕投到电脑上，或允许电脑反过来操作这台手机。

两个角色用同一个 App、同一个账号完成，不需要额外装别的软件。

## 二、屏幕镜像：扫码投屏到电脑

镜像（Mirror）是最轻量的用法，步骤如下：

1. 电脑端 AnyViewer 与手机端登录**同一个**账号。
2. 在电脑端发起「镜像安卓屏幕」功能，屏幕上会出现一个二维码。
3. 手机端打开 App 扫这个二维码，并按系统提示允许屏幕捕获权限。
4. 投屏建立后，电脑上会实时显示手机画面，官方标注为高清、低延迟。

首次使用时安卓系统会逐项弹出权限请求（网络、屏幕捕获等），全部允许后流程才能继续；中途拒绝会导致投屏黑屏或直接失败，到系统设置的权限管理里补开即可。

## 三、用电脑控制安卓

除了「看」，AnyViewer 也支持从电脑（以及 iOS 设备）反向控制安卓设备，用来远程诊断和修复手机上的问题。设置路径与镜像类似：同一账号下，在电脑端选择目标安卓设备发起控制，手机上按提示确认并授予所需权限即可。

连上后你可以像坐在手机前一样操作：打开设置、卸载应用、处理弹窗。给异地长辈调手机时，这个方向比让老人描述屏幕内容高效得多。

## 四、这些方向各自的典型用途

| 场景 | 建议用法 |
| --- | --- |
| 开会/课堂演示手机 App | 屏幕镜像，扫码即投 |
| 盯着孩子或共用设备的使用情况 | 镜像 + 电脑端实时监控 |
| 异地帮家人修手机 | 电脑反向控制安卓 |
| 手机放公司充电，人在外面想看消息 | 镜像到随身笔记本（同一账号下） |

## 五、注意事项

- 镜像与反向控制都要求两端登录同一账号，账号体系与额度（免费版 3 台登录设备等）同样适用于这个方向，详见 [免费版限制与付费计划.md](免费版限制与付费计划.md)。
- 投屏画质与流畅度受两端网络影响，卡顿时按 [连接失败与卡顿排查.md](连接失败与卡顿排查.md) 里画质与帧率那一节调。
- 会话传输采用端到端加密，但投屏内容会完整显示在电脑屏幕上——公共场合使用时注意周围环境。
