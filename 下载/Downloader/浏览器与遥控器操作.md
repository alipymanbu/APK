## 一、遥控器按键对照

官方文档给出的按键映射如下（以遥控器上的图标为准）：

| 按键 | 作用 |
| --- | --- |
| 四个方向键 | 移动屏幕上的光标 |
| 确认键（方向键中间） | 点击光标下的链接 |
| 快进键 | 放大页面 |
| 快退键 | 缩小页面 |
| 菜单键 | 打开浏览器菜单；连按两次切换全屏 |
| 返回键 | 回到上一个页面 |
| 播放键 | 前进到下一个页面 |

滚动页面的方式是把光标往页面边缘移：光标到边缘后继续按同方向，页面就朝该方向滚动；滚到底后焦点会移出浏览器窗口、落到上下的导航菜单上。

## 二、游戏手柄操作

接了手柄的话，对应关系是：左摇杆移光标，Ⓐ 键点击，R1 放大、L1 缩小，按下左摇杆前进，菜单键同样是浏览器菜单与全屏开关。

## 三、浏览器菜单里有什么

浏览器右上角的菜单图标（或遥控器菜单键）打开的菜单里，主要有：收藏夹列表、把当前页面存为收藏（页面标题与网址会自动填好）、全屏模式开关。全屏也可以用「菜单键连按两次」快速进出。

## 四、JavaScript 开关

浏览器里的 JavaScript 默认是关闭的。典型表现是：网页加载出来缺块、按钮点了没反应、排版乱掉。

- 打开路径一：浏览器菜单里的 JavaScript 开关；
- 打开路径二：应用主界面的 Settings 区，勾选 Enable JavaScript In Browser。

保持默认关闭也有好处：页面加载更快，广告脚本多半不加载。所以更省心的用法是平时关着，哪个页面坏了再单独开它。

## 五、从浏览器里发起下载

在网页里点下载链接，Downloader 会接手把文件存到下载目录（默认 `/sdcard/Downloader`），效果与你在首页直接输文件地址一致。存下来的文件怎么装、怎么删，见 [文件管理与收藏夹.md](文件管理与收藏夹.md)。

Fire TV 上从 Amazon Appstore 装的版本，如果任何网页都打不开（提示 Webpage not available），那是商店渠道默认没装浏览器引擎，装上官方浏览器组件即可，见 [浏览器组件安装方法.md](浏览器组件安装方法.md)。
