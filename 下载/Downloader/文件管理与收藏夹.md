## 一、下载目录与文件列表

所有下载的文件都落在下载目录里，默认是设备的 `/sdcard/Downloader`。位置可以在 Settings 的 Download Folder 里改——填的是 /sdcard 下的文件夹名，不存在会自动创建；Files 区列出的就是这个文件夹里的全部内容。

在 Files 列表里：

- 选中一个文件按确认键 = 打开它；APK 文件会直接触发系统安装流程；
- 高亮后按菜单键 = 删除，有确认步骤，删了就找不回来。

电视盒子空间普遍紧张，APK 装完本身就没有保留价值，定期进 Files 清一清属于正常维护。

## 二、APK Auto-Install 设置

Settings 里的 APK Auto-Install 默认勾选：APK 一下完就弹安装提示。取消勾选的场景是「一次要下好几个包」——先让所有包下完，再从 Files 里逐个打开安装，避免每个包下完都停下来等你确认一次。

## 三、收藏夹

收藏夹就是网址书签，在 Favorites 区管理：

- **添加**：Favorites 菜单里的 Add new favorite，名字可不填（不填就用网址当名字）；从浏览器菜单里添加更省事，当前页面的标题和网址会自动填好；
- **上限**：最多存 500 条；名字和网址完全相同的重复条目不允许；
- **载入**：选中一条按确认键——存的是网页地址就打开网页，存的是文件地址就直接开始下载；
- **编辑 / 删除 / 排序**：高亮后按菜单键，分别对应 Edit favorite、Delete favorite、Move favorite（选 Move 后用上下键调整位置，再按确认保存）。

Favorites 菜单里还有一个 Delete ALL favorites，一次性清空全部收藏，删除不可恢复，按之前想清楚。

## 四、批量导入导出（换设备迁移）

收藏支持整批进出，载体是纯文本 .txt：

- **导出**：Favorites 菜单里选 Export favorites to file，会在下载目录生成一个 `downloader-favorites-日期.txt`（文件名形如 downloader-favorites-2026-09-29）；
- **导入**：两个入口——Import favorites from file（从下载目录里选 .txt 文件）和 Import favorites from URL（给一个在线 .txt 地址，也支持 pastebin.com 页面）。

文件格式：每行一条，行首是网址，后面跟一个空格再加可选的名字（名字里可以有空格）：

```text
https://www.google.com Google
https://amazon.com Amazon
http://urls-without-names-are-also-fine.com
```

换设备时，把导出的 txt 传到新设备的下载目录再导入，收藏就整体搬过去了。导入完成后逐条核对一遍，个别失效链接按 [短代码下载用法.md](短代码下载用法.md) 里说的换新地址。
