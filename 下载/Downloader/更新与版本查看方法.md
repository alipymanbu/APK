# Downloader 更新与版本查看方法

> 这一篇讲 Downloader 怎么更新：商店渠道的自动与手动更新、侧载安装版的覆盖升级，以及在哪里看当前版本号与官方更新记录。

## 一、先看当前是什么版本

在系统设置里就能看：Fire TV 是「Settings → Applications → Manage Installed Applications → Downloader」，条目里会列出版本号；安卓手机与平板在系统「设置 → 应用」里同样能看到。本文的 Downloader 安装文件资源对应的是 1.5.1-ForGoogleAndroidDevices 这一版，设备上显示的号如果不一样，说明装过别的版本，更新前先看清当前状态。

官方每次更新改了什么，可以查官方的版本历史页：[Downloader Version History](https://www.aftvnews.com/downloader/history/)。商店页面的「新变化」栏也会随版本滚动（比如 2026 年 7 月的一版修复了从 MediaFire 下载失败的问题）。

## 二、商店渠道：跟着商店自动更新

| 安装渠道 | 更新方式 |
| --- | --- |
| Google Play（手机 / 平板 / Android TV / Google TV） | 商店自动更新；也可进 Play 商店该应用页面手动点更新 |
| Amazon Appstore（Fire TV / Fire 平板） | 自动更新开关在「Settings → Applications → Appstore → Automatic Updates」，确保为 ON；手动更新则在商店搜 Downloader，应用页上 Open 变成 Update 时点它 |

商店渠道装的不用自己管版本，更新完即是最新。

## 三、侧载安装的版本：只能手动覆盖

侧载（用 APK 文件装的）版本不接入任何商店，不会自动更新。更新办法：

1. 从当初拿到安装包的同一来源取新版 APK——侧载版不会自己变新，来源更新到哪版，你才能更到哪版；
2. 在 Downloader 或文件管理器里打开新版 APK 直接覆盖安装，一般会保留你原有的收藏与设置；
3. 提示无法安装（签名冲突之类）时，先卸载旧版再装新版。卸载会清掉应用内数据，**先导出收藏**（步骤见 [文件管理与收藏夹.md](文件管理与收藏夹.md)）。

侧载版还有一个容易忽略的点：Fire OS 系统更新后，「未知来源」放行有时会被重置，表现为之前能装的现在装不了，重新打开一次即可，路径见 [下载与安装教程.md](下载与安装教程.md)。

## 四、更新后快速核对两处

- **Favorites**：覆盖安装一般不动收藏，但卸载重装会清空——装完进 Favorites 看一眼；
- **下载目录**：如果你改过 Download Folder，进 Files 确认文件还在预期位置。

更新后网页打不开或行为异常，先按 [常见问题排查.md](常见问题排查.md) 走一遍；Appstore 版浏览器打不开另见 [浏览器组件安装方法.md](浏览器组件安装方法.md)。
