Walk Play 是给 USB-C 数字耳机、解码耳放（俗称「小尾巴」）调音的安卓 App。它自己不放音乐，作用是连上耳机里的音频芯片，改均衡器、调麦克风增益，再把设置写进设备。本篇只讲安装；装完怎么把设备认上是下一篇的事。

## 一、装之前先核对网盘里这份包

网盘里放的是整理时留存的那一版，和你今天在官网或应用商店看到的最新版常常不是同一个版本号，装之前对一眼：

| 项目 | 值 |
| --- | --- |
| 版本号 | 2.3.7 |
| 包名 | `com.ttgk.musicbox` |
| 安装包大小 | 64.68 MB |
| 安装包 MD5 | `E26A3099233EBD359E6F48D10348E9F5` |
| 系统要求 | 记录标注为安卓 5.2 以上，实际以安装时的系统提示为准 |

包名 `com.ttgk.musicbox` 是判断「装的是不是这个 App」最可靠的一条：名称可以被别人改，包名一般不会动。装好后在 App 的「关于」一类页面能看到当前版本号，对不上就说明装的是另一版。

官方产品页写明这个 App 完全免费，下载与使用都不需要付费。官网目前的安卓包版本比 2.3.7 新，具体版本号以官方页面当时显示的为准。

## 二、从网盘取安装包

1. 打开分享页，或者先「保存到我的网盘」再在夸克 App 里取回本地；
2. 文件夹名是 `walkplay（先保存再下载）`，里面是 `walkplay_v2.3.7.apk`；
3. 下载完成后核对大小是否在 64.68 MB 上下，明显偏小说明没下完整。

需要重新取包时用这一份：[Walk Play 安装文件资源（夸克网盘）](https://pan.quark.cn/s/843b3dda66ef)。

想核对 MD5，把 apk 传到电脑后执行：

```powershell
Get-FileHash "walkplay_v2.3.7.apk" -Algorithm MD5
```

输出与上表一致（不区分大小写）就是原包。

## 三、安卓手机安装步骤

1. 点开下载好的 apk；
2. 系统提示「已屏蔽安装」或「无法安装」时，去设置里把「安装未知应用」的开关给你下载用的那个应用（浏览器或网盘 App）打开，回来重新点安装；
3. 部分国产系统会再弹一次「风险应用」确认，这是第三方来源应用的常规提示，确认继续即可；
4. 装完桌面会出现图标，点「打开」进得去就说明包装好了。

## 四、首次打开要注册账号

首次进入一般要先注册或登录：邮箱或手机号收验证码，再设密码。有用户反馈安卓端每次重新打开应用都要再允许一次访问 USB 设备，遇到时就按提示点允许；具体提示以你手机上的界面为准。

## 五、iPhone、iPad 和电脑上怎么用

- **iPhone / iPad**：iOS 装不了 apk，网盘里这份在 iPhone 上用不上。App Store 搜 `Walk Play` 装 iOS 版；它的上架主体与安卓版公司名不完全一样，隐私政策页面挂在同一厂商的域名下，属同一支产品，以商店页面当时标注为准。
- **网页调音台**：不想装 App 的话，用浏览器打开 [peq.szwalkplay.com](https://peq.szwalkplay.com/)，登录账号、插上设备就能调 EQ，iOS、macOS、Windows 都走这条路。
- **设备厂商的专用驱动**：个别解码耳放（例如 EPZ TS01）另有 Windows 端控制软件，从设备厂商的官方下载页取，别从别处拿。

## 六、装完之后

安装只是第一步，接下来要确认两件事：设备连上手机了没有、App 里有没有认到它。接法与排查见 [支持的设备与连接方法.md](支持的设备与连接方法.md)；如果安装或打开环节就卡住了，翻 [常见问题与排查.md](常见问题与排查.md)。要是手里的包介绍和你看到的界面完全对不上，先看 [是运动播放器还是耳机调音工具.md](是运动播放器还是耳机调音工具.md)。
