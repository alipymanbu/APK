# 提取APK与批量导出

## 一、这一篇解决什么

换手机前想留一份安装包、某个应用从商店下架了想留住它、要把某个应用发给朋友——这些需求都可以用 Skit 的「提取」完成：把手机上已装的应用导出成 APK（或分体格式）存进手机存储，你再自己决定拷走还是分享。本篇讲具体怎么点、存到哪、批量与系统应用的限制，提取出来的文件怎么装回去见 [分体APK怎么安装.md](分体APK怎么安装.md)。

## 二、提取单个应用的 APK

1. 打开 Skit，在列表里找到目标应用（用户应用与系统应用都能提取，侧边栏切换分类，别在搜索里漏了系统应用）；
2. 点进该应用，再点右下角的功能按钮；
3. 在弹出的选项里选「提取」——文件会存进手机内部存储的 `Skit` 文件夹；选「分享」则直接调起系统分享面板发给别人；
4. 提取完用文件管理器打开 `Skit` 文件夹确认文件在。

**免费版一次只能提取一个应用**，导出多个要一个一个来；批量提取与批量卸载是 Premium 功能（区别见 [常见问题与排查.md](常见问题与排查.md)）。

## 三、提取出来的是 .apk 还是 .apks

取决于目标应用的打包方式：

- 老式单包应用 → 导出 `.apk`，谁都能直接装；
- 用 App Bundle 分发的新应用（2021 年起商店新应用与更新的主流）→ 导出 `.apks` 分体包，**系统自带安装器装不了**。

Skit 的设置里有强制把 App Bundle 也导成单个 APK 的选项，但这样导出的包可能装不上（缺对应机型的配置分片）。所以拿到 `.apks` 不是导出失败——格式来龙去脉与怎么装回手机，完整讲在 [分体APK怎么安装.md](分体APK怎么安装.md)。

## 四、系统应用能不能提取

能。Skit 的提取对系统应用同样有效，不需要 root——**但导出的系统应用 APK 换到别的手机、别的系统版本上很可能装不上或一打开就闪退**：系统应用常依赖所在 ROM 的私有接口与预置环境，它只是「在本机可导出」，不等于「到哪都能装」。把它当本机备份看待即可，别指望跨机型搬运（相关排查见 [常见问题与排查.md](常见问题与排查.md)）。

## 五、导出整份应用清单（Apps List）

除了逐个导文件，还可以把手机上装了什么整体记一笔：

1. 在功能入口里找到「Apps List」（旧版本里叫 Simple backup）；
2. 生成后得到一份 **JSON 文件**——3.4 起用通用 JSON 格式，不再是早年的自定义 TXT，除了应用名与包名，还带体积、最后更新时间、SDK 版本等字段，文本编辑器直接能读；
3. 生成后可直接导出到文件管理器（3.4 起支持在应用内直接导出到已安装的文件管理器里）。

这份清单适合换机前留档、或事后查「上一部手机都装了些什么」。清单是纯文本记录，**不含应用本体**；要连安装包一起留，还得按第二节逐个提取。

## 六、提取出来的文件怎么管

- 文件都在内部存储 `Skit` 文件夹里，手动整理、拷贝、删除都随你；
- 同一应用再次提取会再生成文件，旧的不会自动清，嫌乱就定期清一次；
- 提取 ≠ 备份应用数据：APK 只有程序本体，聊天记录、账号登录这类应用内数据不在里面；换机时「程序」和「数据」分别怎么带走，见 [换手机时怎么带走应用.md](换手机时怎么带走应用.md)。
