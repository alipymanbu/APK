## 一、这套工具解决什么

你手上有条视频但想要它的配乐反过来用，或者录了段配音要压到画面上——CC魔盒的音视频工具组就干这两件事：**音频视频合并**（一条音频 + 一条视频 → 一条新视频）和**视频提取音频**（一条视频 → 一条音频）。都在同一个分类下，操作套路一致：进工具 → 选文件 → 点开始 → 等进度。

前提只有一个：装好应用并且**给了存储权限**，否则选文件这步就会失败（权限补法见 [打不开闪退与常见问题.md](打不开闪退与常见问题.md)）。

## 二、音频视频合并：分步走

1. 打开 CC魔盒，默认就在【分类】板块，找到「音视频工具」这一组，点「音频视频合并」。
2. 按界面提示分别选中你要用的**音频文件**和**视频文件**——通常两个选择入口各选各的，选中后界面会显示文件名，确认没选反。
3. 点底部的**开始合并**按钮。
4. 等进度条走完，完成后一般能直接在结果页播放预览，确认声音画面都对。

合并期间别切出去把应用杀掉，进度会中断。选文件时如果列表是空的，八成是存储权限没给，见常见问题那篇。

## 三、视频提取音频

同一个分类里点「视频提取音频」，选一条视频 → 开始 → 得到音频文件。用途和合并相反：你要的只是声音（比如把访谈、配音扒出来剪），就没必要带着画面。

同组还有「视频 md5 修改」这类文件信息处理工具，同样是选文件 → 处理的套路；用不到可以完全忽略它，不影响别的功能。

## 四、合并完的文件去哪找

完成后先在结果页直接播放确认效果。要拿去别处用的话，在手机的文件管理器里按**修改时间倒序**找最近生成的视频/音频文件即可；不同版本保存路径可能不同，应用内若显示了输出路径，以界面显示为准。找不到就看 [打不开闪退与常见问题.md](打不开闪退与常见问题.md) 里「合并完了找不到文件」那条。

## 五、失败时先查这三点

- **选不到文件** → 存储权限没给，去设置里打开（见 [下载与安装教程.md](下载与安装教程.md) 权限表）。
- **点了开始没反应 / 一直卡在 0%** → 文件格式太冷门或文件本身损坏，换一条试试；仍不行就重启应用再走一遍。
- **合成后没声音或画面异常** → 音频、视频是否选反了；重选一遍按步骤再来。

要拿应用本体或版本对不上，见 [下载与安装教程.md](下载与安装教程.md)。
