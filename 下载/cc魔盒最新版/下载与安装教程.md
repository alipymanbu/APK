## 一、先确认你要装的是哪个应用

CC魔盒是个安卓工具箱应用，把日常、图片、音视频、文字等小工具合在一个包里。市面下载站上叫「CC魔盒」「cc魔盒」的不止一个，包名并不相同——有的是文件管理类、有的是抽签类，装错了你会找不到本文说的这些功能。**认准包名 `com.web.magicbox`**，这个应用的事实信息如下：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.8.7 |
| 包名 | `com.web.magicbox` |
| 安装包大小 | 41.61M |
| MD5 | `2c22d9a07464127013b5cdd689728fd2` |
| 记录时间 | 2026-09-23 |

版本号会随官方更新一直变化，网上下载站标注的最新版可能与上表不是同一版；**上表描述的是网盘里那份包**，你装的是哪版就以哪版为准。

## 二、拿到安装包

走网盘最省事：打开 [CC魔盒 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1e79ce831250)，把 `cc魔盒最新版_v1.8.7.apk` 转存或直接下载到手机。这份就是上表那一版，下完可以自己核一下 MD5——用任意一款校验工具读文件摘要，跟表里对得上就说明传输途中没损坏。

从别的渠道下的包也一样：先看包名是不是 `com.web.magicbox`，再对一次体积（约 41M 量级），对不上说明不是同一份。

## 三、安装步骤

1. 把 APK 文件放进手机（下载目录就行），点它开始安装。
2. 系统弹「禁止安装来自此应用的应用」或「不允许安装未知来源应用」，是因为发起安装的浏览器或文件管理器还没有「安装未知应用」权限：去设置里对准该应用打开这个开关，再回来点一次。
3. 等安装完成，先别急着开——把权限过一遍（下一节），再首次启动。
4. 首次打开会弹条款与隐私政策，同意后进入主界面，直接落在【分类】板块，接下来见 [工具分类与基本用法.md](工具分类与基本用法.md)。

装完如果提示解析错误、安装包损坏，多半是下载不完整或文件被改过——重新下一次再装；MD5 对不上也照此处理。

## 四、它要的权限，给还是不给

应用申请的权限里，前几项是功能能不能跑起来的关键：

| 权限 | 用在哪 | 建议 |
| --- | --- | --- |
| 存储（读写手机文件） | 选本地音视频做合并、压缩图片、处理文件 | 必给，不给这些工具选不到文件 |
| 网络访问 | 在线解析、直播、查询类工具联网 | 必给 |
| WLAN / 网络状态 | 投屏时扫局域网里的电视设备 | 要投屏就给 |
| 请求安装文件包 | 你用它装别的 APK 时用到 | 不用它装包可以拒绝 |
| 修改系统设置 | 部分显示类工具（如时间屏幕）改系统显示项 | 按需给 |

权限被拒过、功能点不动时，去设置 → 应用 → CC魔盒 → 权限里手动打开，再回应用重试，具体见 [打不开闪退与常见问题.md](打不开闪退与常见问题.md)。

## 五、以后更新换版本

官方更新后，你手头这版不会自动升级。再装新版时直接点新 APK 覆盖安装，通常应用内的工具设置会保留；万一覆盖后打不开，先清数据再装回原版（清数据会丢掉应用内的自定义选项）。各渠道标注的「最新版」时间不同，以你实际打开后显示的版本号为准（在应用内「关于」一类页面能看到）。
