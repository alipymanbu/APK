# 手机投屏搜不到电视怎么办

> 这篇只排查一件事：点【扫局域网】后列表是空的。按手机、电视、路由器三层往下查，每层给一个可执行的判据。

## 一、先用三十秒定位问题在哪一层

投屏要成立，手机和电视得能互相「看见」，中间隔着路由器。所以扫不到设备只有三种可能：**手机端没扫、电视端没开、路由器不让它们互通**。下面三层依次排查，哪一层对得上就从哪一层处理；做完第二层的热点测试，能直接把责任切成两半（见第三节）。

前提是已经按 [投屏到电视的方法.md](投屏到电视的方法.md) 切过局域网模式并重启过应用——没做这步，后面全白查。

## 二、手机与电视是不是真的同一个网

这层最常见，先核对：

1. **同一路由器**：手机连了路由器、电视（或盒子）连了光猫，看起来都「有网」，实际是两个局域网，互相发现不了。把两边都连到同一台路由器上。
2. **频段别分家**：路由器开了「双频合一」，或手机连 5GHz、电视连 2.4GHz，本质可能不在同一网段。让两边连同一个 Wi-Fi 名称，或关掉双频合一后重连。
3. **别隔着信号放大器**：设备一个连放大器网络、一个连路由器本体，也会对不上。让两边连同一个。
4. **电视端开关没开**：海信、康佳、乐视等品牌要在电视设置里打开「多屏互动」或「DLNA 服务」；小米设备先到「我的应用」里把「无线投屏」打开，电视侧还有一项「公共场所限制」（设置 → 账号与安全）要处于关闭状态。找不到开关就问电视品牌客服。
5. **手机端权限没给**：部分安卓系统要允许应用的「定位」类权限才能读取网络信息来扫描；系统设置里给了再回应用重扫一次。

## 三、用手机热点做一次「二分测试」

两边都连家里 Wi-Fi 却还是扫不到时，把判断做成一刀两断：

1. 手机开热点。
2. 让**电视连上手机热点**（电视那侧改连 Wi-Fi 即可）。
3. 回到应用点【扫局域网】。

- **能扫到了** → 手机和电视之间没问题，毛病出在路由器配置上，直接看第四节。
- **还是扫不到** → 路由器无关，回头看第二节第 4、5 条（电视端开关、手机权限），以及应用是否真的切了局域网模式。

## 四、路由器这一层的三个开关

路由器侧会让设备互相「失联」的设置，就那么几项（不同品牌路径不同，一般在「无线设置 / 高级设置」里）：

| 设置 | 影响 | 怎么处理 |
| --- | --- | --- |
| AP 隔离 | 把连在同一 Wi-Fi 的设备隔成互不可见 | 关掉 |
| 访客模式 | 访客网络与主网络不互通 | 关掉，或让两台设备都连主网络 |
| 双频合一 / 频段引导 | 手机电视被分到不同频段 | 关掉，或手动让两边连同一频段 |

改完重启路由器，再点一次【扫局域网】。

## 五、都试完还是不行

按顺序再走一遍：重启电视（盒子）→ 重启路由器 → 强停并重开 CC魔盒 → 再扫。还不行，多半是电视那侧根本不接收这类投屏——用电视自带的投屏功能试一次能否被发现，能发现说明应用这侧没问题，不能发现则是电视侧问题，找电视品牌客服。其余症状（应用打不开、权限、版本）见 [打不开闪退与常见问题.md](打不开闪退与常见问题.md)。
