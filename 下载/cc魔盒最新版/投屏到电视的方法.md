# CC魔盒投屏到电视的方法

> 这篇讲怎么用 CC魔盒 把手机上的内容投到电视/盒子上：先切局域网模式，再扫设备，扫不到怎么办。

## 一、开投屏前先满足三个条件

1. 手机和电视（或电视盒子）**连在同一个 Wi-Fi** 下——不同网段、一个用流量，都扫不到。
2. 电视那侧处于可被发现的状态（系统自带的投屏/镜像功能开着，或装了支持接收的投屏 App）。
3. CC魔盒这边**已切到局域网模式**，这是最容易漏的一步，见下面第二节。

WLAN 权限也得给应用，没给的话扫描按钮点了没结果，权限补法在 [打不开闪退与常见问题.md](打不开闪退与常见问题.md)。

## 二、切换局域网模式（关键步骤）

1. 打开 CC魔盒，进入**高级设置**。
2. 找到**【切换局域网模式】**选项，勾选它。
3. 点**保存**。
4. **完全退出并重新打开**应用（不重启不生效）。
5. 确认手机已连上 Wi-Fi。

## 三、扫描并连接投屏设备

重新进入应用后，点**左上角的【扫局域网】**按钮，应用会列出同一局域网里搜到的设备，点你要投的那台即可开始投屏。以后再投就不用重复第二节了，直接扫就行（换了路由器或换了 Wi-Fi 才需要重新确认网络环境）。

## 四、扫不到设备时按顺序排查

先走这三步，多数情况到这就解决了：

1. **确认真的在同一 Wi-Fi**：手机关掉流量再试，电视那侧也看一眼网络状态。
2. **电视端还没准备好**：先把电视的投屏/镜像打开，再回来扫。
3. **WLAN 权限没给**：去设置 → 应用 → CC魔盒 → 权限里打开，然后重开应用。

三步都做了列表还是空的，问题通常在路由器设置（AP 隔离、访客模式、频段分家）或电视端的接收开关上——那套逐层排查独立成篇，见 [投屏搜不到设备怎么办.md](投屏搜不到设备怎么办.md)，里面还有一个用手机热点一次定位问题在哪一层的测试。

更完整的故障清单在 [打不开闪退与常见问题.md](打不开闪退与常见问题.md)。投过去想播什么内容，可以配合影视搜索与直播功能，见 [怎么看电视剧与电视直播.md](怎么看电视剧与电视直播.md)。
