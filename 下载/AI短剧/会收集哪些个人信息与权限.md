## 一、政策原文在哪

应用的《AI短剧隐私政策》挂在官方页面：[https://mpy.shipook.com/yszc_aidrama.html](https://mpy.shipook.com/yszc_aidrama.html)（页面标注更新与生效日期为 2023-10-16，以该页当时显示为准）。开发主体为合肥市醉强网络科技有限公司，政策里明确适用范围只有 AI短剧 这一款产品。装应用前遇到「同意隐私政策」的弹窗，点进去看的就是这份。

## 二、它收集什么

按政策第二节的自述，分四类：

| 类别 | 具体内容 | 什么时候收 |
| --- | --- | --- |
| 注册与账号 | 电话号码、姓名、邮箱 | 注册账号时你填的 |
| 你主动提交的数据 | 上传的头像、分享的照片、意见反馈的截图 | 你使用对应功能时 |
| 设备与软件信息 | 设备型号、系统版本、唯一设备标识符、IP 地址、分辨率、网络状态等 | 使用过程中自动记录 |
| 作品与消费记录 | 输入的文本内容、创作作品记录、下载记录、订单信息（订单号、价格、支付方式、支付时间） | 你创作、下载、充值时 |

其中作品与金币、会员状态会**传到服务器并绑定账号**——政策写明目的是同一账号在不同设备上数据一致。换句话说：**成片和账号资产存在官方服务器上，不只是在你手机里**，这也解释了换手机登录同一账号还能看到作品记录。

## 三、每项权限对应什么功能

政策里列了权限与业务功能的对照，挑与你日常使用相关的：

| 权限 | 用在哪 | 拒绝的后果 |
| --- | --- | --- |
| 网络（查看 WLAN 连接） | 联网生成、登录 | 无法使用核心功能 |
| 读/写存储、Android 13 的媒体读写 | 文件下载（成片存相册）、意见反馈选图 | 成片导不出、反馈带不了图 |
| 读取手机状态和身份 | 统计、版本与设备校验、支付 | 支付与统计功能异常 |
| 读取软件安装列表 | 微信登录、分享、微信/支付宝支付前判断是否装了对应应用 | 相关登录与支付方式不可用 |
| 录音（应用权限列表中列出） | 与创作、配音相关的功能按需调用 | 对应功能不可用 |

权限是**逐项弹窗、可关可开**的：政策明确你在设备设置里逐项查看和开关，关掉某项就不基于它继续收集，但会影响对应功能；此前基于授权已进行的收集不受影响。

## 四、它接了哪些第三方 SDK

政策第三节公开了 SDK 清单，与你有关的几项：

- **阿里云号码认证**——本机号码一键登录（把手机号相关字段发给运营商完成校验）；
- **支付宝 App 支付 SDK、微信 OpenSDK**——支付、微信登录与分享；
- **友盟统计与性能监控**——数据分析、崩溃分析，会收集设备与使用统计信息；
- **阿里云 OSS**——上传你生成的文件。

在政策页面点「同意」，等于同时授权这些 SDK 按各自政策取用对应信息；每家 SDK 的隐私政策链接都附在清单里，想看细节就点进去。

## 五、几个使用建议

1. **只给必需权限**：联网必给；媒体读写在第一次导出成片时给即可；不常用的功能（反馈、分享）用到再给；
2. **未满 18 周岁**要在监护人陪同下阅读并经同意后使用（政策第八节明示）；
3. 政策列有「你的权利」一节与未成年人保护条款，涉及账号数据的查询、更正、删除等具体操作入口以政策原文和应用内当时的设置页为准，政策没写清的不要自己猜；
4. 政策会修订，页面上的更新日期变了就重新读一遍——你此前的授权按新版执行。
