# 成片保存与二次发布

> 生成的短剧怎么存进相册、怎么二次剪辑后再发到短视频平台。

## 一、成片出来后先做三件事

生成结束不代表可以直接发。你拿到成片后按这个顺序过一遍：**看完整度 → 存到相册 → 决定要不要二次剪辑**。三条路线的操作都在下面，前置创作步骤见 [剧本写作与短剧创作模式教程.md](剧本写作与短剧创作模式教程.md)。

## 二、保存到手机相册

1. 在成片页完成预览，确认时长、画面、配音没有明显问题。
2. 使用导出/保存功能，成片会写入手机本地相册。
3. 打开系统相册 app 找到对应视频确认已落盘——**导出是需要存储（媒体写入）权限的**，之前拒绝过权限会保存失败，去系统设置里给 AI短剧 打开「照片和视频」权限再重试（权限问题的完整处理见 [常见问题与排查.md](常见问题与排查.md)）。

保存后原成片通常仍保留在应用内记录里；重要成片建议同时在相册里做好备份，避免清缓存时误删。

## 三、要不要二次剪辑

直接导出的成片适合「生成即发」；以下几种情况建议先过一遍剪辑工具：

| 情况 | 你该做什么 |
| --- | --- |
| 需要换配乐 / 加字幕样式 | 在剪辑 app 里替换音轨或重新加字幕 |
| 多集连发、节奏要统一 | 把几集导入同一剪辑工程，统一片头片尾 |
| 平台要求特定时长或比例 | 裁剪到目标时长，确认导出分辨率符合平台要求 |
| 台词有小瑕疵 | 只改出错那一小段，不必整条重新生成 |

生成的视频可直接在相册分享页发到抖音、快手等短视频平台；具体支持的导出格式与分辨率以应用内当时提供的选项为准。

## 四、发布前的自查

- 画面里是否有生成瑕疵帧（手指、文字、背景穿帮），有就剪掉或重新生成这一段；
- 台词字幕与配音是否一致；
- 发布平台的商用规则各不相同，你发布自己的账号前，确认内容符合该平台的规范；
- AI 生成的成片发布时要主动声明，别删平台加的 AI 标识——具体到各平台怎么勾选，见 [发布时要标注AI生成吗.md](发布时要标注AI生成吗.md)。

二次发布涉及平台规则与账号运营，应用本身只负责出片；生成质量不理想时回到 [剧本写作与短剧创作模式教程.md](剧本写作与短剧创作模式教程.md) 调参数重新生成更划算。
