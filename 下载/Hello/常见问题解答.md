## 一、我拿到的版本和商店里的不一样，是假的吗？

不是。Hello语音的版本号随各渠道滚动更新，同一时间不同商店、不同分享渠道拿到的版本号不同是常态。判断真伪看两点：

- **包名一致**：官方安卓包的包名固定是 `com.yy.huanju`，核对方法见[下载与安装教程.md](下载与安装教程.md)第五节；
- **MD5 一致**：网盘里这份安装包（8.2.1 版，2026-09-21 打包）的 MD5 是 `09c054951673cec34c93328b32966867`，对得上就说明包没有在传输中被改动。

版本旧一点不影响基本玩法；介意版本新旧就用官网或商店装最新版。

## 二、不想装 App，能直接用吗？

能。官方有网页版入口：[web.52hello.com](https://web.52hello.com/)，浏览器打开即可听语音直播间。电脑上的两种方式（网页版与应用宝电脑版）见[电脑上怎么用.md](电脑上怎么用.md)；开黑、连麦这类要占用麦克风并能常驻后台的功能，还是手机 App 体验完整。

## 四、安装失败怎么办

按现象排查：

| 现象 | 处理 |
| --- | --- |
| 提示「解析包错误」 | 安装包下载不完整，重新下载后核对 MD5 再装 |
| 提示「禁止安装未知来源应用」 | 在系统设置里对该文件管理器/浏览器放行安装权限 |
| 点安装没反应 | 确认手机剩余空间大于 1 GB；重启后再试 |
| 与已装版本冲突 | 商店版与网盘版包名相同，会互相覆盖或拦截，二选一：先卸载另一个再装 |

## 五、怎么核对安装包没被改动

Windows 电脑上，`Win + R` 输入 `cmd` 打开命令行，执行：

```bat
certutil -hashfile "安装包文件名.apk" MD5
```

把输出的值与 `09c054951673cec34c93328b32966867` 对比。安卓手机上也可以装带「文件校验」功能的文件管理器直接算。对不上就别装，回到[下载与安装教程.md](下载与安装教程.md)重新拿包。

## 六、iPhone 用户怎么装

iOS 版不走 apk，直接在 App Store 搜索「Hello语音」安装（免费下载、含 App 内购买）。注意 iOS 端的会员是订阅制、绑定 Apple ID 自动续订，装完后建议先把取消路径读一遍：[大会员与付费订阅说明.md](大会员与付费订阅说明.md)第二节。

## 七、账号不用了想注销怎么办

按官方指引的路径操作：App 里「我的」→「安全中心」→「账号安全」→「注销账号」，官方在收到申请的七天内完成处理。注销不可逆，点之前先处理余额、解绑支付、取消 iOS 自动续订，完整清单见[权限管理与账号注销.md](权限管理与账号注销.md)。注意**卸载 App 不等于注销**，账号数据在卸载后仍会保留在平台侧。
