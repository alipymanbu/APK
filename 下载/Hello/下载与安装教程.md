## 一、装之前先确认

- **机型**：Hello语音是手机应用，安卓手机装 `.apk` 安装包；iPhone 走 App Store，不通过 apk 安装。
- **空间**：你拿到的那份安装包约 97.81 MB，加上运行后产生的缓存，建议预留 1 GB 以上空闲空间。
- **版本**：本教程对应的安装包是 **8.2.1 版**（2026-09-21 打包）。应用商店里的版本号会持续更新，和你手里这份不一样属正常，见[常见问题解答.md](常见问题解答.md)里的版本差异说明。

## 二、从夸克网盘拿安装包

上面头部给出的就是 **Hello 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/6e2a9c527488](https://pan.quark.cn/s/6e2a9c527488)。转存步骤：

1. 点开链接，用夸克 App（或网页端登录）打开分享页；
2. 勾选里面的安装包，点「转存」，存到你自己的网盘空间；
3. 在你的网盘里选中该安装包下载到手机本地；
4. 下载完成后按第六节的方法核对一遍 MD5，再安装。

转存后再下载的好处：分享链接如果日后失效，你已转存的那份不受影响。

## 四、安卓安装步骤

1. 打开手机「文件管理」，找到刚下载的 `.apk` 文件，点它；
2. 系统若提示「禁止安装未知来源应用」，按提示允许「本次安装」或在设置里对该文件管理器放行；
3. 点「安装」，等待完成；
4. 装好后首次打开会请求**麦克风、存储、通知**等权限：开黑、连麦、K 歌都要录音权限，不给就发不了声；存储权限用于保存头像图片等；你可以按需选择「仅在使用中允许」。各权限给不给、给了怎么撤回，见[权限管理与账号注销.md](权限管理与账号注销.md)。

安装被手机管家拦截时，先核对第六节的 MD5，确认与你拿到的那份一致后再决定是否继续。

## 五、首次打开与登录

1. 打开 App，先勾选同意用户协议与隐私政策；
2. 选手机号登录/注册，输入手机号接收短信验证码完成登录（具体方式以应用内当时显示为准）；
3. 登录后即可进房间；账号昵称、头像等资料在「我的」里改。

验证码谁问都不给——见[未成年人保护与账号安全.md](未成年人保护与账号安全.md)里的账号安全部分。

## 六、核对安装包（MD5）

担心包在传输中出问题，可以核对 MD5 值。这份安装包的信息是：

| 项目 | 值 |
| --- | --- |
| 版本 | 8.2.1 |
| 包名 | `com.yy.huanju` |
| 体积 | 97.81 MB |
| MD5 | `09c054951673cec34c93328b32966867` |

在 Windows 电脑上核对（先把包传到电脑，或手机用带哈希功能的文件管理器）：

```bat
certutil -hashfile "安装包文件名.apk" MD5
```

输出的 MD5 与表格里一致，包就是完整的。对不上就重新下载一次，别强行安装。
