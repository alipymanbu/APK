## 八个板块一张表

Cybox Life 把 AI 对话和模拟经营放在同一个虚拟世界里，八个板块共享同一套 NPC 与城市状态：

| 板块 | 你在里面做什么 |
| --- | --- |
| AI 角色对话 | 创建角色、设定性格与关系，在微信风格的界面里聊天 |
| 虚拟陪伴养成 | 与角色建立恋人、朋友、陌生人等关系，随互动加深发现其另一面 |
| 宠物养成 | 领养宠物，喂食、玩耍、洗澡（本篇下半段展开） |
| 公司创业模拟 | 从初创团队做到上市企业，招聘员工、与 AI 谈判 |
| 选秀造星 | 赛季制选秀：报名、初舞台、公演、顺位淘汰，把素人捧成顶流 |
| 证券交易 | 看实时行情图表，在 AI 驱动的虚拟市场里做投资决策 |
| 世界探索 | 在 8 座城市地图上查看角色的活动轨迹，找演出场馆与工作地点 |
| 娱乐头条 | 虚拟世界的新闻中心，AI 生成头条与热搜榜 |

不用一次全碰。对话与陪伴是主线，经营类板块（公司、选秀、证券）等你熟悉 NPC 的行为逻辑后再开更顺。

## NPC 的记忆与社交：为什么值得先聊再做别的

- **长期记忆**：角色记得你们聊过的内容和你的行为，情绪与态度随时间变化，不用每次从头建立关系；
- **独立社交圈**：每个角色有自己的好友关系和聊天记录，你可以翻看其社交动态；
- **日程与轨迹**：角色的手机日程、位置轨迹、日记都可以查看，配合城市地图能看到它「现在在哪、在干什么」。

理解了这套机制，你就能安排「让某个角色去某座城市演出，再在头条上看它的新闻」这类连环玩法，板块之间是这么联动的。

## 宠物养成：品种与互动

宠物系统目前提供 **6 个品种**，像素风动画呈现：

| 品种 | 类型 |
| --- | --- |
| 金毛 | 狗 |
| 萨摩耶 | 狗 |
| 柯基 | 狗 |
| 哈士奇 | 狗 |
| 布偶猫 | 猫 |
| 英短 | 猫 |

领养后的日常互动有三类：**喂食、玩耍、洗澡**。三种互动覆盖了宠物状态的主要维持动作，像素动画会随互动变化，属于低消耗的挂机型玩法——不影响主线剧情，想养就养。

## 和 AI 角色共同领养

宠物不是只能自己养：与 AI 角色的亲密羁绊达到条件后，可以**共同领养**一只宠物，双方一起完成喂食、陪伴等日常任务。这是把「对话关系」与「宠物系统」串起来的机制——关系越近，共同养宠这条线越自然。想加快羁绊进度，参考 [Credits充值与消耗规则.md](Credits充值与消耗规则.md) 里深度互动的消耗规则，分配好点数再聊。

## 上手顺序建议

1. 注册并进入世界（流程见 [注册与首次上手.md](注册与首次上手.md)）；
2. 建 1~2 个角色，先聊几轮，确认记忆与性格在按你的设定走；
3. 领养一只宠物作为日常挂机项；
4. 再开公司或选秀，把经营线铺开；
5. 期间用娱乐头条和城市地图追踪你角色的动态。
