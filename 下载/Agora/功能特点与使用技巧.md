## 一、树状对话：改一句话不用重开一轮

对话不是一条直线：编辑、重新生成任何一条历史消息，都会从那里**分出一条新分支**，原来的回答仍然保留。适合同一个问题想换种问法对比、或改掉提问里的错误信息后接着聊——上下文不会丢，来回切换分支就能对照两个版本的答案。数据存在本机的 Room 数据库里，分支再多也不影响原对话。

## 二、上下文压缩（Compact）：长对话不爆窗口

模型的上下文有上限，聊久了要裁剪。Agora 的做法是给每轮估计一个 **4K~1M 的 token 预算**，超出时用非破坏性的 Compact「胶囊」压缩旧内容——最近的一段原文原样保留，更早的被收拢成摘要。压缩只插入一个可见的摘要边界，**原消息一条不删**：删掉胶囊，边界就回到压缩前；压缩进行中发消息会先排队。聊长了发现它开始忘记开头细节，就手动触发一次 Compact。

## 三、内置工具：让模型自己动手

在设置的 Agentic Tools 里按需开启，开了之后模型在回答中可自主调用：

| 工具 | 干什么 | 注意 |
| --- | --- | --- |
| 联网搜索 | 模型可搜索网页再回答 | v1.3.6 起默认用 DuckDuckGo Lite 匿名搜索；搜索直连外部服务 |
| 抓取网页 | 读取网页正文 | v1.3.7 起返回完整页面内容（此前只回跳转信息） |
| 图像生成 | 按提示词生图并内嵌显示 | v1.3.3 起，复用你已配服务商的密钥与额度 |
| 记忆 / 会话检索 | 跨对话记住与查找旧内容 | 只读你本机的会话数据 |
| 远程 Shell / SSH | 操作你自己授权的服务器 | v1.3.2 起有主机密钥固定与二次确认，别授权不明设备 |
| Linux 沙箱 | 本机跑 Python、wget 等命令行工具 | PRoot 方案，**F-Droid 版才有集成沙箱** |

工具只在你启用并使用时才向外部发数据；不用就全部关掉。

## 四、数据：导入导出与自动备份

- 导出为带版本的 `.agora` ZIP 归档，换机时导入即可迁移（v1.3.7 修过大导出时内存不足的问题）。
- 支持导入 ChatGPT 导出的对话记录。
- v1.3.0 起有**自动备份**：按 WorkManager 定时备份，间隔与备份类别可在引导或设置里调，嵌入缓存也会一起备份。
- 密钥从自动备份恢复在历史版本有过丢失问题（v1.3.4 修复），升级后核对一下密钥还在不在。

备份怎么开、换机完整步骤、导出文件的安全注意，整理在 [对话记录备份与迁移.md](对话记录备份与迁移.md)。

## 五、界面定制（省心但值得调的几处）

- **界面语言**：内置 12 种界面语言加「跟随系统」，中文在列——想改成中文，在 Language 设置里选，不用等系统语言。
- **字体**：v1.3.7 起支持自定义字体并可导入导出。
- **思考过程展示**：推理模型的思维链可配置展示方式；v1.3.6 起思考块分组显示，流式输出的 Markdown 与 LaTeX 渲染也更顺。
- Material 3 主题、触感反馈均可调；这些都在设置里翻一遍即可，不影响功能。

## 六、版本差异提醒

网盘里的是 **v1.3.7**（见 [下载与安装教程.md](下载与安装教程.md)）；官方更新很快（截至 2026-09 已到 2.x，自动化任务、Groq 支持、原生备份等是后来加的），本文只写 v1.3.7 已有的能力。要新功能就去官方渠道下最新版，以官方 Release Notes 为准。
