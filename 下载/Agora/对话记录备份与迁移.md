## 一、备份入口与文件格式

备份统一在 **设置 → Import & Export（导入导出）** 里做。导出的 `.agora` 文件其实是一个 **ZIP 压缩包**，导出时可以勾选要包含的类别，也可以选择是否把密钥等敏感项一起打包。

会话数据存在应用本机数据库里，**卸载应用或「清除数据」就没了**——除非你提前导出、或开了自动备份。所以在清理应用、刷机、换机之前，先走一遍这里的流程。

## 二、自动备份怎么开

v1.3.0 起内置自动备份（基于 Android 的 WorkManager 定时执行）：

- 首次启动的引导页里就有自动备份这一步，直接打开；错过了也能进设置补开。
- 备份**间隔与备份类别可调**，嵌入缓存（本地向量索引）也会一起备份，恢复后不用重算。
- 自动备份适合兜底，**换机前仍建议手动导出一份**——两份保险。

## 三、换新手机的完整步骤

1. 旧机：设置 → Import & Export → 导出，拿到 `.agora` 文件（文件大就先接到电脑或网盘中转）。
2. 新机：装好 Agora（从哪拿见 [下载与安装教程.md](下载与安装教程.md)）。
3. 新机：同一入口选导入，选中该 `.agora` 文件，按提示勾选类别。
4. 导入后核对：会话是否都在、Providers 页密钥是否还在（旧版本从备份恢复丢 API key 的问题在 v1.3.4 修复）。

密钥也可以不随备份走：导出时不勾密钥，新机重新填一次，更稳妥。

## 四、导出文件的安全注意（务必看）

- **导出包里的密钥是明文**。你勾了「包含密钥」，ZIP 内部就不加密——这个文件等同于把你的 API 密钥装在信封里。别发给别人、别丢进公开网盘，用完删掉多余副本。
- 归档带版本标识，高版本导出的文件导入低版本可能不认；跨版本迁移尽量两头都用较新的版本。
- 只想迁会话不带设置时，导出时只勾会话相关类别即可。

## 五、从其他产品导入

除 `.agora` 归档外，应用还支持**导入 ChatGPT 导出的对话记录**（新版对 Claude 导出也提供了支持，以你装的那个版本的导入列表为准）。拿到官方导出文件后在同一页面导入，原对话会转成本地会话；导入大文件时流式处理，历史版本曾有超大文件内存不足的问题（v1.3.5 起修复）。

更多「对话没了怎么找回来」的场景见 [常见问题与解决办法.md](常见问题与解决办法.md)。
