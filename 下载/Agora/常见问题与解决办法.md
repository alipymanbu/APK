## 一、安装阶段

**提示「禁止安装未知应用」**
系统拦的是来源不是应用：按弹窗去给你的文件管理器/浏览器开「允许安装未知应用」，再装一次。

**装不上 / 解析包错误**
安装包大概率没下完整。网盘那份可校验 MD5 是否为 `43dfba1691dc67eb5eb0103315214f42`（v1.3.7），不一致就重新下载；另外确认系统版本满足要求（官方 v2.1.0 起要求 Android 8.0+）。

**同包名装过别的签名包**
手机里若有来源不明的同包名应用（官方公告过被套壳的第三方版本），先卸载再装官方包，避免签名冲突。

## 二、配置阶段

**填了密钥发消息没反应**
按顺序查：Models 里模型是否已勾选启用 → 底部栏选中的模型是否属于刚配的服务商 → 密钥是否有效有余额 → 网络能否直连该服务商（需要代理的按 [配置API密钥教程.md](配置API密钥教程.md) 第四节配）。服务商后台的报错信息最准。

**密钥填进去重启后没了**
旧版本从自动备份恢复时丢 API key 的问题已在 v1.3.4 修复；仍在发生就升级版本，并到 Providers 页确认密钥还在。

**用不了某家服务商**
官方预设之外的服务商，走「自定义 OpenAI 兼容」端点填密钥与 Base URL（v1.3.7 会自动补全 `/v1`）。协议不对口（非 OpenAI/Google/Anthropic 风格）的端点连不上属正常，换兼容地址。

## 三、运行阶段

**模型加载失败 / 导入后选不到**
- 文件没下完（GGUF 不完整是头号原因），重新下；
- 没给存储权限，去系统设置里授予后重试；
- 内存不够：换更小的模型，导入前关掉后台大应用。

**聊着很慢 / 卡顿 / 耗电快**
本地推理吃 CPU 属正常。有效手段：关后台应用、换更小或量化更高的模型、插电使用。云端模型慢则查网络与代理。

**闪退 / 黑屏**
先按上面两条收缩内存占用；仍闪退时清理应用缓存，或换一个模型试——单个模型文件损坏也会导致加载即崩。崩溃后下次启动会弹匿名诊断报告确认框，**只有你点确认才会发送**，不想要就拒绝。

**模型答非所问、乱码**
多为量化过度或文件损坏：换 Q4 量化的正规版本重新导入。

## 四、界面与数据

**怎么改中文**
设置 → Language，选中文即可（内置 12 种界面语言加跟随系统），无需改手机系统语言。

**对话记录在哪、怎么迁移**
会话存在应用本机数据库，不上传。换机用 `.agora` 导出再导入；旧记录也可从 ChatGPT 导出文件导入。导出的归档里**密钥是明文**，别直接发给别人。

**想恢复旧版本对话分支**
树状对话下编辑/重新生成只是开新分支，原回答没删——在该条消息处切换分支即可找回。

**更新后找不到某功能**
版本差异导致的（如沙箱只有 F-Droid 版有）。对照 [功能特点与使用技巧.md](功能特点与使用技巧.md) 的版本说明，或去官方仓库 Release Notes 查该功能加于哪个版本。
