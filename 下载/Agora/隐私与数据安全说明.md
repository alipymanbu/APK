## 一、没有中转：请求直接发给你配的服务商

Agora 是 BYOK 客户端，**不运营聊天中转服务**：对话请求从手机直接发到你在 Providers 里配置的服务商或端点。你的对话内容会到哪里，完全取决于你配了谁——配了本地模型，就哪也不去。想换数据流向，改配置即可，见 [配置API密钥教程.md](配置API密钥教程.md)。

## 二、存在本机的数据

会话、消息树、任务、记忆、提示词、附件与工具产生的媒体文件，都存在应用自管的数据库与文件里；普通设置走 Android 标准偏好存储。**删除应用数据或卸载应用，这些就没了**（除非有导出文件或 Android 备份留存）——备份操作见 [对话记录备份与迁移.md](对话记录备份与迁移.md)。

## 三、什么时候会有数据离开手机

按官方隐私文档的口径，**只有你用到对应功能才产生对应流量**：

| 动作 | 数据去向 |
| --- | --- |
| 聊天、标题生成、转写、生图、向量化 | 发给你选中的模型/服务商 |
| 联网搜索 | 发给你选中的搜索服务 |
| MCP 工具调用 | 发给你启用的 MCP 服务器 |
| 远程 Shell / SSH | 发给你配置的设备 |
| 更新检查 | 应用启动时拉取版本信息，**每天最多一次** |
| 评分表单 | 你主动提交的评分与留言才会发出 |
| 崩溃报告 | 见下节 |

应用没有通用的统计/遥测通道。

## 四、崩溃报告是「问过才发」

崩溃后应用会在本地存一份诊断报告，**下次启动时弹窗问你**，你点了确认才发送；内容是堆栈、应用/安卓版本、机型与时间戳等诊断信息，**不含会话文本、凭据与设备标识**。不想要就拒绝，什么都不发。

## 五、密钥怎么存、哪里会漏

- 密钥等敏感设置正常走 **Android Keystore 支持的 AES-256-GCM 加密**存储（v1.3.2 起）。
- 两个例外要心里有数：**历史遗留的旧值可能是明文**；加密失败时会**故意回退明文**存下来（宁可不加密也不丢值）。
- **导出的 `.agora` 归档里，勾选的密钥是明文**（详见 [对话记录备份与迁移.md](对话记录备份与迁移.md) 第四节）。

结论：手机锁好、导出文件管好，密钥这条链就是安全的；反过来，把导出包随手转发，加密就形同虚设。

## 六、代理与传输的覆盖范围

应用里配的网络代理管的是**共享 HTTP 客户端的流量**——聊天、搜索这类走代理；**SSH、本机推理、沙箱进程的网络不走它**。另外发送敏感内容前，自己核对一遍端点地址与证书；第三方工具的权限按需开，不用就关（工具清单见 [功能特点与使用技巧.md](功能特点与使用技巧.md)）。
