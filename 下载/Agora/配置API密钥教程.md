## 一、先搞懂 BYOK 是什么意思

Agora 是 BYOK（Bring Your Own Key，自带密钥）客户端：你用自己的服务商账号生成 API 密钥填进去，请求从手机直连该服务商的接口，Agora 不做中转、也不代收你的对话。所以**聊天花多少钱、能不能用，取决于你配的那家服务商的计费与可用性**，与 Agora 本身无关（应用本身免费开源）。

没账号没密钥又只想先体验，走本地模型那条路更省事，见 [加载本地离线模型教程.md](加载本地离线模型教程.md)。

## 二、配置流程（官方 Getting Started 的顺序）

1. 打开会话抽屉（conversation drawer），进 **设置（Settings）**。
2. 进 **Providers（服务商）**，选一家服务商，填入它的 API 密钥；有自定义 Base URL 需求的也在这里填。
3. 进 **Models（模型）**，点同步把该服务商的模型列表拉下来，**勾选启用**你要用的模型。
4. 回到底部聊天栏，点模型选择器切到刚启用的模型。
5. 发一条消息，出字即配好。

配完可以回头补：上下文与 Compact 在 Context 设置里，外部工具在 Agentic Tools 里，界面语言与外观在 Language / Appearance 里。

## 三、服务商与端点怎么选

- 应用内内置多家主流服务商的预设（具体清单以应用内 Providers 列表为准，官方版本迭代较快）。
- v1.3.4 起支持**自定义 OpenAI 兼容服务商**，v1.3.7 起 Base URL 会自动解析补上 `/v1`。自建服务、中转站、Ollama 远程地址这类 OpenAI 兼容端点都走这条路。
- OpenRouter 在 v1.3.7 起也可用于 embeddings（向量），并支持 API 密钥自动填充。
- **用哪家就填哪家的真密钥**，密钥只保存在本机（v1.3.2 起密钥等敏感设置用 Android Keystore 的 AES-256-GCM 加密存储）。密钥在什么情况下可能以明文存在、备份里怎么处理，见 [隐私与数据安全说明.md](隐私与数据安全说明.md) 第五节。

## 四、网络代理（v1.3.7 新增）

部分服务商在你的网络环境下可能连不上。v1.3.7 起应用内支持网络代理，设置里可配 HTTP / HTTPS / SOCKS5 三种协议，并可填**绕过列表**（bypass list，指定哪些地址不走代理，比如局域网的 Ollama 地址）。代理端口与类型按你自己的代理软件显示的为准。

## 五、配好但不出字，先查这四处

1. 模型有没有在 Models 里**勾选启用**（同步了不等于启用了）。
2. 底部栏选中的模型是不是刚配那家的（切错服务商照样失败）。
3. 密钥是否有效、账户是否有余额；服务商后台的报错信息最准。
4. 网络是否直连得上该服务商——需要代理的先按第四节配上。

更多报错场景见 [常见问题与解决办法.md](常见问题与解决办法.md)。
