## 一、先做这一步：把界面切成简体中文

TELTLK 默认是英文界面，登录页就能切语言，不用先注册：

1. 打开 TELTLK，停在登录主界面；
2. 点页面**右上角**的功能图标；
3. 在语言列表里选「简体中文」；
4. 返回登录页，后续按钮就是中文的了。

这一步几乎所有新用户都会先做，避免在英文界面里猜按钮含义。

## 二、邮箱注册流程

多数用户走的是邮箱注册，整个流程大概一两分钟：

1. 在登录页点「注册」；
2. 按页面提示选择注册渠道（选邮箱方式）；
3. 依次填写**邮箱地址、昵称、常用语种**；
4. 勾选用户协议与服务条款相关的选项；
5. 核对信息无误后点「同意并继续」；
6. 登录你填的邮箱，查收验证码邮件；
7. 回到注册页把验证码填进去，提交后账号就建好了。

几点提醒：

- 邮箱要填真实可收信的，验证码只会发到这个邮箱；
- 昵称注册后一般可以改，但常用语种会影响翻译和推荐的初始设置，建议按你的母语填；
- 官方隐私政策里提到注册环节会收集手机号用于身份核验，所以你使用的版本如果要求手机号，属于政策允许的范围，按提示操作即可。

注册完成后，多数人是冲着跨语言聊天来的，翻译的用法见[AI翻译怎么用](AI翻译怎么用.md)；想在群组和社区里找人的，看[群聊与社区怎么玩](群聊与社区怎么玩.md)。

## 三、收不到验证码怎么办

| 情况 | 处理 |
| --- | --- |
| 等了一两分钟没到 | 先检查邮箱的垃圾邮件/广告邮件文件夹，验证码邮件经常被分到那里 |
| 垃圾箱里也没有 | 回到注册页点重新发送，再等几分钟 |
| 反复收不到 | 换一个邮箱服务商重试（部分小众邮箱域名的收信成功率低） |
| 邮箱填错了 | 返回上一步修改邮箱地址再走一遍流程 |

另外有用户反馈注册环节偶发报错（用户反馈级）：遇到报错先切一下网络（Wi-Fi 与流量互换）或过段时间再试，多数能过；反复不行就换邮箱服务商重走流程。

## 四、登录与账号的几个常见问题

- **换手机登录**：用同一个注册邮箱走登录入口即可，聊天记录是否同步取决于应用内的备份机制，重要内容别只存在一台设备上；
- **忘记密码**：在登录页找「忘记密码 / Forgot password」入口，按邮件指引重置，具体流程以你打开的页面为准；
- **注销账号**：官方隐私政策写明用户可以删除自己的账号，入口一般在「设置 → 账号」一带，注销前先把需要的内容自己留档。

碰到登录之外的问题（消息发不出去、权限怎么给），先翻[常见问题排查与隐私设置](常见问题排查与隐私设置.md)。
