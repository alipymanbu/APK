# MM131 在电脑上使用的方法

> 本篇讲怎么在 Windows 电脑上跑 MM131 这类安卓应用：官方商店支持的「应用宝电脑版」路子、直接装 apk 的差异，以及各自的限制。

## 一、先说清楚：apk 不能在电脑上直接双击安装

MM131 是安卓应用，安装文件是 apk 格式，Windows 本身跑不了它——必须借助一个「能在电脑上运行安卓系统」的环境。目前常见的是两类：

| 方式 | 原理 | 适合谁 |
| --- | --- | --- |
| 应用宝电脑版 | 腾讯官方的电脑端安卓运行环境（内置 Android 13） | 想省事、要官方渠道的人 |
| 通用安卓模拟器 | 第三方虚拟机方案 | 需要多开、自定义配置的人 |

## 二、用应用宝电脑版（官方商店支持的路子）

应用宝的官方详情页收录了 MM131（上架名小写 mm131），并提供了电脑端运行支持。步骤：

1. 在电脑浏览器访问应用宝官网 `https://sj.qq.com`，下载电脑版安装程序并装好；
2. 打开应用宝电脑版，在商店里搜索 `mm131` 进入详情页；
3. 点「安装」，由它把应用装进内置的安卓环境里；
4. 完成后从桌面图标启动，之后可从桌面、系统栏或菜单再次打开。

这条路的好处是商店直装、不用自己找安装包；代价是你必须在它的环境里用，商店里的版本号以当时页面显示为准，未必等于你网盘里那份 1.12。

## 三、把网盘里的 apk 装进电脑端安卓环境

如果你想用网盘资源里那份特定的 1.12 版（比如要对齐 MD5 或固定版本），可以走「自装 apk」：

1. 按[下载与安装教程.md](下载与安装教程.md)的方法，把 MM131 安装文件资源（夸克网盘）下载到电脑上；
2. 打开应用宝电脑版（或你已在用的安卓模拟器），找「安装本地 apk」之类的入口；
3. 选中下载好的 apk，等它装进安卓环境后启动。

两种方式装的算同一个应用，数据各自独立，别来回混装两个版本——图片收藏这类本地数据不互通。

## 四、限制与注意

- **操作习惯**：图片滑动浏览用鼠标滚轮或拖拽就行；但设壁纸这类依赖系统层的功能，最终作用在模拟环境的桌面上，未必能改到你 Windows 桌面的壁纸，想要「电脑桌面壁纸」应该直接在 Windows 里设置图片。
- **性能**：安卓环境本身要占内存与显卡资源，老电脑跑起来会卡；建议至少 8 GB 内存。
- **账号与缓存**：在电脑环境里产生的浏览记录、收藏都存在那个环境里，卸载环境等于一并清掉。
- 电脑上刷图遇到加载问题、闪退等，排查思路与手机一致，见[常见问题与解决方法.md](常见问题与解决方法.md)。
