# MM131 常见问题与解决方法

> 本篇汇总 MM131 安装与使用中最常碰到的几类问题：安装失败、闪退、图片加载不动、登录异常、壁纸设置失败，每条给出可执行的排查顺序。

## 一、安装时提示「解析失败 / 安装失败」

按命中率从高到低排查：

1. **安装包没下完整**——最常见的原因。删掉这个 apk，回网盘重新下载一遍；下载中途断网、切换网络都可能产出残缺文件；
2. **存储空间不足**——安装包约 115 MB，加上解包所需的临时空间，手机剩余空间最好留出 1 GB 以上；
3. **文件传输损坏**——如果是电脑传到手机的，换一种传输方式再传一次（数据线传输最稳）；
4. 重新下载的包可以核对 MD5 是否为 `0EF2C6FD7B187D5653FAC11F0691D7FA`，一致说明包是完整的，问题出在手机侧。

## 二、打开就闪退

1. 先确认系统版本：这版要求较新的安卓系统（采集记录标注 5.2 以上），太老的系统装上也跑不起来；
2. 重启手机后再试一次，排除内存被占满的临时状态；
3. 清除应用缓存或数据后重开（系统设置 → 应用管理 → MM131 → 存储）；
4. 还不行就卸载重装，安装包从[下载与安装教程.md](下载与安装教程.md)的网盘资源重新取。

## 三、图片加载不出来 / 一直转圈

1. 检查网络：这类图片应用的内容靠在线加载，网络不稳就是刷不出来，切 Wi-Fi / 流量对比一下；
2. 完全退出应用（从最近任务里划掉）再打开；
3. 清缓存后重试；
4. 长时间整体加载不出来，可能是内容服务在维护或调整，隔几小时再看，同时留意应用内是否有更新提示——旧版接口下线是老应用加载失败的常见原因。

## 四、登录或账号异常

有用户反馈过登录不上的情况。这类问题多数与应用本身无关，按这个顺序排查：

1. 换网络环境再试（Wi-Fi 与流量互切）；
2. 检查是否给应用开了联网权限——部分机型的流量管控或省流策略会拦住它的联网请求，在系统设置的流量管理里把它放行；
3. 检查系统时间是否正确——时间不准会连带证书校验失败，登录、加载都会报错；
4. 确认用的是当前版本，旧版本可以按第一节思路重装最新拿到的版本；
5. 排查后仍不行，等一段时间再试，服务端问题只能等服务端恢复。

## 五、设壁纸没反应 / 壁纸设置失败

1. 回顾操作路径：大图页点「设为壁纸」，部分机型会跳到系统壁纸预览页，需要在那里再点一次「应用」才算完成；
2. 检查权限：系统设置里确认 MM131 的存储等权限已开，权限被关时设置动作会静默失败；
3. 换一张图试试，个别超大图或特殊格式在部分机型的壁纸服务上会失败；
4. 实在设不上，退而求其次：把图保存到相册，用系统相册的「设为壁纸」功能完成同样的事。

## 六、卸载与重装

长按桌面图标卸载即可，本地的收藏等数据会一并清掉，卸载前有需要先保存的图片先存到相册。重装的安装包一律回到[下载与安装教程.md](下载与安装教程.md)重新获取，不要用来源不明的旧包。想在电脑环境里重装则参考[在电脑上使用的方法.md](在电脑上使用的方法.md)，手机端的日常使用与设置问题优先看[使用入门与壁纸设置.md](使用入门与壁纸设置.md)。
