## 一、安装前先核对这几点

MM131 是一款手机图片类应用，开发者是长沙蓝普信息技术有限公司。不同渠道对它的定位描述不完全一致：应用宝官方页面的简介侧重音乐相册与图片、视频编辑；网盘里这一版（1.12）按采集记录提供的是多类别高清图片浏览与壁纸设置，图片按自然、艺术、都市等主题分类。你拿到手先按下面的表核对，确认是你要的那一个：

| 项目 | 内容 |
| --- | --- |
| 应用名 | MM131（应用宝上架名小写「mm131」） |
| 版本 | 1.12 |
| 包名 | mm.meitu.lanpu |
| 安装包大小 | 约 115 MB |
| MD5 | `0EF2C6FD7B187D5653FAC11F0691D7FA` |
| 开发者 | 长沙蓝普信息技术有限公司 |
| 系统要求 | 安卓（采集记录标注 5.2 以上，实际以安装时提示为准） |

版本号、包名、大小都以这份网盘资源里的包为准。你在别处搜到的「官方最新版」版本号可能更高，属正常现象——网盘里保存的是采集当时的那一版，功能与那一版对应。

## 二、从网盘资源获取安装文件

安装包通过夸克网盘分享获取，流程是「转存到自己的网盘，再从网盘下载到手机」：

1. 打开上面网盘提示块里的链接（或复制到浏览器打开）；
2. 选择「保存到网盘」，把它转存到你自己夸克网盘的任意目录；
3. 在手机上装好夸克 App 并登录同一账号，进入刚才保存的目录；
4. 勾选 MM131 的 apk 文件，点「下载」；下载完成后在通知栏或夸克的「传输/下载」列表里能找到它。

如果你是在电脑上转存的，也可以先在电脑上下载 apk，再通过数据线、微信/QQ 文件传输助手等任意方式把文件传到手机存储里，效果一样。

## 三、安装步骤

1. 在手机的文件管理器里找到刚下载的 apk（文件管理器的「下载」或夸克 App 的下载目录里）；
2. 点它，系统会弹「是否允许安装」，选允许；
3. 如果弹出「禁止安装未知来源应用」之类的拦截提示，去系统设置的「安装未知应用」权限页，给来源 App（浏览器 / 文件管理器 / 夸克，取决于你从哪里点的安装）开权限，再回来重新点；
4. 等安装进度走完，点「打开」或回桌面点图标启动。

国内厂商的系统（小米、华为、OPPO、vivo 等）对未知来源的拦截位置各有不同，找不到开关时在设置里直接搜「未知来源」最快。

## 四、首次启动

第一次打开时会申请存储等基础权限，按需同意即可——图片浏览与保存壁纸都依赖存储权限，不同意的话相关功能会受限。进入主界面后你能看到按主题分类的图片内容，挑一张设置成壁纸的完整路径见[使用入门与壁纸设置.md](使用入门与壁纸设置.md)。

安装这一步如果卡住、报错或解析失败，先去[常见问题与解决方法.md](常见问题与解决方法.md)对照排查，多数情况是安装包没下完整或存储空间不够。
