## 一、先确认你要装的是哪一个

安卓平台上名字叫 codeformer 的应用不止一个，开发者与功能各不相同。本套文档对应的是下面这一版，装之前先对一下：

| 项目 | 信息 |
| --- | --- |
| 应用名 | codeformer |
| 包名 | `com.dubi.dongyan` |
| 版本 | 1.6 |
| 安装包大小 | 78.21 MB |
| 安装包文件名 | codeformer_v1.6.apk |
| MD5 | 292C465B76155409B07FF2DAF732F99C |

它基于同名的 CodeFormer 开源人脸修复模型（南洋理工大学 S-Lab 团队发布，源码在 [github.com/sczhou/CodeFormer](https://github.com/sczhou/CodeFormer)）做成手机端工具，主打把模糊、破损、有噪点的人脸照片修清楚。公开渠道后来还能看到更高的版本号，但功能入口与界面细节以你手上这份 1.6 的实际显示为准。

顺带一提：搜这个名字时你还会碰到要配 Python 环境的开源项目和网页版 demo，那些是同一模型的电脑侧形态，与手机版的关系见[手机版与电脑版CodeFormer的区别.md](手机版与电脑版CodeFormer的区别.md)。

## 二、下载与核对

1. 打开 [codeformer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/94c6ce4474d4)，把 `codeformer_v1.6.apk` 转存到自己网盘后下载到手机，或直接下载。
2. 下载完在文件管理器里查看文件属性：大小应在 78.21 MB 上下；想更稳妥可以核对 MD5 是否为 `292C465B76155409B07FF2DAF732F99C`（多数文件管理器的文件详情页能看到）。对不上说明没下完整，删掉重下即可。

## 三、安装步骤

1. 在文件管理器里点开 `codeformer_v1.6.apk`。
2. 系统提示「不允许安装未知来源应用」时，按提示允许文件管理器（或你用来打开的那个应用）安装应用，装完可以把这个开关关回去。
3. 等安装走完，点「打开」。

系统要求方面，公开页面标注为安卓 5.2 以上，实际以安装时手机给出的提示为准，近几年的安卓手机一般都能装。

## 四、首次启动要给的权限

第一次点进功能时应用会先要权限：

- **照片与文件（存储）权限**：必给。不给的话读不到相册，导入照片的列表会是空的。
- **网络权限**：默认允许即可。

如果导入照片时列表一片空白，基本都是存储权限被拒了：去系统「设置 → 应用 → codeformer → 权限」，把照片或存储权限改成允许，再回应用重试。

## 五、装不上或打不开怎么办

| 现象 | 处理办法 |
| --- | --- |
| 提示「解析包出错」 | 安装包多半没下完整，重新下载并核对 MD5 |
| 安装中途失败 | 清一下存储空间，剩余空间最好保持在安装包体积的 3 倍以上 |
| 点开就闪退 | 先重启手机再试；仍闪退看[修复效果不理想怎么办.md](修复效果不理想怎么办.md) |
| 装好了但读不到照片 | 存储权限没给全，按上一节处理 |

装好后直接看[人脸修复操作步骤.md](人脸修复操作步骤.md)，把第一张模糊照片修出来。
