## 一、能对视频做什么

| 操作 | 适合的场景 |
| --- | --- |
| 画质增强 / 放大 | 老录像、低分辨率的视频想看得更清楚 |
| 消除画面抖动 | 手持拍摄晃得厉害的片段 |
| 去噪点 | 暗光拍出来的颗粒感视频 |
| 加马赛克 | 想遮挡画面里某个区域的片段 |
| 画质参数修改 | 需要改一下视频画质属性再保存的场景 |

照片和视频共用同一套「导入 → 处理 → 保存」逻辑，照片的操作细节见[人脸修复操作步骤.md](人脸修复操作步骤.md)。

## 二、操作流程

1. 打开应用，选视频处理类的功能入口。
2. 从相册或文件里导入视频。
3. 选要做的处理，点开始，等待渲染完成。
4. 预览确认后导出，成片到系统相册或文件管理器里按日期找。

## 三、格式与兼容问题

- 部分特殊编码的视频可能导入失败或直接报错，先把它转成常见的 MP4 再试。
- 1.6 版的更新说明里提到扩充了小众视频编码的兼容格式，遇到老设备录的视频导不进来，可以先用这一版试试，不行再转格式。
- 转格式工具在应用商店随便搜「视频格式转换」就有，把编码换成 H.264 + MP4 容器是最稳的组合。

## 四、性能与等待时间

- 高清视频的处理占用手机性能明显偏高，开始前关掉多余的后台应用，避免中途被系统杀掉。
- 长视频一次跑完可能要等很久，建议先截取一小段试效果，确认参数合适再跑整段。
- 1.6 版同时优化了长视频的渲染算法，但「先试片段再跑全片」的习惯仍然能省不少时间。
- 滑块对视频同样生效：官方对视频用的是最保守的档位（保住脸优先），原因见[修复深浅与保真度怎么调.md](修复深浅与保真度怎么调.md)第一节。

## 五、导出后找不到成片

1. 先看系统相册最近日期，多数情况会直接出现在相册里。
2. 华为鸿蒙 HarmonyOS 5 及以上的设备，第三方应用保存的内容可能不在图库里显示（华为官方说明过的现象），去文件管理 App 按导出当天的日期搜视频文件。
3. 还是没有说明导出没成功，重跑一遍；反复失败的排查思路见[修复效果不理想怎么办.md](修复效果不理想怎么办.md)。
