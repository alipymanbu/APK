## 一、哪些老照片值得交给它

- 人脸模糊到五官分不清、只剩轮廓的。
- 相纸有折痕、划痕、缺角的。
- 黑白照、褪色发黄想还原色彩的。

这几种问题对应的功能不一样：模糊靠人脸修复，破损靠修补，黑白上色是单独的入口，导入前先在首页选对功能。

## 二、纸质照片先拍好，修复就成功了一半

修图应用处理的是电子版，老照片翻拍的质量直接决定效果：

1. 找光线均匀的地方，靠窗的自然光最好，别用闪光灯（相纸会反光）。
2. 手机正对照片拍摄，别斜着拍，避免透视变形。
3. 照片撑满取景框，四周留一点边即可，拍完裁掉多余背景。
4. 有玻璃相框的先取出来拍，玻璃的反光和倒影会被当成画面内容。

已经拍歪、拍暗的电子版也能修，但先重拍一遍往往比后期补救更快。

## 三、修复与上色的操作

1. 打开应用，导入翻拍好的照片。
2. 按需求选功能：破损划痕选修补类，黑白照选上色类，单纯模糊选人脸修复。
3. 用滑块控制改动幅度（调法与[人脸修复操作步骤.md](人脸修复操作步骤.md)第三节一致：不像本人往保守方向拉，细节不够往激进方向拉；按照片类型选档的参考值见[修复深浅与保真度怎么调.md](修复深浅与保真度怎么调.md)）。
4. 点开始修复，等预览出来对比原图。
5. 满意后保存到相册。一张老照片常常要「修补 + 上色」跑两遍，先修破损再上色效果更稳。

## 四、对结果的合理预期

| 期望 | 实际情况 |
| --- | --- |
| 划痕折痕消失 | 大部分能修掉，跨越人脸的大面积破损可能留痕迹 |
| 黑白照变彩色 | 颜色是算法推断的，衣服、背景的颜色未必与现实一致，肤色通常更接近常理 |
| 认不出的人修到能认 | 信息量够时效果明显；损坏到只剩轮廓时，补出的长相是「合理想象」 |
| 五官与本人一致 | 用滑块往保留原样方向调会更像，但清晰度提升相应变小 |

修完效果不对劲，对照[修复效果不理想怎么办.md](修复效果不理想怎么办.md)逐条排查；批量处理一整本相册的流程见[人脸修复操作步骤.md](人脸修复操作步骤.md)第四节。
