# Cherry Studio 手机版从电脑导入配置（设备互联配对教程）

> 电脑上已经配好 Cherry Studio 桌面版？本篇讲怎么把服务商配置与模型扫码导入手机，哪些东西导不过来、同步失败怎么查。

## 一、这个功能能带过来什么

先把边界说清楚（截至 2026-09 官方口径）：导入范围是**模型服务商配置与已启用模型**。对话聊天记录、插件账号授权都不在导入范围内；它也不是远程控制电脑的方式。配对成功后不会持续自动同步，以后想更新配置，要再手动同步一次。

电脑上的本地模型服务（Ollama、LM Studio 这类跑在本机的东西）同样导不过来——配对不会让手机凭空调用你电脑里的本地模型。

## 二、配对步骤

1. 手机与电脑连**同一个局域网**（比如同一个家庭 Wi-Fi），电脑上保持桌面版 Cherry Studio 运行。
2. 桌面端打开「设备互联」，屏幕上会出现配对二维码。
3. 手机端打开 **设置 → 设备互联 → 扫描二维码**；第一次用会要相机权限和局域网访问权限，都允许。
4. 扫完按页面提示继续，勾选要同步的服务商。

手机没有相机或扫不了码时，用页面提供的手动输入方式，把桌面端二维码里的配对内容粘进去。注意要粘的是**配对内容**，不是普通网页链接。

## 三、导入时会发生什么

选好服务商点同步之后，按官方给出的规则逐项对号：

| 情况 | 结果 |
| --- | --- |
| 勾选的服务商 | 覆盖为电脑上的地址和密钥，并在手机启用 |
| 电脑启用、手机还没有的模型 | 加到手机 |
| 手机上已有的同名模型 | 保留手机现有设置，不重复加 |
| 手机独有的服务商或模型 | 保留 |
| 电脑上已停用的服务商或模型 | 不导入 |
| 聊天记录、插件授权 | 不导入 |

最要留意第一行：**就算没有新模型，把已有服务商再同步一次，也会把手机上的地址和密钥替换成电脑那份**。手机和电脑用的是不同密钥的话，想清楚再点同步。

## 四、有些服务商为什么勾不了

条目上会写原因，常见三种：

- **认证方式不支持**：电脑端登录的账号没有可导出的移动端密钥，只能在手机上单独配。
- **未配置可用密钥**：先回电脑确认该服务商至少有一个有效且启用的 API Key。
- **当前版本无法识别配置**：更新手机版再试，或先跳过这条，导其他能用的。

## 五、扫码成功了，同步却失败

配对保存的只是连接凭据，真正读配置时还得连得上电脑。按顺序查：

1. 桌面端还开着吗；
2. 两台设备还在不在同一局域网（路由器的访客网络隔离会把两台设备隔开）；
3. 电脑防火墙或代理有没有拦；
4. iPhone / iPad 之前拒绝过局域网权限的话，去系统设置里给 Cherry Studio 打开；
5. 页面提示「需要重新配对」就重扫一次二维码。

## 六、换手机与解除配对

- 手机端「移除设备」只删掉这台手机里存的连接凭据；要真正撤销授权，还得在电脑端「设备互联」里把这台移动设备移除。
- 导入配置不是备份。重要对话和文件，换机前用分享或导出功能另行保存。
