## 一、先弄清楚你要装的是哪一版

Cherry Studio 有两套客户端：一套是电脑桌面版（Windows / macOS / Linux，迭代较久），另一套是手机移动版（Android、iPhone 与 iPad，目前处于 Beta 阶段）。本篇讲的是**安卓手机版**。

截至 2026-09，安卓版通过官方 APK 发布，主流应用商店里没有官方上架（以官方下载页当时显示为准）。你可以用包名核对装的是不是官方那份：`com.cherry_ai.cherry_studio_app`。

## 二、从哪拿安装包

两条路，任选其一：

1. **官方下载页**：打开 [官方下载页的移动端选项](https://cherryai.com.cn/download?platform=mobile)，选择「下载 APK」。官方 APK 面向 ARM64 设备，近几年出的手机基本都符合。
2. **网盘资源**：本篇顶部的 cherry studio 安装文件资源（夸克网盘）转存到自己的网盘后，把里面的 APK 下载到手机即可安装。

认准官方渠道：官网是 [cherry-ai.com](https://www.cherry-ai.com/) 与 [cherryai.com.cn](https://www.cherryai.com.cn/)，安卓端源码仓库是 [github.com/CherryHQ/cherry-studio-app](https://github.com/CherryHQ/cherry-studio-app)。搜索结果里一些打着「中文站」旗号的第三方站点（如 `cherrystudiocn.app`）并非官方，不要从那里装。

## 三、安装步骤

1. 下载完成后，从浏览器的下载记录或文件管理器里点开 APK。
2. 如果系统弹出「禁止安装」，按提示进入设置，给当前这个浏览器或文件管理器临时勾选「允许安装未知应用」。
3. 返回安装界面，点安装，等它跑完。
4. 装好后建议回到刚才的设置页，把「安装未知应用」授权关掉，平时用不上了。

装不上、报「解析包错误」或「App 未安装」的，按 [常见问题与解决方法.md](常见问题与解决方法.md) 第四节的清单排查。

## 五、升级与卸载

- **升级**：新版本发布后，从官方下载页重新下载 APK，直接覆盖安装即可，聊天数据一般会保留；升级前先看一眼官方版本说明，Beta 阶段界面变动比较频繁。之前装过来路不明的同名应用的话，覆盖安装可能因签名不一致而失败，先把旧的卸掉再装官方包。
- **卸载**：长按图标卸载即可。卸载前如果里面有你还需要的对话内容，先把要留的导出（把对话导出成 Markdown、HTML 或图片的做法，见 [智能体与插件工具用法.md](智能体与插件工具用法.md) 第五节的说明）。

## 六、装完第一件事：配模型服务

这个客户端本身不带模型额度，装完打开会发现自己还发不出第一条消息——你需要先接入至少一个模型服务（填 API 密钥）。具体步骤见 [API密钥与模型服务配置.md](API密钥与模型服务配置.md)；如果电脑上已经在用桌面版，也可以直接把电脑里配好的服务商导入手机，两条路线都在那篇里。
