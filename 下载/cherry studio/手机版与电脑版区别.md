## 一、一句话结论

两套客户端同属 CherryHQ、都开源（AGPL-3.0 协议），核心玩法一样——用你自己的 API 密钥接入多家模型服务。区别在于：桌面版迭代多年、功能更全；手机版 2026 年起才放出、目前是 **Beta**，界面与功能会随版本快速调整（截至 2026-09，以官方页面为准）。

## 二、对照表

| 对比项 | 手机移动版 | 电脑桌面版 |
| --- | --- | --- |
| 平台 | Android（官方 APK，ARM64 设备）、iPhone / iPad（TestFlight 测试） | Windows / macOS / Linux |
| 成熟度 | Beta 阶段，功能与界面变动快 | 正式版，迭代较久 |
| 源码仓库 | `github.com/CherryHQ/cherry-studio-app` | `github.com/CherryHQ/cherry-studio` |
| 获取入口 | [官方下载页的移动端选项](https://cherryai.com.cn/download?platform=mobile) | 官方下载页的桌面端选项 |
| 配置方式 | 手机内添加服务商，或与电脑版配对导入 | 桌面端内添加服务商 |

## 三、功能上的差别（截至 2026-09）

- **手机版有的**：多模型对话（流式回复、Markdown 渲染、图片与文件附件）、智能体、插件与 MCP 工具、联网搜索与网页阅读、图片生成、文件库与分享导出（Markdown / HTML / 长图）、日历与提醒事项等设备能力。
- **桌面版更全的地方**：知识库这类桌面级功能，截至 2026-09 在移动端文档里还没有对应入口，这类需求目前仍以电脑版为准。
- **两者打通的地方**：手机版可以和桌面版**配对**，把电脑里配好的服务商配置与模型导入手机。但注意边界——对话历史不会同步过来，远程控制电脑端智能体也不在配对功能范围内。配对的具体操作见 [与电脑版配对导入配置.md](与电脑版配对导入配置.md)。

## 四、「到底有没有安卓版 / iOS 版」

这是搜索里最常见的疑问，准确答案（截至 2026-09）：

- **安卓版：有**。官方通过 APK 形式发布，走 [官方下载页的移动端选项](https://cherryai.com.cn/download?platform=mobile) 获取，装法见 [下载与安装教程.md](下载与安装教程.md)。
- **iOS / iPadOS：有，走 TestFlight**。先在 App Store 装 Apple 的 TestFlight，再从官方下载页加入测试。名额和测试版有效期由 Apple 的机制管理，邀请暂时不可用就稍后再试。
- **网页版：没有**。官方不提供网页登录入口，也不要在任何第三方网页里填你的 API Key。

网上一些文章声称「Cherry Studio 没有手机版」，那是移动版正式发布之前的旧说法；也有第三方「中文站」发布过相反口径的信息。判断以官方渠道为准：[cherry-ai.com](https://www.cherry-ai.com/)、[cherryai.com.cn](https://www.cherryai.com.cn/) 与 GitHub 的 CherryHQ 组织。

## 五、怎么选

- 主要在手机上用、需求是随时聊几句、发图片读文件、出门在外改改图 → 手机版够用。
- 要建知识库、跑长任务、写代码做长文 → 装桌面版，两边用同一个平台的密钥，手机版还能直接把配置导过去。
- 拿不准就直接两边都装，配对导入一次，体验差异一试便知。
