## 一、发了消息没有回复

按这个顺序排查，多数问题停在前两步：

1. **换一条不带附件的短消息重试**。长文本、大图走的是另一条路，先用最小 Case 确认链路通不通。
2. **核对 API Key**：是不是把平台登录密码当成了密钥；密钥有没有多余的空格；这家平台的普通会员是不是根本不含接口额度。
3. **确认服务商与模型都启用**：设置 → 模型服务里该服务商处于启用状态，对话顶部选的也是它底下已启用的模型。
4. **检查网络**：部分模型平台的服务器在境外，网络环境不通时什么客户端都救不了。

界面上有明确报错码的，直接对下面的表。

## 二、报错提示对照

| 提示 | 先查什么 |
| --- | --- |
| 401 / 未授权 | 密钥是否完整、有效、已保存并启用 |
| 403 / 无权限 | 账号、地区、目标模型或组织权限是否允许访问 |
| 404 / 不存在 | 基础地址、接口和模型 ID 是否正确，是否重复拼了请求路径 |
| 429 / 请求过多 | 等限流恢复，查账户额度与请求限制，别连续重发 |
| 网络失败 / 超时 | 当前网络能否访问该平台，代理与平台服务是否正常 |
| 内容过长 / 请求过大 | 减附件或历史内容、换个更合适的模型，光调上限数字没用 |

有些平台用的是自己的错误码，结合报错详情与平台说明判断，别只盯着数字。

## 三、模型列表同步失败，或模型选择器是空的

- **列表拉取失败**：服务商的模型列表接口和对话接口是分开的，有的平台只支持后者——所以列表同步失败不代表不能聊，用平台给的**准确模型 ID** 手动添加即可；已有的模型也不会因为同步失败被清掉。
- **选择器为空**：确认服务商已启用；把选择器的筛选改成「全部」；等首次模型资料下载完成；再确认你选的不是仅供管理的嵌入或重排类型——那类模型本来就不出现在聊天选择器里。
- **改了设置没生效**：服务商地址和密钥、手动添加模型这类改动要点保存或添加；改完服务商地址再测连接之前，先把当前配置保存了。

## 四、安装被拦，或装不上

- **系统直接拦截**：安卓默认拦「来源不明」的 APK。按弹窗提示给**当前打开 APK 的那个应用**（浏览器或文件管理器）勾选「允许安装未知应用」。注意这是按应用授权的：你用浏览器下载、却用文件管理器打开安装，两个都要允许。装完建议把授权关回去。
- **提示解析包错误 / App 未安装**：按顺序查——下载是否完整（文件大小明显偏小就是没下完，重新下载后比对 MD5，见 [下载与安装教程.md](下载与安装教程.md) 的核对信息）；手机存储够不够（至少留出比安装包更大的一块空间）；安卓版本是否过低；手机是不是 32 位的老机型（官方包面向 ARM64 设备，老机器装不了）。之前装过来路不明的同名应用时，签名对不上会报「未安装」，先卸载旧的再装官方包。
- **TestFlight 加不进去（iPhone / iPad）**：名额、测试版有效期或平台服务异常都可能影响，稍后重试或关注官方渠道。

## 五、Beta 版本的几点预期管理

- 界面与功能随版本调整很快：教程截图和你的界面长得不一样，多半是版本差异，先更新再找入口。
- 升级走覆盖安装：从官方下载页重新下载 APK 直接装，聊天数据一般保留。
- **后台没通知、锁屏后生成中断**：查设置 → 通知的相关开关与系统通知权限；系统本身也可能限制后台运行，回到原对话或绘图页看结果，再决定要不要重新提交。
- 某个功能突然不见了：先看官方版本说明确认是挪了位置还是下线，别急着卸载重装。

## 六、数据与隐私

- 对话与配置数据在你设备上的存留、授权范围、换机前要做什么准备，官方有一篇「数据、隐私与权限」专门讲，换手机前值得读一遍。
- 手机与电脑**不会自动同步聊天记录**；设备互联导入的只是服务商配置与模型，换机前把重要内容另行导出（做法见 [智能体与插件工具用法.md](智能体与插件工具用法.md) 第五节）。
- 你用的是自己的 API Key，调用明细与费用都在对应平台侧可查；客户端里看不到账单。
- 不要在第三方网页或来路不明的「镜像客户端」里填密钥。

## 七、搜到的「官网」哪个是真的

认这三个（截至 2026-09）：

- 官网：[cherry-ai.com](https://www.cherry-ai.com/) 与 [cherryai.com.cn](https://www.cherryai.com.cn/)
- 移动版源码仓库：[github.com/CherryHQ/cherry-studio-app](https://github.com/CherryHQ/cherry-studio-app)

搜索引擎里一些「中文站」「镜像站」（如 `cherrystudiocn.app`）并非官方，下载与填密钥都别用它们。

## 八、上面都试过还是不行

去 [App 仓库的问题反馈页](https://github.com/CherryHQ/cherry-studio-app/issues)提 issue，写清四样：客户端版本、手机型号与系统版本、复现步骤、错误提示原文；提交前把密钥和私人对话内容遮掉。服务商相关的疑难（密钥、额度、地区限制）则要找对应平台的客服，客户端这边解决不了平台侧的问题。
