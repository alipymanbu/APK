## 一、发了消息没有回复

按这个顺序排查，多数问题停在前两步：

1. **换一条不带附件的短消息重试**。长文本、大图走的是另一条路，先用最小 Case 确认链路通不通。
2. **核对 API Key**：是不是把平台登录密码当成了密钥；密钥有没有多余的空格；这家平台的普通会员是不是根本不含接口额度。
3. **确认服务商与模型都启用**：设置 → 模型服务里该服务商处于启用状态，对话顶部选的也是它底下已启用的模型。
4. **检查网络**：部分模型平台的服务器在境外，网络环境不通时什么客户端都救不了。

还走不通，去[官方移动版文档的「常见问题」页](https://www.cherryai.com.cn/docs/zh-cn/mobile/troubleshooting/)对一遍错误提示。

## 二、模型列表同步失败

平台接口偶尔拉不动模型列表。处理办法：把平台文档里给出的**准确模型 ID** 复制下来，在客户端里手动添加模型。手动添加之后再测一条消息，通了就继续用。

## 三、安装时被系统拦截

安卓会默认拦下「来源不明」的 APK。在弹出的提示里给当前的浏览器或文件管理器临时勾选「允许安装未知应用」，装完建议把这个授权关回去。完整步骤与安装包核对方法见 [下载与安装教程.md](下载与安装教程.md)。

## 四、Beta 版本的几点预期管理

- 界面与功能随版本调整很快：教程截图和你的界面长得不一样，多半是版本差异，先更新再找入口。
- 升级走覆盖安装：从官方下载页重新下载 APK 直接装，聊天数据一般保留。
- 某个功能突然不见了：先看官方版本说明确认是移动还是下线，别急着卸载重装。

## 五、数据与隐私

- 对话与配置数据在你设备上的存留、授权范围、换机前要做什么准备，官方有一篇「数据、隐私与权限」专门讲，换手机前值得读一遍。
- 你用的是自己的 API Key，调用明细与费用都在对应平台侧可查；客户端里看不到账单。
- 不要在第三方网页或来路不明的「镜像客户端」里填密钥。

## 六、搜到的「官网」哪个是真的

认这三个（截至 2026-09）：

- 官网：[cherry-ai.com](https://www.cherry-ai.com/) 与 [cherryai.com.cn](https://www.cherryai.com.cn/)
- 移动版源码仓库：[github.com/CherryHQ/cherry-studio-app](https://github.com/CherryHQ/cherry-studio-app)

搜索引擎里一些「中文站」「镜像站」（如 `cherrystudiocn.app`）并非官方，下载与填密钥都别用它们。应用本身的 bug 或功能建议，去 GitHub 仓库提 issue，回复一般比想象中快。

## 七、重装还是解决不了

先确认你装的是官方包（包名 `com.cherry_ai.cherry_studio_app`，可用 MD5 比对，见 [下载与安装教程.md](下载与安装教程.md) 里的核对信息），再卸载重装一次；服务商标定与密钥问题则按 [API密钥与模型服务配置.md](API密钥与模型服务配置.md) 重新走一遍。智能体与工具不执行的问题，多出在权限与配置上，见 [智能体与插件工具用法.md](智能体与插件工具用法.md) 的说明。
