## 一、为什么装完还不能直接聊

Cherry Studio 是客户端，本身不附带模型额度。你在里面看到的每一个回答，都是它拿着你提供的**API Key（调用模型服务的密钥）**去对应平台请求回来的。所以第一次打开时，你要先做一件事：把至少一个模型服务接进来。

两个容易踩的认知坑：

- **不要把平台登录密码当 API Key**。密钥是你在平台的开放接口页面里单独创建的一串字符，不是账号密码。
- **普通聊天会员不一定包含开放接口额度**。在某家平台充了会员，不代表它的 API 就能随便调，去对应平台确认一下额度规则。

调用产生的费用由模型平台按量收取，与客户端本身无关。

## 二、两条配置路线，先选一条

| 你的情况 | 走哪条路 |
| --- | --- |
| 电脑上已经在用 Cherry Studio 桌面版，服务商都配好了 | 用「从电脑导入配置」，把电脑里配好的服务商和模型导进来，成功后直接跳到本文第五节 |
| 第一次用，或者电脑上没配过 | 在手机上直接添加服务商，按第三、四节走 |

官方文档把第一条路叫「从电脑导入配置」：手机与桌面版配对后，选择要带到手机的服务商和模型即可。注意截至 2026-09 的口径——**对话历史不会跟着同步**，配对导入的只是服务商配置与模型；远程控制电脑端智能体也不在配对功能范围内。具体扫码步骤、覆盖规则与同步失败的排查，见 [与电脑版配对导入配置.md](与电脑版配对导入配置.md)。

## 三、在手机上添加服务商

1. 首次使用向导里直接选服务商；错过了向导，就打开 **设置 → 模型服务 → 添加服务商**。
2. 内置服务商列表覆盖了常用平台，连预先填好的连接设置都带上了；列表里没有你的平台时，选创建自定义服务商。
3. 填入平台给你的 API Key，点保存。自定义服务商还要按平台说明填**基础地址**并选连接方式。
4. 同步模型列表，选一个常用的文字模型并确认。首次拉取模型资料可能要等一会儿；列表拉取失败时，把平台文档里给的准确模型 ID 复制下来手动添加。
5. 回头确认服务商处于启用状态，再从对话顶部打开智能体编辑页，选中刚启用的模型。

## 四、API Key 从哪来

- **各模型平台的开放接口页面**：在 DeepSeek、硅基流动、智谱这类平台注册账号后，进它们的开放平台或个人中心创建密钥（各家入口名不一样，以平台当时页面为准）。
- **免费模型**：官方与一些合作渠道会提供免密钥或免费的模型供体验（截至 2026-09 的官方页面口径，活动随时可能调整）。
- **额度的查看**：用量记在平台那一侧，去你创建密钥的平台查消耗明细，客户端里看不到账单。

## 五、发第一条消息验证

配置是否成功，发一条消息就知道：

1. 使用初始的 Cherry 智能体，在对话顶部选好刚配置的模型。
2. 发一句「用三句话介绍你能帮我做什么」。
3. 收到回复，基础配置就完成了。

没收到回复的话，先换一条**不带附件的短消息**重试；还不行就按 [常见问题与解决方法.md](常见问题与解决方法.md) 里的顺序排查密钥、模型和网络。

## 六、配好之后值得先试的三件事

- 给写作、翻译这类常用任务分别存一个智能体，各写各的任务说明，见 [智能体与插件工具用法.md](智能体与插件工具用法.md)。
- 把照片或文件丢进对话，让模型帮你看图、读文档。
- 在设置里把字号、主题调成你顺手的样子，用起来更久。
