# Scene ADB 模式激活教程（免电脑）

> ADB 模式是 Scene 里性价比最高的一档：免 ROOT，就能用帧率记录、应用冻结、权限管理这些核心功能。本篇按你的设备条件给你三条激活路线，以及激活失败的排查清单。

## 一、先确认你该走哪条路

| 你的情况 | 走哪条 |
| --- | --- |
| Android 11 及以上，不想连电脑 | 路线一：Shizuku + 无线调试（推荐） |
| Android 11 及以上，装不了 Shizuku 或偏好别的授权器 | 路线二：黑阈 + 激活脚本 |
| Android 10 及以下，或无线调试不可用 | 路线三：电脑 adb |

「无线调试」是 Android 11 起系统自带的功能，它决定了前两条路线的门槛。不管走哪条，都要先把**开发者选项**打开：设置 → 关于手机 → 连续点击「版本号」约 7 次，直到提示已处于开发者模式。

## 二、路线一：Shizuku + 无线调试（Android 11+，推荐）

[Shizuku](https://shizuku.rikka.app/zh-hans/) 是一个把 adb 级权限转交给普通应用使用的工具，Scene 认它作为授权来源。

1. 安装 Shizuku，首次打开允许它发送通知（配对码要通过通知栏输入）；
2. 开发者选项里同时打开「USB 调试」和「无线调试」，手机连着 WLAN（不要用流量）；
3. 进入系统的「无线调试」页面，点「使用配对码配对设备」，会弹出一组 6 位配对码和端口；
4. 下拉通知栏，在 Shizuku 的通知里输入这组配对码，确认配对；
5. 回到 Shizuku 主页点「启动」，等状态变成「正在运行」；
6. 切回 Scene，选择 ADB 模式，弹出授权框时选「始终允许」。

两个系统层面的限制要心里有数：**配对只需一次，但每次重启手机后 Shizuku 服务都要重新点一次启动**（Android 的限制，不是 Scene 或 Shizuku 的毛病）；无线调试依赖同一个 WLAN 环境，换网络后可能要重新来。

## 三、路线二：黑阈 + 激活脚本

黑阈（Brevent）也能充当授权器。这条路线要用到 Scene 官方发布的 ADB 激活脚本，从官方发布页或官方社区获取，**以官方当时提供的为准**，不要用来路不明的脚本。

1. 安装黑阈并完成它自己的初始化；
2. 开发者选项里开启「USB 调试」与「无线调试」（部分机型还需打开「禁止权限监控」，否则配对会提示权限不足）；
3. 在黑阈里点「无线调试端口」，按提示用配对码完成无线配对；
4. 把激活脚本（`scene_adb_init.sh`）放进手机存储，比如 Download 目录；
5. 黑阈主界面 → 左上角菜单 → 「执行指令」，输入：

```bash
sh /storage/emulated/0/Download/scene_adb_init.sh
```

（路径按你实际放置脚本的位置改）

6. 命令返回 ok 即激活成功，回 Scene 选 ADB 模式。

## 四、路线三：电脑 adb（Android 10 及以下）

1. 电脑下载 Google 官方 [SDK 平台工具（platform-tools）](https://dl.google.com/android/repository/platform-tools-latest-windows.zip)并解压；
2. 手机开启 USB 调试，数据线连电脑，首次连接在手机上点「允许调试」；
3. 电脑在解压目录打开终端，先执行 `adb devices` 确认设备已列出；
4. Scene 的 ADB 激活页会显示一条需要在电脑上执行的激活命令，照着复制执行即可 —— **不同版本的命令不同，以应用内当时显示的为准**。

## 五、激活失败的排查清单

| 现象 | 先检查什么 |
| --- | --- |
| 提示「正在搜索配对服务」一直不成功 | 手机与配对是否在同一 WLAN；把无线调试关掉再打开重试 |
| 输入配对码立刻失败 | 配对码是一次性的，弹窗关掉或超时就失效，回系统页面重新取一组 |
| 配对成功但 Scene 弹不出授权框 | 重启 Scene 再进 ADB 模式；检查 Shizuku 状态是否「正在运行」；给 Scene 关掉省电限制、允许后台运行 |
| 提示「adb 权限受限 / 权限不足」 | 部分机型要在开发者选项里开启「禁止权限监控」 |
| 重启手机后 ADB 功能又用不了 | 正常现象：服务被系统清了，重新启动一次 Shizuku（或黑阈）即可，不用重新配对 |

激活成功后能解锁哪些功能、怎么用，见 [帧率记录与性能监控.md](帧率记录与性能监控.md)。
