# Scene 后台被杀与保活设置

> 帧率录到一半断、场景规则不触发、悬浮窗自己消失 —— 这三类问题十有八九不是 Scene 坏了，是系统把它的后台进程清了。本篇给出通用放行步骤与各品牌的具体入口。

## 一、哪些功能依赖后台常驻

Scene 有三件事需要进程活着才能干：帧率记录与悬浮监视器要持续采样；场景模式要在应用切换的瞬间套用你的规则；ADB / Shizuku 服务本身也挂在一个常驻进程上。而国产手机厂商的省电策略普遍激进（多份安卓社区资料的一致结论），不在白名单里的应用，后台几分钟到一晚上不等就会被清掉 —— 表现就是「功能莫名失灵」。

## 二、通用三步（不管什么品牌先做完这三步）

1. **电池不受限**：设置 → 应用 → Scene → 电池（省电策略）→ 选「无限制 / 不受限制 / 允许后台活动」（各家叫法不同，选最宽松的那个）；
2. **允许自启动**：在应用信息或手机管家里找到「自启动」开关并打开；
3. **最近任务加锁**：多任务界面里按住（或下拉）Scene 的卡片，出现锁图标 —— 加锁的卡片在一键清理时会被跳过。

做完这三步后重启一次手机让策略生效。代价是耗电略增，属于这类工具的正常开销。

## 三、各品牌的具体入口

厂商自定义省电层比安卓原生的严格得多，且入口随系统版本变化，下表整理自各品牌通用的保活经验（截至 2026-09），**找不到对应菜单时直接在系统设置里搜「自启动」或「电池优化」**：

| 品牌 / 系统 | 除通用三步外还要看 |
| --- | --- |
| 小米 MIUI / HyperOS | 长按桌面图标 → 应用信息 → 电量消耗 → 「无限制」；安全中心 → 自启动管理放行；省电与电池 → 睡眠待机优化里排除 Scene |
| 华为 / 荣耀 EMUI / HarmonyOS | 设置 → 电池 → 启动管理 → 把 Scene 改成「手动管理」，三个开关（自启动 / 关联启动 / 后台活动）全开 |
| OPPO / 一加 / realme ColorOS | 设置 → 电池 → 应用耗电管理 → Scene → 允许完全后台行为；自启动列表放行 |
| vivo / iQOO Funtouch OS | 设置 → 电池 → 后台功耗管理放行；应用信息里开自启动与后台高耗电 |
| 三星 One UI | 设置 → 电池 → 后台使用限制 —— 确认 Scene 不在「深度睡眠」列表里；把未监测的应用排除项留空 |
| 原生安卓 / Pixel | 通用三步基本够用；设置 → 应用 → Scene → 电池 → 选「无限制」 |

另外两件小事也会杀后台：装了第三方「清理加速」类应用的，它们会按计划清进程，把 Scene 加进自己的白名单或干脆别装；开发者选项里的「后台进程限制」若被改过，恢复「标准限制」。

## 四、验证保活真的生效

设置完别凭感觉，做一次实测：

- **帧率记录**：连录两局游戏，第二局的曲线完整无断档即为通过；
- **场景模式**：给某个应用配一条「切亮度」规则，把手机放半小时回来打开那个应用，规则触发即通过；
- **悬浮监视器**：开着监视器刷一小时别的应用，中途消失即不通过。

哪项不过，回到第二节逐项复查，重点是省电策略有没有真的落到「无限制」。

## 五、重启手机后为什么功能又失效

保活只保「运行中不被杀」，保不了「重启后自动恢复」。Android 11+ 的无线调试服务在重启后必须重新启动一次（系统限制，详见 [ADB模式激活教程.md](ADB模式激活教程.md)），帧率与场景功能随之不可用，这是机制如此，不是设置丢了 —— 重新点一次 Shizuku 的「启动」即可，配对不用重做。

保活本身的具体用途（录帧率、跑场景）见 [帧率记录与性能监控.md](帧率记录与性能监控.md) 与 [场景模式与应用管理.md](场景模式与应用管理.md)。
