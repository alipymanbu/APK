# Scene 三种工作模式怎么选

> Scene 的功能按「基础 / ADB / ROOT」三种模式分层开放，模式选错轻则功能点不开、重则系统出问题。本篇给你一张对照表，以及按需求选模式的判断路径。

## 一、为什么打开就让你选模式

Scene 的很多功能要越过普通应用的权限上限：读帧率、改 CPU 调度、卸载系统应用，靠的都是系统级接口。你选的模式就是给它授多大的权 —— 权限越大，能做的事越多，操作失误的代价也越大。所以模式选择不是注册流程里的一步仪式，而是安全边界。

## 二、三种模式对照表

| | 基础模式 | ADB 模式 | ROOT 模式 |
| --- | --- | --- | --- |
| 能做什么 | 查看概览（电量、温度、型号、开机时长）、屏幕测试；应用管理的基础操作（卸载第三方应用、清缓存、隐藏图标） | 在基础之上解锁帧率记录、充电/耗电统计、系统应用卸载、权限管理、应用冻结、CPU 与 SWAP 调校 | 全部功能，包括删除预装应用、写入或还原系统文件、刷入/备份 Boot 与 Recovery 镜像 |
| 需要什么 | 装上就能用 | 免 ROOT；Android 11 及以上可用无线调试激活，免电脑 | 手机已 ROOT，并在 ROOT 管理器里给 Scene 授权 |
| 主要风险 | 基本没有 | 误卸载关键系统应用，可能要恢复出厂设置才能开机 | 操作不当可能无法进系统、丢失数据 |
| 适合谁 | 只想看看数据、先体验一下 | 想用帧率记录和应用管理，但不想 ROOT 的主流用户 | 玩机老手，手头有备用机或已做好救砖准备 |

## 三、没把握就先停在基础模式

基础模式不会改你系统里的任何东西，适合两件事：一是先熟悉界面，看看你的机型能读到哪些数据；二是做购机验机类的只读检查（屏幕坏点、断层测试就在这个层级可用，具体操作见 [屏幕测试与验机.md](屏幕测试与验机.md)）。

基础模式点不开数据采集类功能（帧率记录、充电统计、耗电统计）—— 菜单里能看到入口，但实际采集需要 ADB 或 ROOT 模式。这不是故障，是权限分层。

## 四、想用帧率记录和应用冻结：ADB 模式

大多数人用 Scene 的目的 —— 给游戏录帧率、冻结后台应用、管自启权限 —— ADB 模式就够，而且**不需要 ROOT**。代价是要做一次激活操作：Android 11 及以上用无线调试配对就能激活，全程不用电脑。

激活步骤与失败排查见 [ADB模式激活教程.md](ADB模式激活教程.md)。进 ADB 模式前应用会让你确认一份风险提示，核心一条值得提前知道：**这个层级可以卸载系统应用**，卸错了可能导致手机无法开机、只能恢复出厂 —— 列表里看不懂用途的条目，不要动手。

同一次确认里还会说明：应用可能收集设备型号、厂商、硬件配置、性能与温控数据，用于适配改进 —— 介意的用户在点「同意」前先看清提示内容。

另外，从 Scene 5 起部分高级功能逐步划入专业版体系，免费可用的主体是基础与 ADB 模式；哪些功能会弹专业版提示随版本变动，付费与积分的规则见 [专业版激活与积分说明.md](专业版激活与积分说明.md)。

## 五、ROOT 模式的门槛与红线

ROOT 模式要求你的手机已经 ROOT，并且 Scene 第一次使用时会在 ROOT 管理器（Magisk、KernelSU 等）里弹授权请求。

点 ROOT 模式提示「没有获取到 ROOT 权限」，通常是两种情况：你的手机本来就没 ROOT；或者 ROOT 管理器的授权弹窗被你点了拒绝 —— 到管理器的应用授权列表里把 Scene 改成允许即可。

应用内对 ROOT 模式的警告大意是：如果你没听说过刷机、变砖、恢复出厂设置，手边也没有备用设备，这个模式不适合你；并且不要在**用来工作**或**存有重要数据**的手机上使用，以免造成无法挽回的损失。这两条是官方原文的立场，不是夸张 —— ROOT 模式下能写入系统文件，写错是真的会开不了机。

## 六、模式随时能切

选错了不用重装：主界面底部有重新选择工作模式的入口，随时切换。从 ADB 切回基础模式，之前做过的配置不会丢；反向切换则要再过一次对应的授权流程。
