## 一、Scene 是什么

Scene 是一款安卓系统级工具箱，前身是玩机圈流传多年的「微·工具箱 / 骁龙工具箱」（vtools），现由苏州聚芒网络科技有限公司开发。它把硬件信息查看、帧率记录、充电与耗电统计、应用管理、性能调校等系统级操作收进一个应用，按「基础 / ADB / ROOT」三种工作模式分层开放权限，不需要 ROOT 也能用其中一部分功能。

它适合想看清游戏真实帧率与温度曲线、想冻结后台应用、想给单个应用单独配性能方案的用户。如果你只想清垃圾、加速手机，这套工具对你的日常来说明显过重，可以不用往下看。

## 二、你手上这份是什么版本

本篇步骤以 2026-09 整理的 v9.1 安装包为基准。Scene 更新很勤，官方渠道的最新版本号大概率已经更高，界面细节以你实际装到的版本为准。

| 项目 | 信息 |
| --- | --- |
| 版本 | 9.1 |
| 包名 | com.jumang.scene |
| 安装包大小 | 27.99M |
| MD5 | 64273429567f891dc177770dc62f33f0 |
| 开发者 | 苏州聚芒网络科技有限公司 |

两点提醒：

- 包名 `com.jumang.scene` 与老版本 `com.omarea.vtools` 不是同一个应用。你以前装过老版骁龙工具箱的话，新 Scene 会作为独立应用安装，两者并存、互不覆盖，想留哪个用哪个。
- 转存后如果反复安装失败，可以核对一下安装包的 MD5 是否与上表一致；不一致说明文件在传输中损坏了，重新下载一份再试。

## 三、获取安装包

从 [Scene 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e3a442d22c5c) 获取，流程是三步：

1. 打开链接，把安装包**转存到自己的夸克网盘**；
2. 手机装好夸克网盘客户端，登录同一账号，在「我的转存」里找到该文件；
3. 下载 APK 到手机本地存储（建议放到「Download」目录，方便后面找）。

也可以先在电脑上完成转存与下载，再用数据线把 APK 拷到手机，效果一样。

## 四、安装步骤

1. 在手机文件管理器里找到下载好的 APK，点它；
2. 系统提示「禁止安装未知来源应用」时，按提示跳到对应开关页，**允许你的文件管理器或浏览器安装应用**（不同品牌入口不同：多数在 设置 → 应用 → 特殊应用权限 → 安装未知应用；小米在 设置 → 隐私保护 → 特殊权限）；
3. 回到安装页点「安装」，等进度走完；
4. 装完点「打开」，或者稍后在桌面点 Scene 图标。

安装包不到 28MB，装完也基本不占什么空间，对存储紧张的旧机型没有压力。

## 五、首次启动：选一种工作模式

首次打开 Scene 会先让你选工作模式，这一步决定了后面能用哪些功能：

- **基础模式**：装上就能进，只能看数据、做应用管理的基础操作，对系统零改动；
- **ADB 模式**：解锁帧率记录、应用冻结等大部分常用功能，免 ROOT，但需要先激活；
- **ROOT 模式**：全功能，风险也最大，只适合已经 ROOT 且清楚自己在做什么的机器。

不确定就先选**基础模式**进去看看，模式之后随时能切。三种模式的能力与风险差异在 [工作模式怎么选.md](工作模式怎么选.md) 里有完整对照；想用帧率记录这类功能，按 [ADB模式激活教程.md](ADB模式激活教程.md) 激活即可。

## 六、装不上 / 打不开的常见情况

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 提示「解析包错误 / 解析失败」 | 安装包没下完整，或下载过程中被改名 | 核对 MD5（见第二节），重新下载；确认文件扩展名是 `.apk` |
| 提示「存在风险 / 已拦截」 | 手机管家拦未知来源 | 在管家或系统安装器里选「仍要安装」；部分品牌要去管家设置里临时关闭安装拦截 |
| 点开就闪退 | 少数机型权限初始化异常 | 重启手机再打开；仍闪退就到官方发布页确认你的机型是否有已知问题 |
| 装完桌面没图标 | 桌面缓存没刷新 | 重启桌面（或重启手机）；确认包名对应的 Scene 在应用列表里 |

如果这些都不奏效，去官方发布渠道看一眼当前版本的机型适配说明，比反复重装更有用。
