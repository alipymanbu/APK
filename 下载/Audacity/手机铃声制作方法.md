# Audacity 制作手机铃声的步骤

> 本篇讲怎么用安卓版 Audacity 把一首歌剪成铃声、转成合适的格式、放到手机认的目录里并设为铃声。

## 一、铃声的三条硬要求

做铃声前先知道系统认什么，能少走弯路：

| 项目 | 建议 | 原因 |
| --- | --- | --- |
| 时长 | 30~40 秒 | 铃响到接听通常就半分钟，剪太长白占空间；彩铃类场景 15 秒也够 |
| 格式 | MP3 最稳，iPhone 场景用 M4A | MP3 各品牌系统设置里都能选；M4A 是 iOS 铃声的格式要求 |
| 开头 | 高潮部分直接进 | 铃声没有"前奏"的耐心，从副歌入口剪起最实用 |

## 二、剪出铃声段落

1. 打开应用，选中源歌曲，播放确定副歌位置（方法见 [音频剪辑与拼接操作.md](音频剪辑与拼接操作.md) 的剪辑一节）；
2. 标记起点和终点，截出 30~40 秒；
3. 试听三处：**开头**是否干脆（别带上一句的尾音）、**结尾**是否完整（别切断在半个字上）、整体音量是否够响（手机外放和口袋里都要听得见）；
4. 结尾生硬的话，给最后 1~2 秒加一个淡出，接电话前的体验好很多。

## 三、导出成铃声格式

- 导出为 **MP3**（安卓通用）或 **M4A**（给 iPhone 用，安卓上做好的 M4A 需再经苹果工具处理）；码率 192 kbps 左右就够——铃声总长才半分钟，320 kbps 和 192 kbps 听感差异远小于体积差异（码率与体积的换算见 [音频格式转换方法.md](音频格式转换方法.md)）；
- 文件名改成好认的名字，比如 `铃声-歌名-副歌.mp3`，后面在系统设置里选的时候一眼能找到。

## 四、放进系统认的目录并设为铃声

安卓系统只把固定几个目录登记进媒体库（`Music`、`Ringtones`、`Alarms`、`Notifications`、`Recordings` 等），放在别处的音频在系统设置里常常选不到：

1. 用文件管理器把导出的文件**复制到 `Ringtones` 目录**（手机自带文件管理器一般都支持；目录不存在就新建一个）；
2. 进"设置 → 声音和振动 → 手机铃声"，在列表里找刚才的文件名选中；
3. 想给**闹钟**用就放进 `Alarms`，**通知/短信音**放进 `Notifications`，对应去各自的设置页选。

图省事的话，很多品牌允许在文件管理器里长按音频 → "设为铃声"，跳过手动挪目录——但这种快捷入口认的格式和时长限制各不相同，不生效时老老实实按上面三步走。

## 五、设完不生效怎么办

- **列表里找不到文件**：九成是没放进 `Ringtones` 目录，或放完没刷新媒体库——重启手机最省事；
- **选项是灰的 / 点击没反应**：个别系统对铃声文件有时长或格式限制，换 MP3、剪短到 40 秒以内再试；
- **响一声就停 / 有杂音**：回头检查剪辑点的淡出和音量（见本文第二节第 3 步）；
- **装了多个剪辑应用后选项错乱**：系统"默认应用"设置里可能残留旧应用的铃声选择器，清理默认设置再选。
