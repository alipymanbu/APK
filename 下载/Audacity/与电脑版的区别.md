## 一、先说结论：不是同一家出品

官方 Audacity（由 Audacity 团队开发、官网为 [audacityteam.org](https://www.audacityteam.org/) 的那款）**只有 Windows、macOS、Linux 桌面版**，官方 FAQ 明确说明没有推出过安卓或 iOS 版本，应用商店里带这个名字的移动应用不是官方团队做的。

你手上这份安卓安装包是第三方开发者发布的同名音频剪辑应用：

| 项目 | 安卓版（本文档的主角） | 官方桌面版 |
| --- | --- | --- |
| 开发方 | 贵阳惠跃网络技术有限公司（包名 `com.audcity.huiyex`） | Audacity 团队（开源项目） |
| 运行平台 | 安卓手机 / 平板 | Windows、macOS、Linux |
| 获取方式 | 夸克网盘安装包（见 [下载与安装教程.md](下载与安装教程.md)） | [官网下载页](https://www.audacityteam.org/download/) |
| 定位 | 手机上快速剪、拼、转格式、录音 | 电脑上的多轨编辑与精细处理 |

在应用商店看到付费的"Audacity"或"Audacity 移动版"时别当成官方手机版购买——官方团队对这一点的口径是明确的。

## 二、官方桌面版是什么水平

桌面版是免费开源软件（GPL 协议），从 2000 年发展至今，长项在"深度处理"：

- **多轨编辑**：几十条音轨上下排开，分别剪辑、移动、混音；
- **降噪与修复**：采样降噪、点击去除这类精细修复工具；
- **效果器体系**：均衡器、压缩、变调不变速、混响回声等，还支持 VST3、Nyquist 插件扩展；
- **格式支持全面**：导入导出 WAV、MP3、FLAC、OGG、M4A、AIFF 等，可做批量导出。

想在电脑上装桌面版的话，截至本文写作时官方标注的系统要求是 Windows 10/11、macOS 12 及以上、Ubuntu 22.04 一类的近年发行版，老系统装不装得上以官方页面说明为准；下载渠道有官网直下和 MuseHub 两种，都是免费的。以上信息来自官方站点的功能与 FAQ 页面，具体以官方页面为准。

## 三、功能对照：手机版有什么、没什么

安卓同名应用走的是"轻量快速"路线，围绕手机上的高频需求：

| 需求 | 安卓版 | 桌面版 |
| --- | --- | --- |
| 截一段音频 / 删一段杂音 | 能，几步完成 | 能，更精细 |
| 多段拼接成一条 | 能 | 能，接缝处理更细 |
| 转 MP3 / WAV 等格式 | 能 | 能，且支持批量 |
| 调音量、淡入淡出 | 能 | 能 |
| 实时录音 | 能（手机麦克风随身带） | 能（需外接或内置麦克风） |
| 多轨混音、降噪、变调变速 | 不是强项 | 强项 |
| 插件扩展 | 无 | 支持 VST3 / Nyquist |

一句话分工：**手机版管"随时随地快速出活"，桌面版管"坐下来精细处理"**。

## 四、两边怎么搭配用

实际用起来效率最高的组合：

1. **手机上先处理**：录音、截取、拼接、转格式这些快活直接在手机上完成，传电脑省一步；
2. **电脑上再精修**：需要降噪、多轨混音、精细变调的文件传到电脑，装桌面版处理；
3. **文件互通**：用网盘、数据线或聊天工具把音频在两端之间传，格式选 MP3 或 WAV（手机端转换方法见 [音频格式转换方法.md](音频格式转换方法.md)），WAV 留给要精修的母带，MP3 用来日常传输。

只在手机上处理轻度需求的话，安卓版单独用就够，不必为了剪个铃声去装电脑软件。

## 五、别装错：认准你要的那一个

- 想在**手机**上剪音频 → 用你手上这份安卓安装包，安装与权限设置见 [下载与安装教程.md](下载与安装教程.md)；
- 想在**电脑**上做深度音频编辑 → 去官方站点下载桌面版，免费开源，官网地址见本文第一节表格；
- 看教程时先分清写的是哪一版：桌面版教程里的菜单和快捷键在手机版上对不上号，属于正常现象。
