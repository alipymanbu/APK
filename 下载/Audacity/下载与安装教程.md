## 一、先认清你要装的是哪个 Audacity

搜索"Audacity"时，排在前面的大多是**官方桌面版**（Windows / macOS / Linux 上的音频编辑软件）的资料。但官方团队至今没有出过手机版——安卓上带这个名字的应用是第三方开发者发布的同名产品，两者不是一回事。你手上这份安装包的基本信息：

| 项目 | 信息 |
| --- | --- |
| 应用名 | Audacity（安卓音频剪辑应用） |
| 安装包大小 | 约 78.55 MB（本文写作时网盘这份的版本为 1.3） |
| 包名 | `com.audcity.huiyex` |
| 开发者标注 | 贵阳惠跃网络技术有限公司 |
| 系统要求 | 安卓 5.2 及以上（以安装时系统实际提示为准） |

装之前确认手机系统版本达到要求，一般安卓 5.x 之后的机型都能装。两个"Audacity"的关系与差异，在 [与电脑版的区别.md](与电脑版的区别.md) 里有完整说明。

## 二、获取安装文件

安装包放在夸克网盘里，按下面顺序操作：

1. 打开上面网盘链接，把安装文件**转存到自己的网盘**（不转存部分场景下无法完整下载）；
2. 在夸克网盘 App 里找到转存后的文件，下载到手机本地存储；
3. 下载完成后从通知栏或"文件管理 → 下载"里找到这个 `.apk` 文件。

下载中断、进度卡住时，先检查手机剩余存储空间是否充足（安装包约 78.55 MB，加上安装过程的空间开销，建议预留 500 MB 以上）。

## 三、安装步骤

安卓对"应用商店之外"的安装包默认有拦截，第一次装通常要手动放行：

1. 在文件管理里点击刚下载的 `.apk` 文件；
2. 系统弹出"出于安全考虑，已禁止你的手机安装来自此来源的应用"时，点"设置"，把**允许来自此来源的应用**打开（不同品牌叫法略有差异：华为/荣耀叫"允许安装未知应用"，小米在"纯净模式"里关，OPPO/vivo 在安装时直接给权限）；
3. 返回安装界面，点"安装"，等进度条走完；
4. 安装完成后点"打开"，或从桌面图标进入。

首次启动时应用会陆续申请权限，逐条看清楚再点允许：

- **存储 / 文件权限**：扫描、导入手机里的音频，以及保存剪辑和导出结果，都靠它，建议允许。安卓 13 及以上系统里这一项会显示为"**音乐和音频**"，是同一个用途的细分权限；不用录音可以跳过下面的麦克风项，但这项不能跳；
- **麦克风权限**：要用实时录音功能就必须允许，不用录音可以拒绝，剪辑和格式转换不受影响；
- **网络权限**：应用联网时系统会自动处理，一般无需手动设置。

以安装时系统实际弹出的清单为准，与本文描述有出入时以弹窗为准。

## 四、装不上或被拦截怎么办

按现象对号入座：

- **提示"解析包时出现问题"**：多数是安装包没下完整。核对文件大小是否约 78.55 MB；要求严格的可以核对 MD5 是否为 `E14A2AF9326BB2CD493607C91C6CA996`，对不上就重新下载一遍。
- **点了安装没反应 / 一闪而过**：先在"设置 → 应用管理"里卸载旧的同名应用再装；重启手机后再试一次。
- **小米/红米提示"禁止安装"**：进"设置 → 更多设置 → 纯净模式"，暂时关闭后再装，装完可以再打开。
- **提示存储空间不足**：清理出 500 MB 以上空间再装。
- **安装完成后桌面没有图标**：部分手机把新应用归到"应用抽屉"或需要手动添加到桌面，在全部应用列表里找一下。

仍装不上时，把报错文字截图记下来，对照 [常见问题与解决办法.md](常见问题与解决办法.md) 里"装不上"一节逐条排查。

## 五、装完先做两件事

1. **给存储权限**：进入应用后如果它提示需要访问文件，直接同意；漏掉了也可以到"设置 → 应用 → Audacity → 权限"里手动补上。
2. **试录一段音**：录 10 秒、播放、保存，全流程走通一次，确认麦克风权限和存储权限都正常，后面正式剪音频就不会在半路卡权限。
