## 一、两条版本线

| | 旧版（网盘这份 3.20.0 所属的线） | 新版（官网 / Google Play 在发） |
| --- | --- | --- |
| 平台 | Android | Android、Windows、macOS |
| 功能 | 只做画质增强（放大） | 放大 + 照片上色 + 背景移除 + 人像 / 动漫增强 |
| 输出格式 | PNG、JPG | PNG、JPG（另有第三方评测提到新增 WebP，以实际界面为准） |
| 分发 | GitHub 仓库已归档为只读，仅剩早期版本包可下 | 官网 [https://superimage.io/](https://superimage.io/) 与 Google Play |
| 收费 | 免费 | 免费版 + Pro 一次性买断 |

旧版就是「只做一件事」的应用：选图、选档位、放大，没有账号、没有订阅。3.20.0 的界面与档位细节见[把模糊照片变清晰的步骤](把模糊照片变清晰的步骤.md)。

## 二、新版多了什么

截至 2026-09，官网与商店页面列出的新版能力：

- **照片上色**：黑白老照片一键上色；
- **背景移除**：抠出主体、生成透明底；
- **人像增强 / 动漫增强**：针对人脸细节与动漫线稿的专门处理；
- **放大**：仍在本机 GPU 上处理，不上传云端；
- **批量队列**：一次排多张图。

其中上色、背景移除等只在新版里有，旧版 3.20.0 装不出来这些功能。

## 三、免费版与 Pro 的差别

官网把新版分成免费版和 Pro（官方口径为一次性买断、无订阅）。截至 2026-09 官网列出的差别：

| 项目 | 免费版 | Pro |
| --- | --- | --- |
| 批量队列 | 每批最多 25 张 | 无限制 |
| 广告 | 含广告（Pro 功能列表明确列「无广告」） | 无广告 |
| 保存位置 | — | 可自选保存位置 |
| 自定义模型 | 免费版未列出 | 支持（详见[自定义模型怎么导入](自定义模型怎么导入.md)） |
| 新功能 | — | 抢先体验 |

Pro 的价格随渠道与时期变动，具体以官网当时显示为准。

## 四、怎么选

- **手机上只是想把照片放大变清晰**：网盘这份 3.20.0 就够用——免费、无广告、不联网，从上面的[SuperImage 安装文件资源（夸克网盘）](https://pan.quark.cn/s/80a7b9f8adf4)转存即用；
- **要在电脑上批量处理大图**：只有新版有 Windows / macOS 版，去官网下载；
- **需要上色、抠背景**：同上，只有新版有这些工具；
- **手机上想要新版功能**：走 Google Play 或官网的 Android 入口，注意免费版含广告、部分能力要 Pro。

装机步骤不分新旧版，见[下载与安装教程](下载与安装教程.md)。
