# SuperImage 跑不动或闪退的排查方法

> 图像处理到一半没动静、应用闪退、跑完了找不到结果——本篇按现象给排查顺序，多数问题出在设备门槛和档位选择上。

## 一、先核对两道设备门槛

装得上不代表跑得动，处理发生在 GPU 上，两道缺一不可：

| 现象可能的根源 | 核对方法 |
| --- | --- |
| 安卓版本低于 7.0 | 设置 → 关于手机 → Android 版本 |
| GPU 不支持 Vulkan 或 OpenCL | 用设备信息类应用查 GPU 型号与支持的图形 API |

都满足还闪退的话，先试 x4 快速档处理一张小图，排除「图太大」的因素（见第三节）。

## 二、处理太慢，像卡死了

多半不是卡死，是真的在算。SuperImage 把整张图切成小块在 GPU 上逐块放大再拼合，分辨率和倍数上去之后耗时以分钟甚至十分钟计——骁龙 855 跑 16x 常规档处理一张 1080p 也要约 11 分钟，中低端机更久。

判断真假卡死的办法：对照上面的耗时量级先等够时间；真异常的表现通常是应用直接退出，而不是画面停住。

提速手段按性价比排：

1. 换 **x4（快速）** 档，速度差一个量级；
2. 换小一点的原图；
3. 动漫图改选 **x16（画质 - 绘画）**，比同倍数常规档快得多——档位细节见[超分模式与输出格式怎么选](超分模式与输出格式怎么选.md)。

## 三、大图失败或闪退

放大倍数是乘在**边长**上的：一张 4000x3000 的照片走 16x，输出是 64000x48000，远超一般手机的内存承受范围。表现就是处理中闪退或中途失败。

处理思路：倍数降一档（16x 改 x4）、或者先用别的工具把图缩到 1080p 级别再放大。原图越大，越要选低倍数。

## 四、跑完了找不到结果文件

三个地方依次找：

1. **相册 / 图库**：按时间排序，最新那张就是，文件名可能带着所用模式的标记；
2. **文件管理器的图片目录**：开了设置里的「输出文件后缀名」开关时，输出文件名会包含模式信息，搜后缀关键字能直接定位；
3. **确认处理真的完成了**：设置里「复制图像元数据」等开关不影响出图，但如果中途杀过应用，任务是作废的，重新跑一遍。

## 五、透明背景的图变色了

SuperImage 在增强过程中会丢掉透明度（设置页原文的说明），透明区域会被填充成设置里「透明图像的背景颜色」指定的颜色，默认可能是白色或黑色。需要保留透明通道的图（PNG 抠图素材之类），3.20.0 处理不了，先在别的工具里处理透明背景。

## 六、以上都排过了还不行

反馈渠道按可用程度排：

- **Telegram 群组**：设置页里的入口，有开发者和其他用户，是目前最直接的求助渠道；
- **GitHub 仓库**：[https://github.com/Lucchetto/SuperImage](https://github.com/Lucchetto/SuperImage) 已归档为只读，issue 区只能翻历史讨论、不能新开帖，但旧帖里常能找到同类问题的答案；
- **官网**：[https://superimage.io/](https://superimage.io/)。如果你的问题出在旧版、新版已经改掉，换新版渠道比继续折腾旧版更省事，两条版本线的差别见[电脑版与手机版有什么不同](电脑版与手机版有什么不同.md)。

提问时附上手机型号、安卓版本和出问题的原图尺寸，回复会快很多。

重新安装或换版本时，安装包入口见[下载与安装教程](下载与安装教程.md)。
