# Todoist 过滤器查询写法

> 过滤器是自建任务视图：一条查询 = 一个只显示符合条件任务的列表。本篇把常用符号与查询组合列成表，抄进去就能用。

## 一、在哪建过滤器

1. 打开应用，点右下角**浏览**；
2. 点**过滤器与标签**；
3. 在**过滤器**旁边点「+」，起名、填查询、保存。

免费版最多 3 个过滤器，Pro 150 个（数字见 [免费版与专业版区别.md](免费版与专业版区别.md)），免费用户要把名额用在刀刃上——建议先从第四节的组合里挑。

## 二、六个符号

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| `\|` | 或 | `today \| overdue` |
| `&` | 且 | `today & p1` |
| `!` | 非 | `!#工作` |
| `()` | 分组，先算括号里 | `(today \| overdue) & #工作` |
| `,` | 分成多个列表显示 | `due: yesterday, today` |
| `\` | 转义特殊字符与多词名称 | `#One \& Two` |

## 三、常用查询词

| 想看什么 | 查询 |
| --- | --- |
| 今天到期 | `today` |
| 今天或已逾期 | `today \| overdue` |
| 今天到期的 P1 | `today & p1` |
| 某项目里的任务 | `#项目名` |
| 带某标签的任务 | `@标签名` |
| 没有日期的任务 | `no date` |
| 任务名含关键词 | `search: 会议` |
| 某天之前到期 | `due before: 5/5` |

写法说明：

- 项目用 `#`、标签用 `@`，后面跟名字；名字里有空格或 `&` 这类符号时用 `\` 转义；
- 日期词（`today`、`overdue`、`no date` 等）用英文写法在各个语言界面都通用；不确定时直接敲进**搜索框**验证——搜索框支持同一套查询语法；
- `p1` 到 `p4` 是优先级，P1 最高。

## 四、抄了就能用的三个组合

```text
(today | overdue) & p1          # 今天到期或已逾期的最高优先级
#工作 & (today | overdue)       # 「工作」项目里今天要交的和已经拖了的
@等待 & !#工作                  # 带「等待」标签、但不在工作项目里的
```

一个过滤器默认只放一条查询；想在同一个过滤器里分多个列表显示，用 `,` 隔开多条查询（如 `due: yesterday, today`）。

## 五、查询不生效时

- 符号拼成全角（`｜`、`＆`）不认，要用英文半角；
- `#`/`@` 后面的名字要与项目、标签的实际名字逐字一致（含大小写）；
- 过滤器建好了但列表是空的：不是出错，是确实没有符合条件的任务——把条件拆开逐段验证。

官方的完整查询字典见 [Introduction to filters](https://www.todoist.com/help/articles/introduction-to-filters-V98wIH)。写好的过滤器视图可以直接绑到桌面小部件上，见 [桌面小部件用法.md](桌面小部件用法.md)。
