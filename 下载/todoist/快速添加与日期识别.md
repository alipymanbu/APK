# Todoist 快速添加与日期识别

> 本篇讲 Todoist 用得最多的一个动作：把任务敲进输入框。日期、循环、优先级、标签都能在标题里直接写出来，不用进二级菜单。

## 一、入口与基本操作

- 打开应用后点底部的**添加任务**按钮（或在某个项目里点「+」），输入任务名，保存即可；
- 输入时 Todoist 会实时识别你写下的日期与重复规则，并把识别到的部分**高亮**——出现高亮就代表它听懂了；
- 识别错了？点一下高亮的词即可取消，让整句当普通文字处理。

## 二、日期与循环的自然语言写法

任务名里直接混着写日期就行，常见写法对照：

| 你输入 | 得到什么 |
| --- | --- |
| `明天` / `明天 14:00` | 到期日（可带时间） |
| `每周一` / `每天` / `每月5号` | 循环任务，完成后自动跳到下一轮 |
| `9月30日 9:00` | 指定日期+时间 |
| `every Monday` / `every!` | 英文写法；`every!` 按「实际完成日」推进 |

规则说明：

- 完成一条循环任务后，它会自动出现在下一轮日期上，不用重建；
- `every`（如 `每周一`）按**计划日期**推进；`every!` 按**你实际点完成的那天**推进，适合「干完一轮再隔固定时间」的事；
- 不想手打，也可以点开任务详情 → **日期** → **重复** → **自定义**，在界面里选频率与结束时间。

官方对循环日期的完整说明见 [介绍循环日期](https://www.todoist.com/help/articles/introduction-to-recurring-dates-YUYVJJAV)。

## 三、优先级与标签

- 任务名末尾加 `p1` 到 `p4`：P1 最高，P4 最低，保存后变成不同颜色的小旗子；
- 加 `@标签名` 可以给任务打标签，一个任务可挂多个标签；想按标签、优先级把任务拉成自定义列表，写法见 [过滤器查询写法.md](过滤器查询写法.md)；
- 这两样免费版都能用；标签每账号上限 500 个，正常用量碰不到。

## 四、子任务与版块

- 任务详情里可以加**子任务**，把大事项拆成步骤；
- 项目内可建**版块**（Section）分组，每个项目最多 20 个版块（官方用量限制，所有套餐一致）；
- 任务描述（详情里的第二个输入框）适合放链接和备注，长度上限一万多字符，够写。

## 五、提醒跟日期的关系

- 任务带上**日期+时间**后，会按设置默认生成一条**自动提醒**——免费版可用，默认约提前 30 分钟，可在提醒设置里改；
- **自定义提醒**（指定提醒时间、按位置提醒）属于 Pro 功能；
- 具体差异与数值见 [免费版与专业版区别.md](免费版与专业版区别.md)；提醒收不到的排查见 [常见问题与解决方法.md](常见问题与解决方法.md)。
