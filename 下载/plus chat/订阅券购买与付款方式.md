## 一、先分清免费和付费

| 免费 | 付费（需买使用券） |
| --- | --- |
| 艺人社区（HOME / FEED 看帖、互动） | 与艺人的私人 CHAT |
| MEDIA 里艺人发布的内容 | ChitChat 成员群聊 |
| 关注艺人、收官方公告 | —— |

价格与在售艺人随时变化，以购买页显示为准；ZEROBASEONE、EVNNE、izna 等多个艺人社区开通过聊天服务，并非所有艺人都有。

## 二、两种使用券

| | 订阅型使用券 | 期间型使用券 |
| --- | --- | --- |
| 扣费方式 | 定期付款，应用商店自动续费 | 单次付款 |
| 有效期 | 按订阅周期持续有效 | 自付款日起 1 个月 |
| 续期 | 自动续费，取消按渠道规则操作 | 到期即停，想续要每月重新买 |
| 适合谁 | 长期追、不想每月手动操作 | 先试一个月、或只追某段活动期 |

同一艺人同一时间买一种即可；想不中断使用，订阅型更省事。应用商店的自动扣费可能落在续费日前后 48 小时内，留意扣费时间。

## 三、在哪买

1. **网页端艺人商店**（支付方式最全）：打开 `https://artist.mnetplus.world` 进入对应艺人页面，进 SHOP 选使用券，再选人数（1 人券到 N 人券）和艺人。
2. **App 内商店入口**：艺人页面内直接购买。
3. **App Store / Google Play 内购**：订阅型走应用商店自动扣费，取消也在应用商店里办。

付款前再确认四件事：

- **先看成员名单**：不是每位成员都开放聊天，购买页会列出提供服务的成员，确认你的本命在列再付款；
- **券数等于能选的人数**：买几张（人）券，就能选几位成员收发消息（1 人券到 N 人券）；
- **同一方案不能重复购买**：给同一位成员重复买同种券会被拒绝；
- **入口以艺人页面为准**：有的艺人聊天只在 App 内出售，网页商店没有对应商品。

## 四、不能上 Google Play 时的买法（支持支付宝）

官方专门给无法使用 Google Play 的用户开了网页购买流程：

1. 打开官方指引页 [https://www.mnetplus.world/zh-CN/external/pluschat-apk-download](https://www.mnetplus.world/zh-CN/external/pluschat-apk-download)。
2. 注册或登录（Mnet Plus ID 或 PlusChat ID 都行）。
3. 在商品页点购买；先在右上角头像菜单里把语言调成中文、货币调成 USD 或 JPY。
4. 选订阅型或期间型使用券，选人数、选艺人。
5. 支付方式选 EXIMBAY，再选支付宝完成付款。
6. 付款完成后，App 里必须登录**同一个 ID** 才能用聊天服务（见 [注册与登录流程.md](注册与登录流程.md)）。

通过这个页面购买，积分奖励等福利与应用商店购买相同（官方说明）。

## 五、退款与取消

- 未开始使用服务的情况下，自购买日起 7 天内可申请撤销认购并退款（以购买页与官方公告的具体说明为准）。
- 订阅型的取消与退款走付款渠道：应用商店买的在应用商店里取消，网页端买的按其支付规则处理。
- 因发送威胁性或不当内容被官方限制使用的，已购使用券不予退款。

"取消续订"和"申请退款"是两回事，后者的代价（使用权立即结束、订阅天数清零）与申请路径见 [到期取消与换绑指南.md](到期取消与换绑指南.md)。

## 六、买完之后

打开 App，确认登录的是买券那个 ID，底部切到 CHAT 页签即可开始（操作细节见 [聊天功能与回复规则.md](聊天功能与回复规则.md)）。
