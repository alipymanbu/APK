# TickTick 数据备份与两个账号怎么合并

## 一、数据到底存在哪

TickTick 的任务、清单、习惯、专注记录都挂在**账号**上，不在手机本地 —— 换手机、重装应用后登录同一账号就全回来了（前提是你记得密码、能收验证邮件；密码保管好，有条件再开双重验证）。这意味着两件事：

1. **备份 = 备份账号数据**，官方入口在网页端，不在手机 App 里；
2. **手机丢了不等于数据丢了**，但账号被盗就等于数据没了，账号安全比装哪个安装包更要紧。

如果你手上有两套账号数据要合并，或想从其他待办应用搬家，往下看；只是日常换设备，登录同账号即可，不用走备份流程。

## 二、生成备份文件（网页端）

1. 用你的账号登录网页版 [www.ticktick.com](https://www.ticktick.com)；
2. 点左上角**头像 → 设置 → 账户 → 备份与恢复**（帮助中心的路径表述为「设置 → 账户 → Backup & Restore」，菜单以实际页面为准）；
3. 点**「生成备份」**，浏览器会把一份包含你全部数据的备份文件下载到电脑上。

定期导一份放在本地是低成本的保险：账号异常、误删清单时，有文件才有得恢复。

## 三、把两个账号的数据合并成一个

官方给的合并思路是「**先备份，再导入**」，方向是单向的 —— 把 A 账号的数据并进 B 账号，而不是双向对等合并：

1. 登录 **A 账号**（要被并掉的那个）→ 网页端「设置 → 账户 → 备份与恢复 → 生成备份」，存下备份文件；
2. 退出，登录 **B 账号**（保留为主账号的那个）→ 同一页面点**「导入备份」**，上传刚才的文件；
3. 等导入完成，B 账号里就会多出 A 账号的清单与任务。

两个注意点：

- 导入是**往主账号里加**，官方只给了「备份一个账号、导入另一个账号」这条路径，没有描述同名清单会怎么处理 —— 导完把清单列表过一遍，发现重复就手动删掉冗余那份；
- 导入前先在 B 账号里生成一次自己的备份，万一导入结果不符合预期，手里有恢复用的文件。

## 四、从其他待办应用搬数据进来

如果你想从 Todoist、Microsoft To Do、Apple 提醒事项等工具迁移：

- **手机端**：「设置 → 导入与集成」里可直接导入部分应用（帮助中心列出的有提醒事项、Todoist、Microsoft To Do 等，具体可选项以你版本里的列表为准）；
- **网页端**：「头像 → 设置 → 集成与导入」，支持的范围更广（Todoist、Microsoft To Do、Wunderlist、OmniFocus、Toodledo、iCal 等），按提示上传对应格式的备份文件即可。

搬过来之后建议先跑一遍清单归类 —— 导入后的任务落在哪些清单里因导入方式而异，别假设它们会自动对上你的分类习惯，逐个清单过一遍再重新分派（分类方法见[看板日历时间线视图怎么用.md](看板日历时间线视图怎么用.md)）。

## 五、把 TickTick 日历订阅到其他日历

除了搬进来，也能把 TickTick 的日程**单向输出**给 Google 日历、Outlook 这类外部日历看（反方向把外部日历接进 TickTick 的设置在第三方关联里，用法见[看板日历时间线视图怎么用.md](看板日历时间线视图怎么用.md)）：

1. 在桌面端登录 TickTick，「头像 → 设置 → 集成与导入」；
2. 找到「其他 → 订阅 TickTick」，点「启用 URL」；
3. 勾选要订阅的清单，生成对应的 URL 链接；
4. 把链接粘贴进目标日历的「添加订阅日历」里，完成订阅。

这是链接订阅，别人拿到链接就能看到所选清单的日程，生成后注意别把链接贴到公开场合。

## 六、多端同步与备份的关系

**同步不是备份**：各端登录同一账号后是实时互相可见的同一份数据 —— 这解决「多设备看到同一套任务」，不解决「数据误删/账号异常后找回来」。恢复靠的是第二、三节的备份文件（网页端「导入备份」可以把文件恢复进账号）。

某台设备上的改动没出现在另一台上时，按顺序查三处：

1. **两端登录的是不是同一个账号**（登错邮箱是最常见的原因）；
2. **网络通不通** —— 同步要联网，离线期间的改动要等联网后才上传；
3. **应用版本是否过旧** —— 网页端刷新一下，若网页端能看到新任务而手机端看不到，让手机端在前台打开、切一次页面触发刷新，仍不更新再考虑重装（重装不丢数据，任务在账号里）。

另外，会员到期不续不会清数据（见[免费版和高级会员区别.md](免费版和高级会员区别.md)），所以即使你升级过又退回免费版，历史任务也都在。
