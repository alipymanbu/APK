## 一、小组件能替你干什么

小组件让你**不打开应用**就能看到今天的任务、日程、习惯进度，并且小组件上往往带一个「+」，点一下直接进添加任务界面 —— 这是从桌面两步完成记录的最短路径。先把应用装好、登录账号（见[下载与安装教程.md](下载与安装教程.md)），小组件显示的才是你的数据。

## 二、添加入口：各品牌的通用动作

安卓没有统一的小部件入口，但动作都是「**长按桌面空白处 → 小部件/Widget → 找 TickTick**」。官方帮助中心给的分品牌步骤：

| 品牌 | 入口 |
| --- | --- |
| Google Pixel | 长按桌面空白处 → 点「小部件」→ 找到 TickTick → 选中要添加的部件 → 添加 |
| 三星（Samsung） | 长按空白处（或双指捏合桌面）进入桌面编辑模式 → 底部点「小组件」→ 搜索 TickTick → 选择并添加 |
| 其他品牌 | 长按桌面空白约 2 秒 → 出现「添加小部件/Widget」→ 在列表里找 TickTick → 点「添加」 |

找不到 TickTick 那一项时，按下面第四节处理，多半不是应用的问题。

## 三、可选哪些小组件

官方帮助中心列出的类型（你机型上实际可选的以列表为准）：

- **任务类**：任务列表（直接看今天的任务）、任务完成统计（近 30 天每天完成数）、快速添加任务（一个带「+」的按钮）；
- **日历类**：今日日历、日/周程视图、月历总览；
- **四象限**：在桌面上直接按重要/紧急四格看任务；
- **习惯类**：今日习惯、本周习惯、习惯热力图（当月打卡分布）；
- **番茄专注**：今日专注（当天累计专注时长）、专注分布（本周各天时长）；
- **倒数**：把重要的纪念日/倒计时钉在桌面。

选哪个取决于你桌面想盯什么：想盯今日任务选任务列表，想盯打卡选习惯，想少占地方选快速添加。各类型的用途细节与视图里的对应关系见[看板日历时间线视图怎么用.md](看板日历时间线视图怎么用.md)。

## 四、小部件列表里找不到 TickTick

按可能性从高到低排查：

1. **应用装在了 SD 卡上** —— 部分机型不允许从 SD 卡安装的应用提供桌面小部件，把应用移到手机内存（设置 → 应用 → TickTick → 存储 → 更改存储位置，机型不支持则先卸载重装到内部存储）；
2. **桌面本身的毛病** —— 小部件偶尔消失时，重启手机一般就能恢复；
3. **还没装应用** —— 小部件由应用提供，没安装就不会出现在列表里；
4. **系统对后台的限制** —— 桌面不刷新、任务不更新时，先对照[安卓提醒不响怎么排查.md](安卓提醒不响怎么排查.md)第三层把 TickTick 的后台限制放开，小组件的刷新同样吃这个设置。

## 五、调整大小与位置

长按已添加的小部件，拖动边角的控制点即可改大小；大部分任务/日历类部件支持拉伸，个别固定尺寸的部件（如角标类）拉不动属正常。想换内容就删掉重新添加 —— 小组件本身不存数据，删掉不影响账号里的任何任务。
