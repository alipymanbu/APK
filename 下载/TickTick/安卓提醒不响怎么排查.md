# TickTick 安卓提醒不响怎么排查

## 一、先明白问题出在哪一层

安卓上的「到点不提醒」几乎从来不是应用本身没算对时间，而是**提醒在到达你眼前之前被系统拦掉了**：要么通知权限没给，要么应用在后台被电池优化杀掉，要么系统的定时唤醒没轮到它。所以排查顺序是从「最容易被关掉的开关」查到「最深的系统设置」，每查一层就测一次，不用一次全改完。

本篇针对安卓手机端；先确认装的是这份包（版本 8.1.3.6、包名 `com.ticktick.task`，见[下载与安装教程.md](下载与安装教程.md)）。

## 二、第一层：应用内与系统通知权限

1. 打开 TickTick →「设置 → 声音与通知」，确认通知权限是开启的；这一页面里还带一个**「提醒不工作？」（Reminders not working?）的自助入口**，点进去是官方按机型整理的解决方案列表，先把它过一遍能少走弯路；
2. 系统设置 →「通知」→ 找到 TickTick → 确认通知处于允许状态，且不是「静默送达」；
3. 同一页面里的**「响铃模式」（Alert Mode）**要打开 —— 官方帮助中心明确提到，受安卓系统限制，部分手机必须启用它提醒才可靠（位置在「设置 → 声音与通知 → 高级设置」）；
4. 需要「响铃到你处理为止」的话，再开「持续提醒」，否则提醒只是响一声的普通通知。

上面这些都是开关层面的设置，与会员无关。顺带一提，免费版的提醒数量有总量上限（会员页口径为 2 个），高级会员为 5 个 —— 如果你发现「有些任务根本设不上提醒」，那是配额到了，不是故障，区别见[免费版和高级会员区别.md](免费版和高级会员区别.md)。

## 三、第二层：别让系统在后台杀掉它

国产 ROM 的电池管理是重灾区。官方为安卓专门做了一份各品牌保活指引（`ticktick.com/public/android-reminder/`），思路一致：**自启动放行 + 后台不限制 + 最近任务里锁定**。以华为为例的四项设置：

1. 「手机加速 → 设置 → 受保护应用」：允许 TickTick 在熄屏后继续运行；
2. 「启动管理」：允许 TickTick 开机自启动；
3. 「省电」模式选「普通」，不要用「超级省电」；
4. 在多任务（最近任务）界面里把 TickTick 上锁 —— 官方特别标注这步不做提醒就不响。

其他品牌同理，在「电池 → 应用耗电管理 / 后台限制」里把 TickTick 设成「不限制」或「无限制」，并在「自启动」里放行。菜单名字各厂不同，但找「电池」「自启动」「应用启动管理」这三个词能覆盖绝大多数机型。

## 四、第三层：一锤定音的 2 分钟测试

改完设置不用等到明天，自己造一条任务验证：

1. 新建一条任务，提醒时间设为 **2 分钟后**；
2. **锁屏、把应用退到后台**，不要停在 TickTick 界面里等；
3. 到点看通知栏：
   - 准时响 → 之前的设置已生效，收工；
   - 一打开应用就「补发」了刚才的提醒 → 说明后台还是被杀着，回到第三层继续放行；
   - 压根没有这条提醒 → 回到第二层，重点看响铃模式与系统通知设置。

每次只改一层再测，这样能知道是哪一项起了作用，不然改了五处还是不响，你不知道该保留哪处。

## 五、提醒响了但你觉得太轻/太重

- **换铃声**：「设置 → 声音与通知 → 提醒铃声」里选；打开「按优先级使用提醒铃声」后，不同优先级的任务到点用不同铃声，不亮屏也能听出轻重缓急。
- **多时间点提醒**：一条任务可以设多个提醒，也可以勾「结束时」提醒 —— 适合有起止时间的会议类任务。
- **每日提醒**：在「设置」里开启并定个时间，每天固定提醒你规划当天任务，属于另一类「例行提醒」，和单条任务的提醒互不影响。
- **邮件提醒**：在网页端「头像 → 设置 → 提醒与通知」里开，作为手机通知之外的兜底渠道。
