## 一、这是一款什么应用

Kanade 是一个第三方网易云音乐客户端（开发者 rcmiku，源码发布在 GitHub），作用和网易云音乐 App 一样是听歌，但安装包只有约 4M，界面里没有直播、商城、动态这类额外内容。官方仓库标注了「仅供学习交流使用」。

它不是网易云音乐官方出品，登录时用的也是你自己的网易云账号；与官方 App 的逐项对照见 [与网易云音乐官方 App 的区别.md](与网易云音乐官方 App 的区别.md)。

## 二、装之前先核对这几项

本文档配套的安装包信息如下（网上搜到的可能是更高版本）：

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.3（官方 2025-09-16 发布） |
| 包名 | `com.rcmiku.kanade` |
| 安装包大小 | 3.79M |
| MD5 | `8BAD80E906FF62459814CA280E940C1F` |
| 系统要求 | Android 5.0 以上（收录记录标注为 5.2 以上，以实际安装提示为准） |

如果你希望用上 1.3 之后的新功能（播客、逐字歌词等），可以到官方 GitHub 仓库 [github.com/rcmiku/Kanade](https://github.com/rcmiku/Kanade) 看更高版本的发布页；不过该仓库 2026 年 5 月已归档，不再有后续更新。各版本改了什么见 [版本历史与更新说明.md](版本历史与更新说明.md)。

## 三、获取安装文件

从上文网盘链接进入后，把里面的 `kanade_v1.3.apk` 转存或下载到手机。网盘的用法：

1. 夸克网盘分享页支持直接下载单个文件；
2. 也可以先「保存到我的网盘」，再在夸克 App 里取回本地；
3. 下载完成后核对一下文件大小是否在 3.8M 上下，明显偏小说明没下完整。

想核对 MD5 的话，把 apk 传到电脑后用 PowerShell 执行：

```powershell
Get-FileHash "kanade_v1.3.apk" -Algorithm MD5
```

结果与上表一致（不区分大小写）就是原包。

## 四、安装步骤

1. 点开下载好的 apk，系统弹出「是否允许安装」时选允许；
2. 如果提示「禁止安装未知来源应用」，按手机指引跳到系统设置，给浏览器或文件管理器勾选「允许安装未知应用」，返回后重试；
3. 部分国产系统（MIUI、HarmonyOS 等）会额外弹一次「风险应用」确认，属于第三方应用的常规提示，确认继续即可；
4. 装完桌面会出现 Kanade 图标，首次打开会请求存储、网络等权限。

## 五、装不上时的几个常见原因

- **解析包错误**：安装包没下完整，重新下载一遍；
- **签名冲突**：手机里装过别的 Kanade 来源的包（不同签名），先卸载旧的再装；
- **系统版本过低**：Android 5.0 以下的设备装不上；
- 其他安装之外的运行问题，见 [常见问题解答.md](常见问题解答.md)。
