## 一、一句话定位

两个都是「登网易云账号听歌」的安卓应用：官方 App 是平台自己的全功能客户端，Kanade 是独立开发者做的第三方客户端，只保留听歌这条路径。

## 二、逐项对照

| 对照项 | Kanade（网盘收录 1.3 版） | 网易云音乐官方 App |
| --- | --- | --- |
| 安装包体积 | 3.79M | 通常为一两百 MB 量级（以应用商店当时显示为准） |
| 获取渠道 | GitHub Releases / 网盘 apk，需手动允许安装 | 应用商店直接装 |
| 界面内容 | 搜索、播放、歌词、歌单等听歌功能 | 听歌之外还有直播、社区、商城等板块 |
| 账号 | 同一个网易云账号，歌单与收藏数据互通 | 原生账号体系 |
| 可听范围 | 与同账号在官方 App 里一致 | 按版权与会员规则 |
| 更新维护 | 2026-05-06 归档，停在 2.3 版 | 持续更新 |

两点说明：

- **体积差一个数量级**：3.79M 对一两百 MB，是「只做播放器」和「全功能平台客户端」最直观的差别，存储紧张的设备上这个差距是实际存在的；
- **数据互通**：Kanade 走网易云的账号接口，登录同一账号后，在官方 App 收藏的歌单在 Kanade 里能看到，反之亦然——所以两者可以并存，按场景换着用，不存在二选一的迁移成本。

## 三、第三方客户端的固有短板

用 Kanade 之前要知道它比官方 App 多承担什么风险：

- **接口失效没人修**：它依赖网易云的接口工作，官方接口一变就可能整体不可用；官方仓库已归档，不会再有修复版本（时间线见 [版本历史与更新说明.md](版本历史与更新说明.md)）；
- **没有客服与保障**：登录、播放出问题时没有官方渠道可求助，只能靠社区与文档；
- **功能更新停了**：官方 App 每周都在变，Kanade 的功能清单定格在 2.3 版。

## 四、什么情况下它对你是可选项

以下都是事实层面的对应关系，自己权衡：

- 设备存储所剩无几，且只用「搜歌—播放—看歌词」这条最小路径；
- 只想要一个干净的播放界面，不点开直播与社区板块；
- 手里已有网易云账号，不想再多注册任何东西——它直接复用你的账号。

反之，依赖评论区、直播、歌房这类社区功能，或希望应用持续有人维护，官方 App 是唯一选择。播放受限类问题的成因单独成篇，见 [歌曲变灰与播放失败的原因.md](歌曲变灰与播放失败的原因.md)。
