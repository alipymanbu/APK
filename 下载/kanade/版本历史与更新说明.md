## 二、网盘收录版是 1.3，意味着什么

网盘收录的安装包是 1.3 版（2025-09-16 发布，3.79M，MD5 `8BAD80E906FF62459814CA280E940C1F`）。对照上表：

- 听歌、搜索、歌词、歌单这些核心功能在 1.3 里都是完整的；
- 1.3 **没有**：状态栏歌词（1.5）、播客（1.7）、按标签浏览歌单（1.9）、逐字歌词动画（2.0）、专门的缓存清理入口（2.3）；
- 设置里找不到某项功能时，先对照上表确认是不是版本差异，而不是应用出了问题，可参考 [常见问题解答.md](常见问题解答.md)。

## 三、仓库已归档，后续不会再更新

2026-05-06 发布 2.3 当天，官方仓库被归档为只读状态。这意味着：

- 不会再有新版本，GitHub Releases 页面拿到的最新版就是 2.3；
- 网易云官方接口一旦变动，第三方客户端大概率会失效且**不会有官方修复**——这是所有第三方客户端的共同风险，遇到整体不可用时只能另寻替代（与官方 App 的完整对照见 [与网易云音乐官方 App 的区别.md](与网易云音乐官方 App 的区别.md)）；
- 高版本 apk 只在官方 GitHub 的 Releases 页发布过，配套网盘仅收录 1.3 版。

## 四、要不要追新版

- 只想轻量听歌：1.3 够用，且体积最小；
- 想要逐字歌词、播客：1.3 满足不了，只能去官方仓库找 2.x 版本，装法与 1.3 相同（见 [登录与使用入门.md](登录与使用入门.md) 的使用部分）；
- 两个版本签名一致时可以直接覆盖安装，不必先卸载；装不上再按 [下载与安装教程.md](下载与安装教程.md) 的排错思路处理。
