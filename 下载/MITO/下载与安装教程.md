## 一、先核对版本再动手

MITO 是一款影视聚合类应用，收录电影、电视剧、综艺、动漫、纪录片等类型的内容，界面按类型做了分类导航。网盘里发出去的是下面这一版，涉及版本号、大小、包名都以这份为准：

| 项目 | 数值 |
| --- | --- |
| 版本号 | 2.2.0 |
| 包名 | com.yslkjgs.azmzwtds |
| 安装包大小 | 25.50 MB |
| MD5 | EDE5D9FF613E547D1CE48996E94CCB6C |
| 信息核对时间 | 2026-09-23 |

两点背景说明：

- 公开渠道显示，这款应用此前曾以「热剧猫」的名字发行过早期版本，你搜资料时两个名字都可能撞到，属于同一系应用。
- 系统要求方面，本地记录标注为「安卓 5.2 及以上」，实际安装时以系统弹出的提示为准。

网上能搜到的介绍通常写的是官方最新版本号，与网盘里这份不一定相同。装完后想核对版本，在系统「设置 → 应用管理 → MITO」或应用内「关于」页面能看到具体版本号。

## 二、安装包从哪拿

安装包通过网盘分发，入口是 [MITO 安装文件资源（夸克网盘）](https://pan.quark.cn/s/384ad593d816)。完整步骤：

1. 打开上面的网盘链接，把 APK 文件转存到自己的网盘，再从网盘下载到手机（夸克的分享内容需要先转存才能下载）。
2. 下载完成后，在手机通知栏或网盘 App 的传输列表里点开这个 APK 文件。
3. 系统会提示「是否允许安装来自此来源的应用」，选择允许，然后点「安装」。
4. 等待安装完成，桌面出现 MITO 图标即装好了。

如果你对文件完整性有要求，可以在电脑或手机上用校验工具算一下 APK 的 MD5，与上面表格里的值核对，一致说明文件没有损坏。

## 三、安装被拦截或装不上

按现象对号入座：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 安全软件提示「存在风险」，安装被拦 | 这类影视聚合应用常被手机管家类软件拦截，有用户反馈多属误报 | 自行判断是否继续；确认要装就允许安装或暂时关闭拦截 |
| 提示「解析包错误」 | APK 下载不完整或文件损坏 | 删掉重下，核对大小是否为 25.50 MB、MD5 是否一致 |
| 提示系统版本过低 | 安卓版本低于要求 | 升级系统或换设备；具体门槛以安装时系统提示为准 |
| 提示「应用未安装」/ 与现有应用冲突 | 手机里装过同包名的其他来源版本，签名不同会覆盖失败 | 先卸载旧版本再装这份 |
| 下载到一半中断 | 网盘传输不稳 | 回网盘重新转存下载，装前先核对大小 |

安装成功后如果打不开或闪退，去看[卡顿与播放失败排查.md](卡顿与播放失败排查.md)；想直接上手找片，去[找片与播放技巧.md](找片与播放技巧.md)。
