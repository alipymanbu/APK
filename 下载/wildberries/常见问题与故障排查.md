# Wildberries 常见问题与故障排查

> 打不开页面、收不到验证码、付不了款、通知太多或收不到 —— 这些都是实际用起来高频撞到的问题，本篇按「先试什么、再试什么」给排查顺序。

## 一、应用打不开、商品页一直转圈

按命中率从高到低试：

1. **先关掉 VPN 再试**。公开资料显示，自 2026 年 4 月中旬起，俄罗斯境内服务会过滤来自境外 IP 与数据中心的流量：挂代理时的典型表现是商品页、购物车、结算页加载不出来，或直接报 403/拒绝访问。关掉后重启应用能恢复，就说明是这条路 —— 想两者同时用，得在代理客户端里给 Wildberries 做分流（让它走直连），应用内不用改任何设置。
2. **换网络**：Wi-Fi 切流量，或换个热点，排除本地网络问题。
3. **清缓存**：手机「设置 → 应用 → Wildberries → 存储 → 清除缓存」。清缓存不会退出账号，比卸载安全。
4. **看是不是平台自己在故障**：以上都试过仍不行、且同一时间很多人都反映有问题，那就是服务端的事，等一段时间再打开即可。

## 二、登录收不到验证码

- 核对**区号与号码**是否选对、输错一位都收不到。
- 信号弱时换到信号好的地方重试；开了 Wi-Fi Calling 的号码注意验证码可能走的是另一条通道。
- 提示「号码已注册」但你不记得：别重复注册，直接用该号收验证码登录即可找回账号（见[注册登录与账号设置.md](注册登录与账号设置.md)）。
- 等待倒计时结束后再点一次，别连续狂点 —— 短时间多次请求反而会被拖慢。

## 三、支付失败

| 症状 | 先查什么 |
| --- | --- |
| 卡被拒绝 | 卡是否开通了网上支付、是否过期、额度是否够；部分银行会拦境外或大额交易，换张卡或换银行 App 里确认一下 |
| 结算页根本没有这个支付方式 | 页面列出的就是你可用的全部，换一种（СБП、WB 钱包），见[下单购买与支付方式.md](下单购买与支付方式.md)第三节 |
| WB 钱包提示余额不足 | 用 СБП 充值，或本次改用其他方式，见[WB钱包余额与优惠使用说明.md](WB钱包余额与优惠使用说明.md) |
| 付完款订单没出现 | 先别重复付款，回订单列表刷新看状态；确实没有再联系客服，报订单号 |

## 四、收不到订单通知 / 促销通知太多

两层开关都要看，只改一层往往没效果：

1. **应用内**：个人中心 → 设置 → 通知（Push）→ 按类别开关。**订单状态建议留着**，促销、推荐这两类可以关。
2. **系统层**：手机「设置 → 应用 → Wildberries → 通知」，允许总开关打开。
3. **小米、华为等机型额外一步**：在系统的省电/应用管理里放开该应用的**自启动、后台运行、省电策略（不限制）**，否则推送会被系统在后台杀掉 —— 这是「订单到了手机没响」最常见的原因。

关掉的开关只影响之后的新通知，历史消息仍留在通知列表里。

## 五、安装失败、提示签名冲突

- 手机上已装了另一来源的同包名版本（包名同为 `com.wildberries.ru`）而两者签名不同时，系统会拒绝覆盖。**先卸载旧的再装**；卸载会清掉本地缓存与登录态，账号数据在云端，装回后用手机号收验证码重新登录即可。
- 提示空间不足：清出 1 GB 以上可用空间再装（安装前核对与步骤见[下载与安装教程.md](下载与安装教程.md)）。
- 装完界面与官方商店截图不符：回头核对包名与 MD5，文件与描述不符就不要继续用它。

## 六、找不到取货码、订单对不上

取货码、订单号、追踪号三者用途不同，在订单页各看各的位置，对照表见[订单取货与退货退款流程.md](订单取货与退货退款流程.md)第一节；取货码每天 00:00 更新，重新打开订单页刷新一次通常就有了。

## 七、找客服

- **应用内**：个人中心 → **Обращения**（请求/反馈），可文字描述并附订单号。
- **官网**：[www.wildberries.ru](https://www.wildberries.ru/) 页脚的 Контакты 入口。
- 描述问题时报**订单号**，并附上出问题那一步的截图，能省掉一轮来回。
