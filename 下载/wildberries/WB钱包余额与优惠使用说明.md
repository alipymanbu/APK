# WB钱包余额与优惠使用说明

> WB 钱包（WB Кошелёк）是挂在你 Wildberries 账号下的余额账户：付钱有折扣，但充值、提现、额度都分状态；本篇讲清怎么开、怎么充、怎么省。

## 一、它是什么、能干什么

WB 钱包是 Wildberries 体系内的电子余额账户，运营方为该生态的持牌机构（公开资料标注为 WB 生态银行，即 ООО «Вайлдберриз Банк»）。它只在 Wildberries 买单时用得上：结算时选它直付，余额不够再从其他方式补。**它不是银行卡**，不能拿到别家商户消费，也不能绑卡充值（见第三节）。

它对你的实际价值有两个：**付款打折**（第四节）和**退款落点**（退货的钱可能回到这里，可直接用于下一笔）。

## 二、两种状态的额度差别

钱包分「匿名」与「实名（通过 Госуслуги 政务门户验证）」两种状态，额度差一大截：

| 项目 | 匿名钱包 | 实名钱包 |
| --- | --- | --- |
| 余额上限 | 15,000 ₽ | 60,000 ₽ |
| 每月支出上限 | 40,000 ₽ | 200,000 ₽ |
| 提现到自己 | 不可提现 | 单笔至多 60,000 ₽、每月至多 200,000 ₽ |
| 转给他人 | 不可 | 单笔至多 10,000 ₽ |
| 开通方式 | 结算页选钱包即开，只需手机号 | 需完成身份验证 |

以上为 2026 年公开资料口径，**具体限额以应用内余额页当时显示为准**。

## 三、开通与充值

1. **开通**：结算时在「Способ оплаты」里选 WB 钱包，按提示确认即可开通匿名状态；升级实名走余额页的验证入口（需通过 Госуслуги）。
2. **充值**：只能通过 **СБП**（俄罗斯快速支付系统）按手机号转账/扫码充值，实时到账、银行侧不收手续费。
3. **不能做的事**：不支持直接从银行卡扣款充值，也不支持把卡绑定到钱包上 —— 想让钱包有钱，走 СБП 这一条。

## 四、付款折扣怎么拿

用钱包付款时结算页会显示一笔折扣，公开资料口径为 **2%~7%**，比例与你的实名等级及是否订阅会员有关；**结算页上写多少就是多少**，以页面显示为准。想吃到折扣，动作只有一个：结算时把支付方式切成 WB 钱包。

## 五、提现

- **匿名状态提不了现**，余额只能用于下单一笔笔花掉；要提现先做实名验证。
- 实名后在**个人中心 → 余额（Баланс）**里发起转账/提现，走 СБП 到你本人手机号对应的账户（第三方资料口径，以页面实际入口为准）。

## 六、余额相关的问题

| 现象 | 怎么处理 |
| --- | --- |
| 退货的钱没回到卡上 | 可能退回了钱包余额，去余额页的交易记录里核对；可用于下一笔订单 |
| 支付时提示余额不足 | 用 СБП 先充值，或本次换其他支付方式 |
| 余额对不上 | 先看交易记录逐笔核对；仍有疑问走应用内个人中心 → **Обращения**（反馈/请求）找客服，报订单号（对照[订单取货与退货退款流程.md](订单取货与退货退款流程.md)第一节） |
| 余额页打不开、一直加载 | 多半是网络或代理问题，排查见[常见问题与故障排查.md](常见问题与故障排查.md) |
