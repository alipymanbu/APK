# Wildberries 下单购买与支付方式

> 从挑商品到付完款，Wildberries 的下单流程一共五步，卡点几乎都在支付方式上；本篇把每一步和可选的付款方式讲清。

## 一、挑商品时看四样

商品页（карточка товара）是你做决定的地方，卖家自己填的内容，重点看：

1. **价格与折扣**：划掉的原价与现价、折扣百分比，活动价常标注截止日期。
2. **评分与评价**：评分、评价条数，点进去看带图评价更准。
3. **卖家是谁**：同一款商品可能有多个卖家，价格与发货速度不同。
4. **退货标注**：商品页底部标了退货期限的，一般支持无理由退；没标的多半不可无理由退（详见[订单取货与退货退款流程.md](订单取货与退货退款流程.md)）。

## 二、下单五步

1. 选好尺码/规格 → **В корзину**（加入购物车）或直接买。
2. 进购物车确认数量，点结算。
3. **选配送方式**：自提点（ПВЗ，地图上就近选）或送到家的快递。
4. **选支付方式**（见第三节）。
5. 付款成功后，订单出现在**个人中心 → 订单（Заказы）**里，状态会实时往前走；到件会有推送（前提是你放行了通知权限）。

## 三、支付方式对照

结算页「Способ оплаты」里列出的选项就是你当前可用的全部，下面是这些选项各自的适用条件：

| 方式 | 怎么用 | 适用条件与注意 |
| --- | --- | --- |
| 银行卡在线支付 | 结算页填卡或选已存的卡 | 卡要开通网上支付且在有效期内；卡组织是否被接受以结算页列出的图标为准 |
| СБП（俄罗斯快速支付系统） | 扫码或跳转到银行 App 确认 | 需要你的银行支持 СБП |
| Mir Pay | 支持 Mir 卡的安卓手机用 NFC 唤起支付 | 仅限 Mir 卡与支持的银行，境外发行的卡用不了 |
| WB 钱包（WB Кошелёк） | 用账户余额直付，享折扣 | 余额不足要先充值；折扣与限额见[WB钱包余额与优惠使用说明.md](WB钱包余额与优惠使用说明.md) |
| 取货时付款 | 收到货再付 | 部分订单才提供这个选项，有没有由结算页决定 |

**你的卡到底能不能用，以结算页当场列出的选项为准** —— 页面没给的入口，说明这笔订单不支持它。支付失败的排查顺序见[常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、运费与配送范围

- 送到**自提点**通常免运费；偏远地区、加急、大件家具等可能产生费用，结算页会把最终金额算给你看，确认后再付。
- 配送时效在结算时按你选的自提点/地址给出预计日期，订单页会更新实际进度。
- Wildberries 的配送以其覆盖国家境内为主（俄罗斯站配送俄罗斯境内地址）；收货地址能不能选，以结算页地图上能否选到自提点为准。

## 五、订单状态怎么读

| 状态含义 | 你会看到什么 |
| --- | --- |
| 已下单待发 | 订单出现在列表里，等待卖家发货 |
| 运输中 | 显示物流进度与预计到达日 |
| 已到达可取 | 有取货码/二维码，去自提点报码取件 |
| 已完成 | 已取货且过了确认期 |

取货码、订单号、追踪号各是干什么的，别搞混 —— 见[订单取货与退货退款流程.md](订单取货与退货退款流程.md)第一节的对照表。
