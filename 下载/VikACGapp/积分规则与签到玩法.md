## 一、积分能用来做什么

社区里部分内容会由作者设置成「支付积分可查看」，你查看这类内容要花自己的积分；反过来，你发布的文章也可以设置这个门槛，别人支付时积分到你的账上。签到与互动攒分，本质上是让你有余额去看这类内容、也激励你自己发内容。

积分规则由站方制定，具体数值可能随版本与公告调整，下表是站方此前公布的标准，以你 App 内看到的最新说明为准。

## 二、积分来源一览

| 行为 | 积分变化 |
| --- | --- |
| 新人注册 | 初始 400 分 |
| 每日签到 | 500 ~ 2000 |
| 发表文章 | +1000 / 篇 |
| 发布圈子贴（点子） | +50 / 条 |
| 关注别人或被关注 | +60 / 次 |
| 内容（文章、点子）被点赞 | +50 / 次 |
| 内容被评论 | +10 / 次 |
| 评论被点赞 | +10 / 次 |

从表里能看出节奏：签到是每天稳定的进项，发文章是单次收益最高的一项，圈子贴适合日常随手发，互动（关注、被点赞）是细水长流。

## 三、每日签到在哪

1. 打开 App 进入首页；
2. 在首页找到签到入口（通常在首页的显眼位置）；
3. 点签到，即可领取当天的积分（500~2000 之间浮动）。

签到的位置与形式可能随版本调整，找不到时在首页顶部或「我的」附近找一圈，或看站内公告。

## 四、怎么自然涨分

- **每天先签到**：这是不用动脑的固定收入；
- **有内容可写就发文章**：一篇 +1000，比刷十条例子都划算；只是随手记录就用圈子贴，一条 +50；
- **多互动**：认真评论别人的内容，被点赞、被回复都有加分，还能涨关注；
- **别刷分**：站方明确不鼓励水评论、刷分这类行为，违规可能得不偿失；高质量互动才是稳定的涨分方式。

## 五、给自己发布的内容设「支付积分可查看」

发文章时可以选择设置支付积分门槛：别人要支付对应积分才能查看，这些积分会到你的账户。两点站方提醒值得留意：

- 不建议对普通内容设置高额门槛，读者用脚投票，设太高反而没人看；
- 站方不鼓励把「付积分看内容」用在非优质作品上，把门槛留给真正花了功夫的内容。

## 六、积分没到账或数值对不上

先确认这几点：签到入口是不是当天已签过；发帖时间与加分时间可能有延迟；站方调整规则后，旧数值会失效。仍对不上时，通过站内反馈渠道或官方邮箱 `support@vikacg.com` 反馈你的账号与情况。其他常见问题见 [常见问题与注意事项.md](常见问题与注意事项.md)，发帖相关操作见 [社区板块与发帖入门.md](社区板块与发帖入门.md)。
