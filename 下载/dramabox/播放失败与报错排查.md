## 一、先走通用五步

大多数「看不了」用这五步就能解决，按顺序来：

1. 确认网络正常（浏览器随便开个网页试试）；
2. 彻底关掉 DramaBox 再打开——从后台任务里划掉，不是退回桌面；
3. 系统设置 → 应用 → DramaBox → 清除缓存；
4. 检查有没有新版本，商店里点更新；
5. 重启手机再试。

## 二、报错信息对照表

社区里报得比较多的几种（叫法以你的界面实际显示为准）：

| 报错字样 / 现象 | 多半是什么 | 先做什么 |
| --- | --- | --- |
| anomali data / data exception | 缓存脏数据或网络波动 | 清缓存 → 切网络（Wi-Fi 与流量互换）→ 重启应用 |
| network issue | 网络不通或被限速 | 换个网络环境再试 |
| 一直转圈不出画面 | 加载超时 | 换一集点开测试，再走通用五步 |

看广告解锁时转圈、看完也没拿到奖励，多数是当日次数到顶或广告加载失败，规则与处理见[免费看剧途径与签到任务.md](免费看剧途径与签到任务.md)。

## 三、清缓存和清数据的区别

- **清除缓存**：只删临时文件，追剧记录、金币余额都在；
- **清除数据**：等于恢复出厂，本地记录清空，重新打开就是全新状态。

所以先清缓存，走投无路再清数据。清数据前确认你登录过账号（见[登录方式与账号管理.md](登录方式与账号管理.md)）——登录过的账号记录在云端，清完登录回来还在；没登录过就先忍住别清。

## 四、只有某一部剧看不了

别的剧正常、只有这一部打不开或提示不可用，多半是那部剧在你的地区没有版权授权——内容目录本来就是按地区分的，同一部剧在这个区能看、那个区看不了很正常。你这端做什么都没用，等官方调整或换别的剧。

## 五、都不行就重装

卸载重装是最后一招。卸载前确认已登录（理由同第三节），重装的包从官方渠道拿（见[下载与安装教程.md](下载与安装教程.md)）。装完还不行，走应用内或官方支持页的客服入口反馈，把手机型号、系统版本、报错截图一起给，处理得比文字描述快得多。
