## 一、装之前先核对三件事

1. **手机系统版本**：本文对应的安装包要求 Android 5.2 及以上。较新的官方版本（如 1.6.x）要求 Android 7.1 以上，版本越新门槛越高，详见[更新日志与版本区别.md](更新日志与版本区别.md)。
2. **剩余存储空间**：安装包本体约 45.82M，安装后加上缓存与对话记录，建议至少留出 200M 空闲空间。
3. **来源与文件完整性**：从网盘拿到安装包后，先确认文件名以 `.apk` 结尾、大小在 45M 上下。如果文件明显偏小（比如只有几 MB），多半是没下完，重新下载再装。

本篇对应安装包的本地信息：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.2.8 |
| 包名 | com.aichatbot.mateai |
| 大小 | 45.82M |
| MD5 | 429298A8722023174F34AB79235E3652 |
| 系统要求 | Android 5.2 及以上 |

较真的话可以顺手验一下 MD5，和表里的值对得上就说明文件在传输中没有损坏：

- **Windows**：打开 PowerShell 或命令提示符，执行 `certutil -hashfile "APK文件完整路径" MD5`，输出的第二行就是校验值（字母大小写不同不算差异）；
- **安卓**：部分文件管理器（如 MT 管理器、文件大师类工具）自带「校验 / 属性」功能，长按 APK 文件即可看到 MD5。

对不上就删掉重下，不用怀疑别的。

## 二、从网盘把安装包拿到手机

1. 点开上面的 **MateAI 安装文件资源（夸克网盘）** 链接；
2. 登录夸克账号后先「转存」到自己的网盘，再从网盘里把 APK 文件下载到手机本地的「下载（Download）」目录；
3. 下载完成后，在手机通知栏或文件管理器里确认文件已完整落地（大小约 45.82M）。

如果你更习惯用官方渠道，也可以直接从 Google Play 搜索安装：[play.google.com/store/apps/details?id=com.aichatbot.mateai](https://play.google.com/store/apps/details?id=com.aichatbot.mateai)。注意官方渠道装到的是当时的最新版，体积、系统要求与功能都和网盘里这份 1.2.8 不一样。

## 三、允许安装「未知来源」应用

从网盘下载的 APK 不经过应用商店，安卓默认会拦一下，你需要给「文件管理器」或浏览器放行：

| 品牌 | 入口（大致路径，以系统实际显示为准） |
| --- | --- |
| 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / vivo | 设置 → 安全 → 安装未知应用（或在安装弹窗里直接点「仍要安装」） |
| 三星 | 设置 → 生物识别和安全性 → 安装未知应用程序 |
| 原生 Android | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

建议只给「文件管理器」这一个应用放行，装完再把开关关回去。

## 四、安装与首次打开

1. 在文件管理器里点开下载好的 APK，确认弹窗里的包名为 `com.aichatbot.mateai` 后点「安装」；
2. 安装完成后点「打开」。第一次启动会让你**选语言**，按需要选即可；
3. 进入主界面后，如果 App 要求注册或登录，按界面提示用邮箱或手机号完成即可，具体流程以 App 内实际显示为准；
4. 进到对话界面就能开始使用了，具体玩法见[怎么用.md](怎么用.md)。

## 五、装不上时先看这几条

- **提示「解析包出现问题 / There was a problem parsing the package」**：多半是安装包没下载完整，或者文件在传输中被改名截断。删掉重新下载一次再装。
- **提示系统版本过低**：这份 1.2.8 要求 Android 5.2 以上，如果你的系统达不到，只能换官方渠道的新版（要求反而更高，Android 7.1+），老设备可能两头都装不了。
- **提示存储空间不足**：清出空间再装。
- **安装卡在某一进度**：重启手机后重试；仍失败就重新下载安装包。

以上都排除了还装不上，去[常见问题解答.md](常见问题解答.md)对一遍其他可能。
