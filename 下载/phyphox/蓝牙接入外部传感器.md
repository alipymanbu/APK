## 一、外接能补什么

手机里没有的量——温度、外部距离、力、气压对比——都可以由外接设备提供，phyphox 从 1.1.0 版起支持外部设备（本篇对应的安装包是 1.2.0-beta2，已包含），安卓与 iPhone 都能用。前提只有一条：设备走 **BLE（蓝牙低功耗）** 通信。

## 二、扫描前先确认设备是 BLE

最容易踩的坑：设备明明叫"蓝牙 4.0"，却扫不出来。蓝牙 4.0 包含经典蓝牙和 BLE 两套协议，phyphox 只认 **BLE**。经典蓝牙设备（多数老式音箱、SPP 串口模块）无论怎么扫都不会出现——买模块时认准 "Bluetooth Low Energy / BLE / Bluetooth Smart" 字样。

## 三、扫描：白名单与灰名单

主界面右上角「+」里选扫描蓝牙设备，范围内的 BLE 设备都会列出：

- **白色条目**：phyphox 直接支持——选中后应用会给出一个或多个配套实验，选一个就能直接看数据；
- **灰色条目**：暂无直接支持——不代表不能用，而是需要一个"配置文件"告诉 phyphox 怎么跟它对话（见下一节）。

给系统授权时放行「附近设备 / 蓝牙」权限，否则扫描列表一直是空的（权限对照见[下载与安装教程.md](下载与安装教程.md)第五节）。

## 四、灰色设备靠配置文件点亮

配置文件就是`.phyphox` 格式的实验配置，只是里面额外定义了蓝牙通信细节。加载方式与普通自定义实验一样（扫二维码 / 打开文件 / 输入网址），区别在于这个配置会**自己发起蓝牙扫描**，不用你再从主菜单扫。加载时应用会问要不要存进实验列表，选是，以后一次点击直达。

去哪找配置：

- 官方 Wiki 的**蓝牙设备数据库**（`https://phyphox.org/wiki/index.php?title=Bluetooth_device_database`，英文）；
- 官方论坛（`https://phyphox.org/forums/`），很多用户把自己做的配置发在那里。

找不到现成配置？可以自己写一个——用官方编辑器（见[二维码加载自定义实验.md](二维码加载自定义实验.md)第四节）或文本编辑器直接按格式写，需要弄懂 GATT 这层概念，属于进阶操作。

## 五、自己的 Arduino / ESP32：几行代码的事

想自己做数据采集端，官方维护了 **phyphox BLE 库**：设备端只要在代码里启动 BLE 服务、把读数写进去，手机上扫描连接就能实时画出曲线，连图表配置都会自动传过去。

| 板子 | 情况 |
| --- | --- |
| ESP32 系列 | 自带 BLE，便宜且常用，官方示例用超声波测距传感器 HC-SR04 演示 |
| Arduino Nano 33 BLE / IoT / Sense | 原生 BLE，官方支持 |
| 老款 Arduino UNO 等 | 本身无 BLE，要另配支持 BLE 的扩展模块 |

用 MicroPython 写 ESP32 的也有对应的 `phyphoxBLE` 库（PyPI 上有，官方维护者发布）。动手材料：官方 Wiki 的 Arduino/ESP32 示例项目，搜索 "phyphox BLE Arduino" 即可到达。

一点提醒：你装的是 beta 版应用时，官方提示网页编辑器的新功能可能还没跟上 beta 的格式——配置文件加载报格式错误时，先怀疑这一条。

## 六、接上之后

外接设备的实验和内置实验长一样：播放、暂停、标签页、导出数据全部通用（操作见[传感器实验怎么用.md](传感器实验怎么用.md)）。缺硬件时的整体思路对照见[传感器缺失灰色排查.md](传感器缺失灰色排查.md)。
