## 一、inshow 是什么

inshow（官方中文名「映秀」）是一款由**北京犀尧科技有限公司**开发运营的安卓 / iOS 应用，定位是时尚穿搭、美妆学习与明星动态的内容社区。你在里面主要做三件事：刷博主更新、追明星动态、找穿搭与美妆灵感。

你在各大应用商店能搜到的版本与官网下载的是同一个应用，包名统一是 `com.xiyao.inshow` —— 安装前可以拿这个包名核对，避免装到同名的别的东西。

## 三、安卓安装步骤

1. 把 APK 文件下载到手机（或先下到电脑再传过去）。
2. 点开 APK，系统会提示「禁止安装来自此来源的应用」—— 这是安卓对**所有**侧载安装的统一拦截，不是这个包有问题。
3. 按提示进入「设置 → 允许安装未知应用」，给你用来点击安装的那个应用（文件管理器 / 浏览器 / 下载器）开权限，返回继续装。
4. 华为、荣耀等带「纯净模式」的机型还要额外关一次：设置 → 系统和更新 → 纯净模式 → 关闭。
5. 装完打开，首次会要你同意《用户协议》和《隐私政策》，点同意后才能进登录页。

**安装报错对照**：

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 解析包时出现问题 | 文件下了一半、不完整 | 重新下载，装前核对 MD5 |
| 应用未安装 | 手机上已有同包名不同签名的旧版 | 先卸载旧版再装（会丢应用内数据） |
| 应用未安装（版本降级） | 新版在机上，装的是旧版 | 先卸载再装旧版 |
| 存储空间不足 | 解压需要约 1.5~2 倍包体积的空余 | 清缓存腾空间再装 |

## 四、登录与注册

打开后走这几步：

1. 点「同意」接受协议政策 —— 不同意进不去，这是硬前置。
2. 用**手机号 + 短信验证码**注册 / 登录，这是最主要的方式。
3. 也可以用第三方账号（QQ、微信、微博）授权登录，授权时会读写一次剪贴板用于传递登录态。
4. 登录后按需要补全性别、生日、个人介绍 —— 这些是选填，不填也能用。

登录成功后建议顺手做三件事：去 **「我的 → 设置 → 通用设置」** 打开视频自动播放（或明确关掉）、去 **「我 → 设置 → 通知设置」** 决定要不要特别关注推送、给系统通知权限开个口子。三条的完整路径见 [浏览与消息设置怎么调.md](浏览与消息设置怎么调.md)。

收不到验证码、登录卡住的排查见 [常见问题与排查.md](常见问题与排查.md)。

## 五、版本与平台要求

- **iOS**：App Store 页面标注需要 iOS 13.0 或更高（iPhone / iPod touch），也支持装有 M1 及以上芯片的 Mac（macOS 11.0+）与 visionOS 1.0+。iOS 端包体约 117.2 MB，与安卓端不是同一个体积。
- **安卓**：官网只提供一个通用 APK 直链，没标最低系统版本；第三方页面给的说法不一致，以实际能否装上为准。
- **版本号**：安卓端各渠道常见 1.2.x 系列，iOS 端已到更高版本，两端版本号**不同步**，别拿 iOS 的版本号去对照安卓包。
