## 一、权限清单（官方口径）

官方《设备权限清单》里列了以下几项，装完首次用到对应功能时会弹窗向你要：

| 权限 | 平台 | 官方写的用途 |
| --- | --- | --- |
| 读取手机 / 电话状态（IMEI、IMSI、本机号码） | Android | 安全风控，防止账号被盗 |
| 读取 / 写入外置存储 | Android | 设置头像图片，保存 App 内部的图片及视频 |
| 摄像头 | Android | 拍照设置头像 |
| 读取系统日志 | Android | 跟踪崩溃日志，用于分析和改进 |
| 读取 / 写入相册 | iOS | 设置头像图片，保存 App 内的图片及视频 |
| 位置（GPS / 基站 / WLAN） | iOS | 安全保障，提供更精准和个性化的内容 |
| 设备唯一标识 | iOS | 标识设备，保障服务安全与浏览体验 |

清单里说明了这是「可能申请、使用」的权限，随版本升级会调整，**以你客户端里弹出的实际请求为准**。

**你实际会碰到的取舍**：

- 不给**存储 / 相册** → 换不了头像、存不了图，浏览本身不受影响。
- 不给**位置** → 内容推荐不做本地化，其他功能正常；想关可以直接在系统设置里单独关掉。
- 不给**通知**（系统通知权限，不在上表内）→ 特别关注的博主更新不会提醒你；App 内还有一层「特别关注推送」开关，两层的位置与判断顺序见 [浏览与消息设置怎么调.md](浏览与消息设置怎么调.md) 第二节，关注本身的操作在 [特别关注和评论查看方法.md](特别关注和评论查看方法.md)。
- **读取手机状态与系统日志**与风控、崩溃定位有关，拒绝后是否影响登录没有官方说明 —— 遇到登录异常时，可以先把这两项打开再试一次。

## 二、在哪关掉某项权限

安卓通用路径：**设置 → 应用 → 应用管理 → inshow → 权限**，逐项改成「允许 / 拒绝 / 仅在使用中允许」。各品牌菜单名略有差异（小米在「应用设置」，华为在「应用和服务」），找不到就用系统设置顶部的搜索框搜「权限」。

iOS：**设置 → 往下翻找到 inshow**，每个权限是一个开关。

关掉权限不会注销账号，只影响对应功能；系统已授予的权限也可以随时改回来。

## 三、它会收集哪些信息

官方《隐私政策》（更新时间 2022-12-31，生效 2023-01-01）里，收集范围大致是三类：

1. **你主动提供的**：手机号（注册登录必填）、性别、生日、个人介绍（选填），以及点赞、收藏、评论、搜索、分享这些操作产生的日志。
2. **设备与网络侧自动收集的**：IP 地址、设备型号、唯一设备识别码、操作系统与应用版本、网络类型与质量数据、访问过的页面与点击过的链接、崩溃日志。
3. **为推荐与广告做的画像**：基于浏览与搜索记录提取偏好特征，用于内容推送与广告展示。

经营者是**北京犀尧科技有限公司及其关联公司**，注册地址为北京市平谷区金海湖镇韩庄南大街 111 号。

## 四、接了哪些第三方 SDK

这些是隐私政策里点名的，也是你在别处看到「为什么它知道我装了什么」的常见来源：

| 类别 | SDK | 拿什么、干什么 |
| --- | --- | --- |
| 登录 / 分享 | QQ、微信、微博 | 设备标识、网络信息，用于第三方授权登录与内容分享 |
| 支付 | 微信支付（财付通） | 设备标识、MAC、WLAN 接入点，用于完成支付 |
| 广告 | 穿山甲、快手联盟、百度联盟 | 设备标识、网络状态、传感器、应用列表，用于广告投放与统计 |
| 推送 | 极光、友盟、小米 / 华为 / 荣耀 / OPPO / vivo 推送 | 设备标识、网络信息，用于消息推送 |
| 崩溃统计 | Bugly（腾讯） | 机型、系统版本、内存与磁盘占用、进程信息，用于定位崩溃 |

Apple 的隐私标签另标了：**标识符可能用于在其他公司的 App 和网站中追踪你**，并有用于第三方广告的设备 ID。

想减少被追踪：在 iOS 里可以关掉 App 的「允许跟踪」，安卓里可以重置广告标识符 —— 这两个是系统级开关，不依赖 inshow 自己给选项。

## 五、未成年人与账号注销

- 用户协议写明：**未满 18 周岁**（或民事行为能力不足）的人，要在法定监护人陪同、指导并同意后才能使用。
- 账号可以按客户端内的流程申请注销；注销前产生的行为责任仍由你承担，注销后账号内的内容与虚拟财产会被清空，**这一步不可逆**，操作前先确认没有需要保留的东西。

对 App 突然闪退、加载慢有疑问，多半和权限、网络有关，见 [常见问题与排查.md](常见问题与排查.md)；安装阶段的报错则看 [下载与安装教程.md](下载与安装教程.md)。
