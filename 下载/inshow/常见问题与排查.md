## 一、登录时一直收不到验证码

App Store 与应用商店的评论区都有用户反馈「一要验证码就不发」。按这个顺序排：

1. **看手机有没有拦截** —— 短信被垃圾信息拦掉是最常见的一种，去短信 App 的拦截 / 垃圾箱里翻。
2. **别连点「获取验证码」** —— 短时间内反复点会触发频控，反而更收不到；等 60 秒再点一次。
3. **查信号** —— 地下室、电梯里短信会延迟甚至丢失，换到信号好的地方重试。
4. **确认手机号没输错**，含区号或空格都会发偏。
5. **手机系统时间设成自动** —— 时间偏差大的设备，收到的码校验时会判过期。
6. 换网络（Wi-Fi ↔ 流量）重试一次，再不行就重启手机。
7. 仍不行：先用 QQ / 微信 / 微博第三方登录顶上（见 [下载与安装教程.md](下载与安装教程.md) 第四节），或过一段时间再试。

## 二、图片和视频加载特别慢 / 刷不出来

有用户在版本更新后集中反馈「图片视频刷新不出来、要等很久」。这是**客户端 + 网络**两侧都可能出的问题：

| 排查 | 具体做法 |
| --- | --- |
| 是不是全站慢 | 换 Wi-Fi 或流量对比；只在某一个网络下慢，就是网络侧 |
| 缓存脏了 | 设置 → 应用 → inshow → 存储 → **清除缓存**（别点「清除数据」，那会退出登录） |
| 后台被限制 | 电池优化把它设成「允许后台活动」，部分机型的省电策略会掐断图片请求 |
| 版本问题 | 当前版本更新后出现的，可以等下一次更新；急用就先退回你手里那个稳定版（见 [下载与安装教程.md](下载与安装教程.md) 第二节） |
| 空间不够 | 手机剩余存储低于 1 GB 时，图片解码缓存容易失败，先清空间 |

## 三、装不上、打开就闪退

- **装不上**：报错对照表在 [下载与安装教程.md](下载与安装教程.md) 第三节，多数是「未知来源」没开、包不完整、或和同包名旧版签名冲突。
- **打开就闪退**，按命中率从高到低试：
  1. 清缓存（不清数据）后重开；
  2. 后台全清、重启手机；
  3. 确认存储和内存都还有余量；
  4. 确认授予了存储 / 手机状态权限（见 [权限与隐私设置说明.md](权限与隐私设置说明.md) 第一节）；
  5. 系统刚升级过的话，等应用更新适配；
  6. 以上都试过 → 卸载重装（会丢应用内数据，账号本身不受影响）。

## 四、为什么我发不了内容、看不了直播

这是**设计如此**，不是你操作错了。公开的常见问题答复写明：inshow 当前不支持拍照、滤镜特效、发布作品，也**不支持看直播**；你刷到的内容并不是博主通过 inshow 发布的，而是从其他网络平台聚合同步过来的。

所以你在 inshow 里能做的就是**浏览、关注、加特别关注、看评论**这一套消费动作，别按社交平台的习惯去找发布按钮。评论区相关的操作见 [特别关注和评论查看方法.md](特别关注和评论查看方法.md)。

## 五、评论、翻译相关

| 现象 | 说明 |
| --- | --- |
| 评论区点不开 / 看不到评论 | 需要先把该博主加入**特别关注**，见 [特别关注和评论查看方法.md](特别关注和评论查看方法.md) |
| 翻译点不了 | 有用户反馈翻译功能需要会员，规则以客户端实际提示为准，档位见 [会员价格与充值方式.md](会员价格与充值方式.md) |
| 看不到我关注人的关注列表 | 部分用户反馈过同样情况，未见官方解释，先升级到最新版再看 |

## 六、扣了钱、会员没生效

先退出账号重新登录，等权益刷新；超过 24 小时仍未生效，按支付渠道申请核查（微信 95017、支付宝 95188、苹果 400-666-8800）。完整的充值与退款路径在 [会员价格与充值方式.md](会员价格与充值方式.md) 第四节，自动续费的关闭在同篇第五节。
