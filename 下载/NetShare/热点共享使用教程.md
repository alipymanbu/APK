## 一、先弄明白整体流程

整条链路是四步，缺一步第二台设备就上不了网：

1. 手机装好 NetShare（还没装的看 [下载与安装教程.md](下载与安装教程.md)）；
2. 打开应用，勾选 **Start Hotspot**，屏幕上会出现网络名（SSID）和密码；
3. 第二台设备的 Wi-Fi 列表里找到这个热点，输密码连上；
4. 在第二台设备上把 HTTP 代理指到手机屏幕上显示的地址。

第 4 步最容易漏。安卓系统不允许未 root 的应用直接转发网络流量，所以第二台设备的流量必须走代理才能出网——「连上热点」只是第一步，「配好代理」才算接通。这是这套用法和系统自带热点的最大区别。

代理地址默认 `192.168.49.1`，端口 `8282`；一切以应用屏幕上显示的为准。

## 二、在手机上开启共享

1. 打开 NetShare，勾选 **Start Hotspot**；
2. 屏幕上会列出三样东西：网络名、密码、代理地址（IP 与端口）；
3. 共享期间保持应用在后台运行，别从最近任务里划掉。系统省电策略把它杀掉，是「共享用着用着就断」的常见原因，排查见 [连不上与常见问题排查.md](连不上与常见问题排查.md)。

设备列表里找不到热点名时，注意有没有 **DIRECT-** 开头的条目——这个热点走 WiFi Direct 建立，名称不一定叫 NetShare，以实际显示为准。

如果手机当前还连着 Wi-Fi，开启共享后分出去的就是这条 Wi-Fi 的网络，而不是流量——这就是中继用法，见第五节。

## 三、各平台连接速查

第二台设备连上热点之后，按平台对号入座：

| 第二台设备 | 连上热点后要做什么 | 代理配置入口 |
| --- | --- | --- |
| Windows | 配代理，或用官方脚本加一个 VPN 连接 | 控制面板 → Internet 选项 → 连接 → 局域网设置 |
| macOS | 终端跑一条脚本，或手动配自动代理 | 系统设置 → 网络 → Wi-Fi → 详细信息 → 代理 |
| iPhone / iPad | 在该 Wi-Fi 的配置里手动填 HTTP 代理 | 设置 → Wi-Fi → 点开该网络 → HTTP 代理 → 手动 |
| 安卓（另一台手机/平板） | 也装一个 NetShare，打开后点 CONNECT（首次会请求 VPN 权限，允许即可） | 应用内完成，不用手动填代理 |
| Linux | 按桌面环境配系统代理，或设环境变量 | GNOME：设置 → 网络 → 网络代理 → 手动 |

三样默认值（以应用内显示为准）：

| 项目 | 默认值 |
| --- | --- |
| 代理地址 | `192.168.49.1` |
| 代理端口 | `8282` |
| 热点加密 | WPA2 |

Windows、macOS、Linux 的完整步骤与命令在 [电脑端连接教程.md](电脑端连接教程.md) 里逐平台展开；安卓当第二台设备最省事，装个应用点 CONNECT 就行。先给一个预期：浏览器、网页类用途没问题，但游戏、语音通话这类不走系统代理的应用多半连不上，原因与对策见 [游戏连不上怎么办.md](游戏连不上怎么办.md)。

## 四、中继模式：把已有 Wi-Fi 再分一份

手机先连上家里或办公室的 Wi-Fi，再开启共享。这时连上你热点的设备，用的还是原来那条 Wi-Fi 的网络，不消耗流量。其实没有单独的「中继开关」要开——分出去的是什么，取决于手机自己用什么上网：手机连 Wi-Fi 时分出去的是 Wi-Fi，用流量时分出去的是流量。

两种典型场景：

- 房间隔了几堵墙、Wi-Fi 信号弱，拿一台手机接力补一层覆盖；
- 平板、笔记本只有 Wi-Fi 没有网线可用，而手机有流量，直接流量共享。

## 五、连上了但没网、还想分 VPN

九成是代理没配对或端口填错，按 [连不上与常见问题排查.md](连不上与常见问题排查.md) 的症状表逐项核对。

手机端开着 VPN 还想把 VPN 一起分出去的，需要先在 VPN 应用里打开局域网访问开关，步骤见 [共享VPN连接的方法.md](共享VPN连接的方法.md)。
