> 本篇按平台给出电脑连上 NetShare 热点后的配置步骤：代理设置是通用方式，Windows 与 macOS 另有官方一键脚本。

## 一、开始前的三样核对

1. 手机端已勾选 **Start Hotspot**，热点名和密码显示在屏幕上；
2. 电脑已连上这个热点；
3. 记下手机屏幕上显示的代理地址与端口——默认 `192.168.49.1`，端口 `8282`。下文全部按默认值写，你屏幕上显示的不一样就换成屏幕上的。

Windows 与 macOS 各有两条路：代理配置（手动但通用）和官方脚本（一条命令，往系统里加一个连接）。先试代理方式，不奏效再上脚本。

## 二、Windows

### 方式一：手动配代理

1. 打开 控制面板 → 网络和 Internet → Internet 选项；
2. 切到「连接」选项卡，点右下角「局域网设置」；
3. 勾选「为 LAN 使用代理服务器」，填：
   - 地址：`192.168.49.1`
   - 端口：`8282`
4. 一路「确定」保存，开浏览器验证能不能打开网页。

### 方式二：官方 SSTP 脚本

1. 按 `Win + R`，输入 `cmd` 回车，打开命令提示符；
2. 粘贴运行：

```bat
curl http://192.168.49.1:8181/wbt -o w.bat & start w.bat
```

3. 脚本会往系统里加一个名为 NetShare 的 VPN 连接；
4. 点任务栏的网络图标，在 VPN 连接列表里选 NetShare，点「连接」。

## 三、macOS

### 方式一：终端脚本

1. `Command + 空格` 搜「终端」并打开；
2. 粘贴运行（提示输密码时，输你登录电脑用的那个）：

```bash
bash <(curl -s http://192.168.49.1:8181/msh)
```

### 方式二：手动配自动代理

1. 打开 系统设置 → 网络，选中 Wi-Fi，点已连上的 NetShare 热点旁边的「详细信息…」；
2. 切到「代理」标签，打开「自动代理配置」；
3. URL 填：`http://192.168.49.1:8282`
4. 点「好」，再点「应用」。

## 四、Linux

### GNOME（Ubuntu / Fedora / Pop!_OS 等）

1. 打开 设置 → 网络 → 网络代理 → 手动；
2. HTTP 代理填 `192.168.49.1`，端口 `8282`；
3. 桌面支持的话，HTTPS 代理填同一组，保存。

### KDE Plasma

1. 系统设置 → 网络 → 代理 → 手动配置；
2. HTTP 与 HTTPS 都填 `192.168.49.1`，端口 `8282`；
3. 点「应用」。

### 只给当前终端用

```bash
export http_proxy=http://192.168.49.1:8282
export https_proxy=http://192.168.49.1:8282
export HTTP_PROXY=http://192.168.49.1:8282
export HTTPS_PROXY=http://192.168.49.1:8282
```

验证：

```bash
echo $http_proxy
```

### 验证连通

配完任一平台，开浏览器随便打开一个网页；能开就通了。

## 五、浏览器能开，别的软件没网

系统代理只对「认系统代理」的程序生效。典型表现：浏览器正常，Steam、微信、终端里的包管理器却连不上。处理方式：

- 终端程序：把上面第四节的 `export` 几行跑一遍（要常驻就写进 `~/.bashrc`）；
- 图形软件：进它自己的设置找代理选项，填同一组地址和端口；
- 改完还不行的，按 [连不上与常见问题排查.md](连不上与常见问题排查.md) 的症状表再过一遍；
- 游戏、语音这类大概率救不回来——它们不走系统代理，属方式边界，判断依据见 [游戏连不上怎么办.md](游戏连不上怎么办.md)。
