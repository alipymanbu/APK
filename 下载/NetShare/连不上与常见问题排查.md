## 一、先核对三件最基本的事

症状是「连上热点但没网」时，先过这三条，多数到此就解决了：

1. 手机端 NetShare 在跑：Start Hotspot 勾着、应用没被从后台划掉；
2. 第二台设备连的是 NetShare 的热点，不是别的同名 Wi-Fi；
3. 代理已配置，地址和端口与手机屏幕上显示的一致（默认 `192.168.49.1`，端口 `8282`）。

三条都对还是不行，再按下一节的症状对表。

## 二、按症状对表

| 症状 | 先查什么 | 再查什么 |
| --- | --- | --- |
| 搜不到热点 | 手机端 Start Hotspot 是否勾上 | 热点名可能带 **DIRECT-** 前缀（走 WiFi Direct 建立），找这类条目；仍没有就重启两端 Wi-Fi 再看 |
| 连上热点但没网 | 代理没配或配错端口 | 地址端口是否照应用屏幕显示填的 |
| 浏览器能开，其他软件没网 | 那个软件不吃系统代理 | 电脑端处理见 [电脑端连接教程.md](电脑端连接教程.md) 第五节 |
| 游戏、语音、视频通话连不上（浏览器正常） | 这类应用不走系统代理，属方式边界 | 分不清时按 [游戏连不上怎么办.md](游戏连不上怎么办.md) 的对照测试走一遍 |
| 回到原来的 Wi-Fi 后反而没网 | 手动代理忘了关 | 把该网络的代理设回「无」再连（见第四节） |
| 用一会儿就断 | 手机省电策略、息屏后热点被关 | 给 NetShare 关电池优化、允许后台运行 |
| VPN 一开共享就断 | VPN 应用没开局域网开关 | 见 [共享VPN连接的方法.md](共享VPN连接的方法.md) |
| 之前能用，突然不行 | 应用屏幕上的 IP 或端口变过 | 代理处同步改成屏幕当前显示的值 |

分平台的代理配置入口：iPhone / iPad 在 设置 → Wi-Fi → 点开该网络 → HTTP 代理 → 手动；Windows / macOS / Linux 的完整步骤与命令见 [电脑端连接教程.md](电脑端连接教程.md)；安卓当第二台设备时在 NetShare 应用里点 CONNECT，不用手动填代理。

## 三、常见疑问

**为什么一定要配代理？**
安卓系统不允许未 root 的应用直接转发网络流量，NetShare 在手机本机起了一个代理服务来接通第二台设备的访问。这是整个用法里唯一的额外步骤，跳过它热点就是「连着但没网」。

**热点安全吗？**
官方说明热点用 WPA2 加密。密码别外传——知道密码的设备都能连进来蹭网络。

**需要专门的热点套餐吗？**
官方说明无需专门的热点套餐或 tether 费用；你实际会不会被计费、怎么计费，以运营商的口径为准。

**耗电和发热正常吗？**
开热点共享期间，手机比普通待机耗电明显、机身发热，属于正常现象；长时间共享建议插着电源。

**速度比直接连 Wi-Fi 慢？**
流量多绕了一道，再叠加距离、信号与发热，速度比直连慢是普遍情况。手机和接收设备放近一点、给手机散热、避开网络使用高峰，能改善一些。

**手机熄屏后共享就断？**
部分系统在熄屏后限制后台网络。去设置里给 NetShare 关掉电池优化、允许后台活动，再试。

## 四、用完之后：把代理关掉

手动配过代理的设备（iPhone / iPad、Windows、macOS、Linux），回到别的 Wi-Fi 之前把代理设回「无」或取消勾选——代理留着，设备连原网络时还会去找 `192.168.49.1`，结果就是「换了网络反而没网」。用 NetShare 的 Windows 连接方式（VPN 连接）的，断开那个连接即可。

## 五、收尾手段：重开与重装

上面都对过还不行，按轻到重试：

1. 手机端取消勾选 Start Hotspot，等几秒再勾上；
2. 完全退出 NetShare 重开，第二台设备关 Wi-Fi 重连；
3. 还不行就重启两台设备；
4. 重装前先记下当前版本信息（版本口径见 [下载与安装教程.md](下载与安装教程.md)），再卸载重装，重装后重新走一遍连接流程（[热点共享使用教程.md](热点共享使用教程.md)）。
