# NetShare 下游戏与部分应用连不上怎么办

## 一、先分清是没配好，还是本来就不通

接上热点后做一次对照测试：

| 测试 | 结果 | 说明 |
| --- | --- | --- |
| 浏览器打开一个网页 | 能开 | 代理配置没问题，问题在具体应用 |
| 浏览器打开一个网页 | 打不开 | 代理没配好，先回 [连不上与常见问题排查.md](连不上与常见问题排查.md) |
| 换一个应用（聊天、邮件、看网页视频） | 能用 | 只有部分应用不行，往下看 |
| 换一个应用 | 全都不行 | 回排查篇，代理地址或端口大概率填错了 |

浏览器能用而某些应用不能，是这套方式的固有边界，不是你哪里配错了：NetShare 在第二台设备上靠系统代理转发流量，而系统代理只接手「认系统代理」的网页类流量（HTTP/HTTPS）。商店评价里最常见的抱怨正是「在线游戏连不上」，大量用户反馈过同样的现象。

## 二、哪些应用通常不行

- **在线游戏**：多数游戏用 UDP 或自有协议直连服务器，不经系统代理，基本连不上。少数只走 HTTP 的网页游戏、小游戏反而能用。
- **语音、视频通话类**：同样以 UDP 为主，多半不通。
- **直播、投屏类 App**：多为自有协议，不通的概率大。
- **下载工具的 P2P 部分**：BT、磁力链这类点对点流量不走代理。
- **App 内视频**：网页版视频能看，不代表 App 内也行——App 内播放器常走自有协议。

判断口径一句话：**这个应用是不是只走网页那一套流量？是就行，不是就悬。**

## 三、能试的办法

办法有限，按顺序试：

1. **看应用自身有没有代理设置**。少数软件（如部分聊天工具、下载工具）自带代理选项，填和系统代理同一组地址端口（默认 `192.168.49.1`，端口 `8282`，以应用屏幕显示为准），能救回一部分；
2. **电脑端认系统代理的软件**，处理思路见 [电脑端连接教程.md](电脑端连接教程.md) 第五节；
3. **游戏场景没有官方给出的解决途径**。真要在第二台设备上打游戏，若手机能开系统自带热点，直接用自带热点开一局是更省事的路。

## 四、反过来：哪些场景通常没问题

走网页流量的场景基本都能用：

- 网页浏览、网页版邮箱与文档、网页版办公；
- 聊天软件的文字消息、收发图片（个别 App 仍看它是否认系统代理）；
- 看网页里的视频；
- 查资料、刷网页版社区。

给第二台设备配的用途如果在上面这张单子里，NetShare 够用；要打游戏、开视频会议，先做第一节的对照测试再下结论。
