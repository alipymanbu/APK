## 一、观星指数是什么、在哪看

观星指数（Stargazing Index）是一个百分比评分，综合四项因素算出「今晚这个地点适不适合观星」：

| 因素 | 怎么影响结果 |
| --- | --- |
| 月相 | 月亮越圆，天空越亮，暗星越难看见 |
| 光污染 | 你所在位置的夜间灯光水平（城市中心天然吃亏） |
| 云量 | 云多直接看不见 |
| 天体可见时间 | 目标天体当晚能悬在地平线以上多久 |

**指数越高，观测条件越好。** 入口有两处：「今晚可见 / Visible Tonight」板块和「天文日历 / Calendar」板块里都有显示。Space.com 对这个功能的评价是「把日落时间、月相和云量合成一个百分比，告诉你今晚看到东西的概率，非常实用」——它的价值就是替你把查月历、查天气这几步并成了一眼。

## 二、怎么用指数做决定

- **指数高（比如 70% 以上）**：直接出门，重点看暗弱目标（深空天体、彗星）；
- **指数中等**：看月亮、行星这类亮目标照样行，暗目标留着等好夜；
- **指数低**：先看是哪项拖了后腿——满月等几天就亏下去，阴天等天气，光污染则只能挪地方。

一个月里指数的起伏基本跟着月相走：农历月初和月底（蛾眉月、残月）前后是暗夜窗口，满月前后几天适合看月亮本身。想知道某天具体看什么，就轮到天文日历了。

## 三、天文日历：事件都在这

「日历 / Calendar」板块按日期列天文事件，覆盖的类型：月相（新月、满月、上弦下弦）、流星雨（极大期）、日食月食、行星冲日、合相（两颗天体靠得近的时刻）等。日历可以往前翻——想查「去年那天晚上有什么天象」也能看。

配合星空图用是标准流程：日历里看到「某日木星冲日」，点进去用时间机器把星空图拖到那天晚上，就能提前知道它几点升起、在哪个方位（时间机器的用法见 [界面与基础操作.md](界面与基础操作.md)）。

## 四、事件提醒：别再错过流星雨

应用支持给**任意事件、任意日期时间**设提醒，不局限于日历里预置的那些。设置方法：

1. 把时间面板拖到你想提醒的那个未来时刻；
2. 点时间面板上的**铃铛图标**，提醒就挂上了。

能设的不只是日食、满月这种大事件——「某天凌晨木星和月亮靠得比较近」这种小天象也能设。到点应用会推送通知，前提是安装时没拒绝通知权限（权限对应关系见 [下载与安装教程.md](下载与安装教程.md)）。

## 五、一次完整的观测计划长什么样

把上面几样串起来，一次像样的计划流程是：

1. 在日历里挑一个感兴趣的事件（比如某晚的英仙座流星雨极大）；
2. 看那天的观星指数，确认月相和天气不拖后腿；
3. 用时间机器把星空拖到事件发生的时刻，记下方位和高度角；
4. 给这个时刻设上铃铛提醒；
5. 出门前打开星空图切夜视模式，按预演的方位找目标。

天气部分应用内就带了天气预报显示，不用再切天气 App。
