## 一、进入手势绘制模式

在 KingDraw 的绘制界面（画板），点击**右上角的【手势绘制工具】**即可进入手势绘制模式。开启后直接用手指在画板上划出轮廓，软件会把手势转成对应的结构片段——画常用骨架时，比一根一根点键快得多。

手势绘制工具支持十几种绘制手势。不用背：**长按【手势绘制工具】按钮，随时可以调出手势对照表**，画的时候放在旁边参照即可。

## 二、与画板配合的通用手势

下面这几个手势不挑模式，日常操作画板时用得上（来自官方手势教程）：

| 手势 | 作用 |
| --- | --- |
| 双指平移 | 移动画板 |
| 双指捏合 | 缩放画板 |
| 单指双击 | 定位到画板中间，并还原缩放比例 |
| 画板右侧快速下划 | 打开元素周期表目录 |
| 画板右侧快速上划 | 打开常用基团目录 |

"侧边上划调出基团目录"这条在实际画图里最省事：手指从画板右缘往上一划，常用基团列表就在手边，点选即插入，不用绕到左侧功能区找。

## 三、手势绘制怎么配合普通工具用

一个顺手的分工是：**骨架成型靠手势，修饰调整靠普通工具**。

1. 开手势绘制，把碳骨架、苯环这类主体结构划出来；
2. 关掉（或不用管）手势模式，换【框选工具】与颜色、文本工具做加杂原子、改颜色、加标注这些精修；
3. 歪了不齐先用美化工具自动排一遍，操作见 [画板绘图入门.md](画板绘图入门.md)。

手绘图转 3D 看立体结构时，同样支持手势旋转，操作见 [分子3D模型查看与操作.md](分子3D模型查看与操作.md)。手势划错了就撤销，别用橡皮擦一点一点蹭。
