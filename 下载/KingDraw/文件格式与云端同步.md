## 一、手机版能存成哪些格式

手机版画板里点【另存为】时可选的目标格式（来自官方 App 教程，以软件实际菜单为准）：

| 格式 | 用途 |
| --- | --- |
| .king | KingDraw 自己的文件格式，默认保存格式 |
| .kdx | 新版默认文件格式（v3.0.0 起启用） |
| .cdx | ChemDraw 文件格式，给用 ChemDraw 的同学或导师交换文件用 |
| .mol | 通用结构式文件格式，多数化学软件都认 |
| .mol v3000 | MOL 格式的 3000 版本 |
| .png | 图片，可保存到相册或直接分享 |

分享按钮也走图片路线：把结构式以 png 存进相册、或分享给别人。绘图标准方面，画板支持一键切换到 ACS 1996 标准；导出图片是否带水印与账号类型有关，见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 二、和 ChemDraw、Office 怎么互通

- **读 ChemDraw 文件**：手机版支持编辑 ChemDraw（cdx）文件。按官方说明的做法：在 PC 端登录账号，把 cdx 文件上传到云端，手机端的云端文件列表里就会出现它，点开即可编辑；手机端画的文件也能反向存成 cdx 交给 PC。
- **在电脑上用 KingDraw**：Windows 版分个人版、专业版、教育版（教育版面向高校，用高校邮箱绑定可免费使用全部功能，截至官方页面口径）。PC 版还有把结构式直接粘贴进 Office、与 WPS 互通、导出 SVG 等移动端没有的能力，需要这些时再装 PC 版。
- **手机到电脑的完整链路**：手机画 → 存云端 → PC 打开继续编辑 → 另存为 cdx/mol 交出去。这也是多端同步最主要的使用场景。

## 三、登录账号与多端同步

1. **注册登录**：支持手机号或邮箱注册登录（邮箱登录自 v3.4.0 起支持）。
2. **云端文件**：本地文件可上传到云端，换手机、装 PC 版后登录同一账号即可看到。
3. **同步范围**：手机、Pad、PC 三类客户端之间一键同步；手机上画的、平板上改的、电脑上导出的，都指向同一个云端文件库。

不登录也能画，但文件只存在本地，卸载或换机会丢；重要的图建议养成传云端的习惯。

## 四、免费与会员的存储差别

官方会员页列出的**移动端**会员特权包括：无限本地文件存储量、无限云端文件存储量、无水印图片、基团展开、展示立体构型。反过来看，免费账号在本地与云端文件数量上有上限，导出图片带水印。具体限额数值官方页面没有公开写明，以应用内提示为准。

对用量大的人（一个学期几十个反应方案）这个差别是实际的；偶尔画一两张的话免费额度通常够用。会员与免费的具体差额和开通方式见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 五、按结构找文件

文件攒多了靠文件名翻找很慢，KingDraw 支持结构式检索：画出一个**部分结构**，就能找出包含这个结构的文件。官方 PC 版教程里的口径是"快速检索出云端和本地文件中包括该结构式的文件"，覆盖 .king / .cdx / .mol；手机版的功能列表里也标注了子结构式搜索。找"上次画的那个带磺酸基的东西在哪份文件里"这类需求，画个特征片段比回忆文件名靠谱得多。
