# ImageOverlay 常见问题排查

> 本篇按症状整理 ImageOverlay 用起来最容易碰到的状况：遮罩看不见、图片被拉伸、保存失败、透明度不生效、绑定不工作，以及清理和卸载。装不上或第一次打开就报错的情况，先回 [下载与安装教程.md](下载与安装教程.md) 核对安装环节。

## 一、点了启动但看不到遮罩

按顺序检查两处：

1. **悬浮窗权限**：确认「在其他应用上层显示」已经允许。部分品牌系统（如 MIUI）除了应用内的弹窗引导，还要在系统权限管理里再单独允许一次——这是「看不到遮罩」的头号原因。
2. **分屏 / 画中画**：如果你正在分屏或小窗模式里用，系统层级可能影响遮罩显示。先退出特殊窗口模式，回到全屏再试。

权限给过还是不行，重启一次应用再启动遮罩；依然无效时，到应用官方仓库（[https://github.com/PerryKum/ImageOverlay](https://github.com/PerryKum/ImageOverlay)）的 issue 区看看有没有同款机型的反馈。

## 二、遮罩图片被拉伸、比例不对

当前版本会把遮罩图拉伸铺满整块屏幕，图片比例和屏幕不一致时就会出现变形。这不是 bug，是这版的设计行为：

- 做遮罩图时按你设备的实际分辨率来，长宽对上了就不会变形；从零做一张比例正确的遮罩图，步骤见 [遮罩图片制作方法.md](遮罩图片制作方法.md)；
- 想让遮罩严丝合缝盖住刘海或挖孔区域，设置里有对应开关可以选择遮罩是否覆盖到那块区域。

期待等比缩放或自定义位置的话，只能等后续版本，最新版的改动方向见 [版本更新内容一览.md](版本更新内容一览.md)。

## 三、选完图片保存失败或不显示

三步排查：

1. **存储目录**：进设置里先把配置目录选成系统文件选择器授权的目录（SAF 目录），这比手动指定的传统路径稳；坚持用传统路径的话，确认那个目录可写。
2. **图片本身**：确认是 PNG，且没有被系统清理工具删掉——遮罩图放在容易被「深度清理」波及的目录里，隔天消失多半是这个原因。
3. **外置存储**：图放在 SD 卡上的，确认系统已授权应用读写该位置。

## 四、透明度调整了没效果

透明度是全局设置，统一作用于所有遮罩，注意两点：

- 调整停止约半秒后才自动保存；保存前切走，改动可能没存上；
- 屏幕上正在跑的遮罩会实时跟随，但如果它看起来纹丝不动，先回设置页确认滑块确实改成功了，再重新启动一次遮罩。

## 五、应用绑定不自动切换

应用绑定依赖「使用情况访问权限」，逐一确认：

1. 系统设置里的「使用情况访问」已允许 ImageOverlay（这个权限不在弹窗引导流程里，要去系统设置手动开）；
2. 被绑定的应用确实已安装、能正常打开；
3. 绑定的是「组」不是单个配置——长按组才能看到绑定入口，绑错了层级自然不生效。

都确认过还是不行，重新绑定一次组，再切几次应用试试。

## 六、应用崩溃了怎么办

崩溃后再次打开应用时，界面会显示上一次的错误信息，可以复制下来。反馈问题就带上这段信息，去官方 QQ 群（710807742）或 GitHub 仓库提 issue，作者会跟。

## 七、想彻底清理或卸载

- 只清数据：设置里有「清除缓存」，可以删掉无效图片或全部数据；
- 卸载前想干净收尾：用文件管理器进你当初授权的配置目录，把里面的 `ImageOverlay/` 文件夹整个删掉，再卸载应用，本地就不会留任何残余。

## 八、其他容易误会的两点

- **快速使用和预设点不动**：不是坏了，两者互斥——预设有配置激活时快速使用启动不了，反之亦然，先去停掉另一边，见 [遮罩启动与快速使用.md](遮罩启动与快速使用.md)。
- **回到桌面遮罩就没了**：3.0 版支持回到桌面自动关闭遮罩，这是功能在起作用，不是异常；希望遮罩常驻的话检查这个开关，或者改用应用绑定精确控制。
