## 一、Tale 是什么

Tale短视频创作（应用内与各处均以 `Tale` 显示）是一款安卓端的短视频剪辑工具：你从模板起步或从空白项目起步，导入手机里的图片和视频，加上字幕、滤镜、背景音乐，最后导出成片发到社交平台。它面向的是「想快速出一条能发的短视频」的普通用户，不需要你有剪辑基础。

本篇只讲下载安装；装好之后怎么做出第一条视频，见 [模板一键制作与导出保存.md](模板一键制作与导出保存.md)。

## 二、安装包参数（以本份安装文件为准）

你从网盘拿到的这份安装包，参数如下——装之前可以先核对，避免下错包：

| 项目 | 数值 |
| --- | --- |
| 版本号 | 1.0.8 |
| 包名 | `com.talekdg.kol` |
| 安装包大小 | 93.70M |
| MD5 | `E5EC5EE7DC909D93716D4E7BA590D4CA` |
| 系统要求 | 安卓 5.2 及以上 |
| 开发者 | 深圳市践迹科技有限公司 |

几点说明：

- **版本以这份包为准**。网上搜到的「最新版」可能是别的版本（同名应用还有国际版等变体，包名不同），如果你想装的就是手头这份，别被商店里的版本号带偏。
- **核对 MD5**：文件较大时若下载中断，装不上多半是包不完整。用任意 MD5 校验工具算一下安装包的 MD5，与上表一致才是完整文件。
- **认包名不认名字**：桌面图标与应用名都可能被改，`com.talekdg.kol` 才是这个应用的唯一标识。手机「设置 → 应用管理」里搜这个包名，能确认装的是不是它。

## 三、下载

1. 打开 [Tale短视频创作 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2ed07701fa26)，转存到自己的网盘或直接下载。
2. 网盘里的安装包文件名形如 `tale_v1.0.8.apk`，确认大小约 93.70M 后再继续。
3. 若网盘提供的是文件夹形式，进去找到 `.apk` 那个文件下载即可；文件夹里的说明文本不是安装所需。

下载完成后先别急着点开，看下一段的安装设置。

## 四、安装

安卓从应用商店之外安装 APK，需要先授权一次「安装未知应用」：

1. 用手机自带的「文件管理」找到下载的 `.apk` 文件，点它。
2. 系统若提示「禁止安装来自此来源的应用」，按提示进入 **设置 → 安全/隐私 → 安装未知应用**，给你的文件管理器（或浏览器）打开「允许来自此来源的应用」。不同品牌手机菜单名略有差异，但都在安全设置里。
3. 回到文件管理器再次点击 APK，确认应用名与包名信息后点「安装」。
4. 等进度走完，显示「安装完成」即可打开。

安装报错的处理（解析错误、安装失败等）见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 五、首次运行：它会要哪些权限

首次打开时，Tale 会陆续请求几类权限，和它的功能直接对应：

- **存储（照片与视频）**：导入你手机里的素材、把导出的成片保存到相册 —— 不给就只能用应用内置素材，也存不了片。
- **网络**：获取模板、特效、贴纸、音乐等在线素材 —— 不给的话素材库会是空的。
- **麦克风**：给视频配音、录旁白用。
- **相机**：在应用内直接拍摄素材用。

建议按需开启：只想剪已有素材，可以先拒掉相机和麦克风，用到时再开。权限随时可在系统「设置 → 应用管理 → Tale → 权限」里改。安装包声明的权限还包括网络访问、WLAN 状态等常规项，以安装时系统的权限清单为准。

关于数据收集与处理，应用附带的隐私政策地址为：`http://oss.bestkids.net/android-static/app-build/com.talekdg.kol/com.talekdg.kol-2.html`（以应用内最新公示为准）。
