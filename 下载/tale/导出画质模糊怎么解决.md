# Tale导出画质模糊怎么解决

> 先判断模糊发生在哪一环——是导出时就糊，还是发到平台后才糊——再对症处理。

## 一、先定位：模糊发生在哪一环

同样一句「导出的视频糊了」，原因分三段，处理完全不同。按下面顺序各看一眼：

| 检查点 | 怎么看 | 结论 |
| --- | --- | --- |
| 素材本身 | 把导入前的原视频在相册里全屏播放 | 原素材就糊 → 问题在源头，见第三节 |
| 本地导出文件 | 导出后在相册里全屏播放成片 | 导出文件糊 → 问题在导出参数，见第二节 |
| 平台上的成品 | 发布后下载自己那条视频对比 | 本地清晰、平台糊 → 平台二次压缩，见第四节 |

一环一环排，别跳着改——在错的环节上调参数没有作用。

## 二、导出文件就糊：参数与素材不匹配

1. **导出分辨率低于素材**：你导入的是 1080P 素材、导出选了 720P，细节一定丢。导出分辨率选 ≥ 素材分辨率（参数怎么选见 [模板一键制作与导出保存.md](模板一键制作与导出保存.md) 的导出一节）。
2. **帧率与内容不匹配**：运动密集的画面导出 30fps 会比 60fps 显得糊一点（拖影感），这类素材把帧率拉高再导。
3. **劣化会叠加**：把上次导出的成片再导入再导出，等于二次有损压缩。每次都从**相册里的原始素材**剪，不要拿成片当素材来回倒。
4. **滤镜与特效拉太狠**：重度锐化、强颗粒滤镜在低分辨率下会糊成一片。先把滤镜强度往回收一档试试。

改完参数**重新导出一份**再看——已经导出的文件不会因为改设置变清晰。

## 三、素材源头就糊：先解决输入

- **别用社交软件传过来的视频当素材**：微信、QQ 传输时会强压缩，收到的往往已经是低码率版本。尽量用手机相机直接拍的原片，或从相机胶卷原始文件导入。
- **截图当素材天然糊**：静态图分辨率不够时放大使用必然发虚，导入前先确认图片分辨率。
- **下载的视频看原始画质**：很多平台下载入口给的是标清版本，选「高清/原画」下载再导入。

源头素材的清晰度是上限，导出参数只能保住它，不能凭空提高它。

## 四、本地清晰、发出去才糊：平台二次压缩

几乎所有短视频与社交平台都会对上传视频**重新压缩**一遍，这不是 Tale 导出的问题。按下面做能最大程度保住画质（各平台开关名称与位置以其当时版本为准）：

1. **导出就选 1080P**：给平台留足压缩余量，别导 720P 再指望平台放大。
2. **发布时打开高清选项**：多数平台在发布页有「高清发布 / 允许高清上传 / 原画质」之类的开关，默认常是关的，手动打开。
3. **关掉省流量模式**：平台或手机的省流量模式会主动压低上传画质。
4. **用稳定的 Wi-Fi 上传**：弱网下平台容易接受更低质量的文件或加重压缩。
5. **别在平台内二次编辑**：发布后再用平台自带编辑器改动，会再压一轮。

## 五、一条判据收尾

**同一段素材，导出两份（720P 与 1080P），全屏播放对比**：差异明显说明之前是导出参数问题；差异不大而整体都糊，回头查素材源头。定位清楚再动手，比逐个参数瞎调快得多。

平台侧设置反复调过仍糊的，属于平台压缩策略本身，本地已无能为力——这与 [常见问题与解决方法.md](常见问题与解决方法.md) 里「导出失败」是两回事，别混在一起排查。
