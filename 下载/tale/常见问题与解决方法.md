## 一、安装阶段

### 提示「解析包时出现问题」/ 安装包无法解析

按顺序排查：

1. **下载不完整**：93.70M 的包断点续传容易出坏文件。重新下载一遍，并核对 MD5 是否为 `E5EC5EE7DC909D93716D4E7BA590D4CA`（见 [下载与安装教程.md](下载与安装教程.md)）。
2. **系统版本过低**：本包要求安卓 5.2 及以上，在「设置 → 关于手机」里确认系统版本。
3. **包与 CPU 架构不匹配**：极少数情况下会报架构不支持，换一台设备试装确认。

### 提示「已安装同名应用」或安装后是旧版本

多半是手机里已有同包名的另一个版本。先在「设置 → 应用管理」搜 `com.talekdg.kol`，确认现有版本号；需要覆盖为手头这份时，先在应用内导出草稿与作品（**卸载会清掉应用内数据**），再卸载重装。

### 安装按钮点不动 / 一直显示安装中

- 存储空间不足会导致安装卡住：先确认手机剩余空间大于安装包体积的两倍；
- 部分手机的「纯净模式」「安装监控」会拦第三方安装，在安全设置里临时放行后重试。

## 二、启动阶段

### 打开就闪退 / 停止运行

逐项试，通常前两步就能解决：

1. **清缓存**：长按图标 → 应用信息 → 存储占用 → 清理缓存（先别清数据，清数据会丢草稿）。
2. **给权限**：应用信息 → 应用权限，把存储、网络等权限打开——权限被拒后应用处理不当是三方应用闪退的常见原因。
3. **清后台重启**：划掉后台里的 Tale，或直接重启手机再打开。
4. **检查存储与内存**：手机剩余存储过少、运存被占满都会让剪辑类应用崩溃，先清理再试。
5. **确认不是新版本引入的问题**：如果闪退是最近某次覆盖安装后才出现的，卸载后重装当前这份 1.0.8（注意先备份应用内数据）。

### 素材库是空的 / 特效贴纸加载不出来

素材库是在线拉取的，先查网络：切换 Wi-Fi 与移动数据各试一次；再确认应用有网络权限。网络正常仍空，说明是应用侧服务波动，过段时间重进。

## 三、编辑与导出阶段

### 导入不了图片或视频

1. 检查**存储权限**是否授予（系统设置 → 应用管理 → Tale → 权限 → 照片与视频/存储）；
2. 确认素材本身能被系统相册正常显示——损坏的文件应用也读不出；
3. 权限是最近才拒过的，授完后**完全退出应用重进**，让权限生效。

### 导出失败 / 导出到一半停住

- **导出时不要锁屏、不要切到其他应用**：这是最常见的原因，切走后渲染被系统挂起就会失败。留在导出界面等进度走完。
- **存储空间不足**：导出前确认剩余空间够放下成片。
- **后台清理过猛**：部分手机的省电策略会杀后台渲染，导出前把 Tale 加入「后台运行/电池优化白名单」。

### 导出成功但相册里找不到

1. 在系统相册里下拉刷新，或等几秒让媒体库扫描完成；
2. 检查相册是否按日期过滤——导出的成片按导出时间归档；
3. 用文件管理器查 `DCIM` / `Movies` 目录（导出路径以版本实际行为为准）；
4. 应用内的「作品集」里也存着已完成作品，可从那里重新导出一份。

### 视频导出后没有声音 / 声音很小

检查时间线上音乐轨与人声轨是否被静音、音量条是否拉到了 0；用提取音频功能拆出来的音轨默认音量可能偏低，点开它调高再导出。相关操作见 [剪辑功能使用技巧.md](剪辑功能使用技巧.md)。

### 导出的视频画质模糊

先按 [导出画质模糊怎么解决.md](导出画质模糊怎么解决.md) 定位模糊发生在哪一环（素材、导出参数、还是平台压缩），再改对应环节；导出参数的选法在 [模板一键制作与导出保存.md](模板一键制作与导出保存.md)。

### 剪辑时预览卡顿、手机发烫

预览卡但导出正常通常是资源问题，按 [剪辑卡顿与手机发烫怎么办.md](剪辑卡顿与手机发烫怎么办.md) 的顺序处理（清后台 → 存储余量 → 降温 → 分段剪）；卡到闪退回看本篇第二节的闪退流程。

## 四、数据与卸载

**草稿箱与作品集存在应用内部**，卸载应用会一并清除。需要保留的半成品，先导出成视频文件存到相册；确实要卸载重装时，先做这一步再操作（参见 [模板一键制作与导出保存.md](模板一键制作与导出保存.md) 的草稿箱一节）。

排查到这一步仍不解决的，多为应用自身在该机型上的适配问题——留意应用后续版本更新，升级后再看是否复现。
