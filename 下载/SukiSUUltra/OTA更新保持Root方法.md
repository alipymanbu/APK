# SukiSU-Ultra OTA更新保持Root方法

> 本篇讲系统 OTA 更新为什么会让 root 消失，以及重启前怎么动手才能保住它。

## 一、为什么一更新 root 就没了

新一点的安卓设备用 A/B 双分区：系统更新写入另一个插槽，重启时切过去。你刷的 SukiSU-Ultra 内核在旧插槽上，新插槽是原厂内核 —— 重启完成的那一刻，root 自然消失。所以保 root 的全部思路就是一句话：**在重启之前，把带 SukiSU-Ultra 的内核也装到新插槽上**。

## 二、动手前的检查清单

OTA 提示可更新时，先别点安装，把这几样备齐：

- **当时刷入用的内核包**（`AnyKernel3` zip）已备份在电脑或手机存储 —— 对侧插槽刷的就是它；
- **原厂 boot / init_boot 镜像**在手边（提取方法见[boot镜像提取与修补.md](boot镜像提取与修补.md)），万一插槽刷错还有退路；
- 手机电量充足、电脑 fastboot 环境正常 —— 整个流程要在「装完 OTA 但还没重启」的窗口里一口气做完。

## 三、方法一：刷入到另一个插槽（官方推荐流程）

OTA 更新包下载安装完成后，**不要点重启**，按这个顺序做：

1. 打开 SukiSU-Ultra 管理器，进入「刷入 / 修补内核」界面；
2. 选 GKI/non-GKI install 方式，选中你的 `AnyKernel3` 内核 zip 文件；
3. 插槽选择上选**当前正在使用的插槽的对面那个**（也就是这次 OTA 刚写入的插槽）；
4. 刷入完成后再重启系统。

重启之后新系统和你手上的 root 就都在了。

## 四、方法二：LKM 模式

GKI 设备也可以用 LKM 方式，把内核模块安装到未使用的插槽，效果一样：OTA 后不重启，管理器里选 LKM 模式装到对侧插槽，再重启。用哪种看你当初的刷入方式与习惯，官方文档把两种都列为可行。

## 五、非 GKI 设备怎么办

非 GKI 机型没有通用插槽刷法可依赖，官方文档给的最稳妥办法很直接：**OTA 后用 TWRP 把定制内核重新刷一遍**。这条路线不需要管插槽逻辑，但要求你的 recovery 与内核包都在手边 —— 所以每次成功刷入后，把当时用的 AnyKernel3 zip 存进电脑备份一份。

## 六、更新后的验证

重启进入新系统后照常核对：管理器首页状态正常、root 检测应用能正常拿到授权、关于手机里的内核版本带上了你的定制痕迹。状态不对时先别继续折腾，按[常见问题与风险须知.md](常见问题与风险须知.md)的排查顺序来。

另外提醒一句：OTA 偶尔会连 bootloader 状态、第三方 recovery 一起动，更新完成后顺手确认这两个还正常，别等到下次要刷东西时才发现。第一次刷入的完整流程见[下载与安装教程.md](下载与安装教程.md)。
