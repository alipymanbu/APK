## 一、动手前先掂量的四件事

- **保修**：解锁 bootloader、刷内核在多数厂商那里都算放弃保修的举动，官方文档开头就警告了这一点；
- **数据**：解锁 bootloader 的过程会清空手机数据，不是可能，是会；
- **变砖**：刷错版本、刷错分区、中途断电，都可能导致设备无法启动 —— 出门前必须有自己的恢复手段（见第三节）；
- **部分应用不工作**：一些应用有 root 检测，检测到环境被改会拒绝运行。这是客观存在，刷之前想清楚自己依赖哪些应用。

## 二、管理器显示「未安装」或状态异常

| 现象 | 先检查什么 |
| --- | --- |
| 管理器首页显示未安装 | 内核根本没刷成功，或刷的是不含 SukiSU-Ultra 的内核 —— 回到刷入环节重来 |
| 刷完显示未安装 | 确认刷的包和你内核版本对得上（前两位一致），非 GKI 机型确认走的编译集成路线 |
| 管理器显示「不支持」 | 这和「未安装」不是一回事：说明设备没有官方开箱即用的内核支持，要自己编译内核集成（官方 FAQ 口径），参考[GKI内核判断与刷入方式选择.md](GKI内核判断与刷入方式选择.md)第四节 |
| 授权弹窗不出现 | 应用列表里该应用是否被关掉了 root；重启一次再试 |
| 模块装了不生效 | 内核是否支持该模块依赖的能力（比如 KPM 模块要内核带 `CONFIG_KPM=y`） |
| 刷完反复重启 | 十有八九是包和内核不匹配：系统是 Android 13 但内核是 `android12-5.10` 之类的错配最常见 —— 永远按**内核版本**挑包，见[boot镜像提取与修补.md](boot镜像提取与修补.md) |

## 三、刷完卡在开机画面怎么救

这就是第一节说的「恢复手段」，关键在**提前**准备：

1. 刷任何东西之前，把你当前系统版本对应的原厂 `boot.img` / `init_boot.img` 提取或下载好，存到电脑（怎么提取、怎么核对版本，见[boot镜像提取与修补.md](boot镜像提取与修补.md)）；
2. 卡开机时，进 fastboot 模式（多数机型是关机后按住电源 + 音量下），用数据线连电脑；
3. 把原厂镜像刷回对应分区，重启 —— 设备回到没刷过的状态，再从头排查是包不对还是步骤错了。

没有原厂镜像就出不了这个局，所以「先备镜像再动手」不是建议，是前提。

## 四、OTA 后 root 消失

正常现象，而且是可以在重启前避免的 —— 按[OTA更新保持Root方法.md](OTA更新保持Root方法.md)的流程处理。已经重启完、root 没了的话，把对应内核包重新刷一遍即可。
