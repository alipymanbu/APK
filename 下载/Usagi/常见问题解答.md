## 一、装完打开是空的，是不是坏了？

不是。官方说明写明应用本身不包含任何内容，内容全部来自你自己添加的外部插件。先去加图源（步骤见[图源添加与管理.md](图源添加与管理.md)），或把手头的本地漫画文件导入（见[本地漫画导入阅读.md](本地漫画导入阅读.md)）。

## 二、图源刷不出来、加载失败怎么办？

按顺序试：

1. 先确认不是所有图源一起挂——单独换一个图源验证，能区分是网络问题还是单个图源的问题；
2. 单个图源挂：在图源管理里停用再启用，或换同类图源替代。图源本身失效是常态，与应用好坏无关；
3. 全体图源都刷不出：优先查网络；网络受限环境下可以试应用内置的网络隧道功能，或换个网络环境再试。

单部漫画一直加载失败、其他漫画都正常，可以把它迁移到别的图源，见[图源失效与换源迁移.md](图源失效与换源迁移.md)。

## 三、Usagi 和 Kotatsu 是什么关系？

Usagi 是 Kotatsu 系的开源分支（官方仓库初始提交注明代码来自 Yumemi 项目），Kotatsu 的主要功能它都保留。0.0.x 的更新日志提到增强了对外部数据的读取与向下兼容、提升与其他 Kotatsu 分支的兼容性——如果你在用 Kotatsu，想把收藏和历史搬过来是有戏的，但具体能搬多少、搬过来什么样，以你手上的版本实测为准，日志口径不等于实际效果。Usagi 本身支持还原备份文件（官方更新日志里有多处还原备份相关的修复），所以可以先在 Kotatsu 里把收藏导出成备份文件，再到 Usagi 里试着还原；找不到还原入口或还原不完整，就说明这条路在你这个版本上走不通，退回手动重搜重收藏。

## 四、收费吗？安全吗？

免费、开源，源码以 GPL-3.0 许可证公开在 GitHub（[https://github.com/UsagiApp/Usagi](https://github.com/UsagiApp/Usagi)），任何人都能查。安装包是否被第三方动过，可以对照官方公布的签名证书指纹来核（方法见[下载与安装教程.md](下载与安装教程.md)第四节）。

## 五、老手机能用吗？

官方标注支持 Android 5.0 及以上，且针对低端设备做过优化。实际体验与机型、系统底层都有关系，年限较久的设备建议装完先开几话漫画试试流畅度。

## 六、更新通知重复弹是什么毛病？

0.0.x 早期版本出现过新章节通知重复推送的情况，官方在 0.0.31 专门修过一轮（重复的章节检查结果与通知去重）。还在遇到的话先升级再试；升级前嫌它吵，可以在系统设置里临时关掉这个应用的通知。

## 七、遇到问题去哪反馈？

官方渠道是 GitHub 仓库的 Issues 页（[https://github.com/UsagiApp/Usagi/issues](https://github.com/UsagiApp/Usagi/issues)），社区另有 Discord 与 Telegram 群组，入口都在仓库 README 里。反馈时写清版本号、系统版本与复现步骤，处理得快。
