## 一、先了解这款应用

Usagi 是一款免费开源的安卓漫画阅读器，属 Kotatsu 系分支（官方仓库的初始提交注明代码来自 Yumemi 项目），源码以 GPL-3.0 许可证公开。它本身不内置任何漫画内容，能看什么完全取决于你添加的图源插件和导入的本地文件——所以装完之后的第一步通常是加图源，见[图源添加与管理.md](图源添加与管理.md)。

下面是网盘资源里那份安装包的版本信息（网上能搜到的「最新版」版本号很可能更新，别混着看）：

| 项目 | 数值 |
| --- | --- |
| 版本 | 0.0.2 |
| 包名 | org.draken.usagi |
| 安装包大小 | 14.34 MB |
| MD5 | 4DDD0908D38637E474B6F6EC3F7D9150 |

系统要求方面，官方仓库的徽标标注 Android 5.0 及以上，并称针对低端设备做过优化；不同页面也能见到 6.0+ 的说法，以官方发布页为准。

版本节奏上，Usagi 迭代很快：0.0.x 系列之后进入 1.0（代号 Manju），截至 2026-09 官方稳定版已发布到 1.1，以 [Releases 页](https://github.com/UsagiApp/Usagi/releases)为准。网盘资源里的 0.0.2 属于早期版本，插件与本地格式支持都和新版有差距，介意的话可以直接从官方渠道装新版。

## 二、获取安装包

安装包可以从上面的 [Usagi 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e03108b84d3a)获取，转存后把 `Usagi_v0.0.2.apk` 下载到手机即可。

想对照官方原始渠道的话，有两个入口：

- 官方 GitHub 仓库的 Releases 页：[https://github.com/UsagiApp/Usagi/releases](https://github.com/UsagiApp/Usagi/releases)
- F-Droid 应用页：[https://f-droid.org/en/packages/org.draken.usagi/](https://f-droid.org/en/packages/org.draken.usagi/)

两边都是官方认可的发布渠道，版本节奏可能不完全同步，装哪个版本以你自己的需要为准。

还有一点值得知道：1.0 起应用内的自动更新检查默认是关闭的（官方为符合第三方商店条款而默认关），装了新版之后迟迟不见更新提示属正常现象，想升级就到 Releases 页手动看。

## 三、安装步骤

Usagi 不走应用商店上架，属于 APK 侧载安装，流程如下：

1. 把 APK 文件放到手机存储里（网盘转存后下载，或从官方渠道直接下载都行）。
2. 在文件管理器里点开这个 APK。首次安装时系统会提示「不允许安装未知来源应用」，按提示允许「安装未知应用」权限（不同品牌手机的提示措辞略有差异，意思一致）。
3. 回到安装界面点「安装」，等进度走完。
4. 装完点「打开」；如果跳过了，也可以在桌面点 Usagi 图标进入。

安装被拦或报「解析包出现问题」这类情况，常见原因与处理见[常见问题解答.md](常见问题解答.md)。

## 四、装之前可以顺手核对的两个信息

- **MD5**：把下载得到的 APK 用校验工具算一下 MD5，与本文表格里的值对照，能确认文件在传输过程中没有损坏。
- **签名证书**：官方仓库公布了两份签名证书指纹（SHA-1 与 SHA-256）。官方发出的安装包用官方签名，被第三方重新打包过的安装包签名会不一样；想确认「装的是不是官方原包」，可以用签名查看工具读一下你手上 APK 的证书，与仓库 README 公布的指纹对照。

## 五、装完之后先做什么

首次打开 Usagi，首页大概率是空的——这是正常的，官方明确说明应用本身不带内容，内容全部来自你后加的图源插件。接下来：

- 想在线追漫 → 先去添加图源，步骤见[图源添加与管理.md](图源添加与管理.md)；
- 手头有本地漫画文件 → 直接导入阅读，见[本地漫画导入阅读.md](本地漫画导入阅读.md)；
- 想先把界面与阅读习惯调顺 → 见[阅读功能与设置.md](阅读功能与设置.md)。
