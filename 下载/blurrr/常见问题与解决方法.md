## 一、安装类

**安装时提示解析错误 / 安装包损坏**
多半是文件没下完整。核对 MD5（`ab56025c4be8685745e3ef673d1977a8`，核对方法见 [下载与安装教程.md](下载与安装教程.md) 第二节），对不上重新下载。

**提示系统版本不兼容**
当前版本的第三方渠道标注要求 **Android 10+**。先查 **设置 → 关于手机 → Android 版本**：低于 10 就是装不了，别反复试；等于或高于 10 仍报错，多半是安装包与架构不匹配，换官方商店渠道的包再装。

**空间不足装不进去**
安装包 243M，安装与解压还需要额外空间。清出 1GB 以上可用空间再装。

## 二、启动与稳定性类

**一打开就闪退**
按命中率排查：

1. 系统与内存是否达标（Android 10+、2GB 起，见 [下载与安装教程.md](下载与安装教程.md) 第四节）；
2. 存储是否快满 —— 存储紧张时系统会优先杀掉占空间大的应用；
3. 重启手机后只开 Blurrr 再试，排除后台占用；
4. 还闪退：卸载后重装一次（工程文件不随卸载保留，重要工程先确认已保存）。

**剪着剪着卡顿 / 预览掉帧**
先分清是**预览卡**还是**导出也卡**：预览卡常见原因是实时特效层数多、4K 素材直剪，处理办法见 [3D摄像机与图层混排功能说明.md](3D摄像机与图层混排功能说明.md) 第五节；导出也卡则是设备性能或存储写入瓶颈，降低导出分辨率档位再试。

**编辑中出现异常（错位、参数不生效）**
官方 2.0.6 版本更新说明写明「修复了一些编辑过程中的问题」，并优化了相册性能 —— 先确认自己是最新版，旧版本的已知问题升级即可解决（网盘那份是 2.0.6-3.2）。

**版本号和别人对不上**
商店版会持续更新小版本（第三方下载站已出现 2.0.6-5.1），网盘固定是 2.0.6-3.2 —— 两者不是同一批包，差异只有小版本号，功能以你装的这版为准。要最新就从官方商店更，要固定就用网盘那份（见 [下载与安装教程.md](下载与安装教程.md)）。

## 三、导出类

**导出时看不到 4K 选项 / 提示需要会员**
4K 分辨率、运动模糊、AI 补帧在官网会员页上列在 SVIP 权益里，免费版按可用档位导出。权益与价格见 [会员价格与免费版区别.md](会员价格与免费版区别.md)。

**导出很慢或中途失败**
- 选低一档分辨率先验证流程能不能走通，能走通说明是性能/空间问题；
- 检查可用存储 —— 导出要临时占用成片体积数倍的空间；
- 导出期间别切到别的重应用，避免进程被系统回收。

**导出后没找到成片**
先查相册权限是否给了（首次启动拒过就去设置补开）；再看导出完成页有没有「保存到相册」这一步没点。仍找不到，用文件管理器按修改时间排序找最近生成的视频文件。

## 四、功能找不到类

| 想做的事 | 入口 |
| --- | --- |
| 打关键帧 / 调曲线 | 选中图层 → 关键帧按钮；曲线在曲线编辑器，见 [关键帧与曲线编辑教程.md](关键帧与曲线编辑教程.md) |
| 用保存过的预设 | 选中素材 → 功能栏「预设」→「导入」→ 选列表项 |
| 变速 / 卡点 | 选中素材 → 变速面板，用时间重映射，见 [变速卡点与时间重映射教程.md](变速卡点与时间重映射教程.md) |
| 让多个元素一起动 | 建空对象 + 父子绑定，见 [3D摄像机与图层混排功能说明.md](3D摄像机与图层混排功能说明.md) |
| 换画幅 / 分辨率 | 新建项目时设定；已建工程以导出设置为准 |

## 五、还是解决不了

带上这四样信息去找官方，响应最快：

1. 手机型号 + Android 版本；
2. 应用版本号（设置/关于里看，网盘版是 2.0.6-3.2）；
3. 出问题的具体操作步骤与提示原文；
4. 截图或录屏。

反馈邮箱与会员售后邮箱见 [会员价格与免费版区别.md](会员价格与免费版区别.md) 第五节；想找活人问，官方 QQ 群（`619829395`）、Discord、抖音与 B 站渠道都列在 [分享链接与剪同款模板怎么用.md](分享链接与剪同款模板怎么用.md) 第五节；装包本身有问题则回 [下载与安装教程.md](下载与安装教程.md) 重新核对。
