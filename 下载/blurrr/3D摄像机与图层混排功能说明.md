## 一、有哪些图层类型

按官网口径，支持自由混排的图层包括：**视频、文字、形状、矢量绘制、素材、特效、滤镜、3D 摄像机、空对象**。日常用得多的是这几类：

| 图层 | 干什么用 |
| --- | --- |
| 视频 / 图片 | 主画面素材，可多层叠（画中画、分屏） |
| 文字 | 标题、字幕；文字样式与动画都可打关键帧 |
| 形状 / 矢量绘制 | 遮罩块、装饰图形；钢笔工具画路径 |
| 特效 / 滤镜 | 作用于下层画面；同轨可叠多个、各自调强度 |
| 3D 摄像机 | 让整个场景产生镜头运动（推拉摇移、纵深） |
| 空对象 | 看不见的控制柄，用来带动一堆图层一起动 |

**层级规则就一条：上层盖下层。** 图层顺序在面板里拖动调整；特效、滤镜类图层与目标图层的上下顺序决定它作用到谁，加完特效回放确认作用对象不对就换顺序。

## 二、空对象与父子集：管住一屏元素

一屏有七八个元素要同时缩放位移时，逐个打帧既慢又对不齐。做法是**父子绑定**：

1. 新建一个**空对象**（画面上不显示，只是个坐标点）；
2. 把要联动的图层**设为该空对象的子层**；
3. 之后只给空对象打关键帧 —— 所有子层跟着一起动；
4. 子层自己的动画照常打帧，两者叠加（父层管整体、子层管个例）。

典型用法：标题 + 装饰框 + 角标要整体从左滑入并统一缩放 —— 绑一个空对象，一个关键帧搞定；其中角标额外转个圈，单独给角标加自己的帧。

## 三、3D 摄像机能做什么

开启 3D 摄像机后，工程有了纵深（Z 轴），你可以像真摄像机一样运动：

- **镜头运动**：推近、拉远、环绕、倾斜 —— 给摄像机打关键帧即可（属性与曲线和 [关键帧与曲线编辑教程.md](关键帧与曲线编辑教程.md) 完全同一套）；
- **纵深排版**：把图层沿 Z 轴拉开距离，摄像机一动就产生视差，平面素材立刻有空间感；
- **3D 造型**：官网举的例子包括 3D 隧道、传送带、立方体这类由面片拼出来的结构 —— 它们是图层 + 摄像机配合做出来的，不是建模工具。

**新手建议**：先把 2D 的关键帧玩熟再进 3D。摄像机一动整个场景都在动，层级关系没理顺时你会分不清是「元素在动」还是「镜头在动」。

## 四、随图层一起用的三类增强功能

| 功能 | 作用 | 什么时候用 |
| --- | --- | --- |
| 粒子系统 | 烟花、火焰、飘雪、星空等粒子效果 | 氛围段落；可与图层叠加 |
| AI 动态抠图 | 识别人物/物体轮廓，去背景并支持跟踪 | 换背景、人物与新场景合成 |
| 动漫超分 | 提升低清素材的分辨率 | 素材糊、老视频翻新 |

## 五、图层多了工程变卡怎么办

图层混排是吃性能的大头，卡顿优先这么排：

1. **关掉预览**里暂时不用的效果，或把预览分辨率调低 —— 预览卡不等于导出卡；
2. **4K 素材先代理**：拿低清素材剪，导出时再换回原片（若你的版本提供代理流程）；
3. **减少实时特效层数**：把多个特效合并到调整层，或把强度高的特效只放在需要的片段；
4. 依然卡到不能剪，见 [常见问题与解决方法.md](常见问题与解决方法.md) 里对设备与存储的排查。
