## 一、整体流程就五步

Blurrr 的创作链路是固定的：**新建项目 → 导入素材 → 时间线剪辑 → 加效果 → 导出**。先在脑子里过一遍这五步，遇到不认识的按钮不至于慌。

1. 打开应用，点首页 **开始创作**；
2. 设画幅比例、工程分辨率、帧率，新建项目（三项含义见 [下载与安装教程.md](下载与安装教程.md) 第五节）；
3. 点 **+** 号从相册导入视频、图片、音频，素材会归进项目媒体库；
4. 在时间线上裁剪、分割、变速，叠滤镜、音乐、文字、特效；
5. 导出，存相册或直接分享到平台。

## 二、导入素材与时间线的基本操作

- **导入**：点 + 号选素材。批量导入没问题，导入后素材在媒体库里重复调用，不用每次都翻相册。
- **裁剪与分割**：把播放头拖到要切的位置，用分割把一段切成两段，再把不要的那段删掉 —— 这是最常用的两个动作。
- **多层叠加**：素材不只占一条轨道，视频、图片、文字、贴纸可以叠在同屏不同层，上层盖下层。层级关系想调，拖动图层顺序即可（详见 [3D摄像机与图层混排功能说明.md](3D摄像机与图层混排功能说明.md)）。
- **预览**：编辑器里随时点播放看效果，所见即所得；预览卡不代表导出也卡，先剪完再判断。

## 三、想快速出片：模板与预设

没想法或赶时间时，两条捷径：

- **模板**：进模板中心（或首页的模板入口），挑一个分场景模板点「制作同款」，导入工程后选「进入工程」，把模板里的图文、特效换成自己的素材即可；模板自带的特效图层可以增删、动画节奏可以调。应用内模板区之外，官方分享区还有一批用户发布的工程模板（[blurrrvideo.com/share](http://www.blurrrvideo.com/share)），拿到链接怎么导进应用见 [分享链接与剪同款模板怎么用.md](分享链接与剪同款模板怎么用.md)。
- **预设**：把调好的一组效果存成预设，下次直接套。**使用已保存的预设**：点选视频素材 → 底部功能栏选 **预设** → 点 **导入** → 在列表里选中即自动应用到当前素材。

预设是可复用资产，做一次卡点、调一次色，之后每个工程都能直接调出来，比每次重调省事得多。

## 四、导出与分享

剪完点导出：

- **分辨率**：可选档位从 720p 到 4K。**4K 导出属于会员权益**（官网会员页把 4K 列在 SVIP 权益里），免费版按可用档位导，具体以你账号里实际可选的为准 —— 权益与价格见 [会员价格与免费版区别.md](会员价格与免费版区别.md)。
- **保存与分享**：成片直接存相册，或分享到抖音、微信等平台。

导出慢、卡住、成片有问题，见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 五、新手最容易卡住的三个点

| 卡点 | 怎么办 |
| --- | --- |
| 图层一多就不知道哪层是哪层 | 给每层改个可辨认的名字，从上往下理层级；层级逻辑见 [3D摄像机与图层混排功能说明.md](3D摄像机与图层混排功能说明.md) |
| 想让文字/贴纸动起来但找不到入口 | 用关键帧：选中图层 → 打关键帧 → 改属性 → 再打一个，中间的过渡交给曲线调，见 [关键帧与曲线编辑教程.md](关键帧与曲线编辑教程.md) |
| 想踩 BGM 节奏但手动拖不准 | 用时间重映射 + 节拍标记，见 [变速卡点与时间重映射教程.md](变速卡点与时间重映射教程.md) |

会了这三块，剩下的就是堆素材和练手感了。
