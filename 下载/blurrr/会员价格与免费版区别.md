## 一、免费版能干什么

免费版可以完成完整剪辑流程：新建项目、导入素材、多图层混排、打关键帧与曲线、加特效滤镜、变速、导出成片（按账号内可用的分辨率档位）。**日常发短视频，免费版的边界通常不在功能，而在导出规格与 AI 类功能** —— 具体某项功能是否要会员，以应用内点开时的提示为准。

## 二、SVIP 覆盖什么

官网会员页列出的 SVIP 权益（口径为「全部功能 + 4K 分辨率 + 运动模糊 + AI 补帧」）：

| 权益 | 说明 |
| --- | --- |
| 全部功能 | 官网表述为「Enjoy all the features」，以应用内实际解锁为准 |
| 4K 分辨率导出 | 高清档导出；免费版按可用档位导 |
| 运动模糊（Motion blur） | 动效增强类特效 |
| AI 补帧（AI interpolation） | 慢放补帧，详见 [变速卡点与时间重映射教程.md](变速卡点与时间重映射教程.md) |

会员分 **SVIP** 档位，购买页标注**安卓与 iOS 通用**（for Android & iOS both）—— 一处购买双端生效的具体规则，以购买页当时说明为准。

| 档位 | 标价（美元） |

| 季会员 Seasonal SVIP | $29.99 |
| 年会员 Yearly SVIP | $34.99（划线价 $100） |
| 永久会员 Permanent SVIP | $99.99 |

页面以「限时优惠」形式展示，**划线价与现价都会变，下单前以 [blurrrvideo.com/store](https://blurrrvideo.com/store) 当时显示为准**。

按这份标价，年付折合每月不到 3 美元，比月付划算；如果只是某一期视频需要 4K 或 AI 补帧，周会员（$2.99）做完就停，成本最低。**永久会员与年会员的差别是计费方式**（一次买断 vs 按年续费），下单时看清楚选的是哪种。

## 四、订阅与续费规则

官方订阅服务声明（App Store 应用页所列，其他渠道以该渠道规则为准）：

- **服务名称**：包年 VIP、包年 SVIP；
- 订阅费在确认购买时从你的账户扣除；
- **订阅会自动续费**，除非在当前周期结束前至少 24 小时关闭自动续订；
- 取消续费只停掉下一期，当期剩余时间仍可用。

**iOS 上的取消路径**（官方说明原文顺序）：**设置 → iTunes Store 与 App Store → Apple ID → 查看 Apple ID → 账户设置 → 订阅 → 选中 Blurrr 取消订阅**。安卓侧在应用商店的订阅管理里关（Google Play：`play.google.com/store/subscriptions`）。

买错档位、扣费异常、会员没到账，走会员售后邮箱（见下节），**别在第三方「代充」页面下单** —— 到账与售后都没保障。
