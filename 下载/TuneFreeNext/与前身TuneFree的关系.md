## 一、家族谱系

开发者 GitHub 主页（[GSQZ](https://github.com/GSQZ)，个人站 [sayqz.com](https://sayqz.com/)）上，TuneFree 家族在 TuneFreeNext 之前有两代：

| 产品 | 形态 | 基础 |
| --- | --- | --- |
| TuneFree | 桌面 / Web 端 | 基于 Splayer 二次开发 |
| TuneFree for Android | 安卓端 | 基于 Dso Music 二次开发 |

两代的项目说明都写明是「网易云音乐第三方播放器」——这就是家族底色：围绕一个主流平台的账号体系与曲库做第三方客户端。前代的功能底子（扫码登录同步歌单、每日推荐、私人 FM、云盘歌曲、逐字歌词，软件站对前代的介绍口径）在第三代商店介绍里仍能看到影子：聚合搜索、歌单导入、歌词自定义，一脉相承。TuneFreeNext 顺理成章排在第三代。

## 二、TuneFreeNext 的定位差异

- **曲库更宽**：前两代绑定单一平台生态，第三代的商店介绍改成「聚合各大主流音乐平台的资源」，跨平台搜歌免切换；
- **包名直接表明身份**：`com.sayqz.tunefreenext`，`tunefreenext` 即「TuneFree 的下一代」；
- **形态收在手机端**：这代按商店口径是手机播放器，安装与系统要求见 [下载与安装教程.md](下载与安装教程.md)。

## 三、开发者与家族现状

开发者的个人主页写明：早期跨平台开源项目累计 800+ Star，「现已按合规要求下架」。家族现状一览：

| 项目 | 现状 |
| --- | --- |
| TuneFree（桌面） | 仓库 README 只剩「项目已停止维护」，构建产物与下载链接已移除 |
| TuneFree for Android | 同样停止维护 |
| TuneFreeNext | 官方公告停止一切服务（见 [停运后还能用吗.md](停运后还能用吗.md)） |

网盘里这份 3.0.6（信息记录于 2026-09-24）是它公开分发阶段的版本之一；停运之后官方不再提供任何下载，这份包的核对信息见 [下载与安装教程.md](下载与安装教程.md) 第二节。

还有一个家族传统值得一提：白名单验证。前代的项目说明就写明「为防止项目被滥用，必须先通过白名单验证才能正常使用」，第三代延续了这个机制——它如今的现状见 [停运后还能用吗.md](停运后还能用吗.md) 第四节。

账号能力为什么是网易云一路，见 [账号登录与歌单导入.md](账号登录与歌单导入.md) 第一节。
