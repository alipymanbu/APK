SelfyzAI 的生成类功能都在云端跑，你手机性能再好也帮不上忙；真正决定出图质量的是上传的那张照片。同一功能、同一参数，换一张素材效果天差地别，这是用户反馈里最普遍的落差来源。

## 一、好素材的四条通用标准

1. **分辨率要够**：用相册原图，不要用聊天软件传过一遍的压缩图；截图、翻拍屏幕的照片也属于低分辨率素材；
2. **光线均匀**：脸部受光均匀、没有大面积阴影或过曝，逆光照是重灾区；
3. **正脸优先**：人脸类功能（时光机、肖像工作室、美颜）对正脸敏感，侧脸、低头、墨镜遮挡都会明显打折；
4. **画面元素完整**：人物肢体入镜越完整，跳舞类功能的姿态还原越准。

## 二、按功能对照的素材要求

| 你要用的功能 | 素材建议 |
| --- | --- |
| 照片跳舞（Photo Dance） | 全身或半身、四肢完整无遮挡；坐姿、倚靠姿势容易肢体扭曲 |
| 双人互动（亲吻/拥抱/宝宝预测） | 两张照片角度接近、光向一致；一正一侧、光源相反时脸部容易崩 |
| 魔法时光机 / 肖像工作室 | 清晰正脸，刘海遮眉、大框眼镜会压缩变化幅度 |
| AI 动物融合 | 人照与动物照头部都完整居中 |
| 老照片修复与上色 | 翻拍前把照片裁平，避开玻璃反光，扫平褶皱 |
| 游戏滤镜 / Y2K / 复古风情 | 要求最低，风景、静物、宠物都能套 |

## 三、翻车重灾区清单

- 聊天软件压缩图、社交平台保存的二次压缩图；
- 多人重叠、只有部分人入镜的合影（修集体照闭眼用 Fix Group Photo 是例外）；
- 戴墨镜、口罩或大面积头发遮挡的照片；
- 夜间弱光、明显噪点的照片；
- 本身已经重度美颜过的图（磨皮过头的脸会让 AI 识别不到五官特征）。

## 四、效果不满意时，按这个顺序重试

1. **同一张再跑一次**：生成有随机性，同一输入两次结果可能差异明显；
2. **换模板或风格**：某个模板一直出不好，换相近风格对比，比如动漫不行换 3D 卡通；
3. **换照片**：对照上面两节挑一张新素材，比反复调整参数有效；
4. **提示被拒就换素材，不要原样重试**：素材或自定义提示词触发内容审核时，重复提交不会自己通过，改写描述或换图再试；报错时顺手截图，需要联系应用内客服时用得上。

## 五、把试错成本算进去

免费额度下每项功能每天次数很少，生成失败一般也不退还次数。所以别一上来就拿最重要的那张照片试新功能，先用一张可弃的普通照片把流程跑通、确认这个模板的画风合不合预期，再上正片。次数、订阅与信用点的关系见 [订阅与免费额度说明.md](订阅与免费额度说明.md)。跳舞类功能的模板与操作路径在 [照片跳舞与视频玩法.md](照片跳舞与视频玩法.md)；试过各种素材仍然失败、报错的情况，去 [常见问题与解决思路.md](常见问题与解决思路.md) 对症排查。
