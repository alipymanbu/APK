SelfyzAI 除了让照片跳舞，还有一整组静态编辑功能：从常规的美颜、换背景，到把照片转成动漫或 PS2 游戏画风的风格化处理。这类功能多数是即时出图的，不用像视频生成那样等云端排队。

## 一、面部与美颜

面部编辑器覆盖这些可调项：肤色、年龄观感、表情、性别倾向；美颜部分则是常规套路：

- 去痘痘与瑕疵、磨皮、美白牙齿；
- 换发色（AI Hair 还能试不同发型，先看效果再真去理发）；
- 瘦脸瘦身；
- 试流行妆容：粉底色号、眼影、口红。

试妆与换发型的价值在于「先看再决定」，这些预览不改变原图，导出前随时可以撤销重来。

## 二、身形重塑

在身体编辑里可以调整腰围、手臂等部位的比例，官方称之为身体重塑。调整幅度建议小步来：一次拉太多，背景线条（门框、地砖、扶手）会跟着变形，一眼就能看出修过。

## 三、换背景与 AI 重绘

- **换背景**：内置花海、海边、雪山、城市、田野等主题背景，人物抠出来后直接替换；抠图边缘在头发丝处最容易露馅，选背景时优先选与原图光向一致的；
- **AI 重绘**：圈选画面里不需要的物体（路人、杂物）让 AI 抹掉，也可以用自定义提示词修改照片局部。重绘属于生成类操作，要消耗次数或信用点，免费额度用完时这项会先「点不动」，原因排查见 [常见问题与解决思路.md](常见问题与解决思路.md)。

## 四、肖像工作室与主题风格

Portrait Studio 用预设场景生成专业观感的 AI 肖像：官方页面点名过毕业典礼、K-Pop 偶像、复古时尚等场景；主题风格里有芭比风、霍格沃茨巫师风这类话题模板。这类功能输入 1 张清晰正脸照即可出片，是最省事的「一键换头」路径。

## 六、艺术风格与怀旧滤镜

| 风格 | 效果 |
| --- | --- |
| 动漫 | 把人像转成日式动漫画风 |
| 漫画 | 美式漫画线条感 |
| 3D 卡通 | 皮克斯式立体卡通形象 |
| PS2 游戏滤镜 | 复古老游戏的低多边形质感 |
| Y2K | 千禧年梦幻模糊、朦胧光晕 |
| 复古风情 | 文艺典雅的旧时代色调 |

游戏滤镜与 Y2K 属于整体风格替换，对照片内容没有要求，风景、宠物、静物都能套；动漫和 3D 卡通则只对人脸友好。

## 七、老照片与画质修复

画质类工具做三件事：提高分辨率、给黑白照上色、去掉照片上的划痕折痕。翻拍的老照片先裁平、擦干净玻璃反光再上传，修复效果会好一截。

## 八、一张照片的推荐处理顺序

想让一张自拍既美颜又换背景再转动漫，按这个顺序走返工最少：先做画质修复 → 美颜与面部调整 → 身形重塑 → 换背景 → 最后套艺术风格。每一步都基于上一步的成品，风格化永远放在最后，否则美颜细节会被风格滤镜覆盖。

编辑完的照片与跳舞视频都在应用的作品区统一管理。玩完编辑类想试试动态效果，转到 [照片跳舞与视频玩法.md](照片跳舞与视频玩法.md)；如果发现某项功能消耗的次数比自己预期多，先看 [订阅与免费额度说明.md](订阅与免费额度说明.md) 再决定要不要订阅。生成结果不如预期时，多半是素材没挑对，标准见 [什么样的照片效果好.md](什么样的照片效果好.md)。
