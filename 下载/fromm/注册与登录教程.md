## 一、fromm ONE ID 是什么

fromm 用**邮箱 + 密码**作为账号体系，官方叫 fromm ONE ID。你关注的艺人、订阅订单、客服沟通记录都挂在这个账号下，换手机、重装应用之后也靠它找回数据。注册前准备好一个能正常收信的邮箱就行。

## 二、注册步骤

1. 打开 fromm，在首页点「通过 fromm ONE ID 注册」（不同版本入口文案略有差异，认准「注册 / Sign Up」字样）；
2. 勾选服务条款与隐私政策的同意项，全选后确认；
3. 输入你的邮箱地址，点确定；
4. 去邮箱收 **6 位数字验证码**，填回应用；
5. 设置登录密码，完成注册。

如果流程里出现绑定手机号这一步，注意把默认的国际区号从 +82（韩国）切换成 +86（中国大陆）再填号码；这一步是否强制，以应用当时的流程为准。

## 三、登录与找回密码

- **已有账号**：首页点登录，输入注册邮箱和密码；
- **忘记密码**：在登录页点「忘记密码」，按提示走邮箱重置流程；
- **换手机 / 重装**：在新设备上用同一个 fromm ONE ID 登录即可，关注与订阅信息跟账号走，消息记录官方是云端保存的，登录后可以回看（个别异常情况见 [常见问题与解决办法.md](常见问题与解决办法.md)）。

## 四、注册 / 登录常见卡点

- **验证码邮件没到**：先翻垃圾箱，再等一两分钟点重发，别连续点；
- **提示邮箱已注册**：说明之前注册过，直接走登录或找回密码；
- **密码不通过**：按页面提示的组合设置（长度与字符类型以页面提示为准）。

注册完成之后，想开通和偶像的私信要看订阅，流程与付费方式见 [订阅开通与付费方式.md](订阅开通与付费方式.md)。
