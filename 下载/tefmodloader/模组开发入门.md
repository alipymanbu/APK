## 一、先认清这套体系里的三个名词

| 名词 | 是什么 | 在哪 |
| --- | --- | --- |
| TEFModLoader | 加载器，负责把模组挂进泰拉瑞亚 | 你手机上装的入口 |
| EFMod | 官方定的模组设计标准，MIT 协议 | [https://gitlab.com/2079541547/efmod](https://gitlab.com/2079541547/efmod) |
| .tefmod 文件 | 按这个标准打包出来的模组文件 | Mod管理页里装的就是它 |

写模组，实际是按 EFMod 标准做一个 `.tefmod` 文件，再拿加载器装进游戏验证。

## 二、用什么语言、什么工具

- **语言是 C++**，走 C++20 稳定 ABI，官方标称兼容 NDK / Windows SDK / Linux GCC 这几套编译环境。
- 官方仓库里有 `example` 目录，是从零起步最直接的参照 —— 照着示例工程的目录结构改，比自己从空文件拼快得多。
- 构建系统是 CMake 配 Gradle，官方推荐在 Debian 环境构建；Windows 端需要 Visual Studio 2022 17.8 以上加 CMake 3.29 以上。
- 只是想给游戏加点东西、并不想碰 C++ 的，优先去装别人做好的模组（见[模组安装与Mod管理.md](模组安装与Mod管理.md)），开发是另一条路。

## 四、动手路径建议

1. 把加载器在手机上跑通（流程见[下载与安装教程.md](下载与安装教程.md)），确认你能正常装模组、进游戏 —— 开发环境先建立在「会用人家的东西」之上。
2. 读 EFMod 文档，理解模组的组织方式。
3. 克隆主仓库，打开 `example` 示例工程，编译出第一个 `.tefmod`。
4. 装进加载器验证，再逐步改成自己的内容。

## 五、两个已知的历史坑

- **路径拼写错误**：10.0.0 Beta3.4 以下的所有 Beta 版本，路径里把 `TEFModLoader` 错写成了 `TEFModLoaLoader`。如果你的模组要兼容老版本加载器，官方 README 里给了一段自动修正路径的示例代码；新版本没这个问题。
- **小型模组先起步**：官方公开的实测数据基于 5 MB 以内的小型模组包，大型模组场景社区还在积累。第一个模组从小的做起，验证流程比重做出东西更重要。
