# 和平精英高帧率前置设置

> 和平精英能不能跑出 90 帧，游戏侧还有几道开关要先打开：屏幕刷新率、游戏内画面档位、和平营地的帧率提升。本篇把它们一次列清，再回到工具侧解锁。

## 一、第一道开关：屏幕刷新率

游戏的帧率上限不会超过屏幕刷新率，屏幕停在 60Hz，后面做什么都白搭。先到手机「设置 → 显示与亮度 → 屏幕刷新率」把它拉到最高（各家叫法不同：90Hz / 120Hz / 高 / 智能切换）。

## 二、游戏内的前提档位

进和平精英「设置 → 画面设置」：

- **画面品质选「流畅」**：90 帧档位只挂在流畅画质下，别的画质档里看不到 90 帧；
- **帧数选 90 帧**：菜单里能直接看到这个选项，说明你的机型已被游戏适配；看不到，就是还没适配，接着看下一节。

PUBG MOBILE 国际服同理：Smooth 画质 + 90 FPS 档位，选项是否出现取决于游戏自己的设备白名单，以游戏内实际显示为准。

## 三、菜单里没有 90 帧：和平营地的「帧率提升」

多份第三方画质工具的教程与常见问题页都提到同一个办法：到官方的「和平营地」App 里找到「画质提升」工具，开启「帧率提升」。注意两点：

- 开启的账号要和游戏账号一致；
- **只开「帧率提升」这一项**，画质提升、分辨率提升都别开——有教程把「改完帧率选项消失」「帧率变回 30 帧」归因于开了营地的那几项提升，出这类情况时先把它们关掉再试。

这一步属于游戏侧机制，与 90fps 无关；效果因机型而异，以游戏内实际显示为准。

## 四、回到工具侧

游戏侧开关都打开后，再用 90fps 做解锁，完整顺序是：屏幕刷新率 → 游戏内档位 → 营地帧率提升 → 工具解锁 → 进对局验证。解锁的具体步骤见 [帧率解锁与画质设置教程.md](帧率解锁与画质设置教程.md)，哪一环卡住见 [常见问题排查.md](常见问题排查.md)。
