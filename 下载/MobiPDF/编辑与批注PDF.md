## 一、先分清两种模式

打开 PDF 默认停在查看模式：翻页、缩放、搜索都在这里，界面干扰最少。要改内容，点右下角的编辑图标进入编辑模式，改完保存。

判断用哪个的标准很简单：只看不改用查看模式，要动文件内容才进编辑模式。

## 二、查看模式下能做的事

点屏幕右上角的菜单（三个点），能看到这一排选项（个别项随文件情况出现）：

| 菜单项 | 用途 |
| --- | --- |
| 保存 / 另存为 | 把改动存回原文件，或存到别的位置 |
| 打印 | 连同一网络的打印机直接打 |
| 查找 | 搜文中的字词，结果间可跳转 |
| 导出 | 转成 Word、Excel 或 ePub，详见[格式转换与OCR识别.md](格式转换与OCR识别.md) |
| 保护 | 给文件上密码，见[签名加密与云同步.md](签名加密与云同步.md) |
| 快速签名 | 往页面上盖一个手写签名 |
| 朗读 | 文本转语音，适合通勤时听 |
| 页面视图 | 连续 / 单页 / 双页 / 带封面双页 / PDF 重排几种排布 |
| 夜间模式 | 暗光环境下换成深色显示 |
| 转到页面 | 输页码直达 |
| 大纲 | 一览文件自带的目录、数字签名和批注（文件里本来有才有内容） |

翻页用上下滑动，缩放用双指捏合；点一下屏幕中央可以收起或呼出工具栏。

## 三、编辑：改文字、改图片

进入编辑模式后可以：

- 直接修改 PDF 里的文字。
- 替换、移动页面上的图片。
- 新建一份空白 PDF，从零往里加内容。

有一类文件改不了：扫描件和照片型 PDF 的页面是一整张图，里面没有文本层，文字点不中。这类文件想拿到里面的字，先走一遍 OCR，见[格式转换与OCR识别.md](格式转换与OCR识别.md)。

改文字、替换图片、新建空白 PDF 这一组按官方商店页口径都在付费档，分界表见[免费版与付费版区别.md](免费版与付费版区别.md)。

## 四、批注与标记

不动原文、只做标记的这些事都在批注工具里：

- 高亮、划线这类标重点的手段。
- 加批注评论；批注里显示的作者名可以在设置里改成自己的名字。
- 盖图章、手绘涂写，以及把别的文件作为附件插进这份 PDF。

## 五、整页操作与合并

页面级的整理在编辑模式的页面管理里：

- 重排、插入、删除、提取、复制、旋转某一页。
- 把多份 PDF 合并成一份，比如把几章合成一个完整文件。
- 加书签，标记看到哪一页，下次接着看。

页面重排与合并也在付费档里；免费档做不了这几件事时，先确认分界再动手，见[免费版与付费版区别.md](免费版与付费版区别.md)。

## 六、改完存哪

保存时可以存回原文件，也可以另存到手机目录；登录账号后还能存进 MobiDrive 或 Google Drive、Dropbox、Box，在另一台设备上接着处理，云端的用法见[签名加密与云同步.md](签名加密与云同步.md)。

文件偏大时，官方还提供内置的 PDF 压缩工具把文件压小，压完不影响正常阅读；入口位置随版本而异，找不到就从文件列表的选中菜单里找。
