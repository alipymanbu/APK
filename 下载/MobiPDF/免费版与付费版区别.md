## 一、免费与付费的分界

官方在商店页把功能分成两档，下表按「你想干什么」归类（以官方商店页口径为准，安卓端具体到某一项时以应用内提示为准）：

| 你想干的事 | 免费能用吗 |
| --- | --- |
| 打开、翻页、搜索、缩放、夜间模式 | 免费 |
| 高亮、划线、批注、图章、手绘 | 免费 |
| 扫描纸质件并存成 PDF | 免费 |
| 填表单、手写签名、复用保存过的签名 | 免费 |
| 存进 MobiDrive（5GB）与第三方云盘 | 免费 |
| 改 PDF 里的文字、图片 | 付费 |
| 转 Word、Excel、ePub 等格式 | 付费 |
| 合并多份 PDF、整页重排、插页删页 | 付费 |
| 给文件上密码、加密、数字证书 | 付费 |
| 云空间扩到 50GB | 付费 |

付费档官方标注有 7 天免费试用，试用结束不取消会转成正式订阅。

## 二、订阅档位与覆盖设备

官方用户指南（Windows 版）列出的档位：

- **MobiPDF Pro**：按月或按年订阅，高级编辑与转换可用；官方说明一份订阅覆盖一台 Windows 桌面加最多两台移动设备。
- **MobiPDF Lifetime**：一次性买断，只管一台 Windows 桌面上的基础编辑功能。
- **MobiPDF Free**：免费档，查看与基础文档工具。

价格与在售档位随地区和时间变动，iOS 商店里还能看到按周订阅的档位；比价前以官方定价页为准：[https://mobisystems.com/en-us/mobipdf/pricing](https://mobisystems.com/en-us/mobipdf/pricing)

## 三、判断要不要付费的思路

- 只需要看、批注、扫文件、签个字 → 免费档够用，不用订阅。
- 要改 PDF 正文、批量转格式、给文件上密码 → 这些全在付费档，先开 7 天试用验证它能不能处理你的文件，再决定订不订。
- 订阅经 Google Play 收取并自动续订；取消与退款的做法见[签名加密与云同步.md](签名加密与云同步.md)。

装好后的第一批操作，从[下载与安装教程.md](下载与安装教程.md)开始；转换功能的具体用法见[格式转换与OCR识别.md](格式转换与OCR识别.md)。
