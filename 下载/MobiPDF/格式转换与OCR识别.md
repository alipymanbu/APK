## 一、支持哪些转换方向

| 转换方向 | 说明 |
| --- | --- |
| PDF → Word / Excel / PowerPoint / ePub | 官方标注保留原始排版与格式 |
| Word / Excel / PowerPoint / ePub → PDF | 转成 PDF 再发出去，内容不容易被顺手改动 |
| PNG / JPEG → PDF | 把图片合成 PDF |
| PDF → PNG / JPEG | 把 PDF 页面导出为图片 |

## 二、转换入口在哪

同一件事有三个入口，用哪个看你当时在哪：

- 文件已打开：右上角菜单 →「导出」，选目标格式。
- 在文件列表里：长按文件进入选中状态 → 转换。
- 还没开始：侧边栏「创建文档」→ 转换，把 Word、Excel、ePub 转成 PDF。

不同版本的菜单措辞略有差异，找不到时先从右上角菜单开始找。

## 三、哪些转换要付费

免费版可以看、可以批注；转换和 OCR 属于应用内购买解锁的部分，具体某一项是否免费，以你点开那个功能时应用内的提示为准，别凭网上旧帖判断，完整的分界表见[免费版与付费版区别.md](免费版与付费版区别.md)。订阅经 Google Play 收取并自动续订，取消和管理的入口在 Google Play 账户设置的订阅页。

## 四、OCR：把扫描件变成可复制的文本

1. 打开扫描件或图片型 PDF。
2. 选识别文本（OCR）。
3. 识别完成后，页面上的文字可以选中复制，也可以通过邮件或消息应用直接分享出去。

典型用途：把拍照的合同变成能复制条款的文本；把扫描的发票文字提出来登记。识别质量取决于拍照质量，先按[扫描证件与纸质文档.md](扫描证件与纸质文档.md)里的做法把件扫清楚再识别，返工最少。

动手前先看一眼语言支持：官方的识别语言列表里没有中文，中文文档的应对办法与提高准确率的做法单独整理在[OCR识别语言与准确率.md](OCR识别语言与准确率.md)。

## 五、打印

查看模式菜单里有「打印」：手机和打印机连同一个网络时，可以无线打印整份文件，也可以只打指定的页。打印前用「转到页面」确认一下页码范围，避免整份重打。
