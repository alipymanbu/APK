# MiraPlug 连不上电视或无画面排查

> 插线后手机没弹窗、点了没反应、电视一直黑屏时，按这篇逐环节定位。

## 一、按环节对号入座

整条链路是「供电 → 信号源 → 手机弹窗 → App 授权 → 画面」，哪一环断了就在哪一环停下：

| 现象 | 断在哪一环 | 去哪查 |
| --- | --- | --- |
| 电视一直黑屏/无信号 | 供电或电视信号源 | 第二、三节 |
| 插线后手机毫无反应 | 手机侧弹窗没触发 | 第四节 |
| 手机弹 `No installed apps work with this USB accessory` | App 没装 | 第五节 |
| App 打开了但电视没画面 | 授权没点/模式不对 | 第六节 |

## 二、先看供电

这类投屏配件是「线 + 独立供电」的结构，供电没接电视一定不出画面：

- 用配件原装的 USB 供电线，接到充电头或电视 USB 口；只插数据端不插供电端，多数情况带不动。
- 换一个供电口试试（电视 USB 口输出不足时换充电头更稳）。

## 三、再看电视信号源

- 用遥控器按「信号源 / Source / 输入」，切到插着投屏线的那个 HDMI 口。
- HDMI 口不止一个时逐个试一遍；接在哪个口就切哪个，别凭印象。
- 插拔过线或电视重启过，信号源可能被电视自动切走，重新选一次。

## 四、手机插线后完全没弹窗

1. 确认 USB 端**插紧**：Type-C 口正反插一次，Micro-USB 方向别硬插。
2. 拔掉等 3 秒重插，弹窗一般会在几秒内出现。
3. 之前若勾过「默认打开」或拒绝过，弹窗可能被记住而不再询问：进 `设置 → 应用 → MiraPlug → 打开默认设置`，清除默认后再重插。
4. 换一根数据线/换一台手机交叉试一次，能判断是线、手机口还是配件的问题。
5. 以上都试过仍不弹：重启一次手机再试；还不行就进 `设置 → 应用 → MiraPlug` 清一次缓存/数据（会清掉「默认打开」记录），或直接卸载重装——这几步是安卓上「授权弹窗不出现」的通用处置，多数卡在记住的拒绝记录上。

各条弹窗的原文与点法逐条列在 [界面与常见提示语对照.md](界面与常见提示语对照.md)。

## 五、弹的是 `No installed apps work with this USB accessory`

这是安卓系统的原话：手机上**没有能接管这个 USB 配件的应用**——即 MiraPlug 还没装。处理：

1. 点提示里的 `View`，按引导跳转下载页安装；
2. 或者直接装本地这份：[MiraPlug 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f6ef4385b4e4)（版本信息见 [下载与安装教程.md](下载与安装教程.md)）；
3. 装好后拔线重插，弹窗就会变成「是否打开 MiraPlug」。

## 六、App 开着但电视没画面

- 有没有点 `START NOW`：没点这个授权，电视端永远是黑的；界面停在 `Please Wait...` 就多等几秒。
- 配件是否切到 Plug&Play 模式：用针按一下小孔里的按钮再重插（见 [投屏连接步骤.md](投屏连接步骤.md)）。
- 画面出来但没声音是另一类问题，走 [投屏没有声音的解决方法.md](投屏没有声音的解决方法.md)。

逐项试完仍不出画面，用另一台手机接同一套配件做交叉验证：换手机就好了，问题在原手机的系统/权限；换手机一样黑，问题在线缆或配件本身。
