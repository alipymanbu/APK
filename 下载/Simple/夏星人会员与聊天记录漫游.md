## 一、夏星人是什么、怎么买

夏星人是 Simple 的官方付费会员，官方页面里「夏星人」「守望者」两个叫法都出现过，指同一套体系。购买路径：

1. 打开 Simple，进入「我的」页面。
2. 点「守望者」按钮。
3. 选 1 / 3 / 12 个月其中一个档位，支付成功即开通。

付费与续费口径（以 App 内收费界面为准）：

| 项目 | 口径 |
| --- | --- |
| 价格 | 基准约 28 元/月，具体档位价以客户端展示为准（截至本文检索时） |
| 档位 | 1 个月 / 3 个月 / 12 个月 |
| 自动续费 | 官方未开通自动续费，到期不续费就自动恢复普通用户 |
| 退款 | iOS 用户找苹果（App Store 退款流程），不经过应用方 |

## 二、iOS 用户特有三个坑

官方会员 FAQ 里专门给 iOS 用户写了三条提醒，用安卓没这些事，用 iPhone 先看这里：

1. **一个 Apple ID 只能绑一个账号**：同一个 Apple ID 给第二个 Simple 账号购买夏星人时，原先进号的那个会话会员会**自动失效**。家里多人共用一个 Apple ID 的要特别注意。
2. **改套餐时弹「未购买成功」是假警报**：在特权续费界面直接点选新档位（比如从 1 个月改 12 个月）就行，不需要先取消订阅；系统可能弹「未购买成功」的提示，官方明确说明此时更改其实已经成功，不用重复付款。
3. **也可以走系统订阅页改**：设置 → Apple ID → 查看Apple ID → 订阅 → 选 Simple → 选所需档位。

另外，**付款成功但会员没生效**：先杀掉 App 重新打开；还不行就通过小红书官方账号「Simple App」反馈（客服渠道详见 [常见问题与安全提醒.md](常见问题与安全提醒.md)）。

## 三、会员权益清单

夏星人的权益共六项，官方列法如下：

| 权益 | 说明 |
| --- | --- |
| 自定义主页封面 | 普通用户不能改主页封面图 |
| 表情包收藏上限 300 | 免费用户的收藏上限更低 |
| 主页置顶动态 6 条 | 免费用户置顶数量更少 |
| 自定义聊天背景 | 单独设置与某人的聊天页背景 |
| 黄钻标识 | 昵称下方显示会员标识 |
| 聊天记录云漫游 | 六项里唯一涉及数据安全的，下节单独讲 |

前五项都是个性化装扮类。是否值得为它们付费，取决于你在不在意这些展示细节；对多数只想安静交朋友的用户，免费功能的完整度已经够日常使用。

## 四、聊天记录云漫游：开启方法与规则

Simple 的聊天记录默认只存在手机本地，删了 App 或换手机就没了。云漫游是官方给的云端备份方案，但它是会员权益，而且**必须主动开启**——买了会员也不会自动开始同步。

**怎么开**：在聊天管理页面里对单个好友开启消息漫游（入口在对应聊天的设置里）。

**怎么同步**：开启后在新设备上进入聊天管理页，**下拉刷新**即可把云端消息同步到本地；同步后本地消息没更新的，杀掉 App 进程重新进。

**规则（官方原文口径，逐条列清）**：

1. 只漫游**开启之后**产生的聊天内容；开启前的记录只存在当时的设备上，换设备无法找回。
2. 关闭云漫游后立即停止同步，**已同步的历史消息会立刻清空**；重新开启后只同步重开之后的内容。
3. 会员过期后停止同步，云端消息保留 **7 天**；7 天内重新购买则历史消息保留，超过 7 天清空。
4. 云端最长保存 **3 个月**内的聊天信息。
5. 只同步文字、语音、图片、视频、表情类消息，系统消息等不同步。
6. 网络不稳定时可能部分记录漫游失败，属于官方承认的已知情况。

**换手机的正确顺序**：

1. 在旧手机上对重要聊天的对象逐个开启云漫游，并保持会员有效。
2. 等待同步完成（下拉刷新确认）。
3. 新手机登录同一账号，进聊天管理页下拉刷新同步。

没买会员的替代方案只有一个：重要对话提前截图。账号与登录的相关操作见 [注册登录与账号设置.md](注册登录与账号设置.md)；安装环节见 [下载与安装教程.md](下载与安装教程.md)。
