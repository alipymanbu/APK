# SimpleTV 使用方法与频道操作

> SimpleTV 属于「打开即看」型的电视直播应用：装完点开就是直播画面，没有要先填的配置。本篇讲打开后的频道构成、遥控器与触屏操作、频道源什么时候需要手动更新，以及一个买定离手的边界——不支持自己导入直播源。

## 一、打开就能看

第一次点开应用会先初始化频道列表，随后直接进入直播画面，中间没有要你注册登录、也没有要填的源地址。你唯一要确认的是网络：普通宽带能看一部分台，另一部分台需要 IPv6（详见 [部分频道看不了怎么解决.md](部分频道看不了怎么解决.md)）。

如果第一次打开就停在「初始化频道列表失败，请尝试手动更新或退出重试」，不用怀疑安装包有问题，先按排查篇的手动更新步骤走一遍。

## 二、频道构成

按项目页的频道展示，频道大致分这么几类：

| 类别 | 例子 |
| --- | --- |
| 央视 | CCTV-1 综合等央视频道 |
| 卫视 | 湖南卫视等各省卫视 |
| 地方台 | 湖北经视这类城市 / 省级地方频道 |
| 特色频道 | CHC 高清电影、NewTV 军事评论等轮播类频道 |

有两点提前说清楚，免得用的时候产生错误预期：

1. **频道列表不是固定的**。频道源来自社区维护的公共 IPTV 源项目（项目页致谢里列了 [github.com/Meroser/IPTV](https://github.com/Meroser/IPTV) 与 [github.com/fanmingming/live](https://github.com/fanmingming/live)），源项目增删频道，你这里的列表就会跟着变；哪个台长期打不开，多半是那路源失效了，等应用更新即可。项目页也注明这些素材来自互联网、仅供测试研究。
2. **不能自己加源**。SimpleTV 内置源、定期更新，没有提供导入 m3u / txt 自定义直播源的功能。如果你想要「自己找源、自己维护订阅」的玩法，需要另选支持自定义源的播放器类应用，SimpleTV 不是那类工具。

## 三、遥控器与触屏操作

界面按电视遥控器的使用习惯设计，方向键选台、确认键呼出频道列表这类操作和常见电视应用一致；项目页的操作说明以小米遥控器为例给了按键图示，你手上是什么盒子就按它的遥控器实际响应来，按键布局略有差异不影响使用。

在手机上则是普通触屏操作：滑动选台、点频道名切换。同一个包在两类设备上的频道内容一致，区别只在操作方式。

## 四、手动更新频道源

应用自带「手动更新频道源」的入口。需要更新频道的典型时机：

- 打开应用提示**「初始化频道列表失败，请尝试手动更新或退出重试」**；
- 频道列表能出来，但**成片频道的播放失败**、连续转圈。

操作路径就是应用内设置里的更新频道源（项目页 FAQ 配了操作截图）。要点是：**更新成功后要退出应用再重新进入，新列表才生效**。如果更新本身就失败，先确认设备当前网络是否连通，再重试。

更新之后仍然打不开某个台，就不是你操作的问题了，按排查篇的三步走：[部分频道看不了怎么解决.md](部分频道看不了怎么解决.md)。
