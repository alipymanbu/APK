# SimpleTV 下载与安装教程（手机 / 平板）

## 一、先确认你的设备

SimpleTV 只有一个安装包，手机、平板、电视盒子装的是同一个 APK，不用分「手机版」「电视版」分开下载。

设备要求只有一条：**安卓 6.0 及以上**（来自项目页说明）。你的手机在「设置 → 关于手机」里能看到安卓版本，低于 6.0 的设备装不上。

如果你要装的是电视盒子或智能电视，安装方式和手机不一样（涉及 U 盘、远程推送或 ADB），直接看 [电视盒子上怎么安装.md](电视盒子上怎么安装.md)。

## 二、获取安装文件资源

安装包通过夸克网盘分享获取，不需要去任何应用商店搜索：

1. 打开上面的 **SimpleTV 安装文件资源（夸克网盘）** 链接；
2. 把文件转存到自己的网盘（需要先登录或注册夸克账号），再从网盘下载到手机；
3. 下载得到一个 `.apk` 文件，就是安装包本身。

网盘里这一份安装包的实际信息：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.3 |
| 包名 | com.ww.simpletv |
| 安装包大小 | 20.75M |
| MD5 | CD67383D55FD9D498EFEC851A79119E4 |

下载完成后，如果你在乎包的完整性，可以用文件管理器的属性页或校验工具算一下 MD5，与上表一致说明文件没坏。项目后续还有更新的版本（截至 2026-09 检索时见到 1.0.8 的发布记录），是否追新版以项目页 [gitee.com/hackrol_admin/mytv](https://gitee.com/hackrol_admin/mytv) 的说明为准。

## 三、在手机上安装

1. 在文件管理器里找到刚下载的 `.apk`，点它；
2. 系统会弹「是否允许此来源安装应用」之类的提示——因为 SimpleTV 不在任何应用商店上架，安卓默认拦截商店之外的安装来源。选「允许」「仍然安装」即可；也可以在弹出前先去「设置 → 应用 → 特殊权限 → 安装未知应用」，给你用的文件管理器（或浏览器）勾上允许安装的权限，一次性解决；
3. 等进度条走完，点「打开」。

装好后的第一次启动会初始化频道列表，通常几秒内直接进入直播画面。如果第一次打开就报「初始化频道列表失败」，处理步骤在 [部分频道看不了怎么解决.md](部分频道看不了怎么解决.md)。

## 四、安装时可能碰到的提示

- **「检测到病毒」或 Play Protect 拦截**：安卓对不上架商店的 APK 常有这类提示，属于来源提示，不代表包一定有问题。稳妥的做法是核对上表的 MD5 与文件大小是否一致，确认拿到的是同一份包后再决定继续安装。
- **「解析包时出现问题」**：多半是下载没下完整，重新下载一次再装；也检查一下手机剩余存储空间。
- **装完点开闪退**：先确认安卓版本达到 6.0；还是不行就卸载重装一次，仍不行可到项目页反馈。

装好之后怎么换台、怎么更新频道源，看 [使用方法与频道操作.md](使用方法与频道操作.md)。
