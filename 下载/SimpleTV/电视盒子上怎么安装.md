# SimpleTV 电视盒子安装教程（U 盘 / 当贝市场 / ADB）

> SimpleTV 的安装包在电视盒子、智能电视上和手机通用，但电视上没法直接用浏览器下载 APK，项目页给了三种安装方式。本篇按你的设备情况帮你选一种，并给出每种的步骤。

## 一、三种方式怎么选

| 方式 | 前提 | 适合谁 |
| --- | --- | --- |
| U 盘安装 | 一个 U 盘 + 一台能拷文件的电脑或手机 | 绝大多数盒子与电视，最通用 |
| 当贝市场远程推送 | 盒子和手机都装了当贝市场 | 不想拔插 U 盘、家里已有当贝市场 |
| ADB 安装 | 电脑 + 会用命令行 | 手上没有 U 盘、愿意折腾的开发型用户 |

三种方式装的都是同一个安装包（版本、包名等信息见 [下载与安装教程.md](下载与安装教程.md) 的信息表），装完效果没有区别。电视上的系统要求同样是安卓 6.0 及以上。

## 二、U 盘安装

1. 先在电脑或手机上，通过上面的 **SimpleTV 安装文件资源（夸克网盘）** 链接把 `.apk` 下载下来，拷进 U 盘；
2. U 盘插到盒子或电视的 USB 口；
3. 在电视上打开自带的「文件管理」「媒体中心」之类应用，找到 U 盘里的 APK 文件，选中安装；
4. 弹出「禁止安装未知来源应用」提示时，进「设置 → 安全」把「允许安装未知来源应用」或「未知来源」打开，再回来装一次。

**TCL 电视的特例**：TCL 的系统会屏蔽 U 盘里的 APK 文件，在普通文件管理器里根本看不到它。项目页给的处理办法是用 TCL 自带的系统应用进入 U 盘安装（TCL 系统里的电视卫士类应用提供 U 盘安装入口），具体入口名称以你的 TCL 系统版本显示为准。

## 三、当贝市场远程推送

当贝市场是电视端常用的应用商店，它自带的「远程推送」功能可以把手机里的安装包直接发到电视上，全程不需要 U 盘：

1. 盒子和手机都安装当贝市场（手机端装「当贝市场」的配套应用即可）；
2. 在盒子上的当贝市场里进「管理」界面，找到「远程推送」；
3. 用手机扫码登录推送页面，点击上传文件，把提前下载好的 SimpleTV APK 从手机传上去；
4. 传输完成后电视端会提示安装，确认即可；同样可能需要先允许未知来源安装。

推送连不上时先查一件事：**手机和电视必须连同一个 WiFi**，这是远程推送能工作的前提，不在一个网络里扫了码也连不上。除了扫码，电视端还会显示一个网址，用手机或电脑浏览器打开它、走「上传文件」流程，效果一样——家里没有 U 盘时，用电脑浏览器推送也很顺手。

## 四、ADB 安装

适合手边没有 U 盘、但电脑上装了 ADB 工具的情况。前提：电视打开开发者模式并允许 USB / 网络调试（入口通常在「设置 → 关于」里连按「版本号」或「产品型号」几次解锁开发者选项），电视和电脑连同一个网络。

```bash
# 1. 让电脑连上电视（IP 在电视的网络设置里能看到）
adb connect 192.168.1.100:5555

# 2. 安装 APK（路径换成你电脑上 APK 的实际位置）
adb install SimpleTV_v1.0.3.apk
```

出现 `Success` 就是装完了，在电视的应用列表里找得到。不同品牌盒子的调试端口可能不是 5555，以设备说明为准。

## 五、装完先做这两件事

1. 打开 SimpleTV，等频道列表初始化完成，直接选台看；
2. 如果多数频道都转圈或报「播放失败」，大概率不是装错了，而是网络条件不满足——部分频道只有 IPv6 网络能看，排查步骤见 [部分频道看不了怎么解决.md](部分频道看不了怎么解决.md)。

日常换台、更新频道源的操作见 [使用方法与频道操作.md](使用方法与频道操作.md)。
