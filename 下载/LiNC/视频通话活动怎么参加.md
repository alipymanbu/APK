## 一、活动长什么样

LiNC 上的艺人间接互动主要有两类：1:1 视频通话（Meet & Call / Relay Call）与双人合影（Two-Shot，和艺人同框拍照留念）。两类活动都在应用内的活动房间（Event Room）进行，票从活动页购买。

## 二、购票规则

官方活动页列出的通行规则如下（个别场次可能有差异，以活动页说明为准）：

| 项目 | 规则 |
| --- | --- |
| 单张票 | 1 分 30 秒通话时长 |
| 单账号上限 | 8 张（8 张 = 12 分钟） |
| 时长累加 | 2 张 3 分钟、4 张 6 分钟，以此类推 |
| 取消/退款 | 开演前 72 小时内不可取消；退改找客服 |
| 入场方式 | 售票截止后，官方发含入场码的参与邮件 |
| 通话地点 | LiNC 应用内的活动房间 |

购票前必须先把昵称设好——艺人按昵称称呼你；购票截止后再改昵称，可能无法参加活动。

## 三、通话当天

- 提前进入 LiNC 应用的活动房间，应用内会有现场公告。
- 保证网络稳定；提前在系统设置里允许相机与麦克风权限。
- 参与邮件（含入场码）发到注册邮箱，售票截止后才发出；到时候没收到，先确认登录的还是当初购票的那个账号——登录方式选错会看到另一个空账号，排查见 [订阅记录不见怎么办.md](订阅记录不见怎么办.md)。
- 通话顺序与开始时间可能根据进度调整，人不在就可能错过自己那一场。
- 没接通时官方会重拨，最多 3 次；3 次都未到场按取消处理，不退款。
- 艺人来电一直连不上：保持登录状态，重启应用再等。
- 聊天消息看不懂：去 Settings → Language → Translation 设置翻译语言。

## 四、常见失误清单

| 失误 | 后果 |
| --- | --- |
| 购票截止后才改昵称 | 可能无法参加活动 |
| 错过通话时间 | 重拨 3 次未到场按取消处理，不退款 |
| 没给相机/麦克风权限 | 通话画面或声音异常 |
| 网络不稳 | 掉线，白白消耗有限的通话时长 |
| 没留意参与邮件 | 找不到入场码，进不了活动房间 |

## 五、没有票怎么办

热门艺人的场次经常直接售罄（活动页显示 Sold out）。可以留意官方的后续场次，或者转向其他互动形式：私信订阅是长期通道，日常应援消耗的积分攒法见 [粉丝积分怎么攒.md](粉丝积分怎么攒.md)。还没装应用的，从 [下载与安装教程.md](下载与安装教程.md) 开始。
