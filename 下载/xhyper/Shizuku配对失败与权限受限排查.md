# Shizuku 配对失败与权限受限排查

## 一、先分清卡在哪一段

Shizuku 的启动链路是「配对 → 启动服务 → 授权应用」，不同环节的故障现象不同，对号入座：

| 你看到的现象 | 大概率原因 | 看哪一节 |
| --- | --- | --- |
| 一直显示「正在搜索配对服务」 | 后台被限制，访问不了本地网络 | 第二节 |
| 点「输入配对码」后立刻提示失败 | 通知权限没给，或配对码过期 | 第三节 |
| 服务起来了但提示 adb 权限受限 | 没开「USB 调试（安全设置）」 | 第四节 |
| 用着用着 Shizuku 自己停了 | 省电策略把后台服务杀了 | 第五节 |

## 二、一直「正在搜索配对服务」

Shizuku 官方手册对此的解释：搜索配对服务需要访问本地网络，而许多厂商会在应用退到后台后就禁止它访问网络。处理顺序：

1. 到系统设置里允许 Shizuku 在后台运行——小米机型的位置是「应用设置 → Shizuku → 省电策略」，改成「无限制」；
2. 手机保持连接 Wi-Fi，无线调试走的就是本地网络，用流量不行；
3. 仍然搜不到就把「开发者选项 → 无线调试」关掉再打开，重新走一遍配对。

## 三、输入配对码后立刻失败

两个高频原因，先查第一个：

1. **Shizuku 的通知权限没给**。配对码要填进 Shizuku 弹出的通知里的输入框，通知被系统拦掉这一步就直接失败——小米（MIUI / 澎湃OS）机型尤其常见，去「通知管理」把 Shizuku 的通知打开再试；
2. **配对码过期**。配对码每次打开配对界面都会刷新，旧的 6 位码立即作废。关掉手机上的配对弹窗重新点「使用配对码配对设备」，趁新弹窗开着尽快把码填进去。

## 四、提示 adb 权限受限

这是小米机型的特有限制：MIUI / 澎湃OS 默认限制 adb 权限，Shizuku 服务能启动但拿到的权限是残缺的。处理办法是回「开发者选项」，把 **「USB 调试（安全设置）」** 也打开——它和普通「USB 调试」是两个开关，只开后面那个不够。XHyper 要做的系统级操作恰好依赖这一层，这个开关没开时授权就算成功，功能开关也照样不生效。

## 五、Shizuku 用着用着自己停了

同样是后台限制：系统省电策略把 Shizuku 的后台服务回收了。把它的省电策略设为「无限制」（或加入省电白名单）可以避免反复被杀。服务被杀后 XHyper 会跟着提示未授权，这不是授权丢了，重新启动 Shizuku 就能恢复。

## 六、Android 11 以下的机器

无线调试这种启动方式只适用于 Android 11 及以上版本；更低的版本需要连电脑、用 Google 官方的 SDK Platform Tools 里的 adb 命令来启动 Shizuku，具体步骤以 [Shizuku 官方手册](https://shizuku.rikka.app/guide/setup/) 为准。装好 Shizuku 后回到 [Shizuku授权与无线调试配对.md](Shizuku授权与无线调试配对.md) 继续授权 XHyper。
