## 一、装好了、也打开了，但功能点了没反应

按概率从高到低排查：

1. **Shizuku 服务没在跑**：打开 Shizuku 看主页状态，显示「未运行」就先启动它；
2. **授权关系没建立**：Shizuku 的「已授权应用」列表里要有 XHyper，没有就把 XHyper 完全退出重开一次；
3. **调试开关没开全**：回开发者选项核对「USB 调试」和「USB 安全设置」两项都开了——只开 USB 调试、没开 USB 安全设置，是最常见的漏项，XHyper 要的系统层操作恰好卡在这一层；
4. **Shizuku 本身起不来或配对失败**：一直搜不到配对服务、输配对码立刻失败、提示 adb 权限受限，这些故障的逐项解法在 [Shizuku配对失败与权限受限排查.md](Shizuku配对失败与权限受限排查.md)。

前三步排查的完整操作在 [Shizuku授权与无线调试配对.md](Shizuku授权与无线调试配对.md) 第二到五节。

## 二、手机重启后提示未授权

这是正常现象，不是坏了：无线调试方式启动的 Shizuku 服务不跨重启存活，服务一停，XHyper 拿到的权限就没了。

处理办法只要两步：重新打开开发者选项里的「无线调试」→ 打开 Shizuku 点「启动」。不用重新配对（配对关系系统会记住），也不用重新授权 XHyper。

## 三、有些应用冻结不了

1.1 版确实存在冻结不生效的组件，官方教程对此给的办法很直接：**冻结不了的改用卸载解决**。操作路径是底部中间入口进应用详情列表，对目标应用直接执行。

卸载前留一个心眼：不确定这个组件管什么的，先搜一下包名再动手；系统核心组件（电话、短信、相机这一类）误删会引起功能异常，拿不准就放着。

## 四、一键优化里找不到禁止云控

不是你漏了，是 1.1 版的一键优化**本来就不包含**禁止云控这一项，官方说明里明确写了它属于后续推送的内容。现阶段想处理云控相关组件，只能到应用详情列表里手动冻结或卸载。

## 五、改过设置之后想全部退回去

XHyper 对它做的每类改动都给了对应的还原入口，对着下表找：

| 你动过的东西 | 去哪里还原 |
| --- | --- |
| 一键优化的一组调整 | 主界面的「还原」 |
| 单个进程的留存策略 | 进程设置里逐项还原 |
| 隐藏的 HD 标识 | 「还原 HD」 |
| 禁用的系统更新 | 系统更新开关的「恢复」 |

还原之后如果某项没立刻变回去，重启一次手机即可。

## 六、想换新版本或重新安装

XHyper 处于公测阶段，版本迭代会比较频繁，旧包卸载后装新包即可，授权关系不受影响（Shizuku 那边认的是包名 `com.itos.xplanforhyper`）。需要安装包的话，用 [XHyper 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5945cdc629c6) 里的这份；之后的版本出来后以官方发布渠道的说明为准。

从公开渠道的信息看，2.x 版本已经补上了 1.1 还缺的那几块：温度监控、禁止云控入口、垃圾清理都出现在 2.x 的功能列表里（截至本文写作时各渠道展示的最新版为 2.1）。你手上这份 1.1 没有这些功能是正常的，要不要升级、升级到哪一版，以官方发布说明为准。
