## 一、这套操作在解决什么问题

PicEncrypt 的加密结果**仍然是一张图片文件**，但像素已经被打乱，用相册、聊天软件预览都会显示成一团乱码，看不出原内容；只有在 PicEncrypt 里输入正确的密钥，才能把它还原成原图。整个过程在手机本地完成，不上传服务器。

适合你处理这几类图：不想让别人随手翻到的私密照片、需要发给特定人但不想中途被截屏看懂的设计稿、以及论坛/社交平台上「给一串数字自己去解」的互动图。

## 二、加密：五步

1. 打开 PicEncrypt，点**添加照片**。
2. 在相册里选中要加密的图片（支持批量多选），选中后回到主界面能预览到这张图。
3. 选择**压缩系数**。这是加密前对图片做压缩处理的程度选项，取值会影响加密后文件的大小；拿不准就保持默认档位，先用一张废图试出自己满意的组合。
4. 输入**密钥**。这里的密钥不是随手打的字母密码，而是一串**带小数点的数字**，例如 `0.168437`（界面会校验格式，格式不对不让点加密）。
5. 点**加密**。完成后会生成一张像素被打乱的图，保存在应用给出的位置；这张图可以用相册、微信、论坛正常发送和展示，别人看到的就是乱码。

界面上还提供「行（多线程）」这类处理模式选项，它的处理速度更快，但输出效果可能和默认模式略有差别 —— 要发给别人的内容建议固定用一种模式，别混着来。

## 三、解密：还原原图

1. 在 PicEncrypt 里添加那张被加密过的乱码图。
2. 输入加密时用的**同一串密钥**，点**解密**。
3. 还原成功会直接显示原图，再保存回相册即可。

几个必须记住的点：

- **密钥必须逐位一致**。`0.168437` 和 `0.168473` 是两把完全不同的钥匙，错一位还原出来还是乱码。
- **图片必须是原图**。加密图在传输、上传过程中一旦被压缩（聊天软件默认压缩发图、截图、二次保存），像素数据变了就可能解不开。发送时一定选「原图」，详见[加密图片发给对方打不开怎么办.md](加密图片发给对方打不开怎么办.md)。
- **密钥丢了就找不回**。PicEncrypt 没有找回机制，密钥是唯一凭证，怎么处理见[忘记密钥或闪退怎么办.md](忘记密钥或闪退怎么办.md)。

## 四、密钥怎么设才好用

密钥只能你自己保管，应用不会替你记。下面几条是实际可执行的做法：

| 做法 | 原因 |
| --- | --- |
| 记在只有你能看到的地方（密码管理器、手写备忘） | 忘了就等于这张图永久变乱码 |
| 同一批图用同一串，不同用途分开 | 方便记忆，也避免一把密钥泄露波及全部 |
| 别用生日、手机号改的小数 | 看到乱码图的人如果认识你，猜起来成本很低 |
| 定期换新密钥加密新图 | 旧图继续用旧密钥还原即可，互不影响 |

## 五、加密前后的自查清单

- [ ] 选的是要加密的那张原图，不是缩略图或截图
- [ ] 压缩系数与处理模式记下来了（下次还原用同样设置）
- [ ] 密钥已写进你的存档，且和界面输入完全一致
- [ ] 加密后的图先自己解一遍，确认能还原再发出去
- [ ] 发送时选「原图」发送

自查里任何一条没过，先别急着删原图 —— 保留原图直到你确认加密图能独立还原为止。
