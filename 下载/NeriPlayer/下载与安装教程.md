## 一、这是个什么应用

NeriPlayer（界面里的中文名叫「音理音理!」）是一个开源的原生 Android 音频播放器，源码在 [github.com/cwuom/NeriPlayer](https://github.com/cwuom/NeriPlayer)，采用 GPL-3.0 许可。这个应用不自建曲库：把你自己的网易云音乐、哔哩哔哩、YouTube Music 账号接进来在线播放，同时管理手机本地的音频文件；歌单、播放记录默认留在本机，另有一套可选的同步方案（见 [GitHub同步备份与换机迁移.md](GitHub同步备份与换机迁移.md)）。

适合的人：手上既有在线平台歌单、又存了一批本地无损音频，不想在好几个音乐应用之间来回切换。

## 二、网盘里那份包的信息

网盘里这份安装包的事实如下（截至 2026-09-23，网上各下载站的「最新版」可能是别的版本，别拿来对照）：

| 项目 | 值 |
| --- | --- |
| 版本 | 95a21a6.01041213 |
| 包名 | moe.ouom.neriplayer |
| 大小 | 10.47M |
| MD5 | AF6CD7ED1D6153A997750655B5213BBA |
| 文件名 | NeriPlayer_v95a21a6.01041213.apk |

**版本号怎么读**：`95a21a6` 是构建时的代码提交短哈希，`01041213` 是构建时间（月日时分）。官方发布页的标签也是这个格式（如 `NeriPlayer-8a1b999.04022058`），所以**版本号不能按字典序比新旧**——想知道自己是不是最新版，以 [GitHub Releases 页面](https://github.com/cwuom/NeriPlayer/releases) 当时显示为准。

## 三、系统要求

- **系统版本**：官方仓库标注 Android 9（API 28）及以上。部分第三方下载页写的是「安卓 4.3 / 5.2 以上」，各处写法不一致，装之前以官方仓库说明为准。
- **处理器架构**：官方发布页提供多个架构包——大部分手机选 arm64-v8a，32 位老机型选 armeabi-v7a，x86 面向模拟器。网盘里这份是单个 APK 文件，下载后直接安装即可。

## 四、从网盘获取并安装

1. 打开 [NeriPlayer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cebecf416ea2)，把文件夹转存到自己的网盘，再把里面的 `.apk` 下载到手机（先下到电脑再传过去也一样）。
2. **校验文件（可选但推荐）**：比对文件名、大小是否与第二节的表格一致；想进一步确认，在电脑上用系统自带的哈希工具算一下 MD5：

```powershell
certutil -hashfile "NeriPlayer_v95a21a6.01041213.apk" MD5
```

算出来的值与表格里的 MD5 对不上，说明文件在传输中损坏或被换过，重新下载再说。

3. 在手机上点开这个 APK。系统会拦一道「禁止安装未知来源应用」——不同品牌路径不一样，一般在 **设置 → 安全 / 安装未知应用** 里，给文件管理器或浏览器授一次权，然后继续安装。
4. 装完打开。首屏是免责声明页，要等几秒才能点继续，点一下就进主界面了。

## 五、装不上或装完打不开

| 现象 | 原因与处理 |
| --- | --- |
| 提示「解析包时出现问题」 | 系统版本低于要求，对照第三节；也可能是下载不完整，重新下一次 |
| 提示「应用已安装」/ 签名冲突 | 手机上已有同包名但签名不同的旧版，先卸载旧版再装（会丢本机数据，先看 [GitHub同步备份与换机迁移.md](GitHub同步备份与换机迁移.md) 里的备份方法） |
| 装完一点就闪退 | 多半是系统兼容或数据问题，按 [常见问题排查.md](常见问题排查.md) 逐条试 |
| 想换回旧版本 | 不建议直接降级：官方更新日志明确数据库升级后降级会导致崩溃，换版本前先做备份 |

装好之后，怎么搜歌、怎么放歌，见 [搜索音乐与在线播放.md](搜索音乐与在线播放.md)。
