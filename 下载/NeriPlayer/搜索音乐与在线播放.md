## 一、先认识界面

打开应用，底部有四个页签：**首页**、**探索**、**媒体库**、**设置**。

- **首页**：直接给一批推荐歌单（封面点进去就是播放列表），想随便逛逛从这开始。
- **探索**：搜歌就在这，带平台标签与分类标签。
- **媒体库**：你自己的歌单和本地音乐，见 [歌单管理与本地音乐导入.md](歌单管理与本地音乐导入.md)。
- **设置**：登录账号、调选项、备份同步都在这。

## 二、在线能力从哪来

这个应用不自建曲库，**在线播放、搜索、访问平台歌单这些能力来自你自己平台账号的授权**：你在设置里登录网易云音乐、哔哩哔哩等平台的账号，才能读到自己的收藏和歌单。登录入口在 **设置 → 登录三方平台**，按页面给的方式（扫码或账号验证）完成授权即可，登录后平台侧的歌单会同步进来。

不登录也能打开应用、浏览首页推荐；要稳定地搜索、播放、看到自己的收藏，把账号授权配上是最稳的方式。

## 三、怎么搜一首歌

1. 切到 **探索** 页，点页面上方的搜索框。
2. 输入歌名或歌手名，回车出结果。
3. 结果上方有**平台标签**（如网易云、哔哩哔哩等），点标签就换一个来源看同一关键词的结果——一首歌在这个源搜不到、换个标签常有。
4. 也可以用**分类标签**（流行、ACG、影视原声这类）先缩小范围再挑。

搜到后直接点条目就进播放页；有的结果需要你再点一下播放按钮才开始出声，取决于条目来自哪个平台。

## 四、播放页能做什么

点正在播放的封面进入全屏播放页，你会看到这些：

| 位置 | 作用 |
| --- | --- |
| 中间大按钮 | 播放 / 暂停 |
| 左右箭头 | 上一首 / 下一首 |
| 进度条、音量条 | 拖动跳转、调音量 |
| 循环模式按钮 | 在单曲循环、列表循环、随机、顺序播放之间切换（以图标当前样式为准） |
| 歌词区 | 逐字滚动显示歌词；没歌词时会尝试在线补全 |
| 右下角「带加号的列表图标」 | 把当前这首加进指定歌单（选「我喜欢的音乐」就是收藏） |
| 右上角三点菜单 | 歌曲信息、下载到本地、调整歌词偏移、改歌词字体大小、查看专辑、分享 |

播放页会**标出当前曲目来自哪个平台**，同一首歌挂掉时，回搜索页换个来源再点开是最快的处理方式（另见 [常见问题排查.md](常见问题排查.md)）。

## 五、把歌存下来

在播放页右上角三点菜单里选**下载到本地**，这首歌连同封面、歌词一起存进应用的专属目录；下载进度和已下载内容在 **设置 → 下载管理** 里看。注意存的是应用内可管理的文件，不是随便一个公共文件夹——要在别的播放器里放，得先弄清目录位置（不同系统版本路径不同，以你手机上实际显示为准）。

## 六、顺手值得开的几个选项

- **睡眠定时器**：播放页有入口，设定倒计时到点自动暂停，睡前听歌用。
- **动态取色**（设置里）：界面颜色跟着当前封面走。
- **触感反馈**（设置里）：按键有震动回应。
- **音频反应式背景**：Android 13 及以上机型在正在播放页可开，背景会跟着声音动。

本地文件怎么进媒体库、歌单怎么建，接着看 [歌单管理与本地音乐导入.md](歌单管理与本地音乐导入.md)。
