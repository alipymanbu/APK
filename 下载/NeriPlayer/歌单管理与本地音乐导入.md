## 一、媒体库里有什么

切到 **媒体库** 页，你面对的是两类东西：

- **本地音乐**：扫出来的、实实在在存在手机存储里的音频文件。
- **歌单**：自己建的收藏夹，其中「我喜欢的音乐」是系统预置的那个——播放页点「加号列表图标」收藏的歌都落在这里。

## 二、建歌单与整理曲目

1. 在媒体库页点 **+ 新建歌单**，输入名称，回车即成。
2. 往里加歌：在播放页右下角点「带加号的列表图标」，弹窗里选目标歌单（操作细节见 [搜索音乐与在线播放.md](搜索音乐与在线播放.md) 第四节）。
3. 进入某个歌单后，条目支持**拖动排序**与**逐条删除**，批量整理不用跳出去换别的应用。
4. 不要的歌单整个删除也不留垃圾——删除记录会进同步范围（见 [GitHub同步备份与换机迁移.md](GitHub同步备份与换机迁移.md) 第三节）。

在线歌单与本地歌单在同一个界面里管，混合播放时不用来回切应用。

## 三、把本地音频导进来

两条路，按你手上的文件在哪选：

- **自动扫描**：媒体库会扫描设备本地存储里的音频文件，扫完直接列出来。文件多了以后新放进去的没出现，就手动触发一次重新扫描。
- **从别的应用分享过来**：在文件管理器、聊天窗口里长按一个音频文件，用「分享 / 打开」方式发给 NeriPlayer，文件就进库了——一次分享多个文件也支持。

导入时会顺手找**同目录下的 `.lrc` 歌词文件和图片**，找到就把歌词、封面一并挂上；音频文件本身标签（标题、歌手、专辑）缺失的，会尝试用在线搜索补齐。所以本地歌单看着乱，多半是文件本身没标签——补一次，之后就稳定了。

## 四、支持什么格式

常见音频格式（MP3、FLAC、WAV 等）都能直接播，无损格式不用额外装解码包。具体支持范围以官方仓库说明为准；遇到某个文件放不出来，先确认文件本身是否完整（见 [常见问题排查.md](常见问题排查.md)）。

## 五、歌单文件导出与导入（换机 / 手工备份）

歌单不只能靠账号同步，还能当**文件**搬：

- **导出**：把本地歌单与收藏导出成 JSON 文件存到手机存储里。
- **导入**：在新设备上把这份 JSON 选回来，歌单原样重建。

这适合不想绑 GitHub、或换机时一次性迁移的场景。要长期自动同步，走 [GitHub同步备份与换机迁移.md](GitHub同步备份与换机迁移.md) 那条路；两条路不冲突，可以都开。

## 六、下载的歌放在哪

在线曲目用「下载到本地」存下来后，在 **设置 → 下载管理** 里能看到全部已下载内容与进度。这些文件归应用管理，配合上面的 JSON 导出、GitHub 同步，换机时把「歌单结构 + 已下载文件」都带上，新手机上就不用从零整理——新手机装应用那步，用 [下载与安装教程.md](下载与安装教程.md) 里的方式装好即可。
