# GitHub同步备份与换机迁移

> 讲怎么把歌单、收藏、播放历史同步进你自己的 GitHub 私有仓库，以及换新手机时怎么把数据接回来。

## 一、这是个什么机制

这个应用没有自己的云服务，同步用的是**你自己的 GitHub 仓库**：你在应用里填一个 GitHub 令牌，歌单、收藏、最近播放这些数据就会以文件形式提交进你的仓库；换一台设备填同一个仓库，就能把数据拉回来。数据在谁手里由你决定——选**私有仓库**，就只有你自己看得到。

除了 GitHub，官方说明里还支持 **WebDAV** 作为同步远端——你有支持 WebDAV 的网盘或自建存储，也能当同样的同步目标，配置入口与 GitHub 那套并列在设置里，以你版本的设置页实际选项为准。

**同步的是数据不是音频**：歌单结构、收藏、播放历史、播放统计这些元数据会同步；下载的音频文件不进仓库，换机时音频要么重新下载、要么从旧手机拷过去。

## 二、配置步骤（一次性）

1. 打开应用，点底部 **设置**，进入 **备份与恢复**。
2. 点 **配置 GitHub 同步**，弹出配置窗口。
3. 点 **在GitHub创建Token**，跳到 GitHub 的令牌创建页，勾上 **repo** 权限后生成，复制令牌。
4. 回到弹窗里粘贴令牌，点 **验证Token**。
5. 验证通过后进入第二步：选 **创建新仓库**（由应用代建）或 **使用现有仓库**（填你已有的）。
6. 回到同步设置，把 **GitHub 自动同步** 的开关打开。

之后就是后台自动提交与拉取，你不用每次手动点。网络不通时会攒着，恢复后补交。

## 三、同步哪些、注意什么

| 项目 | 说明 |
| --- | --- |
| 同步内容 | 本地歌单、收藏歌单、最近播放、播放统计、删除记录 |
| 不同步 | 音频文件本身、图片等二进制内容 |
| 仓库可见性 | 建议私有；公开仓库等于把你的听歌记录晾给别人 |
| 更新风险 | 官方更新日志明确：同步数据模型升级后**不保证完全向下兼容**，大版本更新前先手动导出一份 JSON 备份（见 [歌单管理与本地音乐导入.md](歌单管理与本地音乐导入.md) 第五节） |
| 降级风险 | 数据库升级后回装旧版会崩溃，别拿降级当回退手段（见 [下载与安装教程.md](下载与安装教程.md) 第五节） |

令牌丢了或过期，重新走一遍第二节生成新的填进去即可；仓库里那份历史数据不受影响。

## 四、换新手机的完整流程

1. **装应用**：打开 [NeriPlayer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cebecf416ea2)，把安装包转存后装到新手机上（步骤详见 [下载与安装教程.md](下载与安装教程.md)）。
2. **接数据**：进 设置 → 备份与恢复 → 配置 GitHub 同步，按第二节填令牌、选原来那个仓库、打开自动同步——歌单和播放历史会拉回来。没用过 GitHub 同步的，用旧手机导出 JSON、新手机导入（[歌单管理与本地音乐导入.md](歌单管理与本地音乐导入.md) 第五节）。
3. **接账号**：设置 → 登录三方平台，把网易云、哔哩哔哩等账号重新授权一遍（授权信息只存本机、不进同步，见 [支持哪些音乐平台.md](支持哪些音乐平台.md) 第四节）。例外：若旧手机上用过「完整配置」导出（见第五节），导入这份文件会把平台授权一并带过来，可以省掉这一步。
4. **补音频**：已下载的歌曲在新手机上不存在，按 [搜索音乐与在线播放.md](搜索音乐与在线播放.md) 第五节的方式重新下载，或从旧手机把应用的下载目录拷过来。

## 五、只想备份不想同步

**备份与恢复**里的导出分两种，用途不同：

| 导出类型 | 内容 | 用在 |
| --- | --- | --- |
| 歌单 JSON | 本地歌单与收藏 | 只想保住听歌清单，或一次性搬歌单 |
| 完整配置 | 设置、语言、**平台授权**、GitHub/WebDAV 配置、一起听数据 | 换机整机迁移：导出后在新手机导入，绝大部分配置不用重配 |

偶尔点一下导出，存一份到手机或电脑，就够了。同步开关与本地导出互不影响，平时开着同步、大更新前再手动导一次完整配置，是稳妥的组合（大更新为什么先导出见第三节）。
