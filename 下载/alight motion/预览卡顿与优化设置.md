# Alight Motion 预览卡顿与优化设置

## 一、先明确一件事：预览卡不等于成片卡

预览是手机在实时算每一帧，卡顿说明算不过来；导出是离线逐帧渲染，慢但不会掉帧。所以预览卡顿优先靠「减负」解决，而不是放弃项目。下面按见效程度排。

## 二、开低质量预览（安卓立竿见影）

侧边菜单（编辑界面左上角的三横线）里有「低质量预览」（Low Quality Preview）开关：

- 打开后预览用低分辨率渲染，**不影响导出视频的质量**；
- 官方说明该功能在 iOS 上不可用——iPhone / iPad 会自动管理预览分辨率，没有这个开关不是你找不到；
- 少数机型上关掉它反而更流畅，两档都试一下就知道。

## 三、把重效果降下来

官方性能指南点名了资源消耗大的效果，叠在多个图层上时预览会明显变慢：

| 重效果（官方点名） | 省资源的替代或做法 |
| --- | --- |
| Shadow（阴影，尤其 Size 值大时） | 缩小 Size，或只在少数层上用 |
| Glow / Inner Glow（发光） | 能不用就不用，或只给重点层加 |
| Contour Gradient / Contour Lines | 同上 |
| Smooth Bevel、Glass | 减少叠加层数 |
| 各类 Blur（方向、径向、镜头、遮罩、运动） | 剪辑阶段关掉，导出前再开 |
| Long Shadow、Radial Shadow | 同上 |
| Matte Choker | 同上 |

还有一条官方给的替代思路：**Stroke（描边）比 Border（边框）省资源**，效果接近时优先用前者。另外效果的强度、尺寸、半径参数越大越耗性能——发光范围从 10 调到 100，性能开销不是线性涨的。

## 四、暂时关掉不编辑的图层

每个图层旁边有一个眼睛图标，点掉就把该层从预览渲染里摘出去：

- 只在剪某一层时把无关层（背景视频、特效层）先关掉，编辑流畅度提升明显；
- **导出前务必全部开回来**——关着的层不会出现在成片里，这是最容易翻车的一步。

## 五、从项目结构上减负

- **项目分辨率别超过需要**：官方明确说 1080p 以上的分辨率（如 4K）对最强的手机都是负担。发短视频就用 1080p；
- **素材先降档再导入**：预录的 4K 素材压到项目尺寸再进项目；录屏、相机素材的帧率也与项目匹配，别 60 fps 素材配 30 fps 项目；
- **关掉后台应用再剪**：可用内存多一点，预览就稳一点。

## 六、优化完还卡的兜底

以上都做了还卡，说明项目复杂度超出了这台手机的承载：把长项目拆成两段分开剪、或者把已经定稿的片段先导出成视频再作为素材导回来（相当于手动渲染中间结果）。导出环节本身失败的排查是另一套思路，见 [导出视频与参数选择.md](导出视频与参数选择.md)。
