## 一、导出入口与五种产物

项目编辑界面右上角的导出 / 分享按钮进导出面板，能产出的东西不止成片一种：

| 导出类型 | 说明 | 什么时候用 |
| --- | --- | --- |
| 视频（MP4） | 常规成片，H.264 / HEVC 编码 | 发平台、存档，绝大多数场景 |
| GIF 动图 | 无声动图 | 表情包、论坛发帖 |
| PNG 序列 | 逐帧图片 | 拿到电脑上二次合成 |
| 当前帧静图 | 存单帧 PNG | 截封面、取素材 |
| 项目包（Project Package） | 可编辑的项目文件 | 备份、发给别人继续剪 |

前四种是「成品」，最后一种是「半成品」。想留给以后继续改的，一定导一份项目包——导成视频后再也改不回图层了。

## 二、分辨率与帧率怎么选

导出面板里可以改分辨率、帧率与画质。项目建的时候是什么比例，导出就是这个比例，改的是清晰度：

| 用途 | 建议参数 |
| --- | --- |
| 常规短视频（抖音、快手） | 1080p，30 fps |
| 动作多的动画 / 运动图形 | 1080p，60 fps |
| 只发朋友圈 / 群里看看 | 720p，30 fps（导出最快） |
| 大屏播放 / 精细成片 | 档位取决于设备与版本，以应用内实际提供的为准 |

两点经验：导出时长与分辨率、图层数、效果数量都成正比，高分辨率档导出可能比 1080p 慢数倍；手机发烫降频时导出会进一步变慢，别在导出时切出去干别的。

## 三、免费版水印这回事

免费账号导出的视频右下角带 Alight Motion 水印，这是产品设计的限制，与你怎么设置无关。官方的去水印途径是订阅会员：首页右上角进「我的账户」（My Account）→「会员选项」（Membership Options），里面列出当前的订阅方案；订阅会自动续费，到期前不想续要记得提前在应用商店的订阅管理里取消（至少提前 24 小时）。

除了水印，会员还包含完整的效果库与更高档的导出选项。要不要买取决于你的使用频率——偶尔出片的话，免费版的功能（剪辑、关键帧、大部分效果）本身够用，只是成片带角标。

另外提醒一句：网上流传的各种宣称「无水印导出」的安装包改过官方程序，既不可靠也有安全风险，真需要无水印就走官方订阅，别拿主力设备去装来路不明的包。

## 四、导出失败 / 中途崩溃排查

导出到一半失败或直接闪退，按出现概率从高到低排查：

1. **内存不够**：图层数多、效果多、开运动模糊的项目最容易在导出时崩。先关掉后台其他应用再导；还不行就把运动模糊等重效果临时关掉，或把长项目拆成两段分开导（平时的预览卡顿优化见 [预览卡顿与优化设置.md](预览卡顿与优化设置.md)，两者方法通用）；
2. **存储空间不足**：导出的临时文件需要的空间比成片本身大，确认手机剩余空间比项目预计成片大好几倍；
3. **分辨率档位过高**：最高档位在低端机型上经常直接失败，降到 1080p 再试；
4. **应用版本太旧**：升级到当前版本再导（官方帮助中心对导出崩溃有专门的排查文章，遇到顽固问题可以去 [support.alightmotion.com](https://support.alightmotion.com) 搜「crashed during export」）。

导出失败不会损坏项目本身，时间线里的东西还在，排除原因后重新导即可。

## 五、换手机：项目怎么带走

前面说过卸载会清空本地项目，换设备前按这个顺序做：

1. 在旧手机上逐个项目导出**项目包**（导出面板里选 Project Package）；
2. 把项目包文件传到新手机（网盘、数据线、任意你顺手的方式）；
3. 新手机上装好 Alight Motion（安装包可以从 [Alight Motion 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a3e6741d5a32) 转存获取），打开后通过「导入项目包」把文件导入；
4. 导入后检查素材引用：外部字体、音频如果当时是引用手机文件，可能要在新设备上重新指定或导入一遍。

跨平台（安卓 → iPhone）迁移用同样的项目包方式，图层与关键帧能带过去，效果库的可用范围以新设备上的账号状态为准。
