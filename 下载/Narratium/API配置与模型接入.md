> Narratium 本体不带模型，第一次打开必须先配一个模型接口才能开始聊。这篇把配置五步、常用服务商的填法和报错排查一次讲清。

## 一、为什么要先配 API

Narratium 是个「壳」：角色卡、剧情树、世界书这些都在本地，但真正生成回复的是你接入的大模型服务。所以它支持接入 OpenAI、DeepSeek、Ollama 这类主流模型接口，你自己填 Key 就能换模型；不配接口，角色列表点进去也聊不起来。

## 二、配置五步走

首次启动会直接弹出「创建你的第一个配置」，之后想加新配置，在设置里选「新建配置」即可：

1. **选 LLM 类型**——比如 OpenAI API 这种通用格式（DeepSeek、OpenRouter 等多数服务商都兼容这个格式）。
2. **填 Base URL**——服务商的接口地址，见下面第三节的对照表。
3. **填 API Key**——在对应服务商的开放平台后台创建，粘贴进来。
4. **点「获取模型列表」**——能拉出模型清单说明地址和 Key 都填对了。
5. **选一个模型，点「创建配置」**——完成，回到角色列表就能开聊了。

配置支持建多条，想换模型时切一条激活即可，不用删了重来。

## 三、常用服务商怎么填

| 服务商 | Base URL | 备注 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | 通用格式，Key 在 `platform.openai.com` 后台创建 |
| DeepSeek | `https://api.deepseek.com` | 国内可直接访问，Key 在开放平台创建 |
| OpenRouter | `https://openrouter.ai/api/v1` | 一个 Key 换多家模型 |
| Ollama（本机模型） | `http://localhost:11434` | 只对同屏电脑/手机侧有效，见第五节 |

以上地址以各服务商自己文档的最新写法为准；填完点「获取模型列表」验证是最快的核对方式——列表拉得出来就是通的。

选模型时还有一个值得看的参数：**上下文长度**。它决定一场长剧能铺多长、AI 能记多少轮，不同模型的差距很大；上下文和角色卡内容怎么互相挤占，见 [角色卡字段含义与写法.md](角色卡字段含义与写法.md)。

## 四、关于「官方试用 API」

网页版曾内置过官方提供的 DeepSeek、Gemini 试用接口，列表里没出现时刷新一下页面就会出现；这个逻辑是「试用」性质的，随时可能调整，以页面实际显示为准。安卓端以应用内实际提供的选项为准，没有的话就用自己配的 Key。

## 五、用 Ollama 跑本地模型

如果你电脑上装了 Ollama，想让它当 Narratium 的后端：

1. 电脑上启动 Ollama 并拉好模型（`ollama pull` 命令，见 Ollama 官方文档）。
2. Base URL 填 `http://localhost:11434` ——Windows 版对这种写法有兼容处理，`localhost:11434` 会自动补全成带 `http://` 的完整地址，少个协议头也能识别。
3. Key 可以留空，获取模型列表选一个本机模型即可。

注意 `localhost` 指的是「运行 Narratium 的那台设备自己」——在电脑浏览器里用网页版时，`localhost` 是这台电脑；在手机上用安卓端时，`localhost` 是手机本身，手机连不上你电脑上的 Ollama（除非你清楚怎么把地址换成电脑的局域网 IP 并放开防火墙，这属于网络配置问题，本文不展开）。

## 六、配置报错对号入座

| 现象 | 多半是 | 怎么处理 |
| --- | --- | --- |
| 提示未配置模型 / 点角色没反应 | 还没建配置，或建了没激活 | 回设置里完成/激活一条配置 |
| 「获取模型列表」失败 | Base URL 填错（漏 `/v1`、多斜杠）、Key 无效 | 逐字对照服务商文档，重新粘贴 Key |
| 能聊但中途断掉、报额度类错误 | Key 余额用完或限流 | 去服务商后台看用量与余额 |
| 回复特别慢或一直转圈 | 所选模型本身慢，或网络不通 | 换个模型试试；检查设备网络 |

配好了还是聊不动，去 [数据存储与常见问题排查.md](数据存储与常见问题排查.md) 的排查表再过一遍；聊天界面里那些「剧情分支」「世界书」按钮的用法在 [剧情分支与世界书玩法.md](剧情分支与世界书玩法.md)。
