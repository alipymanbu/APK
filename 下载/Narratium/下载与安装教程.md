## 一、这是个什么应用

Narratium（中文叫法是「叙梦Naro」）是一个开源的 AI 角色扮演与互动叙事项目，你可以在里面创建带性格、背景、口头禅的虚拟角色，也可以用别人做好的角色卡开一场有分支剧情的对话。项目源码在 [github.com/Narratium/Narratium.ai](https://github.com/Narratium/Narratium.ai)，官网是 [www.narratium.org](https://www.narratium.org)。

它同时有几种形态：网页版（浏览器直接打开）、桌面版（Windows/Linux/Mac 安装包）、以及你现在要装的这份安卓端 APK。几端的功能框架一致，但数据和聊天记录各自独立保存（详见 [数据存储与常见问题排查.md](数据存储与常见问题排查.md)）。

## 二、拿安装包

本篇用的安装包就是 **Narratium 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/5d71a65eb63e](https://pan.quark.cn/s/5d71a65eb63e) —— 转存到自己的网盘后下载即可。这一份的版本信息如下（以它为准，别拿别处的版本号来对）：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.0 |
| 包名 | `com.ai.narratium.org.baobeiy` |
| 大小 | 3.72M |
| MD5 | `075DE20EA67733976EDE5907CC401065` |

下载完可以顺手核对一下 MD5 是否一致（很多文件管理器长按文件就能看属性），不一致说明传输中损坏了，重新下一次即可。这份包只有 3.72M，因为它本体不带 AI 模型，聊天时连的是你在应用里自己配置的模型接口，所以装完还不够，还要配一次 API（见 [API配置与模型接入.md](API配置与模型接入.md)）。

## 三、安装步骤

1. 把 APK 传到手机上（直接用手机下载、数据线拷贝、局域网互传都行）。
2. 用文件管理器点开这个 `.apk` 文件。
3. 系统会弹「是否允许安装未知应用」——给文件管理器或浏览器授予这个权限，再回到安装界面点安装。
4. 装完点「打开」，或回桌面找图标。

> [!NOTE]
> 如果手机开了纯净模式 / 应用管控（各品牌叫法不同），会额外拦一道，按提示选「仍要安装」即可。安装来源是你自己下载的这份包，拿不准时先核对上面表格里的 MD5。

## 四、第一次打开点什么

1. 首次进入会引导你「创建你的第一个配置」——这是在配模型接口，一步步填就行，每一步填什么见 [API配置与模型接入.md](API配置与模型接入.md)。
2. 需要账号的话，页面下方有登录入口：邮箱注册（会发验证码）或者游客登录；登录后可以设定你在剧情里的主角名称。
3. 配置完模型，进角色列表挑一张卡就能开始第一场对话，流程见 [角色卡导入与社区下载.md](角色卡导入与社区下载.md)。

## 五、安卓端和网页版/桌面版的关系

- **网页版**：浏览器打开官网就能用，不用安装；项目还支持把它安装成 PWA（在浏览器菜单里选「添加到主屏幕」）。
- **桌面版**：Windows、Linux、Mac 的安装包在项目的 GitHub Releases 页面发布。
- **安卓端**：也就是本文这份 APK，底部有自己的导航栏，按手机习惯做了触屏优化。

三端互相独立：网页版的数据跟着浏览器走，桌面版的数据在电脑本地目录里，安卓端的数据在这台手机上。想在两端聊同一段剧情，目前没有现成的同步通道，别指望装完自动迁移。

## 六、系统要求与版本说明

- 官方渠道没有公布明确的最低 Android 版本，安装时以系统本身的提示为准；如果安装时提示版本过低，说明这台设备的系统低于该包的要求。
- 网盘里这份是 **2.0**（3.72M）。开源项目更新很快，网上搜到的「最新版」可能比它新 —— 本文各处的版本号、包名、体积一律以第二节那张表为准。
