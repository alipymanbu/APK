## 一、安装失败或提示解析错误

按顺序排查：

1. **包是否完整**：两百多兆的包下载中断就会装不上。核对文件大小（约 226.88M）与 MD5 `9b700f9275263bef93d0441eee4f4aa9`，对不上就重新下。
2. **是否给了安装权限**：系统「设置 → 安全/隐私 → 安装未知应用」里，给你的文件管理器打开开关，再点一次 APK。
3. **空间是否够**：安装这么大的包加上解压空间，手机存储最好留出 1GB 以上余量。
4. **是否装过旧版本**：覆盖安装仍失败时，先备份应用内还要的数据，卸掉旧的再装新的。

## 二、打开就闪退、用着用着崩溃

常见原因与对应动作：

| 现象 | 先做什么 |
| --- | --- |
| 打开立刻退回桌面 | 清缓存：设置 → 应用管理 → SuperAI → 存储 → 清除缓存，然后强行停止再开 |
| 用一段时间后崩 | 看手机剩余内存与存储，关掉后台一堆应用再试 |
| 装完新版本才开始崩 | 大概率是该版本本身的问题；换一个版本装（网盘里的 6.1.0 可作备选） |
| 一直崩且以上都试过 | 重启手机；再不行就清除数据重装（会丢应用内未同步的数据，先确认记录已导出） |

另外检查一下是否拒了关键权限（存储、网络）——权限被禁的应用行为异常很常见，见 [下载与安装教程.md](下载与安装教程.md) 的权限一节。自查都试过还闪退，走反馈渠道：开发者在应用商店公开答复里给出的联系途径是**个人中心里的联系我们入口**，把机型、系统版本与闪退发生在哪一步写清楚发过去。

## 三、生成慢、排队、失败

视频与图片都是在服务器端生成的，等待时间受网络和排队情况影响，你可控的部分是这些：

- 生成前确认网络稳定，Wi-Fi 断流比流量更容易让任务失败。
- 失败的任务稍等再重试，不要连续狂点——重复提交只会更慢。
- 描述写得太离谱或素材太大也会拖慢，适当精简。
- 高峰时段慢属正常，隔一段时间再用。

反复失败时先用聊天功能试一下：聊天也慢说明是网络或服务的问题，只有生成失败就是该功能的事。

## 四、导出的图片带水印怎么办

1. 先在生成完成页与导出设置里找水印开关，有的版本把关闭选项放在这里。
2. 找不到开关，说明你这个版本没提供关闭入口——以应用内实际选项为准，不要安装来路不明的第三方修改包。
3. 图片带水印的更多上下文见 [图片特效与改图玩法教程.md](图片特效与改图玩法教程.md)。

## 五、找不到某个功能入口

应用版本不同，功能列表会有增减。逐一确认：

1. 你装的是哪个版本（设置或应用信息里看，网盘这份是 6.1.0）。
2. 入口是否换了位置——视频、图片、智能体几类都在首页功能列表里，可上下滑动或用搜索找。
3. 有的功能要先进二级页面（如智能体在 AI 工具类入口下）。

## 六、网上同名的「Super AI」不止一款

搜索时你会搜到好几款名字接近的应用，认包名即可区分：

- 本文这款 = `com.chatai.superai`（开发者：北京七麦科技股份有限公司），即 [下载与安装教程.md](下载与安装教程.md) 里网盘那份包。
- 另有开发者不同的同名英文应用（包名 `com.superai.chatgpt` 之类），功能与界面完全是两回事。

装完后到「设置 → 应用管理」核对包名，是 `com.chatai.superai` 就对了。

## 七、能在电脑上用吗

可以走安卓模拟器或应用宝电脑版：访问 [应用宝官网](https://sj.qq.com/appdetail/com.chatai.superai) 的应用详情页，按页面提示用电脑版应用宝安装运行。电脑上跑的是同一个安卓应用，功能与手机一致。

## 八、订阅与扣费

应用可免费下载使用，部分高级功能可能带内购或订阅项，是否收费、收多少以**应用内购买页面的实时显示为准**。几条用得上的信息（截至 2026-09，之后以官方页面为准）：

- 商店页显示的内购档位覆盖月付、年付与买断，价格从几十元到三百元区间（App Store 页列出的档位含月付、年付、终身买断等，具体哪个价对应哪档以购买页为准）。
- **会员之外还有按次消耗**：有用户反馈充了会员后，导出视频仍要消耗应用内的按次代币（评论里称「星星」），会员不等于无限次导出。付费前先把当期能导出多少次问清楚，或先用免费额度试一轮。
- 若你订阅了自动续订，取消入口在应用内的订阅管理页或手机商店的账户订阅设置里；取消后当前周期结束前仍可正常使用。
- 付费后对额度、扣费有异议，走个人中心的联系我们入口反馈（与闪退反馈同一条渠道）。

生成的成品能不能拿去商用，与花多少钱无关，判据见 [生成的视频图片能商用吗.md](生成的视频图片能商用吗.md)。
