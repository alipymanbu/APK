# 下载与安装教程

> Amarket 本体是安卓 APK，难在「装进手表」而不是装本身 —— 本篇按你的手表类型给出装法，含 Wear OS 4 的授权命令。

## 一、先确认你的手表属于哪一类

Amarket 装到手表上之前，先按 [支持哪些手表型号.md](支持哪些手表型号.md) 判定你的手表属于安卓、鸿蒙、Wear OS 还是 Wear OS 4 —— 首次启动时要选的「安装模式」就是按这个分的，选错了应用装得上但装不进应用。

本篇涉及的版本与包信息以此表为准：

| 项 | 值 |
| --- | --- |
| 版本 | 3.2 |
| 包名 | `com.github.wearmex.amarket` |
| 安装包大小 | 13.97M |
| MD5 | `2C8CB313F601F50157D575EF3AF991C0` |
| 系统要求 | 安卓 5.2 以上（以安装时实际提示为准） |

## 二、拿到安装包

1. 从 [Amarket 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e7a722d8fa5e) 下载 `Amarket_v3.2.apk` 到你的**手机**（不是手表）—— 手表浏览器下大文件、找文件都费劲，手机下完再传过去更稳。
2. 校验完整性（可选但推荐）：用手机上的文件管理器或校验工具比对 MD5，应为 `2C8CB313F601F50157D575EF3AF991C0`。对不上说明包在传输中损坏，重新下载。
3. 若你的手表能直接上网（连了 Wi-Fi），也可以在手表浏览器里直接打开网盘链接下载 —— 但下载前先确认手表存储还有富余，13.97M 的包本身不大，解压安装还需要额外空间。

## 三、装进手表：按手表类型选路

### 路线 A：手表是普通安卓手表（OPPO Watch 等）

这类手表就是个小安卓机，装法与手机相同：

1. 把 APK 传到手表（蓝牙文件传输、手表自带的文件管理器、或通过 Wi-Fi 共享目录均可）；
2. 在手表上用文件管理器点开 APK；
3. 系统会提示「禁止安装未知来源应用」，按提示允许一次即可。

### 路线 B：Wear OS 手表（含 Wear OS 4、三星新款、Pixel Watch）

Wear OS 手表不给直接点开 APK 安装，要走无线调试。手表与手机连**同一个 Wi-Fi**，然后：

1. 手表上开启开发者选项：`设置 → 关于 → 版本号`（有的机型在 `软件信息 → 软件版本`）连点多次；
2. 开发者选项里打开 `ADB 调试` 与 `无线调试`，记下手表显示出的 IP 地址；
3. 手机装一个 ADB 桥接应用（Wear Installer 2、Bugjaeger、Easy Fire Tools 任选其一），填入手表 IP 配对；
4. 手表弹「允许调试吗」时选「始终允许」；
5. 用桥接应用把手机上的 `Amarket_v3.2.apk` 推送到手表安装。

**Wear OS 4 还差一步系统授权**：Wear OS 4 收紧了「应用安装」权限，装完 Amarket 后先在电脑（或手机 ADB）上执行一条命令再用：

```bash
adb shell appops set --uid com.github.wearmex.amarket REQUEST_INSTALL_PACKAGES allow
```

然后**把 Amarket 里的安装方式切换为「安卓」**，商店里的应用才能正常装进手表。这条命令在社区教程（机智库 Wear OS 4 安装帖）里被反复验证过，对汉克米、维趣等其他手表商店同样适用。

### 路线 C：鸿蒙手表（华为 Watch 3 等 HarmonyOS 设备）

装法同路线 A：允许未知来源 → 文件管理器点开 APK 安装。鸿蒙的「纯净模式」会拦第三方 APK，装之前先在 `设置 → 系统和更新 → 纯净模式` 里关掉。

## 四、首次启动的两个选择

装好第一次打开 Amarket：

1. **隐私授权弹窗** —— 点同意进入；
2. **安装模式选择** —— 按你手表的系统选（安卓 / 鸿蒙 / Wear OS / Wear OS 4）。这一步决定它用哪套方式往手表里装应用，选错的典型症状是「商店能浏览、点安装没反应」，可回到设置里改（见 [常见问题与排查.md](常见问题与排查.md)）。

之后在首页浏览或搜索应用，点下载即装到手表；下载管理页能看进度和已下完的包。

## 五、更新与覆盖安装

Amarket 更新时官方发的是**新文件名的 APK**（版本号变则文件名变），覆盖安装即可，不用先卸载 —— 数据与登录状态会保留。若覆盖时提示签名冲突，才需要卸载旧版重装（会丢登录态，注意先记下你的绑定 ID，换绑走 [常见问题与排查.md](常见问题与排查.md) 一节）。
