# 手表存储不足的清理办法

> 手表可用空间往往只有几个 GB，满了之后 Amarket 里的应用会下不下来 —— 先看清谁在占地方，再按顺序清。

## 一、空间不足时你看到的症状

- Amarket 里点下载，进度走一点就停，或直接提示失败（归类见 [常见问题与排查.md](常见问题与排查.md) 第一节）；
- 手表弹「存储空间不足」；
- 已装应用更新不了、表盘换不了。

一个背景数字：Wear OS 手表常见总容量在 4GB~8GB（新款多为 16GB~32GB），**其中相当一部分被系统与预装应用占掉** —— 厂商标的容量不等于你能用的容量，装几个应用加一批离线内容就会见底。

## 二、先看清楚谁在占

打开 `设置 → 存储`（有的表在 `设置 → 系统 → 存储` 或 `设置 → 设备护理 → 存储`，路径按机型略有差异；部分机型也能在手机端配套应用里看）。界面会把占用按类别分开，常见的大头：

| 类别 | 为什么大 | 值不值得清 |
| --- | --- | --- |
| 离线音乐 / 撬客 | 几套离线歌单轻松吃掉 1~2GB | 优先清：手机常在身边就用流媒体，留一两套歌单轮换 |
| 离线地图 | 导航类应用的区域地图包 | 不常用地区直接删 |
| 下载的表盘 | **每个表盘按应用算**，带图与动画的表盘一个几十 MB 起 | 清：留常用的两三个 |
| 不用的应用 | 试装后忘删的应用 + 它们的缓存数据 | 清：卸了要用再装 |
| 照片 / 录音 / 手动传的文件 | 手表相册与语音备忘录 | 清：老照片导回手机 |

## 三、按这个顺序清，收益最大

1. **删离线内容**（音乐、播客、地图）—— 单个体积最大、删了几乎无损失；
2. **删多余的下载表盘** —— 长按表盘进选择器即可移除，删表盘不影响其他数据；
3. **卸不用的应用**：`设置 → 应用 → 全部应用` 里逐个看，或在手表 Play Store 的已安装列表里卸载。系统预装只能「停用」，别强删看不懂用途的系统组件；
4. **清缓存**：`设置 → 应用 → 选中应用 → 存储 → 清除缓存` —— 只清临时文件，不动登录与数据；
5. 全做完还不够，才考虑恢复出厂（`设置 → 系统 → 恢复出厂设置`）—— **会清掉手表全部数据**，先想清楚再按。

## 四、腾出多少空间才够

保守估计：要装的应用体积 × 2。以 [下载与安装教程.md](下载与安装教程.md) 里的 Amarket 本体为例是 13.97M，安装时还需要解压与缓存空间；商店里下别的应用同理 —— 提示「空间不足」时至少再腾出一两百 MB 的余量再试。日常保持 500MB 以上的空闲，下载失败与更新失败会少一大半。
