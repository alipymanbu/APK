## 一、安装前先确认三件事

1. **你在不在服务范围**。Cici 是字节跳动面向海外市场的 AI 助手，截至 2026 年中的公开资料，它在美国、加拿大、澳大利亚和中国大陆不提供服务，主要覆盖英国、墨西哥、巴西、印尼、菲律宾、马来西亚、泰国、西班牙、法国、阿根廷、阿联酋等市场。中国大陆用户打开应用大概率会遇到「地区不可用」提示，这一步没有绕开的官方途径，是否可用请以官方页面为准。
2. **用什么账号注册**。官方支持邮箱、Google 账号、Apple ID 三类注册方式，注册页面以应用内实际显示为准。想先用再注册的话，部分教程的截图显示底部有「不登录直接使用」的入口（属用户反馈，不是官方文档说法），能不能跳过登录以你装的那一版为准。
3. **装的是哪个包**。本篇配套的安装包固定信息如下，转存后可以按这些值核对文件是否完整：

| 项目 | 值 |

| 版本 | 13.1.0 |
| 包名 | com.larus.wolf |
| 安装包大小 | 161.23 MB |
| MD5 | a2d235b7ac06b045c9bc2bb26c08f72a |

包名 `com.larus.wolf` 是认这个应用的硬依据——应用商店里它现在的名字可能显示为「Dola (formerly Cici)」（原因见[豆包国际版与更名Dola说明.md](豆包国际版与更名Dola说明.md)），但包名从上线到现在没变过。

## 三、安卓安装步骤

从商店以外装 APK，安卓会要求你先放行「未知来源」：

1. 打开手机自带的**文件管理**，找到刚下载的 APK 文件（约 161 MB）；
2. 点击安装，系统弹出「出于安全考虑，禁止安装未知来源应用」之类的提示时，按提示进入设置页，**允许浏览器或文件管理器安装应用**；
3. 回到文件管理器再点一次 APK，等安装进度走完；
4. 装完点打开，首次启动会请求网络、麦克风（语音对话用）等权限，按需允许——不给麦克风权限只是用不了语音输入，打字对话不受影响。

部分国产手机（小米、华为等）还会额外问「是否允许该应用联网/自启动」，都按正常使用需要给即可。安装卡在某个百分比或报「解析包失败」，多数是下载不完整，先按上面表格里的 MD5 核对文件，再删掉重下；其他安装类问题见[常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、注册与登录

1. 打开应用，选注册方式：邮箱、Google 或 Apple ID（以应用内实际显示的选项为准）；
2. 邮箱注册需要收一封验证邮件，填写能正常收信的邮箱即可；用 Google/Apple ID 则直接授权登录；
3. 登录成功后，对话记录会跟着账号走——换手机重装后登录同一账号，历史对话还在（以应用内实际表现为准）。

## 五、界面语言

界面语言一般跟随系统语言，也可以在应用设置里手动切换。官方应用商店条目列出的界面语言共 18 种，**简体中文与繁体中文都在其中**（英文、印尼语、马来语、泰语、越南语、日语、韩语、西语、葡语、法语、德语等，iOS 商店口径；安卓端以应用内实际可选列表为准）。对话内容本身不受界面语言限制，用中文提问通常也能得到中文回答，翻译场景见[日常用法与实用技巧.md](日常用法与实用技巧.md)；不在手机上装、想直接在电脑上用，见[网页版与电脑端怎么用.md](网页版与电脑端怎么用.md)。
