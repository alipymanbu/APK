## 一、调出阅读设置

进入阅读界面后，点**页面中间区域**即可展开菜单——1.2.0 起翻页模式下点中间也会展开（旧版翻页模式下点中间没反应）。菜单里带齿轮图标的入口是设置页，字体大小、颜色、背景、翻页模式、边距都在里面按需调整。

改完即时生效；从阅读器页面直接改背景也不会丢翻页进度（这是 1.2.0 修过的问题，旧版会出现进度跳回开头的情况）。

## 二、常调的几项设置

| 想做什么 | 去哪调 |
| --- | --- |
| 字号、行距、边距 | 阅读设置里的文本排版项 |
| 阅读背景（含深色模式独立背景色） | 设置里的背景项；1.2.0 起深色模式可以单独设一个背景色，白天夜晚互不干扰 |
| 翻页模式 / 无限滚动 | 阅读设置；1.2.0 起无限滚动**默认开启** |
| 沉浸模式（隐藏系统栏全屏读） | 阅读设置里的沉浸模式开关；1.2.0 起进入沉浸模式会直接应用全屏 |
| 日期与时间显示格式 | 1.2.0 加入的日期时间格式设置项 |
| 自定义字体 | 阅读设置里的字体项——注意 1.1.7a 修过「阅读器自定义字体失效」，碰到失效先升级 |

另外两个阅读时会碰到的交互：

- **章节切换提示**：1.2.0 起翻页时会有章节切换的文本提示，看到提示就知道下一页跨章了；
- **阅读进度保存**：进度按章节存储，退出再进会回到上次那一章的位置；如果进度不准，1.2.0 修过「章节阅读进度计算不准确」，先升级版本再判断。

官方宣传页还提到「统计」功能：能看每日阅读时长和整体阅读数据（入口在应用内统计页，具体位置以界面为准）。

## 三、把书导出成 EPUB

LightNovelReader 支持把缓存在本地的书导出成标准 EPUB 文件，导出后可以丢进任何其他阅读器里读。1.2.1 对整个导出流程做了一轮优化，现在的实际体验：

1. 在书本详情页或书本管理页找到「导出」入口；
2. 弹出的对话框里可选择**导出哪一卷**、是否**导出图片**——1.2.1 修复了以前「选了卷和图片设置却不生效」的问题，这两个选项现在真的起作用；
3. 确认后开始导出，**通知栏会出现导出进度**（1.2.1 新增的进度可视化）；
4. 导出完成按提示保存文件即可。

注意事项：

- **先把书缓存完整再导出**：导出的是本地内容，没缓存到的章节自然不在文件里（缓存方法见 [书架管理与离线缓存.md](书架管理与离线缓存.md) 第三节）；
- **慢速网络下**导出含图的书可能不稳定，1.2.0 系列专门优化过慢网导出的稳定性，出错先升级到 1.2.1+；
- 1.2.0 修过「EPUB 书本无法被正常导出」的致命 bug——你手上如果是 1.1.x 的包，导出失败大概率是版本问题，别反复重试，去 [下载与安装教程.md](下载与安装教程.md) 拿新版。

## 四、无痕滚动是什么

阅读设置里有个「无痕滚动」开关。官方没有给它写专门的说明文档，能确认的是：它和阅读进度的记录方式有关——1.2.0 把阅读进度改为按章节存储时，专门修复过该模式下的异常跳转逻辑。也就是说这个模式在旧版上有过跳章问题，**如果你开了它遇到进度乱跳，先升级到 1.2.1 及以上再判断**；平时不确定用途就保持默认关闭。
