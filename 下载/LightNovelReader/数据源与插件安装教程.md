## 一、先搞清「数据源」和「插件」的关系

LightNovelReader 本身只是个阅读器外壳，书的内容来自「数据源」：每个数据源负责一个站点的搜索、目录与正文抓取，**数据源之间数据独立**——你在 A 源收藏的书，切到 B 源看不到，这是正常设计而不是丢数据。

从 1.2.0 起，数据源以「插件」形式管理：插件就是装进 LightNovelReader 的一个个小 APK，加载后在「探索」页提供搜索与书籍列表。1.2.1 又加入了**插件市场**支持，可以在应用里直接看到可安装的插件并检查更新。

装好应用后，先用内置源确认搜索能用；内置源满足不了时，再按下面几节装插件扩展更多源。

## 二、内置数据源：不装插件也能搜

新版安装包自带内置数据源，装完直接在底部「探索」页点搜索框、输入关键词就能搜书。内置源由官方维护，出现问题时通常靠升级解决——最新的 1.2.2a 就专门修了「内置数据源封面与插图加载异常」。

内置源挂了、或你想找内置源没有的书，再考虑装插件，见下节。

## 三、安装插件的三种方式

入口统一在：**设置 → 扩展插件**，点「安装插件」后会弹出安装方式选择：

1. **本地存储**：先把插件的 APK 文件下载到手机（浏览器下载即可），在对话框里选「本地存储」，从文件列表里挑中它，确认安装。
2. **外部导入**：拿到别人分享的插件链接时，选「外部导入」，粘贴 URL 让应用自己拉取。
3. **插件市场**：1.2.1 起支持插件市场 API——在扩展插件页会出现安装底栏与插件列表，直接点安装即可，之后应用还会帮你检查插件更新。

安装完成后：

- 插件会出现在插件列表里，**保持启用状态**才会参与搜索；
- 有反馈说部分插件装完要**重启应用**才生效，遇到搜不到新源时先彻底关掉应用再打开；
- 1.2.1 起插件文件建立了系统关联，你在文件管理器里点开一个插件格式的文件，会直接调起 LightNovelReader 的安装对话框。

## 四、切换数据源

同一个作品在不同源的收录不一样（有的缺卷、有的更新慢），1.2.0 起有专门的**数据源切换页面**：

1. 打开某本书的详情页；
2. 进入数据源设置入口（详情页或书本菜单里，不同版本位置略有差异）；
3. 列表里挑另一个源，确认切换；
4. 切换后这本书的目录与进度会按新源重新加载——**各源数据独立**，你原来在旧源下的收藏和进度不会丢，切回去时还在。

找书时也可以直接在探索页换源搜索：搜索结果页可选择用哪个数据源发起查询。

## 五、插件装不上的几个已知情况

LightNovelReader 对坏插件有一套保护逻辑（1.2.0 系列陆续加入），对照处理：

| 现象 | 原因 | 你能做的 |
| --- | --- | --- |
| 插件装完自动变灰 / 被标记错误 | 加载失败时应用会自动禁用错误插件，防止连带崩溃 | 换一个插件源重新下载该插件；确认文件没下完整 |
| 提示 API 不兼容 | 插件是给别的 LNR 版本写的，应用会禁用不兼容插件并显示提示 | 升级或降级 LightNovelReader，或找适配当前版本的插件 |
| 插件列表里看不到已装的插件 | 应用启动时不再加载「未启用」的插件 | 到插件管理里确认启用开关是打开的 |
| 想确认手机里哪些应用是插件 | 1.2.0 起支持扫描本地已安装应用里的插件 | 在扩展插件页查看「本地插件应用列表」 |

实在装不上时，先回到 [下载与安装教程.md](下载与安装教程.md) 核对 LightNovelReader 本身的版本，再看 [常见问题与排查.md](常见问题与排查.md) 里的整体排查步骤。
