## 一、封面或插图加载不出来

**先看版本**：官方 1.2.2a 的发布说明就是「为内置数据源修复了封面与插图加载异常问题，建议所有正式版用户安装」。也就是说这个现象是已知 bug，**升级到 1.2.2a 即可**，不需要改任何设置。

升到最新版还出现个别图片挂掉的，多半是那张图的源站问题——换一个数据源打开同一本书试试（切换方法见 [数据源与插件安装教程.md](数据源与插件安装教程.md) 第四节）。

## 二、搜索没结果 / 加载失败 / 显示离线

按顺序过一遍，每步都是一个独立的排除项：

1. **网络本身通不通**：先确认手机的 Wi-Fi 或移动数据开着、信号正常，用浏览器打开任意网页验证。
2. **下拉刷新，或切到「探索」「书架」标签重新进入**——临时的请求卡死这样能恢复。
3. **等缓存/加载走完**：详情页显示缓存没完成时，等进度结束再读（缓存流程见 [书架管理与离线缓存.md](书架管理与离线缓存.md) 第三节）。
4. **换数据源**：某个源的站点挂了或改版了，它的搜索与正文就会整体失败，切到另一个源即可排除。
5. **重启应用**：彻底关闭再打开，清掉临时的请求与缓存故障。
6. **确认版本**：旧版可能存在网络和缓存的兼容性问题，升级到最新正式版（渠道见 [下载与安装教程.md](下载与安装教程.md) 第二节）。
7. 以上都无效，再考虑清除应用缓存或重装——**重装前先确认书架数据要不要保**，见第三节。

另一个容易忽略的可能：**你的界面和教程截图根本对不上**——搜「light novel reader」时容易装成另一款同名应用 LNReader，它的菜单结构完全不同。先核对包名是不是 `indi.dmzz_yyhyy.lightnovelreader`，两款怎么区分见 [和LNReader的区别.md](和LNReader的区别.md)。

## 三、升级前必须做的备份（最容易踩的坑）

官方在 1.2.0 发布说明里写得很直白：

> 注意：从旧版升级之后，将无法导入先前导出的存档，请提前备份重要数据

也就是说：**如果你在 1.1.x 上导出过存档（用户数据备份文件），升到 1.2.0+ 之后那个存档就作废了**。升级动作本身不丢书架，但别指望旧存档还能导回来。正确顺序：

1. 停留在旧版时，先导出并保存好用户数据存档；
2. 再升级到新版；
3. 新版装好后核对书架与阅读进度是否完整。

已经被升上去了、旧存档导不进：1.2.1 起导入时提供「合并或覆盖」选项（1.2.0 期间加入），新装用户不受影响；旧存档本身与新版不兼容的情况没有公开的解法，只能重新收藏该书目。

## 四、插件相关的问题

插件装不上、装完不生效、被自动禁用，常见原因与处理在 [数据源与插件安装教程.md](数据源与插件安装教程.md) 第五节的对照表里，这里不重复。核心三条：

- 提示 API 不兼容 → 插件与 LightNovelReader 版本不配对，先对版本再装插件；
- 插件自动变灰 → 应用检测到加载错误后自动禁用（保护机制，不是你操作错了）；
- 搜不到书 → 先确认插件启用开关开着，再确认 LightNovelReader 本身是最新正式版。
