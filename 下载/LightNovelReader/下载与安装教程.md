## 一、这是什么软件

LightNovelReader 是一款开源的安卓轻小说阅读器，用 Kotlin 和 Jetpack Compose 写成，Apache-2.0 许可，作者在 GitHub 上的仓库是 [dmzz-yyhyy/LightNovelReader](https://github.com/dmzz-yyhyy/LightNovelReader)。它的安装包只有 5 MB 出头，装完能做的事包括：按数据源搜索与阅读轻小说、缓存后离线读、多书架管理、把书导出成 EPUB 文件。

它支持 Android 7.0 及以上系统（官方 README 标注支持到 Android 15，F-Droid 页面标注最低 Android 7.0，以官方页面当时显示为准）。

## 三、安装步骤

1. 在手机上打开 APK 文件；系统会提示「不允许安装未知来源的应用」，这是安卓对所有侧载安装的默认拦截。
2. 按提示进入该来源的授权页（通常是文件管理器或浏览器），打开「允许安装此应用」，返回。
3. 点「安装」，几秒钟即可完成——安装包只有 5 MB 左右，安装过程很快。
4. 装完打开，首次进入是底部的「探索」页——安装包自带内置数据源，直接就能搜索；想加更多数据源，下一步按 [数据源与插件安装教程.md](数据源与插件安装教程.md) 配置。

同一台手机上已装过旧版 LightNovelReader 的话，直接用新包覆盖安装即可，书架与阅读进度会保留；但从 1.1.x 升到 1.2.0 及以上有一个例外，见第五节。

## 四、它申请了哪些权限

F-Droid 页面列出的权限（截至 2026-09，以官方页面为准）：

- **完全的网络访问权限 / 查看网络连接**：搜索、加载章节、检查更新都要联网；
- **显示通知**：EPUB 导出会以通知显示导出进度，书本更新提示也走通知；
- **前台服务（dataSync 类型）**：缓存章节、下载内容时在后台继续跑；
- **请求安装 / 删除文件包**：用于应用内更新提示时调起安装器；
- **开机启动、精确闹钟、防止休眠**：用于定时的更新检查与后台任务。

这些权限都是阅读器类应用的常规配置。你不想要应用内更新提醒的话，可以在系统设置里单独关掉它的通知，不影响阅读功能。

## 五、版本号怎么读

LightNovelReader 的版本号形如 `1.2.1`，另外还有两类变体：

- **正式版**：`1.2.0`、`1.2.1` 这种三段数字，发在 GitHub Releases 的正式条目里；
- **修复版**：尾部带字母 `a`，如 `1.1.7a`、`1.2.2a` —— 通常是上一版的紧急修补，官方会建议「所有正式版用户安装」；
- **预览版**：带 `pre` 字样（如 `1.2.0-pre34`）或标注 Release Candidate，面向插件开发者与体验用户，官方明确提示「普通用户谨慎使用」。

你在网盘里拿到的是 **1.2.1**（5.50M，包名 `indi.dmzz_yyhyy.lightnovelreader`）。官方此后已发布 1.2.2a（修复内置数据源的封面与插图加载异常）——想升级就去 GitHub Releases 下载，以页面当时显示的最新版为准。

升级前有一条硬性注意：**从 1.1.x 升到 1.2.0 之后，将无法再导入升级前导出的存档**，官方在 1.2.0 的发布说明里明确要求「请提前备份重要数据」。备份与升级的细节见 [常见问题与排查.md](常见问题与排查.md)。
