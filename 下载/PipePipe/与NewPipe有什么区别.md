> 两个都是免广告的第三方视频客户端，但已经是各自独立开发的两个应用。这篇用一张对照表讲清差别，帮你决定装哪个。

## 一、一句话说清两者的关系

PipePipe 是开发者在 2022 年初从 NewPipe 分叉（fork）出来的项目，之后**两边各自独立开发**：按官方仓库的说明，PipePipe 既不接收 NewPipe 的更新、也不向其回推改动，一个项目里修好的问题不会自动出现在另一个里。所以严格说，PipePipe 不是 NewPipe 的「新版」，而是从同一棵树上长出的另一棵树。

因为分叉时间早、改动大，两者连包名都不同：NewPipe 的包名是 `org.schabi.newpipe`，PipePipe 的包名是 `InfinityLoop1309.NewPipeEnhanced`——装在同一台手机上互不冲突，可以并存着各试几天再决定留哪个。

## 二、功能对照表

| 对比项 | NewPipe | PipePipe |
| --- | --- | --- |
| 支持平台 | YouTube、PeerTube、SoundCloud、Bandcamp、media.ccc.de 等 | YouTube、BiliBili、NicoNico |
| 跳过赞助片段（SponsorBlock） | 无 | 有，且 YouTube 与 B 站都可用 |
| 显示点踩数（Return YouTube Dislike） | 无 | 有 |
| 直播弹幕式聊天 | 无 | 有（弹幕形式滚动显示直播评论） |
| 登录账号 | 不支持登录 | 支持登录，可访问账号有权限的内容 |
| 屏蔽 Shorts / 付费视频、按关键词或频道过滤 | 无 | 有 |
| 音乐播放器模式 | 无 | 有 |
| 睡眠定时器 | 无 | 有 |
| 本地播放列表内搜索与排序 | 无 | 有 |

上表整理自两个项目的官方说明，功能边界会随版本变化，装之前建议再对照一遍两边的发布页。表格里没写全的播放体验（后台播放、手势这些）两边的差异，在 [后台播放与手势设置.md](后台播放与手势设置.md) 里单独展开。

## 三、怎么选

- **主要看 YouTube，还想听 SoundCloud、Bandcamp 的音频**：选 NewPipe，它支持的平台更多。
- **要刷 B 站或 NicoNico、想跳过赞助片段、想用自己账号看会员内容**：选 PipePipe，这些是它分叉后主攻的方向。
- **两个需求都有**：两个都装，包名不同不冲突。
- **拿不定主意**：先用本文开头的 PipePipe 安装文件资源（夸克网盘）装上试几天，不合适再换 NewPipe，迁移成本只有重新订阅一轮。

无论装哪个，都记得从各自的官方发布渠道拿安装包，安装与核验步骤见 [下载与安装教程.md](下载与安装教程.md)。
