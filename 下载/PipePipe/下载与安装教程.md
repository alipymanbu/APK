## 一、先认清它的分发方式

PipePipe 是一个开源 Android 客户端，作者只通过官方渠道发布安装包，Google Play 上搜不到正式上架版本。你拿到安装包的正常途径只有这几类：

| 渠道 | 地址 | 特点 |
| --- | --- | --- |
| 官网 | [pipepipe.dev](https://pipepipe.dev/) | 项目主页，跳转到官方发布页 |
| GitHub Releases | [github.com/InfinityLoop1308/PipePipe/releases](https://github.com/InfinityLoop1308/PipePipe/releases) | 新版本出现得最快，附每个版本的更新说明 |
| F-Droid | [f-droid.org/packages/InfinityLoop1309.NewPipeEnhanced](https://f-droid.org/packages/InfinityLoop1309.NewPipeEnhanced/) | 独立应用商店，上架时间可能落后于 GitHub |
| IzzyOnDroid | [apt.izzysoft.de/fdroid/index/apk/InfinityLoop1309.NewPipeEnhanced](https://apt.izzysoft.de/fdroid/index/apk/InfinityLoop1309.NewPipeEnhanced) | 另一个 F-Droid 类仓库，发布节奏同样独立 |

除以上官方渠道外，网上第三方镜像站流传的 APK 无法核验来源，不建议安装。如果你手里已经是离线安装包（比如通过本文开头的 PipePipe 安装文件资源（夸克网盘）转存得到的那份），直接进入下面的安装步骤即可，它的版本信息见第三节。

## 二、系统要求与 APK 选型

F-Droid 的收录记录显示，近期版本最低要求 Android 5.0 起、最新版本要求 Android 6.0+（不同版本要求可能不同，以官方发布页为准）。同一版本通常按 CPU 架构分成多个 APK，官方在发布说明里给的选择建议是：

| 你的设备 | 选这个 |
| --- | --- |
| 近几年的大部分手机 | `arm64-v8a` |
| 很老的手机 | `armeabi-v7a` |
| PC 上的 64 位安卓模拟器 | `x86_64` |
| PC 上的 32 位安卓模拟器 | `x86` |

拿不准就用 `arm64-v8a`，装不上再换。

## 三、安装步骤

1. 在手机上打开 APK 文件。Android 8 及以上会先要求授予「允许安装未知应用」权限——按提示在系统设置里给对应应用（浏览器或文件管理器）打开这个开关即可。
2. 点安装，等待完成。
3. 装完打开，首次启动会进入引导页，直接按默认设置走完就能用，登录不是必需的（什么时候值得登录，见 [B站与YouTube登录设置.md](B站与YouTube登录设置.md)）。

通过网盘拿到的这份安装包，核对信息如下（以此为准，网上搜到的是官方最新版，两者不一定是同一版）：

| 项目 | 值 |
| --- | --- |
| 版本 | 4.1.0 |
| 包名 | `InfinityLoop1309.NewPipeEnhanced` |
| 安装包大小 | 44.37M |
| MD5 | `6EC245AF80F9A7A3269646A2716B0C00` |

安装后可以在系统的应用信息里核对包名是否一致，避免装到了同名冒牌应用。

## 四、怎么判断安装包有没有被换过

社区 Wiki 维护了官方发布 APK 的签名证书指纹（SHA-256）：

```text
dec73429ce2563275f5ed19825e44652b32b363a46f38bdff9ad6dcde4842d88
```

用 [AppVerifier](https://github.com/soupslurpr/AppVerifier) 这类工具读一下你手里 APK 的签名指纹，与上面比对一致再装。指纹属于会随发布策略变化的信息，若比对不上，以官方发布说明为准。

## 五、装完之后怎么更新

三条路任选其一，保持固定即可，出问题时方便报版本：

- **应用内更新**：设置里有更新检查项，可以手动触发，也可以选择接收预发布版本。
- **GitHub Releases**：定期打开发布页看新版本，这是修复说明最全的地方。
- **Obtainium**：把 `https://github.com/InfinityLoop1308/PipePipe` 添加为源，它能盯着仓库提醒你出新版，不用注册任何商店账号。

F-Droid 与 IzzyOnDroid 的上架时间独立于 GitHub，新版本可能晚几天才出现；等修复等不及时，直接对照 GitHub 发布页的版本号判断自己装的是不是最新。

换渠道更新时留意一件事：Android 不允许在签名不一致时覆盖安装。如果覆盖安装时提示安装失败或签名冲突，多半是先后两个包不是同一来源签发的——最省事的做法是沿用当初的安装渠道；确实要换，先把应用数据导出备份，卸载重装后再导入，数据怎么搬见 [导入订阅与数据迁移.md](导入订阅与数据迁移.md)。

装好之后遇到播放不了、搜索失败一类的问题，排查思路见 [常见问题与故障排除.md](常见问题与故障排除.md)；它和 NewPipe 到底是什么关系、该用哪个，见 [与NewPipe有什么区别.md](与NewPipe有什么区别.md)。
