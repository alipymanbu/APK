## 一、先搞清楚「换 DNS 能改变什么」

DNS 只负责「把域名翻译成 IP」这一件事。换 DNS 服务器影响的是：域名解析的快慢、解析结果被污染或劫持的可能、以及部分按域名过滤的网络行为。它**不会提升你的下载和上传速度**——带宽多少还是多少。官方说明里也是这个口径：改善的是浏览响应，不是带宽。

所以换 DNS 值得动手的三种情况：

- 打开网页时转圈久（域名解析慢），但看视频、下载并不慢；
- 怀疑运营商 DNS 把某些域名解析错了或插了广告；
- 想让家里的设备自动拦掉恶意域名或成人站点（选带过滤的 DNS）。

选型小结：

- **只想快点、不被烦**：Cloudflare 或 Google 起步，测速后按结果定；
- **想拦恶意网站**：Quad9 或 Comodo；
- **家长控制**：CleanBrowsing 家庭档（`185.228.168.168`）或 OpenDNS 的 FamilyShield 档（`208.67.222.123`）；
- **明确不想要任何过滤**：DNS.WATCH 或 UncensoredDNS。

带过滤的 DNS 会真的拦站——选了家庭档之后有些网站打不开是它在过滤，不是坏了，换个档位即可恢复。

## 三、用内置测速挑最快的

预设这么多，不用挨个试：DNS Changer 自带 DNS 服务器测速，直接在你当前的网络环境里量延迟。用法：

1. 打开应用，进测速（Speed Test）功能页；
2. 点开始，它会逐个测试预设服务器的响应时间，等它跑完；
3. 看结果列表，数值越小越快；同一个城市不同运营商的结果可能差很多，以你自己网络的测试结果为准；
4. 直接从结果里选中意的那一家，回主界面连接。

两个注意点：测速结果只反映**解析延迟**，和你的带宽无关；换了一个网络（换了 Wi-Fi 或切流量）之后，最快的那个可能换人，重新测一遍即可。

## 四、想用的地址不在列表里

预设列表外的地址（比如你自己搭的解析服务）走自定义一栏填入，填写规则和 IPv4/IPv6 的注意事项见 [怎么修改DNS服务器.md](怎么修改DNS服务器.md)。

填完连上之后发现网页打不开，先排除地址本身的问题：把主 DNS 换成上面表里的任一常用地址（比如 1.1.1.1）再连一次，能通就说明是那个自定义地址的问题，不通才是手机或网络的问题，按 [连接后无法上网怎么解决.md](连接后无法上网怎么解决.md) 往下查。其他常见疑问（root、流量去向、Pro 差异）集中在 [常见问题解答.md](常见问题解答.md)。
