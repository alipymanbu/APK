## 一、改 DNS 的基本路径

装好并完成首次 VPN 授权后（没装过的先看 [下载与安装教程.md](下载与安装教程.md)），改 DNS 就是三步：

1. 打开 DNS Changer，在服务器列表里挑一个预设的公共 DNS，或切到自定义一栏自己填地址；
2. 点连接开关，状态从断开变为已连接；
3. 此时手机的 Wi-Fi 和移动数据都会改用这个 DNS 解析域名——它不需要你分别去改两个网络的设置，也不需要 root。

断开同样在这个开关上：再点一次即恢复手机默认的 DNS。如果你在系统里开启了「始终开启的 VPN」，断开和切换的行为会受影响，遇到异常先看 [连接后无法上网怎么解决.md](连接后无法上网怎么解决.md)。

顺带一提，改 DNS 不是只有用应用这一条路：Wi-Fi 设置里手动改、系统「私人 DNS」、路由器上改都能做到，各自适合什么场景见 [安卓改DNS的几种方式对比.md](安卓改DNS的几种方式对比.md)；想在移动数据下也生效、或者要一键切换加测速，应用这条路最合适。

## 二、用预设列表还是自定义

**预设列表**适合大多数情况：官方内置了一批公共 DNS（Cloudflare、Google Public DNS、Quad9、OpenDNS、CleanBrowsing、DNS.WATCH、Comodo Secure DNS、Level3、Neustar UltraDNS、UncensoredDNS、Yandex.DNS 等），点选即可，不用自己查地址。各家有什么差别、按什么场景选，直接翻 [公共DNS服务器对照表.md](公共DNS服务器对照表.md)。

**自定义**适合两种情况：

- 你想用的 DNS 不在预设列表里（比如自建的解析服务、运营商给的本地 DNS）；
- 你从某个可信渠道拿到了一组明确的地址，想原样填进去。

自定义要填两个地址：主 DNS 和备用 DNS。主 DNS 不通时系统才会去问备用，所以两个地址不要填成同一个。

## 三、IPv4 与 IPv6 两栏怎么填

DNS Changer 支持 IPv4 和 IPv6 两种 DNS 服务器。填写时注意：

- IPv4 地址是四段数字（如 `1.1.1.1`），IPv6 地址是一串冒号分隔的十六进制（如 `2606:4700:4700::1111`），**别把 IPv4 填进 IPv6 栏**，填错那栏会导致解析失败；
- 只填 IPv4 也能正常用——你家宽带或运营商暂不支持 IPv6 时，IPv6 栏留空即可；
- 不确定某个服务商的 IPv6 地址时，优先用它官网公布的地址，别凭记忆拼。

## 四、连接后的几个日常细节

- **常驻通知**：连接期间通知栏会一直挂着一条通知，这是安卓对活跃 VPN 的系统要求。点开通知可以快速断开；不要在系统里把这条通知强行关成「静默隐藏」，否则有时会找不到断开入口。
- **换网络后**：从 Wi-Fi 切到流量（或反过来）时，应用会跟着新网络走，一般不需要手动重连；个别机型如果发现解析又回到默认了，重新点一次断开再连接。
- **开机自启**：应用带「开机自启」选项，开了它，重启手机后会自动恢复连接，适合想让 DNS 设置长期生效的情况；不常改的话不开也没关系。
- **分流是 Pro 功能**：按官方的功能说明，「指定哪些应用走所选 DNS」属于 Pro 版能力，免费版是全局生效——所有应用的解析都走你选的那个 DNS。

## 五、改完没效果的排查顺序

先确认应用界面里状态确实是「已连接」，再按下面的顺序查：

1. 浏览器开个无痕窗口访问网页，排除浏览器本地缓存；
2. 断开重连一次；
3. 检查自定义地址有没有填错栏、拼错数字；
4. 仍不行就按 [连接后无法上网怎么解决.md](连接后无法上网怎么解决.md) 的清单逐条过，最常见的两个原因是系统「私人 DNS」和别的 VPN 应用在抢通道。

选不好用哪个 DNS 的话，可以用应用内置的 DNS 测速，跑一遍就知道哪个在你的网络里响应最快，用法和各家地址见 [公共DNS服务器对照表.md](公共DNS服务器对照表.md)。
