## 一、先花三十秒确认故障范围

排查前先分清是「整个手机断网」还是「只是个别网站打不开」，处理路径完全不同：

- **整个断网**：任何应用都连不上、网页全打不开 → 从下面第二节开始按顺序查；
- **个别网站打不开、其他正常** → 多半不是故障：你选的可能是带过滤的 DNS（Quad9、CleanBrowsing、Comodo 这类），它把那个域名拦了。换一个无过滤的 DNS（如 DNS.WATCH）或恢复默认即可验证，各家档位见 [公共DNS服务器对照表.md](公共DNS服务器对照表.md)。

## 二、按命中率排查

### 1. 检查 DNS 地址有没有填错

自定义模式下最常见的问题。核对三件事：数字有没有拼错（`8.8.8.8` 打成 `8.8.8.9` 就可能不通）、IPv4 有没有误填进 IPv6 栏、主备两个地址是否填成了同一个。拿不准就把主 DNS 改成预设列表里的一档再连。

### 2. 关掉系统自带的「私人 DNS」

安卓 9 起系统设置里有一个「私人 DNS」（设置 → 网络 → 私人 DNS，不同机型叫法略有差异）。它和第三方改 DNS 应用走的是两套机制，同时开启容易互相干扰。处理：把「私人 DNS」设为**自动或关闭**，再断开重连 DNS Changer。

### 3. 断开其他 VPN 类应用

安卓同一时间只允许一个应用占用 VPN 通道。如果你装着其他 VPN、加速器、广告过滤类应用，先断开它们（最好从各自应用里断，而不是只杀后台），再连 DNS Changer。判断依据：状态栏如果出现两个 VPN 钥匙图标，或之前装过的 VPN 应用还在「设置 → VPN」列表里挂着，就可能冲突。

### 4. 检查「始终开启的 VPN」设置

「设置 → 网络 → VPN」里如果给 DNS Changer（或之前某个 VPN 应用）开了「始终开启的 VPN」，系统会按这条设置拦截或接管连接。处理：进这个页面，把「始终开启」只留给 DNS Changer，或先全部关掉再重连试试。

### 5. 换一个 DNS 服务器再连

你所在运营商的网络到某个公共 DNS 的链路可能不通（公共 DNS 偶有区域波动）。在应用里换一档预设（比如从 Yandex 换成 Cloudflare）再连，能通就说明只是那一档在当前网络里不可达，测速重选即可。

### 6. 排除当前网络的限制

部分校园网、企业网、酒店 Wi-Fi 会在网络层限制外部 DNS 查询。验证方法：手机切到移动数据再连一次，能正常上网就说明是那个 Wi-Fi 环境的限制，这类网络下改 DNS 没有办法绕，只能在该网络下恢复默认。

### 7. 兜底动作

以上都没解决，按顺序做：断开重连一次 → 彻底关闭应用后重开 → 重启手机 → 还怀疑有别的应用捣乱，就重启进**安全模式**验证（长按「关机」选项会出现「进入安全模式」；安全模式下第三方应用全部停用，若这时一切正常，就逐个清理最近装的应用，重点怀疑其他 VPN、加速器、网络过滤类）→ 最后才到「设置 → 应用 → DNS Changer」清除数据，重新走一遍授权（首次授权流程见 [下载与安装教程.md](下载与安装教程.md)）。清除数据会丢掉你在应用里的自定义地址，先抄下来。

## 三、连上了但「时好时坏」

- **换网络后失效**：Wi-Fi 切流量、或连上新的 Wi-Fi 后解析回到默认，重新断开再连接一次即可；想让重启后也自动恢复，开启应用里的「开机自启」选项。
- **锁屏一会儿后变慢**：部分机型的省电策略会在息屏后冻结后台应用。把 DNS Changer 加入电池优化的白名单（设置 → 电池 → 应用耗电管理），避免它被系统挂起。
- **只有某些应用解析异常**：确认配置里没有按应用分流的残留设置（分流是 Pro 功能，免费版是全局生效）；拿不准就按上一条清除数据重连。
- **只有浏览器「没生效」**：浏览器自带的「安全 DNS」（DoH）会绕过系统 DNS、用它自己那套加密解析。判断方法：同一个网址换别的应用打开，其他都正常、唯独浏览器不对，基本就是它。到浏览器设置里关掉「使用安全 DNS」再试。
- **连公共 Wi-Fi 后全断**：很多公共 Wi-Fi 要先在认证页点一次登录。这类网络会先把你的 DNS 查询拦到认证页，先断开应用、把认证页过完，再重新连接。

排查完仍然反复出现、且换网络也不能恢复的，可以带着「机型、安卓版本、当时的 DNS 地址」去官方反馈渠道（support@AppPlanex.com）询问，这是开发者在官方页面公布的联系邮箱。装好还没连过的、想知道改完 DNS 之后日常怎么用的，分别看 [下载与安装教程.md](下载与安装教程.md) 和 [怎么修改DNS服务器.md](怎么修改DNS服务器.md)。
