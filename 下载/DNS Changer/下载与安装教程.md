## 一、安装前先确认这几点

DNS Changer 是一款安卓端的 DNS 修改工具，开发者是 AppPlanex，官方列名为 DNS Changer - IPv4 & IPv6。它不需要 root，也不能在 iPhone 或电脑上用。

网盘里这份安装包的版本信息如下，装好后可以在系统「设置 → 应用」里核对包名是否一致：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.6.3 |
| 包名 | com.appplanex.dnschanger |
| 安装包大小 | 6.80 MB |
| MD5 | 766E685ECF1B96F36196566496BDD888 |
| 系统要求 | 安卓 5.2 以上（以安装包信息为准） |
| 信息核对时间 | 2026-09-23 |

两点说明：官方渠道的版本更新较快，截至 2026-09 官方已发布更新的版本，具体以官方页面为准；但网盘里这份就是 2.6.3，文档里的版本、包名、大小都按它来。如果你的手机系统版本低于要求，安装时会提示解析失败或版本不符。

## 二、下载与安装步骤

1. 打开上面的 **DNS Changer 安装文件资源（夸克网盘）** 链接，把 apk 文件转存或下载到手机。
2. 在手机上点开下载好的 apk。第一次装会触发系统的「未知来源应用」限制：
   - 部分手机（如小米、华为、OPPO、vivo）会弹出「是否允许此来源安装应用」，点允许；
   - 有的系统会让你去「设置 → 安全 → 安装未知应用」里，给浏览器或文件管理器单独开权限，开完再回来点安装。
3. 等安装完成，点打开。图标名会显示为 DNS Changer。
4. 首次打开后，界面上会有一个连接开关。点下连接时，系统会弹出「VPN 连接请求」提示，问你是否允许该应用建立 VPN 连接，点**确定/允许**。

第 4 步的弹窗不是出问题了，而是它改 DNS 的正常方式：这类应用要借助安卓的本地 VPN 接口才能接管 DNS 地址。按官方的说明，它只建立本地 VPN 接口来修改 DNS 服务器地址，网络流量并不会被发往某个远程 VPN 服务器。授权后状态栏会出现一个 VPN 钥匙图标和一条常驻通知，这是安卓对所有活跃 VPN 的统一要求，不是异常。

## 三、验证 DNS 是否已经生效

连上之后，用下面任意一种方式确认：

- 回到应用主界面，看它显示的当前连接类型和 IP 信息是否为你所选的 DNS；
- 手机断开再重连一次 Wi-Fi 或移动数据，浏览器随便打开一个网页，能正常打开说明解析正常；
- 想确认解析走的就是新 DNS，可以在应用内置的测速或网络信息页面查看（用法见 [公共DNS服务器对照表.md](公共DNS服务器对照表.md)）。

## 四、安装环节常见的失败

- **提示「解析包出现问题」**：多半是 apk 没下载完整，回网盘重新下载一遍再装；也可能是手机系统版本低于上面表格里的要求。
- **提示版本降级失败或安装冲突**：手机上已经装了更高版本时，无法直接覆盖装回旧版，需要先卸载已有的 DNS Changer 再装。
- **安装完打不开或闪退**：先重启手机再试；仍不行就到「设置 → 应用」里清除它的数据，重新打开。
- **连接开关点了没反应**：重点检查第 4 步的 VPN 授权是否被拒绝过——去「设置 → 应用 → DNS Changer」里看有没有 VPN 连接相关权限，或清除数据后重新授权。
