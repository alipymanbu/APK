## 一、四种方式一览

同样是「把 DNS 换掉」，安卓上能落手的位置有四个，差别主要在**覆盖范围**和**操作门槛**：

| 方式 | 覆盖范围 | 门槛 | 短板 |
| --- | --- | --- | --- |
| 当前 Wi-Fi 里手动改（长按网络 → 修改 → 静态 IP，填 DNS） | 只限这一个 Wi-Fi | 免装任何东西 | 每换一个 Wi-Fi 要重设一遍；**移动数据用不了这招** |
| 系统「私人 DNS」（安卓 9 起，设置 → 网络 → 私人 DNS） | 全局，Wi-Fi 和流量都管 | 免装 | 填的是主机名不是 IP；部分公共/企业网络下连不通；只支持加密 DNS（DoT） |
| 路由器管理页里改 DNS | 接这台路由器的所有设备 | 要有路由器管理权限 | 出门就失效；家里以外的网络管不到 |
| 改 DNS 应用（如 DNS Changer） | 全局，Wi-Fi 和流量都管 | 装一个应用，首次要允许 VPN 授权 | 占用安卓唯一的 VPN 通道，不能和其他 VPN 同时用 |

DNS Changer 属于最后一种：它借本地 VPN 接口改 DNS，免 root、同时管住 Wi-Fi 和移动数据，还带一键切换与内置测速——这是它在「Wi-Fi 里手动改」之外存在的理由。装法见 [下载与安装教程.md](下载与安装教程.md)，日常操作见 [怎么修改DNS服务器.md](怎么修改DNS服务器.md)。

## 二、按你的场景对号入座

- **只想在家里的 Wi-Fi 上换 DNS，手机就一台**：在 Wi-Fi 设置里手动改最省事，不用装应用；
- **家里所有设备（电视、平板、访客手机）都想跟着换**：改路由器，一次管全家；
- **移动数据下也想换 DNS**：只有「私人 DNS」和改 DNS 应用两条路；
- **想频繁切换、还想先测速再选**：改 DNS 应用最顺手，DNS Changer 内置测速（用法见 [公共DNS服务器对照表.md](公共DNS服务器对照表.md)）；
- **在意解析被窃听、想走加密**：系统「私人 DNS」是免装方案；改 DNS 应用走的是常规 53 端口查询。

## 三、能不能混着用

- **「私人 DNS」和改 DNS 应用二选一**。两套机制叠着开容易互相干扰，是「连上却打不开网页」的常见原因，排查动作见 [连接后无法上网怎么解决.md](连接后无法上网怎么解决.md)；
- **VPN 通道是独占的**。安卓同一时间只允许一个应用占 VPN，你如果同时用其他 VPN、加速器，只能轮着来；
- **浏览器可能自作主张**。Chrome 等浏览器自带「安全 DNS」设置，开了它浏览器会绕过系统 DNS 直接用自己那套加密解析——你改了 DNS 却发现浏览器「没生效」，先去看浏览器自己的设置；
- **路由器改的和手机改的不冲突**：路由器层面改了 DNS，手机再用应用改，手机会优先走自己那套，回家想恢复默认时断开应用即可。

## 四、回到 DNS Changer 的适用判断

一句话归纳：手机上临时试一个 DNS、或者要在流量下换 DNS、或者想一键切换加测速，用它合适；如果你的需求只是「家里固定换个解析」，Wi-Fi 手动改或改路由器就够了，不必多装一个应用。选好之后用哪个 DNS 服务器，对照表和测速方法都在 [公共DNS服务器对照表.md](公共DNS服务器对照表.md)。
