## 一、需要 root 吗？

不需要。它通过安卓的本地 VPN 接口来修改 DNS 服务器地址，这是系统提供的标准机制，普通用户权限就能完成。代价是首次连接时系统会弹一次「VPN 连接请求」授权框，点允许即可（流程见 [下载与安装教程.md](下载与安装教程.md)）。

## 二、它会不会把我的流量发给某个 VPN 服务器？

不会。状态栏出现 VPN 图标是因为它借用了 VPN 接口，但按官方说明，它只建立本地 VPN 接口来修改 DNS 服务器地址，你的网络流量不会被发送到远程 VPN 服务器。真正发出去的只有「域名 → 该问哪个 DNS 服务器」的解析查询，问的对象就是你选的那家公共 DNS（如 Cloudflare、Google），这一点和你不装它、手动在 Wi-Fi 设置里改 DNS 是一样的。

## 三、免费版和 Pro 差在哪？

按官方公布的功能列表，免费版已经包含：预设公共 DNS 选择、自定义 DNS、DNS 测速、IPv4 与 IPv6、Wi-Fi 与移动数据支持、开机自启、实时网络图与连接信息。Pro 独有的是「指定哪些应用走所选 DNS」的分流能力。免费版在使用中无广告、无弹窗——这也是官方明确写出的口径。是否需要 Pro 只取决于你想不想按应用分流，普通改 DNS 用免费版就够了。

## 四、为什么状态栏一直挂着一条通知？

那是安卓对活跃 VPN 连接的系统要求，应用自己去掉不掉。它其实有用：点开这条通知可以快速断开或查看状态。连接期间别把这条通知隐藏，否则断开要回应用里找开关。

## 五、它费电、占内存吗？

它只是在本地接管 DNS 查询，不转发流量，官方口径是不额外消耗电池和内存。实际耗电可以在手机的「设置 → 电池」里看它的占比，和微信、浏览器这类常驻应用对比就知道了；如果你发现它占比异常，按 [连接后无法上网怎么解决.md](连接后无法上网怎么解决.md) 第三节末尾提到的电池优化白名单处理。

## 六、网盘里是 2.6.3，官方已经有更新的版本了，要升级吗？

网盘里这份安装包的版本是 2.6.3（包名 com.appplanex.dnschanger、6.80 MB，信息核对于 2026-09-23），官方渠道后续一直在更新，截至 2026-09 已有更高版本，以官方页面为准。两个版本都能正常改 DNS，核心功能没有差别；区别主要在新机型的适配和新加的 DNS 服务商。用不用升级由你自己决定——只要包名一致，就是同一个应用。

## 七、我的手机能装吗？

要求安卓 5.2 以上（以这份安装包信息为准），这个门槛相当低，近几年的手机基本都满足。它只支持安卓手机，没有 iPhone 版和电脑版；平板装安卓系统的可以正常使用。安装时若提示系统版本不符，就是当前机型不在支持范围内。

## 八、改了 DNS 之后，哪些东西会跟着变？

- 变的：所有应用的域名解析都走你选的 DNS（免费版全局生效），解析速度、是否被过滤、部分域名的可达性会跟着变；
- 不变的：你的 IP 归属地、带宽、游戏服务器连接——它不是代理也不改 IP，想隐藏 IP 或换地区访问的读者，这个工具不解决那个需求，别装错工具。

各家 DNS 服务商的过滤与速度差别、以及用测速挑最快节点的方法，见 [公共DNS服务器对照表.md](公共DNS服务器对照表.md)；从安装到改 DNS 的完整操作路径，从 [下载与安装教程.md](下载与安装教程.md) 开始。

## 九、手机自带的「私人 DNS」和它是一回事吗？

不是一回事，但解决的是同一个问题。系统「私人 DNS」是安卓 9 起的内置功能，走加密解析（DoT），填的是服务商主机名而不是 IP；DNS Changer 这类应用走的是常规查询，胜在能一键切换、内置测速、而且不挑网络。两套机制不要同时开着用，会互相干扰。四种改 DNS 方式的完整对比（Wi-Fi 手动改 / 私人 DNS / 路由器改 / 应用改）见 [安卓改DNS的几种方式对比.md](安卓改DNS的几种方式对比.md)，按你的场景选即可。
