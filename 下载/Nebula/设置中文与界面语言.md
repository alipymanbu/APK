# Nebula 设置中文与界面语言

> Nebula 的控制面板支持切换简体中文，这篇给出切换路径，顺带把面板里常用的几处设置一次说清。

## 一、把面板切到简体中文

中文社区提供的参考路径是这三步（不同版本菜单叫法可能略有差别，找不到就按括号里的关键词认）：

1. 打开 Nebula 面板，点**左上角的三横线菜单**（抽屉菜单）。
2. 进入 **Settings（设置）**。
3. 点 **Language（语言）**，在列表里选 **Chinese Simplified（简体中文）**。

切换后界面立即生效，不需要重启应用。如果你的版本里 Language 项的位置不同，可以在设置页里找「语言 / Language / Locale」这类字样；万一整个面板没有语言选项，说明当前版本未内置中文，只能用英文界面 —— 功能上没有区别，图标照常可用。

## 二、面板里常用的几个入口

把面板当成这套图标的「控制中心」，常用入口就这几个：

| 入口 | 作用 |
| --- | --- |
| Apply / 应用 | 把图标包套到你正在用的桌面上，并显示检测到的支持列表 |
| 图标浏览 / Icons | 按名称或分类查看 7000 多枚图标，确认你要的应用有没有被覆盖 |
| Request / 请求 | 提交缺失图标的申请（每周 10 枚的额度） |
| Wallpapers / 壁纸 | 浏览并应用 20 张配套壁纸 |
| Settings / 设置 | 语言切换、面板外观、关于信息等 |

第一次装完建议按这个顺序走一遍：先切语言（本篇），再 Apply 应用到桌面（见应用篇），最后翻一下图标浏览确认常用应用都覆盖了。

## 三、壁纸怎么一起换

面板里那 20 张壁纸与图标的配色是配套设计的，一起换观感更完整：

1. 面板 → **Wallpapers（壁纸）**。
2. 点开任意一张，选择**下载或应用**，按提示交给系统或桌面设置为壁纸。

也可以完全不用面板的壁纸，桌面壁纸保持原样，只换图标 —— 两者不冲突。

## 四、面板之外没有别的设置

图标包的特殊性在于：换图标、调图标大小、改图标形状这些**桌面侧**的选项都在你的桌面启动器里，不在 Nebula 面板里。面板管的是素材浏览、请求、语言这类自己的事，桌面上的观感调整去桌面设置里找，两边的分工别搞混。
