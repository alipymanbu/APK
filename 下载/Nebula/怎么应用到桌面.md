## 一、先确认一件事：你用的桌面能不能套图标包

Nebula 的官方说明里专门写了一条：**必须使用自定义桌面（第三方 launcher），图标包才能生效**。原因是图标包本身不替换系统界面，它只提供一套图标素材，由桌面读取并套用。

判断办法很简单：

1. 长按桌面空白处，看有没有「设置 / 壁纸与样式 / 桌面设置」这类入口，进去翻一翻有没有**「图标包 / Icon Pack / 图标风格 / 主题」**字样的选项。
2. 有 → 直接进第三节的路径表操作。
3. 没有 → 你手机的系统自带桌面不支持，装一个支持图标包的第三方桌面即可（Play 商店里主流的 Nova、Action、Apex、Smart、Niagara、Microsoft Launcher 等都支持），装完把默认桌面切换成它。

少数系统有自己的主题机制（例如三星的 Good Lock 里的 Theme Park 组件可以套用 Play 上的图标包；部分国产系统走自家主题商店）—— 这种情况按各自主题工具的流程走，不走下面的通用路径。

另有一条经验值得先记住：**Google 自家的 Now Launcher 这类原生桌面不支持任何图标包**，别在它身上浪费时间找设置项。

## 二、两条应用入口

装好 Nebula 后有两条路可以走到「应用」这一步，结果一样：

- **从桌面侧**：桌面设置 → 外观 / 图标 → 图标包列表 → 选 Nebula。
- **从面板侧**：打开 Nebula 面板 → 找 Apply（应用）入口 → 面板会列出它检测到的、支持套用的桌面 → 点选后在弹窗里确认。面板对**默认桌面**支持一键快速应用，多数情况点一下就完成。

面板侧入口省事的地方在于：它会直接告诉你哪些桌面能用，不用自己去翻桌面的设置菜单。

## 三、主流桌面的套用路径

不同桌面版本菜单名略有出入，找不到就优先找**「外观 / Appearance / 主题 / 图标」**相关的项：

| 桌面 | 操作路径 |
| --- | --- |
| Nova Launcher | 长按桌面 → Nova 设置 → 外观 → 图标主题 → 选 Nebula |
| Action Launcher | 长按桌面 → 设置 → 屏幕（显示）→ 图标包 → 选 Nebula |
| Apex Launcher | Apex 设置 → 主题设置 → 选 Nebula → 应用 |
| Smart Launcher | 长按桌面 → 设置 → 外观 / 图标包 → 选 Nebula |
| Niagara Launcher | Niagara 设置 → 外观 → 图标包 → 选 Nebula |
| Microsoft Launcher | 设置 → 个性化 → 图标包 → 选 Nebula |

应用成功后，桌面与应用抽屉里的图标会整体换成 Nebula 的样式；没换的那几个图标属于覆盖范围问题，见下一节。

表里列的是最有代表性的几个；ADW、Go、Solo、Aviate 这类老牌桌面同样长期支持图标包。你手里的桌面到底在不在支持之列，最省事的判据就是打开面板的 Apply 入口看它列出了谁 —— 列表里有就能用。

## 四、应用之后可以再调的细节

- **图标形状与大小**：多数桌面允许在「图标」设置里调底板形状、缩放比例，Nebula 的图标是 192×192 的高分辨率素材，调大也不容易糊。
- **配套壁纸**：面板里带了 20 张配套壁纸，和这套图标的配色是一起设计的，一起换上观感更完整。
- **个别图标不满意**：长按桌面上的某个图标 → 编辑 → 从 Nebula 的列表里给这个应用指定另一枚图标；这只是单点替换，不影响全局主题。
- **界面语言**：面板支持切换到简体中文，路径见 [设置中文与界面语言.md](设置中文与界面语言.md)。
- **缺图标的处理**：有的应用没被主题覆盖，先在面板里提交图标请求，等每周更新；急用时也可以先按上一条单独指定替代图标。
- **日历类应用的日期**：套用后日历图标上的日期停住不动，多与桌面的动态日历渲染有关，排查步骤见 [日历图标日期不更新怎么办.md](日历图标日期不更新怎么办.md)。
