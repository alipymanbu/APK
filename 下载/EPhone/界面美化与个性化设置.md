## 一、边框：最外层的「手机壳」

首次打开时选的有边框/无边框，决定小手机界面外面要不要一圈手机外壳样式；据发布页介绍，这个开关在启动时可以切换，之后也能在设置里再改（以你手上版本的界面为准）。两种模式功能一致，纯观感差别。

## 二、能自定义的项目一览

据发布页介绍，可以逐项替换的包括：

| 项目 | 说明 | 注意点 |
| --- | --- | --- |
| 壁纸 | 聊天与桌面背景 | 支持导入外部图片资源 |
| 字体 | 界面字体 | 通过字体文件的 URL 链接导入 |
| 气泡样式 | 聊天气泡的外观 | 可逐项替换 |
| 通知音效 | 收到消息的提示音 | 可换成自己的音频 |
| 收发动画 | 消息出现与发出的动效 | 可调可换 |

这类应用改版频繁，不同版本的菜单名和位置可能对不上截图教程，认「壁纸 / 字体 / 外观 / 设置」这类关键词去找入口即可。找不到某一设置项时，先确认应用是本篇对应的 EPhone（包名 `com.ephone.jcyapp`），再对照 [下载与安装教程.md](下载与安装教程.md) 里的安装包信息。

## 三、字体与壁纸的 URL 导入怎么玩

字体走的是链接导入：找一个字体文件的直链地址，粘进字体设置里。所谓直链，是浏览器打开就能直接开始下载、而不是跳转到下载页面的地址。

- 链接加载不出来时，先在浏览器里打开这个链接，验证能不能直达文件本身；
- 图片壁纸同理，优先用稳定图床生成的直链；
- 导入后界面没变化，退出应用重新进一次再看。

## 四、改乱了怎么退回来

外观类的改动不碰聊天数据，可以放心折腾。改得不满意，回到对应设置项换回默认样式即可；想不起改过哪些，就把自己动过的项目逐个换回去。真到界面乱得没法看的程度，卸载重装也能回到初始状态——但应用本地存的数据（包括聊天记录）大概率会一起没掉，重装前先想清楚。
