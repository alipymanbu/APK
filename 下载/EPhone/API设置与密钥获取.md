## 一、为什么装完还得配 API

社区教程里有个说法值得先知道：小手机这类应用的本体是一层网页界面（HTML 前端），你在界面上看到的能力——角色主动发消息、朋友圈动态、模拟来电、识图——都要靠背后接入的 AI 服务来驱动。EPhone 就是这个家族里打包成安卓应用的一个改版（包名里的 `jcy` 与社区流传的 JCY 改版对应）。

换句话说：装好应用只是有了「手机壳」，AI 服务要你自己接。接口配置的入口就在应用主界面里，需要填的就是 URL 和密钥两项。

## 二、API 由哪两部分组成

| 组成 | 通俗理解 | 长什么样 |
| --- | --- | --- |
| URL（接口地址） | 中转服务的地址 | 一串 `https://` 开头的网址 |
| 密钥（key / 令牌） | 证明「这个请求是你发的」的凭证 | 一长串字母数字组合 |

填错任何一个，表现都是角色不回消息或直接报错。

## 三、接口从哪来：三种渠道

- **自建**：自己部署或直接购买官方模型的接口，自由度最高，但流程繁琐，不适合只想先玩起来的新手。
- **公益站**：社区自发搭建的免费中转站，注册就能用，主流模型基本都有。缺点是稳定性看运营者，高峰期容易提示「上游负载」，也可能随时停摆。
- **付费站**：按用量计费的中转站，稳定性一般好于公益站，花费因人而异。

三种渠道任选其一即可；无论哪种，你最终要拿到的都是上面那两样——一个 URL、一个密钥。站点怎么选、安不安全请自行判断，本文不推荐任何具体站点。

公益站要多说一句：它的模型列表与额度是随时可能调整的，今天能用的模型明天可能下线，整个站也可能突然关闭——用之前对「说停就停」有个预期。去哪发现这些站、按哪几项筛选，展开成了单独一篇：[公益站怎么找与怎么挑.md](公益站怎么找与怎么挑.md)。

## 四、拿到地址和密钥的通用步骤

公益站与付费站的界面大同小异，一般流程是：

1. 注册并登录站点；
2. 找到「令牌管理」（有的叫令牌或 API Keys，多在侧边栏菜单里）；
3. 新建令牌，额度与有效期按站点规则选（一般可选无限额度、永不过期）；
4. 复制生成出来的那串字符——这就是你的密钥。

接口地址一般就是站点自己的网址。

## 五、填写与保存

1. 进入 EPhone 主界面的 API 设置；
2. URL 栏填站点地址，**把结尾的 `/v1` 之类后缀去掉**——这是这类应用最常见的填错点，路径由应用自己拼接；
3. 密钥栏粘贴刚才复制的令牌，注意前后别带上空格或换行；
4. 保存，然后随便发一句话，看角色是否正常回复。

有模型选择入口的话，选一个站点列表里确实提供的模型名；模型名写错或站点没有这个模型，同样会不回复。

顺带提醒：地址带不带 `/v1` 是每个前端自己的约定——有的要求去掉、有的反而要求带上。EPhone 按上面的写法处理即可，但你以后换别的聊天前端时别照搬，以那个前端的说明为准。

## 六、填完还是不回，先查这几样

- 地址结尾是不是还挂着 `/v1`；
- 密钥有没有复制完整、有没有混进空格；
- 站点是不是正在「上游负载」（高峰期常见，等一会再试）；
- 换一个模型名再试。

逐项排查仍不行，翻 [常见问题与报错处理.md](常见问题与报错处理.md) 按现象对号入座；想让角色聊起来更有设定感，接着看 [虚拟角色与世界书导入.md](虚拟角色与世界书导入.md)。
