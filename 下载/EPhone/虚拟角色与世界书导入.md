## 一、角色设定管什么

角色是这个玩法的主角：你可以在应用里自建聊天对象，把性格、语气、背景故事写成一段设定文本；动漫、游戏角色或者你自己的 OC 都可以。设定写得越具体，回复越贴近你要的感觉——只写一句「温柔」，模型能发挥的空间就全靠猜了。

新建聊天的入口在主界面上；据发布页介绍，一对一私聊和群聊两种形态都有（以你手上版本的界面为准）。角色能不能开口说话，前提是 API 已经配好，还没配的先看 [API设置与密钥获取.md](API设置与密钥获取.md)。

## 二、世界书是什么

世界书（Lorebook）是 AI 角色扮演圈通用的设定文件，常见后缀 `.json`，最早流行于 SillyTavern 这类工具。它的机制像一本词典：你预先写好「关键词 → 内容」的条目，对话里出现关键词时，对应内容才被提供给模型。

比如你设了一条「蟹堡王 → 一家快餐店」，当对话里出现「蟹堡王」时模型就知道那是什么；没出现就不占上下文。它解决的是「设定之外的专有名词模型不知道」的问题——世界观、地名、人物关系、行为规则，都适合往里放。据发布页介绍，EPhone 支持通过世界书文件批量导入人物设定，包含规则与响应倾向。

## 三、现成资源从哪来

先分清两种文件：在这个生态里，**世界书和各类设定文件常见 `.json` 后缀**；而**角色卡在酒馆（SillyTavern）生态里多为 png 图片**——设定文本内嵌在图片数据里，所以一张「图」其实是一张卡。

- **社区分享**：Discord 等社区有大量玩家自建的世界书与角色卡，进社区一般要先完成新人验证；找资源时留意有没有专门的搜索频道，比在资源频道里翻标签高效得多；
- **公开卡站**：社区之外也有可按标签检索的角色卡站点，多面向英文用户，检索体验一般（这是社区里的常见反馈）；
- **不建议**：网上有人打包出售成 GB 的角色卡合集，有玩家反馈这类合集类型混杂、完成度不明、还缺配套设定，不如自己挑几张合心意的；
- **自己动手**：一条条目就是「关键词 + 内容」两栏，多个关键词之间用英文半角逗号隔开。

png 角色卡能不能直接导进 EPhone，以你手上版本的导入入口为准；小手机这类轻量前端常见的用法是把卡里的设定文字取出来，贴进角色设定里当人设用。

来源不明的文件导入前留意一下内容——世界书本身是纯文本设定，但里面写的规则会直接影响模型的回复倾向，先看一眼再导入。

## 四、导入了不生效，按这几样查

| 现象 | 常见原因 |
| --- | --- |
| 条目从不触发 | 对话里的词和关键词没对上（多数是逐字匹配，差一个字都不行）；条目没启用 |
| 触发了但回复没用上 | 有的版本需要把世界书挂到对应聊天上才生效，检查设置里的绑定关系 |
| 导入后是空的 | 文件格式与这个版本不兼容（不同工具导出的字段有差异），换标准格式的文件再试 |

排查顺序：先确认条目已启用、关键词逐字一致，再看绑定关系，最后才怀疑文件本身。

## 五、一次别塞太多

条目越多、内容越长，每次对话占掉的上下文就越大，回复质量与速度都会往下掉。起步阶段挑最重要的几条放进去，缺什么再补，比一上来塞一整本好用。角色与设定的其他问题，翻 [常见问题与报错处理.md](常见问题与报错处理.md)。
