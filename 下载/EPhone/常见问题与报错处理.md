## 一、首次打开，界面加载不出来

发布页 FAQ 里点名的第一条：初始的「有边框 / 无边框」选择没有完成，可能导致初始化失败。处理办法：

1. 彻底退出应用（从后台任务里划掉），重新打开，把第一次的选择做完；
2. 仍不行就清掉应用数据重进，或卸载重装（本地数据会一起清掉）。

## 二、角色不回消息 / 提示连接失败

使用频率最高的问题，几乎全落在 API 配置上，按顺序查：

1. URL 结尾是不是带着 `/v1`——要去掉；
2. 密钥是否复制完整、有没有混入空格或换行；
3. 模型名是不是站点确实提供的；
4. 是不是高峰期的「上游负载」——等几分钟再发；
5. 手机网络本身通不通（WiFi 与流量切换对照试）。

详细填法见 [API设置与密钥获取.md](API设置与密钥获取.md)。

还有一种情况要单独说：**整个站点挂了**。公益站动态调整模型、额度甚至直接关站都是常态，表现是昨天还好好的、今天所有模型一起报错。这种情况别反复重试，直接换站——按 [公益站怎么找与怎么挑.md](公益站怎么找与怎么挑.md) 重新挑一个，换个地址和密钥就恢复了。

## 三、发图片或表情失败

- 先看存储权限给没给：系统设置 → 应用 → EPhone → 权限；
- 图片用 JPG、PNG、GIF 这类常见格式，冷门格式可能发不出去；
- 以上都没问题就清一次缓存再试。

## 四、动态圈内容不显示

动态圈这类模拟社区的内容同样靠接入的 AI 生成：先确认 API 可用（去私聊里发一句话验证），再确认网络在线，然后刷新或退出重进；仍不出来多半是站点过载，过段时间再看。

## 五、版本与更新

这个应用没有公开的官网与固定发布渠道，各发布页的版本更新并不同步。你手里这份是 1.0（3.62M，MD5 `A6844925FC35C57F42576603BFD9999B`，包名 `com.ephone.jcyapp`）；网上搜到的「最新版」未必比你手里这份新，覆盖安装前先对一下包名与版本号，避免把能用的版本刷成来路不明的一个。安装环节的问题回 [下载与安装教程.md](下载与安装教程.md)，角色与设定类问题看 [虚拟角色与世界书导入.md](虚拟角色与世界书导入.md)。
