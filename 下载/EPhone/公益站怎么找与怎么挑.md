## 一、公益站为什么免费，又为什么老出问题

公益站多是个人或社区玩家拿自己手里的资源搭的中转服务：号池有余量时开放注册，额度用完、上游出问题或运营者没空维护时就关站或限流。有运营者在社区发帖开放注册时说得很直白——后续会「根据实际使用情况动态调整可用模型、额度或并发策略」。这不是某一家的问题，而是这类站的常态：**今天的模型列表和额度，明天可能就不一样**。

知道这一点，你对公益站的预期就该是：拿来入门和轻度使用合适，别当成长期稳定的依赖，也别在里面积攒重要的东西。

## 二、去哪发现还能用的站

- **聚合导航页**：搜「AI API 公益站导航」「中转站收集」这类词，能找到几个社区维护的聚合页，把几十上百个站按免费额度、倍率、标签列在一起，并标注更新时间；
- **社区帖子**：V2EX、NGA 这类社区常有人在开放注册时发帖，评论区能看出一个站的实际口碑；
- **GitHub 收集板**：有的收集项目把站点列表连同「最后可用时间」放在仓库里持续更新。

同一个站常在几处重复出现，交叉着看能省不少试错成本。

## 三、挑站看哪几项

导航页信息很密，重点看这几列：

| 看什么 | 说明 | 警惕信号 |
| --- | --- | --- |
| 免费额度写法 | 注册送多少、签到送多少，有没有明确数字 | 只写「免费」不给额度的 |
| 倍率 | 实际消耗按额度打几折，决定额度耐不耐用 | 倍率写得含糊 |
| 模型列表 | 你要用的模型在不在、是不是「参水」（缩水版） | 只有名字没有分组说明 |
| 更新时间 | 聚合页通常标注最近一次确认可用的时间 | 几个月没更新的条目 |
| 注册门槛 | 要不要邀请码、加群、绑定手机或 GitHub | 门槛繁琐的站往往已临近关停 |

## 四、用之前的三条自保

1. **先读免责声明**：多数收集板自己都写明「不保证安全和稳定」——这不是谦虚，是这类站的真实状态；
2. **别交重要的东西**：注册用小号邮箱，不绑支付方式，不发涉及隐私的对话内容——中转站技术上能看到你发送的全部内容；
3. **预期它会消失**：站点关停是常态，密钥失效别奇怪，按 [API设置与密钥获取.md](API设置与密钥获取.md) 的流程到新站重新拿地址和密钥即可。

## 五、同一个地址，换个前端填法可能不同

接口地址要不要带 `/v1`，取决于前端自己的拼接约定：社区文档里两种写法都存在（有的前端要求带、有的要求去掉）。EPhone 的口径是**去掉**，见 [API设置与密钥获取.md](API设置与密钥获取.md)；以后换别的聊天前端时别照搬这里的填法，以那个前端的说明为准。

站点选好、配好之后，下一步是给角色加设定，看 [虚拟角色与世界书导入.md](虚拟角色与世界书导入.md)；用着用着角色突然集体沉默，多半是站点侧的问题，排查思路见 [常见问题与报错处理.md](常见问题与报错处理.md)。
