## 一、APP 内查看原文的步骤

X-MOL 里展示的是标题、摘要与期刊信息，全文在出版商的原始页面上，跳转路径如下：

1. 打开 APP，从检索结果或「我的关注」里点开一篇文献。
2. 在文献详情页下拉到底，找到「查看原文」，点它。
3. 弹出选择打开方式时，选一个浏览器（手机自带浏览器即可）。
4. 页面在浏览器里打开后，看到的就是出版商网站上的原文页面。

之后想回到 X-MOL 继续刷文献，切回 APP 就行；这条「详情页 → 查看原文 → 浏览器」的路径对多数文献都一样。

## 二、原文页面拿不到 PDF 时

出版商页面上的全文能不能直接下载，取决于文章类型与你有没有权限，这是所有文献工具共同的现实，不是 X-MOL 单独的限制：

| 文章情况 | 通常能拿到什么 |
| --- | --- |
| 开放获取（OA）文章 | 页面上直接提供 PDF 下载 |
| 付费期刊 + 你所在机构有订阅 | 用校园网或机构网络访问，自动获得下载权限 |
| 付费期刊 + 无机构权限 | 只能看摘要；部分出版商允许注册用户免费读若干篇 |

按这个表先判断文章性质，再决定下一步，比反复换工具试更快。

## 三、机构权限之外的几条正当路径

- **校园网或学校图书馆入口**：校外先登录学校图书馆提供的远程访问（VPN 或网页入口），再从原文页面下载，权限就接上了。
- **预印本版本**：很多文章在 arXiv、bioRxiv、ChemRxiv 等预印本平台有免费版本，内容与正式版接近，搜标题通常能找到。
- **向作者索取**：出版商页面一般提供通讯作者邮箱，研究用途的索取邮件多数作者愿意回复。
- **公共渠道核实**：Unpaywall 这类工具可以自动检查一篇文章是否存在合法的开放版本。

以上都是通过正常授权渠道获取，各期刊的具体政策以其官方页面为准。

## 四、已知 DOI 时的快速路径

如果你是从别处引用清单里来的，已经带着 DOI，不用先在 APP 里搜——用[文献检索与中文模式.md](文献检索与中文模式.md)里说的「文献直达」，粘 DOI 直接跳原文，省掉检索这一步。而平时追新文献，还是靠[期刊订阅与追文献.md](期刊订阅与追文献.md)里设置的每日推送更省事。
