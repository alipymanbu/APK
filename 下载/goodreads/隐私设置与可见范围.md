## 一、先明白默认状态：你的阅读是公开的

Goodreads 是社区型产品，**书架、评分、动态默认对其他人可见** —— 你在读什么、给几分、写了什么书评，路过你主页的人都能看到。多数人不介意，但如果你想只留给自己看，要手动去改，它不会替你收着。

## 二、改可见范围的两个入口

**手机 App**：底部「更多 / More」→ 设置 → 隐私（Privacy）→ 在这里管理「谁能看到你的书评」等选项。

**网页版**（选项更全）：登录 [goodreads.com](https://www.goodreads.com) → 头像 → 资料编辑（Profile 的 Edit）→ 找到隐私（Privacy）区块，几组关键开关是：

| 开关 | 设成仅自己后的效果 |
| --- | --- |
| 谁能看到我的动态（Who can see my updates） | 在读状态、评分、书评不再出现在别人的动态流里 |
| 谁能看到我的资料（Who can see my profile） | 主页与书架只对好友（或仅自己）可见 |
| 谁能看到我的书评（Who can see my reviews） | 书评不再公开显示 |

两侧口径有出入：有第三方教程说 App 里的选项比网页版少，拿不准就把两处都翻一遍，以你实际看到的界面为准。改完想确认生效没有，开一个无痕窗口访问自己的主页 —— 无痕窗口看到的就是陌生人视角，书架和动态都藏住了才算设置到位。

## 三、只藏几本书：用「专属书架」

不想全隐身、只想把个别书（比如还没读完不想被催的、私人口味的）从公开书架上拿开：

1. 新建一个自定义书架（建法见 [书架与阅读记录怎么用.md](书架与阅读记录怎么用.md) 第二节）。
2. 把要藏的书移进去。
3. 在书架设置里把这个书架勾成「专属 / Exclusive」—— 按第三方教程的说法，专属书架不会出现在你的公开资料页上。

代价要先知道：书一旦只放在专属书架上，就不走常规书架统计，**年度阅读挑战的进度可能不把它算进去**（此点来自第三方教程，以实际界面行为为准）。隐私和统计不可兼得时，自己选一边。

## 四、隐私和导出的关系

可见范围只管「别人能不能看到」，数据本身还在你账号里。要给自己留底（换 App、防意外），走 [书架数据导出与备份.md](书架数据导出与备份.md) 导出 CSV；想连账号一起注销的，先把导出做好 —— 导出功能只在账号存在时可用，注销入口在网页版设置里，具体流程以官网当时显示为准。
