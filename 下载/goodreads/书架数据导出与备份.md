## 一、导出只能在网页版做，App 里没有这个功能

想给书架留一份离线备份（或将来换别的读书 App），Goodreads 官方提供 CSV 导出，但入口**只在网页版**——手机 App 里找不到导出按钮，手机上用浏览器打开也要切到「桌面版网站」才看得到完整界面。账号数据是网页、App 互通的（见 [书架与阅读记录怎么用.md](书架与阅读记录怎么用.md)），所以用电脑浏览器操作最省事。

## 二、导出步骤

1. 用浏览器登录 [goodreads.com](https://www.goodreads.com)，点顶部导航的「我的书 / My Books」。
2. 在左侧书架列表下方找到「工具 / Tools」，点其中的「导入与导出 / Import and export」（也可以直接访问 [goodreads.com/review/import](https://www.goodreads.com/review/import)）。
3. 点「导出书库 / Export Library」按钮。页面上不会立刻出现进度条，别以为没生效 —— 后台正在生成文件。
4. 等几秒到几分钟（藏书越多越久，几千本可能要多等一会，必要时刷新页面），按钮下方会出现一个带日期的下载链接，点它下载 `goodreads_library_export.csv`。
5. 5 分钟还没出链接：刷新重试；再不行就退出登录重新登录，再点一次导出（藏书量特别大的账号，生成偶尔会卡住，第二次一般能出）。

导出是全量的：所有书架一次性打包，**不能只导某一个书架**。

## 三、文件里有什么、没什么

| 会导出 | 不会导出 |
| --- | --- |
| 书名、作者、ISBN | 好友、关注、小组、评论互动 |
| 你的星级评分、写的书评全文 | 阅读挑战的历史目标与完成情况 |
| 私人笔记（只有你可见的那种） | Kindle 的高亮与笔记（归亚马逊阅读体系管，要去 [read.amazon.com/notebook](https://read.amazon.com/notebook) 另取） |
| 每个书架归属、在读/已读/想读状态 | 社交动态与推荐记录 |
| 加入书架日期、读完日期、重读次数 | 书封图片（只带站内地址） |
| 页数、出版信息 | |

两个容易踩的细节：

- **重读多次只留一个日期**：一本书读过 3 遍，CSV 里「重读次数」是 3，但「读完日期」只有最后一次 —— 历年阅读日期不会完整保留，介意就先导出再补截图留底。
- **拿到原始文件先别用 Excel 改存**：Excel 打开再保存会改动 ISBN、日期等字段格式（用 Excel 打开中文内容还可能显示乱码），要把数据迁去别家时，导入方要的是这份**未经改动的原始 CSV**。

## 四、什么时候该导一份

- 换读书 App、要把书架迁到别处（多数读书类 App 都接受 Goodreads 的 CSV 导入）；
- 定期给自己留底 —— 书评和笔记是你自己写的内容，隔段时间导一次不亏；
- 打算注销账号前：**先导出再注销**，导出按钮只在账号还存在时有效。

导出只是备份动作，不影响账号里的原有数据（账号与云端数据的说明见 [书架与阅读记录怎么用.md](书架与阅读记录怎么用.md) 第六节）；账号登录问题见 [注册与登录账号.md](注册与登录账号.md)。
