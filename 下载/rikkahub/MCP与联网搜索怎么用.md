## 一、联网搜索：给 AI 接搜索引擎

开了联网搜索后，AI 回答前会先查实时网页，再基于结果作答，适合问「今天/最近」开头的问题。

1. 准备搜索服务的密钥。RikkaHub 支持的搜索服务包括 **Exa、Tavily、Brave、智谱、LinkUp、Perplexity** 等，大多要你到对应官网单独注册拿 key（这与模型服务商的密钥是两回事，各家计费与免费额度以官网为准）。
2. 在设置里找到网络访问（Web Access）相关项，填入搜索服务密钥并开启。入口的具体位置随版本略有变化，以你手上版本的实际界面为准。

注意：搜索是按次向搜索服务计费（或耗其免费额度）的，不是走你模型服务商的账。

想先不花钱接搜索，有两条被第三方教程提到的路（以你版本的实际界面与所选服务商为准）：一是选有免费方案的服务（如 Bing 类）；二是自建 SearXNG 这类聚合搜索再接进来，属于进阶玩法。另外部分聚合 API 平台提供内置了联网能力的模型变体（模型名常带 search 之类后缀），联网走模型账单、不用单独配搜索 key。

## 二、MCP：给 AI 挂外部工具

MCP（Model Context Protocol）一句话说：让 AI 调用外部工具与数据源的通用接口。接上之后，AI 能按需去执行查数据、调接口这类动作，而不只是聊天。

- 在设置里添加 MCP 服务器，配置它的地址与请求头等信息；
- 聊天时由模型决定何时调用哪个工具，界面上能看到工具调用过程与结果；
- 连不上时先核对服务器地址、请求头拼写（官方更新日志里就修过「请求头名称为空导致连接失败」这类问题，旧版本踩到的先升级再试）。

MCP 服务器可以是本地进程，也可以是远程服务；具体怎么加、加什么，取决于你想接的工具，配置方法以工具方给的说明为准。

## 三、两条路怎么选

| 你想要的效果 | 用哪个 |
| --- | --- |
| 回答里带上最新资讯、实时行情 | 联网搜索 |
| 让 AI 操作外部系统（查库、发消息、跑流程） | MCP |
| 又要查资料又要动手 | 两个都开，互不冲突 |

## 四、配好后去哪试

回到聊天页，问一个需要实时信息的问题（比如「帮我查一下最近……」）观察是否触发搜索；MCP 则用一句明确需要工具的话去试，并留意界面上的工具调用提示。

搜索不触发、MCP 连不上这类问题 → [常见问题与解决方法.md](常见问题与解决方法.md)；想让某个助手默认带着这些能力，在助手的模型与工具设置里单独指定 → [新手对话与助手设置.md](新手对话与助手设置.md)。
