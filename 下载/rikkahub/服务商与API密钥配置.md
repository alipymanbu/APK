> RikkaHub 装好后还不能直接聊：它不带模型，要你自己填 API 密钥。本篇讲密钥从哪来、服务商怎么配、模型怎么挂进去。

## 一、先想清楚你要用哪家的模型

先说不用花钱的：应用与合作方内置了免费小模型，不配任何密钥也能先聊（见 [免费模型与低成本用法.md](免费模型与低成本用法.md)）。需要更强模型时，你至少要有一家的 API 密钥，常见来源：

| 来源 | 拿到什么 | 备注 |
| --- | --- | --- |
| [platform.openai.com](https://platform.openai.com) | OpenAI 系模型 | 按量计费 |
| [aistudio.google.com](https://aistudio.google.com) | Google Gemini 系模型 | 有免费额度，政策以官方页面为准 |
| [console.anthropic.com](https://console.anthropic.com) | Claude 系模型 | 按量计费 |
| 各类 OpenAI 兼容端点 | 中转/聚合服务上的模型 | 需要另外填 Base URL |
| 本地推理端点（Ollama、LM Studio 等） | 本机跑的模型 | 同样走 OpenAI 兼容格式，Base URL 指向本机 |

密钥等同密码：只填在 RikkaHub 里，不要发给别人、不要贴进不信任的应用。

## 二、配置步骤

1. 侧边栏底部齿轮进设置，选「服务商设置」（Provider Settings）。
2. 应用内置了常见服务商：列表里有就直接点进去填密钥；没有就点右上角按钮新建。
3. 填入 API 密钥；服务商不是内置的那几个时，还要一并填 **Base URL**。
4. 保存后回到服务商页，滚到底部「模型」区：多数服务商支持点展开按钮**自动拉取模型列表**，勾选你要用的即可；不要的模型左滑删除。
5. 回设置页选「默认模型与提示词」（Default Models & Prompts），给各功能模块定默认模型。分配原则：聊天用你的主力模型；标题生成、摘要这类小活儿用参数量小的稳定模型（别用推理类大模型，慢且贵）；输入框上方的「聊天建议」不需要的话直接关掉，关掉后不再产生调用。

以上入口名称以你手上版本的实际界面为准（网盘这版是 2.3.2，界面措辞可能与官方文档描述略有出入）。

## 三、API 格式怎么选

新建或修改服务商时会碰到 API 格式（类型）的选项：

| 格式 | 适用 |
| --- | --- |
| OpenAI（Chat Completions，默认） | 绝大多数服务商、中转站 |
| OpenAI Responses API | OpenAI 官方接口或镜像 GPT 模型的中转；在服务商页点「Use Responses API」切换 |
| Google | Google Gemini 自家格式 |
| Anthropic | Claude 及部分兼容它的服务 |

拿不准就用默认的 OpenAI 格式先试，报错了再对照服务商文档换。

## 四、密钥与配置的安全

- 按官方文档口径：密钥只存在你手机本地，请求由应用直连你选的服务商，不经过第三方服务器。
- 服务商配置支持**二维码导出/导入**（换手机很省事，步骤见 [常见问题与解决方法.md](常见问题与解决方法.md)），但二维码里含完整密钥，别截图外传。
- 在公共场合演示时留意别把密钥连同屏幕一起露出去。
