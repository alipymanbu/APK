## 一、装之前先知道这几件事

- RikkaHub 是一款**安卓 AI 聊天客户端**，本身不带模型：装好后需要你填入自己的 API 密钥才能开始对话，这一步见 [服务商与API密钥配置.md](服务商与API密钥配置.md)。
- 它是开源应用（源码在 GitHub 上，AGPL-3.0 许可），国内手机应用商店里搜不到，装 APK 是主要方式。
- 官方只认两个发布渠道：**Google Play** 与官网 `rikka-ai.com`。开发者特意提醒过：网上有大量 RikkaHub 的分叉改版，出了问题与官方无关，还可能索要多余权限，别用来路不明的包。

## 三、获取安装文件

打开 [RikkaHub 安装文件资源（夸克网盘）](https://pan.quark.cn/s/679a2a3a7fb0)，转存到自己的网盘后，把 `rikkahub_v2.3.2.apk` 下载到手机。手机上用夸克直接点文件一般会调起安装；电脑上下载的，用数据线或任意方式传到手机再装也行。

也可以走官方渠道拿最新版：Play 商店搜 Rikka（包名同为 `me.rerere.rikkahub`），或在浏览器访问官网下载页 [rikka-ai.com/download](https://rikka-ai.com/download)。官方渠道与网盘这份是同一款应用，只是版本新旧不同。

## 四、安装步骤

1. 在手机「文件管理」里点 APK。系统弹「禁止安装来自此来源的应用」时，按提示跳到设置，给当前的文件管理器或浏览器开「允许安装未知应用」。
2. 回到安装界面点「安装」，等进度走完。
3. 装完点「打开」，进入首次启动引导。

## 五、首次启动的四步

1. 欢迎页，点「开始使用」；
2. 添加服务商：选 OpenAI、Google Gemini、Anthropic Claude 或自定义 OpenAI 兼容端点，填入 API 密钥（还没有密钥的话，先看 [服务商与API密钥配置.md](服务商与API密钥配置.md)；暂时不想申请密钥，也可以直接用内置的免费小模型，见 [免费模型与低成本用法.md](免费模型与低成本用法.md)）；
3. 选一个默认模型；
4. 点「开始聊天」进入主界面。

## 六、装完核对

系统「设置 → 应用管理」里找到 RikkaHub 点开应用信息：

| 核对项 | 应该是 |
| --- | --- |
| 包名 | `me.rerere.rikkahub` |
| 版本 | 2.3.2（网盘这份） |

装不上、打开闪退之类的问题按 [常见问题与解决方法.md](常见问题与解决方法.md) 排查；想先弄清它和 ChatGPT 这类官方 App 的差别再决定装不装，见 [和ChatGPT官方App有什么区别.md](和ChatGPT官方App有什么区别.md)。
