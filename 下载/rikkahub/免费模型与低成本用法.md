# 免费模型与低成本用法

> 不想先花钱也能把 RikkaHub 跑起来：应用内置的免费模型、官方渠道的免费额度、本机模型，三条路按成本从低到高排。

## 一、不配任何密钥：内置免费模型

自 1.4.8 版本起，RikkaHub 与硅基流动合作，**应用里默认内置了免费小模型，不需要注册、不需要 API Key**，装好后进入对话页，点左下角的模型选择器就能直接切换使用（合作方文档列出的内置模型有 Qwen3-8B、GLM-4.1V-9B，名单随版本可能变化，以你手上版本实际显示为准）。

这条路适合刚装完先试试手感和界面；小模型能力有限，复杂任务还是要走下面两条路。

## 二、免费额度的官方渠道

各家模型服务商里有免费额度可用的，最典型的是 Google AI Studio 的 Gemini API（[aistudio.google.com](https://aistudio.google.com)）：注册后有免费额度，把拿到的 key 填进 RikkaHub 就能正常用（配置步骤见 [服务商与API密钥配置.md](服务商与API密钥配置.md)）。

注意：免费额度、限速与可用模型会随政策调整，申请前以各家官网当时显示为准，别把「现在免费」当成永久承诺。

## 三、本机模型：零 API 费

你可以在电脑上用 Ollama、LM Studio 这类工具跑开源模型，再让 RikkaHub 连过去：

1. 电脑上装好 Ollama（默认端口 11434）或 LM Studio，拉一个模型跑起来；
2. 手机与电脑连**同一个网络**；
3. RikkaHub 里新建服务商，格式选 OpenAI 兼容，Base URL 填电脑的局域网地址与端口（形如 `http://192.168.x.x:11434/v1`），密钥按工具要求填（Ollama 通常留空即可）。

这条路没有 API 账单，但对话质量取决于你电脑跑得动的模型，出门不在同一网络就连不上。

## 四、按量付费时的省法

走付费 API 时，成本大头在聊天模型；官方默认模型设置页是按功能分模块的，把小任务分给小模型是通用省钱做法：

| 功能 | 建议 |
| --- | --- |
| 聊天模型 | 按需选主力模型，这里决定回答质量 |
| 标题生成模型 | 选参数量小、稳定的模型，别用推理类大模型 |
| 聊天建议模型 | 不需要输入框上方那些建议的话，直接关掉，不再产生调用 |
| 翻译模型 | 常用量不大，小模型即可 |

模块怎么逐个设置，见 [服务商与API密钥配置.md](服务商与API密钥配置.md) 的「默认模型与提示词」部分；配置好后的日常使用见 [新手对话与助手设置.md](新手对话与助手设置.md)。
