## 一、安装与启动

**有 iOS 版本吗**
没有。官方文档明确 RikkaHub 只出 Android（另有 Web 界面），iPhone 装不了，别找「iOS 版」的包——那只会找到分叉改版或假冒的。

**点 APK 提示「禁止安装」**
按提示跳到设置，给当前的文件管理器/浏览器开「允许安装未知应用」，再回来重装。

**提示系统版本过低**
最低安卓版本以 [Google Play 页面](https://play.google.com/store/apps/details?id=me.rerere.rikkahub)标注为准；设备不满足就升级系统或换设备。

**装完打不开 / 闪退**
1. 核对应用信息里包名是 `me.rerere.rikkahub` —— 不是这个值说明装到分叉改版了，卸掉换官方渠道或网盘里的包重装；
2. 还不行就卸载重装一次；
3. 依旧复现的，带上版本号到 GitHub Issues 反馈。

## 二、对话与报错

**不配密钥能直接聊吗**
能先聊：应用内置了合作方的免费小模型，装好就能用（见 [免费模型与低成本用法.md](免费模型与低成本用法.md)）；能力更强的模型才需要配密钥。

**发消息一直转圈 / 回复报 401**
密钥填错、失效或没保存。回「服务商设置」重新粘贴，注意前后别带空格。

**报 Base URL 相关错误**
用中转或本地端点时，Base URL 拼错是最常见原因：对照服务商给的地址逐字符核对，注意结尾要不要带 `/v1`。更细的渠道类型排查（比如 Gemini 通了、GPT/Claude 不通）见 [中转API的BaseURL怎么填.md](中转API的BaseURL怎么填.md)。

**报额度/余额类错误**
你与服务商之间的问题：余额不足、限流或欠费，登录服务商后台看用量与账单。

**部分服务商连不上、一直超时**
先换一个网络环境对比测试；确认不是网络问题后，改用该服务商在你网络下可用的接入端点。

**问它「你是谁」答得不对**
正常现象。RikkaHub 默认不给模型注入身份提示词，模型自我认知本来就不准（见 [新手对话与助手设置.md](新手对话与助手设置.md)）；在意的话在系统提示词里写明身份。

## 三、功能不生效

**联网搜索没反应**
搜索服务的密钥没填或没开 —— 搜索用的是搜索服务自己的 key，与模型密钥无关，配置见 [MCP与联网搜索怎么用.md](MCP与联网搜索怎么用.md)。

**MCP 服务器连不上**
核对服务器地址、请求头名称与取值；确认该 MCP 服务本身在线。旧版本可能有兼容问题，升级官方最新版再试。

**找不到某个功能**
先对版本。语音模式、Linux 工作区、技能等是 2.4/2.5 之后加入的；网盘这份 2.3.2 不一定有，想要就从官方渠道升级（见 [下载与安装教程.md](下载与安装教程.md)），更新节奏以 [官网下载页](https://rikka-ai.com/download)的更新日志为准。

## 四、数据与换机迁移

**换手机**
新机装好 RikkaHub 后，在旧机上「服务商设置」里把配置导出成二维码，新机扫码导入即可，免重新敲密钥。注意二维码含完整密钥，导出后别截图乱放。

**备份对话与配置**
设置里有备份与恢复相关项，位置与能力随版本有差异，以你手上版本为准；重装或换机前先备份一次。

**密钥弄丢了**
应用里删了只能去服务商后台重建；所以别只存在手机里，找个安全的地方另存一份。

## 五、还没解决

- 到 [github.com/rikkahub/rikkahub](https://github.com/rikkahub/rikkahub) 提 Issues，附上版本号与复现步骤；官方 Discord 社区也能问到人；
- 先升级到官网最新版再试 —— 官方更新很频繁，很多老版本的问题在更新日志里能看到修复记录。
