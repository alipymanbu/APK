# 和ChatGPT官方App有什么区别

> RikkaHub 与 ChatGPT、豆包这类「装好就能聊」的官方 App 是两种东西：一个要自己带密钥，一个开箱即用。本篇把差别摆开，帮你判断适不适合你。

## 一、一句话差别

- ChatGPT 官方 App：注册账号就能用，模型、计费、额度全由官方打包好；
- RikkaHub：只是一个「壳」，不带任何模型。你在里面填各家服务商的 API 密钥，用哪家的模型、花多少钱，都是你和服务商之间的事，RikkaHub 本身不收费、不抽成。

## 二、逐项对照

| 方面 | ChatGPT 官方 App | RikkaHub |
| --- | --- | --- |
| 上手门槛 | 注册账号即可 | 要自己申请 API 密钥（见 [服务商与API密钥配置.md](服务商与API密钥配置.md)） |
| 计费方式 | 订阅制或免费额度 | 按各服务商 API 用量计费 |
| 能用的模型 | 官方自家模型 | OpenAI、Gemini、Claude 及任何 OpenAI 兼容端点，同一对话里随时切 |
| 数据存放 | 在官方服务器上 | 密钥与对话记录都存你手机本地；对话内容会发给你所选的服务商处理，隐私看各家服务商政策 |
| 定制能力 | 官方给的固定玩法 | 自定义助手、消息分支、记忆、MCP 工具、联网搜索 |
| 渠道 | 应用商店 | Google Play、官网，或上面那栏的夸克网盘资源 |

## 三、什么人适合 RikkaHub

- 手里已经有 API 密钥（或愿意去申请一次），想在一个 App 里用多家模型的人；
- 需要自定义助手、MCP 工具、联网搜索这类进阶玩法的人；
- 在意对话数据只留在自己手机上的人。

## 四、什么情况用官方 App 更省心

- 不想碰密钥、Base URL 这些概念，只求装上就能聊；
- 主要靠官方的免费额度，或依赖官方生态里的独有功能。

## 五、它是开源应用

- 源码在 [github.com/rikkahub/rikkahub](https://github.com/rikkahub/rikkahub)，AGPL-3.0 许可；项目不接受外部 PR；
- 有官方 Discord 社区，问题反馈走 GitHub Issues；
- 再次提醒：网上大量分叉改版与官方无关，装包认准官方渠道或 RikkaHub 安装文件资源（见 [下载与安装教程.md](下载与安装教程.md)）。
