## 一、怎么用这张表

报错以**原文**为键。多数报错是英文或中英混排，照着你屏幕上看到的字找，找不到完全一致的就找最接近的那条。表里给的处理分两档：**你能自己做的**先做完，做不了的归到「找管理员」——登录、许可证、安全角色这三类的最终开关都在公司 IT 手里，手机端反复试是浪费时间。

对照前先排除两个万能因素：**网络不通**（换个网络重试）和**账号没权限**（问 IT 有没有给你共享应用、有没有配许可证）。相当一部分报错的根子在这两处。官方通用排障策略还给了三个维度：换网络（移动数据换 Wi-Fi、先关 VPN）、换设备（另一台手机能开就是本机的限制）、隔离变量（一次只改一处，改回去再验）。许可证一档的细节见 [许可与价格说明.md](许可与价格说明.md)。

## 二、登录类报错

| 报错原文（屏幕显示） | 含义 | 处理 |
| --- | --- | --- |
| 登录时出现问题（There was a problem signing you in） | Microsoft Authenticator 的账号状态有问题 | 先装/重装 Authenticator 并恢复备份，顺序见 [登录问题排查.md](登录问题排查.md) 第二节 |
| 你的设备配置阻止登录（Your device configuration is preventing sign in） | 公司要求 Intune 或认证 App 登录，而手机设置拦了 Power Apps 唤起认证 App | 手动打开认证 App 再登录；不行就按机型给认证 App 放开自启动/被唤起权限，机型步骤见 [登录问题排查.md](登录问题排查.md) 第三节 |
| `AUTH_FAILED_INTUNE_POLICY_REQUIRED` / `AADSTS53005`：应用程序需要实施 Intune 保护策略 | 你的设备未满足公司的 Intune 合规要求 | 自己改不了，找 IT：要么在设备上装公司门户并完成注册，要么申请豁免 |
| 要访问你组织的移动应用，请与你的管理员联系 | 组织侧访问策略没放行 | 找管理员，附上报错原文 |
| 你未被授权使用此应用程序。请与你的系统管理员核查以更新你的设置 | 缺许可证或没被共享该应用 | 找管理员核对许可证与共享 |
| 抱歉，初始化应用程序时发生错误。请重试或者重新启动应用程序 | 应用启动阶段异常 | 先重试、再强退重开；仍复现就清除应用数据重登（会退出账号） |

## 三、列表与数据类

| 报错/现象 | 含义 | 处理 |
| --- | --- | --- |
| 应用列表为空 | 列表下载中途断网（首次登录/下拉刷新/离线恢复在线三个时机），或压根没被分配访问权 | 稳定网络下拉刷新；仍为空找 IT 确认访问权（如「基本」访问权） |
| 此记录不可用（This record is unavailable） | 要打开的那条记录被删了或你无权看 | 回列表换一条试；换几条都这样才需要找管理员 |
| 你的服务器不可用或不支持此应用程序 | 后端环境不可达或版本不匹配 | 换网络重试；持续出现找 IT 查环境状态 |
| 分派给该记录的流程不可用或已删除 | 该记录挂的业务流程被删了 | 这条记录上的流程没了，找该应用的制作者 |
| 公司系统上安装的语言在该应用程序上不可用 | 组织语言与应用支持语言对不上 | 找管理员设置支持的语言 |

## 四、功能限制类（不是故障，是平台边界）

| 现象 | 说明 |
| --- | --- |
| 移动版下载不了 SharePoint 附件 | 移动版的已知问题；改在电脑端打开该应用下载，或让制作者调整附件存储 |
| 解决方案中创建的流程在移动版不支持 | 该流程无法在手机端触发；到电脑端 Power Automate 里跑 |
| 提示不支持本地 Android / iOS 链接 | 应用里用了移动版不支持的原生链接协议；属于制作者侧的兼容问题，反馈给制作者 |
| 自定义更改没出现在移动应用中 | 制作者的改动尚未发布或需刷新；你这边下拉刷新、退出重进，仍没有就等制作者发布 |
| 应用运行中突然重置 | 应用占用的资源超过设备可用资源时会被系统重置，安卓上看起来就是闪退回桌面；处理顺序见 [应用闪退回桌面怎么办.md](应用闪退回桌面怎么办.md) |

## 五、后台网络报错

**现象**：应用切到后台一会儿，回前台时弹「网络请求失败」一类提示。

**原因**：手机系统把后台应用的请求降级或直接取消了，请求根本没发出去——不是服务器挂了。

**处理**：回到前台后把刚才那步操作重做一遍即可。频繁出现就检查省电设置：别让系统把这个 App 的后台活动掐太死（各家入口不同，找「后台运行」「省电策略」里对应的例外项）。

**和其他报错的分界**：只有这一个 App 在切后台时报、重做就好 → 系统省电行为；所有网络操作都失败 → 先查你自己的网络，再看上面对应条目。

## 六、还没到报错那一步的
