# 安装时提示「解析包时出现问题」怎么解决

> 点开安装包却弹出「解析包时出现问题 / 无法解析软件包」，这篇按出现概率把原因和对应处理列清楚，多数几分钟就能装上。

## 一、这个提示在说什么

安卓在安装一个 `.apk` 之前会先读一遍安装包：结构是否完整、系统版本够不够、签名信息对不对。任何一步读不下去，安装器就停下来报「解析包时出现问题」（不同系统版本的措辞略有差异）。这个提示**不代表手机坏了，也不代表包一定有毒**，多数情况是下面这些可以自己处理的小问题：

| 原因 | 典型情形 | 对应处理 |
| --- | --- | --- |
| 包损坏或不完整 | 下载中断、转存不完整就急着装 | 重新转存、下载一遍（见下文第三节） |
| 系统版本不兼容 | 手机系统太旧或太新，超出安装包支持范围 | 看系统版本，太旧先升级系统 |
| 未知来源没开对 | 只开了全局开关，没给「来源应用」授权 | 安卓 8 以上是**按来源应用**授权的，见安装教程第三节 |
| 文件名或路径问题 | 部分老机型对中文长文件名支持差 | 把文件改成短的英文名（如 `mixt.apk`）再装 |
| 存储空间不足 | 手机剩余空间太小 | 清出几百 MB 再试 |

## 二、按顺序排查

按花费时间从短到长：

1. **重新转存、下载一遍** —— 这是命中率最高的一步，下载中断是这类报错最常见的原因；
2. **核对 MD5** —— 重新下载后先对一遍校验值，确认包是完整的，方法见 [下载与安装教程.md](下载与安装教程.md) 第四节；
3. **检查未知来源授权** —— 安卓 8 及以上不是全局开关，要给「用来打开安装包的那个应用」（浏览器、网盘 App 或文件管理器）单独开「安装未知应用」权限；
4. **改短文件名** —— 部分机型对中文或超长文件名的安装包解析会出问题，改成纯英文短名再试；
5. **换一个入口打开** —— 换一个文件管理器重新发起安装，个别第三方文件管理器自己会出问题。

这些步骤做完还不行，且**装别的 APK 也报同样的错**，那就是系统层面的问题（安装器异常等），重启手机再试一次；仍然不行就得考虑系统故障，不在安装包这一侧了。

## 三、重新下载一份完整的包

排查到「包不完整」这一步，直接重新获取一份：

1. 打开 [Mixt 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e245ef8d679b)，把文件重新转存到自己的网盘；
2. 下载到手机，**等进度条走完再打开**，中途取消最容易造成包不完整；
3. 下载完先对一遍 MD5（方法见 [下载与安装教程.md](下载与安装教程.md) 第四节），对上了再发起安装。

能装上但后续用着不对劲的（渐变有色带、壁纸发虚），属于另一类问题，分别看 [渐变壁纸有色带怎么办.md](渐变壁纸有色带怎么办.md) 和 [壁纸变模糊怎么处理.md](壁纸变模糊怎么处理.md)。
