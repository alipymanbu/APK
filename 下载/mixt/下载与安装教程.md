## 一、装之前先对一遍信息

Mixt 是一款生成双色渐变壁纸的安卓小工具，本身体积很小，对手机配置几乎没有要求。安装前建议先核对下面几项，确认手上的包和发布时的版本一致：

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.4.2 |
| 包名 | com.massive.papaya.mixt |
| 安装包大小 | 约 1.22 MB |
| MD5 | 69633877E2BDF5C5CB8C078B734DF0B9 |
| 系统要求 | 安卓 5.2 以上（以安装时系统提示为准） |

版本号和大小以这里写的为准：网上能查到的多半是官方最新版，和你实际拿到手的安装包未必是同一个版本。如果你的系统版本太老，安装时会被系统直接拦下，这种情况下先升级系统再装。

## 二、获取安装文件资源

安装包从夸克网盘取，步骤如下：

1. 打开 [Mixt 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e245ef8d679b) 的分享页；
2. 把分享里的文件**转存到自己的网盘**（没有登录会先要求登录夸克账号）；
3. 在自己网盘里找到刚转存的文件，下载到手机；
4. 下载完成后，在手机的「文件管理」或通知栏里打开这个 `.apk` 文件，进入安装。

用手机浏览器直接打开分享链接也可以完成转存，之后在夸克网盘 App 里操作下载更方便一些。

## 三、允许安装来自未知来源的应用

安装包不是从应用商店下的，安卓会把它当作「未知来源」应用，第一次安装时会拦一次，放行一次就好：

- **安卓 8 及以上**：安装时弹出「出于安全考虑，已禁止安装未知应用」的提示，点「设置」→ 找到「允许来自此来源的应用」并打开 → 返回继续安装；
- **老版本安卓**：在「设置 → 安全」里勾选「未知来源」，装完可以再关掉。

不同品牌（小米、华为、OPPO 等）的菜单叫法略有差异，但路径都在「设置 → 应用 / 安全 / 权限管理」这一带，搜「未知来源」或「安装未知应用」能直接定位。

## 四、核对安装包（可选）

如果你怀疑下载中断导致包不完整，可以核对一下 MD5 值：

1. 在文件管理器里长按 APK 文件，部分文件管理器自带「属性 / 详情」里会显示 MD5；
2. 没有的话，用任意一个「MD5 校验」类小工具算一遍；
3. 结果应等于 `69633877E2BDF5C5CB8C078B734DF0B9`（不分大小写）。

对不上就说明包坏了或不完整，删掉重新转存、下载一次即可。

## 五、装不上时的排查

按出现概率从高到低：

- **提示「应用未安装」**：多数是系统版本低于要求，或者手机存储空间不足，清一点空间再试；
- **安装到一半取消**：包不完整，按上一节的 MD5 核对一遍，重新下载；
- **找到不到安装入口**：夸克网盘 App 内可以直接点已下载文件发起安装，或者去系统「文件管理 → Download / Quark」目录里找；
- **提示「解析包时出现问题」**：这个报错有专门的一篇排查清单，按顺序过一遍，见 [解析包时出现问题怎么解决.md](解析包时出现问题怎么解决.md)；
- **安装成功但打不开**：先确认手机系统是安卓且版本符合要求，再看是否被「纯净模式」之类的厂商开关拦了，关掉后重装。
