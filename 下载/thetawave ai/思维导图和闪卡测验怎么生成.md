## 一、六种产出来自同一次上传

你丢进去一份资料（一段录音、一个 PDF、一条 YouTube 链接），拿到的不止一篇笔记。官方列出的同一份资料可生成的产出有六种，来回切换不用重新上传、也不用重新写提示词：

| 产出 | 形态 | 典型用法 |
| --- | --- | --- |
| 笔记 | 分节标题、要点、表格、公式 | 课后第一遍通读 |
| 摘要 | 精简版要点 | 考前快速过一遍 |
| 思维导图 | 可缩放的概念分支图 | 先看清整章知识点怎么关联 |
| 闪卡 | 问答卡，点按翻面 | 术语、公式、日期的主动回忆 |
| 测验 | 选择题 + 简答题，附解析 | 考前自测找薄弱点 |
| 播客 | 生成的音频回顾，带章节标记 | 通勤、走路时听 |

另外还有一个常驻的 **AI 助教对话入口**：围绕你上传的这份资料提问，它按资料内容回答——卡在某个概念时直接在旁边追问，不用离开这个学习会话。

## 二、操作步骤

1. **进入一份已有资料**：新生成的走 [课堂录音转笔记怎么用.md](课堂录音转笔记怎么用.md) 的录音流程，或从 [支持哪些文件格式和语言.md](支持哪些文件格式和语言.md) 的入口上传文件；已有的直接打开。
2. **切换产出标签**：在笔记工作区里点对应的标签（笔记 / 摘要 / 思维导图 / 闪卡 / 测验 / 播客），每个都基于同一份底层材料生成。
3. **生成后核对**：测验的选项解析、闪卡的问答内容都要和原始资料对一遍再拿来背——服务条款写明 AI 输出可能不准确或不完整，定位是辅助学习而不是替代你判断。
4. **播客按时长选档**：生成音频回顾时可选 3–8 分钟速览、8–15 分钟复习、15–20 分钟深挖，或让它按材料长度自动决定。

## 三、哪些是付费功能

按定价页的对照表（截至 2026-09，以官网当时显示为准）：

- **测验**：免费版不支持生成，Pro 版无限次；
- **播客**：免费版不支持，Pro 版无限；
- **笔记、摘要、思维导图、闪卡、AI 助教对话**：免费版可用，但受每天 3 条笔记、单条 1 个来源的额度限制。

也就是说复习闭环里「自测」这一环基本绑定订阅。免费版能不能撑住你的用法，对照 [免费版和Pro版区别.md](免费版和Pro版区别.md) 的表逐项看；订阅之后想反悔的话，取消和退款的条件要提前知道，见 [订阅取消与退款怎么操作.md](订阅取消与退款怎么操作.md)。

## 四、复习时的建议顺序

按资料的消化深度排，比较顺手的用法是：先读笔记 → 用思维导图把章节关系过一遍 → 合上资料刷闪卡做主动回忆 → 用测验查漏 → 走路时听播客回顾。前两步免费版都能做，后两步（测验、播客）需要 Pro。

录音怎么产生、笔记怎么核对，见 [课堂录音转笔记怎么用.md](课堂录音转笔记怎么用.md)。
