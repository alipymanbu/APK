## 一、能丢进去的东西（输入格式）

官方功能页列出的入口覆盖了学生手头常见的全部载体，按类型整理如下（截至 2026-09，以官网当时显示为准）：

| 类型 | 支持格式 / 形式 |
| --- | --- |
| 文档 | PDF、DOCX、PPTX、TXT、Markdown |
| 音频 | MP3、M4A、WAV |
| 视频 | MP4、MOV |
| 图片 | 手写笔记 / 课件的照片、截图 |
| 在线链接 | YouTube 链接、网页链接 |
| 直接粘贴 | 复制过来的纯文本 |

单个文件的大小上限按套餐分：**免费版 3 MB / 资源，Pro 版 500 MB / 资源**。一份扫描版教材 PDF 动辄几十 MB，免费版大概率塞不进去——这是实际使用中最先撞到的墙，超过时只能换小文件或升级，判断口径见 [免费版和Pro版区别.md](免费版和Pro版区别.md)。

## 二、能拿出来的格式（导出）

- **笔记正文**：可导出为 PDF、DOCX、Markdown 三种常见格式。注意导出是 **Pro 版功能**，免费版的对比表里「导出」一栏是空的。
- **播客音频**：从笔记生成的音频回顾存在应用内的资料库里，网页版和手机 App 都能播放；官方没有列出把它下载成音频文件的入口。
- **思维导图**：笔记可以一键转成思维导图，在应用内查看。

## 三、语言

- **输入（转写/理解）**：官方下载页标注支持 **10 种语言**，课堂上老师用什么语言讲课就按什么语言处理。
- **输出（笔记、播客等）**：功能页标注 **11 种输出语言**——你可以用一种语言听课、用另一种语言记笔记，也可以让它自动跟随来源语言。
- 两处页面的数字不一致（10 与 11），属于官方自身口径差异，本文不做取舍，**以官网当时显示为准**。

## 四、怎么判断自己的资料能不能用

拿不准时按这三条过一遍：

1. 是不是上表里的格式？不是就先转成 PDF 或 MP3 再传。
2. 单个文件是否超过 3 MB（免费版）？超了看 [免费版和Pro版区别.md](免费版和Pro版区别.md) 决定是压缩还是升级。
3. 是不是已经有现成录音？有就直接传音频，不用重录——处理结果和现场录音一致，流程见 [课堂录音转笔记怎么用.md](课堂录音转笔记怎么用.md)。
4. 格式和大小都合规却反复上传失败？排查顺序和官方联系邮箱整理在 [常见问题与解决方法.md](常见问题与解决方法.md)。

首次安装与账号设置若还没做，先回到 [下载与安装教程.md](下载与安装教程.md)。
