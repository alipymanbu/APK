## 一、什么时候用 WebDAV

网页端只解决「浏览器里看看、下下载」。想在其他应用里直接用这些文件——电视播放器播网盘电影、手机文件管理器里直接读写、电脑当网络硬盘挂载——走的就是 WebDAV。AListLite 起的服务自带 WebDAV，不用另外开启服务本体，但**账号要给 WebDAV 权限**（第二节）。

## 二、连接参数

在任何支持 WebDAV 的应用里，填这几项：

| 参数 | 填什么 | 说明 |
| --- | --- | --- |
| 地址 | `http://设备IP:5244/dav` | 服务跑在哪台设备上就填它的 IP；设备本机可填 `http://localhost:5244/dav` |
| 账号 | AList 的用户名 | 默认 `admin` |
| 密码 | 对应用户的密码 | 默认 `123456`，改法见 [管理员密码与权限设置.md](管理员密码与权限设置.md) |
| 端口 | `5244` | 没改过高级配置就是它 |

**WebDAV 权限要单独给**：登录管理页 →「管理」→「用户」→ 编辑对应用户，勾选 WebDAV 读取（需要在线管理文件再勾 WebDAV 管理）。不勾的话，连接会报 401 或能看到目录但读不了文件。不同版本管理界面入口略有差异，以你登进去看到的为准。

地址末尾的 `/dav` 不能漏、也不能改：部分客户端（比如 Windows 下的 RaiDrive）会校验地址必须以 `/dav` 开头，填成服务首页地址会直接提示「不是有效的 WebDAV 地址」。

## 三、常见用法对照

| 你在哪 | 挂上后能干什么 | 填法 |
| --- | --- | --- |
| 电视 / 盒子上的播放器 | 直接播放挂进来的网盘视频，不占本机空间 | 播放器设置里添加 WebDAV 来源，填上表参数，选目录播放 |
| 手机文件管理器 | 像本地文件夹一样浏览、复制网盘文件 | 管理器「添加网络存储」选 WebDAV，填上表参数 |
| 电脑（Windows） | 映射成网络驱动器，资源管理器里直接用 | 用支持 WebDAV 的挂载工具填 `http://IP:5244/dav` |

支持 WebDAV 的播放器很多，选哪个以各播放器自己的说明为准；共同点是都能填「地址 / 账号 / 密码」三项。

人在外面想连家里的服务，地址换成你的外网入口即可，其余参数不变——外网入口怎么弄见 [外网访问与内网穿透.md](外网访问与内网穿透.md)。

## 四、放不了视频，按这个顺序查

1. **文件管理器里能不能看到目录**：看不到 → 地址或账号密码错，或对方设备和服务不在同一局域网；
2. **能看到目录、播放报错**：回管理页查该用户的 WebDAV 读取权限是否已勾选；
3. **能列目录、播放卡住**：多为网盘侧限速或直链超时，换一个网盘源验证是单家网盘的问题还是配置问题；
4. **电脑挂载连不上**：Windows 自带的 WebClient 对大文件和部分字符支持差，改用第三方 WebDAV 挂载工具重试。

存储本身挂不上、目录打不开这类问题不属于 WebDAV，先解决存储，见 [挂载网盘与添加存储.md](挂载网盘与添加存储.md)；服务反复掉线见 [常见问题与报错处理.md](常见问题与报错处理.md)。
