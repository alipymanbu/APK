## 一、默认账号：admin / 123456

服务启动后，浏览器打开管理页面（手机本机是 `http://localhost:5244`，局域网内其他设备把地址里的 IP 换成这台设备的），用默认账号 `admin` / `123456` 登录。

默认密码只适合装机后第一时间登录进去，留着它等于把这台设备的文件门户对局域网里所有人敞开——先改密码，再往里挂网盘。

## 二、改管理员密码

在 AListLite 应用里操作，不动网页端：

1. 打开 AListLite，点右上角 `+` 号；
2. 选「密码设置」，输入新密码保存；
3. 之后网页端登录就用新密码。

改完如果网页端还停在登录页，直接用新密码重新登录即可。哪天忘了密码，同样回到应用里这个入口重设，不需要重装应用。

## 三、权限配置：每一项管什么

首次打开应用时会弹出权限申请，全部允许最省事。漏掉或后来被系统收紧了，可以点右上角 `+` 号进「权限配置」页面，逐项查看与补授：

| 权限 | 管什么 | 缺了会怎样 |
| --- | --- | --- |
| 存储（所有文件访问） | 服务读写设备里的文件 | 挂载本机存储时看不到文件或报错 |
| 通知 | 显示服务运行中的常驻通知 | 服务容易被系统当成无响应进程清掉 |
| 后台运行 | 服务在锁屏后继续跑 | 锁屏一会儿服务就停，网页端连不上 |

## 四、开机自启与后台常驻

**开机自启要开两处**：只给应用权限还不够，官方说明里明确要求「授予相关权限后，还需要在系统设置中手动开启应用的自启动开关」。路径因手机品牌而异，一般在系统的「应用管理 → AListLite → 自启动」或安全类应用的启动管理里。

**后台常驻防杀**：想让服务长时间挂着（比如当家庭文件服务器用），把 AListLite 的电池策略放宽——系统设置 → 应用 → AListLite → 电池，选「无限制 / 不受限制」，同时允许它后台运行。国产 ROM 通常还有「最近任务上锁」「省电白名单」这类开关，一并打开。设完这些还是会被杀后台的排查思路见 [常见问题与报错处理.md](常见问题与报错处理.md)。

几个主流品牌对应的具体开关（菜单名称随系统版本有出入，在系统设置里搜下面加引号的关键词最快）：

| 品牌 / 系统 | 要动的开关 |
| --- | --- |
| 华为 / 荣耀 | 「应用启动管理」关掉自动管理、改为手动管理并勾选允许后台活动；「电池优化」里对该应用设为不允许优化；多任务界面把卡片下拉加锁；省电模式关掉 |
| 小米 / 红米 | 安全中心里开「自启动」；多任务卡片加锁；省电策略设为无限制 |
| 三星 | 「电池 → 后台使用限制」，把应用从「深度休眠」列表里移出来 |
| OPPO / vivo | 「自启动」管理里手动允许；「后台高耗电 / 冻结」类开关里放行 |
| 接近原生的系统 | 设置 → 应用 → AListLite → 电池，选「无限制」 |

另一个容易忽略的来源：第三方「管家 / 清理加速」类应用也会杀后台——这是华为官方支持文档里明确列的排查项，其他品牌同理。装了这类应用的话，把 AListLite 加进它们的白名单，或直接卸掉再观察。

## 五、顺手检查更新

右上角 `+` 号菜单里还有「检查更新」入口；应用每次开启时也会自动检查新版本。注意它指向的是官方发布页的最新构建——如果你用的是网盘里这份 2.0.6 版，更新与否由你自己决定，覆盖安装不影响已挂载的存储配置。版本号 / 包名 / 体积这类基准信息以 [下载与安装教程.md](下载与安装教程.md) 里记录的采集信息为准。
