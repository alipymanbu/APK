# AListLite 常见问题与报错处理

> 本篇汇总 AListLite 用起来最常见的几类故障：服务起不来、网页打不开、后台被杀、端口冲突、忘记密码，逐条给排查动作。

## 一、开关打开了，浏览器却打不开服务页

按顺序核对：

1. **确认服务确实在跑**：回 AListLite 主界面看开关状态，关了就重新打开；应用被系统从最近任务里划掉不等于服务停了，以开关和应用通知为准；
2. **地址对不对**：设备本机访问用 `http://localhost:5244`；从别的设备（电脑、另一台手机）访问要把 `localhost` 换成服务那台设备的局域网 IP，在系统 WLAN 详情里查；
3. **在不在同一个网络**：电脑连的 Wi-Fi 和手机连的 Wi-Fi 不是同一个（或有 AP 隔离）时互访不通，先在电脑上 ping 一下手机 IP；
4. **浏览器别用错协议**：是 `http://` 不是 `https://`，本地服务没有证书，用 https 会直接打不开。

出了家门就连不上不是故障：这套服务只对局域网开放，在外面访问要走公网 IP 或穿透 / 组网，做法见 [外网访问与内网穿透.md](外网访问与内网穿透.md)。

## 二、服务起不来，或开关一弹就停

最常见的触发点：**改坏了高级配置**。右上角 `+` 号 →「高级配置」里可以直接改 AList 的配置文件（自定义端口、HTTPS、数据库等），官方对它的提示是「错误的配置可能导致服务无法启动」。

- 最近动过高级配置 → 把改动逐项退回去，或恢复成默认配置再启动；
- 没动过 → 检查端口占用（见下一节），再检查存储权限是否被系统收紧（权限配置页逐项核对，见 [管理员密码与权限设置.md](管理员密码与权限设置.md)）。

## 三、锁屏一会儿服务就断

这是被系统电池策略杀后台了，不是故障。处理动作：

1. 系统设置 → 应用 → AListLite → 电池，改成「无限制 / 不受限制」；
2. 在权限配置页确认「后台运行」权限已授；
3. 国产 ROM 再做两步：最近任务里给 AListLite 上锁；自启动管理里允许它自启与关联启动；
4. 想要重启手机后服务自动回来，除了以上权限，还要在系统设置里单独开「自启动」开关（官方说明明确要求这一步，见 [管理员密码与权限设置.md](管理员密码与权限设置.md) 第四节）；
5. 还有一种「服务挂着但谁都连不上」：锁屏后系统把后台联网也掐了。把省电模式关掉；华为机型在电池设置里开「睡眠时保持网络连接」，荣耀机型关掉「智能省流量」——这两个开关会在锁屏或省电时直接断后台网络。

## 四、端口被占用或想换端口

默认端口是 `5244`。如果设备上另有程序占了 5244，服务会起不来或地址冲突。在右上角 `+` 号 →「高级配置」里改配置文件的端口项，保存后重新开关一次服务，之后所有访问地址（网页、WebDAV）里的 `5244` 都要跟着换。

改配置前记下原值；服务改完起不来就按第二节退回。WebDAV 的地址端口同步规则见 [WebDAV连接与播放器搭配.md](WebDAV连接与播放器搭配.md)。

## 五、忘记管理密码

不用重装。打开 AListLite → 右上角 `+` 号 →「密码设置」重设一个，网页端用新密码登录即可。前提是手机还在你手里；如果设备本身已经交给别人用，改完密码最好顺手检查「管理 → 用户」里有没有不认识的账号。

## 六、挂载的网盘目录突然打不开

多一半是**网盘凭据过期**，不是 AListLite 坏了：

1. 回「管理 → 存储」编辑对应那条，重新取一份令牌 / Cookie 填入保存；
2. 单个目录异常按 [挂载网盘与添加存储.md](挂载网盘与添加存储.md) 第四节处理；全部目录同时异常则先确认服务与网络正常（第一节）；
3. 网盘侧风控（改密码、异地登录、长期不登录）也会导致凭据失效，重新登录网盘官方客户端后再取新凭据；
4. 阿里云盘目录报 `ExceedCapacityForbidden`：这是网盘容量超限触发的限制，不是服务坏了——扩容或清理出足够空间后恢复；
5. 报 `Too Many Requests`：短时间内请求太频触发了官方防滥用限制（比如反复取令牌），停一阵再操作。

## 七、想换新版本

应用每次打开会自动检查更新，也可以在 `+` 号菜单里手动「检查更新」，它指向官方发布页的最新构建。装网盘里那份 2.0.6 的用户可以一直不动，也可以从发布页取最新包覆盖安装；覆盖安装不改变存储配置，装完重新开关一次服务即可。版本基准与渠道列表见 [下载与安装教程.md](下载与安装教程.md)。
