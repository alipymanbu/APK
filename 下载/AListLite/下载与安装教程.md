## 一、装之前先对号：它是干什么的

AListLite 让你在安卓设备上直接跑 AList / OpenList 文件服务：装上以后不用 Termux、不用敲命令行，打开应用点一下开关，这台手机 / 平板 / 电视盒子就变成一台能用浏览器和 WebDAV 访问的文件服务器。下面这些需求它对得上：

- 手里有多个网盘（阿里云盘、百度网盘、夸克、天翼云盘等），想在一个网页里集中浏览和取用；
- 想把旧手机或盒子当成家里的文件中转站，不另外购置设备；
- 想在电视或播放器上直接播放网盘里的视频（走 WebDAV，见 [WebDAV连接与播放器搭配.md](WebDAV连接与播放器搭配.md)）。

本篇对应的是 2.0.6 版安装包（约 49 MB，2026-09 采集，包名 `com.leohao.android.alistlite`，MD5 `9837EAB2F08D8BFC624C15DDEE4E58D3`）。官方发布页按 OpenList 的节奏滚动出新构建，版本号会一直往前走，装哪一版取决于你从哪个渠道拿包（下一节）。

搜资料时你还会同时看到 AList 和 OpenList 两个名字：AList 是原项目，2025 年转由公司运营后，社区在它的代码基础上分叉出了 OpenList 继续开源维护；AListLite 官方说明原话是「支持运行 AList 服务（现已迁移到 OpenList）」，新的发布包也跟随 OpenList 版本滚动构建。对使用者来说两代服务的管理界面与用法基本一致，检索教程时哪个名字下的资料都能参考，具体差异以官方发布页说明为准。

官方发布页每个版本会同时放出多个 APK：`universal` 通用包（包含全部 CPU 架构，体积大）和按架构拆分的包（`arm64-v8a`、`armeabi-v7a`、`x86`、`x86_64`，单个体积小得多）。不确定自己设备的架构时，直接下 universal 包最省事；主流手机选 `arm64-v8a` 包。具体包名与体积以发布页当时显示为准。

## 三、手机安装步骤

1. 从上面任一渠道下载 APK 到手机；
2. 点开下载完成的文件，系统提示「是否允许安装来自此来源的应用」时选择允许——这只针对你下载文件用的那个应用（浏览器或网盘客户端），装完可以再关掉；
3. 等安装结束，打开 AListLite。

不需要 Root，也不需要额外装运行环境。设备要求 Android 5.0 及以上（官方标注最低 SDK API 21，以官方发布页为准）。

## 四、第一次打开要做的事

1. **授予权限**：首次启动会依次申请存储、通知与后台运行权限，逐项允许。想核对或补授，点右上角 `+` 号进「权限配置」页面查看每一项的状态；
2. **改掉默认密码**：管理页面的默认登录是 `admin` / `123456`，改法见 [管理员密码与权限设置.md](管理员密码与权限设置.md)；
3. **启动服务**：回到主界面点右上角开关。开关打开后服务就跑起来了，这时用本机浏览器访问 `http://localhost:5244` 就能看到文件页面。

这三步做完，你就可以继续把网盘或本机文件夹挂进来了（见 [挂载网盘与添加存储.md](挂载网盘与添加存储.md)）。Android 7.0 及以上的设备还可以在系统下拉栏里添加 AListLite 的快速启停磁贴，不用进应用就能开关服务。

## 五、电视 / 盒子怎么装

AListLite 同时适配 TV 设备。安装思路和手机一样：把 APK 拷进 U 盘插到电视上安装，或通过局域网文件管理器推送到电视。电视上输入网址麻烦，可以走应用内「远程访问」：点右上角 `+` 号选「远程访问」，屏幕上会出现二维码，用手机扫码就能在手机上完成这台电视服务的访问与配置。

装完电视上打不开服务、或者开关点了没反应，直接翻 [常见问题与报错处理.md](常见问题与报错处理.md) 里的对应条目。
