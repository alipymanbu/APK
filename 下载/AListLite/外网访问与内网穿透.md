## 一、为什么在家连得上、在外面连不上

服务跑在家里那台设备上，访问地址是它的局域网 IP（`192.168.x.x` 这类）。这个地址只在你家网络内部可达，出门换了网络自然就断了。想在外面接着用，本质是让外网的请求能找到家里那台设备——三条常见路线，按你家的宽带条件选一条即可。

## 二、三条路线对照

| 路线 | 适合谁 | 大致做法 | 要留意的 |
| --- | --- | --- | --- |
| 公网 IP + 端口转发 | 宽带有公网 IP 的家庭 | 在路由器里把一个外部端口映射到设备 IP 的 `5244`；家里 IP 会变的话再配 DDNS 绑个域名 | 等于把服务直接暴露在公网，下一节的安全项一条都不能省 |
| 内网穿透 | 没有公网 IP 的家庭宽带（现在大多数） | 装一个穿透工具（花生壳、frp、cpolar 这类），把家里的服务映射到工具提供的中转地址 | 免费档一般限速限流量；流量要过工具的中转服务器 |
| 组网工具 | 只想自己几台设备用、不对别人开放 | Tailscale / ZeroTier 这类，把手机和家里设备拉进同一张虚拟局域网，之后照常用原来的地址访问 | 每台要用的设备都得装它的客户端 |

判断有没有公网 IP 的快速办法：看路由器 WAN 口拿到的地址，是 `100.x` 开头这类运营商内网段，说明运营商没给你公网 IP，直接走穿透或组网。各家工具的具体步骤以所选工具的官方文档为准；AListLite 这边唯一要保证的是服务在跑、端口没改（改过就把对外映射换成新端口，见 [常见问题与报错处理.md](常见问题与报错处理.md) 第四节）。

## 三、上公网之前，这三件事先做完

1. **改掉默认密码**。默认的 `admin` / `123456` 在局域网里是隐患，到了公网就是敞门——改法见 [管理员密码与权限设置.md](管理员密码与权限设置.md)，密码设长设复杂；
2. **服务地址不要公开传播**。不发群、不发帖；公网入口只给自己和家里人在用；
3. **尽量走加密**。明文 `http` 会把账号密码裸传，对外暴露的入口建议在「高级配置」里启用 HTTPS，或在前面套一层带证书的反向代理。配置改坏了服务起不来，按 [常见问题与报错处理.md](常见问题与报错处理.md) 第二节退回。

另外提醒一句网盘侧的风险：把挂了网盘的服务暴露到公网，等于让网盘账号被多个 IP 访问，可能触发网盘风控，官方文档对此有明确警告（见 [挂载网盘与添加存储.md](挂载网盘与添加存储.md) 第四节）。组网工具路线（只有自己的设备可达）在这点上最稳妥。

## 四、配完怎么验证

手机关掉 Wi-Fi、用流量访问你配好的外网地址：能看到登录页说明链路通了；再登录点开一个挂载目录，能列出文件才算全程可用。连不通时先在家里网络内确认服务本身正常（[常见问题与报错处理.md](常见问题与报错处理.md) 第一节），服务没问题再去查路由器或穿透工具那一侧。

在外面连上之后，网页、WebDAV 的用法和在家完全一样，只是地址换成外网入口——播放器那套参数填法见 [WebDAV连接与播放器搭配.md](WebDAV连接与播放器搭配.md)。
