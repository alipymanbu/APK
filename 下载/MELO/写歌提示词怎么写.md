## 一、一句话决定八成结果

在 MELO 里，「给我写首好听的歌」这类描述等于让 AI 猜你的口味——它猜错不是能力问题，是你没给信息。多轮公开教程总结出一个通用公式，套上就基本不翻车：

**语种 + 曲风 + 人声风格 + 情绪氛围 + 小细节**

反面：`给我写首悲伤的歌`
正面：`国语女声，emo 流行，烟嗓，凌晨三点刷朋友圈的丧感，钢琴打底，带点下雨的白噪音，旋律别太吵，适合深夜循环`

差别只有一处：后者每个词都在缩小选择范围。写提示词的本质就是把「你脑子里那个画面」拆成 AI 能执行的约束。

## 二、五个要素各自写什么

| 要素 | 写得具体一点的样子 |
| --- | --- |
| 语种 / 方言 | 国语、粤语男声、闽南语、英语、日语 |
| 曲风 | 不要只写「电子」，写 lo-fi、City Pop、90 年代港风摇滚、史诗配乐 |
| 人声 | 男声 / 女声 + 质感（烟嗓、气声、清甜、童声）+ 唱法（慵懒、高亢、带哭腔） |
| 情绪 / 场景 | 用画面替代形容词：「凌晨三点的出租屋，窗外下雨」比「伤感」准得多 |
| 小细节 | 主乐器（钢琴 / 古筝 / 吉他）、速度（中速 / 慢）、用途（适合深夜循环、当 Vlog BGM） |

三条避坑：

1. **别堆乐器**——列七八样会互相打架，挑 3~5 核心的就够；
2. **别自相矛盾**——「又炸又安静的纯音乐」这种描述，AI 只能二选一；
3. **定位放开头**——先写「都市治愈流行曲」再补细节，比把关键信息埋在句尾有效。

## 三、结构标签：让歌有完整骨架

不想只得到一段副歌循环，就在提示词或歌词里标出段落：

```
[前奏] 古筝泛音 + 流水声，静谧悠远
[主歌] 竹笛打底，人声轻柔叙事，鼓点弱进
[副歌] 大鼓 + 弦乐齐奏，人声高亢有力量
[桥段] 节奏抽空，只剩人声和钢琴
[尾奏] 渐弱收尾
```

通用标签对应关系：`[Intro]` 前奏、`[Verse]` 主歌、`[Chorus]` 副歌、`[Bridge]` 桥段、`[Outro]` 尾奏。分段描述每一段的配器与情绪，成品的层次感会明显不同于「一整块」的提示词。

## 四、排除法：说清不要什么

生成结果里老混进不想要的元素时，直接声明排除项，这招在多篇实测里被反复提到：

- 生成国风抒情曲：补一句「避免电子鼓、合成器音色，不要现代流行元素」；
- 生成轻柔纯音乐：补「无打击乐，无强烈节奏」；
- 只要伴奏不要人声：明确写「纯音乐，无人声」。

「不要什么」和「要什么」同等重要——它把模型的自由发挥空间再砍一刀。

## 五、歌词里的几个符号技巧

以下是用户实测总结的写法（有用户反馈称在 MELO 上有效，你可先小成本试一次）：

- **拖长音**：把字拆开写，`快乐～` 写成 `快 - 乐 -`，唱出来就带余音；
- **加和声**：把要和声的词塞进括号，`摸鱼的快乐（快乐） 谁懂啊（懂啊）`，直接出双声部；想做合唱、童声伴唱同理；
- **控情绪**：句末用标点引导力度——`下班万岁！` 走高亢，`老板来了吗？` 走心虚低语；
- **写清演唱对象与场景**：「给女朋友的纪念日民谣」比「情歌」的成品贴合度高。

## 六、生成之后怎么迭代

1. **一次会出多个版本**：有用户反馈 MELO 普通短曲几十秒出结果、一次给两个不同版本，先在两版里挑，再往下改；
2. **改描述比重做整首省**：在对话里指出具体问题（「副歌再高一点」「鼓别这么满」），模型会接着调；
3. **分段推进**：先让副歌达标，再扩展成完整歌曲；单段不满意就只改那一段，保住已经好的部分；
4. **用素材锚定方向**：脑子里有旋律就录哼唱、有氛围就丢张照片——比纯文字更不容易跑偏（输入方式见 [AI写歌怎么用.md](AI写歌怎么用.md)）。
