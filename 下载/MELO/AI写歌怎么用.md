## 一、它的交互方式：聊出来的歌

MELO 没有参数面板——没有「BPM 滑块 + 调式下拉 + 编曲模板九宫格」那套。你打开应用，对着输入框像发消息一样描述你想要的歌，它就去生成。不懂乐理、不会乐器、没碰过 DAW，都不影响你走完全流程。

第一条提示词决定了 80% 的结果。写清这三件事，出来的歌通常一次就对：

1. **主题**：写什么——毕业季、生日、给某个人、一段旅行；
2. **情绪 / 曲风**：治愈民谣、燥一点的摇滚、夜晚都市感、史诗配乐；
3. **具体要求**：想要男声还是女声、要不要纯音乐、多长、用什么语言唱。

例如「写一首关于毕业季的粤语民谣，女声，前奏用吉他，3 分钟左右」。含糊的「来首好听的」也能出歌，但大概率要靠后面反复改——提示词的完整写法（含结构标签、排除法）单独写在 [写歌提示词怎么写.md](写歌提示词怎么写.md)。

## 二、你能喂给它的东西

不限于打字。MELO 的输入覆盖了这几类，随手有什么就给什么：

| 输入 | 你得到什么 |
| --- | --- |
| 一句话 / 情绪描述 | AI 自动作词、谱曲、演唱、混音的完整歌 |
| 完整歌词 | 直接给词谱曲演唱 |
| 一张照片 | 识别画面色调与情绪，生成匹配氛围的歌或纯音乐 |
| 哼唱 / 清唱 | 旋律片段被扩展成完整歌曲 |
| 伴奏 / beat | 自动填词配人声 |
| 短视频 / vlog 片段 | 按画面节奏生成卡点的背景音乐 |
| 参考音频 | 解析风格，按那个路子重做一版 |

图片和视频那两类要先给相册权限，哼唱要给麦克风——权限没开就调不起来，见 [下载与安装教程.md](下载与安装教程.md) 第五节。

## 三、曲风、语言和时长

- **曲风**：流行、古风、民谣、R&B、说唱、DJ、摇滚、史诗、电子、Lo-fi 等都在覆盖范围；国风里的古筝、唢呐、二胡、马头琴这类音色也做得比较细。曲风直接写进提示词即可，例如「赛博朋克 + 民乐」这种混搭也是这么写。
- **语言**：中文咬字是它主打的部分；方言与民族语言做了专门优化——粤语、闽南语、藏语、蒙语、维吾尔语、客家话都能唱；外语支持英语、日语、韩语、西班牙语、印地语、越南语等。
- **时长**：单首最长可到 8 分钟，能放下完整的前奏、主副歌、桥段和尾奏，长篇叙事的歌不至于被拦腰截断。

## 四、音色：用别人的声音，也用你自己的

- **系统音色**：烟嗓、御姐、奶声、气泡音、童声、大合唱等，点选即可；男女对唱、多人合唱也能配。
- **音色克隆**：你上传一段自己的录音（朗读或清唱都行），它训练出一张专属音色卡片，之后任何一首歌都能指定用你的声音唱。录样本时在安静环境、离麦 20 厘米左右、连读一两分钟不被打断，出来的效果比随手录一句自然。
- 克隆的音色属于你账号，见 [注册账号与登录.md](注册账号与登录.md)——换设备登录同一账号就能用上。

## 五、二创：翻唱、改编与续写

拿到一首歌之后还能继续折腾：

1. **原曲翻唱**：上传原唱音频或无伴奏人声，AI 换一种唱法、换一个音色重唱；
2. **提取伴奏**：把人声和乐器拆开，得到可复用的伴奏；
3. **原词新曲 / 重新编曲**：词不变换曲子，或保留旋律改编曲；
4. **灵感提取**：从一首成品里抽动机，作为下一首的起点。

唱别人的歌来玩没问题，但**要把成品发到音乐平台或用于商用，先确认词曲本身的授权**——平台保的是你生成的那部分，原作版权是另一回事。

## 六、几个实用习惯

- **不满意就接着聊**：在对话里说「副歌再高一点」「鼓别这么满」，比从头重写省时间。
- **一次多试几版**：同一句提示词可以生成多个方案，挑最接近的再往下改；有用户实测普通短曲**几十秒**就能出结果、一次给两个版本——短曲的试错成本不高，别在一条死路上改到天荒地老。
- **免费额度是每日重置的**：每天登录领当日积分，不用攒着，见 [会员价格与积分.md](会员价格与积分.md)。
- **觉得能用就先导出**：歌在云端，本地留一份 MP3 / WAV 才踏实，方法见 [导出MP3与分轨.md](导出MP3与分轨.md)。

生成一直转圈、报失败、或者积分不够了，去 [常见问题与排查.md](常见问题与排查.md) 找对应的处理办法。
