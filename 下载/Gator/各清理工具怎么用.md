Gator 一共七件工具，都从首页进入，官方没有出中文界面，第一次用容易在术语上卡住。本篇按日常使用频率排的顺序逐个讲：先主清理，再单项工具，最后是自动化。安装与权限还没配好的，先看[下载与安装教程](下载与安装教程.md)。

## 一、System Cleaner：主清理入口

这是打开 Gator 后最常用的一个，清理对象包括残留文件、缓存、日志、浏览器历史这类系统垃圾：

1. 点 System Cleaner 右下角的 **scan** 开始扫描；
2. 第一次扫描会接连弹出存储、使用情况等授权窗，按提示逐个允许，回到 Gator 再点一次 scan；
3. 扫描结果里点条目左侧的眼睛图标，能展开看到具体是哪些文件，再决定去留；
4. 勾选要删的项，点右下角的清理按钮执行。

有一类条目要留意：临时 root 数据的清理只对已 root 的设备生效，没 root 时这项扫不出来或执行不了，不是故障，说明见[常见问题与排查](常见问题与排查.md)第二节。

## 二、Cache Cleaner：按应用清缓存

按单个应用清缓存，适合「就那几个应用占得多」的场景。网盘里这份 8.1.16 的设置里有两项与扫缓存直接相关的开关，都是这一版刚加上的：

- **最小缓存体积**：低于这个大小的缓存直接跳过，省得为几百 KB 跑一轮；
- **是否扫描系统应用**：系统应用的缓存一般不大，关掉能明显缩短扫描时间。

排除指定应用的开关是 8.1.17 才加的，8.1.16 没有——想跳过某个应用，只能靠上面两项粗粒度设置凑合，或者升级到更新版本（版本差异的完整对照见[常见问题与排查](常见问题与排查.md)第五节）。

## 三、Duplicate Finder：找出重复文件

把重复的照片、视频、文档找出来列出，你核对后删掉多余的副本，给存储腾地方。删除前把每组展开看清楚再勾——同一场景连拍了两张，留哪张只有你自己能判断。文件删了就找不回来，拿不准的先复制一份到别处再动手。

## 四、Exporter：把文件搬到外置存储

Exporter 负责把选中的文件转移到 SD 卡一类的外置存储，给内部存储腾地方。手机没插存储卡时这项用不上；插了卡但提示无权限的，先去系统设置里确认 Gator 的存储写入权限已打开（各系统叫法不同，以设置里实际显示为准）。

## 五、Storage Analyzer：先看空间都被谁占了

删之前先搞清楚空间去哪了：Storage Analyzer 按占用列出文件与应用，占大头的大文件、大应用一目了然。顺手的用法是先用它定位，再用 Exporter 把不想删的大文件搬去外置卡，或在 App Manager 里卸载不用的应用。

## 六、App Manager：备份与卸载应用

App Manager 列出已装应用与各自占用，能做两件事：

- **卸载**：点选应用直接卸载；卸载系统自带应用需要 root，普通应用不需要；
- **备份**：把应用的安装包导出来留存，重装不用重新找资源。

备份出的安装包落在手机存储里，换机或恢复出厂设置前记得先用 Exporter 或文件管理器把它挪出去（恢复时的步骤见[常见问题与排查](常见问题与排查.md)第四节）。

## 七、Automated Cleaning：让清理自动跑

Automated Cleaning 是自动清理：设定好之后不用你手动点扫描，到点自动执行。它的缓存清理部分靠系统无障碍接口代替你操作（官方在应用介绍里明确做了这条说明），所以这个功能能不能长期稳定跑，取决于无障碍权限是否一直有效——被系统省电策略自动关掉是这类功能最常见的失效原因，恢复办法见[无障碍服务权限怎么开](无障碍服务权限怎么开.md)。

另要有心理预期：在用户评论里，「Scheduler（定时器）不干活」是被反复提到的一类反馈，权限全对、设备也兼容的仍可能撞上。排查无果就先回 System Cleaner 手动清，别在自动清理上死磕，具体见[常见问题与排查](常见问题与排查.md)第三节。

## 八、七个工具速查

| 工具 | 一句话用途 | 备注 |
| --- | --- | --- |
| System Cleaner | 扫描并清理残留、缓存、日志、浏览器历史 | 临时 root 数据项需 root |
| Cache Cleaner | 按应用清缓存，可设最小缓存体积 | 排除指定应用需 8.1.17 及以上 |
| Duplicate Finder | 找出重复文件，删多余副本 | 删前逐组核对 |
| Exporter | 把文件转移到外置存储 | 需要外置存储在位 |
| Storage Analyzer | 按占用定位大文件、大应用 | 定位后配合 Exporter、App Manager 用 |
| App Manager | 备份、卸载应用 | 卸载系统应用需 root |
| Automated Cleaning | 自动清理 | 依赖无障碍服务 |
