# Gator 权限与隐私

> Gator 是清理类应用，申请的权限级别普遍不低；本篇把它权限单里影响大的项逐个讲清是干什么用的，追踪器与隐私政策的现状也一并交代，给你授权前判断的依据。

清理工具的工作方式决定了它必然碰文件、碰应用列表，权限申请单因此普遍偏长，Gator 也不例外。本篇把这份权限单拆开看，再交代数据上报与隐私政策；授权时机与无障碍权限的取舍见[无障碍服务权限怎么开](无障碍服务权限怎么开.md)。

## 一、权限单逐项看

第三方隐私分析平台 εxodus 对 Google Play 版 8.1.23 的静态分析显示共 17 项权限（8.1.16 与其同属 8.1.x 代码线，你的设备上以安装时系统弹出的清单为准）。影响较大的几项：

| 权限 | 干什么用 |
| --- | --- |
| MANAGE_EXTERNAL_STORAGE（所有文件访问） | 扫描与清理的基础，不给则核心功能基本用不了 |
| CLEAR_APP_CACHE | 直接清除应用缓存，Cache Cleaner 与自动清缓存都靠它 |
| PACKAGE_USAGE_STATS（使用情况访问） | App Manager、Storage Analyzer 的占用数据来源 |
| QUERY_ALL_PACKAGES | 应用管理页能列出设备上全部应用 |
| REQUEST_DELETE_PACKAGES | App Manager 卸载应用的动作 |
| WRITE_SECURE_SETTINGS | 可写入部分系统设置；官方未逐项说明用途，属于这份清单里级别最高、最值得留意的一项 |
| RECEIVE_BOOT_COMPLETED | 开机自启，重启后恢复自动清理 |
| FOREGROUND_SERVICE、POST_NOTIFICATIONS、WAKE_LOCK | 清理过程保活、进度通知、批量清理时不被系统休眠打断 |
| INTERNET、ACCESS_NETWORK_STATE | 基本网络能力，主要对应崩溃统计上报 |

判断的落脚点不是它申请了多少，而是这些权限是否都能对上你用得到的功能。完整清单在安装时的系统弹窗里可以逐项看到，装完想复核的，到 εxodus 报告页搜包名 `com.mitigator.gator` 即可：`https://reports.exodus-privacy.eu.org/en/reports/search/com.mitigator.gator/`。

## 二、追踪器与数据上报

同一份 εxodus 报告显示，8.1.x 与 8.2.x 这些较新版本只检出 Google CrashLytics 一个追踪器（崩溃统计用途）；更早的版本（8.0.8 及以前）曾检出 2 个。也就是说联网行为主要就是崩溃上报这一类，应用本身没有登录账号体系，也没有账号可注销的问题。

## 三、隐私政策在哪

开发者在 GitHub 上发布了隐私政策（`https://github.com/ampfarisaho/GATOR`），授权前想先读条款的从这里进。另有用户评论提到它「不索要不必要权限、不与第三方共享数据」——这是单个用户的评价口径，不构成审计结论，参考即可。

## 四、这个应用的基本盘

给你几个第三方统计口径的背景数字（截至 2026-09，chrome-stats 统计）：2019 年 6 月上架 Google Play，累计下载约 74 万，全期评分 3.82（约 3400 条评分），近期评分 3.40。好评集中在清理效果、速度快与无广告，差评集中在稳定性——卡死、自动清理失效、个别机型（如 Poco）兼容问题，这些反馈对应的处理办法写在[常见问题与排查](常见问题与排查.md)里。开发者发布地按 chrome-stats 记录为南非。
