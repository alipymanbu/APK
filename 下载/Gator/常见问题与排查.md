# Gator 常见问题与排查

> 扫描完了空间没变大、系统应用卸不掉、自动清理隔天就停——Gator 用起来最常见的几个问题，本篇逐个给排查方向。

Gator 本身操作不复杂，多数「用不动」的情况都出在权限、root 限制与预期落差上。本篇按出现频率排序列了六个问题，每个先给判断办法，再给处理步骤。

## 一、扫描完成，可用空间却没变大

先分清「列出的垃圾」和「真正删掉的」：

- 清理执行中途弹了权限窗没处理的，动作可能没跑完——重跑一次扫描，看列表是否明显变短；
- 缓存类垃圾单个都不大，一次清出几十到几百 MB 就算正常，别期待清出几个 GB；
- 部分系统的存储统计有延迟，隔几分钟再看设置里的存储页；
- Duplicate Finder 只列出重复项，不会主动删，要去[各清理工具怎么用](各清理工具怎么用.md)第三节手动确认删除。

## 二、系统应用卸不掉 / root 相关功能不生效

Gator 里有两类操作明确需要 root：卸载系统自带应用、清理临时 root 数据。没 root 的设备上，这些条目要么不出现、要么点了没效果——这是权限限制，不是软件坏了。普通应用的备份与卸载不受影响，也不会因为没 root 而打折扣。

## 三、Automated Cleaning 到点不跑

九成是无障碍权限被系统关了，按[无障碍服务权限怎么开](无障碍服务权限怎么开.md)第二节恢复；恢复后回到 Automated Cleaning 检查定时计划是否还在，等下一个周期验证。反复失效的，重点查省电策略与手机管家的权限回收。

## 四、App Manager 备份的应用怎么恢复

备份得到的是 APK 安装包，存在手机存储里，恢复就是把它再装一遍：

1. 换机或恢复出厂前，先用 Exporter 或文件管理器把备份文件转移到外置存储或云盘；
2. 在新设备上打开 APK 安装，「未知来源」的处理与首次授权见[下载与安装教程](下载与安装教程.md)第三节、第四节；
3. 装完用 App Manager 核对一下应用列表，确认备份的应用都在。

## 五、网盘里的版本比官方旧，要不要紧

网盘里这份是 8.1.16（版本、体积、MD5 见[下载与安装教程](下载与安装教程.md)第二节），截至 2026 年 9 月官方渠道最新版已到 8.2.8。功能差异集中在 Cache Cleaner 的设置上：8.1.17 加了排除指定应用的开关，8.1.19 加了包含隐藏系统应用的选项。在意这几项设置的，从官方渠道更新；只是日常清缓存的话，这些差异影响不大。

| System Cleaner | 系统清理（主入口） |
| Cache Cleaner | 缓存清理 |
| Duplicate Finder | 重复文件查找 |
| Exporter | 导出 / 搬到外置存储 |
| Storage Analyzer | 存储分析 |
| App Manager | 应用管理 |
| Automated Cleaning | 自动清理 |
| scan | 扫描 |
