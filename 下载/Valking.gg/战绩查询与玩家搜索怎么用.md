## 一、查战绩前先知道的一件事

Valking.gg 能查的是**公开资料的玩家**——这是官方描述里写明的前提（"Look up any Valorant player with a public profile"）。自己的数据如果查不出来，多半是账号可见性没开，处理办法见[常见问题与排查.md](常见问题与排查.md)。

查数据不需要在手机上装《无畏契约》，它只是读取官方接口里的对局记录。装好 App、登录 Riot 账号后就能用，安装见[下载与安装教程.md](下载与安装教程.md)。

## 二、搜一个玩家

1. 打开应用，进搜索入口，输入玩家的 Riot ID（游戏名 + 标签码，形如 `showmeth castle#rrr`）；
2. 打开对方的公开资料页；
3. 资料页里能看到段位、近期比赛列表和汇总数据。

搜不到人时的排查见[常见问题与排查.md](常见问题与排查.md)。

## 三、收藏夹：盯住固定的对手和好友

把常用的人加进收藏夹，之后查战绩就不用每次重搜：

1. 在玩家资料页点收藏 / 加入 favourites；
2. 收藏夹里的人再打开时，能直接看其每场比赛的详细数据；
3. 对手和好友用同一套收藏管理，改名或换号后按新的 Riot ID 重搜一次即可。

## 四、逐场比赛看什么

点开比赛历史里的任意一场，能看到一局的完整复盘数据：

- **计分板**：双方每个人的击杀 / 死亡 / 助攻；
- **武器数据**：爆头率、平均命中等分枪统计；
- **KDA 与其他指标**：用来和这局里的好友、对手横向比。

这些数字都来自对局记录本身，看的是**已经打完的局**，没有预估和换算成分。

## 五、战绩总览：近期表现一页看完

总览页是对最近一批比赛的汇总，适合每局打完随手看：

| 区块 | 你能看到什么 |
| --- | --- |
| 按地图统计 | 每张地图上的场次、胜率等汇总 |
| 按特工的段位详情 | 用不同特工打出来的段位分布 |
| 武器统计 | KDA、胜率、平均命中等近期汇总 |

拿不准「胜率高但段位没动」是为什么，可以结合[特工胜率榜数据怎么看.md](特工胜率榜数据怎么看.md) 里的全服基准对照着看——全服同段位的胜率水平是会随版本变的。
