## 一、先做三个通用动作

按顺序做，多数小毛病在这一步就解决了：

1. **完全关掉再开**：从最近任务里划掉 twime，重新打开。
2. **重启手机**：清掉后台内存冲突，对「一闪就退」类问题最省事。
3. **换网络试**：Wi-Fi 和移动数据切一下 —— 登录、发帖、刷推文全要联网，网络不通时表现出来就是「卡住不动」。

有效就到此为止，无效继续往下。

## 二、打不开或闪退

1. **强制停止**：长按 twime 图标 → 应用信息 → 强制停止，再打开。
2. **清缓存**：应用信息 → 存储占用 → 清除缓存（不丢登录状态），再试。
3. **查存储空间**：手机可用空间低于 1GB 左右时，安卓会边跑边杀应用。去设置里清理出 2GB 以上再测。
4. **清数据重来**：应用信息 → 存储占用 → 清除数据。**这一步会退出登录、清掉本地草稿**，先确认没有没发的稿子再点。
5. **重装**：以上都无效就卸载重装 —— 安装包用 [下载与安装教程.md](下载与安装教程.md) 里那份（twime 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/a082b9f9399b](https://pan.quark.cn/s/a082b9f9399b)），装完重新微信登录。
6. **只在 twime 上闪退、别的应用正常**时才继续深挖；如果好几个应用同时闪退，问题多半在手机本身（存储、内存、系统更新），先把手机侧处理干净。

## 三、微信登录不上

twime 只有微信登录这一条路，登录失败基本就四种原因：

| 现象 | 原因与处理 |
| --- | --- |
| 点「微信登录」没反应 | 手机上没装微信，或微信本身没登录 —— 先打开微信确认能用，再回来重试 |
| 跳到微信后返回失败 | 微信授权页没点同意；重新点一次登录，在微信侧完成授权 |
| 一直转圈 | 网络不通，按第一节第 3 条切网络；或者服务端忙，过几分钟再试 |
| 反复回到登录页 | 本地登录态坏了：清缓存 → 不行就清数据 → 再不行卸载重装再登 |

若你的微信本身被封或需要验证，先在微信里把账号问题解决，twime 这侧登不进去是正常表现。

## 四、页面空白、帖子发不出去

- **刷不出内容**：切网络重试；清缓存后重开（缓存损坏时页面会长期空白）。
- **点「+」没反应**：先确认没卡在加载动画上 —— 等几秒；仍无反应就强制停止后重开，编辑中的草稿若还在，见 [捡手机文学发帖教程.md](捡手机文学发帖教程.md) 的步骤重发一遍。
- **发布后看不到自己的帖**：回发现页下拉刷新；刷新后仍没有，退出重登一次再看。
- **图片传不上去**：检查相册权限（应用信息 → 权限 → 存储/照片），并确认图片本身能打开。
- **被扣了费、想关自动续费**：这不是故障，是订阅在自动续期 —— 去 Apple 的订阅管理里取消，步骤见 [会员价格与取消续费.md](会员价格与取消续费.md)。

## 五、什么时候该换版本

同一台手机反复出问题、而别的手机正常时，可以考虑换一版包试：商店里的最新版和网盘里这份 1.3.0 不是同一个文件，版本差异可能就是差异来源。两份怎么选、怎么核对 MD5，见 [下载与安装教程.md](下载与安装教程.md)。角色或对话相关的表现异常（内容明显不对劲），多半不是故障，先看 [自定义角色设置教程.md](自定义角色设置教程.md) 的设定是否写清了。
