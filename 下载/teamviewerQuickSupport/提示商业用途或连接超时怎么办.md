# 提示商业用途或连接超时的解除办法

> 免费版连不上、报「连接超时」，多半是 TeamViewer 把你判成了商业用途——官方解除路径只有这一条。

## 一、先对号入座：这些提示是同一件事

TeamViewer 官方知识库明确：对**无许可的免费用户**，下面这些表现都指向同一个原因——你的 TeamViewer ID（和/或账户）被判定为**疑似商业用途**：

- 连接时提示「疑似商业用途 / 检测到商业用途」；
- 反复报**「连接超时」**——官方 FAQ 直说这个报错不是软件故障，同样与疑似商业用途有关；
- 连接请求发出去后对方无响应，重试也一样。

用家里人帮家里人、朋友之间远程看一眼的场景，被误判并不罕见；官方也承认会有误判，并为这种情况留了申诉通道。

## 二、解除路径：只有一条，走官方重置表单

先排除一个常见错误做法：**卸载重装没有用**。官方 FAQ 原话——卸载 TeamViewer 不会移除疑似商业用途标记，只有申请重置并拿到官方肯定回复才会解除。

正确步骤（官方表单 [teamviewer.com/reset](https://teamviewer.com/reset)）：

1. 打开表单页，点开始按钮；
2. 填你的姓名、注册 TeamViewer 用的邮箱，并**用几句话写清你怎么使用**（比如「个人免费版，帮家人远程处理手机问题」）；
3. 填上这次连接**涉及的所有 TeamViewer ID**——你自己的和对方设备的都要填；
4. 同意隐私政策，提交。

提交后的处理节奏（官方口径，以官方页面当时显示为准）：

- 审核承诺 **72 小时内**开始处理并发邮件回复；实际积压时官方给过「争取 7 个工作日内处理完」的说法；
- 申诉表**按提交先后**处理；同一 ID 不要重复提交，重复提交会以最新一次重新排队，反而更慢；
- 表单需**用英文填写**；一周没收到回复，先查垃圾邮件文件夹。

几个容易踩的坑：

- **每份表单最多填 10 个 ID**。要把你这头和对方那头的 ID 都报全，漏掉对端 ID 会让连接继续超时；
- 解锁只对**表单里提交过的 ID** 生效，不作用于账户整体——所以两头的 ID 都得提交。

## 三、提交完的两种结果

1. 官方确认为个人用途 → **重置你的 TeamViewer ID**，恢复正常免费使用；
2. 仍被判定疑似商业用途 → 不重置，但会给你一次填写**个人用途声明**的机会（依据最终用户许可协议第 3.9 条）。

注意第一种结果意味着**你的 TeamViewer ID 会变**——旧 ID 记在对方设备的收藏列表里的话要更新，新 ID 从 QuickSupport 主界面上读，见 [远程协助连接步骤.md](远程协助连接步骤.md) 第一步。

## 四、免费政策本身没有变

官方在同一篇 FAQ 里反复确认：**个人使用 TeamViewer 仍然免费**，免费版的定位就是帮家人朋友；要求商业使用的人买许可，是为了维持免费版。所以你不需要为「解除误判」付钱——走完上面的申诉流程即可；真正用于商业支持的场景，才需要订阅方案（免费与商业的边界见 [常见问题与免费限制.md](常见问题与免费限制.md)）。

如果被限制的是你自己的 ID，解除后继续按 [下载与安装教程.md](下载与安装教程.md) 的口径核对版本即可。
