# QuickSupport 和 Host 无人值守版怎么选

> 两款都能让别人进你的安卓手机，差别只在「进之前要不要你点允许」——选错款会白装。

## 一、一句话差别

- **QuickSupport**（本篇这份）：每次有人连进来，**你的手机上必须弹窗、必须你亲手点允许**——有人值守。
- **Host**：设备绑定到一个 TeamViewer 账户后，**不需要任何人点允许**就能被连——无人值守。

两者装在同一台手机上**互不冲突，可以共存**，按当下场景用哪个都行。

## 二、对照表

| 对比项 | QuickSupport | Host |
| --- | --- | --- |
| 连接要不要被控端确认 | 要，每次连接都要点允许 | 不要，可无人值守直接连入 |
| 谁能连进来 | 手上有你 TeamViewer ID 的人（经你允许） | **只有你绑定的那个 TeamViewer 账户**，ID 直连不支持 |
| 典型场景 | 临时找人帮忙：长辈手机出问题、朋友远程指导 | 自己长期管理：备用机、门店展示机、POS/广告机 |
| 需要账号吗 | 被控端不需要登录 | 装好后必须把设备**分配到你的账户** |
| 插件 | 支持厂商专用插件；另有通用插件（Android 7+） | 只能用厂商专用插件，**通用插件不适用** |

## 三、按场景选

**选 QuickSupport，如果**：问题是临时的——你人在场、能把 ID 报给对方、也愿意每次看着他进来。这是「找人远程协助」的默认答案，也是唯一支持「对方拿 ID 直接发起连接」的那款（Host 不支持 ID 直连）。

**选 Host，如果**：设备放得远、你没法在旁边点允许——比如家里常年不用的备用机、店里没人看管的展示设备。绑定账户后你从自己的电脑或手机上随时连进去，不用任何人操作手机。

一个折中判断：**你需不需要「对方连进来时我不在手机旁边」**。需要 → Host；不需要 → QuickSupport 就够。

## 四、连进来之后能做什么

不管哪款，能做什么先取决于前面提过的两级能力：屏幕共享所有 Android 5.0+ 机型都有，远程控制（能替你点按）要看厂商支持，排查方法在 [只能看屏幕不能控制怎么办.md](只能看屏幕不能控制怎么办.md)。

另外，被控端是安卓**手机对手机**的连接属于纯远程访问——只有控制画面，没有文件传输这类功能；桌面端对手机的连接能力和授权要求另算，见 [常见问题与免费限制.md](常见问题与免费限制.md)。
