## 一、免费吗？

免费，但**分用途**：官方口径是 QuickSupport 个人非商业用途免费；用于商业远程支持则需要有效的 TeamViewer 许可或订阅。个人拿它帮家人修手机，属于前者。

需要留意的是，「免费」还叠着下面几条连接层面的限制——不是装完就一劳永逸。

## 二、5 分钟限制是怎么回事

官方知识库写明：**个人（免费）用户，手机连手机的每次连接限时 5 分钟**。

- 限的是**单次会话**，不是总量——到点断开后重新发起即可，次数不受限。
- 断在关键步骤上确实烦，所以一次协助前先把事情说清楚（要改什么、对方会点哪里），真不够用就到点重连，见 [远程协助连接步骤.md](远程协助连接步骤.md)。
- 排查「突然断线」时先掐表看是不是总在第 5 分钟——是的话就不是故障，见 [连接几秒就断怎么排查.md](连接几秒就断怎么排查.md) 第四节。
- 该条针对的是移动设备之间的连接；具体口径以 TeamViewer 官方知识库当时显示为准。

## 三、电脑连手机要不要钱

要。官方 QuickSupport 页面标注：**从桌面设备连接到移动设备，需要 TeamViewer 订阅方案 + 移动设备支持（MDS）加载项**。也就是说，你在电脑上输入手机的 ID 去连，属于付费能力范畴。

官方两处口径要并列看：用例页写的是「桌面连移动需要订阅 + MDS 加载项」，而官方知识库的移动设备连接仪表盘文章里又写明「私人用户每次连接也限 5 分钟」——前者说的是许可门槛，后者说的是私人用户实际连接时的时长限制，两篇文章都在官方站点上，实际以哪条执行，以你连接时官方页面与提示为准。

免费能走通的组合是：**手机对手机**（受 5 分钟限制约束）。你若是纯粹「让懂行的朋友用他的手机帮我看一眼」，免费口径够用；要从自己的电脑长期维护手机，就得看订阅方案了。

## 四、它能做什么、不能做什么

**能**：

- 被动接收远程协助——对方通过你的 ID 发起、你点允许，之后看到你的屏幕；
- 配合厂商支持与插件，进一步让你被远程操作（点按钮、滑页面）；
- 不登录 TeamViewer 账户也能被连接（被控端不强制登录）。

**不能**：

- **不能主动去控制别人的设备**。官方明确：QuickSupport 不提供任何「从这里发起、去连别人手机/电脑」的功能。你想反向操作别人的手机，装的是「TeamViewer 远程控制」或桌面客户端。
- **不是无人值守方案**。想要「不用点允许就能连」，那是 Host 的活，见 [和Host版有什么区别.md](和Host版有什么区别.md)。
- **手机对手机的会话只有纯远程访问**：没有文件传输、没有设备仪表盘这类能力（这些属于桌面连接或 Host 侧的功能）。
- 不保证所有机型都能被操作——能不能动，取决于厂商支持，见 [只能看屏幕不能控制怎么办.md](只能看屏幕不能控制怎么办.md)。

## 五、其他高频疑问

**Q：每次连接都弹窗，正常吗？**
正常，这正是 QuickSupport 的设计（相对的是 Host 的免确认）。嫌它烦就换 Host，别指望这个 App 有「记住允许」的开关。

**Q：ID 会不会变？**
ID 显示在 QuickSupport 主界面，用于让对方发起连接。把它存进对方 TeamViewer 的「计算机和联系人」列表，下次能少报一遍数字；具体是否长期固定，以官方说明为准。唯一确定会换号的情况是走完了 ID 重置申诉（见 [提示商业用途或连接超时怎么办.md](提示商业用途或连接超时怎么办.md)）——重置通过后要重新把新 ID 告诉对方。

**Q：对方一直连不上，报「连接超时」？**
先别怀疑网络——官方 FAQ 明说这个报错与疑似商业用途有关，解除路径见 [提示商业用途或连接超时怎么办.md](提示商业用途或连接超时怎么办.md)；网络与后台层面的排查在 [连接几秒就断怎么排查.md](连接几秒就断怎么排查.md)。

**Q：装哪个版本？**
网盘里这份是 **15.50.396**（46.05M，包名 `com.teamviewer.quicksupport.market`，存档日期 2026-09-23），核对信息在 [下载与安装教程.md](下载与安装教程.md) 第二节；要不要直接装它、还是换官方商店的更新版本，以你手机实际的安装提示为准。

**Q：连上后黑屏或点不动？**
按 [只能看屏幕不能控制怎么办.md](只能看屏幕不能控制怎么办.md) 的三层排查走：权限 → 插件 → 机型支持。

**Q：想让设备长期被自己管着？**
用 Host 无人值守版，和 QuickSupport 的选型对照见 [和Host版有什么区别.md](和Host版有什么区别.md)。
