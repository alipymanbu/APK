# 让别人远程控制你手机的完整步骤

## 一、先把两边的角色分清

一次远程协助有两端：

- **你的手机（被控端）**：装 TeamViewer QuickSupport，负责「让人进来」。
- **对方的设备（支持端）**：装什么都行——TeamViewer 桌面客户端、网页版 [web.teamviewer.com](https://web.teamviewer.com/)、或手机上的「TeamViewer 远程控制」App，负责「发起连接」。

对方从哪边发起都可以，操作逻辑一致：填你的 ID → 发起 → 你点允许。你这边从头到尾只有一个动作核心：**把 ID 给出去，然后在弹窗上点允许**。

你还没装的话，先按 [下载与安装教程.md](下载与安装教程.md) 装好并跑通首次授权。

## 二、连接前的 3 个准备

1. **你的手机**：QuickSupport 处于打开状态，停留在显示 ID 的主界面；「显示在其他应用上层」权限已开（见安装教程第四节）。
2. **对方设备**：能上网，TeamViewer 版本别太旧——官方知识库的口径是对方需要 TeamViewer 12 或更新的 TeamViewer (Classic)，或新版 TeamViewer Remote。
3. **对方的身份**：确认发起连接的是你认识、且你愿意让他操作的人。你点下「允许」，对方就能看到你的屏幕，支持控制的机型上还能替你点按。

## 三、一次会话的完整流程

### 第 1 步：把 ID 告诉对方

打开 QuickSupport，主界面那串数字就是你的 TeamViewer ID。部分版本界面上还会同时显示一次性密码；没有密码也没关系——连接的确认权在你手里，对方靠 ID 发起后，你点允许即可。

直接打电话或发消息把 ID 报给对方，比打字传更不容易错。

### 第 2 步：对方发起连接

对方在他的 TeamViewer 里（桌面端的「远程支持」、远程控制 App 的「连接」页）输入你的 ID，点**连接 / 远程控制**。此刻你的手机屏幕上会弹出连接请求，显示请求方的信息。

### 第 3 步：你点「允许访问」

在你的手机弹窗上点**允许**（Allow access）。这一步就是 QuickSupport 和无人值守版的核心区别——**不点，谁也进不来**；点错了可以立刻断开。

### 第 4 步：确认系统的屏幕录制弹窗

允许之后，安卓系统还会再弹一次「开始录制 / 投射屏幕？」之类的提示，点**立即开始**（有的机型叫「开始现在」「允许」）。这一步是系统级的截屏录屏授权，不是 TeamViewer 自己的界面，漏掉它对方就会卡在「正在连接」。

到这里对方就能看到你的屏幕了。能不能进一步**替你操作**（点按钮、滑页面），取决于你手机的品牌是否被支持、插件有没有装对——连上却只能看不能动，按 [只能看屏幕不能控制怎么办.md](只能看屏幕不能控制怎么办.md) 处理。

### 第 5 步：结束会话

问题解决后，你可以在 QuickSupport 里断开连接，或直接把 App 关掉、退出会话。会话一结束，对方的访问权随之失效；下次再连要重新走一遍「发起 → 你允许」。

## 四、几个实用细节

- **ID 会一直显示在主界面**，不用登录 TeamViewer 账号也能被连——QuickSupport 的设计就是「打开、报 ID、允许」三步。
- **每次连接都要你手动允许**，这是 QuickSupport 的机制，不是故障。想免去这一步、让对方随时能进（无人值守），要用 Host 版，见 [和Host版有什么区别.md](和Host版有什么区别.md)。
- **对方连的是「手机连手机」还是「电脑连手机」**，影响能否免费用：手机连手机的免费口径与 5 分钟限制、电脑连手机的订阅要求，都写在 [常见问题与免费限制.md](常见问题与免费限制.md)。
- 弹窗有时会被系统延后几秒才出。等了十几秒还没见到，回 QuickSupport 主界面看一眼是否仍在运行，必要时重新打开它让对方重发。
