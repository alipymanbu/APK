## 一、先分清你要的是哪种歌词

| 类型 | 数据从哪来 | 在哪开 |
| --- | --- | --- |
| 内嵌歌词 | 写在 MP3 / FLAC 等文件内部 | 自动读取，无需开关 |
| LRC 文件歌词 | 与歌曲同目录、同名的 `.lrc` 文件（多编码都能读） | 自动匹配，文件放对位置即可 |
| 网络歌词 | 联网按歌名匹配 | 设置的「歌词」一节，需网络权限 |
| 翻译行 | 与正文同时间戳的翻译 | 歌词自带翻译时随主歌词一起显示 |
| 播放页歌词 / 迷你播放条歌词 | 同上任意来源 | 播放页点击歌词区域切换 |
| 桌面歌词 | 同上任意来源 | 单独开关，见第二节 |
| 状态栏 / 通知栏歌词 | 同上任意来源 | 单独开关 + 通知权限，见第三节 |
| 车载蓝牙歌词 | 走蓝牙把歌词带到车机 | 见 [手机车机适配与投送播放.md](手机车机适配与投送播放.md) |

排查从这张表开始：**你打开的开关，和你放的歌词文件，是不是同一行**。

## 二、桌面歌词开了却不显示

1. **开关位置**：多版本的教程给的路径是「设置 → 歌词 → 桌面歌词」，也有版本在「设置 → 用户界面」里 —— 两个入口都翻一下，以你这版界面上实际出现的为准；
2. **悬浮窗权限**：桌面歌词要盖在其他应用上面，系统不给 Salt Player 悬浮窗（显示在其他应用上层）权限时，开关打开了也不会出现 —— 到系统「设置 → 应用 → Salt Player → 权限」里补授；
3. **歌词本身不存在**：内嵌没有、同名 LRC 也没有、网络匹配又没开 —— 三路都空，屏幕上自然没字。先切到「播放页歌词」确认这首到底有没有歌词。

## 三、状态栏 / 通知栏歌词不显示

1. **先给通知权限**：这是最常见的原因。部分机型（OPPO ColorOS 是官方适配文档点名的一家）会默认屏蔽 Salt Player 的通知 —— 不去「设置 → 应用 → Salt Player → 通知」手动打开，状态栏歌词不会出现；
2. **找歌词开关**：设置的「歌词」一节里有状态栏/通知栏歌词的独立开关（较新的版本还带通知栏歌词的显隐选项），两个都要开；
3. **系统侧限制**：魅族 Flyme 的状态栏歌词是官方适配过的；华为鸿蒙的音乐控制中心则按白名单控制、暂不支持 —— 这类「系统不给位置」的情况见 [手机车机适配与投送播放.md](手机车机适配与投送播放.md)。

## 四、播放页歌词相关的小问题

- **歌词不滚动 / 快进后对不上**：先换歌词来源试 —— 内嵌、LRC、网络三路换一遍，能定位是歌词文件本身的时间轴问题还是读取问题；
- **翻译行不显示**：确认歌词文件自带翻译时间轴；没有翻译数据的歌词不会凭空生成翻译；
- **歌词界面入口**：播放页点击歌词区域进出歌词界面，左右滑切换（播放页 / 歌词 / 详情）的手势随版本略有差异，以你这版实际手势为准。

## 五、跟歌词无关但长得像的两种情况

- **通知整个不见了**：歌词开关没用，因为通知本身被系统清了 —— 通知权限与后台存活问题分别看第三节和 [后台播放中断怎么解决.md](后台播放中断怎么解决.md)；
- **歌都扫不出来**：没有歌自然没有歌词，回到 [扫描不到歌曲怎么办.md](扫描不到歌曲怎么办.md)。

刚装完想先把权限一次给齐，见 [安装与首次使用.md](安装与首次使用.md)。
