## 一、界面是韩文，怎么切语言

my1pick 由韩国公司 Doohub 出品，首次打开默认韩文。App 支持多语言界面（App Store 页面标注英文在内共 8 种），但**语言列表里有没有中文，以你手上这一版实际显示为准**——不同版本的翻译覆盖不一样。

切换入口在「我的页面」的设置里：

1. 点底部导航的 My（我的）。
2. 点右上角的齿轮（设置）。
3. 在设置列表里找 `Language` 或韩文 `언어` 字样的条目，点开选语言。
4. 菜单名各版本略有差异；找不到文字就认齿轮图标进去逐项翻。

如果语言列表里没有中文，选 `English` 是最稳的选择——官方商店页面明确列了英文界面。

## 二、注册与登录

投票、发帖这些核心功能都要先登录。登录方式随版本有变化，公开资料里的口径如下：

| 登录方式 | 说明 |
| --- | --- |
| Kakao | 韩国主流聊天工具账号 |
| Naver | 韩国门户网站账号 |
| Facebook | 各地区用户都比较容易具备 |
| Apple ID | iOS 设备上常见 |
| Line | 3.0.58 版（网盘安装包）的介绍文字提到过这一项 |

登录页实际显示哪几个入口，以你打开时看到的为准。对国内用户来说，Kakao 与 Naver 的注册门槛高，手上有 Facebook 或 Apple ID 就优先用那个。

登录后还有两步：起一个昵称、选一位主推艺人。粉丝社群的整理提到「只能选 1 位主推」「同一台设备可以用不同社交账号建多个账号」，这两点没有官方页面背书，以 App 内实际提示为准。

## 三、退出登录

1. 底部点 My（我的）。
2. 点右上角齿轮进设置。
3. 在登录方式那一栏，点你自己所用社交账号旁边的登出按钮。

## 四、换设备怎么办

账号跟着社交登录走，换手机后用同一个社交账号重新登录即可。换机前如果里面还攒着没投的心，先看一眼 [投票与爱心收集指南.md](投票与爱心收集指南.md) 里心的有效期口径，免得白攒。
