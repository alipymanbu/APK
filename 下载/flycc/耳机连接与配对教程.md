# Flycc 耳机连接与配对教程

> 本篇讲 Flycc 和耳机建立连接的完整链路：先在系统蓝牙里配对、再进 App 绑定，以及配对模式怎么进、提示恢复出厂怎么办。相关文档：[下载与安装教程.md](下载与安装教程.md) · [音效与降噪设置指南.md](音效与降噪设置指南.md) · [连接不上的解决办法.md](连接不上的解决办法.md)。还没装 App 的先看第一篇。

## 一、连接的整体顺序：先蓝牙，后 App

很多人卡在「App 搜不到耳机」，多半是顺序反了。Flycc 不负责让耳机被发现，它是在耳机已经连上手机蓝牙之后，再接管配置的。正确的顺序是：

1. 让耳机进入配对模式，在手机的蓝牙设置里完成配对；
2. 打开 Flycc，点「选择设备」，从已配对设备列表里点你的耳机；
3. App 与耳机建立连接后，耳机当前的配置会自动同步到 App 界面上；
4. 之后你在 App 里改任何一项设置，都会实时同步回耳机。

也就是说，App 的「选择设备」列表里出现的，是手机蓝牙**已经配对过**的设备。列表里空空如也，说明第一步还没完成。

## 二、第一步：让耳机进入配对模式

悦虎方案的耳机通常有两个默认行为：开盖自动开机，合盖自动关机。进入配对模式的方法取决于你的充电盒是哪种：

| 充电盒类型 | 操作方法 |
| --- | --- |
| 盒上有按键 | 耳机放盒内、开盖不取出，长按盒上按键约 3 秒，等指示灯闪烁 |
| 盒上无按键（带加速度传感器） | 开盖状态下，10 秒内连续双击充电盒，等指示灯闪烁 |
| 部分取消实体按键的新机型 | 开盖后按说明书提示敲击充电盒进入配对 / 重置（以你耳机附带说明为准） |

指示灯闪烁后，打开手机「设置 → 蓝牙」，在搜索列表里点耳机名字，手机弹出配对提示时选「配对」。不同手机系统的提示样式不同，同意即可；部分手机会要求授予位置或附近设备相关权限，给足，否则可能一直搜不到设备。

配对成功后，耳机就会在每次开盖时自动回连这台手机，之后一般不用再手动配对。

## 三、第二步：在 App 里「选择设备」完成绑定

耳机在系统蓝牙里显示「已连接」后，打开 Flycc：

1. 首页点「选择设备」；
2. 在弹出的已配对设备列表里，找到并点击你的耳机；
3. 连接成功的标志是：耳机上的配置信息自动出现在 App 界面里（电量、固件版本等）。

从这一步开始，App 才真正接管了耳机：你改的每一项都会实时写进耳机，各设置项的用法集中在 [音效与降噪设置指南.md](音效与降噪设置指南.md)。这一步绑定失败、或连上就断的，直接按 [连接不上的解决办法.md](连接不上的解决办法.md) 的排查清单走。

## 四、修改配置时提示「需恢复出厂」怎么办

个别配置项改动时，App 会提示需要耳机先执行恢复出厂设置。按这个流程处理：

1. 两只耳机都放回充电仓；
2. 保持开盖状态；
3. 长按充电盒按键约 10 秒，完成恢复出厂；
4. 回到 App 重新做刚才那项修改。

注意：恢复出厂会把耳机上已有的自定义设置一并清空，不只是你正在改的那一项。如果你的耳机之前调过不少东西，改完需要重新设置一遍。

## 五、一拖二：让耳机同时连两台设备

部分支持 EMP（双设备智能连接）的机型可以让一副耳机同时接两台手机。操作顺序：

1. 耳机先和第一台设备正常连接；
2. 把耳机放回仓内，按第二节的办法再次进入配对模式；
3. 用第二台设备搜索并连接该耳机；
4. 成功后两台设备都在连接列表里，哪台出声耳机就切给哪台。

你的机型支不支持 EMP，连上 App 后在设置里看有没有对应入口，没有就是不支持；少数旗舰芯片的机型还支持「一拖三」，操作与一拖二相同。各芯片与功能的对应关系见 [音效与降噪设置指南.md](音效与降噪设置指南.md) 和 [没有降噪设置怎么办.md](没有降噪设置怎么办.md)。

连接稳定之后，想做耳机固件升级的，再看 [固件OTA升级教程.md](固件OTA升级教程.md)。
