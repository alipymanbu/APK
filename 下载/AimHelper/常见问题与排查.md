## 一、准星根本不显示

按出现频率从高到低查：

1. **权限没给或被收回**——占这类问题的绝大多数，见[悬浮窗与无障碍权限怎么开.md](悬浮窗与无障碍权限怎么开.md) 第五节，处理完切回应用重开准星再进游戏；
2. **只装了没开**——准星要在 Aim Helper 里选中并启用才会画，装完直接进游戏是不会自己出现的；
3. **开了但被一键清理划掉了**——重新打开应用，把它的后台加上锁；
4. **安装包本身有问题**——核对版本与 MD5 是否和[下载与安装教程.md](下载与安装教程.md) 表格里的一致，不一致就重新下。

## 二、准星不在屏幕正中，总是偏

两种情况分开处理：

- **刚调完就偏**：位置参数没归中，回编辑界面把「位置」调回正中，顺序按[准星样式怎么调.md](准星样式怎么调.md) 第三节来；
- **进游戏打着打着偏了**：商店评论里有用户反馈过准星会移开中心。先确认不是自己没校准——安卓设备屏幕规格繁多，覆盖层的坐标不一定和某款游戏的准星重合，**用手动微调对齐**是通用做法：进游戏记下偏差方向（比如「往左上偏了约 5 毫米」），切回 Aim Helper 把位置参数往反方向挪同样距离，再回游戏看，一般两三个来回就能压中。再查屏幕比例这个诱因（游戏全屏、挖孔屏、21:9 屏都会让覆盖层坐标对不上）：先在游戏里把画面设成与手机原生比例一致（不少射击游戏有「画面比例 / 刘海屏适配」选项），再校一次。

## 三、进游戏闪退或变卡

评论里另一类常见反馈是运行中崩溃。按代价从小到大依次做：

1. **强制停止后重开**：「设置 → 应用 → Aim Helper → 强制停止」，再重新打开——不少偶发卡死到这一步就好了；
2. **清缓存**：同一页面「存储与缓存 → 清除缓存」。缓存只是临时文件，**不会删掉你存的准星**；只有「清除数据」会把设置全部重置，作为后手；
3. **先更新**：商店当前版本高于网盘这份，若闪退正是新版修掉的问题，升级即可；想继续用网盘这版，就跳过这条继续往下；
4. **查存储与内存**：手机可用空间低于 10% 时应用普遍容易崩，先清出几个 GB；后台挂一堆应用的低配机也一样，先清后台再进游戏；
5. **重装**：以上都无效就卸载重装（会丢已保存的准星，注意先记下自己的参数）。重装后问题依旧，且**只有这一款应用崩、别的都正常**——那多半是它与你系统的兼容问题，只能等开发者更新（你手里的 v1.1.7 之后官方还有新版本发布，见最后一节）。

顺带区分：若**多款应用同时开始崩**，问题通常不在 Aim Helper 身上，按系统更新、WebView 组件更新的思路查。

## 四、无障碍开关自己跳回关闭

安卓对无障碍的管控逐年收紧，常见原因与对策：

- **系统定时提醒**：有的系统会提示「无障碍服务可能读取你的屏幕内容」并要求重新确认，按提示确认即可，这不是它偷偷关的；
- **被清理工具关掉**：部分「手机加速 / 清理」类应用会在清理时顺手关掉无障碍。把它加入清理白名单；
- **系统升级后重置**：升级后到无障碍列表里重新打开一次。

官方说明里只声明了无障碍用于绘制准星，是否长期开着由你自己决定。

## 五、广告多、内容不合适

应用免费、内含广告，评论里也有用户提到广告体验问题。可用的缓解办法：开启飞行模式后使用（它画准星不需要联网，但部分广告加载也会失败）、或在系统里限制它的网络权限。注意断网后应用内某些在线素材可能加载不出来，本地已保存的准星不受影响。

## 六、担心用了被游戏封

这是个独立问题，两层答案（工具原理 / 游戏规则）与判断方法都拆在[用了会被封号吗.md](用了会被封号吗.md) 里，这里不重复。

## 七、网盘里是 v1.1.7，商店显示的却是别的版本

不是你下错了。网盘那份固定停在 **v1.1.7**（4.80M），官方版本记录里这一版是一次小幅 bug 修复，之后商店又发过更新的版本。两个版本号对不上完全正常——想确认手里这版的版本号、包名、MD5，对照[下载与安装教程.md](下载与安装教程.md) 第一节的表格；想换版本，重新打开 [Aim Helper 安装文件资源（夸克网盘）](https://pan.quark.cn/s/df1bb7ae854a) 取包即可。
