## 一、打开是白屏、加载转圈不停

GitMind 的保存与协作都在云端，官方明确说明不支持离线使用。白屏或一直加载，先按网络问题处理：

1. 确认手机能正常打开网页，网络本身没断；
2. 切换 Wi-Fi 和流量再试；
3. 杀掉 App 重新打开。

网络正常仍白屏的，可能是服务端临时故障，隔一段时间再试，不要反复卸载重装——文件在云端账号里，跟装不装没关系。

## 二、登录不上或收不到验证码

- **第三方登录转圈失败**：Google、Facebook 登录需要相应的网络环境，条件不具备时换**邮箱注册**最省事；
- **邮箱验证码收不到**：查垃圾邮件文件夹；还不行就换一个邮箱重新注册；
- **换绑邮箱**：登录后点头像进「我的账户」，在「用户资料」里可以改邮箱；
- **想删号重来**：手机端在底栏「我的」→「设置」→「删除账号」。账号数据在手机和电脑端是同一份，任一端删除即可，不用两端都删。

## 三、画图时的操作问题

| 状况 | 处理 |
| --- | --- |
| 节点里文字想手动换行 | 点键盘上方的换行键；蓝牙键盘用 `Shift + Enter` |
| 删了父节点，子节点跟着没了？ | 不会。删除节点后，子节点自动上移一级挂到上一层级 |
| 连接线颜色、节点形状想改 | 选中节点 → 样式图标，改形状、边框、线条颜色 |
| 想换整张图配色 | 右上角魔法棒图标一键换主题；背景可在样式里换或自定义上传图片 |
| 概要加错了 | 选中概要，按删除键即可；覆盖范围拖概要边上的黄色边框调整 |
| 图片插不进去 | 免费版每张图只能插 2 张图片，先数数已插几张 |
| 图片位置、大小想调 | 选中后拖拽；点图片可查看或删除 |
| 粘贴内容乱了 | 复制后选中目标节点按粘贴；也可以整枝复制一个分支 |
| 免费版建满 3 个文档，旧的还能改吗 | 能。官方说明建满后只是不能再新建或保存新文档，已建的 3 个文档仍然可以编辑 |
| 买了激活码 / 兑换码在哪输 | 登录后点头像进「我的账户」→「设置」→「激活码」，输入后激活对应的会员时长或额度 |
| 从 XMind 等旧工具换过来的导图怎么搬 | 用导入功能，支持 xmind、FreeMind、Markdown 等格式，步骤见[怎么导入和迁移旧导图.md](怎么导入和迁移旧导图.md) |

节点数到 60 加不动的，不是故障，是免费版单图上限，对照[免费版和会员版区别.md](免费版和会员版区别.md)。

## 四、文件找不回

- **误删的导图**：底栏「我的」→ 进回收站恢复。免费版回收站保留 7 天，过期清空；会员不限时长；
- **改坏了想退回旧版**：免费版有 7 天版本历史，会员 30 天，在文件的历史版本里回退；
- **换手机后文件不见了**：登录的是不是同一个账号？GitMind 文件全部存云端，同一账号登录旧文件自动出现。

## 五、导出与分享问题

- 导出菜单里找不到高清或 PDF：免费账号没有这两项，见[怎么导出和分享.md](怎么导出和分享.md)；
- 图片导出发糊：免费只有标准清晰度；会员在电脑端用高清导出、渲染比例调到 400%；
- 对方打不开分享链接：确认权限设置里给了对方「查看」以上权限，设了密码的要把密码一起告诉对方。

装不上、安装报错的，回到[下载与安装教程.md](下载与安装教程.md)对一遍步骤。
