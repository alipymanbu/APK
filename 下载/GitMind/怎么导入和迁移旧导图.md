## 一、能导入哪些格式

按官方教程与 2026 年更新日志（网页版），截至 2026-09 支持导入的格式包括：

| 来源 | 格式 |
| --- | --- |
| GitMind 自己的文件 | `.gmind` |
| XMind | `.xmind` 工作簿 |
| FreeMind | FreeMind 格式 |
| MindMaster / EdrawMax | MindMaster 格式 |
| MindManager、MindMeister | 各自的导出格式 |
| 纯文本类 | Markdown、OPML、HTML |
| 流程图 | Visio（导入后转成可编辑的流程图，也能再导出为 Visio） |

从 XMind、MindMaster 这类工具换过来的旧图，大概率能直接搬进来，不用重画。个别版本格式互不认的，先在原软件里另存为上面的通用格式再导。

## 二、导入步骤（以网页版为准）

1. 登录后进「我的文件」（我的想法）页面；
2. 找到「本地导入」（导入本地文件）选项——在「更多」菜单里；
3. 选择本地文件直接添加，或把文件拖进窗口；
4. Markdown 文件导入后会自动生成一张导图。

手机 App 界面以你设备上实际显示的入口为准；网页版能力最全，找不到导入入口时优先去网页版操作。

## 三、导入之后的整理

- **拆分**：一张大图想拆成两张，打开导图后选中要拆出去的分支，右键选「分解」，该分支自动生成一张新导图；
- **合并**：在一张导图的空白处右键选「引入心智图」（插入导图），选中要并进来的文件，把内容拖到目标节点下；
- **移动层级**：拖 A 节点到 B 节点上，A 变成 B 的子节点；外接键盘可用 `Alt + ↑/↓` 上下调整节点位置。

导入只是把结构搬进来，样式（主题、配色）要重新套：在编辑页右上角用魔棒图标换主题即可。节点怎么改、快捷键有哪些，见[怎么新建和编辑思维导图.md](怎么新建和编辑思维导图.md)；搬进来之后要导出或发给别人，流程在[怎么导出和分享.md](怎么导出和分享.md)。

注意导入的图和手画的图一样计入账户额度：免费账号总共 3 个文件、单张 60 节点，图多的话先看[是什么与适合谁用.md](是什么与适合谁用.md)里的额度说明再决定搬几张。
