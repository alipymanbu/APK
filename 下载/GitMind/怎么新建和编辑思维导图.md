## 一、新建一张导图

1. 打开 App 登录后进到文件首页；
2. 点右下角橙色的「+」按钮，新建一张空白导图；
3. 想套模板的，点底部的「模板」标签，选一个点进去，右下角点「编辑」就能在这份模板上改内容。

手机、网页、电脑客户端的操作入口一致：都是先登录、再新建。以下步骤以手机触屏操作为准。

## 二、加节点、改文字

点选一个节点（新建的图里就是中心主题），节点旁边会浮出一排按钮：

| 按钮 | 作用 |
| --- | --- |
| 编辑 | 修改节点文字 |
| 子节点 | 在它下面加一级分支 |
| 兄弟节点 | 在同级加一个节点 |
| 格式 | 改样式（见第四节） |
| 删除 | 删掉这个节点 |

- **移动节点**：按住节点拖到新位置松手；把节点 A 拖到节点 B 上，A 会变成 B 的子节点——这是调整层级最快的方式。
- **换行**：节点文字到一定宽度会自动换行；想手动断行，点键盘上方的换行键。外接蓝牙键盘时用 `Shift + Enter` 或 `Ctrl + Enter`。
- **撤销**：蓝牙键盘 `Ctrl / Cmd + Z`。
- **更多键盘操作**（网页版与外接键盘）：`Shift + Tab` 给选中节点补一个上级节点；`Alt + ↑ / ↓` 把节点上移或下移；`Tab` 加子节点、`Enter` 加同级节点。

## 三、大纲模式：不想拖节点就打字

编辑页可以一键切换大纲视图和导图视图。大纲模式下你逐行输入文字、用缩进表示层级，系统自动转成导图；画完想快速改文字也可以切回大纲。嫌手机上拖节点麻烦的，优先用这个模式。

## 四、改样式

选中节点后点「格式」，可以设置加粗、下划线、删除线、字号、字体、背景色，电脑版还能调对齐方式与行距。整体风格不用逐个节点调：

- **换主题**：编辑页右上角的魔法棒（魔棒）图标，一键换整套配色与样式；
- **改背景**：在样式里选「背景」，自带若干选项；没有满意的，主题设置里的背景支持自定义上传你自己的图片；
- **改连接线**：选中节点后点样式图标，可以改线条颜色、节点形状和边框；
- **插图标**：选中节点点「+」，从图标库里插入；
- **插本地图片**：选中节点，点浮动工具栏里的图片图标，从手机相册选图；插入后点图片可查看或删除，拖拽可调位置与大小；
- **调节点宽度**：选中节点拖动左右边框；电脑版还能框选多个同级节点批量统一宽度，版面更整齐；
- **给节点加附件**（会员功能，网页版）：每个节点最多挂 10 个文件，支持 PDF、Word、Excel、PPT、TXT、CSV 等格式，附件会全平台同步。

## 五、关系线、概要与评论

这三样是整理复杂导图时常用的：

- **关系线**：在两个节点之间补一条连线表达关联，加好后拖动两端可以调整起止位置；
- **概要**：选中相邻的多个节点，点工具栏「概要」，会给它们加一个括起来的汇总框；拖动概要边上的黄色边框调整覆盖范围；选中概要按删除键可删掉；
- **评论**：选中节点点评论图标就能留言；你把文件通过链接分享出去后，打开链接的人也可以在节点上评论，协作讨论不用切到聊天工具。

## 六、AI 生成初稿

编辑页右下角有 GitMind AI 入口：在对话框里输入你的问题或主题，它给出回答后点回答下方的「复制」，一键把内容插入导图，再手动整理。适合「只有一个题目、不知道从哪拆起」的情况。AI 消耗账户里的算粒，免费账户与各会员档的额度不同，以你登录后账户内显示为准。

## 七、管理文件

- **搜索**：首页顶部的搜索框按文件名找；
- **重命名 / 复制 / 移动 / 删除**：首页里把文件往左滑，点「…」，菜单里有分享、重命名、复制、移动、删除、多选；
- **找回删掉的**：底部「我的」进回收站恢复。免费版回收站保留 7 天，过期就找不回来了，会员版不限时长——删除前想清楚，或者先看[免费版和会员版区别.md](免费版和会员版区别.md)。

画完之后怎么存成图片发给别人，见[怎么导出和分享.md](怎么导出和分享.md)；对这张图能有多少节点、建多少文件有疑问的，也在这篇里有数字对照。
