## 一、这份安装包的基本信息

你拿到手的这份安装包是安卓客户端，关键信息如下（以安装包本身为准，网上各渠道的版本信息可能不一样）：

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.0 |
| 安装包大小 | 约 1.13 MB |
| 包名 | `com.liblib.java800.com` |
| MD5 | `B2628AF1444AE1F3311899D38F4037A5` |

三点提醒：

- 1.13 MB 属于很小的安装包，说明这是个轻量客户端，对手机配置几乎没要求；它的作用是帮你更快进入 LiblibAI 平台。
- 平台的主要创作能力（生图、模型库、在线训练）在网页端 `https://www.liblib.art` 上是完整版；装不装客户端、装哪一版，不影响你注册和使用同一个平台账号。
- 官方 App 下载页（[https://www.liblib.art/app/download](https://www.liblib.art/app/download)）提供的安卓客户端体积大得多、版本号也不同——那是另一份安装文件，两份包认准你要装的那份即可，别混着装。

## 二、下载与安装步骤

1. 把上面「LibLibAI 安装文件资源」里的安装文件先转存到自己的夸克网盘，再从网盘下载到手机。
2. 在手机的文件管理器里找到这个 `.apk` 文件，点它开始安装。
3. 第一次安装非应用商店来源的包时，系统会拦一道，提示"禁止安装未知来源应用"。按提示把对应来源（一般是"文件管理"或浏览器）的"允许安装未知应用"开关打开，再回文件管理器继续装。
4. 装完点打开。首次启动如果弹权限申请（网络、存储之类），按需允许即可。

几个常见品牌的拦截提示与处理：

| 常见提示 | 处理思路 |
| --- | --- |
| 华为/荣耀 "该应用存在风险" | 选择"继续安装"，或在纯净模式/更多安全设置里放行 |
| 小米 "高危应用" | 安装页按提示验证后选"继续安装" |
| OPPO/vivo "来源未经验证" | 勾选"我已知晓风险"后继续 |

不同系统版本的措辞有差异，以你手机当时弹出的提示为准。

## 三、装好之后怎么进

- 打开客户端，按界面提示注册或登录平台账号；登录后你账号里的积分、会员状态就是平台侧的那一份（积分怎么花见 [会员与积分怎么算.md](会员与积分怎么算.md)）。
- 网页端登录同一账号即可；日常出图用手机客户端，重活去网页端。
- 不想装客户端也可以"把网页当 App 用"：手机浏览器打开官网后，在浏览器菜单里选"添加到主屏幕"，之后从桌面图标进入，体验接近原生应用。
- 如果你更习惯用浏览器：直接访问 `https://www.liblib.art` 注册登录就行，本篇的安装步骤可以整个跳过。

## 四、装不上或打不开

安装中断、打不开、登录没反应这类情况，多数与手机系统的来源限制或网络有关，逐项排查的思路写在 [常见问题与注意事项.md](常见问题与注意事项.md)。
