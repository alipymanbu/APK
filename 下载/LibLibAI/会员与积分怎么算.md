## 一、什么操作会扣积分

生图、生视频、图像编辑、在线训练这类算力操作都按积分扣，消耗量随模型和参数浮动：张数翻倍扣得翻倍，视频类模型的单次消耗明显高于普通图片，训练一次 LoRA 的开销又远高于一次生图（训练本身要花多少，见 [LoRA在线训练怎么做.md](LoRA在线训练怎么做.md)）。生成前在界面上能看到当次预计消耗（以界面实际显示为准）——先看一眼再点生成，是控制积分最快的习惯。

## 二、免费部分

- 每日登录有赠送积分（截至 2026-09 官方会员页标注为每天 20 积分，后续可能调整，以官方页面为准）。
- 免费账号另有 3GB 云端存储空间（同样截至 2026-09 的官方口径）；订阅会员的月度积分按 31 天周期重置，当期不用完就作废。
- 免费积分够轻量试玩：小尺寸、少张数的图片生成本身消耗不高；重活（大图、视频、训练）基本要靠充值或订阅。
- 你手头这份安装包只是个安装文件，本身不带任何会员或赠送积分，账号里有什么全看平台侧。

## 三、会员档位差在哪

会员分创作会员与团队会员两条线，创作会员按年/季/月订阅，档位从入门到至尊，档与档之间主要差五件事：

| 维度 | 低档 | 高档 |
| --- | --- | --- |
| 每月积分 | 数百级 | 数万级 |
| 并发任务 | 少，排队明显 | 多 |
| 云端存储 | 数十 GB | 上百 GB |
| 排队与加速 | 正常队列 | 会员加速通道 |
| 品牌水印 | 有 | 去除（对商用出图重要） |

价格与积分比例的官方活动很频繁（连续包年/季/月折扣、限时活动价），**具体价格与档位内容一律以官方会员页当时显示为准**，本篇不落死数字。

## 四、别充错积分体系

LiblibAI 有两套互不相通的积分：你在网页或客户端里出图用的创作积分，以及调用 API 接口才用的 API 积分。官方 FAQ 明确写了两者不通用。你只是自己出图，充创作侧就够了；搞开发对接才碰 API 侧。充错了需要找客服处理，先对准再付款。

## 五、控制消耗的几个习惯

- 先用低张数、小画幅试构图，满意了再上高参数出成品。
- 视频、训练这类高消耗操作，脚本与素材想清楚再跑，避免反复重试白扣分。
- 排队说明并发额度用完了：偶尔用一次，等一等比开会员划算；天天出图才值得算订阅的账。
- 积分扣了但没出图的处理方式，见 [常见问题与注意事项.md](常见问题与注意事项.md)。
