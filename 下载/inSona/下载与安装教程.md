## 一、先确认你手里的是哪一份包

网盘里放的是安卓安装包（`.apk`）。装之前先对一遍下表，几项都能对上，说明你拿到的是这一份，后面的步骤才适用。

| 项目 | 内容 |
| --- | --- |
| 应用名 | inSona |
| 开发者 | 江苏英索纳通信科技有限公司 |
| 包名 | com.pairlink.insona.bluebee |
| 版本 | 1.8.9 |
| 安装包大小 | 74.32 MB |
| MD5 | 37B15A6FE743ED4ABAD1228C06A8FC62 |

三点要留意：

- **这里的版本号说的是这一份包**。官方渠道的版本会随更新变化（截至本文档核对时，腾讯应用宝上 inSona 的版本号同样是 1.8.9，页面标注的更新时间为 2026.1.14；商店随时会更新，以你当页看到的为准）。所以后文出现的版本号、包名、体积，一律按上表理解，别拿商店页的数字来对。
- **包名 `com.pairlink.insona.bluebee` 是它和别的 App 的分界线**。手机里同时装着别的智能家居 App 是正常的，彼此独立、不会互相替代，清理手机时别只看图标相似就删错。
- **这是「一整套系统一个 App」的那一个**，不是某盏灯、某个面板的专用工具。官方知识库把 App 分成「调试版本」和「个人家庭版本」两套入口，账号也分成经销商调试账号与个人账号 —— 你手上这个包装上之后用哪种身份登录，取决于你要做什么，见 [账号注册与家庭权限设置.md](账号注册与家庭权限设置.md)。

## 二、系统要求与装之前要确认的事

- **系统版本**：官方知识库写明手机端支持 iPhone / Android 两个平台。**这一份是安卓包**，苹果设备装不了，iOS 要走 App Store。
- **安卓版本**：这一份安装包的信息页标注的是「需要支持安卓系统 5.2 以上」。安卓并没有 5.2 这个正式版本号，稳妥起见**按 Android 5 以上准备**；手机系统还停在 Android 4.x 的，先别折腾。
- **存储空间**：安装包 74.32 MB，装完占用会更大，留出 200 MB 以上比较省事。
- **安装权限**：因为不是从应用商店装，需要先允许「安装未知应用」（部分系统叫「未知来源」）。这个开关是给**你用来打开安装包的那个应用**（文件管理器或浏览器）的，不是给 inSona 的。装完之后可以关回去。
- **蓝牙与定位权限**：不在这一步给。它们要到你在 App 里搜设备、加设备的时候才用得上，而且**必须给**，否则扫描列表多半是空的，见 [添加设备与配网入网.md](添加设备与配网入网.md)。
- **硬件前提**：inSona 是控制端，被控的是 inSona 自己的蓝牙设备（驱动电源、面板、窗帘电机、传感器等）。**家里没有这些设备的话，App 装上也只能看个界面**，能完成的操作很有限。

## 三、安装步骤

1. 打开 [inSona 安装文件资源（夸克网盘）](https://pan.quark.cn/s/77491809f54c)，把安装包转存到自己网盘后再下载到手机，也可以直接在手机上打开这条链接下载。
2. 下载完的文件后缀是 `.apk`。用手机自带的文件管理器在「下载」目录里找到它，点一下开始安装。
3. 如果弹出「出于安全考虑，已禁止安装未知来源的应用」，点提示里的设置入口，把当前这个文件管理器的开关打开，返回后重新点安装。
4. 装完桌面出现图标即成功。图标点不开、或者装到一半报错，看第五节。

## 四、装上之后核对一下 MD5

网盘下载的安装包，花半分钟核一下校验值，能直接排除「下载断流导致装不上」这类问题。把手机里的包拷到电脑上，或者直接用电脑下载一份，然后执行（文件名以你实际下载到的为准）：

```powershell
certutil -hashfile "D:\Downloads\insona_v1.8.9.apk" MD5
```

算出来的 32 位十六进制串应该与 `37B15A6FE743ED4ABAD1228C06A8FC62` 完全一致；不一致就删掉重新下载一次。手机上也可以用支持查看文件哈希的文件管理器核对。

## 五、装不上、打不开怎么办

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现错误」 | 安装包下载不完整 | 删掉重新下载，下完先按第四节核 MD5 |
| 提示「应用未安装」 | 手机里已有同包名但签名不同的 inSona | 先卸载原来的再装；卸载前确认不需要保留 App 内的家庭与设备配置 |
| 点了安装没有反应、不弹安装界面 | 没给「安装未知应用」权限 | 按第三节第 3 步开权限后重试 |
| 装上了一打开就闪退 | 系统版本过低，或系统对新装的包不兼容 | 换一台系统版本较新的手机试；也可以改用官方渠道的当前版本 |
| 装完打开是空白页、一直转圈 | 多半是账号或权限问题，不是安装问题 | 见 [常见问题与排查.md](常见问题与排查.md) |

装好之后的下一步是处理账号：如果整套系统是别人（经销商、集成商）给你调试的，你要的是个人账号；如果要自己从头建一套，才需要调试账号。两种角色的差别见 [账号注册与家庭权限设置.md](账号注册与家庭权限设置.md)。
