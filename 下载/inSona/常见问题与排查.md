# inSona 常见问题与排查

> 把 inSona 用起来之后会碰到的问题，其实集中在几个固定位置：装包、账号权限、蓝牙扫描、设备入网、第三方平台同步。这一篇按「先分是哪一类」的顺序排，每个现象都给到能动手的一步。

## 一、先定性：问题在哪一层

inSona 的故障看着都像「点了没反应」，但分层很清楚。按下面顺序问自己，命中哪一层就跳到对应小节：

1. **App 装不上、打不开** → 第三节
2. **装好了但登录后没有家庭、看不到设备** → 第四节
3. **有家庭，但扫不到设备、加不上** → 第五节
4. **设备在列表里，但控制不灵、时好时坏** → 第六节
5. **语音音箱、HomeKit 里的设备和 App 不一致** → 第七节

**别跨层乱试**。最常见的时间浪费，是账号权限没给够却在反复重置设备。

## 二、总览表

| 现象 | 最可能的原因 | 先做这一步 |
| --- | --- | --- |
| 提示「解析包时出现错误」 | 安装包下载不完整 | 重新下载并核对 MD5 |
| 登录后显示「暂无家庭」 | 账号不是创建者、也没被移交 | 走家庭移交或让管理员加成员 |
| App 里到处是灰的、建不了家庭 | 用的是个人账号 | 创建家庭需要调试账号权限 |
| 扫描列表空的 | 定位 / 蓝牙权限没给，或人离设备太远 | 开权限，走到设备旁边 |
| 设备反复加不上 | 它已经入过别的网络 | 用 Mesh Scan 清出来（仅安卓） |
| 灯在闪、以为坏了 | 正常现象 | 那是它在等待配网 |
| 语音平台里不显示对接账号 | 登录的是调试账号 | 换个人用户账号查看 |
| 米家里看不到灯 | 平台限制 | 直接用语音控制验证 |
| HomeKit 一直转圈 | 平台侧顺序同步 | 等 2~10 分钟 |
| 停电来电后满屋子灯自己亮 | 设备默认回到断电前的状态 | 离家前先把灯关掉 |
| 感应器白天不触发 | 环境照度高于阈值 | 调高阈值或取消亮暗检测 |

## 三、装包与启动

- **解析包错误 / 应用未安装 / 点了没反应**：三种现象的成因和处理见 [下载与安装教程.md](下载与安装教程.md) 的故障表。核心两步是**重新下载安装包**（下载地址：[inSona 安装文件资源（夸克网盘）](https://pan.quark.cn/s/77491809f54c)）和**核对 MD5 是否为 `37B15A6FE743ED4ABAD1228C06A8FC62`**。
- **装完打开是空白页或一直转圈**：这已经不是安装问题了。按第一节的分层，先去第四节确认账号与家庭。
- **换手机之后要不要重装、配置会不会丢**：官方说明设备配置数据由设备自身本地存储、不依赖云端，所以换手机后**用原来的账号登录**（个人账号）就能看到移交给你的家庭与设备。注意是「用原来的账号」，重新注册一个新账号是不会自动带上原来那套的。

## 四、账号、家庭与权限

这一层的问题，完整版在 [账号注册与家庭权限设置.md](账号注册与家庭权限设置.md)，这里只列三步定性：

1. **登录的是什么账号**？经销商调试账号能创建家庭、能配置设备；个人账号只能使用已经移交给你的家庭。
2. **显示「暂无家庭」**？说明这个账号当前不在任何家庭里，多半是被移出了。个人账号自己加不回去，需要管理员重新授权，或让调试账号重新走一次移交。
3. **搜不到家庭**？调试账号按官方三条排查（定位+蓝牙授权 → 「我」-「临时访问」-「本地登录」 → 「辅助功能」-「项目管理」-搜索家庭名称）；个人账号则确认蓝牙授权，并确认家庭确实移交过。

## 五、设备扫描与入网

这是提问最多的一层，官方文档给的排查手段也最多：

1. **权限**：手机定位与蓝牙都要开启并授权给 inSona App。这一条官方放在家庭与设备问题的第一条位置。
2. **距离**：蓝牙是近场通信，站在设备旁边再扫。隔墙、隔金属柜都会明显缩短能扫到的范围。
3. **设备是否处在可配网状态**：只有刚上电或刚重置的设备才会被扫出来。各类设备怎么进这个状态、怎么重置，见 [添加设备与配网入网.md](添加设备与配网入网.md) 的两张表。
4. **设备是不是已经入过网**：「我」→「设置」→「Mesh Scan」→ 找到 **ID 和 Num 不一样**的设备 → 长按重置。**这一步仅限安卓手机**，iOS 做不了。
5. **扫码兜底**：电源、窗帘电机、存在式感应器都支持扫描设备二维码完成添加或重置，实体重置按键找不到时用它。

一个必须记住的正常现象：**灯的输出端呈呼吸闪烁，是设备在等你添加，不是坏了**。看到灯闪就去断电，等于把它从配网状态里赶出来。

## 六、设备在列表里但控制不灵

- **时好时坏**：先看是不是距离或遮挡变化导致的。官方在产品注意事项里反复提醒，不要把设备装在四周都是金属的封闭环境里。
- **完全点不动**：先确认手机蓝牙开着、App 有定位权限，再把手机拿到设备旁边试一次，区分是手机侧还是设备侧。
- **设备指示灯不对**：官方手册提示，设备无法连接时首先要查供电，正常启动会有对应的指示灯表现（网关是红绿蓝交替呼吸）。具体设备的指示灯含义要看该产品的数据手册。
- **窗帘动作不对、开合不到位**：多半是行程问题。重新配行程或清除行程的方式见 [灯光窗帘与面板怎么调.md](灯光窗帘与面板怎么调.md)。
- **墙上面板按了没反应**：面板按键是绑定的，绑了才有功能。绑定方式见 [房间分组与场景设置.md](房间分组与场景设置.md)。
- **场景执行结果和预期不一样**：场景记的是你建它时调好的状态。设备换了房间、亮度被改过之后，回去把场景重调一遍。
- **感应器白天不开灯、或者没人也亮**：这两种相反的现象各有成因 —— 白天不触发多半是环境照度高于阈值，没人也亮则常是微波穿透玻璃或木板把隔壁的人也算了进来。官方手册给了逐条对照的成因与处理，见 [感应器怎么布点与调试.md](感应器怎么布点与调试.md)。
- **停电恢复后灯自己亮了**：这是灯具的默认上电行为（回到断电前的状态），不是故障。不想出现这种情况，长时间离家前先把灯关掉再断总闸；想改默认配置见 [灯光窗帘与面板怎么调.md](灯光窗帘与面板怎么调.md)。

## 七、第三方平台与语音

- **平台里看不到对接账号**：先确认登录的是个人用户账号，不是调试账号 —— 官方在两个平台的说明里都把这条列为首因。
- **米家 App 里没有灯的卡片**：这是平台限制，不是没接上。云云对接的设备在米家里只走小爱音箱的语音控制。
- **同步列表里没有蓝牙设备**：查网关是否在线、是否正常联网、固件是否为最新版本。
- **语音说了没反应，但手动能控**：这是语音识别的问题，不是对接的问题。把设备名称改简单一些，识别率会明显好转。
- **HomeKit 同步转圈**：官方说明受 Apple 平台侧限制，一般 2~10 分钟，耐心等，别反复重启。

以上都试过还控不了，那就回到第二节点一遍是哪一层 —— 大多数「查不出原因」的个例，最后都落在「账号身份不对」或「权限没给」这两件事上。
