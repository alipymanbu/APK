# inSona 房间分组与场景设置

> 设备都加进来之后，最花时间也最影响日常体验的，是把它们按房间理清、把常用的几个动作固化成能一键执行的场景。这一篇讲房间怎么建和怎么批量搬、设备组和场景的区别、动态场景的循环怎么选，以及面板按键怎么绑上去。

## 一、房间：先建结构，再挪设备

### 1.1 创建与整理房间

- **新建房间**：选择一个默认房间 → 房间管理 → 添加房间 → 输入房间名称 → 确定。
- **重命名 / 删除 / 排序**：选择房间 → 房间管理 → 长按要改的房间，出现「重命名 / 删除 / 排序」三个动作。

排序值得现在就顺手做一次：设备装完可能有一二十个房间，之后每次控制都要先找到房间，顺序乱了就是每天都难受。

### 1.2 把设备放进对的房间

- **单个设备**：长按设备名称 →「编辑」→ 设备属性编辑页 → 选择房间（或直接输入新建的房间名）→ 保存配置。
- **批量挪**：进入设备页面（如灯光页面）→ 点顶部房间名称 →「房间管理」→ 进入目标房间 → 选中要挪进来的设备 → 确认保存。例如把一批设备从「客厅」挪到「卧室」，就是先选「卧室」房间进去，再勾设备。

### 1.3 家庭本身也能改

家庭名称可以改、家庭也可以删除：选该家庭 → 家庭管理 → 更改名称 / 删除家庭。删除家庭是重手操作，确认这套系统不再需要由这个账号管理时再做。

## 二、设备组：让一批设备「听同一个指令」

创建群组设备的做法，是把多个单设备组合起来做群控。现实里的用法是：客厅三盏筒灯永远一起开关、或者一整排灯带要同步调亮度，做成组之后一次操作搞定，不用进场景也能直接群控。

解散也简单：长按群组 → 删除；或者长按群组 → 编辑 → 取消配件编组 —— 后者只解散组，设备本身还在。

**组和场景别混用**：

| | 设备组 | 场景 |
| --- | --- | --- |
| 干什么 | 把一批设备当一个来操作 | 记住一批设备「当时的状态」，一键还原 |
| 典型用法 | 客厅六盏射灯一起调亮度 | 「回家」开灯 + 关窗帘 + 开空调 |
| 含不含窗帘、空调 | 以组内绑定的设备类型为准 | 可以混着来 |

## 三、一键执行场景：最常用的那一种

官方知识库给的创建步骤：

1. 添加场景 → 输入场景名称 → 选择场景所在房间 → 选择灯光 / 窗帘 / 空调设备 → 点设备调出你想要的状态 → 完成。

关键在最后两步：**场景记录的是「你调好的那个状态」**，不是固定动作。所以建场景时要在 App 里把亮度、色温、窗帘开合这些都调到位，再点完成。

编辑和删除：选择「我的情景」→ 长按需要编辑或删除的场景 → 添加/删除 → 完成。

场景挂在哪个房间也有讲究：**它的显示位置跟「场景所在房间」走**。把「观影」挂在客厅、把「起床」挂在卧室，日常才找得到。

## 四、动态场景：会自己变化的场景

一键执行场景是「一步到位」，动态场景是「按节奏变化」。例如灯光在 30 秒里缓慢从暖黄过渡到暖白，就是它的用武之地。

1. 「我的情景」→ 添加情景（动态场景）→ 输入动态名称。
2. **选择循环方式**：一直循环 / 循环 1 次 / 自定义循环。三个选项对应三种完全不同的行为 —— 演示氛围用「一直循环」，一次性过渡用「循环 1 次」，有明确时长的用「自定义循环」。
3. 模式选择。
4. 模式选完之后还要**添加设备状态**（官方文档举的例子是「场景融合」），这一步不做，场景是空的。
5. 完成。

编辑或删除：长按场景 → 编辑 / 删除。

## 五、把场景挂到墙上的面板按键

面板买回来时按键是空的，要自己绑功能。做法是点面板界面里的数字，进入单个按键的编辑界面。

官方文档给了两个例子，正好代表了两种最实用的绑法：

- **按键 1 绑「开关切换」**：可以绑灯光设备，也可以绑窗帘，实现按一下开、再按一下关的效果。**注意一个限制：这个按键绑了灯光，就不能再绑窗帘** —— 一个按键只服务一类对象。
- **按键 2 绑「情景模式」**：情景模式里可以选一键执行场景，也可以选动态场景。

也就是说，家里的墙面面板不需要为每个灯做一个物理按键，靠「按键 + 场景」这两层就可以把常用的几个动作全放上去。面板本身的界面说明见 [灯光窗帘与面板怎么调.md](灯光窗帘与面板怎么调.md)。

## 六、什么该做成场景，什么不该

不是所有操作都值得做成场景。建场景有维护成本：房间一改、设备一挪，场景就可能要重新调。

- **值得做**：每天都会用、且要同时动好几个设备的动作（回家、观影、睡前、离家、起床）。
- **不值得做**：单独开关某一盏灯、只调一个窗帘 —— 这些直接在对应房间里点更快，做成场景反而多一层跳转。

场景数量控制在十个以内，面板上也放得下，家里其他人也记得住。
