## 一、什么情况下需要开这些权限

AionClaw 手机端有两种干活方式：一是你发指令、电脑端执行（不需要动手机系统权限）；二是让它在手机上直接执行自动化操作——翻聊天记录整理素材、跨应用取数据、抓浏览器里的内容。第二种方式下，安卓系统要求它拿到相应授权才能「替你点、替你划」，否则它只能和你聊天。

给权限之前值得知道的一层背景：科技媒体在报道这类「能直接操作设备」的 AI 工具时，整理过用户的真实翻车反馈——误删文件、把隐私内容发到不该发的地方、任务空转烧额度。授权不改变工具本身的意图，但决定了翻车时的波及面。所以下面这些权限，建议按「当前真的要用的功能」逐项给，别一次性全开。

## 二、开启无障碍服务（四步）

不同品牌的安卓机，设置入口名字略有差异（华为/荣耀常叫「智能辅助」，小米/vivo/OPPO 多叫「辅助功能」），路径大同小异：

1. 打开手机【设置】，找到【辅助功能】或【智能辅助】；
2. 进入【无障碍】，往下找到 AionClaw（部分版本显示为「AI 龙虾」相关的服务名）；
3. 打开右侧开关；
4. 弹出风险提示时点【确定】或【允许】完成授权。

全程不需要 root 或开发者模式。开完无障碍，它才能读屏幕内容、模拟点击滑动，去完成跨应用的操作类任务。

## 三、还要检查的两项

- **悬浮窗权限（显示在其他应用上层）**：用于在别的应用上面弹出操作窗、实时响应指令。路径：【设置】→【应用管理】→【AionClaw】→【权限】→ 开启「显示在其他应用上方」；
- **自启动 / 后台运行**：保证 App 不被系统清理，定时任务（比如每天早上推一份简报）才能准时跑。同一权限页里开启「自启动」；小米等品牌还要在省电策略里把 AionClaw 设为「无限制」或允许后台运行。

## 四、App 内的快捷入口

懒得在系统设置里翻找的话，打开 App，进【我的】→【设置】，里面有权限相关的引导项，点「立即开启」会直接跳到对应的系统设置页。用这个入口能避免「机型不同找不到设置项」的问题。

## 五、App 本身申请的权限清单

应用商店里公示的 AionClaw 权限如下，你可以对照判断哪些该给：

| 权限 | 用途 |
| --- | --- |
| 查看网络状态 / 完全的互联网访问 | 与服务端通信、任务下发与结果回传 |
| 读取文件与文档 / 写入文件与文档 | 读写你交给它处理的文件、保存产出 |
| 拍摄照片和视频 | 按任务需要拍摄素材 |
| 录音 | 语音下达指令 |
| 防止手机休眠 | 长任务执行期间保持运行 |

按最小够用原则给权限：只打算连电脑发指令的，网络权限给上就够；要用语音就说录音；要让它在手机上动手，才需要第二、三节里的那几项。

## 六、权限开了还是不动手

1. 无障碍服务容易被系统「悄悄」关掉（部分品牌会定期回收），去无障碍列表里确认开关还是开的；
2. 后台被杀后任务停摆，按第三节把自启动和省电策略放宽；
3. 仍未解决的话，把 App 切到前台重新发一次任务，或在 [常见问题解答.md](常见问题解答.md) 里找对应现象。
