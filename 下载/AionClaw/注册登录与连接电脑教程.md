## 一、注册与登录

按安装引导的流程，打开 App 后进入主页登录界面，选择微信登录或手机号登录，按提示完成即可。两种方式的差别主要在方便程度：

- **微信登录**：不用记密码，授权即登录，适合只想快速上手的人；
- **手机号登录**：走验证码，账号独立于微信，适合微信多号切换或不想把工作号绑进 App 的人。

登录这一步不用自己填任何模型的密钥。官方对 AionClaw 的设计是不需要用户自己配置 API key，模型由平台侧调度，这点和你自己搭开源 Agent 的用法不一样。

## 二、为什么要连电脑端

AionClaw 的实际执行主力在电脑端：浏览网页、读写文件、运行命令这些动作都发生在你的电脑上。手机端扮演的是「随身遥控器 + 结果接收器」——人在外面，对着手机说一句需求，电脑开始动工，成果送回手机。

连上之后你能做到的典型场景：

- 通勤路上把「整理这周的周报素材」说出去，到公司电脑上初稿已经好了；
- 定好的报告、监控类任务，电脑端到点自己跑，结果推到手机或工作群；
- 手机把任务发过去，人不用守在电脑前。

## 三、扫码连接电脑端的步骤

1. **电脑端先就位**：在官网 [www.aionclaw.cn](https://www.aionclaw.cn/) 下载 Windows 版或 Mac 版并安装（没有电脑端的话，这一步先做）；
2. **电脑端注册**：在电脑端完成注册——官方有「电脑端注册领体验积分」的设定，积分用于驱动任务执行；
3. **App 扫码**：打开手机端 App，找到扫码连接入口，对着电脑端显示的二维码扫一下，即完成配对；
4. **验证连通**：配对成功后，从手机端发一个简单任务（比如「在桌面新建一个 txt 写上 hello」），看电脑端是否开始动作。

扫不上时按这个顺序排查：

| 现象 | 处理 |
| --- | --- |
| 找不到扫码入口 | 确认 App 已登录；入口一般在主页或连接相关的明显位置，不同版本位置可能调整 |
| 扫码后没反应 | 确认电脑端处于运行且已登录状态；手机和电脑最好在同一网络环境 |
| 配对成功但不执行 | 检查电脑端是否被系统休眠、杀后台；笔记本别合盖睡眠 |
| 提示积分不足 | 去电脑端看体验积分到账情况，额度用完需要补充，档位见 [费用与额度说明.md](费用与额度说明.md) |

另外几条来自第三方教程整理的经验（单一来源，供参考，以你设备上的实际界面为准）：

- **手机端的登录路径可能依赖电脑端就绪**：有教程提到，电脑端没启动或没完成首次登录时，手机端即便信息输对了也可能提示「未检测到已授权设备」——先在电脑上把客户端跑起来再操作手机；
- **二维码会过期**：电脑端展示的二维码大约一分钟刷新一次，切走窗口或停留太久都会失效，提示「二维码已失效」时回到电脑端点刷新重扫即可；
- **换手机不用重新注册**：先在电脑端的设备管理里把旧设备解绑，新手机重装 App 后再扫一次码，已配好的任务配置不受影响。

## 四、不连电脑，手机端能干什么

手机端本身也能直接对话下任务，适合轻量活：问问题、整理一段文字、出个思路。但像操作电脑里的文件、跑脚本、批量抓网页这类活，只能由电脑端完成。所以「手机端只是个聊天 App」和「不用装电脑端」这两种理解都不对——它是整套系统里的移动入口。

没有合适电脑、或人在外电脑开不了机，还有一条付费路：买云主机月卡，让任务在云端主机上跑，手机端可独立运行。代价与数据落点的差别见 [费用与额度说明.md](费用与额度说明.md)。

任务怎么描述、哪些活适合交出去，见 [能交给它做什么与技能市场.md](能交给它做什么与技能市场.md)。如果电脑端执行时手机上一直没收到结果，多数是连接断了，重新扫码即可；权限没开全导致 App 后台被杀的情况，见 [权限开启与自动化授权设置.md](权限开启与自动化授权设置.md)。
