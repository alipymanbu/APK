## 一、AionClaw 和 OpenClaw 是什么关系

按官方的说法：OpenClaw 是开源社区版，AionClaw 是它的一键安装发行版，目的是让不懂技术的人零门槛用上 OpenClaw 的能力。落到使用上的差别：

| | OpenClaw（开源版） | AionClaw |
| --- | --- | --- |
| 上手方式 | 自己部署、自己配置 | 装上就用 |
| 模型 | 自己准备各家的 API key | 平台侧调度，不用自己配 key |
| 费用 | 花在模型厂商那边 | 注册送额度，按任务调用扣 |

如果你本来就是会折腾命令行的用户，直接用开源版更自由；只想「说句话让 AI 干活」，AionClaw 省掉的是部署和配 key 那一段。

## 二、和 ChatGPT、豆包这类对话工具有什么区别

官方把它与对话工具的差别概括为：对话工具停在「给建议」，它负责「把活干完交回来」。用起来的体感差别在于：普通 AI App 聊完，写文档、做表格的还是你自己；AionClaw 在你授权的范围内直接操作设备去完成，并且记着你的习惯（文档格式、称呼、常用标准），重复性工作越到后面交代得越少。

## 三、支持哪些大模型

官网展示的模型阵容包括 DeepSeek、Qwen、火山引擎、MiniMax、智谱 GLM、Kimi、小米 MiMo、文心一言、腾讯混元等国内主流模型，企业版页面还列有 Gemini、OpenAI、Anthropic（名单随时间变化，以官方页面为准）。你不需要自己选模型，官方的口径是「系统帮你选最强的」——难任务自动调用更擅长深度思考的模型。

对使用者来说，这省掉的是「测哪家模型适合我的活」这件事本身。

## 四、积分（额度）怎么算

按官方页面的说明：

- 注册即送体验积分（限时活动还有「登录即领 5000 万 Token」之类的额度，活动口径以官方页面为准）；
- **调用 AI 执行任务才扣额度**，安装技能不收钱；
- 额度用完随时补充，按实际用量计费。

具体档位、订阅口径与省额度的习惯，见 [费用与额度说明.md](费用与额度说明.md)。

## 五、数据安全吗，存在哪

官方对数据口径的说法：全程在本地设备运行，记录与配置仅存于你的设备，数据不经过外部服务器。对应到你要注意的实操边界：执行任务的电脑就是数据的落点，电脑端所在机器的安全状况（谁能动它、有没有设锁屏密码）决定了这些数据的安全状况；给它的权限越大（尤其开了无障碍之后），越应该只在自己常用的设备上开。

## 六、手机端和电脑端必须装在一起吗

不是「必须」，但「手机端 + 电脑端」才是完整用法：电脑端负责执行，手机端负责随时随地交代任务和收结果。只装手机端也能对话处理轻量活，操作文件、跑浏览器、批量处理这类活交不出去。装机与扫码配对的操作见 [注册登录与连接电脑教程.md](注册登录与连接电脑教程.md)，能交什么活见 [能交给它做什么与技能市场.md](能交给它做什么与技能市场.md)。
