# OpenLess 安卓版和电脑版有什么不一样

> 搜 OpenLess 的人常被绕晕：有的页面讲全局快捷键，有的页面讲输入法。本篇把两个形态摆在一起对照，帮你确认自己该装哪一份、手上的资料是不是你需要的。

OpenLess 有**两套客户端**：桌面版跑在 macOS / Windows / Linux 上，安卓版跑在手机上。它们出自同一个开源项目、共用同一批设计思路，但**交互形态完全不同**——桌面版是一个常驻后台、监听全局快捷键的工具，安卓版则是一个系统输入法。本篇帮你判断该装哪一份，以及两边哪些经验可以互相借用。

## 一、一句话认清两个形态

| 对比项 | 安卓版（本文附的这份） | 桌面版 |
| --- | --- | --- |
| 怎么唤起 | 切到 OpenLess 输入法后，在键盘上按住说话 | 按一个**全局快捷键**，在任何应用里都能唤起 |
| 文字怎么落位 | 由输入法把润色结果送进当前光标 | 由客户端把文本**插入到任意应用的光标处** |
| 显式入口 | 系统输入法列表 | 常驻托盘图标，以及一个跟随当前显示器的迷你状态胶囊 |
| 平台 | 安卓 | macOS 12+、Windows 10+；Linux 另有一套原生界面 |
| 获取渠道 | 官方发布页的 APK（网盘里也有一份，见文首入口） | 官网 [openless.top](https://openless.top/) 与代码仓库发布页的安装包 |

安卓版由项目里专门的安卓维护者负责，桌面版的打包与签名是另一条线，但**两者发布在同一个官方 Release 页上、共用同一个版本号**——比如 `v1.3.18` 这一版里，既有 macOS 的 DMG、Windows 的 EXE，也有各个架构的安卓 APK。所以按版本号找包时，认准这个编号即可。

## 二、哪些能力是两边都有的

下面这些是项目层面共有、两端都实现了的，不必担心安卓版是「缩水版」：

- **四种输出模式**：原文、轻度润色、结构化（也就是 AI Prompt 模式）、正式；
- **风格包**与风格包市场：可以新建自定义风格、切换当前生效的风格，也能从市场安装别人分享的；
- **词典热词**：专有名词、人名、产品名、术语可以加进词典，识别与润色两个环节都会用到；
- **插入失败回退剪贴板**：目标应用不接受直接写入时，结果会被复制到剪贴板，你说过的话不会丢；
- **本地优先**：音频、转写、词典、历史存在你自己的设备上；
- **自带凭据**：识别与润色都走你自己申请的云服务凭据，不绑定特定供应商；
- **开源**：代码以 MIT 协议公开。

## 三、哪些细节是端上特有的

**桌面版独有、安卓版没有的**，典型是这几类，看官方资料时别对号入座：

- **全局快捷键与线控触发**——桌面版可以设 Caps Lock、鼠标侧键之类的全局热键，还支持有线耳机的线控按键起停录音；安卓版是输入法形态，唤起方式跟随输入法本身。
- **光标上下文**——桌面版在 macOS 上可以开启一项让润色模型读到光标周围内容的开关；安卓版没有这一项。
- **本地 ASR 模型管理**——桌面版可以在设置里管理本地语音识别模型的磁盘占用，属于桌面端的路线。
- **选区问答面板**——桌面版有一个针对高亮选中文字做语音问答的入口。

**安卓版特有、桌面版没有的**，主要是围绕输入法与手机权限的一整套：

- 文本插入策略、悬浮窗显示时机、录音滑向这类**操作项设置**；
- 悬浮窗与后台存活相关的**系统权限**；
- 系统输入法列表里的启用与切换。

## 四、数据能不能跨端

**目前没有跨端同步的账号体系。** 项目走的是本地优先路线，词典、历史、风格包这些都是存在本机上的，两端之间不会自动对齐。所以：

- 想让手机和电脑用同一套词典与风格，只能**各自配一遍**；
- 换手机、重装应用时，**本机那份历史与词典不会自动回来**，换机前先想清楚哪些东西需要另存；
- 风格包是唯一能间接共享的东西——把它发布到市场，另一端从市场装回来，但这条路径要过审核、也不是同步，见 [风格包与自定义风格怎么用.md](风格包与自定义风格怎么用.md)。

服务凭据同样要在两端分别填。哪一端要重新配，照 [语音识别与润色服务怎么配置.md](语音识别与润色服务怎么配置.md) 走一遍即可，两份客户端填的字段是一样的。

## 五、该装哪一个

- 平时**主要在手机上打字、发消息**（微信、备忘录、搜索框）——装本文这份安卓版，先按 [下载与安装教程.md](下载与安装教程.md) 装好并用起来；
- 主要在**电脑上写提示词、写邮件、写代码注释**——装桌面版，它才是「按一下快捷键、任意应用里说话就出字」的那套；
- 两个场景都占——两份各自装、各自配，互不冲突，只是词典与风格要配两遍。
- 用的是 **iPhone**——官方目前没有 iOS 客户端（以官方发布页当时提供的资产为准），安卓与桌面这两套都装不上。

装机顺序不分先后，但两边都绕不开同一件事：**先把自己的识别与润色凭据准备好**。

如果你还在犹豫「要不要换掉现在用的输入法」，先看 [和搜狗讯飞这些输入法有什么不一样.md](和搜狗讯飞这些输入法有什么不一样.md) 那张产品模型对照表——两套输入法在安卓上可以并存，不必二选一。
