搜狗输入法、讯飞输入法这类产品也都有语音输入，而且装完就能用、默认给一份免费额度。OpenLess 走的是另一条路：它把识别和润色都交给你自己申请的云服务，软件本体开源、数据留在本机。**这不是谁好谁坏的问题，是两套不同的产品模型**——本篇把差异摆清楚，你按自己的用法判断。

## 一、先看这张对照表

下面说的「常见商业输入法」，指搜狗、讯飞、百度这类闭源、账号制的产品，具体条款以各自官方说明为准。

| 对比项 | OpenLess（安卓版） | 常见商业输入法 |
| --- | --- | --- |
| 代码 | 开源，MIT 协议 | 闭源 |
| 识别在哪跑 | 走你自己配的云端识别服务 | 默认云端识别；多家另提供离线语音包 |
| 费用怎么算 | 软件免费，识别与润色按你选的服务商计费 | 通常自带一份免费额度，超出后走会员或内购 |
| 要不要账号 | 不需要注册；只有往风格包市场发布时才需登录 GitHub 身份 | 普遍需要注册登录 |
| 词库与历史存哪 | 只在本机设备上 | 通常在厂商账号体系内 |
| 词库能否跨端同步 | 不能，换端要各自配一遍 | 普遍支持账号云同步，多端共用一套词库 |
| 输出的是什么 | 转写之后**再做一遍润色**，可选原文 / 轻度润色 / 结构化 / 正式 | 主要是「把话转成文字」，改写通常不是核心 |
| 有没有本地识别模型 | 安卓版没有（本地识别模型目前是桌面端 macOS / Windows 的能力） | 部分产品提供离线语音包 |

**一句话概括差别**：常见商业输入法把「识别」做成一项开箱即用的服务，连额度一起包给你；OpenLess 把「识别 + 润色」做成两段可以自己接的管道，软件免费但管道要你自己供。

## 二、「谁付钱」这件事，是最大的实际差别

两边都要联网做识别（安卓版没有本地识别），但账单的落点不同：

- **常见商业输入法**：识别通常包含在产品的免费额度里，日常聊天量基本用不完；超出才涉及付费。顺手就能用，代价是你的语音要经过厂商的云。
- **OpenLess**：软件不收费，识别与润色各自按你填的那家云服务的计价方式结算，用量、免费额度、单价都以那家控制台当时显示的为准。**好处是供应商随你换，代价是这份账单得你自己盯。**

按场景粗分一下，避免误判成本：

| 你的用法 | 更适合哪种模型 |
| --- | --- |
| 每天零星回几条消息 | 商业输入法的免费额度通常绰绰有余 |
| 每天大量长段口述（会议、稿件） | 两边都要看用量，OpenLess 侧建议先把识别与润色分开比价 |
| 想要 AI Prompt 结构化 / 按风格改写 | 这是 OpenLess 的主链路，商业输入法的语音输入一般不做这一层 |

费用与额度的具体口径见 [语音识别与润色服务怎么配置.md](语音识别与润色服务怎么配置.md) 第四节。

## 三、词库同步：换机频繁的人要注意

这是两边体验差距最明显的一处，也最容易被忽略：

- **商业输入法**：注册账号后，个人词库、常用短语能跟着账号走，换手机登录一次就回来了，多端共用一套。
- **OpenLess**：词典、历史、风格包**都只存在本机**，不跟账号走。换手机、重装应用，这些不会自动回来，得重新配一遍。

所以：**如果你换机频繁、又很依赖长期攒下来的个人词条**，这一点要先想清楚——它不是设置问题，是产品路线如此。OpenLess 侧应对办法是词典条目自己另存一份，做法与注意点见 [词典热词怎么设置.md](词典热词怎么设置.md)；两套客户端之间也是各配各的，见 [安卓版和电脑版有什么不一样.md](安卓版和电脑版有什么不一样.md)。

## 四、输出的东西本来就不是一回事

同样按着说话，出来的结果定位不同：

- 商业输入法的语音输入，目标是**把你说的字准确变成文字**，有的还会补标点、转书面语；
- OpenLess 在转写之后**还有一道润色**，而且这道润色是可选力度的——原文、轻度润色、结构化、正式四种模式，可以再叠一层风格包决定语气。

这一层差别在写 AI 提示词、写邮件、写提交信息时最明显：前者给你一句干净的话，后者给你一段可以直接拿去用的结构化文字。四种模式的取舍见 [按住说话怎么用与四种输出模式.md](按住说话怎么用与四种输出模式.md)，风格包的做法见 [风格包与自定义风格怎么用.md](风格包与自定义风格怎么用.md)。

另外两边的边界也不同：OpenLess 的润色模型**只整理你的话，不替你回答问题**——你说「这周有什么待办」，它给的是一句工整的问句，不会真去列清单。想要 AI 替你作答，那是另一个工具的事。

## 五、按需求对号入座

**倾向 OpenLess 的情况**：

- 在意语音与文本不下厂商账号、词典与历史只留在本机；
- 愿意自己去申请一次识别与润色的凭据，并接受按用量付费；
- 经常写 AI 提示词、邮件、提交信息，需要「结构化 / 按风格改写」这一层；
- 愿意接受「换机要重配词库」这条代价。

**倾向继续用现有输入法的情况**：

- 追求装完即用、零配置，不想碰任何密钥；
- 离不开跨端同步的个人词库；
- 语音输入只用于日常聊天短句，用不到润色那一段。

## 六、不用二选一

安卓上两套输入法可以**并存**，随时在输入框里长按切换：平时用惯的那套照旧，需要口述提示词或长段文字时切到 OpenLess，互不冲突。这也是最省事的过渡方式——先并存用一阵，再决定要不要把它设成默认。
