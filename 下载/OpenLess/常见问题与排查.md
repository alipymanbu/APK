> 装不上、切不到输入法、按住没反应、字没落进输入框——本篇按现象归拢，每条给出先查什么、再查什么。

排查 OpenLess 的问题，顺序只有一条：**先分清卡在哪一段**——是包没装好、输入法没启用、权限没给、凭据没配对，还是文字落位被挡。这五段的表现长得很像（都是「按了没动静」），但修法完全不同。下面按现象列，每条按可能性从高到低排。

## 一、安装阶段

| 现象 | 常见原因 | 怎么办 |
| --- | --- | --- |
| 提示「解析包错误」「无法打开文件」 | 下载不完整；APK 被聊天软件改过 | 从 [OpenLess 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e41649c82c38) 重新下载；比对 MD5 是否与 [下载与安装教程.md](下载与安装教程.md) 开头表格一致 |
| 点了安装包没反应，或被系统拦下 | 安装未知应用的权限没给 | 「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给文件管理器或浏览器打开开关 |
| 提示已存在同应用，装不上 | 手机里有同包名、签名不同的旧版本 | 卸载旧的再装 |
| 装上了但打开就退、或语音处理异常 | APK 的 ABI 与手机架构不匹配 | 按 [下载与安装教程.md](下载与安装教程.md) 第二节选对应架构的包重装 |

## 二、输入法阶段

| 现象 | 常见原因 | 怎么办 |
| --- | --- | --- |
| 输入框里调不出 OpenLess 键盘 | 应用装了，但没在系统里启用它 | 「设置 → 系统 → 语言和输入法」里启用，并在长按输入框时切到 OpenLess |
| 键盘能出，但没有语音入口 | 当前用的是别的输入法 | 长按输入框确认当前键盘是 OpenLess；换回来再试 |
| 启用后别的应用里仍不显示 | 部分应用自带输入框不吃第三方键盘 | 换到系统自带的输入框试，确认是应用限制而不是 OpenLess 的问题 |

## 三、录音与权限阶段

| 现象 | 常见原因 | 怎么办 |
| --- | --- | --- |
| 按住说话完全没反应 | **麦克风权限没给**（最常见） | 设置 → 应用 → OpenLess → 权限，把麦克风设为「使用应用时允许」 |
| 权限明明给了，还是录不到 | 系统级麦克风开关被关掉了 | 下拉快捷面板看有没有麦克风或隐私开关被关；再进「设置 → 隐私 → 权限管理 → 麦克风」确认全局没关 |
| 第一次能用，之后偶尔才弹授权 | 权限被设成了「每次询问」，弹窗被忽略就等于拒了 | 把权限改成「仅在使用时允许」，别用「每次询问」 |
| 能录但录不到声音 | 麦克风被别的应用占着；或被蓝牙耳机的麦接管 | 关掉正在占用麦克风的应用；断开蓝牙耳机再试 |
| 说话时看不到状态提示 | 悬浮窗权限没给 | 给 OpenLess 打开悬浮窗相关权限（部分系统叫「显示在其他应用上层」） |
| 用一段时间后按键失灵，重启应用又好了 | 被系统的省电策略在后台清掉了 | 把 OpenLess 加入电池优化的白名单；部分定制系统的省电模式更激进，要单独放行 |

**这一类要特别注意**：安卓各家定制系统对后台运行与悬浮窗的管控差别很大，同一套设置在不同手机上表现不同。系统更新后权限被重置、旧设置失效，也是常见情况——出问题先回去把这几项权限重看一遍，比到处找原因快。

## 四、配置阶段

| 现象 | 常见原因 | 怎么办 |
| --- | --- | --- |
| 按住说话后有反应，但一直不出字 | 识别服务的密钥、接口地址或模型名填错了 | 回到配置页逐项核对三项；注意模型名要填控制台里的调用名，不是界面上那个中文显示名 |
| 报鉴权失败 / 未授权 | 密钥复制时带了换行或空格；密钥与供应商不匹配 | 重新整段复制密钥与接口地址，别自己补路径 |
| 能出字，但出来的是没整理过的口语稿 | 润色这一端没配通，或模式选了「原文」 | 单独检查润色供应商；确认输出模式不是「原文」 |
| 之前好好的，突然不出结果 | 云服务额度用完、欠费、或服务临时故障 | 登录对应供应商控制台看用量与余额；这跟没配置不是一回事 |
| 某个专有名词老是识别错 | 用的识别服务不支持热词 | 见 [词典热词怎么设置.md](词典热词怎么设置.md) 第三节，换支持热词的识别端 |

## 五、文字落位阶段

| 现象 | 常见原因 | 怎么办 |
| --- | --- | --- |
| 输入框里没出现文字 | 目标应用不接受直接写入，已自动回退剪贴板 | 在当前输入框长按 → 粘贴；这是设计内的兜底，不是坏了 |
| 文字像打字一样一个个冒出来，有时中间断 | 走的是流式插入 | 属于正常行为；某个应用吃不住就改成一次性粘贴策略 |
| 文字插到了错的位置 | 说话前光标不在你以为的那个框里 | 先点一下目标输入框确认光标位置，再按住说话 |
| 插入的内容被截断了 | 目标输入框有长度上限 | 长内容先说短一点，或分两次说 |

## 六、版本与更新

- **应用内检查更新**：进「设置 → 关于 → 检查」，走官方渠道取新版；想提前试新版可在「设置 → 关于 → 加入 Beta 频道」，Beta 版本不会自动推给正式用户。
- **网盘里这份是 1.3.11**；截至 2026 年 8 月 21 日，官方发布页上的最新正式版是 `v1.3.18`（以官方发布页当时显示为准）。新版功能在旧版里找不到，属于版本差异。
- 更新前留意：词典、历史、风格包都在本机，更新过程一般会保留；但**换机重装不会自动带过来**，重要词表先自己留一份。

## 七、还是解决不了

按顺序试这三个官方入口：

1. **代码仓库的 Issues**——搜一下有没有人遇到同样现象，没有就新开一条，附上手机型号、系统版本、OpenLess 版本号、复现步骤，见 [github.com/Open-Less/openless/issues](https://github.com/Open-Less/openless/issues)；
2. **Discord 社区**——[加入 Discord](https://discord.gg/vTZHTFGFm)，适合问得比较碎的问题；
3. **QQ 群 1078960553**——同样的社群入口。

提问时把「哪一段卡住」先说清楚（装包 / 启用输入法 / 权限 / 凭据 / 落位），能省掉一轮来回。想确认自己装的是不是旧版、或要重新取一份包，回到 [下载与安装教程.md](下载与安装教程.md) 第一节比对版本号与包名。
