# OpenLess 风格包与自定义风格怎么用

> 输出模式决定「整理到什么程度」，风格包决定「用什么语气写」。本篇讲怎么建自己的风格、怎么从市场装别人的、发布要注意什么。

润色这一步，模型不是凭空知道你想要什么文风的。OpenLess 把它拆成两个可以分别调的东西：**输出模式**管整理力度（原文 / 轻度润色 / 结构化 / 正式），**风格包**管写作语气。风格包就是一段带名字的、专属的系统提示词——你告诉模型「用这种口气写」，它照办，不用每次说话都重讲一遍。

## 一、模式和风格包，别混在一起调

| 你想改的是 | 该动哪个 |
| --- | --- |
| 输出得「更干净一点」还是「原样保留」 | 输出模式 |
| 输出得「像周报」「像客服回复」还是「像小红书文案」 | 风格包 |
| 用哪种语言输出 | 翻译目标语言 |
| 某个专有名词老被写错 | 词典热词，见 [词典热词怎么设置.md](词典热词怎么设置.md) |

两者可以叠：选「结构化」模式 + 「工程 commit message」风格包，出来的是结构化的提交信息；选「轻度润色」+ 同一种风格包，出来的是语气对但结构简单的一段话。

## 二、建一个自己的风格包

在 OpenLess 的**风格**页里新增一个风格包，写两样东西：**名字**，和**自定义系统提示词**。名字自己认得就行；提示词才是真正生效的部分。

写提示词时，抓住这四样，比堆形容词有用得多：

- **口吻**——对谁说话（客户/同事/朋友）、是客气还是直接；
- **长度与结构**——要不要分点、要不要小标题、大概几段；
- **署名与格式**——是否保留称呼、是否加落款、要不要加标题；
- **禁止项**——比如「不要加表情符号」「不要用感叹号」「不要总结成一句话」。

几个可以直接照着改的例子：

```text
把口述内容写成一条工程提交信息：一句话总结改动，不超过 50 字，不加句号，不分点，不用表情。
```

```text
把口述内容写成一段给客户看的回复：语气客气、不使用感叹号、先讲结论再讲原因，控制在三句话以内。
```

```text
把口述内容写成一条社交平台文案：开头一句抓人的话，中间分两到三点，结尾一个提问；可以带表情符号，但不超过三个。
```

**一个要点**：润色模型只负责整理你的话，**不替你回答问题、不执行任务**。所以提示词应当描述「怎么改写这段话」，而不是「帮我写一份什么东西」——你说「今天天气怎么样」，它给你的是一句标点规范的问句，不是天气预报。指望它代答是走错门了，那种事该交给 ChatGPT、Claude 那边。

## 三、装别人的风格包：市场

风格页之外还有一个**市场（Marketplace）**，里面是别人分享出来的风格包：

- 可以浏览、搜索，看到合适的**一键安装**，装完就和自建的一样出现在你的风格列表里；
- 用得顺手的可以**点赞**；
- 市场里的风格包按用途陈列，想知道社区里的人主要在做哪类风格，翻分类列表即可。

装回来的风格包是**本地的一份配置**，之后与你自己的自建风格地位相同，随时可改、可删。

## 四、把自己做的发布出去

想让别人也能用到你写的那套，流程是：

1. 在**设置 → 市场**里用 **GitHub 身份登录**——发布要认一个可追溯的身份，不做匿名上传；
2. 回到风格页，选中要发布的风格；
3. 选择**发布到市场**。

有两点要先知道：

- **上传内容会经过审核后才公开**，不是发完立刻出现在市场里；
- 发布的是**那套系统提示词**，别在提示词里写自己的私人信息、内部项目名或密钥——它是要公开展示的。

## 五、多个风格之间怎么切

风格包做多了，切换就要顺手。OpenLess 支持配置风格的切换方式，不用每次退回应用界面翻列表。常用的两三种固定下来就够，比如「日常聊天」「正式邮件」「工作提交信息」——**风格越贴合你当下真正在做的事，出来的文字差别越明显**，这也是这套机制存在的理由。

改完风格或装了新风格，实说一次确认效果确实是你要的；最小验证的三步见 [下载与安装教程.md](下载与安装教程.md) 第五节。
