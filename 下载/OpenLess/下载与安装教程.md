OpenLess 是一款开源的语音输入工具：你按住说话，它先把语音转成文字，再按你选的模式润色一遍，最后把结果直接落到光标处。它在安卓上**以系统输入法的形态运行**——包名叫 `com.openless.app`——所以装完并不算完事，还要完成授权、填好识别与润色的服务凭据、再把它设为输入法，语音输入才真正可用。本篇只负责把这条链走完。

三点容易搞混，装之前先心里有数：

- **同名产品里，安卓版是「输入法」，桌面版是「全局快捷键工具」。** 搜索 OpenLess 时最先撞见的往往是 macOS / Windows 那一套，它和本文这份不是同一个客户端。两份的差别见 [安卓版和电脑版有什么不一样.md](安卓版和电脑版有什么不一样.md)。
- **网盘里这份旧于官方当前版本。** 截至 2026 年 8 月 21 日，官方发布页上的最新正式版是 `v1.3.18`，本文对应的这一份是 1.3.11（以官方发布页当时显示为准）。如果官方介绍里的某个新功能你装完找不到，多半是版本差异，不是设置没开。
- **MD5 是文件的指纹。** 下载完自己算一遍，与上表一致说明文件完整、没被中途替换；对不上就重新下一次，别将就着装。

## 二、装之前要核对的一件事：选对 ABI

同一个版本号，官方会放出针对不同 CPU 架构的多个 APK。选错了不一定装不上，但运行起来容易出问题，先按手机的实际架构挑：

| 你的设备 | 该选哪种包 |
| --- | --- |
| 近几年的真机（绝大多数） | `arm64-v8a` |
| 较老的 32 位 ARM 机型 | `armeabi-v7a` |
| 64 位安卓模拟器 | `x86_64` |
| 32 位安卓模拟器 | `x86` |

分不清自己手机是哪一种，可以在电脑上用 adb 查一下：

```bash
adb shell getprop ro.product.cpu.abi
```

输出值直接对应上表的行。机型确实老、又不确定时，`armeabi-v7a` 通常能兼容更多设备，但语音处理的流畅度会差一些。

官方每个版本实际放出的架构**以发布页当时提供的文件为准**，可能多一种也可能少一种，别把上表当固定清单。

另外，官方文档没有明确公布安卓版的最低系统要求，所以不必提前纠结——**系统版本过低会直接在安装环节报错**，装的时候就知道。

## 三、安装步骤

1. 在上面的网盘入口里把 APK 转存到自己的网盘，再下载到手机；
2. 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给打开安装包的那个应用（文件管理器或浏览器）打开开关；
3. 点击 APK 完成安装。系统提示「应用未经过安全检测」时选择继续安装，这是第三方渠道安装包的常规提示；
4. 如果手机里已经装过同一个包名、但签名不同的版本，安装会直接失败——先卸载旧的再装。

## 四、第一次打开要走的四步

装完打开，界面会按顺序引导你，四步都过一遍再谈好不好用：

| 顺序 | 做什么 | 漏掉会怎样 |
| --- | --- | --- |
| 1 | 按引导完成**系统授权**，麦克风与悬浮窗相关权限都要给 | 麦克风不给就录不到音；悬浮窗不给，说话时看不到状态提示 |
| 2 | 设置**文本插入策略、悬浮窗显示时机、录音滑向**等操作项 | 不改也能用，但插入方式和提示位置是默认值，未必合手机习惯 |
| 3 | 填**语音识别（ASR）与文本润色（LLM）的服务凭据** | 这一步不填，按了没有识别结果，等于一块空键盘 |
| 4 | 去系统设置里**把输入法切换成 OpenLess** | 不切换，在聊天框里调不出语音输入 |

第 3 步是这套工具唯一的门槛，也最容易卡住，单独写了一篇：[语音识别与润色服务怎么配置.md](语音识别与润色服务怎么配置.md)。第 4 步的一般做法是：进入任意可输入文字的地方，长按输入框 → 选择输入法 → 切到 OpenLess；之后也可以去「设置 → 系统 → 语言和输入法」里把它设为默认。

## 五、装完做一次最小验证

按顺序试这三件，全过得去，说明链路是通的：

1. 长按输入框能切到 OpenLess，键盘正常弹出来；
2. 按住说话，松开后**有文字出现在光标处**——这一步验的是 ASR 与 LLM 都配对了；
3. 到 OpenLess 的**历史记录**页看一眼，刚才那次的原始转写与润色结果都在。

任何一步过不去，先看 [常见问题与排查.md](常见问题与排查.md)，再按那篇的分支回到这里重新取包或重新配置。

## 六、想把安卓版换成电脑版怎么办

桌面版（macOS / Windows / Linux）与安卓版是**两份独立安装的客户端**，不存在「一份包同时装两端」。桌面版走官网 [openless.top](https://openless.top/) 与代码仓库 [github.com/Open-Less/openless](https://github.com/Open-Less/openless) 的发布页获取，形态与用法和这边差别不小，见 [安卓版和电脑版有什么不一样.md](安卓版和电脑版有什么不一样.md)。

需要重新下载网盘里这份安卓包时，仍然从本篇开头的网盘入口取。
