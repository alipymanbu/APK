## 一、先判断你要哪种

手机和电脑在**同一个 Wi-Fi** 里，用内网 IP 直连就够了，什么都不用配（做法见 [远程桌面连接设置教程.md](远程桌面连接设置教程.md)）。只有当你人在外面、电脑在家里或公司内网时，才需要下面的办法——远程桌面是点对点连接，路由器默认不会把外面的请求放进内网，这道口子得你自己开，或者绕开它。

微软官方文档给了两条路：**端口转发**或 **VPN**，二选一。

## 二、路一：路由器端口转发

把路由器公网 IP 上的一个端口映射到家里那台电脑。动手前先备齐四样东西：

| 要什么 | 从哪拿 |
|---|---|
| 电脑内网 IPv4 地址 | 电脑上「设置 → 网络和 Internet → 状态 → 查看网络属性」 |
| 公网 IP（路由器的地址） | 搜「我的 IP」，或看路由器 WAN 口状态页 |
| 端口号 | 默认 3389 |
| 路由器管理员权限 | 管理员账号 |

然后进路由器管理界面加一条转发规则：外网端口 3389 → 电脑内网 IP 的 3389。配完后手机那条连接的 **PC name** 填**公网 IP**，其余步骤不变。

三个会咬人的后续问题，官方都点了名：

- **公网 IP 会变**：运营商随时可能给你换 IP，一变就连不上了。官方建议用动态 DNS（DDNS）——它给你一个固定域名，IP 变了自动跟着更新，你填域名就不用管 IP；
- **内网 IP 也会变**：电脑重启后 DHCP 可能换地址，转发规则就指空了。给这台电脑在路由器里绑定静态内网 IP；
- **别把口子开给所有人**：多数路由器支持限制来源——你知道自己只从某个网络连，就把来源限定到那个网段，避免把端口暴露给整个互联网。

## 三、路二：VPN（官方更推荐的那种）

手机先连上家里的 VPN，就相当于进了同一个局域网——此时远程桌面客户端的行为和在家时完全一样，电脑**不需要**对公网开任何口子。官方文档的原话口径是：把电脑接进互联网不建议；如果必须，要给电脑设强密码，**更好的做法是用 VPN**。

具体选哪种 VPN 因人而异（自建、组网型方案各有取舍），这里不替你选；判断标准就一条：**你的 3389 端口有没有直接暴露在公网上**。没暴露，风险面就小一截。

## 四、暴露 3389 意味着什么（多篇安全实践的共识）

多篇独立的 RDP 安全文章口径一致，这里只列对你有动作含义的：

- **公网可达的 3389 会被全天候扫描**，弱口令账户面临爆破与撞库——所以远程登录用的账户必须是强密码，且不要和日常轻量账户共用；
- **NLA（网络级别身份验证）保持开启**：它要求先完成身份验证才建立完整会话，是廉价且有效的一层。排查凭据问题时临时关掉可以，验完要开回去（见 [连接失败排查方法.md](连接失败排查方法.md) 第二节）；
- **改端口不算防护**：把 3389 改成别的端口能减少扫描噪音，但协议指纹仍可被识别，别把安全感建立在「没人知道端口」上；
- **只留必要的人能连**：远程桌面用户组里不需要的账户及时移除。

以上是安全建议，不是操作教程——真正动手的只有两件事：开 NLA、给远程账户设强密码；其余按你的网络条件量力而行。
