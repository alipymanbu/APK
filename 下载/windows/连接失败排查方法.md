## 一、先做这四个低成本检查

排障别一上来就改设置，先用这四步筛掉一半问题：

1. **手机和电脑是不是同一网络**。同一 Wi-Fi 用 IP 直连最稳；不在同一网络（手机在外面、电脑在家里）本来就直接连不通，需要路由器端口转发或组网，与客户端无关。
2. **电脑有没有休眠/关机、网络有没有掉**。被连端睡着了，客户端表现就是一直转圈或超时。
3. **电脑端远程桌面开关是否开着**，「设置 → 系统 → 远程桌面」确认一次。
4. **换 IP 连**。电脑名解析失败时，直接填 IPv4 地址能立刻区分「是名字问题还是链路问题」。

## 二、提示「凭据不工作 / 用户名或密码不对」

这是最高频的一类，按命中率排序查：

| 原因 | 怎么处理 |
|---|---|
| 填了 PIN | 必须填账户的真实登录密码，PIN 不管用 |
| 本地账户用户名写法不对 | 写成 `电脑名\用户名`；裸用户名在部分场景也认，但带前缀最保险 |
| 微软账户没按格式写 | 用完整邮箱地址，或 `MicrosoftAccount\邮箱`；密码是微软账户密码 |
| 账户没有远程登录权限 | 在电脑上把该账户加进「远程桌面用户」组（管理员组默认有权限） |
| 账户没设密码 | 无密码账户不允许远程登录，先给它设密码 |
| 提示密码已过期（`0xf07`） | 到电脑上更新该账户密码后重试 |

另有一个折中手段：在电脑的远程桌面设置里关闭「要求使用网络级别身份验证（NLA）」再试——Android 客户端本身支持 NLA，此操作只在排除问题时临时用，验完建议改回开启状态，它关系到连接前的身份验证安全。

## 三、完全连不上、一直超时

- **被连端是家庭版**：Windows 家庭版没有被远程桌面连接的能力，换专业版及以上的系统，或改用其他远程方案；
- **防火墙没放行**：电脑的防火墙或第三方安全软件拦了 3389 端口，检查「允许应用通过 Windows 防火墙」列表里远程桌面相关项是否勾选；
- **IP 填错**：确认填的是「设置 → 网络和 Internet」里当前连接的 IPv4 地址，别拿路由器管理页或别的设备的地址；
- **换了网络后 IP 变了**：路由器重启或换网后电脑可能拿到新 IP，在电脑上重新看一遍再填。
- **手机一锁屏或切后台就断**：安卓系统的省电机制会清理后台应用，会话被切到后台后掉线属常见表现。到手机「设置 → 应用」里找到该应用，把电池优化改为「不优化」、允许后台运行；不同品牌手机菜单名不一样，认准「省电策略 / 后台活动 / 锁屏清理」这类字样。改完仍因机型而异，锁屏后保持连接的最稳办法是让会话停在前台。

## 四、弹证书确认与「无法验证身份」

首次连某台电脑会弹证书提示，属正常——点 **Connect** 继续即可，勾选「不再就此计算机询问」以后不再弹。若连接直接失败且与证书相关，检查电脑的系统日期时间是否正确：时间偏差过大会让证书被判为无效。

## 五、连上了但画面/输入不对

- **画面糊或比例怪**：在该连接的编辑页开「自定义显示分辨率」指定一个与手机屏幕接近的分辨率；
- **横竖屏切换后显示错乱**：断开重连一次即可按新方向重新缩放；
- **按键没有反应/键位错位**：与远程会话的输入法语言有关，先确认软键盘已呼出；顽固的键位问题可在通用设置里切换 scancode 输入开关（以你装的版本是否有该选项为准）。
