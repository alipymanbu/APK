## 一、两种鼠标模式先分清

连上之后，会话里有两种鼠标模式供你切，用途完全不同：

- **直接触控（Direct touch）**：你点屏幕哪里，就等于在那个位置点了一下鼠标，屏幕上不显示鼠标指针。桌面本身支持触控时用它最顺手，Windows 的原生触控与多点手势也只在这种模式下生效。
- **鼠标指针（Mouse pointer）**：屏幕上出现一个可见的鼠标指针，你按住拖动，指针跟着走。远程桌面是密集的小按钮、小菜单时，用它比直接触控准。

切换入口在会话顶部的连接栏里（见第四节），随时可切，不用断开重连。

## 二、手势对照表

同一只手在两种模式下含义不同，按下表对应：

| 模式 | 鼠标动作 | 手势 |
|---|---|---|
| 直接触控 | 左键单击 | 单指轻点 |
| 直接触控 | 右键单击 | 单指按住再松开 |
| 直接触控 | 左键拖动 | 单指双击并按住，然后拖 |
| 鼠标指针 | 左键单击 | 单指轻点（点在哪指针就在哪） |
| 鼠标指针 | 左键拖动 | 单指双击并按住，然后拖 |
| 鼠标指针 | 右键单击 | 双指轻点 |
| 鼠标指针 | 右键拖动 | 双指双击并按住，然后拖 |
| 鼠标指针 | 鼠标滚轮 | 双指按住，上下拖 |
| 鼠标指针 | 缩放 | 双指捏合 / 张开 |

最容易混的是「右键」：直接触控模式下单指长按就是右键，而鼠标指针模式下要双指点。连过去发现自己一点就弹右键菜单，说明当前是直接触控模式、而你以为自己在用指针模式。

## 三、键盘输入的两个现实问题

1. **手机没物理键盘**，打字靠调起软键盘——会话里点连接栏的键盘图标即可呼出，再点一次收起。
2. **组合键没有物理键可按**。远程桌面上常用的 `Ctrl+Alt+Del`、`Alt+Tab`、`Win` 键在手机上都得走替代方式：`Ctrl+Alt+Del` 对应客户端里的 `Ctrl+Alt+End`，`Alt+Tab` 对应 `Alt+Page Up` / `Alt+Page Down`，`Win` 键对应 `Alt+Home`。这些替代键在客户端的键盘快捷入口里能找到，完整对应关系可对照 [微软官方的键盘快捷键说明](https://learn.microsoft.com/zh-cn/windows-app/input-keyboard-mouse-touch-pen)，具体以你装的版本界面为准。

远程会话里的输入法语言默认跟随电脑的区域设置，要改在电脑端改。

## 四、连接栏、命令栏与会话切换

连上后屏幕**顶部中间**挂着一条连接栏，可以左右拖动改位置，它带你进三个东西：

- **平移控件**：直接触控模式下想看屏幕外的区域，点连接栏上的平移图标，画面会缩小并出现一个摇杆，按住摇杆拖动就能看别处；再点一次恢复原尺寸。
- **命令栏**：点连接栏展开屏幕右侧的命令栏，在这里切鼠标模式（直接触控 ↔ 鼠标指针）、点 Home 回连接中心。回连接中心**不会断开**当前会话，随时能切回去。
- **会话选择栏**：你同时开着多台电脑时，点连接栏展开屏幕左侧的会话列表，在几个已开连接之间跳转；点某张卡片上的 **X** 可断开那一路，点 **Start New** 能在同一连接里再开一个会话。

## 五、把连接固定到桌面

每次都要打开应用再点卡片嫌麻烦，可以用小部件把某条连接钉到手机桌面：

1. 长按桌面空白处或进应用抽屉的「小部件」；
2. 找到带「Pin Remote Desktop」字样的远程桌面小部件；
3. 拖到桌面松手，在弹出的列表里选要固定的那条连接。

以后点这个图标直接发起连接。注意：在应用里给连接改名后，桌面图标的文字**不会**跟着更新，想同步得重新添加一次小部件。
