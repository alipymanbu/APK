## 一、设置入口在哪

连接中心里进 **Settings**，里面分几组：**General**（通用）、**Display**（显示）、**Gateways**（网关）、**User accounts**（用户账户）。改的是全局默认值，已经单条配置过的连接不受影响；另外**显示类设置只对之后新建的连接生效**，当前会话要重连一次才吃到新设置。

## 二、通用设置里值得动的三项

- **显示桌面预览**：连接中心里给每条连接显示缩略图，默认开启，关掉列表更清爽；
- **Pinch to zoom（双指缩放远程会话）**：默认开启。注意一个反直觉的点——如果你远程操作的程序本身支持多点触控（Windows 8 之后的不少应用支持），把这项**关掉**，否则你的双指手势会被客户端吃掉、传不到远端程序；
- **Use scancode input when available**：键盘输入以扫描码方式发送。远程程序对按键没反应或键位错乱时切一下这个开关试试（以你装的版本是否有该选项为准）。

其余项涉及匿名使用数据上报，你介意就关，不影响连接功能。

## 三、用户账户：一次保存，处处免输

懒得每次敲密码，就把账户存进应用：

1. **Settings → User accounts → +**；
2. **User name** 支持三种写法：`用户名`、`域名\用户名`、`用户名@域名`；
3. 填 **Password**——保存的远程账户必须带密码；
4. **Save**。之后在任意连接里选这个账户即可。

删除时长按账户条目（可多选）再点垃圾桶图标。注意存的是**明文可复用的凭据**，手机丢了别人拿到就能连你的电脑，所以给手机本身设锁屏很要紧。单条连接仍可在编辑页选「每次连接时输入」来覆盖这个默认值。

## 四、显示设置

- **Orientation**：会话用横屏还是竖屏优先；
- **Resolution**：全局远程分辨率。手机屏幕小、字太小看不清时，把分辨率调低反而更清楚；
- 注意连 Windows 8 或更老的系统时，中途旋转设备会导致缩放不对，断开按目标方向重连即可；被连端是 Windows 10 及以上则不会遇到这个问题。

## 五、网关与远程资源（家用一般用不上）

- **Gateways**：远程桌面网关让身处外网的你经一台网关机转入内网电脑。**Settings → Gateways → +**，填服务器名（可带端口，如 `RDGateway:443`）与访问账户（可选「使用桌面用户账户」复用连接凭据）。家用没有网关就留空；自家电脑从外网直连的取舍（端口转发 vs VPN）另见 [外网连接与安全建议.md](外网连接与安全建议.md)。
- **远程资源（Remote Resource Feed）**：管理员把 RemoteApp、发布的桌面以 URL 或邮箱形式发给你时用——连接中心 **+ → Remote Resource Feed**，填对方给的地址，按提示登录，发布出来的应用会出现在连接中心。个人直连电脑用不到它，看到它不是你装错了。

## 六、会话里的每条连接还能单独调

添加/编辑连接时（**... → Edit**）的可选项回顾：友好名、网关、声音从哪放、专属分辨率、左右键对调、连接管理员会话、重定向本地存储。各选项含义与用法在 [远程桌面连接设置教程.md](远程桌面连接设置教程.md) 第二节，操作手势在 [触控手势与鼠标模式说明.md](触控手势与鼠标模式说明.md)，重定向开关（剪贴板、存储）到底能通什么、传文件走哪条路，单独在 [复制粘贴与文件传输.md](复制粘贴与文件传输.md) 讲。

连接出问题时先别改设置，走 [连接失败排查方法.md](连接失败排查方法.md) 的顺序查一遍。
