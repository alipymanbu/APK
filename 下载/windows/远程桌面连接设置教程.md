## 一、先确认电脑这边够不够格

连不上十有八九不是手机端的问题，先在**被连的那台电脑**上核对三件事：

1. **系统版本**：Windows 家庭版（Home）不能被远程桌面连接，被连端必须是专业版、企业版或教育版。在电脑上「设置 → 系统 → 关于」的「Windows 规格」里看版本。判断标准以官方说明为准：客户端侧用什么系统都行，卡的是被连端。
2. **远程桌面开关**：「设置 → 系统 → 远程桌面」，把开关打开并确认。打开后记下这一页显示的**电脑名称**，等会儿要用。
3. **账户能被连**：默认只有管理员组账户能连；要让别的账户连，把它加进「远程桌面用户」组。账户必须设过密码——无密码账户连不上。

同一局域网里想用 IP 直连，就在电脑上「设置 → 网络和 Internet」里看当前连接的 IPv4 地址。

## 二、手机端添加一条连接

电脑准备好后，在装好 Windows App 的手机上（没装先看 [下载与安装教程.md](下载与安装教程.md)）：

1. 打开应用进入连接中心，点 **+**，选 **Desktop**（部分版本叫 **PC connection**）；
2. **PC name** 填电脑名或 IP 地址——这是唯一必填项。填 IP 时可以带端口，如 `10.0.0.1:3389`（默认端口就是 3389，不改端口可以省略）；
3. **User name** 选登录方式：选「每次连接时输入」就每次都要打密码；选「添加用户账户」则把常用账号存进应用，以后免输；
4. 需要的话点「显示其他选项」补几个可选设置：
   - **Friendly name**：给这条连接起个好认的名字（比如「家里电脑」），不填就显示电脑名；
   - **Gateway**：从外网经远程桌面网关接入时才填，家用场景一般空着；
   - **Sound**：远程会话的声音从手机放、电脑放，还是不放；
   - **Customize display resolution**：单独给这条连接定分辨率；
   - **Swap mouse buttons**：左右键对调，左手习惯的人用；
   - **Redirect local storage**：把手机存储挂进远程会话，默认关闭；
5. 点 **Save**。连接中心多出一张卡片，点它就开始连。

要改就点卡片旁的 **...** → **Edit**，要删就 **...** → **Remove**。

## 三、凭据怎么填（最容易卡住的一步）

弹出的账户密码框里，填的是**电脑上的账户**，规则如下：

| 电脑上的账户类型 | 用户名填法 | 密码 |
|---|---|---|
| 本地账户 | `电脑名\用户名` 或裸 `用户名` | 该账户的登录密码 |
| 微软账户 | 完整邮箱地址（也可写成 `MicrosoftAccount\邮箱`） | 微软账户密码 |
| 域账户 | `域名\用户名` | 域密码 |

三条踩过无数次的坑：

- **密码是账户密码，不是 PIN**。你在电脑锁屏上用指纹或四位 PIN 登录不代表这里也能填 PIN，必须填真实密码；
- 第一次连会弹证书确认，点 **Connect** 即可；信任这台电脑就勾上「不再就此计算机询问」；
- 提示「用户的密码已过期」（错误 `0xf07`）时，去电脑上把这个账户的密码改新再连。

凭据反复被拒的完整排查在 [连接失败排查方法.md](连接失败排查方法.md)。

## 四、连上之后

连接成功后你看到的就是那台电脑的完整桌面，操作方式（单指点左键、长按右键等）见 [触控手势与鼠标模式说明.md](触控手势与鼠标模式说明.md)。会话里按需调显示、声音、账户等设置的入口在 [常用功能与设置说明.md](常用功能与设置说明.md)。

在公司网络之外连回家里电脑，还需要路由器端口转发或组网方案，这一层与客户端无关，本文不展开；只在同一 Wi-Fi 下用的话，上面四步就够了。
