# Sam Helper 改屏幕分辨率与刷新率的方法

## 一、先授权：写入安全设置权限

改分辨率、DPI、刷新率、动画速度都属于系统级设置，Sam Helper 需要拿到「写入安全设置」（WRITE_SECURE_SETTINGS）权限才能动手。三种方式任选其一：

- **ADB（推荐，需要一台电脑）**：手机打开开发者选项与 USB 调试，连接电脑后执行：

```bash
adb shell pm grant com.litebyte.samhelper android.permission.WRITE_SECURE_SETTINGS
```

- **Shizuku**：先让 Shizuku 在手机上跑起来（无线调试或电脑 ADB 均可启动），再回到 Sam Helper 完成授权。
- **Root**：已 root 的机器可直接授权。

授权一次长期有效，之后这些设置项都能直接改。

还没有装 app 的话，Sam Helper 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/66b33b7d3842](https://pan.quark.cn/s/66b33b7d3842)。

## 二、改分辨率与 DPI

入口：主页「系统设置」板块 → 屏幕分辨率，按提示输入想要的宽度、高度、密度（DPI）。操作前记住两条：

- **保持「锁定比例」开启**。关掉比例锁定后随意填宽高，界面比例会失真。
- **保守改 DPI**。错误的分辨率与 DPI 组合可能让界面元素超出屏幕、无法点击。

## 三、改错了怎么救回来

分辨率改错导致屏幕点不动时，按顺序试：

1. **音量下键重置**：回到 Sam Helper 的「系统设置」界面按音量减键，可重置分辨率（有用户反馈这个方法有效）。
2. **ADB 重置**：连电脑执行：

```bash
adb shell wm size reset
adb shell wm density reset
```

两条命令分别恢复原生分辨率与 DPI，执行完屏幕立即回到出厂状态。

## 四、改刷新率

入口：「系统设置」→ 屏幕刷新率。列表会列出当前机型支持的档位（如 48 / 60 / 96 / 120Hz，因机型而异），点选即生效。

调高刷新率滑动更跟手，耗电也会随之增加；追求续航就选低档位，玩高帧率游戏再把刷新率调上去。

省电模式的一个细节：有用户分享，省电模式下系统默认锁低刷新率，此时可以在 Sam Helper 的分辨率设置里把刷新率选成自适应模式，让省电时自动降档、日常恢复高刷。

## 五、动画速度

入口：「系统设置」→ 动画速度。把动画缩放调低后，窗口与过渡动画明显变快；这里的数值与开发者选项里的动画缩放是同一类参数，Sam Helper 提供了独立入口，不用去开发者选项里翻。

## 六、其他可调项

「系统设置」板块里还有这些入口，按需使用：

| 设置项 | 用途 |
| --- | --- |
| 屏幕模式 | 在自然、护眼、夜间等显示风格间切换 |
| 系统界面调节 | 调整系统界面的显示参数 |
| 移动网络模式 | 切换移动网络的制式模式 |
| 移动网络频段 | 勾选频段；误操作可能影响信号，不熟悉别乱改 |
| 系统文件管理 | 读写 `/Android/data/` 目录（Android 11 之后系统文件管理器进不去的位置） |
| 暗码功能 | 跳转系统转储、硬件测试等工程菜单，见 [查看手机信息与暗码.md](查看手机信息与暗码.md) |

主页上还有两个独立板块：**应用管理**（应用提取、应用分身、应用双开，见 [应用分身与双开.md](应用分身与双开.md)）与 **Shizuku 终端**（以 adb 权限执行 shell 命令，典型用途如查电池循环次数，见 [电池循环次数怎么查.md](电池循环次数怎么查.md)）。
