## 一、「手机信息」页有什么

Sam Helper 的「手机信息」页汇总了系统设置里不直接展示的设备数据，常用的几项：

| 信息项 | 看什么 |
| --- | --- |
| 出厂日期 | 核对机器实际出厂时间，二手验机时与卖家描述对照 |
| 电池循环次数 | 充放电周期数，反映电池损耗程度；两种查法见 [电池循环次数怎么查.md](电池循环次数怎么查.md) |
| 电池容量 | 电池容量相关数据 |
| Knox 状态 | 三星安全平台 Knox 的触发状态 |
| DRM 安全等级 | 设备 DRM 密钥层级状态 |

这些是只读信息，你只看不改。二手验机时，把这一页与 [气密性测试怎么用.md](气密性测试怎么用.md) 的结果放在一起看：信息页看「履历」，气密测试看「密封现状」。

## 二、桌面长按图标：隐藏功能捷径

在桌面长按 Sam Helper 图标，弹出的快捷方式（shortcuts）里可以直接进入几个系统隐藏功能入口，不用先打开 app 再逐级翻菜单。

## 三、暗码功能：一键跳转工程菜单

三星系统内置了一批以 `*#` 开头、以 `#` 结尾的暗码，在拨号盘输入即可打开对应的工程菜单。Sam Helper 把常用的暗码整理成入口，点一下就能跳转，不用记、不用输：

| 入口 | 对应的常见暗码 | 打开什么 |
| --- | --- | --- |
| 系统转储 | `*#9900#` | 系统转储与日志菜单 |
| 硬件测试 | `*#0*#` | 屏幕、传感器、震动等硬件逐项测试 |
| USB 模式 | `*#0808#` | USB 连接模式设置 |
| 固件版本 | `*#1234#` | 当前固件版本信息（AP/CP/CSC） |
| 电池状态 | `*#0228#` | 电池详细状态 |
| 服务模式 | `*#0011#` | 网络服务模式信息 |

以上对应关系是三星机型的通行口径，个别机型或系统版本可能不同，以你手机的实际显示为准。

工程菜单里的选项影响系统行为，不认识的项不要乱点；只是想看信息的话，看完退出即可。
