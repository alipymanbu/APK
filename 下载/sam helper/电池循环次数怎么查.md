# Sam Helper 电池循环次数怎么查

> 查三星手机电池循环次数的两种方法：Sam Helper 手机信息页直接看，或用内置 Shizuku 终端跑命令看原始数值。

## 一、循环次数说明什么

电池循环次数是充放电周期数：累计放电量每凑满一个完整周期就计一次。次数越多，电池损耗越大。二手验机时，它是判断「机器用了多久、电池还剩多少成色」的硬指标，比系统设置里的电池百分比更能说明问题。

## 二、方法一：手机信息页直接看

打开 Sam Helper → 「手机信息」页 → 电池循环次数。这个方法不需要 root，也不需要 ADB/Shizuku 授权，日常查看用它就够。这一页还能一起看出厂日期、Knox 状态等信息，见 [查看手机信息与暗码.md](查看手机信息与暗码.md)。

## 三、方法二：Shizuku 终端命令法

Sam Helper 内置了 Shizuku 终端，能以 adb 权限直接执行 shell 命令，适合想看原始数值（健康度、历史最高温度等）的用户：

1. 手机上装好 Shizuku 并完成配对：先在开发者选项里打开 USB 调试与无线调试，再在 Shizuku 里按提示输入配对码、启动服务；
2. 打开 Sam Helper，从右上角的终端图标进入 Shizuku 终端；
3. 执行：

```bash
dumpsys battery | grep -i msave
```

如果终端不支持管道，直接执行 `dumpsys battery`，在输出里找 `mSavedBattery` 开头的字段。

有用户分享的输出示例（数值随机器不同）：

```text
mSavedBatteryAsoc: 100 (电池健康)
mSavedBatteryMaxTemp: 442
mSavedBatteryMaxCurrent: 8124
mSavedBatteryUsage: 23005 (充电循环次数)
```

怎么读：

- `mSavedBatteryAsoc`：电池健康度（百分比）；
- `mSavedBatteryMaxTemp`：历史最高温度，数值除以 10 得到摄氏度（442 → 44.2℃）；
- `mSavedBatteryUsage`：充电循环次数，去掉末尾两位数字就是次数（23005 → 230 次）。

## 四、两种方法怎么选

| | 信息页 | Shizuku 终端 |
| --- | --- | --- |
| 前提 | 无 | Shizuku 配对并启动 |
| 能看到 | 循环次数 | 循环次数、健康度、最高温度等原始字段 |
| 适合 | 日常查看、验机快照 | 想核对原始数值的用户 |

字段口径来自社区分享，个别机型或系统版本的输出可能不同，以你手机的实际结果为准。
