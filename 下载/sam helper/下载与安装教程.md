## 一、Sam Helper 是什么

Sam Helper 是一款运行在三星手机上的系统工具箱，界面按 One UI 风格组织。你可以在里面做这些事：跑气密性测试、改屏幕分辨率与刷新率、调整动画速度、让第三方主题字体通过系统校验、集中管理 Good Lock 与 Galaxy Labs 模块、导出应用安装包或开应用分身、查看出厂日期与电池循环等设备信息，以及一键跳转常用暗码对应的工程菜单。

它的多数功能依赖三星机型的传感器与 One UI 环境（比如气密性测试要有机身气压计），非三星手机装上后大概率只有少数功能可用。系统要求为 Android 5.0 及以上；下面这份 2.8 版已适配 Android 14（One UI 6）。

公开分发渠道已有比 2.8 更新的版本，功能与适配会有差异；本套文档一律以网盘里这份 2.8 为准。安装前想核对文件是否完整，可以在电脑上对下载好的 APK 执行：

```bat
certutil -hashfile samhelper.apk MD5
```

输出的值与上表 MD5 一致，说明文件没有损坏。

## 三、安装步骤

1. 把 APK 下载到手机存储（或先从电脑传过去）。
2. 在文件管理器里点开 APK。首次安装时系统会提示「禁止安装未知来源应用」，按提示跳到设置页，允许「文件管理器」（或你用来打开 APK 的那个应用）安装应用。
3. 回到文件管理器继续安装，完成后打开。

部分厂商定制系统可能额外弹一次风险确认，自行判断后选择是否继续即可。装完不要急着改设置 —— 改分辨率、刷新率、动画速度这几类功能需要先给 app 授「写入安全设置」权限，见下一节。

## 四、装完先做什么

第一步先确认气密性测试能不能跑：从主页顶部图标进入，能读出气压数值说明你的机型带气压计，验机相关的用法见 [气密性测试怎么用.md](气密性测试怎么用.md)。

第二步打算调屏幕参数的话，先做 ADB 授权（需要一台电脑，一次性操作），命令与注意事项在 [改屏幕分辨率与刷新率.md](改屏幕分辨率与刷新率.md) 里。

第三步按需翻 [查看手机信息与暗码.md](查看手机信息与暗码.md)：出厂日期、电池循环、Knox 状态都在「手机信息」页里，二手验机时常用；电池循环次数另有一种命令查法，见 [电池循环次数怎么查.md](电池循环次数怎么查.md)。
