# PUBG Tool 常见问题与解决方法

> 本篇按现象汇总 PUBG Tool 的高频问题：解锁失败、闪退、帧率不生效、键位错乱、安全警告等，每条给出对应处理。

PUBG Tool 的问题大多集中在三类：权限没给够、操作顺序不对、设备或游戏版本不匹配。本篇把这些现象整理成速查表，先对号入座，再按对应步骤处理；处理完仍不行的，多半要等游戏或应用本身的版本适配，文末说明了这种情况怎么判断。

## 一、打开与解锁阶段

| 现象 | 处理方法 |
| --- | --- |
| 提示「无法连接服务器，程序即将关闭」 | 官方公告给出的解法是安装新版 PUBG Tool，版本相关说明见[版本更新与兼容性](版本更新与兼容性.md) |
| 提示「开启失败，请运行游戏后重试」 | 手动赋予存储权限后重启应用；或先手动运行游戏进入大厅，再回来操作 |
| 点「保存并启动游戏」一直转圈 | 安装并激活 Shizuku 后重试，见下文第三节 |
| 解锁后游戏闪退 | 长按「解锁画质帧率」取消解锁，游戏即可正常启动 |
| 提示「未安装」 | 顶部选的游戏版本和手机上装的游戏对不上，改选正确版本 |
| 该弹的权限窗口没弹 | 到「设置 → 应用 → PUBG Tool → 权限」里手动补授存储权限 |

## 二、帧率与画质不生效

这一组问题的根源大多相同：**生效位置在游戏对局内，不在大厅**。

- **大厅里只有 30 帧**：正常现象。和平精英大厅锁定 30FPS，进入对局后再开 120FPS 选项；帧数设置被还原成 30FPS 也不用管，120FPS 实际是生效的。
- **解锁后只有 90FPS**：流畅 / 均衡 / 高清 / HDR高清 / 超高清这几档自带 90FPS。想上 120FPS，把画质调高一挡，或者直接选极清 + 120FPS 再解锁。
- **流畅 + 120 组合选不了**：和平精英已屏蔽这个组合，240FPS 选项也已被移除，这不是应用的问题。
- **帧数选项整个消失**：先关闭和平营地里的「画质提升」功能，再回游戏看。
- **设备怎么都开不了高帧**：游戏没适配你的设备时，无法强开 120 / 144 / 165 / 240FPS；屏幕不支持高刷新率时，开了实际也不会变。
- **解锁后又在游戏里改了画质**：解锁会失效，回 PUBG Tool 重新解锁一次，之后不要再动游戏内画质设置。

## 三、Shizuku 相关

部分设备（尤其系统安全补丁较新的机型）需要通过 Shizuku 授权读写。Shizuku 是独立的开源小工具，需要自己安装并激活：Android 11 及以上走「无线调试」配对，全程不用电脑；Android 10 及以下要连一次电脑。完整的安装、激活步骤与配对失败处理单独成篇，见[Shizuku授权与激活方法](Shizuku授权与激活方法.md)。

不想装 Shizuku 时：1.0.8.8 起应用内提供无需 Shizuku 的读写方式，先在应用右上角确认有「读写方式」选项（没有就先更新应用），换一种方式多数情况能绕开这一步。

## 四、画面与键位异常

| 现象 | 处理方法 |
| --- | --- |
| 改了分辨率后键位错乱 | 不要修改分辨率，或进游戏重新调整键位位置 |
| 游戏画面显示异常 | 依次尝试「画面修复」的各个选项，直到画面正常；或把保存模式从 EC 改成 UC（官方日志口径：UC 方式会在启动游戏时自动删除 EC 配置文件，避开读取冲突） |
| 部分小米手机分辨率不生效 | 把游戏切到小窗再还原全屏 |
| 分辨率调高后卡顿 | 调回默认分辨率，设备性能跟不上时高分辨率只会掉帧 |

## 五、其他

- **双开 / 分身不支持**：PUBG Tool 不支持对双开或分身的游戏生效，用游戏本体。
- **系统弹出安全警告**：官方说明该提示与是否使用本应用无关，人人都会遇到，无需惊慌。
- **手机安全软件提示风险**：2024 年 1 月曾有安全软件将 PUBG Tool 标记为含风险代码，官方随后发布声明否认，称其为免费软件、无广告无病毒（以上为官方声明口径，是否信任由你自行判断）。核对安装包完整性的方法见[下载与安装教程](下载与安装教程.md)。
- **和别的画质工具冲突**：要用 GFX Tool 等其他工具时，先长按「解锁画质帧率」取消本应用的解锁，两边只能留一边。
- **首次使用的建议顺序**：先点「还原」，进一次游戏大厅后退出游戏（关闭后台），再做解锁，完整流程见[使用方法与画质设置](使用方法与画质设置.md)。

以上处理都试过仍不生效时，先确认游戏本体是否刚更新了大版本——应用适配通常滞后几天，等更新而不是反复折腾旧版，版本动态见[版本更新与兼容性](版本更新与兼容性.md)。
