# PUBG Tool 使用方法与画质设置

> 本篇讲 PUBG Tool 的完整操作流程：选游戏版本、解锁画质帧率、SG 优化进阶方案，以及关闭与还原的做法。

PUBG Tool 的日常使用围绕两三个按钮展开：选对游戏版本，点「解锁画质帧率」，再重启游戏。顺序和几个细节决定能不能生效——比如先关掉游戏后台、进对局再开 120 帧。本篇按实际操作顺序把流程走一遍，并列出每一步可能遇到的提示。

## 一、开始前确认三件事

1. **游戏本体已安装**：PUBG Tool 是配合游戏用的，手机上要先装好下面任意一版（官方列出的支持范围）：
   - 和平精英
   - 和平精英（体验服）
   - PUBG MOBILE（国际版）
   - PUBG MOBILE KR（韩国版）
   - PUBG MOBILE VN（越南版）
   - PUBG MOBILE TW（台湾版）
   - PUBG MOBILE BETA（测试版）
   - PUBG MOBILE LITE（轻量版）
   - PUBG MOBILE IN（印度版）
2. **游戏已彻底退出**：从后台划掉和平精英 / PUBG MOBILE，画质帧率选项才能在下次启动时生效。
3. **首次使用先点「还原」**：官方教程建议第一次先执行还原，进一次游戏大厅后再退出游戏（关闭后台），之后再做解锁。

应用还没装的，先看[下载与安装教程](下载与安装教程.md)。

## 二、基础流程：选版本 → 解锁 → 重启游戏

1. **选择游戏版本**：在 PUBG Tool 顶部下拉列表中选择你要修改的游戏版本，默认是中国版（和平精英），玩国际服或其他地区版本就选对应的一项。
2. **点击「解锁画质帧率」**：这是基础方案，多数情况这一步就够了。
3. **按提示处理**：点击后可能遇到三种提示——
   - 未安装：先安装对应的游戏本体；
   - 权限授权：首次使用需授予存储权限，点「授予」；
   - Shizuku 授权：部分设备需通过 Shizuku 授权，先启动 Shizuku 并为本应用授权。
4. **重启游戏**：提示解锁成功后重新进入游戏。建议用 PUBG Tool 里的「保存并启动游戏」直接进，避免自己点图标时后台没清干净。

## 三、进阶方案：SG 优化

在基础方案之上多一步：

1. 先点「开启 SG 优化」；
2. 再点「解锁画质帧率」。

两个注意点：

- 如果之前已经执行过「解锁画质帧率」，要**先长按它取消**，再走进阶方案；
- 长按「开启 SG 优化」或「解锁画质帧率」都可以关闭对应功能，这两个开关都支持长按取反。

## 四、关闭与还原

- **关闭某个功能**：长按对应按钮（解锁画质帧率 / SG 优化）即可取消；
- **游戏闪退时**：长按「解锁画质帧率」取消解锁，游戏即可恢复正常启动；
- **想用其他画质类工具**：先长按「解锁画质帧率」取消本应用的解锁，否则其他工具的修改不会生效——两类工具不要叠加使用。

## 五、决定效果的几条口径

官方教程里反复强调的几条，直接决定解锁后的实际体验：

| 口径 | 说明 |
| --- | --- |
| 大厅 30 帧是正常的 | 和平精英大厅锁定 30FPS，进入对局后再开 120FPS 选项才会生效；帧数设置显示被还原为 30FPS 也不用管，实际以对局内帧率为准 |
| 120 帧要画质调高一挡 | 流畅 / 均衡 / 高清 / HDR高清 / 超高清自带 90FPS，想把 120FPS 用起来，需要把画质调高一挡（例如均衡 → 高清），或直接选极清 + 120FPS |
| 流畅 + 120 开不了 | 和平精英已屏蔽该组合，240FPS 选项也已被移除 |
| 解锁后别动游戏内画质设置 | 解锁成功后不要再在游戏里改画质选项，否则解锁会失效 |
| 分辨率建议默认 | 分辨率调高会增加负载导致卡顿，部分设备改分辨率还会键位错乱、画面异常，拿不准就用默认 |
| 实际帧率有上限 | 部分设备的最高帧率受系统限制，屏幕不支持高刷新率时，开高帧选项实际意义不大 |

## 六、提示与报错速查

| 提示 | 含义与处理 |
| --- | --- |
| 开启失败，请运行游戏后重试 | 手动赋予存储权限后重启应用，或先手动运行游戏进入大厅再回来操作 |
| 点「保存并启动游戏」转圈无反应 | 需要安装并激活 Shizuku，见[常见问题与解决方法](常见问题与解决方法.md) |
| 解锁成功但游戏闪退 | 长按「解锁画质帧率」取消解锁即可恢复 |

更多按现象排查的条目（帧数选项消失、键位错乱、安全警告等）集中在[常见问题与解决方法](常见问题与解决方法.md)。
