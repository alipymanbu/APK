PUBG Tool 生态里有免费主线（1.x 与 2.x 两条版本线）和一条独立的 Pro 付费产品线，安装包互不相同、节奏也不同。弄清自己用哪条、什么时候该更新，能省掉「更新后反而不会用了」的麻烦。本篇以网盘收录的 1.0.8.8 为基准，把版本与兼容的事说清。

## 一、版本线与产品线

| 版本线 | 名称 | 说明 |
| --- | --- | --- |
| 1.x | PUBG Tool / pubgtool画质助手 | 经典版本线，本篇对应的安装文件 1.0.8.8 属于这一线，免费使用 |
| 2.x | PT画质助手（PUBG Tool 2.0） | 官方 2026 年 3 月发布的重构版本（官方称采用 Kotlin 重写），应用市场条目与 1.x 的包名不同，是独立的新安装包 |
| Pro | PUBG Tool Pro | 官方的另一条付费产品线，可调项更细（分辨率、画面修复、保存模式等），官网为 [pubgtool.pro](https://www.pubgtool.pro)，与免费线是不同产品 |

几点实用结论：

- 三条线互不相同，装了其中一个不代表装了另一个；
- 搜「pubgtool」时几条线的说法都会出现，对信息前先看版本号与包名属于哪条线。

## 二、1.0.8.8 更新了什么

官方更新日志列了五项：

1. 适配 Android 2024-02-01 安全补丁更新（无需 Shizuku）；
2. 适配 Android 2024-02-01 安全补丁更新（Shizuku API）；
3. 修复若干 BUG，提升稳定性；
4. 新增 Shizuku 读写方式；
5. 新增原生读写方式。

对使用影响最大的是读写方式：这一版起，应用内可以按设备情况选「无需 Shizuku」「Shizuku」「原生」几种读写方式，对应不同的系统补丁情况。遇到授权或解锁失败时，先在应用里换一种读写方式，这是官方给出的第一处理手段，其余排查见[常见问题与解决方法](常见问题与解决方法.md)；确需 Shizuku 时，安装与激活步骤见[Shizuku授权与激活方法](Shizuku授权与激活方法.md)。

## 三、系统兼容口径

| 事项 | 口径 |
| --- | --- |
| 1.x 系统支持 | 官方对 1.0.8.x 世代的说法是全面支持 Android 8–16，兼容 Shizuku 模式 |
| 2.x 系统支持 | 应用市场收录的 2.x 条目标注 Android 7.0 以上；2026 年 9 月的 2.x 版本已标注适配 Android 17 |
| 兼容性变化 | 系统补丁、游戏版本更新都可能让旧版失效，属于常态，随应用更新解决 |

以上为官方页面与渠道页面的口径，会随版本演进变化，以官方页面为准。手机系统过新或过旧时，装不上、闪退、解锁无效都可能出现：先升级到所在线的最新版，仍不行就等下一版适配，见下文「什么时候该换版本」。

## 四、什么时候该换版本

- **提示「无法连接服务器，程序即将关闭」**：官网公告明确说安装新版即可解决，这是最典型的该更新信号；
- **游戏本体大版本更新后失效**：应用适配通常滞后几天，等更新而不是反复折腾旧版；
- **旧版可以自己选**：官网为偏好旧版的用户保留了 1.0.8.5 等旧版本的下载入口；不过「能连上服务器、能解锁」优先于「用旧版」。

官网入口为 [pubgtool.cn](https://www.pubgtool.cn)，版本公告与更新日志都发布在这里，具体信息以官网当时显示为准。

## 五、怎么查当前版本

- **系统里查**：「设置 → 应用管理 → PUBG Tool」，版本号与包名都在应用信息里；包名 `com.xingguang.xgpubg` 对应本篇说的 1.x 安装文件；
- **应用内查**：部分版本在「关于」或设置页里有版本信息；
- **对不上怎么办**：手机上的版本与网盘文件版本不一致，说明装过别的版本，重新获取并安装即可，步骤与核对方法见[下载与安装教程](下载与安装教程.md)。
