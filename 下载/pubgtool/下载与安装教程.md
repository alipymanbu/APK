PUBG Tool 是一款为和平精英与 PUBG MOBILE 玩家开发的安卓画质助手。装好它只需几分钟，容易出问题的地方是「拿错安装文件」和「跳过权限授权」：本篇先给出安装包的核对信息，再带你走完获取、安装、首次打开三步，最后教你确认手机上装的就是这一版。

## 一、安装前先核对版本信息

叫「pubgtool」的应用不止一个，先对信息再安装。下面是本篇对应的这份安装包的实测信息：

| 项目 | 信息 |
| --- | --- |
| 应用名称 | PUBG Tool（也叫 pubgtool画质助手） |
| 版本 | 1.0.8.8 |
| 包名 | `com.xingguang.xgpubg` |
| 安装包大小 | 27.07M |
| MD5 | `CA7CEE61C09B122624D0E8F5E32438A0` |

这份信息有两个用途：

- **认包名**：装完后在「设置 → 应用管理」里能看到包名。名字相同的其他应用包名不一样，认包名比认名字可靠。
- **核对 MD5**：在电脑上执行下面的命令（路径换成实际位置），算出的值与表格一致，说明文件没有损坏或被替换：

```powershell
certutil -hashfile "D:\Downloads\pubgtool.apk" MD5
```

系统要求方面，官方对这一代版本的口径是全面支持 Android 8 至 Android 16，以官方页面为准。另外它是配合游戏使用的，手机上需要先装好和平精英或 PUBG MOBILE 的某一版本，具体支持哪些游戏版本，在[使用方法与画质设置](使用方法与画质设置.md)里列了完整清单。

## 二、获取安装文件

安装文件放在夸克网盘：[PUBG Tool 安装文件资源（夸克网盘）](https://pan.quark.cn/s/702161f962a5)。

1. 打开链接进入网盘页面；
2. 将文件转存到自己的网盘账号，再从网盘 App 或网页端下载；
3. 下载完成后得到一个 `.apk` 文件，这就是安装包。

下载速度慢多半是网盘高峰期，换个时段再下即可，不需要反复取消重试。

## 三、安装步骤

1. 打开下载好的 `.apk` 文件；
2. 系统弹出「不允许安装未知来源应用」时，按提示允许浏览器或文件管理器安装应用（不同品牌手机的开关入口略有差异，一般就在弹窗里直接给）；
3. 回到安装界面点「安装」，等待完成；
4. 点「打开」进入应用，或稍后从桌面图标进入。

安装时如果提示解析失败或安装失败，通常是文件没下载完整，重新下载一遍再装；换一个文件管理器打开也常能解决。安装或首次打开时若被手机安全软件拦截提示，相关口径的说明见[常见问题与解决方法](常见问题与解决方法.md)。

## 四、首次打开要给的权限

第一次打开 PUBG Tool，按需要给两类授权：

- **存储权限**：解锁画质帧率时要用到，弹窗出现时点「允许」。如果当时点了拒绝，后面解锁会提示失败，去「设置 → 应用 → PUBG Tool → 权限」里手动补上即可。
- **Shizuku 授权（部分设备）**：个别系统补丁较新的手机，应用会提示需要通过 Shizuku 读写。Shizuku 是另一个免费小工具，装好并激活后回到 PUBG Tool 完成授权即可，步骤见[常见问题与解决方法](常见问题与解决方法.md)。

## 五、装好之后

装完先花十秒核对：进入「设置 → 应用管理」找到 PUBG Tool，确认包名是 `com.xingguang.xgpubg`、版本是 1.0.8.8，与第一节的表格一致。

确认无误后就可以正式使用了，操作流程见[使用方法与画质设置](使用方法与画质设置.md)；如果卡在某一步，[常见问题与解决方法](常见问题与解决方法.md)按现象列了对应的处理办法。
