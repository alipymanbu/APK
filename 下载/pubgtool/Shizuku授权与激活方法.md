# PUBG Tool 的 Shizuku 授权与激活方法

> 本篇讲 PUBG Tool 什么时候需要 Shizuku、Shizuku 怎么安装激活，以及配对失败、重启后失效等状况的处理。
> **相关文档**：[常见问题与解决方法.md](常见问题与解决方法.md) · [使用方法与画质设置.md](使用方法与画质设置.md)

---

> **PUBG Tool 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/702161f962a5](https://pan.quark.cn/s/702161f962a5)

Shizuku 是一个给普通应用提供系统级读写能力的小工具，PUBG Tool 在部分手机上（尤其系统安全补丁较新的机型）要借助它才能完成画质配置的写入。本篇讲清三件事：什么情况才需要装它、Android 11 以上和以下分别怎么激活、激活后怎么回到 PUBG Tool 完成授权。

## 一、先确认是否真的需要

出现下面任一情况，才需要走本篇流程：

- 点「保存并启动游戏」一直转圈（官方 FAQ 给出的对应解法就是装 Shizuku）；
- 应用内明确提示需要 Shizuku 授权；
- 存储权限已给、游戏也进过大厅，解锁仍然失败。

先别急着装：1.0.8.8 起应用内提供多种读写方式，部分设备选「无需 Shizuku」的方式就能用——先在应用右上角「读写方式」里换一种试试。为什么会有多种读写方式，见[版本更新与兼容性](版本更新与兼容性.md)。

## 二、安装 Shizuku

Shizuku 是独立的开源应用，不随 PUBG Tool 附带，需要单独安装：

1. 打开 GitHub 上的 [Shizuku Releases](https://github.com/RikkaApps/Shizuku/releases) 页面，下载最新版中的 `shizuku-xxx-release.apk`；
2. 打开下载好的文件完成安装，系统给出的常规安全确认按提示确认即可。

## 三、激活方式一：无线调试（Android 11 及以上）

这是不需要电脑的方式。配对只需做一次，但受系统限制，**手机每次重启后都要重新点一次「启动」**：

1. 打开「设置 → 关于手机」，连续点击版本号数次，直到提示已进入开发者模式（不同品牌入口略有差异，例如 vivo 在「系统管理 → 关于手机 → 版本信息」里连点软件版本号）；
2. 在「开发者选项」中开启「USB 调试」和「无线调试」；
3. 打开 Shizuku，在「通过无线调试启动」板块点「配对」，按提示授予通知权限；
4. 进入系统的「无线调试」页面，点「使用配对码配对设备」，弹窗里会显示一串配对码；
5. 下拉通知栏，在 Shizuku 的通知里输入这串配对码并确认；
6. 回到 Shizuku 点「启动」，状态变为运行中即成功。

启动失败时，把系统的「无线调试」开关关掉再重新打开，然后重试。

## 四、激活方式二：连接电脑（Android 10 及以下）

老系统没有无线调试，需要一台电脑配合：

1. 在电脑上下载 Google 官方的 SDK 平台工具（platform-tools）并解压到任意文件夹；
2. 手机开启 USB 调试后用数据线连接电脑，首次连接时在手机上确认调试授权；
3. 在解压目录打开终端执行：

```shell
adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
```

已 root 的设备不用这么折腾：在 root 管理器里给 Shizuku 授权，然后直接在应用内点「启动」。

## 五、回到 PUBG Tool 完成授权

1. 保持 Shizuku 在后台运行——它的服务被系统杀掉就会失效；
2. 打开 PUBG Tool，在弹出的授权提示里允许，或在应用内「读写方式」里选择 Shizuku 方式；
3. 之后按正常流程操作即可，步骤见[使用方法与画质设置](使用方法与画质设置.md)。

## 六、常见状况

| 状况 | 处理 |
| --- | --- |
| 一直显示「正在搜索配对服务」 | 确认手机连的是 WLAN 而不是移动网络，且系统「无线调试」开关处于开启状态 |
| 输入配对码后立刻失败 | 回到系统「无线调试」页重新点「使用配对码配对设备」生成新码，再输入一次；仍失败就关掉再重开无线调试 |
| 手机重启后 PUBG Tool 又提示需要授权 | 正常现象（系统限制），打开 Shizuku 重新点「启动」即可 |
| Shizuku 显示运行中但 PUBG Tool 没反应 | 在 PUBG Tool 的读写方式里切走再切回，触发一次授权；仍不行就把两个应用都从后台清掉重开 |
