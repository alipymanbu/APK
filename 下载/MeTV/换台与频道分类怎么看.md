## 一、打开就是直播画面，不用先注册

多数点播类应用打开先给你一个首页和登录框，MeTV 不是这个路子：装好点开，直接进的就是电视直播画面，不用注册也不用登录就能看。对只想「打开电视有个台在响」的人来说，这一步省得很实在。

打开后你能看到的东西大致分两块：

| 区域 | 里面是什么 |
| --- | --- |
| 直播 | 央视、卫视、地方台、高清、体育、少儿等不同类型的频道 |
| 点播 | 电影、电视剧、综艺这类可以自己挑着看的片子 |

看腻了直播切到点播搜一部片子，是它比较常见的用法；两块内容在同一个应用里，不用另外再装一个影音应用。

## 二、换台的两种操作方式

**手机上**：画面是触摸操作的。手指点一下屏幕会把选台菜单唤出来，在菜单里选中想看的频道即可，菜单会自己收回去。

**电视和盒子上**：手上只有遥控器，操作逻辑与多数电视直播应用一致 —— 用方向键把光标移到想看的频道上，按 OK／确定键进去。遥控器上的返回键用来退出选台菜单或退回上一个界面；菜单键、帮助键这类按键在不同的遥控器上叫法不同，实际能不能唤起面板以你的设备为准。

换台的几条经验：

- 换台之后画面出画需要一两秒，尤其是高清台，别连着按 —— 连按会让上一路信号还没断、下一路已经开始连，反而更慢。
- 手滑点错台，不用回到列表重找，直接在画面里唤出选台菜单再选一次。
- 有些台在列表里能看到但点开是黑的，那是这一路信号的问题，不是操作错了，换台或换源都能绕开，处理办法见 [直播卡顿与频道打不开怎么排查.md](直播卡顿与频道打不开怎么排查.md)。

## 三、按类型找台：别一个个翻

频道是按类型归好类的，找台先想清楚要看哪一类，再去对应的分类里挑，比从头翻到底快得多。常见的分类和里面的内容大致是这样：

| 分类 | 大致包含 |
| --- | --- |
| 央视 | 中央台的各个频道，新闻、综艺、纪录等 |
| 卫视 | 各省上星频道，适合看热播剧和综艺 |
| 地方台 | 各省市本地频道，想看家乡的节目从这里找 |
| 高清 | 单独归到高清一档的频道 |
| 体育 | 赛事直播与体育资讯类频道 |
| 少儿 | 动画与少儿节目 |

同一类里频道多的时候，靠遥控器一路按下去很费劲，可以结合选台菜单里的排序或搜索入口找；搜索入口对点播那块的用处更明显，直接输入片名比翻分类快。

## 四、点播区怎么用

直播之外，点播区放的是电影、电视剧、综艺这类片子。用法和常见的影视应用一样：进分类挑，或者搜片名。两点提醒：

- 点播是跟着网络走的，网络差的时候点播比直播更容易卡在缓冲圈上，这种时候先看直播更省事。
- 网络条件一般的话，别一上来就挑高分片源的超清档，先从默认清晰度看，能流畅播放再往上调。

## 五、找不到想看的频道

先分清是哪一种「找不到」，处理方式完全不同：

| 现象 | 多半原因 | 怎么办 |
| --- | --- | --- |
| 整个选台列表是空的 | 频道数据没拉下来，多半是网络问题 | 退出应用重进；仍为空就换一个网络（手机热点）再试 |
| 列表正常，但就是要找的那个台没有 | 这个应用没收录该频道 | 换同类型的其他台；不要指望同类应用把每个台都收全 |
| 能找到这个台，点开是黑的或一直转圈 | 这一路信号此刻不通 | 换其他台验证一下，再回来看是不是恢复了；一直不行见 [直播卡顿与频道打不开怎么排查.md](直播卡顿与频道打不开怎么排查.md) |
| 昨天还在列表里的台今天没了 | 频道列表会随版本和数据更新变动 | 以应用内实际显示的列表为准 |

如果你在同一台设备上还装了别的直播应用，遇到某个台在 MeTV 上看不了，用另一个应用对照着试一次，能很快判断是「这个台本身没信号」还是「MeTV 这一路源不通」。
