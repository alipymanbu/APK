## 一、装之前先对一遍版本和要求

下面这张表是网盘里那份包的实际情况。网上搜到的「最新版」往往已经是另一个版本号，装之前以这张表为准，装完也可以在设备上核对。

| 项目 | 值 |
| --- | --- |
| 应用名 | MeTV |
| 包名 | `com.eztv.test` |
| 版本 | 6.1.0 |
| 安装包大小 | 15.99M |
| 安装包 MD5 | `5428D736FE90044FEC70E4922A4F5F53` |
| 系统要求 | 安卓 5.2 及以上 |
| 界面语言 | 简体中文 |

三条判断：

- 系统低于安卓 5.2 的设备（部分老盒子和老电视）装上去多半提示不兼容，或者装完一点就退，别在这类设备上耗时间。
- 设备留出 30M 以上的空闲空间再装，安装过程还要额外占一点。
- 这是一份安卓安装包，手机、平板、智能电视、安卓盒子都能装。公开资料把它的定位写成「为电视盒子和智能电视打造」，所以电视端才是它主要的用法；随手装在手机上也能看，只是换台靠触摸而不是遥控器。

## 二、从网盘把安装包取到设备

1. 打开 [MeTV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b827f6f32a6b)。
2. 先点「保存到我的网盘」，再从自己的网盘里下载。直接下载也能用，但转存之后原分享失效了也不影响你自己那份。
3. 手机上下载完，记下文件位置，浏览器一般放在「下载」或「Download」目录；文件名通常形如 `MeTV_v6.1.0.apk`，以网盘里实际显示的名字为准。
4. 要装到电视或盒子上，别在电视自带的浏览器里去下：电视端浏览器普遍不好操作，也容易下到一半断掉。更稳的做法是在电脑或手机上下好，再按第三节把它送进电视。

## 三、装到智能电视 / 安卓盒子上

两条路，按你手头的条件挑一条。

| 方式 | 需要什么 | 适合的情况 |
| --- | --- | --- |
| U 盘 | 一个 U 盘，电视上有文件管理器 | 电视上没装过任何第三方应用市场，最通用 |
| 电视端工具 | 电视能上网，且已装有一个带「远程推送」或「U 盘安装」功能的应用市场 | 电视上已经在用当贝市场、欢视助手这类工具 |

U 盘这条路，按顺序做：

1. 在电视或盒子的设置里，把「安装未知来源的应用」改成允许。这个开关的位置各品牌不一样，常见叫法是「账号与安全」「安全」「通用」，记不住就到设置顶部的搜索里搜「未知来源」。
2. 把 `MeTV_v6.1.0.apk` 拷到 U 盘根目录，U 盘插进电视的 USB 口。U 盘最好是 **FAT32** 格式 —— 安卓电视和盒子对 NTFS 格式经常不认，而「插上 U 盘什么都没发生」正是这一步最常见的失败原因，格式转换与不识别的排查见 [U盘安装失败与识别不了怎么排查.md](U盘安装失败与识别不了怎么排查.md)。
3. 电视通常会弹出「检测到新的 USB 设备」，选「打开 U 盘」；没有弹窗，就自己到「应用」或「我的」里的本地媒体、U 盘入口去找。
4. 找到那个 apk 点它，按提示装完；回到桌面能看到图标。
5. 有些品牌（例如部分 TCL 机型）自带的文件管理器不给直接安装，要先在电视已有的第三方工具（如欢视助手）里进「管理 → U 盘 → 安装包」再点开装。

如果电视上已经有带远程推送功能的应用市场，也可以直接在电脑或手机浏览器扫码上传 apk，让电视那边自己下载安装，省掉 U 盘的来回。

## 四、装到手机上

手机这条路要短一些，四个动作：

1. 先在系统里放行「未知来源」。网盘里的包不是从应用商店装的，安卓默认会拦一次，要给负责下载的那个应用（浏览器或夸克）开安装权限：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 权限管理 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装外部来源应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 原生安卓 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

2. 打开文件管理器，到「下载」目录找到那个 `.apk` 点开，安装界面点「安装」。
3. 首次启动会弹权限申请。真正影响能否正常看的是下面这几项，其余的给不给都不影响：

| 权限 | 不给会怎样 |
| --- | --- |
| 网络 | 频道列表和画面都加载不出来 |
| 存储 / 照片和视频 | 播放缓存写不进去，换台、回看时更容易卡 |
| 通知 | 只影响消息提醒，不影响观看 |

4. 装好后桌面会出现图标，名称以实际显示为准。名字和「MeTV」有出入时不用怀疑装错了，认包名更可靠，核对方法见 [同名应用与版本怎么认.md](同名应用与版本怎么认.md)。

## 五、装不上、装完打不开

按顺序自查，比反复重装有效：

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」「应用未安装」 | 安装包没下完整，或设备系统版本低于要求 | 重新下载一次；仍报错就看设备系统版本是否低于安卓 5.2 |
| 提示「已被阻止安装」 | 「未知来源」没开，或者开给了错误的那个应用 | 回到第三节、第四节把开关打开，注意要开给实际负责安装的那个应用；安卓 8 及以上没有全局开关，要按来源逐个授权，见 [U盘安装失败与识别不了怎么排查.md](U盘安装失败与识别不了怎么排查.md) |
| 装到一半提示空间不足 | 剩余存储不够 | 先清出不小于 15.99M 的空间，再多留一点余量 |
| 电视上找不到 apk 文件 | U 盘格式或插口问题，也可能文件被放进了子文件夹 | 把 apk 放到 U 盘根目录、把 U 盘格成 FAT32 再试；完整排查见 [U盘安装失败与识别不了怎么排查.md](U盘安装失败与识别不了怎么排查.md) |
| 装好后点图标闪一下就退 | 系统版本偏低，或该设备解码能力跟不上 | 换一台设备试；具体排查见 [常见问题与排查.md](常见问题与排查.md) |

装好之后的换台、找台，见 [换台与频道分类怎么看.md](换台与频道分类怎么看.md)；画面卡住、频道打不开，见 [直播卡顿与频道打不开怎么排查.md](直播卡顿与频道打不开怎么排查.md)。
