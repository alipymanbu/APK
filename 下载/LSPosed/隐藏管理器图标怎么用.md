# LSPosed 隐藏管理器图标怎么用

管理器（包名 `org.lsposed.manager`）本身是个普通应用，装完之后启动器里会留一个图标。LSPosed 的管理器带一个隐藏入口，开启后这个图标就不再出现在启动器里，界面改由拨号盘拉起。本篇讲这个开关怎么用，以及隐藏之后那些容易忘掉的事。

## 一、什么时候需要隐藏

先说清它不是必选项。管理器的图标放在桌面上不影响任何功能，只有下面这几种情况才值得藏：

- 手机常被别人拿着用，不想让桌面多出一个看不懂的应用图标；
- 桌面应用比较多，想减少一个不常用的图标；
- 你习惯用拨号盘这种固定入口，觉得图标反而多余。

## 二、怎么打开隐藏

1. 打开管理器；
2. 进设置，找到管理器的隐藏入口（不同版本里它的名称略有差异，通常是「隐藏管理器」一类）；
3. 打开之后，启动器里的图标会消失。部分机型的启动器需要几秒刷新，或者切换一次桌面再回来看。

隐藏只影响「有没有图标」，**不影响已经装好的模块与作用域**，也不用重启整机。

## 三、藏起来之后怎么再打开

三条路，按顺序试：

1. **拨号盘**：输入 `*#*#5776733#*#*`。这是 LSPosed 的固定入口，管理器藏起来、图标被删掉的情况下依然有效（`5776733` 是 `LSPOSED` 在九宫格键盘上对应的数字）；
2. **通知**：如果状态通知还开着，重启后状态栏会出现管理器入口，点它同样能进；
3. **把图标装回来**：取消隐藏后图标会恢复；如果之前连应用一起删了，可以装一次 [LSPosed 安装文件资源（夸克网盘）](https://pan.quark.cn/s/293a930cd5dc) 里的那份管理器，包名一致，会覆盖安装。

第三条路也是隐藏功能最实用的兜底：就算你把「怎么打开管理器」这件事忘干净了，只要还记得拨号码，一般都能进得去。

## 四、隐藏之后要注意的三件事

| 要留意的事 | 说明 |
| --- | --- |
| 卸载别找不到入口 | 要卸载管理器，得先从手机「设置 → 应用管理」里按包名 `org.lsposed.manager` 找到它，桌面上已经没图标可点了 |
| 部分桌面整理工具会误判 | 有些桌面清理、图标整理类应用会把「没有图标的已安装应用」当成可疑项，遇到提示时不要随手清掉 |
| 通知开关与隐藏是两件事 | 关掉状态通知、和隐藏图标互不影响，可以只做一个；把两个都关掉之后，能想到的入口基本就只剩拨号码了 |
| 还有一个「自动添加快捷方式」类开关 | 关掉之后重启不再弹「是否创建桌面快捷方式」的提示。它管的是提示，不是图标本身，和隐藏功能各管一段 |

## 五、和「应用提示设备被改动」不是一回事

装上框架之后，你可能会遇到某个应用打开就退出、或者弹出「设备不符合安全要求」一类的提示。这是**那个应用自己的保护策略**——它察觉到运行环境被改动，选择限制自己的功能。这和管理器图标藏不藏没有任何关系，隐藏图标不会改变这类应用的行为。

Magisk 里有一个官方机制叫排除列表（部分版本里叫 DenyList）：把应用加进这个列表，它就不会被注入任何 Zygisk 模块。作为交换，**这个应用里也就不能再用 LSPosed 的模块了**——把某个应用加进排除列表，等于放弃了在那个应用上挂模块的可能，这是个明确的取舍，不是免费的开关。

至于应用具体靠什么判断、怎么判断，各家规则都在变，没有哪种做法能保证对所有应用长期有效，本篇也不做这方面的承诺。你只要记住一件事：一旦某个应用开始限制自己，先确认是不是刚给它勾过作用域或刚改过系统环境，把变量退回去，往往比继续折腾更省时间。

如果隐藏之后你连框架状态都看不到了（比如拨号码也进不去、通知也被关了），最省事的做法是直接在 Magisk 里停用 LSPosed 模块再重启，把环境退回干净状态，步骤见 [卸载与恢复原状.md](卸载与恢复原状.md)。
