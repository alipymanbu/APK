# LSPosed 下载与安装教程

> 本篇讲清网盘里这份 LSPosed 是哪一支、在已 Root 的安卓手机上要走哪几步才能用起来，以及第一次打开要确认什么。

LSPosed 是安卓上的一个 Xposed 实现：模块能在你指定的应用进程里生效，而不改动任何 APK。它面向已经 Root 并装了 Magisk 的手机，这是硬门槛。本篇只解决一件事：把这份包装上，并让管理器第一次打开就能认到框架。

## 一、先弄清网盘里这份是哪一版

网上搜到的多半是发布时的最新版，网盘里这份是整理文档时核对过的那一版，两者未必是同一个版本号。下面这些值以网盘里那份包为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | LSPosed |
| 版本号 | 1.9.3 |
| 包名 | `org.lsposed.manager` |
| 登记体积 | 2.62 MB |

包名这一栏最关键：`org.lsposed.manager` 对应的是 LSPosed 的**管理器**（LSPosed Manager），也就是你用来查看框架状态、勾选模块作用域的那个界面。

LSPosed 的完整安装包是一个 Root 管理器模块（在 Magisk 上就是 Magisk 模块，KernelSU 上是它的同类模块），管理器界面就打包在里面，装上模块重启后会一起出现；而网盘里这份是**管理器单独那一个 APK**。所以有一件事要先说清楚：**光装这个 APK 不会带来框架本体**，管理器打开后只会告诉你框架还没装上。它真正派得上用场的是下面这几种情况：

- 模块装上、重启之后，启动器里没出现管理器图标（部分启动器不弹「是否创建快捷方式」的提示，就静默跳过了）；
- 之前把管理器删了，想装回来；
- 想在另一台设备上先把界面装上看一眼。

体积一栏只当参考——同一个版本在不同来源给出的体积未必一致，判断是不是同一个应用看包名，判断是哪一版看版本号。

## 二、装之前先确认两件事

**第一，设备必须已经 Root，并且装好了 Magisk。** 官方对这一支的要求是 Magisk v24 及以上；Riru 路线则要求先装 Riru v26.1.7 及以上。验证方式很直接：打开 Magisk，能看到版本号、且状态显示已安装，就算过。

**第二，系统版本要在支持范围内。** 官方 README 给 1.9.x 这一支写的范围是 Android 8.1 到 Android 14；后来的分支把范围往上扩了，具体以官方页面当时显示为准。机型不在范围内时，最典型的症状不是装不上，而是装完重启后框架起不来、管理器一直显示未激活。

这两条都属于「不改动系统就绕不过去」的前提，本篇不展开 Root 本身的步骤——没 Root 的话，先去看 [和Xposed有什么区别.md](和Xposed有什么区别.md)，那里说明了为什么这个框架离不开 Root，以及有没有不用 Root 的替代路线。

## 三、装框架本体（Magisk 模块）

框架本体不在网盘里，需要从官方发布页取，文件名形如 `LSPosed-v<版本号>-<构建号>-zygisk-release.zip`（以官方页面当时显示为准）。选哪一支按你现有的环境定：

| 你的环境 | 取哪一个包 | 前置 |
| --- | --- | --- |
| Magisk 里已打开 Zygisk | `zygisk-release.zip` | Magisk v24+，Zygisk 已开启 |
| 设备用 Riru（旧机型或特定 ROM） | `riru-release.zip` | 已装 Riru v26.1.7+ |

如果你用的是 **KernelSU 或 APatch**，上表的前提要换个说法：这两种 Root 方案本身不含 Zygisk，得先装一个提供 Zygisk 环境的模块，才能接着装 LSPosed，完整步骤见 [不用Magisk的Root环境怎么装.md](不用Magisk的Root环境怎么装.md)。

**Zygisk 路线（推荐先试这一条）：**

1. 打开 Magisk，进设置，把 **Zygisk** 这一项打开，然后重启手机；
2. 把上表对应的包传进手机存储（放 `Download` 目录就行）；
3. Magisk → 底部「模块」→ 「从本地安装」，选中这个包，等它装完；
4. 出现重启按钮后重启。重启完成时状态栏会有一条 LSPosed 的通知，点它就能打开管理器。

**Riru 路线：** 先按同样的方式装 Riru，重启确认生效，再装 `riru-release.zip`，再重启。**Zygisk 与 Riru 二选一**，两个环境同时装上是常见的翻车原因。

如果重启后卡在开机动画进不去系统，不要反复重启试探，直接看 [开机卡住进不去系统怎么救.md](开机卡住进不去系统怎么救.md)，三条救援路径都在那篇里。

## 四、把管理器装上（网盘里这份）

框架装好之后，管理器通常已经跟着出现了。只在没出现、或者你主动删过的情况下，才需要手动装一次：

1. 从 [LSPosed 安装文件资源（夸克网盘）](https://pan.quark.cn/s/293a930cd5dc) 把这份 APK 转存到自己的网盘，再下载到手机；
2. 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用放开开关；
3. 点安装。包名与框架自带的管理器完全一致，属于覆盖安装，已有的模块开关与作用域设置会保留。

还有一条不用装任何东西的入口：在拨号盘输入 `*#*#5776733#*#*` 就能直接拉起管理器。这个号码在管理器被隐藏、图标被删掉的情况下照样有效，后面 [隐藏管理器图标怎么用.md](隐藏管理器图标怎么用.md) 会用到它。

## 五、第一次打开要确认三件事

| 要做的事 | 在哪看 | 不做的后果 |
| --- | --- | --- |
| 确认框架状态 | 管理器首页的状态区 | 显示未激活就别急着装模块，先回头查 Zygisk 与系统版本 |
| 决定要不要状态通知 | 管理器设置里的通知开关 | 不开不影响功能，只是状态栏会常驻一条通知 |
| 装一个模块试手 | 见 [模块怎么激活与作用域怎么设置.md](模块怎么激活与作用域怎么设置.md) | 不装模块的话，框架本身不改变手机的任何行为 |

## 六、装完做一次最小验证

1. 打开管理器，看首页是不是显示框架已激活；
2. 随便装一个 Xposed 模块的 APK，回到管理器的「模块」页，看它有没有出现在列表里；
3. 给这个模块勾一个作用域（挑一个不重要、丢了也不心疼的应用），重启该应用；
4. 观察模块说明里描述的效果有没有出现。

第 2 步能出现、第 3 步勾得上，说明框架与管理器这条链路是通的，剩下的问题基本都出在单个模块或单个应用上，排查方法在 [模块装了不生效怎么排查.md](模块装了不生效怎么排查.md)。

## 七、以后出了新版本怎么升级

网盘那条分享是长期有效的：换版本时替换的是里面的文件，**分享链接本身不变**，升级不用重新找地址。

1. 框架主体是新版本时，在 Magisk 的模块页用新的 zip 覆盖安装，再重启；
2. 管理器是新版本时，直接装新的 APK 覆盖即可，设置保留；
3. 两者尽量配套升级——管理器与框架本体的版本差太多时，界面可能出现读不到状态的情况；
4. 升级前建议先按 [卸载与恢复原状.md](卸载与恢复原状.md) 记一下当前启用了哪些模块、各自的作用域，万一新版起不来，恢复起来有据可依。

有两点自己留意：它不是从手机自带应用商店装的，商店不会替第三方来源的应用提示更新，想保持新版得隔一段时间回来看一眼；另外，系统大版本更新（OTA）之后，Zygisk 的相关设置有时会被重置，更新完建议回 Magisk 复查一次。
