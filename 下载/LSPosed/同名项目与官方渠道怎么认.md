搜 LSPosed 的时候，你会同时撞上几个名字很像的项目，以及大量流传的旧教程——里面有的信息已经过期，有的干脆写的是另一个软件的流程。本篇只做一件事：告诉你哪些是官方渠道、这个应用该拿什么来认，以及那几个容易混的名字各自是什么。

## 一、官方渠道只有这几处

| 用途 | 地址 |
| --- | --- |
| 框架本体（模块包的发布页） | `https://github.com/LSPosed/LSPosed` |
| 模块仓库 | `https://modules.lsposed.org` |
| 官方文档 | `https://docs.lsposed.org` |

管理器是随框架一起发布的，也可以在官方渠道单独取得。**官方的发布物都是模块包（zip）与管理器 APK**，不会以「一键安装器」「整合包」「带配置的懒人版」这类形式出现——遇到这类包装，无论说得多么方便，都不是官方发布物。

## 二、用包名认，不要用名字认

框架本体以 Root 管理器的模块形式安装（Magisk 上是 Magisk 模块，KernelSU、APatch 上是它们的模块），管理器是个独立应用，包名是：

```
org.lsposed.manager
```

判断手机里装的是不是它，看包名最稳：应用市场里叫 Xposed、LSPosed 的应用不止一个，图标和名字都可能撞车，系统区分它们靠的正是包名。装完在「设置 → 应用管理」里回看一眼即可。

## 三、版本号怎么读

- **版本号形如 `1.9.x`**，官方还会在后面附一个构建号，例如模块包的文件名形如 `LSPosed-v1.9.2-7024-zygisk-release.zip`；
- 文件名里的 `zygisk` / `riru` 说明它对应哪种运行环境，**选错环境装上去不会报错，只是不生效**；
- 具体的版本号与文件名会随发布变化，**以官方发布页当时显示为准**，不要照着一份旧教程里的文件名去找。

网盘里那份的版本号与包名以 [下载与安装教程.md](下载与安装教程.md) 第一节的表格为准。

## 四、几个容易混的名字

| 名字 | 是什么 | 和你手上的这份是什么关系 |
| --- | --- | --- |
| LSPosed | 本项目 | 就是它 |
| Vector | 同一套技术路线的社区分支，由另一位维护者接手继续维护 | 模块生态通用，但它不是本项目，版本号体系与官方发布页也不一样 |
| EdXposed | LSPosed 的前身，项目已停更 | 老教程里见到它时，说明那份教程的年份偏早 |
| 原版 Xposed | 最早的框架，在 Android 8.1 之后基本失效 | 只有历史意义，不用照着它的流程操作 |
| LSPatch | 不需要 Root 的另一条路——给单个 APK 打补丁 | 完全是另一个项目，作用范围只限被打过包的那个应用 |
| ZygiskNext / ReZygisk / NeoZygisk | 给 KernelSU、APatch 这类本身不带 Zygisk 的 Root 方案提供 Zygisk 环境 | 不是框架本体，但缺了它框架在那些设备上起不来，顺序见 [不用Magisk的Root环境怎么装.md](不用Magisk的Root环境怎么装.md) |

遇到教程里让你「先装 EdXposed 再装 Riru」的，那就是很旧的流程了，别照着走。两者的差别在 [和Xposed有什么区别.md](和Xposed有什么区别.md) 里有对照表。

## 五、它曾经停更过，这件事要提一句

这个项目在 2024 年初曾对外宣布停止维护，代码仓库一度转为只读状态，当时不少媒体报道过。此后有社区分支接手继续维护，官方仓库当前也已恢复更新——是否归档、最近一次提交是什么时候，都能在仓库页面上直接看到。

这对你的实际意义有两点：一是你搜到的「LSPosed 已经停止维护了」这类说法属于当时的旧闻，**项目当前的维护状态以官方仓库页面为准**；二是正因为经历过这段，网上流传的整合包与「最后一版收藏版」特别多，而这类框架的管理器权限不小，来源不明的重打包包不值得冒险。

## 六、下载渠道怎么挑

按这个顺序选，能避开绝大部分坑：

1. **官方模块仓库**里收录的模块优先，因为它至少有人替你核对过包名与来源；
2. 模块作者自己的发布页，看它的更新记录是否还在维护；
3. 框架本体与管理器，只从官方渠道取；网盘里这份是给不方便访问官方渠道时用的管理器安装包，[LSPosed 安装文件资源（夸克网盘）](https://pan.quark.cn/s/293a930cd5dc)；
4. 论坛、群聊里转发的「打包好的版本」，在没有核对过包名与来源之前不要装。

有两条独立的判断线可以随时用：**包名是不是 `org.lsposed.manager`**、**模块包是不是从官方发布页来的**。这两条对上，基本就不会装错东西。
