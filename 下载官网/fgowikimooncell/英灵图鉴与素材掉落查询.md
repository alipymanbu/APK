## 一、打开后你会看到什么

Mooncell 客户端加载的是 Mooncell 网站（[fgo.wiki](https://fgo.wiki)）的内容，首页按栏目排列，直接点对应栏目进查询页：

| 栏目 | 查什么 |
| --- | --- |
| 英灵图鉴 | 从者的数值、配卡、宝具、技能、灵基再临与技能强化的素材需求 |
| 礼装图鉴 | 概念礼装的属性与获取方式 |
| 纹章图鉴 | 命令纹章 |
| 灵衣一览 | 从者的灵衣开放条件 |
| 道具一览 | 素材、道具的分类与用途 |
| 关卡配置 | 各关卡的敌人配置、AP 消耗 |
| 敌人一览 | 敌人的职阶、血量、技能 |
| 技能一览 | 从者技能的升级素材与效果 |
| 活动一览 / 卡池一览 | 当前与历史活动、召唤卡池的时间表 |
| 魔术礼装 | 御主礼装（魔术礼装）的等级与获取 |

以上栏目来自 Mooncell 网站首页，客户端内按同一套导航访问；具体排布随网站改版可能调整，以你当时看到的页面为准。

## 二、查一个英灵的完整路径

以查某个从者的养成素材为例：

1. 进入「英灵图鉴」，按星级、职阶或直接搜索名字定位目标从者；
2. 打开该从者页面，「基础数值」「宝具」「技能」几节给出战斗相关的数据；
3. 「素材需求」一节把**灵基再临**与**技能强化**分开列出所需素材，最后一行有两项合计 —— 养成一个从者要刷多少素材看这张表就够了；
4. 页面下方还有成长曲线、牵绊等级、语音与各阶段战斗形象，按需往下翻。

Mooncell 是 wiki 式内容，每页由玩家共同编辑并带修改记录，数据随游戏版本更新而更新；如果某页数据看着对不上游戏内实况，以游戏内为准，并可以自己去网站上改。

## 三、查素材掉落与关卡

刷素材前先确定去哪刷：

1. 「道具一览」里找到目标素材，页面会链到掉落该素材的关卡；
2. 「关卡配置」按主线、支线、活动分类，点进具体关卡能看到敌人配置（职阶、数量、血量）；
3. 结合「敌人一览」核对敌人的特性，规划用什么队去打。

掉落率这类数据是玩家实测汇总的结果，会随游戏调整掉落而过期，页面通常标注了统计口径，读的时候一并看一眼。

## 四、查活动与卡池排期

「活动一览」与「卡池一览」按时间线列出日服、国服的活动与召唤卡池。规划圣晶石往哪抽、活动什么时候开，看这两页即可；国服进度落后于日服，页面会分别标注服别，别把日服的时间直接当国服的时间用。

## 五、查不到或页面打不开

图鉴依赖网络加载，页面白屏、图片不显示的排查步骤在 [打不开进不去怎么办.md](打不开进不去怎么办.md)；还没装上客户端的先看 [下载与安装教程.md](下载与安装教程.md)。想顺手试一把抽卡手感，见 [抽卡模拟器怎么用.md](抽卡模拟器怎么用.md)。
