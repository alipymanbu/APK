## 一、打开后你会看到什么

Mooncell 客户端加载的是 Mooncell 网站（[fgo.wiki](https://fgo.wiki)）的内容，首页按栏目排列，直接点对应栏目进查询页：

| 栏目 | 查什么 |
| --- | --- |
| 英灵图鉴 | 从者的数值、配卡、宝具、技能、灵基再临与技能强化的素材需求 |
| 礼装图鉴 | 概念礼装的属性与获取方式 |
| 纹章图鉴 | 命令纹章 |
| 灵衣一览 | 从者的灵衣开放条件 |
| 道具一览 | 素材、道具的分类与用途 |
| 关卡配置 | 各关卡的敌人配置、AP 消耗 |
| 敌人一览 | 敌人的职阶、血量、技能 |
| 技能一览 | 从者技能的升级素材与效果 |
| 活动一览 / 卡池一览 | 当前与历史活动、召唤卡池的时间表 |
| 魔术礼装 | 御主礼装（魔术礼装）的等级与获取 |

以上栏目来自 Mooncell 网站首页，客户端内按同一套导航访问；具体排布随网站改版可能调整，以你当时看到的页面为准。

## 二、查一个英灵的完整路径

以查某个从者的养成素材为例：

1. 打开英灵图鉴（1.4.6 版的第三方教程给的路径是：左上角「更多」菜单 → 英灵图鉴；版本不同入口若不同，以实际界面为准）；
2. 在筛选框里输入条件检索 —— 可以按名字查，也可以勾选星级、职阶等标签组合筛选，勾完下拉到页面底部就列出符合条件的从者（1.4.6 版教程口径）；
3. 点开目标从者页面，「基础数值」「宝具」「技能」几节给出战斗相关的数据；
4. 「素材需求」一节把**灵基再临**与**技能强化**分开列出所需素材，最后一行有两项合计 —— 养成一个从者要刷多少素材看这张表就够了；
5. 页面下方还有成长曲线、牵绊等级、语音与各阶段战斗形象，按需往下翻。

Mooncell 是 wiki 式内容，每页由玩家共同编辑并带修改记录，数据随游戏版本更新而更新；如果某页数据看着对不上游戏内实况，以游戏内为准，处理办法见第五节。

## 三、查素材掉落与关卡

刷素材前先确定去哪刷：

1. 「道具一览」里找到目标素材，页面会链到掉落该素材的关卡；
2. 「关卡配置」按主线、支线、活动分类，点进具体关卡能看到敌人配置（职阶、数量、血量）；
3. 结合「敌人一览」核对敌人的特性，规划用什么队去打。

掉落率这类数据是玩家实测汇总的结果，会随游戏调整掉落而过期，页面通常标注了统计口径，读的时候一并看一眼。

## 四、查活动与卡池排期

「活动一览」与「卡池一览」按时间线列出日服、国服的活动与召唤卡池。规划圣晶石往哪抽、活动什么时候开，看这两页即可；国服进度落后于日服，页面会分别标注服别，别把日服的时间直接当国服的时间用。客户端的侧边栏还会显示当前活动 —— 1.4.6 版更新日志提到开启「国服版本」时侧边栏活动取国服译名，你界面上的开关位置以实际版本为准。

## 五、数据有错、页面缺内容怎么办

Mooncell 是 wiki：每个页面右上有编辑入口，注册登录后你就能直接改。改动前先看一眼官方的[编辑规范](https://fgo.wiki/w/Mooncell:%E7%BC%96%E8%BE%91%E8%A7%84%E8%8C%83)，从者命名、数据录入都有约定（例如国服从者名以国服翻译为准）；不想自己动手，也可以在页面讨论区或官方反馈渠道指出问题，等编辑者处理。判断数据对不对时，记得以游戏内实况为最终标准。

## 六、查算配合：伤害与 NP 用计算器

图鉴给的是静态数据，「这个宝具打过去多少伤害、这卡回多少 NP」要靠计算器 —— 入口、填写顺序与易漏项在 [伤害计算器怎么用.md](伤害计算器怎么用.md)。

## 七、查不到或页面打不开

图鉴依赖网络加载，页面白屏、图片不显示的排查步骤在 [打不开进不去怎么办.md](打不开进不去怎么办.md)；还没装上客户端的先看 [下载与安装教程.md](下载与安装教程.md)。想顺手试一把抽卡手感，见 [抽卡模拟器怎么用.md](抽卡模拟器怎么用.md)。
