## 一、这是个什么应用

OrionTV 是一个开源的安卓影视播放客户端（GitHub 上的 [orion-lib/OrionTV](https://github.com/orion-lib/OrionTV) 项目，MIT 许可），本身不带任何片源：它要连到一个现成的影视站点（比如自建的 MoonTV）才能出内容，首页分类、搜索、收藏都建立在这个站点之上。同一份 apk 在手机、平板、电视盒子上都能装，界面按屏幕大小自适应，差别只在操作方式 —— 触屏点按或遥控器聚焦。所以装完只是第一步，还差「配服务器地址」这一步，见 [服务器地址配置方法.md](服务器地址配置方法.md)。

顺带提醒：塞尔维亚运营商 Orion telekom 旗下也有一个同名的「Orion TV」订阅电视应用，跟本文讲的这个开源播放器完全是两回事，搜教程时留意区分（见 [常见问题与播放失败排查.md](常见问题与播放失败排查.md) 最后一节）。

## 二、安装包规格（以网盘里这份为准）

各分发页标注的版本经常互相打架，下面是**网盘里那份安装包**的信息，装完想核对「是不是同一份」时用得上：

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.3.11 |
| 包名 | com.oriontv |
| 安装包大小 | 66.98 MB |
| MD5 | 90DDA014D3D4EEA04C937FC0DF7D4595 |
| 系统要求 | 资料标注「安卓 5.2 以上」，以安装时的实际提示为准 |
| 界面语言 | 简体中文 |

核对包名的办法：装完后进系统「设置 → 应用管理」找到 OrionTV，包名显示为 `com.oriontv` 就对了。版本号以网盘里当时的文件为准（上表对应 2026-09-27 整理的那份）；应用设置里自带「检查更新」，装好后可以在应用内升级，不用一直等新包。

## 三、获取安装包

1. 打开 [OrionTV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/62a473b3b74b)；
2. 先转存到自己的网盘再下载，67M 的文件在线直接拉容易中断，断了的包装不上；
3. 下载完确认文件大小约 67M、文件名类似 `OrionTV_v1.3.11.apk`，再点安装。

另一个正规来源是官方 GitHub 发行页 [github.com/orion-lib/OrionTV/releases](https://github.com/orion-lib/OrionTV/releases)，由项目方发布 APK，版本以页面当时显示为准 —— 想装官方当前版去那里，想装与本文口径一致的 1.3.11 就用网盘这份。

## 四、装到手机 / 平板上

1. 点开下载好的 apk。系统若提示「不允许安装未知来源的应用」，按弹窗给的入口进设置，允许这个来源安装（各品牌提示语大同小异）；
2. 等安装进度走完，点「打开」；
3. 首次启动把网络权限给了 —— 这个应用没有网络什么都加载不出来。

## 五、装到电视 / 盒子上

电视上一般没有现成的文件入口，常规走法是 U 盘中转：

1. 电脑上把 apk 拷进 U 盘；
2. U 盘插到电视或盒子上，用自带的「文件管理」类应用找到 apk 安装；
3. 电视上没有文件管理器的话，先在自带应用市场里装一个文件管理器类应用，再走第 2 步；
4. 部分系统同样会拦「未知来源」，到设置里的安装权限放行。

装完打开，用遥控器操作：焦点默认落在首页顶部的分类上，左右键切换「热门剧集 / 电视剧 / 电影 / 综艺」。

## 六、第一次打开是什么样

底部固定四个标签：**首页 / 搜索 / 收藏 / 设置**。还没配服务器地址时：

- 首页中间会提示「请点击右上角设置按钮，配置您的服务器地址」；
- 收藏页会显示一串 `API_URL_NOT_SET`。

这两个都是「还没配后端」的正常表现，不是装坏了。下一步去 [服务器地址配置方法.md](服务器地址配置方法.md)。
