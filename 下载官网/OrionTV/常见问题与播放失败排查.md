## 一、按症状对号

先对着症状表找到自己的情况，再跳到对应小节；表里对不上的，从第二节的通用动作查起。

| 症状 | 多半是 | 先看 |
| --- | --- | --- |
| 首页空白，提示「请点击右上角设置按钮，配置您的服务器地址」 | 没配服务器地址 | [服务器地址配置方法.md](服务器地址配置方法.md) 第二节 |
| 收藏页显示 `API_URL_NOT_SET` | 地址没配或没保存成功 | [服务器地址配置方法.md](服务器地址配置方法.md) 第二节 |
| 填了地址提示无效、保存不生效 | 地址不完整或服务端没上线 | 本文第三节 |
| 首页有片单但播放失败 | 服务端侧的源失效或网络不通 | 本文第四节 |
| 收藏、播放记录不互通 | 同步条件没凑齐 | [收藏与播放记录同步.md](收藏与播放记录同步.md) 第二节 |
| 检查更新没反应 | 设备访问不到发布渠道 | 本文第六节 |

## 二、排查前先做一个动作

**把服务器地址粘进手机或电脑浏览器里打开。** 浏览器里能看到站点页面，问题在 OrionTV 这头或设备网络；浏览器都打不开，问题在服务端或地址本身 —— 客户端里怎么重试都没用。这一步能砍掉一大半无效折腾。

## 三、地址与登录问题

- **提示地址无效**：常见错法是丢了 `https://`、粘进了空格、域名敲错，重新整段复制粘贴，别手打；
- **登录失败**：用户名密码是**影视站点自己的账号**（部署 MoonTV 时设置的那套），不是邮箱、不是手机号、也不是别的应用账号；
- **保存后还是老样子**：确认保存按钮真的点过；电视端改用局域网网页配置重走一遍（[服务器地址配置方法.md](服务器地址配置方法.md) 第三节）；
- **昨天能用今天空白**：站点地址变了或服务端挂了 —— 先按第二节验证，再回应用里改地址。

## 四、播放失败与卡顿

- **单个片播不了，别的正常**：是那个片对应的源失效了，换别的看，客户端侧无解；
- **全部播不了**：回到第二节验证服务端还活着，再查设备网络（电视连的是不是同一个 Wi-Fi）；
- **卡顿缓冲慢**：瓶颈通常在源站或服务端出口，不在播放器本身，换时段、换内容比在客户端里调设置有效。

服务端聚合的接口失效时，客户端能做的只有换内容 —— 这是「播放器 + 自备站点」这种结构的固有分工，别在 OrionTV 里死磕。想加源、换源，动作都在服务端管理后台，见 [搜不到想看的片怎么办.md](搜不到想看的片怎么办.md)。

## 五、老设备专属坑

安卓 6、7 一类的老电视盒子有两类高发问题：

1. **证书兼容**：老系统认不出部分新站点的 HTTPS 证书（社区分支的更新记录里提过这类修复），表现为浏览器能打开站点、应用里连不上。绕不开时只能换新一点的设备；
2. **安装即失败或界面异常**：安装包资料标注安卓 5.2 以上，但太老的系统装新包容易出兼容问题 —— 同一份包换台新设备装一次，就能对比出是包的问题还是设备的问题。

先排除第三节之前的地址与网络原因，剩下的才轮到设备本身。

## 六、检查更新失败，或想直接重装

- 更新检查走的是 GitHub 发布渠道，设备网络到不了 GitHub 时会一直没反应，换个网络环境再试；
- 等不及更新或想覆盖重装的，从网盘重新取包：[OrionTV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/62a473b3b74b)，转存下载后直接覆盖安装，同包名同签名会保留本地数据；
- 覆盖安装的步骤与注意点见 [下载与安装教程.md](下载与安装教程.md)。

## 七、别认错应用

搜「OrionTV」很容易搜出另一个东西：塞尔维亚运营商 Orion telekom 的订阅电视应用「Orion TV」（官网 `https://oriontelekom.rs`，要买他们的套餐、用他们的账号登录）。本文讲的是开源播放器 OrionTV（[github.com/orion-lib/OrionTV](https://github.com/orion-lib/OrionTV)）。区分办法很简单：要买套餐的是运营商那个，装完让你配服务器地址的是本文这个。发提问、找教程前先对一眼，不然答非所问。

同名项目下还有另一层容易混的：开源社区里有人基于 OrionTV 做过重制分支（换包名、改界面的那种），包名不再是 `com.oriontv`。对口径的办法还是看包名 —— 系统应用信息里显示 `com.oriontv` 的，才是与本文所有版本、安装、配置口径对应的这一条线。
