## 一、先做这套「三分钟通用重置」

大多数连接问题先走这一遍，走完多半能好：

1. iPhone（或安卓机）进 设置 → 蓝牙，把车机点「忽略此设备」；
2. 车机进 设置 → 蓝牙，删掉已配对的手机（顺手把车机已记住的 WiFi 忽略掉）；
3. 车机用系统里的 **RESET/重启**完整重启一次（不是关屏再开 —— 很多车机的「关屏」不等于重启）；
4. 手机也重启一次；
5. 从第一步重新配对。

原理很简单：残留的配对记录是「一直显示连接中」最常见的原因，清掉重来比逐项猜快。

## 二、按症状对照

| 症状 | 先查什么 | 处理 |
|---|---|---|
| 一直停在「等待连接」 | 蓝牙是否先配对 | 无线 CarPlay 必须先完成蓝牙配对再开 zlink5，顺序反了就卡这里 |
| 配对时搜不到车机 | 车机蓝牙可发现状态 | 进车机蓝牙页让它「可被发现」，别停留在已配对列表页 |
| 有线插上没反应 | 线是不是只充电线 | 换一根能传数据的原装/认证线；再换插车机另一个 USB 口 |
| 连上十几秒就掉 | WiFi 频段与距离 | 车机与手机之间别隔金属物；手机开热点给车机时开「最大化兼容性」（走 2.4GHz） |
| 用一会儿才断、跑高速必断 | 干扰/发热/配对残留 | 已单列一篇，按原因分层查：[无线CarPlay断连怎么办.md](无线CarPlay断连怎么办.md) |
| 连上了但没声音 | 车机音源没切 | 手动把车机音源切到互联界面；手机端关掉单独的「媒体音频」蓝牙通道 |
| 手机弹不出「允许CarPlay」 | iPhone 限制 | 设置 → 屏幕使用时间 → 内容和隐私访问限制 → 允许 CarPlay |
| 打开 zlink5 要激活 | 车机未授权/版本不对 | 见下节 |

## 三、卡在激活/授权页

zlink5 的激活信息由**车机厂商**写进固件，App 自己解不开。装了 APK 但没走厂商升级包的车机，常见表现就是进 App 直接要激活码。两条路：

- 找车机卖家要带 zlink5 的整机升级包（`update.zip`），按厂商说明刷进去；
- 车机原本预装过、只是你手动覆盖安装了别的版本 —— 卸载更新恢复到出厂那版再试。

不要去网上找来路不明的所谓「激活工具」，来源不可控还可能把车机刷坏。

## 四、版本与更新

zlink5 没有应用商店自动更新，版本随车机厂商的固件走。你手上这份是 **5.4.79**（包名 `com.zjinnova.zlink`）；网上能搜到的版本号与此不同属正常，以车机厂商发布的固件为准。判断要不要更新只看一条：**现在这套连接是否稳定** —— 能稳定用就不折腾，出问题且确认是版本旧，再找厂商要新固件。

**刚更新完就出问题的**（连不上、报错页、闪退），先别回滚：清一次 zlink5 的缓存与数据（设置 → 应用 → zlink5 → 存储），再按第一节重置蓝牙与 WiFi —— 多数更新后异常是残留数据造成的，清完就好。清完仍不行的按 [应用闪退与消失怎么找回.md](应用闪退与消失怎么找回.md) 第三节往下走。升级包的安装要点（U 盘 FAT32、包放根目录）也写在那一篇里。

## 五、还是不行的两个硬边界

1. **协议不支持**：车机固件里没开你手机那套协议（比如只有 CarLife 没有 Android Auto），软件层面怎么折腾都出不来入口 —— 换协议连，见 [安卓手机连接教程.md](安卓手机连接教程.md)；
2. **系统版本太低**：这份包要求车机安卓 5.2 以上（见 [下载与安装教程.md](下载与安装教程.md)），低于它装都装不上，只能走厂商整机升级。

逐项走完仍无解时，把「卡在哪一步、屏幕上原话是什么」记下来带给车机厂商，比笼统说「连不上」有效得多。
