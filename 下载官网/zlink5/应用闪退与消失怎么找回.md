# 应用闪退与消失怎么找回

> 桌面上找不到 zlink5 了、一点就闪退、打开报错页 —— 三种情形分别怎么处理。

## 一、先判断是「没了」还是「被禁用了」

图标从桌面消失 ≠ 应用被卸载了。先做一步检查：车机 **设置 → 应用/应用管理 → 全部应用** 里搜 zlink（或 zLink、CarPlay 等别名）。

- **列表里有，但打不开或桌面没图标** → 是被禁用了，在应用信息页点「启用」，图标一般就回来了，往下看第四节；
- **列表里确实没有** → 应用真的不在了，看第二节。

另外注意别名：不同车机厂商给它的桌面图标名不同（「手机互联」「Smart Connect」「Connectivity」都可能是它），先在应用列表里翻一遍再下结论。

## 二、恢复出厂或升级后应用没了

zlink5 是车机系统应用，但它有些版本装在用户分区 —— 一旦**恢复出厂设置、或刷了不匹配的固件**，就可能跟着消失。找回顺序按省事程度排：

1. **看车机有没有「恢复 CarPlay/互联」的开关**：部分车机恢复出厂后只是把该功能关了，进 车机设置 → 系统设置/恢复出厂 相关页面找 CarPlay、互联选项重新打开；
2. **刷回正确的整机固件**：找车机卖家报型号要 `update.zip` 升级包（U 盘格式化成 FAT32、包放根目录、车机 设置 → 系统更新 里安装）—— 刷错型号的包正是它消失的常见原因；
3. **最后一招才是重装 APK**：按 [下载与安装教程.md](下载与安装教程.md) 从 U 盘装一遍；装完停在激活页说明这台车机必须走第 2 步的厂商包，APK 单独装救不回来。

## 三、一点就闪退 / 打开报错页

闪退和报错大多是缓存与数据残留，尤其刚经历过升级。处理顺序：

1. 车机 **设置 → 应用 → zlink5 → 存储**，先点**清除缓存**，重开应用；
2. 还闪退再点**清除数据**（会把 App 恢复到初装状态，不丢车机任何其他数据），重开；
3. 报 `Service unavailable`、`Channel Err` 这类错误页的，同样先清缓存再清数据 —— 多数出现在安装方式不对或升级中断之后（来源：多个独立教程站一致给出此步骤）；
4. 三步都做完仍报错，回 [下载与安装教程.md](下载与安装教程.md) 核对版本：装了与这台车机不匹配的版本（系统低于 5.2、或厂商渠道不同的包）就是这种情况，只能换厂商的正确包。

## 四、清缓存清数据都试过了

那就是应用与当前固件真的不兼容了，软件侧到头：

- 走第二节第 2 步，刷回车机厂商的完整固件 —— 固件会把 zlink5 一并装回匹配的版本；
- 刷完还是不行，把「车机型号 + Android 版本 + 报错原文」一起带给车机厂商，这三项是他们定位问题需要的全部信息。

刷固件这类整机操作有变砖风险，只用**车机卖家给的、明确写了你这个型号**的包，不要用来源不明的固件。日常使用中若只是偶尔断连卡顿（应用本身能打开），那属于连接问题而不是本篇的范畴，见 [无线CarPlay断连怎么办.md](无线CarPlay断连怎么办.md)。
