## 一、先认清你要找的是哪一款

搜「ChatTTS」会撞到两类不同的东西，先分清楚再动手：

| 对比项 | ChatTTS 安卓版（本篇讲的对象） | 2noise 的 ChatTTS 语音生成模型 |
| --- | --- | --- |
| 形态 | 安卓手机上的配音应用，装上就能用 | 开源模型与代码，需要自己部署运行 |
| 使用方式 | 粘贴文字、选声音、一键生成配音 | 用 Python 调用，面向开发者 |
| 适合谁 | 想给视频、有声书配个声音的普通用户 | 想自己搭语音合成服务的技术人员 |

本文只讲手机上的这款配音应用。如果你是开发者、想了解开源模型本身，可以看官方仓库 `https://github.com/2noise/ChatTTS`（写代码部署的路子，与手机应用无关）。

## 三、从哪里拿安装包

这款应用在国内主流应用市场的上架覆盖面有限，搜不到属正常现象。最直接的办法是取本文开头给出的 [ChatTTS 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8d5fae3ce168)：打开分享页，把安装包**转存到自己的网盘**，再从自己网盘里下载 apk——先转存再下载，是为了避免分享链接日后失效时干等。

## 四、安装步骤

1. 从网盘把 apk 下载到手机存储；
2. 在文件管理器里点开下载好的 apk；
3. 系统弹出「禁止安装未知来源应用」提示时，按提示去设置里允许你的文件管理器（或浏览器）安装应用，返回后继续；
4. 点「安装」，等进度条走完；
5. 打开应用，首次启动如果出现功能引导页，按需跳过即可。

装好之后先别急着长篇配音，拿两三句短文本试一次完整流程，确认能正常出声，再进入正式使用；具体操作见 [文字转语音生成步骤.md](文字转语音生成步骤.md)。

## 五、装不上或打不开的排查

| 现象 | 先试什么 |
| --- | --- |
| 提示「解析包错误」 | 多半是下载不完整：重新下载一遍，并核对文件大小是否在 16M 上下 |
| 安装按钮点不动 / 一直转圈 | 确认已给文件管理器「安装未知应用」权限；清理手机存储后重试 |
| 提示系统版本过低 | 先把系统升级到较新的安卓版本再装 |
| 打开就闪退 | 重启手机再开；不行就清一下应用缓存或卸载重装 |
| 安装后图标消失 | 部分手机管家会把新装应用折叠进「风险应用」，去手机管家里恢复信任即可 |
