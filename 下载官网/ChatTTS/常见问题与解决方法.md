## 一、生成与播放问题

| 问题 | 处理办法 |
| --- | --- |
| 点生成没反应 / 一直转圈 | 先确认网络可用；语音合成一般要联网完成，弱网环境下等一会或换网络再试 |
| 提示生成失败 | 缩短文本重试——先把出问题的段落砍半，定位是长文本问题还是内容问题 |
| 生成的声音和上次不一样 | 确认音色选择没有变；每次生成都核对一遍当前选中的声音（见 [音色与声音模型选择.md](音色与声音模型选择.md)） |
| 多音字 / 人名念错 | 改写文案绕开，比重试更有效；具体写法见 [文字转语音生成步骤.md](文字转语音生成步骤.md) 第二节 |
| 试听正常、导出后没声音 | 检查手机媒体音量（而不是铃声音量）；再核对播放器支持的格式 |
| 保存后在文件管理器里找不到 | 按时间排序找最新音频；或回到应用里看保存路径的提示 |
| 配音听着像机器人 / 太机械 | 先改文案再重生成，不要先怀疑工具：短句化、口语化、标点控停顿，完整清单见 [配音不自然怎么调整.md](配音不自然怎么调整.md) |
| 音频有轻微底噪 / 音质发闷 | 开源版模型官方说明里就自带少量高频噪声与音质压缩（防滥用设计），轻微底噪未必是应用故障；解释与判别见 [停顿与笑声的控制方法.md](停顿与笑声的控制方法.md) |

## 二、设备与安装类问题

- **iPhone 能装吗**：不能。这份安装包是安卓 apk，iOS 设备装不了。
- **平板能用吗**：安卓平板通常能装能跑，但界面是按手机竖屏设计的，布局可能只占一部分屏幕；以实际显示为准。
- **电脑上能用吗**：这款应用没有电脑版。想在电脑上做配音，可以把手机生成的音频传到电脑剪辑；技术人员想在 PC 上跑同源的 ChatTTS 模型，走的是开源仓库 `https://github.com/2noise/ChatTTS` 的部署路线，那是另一套流程。
- **换手机后作品还在吗**：应用不提供云端作品库，已生成的音频只存在手机本地；换机前把音频文件导出到网盘或电脑。

## 三、版本与更新

- 本文记录的安装包版本是 **1.1.0**（整理于 2026-09-27，包名 `uni.UNI8B3F4DF`、大小约 15.84M）。你从 [ChatTTS 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8d5fae3ce168) 拿到的就是这一份。
- 有没有新版本、更新了什么，以应用内「关于 / 检查更新」和官方发布渠道显示为准；应用市场与网盘渠道的版本号经常不同步。
- 旧版本能用就先用着：这类工具的核心是生成效果，版本差异通常小于文案写法带来的差异。

## 四、关于商用

ChatTTS 这个名字对应的语音生成模型，其开源许可（截至本文检索时，以官方仓库页面为准）对模型权重部分用的是 CC BY-NC 4.0，即**限非商业用途**；手机应用实际调用的是什么版本、授权如何，应用内没有公开标注。所以如果你的配音要用于商业项目（收费课程、带广告的视频等），稳妥的做法是：

1. 先小范围使用，保留生成记录；
2. 用到正式商用前，在应用内或官方渠道确认授权口径；
3. 不确定时，选择明确允许商用的其他配音工具或人工配音。

本文不替任何渠道的授权做担保，以上只是提醒你「许可这层存在」，判断以官方说明为准。
