## 一、「ChatTTS」名字背后的语音模型

手机上这款应用借用的，是 2noise 团队在 GitHub 开源的同名语音生成模型。按官方仓库（`https://github.com/2noise/ChatTTS`）的介绍，它有几个与「配音」直接相关的特点：

| 特点 | 对你意味着什么 |
| --- | --- |
| 专为对话场景设计 | 念对白、口播这类「说人话」的文本，比念书面公文更自然 |
| 支持中文和英文 | 中英混排的文案（比如产品名带英文）可以整体生成，不用切软件 |
| 能控制笑声、停顿、语气词这类细粒度韵律 | 文案里留好标点与语气词，出来的声音更有「聊天感」 |
| 用约 10 万小时中英文音频数据训练（公开的预训练版为 4 万小时） | 音色库有底子，同一句话换不同声音，风格差异明显 |

这些是模型层面的官方说法。手机应用实际用了哪些能力、开放到什么程度，以应用内能做出什么效果为准；其中「控制笑声与停顿」这一条在文案里具体怎么用，见 [停顿与笑声的控制方法.md](停顿与笑声的控制方法.md)。

## 二、按用途挑音色

应用里提供了多种类型的声音模型（具体数量与命名以界面实际显示为准），挑选时可以按这个对照思路来：

| 你的用途 | 适合往哪个方向挑 | 原因 |
| --- | --- | --- |
| 短视频口播 | 语速偏快、吐字利落的声音 | 观众耐心短，拖沓的声音直接划走 |
| 有声书 / 故事 | 语气起伏大、偏「讲述感」的声音 | 长时间听，平淡的声音容易让人走神 |
| 科普 / 教程讲解 | 吐字清晰、语速平稳的声音 | 信息密度高，清晰度优先 |
| 双人对话 | 挑两个音色特征差异明显的（男女搭配或声线区分大） | 听众不用看画面也能分清谁在说 |

注意一个坑：**挑音色时别只听单句**。单句好听的声音放在长文本里可能显得累，建议拿你真实的文案（至少三五句、带标点的）试听，再决定用哪个。

## 三、试听比对的省力做法

1. 固定一段「试音文本」——从你实际要配音的内容里截一小段，三五句、带标点的才有参考价值，随手打的短句听不出差别；
2. 同一段文本依次换 3~4 个候选音色各生成一次；
3. 对比时只听两点：多音字有没有念错、长句有没有念得上气不接下气；
4. 锁定音色后，把它的名字记下来——之后所有配音都用同一个声音，成品的连贯性比频繁换声音重要得多。

选定声音后的完整生成流程见 [文字转语音生成步骤.md](文字转语音生成步骤.md)；拿到配音后怎么用在视频和有声书里，见 [视频配音与有声书制作.md](视频配音与有声书制作.md)。
