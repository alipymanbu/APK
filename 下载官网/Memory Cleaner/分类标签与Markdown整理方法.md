# 用分类标签和 Markdown 整理记忆内容

> 记忆条目一多就会乱，本篇讲类别、标签、搜索、图片、Markdown 和日历视图各自解决什么问题、怎么配合用。

## 一、类别和标签各管一头

Memory Helper 给了两套归类方式，分工不同，建议都用：

| | 类别 | 标签 |
| --- | --- | --- |
| 形态 | 像文件夹，一条记忆属于一个类别 | 像贴纸，一条记忆可以贴多个 |
| 适合 | 内容来源互斥的划分：古诗 / 单词 / 公式 | 内容属性的交叉：易错 / 本周冲刺 / 已掌握 |
| 典型用法 | 决定「这是哪门功课的」 | 决定「这条现在处于什么状态」 |

**一条记忆只进一个类别、可以带多个标签**——类别管归属，标签管状态。这样在复习界面按标签筛选时，「易错」这类动态标签才能真的把当前最该练的挑出来。

## 二、用搜索直达，不靠翻列表

条目多了之后，靠滚动找一条很慢，搜索是最快的定位方式：输入记忆名称里的任何片段即可直达。**给记忆起名时就为搜索服务**——名称里带上可区分的关键词（如「岳阳楼记·首段」而不是「古诗1」），否则将来搜不出来。

## 三、图片与图标

- 需要记的内容本身是图（图表、地图、手写笔记），把图片直接添加到这条记忆里；
- 记忆可以**编辑图标**，让列表里一眼能扫到分类；
- 图片提示已损坏时，重新添加一次即可，不影响这条记忆的排期。

## 四、Markdown：让内容能「盖住答案」

正文支持 Markdown，这是把记忆做成自测卡的关键：

- 用列表、加粗把释义和要点结构化，复习时更好对照；
- Markdown 里可以直接加图片，图文混排记笔记很方便；
- 配合复习窗的「先回忆后对照」，把答案部分放在备注里，先自己想再展开。

不需要会很复杂的语法，会用「**加粗**」「- 列表」「![](图片)」这三样就够搭出一张能自测的记忆卡。

## 五、日历视图：安排新任务的依据

日历视图把**每日复习任务一览无余**，它的用途不是好看，而是回答一个问题：**我还能不能再添新的记忆？**

- 某几天到期量已经很满 → 别再集中添加新内容，把新增摊到空的几天；
- 未来几天相对空 → 可以放心开始新的一批。

添完之后按到期顺序复习，操作见 [添加记忆与复习流程怎么用.md](添加记忆与复习流程怎么用.md)；忘记当场添加的内容可以事后补录并修改创建时间，也在那一篇里。

## 六、整理的边界：别把结构做太深

类别嵌套太深、标签起几十个，维护成本会超过收益——**标签只建你真的会用来筛选的那些**。整理是为复习服务的——判断标准永远是「复习界面里我能不能快速挑出该做的那批」，而不是分类体系多完整。
