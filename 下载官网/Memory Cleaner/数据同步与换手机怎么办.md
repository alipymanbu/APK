# 数据同步与换手机怎么处理

## 一、先弄清你的数据靠什么承载

这个应用有两条互不影响的数据路径，装机时选的那条决定了一切：

| | 无账号试用 | 登录账号 |
| --- | --- | --- |
| 数据承载 | 本机 | 服务器（云端同步） |
| 换手机 | 没有可同步的对象，数据留在旧机上 | 新机登录同一账号，数据回来 |
| 适合 | 先试试手感 | 长期使用、可能换机 |

官方口径是**所有数据同步到服务器，登录同一账号，数据近在咫尺**——前提是你的数据确实挂在账号下。用「无账号试用」攒的记忆不会自动找回来，这是两类模式最本质的区别。

## 二、换手机的标准动作

1. **旧机上先确认**：打开应用看是否已登录账号。没登录的话，先把旧机登回同一账号并保持联网，让数据完成同步再动手机；
2. **新机装应用**：安装包见 [下载与安装教程.md](下载与安装教程.md)，装好后**登录旧机用的同一个账号**；
3. **联网等首次同步**完成，记忆条目和复习排期会一并回来。

注意两点：

- 同步的前提是「同一个账号」——账号记错登了新的，看到的是空库，不是数据丢了，退出重登正确账号即可；
- 旧机在同步完成前别急着恢复出厂或卸载应用，一旦本机数据没了又没登录过账号，这部分就带不过来了。

## 三、想把手动备份也做一份

云端是主路径，若想再留一手（比如担心账号或网络问题），可用手机自带的备份功能把应用数据整体备份到厂商云，或截图留存关键内容。**不建议只靠导出某一条记忆**——批量内容的迁移靠账号同步，单条备份覆盖不了排期信息。

## 四、免费档能用到什么程度

- **记忆条目数量不受限制**——官方明确不会限制免费用户的记忆条目数，也不会在更新中收回已有权益；
- 需要付费的只有**高级功能**（如智能曲线），触发到订阅页面时再按需决定，别为用不上的功能订阅，见 [复习曲线与智能曲线怎么调.md](复习曲线与智能曲线怎么调.md)；
- 免费与付费的档位以应用内与官方页面当时显示为准，官方商店的版本也可能比网盘这份新（网盘为 3.17.3）。

## 五、多平台与桌面版

官方说明兼容主流 iOS 与 Android 系统，官网 [memoryhelper.net](https://memoryhelper.net) 的下载页提供各端安装包（含 Windows 与 macOS 桌面版）。跨端数据靠同一账号云端同步——换端逻辑与换手机一致，登录同一账号即可。iOS 端的具体获取方式以官网下载页当时显示为准。
