# 批量导入与分享保存记忆

> 逐条手敲太慢时用这篇：菜单里的批量导入、从其他应用直接分享文字、打开别人发来的记忆文件，三种把内容一次性塞进复习排期的方法。

## 一、先想清楚导什么

导入解决的是「内容已经成批存在」的场景：整理好的单词表、错题条目、知识点清单。如果内容还是一整篇文章，先做一次拆分——**导入进来的每一条都会各自进入复习排期**，一条装一屏文字，复习时根本没法自测。拆分标准和手动添加一致：一条一个知识点（见 [添加记忆与复习流程怎么用.md](添加记忆与复习流程怎么用.md)）。

## 二、菜单里的「批量导入」

应用菜单（界面右上角的三点图标）里有**批量导入**入口，选中要记忆的文件文档即可导入。要点：

- 入口在三点菜单里，若你的版本找不到，以应用内实际界面为准（不同版本入口位置可能有出入）；
- 导入的是**文件文档**——先把内容整理成应用能读的文档再导，别指望它替你把一篇课文切成记忆条目；
- 导入量大时分批导，每批导完抽查几条，确认名称、备注没乱，再导下一批。

## 三、从其他应用直接分享进来（官方功能）

看到一段值得记的文字——网页、笔记、聊天记录里的一条——**在那个应用里选中文字 → 分享 → 选 Memory Helper，就会直接保存为一条记忆**，并自动安排复习。这是官方版本描述里写明的功能（「新增文字分享保存：在其他应用中分享文字，即可直接保存为记忆，自动安排复习」），比复制粘贴再打开应用快一截。

适合随手记：灵感、临时要背的一句话。批量内容还是走第二节的批量导入。

## 四、别人发来的记忆文件

社区里有人整理好成套的记忆内容直接分享，拿到文件后：

1. 下载/接收该文件；
2. 点开文件，选择用 **Memory Helper** 打开，它会把内容接进应用。

注意两条：**导入前先把文件打开看一眼内容**，确认是你要的东西、没有无关或错乱条目；来源不明的文件同样先过目再导，避免把错误内容整批灌进排期。

## 五、导完先检查这三样

1. **条数对不对**：列表里数一下，与预期差得多就重导一次；
2. **类别和标签**：批量导入的条目未必落在你想要的类别里，手动归一下位，复习界面按标签筛选才好使（见 [分类标签与Markdown整理方法.md](分类标签与Markdown整理方法.md)）；
3. **排期压力**：一口气导入几百条，等于瞬间生成几百条到期任务。先看日历视图这几天的量，必要时分几天导，或导完先处理积压策略（见 [复习曲线与智能曲线怎么调.md](复习曲线与智能曲线怎么调.md)）。

## 六、备份与导出

有资料提到记忆库支持**导出备份**（旧版更新日志里出现过修复导出备份问题的记录），具体入口以应用内为准。导出备份和云端同步是两回事：同步靠账号（见 [数据同步与换手机怎么办.md](数据同步与换手机怎么办.md)），导出是额外留一份在自己手里，两者都做最稳。
