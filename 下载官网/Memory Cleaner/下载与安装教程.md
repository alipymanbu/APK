## 一、先说清名字：文件叫 Memory Cleaner，应用是 Memory Helper

你从网盘拿到的文件夹名是「Memory Cleaner（先保存再下载）」，里面的安装包叫 `Memory Cleaner_v3.17.3.apk`。但把它装进手机后，桌面图标和启动页显示的名字是 **Memory Helper**，包名是 `com.fujianjin6471.memoryhelper`。

这不是装错了：这份安装包的实际内容就是 Memory Helper —— 一个按艾宾浩斯遗忘曲线安排复习的记忆工具（官网 [memoryhelper.net](https://memoryhelper.net)），不是清理内存的软件。核对方法见下节，以包名为准。

如果你要找的本来就是记忆复习工具，直接往下装即可；文件名不用改，网盘里的名字保持原样才能对上分享链接。

## 二、从网盘拿安装包

1. 打开[Memory Helper 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d3733ff456a7)，把文件夹转存到自己的网盘；
2. 在网盘里进入该文件夹，找到 `Memory Cleaner_v3.17.3.apk`；
3. 手机上（或先下到电脑再传手机）下载这个 apk 文件——别只点「在线预览」，那不会把安装包落到手机里。

## 三、下完先核对这几个值

以本地留存的这份为准（官方商店里的最新版可能比它新，版本号不同属正常）：

| 项目 | 值 |
| --- | --- |
| 版本号 | 3.17.3 |
| 包名 | `com.fujianjin6471.memoryhelper` |
| 安装包大小 | 166.26M |
| MD5 | `001010089e0b745e2615b8cd77fcf53f` |

核对包名最省事：安装时弹出的确认页、或装完后到「设置 → 应用 → Memory Helper → 应用信息」里看，包名对得上就是同一个包。MD5 想核的话在电脑上算，不核也不影响安装。

安装包 166M 里有相当一部分是给不同处理器架构准备的原生库，安装时只取你这台机器用得上的那套，装完后的实际占用通常小于安装包体积。

顺带对齐几个背景信息，装之前心里有数：

- **开发者/厂商**：温州云忆剑影科技有限公司（应用商店页面标注），官网 [memoryhelper.net](https://memoryhelper.net)；
- **系统要求**：Android 7.0 及以上——与本包的最低版本要求一致，商店页面口径相同；
- **版本参照**：官方商店在网盘这份（3.17.3）之后仍在更新（如 2026-09 已有 3.24.1、约 194M），**版本号与体积以官方页面当时显示为准**；换新版后包名不变，覆盖安装即可。

## 四、安装（装不上先看这里）

1. 下载 apk 后点开，系统会拦「不允许安装未知来源应用」——按提示进入「安装未知应用」权限页，给你的浏览器或文件管理器打开这个开关，返回再装；
2. 系统要求 **Android 7.0 及以上**（这份包的最低版本要求是 Android 7.0 / API 24），低于它会提示「解析包时出错」或直接不让装；
3. 提示「已存在同名应用」说明手机里装过旧版：直接覆盖安装即可，数据是否保留取决于你之前是否登录过账号，见 [数据同步与换手机怎么办.md](数据同步与换手机怎么办.md)；
4. 提示存储空间不足时先清理空间——安装阶段需要的临时空间比 166M 更大。

## 五、第一次打开：先决定用不用账号

首次启动会要求同意隐私协议（隐私政策在 [memoryhelper.net/privacy](https://memoryhelper.net/privacy)），同意后进入主界面。这时你有两条路：

| | 无账号试用 | 登录/注册账号 |
| --- | --- | --- |
| 入口 | 界面右上角「无账号试用」 | 首次启动的登录页 |
| 能不能用 | 全部功能照常用 | 全部功能照常用 |
| 数据放哪 | 没有账号承载，换手机时没有可同步的对象 | 数据同步到服务器 |
| 适合谁 | 先试试手感 | 打算长期用、以后可能换机 |

选「无账号试用」也能完整走一遍新手教程。但只要你打算用超过一两周，建议这一步就登录或注册——后补的代价是换机时数据带不走，见 [数据同步与换手机怎么办.md](数据同步与换手机怎么办.md)。

装好后的下一步见 [添加记忆与复习流程怎么用.md](添加记忆与复习流程怎么用.md)。
