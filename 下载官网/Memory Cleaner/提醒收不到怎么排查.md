## 一、为什么这个应用特别吃通知权限

它的工作方式是：复习时间到了，你又不在应用里，就**推送一条通知**叫你回来做任务。通知链路断了，应用不会「攒着等你来」，你只有主动打开才看得到到期任务——表现出来就是任务莫名积压、越欠越多。所以下面几项按顺序全查一遍，不确定开哪些就全开。

## 二、按这个顺序查

### 1. 系统通知权限

到「设置 → 应用 → Memory Helper → 通知」，把**允许通知**打开，其下的横幅、锁屏、声音等子项也一并打开；「勿扰/静默通知」若有开关，关掉它。安卓 13 及以上首次启动时会弹一次通知权限请求，当时点了「不允许」就会走到这一步补开。

### 2. 别杀它的后台

**不要关闭应用、不要清后台、保持它在后台运行**——进程被杀，计时中的提醒就没了。实操两条：

- 在最近任务列表里把它的卡片**下拉加锁**（部分机型是点锁形图标），避免一键清理时被扫掉；
- 系统的「一键清理/内存优化」把它排除掉。

### 3. 电池优化与省电模式

省电策略会把后台应用冻结，提醒跟着停：

- 关闭「省电模式/超级省电」（设置 → 电池）；
- 「设置里搜索**电池优化**」，找到 Memory Helper 设为**不允许**；
- 部分机型（华为/荣耀等）另有「应用启动管理」，把它的**自动管理关掉**，手动打开自启动、关联启动、后台活动三项。

### 4. 重启手机之后要先打开一次

手机重启后所有应用都未启动，提醒此时不会来——**开机后手动打开一次 Memory Helper**，之后提醒恢复正常。这不是故障，每次都这样。

### 5. 确认「有没有任务到期」而不是「提醒响没响」

以上都开了仍觉得没提醒，先打开应用看复习列表：若列表是空的而你认为该有任务，问题出在排期不在提醒——见 [复习曲线与智能曲线怎么调.md](复习曲线与智能曲线怎么调.md)；若列表有任务、只是没弹通知，回头把第 1～3 项再核对一遍，多半是某一项被系统更新重置了。

## 三、判断改哪一项的捷径

| 症状 | 先查 |
| --- | --- |
| 从来没收到过通知 | 第 1 项通知权限，其次第 2 项后台 |
| 收到过、最近开始收不到 | 第 3 项电池优化（多半是系统更新后省电策略变严） |
| 只有重启后当天收不到 | 第 4 项，重启后先打开一次 |
| 通知来了但很晚 | 第 2、3 项：进程被冻结，送达被拖延 |

## 四、还没解决

逐项做完仍不提醒，可以卸载重装一次（安装包从 [下载与安装教程.md](下载与安装教程.md) 里拿），重装后把上述权限一次给全。**动手前先看一眼是否登录过账号**：登录过的，重装后登回同一账号数据即回；一直用「无账号试用」的，重装会丢掉本机记忆，先别卸载，见 [数据同步与换手机怎么办.md](数据同步与换手机怎么办.md)。若确认是版本问题，注意网盘这份是 3.17.3，官方商店可能已有新版本，以官方页面当时显示为准。
