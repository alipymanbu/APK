AnyPlay 是一款安卓上的视频播放器，同时带文件管理和网页视频下载功能，适合想在手机上集中管理本地视频、顺手从网页存视频的人。本篇从拿到安装文件讲到装完后的第一步操作，装完遇到播放问题再去看排查那篇。

| 项目 | 值 |

| MD5 | A61FEA62ECE9D2AAE0E0AA4F860181F5 |

说明：这款应用更新比较勤，网上搜到的「官方最新版」版本号通常比这份新。**版本号、包名、体积一律以上表为准**——网盘里放的就是这一版。装好后想确认版本，一般在应用内「设置 / 关于」里能看到。

## 二、把安装文件从网盘转到手机

1. 点开 [AnyPlay 安装文件资源（夸克网盘）](https://pan.quark.cn/s/fb3fdc4eb0cf)；
2. 登录夸克账号（没有就现场注册一个，免费）；
3. 选「保存到网盘」，把它转存到你自己的网盘空间；
4. 手机上打开夸克 App，登录同一个账号；
5. 在「我的网盘」里找到刚转存的 AnyPlay 安装包，点下载到手机本地。

也可以在电脑上完成转存，再用手机登录同一账号下载，步骤一样。

## 三、允许安装未知来源应用

APK 不是从应用商店下的，安卓默认会拦。你需要给「用来打开这个 APK 的应用」授权：

1. 手机「设置」→「应用管理」（部分品牌叫「应用设置」）；
2. 找到你将用来打开安装包的那个应用（夸克 App 或系统文件管理器）；
3. 进入它的权限设置，打开「安装未知应用 / 允许安装未知来源」。

不同品牌路径略有差异：小米在「特殊权限」里，华为 / 荣耀在「更多安全设置」里，vivo / OPPO 一般在点开安装包时当场弹窗，选「仍要安装」或「仅此一次允许」即可。

## 四、首次启动要给的权限

装完第一次打开，AnyPlay 会请求媒体相关权限，建议都允许，不然功能用不全：

| 权限 | 不给会怎样 |
| --- | --- |
| 照片和视频 / 存储权限（旧系统叫「存储」） | 扫不到手机里的视频，列表是空的 |
| 音乐和音频（部分系统合并进媒体权限） | 音频文件识别不出来 |

后面用到「弹窗小窗播放」时，系统还会要「显示在其他应用上层 / 悬浮窗」权限，到时候再给也行。

## 五、装完先做这三件事

1. **扫一遍媒体库**：进「视频」或「文件夹」页，等它把手机和存储卡里的视频列出来；
2. **试播一个**：随便点开一个视频，确认画面、声音正常；放不出来就按[支持格式与播放问题排查.md](支持格式与播放问题排查.md)里的顺序过一遍；
3. **顺手熟悉手势**：播放界面上滑动是快进快退、调亮度调音量，具体见[视频播放与手势操作.md](视频播放与手势操作.md)。

想从网页存视频的，直接看[网页视频怎么下载.md](网页视频怎么下载.md)。

## 六、以后出了新版本怎么更

网盘里这份是 1.2.3，官方渠道后来还会发新版本。更新时的两条通用规律：

- **覆盖安装即可升级**：新 APK 的包名一致（`videopalyer.hd.video.music.player`），直接装在上面，不用先卸载；播放记录和设置一般会保留（个别版本例外，以实际为准）；
- **想降回旧版才需要卸载重装**：先卸载当前版本再装旧 APK。注意：卸载会连带清掉应用私有目录里的数据——如果你用过隐藏视频功能，务必先按[隐藏视频与隐私保护.md](隐藏视频与隐私保护.md)里的办法把视频移出来，再卸载。
