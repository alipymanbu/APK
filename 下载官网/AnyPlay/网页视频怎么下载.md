除了播本地视频，AnyPlay 还带一个内置浏览器，可以在应用里打开网页、把页面上的视频直接存进手机。这篇讲清楚入口在哪、清晰度怎么选、下不动的时候按什么顺序排查。

## 一、下载入口在哪

打开 AnyPlay 里「下载器 / 发现」类的入口，会进入内置浏览器。在里面像平时一样打开有视频的网页，播放页上会出现下载按钮，点它就开始下载。

下载能力对站点的兼容性参差：普通视频页成功率较高；需要登录、会员专享、加密流的站点下不动是正常的，这不是播放器坏了。

## 二、下载时选清晰度

点下载后会让你选分辨率，常见档位：

| 档位 | 适合场景 |
| --- | --- |
| 1080P / 720P | 想投屏、在大屏上看 |
| 540P / 480P | 日常手机看，兼顾体积 |
| 360P | 只求快速存一份 |

同一部片子，档位越低体积越小，手机空间紧张就往低选。

## 三、书签与下载管理

常用站点可以加书签，下次不用重新输网址。下载列表里能看到每个任务的进度，下完的视频会进 AnyPlay 的媒体库，和本地视频放在一起管理，排序、归类的方式见[视频播放与手势操作.md](视频播放与手势操作.md)第五节。

## 四、下载的视频存在哪

应用内最直接：媒体库的「下载 / 最近添加」类视图里能看到刚下的片子。想用文件管理器找实体文件，按安卓的通用规律排查（具体路径以实际版本为准）：

1. 手机内置存储的 `Movies/` 或 `Download/` 目录；
2. 存储卡上同名目录（如果片源存到了 SD 卡）；
3. 都没有就回到 AnyPlay 媒体库，确认下载任务是否真的完成了。

安卓各应用下载文件的默认落点不同，「下载的视频找不到」多半是落在了别的目录，按上面顺序找一遍即可。下好的片子不想出现在普通列表里，也可以隐藏起来，做法见[隐藏视频与隐私保护.md](隐藏视频与隐私保护.md)。

## 五、下载失败排查顺序

1. **换个清晰度再试**：高清晰度的源经常拿不到，降到 480P / 360P 常常就过了；
2. **确认网页能在内置浏览器里正常播放**：网页本身放不出来，下载自然也没戏；
3. **检查网络**：部分站点对移动网络限速，换 Wi-Fi 试试；
4. **确认视频有没有访问限制**：要登录、会员专享、加密流的内容下不了；
5. 都不行就换个源——这类下载器对站点兼容性本来就参差。

下好的视频想挪位置、重命名，用 AnyPlay 自己的文件管理或手机自带的文件管理器都行。安装入口还没搞定的，回[下载与安装教程.md](下载与安装教程.md)。
