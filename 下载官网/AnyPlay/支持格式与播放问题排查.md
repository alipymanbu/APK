「这个片子它放不放得出」取决于两件事：封装格式在不在支持范围、解码器选得对不对。这篇先给官方的格式清单，再给一套从软到硬的排查顺序，大多数播放问题在前两步就能解决。

## 一、官方列出的支持格式

| 类型 | 格式 |
| --- | --- |
| 视频 | MKV、MP4、M4V、AVI、MOV、3GP、FLV、WMV、RMVB、TS 等 |
| 音频 | MP3、M4A 等 |

清单带「等」字，意味着不限于表内格式——实际能不能播，装上试一下最快。

## 二、放不出来？先切软解

最常见的「有片放不出」是解码器问题，排查顺序：

1. 进播放设置，把解码方式从**硬解**切到**软解**（或反过来）再试；
2. 还不行，确认文件本身没坏——在电脑上或别的播放器里能不能正常播；
3. 文件正常、软硬解都试过仍黑屏，基本可以判定这个封装 / 编码不在支持范围内，换个片源。

## 三、常见症状对照

| 症状 | 优先怀疑 | 处理 |
| --- | --- | --- |
| 花屏、绿屏、马赛克块 | 硬解兼容性 | 切软解 |
| 有画面没声音 | 音轨编码设备不支持 | 换有多条音轨的片源，或换格式 |
| 有声音没画面 | 封装 / 编码组合罕见 | 切软解试试 |
| 卡顿、掉帧 | 片子码率高、手机性能吃紧 | 换低清晰度片源，关掉后台应用 |
| 字幕乱码 | 字幕文件编码不是 UTF-8 | 用文本编辑器把字幕另存为 UTF-8 再导入 |
| 列表突然空了、视频「消失」 | 存储权限被系统省电策略收回 | 到系统「应用信息 → 权限」里重新给媒体权限，再进应用等它重扫 |

## 四、关于版本与格式支持的提醒

网盘里这份是 1.2.3 版，官方后来还在更新。如果你装的是更新的版本，支持的格式清单和设置入口可能有出入，**以你手上那一版的实际表现为准**。
