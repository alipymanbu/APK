## 一、小组件能干什么

FlowMark 提供多尺寸的桌面小组件，装好后你可以在桌面上直接完成打卡、计时、查看待办，不用每次点进应用。部分版本的组件还带周视图摘要、标签占比饼图（点组件右侧区域打卡、点左侧唤起应用，是某些版本的交互设计，以你手上版本为准）。

前提是先装好应用 —— 桌面组件列表里没有 FlowMark，多半是还没安装或安装没成功，见 [下载与安装教程.md](下载与安装教程.md)。

## 二、安卓手机添加步骤

不同品牌手机对「小组件」的叫法不一样（小组件 / 窗口小工具 / 原子组件 / 卡片），入口都是**长按桌面空白处**：

1. 长按桌面空白位置，等桌面进入可编辑状态；
2. 点底部或顶部出现的「小组件 / 窗口小工具 / 卡片」入口；
3. 在列表里找到 FlowMark（列表长的话直接搜索）；
4. 左右滑动选尺寸，长按拖到桌面空白处放下；
5. 部分组件支持点选显示哪几条习惯 —— 拖出后点一下组件进入选择页。

添加后点组件上的打卡按钮即可直接记一次，不用打开应用。

## 三、iPhone 添加步骤

1. 长按主屏幕空白处，图标开始抖动；
2. 点左上角 `+`，打开小组件库；
3. 搜索 FlowMark，选尺寸后点「添加小组件」；
4. 点右上角「完成」。

iOS 版的组件同样支持在桌面直接操作，具体支持哪些控件以组件库中实际展示的为准。

## 四、组件不显示 / 点不动

| 现象 | 处理 |
| --- | --- |
| 组件列表里找不到 FlowMark | 确认已安装完成；部分桌面需要重启桌面或重启手机后才刷新组件列表 |
| 组件显示但数据是空的 | 组件读的是本地库，先打开应用完成一次同步加载，再回桌面看 |
| 点组件没反应 | 省电模式杀后台会导致唤起失败，把 FlowMark 加入后台白名单（见 [常见问题与解决方法.md](常见问题与解决方法.md) 第二节） |
| 旧版本没有组件入口 | 组件功能随版本演进，版本较旧时可能没有或尺寸不全，可考虑更新版本 |

如果你只是想偶尔补一次卡，直接打开应用点 `+1` 就够了 —— 组件解决的是「高频、一步完成」的场景，见 [打卡与统计功能使用教程.md](打卡与统计功能使用教程.md)。
