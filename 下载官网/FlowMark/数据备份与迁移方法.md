## 一、你的数据存在哪

FlowMark 的核心功能是**纯本地运行**的：记录存在手机上，断网、不开飞行模式都能正常打卡，注册登录也不是使用前提。这带来两个直接后果：

- 好处：隐私相对可控，应用不靠你的记录联网干活；
- 代价：**手机丢了、卸载了、清了数据，本地记录就没了** —— 备份要自己动手。

## 二、导出 ZIP 备份包（最主要的备份方式）

应用支持生成**标准 ZIP 备份包**，这是跨设备迁移数据的通用做法：

1. 在应用的设置/数据相关页面里找「导出 / 备份」入口（不同版本菜单名略有差异）；
2. 生成 ZIP 备份包后，保存到手机本地；
3. 把这个文件传到你自己的存档位置 —— 电脑、网盘都可以。

**建议养成的习惯**：每月固定导出一次，ZIP 包丢进自己的网盘。打卡数据是纯文本类记录，文件很小，存一份几乎零成本。

## 三、换手机怎么迁移

| 场景 | 做法 |
| --- | --- |
| 新机是安卓 | 旧机导出 ZIP → 传到新机 → 在新机的 FlowMark 里用导入/恢复功能读入 |
| 换到 iOS | 同样走 ZIP 备份包，标准 ZIP 格式的用意就是跨平台迁移；能否完整读入以实际导入结果为准 |
| 同为 iPhone/iPad | 苹果版支持一键备份到 iCloud 云盘（iCloud 同步是苹果生态能力，安卓版不适用） |

别把希望全押在「手机克隆 / 换机助手」上：这类工具是否连应用内的打卡数据一起搬、搬过去能否被读出来，**因品牌与系统版本而异**，没法提前保证。导出 ZIP 是唯一你亲手验证过的那份底稿，换机前务必先导出，再把克隆当锦上添花。

换机前**务必在旧机上先导出再换**，不要指望安装包还在就能找回数据 —— 重装 APK 只恢复程序，不恢复记录。

## 四、关于云端备份

- **安卓版**：官方对「云同步」的表述以应用内为准；部分渠道把云端自动备份标为 Pro 版功能。没有开成云端备份也不影响使用 —— 手动导出 ZIP 是人人可用的兜底。
- **iOS 版**：走 iCloud，前提是你的 Apple ID 有可用的 iCloud 空间。

## 五、和安装包一起归档

网盘里的 [FlowMark 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a9e288f43091) 存的是 APK 安装文件。换机时的完整流程是：**旧机导出 ZIP → 新机先装 APK → 再导入 ZIP**。只留 APK 不留备份包，装上后是一个空库。APK 版本信息见 [下载与安装教程.md](下载与安装教程.md)；导入、恢复相关的异常处理见 [常见问题与解决方法.md](常见问题与解决方法.md)。
