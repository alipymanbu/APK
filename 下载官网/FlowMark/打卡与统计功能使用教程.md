## 一、先建一个习惯

应用主界面右上角有 `+` 按钮，这是你以后用得最多的入口：

1. 点右上角 `+`，进入新建事件/习惯页面；
2. 从预设分类里挑一个（如生活日常、健康习惯、心情日记、旅行、简单记账这类场景模板），也可以自定义：填名称、选颜色/图标、设分组；
3. 按需设置提醒时间、打卡周期、展示模式；
4. 点右上角「保存」，习惯就出现在首页列表里。

一个建议：**第一次别建太多**。先建一两个真正每天会做的（喝水、阅读、早睡），跑通「打卡 → 看统计」的循环，再批量加别的。

## 二、日常打卡

在首页的习惯列表里，点某条习惯右侧的 `+1` 就完成一次打卡；需要补细节时可以进入编辑页，补记内容、文字备注、评分（支持文本、多选、1-5 星这类状态记录）。

记录方式不只有「打个勾」：

| 记录方式 | 适用场景 |
| --- | --- |
| 次数打卡 | 喝水、服药这类一天多次的事，点一次记一次 |
| 计时 | 读书、专注这类要记时长的事，开始/结束各点一下 |
| 纯记录 | 体重、金额、步数这类只存数值的项 |
| 文字 / 照片备注 | 心情日记、留档，配文字或图片 |

手动编辑打卡时间也是允许的 —— 补录昨天的记录不用另找入口。

**目标不止「连续打卡」一种**：设置里可以把目标设成累计型（累计 100 小时）、倒计时型、区间型或最新值型，长期项目用「累计了多少」比「连续几天没断」更贴合实际。

打卡频率高的话，把 [桌面小组件添加方法.md](桌面小组件添加方法.md) 里的组件放上桌面，一步完成不用进应用。

## 三、看统计数据

底部导航进入「数据」栏 → 点选某条记录，就能看到该习惯的日期统计，并且可以编辑修改或分享导出。可用的可视化形态包括：

- **折线图 / 柱状图**：看一段时间的打卡趋势与各习惯对比；
- **热力图**：按记录的数值深浅渲染颜色（比如起床时间），一眼看出整月作息规律；
- **摘要（周/月/年）**：汇总列表支持自定义排序，把最在意的习惯排在前面。

部分版本还支持把进度导出为文件或分享卡片，入口以你手上版本的界面为准。

## 四、两个值得先设置的功能

**深色模式**：底部导航点设置图标 → 找到「显示模式」→ 下拉选择「深色」，界面立即切换。

**跨天时间（夜猫子模式）**：在设置里可以自定义「一天从几点开始」。如果你常在凌晨两点复盘打卡，把跨天时间调晚，记录会算进「昨天」，不用手动补卡。

## 五、提醒不响？先把权限给了

FlowMark 的打卡提醒依赖系统通知权限，安卓 13+ 安装后默认不会自动开启：

1. 手机 设置 → 应用 → FlowMark → 通知，允许发送通知；
2. 应用申请日历相关权限（`READ_CALENDAR` / `WRITE_CALENDAR`）时，同意后提醒才能写入系统日历；
3. 若手机有「后台弹出界面 / 悬浮窗」限制（应用申请了 `SYSTEM_ALERT_WINDOW` 权限），在系统设置里允许，弹窗类提醒才不会被拦。

国产手机还要额外检查电池优化白名单，不让系统在后台杀掉它 —— 详见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 六、免费版与 Pro

FlowMark 免费可用，核心打卡与基础统计不付费也能用；应用内提供购买项目（Pro），部分渠道把 Pro 描述为：云端备份、深度数据报告、自定义主题、完整导出等。**具体哪些功能归 Pro、价格多少，一律以应用内购买页显示为准**，不同版本的划分可能不同。
