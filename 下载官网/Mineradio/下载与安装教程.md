## 一、先确认你要装的是哪一版

Mineradio 是一款按 GPL-3.0 协议开源的音乐播放器，官网为 [mineradio.cn](https://mineradio.cn/)，源码托管在 [GitHub](https://github.com/XxHuberrr/Mineradio)，提供 Windows、macOS、Android 与网页版四种入口。按官方仓库的公告，项目目前处于长期停更状态，官网与仓库保留源码和历史版本供继续使用。

本篇对应的安卓安装包信息如下。这是一份固定的存量版本，和官网现在挂出的安卓最新版不是同一个：

| 项目 | 信息 |
| --- | --- |
| 版本号 | 1.1.5 |
| 包名 | com.mineradio.app |
| 安装包大小 | 40.85 MB |
| MD5 | 0CCAC0D50298FBDF78EA73D3201E87C2 |
| 系统要求 | 安卓 5.2 及以上（以安装包实际要求为准） |

两点版本背景，选的时候心里有数：

- 官网当前提供的安卓最新版要求安卓 8.0 及以上，界面与功能较 1.1.5 有增改；
- 官方公告明确提示 v1.0.10 及更早的安装包不建议继续安装，本文这份 1.1.5 不在该范围内。

## 二、安装包从哪来

从 [Mineradio 安装文件资源（夸克网盘）](https://pan.quark.cn/s/490e91ce55c1) 打开分享页，转存到自己的网盘后再下载到手机，得到的是 `Mineradio_v1.1.5.apk`。下载完先看一眼文件大小是否在 40.85 MB 上下，明显偏小说明没下完整，重下再装。

## 三、安装步骤

1. 在手机上点开 `Mineradio_v1.1.5.apk`；
2. 系统弹出「是否允许安装」时选择允许；如果提示先开启「安装未知来源应用」，按提示跳到系统设置，把权限授给这次打开安装包的入口（浏览器或文件管理器），再返回重试；
3. 等安装进度走完，点「打开」或回桌面点图标启动；
4. 首次启动进入首页：顶部是搜索框，右上角有「登录」入口，接入网易云/QQ 音乐账号的步骤见 [账号登录与歌单同步.md](账号登录与歌单同步.md)。

## 四、装不上时先查这几项

| 现象 | 先查什么 |
| --- | --- |
| 点安装包没反应，或提示「解析失败」 | 文件多半没下完整，重新下载并核对大小与 MD5 |
| 文件大小正常却提示「解析包出现错误」 | 部分系统的「纯净模式」会拦第三方安装包，先关闭再装；同时确认存储空间充足 |
| 提示存储空间不足 | 清出比安装包大出数倍的可用空间再装，安装过程需要额外空间展开文件 |
| 提示与已有应用冲突 | 手机里可能装过同包名（com.mineradio.app）的旧版，先卸载再装 |
| 提示系统版本过低 | 确认安卓版本不低于安装包要求；差得远的机器装不了 |

装好之后用起来的其他问题，集中列在 [常见问题排查.md](常见问题排查.md)；想把本地音频文件导进去，看 [本地音乐导入与歌单管理.md](本地音乐导入与歌单管理.md)。
