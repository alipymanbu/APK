## 一、先连上：蓝牙手柄的标准流程

外接手柄能让你不用手指盖住屏幕地玩 DS 游戏，但配对之后还差「映射」这一步——手柄按键要逐个对上 DS 的键位才生效。流程分三步：

1. 手柄进入蓝牙配对模式，在安卓 **设置 → 已连接的设备 → 配对新设备** 里点中它；
2. 连接成功后打开 DraStic → 设置 → **External Controller**；
3. 选一个映射槽（**Select key mapping**），点 **Map Keys / Map Special**，在弹出的映射对话框里依次按手柄按键，把 DS 的方向键、A/B/X/Y、L/R、Start/Select 对上去。

映射相关的几个实用选项：

| 选项 | 作用 |
| --- | --- |
| Select key mapping | 最多保存 **3 组**映射——可以给不同手柄、或同一手柄的两种键位各存一套 |
| Rename | 有些手柄识别出来是通用名，改个名好区分；想给一只手柄存两套键位也靠它 |
| Map Keys / Map Special | 逐键映射；除了普通按键，还能把某个键映射成**换屏**功能（单屏布局下特别有用） |
| Disable mapped keys in overlay | 开启后，已映射到实体键的虚拟按键不再显示，画面更干净 |
| Enable analog triggers | 手柄的 L/R 是线性扳机时开启，才能识别行程 |
| Fast-forward toggle mode | 开：映射键按一下切换快进开/关；关：按住才快进 |

映射完直接进游戏试，手感不对回来改，不用重启。

## 二、右摇杆当触控笔：FPS 类游戏的解法

DS 没有摇杆，但不少游戏（尤其第一人称类）靠触屏拖动视角。**Right Stick Mode** 允许你把外接手柄的右摇杆映射成触控输入，两种模式自选：

- **FPS mode**：按 FPS 游戏习惯拖动视角；
- **Stick mode / Pointer Mode**：右摇杆直接移动一根「笔尖指针」，配合一个映射键按下——等于用手柄遥控触屏。

配套的 **Right-Stick Deadzone**（死区）用来消除摇杆漂移：指针自己慢慢挪就调大它。哪种模式合手没有标准答案，两种都试一遍，看哪个游戏用哪个。

## 三、没有手柄时：虚拟按键的排布

设置 → Virtual Gamepad Settings（电视模式下没有这组）：

- **Controller opacity**：虚拟按键透明度，0% 全透明、100% 不透明。嫌按键挡画面就调低，嫌按不准就调高。
- **Always show start and select buttons**：Start/Select 默认收在屏幕底部中央的「扩展按钮」里，开启后常驻显示，玩要用 Start 菜单的游戏省一次点击。
- **Menu-Button position**：那个 `^` 快捷菜单按钮的位置，可以改甚至隐藏——**但如果你没把它映射到任何实体键就藏了它，游戏内将打不开快捷菜单**，等于自断一臂。
- **Special Button I / II / III**：给三个特殊槽位指派功能：快进、快速存/读档、换屏、单/双屏布局切换、显隐虚拟按键、模拟麦克风、自动连发（连发只对 A/B/X/Y/L/R 生效）。
- **D-Pad touch region modifier / Action-Button touch region modifier**（1.0~2.0）：扩大方向键与 A/B/X/Y 的触控感应区，手指总差一点就调大。
- **No diagonal input for on-screen D-Pad**：屏蔽斜向输入，只留上下左右——给不需要斜方向的游戏防误按。
- **Skin**：换虚拟手柄皮肤。自带 Default，另外官方皮肤 `Simple` 放在 `/sdcard/DraStic/virtual_controller`；想自制就做一组同名 PNG 打成 `.zip` 丢进该目录，设置里会自动列出。
- **Haptic feedback**：按下虚拟键时震动（设备支持才有）。

## 四、游戏内快捷菜单（`^` 按钮）与手柄操作

游戏中点屏幕上的 `^` 按钮（或你映射的「Open Menu」键）会呼出环形快捷菜单，游戏随之暂停。顺时针依次是：关 DS 上盖、开关触控、快速存档、交换上下屏、进完整游戏菜单、单/双屏布局切换、快速读档、显隐虚拟按键；中央的 `>>` 是快进开关。

用手柄操作这套菜单：左摇杆/方向键移动选择，**映射为 DS B 键的键确认，映射为 DS A 键的键取消**（例如「读快速档」= 方向键左 + B 键）。环形四周的小圆钮直连功能：L = 声音开关、R = 模拟吹气、X = DS Select、Y = DS Start。

调完手柄若遇到卡顿、花屏之类的问题，多半是视频选项的事，见 [画面与性能设置优化.md](画面与性能设置优化.md) 与 [常见问题与解决方法.md](常见问题与解决方法.md)。
