## 一、两种存档，用途完全不同

玩 DraStic 会同时遇到两套存档机制，很多「进度丢了」的抱怨其实是混用了它们。本篇把两者的区别、自动存档与保险开关、云端同步、游戏内时间的怪现象，以及重装换机前的备份步骤一次讲清：

| | 即时存档（Save State） | 游戏内存档（in-game save） |
| --- | --- | --- |
| 存的是什么 | 整台模拟器此刻的全部状态 | 游戏自己写的存档，等同当年实体卡带的存档 |
| 怎么存 | 游戏菜单选 Save State，读取用 Load State | 游戏内正常存档流程（菜单 → 存档） |
| 特点 | 随时随地、精确到任意一帧 | 兼容性最好，换模拟器、换设备都通用 |
| 风险 | 覆盖了就找不回（除非开了确认弹窗） | 依赖游戏自身的存档机制 |

**实用建议**：日常「随手一存」用即时存档，推进到关键剧情后再用游戏内正规存一次——两套各存一份，任何一边出问题都还有退路。

## 二、自动存档与两个保险开关

- **Autosave**（设置 → General）：你退出 DraStic 时自动存下当前进度。它**不占**正常存档槽，下次打开只有点主菜单的 **Continue** 才会恢复这份进度。
- **Savestate overwrite needs confirmation**：每次覆盖即时存档前弹确认，防手滑覆盖掉几小时的进度。
- **Savestate loading needs confirmation**：读档前也弹确认，防止在存档列表里误点读进旧档、把当前没存的进度冲掉。

长期玩的话建议把两个确认都打开，代价只是每次多点一下。

## 三、进阶选项「Store in-game saves in savestates」要不要开

设置 → Advanced 里有一项 **Store in-game saves in savestates**，作用是把游戏内存档复制一份塞进即时存档文件里，让两者始终保持同步。官方帮助同时标注了风险：**在部分游戏（尤其是宝可梦系列）里，两套存档不同步会导致游戏内存档损坏**。

判断口径很简单：

- 你只用即时存档、不走游戏内存档 → 开着问题不大；
- 你在正常玩宝可梦这类依赖游戏内存档的游戏 → **保持关闭**，并按第一节的做法两套都存。

Advanced 分组里的其他选项（自动解包、忽略卡带上限、ROM 裁剪等）都标注了「可能破坏游戏或造成不稳定」，不清楚用途就别动。

## 四、把存档同步到 Google Drive

DraStic 内置了 Google Drive 同步（设置 → Google Drive），可以把即时存档传到云端，换手机、重装后拉回来：

1. 进入存/读档菜单，点 **Available on Google Drive** 手动刷新各槽位的云端可用状态；
2. 打开该设置项的自动刷新后，每次进存/读档菜单都会自动查一遍（**需要联网**，不想让它自动联网就把自动刷新关掉）；
3. 换账号用 **Reset Google Drive account** 清掉绑定，下次用功能时重新选账号。

两个官方帮助里点名的故障点：一是云端的 `DraStic` 文件夹偶尔创建失败，上传后去网盘里看一眼，没有就手动建一个再传；二是**从云端下载恢复要求所有设备上的游戏文件名完全一致**，文件名不同步会拉不下来。存档文件的具体路径与格式见 [存档迁移到其他模拟器.md](存档迁移到其他模拟器.md)。

没有谷歌服务的机型用不了这个功能，退回本地备份（见第六节）。

## 五、游戏内时间：快进会让时间「跑偏」

DS 游戏普遍带实时时钟（RTC），DraStic 的处理方式是：**只在模拟器启动时取一次安卓系统时间，之后按模拟时间走**。由此产生的三个现象都正常：

- 开快进赶路 → 游戏内时间跟着变快；
- 读一个旧的即时存档 → 时间回到存档那一刻继续算；
- 想和现实时间重新对齐 → **重启游戏并读游戏内存档**即可（官方帮助给出的复位办法）。

另外设置里有 Custom System Date / Custom System Time，可以手动指定 RTC 的起始时间——不确定自己在干嘛就别碰，用上面的重启复位法更省事。

## 六、重装、换机前怎么备份

DraStic 会在手机存储里建自己的数据目录（官方帮助提到的皮肤路径 `/sdcard/DraStic/virtual_controller` 就在其中）。可靠的做法：

1. 用文件管理器找到手机存储根目录下的 **DraStic 文件夹**；
2. 整个文件夹复制到电脑或云盘——不要只挑里面的某个子目录，不同版本的存档子目录布局可能有差异；
3. 装好新版本（或换机后）再把整个文件夹拷回原位，先启动一次确认进度在。

动手前多做一层保险：先在游戏内正规存一次档，确认能读回来，再开始搬文件。搬完想把进度接到其他模拟器上，走 [存档迁移到其他模拟器.md](存档迁移到其他模拟器.md) 的步骤；装新版本的具体步骤见 [下载与安装教程.md](下载与安装教程.md)。
