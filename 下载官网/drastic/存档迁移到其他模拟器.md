## 一、先分清两类文件：能搬的和不能搬的

换模拟器、换手机之前，先搞清楚你手里的存档属于哪一类——**只有其中一类能跟着你走**：

| 文件 | 扩展名 | 能否跨模拟器 |
| --- | --- | --- |
| 游戏内存档 | `.dsv` | 能（需按下面的步骤改名放置） |
| 即时存档 | `.ds1`、`.ds2` … `.ds9` | **不能**，各家模拟器的状态格式互不兼容 |
| 自动存档 | 通常占槽位 0 | 同即时存档，不能跨模拟器 |

结论先说：**想把 DraStic 的进度带去别的模拟器，唯一的通道是游戏内存档**；即时存档只能在 DraStic 内部用。这也是 [存档与进度备份.md](存档与进度备份.md) 一直建议「关键进度用游戏内存档正规存一次」的原因。

## 二、存档文件在哪

DraStic 的存档统一放在一个 backup（备份）目录里，路径随安卓版本与应用版本有新旧两种口径：

- **新版本**（适配分区存储的安卓）：`/Android/data/com.dsemu.drastic/files/backup/`
- **旧版本 / 旧系统**：手机存储根目录下的 `DraStic/backup/`

拿不准就以你设备上实际存在的那个为准——两个路径都找一遍，哪个里面有你的 `.dsv` 文件就是哪个。目录里的内容对应关系：

- `*.dsv` → 各游戏的游戏内存档，一个游戏一份；
- `*.ds1` ~ `*.ds9` → 即时存档槽位；
- 自动存档 → 通常占槽位 0。

另外两条文件名规则，搬家前必读：

1. **即时存档绑定 ROM 文件名**——保存之后再改游戏文件名，槽位就读不回来了；
2. **Google Drive 下载恢复的前提是所有设备上的 ROM 文件名完全一致**（官方帮助原文口径），文件名不同步会导致云端存档拉不下来。

## 三、把存档转到 melonDS（或同类模拟器）

步骤在多个独立来源（melonDS 官方论坛、第三方教程）基本一致：

1. 在 DraStic 里用**游戏内正规存档**存一次（别拿即时存档当数据源）；
2. 进入上一节的 backup 目录，找到目标游戏的 `xxx.dsv`，复制出来；
3. 把它改名为 `.sav`，且**主文件名与你在 melonDS 里用的游戏文件名完全一致**（大小写也一致），放在游戏文件旁边；
4. 在 melonDS 里启动该游戏，读取存档。

**两边口径有分歧的地方，照实说**：有教程认为「改个扩展名放过去」就够了；melonDS 开发者在论坛里补充，DraStic 的 `.dsv` 尾部带有一段附加数据，严格做法是用十六进制编辑器把文件裁到 2 的幂的大小。所以：

- 按第 3 步做完能读出来 → 结束；
- 读不出来或提示存档损坏 → 再按 melonDS 开发者的说法裁剪尾部数据（这一步涉及改文件内容，动手前先把原文件备份一份）。

## 四、反向：从 DeSmuME（电脑）把存档带进 DraStic

1. 在电脑端 DeSmuME 里用**游戏内存档**存一次，拿到同名的 `.dsv` 文件；
2. 确认主文件名与手机上该游戏的文件名一致（只改后缀对齐 `.dsv`）；
3. 把文件放进 DraStic 的 backup 目录（第二节的两个路径二选一，放你设备实际用的那个）；
4. 手机上启动同一个游戏，正常会直接读到进度。

若读不到：先在 DraStic 里新开档存一次，再用电脑上的文件**覆盖**这个刚生成的同名文件——这样能排除「目录不对」的干扰，只可能是文件本身的问题。

## 五、搬完之后的验证动作

不管方向是哪边，搬完都做同一件事：进游戏读档 → 确认队伍、道具、进度都在 → 再覆盖存一次。读不出来时按顺序回查：文件是否在 backup 目录、主文件名是否与 ROM 逐字一致、是否错拿了 `.ds1` 这类即时存档文件。更广义的备份策略见 [存档与进度备份.md](存档与进度备份.md)，日常故障排查见 [常见问题与解决方法.md](常见问题与解决方法.md)。
