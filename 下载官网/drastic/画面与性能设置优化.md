## 一、设置入口

DraStic 的选项按视频、音频、通用等分组铺在设置页里，其中跳帧、3D 分辨率、音频延迟三项直接决定你这台设备玩起来卡不卡、糊不糊；本篇逐项讲清每个选项改了会发生什么，并给一套按设备档位的起步配置。入口有两个，进的是同一套选项：

- 主菜单 → **Configure options**：全局设置，对所有游戏生效；
- 游戏内菜单 → **Options**：调的是同一套选项，边玩边调方便对比效果。

部分选项在特定硬件上不存在（比如安卓电视上就缺一批虚拟手柄选项），找不到就是你的设备不支持，不是操作错了。下面按设置页的分组逐个说。

## 二、视频（Video）：决定画质与流畅度的核心

| 选项 | 作用 | 怎么选 |
| --- | --- | --- |
| Frame skip type（跳帧方式） | `manual` 手动跳帧：每 N+1 帧渲染 1 帧（设 2 就只渲染 1/3）；`automatic` 只在跑不满速时才跳，且连续不超过 N 帧 | 卡就设 `automatic` + 1~2；不卡保持 0 |
| Frameskip value（跳帧值） | 上面那个 N，取值 0~9 | 0 = 全帧渲染最流畅但最吃性能 |
| Fast-forward maximum speed（快进上限） | 游戏内按快进键时的最大倍速 | 只是上限，实际速度受设备限制——设 300% 而设备只能跑 200%，也就 200% |
| Filter（滤镜） | 缩放滤镜，由 GPU 着色器实现，性能开销很小 | 想画面柔和就开，开销可忽略 |
| High-Resolution 3D Rendering | 3D 以两倍分辨率渲染，画面明显变清晰 | 需要强机（最好四核）；2D 游戏开了没收益 |
| 16-bit rendering | 改用 16 位纹理格式，画质下降、部分设备反而更流畅 | 低端机救急用 |
| Multi-threaded 3D rendering | 把渲染任务丢到别的核心，提速明显 | **可能造成花屏与不稳定**——排查问题前先把它关掉 |
| Keep Main Screen on Top Screen | 强制「主引擎画面」固定在上屏，忽略游戏自己的上下屏交换 | 像 Sonic Rush、Sonic Chronicles 这类游戏，开着能让上屏始终跟着主角 |

一个要点写在官方帮助里：**跳帧不只是让画面变卡，某些游戏会被跳帧「跳」出画面异常**——遇到图形错乱，第一反应是把跳帧关掉试一次，再考虑别的。

## 三、音频（Audio）

- **Audio Latency（音频延迟）**：追求音画同步就设 `low`；如果游戏因此变卡，退回 `medium` 或 `high`。
- **Sound enabled**：全局静音开关，关了所有游戏都没声。
- **Device microphone enabled / Microphone Level**：DS 有不少游戏要用麦克风（吹气、喊话类互动）。平时关掉能省点电，玩到需要麦的关卡再开，并调好灵敏度。

## 四、通用（General）里与体验直接相关的几项

- **Show FPS**：屏幕上显示实时帧率，调设置时开着它，改一项看一眼数值，效果一目了然。
- **Autosave**：退出 DraStic 时自动存一份进度。这份存档**不占用**正常存档槽，下次启动只有从主菜单点 **Continue** 才会接上。
- **Disable back button**：禁用安卓实体/手势返回键的默认作用。推荐打开——不然玩到一半误触返回，直接被踢回游戏菜单。
- **Savestate overwrite / loading needs confirmation**：即时存档的覆盖与读取各加一次确认弹窗。手上有要紧进度就打开，防误覆盖。详见 [存档与进度备份.md](存档与进度备份.md)。
- **Landscape Layout Rotation**：横屏布局的旋转策略。`Auto` 自动旋转；选了竖屏布局则永不自动旋转（有些游戏要竖着「书本式」玩）。需要固定方向时可改 `Landscape` / `Reverse Landscape`。

## 五、按设备档位的参考组合

拿不准从哪套起手，就按设备档位对号入座，进去先照这个设，再按 Show FPS 的读数微调：

| 设备档位 | 跳帧 | 高分辨率 3D | 滤镜 | 其他 |
| --- | --- | --- | --- | --- |
| 低端（老机器、2GB 内存） | automatic，值 2~3 | 关 | 关 | 需要时开 16-bit rendering |
| 中端 | automatic，值 1 | 关 | 开 | 音频延迟 low，卡了改 medium |
| 高端 | 0 | 开 | 开 | 多线程渲染可试，出花屏就关 |

调完记得观察两点：帧率上去了但画面出现撕裂错乱 → 关跳帧或多线程；画质没变化却变卡 → 关高分辨率 3D。改崩了随时可以在设置里恢复默认，再对照 [常见问题与解决方法.md](常见问题与解决方法.md) 定位是哪个选项惹的祸。
