## 一、安装阶段的问题

下面按「安装 → 找不到游戏 → 画面 → 性能 → 闪退 → 按键 → 进度 → 支持范围」的顺序组织，多数症状能在一节内对上号；每条给的都是可以直接照做的动作，改完一项进游戏验证一次再改下一项。

**点 APK 提示「无法安装」/「解析包时出现问题」**
先确认文件下完整了（大小应与版本信息对上的 12.30M 量级），再看系统版本是否过旧。多品牌机的拦截图标不同：按提示去 **设置 → 安全/安装未知应用** 给下载来源放行即可，参见 [下载与安装教程.md](下载与安装教程.md) 第五节。

**安装成功但图标打不开、立刻闪退**
基本不是安装问题，往下看第五节的「闪退」。

**从哪拿安装包？网上版本太多分不清**
DraStic 已于 2025 年 2 月从 Google Play 下架、原官网关闭，现在各渠道流传的都是侧载 APK，版本与二次打包情况混杂。认准包名 `com.dsemu.drastic` 与版本号 `r2.6.0.4a`，装完在「设置 → 应用」里核对；本篇所用的文件可直接从 [DraStic 安装文件资源（夸克网盘）](https://pan.quark.cn/s/89c549f0e006) 获取。

## 二、游戏列表里看不到我的游戏

按出现频率排序逐个排除：

1. **存储权限没给** → 设置 → 应用 → DraStic → 权限，授予存储/媒体权限后重进；
2. **文件格式不对** → 用 `.nds`（有资料称 `.zip` 也行），`.rar`、带密码的压缩包它不认；
3. **文件本身坏了** → 换一份确认完好的文件试，损坏的包会静默不出现在列表或启动失败；
4. **目录导航层级不对** → Load New Game 的浏览器要一层层点进真正放文件的那个文件夹。

## 三、黑屏 / 花屏 / 画面错乱

按这个顺序改，每改一项进游戏验证一次：

1. **关掉 Multi-threaded 3D rendering** —— 官方帮助明说它「可能造成图形异常与不稳定，报问题前先关掉」，这是花屏的第一嫌疑；
2. **跳帧调回 0 或关掉** —— 跳帧不止是变卡，部分游戏会被跳出画面异常；
3. **触屏出现在错误的屏幕上 / 画面闪烁** → 把 `Multi-threaded 3D rendering` 与 `Keep Main Screen on Top Screen` 一起关掉（官方帮助点名的组合）；
4. **关掉 High-Resolution 3D Rendering** —— 弱机开双倍分辨率容易出错；
5. 有声音无画面、画面停在某处 → 多半是文件问题，回到第二节查游戏文件。

## 四、卡顿、掉帧、声音不同步

1. 跳帧方式设 `automatic`、值 1~2，用设置里的 **Show FPS** 盯着数值变化；
2. Audio Latency 从 `low` 试到 `medium` / `high`——音频延迟高一档，换来的流畅度有时立竿见影；
3. 关高分辨率 3D、关滤镜之外的负担（16-bit rendering 在部分设备上反而提速）；
4. 快进达不到设定倍速是正常的：**实际速度以设备能力为上限**，设 300% 只能跑到设备极限的 200%。

各选项机理与按档位的组合见 [画面与性能设置优化.md](画面与性能设置优化.md)。

## 五、闪退、卡死、进不了游戏

- **一进某游戏就崩/黑屏进不去** → 先按 [金手指代码使用教程.md](金手指代码使用教程.md) 第三节走两步恢复法（全局关金手指 → 进游戏取消问题码），金手指是此类症状的头号来源；
- **改了某个设置后开始崩** → 到设置里把 Advanced 分组的改动逐项还原，或直接恢复默认；Advanced 里的选项官方标注了「可能破坏游戏或造成不稳定」；
- **纯偶发闪退** → 清一次 DraStic 的缓存再试；仍不稳就重装（重装前先按 [存档与进度备份.md](存档与进度备份.md) 第六节把 DraStic 数据目录备份走）。

## 六、按键与触屏问题

| 症状 | 处理 |
| --- | --- |
| 误触返回键退回菜单 | 开 **Disable back button** |
| 虚拟键总按不到 | 调大 D-Pad / Action-Button 的 touch region（1.0~2.0） |
| 方向键老出斜向误输入 | 开 **No diagonal input for on-screen D-Pad** |
| 手柄映射不生效 | 重新走 External Controller 的 Map Keys；手柄名显示为通用名时用 Rename 另存一组 |
| Start/Select 藏得深 | 开 **Always show start and select buttons** |
| 宝可梦里按 Start 打不开菜单 | 默认 Start 就不绑定任何动作，进菜单要按 **X**（想改键位到改键设置里调） |

更完整的手柄与虚拟键说明见 [手柄连接与按键设置.md](手柄连接与按键设置.md)。

## 七、进度与时间类疑问

- **存档去哪了 / 怎么备份** → [存档与进度备份.md](存档与进度备份.md)，重装前务必整目录备份；
- **存档、即时存档老是莫名消失** → 官方帮助的结论是「DraStic 自己不会删」，历次案例都是**别的应用干的**——重点排查手机上的内存清理、杀毒类 App，把 `DraStic` 文件夹加入它们的排除/白名单；
- **想把进度搬到电脑或其他模拟器** → 只有游戏内存档（`.dsv`）能搬，即时存档跨不了模拟器，步骤见 [存档迁移到其他模拟器.md](存档迁移到其他模拟器.md)；
- **游戏内时间突然变快变慢** → 快进与读即时存档的正常副作用，重启游戏并读游戏内存档即可与现实时间对齐；
- **换了新版本进度还在吗** → 只要 DraStic 数据目录还在、或游戏内存档文件还在，进度就在——版本更新不等于数据清空。

## 八、支持范围类疑问

- **能玩 3DS / 2DS 游戏吗** → 不能。官方帮助的原话是「不支持，而且永远不会」——3DS 是完全不同的一代硬件，别再找所谓「能跑 3DS 的 DraStic 版本」；
- **能联机吗** → 公开资料口径不一：部分页面称支持本地无线联机，也有页面明确「手机端仅本地单机」。两边并列在此，没有更高级别的可靠证据前不替你下结论，实测以你的游戏与网络环境为准；
- **某个游戏以前能跑、突然不跑** → 先核对版本号是否与菜单显示一致（本篇口径是 `r2.6.0.4a`），再按第三节、第五节的顺序排查：视频选项、金手指、游戏文件本身，逐项隔离。
