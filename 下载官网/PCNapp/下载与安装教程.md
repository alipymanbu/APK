## 一、这是什么应用

PCNapp（应用市场里也常写作 PCN、`p.cn`）是一款安卓端的网址导航 + 购物返利类工具，包名 `com.scce.pcn`，第三方应用市场页面标注的厂商为深圳数贸恒科技有限公司。你在应用里能做的是：用它的导航页打开常用网站、在 P客商城里购物、按应用内的规则完成签到与任务拿 P币。

本篇只讲「拿到安装包并装上」这件事；装好之后怎么注册、怎么用积分功能，见 [注册登录教程.md](注册登录教程.md) 与 [P币签到与任务奖励怎么用.md](P币签到与任务奖励怎么用.md)。

应用不在 Google Play 上分发，你的获取途径基本是网盘转存或第三方应用市场页面。网盘里保存的是**当时存档的那一版**，与官方最新版可能不是同一版本，装之前先看清楚版本号：

| 包名 | com.scce.pcn |
| 安装包大小 | 45.08M |
| MD5 | `975ED4033CA183889B45AD5A33877A60` |
| 网盘存档日期 | 2026-09-23 |

**PCNapp 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/35c9feb7ae0f](https://pan.quark.cn/s/35c9feb7ae0f)

在网盘页面里把应用文件夹转存到自己的账号，再从手机上打开转存的文件夹、点 APK 下载即可；用电脑下载后传到手机也一样。

拿到文件后可以顺手校验一下完整性：把 APK 拷进手机后用文件管理器查看、或在电脑上执行 `certutil -hashfile PCNapp_v3.4.2.apk MD5`，结果与上表的 MD5 一致说明文件没下残。

## 三、系统要求

- 安卓 5.2 及以上（安装时系统低于此版本会直接提示不兼容）；
- 需要联网：导航页、签到、商城、聊天这些功能全部依赖网络；
- 安装包约 45M，装完后应用本身还会占用额外空间，建议预留 200M 以上。

## 四、安装步骤

1. 从网盘或文件管理器点开 `.apk` 文件；
2. 若系统弹出「禁止安装来自此来源的应用」，点提示里的**设置**，打开「允许来自此来源的应用」开关（不同品牌手机措辞略有差异，有的叫「安装未知应用」）；
3. 返回安装界面，点**安装**，等进度走完；
4. 装完先别急着打开 —— 手机的 Play Protect 或自带管家可能弹扫描提示，选择「仍然安装」即可（网盘里是普通分发包，不在商店渠道内）。

具体每一步的界面截图位置与各品牌差异，见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 五、应用会申请哪些权限

据第三方应用市场页面标注，PCNapp 申请的权限包括：

| 权限 | 用途 |
| --- | --- |
| 存储（读写外部存储、SD 卡） | 下载文件、保存缓存 |
| 请求安装文件包 | 应用内引导安装其他 APK 时使用 |
| 网络（完全网络访问、查看网络连接） | 页面加载与数据请求 |
| WLAN 状态 | 判断当前网络是否可用 |
| 位置信息 | 部分导航/商城功能使用 |
| 修改系统设置 | 应用内某些偏好设置 |

其中「请求安装文件包」与「修改系统设置」值得留意：如果你只是拿它当导航用，可以在系统设置里按需关掉不需要的权限。路径一般是 **设置 → 应用 → PCNapp → 权限**。

装好之后，注册账号那一步见 [注册登录教程.md](注册登录教程.md)。
