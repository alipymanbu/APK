## 一、为什么有的应用卸不掉

PCNapp 是你自己从网盘装的普通应用，正常情况下长按图标就能卸载。卸不掉时，通常是这几种原因之一拦在前面：

| 现象 | 常见原因 |
| --- | --- |
| 长按图标没有「卸载」 | 应用正被使用、或被授予了设备管理器权限 |
| 卸载按钮是灰的 | 应用有后台服务在跑、或开了无障碍服务 |
| 卸载后过几天又出现 | 有配套服务把它拉回来（先查无障碍与设备管理器） |
| 桌面上找不到图标 | 图标被隐藏，实际仍在「设置 → 应用」里 |

按下面的顺序逐级处理，一般走到第三步就能卸掉。

## 二、按顺序处理

**第 1 步：撤销设备管理器权限**
打开 **设置 → 安全（或「安全与隐私」）→ 设备管理器**（有的手机叫「设备管理员」），找到 PCNapp，取消勾选/停用，确认解除。设备管理器权限在没被撤销前，系统会阻止卸载。

**第 2 步：关闭无障碍服务**
打开 **设置 → 无障碍（或「辅助功能」）→ 已下载的服务**，如果列表里有 PCNapp，点进去关闭。无障碍服务会让应用保持活跃，干扰卸载。

**第 3 步：强停后再卸载**
**设置 → 应用 → PCNapp → 强行停止**，回到应用信息页点**卸载**。若卸载按钮仍灰着，先「清空缓存」再试。

**第 4 步：安全模式卸载（终极办法）**
前三步都无效时用这招，实测能卸掉大多数「顽固」应用：

1. 长按电源键，在弹出的关机界面上**长按「关机」或「重启」图标**（不同品牌操作略有差异）；
2. 等屏幕提示「进入安全模式」，确认，手机重启后左下角会显示「安全模式」；
3. 进 **设置 → 应用管理**，找到 PCNapp，点**卸载**；
4. 正常重启手机，确认图标已消失。

## 三、卸载前别忘了两件事

- 该提的积分/余额先处理掉 —— 卸载后账号数据只能靠手机号重新登录找回，相关路径见 [积分提现被拒怎么投诉.md](积分提现被拒怎么投诉.md)；
- 只是想腾空间的话，可以先到 **设置 → 应用 → PCNapp → 存储** 清缓存，不必直接卸载（清缓存不会退出登录）。

卸载过程中碰到的其他报错，见 [常见问题与解决方法.md](常见问题与解决方法.md)。
