# MActivePro 消息提醒与权限设置

## 一、先懂原理，再动手排查

手表的「消息提醒」不是手表自己去收消息，而是**把手机弹出的通知镜像到手表上**。所以排查永远从手机侧开始：

- 手机上本来就不弹的通知（你关了某个 App 的通知、开了勿扰模式），手表上一样不会有。
- 手机上正常弹的通知，手表不推，才是 MActivePro 这条链路的问题。

按这个顺序查：**App 内的消息提醒开关 → 手机的通知权限 → 手机的后台保活**。三关都过了，提醒基本就通了。

## 二、App 内：把要提醒的应用勾上

打开 MActivePro，进入设备页，找到「消息提醒」（部分固件叫通知/Message Reminder），把微信、QQ、短信、来电等你想在手表上看到的逐个打开。这里没勾的应用，手机弹再多手表也不会推。

想在看表时直接读出消息内容，还有一个容易漏的开关：把手机上微信、QQ 的通知设置成**显示消息详情**，手表上才会带出内容，否则只提示「你收到一条消息」。

另外注意勿扰逻辑：手表端一般也有勿扰/静音时段设置，检查别把全天设成了勿扰。

## 三、手机通知权限：安卓 13 以后要显式打开

- **安卓 13 及以上**：应用的通知权限是安装后默认关闭的，需要你手动开。路径：系统设置 → 通知/应用通知 → 找到 MActivePro → 打开「允许通知」，并把横幅、锁屏通知等显示方式一并开启。
- **iOS 版**：系统设置 → 通知 → MActivePro → 允许通知。iOS 上还需要在系统蓝牙里确认连接正常。
- **别开静默通知**：部分系统会把通知降级成「静默」，看起来权限开了实际不响不弹。

## 四、后台保活：国内安卓的重头戏

MActivePro 必须常驻后台才能把通知转发给手表，被系统杀掉就全断。各品牌手机的关键设置：

| 品牌 | 关键设置路径 |
| --- | --- |
| 华为 / 荣耀 | 设置 → 搜索「应用启动管理」→ 关掉 MActivePro 的自动管理 → 打开允许自启动、允许关联启动、允许后台活动 |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → MActivePro → 省电策略改为「无限制」，并锁定任务卡片 |
| OPPO / 一加 / realme | 设置 → 电池 → 找到 MActivePro → 允许后台运行/关闭智能后台管控 |
| 三星 | 设置 → 电池 → 后台使用限制 → 把 MActivePro 从「睡眠应用/深度睡眠应用」列表移出 |
| 通用做法 | 最近任务界面下拉锁定应用卡片；设置 → 电池 → 电池优化 → MActivePro 设为「不允许优化」 |

设置完可以做个验证：锁屏放几分钟，用另一个手机给你发条消息，看手表推不推。系统大版本升级后这些开关有时会被重置，提醒突然失灵先回来检查这里。

## 五、来电显示：号码而不是姓名

来电在手表上只显示号码不显示姓名，是联系人权限没给够，或者通讯录同步没做：

1. 系统设置里把 MActivePro 的**联系人/电话权限**设为允许。
2. 回到 App 的设备页，把常用联系人同步到手表电话本（上限 100 人，操作见 [连接手表与配对教程.md](连接手表与配对教程.md)）。
3. 重新来一通电话验证。有用户反馈同样是这个症状，补上通讯录权限后恢复正常。

## 六、还是不推？

按这个顺序兜底：

1. 重启手机和手表，重新进 App 等蓝牙回连。
2. 检查手表固件有没有更新（入口说明见 [功能与使用技巧.md](功能与使用技巧.md)）。
3. 卸载重装 App，重装时权限逐个同意，完整流程见 [手表连接不上怎么办.md](手表连接不上怎么办.md) 第五节。
