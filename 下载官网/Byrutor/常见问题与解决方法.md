## 一、打开后白屏或一直加载

按顺序排查：

1. **换网络试一次**：Wi-Fi 和移动数据各开一次，先排除当前网络的问题。
2. **等 30 秒**：海外站点在部分网络下首屏较慢，短暂等待有时就能加载出来。
3. **知道它的可达性背景**：该站为俄语区站点，有俄语区用户在公开问答里反馈它在俄罗斯被法院封锁（截至 2026 年，以你访问时的实际情况为准）——这意味着不同网络、不同时段的可达性差异很大，某个网络下打不开不等于坏了。换网络能开，就是网络可达性问题，与 APK 本身无关。
4. **对镜像域名保持警惕**：站内域名历史上有更换与镜像流传，但公开渠道给出的镜像地址真假混杂（有的用户反馈镜像带恶意程序）。要用镜像前，只认你能验证的来源；来历不明的域名不要在里面输账号密码。
5. **确认装的是对的包**：版本 `1.0.0`、包名 `com.byrutor`，与 [下载与安装教程.md](下载与安装教程.md) 的表格核对。

## 二、首次启动的人机验证过不去

首次打开会弹人机验证，过不去基本是这两个原因：

- **验证框加载不出来**：页面资源被网络拦了，换个网络再开一次；
- **点了没反应**：验证组件依赖网络请求，请求超时就会「点了不动」——退掉应用重开，让验证重新加载。

多试两次仍不过，先回到第一步把网络问题排除，再回来验证。

## 三、界面全是俄语/英语，看不懂

按 [中文设置与界面操作教程.md](中文设置与界面操作教程.md) 第一节两条路走：先在应用内找语言选项；找不到就用浏览器的网页翻译兜底。机器翻译对按钮和菜单大体准确，个别词条翻得生硬时对照图标理解。

## 四、搜不到我想找的游戏

1. 用**原文名**（英文名）而不是中文译名搜；
2. 只输前几个字母，看联想列表里有没有；
3. 换系列简称或去掉副标题再试；
4. 还没有就去对应分类里按筛选条件翻。

都试过确实没有，说明站内没收录这个条目，换个关键词或等后续收录。

## 五、磁力链接 / 种子下载不动

磁力和种子不是浏览器能直接下的，正常获取流程先看 [磁力与种子下载教程.md](磁力与种子下载教程.md)；卡住了按下面找原因：

- **没装客户端**：磁力链接要放进 torrent 客户端（如 μTorrent、qBittorrent）里才能开始，浏览器直接点是没反应的；
- **做种人数为 0**：详情页的做种人数长期为 0，说明没有节点在供源，等多久都下不动——换一个资源条目（同游戏常有多个来源）比干等有用；
- **下到一半停了**：客户端里暂停再继续、或等做种人数回升；长期停滞同样是资源侧问题，不是你的网络坏了；
- **文件校验不过**：详情页若提供了校验值（SHA-256 等），下载完成后核对一次；不一致就删掉重下，别用不完整的文件。

## 六、APK 装不上或装完闪退

| 症状 | 原因与处理 |
| --- | --- |
| 「解析包时出现问题」 | APK 没下完整，重新下载；下载完先核对 MD5 是否为 `A260DD24BDDCEAD2133DA85BF5F2B9D4` |
| 「禁止安装来自此来源的应用」 | 去 `设置 → 安全/安装未知应用` 给当前来源授权，再点安装 |
| 装完一点就闪退 | 系统版本低于安卓 5.2；或安装包与系统不兼容，先确认设备系统版本 |
| 提示已安装但版本不对 | 设备上有旧版残留，先卸载再装新的 |

## 七、核对安装包有没有被改过

对下载到手的 APK 算一次 MD5，与这份值逐字比对：

```text
A260DD24BDDCEAD2133DA85BF5F2B9D4
```

一致就是 [下载与安装教程.md](下载与安装教程.md) 里那一版（1.0.0 / 3.01M / `com.byrutor`）；不一致说明文件在传输中损坏或不是这份包，回到网盘重新下载。
