## 一、先把界面调成中文

Byrutor 出自俄语站点，默认界面多半是俄语或英语，看不懂就先做这一步，两条路任选：

1. **应用内改**：如果你的版本里有账户/个人中心，进 `设置`（或 `Language` / `Язык`）找语言选项，选 `中文` 或 `Chinese`，保存后回到主界面看是否生效。找不到这个选项就走第二条路——不同版本界面有差异，以你实际看到的为准。
2. **翻译兜底**：页面类内容可以靠机器翻译看懂——打开时若弹出「翻译成中文」提示就点它；没有提示，就把浏览器的「网页自动翻译」打开再访问。俄语页面走机器翻译，按钮和菜单大体能看懂，个别词条会翻得生硬，对照图标理解即可。

## 二、首页：从推荐与排行入手

进主界面后，你看到的通常是推荐位与热门条目。找内容的效率从高到低是：**搜索 > 分类 > 首页推荐**。首页适合「没什么明确目标、随便看看」的场景；有目标就直接用搜索。

## 三、搜索：知道名字就用它

1. 点顶部的放大镜图标。
2. 输入游戏名。外语游戏用**原文名**搜命中率最高；记不全就输前几个字母，多数站内搜索带联想。
3. 搜索结果里点条目进详情页，简介、截图、配置要求都在那里。

搜不到时先确认是不是记错了名字（系列简称、副标题经常和主名对不上），见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、分类与筛选：不知道搜什么时用它

分类页按游戏类型（动作、角色扮演、策略、射击等）把条目拆开，逐级点进去即可。条目多的分类可以叠加筛选条件（题材、平台、时间、热度）缩小范围，避免一页页翻。这套「分类 + 筛选」的组合适合补全你的备选清单。

## 五、详情页看什么

点进一个条目后，重点核对这几样再决定要不要下载：

- **配置要求**：CPU、显卡、内存的最低与推荐档，和你的机器对一遍；
- **语言支持**：有没有中文（或英文语音可接受）；
- **截图与简介**：确认是你要的那款游戏，同名作品并不少见；
- **资源信息**：做种人数、资源大小、更新时间——做种人数长期为 0 的资源可能下不动。

## 六、下载怎么发起

详情页里的下载入口一般是**磁力链接（magnet）或种子文件（.torrent）**两种形态，部分条目也提供 HTTP 直链：

- 磁力链接：长按复制，粘贴进你手机上的 torrent 客户端（如 μTorrent、qBittorrent）即可开始；
- 种子文件：下载 `.torrent` 后用 torrent 客户端打开；
- HTTP 直链：直接用浏览器或下载工具拉取。

客户端怎么装、RePack 压缩包怎么解、下载完怎么查一遍，完整步骤见 [磁力与种子下载教程.md](磁力与种子下载教程.md)；下到一半断了、做种人数为 0 这类卡住的问题，见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 七、下载管理与「我的」

下载过的任务、最近浏览过的条目一般在「下载」或「我的」类入口里集中列出，可在这里看进度、暂停/继续、打开已下载文件。你最近玩过什么、时长多少，也会记录在「我的」页面，点记录可继续上次的进度（该功能以你实际版本为准）。
