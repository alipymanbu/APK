## 一、这是什么，装之前先对上号

Byrutor 是俄罗斯游戏资源网站（入口 [byrut.org](https://byrut.org)）对应的安卓客户端，你在手机上浏览游戏条目、搜索、看资讯都靠它。它本体只有 3 MB 出头，装起来很快，但**版本与包名要先核对**——网上叫 Byrutor 的页面很多，包对不上就不是同一个东西。

安装包的权威信息如下（以这份为准，别拿别处页面写的版本号来比）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.0 |
| 包名 | `com.byrutor` |
| 大小 | 3.01M |
| MD5 | `A260DD24BDDCEAD2133DA85BF5F2B9D4` |
| 系统要求 | 安卓 5.2 及以上 |

你手上那个 APK 如果 MD5 和上表不一致，就不是这份安装包，别急着装（校验方法见 [常见问题与解决方法.md](常见问题与解决方法.md)）。

## 二、从哪拿安装包

从上面的 **Byrutor 安装文件资源（夸克网盘）**（[https://pan.quark.cn/s/e1490628a41b](https://pan.quark.cn/s/e1490628a41b)）转存获取：打开分享链接 → 保存到自己的网盘 → 在网盘里找到 `Byrutor_v1.0.0.apk` 下载到手机。网盘里存的就是上表那一版，版本、包名、MD5 三样都对得上。

## 三、安装步骤

1. 把 APK 从网盘下载到手机的下载目录。
2. 点击 APK 开始安装。系统若弹出「禁止安装来自此来源的应用」，是没给浏览器或文件管理器装 APK 的权限——去 `设置 → 安全/安装未知应用` 里给当前来源开一下，再回来点安装（不同品牌手机菜单名略有差异）。
3. 装完打开。首次启动会做一次**人机验证**（勾选或点选的验证框），通过才进主界面。这一步过不去多半是网络问题，处理办法见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、装完先确认三件事

- **应用能打开**：主界面能加载出游戏条目，说明网络与客户端都正常。
- **版本是 1.0.0**：在系统的应用信息页能看到版本号，与本文表格一致即可。
- **界面能看懂**：默认很可能是俄语或英语，先按 [中文设置与界面操作教程.md](中文设置与界面操作教程.md) 把语言问题解决，再开始找内容。
