## 一、故障速查表

先对号入座，再到下面对应小节看详细处理：

| 现象 | 最可能的原因 | 处理 |
| --- | --- | --- |
| 首页空白、点不动 | 没配置影视源 | 按配置方法填一次源 |
| 昨天还能看，今天全空 | 配置地址失效 | 换一个新的源地址 |
| 搜片有结果但播放失败 | 当前线路断了 | 播放页里换线路 |
| 播放卡顿、频繁缓冲 | 线路慢或网络差 | 换线路；测网络 |
| 直播黑屏 | 该频道流断了 | 换台；或换带直播数据的源 |
| 历史记录看不到 | 未配置源或还没看过 | 先配置，看一部再回来 |
| 安装时提示解析失败 | 安装包下载不完整 | 用 MD5 核对后重新下载 |
| 打开就闪退 | 系统过旧或存储不足 | 对照本文第三节处理 |

## 二、内容相关的问题

### 2.1 首页空白、点不动

这是没有加载到影视源的正常表现，不是软件坏了。进配置入口，把影视源地址填上并确定，等首页刷出内容即可，具体步骤见 [影视源配置方法.md](影视源配置方法.md)。

### 2.2 源失效：昨天能用今天全空

这类应用的内容完全挂在配置地址背后的服务上，源站关了、换了地址，你这边就全空。处理方式就是重新配一次：删旧地址、填新地址、确定、等刷新。强烈建议手里常备两个以上可用源，一个挂了立刻切换。

### 2.3 播放失败或卡顿

按顺序试：

1. 在播放页里**换线路**——同一部片通常有多条线路，这是成本最低的自救；
2. 换一部其他影片验证：别的能播，就是这条线路的问题；别的也不能播，往下走；
3. 检查网络：电视优先用有线，Wi-Fi 信号弱会直接表现为频繁缓冲；
4. 都不行就换一份源配置。

### 2.4 直播问题

直播频道列表跟着源走：列表里频道很少或全是黑屏，说明当前源里的直播数据不行，换源比逐个频道调试有效。个别频道黑屏时先换台再回来看，可能是临时断流。

## 三、安装与启动的问题

### 3.1 提示解析失败 / 安装中断

基本是安装包没下载完整。核对你手上那份 APK 的 MD5 是否为 `FAE06AC353E6C2881123D09D7006AEE7`（版本 3.0.35、29.39M），不一致就重新下载；U 盘安装时也要确认拷贝完整后再拔盘。

### 3.2 打开就闪退

按可能性排查：

- **系统版本过旧**：本包是兼容老设备的构建（包名带 kitkat 字样），但极老的设备仍可能跑不起来，换设备验证；
- **存储空间不足**：清掉电视/盒子里不用的应用再试；
- **安装包损坏**：按上一节核对后重装。

### 3.3 电视上找不到「允许未知来源」开关

各品牌叫法和位置不同，常见的藏身处：「设置 → 安全」「设置 → 通用 → 安全」「设置 → 账户与安全」「应用管理里的高级选项」。实在找不到，在设置的搜索框里直接搜「未知来源」。

## 四、还有一条万能路径

排查不出来的时候，退出应用清后台重开一次，能解决相当一部分界面假死、内容不刷新的问题；仍不行就按「重配源 → 重装」的顺序走一遍，两步的操作细节分别在 [影视源配置方法.md](影视源配置方法.md) 和 [下载与安装教程.md](下载与安装教程.md)。
