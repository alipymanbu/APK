## 一、先打通手机的打印服务

手机能不能打印，第一步不在 OfficeSuite 里：安卓的打印走系统打印框架，应用发起打印后，由系统里启用的「打印服务」去发现打印机。第一次打印前先做两件事：

1. 打开手机「设置 → 已连接的设备 → 连接偏好设置 → 打印」（不同机型路径略有差异），确认「默认打印服务」已开启；
2. 确认手机和打印机连的是**同一个 Wi-Fi**。打印机用 USB 线插在电脑上的，手机搜不到它，除非电脑把打印机共享到了局域网。

老款打印机如果默认打印服务搜不到，去应用商店装对应品牌的打印插件或应用（HP Smart、Canon PRINT、Epson iPrint、Brother iPrint&Scan 这类），装完再回打印设置里刷新。

## 二、在 OfficeSuite 里从哪点打印

官方帮助文档给出的安卓端路径（界面措辞可能随版本略有差异）：

1. 打开要打印的文档；
2. 点功能区顶部的「主页/Home」按钮，在下拉菜单里选「文件/File」；
3. 在顶部功能区**向左滑动**工具图标，直到看到「打印/Print」图标；
4. 点「打印」，进入系统打印界面：选打印机、份数、纸张、彩色/黑白、页码范围；
5. 确认后开始打印。

打印机列表为空，回到第一节检查打印服务和网络。

## 三、搜不到打印机怎么排查

按顺序过一遍：

1. **网络**：手机和打印机是否在同一 Wi-Fi；访客网络常把设备互相隔离，换主网络试；
2. **刷新**：打印设置的打印机列表里手动刷新，等几秒再选；
3. **重启**：路由器、打印机、手机各重启一次，能解决一大半「突然搜不到」；
4. **任务卡住**：设置 → 打印 → 打印任务里取消卡住的任务再重试；
5. **打印机本身**：确认打印机已连上网（多数型号机身屏幕上有网络状态），必要时在打印机上重新连一次 Wi-Fi。

## 四、没有打印机：先存成 PDF

打印对话框里不选真打印机也有用：目标选「另存为 PDF」，就把排版固定的 PDF 存到手机里，回头传给有打印机的人或打印店。给打印店发文件时，发 PDF 比发 docx 稳——它不会因为对方电脑缺字体而变版式。

PDF 里怎么加批注和签名见 [PDF批注与电子签名.md](PDF批注与电子签名.md)；文档编辑本身见 [新建与编辑文档教程.md](新建与编辑文档教程.md)。打印相关的其他异常（应用闪退、文件打不开）在 [打不开与常见问题排查.md](打不开与常见问题排查.md)。
