## 一、装之前先弄清三件事

OfficeSuite 是 MobiSystems（2001 年成立的办公软件厂商，总部在欧洲保加利亚，官方称全球用户超 5.5 亿）出品的安卓移动办公套件，把文字文档、表格、演示文稿和 PDF 四个编辑模块装进同一个应用。有一点要先知道：2024 年 11 月起官方把 OfficeSuite 更名为 MobiOffice，应用商店里现在搜到的是 MobiOffice 这个名字，但包名 `com.mobisystems.office` 没变——你拿到的这份 15.0.54 属于 15 系列，正是更名刚落地时的版本系列。

本文以网盘里这一版为例，它的基本信息如下（版本/包名/大小以此为准，官方最新版编号可能更高，属于正常现象）：

| 项目 | 信息 |
| --- | --- |
| 应用名 | OfficeSuite（现已更名 MobiOffice） |
| 版本 | 15.0.54 |
| 包名 | com.mobisystems.office |
| 安装包大小 | 263.02M |
| MD5 | FD67B6A87D3989C2FE2D8B34E329D046 |
| 系统要求 | 旧版对安卓版本的要求低于官网当前最新版，以安装时系统提示为准 |

两点提醒：一是这份安装包超过 260M，装之前确认手机剩余空间够用（建议留出 2GB 以上）；二是安装包装完就可以删掉，不影响已装好的应用。

## 二、把安装包拿到手机上

1. 把本篇开头的 **OfficeSuite 安装文件资源（夸克网盘）** 链接复制到手机浏览器打开（或先用电脑打开、转存到自己网盘后再用手机取）。
2. 在网盘里选中 `OfficeSuite_v15.0.54.apk` 下载到手机存储。
3. 下载完成后，文件通常在手机「文件管理」的 Download（下载）目录里。

不习惯在手机上操作的话，也可以在电脑端下载，再用数据线把 APK 传到手机，效果一样。

## 三、安装步骤

安卓默认不允许安装应用商店之外的程序，第一次装会要求你先放开「未知来源」权限。不同品牌的设置入口大致如下：

| 手机品牌 | 设置路径（大致） |
| --- | --- |
| 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全与隐私 → 更多设置 → 安装未知应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 允许安装未知应用 |
| 三星 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |
| 原生安卓 / 其他 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

然后按这个顺序操作：

1. 在「文件管理」里点开刚下载的 `OfficeSuite_v15.0.54.apk`。
2. 系统询问「是否允许此应用安装」时，选「设置」→ 打开「允许来自此来源的应用」→ 返回。
3. 点「安装」，等进度条走完。
4. 提示「应用已安装」后点「打开」。

注意，第 2 步授权的是「文件管理器」这个来源，不是给 OfficeSuite 本身授权；装完不放心可以在同一个设置页里把权限关回去，不影响已装好的应用。

## 四、首次启动要做的事

第一次打开 OfficeSuite，通常会经过这几步：

1. **选界面语言**：应用支持包括中文在内的多种语言，一般会跟随系统语言，也可以在设置里手动改。
2. **权限申请**：会依次请求存储（读写文档）等权限。想先随便看看的话可以逐项处理，用到对应功能再补授权。
3. **登录账号（可跳过）**：侧边菜单里有登录入口，支持 Google 等账号。登录的作用是同步应用设置与最近文件列表，不登录也能正常编辑本地文档，先跳过完全没问题。

主界面认识一下：左上角是导航菜单（新建文档、连接云盘、升级入口都在里面），底部有快捷按钮，右下角的「创建」按钮点开是一个扇形菜单——新建 Word/Excel/PPT、扫描成 PDF 都从这里进。

## 五、装不上怎么办

按出现频率排：安装包没下完整（对一下上面表格里的 MD5）、存储空间不足、旧版本残留未卸载干净、系统版本低于安装包要求。[打不开与常见问题排查.md](打不开与常见问题排查.md) 里有逐项的处理办法。

## 六、装完之后，版本怎么更新

用安装包装的应用不挂应用商店，不会自动弹更新，版本就停在你装的这个。两条路：

1. **换装官方新版**：官方现在主推更名后的 MobiOffice，当前最新为 16 系列（以官方页面为准）；旧版 OfficeSuite 已不再收到更新，官网（[www.mobisystems.com](https://www.mobisystems.com/)）仍保留旧版下载页但同样标注了不再支持。同一包名直接覆盖安装，本地数据一般会保留。
2. **维持现状**：15.0.54 对老机型更省心，日常看文档、改文档都够用，只是别指望再收到更新。

换版前后的数据不用专门迁移：文档本身存在手机本地或你的网盘里，卸载应用不会动它们；重装或换新版后登录同一账号，应用设置与最近列表会跟回来。动手前把正在编辑的文档保存、关闭即可。

要判断免费版和付费版差在哪，看 [免费版与付费版区别.md](免费版与付费版区别.md)；装完想上手编辑，直接看 [新建与编辑文档教程.md](新建与编辑文档教程.md)。
