# 远程组队上团教程

> 讲用 Poke Genie 的远程组队（Remote Raid Coordinator）匹配房主、交换好友码、进团打五星与超级团体战的全流程。

## 一、它解决什么问题

住在玩家少的地区，五星、超级这类团体战凑不齐人；或者出门少，错过了道馆边的团。远程组队把全球玩家的团放在一个队列里：你在应用里选好要打的 Boss，它给你匹配正在开团的房主，你在游戏里远程进团。身边一个人都没有也能打大型团。

## 二、进团前的三个前提

| 前提 | 说明 |
| --- | --- |
| 远程团体战券 | 参加远程团要消耗游戏内购买的远程团体战券，价格与获取方式以游戏内商店为准 |
| 每日远程上限 | 游戏对每天参加远程团的场数有限制（当前为 5 场，官方活动偶尔放宽，以游戏内提示为准） |
| 好友位有空余 | 上团要和房主互加好友，游戏好友上限 200 人，满了要先清理 |
| 团内人数未满 | 一个团体战队伍最多 20 人入队，热门房主的团去晚了挤不进 |

## 三、上团全流程

1. 打开 Poke Genie 的 Raid（组队）页，选要打的 Boss；
2. 选一个房间加入，进入排队；
3. 匹配成功后，应用把房主的好友码复制到剪贴板；
4. 切到 Pokémon GO，用好友码搜索并添加房主；
5. 等房主发来团体战邀请；
6. 收到邀请后消耗远程团体战券入队，开打。

从排队到进团通常几分钟；热门 Boss 排队的人多，等待时间会长一些，赶上活动期要有心理准备。

## 四、当房主开团

你自己人在道馆边时，也可以做房主：在组队页选「开团（Host）」，选对应 Boss 建房，等别人来加你好友，再把他们逐个邀请进团。注意开团必须人在道馆现场，远程只能进别人的团；房主不用消耗远程券，被邀请的远程玩家才消耗。人凑齐了正常开打即可。

## 五、提高成功率的几个细节

- **先加好友再排队**：有些玩家开团前会先在群里约人，好友申请通过得越快，进团越顺；
- **掐点进团**：匹配成功后别干别的，房主一般等人齐就开，超时会被移出；
- **打之前把队伍排好**：入团前在游戏里调整克制 Boss 的队伍，输出效率看 [PvP联赛个体值分析.md](PvP联赛个体值分析.md)；
- **打完互删随意**：不少玩家打完就互删好友腾位置，属正常现象，不用纠结。

上团打的 Boss 掉的宝可梦，抓到后照旧用 [扫描个体值操作步骤.md](扫描个体值操作步骤.md) 的方法查个体值。
