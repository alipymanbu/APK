## 一、这件事的分工

远程控制是 FDM 全家桶里的一个功能：两端都装 FDM，电脑端跑任务，手机端当遥控器。你在手机上能做的是**查看活动与已完成的下载列表、新建下载任务**；真正的下载发生在电脑上——手机上看到想要的直链，直接派给电脑，回家文件已经在下载或下完了。

这个功能在 FDM 的桌面端描述里一直存在（官方口径叫 Remote Control，通过 Web 界面查看与发起任务），手机端 App 同样承担遥控器角色——多个评测口径对「手机控制电脑」的描述一致，但**具体入口名称随版本变化**，以你两台设备上的实际菜单为准。

## 二、动手前的三件事

1. **电脑端装桌面版**：去官网 [www.freedownloadmanager.org](https://www.freedownloadmanager.org/) 取对应系统的版本，安装后在设置里把远程控制 / Web 界面相关的选项打开（不同版本叫法有差异，认准「远程」「remote」「Web 界面」这类字样）。
2. **手机端装安卓版**：手机上还没装的话，用 [Free Download Manager 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5d484e77cecd)，安装步骤见 [下载与安装教程.md](下载与安装教程.md)。
3. **两端能互通**：最稳的姿势是手机和电脑在同一个局域网里；不在同一网络时的可达性取决于你电脑端的网络与设置，连不上先回同一 Wi-Fi 验证。

## 三、典型场景

- **派任务**：手机上逛到一个大文件直链，复制 → 在 FDM 里新建任务 → 指到电脑端，让电脑挂着下载，不占手机电量和流量。
- **查进度**：电脑上挂了几个大任务，出门在外想知道下到多少、哪些完成了，手机上翻列表。
- **接着管**：任务完成与否、还差什么文件，在手机上确认，不用为了看进度专门开电脑。

## 四、连不上时怎么想

- 先确认**电脑端 FDM 正在运行**——电脑端关了，遥控器再对也收不到信号。
- 确认电脑端设置里的远程访问 / Web 界面开关是开的，地址和端口按它显示的填。
- 同一局域网内能连、外网连不上，是正常的网络可达性问题，不是软件坏了；要不要为此改路由器，你自己权衡。
- 手机端本身的下载问题（不是远控问题）去 [下载失败与速度慢排查.md](下载失败与速度慢排查.md)。

手机端把链接抓下来的两条路（内置浏览器、复制粘贴），在 [视频音频下载与文件整理.md](视频音频下载与文件整理.md) 第一节；速度与续传相关设置见 [断点续传与多线程加速设置.md](断点续传与多线程加速设置.md)。
