## 一、添加任务的两种方式

**磁力链接**：在网页或聊天工具里复制 `magnet:?xt=...` 开头的完整链接，打开 FDM 点「+」，链接会自动带出（或手动粘贴），确认即可。FDM 内置完整的 BT 客户端，不用再装别的工具。

**.torrent 文件**：把种子文件下到手机后，点 FDM 的「+」选择本地 .torrent 文件，确认。

添加 BT / 磁力任务时，FDM 会先列出种子内的全部文件，**勾选你真正要的那几个再开始**——BT 任务默认把整包全下，全选既慢又费流量。

## 二、挑文件与设优先级

进入任务详情可以调整种子内单个文件的优先级：急着要的设高，不需要的直接不选。多个任务并行时，任务级别同样可以排序——长按任务（或进任务菜单）可暂停、删除、调整顺序。

## 三、BT 相关设置

设置里的 BT（种子）分组，常用的是这几个：

| 设置 | 作用 |
| --- | --- |
| 上传速度限制 | 不想做满上传就限一个值，避免占满上行带宽 |
| 下载速度限制 | 给 BT 任务封顶，把带宽让给其他任务 |
| DHT | 没有 Tracker 的情况下也能找到 peers，保持开启 |

## 四、磁力没速度，按这个顺序查

1. **先看资源本身冷不冷**：做种人数为 0 的任务谁都下不动，这不是 FDM 的问题。
2. **手动补 Tracker**：任务属性里可以添加 Tracker 服务器地址，冷门种子补几个活跃 Tracker 常常就能连上。
3. **确认 DHT 开着**。
4. **网络环境**：公司网、校园网或部分运营商会对 BT 流量做限制，换个网络对比一下就能定位。

前两条查完还是不动，去 [下载失败与速度慢排查.md](下载失败与速度慢排查.md) 对照完整的现象表。

BT 任务下什么内容由你自己把关，获取受版权保护的内容前，先确认你有权获取它。
