## 一、先对症状

| 现象 | 最可能的原因 | 先做这一步 |
| --- | --- | --- |
| 任务一直排队 / 等待 | 默认仅 Wi-Fi 下载，当前走的是移动数据 | 设置里开「Use mobile network」，或连上 Wi-Fi |
| 速度和浏览器下载差不多 | 服务器不限单连接速度，多线程无提升空间 | 换个源对比；确有需求再调连接数 |
| BT / 磁力 0 速度 | 无做种人 / DHT 关闭 / 网络限制 | 见 [磁力链接与BT种子下载方法.md](磁力链接与BT种子下载方法.md) 第四节 |
| 提示存储失败、无法写入 | 存储权限被拒 | 系统设置 → 应用 → FDM → 权限，允许存储 |
| 断点续传没接上 | 任务已被删除 | 续传只对列表里还存在的任务有效，只能重下 |
| 提示连接超时 / 服务器断开 | 网络波动，多半会自动续传 | 等它自己接上；反复失败就暂停再开始 |
| 直链失效 | 链接过期 | 换链接；旧链接有时能用续传功能恢复 |

## 二、逐条展开

### 1. 任务排队不动

九成是这个：FDM 默认只在 Wi-Fi 下下载（详见 [断点续传与多线程加速设置.md](断点续传与多线程加速设置.md) 第五节）。到设置里打开移动数据开关即可。另一种可能是你手动暂停过任务——点一下继续。

### 2. 速度上不去

FDM 的加速靠把文件拆成多个片段并行下载，效果取决于**对方服务器**是否限制单连接。服务器不限速时，FDM 不会更快，这是机制上限，不是故障。可以把设置里的最大连接数调高试试，但别期待质变。

### 3. 存储权限被拒后怎么恢复

首次启动拒绝过存储权限的，之后所有任务都会写盘失败。到系统「设置 → 应用 → Free Download Manager → 权限」里把存储（文件与媒体）设为允许，回到 FDM 重新开始任务即可，已下载的部分会接着用。

### 4. 任务中断与恢复

断网、杀后台造成的中断，网络恢复后从断点继续；直链过期这类失效链接，FDM 也会尝试续传恢复。判断标准就一条：任务还在列表里，就有机会接着下。

提示「连接超时」「服务器断开」这类报错，多数是网络波动，FDM 会自动续传，不用手动干预；反复出现就手动暂停一次再开始，让它从断点重新握手。一直卡死的任务不值得反复重试——先确认链接在浏览器里还能不能打开。

### 5. 还是不行

- 核对安装包完整性：拿 [下载与安装教程.md](下载与安装教程.md) 第一节的 MD5 比对文件，确认不是坏包。
- 向官方反馈：[www.freedownloadmanager.org](https://www.freedownloadmanager.org/)。

顺带一提：如果你主要在电脑上下载，桌面版 FDM 的浏览器接管体验更完整，安卓端定位是「手机上直接抓链接和 BT」——两边的功能取舍不同，别用桌面版的功能清单来对照安卓版。
