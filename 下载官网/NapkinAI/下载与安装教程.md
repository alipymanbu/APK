## 一、装之前先核对这份包

先确认你要装的就是本文说的这个安卓应用。本篇对应的安装包信息如下，这些以包本身的实际数据为准（网上商店页写的版本可能和你拿到的不是同一份）：

| 项目 | 值 |
| --- | --- |
| 应用名 | NapkinAI（商店页也写作 Napkin AI / napkinai） |
| 版本 | 1.0.1 |
| 安装包大小 | 28.17M |
| 包名 | `com.zhumengwangluo.airj` |
| MD5 | `ab44bfe2726cbdc5d8d51721a5426a82` |
| 语言 | 简体中文 |
| 开发者 | 长沙逐梦网络科技有限公司（公开商店页标注） |

两点说明：

- **系统要求**：公开商店页标注"支持安卓系统 5.2 以上"。安卓官方版本号里并没有 5.2 这个版本，可以理解为 5.x 以上；实际能不能装，以你手机安装时的系统提示为准。
- **MD5 怎么用**：把安装包下载到手机或电脑后，用校验工具算一下 MD5，和上表一致就说明文件完整、没有被改过；对不上通常是下载中断导致文件不完整，重新下载一次即可。

## 二、下载安装包

打开本篇头部或这里的 [NapkinAI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/be745806361f) → 转存到自己网盘（或直接下载）→ 把 APK 文件拿到手机存储里。夸克网盘的文件在手机上装了夸克 App 后可以直接下载，不需要电脑中转。

## 三、安装步骤

1. 在手机文件管理器里找到下载好的 APK 文件，点它。
2. 系统会提示"是否允许安装未知来源应用"（不同品牌的说法略有差异），选择允许该来源安装。这个提示只在安装非应用商店渠道的 APK 时出现，属于安卓的常规流程。
3. 等待安装完成，桌面出现 NapkinAI 图标。

安卓各品牌允许未知来源的入口位置不同，一般在 系统设置 → 安全/隐私，或安装时弹窗里直接授权，按你手机的提示操作即可。

## 四、首次启动与登录

首次打开 NapkinAI 的大致流程（综合多个商店页的使用教程）：

1. 启动后先同意软件政策/用户协议。
2. 点右上角的人像图标，进入登录页面。
3. 完成登录后即可开始使用创作功能。

关于登录方式，不同商店页的教程写了两种口径：一种写**手机号 + 验证码**登录，另一种写**手机号 + 密码**先注册、再返回登录页用密码登录。两种描述可能是不同时期的界面，你以应用里实际显示的入口为准；验证码登录需要手机能正常接收短信。

验证码收不到时，按顺序排查这几项（安卓通用做法，并非该应用特有问题）：

1. 核对手机号没填错、信号正常，必要时在 Wi-Fi 与移动数据之间切换；
2. 检查短信有没有被骚扰拦截类功能归进拦截记录；
3. 把系统时间改成"自动获取网络时间"——时间偏差大会导致验证码判定失败；
4. 隔几分钟再点"重新获取"，短时间内反复点可能触发限流。

## 五、装不上或打开不对劲的常见原因

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示解析包失败/安装中断 | 安装包下载不完整 | 重新下载，算一遍 MD5 再装 |
| 点安装没反应 | 未授权"未知来源" | 按弹窗提示去设置里允许该来源 |
| 提示系统版本过低 | 手机安卓版本低于应用要求 | 换系统版本更新的设备尝试 |
| 装完发现功能对不上 | 装到了同名的另一个包 | 不同渠道流出的"1.0.1"并非都是同一份文件，核对包名是否为 `com.zhumengwangluo.airj` |

同名应用混淆这一点值得专门留意：搜索"NapkinAI"时还有一个同名的网页工具（napkin.ai），两者是完全不同的产品，详见 [安卓版与网页版的区别.md](安卓版与网页版的区别.md)；同一家开发者（长沙逐梦网络科技）还有简介文案几乎一样的其他应用，判据见 [同厂商的相似应用怎么区分.md](同厂商的相似应用怎么区分.md)。装好之后就可以看 [文生图和图生图怎么用.md](文生图和图生图怎么用.md) 开始出图了，做表情包的部分见 [表情包制作与一键分享.md](表情包制作与一键分享.md)。
