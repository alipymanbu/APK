## 一、官方列出的支持引擎（截至 2026-09）

官网首页按类型给出这张清单，认准引擎再下游戏，能省掉大量试错：

| 类型 | 引擎 |
| --- | --- |
| 角色扮演 | RPG Maker、Wolf RPG（1.00 至最新版）、SMILE GAME BUILDER、RPG Developer Bakin |
| 视觉小说 / ADV | TyranoBuilder、Kirikiri 2/Z、Ren'Py、Visual Novel Maker、ChoiceScript |
| 策略 | SRPG Studio |
| 其他 | Pixel Game Maker MV |

怎么判断手里的游戏是什么引擎：看游戏根目录的文件——有 `Game.rgss3a` / `Game.rgss2a` / `Game.exe` 加 `Data` 文件夹的基本是 RPG Maker；有 `Data.xp3` 的是 Kirikiri；有 `renpy` 字样文件夹的是 Ren'Py；有 `GamePro.exe` 或 `*启动程序` 之类的多是 Wolf RPG。对不上号的引擎就别硬试了；放进 `/MTool/Games` 后游戏不识别，先在工具内更新一遍再试，还不行见[常见问题与解决方法](常见问题与解决方法.md)。

## 二、安卓端的插件结构

手机版不是一个大包全包的：主 APK 只提供运行环境，各个引擎靠单独的插件 APK 提供支持。官方安卓发布页（[trs.mtool.app/release.php](https://trs.mtool.app/release.php)）列出的组件如下，体积为截至 2026-09 的数字，以官方发布页当时显示为准：

| 组件 | 体积 | 谁需要装 |
| --- | --- | --- |
| MTool 主程序 | 235 MB | 必装 |
| RPG Maker XP/VX/VX Ace 支持插件 | 379 MB | 玩 RPG Maker XP / VX / VX Ace 游戏 |
| RPG Maker 2000/2003 支持插件 | 164 MB | 玩 RPG Maker 2000/2003 复古游戏 |
| Ren'Py 支持插件 | 335 MB | 玩 Ren'Py 视觉小说 |
| Windows 游戏支持组件（Winlator） | 1.1 GB（早期预览） | 想跑非上述引擎的 Windows 游戏 |

几个实际使用里的点：

1. **按需装**：插件清单里没有 RPG Maker MV/MZ 的对应项，玩这类游戏一般主程序就够；玩到 XP/VX/VX Ace、Ren'Py 再装对应插件，别一上来把 1.1 GB 的 Winlator 也下了；
2. **插件更新也在工具内**：官方说明 APK 只提供运行环境，主程序和插件的新功能都从工具内的「获取更新」进来；
3. **Winlator 组件是早期预览**，兼容性没有上面几类稳，跑不起来说明游戏确实不在这套方案的覆盖范围内，别反复折腾；
4. 本文网盘里那份 1.0 版约 275.79 MB，与官方当前主程序的 235 MB 口径不同——打包形式随版本变过，装完以工具内更新后的实际组件为准。

插件装好之后，回[导入游戏与翻译步骤](导入游戏与翻译步骤.md)把游戏放进 `/MTool/Games`、启动、翻译；翻译环节提示等级不足的，看[订阅等级与翻译引擎](订阅等级与翻译引擎.md)。
