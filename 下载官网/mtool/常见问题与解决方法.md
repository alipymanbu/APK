## 一、症状速查表

| 症状 | 大概率原因 | 处理 |
| --- | --- | --- |
| 第一次打开白屏、滚代码 | 初始化运行环境 | 等它自己进主界面，别杀进程 |
| 启动游戏后一直「正在加载资源」 | 正常加载，大游戏要十几分钟 | 不最小化，等；实在没动静点一下游戏窗口 |
| 游戏库是空的 | 游戏没放对目录 | 整个文件夹放进 `/MTool/Games`，见[导入游戏与翻译步骤](导入游戏与翻译步骤.md) |
| 游戏能跑但全是外文 | 没翻或翻译文件没加载 | 右上角设置 → 翻译 → 开始翻译 |
| 翻译引擎灰色/提示等级不足 | 该引擎要 lv.1 / lv.2 | 换必应免费翻，或看[订阅等级与翻译引擎](订阅等级与翻译引擎.md) |
| 翻译到一半失败 | 先更版本再重试 | 工具内点「获取更新」后重新翻 |
| 游戏文字识别不到 / 黑屏 | 悬浮窗权限没给 | 见第二节第 4 条 |
| 打开就闪退 | 存储不足或系统版本不够 | 清存储与缓存，重启后重装 |
| 改数值没效果 | 游戏带反作弊，拦截修改 | 有玩家反馈这类游戏改不了，用翻译功能就好 |
| 存档丢了 / 想退回修改前 | 有自动备份可用 | 见[存档备份与数据迁移](存档备份与数据迁移.md) |
| 界面是英文 | 没切语言 | 右上角选「简中」 |

## 二、白屏与加载慢，哪些要等、哪些要动手

**要等的两种**：

1. 首次启动的代码白屏——初始化只发生一次，通常几十秒内结束；
2. 启动游戏时的加载——官方教程明说「游戏与工具可能会停止响应（几秒到十几分钟）」，文本量大的游戏前面这段最熬人。期间**不要最小化游戏窗口**，尽量让它待在前台，长时间没反应可以点一下游戏窗口唤它一下。

**要动手的几种**：

1. 等了二十分钟以上还卡在加载、数据状态数字不动 → 杀掉重进，还不行就删缓存重加载（翻译页里有「删除缓存并重新加载」入口）；
2. 字体太大太小、文字超框 → 主页有字体大小调整选项，进游戏前先调好；
3. 反复加载同一游戏都失败 → 把游戏文件夹挪出 `/MTool/Games` 再放回去，排除复制到一半的残缺文件；
4. 翻译识别不到游戏文字、或进游戏后黑屏 → 去系统设置的应用管理里给 MTool 开「悬浮窗 / 显示在其他应用上层」权限（各机型叫法略有差异），关掉会遮挡画面的后台应用，重开工具和游戏再试；
5. 打开就闪退 → 清一下手机存储空间、清 MTool 缓存，重启手机后重新安装。

## 三、版本问题：为什么「我刚装的版本」反而是旧的

MTool 官方发布页持续挂出新构建（截至 2026-09 仍在更新），而且官方社区页特别提醒：**稳定版不是最新版，很久都不更新**。所以：

1. 刚从任何渠道装好 APK（包括本文网盘这份 1.0 版），第一步都是进工具点「获取更新」，把主程序和插件更到当前版；
2. 遇到任何诡异报错，第一反应也是先更一次版本——官方给的求助顺序第一条就是「确保使用最新版本的工具（最重要）」；
3. 别用版本号判断新旧，安卓端版本号表达不出构建先后，以工具内更新后的提示为准。

## 四、翻译相关的两个高频疑问

1. **「点了开始翻译没反应」**：先确认源语言选对（日文游戏选日语），再确认引擎没被等级卡住——必应无门槛，DeepSeek、彩云要 lv.1，ChatGPT 3.5 要 lv.2，对照[订阅等级与翻译引擎](订阅等级与翻译引擎.md)那张表换一个能用的引擎先翻起来；
2. **「想改翻译结果」**：翻译页里「导出待翻译的原文」可以导出文本自己改，「还原原文本」一键回到未翻译状态。改完重新加载即可，不用整场游戏重翻。

## 五、自己搞不定的时候

- 官方 MCenter（`https://trs.mtool.app/share/`）：共享汉化 json、翻译补丁、MOD 和存档，热门游戏先来这里找现成的；
- 官方 Discord（`https://discord.gg/NV5pjK5cYn`）：实时求助，多语言频道，提问时附上工具版本、游戏引擎、报错截图；
- 提问前先把工具内更新做一遍，大部分「奇奇怪怪的问题」到这一步就消失了。

装包环节的问题（安装不上、系统版本不够）回到[下载与安装教程](下载与安装教程.md)排查；游戏放进去跑哪些引擎要装哪个插件，见[引擎支持与插件下载](引擎支持与插件下载.md)。
