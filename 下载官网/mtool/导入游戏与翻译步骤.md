## 一、把游戏放进指定目录

手机版不「拖拽」，靠目录约定：把整个游戏的文件夹（连同里面的数据文件一起）复制或移动到手机的 `/MTool/Games` 目录下。

1. 用手机自带的文件管理器（或第三方文件管理应用）找到下载好的游戏包，解压出完整的游戏文件夹；
2. 把它整个剪切或复制到 `/MTool/Games` 下，路径结构大致长这样：

```text
/MTool/Games/
  └── 你的游戏名/
      ├── Game.exe
      ├── Game.rgss3a（或其它引擎数据文件）
      └── ...
```

3. 游戏资源包常见加密压缩，先解压成普通文件夹再放进去；只放一个压缩包进去它认不出来；
4. 找不到 `/MTool/Games` 就先启动一次 MTool，它会自己建目录；也可以直接在文件管理器的搜索栏搜 `MTool`。

## 二、启动游戏

1. 打开 MTool，进「游戏库」，刚放进去的游戏会出现在列表里；
2. 条目上可以给游戏设一张封面图，方便区分；
3. 点「启动游戏」。第一次启动某个游戏要加载资源，几秒到十几分钟都有可能，期间工具或游戏暂时无响应是正常的；
4. 加载完了游戏窗口会起来。手机端靠触屏操作，键位映射能把键盘按键映射成屏幕上的虚拟按键，键位可以自定义、保存成方案（不同游戏切不同键位），RPG/SLG 类基本够用；
5. 游戏放进去了却报不支持、或者起不来：先去[引擎支持与插件下载](引擎支持与插件下载.md)对引擎，还解决不了再看[常见问题与解决方法](常见问题与解决方法.md)。

## 三、翻译：两种情况

**情况 A：游戏自带汉化文件。** 有些游戏包里挂了 MTool 的 json 翻译文件（比如从社区分享拿来的），启动游戏时会自动加载，你什么都不用做，直接玩。

**情况 B：没有汉化文件，自己翻。**

1. 进入游戏后，点右上角的应用图标打开设置页；
2. 点「翻译」；
3. 选好源语言和目标语言（日文游戏就是 日语 → 简中）；
4. 点「开始翻译」。它会自动识别引擎、导出游戏文本、调用翻译引擎处理，完成后生成汉化文件并自动加载；
5. 文本量大的游戏这一步要等一阵，翻完之后文本就固定下来了——之后玩的时候**不需要一直联网**，地铁上、飞行模式都能继续看中文剧情。

想换回原文、或者导出待翻文本自己改，都在翻译页里：「还原原文本」「导出待翻译的原文」两个入口就在同一处。翻译引擎选哪个、哪些要订阅，看[订阅等级与翻译引擎](订阅等级与翻译引擎.md)。

## 四、修改游戏数值

在游戏运行中打开修改面板，可以查看和调整金钱、属性等数值，也能做游戏加速、穿墙、跳过战斗这类开关式操作；修改前它会先自动备份存档，改坏了能退回来，备份与恢复的细节见[存档备份与数据迁移](存档备份与数据迁移.md)。几点提醒：

- 不是所有道具、数值都能改到——部分游戏的某些道具改完也不会出现在道具栏里，属于引擎差异，不是操作错了；
- 有玩家反馈带反作弊机制的游戏会拦截修改操作，这类游戏改不了数值，翻译功能一般不受影响；
- 改数值、跳战斗这类操作只建议用在自己的单机存档上，联网对战或排行类内容别碰。

想看事件的触发条件、密码、分支：地图界面打开「事件迷你地图」（右上角）进「地图Ex」，里面按事件列出按钮，逐个点开对应开关；「开关 / 变量」界面里则是日期、时间段、隐藏数值这类参数。卡关、找回想入口时，这两个界面比翻攻略直接。
