如果你的机器上已经有一份能用的播放器，看这篇是为了回答一个具体问题：**「我看到别人说的某个功能，为什么我这一版里找不到？」** 多数情况下不是没找到，而是那一版还没有。下面的对照取自官方发布记录。

## 一、按版本看，后来加了什么

网盘里这一版是 **0.14.0**。之后的版本大致按这个节奏走（截至 2026-09 核对官方发布记录，具体以官方更新日志为准）：

| 版本 | 新增的主要内容 | 对使用的影响 |
| --- | --- | --- |
| 0.14.0 | 视频循环模式、关于页面、媒体列表网格视图、记住所有视频的播放位置、文件夹上显示时长 | 网盘里这一版 |
| 0.15.0 | 播放界面整体重写、Material 3 界面改版、媒体多选、随机播放、崩溃报告页 | 界面观感与操作位置变化较大 |
| 0.16 系列 | 底层播放库升级，修复锁定控制条时的黑幕、负时长导致的崩溃、添加外挂字幕后播放位置被重置等问题 | 稳定性与字幕相关的手感 |
| 0.17.0 | 隐藏视频保险库（PIN 锁）、媒体文件复制与移动、初步支持 Android TV、SMB/FTP/WebDAV 网络播放 | 功能上跨度最大的一版 |
| 0.17.2 ~ 0.17.5 | 修复 Android 7 上的存储权限崩溃、优化 SMB 传输、修复 WebDAV 目录地址处理 | 网络播放与老系统兼容性 |
| 0.18 系列 | 最新发布系列 | 内容以官方更新日志为准 |

一句话概括：**0.14.0 到 0.15.0 主要变界面，0.17.0 才是变能力。**

## 二、这一版没有的功能

对照官方新版的功能清单，下面这些是 0.14.0 之后才有的，在这一版里找不到入口：

| 功能 | 从哪一版开始 | 你会不会需要 |
| --- | --- | --- |
| 网络存储播放（SMB / FTP / WebDAV） | 0.17.0 | 想在电视盒子、路由器硬盘或 NAS 上直接放片时，这个功能是刚需 |
| 隐藏视频保险库（PIN 锁隐藏文件） | 0.17.0 | 手机里有不想被随手翻到的视频时才有用 |
| 媒体文件复制与移动 | 0.17.0 | 想在应用里直接整理文件、而不是切到文件管理器时有用 |
| Android TV 支持 | 0.17.0 | 电视盒子上装的才有意义 |
| 媒体多选与随机播放 | 0.15.0 | 片库大、经常连着放一整批的时候方便 |

另外，官方新版的功能清单里还能看到**媒体库搜索**、**字幕延迟调节**这类项目；本文没有逐字核对它们从哪一版开始提供，需要的话以官方更新日志为准。就 0.14.0 而言，字幕对不上时间轴时按 [字幕加载与音轨切换.md](字幕加载与音轨切换.md) 第五节的办法处理即可。

## 三、想换版本怎么操作

按你的目的分两种情况：

1. **只是想拿回网盘里这一版**（比如换手机重装、或者新版用不惯想退回来）：仍走 [Next Player 安装文件资源（夸克网盘）](https://pan.quark.cn/s/322a920fdc6f)，取到的就是 0.14.0；
2. **想用官方新版**：从官方出口取，渠道与地址列在 [下载与安装教程.md](下载与安装教程.md) 的最后一节。同一台机器上，从 Google Play 装的版本与从 GitHub、F-Droid 装的版本**签名不同，不能互相覆盖**，跨渠道换版本要先卸载再装。

升级或退回前先记住三件事：

- **卸载会清掉播放记录与你在应用里的设置**，介意的话别急着卸载，先确认新版一定要装；
- **老系统要多一步核实**：官方在 0.17.2 的更新记录里修过一条「Android 7 上的存储权限崩溃」，说明较新的版本在老系统上出过状况。手机系统还停在 Android 7 及更低版本时，装新版本之前先翻一眼官方更新日志里有没有相关的兼容说明；
- **升级后界面会变**：0.15.0 起播放界面经过一次整体重写，手势和按钮的位置与 0.14.0 不完全一致，原来的操作习惯要重新对一遍。

## 四、什么时候不用升级

不是所有情况都值得折腾。下面这几类需求，0.14.0 就能满足，升级带来的只是界面变化：

- 只放手机本地文件，不用电视、不用网络存储；
- 需要的手势、外挂字幕、倍速、画中画、后台播放都已经够用（这几项在 0.14.0 里就有）；
- 手机系统较老，或者不想重新适应一套新界面。

反过来，如果你要挂网络存储放片、要投到 Android TV、或者需要隐藏视频这类新功能，那就得升到 0.17.0 之后的版本，光靠 0.14.0 是补不出来的。

判断播放相关的问题属于哪一类，先看 [常见问题与排查.md](常见问题与排查.md)；一个文件到底能不能播，看 [支持哪些视频与字幕格式.md](支持哪些视频与字幕格式.md)。
