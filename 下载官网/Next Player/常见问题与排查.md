一个播放器装好之后真正会卡住人的，往往不是功能，而是权限、解码和后台限制这几处。这篇按「你看到什么」来分节，每节只给能动手的步骤，遇到问题时直接跳到对应那一节。

## 一、媒体库列表是空的

按顺序查这三项：

1. **读取视频的权限还在不在**。进「设置 → 应用 → Next Player → 权限」，看媒体相关项是不是「允许」；Android 13 及以后会分成「视频」「照片和视频」这类分项，缺一项就少一类文件。部分系统会在应用长期不用后自动收回权限，这类情况重新授权即可。
2. **文件放在哪里**。部分定制系统把 `Android/data` 一类的目录对新装应用完全隔离，放在那里的视频扫不到。把片子移到「下载」或自建的目录下，再刷新列表。
3. **该目录是不是被排除了**。带 `.nomedia` 标记的目录会被媒体扫描跳过，应用里也可能有按目录排除的选项，两者都会让内容不显示。

三项都排除过仍为空，先确认手机里确实有视频文件——用系统自带的相册或文件管理器看一眼。

## 二、点开文件没反应、黑屏或转圈

| 现象 | 先做什么 |
| --- | --- |
| 点了没反应，界面不动 | 确认这份文件不是 0 字节或传输中断的半成品，重新拷一次 |
| 一直转圈或黑屏有声 | 换另一部正常片子试，正常的能播说明是这一个文件的问题 |
| 提示不支持该格式 | 查它的视频与音频编码，对照 [支持哪些视频与字幕格式.md](支持哪些视频与字幕格式.md) 的清单 |
| 只有个别文件这样 | 是文件本身的问题，不是应用故障 |

从压缩包里直接点开播放在部分机型上会失败，先把文件解压到本地目录再播。

## 三、卡顿、高码率不流畅、发烫

按影响从大到小排：

1. **解码路径不合适**。同一部片子别的播放器流畅、这里转圈，多数是这个原因，在播放相关的设置里看看有没有解码方式可选，切换后重试。硬解通常比软解流畅且省电。
2. **片源本身超出设备能力**。4K 高码率原盘配中低端芯片，任何播放器都救不回来，转成较低码率是比较稳的办法。
3. **同时跑的负载太多**。一边看片一边后台下载、一边开着小窗聊天，解码会抢不到资源。
4. **发热降频**。连续看半小时以上才开始卡，多半是机身温度上去了被降频，摘掉厚壳、别边充边看能缓解。

## 四、有画面没声音，或者声音和画面不同步

**没声音**时先做这两步：

1. **换一条音轨**。多音轨影片默认选中的那条可能是多声道格式（AC-3、DTS 之类），手机扬声器或普通耳机解不了就变成静音，切到立体声轨往往就有声音了；
2. **换一个文件验证**。别的文件有声音、只有这个没有，说明是这份片源的音频编码问题，见 [字幕加载与音轨切换.md](字幕加载与音轨切换.md) 里的音轨选择。

**音画不同步**分两种：整体固定差几秒属于片源或蓝牙耳机延迟，接线耳机试一次就能区分；播放过程中越来越不同步，通常是性能跟不上导致的，按上一节的卡顿来处理。

## 五、字幕不显示、乱码或对不上

- **完全不显示**：先确认字幕是内嵌轨还是外挂文件。外挂文件要手动载入（长按字幕图标），内嵌轨要在轨道列表里选中；如果关掉所有轨道后字幕仍在，那是硬字幕，关不掉；
- **显示成方块或乱码**：把字幕文件另存为 UTF-8 编码再重新载入；
- **时间轴整体偏移**：换一份与片源版本匹配的字幕，或整体平移字幕文件里的时间码。具体操作见 [字幕加载与音轨切换.md](字幕加载与音轨切换.md)。

## 六、装不上、闪退

| 现象 | 处理 |
| --- | --- |
| 提示「应用未安装」 | 手机里已装了更高版本，或装了另一条分发渠道的同包名版本（签名不同不能互相覆盖）；先卸载再装 |
| 提示与设备不兼容 | 本机系统低于这份包的兼容线，或安装包没下载完整，重新下一次 |
| 装完打开就闪退 | 卸载后重装一次，直接覆盖安装遗留的旧数据是常见诱因 |
| 安装界面反复弹安全提示 | 第三方渠道安装包的常规提示，按提示继续即可 |
| 想要一份干净的安装包 | 从 [Next Player 安装文件资源（夸克网盘）](https://pan.quark.cn/s/322a920fdc6f) 重新转存下载，装之前先卸载旧版 |

重装会清掉本地的播放记录与设置，介意的话先别急着重装，把权限和后台限制这两项先排除掉。如果是想换一个版本（升级到官方新版、或从新版退回网盘里这一版），先看 [网盘里这一版和官方新版有什么区别.md](网盘里这一版和官方新版有什么区别.md) 里的注意事项，跨渠道换版本必须先卸载。

## 七、后台播放被掐断、小窗弹不出来

退出应用后声音立刻停，是系统的后台限制在起作用，不是播放器被关掉了：

1. 进「设置 → 应用 → Next Player」，找到电池相关的选项；
2. 把省电策略改成「不受限制」或加进白名单；
3. 部分机型的手机管家里还有一层「后台运行管理」，同样要放行；
4. 别用第三方清理工具冻结它的后台进程，被冻结后常常表现为播不动、列表空掉。

小窗（画中画）弹不出来时，先在应用详情页里找有没有单独的画中画开关，被关掉的情况下按主屏键只会直接退出。这两项的操作细节见 [播放手势与画面设置.md](播放手势与画面设置.md)。

## 八、耗电偏快

同一部片子，硬解通常比软解省电得多，长时间看片优先保证走硬解路径；只听声音时把画面退到后台，也比亮着屏播放省。如果只是待机时耗电快，那和播放器无关，去系统的耗电排行里确认是谁在跑。安装与权限的基础配置见 [下载与安装教程.md](下载与安装教程.md)。
