## 一、免费版装上就能用的部分

按官方支持页面的划分，免费版包含的内容足够你完整地做一次混音：

- 双转盘（2-deck）混音台、滤波、EQ 与基础效果器；
- Automix 自动混音，歌曲之间的衔接会自动做对拍处理；
- 接入受支持的流媒体曲源或播放本机音乐（曲源详见[曲库管理与曲源接入](曲库管理与曲源接入.md)）;
- 连接受支持的 DJ 控制器（具体到设备，功能支持程度有差异）。

本机音乐混音不强制注册账号，装好后选歌就能开练。

## 二、Pro 订阅额外解锁什么

下表按官方说明整理（标注平台的功能在安卓上不提供）：

| 功能 | 免费版 | Pro |
| --- | --- | --- |
| 双转盘混音、EQ、滤波、基础效果 | 有 | 有 |
| Automix 自动混音 | 有 | AI 版本，衔接更完整 |
| 耳机预听（Pre-cueing） | 无 | 有 |
| Neural Mix 人声/鼓/旋律实时分离 | 无 | 有（安卓上因设备而异） |
| 音序器与循环器（Sampler & Looper） | 无 | 有 |
| 4 转盘模式 | 无 | 有（macOS / iOS / Windows，安卓无） |
| 录制混音 | 无 | 有 |
| 视频混音 | 无 | 有（macOS / iOS，安卓无） |
| 控制器支持 | 可连但功能受限 | 100+ 型号即插即用、DVS、MIDI 自定义映射 |

从[下载与安装教程](下载与安装教程.md)装好的免费版里，这些 Pro 功能的入口一般以锁定状态出现，点了会引导你订阅。

## 三、订阅方式与跨平台

- **开通途径**：在应用内订阅。安卓上通过 Google Play 结算，开通前有 7 天免费试用；不想续费要在试用期结束前足够早地取消，避免被扣费。
- **跨平台通用**：Pro 订阅绑定 djay 账号，登录同一个账号即可在 Android、iOS、macOS、Windows 上共用同一份订阅。
- **价格与时点**：订阅价格与政策会调整，以应用内或官方页面的当时显示为准。

## 四、两个容易踩的限制

这一节是官方文档里写了、但很多人到手上才发现的部分：

1. **耳机预听属于 Pro**。想在正式播放前用耳机单独听下一首（DJ 打碟的标准动作），免费版做不到。安卓上没有外接声卡时的替代方案 Split Output 也属于 Pro（设置方法见[音频输出与耳机预听设置](音频输出与耳机预听设置.md)）。
2. **流媒体曲目上的两个禁区**：用流媒体源放歌时不能录制混音；Neural Mix 的人声分离不能作用于 Apple Music 或 Spotify 的流媒体曲目。想对一首歌做人声分离，需要先把这首歌以本地文件的形式放进设备。录制的完整操作与导出方法见[录制混音与导出音频](录制混音与导出音频.md)。
