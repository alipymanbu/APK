## 一、安卓上音频是自动配置的

与电脑版不同，安卓版的音频路由基本由系统自动处理：没有混音模式选择、没有输出设备下拉菜单。你能在 djay 设置的声音（Sound）页里直接调的只有两项：

- **主音量（Main Volume）**；
- **Split Output（分离输出，用于耳机预听）**。

声音从手机扬声器、耳机口还是已连接的控制器出来，取决于你的硬件连接方式。如果声音出得不对，第一反应不是翻设置，而是检查「谁占着音频输出」——拔掉蓝牙音箱、重新插一次耳机，往往就正常了。

## 二、Split Output：一副耳机分左右做预听

想边放歌边用耳机听下一首（DJ 的标准动作），没有专用声卡时靠 Split Output：

1. 准备一根**立体声转双单声道的 DJ 分线**（stereo/mono split cable）：插头一端插手机，另一端分出两个输出口——一个出主输出，一个出预听（Cue）。
2. 主输出（观众听的那路）接音箱，预听那路接耳机。
3. 在 djay 设置里打开 Split Output。

开启后，主输出走立体声的一侧（左声道）、预听走另一侧（右声道），分线再把两侧拆开；预听到的始终是与主输出相对的那一个转盘。三点注意：

- **这个功能属于 Pro 订阅**（免费版里该开关不可用，功能边界见[免费版与Pro订阅对比](免费版与Pro订阅对比.md)）；
- 普通的一分二耳机分线器不是这种用途的 DJ 分线，买之前认准「stereo to mono split」的描述，Traktor DJ Cable 是这类分线的常见选择之一；
- 现在不少手机没有耳机口，整条链路是 **USB-C 转 3.5mm 转接头 + DJ 分线**。转接头有数字、模拟两种，你的手机只认其中一种（常见表现为插上完全没声音），买之前先确认兼容性；想边接转接头边充电，需要带供电口的产品。

## 三、蓝牙与有线的差别

蓝牙耳机/音箱接入后必然带有可感知的延迟：你搓一下盘，声音晚半拍才出来。结论很简单：

- **练手、随便听**：蓝牙能凑合，但对不上拍的时候别怀疑自己的手法，先怀疑蓝牙；
- **认真混音、接音箱放歌**：一律有线——耳机口、USB-C 声卡，或带音频接口的 DJ 控制器。

## 四、接 DJ 控制器时先查什么

安卓版对控制器是即插即用的设计，官方列出过的原生支持型号包括 Pioneer DJ DDJ-200（蓝牙 MIDI 连接）、DDJ-WeGO4 / DDJ-WeGO3、Reloop Mixtour、Reloop Beatpad / Beatpad 2、Reloop Mixon 4、Reloop Buddy 等，具体清单与系统要求以[官方硬件页面](https://www.algoriddim.com/hardware)当时显示为准。接不上或声音不对时按顺序查：

1. **供电**：不少控制器需要独立供电（电源适配器或充电宝），只靠手机供电带不动；
2. **连接方式**：DDJ-200 这类走蓝牙 MIDI 的，先在手机蓝牙设置配对，再到 djay 设置的 MIDI 里扫描选择；USB 型号用 OTG 线直连，优先用官方转接头。注意蓝牙 MIDI 的配对在应用关闭或手机休眠后会丢失，**每次开工都要重新配对**，排练时别把这步漏在最后；
3. **声音出在哪**：控制器带音频接口的，声音默认走控制器；只有 MIDI 功能的，声音仍走手机。

## 五、声音不对时的排查清单

按命中概率排序，逐条试：

| 现象 | 处理 |
| --- | --- |
| 完全没声音 | 检查主音量、确认没有别的应用占着音频、重启 djay |
| 一卡一卡、有杂音 | 关掉后台大型应用；关闭系统对 djay 的电池优化（设置 → 电池） |
| 推子/旋钮有延迟 | 换掉蓝牙输出改有线；换一条 USB 线或直连不经过集线器 |
| 只有一边响 | 检查 Split Output 是否开着却没接分线；换耳机确认不是耳机问题 |
| 放着放着声音停了、应用退到后台被杀 | 把 djay 加入电池优化白名单；演出/排练前把系统屏幕休眠时间设为「永不」或长于最长曲目 |

有用户反馈部分机型（尤其个别小米/Redmi 机型）在 USB 音频路由上兼容性差，同一台控制器换一台手机结果就不同——遇到这类现象，换设备验证比反复调设置更快。另有用户反馈在较新的安卓系统上遇到过 USB 音频路由导致的数百毫秒级延迟，开发者选项里「停用 USB 音频路由」后消失（属单一案例，遇到同样现象可一试）。
