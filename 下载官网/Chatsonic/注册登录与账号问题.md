## 一、需要账号才能用

Chatsonic 走 Writesonic 的账号体系，网页版和手机 App 用的是同一个账号。首次打开应用会停在登录页，先注册或登录才能进对话界面。官方渠道是 [writesonic.com](https://writesonic.com)，账号相关操作（找回密码、改邮箱、管理订阅）以官网页面提供的入口为准。

## 二、注册与登录步骤

1. 打开应用，在登录页选择注册新账号；
2. 按提示填写邮箱并完成验证（也支持官网已有的账号直接登录）；
3. 登录成功后进入对话界面，之后换手机、重装应用，用同一个账号登录即可。

注册时用的邮箱要记牢——找密码、换设备都靠它，用一次性邮箱注册后续接收不到验证邮件会很麻烦。

## 三、免费额度与付费的大概口径

- 新注册的账号有免费试用额度，核心功能都能先试一遍再决定要不要付费；
- 额度用完后继续使用需要订阅官方套餐，按月或按年计费；
- 官方资料里提过套餐内有不同「质量档位」可选，档位越高单次生成消耗的额度越多，同样的额度在高档位下能用的次数更少；
- 额度数值、价格、档位名称官方会调整，别按文章里的旧数字做决定，以官网当时显示为准。

## 四、登录不上的常见处理

| 现象 | 按顺序试 |
| --- | --- |
| 密码错误 | 先用「忘记密码」走重置流程；确认注册用的邮箱没记错 |
| 收不到验证邮件 | 翻垃圾箱；等几分钟再试；还不行换个邮箱重新注册 |
| 一直转圈进不去 | 检查网络；在 Wi-Fi 和流量之间切换一次再登录 |
| 换设备后「账号不存在」 | 确认登录方式和邮箱与注册时是同一套，别混用 |
| 用第三方账号（如 Google）注册的，邮箱密码登不上 | 这类账号没有独立密码，回到登录页改用对应的第三方登录方式 |
| 开了两步验证后验证码总不对 | 核对手机「自动设置日期与时间」——两步验证对时间敏感，手机时间不准会全错 |
| 提示账号被临时锁定 | 连续输错密码会触发临时锁定，等 15~30 分钟再试，期间别反复点登录按钮 |

## 五、几点提醒

- 免费额度属于正常的使用限制，额度用尽时应用会给出对应提示，按官方套餐规则处理即可；
- 网页版（writesonic.com）和 App 的功能范围不完全一样，具体差异以官方页面为准；
- 登录问题处理后仍进不去应用的，检查是不是装错了包——安装包信息核对见 [下载与安装教程.md](下载与安装教程.md)，其他使用问题见 [常见问题与解决办法.md](常见问题与解决办法.md)；
