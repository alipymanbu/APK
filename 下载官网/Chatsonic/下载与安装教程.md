## 一、先对一眼安装包信息

装之前先确认手里的文件是不是这一份，避免装错包：

| 项目 | 内容 |
| --- | --- |
| 应用名称 | Chatsonic（安卓应用名 Chatsonic - AI Chatbot） |
| 版本 | 1.3.2 |
| 安卓包名 | `news.chatbxt.bxta` |
| 安装包大小 | 54.67M |
| MD5 | 2CF114CA2FA35D3AAD23342F997B17D6 |

官方后续可能发布更新版本，新版本的改动以官方发布页为准。

## 二、从网盘转存到手机

1. 打开 **Chatsonic 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/47dde1361dc7](https://pan.quark.cn/s/47dde1361dc7)（手机装夸克 App 或用浏览器打开都行）；
2. 选择「保存到网盘」，先转存到自己名下；
3. 在自己的网盘里找到这份安装包，下载到手机本地存储。

转存这一步不能省——分享链接里的文件不转存就直接用，链接失效后就找不回来了。

## 三、安装步骤

1. 在手机的「文件管理」或「下载」里找到下载完成的 `.apk` 文件，点击安装；
2. 如果系统提示「禁止安装未知来源应用」，按提示跳到设置页，允许这个来源安装后返回继续；
3. 等安装完成，点「打开」直接进入应用。

「未知来源」授权的入口各品牌不太一样，常用的几条路：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / vivo | 安装弹窗里选「仍要安装」，或按提示去设置授权 |
| 原生 / 其他 | 设置 → 应用 → 特殊访问权限 → 安装未知应用 |

系统版本不同入口名称会略有出入，找不到时直接在设置顶部的搜索框里搜「未知」两个字最快。

## 四、第一次打开会看到什么

首次启动会要求登录账号——Chatsonic 走 Writesonic 的账号体系，没有账号先注册一个，步骤见 [注册登录与账号问题.md](注册登录与账号问题.md)。登录后就能进对话界面了，选角色、语音对话这些玩法见 [角色扮演与对话玩法.md](角色扮演与对话玩法.md)。

## 五、装不上怎么办

- **提示「解析包错误」或「应用未安装」**：多半是文件没下载完整，删掉重新下一遍，怎么核对文件没坏见 [常见问题与解决办法.md](常见问题与解决办法.md)；
- **提示存储空间不足**：安装包本身 54.67M，安装后占用的空间比它大，留出 200M 以上余量再装；
- **提示系统版本过低**：这份包对安卓版本要求不算高，个别老机型遇到提示只能先升级系统。

安装环节的其他报错在 [常见问题与解决办法.md](常见问题与解决办法.md) 里按场景列了处理顺序。
