## 一、首次打开：权限与界面

首次启动 HMCL-PE 会请求存储权限，允许——游戏文件、存档、模组全都要写进手机存储。官方 Wiki 的快速上手也把这一步列为开始前的必要动作；如果卡在这一步之前（闪退、装完点不开），先去 [常见问题与故障排查.md](常见问题与故障排查.md) 对现象。

主界面里能看到几块主要内容：账号管理、游戏列表、下载入口与设置。界面支持多语言，主题与配色在设置里可以换（官方把「自定义主题和颜色」列在功能清单里），不习惯默认配色就先去设置里调。设置里改的东西不影响游戏本身，随时可以再改回来。

## 二、先加账号再下载

账号在启动器里添加，有三类，按你的情况选：

| 类型 | 你需要什么 | 能干什么 |
| --- | --- | --- |
| 离线账号 | 只填一个用户名 | 进单人游戏、局域网联机；皮肤可以在启动器里自定义 |
| 微软账号 | 拥有 Minecraft Java 版的微软账号 | 正版登录，可加入需要正版验证的服务器 |
| 外置登录 | 第三方认证服务器（皮肤站）的地址与该站账号 | 以该皮肤站的认证方式登录，皮肤用皮肤站上的 |

几点具体说明：

- **离线账号**最省事，适合先跑通流程。名字即游戏内 ID，想好后填；想给它换皮肤也得靠这个名字对应（见 [账号皮肤与外置登录设置.md](账号皮肤与外置登录设置.md)）；
- **微软账号**走官方授权登录，按提示在网页里完成授权即可。如果登录成功了却提示找不到 Minecraft 配置文件，说明这个微软账号没有 Java 版的购买记录，处理思路见 [常见问题与故障排查.md](常见问题与故障排查.md)；
- **外置登录**面向使用 LittleSkin 这类皮肤站的玩家：添加账号时选外置认证类型，把你的认证服务器地址填进去。具体地址格式、皮肤站角色与游戏 ID 的对应关系，完整流程见 [账号皮肤与外置登录设置.md](账号皮肤与外置登录设置.md)；
- 账号列表里还留有 Mojang 旧账号的入口，但旧 Mojang 账号登录早已被微软停用、账号都并入了微软账号体系，这条通道实际用不上，不用纠结。

## 三、下载游戏本体

进「下载」页，游戏版本分三类：

| 类型 | 是什么 | 适合谁 |
| --- | --- | --- |
| 正式版 | 官方正式发布的稳定版本 | 绝大多数人，包括想装模组的 |
| 测试版 | 官方放出的下一版本预览（快照） | 想尝鲜新内容的；不稳定，模组基本跟不上 |
| 远古版 | 很早期的老版本 | 想怀旧、或模组/存档指定老版本的 |

选择顺序建议：**先定你要玩的东西，再定版本**。想装某个模组或整合包，先看它支持的 Minecraft 版本和加载器，再回到这里下载对应版本（详见 [模组与整合包安装.md](模组与整合包安装.md)）；只是想先玩起来，就下最新正式版。

点「安装」后启动器开始拉取游戏文件。两点提醒：

- 游戏本体加资源文件的体积远大于启动器安装包，下载前确认剩余空间充足；
- 下载页偶尔加载不出内容，多数是资源服务器暂时不可用，刷新或过段时间再试。

游戏文件都落在启动器存储目录的 `.minecraft` 文件夹里（所以文件管理器要能显示隐藏文件夹），以后手动放模组、拷存档都认这个位置。

## 四、启动游戏

回到游戏列表，选中已安装的版本点「启动」。第一次启动某个版本时，启动器会先核对并补全游戏文件，所以会多等一阵；之后启动就快了。

Java 环境不用你操心：启动器内置了 Java 8 与 Java 17 两套运行时（按设备架构提供），旧版本 Minecraft 用 Java 8，1.17 及以上的新版本用 Java 17。自己另外装 Java 反而容易出问题。只有一种情况会卡住：个别新整合包要求高于 Java 17 的运行环境——那超出了这套启动器（最终版 2.0.8）内置运行时的范围。

进入游戏后的操作是纯触屏方案，按钮布局与虚拟鼠标的调整见 [触屏操作与虚拟鼠标设置.md](触屏操作与虚拟鼠标设置.md)。游戏能进、能存档，基础流程就通了；之后想装模组或整合包，回 [模组与整合包安装.md](模组与整合包安装.md)。
