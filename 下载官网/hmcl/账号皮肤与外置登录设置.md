## 一、皮肤跟着账号类型走

你在游戏里长什么样，取决于登录用的是哪类账号（账号的添加方法见 [首次启动与游戏下载.md](首次启动与游戏下载.md)）：

| 账号类型 | 皮肤来源 |
| --- | --- |
| 微软账号（正版） | 自动读取你在官方的皮肤，不用设置 |
| 离线账号 | 默认皮肤；想换就靠皮肤站同步或应用内的皮肤管理 |
| 外置登录 | 使用你认证站（皮肤站）上这个角色的皮肤 |

HMCL-PE 的账号系统自带皮肤管理，还有 3D 皮肤预览（应用内能直接看到换上后的效果）。皮肤站的账号体系是独立于游戏的第三方服务，注册、上传皮肤都在皮肤站网站上完成，启动器只负责「同步」这一步。

## 二、离线账号挂皮肤站皮肤（以 LittleSkin 为例）

LittleSkin 是最常见的公开皮肤站，流程五步：

1. 在 [LittleSkin](https://littleskin.cn/) 注册账号；
2. 进「角色管理」，添加一个角色——**角色名就是你以后的游戏 ID**；
3. 在 HMCL-PE 里新建（或核对）离线账号，**用户名必须与角色名逐字一致**，不一致就删掉重建一个同名的；
4. 在站上的「我的衣柜」给角色穿上皮肤；
5. 回到启动器的账号管理里，对该账号选 LittleSkin 同步。

两点提醒：

- 角色名一旦传开就是你的游戏身份，先想好再建，改名要重来一遍上面的对应关系；
- 换皮肤在皮肤站网站上换，游戏里同步生效，不用反复动启动器。

其他基于 Blessing Skin 系统搭的皮肤站（一些社区自建站）流程相同，只是入口换成了那个站自己的网址。

## 三、外置登录账号怎么加

外置登录面向使用第三方认证服务器的玩家——不只皮肤，连登录验证都走那个站。添加账号时选外置认证类型，填三样东西：

| 要填的 | 填什么 |
| --- | --- |
| 认证服务器地址 | 皮肤站提供的 API 地址，形如 `https://站点域名/api/yggdrasil`，以站内说明页给的为准 |
| 账号 | 你在该站的注册账号（多数站是邮箱） |
| 密码 | 该站密码 |

建好后游戏内身份就是你在该站的角色，皮肤、披风都从站上读。选哪个站看你要进的服务器：不少服务器只认特定认证站的账号，加服前先看服务器的说明。

## 四、联机时别人能不能看到你的皮肤

这是离线皮肤最常见的落差，先把口径说清：

- **正版账号**的皮肤在官方与多数服务器上都正常显示；
- **皮肤站同步**的皮肤，在同样走该认证方式的服务器上其他玩家看得到，普通服务器上不一定；
- **纯本地/默认离线皮肤**，联机时其他人大概率看不到，只有你自己屏幕上是新的。

想让人看到，就把皮肤放在账号体系里（正版或认证站），而不是只在本地改。联机本身的版本一致等问题见 [常见问题与故障排查.md](常见问题与故障排查.md)。
