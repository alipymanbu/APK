## 一、HMCL-PE 是什么

HMCL-PE（Hello Minecraft! Launcher: Pocket Edition）是安卓平台上的 Minecraft Java 版第三方启动器，作者是 Tungsten，以 GPL v3 协议开源（[官方主页](https://tungstend.github.io/)、[GitHub 仓库](https://github.com/HMCL-dev/HMCL-PE)）。你在手机上要做的版本管理、账号登录、模组安装、光影与存档，都通过它完成。

先把几个容易混淆的点说清：

- 它跑的是 **Java 版** Minecraft，不是手机应用商店里那个「我的世界」（基岩版）。两边的存档、模组体系互不通用；
- 它与电脑上的 HMCL 启动器是**两个应用**：HMCL-PE 是安卓上的独立实现，包名为 `com.tungsten.hmclpe`，电脑版安装包装不到手机上；
- 安装包里**只有启动器**，不带游戏本体。Java 版 Minecraft 要装好启动器之后，在应用内的「下载」页另行下载（见 [首次启动与游戏下载.md](首次启动与游戏下载.md)）。

## 二、停更状态（动手前先知道）

官方仓库的说明写得很直接：HMCL-PE 已停止维护，2.0.8 就是最后一个版本（2024-02-08 发布，官方留在应用内更新元数据里的最后一条更新日志写的是「Final update」）。同时官方建议想要更好体验的用户改用 [Fold Craft Launcher](https://fcl-team.github.io/) 或 [PojavLauncher](https://github.com/PojavLauncherTeam/PojavLauncher)。

对你实际意味着两件事：

- 现在从任何渠道拿到的官方安装包都是 2.0.8，不存在「下到旧版、要不要升级」的问题；
- 在较新的手机系统上遇到 bug，不会再有修复版本，能自己绕过去的问题见 [常见问题与故障排查.md](常见问题与故障排查.md)，绕不过去的就按官方建议换用仍在维护的启动器。

## 三、你的手机能不能用

| 项目 | 要求 |
| --- | --- |
| 系统 | Android 8.0 及以上（官方源码声明的最低系统版本） |
| 设备 | 64 位安卓手机 |
| 内存 | 至少 4 GB（官方 Wiki 口径） |
| 存储 | 剩余空间 512 MB 是官方 Wiki 给的底线；这只够启动器自己，游戏本体、资源与存档要另留空间 |
| 文件管理器 | 要能显示隐藏文件夹——游戏目录 `.minecraft` 以点开头，很多文件管理器默认不显示 |

内存低于 4 GB 的机器不是不能装，而是装完下载游戏后大概率带不动，先按第四节把启动器装上看主界面没问题，再决定要不要下游戏。

## 四、安装包从哪拿

两条路，拿到的都是同一个最终版本：

1. **网盘**：打开 [HMCL-PE 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5d0c3cfc92f2)，把 APK 下到手机直接装。适合不方便访问 GitHub 的网络环境。
2. **官方发布页**：[github.com/HMCL-dev/HMCL-PE/releases](https://github.com/HMCL-dev/HMCL-PE/releases)，2.0.8 这个发布对应的文件名是 `HMCLPE-release.apk`（以发布页当时显示为准）。

HMCL-PE 的官方分发渠道就是 GitHub 发布页，不通过应用商店。安装完成后应用内也不会再推送新版本——没有下一个版本了。

## 五、装之前核对安装包

网盘里这份安装包的记录如下，下载完可以逐项核对：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.0.8 |
| 大小 | 170.99 MB |
| 包名 | `com.tungsten.hmclpe` |
| MD5 | `0C99379AF9809C4CE6A040BCB195A10C` |
| 信息记录日期 | 2026-09-27 |

- **核对大小**：下载完成的文件应在 171 MB 上下，明显偏小说明没下完整，删掉重下；
- **核对包名**：用任意「APK 信息查看」工具打开文件，包名应是 `com.tungsten.hmclpe`。安卓上的 Java 版启动器不止 HMCL-PE 一个，包名对不上就别装；
- **核对 MD5**：需要严格确认文件没被改动时，用文件管理器或电脑上的校验工具算一遍 MD5，与表中对照。

## 六、安装步骤

1. 按第四节把 APK 下到手机存储里；
2. 在文件管理器里点开 APK。系统提示「未知来源应用」时，允许本次安装；
3. 装完在桌面打开 HMCL-PE，首次启动会请求存储权限，允许——后面的游戏文件全部存在手机存储里；
4. 进主界面后先添加账号，再下载游戏，顺序见 [首次启动与游戏下载.md](首次启动与游戏下载.md)。

安装过程没有任何选项要填。如果安装被系统拒绝，先按第五节核对 APK 是否完整，再确认手机系统是 Android 8.0 以上；装上之后遇到问题，先去 [常见问题与故障排查.md](常见问题与故障排查.md) 对一遍现象。
