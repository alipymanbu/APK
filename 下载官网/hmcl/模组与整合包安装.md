## 一、先装加载器，再谈模组

模组不能直接丢进原版游戏，要先给对应的游戏版本装上模组加载器。入口在启动器的游戏管理里（「自动安装」），支持这几类：

| 加载器 | 说明 |
| --- | --- |
| Forge | 老牌加载器，历史上多数大型模组面向它 |
| Fabric | 轻量加载器，新模组很多优先支持它 |
| OptiFine | 画质优化向，可与上面两者形成组合关系 |
| Quilt | Fabric 系的分支 |
| LiteLoader | 早期轻量加载器，服务于老版本模组 |

两条铁律：

1. **加载器版本必须匹配游戏版本**——给 1.20.4 的游戏装 1.12.2 的 Forge 是装不上的，选加载器时先确认游戏版本；
2. **Forge 模组与 Fabric 模组互不通用**——想玩的模组说明里写了要 Forge 就装 Forge，写了 Fabric 就装 Fabric，别混。

装好加载器后，这个游戏版本的目录里会出现 `mods` 文件夹（在 `.minecraft` 下面，文件管理器要能显示隐藏文件夹），模组文件就放这里。

## 二、模组文件两种放法

**手动放文件**：把下载好的 `.jar` 模组文件复制进对应版本的 `mods` 文件夹，重进游戏生效。注意模组的 Minecraft 版本与加载器类型都要对得上，塞进去一大堆不匹配的 `.jar` 是游戏打不开的常见原因。

**应用内下载**：启动器的「下载」页里能直接搜模组——官方功能清单里明确列了模组、整合包、材质、地图的下载。搜到想要的模组点安装，省去找文件、拷文件的步骤。无论哪种放法，装完启动报错时先怀疑模组冲突，排查思路见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 三、材质包与光影

- **材质包**（官方叫 Textures，应用内可直接下载）：换游戏贴图的外观包，原版渲染就能用，装上即可；
- **光影**（Shaders）：动态阴影、水面反射这类画面增强，**必须在 VirGL 渲染器下才有画面**——这是官方功能清单里写明的绑定关系。渲染器在启动器设置里切换：想开光影就切 VirGL，代价是对设备性能要求更高；性能跟不上的机器用 GL4ES 并放弃光影，画面稳定得多。两个渲染模式怎么选、光影的代价与预期，见 [渲染模式选择与光影画质.md](渲染模式选择与光影画质.md)。

## 四、整合包与地图

- **整合包**（ModPacks）：别人配好的一整套模组组合，在应用内下载后直接玩，省去逐个装模组、调配置的步骤。玩整合包遇到启动问题，先找整合包作者给的说明——整合包自带的配置与启动器设置不一致时，以整合包说明为准；
- **地图 / 存档**（Worlds）：应用内可下载地图；自己的存档支持导入、导出与备份，换机或重装前先导出一份。手机和电脑之间的存档互通的做法见 [常见问题与故障排查.md](常见问题与故障排查.md)。

装好模组进入游戏后，很多模组界面要靠虚拟鼠标才能点按，操作相关的内容见 [触屏操作与虚拟鼠标设置.md](触屏操作与虚拟鼠标设置.md)。
