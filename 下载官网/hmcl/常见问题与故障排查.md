# HMCL-PE 常见问题与故障排查

> 启动不了、卡在「准备中」、没有声音、登录报错、联机失败——按现象对号入座，每条都给你能直接做的动作。

## 一、下载页 / 资源列表空白

**现象**：「下载」页里游戏列表或模组列表加载不出任何东西。

**处理**：先刷新。资源服务器偶尔不可用，是这类启动器下载源的常见情况，隔一段时间再试通常就恢复了。反复多天都空白，再检查手机网络（切换 Wi-Fi / 流量对比）。

## 二、启动一直卡在「准备中」

**现象**：点了启动，状态长时间停在「准备中」，进不去游戏。

**原因**：多与游戏文件没下全有关——库文件（`libraries`）下载中途出错，启动器在反复补文件。下载过程断过网的话很容易撞上。

**处理**：换个更稳的网络再启动一次；反复卡在同一位置，就到 `.minecraft` 目录里删掉 `libraries` 文件夹，让启动器重新下载（知道具体是哪个文件出错的话，只删那个文件也行）。

## 三、游戏一闪而过 / 点了没反应

**现象**：启动画面闪一下就回桌面，或者干脆没进游戏。

**处理**：按顺序排查——

1. 先按第二节删 `.minecraft/libraries` 重新下载，这是最常见的原因；
2. 装了模组的，退掉 `mods` 文件夹里的模组再启动一次，能进就说明是模组冲突，逐个加回去定位（见 [模组与整合包安装.md](模组与整合包安装.md)）；
3. 怀疑安装包本身损坏时，对照 [下载与安装教程.md](下载与安装教程.md) 里的 MD5 表核对；对不上就重新下载 [HMCL-PE 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5d0c3cfc92f2)，重装启动器；
4. 手机内存紧张也会导致直接被杀，关掉后台大应用再试。

## 四、没有声音 / 游戏里没有中文

**现象**：游戏能玩，但音效全无，或界面文字缺成英文。

**原因**：游戏的声音与语言资源文件没有下载全。

**处理**：在启动器设置里找资源下载入口，选「全部下载」把资源文件补齐，然后重启游戏。

## 五、微软账号登录报错（找不到配置文件 / 404）

**现象**：微软授权本身成功了，但登录后提示没有 Minecraft 配置文件。

**原因**：这个微软账号没有 Minecraft Java 版的购买记录——启动器登录没问题，是账号没有游戏权益。

**处理**：确认你登的是买过 Java 版的那个微软账号；只想先体验的话改用离线账号（想给离线账号配上皮肤，见 [账号皮肤与外置登录设置.md](账号皮肤与外置登录设置.md)），但离线账号进不了需要正版验证的服务器。

## 六、黑屏 / 光影不显示

**现象**：开光影后黑屏、花屏，或者画面整体异常。

**处理**：光影必须配 VirGL 渲染器（[模组与整合包安装.md](模组与整合包安装.md) 里有说明），先到启动器设置里确认渲染器；切到 VirGL 后性能跟不上的机器会黑得更频繁，那就退回 GL4ES 并关掉光影——低端设备与光影基本无缘，这是取舍不是故障。两个模式的取舍逻辑见 [渲染模式选择与光影画质.md](渲染模式选择与光影画质.md)。

## 七、联机失败

**现象**：朋友之间加不上彼此的游戏。

**逐项核对**：

1. **版本一致**：所有人的游戏版本、已装模组必须完全一致，版本差一点都连不上，这是联机失败的第一大原因；
2. **房主操作**：房主在游戏内菜单选「对局域网开放」，创建世界后把端口信息给朋友；
3. **同一网络**：所有人连同一个 Wi-Fi / 局域网。跨城市的联机需要额外的组网工具，那不属于启动器或游戏本身的功能，不在本篇范围。

## 八、存档和电脑版能不能通用

能。Java 版的存档目录在手机和电脑上都是 `.minecraft/saves`，把存档文件夹直接拷过去就能用——手机玩一半回电脑接着玩是可行的。注意只有 Java 版之间通用，基岩版（手机应用商店那个「我的世界」）的存档不通用。

存档的导出备份操作见 [模组与整合包安装.md](模组与整合包安装.md)；找不到 `.minecraft` 文件夹，多半是文件管理器没显示隐藏文件夹。

## 九、都试过还是不行

HMCL-PE 停更在 2.0.8，不会再有修复版本。你的手机系统如果比它新很多（比如新的安卓大版本），遇到绕不过去的兼容问题，按官方仓库的建议改用仍在维护的启动器（PojavLauncher、Fold Craft Launcher）是最后一条路。启动器本身的版本核对与重装见 [下载与安装教程.md](下载与安装教程.md)，账号与游戏下载的问题回 [首次启动与游戏下载.md](首次启动与游戏下载.md) 对一遍流程。
