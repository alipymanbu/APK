## 一、同步进来的是什么数据

腕表连上 app 后，这些数据会自动进 Suunto App：

| 类别 | 内容 |
| --- | --- |
| 锻炼与潜水记录 | 每次的详情数据与轨迹，配活动图表；你可以给记录补照片、视频和文字描述 |
| 日常活动 | 步数、卡路里、睡眠跟踪 |
| 长期趋势 | 训练负荷、活动与训练的长期曲线 |

点开日记里的任意一条记录能看完整详情；主页屏幕视图把日常关键活动放在最上层，日常活动水平和睡眠习惯从这里看。

## 二、SuuntoPlus 小功能

SuuntoPlus 是一组可选的小功能，官方明确列出的包括：

- **Burner**：锻炼期间显示脂肪与碳水的燃烧速度；
- **Ghost Runner**：虚拟领跑者，用来练配速；
- **Variometer**：垂直速度跟踪，徒步与飞行场景用；
- **通勤标记**：把骑行、跑步、步行标为「通勤」，看相比机动车出行的 CO2e 排放差；
- **音乐控制**：运动中用腕表控制手机上的播放（音量、暂停、切歌）。

哪些能用取决于你的腕表型号与软件版本，以 app 与腕表里实际出现的为准。

## 三、绑定第三方运动服务

官方的伙伴服务网络有 200 多个，常见的有 Strava、TrainingPeaks、komoot、Runtastic 等。绑定步骤（官方 Suunto 7 文档的通用流程）：

1. 打开 Suunto App，进「个人资料 / Profile」标签；
2. 点「连接其他服务 / Connect to other services」；
3. 选要绑的服务，按屏幕提示授权。

完整伙伴列表见官方页面 [www.suunto.com/partners](https://www.suunto.com/partners/)。官方国行宣传里也提过 Keep、咕咚、悦跑圈这类国内应用的关联，实际可选列表以你 app 内「连接其他服务」页显示的为准。绑上后活动会自动同步到对应平台，不用手动导出。

不想等自动同步，也可以把单次锻炼手动导出成文件带走，见 [GPX与FIT文件导出导入.md](GPX与FIT文件导出导入.md)。

## 四、手机通知推到腕表

配对完成后，安卓用户按这个顺序把通知打通：

1. app 内点「腕表上的通知 / Notifications on watch」，把里面列出的权限逐个点「允许」（重点是**通知使用权**：在系统页里打开 Suunto App 的开关并确认弹窗）；
2. 腕表侧也要开：
   - Suunto 3 / 5 / 9、Spartan 系列：设置 → 通知，打开；
   - Ambit3：选项 → 连接 → 设置 → 通知 → 开；
   - Traverse：选项 → 连接 → 通知 → 开；
   - Suunto D5：常规 → 连接 → 通知，确认开启；
3. 在 app 的「应用」一节里挑哪些应用可以把通知推到腕表。

注意两点：Suunto 7 的通知走 Wear OS 自己的机制，不适用上面这套；如果手机上还装着老 Movescount 应用，它和 Suunto App 并存会造成连接与通知异常，官方建议卸掉。通知不生效的进一步排查放在 [常见问题与排查.md](常见问题与排查.md)。
