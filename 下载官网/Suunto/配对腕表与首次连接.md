# Suunto 腕表与手机配对及首次连接

## 一、配对前先检查三件事

1. 腕表蓝牙开着、飞行模式关着——官方手册明确：飞行模式开启时无法配对任何设备（腕表路径一般是 设置 → 连接 → 飞行模式）；
2. 腕表的「发现 / Discovery」开着（Suunto Ocean 的例子：设置 → 连接 → 发现），否则 app 搜不到它；
3. 腕表没有处在省电休眠状态——部分表型闲置几分钟后会进入省电模式并关闭蓝牙，按键唤醒再配。

## 二、蓝牙腕表的标准配对流程

适用于 Suunto 3 / 5 / 9 系列、Vertical、Race、Spartan 系列、Traverse、Ambit3，以及 D5、EON Core、EON Steel、Ocean 等潜水设备：

1. 手机打开 Suunto App，注册或登录 Suunto 账号；
2. 点 app 主界面**左上角的腕表图标**；
3. 点「配对 / PAIR」；
4. 腕表屏幕上会显示一组配对码，把它输入手机 app 完成确认。

配对成功后同步自动进行：手机与腕表的蓝牙都开着、彼此在有效范围内时，打开 app 就会自动同步数据；点 app 顶部的腕表图标可以查看同步进度。

app 还没装的话，先看 [下载与安装教程.md](下载与安装教程.md)（渠道表在它的第二节；也可以直接从 [Suunto 安装文件资源（夸克网盘）](https://pan.quark.cn/s/48faeea96f10) 转存）。

每次同步也会顺带更新腕表的 GPS 优化数据（官方兼容能力清单里列有「腕表 GPS 优化」一项），为的是腕表在户外定位更快。

心率带、踏频器、功率计这类传感器不走 app 配对——它们直接和腕表配，步骤见 [传感器与传感豆配对.md](传感器与传感豆配对.md)。

## 三、Suunto 7 要先走 Wear OS

Suunto 7 是 Wear OS 腕表，顺序和其他表相反：

1. 先用手机上的 **Wear OS by Google** 应用把腕表配对好；
2. 再打开 Suunto App，点左上角腕表图标，看到腕表后点「连接」；
3. 连接后跟着快速介绍走一遍，了解腕表基本操作。

## 四、Ambit / Ambit2 老款：走 SuuntoLink 数据线

Ambit（1、2）两代没有蓝牙通道，只能用电脑：

1. 在电脑上装 SuuntoLink（官方下载页：[www.suunto.com/Support/software-support/suuntolink/](https://www.suunto.com/Support/software-support/suuntolink/)）；
2. 用随附 USB 线把腕表连到电脑；
3. SuuntoLink 识别设备后会要求你提供 Suunto App 的账号凭据——账号必须先在手机 app 里注册好，**SuuntoLink 里不能注册新账号**；
4. 登录后数据自动同步进 app 的日记。

Ambit3 与 Traverse 系列既可以直接蓝牙连 app，也可以经 SuuntoLink 管理腕表设置、自定义运动模式和同步路线——Movescount 关闭后这条是老表唯一的设置通道。

## 五、换表与多台设备

- Suunto App 一次只保持一台设备连接。换新表：先在 app 里取消旧设备配对，再按第二节流程连新表（官方 Suunto 7 文档的口径）；
- 官方支持区有「在 Suunto App 中管理多个设备」的用法视频，多台轮换用的人可以照着操作；
- 配对码收不到：安卓手机上配对请求可能以**通知**形式出现在状态栏，重新发起配对后下拉通知栏看看；「勿扰模式」开着时腕表不出配对码，先关掉。

## 六、连上之后建议先做的事

1. 等第一次完整同步结束（历史锻炼、日常活动数据都会进来）；
2. 把常用路线或兴趣点存进腕表，见 [路线规划与户外地图.md](路线规划与户外地图.md)；
3. 到 app 的「腕表通知」里把权限补齐，让消息提醒能用，权限细节见 [常见问题与排查.md](常见问题与排查.md)；
4. 绑定 Strava 等第三方运动服务，见 [运动数据分析与第三方服务.md](运动数据分析与第三方服务.md)。
