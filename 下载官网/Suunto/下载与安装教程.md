## 一、先分清你要装的是哪一款

Suunto（颂拓）的运动腕表和潜水电脑都靠手机上的 **Suunto App** 管理：锻炼、潜水、日常活动数据同步到这里查看，路线规划、腕表设置调整、第三方服务绑定也在 app 里完成。安卓端存在两个发行版本，装之前先认包名：

| 版本 | 安卓包名 | 从哪来 |
| --- | --- | --- |
| 国际版 | `com.stt.android.suunto` | Google Play、国际官网 |
| 中国版 | `com.stt.android.suunto.china` | 中国官网下载页、国内应用商店 |

两个版本是各自独立发行的应用。本篇第四节核对的安装包就是中国版。

商店里的版本号可能滞后或超前于官网下载页，以页面当时显示为准。

## 三、系统要求

以官方页面现行列出的最低要求为准（后续可能调整，装之前可再核对）：

| 平台 | 要求 |
| --- | --- |
| Android | 8.0 或更高 |
| 蓝牙 | 4.0 或更高 |
| Google Play 服务 | 官方要求页在 Android 一栏同时列了「已安装 Google Play 服务」（中国官网页面也是如此列出） |
| Wear OS | 仅 Suunto 7 腕表需要（已安装 Wear OS by Google） |
| iOS / iPadOS | 16.0 或更高 |

网盘里这份 4.107.2 属于较早的构建，它对系统的实际门槛以你安装时手机弹出的提示为准。

## 四、网盘安装包核对与安装

本地收录的中国版安装包信息如下，安装前可以先核对一遍：

| 项目 | 值 |
| --- | --- |
| 版本 | 4.107.2 |
| 包名 | `com.stt.android.suunto.china` |
| 大小 | 143.07M |
| MD5 | `D15926C2FD84B1BB4A127E0A92122434` |
| 收录时间 | 2026-09-23 |

从 [Suunto 安装文件资源（夸克网盘）](https://pan.quark.cn/s/48faeea96f10) 转存后，把 APK 传到手机安装。MD5 在电脑上就能算（以 Windows 为例）：

```powershell
Get-FileHash -Algorithm MD5 "Suunto_v4.107.2.apk"
```

算出的串与上表一致（不区分大小写）说明文件完整。安卓侧安装步骤：

1. 把 APK 复制到手机存储；
2. 用文件管理器点开，系统会提示「允许安装未知来源应用」——按提示给本次安装放行（不同品牌的设置路径不同，一般在安装弹窗里直接点允许）；
3. 等安装完成，打开 app。

## 五、装完之后

1. 首次打开会要求注册或登录 Suunto 账号（手机号或邮箱，按 app 内提示走）；
2. 按屏幕引导给 app 基本权限（蓝牙、定位等，路线与运动记录依赖定位权限）；
3. 然后把腕表配对进来，流程见 [配对腕表与首次连接.md](配对腕表与首次连接.md)；
4. 装不上、打不开、提示签名冲突之类的状况，先看 [常见问题与排查.md](常见问题与排查.md)。
