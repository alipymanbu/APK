## 一、先记住：传感器不在 app 里配

心率带、速度/踏频传感豆、功率计、足部传感豆的配对入口在**腕表设置**里，不在 Suunto App 里。官方用户手册（以 Suunto Ocean 与 Spartan Ultra 为例）的流程：

1. 腕表设置 → 连接；
2. 选「配对传感器」，出传感器类型列表；
3. 滑动列表，点选要配的类型；
4. 按腕表屏幕指引完成（需要时翻传感豆自己的手册），短按中间按钮进入下一步。

两个前提：飞行模式开着时配不了任何设备，先关；部分传感豆在配对过程中会要求输入设置值（比如功率计的曲柄长度）。

潜水侧同理：Suunto Nautic 可以把心率传输带配到潜水电脑上，用于潜水期间监测心率，路径是 控制面板 → 连接 → 配对新设备 → 从列表选传感器。官方手册：[www.suunto.com/zh-chs/Support/Product-support/suunto_nautic/suunto_nautic/settings/bluetooth-connectivity/](https://www.suunto.com/zh-chs/Support/Product-support/suunto_nautic/suunto_nautic/settings/bluetooth-connectivity/)

## 二、支持哪些类型

以官方手册列出的为例：

| 类型 | 用途 |
| --- | --- |
| 心率（传输带） | 锻炼或潜水时记录心率 |
| 自行车（速度/踏频） | 骑行数据 |
| 功率（功率计） | 骑行功率 |
| 足部（步频传感豆） | 室内跑的配速与距离 |
| 罐压（Tank POD，潜水设备） | 气瓶压力 |

配好之后，只要你在腕表上选择用到该类型传感器的运动模式，腕表就自动去搜它。

## 三、管理与移除

已配对设备列表在腕表 设置 → 连接 → 已配对的设备；要解除某只传感器，选中它点「忘记」。腕表与手机那条连接是另一回事，流程见 [配对腕表与首次连接.md](配对腕表与首次连接.md)。

## 四、三类校准入口

| 传感器 | 校准怎么做 |
| --- | --- |
| 自行车传感豆 | 在腕表里设车轮周长（毫米）：设置 → 连接 → 已配对的设备 → 选 Bike POD → 选新周长；换轮子（周长变了）后要重设 |
| 足部传感豆 | 首次配对后腕表用 GPS 自动校准：选一个用足部传感豆、GPS 精度设为「最佳」的运动模式，平整路面匀速跑至少 15 分钟；之后有 GPS 速度时腕表会自动重校 |
| 功率计 | 从运动模式选项里发起：选一个用功率计的运动模式 → 模式选项 → 校准功率 POD，按腕表提示做；建议定期重校 |

## 五、搜不到传感器时

按顺序过：确认传感豆进入配对/广播状态（各品牌做法见其手册）、腕表飞行模式关、蓝牙发现开、离其他正在连蓝牙的设备远一点。还不行就翻 [常见问题与排查.md](常见问题与排查.md)。
