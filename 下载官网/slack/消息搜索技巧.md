## 一、从哪进搜索

安卓端：点屏幕底部的**搜索图标** → 点搜索框输入 → 回车或点建议列表里的结果 → 需要再收窄就点「更多筛选器」。

先说一个前提：**免费版工作区只能搜到最近 90 天的消息和文件**，更早的内容搜不出来（详见 [免费版功能限制.md](免费版功能限制.md)）。参数用得再熟，也捞不出被隐藏的那部分。

## 二、参数速查表

搜索框里直接拼这些前缀，多个参数可以叠加：

| 想怎么找 | 写法 | 例子 |
|---|---|---|
| 精确短语 | 给词加引号 | `"季度报告"` |
| 排除某个词 | 词前加 `-` | `季度 -草稿` |
| 只在某个频道 | `in:` + 频道名 | `季度报告 in:#team-marketing` |
| 某人发的 | `from:` + 显示名 | `季度报告 from:@张三` |
| 带某表情回复的 | `has:` + 表情码 | `设计稿 has::eyes:` |
| 我加过表情的 | `hasmy:` + 表情码 | `排期 hasmy::eyes:` |
| 我存过的 | `is:saved` | `报价单 is:saved` |
| 被置顶的 | `has:pin` | `规范 has:pin` |
| 某天之前/之后 | `before:` `after:` `on:` | `合同 before:2026-09-01` |
| 某月/某年 | `during:` | `复盘 during:august` |
| 只在线程里的 | `is:thread` | `方案 is:thread` |
| 和某人相关的 | `with:` + 显示名 | `排期 with:@张三` |
| 某人建的画板 | `creator:` + 显示名 | `白板 creator:@张三` |
| 排除某频道 | `-in:` | `报告 -in:#测试` |

**叠加才出效果**，比如 `季度报告 in:#team-marketing from:@张三` 一条就把范围缩到某个人在某个频道发的内容。

## 三、结果页再筛一把

搜出来太多时，结果页的筛选器能继续收窄：

- 按**类型**分：消息、文件、频道、成员、画板；
- 按**时间**分：最近一周、一个月、自定义区间；
- 按**频道**分：只看来自某个频道的结果。

文件类结果尤其好用 —— 你只记得文件名不记得在哪发的，直接搜文件名再按类型筛「文件」。

## 四、搜不到的时候先查这三件事

1. **是不是超出 90 天了** —— 免费版的硬限制，不是搜索坏了；
2. **词拼对没有** —— 中英文输入法、全半角引号都会影响精确匹配；
3. **权限够不够** —— 私人频道里的内容，你不在那个频道就搜不出来，这是设计如此。

日常找消息的高频场景就这些；要让重要消息主动找到你，靠的是通知而不是搜索 —— 见 [通知设置与问题排查.md](通知设置与问题排查.md)。
