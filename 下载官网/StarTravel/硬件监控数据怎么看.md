## 一、数据在哪看

打开 StarTravel 首页即是 CPU 管理界面，实时刷新各项硬件数值；更完整的分类与开关在底部「工具」页。以下各项都无需授权，装好就能看。

## 二、各项指标怎么读

| 指标 | 你该关注什么 | 数值异常时的动作 |
| --- | --- | --- |
| CPU 核心频率 | 各核心当前运行速度，负载上来时频率会随之拉高 | 长期顶在最高频且机身发烫 → 关掉后台高负载应用 |
| CPU / 机身温度 | 结合温度曲线看趋势，而非单个瞬时值 | 曲线持续上行 → 降负载或开启高温降亮 |
| GPU 占用 | 游戏与视频场景的主要负担来源 | 玩游戏时长期满载 → 调低游戏画质档位 |
| 内存占用 | 剩余内存越少，切后台越容易被杀 | 占用过高 → 用一键释放内存清理后台 |
| 电池信息与充电功率 | 充电时长、耗电速率、温度变化曲线 | 充电时温度曲线过陡 → 换功率更低的充电器或取下保护壳 |
| 功耗统计 | 一段使用时间内的耗电分布 | 某个应用占比异常高 → 到系统设置里限制它 |
| 帧率（FPS） | 高负载场景下的帧率波动，比「平均帧」更能反映卡顿 | 频繁掉帧 → 配合插帧与性能模式调整，见 [全局插帧开启与发热处理.md](全局插帧开启与发热处理.md) |

## 三、两个常见用法

- **判断发热该不该降负载**：看温度曲线是否持续上行，比摸机身准。曲线抬头而你在刷视频这类轻负载场景，说明有后台应用在偷偷吃资源，用清缓存、清后台处理。
- **判断游戏卡顿的来源**：同时盯帧率与 GPU 占用 —— 帧率掉而 GPU 没满载，瓶颈多半在 CPU 或温度降频；GPU 满载则是画质档位超了。

## 四、让数据一直在手边

工具页里有「状态栏显秒」等显示类开关，可把关键信息固定在状态栏上，不必反复切回 App 查看。这些开关改动的是系统显示设置，若点下无效，按 [Shizuku授权激活教程.md](Shizuku授权激活教程.md) 处理授权。

数值长期异常却找不到原因，转 [常见问题与排查.md](常见问题与排查.md)。
