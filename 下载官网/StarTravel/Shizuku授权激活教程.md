# StarTravel 的 Shizuku 授权怎么激活

## 一、为什么需要这一步

StarTravel 里那批会改动系统参数的功能（全局插帧、Monster+ 性能模式、刷新率调节、触控调校等），需要借助 Shizuku 取得调试权限才能生效，**不需要 Root、不需要解锁 Bootloader**，也就不会因此失去保修。

判断当前到底缺什么很直接：在工具页点某个高级功能的开关，界面毫无反应或提示需要授权 → 先按本文把 Shizuku 装好、启动、授权，再回来点。

## 二、准备：装 Shizuku 并打开开发者选项

Shizuku 是独立应用，需要另外下载安装（各主流应用市场与 [GitHub 官方仓库](https://github.com/RikkaApps/Shizuku) 都有）。

1. 手机「设置 → 关于手机」，连续点击「版本号」7 次，提示已进入开发者模式；
2. 返回设置主页面，找到「开发者选项」（部分机型藏在「更多设置」里）；
3. 开启「USB 调试」与「无线调试」两个开关。

## 三、用无线调试配对启动（安卓 11 及以上，全程不用电脑）

1. 打开 Shizuku，首页点「配对」；
2. 按提示跳到开发者选项，点「无线调试」进入其详情页；
3. 点「使用配对码配对设备」，记下弹出的 6 位配对码；
4. 下拉通知栏，在 Shizuku 的配对输入框里填入该配对码，确认；
5. 提示「配对成功、服务已启动」即完成，Shizuku 首页会显示「正在运行」。

几个机型差异（照做能省掉大半配对失败）：

| 机型 / 系统 | 额外要做的 |
| --- | --- |
| 小米 / MIUI | 通知样式改成「原生样式」，否则通知栏里没有配对码输入框；开发者选项里把「USB 调试（安全设置）」也打开 |
| OPPO / realme / 一加（ColorOS） | 开发者选项底部打开「禁止权限监控」 |
| 所有机型 | 关掉省电模式，允许 Shizuku 在后台运行，别让系统把它杀掉 |

安卓 10 及以下没有无线调试，需改用电脑 ADB 命令启动，Shizuku 官方页有对应命令。

## 四、给 StarTravel 授权

1. 保持 Shizuku 显示「正在运行」，打开 StarTravel；
2. 触发任一高级功能时会弹出 Shizuku 授权请求，点「允许」；
3. 回到 Shizuku 的「已授权应用」列表，能看 StarTravel 即已生效，之后不必重复授权。

## 五、重启手机之后

手机重启会把 Shizuku 服务停掉，**已授权的应用不用再授权一遍**，你只要重新走一遍第三节的「启动」（配对过的话通常只需点一下启动），StarTravel 那边就恢复了。

## 六、配对或启动失败时

- 页面提示找不到配对服务 → 确认「无线调试」开关是开着的、且停在它的详情页而不是总开关页；
- 配对码输入后一直转圈 → 系统在后台拦截，关掉省电模式、允许 Shizuku 后台运行后重试；
- 反复失败 → 换电脑 ADB 方式启动一次，Shizuku 官方文档给了命令。

处理完仍无效的具体表现，对照 [常见问题与排查.md](常见问题与排查.md)。
