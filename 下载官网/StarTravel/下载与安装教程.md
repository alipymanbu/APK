## 一、先确认手里这份包对不对

你下载的版本信息应当与下表一致，装之前花一分钟核对，能挡掉大半「装不上 / 装完打不开」的问题。

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.4-1 |
| 包名 | com.startravel.app |
| 安装包大小 | 4.76M |
| MD5 | `D539B75D3FD3A5CF14471BB9235281CC` |
| 平台 | 安卓 |

- 包名决定了它在系统里的身份：装完后桌面图标下的名字、设置里「应用信息」中看到的都是它。同名的应用未必是同一个，认包名最稳。
- MD5 用来判断文件在传输中有没有损坏。你用任意一款校验工具算出的 MD5 与上表**逐字符一致**，这份包就是完整的；不一致就重新下载一次。
- 系统版本要求方面，各下载页没有给出统一的最低安卓版本数字，安装时若弹出「安装包与系统不兼容」提示，以手机上的实际提示为准。

## 二、下载安装包

打开 [StarTravel 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ab03be007f5d)，找到应用文件夹，里面是 `StarTravel_v1.0.4-1.apk` 与一个说明 txt。

1. 在网盘页面把 APK 转存到自己的账号；
2. 手机上打开夸克，从「我的文件」里点这个 APK，选下载到本机；
3. 也可以先在电脑上下载，再用数据线或局域网传到手机。

网盘里的包就是上表那一版，与网上各下载站标称的版本一致。

## 三、安装

1. 点击下载好的 APK，系统会弹「禁止安装来自此来源的应用」——这是「未知来源安装」的常规拦截，不是病毒提示。
2. 按提示进入「安装未知应用」开关，给你的浏览器或文件管理器打开该权限，返回继续安装。
3. 安装完成后桌面会出现图标，直接点开即可。

应用体积只有 4.76M，装完占用空间很小，低配机型也不必担心存储压力。

## 四、首次打开：先看它要不要授权

第一次进入会看到首页的 CPU 监控数据与底部的「工具」入口。**看数据、清缓存这类基础功能直接就能用**；但全局插帧、性能模式、刷新率调节这类会改动系统参数的功能，需要先装好 Shizuku 并授权，否则开关点下去没有反应。

具体授权步骤（含无线调试配对、机型差异、重启后的处理）见 [Shizuku授权激活教程.md](Shizuku授权激活教程.md)。

## 五、装完打不开怎么办

安装失败、闪退、图标点开白屏，先看 [常见问题与排查.md](常见问题与排查.md) 里的对应条目，多数情况能在两分钟内定位。
