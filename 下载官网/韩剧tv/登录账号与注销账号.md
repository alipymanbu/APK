## 一、不登录能用到什么程度

按官方隐私政策的说法，**不注册、不登录也能浏览、搜索、播放**——看剧本身不拦。登录解决的是这几件事：

- 观看进度、收藏与追剧列表跨设备同步（换手机不丢）；
- 参与评论、弹幕等互动功能；
- 会员权益的领取与生效（若你开通了）。

所以轻度观看可以先不登录；要长期追剧、换过手机，再登录更省心。

## 二、登录与绑定手机号

1. 打开应用，进「我的」页面，选登录入口，按提示用手机号完成登录；
2. 如果你平时用第三方账号（微信等）登录，想和手机号互通，在「我的 → 设置 → 账号安全中心」里找**绑定手机号**，按弹窗提示依次确认即可完成一键绑定；
3. 绑定后，两个入口都能进同一个账号，观看记录不会分家。

一个手机号通常只对应一个账号，绑定前想清楚要以哪个为准。

## 三、注销账号的入口

官方隐私政策写明的路径是：

```
我的 → 设置 → 账号安全中心 → 注销账号
```

按页面流程提交即可。若界面上找不到该入口（个别版本、或账号状态不满足条件），用《"韩小圈"用户服务协议》里留的官方联系邮箱 `hanjutv@greatyun.com` 发申请，写清你的用户 ID、绑定手机号和注销理由，等工作人员处理。

## 四、注销前必须知道的四件事

1. **不可恢复**：注销是单向操作，官方明确提示注销后无法恢复，账号内的观看记录、收藏、追剧列表都会清掉。
2. **权益会丢**：已充值的会员时长、购买记录等一并作废，且无法转移或折现。注销前先把会员用完，或先别注销。
3. **责任不免除**：注销成功后，你仍需对注销前使用期间的行为负责（用户服务协议的约定）。
4. **只注销你自己的**：流程只允许账号本人申请，且需先把该账号下的服务（如自动续费）处理干净。

只是想换台手机接着看——**不用注销**，在新设备上登录同一账号即可，进度和追剧列表都会跟过来（见 [追剧提醒与离线缓存.md](追剧提醒与离线缓存.md)）。

## 五、常见疑问

| 疑问 | 回答 |
| --- | --- |
| 换手机了记录还在吗 | 已登录账号的观看进度、追剧列表存在云端，新设备登录同账号即可同步 |
| 卸载重装要注销吗 | 不用。卸载重装后重新登录即可；本地缓存的剧集会随卸载清掉，需要重新缓存 |
| 忘记绑的手机号 | 走第三方账号登录入口进「账号安全中心」查看绑定信息，或用官方联系邮箱求助 |
| 注销后能重新注册吗 | 能重新注册新账号，但原账号的数据找不回来 |

换机、重装、清数据这类操作对追剧列表的影响，见 [追剧提醒与离线缓存.md](追剧提醒与离线缓存.md)；应用本身装不上、打不开，见 [下载与安装教程.md](下载与安装教程.md) 与 [常见问题与解决方法.md](常见问题与解决方法.md)。
