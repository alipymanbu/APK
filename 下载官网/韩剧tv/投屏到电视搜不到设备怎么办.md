## 一、正常投屏的步骤

投屏的前提只有两条：**手机和电视连的是同一个 Wi-Fi**（或同一个手机热点），**电视那边有接收投屏的能力**。满足之后：

1. 打开韩小圈，搜到或点开你要看的剧，进入播放页；
2. 点播放器**右上角的「TV」投屏按钮**；
3. 应用会搜索同一网络下的设备，列表里点你的电视名称；
4. 手机上出现「正在播放中」一类提示，就说明画面已经交给电视了——此时手机可以退出应用去干别的。

部分品牌电视（如三星部分型号）会要求在电视上输入一个 PIN 码确认，照屏幕提示输入即可。

## 二、搜不到电视，先查这三项

按命中率从高到低排：

| 检查项 | 怎么做 |
| --- | --- |
| 是否同一个网络 | 手机连的 Wi-Fi 和电视连的 Wi-Fi 要来自**同一个路由器**；一个走 Wi-Fi、一个走手机流量、或连了不同路由器的访客网络，都搜不到 |
| 电视有没有投屏接收能力 | 老电视或部分电视盒子不带接收功能。到电视自带的应用商店搜「投屏」，装一个投屏接收应用（如乐播投屏，电视端搜索字母 `LBTP`）就能让电视具备接收能力 |
| 是否在同一网段的隔离设置 | 路由器开了「访客网络」「AP 隔离」会把设备互相隔开，关掉再试 |

三项都排除了还搜不到，重启一次路由器和手机再重复第一节的步骤。

## 三、投上了但电视提示加载失败 / 播放错误

画面交出去了、电视却报错，通常是电视端播放器解不了这个视频流：

1. 在电视端装的投屏应用里找**播放器切换**选项（如乐播投屏设置里可切换播放器内核），换一个再试；
2. 换一集、换一部剧试——只有一部剧失败，多半是那一条线路的问题，回手机端在播放页换个清晰度或线路再投（见 [播放卡顿与线路切换.md](播放卡顿与线路切换.md)）；
3. 全部剧都投不上、电视端一直转圈：确认电视与手机在同一 Wi-Fi 后，把投屏应用升到最新版。

## 四、投屏总是断、分成很多段

这类问题多与版本有关，处理顺序：

1. 确认手机上的韩小圈是最新版（旧版本修过投屏分段的问题）；
2. 投屏时手机别锁屏、别清理后台，部分手机的省电策略会掐断投屏连接；
3. 换一部剧验证：只有某一部断，是那条线路不稳，切清晰度或线路再投。

投屏过程中的卡顿属于播放侧问题，排查思路与 [播放卡顿与线路切换.md](播放卡顿与线路切换.md) 相同；应用本身打不开、闪退则见 [常见问题与解决方法.md](常见问题与解决方法.md)。
