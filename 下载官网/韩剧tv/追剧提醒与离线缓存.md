## 一、把剧加进追剧列表

1. 在剧集详情页点**「追剧 / 加入追剧」**一类按钮（不同版本叫法略有差别）；
2. 加完之后，这部剧的新集更新会出现在首页的「我的追剧」入口里，进去就能看到哪几部更新了；
3. 没看完的剧也会留在列表里，点开直接续播——应用会记住你上次看到第几分钟，这一步不需要你做任何设置。

追剧列表与观看进度绑定在账号上，**登录后换设备也跟着走**；没登录就只存在本机，卸载即丢（登录相关见 [登录账号与注销账号.md](登录账号与注销账号.md)）。

## 二、找剧的几个入口

- **搜索**：首页右上角放大镜，或底部「发现」页顶部的搜索框，输剧名/演员名都行；
- **榜单**：首页的各类排行榜（热播、高分等），不知道看什么时按榜单挑；
- **分类筛选**：按类型、年份等条件过滤，适合有明确偏好的时候用。

## 三、缓存（离线下载）剧集

通勤、飞行模式前想离线看，用缓存功能：

1. 进入剧集详情页或播放页，找**「缓存 / 下载」**按钮；
2. 选清晰度和要下的集数，任务会在缓存列表里显示进度；
3. 下完后在「我的 → 缓存」里找到，无网络也能播。

三个实际注意点：

- **存储空间**：每集几十 MB 到上百 MB 不等，缓存前确认手机剩余空间够（本地安装包本身就有 100.27M）；
- **权限**：首次缓存会要存储权限，不给就存不下来；
- **部分剧集的缓存权限与会员挂钩**：有的剧提示需要会员才能缓存，按页面提示操作即可，是否可缓存以当时界面显示为准。

## 四、查看与删除缓存

缓存列表与清理入口都在应用里，不用翻手机文件管理器：

- **查看/播放**：「我的 → 离线缓存」，列表里点任意一集直接离线播放；列表可切换「全部 / 正在缓存」看下载进度。
- **删除单集**：「离线缓存」页右上角**「编辑」**，勾选要删的集数批量移除。
- **清出空间**：「我的 → 设置 → **存储空间** → 清理缓存」——清的是播放产生的临时文件，不动你手动缓存的剧集、不影响登录与追剧列表；要连缓存剧集一起清，走「离线缓存」的编辑删除。

手机「设置 → 应用」里的「清除数据」比这两者都狠（会退出登录），只在应用自身清理无效时用，见 [常见问题与解决方法.md](常见问题与解决方法.md) 第二节。

## 五、会员与广告的实际情况

应用内提供「V享会员」一类的付费订阅，官方列出的权益包括：蓝光 1080P 画质、极速缓存、去片头广告、免广告投屏、专属弹幕样式与会员标识。需要留意的：

- **基础观看免费**：不开会员也能看大部分内容，部分剧集/画质/缓存权限会要求会员；
- **价格与套餐以应用内显示为准**：第三方渠道代充价格五花八门，账号安全风险自担，建议只在应用内购买；
- 开通前先看清自动续费条款，不需要时在「我的 → 设置」或系统订阅管理里关闭续费；
- **已开通了自动续费想关掉**，要在**付款那一侧**操作，应用内关不掉扣款：支付宝走「设置 → 支付设置 → 免密支付/自动扣款」、微信走「我 → 服务 → 钱包 → 支付设置 → 扣费服务」、iOS 走「设置 → Apple ID → 订阅」，找到对应项目取消；关闭后当期已付的费用不退，次期起不再扣（路径以各支付平台当前界面为准）。

## 六、追剧相关问题速查

| 疑问 | 处理 |
| --- | --- |
| 更新了但列表没提示 | 进详情页手动刷新；确认已把该剧加入追剧列表 |
| 续播进度不准 | 确认已登录账号；进度在云端，本地清缓存不影响（见 [登录账号与注销账号.md](登录账号与注销账号.md)） |
| 缓存的剧播不了 | 到「我的 → 缓存」检查是否下载完成；没下完重新下 |
| 缓存的剧画面卡 | 属于播放侧问题，见 [播放卡顿与线路切换.md](播放卡顿与线路切换.md) |
| 想在电视上看缓存的剧 | 用投屏，见 [投屏到电视搜不到设备怎么办.md](投屏到电视搜不到设备怎么办.md) |
| 缓存太多手机满了 | 见本篇第四节删除缓存 |
| 想调倍速/关弹幕 | 见 [倍速播放与弹幕设置.md](倍速播放与弹幕设置.md) |
