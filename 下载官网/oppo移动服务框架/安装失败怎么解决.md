## 一、先做三件通用检查

不管报什么错，先把这三步做完，能排掉一大半情况：

1. **文件完整吗** —— 从 [OPPO移动服务框架 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ec0b610f1d4d) 拿到的 APK 应约 24.60 MB，MD5 为 `4EC2576D1DA97B85447FE898519433F2`；对不上就是没下完或下错了，重新下载。
2. **安装权限开了吗** —— 非商店来源的 APK 需要先给浏览器/文件管理器「安装外部来源应用」权限，各系统版本的路径见 [下载与安装教程.md](下载与安装教程.md) 第四节。
3. **存储空间够吗** —— 安装时需要解压空间，通常要有安装包 1~2 倍的余量；空间不足会直接失败，先清理缓存再试。

## 二、按报错现象排查

| 现象 | 常见原因 | 怎么处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | 文件下载不完整/已损坏；或包与系统版本不兼容 | 重新下载并核对大小与 MD5；仍报错说明这个包与你的系统不匹配，换一个版本 |
| 「本机版本高于下载版本」 | 手机里已装的版本更新，安卓不允许覆盖降级 | 见下方第三节 |
| 「应用未安装」 | 签名冲突：系统里已有同包名但签名不同的版本 | 卸载现有版本再装（系统预装组件用下方 adb 命令处理） |
| 点击后一闪、没有安装界面 | 安装来源权限没开，或被安全组件拦截 | 开权限；有「纯净模式」类设置的先临时关闭 |
| `INSTALL_FAILED_NO_MATCHING_ABIS` | 安装包的 CPU 架构与手机不匹配 | 换与你机型架构一致的包，常见于拿错海外/变体包 |
| `INSTALL_FAILED_INSUFFICIENT_STORAGE` | 空间不足 | 清缓存、删掉用不到的安装包与大文件后重试 |

## 三、降级安装：「本机版本高于下载版本」

安卓默认禁止安装比系统里已装版本更旧的包。如果你确实要装网盘里这一份（版本 `2.2.5_a16ed3a_250529`），而手机里的版本更新，两条路：

- **普通用户**：在 设置 > 应用管理 里找到「移动服务」，点「卸载更新」（相当于退回出厂版本），再点 APK 安装；
- **会用 adb 的**：

```bash
adb install -r -d com.heytap.htms.apk
```

`-d` 允许降级。多数情况下你其实不需要降级 —— 手机里版本更新、提示也已消失的话，装回旧版反而多此一举，看 [可以卸载吗.md](可以卸载吗.md) 判断你到底需不需要动它。

## 四、用 adb 装或修（进阶）

系统组件类的包有时会拒绝普通安装，用 adb 更直接：

```bash
# 覆盖安装并保留数据
adb install -r com.heytap.htms.apk

# 降级安装
adb install -r -d com.heytap.htms.apk

# 手机里有记录但被卸载/禁用过，直接恢复
adb shell pm install-existing com.heytap.htms
```

> `adb install` 报 `INSTALL_FAILED_VERSION_DOWNGRADE` 同样是第三节的降级问题；`INSTALL_FAILED_UPDATE_INCOMPATIBLE` 则是签名不同，只能先卸掉旧的。

## 五、都试完还是不行

- 换一台同型号手机验证：都装不上说明包有问题，找另一份来源的安装包（可用 [下载与安装教程.md](下载与安装教程.md) 里的 MD5 核对）；只有一台装不上则多半是系统兼容问题；
- 弹的是「游戏/应用提示需要安装移动服务框架」而不是安装报错 —— 那是另一类问题，见 [游戏提示需要安装怎么办.md](游戏提示需要安装怎么办.md)。
