## 一、为什么游戏会要这个东西

很多游戏有「OPPO 渠道服」，用的是欢太体系的账号登录与支付 —— 这套能力就由 `com.heytap.htms`（OPPO移动服务框架）在手机上提供。出现提示的典型场景：

- 手机是 OPPO / 一加 / realme，但这个组件被清理软件删了或停用了；
- 其他品牌手机装了 OPPO 渠道的游戏：手机上从来没有过这个组件，游戏一启动发现缺依赖就弹提示；
- 手机里有，但版本比游戏要求的旧，提示你更新。

注意：**这不是中病毒，也不是游戏本身坏了**，缺的是一个基础组件。解决办法就是把这个框架装上，与游戏是不是从商店下载的无关。

## 二、标准处理顺序

1. **拿到安装包** —— 从 [OPPO移动服务框架 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ec0b610f1d4d) 下载，核对大小约 24.60 MB；
2. **开安装权限并安装** —— 非 OPPO 手机同样可以装，步骤见 [下载与安装教程.md](下载与安装教程.md) 第四节；安装报错看 [安装失败怎么解决.md](安装失败怎么解决.md)；
3. **重启游戏** —— 彻底退出（从最近任务里划掉）再进，不要只是切后台；
4. **保持联网** —— 账号登录、支付这些能力要联网校验，装完断网仍可能提示失败。

多数情况走到第 3 步提示就消失了。

## 三、装了还是提示？按这三点查

| 检查点 | 说明 |
| --- | --- |
| 装的版本对不对 | 公开渠道有带 `_OS15Oversea` 之类后缀的海外变体；国内行货手机、国服游戏优先用不带海外后缀的国内版 |
| 装成功没有 | 到 设置 > 应用管理 搜 `com.heytap.htms`，确认版本号是你刚装的那个 |
| 是不是又被删了 | 部分清理工具会把这个无图标组件当「冗余」清掉，把它加入白名单（见 [可以卸载吗.md](可以卸载吗.md)） |

另外，个别游戏要求的是**它内置的更新版本**，会自己拉一个更新 —— 装完基础包后按游戏内提示走完更新即可，以游戏当时页面显示为准。

## 四、顺带：账号登录与换绑手机号

框架只是把账号能力接上，账号本身在欢太那边管理：

- **登录**：游戏里用 OPPO / 欢太账号登录即可，框架在后台完成校验；
- **换绑安全手机**：在浏览器打开欢太账号中心 `id.heytap.com` 登录 → 找到「安全手机」点修改 → 按页面提示选择验证方式（原手机/短信等）→ 验证通过后填新号码完成绑定。换绑成功后，回到游戏重新登录一次。

登录遇到验证码收不到、原号码已停用这类问题，走该页面提供的其他验证方式或联系官方客服，本篇无法替代官方的身份核验流程。
