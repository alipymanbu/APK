## 一、这是个什么应用

Reex 是安卓端的本地视频播放器，由开发者 lntls 维护，源码与历史发行版公开托管在 Gitee（[gitee.com/lntls/reex](https://gitee.com/lntls/reex)）。应用不带广告与弹窗，装完只需要存储权限就能扫视频、播本地文件；网络共享（SMB / FTP / WebDAV）与在线流地址播放是它的进阶玩法。

下面这份参数是**当前手头这份安装包**的事实，网上搜到的官方最新版未必与它同一个版本，涉及版本号、包名、体积一律以此为准：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.8.9 |
| 包名 | `xyz.re.player.ex` |
| 安装包大小 | 21.07M |
| MD5 | `D9E8F6878CCB3E4B2C95B861C171C71A` |
| 系统要求 | 安卓 5.2 以上（以安装时的提示为准） |

## 二、安装包从哪里拿

两条路，任选其一：

1. **网盘**：[Reex 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f6e8601148a0) —— 打开后转存到自己的网盘，再在手机上下载 `reex_v1.8.9.apk`（或下载到电脑后传到手机）。
2. **官方发行页**：[gitee.com/lntls/reex/releases](https://gitee.com/lntls/reex/releases/) —— 官方每个版本会按 CPU 架构放出多个 APK，页面往下翻能看到各版本的附件。
3. **酷安**：另有第三方文章提到该应用也上架了酷安，在酷安里搜 `Reex` 看有没有结果即可（渠道是否仍在、版本是否同步，以商店当时显示为准）。

### 架构怎么选（官方发行页才有得选）

官方发行页的附件按架构命名，截至 v1.8.9 有三种：

| 附件名 | 适用设备 |
| --- | --- |
| `arm64-v8a-release-*.apk` | 绝大多数近十年的手机，拿不准就选它 |
| `armeabi-v7a-release-*.apk` | 老旧机型、32 位系统 |
| `x86_64-release-*.apk` | 少数 x86 处理器设备与电脑上的安卓模拟器 |

判断不准时的笨办法：先装 `arm64-v8a`，安装时若提示与处理器不兼容，再换 `armeabi-v7a` 装一次。网盘里那份是通用包，不用做这个选择。

## 三、安装步骤

1. 在手机上把 APK 下载到本地（或从电脑传过去）。
2. 用文件管理器点开这个 `.apk`。首次安装时系统会要求你允许「安装未知应用」—— 去设置里给文件管理器开这个权限，回到安装界面继续。
3. 国产手机（小米、OPPO、vivo、华为等）安装时可能弹「风险应用」「纯净模式」一类的拦截提示。Reex 没有上架这些厂商自带的应用商店，独立开发者应用被这样提醒很常见；提示不等于包本身有问题，看清来源后由你自己决定是否继续。
4. 装完首次打开，会申请「照片和文件」（存储）权限 —— 点允许。不允许的话列表里扫不出任何视频。

> 关于权限的边界：Reex 开发者声明应用不收集、不上传使用者数据，实际运行也只需要文件读取相关的权限。你可以在系统「应用信息 → 权限」里随时核对它拿到了什么。

## 四、验证装对了

到 系统设置 → 应用管理 → Reex → 应用信息，看版本号是否为 `1.8.9`、包名是否为 `xyz.re.player.ex`。对得上，就与上面表格里的那份安装包一致；接下来就可以按 [本地视频播放与倍速手势设置.md](本地视频播放与倍速手势设置.md) 开始把视频加进列表了。
