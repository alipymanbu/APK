## 一、先让列表里出现你的视频

打开 Reex 后，首页左上角有刷新按钮，列表按文件夹展示设备里的视频。两种方式把视频加进来：

- **自动扫描**：点刷新，应用会按目录把存储里的视频读出来，按文件夹归类（手机拍照、微信保存、QQ 保存等各自成组）。首次使用走这条路最快。
- **手动添加目录**：不想全盘扫，就进设置把自动扫描关掉，改成手动添加指定文件夹。两个附带的好处：
  - 不想被看到的视频，所在目录不添加就不会出现在列表里（隐私场景常用）；
  - 设置 → 常规 → 其他里可以按视频体积做过滤 —— 比如你的片子基本都在 100M 以上，就填 100M，小体积的零碎文件（广告片段、缓存）会被挡在列表外。

添加完，首页按目录分组，点开目录再点文件就开播。

## 二、播放界面里能干什么

播放中点一下屏幕调出控制条，「更多」里藏着下面这些：

| 操作 | 说明 |
| --- | --- |
| 截图 | 当前画面直接存到相册，不用再拿另一台设备拍屏 |
| 切换同目录视频 | 不用退回列表，直接跳到同文件夹的上一个/下一个 |
| 音轨 / 视频轨切换 | 多音轨的 MKV、多视角文件可以现场换 |
| 画面参数 | 亮度、对比度、色相、饱和度、伽马值都能调 |
| 镜像翻转 | 左右翻转（镜像）、上下翻转 |
| 缩放平移 | 放大画面并拖动位置，字幕挡脸时也能用 |
| 画中画 | 弹出小窗，切到别的应用继续看（有用户反馈小窗状态下回不到应用主页，属已知体验问题） |
| 后台播放 | 关屏、切应用后声音继续（需在设置里开启） |
| 定时暂停 | 睡前挂机看，到点自己停 |

手势方面，左右滑动定位进度、上下滑动调音量/亮度是常规操作；手势的灵敏度与具体映射在设置的「手势」里改。

## 三、长按倍速播放

这是 Reex 最常用的一个功能：

1. 进 设置 → 手势，开启「长按」相关选项；
2. 播放中按住屏幕不放，画面会进入加速播放，松手回到原速；
3. 加速档位在设置里自定义，长按手势下最高可调到 **10 倍**。

刷剧跳过注水段落、拖进度条找镜头时，长按比反复点进度条省事得多。除了长按，播放界面里也能直接选一个固定倍速持续播放；**有第三方资料称手动倍速的可调范围宽至 0.01~100 倍** —— 以你设备上实际可调的档位为准，长按手势的上限则是 10 倍（多个来源一致）。

## 四、A-B 循环：把一段锁起来反复看

「更多」里的 A-B 循环（分段重复）适合学动作、抠台词、反复听某一句：

1. 播到起点，设 A；
2. 播到终点，设 B；
3. 之后播放到 B 会自动跳回 A，循环到你取消为止。

配合倍速看，片段学习的效率更高。看完记得把循环点清掉，否则下次打开还在原地打转。

## 五、播放记录与续播

Reex 会记住你上次看到的位置，重新打开同一文件可以直接续播；播放记录在首页可以查看，方便回头找没看完的片子。记录只存在本机，清应用数据会一并清掉。

播放记录没有做云端同步（未见任何官方入口），换设备或重装后要重新看一遍，属正常。装完应用后若列表为空或记录丢失，先回 [下载与安装教程.md](下载与安装教程.md) 核对存储权限是否给了。

## 六、自定义按钮与遥控电视

- **自定义按钮**：v1.8.0 起支持（官方更新说明）。社区里常见的用法是把「精确跳转 N 秒」绑到按钮上 —— 例如 `seek 87 exact` 直接跳过开头 87 秒，前面留几秒反应时间；快进的步长也可以自定义，不受默认档位限制（用户反馈，出自小众软件论坛的讨论帖）。设置里按钮的具体配置项以应用内为准。
- **遥控电视端**：v1.8.3 的更新说明写了「（实验性）增加遥控功能，用于控制电视端」。标注为实验性，能控什么、怎么配对以应用内实际表现为准，不保证所有机型可用。
