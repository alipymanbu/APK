# Reex 局域网 SMB 与 WebDAV 网络共享播放

## 一、先看你要连的是哪类东西

Reex 的「网络共享」入口支持三种协议，按你手头的东西对号入座：

| 你想要的 | 用的协议 | 典型场景 |
| --- | --- | --- |
| 播电脑/NAS 上共享的文件夹 | SMB | Windows 右键共享一个文件夹，手机直连 |
| 播自建服务、网盘挂载出来的目录 | WebDAV | Alist 等工具把网盘挂成 WebDAV 后连上去 |
| 播 FTP 服务器上的文件 | FTP | 自建 FTP、部分 NAS 的 FTP 服务 |

另外还有独立的「播放网址/打开 URL」入口：直接给一条流媒体地址（如 `.m3u8` 直播流），不走上面三种协议。

## 二、连 SMB：播电脑或 NAS 的共享

1. 电脑端（Windows）：右键你要分享的文件夹 → 属性 → 共享，开启共享并记下共享名；同一局域网下无需复杂配置。
2. 手机与电脑连**同一个 Wi-Fi**（不同网段、开了访客网络会找不到）。
3. Reex 的网络共享里选 SMB，填电脑的局域网 IP 或计算机名、共享目录、账号密码。
4. **共享目录没设密码**时，Reex 自 v1.7.0 起支持 SMB 无密码连接（官方更新说明），账户名留空/填访客即可，具体以界面提示为准。
5. 连上后目录结构照常显示，点文件直接播，体验与本地文件一致。

电脑休眠、SMB 服务没开、防火墙拦了局域网发现，都会导致列表拉不出来 —— 先在电脑上确认这个共享在另一台电脑上能打开，再排查手机端。

## 三、连 WebDAV：把网盘内容当本地目录播

WebDAV 是三种协议里最省事的一条路，因为它既能连自建服务，也能连「网盘 → WebDAV 挂载」这类中转：

1. 准备一个 WebDAV 地址：自己部署的服务、NAS 自带的 WebDAV、或用开源工具（如 Alist）把网盘挂载成 WebDAV，拿到 `地址:端口`、用户名、密码；
2. Reex 网络共享里选 WebDAV，填这三项，确认；
3. 进入目录直接点播 —— 视频边下边播，不需要先转存到手机。

两个版本相关的注意点（来自官方更新说明）：

- **302 跳转**：v1.7.2 起支持 WebDAV 的 302 跳转，很多网盘中转服务靠跳转下发真实地址，旧版本连上却播不了时先升级；
- **网络共享封面**：v1.8.9 起「列表文本获取网络共享视频信息封面」为可选功能，需要手动开启，默认不拉封面（省流量、也更快）。

## 四、连 FTP

网络共享里选 FTP，填服务器地址、端口、账号密码即可。FTP 明文传输，只建议在家庭局域网内用；要走公网，优先选 WebDAV 并配上 HTTPS 地址。

## 五、直接播一条网络流地址

看直播、播一条现成的视频 URL：

1. 播放界面或首页找到「播放网址 / 打开 URL」类入口；
2. 粘贴完整地址（`.m3u8`、直链 mp4 等）；
3. 确认开播。地址失效、需要鉴权的链接会直接黑屏或报错，属地址本身的问题，不是播放器坏了。

网络源播不动（一直缓冲、起播失败）时，先分清是**网络慢**还是**解码跟不上**，对照 [播放卡顿与常见问题排查.md](播放卡顿与常见问题排查.md) 逐步排除。
