## 一、安装时提示「风险应用」，装不上

国产手机安装非商店来源的应用时会弹拦截页。逐条排查：

1. 确认包的来源：按 [下载与安装教程.md](下载与安装教程.md) 的方式核对版本号与包名（`1.8.9` / `xyz.re.player.ex`），来源清楚再继续；
2. 装不上多半不是包坏了，而是**纯净模式 / 安全守护**在拦 —— 在系统安全设置里临时放行「本次安装」，装完再恢复；
3. 提示「与处理器架构不兼容」→ 换另一个 CPU 架构的 APK（见安装篇的架构表）。

## 二、列表里没有我的视频

按这个顺序查，通常三步内解决：

1. **权限**：系统设置 → 应用管理 → Reex → 权限，「照片和文件/存储」是否为允许；
2. **扫描范围**：设置里自动扫描是否被关了（手动添加模式下，没添加的目录就是不显示）；开着就回首页左上角点一次刷新；
3. **体积过滤**：设置 → 常规 → 其他里若配了「按体积过滤」，小体积文件会被挡掉，把它清掉再刷新。

三步都对仍缺文件时：**有用户反馈部分手机内存里的视频扫描不到**（小众软件论坛的讨论帖）—— 这类情况把那个目录手动添加进列表即可，不必等自动扫描。

## 三、外挂字幕死活不显示

排查顺序：

1. 文件名与目录是否**逐字同名、同目录**（见字幕篇第一节，这是最常见的原因）；
2. 系统的「所有文件访问」权限是否给了 —— 官方 v1.8.7 更新说明明确写了新增此可选权限用于解决本地字幕自动加载问题；
3. 都对还不行 → 播放界面里手动加载一次这个字幕，能加载说明只是自动识别没触发，把它记为需要手动的目录。

## 四、高码率视频卡顿、花屏、黑屏

先分清是哪一层的问题：

1. **切换解码方式**：播放界面「更多」里可在硬解与软解之间切换。花屏、色块、开头几秒异常，多数是当前机型硬解对这个编码支持不好，换软解验证；
2. **硬解模式细分**：硬解里有 `mediacodec`、`mediacodec-copy` 等模式。需要挂载着色器（画质增强）时，社区通行做法是选 `mediacodec-copy`；普通播放则选默认模式即可（具体表现以你的机型为准）；
3. **手机性能**：4K 高码率、10bit 色深文件对老芯片就是吃力，软硬解都卡说明是性能上限，与应用设置无关；
4. **网络源**：只在网络共享/流地址播放时卡，多半是带宽不够或对端限速，用本地同名文件试播对比一次就能确认。

## 五、闪退、无响应、打不开

按代价从小到大试，一般走到第三步就好：

1. **强停重开**：系统设置 → 应用管理 → Reex → 强行停止，再重新打开；
2. **清缓存**：应用信息 → 存储 → 清理缓存（清缓存不动你的视频与设置；「清除数据」会把播放记录、扫描配置一并清掉，先想清楚再点）；
3. **查权限与内存**：确认存储权限仍为允许；后台开太多导致内存不足时，清一遍后台再开；
4. **卸载重装**：以上都无效就卸载后重新安装 —— 注意卸载会清掉播放记录与扫描配置，装完按 [下载与安装教程.md](下载与安装教程.md) 重新给权限、重新添加目录。

只有播放某一个文件时才崩，而换文件正常 → 是那个文件本身的问题，不用折腾应用。

## 六、进阶：mpv.conf 配置文件与自定义按键

Reex 基于 libmpv，保留了 mpv 的配置文件机制。配置目录在：

```text
/storage/emulated/0/Android/data/xyz.re.player.ex/files/mpv/
```

- `mpv.conf` —— 播放行为的全局配置，改完重启应用生效；每条选项就是 mpv 的一个选项，可查 [mpv.io 手册](https://mpv.io/manual/master/) 对照写；
- 着色器（`.glsl` 文件）放在该目录的 `shaders/` 子目录，通过 `mpv.conf` 里的 `glsl-shaders-append` 引用 —— 完整的实战案例（挂 Anime4K 提升动漫画质）见 [Anime4K着色器画质增强教程.md](Anime4K着色器画质增强教程.md)；
- 自定义按键（类 `input.conf` 的交互）与自定义按钮也在设置里有对应入口，v1.8.0 起支持自定义按钮（官方更新说明）。

手改配置前先备份原文件；改坏了删掉 `mpv.conf` 即可回到默认。

## 七、还没解决

先确认三件事再扩大排查范围：版本号是否 `1.8.9`（见安装篇的核对方法）、权限是否给全、问题是否只出现在某一个文件/某一个网络源上。**只有一个文件出问题** → 是那个文件本身（编码、字幕轴、损坏）；**所有文件都出问题** → 才是设置或设备层面的事。
