## 一、装不上：提示「未知来源」「解析错误」「应用未安装」

按顺序排查：

1. **没给安装权限** → 按 [下载与安装教程.md](下载与安装教程.md) 第二节允许未知来源，或在弹窗里直接点允许；
2. **包不完整** → 「解析错误」几乎都是下载中断导致的。删掉重新下，下完核对大小是否为 89.13M、MD5 是否为 `c5dbf5c5871a9b8083ee04d2b8a94288`；
3. **后缀被改** → 有的网盘下载后会把文件名加上参数或改后缀，确认文件名以 `.apk` 结尾；
4. **空间不足** → 安装需要临时空间，89M 的包建议预留 500M 以上。

## 二、装上了打不开 / 闪退

- **系统版本过低**：第三方页面标注最低 Android 7.0，低于此版本的机型大概率跑不起来；
- **首次启动慢**：安卓首启会加载大量资源，比平时慢，等十几秒再操作，别连点；
- **权限没给全**：存储权限被拒会导致读不到资源直接退出，去应用信息里把权限打开再进；
- **装了与系统不兼容的架构包**：极少数机型（老 32 位机）装 64 位包会闪退，需要换对应架构的构建——这种情况官方页面没有逐一列出，只能试不同来源的包。

## 三、玩着玩着卡死、报错

- **「Array buffer allocation failed」一类报错**：有玩家反馈在浏览器版遇到过，属于内存分配失败——关掉后台应用释放内存后重开；手机端同样先清后台再进游戏；
- **某场剧情卡住不动**：官方 devlog 里修过多次「战斗中不能移动」「开场重进」这类问题——**战斗中失去移动控制这个 bug 官方在 0.3.4_2 才修**，你玩的若是 0.3.3，遇到属于该版未修问题，只能升级解决（对照 [版本更新历史与安装包怎么选.md](版本更新历史与安装包怎么选.md)）；
- **走到树旁拿到蛋后走不动**：有玩家反馈该处不是死机，是需要按一次确认键（手机上对应确认按钮）才继续，别急着退出重开；
- **弹幕关过不去**：这不是故障，是玩法难度——玩家普遍反馈没有难度选项。换用摇杆控件、把红心贴着方框边缘走会好一些。

## 四、存档丢失

这是玩家反馈最集中的一条：

- **版本更新后存档没了**：有玩家反馈跨版本更新会丢进度，官方**目前没有提供存档导出/导入功能**；
- **长期没打开后存档失效**：也有玩家反馈闲置一段时间后进度消失；
- **能做的**：大版本更新前别指望自动保留；想要保险，更新前用文件管理器把应用数据目录整目录备份一份（需要 root 才能完整拷贝，普通机型只能碰运气）——**没有任何官方手段能保证跨版本存档存活**，这是该版本阶段的已知短板。

## 五、手机虚拟按键失灵

玩家反馈的典型现象：方向键 / 摇杆偶尔不动，或者点屏幕误触导致场景被直接跳过。可依次试：

1. 点一下屏幕空白处，让控件重新获得焦点；
2. 在设置里**把方向键切成摇杆（或反过来）**；
3. 对话与菜单改用点按**对话框或选项本身**推进（别点画面空白处）；
4. 都无效则重启游戏——临时性控件失灵重启后基本能恢复。

另一个高频误触：**对话中点画面会直接结束当前场景**（有玩家在商店类场景反复中招）。推进对话尽量走确认键或对话框本身，别点画面空白处。

## 六、语言相关

- **怎么没有中文**：截至官方 0.3.5，语言为英语、西班牙语、俄语（0.3.3 起加入后两者），**无中文**，以官方页面为准；
- **语言在哪切**：0.3.3 换了新主菜单，语言选项在主菜单/设置内；若你的 0.3.3 包里找不到，说明该构建没带对应选项，不折腾；
- **别用来源不明的「汉化版」**：汉化包多为第三方改动，可能被植入额外代码；介意的话就用原版英文。

## 七、其他零碎

- **想换更新的版本**：官方三平台包都在发布页，操作见 [版本更新历史与安装包怎么选.md](版本更新历史与安装包怎么选.md)；
- **想从头开始**：应用信息里「清除数据」即可重置（存档一并清掉）；
- **画廊条目解锁了却显示未拿到**：有玩家反馈部分场景的画廊解锁**要求解锁时身上带着对应道具**，道具没了就显示不出来——这属于当前版本的已知怪象，可留意官方 devlog 后续修复；
- **改不了键位**：官方页面没有键位自定义入口，玩家在评论里问过多次，目前只能适应默认键位。
