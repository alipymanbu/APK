AniCh 是个人维护的开源项目，版本迭代快、接口也会调整，很多"用不了"的问题答案都是同一句：先升级。下面按问题逐条说。

## 一、打开后列表空白、内容加载不出来怎么办

这是旧版本最常见的问题。有用户反馈过旧版本因接口调整而连不上、内容取不到的情况，作者也因此提示尽快更新到新版本。

处理顺序：

1. 先升级到发布页最新版（1.5.21 版起应用内也能直接更新）；
2. 还不行就检查网络环境 —— 作者提示过更新接口在部分地区无法访问的情况，这种只能等接口调整；
3. 有一点常被忽略：有反馈称设备系统时间被手动改过、偏差太大时也会加载异常，把时间设成自动同步再试；
4. 个别番剧只有单一线路且该线路临时故障时，只有这一部加载不出来，换一部能放就是线路问题，等它恢复。

发布页地址：[github.com/Sle2p/AniCh/releases/latest](https://github.com/Sle2p/AniCh/releases/latest)。

## 二、网盘里的版本和官方最新版为什么不一样

网盘里固定是 1.5.18（2026-09 收录），官方仓库在这之后还在继续发版，截至 2026-09 已到 1.5.25。两者不是矛盾，只是时间差：

| 你想要什么 | 去哪拿 |
| --- | --- |
| 1.5.18 的安装文件 | 本篇头部的 AniCh 安装文件资源 |
| 1.5.25 及之后的新版 | GitHub 发布页，或应用内更新（1.5.21 版起） |

功能差异看版本：弹幕密度、外挂字幕导入、线路排序这些都在 1.5.18 之后才加入，各篇文档里标注了"某版本起"的都是这种情况。

## 三、搜出来一堆"AniCh"，怎么认准是这一个

名字带 AniCh 的站点和应用不止一家，有的是完全不同的产品（包名都不同）。认准两条：

1. **包名是 `app.anich`**：安装包信息里看包名，对得上才是本篇说的开源 AniCh；
2. **开源仓库在 GitHub**：项目地址 [github.com/Sle2p/AniCh](https://github.com/Sle2p/AniCh)，安装文件认它的发布页。

网上一些介绍页把不同产品的下载入口混在一起贴，跟着那种页面走容易装错包，装完发现界面和文档对不上，先核包名。

## 四、鸿蒙、平板、电视能用吗

| 设备 | 情况 |
| --- | --- |
| 鸿蒙（HarmonyOS） | 1.5.17 版起适配，但需要自签名、侧载方式安装，步骤比安卓麻烦 |
| 电视 / TV 端 | 1.5.19、1.5.20 版连续做了 TV 端适配 |
| 平板 | 沿用安卓包，画廊与列表布局自适应 |

这几类的安装包都在 GitHub 发布页，按设备挑对应文件。

## 五、观看记录没记上、进度丢了怎么办

1.5.18 修复了"部分操作误触发拖动画面"、优化了观看记录上传逻辑，1.5.19 又修了"本地观看记录有时无法记录进度"的问题。所以：

1. 升级到新版本（这是记录类 bug 的主要修法）；
2. 登录账号让进度走云端，换设备也不断档；
3. 卡片上的进度显示是 1.5.19 版起才有的，旧版看不到不是记录丢了，是没显示。

## 六、注册或改用户名、密码时报错

完整的注册步骤和报错排查收在[账号注册与数据同步.md](账号注册与数据同步.md)里。一句话版本：先把应用升级上来（1.5.25 版修过"注册与修改用户名、密码失败时错误提示不够详细"的问题），再按提示检查验证码与用户名。

以上问题之外的情况，先看对应主题的篇章：装机与升级在[下载与安装教程.md](下载与安装教程.md)，弹幕不显示在[弹幕设置与过滤方法.md](弹幕设置与过滤方法.md)，界面结构在[追番入门使用指南.md](追番入门使用指南.md)。
