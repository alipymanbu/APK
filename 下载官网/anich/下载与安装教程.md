# AniCh 下载与安装教程

> 本篇讲 AniCh 的安装文件从哪拿、怎么核对版本、怎么装到手机上，以及装好之后怎么升级。

AniCh 是一个开源的在线追番应用，支持番剧索引与搜索、弹幕、倍速播放、离线缓存和超分辨率，界面里没有广告位。本篇只解决两个问题：安装文件从哪拿、怎么装上手机。

## 一、安装文件的两个来源

| 来源 | 版本情况 | 适合谁 |
| --- | --- | --- |
| 夸克网盘 | 固定为 1.5.18（见下表核对信息） | 想先转存一份、离线留底再装 |
| GitHub 发布页 | 跟随作者更新（截至 2026-09 最新为 1.5.25） | 想要最新功能与修复 |

两个来源背后是同一个开源项目：[github.com/Sle2p/AniCh](https://github.com/Sle2p/AniCh)。作者更新比较勤，隔一阵就出一个新版本，**功能差异以发布页的更新日志为准**：[github.com/Sle2p/AniCh/releases/latest](https://github.com/Sle2p/AniCh/releases/latest)。

## 二、从网盘获取（转存后下载）

打开 [AniCh 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5e0bd5cc6215)，把资源转存到自己的网盘，再从网盘 App 里把 APK 下载到手机。网盘里那份安装包的信息如下，**下载完可以逐项核对**：

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.5.18 |
| 包名 | app.anich |
| 安装包大小 | 24.03M |
| MD5 | 2EDE1930199B034D53424A843080C4B9 |

其中**包名**最实用：安卓靠包名识别应用，同包名才能覆盖安装。如果你手机上已经有一个"AniCh"却对不上 `app.anich`，那其实是另一个同名产品，别混装（详见[常见问题解答.md](常见问题解答.md)里的同名产品一条）。

## 三、从 GitHub 发布页获取

打开发布页，最新一个 release 下方会列出多个文件：作者同时发布安卓、桌面端等平台的包，安卓包是 `.apk` 后缀、体积相对较小的一个。文件名里带版本号，认准最新日期那一批即可。

## 四、安装步骤

1. 把 APK 弄到手机上：网盘 App 直接下载，或电脑下载后用数据线拷过去；
2. 在文件管理器里点开 APK，系统弹出"未知来源 / 允许安装"提示时按提示放行。各品牌入口不太一样：小米在安装弹窗里直接给开关，华为与荣耀会引导去"更多安全设置"，vivo 与 OPPO 在弹窗里点"仍要安装"；
3. 等安装完成，打开应用。

系统要求为 Android 5.2 及以上（以安装包标注为准）。

## 五、装好之后怎么升级

- **应用内更新**：1.5.21 版起新增了应用内下载最新版的功能。路径大致是「我的」→「版本信息」→ 检查更新，有新版就按提示下载安装（入口名称以你手上的版本为准）；
- **手动覆盖**：重新下载新版 APK 装一遍即可，观看记录与设置会保留；
- 网盘里那份 1.5.18 是固定版本，不会自己变成新版，要新版就走发布页或应用内更新。

装好之后先去哪点：看[追番入门使用指南.md](追番入门使用指南.md)把找番、追番、看进度的路数走一遍；打开后列表空白或加载不出来，直接翻[常见问题解答.md](常见问题解答.md)。
