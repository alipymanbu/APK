## 一、Rays 是什么

Rays（Record All Your Stickers）是一款在**手机本地记录、查找、管理表情包**的开源工具，由开发者 SkyD666 维护，代码以 GPL-3.0 协议发布在 GitHub（`https://github.com/SkyD666/Rays-Android`）。你把散落在相册、聊天记录里的表情包统一收进它，再靠标签和搜索把要用的那张翻出来。本篇只解决一件事：把 2.3 版装进手机。

## 三、版本与包型怎么选

### 3.1 官方 2.3 发布页提供的构建

同一版按 CPU 架构分了好几个包，选错架构会直接装不上（报「解析包时出错」）。官方 2.3 发布页当时提供：

| 构建名 | 大小（字节） | 适合谁 |
| --- | --- | --- |
| `arm64-v8a` | 43,925,399 | **绝大多数现代安卓手机**，先试这个 |
| `armeabi-v7a` | 39,946,755 | 老旧 32 位机型 |
| `universal` | 105,954,000 | 包含全部架构，不确定时用它兜底 |
| `x86_64` | 39,272,522 | x86_64 模拟器 / 个别平板 |
| `x86` | 48,253,567 | 老式 x86 模拟器 |

网盘里那份 2.3 包的大小（43,925,399 字节）与官方 `arm64-v8a` 构建**完全一致**，可按 arm64 版对待——近几年的主流手机都属于这一类。

### 3.2 系统要求

官方 README 标注支持 **Android 7.0 及以上**。系统低于 7.0 大概率装不上或功能异常，先确认系统版本（设置 → 关于手机）。

## 四、安装步骤

1. 从网盘或官方发布页把 APK 下载到手机。
2. 点开 APK 文件，系统会弹「禁止安装未知来源应用」——这是安卓对非商店来源的默认拦截，按提示进入**该来源（浏览器或文件管理器）的安装许可**开关，打开后再返回安装。
3. 安装完成后桌面会出现 Rays 图标，首次打开会进入首页，右下角是添加表情包的加号按钮。
4. 首次使用建议先看一眼[表情包添加与标签管理.md](表情包添加与标签管理.md)，把第一批表情包收进去。

安装失败、报「解析包时出错」或装完闪退的，直接看[常见问题与排查.md](常见问题与排查.md)。

## 五、升级与降级

- **升级**：官方 Releases 页下载新版 APK 覆盖安装即可，已有的表情包数据留在本地，不会因为覆盖安装丢掉；换架构的包（比如从 arm64 换 universal）同样可以覆盖装。
- **降级**：安卓不允许直接装低版本，需先卸载再装——**卸载会清掉应用内的表情包数据**，降级前务必先走一遍[数据备份与换机迁移.md](数据备份与换机迁移.md)的导出流程。
- 版本历史（官方发布页可查）：2.0（2023-12）→ 2.1（2024-02）→ 2.2（2024-07）→ **2.3（2025-02）**，2.3 新增了相似表情包搜索、全屏显示、合并表情包、列表多选、AMOLED 深色等功能。
