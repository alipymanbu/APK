## 一、装不上或装完就闪退

按出现频率排：

1. **「解析包时出错」** —— 大概率是架构不匹配。回到[下载与安装教程.md](下载与安装教程.md)第三节，按手机架构重下对应包；实在判断不了就用官方的 `universal` 构建。
2. **系统版本过低** —— 官方标注需 Android 7.0+，低于此版本先确认系统（设置 → 关于手机）。
3. **点安装没反应 / 被拦下** —— 是「未知来源安装」许可没开，按安装教程第四节给对应来源开权限。
4. **覆盖升级后闪退** —— 先不卸载，试装官方 `universal` 包；仍闪退则先导出数据（见[数据备份与换机迁移.md](数据备份与换机迁移.md)）再卸载重装，**别上来就卸载**。
5. **打开就闪 / 无响应（通用三步）** —— 安卓各家厂商支持文档给的通用顺序同样适用本应用：先**强行停止并重启**（设置 → 应用 → Rays → 强行停止），再**清缓存**（同一页面 → 存储 → 清除缓存——**清缓存不等于清数据**，表情包库不受影响；「清除数据」才清库，点之前先想清楚），最后**重启手机**再进。三步都做过仍崩，才走上一条的重装路径。

### 用起来才碰到的两个已知问题

- **添加图片时一直卡住** —— 不是安装问题，处理办法在[表情包添加与标签管理.md](表情包添加与标签管理.md)第 2.5 节（设置的 AI 页关掉「分类」与「文字识别」）。
- **批量删除时崩溃** —— 有用户反馈 2.3 版在较新系统上批量删除表情包会闪退（官方仓库 issue #55，截至 2026-09 仍为 open、未见修复版本）。在等更新期间，**把大批量删除拆成小批逐次删**，删之前确认已导出备份。

## 二、明明收了图，却搜不到

逐项过一遍，多数问题停在前两条：

- **搜索域没勾对字段** —— 标签存的东西要在「标签」域里查。先开搜索配置页核对（详见[表情包搜索技巧.md](表情包搜索技巧.md)第一节）。
- **正则模式开着** —— 正则下 `Genshin` 只匹配整词，想模糊匹配要写 `.*Genshin.*`；不确定就先把正则关掉。
- **图是收进来了但字段是空的** —— 没打标签、图里也没识别出文字的，任何关键词都搜不到它，补标签即可。
- **文字识别没生效** —— 去设置里调整文字识别阈值后对这批图重新识别，或直接手打标签。

## 三、AI 相关功能用不了

AI 推荐标签（官方标注支持更换模型）与 AI 图片风格转移的实际表现，取决于你选的模型与设备算力：

- 先确认已在应用内**选定模型**（添加页/设置页有模型选择入口）；
- 模型下载、推理速度、离线可用性等**以应用内页面与官方说明为准**，这里不给具体数值；
- 推荐标签只是候选，AI 不可用时**纯手工打标签不影响任何搜索功能**——标签体系不依赖 AI。

## 四、WebDAV 同步失败

1. 核对服务器地址、账号密码是否填对（多打一个字符都会 401/404）；
2. 确认该 WebDAV 服务允许第三方客户端登录（部分服务要用「应用专用密码」而不是账号密码）；
3. 换过服务商的，先在设置里**移除旧的服务器与账户信息**（2.3 支持）再重新配置；
4. 有改动才同步：库里没变化时应用可能本就不上传，先确认自己改过数据再判断是不是故障。
5. **换了手机后一进 WebDAV 设置就崩** —— 多半发生在用第三方工具整机还原应用之后，处理与预防见[数据备份与换机迁移.md](数据备份与换机迁移.md)第五节。

## 五、其他高频小问题

| 现象 | 怎么处理 |
| --- | --- |
| 界面是英文 | 系统「应用语言」里给 Rays 单独设中文（Android 13+ 支持应用内语言偏好），或在应用设置里找语言项 |
| 列表里某些图糊成一团 | 那是单张开了「模糊显示」，进详情关掉即可 |
| 分享面板里找不到 Rays | 少数场景需在 Rays 设置里指定允许 URI 分享的包名（1.2 起有该设置项），具体见[在聊天软件里发送表情包.md](在聊天软件里发送表情包.md) |
| 从聊天应用附件里翻不到表情包 | 走「文件 / 文档」入口而不是「相册」，路径见[在聊天软件里发送表情包.md](在聊天软件里发送表情包.md)第三节 |
| 想确认手里的包是不是 2.3 | 对照[下载与安装教程.md](下载与安装教程.md)第二节的版本/包名/MD5 表核验 |
| 版本太旧缺功能 | 2.3 相比 2.2 新增相似搜索、合并表情包、多选、AMOLED 深色等，从安装教程的入口升级 |

遇到本文没覆盖的问题，官方仓库的 Issues（`https://github.com/SkyD666/Rays-Android/issues`）和项目页留的 Telegram / Discord 社群是能直接找到开发者的渠道。
