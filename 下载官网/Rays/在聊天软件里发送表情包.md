# 在聊天软件里发送表情包

## 一、从 Rays 往外发：三条路

1. **系统分享面板**：列表里多选表情包 → 分享 → 在系统分享面板里点目标聊天应用。这是最通用的一条，发给谁都走它。
2. **复制到剪贴板**：打开单张 → 复制，然后到聊天窗口长按粘贴发送。适合只发一张、要插进正在输入的那段话里的情况。
3. **自动分享**（1.3 起）：开启后，选中表情包会**直接分享回上一个页面对应的应用**——你从聊天窗口跳进 Rays 找图，找到后不用再走一遍分享面板。

**透明背景的图发出去变黑底**：旧版本在复制/粘贴路径上丢过透明度（官方 2.1 修复记录有这条），还停在老版本的先升级到 2.3，见[下载与安装教程.md](下载与安装教程.md)。

## 二、微信里的两个专门设置

官方对微信这个场景单独做过适配（1.2 及 1.2-Patch 1 更新记录）：

- **表情包 URI 字符串**：分享时可以复制表情包的 URI 字符串，官方说明这条目前**仅针对在微信中发送**的场景；
- **允许 URI 分享的包名**：这个 URI 分享发给哪些应用，可以在设置里**指定包名**——默认列表没覆盖到的应用，把包名加上才收得到。

按 URI 方式发送时用的是 `content://` 开头的共享地址，聊天应用拿到的是受控的读取授权，不是文件的原始路径——所以目标应用读不到图，先查这里有没有把它加进允许列表。

## 三、反过来：从聊天应用里取 Rays 的图

正常的「+ → 相册」入口调的是系统相册，不会出现 Rays。要从聊天应用里直接翻 Rays 的库，走**附件的「文档 / 文件」入口**：

1. 聊天窗口点加号 → 选「文件 / 文档」（不是「相册」）；
2. 在文件浏览列表里找到 Rays 提供的入口（2.2 起内置了 DocumentsProvider，表情包会在系统文件选择器里出现）；
3. 进去后按标签搜、选图发送。

**限制（有用户反馈）**：WhatsApp 附件的「相册」选择器里看不到 Rays 入口，只能按上面的「文档」路径走——这是官方仓库仍处 open 状态的功能请求（issue #35，截至 2026-09 未实现），其他聊天应用是否在相册入口列出 Rays 同样取决于对方的选图器，没列出就用文档路径。

## 四、给接了其他工具的读者

Rays 对外留了调用口：**系统广播搜索**（1.3 起，其他应用可通过广播搜表情包）与 **AIDL 接口**（2.2 重构）。你如果在用自动化类工具链，可以让它按标签检索 Rays 并取图；具体接口定义见项目仓库（`https://github.com/SkyD666/Rays-Android`）。不用这些的读者，前两节的分享面板已经覆盖日常。
