## 一、装之前先对一下这张表

| 项目 | 这一版的情况 |
| --- | --- |
| 软件名 | I own |
| 版本号 | 1.0.5 |
| 包名 | `com.example.lown_xian_hua` |
| 安装包大小 | 30.62 MB（32,108,013 字节） |
| 安装包 MD5 | `77F3869D80AA6AA3ACCE1B44057A2FBE` |
| 适用设备 | 安卓手机 / 安卓平板 |
| 系统要求 | 整理这一版时记录到的是「需要支持安卓系统 5.2 以上」 |
| 官方分类 | 生活 |

三点先说明：

1. **版本号以本页表格为准。** I own 在 App Store 有 iOS 版，该页面的版本历史停在 1.0.4（2025 年 11 月），而这份安卓资源是 1.0.5 —— 两端本来就不完全同步。网上介绍页写的数字多半停在更早的版本，不用拿来跟你手上的包对照。
2. **「安卓 5.2」这个写法不必纠结。** 安卓官方并没有对外的 5.2 版本（公开版本是 5.0、5.1，之后直接跳到 6.0），这句按「Android 5 系及以上」理解就行。真正能不能装，以你设备上点下去之后的提示为准。
3. **装完可以自己复核。** 安卓的 设置 → 应用 → I own 里能看到版本号，和上表对得上，说明装的就是这一版。

## 二、从网盘把安装包取出来

1. 打开 [I own 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ab044a628476)。手机、电脑都能操作，用夸克 App 打开更稳。
2. 点「保存到我的网盘」转存到自己账号下 —— 转存之后，下载就不再依赖原分享链接是否还在。
3. 下载到本地，确认文件名结尾是 `.apk`。
4. 核对 MD5 是不是 `77F3869D80AA6AA3ACCE1B44057A2FBE`。在电脑上下载的话，Windows 可以在文件所在目录用下面这条命令算一遍（文件名换成你实际下到的那个；文件名里有空格或中文时，整段用英文双引号包起来）：

```powershell
certutil -hashfile "I own_v1.0.5.apk" MD5
```

5. 对不上就删掉重下。安卓装到一半报「解析包错误」，绝大多数是包没下完整或被传输截断。

## 三、安卓安装步骤

这个包不是从手机自带软件商店里装的，安装时系统会拦一下，属于正常现象，不代表文件有问题。

1. 打开手机的「文件管理」，进 `Download`（下载）目录，找到刚下好的安装包，点它。
2. 弹出「不允许安装来自此来源的应用」时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要绕一层：设置 → 应用 → 特殊应用权限 → 安装未知应用，在里面找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」，别急着打开 —— 先看下一节，第一次进去有几件事要一次做对。

## 四、首次打开要做的事

1. **要登录。** 装完第一次进去会走到登录页。App Store 的评论区里有用户提到登录要收短信验证码（该用户同时反馈验证码一直显示发送中）。验证码一直不来，按 [常见问题与排查.md](常见问题与排查.md) 第一节的顺序查，别反复点「重新发送」。
2. **首页先看一眼今天那句。** 官方说明里，首页每天提供一句正向肯定语，这就是它最日常的用法：不用设置、不用填表，打开就有一句。想自己写、想计数，再去另外那两块。
3. **四个板块各管一件事**，先知道自己要哪个，不用全都填一遍：
   - 每日正向肯定语 —— 见 [每日肯定语与计数器怎么用.md](每日肯定语与计数器怎么用.md)
   - 肯定语计数器 —— 同上，同篇里一起讲
   - 感恩日记 —— 见 [感恩日记怎么写.md](感恩日记怎么写.md)
   - 自定义肯定音频 —— 见 [肯定音频怎么做.md](肯定音频怎么做.md)
4. **权限不用一次给全。** 安卓的权限是「用到才要」，遇到弹窗按提示放行即可；没遇到就别主动去系统设置里翻开关。

## 五、装不上时先查哪几处

| 现象 | 大概率原因 | 怎么处理 |
| --- | --- | --- |
| 「解析包错误」 | 包没下完整、传输被截断 | 删掉重新下载，用第一节的 MD5 核对 |
| 「应用未安装」 | 设备上已有同包名旧版，签名对不上 | 先卸载旧版再装；卸载会清掉应用内的记录，能覆盖安装就别卸载 |
| 提示不允许安装未知应用 | 系统的来源限制 | 见第三节第 2 步 |
| 装完图标不出现 | 装到了当前用户之外的空间 | 到系统「应用管理」里搜 I own，能找到就说明装成功了，从那里打开 |
| 打开就闪退 | 系统版本过低，或包在传输中损坏 | 换一台设备试，或重新下载原包后再装 |

打开后卡在登录、验证码收不到，以及音频合成出来的文件找不到，都在 [常见问题与排查.md](常见问题与排查.md) 里，不在这里重复。
