# I own 肯定音频怎么做

> 官方的「灵魂回响」板块，是把你自己的肯定语和一段音频合成一条专属于你的肯定音频。本篇讲句子要先做成什么样、音频怎么配、音量和时长定在哪条线上、什么时段适合听，以及听不到声音或合成失败先查哪几处。

## 一、这一步到底在合成什么

官方对这一块的说明是「把你的自我肯定语，融合各种音频，制作合成专属于你的肯定音频」。拆开就是两样输入、一样输出：

- 输入一：**一句你自己写的肯定语**；
- 输入二：**一段音频**（背景声）；
- 输出：一条能循环播放的音频。

顺序上，**先把句子写对再进来**，句子没写好，音频做得再顺耳也只是把一句别扭的话重复几十遍。写句子的四条要求见 [每日肯定语与计数器怎么用.md](每日肯定语与计数器怎么用.md)。

## 二、句子先做减法

音频里那句话会被你反复听到，所以标准比写在纸上更严：

- **一句只放一个主题。** 想同时处理健康、收入、关系，就做三条，别塞进一句。
- **长度控制在 10~20 秒能念完。** 长句听三遍就烦，第三条就开始跳过了。
- **不要列清单。** 「我健康、我富有、我被爱」这类排比，听起来完整，其实三件事你一件都没真的听见。
- **别用否定句。** 「我不再拖延」在音频里反复响，反复出现的是「拖延」两个字。

## 三、音频怎么配

「sub」这一类做法在公开流传的介绍里，共同点是**让人声和背景音互相盖住一点**：

| 要素 | 常见做法 | 为什么 |
| --- | --- | --- |
| 人声 | 压到**刚好能听清**，不必句句分明 | 太清楚会变成刻意听，反而听不久 |
| 背景 | 雨声、白噪音、轻音乐这类无歌词无起伏的内容 | 带歌词的音乐会抢注意力，你听的是歌词不是那句话 |
| 音量 | 先按设备最大音量的六成试一段 | 听得舒服就定在那儿，直接拉满第二天就放弃了 |

这三条都是流传经验，没有官方标准；判断依据只有一条 —— **听完不头疼、不烦躁**。

## 四、音量、时长与时段

**先守两条线。** 这两条来自公共卫生机构和耳科医生的公开建议，不是这个应用自己的说法：

| 项目 | 建议 | 说明 |
| --- | --- | --- |
| 音量 | 不超过设备最大音量的 60% | 即常说的「60-60 原则」，并且要在这个范围内再挑能听清的最小音量 |
| 单次时长 | 连续不超过 60 分钟，之后让耳朵歇 10~15 分钟 | 同一条原则的后半段 |
| 睡觉 | 不建议戴着耳机听整夜 | 睡着之后听觉仍在工作，毛细胞得不到休息；耳道长时间密闭也容易发炎 |

这条线卡得这么死是有原因的：手机耳机开到最大可以超过 110 分贝，而世卫组织给出的参考是「不超过 80 分贝、每周累积 40 小时」。地铁车厢的环境声本身就有 80 分贝左右 —— **在那种环境里你还能听清耳机里的内容，音量其实已经超了。**

**再看时段：**

| 场景 | 合适吗 | 说明 |
| --- | --- | --- |
| 睡前躺着 | 合适 | 最常见的用法，但要设好定时，别整夜播 |
| 通勤戴耳机、做家务 | 合适 | 不需要动脑的时段，正好当背景 |
| 走路、骑车、开车 | 不合适 | 这类音频会盖住环境音，是实打实的安全问题 |
| 需要专注处理事情时 | 不合适 | 你既听不进去，手上的事也被拖慢 |

**身体有反应就停。** 摘下耳机之后出现耳鸣、耳闷、听别人说话发闷，是听觉疲劳的信号，先停几天；持续不缓解就去耳鼻咽喉科看，别靠加大音量硬听。

最后一条不是健康提醒：**别把「听够多少遍」当任务。** 音频在这里是背景，开始数次数之后，你盯的就是数字，不是那句话了。

## 五、听不到声音、合成失败先查哪几处

1. **先分清是没合成出来，还是合成出来没声音。** 把媒体音量调到一半，用别的歌或视频试一下：别的也没声，问题在手机音量或音频通道，不在应用。
2. **蓝牙可能抢了音频通道。** 连着蓝牙音箱、车机或手表时，声音会被路由到那个设备上。断开蓝牙再试一次。
3. **合成结果找不到。** 到手机的「文件管理 → 音频（Music）」目录里找，别去相册里翻 —— 那里面不会有。
4. **合成中途失败。** 先清掉后台重进一次再重试；手机剩余空间太少时也可能存不下结果，清出几百 MB 再试。

这几种情况里还有没覆盖到的，见 [常见问题与排查.md](常见问题与排查.md)。
