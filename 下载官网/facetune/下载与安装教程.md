## 二、获取安装包并核对文件

1. 打开网盘链接，把 `facetune_v2.51.0.1-free.apk` 转存到自己的网盘后下载到手机；这一步用开头的 **Facetune 安装文件资源（夸克网盘）** 链接即可。
2. 手机存储至少预留 1GB：安装包本身约 291MB，安装展开后还要占一份空间。
3. 如果你担心文件在传输中损坏，可以在电脑上用 MD5 核对一次。Windows 下打开 PowerShell：

```powershell
certutil -hashfile "下载路径\facetune_v2.51.0.1-free.apk" MD5
```

输出的值与上表中的 MD5 一致（不区分大小写）就说明文件完好；对不上就重新下载一次。

## 三、安装步骤

安卓首次安装「应用商店以外」的安装包，会先卡在权限这一步，流程是：

1. 点开下载好的 `.apk` 文件。
2. 系统弹出「未知来源」提示时，选择允许——不同品牌的位置不一样：
   - 原生系统：弹窗里直接点「设置」→ 打开「允许从此来源安装」；
   - 小米 / 红米：设置 → 隐私保护 → 特殊权限 → 安装未知应用；
   - 华为 / 荣耀：设置 → 安全 → 更多安全设置 → 安装外部来源应用；
   - OPPO / vivo / 三星：装的时候弹窗里会给「去设置」入口，按提示开即可。
3. 回到安装界面点「安装」，等进度走完。
4. 提示「已安装」后点「打开」。首次启动会请求照片 / 存储 / 相机权限，按需给——只想修本地照片的话，给存储权限就够。

## 四、装不上时先查这几处

按出现频率从高到低：

1. **提示「应用未安装」**：最常见的原因是手机里已经装了另一个 Facetune 系的版本（包名相同、签名不同），先卸载旧的再装；具体是哪几个版本在打架，见 [新旧版本与免费版说明.md](新旧版本与免费版说明.md)。
2. **点开没反应 / 下载到 99% 停住**：存储空间不足，清出 1GB 以上再试；仍不行就重新下载一次安装包并用第二节的 MD5 核对。
3. **提示解析包出错**：文件没下完整，或下载过程中被改名丢掉了 `.apk` 后缀，重下并确认文件名完整。
4. **系统版本太老**：安卓版本低于 5.2 的设备装不上，这是硬性限制。

装上了但用的时候出问题，翻 [常见问题与解决方法.md](常见问题与解决方法.md)；装好之后先弄清免费能用到什么程度，见 [免费功能与收费边界.md](免费功能与收费边界.md)。
