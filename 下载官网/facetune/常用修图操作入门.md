开始之前说一句：Facetune 的功能随版本更新一直在加，你手上这一版未必包含官方宣传的全部新功能，下面按长期稳定存在的那批工具来写；某一节在你手机上找不到对应按钮，就说明这版没有或入口位置不同，以 App 内实际界面为准。

## 一、第一张照片从哪开始

1. 打开 App，在首页选择「编辑照片」（或相机图标直接拍摄）。
2. 从相册选中一张人像照片。
3. 先试「一键增强」（增强 / Enhance 类工具）：它自动调整亮度、清晰度和色彩，多数照片用它打底就够，比手动逐项调快得多。

这些涂抹类的修图工具是内置在 App 里的，不用联网也能用；离线可用性的细节见 [常见问题与解决方法.md](常见问题与解决方法.md) 第三节。

## 二、皮肤：磨平与去痘

这是 Facetune 最经典的用法，两个工具分工不同：

| 工具 | 适合处理 | 用法要点 |
| --- | --- | --- |
| 平滑（Smooth） | 整片皮肤粗糙、毛孔明显 | 用手指在皮肤区域涂抹，力度别拉满，留一点皮肤质感更自然 |
| 消除斑点 / 痘印（Patch / Blemish） | 局部痘痘、痣、疤痕 | 点一下或框住瑕疵，App 会从旁边皮肤取样覆盖 |

顺序建议：先用消除类把明显的点状瑕疵处理掉，再整体抹平滑，最后拉低强度回到自然状态。

## 三、牙齿与笑容

美白牙齿（Whiten）在工具栏里通常是独立一项：把范围涂在牙齿上，亮度会逐级提高。两个注意点——涂抹时别扫到牙龈和嘴唇，否则会跟着变白；强度停在中间档比较可信，拉满会出现「荧光牙」。

## 四、脸型与五官

- **瘦脸 / 缩小（Refine / Slim）**：推挤边缘轮廓，用于下颌线、脸颊；小幅调整比大改自然。
- **五官微调**：眼睛大小、鼻梁宽度等按部位独立调节，同样建议在原图基础上动 10%~20%。
- 所有几何调整都是「推像素」，改得越多背景越容易扭曲——这是判断「修没修过头」的最快方法：看脸部旁边的直线（门框、墙线）弯没弯。

## 五、发色与背景

- **换发色**：涂选头发区域再选颜色，适合先试「我染这个色好不好看」，再决定去不去理发店。
- **背景处理**：模糊背景突出人物，或直接更换 / 抹除背景；人物边缘复杂的（碎发多）抠图效果会差一些，可以先用简单背景的照片试手。

## 六、裁剪与比例

发不同平台之前，用「调整 → 裁剪」把构图切对，比修完再被平台二次裁切强。官方当前版本内置了这些固定比例（较老的版本选项少一些，以你 App 内实际列表为准）：

| 比例 | 适合 |
| --- | --- |
| 1:1 | 头像、朋友圈 / 微博方图 |
| 3:4、4:3 | 手机竖拍 / 横拍的原始感 |
| 4:5 | Instagram 竖版贴文（占屏最大的竖图比例） |
| 9:16 | 竖屏全图、短视频封面 |
| 16:9 | 宽幅、电脑壁纸 |
| 2:3、3:2（35mm） | 冲印打印 |

裁剪不会降低画质（只是切掉边缘），但**几何修脸拉太狠会让背景弯曲**，这两件事别混在一起判断。

## 七、保存与导出

编辑完成后点保存 / 导出，成图存进相册。免费额度与水印规则在 [免费功能与收费边界.md](免费功能与收费边界.md) 里已经讲过：免费每周 3 次、带水印（以你这版的实际提示为准），保存前看一眼剩余次数，避免修好了才发现次数用完——次数没了编辑不会丢，等下周重置再保存即可。

另外记住一点：**导出到相册才算真正落袋**，编辑项目只存在手机本地，卸载或换机就不在了，细节见 [照片保存位置与隐私.md](照片保存位置与隐私.md)。

修图过程中工具点了没反应、保存失败这类情况，直接查 [常见问题与解决方法.md](常见问题与解决方法.md)。
