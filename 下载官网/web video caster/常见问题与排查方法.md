## 一、搜不到电视 / 设备列表是空的

按出现概率从高到低排查：

1. **两台设备不在同一个 Wi-Fi**：手机和电视要连同一个路由器的同一个网络；双频路由器的 2.4G 和 5G 若是两个名字，两边必须选同一个；访客网络互相隔离，也不行。
2. **开着 VPN 或代理**：会拦掉局域网设备发现，关掉后重新扫描。
3. **路由器开了 AP 隔离 / 客户端隔离**：常见于 mesh 路由和运营商送的路由，登录路由器后台关掉「AP 隔离」类选项。
4. **电视处于完全断电状态**：待机的电视多数能被扫到，彻底断电的扫不到，先把电视打开。
5. **手机没给「附近设备」权限**：在系统设置 → 应用 → Web Video Cast → 权限里补上，再回应用重新扫描。

还有一步值得做：重启应用再扫一次，扫描偶发失败不算罕见。

## 二、页面点了播放，但应用识别不到视频

1. 先确认视频在手机内置浏览器里**真的在播**（画面或声音出来了）——很多网站要先点一次播放按钮，视频流才会加载；
2. 换清晰度或换线路：有的线路是加密流，换普通线路就能抓到；
3. 换页面上的另一个播放入口，一个网站常有多个播放器；
4. 若视频本身是 Flash/FLV，或 Netflix、Disney+ 这类 DRM 加密的付费流媒体，抓不到属于应用能力边界——加密流只有服务方自己的应用能解，任何浏览器类投屏应用都一样，付费流媒体请用它们的官方电视应用；换内容源比反复重试有效。

## 三、能连上电视，但黑屏或没声音

先记住一条规则：应用不做转码，**视频由电视自己解码**。手机能放、电视不行，通常是格式问题：

| 现象 | 多半原因 | 处理 |
| --- | --- | --- |
| 电视黑屏，有声音 | 视频编码电视解不动 | 换 mp4 线路；或装官方接收端应用 |
| 有画面，没声音 | 音轨编码电视不支持 | 常见于某些 mkv；换线路或转格式 |
| 直播流（m3u8）放不出 | 该设备不支持 HLS | 多数 DLNA 设备没这能力；Chromecast 或装了接收端的设备可以，各设备差异详见 [IPTV列表与m3u8直播怎么投.md](IPTV列表与m3u8直播怎么投.md) |
| 一切正常但清晰度低 | 网站给的流本身低清 | 换清晰度，由页面决定而非应用 |

「装官方接收端应用」指的是电视那头装 Web Video Caster Receiver，各设备商店的入口见 [投屏设备连接方法.md](投屏设备连接方法.md) 第四节——它的视频兼容性和字幕支持都比 DLNA 直连好。

## 四、播放卡顿、缓冲不停

1. **高峰时段缓冲**：视频由网站服务器直接发给电视，网站那边负载高时谁都救不了——这是官方明说的边界，应用侧调不了；
2. 先在手机浏览器里直接播同一路视频对比：手机也卡，就是源站或网络的问题，与应用无关；
3. 路由器侧：让电视走 5G 频段或网线，减少无线干扰；
4. 换低一档清晰度，流量压力小很多。

## 五、这几类事它做不到（免得反复折腾）

- **投 Flash / FLV 视频**：不支持，这类内容也基本绝迹了；
- **投整个标签页或镜像手机屏幕**：它不是屏幕镜像应用，投的是网页里的视频流本身；
- **替你解决源站的播放失败**：视频由内容方服务器直发电视，服务器端的问题应用侧无解；
- 手机上能放就一定能投？不一定——最终取决于**电视**能不能解码该视频。

对照上面几条还解决不了的，可以到官方支持渠道反馈（附上电视品牌与型号）：[www.webvideocaster.com](https://www.webvideocaster.com)。安装与权限相关的问题也可以回看 [下载与安装教程.md](下载与安装教程.md)。
