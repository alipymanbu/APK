# 账号可以借给别人用吗

## 一、先给结论

**不能。** 中油e学的官方用户协议把账号使用边界写得很明确：账号归中国石油远程培训学院所有，用户不得转让、出借账号，不得用非官方认可的软件、插件、外挂登录使用。本篇把这些边界和背后的留痕机制讲清楚，让你知道"为什么不行"而不只是"被告知不行"。

## 二、协议里明令禁止的行为

用户协议列出的账号使用禁止事项，与你日常最相关的有这些：

- 把账号**转让或出借**给他人使用；
- 通过非官方开发、授权或认可的**软件、插件、外挂**登录使用；
- 对客户端做**反向工程、反向汇编、反向编译**；
- 用账号**批量发广告、垃圾信息**，或传播违法违规内容。

违反这些规定，平台有权**在不事先通知的情况下终止账号的在线功能** —— 对你来说就是某天突然登不上了，且不是密码问题（那种情况去 [登录与密码找回教程.md](登录与密码找回教程.md) 找回也没用）。

## 三、为什么"没人发现"是错觉

用户协议的隐私条款写明：你的 **IP 地址、操作状态、设备信息、使用习惯**等会被客观记录在平台服务器端。也就是说，学习行为本身是**留痕**的：

- 同一账号异常的登录设备、登录地切换；
- 学习时长与实际播放行为的对应关系；
- 操作时间分布。

加上平台与集团人力资源管理系统对接、培训结果数据回传内网，学习记录最终会落到单位的培训档案里。替考、挂学时这类动作一旦被核，暴露的不只是"这一次"，而是整条记录 —— 具体的核查尺度由你所在单位掌握，这里只陈述协议与机制本身。

## 四、常见变体同样不行

| 想法 | 为什么不行 |
| --- | --- |
| 借给同事"顺手学一下" | 账号出借违反协议 2.4，且设备切换全部留痕 |
| 用自己的号在两台设备同时刷 | 单终端只保持最后一次登录，先登的被挤下线，学时记不准（见 [学时没记上怎么解决.md](学时没记上怎么解决.md)） |
| 用脚本 / 插件自动播课 | 属于非官方认可的插件外挂，协议明令禁止，违规可直接停用在线功能 |
| 转发验证码帮人登录 | 等于交出账号控制权，后续所有操作都记在你名下 |

## 五、正确的做法

1. **账号只自己用**，密码不告诉任何人 —— 忘了就走正规找回流程（[登录与密码找回教程.md](登录与密码找回教程.md)）；
2. 需要在多台设备学，就**登同一账号、学完一端再换另一端**，别两端同时开；
3. 课想快点过，用播放器自带的**倍速**，别拖进度条、别上任何第三方工具（口径见 [学时没记上怎么解决.md](学时没记上怎么解决.md) 第四节）；
4. 账号被停用、提示异常，先自查上面几条，再联系本单位管理员（自助排查见 [常见问题与排查.md](常见问题与排查.md)）。

账号出问题 99% 出在密码保管上，先把登录那一层弄稳：[登录与密码找回教程.md](登录与密码找回教程.md)。
