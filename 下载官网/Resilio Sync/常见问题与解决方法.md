## 一、锁屏后就不同步了（最常见）

**症状**：亮着屏、开着应用时一切正常；锁屏或切到别的应用一会儿，新文件就不动了，解锁后过一阵又突然传完。

**原因**：安卓的省电机制会杀掉后台应用，而同步必须持续在后台跑。应用商店页面自己也写明了这一点——Resilio Sync 需要前台服务权限才能在应用被最小化或设备进入省电状态时继续传输，否则进程会被系统停掉，导致传输中断、备份延迟。

**解决**（国产 ROM 上基本都要做一遍，路径按品牌略有差异）：

1. 系统设置 → 电池 → 找到 Resilio Sync，把省电策略改成 **无限制 / 不优化**；
2. 在「应用启动管理」（华为）/「自启动管理」（小米、OPPO、vivo）里允许该应用自启动、允许后台活动；
3. 多任务界面里把它的卡片 **加锁**（下拉卡片出现锁图标），避免一键清理时被扫掉；
4. 改完把应用划掉重开一次，再用一个小文件测：锁屏放 10 分钟，看文件是否还能同步过来。

另外，应用内如果提示需要「前台服务」「通知权限」，都同意——那个常驻通知就是它在告诉你「我还在后台干活」，不是 bug。

## 二、两端都开着，设备却显示离线

**症状**：电脑端的设备列表里手机是灰色/离线，文件怎么都不过去。

按这个顺序查：

1. **是不是真的在线**：手机端应用在后台被杀掉 = 离线。先按上一节把后台权限配好。
2. **是不是跨网络了**：两台设备连同一个 Wi-Fi 时走局域网直连，最容易成功；一台在家一台在公司，就需要双方都能访问官方的发现服务器。关于跨网失败，有两个互相独立的公开来源指向同一原因：一是有用户持续反馈「获取追踪器列表失败」，二是有资料记载 2017 年 6 月起该服务的追踪器列表在部分网络环境下无法正常获取。表现就是两台设备互相找不到、文件不动，而设备、密钥本身都没问题。同 Wi-Fi 下扫码同步不依赖这一环，不受影响；跨网场景则需要换一个能正常访问这些服务器的网络环境再试。
3. **密钥对不对**：重新在电脑端点分享，用新生成的二维码再扫一次。密钥本身不会过期，但两端加的必须是 **同一个文件夹的** 密钥——拿 A 文件夹的密钥在手机上加 B 目录是配不上的。
4. **路由器开了 AP 隔离 / 访客网络**：同一 Wi-Fi 但设备之间被路由器禁止互访，症状和跨网失败一样。关掉 AP 隔离，或把两台设备都接到主网络。

## 三、文件少了一份 / 某个文件不同步

逐项排除：

- **检查两端文件夹路径是否都对**：手机端在应用里点开该文件夹能看到「本机路径」，路径被系统回收（比如指向了已卸载的 SD 卡）时，同步会静默停住。
- **检查空间**：任一端磁盘/存储满了，新文件写不进去。Resilio Sync 对文件大小没有限制，但每台设备都得有装得下整个文件夹的空间。
- **文件名特殊字符**：Windows 与安卓对文件名合法字符的要求不同，名字里带 `? * : " < > |` 的文件在跨系统同步时会失败。改个名字重试即可。
- **只读权限**：用只读密钥加入的一端改动不会回传（权限说明见 [手机和电脑同步教程.md](手机和电脑同步教程.md)）。

## 四、误删的文件在所有设备上都没了

这不是故障，是同步的本性：**同步不是备份**。读写权限下，一端删除、另一端跟着删除。发生之后的补救：

1. 立刻停止操作那台删错的设备，避免继续覆盖；
2. 检查电脑端是否开了文件版本归档（部分版本的高级设置里有「归档被删除/修改的文件」类选项，有的话旧版本还在归档目录里）；
3. 都没有，就只能从你自己的其他备份（另一块硬盘、网盘相册等）恢复。

防患办法：往同步文件夹里放「只读端」的另一台设备当底账，或者干脆别把唯一副本放进读写同步目录。

## 五、密钥发错了人 / 手机丢了怎么办

Resilio Sync 的密钥就是门禁卡——谁拿到谁能进。按事故严重程度处理：

1. **只是发错了对象、对方还没加入**：赶紧作废旧密钥——在电脑端该文件夹里重新生成一把新密钥，旧的分享链接与密钥立即失效。
2. **对方已经加入了**：在该文件夹的授权设备列表里找到它、移除，它会立刻断开并失去后续内容。
3. **手机整个丢了**：先在电脑端移除丢失设备，再按上一条重新生成密钥，把其余正常设备用新密钥重新加一遍。丢的那台手机上已经同步过去的文件，软件层面收不回来——只能靠远程擦除或改存储密码，这部分属于手机本身的防护能力，与 Sync 无关。

两种撤销操作的具体说明见 [手机和电脑同步教程.md](手机和电脑同步教程.md) 第四节。养成两个习惯能少遇这类事：给别人的永远用只读或限时密钥，长期密钥只留在自己的设备之间。

## 六、装完点开闪退 / 装不上

- **闪退**：先确认包名是 `com.resilio.sync`、手机系统 ≥ Android 5.2（本篇安装包的实测信息见 [下载与安装教程.md](下载与安装教程.md)）。仍闪退时，进系统设置 → 应用 → 存储，清一次缓存再开；从旧版本覆盖上来的，清缓存不影响已配对的文件夹。
- **安装被拦**：是「未知来源安装」权限没给，不是包有问题；按安装页的提示给浏览器或文件管理器授权即可。
