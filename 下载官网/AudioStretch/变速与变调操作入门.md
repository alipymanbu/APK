## 一、先把文件导进来

打开应用后点左上角的 `+`（或右上角三点菜单里的导入项），从设备文件、音乐管理器或已装的云盘客户端里挑一个音频/视频文件。两点容易踩坑：

- 文件必须**实际存在手机存储里**。只有在线流媒体播放列表里的歌（比如音乐 App 的会员曲库）不会出现在列表里，具体原因见[常见问题解答.md](常见问题解答.md)。
- 格式不在支持清单里会导入失败或没声音，先确认你的文件类型，清单见[支持的格式与导入导出.md](支持的格式与导入导出.md)。

导入成功后，界面主体就是这首歌的波形，底部是控制区。

## 二、改速度

速度控制区位于左下角，可调范围从 -10 倍到 10 倍（负值即倒放），改速度时音调保持不变。各个手势的作用：

| 手势 | 效果 |
| --- | --- |
| 点 `-` / `+` | 每次降/升 5% 速度 |
| 左右拖动数字 | 细微连续调节 |
| 双击数字中间 | 速度瞬间归零（停在该位置逐音听） |
| 长按数字中间 | 回到原始速度 |

几个实用组合：

- **练琴跟练**：先用 `+`/`-` 降到 70%~80%，能跟上了再逐步回原速；
- **听清某个和弦**：双击把速度钉在 0，配合按住波形慢慢挪（也就是 LiveScrub，见[LiveScrub精听与扒谱方法.md](LiveScrub精听与扒谱方法.md)）；
- **做速度实验或倒放**：把数字拖到负值区间即可反向播放。

## 三、改音调

音高控制区位于右下角，整体升降调范围 ±36 个半音，改音调时速度保持不变：

| 手势 | 效果 |
| --- | --- |
| 点 `♭` / `♯` | 每次降/升 1 个半音 |
| 左右拖动数字 | 以音分（cents）微调 |
| 双击数字中间 | 在「当前调整值」与「原始音调」之间来回切换，方便对比 |
| 长按数字中间 | 回到原始音调 |

典型用法：

- 唱歌降 key：原曲太高，整体降 2~3 个半音跟着唱，音与音之间的相对关系不变；
- 对齐调性：把伴奏升/降到你的乐器调性（比如把 C 调伴奏降到 G 调）；
- 双击对比：调完想确认有没有跑偏，双击切回原始音调听一遍，再双击切回调整值。

## 四、播放与走带控制

底部走带条负责常规播放操作：播放/暂停、快进、快退；在进度条或波形上左右滑动可直接跳到指定时间点。

## 五、把改好的结果导出

调到满意后，点右上角的下载（Download）按钮，当前这版调整结果（含速度与音高改动）会导出到你的设备。导出文件的去向与再导入方法，见[支持的格式与导入导出.md](支持的格式与导入导出.md)。

另外，如果你同时在使用 BandLab：在它的 Studio 里选中某条音频区域后右键选 AudioStretch，菜单里先给 ±1 个半音、±10% 速度的快捷项，点「More」展开完整面板再细调 Speed 与 Pitch，完成后点 Apply 应用或 Undo Changes 撤销，调整结果可以直接留在编曲工程里继续用。
