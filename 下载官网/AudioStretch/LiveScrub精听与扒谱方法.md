# AudioStretch LiveScrub 精听与扒谱方法

> 本篇集中讲 AudioStretch 里为「扒谱、逐音精听」服务的几个功能：LiveScrub 按住波形逐音听、标记打点、A/B 循环反复磨一段、频谱键盘认音，最后串成一套完整的扒谱流程。

## 一、LiveScrub：按住波形逐音听

建议把它放在第一个学。操作方式：

- **手指按住波形并拖动**：声音跟着你手指的位置走，挪多快听多快——快速滑过就听到一串被压缩的音符，缓慢挪动就能把每个音分开听清；
- **按住不动**：播放冻结在零速，你停在哪就反复响哪个音；
- **按住波形上的同一位置再微调**：相当于在零速附近「搓盘」，对付密集的快速乐句尤其有效。

和「降速播放」的区别：降速播放（操作见[变速与变调操作入门.md](变速与变调操作入门.md)）仍然按时间轴走，适合跟练；LiveScrub 完全由手指控制，适合「这一小节第 3 个音到底是什么」这类定点确认。

## 二、标记与 A/B 循环

对付反复出现的难句，靠来回拖波形找位置效率很低，用打点和循环：

| 操作 | 做法 |
| --- | --- |
| 打一个标记 | 在目标位置点 Pin（图钉）按钮 |
| 清除全部标记 | 长按 Pin 按钮 |
| 设循环起点 | 在起始位置点 A |
| 设循环终点 | 在结束位置点 B |
| 开启/关闭循环 | 点 Repeat（循环）按钮 |
| 重置 A/B | 长按 A 或 B 回到默认位置 |

典型场景：副歌有一段 4 小节的转换总弹不顺——设好 A/B 后开启循环，再把速度降到 75%，循环里反复磨，练顺了再逐步提速、缩小范围。

## 三、频谱键盘：认出正在响的音

打开键盘/频谱视图后，当前播放位置的声音会被显示到一组琴键上：哪个键亮，你听到的就是哪个音；泛音列也会在对应位置显示出来。对扒谱者的实际价值：

- 快速段靠耳朵听不准时，看亮起的琴键直接确认音名；
- 分不清「这个音是主音还是泛音」时，看能量分布——主音位置的能量条通常显著更强；
- 移调练习时配合音高调整，确认当前实际音高落在哪个键。

## 四、串起来：一套常用的扒谱流程

1. 导入歌曲，先原速整体听一两遍，找到要攻的段落；
2. 在段落两端打 A/B 并开启循环；
3. 速度降到 60%~80%（不影响音调，该是哪个键还是哪个键）；
4. 仍听不清的音符，双击速度数字把播放钉在 0，用 LiveScrub 按住波形逐音搓；
5. 对照频谱键盘确认音名；
6. 难点单独打标记（Pin），方便下次直接跳回；
7. 全部确认后把速度调回原速完整过一遍，需要留存就导出（导出说明见[支持的格式与导入导出.md](支持的格式与导入导出.md)）。

导入的如果是视频（比如教学演示、演奏录像），以上每一步同样适用，画面会伴随播放。文件加载不出来时先看[常见问题解答.md](常见问题解答.md)。
