## 一、音频格式清单

按官方帮助中心的口径，音频文件的支持情况是：

| 格式 | 能否导入 |
| --- | --- |
| WAV | 可以 |
| AIFF | 可以 |
| MP3 | 可以 |
| M4A | 可以 |
| FLAC | 官方清单未列出，以你手上版本实测为准 |
| WMA | **不可以** |

手上有 WMA 文件（比如从 Windows 自带的录音或老播放器里导出的），先用格式转换工具转成 MP3 或 WAV 再导入，否则会导入失败。

FLAC 在官方格式清单里没有被列出。这个格式很常见，如果你的文件导入后无法播放，不要反复重试，转成 MP3/WAV 是最省事的路径。

## 二、视频格式

视频方面，常见的主流格式都能导入，导入后画面与波形一起播放，变速、变调、LiveScrub、循环这些操作对视频同样生效。典型用法：

- 把演奏示范视频慢速逐帧模仿；
- 用手机相机现场拍一段视频直接导进应用里分析（App 内支持调用相机录制）；
- 做慢放/倒放类的短视频素材。

## 三、从哪里导入

点左上角 `+` 后，可选的来源取决于你手机上装了什么：

- **本机存储**：文件管理器里的音频/视频文件，以及本机音乐库里的歌曲；
- **云盘客户端**：装了对应 App（如 Google Drive、Dropbox、OneDrive 等）就能从那里取文件；
- **相机直录**：不用先拍再导，App 内可以直接录。

关键前提只有一条：**文件要实体存在于设备上**。音乐 App 会员曲库里的歌只是「能播」，本地并没有音频文件，所以不会出现在可导入列表里——这不是故障，是硬性限制。

## 四、导出与文件去向

调完速度/音调后点右上角的下载（Download）按钮，改动结果会导出成新的音频文件到设备存储。导出后的常见去处：

- 用文件管理器在常用媒体目录（如 `Music`、`Download`）下找；
- 拿去别的 App 继续加工：作为伴奏导入剪辑软件、作为采样导入编曲应用都行；
- 需要传回电脑时走数据线或任意网盘客户端。

## 五、导入失败或没声音的排查顺序

遇到「列表里根本没有这首歌」或「导进去了但没声音」，按这个顺序查：

1. **是不是流媒体曲目**——只能播、没实体文件的歌导不进来，先把它下载到本机或换成有本地文件的版本；
2. **是不是 DRM 保护**——部分平台的下载内容带版权保护（官方帮助中心点名了 Apple Music 的歌曲无法加载），这类文件即使下载到本机也读不出音频，无解，只能换无 DRM 的来源；
3. **格式是否在支持清单里**——WMA 直接排除，其他不认识的扩展名先转成 MP3 再试；
4. **文件是否完整**——传输中断生成的半截文件会导入失败，核对大小或重新传输一次。

排查后仍导入不了的具体问题，可以到[常见问题解答.md](常见问题解答.md)对号入座；操作层面的疑问则在[变速与变调操作入门.md](变速与变调操作入门.md)里。
