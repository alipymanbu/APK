## 一、能接哪些大模型

AstrBot 框架同时兼容 OpenAI、Google、Anthropic 三种原生 API 接口，外加一切「OpenAI 兼容」的第三方接口。落到实际选择上：

| 你的情况 | 可选的接法 |
| --- | --- |
| 有国外大平台的账号 | OpenAI（GPT 系列）、Google Gemini、Anthropic（Claude）原生接口 |
| 用国产模型 | DeepSeek、智谱（GLM）、Kimi、MiniMax 等，多走 OpenAI 兼容接口 |
| 想跑本地模型、不花 API 钱 | Ollama、LM Studio 里部署的开源模型（Llama 等），填本机或局域网地址 |
| 有现成的智能体应用 | Dify 等应用可直接接入 |

填写位置与步骤见 [QQ登录与密钥配置步骤.md](QQ登录与密钥配置步骤.md) 的「填大模型密钥」一节。各家模型的价格、免费额度、可用性随时会变，接入前以对应平台当时的页面为准。

**API Key 从哪申请**（申请入口经核对，2026-09）：

| 平台 | 入口 | 备注 |
| --- | --- | --- |
| DeepSeek | `https://platform.deepseek.com/` | OpenAI 兼容接口，base_url 为 `https://api.deepseek.com` |
| 硅基流动 | `https://siliconflow.cn/` | 聚合多家开源模型的云平台，OpenAI 兼容，一个 Key 可调多家模型 |
| Ollama / LM Studio | 不需要 Key | 跑在你自己的设备上，填本机或局域网地址即可 |
| OpenAI / Gemini / Claude | 各自的开放平台 | 需要相应的账号与网络条件 |

## 二、插件怎么装

插件在管理面板（WebUI）的插件页安装，一键装、一键卸。装好后机器人就多出对应技能，常见的有：

- 翻译、网页搜索——让机器人能查实时信息；
- 长期记忆、人设（persona）类——对话更像「一个固定的角色」；
- 社群管理、娱乐互动类——群里用得多。

插件市场的完整列表可以在浏览器打开 `https://plugins.astrbot.app/` 浏览，生态里有上千个插件，装之前看一眼插件页的说明与依赖。

## 三、安卓 App 的能力边界（装前想清楚）

安卓 App 为了「开箱即用」做了聚焦，代价是下面这些做不到或要变通：

| 能力 | 安卓 App | 说明 |
| --- | --- | --- |
| QQ 个人号变机器人 | 支持 | 当前版本唯一支持的消息平台；第三方协议接入的账号风险见 [封号风险与账号安全.md](封号风险与账号安全.md) |
| 微信 / Telegram / 钉钉等平台 | 不支持 | 这些平台需要自行部署完整版 AstrBot |
| 代码执行器（沙箱） | 默认不可用 | 依赖 Docker 环境，安卓上的容器默认未安装 |
| 图形化配置 | 支持 | 内置 WebView，全部设置在手机上完成 |
| 插件扩展 | 支持 | 翻译、搜索、记忆等可正常装用 |
| 后台常驻 | 支持 | 息屏、切后台不断线，前提是常驻通知不被清 |

也就是说：**只想要一个 QQ 上的 AI 机器人，安卓 App 够用**；要接多平台、跑代码沙箱，就得看电脑/服务器部署了，两种路线的取舍见 [和电脑版部署有什么区别.md](和电脑版部署有什么区别.md)。

## 四、知识库、MCP 这些高级功能能用吗

知识库（RAG）、MCP、工具调用这些属于 AstrBot 框架层面的能力，管理面板里有对应入口；但在安卓 App 上，实际效果取决于手机性能与该功能对运行环境的要求——代码执行器就是典型的环境依赖例子。建议用到哪项试哪项，别按电脑版的预期照搬。
