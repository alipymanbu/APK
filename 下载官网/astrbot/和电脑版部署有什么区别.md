## 一、一句话结论

只想在 QQ 上挂一个自动回复的机器人、手头没有常开的电脑 → 用安卓 App；要接多个聊天平台、跑代码沙箱、追求长期稳定挂机 → 用电脑或服务器部署官方版。两者不冲突，安卓 App 玩熟之后想迁移到服务器，配置思路是相通的。

## 二、差异对照表

| 维度 | 安卓 App（本系列文档） | 电脑 / 服务器部署（官方原版） |
| --- | --- | --- |
| 部署门槛 | 装 APK，全自动初始化 | 要装 Python 3.12+ 或 Docker，按文档操作 |
| 是否需要命令行 | 不需要 | 大多数方式需要一点 |
| 支持的消息平台 | 仅 QQ 个人账号 | QQ、企业微信、飞书、钉钉、Telegram、Discord、Slack 等 |
| 代码执行器（沙箱） | 默认不可用 | 支持（依赖 Docker） |
| 插件、人设、知识库 | 支持 | 支持，功能最全 |
| 挂机方式 | 跟着手机走，需做保活设置 | 服务器上可长期不间断运行 |

## 三、两种路线各自的来历

官方 AstrBot 框架由 AstrBotDevs 开源维护，采用 AGPL-3.0 许可证，官方文档在 `https://docs.astrbot.app/`，提供 uv 一键部署、Docker、桌面 App、启动器等多种安装方式。若把修改后的框架用于商业性网络服务，按许可证要求需要开源所做的修改。

安卓 App 是社区开发者（zz6zz666）基于框架做的封装：把 AstrBot 核心、NapCatQQ 适配器和 Ubuntu 容器环境打成一个 APK，项目本身采用 BSD-3-Clause 许可证。**AstrBot 官方文档把它收录在「社区提供的部署方式」一节，并注明官方不对社区方案的安全性与稳定性背书**——这句话的含义是：它能正常用，但出问题时别去找官方框架的锅。

## 四、怎么选

- **选安卓 App**：手机就是全部家当；只想让 QQ 号变智能；不想学命令行；能接受偶发出问题时重启或清数据重来。
- **选电脑/服务器**：机器人要服务一个群或一个团队；要接微信生态、Telegram 等多平台；需要代码沙箱这类完整能力；打算长期不关机。

安卓 App 上的模型提供商、插件、人设这些概念与官方版完全一致，迁移成本主要在环境搭建那一步。装安卓版的完整过程见 [下载与安装教程.md](下载与安装教程.md)，装好后怎么用见 [QQ登录与密钥配置步骤.md](QQ登录与密钥配置步骤.md)。
