## 一、指令都长什么样

指令以「唤醒前缀」开头，默认是斜杠 `/`。你在 WebUI 里改过唤醒前缀的话，指令也要跟着换——比如改成 `!` 之后，`/help` 就得写成 `!help`。

| 指令 | 作用 | 权限 |
| --- | --- | --- |
| `/help` | 查看当前实际可用的指令清单和版本信息 | 所有人 |
| `/sid` | 查看当前会话来源、你的用户 ID（加管理员要用） | 所有人 |
| `/new`、`/reset` | 开一个全新对话（两者等价） | 所有人 |
| `/stop` | 停掉当前会话正在跑的任务 | 所有人 |
| `/stats` | 看当前会话的 Token 用量 | 所有人 |
| `/provider` | 查看 / 切换大模型提供商 | 管理员 |
| `/name 别名` | 给当前会话起个可识别的名字 | 管理员 |
| `/dashboard_update` | 更新 WebUI 面板 | 管理员 |

AstrBot 为了保持核心轻量，主程序只内置这一小撮指令；管理类、扩展类指令大多在插件里。所以装完插件之后用 `/help` 看到的清单，才是你真正可用的全部——比你预期的短是正常的。

## 二、三个马上要用的场景

**1. 把自己设成管理员。** 先给机器人发 `/sid`，输出里有你的用户 ID（UID）；再到 WebUI「配置 → 其他配置 → 管理员 ID」里把这个 UID 填进去。管理员才能用 `/provider`、`/name` 这类指令。

**2. 对话聊歪了、想重来。** 发 `/reset`（或 `/new`）开新对话。换过人设、改过提示词之后也建议来一次——旧对话的上下文还带着原来的设定，新对话才是干净的。

**3. 任务卡住了。** 发 `/stop` 停掉当前正在跑的任务，再发别的消息试试；还卡就去看 WebUI 的日志页，排查思路见 [初始化失败与常见问题.md](初始化失败与常见问题.md)。

## 三、在群里和私聊里有什么不一样

- **私聊**：通常直接说话它就会接；
- **群聊**：要看唤醒规则——默认靠唤醒前缀或 @ 机器人触发，光 @ 它聊天之前先拿 `/help` 验一下。

拿不准就发一条 `/help`：它回了，说明整条链路是通的，剩下的只是唤醒方式问题；不回，去 [初始化失败与常见问题.md](初始化失败与常见问题.md) 排查。

## 四、人设怎么换

人设（persona）在 WebUI 的配置里编辑：名字、提示词可以按人设各配一套，改完回 QQ 里发 `/reset`，让新设定从干净的上下文生效。换模型不用动人设，用 `/provider` 直接切（管理员），可接的模型范围见 [支持的模型和插件.md](支持的模型和插件.md)。
