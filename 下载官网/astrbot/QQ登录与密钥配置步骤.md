## 一、操作总览

整个接入过程五步：允许通知权限 → QQ 扫码登录 → 登录控制台并改密码 → 确认内置通信接口 → 填大模型密钥并重启。前两步在 App 界面上完成，后三步在内置的管理面板（WebUI）里完成。

## 二、QQ 扫码登录

1. 打开 App，允许通知权限（如果初始化时没给，现在给也行）；
2. 等 NapCatQQ 与 AstrBot 服务同步启动完成，屏幕会**弹出 QQ 登录二维码**；
3. 用你手机上的 QQ 扫码登录。扫码过程中可以自由切后台（比如切到 QQ 去扫），返回 App 后会话不丢；
4. 登录成功后二维码窗口自动消失，App 内置 WebView 打开 AstrBot 管理面板。

一个容易踩的「假故障」提前说：App 里的机器人走的是 QQ 电脑端协议，**扫码之后别再在电脑 QQ 上登录同一个号**，两边互挤会把机器人挤下线；手机 QQ 与它互不影响。背景见 [封号风险与账号安全.md](封号风险与账号安全.md)。

二维码一直不弹的话，多半是初始化时 napcat 组件没装好——关掉 App 重新打开，基本能自愈，详见 [初始化失败与常见问题.md](初始化失败与常见问题.md)。

## 三、首次登录控制台

- 默认用户名：`astrbot`
- 默认密码：`astrbot`

登录后**立即改密码**，面板会引导你改。这个面板就是你以后管理机器人的地方：配置、日志、插件都在里面。面板只是管理端，平时在 QQ 里怎么跟机器人对话、有哪些口令，见 [常用指令与日常用法.md](常用指令与日常用法.md)。

## 四、别动那条 pre-config 通信接口

在管理面板的「机器人」→「通信接口」里，有一条名为 `pre-config` 的接口——它是 App 内置的 NapCatQQ 连接通道，QQ 消息全靠它进出。**不要修改、不要删除**，删了机器人就和 QQ 断了，App 里也没有向导帮你重建。

## 五、填大模型密钥（唯一要动手配的地方）

1. 在管理面板进入「模型提供商」（Provider）页面；
2. 新增一个提供商，选你手里的服务：OpenAI、Anthropic（Claude）、Google Gemini、DeepSeek、智谱、Ollama 本地模型，或任何 OpenAI 兼容接口、Dify 应用都行，各家支持情况见 [支持的模型和插件.md](支持的模型和插件.md)；
3. 粘贴该平台发给你的 API Key，选一个默认模型，保存；
4. 保存后按提示**重启机器人**，配置才生效。

API Key 需要你自己到对应平台的开放平台页面申请，价格与免费政策随时会变，以各平台当时的页面为准。

## 六、运行状态确认

一切就绪后，通知栏会挂一条「正在运行」的常驻通知。它是机器人的命脉：**这条通知不能手动清除**，清掉服务就停了；反过来，只要它在，息屏、切后台、锁屏都不影响收发消息。

想验证真的通了：用另一个 QQ 号（或让朋友）给你的机器人号发条消息，看它是否自动回复。能回，整条链路就通了；不回，先看管理面板的日志页，再到 [初始化失败与常见问题.md](初始化失败与常见问题.md) 对着排查——如果日志没有报错，想想这个号是不是刚在电脑 QQ 上登录过，详见 [封号风险与账号安全.md](封号风险与账号安全.md)。
