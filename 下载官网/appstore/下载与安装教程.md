## 一、安装前先核对这些信息

你拿到的安装包应该与下表一致。版本号、大小、包名以安装包本身为准，网上搜到的「最新版」可能是另一条更新线。

| 项目 | 值 |
| --- | --- |
| 版本 | 3.0.0 |
| 安装包大小 | 15.15M |
| 包名 | com.yfzy.appstore |
| MD5 | A87C56791F9346AC244B0D22DDBD3ACC |
| 系统要求 | 安卓 5.2 以上 |
| 开发商 | 深圳市远方卓越科技有限公司 |

版本 3.0.0 在第三方收录页的更新说明只有一句：首次发布的可执行版本。也就是说 3.x 这条线没有更早的旧版可回退，装完出问题只能卸载重装（见[无法连接怎么办.md](无法连接怎么办.md)）。

## 二、获取安装文件

安装包从网盘转存获取：

1. 打开上面的 **appstore 安装文件资源（夸克网盘）** 链接；
2. 登录你的夸克账号（没有就现场注册一个，免费）；
3. 点「保存到网盘」把文件转存到自己网盘，再从网盘里下载到手机存储；
4. 也可以先转存到网盘后，用电脑下载，再通过数据线或聊天工具传到手机。

手机浏览器直接打开网盘链接也能下载，但夸克网页端通常有限速，转存后用客户端下载更快。

## 三、放开「未知来源」安装权限

这个应用不在你手机自带的应用商店里，安装时系统会拦一道。你需要先允许「从陌生来源安装」，不同系统的入口不同：

| 系统 | 入口 |
| --- | --- |
| 原生安卓 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |
| 小米 / 红米 | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / 真我 | 设置 → 安全 → 安装未知应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 应用安装 |

推荐的做法是只给「文件管理器」或浏览器这一个应用放行，而不是全局打开「允许安装未知应用」总开关——装完这次之后，把放行再关掉。

## 四、安装步骤

1. 在文件管理器里找到下载好的 `appstore_v3.0.0.apk`；
2. 点它，系统弹出「是否安装此应用」，点继续；
3. 首次安装会触发上一节的权限确认，按提示跳到设置里放行，返回后重试；
4. 等进度条走完，点「打开」或回桌面点图标。

如果点安装包没反应，先确认第三节那个权限已经给到位；如果提示「解析包失败」，多半是下载没下完整，重新下载一遍再装。

## 五、核对安装包有没有被换过

每个 APK 文件都有唯一的 MD5 值，和第一节的表格对得上就说明文件完好。在电脑上核对最方便（Windows 自带工具）：

```powershell
certutil -hashfile "appstore_v3.0.0.apk" MD5
```

输出第二行那串十六进制，忽略大小写与空格后应该等于 `A87C56791F9346AC244B0D22DDBD3ACC`。对不上就别装，重新下载一次再核对。

装完之后第一次打开，如果出现连不上、页面空白之类的情况，直接看[无法连接怎么办.md](无法连接怎么办.md)；想先搞清楚它跟苹果那个 App Store 是不是一回事，看[安卓能用吗.md](安卓能用吗.md)。
