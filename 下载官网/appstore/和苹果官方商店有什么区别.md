# App Store 和苹果官方商店有什么区别

> 名字一字不差，但这是两家公司的两个产品：一个是深圳市远方卓越科技有限公司出的安卓应用商店，一个是苹果自带的 iOS 应用商店。这篇把区别逐项列出来。

## 一、逐项对照

| 对比项 | 本篇说的 App Store（安卓版） | 苹果官方 App Store |
| --- | --- | --- |
| 开发商 | 深圳市远方卓越科技有限公司 | 苹果公司 |
| 运行平台 | 安卓 5.2 以上 | iPhone / iPad（iOS 系统自带） |
| 获取方式 | 下载 APK 安装（见[下载与安装教程.md](下载与安装教程.md)） | 系统预装，无需安装 |
| 账号要求 | 不需要 Apple ID | 需要 Apple ID |
| 内容库 | 国内常见软件与游戏为主 | 苹果审核上架的 iOS 应用 |
| 能否下载 iOS 应用 | 不能 | 能（仅限苹果设备） |
| 更新来源 | 开发商自行发布版本 | 随 iOS 系统更新 |

一句话总结：**它们除了名字，没有任何关系**。这款安卓版不是苹果的移植版、不是镜像、也不是什么「安卓版入口」，就是一个用了相同名字的第三方商店。

## 二、为什么会有两个同名产品

第三方应用起名时与知名产品撞名并不罕见。对苹果来说 App Store 是商标和系统组件；而这款安卓应用只是把「App Store」当作自己的展示名。第三方收录站在介绍它时通常都会专门标注「与苹果无关」「两款不同的应用」，检索时你看到的很多页面其实是混在一起讲的，这也是很多人误以为「安卓能装苹果商店」的来源。

分辨的办法很简单：看包名。苹果官方商店不存在 APK，也不会有 `com.yfzy.appstore` 这个包名——前缀 `com.yfzy` 对应的是这款安卓应用自己的开发商。另外，各下载站收录的这款应用版本号从 2.0.0 到 3.78.2 都有、体积差异很大，检索时认包名比认版本号靠谱（版本对照见[下载与安装教程.md](下载与安装教程.md)第六节）。

## 三、安卓上做不到的那些事

如果你装它是为了下面这些期待，先泼冷水：

- **在安卓手机上运行 iOS 应用**：做不到。iOS 应用是给苹果系统编译的，安卓系统读不了，中间不存在「转换器」；
- **用安卓手机登录 Apple ID 下应用**：做不到。Apple ID 的下载体系只在苹果设备上生效；
- **在安卓上看苹果商店**：只能看不能装。用浏览器打开苹果官方的网页版商店（`https://apps.apple.com/cn/`）可以浏览中国区榜单和应用介绍，但页面上没有可下载的安装包。

## 四、那它适合什么人

它适合的就是「安卓手机上想多一个找应用的入口」这件事本身：榜单、搜索、分类、同开发者应用，功能就是普通商店的那一套，见[排行榜和搜索怎么用.md](排行榜和搜索怎么用.md)。装不装取决于你信不信第三方渠道，权衡点写在[安卓能用吗.md](安卓能用吗.md)第四节。
