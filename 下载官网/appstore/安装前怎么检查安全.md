# 安装前怎么检查安全

> 从商店之外装 APK，安全检查要自己做。这篇是一份按顺序执行的清单：核对 MD5、多引擎扫描、看权限要得对不对、装完观察什么信号、出事怎么止损。

## 一、为什么这一步要自己把关

系统商店里的包上架前有平台扫描这道工序；从网盘或网页拿到的 APK 没有。文件是不是原封未动、要的权限合不合理，都得你在点「安装」之前自己判断。这套清单是通用的 APK 检查流程，适用于任何第三方安装包，不只这一款。

## 二、第一步：核对 MD5，确认文件没被换过

这款应用 3.0.0 版安装包的 MD5 是 `A87C56791F9346AC244B0D22DDBD3ACC`，核对方法在[下载与安装教程.md](下载与安装教程.md)第五节（Windows 用 `certutil`，macOS 用 `md5 文件名`）。

两点要清楚：

- 对不上 → 下载或传输环节出了问题，也可能被掉包，别装，重新获取；
- **对上了也不等于无毒**。MD5 只证明「文件和分发渠道给出的是同一份」，不能证明「这份本身干净」，所以还需要后面两步。

## 三、第二步：多引擎扫描

用 [VirusTotal](https://www.virustotal.com/)（免费网页服务）：把 APK 上传上去，几十个杀毒引擎同时扫一遍，几十秒出报告。

判断口径：

- **两三个以上引擎报毒** → 放弃，别装；
- 个别引擎报「风险程序 / PUP」一类 → 常见误报，结合下一节权限一起判断；
- 先扫后装，顺序别反——装完再扫，恶意行为可能已经发生。

手机上如果装了安全类 App 也可以扫，但引擎数量和更新频率一般不如网页版全。

## 四、第三步：看权限要得对不对

一个应用商店类应用，正常需要的权限大概是：网络、存储（保存和安装包体）、查看应用列表。安装时系统弹出的权限清单里出现下面这些，就要警惕：

| 权限 | 商店类应用为什么不需要 |
| --- | --- |
| 短信 / 通话记录 | 与下载分发无关，是扣费类恶意应用的常用入口 |
| 无障碍 | 能替你点屏幕、读取屏幕内容，盗刷场景常用 |
| 设备管理器 | 会让应用难以正常卸载 |
| 悬浮窗 | 常被用来在别的应用上面伪造登录界面 |

命中任何一条 → 不装。权限以你实际安装时系统弹出的为准，不同版本要的权限可能不同。

## 五、第四步：装完之后观察几天

- **耗电与流量**：到系统设置的电池、流量排行里看它有没有异常的后台活动；
- **弹窗与通知**：锁屏弹广告、通知栏出现没见过的推广；
- **多出来的应用**：桌面出现你没装过的图标；
- 任何一条命中 → 直接卸载，卸载前先把它的存储、无障碍等权限关掉。

## 六、真出事时的止损顺序

1. 卸载应用（设置 → 应用里正常卸载；如果卸载按钮是灰的，先在「设备管理器」里取消它的激活）；
2. 用手机自带的安全中心做一次全盘查杀；
3. 它本身不需要你登录账号，但如果你在其他应用里输过密码、又出现过第四节的红旗权限，改一遍重要账号的密码；
4. 核对近期的账单和话费，有没有不明扣费。

安装环节本身（怎么放行未知来源、怎么装）在[下载与安装教程.md](下载与安装教程.md)；装完之后用着用着出的问题，在[无法连接怎么办.md](无法连接怎么办.md)。
