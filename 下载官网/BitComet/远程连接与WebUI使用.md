# BitComet 安卓版远程连接与 WebUI 使用

> 本篇讲怎么用手机上的 BitComet 远程管理电脑上的 BitComet 任务，以及怎么用浏览器打开它的 WebUI 网页端。

手机装它还有一个常见理由：人在外面，让家里的电脑挂着下载，用手机随时看进度、加任务、删任务。这套「远程连接」功能在手机端是内置的，配对一次以后长期可用。

## 一、远程连接能做什么

手机连上电脑端的 BitComet 之后，你可以：

- 看到电脑端全部任务及其进度；
- 在手机上往电脑端加新任务（磁力链接、种子都行）；
- 暂停、继续、删除电脑端正在跑的任务；
- 把电脑端已下载完成的文件下载到手机上（2.7.0 起这个传输支持暂停后继续）；
- 电脑端下完的视频可以直接在手机上播放，不用先传文件（官方安卓版更新日志里有这条能力，两端版本太老时不支持，以你设备上的实际界面为准）。

反过来，电脑端 BitComet 也有对应的「关联应用」入口，两边是同一套机制。

## 二、配对前的准备

| 准备项 | 说明 |
| --- | --- |
| 电脑端 BitComet | 版本别太老，官方更新日志里对远程连接标注过「需要 v1.96 或更高」的要求 |
| CometID 账号 | 官方账号体系（彗星通行证），手机端与电脑端登录同一个账号 |
| 同一局域网 | 第一次配对最省事的做法，手机和电脑连同一个 Wi-Fi |

CometID 的注册与登录入口在手机端侧边菜单和电脑端通行证面板里都有，注册用手机号或邮箱即可（以官方页面实际流程为准）。

## 三、扫码配对（推荐方式）

两端都登录好 CometID 后，按这个顺序操作：

1. **电脑端**：主界面工具栏点「关联应用」，确认开启远程访问，弹出的配置窗口里选「绑定应用」标签页，屏幕上会显示一个二维码。
2. **手机端**：打开侧边菜单，进「远程连接」，点「扫描二维码」，对准电脑屏幕扫一下。
3. 配对成功后，手机端的远程连接列表里会出现这台电脑，点进去就是电脑端的任务列表。

较新的电脑端在扫码绑定时会让你选「直连」或「云服务」模式：直连走同一局域网、延迟低；云服务用于手机在外面、或路由器打不通端口的场景。两条路可以都留着，连不上时换另一条。

之后只要电脑端开着 BitComet，你在外面的 4G / 5G 网络下也能连回去——公网访问走的是账号绑定的云端服务，2.0.0 版起对所有 CometID 用户开放，不需要你在路由器上做端口转发；如果你的网络环境下云服务不稳定，也可以改走路由器端口转发，但那属于进阶做法，一般不用。

## 四、用浏览器访问 WebUI

它还内置了一个网页端（WebUI），场景和远程连接互补：手机端自己开一个 WebUI 服务，你在**电脑的浏览器**里输入手机管理页地址，反过来用电脑看手机上的下载；电脑端 BitComet 的 WebUI 则让你在任意浏览器里管理电脑端任务。

- 手机端在设置页里有 WebUI 相关设置（2.4.0 起支持从浏览器访问），开启后会给出访问地址与账号口令，照着填就行。
- 电脑端浏览器打开这个地址，登录后就能看到手机端的任务列表。
- 2.7.0 的 WebUI 里已经带 BT 任务配置页，网页端不只是能看，还能改任务设置。

两个使用建议：访问口令别设太简单——WebUI 开着时，同一网络里的人都能摸到这个页面；用完不常用就把 WebUI 开关关上，需要时再开。

## 五、连不上时

按出现环节查：

- **扫码后连不上**：先确认两端登录的是同一个 CometID；再确认电脑端 BitComet 正在运行且版本不低于 1.96。
- **同一 Wi-Fi 下连不上**：部分路由器开了「AP 隔离」会拦设备互连，关掉再试。
- **外面连家里连不上**：确认家里那台电脑开着、BitComet 没退出；云服务状态可以在电脑端统计页看。
- 其他奇怪的下载问题（没速度、卡进度）与远程连接无关，去 [常见问题排查.md](常见问题排查.md) 查。
