先说清楚装的是什么：这是安卓平台上一款叫「App Store」的第三方应用商店（版本 2.0.0，安装包约 5.87 MB），界面为中文，不是苹果设备上的官方 App Store。iPhone 装不了这个包，下面的步骤只适用于安卓手机与平板。

## 一、装之前先对一下条件

| 项目 | 说明 |
| --- | --- |
| 设备 | 安卓手机或平板 |
| 系统 | 第三方收录站标注为安卓 4.4 及以上，以实际安装为准 |
| 安装包体积 | 约 5.87 MB |
| 版本 | 2.0.0（以下载到手的这份为准；网上可能已有更新版） |

## 二、从网盘拿到安装文件

安装文件资源在这里：[App Store 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f12e548f7232)。

1. 打开上面的链接，手机上会唤起夸克网盘；没登录的话先登录自己的账号；
2. 点「转存」把文件存进自己的网盘（转存后资源不会被收回，比直接下载稳）；
3. 打开网盘客户端的「我的网盘」，找到刚转存的安装包（文件名形如 `app store_v2.0.0.apk`，以网盘内实际显示为准），点「下载」存到手机存储；
4. 下载完成后，从通知栏或网盘客户端的传输列表可以直接点开。

## 三、允许安装来自这个来源的应用

安卓默认不允许安装应用商店之外的包，第一次安装会弹「禁止安装」提示，按下面放开：

1. 安装被拦时，直接点提示里的「设置」进入授权页；
2. 也可以提前开：**设置 → 应用管理 → 特殊应用权限 → 安装未知应用**，给你用来打开安装包的那个应用（文件管理器或网盘客户端）授权；
3. 各品牌入口略有差异：小米在「更多设置」、华为在「安全」、OPPO 与 vivo 多在「安全与隐私」里，找不到就在设置里搜「未知」两个字。

## 四、安装与首次打开

1. 在文件管理器里点开下载好的安装包；
2. 确认安装，等进度走完；
3. 打开后从底部栏目切到「应用」「游戏」等板块，能刷出列表就说明正常了。

## 五、顺手核对一下包（可选）

不确定包是否完整时，核对这三项：

- 版本：2.0.0
- 体积：约 5.87 MB
- MD5：`8351e1be0b25d31803f1acb1870bdd82`

MD5 在多数文件管理器里长按文件选「详情」或「属性」就能看到；手机自带的文件管理没有这一项时，装一个校验类小工具来读。对得上说明包没有损坏，对不上就回[第二节](#二从网盘拿到安装文件)重新取一份。

装好之后去哪找内容，看[怎么下载游戏.md](怎么下载游戏.md)；安装或打开时报错，先翻[常见问题与解决办法.md](常见问题与解决办法.md)。
