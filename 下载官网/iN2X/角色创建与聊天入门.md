# iN2X 角色创建与聊天入门

> 登录进 iN2X 之后，主线玩法就两件：挑一个现成角色开始聊，或者自己捏一个专属角色。本篇把界面入口、聊天功能、建角色的步骤一次讲清。

## 一、先认一下主界面

还没登录的先看 [注册登录方式有哪些.md](注册登录方式有哪些.md)；还没装好的看 [下载与安装教程.md](下载与安装教程.md)。iN2X 的主界面入口在不同版本里叫法略有出入，下面是公开教程里出现过的几个主要位置，名称以你手机上实际显示的为准：

| 入口 | 是干什么的 |
| --- | --- |
| 广场 / 物语 | 浏览现成的虚拟角色，按异世界、恋爱、悬疑、热血等主题分类 |
| 车间 | 故事创作引导，分步骤帮你设计情节与角色，想自己写故事的用 |
| 集市 / 发现 | 看别人创作的角色、漫画片段、插画壁纸，也能上传自己的作品 |
| 我的 / 个人资料 | 自己的账号信息 |

第一次用不用每个都点一遍，直接从「广场 / 物语」挑角色开聊就是最快的上手路径。界面打开是日文的，先看 [日文界面怎么设置中文.md](日文界面怎么设置中文.md)，认准入口再用这张表。

## 二、挑一个角色开始聊

1. 在广场里按主题挑一个感兴趣的角色。每个角色都有自己的设定：姓名、性格标签、身高生日、背景故事，点进去先扫一眼设定再决定；
2. 选一个想开始的故事；
3. 进入聊天界面。你回复什么、怎么选，会实打实影响剧情往哪个方向走，同一个角色能聊出不同的故事线；
4. 聊天记录自动保存，之后随时能翻回去。

角色是带记忆的：前面聊过的内容，后面的对话会被接回来引用，中途换话题它也认得上文。

## 三、聊天界面里的几个功能

| 功能 | 用处 |
| --- | --- |
| X 专业模式 | 对文本表现不满意时切换，回复质量更稳 |
| 读心术 | 直接看角色「心里在想什么」，不想猜剧情的时候用 |
| 语音 / 声音设置 | 给角色挑一个声音，部分版本还支持用自己的声音来定制 |

这些入口都在聊天界面里，一时找不到不用纠结 —— 功能是随版本逐步加进来的，旧版可能没有，界面叫什么以你手上的版本为准。

## 四、创建一个自己的角色

1. 在角色列表页点加号（+）；
2. 选创建角色，先添加形象、设定性别这些基础属性；
3. 补上性格标签和身世设定 —— 这两块写得越具体，角色在聊天里就越贴你想要的感觉；
4. 保存之后就能和它开始对话。

不会画画也不用担心：创建过程是选填属性，不需要动手画图。

## 五、剧情聊腻了想重来

主界面里有一个重置冒险类的入口（各版本叫法不同），作用是清空当前剧情、回到起点重新开始。注意它清掉的是**这条剧情线的记忆**，已经聊出来的故事内容不可恢复，动手前确认你不再需要这条线。数据相关的其他注意事项（聊天记录、换手机）汇总在 [常见问题与解决方法.md](常见问题与解决方法.md)。
