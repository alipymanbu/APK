# 日文界面怎么设置中文

> 装上 iN2X 打开发现界面是日文，多半不是手机的问题，而是这份版本本身没带中文。本篇讲原因、判断办法，以及日文界面上主要菜单的对照。

## 一、为什么打开是日文

iN2X 起初以日文界面为主，有教程提到 2.4.0 版本起才内置中文、装上打开就是中文。而网盘里这份 iN2X 安装文件资源是 2.0.0 版，早于这个节点 —— 打开后看到日文界面，符合这个时间线，不是你装错了，也不用怀疑手机设置。

## 二、先去设置里翻一遍语言选项

进设置（一般是主界面角落的齿轮或「設定」）找一找：

- 有「言語 / Language」这类选项 → 切成简体中文，收工；
- 没有语言选项 → 这个版本没带中文包，界面里改不出来，换新版本是唯一办法。

## 三、日文菜单对照

换版本之前想先把应用用起来，按下面这张表认入口（按功能含义整理，不同版本的入口名称或有出入）：

| 界面日文 | 含义 |
| --- | --- |
| 奇遇 | 开启一段新的剧情故事 |
| 自由に話そう | 自由聊天，不限定剧情走向 |
| 個性設定 | 个性设定：你在剧情里的名字与人设 |
| 冒険再開 | 重置冒险：清空当前剧情、回到起点重新开始 |
| 囁き | 私语：已建立联系的角色列表 |
| 発見 | 发现：浏览其他用户创作的作品 |
| プロフィール編集 | 编辑个人资料 |

中文版本里这些功能另有叫法（广场、物语、车间、集市等），功能对照见 [角色创建与聊天入门.md](角色创建与聊天入门.md) 的入口表。注意「冒険再開」这类带清空性质的入口别手滑点下去，后果在 [常见问题与解决方法.md](常见问题与解决方法.md) 第四节有说明。

## 四、换成中文版本要注意什么

1. 卸载旧版再装新版，或直接覆盖安装，两种都可以；
2. 装完用**同一种登录方式**登录，账号里的角色和聊天内容跟着账号走，换了方式等于换账号；
3. 新版本的获取与安装步骤见 [下载与安装教程.md](下载与安装教程.md)；装完登录不上、闪退这类问题去 [常见问题与解决方法.md](常见问题与解决方法.md) 对照排查。
