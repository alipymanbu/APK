## 一、四种连接方式怎么选

Yousician 的钢琴课支持真钢琴、电钢琴和不带音源的 MIDI 键盘，官方建议选 **61 键及以上**的键盘。四种接法对照：

| 接法 | 需要的东西 | 识别效果 | 适合谁 |
| --- | --- | --- | --- |
| 设备麦克风 | 无 | 一般，受噪音影响 | 真钢琴 / 先试试水 |
| USB 线直连 | USB B 线（方口，俗称「打印机线」），手机再配一个转接头 | 好 | 电钢琴 / MIDI 键盘，最省事的稳妥方案 |
| MIDI 圆口转接 | MIDI 转 USB 接口线 | 好 | 老款电钢琴（只有 MIDI In/Out 圆口） |
| 蓝牙 MIDI | 键盘本身支持蓝牙 MIDI | 好，免线 | 键盘支持蓝牙时的无线方案 |

看键盘背面就能判断：有 USB B 方口（标着 USB to host）走第二条路，只有两个圆 MIDI 口走第三条路，说明书里写了 Bluetooth MIDI 走第四条路。

## 二、什么都不接：用麦克风先上课

把手机或平板放在键盘旁边就能上课，app 用设备麦克风听你弹。三个官方提醒：

- 设备媒体音量调到一半左右，太大会盖过琴声；
- 戴耳机（有线、蓝牙都行）识别更稳——app 的示范音进了耳机，麦克风就只听到你的琴；
- 麦克风权限必须给过（检查路径见[麦克风识别问题排查](麦克风识别问题排查.md)第一节）。

真钢琴没有别的接法，只能走这条路；电钢琴建议往下看，接线后识别明显更准。

## 三、USB 线直连（最常见）

电钢琴背面板上有个方形的 USB B 口的话：

1. 拿一根 USB B 线（一头方口接钢琴，一头标准 USB）。
2. 手机 / 平板还需要一个转接头（按你设备的充电口类型买，如 USB-C 转 USB）；电脑直插即可，不用转接。
3. 全部插好后打开 Yousician，**在琴上随便按一个键**，app 会弹窗问是否使用 MIDI，点 **Yes, use MIDI** 完成连接。

就这么多，不需要装驱动。

## 四、老键盘的 MIDI 圆口转接

只有 MIDI In / MIDI Out 圆口的键盘，需要一根 **MIDI 转 USB 接口线**：

1. 接口线的 USB 端插到设备（手机加转接头，电脑直插）。
2. 接口线标 **MIDI In** 的插头插钢琴的 **MIDI Out** 口，标 **MIDI Out** 的插头插钢琴的 **MIDI In** 口——两头是交叉的，插反了不通。
3. 打开 app 按任意键，点 **Yes, use MIDI**。

## 五、蓝牙 MIDI 免线连接

键盘支持蓝牙 MIDI 的话，在 app 的 **设置 → Game（游戏）→ 高级音频设置** 里用 **Connect Bluetooth MIDI keyboard** 选项搜索配对你的键盘（先确认键盘的蓝牙处于可配对状态）。免线是方便，但蓝牙的延迟比线材高，介意手感反馈的话优先选有线。

## 六、接好之后的两个设置

都在 **设置 → Game → 高级音频设置** 里：

- **MIDI 灵敏度（MIDI sensitivity）**：调钢琴音量对你按键轻重的响应。带力度感应的键盘才有意义；选高灵敏度，琴声会更大。
- **缓冲区（buffer size）**：手机上弹琴觉得声音有延迟，把缓冲区调到 **256 或更低**。

一个快速自检：高级音频设置里有 **Input activity** 指示点，弹琴时点亮就说明 app 收到你的信号了。不亮的话按[麦克风识别问题排查](麦克风识别问题排查.md)的顺序查一遍。

## 七、连接方案之外的两件事

- 手机 / 平板上有个**内置触屏键盘**开关（Game 标签页里），开了会在屏幕上显示一排可弹的琴键——手边没有琴时用它跟课，但练不了真功夫，只能算过渡。
- 电脑版有键盘快捷键和全屏开关，大屏跟课更舒服。

设备都接好了之后，第一次上课的流程（选乐器、换中文、调音）见[新手入门与中文设置](新手入门与中文设置.md)；还没装 app 的从[下载与安装教程](下载与安装教程.md)开始。
