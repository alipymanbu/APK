# Yousician 听不见或识别不准的排查方法

> Yousician 靠麦克风听你弹奏来打分，「它听不见 / 听错了」是官方支持站里单独设板块（Recognition，识别）重点处理的一类问题，而且绝大多数出在设置而不是设备本身。本篇按从最常见到最少见给你一套排查顺序。

## 一、先确认麦克风权限没被关掉

权限被拒时 app 会一直「听不见」。安卓的检查路径：

```
设置 → 应用 → Yousician → 权限 → 麦克风 → 允许
```

首次安装时弹出的「允许 Yousician 录制音频」如果点了拒绝，就从上面这条路径补开。补开后回到 app 重新进入课程测试。

## 二、最常见的六个原因（按顺序过）

官方支持页的排查思路整理如下，建议从第一条开始按顺序过：

1. **没用 app 内置调音器调音**。用其他调音器软件调的音，可能让 Yousician 的识别出问题——先在 app 里走一遍内置调音流程再说。
2. **设备音量太大**。媒体音量开满会盖过琴声，把手机音量调到一半左右。
3. **环境噪音**。电视声、人声、风扇声都会干扰和弦识别。戴耳机（有线或蓝牙都可以）能明显改善——耳机隔离了 app 自己的示范音，麦克风就只听到你的琴。
4. **电吉他带效果器**。失真、混响这类效果会破坏识别，把效果器关掉、用干净音色。
5. **电吉他没插音箱、声音太小**。不插音箱的闷弹声音量不够，官方建议接音箱、音量开到「正常说话」的响度即可，不用轰。
6. **麦克风被别的应用占用**。后台挂着录音、通话类应用时会抢麦克风，关掉再试。

## 三、检查应用内的高级音频设置

权限和音量都没问题还不行，进 app 的音频设置看一眼输入设备：

1. 打开 **设置 → Game（游戏）**。
2. 点开 **高级音频设置（Advanced audio settings）**。
3. 看 **Input device（输入设备）** 列表：你的麦克风应该是**绿色高亮**状态。如果选中的是别的设备（比如不存在的耳麦），手动点回你的麦克风。
4. 顺手看 **Input activity（输入指示）**：对着琴出声时指示点会亮。亮了 = app 已收到你的信号；不亮才继续往下查。

## 四、安卓设备专属的两招

官方专门给 Android 用户留了两个调节项，都在「高级音频设置」里：

- **重新校准音频（Re-calibrate）**：环境变化（换房间、换琴）之后跑一次校准，识别准确率会回来。
- **切换音频驱动**：可以在 Android Audio / OpenSL 等选项之间切换；选 AAudio 时缓冲区自动调整。部分设备换一个驱动就解决了延迟和听不清。校准不生效时，把缓冲区（buffer size）调低一试。

## 五、唱歌课听不见你的声音

唱歌课的识别对象是你的嗓音，检查项和琴不一样：

- 设备（麦克风那头）**靠近嘴边**，别放在房间另一头；
- 戴耳机，别外放——伴奏从扬声器出来会混进你的歌声里干扰识别；
- 想要更好的效果，用带麦克风的一体式耳麦或外接麦克风，并在**高级音频设置**里把它选成 Input device；
- 首次上课做一次**音域校准**（唱出最低、最高能舒服唱到的音，做法见[新手入门与中文设置](新手入门与中文设置.md)第四节），练习会落在你的音区里，识别和跟唱体验都会更顺。

## 六、电吉他的进阶接法：音频接口

想获得最稳的识别，官方推荐的方案是**把琴直接接进设备**（跳过空气传声），需要一个音频接口（audio interface）：

1. 确认接口支持你的设备系统（安卓和电脑需要不同型号）。
2. 琴线插在标有 **Hi-Z / Inst（乐器输入）** 的插孔上，有拨杆的拨到 Inst 档。
3. 接口的 gain（增益）从零开始拧大，弹响琴看 Peak 灯，快亮时回退一点。
4. 在 app 的 **高级音频设置** 里把输入设备选成你的接口（而不是手机麦克风）。
5. 电脑上如果接口附带的 ASIO 驱动出问题，换回 Windows Audio 驱动。

两点注意：

- 蓝牙无线传输的延迟对乐器演奏偏大，接了蓝牙音频设备后 app 的 Mixer（混音台）功能会自动停用——这是保护机制，不是故障。
- 接了接口但 app 里听不到自己，用暂停菜单里的 **Mixer** 功能调大琴的音量、必要时先做一次 Calibrate（校准）。

## 七、还不行

把设备重启一次再走一遍第二节的顺序，仍无解的话去官方支持站查：[support.yousician.com](https://support.yousician.com)。识别问题与设备型号强相关，支持站的 Recognition（识别）板块会随版本更新补充新机型的已知问题。

课能上了之后想弄明白免费额度够不够用，见[免费版限制与会员订阅](免费版限制与会员订阅.md)。用 MIDI 线接了钢琴还遇到延迟的，看[钢琴与MIDI键盘连接方法](钢琴与MIDI键盘连接方法.md)第六节的缓冲区调整。
