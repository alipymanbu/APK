## 一、爱选修解决什么问题

每到选课季，你真正想知道的其实是三件事：这门课给分怎么样、考核方式是写论文还是考试、老师讲得能不能听懂。这些信息教务系统里没有，往年只能靠群里问学长学姐。Hustoday 的「爱选修」把华中科技大学开设的选修课程汇到一处，并沉淀历届学生留下的课程评价，让你在选课前先看口碑再下手。

它是**参考信息，不是选课通道** —— 真正的选课仍在学校的教务系统里完成，爱选修的作用是帮你筛掉不合适的课、找到值得选的课。

## 二、能查到什么

按官方说明与实际模块，一门选修课下通常能看到这几类信息：

| 信息 | 用途 |
| --- | --- |
| 课程基本信息 | 课程名、学分、开课院系、上课时间 |
| 历届课程评价 | 往届学生的体验反馈 |
| 老师给分情况 | 分数宽紧的参考 |
| 期末考核方式 | 论文 / 考试 / 平时分构成 |
| 学习建议 | 前人踩过的坑与备考提示 |

不同课程条目下信息的完整程度不一样 —— 冷门课可能只有寥寥几条评价，热门公选课则往往评价很多。信息少的课，别当成「这课没问题」，只是参考样本少。

## 三、选课时的典型用法

1. **先按时间筛**：把跟已有课表冲突的时间段排掉。课表怎么看，见 [课表怎么导入.md](课表怎么导入.md)。
2. **再看考核方式**：不想期末考试就优先挑论文 / 作业型的课；反之亦然。
3. **对照给分与评价**：给分、评价、考核方式三项一起看，只看单项容易误判 —— 给分高的课可能课业负担也重。
4. **回教务系统选课**：在爱选修里定好目标，去教务系统实际选；选上后重新导入课表，确认课程已出现在课表里。

## 四、评价是别人写的，怎么看待

- 评价是历届学生留下的主观感受，年份越久参考价值越低（老师风格、考核方式都可能变）。
- 同一门课不同老师开，评价可能完全不同，注意区分评价说的是哪个教学班。
- 选课成功与否、最终课表，以教务系统的选课结果为准，爱选修里的信息不构成任何承诺。

## 五、模块打不开或信息为空

先确认已登录校内账号、网络能访问校内资源；仍不行按 [常见问题与排查.md](常见问题与排查.md) 的通用排查走。另外，选修课库的内容随教务数据更新，学期初信息最全，选课季之外查到的可能是往期数据。
