## 一、资讯板块：谁在写、能看到什么

Hustoday 的资讯板块由「喻家山下」团队运营 —— 这是一个做华中科技大学内容的学生媒体团队。你能在这看到的内容大致分四类：

1. **学校通知与官方发布**：教务、后勤等单位的正式通知；
2. **学术讲座与活动**：讲座报名、活动预告；
3. **校园热点**：正在被讨论的话题；
4. **身边趣闻**：校园里的小事。

按官方更新日志，资讯已支持评论、点赞、收藏、关注，并邀请了部分发布方入驻 —— 也就是说你可以关注特定发布方，更新会出现在你的关注列表里。看到有用的通知（比如讲座报名截止），顺手收藏比想着「回头再找」可靠。

## 二、全面搜索：一次输入搜多个信源

「搜索」是 Hustoday 里独立于资讯的一个入口。它把散落在各处的信息聚合到一个搜索框里，覆盖的信源包括：

- 校内官网与各院系网站；
- 图书馆、后勤集团；
- 校园民间论坛等第三方信源。

典型场景是这类问题：

| 你想找 | 直接搜什么 |
| --- | --- |
| 某个通知原文 | 通知里的关键词（如「国庆放假」） |
| 某个部门的联系方式或邮箱 | 部门名（如「网络与计算中心」） |
| 某个办事流程 | 「补办校园卡」「成绩单打印」 |
| 食堂、校车等生活信息 | 「校车时刻」「食堂」 |

**搜索技巧**：

- 用通知里的**专有名词**搜，别用整句 —— 聚合搜索按关键词匹配，词越具体命中的页面越准。
- 搜办事流程时带上**对象名**（「校园卡」「火车票」），比单搜「怎么办」有用得多。
- 第一轮结果不满意，换一个同义词再搜（「网费」↔「校园网充值」）—— 不同信源用词不一样。
- 搜到的仍是网页，点进去就是原文，信息以原网页为准。

## 三、工具箱里的 1037wiki 与 1037life

按官方更新日志，Hustoday 的工具箱加入了 1037wiki 和 1037life 两个入口。它们是围绕华中科技大学校内信息的查询/生活服务工具，入口在 App 的工具箱里，具体功能以你打开后看到的为准（不同版本界面可能有出入）。可以理解为：搜索框解决「我有关键词」的查找，工具箱解决「我要办某类事」的直达。

## 四、这块功能出问题时

资讯不更新、搜索无结果、工具箱打不开，多半是网络或账号问题，按 [常见问题与排查.md](常见问题与排查.md) 的顺序排查；资讯与搜索依赖联网，离线状态下两块都不可用。如果你是想找某门课的评价而不是通知，那是 [爱选修功能怎么用.md](爱选修功能怎么用.md) 的范围。
