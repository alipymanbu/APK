## 一、两者是什么关系

时间线大致如下，各事件均见于公开报道与维基类条目：

| 时间 | 事件 |
| --- | --- |
| 2011 年 | 白俄罗斯团队发布 MapsWithMe，主打离线地图 |
| 2014 年 | Mail.Ru Group 收购，应用改名 MAPS.ME 并转为免费 |
| 2015 年 | 核心代码以 Apache 2.0 许可开源（仓库 [github.com/mapsme/omim](https://github.com/mapsme/omim)） |
| 2020 年底 | Mail.Ru 出售 MAPS.ME，新东家改版界面并引入更重的商业化 |
| 2021 年初 | 原开发团队成员另起分支，发布无广告的 Organic Maps |

也就是说，Organic Maps 不是「仿品」，而是从同一份开源代码分出去的、由部分原作者继续维护的应用；两者今天仍在各自的轨道上更新，界面与功能逐渐出现差异。多个第三方页面在描述这次分家时都把动机指向同一处：MAPS.ME 收归新东家后转向广告与付费墙的商业路线，老团队想要回「干净的离线地图」。

## 二、逐项差异对照

| 对比项 | MAPS.ME | Organic Maps |
| --- | --- | --- |
| 广告 | 有（可用内购关闭） | 无广告（官方口径也无追踪） |
| 免费离线地图数量 | 用户反馈上限 10 个区域，以应用内提示为准 | 无数量上限（开源项目，地图数据免费） |
| 旅行指南 | 内置与内容创作者合作的付费/免费指南 | 无这套指南体系 |
| 开源 | 历史上开源，现行为以官方渠道为准 | 开源，代码在 GitHub 公开 |
| 维护主体 | 商业公司（App Store 显示为 Convexity Holdings AG） | 非商业的开源社区 + 原创始团队 |
| 界面 | 改版后商业元素更多 | 更接近早年 MAPS.ME 的简洁界面 |

表格里「用户反馈」与「以官方为准」的条目属于随时可能调整的商业策略，使用时以两个应用内实际显示为准。

## 三、怎么按自己的用法选

给判断依据，不替你下结论：

- **出境旅行、想要现成行程指南**：MAPS.ME 内置的旅行指南体系是 Organic Maps 没有的，愿意容忍广告或付费去广告的话，功能更全。
- **只当离线地图用、讨厌广告**：Organic Maps 没有广告，也没有下图数量的限制，界面上少一堆商业入口。
- **手机较老**：两边都支持较多旧机型，具体以各自商店页面标注的系统要求为准。
- **在意数据贡献**：两边都能把编辑提交回 OSM 社区；数据底座同源，一条路线在两边的差异主要来自各自的渲染与规划策略。

## 四、互相换用时要注意什么

- **书签不直接互通**：两边都支持 KML/KMZ 导入导出，换用前先把书签从旧应用导出成文件，再在新应用里导入，具体操作见[书签备份与换机迁移.md](书签备份与换机迁移.md)。
- **地图包不通用**：MAPS.ME 下载的区域地图不能拷给 Organic Maps 用，换过去要重新下载一遍目的地的地图。
- **可以共存**：两者包名不同，可以同时装在一部手机上对比几天再决定留下哪个。
- **获取渠道**：Organic Maps 在各家应用商店与官网都能下载；MAPS.ME 的获取与安装见[下载与安装教程.md](下载与安装教程.md)。
