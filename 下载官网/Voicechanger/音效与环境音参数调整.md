## 一、先说结论

Voicechanger 的声音处理分三层：**声线**（决定你是谁）、**环境音**（决定你在哪儿）、**参数**（决定效果多狠）。三层可以任意组合，每加一层都能实时试听。本篇按这三层展开；操作步骤（怎么录音、怎么保存）在 [录音变声与保存分享教程.md](录音变声与保存分享教程.md)。

## 二、声线库都有哪些

官方标注 **30 余种变声效果**，实际列表会随版本更新增加。按用途分组：

| 类别 | 典型声线 | 适合的场景 |
| --- | --- | --- |
| 性别与年龄 | 女孩、男孩、婴儿、大叔、老奶奶 | 语音消息整蛊、角色扮演 |
| 科幻与恐怖 | 机器人、外星人、僵尸、怪物、幽灵 | 鬼故事、游戏配音 |
| 动物 | 羊、蜜蜂等动物声 | 短视频搞笑桥段 |
| 演唱与口音 | rapper 模式、口音模式 | 改节奏、装外国人 |
| 基础变调 | 升调、降调、深沉低音 | 快速微调，不想换角色时 |

用法就是点选试听、不满意再换 —— 没有「选错了要重录」这回事，同一段干声可以无限重试。

## 三、环境音：把声音放进一个场景

环境音和声线是**叠加关系**，不是二选一。内置的场景音包括：

- 洞穴回音、雨天、嘈杂街面、火车车厢等；
- 在效果界面**右侧入口**点选，加错了再点一次取消；
- 不加也完全没问题，很多人只用人声。

一个实用组合：**幽灵声线 + 洞穴回音**做恐怖氛围，**婴儿声线 + 街面噪音**做「街头偶遇」式整蛊。组合自己试，界面切换是实时的，成本很低。

## 四、参数：手动拧出自己的声音

预设声线是开箱即用的，但每个人嗓音不同，同一效果在你身上可能偏高或偏低。应用的**语音编辑器**提供这几个可调项：

| 参数 | 调高会怎样 | 什么时候动它 |
| --- | --- | --- |
| 音调（pitch） | 声音变尖变细 | 想要萝莉音/正太音但预设太夸张时往回收 |
| 清晰度 | 咬字更突出 | 录音环境吵、出来发闷时 |
| 音量 | 输出更响 | 变声后音量比原声小的时候 |
| 回音 | 拖尾更长 | 配合恐怖声线做空间感 |
| 变音强度 | 效果更浓 | 预设「不够像」或「太假」时双向微调 |

调整时**边听边拧**：应用支持实时试听，改一下按播放确认，满意了再保存。想把某套参数留成常用配方，调好后保存，之后的作品可以直接套用。

## 五、给视频配音

除了纯音频，你还可以拿它处理视频：

1. 录好旁白（或直接导入视频里的原声）；
2. 变声 + 调参，试听到满意；
3. 保存音频，导出到剪辑工具里对轨；或在应用内直接对视频素材应用效果。

短视频（YouTube、TikTok 这类平台的内容）、游戏解说、语音鬼畜，走的都是这条流水线。做多条系列内容时，**把常用声线和参数固定下来**，几条视频的音色就能保持一致。

## 六、常见调整误区

- **一上来就把强度拉满**：效果越浓越容易听出是合成的，整蛊场景反而穿帮。先用默认值，不够再加。
- **音调和声线重复施加**：已经选了「婴儿」这类高音调声线，再手动升调容易尖锐刺耳、甚至破音。
- **忽略环境音的音量平衡**：环境音太响会盖住人声，嘈杂场景点到为止。

调参本身不会破坏原录音 —— 不满意随时恢复默认重来。真遇到调了没反应、试听无声的情况，转 [常见问题与解决方法.md](常见问题与解决方法.md)。
