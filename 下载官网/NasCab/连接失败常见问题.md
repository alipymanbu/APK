## 一、连不上服务器：按现象查

| 现象 | 排查顺序 |
| --- | --- |
| 添加时提示验证失败 / 超时 | ① 手机和电脑是否连的同一个 WiFi（手机流量下连内网 IP 必失败）；② 服务端是否开着；③ 地址和端口是否与**服务端主界面显示的**一致，别照抄教程里的示例数字 |
| 之前能连，现在连不上 | 大概率电脑 IP 变了：路由器重启后会重新分配，回服务端主界面看新地址，编辑手机端那条服务器改掉 IP |
| 在家好好的，出门就连不上 | 内网 IP 出门连不上是正常的，需要外网地址，见 [外网访问设置方法](外网访问设置方法.md) |
| 突然全部连不上 | 先重启服务端，再重启手机 WiFi；还不行查电脑防火墙是否放行了 NasCab 的端口 |

## 二、登录失败

- 用户名密码是**装服务端时创建的管理员账号**，不是夸克、不是任何网盘或邮箱账号，两码事；
- 多份第三方教程都提到，服务端设过密保问题的，登录时还要填**密保答案**——答案是你当初在服务端设置的，不记得就去服务端看或重设；
- 密码忘了：在服务端所在电脑上处理（重装服务端或按官方渠道的找回方式），手机端没有重置入口。

## 三、视频播放卡顿、花屏、没声音

1. **先切低分辨率**：播放界面里切多分辨率档位，立刻能判断是不是带宽问题；
2. **查转码**：手机解不动的格式靠服务端实时转码，确认服务端开启了实时转码、硬件解码（调 GPU）可用；
3. **分清局域网和外网**：局域网卡多半是转码没开；外网卡多半是家里上传带宽的上限，跟软件设置无关；
4. **蓝光原盘**：BDMV 这类大文件建议在家用局域网看，外网远程放它不现实。

## 四、相册备份不动 / 失败

按顺序检查：手机与服务端是否连通（切到别的页面看能不能刷出来）→ 服务端「照片来源」是否已经配置 → 手机后台是否被系统杀掉（把 NasCab 锁后台、或插上电源再备份）。备份的完整配置步骤在 [相册备份与照片管理](相册备份与照片管理.md)。

个人版永久免费，专业版与白金版是付费档；外网访问相关的「专属域名 DDNS」「内网穿透」都在付费档里，免费版走第三方穿透即可。功能对照与价格口径专门写在 [免费版专业版白金版区别](免费版专业版白金版区别.md)，这里只提醒一句：**连接失败基本与档位无关**，免费版连不上按第一节的表查，别急着怀疑版本。
