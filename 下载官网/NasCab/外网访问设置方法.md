## 一、先分清两种连接场景

| 场景 | 用什么地址 | 前提 |
| --- | --- | --- |
| 在家（同一 WiFi） | 内网 IP，如 `192.168.x.x:80` | 无，直接连（见 [添加服务器连接教程](添加服务器连接教程.md)） |
| 出门在外 | 域名或公网地址 | 本篇要解决的：家里通常没有固定公网 IP |

内网 IP 出了家门就连不上了，所以外网访问的核心是**给你家弄一个在外面能找到的地址**。两条路线：官方专属域名、第三方内网穿透。

## 二、路线一：官方专属域名与白金版内网穿透

官方付费档里带两类远程能力：**专属域名 DDNS**（评测口径归专业版，域名形如 `https://你的用户名.nas-cab.com`，无需公网 IP、无需配路由器，走 https 加 AES 双重加密）和**内网穿透**（归白金版，官方自己的外网访问方案）。价格与档位细节在 [免费版专业版白金版区别](免费版专业版白金版区别.md)，付费前**以软件内和官网当时的说明为准**。

配置入口在服务端设置里，开通后手机端直接把服务器地址换成这个域名就能连。

## 三、路线二：第三方内网穿透

不想用（或用不了）官方付费方案，常见做法是第三方内网穿透工具：在家里电脑上跑一个客户端，它把 NasCab 的本地端口映射成一个公网地址。第三方教程里出现较多的组合：

| 工具 | 教程里的大致做法 |
| --- | --- |
| cpolar | 注册账号 → 装 Windows 客户端 → 建一条隧道指向 NasCab 的本地端口 → 得到临时公网地址（付费可固定二级子域名） |
| 花生壳 | 注册账号 → 客户端里添加映射（协议 http，内网主机填电脑 IP，内网端口填 NasCab 端口）→ 用账号自带的域名访问 |
| 路由侠 | 添加映射选「原生端口」，填本地端口创建 → 复制生成的公网地址访问 |

这三家都是独立于 NasCab 的第三方服务，免费档一般有带宽和地址限制，怎么选看你自己的预算，本文不为任何一家背书。共同思路就一条：**穿透工具占住 NasCab 的本地端口，给你一个外网地址**。

## 四、手机端填外网地址

拿到外网地址后，在手机端把它当成一个「服务器」来加：

1. 打开客户端 → 添加服务器；
2. 名称另起一个（如「家里电脑-外网」），和局域网那条区分开；
3. 服务器地址填穿透给的域名（或公网 IP），端口填对应的外网端口；
4. 账号密码不变，验证通过就能用。

这样你的服务器列表里会有两条：在家点局域网那条（快），在外面点外网那条（能用）。用官方专属域名的话，一条域名条目内外通吃，不需要切换。

## 五、暴露到外网之后的安全清单

服务一旦出了家门，就会被扫描，几件事值得做：

- **别用默认端口**：有用户实践提到改一个冷门端口能明显减少恶意扫描；
- **强密码**：管理员账号是唯一的门，弱密码等于开门；
- **开两步登录 / 黑白名单**：NasCab 服务端的安全中心里有这两样，外网暴露时建议都配上；
- **上 https**：官方域名自带 https；走第三方穿透的，选支持 https 的方案。另外有用户反馈 iOS 端登录只认 https，全家都有的话干脆统一上 https。
