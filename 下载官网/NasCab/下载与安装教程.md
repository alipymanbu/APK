## 一、你要装的是什么

NasCab（又叫「云可云」）是一套跨平台 NAS 软件：在一台常开的电脑或 NAS 上装「服务端」，手机、平板、电视上装「客户端」，就能在这些设备上看家里电脑里的照片、影音和文件。官网是 [www.nascab.cn](https://www.nascab.cn/)，服务端支持 Windows / Mac / Linux / Docker，客户端有安卓、安卓 TV、iOS、鸿蒙几套。

本篇装的是**安卓手机客户端**。它本身不存文件，装好后要连接你的 NasCab 服务端才有内容可看——这一步在 [添加服务器连接教程](添加服务器连接教程.md) 里讲。

## 三、把安装包拿到手机

1. 打开 **NasCab 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/075c52dccfd3](https://pan.quark.cn/s/075c52dccfd3)
2. 手机上装了夸克 App 的话会直接拉起转存；没装就先转存到自己的夸克账号，再在 App 里下载。
3. 下载完成后会得到一个 apk 文件（对应版本 NasCab v5.5）。
4. 也可以在电脑上下载，再用数据线把 apk 拷到手机的「下载」文件夹，效果一样。

## 四、允许安装来自浏览器的应用

apk 不走应用商店，安卓默认会拦一下，需要你手动放行一次：

1. 点开 apk 时如果弹出「禁止安装未知来源应用」的提示，点提示里的「设置」；
2. 找到「允许来自此来源的应用」，把开关打开；
3. 返回重新点 apk 继续安装。

不同品牌的入口名字略有差别：小米在「设置 → 隐私保护 → 特殊权限 → 安装未知应用」，华为在「设置 → 安全 → 更多安全设置 → 安装外部来源应用」，vivo / OPPO 在「设置 → 安全 → 安装未知应用」。装完之后这个授权可以关掉，不影响已装好的 App 运行。

## 五、安装与首次启动

1. 在文件管理器里点开 apk → 点「安装」，等进度走完；
2. 点「打开」直接进入，或之后从桌面图标进入；
3. 首次启动会要求网络与存储等权限，按需允许（相册备份功能需要存储权限）；
4. 接下来就是「添加服务器」页面——NasCab 客户端必须连上服务端才有内容，跟着 [添加服务器连接教程](添加服务器连接教程.md) 走完这一步就能用了。

## 六、装完用不了再看这两处

- 连接报错、验证失败：先看 [连接失败常见问题](连接失败常见问题.md)，多数是地址或端口填错；
- 服务端还没装：先去官网装好服务端并创建管理员账号，再回头连手机。
