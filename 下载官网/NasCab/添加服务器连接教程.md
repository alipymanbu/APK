## 一、连接前要备齐的东西

| 需要什么 | 说明 |
| --- | --- |
| 装好客户端的手机 | 还没装的话看 [下载与安装教程](下载与安装教程.md) |
| 装好服务端的电脑 / NAS | 服务端去官网 [www.nascab.cn](https://www.nascab.cn/) 下载，安装时创建管理员账号密码 |
| 同一个局域网 | 第一次连接建议手机和电脑连同一个 WiFi，通了再折腾外网 |

服务端的安装没有复杂选项：官网下载 Windows 安装版（撰写时要求 Win10 及以上 64 位系统，双核 CPU、2GB 内存即可），装完打开，按引导设置管理员账号，服务就算跑起来了。

## 二、找到服务端的局域网地址

打开电脑上的 NasCab 服务端主界面，界面上会直接显示当前的局域网地址，形如 `192.168.50.116:80`——冒号前是电脑的内网 IP，冒号后是端口。端口常见是 80，也有安装环境显示 81 的情况，**以你屏幕上显示的为准**，别照抄别人教程里的数字。

顺手做一件事：进路由器管理页，把这台电脑的内网 IP 绑定固定（DHCP 静态分配）。不然路由器重启后 IP 可能变化，手机端就得重新改地址。

## 三、在手机端添加服务器

1. 打开 NasCab 客户端，首次运行会直接进入「添加服务器」页面；
2. **名称**：随意起，方便你自己区分（比如「家里电脑」）；
3. **服务器地址**：填上一步看到的内网 IP，只填 IP；
4. **端口**：填服务端显示的端口（一般 80）；
5. **用户名 / 密码**：填服务端创建的管理员账号，不是任何网盘账号；如果你的服务端设置过密保问题，这里还会多一项**密保答案**，填当初设的那个（多份第三方教程都提到这一项，答案记不住就回服务端看）；
6. 点「添加服务器」，提示「服务器地址验证成功」后点确定；
7. 回到服务器列表，点刚加的这条就进入主界面了。

## 四、扫码登录：不想手输 IP 就扫这个

电脑端客户端里有登录二维码，手机端在添加服务器页面选扫码登录，对准扫一下，地址、端口、账号就都填好了。局域网里这是最省事的连法，也最不容易填错。

连通之后局域网的体验上限不低：有第三方评测实测手机直接播电脑上的视频与本地播放几乎无差别，文件下载能跑到 40 MB/s 左右（取决于你的网卡与路由）。

## 五、连上之后先做两件事

- 让相册开始备份：服务端和手机端各配一次，步骤见 [相册备份与照片管理](相册备份与照片管理.md)；
- 把电脑里的电影、音乐目录加进服务端，手机上就能在线看：见 [影视音乐在线播放](影视音乐在线播放.md)。

## 六、地址变了或要管理多个服务器

- **之前能连、现在连不上**：八成是电脑 IP 变了，回服务端主界面看新地址，在手机端长按或编辑那条服务器，改掉 IP 即可；
- **有多台电脑 / 多个地点**：再点一次「添加服务器」加新条目，名称区分开就行，条目之间互不影响；
- **出门在外也要连**：局域网地址出了家门是连不上的，需要外网地址，看 [外网访问设置方法](外网访问设置方法.md)。
