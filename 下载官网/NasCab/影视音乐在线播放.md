## 一、先在服务端把媒体目录加进去

手机上能不能看到片子，取决于服务端有没有收录它们。在电脑端：

1. 「影音管理」→ 来源目录 → 新增，指向你存电影的文件夹；
2. 「音乐管理」→ 设置来源文件夹 → 新增，指向存音乐的文件夹；
3. 等服务端扫完。影音目录扫完会按文件名自动匹配海报，海报墙就是这时候生成的。

手机端看到的永远只是服务端目录的投影，目录加了什么，手机上就有什么。

## 二、手机上看电影

| 能力 | 实际体验 |
| --- | --- |
| 全格式支持 | 常见视频格式都能播，蓝光原盘（BDMV）也支持 |
| 自动海报匹配 | 按文件名匹配海报墙，找片靠看图不靠记文件名 |
| 实时转码 | 手机解不动的格式由服务端实时转码再推给你，服务端支持硬件解码（调用 GPU） |
| 多分辨率 | 网络不好时切低分辨率，画面先保流畅 |

局域网里千兆内网基本秒开——有第三方评测实测手机直接播电脑上的视频与本地播放几乎无差别；外网看片的上限是你家里的上传带宽，4K 原盘出门在外最好别碰，切低码率版本更现实——外网连接的配置见 [外网访问设置方法](外网访问设置方法.md)。

## 三、手机上听音乐

服务端音乐目录扫完后，手机端可以按歌手、专辑浏览。格式上 MP3、FLAC、WAV、WMA、AAC、M4A、OGG、OPUS 这些常见格式都支持，会读取 ID3 标签来归类；歌词支持自动匹配，也可以加载你放在同目录的本地歌词文件。

## 四、文件浏览与远程管理

「文件浏览器」是管照片影音之外最常用的一块：

- **上传下载**：手机和服务器之间任意传文件，随手把手机里的文档丢到电脑上；
- **在线压缩 / 解压**：服务器上的 zip 包直接在线解开，不用先下载；
- **在线查看**：PDF、图片、视频、常见文档不下载直接看；
- **挂载网盘**：把其他网盘挂进来，在 NasCab 里统一浏览；
- **快速分享**：把服务器上的文件生成分享给别的设备。

## 五、把服务端磁盘共享给电脑用：FTP / WebDAV

服务端开 FTP 或 WebDAV 服务后，家里其他电脑可以把 NasCab 的磁盘挂载成网络盘符，在资源管理器里当本地盘用；WebDAV 还能通过 http 远程挂载——出门在外用笔记本访问家里的文件，就是这条路。端口在服务端的文件分享设置里配。

## 六、看不了 / 卡顿的快速判断

- 手机上列表是空的：回服务端确认来源目录加对了、扫描完成了；
- 能看到但播放卡：先切低分辨率试试，还不行看服务端转码是否开启、硬件解码是否可用；
- 外网尤其卡：那是上传带宽的上限，不是软件坏了。
