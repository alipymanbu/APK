## 一、先把问题分成三类

连接类的报错看着都差不多，处理路径却完全不同。先对号入座，再按对应小节往下走，比笼统地「重启一下试试」有效得多。

| 表现 | 大概率方向 | 去哪儿 |
| --- | --- | --- |
| 添加设备时就报 Connection Failed | 地址、端口、账号密码、端口映射 | 第二节、第三节 |
| 设备在列表里，点开没画面或全黑 | 码流偏高、设备侧码流加密、手机解码能力 | [实时预览与云台对讲怎么用.md](实时预览与云台对讲怎么用.md) |
| 能看，但看一会儿断掉 | 设备连接名额被占满、网络抖动 | 第六节 |
| 全是数字错误码 | 见对照表 | 第五节 |

## 二、Connection Failed 的四个常见原因

海康给经销与客服的官方 FAQ 里，把这一类失败归成四条原因，照这个顺序查：

1. **设备侧网络配置不对** —— 默认网关等信息填错。验证方法很直接：用电脑浏览器在同一个局域网里打开设备地址，进不去就说明是设备侧的网络问题，先修设备。
2. **端口映射不对** —— 只在从外网访问时相关，家里同一 WiFi 下连不上跟它无关。
3. **网络状况差** —— 手机所在网络本身就丢包。
4. **地址或端口填错** —— 最常见的是内网配置和外网配置两套数据填混了。

## 三、局域网内也连不上的两种情况

1. **不在同一网段**。手机连的是 `192.168.0.x`，设备的 IP 是 `192.168.1.x`，看起来都在内网，实际走不通。把两者放到同一个网段的网络里。
2. **端口填成了 HTTP 端口**。添加设备要填的是**设备服务端口（默认 `8000`）**，不是浏览器访问管理页面用的 80 或 8080。这一栏填错，表现就是一直 Connection Failed。

另外，如果设备接的是 NVR，注意别把「设备的服务端口」和「某个通道的端口」搞混 —— 通道不用单独填端口。

## 四、外网能连、在家用 WiFi 反而连不上

这种情况有明确的常见原因：**路由器不支持回环（NAT loopback）**。当你添加设备时填的是公网 IP，人在家里、手机和设备其实都在同一个内网，路由器却没法让内网设备通过公网地址绕回自己。

两个办法，选一个就行：

- **在家改走内网配置**：给同一台设备再存一条内网 IP 的配置，在家用这条。
- **换路由器**：换成支持回环的型号，公网配置在家里也能直接用。

## 五、错误码对照表

下面这些错误码与释义来自海康面向经销与客服的官方 FAQ，以及公开整理资料；命中之后先做「先做这一步」那一列，比在应用里反复重试快。

| 错误码 | 含义 | 先做这一步 |
| --- | --- | --- |
| 1 | 用户名或密码错 | 重新输入；确认没把应用登录账号当成设备账号 |
| 4 | 通道号不对 | 检查该通道是否被隐藏；通道数留空让应用自动识别 |
| 7 | 设备离线或连接超时 | 确认设备通电、网线正常，能在局域网里访问到它 |
| 9 | 没有收到设备数据 | 查网络丢包与超时 |
| 10 | 接收数据超时 | 同上，重点看带宽够不够 |
| 43 | 地址或域名无效；HiDDNS 的地址与端口不对 | 核对地址与端口；HiDDNS 服务已停用，改用 `IP/Domain` 模式 |
| 47 | 找不到该用户 | 核对账号；海康 FAQ 对此条的建议是改用 Hik-Connect 或更新应用，而本应用已停止更新，所以优先核账号 |
| 55 | 未授权的 IP | 设备里开了 IP 地址过滤，把手机所在网络的公网 IP 加进白名单 |
| 56 | 开启了 MAC 地址登录限制 | 在设备的安全设置里放开这条限制 |
| 73 | 端口映射配错 | 重新核对转发规则：外部端口、内部 IP、内部端口、协议四项是否与设备实际一致 |
| 153 | 连续输错密码次数过多，设备被锁定 | 等约 30 分钟自动解除锁定，或重启设备加速 |
| 8200 | 加密异常 | 先临时关掉设备上的码流加密试一次，确认是不是加密导致 |

还有两种不带数字码的提示，别和上面的码混为一谈：

- **The device is not registered in the DDNS**：走的是 HiDDNS 那条通道，服务已经停了，改用 `IP/Domain`。
- **Connection Failed**：回到第二节按四条原因查。

## 六、提示「已达到设备的最大连接数」

这是**设备端**的连接名额被占满了 —— 同一台设备能同时接受的客户端连接是有限的，多个客户端同时登、或者上一次的连接没正常释放，都会占住名额。

处理顺序：

1. 重启设备，让连接释放。
2. 还不行，按海康 FAQ 的做法：改一次设备密码，然后用新密码重新连一次。

## 七、改过设备密码之后设备掉线了

用 `IP/Domain` 模式添加的设备，在设备端改密码并重启之后，应用里会掉登录 —— 这是正常现象，不是配置坏了。

处理：回到设备列表，编辑那条设备，把密码更新成新密码再保存。

## 八、密码忘了怎么办

先分清忘的是哪一个，两者的处理完全不同：

- **忘的是设备的 `admin` 密码**（就是填在「密码」那一栏的那个）：这个密码没有出厂默认值，也不该靠反复猜 —— 连错次数过多会触发错误码 153，把设备锁定约 30 分钟。走海康官方的密码重置流程：官方客户端或工具（如 iVMS-4200、SADP）里带密码重置功能，或按设备本地菜单的重置引导操作；也可以拨打海康威视客户服务热线 `400-800-5998`（官方公告里给的号码）求助。不要用来路不明的第三方工具去处理设备密码。
- **忘的是应用自己的登录账号**（第一次打开时建的那个）：它跟设备无关，忘记它不会影响设备上的任何设置。实在想不起来，重装一次应用、重新建号即可，代价是应用里已添加的设备要重新加一遍。
