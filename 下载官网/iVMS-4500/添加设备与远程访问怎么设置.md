## 一、先把两种使用场景分开

iVMS-4500 连不上设备，绝大多数问题出在「地址」和「端口」这两栏上。这篇先把添加设备的六个字段讲清楚，再分成局域网直连和公网远程两条路分别操作，最后给一个连不上时的自查顺序。

两种场景的区别只有一处 —— **地址填什么**：

- **局域网直连**：手机和录像机连在同一个路由器下，地址填设备的**内网 IP**（形如 `192.168.1.64`）。速度快，不受外网影响，建议先把这个调通。
- **出门在外远程看**：手机用流量或在别的网络里，地址填**公网 IP 或域名**，并且要在路由器上做端口映射。能不能成，取决于宽带有没有公网 IP、映射配得对不对。

这两套配置可以同时存在：同一台设备在家里存一条内网 IP 的、在外存一条公网地址的，需要哪条用哪条。

## 二、添加设备的入口与六个字段

菜单 → 设备（Devices）→ 右上角 `+` → 手动添加（Manual Adding），弹出的表单一共这么几栏：

| 字段 | 填什么 | 容易错的地方 |
| --- | --- | --- |
| 别名 / 设备名 | 自己起，按位置命名（家里、店里） | 用默认名，设备一多就分不清 |
| 注册模式 | `IP/Domain` 或 `HiDDNS` | 见第五节，现在只该选前者 |
| 地址 | 设备 IP 或域名 | 内网配置填内网 IP，外网配置填公网 IP |
| 端口 | 设备服务端口，默认 `8000` | 填成了浏览器用的 HTTP 端口（80 / 8080） |
| 用户名 | 设备账号，海康设备的默认管理员账号一般是 `admin` | 把第四节里那个应用登录账号填了进来 |
| 密码 | 设备密码，设备激活时你自己设的 | 设备改过密码却没同步过来 |
| 通道数 | 留空即可 | 保存后通常会自动识别，不用手填 |

填完保存，设备会出现在设备列表里。

「用户名」和「密码」这两栏有两个背景值得先知道，能省掉一大半「怎么填都不对」：

- **海康设备没有统一的出厂默认密码**。设备出厂是「未激活」状态，第一次上电时由你（或装维人员）在设备上创建 `admin` 密码，之后手机端要用的是**那一个**密码，不是老教程里写的 `12345`。如果设备从没激活过，先去激活它，再回来填这一栏。
- **密码本身有规则**：长度 8~16 位，且至少由数字、小写字母、大写字母、特殊字符中的两种或以上组合，不能包含用户名。填错一位就会直接报「用户名或密码错误」。

## 三、局域网内先把画面调通

1. 让手机连上**和录像机同一个路由器**的 WiFi。
2. 查出设备的内网 IP：在设备本地菜单里看（主菜单 → 网络 → TCP/IP），或在电脑上跑海康官方的 SADP 工具扫一遍局域网，它会列出设备 IP 与端口。顺手确认一下服务端口是不是 `8000`。
3. 按第二节填表：注册模式选 `IP/Domain`，地址填刚才那个内网 IP，端口 `8000`，用户名密码填**设备**的。
4. 保存后回到设备列表，点这个设备，选通道，开始预览。
5. 出画面就说明账号、密码、端口、网络全对了。不出画面，直接按 [连接失败与错误码排查.md](连接失败与错误码排查.md) 里的顺序查，不要先去动端口映射。

关于总共能加多少台设备，两处公开说法并不一致：海康早期的客户端手册写的是「最多管理 16 台 IP 设备」，而第三方应用信息页在 v4.7.5 的更新记录里写的却是「本地设备数量限制改为 256」。两处都不一定正好对应 4.7.12 这一版，以你在应用里实际能加到多少为准 —— 家里几台设备的场景碰不到这条限制。

## 四、出门在外看：公网 IP 加端口映射

1. **先确认宽带有没有公网 IP**。在路由器上查到的 WAN 地址，如果和你在外网环境下查到的公网 IP 不一样，说明分到的是运营商的内网地址，端口映射做了也访问不到。遇到这种情况，先看 [还能继续用吗与替代应用.md](还能继续用吗与替代应用.md) 里的替代方案。
2. **映射设备服务端口**。在路由器里加一条端口转发规则，四项这样填：外部端口 `8000`（或换成 `8800` 之类不常见的端口，减少被扫描）、内部 IP 填录像机的内网 IP、内部端口 `8000`（要与设备实际的服务端口一致）、协议选 TCP。
3. **要用报警推送的话，还要映射 HTTP 端口**。海康的报警推送走设备的 HTTP 端口（默认 80），且**内外部端口号必须一致** —— 详见 [报警推送收不到怎么排查.md](报警推送收不到怎么排查.md)。
4. **在应用里再添加一条设备**：注册模式 `IP/Domain`，地址填公网 IP（或你申请的域名），端口填第 2 步用的外部端口。
5. 断开 WiFi，用手机流量测一遍。能出画面就成了。

## 五、注册模式怎么选：IP/Domain 还是 HiDDNS

- **IP/Domain**：地址由你自己给，可以是内网 IP、公网 IP，也可以是你在免费 DDNS 服务商那里申请的域名。这是现在还能用的那一种 —— 另外两条通道（HiDDNS 与官方云服务）都已经停了。
- **HiDDNS**：海康早年给的免费域名服务，用它就不用记会变的 IP。**这项服务已经在 2022 年 2 月停止**，所以这一栏现在填了也连不上。

网上流传的老教程里那种「注册模式选 HiDDNS → 服务器地址填 `www.hik-online.com` → 再填设备域名」的写法，对应的是已经下线的服务，不要再照着做。

## 六、连不上时的自查顺序

按这个顺序走，能省掉大量来回试：

1. **同一 WiFi 下也连不上** → 问题在局域网这一层，回到第三节查 IP、端口、账号。
2. **局域网能看、外网不能看** → 问题在映射这一层，回到第四节查公网 IP 与转发规则。
3. **怀疑端口没通** → 换一个不在设备局域网里的网络，用在线端口检测工具测你映射出来的外部端口，通不通一眼就知道。
4. **仍然报错** → 记住报的具体错误码，对着 [连接失败与错误码排查.md](连接失败与错误码排查.md) 的对照表看。
