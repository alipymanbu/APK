## 一、报警推送要同时满足三件事

报警推送不是一个开关打开就完事的功能。设备端要上报、网络端要能通、手机端要允许接收，三头都成立才会响。这篇按「手机端 → 设备端 → 网络端」的顺序给出每一头的检查点 —— 先改自己能立刻改的，再动设备配置。

开始之前先确认一件事：**你在预览里能正常看到这台设备**。连预览都不通的话，先解决连接问题，回 [连接失败与错误码排查.md](连接失败与错误码排查.md)。

## 二、手机端：通知权限与推送开关

这一头最容易漏，也最快能改：

- **系统通知**：手机设置里找到这个应用，确认通知是允许的。系统的省电策略、专注模式、通知静音都会把推送压掉。
- **应用内开关**：在应用的报警相关设置里，确认报警推送（通知）是打开的。
- **报「Failed to get the push token」**（获取推送令牌失败）：海康官方 FAQ 对这个提示的解释就是系统不允许该应用推送。回到上一行把通知权限打开，再点一次。
- **点开关时报连接类错误**：官方 FAQ 列的原因包括设备离线、网络状况差、HTTP 端口未配置或不正确。往下看第三、第四节。

权限开了还是不响，问题多半出在系统把应用清出了后台。几家手机厂商的官方支持文档给的排查项基本一致，逐条对着改：

| 要改的设置 | 怎么找 |
| --- | --- |
| 后台锁定 | 打开应用后进多任务界面，下拉该应用卡片加锁 |
| 允许自启动与后台活动 | 设置里搜「应用启动管理」，关掉自动管理，勾允许后台活动 |
| 电池优化放行 | 设置里搜「电池优化」，把该应用设为不允许优化 |
| 关省电模式 | 设置 → 电池，关掉省电（低电量）模式 |
| 休眠不断网 | 设置 → 电池 → 更多电池设置，开启「休眠时始终保持网络连接」 |
| 第三方管家 | 卸载或加白名单，避免它清理后台 |

## 三、设备端：侦测与联动必须都勾上

在设备的本地菜单里（不是手机应用里）逐项确认：

1. **侦测本身是开着的**：移动侦测、越界侦测等对应功能的开关已启用，侦测区域和灵敏度不是全关状态。
2. **联动动作里勾了上报**：在侦测的联动动作里，要勾选**上报监控中心（Notify Surveillance Center）**这类上送项。只勾了录像、只勾了声音，设备本地会报警，但手机上不会有推送。
3. **设置确实保存了**：改完确认保存，设备没有中途掉电或被恢复出厂。

## 四、网络端：HTTP 端口不通就收不到

海康的报警推送走设备的 **HTTP 端口**（默认 80），这一点在官方 FAQ 里是明确写出来的 —— 端口没通，推送出不来。

- 在路由器上把设备的 HTTP 端口转发出去，规则写法和 [添加设备与远程访问怎么设置.md](添加设备与远程访问怎么设置.md) 第四节的服务端口一样，只是端口号换成 HTTP 端口。
- **内部端口与外部端口必须一致**。官方 FAQ 特别指出：如果内外部的 HTTP 端口不一致，会出现「看似连上了，实际连的是局域网里另一台不支持推送的设备」这种尴尬情况，而且局域网里同时有多台海康设备时最容易踩。
- 改完 HTTP 端口后，把设备在应用里的配置也重新保存一次再测。

## 五、这三步都做了还收不到，只能实测确认

海康已在 2022 年 2 月停止这个应用的云服务，推送所依赖的服务端通道未必还在运行。**上面三头都按清单做到位了仍然收不到，很可能就是应用停服带来的结果，不代表你哪一步配错了** —— 这种情况没有配置层面的解法，只能改用官方替代应用，见 [还能继续用吗与替代应用.md](还能继续用吗与替代应用.md)。

判断方法也很简单：同一台设备、同样的侦测配置，换一个还在维护的官方客户端去测，如果那边能收到推送，那就确认是 iVMS-4500 这一侧的问题。
