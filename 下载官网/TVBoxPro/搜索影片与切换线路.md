## 一、先确认接口已经在手

下面所有操作都建立在接口已经读出来的前提上：首页能看到分类与海报。还是空的话先回 [配置接口地址教程.md](配置接口地址教程.md) 把地址填上，那一篇也讲了接口失效时怎么换。

## 二、找片的三条路

1. **首页分类翻**：接口里的分类（电影、剧集、综艺、动漫…）会平铺在首页，遥控器方向键移动、确认键进详情页。
2. **搜索**：首页找搜索入口（多在顶部或侧边栏），输入片名首字母或全名，结果是**跨接口里所有站点聚合**出来的 —— 同一部片会出现多条，来自不同站点。
3. **详情页选集**：进详情页后，剧集列表、评分、简介都在这一屏；同一部片如果挂在多个站点下，可以退回结果列表换一条看。

遥控器打字慢的，先看 [配置接口地址教程.md](配置接口地址教程.md) 第四节的扫码推送思路 —— 搜索框同样吃输入法，连个蓝牙键盘或用手机输入法投屏会快很多。

**搜不到想看的片**，按这个顺序试：① 确认搜索词没打错、换个更短的词再搜一次；② 分类之间切一下，有的接口把内容放在不同分类下；③ 首页刷新/重进一次（接口高峰时段响应慢，常见做法是先刷新再换源）；④ 还是没有，说明这条接口里就没有，换一条接口才有 —— 搜索结果只覆盖你当前填的那条接口。

## 三、播放卡了就换线路

同一个片名下每条结果就是一个线路；正在播的画面里也能切：

- 播放中调出控制条，找「线路 / 解析 / 源」一类的按钮，换一条通常立刻生效；
- 某条线路转圈不出画、或只有声音没画面，**别怀疑软件，先换线路** —— 单条线路失效是常态；
- 全部线路都播不了，说明这个站点整体挂了，退回搜索结果换另一条（另一个站点）的来看。

换线路仍全部失败的排查顺序见 [常见问题与排查.md](常见问题与排查.md)。

## 四、播放器里值得记住的几个键

各家接口与版本提供的选项不完全一样，界面上有的才生效，以下以你实际看到的为准：

| 操作 | 常见入口 |
| --- | --- |
| 暂停 / 播放 | 确认键 |
| 进度拖动 | 左右方向键，或调出进度条后按 |
| 倍速播放 | 播放控制条里的倍速选项 |
| 跳过片头片尾 | 控制条里的跳过设置，可自定义时长 |
| 字幕开关与切换 | 控制条里的字幕选项（接口提供字幕才有） |
| 全屏 / 退出全屏 | 播放界面的全屏按钮 |
| 返回上一级 | 遥控器返回键 |

## 五、电视直播在哪看

直播频道不随软件自带，**接口里包含直播源时**才会出现直播入口（通常在首页频道栏，或设置里的直播配置）。你手里是直播接口的话，按 [配置接口地址教程.md](配置接口地址教程.md) 第三节的表格填到直播那一栏，别混进「配置地址」里去。

接口没有直播分类，就是这条接口不含直播源，换一条带的即可，不是你操作错了。
