## 一、先分清是哪一类问题

按现象对号入座，别跨类乱试：

| 现象 | 去看 |
| --- | --- |
| 装不上、安装按钮灰、提示解析错误 | 第二节 |
| 打开闪退、装完找不到图标 | 第三节 |
| 界面空的、提示读取失败 | 第四节 |
| 能播但卡顿、黑屏、只有声音 | 第五节 |

## 二、安装阶段的三个卡点

- **安装按钮灰色点不动**：设备还没允许装未知来源应用。去设置里找「允许安装未知来源应用 / 安全与隐私 / 账号与安全」打开，各家位置不同，也有品牌要先连续点击系统版本号激活开发者选项才露出这一项。
- **提示解析错误**：安装包不完整或与系统不兼容。重新下一次包（[下载与安装教程.md](下载与安装教程.md) 第二节有这一份的版本与大小，可核对），仍报错就说明这个包与你的系统版本不匹配。
- **提示与已有应用签名不一致**：设备上装过同包名的其他版本。先卸载旧版再装 —— 注意卸载会清掉旧版里存的接口配置，换新版本前把接口地址抄下来，装完重贴一次（照 [换设备后怎么恢复配置.md](换设备后怎么恢复配置.md) 的存法，以后就不用现抄了）。

## 三、闪退与找不到图标

- **一点就退**：先确认设备安卓版本够新、内存吃紧的应用先清后台再开；换一台设备装同一个包能开，说明问题在原设备的系统环境，不在包本身。
- **装成功但桌面上没有图标**：多数电视系统只把常用应用放首页，去「应用中心 / 全部应用」里找；找到后可固定到主页，下次一键打开。

## 四、界面空的、读不出接口

按出现频率从高到低：

1. **地址贴错了**：前后带了空格换行、复制被截断、把直播接口贴进了「配置地址」—— 三种的辨别方法见 [配置接口地址教程.md](配置接口地址教程.md) 第二、三节。
2. **接口本身挂了**：接口由第三方个人维护，打不开是常态。换一条地址重填；你手里存了多条的话，从「我的」里的数据源入口切一条试。
3. **没给存储权限**：走本地接口文件（`clan://localhost/` 开头）时必须先在设置里允许存储权限，否则永远读不到。
4. **网络问题**：设备浏览器直接打开那条接口地址 —— 打不开就是网络或地址的问题，与软件无关；打得开才是软件这边的填写问题。
5. **时机问题**：接口服务器高峰时段响应慢，先退出重进一次、过几分钟再看，仍然不行才按上面四条逐条查。

换了好几条地址都读不出来、而这台设备昨天还好好的，就该怀疑是不是重装或恢复出厂把配置清了 —— 回 [换设备后怎么恢复配置.md](换设备后怎么恢复配置.md) 把你存的那份地址重贴一次。

## 五、能播但体验不对

| 现象 | 先试 | 不行再试 |
| --- | --- | --- |
| 转圈、加载慢 | 换线路 | 换接口（不同接口的站点与服务器不同） |
| 黑屏但有声音 | 换线路（多为该线路解码方式与设备不合） | 换接口，或降低清晰度选项 |
| 画面卡顿 | 看是不是走到了高码率源，切低一档清晰度 | 检查家里带宽，尤其晚高峰 |
| 进度条拖不动 | 换线路（部分线路不支持拖动） | 换接口 |

设备本身太旧、硬解能力弱时，换线路也救不回来 —— 这种情况换一台设备试同一个包，能定位问题出在哪一侧。

## 六、还没解决怎么办

逐条试完仍不行，回到起点核对三样东西：装的是不是网盘里那一版（[下载与安装教程.md](下载与安装教程.md) 第二节的版本与包名）、接口地址是不是完整可访问、设备是不是允许了未知来源安装与存储权限。这三样都对还异常，多半是这个包与你的设备不兼容，换个设备验证比反复重装更快。
