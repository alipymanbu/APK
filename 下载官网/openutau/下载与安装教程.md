## 一、它是什么

先分清两个名字：

| 名字 | 是什么 |
| --- | --- |
| OpenUtau | 电脑端的开源歌声合成编辑器（UTAU 社区的现代化替代品），官网 [www.openutau.com](https://www.openutau.com/) |
| OpenUtau Mobile | 你要装的这一个：基于 OpenUtau Core 改造的**移动端编辑器**，作者是 GitHub 用户 vocoder712，项目仓库 [github.com/vocoder712/OpenUtauMobile](https://github.com/vocoder712/OpenUtauMobile) |

按官方仓库自己的声明，OpenUtau Mobile **不是** OpenUtau 官方推出的应用，而是社区开发者基于 OpenUtau 内核做的移动端项目，以 Apache 2.0 协议开源。它完整支持 OpenUtau 的 `.ustx` 工程文件，支持的歌手声库类型为 DiffSinger、UTAU、Vogen 三类（官方仓库注明其他类型不保证可用）。

## 三、从哪里拿安装包

两个常规入口：

1. **官方 GitHub Releases**：到 [github.com/vocoder712/OpenUtauMobile/releases](https://github.com/vocoder712/OpenUtauMobile/releases) 选对应架构的 APK 下载；开发者还提供 dev 分支的 nightly 测试版，入口写在仓库首页说明里，尝鲜可去、日常使用不推荐。
2. **网盘转存**：如果不方便直连 GitHub，可以从 [OpenUtau Mobile 安装文件资源（夸克网盘）](https://pan.quark.cn/s/841daeb1f7d9) 转存后下载这份 1.1.7 的安装包。

无论哪个入口，拿到包后建议核对一下 MD5 是否与第二节的一致，避免拿到被改动过的文件。

## 四、安装步骤

1. 手机上打开 APK 文件，系统会提示「允许安装未知来源应用」，在弹出的设置页里允许后继续安装；
2. 等安装完成，首次启动如果弹出存储权限请求，选择允许 —— 后面导入声库需要读取手机存储里的文件；
3. 打开应用进入主页，主页有 `New`（新建）、`Open`（打开工程）、`Singer`（歌手）几个主要入口。

## 五、装完先做什么

1. **先把界面换成中文**：右上角进入 options → settings → language，选简体中文后重启应用生效，具体见[新建工程与音符编辑上手.md](新建工程与音符编辑上手.md)；
2. **导入至少一个声库**：没有声库这个应用不会出声，声库去哪下、怎么导入见[声库下载与导入教程.md](声库下载与导入教程.md)；
3. **建第一个工程**：回主页点 `New` 就能进入编辑界面开始写音符。

另外提前说一句：官方仓库明确写了这个软件目前还比较不稳定，编辑时**记得勤保存**，万一闪退可以用工程同目录下的恢复文件找回来，细节见[常见问题与闪退排查.md](常见问题与闪退排查.md)。
