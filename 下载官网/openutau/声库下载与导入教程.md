## 一、先搞清声库的三种类型

OpenUtau Mobile 官方仓库列出三类可用的歌手类型：

| 类型 | 合成方式 | 特点 |
| --- | --- | --- |
| DiffSinger | AI 神经网络合成 | 出声自然度高，是社区现在的主流方向，也是 OpenUtau Mobile 宣传里主打的一类 |
| UTAU | 传统音频采样拼接 | 老牌体系，历史声库数量最多，手动调音空间大 |
| Vogen | AI 合成（中文向） | 中文 AI 歌声声库 |

官方注明「其他未经测试的类型不保证正常工作」，所以拿到来历不明的声库装不上时，先确认它是不是这三类。

## 二、声库去哪里找

官方 README 推荐的两个入口：

1. **DiffSinger 自定义声库分享页**：一份腾讯文档表格，社区把自制 DiffSinger 声库的下载链接集中登记在那里（入口链接写在 [github.com/vocoder712/OpenUtauMobile](https://github.com/vocoder712/OpenUtauMobile) 仓库首页的 Quick Start 一节）；
2. **UTAU Wiki**：[utau.fandom.com](https://utau.fandom.com/)，各类 UTAU 声库的介绍页通常会给出发布页链接。

除这两个入口外，社区教程里通行的一条找声库路径是：在萌娘百科（[zh.moegirl.org.cn](https://zh.moegirl.org.cn/)）搜歌手名 → 进歌手页的「外部链接」区找 UTAU 百科 → 在百科页的声库区选版本点 DL 下载压缩包。

社区讨论里常被提到的声库有重音 Teto、足立レイ、洛天依等，找声库时按歌手名搜索即可。声库文件一般打成 ZIP 包，体积从几十 MB 到上 GB 都有，下载前留意手机剩余空间。

## 三、导入步骤

综合官方 Quick Start 与多篇社区教程，完整流程是：

1. 把声库 ZIP 压缩包放进手机内置存储 —— **别提前手动解压**，也别放进多层嵌套的文件夹（嵌套太深会加大识别难度）；
2. 打开应用，主页点击 `Singer` 按钮进入歌手列表；
3. 点右下角的 `+` 号，应用申请「查看所有文件」权限时选择允许 —— 不给这个权限就读不到声库文件；
4. 选中声库 ZIP 包，选择压缩包解码方式（一般选列表最上方的默认项；装不上或歌手名变乱码时再换其他编码）；
5. 按界面提示填写歌手类型（常见有 CV、CVVC、VCCV 等，不确定就先用默认，装完不对再换）；
6. 等解压完成、按提示安装，回到歌手列表确认新歌手出现，回主页点 `New` 新建工程就能选它演唱。

几条补充：

- UTAU 类压缩包要通过应用内置的导入功能添加，不要手动解压后把文件夹直接丢进目录；
- 声库包以 ZIP 为主；也有第三方资料称支持 `.uar` 包和文件夹形式加载，以你手上应用导入界面的实际支持为准；
- 1.1.3 版本起支持配置「额外歌手目录」，声库可以放在自定义目录里（官方更新说明口径）；
- 有用户反馈把声库放在 SD 卡或 OTG 设备上会读取失败，声库文件建议放在手机内置存储里。

## 四、DiffSinger 声库的依赖问题

DiffSinger 声库不是单个文件就完事，部分声库运行时需要配套的依赖包。1.1.7 版本的更新说明里提到加入了「依赖项安装与管理机制」来简化这个流程 —— 实际使用时，如果加载某个 DiffSinger 声库时界面提示缺依赖，按提示操作即可；没有提示就正常使用。依赖、性能与调音入口的完整说明单独成篇，见[DiffSinger声库使用与依赖安装.md](DiffSinger声库使用与依赖安装.md)。

另外注意：AI 类声库的合成计算全部在你的手机上完成，不联网也能用，但合成速度取决于手机性能，老设备上出声会慢一些。
