# mcaddon 文件怎么导入我的世界（安卓 / iOS）

> 本篇讲 `.mcaddon`、`.mcpack` 这类文件怎么手动装进《我的世界》基岩版：安卓和 iPhone 各自的打开方式、下载成 `.zip` 怎么补救、导入成功后去哪里确认。

## 一、先分清这几种文件

基岩版的加载项内容打包成几种固定后缀，装法一样、装完去的地方不同：

| 后缀 | 里面是什么 | 导入后去哪找 |
| --- | --- | --- |
| `.mcpack` | 单个资源包或行为包 | 编辑世界时的「资源包」或「行为包」页签 |
| `.mcaddon` | 行为包 + 资源包合在一起（可能含多个） | 同上，两个页签里分别找 |
| `.mcworld` | 一个完整的世界存档（可能自带加载项） | 游戏主界面「游戏」菜单的存档列表 |
| `.mctemplate` | 世界模板 | 新建世界时可选的模板列表 |

如果你是从 Craft Addons 里下载的内容，优先用应用内的一键导入（流程见[模组皮肤导入游戏教程.md](模组皮肤导入游戏教程.md)）；手动导入是应用内导入没反应时的兜底办法。

## 二、安卓手机怎么打开

1. 用文件管理器找到下载的文件，一般在 `Download`（下载）目录；系统自带「设置 → 存储 → 浏览」也能当文件浏览器用。
2. 点一下文件，系统会让你选择用哪个应用打开，选《我的世界》。
3. 游戏弹出「导入成功」的通知就完成了：
   - 打开的是 `.mcworld` → 提示世界导入成功，从「游戏」菜单能找到；
   - 打开的是 `.mcpack` / `.mcaddon` → 弹窗提示包导入成功，编辑世界时到「行为包」或「资源包」页签里找。

## 三、iPhone / iPad 怎么打开

1. 在来源处（浏览器、聊天工具、云盘 App）点开文件；
2. 系统提示用哪个应用打开时，选《我的世界》，点「在 Minecraft 中打开」；
3. 后续确认位置与安卓相同（`.mcworld` 在游戏菜单，`.mcpack` 在世界的包页签）。

## 四、下载下来是 .zip 怎么办

有的网站或传输方式会把文件转成 `.zip`。官方文档给的补救办法是直接改后缀：把 `.zip` 改成 `.mcpack`（资源包 / 行为包）或 `.mcworld`（世界存档），再按上面的方式打开。改后缀在文件管理器的「重命名」里做；看不到扩展名的话，先在文件管理器设置里打开「显示文件扩展名」。

## 五、导入成功后去哪确认

| 你导入的 | 确认位置 |
| --- | --- |
| 资源包 / 行为包 | 编辑（或新建）世界 → 下拉到「资源包」「行为包」→ 列表里能看到 → 点「启用」 |
| 世界存档 | 主界面「游戏」→「新建」列表 |
| 模板 | 新建世界的模板选择页 |

启用这一步不能省，具体见[模组皮肤导入游戏教程.md](模组皮肤导入游戏教程.md)第四节；自己用编辑器做的行为包导出后，也按本篇流程装回游戏，制作入口见[插件编辑器入门教程.md](插件编辑器入门教程.md)。

## 六、点开没反应的常见原因

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点文件没有任何弹窗 | 手机没装基岩版，或没有应用注册了这个后缀 | 先装《我的世界》国际版；或长按文件 → 「用其他应用打开」→ 选《我的世界》 |
| 提示导入失败 | 文件不完整 / 后缀被改坏 | 重新下载一次；`.zip` 改后缀时确认改的是扩展名本身 |
| 导入成功但游戏里没有 | 忘了在世界设置里启用 | 按第五节去世界的包页签开启 |
| 反复失败 | 应用或游戏版本过旧 | 两边都更新到当前版本再试 |

逐条试过还不行的，去[常见问题排查.md](常见问题排查.md)按现象对号入座。
