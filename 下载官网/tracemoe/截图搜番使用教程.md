用 tracemoe 查一张动漫截图的出处，核心动作只有一个：把尽量「原汁原味」的一帧交给它，然后拿返回的预览短片核对结果。整个过程一分钟内能走完，成败的关键在挑图这一步。

## 一、先挑一张「好搜」的截图

搜索按图匹配，所以图本身的状态直接决定成败。挑图记住四条：

1. 用**原始比例的完整画面**，别裁剪、别加边框贴纸；
2. 别用加了滤镜的图（黑白、调色、反转色这类都不行）；
3. 分辨率别太低，至少 320x180 这个量级；
4. 别对着屏幕翻拍 —— 直接用播放器截图或保存的原图。

每条背后的原因和更多反例，整理在 [搜不到结果的常见原因.md](搜不到结果的常见原因.md)，搜不动的时候先去对着那张表检查。

## 二、搜索步骤

界面文字为英文，但操作路径很短，以应用内实际界面为准：

1. 先把要查的截图存进手机相册（或复制图片地址，取决于应用当次提供的入口）；
2. 打开 tracemoe，选择上传图片或粘贴图片地址；
3. 等待搜索完成，通常几秒到十几秒；
4. 看结果列表，从相似度最高的那条往下核对。

一次没搜中可以换一帧再搜。同一部番的不同画面匹配结果差别很大，换图重搜往往比反复调一张图更有效。

## 三、怎么读搜索结果

结果里通常包含这几类信息，逐项核对：

| 结果字段 | 含义 | 你要做的 |
| --- | --- | --- |
| 作品名 | 截图所属的番剧，可能同时给日文原名与罗马音 | 拿名字去搜一下确认是否存在这部番 |
| 集数 | 该画面出现在第几集 | 注意剧场版、OVA 会单算 |
| 时间点 | 该画面在那一集出现的时刻 | 用它快速跳转核对 |
| 相似度 | 画面匹配程度 | 高相似度只是参考，最终以预览为准 |
| 预览短片 | 命中场景前后几秒的片段 | 最可靠的核对依据，看一眼就知道对不对 |

结果不一定全对 —— 官方也明说搜索结果可能出错，所以才提供几秒预览给你验证。**核对习惯**：点开预览短片，画面和你手里的截图对上了，这条结果才算数；对不上就试下一条。

## 四、手机之外的三条备用渠道

同一个搜索引擎在电脑上也能用，场景不同可以换着来：

- **网页版**：浏览器打开 [https://trace.moe/](https://trace.moe/)，把图片拖进页面或粘贴图片地址即可搜索，电脑上批量核对截图时更顺手；网页端上传时会自动裁掉画面边框，裁的位置不对可以手动拖动调整；
- **浏览器扩展**：官方出了 Chrome / Firefox / Edge / Opera 的「Search Anime by Screenshot」扩展，网页里看到截图可以右键直接搜，不用先存图；
- **Telegram Bot**：Telegram 里找 [@WhatAnimeBot](https://telegram.me/WhatAnimeBot)，把图发给机器人就能搜。它接受图片、GIF、视频、贴纸和图片链接，也能把别的会话里的图直接转发给它；群聊里回复某张截图并 @WhatAnimeBot 同样可搜。发图时在说明文字里附加这些关键词可以控制行为：`mute`（预览短片静音）、`nocrop`（关闭自动裁边）、`skip`（只要文字结果、不生成预览短片）。想让它固定用中文回答，发 `/lang` 选简体中文即可。

这几条渠道和 tracemoe 搜到的是同一套库，结果互相印证。短时间内大量搜索会碰到限速与配额，规则和自查入口见 [搜索配额与用量限制.md](搜索配额与用量限制.md)。安装包还没着落的话，回 [下载与安装教程.md](下载与安装教程.md)；别的疑问看 [常见问题解答.md](常见问题解答.md)。
