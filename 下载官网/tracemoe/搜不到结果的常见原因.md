# 搜不到结果的常见原因

> 截图发上去没有结果或结果明显不对时，按本篇两张表逐项排查：先是图的问题，再是收录范围的问题。都不属于的话看 [常见问题解答.md](常见问题解答.md)。
> **相关文档**：[截图搜番使用教程.md](截图搜番使用教程.md) · [常见问题解答.md](常见问题解答.md)

---

tracemoe 搜不到结果，多数情况出在截图本身；图本身没问题的话，就要考虑「这部番还没被收录」。下面两张表分别对应这两种情况，排查顺序建议先图后库。先分清两件事：**返回「没有匹配」**才需要按本篇排查；如果搜索请求本身报错、转圈发不出去，多半是撞了限速或配额，直接看 [搜索配额与用量限制.md](搜索配额与用量限制.md)。

## 一、先检查截图本身

按匹配方式，只有和原片画面「近乎一样」的图才容易命中。对照下表逐项检查：

| 截图问题 | 为什么搜不到 | 怎么改 |
| --- | --- | --- |
| 裁剪过（只留人物局部） | 画面信息丢得太多 | 换完整的原始画面帧 |
| 带黑边 / 白边 / 相框 | 多出来的边框会干扰匹配 | 先把边框裁干净，保留纯画面 |
| 加了滤镜（黑白、调色、加深减淡等） | 颜色信息被大幅改动 | 找未加滤镜的原图 |
| 镜像 / 翻转 / 旋转过 | 画面方向变了就匹配不上 | 猜测被翻转过的话，翻转回来再搜 |
| 大段字幕或水印占满画面 | 大面积文字盖住了画面本身 | 换字幕少、画面干净的帧 |
| 画面太暗或大片纯色 | 可辨认的特征太少 | 换光影层次丰富的帧 |
| 分辨率过低 | 细节不足，低于 320x180 量级基本搜不动 | 找更高清的同一画面 |
| 对着屏幕翻拍 | 角度、反光、摩尔纹都会破坏画面 | 改用播放器直接截图或原图文件 |

两个容易忽略的点：

- **GIF 也可以用** —— 抽其中一帧发上去就行，前提是那一帧本身没被过度加工；
- **手绘的近似画面也能命中** —— 只要构图和上色与原场景足够接近，不必非得是播放器截的图。

## 二、再确认收录范围

图没问题还是搜不到，多半是库里还没有这部番：

| 情况 | 说明 |
| --- | --- |
| 正在播的新番 | 播出后大约 24 小时才会收录，刚播完的剧情要等一等 |
| 老番 | 大部分 2000 年以后的日本动画有收录，90 年代只有部分热门作品，更早的很少 |
| 长篇日常番 | 《哆啦A梦》《蜡笔小新》《樱桃小丸子》《游戏王》这类作品收录不全 |
| 非日本动画 | 欧美动画、国产动画不在收录范围内 |
| 漫画 / 插画 / 同人图 | 完全不在收录范围内，用这类图不会有有意义的结果 |

收录列表以官方说明为准，具体可在 [https://trace.moe/faq](https://trace.moe/faq) 查看；服务是否在正常运行可以看状态页 [https://status.trace.moe/](https://status.trace.moe/)。

## 三、排查后的两条出路

1. **换一帧重搜**。同一部番里随手再截一帧信息丰富的画面，往往一次就中，比反复加工同一张图有效得多；
2. **换工具**。图本身是漫画、插画、壁纸的话， tracemoe 帮不上忙，改用 [https://saucenao.com/](https://saucenao.com/) 或 [https://iqdb.org/](https://iqdb.org/)，这两个专门搜这类图。更多渠道差异见 [常见问题解答.md](常见问题解答.md)，基础操作不会的话回 [截图搜番使用教程.md](截图搜番使用教程.md)。
