## 一、动手前先自查三件事

不管什么现象，先把这三条过一遍，能省掉一半无效尝试：

1. **版本**：装的是不是 `com.jushuitan.JustErp`（在「设置 → 应用 → 应用信息」里看），版本号与你预期的是否一致（这份安装包是 `v3.0.9`，口径见 [下载与安装教程.md](下载与安装教程.md)）。
2. **账号**：登的是不是你企业的账号——账号没关联企业，进去必然是空的，见 [账号注册与登录.md](账号注册与登录.md)。
3. **网络**：它全程要联网，先把 Wi-Fi / 流量切一下确认网络通。

## 二、安装失败 / 装不上

按命中率排：

1. **没允许未知来源**：安装时被系统拦下，按提示进「设置 → 安全 / 安装未知应用」，放行你用的浏览器或文件管理器（各品牌菜单名不同，见 [下载与安装教程.md](下载与安装教程.md) 第四节）。
2. **与手机上已装的版本打架**：如果你之前从应用商店装过 JustErp，商店包和这份包签名可能不同，直接覆盖会提示失败。处理：**卸载旧的再装这份**——数据在云端，重装后登同一账号即可，不会丢（见 [账号注册与登录.md](账号注册与登录.md) 第五节）。
3. **文件不完整**：下载中断会装到一半报错。用 MD5 工具比对 `3D541BF62615AB61591BBD51E8B35411`，对不上就重新下。
4. **空间不足**：安装包 30.09M，但解压安装还要额外空间，清一下存储再试。

## 三、打开就闪退 / 白屏

1. 先升级：旧版本跑在新系统上是闪退常见原因，换最新包（官方下载页 [app.jushuitan.com/sdrms/home/download/20](https://app.jushuitan.com/sdrms/home/download/20)，以页面当时显示为准）。
2. 还闪退就清缓存：**设置 → 应用 → JustErp → 存储 → 清除缓存**（先别清数据，清数据会把本地登录态也抹掉，重登一次虽然不丢单据但麻烦）。
3. 两步都无效就卸载重装，装完按第四节把权限给齐。

## 四、权限被拒导致功能受限

**设置 → 应用 → JustErp → 权限** 里确认：

- **网络**：必须给，不给等于废掉；
- **存储 / 照片和文件**（安卓 13+ 上表现为媒体类权限）：涉及导出文件、保存面单时要允许，拒绝后对应功能会直接失败或没有任何产物；
- 提示「无法安装应用」之类与安装相关的能力，则对应权限列表里的「请求安装应用」项，按系统弹窗放行即可。

## 五、打印面单失败

有渠道记载过**部分安卓机型打印面单失败**的问题，对应版本的更新日志称已修复。处理顺序：

1. 升到最新版（官方下载页见上）；
2. 检查打印机与手机在同一网络 / 已配对，打印测试页确认打印机本身没问题；
3. 面单模板、快递公司在后台配好后手机端才能取到；
4. 还不行就换电脑端打印——批量面单本来就更适合在电脑上打（见 [订单审核与发货操作.md](订单审核与发货操作.md) 第五节）。

## 六、订单不显示 / 数据看起来没更新

1. 切到「全部订单」页签再找一遍，别只盯着当前状态页；
2. 下拉刷新或退出订单页重进；
3. 确认登录账号与你司店铺匹配、账号有这家店的权限——不对就找企业管理员（见 [账号注册与登录.md](账号注册与登录.md)）；
4. 以上都正常还是没有：订单是后台规则流转的，卡在某一状态多半是规则拦的，去电脑端订单页看异常原因（见 [订单审核与发货操作.md](订单审核与发货操作.md) 第三节）。

## 七、怎么更新到最新版

两条路任选：手机上从你常用的应用商店更新；或从官方下载页 [app.jushuitan.com/sdrms/home/download/20](https://app.jushuitan.com/sdrms/home/download/20) 下最新 APK 覆盖安装（报「安装失败」就先卸载再装，数据不丢）。版本号以页面当时显示为准，别拿第三方下载站标的时间当准。
