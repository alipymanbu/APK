# 聚水潭面单打印怎么设置

> 快递面单的打印基本是电脑端的活：绑快递、配面单账号、装打印组件，再按「获取面单 → 打印 → 发货」的顺序走。

## 一、先把链路摆正

一笔单从审核到发出的完整顺序是：

```
已付款待审核 → 审核 → 打单拣货 → 获取电子面单 → 打印物流单 → 直接发货
```

审核在手机上做也行（见 [订单审核与发货操作.md](订单审核与发货操作.md)），但**绑快递、配面单、装打印组件、批量出单这些设置与操作都在电脑端网页版**。手机端也有打面单的入口，只是有渠道记载过部分安卓机型打印失败的问题（见 [常见问题与解决方法.md](常见问题与解决方法.md) 第五节），日常批量出单别指望它。下面的步骤按官方文档与公开教程整理，界面名称以你实际版本为准。

## 二、开打之前的三项设置

1. **绑定物流公司**：电脑端进「设置 → 物流（快递）公司及打印模板」，点「绑定新的物流（快递）公司」，勾选你合作的快递保存；绑完选中它做「编辑」，审单时系统才能自动匹配快递（公开教程口径）。
2. **配好电子面单账号**：面单号是各平台电子面单账号生成的——菜鸟（淘宝天猫）、拼多多、抖音、快手各走各的面单，账号要在后台接好。官方文档明确提到抖音订单要支持抖音电子面单、快手订单要对接快手电子面单，**没接对应面单，这平台的单就出不了号**。
3. **装打印环境**：公开教程给的配置是——聚水潭 ERP 助手（教程写明 v2.9.0.0 及以上）+ 菜鸟云打印组件（v0.4.4.4 及以上），装完用「云打印连接测试工具」确认连接正常；打印机用**热敏打印机**（80mm 或 100mm 宽）。A4 喷墨 / 激光机打不了面单，只能走「下载面单」拿 PDF 再手动打。

## 三、日常打单五步（电脑端）

1. 「订单模块 → 订单」，筛出已审核的单（没审的先批量审核，见 [订单审核与发货操作.md](订单审核与发货操作.md) 第三节）；
2. 进「打单拣货」，勾选要出单的订单（支持全选）；
3. 点「**获取电子面单**」——系统向已绑定的面单账号批量申请运单号，等提示成功、面单号字段填上才算数；
4. 点「**打印物流单**」，在弹窗里选中识别到的热敏打印机、核对纸张尺寸（如 80mm）后开打；
5. 打完保持勾选点「**直接发货**」——教程特别提醒：这一步才会把单号、承运商回传到淘宝、拼多多等平台，**只点打印不点发货，平台那边还是未发货**。

## 四、常见卡点

| 现象 | 原因与处理 |
| --- | --- |
| 打出来是空白 / 报「未获取面单信息」 | 跳过了「获取电子面单」那步，回去先取号再打 |
| 云打印组件连不上 | 重装组件后跑一遍「云打印连接测试工具」，确认显示连接正常 |
| 某个平台的单取不到号 | 该平台的电子面单账号没接或已失效，回后台核对面单配置 |
| 手机端打面单失败 | 换电脑端打，或升级 app 版本（部分机型问题有版本称已修复） |
| 打印机不出纸 | 先打张测试页排除打印机本身；再核对模板纸张尺寸与实际纸卷是否一致 |

## 五、单量大了嫌慢

两条公开教程里给的提速开关：一是「设置 → 系统参数设置 → 打单设置」里的**批量面单合并渲染**（开启后取面单会自动分组、打印一次成批进队列）；二是打印机临时趴窝时，勾选已取号的订单点「**下载面单**」拿 ZIP 里的 PDF，用阅读器离线批量打。这两项都是电脑端设置，版本不同入口可能有出入，以界面实际显示为准。
