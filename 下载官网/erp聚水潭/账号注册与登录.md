## 一、先弄清楚：装了 app 不等于有账号

JustErp 只是聚水潭 ERP 的手机端，而聚水潭是给企业用的 SaaS 系统——你手机上看到的订单、库存，都是你公司在聚水潭里开的账号名下的数据。**账号一般由企业管理员在聚水潭后台开通并分给你**（有子账号体系，权限也是管理员分的），不是下载完 app 就自动有一个。你要是卖家或仓库人员，先问一句「公司开通聚水潭了吗、给我的账号是什么」，能省掉后面一串折腾。

## 二、登录步骤

1. 打开 JustErp，在登录页输入 ERP 账号和密码。
2. 点「登录」，进入「工作台」页面。
3. 日常操作从工作台进，点「订单」就是单子列表，流程见 [订单审核与发货操作.md](订单审核与发货操作.md)。

账号密码是从公司拿的，不是手机号注册出来的通用账号——拿不准先问管理员，别拿自己手机号反复试。

## 三、没有账号：登录页的「立即注册」

多个使用教程的截图里都能看到登录页有「立即注册」入口，点开按表单填信息即可走完注册流程。要分清的是：这条路注册出来的是聚水潭系统的一个账号，**能不能看到你店铺的数据，取决于你的企业是否已开通、有没有把这个账号关联到你的企业**。注册完登录进去空空如也，不是 app 装错了，是账号权限没到位——找企业管理员处理。

## 四、忘记密码 / 登不上

按这个顺序排：

1. 先核对账号密码本身：大小写对不对、复制粘贴有没有带上空格（从聊天记录里复制的账号常带空格）。
2. 登录页上若有找回 / 重置入口，按提示走一遍。
3. 没有找回入口的，密码只能在聚水潭后台重置——找你企业的管理员；管理员也处理不了，打官方客服 `400-806-8666`（官网 [www.jushuitan.com](http://www.jushuitan.com) 首页挂的号码）。
4. 确认没输错还提示「账号或密码错误」：多半是这个账号没开、或已被停用，同样走管理员或客服。

更完整的排查（网络、版本、闪退）见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 五、换手机、重装、卸载重开

聚水潭的数据存在云端服务里，不在你手机本地。换手机只要三步：装好 app（见 [下载与安装教程.md](下载与安装教程.md)）→ 登同一账号 → 单据、库存照旧。卸载重装也一样，**不需要重新注册**，也不会因为重装丢数据；被清掉的只是本地缓存，代价只是首次打开多加载一会儿。

## 六、常见疑问

| 疑问 | 回答 |
| --- | --- |
| 注册了还是看不到单子 | 账号没关联到企业、或权限不够，找企业管理员开通并授权 |
| 换手机要不要重新注册 | 不用，装好 app 登同一账号即可 |
| 密码忘了找谁 | 先找企业管理员在后台重置；处理不了再打官方客服 `400-806-8666` |
| 想自己注册一个随便试试 | 注册入口走得通，但没有企业数据，进去也看不到真实单据 |
| 公司停用我的账号了 | 手机端登不上是预期结果，账号的开与停只能由企业管理员操作 |
