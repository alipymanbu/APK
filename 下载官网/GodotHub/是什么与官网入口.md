## 一、GodotHub 是什么

GodotHub 是面向国内 Godot 引擎开发者的第三方社区平台，由 GodotHub 社区运营，官网在 [godothub.com](https://godothub.com)。它不修改、不发行引擎本身，主要做三件事：

- 给 Godot 各版本提供下载入口与国内镜像加速；
- 聚合插件、工程模板、代码片段、素材这类开发资源；
- 承载中文教程、资讯与社区讨论，把散在各处的资料收到一处。

安卓 App（包名 `com.godothub.app`）是这套平台的手机端，把引擎管理、项目管理、资源与教程装进同一个应用。本套文档使用的安装包为 1.0.8 版，大小 25.28 MB。

## 二、和 Godot 官方是什么关系

Godot 是开源的跨平台游戏引擎，官方站点在 [godotengine.org](https://godotengine.org/)，采用 MIT 许可证。GodotHub 与 Godot 官方没有隶属关系，是社区自发搭建的服务平台。对使用者的实际影响：

- 引擎本体以 Godot 官方发布为准，GodotHub 提供的是下载通道与周边服务；
- 引擎本身的 Bug 与功能疑问，以 Godot 官方文档与官方仓库为最终依据；
- 插件、模板等第三方资源，GodotHub 负责聚合与展示，质量与授权以资源详情页标注为准。

## 三、官方渠道一览

| 渠道 | 入口 | 用途 |
| --- | --- | --- |
| 官网 | [godothub.com](https://godothub.com) | 引擎下载、资讯、资源中心与社区入口 |
| 引擎镜像页 | [godothub.github.io/download/engine](https://godothub.github.io/download/engine/) | 按系统与版本列出引擎、导出模板的镜像下载 |
| 社区软件页 | [godothub.github.io/download/app](https://godothub.github.io/download/app/) | Windows 桌面端的获取入口 |
| 开源仓库 | [atomgit.com/godothub](https://atomgit.com/godothub) | 社区开源项目（Gitee 组织页注明已迁移至此） |
| 安卓 App | 见 [下载与安装教程.md](下载与安装教程.md) | 本文主题，包名 `com.godothub.app` |

社区还有公众号、论坛与微信/QQ/Discord 社群，入口从官网底部可查；自 2023 年起每年举办一届 GodotHub Festival 开发大赛。

## 四、安卓 App 的功能构成

按 1.0.8 版的界面，功能集中在五个模块（具体措辞以你手上的版本为准）：

- **引擎**：列出 Godot 3.x 与 4.x 各版本，支持下载、安装与切换，走国内镜像；
- **项目**：管理手机里的 Godot 工程，可新建 2D/3D 工程或导入已有项目；
- **资源**：插件、模板、代码片段与素材，按类型与适配版本筛选，带评分评论；
- **教程**：入门、进阶、实战分类的中文图文内容；
- **社区**：浏览与发布开发经验、项目模板，找协作伙伴。

各模块怎么操作，分别写在 [引擎下载与版本切换.md](引擎下载与版本切换.md) 和 [项目与插件使用入门.md](项目与插件使用入门.md)。

再补充一层关系：「引擎」模块里装的各版本，本体就是 Godot 官方的安卓编辑器安装包，GodotHub 做的是镜像加速与统一管理；所以编辑器本身的限制与更新节奏，以 Godot 官方页面为准。
