## 一、先装好 App

引擎管理是 App 内的功能，你先要有 GodotHub 本体，获取与安装看 [下载与安装教程.md](下载与安装教程.md)。本文以 1.0.8 版为基准，界面措辞以你手上的版本为准。

## 二、下载与安装引擎版本

App 的引擎模块把 Godot 3.x 与 4.x 的各版本整理成列表，走国内镜像分发，不用再去各处找下载源。典型流程：

1. 进入引擎界面，浏览或搜索目标版本；
2. 选定版本后点击下载，等待完成（镜像通道通常比直连官方源顺畅，实际速度看你的网络）；
3. 下载完成后按提示安装，同一台手机可以保留多个版本；
4. 不再需要的版本在应用内卸载，占空间的缓存也可以一并清理。

版本列表随官方发布节奏更新，想要某个具体版本时，先在列表里搜版本号再下载。

## 三、给项目切换引擎

App 会记录每个工程适配的引擎版本：

- 打开项目时能看到它对应的引擎版本；
- 版本不匹配时，在项目详情里可以切换到匹配的引擎；
- 新建工程时选择 2D 或 3D，并确认使用的引擎版本。

具体操作步骤见 [项目与插件使用入门.md](项目与插件使用入门.md)。

## 四、安卓端跑 Godot 编辑器的几个现实约束

这部分来自 Godot 官方对安卓编辑器的说明，与你从哪个入口安装无关，装上之后都会遇到：

- **官方定位是实验阶段**：安卓编辑器在 Godot 官方下载页标注为 experimental，稳定度不如桌面版；
- **强烈建议外接键盘鼠标**：编辑器 UI 尚未针对触屏适配，纯触屏操作效率很低；
- **C#/.NET 在安卓编辑器上不可用**：官方注明安卓编辑器不含 C# 支持，需要 C# 就回到桌面端；
- **导出安卓包另有条件**：从安卓编辑器导出时若走 Gradle，还需要额外安装官方的 GABE（Godot Android Build Environment）应用；非 Gradle 导出或导出其他平台则不需要。
- **输入与后台的已知问题**：官方文档列出的已知问题包括——用三星键盘写脚本时可能随机插入字符（建议换 GBoard 等键盘）；开发者选项开了「不保留活动」时，编辑器切后台再回来可能无法正常恢复；「所有文件访问」权限受限时只能访问部分目录，建议在系统设置里把该权限授予编辑器；
- **渲染器选择**：安卓设备上一般选 Mobile 或 Compatibility 渲染器，Forward+ 在部分设备上性能表现不佳，官方也不推荐。

官方安卓下载页在 [godotengine.org/download/android](https://godotengine.org/download/android/)，最新版本与要求以该页为准。安装或启动遇到问题，先看 [常见问题与解答.md](常见问题与解答.md)；做完工程要出安装包，路线见 [导出安卓安装包.md](导出安卓安装包.md)。
