# JoiPlay 存档在哪里：各引擎位置与备份方法

> JoiPlay 没有统一的存档目录，存档跟着游戏文件夹走。本篇列出各引擎的存档落点、PC 与手机之间怎么互拷存档、重装前怎么备份。

## 一、先记住一个原则

JoiPlay 跑的是游戏本体的存档逻辑，所以存档落在**你放游戏的那个文件夹**里，而不是 JoiPlay 自己的目录里。你在 [怎么添加游戏.md](怎么添加游戏.md) 里把游戏放在哪，存档就在哪。这也是为什么前面建议把游戏放在普通目录 —— 存档要经常拷进拷出，放在好找的地方，后面所有操作都简单。

## 二、各引擎的存档位置

| 引擎 | 存档位置 | 存档文件长这样 |
| --- | --- | --- |
| RPG Maker MV / MZ | 游戏目录的 `www/save/` | `file1.rpgsave`、`global.rpgsave` |
| RPG Maker VX Ace | 游戏目录的 `save/` | `Save01.rvdata2` 起 |
| RPG Maker VX | 游戏目录的 `save/` | `Save01.rvdata` 起 |
| RPG Maker XP | 游戏目录的 `Save/` | `Save01.rxdata` 起 |
| Ren'Py | 游戏目录的 `game/saves/`；个别游戏没有这个目录时，存档会落在内部存储的 JoiPlay 数据目录里 | 一串数字加 `.save`，另有 `persistent` 文件 |

三个实用判断技巧：

- 分不清引擎？看游戏文件夹里有没有 `www` 子目录：有就是 MV/MZ，存档在 `www/save/`；没有 `www` 但有 `Data`，就是 XP/VX/VX Ace 系。
- 存档文件按「槽位」编号，`file1` / `Save01` 就是游戏里第一个存档位，和你在游戏里看到的存档栏一一对应。
- 全局存档（如 MV 的 `global.rpgsave`）记录存档栏的预览信息；Ren'Py 的 `persistent` 文件记录「已看过的场景」和回廊解锁状态。备份时把它们一起带上，不然读档列表、图鉴回忆会缺一块。

## 三、PC 存档与手机存档互通

RPG Maker 与 Ren'Py 的存档文件本身与平台无关，PC 端和 JoiPlay 端的存档是同一套文件，互拷就能用：

- **PC 存档带过来**：把 PC 游戏目录里 `www/save/`（或 `save/`、`saves/`）里的文件，拷到手机上同款游戏的对应文件夹，覆盖前先留一份原件。
- **手机存档带回 PC**：反向拷贝即可。
- 前提是**两边游戏版本一致**。游戏更新后存档结构可能变化，跨版本的存档能不能读由游戏决定，读不出来先确认版本。

## 四、备份与恢复

**最省事的做法**：把整个游戏文件夹拷走 —— 存档、游戏、设置一起带走，恢复时原样拷回来再在 JoiPlay 里重新添加一次。

**只备份存档**：按第二节的位置表，把存档文件夹拷出来就行，体积通常只有几 MB。

几个提醒：

- 重装 JoiPlay 主程序或插件**不动游戏文件夹**，存档不受影响；会丢存档的是「删了游戏文件夹」这一步。
- 手动改存档文件（换档、改数值）之前，先把原文件复制一份，改坏了还有退路。
- 存放游戏的目录如果是 `Android/data/`，普通文件管理器进不去，备份会很折腾 —— 这也是建议把游戏放普通目录的另一个原因。

## 五、游戏存不了档怎么办

存档栏点下去报错、或存完重开进度没了，按这三条查：

1. **给「所有文件访问」权限**：系统「设置 → 应用 → 特殊应用权限 → 所有文件访问」，把 JoiPlay 和 RPG Maker Plugin **都**设为允许 —— 只给主程序不够，插件也要。游戏存档实际是在往游戏文件夹里写文件，权限不足就会失败（报 `Read-only file system` 也是这个原因）。
2. **换游戏文件夹的位置**：部分机型对 `Android`、`Download` 这类系统目录限制写入，把游戏挪到自己新建的普通文件夹（如 `内部存储/Games/`）再试。
3. **SD 卡问题**：个别手机对存储卡写入有限制，把游戏从 SD 卡挪到内部存储。

更多相关现象（黑屏、闪退、报错对照表）见 [常见问题与解决.md](常见问题与解决.md)。

## 六、常见疑问

**换了手机，存档怎么迁？** 把游戏文件夹整体拷到新手机（数据线、网盘、局域网都行），在新手机的 JoiPlay 里重新添加游戏即可，存档原样生效。

**卸载 JoiPlay 会丢存档吗？** 不会，存档在游戏文件夹里，不在 JoiPlay 的应用数据里。但如果游戏文件夹放在 `Android/data/cyou.joiplay.joiplay/` 相关路径下，卸载应用可能连带清掉这些目录 —— 又一个把游戏放普通目录的理由。

**游戏内读档列表是空的？** 检查存档文件是不是拷到了错误的引擎目录（比如 MV 的存档拷到了 `save/` 而不是 `www/save/`），位置放对就能读出来。
