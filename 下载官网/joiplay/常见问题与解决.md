## 一、游戏加进去了，点开就闪退或没反应

按命中率从高到低排查：

1. **缺插件**。RPG Maker XP/VX/Ace、Ren'Py、Flash、Godot 的游戏都依赖对应插件，只装主程序跑不起来。对照 [插件安装与引擎支持.md](插件安装与引擎支持.md) 补装。
2. **Ren'Py 插件选错分支**。Ren'Py 8 的游戏配了 7.x 插件（或反过来）会直接打不开；两个分支可以共存，换一支再试。
3. **启动文件选错了**。比如 RPG Maker XP/VX/Ace 选到了 `www` 里的文件、Ren'Py 选到了 `lib` 目录。删掉这条游戏记录，按 [怎么添加游戏.md](怎么添加游戏.md) 的对照表重新添加。
4. **游戏文件夹不完整**。解压不完整、传输中断都会缺资源，现象是启动到一半退出。重新解压一份完整的覆盖。
5. **游戏本身不兼容**。官方口径里 Godot（约 50%）与 Flash（约 60%）兼容度偏低，重度自定义脚本的 RPG Maker 游戏也可能出问题。拿同引擎的另一个游戏试，能跑就是这一款游戏的事。

## 二、启动时弹出英文报错提示

| 报错信息（认关键字） | 原因 | 处理 |
| --- | --- | --- |
| `Failed to load: Graphics/...`、`Failed to load: Audio/...` | 缺 RTP 共享素材包（XP/VX/Ace 游戏） | 按 [缺少RTP怎么办.md](缺少RTP怎么办.md) 导入 RTP |
| `No game scripts specified (missing Game.ini?)` | 游戏文件夹里缺 `Game.ini` | 重新解压游戏；个别游戏打包时就漏了它，找游戏作者要 |
| `Failed to read script data` | `Game.rgssad` / `.rgss2a` / `.rgss3a` 脚本包缺失，或游戏做了特殊加密 | 先重解压；还在就报这个错的话，是加密游戏，JoiPlay 跑不了 |
| `Script error` 或弹窗带「解決?」 | 游戏脚本与运行环境不兼容 | 更新主程序和插件到最新再试；仍报就是游戏不兼容，找游戏作者反馈 |
| `Read-only file system` | 没有写入权限，存不了档 | 见第七节，给「所有文件访问」权限 |
| 「网页不可用」/ Web page not available（HTML、MV/MZ 游戏） | `index.html` 丢失、WebView 太旧或代理干扰 | 重解压游戏；更新系统里的 Android System WebView；开着 VPN / 私人 DNS 就先关掉 |
| `Your browser does not support WebGL` | 系统 WebView 过旧 | 更新 Android System WebView 后重试 |

`Game.ini` 丢失又拿不到原文件的，有人会照游戏目录里实际的 `RGSS****.dll` 和 `Data\Scripts.rxdata`（或 `.rvdata` / `.rvdata2`）自己补写一个 —— 有一定门槛，先试重解压。

## 三、黑屏（有声音、有触感，就是没画面）

- **MV/MZ 与 HTML 游戏**：多是渲染问题。进这条游戏的设置项，把渲染 / 图形相关开关切换一下（比如把 WebGL 换成 Canvas 一类；不同版本菜单名称有差异，认「Graphics」「Renderer」「WebGL」这类字样）。Canvas 模式性能会明显下降，适合救急。
- **渲染选项的用法**：渲染器一般是 OpenGL ES 的几个变体加一个软件渲染模式；软件渲染最慢但兼容面最广，卡在某个特定场景过不去时用它救场。
- **XP/VX/Ace 游戏黑屏**：先查 RTP，见 [缺少RTP怎么办.md](缺少RTP怎么办.md)。
- **有声音、按键有反应、画面全黑**：更偏设备兼容问题，升级主程序与插件到最新版再试；个别 RPG Maker XP 游戏地图全黑，有用户反馈在 RPG 设置里关掉「Use Ruby 1.8」后恢复。
- **等一会儿**。大游戏在低配机上初始化慢，加载几十秒才出画面属正常。

## 四、JoiPlay 本体装不上（解析包错误 / 应用未安装）

- **安装包没下完整**：核对文件大小，明显小于正常体积（约 26 MB 级别）就重新下载。
- **旧版本残留冲突**：从老版本升级装不上时，备份好游戏存档（见 [存档位置与备份.md](存档位置与备份.md)），卸载旧版再装新版。
- **手机是 32 位机型**：老机器或部分 Android Go 设备用的是 32 位架构，装不上只出了 64 位包的应用 —— 这种情况换设备才能解决。
- **存储空间不足**：清出足够空间再装。

## 五、已装插件，JoiPlay 却说找不到

常见于小米等用 MIUI / HyperOS 的机型 —— 系统默认不让 JoiPlay 读已安装应用列表，它就「看不见」装好的插件：

1. 系统设置 → 应用 → JoiPlay → 权限。
2. 找到「获取已安装应用信息」之类的条目（HyperOS 在「其他权限」里）。
3. 设为「始终允许」，重启 JoiPlay。

插件和主程序都升到最新版再核对一遍，个别情况重装插件也能解决。

## 六、加游戏时选不了文件 / 列表里看不到游戏

- 首次启动没给存储权限：系统「设置 → 应用 → JoiPlay → 权限」里把存储 / 文件权限设为「允许」。
- 游戏放在了 `Android/data/` 下面：安卓 11 以后这里受系统限制，选择器经常进不去。挪到普通目录（如 `内部存储/Games/`）再添加。
- 游戏放在 `Download` 等系统特殊目录也会被部分机型限制读写，建议给游戏单独建一个普通文件夹。
- 游戏还在压缩包里没解压：先完整解压成文件夹。
- **顺手防一个后续问题**：解压后游戏图片出现在手机相册里的话，在游戏文件夹（或放所有游戏的那个文件夹）里新建两个空文件，命名为 `.nomedia` 和 `.nosearch`，相册就不扫这些图了。

## 七、游戏存不了档

- **给「所有文件访问」权限**：系统「设置 → 应用 → 特殊应用权限 → 所有文件访问」，把 **JoiPlay 和 RPG Maker Plugin 都**设为允许 —— 只给主程序不够，插件也要。首次启动弹权限框时如果顺手拒了，就去设置里补。
- **换游戏文件夹的位置**：部分机型对 `Android`、`Download` 这类特殊目录限写，把游戏挪到自己新建的普通文件夹里再试。
- **SD 卡存不了档**：个别手机对存储卡写入有限制，把游戏挪到内部存储。
- 存档位置本身在哪、怎么备份，见 [存档位置与备份.md](存档位置与备份.md)。

## 八、中文显示方框或乱码

RPG Maker 游戏在手机上出现「方框」多数是字体问题，换一个自定义字体通常能解决：

1. JoiPlay 右上角菜单 → Settings（设置）。
2. 找到 RPG Maker 设置区（RPGM Settings）。
3. Custom Font（自定义字体）→ 点 CHOOSE，从手机里选一个 `.ttf` / `.otf` 字体文件。

选**笔画较细**的字体（细黑体一类），粗字重的字库在游戏里容易显示成方框。这个设置作用于 RPG Maker 游戏，改完重新启动游戏生效。

## 九、虚拟按键与键盘

- 游戏内呼出菜单可以调整虚拟手柄的布局、大小与透明度，按键位置按自己手感摆。
- RPG Maker 系游戏的传统键位（确认、取消、打开菜单）在虚拟手柄上都有对应按钮；Ren'Py 游戏点屏幕推进对话，需要输入名字之类的场景会自动弹键盘。
- 觉得按键挡视线，把透明度调低或收起，需要时再呼出。

## 十、卡顿、掉帧

- MV/MZ 与大型 HTML 游戏吃内存：玩之前清一下后台，别同时挂着几个大应用。
- 关掉省电模式再玩，有性能模式 / 游戏加速之类开关的机型把它打开。
- 旧引擎（RPG Maker XP/VX/Ace）的 2D 游戏负载最轻，低配机优先玩这类。
- 官方没有公布最低配置要求；同一款游戏在更新的设备上明显更流畅属正常现象。

## 十一、存档丢了、想备份

存档位置与备份方法单独写成了一篇，见 [存档位置与备份.md](存档位置与备份.md)。核心一句话：存档在游戏文件夹里，重装 JoiPlay 前把游戏文件夹整个拷走就等于把存档带走了。
