## 一、先准备游戏文件夹

JoiPlay 里没有任何内置游戏，你加进去的是什么就玩什么。绝大多数情况下，你需要的是该游戏 **PC 版的完整文件夹**：

1. 把游戏的压缩包（zip / rar）解压出来 —— 别对着压缩包里的文件添加，先完整解压。
2. 解压后的文件夹里应该有 `Game.exe`（RPG Maker 系）、游戏同名的 `.exe`（Ren'Py 系）或 `index.html`（HTML 系）这类启动文件，旁边跟着 `www`、`Data`、`lib`、`audio`、`img` 等资源文件夹。
3. 把整个文件夹拷到手机存储的普通目录，比如 `内部存储/Games/游戏名/`。保持文件夹内部结构原样，一个文件都不能拆出来单放。

**放哪里有讲究**：放「内部存储」或 SD 卡的普通目录最省事；不要放进 `Android/data/` 下面 —— 安卓 11 以后普通文件管理器进不去这个目录，之后想拷存档、换文件都麻烦（详见 [存档位置与备份.md](存档位置与备份.md)）。

游戏从哪来：各游戏的官方发布页、商店页或作者主页都会提供 PC 版下载，官网的说法是「直接从游戏商店等官方来源下载，或把电脑上的游戏文件夹拷到手机」。用电脑下载再传到手机，往往比手机直接下大文件更稳。

## 二、添加游戏的完整步骤

1. 打开 JoiPlay，点右上角「+」。
2. 选「Add Game」（添加游戏）。
3. 逐项填写：

| 字段 | 填什么 |
| --- | --- |
| Name | 游戏名，随便起，显示在列表里 |
| Executable File | 点 CHOOSE，去文件里选启动文件（见下表） |
| Icon（可选） | 想换图标就选一张图，不选就用默认 |

4. 点 ADD 保存，游戏出现在主列表。
5. 点游戏即可启动；第一次启动某个引擎的游戏前，确认对应插件已装好（见 [插件安装与引擎支持.md](插件安装与引擎支持.md)）。

## 三、不同引擎分别选哪个启动文件

| 你玩的游戏 | Executable File 选这个 | 需要的插件 |
| --- | --- | --- |
| RPG Maker XP / VX / VX Ace | 游戏目录里的 `Game.exe` | RPG Maker Plugin |
| RPG Maker MV / MZ | 游戏目录里的 `Game.exe`，或 `www/index.html`（官方说明两种都行，一个打不开就换另一个） | 不需要（主程序自带 HTML 支持） |
| Ren'Py 游戏 | 游戏目录里与游戏同名的 `.exe` | Ren'Py 插件（8.x 或 7.x 按游戏版本选） |
| TyranoBuilder / TyranoScript | 游戏目录里的 `index.html` | 不需要 |
| Construct 2/3 及其他 HTML5 游戏 | `index.html` | 不需要 |
| Adobe Flash 游戏（.swf） | 游戏的 `.swf` 文件 | Ruffle Plugin |
| Godot 3 / Godot 4 游戏 | 以官方说明为准（实验性支持，仅 GDScript 制作的游戏） | 对应版本的 Godot 插件 |

几个容易踩的点：

- **选错启动文件是最常见的失败原因**。RPG Maker XP/VX/Ace 选了 `www` 里的文件、Ren'Py 选了 `lib` 目录里的东西，都会启动失败。
- RPG Maker MV/MZ 的 `Game.exe` 在游戏根目录，`index.html` 在 `www` 子目录里，两者别混。
- Ren'Py 游戏的 `.exe` 名字跟游戏走（比如 `MyGame.exe`），不叫 `Game.exe`，别找不到就以为下错了。
- **路径尽量全英文、不含空格**。有用户反馈中文或特殊字符路径会让个别游戏读不到文件；给游戏建个 `Games` 文件夹统一放，出问题的概率最小。
- RPG Maker XP/VX/Ace 游戏启动时报 `Failed to load: Graphics/...` 之类的缺文件错误，不是加错了，是缺 RTP 共享素材包，处理见 [缺少RTP怎么办.md](缺少RTP怎么办.md)。
- 加完点开没反应或直接闪退，先按 [常见问题与解决.md](常见问题与解决.md) 排查插件与文件完整性，再考虑游戏本身不兼容。

## 四、装好之后

- 想调整虚拟按键布局、屏幕比例，长按列表里的游戏或在游戏内的菜单里进设置。
- 存档会落在游戏文件夹里，怎么备份、怎么把 PC 端存档带过来，看 [存档位置与备份.md](存档位置与备份.md)。
