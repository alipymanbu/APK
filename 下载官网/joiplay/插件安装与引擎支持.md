# JoiPlay 插件怎么装：引擎对照、版本选择与安装顺序

> JoiPlay 主程序只自带 HTML 类游戏的支持，其余引擎各要一个插件 APK。本篇讲哪个引擎装哪个插件、Ren'Py 插件怎么选版本、按什么顺序装。

## 一、为什么必须装插件

主程序里装的是界面、游戏管理和 HTML 类游戏支持；RPG Maker XP/VX/Ace、Ren'Py、Flash、Godot 这些引擎的运行能力放在单独的插件 APK 里，不装就跑不了对应引擎的游戏。**游戏加进来点开就退、或提示缺组件，先查插件**，这是使用 JoiPlay 排查频率最高的一件事。

注意区分另一种「打不开」：RPG Maker XP/VX/Ace 游戏启动时报 `Failed to load: Graphics/...` 之类的缺文件错误，插件装没装都救不了它 —— 那是缺 RTP 共享素材包，处理方式见 [缺少RTP怎么办.md](缺少RTP怎么办.md)。

## 二、插件与引擎对照表

下表来自官方下载区（版本与体积为 2026-02 官网页面标注，会随更新变化，以 [joiplay.net](https://joiplay.net/) 当前页面为准）：

| 插件 | 给什么用 | 版本 | 体积 |
| --- | --- | --- | --- |
| RPG Maker Plugin | RPG Maker XP / VX / VX Ace 的游戏 | 1.22.00 | 80.0 MB |
| Ren'Py 8.5 Plugin | Ren'Py 8+ 的游戏 | 1.01.00 | 53.4 MB |
| Ren'Py 7.7.1 Plugin | Ren'Py 7+ 的游戏 | 1.00.60 | 38.0 MB |
| Ruffle Plugin | Adobe Flash 游戏 | 1.02.00 | 26.0 MB |
| Godot 4.3 Plugin | Godot 4 的游戏（GDScript） | 1.00.60 | 73.5 MB |
| Godot 3.6 Plugin | Godot 3 的游戏 | 1.00.50 | 49.5 MB |

另外还有三个**可选**的 Ren'Py 专用插件（对应 Ren'Py 8.3.7 / 8.2.3 / 8.1.3），装上后对相应小版本的游戏兼容性更好；不装也能玩，遇到特定游戏异常时再补。

**不需要任何插件**的：RPG Maker MV / MZ、TyranoBuilder、Construct 2/3、其他 HTML5 游戏 —— 这些都是 HTML 类，主程序直接支持。

插件只装自己用得上的就行，全装也不报错，但每个插件几十 MB，没必要都塞进去。

## 三、Ren'Py 插件怎么选版本

Ren'Py 插件按引擎大版本分两支，**选错是「Ren'Py 游戏打不开」的头号原因**：

- 游戏**用 Ren'Py 8 引擎做的** → 装 Ren'Py 8.5 Plugin；
- 游戏**用 Ren'Py 7 引擎做的** → 装 Ren'Py 7.7.1 Plugin。

游戏的 Ren'Py 版本一般写在它发布页的说明、更新日志或启动画面里；分不清就先把 8.5 插件装上试，打不开再换 7.7.1 那支。两个插件可以共存。

## 四、安装顺序与升级

1. **先装 JoiPlay 主程序，再装插件**；插件彼此之间没有先后。
2. 插件安装方式与主程序一样：下载 APK → 文件管理器点开 → 安装（同样需要「安装未知应用」授权，见 [下载与安装教程.md](下载与安装教程.md)）。
3. 插件与主程序**各自独立更新**，版本号互不对应（比如主程序 1.21.000 配插件 1.22.00 是正常组合）。某个游戏打不开而同引擎的其他游戏正常时，先去官方下载区看这类游戏对应的插件有没有新版本。
4. 更新作者会把最新构建先发在 [Patreon](https://www.patreon.com/joiplay)，官网公开版可能滞后一步。

装了插件 JoiPlay 却提示找不到？常见于小米等机型：系统默认限制应用读取「已安装应用列表」，插件装了也「看不见」。到系统设置的 JoiPlay 权限页里，把「获取已安装应用信息」设为始终允许，重启 JoiPlay 即可，具体步骤见 [常见问题与解决.md](常见问题与解决.md)。

## 五、各引擎的兼容度参考

官方给了一组兼容度参考（百分比是官方口径，随版本推进变化）：

| 引擎 | 官方兼容度 | 备注 |
| --- | --- | --- |
| RPG Maker MV / MZ | 约 95% | 主程序直接支持 |
| TyranoBuilder | 约 95% | HTML 类 |
| HTML5 游戏 | 约 95% | 主程序直接支持 |
| RPG Maker XP / VX / VX Ace | 约 90% | 需 RPG Maker Plugin |
| Ren'Py | 约 90% | 需对应版本插件 |
| Construct 2 | 约 75% | HTML 类 |
| Construct 3 | 约 70% | HTML 类 |
| Adobe Flash | 约 60% | 需 Ruffle Plugin |
| Godot | 约 50% | 实验性，仅 GDScript 游戏，重游戏在低配机上跑不动 |

兼容度不到 100% 意味着个别游戏跑不起来或部分功能异常，这与插件无关、也与你的操作无关 —— 重度自定义脚本的 RPG Maker 游戏和复杂 Ren'Py 游戏最容易出状况。遇到打不开的游戏，先按 [常见问题与解决.md](常见问题与解决.md) 排一遍，仍不行就换同引擎的其他游戏验证是不是个例。
