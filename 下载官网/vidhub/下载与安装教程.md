两点提醒：

- 上面这份是**网盘资源里那个安装包**的实测信息；官方线上最新版可能已经更高，介意版本新旧的话先看官方发布渠道的当前版本号。
- 采集记录标注系统要求为安卓 5.2 以上，实际以安装时系统给出的提示为准。

## 二、从网盘资源获取安卓安装包

安卓端安装包从这里拿：[VidHub 安装文件资源（夸克网盘）](https://pan.quark.cn/s/183c45811c44)。步骤：

1. 在浏览器或夸克网盘客户端打开上面的链接；
2. 把资源**转存到自己的网盘**（分享内容转存后才是稳定可用的）；
3. 在夸克网盘客户端里找到转存后的 APK 文件，点下载；
4. 下载完成后在下载列表或本地「Download」目录里找到该 APK，点开即进入安装。

## 三、安卓手机安装步骤

1. 点开 APK 后，系统会提示「是否允许安装未知来源应用」——不同品牌入口略有差异：
   - 多数机型：安装弹窗里直接点「设置」→ 打开「允许来自此来源的应用」→ 返回继续安装；
   - 部分机型：进「设置 → 安全（或隐私）→ 更多安全设置 → 安装未知应用」，给浏览器或网盘客户端授权；
2. 回到安装页点「安装」，等待完成；
3. 安装完首次打开，应用一般会请求存储、网络等权限，按需允许——不给存储权限会导致后面无法添加本地目录。

## 四、安装包完整性校验（可选但建议）

转存下载过程偶有中断，装之前花一分钟校验 MD5，能排除「包不完整」这类安装失败：

```powershell
# Windows PowerShell
Get-FileHash "vidhub_v2.0.1.apk" -Algorithm MD5
```

```bat
:: 或 Windows 命令行
certutil -hashfile vidhub_v2.0.1.apk MD5
```

macOS / Linux 用：

```bash
md5sum vidhub_v2.0.1.apk        # Linux
md5 vidhub_v2.0.1.apk           # macOS
```

算出的值与第一节表格里的 MD5 完全一致即为完整包。

苹果端与安卓端登录同一账号后，文件源等配置可以互通（详见 [常见问题解答.md](常见问题解答.md) 的同步一节）。

## 六、安装失败时的排查顺序

1. **MD5 对不上** → 包在下载或转存中损坏，删掉重新下载；
2. **提示解析包失败** → 多为下载不完整或存储路径异常，同样重新下载；
3. **提示存储空间不足** → 181.67 MB 的安装包解压后占用更大，清出空间再装；
4. **系统版本过低** → 按第一节标注核对系统版本；
5. 装上了但打不开、闪退 → 见 [常见问题解答.md](常见问题解答.md)。
