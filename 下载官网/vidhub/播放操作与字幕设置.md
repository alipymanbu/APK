## 一、播放界面控件速查

按官方文档对播放界面的说明，常用的几个控件：

| 控件 | 位置 | 作用 |
| --- | --- | --- |
| 锁屏 | 界面左侧 | 锁定后除锁屏键外全部触控失效，防止口袋里误触；再点一次解锁 |
| 横竖屏切换 | 界面左侧 | 绿色为横屏，点成白色则转竖屏 |
| 选集 | 左下角 | 列出同文件夹内的全部视频；文件夹里只有一个视频时不显示 |
| 分辨率 | 底部「原画」按钮 | 展开可选分辨率；**WebDAV/Alist 来源的视频不显示此项** |
| 截图 | 右侧中间相机图标 | 播放和暂停状态都能截当前帧 |
| GIF 录制 | 右侧 GIF 图标 | 再点一次生成 GIF 存入相册；录制中点空白处关闭窗口 |
| 画面适应 | 右侧 | 把画面调整到适合屏幕比例 |

不同设备与版本的入口位置可能微调，以你手上的界面为准。

## 二、倍速播放

播放页可调整播放速度。移动端有用户反馈可以长按画面临时加速（类似短视频应用的习惯），具体入口与手势随版本变化，以实际界面为准；长按倍速结束恢复原速。

## 三、字幕设置

- **内置字幕**：视频文件里封好的字幕直接读取，播放时在字幕菜单里切换或关闭；
- **外挂字幕**：支持 SRT、SSA、ASS、SUB 等常见格式，把字幕文件与视频放在同一目录（文件名对应）或在播放时手动挂载；
- **在线字幕**：应用提供在线字幕检索，播放时可自动或手动匹配当前视频的字幕，对美剧、日韩剧这类需要翻译字幕的片源比较实用；检索命中率取决于片名规范程度，匹配不到时先按 [文件源与媒体库配置.md](文件源与媒体库配置.md) 的命名规范改文件名；
- **字幕调整**：字号、样式等可在字幕设置里调，具体可调项以版本界面为准。

## 四、画质与解码

- VidHub 支持高清、4K、HDR 等规格的视频播放，MKV、MP4、RMVB、AVI、WMV、MOV、WebM 等常见容器格式都在支持列表内；
- 多音轨视频（如 MKV 内封多语言音轨）可在播放时切换音轨；
- 从 WebDAV/Alist 播放时不显示分辨率切换选项，视频按源文件的原始码流播放。

## 五、杜比视界与杜比全景声能不能点亮

能不能点亮杜比，**取决于硬件**，应用只是调起方。按 2026 年 4 月的实测与官方说明：

| 平台 | 杜比视界 | 杜比全景声 |
| --- | --- | --- |
| 安卓手机 / 安卓电视 | 可点亮（需设备厂商已适配） | 可点亮（需设备厂商已适配） |
| iPhone / iPad | 可点亮 | 可点亮 |
| Apple TV | 可点亮 | 可点亮 |
| Mac | 可播放、画面正常，但无亮度变化 | 不支持 |
| Windows | 无 VidHub | 无 VidHub |

判断方法：播放杜比测试片时屏幕亮度有明显变化即为视界点亮成功，播放全景声影片时界面出现 Atmos 标识即为音频点亮成功。你的设备本身不支持杜比的话，换任何播放器都点不亮。

## 六、从其他应用调起播放

VidHub 提供了 URL Scheme 接口，其他应用可以把视频直接交给它播放：安卓端使用 `open-vidhub://x-callback-url/play`（苹果端另有旧版 `/open` 接口保留）。普通用户一般在用「外部播放器」功能的网盘、下载工具里会遇到这个入口——把外部播放器选成 VidHub 即可。参数细节面向开发者，日常使用只需要知道这个调用关系。

## 七、播放不顺畅时

1. 网络源卡顿先排查网盘限速与局域网带宽，再考虑换源（见 [常见问题解答.md](常见问题解答.md)）；
2. 高码率 4K 卡顿多与设备解码能力有关，可尝试切换硬解/软解（如有该选项）或换低码率版本；
3. 切换音轨后无声等问题，见 [常见问题解答.md](常见问题解答.md) 的播放一节。
