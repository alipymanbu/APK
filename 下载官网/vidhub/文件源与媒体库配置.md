# VidHub 文件源与媒体库配置

> VidHub 的影片全部来自「文件源」——云盘、SMB/WebDAV、本地目录或影视服务器。本篇讲各类文件源怎么添加、刮削与命名规范、媒体库怎么整理。

## 一、先搞懂两个概念：文件源与媒体库

你添加的每一个「文件源」是一个存放影片的仓库；VidHub 会扫描文件源里的视频文件，按文件名在线匹配海报、简介、演员表（这个过程叫刮削），整理成海报墙式的媒体库。两者关系：

- 删掉某个文件源，媒体库里与它相关的影片会一并移除；
- 「禁用」文件源只是把相关影片从媒体库隐藏，重新「启用」后恢复；
- 文件源支持重命名、单独重新扫描，多个文件源可以批量编辑删除。

一个关键限制：**自动导入按「文件夹」为单位**——你只能勾选某个文件夹作为文件源，不能只挑单个文件。想让某部影片进媒体库，就把它（连同同类的）放进一个文件夹再加进来。

## 二、添加云盘文件源

官方文档口径下支持的云盘包括阿里云盘、百度网盘、115、移动云盘、Dropbox、OneDrive、Google Drive 等（截至文档更新时的列表，以应用内「添加存储」页面实际显示为准）。以阿里云盘为例：

1. 在文件源页点「添加 / 修改文件源」→「添加存储」；
2. 选择对应云盘，点「添加」，进入授权页后点「允许」；
3. 授权时注意勾选云盘里存放影片的目录范围（阿里云盘有「备份盘」与「资源库」两个位置，影片放在哪边就勾哪边）；
4. 回到选择页，**勾选影片所在的文件夹**，给文件源起个名字，点「完成」；
5. VidHub 自动扫描该文件夹下的视频并刮削入库。

两点实际会碰到的坑：

- 网盘方对第三方应用的授权政策会调整，授权失败、播放被限清晰度或限速都可能是政策原因——阿里云盘的第三方权益包政策是其中影响最大的，详见 [网盘限速与授权问题.md](网盘限速与授权问题.md)；
- 扫码授权的云盘，换设备后需要在新设备上重新登录授权。

## 三、添加 SMB / WebDAV 网络共享

NAS、路由器共享目录、Alist 这类存储走网络共享方式添加：

| 填写项 | 说明 |
| --- | --- |
| 服务器地址 | 局域网 IP 或域名，如 `192.168.1.10` |
| 协议 | SMB 或 WebDAV（Alist 挂载后用 WebDAV 方式接入） |
| 端口 | SMB 常见 445，WebDAV 以你的服务配置为准 |
| 用户名 / 密码 | 共享目录的账号，匿名共享可留空（以界面为准） |
| 路径 | 选填，直接指到影片所在目录可少扫一层 |

注意事项：

- 路径指得越准，首次扫描越快；只填根目录会连配置文件一起扫；
- 从 WebDAV/Alist 导入的影片，播放页**不显示分辨率切换选项**，这是官方文档明确写的表现，不是故障；
- 连接失败时按顺序查三样：端口对不对、账号密码对不对、路径写没写对——「挂载成功但列表是空的」多半是路径指到了空目录；
- 电视端与手机端可以各自添加同一个共享地址，互不依赖。

## 四、直连影视服务器（Emby / Jellyfin / Plex 及国产 NAS）

如果你的片库已经在某个影视服务器里整理过，VidHub 可以直接连它的媒体库，不用重新刮削：

1. 在应用内选择「添加影视服务器」；
2. 从 Emby、Jellyfin、Plex、飞牛、极空间、绿联、KinoFlow 等选项里选对应类型（列表以应用内实际显示为准）；
3. 填服务器地址、端口、用户名、密码，确认添加；
4. 连接成功后，服务器上已整理好的媒体库直接以海报墙呈现。

以绿联 NAS 为例（2026 年 8 月底开放的适配，截至 2026-09 的口径）：需 NAS 固件 1.18.0.0075 以上，在「影视中心 → 设置 → 媒体服务器」里打开媒体库服务、单独建一组媒体库账号，然后把页面显示的服务器地址与端口（默认 HTTPS 9443）填进 VidHub。其他品牌的适配进度不同，以各自说明为准。

## 五、添加本地目录

- 「添加本地目录」把手机存储里的某个文件夹作为文件源，扫描后入库；
- 存在相册里的视频要先通过系统「共享 → 存储到文件」转存到文件管理器里，再添加；
- 本地文件源适合离线场景；网盘与网络共享源在断网时不可用。

## 六、扫描与整理的实操建议

- **文件命名规范**：刮削按文件名匹配，`电影名.年份.mkv` 这类规范命名的匹配成功率远高于「新建文件夹(3)/最终版2.mp4」；电影、剧集、特别篇的完整命名规则与 tmdbid 写法见 [文件命名与刮削修正.md](文件命名与刮削修正.md)；
- **重新扫描**：文件源内容有增删改后才需要；片库很大时全量重扫耗时较长，只变动了一个目录的话，单独扫描那个文件源；
- **编辑媒体库**：媒体库顶部的类目（电影、电视剧等）可以隐藏或调整顺序；
- **匹配错了**：用影片详情里的「编辑信息」手工修正，改完不需要重扫；
- 添加文件源时如果卡在授权或扫描，见 [常见问题解答.md](常见问题解答.md)。
