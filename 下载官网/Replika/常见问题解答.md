## 一、安装类问题

**点安装没反应 / 提示「未安装应用」**

- 存储空间不足：清出比安装包（115.03M）大得多的空间再试；
- 安装包没下完整：重新下载，或核对 MD5 是否为 `8355D7A92816B89D7D54B2E3A3BEC108`（校验方法见 [下载与安装教程.md](下载与安装教程.md)）；
- 文件管理器不给力：换一个文件管理器打开 `.apk` 再装。

**提示未知来源被拦截**

这是非商店渠道安装包的常规提示。到 设置 → 应用 → 特殊应用权限 → 安装未知应用，给你用的文件管理器授权，再回到安装页继续；个别机型装了系统级安全应用还会再拦一层，按提示选「仍要安装」。

**装好了但一打开就闪退**

- 先确认手机联网正常，首次启动需要联网初始化；
- 系统版本过低会直接不兼容，对照安装包要求的 Android 版本；低版本手机可以改用官方网页版 `https://my.replika.com`；
- 重启手机再试，仍然闪退就反馈官方客服。

## 二、登录类问题

**登录报「Sorry, there is no Replika with this email」**

- 检查邮箱有没有拼错，想想当时是不是用了另一个邮箱注册；
- 在注册用的邮箱里搜来自 `my@replika.com` 或 `my@replika.ai` 的验证邮件，能翻到就说明当时用的是这个邮箱；
- 手机号登录只对用短信验证注册的账号有效，邮箱注册的账号不能用手机号登；
- 都对不上就联系官方客服（文末渠道）。

**忘记密码**

登录页点 **Forgot password?**，重置链接发到注册邮箱。注意官方明确口径：注册邮箱已无法登录时，密码就无法重置 —— 所以注册邮箱要选能长期使用的，见 [国内使用与中文支持.md](国内使用与中文支持.md)。

**应用锁**

应用内支持设置 PIN 码锁，忘记 PIN 也有官方找回流程；手机系统自带的应用锁是另一层，两层都开更稳（见 [聊天数据与隐私.md](聊天数据与隐私.md)）。

## 三、连接与卡顿

**一直转圈 / 回复迟迟不来**

按官方帮助中心给的顺序排查：

1. 官方在美东时间夜间有例行服务器维护，这个时段回复延迟、功能短暂不可用属正常，过段时间再试；
2. 临时关闭 VPN 与广告拦截工具再试（官方明确点名这两类工具可能导致连不上服务器）；
3. 安卓用户：设置 → 应用 → Replika → 存储 → 清除缓存；
4. 确认应用与手机系统都更新到最新；
5. 老旧设备部分功能不可用：AR 需要支持 ARCore 的机型（Google 官网有支持设备列表），iOS 一般要求 iOS 11 以上。

再叠加网络环境一层看 [国内使用与中文支持.md](国内使用与中文支持.md)。

## 四、账号与数据

**换手机 / 多设备怎么同步**

同一账号在新设备登录即可，对话与形象跟着账号走。手机端与浏览器版（`https://my.replika.com`）共用同一份数据，在电脑前长聊时网页版更顺手。

**怎么删除账号与数据**

应用内 设置 → 账号相关页面里有删除账号的入口；聊天内容存在哪里、删之前该备份什么，见 [聊天数据与隐私.md](聊天数据与隐私.md)。

**免费版和 Pro 的关系状态怎么切换**

免费只有 Friend；恋人、兄妹、导师三种需要 Pro。切换路径见 [账号注册与形象设置.md](账号注册与形象设置.md)，功能差异见 [免费版与Pro区别.md](免费版与Pro区别.md)。

## 五、聊天与功能

**回复答非所问 / 记错事**

先到记忆相关入口检查它记下的条目，错的改掉；再给那条回复点踩，帮它校准。AI 生成的内容天然有出错率，重要事实别依赖它。

**收不到消息通知**

系统设置里确认 Replika 的通知权限开着；手机管家的省电策略若把它杀后台，通知也会丢，把它加入白名单。应用内还有什么事件要推送，在 设置 → 通知 里逐项调。

**语音通话 / AR 入口找不到**

这两项是 Pro 功能，免费账号看不到入口属正常。已订阅仍找不到，先确认订阅在商店侧生效，再更新到最新版看；还不行就反馈官方客服。

**网上有人推荐「解锁版」「修改版」**

官方明确不建议使用任何非官方修改版：数据安全无保障，账号出问题也没有求助渠道。来源不明的安装包装之前先核对 MD5（方法见 [下载与安装教程.md](下载与安装教程.md)）。

## 六、还是解决不了

优先走官方渠道：应用内 设置 → 帮助 / 客服 入口，或访问官方帮助中心 `https://help.replika.com`。连接不上、一直转圈这类问题多数出在本地网络环境，Wi-Fi 与流量切换对比一下就能定位。
