# Qboost 锁频不生效的排查方法

> 设了模式却没效果、或者锁一会儿又弹回去了？本篇按从常见到少见的顺序列出原因和对应的处理办法。

## 一、先分清两种「不生效」

处理方式完全不同，先对号入座：

- **完全没反应**：设置了模式，用监控工具看频率纹丝不动——多半是机型不支持或服务根本没跑起来；
- **锁一会儿就失效**：刚设置时有效，过几分钟或熄屏一次就回去了——多半是服务被杀或温控介入。

怎么用监控工具确认频率状态，见 [设置步骤与生效验证.md](设置步骤与生效验证.md) 第三节。

## 二、完全没反应：按顺序查这四条

1. **处理器不在支持名单**。只支持高通骁龙的 425、430、435、630、650、652、653、660、808、810、820、821、835 这批型号，**625 和 626 已确认不可用**（依赖的高通官方 SDK 不支持它们）；联发科、麒麟等非骁龙芯片一律无效。这是第一条要排除的，不是调参数能解决的。
2. **服务没启动**。检查通知栏有没有 Qboost 的常驻通知；没有就是服务没跑起来，回应用里重新点「开始」。
3. **系统调度没交出去**。点一次「重置」（或选「系统默认」再点开始），然后重新设置目标模式——有用户反馈它偶尔会锁核，重置一次就正常。
4. **ROM 不配合**。不同系统的权限管理强度不同，有用户反馈同机换系统后效果消失：在某个第三方 MIUI 上正常，刷了 Flyme 就不生效了。这种属于系统层面的限制，应用侧无解，只能换系统或接受现状。

## 三、锁一会儿就失效：按顺序查这三条

1. **服务被系统清理了**。这是最常见的原因。去设置里给它自启动权限、关闭电池优化、在最近任务里加锁；国产系统的省电策略普遍激进，这几步缺一不可，各厂商的具体入口见 [后台保活设置方法.md](后台保活设置方法.md)。做完之后熄屏再亮屏试试还掉不掉。
2. **温控介入了**。频率被锁在高位、机身持续发热后，系统温控仍可能强制压频，这不是 Qboost 失效，是硬件保护。降一档频率、或给设备散散热再试。
3. **后台被手动清掉了**。有些用户习惯性一键清理后台，会把服务一起带走。把它加进白名单，或者改变一键清理的习惯。

## 四、都试过还不行

- 重启手机后重新设置一遍（重启也会清掉之前可能存在的错误状态）；
- 还不行就基本可以判定该机型或该系统版本不受支持，普通卸载即可，无需 Root、不残留系统级改动；
- 装不上 APK 的情形属于另一类问题，见 [下载与安装教程.md](下载与安装教程.md) 第四节。
