# Qboost 后台保活设置方法

> Qboost 锁频失效的头号原因是服务被系统清掉。本篇按厂商给出把 Qboost 加入保活白名单的具体入口和操作。

## 一、先认清「被杀」的三个症状

出现任何一个，都说明系统在清理 Qboost 的服务，按下面的办法处理：

- 设置生效几分钟后，频率自己回弹了；
- 熄屏再亮屏之后设置失效；
- 通知栏的常驻通知不见了。

## 二、所有系统通用的四步

不管什么牌子，先把这四步做满（都在系统设置里）：

1. **电池优化白名单**：设置搜索「电池优化」，切到「所有应用」，找到 Qboost，设为「不允许优化」——这是原生 Android 的通用入口，多数国产系统也保留了这个页面；
2. **自启动**：搜索「自启动」，把 Qboost 的开关打开；
3. **多任务加锁**：在最近任务界面下拉或长按 Qboost 的卡片，出现锁图标即加锁，防止一键清理带走它；
4. **关省电模式**：省电模式开启时系统清理后台最狠，玩游戏的期间把它关掉。

## 三、各厂商的具体入口

| 系统 | 入口与操作 |
| --- | --- |
| 华为 / 荣耀（HarmonyOS / MagicOS） | 设置搜「应用启动管理」→ 关掉 Qboost 的自动管理 → 弹窗里选「允许后台活动」；再搜「电池优化」设为不允许；多任务界面下拉卡片加锁；关掉低电量模式 |
| 小米 / 红米（MIUI / 澎湃 OS） | 设置 > 应用设置 > 授权管理 > 自启动管理，允许 Qboost；长按桌面图标进应用信息，把「省电策略」（部分版本叫「电量消耗」）改为「无限制」；设置 > 电池与性能 > 右上角设置 > 「锁屏后清理内存」选「从不」；多任务里按住卡片点小锁 |
| 一加 / realme 等（ColorOS / OxygenOS 系） | 设置 > 电池 > 电池优化，右上角高级优化里关闭智能电池管理和睡眠待机优化，并把 Qboost 的电池优化设为「不优化」；多任务长按卡片选锁定 |
| 其他系统 | 认准三个关键词在设置里逐个搜：「自启动」「电池优化」「省电策略」，找到后全部放行 Qboost |

入口名称随系统版本会有出入，搜不到就换相近的关键词试。

## 四、都设了仍可能被杀，别意外

即便全部设好，系统在内存吃紧或运算量大时仍可能回收后台——厂商客服的官方口径也是如此，个别系统还会把省电策略悄悄改回默认值。所以锁频失效时先看通知栏的常驻通知还在不在：不在就重开 Qboost 再点一次「开始」。

保活只解决「锁一会儿就失效」这一类问题；设置后完全没反应属于另一类，去 [锁频不生效的排查方法.md](锁频不生效的排查方法.md) 按机型支持、服务启动、ROM 兼容的顺序逐项排查。
