## 一、微课（学练课）是什么

微课在应用里也叫「学练课」，是官方为手机端设计的一种课程形式：每节用图文、语音或视频讲一小段，紧接着附上训练题让你做，做完才能往下走。对你来说，它的实际意义是——每学一小节都能立刻检验自己有没有真的懂，而不是看完了才发现没记住。

入口：应用首页的「学练课 / 微课」模块。电脑上也能学，网页端地址是 [https://www.w3cschool.cn/minicourse/](https://www.w3cschool.cn/minicourse/)，同一账号两边的进度通用。

## 二、有哪些微课，怎么挑

微课覆盖多门语言，入门阶段常被选的是这几门（官方课程列表在架课程）：

| 课程 | 官方的一句话介绍 |
| --- | --- |
| HTML 入门课程（含 HTML5） | Web 前端的第一步 |
| CSS 入门课程 | 页面样式的基础 |
| JavaScript 入门课程 | Web 前端必学语言之一 |
| Python3 入门课程 | 爬虫、脚本、数据方向常用 |
| SQL 入门课程 | 程序员必备的基础知识 |

挑的时候看两点：

- **付费标示**：列表里每门课都标了价格或「VIP 免费」「免费」，免费课直接学；标了价格的课，要么单独购买，要么开会员后免费学，两种身份的权益差别见[VIP会员权益对照.md](VIP会员权益对照.md)，不必为了单门课急着开会员；
- **难度标示**：课程介绍里写明了适合谁，零基础就只看标入门的，别从进阶课开始硬啃。

## 三、编程实战怎么玩

编程实战是闯关制的训练营：每一关给你一个目标，直接在手机上写代码，通过校验才算过关。官方口径的覆盖范围是 HTML、CSS、JavaScript、jQuery、Bootstrap 等方向，其中 VIP 权益部分标称 500+ 关，免费账号能玩的是其中的部分关卡。

实际用下来的顺序建议：

1. 先把对应语言的微课基础部分学完，再进实战，否则关卡做起来会很挫败；
2. 卡关时回到该语言的教程手册翻对应章节，再回来重做；
3. 想随手跑一段自己的代码而不是做关卡时，用编译工具（见[使用入门.md](使用入门.md)第三节的模块表）。

## 四、学习证书

完成微课或实战课程后可以拿到学习证书，证书上有你设置的真实姓名。官方口径明确：**目前只有微课和实战这两类课程提供证书**，其他内容学完没有证书。两点提醒：

- 免费账号能拿的证书有限（官方会员权益对比里，普通用户一栏写的是「个别免费实战证书」，会员解锁全部微课与实战证书）；
- 证书展示的名字需要在账号资料里先设置真实姓名，领证书前先去把资料补上。

证书属于学习记录性质的凭证，具体哪些课程发证、以应用内当时标示为准。

## 五、学练结合的节奏

官方课程体系按「基础入门 → 基础实战 → 进阶提升」分层，跟着这个顺序走最省力：微课学完一个语言的基础，就去做对应的基础实战，做完再决定是否往进阶走。中途断了不用重头再来，已完成的关卡和课程进度都在「我的学习」里。
