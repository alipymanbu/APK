## 一、这是个什么应用

w3cschool（编程狮）是 [w3cschool.cn](https://www.w3cschool.cn/) 推出的编程学习应用，手机上主要做两件事：**查教程手册**（HTML、CSS、JavaScript、Python、Java、PHP、SQL 等语言的在线教程与参考手册，官方标称为 1000+ 本）和**学课程**（微课、编程实战、题库）。

它适合的场景：通勤或碎片时间刷一节微课、写代码卡壳时在手机上翻一下语法手册、零基础想先试试自己能不能学进去。需要长时间系统学习或大屏阅读时，同一账号还有网页端和 PC 客户端可用，见[离线缓存与多端学习.md](离线缓存与多端学习.md)。

## 二、第一次打开：注册与登录

打开应用后建议先注册登录，因为收藏教程、保存学习进度、离线下载这些功能都挂在账号上：

1. 用手机号加验证码注册或登录；
2. 如果不想记密码，登录后可以在账号设置里绑定第三方登录方式，之后用绑定的方式进；
3. 同一账号可以在多台设备登录，但应用对登录设备数量有上限，换新手机前先把旧设备退出，避免提示设备数超限。

收不到验证码、账号异常之类的问题，处理办法集中在[常见问题解答.md](常见问题解答.md)。

## 三、首页的几大模块

打开应用后，你会用到的主要是下面几块。先知道每块是干什么的，用的时候就不会绕路：

| 模块 | 是什么 | 什么时候用 |
| --- | --- | --- |
| 教程手册 | 按语言分类的图文教程与参考手册，可搜索、可收藏、可离线 | 查某个语法、系统过一遍某门语言 |
| 学练课（微课） | 游戏式的小节课程，图文、语音、视频搭配练习题 | 零基础入门，边学边练 |
| 编程实战 | 闯关式训练营，直接在手机上写代码 | 学完基础后动手练 |
| 编译工具 | 在手机上直接写代码并运行，官方标称支持 20+ 编程语言 | 手边没有电脑，想跑一小段代码验证 |
| 题库 | 基础题与面试题（官方标称近 1000 份） | 备面试、检验学习成果 |

微课与实战的详细玩法单独写在[微课与实战闯关.md](微课与实战闯关.md)；编译工具、网页端在线实验室、独立的工具箱 App 三个写代码入口的差别，见[编译工具与在线编程.md](编译工具与在线编程.md)。

## 四、初学者从哪开始

官方帮助中心给的建议可以概括成三步：

1. **先定方向再选语言**：想做什么决定先学什么——做网页从 HTML、CSS、JavaScript 开始，做数据处理或自动化从 Python 开始，别一上来贪多；
2. **用微课入门**：新手直接进首页的「学练课 / 微课」模块，它每节都配练习题，比只看图文教程更容易知道自己有没有学会；
3. **跟着课程编排走**：课程按「基础入门 → 基础实战 → 进阶提升」组织，入门阶段做完基础课程，就去做对应的基础实战练手，再回来看进阶内容。

## 五、查手册与收藏教程

- 顶部搜索框可以直接搜教程与词条，比如搜「flex」能定位到 CSS 相关内容；
- 打开任意教程页，点收藏，之后在「我的学习」里能找到，不用每次重新搜；
- 常用的那几本教程，建议顺手下载离线（教程页点「下载离线版」），具体步骤与数量限制见[离线缓存与多端学习.md](离线缓存与多端学习.md)。
