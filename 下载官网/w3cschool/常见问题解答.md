## 一、闪退、卡顿、画面异常

**闪退、使用不流畅？** 官方帮助中心对闪退的处理是让你带着信息反馈，因为具体原因要看场景。反馈前先做两件事：清理 App 缓存、关机重启后再试一次。仍然复现的话，收集这几项再反馈，官方给的范例就长这样：

1. 发生闪退的场景与操作步骤（如「打开教程页，点保存按钮时必现」）；
2. 频率与最近一次发生的时间；
3. 清缓存或重启后问题是否仍在；
4. 手机内存是否充足、其他 App 是否正常。

**图片不显示、视频播不了？** 官方给的排查顺序：先清缓存并彻底关闭 App 重开 → 切换网络（Wi-Fi 与流量互换）再看是否恢复 → 仍然异常就截图反馈，说明是否每次都出问题。

安装与升级类的问题（装完提示升级、商店版与这份安装包的关系）集中在[下载与安装教程.md](下载与安装教程.md)。

## 二、账号与登录类

**收不到验证码？** 官方口径里常见就两种情况：

1. 手机号被短信服务商过滤——如果你以前把这类短信标记过垃圾短信，服务商会把你过滤掉。解决办法是联系在线客服或在帮助反馈里留下手机号，让官方处理；
2. 手机里的短信拦截规则太严，拦掉了某些号码。暂时关闭拦截再试。

前提先确认：手机信号正常、没有欠费。

**提示登录设备数超限？** 这是官方的账号保护机制。确实是你的多台设备在登录 → 在旧设备上退出登录即可；你并没有多台设备登录却收到提示 → 官方建议按密码可能泄露处理，尽快联系客服。设备已被限制时走客服渠道解锁。

**账号为什么会被冻结？** 官方列的触发原因主要有这几类：发布违法违规或侵权内容；辱骂、骚扰其他用户；发广告与垃圾信息；同一 IP 频繁注册多个账号；违规共享使用账号（借给别人用也算）。反过来讲，正常自用、不共享账号，基本碰不到冻结。被误冻时联系客服申诉。

**想换绑手机号或注销账号？** 官方帮助中心「账号问题」分类下有换绑与注销的专门条目，按里面的入口操作。

## 三、付费与权益类

**VIP 与终身 VIP 有什么区别？** 官方口径一条就能说清：标「终身 VIP 免费」的课程只有终身 VIP 能学，普通 VIP 不包含；其余权益（题库、编译次数、离线额度、证书）两边一致。对照表见[VIP会员权益对照.md](VIP会员权益对照.md)。

**支付成功了但权益没生效？** 先退出账号重新登录刷新；还不行就带支付凭证联系客服。

**能退款吗？** 官方帮助中心对 VIP 会员与单门课程分别列有退款说明条目，政策以官方页面当时的内容为准，购买前先看一眼。

**会员权益数字对不上？** 不同官方页面的标示偶有出入，以应用内与会员中心当时显示为准，并确认登录的是购买时用的那个账号。

## 四、找谁解决

官方渠道与联系方式（微信号以官方帮助中心当时公示的为准）：

| 问题类型 | 渠道 |
| --- | --- |
| 闪退、卡顿、功能异常 | 应用内「意见反馈」按钮，或微信人工客服「小狮妹」（官方帮助中心公示的微信号） |
| 设备被限制解锁 | 官方客服微信（帮助中心「APP 登录设备上限」条目公示） |
| 人工客服在线时间 | 工作日周一至周五 9:30–18:00 |
| 内容举报、违规反馈 | 投诉 / 举报入口 |
| 学习交流 | 官方交流群（帮助中心有加群方式） |

反馈时按第一节的清单把场景、频率、截图给全，一次说清比来回追问快得多。

## 五、学习类小问题

**有老师答疑吗？** 官方提供答疑渠道（帮助中心「其他问题」分类有专门条目），另外交流群里也能互助提问。

**课程资料（笔记、源代码）在哪里下载？** 部分课程附带，官方口径是只在电脑端 w3cschool.cn 对应课程介绍页的「资料下载」处下载，手机 App 里拿不到，细节见[离线缓存与多端学习.md](离线缓存与多端学习.md)。

**零基础完全不知道学什么？** 先看[使用入门.md](使用入门.md)第四节的三步法，定方向比挑课更重要。
