## 一、安装与升级类

**装完还一直提示升级？** 说明官方发布了更新的版本，忽略或去应用商店更新都可以，两个选择的利弊见[下载与安装教程.md](下载与安装教程.md)第四节。

**闪退、卡顿、使用不流畅？** 官方帮助中心把这几项单列为使用问题，说明确实会发生。按通用思路排查：

1. 彻底关掉应用重开（从后台任务里划掉，不是只退到桌面）；
2. 检查手机剩余存储空间，空间紧张时清一清；
3. 图片不显示、视频播放不了时，先切换一下网络（Wi-Fi 与流量互换）再试；
4. 还不行就重启手机；持续闪退记下触发场景（打开哪个页面闪退），反馈给客服。

## 二、账号与登录类

**收不到验证码？** 先看短信拦截与骚扰拦截设置里有没有把它拦掉，等一两分钟再点重发；换网络环境或换时间段重试；多次失败后改用绑定的第三方登录方式进，进去后再处理手机号绑定问题。

**提示登录设备数超限？** 应用的登录设备数量有上限，把不用的旧设备退出登录即可。找不到旧设备时，走官方帮助中心的对应条目处理。

**账号被冻结？** 官方帮助中心有专门条目说明冻结原因（多与违反社区规则有关）。按提示申请解封或直接联系客服，别急着重新注册——重新注册解决不了原账号的问题。

**想换绑手机号 / 注销账号？** 官方帮助中心的「账号问题」分类下有换绑与注销的专门说明，按里面的入口操作。

## 三、付费与权益类

**支付成功了但会员或课程没生效？** 先退出账号重新登录刷新权益；还不行就联系客服，把支付凭证截图留好。

**VIP 和终身 VIP 有什么区别？** 官方会员页的口径：普通 VIP 按时长购买、到期失效；终身 VIP 在此基础上解锁后续更新的新课。选哪个看你的学习周期，短周期学一两门课没必要上终身。

**能退款吗？** 官方帮助中心对 VIP 会员与单门课程分别列有退款说明条目，政策以官方页面当时的内容为准，购买前先看一眼那两篇。

**离线额度、实战关卡数这些会员权益对不上？** 权益数字以应用内当时显示为准（不同入口的标示偶有出入），确认自己登录的是购买时用的那个账号。

## 四、找谁解决

官方提供了几条渠道，都在官方帮助中心（[https://m.w3cschool.cn/w3cschool_help](https://m.w3cschool.cn/w3cschool_help)）能找到入口：

| 问题类型 | 渠道 |
| --- | --- |
| 功能异常、闪退、权益问题 | 人工客服 |
| 内容举报、违规反馈 | 投诉 / 举报入口 |
| 学习交流 | 官方交流群（帮助中心有加群方式） |
| 购买与发票 | 帮助中心「购买问题」分类 |

反馈时说清三件事：用的什么手机与系统版本、哪个页面出的问题、问题的截图，处理会快很多。

## 五、学习类小问题

**有老师答疑吗？** 官方提供答疑渠道（帮助中心「其他问题」分类有专门条目），另外交流群里也能互助提问。

**课程资料在哪里下载？** 官方帮助中心有专门条目说明课程资料的下载位置，跟着指引找即可；教程手册的离线下载则是另一个功能，见[离线缓存与多端学习.md](离线缓存与多端学习.md)。

**零基础完全不知道学什么？** 先看[使用入门.md](使用入门.md)第四节的三步法，定方向比挑课更重要。
