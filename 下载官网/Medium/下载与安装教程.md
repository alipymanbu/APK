## 一、先核对安装包信息

网上能搜到的是官方最新版，而手头这份安装包是固定的一版。装之前先对一遍下面的信息，确认它就是你要的那份：

| 项目 | 信息 |
| --- | --- |
| 应用名称 | Medium |
| 版本号 | 4.5.1214492 |
| 包名 | com.medium.reader |
| 安装包大小 | 19.37 MB |
| MD5 | 75E6A21904FF8492DEF196C15B4B738A |
| 信息获取日期 | 2026-09-24 |

两点提醒：

- 包名 `com.medium.reader` 是官方安卓客户端的标识，安装时系统弹出的应用信息里也会显示它，可以用它确认装的不是同名仿冒应用。
- 版本号以后会不会更新、更新到多少，以官方渠道当时显示为准。

## 二、获取安装文件

安装文件放在夸克网盘里，转存到自己网盘后即可下载到手机：

[Medium 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2caa1a573862)

具体流程：打开上面的链接 → 保存到自己的夸克网盘 → 在网盘客户端里把这个 APK 文件下载到手机存储。如果你还没有用过夸克网盘，按它的注册与登录提示操作即可，转存功能是免费的。

## 三、安装步骤

1. 在手机上找到刚下载的 APK 文件（一般在「下载」或网盘客户端的下载目录里），点它。
2. 系统第一次安装来源不明的应用时，会提示「不允许安装未知应用」——点进设置，允许你用来打开 APK 的那个应用（浏览器或网盘客户端）「安装未知应用」。
3. 回到安装界面，点「安装」，等进度条走完。
4. 点「打开」直接进入应用，或回桌面找到 Medium 图标再进。

如果你的系统是较新的安卓版本，路径可能是「设置 → 应用 → 特殊应用权限 → 安装未知应用」，按实际菜单名找就行。

## 四、装好之后先做什么

- 首次打开需要登录或注册账号，邮箱登录不需要密码，走邮件验证链接，具体步骤见 [注册与登录方法.md](注册与登录方法.md)。
- 登录后不充值也能读，只是每月能看的会员专属文章数量有限，免费与会员的区别见 [会员与免费额度.md](会员与免费额度.md)。
- 装完打不开、安装中断、提示解析失败这类情况，先去 [常见问题排查.md](常见问题排查.md) 对一遍常见原因。
