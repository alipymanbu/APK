> 本篇讲怎么管住 Medium 发到你邮箱的各类邮件：摘要（Digest）频率在哪改、哪些邮件能单独关掉、想换收件邮箱去哪里改。

## 一、设置入口

手机端路径：底部栏点头像 → 右上角 **Settings** → **Account** → **Notifications**，这一页是所有邮件通知的开关列表，按需勾选即可。另一项不在这一页：摘要邮件的发送频率在 **Account** 标签页里，找 **Your Medium Digest frequency** 直接选。

## 二、邮件分几类，各是什么

设置页里可单独开关的邮件类型不少，常见的有这些（以你设置页实际显示为准）：

| 邮件类型 | 内容 |
| --- | --- |
| Medium Digest | 按你的兴趣挑出的精选文章汇总，频率可在 Account 标签页改 |
| Recommended reading | 根据你的阅读历史推荐的文章、专栏与合集 |
| 关注作者的新文章 | 你订阅的作者发布了新文章 |
| 列表更新 | 你保存的列表里新增了文章 |
| 出版物摘要 | 你关注的出版物的内容汇总 |
| 社交通知 | 有人关注你、或划了与你相同段落 |
| 与你文章相关的通知 | 别人对你的文章有反应、回复、收藏，以及文章数据 |
| 会员相关信息 | 会员专属推荐文章与会员功能说明 |
| 产品更新 | 新功能说明、使用技巧与用户调研邀请 |

提醒：最后两类（产品更新、会员信息）和阅读行为无关，嫌邮件多的人可以优先关这两类，再处理阅读推荐类。

## 三、觉得邮件太多怎么收

按「先降频、再断源」的顺序处理：

1. 把 **Your Medium Digest frequency** 调低频率，一天一封变几天一封；
2. 在 Notifications 页关掉你不看的类型（对照上表逐项判断）；
3. 关注的作者太多导致邮件轰炸的，去取关一部分——取关同时也会让首页更清爽，见 [阅读推荐与关注管理.md](阅读推荐与关注管理.md)。

## 四、换收件邮箱

Account → **Email address** → 输入新邮箱 → Save。换完之后，登录验证邮件也会发到新邮箱——Medium 登录靠邮箱验证码/链接（没有密码），所以这个邮箱要保持在能用状态，登录规则见 [注册与登录方法.md](注册与登录方法.md)。

邮件收不到、验证邮件进垃圾箱这类问题，见 [常见问题排查.md](常见问题排查.md) 第一节。
