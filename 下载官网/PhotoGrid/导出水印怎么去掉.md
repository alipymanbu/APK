# PhotoGrid 导出的图有水印怎么去掉

> 免费版导出会带 PhotoGrid 水印。本篇讲水印的来源、官方给的两条去除路径（升级会员 / 官网免费网页工具），以及不想花钱时的替代办法。

## 一、先分清水印是哪来的

只有免费版导出的成图 / 成片会带应用水印，会员导出默认不带（版本边界见 [免费版和会员有什么区别.md](免费版和会员有什么区别.md)）。

- **PhotoGrid 自己加的水印**：走下面第二、三节的官方路径。
- **照片里本来就有的**（自己翻拍老照片上的时间戳、画面里的杂物）：这不是「水印去除」问题，用消除笔当普通杂物处理即可，方法见 [抠图与消除笔怎么用.md](抠图与消除笔怎么用.md)。

## 二、路径一：升级会员

会员导出无水印，这是官方对应关系里最直接的一条；常导出图的话，广告也一并免了。会员权益与订阅管理见 [免费版和会员有什么区别.md](免费版和会员有什么区别.md)。

## 三、路径二：官网的免费网页工具

官方在 [photogrid.app](https://www.photogrid.app/zh-cn/) 上提供网页版「AI 水印消除」工具，手机浏览器就能打开：

1. 进官网的工具列表，找 **Watermark Remover（水印消除）**。
2. 上传图片，支持 JPG / JPEG / PNG / WebP，可以批量多张。
3. 三种选法：**Auto** 自动识别并消除；**画笔** 涂出水印区域；**矩形** 框住水印。
4. 处理完下载，输出高清图。

两点实际反馈：

- 官方口径是消除后不损画质；有第三方评测实测后反馈：小水印效果好，大面积铺满的水印消除后可能有涂抹感。有残留就换画笔手动补一遍。
- 具体免费额度与功能范围以官网当时显示为准。

## 四、不想花钱的替代办法

- **构图避开**：应用水印一般固定在角落，导出前先定好比例、主体别顶到边缘，后续裁掉角即可；部分模板水印位置不固定，这招不通用。
- **用消除笔涂**：对自己导出的图，编辑里的消除笔可以直接涂掉水印；免费版能操作，小图上会有涂抹痕迹，放大看比较明显。
