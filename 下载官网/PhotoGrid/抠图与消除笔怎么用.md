## 一、智能抠图

1. 打开一张照片进入编辑，找到 **Cutout（抠图）** 入口。
2. 点一下主体（人物、宠物、物品），应用自动识别边缘，把主体抠出来。
3. 换背景：可选纯色、渐变、图案，也能从相册另选一张照片当背景。
4. 边缘不干净时，用擦除 / 修复笔沿着轮廓手动修一圈。

典型用途：做头像、商品图换底色、把人从合影里单独拎出来再合成。

## 二、AI 消除笔（去除路人 / 杂物）

1. 编辑照片时选 **Remove（消除笔）**。
2. 把要去掉的东西涂出来：路人、电线、地面上的杂物都可以。
3. 松手后应用用周围画面自动补上；不满意就撤销，换个范围再涂。

用好的两个限度：

- 背景简单的照片效果好；背景纹理复杂（人群、树叶、砖墙）时，补出来的区域可能有涂抹感，分小块多试几次。
- 一次消除的面积别贪大，分多次小面积消除比一整块涂掉效果好。

## 三、常用编辑工具速查

| 工具 | 位置 | 干什么用 |
| --- | --- | --- |
| 滤镜 | 编辑底部栏 | 整体调色，另有一批动态滤镜 |
| 调节 | 编辑底部栏 | 亮度 / 对比度 / 饱和度 / 色温手动微调 |
| 文字 | 编辑底部栏 | 加字、换字体，支持弧形文字 |
| 贴纸 | 编辑底部栏 | 数量较多，可按关键词搜索 |
| 马赛克 / 模糊 | 编辑底部栏 | 挡住车牌、人脸等敏感信息 |
| 裁剪 / 比例 | 编辑底部栏 | 按 1:1、4:5 等比例裁切 |

## 四、处理完的照片去哪了

保存后进相册里 PhotoGrid 的目录；导出的图带不带水印取决于你用的是免费版还是会员版（边界见 [免费版和会员有什么区别.md](免费版和会员有什么区别.md)）。
