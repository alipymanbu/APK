## 一、免费版能用到什么

- 拼图（网格、模板）与照片编辑的基础工具可以长期用，没有天数限制。
- 视频编辑有限制：官方中文官网的会员页口径是 30 秒 / 720P（截至 2026-09）。
- 素材库只放开一部分（官方口径约 1000+ 项），会员素材带角标。
- 导出成图 / 成片带应用水印（去除路径见 [导出水印怎么去掉.md](导出水印怎么去掉.md)），使用中会看到广告。

## 二、会员（Premium）多给什么

| 项目 | 免费版 | 会员 |
| --- | --- | --- |
| 素材库 | 部分（约 1000+ 项） | 全部（官方口径 20000+ 项） |
| 视频导出 | 30 秒 / 720P | 更长时长 / 更高清晰度 |
| 水印 | 有 | 无 |
| 广告 | 有 | 无 |
| 比例 | 常用比例 | 可自定义 |

注意口径差异：官方中文会员页写的是「15 分钟高画质视频编辑」，英文商店页的应用介绍里写的是「VideoGrids up to 3 minutes」。两个数字来自不同时期的官方材料，买之前以你看到的购买页为准。

## 三、订阅管理（买过或想退的看这里）

- **年方案有 3 天免费试用**，仅限首次购买；要在当前订阅周期结束前至少 24 小时取消，到期后才不扣下一期。
- **为什么被扣款**：免费试用期结束后会自动续订，到期前没取消就会扣下一期费用（官方 FAQ 原口径）。
- **删掉 App 不等于取消订阅**：直接卸载应用，订阅还在继续扣；要退订必须去订阅渠道操作（官方 FAQ 特别提醒过这一点）。
- **在官网（Web）买的会员**：登录 [photogrid.app](https://www.photogrid.app/zh-cn/) → 右上角头像 → 设置 → 取消订阅；Web 购买的会员可以在 Web / Android / iOS 跨平台使用。
- **在 Google Play / App Store 买的会员**：要回到对应商店的订阅管理里取消；商店渠道与 Web 之间的订阅不能互相转移。
- **换设备怎么接着用**：会员绑定的是购买时的账号。换安卓手机 / 平板，用同一个 Google 账号登录，重开 App 一两次即可同步会员状态；从安卓换 iPhone，只有在官网购买过会员才能跨平台继续用。
- **买完 App 里没显示会员**：官方给的排查顺序是——先把 App 更新到最新版，再退出账号、用购买时的那个 Google / Apple 账号重新登录。
- **老账号资料找回**：官方 FAQ 提到 Facebook 登录通道曾中断，此前用 Facebook 注册的账号登录不上；要找回账号里的点数或照片需要发邮件联系官方。
- 官方服务条款与隐私政策：`https://media.grid.plus/doc/grid_plus_terms_of_service` 与 `https://media.grid.plus/doc/grid_plus_privacy_policy`。

## 四、按这两条边界自己权衡

- 只偶尔拼几张图：免费版与会员的主要差别是水印和广告。
- 常做视频拼贴、要无水印出图：免费版的时长与清晰度上限才是主要差别。

订阅入口在应用内「我的 / 设置」里；本篇列的是官方页面的公开口径，不替代购买页的最终条款。
