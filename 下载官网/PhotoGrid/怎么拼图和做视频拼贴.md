# PhotoGrid 怎么拼图和做视频拼贴

> 本篇按步骤讲两条最常用的路线：把多张照片拼成一张网格图，以及把照片和短视频拼进同一个分屏视频。跟着做完一张图只要几分钟。

## 一、网格拼图：从选图到保存

1. 首页点 **Grid（网格）**。
2. 从相册勾选 2~16 张照片（一次最多 16 张），点下一步。
3. 应用按张数自动给出多套布局预览，左右滑动换布局；想调整某格里的图，长按拖动换位。
4. 底部工具栏可以调：边框粗细、圆角、背景（纯色 / 模糊 / 图案）、整体比例。
5. 点单张照片还能对它单独裁剪、旋转、加滤镜。
6. 右上角保存导出，成图写进相册。

两个省时间的做法：

- 张数没定先多选几张，布局预览会跟着张数变，比逐格删快得多。
- 先在「比例」里定好目标尺寸（发朋友圈 / Instagram 用 1:1，小红书常用 3:4），再排图，比排完再裁省事。

## 二、模板拼图：不想自己排版就用现成的

1. 首页选 **Template（模板）**，按节日、旅行、生日等主题挑一套。
2. 模板里的占位格逐个点开换上自己的照片，文字、贴纸也能改。
3. 免费模板与会员模板混在一起，带角标的是会员素材（区别见 [免费版和会员有什么区别.md](免费版和会员有什么区别.md)）。

模板库需要联网加载，网络不通时只剩本地布局；素材数量与分类以你打开应用时实际显示为准。

## 三、视频拼贴：把照片和短视频放进同一个画面

1. 首页选 **Video Grid（视频拼贴）**，或在模板里选带视频的款式。
2. 最多选 4 段视频，也可以照片、视频混选。
3. 每格单独裁剪时长；多段视频可以按同一时刻对齐开头（适合同一个场景的多机位片段）。
4. 加背景音乐：应用自带曲库直接挑；想用自己的歌，确认是 MP3 格式，先把它复制到「下载」以外的目录（官方 FAQ 的步骤要求先移出下载文件夹，复制失败说明文件已损坏），编辑页点「音乐」→ 右上角「我的音乐」添加。
5. 导出前完整预览一遍声音与画面。
6. 导出时长与清晰度受版本限制：免费版有 30 秒 / 720P 的上限（官方会员页口径），会员可到更长时长与更高清晰度，以应用内实际提示为准。

## 四、保存之后

- 成图 / 成片在相册里 PhotoGrid 自己的目录（不同机型目录名不同，找不到时看 [常见问题与解决方法.md](常见问题与解决方法.md)）。
- 几项与导出直接相关的设置都在首页左上角「选单」→「设置」里：

| 设置项 | 作用 |
| --- | --- |
| 保存路径 | 查看并更改成图 / 成片的落盘位置 |
| 图片格式 | 切成 `.PNG`，成图按无损格式保存 |
| 图片大小 / 影片拼贴画质 | 调整导出分辨率与清晰度 |

- 分享用系统分享面板直接发到微信、Instagram 等。
- 图里有想抹掉的路人或杂物，接着看 [抠图与消除笔怎么用.md](抠图与消除笔怎么用.md)；导出的图带水印，去除路径见 [导出水印怎么去掉.md](导出水印怎么去掉.md)。
