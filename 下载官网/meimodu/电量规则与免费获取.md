## 一、电量怎么扣

你每发一条消息、角色每生成一条回复，都会消耗一定电量。文字、语音、剧情场景等不同互动方式的消耗口径可能不同，以应用内电量页的实时说明为准——那里同时显示当前余额与获取入口。

按多个公开介绍页的一致说法：免费电量用完后，想继续聊就需要在应用内付费补充；不打算付费的话，思路就是「把免费渠道全部用满」。

## 二、免费获取途径汇总

| 途径 | 说明 |
| --- | --- |
| 新用户登录奖励 | 首次登录送一笔初始电量（有介绍页写为 50 点，以你登录时页面显示为准） |
| 每日签到 | 每天一次，数额不大但稳定，适合当基本盘 |
| 完成任务 | 应用内的日常或活动任务，完成后发放电量 |
| 创作并发布剧情卡 / 原创角色 | 产出型途径，做卡上架、参与平台活动都能拿奖励，做法见 [角色卡创建与导入.md](角色卡创建与导入.md) |
| 分享应用 | 按页面指引分享后领取，多为一次性 |
| 兑换码 | 官方不定期发放；网上介绍页列出过若干兑换码，是否仍然有效以应用内兑换入口实测为准，别按过期攻略硬试 |

各途径的具体数值随版本调整很常见，动手前以应用内当时显示为准。

## 三、免费电量用完了怎么办

两条路：

1. **应用内充值**：在电量页直接购买，适合已经有固定聊天对象、想保持连续对话的情况；档位与价格以应用内为准。
2. **等次日免费额度**：签到与任务每天刷新，当天电量见底就先停，第二天续上。适合一天聊一阵就够、不着急的用户。

有用户反馈免费电量「聊几句就见底」——初始那笔电量主要是让你熟悉玩法，别指望它撑太久。打算长期用，就从第一天起把签到和任务当成每日动作。

## 四、让电量花得慢一点

- 挑一两个角色深耕，比同时开十来条会话省——每条线的剧情铺垫都要按消息条数扣电量；
- 对方一条回复跑偏时，先用「重说」或「编辑」纠正（操作见 [对话技巧与记忆功能.md](对话技巧与记忆功能.md)），比连发几条解释更划算；不同操作的计费口径以应用内为准；
- 语音通话的消耗与打字不同，睡前长时间挂机前先确认当前余额。
