## 一、它会要哪些权限

应用商店权限清单（截至 2026-09）里列出的主要权限，按用途整理：

| 权限 | 干什么用 | 建议怎么给 |
| --- | --- | --- |
| 麦克风（录音） | 语音房上麦、语聊 | 核心功能，想玩语聊就给 |
| 相机（拍摄） | 视频聊天、发视频动态 | 用到再给 |
| 位置 | 房间与内容推荐可能用到 | 可以先拒绝，用到时再开 |
| 存储/照片/媒体 | 发图片、存图片 | 可以先拒绝，用到时再开 |
| 通知 | 好友邀请、活动提醒 | 按需给，嫌吵就关 |
| 后台运行/前台服务 | 语音通话时保持连接不断线 | 系统自动管理，一般不用管 |
| 蓝牙、NFC、精确闹钟等 | 配套功能 | 一般不用主动开 |

被拒掉的权限只影响对应功能，之后随时可以在手机的系统设置里补开；不用应用时也可以在这里把权限收回去。

## 二、为什么它总在后台被唤起

官方协议里有一节「APP 自启动与关联启动的特别说明」，把唤起场景说清楚了：开着实时语音会话时，应用要在后台维持连接保证通话不断；开了消息通知后，离线消息（好友邀请、活动提醒）会经厂商推送通道在到达时短暂唤起应用展示通知。嫌它后台活跃的话，官方给出的关闭路径是手机系统设置或应用内「设置-通知管理」，关掉后不影响基础聊天使用，只是对应的通知收不到了。

## 三、它接了哪些第三方服务

官方《用户隐私协议》（2026-09-16 更新）披露的第三方接入，按用途归类：

| 用途 | 涉及的服务 |
| --- | --- |
| 实时语音连线 | 声网 Agora |
| 私聊、群聊、房间公屏 | 环信即时通讯 |
| 广告展示与短剧 | 穿山甲（GroMore）、穿山甲短剧 SDK |
| 登录与支付 | 微信、QQ、Facebook、支付宝、移动/联通/电信一键登录 |
| 统计与崩溃上报 | 友盟、Bugly、火山引擎 |
| 内容安全过滤 | 数美设备风险 SDK |
| 渠道统计与版本升级 | OpenInstall、Shiply |

这些 SDK 各自有独立的隐私政策，官方协议里附了链接。你在应用里说的话、发的动态会经由这些服务传输和存储，介意哪一家就去读哪一家的政策。完整协议见 [ChatGC 用户隐私协议](https://admin.chatgc.top/api/article/detail/id/19)（`chatgc.top` 域名下，2026-09-16 版，以官方页面最新版为准）。

## 四、和陌生人聊天的防骗要点

跨国语聊类应用是诈骗套路的高发区，几条硬规则：

- **谈钱就停**：对方不管编什么由头 —— 投资、博彩、代充、救急 —— 只要聊到转账、充值、带你「赚钱」，直接拉黑举报。
- **不给验证码**：短信验证码谁要都不给，给了等于把账号送人。
- **不发证件与住址**：身份证、护照、家庭住址、行程，发了就可能被拿去做别的。
- **警惕过快升温**：认识没几天就「深入灵魂」，再顺势带你投资理财，是这类平台上最常见的组合拳。
- **举报入口在应用内**：遇到骚扰或诈骗，先在应用内举报并留好截图，必要时向平台客服进一步反映。

## 五、账号与协议里值得看的几点

- 注册时填的资料、聊天产生的数据都按官方协议收集和存储；注销账号后相关数据按约定删除，操作见 [注册登录与账号注销.md](注册登录与账号注销.md)。
- 协议约定的管辖法院是陕西省西安市雁塔区人民法院（2026-09-16 版协议），点「同意」之前知道这件事就好。
- 未成年人使用：协议有专门章节处理未成年人信息；家长不希望孩子用的话，最直接的办法是在设备层面做管控，而不是指望应用内的年龄门槛。
