## 一、Laplace 是干什么的

Laplace 是 Chaldea 内置的战斗模拟器：你选一个关卡、摆好队伍，它按游戏规则计算每张指令卡与宝具的**伤害、NP 回收、星星掉落**，帮你验证「这套队伍三回合能不能清掉」。周常 Free 本要摆 3T 队、挑战本要算伤害线时，先在这里跑一遍验证，不用消耗游戏内的体力。

模拟结果的可信度取决于你喂给它的数据 —— 从者等级、技能练度、宝具级都可调，用它模拟「我还没练满的从者」时记得把等级改对，否则算出来的是满级数据。

## 二、第一步：选关卡

四种选法，任选其一：

1. **下拉菜单**直接选 Free 关卡；
2. 从章节（War）进关卡详情，点 Spot 名字右侧的**计算器图标**跳转进来；
3. **输入 Atlas ID 或 URL** —— 形如 `93000002/3`（关卡 ID + 第几段），也支持 `https://cn.chaldea.center/quest/93000002` 这类地址，仅限日服与美服数据；
4. **导入 JSON** —— Atlas DB 格式的关卡数据，从任意关卡的「Export JSON」可看到结构，不懂这个格式就用前三种。

选好后还能基于当前关卡**自建关卡**（Custom Quest）：改敌人、改属性。敌人从者选中后属性会自动填充，死亡率一般也按从者数据预填（敌方从者通常低于 1%，多为 0.2%）；防御 NP 率是游戏服务器下发的值，需要你手动填。

## 三、第二步：编成与从者设置

编成区的关键按钮：

- **Clear** —— 清空当前队伍；
- **Save** —— 把当前队伍存为模板，存在本地（Local Teams）；
- **Local Teams / Shared Teams** —— 载入自己存过的模板，或看**别人上传的通关队伍**（见第五节）。

点从者或礼装图标进入设置，可改的项：

| 项目 | 说明 |
| --- | --- |
| 再临阶段 | 点「Ascension X」标签切换，影响卡面与部分效果 |
| 等级 / Fou / 指令卡强化 / 纹章 | 滑条项点左侧标签可直接输数字 |
| 技能与宝具 | 手动配置等级，也可以禁用某技能或自定义 |
| 追加技能 | 从者等级为 0 时追加技能项禁用 |
| Support / NPC | 只影响**算 Cost**；标成 NPC 的从者不能随队伍上传到共享队伍 |

还有两个容易忽略的点：

- **强化状态与默认等级**（Formation Edit 里）：未加入当前规划的从者按「Default Lvs」的默认值进入模拟；已加入的可选按规划的**当前**练度或**目标**练度来。模拟「我现在打不打得过」选当前，模拟「练满后打不打得过」选目标。
- **自定义技能 / Buff**：能往从者身上挂自定义效果，会作为被动加入计算；右上角菜单还可以添加敌人或 NPC 支援（剧情助战那种）。

## 四、跑模拟：看什么

设置完直接跑，输出覆盖每回合的伤害、NP、星星。判断 3T 队是否成立，主要看两件事：

1. **每面伤害是否过线** —— 按敌方血量与特攻情况核对，宝具本、技能等级不对时结果会差很多；
2. **NP 回收是否支撑连发** —— 鞭尸、过量伤害（overkill）影响 NP 回收，模拟里都会算进去。

队伍模板（Save 存的）留在本地，同一关卡反复迭代时直接载入改数字即可。

## 五、参考别人的通关队伍

Shared Teams 页面列出**其他用户上传的、通关当前关卡的队伍**，右上角图标可过滤条件，点 Details 能看上传者当时的具体操作序列。适合挑战本卡关时看别人的解法抄思路 —— 注意上传队伍要求完整通关且不能含 NPC 支援，所以列表里的队伍都是真实可复现的。

想把自己打过的队伍传上去给别人看，就在通关后用上传入口；上传的内容同样受「不含 NPC 支援」这条约束。
