## 一、启动失败或白屏

按出现频率排：

1. **压缩包里直接运行** —— 桌面版必须先解压再启动，别在压缩软件的预览窗口里点；
2. **路径需要管理员权限** —— 放到 `C:\` 根目录、`C:\Program Files\` 或网络盘/FTP 映射盘都会导致读写受限，换到普通用户目录；
3. **系统不满足** —— Windows 只支持 64 位、Win10 及以上；安卓要求 Android 7.0 起（完整表见 [下载与安装教程.md](下载与安装教程.md)）；
4. **杀毒软件拦截** —— 开源项目，把应用目录加入排除/信任即可；
5. **Web 版白屏** —— Firefox 无痕模式或「关闭时清除历史记录」会禁用 IndexedDB，导致应用起不来，换个普通窗口即可。

## 二、图片/语音加载不出来

卡牌图标、技能图标、立绘、语音大多是**用到时才下载**的，第一次大量使用会集中发请求，部分失败很常见。三步排查：

1. **重启应用** —— 一次性请求太多导致的零星失败，重启基本就好；
2. **检查网络设置** —— 设置里若显示离线但实际有网，打开「强制在线模式」；
3. **切换服务线路** —— Chaldea 的服务分国内与海外两条路线，连不上就切另一条；能连海外时用海外可省流量；
4. **清缓存重下** —— 设置的游戏数据管理里可分别清理内存缓存、temp 目录、图片资源目录；图标类缓存（从者/礼装/buff 图标共 3000+ 张）损坏时清掉重下最直接。

## 三、找不到某个从者或礼装

绝大多数情况不是数据丢了，是**被你自己筛掉了**：检查列表页的心形「收藏」按钮、筛选对话框、优先级筛选，看计数是不是「显示 N / 总计 N」里被藏了那部分。重置筛选再找一次，基本都能找到。

## 四、数据备份：卸载前必做

这条最容易吃大亏：**Android 上卸载应用会把应用数据目录整个删掉**（`Android/data/cc.narumi.chaldea/files/`），你的养成规划、导入的账号数据全部在内，卸载即清空。所以换机、重装、升级 v1→v2 之前，先备份：

| 备份方式 | 怎么做 | 适用场景 |
| --- | --- | --- |
| 应用内备份 | 设置 → 用户数据 → 备份，生成 `userdata.json` | 日常、卸载前 |
| 历史备份 | 设置 → 用户数据 → 历史备份，应用**每天自动**存一份 | 兜底，忘了手动备份也有 |
| 服务器备份 | 设置里上传备份，换机时下载恢复 | 换设备 |
| GitHub 备份 | 把数据同步到自己的 GitHub 仓库；SHA 不匹配会同步失败，清除 SHA 后可强制覆写远端 | 想留一份异地副本 |
| 手动复制 | 直接拷贝 `userdata.json`（路径见下） | 应用打不开时抢救 |

两点容易误会的性质：**服务器备份不是自动同步** —— 需要你手动上传、手动下载，换机时别指望它后台悄悄同步；**多设备同时用**时同一份数据不会自动合并，谁后上传谁覆盖。日常维护的顺序建议是：改完数据 → 上传服务器备份 → 隔几天留一份本地 json。

数据根目录在 Android 上是 `Android/data/cc.narumi.chaldea/files/`，应用内「设置 → 用户数据 → 数据文件夹」能看到真实路径。核心文件是 `user/userdata.json`（全部用户数据）与 `user/settings.json`（本地设置），每日自动备份在 `backup/` 下。恢复时导入任意一份 json 即可。

注意：**不同版本的数据结构可能不兼容**，老版本的备份在新版本里未必能恢复 —— 重要数据别只留一份。

**有 SD 卡的手机**：设置的用户数据里可切换外部储存（SD 卡）并自动迁移数据。两个警告要当心 —— 自动迁移会**直接覆盖**目标位置已存在的文件；切换后必须**重启应用**才生效。迁移前先按上表做一份手动备份，官方文档原话就是「做好手动备份以防意外」。

新装应用后要恢复数据（而不是重新抓包），走的也是导入备份这条路，步骤见 [账号数据导入教程.md](账号数据导入教程.md)。

## 五、忘记密码

账号系统只用于在线备份与队伍分享，忘了密码按下面信息找回：**准确的用户名、注册日期、近期登录过的设备 UUID**。UUID 的取法：「关于 Chaldea」→ 长按 logo → 复制 UUID；用应用内「反馈」发送会自动附带 UUID。另外官方再次提醒这个账号别用常用密码，忘了也不至于心疼。

## 六、其他零碎问题

- **文本/数据有错**：未实装内容常缺翻译；技能、宝具、任务文本是按游戏数据自动解析的，发现解析错误可通过应用内反馈提交。
- **应用老弹更新**：「关于 Chaldea」里可开关自动更新检测；安卓上检测到更新会跳转下载页，装新 apk 覆盖即可。版本号会随时间变化，以官方发布页当时显示为准。
- **多个实例互相覆盖**：手机 app、桌面版、网页版别同时改同一份数据，操作完一个再开下一个（见 [新手使用指南.md](新手使用指南.md)）。
