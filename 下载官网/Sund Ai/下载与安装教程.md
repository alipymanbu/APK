## 一、动手前先对上这张表

Sund Ai 是广西盈豪科技有限公司开发的 Android 端 AI 音乐创作应用：你输入一段文字灵感或自己写的歌词，它生成带人声与伴奏的完整歌曲，之后还能接着做翻唱、伴奏提取、歌词改写和音乐 MV。

装之前先核对事实。同名或近名的安装包在网络上不止一份，版本号、体积、包名对不上，后面看到的功能就会和界面实际内容对不上。

| 项目 | 值 |
| --- | --- |
| 应用名称 | Sund Ai |
| 版本号 | v1.8.4.1 |
| 包名 | `com.sw.suno` |
| 安装包大小 | 92.67M |
| 文件校验值（MD5） | `412df3d22592a531cf4cb749b1b84745` |
| 系统要求 | 需要 Android 4.3 及以上（以应用内页面为准） |
| 资费 | 应用内提供付费项目，具体价格与包含内容以应用内页面为准 |

其中**包名**和**版本号**最该看：包名是应用在系统里的身份，版本号决定你拿到的功能对不对得上本文的描述。网上还能搜到同一应用的其他版本——更早的 v1.8.3、更晚的 v1.8.5 与 v1.8.6——那是不同时间发布的包，体积和细节都可能不同，两边数字不要混着用，以你手上这一份为准。

还有一点容易绕晕：这个名字在应用商店、应用宝、第三方下载站上的写法各不相同，早期也以别的名字上架过。名字换了几轮，包名 `com.sw.suno` 一直没变，所以**认包名比认名字可靠**。哪些写法属于同一个应用、哪些同名应用其实无关，单独收在 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 里。

## 二、把安装包取到手机里

1. 在手机上打开 [Sund Ai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/773eeac5e236)，进入分享页。分享页指向的是这个应用所在的目录，进去后取里面的安装包文件。
2. 没有网盘账号的先按提示注册或登录，已有账号的点「保存到网盘」，把目录转存进自己的空间，再从自己的网盘里下载。转存后下载比在分享页里直接打开稳：分享页刷新、网络波动都不会把下载打断。
3. 下载完的文件名形如 `Sund Ai_vv1.8.4.1.apk`。**别在网盘里直接点「打开」**，那通常只会触发在线预览；要选「下载」，等文件完整落到手机的下载目录。
4. 想确认文件有没有下坏，用上一节的 MD5 对一遍：`412df3d22592a531cf4cb749b1b84745`。不少文件管理器自带校验入口，算出来的字符串与这串完全一致就说明文件完整；没有校验入口的，也可以看文件体积是否在 92.67M 附近。

这一步卡在「网盘打不开」或速度极慢，先换手机流量、或者挪到网络空闲的时段再试，这类情况基本与安装包本身无关。

## 三、允许这个来源安装应用

Android 默认不允许安装来自浏览器或网盘的文件，第一次装通常会弹「已阻止安装」。打开方式按系统版本分两路：

| 系统版本 | 操作路径 |
| --- | --- |
| Android 8.0 及以上 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 → 选中你下载用的浏览器或网盘 App → 打开开关 |
| Android 7.x 及以下 | 设置 → 安全 → 打开「未知来源」 |

开关打开后回到文件管理器，点安装包继续。装完建议把开关关回去，以后需要时再临时打开。

## 四、安装时的几种提示怎么处理

| 提示 | 含义与处理 |
| --- | --- |
| 「解析软件包时出现问题」 | 文件没下完或已损坏。删掉重新下载，并按第二节的 MD5 再校验一遍 |
| 「应用未安装」 | 手机上已存在包名 `com.sw.suno` 的其他版本。先在设置里卸载旧的那个，再装这一份 |
| 安全软件提示风险 | 非应用商店来源的常见提醒。确认文件来自你信任的渠道后继续 |
| 装完桌面上没有图标 | 部分启动器需要几秒刷新；回桌面下拉一次，或在应用列表里搜「Sund Ai」 |
| 装到一半反复失败 | 先看手机剩余存储够不够——安装过程也会占临时空间，腾出空间再重试 |

## 五、第一次打开要做三件事

1. **同意隐私政策与用户协议**。首次启动会先弹这两份文本，读完同意才能进主界面。
2. **登录账号**。创作、作品库、翻唱这些功能都绑在账号上，按提示用手机号或应用支持的第三方方式登录。登录环节的异常处理收在 [常见问题与排查.md](常见问题与排查.md)。
3. **按提示给权限**。这个应用申请的权限比较全，逐项对应关系如下：

| 权限 | 用它做什么 |
| --- | --- |
| 麦克风（录音） | 录制声音做音色卡片，以及涉及哼唱、音频输入的创作方式 |
| 照片与视频 / 读取媒体文件 | 从相册挑照片做音乐 MV，读取你要处理的音频 |
| 写入文件与文档 | 把生成好的歌曲、MV 存到手机 |
| 网络与查看网络状态 | 生成、同步、分享都靠联网 |
| 拍摄照片和视频、闪光灯 | 应用内有拍照入口时使用 |
| 通知与振动 | 生成完成后提醒你 |

不给麦克风权限，音色卡片和翻唱就做不了；不给存储权限，生成好的作品可能保存不下来。用不到的功能可以不给，但要清楚代价是什么。
