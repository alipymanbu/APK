## 一、先分清卡在哪一步

Sund Ai 是一款输入文字就能生成歌曲的 Android 应用，出问题时，先把「卡在哪一步」定下来，比挨个试快得多：

| 现象出现在哪 | 问题多半在 | 看本文第几节 |
| --- | --- | --- |
| 装着装不上 | 安装包或系统设置 | 第二节 |
| 登录、进不去主界面 | 账号或网络 | 第三节 |
| 点了生成迟迟没结果 | 网络、后台、灵感写法 | 第四节 |
| 出歌了但不好听 | 灵感与歌词的写法 | 第五节 |
| 提取伴奏、翻唱出问题 | 权限或素材本身 | 第六节 |
| 保存、分享、发行异常 | 权限、存储或平台侧 | 第七节 |

如果是刚装完就出现的异常，先核对手上的版本：本篇对应的这一份是 **v1.8.4.1**，包名 `com.sw.suno`，大小 92.67M。版本对不上就先回安装篇重新取一份再排查。

## 二、安装与升级

| 现象 | 处理 |
| --- | --- |
| 提示「解析软件包时出现问题」 | 文件没下完或已损坏。删掉重新下载，用 MD5 `412df3d22592a531cf4cb749b1b84745` 校验一遍 |
| 提示「应用未安装」 | 手机上已有包名 `com.sw.suno` 的其他版本，先在设置里卸载旧的再装这一份 |
| 点安装包没有任何反应 | 检查「安装未知应用」权限是否给了下载用的那个 App |
| 应用权限里找不到麦克风 / 存储 | 到系统设置 → 应用 → Sund Ai → 权限里单独打开。录音权限关着就做不了音色卡片，存储权限关着保存会失败 |
| 升级后原来能用的功能不见了 | 界面入口会随版本调整。核对版本号，并确认是不是被挪进了别的创作入口 |
| 装完发现功能完全不对，像是另一个应用 | 大概率装成了同名但不同包名的应用。卸载后按包名 `com.sw.suno` 重新取包，甄别方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) |

逐项提示的完整对照与分系统版本的操作路径，见 [下载与安装教程.md](下载与安装教程.md)。

## 三、登录与首次启动

- **收不到验证码**：先换网络重试。短信验证在信号差或被运营商拦截时容易迟到，连续点击会触发频次限制，等几分钟再来更有效。
- **登录后仍停留在登录页**：把应用从后台彻底清掉再打开；仍然如此，检查系统时间是否自动校准。
- **每次打开都要重新登录**：多半是被系统省电策略限制了后台。把 Sund Ai 加进电池优化的白名单，或关掉针对它的省电限制。
- **换了手机作品不见了**：作品挂在账号上，先用同一个账号登录，再对照 [作品怎么保存分享与发行.md](作品怎么保存分享与发行.md) 第七节看换机步骤；哪些内容会跟着账号走（作品库、音色卡片）以及同步范围的口径，见同一篇第一节与第五节。

## 四、点了生成，迟迟没结果

这一类最常见，基本落在三个原因上：

1. **网络中断**。生成全程联网，走到一半断网就停在原地。切到稳定的 Wi-Fi 或换手机流量重试。
2. **应用被后台清掉**。等待期间划掉应用、或者被省电策略杀掉，任务会中断。生成时让应用留在前台。
3. **灵感写得太空泛**。只写「好听的歌」这类描述，应用要自行发挥，结果既慢又容易跑偏。按 [怎么用一句话生成一首歌.md](怎么用一句话生成一首歌.md) 第二节补上画面、曲风、情绪三件事再试。

生成本身需要等一段时间，而且**没有固定时长**——等待长短取决于服务器排队与你的网络状况，官方资料里也没有给出一个可以照着判断的数值。所以判断标准不是「过了几分钟」，而是**界面长时间没有任何变化**：到了这一步才按上面的顺序排查。

## 五、出歌了但不满意

| 不满意的地方 | 先改什么 |
| --- | --- |
| 曲风整个不对 | 换风格选项，或改灵感里的曲风词，一次只换一个方向 |
| 情绪不对但曲风对 | 只改灵感里的情绪描述，别动风格 |
| 人声咬字含糊 | 换成自己填词，把长句拆短、标点别乱 |
| 段落接不上、顺序乱 | 用续写补，或换到能控参数的入口，见 [创作入口与参数怎么选.md](创作入口与参数怎么选.md) |
| 整体还行只差一点 | 输入不动，直接再生成一版 |

歌词与灵感的分工、续写与改写的用法，分别见 [怎么用一句话生成一首歌.md](怎么用一句话生成一首歌.md) 和 [伴奏提取与热歌改词怎么做.md](伴奏提取与热歌改词怎么做.md)。

## 六、伴奏提取与翻唱出问题

| 现象 | 处理 |
| --- | --- |
| 提取伴奏失败 | 先换一份音质更好的源文件重试。旧版本在部分机型上有此问题，v1.8.4.1 的更新说明里写明已修复，版本偏低就升级 |
| 提取出来还残留人声 | 原曲人声与伴奏叠得厚，属于素材本身的限制。试试换源文件，或改用本身就是伴奏的音频 |
| 录不进声音、做不出音色卡片 | 检查录音权限；确认录制环境没有回声和背景音乐；只录人声，别混伴奏 |
| 翻唱出来还是原来的声音 | 创作时没有选中自己的音色卡片。回到创作页确认卡片被选中后重新生成 |
| 上传的音频读不出来 | 确认存储 / 媒体读取权限已给；换一个格式常见的文件再试 |

录音与卡片的质量要求，见 [AI翻唱与音色卡片怎么做.md](AI翻唱与音色卡片怎么做.md) 第二节。

## 七、保存、分享与发行异常

- **找不到下载下来的文件**：多半是存储权限没给。到设置里打开存储／媒体权限后重新下载，然后去文件管理器的下载目录里找。
- **下载到一半失败**：先看剩余存储空间是否够——音频还好，MV 视频占地明显更大。
- **分享出去对方打不开**：只在应用内预览过、没有生成独立文件的作品，换设备通常打不开。先下载再分享，或者用应用内的分享入口发。
- **点了全网发行没有反应**：发行要填作品信息并走平台侧审核，不是即时上线。确认信息是否填全、作品是否符合入口说明里的要求，具体**以应用内页面当时显示的为准**。
- **重新生成后找不到旧的那一版**：重新生成一般不覆盖旧作品，但列表里容易看混。满意的版本当场保存或下载，做法见 [作品怎么保存分享与发行.md](作品怎么保存分享与发行.md) 第二节。
- **想发行，但不确定这首歌算不算自己的**：作品一旦进入公开曲库就涉及第三方平台，投递之前先按 [AI音乐版权与声音使用边界.md](AI音乐版权与声音使用边界.md) 第六节的六条自查走一遍，把词、曲、人声、画面四份素材的来源都答上来再填发行信息。

## 八、还解决不了时

按「先权限、再网络、最后重装」的顺序走一遍——绝大多数异常集中在前两步。确实需要重装的，先卸载，再回 [Sund Ai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/773eeac5e236) 取同一份安装包重装；重装只影响应用本身，此前已经下载到手机里的音频与视频文件通常不受影响，但**没有下载过的作品请先确认还在账号里**。

从零走一遍完整流程，可以回去看 [怎么用一句话生成一首歌.md](怎么用一句话生成一首歌.md)，按步骤做一遍通常比逐项试错更快定位问题。
