# GammaPPT 在电脑上怎么用

> GammaPPT 是手机应用，本篇讲在电脑上使用它的两条路：用应用宝电脑版直接运行安卓版，或在手机上做好后把 PPTX 导出到电脑加工。

## 一、先分清两种用法

- 想在电脑上直接操作 GammaPPT：用应用宝电脑版（腾讯的安卓应用运行环境）安装手机版 GammaPPT，操作方式与手机一致；
- 只是想在电脑上改做好的 PPT：在手机上把文稿导出成 PPTX 发到电脑，用 PowerPoint / WPS 打开继续编辑，导出方法见 [导出与保存方法.md](导出与保存方法.md)。

两条路不冲突：手机上生成初稿，电脑上精修排版，是常见组合。

## 二、用应用宝电脑版运行

1. 电脑浏览器打开 `https://sj.qq.com`，下载安装应用宝电脑版；
2. 在应用市场里搜 GammaPPT，进入详情页点「安装」；
3. 装完从桌面图标启动（官方支持给安卓应用直接创建桌面图标），鼠标点击、长按对应手机上的触屏操作。

账号方面：用手机号登录时，验证码发到你的手机上填入即可；用 QQ 或微信登录时，官方帮助中心要求电脑端也装好对应的 QQ / 微信再连通，登录前先确认这一点。

## 三、常见状况

| 状况 | 处理 |
| --- | --- |
| 安装应用时提示「下载失败 / 网络错误，请重试」 | 先确认网络；部分校园网、公司网会限制外部应用下载，换手机热点再试 |
| 打开卡顿、卡死 | 用任务管理器关掉占内存的其他程序再试；同时开的应用越多越容易卡 |
| 想跑得更流畅 | 在应用宝电脑版的性能配置里，按自己电脑的配置调节分配给应用的资源 |
| 登录后不是日常用的账号 | 检查登录方式：手机号、QQ、微信登录进的是不同账号，换登录方式前先想清楚文稿在哪个账号里 |

以上处理办法整理自应用宝官方帮助中心，具体界面入口以你装到的版本实际显示为准。

## 四、电脑上要装 Office 吗

只在 GammaPPT 里做 PPT 不需要；要把导出的 PPTX 在电脑上继续编辑或放映，才需要 PowerPoint 或 WPS 之类的办公软件。装不上或卡住的情况见 [常见问题与解决方法.md](常见问题与解决方法.md)。
