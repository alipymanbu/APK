## 一、装之前先知道这几件事

GammaPPT 是一款安卓手机应用，用来在手机上生成和编辑 PPT。本篇对应的安装包信息如下，装完后可以用它核对：

| 项目 | 信息 |
| --- | --- |
| 应用名 | GammaPPT（应用商店上架显示名） |
| 版本 | 6.0.0 |
| 包名 | `com.pdjjxxt.zzzs` |
| 安装包大小 | 45.32 MB |
| MD5 | `034E3B819064827D76E52767644D39A9` |
| 系统要求 | 安卓 5.2 以上（以手机实际兼容情况为准） |

各应用商店也在更新这个应用，商店里的版本号可能比上面这个新。版本不同不影响安装方法，但功能界面可能有差异，遇到对不上的界面时先确认自己装的是哪个版本。

## 二、从夸克网盘拿安装包

1. 打开上面 [GammaPPT 安装文件资源（夸克网盘）](https://pan.quark.cn/s/dd39c56ea611) 的链接；
2. 把文件转存到自己的网盘（夸克网盘的分享需要先转存才能下载）；
3. 在网盘里找到 `gamma_v6.0.0.apk`（文件名以网盘内实际显示为准），下载到手机。

转存按钮在哪、空间不足这类提示怎么处理，见 [网盘转存与下载步骤.md](网盘转存与下载步骤.md)。

## 三、安装步骤

1. 在手机上点开下载好的 APK 文件；
2. 系统提示「未知来源」或「不允许安装未知应用」时，按提示允许（路径一般在 设置 → 安全 → 安装未知应用，不同品牌叫法略有差异）；
3. 回到安装界面，点「安装」，等待完成；
4. 完成后点「打开」，或在桌面找到 GammaPPT 图标启动。

装不上时直接去 [常见问题与解决方法.md](常见问题与解决方法.md) 对号入座，大多数安装失败是下载不完整或系统版本不够。

## 四、在电脑上用怎么办

这款应用是手机端应用。要在电脑上用，可以借助应用宝电脑版（腾讯的安卓应用运行环境，官方页面明确支持这种方式）：

1. 在电脑浏览器打开 `https://sj.qq.com`，下载应用宝电脑版并安装；
2. 在应用宝电脑版里搜索 GammaPPT，进入详情页点「安装」；
3. 装完后从桌面图标启动，后续操作与手机端一致。

装不上、卡顿这类状况的处理办法，见 [电脑上怎么用.md](电脑上怎么用.md) 的常见状况一节。

## 五、装完之后

第一次打开会请求网络等权限，AI 生成功能要在联网状态下使用。装好后从 [一键生成PPT完整流程.md](一键生成PPT完整流程.md) 开始，能最快做出第一份 PPT；做好的文稿怎么存、怎么导出，看 [导出与保存方法.md](导出与保存方法.md)。
