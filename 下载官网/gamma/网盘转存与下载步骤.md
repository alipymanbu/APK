# GammaPPT 网盘转存与下载步骤

> 本篇讲怎么把 GammaPPT 安装文件资源从夸克网盘分享链接存到自己的网盘、再下载到手机，以及转存时各种提示的处理办法。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [常见问题与解决方法.md](常见问题与解决方法.md)

> [!IMPORTANT]
> **GammaPPT 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/dd39c56ea611](https://pan.quark.cn/s/dd39c56ea611)

## 一、为什么要先转存

夸克网盘的分享链接不能直接把文件存到本地，要先把文件转到自己的网盘账号里，再从自己的网盘下载。所以流程固定是两步：转存 → 下载，中间需要登录夸克账号（没有就先用手机号注册一个）。

## 二、转存到自己的网盘

1. 手机或电脑上打开上面的分享链接（链接以 `pan.quark.cn/s/` 开头）；
2. 勾选文件，点「保存到我的网盘 / 转存」，选一个存放位置并确认；
3. 转存完成后，在夸克 App 的「网盘 → 我的文件」里能看到这份文件。

## 三、下载到手机安装

1. 在手机夸克 App 里进入转存后的文件位置，长按勾选，点「下载」；
2. 下载完成后在手机通知栏或夸克的下载列表里点开文件，开始安装；
3. 后续步骤与普通 APK 一样，见 [下载与安装教程.md](下载与安装教程.md) 的安装步骤一节。

## 四、转存时可能遇到的提示

| 提示 / 状况 | 原因与处理 |
| --- | --- |
| 点转存跳到登录页 | 没登录夸克账号，先登录再转存 |
| 提示空间不足 | 普通用户初始空间有限，官方说明新用户首次保存他人分享可扩容，具体额度以夸克页面显示为准；空间不够就先清理网盘或扩容 |
| 保存按钮点了没反应 | 换个网络重试，或在手机 App、电脑网页端换一个入口再操作 |
| 下载速度慢 | 普通用户与会员的下载速度策略不同，高峰期也会更慢，可换个时段再下 |

下载完成后先核对安装包大小（45.32 MB）和 MD5（`034E3B819064827D76E52767644D39A9`），确认文件完整再安装，能省掉「解析包错误」这类返工。装好之后从 [一键生成PPT完整流程.md](一键生成PPT完整流程.md) 开始使用。
