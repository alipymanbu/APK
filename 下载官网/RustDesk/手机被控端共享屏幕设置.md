# 手机被控端共享屏幕设置

> 让电脑控制这台手机：四个权限怎么开、服务怎么启动、密码怎么固定。

## 一、先想清楚要开放到哪一步

「手机被控」= 你在电脑前远程看这台手机的屏幕、替它点操作。RustDesk 把这件事拆成四个开关，按需打开，不用全开：

| 开关 | 作用 | 不开的后果 |
| --- | --- | --- |
| 屏幕录制 | 把手机画面传给对方 | 对方发不出控制请求，什么都看不到 |
| 输入控制 | 允许对方用鼠标/触摸操作手机 | 只能看画面，不能点 |
| 文件传输 | 允许对方读写手机文件 | 对方无法进文件传输 |
| 音频录制 | 共享手机系统内部播放的声音 | 对方听不到手机里的声音（麦克风收音是另一回事） |

屏幕共享需要安卓 6 及以上，系统内部声音共享需要安卓 10 及以上。**除屏幕录制外，其他开关的切换只对新连接生效**——正在会话中要改，先断开连接、改完再让对方重连。

## 二、逐个开权限

在手机上打开 RustDesk，底部导航切到「共享屏幕」页，逐项配置：

1. **屏幕录制**：点开关后系统弹出投屏确认，允许即可。**每次重新启动 RustDesk 都会重新向你要一次这个权限**，这是系统行为，看到弹窗点允许就行。
2. **输入控制**：这是特殊权限，会跳到系统设置里手动开——不同品牌路径略有差异，通用走法是：设置 → 无障碍（或 辅助功能）→ 已安装的服务 → 找到 `RustDesk Input` → 打开。对方要用鼠标操作你手机，全靠它。
3. **文件传输**：同样是特殊权限，点击后会跳到「所有文件访问」一类的系统页授权。
4. **音频录制**：直接点开关允许。

## 三、启动服务，拿到 ID 和密码

权限配好后点「启动服务」（拿到屏幕录制权限时会自动启动）。服务跑起来后：

- 界面上会出现这台手机的**唯一 ID** 和一个**随机密码**，把它们发给电脑那头，对方在桌面端输入即可连入；
- 也可以不开密码让对方发请求、你在手机上手动点确认——适合偶尔被协助一次的场景；
- 服务运行中，你随时可以停止服务，或只断开某一个连接；
- 会话里双方可以收发聊天消息。

电脑连上手机后，鼠标的对应关系是：**右键 = 返回，中键（滚轮按压）= 回到桌面，长按中键 = 最近任务列表，滚轮滚动 = 上下滑动页面**——在电脑前就能把手机的基本导航走完。

## 四、密码每次重启都变？设成固定密码

随机密码在服务重启后会刷新，频繁被连时很烦。在「共享屏幕」页点右上角**三点菜单 → 设置固定密码**，按提示输入：密码要求（长度、字符类型）达标时提示会由警告色变为确认色，点确认即生效。之后无论重启多少次，都是这一个密码。

设置固定密码后注意保管——拿到密码的人就能连上这台手机，不要发给不信任的人。相关的连接问题见[连不上与卡顿排查.md](连不上与卡顿排查.md)。

## 五、后台保活：不设置就前功尽弃

手机系统会积极杀后台，RustDesk 服务被杀 = 对方永远连不上你。要长期挂着被控，把这三件事做完（各品牌路径不同，在手机管家里找）：

1. **省电策略改为「不限制 / 无限制」**，别让系统为省电冻结它；
2. **允许自启动**，开机后自动拉起服务；
3. **后台锁定（加锁/白名单）**，最近任务里别划掉它。

有用户反馈：连接总提示错误或对方连不上时，十有八九是服务在后台退了——回到共享屏幕页看一眼服务是不是还开着。被手机控电脑的另一半操作在[手机远程控制电脑教程.md](手机远程控制电脑教程.md)。
