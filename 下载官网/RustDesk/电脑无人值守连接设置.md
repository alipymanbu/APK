# 电脑无人值守连接设置

## 一、什么叫「无人值守」

默认状态下，被控电脑必须有人坐在跟前：软件得开着、密码临时变、屏幕不能休眠——你半夜在外面想取个文件，家里没人帮你点确认就白搭。**无人值守 = 这台电脑随时接受你的连接**，配齐三件事：固定密码、开机自启、不休眠。三件都在电脑端设置，手机端不用改任何东西。

## 二、第一件：设永久密码

打开电脑端 RustDesk，进 **设置 → 安全**（有的版本显示在右上角菜单里）：

1. 找到「永久密码」（或称固定密码）输入框，设一个只有你知道的密码；
2. 勾选**「仅允许以下密码连接」**——勾上后临时密码失效，别人拿到变化的临时密码也进不来，安全性靠这一步保证；
3. 保存。

没勾「仅允许以下密码连接」时，临时密码通道仍然开着，等于两把钥匙都能开门——建议勾上。手机端怎么用这个密码连接，在[手机远程控制电脑教程.md](手机远程控制电脑教程.md)里。

## 三、第二件：开机自启

电脑重启后 RustDesk 没起来，一切白设。两种开法：

- **软件内开关**：设置 → 通用（General）里打开「开机启动 / Start on boot」；
- **Windows 备用法**：按 `Win+R` 输入 `shell:startup` 回车，把 RustDesk 的快捷方式丢进这个文件夹——软件内开关失效时用它兜底。

装了 360、火绒一类软件的话，自启项可能被拦，弹窗时选择允许并加入白名单，否则下次开机又没了。

## 四、第三件：不让电脑睡

系统休眠 = RustDesk 断线。在 Windows 的电源设置里把**「睡眠/休眠」改为「从不」**（台式机顺便关掉休眠功能）；系统更新后的自动重启也可能把你踢下线，重要用途建议把活动时间或更新时段错开。

笔记本还要多看一项：**盖上盖子的动作**别设成休眠（用电池时尤其容易中招），改为「不采取任何操作」或接通电源时不睡眠。

## 五、验证配好了没有

三个开关都设完，做一次冷启动测试最有说服力：

1. 电脑端**重启一次**；
2. 重启后不碰电脑，看托盘里 RustDesk 是否自己跑起来了；
3. 用手机输入 ID + 你设的永久密码发起连接——能进，说明三件事都成了；进不去，按[连不上与卡顿排查.md](连不上与卡顿排查.md)逐项对照。

## 六、连不上时的额外变量

无人值守配好后仍失败，多半出在网络侧而不是设置侧：电脑在公司内网/严格防火墙后面时，直连可能不通，此时换自建服务器或走中继，见[自建ID与中继服务器教程.md](自建ID与中继服务器教程.md)。RustDesk 安装包在[RustDesk 安装文件资源（夸克网盘）](https://pan.quark.cn/s/729b4a3aecb7)，电脑端与手机端各装一份即可。
