# 连不上与卡顿排查

> 按症状查：一直提示连接错误、ID 不存在、Error 10054、画面卡、输入控制失灵。

## 一、先确认三件基础事

绝大多数连接问题出在这三样上，先各查一遍再往下看：

1. **对端服务在跑吗**——电脑端 RustDesk 是否开着、能看到 ID；手机端「共享屏幕」页服务是否已启动（被系统杀后台是最常见原因，处理办法见[手机被控端共享屏幕设置.md](手机被控端共享屏幕设置.md)第五节）；
2. **ID 抄对了吗**——9 位数字输错一位就找不到人；
3. **两端网络通吗**——最简单的判据是双方换各自网络（WiFi 换流量）再试一次，立刻能定位是不是某一边的网络问题。

## 二、按症状对照处理

| 症状 | 可能原因 | 怎么处理 |
| --- | --- | --- |
| 提示「ID 不存在」/找不到设备 | 对端没启动服务；ID 输错；对端被防火墙拦截 | 让对端打开 RustDesk 看 ID 是否显示；检查防火墙是否放行了 RustDesk |
| 一直「正在连接」然后报连接错误 | NAT 打洞失败，直连不通 | 在对方 ID 后加 `/r` 强制走中继，如 `123456789/r`（用户反馈的通用做法）；仍不行则换网络或自建服务器 |
| Error 10054（连接被对方重置） | 网络丢包、防火墙拦端口、对端服务异常、两端版本差距大 | 先重连一次；再查对端防火墙/杀毒软件是否拦了 RustDesk；最后把两端升到同一大版本 |
| 连上了但黑屏 / 无画面 | 对端屏幕未共享或被省电策略冻结 | 手机被控看「屏幕录制」权限是否授予、服务是否存活；电脑端看是否最小化到托盘后画面停止 |
| 画面卡顿、延迟高 | 带宽不足、走直连质量差 | 调低画质档位优先流畅；仍在卡则改走中继（`/r`）或自建服务器，中继稳定但多一跳延迟 |
| 手机能看画面但点不动 | 对端「输入控制」权限没开 | 手机端到系统设置开启无障碍里的 `RustDesk Input`，见[手机被控端共享屏幕设置.md](手机被控端共享屏幕设置.md) |
| 密码每次都变、连不上了 | 用的随机密码，对端重启过 | 让对端设固定密码：共享屏幕页三点菜单 → 设置固定密码 |
| 频繁掉线 | 后台被杀、电池优化冻结 | 省电策略改无限制、允许自启动、最近任务锁定；相关设置在各品牌手机管家内 |
| 自建服务器连不上 | 端口没放全（漏 UDP 21116 常见）、Key 填错 | 对照[自建ID与中继服务器教程.md](自建ID与中继服务器教程.md)第三节逐端口核对，Key 整段重贴 |

## 三、判断是「直连问题」还是「全线不通」

同一个 ID，先按原样连一次，再用 `/r` 强制中继连一次：

- **原样不通、`/r` 通** → 直连（打洞/端口）有问题，中继可用。想根治就自建服务器，见[自建ID与中继服务器教程.md](自建ID与中继服务器教程.md)；
- **两种都不通** → 对端服务没起来或网络整体不通，回到第一节重查；
- **两种都通但原样很卡** → 网络质量问题，降画质或改走中继。

## 四、版本相关的一条提醒

客户端版本差异过大时握手会失败或表现异常。网盘这份安卓包是 1.4.7（信息记录于 2026-09-22），电脑端若比它旧很多，优先把电脑端升到相近版本再试；下载渠道见[下载与安装教程.md](下载与安装教程.md)。系统要求也别忽略：安卓 5.1 以下跑不了，屏幕共享要安卓 6 以上、系统内部声音共享要安卓 10 以上。
