# KeePassDX 自动填充与指纹解锁设置

> 本篇讲怎么让 KeePassDX 在你登录 App 和网页时自动把账号密码填进去，以及怎么用指纹代替天天输主密码。这两个开关设置一次，之后每天都省事。

## 一、前提：先把库解锁机制理顺

自动填充要能用，前提是数据库处于解锁状态（或能瞬间解锁）。建议先把这两样配好：

- **指纹 / 面容解锁**：在应用内「设置」的安全相关选项里开启生物识别解锁，开启时需要先输入一次主密码完成绑定。之后每次打开库，按一下指纹即可，主密码只在极少数场合（比如换机重绑）才需要再输。
- **锁定策略**：设置里有「多久不用自动锁定库」的选项。手机是个人设备的话，设成几分钟到十几分钟比较平衡——太短了自动填充频繁要求重新验证，太长了别人拿你手机能直接翻库。

## 二、开启系统级自动填充

安卓从 8.0 起提供系统级的「自动填充服务」，把 KeePassDX 设为系统默认的填充来源，各 App 和浏览器在账号密码输入框就能弹出它的建议：

1. 打开手机**系统设置**，找「自动填充服务」这一项。不同品牌的入口位置不同：常见于「设置 → 密码与账户」「设置 → 更多设置 → 语言和输入法」或「设置 → 密码与安全」之下，找不到就在系统设置里直接搜「自动填充」。
2. 把自动填充服务从默认值（通常是「无」或厂商自家服务）切换成 **KeePassDX**。
3. 回到 KeePassDX 应用内，确认「设置」中自动填充相关的开关处于启用状态（应用内也有一个对应的总开关，两边都要开）。

之后随便打开一个登录界面，点用户名或密码输入框，系统会弹出 KeePassDX 的建议条；点它、验证指纹，选对应条目即完成填充。

**保存新密码**：你在某个 App 里手动输了一次新账号密码，系统通常会问「是否用 KeePassDX 保存」，确认后它会提示你把它存进某个条目。让这套流程跑起来，新密码就基本不用再手动录了。

## 三、备用手段：Magikeyboard 输入键盘

有些应用界面对自动填充不友好（弹不出建议），可以在系统输入法切换到 KeePassDX 自带的 **Magikeyboard**：解锁库之后，这个键盘上能直接翻你的条目，点哪个就把用户名或密码「打」进当前输入框，等于把复制粘贴合进了键盘里。它需要在系统输入法列表里启用一次（系统设置 → 输入法管理），平时不用时切回常用输入法即可。

## 四、指纹解锁与自动填充的组合用法

日常最顺手的流程是三者叠加：

1. 系统「自动填充服务」选 KeePassDX（一次性设置）。
2. 应用内开指纹快速解锁（一次性设置）。
3. 登录任何 App：点输入框 → 弹出建议 → 按指纹 → 填充完成。

整个过程主密码可以做到几个月不输一次，但**主密码别因此荒废**——换机、重装、生物识别失效时还是要靠它，务必按 [数据库创建与主密码设置.md](数据库创建与主密码设置.md) 里说的办法记牢。

## 五、弹不出来？先去排错篇

点输入框没有建议、或者弹出来的条目对不上当前网站，是这一套最常见的毛病，多数是 URL 字段写法、浏览器内核或系统权限的问题，对应解法集中在 [常见问题与排错.md](常见问题与排错.md) 的「自动填充」一节，按条排查即可。
