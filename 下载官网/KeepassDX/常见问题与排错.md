## 一、忘记主密码

直接说结论：**没有找回途径**。数据库加密就是靠这把钥匙，官方也不存你的任何副本。能试的只有两条路：

1. 把所有可能的主密码逐个试一遍（注意输入法大小写、全半角、首尾空格这些细节差异）。
2. 翻**旧备份**：如果库是在旧主密码时期备份过，旧备份可能还用旧密码。这也是为什么备份要定期做。

预防永远优于补救：主密码写在纸质笔记本上放在家里安全位置，是最朴素也最有效的方案，见 [数据库创建与主密码设置.md](数据库创建与主密码设置.md)。

## 二、数据库打不开

按顺序核对：

| 现象 | 先查什么 |
| --- | --- |
| 提示密码错误 | 输入法是否切了大小写 / 是否多打了空格；用的是不是当前那个库的主密码（多库的人常拿错库的密码） |
| 提示找不到密钥文件 | 建库时绑过 keyfile 的话，必须找到**当时那个**文件；文件内容变了也不行 |
| 文件根本选不中 / 打不开 | 确认文件扩展名是 `.kdbx` 或 `.kdb`；下载了一半的文件（大小明显偏小）会打不开，重新下载 |
| 用桌面客户端打不开手机新建的库 | 桌面客户端版本太旧不支持 KDBX 4，升级 KeePass / KeePassXC 到新版 |

## 三、自动填充不弹建议

这是使用中最常碰到的问题，按命中率从高到低排查：

1. **系统默认服务没指向它**：系统设置里搜「自动填充」，确认默认服务选的是 KeePassDX（系统升级后这个设置偶尔会被重置）。
2. **条目里的 URL 没填或填法不对**：填到根域名（`https://example.com`）命中率最高。有用户反馈过条目 URL 末尾多一个 `/`、或带了长长的小路径时匹配会失灵，去掉路径部分再试（官方仓库也有对应 issue 在跟进）。
3. **换一个输入框试**：有些登录页（尤其基于 Chromium 内核的浏览器里的两段式登录）点用户名框不弹、点密码框就弹，这是页面表单结构与系统填充服务的配合问题，换框点一下往往就出来了。
4. **用 Magikeyboard 兜底**：实在不弹就切到它自带的键盘手动选条目填充，见 [自动填充与指纹解锁.md](自动填充与指纹解锁.md) 第三节。
5. **应用被系统省电策略拦了**：把 KeePassDX 加入电池优化白名单（或允许后台运行），部分机型会因此杀掉填充服务。

## 四、换新手机怎么搬

1. 先把 .kdbx 文件（以及密钥文件，如果有）从旧手机复制出来：网盘、数据线连电脑、局域网传输都可以。
2. 新手机装好应用（安装方法见 [下载与安装教程.md](下载与安装教程.md)）。
3. 新手机上直接「打开数据库」，选中搬过来的文件，输入主密码。
4. 如果之前配了指纹解锁，需要在新机上重新绑定一次（输入主密码完成授权）。

数据库文件本身包含了所有条目、分组、历史和附件，搬完即等于一切照旧，不需要任何导入导出操作。

## 五、备份怎么做才算数

同步和备份是两回事：同步保证「各处一致」，备份保证「错了能回头」。够用的备份做法：

- **频率**：每次批量改动后手动复制一份；平时至少每月一份。
- **位置**：至少一份放在手机存储之外（电脑、U 盘、另一个网盘）。
- **保留代数**：留最近 2~3 份，不要永远只有一份——万一最新一份被误改误删，还有上一版可退。
- **主密码变更后**：立刻重新备份一次。

上面只列了骨架，完整方案（三份副本放哪、密钥文件怎么单独备、恢复演练怎么做、文件损坏了怎么救）见 [备份与恢复实践.md](备份与恢复实践.md)。

## 六、卸载、重装与版本更换

- **卸载应用不会删除数据库文件**，重装后打开原文件即可；但卸载前确认你**知道文件在哪**。
- 在 Free / Libre 两个包名之间换渠道（见 [下载与安装教程.md](下载与安装教程.md)），相当于「卸旧装新」，数据库文件不受影响。
- 从本页顶部给出的 **KeePassDX 安装文件资源（夸克网盘）** 拿到的安装包与商店 Free 版同包名，可直接互相覆盖升级，无需先卸载。

## 七、其他零碎问题

- **库里能存的不只是密码**：TOTP 验证码、附件、条目历史都在库文件里，字段说明见 [数据库创建与主密码设置.md](数据库创建与主密码设置.md)。
- **界面语言**：应用自带中文界面，在设置里切换即可；个别新功能词条翻译可能滞后，属正常现象。
- **想反馈问题**：官方仓库 [github.com/Kunzisoft/KeePassDX](https://github.com/Kunzisoft/KeePassDX) 的 Issues 区接受问题报告，提交前先搜一下关键词，大概率有人报过同类问题。
