# KeePassDX 跨设备同步数据库方法

> KeePassDX 的库是单个文件，同步的实质就是把这一个 .kdbx 文件在手机、电脑之间保持一致。本篇给三条常用路线（同步盘、WebDAV 直连、点对点同步），以及避免两边互相覆盖的注意事项。

## 一、同步的基本原理，决定了你该注意什么

KeePassDX 不内置任何云账号，你的库数据不会经过它的服务器；相应的代价是，「同步」这件事要靠文件层自己完成。整条原则就一句：

> 数据库是一个文件，任何能让这个文件在多台设备间保持最新文件系统的工具，都能拿来同步它。

由此推出两条纪律：

- **同一时间只有一台设备在改库**。文件级同步工具不知道你哪边改了内容，两台设备各存一份再同时上传，后传的会覆盖先传的。
- **密钥文件（如果有）不放进同步范围**。它和数据库一起被同步走，第二道验证就没了意义。

## 二、路线一：网盘同步盘（最省心，推荐）

如果你已经用坚果云、Nextcloud 这类带**电脑同步客户端**的网盘，最简单的做法：

1. 在电脑上把数据库文件放进网盘的同步文件夹（比如 `D:\坚果云同步\keepass\`）。
2. 手机装对应网盘的客户端，把同一个文件保持在手机上的同步目录里。
3. KeePassDX 里打开的始终是手机上那个本地文件，客户端负责双向搬运。

优点是任何版本的手机端都可用、不依赖应用自身功能；缺点是手机端「实时性」取决于客户端的同步频率，改完手机上的库，记得触发一次客户端同步（或等它自动上传）再去用电脑改。

## 三、路线二：WebDAV 直连

较新版本的 KeePassDX 在「打开数据库」时可以直接填一个网址（URI），对支持 WebDAV 的网盘可以不装客户端、填地址直连打开与保存。以国内常见的坚果云为例，参数如下（以官方帮助页为准）：

| 项目 | 值 |
| --- | --- |
| 服务器地址 | `https://dav.jianguoyun.com/dav/` |
| 完整文件地址 | 服务器地址 + 文件夹 + 具体的 .kdbx 文件名，如 `https://dav.jianguoyun.com/dav/keepass/vault.kdbx` |
| 用户名 | 坚果云注册邮箱 |
| 密码 | **应用密码**（不是登录密码） |

应用密码的获取：登录坚果云官网 → 右上角「账户信息」→「安全选项」→「添加应用密码」，生成一个专门给第三方应用用的密码。

坚果云官方帮助里还有两条明确提醒：地址指向的**文件夹不能用中文名**（先在网页端建好英文文件夹）；地址必须写到具体的 .kdbx 文件，不能只填到目录。

如果你的网盘不支持 WebDAV 或没有电脑客户端，退而求其次也可以「手动同步」：需要时在网盘里下载最新库到手机、改完再传回去。文件小，来回就是几十秒的事，但要养成先下载后改的习惯，防止把旧版本传上去覆盖新版本。

## 四、路线三：Syncthing / FolderSync 类工具

- **Syncthing**（安卓端可用其社区客户端）：设备之间点对点直接同步，不经第三方服务器，把手机与电脑各设一个共享文件夹，数据库放进去即可。
- **FolderSync 等定时同步应用**：按计划把指定本地文件夹与 WebDAV / 各家网盘之间搬运，适合「手机只做读取、电脑才是主编辑端」的用法。

这类工具的自由度高，配置也更多，适合愿意折腾的用户；配置时同样遵守第一节的两条纪律。

## 五、电脑端用什么打开同一个库

.kdbx 是 KeePass 家族的通用格式，官方明确兼容 KeePass、KeePassXC、KeeWeb 等主流桌面程序：

- **Windows / macOS / Linux**：推荐 [keepassxc.org](https://keepassxc.org) 的 KeePassXC，开源、界面现代，直接打开同一个 .kdbx。
- 老牌的 [keepass.info](https://keepass.info)（Windows）也可以，KDBX 4 格式需要 2.x 的较新版本。

也就是说手机上改的密码，电脑端打开同一文件就能看到，反过来也一样。主密码在哪个客户端都通用（密钥文件同理）。

## 六、改了主密码或换了结构之后

- **主密码**在所有设备上共用一个（它属于数据库文件本身），改了以后其他设备下次解锁输新密码即可。
- 如果改了数据库格式版本或加密参数，老版本桌面客户端打不开时，先把桌面客户端升级到新版，别反复试密码。

同步配好之后，把备份体系一并搭起来，完整做法见 [备份与恢复实践.md](备份与恢复实践.md)——同步不等于备份，网盘里的文件被误覆盖时，多一份本地快照才是真保险。
