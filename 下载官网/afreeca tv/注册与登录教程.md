## 一、先弄清：什么情况需要账号

- 只看直播：不登录也能进直播间看画面，多数频道没有观看门槛；
- 要互动：发弹幕聊天、关注主播、收开播通知、送星气球，都需要登录；
- 要开播：同样需要账号，开播入口见[观看直播与互动指南.md](观看直播与互动指南.md)。

## 二、海外用户注册（不需要韩国手机号）

注册入口在官网或 App 的「회원가입（注册会员）」页面，里面按用户类型区分注册通道；海外用户选「海外/外国人」那一项，用邮箱即可完成注册。以下填写项整理自公开教程，注册页以官方当时显示为准：

| 填写项 | 注意 |
| --- | --- |
| ID（用户名） | 输入后页面会提示是否已被占用，被占用就换一个；ID 定了之后基本不改 |
| 密码 / 确认密码 | 按页面的长度与字符要求设置 |
| 姓名 | 公开教程里写随意填写可通过，建议固定一个自己认得的 |
| 生日 | **务必填真实并记牢**：公开教程明确说找回密码时要靠它验证 |
| 性别 / 国籍 / 住址 | 按实际情况填 |
| 邮箱 | 填常用的，接收验证与找回邮件 |
| 验证码 | 页面图形验证 |

注册完成后直接用 ID + 密码登录，官网与 App 用同一套账号。

## 三、在手机 App 里登录

1. 打开 App，切到「마이（MY / 我的）」标签；
2. 点登录按钮，输入 ID 与密码；
3. 登录后回到直播间就能发弹幕、点关注了。

你手上这份 8.12.1 是旧版，界面以韩文为主，按钮位置对不上的话，对照[中文界面与语言设置.md](中文界面与语言设置.md)里的韩文词表找入口。

## 四、登录常见问题

- **提示 ID 或密码错误**：先确认没有多打空格或大小写搞混；忘记密码走登录页的找回流程，用注册时的生日与邮箱验证；
- **收不到验证邮件**：先翻垃圾箱；反复收不到就换一个邮箱重新注册，比干等省事；
- **登录成功但界面仍显示未登录**：旧版本偶见状态不同步，彻底杀掉 App 重新打开再试；
- **付费或活动功能提示「仅限韩国」**：海外账号的正常限制，不是账号异常；哪些功能受限见[海外使用限制与可用功能.md](海外使用限制与可用功能.md)。
