## 一、安装前先核对这些版本信息

你从网盘拿到的是 2026-09-27 采集的这一份安装包，事实如下（网上搜到的官方最新版往往比它新，别混着对号）：

| 项目 | 值 |
| --- | --- |
| 版本号 | 8.12.1 |
| 包名 | `kr.co.nowcom.mobile.afreeca` |
| 安装包大小 | 138.59M |
| MD5 | `AE0F44BD6A86E69D5B247D8D72474835` |
| 采集时间 | 2026-09-27 |

两点提醒：

- 8.12.1 是 2023 年发布的版本，那时平台还叫 AfreecaTV，所以装出来图标与界面都是 AfreecaTV 的样子，这是正常的；
- 平台更名 SOOP 之后，手机版继续沿用同一个包名 `kr.co.nowcom.mobile.afreeca` 更新。这份旧包与商店里的新版本是同一条产品线，更多背景见[平台介绍与SOOP改名说明.md](平台介绍与SOOP改名说明.md)。

## 二、从网盘把安装包拿到手机

1. 打开[afreeca tv 安装文件资源（夸克网盘）](https://pan.quark.cn/s/accdb810c439)的分享页，登录你的夸克账号（没有就先注册一个）；
2. 把分享里的文件**转存到自己的网盘**，再从自己的网盘下载到手机；
3. 下载得到约 138.59M 的 APK 文件，留足存储空间；
4. 想核对文件是否完整，在电脑上对一下 MD5：

```powershell
certutil -hashfile "下载路径\afreeca tv_v8.12.1.apk" MD5
```

算出的值与第一节表格里的 MD5 一致，就说明文件没坏。

## 三、允许安装与安装步骤

安卓默认不允许安装非应用商店来源的安装包，第一次装会卡在权限这一步：

1. 点开下载好的 APK，系统弹出「禁止安装未知应用」提示时，按提示进入设置，允许**来自此来源的应用**。不同品牌叫法略有差异：小米在「应用信息 → 权限管理」，华为在「设置 → 安全 → 更多安全设置 → 安装外部来源应用」，三星在「设置 → 安全性 → 安装未知应用」；
2. 回到安装页点**安装**，等进度走完；
3. 装完点**打开**。首次启动会依次请求网络、存储、通知等权限，按需允许即可；全部拒绝也能进主界面，但涉及保存图片、开播的功能会受限。

## 四、系统要求

- 采集记录标注的系统要求为 Android 5.2 以上；官方商店对近年的新版本标注 Android 8.1 及以上（以官方页面为准）；
- 这是**手机版**包名（`kr.co.nowcom.mobile.afreeca`）。安卓电视/电视盒子对应的是另一个包（`kr.co.afreecatv.atv`，商店里叫 SOOP for Android TV），拿这份手机包往电视上装，不一定能正常运行。
