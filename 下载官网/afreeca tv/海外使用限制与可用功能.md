## 一、海外账号能正常用的

观看与社交这类基础功能，不在官方的海外受限清单里：

- 看直播：App、手机网页、PC 网页都能看，没有地区门槛；
- VOD 回放：错过直播后到频道页回看，正常可用；
- 弹幕与聊天：登录后正常发言；
- 关注与开播通知：正常可用。

## 二、官方明确受限的功能

下表整理自 SOOP 官方帮助中心的海外受限说明（截至 2026-09，后续以官方帮助中心为准）：

| 功能 | 海外状态 |
| --- | --- |
| SOOP 商城（商品购买与赠送） | 不可用 |
| 比赛预测与 Gems | 仅限韩国用户 |
| 广告气球收集与横幅申请 | 仅限韩国用户 |
| 订阅 / Quick View / Quick View Plus 自动续费 | 仅限韩国用户 |
| 用户参与类功能 | 仅限韩国用户 |
| 新人主播扶持中心的奖励积分 | 不可用 |
| SOOP OGQ 表情购买 | 仅限韩国用户，且需韩国本地支付方式 |
| 活动页面 | 仅限韩国用户 |
| SOOP PICK（活动 / My Pick / Pick Up） | 仅限韩国用户 |
| Cineti 影视内容 | 因版权授权仅限韩国用户 |
| 台球新闻内容与页面 | 仅限韩国用户 |

简单说：**看和聊不受影响，被挡住的主要是「花钱」和「参与活动」两类**。遇到这些入口提示仅限韩国，不是你的账号出问题。

## 三、星气球：海外用户怎么买

星气球打赏不在官方列出的受限清单里，购买渠道上网页最稳（价格与规则详见[观看直播与互动指南.md](观看直播与互动指南.md)第四节）：

1. 手机浏览器登录移动版官网，先在左侧菜单登录账号；
2. 点右上角礼盒图标，进「充值星气球」；
3. 选档位支付。支付方式里韩国本地渠道居多，海外银行卡能否通过以支付页实际显示为准。

## 四、遇到问题去哪查

官方帮助中心有英文页面，海外受限清单、支付问题、观看故障都能查到：[SOOP Help Center（英文）](https://sooplive.helpshift.com/hc/en/3-soop/)。登录、找回密码这类账号问题，先过一遍[注册与登录教程.md](注册与登录教程.md)第四节，再查帮助中心。
