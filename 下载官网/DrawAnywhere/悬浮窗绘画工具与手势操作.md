## 一、先建立一个心智：画布和工具栏是两层东西

打开之后你看到的只有两样：一块**画布**（盖在别的应用上，你画画的地方）和一条**工具栏**（悬浮的按钮条，选工具、调颜色、隐藏画布都在这）。画布可以缩放平移、可以整块隐藏；工具栏可以拖走、会自己变淡。功能多的手势都作用在画布上，按钮操作都在工具栏上，先分清这两层，下面的对照表才看得顺。若你的版本界面与描述对不上，见[常见问题与排查.md](常见问题与排查.md)。

## 二、工具栏：布局与移动

| 操作 | 效果 |
| --- | --- |
| 长按并拖动工具栏 | 移动到任意位置（横竖布局都适用） |
| 空闲 3 秒 | 工具栏变透明（约 50%），不挡你画画 |
| 切换横向 / 竖向布局 | 工具栏贴合屏幕边缘的方向 |
| 把工具栏拖到屏幕底部 | 退出服务（关闭应用，见[触摸穿透与悬浮工具栏设置.md](触摸穿透与悬浮工具栏设置.md)第四节） |

工具栏变淡之后看着像不见了，其实点一下还在 —— 新手常在这里以为应用崩了。

## 三、画笔工具：能选什么、怎么调

工具栏里的工具按用途分四类：

- **画笔类**：自由手绘画笔、矩形、椭圆、激光笔。激光笔是那种指过去会消失的演示用笔，讲课指重点用。
- **橡皮**：像素橡皮（擦一块区域）、笔画橡皮（整条线一起删）。带手写笔的设备上，**笔上的按钮可以在画笔与笔画橡皮之间切换**，不用回工具栏点。
- **颜色**：HSV 色轮 + 18 个预设色 + 最近用过的颜色，也支持直接输十六进制色值。
- **粗细与不透明度**：两个滑块，拖动即时生效。

撤销 / 重做最多各 **50 步** —— 画错了连点撤销即可，不用担心一步画错就废掉整屏。

## 四、画布手势对照表

画布是无限画布，可以一直往外画。手势全部是多指触发，单指默认是画画：

| 手势 | 作用 |
| --- | --- |
| 双指捏合 | 缩放画布 |
| 双击 | 重置缩放到初始大小 |
| 三击 | 重置画布位置（回到屏幕中央） |
| 三指双击 | 切换「触摸穿透」开关 |
| 三指三击 | 隐藏画布 |

「触摸穿透」就是让触摸落到画布下面的应用里去，开着时你画的线还留着，但下面的应用能被点 —— 具体场景见[触摸穿透与悬浮工具栏设置.md](触摸穿透与悬浮工具栏设置.md)。

## 五、锁定：防止画着画着把画布挪走了

画布有**三档锁**，锁住时屏幕上有 HUD 指示当前档位：

1. **不锁** —— 缩放、平移都能用；
2. **只锁缩放** —— 手指在画布上还是会画，双指不会把画面放大；
3. **全锁** —— 缩放与平移都被禁止。

在窄屏幕上精细标注时，手一抖就把画布放大了，这时候切到「全锁」再画最省事。

## 六、手指与手写笔怎么分工

平板配笔的人会碰到一个问题：手掌或手指误触被当成一笔。工具栏里有**「手指绘画」开关**，关掉它就变成「只有笔能画、手指只做手势」。笔画橡皮靠笔上按钮切换，这条也归在这里记：笔的按键被占用时，先确认没开像素橡皮模式。

画的时候笔尖附近会有**悬停预览**（笔没落下就显示这一笔的位置和粗细），落笔前能确认效果；这项在支持悬停的设备上才有。
