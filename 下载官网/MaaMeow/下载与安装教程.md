MaaMeow 是《明日方舟》的安卓端助手，开源项目 MAA-Meow 的成品应用：把 MAA 的自动化逻辑直接跑在手机上，不需要电脑，也不需要模拟器。本篇只解决三件事：从哪拿到安装包、怎么装、装完怎么保持更新。

## 一、获取 MaaMeow 安装文件资源

官方发布渠道是 GitHub 仓库 [Aliothmoon/MAA-Meow](https://github.com/Aliothmoon/MAA-Meow) 的 [Releases 页面](https://github.com/Aliothmoon/MAA-Meow/releases/latest)，项目以 AGPL-3.0 协议开源，代码可查。它的定位在 MAA 官方文档里有明确交代 —— MAA 下载页专门标注「MAA Android 版已开放测试，请前往 MAA-Meow 了解更多资讯」，也就是同一套 MAA 自动化核心的桌面端与安卓端两个形态。

如果不方便访问 GitHub，可以从这里获取 MaaMeow 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/abdf9c4a0658](https://pan.quark.cn/s/abdf9c4a0658)。

两个渠道装的应该是同一个东西，区别只在网络环境。装之前可以核对一下安装包基本信息（见第四节）。

## 二、安装步骤

1. 从上面任一渠道把 `.apk` 文件下载到手机。
2. 在文件管理器里点开 APK；系统弹出「未知来源应用」提示时，按提示允许该来源安装（各品牌入口不同，一般在弹窗里直接给开关）。
3. 等待安装完成，点打开。首次启动会要求若干权限（通知、悬浮窗等），逐项允许即可。
4. 装完先别急着跑任务 —— MaaMeow 需要配合 Shizuku（或已 Root 的设备）才能工作，配置方法见[安卓手机运行环境准备.md](安卓手机运行环境准备.md)。

安装本身没有太多坑，多数「装完用不了」都是环境没配好，而不是安装失败。

## 三、版本与更新管理

MaaMeow 应用内自带更新管理：进入设置页的「更新管理」，可以分别检查 **App 本体** 和 **MAA 资源** 两类更新；下载源可在 GitHub 与 Mirror酱 之间切换。注意 Mirror酱 是需要付费订阅的第三方下载加速服务（与 MAA、MaaMeow 均无隶属关系），不想订阅就固定走 GitHub 源，只是速度看网络环境。

几点口径说明：

- 网盘里这份安装包为 **0.11.0 版**（打包核对时间为 2026-09-27）。官方仓库的版本号会持续往前走，你装到的可能比 0.11.0 新，也可能旧，以你实际下载时的页面显示为准。
- 版本号会变，但「设置 → 更新管理」这个入口是稳定的 —— 装完旧版后，优先用应用内更新追到最新，比反复下载 APK 省事。
- MAA 资源是识别与任务逻辑的依赖数据，App 本体没更新不代表资源不用更新；游戏版本变动后，如果任务频繁失败，先到更新管理里把两类更新都拉满。

## 五、支持哪些服务器

MaaMeow 项目简介标注「支持所有客户端」，对应到 MAA 的客户端类型清单就是：国服官服（Official）、B 服（Bilibili）、繁中服（txwy）、国际服英文/日文/韩文（YoStarEN / YoStarJP / YoStarKR）。

装好后第一件事是在「开始唤醒」设置里核对「客户端类型」与你在玩的服务器一致 —— 选错会导致整套界面识别错位（见[常见问题与故障排查.md](常见问题与故障排查.md)）。
