「一键长草」是日常挂机的主页面：左侧是一列任务模块，勾选了才会执行，点模块上的文字进入该任务的设置。先把操作逻辑弄清楚，再逐个配任务，配完的组合就是你的「每日托管清单」。

## 一、先弄懂页面逻辑

- **勾选才是选中**：模块文字可以点开设置，但设置完必须勾上模块才会执行。
- **编辑配置**：决定任务按什么顺序跑。任务从上到下依次执行，长按模块可拖动换序。
- **编辑任务**：可以重命名任务、新增任务模块，同一套配置可以存成多份（比如「周一到周五」「周末」各一份）。
- 改完设置**必须点「确定」**，否则任务模块点不开、设置也不生效。

## 二、开始唤醒（必勾）

开始唤醒是所有任务的前置：它负责「启动游戏 → 选择账号 → 开始游戏」，不勾它，后面的任务一个都跑不了。

三个实用细节：

1. **点「开始任务」后游戏自动重开是正常行为**，不用自己先打开明日方舟。
2. 提示无法启动游戏，多半是游戏本体有待更新 —— 先手动进游戏把更新装完。
3. **账号切换 / 服务器切换**绑定在「开始唤醒」上，每执行一次唤醒就切换一次；只有一个账号就保持默认。服务器务必和实际在玩的匹配（客户端类型选错是常见翻车点）。
4. **账号切换的填写规则**（MAA 官方口径）：只能切到**已在游戏里登录过**的账号，按登录名的片段匹配，且片段要在所有已登录账号里唯一 —— 官服账号形如 `123****4567`，填 `4567`、`123` 这类片段即可；B 服填昵称片段（如 `张三` 填 `张`）；繁中服账号是邮箱，建议填不含星号的明文片段（如 `01@gmail`）。

## 三、自动公招

设置项不多：支持自动使用加急许可，以及设定单次任务的最大招募次数。按自己囤了多少加急许可来勾，不想消耗就保持关闭。

## 四、基建换班

### 默认模式

默认的自动换班会：按设施自动计算最优进驻组合；识别经验书、赤金、源石碎片、芯片并安排对应干员；按「无人机用途」消耗无人机；把心情低于阈值的干员换进宿舍；会客室线索没集齐时不会往线索板上摆。前提是**游戏内的预设队列要自己先设好**，MaaMeow 按游戏内队列的轮换逻辑自动轮班。

### 自定义基建换班（进阶）

想精确控制每班次进驻谁，走自定义流程，三步：

1. **导出干员数据**：勾选「开始唤醒」点「开始任务」；结束后切到「小工具」页 →「干员识别」→ 再点「开始任务」；识别完点「导出文件」，选 JSON 格式保存（文件名以 `operbox` 开头，别把 `.json` 后缀删掉）。
2. **生成排班表**：在基建换班设置里选「自定义基建配置」，点「自定义基建排班制作器」进入[明日方舟一图流排班生成器](https://ark.yituliu.cn/tools/schedule)，点「添加数据源」→「导入 MAA JSON」，选中刚才那个文件；在布局规划里按自己的基建选好生产方式，等排班生成后点「导出 MAA 排班文件」。
3. **导入排班**：回 MaaMeow 的基建换班设置，点「点击选择自定义文件」，在系统文件选择器里找到刚导出的文件（文件名以「一图流」开头）勾选导入。

不同品牌手机的保存/选择界面略有差异（小米在「下载内容」/DLManager 文件夹里找，OPPO 系在「文件 → 下载」里找），文件名没改过就按前缀认。

**班次怎么换**：基建换班任务跑完会自动切到下一班；想按时间切班，配合下面的定时启动。

## 五、理智作战

配置面板项较多，按下面的规则来不容易出岔子：

| 设置项 | 怎么选 |
| --- | --- |
| 结束条件 | 「使用理智药」「指定次数」「指定材料掉落」可以同时勾，但**满足任意一条就会停** —— 日常建议只勾其中一个，避免提前收工 |
| 代理倍率 | `auto`：自动用关卡最大倍率并保证吃药后理智不溢出；「不切换」：不动游戏内的设置 |
| 剿灭 | 勾「自定义剿灭」可在当期剿灭与三个常驻（龙门外环、龙门市区、切尔诺贝利）里选一个 |
| 备用关卡 | 按**当天开放情况**选第一个开放的关卡，是个日程表功能，**不是**任务失败后的兜底 |
| 博朗台模式 | 等理智快溢出时才开打，适合想让自然回体被吃满的场景；无限吃药时它不生效 |

**找不到想刷的关卡**：把关卡选择设为「当前/上次」，然后自己在游戏里点到目标关卡 —— 停在右上角有关卡名和剩余理智、右下角有「代理指挥」「开始行动」的详情界面，再启动任务。

## 六、信用收支

勾选后自动访问好友拿信用点，再去信用交易所按清单购物。两个进阶点：

- **借助战赚信用**：会用助战干员通一次火蓝之心 OF-1（前提是你已解锁该关卡），每天多拿一笔信用，代价是消耗一次好友支援次数；关卡选择为「当前/上次」时这一项不执行。
- **购买优先级与黑名单**：开排序模式可调整优先购买的顺序，点 × 移除；黑名单里的物品不买 —— 除非信用溢出且你开了强制购买。

## 七、领取奖励与定时启动

「领取奖励」负责收每日/活动任务奖励、邮件等，勾上即可，没有多少可配的。

想让整套流程无人值守，用**定时任务**：设好触发时间与要跑的任务，到点自动启动。典型用法是「体力回满的时段跑理智作战 + 领奖励」一套带走；配合基建换班的时间切班也靠它。但有一条官方说明的限制要先知道：**锁屏状态下定时任务会跳过执行** —— 想锁屏挂机，得用 MacroDroid / Tasker 这类工具从外部触发，完整做法见[定时启动与外部自动化联动.md](定时启动与外部自动化联动.md)。

日常这一套配完，每天手动做的就只剩进游戏看看收成。想进一步挂自动肉鸽或抄作业推关，看[自动肉鸽与自动战斗设置.md](自动肉鸽与自动战斗设置.md)。
