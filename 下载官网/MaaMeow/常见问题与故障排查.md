官方 FAQ 的建议顺序是：任何问题先做三件事 —— **更新到最新版本、完整重启一次 MaaMeow、按正确方式收集日志**。大部分群里高频的问题，下面逐个给出对应处理。

## 一、提示截图失败，任务跑不起来

大概率是游戏没被唤醒：只勾了「开始唤醒」但没点「开始任务」，游戏实际没打开。把「开始唤醒」勾上，点「开始任务」，确认游戏进到主界面后再跑其他任务。

同时检查「客户端类型」选的是不是你实际在玩的服务器，选错了识别会整体错位。

## 二、游戏画面顶部多出一条遮挡横条

后台虚拟显示器上出现一条窗口标题栏式的横条，是系统开发者选项里的「桌面模式」把辅助显示屏当成了自由窗口。进系统「开发者选项」，找到**「在辅助显示屏上启用可自由调整的窗口」**，关掉即可。

## 三、各品牌开发者选项设置对照

厂商系统对后台触控和 ADB 有额外限制，按品牌对照处理（官方口径，截至 2026-09）：

| 品牌 | 要做的事 |
| --- | --- |
| 小米 / 红米（MIUI、HyperOS） | 1. 打开「USB 调试（安全设置）」（与「USB 调试」是两个独立开关，开启时需插可联网的电话卡）；2. 通知样式切换为「原生样式」（设置 → 通知与状态栏 → 通知样式设置）；3. 不要用「手机管家」的扫描功能，它会禁用开发者选项 |
| OPPO / 一加（ColorOS）、真我（realme UI） | 开发者选项中打开「禁止权限监控」；ColorOS 16.0.7 及以上该项改名为「禁用系统优化」且开关被隐藏，需把系统语言切到英文后找 "Disable system optimization" |
| 华为（EMUI） | 开发者选项中开启「"仅充电"模式下允许 ADB 调试」 |
| 魅族（Flyme） | 开发者选项中关闭「Flyme 支付保护」 |
| 通用 | 打开「停用 adb 授权超时功能」 |

## 四、Shizuku 相关异常

### 显示「已在后台启动」，但界面仍是「未运行」

几乎都是启动时**没等它运行完就切出了界面**。处理：把 Shizuku 从后台划掉（或卸载重装），重新配对后再点启动，启动过程中**停留在界面等出现「Service started」字样**，再切回 MaaMeow 授权。

### 启动日志报 TimeoutException

日志出现 `java.util.concurrent.TimeoutException: Failed to receive binder within 1 minute` 这类内容时，按官方给的顺序逐条尝试：

1. 在 B 站搜「shizuku 解决错误」相关视频，照着排查；
2. 换一个 Shizuku 版本再启动；
3. 把日志截图发给 AI 助手问一下具体原因；
4. 到交流群问群友（官方 [GitHub Issues](https://github.com/Aliothmoon/MAA-Meow/issues) 也可以提）。

另外提醒：非 Root 设备上 Shizuku **每次重启手机后都要重新启动一次**（不用重新配对），「昨天还能用今天不行」先看这里。

## 五、任务被系统杀掉，或锁屏后定时没跑

分两种情况：

**锁屏后定时任务没执行** —— 这是官方文档明确写出的行为：内置定时任务在锁屏状态下会跳过，不是 bug。想锁屏挂机，用 MacroDroid / Tasker 串「解锁 → 触发 → 锁屏」的流程，见[定时启动与外部自动化联动.md](定时启动与外部自动化联动.md)。

**任务跑到一半 MaaMeow 被系统清理** —— 安卓系统的后台管理机制所致，与 MaaMeow 无关，各家处理思路相同（以下入口名以华为 / 荣耀官方说明为例，其他品牌名称略有差异）：

1. 多任务界面下拉 MaaMeow 的应用卡片**加锁**，避免被一键清理；
2. 「应用启动管理」里关闭该应用的自动管理，在弹框中**允许后台活动**；
3. 「电池优化」里把它设为**不允许优化**；
4. 挂机期间**关闭省电模式 / 超级省电**；
5. 卸载第三方「管家 / 清理」类软件，它们会强制清理后台。

做完这些仍被清理的，检查是否开启了「智能省流量」这类限制后台联网的开关。

## 六、肉鸽或生息演算卡在某一界面不动

官方 FAQ 单独点名的情况：不要停在主界面就点开始任务，先手动把游戏导航到对应关卡 / 模式入口，再启动。肉鸽详细配置见[自动肉鸽与自动战斗设置.md](自动肉鸽与自动战斗设置.md)。

## 七、怎么提问才容易被解决

任务失败想求助（群、Issues 都一样），照官方推荐的四步准备材料：

1. 设置里打开**调试模式**（不开它日志信息太少，定位不了问题）；
2. 复现一遍问题并**录屏**；
3. **导出日志文件**；
4. 视频和日志一起发出来。

官方资料入口：文档站 [docs.maameow.com](https://docs.maameow.com/)、GitHub 仓库 [Aliothmoon/MAA-Meow](https://github.com/Aliothmoon/MAA-Meow)。应用本体或资源缺失时，从这里或[下载与安装教程.md](下载与安装教程.md)里的网盘入口重新获取安装文件资源即可。
