# 定时启动与外部自动化联动

> 本篇讲挂机调度的进阶做法：MaaMeow 内置定时任务的边界，以及用 MacroDroid / Tasker 通过外部命令触发指定任务配置。

MaaMeow 自带定时任务，到点会自动启动指定任务，但有一个官方文档明确写出的边界：**锁屏状态下定时任务会跳过执行**。想让「锁屏挂机」真正无人值守，官方给出的路径是用 MacroDroid、Tasker 这类自动化工具，从外部发命令触发 MaaMeow —— 本篇按官方集成文档把这个流程拆开讲。

## 一、内置定时任务的边界

在一键长草页配置好定时后，任务会按预设时间自动启动，日常场景够用。但如果你遇到「睡前锁了屏，第二天发现任务没跑」，这就是锁屏跳过机制，不是故障。

官方文档给出的典型解法，是把「解锁屏幕」也交给自动化工具，串成一条链：**定时触发 → 解锁屏幕 → 外部命令启动指定配置 → MaaMeow 执行任务 → Webhook 回调 → 锁定屏幕**。

## 二、外部触发的前提

三个条件缺一不可：

| 条件 | 说明 |
| --- | --- |
| 运行模式 | 必须是**后台模式**（在设置页的「运行模式」里切换）；前台模式不支持外部触发，触发了也会被拒绝 |
| 应用状态 | MaaMeow 在后台保持运行，Shizuku 服务处于已连接状态 |
| 执行权限 | `am` 命令需要 Root 权限；MacroDroid / Tasker 的 Shell 动作要勾选「Root 执行」 |

## 三、第一步：拿到 Profile ID

外部触发通过「任务配置（Profile）的 ID」指定要跑哪套配置：

1. 打开 MaaMeow，进入**后台任务**页。
2. 切换到**配置管理**模式（点 Profile 图标进入管理面板）。
3. 找到目标配置，点**编辑（铅笔）图标**。
4. 展开区底部显示该配置的 ID，点右侧复制图标复制完整 ID。

Profile ID 是一串固定的 UUID，形如 `3f4a1b2c-xxxx-xxxx-xxxx-xxxxxxxxxxxx`。

## 四、第二步：构造 am 命令

基本用法：

```bash
am start \
  -a com.aliothmoon.maameow.action.LAUNCH_PROFILE \
  -n com.aliothmoon.maameow/.MainActivity \
  --es extra_profile_id "你的Profile-ID"
```

要中断当前正在运行的任务、立即切换并启动时，加一个参数：

```bash
am start \
  -a com.aliothmoon.maameow.action.LAUNCH_PROFILE \
  -n com.aliothmoon.maameow/.MainActivity \
  --es extra_profile_id "你的Profile-ID" \
  --ez extra_force_start true
```

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `extra_profile_id` | 是 | 目标配置的 UUID |
| `extra_force_start` | 否 | `true` 表示强制中断当前任务后再启动，默认 `false` |

## 五、MacroDroid 配置示例

1. 新建宏，添加触发器（定时、NFC、来电等都可以）。
2. 动作选 **Shell 脚本**，命令填：

   ```bash
   am start -a com.aliothmoon.maameow.action.LAUNCH_PROFILE -n com.aliothmoon.maameow/.MainActivity --es extra_profile_id "你的Profile-ID"
   ```

3. 勾选 **Root 执行**。
4. 想让任务跑完自动锁屏，配合 MaaMeow 的 **Webhook** 功能：在 MaaMeow 设置里填好 Webhook 地址，MacroDroid 监听该回调后执行锁屏动作。

## 六、Tasker 配置示例

1. 新建任务，添加动作 → **代码** → **运行 Shell**。
2. 命令与上面相同（含 `extra_profile_id`）。
3. 勾选 **使用 Root**。

## 七、四个行为细节

- 触发后有 **30 秒倒计时**，期间可在 MaaMeow 内点「立即执行」跳过等待，或点「取消」中止。
- 当前不是后台模式时，触发会被拒绝并弹 Toast 提示，**不会**自动帮你切模式。
- 已有任务在跑且没设 `extra_force_start true` 时，新触发会被跳过，提示「系统繁忙」。
- 解锁屏幕后稍等 1~2 秒再执行 `am` 命令，给应用留出唤醒时间，否则可能触发失败。

锁屏挂机还牵涉系统对后台应用的清理，相关设置见[常见问题与故障排查.md](常见问题与故障排查.md)；日常任务的配置本身见[一键长草日常任务设置.md](一键长草日常任务设置.md)。
