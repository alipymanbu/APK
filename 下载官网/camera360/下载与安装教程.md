## 二、从网盘把安装文件拿到手

安装文件资源放在夸克网盘里，转存到自己网盘后再下载到手机：

1. 手机上打开上面的网盘链接（需要装夸克 App；用浏览器打开会引导你安装）。
2. 点「保存到网盘」，把资源转存到你自己网盘里的某个目录。
3. 转存完成后，进入该目录，选中里面的 APK 文件点「下载」。
4. 下载结束后，从系统通知点进去，或在夸克的下载列表里找到这个 APK 文件。

习惯用电脑操作的话：在电脑浏览器里完成转存，再回到手机 App 里下载安装。APK 是安卓专用的安装包格式，不能直接装在 Windows 电脑上；想在电脑上用，参考[常见问题解答.md](常见问题解答.md)里关于电脑使用的部分。

## 三、安装步骤

1. 点击 APK 文件，系统询问「是否允许安装」时点允许。
2. 第一次从浏览器或网盘装应用，安卓可能提示「禁止安装未知来源应用」，按提示允许该来源安装。不同品牌手机的入口叫法略有差别，一般在「设置」的安全或应用权限页面里。
3. 等待安装完成，桌面上出现 Camera360 图标。

安装包 124 MB，建议在 Wi-Fi 下下载；手机剩余存储空间最好留出 300 MB 以上——装好后应用本体还会再占一部分，使用中产生的照片缓存和素材下载也会持续增长。

## 四、第一次打开时的权限怎么给

| 权限 | 用途 | 不给会怎样 |
| --- | --- | --- |
| 相机 | 取景拍摄、实时滤镜 | 拍摄功能用不了，但还能导入相册照片修图 |
| 照片 / 媒体文件 | 读取相册照片来修图、保存成品 | 「编辑」选不了照片，拍的照片也存不进相册 |
| 位置 | 给照片记录拍摄地点 | 可以拒绝，不影响主要功能 |
| 通知 | 营销与活动提醒 | 可以拒绝，不影响使用 |

权限随时可以在系统「设置 → 应用管理 → Camera360」里改。只想把它当修图工具用的话，给照片/媒体权限、不给相机权限也完全可以。

## 五、装好之后要不要更新

用这一版还是升到商店最新版，差别主要在：

- 新版的界面样式、功能入口位置会有变化，商店页面标注的包体积也比 9.9.44 大；
- 收费项目的范围随版本调整过，更新前可以先看看[会员收费与免费功能区别.md](会员收费与免费功能区别.md)里的说明。

如果更新后不合手，想装回这一版：先卸载新版，再从 Camera360 安装文件资源（夸克网盘）按第二节重装即可。新旧版本包名相同，不能同时装在一台手机上。
