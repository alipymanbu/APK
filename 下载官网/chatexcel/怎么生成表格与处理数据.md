## 一、先建立正确预期

ChatExcel 的用法不是「你自己拉公式」，而是**把要求说给它听，它替你做完再给你结果**。适合两类人：Excel 不熟、不想背公式的人；以及手上表多、想批量处理的人。你在手机上装好、登录之后（见 [下载与安装教程.md](下载与安装教程.md)），从右上角菜单的「开始对话」进主界面。本篇讲手机版里最常用的那条路径。

## 二、主界面里有哪些现成功能

App 首页把高频操作做成了图标入口，你既可以直接点，也可以在对话框里用自然语言下达同类要求：

| 入口 | 你实际会用它做什么 |
| --- | --- |
| 数据清洗 | 删空白单元格、统一数据格式、批量增加单位符号 |
| 智能运算 | 加总、求平均、按条件算提成这类不写公式的计算 |
| 智能数据分析 | 按维度汇总、找异常值、生成分析结论 |
| 数据分类替换 | 批量把某一类值替换成另一类（如把「北区/北方」统一成「华北」） |
| 交叉对比 | 两张表对差异、两组数据横向比 |
| 数据可视化 | 一句话生成图表（柱状、折线、饼图等） |
| 智能判断 | 按条件给行打标（达标/不达标、优先级） |
| 自动纠错 | 找出表里写错、格式不一致的单元格 |
| 多表分析 | 多个 Sheet 或多个文件放一起看 |

## 三、一次完整的处理流程

1. **进对话**：打开 App → 右上角菜单 → 开始对话。
2. **给数据**：把要处理的 Excel 表传进去（上传入口在对话区域）。文件大小限制按版本不同，Pro 版官方口径是最多 3 个文件、单个 5M 以内，Max 版支持更多、单文件上限更高，具体以 [官网价格页](https://www.chatexcel.com/) 当时显示为准。
3. **说要求**：在输入框里用中文讲清你要什么，越具体越准 —— 见下一节的写法。
4. **等它跑**：AI 会在对话区实时显示处理进度，然后给出结果表格。
5. **拿结果**：直接在线查看，确认没问题就下载；要接着分析就继续追加指令（比如「按月份汇总」「出一张趋势图」）。

## 四、指令怎么写才不出错

写指令的核心是四要素：**对象（哪列哪行）、动作（做什么）、条件（按什么规则）、输出（要表格还是图表）**。

- 差的写法：「帮我处理一下这个表」—— 它不知道你要什么。
- 好的写法：「把 A 列和 B 列相加，结果放在 C 列」「按‘地区’分组，算每个地区的销售总和，用柱状图展示」「把所有日期统一成 2026-09-23 这种格式」。

几个实用技巧：

- **一次说一件事**。多个要求挤在一句里，容易漏掉其中一条 —— 分成多轮对话逐条下。
- **带上列名**。列名是它定位数据的主要依据，写「销售额列」比写「右边那列」稳。
- **让它复述口径**。算完可以让它用一句话说明刚才按什么规则算的，方便你核对。
- **结果不对就补条件**，比如「只统计 2026 年的数据」「排除测试订单」—— 不用推倒重来。

## 五、生成图表

数据算完后追加一句「用柱状图展示」即可出图。官方公布的图表类型覆盖柱状、条形、折线、饼图、面积、散点、气泡，以及关系图、热力图、瀑布图、玫瑰图等，还有可切换样式的交互式图表（官方口径为几十种、不同页面写法不一，以产品内实际可选为准）。出图后你可以换类型、改标题，最终结果可以下载带走。

## 六、结果怎么用

处理结果可以在线查看后下载为 Excel 文件。拿到文件后建议抽查几行，确认计算口径和你想的一致再拿去用 —— AI 理解的条件偶尔和你脑子里的规则有出入，多轮对话里补一句条件就能修正。若你要处理的是 PDF 或图片里的表格，先走格式转换（见 [PDF图片转Excel的方法.md](PDF图片转Excel的方法.md)），转成 Excel 后再来本篇的流程。

登录不顺利、文件传不上去了，看 [常见问题与解决方法.md](常见问题与解决方法.md)。
