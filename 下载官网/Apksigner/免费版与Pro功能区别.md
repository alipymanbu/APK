## 一、核心结论

签名、验证、密钥库导入导出这些主力功能，免费版全部可用；Pro 补的是两件事：在手机上直接生成密钥库、换主题。只想给一两个包签名的人，用免费版就够了。

## 二、功能对照

| 功能 | 免费版 | Pro |
| --- | --- | --- |
| 签名 APK | 有 | 有 |
| 验证 apk / jar / zip | 有 | 有 |
| 密钥库导入 / 导出 | 有 | 有 |
| 在手机上新建密钥库 | 无 | 有 |
| 主题 | 单一 | 可换 |
| 广告 | 有（商店评价中常见此反馈） | 无 |

升级以内购形式提供，价格与购买方式以商店页当时显示为准。

## 三、什么情况下才需要 Pro

- 你没有现成密钥库，也不想碰电脑命令行，想直接在手机上生成一份——这是 Pro 最实际的用途。
- 免费版的广告影响操作，想去掉。

没有这两类需求，免费版就是完整的工具。想免费用上「生成密钥库」，也可以在电脑上用 JDK 的 keytool 生成再传回手机导入，具体命令见 [密钥库管理与备份.md](密钥库管理与备份.md) 第三节。

## 四、购买有效期的历史口径

根据应用历年的官方更新日志：完整功能的内购曾带有效期，最初 30 天，6.8.1 版延到 6 个月，6.9.0 版延到 1 年。现行政策以商店页与开发者说明为准——打算购买的话，先看一眼当时的购买页说明再付。

## 五、另一个已知事项：地区可用性

开发者在应用说明里明确写过：这个应用在部分国家/地区不可用。如果你在商店里搜不到它，属于这种情况，用 [下载与安装教程.md](下载与安装教程.md) 里的网盘途径获取安装文件即可，功能不受影响。
