## 一、先确认你要装的是这个工具

apk-signer 是一个装在安卓手机 / 平板上的图形界面工具，用途是给 APK 安装包做签名、验证签名，开发者是 Tra-On（早期版本署名 Hai Bison）。你在手机上选中一个 APK 就能直接操作，不需要连电脑。

它容易和另一个同名工具搞混，先分清：

| 名称 | 它是什么 | 适合谁 |
| --- | --- | --- |
| apk-signer（本篇要装的） | 安卓手机 App，包名 `com.haibison.apksigner`，图形界面 | 在手机上处理一两个安装包 |
| apksigner 命令行工具 | Android SDK Build Tools 自带的电脑端命令行工具，见 [developer.android.com](https://developer.android.com/tools/apksigner) | 批量、自动化的打包发布流程 |

两者功能类似，但一个在手机上点界面、一个在电脑上敲命令，别下错了。

## 三、从哪获取

两种途径：

1. **Google Play 商店**：官方上架页在 [play.google.com](https://play.google.com/store/apps/details?id=com.haibison.apksigner)。开发者自己在应用说明里写过：这个应用在部分国家/地区搜不到，如果你所在地区正好搜不到，走下面第二种途径。
2. **Apksigner 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/65463cf7ecf4](https://pan.quark.cn/s/65463cf7ecf4)。转存后把 APK 下载到手机，拿到的是上面表格里那份 7.3.10 版的包。

无论哪种途径，安装前建议核对文件 MD5：电脑上用 `certutil -hashfile 文件名 MD5`，或用手机文件管理器属性页查看，与第二节表格一致说明包完整、没被改动。MD5 比对与签名验证各能发现什么，展开在 [验证安装包有没有被改过.md](验证安装包有没有被改过.md)。

## 四、安装步骤

1. 把 APK 文件放进手机存储（网盘途径下载转存后即在本机）。
2. 在文件管理器里点这个 APK。系统会提示「未知来源应用」，选允许——具体入口各品牌不同，见下一节。
3. 回到文件管理器再点一次 APK，点安装，等待完成。
4. 装完打开，首次使用会请求存储权限，允许它，否则后面选不到 APK 文件。

## 五、「安装未知应用」权限各品牌怎么开

| 品牌 | 大致路径 |
| --- | --- |
| 原生 / Pixel | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |
| 小米 / 红米 | 设置 → 隐私保护 → 特殊权限 → 安装未知应用（安装弹窗里也会给直通入口） |
| OPPO / 一加 / realme | 设置 → 安全 → 安装未知应用 |
| vivo | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 华为 / 荣耀 | 安装弹窗会引导到「外部来源应用」开关；鸿蒙系统还需在 设置 → 系统和更新 里关闭「纯净模式」 |

不同系统版本菜单名称略有出入，认「安装未知应用 / 外部来源」这个关键词即可，权限只授予文件管理器这一类应用就够，不必全局放开。

## 六、装不上的常见原因

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「应用未安装」 | 手机上已装过同包名的旧版本且签名不同 | 先卸载旧版再装 |
| 提示装的是旧版本 | 设备上已装的版本号比要装的包更高 | 卸载已装版本再装，或换更新的包 |
| 弹「安全风险 / 未备案 / 未经安全检测」 | 国产系统的安装前提示 | 点「继续安装 / 仍然安装」即可 |
| Play 保护机制提示有风险 | Google Play Protect 对非商店应用的例行扫描 | 选继续安装或先发送扫描，确认来源可信再装 |
| 鸿蒙设备点了没反应 | 「纯净模式」在拦截 | 设置 → 系统和更新 → 关闭纯净模式 |
| 安装到一半失败 | 存储空间不够（安装过程一般要占包体积 1.5~2 倍空间） | 清出足够空间再试 |
| 下载后的包点不开 | 传输中文件损坏 | 重新下载并核对 MD5 |
| 系统直接不给装 | 系统版本低于安卓 7.0 | 确认系统版本 |

厂商的安全提示弹窗五花八门，共同点是都给了「继续 / 仍然安装」的出口；拦下不让点的（如纯净模式）才需要去设置里关开关。装好之后就可以开工了，签名和验证的具体操作见 [签名与验证使用教程.md](签名与验证使用教程.md)。
