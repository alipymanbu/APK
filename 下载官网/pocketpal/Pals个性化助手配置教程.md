## 一、Pals 是什么

Pals 是把「用哪个模型 + 一套系统提示词 + 一点人格设定」打包成的预设。你建好几个 Pal，聊天时一键切换，等于换了个专门用途的助手——写作的、查资料的、闲聊的各一个，不用每次重新交代要求。

Pals 从 v1.8.0 加入（官方更新日志），你手上 1.13.3 的版本里有完整入口。系统提示词对回答质量影响很大：同一个模型，提示词写清规则和不写规则，出来的答案完全是两个水平——这是本篇的重点。

## 二、建一个 Assistant（通用助手）Pal

1. 菜单 ☰ → **Pals**（部分版本里在聊天页输入框上方的箭头图标里也能进）；
2. 新建，类型选 **Assistant**；
3. **绑定默认模型**：给这个 Pal 指定一个已下载的模型（没下载先去 [模型下载与加载教程.md](模型下载与加载教程.md)）；
4. **写系统提示词**：手写即可，应用也提供让 AI 帮你生成的入口（没有该按钮属版本差异，以应用内实际为准）；
5. 保存。聊天页切换 Pal 的入口在**输入框上方的箭头 → Pals 标签**，点选即生效。

**Roleplay 类型**多几个字段：地点、AI 扮演的角色、情境参数——想做角色扮演或固定场景对话时用它；日常任务用 Assistant 就够。

## 三、系统提示词怎么写

结构照这三段来，比一句「你是专家」有效得多：

1. **身份**：你是什么、服务谁；
2. **硬规则**：必须做什么、禁止做什么（语言、长度、格式）；
3. **输出格式**：分点还是段落、要不要示例。

一个可用的模板（按需改）：

```text
你是一名中文写作助手。
规则：
1. 始终用简体中文回答；
2. 回答分点，每点不超过两行；
3. 不确定的信息明确说「不确定」，不要编造；
4. 修改文本时先给结论，再给修改稿。
```

实测经验（来自使用者公开分享）：写好规则后如果对某条回答不满意，**改完提示词重新生成一次**对比——多数情况下答案会明显更贴合要求；同一问题也可以直接换一个模型重答。配合 [设置中文界面方法.md](设置中文界面方法.md) 里的「要求模型说中文」，中文场景基本够用。

## 四、几条实用配置

| 想要什么 | 怎么配 |
| --- | --- |
| 固定用小模型省内存 | Pal 里绑定最小那个模型，切 Pal 时不会去载大模型 |
| 中文回答稳定 | 系统提示词里第 1 条写死「始终用简体中文」 |
| 语气区分 | 写作 Pal 正式、闲聊 Pal 轻松，切换即换语气 |
| 答得更准 | 每个 Pal 只干一类事，别用一个 Pal 问遍天下 |

**版本差异提醒**：官方较新版本在 Pals 上加了社区市场（PalsHub）、联网搜索、工具调用等能力，你手上的 1.13.3 不一定有——以应用内实际显示为准，没有这些入口不影响本篇的用法。
