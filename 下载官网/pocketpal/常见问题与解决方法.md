## 一、模型下载失败或一直卡住

按命中率排：

1. **存储空间不够**：模型 1~4GB 很常见，先看手机剩余空间，比模型 Size 大出至少 1GB 再下；
2. **网络到 Hugging Face 不通**：内置列表与 HF 搜索的下载都指向 Hugging Face，有用户反馈部分地区直连会卡进度条或直接失败——换网络重试；反复失败就改走**本地导入**：在电脑/别处下好 `.gguf` 传进手机，用 Models 页 + 从本地存储添加，绕开应用内下载（步骤见 [模型下载与加载教程.md](模型下载与加载教程.md) 第四节）；
3. **权限模型没配 token**：下载 gated 模型前要在 Settings → Set Token 里贴上 Hugging Face access token；
4. **中断后续传**：下载失败不删进度，回到列表重新点 Download 会继续，不用从头来。

## 二、能打字但发不出去，提示 Model not loaded

不是坏了，是模型没在内存里：

1. 回 **Models** 页，看目标模型是不是显示已下载但没 Load —— 点 **Load**，大模型转圈几秒到十几秒属正常；
2. 如果 Load 完马上又被卸掉，多半是内存被别的应用占着：关掉后台大型应用再试；
3. 确认 **自动加载/卸载** 开关（Models 页）处于开启，它会在内存紧张时自动腾地方。

## 三、点 Load 就闪退，或聊一半闪退

**模型超出了手机能给的内存**，这是头号原因。关键认知：**模型文件体积 ≈ 运行内存下限**，还要额外留上下文缓存与系统开销——2GB 的文件想要的空闲内存超过 2GB。

处理顺序：

1. 关掉后台应用，保证可用内存最大化，重试 Load；
2. 还是闪退 = 换小一档的模型：降参数量或降量化档位，对照表见 [手机本地模型选择指南.md](手机本地模型选择指南.md)；
3. 保持自动加载/卸载开启（默认开），能缓解聊一半被挤出去的情况；
4. 反复闪退时顺手确认安装包完整性——按 [下载与安装教程.md](下载与安装教程.md) 表格里的 MD5 核对，不一致就重装。

## 四、能回答，但一个字一个字往外蹦

模型「跑得动但拖不动」的表现——对这台手机来说太大了。处理：

1. 换更小参数或更低量化档位的模型（最有效）；
2. 把上下文长度（Context Size）调低，内存和速度都会好转；
3. 长对话越聊越慢属正常，模型要记住前面全部内容——开个新会话立刻会快。

想知道自己手机到底能跑多快，用应用内置的 **Benchmark** 页测：它输出每秒生成 token 数与内存占用，跑分可选择性上传社区榜单（**不上传也完全不影响使用**——这是应用里少数会离开设备的数据，且仅在你主动点分享时才发）。

## 五、安装相关

| 症状 | 处理 |
| --- | --- |
| 安装时提示禁止安装未知来源 | 设置 → 安全/安装未知应用 里放行该来源，返回继续装，见 [下载与安装教程.md](下载与安装教程.md) |
| 提示解析包错误 / 安装包损坏 | 按 MD5 核对下载的 APK，不一致重新下载 |
| 装完打开是英文 | 正常，按 [设置中文界面方法.md](设置中文界面方法.md) 切中文 |
| 应用能开、但里面啥都没有 | 正常——应用不自带模型，先去下模型，见 [模型下载与加载教程.md](模型下载与加载教程.md) |

## 六、关于隐私的确认口径

你可能会反复确认的一件事：**聊天确实不联网**——模型在手机本地运算，回答不经过任何服务器，飞行模式下照样能聊。官方 README 标注的例外只有两个，且都要你主动操作才会发生：Benchmark 结果（你点分享才上传）、应用内反馈（你主动提交才算）。对话内容不在这两项里。
