## 一、先弄清楚：应用和模型是两回事

PocketPal AI 本身不带 AI——它是个运行环境，真正干活的是你下载到手机里的**模型文件**（GGUF 格式，常见体积 1~4GB）。所以流程固定是：**下载模型 → Load 加载 → 才能聊天**，少了任何一步，聊天页都会提示模型没加载。

下载前先给手机腾出空间：模型文件 + 运行时内存都得留够，按内存挑模型的对照表见 [手机本地模型选择指南.md](手机本地模型选择指南.md)。

## 二、用内置模型列表下载（最省事）

1. 打开应用，点左上角菜单 ☰ → **Models**；
2. 列表里预置了常见小模型（Gemma、Qwen、Phi、Llama、Danube 等系列），每一项会显示体积与参数量；
3. 看准 Size / Parameters 两栏，点 **Download**，界面会显示进度；
4. 下载完成，该项旁边出现 **Load** 按钮，点它把模型载入内存；
5. 切到 **Chat** 页开聊。聊天输入框左侧的箭头图标也能直接调出加载入口，不必退回菜单。

## 三、从 Hugging Face 添加（内置列表没有的）

内置列表没有你想要的模型时，用添加功能搜索：

1. Models 页点右下角 **+**，选 **Add from Hugging Face**；
2. 搜模型名（只能搜到 **GGUF 格式**的文件，其它格式应用不认），同一模型会有多个「量化档位」——数字越低文件越小、质量损失越多，按 [手机本地模型选择指南.md](手机本地模型选择指南.md) 挑；
3. 点下载，或先收藏（bookmark）以后再下；
4. **需要权限的模型（gated model）要先配 token**：去 Hugging Face 账号里生成 access token，然后在应用 Settings → **Set Token** 里粘贴保存，不配就下载不动。

有用户反馈：Hugging Face 在部分地区直连不稳，表现为进度卡住或失败。遇到这种情况可以换「本地导入」（下一节），效果一样。

## 四、本地导入（网络下不动时的替代路径）

已经把 `.gguf` 文件拿到手的（电脑上下载好再传手机、或从网盘转存），可以直接导入：

1. 把 `.gguf` 文件放到手机存储里（任意你能找到的目录，如 Download）；
2. Models 页 + → 选择从本地存储添加（Add from local storage）；
3. 选中该文件，它会出现在你的模型列表里，照常 Load。

这一步之后就完全离线了——模型在本地，之后聊天不再需要任何网络。

## 五、加载状态怎么确认

- **Load 按钮转圈数秒属正常**：大模型载入内存本来就要等一会儿，别连点；
- 加载成功后回到 Chat 页直接发消息即可；如果发消息时提示「Model not loaded」，说明没加载成功或被自动卸载了，回 Models 页重新点 Load；
- Models 页有个**自动加载/卸载（auto load/unload）**开关，默认启用——内存不够时应用会自动把模型卸出去、空闲时再加载回来。它能明显缓解「切个应用回来就闪退」的问题，建议保持开启。

下载失败、加载失败、生成慢的排查，见 [常见问题与解决方法.md](常见问题与解决方法.md)。
