## 一、记录存在哪、会不会传出去

全部存在**你手机本地**，不上传服务器、不需要账号——这也是它和云端聊天工具最大的区别（隐私口径详见 [常见问题与解决方法.md](常见问题与解决方法.md) 第六节）。反过来意味着：**没有云端找回这条路**，换手机、重装应用之前，重要的记录要先导出备份。

## 二、单条消息的四个操作

生成中的回答会实时显示每秒 token 数，生成期间应用会保持屏幕常亮，切走才熄屏。拿到回答后：

| 操作 | 怎么做 |
| --- | --- |
| 复制整条回答 | 点回答旁的复制图标 |
| 只复制一段 | 长按那一段，选复制 |
| 改自己的话重新生成 | 长按你发的消息 → 编辑 → AI 会从你改完的地方重新作答 |
| 这条答得不好，重来 | 点 retry 重答，可以选择换一个模型再试 |

**没发完的草稿不会丢**：从一个会话切到另一个再切回来，输入框里没发出去的内容还在（v1.13.1 起加入的草稿自动保存，你手上的 1.13.3 有）。

## 三、会话列表：搜索、删除、导出

在会话列表页管理整段对话：

1. **搜索**：列表顶部可按内容找回历史会话（官方当前版本说明标注历史记录带搜索；你的版本若没有搜索入口，属版本差异，以应用内为准）；
2. **批量删除**：长按进入多选，可一次删掉多个会话——清理占地方或不想留的记录都走这里（批量删除与导出是较新版本加入的聊天管理能力，入口以应用内为准）；
3. **导出**：会话右上角**三点菜单 → Export/Import → Export all sessions** 可以把会话导出成文件、也能再导回来（第三方教程给出的入口路径，你的版本里若叫法不同，以应用内为准）。

导出的文件是纯文本性质的记录，换机前导一份、放在网盘或电脑里，新手机装好应用再导回来，就能接着聊。

## 四、和 Pals、模型的边界

记录跟的是**会话**，模型和 Pal 设定跟的是**当前配置**——换模型、换 Pal 不会动已有记录；反过来，删记录也不会影响模型与 Pal。给不同用途建不同 Pal 的用法见 [Pals个性化助手配置教程.md](Pals个性化助手配置教程.md)。
