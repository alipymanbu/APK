## 一、游客模式与注册账号的差别

1.3 版把这两者的差别直接写在了注册弹窗里：游客试用仅支持基础流式聊天，注册后即可使用模型、设置、模组和上传功能。落到具体功能上：

| 功能 | 游客 | 注册后 |
| --- | --- | --- |
| 基础流式聊天 | 可以 | 可以 |
| 切换/自定义模型 | 不可以 | 可以 |
| 对话与界面设置 | 不可以 | 可以 |
| 模组、世界书 | 不可以 | 可以 |
| 上传（发图片等） | 不可以 | 可以 |

只想先随便聊两句试试水，游客够用；想认真玩剧情、调设定，注册基本是绕不开的一步。

## 二、注册与登录步骤

1. 打开 RiliAI，从左侧功能栏拉到最底部，点「游客」；
2. 已有账号就直接输入账号密码登录；
3. 第一次用就点「立即注册」，按提示填完资料即可；
4. 登录后回到首页，角色与故事内容会陆续解锁。

## 三、邮箱验证与积分

有第三方渠道的介绍提到：完成邮箱验证后可免费领取一笔积分（口径为 10000 积分）。具体数额以你应用内「奖励」页当时显示的为准。

## 四、积分的三种类型与获取途径

应用内的积分分为三类，公开渠道收录的官方问答给出了各自的来源：

| 积分类型 | 来源 |
| --- | --- |
| 免费积分 | 系统赠送 |
| 普通积分 | 通过充值获取 |
| 奖励积分 | 通过邀请好友或创作内容获取 |

对应的获取途径：

| 途径 | 说明 |
| --- | --- |
| 充值 | 左侧栏「充值」入口；应用内含付费项目，充不充、充多少自己决定 |
| 任务 | 完成应用内任务领取 |
| 邀请好友 | 通过邀请链接拉新获得奖励积分 |
| 创作内容 | 通过创作获取奖励积分 |

左侧栏的「奖励」「充值」两个入口，分别对应领积分和买积分。三类积分混在一起扣，奖励积分的计算只认成功扣取的正常积分——具体规则与两个常见疑问（玩自己的卡片拿不到奖励、奖励为什么是 0）单独成篇，见 [积分类型与奖励规则.md](积分类型与奖励规则.md)。

## 五、消费前的两点提醒

- 这类应用的模式是免费下载、内含付费项目：先在游客和免费积分阶段确认自己用得上，再考虑充值；
- 注册邮箱选一个自己长期使用的，后续验证、找回都靠它。

充值与否不影响你先把 [角色对话入门.md](角色对话入门.md) 里的基础玩法跑通。
