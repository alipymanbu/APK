## 一、安装前先核对这几件事

RiliAI（部分渠道写作 Rili AI，也有「日历AI聊天」的叫法）是一款 AI 角色扮演聊天应用。公开渠道基本只提供安卓版，个别渠道标注过 iOS 信息但没有实际下载入口，以官方渠道为准。官方站点是 [rilichat.com](https://rilichat.com/)，访问时会先经过一道人机验证。下面是这份安装包的基本信息，先核对再装：

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.3 |
| 安装包大小 | 176.56 MB |
| 包名 | `com.rili.rilichat` |
| MD5 | `856C551EC02E4D7DB4BC907DAFA41BBC` |
| 语言 | 简体中文 |
| 系统要求 | Android（不同渠道标注 4.3 或 5.2 以上，稳妥起见建议安卓 5.2 及以上机型） |
| 资费 | 应用内含付费项目 |

版本号、包名、大小与 MD5 都以上面这份安装包为准——网上能搜到更高版本的介绍（后来还发过 1.4、1.6），但那是另外的包，别拿网上的数字对这份文件。

## 二、拿到安装包

1. 打开上面的 **RiliAI 安装文件资源（夸克网盘）** 链接；
2. 按页面提示把文件转存到自己的夸克网盘；
3. 在夸克网盘 App 里把安装包下载到手机存储。

分享里是一个文件夹，内含文件名形如 `RiliAI_v1.3.apk` 的安装包和一个说明文本，以下载到的 APK 文件为准。

## 三、安装步骤

1. 在手机文件管理里找到刚下载的 APK，点开安装；
2. 系统若提示「禁止安装未知来源应用」，按弹窗指引允许本次安装即可，不同品牌的设置入口名称略有差异；
3. 等待安装完成。安装包 176 MB，解包安装后占用更大，手机存储建议预留 2 GB 以上空间；
4. 装完打开，首次启动会加载资源，等进度走完即可。

## 四、第一次打开会看到什么

- 左侧是导航栏：首页、工作室、历史记录、收藏、生图、奖励、日志、充值、信息中心；
- 导航栏最底部是账号入口，默认显示「游客」；
- 首页是角色卡片流，可以按题材标签筛选，也可以看每日/每周/每月排行；
- 以游客身份直接点进一个角色就能试聊，但会弹提示：游客试用仅支持基础流式聊天，注册后即可使用模型、设置、模组和上传功能。

先游客试聊、再注册解锁，是多数人的顺序。注册步骤和积分的事见 [注册登录与积分获取.md](注册登录与积分获取.md)。

## 五、装不上时的排查

| 现象 | 常见原因与处理 |
| --- | --- |
| 提示「解析包失败」 | 多为下载不完整或传输中损坏——重新下载一遍，核对 MD5 是否为 `856C551EC02E4D7DB4BC907DAFA41BBC` |
| 空间不足 | 清出至少 2 GB 空间再装 |
| 安装到一半卡住 | 关掉后台大应用再试；个别安全软件会拦截安装，允许本次安装即可 |
| 装完打开闪退 | 先确认系统版本达到要求，重启手机再试一次；仍闪退可到 [常见问题解答.md](常见问题解答.md) 找同类情况 |
