# Beoplay 常见问题与故障排查

## 一、应用搜不到设备

按出现概率从高到低逐条排查：

1. **蓝牙权限没给全**：安卓 12 及以上检查「附近的设备」权限；安卓 6~11 很多机型蓝牙扫描还依赖定位权限，把定位（精确位置）也允许掉；
2. **设备没进配对模式**：应用添加产品的前提是设备处于配对状态或已完成蓝牙配对，重新长按蓝牙键试一次；
3. **设备连着别的手机**：B&O 设备同一时间通常只保持一路主动连接，先把另一台手机的蓝牙断开或关掉；
4. **手机里留着旧配对记录**：删掉系统蓝牙里该设备的配对记录，从配对重新来一遍，见 [连接与配对教程.md](连接与配对教程.md) 第二节；反复无效就把设备恢复出厂，步骤见 [耳机重置与重新配对方法.md](耳机重置与重新配对方法.md)。

## 二、连上了但电量不显示

- 电量读取依赖应用与设备保持连接，把应用切到前台、确认设备图标显示「已连接」再看；
- 部分早期型号不向应用上报电量，应用页面上没有电量栏属于正常，不是故障；
- 电量数值明显异常（比如一直 100%）：断开重连一次，或重启手机蓝牙再试；
- 不想连手机也能看电量：按 [充电与指示灯含义对照.md](充电与指示灯含义对照.md) 的灯效表，从设备指示灯直接判断。

## 三、声音、音效相关

- **两边音量不一致 / 一边没声（耳机）**：重新戴好让触摸区贴合，或把耳机放回充电盒再取出复位；真无线耳机两只都闪蓝却连不上彼此，属于左右耳失联，处理见 [耳机重置与重新配对方法.md](耳机重置与重新配对方法.md) 第五节；
- **改了 ToneTouch 没变化**：确认播放走的是这台设备，且音效面板顶部选中的就是它；
- **听歌中途断连**：远离微波炉、路由器密集区，或检查手机省电策略是否在后台杀掉了 Beoplay——把应用加入电池优化白名单再试。

设置项的具体位置见 [ToneTouch音效与手势设置.md](ToneTouch音效与手势设置.md)。

## 四、固件更新怎么做

旧款 B&O 产品更新固件有两条路：

1. **应用内更新**：设备连接后，在产品设置里找到「软件 / Software」一项，按提示更新；
2. **电脑端工具 Beoplay Software Updater**：官方为 Windows 与 Mac 提供的独立更新工具，支持的设备包括 Beoplay A1、A2、A2 Active、H7、H8、H8i、H9、H9i、H9 3rd Gen、P2、P6、S3、Beolit 15、Beolit 17 等，可从官方支持页（`support.bang-olufsen.com`）搜索「Beoplay Software Updater」下载。

更新前把设备接上电源或保持充足电量，过程中别断开连接；音箱类产品（如 M5）更新时通常要保持接电、等待指示灯变化后再在应用里操作。

## 五、Beoplay 与新版「Bang & Olufsen」应用的关系

这是装之前最容易混淆的一点：

| | Beoplay（本篇的旧版） | Bang & Olufsen（新版官方） |
| --- | --- | --- |
| 应用商店 | 已从 Google Play 下架 | 正常提供 |
| 面向产品 | 早期蓝牙耳机与音箱 | 较新产品为主，兼容部分旧款 |
| 使用方式 | 蓝牙直连，本地控制 | 多产品管理、多房间，需登录账号 |

- 如果你的设备在 Beoplay 里工作正常，不必强行迁移；
- 如果设备较新（Beosound 系列、EX、Portal 等）而 Beoplay 添加不到，那是型号问题，改用新版应用；
- 两款应用可以共存于同一部手机，按设备分开使用。

## 六、重装与换机

应用卸载后设备上的配对与设置会保留，重装后重新添加产品即可；安装包可随时从 [下载与安装教程.md](下载与安装教程.md) 里的 Beoplay 安装文件资源（夸克网盘）重新获取，装好后按 [连接与配对教程.md](连接与配对教程.md) 重走一遍配对。
