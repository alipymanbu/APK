# Beoplay 连接与配对教程

> 手里的 B&O 耳机或音箱怎么跟 Beoplay 应用对上号：先系统蓝牙配对，再在应用里添加产品。本篇按顺序讲清两个环节，并列出常见可添加的型号。

## 一、配对的整体顺序

B&O 的设备接入 Beoplay 分两步，顺序别反：

1. **系统层面蓝牙配对**：让设备进入配对模式，在手机的蓝牙设置里选中它；
2. **应用层面添加产品**：打开 Beoplay，按引导选择型号、命名，之后设置与状态都在应用里管理。

很多「应用搜不到设备」的问题，其实是第一步根本没完成——应用只能管理已经完成蓝牙配对（或处于配对状态）的设备。

## 二、让设备进入配对模式

不同产品的进入方式不同，常见有这几类（具体以自己型号的说明书或官方支持页为准）：

- **头戴耳机（H8i / H9 / H9i 等）**：开机后长按蓝牙键，指示灯开始闪烁蓝色即处于配对状态；
- **真无线耳机（E8 系列）**：把两只耳机放回充电盒再取出，或长按盒上按键，直至指示灯闪烁蓝色；配对时两只耳塞之间的距离保持在 20 厘米以内（官方对 E8 2.0 的要求）。
- **便携音箱（A1 / P2 / P6 等）**：长按蓝牙键，听到提示音或看到蓝牙图标闪烁。

配对模式通常只维持一两分钟，超时就重新操作一次。

## 三、在系统蓝牙里完成配对

1. 打开手机「设置 → 蓝牙」，确保蓝牙已开启；
2. 在可用设备列表里找到自己的 B&O 设备名称（如 `Beoplay H9 3rd Gen`），点击连接；
3. 部分机型会弹出配对请求，确认即可。

配对成功后，播放一段音乐确认能出声，再进入下一步。

## 四、在 Beoplay 里添加产品

参考官方支持页的引导流程：

1. 打开 Beoplay；
2. 点「添加产品」（Add a product）；
3. 在列表里选择自己的型号；
4. 选择产品颜色（部分型号需要）；
5. 给产品起个名字（默认名也可以），点「下一步」；
6. 显示添加成功后点「完成」。

像 E8 2.0 这类真无线耳机最多可保存 8 个配对设备，开机会自动尝试连接记忆列表里的设备——新设备加不进来时，先按 [耳机重置与重新配对方法.md](耳机重置与重新配对方法.md) 清一遍旧记录再配。

之后每次打开应用，只要设备在蓝牙范围内并已连接，应用会自动识别并显示电量、连接状态。

## 五、常见可添加的产品

Beoplay 面向 B&O 较早期的蓝牙产品，常见可管理的型号包括（**最终以应用内「添加产品」列表实际显示为准**）：

| 类别 | 型号举例 |
| --- | --- |
| 头戴耳机 | H4、H7、H8、H8i、H9、H9i、H9 3rd Gen |
| 真无线耳机 | E6、E8 系列 |
| 便携音箱 | A1、A2、A2 Active、P2、P6 |
| 家用音箱 | M3、M5、S3、Beolit 15、Beolit 17 |

较新的产品（Beosound 系列、EX、Portal 等）请改用新版「Bang & Olufsen」应用，两款应用的分工见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 六、两台音箱组立体声

有两台同型号音箱（如 A2 Active）时，可以在应用里把它们组成无线立体声，分左右声道播放：

1. 两台音箱分别与手机完成蓝牙配对，并在应用里逐一添加；
2. 选中其中一台作为主音箱，点「Stereo Pair」进入立体声配对菜单；
3. 选择要加入的另一台音箱，确认后即完成组对。

两台音箱之间的距离不要超过 3 米，超出这个范围无线立体声连接会不稳定。

## 七、添加失败怎么办

- 应用列表里找不到型号：确认设备已进入配对模式，且手机的蓝牙、定位权限都已授予；
- 系统蓝牙能连但应用里看不到：在应用里刷新产品列表，或把应用切到后台重开；
- 反复失败：把手机里该设备的蓝牙配对记录删掉，从第二节重新走一遍；仍不行就把设备恢复出厂再重来，操作见 [耳机重置与重新配对方法.md](耳机重置与重新配对方法.md)。

更多具体症状（电量不显示、频繁断连等）见 [常见问题与故障排查.md](常见问题与故障排查.md)；添加成功后想调音效或改手势，直接去 [ToneTouch音效与手势设置.md](ToneTouch音效与手势设置.md)。
