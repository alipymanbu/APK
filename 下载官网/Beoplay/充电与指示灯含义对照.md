# 充电与指示灯含义对照

> B&O 设备上那几颗灯各自代表什么、充多久算满、用什么充电头——本篇把官方说明里的数值汇总成对照表，判断耳机是没电了还是出了别的问题。

## 一、充电数值速查

以下数值来自官方支持页（不同代际略有差异，以自己型号的官方页面为准）：

| 项目 | 数值 |
| --- | --- |
| E8 耳机快充 | 充 20 分钟 ≈ 播放 1 小时；充 2 小时 ≈ 播放 4 小时 |
| E8 一代/二代充电盒 | 满电可额外提供 2 倍耳机电量，充电口为 Micro-USB，充满约 2 小时 |
| E8 三代充电盒 | USB-C，支持 Qi 无线充电，满电可额外充电 4 次，整机续航最长约 35 小时 |
| H8i / H9i 头戴耳机 | 充满约 2.5 小时 |
| 适配器上限 | 官方建议不超过 5V / 3A |

给充电盒充电时，指示灯会逐颗闪烁白色，充满后转常亮；充电盒还剩几颗灯，大致等于还能给耳机充满几次。

## 二、E8 耳机指示灯对照

| 灯效 | 含义 |
| --- | --- |
| 白色常亮 | 已开机 |
| 蓝色闪烁 | 蓝牙配对模式，等待连接 |
| 蓝色常亮 | 配对成功 |
| 红色闪烁 | 电量很低（不足 15%） |
| 橙色闪烁 | 正在充电 |
| 绿色 | 已充满（线充常亮，盒充保持约 1 分钟后熄灭） |

看到红闪就该马上回盒充电；如果戴着用时突然单边没声并伴随红闪，基本是电量耗尽而不是故障。

## 三、E8 三代充电盒指示灯对照

以下为**未接电源**时的灯效，充电中各灯的表现以官方页面为准。

**耳机在盒内（开盖观察）**：

| 灯效 | 含义 |
| --- | --- |
| 橙色闪烁 | 耳机正在充电 |
| 绿色常亮（约 5 秒） | 耳机已充满 |

**耳机不在盒内（开盖观察盒子的电量）**：

| 灯效 | 含义 |
| --- | --- |
| 绿色常亮（约 5 秒） | 盒内余量还能充满耳机 1 次以上 |
| 橙色常亮（约 5 秒） | 盒内余量不足 1 次 |
| 红色常亮（约 5 秒） | 盒子快没电了，先充盒子 |

## 四、头戴耳机的灯怎么看

H8i / H9i 这类头戴型号的灯效逻辑与真无线一致：白色表示开机、蓝闪表示配对中、红闪（2 秒）多出现在重置完成时，见 [耳机重置与重新配对方法.md](耳机重置与重新配对方法.md) 第三节的对照。充电中指示灯的状态变化以官方页面图示为准，不同代际表现略有出入。

## 五、应用里的电量显示

Beoplay 应用首页会显示已连接设备的剩余电量，日常出门前看一眼即可；电量数值只在应用与设备保持连接时刷新，数值长期不变或显示异常时，断开重连一次。设备本身不支持上报电量的老型号，应用里没有电量栏，以指示灯为准。
