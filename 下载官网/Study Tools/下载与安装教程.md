## 一、安装前先核对这几点

动手前先确认你要装的就是这一版，免得装到一半发现不对：

| 项目 | 值（以网盘内安装包为准） |
| --- | --- |
| 应用名 | Study Tools（设备上显示为 study tool） |
| 版本号 | 1314520 |
| 包名 | com.wannian.tool |
| 安装包大小 | 约 27.76M |
| MD5 | `5B5E76AFCA726849D2D122C82D8FEF36` |
| 系统要求 | 分发页标注「安卓系统 5.2 以上」 |

几点补充：

- 这款工具走的是 apk 安装包安装的路子，不在主流应用商店上架，所以安装前要先把「安装未知应用」的口子打开（下面第三节）。
- 装好后应用本体约占 35MB，加上运行产生的数据总共约 50MB（以你设备上应用信息页显示为准），预留一点空间即可。
- 网上可能搜到别的版本号，不必纠结——以你实际拿到的安装包为准，本篇按网盘内这一版（1314520）写。
- 担心安装包被人动过手脚，可以先核对 MD5 再装，方法见 [封号风险与使用注意.md](封号风险与使用注意.md)。

## 二、获取 Study Tools 安装文件资源

安装文件资源放在夸克网盘：[https://pan.quark.cn/s/2ae981bb78f3](https://pan.quark.cn/s/2ae981bb78f3)

1. 打开链接，把里面的安装包**转存到自己的网盘**；
2. 用手机夸克 App 把 apk 文件下载到手机存储；
3. 记住下载位置（一般落在 `Download` 目录），下一步要用。

## 三、安装步骤

1. 在文件管理器里找到刚下载的 apk，点它。
2. 第一次装会弹「出于安全考虑，不允许安装未知来源应用」之类的提示，点「设置」，把**允许安装未知应用**打开（授权对象是你刚才点安装用的那个文件管理器或浏览器）。
3. 回到安装页点「安装」，等进度走完。
4. 装完桌面会出现 **study tool** 图标。

如果这一步报「应用未安装」，常见原因是安装包下载不完整或系统版本过低，处理办法见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、首次启动要过两道门

1. **「文件和媒体」权限**：打开应用后，系统先让你选择给 study tool 授予哪些权限，其中「文件和媒体」（访问照片、媒体内容和文件）是它读写配置用的，建议允许，否则后面保存配置会出问题。
2. **工作模式选择**：授权完会弹出「工作模式」窗口，只有三项——**Root**、**无Root**、**退出**。这一步决定工具以什么方式运行，两种模式的差别与选择依据单独写在 [Root与免Root模式怎么选.md](Root与免Root模式怎么选.md)。

选完模式进入主界面后，下一步就是挑游戏、调数值，操作顺序见 [使用步骤与配置保存.md](使用步骤与配置保存.md)。

还有一个以后才会计较的细节：装完之后如果长期不打开，系统会自动把这个应用的权限收回去（安卓 11 起的默认行为），到时保存配置、悬浮窗都会出问题——怎么恢复、怎么提前关掉这个机制，见 [权限被自动撤销怎么办.md](权限被自动撤销怎么办.md)。
