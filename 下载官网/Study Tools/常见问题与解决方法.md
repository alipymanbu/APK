## 一、修改不生效

按顺序核对：

1. **选的游戏对不对**：回工具里确认当前作用的是那款游戏的进程，不是同名应用，也不是系统进程。
2. **改的是不是本地数值**：金币、属性这类存在手机本地的值能改；走服务器校验的值（比如充值获得的货币）改了也会被服务器改回去。
3. **游戏是不是刚更新**：游戏更新后内部数据和旧配置可能对不上，旧改法失效是正常的，等配置跟进或改用基础参数调整。
4. **逐步调整**：一次只改一项，切回游戏看一眼再改下一项，才能确定是哪一项没生效。

## 二、修改后游戏崩溃

- 先查两边版本：游戏刚更新的话等一等再试；工具版本太旧也可能跟不上新游戏，以分发页提供的版本信息为准。
- 恢复到修改前的配置再进游戏，能进说明是某一项改过头了，逐项加回来排查。
- 实在不行就重装游戏——**先确认存档有云备份或本地备份**，否则进度会一起没掉。

## 三、保存的配置无法加载

- 配置存在手机本地，先看文件还在不在——被清理软件或「清空存储空间」删掉就找不回来了。
- 文件还在但读不出来，多半是配置对应的游戏版本对不上：重新调一遍，另存一份新配置。
- 以后把重要配置另存一份到网盘或电脑，别只留手机本地一份。

## 四、应用打不开

按顺序试：重启手机 → 确认「文件和媒体」权限还开着 → 卸载重装。还不行就检查系统更新，个别系统版本对这类工具兼容性差，等适配。

## 五、权限被拒后的典型症状

| 症状 | 多半是这个权限没了 |
| --- | --- |
| 保存配置失败、读不到文件 | 「文件和媒体」（存储）权限 |
| 悬浮窗出不来、切到游戏里看不到工具 | 「显示在其他应用上层」权限 |

两个都在 系统设置 → 应用 → study tool → 权限 里重新打开即可。安装与首次授权流程见 [下载与安装教程.md](下载与安装教程.md)。

要是你根本没动过权限、隔了几个月它自己坏的，那是系统的「未使用应用自动撤销」机制干的，恢复与预防办法见 [权限被自动撤销怎么办.md](权限被自动撤销怎么办.md)。
