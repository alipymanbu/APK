# Study Tools 的 Root 与免Root模式怎么选

> 首次打开 Study Tools 会先弹「工作模式」：Root、无Root、退出。本篇讲两种模式的差别、各自的代价，以及怎么按自己的设备情况选。

## 一、这个窗口在问什么

启动时它问的是：**以什么身份运行**。

- **Root**：你的手机已经解锁并授予了超级用户权限时选这个。能做的事最多，深度修改只有这条路能走。
- **无Root**：手机没解锁、不想折腾的选这个。基础功能可用，能对游戏的本地数值做调整；涉及更深层的修改可能不生效。
- **退出**：反悔了不玩了就点它。

选错模式不用重装——重启应用就会回到这个选择界面。

## 二、两种模式的能力差别

多个分发页对功能的描述口径一致，整理成表：

| 能做的事 | 无Root | Root |
| --- | --- | --- |
| 选择目标游戏、过滤系统应用 | 可以 | 可以 |
| 调整本地数值参数（画质、速度、灵敏度一类） | 可以 | 可以 |
| 保存、恢复配置 | 可以 | 可以 |
| 深度修改、完整功能 | 受限 | 可以 |

（「可以 / 受限」按分发页描述整理；具体到某一款游戏能不能改，以你实际运行为准。）

## 三、选 Root 之前先掂量代价

Root 不是勾一个开关就完的事，动手前想清楚：

1. 解锁 bootloader 大多会**清空手机全部数据**，先备份。
2. Root 后**保修可能失效**（各品牌政策不同，以厂商说明为准）。
3. 银行、支付类应用会检测 Root 环境，可能直接拒绝运行。
4. Root 之后误删系统文件会导致系统异常，这个后果只能自己承担。

没 Root 过的手机，建议先用无Root模式跑一遍，确认这工具对你玩的那款游戏确实有用，再考虑要不要为它去 Root。

## 四、无Root模式达不到效果怎么办

先核对三件事：选的游戏进程对不对、改的是不是本地数值、游戏是不是刚更新过版本。都排除了还是不行，多半是这款游戏在当前环境下改不动——别抱着「Root 了就一定能改」的预期去折腾，先想想要不要为这一个游戏付出 Root 的代价。

风险方面（尤其是联网游戏的封号问题）在 [封号风险与使用注意.md](封号风险与使用注意.md) 里有展开，动手改之前先看一眼。
