# Study Tools 封号风险与使用注意

> 用修改工具改游戏是有代价的：账号被封、存档损坏、装到来路不明的包。本篇把这些风险一次列清，并给出能落地的防护做法。

## 一、先分清：单机还是联网

这是决定风险大小的一条分界线：

- **单机 / 离线游戏**：数据都在你手机本地，改坏了顶多重装，波及不到别人。
- **联网游戏**：数值要过服务器校验，还有反作弊系统盯着，本地改出来的异常数值很容易被比对出来——轻则数据回档，重则**封号**，冲过钱的账号也一样。

分发页上流传的「防封」说法没有可靠的验证依据，别当成安全保障来用。动手前先问自己两个问题：这个游戏有没有服务器校验和排行榜？这个账号丢了你能不能接受？

## 二、动手前先备份

1. **游戏存档**：能云同步的开云同步；纯本地的存档用系统备份或第三方备份工具导一份出来。
2. **工具配置**：调出来的满意配置另存一份（见 [使用步骤与配置保存.md](使用步骤与配置保存.md)），别只留手机本地一份。
3. **手机数据**：打算走 Root 路线的话，解锁 bootloader 会清空全部数据，先整份备份（Root 的代价见 [Root与免Root模式怎么选.md](Root与免Root模式怎么选.md)）。

## 三、核对安装包，别装到被动过手脚的包

同一款工具在不同站点流传的安装包不一定一样，**装之前核对 MD5** 是最省事的自保办法：

1. 拿到安装包后先别装；
2. 电脑上在命令行里执行：

   ```bat
   certutil -hashfile 安装包文件名.apk MD5
   ```

3. 对照结果是否为 `5B5E76AFCA726849D2D122C82D8FEF36`（网盘内 1314520 版安装包的 MD5）。

对不上就别装——改过的安装包可能夹带别的东西。

## 四、几条边界提醒

- 分发页标注适用年龄 **16 周岁以上**，给未成年人用之前自己把关。
- 修改只用于**自己的设备、自己的账号、自己买的游戏**，别去动别人的账号或设备。
- 分发页标注工具需要联网，介意流量或隐私的话，装完在系统流量统计里观察一下它的用量。
