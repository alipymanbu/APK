## 一、离线听歌有两条路

- **缓存**：听过的歌自动在本地存一份，第二次播放不再消耗流量。适合「反复听同一批歌」，你不用做任何事，开着自动缓存就行。
- **离线下载**：把整首歌、整张专辑或整个歌单主动存成离线内容，断网也能完整播放。适合通勤、坐飞机这类提前知道「接下来没网」的场景。主动下载一般属于会员功能，对应哪个方案见[会员方案与免费试用.md](会员方案与免费试用.md)。

## 二、把歌存成离线内容

1. 在播放页或歌曲的「⋯」菜单里找「下载 / 加入离线」；
2. 歌单和专辑页可以整单下载，不用一首首点；
3. 断网后进「我的音乐 / 收藏 / 离线内容」里播放。

不同版本的菜单名称略有差异，认「下载」「离线」这两个字样即可；下载完成的歌曲条目上一般会有离线标记。

有的歌点了却下载不了：版权方没开放离线的歌只允许在线播放，离线栏会显示「未授权」「仅供线上收听」这类字样——这是歌曲本身的授权限制，不是你操作错了，换一版 App 也解决不了。

## 三、自动缓存与清理

- 设置里可以打开「自动缓存」；有用户整理过缓存上限约 4000 首，超出后按一定策略替换，具体以你手上版本的说明为准。
- 缓存和离线内容都会占存储空间，空间紧张时在设置里「清除缓存」即可，清缓存不会影响你的收藏与歌单，只是下次播放要重新连网加载。
- 换手机或重装 App 后，离线内容需要重新下载；歌单和收藏在云端，登录同一账号就会同步回来。

## 四、音质怎么设

- 设置里的「音质」通常分 **Wi-Fi** 与**移动网络**两栏，可以分别设定，这是省流量的关键。
- 标准串流最高 320Kbps，低档有 192Kbps、128Kbps 可选（以 App 内实际选项为准）。
- 流量参考（用户整理的换算值，仅供估算）：320Kbps 约 144MB/小时，192Kbps 约 86MB/小时。通勤一小时大约用掉 100~150MB。

| 音质档位 | 适合场景 |
| --- | --- |
| 320Kbps | Wi-Fi 环境默认 |
| 192Kbps | 移动网络日常听 |
| 128Kbps | 流量紧张、后台听 |
| Hi-Fi / Hi-Res（最高 24bit/192kHz） | 需对应会员方案，且目前仅在台湾、香港、新加坡开放 |

## 五、几条省流量的做法

1. 移动网络档位调低到 192Kbps 或 128Kbps，Wi-Fi 档保持 320Kbps 或无损；
2. 出门前在 Wi-Fi 下把常听的歌单整单下载，通勤路上开飞行模式播放，一点流量都不耗；
3. 关掉自动缓存的反向用法：如果你在意存储空间而不是流量，把自动缓存关掉，只手动下载真正要离线听的歌；
4. 用「一起听」或看视频类内容时走的是串流，流量消耗高于普通听歌，移动网络下留意（一起听的用法见[一起听和动态歌词怎么用.md](一起听和动态歌词怎么用.md)）。
