## 一、登录时报错误码或一直转圈

按顺序排查，每做一步试一次，别一次全做完分不清是哪招起的作用：

1. **换网络**：Wi-Fi 和移动数据互切，确认是不是本机网络的锅；
2. **清缓存**：设置 → 应用 → Bigo Live → 存储 → 清除缓存（不会掉登录态）；
3. **重装最新版**：卸掉重装能同时排除安装包损坏与版本过旧两种原因 —— 安装包见 [bigolive 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e0b039f2f5ce)；
4. **记下错误码**：还不好就带着错误码、账号 BIGO ID、大致时间找官方客服，描述越具体处理越快。

## 二、账号登不回来：三种情况都走申诉

官方明确的三种「登不回」情形 —— **账号被盗、原手机号已停用、原登录方式失效** —— 处理路径一样：

1. 应用启动页点「使用手机号」；
2. 选「账号申诉」→「立即申诉」；
3. 填写 **BIGO ID、手机号、邮箱**及能证明归属的材料；
4. 等审核答复。

细节在 [注册与登录方法.md](注册与登录方法.md) 第四节。补充两条实操建议：

- **申诉期间别反复试密码** —— 连续失败可能触发风控，让流程更慢；
- **看到「封禁 / 账号被停用」提示也走这里**：表单里写明情况，官方客服按记录核查；「我被封了但我没错」这类口头争论没有用，材料才有用。

## 三、闪退、卡顿、黑屏

| 现象 | 先查这几项 |
| --- | --- |
| 一打开就闪退 | 系统版本是否达到门槛（各来源口径不一，官方教程写 Android 5.0+，第三方商店页标注更高，见 [下载与安装教程.md](下载与安装教程.md) 第二节）；安装包是否完整（对照 MD5） |
| 看直播卡顿 | 当前网络带宽与信号；同 Wi-Fi 下其他设备是否在占带宽；换成流畅/标清画质 |
| 开播画面卡 | 上行带宽不足是主因 —— 换 Wi-Fi 或靠近路由器；关掉后台占网的应用；检查摄像头、麦克风权限是否授予（见 [怎么开直播.md](怎么开直播.md) 第一节） |
| 有声音没画面 | 直播模式是否选了语音直播/虚拟直播；摄像头权限是否被系统收回（后台清理会回收权限） |
| 更新后出问题 | 新版本与旧系统不兼容时，先清缓存；仍异常则回退到能用的版本重新装（同一包名直接覆盖安装即可） |

## 四、看直播时遇到不适内容

直播间与评论区都有**举报**入口：在目标对象上找到举报按钮，选原因提交，官方会审核处理。同时可以：

- 直接拉黑该用户，不再看到其内容；
- 关闭弹幕或开启评论过滤，减少干扰。

举报是官方认可的处理方式，比在公屏对线有效 —— 后者只会让你的账号卷进冲突。

## 五、注销账号前必做的一件事

注销入口在应用的设置里（不同版本路径略有差异，一般在「设置 → 账号安全 / 账号管理」下）。**注销前先把钱包里的金豆兑换提现完** —— 账号一旦删除，所有数据与虚拟资产无法恢复，包括没提出来的金豆和没用完的钻石（资金规则见 [钻石充值与金豆提现.md](钻石充值与金豆提现.md)）。

同理，注销前确认没有在途的提现申请、没有绑定中的公会合约（签约主播需先按合同解约）。

## 六、还不行：找官方渠道

- **官方客服中心**：[blog.bigo.tv 客服入口](https://blog.bigo.tv/) 提供分地区的常见问题与联系方式；
- **反馈邮箱**：`feedback@bigo.tv` —— 写邮件时附上 BIGO ID、设备型号、系统版本、错误提示截图与复现步骤，一次说清比来回追问快；
- **官网**：[www.bigo.tv](https://www.bigo.tv/)。

求助时别贴身份证件照片等敏感材料，账号申诉表单里要求什么就提供什么，多给的都有泄露风险。
