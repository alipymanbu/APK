## 一、注册要准备什么

Bigo Live 支持手机号注册，也支持第三方账号直接登录。动手前先备齐两样：一个**能收短信的手机号**（或一个 Facebook / Google / Apple 账号），以及装好应用（见 [下载与安装教程.md](下载与安装教程.md)）。

注册流程（手机号路径）：

1. 打开应用，在注册页输入手机号；
2. 号码**未注册过**时，界面会自动跳到注册流程；已注册过则走登录；
3. 填收到的短信验证码；
4. 设置昵称、头像等资料，同意用户协议与隐私政策，完成注册。

第三方账号路径更短：登录页直接选 Facebook、Google、Apple 等入口，授权后即完成登录；账号是第一次用 Bigo Live 的话，会自动带上授权资料建一个新账号。

**建议在注册完就把手机号 / 第三方账号的绑定关系记牢** —— 后面换手机、丢验证码、账号异常，全靠这套绑定找回，见第六节。

## 二、日常登录方式

| 方式 | 入口 | 适合场景 |
| --- | --- | --- |
| 手机号 + 验证码 | 应用启动页「使用手机号」 | 主用手机，最常见 |
| Facebook / Apple / Google / Twitter / VK | 应用启动页对应按钮 | 手机号换号前绑定过第三方时 |
| 网页扫码 | 官网右上角「登录」+ 手机端「扫码」 | 在电脑上看主页、管理资料 |

扫码登录的具体走法：电脑浏览器打开 [www.bigo.tv](https://www.bigo.tv/)，点右上角「登录」，页面出现二维码；手机打开 Bigo Live，在个人页点「扫码」，对准电脑屏幕，再在手机上确认 —— 电脑端随即进入已登录状态。

扫码登录本身就意味着手机与网页两端同时在用同一个账号 —— 你在手机上确认，电脑那端就进入你的主页，不需要在电脑上再输一次密码。

## 三、收不到短信验证码怎么办

验证码收不到是注册环节最高频的问题，按这个顺序排查（多个来源给出的步骤一致）：

1. **先查区号和号码格式**：国家区号选错、号码多位少位，码根本不会发到你手机上 —— 手输一遍，别用自动填充；
2. **别连着点「重新发送」**：新一次请求会让前一个码作废，连点还会触发临时限流；两次请求之间等几分钟，**只用最后收到的那个码**（验证码有效期短，第三方资料称约 60~120 秒，以页面倒计时为准）；
3. **查手机的短信拦截**：运营商垃圾短信过滤、手机自带的骚扰拦截、第三方短信应用，都可能静默吃掉验证码 —— 去短信的「垃圾箱」翻一下，临时关掉过滤再试；
4. **确认手机能收到普通短信**：让别人给你发一条，能收到说明线路正常，问题在验证环节；收不到就先开飞行模式再关、重连网络；
5. **网络侧干扰**：开着 VPN 或私人 DNS 时验证请求可能发不出去，暂时关掉再试；
6. **还不行就等**：连续失败后等 30 分钟到 1 小时再请求一次 —— 频繁重试只会让限流窗口一再后移。

若提示「号码已被使用」，说明这个号注册过了，直接走登录而不是死磕注册；号码是二手号、以前被别的账号用过的，重试也不会解决，换回自己常用的那个号。

## 四、Bigo ID 在哪看、为什么要记下来

**Bigo ID 是一串 8~9 位数字**，账号建好就有、与昵称无关，昵称可以随便改，ID 不跟着变。看的位置：**「我」→ 个人页 → 昵称下方的「ID: xxx」**，点一下通常直接复制；网页端登录后点头像，在账号信息里同样能看到。

三件事离不开它：**账号申诉与解封**（[账号被封怎么解封.md](账号被封怎么解封.md)、本篇第六节）、**找官方客服**、以及部分充值/好友搜索场景。注册完就把它复制进备忘录 —— 等需要用时账号正登不上，现找会很狼狈。

## 五、登录不上去的先自查

按顺序做三步，多数问题到第二步就解决了：

1. **换网络试一次**：Wi-Fi 与移动数据互相切一下，确认不是本机网络问题（打开别的网页即可判断）；
2. **重装应用**：卸掉再装最新版，既能排除安装包损坏，也顺带把版本升到最新 —— 安装包在 [bigolive 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2dd61bf2eed4)；
3. **看报错内容**：有错误码或提示文字时，把它记下来，按 [常见问题与故障排查.md](常见问题与故障排查.md) 对照处理。

## 六、号码停用 / 账号被盗：走申诉找回

官方给出的三种典型情况 —— **账号被盗、原手机号已停用、原登录方式失效** —— 都走「账号申诉」：

1. 打开 Bigo Live，点「使用手机号」；
2. 选「账号申诉」→「立即申诉」；
3. 在表单里填 **BIGO ID、手机号、邮箱**等信息；
4. 提交后等官方审核答复。

填表时把能证明账号归属的材料写全（注册大致时间、常用登录地、曾用昵称），审核通过率会高一些。申诉期间别反复试密码，触发风控只会让流程更慢。

若怀疑账号被盗后有人在用，先在申诉表里注明，要求官方冻结；找回后立即改密码、检查绑定的手机号与第三方授权，解掉不认识的设备。
