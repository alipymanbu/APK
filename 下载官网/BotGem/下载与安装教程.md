## 一、BotGem 是什么

BotGem 是一个跨平台的 AI 聊天客户端，你在手机、Mac、Windows 上装同一个 App，填入自己从各家 AI 厂商申请的 API 密钥，就能在一处界面里切换使用 GPT、Claude、Gemini、DeepSeek 等模型。它本身不自带模型额度，也不需要注册 BotGem 账号 —— 装好、配好密钥就能聊。

适合已经有（或愿意申请）API 密钥、想在多个模型之间自由切换的用户；如果你只想开箱即用地聊天、不想折腾密钥，它并不合适。

本篇只讲**安装包获取与安装**；装好之后怎么配密钥，见 [API密钥配置教程.md](API密钥配置教程.md)。

## 二、官方下载渠道有哪些

BotGem 官方按平台分发，截至 2026 年 9 月各渠道如下（具体入口以 [官网](https://www.botgem.com/) 当时显示为准）：

| 平台 | 渠道 | 说明 |
| --- | --- | --- |
| Android | Google Play | 搜包名 `com.bytemyth.ama` 或名 BotGem |
| Android | 官网 APK 直链 | 官网提供 `.apk` 直接安装 |
| iOS / iPadOS | App Store | 应用 ID `6446135619`（旧名 AMA） |
| macOS | Mac App Store 或官网 `.dmg` | 分 Intel 与 Apple 芯片两个包 |
| Windows | Microsoft Store | 应用 ID `9NQZVTBFJ86K` |

安卓侧要注意的点：

- **Google Play 渠道**在没有 Google 服务、或连不上 Play 的设备上装不了，此时官网 APK 直链或手动安装 `.apk` 是常规做法；
- 官网直链的版本号跟随官方发布节奏，**不一定与你要装的这份是同一版**；
- 第三方应用市场里的「BotGem」需要核对包名，包名不是 `com.bytemyth.ama` 的都不是同一个应用。

## 四、安卓安装步骤

1. 从上面任一渠道拿到 `.apk` 文件；
2. 在手机「文件管理」里点该文件开始安装；
3. 系统弹出「禁止安装来自此来源的应用」时，按提示进入**设置 → 安装未知应用**，为当前安装来源（文件管理器或浏览器）打开允许，返回继续安装；
4. 安装完成后首次打开，不需要登录或注册。

安装失败的常见原因与处理：

- **解析包时出错**：包没下完或已损坏，重新下载并核对 MD5；
- **版本冲突**：设备上已有同包名但签名不同的旧构建，先卸载再装；
- **系统版本过低**：低于安卓 5.2 的设备装不上。

## 五、装完第一件事

打开 App 后你会看到可以直接进入聊天界面，但此时**任何模型都还不会回答** —— BotGem 不提供模型服务，得先填一家的 API 密钥。路径是：**设置（齿轮图标）→ 服务提供商 → 选一家 → 粘贴密钥 → 保存**。

具体到每家怎么申请、怎么填，见 [API密钥配置教程.md](API密钥配置教程.md)；配好后发不出第一条消息、或报「API 密钥无效」，按 [常见问题与报错排查.md](常见问题与报错排查.md) 处理。
