# Lightleap 换天出现白边光晕怎么办

> 换天后树梢、建筑、人物头发边缘出现白边或光晕，是换天最常见的破绽。本篇讲它的四个成因，以及按症状对号入座的处理办法。

## 一、先弄明白破绽从哪来

白边、光晕不是随机出现的，基本都出自这四种情况：

| 成因 | 典型表现 |
| --- | --- |
| 新天空与前景亮度差太大 | 地面发灰、天空假亮，像贴上去的 |
| 复杂边缘识别误差 | 树枝、发丝、电线周围一圈白晕 |
| 强度或饱和度拉满 | 整张照片一眼假，色彩溢出 |
| 原图天空过曝或过暗 | 识别区域歪，边缘参差不齐 |

多个第三方评测的实测结论一致：明亮、干净的原图换天效果最自然；深色、戏剧化的照片最容易在细小边缘（树梢、屋顶轮廓）出现光晕。所以同样的操作，素材不同结果天差地别。

## 二、按症状处理

| 你看到的 | 先动哪个 | 再动哪个 |
| --- | --- | --- |
| 树梢/建筑一圈白边 | 融合（Blend）调低 | 渐隐（Fade）加大 |
| 整片天空像浮在照片上 | 换一款光线方向一致的天空 | 亮度往前景的明暗靠 |
| 色彩溢出、一眼假 | 强度降到 60%–80% | 色温向原图冷暖靠拢 |
| 识别区域歪了、把地面算进去 | 换天空更简洁的照片 | 缩小调整范围重新试 |

操作顺序建议固定成三步：**先换天空（选光线匹配的）→ 再调融合/渐隐（治边缘）→ 最后调强度（治整体观感）**。顺序反了容易反复返工，因为换一款天空后所有参数都要重来。

## 三、放大检查的三个位置

导出前把照片放大到 100%，重点看：

1. **树梢与植被**——细碎边缘是重灾区；
2. **建筑与地平线轮廓**——直线边缘最显歪；
3. **人物头发与肩膀**——人像照片的换天破绽几乎都在这。

这三处过了，缩略图和社交平台上基本看不出编辑痕迹。

## 四、调不好的三种兜底

- **裁切回避**：把破绽最集中的复杂边缘直接裁出画面，构图上损失一点，但比留一圈白边强；
- **换素材**：天空占比太小、背景太杂的照片换天收益本来就低，换一张室外、天空干净的原图重试；
- **放弃自动换天**：个别照片怎么调都不自然，说明这张的边缘超出了自动识别的处理能力，硬压强度只会整张发灰——这类照片交给手动调色反而更快。
