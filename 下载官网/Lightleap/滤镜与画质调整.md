# Lightleap 滤镜与画质调整

> 换天之外，Lightleap 里日常用得最多的是滤镜和基础调整。本篇按「选滤镜 → 一键外观 → 修瑕疵 → 手动调参数」的顺序，讲每一步实际怎么操作。

## 一、先想清楚你要改什么

一张照片从打开到导出，常见的调整顺序是：先修掉画面里的瑕疵，再上滤镜定色调，最后手动微调曝光和对比。顺序反了容易反复返工——滤镜压上去之后再修图，边缘很容易和色调打架。

Lightleap 的调整工具都集中在底部工具栏，从左到右大致对应「特效类（Sky、特效）→ 滤镜类（Filters、Looks）→ 修图类（Heal、调整）」，具体排布以你手上的版本实际显示为准。

## 二、滤镜：按主题挑，用强度收

滤镜库按主题分组：暖色调、黑白、城市、复古等。用法上三点值得注意：

- **按拍摄场景找主题**，而不是逐个试——食物、人像、街景对应的主题不同，同组滤镜色调一致，试错成本低；
- **强度滑块决定真假**。滤镜默认强度偏高，直接套会出现「一眼滤镜感」，把强度降到一半上下更接近手机直出的质感；
- 同一主题内的滤镜差别主要是偏色方向，先确定想要暖还是冷，再在组里挑具体那款。

## 三、Looks：一键外观

Looks 是打包好的一整套外观预设，点一下同时改变色调、对比等多个维度，适合不想逐项调参数的场合：

- 和单个滤镜的区别是覆盖面：滤镜只管颜色，Looks 是整体观感；
- 套用后仍可以再叠加滤镜或手动调整，但叠加层数越多，画质损失越明显；
- 部分外观在免费额度之外，选不到的会提示订阅（边界见 [免费能用哪些功能.md](免费能用哪些功能.md)）。

## 四、Heal：点掉杂物

Heal 工具用来去掉画面里的小瑕疵——皮肤痘印、地上的烟头、电线等小面积杂物：

- 点或圈住目标，应用自动用周围像素补上；
- 只适合小面积目标。有用户反馈移除较大的物体后会留下模糊或烟雾状的补块，宣传视频里的干净效果多是小块瑕疵；大目标建议用裁切把构图避开；
- 补完不满意就撤销重试，换一个更小的圈往往效果更好。

## 五、手动调整：只动三四个滑块

不套预设时，多数照片只需要动这几项：

| 调整项 | 什么时候动 |
| --- | --- |
| 曝光 | 照片整体偏暗或过曝 |
| 对比 | 画面发灰、没层次 |
| 饱和度 | 天空、植物颜色发闷 |
| 高光/阴影 | 逆光人脸黑、天空死白 |

调整量没有标准值，边拖边看，避免把肤色拖到失真。具体每张照片该动哪几项，取决于原图问题，不存在万能参数。

## 六、导出前最后检查两件事

1. **放大看边缘**：换过天或用过 Heal 的区域，缩略图上看不出的破绽，放大后一目了然；换天的白边、光晕有专门的处理办法，见 [换天出现白边光晕怎么办.md](换天出现白边光晕怎么办.md)；
2. **别重复叠加**：滤镜上再叠 Looks 再调饱和，色彩断层和噪点会一起出来。

换天和光效特效的用法不在这篇范围，见 [换天与特效怎么用.md](换天与特效怎么用.md)；装不上或打不开先去 [下载与安装教程.md](下载与安装教程.md) 和 [闪退打不开怎么办.md](闪退打不开怎么办.md)。
