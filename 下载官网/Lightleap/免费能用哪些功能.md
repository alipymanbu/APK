## 一、免费与付费的边界

Lightleap 是「免费下载 + 应用内购买」的模式，免费部分能体验完整的编辑流程，但素材库大量内容被锁。按公开资料和应用内提示，大致边界如下：

| 范围 | 免费版 | 订阅后 |
| --- | --- | --- |
| 基础调整（曝光、对比等） | 可用 | 可用 |
| 换天（Sky） | 少量天空预设可试 | 60 多种天空全开放 |
| 滤镜 / Looks | 每组少量可试 | 按主题全开放 |
| 光效特效（Light Tricks） | 部分受限 | 全开放 |
| Heal 修瑕疵 | 受限 | 可用 |

免费范围会随版本调整，以你打开应用时实际能用的为准。挑订阅前值得先只用手头免费的部分编辑几张，确认日常需求是不是真的撞墙——不少场合「少量可试」已经够用。

## 二、订阅档位与价格参考

订阅提供「无限访问」：解锁全部付费功能与素材。付费形式有两种：

- **订阅制**：按月、按半年或按年收费；
- **一次性买断**：非订阅的永久授权，适合不想持续扣费的情况。

价格参考（会变动、随区域不同，以应用内订阅页当时显示为准）：

| 渠道 | 参考价格 |
| --- | --- |
| 中国区 App Store 列出的内购档位 | ¥27 / ¥138 / ¥198 三档 |
| 美国区（第三方资料） | 约 $3.99/月起 |

三档分别对应月、半年、年，具体对应关系同样以订阅页为准。年付折算到每月通常最便宜，但前提是你确定会用满一年；不确定就先月付试。

## 三、订阅怎么管理、怎么取消

订阅通过应用商店的账号体系扣费，取消也在商店侧操作，不是在 Lightleap 里：

- **安卓（Google Play）**：Play 商店 → 右上角头像 → 付款与订阅 → 订阅 → 找到 Lightleap → 取消订阅。取消后当前计费周期结束才停止，已扣的费用不按天退。
- **iOS（App Store）**：设置 → 点你的姓名 → 订阅 → 选中 Lightleap → 取消订阅。

两个容易踩的点：

1. **免费试用期内取消**不收费，但一定要在试用期结束前至少一天操作，临期当天取消经常已经扣款；
2. **卸载应用不等于取消订阅**，扣费照常继续，必须到商店的订阅页里取消。

误扣款想追回的话：

- **Google Play**：扣款后 48 小时内可直接在 Play 商店的订单收据页对那笔订单申请退款，超过时限改走客服渠道，是否通过以商店审核为准；
- **App Store**：到 `reportaproblem.apple.com` 用购买时的 Apple ID 登录，找到对应订单发起退款申请，理由写清「未授权扣款」或「无意订阅」，结果同样以苹果审核为准。

## 四、什么情况下值得付费

按使用频率粗略判断：

- 偶尔修几张发社交平台 → 免费额度加基础调整大概率够；
- 长期做内容、需要批量出图、想用完整天空库和特效 → 订阅月付先试一个月再决定要不要转年付或买断；
- 只想要某一两个功能（比如只用换天）→ 先确认那个功能在免费版里的可用程度，别为单一功能直接上年度订阅。

装好应用后从 [换天与特效怎么用.md](换天与特效怎么用.md) 上手；遇到扣费或功能没解锁的问题，先核对是否登录了购买时的同一账号，再走商店侧的订阅管理。
