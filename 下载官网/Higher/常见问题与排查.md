## 一、安装问题

**点 APK 没反应或提示禁止安装**：系统没给「安装未知应用」权限。到「设置 → 应用 → 浏览器（或文件管理器）→ 安装未知应用」里打开允许，再回来重装。

**怀疑包不对或下载不完整**：核对两件事 —— 包名是不是 `com.dalcomsoft.mysu.a`、MD5 是不是 `20AD6FA33D1DED90A6D1E36354C02B9C`（对应版本 2.3.8，详见 [下载与安装教程.md](下载与安装教程.md) 的版本表）。对不上就重新下载一份，可从 [Higher 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4d1c6ae09bff) 再转存一次。

**装上了但打不开**：先重启手机再试；还不行就清一下应用缓存或卸载重装。安卓版本太旧也可能带不动，以官方商店页标注的系统要求为准。

## 二、账号与登录

**注册必填哪些**：邮箱和密码。密码要同时有字母、数字和特殊符号（8~15 位）；性别、姓名、昵称、生日、Dalcom 账号都是选填，不影响注册。

**以前用 SuperStar X 注册过的账号还能用吗**：能。应用更名前的账号沿用原邮箱密码直接登录（据粉丝投票指南的说法，以实际登录结果为准）。

**界面不是中文**：进 My → Setting → Language Setting 切换语言。

**退出登录在哪**：My → Setting → Logout。

**收不到验证邮件**：先翻垃圾箱；确认注册邮箱没写错；还不行换一个常用邮箱重新注册。

## 三、投票问题

**票投了但榜上没变**：实时投票只计入每周日直播窗口内的票，Hot Stage 有自己的起止时间，窗口外的票不存在 —— 先确认你投的时段对不对。

**点投票没扣点数也没反应**：检查是否已登录、Ruby 余额与有效期，网络波动时重进投票页再试；多次失败就等几分钟，别连续重试刷出风控。

**多账号刷票行不行**：不建议。这类公开投票平台都有反作弊风控，异常账号可能被限制，绕规则攒出来的票数最后多半白投。

## 四、活动奖品怎么申请

入口在 My Page → Events → Apply。奖品种类按官方介绍包括人气歌谣入场券、签名拍立得、签名 CD 等；每期活动的时间、规则、开奖方式以活动页公告为准，中选后的领奖通知也走应用内与邮件。

## 五、权限都是干嘛的

按官方商店说明，这些权限全部可选，不同意也不影响基本使用，随时能在系统设置里改：

| 权限 | 用途 |
| --- | --- |
| 照片与媒体 | 设置头像、下载投票认证图 |
| 相机 | 拍摄头像 |
| 通知 | 接收投票、Timepiece、活动的应用内公告 |
| 位置 | 参与 Higher Pop 这类基于位置的小卡活动 |
| 广告标识 | 核对激励广告的观看完成情况，保证任务奖励到账 |
