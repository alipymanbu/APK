## 一、先分清 Basic 和 Premium

官方商店里 Castro 有两个**独立应用**：Basic（包名 `com.itemstudio.castro`）与 Premium（包名 `com.itemstudio.castro.pro`），不是同一个应用内购解锁的关系。Premium 比 Basic 多这些能力（官方 FAQ 原文归纳）：

| 能力 | 说明 |
| --- | --- |
| 深度界面自定义 | 多种颜色与主题 |
| 桌面小部件 | 主屏快速看设备主要信息 |
| 网络测速监控 | 通知栏常驻的网速监控 |
| 电池指示器 | 通知栏常驻显示电池温度、电压、状态等 |
| CPU 使用率监控 | 随时看处理器占用 |
| PDF 导出 | 信息报告可导出为 PDF |

你在 [下载与安装教程.md](下载与安装教程.md) 里核对过包名，就知道手上这份属于哪一类。

## 二、官方明确列出的「不准」场景

以下四条来自官方 FAQ，看到数值奇怪先对照这里，**别急着判定手机有毛病**：

1. **屏幕密度（DPI）可能算错** —— Android 本身无法得知真实 DPI，只会把它缩放到最近的档位（120 / 240 / 360 / 480 / 640），Castro 只能如实显示系统给的值。
2. **电池容量只对原厂电池准确** —— 如果换过第三方电池或扩容电池，Android 和 Castro 都读不到新电池的真实容量，容量一栏仍是旧值或不可用。
3. **最低 / 最高电压目前只在骁龙机型上报** —— 其他平台显示不出来是支持范围问题，不是故障。
4. **相机参数可能有误** —— 部分厂商把错误数值写进了设备的 Android 配置文件，应用只能原样展示。

## 三、其他高频疑问

- **数值一直在跳、频率忽高忽低**：CPU 降频调速是系统正常行为，实时页显示的就是那一刻的值，波动不代表异常。
- **某个字段是空的**：多半是该字段需要权限、或该机型没有对应传感器/上报接口。权限相关的处理见 [数据报告导出与分享.md](数据报告导出与分享.md)。
- **界面和网上截图不一样**：官方从 4.7（2025-01-07）之后又发过 4.8.x、4.9 等版本，逐版都有增删改（见 [官方更新日志](https://pavlorekun.dev/castro/changelog_release/)）。你手上是 4.7，以本目录 [下载与安装教程.md](下载与安装教程.md) 表里的版本事实为准。
- **想换界面语言**：应用内自带语言选择（Android 13 及以上还支持系统级的单应用语言设置），翻译由社区贡献，覆盖度以应用内列表为准。
- **还想查更细的读数**：逐项含义与查看入口在 [仪表盘与硬件信息怎么看.md](仪表盘与硬件信息怎么看.md)。
