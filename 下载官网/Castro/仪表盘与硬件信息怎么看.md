## 一、先看仪表盘（Dashboard）

Castro 打开后的第一屏就是仪表盘，它把「你现在最该知道的」压在一屏里，不想翻菜单就只看这里：

| 卡片 | 你会看到什么 | 什么场景用得上 |
| --- | --- | --- |
| CPU | 各核心频率、使用率 | 玩游戏卡不卡、机器是不是在降频 |
| 电池 | 电量、状态（部分版本含功率） | 判断耗电快是不是硬件问题 |
| 网络 | Wi-Fi / 移动数据的实时用量 | 查哪个应用在偷跑流量 |
| 内存 | RAM 占用与负载 | 手机多任务卡顿时看内存还剩多少 |

卡片数据是实时刷新的，你切回桌面再进来，数值已经换了一轮。个别字段在你装的版本里没有（官方更新日志会逐版增减），以界面实际显示为准。

## 二、信息页（Information）逐项看什么

仪表盘往下是完整的信息页，按硬件分门别类。常用的几类：

- **处理器（CPU / GPU）**：核心数、每颗核心的实时频率、GPU 型号与活跃状态。官方更新日志会持续把新机型补进处理器数据库，方便你对照官网标称规格。
- **电池**：电量、温度、电压、健康状态，支持的机型还会显示循环次数。注意容量一栏可能不准，见 [常见问题与数据误差.md](常见问题与数据误差.md)。
- **内存与存储**：RAM 总量与已用、机身存储占用，用来定位「是谁吃掉了空间」。
- **网络**：Wi-Fi 与移动网络的数据用量、连接状态；Wi-Fi 页还能看到当前网络的安全类型（开放 / WPA2 等）。
- **传感器**：加速度计、陀螺仪、光线、磁力等传感器的**实时曲线**，点进单个传感器能看详情图，采样频率可以直接在详情图上调整。
- **摄像头**：前后摄像头的分辨率、光圈、对焦、防抖（光学防抖，界面里写作 OIS）等参数。
- **编解码器**：设备支持的音视频编解码格式完整列表，装播放器前可以先查这里。
- **蓝牙 / DRM**：蓝牙的支持状态与 DRM 内容保护能力，属于「要用时才查」的信息。

## 三、直接搜索更快

信息项太多时，用**搜索页**直接输入关键词（如 "refresh"、"battery"），不用逐层翻菜单。搜索页有个省心的设计：**即使你没授予权限，搜索结果照样能出信息**（4.7 版起），只是一部分依赖权限的字段会缺失。

## 四、几条读数提醒

- 频率、温度这类数值受厂商上报限制，**波动是正常的**：手机一闲 CPU 就降频，一碰大型应用又拉上去，看到忽高忽低不代表坏了。
- 部分字段（屏幕密度、电池容量等）存在已知误差场景，官方 FAQ 专门列过，先看 [常见问题与数据误差.md](常见问题与数据误差.md) 再下结论。
- 想把整份参数存档发给维修师傅或买家，用导出功能，流程见 [数据报告导出与分享.md](数据报告导出与分享.md)。
- 某个数值可疑、想换一个工具交叉核对，或者要查内核版本这类 Castro 没有的底层信息，见 [和其他硬件检测工具怎么选.md](和其他硬件检测工具怎么选.md)。
