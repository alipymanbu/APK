# touchHLE 的 ipa 导入与游戏运行教程（安卓版）

> 本篇讲游戏文件放哪个目录、怎么放进去、怎么运行，以及存档放在哪。还没装好的先看 [下载与安装教程.md](下载与安装教程.md)；想先确认某个游戏能不能跑，看 [能玩哪些游戏与兼容性查询.md](能玩哪些游戏与兼容性查询.md)；换机要带走进度，看 [存档备份与换机迁移.md](存档备份与换机迁移.md)。

安卓版 touchHLE 只有图形界面（应用选择器），没有命令行，所以「把 ipa 文件放进指定目录」是运行游戏唯一的入口。整个过程分三步：拿到能跑的 ipa → 放进 `touchHLE_apps` 目录 → 在应用选择器里点开。

## 一、先确认你手里的 ipa 能不能用

不是随便一个 iPhone 游戏 ipa 都能跑，放进目录前先过三条：

1. **要是 iPhone OS 2.x / 3.0 时代的 32 位应用**，新 iOS 时代的游戏一律不支持；
2. **ipa 必须是已解密的**（官方说明 app binary 需为 decrypted），App Store 原始下载的那种加密包无法使用；
3. **版本要对**——同一个游戏不同版本之间兼容性差别很大，兼容库里标注能跑的往往只是特定版本（有玩家实测提醒过「一般要求 1.0 的，版本不对打不开」），具体去 [能玩哪些游戏与兼容性查询.md](能玩哪些游戏与兼容性查询.md) 里说的官方兼容库查。

## 二、游戏文件放在哪个目录

```text
/Android/data/org.touchhle.android/files/touchHLE_apps/
```

两点注意：

- 这个目录**要等你至少运行过一次 touchHLE 才会生成**，刚装完找不到属于正常；
- `/sdcard/Android/` 不是 SD 卡，它是手机内置存储的公共入口；在较新的安卓版本里，普通文件管理器不一定能直接浏览 `Android/data`，方法见下一节。

存档则放在同级的 `touchHLE_sandbox` 目录：

```text
/Android/data/org.touchhle.android/files/touchHLE_sandbox/
```

## 三、三种把文件放进去的方法

### 方法 1：touchHLE 自带的 File manager 按钮

打开 touchHLE，点 **File manager** 按钮，会唤起一个文件管理界面，把 ipa 复制进 `touchHLE_apps`。注意：官方 FAQ 承认部分机型上这个按钮会正常打开文件管理器，但一执行复制操作就崩溃（疑似安卓系统层面的问题）。遇到这种情况：从最近任务里清掉它，改走方法 2 或 3。

### 方法 2：用系统自带的文件管理器

在系统的「文件管理 / Files」应用里找 touchHLE（它通常会与网盘应用并列出现在侧栏或存储列表里），从那里进它的数据目录放文件。不同厂商的系统限制不一样，有的能直接进 `Android/data`，有的不行；不行就用方法 3。

### 方法 3：ADB（不熟悉就用网页版）

用浏览器打开 `https://yume-chan.github.io/ya-webadb/`（需要 Chrome 这类支持 WebUSB 的浏览器），手机用 USB 连电脑并允许调试，然后按路径找：`sdcard` > `Android` > `data` > `org.touchhle.android` > `files` > `touchHLE_apps`，把 ipa 拖进去即可，全程不用装任何驱动。

## 四、运行与退出

1. 把 ipa 放好后重新打开（或返回）touchHLE 的应用选择器，游戏图标会出现在列表里；
2. 点图标启动游戏，画面就是这款应用当年的原始分辨率与方向（多数早期游戏为竖屏，也有横屏作品）；
3. 触屏手机直接用手指操作；接了手柄的玩法见 [手柄与重力感应操作设置.md](手柄与重力感应操作设置.md)。

## 五、存档与备份

游戏产生的存档都在 `touchHLE_sandbox` 目录里（见第二节）。换机迁移、完整备份与清进度重玩的具体操作，见 [存档备份与换机迁移.md](存档备份与换机迁移.md)。

## 六、部分游戏支持局域网双人

官方对少量游戏提供了 Wi-Fi 局域网多人支持，目前包括 Asphalt 4 和 N.O.V.A.。玩法：

1. 两台以上设备装好 touchHLE，连**同一个 Wi-Fi**；
2. 在应用的 Quick options 里打开 **Network access**（网络访问）；
3. 在游戏内建主 / 加入房。

不支持蓝牙，也不支持跨互联网联机（走 VPN 隧道官方不承诺可用，但有人反馈能通）。真机 iPhone 与模拟器之间也可以互相加入。
