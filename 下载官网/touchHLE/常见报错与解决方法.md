# touchHLE 常见报错与解决方法

> 本篇按症状列 touchHLE 在安卓手机上的常见问题：装不上、列表里看不到游戏、点了就退、文件管理器崩溃。还没装的先看 [下载与安装教程.md](下载与安装教程.md)；游戏文件的放置方法见 [ipa导入与游戏运行教程.md](ipa导入与游戏运行教程.md)。

安卓版 touchHLE 的问题集中在两头：一头是安装环节（64 位门槛），另一头是放游戏文件环节（安卓存储权限限制）。下面的每一条都标了症状、原因和处理办法，按你遇到的报错对号入座。

## 一、安装时提示「App not installed.」

**这是安卓版被问得最多的问题。**

- 原因：你的手机不支持 64 位应用。touchHLE 的安卓包只有 64 位版本，装不上不是文件坏了；
- 判别：有一部分手机处理器本身是 64 位的，但系统用户层只支持 32 位应用（官方 FAQ 专门吐槽过这种「64 位处理器 + 32 位系统」的组合），这类机型从硬件参数上根本看不出来，只有装的时候才知道；
- 处理：没有绕开的办法，官方也不会为这类机型出 32 位包。只能换一台支持 64 位应用的手机。

## 二、游戏 ipa 放进去了，应用列表里却没有它

按顺序检查：

1. **目录对不对**——安卓版只认 `touchHLE_apps` 这个目录（完整路径见 [ipa导入与游戏运行教程.md](ipa导入与游戏运行教程.md)），放错到别处不会被扫到；
2. **有没有先跑过一次**——这个目录要等你至少启动过一次 touchHLE 才会生成，新装完就找目录会扑空；
3. **文件是不是 ipa 或 .app bundle**——其他格式不会显示；
4. **ipa 是否已解密**——加密状态的 ipa 无法使用；
5. 还不行就重启一次 touchHLE 再看列表。

## 三、点游戏图标秒退、画面一闪就崩

按可能性从高到低：

1. **游戏不在已知可跑列表里**——绝大多数报「能安装不能玩」的情况都是这个。先去 [能玩哪些游戏与兼容性查询.md](能玩哪些游戏与兼容性查询.md) 说的兼容库核对；
2. **版本不对**——数据库里标注能跑的往往是特定版本（常见是 1.0），换个版本再试；
3. **文件损坏或加密**——来路不明的 ipa 常见这个问题，换一份干净的文件；
4. **touchHLE 版本太旧**——兼容性随版本更新在变好，旧版跑不了的游戏可能新版能跑，去官方发布页拿最新稳定版试试。

一个桌面版的补充（如果你同时在电脑上用）：已知游戏能跑但秒崩的话，检查有没有开 Steam / Discord / RivaTuner 这类覆盖层（overlay）——它们靠注入其他程序工作，会把 touchHLE 带崩，关掉覆盖层再试。

## 四、点了 touchHLE 里的 File manager 按钮，打开文件管理器就崩溃

这是官方 FAQ 里承认的已知问题：部分机型上这个按钮能打开文件管理器，但一执行文件操作就会崩（官方认为大概率是安卓系统的问题，他们也没法修）。

- 处理：把崩掉的那个文件管理器从最近任务里清掉，**别再从 touchHLE 的界面进**，直接打开你手机自己的文件管理器应用，手动找到 touchHLE 的目录操作；
- 找不到目录入口的话，改用 ADB 方式放文件，方法见 [ipa导入与游戏运行教程.md](ipa导入与游戏运行教程.md)。

## 五、想清空某个游戏的存档重新开始

存档不在游戏文件里，单独放在 `touchHLE_sandbox` 目录（与 `touchHLE_apps` 同级）。删掉里面对应游戏的数据就能从头开始；换机迁移与完整备份的步骤见 [存档备份与换机迁移.md](存档备份与换机迁移.md)。

## 六、以上都对不上怎么办

先确认你的 touchHLE 是不是最新稳定版（官方每隔几个月发一版，兼容问题和 bug 常随版本修复）；还不行就去官方渠道翻：

- 官方 FAQ：[https://touchhle.org/faq.html](https://touchhle.org/faq.html)
- 源码仓库的 issue 区：[https://github.com/touchHLE/touchHLE](https://github.com/touchHLE/touchHLE)
