# touchHLE 能玩哪些游戏与兼容性查询

> 本篇讲 touchHLE 的兼容范围：哪些年代、哪些游戏能跑，以及去哪查某个游戏能不能跑。找好游戏之后怎么放进手机，见 [ipa导入与游戏运行教程.md](ipa导入与游戏运行教程.md)；装模拟器本身，见 [下载与安装教程.md](下载与安装教程.md)。

> [!IMPORTANT]
> **touchHLE 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/a5b5a3d5813d](https://pan.quark.cn/s/a5b5a3d5813d)

先把预期摆正：touchHLE 只针对早期 iPhone OS 时代的应用，而且**不是这个时代的游戏就都能跑**——官方说法是绝大多数老游戏目前也跑不了，能玩的是其中一小部分。动手找游戏之前先查兼容库，能省掉绝大部分无用功。

## 一、兼容范围一句话说清

| 问题 | 答案 |
| --- | --- |
| 支持哪个年代 | iPhone OS 2.x 和 3.0 时代的应用，大致是 2008~2011 年前后的 iPhone / iPod touch 游戏 |
| 支持什么架构 | 32 位应用（那个年代的应用都是 32 位） |
| 支持新 iOS 游戏吗 | 不支持。64 位 iOS（iOS 7 以后）明确永远不会支持 |
| 这时代的游戏都能跑吗 | 不能。绝大多数 iPhone OS 2.x / 3.x 游戏目前跑不了，能玩的主要是游戏类（工具类应用支持优先级低） |
| 以后会全兼容吗 | 官方明确说永远不会达到 100% 兼容，兼容性只会随时间慢慢变好 |

一句话：这不是「装上就能玩一切 iOS 游戏」的模拟器，它是给早期 iPhone 游戏做保存的项目。冲着「在安卓上玩现代 iOS 应用」来的，这个工具满足不了你。

## 二、怎么查某个游戏能不能跑

官方维护了一个由玩家共同上报的兼容性数据库：

- **App compatibility database**：[https://appdb.touchhle.org/](https://appdb.touchhle.org/)

查的时候注意三点：

1. **搜到游戏名还不够，要核对具体版本号**。同一个游戏不同版本兼容性差别很大，数据库里标注能跑的往往只是某个特定版本（比如 1.0），版本不对很可能打不开；
2. 数据库是玩家上报的，可能有过时或错误的信息，遇到与实际不符的可以按数据库里的说明反馈；
3. 数据库查不到的游戏，也可以翻源码仓库里的 [APP_SUPPORT.md](https://github.com/touchHLE/touchHLE/blob/trunk/APP_SUPPORT.md) 支持列表，两处口径基本一致。

## 三、去哪找能合法获取的老游戏

找到了能跑的游戏名，安装文件从哪来是个现实问题。官方专门建了一个应用档案库，收录了部分老游戏的合法下载：

- **touchHLE app archive**：[https://touchhle.org/app-archive/](https://touchhle.org/app-archive/)

两个提醒：

- 档案库只收录了「某些」老作品，不是全部；不在里面的游戏要你自己用合法途径取得；
- 官方对版权口径很明确：只用 touchHLE 模拟你合法获得授权的软件。网上第三方渠道打包的 ipa 来路不明（可能损坏、加密或被改过），跑不起来往往是文件本身的问题。

## 四、游戏放进去了但跑不了

最常见的原因按顺序排：游戏本身不在已知可跑列表里；版本不对；文件损坏或仍处于加密状态。逐条排查的步骤写在 [常见报错与解决方法.md](常见报错与解决方法.md) 里。

另外，官方明确**不接受「求支持某某游戏」的请求**——某个游戏未来能不能跑，取决于有没有开发者愿意为它补功能，催是催不来的。
