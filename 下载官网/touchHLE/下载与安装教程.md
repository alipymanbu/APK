# touchHLE 下载与安装教程（安卓手机）

> 本篇讲怎么把 touchHLE 装到安卓手机上，以及装不上时先检查什么。装好之后把游戏放进去的步骤，见 [ipa导入与游戏运行教程.md](ipa导入与游戏运行教程.md)；各种报错对症下药，见 [常见报错与解决方法.md](常见报错与解决方法.md)。

---

> [!IMPORTANT]
> **touchHLE 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/a5b5a3d5813d](https://pan.quark.cn/s/a5b5a3d5813d)

touchHLE 是一个开源的 iPhone OS 高层模拟器，目标是运行 2008~2011 年前后 iPhone OS 2.x / 3.0 时代的 iPhone 和 iPod touch 应用（以游戏为主）。它同时有 Windows、macOS 和安卓版本，本篇只讲安卓版：安装包很小（15MB 左右），但有一个硬性前提——你的手机必须支持 64 位应用，这也是绝大多数人装不上的原因。

## 一、装之前先确认这几点

| 项目 | 说明 |
| --- | --- |
| 硬性要求 | 手机必须支持 **64 位（AArch64）应用**。官方 FAQ 明确：32 位应用的手机装不上（见下文「App not installed」） |
| 一类特殊机型 | 有少量手机是「64 位处理器 + 32 位系统用户层」的组合（官方原话叫 64-bit phone with a 32-bit-only userland），这类机型处理器本身是 64 位的，但系统只跑 32 位应用，同样装不上，没有绕开的办法 |
| 安装包大小 | 安装包为 **15.19M** |
| 包名 | `org.touchhle.android` |
| 版本 | 网盘那份的版本标记为 `android`（即安卓平台版）；官方稳定版每隔几个月发布一次，截至本文撰写时官方最新稳定版是 v0.2.3，以官方发布页为准 |
| 系统要求 | 安装包信息里标注为「安卓 5.2 以上」。注意安卓官方版本号里并没有 5.2 这个版本，这一栏实际意义不大，真正的门槛是上面那条「支持 64 位应用」 |

怎么快速判断自己手机能不能装：在系统设置里搜「64 位」，或者直接试着安装，出现 `App not installed.` 就基本是 32 位用户层的问题（见 [常见报错与解决方法.md](常见报错与解决方法.md) 第一条）。

## 二、从哪下载

- **touchHLE 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/a5b5a3d5813d](https://pan.quark.cn/s/a5b5a3d5813d) —— 转存后把 APK 下到手机直接装，版本信息见上面的表格。
- **官方渠道**：官网 `https://touchhle.org/` 的[下载页](https://touchhle.org/download/)，稳定版放在 [GitHub Releases](https://github.com/touchHLE/touchHLE/releases) 里，APK 与 Windows、macOS 版本在同一页。另有从最新代码自动构建的预览版（trunk builds），官方明确不推荐普通用户使用，而且需要登录 GitHub 才能下载。

只认官网 `https://touchhle.org/` 这一个官方网站；项目组在 FAQ 里专门提醒过，其他自称代表 touchHLE 的站点与账号都不可信。

## 三、安装步骤

1. 从上面任一渠道把 APK 文件拿到手机上（网盘转存后下载，或手机浏览器直接从 GitHub Releases 下载）；
2. 在文件管理器里点这个 APK，系统会提示「未知来源应用」——允许该来源安装（不同系统叫法略有差别，一般在弹窗里给该文件管理器授权即可）；
3. 等安装完成，桌面会出现 touchHLE 图标；
4. **先打开一次再退出**——安卓版的数据目录（放游戏用的 `touchHLE_apps` 文件夹）要等你至少运行过一次 touchHLE 之后才会生成，这一步不能省。

## 四、装好了但里面是空的？

这是正常现象。安卓版打开后只会看到一个应用选择器（app picker），你还没往里放游戏 ipa 文件，列表自然是空的。把游戏文件放进去的完整步骤见 [ipa导入与游戏运行教程.md](ipa导入与游戏运行教程.md)；先去 [能玩哪些游戏与兼容性查询.md](能玩哪些游戏与兼容性查询.md) 确认哪些游戏确实能跑，再动手找文件，能少走很多弯路。
