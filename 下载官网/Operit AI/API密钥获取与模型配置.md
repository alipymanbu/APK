## 一、先搞清楚：为什么需要 API 密钥

你在这款 App 里发出的每条消息，最终都要由某个大模型来处理。云端模型按用量计费，App 需要凭一把「密钥」（API Key）替你向模型服务商发起请求、计入你的账户。所以流程是：先在模型服务商那里注册并创建密钥，再把密钥填进 Operit。

不想用云端接口的话，也可以走本地模型路线（在手机上跑离线模型），见本文第五节；但本地路线对设备性能和存储要求高，第一次配置建议先用云端接口把流程跑通。

## 二、拿一枚密钥的通用步骤

各家服务商的界面不同，套路一致：

1. 打开服务商的开放平台官网，注册账号（以 DeepSeek 为例，开放平台入口在 [platform.deepseek.com](https://platform.deepseek.com/api_keys)，官方接口说明见 [api-docs.deepseek.com](https://api-docs.deepseek.com/)）；
2. 在控制台里找到「API Keys」或「API 密钥」页面，点创建，名字随意（比如填 operit，方便以后认出这把钥匙用在哪）；
3. 复制生成的密钥（通常是 `sk-` 开头的一长串）。多数平台密钥只完整显示这一次，关掉窗口就再也看不全，当场存好；
4. 确认账户有可用额度：多数服务商按 token 计费，新账户是否有免费额度、怎么充值，以服务商页面为准。

## 三、可以选哪些服务商

官方支持的云端服务商覆盖面很广（OpenAI、Anthropic、Gemini、DeepSeek、智谱、月之暗面、OpenRouter、SiliconFlow、阿里云通义、百度文心等，完整列表见官网 [operit.app](https://operit.app/)），另外还支持任何 OpenAI 兼容的自定义端点。选择上的几点实际差异：

| 考虑因素 | 说明 |
| --- | --- |
| 国内直连 | 选国内服务商（DeepSeek、智谱、通义、文心等）不需要额外网络条件；OpenAI、Anthropic、Gemini 在国内访问有门槛 |
| 价格 | 各家按 token 计费的价格差异不小，看服务商的定价页，别只看对话效果 |
| 一把钥匙多家模型 | OpenRouter 这类聚合平台一枚密钥可以调多家模型，适合想多试几家的 |
| 视觉/识图 | 如果你打算发图片让 AI 分析，要选支持视觉的模型，纯文本模型收不了图 |

不确定就先选一家国内的、文档写得清楚的，把流程跑通，之后随时可以加别的配置。

## 四、把密钥填进 Operit

App 支持多套模型配置、参数调整、密钥池和连接测试（官方 README 的能力清单里有明说）。一般操作路径：

1. 打开 Operit 的模型/供应商设置页，新建一个模型配置；
2. 选服务商（或「自定义兼容接口」），填入接口地址（Base URL，如 DeepSeek 的 `https://api.deepseek.com`）、API 密钥、模型名；
3. 保存后点「连接测试」，出现回复即配置成功；
4. 进阶：可以给不同任务分不同模型——聊天、记忆整理、总结、界面控制可以分别指定模型配置；多枚密钥也可以组成密钥池轮换。

模型名要和服务商当前提供的名称一致（会随版本更新变化，以服务商文档为准），填错名字是连接测试失败最常见的第二大原因，第一大是密钥粘错。

## 五、本地模型这条线

不打算花钱调用云端接口，或者在意数据不出手机，可以走离线路线：

- 内置 MNN 支持或通过 llama.cpp 跑 GGUF 格式的本地模型；
- 也可以连接局域网里的 Ollama、LM Studio 等本地模型服务。

本地模型的效果和速度取决于手机性能，模型文件本身通常也要占不少存储。手机能跑多大的模型、量化格式怎么挑，见 [本地模型离线运行教程.md](本地模型离线运行教程.md)；遇到具体问题再看 [常见问题排查.md](常见问题排查.md)。

## 六、密钥安全

- 密钥等同于账户余额的钥匙，别截图外发、别贴进公开文档；
- 怀疑泄露就去服务商控制台删掉旧密钥、重新生成一把；
- Operit 的模型配置存储在本地设备上（官方对数据边界的说明），但仍建议不把装有密钥的 App 留在借给别人的设备上。
