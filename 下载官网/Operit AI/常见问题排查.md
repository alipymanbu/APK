## 一、安装环节

**点了 APK 没反应，或提示「无法解析」**

多半是文件没下完整。重新下载，然后用 MD5 核对（值见 [下载与安装教程.md](下载与安装教程.md) 第二节），一致再装。

**提示「设备不兼容」**

Operit 只支持 Android 8.0 以上、arm64 架构的设备。模拟器大多是 x86 架构，装不上属正常。

**安装时弹「风险提示」「未经过安全检测」**

这个 App 不在应用商店上架，侧装 APK 出现此类提示是正常的，确认继续安装即可。介意来源的话先核对 MD5。

## 二、无障碍服务

这一组问题源于 Android 系统对侧装应用和无障碍服务的限制，多见于国产定制系统，菜单名称以你的手机为准：

**Android 13 以上提示「受限制的设置」，开关点不动**

进系统设置的「应用管理」，找到 Operit AI，进应用详情，点右上角菜单，选「允许受限制的设置」，再回去开无障碍。

**无障碍开了过一会儿自己掉**

后台被系统省电策略清掉了。逐项设置：给 Operit AI 开自启动、把电池策略改成「不限制」/「无限制」、在最近任务里把卡片锁定。这三项在不同系统里的入口不同，设置里搜「自启动」「电池优化」能找到。

**授权时提示「有窗口遮挡」**

悬浮球、护眼模式、侧边栏这类悬浮窗口都会挡住系统授权页，把它们临时关掉，授权完成后再打开。找不到是谁挡的，重启手机再授权。

**开关点了没反应**

先把无障碍授权取消，再重新授权一次；还不行就重启手机。

## 三、Shizuku 与调试模式

**配对时一直「正在搜索配对服务」或输入配对码后立刻失败**

回到系统的「无线调试」页面确认开关状态，关掉再重开，重新拿一组配对码快速填入。完整步骤与更多情况见 [Shizuku调试模式激活教程.md](Shizuku调试模式激活教程.md) 第五节。

**调试能力用着用着失效**

Shizuku 在手机重启后不会自动恢复，重新进 Shizuku 点一次「启动」即可。Shizuku 自身后台被杀的处理思路与无障碍服务相同，见第二节。

## 四、终端环境配置

**配置过程中报错**

第三方教程给出的处理顺序：终端页右下角设置里关闭「共享临时目录」→「存储管理」里点重置 → 重启 App → 回到权限配置页重新走一遍配置。

**配置一直卡在下载**

首次配置要下载一套组件，体积大、耗时长，先确认网络可用、存储空间够（建议留出几个 GB），中途别切后台、别锁屏断网。

## 五、模型连接

**连接测试失败**

按出现概率排：

1. 密钥粘错（缺头少尾、混入空格）——重新完整复制一遍；
2. 模型名填错——模型名要与服务商当前文档里的名称一致（会更新换代，以服务商页面为准）；
3. 接口地址（Base URL）填错——对照服务商文档，比如 DeepSeek 官方接口地址是 `https://api.deepseek.com`；
4. 账户没有余额或额度——去服务商控制台确认。

**对话报 401 / 鉴权错误**

密钥无效或被删了，去服务商控制台重新生成一把，填回 App（见 [API密钥获取与模型配置.md](API密钥获取与模型配置.md) 第六节的安全处理）。

**对话报超时 / 网络错误**

你选的服务商可能需要额外的网络条件（如 OpenAI、Anthropic、Gemini），或当时网络不稳。国内网络环境下优先选国内服务商。

**本地模型加载失败或慢得离谱**

按顺序查：内存够不够（清后台再试）→ 模型文件是否下载完整 → 换更小的参数量或量化版本。完整排查顺序与模型选择建议见 [本地模型离线运行教程.md](本地模型离线运行教程.md) 第四节。

## 六、占用与性能

**安装包就 386 MB，装完占用更大**

安装包 385.54 MB 只是起点：终端环境组件、工具包、聊天数据、本地模型文件都会继续占空间。跑本地模型前按所选模型的要求预留空间（官方对资源占用的说明也是如此）。

**手机发热、发烫明显**

本地模型推理、长时间界面自动化、多终端会话都是高负载操作。改用云端接口推理、关掉不用的终端会话可以明显缓解。

**后台经常被杀**

与无障碍被杀是同一个原因，处理办法见第二节；另外 App 内置的局域网网页对话与 HTTP API 默认是关闭的，不用就不要开，减少后台暴露面。
