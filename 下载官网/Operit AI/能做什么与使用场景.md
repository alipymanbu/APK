## 一、按权限分层的能力清单

同一个 App，授权越多能干的事越多。你可以按这张表决定自己停在那一层：

| 授权层级 | 你能做的事 | 典型例子 |
| --- | --- | --- |
| 基础（无特殊权限） | AI 对话、多模型切换、语音输入与朗读、角色卡与记忆、深度搜索、读文档图片音视频并回答 | 长对话写东西、整理资料、语音陪聊 |
| 无障碍服务 | 模拟点击、跨应用操作、读屏理解（官方称为 AutoGLM/PhoneAgent 一类的界面自动化） | 让它替你在某个 App 里完成一串点击操作 |
| 调试模式（Shizuku/ADB） | 安装卸载应用、锁应用等更深的系统操作 | 批量管理手机里的应用 |
| 终端环境 | Ubuntu 24.04 用户空间、Python/Node.js、SSH/SFTP、多终端会话 | 手机上跑脚本、连服务器、处理数据文件 |
| 浏览器代理 | 内置浏览器里读页面结构、点击、填表、滚动、截图 | 让它按页面元素自动填一份表单 |

每一层往上的授权成本和风险都在增加。只想对话，停在基础层就行；「调试」与 Root 层级对普通用户收益有限，不必为了「功能全」去开。调试模式需要先激活 Shizuku 服务，步骤单独成篇：[Shizuku调试模式激活教程.md](Shizuku调试模式激活教程.md)。

## 二、几类典型场景拆开看

**查资料、啃文档**：把网页链接、PDF、图片、音视频丢进对话，让它总结、翻译、对照几份材料的差异。深度搜索模式会跨多个引擎检索再汇总。这一层不需要任何额外授权。

**处理文件**：给它一个文件夹，让它重命名一批照片、解压压缩包、把几十个文档做格式转换。文件系统工具在授权范围内读写，你可以把每个工具设成「每次询问」盯紧点。

**手机上写代码**：从项目模板（Web、Android、Flutter、Python 等）建工作区，用内置编辑器改代码、开预览，配合终端环境跑构建。它还能绑定聊天与工作区，让 AI 直接读项目规则、改项目文件。

**定时与自动化**：用可视化工作流把「触发条件 → 执行 → 判断 → 提取数据」串起来。触发方式支持手动、定时、Tasker、意图广播、语音、App 启动时。适合每天定时干一遍的重复事。

**装插件扩功能**：统一市场里搜脚本、ToolPkg、Skill、MCP 服务，一键安装。MCP 支持本地与远程服务（包括 uvx/npx 启动方式）。有用户反馈过远程 MCP 服务在部分机型上有后台被杀导致掉线的情况，遇到时先看[常见问题排查.md](常见问题排查.md)。

**多人格对话**：角色卡支持导入导出（Tavern JSON/PNG 格式）、二维码分享、独立对话历史，还能让多个角色在群里互聊。每个角色可以绑定不同的模型、记忆空间和工具包。

## 三、它做不了或不好做的事

- **没有模型就没法用**：App 本体不带云端大模型，首次使用必须自己配置 API 密钥或本地模型，见 [API密钥获取与模型配置.md](API密钥获取与模型配置.md)；
- **低端设备体验有限**：安装包 386 MB 起，开终端环境、装本地模型后占用继续涨；本地推理速度取决于手机芯片；
- **自动化受系统限制**：国产系统的后台清理会把无障碍服务杀掉，授权层级越高对系统设置的折腾越多，这部分坑集中写在 [常见问题排查.md](常见问题排查.md)；
- **不是所有手机都支持**：仅限 Android 8.0 以上、arm64 架构。

## 四、从哪开始试

把两篇前置教程走完（安装、权限、模型配置各一篇），然后从基础层的对话和搜索开始，熟练一层再开下一层权限，是最省心的路径。
