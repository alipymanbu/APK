## 一、安装前先确认你的设备够不够

官方对设备的要求（见官方仓库 [github.com/AAswordman/Operit](https://github.com/AAswordman/Operit) 的 Quick Start 一节，以官方页面为准）：

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 系统版本 | Android 8.0（API 26）及以上 | 低于 8.0 的机型装不上，别勉强 |
| CPU 架构 | 仅支持 arm64（arm64-v8a） | 常见手机都满足；x86 架构的模拟器、老平板不支持 |
| 存储空间 | 安装包约 386 MB，另需预留余量 | 如果后续要配置终端环境或跑本地模型，占用还会继续增长，建议预留几个 GB |

查自己手机架构：设置里搜「关于手机」或「处理器」，一般能看到 arm64 / aarch64 字样；近几年出货的安卓手机几乎全是 arm64。

## 二、安装包是哪一版

网盘里这份安装包的核对信息（以安装包文件本身为准；官方仓库会持续更新，装的时候官方可能已有更新版本）：

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.12.2 |
| 包名 | com.ai.assistance.operit |
| 安装包大小 | 385.54 MB |
| MD5 | 2D41F3E1700679B70E8DD4476DE05479 |
| 信息核对时间 | 2026-09-27 |

想核对文件完整性：手机文件管理器多数自带「文件校验」或属性里的 MD5 值；电脑上可用 PowerShell 执行：

```powershell
Get-FileHash "下载的文件名.apk" -Algorithm MD5
```

算出的值与上表 MD5 一致，说明文件没在传输中损坏。不一致就重新下载一次。

## 四、安装步骤

1. 把安装包下载到手机存储（网盘 App 里转存后下载，或电脑下载后传到手机）。
2. 在文件管理器里点这个 `.apk` 文件。第一次装会弹出「是否允许此来源安装应用」之类的提示，选择允许（不同系统的菜单名称略有差异）。
3. 继续点安装，等进度条走完。
4. 安装过程中如果弹出「风险提示」「未经过安全检测」之类的话——Operit AI 不在应用商店上架，侧装 APK 出现这类提示是正常现象，确认继续即可。如果你对来源有顾虑，回到上一节核对 MD5。
5. 装完点「打开」，进入首次启动流程。

装完不是马上能用：第一次打开要做一轮权限与模式配置，否则大量功能是关着的。接下来照着 [首次启动与权限配置.md](首次启动与权限配置.md) 做一遍即可。

## 五、装不上时的几种情况

- 点了没反应或提示解析失败：多半是下载不完整，重新下载并核对 MD5。
- 提示设备不兼容：回到第一节查系统版本和架构。
- 装好了但打开闪退：先确认系统版本达标；还不行看 [常见问题排查.md](常见问题排查.md)。
