# tTorrent 锁屏后下载停止怎么办

> 熄屏后 tTorrent 下载变慢或停住，多半是安卓的电池优化在限制后台 —— 这是系统行为，不是应用坏了，几个设置就能解决。

## 一、先判断是不是后台被限制

典型表现：熄屏几分钟后速度归零或任务不动，亮屏解锁后马上恢复。

这类问题出在安卓系统而不是 tTorrent 本身 —— 电池优化开启时，系统会在内存紧张或熄屏后限制 / 回收后台应用，长时间联网的下载应用首当其冲。各品牌手机的后台策略差异很大（小米、华为、三星各有自己的省电逻辑），[dontkillmyapp.com](https://dontkillmyapp.com/general) 收录了各家的情况与解法。

## 二、把 tTorrent 移出电池优化

通用路径（安卓 6+，各品牌入口略有差异，以你的手机实际菜单为准）：

1. 设置 → 应用 → tTorrent → 电池 → 电池优化 → 切到「所有应用」→ 找到 tTorrent → 选「不允许优化」（Don't optimize）；
2. 部分品牌入口在 设置 → 电池 → 电池优化（或 电池使用详情）里；
3. 顺手检查 tTorrent 的应用信息里有没有「后台限制」「后台运行权限」被关掉 —— 有就打开。

找不到入口的话，直接在手机设置里搜「电池优化」或「后台」关键字最快。

## 三、挂机下载的配套做法

- 挂机时关掉省电模式 / 超级省电 —— 它们会连同后台一起掐；
- 下载期间让 tTorrent 的通知留在通知栏，划掉通知或强制停止都会中断任务；
- 大文件挂机尽量插着电 + 仅 WiFi 模式（见[使用入门与首次设置.md](使用入门与首次设置.md)第一节）；
- 熄屏后速度变慢但没归零，则更可能是网络或存储写入的问题，排查思路见[下载速度慢怎么办.md](下载速度慢怎么办.md)。
