## 一、第一次打开的三件事

1. **授予存储权限**：不给权限就没法保存文件；如果之后标题栏出现 `Free space: 0 B`，是权限丢了，处理方法见[存储路径与SD卡权限.md](存储路径与SD卡权限.md)。
2. **确认保存路径**：默认在 `/sdcard/torrent`，想改到别的位置（包括 SD 卡）去 设置 / Directories 里调整。
3. **打开仅 WiFi 模式**：官方功能列表里有「Wifi only mode」；大流量下载走移动网络前，先确认套餐余额。

挂机下载前还有一件事：把 tTorrent 移出电池优化，否则熄屏后任务会被系统掐掉（见[锁屏后下载停止怎么办.md](锁屏后下载停止怎么办.md)）。

## 二、没有内置搜索，怎么找种子

官方因应用商店政策移除了内置搜索（官方 FAQ 有说明）。现在把任务加进来的常用方式：

- 用浏览器找到 `.torrent` 文件，点开时在系统弹窗里选择用 tTorrent 打开；
- 复制磁力链接（`magnet:` 开头），在 tTorrent 里新建任务粘贴；
- 应用支持 DHT（无 tracker 任务），磁力链接没有 tracker 也能连上来源。

tTorrent 只下载你指定的任务，下到什么完全取决于你选了什么种子 —— 只从可靠来源取种。

## 三、多文件种子里只挑部分下载

一个种子里有几十个文件时不必全下：

- 在任务详情的 Files 标签里按优先级控制：`0` 不下载，`3` 最高优先级，数字越大越先完成；
- 想边下边看就用顺序下载（官方写作 sequential download mode / streaming），按片顺序取数据，开头部分先就绪，但整体完成时间会变长。

## 四、用标签分组管理

标签（Label）可以给任务归类，每个标签还能指定自己的保存路径 —— 比如把「剧集」「软件」分开落到不同目录，配合 RSS 订阅尤其有用（见[远程控制与RSS订阅.md](远程控制与RSS订阅.md)）。

## 五、任务下完之后

- 文件默认在 `/sdcard/torrent`，也可以在详情页 Files 标签里直接点开；
- tTorrent 只负责下载，打开文件要靠对应的播放器 / 阅读器；下载完的视频没声音是常见情况，处理见[常见问题与解决办法.md](常见问题与解决办法.md)。
