## 一、文件默认下到哪

默认目录是 `/sdcard/torrent`。任务详情页的 Files 标签里也可以直接点开已下载的文件。

## 二、外置 SD 卡写权限（安卓 5.0 起）

从 1.5.2 版起，tTorrent 支持把文件写到外置 SD 卡，但需要你手动授一次权：

1. 进入 设置 / Directories / External storage access；
2. 选中 SD 卡的根目录完成授权；
3. **换一张 SD 卡就要重新做一次**。

另外三点官方 FAQ 与设置页会用到：

- 1.8.5 起有「先下载到应用私有目录」的选项，SD 卡写入慢或存储选择框架（Storage Access Framework）出问题时可以试它；
- 即使把数据目录设在 SD 卡，任务列表与 fastresume 数据仍存在应用私有目录里；
- 目录设置里还有两个实用项：**Move completed torrents**（任务下完自动移到另一个目录，只对下到默认目录的任务生效）和 **Run media scanner**（下完的文件立刻出现在相册 / 媒体库里）。

## 三、单文件 4GB 上限（FAT32）

- FAT32 格式的分区单个文件最大 4GB，应用会检测文件系统并自动应用这个限制；
- 整个种子可以超过 4GB，只是其中**单个文件**不能超过；
- 要下单个超过 4GB 的文件，把保存位置换到 exFAT 等支持的文件系统。

## 四、标题栏显示 Free space: 0 B

原因：默认保存路径的存储权限丢了。

处理：到保存路径设置里**重新选择同一个文件夹**，重新授一次权即可恢复。

## 五、卸载会删掉什么

- 卸载应用时，`/Android/data/hu.tagsoft.ttorrent.noads` 目录下的内容会被系统一并清掉；
- 你自己指定的自定义保存路径（如 SD 卡上的普通目录）不受影响，不用时自己手动清理即可。
