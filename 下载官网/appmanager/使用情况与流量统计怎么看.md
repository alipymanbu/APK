## 一、先解决「菜单里根本没有这项」

这组统计依赖系统的**「使用情况统计信息访问」（Usage Access）**权限。官方手册写明：如果这项功能在设置里被禁用，「应用程序使用情况」这个菜单项**根本不会列出来** —— 所以「找不到入口」通常不是版本问题，是权限/开关没开。

按这个顺序处理：

1. 进 App Manager 的设置，确认使用情况相关的功能开关是启用状态；
2. 到系统设置里给 App Manager 授予「使用情况访问 / 使用情况统计信息权限」（不同机型叫法与路径略有差异，一般在特殊应用权限或应用授权管理里）；
3. 回到 App Manager，选项菜单里就该出现「应用程序使用情况」了。

## 二、从哪进、能看什么

入口是主页的**选项菜单 → 应用程序使用情况**。它展示的是系统聚合出来的三类数据：

| 指标 | 含义 |
| --- | --- |
| 屏幕时间 | 该应用在前台占用屏幕的时长 |
| 数据流量 | 移动网络与 Wi-Fi 分开统计 |
| 打开次数 | 你启动该应用的次数 |

应用详情页里也会显示用量与存储信息，同样以使用情况访问权限为前提。

## 三、和「正在运行的应用」怎么配合看

选项菜单里的「正在运行的应用」是另一个页面：列出当前进程及其内存、缓存占用（可用时），可以对进程强行停止或结束（需要 ADB 或 root，见 [三种运行模式说明.md](三种运行模式说明.md)）。

两个页面回答的是不同问题：**用量统计**看的是「这段时间它用了多少」，**运行中应用**看的是「此刻它在不在跑」。注意无 root 模式下，运行页只显示 App Manager 自己的运行情况 —— 这是权限边界，不是数据丢了。

## 四、两个容易踩的点

- **权限一撤，统计就断**：这组数字来自系统对该权限的持续授权，中途撤掉权限再开，之前那段不会补回来。
- **别拿新版本的功能对照旧包**：官方在 v4.1.0 才给应用使用情况加了柱状图之类的展示（官方更新日志可查），网盘这份是 4.0.5 —— 界面上少了什么新效果属正常，以应用内实际显示为准。
