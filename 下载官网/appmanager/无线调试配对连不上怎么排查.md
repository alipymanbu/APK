# 无线调试配对连不上怎么排查

> ADB 模式最常见的翻车点：配对码输不对、连上又断。按现象逐条排查。

## 〇、先满足两个前提

- **系统版本**：无线调试是 Android 11（API 30）及以上才有的功能，老系统走 ADB over TCP + 电脑那条路。
- **开发者选项已开、USB 调试已开**：无线调试的入口就在开发者选项里，这两个开关是前置条件（「关于手机」里连点版本号 7 次可唤出开发者选项，不同机型入口位置略有差异）。

## 一、找不到「无线调试」入口

说明开发者选项没开或没生效：确认「关于手机 → 连点版本号 7 次」后，回设置里找「系统 → 开发者选项」（小米等机型在「更多设置」里）。入口出现后再看 USB 调试是否已勾选。

## 二、点配对后报失败 / 连接被拒绝

按顺序查这四项：

1. **是不是同一网络**：走电脑 `adb pair` 时，手机和电脑必须在同一个 Wi-Fi；有线电脑 + 同一局域网也可以。
2. **企业 Wi-Fi 可能屏蔽 P2P**：官方 ADB 文档明确提到，安全型网络（例如企业 Wi-Fi）可能屏蔽无线连接 —— 换成普通 Wi-Fi 或改用 USB 线试一次即可定位是不是网络的锅。
3. **端口用错了**：「配对端口」和「连接端口」是两个不同的数字，都显示在无线调试页面里；配对阶段只能用配对窗口里那个配对端口。
4. **配对码过期**：配对码与端口会变。重新打开无线调试页面拿一组新的码，在有效期内尽快输完；失败了就重开一次再试。

## 三、用电脑配对时，电脑端发现不了设备

官方 ADB 文档的诊断点：`adb` 依赖 mDNS 自动发现设备，如果设备上 `mdns_enabled` 为 `false`，就无法自动发现 —— 把环境变量 `ADB_MDNS` 设为 `1` 后重启 adb 服务：

```bash
adb kill-server
adb start-server
```

改完仍发现不了，就跳过自动发现，在无线调试页面读出 IP 与端口手动 `adb connect`。

## 四、配对成功，过一会儿按钮又变灰

两种正常原因：

- **重启过手机**：无线调试重启即关，重新配对即可（同 [常见问题与故障排查.md](常见问题与故障排查.md) 第二节）；
- **换了 Wi-Fi**：连接建立在「同一网络」上，切网后旧连接立即失效。

App Manager 自己的策略是：先尝试自动连配置好的端口，失败了才让你手动配对或连接；两种接法都不通，它就回落无 root 模式 —— 表现为一批按钮变灰，而不是应用坏了（详见 [三种运行模式说明.md](三种运行模式说明.md) 第四节）。

## 五、两条安全提醒

- 系统在打开无线调试时会弹「无线调试不安全」一类警告：它确实把调试端口暴露在局域网里，用完随手关掉是好习惯。
- 配对用的二维码、配对码别截图外发 —— 拿到它们的人在同一网络里就能对你的设备发起调试连接。

连上之后就能用 ADB 模式安装分包包了，装法见 [APK与分包安装包怎么装.md](APK与分包安装包怎么装.md)。
