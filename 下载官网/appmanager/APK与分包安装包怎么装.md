## 一、它能吃哪些格式

官方功能清单写明：安装/卸载 APK 文件，**包括带 OBB 的 APKS、APKM 和 XAPK**。也就是说这几个常见「装不上」的格式，App Manager 的安装器直接处理，不用再另找工具：

| 格式 | 常见于 | 说明 |
| --- | --- | --- |
| `.apk` | 常规单包 | 最普通的情况 |
| `.apks` | 分包构建产物 | 多个分包，一次装齐 |
| `.apkm` | 某些应用商店的分包 | 同为分包集合 |
| `.xapk` | 带 OBB 数据的打包 | 内含 APK 与 OBB 数据 |

## 二、三种发起安装的方式

1. **从文件管理器点开**：下载目录里点这个文件，系统问「用哪个应用打开」时选 App Manager（可设为始终），随后按提示装。
2. **多选后分享进去**：装分包时在文件管理器里把相关文件一起选中，用「分享」发到 App Manager 的安装入口 —— 这是装一整套分包最省事的路子（有第三方教程按此流程实测过）。
3. **在应用内操作**：对已导出、已备份的 APK，走它的安装入口直接装。

## 三、不同模式下，安装走的路不一样

官方更新日志写明：**root 和 ADB 用户用 shell 安装，非 root 用户走系统默认安装方式**。差别很实际 —— shell 安装能带上更多选项（降级、重装这类选项在它的安装器里就有，老版本更新日志即列出，具体以应用内为准），而系统默认方式就是你平时点 APK 弹的那个安装器，选项由系统说了算。三档模式的区别见 [三种运行模式说明.md](三种运行模式说明.md)。

## 四、安装相关的设置在哪

- **设置 → 安装器**：安装行为的配置项都在这里；较新的版本还引入了「按会话的安装器选项」（v4.0.0 起，网盘这份 4.0.5 已包含，叫法以应用内为准）。
- **设置 → APK 签名**：官方功能清单里有「安装前用自定义签名签 APK」，相关配置在这部分。
- 配 ADB 时安装流程容易被「无线调试断开」打断，排查见 [无线调试配对连不上怎么排查.md](无线调试配对连不上怎么排查.md)。

## 五、装不上时先对这两条

1. **系统提示签名冲突**：多半是换渠道装（F-Droid 版与 GitHub 版签名不同），处理见 [下载与安装教程.md](下载与安装教程.md) 第二节与 [常见问题与故障排查.md](常见问题与故障排查.md) 第六节。
2. **分包没装全**：官方手册对分包安装标注过已知限制 —— 「当前会安装全部分包」，且注明该行为以后可能变化。所以遇到分包安装报错，先确认你拿的是不是完整的一套分包文件；版本较老的说明以官方手册当前内容为准。
