## 一、入口与两大分区

登录后（注册流程见 [注册登录与账号设置.md](注册登录与账号设置.md)），在首页右上角点 Create Character 进入创建器。创建器分两块，作用完全不同：

- **Character Info**：对外展示与搜索用的元数据，多数字段不影响角色行为；
- **Character Definition**：角色的实际定义，这里写什么，角色就按什么来演。

## 二、Character Info：展示与搜索

| 字段 | 填什么 |
| --- | --- |
| Name（必填） | 角色名 |
| Avatar | 头像图，也可以直接导入一张酒馆 PNG 卡的头像 |
| Tagline | 一句话简介，显示在搜索结果里，写成「电梯演讲」最有效 |
| In-Chat Name | 聊天内的名字，可与搜索显示名不同 |
| Creator's Note | 作者备注，纯展示，不进提示词 |
| Tags | 标签，官方规则：少于三个的角色不会出现在搜索结果里 |
| Type | Public（公开）/ Private（仅自己）/ Unlisted（仅链接可见） |
| Rating | 内容分级（SFW / NSFW），按实际内容如实标注 |

## 三、Character Definition：角色的核心

- **Description（必填）**：人设总描述 —— 性格、外貌、背景、行为习惯都写在这里，纯文本即可，格式随意；
- **Initial message（必填）**：开场白，角色在对话开始时逐字说出的第一句。它对整段对话的走向影响很大，值得花心思写长写细；
- **Scenario（选填）**：对话发生的情境与背景；
- **Example dialogs（选填）**：你与角色的示例对话，用来教角色说话的口吻；每段示例之间用 `<START>` 分隔；
- **Alternate greetings（选填）**：备选开场白，开聊时可以左右切换挑选，每条开头同样要加 `<START>`。

## 四、进阶字段

- **System Prompt / Post Hist Instructions**：角色专属的系统提示与对话后置指令，只在开启 Use V2 Spec. 时生效；后置指令想追加而不是整体覆盖，内容里写上 `{{original}}`；
- **Character's Note**：插进聊天记录第 n 个位置的提示，官方建议深度 1~5；
- **Character Book**：内嵌在卡里的世界书，条目配法见 [Lorebook世界书配置教程.md](Lorebook世界书配置教程.md)。

## 五、好用的占位符

写定义与开场白时可以用双花括号占位符，发送给模型前会被替换成实际值：

| 占位符 | 替换成 |
| --- | --- |
| `{{user}}` | 当前聊天的人的名字 |
| `{{char}}` | 角色名 |
| `{{date}}` / `{{time}}` | 当天日期 / 当前时间 |
| `{{random: A, B, C}}` | 从列表里随机取一个 |
| `{{roll: 1d6}}` | 掷骰子返回点数（支持 2d6+1 这类写法） |

例如开场白写 `Hello {{user}}!`，每个人开聊时看到的都是自己的名字。

## 六、发布与返工

点 Create Character 发布，之后要改就进角色页右下角的 Edit 重新进创建器。发布前自查四件事：标签凑够三个（否则搜不到）、Description 与开场白没留空、整卡内容别太薄 —— 官方规则是少于 50 token（约 150~200 词）的卡不会出现在搜索里、分级标注与内容一致。

做得不好的卡聊起来平淡，想提升质感可以参考社区整理的写卡指南（官方创建文档末尾附了一批链接），以及把世界设定拆进世界书而不是全塞进 Description。
