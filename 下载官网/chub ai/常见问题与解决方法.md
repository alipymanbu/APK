## 一、安装环节

| 现象 | 处理 |
| --- | --- |
| 提示「禁止安装未知来源应用」 | 给你用来打开安装包的应用（文件管理器或浏览器）开「允许安装未知应用」，路径见 [下载与安装教程.md](下载与安装教程.md) 第三节 |
| 安装包解析失败、装不上 | 重新下载一次安装包，算 MD5 与 `5D9C672F3F59052B4BEE4A9948D44DC9` 比对；文件传输损坏是最常见原因 |
| 打开就闪退 | 确认系统版本满足要求、存储空间充足；仍闪退就卸载重装一次 |
| 装好了但界面加载空白 | 检查网络后彻底退出重开；首次启动需要联网拉取数据 |

## 二、账号环节

- **收不到注册或重置邮件**：先翻垃圾箱；换一个邮箱再试；部分邮箱服务对海外来信延迟明显，隔一阵再收；
- **用户名被占用**：换个变体（加数字或下划线）；
- **App 登录不上**：先用浏览器打开 `https://chub.ai` 登一次 —— 网页能登上说明账号没问题，问题出在 App 端，清缓存或重装试试；
- **密码忘了**：走登录页的找回流程，重置邮件发到注册邮箱，这也是注册时邮箱必须填对的原因。

## 三、聊天环节

- **发消息没回复**：几乎都是没连模型。到聊天页菜单的 Secrets 里把 API 配好，见 [API连接与模型配置教程.md](API连接与模型配置教程.md)；
- **回复到一半断掉**：多为所连服务的额度用尽或网络波动，稍后重试；用自己的 API Key 时去对应服务后台查余额与限流；
- **角色忘记前面的剧情**：老对话滑出模型上下文所致，用 Chat Memory 生成或手写前情摘要，用法见 [角色查找与聊天入门.md](角色查找与聊天入门.md)；
- **报 429（请求过多）**：官方订阅按单账号限并发，同一账号在多处同时请求会触发，等一会儿再发；
- **换设备后聊天记录不一致**：确认两台设备登录的是同一个账号；对话数据在云端，登录对了一般会自动同步。

## 四、其他

- **搜不到某个角色**：标签少于三个的角色不出现在搜索结果里（官方规则），试着输入完整角色名；想要的卡确实不存在，也可以自己动手做一张，见 [自建角色卡教程.md](自建角色卡教程.md)；
- **想备份聊天记录**：Chat Settings 里把对话导出为 JSONL、PNG 或纯文本；
- **想把角色卡带去 SillyTavern 等其他工具用**：卡的下载与两个方向互通的接法见 [角色卡导出与SillyTavern互通.md](角色卡导出与SillyTavern互通.md)，导入失败多为文件损坏或对方前端版本过旧；
- **内容与尺度**：平台内容来自社区上传，尺度标准以官方条款与页面为准，是否继续使用请自行判断；
- **界面是英文看不懂**：App 内置了语言切换，把界面切成中文的步骤见 [中文界面与中文对话.md](中文界面与中文对话.md)；高频菜单的中文含义对照见 [角色查找与聊天入门.md](角色查找与聊天入门.md) 第四节。
