## 一、世界书解决什么问题

聊得越久，最早的设定越容易滑出模型的上下文范围，角色开始「失忆」。世界书是外挂记忆：你预先定义一批关键词，聊天里提到某个关键词，对应的设定内容就自动注入提示词 —— 平时不占常驻空间，提到才出现。

## 二、两个全局参数

在聊天页的 Chat Settings 里设置：

| 参数 | 含义 | 怎么给 |
| --- | --- | --- |
| Scan Depth | 从最新消息往前扫几条来找关键词 | 2 就是扫最近一问一答；长段剧情可适当加大 |
| Token Budget | 世界书内容允许占用的 token 上限 | 超出后即使关键词命中也不再注入；设定多就给大一点 |

默认匹配规则：大小写不敏感 + 整词匹配 —— 关键词 Apple 能被 apple、aPPle 触发，但 Applebottom 不会。

## 三、条目属性速查

一条条目里可用的属性（条目名本身不进提示词，只用于自己分类管理）：

| 属性 | 作用 |
| --- | --- |
| Keywords | 主关键词，聊天里提到就触发注入 |
| Secondary Keywords | 次关键词，可与主关键词组合成「同时出现才触发」等条件 |
| Content | 命中后实际注入给 AI 的内容 |
| Insertion Order | 多条同时注入时的排序，数值越小越靠前（越靠前 AI 关注度越低） |
| Case Sensitivity | 是否区分大小写 |
| Priority | 超出 token 预算时决定先舍弃谁 |
| Constant | 常驻注入，不看关键词（重要设定用它） |
| Probability | 触发后按百分比注入，做随机氛围用 |
| Recursive Scanning | 允许条目互相触发，做有依赖关系的复杂设定 |

## 四、创建与挂载

1. **创建**：独立世界书用官方 Lorebook Creator（`https://chub.ai/create_lorebook`）；跟随角色的内嵌书在角色创建器里加 Character Book，做法见 [自建角色卡教程.md](自建角色卡教程.md) 第四节；
2. **挂到聊天**：打开 Chat Settings，从官方世界书库（`https://chub.ai/lorebooks`）找到想用的书，在卡片右下角菜单里 Copy Path 复制路径（形如 `lorebooks/作者/书名`），粘贴进输入框并确认；
3. 内嵌的角色书要生效，需在聊天配置里开启 Use V2 Spec.。

## 五、写条目的实用原则

- 关键词选「聊天里真的会被提起的词」，太生僻的词等于白写；
- 一条 Content 只写一件事，别把整本设定塞进单条 —— 注入是按条触发的，拆细才省 token；
- 主线设定勾 Constant 保底，锦上添花的氛围内容交给 Probability；
- 预算紧张时靠 Priority 排优先级，保证砍掉的是最不重要的；
- 配完先自己提一次关键词试触发，再让 AI 复述一遍设定验证有没有进上下文。
