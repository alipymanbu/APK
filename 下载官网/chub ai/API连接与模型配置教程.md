## 一、为什么必须配 API

App 只是前端，角色的回复由你连接的大语言模型生成。不连模型，发出去的消息不会有任何回复 —— 新用户「发消息没反应」十有八九是这一步没做，而不是 App 出了问题。

## 二、在 Secrets 里连接

聊天页右上角菜单打开 Secrets，按你手头的资源选一种方式：

| 连接方式 | 费用 | 怎么拿 |
| --- | --- | --- |
| Chub 官方订阅 | 月付订阅 | 订阅后自动连接，无需管理密钥 |
| OpenAI | 按 API 用量付费 | 到 `https://platform.openai.com` 注册并创建 API Key |
| Anthropic（Claude） | 按 API 用量付费 | 到 `https://console.anthropic.com` 创建 Key |
| Google（Gemini） | 按 API 用量付费 | 到 `https://ai.google.dev` 创建 Key |
| OpenRouter | 按 API 用量付费 | 到 `https://openrouter.ai` 创建 Key，一个 Key 可切换多家模型 |
| Kobold / Ooba | 本地自建免费 | 连接你自己电脑或租用 GPU 上跑的模型，受硬件条件限制 |
| NovelAI | 订阅 | 写作向模型，到 `https://novelai.net` 的用户设置里拿 Key |

把 Key 粘进对应输入框保存即可。各家价格与可用模型随时间变化，以官方订阅页与各服务官网当时显示为准。

## 三、官方订阅的档位

Chub 自家的订阅按模型规模分两档，部分页面把两档称作 Mercury 与 Mars（截至本文整理时，以 `https://r.chub.ai/pricing` 与 App 内订阅页为准）：

| 档位 | 价格 | 范围 |
| --- | --- | --- |
| 轻量档（Mercury） | 约 $5/月 | 20B 参数以下的模型不限量，回复快，日常闲聊够用 |
| 完整档（Mars） | $20/月 | 全部模型不限量，长对话与复杂人设表现更好，另含多媒体生成等附加项 |

关于免费用量：官方会不定期给新账号发一次性试用额度，大约够聊几十条消息，用完需要订阅或改用自己的 API Key；旗舰大模型通常也附带少量试用消息，非订阅账号可以尝鲜。

换模型时 App 会建议你同时切换到该模型的热门预设（preset），建议照做 —— 不同模型的理想参数不同，官方更新日志里专门强调过这一点。

## 四、生成参数怎么调

Configuration（或对应 API 设置）里常用的几个参数，改动前先记下默认值，不满意随时改回去：

| 参数 | 作用 | 什么时候动它 |
| --- | --- | --- |
| Temperature | 回复的随机度 | 调高更有创造性也更容易跑偏；调低更稳更贴人设 |
| Top P | 采样范围 | 与 Temperature 二选一调，不要同时动两个 |
| Frequency Penalty | 抑制重复用词 | 觉得 AI 老说车轱辘话时往上调 |
| Presence Penalty | 鼓励新话题 | 对话原地打转时往上调 |

官方更新日志里给过两条实测经验，照着调少走弯路：回复反反复复说车轱辘话，说明重复类惩罚（repetition / presence / frequency）给得太低；回复里开始丢常用词（英文的 the、an、代词等），说明惩罚给得太高。

## 五、关于「免费逆向代理」

网上流传的各种免费 reverse proxy（逆向代理）不建议用：官方文档明确提示，这类服务由未经授权的第三方搭建，可能记录你的聊天内容、获取你的 IP，甚至使用来路不明的 Key，且随时会停。要省钱就先用官方试用额度，能用官方 Key 或订阅就用官方的。

## 六、配好了还是没反应

按顺序查三件事：Secrets 里选中的 API 与保存的 Key 是否对得上、模型名有没有写错、账号额度是否用完。都正常仍不回复，翻 [常见问题与解决方法.md](常见问题与解决方法.md) 的「聊天环节」对照处理。
