## 一、开聊前先把模型连上

Chub AI 的角色回复由大语言模型生成，App 本身不带模型：第一次聊天前要先在 Secrets 里把 API 连好，否则发消息不会有任何回复。具体步骤与各连接方式的差别见 [API连接与模型配置教程.md](API连接与模型配置教程.md)。

## 二、找角色

- 用搜索框按角色名或关键词搜，也可以按标签筛类型（奇幻、科幻、日常、恋爱等）；
- 排序可按热度或收藏数，社区会对角色卡打分与评论，优先看收藏多的，踩坑概率小；
- 一个官方规则要知道：**标签少于三个的角色不会出现在搜索结果里**。搜不到不等于不存在，可以试着输入完整的角色名；
- 角色详情页会写明人设、开场白与作者备注，先读一眼再决定要不要聊。

## 三、把对话跑起来

1. 进角色详情页，点 Chat with（开始聊天）按钮；
2. 角色会先发第一句开场白，你在输入框直接回复即可；
3. 对某条回复不满意时可以重新生成；同一个位置的多条备选回复之间可以来回切换，选定后继续往下聊。

界面默认是英文、或想直接用中文聊，相关设置与实际情况见 [中文界面与中文对话.md](中文界面与中文对话.md)。

## 四、聊天页菜单速查

右上角菜单打开后常见条目如下（不同版本入口位置可能微调，以 App 内实际显示为准）：

| 菜单 | 管什么 |
| --- | --- |
| Configuration | 调生成参数与预设（preset），预设可切换 |
| Secrets | 配置 API 连接，聊天前必须完成 |
| Chat Settings | 往对话里加角色、挂世界书（Lorebook）、导出聊天记录 |
| Character Settings | 改当前角色的定义，只影响你自己这份聊天，不动原作者的卡 |
| Chat Memory | 手动写或让 AI 生成前情摘要 |
| Change Persona | 切换或编辑「你」在对话里的人设 |
| New Chat | 与同一个角色另开一段新对话 |

表里挂世界书（Lorebook）一栏的完整配法见 [Lorebook世界书配置教程.md](Lorebook世界书配置教程.md)；社区里看到好卡想自己动手做一张，流程见 [自建角色卡教程.md](自建角色卡教程.md)。

## 五、Persona 与长期记忆

- **Persona** 是「你」在角色眼里是谁：名字、身份、说话习惯。不设也能聊，但设了之后角色的称呼与反应会更贴合你想要的身份；多段聊天可存多套 Persona 随时切换；
- **长期记忆**：对话变长后，最早的内容会滑出模型的上下文范围，角色开始「失忆」。Chat Memory 里的摘要会作为补充上下文一起发给模型 —— 重要设定可以让 AI 自动生成摘要，也可以自己手写进去，是防失忆最直接的手段。

## 六、把聊天记录带走

Chat Settings 里可以把当前对话导出为 JSONL（SillyTavern 格式）、PNG 或纯文本，换设备、做备份或换其他工具继续聊都用得上；具体操作与搬去 SillyTavern 的接法见 [角色卡导出与SillyTavern互通.md](角色卡导出与SillyTavern互通.md)。

聊着聊着遇到没回复、报错、失忆这类情况，先翻 [常见问题与解决方法.md](常见问题与解决方法.md) 对号入座。
