## 一、先弄清两个名词

登录控制台后会反复碰到这两个概念，先说清楚：

- **Clawbot**：你派去干活的那个实例。你用自然语言下指令，它来执行。
- **CloudSpace**：Clawbot 工作时所在的那台云端资源（云电脑）。指令涉及桌面或浏览器操作时，你能实时看到它操作的画面。

创建前确认还有名额：创建页面会显示当前已建数量与当前套餐的上限，满了就先删掉不用的 Clawbot 或升级套餐（各档位数量见 [账号注册与套餐计费.md](账号注册与套餐计费.md)）。

## 二、创建云端 Clawbot

1. 打开控制台 [https://jvs.wuying.aliyun.com/botlist](https://jvs.wuying.aliyun.com/botlist)；
2. 左侧导航选 **Clawbots**，进入管理页；
3. 点左上角 **创建云端 Clawbot** 卡片；
4. 输入 Clawbot 名称，其他选项保持默认，点 **下一步**；
5. 在节点资源类型页选 **CloudSpace - JVS Computer**，点 **创建 Clawbot**。

回到 Clawbots 列表，新卡片状态显示 **运行中** 就可以开始对话了。

创建页如果提供对话语气选项（官方教程里出现过严肃专业、幽默轻松等风格），按用途选一个即可，不同版本的选项可能不同，以创建页实际显示为准。创建完成即占用一个套餐名额，删掉不用的才会释放。

## 三、发第一条指令

1. 在目标 Clawbot 卡片上点 **对话 Claw**，进入对话页；
2. 在输入框里用一句自然语言描述任务（官方示例：「读取最近的十封邮件，总结一下」），或者直接点下方的预设提示词发送；
3. 涉及桌面或浏览器操作的任务，点右上角 **CloudSpace 全屏** 实时看它执行；需要纠正时，可以直接在这个画面窗口里手动接管操作。

指令写得越具体，返工越少。建议写明三件事：要处理什么材料（文件/邮箱/网页）、要输出什么形式（表格/报告/页面）、结果放哪里。

想从邮箱汇总这类最常见的需求上手，接入步骤和现成提示词见 [邮箱接入与邮件汇总.md](邮箱接入与邮件汇总.md)。

## 四、执行中你可以做的操作

| 想做的事 | 怎么做 |
|---|---|
| 中止当前任务、保留这段对话 | 在对话框输入「停止当前任务」并发送 |
| 直接换一个新任务 | 点 **新对话** 另开一段对话 |
| 手机上不想打字 | 移动客户端支持语音输入指令 |
| 给它喂文件 / 取回结果 | 见 [文件上传下载与保存位置.md](文件上传下载与保存位置.md) |
| 让它把结果发到微信 / 钉钉 / 飞书 | 先在控制台配置 IM 通道 |
| 保持 Clawbot 是新版本 | 卡片上点 **升级** 并确认；升级期间会短暂不可用，先确认没有正在跑的任务 |

两个限制提前知道：本地 Clawbot 和基于 CloudPhone 的 Clawbot 不支持配置 IM 通道；多任务并发只有匠心版及以上套餐支持，且没有固定并发数上限，实际取决于任务复杂度与资源状态。

## 五、给 Clawbot 补能力

- **Skills（技能）**：在控制台为 Clawbot 添加技能，让它能处理更多类型的任务；官方教程的路径是控制台的「广场」里挑选添加（例如办公文档-文案助手、搜索研究-天气助手），卡片图标里还能开关单个 skill；
- **Profile**：把一套核心配置打包保存，之后新开 Clawbot 时直接复用，不用重配；
- **自定义模型**：每个 Clawbot 只支持配置一个模型，且仅限国内模型厂商；配了自定义模型后该 Clawbot 调用模型就不再消耗 JVS 积分，费用由模型服务商结算；
- **平台接入**：需要它读取第三方平台的文档时，先在控制台完成平台接入配置；
- **定时任务**：对话之外可以让它每天固定时间自动跑一遍，配置步骤与现成示例见 [定时任务配置与示例.md](定时任务配置与示例.md)。

具体入口以控制台当前界面为准，官方帮助中心的「操作指南」一节有对应说明。
