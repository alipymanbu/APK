## 一、免费版能干什么

Lightroom 移动版下载免费、注册免费，以下功能**全部免费、不限时长**（官方 FAQ 口径）：

- **拍摄**：用应用内相机拍照；
- **组织**：建相册、搜索、整理图库；
- **分享**：导出照片、发到社交平台、分享相册；
- **大部分编辑功能**：光线、颜色、裁剪、效果、细节等基础面板，以及 30 多个自带预设。

也就是说，「拍照 → 修图 → 导出发出去」这条主线，免费账号就能完整走完。装都装不上的话先看[下载与安装教程.md](下载与安装教程.md)。

免费额度用到什么程度，应用里随时能查：**设置 → 云存储与同步**会显示已备份到云端的照片数量与剩余空间；**设置 → Premium 功能**列出订阅解锁的完整清单 —— 拿不准某个功能要不要钱，点它一下看提示最直接（升级墙就在功能入口，不用先付钱试）。

## 二、订阅（Premium）多出什么

官方列在 Premium 名下的功能（截至 2026-09）：

| 功能 | 解决什么问题 |
| --- | --- |
| 云存储空间 | 照片与编辑存 Adobe 云，换设备不丢 |
| 预设与配置文件同步 | 手机、电脑、网页共用同一套预设 |
| 修复画笔 | 点掉路人、瑕疵、杂物 |
| 选择性调整（蒙版） | 只对画面局部调光调色 |
| 几何工具 | 透视拉正、畸变校正 |
| 手机上的 RAW 编辑 | 直接修 DNG 原始格式 |
| 批量编辑 | 一套参数套到多张照片 |
| 人物照片分类 | 按人脸自动归类整理 |
| Sensei 搜索 | 用内容描述搜照片 |
| 网络画廊分享 | 生成网页版相册给别人看 |
| 生成式移除、镜头模糊、自适应预设 | AI 类修图能力（部分可免费试用） |

实际影响最大的是前三类：**修复画笔、选择性调整、几何** —— 免费版打开会提示升级；其余日常修图基本不撞线。

## 三、在哪订，作用范围差很多

| 订阅方式 | 覆盖范围 |
| --- | --- |
| Creative Cloud 订阅 | 手机、平板、桌面、网页全都能用 |
| Creative Cloud 摄影计划 | 同上，另含 Photoshop 与 Adobe Portfolio 站点 |
| Lightroom 单品订阅 | 手机、平板、桌面、网页 |
| 在 App Store / Google Play / Galaxy Store 内购的 Lightroom Premium | **只在移动版生效**，桌面版不带 |

一句话判断：想在电脑上接着修，就选 Adobe 官网那三种计划；只在手机上用，应用商店内购更省事。价格与包含的云存储额度随时会调，**下单前以 [adobe.com 的 Lightroom 页](https://www.adobe.com/products/photoshop-lightroom.html) 当时显示为准**。

## 四、和桌面版、Lightroom Classic 的关系

Adobe 家桌面端现在是两个产品：**Lightroom**（跨设备云图库那套）与 **Lightroom Classic**（本地目录那套，老摄影师用得多）。手机这台和它们的联动规则：

- **手机 ↔ 桌面互相同步照片与编辑**：要有**有效 Creative Cloud 会员**才行；
- **买断/永久许可版的 Lightroom**：官方 FAQ 明说**不能**与手机互相同步；
- 没订阅时手机端自成一体：照片在手机上修、在手机上导出，功能见第一节。

订阅是否划算，取决于你要不要「手机拍、电脑修」这条链路 —— 只在手机出片，免费版已经够用（见第一节）；要跨设备就绕不开订阅。
