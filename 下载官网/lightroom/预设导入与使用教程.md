## 一、先弄清三种文件格式

预设文件常见三种扩展名，Lightroom 移动版都能认：

| 格式 | 是什么 | 适合怎么用 |
| --- | --- | --- |
| `.xmp` | 独立的预设参数文件 | 安卓上最直接，走「导入预设」一步到位 |
| `.DNG` | 带了编辑参数的照片文件 | 别人分享的成品图式预设，导入后从照片里「创建预设」 |
| `.lrtemplate` | 老格式 | 同样可直接导入 |

两个前置动作：**下载来的是 ZIP 必须先解压**（Lightroom 能导单个文件，处理不了压缩包）；DNG 文件先存到手机本地或云存储，保证等下能在文件选择器里找到它。

## 二、路径 A：导入 XMP / lrtemplate（推荐）

1. 把预设文件下载到手机；
2. 打开任意一张照片进编辑视图，底部选**预设**；
3. 选**「您的」**，点选项菜单（三点），选**导入预设**；
4. 导航到文件所在位置，选中它确认；
5. 回到**预设 → 您的 → 用户预设**，导入的预设都在这里，点一下就套到照片上。

## 三、路径 B：从 DNG 文件创建预设

DNG 预设本质是一张「调好色的照片」，你把它的调法存成预设：

1. 点**添加照片**，来源选设备上的照片/文件夹，找到那个 DNG 文件导入；
2. 在所有照片网格里找到它，点开进细节视图；
3. 打开时可能弹**「无法加载文件」**的提示 —— 这是官方文档明说的正常现象，**不用管，继续往下走**；
4. 点右上角**选项（三点）** → **创建预设**；
5. 起个名字、选预设组（默认存「用户预设」，也可新建一个组）；
6. 「选择」下拉里决定带哪些参数：**全部**（所有设置）/ **默认**（默认不含蒙版、镜头模糊、几何等）/ **已修改**（只带这张 DNG 上实际改过的项）/ **无**（全不带再手动勾）；
7. 逐组勾选确认后点完成保存。

官方给的一条实操建议：**创建时把「亮度」组取消勾选** —— 曝光和明暗几乎每张照片都要重新调，把上一张的亮度带进预设反而碍事。

## 四、应用、管理与防丢

- **套用**：任何照片 → 编辑 → 预设 → 您的 → 选组 → 点预设即可，不满意直接换一个或撤销。
- **重名**：新预设与已有预设同名时会弹窗问你「保留两者 / 替换 / 重命名」，别随手点替换，同名不同参的预设很常见。
- **同步**：用 Adobe ID 登录且有有效订阅时，你在桌面版建的预设会自动同步到手机，反之亦然；只在手机上用则不受影响，见[免费版与付费版区别.md](免费版与付费版区别.md)。
- **浏览/套用预设时闪退**：官方已知问题里有一条正是这个（影响 11.3.2 及以后），处理办法见[常见问题与解决办法.md](常见问题与解决办法.md)。

## 五、把你的预设导出给别人

你自己调好的效果可以打包成 DNG 发给朋友，对方按第三节的流程就能装上：

1. 打开一张**已套用该效果**的照片；
2. **共享 → 导出为…**，「设置」下拉里选**预设**，文件类型选 **DNG**；
3. 「更多选项」里可选带不带元数据、怎么命名文件；
4. 点完成导出，把 DNG 发出去即可。

导出的 DNG 里带着你当时的全部编辑参数 —— 对方导入它、按第三节创建预设，拿到的就是同一套调法。批量把一堆预设传到新手机，用同一招逐张导出即可。

自己修图打底用的还是那些基础面板，参数怎么调见[手机修图基本操作.md](手机修图基本操作.md)。
