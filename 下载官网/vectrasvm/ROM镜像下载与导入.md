## 一、虚拟机的「系统」从哪来

Vectras VM 装好之后只是一个空的虚拟机管理器，里面没有操作系统。让虚拟机能开机的系统镜像（ROM）有两个来源：

1. **应用内置的 ROM 商店**：官方准备了一批做好的机器，从 Windows XP、Windows 7 这类老系统，到 Alpine Linux、ReactOS、OpenWrt、KolibriOS 都有，下载导入就能开机。这是新手最省事的路。
2. **自己的镜像文件**：你手上已有的 ISO / IMG 系统安装盘，按 [创建虚拟机与参数设置.md](创建虚拟机与参数设置.md) 的流程手动挂载安装。

ROM 体积普遍在几百 MB 到几个 GB 之间，开工前先做一件事：**确认手机剩余存储放得下**。存储不够是 ROM 下载失败最常见的原因。

## 二、从 ROM 商店下载一台现成的机器

按官方教程给出的顺序操作：

1. **检查可用存储空间**——不够就先清一清；
2. **打开 Roms 页面**——主界面里能找到入口；
3. **选中你要的 ROM**——列表里能看到每个系统的简介与体积；
4. **等待下载与导入完成**——过程中保持网络稳定，别让应用被系统杀掉后台；
5. **回到主界面启动它**——导入成功的机器会出现在主界面，点击即可开机。

两点提醒：

- **有密码的 ROM 一定要记下密码**。部分 ROM 压缩包或系统本身带密码，页面上会写；不记的话导入或登录时会被卡住。
- **老式 Linux 发行版（如 Red Hat 5.2、SuSE 5.2 这一代）登录后不会自动进图形界面**。在命令行登录成功后输入 `startx` 回车，才会启动 X11 桌面。

## 三、商店里都有哪类机器

按官方与社区资料，ROM 商店里的常见门类：

| 类型 | 典型例子 | 适合干什么 |
| --- | --- | --- |
| 老 Windows | Windows XP / 7 / 8.1 | 跑老软件、老游戏，配合 3dfx 补丁可玩 90 年代 3D 游戏 |
| 轻量 Linux | Alpine Linux（Xfce4 桌面） | 低配置手机也能跑的桌面环境 |
| 其他系统 | ReactOS、OpenWrt、KolibriOS | 研究小众系统、软路由、超轻量桌面 |
| 远古 Linux | Red Hat、SuSE 等旧发行版 | 怀旧与学习，注意登录后要手动 `startx` |

商店目录会随版本更新变化，以你打开商店时实际列出的为准。

## 四、下载失败或导入后开不了机

先按这三条排查：

1. 确认剩余存储确实够（ROM 体积 + 解压后的占用，留出双倍余量最稳）；
2. 换一个网络环境重试，有些 ROM 的下载源在特定网络下很慢；
3. 带密码的 ROM 确认密码没有输错。

还解决不了就看 [常见问题与报错处理.md](常见问题与报错处理.md) 里对应的小节。

## 五、商店没有想要的系统怎么办

ROM 商店只是起点，不在目录里的系统（比如某个特定版本的 Linux 发行版、你自己攒的安装盘）走手动创建虚拟机那条路：准备好 ISO，按 [创建虚拟机与参数设置.md](创建虚拟机与参数设置.md) 新建机器、挂载硬盘与光盘，再走一遍系统安装流程。
