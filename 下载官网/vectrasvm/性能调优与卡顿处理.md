## 一、卡顿先怪硬件，再怪设置

虚拟机是在手机上完整模拟一台 x86 电脑，开销天然比普通应用大。官方的推荐配置是 Android 8.1 及以上、8 GB 内存（空闲 3 GB）、骁龙 855 或更好的 64 位处理器。低于这条线的手机不是不能跑，而是要**把期望降下来**：

- XP、KolibriOS、Alpine 这类轻量系统，中端机也能流畅；
- Windows 10/11 或近十年的桌面系统，对处理器和散热都是考验，官方明确建议配合散热措施跑。

机型实测兼容性上，Samsung、Pixel、Xiaomi、Redmi、Poco 的评价最好；Huawei、Honor 机型评价最低，卡顿概率更高。

## 二、把分配调对

创建或编辑虚拟机时（操作见 [创建虚拟机与参数设置.md](创建虚拟机与参数设置.md)），两个数字最影响流畅度：

1. **核心数（命令行里是 `-smp` 与 `cores`）**：按手机实际核心数填。例：八核机填 `-smp 8,cores=8`。核心给少了虚拟机算不动，给多了宿主系统没核可用，两头卡；
2. **内存**：以手机**空闲内存**为上限。空闲 3 GB 时给虚拟机 2 GB 左右比较稳；分配超过空闲值后，宿主系统会频繁杀后台、拖垮整台虚拟机；
3. **多线程加速**：参数里加上 `-accel tcg,thread=multi` 可以让模拟器吃满多个核心——社区通行的 Windows XP 全驱动配置里就带这一段，整行参数与逐段解释见 [QEMU参数进阶与预装镜像开机.md](QEMU参数进阶与预装镜像开机.md)。

另外系统选型本身就是最大的性能变量：同一台手机，跑 KolibriOS 和跑 Windows 11 是两个世界。系统开不动时，官方给的忠告很直接——**换旧版本的操作系统试试**。

## 三、3dfx 补丁：老 3D 游戏的专门通道

你手上这个 v2.9.5-3dfx 版本的核心卖点就在版本号里：**3dfx 支持在 2.9.5 恢复了**。

- 适用对象：Windows 95 / 98 / ME / 2000 / XP 时代、当年靠 3Dfx Voodoo 显卡跑的 3D 游戏；
- 官方同时提醒：3dfx 这条路径**可能不稳定、性能偏低**，属于「让老游戏能跑」而不是「让老游戏跑爽」的方案；
- 附加条件：设备若是 Adreno GPU，官方提到 Turnip 与 Zink 驱动方案能改善性能，但需要设备支持；
- 驱动从哪来：维护者仓库提供 3dfx wrapper 的 ISO 镜像，把它当光盘挂进 Windows 里安装后游戏才走 3dfx 通道，镜像地址与安装步骤见 [QEMU参数进阶与预装镜像开机.md](QEMU参数进阶与预装镜像开机.md) 第四节。

如果你主要想跑的是这类老游戏，建机时优先选老 Windows 的 ROM，再按 [创建虚拟机与参数设置.md](创建虚拟机与参数设置.md) 里的命令行参数核对显卡段配置。

## 四、散热与续航

- 长时间跑虚拟机时手机发热明显，发热会触发降频，降频后虚拟机进一步变卡——**卡顿突然加重时先摸一下手机温度**；
- 建议充电状态下运行（满负荷耗电很快），并摘掉手机壳或加散热背夹；
- 不用虚拟机时从系统内正常关机，别让它挂在后台空转。

## 五、都调过了还是卡

按顺序检查：镜像本身是否完整（重新下载一次）、分配是否超了空闲内存、系统是否超出了手机档次。逐条排查都正常还卡，就去 [常见问题与报错处理.md](常见问题与报错处理.md) 看启动类问题的处理，或回到 [下载与安装教程.md](下载与安装教程.md) 核对安装的版本本身是否完整。
