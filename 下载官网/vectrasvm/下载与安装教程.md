## 一、先核对你的手机够不够格

Vectras VM 是在安卓手机上跑虚拟机的应用，对硬件的要求比普通工具高。装之前对照官方给出的两档要求：

| 档位 | 系统版本 | 内存 | 处理器 |
| --- | --- | --- | --- |
| 最低 | Android 6.0 及以上 | 3 GB（空闲 1 GB） | 性能尚可的处理器 |
| 推荐 | Android 8.1 及以上 | 8 GB（空闲 3 GB） | 64 位 CPU 与系统，骁龙 855 或更好 |

官方还有两条经验判断：

- 2021 年及以后生产的机型，一般都能正常跑；
- 打算模拟 2010 年以后的操作系统时，建议手机有内置散热或另备散热背夹。

机型方面，官方实测兼容性排在前面的是 Samsung、Google Pixel、Xiaomi、Redmi、Poco；Oppo、Realme 属于中游；Huawei、Honor 的兼容性评价最低，装之前要有心理准备。

## 二、安装包从哪拿

三条路，按你的情况选：

1. **GitHub 发布页**：项目开源，稳定版在 [https://github.com/xoureldeen/Vectras-VM-Android/releases](https://github.com/xoureldeen/Vectras-VM-Android/releases)，适合能正常访问 GitHub 的人。
2. **离线安装包**：从 [Vectras VM 安装文件资源（夸克网盘）](https://pan.quark.cn/s/51e5c3c31fef) 获取 APK 后直接安装。装之前建议核对包名是否为 `com.vectras.vm`（与开源仓库一致）再装。
3. **Google Play**：官方也在商店上架了另一个版本，包名是 `com.vectrasllc.vm`，与上面的开源版**不是同一个包**，数据不互通，别装混了。

## 三、本套文档对应的版本事实

网上搜到的都是官方最新版，和网盘里这份未必是同一个。本套文档以下面这份本地记录为准：

| 项目 | 值 |
| --- | --- |
| 版本号 | v2.9.5-3dfx |
| 包名 | `com.vectras.vm` |
| 安装包大小 | 45.34M |
| MD5 | `F61610BC43FEEF779375033CF76EADF9` |
| 记录时间 | 2026-09-23 |
| 系统要求 | 本地记录标注安卓 5.2 以上（官方仓库写明的最低要求是 Android 6.0，以此为准） |

版本号末尾的 `-3dfx` 是这一版的重要特征：2.9.5 恢复了 3dfx 支持，也就是给 Windows 95/98/ME/2000/XP 里的老 3D 游戏补上了 3Dfx 显卡模拟，具体怎么用在 [性能调优与卡顿处理.md](性能调优与卡顿处理.md) 里讲。

## 四、首次启动：先把运行环境装上

Vectras VM 第一次打开不会直接进主界面，而是弹出一个配置窗口，让你安装它赖以运行的引导包（bootstrap）。这一步跳不过去，处理方式有两种：

- **在线安装**：保持网络可用，按窗口提示下载即可。引导包体积不小，建议在 Wi-Fi 下进行。
- **手动安装**：在线下载失败时用这条路。先把引导包提前存进手机存储，然后在配置窗口选手动安装，从手机存储里选中它再继续。社区教程里提到的做法是：先关掉 Wi-Fi 让窗口停在配置这一步，选好本地包后再把网络打开。

引导包不是随便挑一个就能用：**版本必须与主程序配套**。本套文档对应的主程序版本是 v2.9.5，官方进阶文档标注它配 QEMU 8.2.0-3dfx 引导包；完整版本对照见官方仓库的 [ADVANCED.md](https://github.com/xoureldeen/Vectras-VM-Android/blob/master/ADVANCED.md)，配套关系与换版本注意事项在 [QEMU参数进阶与预装镜像开机.md](QEMU参数进阶与预装镜像开机.md) 第三节。

安装过程中**不要把应用切到后台**，等它跑完再离开。

装好引导包后顺手把界面切成中文：进设置里的应用设置，找到 Language 一项，选简体中文。部分界面仍是英文，官方说明里也承认目前中英文混排，看不懂的页面可以借助手机自带的翻译功能。

## 五、装完之后先别急着开机

主界面里还没有任何可用的虚拟机——镜像和机器配置都还没就位。下一步从 ROM 商店挑一台现成的机器，或者用自己的 ISO 新建一台，两条路的详细做法分别在 [ROM镜像下载与导入.md](ROM镜像下载与导入.md) 和 [创建虚拟机与参数设置.md](创建虚拟机与参数设置.md)。
