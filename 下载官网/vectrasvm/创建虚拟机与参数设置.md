## 一、两条建机路线，先选对

- **不想折腾**：直接用 ROM 商店的现成机器，下载导入即用，流程见 [ROM镜像下载与导入.md](ROM镜像下载与导入.md)。
- **要装商店里没有的系统**：手动新建。前提是你已经有目标系统的 ISO 安装镜像，并且手机存储放得下「镜像 + 虚拟硬盘 + 装完系统」这三份占用。

手动建机比商店路线多一道「装系统」的工序——虚拟机第一次开机进的是安装界面，你要像在真机上装系统一样分区、安装、重启，装完才进桌面。

## 二、新建一台 x86 虚拟机的完整步骤

以社区里最常被引用的流程为准：

1. 在主界面点 **加号** 按钮进入创建页，机型选 **x86-x64**；
2. 依次填四样东西：
   - **名称**：随意，方便你认就行；
   - **图片**：虚拟机的封面图，随意选一个；
   - **硬盘**：选你已经准备好的系统镜像或虚拟硬盘文件。如果镜像里还没有操作系统，这里挂的是安装来源；
   - **光盘（CD）**：挂 ISO 安装盘。硬盘里已经有装好系统的人可以不填，只挂硬盘即可；
3. 保存后回到主界面，点击这台机器的图片即可开机。

开机后进入的画面是虚拟机自己的屏幕，你可以用触屏模拟鼠标、用悬浮键盘打字，接了外接键鼠的话体验更接近真电脑。

## 三、进阶：改 QEMU 命令行参数

Vectras VM 支持直接编辑传给底层模拟器的启动参数。社区教程里流传的一行示例：

```text
-M q35,usb=on -device usb-tablet -cpu core2duo,+avx -smp 8,cores=8 -vga vmware -netdev user,id=usernet -device e1000,netdev=usernet
```

逐段拆开看，你只需要动一个地方：

| 参数段 | 作用 | 要不要改 |
| --- | --- | --- |
| `-M q35,usb=on -device usb-tablet` | 机型与 USB 触控设备，决定触屏手感 | 不动 |
| `-cpu core2duo,+avx` | 虚拟 CPU 型号 | 老系统兼容性有问题时才考虑换 |
| `-smp 8,cores=8` | 分配给虚拟机的核心数 | **改**：按你手机的实际核心数填 |
| `-vga vmware` | 虚拟显卡型号 | 不动 |
| `-netdev user ... -device e1000 ...` | 用户态网络，让虚拟机能上网 | 不动 |

改法：把参数框里原有的内容整行删掉，粘贴上面这行，把 `-smp 8,cores=8` 里的两个 `8` 换成你手机的核心数（八核就填 8）。其他段在你遇到具体问题前都保持原样。

这行示例只动了核心数这一处。想更进一步——直接开机别人装好驱动的预装镜像、给虚拟机加多线程加速、逐段看懂每个参数——整理在 [QEMU参数进阶与预装镜像开机.md](QEMU参数进阶与预装镜像开机.md) 里。

## 四、参数填多少不翻车

- **核心数**：等于或略少于手机物理核心数。给得太多，宿主系统和虚拟机互相抢核，两边都卡；
- **内存**：不要超过手机的空闲内存。空闲 3 GB 的手机给虚拟机分 2 GB 是常见做法，分再多宿主系统会先撑不住；
- **硬盘镜像**：老系统（XP 这一档）几个 GB 就够；装近十年的系统先按官方推荐配置核对手机档次，见 [性能调优与卡顿处理.md](性能调优与卡顿处理.md)。

## 五、日常管理

- **开机 / 关机**：主界面点击机器图片开机；关机建议从虚拟机系统内部正常关机，直接断电式关闭可能损坏虚拟硬盘；
- **修改配置**：已创建的机器可以再进入编辑页调整参数，改完下次开机生效；
- **不要用的机器**：确认不要了再删，删掉的同时虚拟硬盘数据一并消失，无法恢复。
