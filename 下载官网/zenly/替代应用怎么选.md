## 一、先确认你要的是哪一种

「找个 zenly 替代品」这个需求其实混着三件不同的事，先分清再挑，能省掉大半纠结：

| 你的真实需求 | 对应的产品形态 | 判断依据 |
| --- | --- | --- |
| 密友小圈子互相知道对方在哪，带点氛围感 | 好友位置社交类 | 你要的是「看见彼此的生活轨迹」，双向好友、可见电量速度这类细节是重点 |
| 家人守护：看孩子、老人到没到该到的地方 | 家庭定位守护类 | 你要的是「确认安全」，重点看地点提醒、历史轨迹、权限管理 |
| 约会、结伴出游时临时汇合 | 临时位置共享类 | 你要的是「这一次别走散」，重点看分享链接是否免安装、能否定时失效 |

zenly 当年最独特的是第一种形态——把位置共享做成了日常社交；后两种市面上工具更多、也更成熟。

## 二、官方指出的路：Snap Map

zenly 停运前，官方在告别公告里直接推荐用户转往 **Snap Map**（Snapchat 内置的地图功能）：同样能看到好友在地图上的位置、热门地点动态。要注意两点：它长在 Snapchat 里，你得先装 Snapchat 并加好友；它是社交地图，但电量、停留时长这类细节以及打卡排行榜玩法与 zenly 并不相同。当年不少 zenly 用户因为社交关系分开管理的原因没有迁移过去，这属于个人取舍。它的开启方式、Ghost Mode 与隐私规则，见[Snap Map 使用与隐身设置.md](Snap Map 使用与隐身设置.md)。

## 三、停运前后被广泛报道的同类应用

zenly 关停消息公布后，一批同类应用进入用户视野。下表是当年媒体与社区报道中出现频率较高的名字，**收录截至 2023 年初的公开报道**——两三年过去，这些产品的功能、区域可用性乃至存续状态都可能已变化，实际选择前以各自官方页面为准：

| 应用 | 当时的定位 | 备注 |
| --- | --- | --- |
| Life360 | 家庭定位守护（地点提醒、行程记录等） | 停运消息后下载量明显上涨；免费版与付费订阅并存，具体权益以官方页面为准 |
| NauNau | 好友/家人位置共享，界面简洁 | 在 zenly 用户聚集的亚太市场讨论度高 |
| iSharing | 家人与好友定位 | 提供到访提醒 |
| Whoo | 年轻用户向的位置共享 | 风格接近 zenly 的社交感 |
| iHere | 好友位置共享 | 同期报道中出现 |
| Bind | 情侣向定位与互动 | 面向亲密关系场景 |
| Now | 好友动态与位置 | 同期报道中出现 |
| Tomotomo | 好友位置共享 | 同期报道中出现 |
| Superlocal | 位置签到与探索 | 偏「打卡探索」方向 |
| DoDo | 社交地图 | 报道称有 zenly 前员工参与顾问 |
| Peer | 社交地图 | 报道称招募了 zenly 相关成员（其「核心团队」说法曾被前员工质疑） |

选型时按第一节那张表对号入座即可：守护家人优先看 Life360 一类，密友氛围感优先看 NauNau、Whoo 一类。血缘最近的候选是下面这个。

### 原班人马的续作：Bump

zenly 创始人 Antoine Martin 离开后，与另外九位在 zenly 任职六年以上的老同事共同创立了 Amo，2023 年底接连推出 ID、Capture、Location 三款应用，2024 年把位置共享这条线整合成了 **Bump**（[Google Play 页面](https://play.google.com/store/apps/details?id=co.amo.android.location)，官方介绍直接写明「来自 zenly 团队」）。截至 2026 年 9 月它仍在持续更新。

当年 zenly 的招牌玩法在 Bump 里基本都有对应：好友实时位置、电量、速度与停留时长；自动识别常去地点；「刮刮地图」探索足迹；摇一摇手机碰一碰；隐身模式；从地图直接导航或叫车。也加了 zenly 没有的东西：好友正在听的歌（对接 Spotify）、桌面位置小组件、给好友共享实时预计到达时间。三件事要想清楚：它要求**安卓 11 及以上**（原版 zenly 的装机门槛只要 5.2，老设备装不了它，见[下载与安装教程.md](下载与安装教程.md)）；好友、打卡、足迹与 zenly 的数据完全无关，全部从零开始；应用会随版本演进增减功能，以它的官方页面为准。

## 四、换任何一款前，先过一遍这几件事

zenly 用了这么多年，换产品时有些账要重新算一遍，这几条适用于所有位置共享应用：

1. **双向授权是底线**：正规产品都要求双方互为好友/同意后才互见位置。遇到声称「只要手机号就能看别人位置」的，直接排除。
2. **耗电与后台常驻**：实时位置靠后台定位，换新应用后头一两天留意耗电变化；多数产品提供「仅使用应用时共享」或低频模式，按需选。
3. **把隐私开关先走一遍**：隐身/暂停共享、按人分组可见、地点提醒的开关在哪，装完第一天就摸清楚，别等要用的时候找不到。
4. **数据与账号**：确认注册方式（手机号还是第三方登录）、账号注销入口和数据导出能力——zenly 的教训之一就是服务一关，什么都没留下。
5. **小圈子迁移靠人**：这类应用的价值取决于你的朋友也在上面。先拉上最常联系的几个人试一两周，合适再扩。
