## 一、Snap Map 在哪，默认状态是什么

Snap Map 不是独立应用，是 Snapchat 里的地图功能。装好 Snapchat 后，在相机画面双指捏合（或点位置图标）就能打开地图。

它是「默认不上图」的设计：即使你给了定位权限，只要没在地图设置里主动开启共享，你就不会出现在任何人的地图上。想出现在好友地图上，要同时满足四个条件：双方互为好友、你打开过 Snap Map、给 Snapchat 开了设备定位权限、在设置里选择了共享位置。

## 二、两种共享方式，先选清楚

| 方式 | 行为 | 适合 |
| --- | --- | --- |
| 仅使用时（Only while using） | 只有 Snapchat 开着时位置才更新；关掉后地图停留在你最后出现的位置 | 只在出门、约会这类场景临时开放 |
| 后台实时（Always） | 关掉应用也持续更新，好友看到的是实时位置 | 需要家人好友持续知道你在路上、到了没 |

两种方式随时可以在地图设置里切换，后台实时也会被系统定期提醒确认。

## 三、隐身：Ghost Mode

1. 打开 Snap Map，点地图设置（齿轮图标，不同版本位置在右上或右下角）；
2. 打开 **Ghost Mode**；
3. 选定时器：**3 小时 / 24 小时 / 直到手动关闭**——想临时消失几小时就选定时，不用记得回来关。

开着 Ghost Mode 时你照样能看地图、看好友在哪，只是别人看不到你。此时你的 Bitmoji 会举着一块带幽灵图标的蓝色牌子。按官方说明，开启后位置数据仍会上传给 Snap 服务端，只是不对其他人展示——它不是「离网」开关。

## 四、几条容易误解的规则

- **24 小时不打开就消失**：超过 24 小时没打开 Snapchat，好友地图上就看不到你，直到你再次打开（除非你开启了持续的实时位置共享）。
- **位置隐身不等于内容匿名**：你投稿到 Snap Map 的公开 Snap（哪怕没署名）不受 Ghost Mode 影响，仍可能出现在地图上——发公开内容前想清楚它暴露了你曾在哪。
- **不是公开地图**：非好友和陌生人看不到你的位置；能看到的范围由「全部好友 / 仅指定好友 / Ghost Mode」三档决定。
- **地图入口移不掉**：Snap Map 是 Snapchat 内置功能，无法从应用里删掉；你能做的是不给定位权限、不开启共享，地图对你来说就只是一张看不了别人的图。

## 五、从 zenly 过来，差在哪

| 当年 zenly 有 | Snap Map 的对应 |
| --- | --- |
| 好友实时位置、电量、速度、停留时长 | 只有位置本身；电量、停留时长没有 |
| 打卡地排行榜、探索率皇冠 | 没有；有地点卡片、地点 Snaps 和场所搜索 |
| 独立的好友圈子 | 要在 Snapchat 重建好友关系，与当年 zenly 好友不通用 |
| 地图上直接聊天 | 有，点好友 Bitmoji 就能开聊 |
