# EasyClaw 不用电脑时的云Bot怎么用

> 本篇讲清云 Bot 和你电脑上那套东西的分工、从哪儿进去、什么任务该交给它，以及它做不到的事。

云 Bot 是 EasyClaw 里最容易和「本地那套」搞混的一块。一句话区分：本地端跑在你自己的电脑上，能碰你电脑里的文件，但电脑一关就停；云 Bot 跑在厂商的服务器上，全天在线，可它够不着你电脑里的东西。这篇就按这条界线往下讲。

## 一、云 Bot 与本地端的分工

| 对比项 | 本地端（桌面端 + 手机端） | 云 Bot |
| --- | --- | --- |
| 运行在哪 | 你自己的电脑 | 服务商的服务器 |
| 是否需要电脑开机 | 需要，关机即停 | 不需要 |
| 能否操作你电脑上的文件和软件 | 能 | 不能 |
| 在线时间 | 跟你的电脑同步 | 7×24 |
| 进入方式 | 装客户端 | 浏览器打开即可，不用装电脑端 |
| 适合的任务 | 本地文件整理、软件操作、系统级自动化 | 查询、搜集与总结、定时提醒与推送 |

## 二、从哪儿进去

- **国内版**：浏览器打开 [cloudbot.easyclaw.cn](https://cloudbot.easyclaw.cn/)，注册登录后即用。
- **海外版**：浏览器打开 [cloudbot.easyclaw.com](https://cloudbot.easyclaw.com/)。
- **手机端应用内也可以创建云 Bot**。各版本入口位置不完全一样，以应用内实际显示为准。

入口在浏览器里，意味着你在任何一台设备上都能登上去看它跑到哪了——这也是它和本地端最大的体验差别。

## 三、什么任务该交给云 Bot

- **不需要碰你电脑的任务**：查资料、把一段内容整理成表格、帮你盯某个信息每天汇总一句。
- **需要长期在岗的任务**：每天早上推一份简报、按固定时间提醒你某件事。
- **你人在外面、电脑没开时临时想办的事**：这类需求用本地端就等于白等，用云 Bot 才有结果。

一个具体的对照：你说「每天早上把几家店铺的销量汇总发我」，如果数据在网页后台，云 Bot 就能干；如果数据躺在你电脑桌面的 Excel 里，那必须让本地端来读。

## 四、云 Bot 做不到什么

- **碰不到你本机的文件**：读不了桌面上的文档、也打不开你电脑里装的软件。这是架构决定的，不是配置问题——想让它操作本机，只能回到本地端。
- **记忆跟本地端不互通**：桌面端、云 Bot、各个聊天渠道的对话上下文各自独立。你在手机端教它的偏好，不会自动出现在云 Bot 里。想跨端一致，得主动让它把内容写进共享的记忆文件。
- **一样要消耗积分**：云 Bot 不是免费通道，规模稍大的任务会实打实扣额度，怎么算见 [积分和会员怎么算.md](积分和会员怎么算.md)。

## 五、怎么选：三个判断问题

1. **要动的东西在你电脑里吗？** 是 → 本地端；不是 → 云 Bot 可以。
2. **你能保证电脑一直开着吗？** 不能，而这个任务又必须按点跑 → 云 Bot。
3. **任务里有没有「打开某个软件、点某个按钮」？** 有 → 只能本地端。

三个问题都落在云 Bot 上时，才值得单独去配它；否则用你已经在用的本地端更省事。两端的角色分工见 [手机端和电脑端怎么连起来.md](手机端和电脑端怎么连起来.md) 第一节，用起来发现没反应，先看 [常见问题与排查.md](常见问题与排查.md)。
