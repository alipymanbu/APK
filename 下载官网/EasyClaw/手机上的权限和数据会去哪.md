一个能操作你电脑、还会看屏幕的客户端，权限问题迟早会碰到。本篇不做评价，只做两件事：把系统权限和它换来的功能对上号；把官方隐私政策里逐项列出的收集内容抄给你看。判断留给读完之后的你。

## 一、权限清单：每一项换来什么

下面这些是应用商店页面上登记的权限项，以及它们对应的功能。**不给某一项，对应功能就用不了，其它功能不受影响。**

| 权限 | 换来的功能 | 不给的后果 |
| --- | --- | --- |
| 查看网络状态、开关 WLAN | 判断当前网络可用性 | 联网相关功能异常 |
| 完全互联网访问 | 把指令送到电脑、把结果取回来 | 应用基本不可用 |
| 读取 / 写入文件与文档 | 在手机上选择附件、保存结果文件 | 不能上传文件、不能保存产出 |
| 录音 | 语音输入指令 | 只能用打字 |
| 拍摄照片和视频 | 拍照类输入 | 不能用相机作为输入源 |

只想先用文字对话的话，录音和相机可以先放一放，需要时再回系统设置里补。

## 二、被截的屏，是电脑的屏

这是最容易误会的一处。官方隐私政策把「AI 辅助操作」列为一项收集场景，涉及的内容包括：

- 你输入的文本内容；
- **当前屏幕的截图数据（含坐标信息）**、屏幕分辨率、窗口显示状态；
- 任务执行相关的屏幕内容；
- 你设置的点击坐标、点击频率、操作触发的窗口标识。

从「点击坐标」「窗口标识」这些字段就能看出，**这里说的是电脑屏幕，不是手机屏幕**。它的作用是让模型看懂界面上有什么、该点哪里。官方在使用指南里也单独说明过：接进来的手机渠道只充当消息通道，不会截取手机屏幕，也不会影响手机上的数据。

想减少这类数据，最直接的做法是**少派需要「看着屏幕点」的任务**；纯查资料、纯整理文本的任务不涉及这一块。

## 三、官方隐私政策里还有这几类记录

同一份政策用清单形式列了全部收集场景，其中几项容易被忽略：

| 场景 | 涉及内容 |
| --- | --- |
| 账号注册 / 登录 | 手机号、短信验证码；用微信登录时是微信昵称与头像 |
| 知识问答 | 你输入的问题、上传的图片 / 文件 / 语音、对话交互记录、你对结果的满意与否 |
| 增值服务 | 订单信息、交易状态、积分余额 |
| 定时任务 | 任务名称与图标、执行时间、AI 指令 |
| PowerShell 脚本 | 你输入或上传的脚本内容、脚本执行日志、系统返回的执行结果 |
| 手机远程 | 飞书 / 钉钉 / QQ 的 App ID（Client ID）与 Secret、你与手机机器人的交互记录 |
| 客户服务 | 设备型号、系统版本、软件版本号、反馈内容与联系方式、你上传的截图、与客服的聊天记录 |
| 产品数据分析 / 渠道归因 | IP 地址、设备型号、Android ID、设备品牌型号与系统版本、设备序列号、剪切板内容 |

两点值得单独说：

- **脚本内容和执行日志也在收集范围内。** 如果你让 Agent 跑脚本，脚本本身就是被记录的对象——别把密钥、口令直接写进交给它执行的脚本里。
- **剪切板内容被列在「数据分析与渠道归因」这个场景下。** 该场景的用途是产品数据分析和渠道归因。如果这一项对你敏感，可以在系统设置里限制该应用的剪切板读取权限，或在使用期间自行清空剪切板。

## 四、本地执行和云端的分界

同一个产品在两种运行形态下，数据的落点不一样：

| | 桌面端（跑在你电脑上） | 云 Bot（跑在服务商服务器上） |
| --- | --- | --- |
| 文件、记忆、配置 | 留在你的电脑上 | 存在云端 |
| 截图与本地操作数据 | 在设备内处理 | 不在这一侧发生（它够不着你的电脑） |
| AI 请求 | 发送到你选用的模型服务商，用于生成回复 | 同样发送到模型服务商 |

**降级风险最有效的动作是少用云那侧**：能在自己电脑上跑完的事，就不必交给云 Bot，分工见 [不用电脑时的云Bot怎么用.md](不用电脑时的云Bot怎么用.md)。

## 五、想核对原文，从这两个入口进

- **应用内**：首次启动的协议页，以及设置里的协议与隐私入口，都能打开完整政策。
- **官方站点**：官方站点的隐私政策页（[easyclaw.cn 隐私政策](https://www.easyclaw.cn/privacy/easyclaw-dl-privacy.html)）。该政策的更新日期是 2026 年 9 月 20 日，功能变化后官方会更新，**以页面当次显示的版本为准**。

## 六、给权限时的三条做法

1. **按需给，不按提示给。** 弹窗是一次性询问，当时拒绝了照样能回系统设置里补；先用不到的功能，对应的权限可以先不给。
2. **设备控制类授权只在自己的设备上开。** 官方协议的口径是：只有你自己合法拥有、使用或管理的设备，才适合接进来做远程控制。
3. **定期回系统设置复查一遍。** 权限给出去以后不会自己收回，换手机、换账号后尤其值得再看一次。

账号层面的规则（一人一号、权益不可转移、账号不可共享）见 [手机端和电脑端怎么连起来.md](手机端和电脑端怎么连起来.md) 第五节；安装时那几个权限弹窗的顺序见 [下载与安装教程.md](下载与安装教程.md) 第四节。
