EasyClaw 不用订阅也能开始用，但它不是「装完就无限跑」——每一次让模型干活都在扣积分。搞清积分从哪来、先扣哪一种、什么时候作废，比事后发现额度没了再想办法要省事得多。

## 一、免费版每天能用多少

免费版（Standard）的方式是**每天补到 200 积分**：每天 00:00 自动补充至 200 点，**当天有效，当天没用完就归零**，不累计。账号上能积存的每日积分有上限，官方口径是 2,000 点。

免费版同时解锁本地设备控制与自动化、核心 AI 技能，够把第一个自动化流程跑通。要判断「这套够不够我用」，看第二节的消耗口径比看数字更直观。

## 二、三种积分：先扣哪种，什么时候过期

| 积分类型 | 怎么拿到 | 有效期 | 消耗顺序 |
| --- | --- | --- | --- |
| 每日积分 | 每天 00:00 自动补至 200 点 | 仅当天 | 最先扣 |
| 订阅积分 | 会员有效期内按月发放，按你的订阅日刷新 | 3 个月 | 其次 |
| 购买积分 | 会员身份下购买加油包获得 | 加油包自到账起 365 天 | 最后扣 |

结算时按「先到期先抵扣」——快到期的先用掉，所以放着不用并不会更划算。关于购买积分，官方两处说明有细微差异：一处的说法是「累积不清零，只要续费就继续有效」，另一处的说法是「自到账之日起 365 天内有效」。实际以你账户里显示的有效期为准。

## 三、会员档位大致怎么分

官方把会员分成四档，**具体价格与权益以官方购买页当时显示为准**：

| 档位 | 定位 | 每月积分（官方公示口径） |
| --- | --- | --- |
| Standard（免费） | 基础体验 | 每天 200 |
| Plus（基础版） | 个人进阶 | 8,800，或 2,800 加 1 个月云 Bot 使用权 |
| Pro（专业版） | 专业创作 | 17,600，或 11,000 加 1 个月云 Bot 使用权 |
| Ultra（旗舰版） | 极致算力 | 44,000，或 37,400 加 1 个月云 Bot 使用权 |

付费方式提供月付与年付，年付官方标注可省约两成。付费档位另有一项「每日额外赠 200 积分」的规则，同样有 2,000 点上限。

## 四、什么在扣积分

| 你的动作 | 扣不扣积分 |
| --- | --- |
| 普通对话（用平台内置模型） | 扣 |
| `browser-use`（浏览器控制）、`computer-use`（电脑控制） | 扣 |
| 图像生成、语音转写 | 扣 |
| 对话，但用的是你自己填的 API Key | 不扣 |
| 上一条里的控制类、生成类服务，即使自备 Key | 照扣 |

最后两行是很多人会误解的地方：**自备 API Key 能省下的是对话那一部分，控制电脑、开浏览器这类走官方底层的服务仍然计费。**

## 五、积分的有效期、退款与转移

- **当月没用完的会员权益积分，周期结束即失效**，不退款、不结转、不退换。
- **付费后不支持退款**。
- 官方在 V1.3.23 及以上版本开放了积分在**桌面版与企业版之间转移**，其它版本之间不行。
- 取消自动续费后，订阅在当前计费周期结束前继续有效；周期结束后降为免费计划，**已购买但未使用的积分会保留在账户里**。

## 六、额度掉得比预想快，按这个顺序处理

1. **换低倍率模型**。官方举的例子是 Qwen 3.5 Plus 这类低倍率模型，同一件事换个模型能省下不少。
2. **定期清上下文**。对话历史越长，每次请求带的上下文越多。官方建议每 10 到 20 轮发一次 `/new` 清空历史。
3. **把大任务拆小**。一句「把我所有工作整理一遍」会一路膨胀；拆成几个有边界的步骤，每步都短，总消耗反而更低。
4. **长期省钱**：配置自定义 API Key，对话部分的消耗转到你自己账号上。
5. **真想压成本，就顺便改改说话方式**——把任务说得具体、少来回确认，本身就是省积分，写法见 [指令怎么写才会照着做.md](指令怎么写才会照着做.md)。

## 七、在哪看自己花了多少

- **查余额**：应用内的积分显示区域，通常在头像或右上角一带。
- **查消耗明细**：走「头像 → 积分」这条路径可以看到积分消耗记录；桌面端另有「账单与用量」入口，能看到每项操作的积分消耗。
- **查状态**：在对话框里发 `/status`，可以看积分情况和运行状态。

额度是够用还是不够，答案取决于你在跑什么任务；如果发现每次都是同一类任务在吃额度，考虑把它改成云端定时跑一次即可，见 [不用电脑时的云Bot怎么用.md](不用电脑时的云Bot怎么用.md)。积分之外的问题走 [常见问题与排查.md](常见问题与排查.md)。
