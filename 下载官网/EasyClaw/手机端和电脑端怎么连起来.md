# EasyClaw 手机端和电脑端怎么连起来

你在手机上装的 EasyClaw 和电脑上装的 EasyClaw，是同一套东西的两个端。手机端很难单独成事，它的价值恰恰在于「人不在电脑前」时还能发号施令。这篇把两端的连接前提、连接动作和常见断点讲清楚。

## 一、两端分别负责什么

| | 电脑端（桌面端） | 手机端（网盘里这份） |
| --- | --- | --- |
| 角色 | 干活的机器 | 发指令、看结果的入口 |
| 能做什么 | 读写本地文件、执行终端命令、操作系统界面与浏览器 | 输入指令、语音输入、上传图片与文件、查看任务结果 |
| 依赖 | 电脑要开着、不能睡死 | 手机能联网、账号与电脑端一致 |
| 支持系统 | Windows 10 / 11、macOS 12.0+（Apple 芯片与 Intel 芯片版本不同） | Android |

两句话概括：**没有电脑端，手机端发出去的活没人干；没有手机端，你只能坐在电脑前指挥它。** 如果连电脑都不方便开，还有第三条路——云端跑的 Bot，见 [不用电脑时的云Bot怎么用.md](不用电脑时的云Bot怎么用.md)。

## 二、连之前必须准备好的三件事

按顺序过，缺一项就连不上：

1. **电脑上装好桌面端，并登录和手机端同一个账号**。两端账号不一致，是「明明都登录了却互相看不见」最常见的原因。
2. **账号类型和登录方式要统一**。国内版用手机号或微信登录，海外版用 Google 账号登录；两个版本的账号体系不互通，也不能同时装在一台电脑上（安装目录相同，装第二个会覆盖第一个）。
3. **让电脑保持在工作状态**。桌面端的 Agent 跑在你自己的电脑上，你一关机它就不干活了；笔记本合盖休眠、系统进入睡眠，任务会中断。跑长任务前把电源接上、关掉自动休眠、切到高性能模式更稳妥。

## 三、把两端连起来

1. **手机端先登录**（见 [下载与安装教程.md](下载与安装教程.md) 第四节），进到设备页。
2. **按应用内的引导在电脑上安装桌面端**，安装包在官方站点获取，登录时用与手机端相同的手机号或微信账号。
3. **两端都登录完成后，手机端的设备页会出现这台电脑**。之后在手机上下达的指令，就是发给它执行。

除了这个「同一个账号」的连接方式，桌面端这边还提供另一条路：在桌面端打开「手机远程」→「远程控制」，把飞书、钉钉、微信、企业微信、QQ 这类聊天工具接成渠道。通道不同，效果类似——都是你在别处发消息，电脑上的 Agent 去执行。飞书的接入体验最完整（扫码一键就能建机器人），钉钉和企业微信需要先去各自的开发者后台拿到 Client ID / Secret 或 Bot ID / Secret，再填回桌面端。

两条路的取舍：手机端 App 能看到设备状态、任务结果更集中；聊天工具渠道的好处是不用再装一个 App，在天天打开的软件里就能发号施令。

## 四、连上之后，指令怎么走

以手机端的完整链路串一遍，出问题时按同一顺序往回找：

1. 你在手机端输入一句话；
2. 指令经你的账号走到电脑端；
3. 电脑端把你这句话理解成步骤，逐步操作本机；
4. 执行结果回到手机端，推送或显示结果。

所以「手机上有反应、电脑上没动作」和「手机上都发不出去」，是两个不同的问题——前者查电脑端，后者查网络与账号。具体对照见第六节。

## 五、用这套连接方式的边界

1. **只连自己的设备。** 手机端与电脑端靠同一账号识别，把账号给别人用，等于把你的电脑交给别人操作。这也是官方协议里明确不鼓励账号共享的原因——账号共享本身还可能导致权益被取消。授权前后的取舍见 [手机上的权限和数据会去哪.md](手机上的权限和数据会去哪.md)。
2. **电脑关机就断。** 需要 7×24 一直在岗的任务，本地端做不到，得考虑云端方案。
3. **记忆是按端独立存的。** 手机端渠道与电脑端桌面端的对话上下文互相独立，想让它两边都记住，要主动让 Agent 把内容写进共享的记忆文件里。

## 六、连不上或者电脑不执行，按这个顺序查

从最近改动过的地方往回找，比从头翻一遍快：

1. **两端账号是不是同一个** —— 手机端退出重新看一眼登录方式（手机号还是微信），再去电脑端核对。
2. **电脑端是不是还在运行** —— 桌面端进程被关掉、或电脑进入睡眠，都不会执行任何指令。远程任务最常见的失败原因就是它。
3. **手机端这条指令有没有真的发出去** —— 网络不稳时消息可能一直转圈，切到浏览器确认手机能正常上网再重发。
4. **是不是额度用完了** —— 积分耗尽时表现和「不执行」很像，在应用内查一下积分余额，规则见 [积分和会员怎么算.md](积分和会员怎么算.md)。
5. **走的是哪条通道** —— 如果用聊天工具渠道而不是手机端 App，那要查的是那个渠道的连接状态（例如桌面端里输入「检查飞书连接」）；渠道连不上，跟手机端 App 没关系。
6. **电脑在跑、手机上却一直没提醒** —— 先打开应用看有没有记录：有记录说明只是消息没推到你手机上，按 [手机端收不到结果怎么办.md](手机端收不到结果怎么办.md) 处理通知与后台设置。

前面几条都过了还是不动，就换一件最小的事试一次（比如让它「在桌面新建一个文本文档」）——能判断出是链路问题还是那条任务本身太难。剩下的疑难见 [常见问题与排查.md](常见问题与排查.md)。
