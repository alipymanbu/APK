EasyClaw 的安卓端更像一台遥控器，而不是干活的机器：你的话从这里发出去，真正动手读写文件、点键鼠的是同一账号下装了桌面端的电脑。所以这篇的目标很具体——把这份包装进手机、能登录、能走到设备页；至于两端怎么接通，看完这篇接着看 [手机端和电脑端怎么连起来.md](手机端和电脑端怎么连起来.md)。

## 一、先认清网盘里这份是哪一版

应用商店页面显示的是官方当时的最新版，和网盘里这份常常不是同一个版本号。本篇出现的版本、包名、体积，一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | EasyClaw |
| 版本号 | 2026.4.151 |
| 包名 | `com.cf.easyclaw` |
| 安装包体积 | 38.85 MB |
| MD5 | `39dfb73445c26a2d8a660751c2435eca` |
| 开发者 | 北京灵豹智能科技有限公司 |
| 适用平台 | Android（手机端 APK） |
| 收费情况 | 应用本身免费下载，使用中按积分计费，另有会员套餐 |

装之前先弄清四件事：

- **手机上这份只是入口。** 它负责把你说的话转成指令发出去、把执行结果收回来；文件读写、软件操作都发生在电脑上。只装手机端、电脑上什么都不装，多数任务跑不起来。
- **认包名，别只认名字。** 搜「EasyClaw」会带出同名的其它产品和同一族「Claw」的不同项目，其中有的根本不是这个客户端（怎么分辨见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)）。这份的包名是 `com.cf.easyclaw`，装好后在「设置 → 应用 → 应用管理 → EasyClaw」里能点进去看到；装之前能对的只有体积和 MD5。
- **这是安卓包，iPhone 装不了。** 官方 iOS 侧走的是另一个分发入口，跟这份 APK 不是同一个文件。
- **这份包没有标注最低安卓版本**（官方页面与应用商店页上都没有这一项）。所以能不能装不靠对表判断，判断标准就是装得上、打得开：装不上或者装完打开即退，说明这台手机跑不了这一版。
- **这一版的更新集中在三处**：Agent 展示的图标与视觉统一、聊天支持删除与清理对话记录、设备页面的显示与交互做了调整。装完如果想确认自己手上是哪一版，看应用内「关于」或应用信息页的版本号即可。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [EasyClaw 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7340bf871d64)，在手机夸克 App 里打开最省事。
2. **先转存再下载**：选中安装包转存到自己的网盘目录，再从转存目录下载。分享链接以后可能失效，转存过的那份不受影响。
3. **核对体积**：下载完成后看一眼文件体积，应当约 38.85 MB。中途断网重连导致体积偏小时，安装阶段会直接报「解析包错误」。
4. **要更稳的核对方式**：把包放到电脑上算一遍 MD5，结果应与上表一致（大小写不敏感）。

```cmd
certutil -hashfile EasyClaw_v2026.4.151.apk MD5
```

安装包文件名随版本变化，以你实际拿到的那一份为准。

## 三、安装步骤

1. **给打开安装包的那个应用授权**：进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把文件管理器（或浏览器）的开关打开。国产定制系统常把这一项收在「安全」「隐私」分类下。
2. **点击 APK 开始安装**：系统提示「来自未知来源」「未经安全检测」时选择继续，这是侧载安装包的常规提示，不代表文件有问题。
3. **安全中心拦下来时**：在拦截记录里选「继续安装」；如果直接被静默拦掉，回第 1 步确认权限。
4. **手机上已有更高版本会装不上**：安卓不允许低版本覆盖高版本，会报「应用未安装」。卸载会一并清掉本机数据，也就是这台手机上的登录状态和已有对话；应用内本身提供了删除与清理对话记录的入口，动手前先翻一遍有没有想留的内容。
5. **留出安装空间**：安装过程中系统还要展开一份文件，建议预留 500 MB 以上可用空间。

## 四、第一次打开：登录与授权

1. **先过协议页**：首次启动会有「同意并使用」这类入口，点进去才能到主界面。
2. **用手机号或微信登录**。这一步的账号就是你后面在电脑端要登录的同一个账号，记清楚用的是哪一种。
3. **逐条处理系统权限弹窗**。应用商店页面上登记的权限项包括：查看网络状态、开关 WLAN、完全互联网访问、读取与写入文件、录音、拍摄照片和视频。弹窗是一次性询问，当时点了「拒绝」，之后就要到「设置 → 应用 → EasyClaw → 权限」里手动改回来；只用对话功能的话，录音和相机可以先不给。每一项权限各自换来哪个功能、官方政策里写了收集哪些内容，见 [手机上的权限和数据会去哪.md](手机上的权限和数据会去哪.md)。
4. **进到主界面后，先找设备页**。设备页里此刻大概率是空的——因为还没有任何一台电脑登录过这个账号，这是正常状态，下一步在 [手机端和电脑端怎么连起来.md](手机端和电脑端怎么连起来.md)。

## 五、装完顺手核对三件事

- **应用信息页里的包名**是 `com.cf.easyclaw`。以后再从别处拿到一个「EasyClaw」，拿这一条一对就知道是不是同一个应用。
- **版本号对得上 2026.4.151**。如果你装的是一份明显更新的包，版本号写法会不一样，属正常，但本文里的体积、MD5 就不再适用。
- **应用内通常带一份新手教程**。各版本入口位置不固定，找不到也不用找——本文后面几篇覆盖的就是它讲的内容。

## 六、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整 | 重新核对体积与 MD5，按第二节再取一次 |
| 提示「应用未安装：签名不一致」 | 手机里已有同包名、不同来源的版本 | 先在应用管理里卸载旧包，再装这份 |
| 点安装没反应 | 「安装未知应用」权限没给 | 回第三节第 1 步补上 |
| 安装被安全中心静默拦掉 | 系统安全策略 | 在拦截记录里放行，或临时关闭拦截后重试 |
| 装完打开就闪退 | 系统版本过低、存储不足或包残缺 | 换一份完整包重装；仍不行见 [常见问题与排查.md](常见问题与排查.md) |
| 登录后一片空白 | 还没绑定任何设备 | 属于正常状态，见第四节第 4 步 |

以后换版本或重装，按第二节重新取一份即可，安装动作与这次完全相同。
