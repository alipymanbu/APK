# EasyClaw 手机端收不到结果怎么办

> 任务发出去了却没动静时，先分清是「推送没到」还是「指令没送到」；本篇给一份从通知权限到厂商后台白名单的检查表。

「发了指令，手机上半天没反应」有两条完全不同的成因：任务在电脑上跑完了、但结果没推到你手机上；或者指令压根没送到电脑。前者查手机，后者查链路。先按第一步分流，再决定修哪边。

## 一、先分清是哪一种

| 你在应用内看到的 | 说明 | 该去哪 |
| --- | --- | --- |
| 任务在跑、或已经跑完，只是没弹通知 | 手机把通知拦了，任务本身没事 | 往下看第二到第五节 |
| 应用内也没有这条记录，或者一直停在发送中 | 指令没送出去或没被接收 | [手机端和电脑端怎么连起来.md](手机端和电脑端怎么连起来.md) 第六节 |

**判断要点是应用内有没有记录，而不是手机有没有响。** 通知只是提醒，任务的真实状态以应用内为准——所以第一步永远是先打开应用看，而不是反复重发指令。

## 二、安卓上通知被拦住的四种常见原因

按影响面从大到小排：

1. **通知权限没给。** 安卓 13 起，应用必须拿到通知权限才能弹通知；首次启动时如果点了「拒绝」，之后**一条都不会显示**，而且不会再弹第二次提醒。
2. **系统省电策略限制了后台。** 国产定制系统默认会在锁屏一段时间后限制后台活动，表现是通知晚到、或者干脆不到。
3. **勿扰 / 睡眠 / 省电模式在生效。** 这几类模式会静音通知，甚至切断后台数据。
4. **数据省电（流量节省）挡住了后台联网。** 应用在后台拿不到网络，自然也推不出通知。

## 三、按品牌把应用放进白名单

菜单名和层级各机型差异很大，找不到原文时，直接在系统设置里搜「电池优化」「自启动」「后台」这三个词，通常能定位到对应开关。

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → EasyClaw → 权限 → 自启动：开；设置 → 电池与性能 → 选择该应用 → 无限制；在最近任务卡片上给它加锁 |
| 华为 / 荣耀 | 设置 → 电池 → 应用启动管理 → 找到该应用 → 关闭「自动管理」，把自启动、关联启动、后台活动三项打开 |
| OPPO / 真我 / 一加 | 设置 → 电池 → 电池优化 → 该应用 → 不优化；关闭「后台冻结」；在手机管家里允许自启动 |
| vivo / iQOO | 设置 → 电池 → 后台耗电管理 → 该应用 → 允许后台高耗电；i 管家 → 自启动管理 → 允许 |
| 三星 | 设置 → 电池 → 后台使用限制：把它从「休眠应用」里移出，并加入「永不休眠的应用」 |

上面这些开关的共同作用是：**允许应用在锁屏后继续留在内存里**。通知能不能及时到达，取决于它还在不在。

## 四、锁屏之后收不到，先查这三项

1. **睡眠时保持网络连接**：在设置的网络或电池分类下，打开这一项，避免手机一睡就断网。
2. **电池优化是否被设成了「优化 / 受限」**：改回「不受限制」。
3. **是否开着省电模式**：省电模式会主动限制后台，临时关掉再试一次。

## 五、通知会来，但要手动打开应用才刷新

这是后台被系统清掉的典型特征——应用不在内存里，通知就没有来源，重新打开应用时它才重新连上并把状态拉回来。按第三节把白名单配好，这类现象会明显减少。

## 六、这样做要付出什么代价

- **允许常驻后台会增加耗电**，这是必然的，属于拿电换实时性。
- **只在需要远程盯任务的那段时间开着更划算**；平时不远程派活时，把后台权限收回，通知晚一点并不影响任务本身——任务在电脑上照跑不误。
- **别把「收不到通知」当成任务失败**。任务状态以应用内记录为准，通知只是提醒层。

## 七、配置都做了还是收不到

按顺序试：换一次网络（Wi-Fi 与移动数据互换）→ 重启手机 → 卸载重装并重新授权。到这里还不行，就把它当作账号或服务端问题，带上「你做了什么、看到什么」联系官方支持，入口见 [常见问题与排查.md](常见问题与排查.md) 第十节。

需要顺带确认电脑那侧有没有正常执行的话，判别方法在 [常见问题与排查.md](常见问题与排查.md) 第三节；指令本身太含糊也会让你误判成「没反应」，写法回顾 [指令怎么写才会照着做.md](指令怎么写才会照着做.md) 第二节。
