故障排查最忌讳从第一个按钮开始逐个点。下面按「你看到的现象」分类，每一类都按从近到远的顺序排——先查最近改动过的东西，再往前追。

## 一、装不上、装完打不开

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整 | 回 [下载与安装教程.md](下载与安装教程.md) 第二节重新取一份，核对体积与 MD5 |
| 提示「应用未安装：签名不一致」 | 手机里有同包名、不同来源的版本 | 在应用管理里卸载旧包再装 |
| 点安装没反应 | 没开「安装未知应用」权限 | 设置 → 应用 → 特殊应用权限 → 安装未知应用，放行文件管理器 |
| 被安全中心静默拦掉 | 系统安全策略 | 在拦截记录里放行，或临时关闭拦截 |
| 装完打开就闪退 | 系统版本偏低、存储不足、包残缺 | 先清出空间并换一份完整包重装 |

## 二、登录与账号

- **收不到验证码**：确认手机号没写错，稍等再取一次；被短信拦截软件挡掉也很常见。
- **微信登录点不动**：多为手机上未登录微信或微信版本过低，先在微信里确认登录状态再回来。
- **换设备后「原来的东西不见了」**：先确认登录方式和你原来用的是不是同一种（手机号还是微信）。国内版与海外版账号体系不互通，同一个人的两个账号是彼此独立的。

## 三、手机端连不上电脑端

按这个顺序查，绝大多数问题在前两步：

1. **两端是不是同一个账号** —— 退出重登，看清登录方式。
2. **电脑端是不是还在运行** —— 电脑关机、合盖休眠、桌面端进程被关掉，都不会执行任何指令。远程任务失败最常撞上的就是这一条。
3. **设备页里有没有这台电脑** —— 空的话说明这台电脑从没登录过该账号，回 [手机端和电脑端怎么连起来.md](手机端和电脑端怎么连起来.md) 第三节。
4. **网络是否通** —— 手机端指令一直转圈，先用浏览器确认手机能上网，再重发一次。
5. **用的是哪条通道** —— 如果走的是聊天工具渠道而不是手机端 App，查的是那个渠道的连接状态，跟 App 无关。

## 四、发了指令没反应，或者只给方案不动手

这三种表现的原因完全不同：

- **只回文字方案、不执行操作**：先确认任务里是不是带了「打开软件、点按钮」这类只在本机能做的事——云端那套够不着你电脑，分工见 [不用电脑时的云Bot怎么用.md](不用电脑时的云Bot怎么用.md)。如果确定用的是本地端，去看它的角色设定里有没有「优先执行操作」这类约束，把人设放宽后再试；同时确认完成这件事需要的技能已经装上。
- **完全没反应**：先去查额度（发 `/status` 看积分和运行状态），再看电脑端是不是掉线了，最后确认这条指令是否已经发出。
- **应用里有记录、手机上没弹通知**：任务多半已经跑了，只是提醒没到你手机上，处理方式见 [手机端收不到结果怎么办.md](手机端收不到结果怎么办.md)。

## 五、跑到一半卡住、报错中断

| 报错 / 现象 | 通常的原因 | 处理 |
| --- | --- | --- |
| `LLM request timed out` | 模型服务过载、上下文太长、任务过大 | 发 `/new` 清空历史，换低延迟模型（如 DeepSeek、Kimi、通义千问），把任务拆小重发 |
| 执行到某一步停住不动 | 那一步需要的权限没给，或那一步本身做不到 | 看停在哪一步，把该给的系统权限补上；仍不行就把任务拆开单独跑 |
| 隔一段时间回来发现任务没了 | 电脑睡眠或被关机，任务被中断 | 接上电源、关掉自动休眠、切高性能模式后重跑 |
| 整件事越跑越慢 | 上下文堆积 | 按 [指令怎么写才会照着做.md](指令怎么写才会照着做.md) 第四节清一次上下文 |

## 六、积分与额度

- **额度去哪看**：应用内积分显示区域看余额；「头像 → 积分」看消耗记录；桌面端「账单与用量」看每项操作的消耗。
- **掉得比预期快**：先换低倍率模型，再按官方建议每 10 到 20 轮发一次 `/new`，最后检查是不是把大任务整包丢给它了。完整规则见 [积分和会员怎么算.md](积分和会员怎么算.md)。
- **自备了 API Key 还在扣**：对话部分不扣，但浏览器控制、电脑控制、图像生成、语音转写这类走官方底层的服务照扣。

## 七、接进飞书 / 钉钉 / 企业微信之后不回复

按这个顺序分：

1. **先在桌面端直接发一条消息**。桌面端能回、聊天工具里不回 → 问题在渠道连接；桌面端也不回 → 问题在本体，跳到第五节。
2. **检查渠道连接状态**。飞书渠道可以在对话框里输入「检查飞书连接」；其它渠道回桌面端「手机远程」页面看连接状态，必要时断开重连。
3. **电脑是不是睡了**。渠道消息要送到你电脑上的 Agent 才能执行，电脑睡了自然不回。
4. **钉钉 / 企业微信的群聊场景**：群的归属组织必须和创建机器人时用的组织一致，否则机器人加不进群。
5. **飞书扫码建机器人的场景**：扫码过程中关掉桌面端页面会导致连接失败；企业应用提交后要等管理员审核，审核通过才会自动连上。

## 八、换手机、换电脑，数据还在吗

- **V1.3.33 及以上版本**支持云端备份与恢复：旧电脑走「头像 → 云端备份/恢复 → 新建备份」，新电脑登录后恢复同一份备份即可。注意云端备份只保留 60 天，会员到期后数据会被清除。
- **低版本要手动搬**：把 `workspace` 目录下的 `SOUL.md`、`AGENTS.md`、`MEMORY.md` 以及整个 `memory/` 文件夹复制到新电脑对应位置。
- **搬不走的**：渠道配置要重新配一遍，积分和套餐无法手动迁移；国内版与海外版之间数据不互通。
- **换手机只影响登录**：手机端是入口，任务记录与记忆主要跟着账号和电脑端走。

## 九、担心给出去的权限和隐私

装的时候它要过通知、存储、录音、相机，用起来还会看屏幕、跑脚本。这些授权分别换来什么、官方隐私政策里逐项列了哪些收集内容，见 [手机上的权限和数据会去哪.md](手机上的权限和数据会去哪.md)。其中三条最容易忽略：

- **脚本内容和执行日志也在收集范围内**，别把口令、密钥直接写进交给它执行的脚本里。
- **截图指的是电脑屏幕，不是手机屏幕**；接进来的手机渠道只当消息通道，不截手机屏、也不动手机上的数据。
- **能在自己电脑上跑完的事就不必交给云 Bot**，云端那侧的落点数据更多，分工见 [不用电脑时的云Bot怎么用.md](不用电脑时的云Bot怎么用.md)。

## 十、什么时候该找官方支持

出现下面几种情况再联系官方渠道，比继续自己试更划算：

- 同一问题反复出现、多次尝试后可稳定复现；
- 账单金额与实际使用对不上；
- 怀疑账号本身被限制或配置被改，而你在界面里改不回来。

支持邮箱是 [support@easyclaw.com](mailto:support@easyclaw.com)。联系时把「你做了什么、看到什么、试过哪些」写清楚，比只贴一张截图有用。
