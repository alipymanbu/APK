## 一、这是个什么应用

Dynadot 是一家 ICANN 认证的域名注册商，你平时在它家网页上注册的域名，可以用这个官方 App 在手机上继续管理。它不是单独的"工具集"，而是与你同一个 Dynadot 账户、同一套域名数据互通的客户端：手机上改的 DNS、续的费、出的价，网页端同步生效。适合已经在 Dynadot 有域名、或者想在手机上完成注册全流程的人。

几点注意：

- 国内部分商店对近期版本标注"Android 8.0 以上"，与这份包标注的要求不同——以你实际打开的官方商店页面为准。
- 装之前可以用任意校验工具比对 MD5，与上表一致说明文件完整、没有在传输中损坏。

## 三、从网盘获取安装包

打开 [Dynadot 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7a7b321e2a2e)，转存到自己的网盘后下载 `Dynadot_v3.12.5.apk` 到手机即可。网盘里同时放了一份"先保存再下载"的说明文件，照做可以避免分享失效后找不到包。

## 四、安装步骤

1. 把 APK 传到手机（数据线、网盘 App 下载都行）。
2. 用手机自带的文件管理器点这个 APK。
3. 系统若弹出"禁止安装来自此来源的应用"，这是正常的陌生来源拦截——进入设置允许该来源（通常在"安装未知应用"里按文件管理器逐个授权），再返回继续安装。
4. 装完打开，首屏就是域名搜索页，登录入口在侧边菜单里。

装不上时先看三件事：安装包有没有下完整（比对 MD5）、手机存储是否够（包体 49.91M，解压与安装需要更多空间）、系统版本是否满足要求。

## 六、装好之后先做什么

第一次打开需要一个 Dynadot 账号——已有域名的直接登；没有账号的可以在 App 里或官网注册。登录如果开了两步验证，还要准备验证码工具，具体见 [登录与账号安全设置.md](登录与账号安全设置.md)。登进去之后怎么搜域名、怎么下单，见 [域名搜索与注册教程.md](域名搜索与注册教程.md)。

## 七、安装时会看到的权限提示

国内应用商店页面给这个包标注的权限不少，装的时候留意弹窗。常见的几项与用途对照（以商店页面标注与你手机实际弹出的提示为准）：

| 权限 | 商店标注的用途 |
| --- | --- |
| 请求安装文件包 | 安装/更新自身，装完可拒绝后续 |
| 网络访问、查看 WLAN / 网络连接 | 域名查询、行情刷新的基础项，不给就用不了 |
| 相机 | 扫二维码（如两步验证的绑定二维码） |
| 读写存储 | 上传文件、下载文件 |
| 位置（精确/粗略、后台） | 商店标注为统计使用范围与推送——与域名功能无关，介意的话在系统设置里拒掉 |
| 电话状态、开机启动、显示在其他应用上等 | 同属与核心功能关联弱的一组，可按需拒绝 |

处理原则：**网络与安装类权限给足，位置与电话类按需拒绝**——拒绝后如果某功能确实异常，再去系统设置里单独放开那一条即可。
