## 一、这篇解决什么

域名转移不是搬家，是"换注册商"：域名本身不动，管理权从 A 家转到 B 家。方向有两个——转入 Dynadot 和从 Dynadot 转出。两边的流程都围绕两把锁：**账户锁**和**域名锁**（详见 [登录与账号安全设置.md](登录与账号安全设置.md)），以及一串 **授权码（Auth Code / EPP 码）**。本篇把两个方向各自讲清。

## 二、先记住两条通用规则

| 规则 | 内容 | 来源口径 |
| --- | --- | --- |
| 60 天锁定 | 域名**注册或上次转移后 60 天内**不能转移（ICANN 规定），期间无法强行解除 | 官方帮助与转入页一致 |
| 别卡到期日 | 建议在到期前**至少 2 周**启动转移；临到期 7~14 天内转移容易出岔子，可能要先续费 | 官方转移帮助 |

## 三、从 Dynadot 转出（去别家）

1. **前置检查**：注册满 60 天且 60 天内没转过；到期日还远；Whois 邮箱是能收信的（对方注册商要靠它发确认邮件）；如果是市场买来的域名，要等 Auction Lock / Buy Lock 结束。
2. **解锁账户**：域名锁在账户锁里面——先在 My Domains → Manage Domains 页面 Unlock Account（要输 PIN/密码 + 验证码）。
3. **解锁域名**：账户解锁后，勾选域名 → Action 下拉选 Unlock Domains。
4. **拿授权码**：点进域名详情，滚到 Authorization Code 区域，解锁后点 Unlock，页面会显示一串字母数字组成的授权码（也叫 EPP 码）。
5. **去新注册商发起转移**：把域名和授权码填进对方的转移页，按对方流程付款、点邮件确认。
6. **转移期间保持域名解锁**，但建议把**账户**重新锁上；流程走完域名转走后，域名锁会随新注册商的规则重新生效。

三个常见坑：

- **域名锁 14 天自动重锁**——官方说明：域名留在解锁状态超过 14 天系统会重新锁上（临近到期等因素会影响这个时限），所以解锁后尽快把转移发起完。
- 授权码**区分大小写且会过期**，复制错了或拖久了就重新生成一份。
- 少数后缀转移规则特殊（如 `.UK`、`.RO`、`.BE`），按官方对应帮助页操作。

## 四、转入 Dynadot（从别家来）

1. 在**原注册商**处解锁域名、拿到授权码；
2. 在 Dynadot 的域名转移页（或批量转移页）输入域名 + 授权码，提交进购物车结账；
3. 付款后等确认邮件，再到 **Whois 邮箱**里点批准链接——这一步不做转移不会完成；
4. 官方给出的典型时长约 **6 天**（可响应对方的确认邮件加速）；
5. 完成后域名进入你的账户，**多数后缀附带自动续 1 年**（个别后缀除外，以结算页显示为准）。

转入的费用按后缀不同（例如官方转入价页显示 `.com` $10.88、`.net` $12.52，价格会调整，以官方页面当时显示为准），转入通常还附带免费 WhoIS 隐私。

## 五、转完之后到哪确认

- **转入成功**：域名出现在 Manage Domains 列表里，年限已加；去 [域名续费与解析设置.md](域名续费与解析设置.md) 核对到期日与 NS 是否要改。
- **转出成功**：原账户里该域名消失，新注册商账户里出现；到期日不变（转出不加年，转入才加）。
- 转移失败且已付款的，官方退款政策写明域名转移失败可退款——请求需在购买后 30 天内提出，默认退到账户余额。
