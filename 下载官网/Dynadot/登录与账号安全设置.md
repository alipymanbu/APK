## 一、这篇解决什么

Dynadot 管的是域名——账号丢了等于域名跟着丢，所以它的登录比一般 App 啰嗦：密码之外还有两步验证，登录之外还有"账户锁定"这道闸。你第一次配置时会觉得繁琐，但这些机制决定了丢手机时域名还找不回来。本篇按"怎么开、怎么用、丢了怎么办"讲。

## 二、登录要提供什么

- **用户名 + 密码**：App 和网页同一套账号，从侧边菜单进登录页。
- **两步验证码（若已开启）**：验证器 App 的动态码或短信码。
- **账户处于锁定状态时**：登录后还要解锁才能改设置（见第四节）。

装 App 的前置步骤在 [下载与安装教程.md](下载与安装教程.md)。

## 三、两步验证怎么开

官方支持的验证器不限于 Google Authenticator，Microsoft Authenticator、Authy、Duo Mobile 都能用，另外还有短信验证与安全密钥两种方式。以验证器为例：

1. 手机装好任意验证器 App；
2. 网页登录 Dynadot → 左侧菜单 My Info → Security → Manage Two-Factor Authenticator；
3. 输入 Security PIN 解锁进设置页；
4. 点验证器旁的加号，弹出 **Key & QR 码**；
5. 用验证器扫码，或手动输入密钥——添加成功后条目在验证器里显示为 `Dynadot:用户名`；
6. 把 Dynadot 页面上显示的 token 填进"Generate A Token"，点 Enable Authenticator App；
7. **顺手生成备份码（Backup Codes）**：同一设置页点 Backup Codes 的加号，弹出一串一次性代码，确认保存。

第 7 步别省：备份码是"手机不在了还能登录"的唯一自助通道，必须先启用一种主验证方式才能生成。

## 四、账户锁定（Account Lock）是怎么回事

- 账户**默认处于锁定状态**，这是官方的安全设计，不是你被封号；
- 解锁（Unlock Account）时要验证身份：**2026 年 8 月 18 日及之后注册的账户用账户密码，之前的账户用 4 位 Security PIN**——如果你设了验证器/短信，还要一并输入对应验证码；
- 解锁后才能做这些事：编辑账户信息、解锁域名（转出/改关键设置前的必要动作）、改两步验证配置；
- 解锁状态**1 小时后系统会自动重新锁定**，也可以在 Security 页点 Lock Account Now 手动锁回去。

改 DNS、续费这类日常操作一般不需要解锁；要动账户级设置时卡在"要求输入 PIN/密码"就是这道闸在起作用。

## 五、密保问题与找回

密保问题是兜底里的兜底（忘 PIN、丢手机、验证码全收不到时用）：

- 截至 2026 年 7 月的规则：从 10 个问题里**选 3 个**作答，答案**区分大小写**；
- 密保问题**每 30 天只能改一次**，改之前想好——选错了要等冷却期；
- 答案务必记在安全的地方（密码管理器），忘了答案严重时需要提交身份证明人工审核。

## 六、手机丢了 / 验证码收不到

按下面的顺序自救，都从登录页或解锁页的对应链接进：

| 情况 | 入口 | 走向 |
| --- | --- | --- |
| 验证器在旧手机上，拿不到动态码 | Lost Cellphone | 用密保问题等信息申请重置验证方式 |
| 备份码还在 | 登录页直接输入备份码 | 正常登录后把验证器换绑到新手机 |
| 安全密钥丢了 | Lost Security Key | 提交重置申请，官方人工审核，页面标注约需 2 个工作日 |
| 忘了 Security PIN | Forgot Security PIN | 答密保问题换新 PIN（新账户则是走密码流程） |

所以换手机前的动作清单是：先导出/生成过备份码 → 新机装验证器前先在旧机上解除绑定 → 到 Security 页换绑新验证器。

## 七、验证频率可以调

默认每次登录都要输验证码；嫌烦可以在 Security 页的验证设置里改成**"每次新 IP 地址"**——同一 IP 记住、换网络才要求验证。安全性上"每次登录"更高，"每次新 IP"是便利折中，按自己设备固定程度选。

## 八、登录不上时的排查顺序

1. 用户名密码大小写对不对（密码区分大小写）；
2. 是不是卡在**账户锁定**上——要的是 PIN 还是密码，看你账户的注册时间（见第四节）；
3. 验证码：验证器时间是否准（验证器 App 里开启"时间同步"）、短信是否被拦截；
4. 三样都拿不到 → 走第五、六节的找回路径；
5. 还不行：App 里点 **CHAT** 可以直接连在线客服，把你账户的注册邮箱、域名等信息准备好再问。

密码本身建议在官网的账户安全页改（路径 My Info → Security），改完在 App 上重新登录一次即可。
