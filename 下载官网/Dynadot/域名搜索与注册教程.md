## 一、这篇解决什么

打开 App 首页就是"Domain Name Search"搜索页：输入想注册的词，选后缀，能查到的就直接加购物车结账。本篇按你的操作顺序讲——搜索、看价、用工具、批量查、下单付款。域名还没买、想先从安装开始的，先看 [下载与安装教程.md](下载与安装教程.md)。

## 二、搜索框怎么用

1. 首页搜索框输入域名主体（比如 `mybrand`），点 Search。
2. 结果页会列出各后缀的可注册状态与价格；首屏的价格条常显示 `.co`、`.vip`、`.io` 这类后缀的促销价（如某后缀首年优惠价与原价并排显示）。
3. 可注册的直接勾选加购物车，占用的通常会给出替代建议或跳转到市场/抢注入口。
4. 购物车图标在页面右上角，进去核对年限与总价后结账。

价格随时间与后缀变化，促销价往往只适用于首年，续费价不同——下单前以结算页显示的金额为准。

## 三、首页面板的工具都是干什么的

搜索框下方有一排快捷入口，常见的是这几个：

| 入口 | 用途 |
| --- | --- |
| Transfer | 发起域名转入：把别家注册的域名转到 Dynadot 名下 |
| TLD Prices | 查各后缀的注册/续费价格表 |
| Whois | 查域名的注册信息与到期时间（域名是否可注册也常用它确认） |
| Appraisal | 域名估价参考 |
| Manage | 进入已有域名的管理列表 |
| Prepay | 给账户充值（预付款） |
| Tracker | 关注列表：盯住想买的域名，有变化时收通知 |
| Custom | 自定义常用功能入口 |

已注册域名点进去就是域名详情页，续费和 DNS 都在那里改，见 [域名续费与解析设置.md](域名续费与解析设置.md)。

## 四、一次查多个：批量搜索

想一次查几十上百个名字，用批量搜索比逐个输快：

- App 里带批量搜索与批量注册功能（官方帮助明确 App 支持）。
- 网页版的批量搜索页支持粘贴名单、按后缀过滤、导入 CSV、结果导出 CSV；每日次数按账户等级不同：普通账户 1,000 次/日，Bulk（累计消费 $500）2,000 次/日，Super Bulk（$5,000）5,000 次/日——截至 2026 年 9 月的官方页面数值，以官方页面当时显示为准。
- 批量查本身免费，不用登录也能用网页版；查出来可注册的再一键全部加购物车。

## 五、下单与付款

1. 购物车里选年限（1 年起，最长可选多年，具体年限以下单页可选项为准）。
2. 结账时可选的付款方式有三种：**账户余额、信用卡、已关联的 PayPal 账户**，账户默认走余额——余额没充值时先去 Prepay 充值，或改用信用卡/PayPal。
3. 信用卡能否使用与账户币种设置有关，具体支持范围以官方支付页面当时显示为准。
4. 注册成功后域名立即进入你的账户，就能去管理页改解析了。

域名注册遵循"先到先得"，搜索结果显示可注册就尽快结账，购物车不锁定域名。

**没有信用卡怎么付**——官方支付页列出的方式里，国内用户常用这几个（截至 2026 年 9 月的官方页面，以页面当时显示为准）：

| 方式 | 要点 |
| --- | --- |
| 支付宝 | 人民币付款，单笔上限 30,000 元，付款完成订单即处理 |
| 银联 | 人民币付款，国内银行卡直付 |
| PayPal | 支持 USD/EUR/GBP/CAD/AUD/MXN 等币种，含未验证账户付款 |
| 信用卡/借记卡 | Visa / Mastercard / AmEx / Discover / JCB / Diners，接受境外发行卡 |
| 银行电汇 | 最低 $500，适合大额；官方建议电汇先充成账户余额再下单，订单即时处理 |

**关于账户余额（Prepay）**：最低 $5 起充、**永不过期**、下单最快（注册常在数秒内完成）；但充值进余额的钱**不可退款**（服务协议写明），按需充。设置自动充值（Auto Prepay）需要账户注册满 1 年且有订单记录。另外余额支付是拿到 Bulk / Super Bulk 价格等级的途径之一。

## 六、注册前值得顺手确认的两件事

- **Whois 隐私**：官方页面标注 WHOIS Privacy 免费，注册后开不开由你在账户设置里决定，开了以后公开查询里显示的是代持信息而不是你的真实资料。
- **这个域名值不值得做**：App 里有 Appraisal 估价、Whois 里的历史记录可以参考；要是域名其实已被注册、你想买的是别人手里的，走的是另一条路——见 [域名拍卖出价教程.md](域名拍卖出价教程.md)。
