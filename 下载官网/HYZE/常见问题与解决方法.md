## 一、打开白屏、一直转圈

HYZE 的角色与对话都靠联网加载，白屏多半是网络到不了服务端：

1. **先换网络试**：Wi-Fi 下正常、移动数据下白屏（或反过来）的情况有用户反馈过 —— 分别用两种网络各开一次，立刻能定位是不是某一侧的线路问题；
2. **关掉省流量/数据节省模式**：系统级的省流量会限制应用拉取内容；
3. **查后台数据权限**：「设置 → 应用 → HYZE → 流量用量」里确认没禁掉移动数据与后台数据；
4. **飞行模式开关一次**：开 10 秒再关，强制重连后重开应用；
5. 换了网络还是白屏，去清一次缓存：「设置 → 应用 → HYZE → 存储 → 清除缓存」（清缓存不会丢登录状态，清「数据」才会，慎点）。

## 二、登录不上

登录这一步单独在 [注册登录与账号设置.md](注册登录与账号设置.md) 第四节展开（转圈、报错、拉不起谷歌账号选择页各有各的查法）。要点复述：先确认浏览器能打开 [accounts.google.com](https://accounts.google.com/)，再看系统时间是否自动同步、Google Play 服务是否最新，最后重启手机重试。

## 三、版本号对不上 / 想更新

各渠道的版本号**互不通用**，别拿 A 版本的数字去对 B 渠道：

| 渠道 | 看到的版本 |
| --- | --- |
| 本文网盘里的包 | 2.2623.249（记录于 2026-09-23） |
| 安卓第三方商店 | 9.2635.288（2026-08-26 更新） |
| iOS App Store | 独立编号，2026-09 已到 10.0.0 |

版本号格式不同、发布节奏不同，都是正常现象；**判断新旧看更新日期，不看数字大小**。想更新：iOS 直接在 App Store 点更新；安卓没有统一商店更新入口时，重新从 [HYZE 安装文件资源（夸克网盘）](https://pan.quark.cn/s/549aba11a20f) 取最新包覆盖安装 —— 包名相同（`com.aics.cookiechat`）就可直接覆盖，聊天记录不会丢。

## 四、闪退、装不上、卡死

按症状走，先做代价最小的三步：**清缓存 → 重启手机 → 覆盖重装**。安装阶段的「解析包失败」「禁止安装未知应用」「空间不足」分别怎么处理，见 [下载与安装教程.md](下载与安装教程.md) 第四节；重装后登录态丢失的重新验证，见 [注册登录与账号设置.md](注册登录与账号设置.md) 第四节。

## 五、对话重复、剧情逻辑怪

官方更新日志长期保持「Add features and fix bugs」的迭代节奏，有资料显示针对用户反馈的**重复发言与对话逻辑**问题在后续版本做过专门修正 —— 遇到角色车轱辘话来回说，先升级到最新版再判断。升级后仍严重的，多半是当前话题被带进了死循环：换个开场、补充一条新的剧情设定，比反复重发同一句有效。

## 六、内容分级与账号安全

- **年龄门槛**：iOS 商店标注 **13+**，PEGI 分级 **12**，含恋爱向剧情与少量暴力元素（分级页标注「卡通或幻想暴力、写实暴力」为不频繁程度）。未成年人模式与监护相关要求以当地规定与应用内设置为准。
- **隐私口径**：数据收集范围见 [www.cookiechat.ai/pp-jp](https://www.cookiechat.ai/pp-jp)（LINE NEXT Corporation 的隐私政策）。介意广告标识的，可在系统设置里关闭应用的广告跟踪权限。
- **对话内容**：你与角色的对话由 AI 生成，涉及你的个人信息（真实姓名、住址、联系方式）不要往对话里输。

## 七、收不到新消息提醒

角色有新回复但手机不响，按这个顺序查（从最常见到最少见）：

1. **勿扰模式**：下拉快捷开关看「勿扰 / 勿扰模式」是否亮着，亮着就关掉 —— 它会静音所有应用通知；
2. **应用通知开关**：「设置 → 通知 → HYZE」确认允许通知、允许锁屏显示；不同厂商路径可能是「设置 → 应用 → HYZE → 通知」；
3. **省电与后台**：国产机型的后台管控最常杀推送 —— 在「设置 → 应用 → HYZE → 省电策略 / 后台活动」里改成无限制或允许后台运行；
4. **应用内提醒设置**：进应用的「我的 / 设置」看消息提醒有没有被关掉；
5. 以上都开着还是收不到，先升级到最新版（见第三节），再重启手机复测。
