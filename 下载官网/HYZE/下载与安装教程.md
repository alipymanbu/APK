## 一、HYZE 是什么

## 二、从夸克网盘获取安装包

1. 打开 **HYZE 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/549aba11a20f](https://pan.quark.cn/s/549aba11a20f)；
2. 在网盘里把该应用文件夹**转存到自己的账号**下；
3. 手机端打开夸克，在自己网盘里找到该文件夹，直接下载其中的 `.apk`；也可以在电脑上下载后，用数据线 / 微信文件助手 / 局域网传输把 APK 拷到手机。

文件夹里的 `先保存再下载避免失效.txt` 是给你的提醒：**先转存再下载**，直接在线播放/预览容易因分享失效拿不到文件。

## 三、安装到手机

1. **允许安装未知来源应用**：不同机型路径略有差别，一般在「设置 → 安全/隐私 → 更多安全设置 → 允许安装未知应用」，为文件管理器或浏览器授一次权即可。
2. 用文件管理器点开下载好的 `.apk`，按提示点击「安装」。
3. 安装完成先别急着打开，回头核对一下装的是不是这一份：在「设置 → 应用 → HYZE → 应用信息」里能看到版本号，应为 `2.2623.249`。
4. 首次打开需要联网加载，登录问题见 [注册登录与账号设置.md](注册登录与账号设置.md)。

## 四、安装失败怎么办

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | 包没下完整，或系统版本过低 | 重新下载并核对大小为 62.59M；确认安卓版本 ≥ 7.1 |
| 「禁止安装未知应用」 | 系统拦截了非商店来源 | 按第三节第 1 步给对应应用授一次权 |
| 「存储空间不足」 | 手机剩余空间不够 | 安装包 62.59M，安装与运行还需数倍空间，建议至少预留 1GB 再装 |
| 装完闪退/打不开 | 安装包损坏或与机型不兼容 | 重新下载安装；仍不行换台设备试，排除机型问题（详见 [常见问题与解决方法.md](常见问题与解决方法.md)） |
