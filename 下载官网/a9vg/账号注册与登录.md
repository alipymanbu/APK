## 一、注册前先分清两个入口

A9VG 的内容分两块：资讯主站与玩家论坛，两个入口的注册页面是分开的：

| 入口 | 地址 | 说明 |
| --- | --- | --- |
| 主站 | [www.a9vg.com](https://www.a9vg.com) | 资讯、评测、游戏资料库内容；注册页在 `www.a9vg.com/account/sign-up` |
| 论坛 | [bbs.a9vg.com](https://bbs.a9vg.com) | 玩家社区讨论；注册方式见本篇第四节 |

在客户端里登录时，以 App 登录页实际提示的账号体系为准；两边账号是否通用、是否需要分别注册，以登录时的实测结果为准。

## 二、主站账号注册

主站注册页（[www.a9vg.com/account/sign-up](https://www.a9vg.com/account/sign-up)）需要填的信息：

| 字段 | 要求 |
| --- | --- |
| 用户名 | 用于登录 |
| 手机号 | 接收短信验证码 |
| 验证码 | 短信下发 |
| 密码 | 6~12 位 |
| 昵称 | 3~8 个字符 |

操作顺序：填用户名和手机号 → 点获取验证码并填入 → 设置密码 → 设置昵称 → 提交。两处长度限制要留意：密码超出 12 位会过不了校验，昵称不足 3 个字符或超出 8 个字符也会被拦。

## 三、忘记密码怎么找回

主站提供找回密码页（[www.a9vg.com/account/reset-password](https://www.a9vg.com/account/reset-password)），流程是：

1. 输入用户名；
2. 输入注册时的手机号；
3. 填入短信验证码；
4. 设置新密码（仍是 6~12 位），确认后提交。

前提是你还能收到那个手机号的短信。手机号已经换掉的情况，只能通过官网的联系方式（「关于我们 → 联系我们」页面）沟通处理。

## 四、论坛账号与它的注册制度

论坛（bbs.a9vg.com）的注册政策历史上变过多次，了解这些能解释你可能遇到的一些现象：

- **早年（2010 年）实行邀请注册制**：只有积分满 100 分、用户组达到「公民」及以上的正式会员才能购买邀请码（1 点积分一个、有效期 1 天），新成员通过邀请链接注册后先进入「游民」用户组。当时还配套了「连坐」制度——被邀请人严重违规，邀请人也会被扣分或禁言。
- **现行政策以论坛注册页当时显示的为准**：开放注册、邀请制还是别的形式，随时可能调整，本篇不替你下结论。
- **用户组与权限挂钩**：论坛用户组（游民、公民等名称曾在公告中出现）通常对应发帖、下载附件等权限差异，具体等级规则以论坛站内的用户组说明为准。

## 五、客户端里登录

1. 打开 A9VG 客户端，进入「我的」或个人中心一类的入口；
2. 选择登录，输入你已有的账号与密码；
3. 没有账号时，部分版本的客户端会直接提供注册入口，跳转后按提示操作即可。

如果登录时提示的账号体系与你手上的账号对不上（比如 App 里要的是论坛账号而你只有主站账号），回到对应入口注册一个即可——两个入口的账号规则见本篇第一、四节。

## 六、注册与登录的常见坑

- 收不到短信验证码：先确认手机号没填错，等 60 秒再点一次重发；仍收不到换网络环境或换时间段再试。
- 密码总是「格式不对」：检查是否在 6~12 位之间。
- 昵称被拒：确认在 3~8 个字符内。
- 登录后部分版块进不去：这与用户组权限有关，见 [常见问题与解决方法.md](常见问题与解决方法.md)。

拿到账号之后，下一步是把论坛的版块结构摸清楚，见 [论坛版块导览.md](论坛版块导览.md)。
