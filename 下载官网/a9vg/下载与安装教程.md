## 一、先确认你要装的是哪个

A9VG 电玩部落是国内的主机游戏玩家社区，官方提供网站（[www.a9vg.com](https://www.a9vg.com)）、论坛（[bbs.a9vg.com](https://bbs.a9vg.com)）与手机客户端。本篇讲的是**安卓客户端**的安装。

本篇对应的安装文件信息如下（以安装包实际信息为准）：

| 项目 | 信息 |
| --- | --- |
| 版本 | 7.4.7 |
| 安装包大小 | 约 41.81 MB |
| 包名 | `com.wanmei.a9vg` |
| MD5 | `FA79298E563E2ECC78097E481948BAF9` |
| 系统要求 | 安装包信息标注需 Android 5.2 及以上 |

版本号、体积以你拿到的安装包为准——官方会持续更新客户端，不同时期下载到的版本号可能不同。

## 二、安装前的准备

1. **系统版本**：确认手机系统不低于安装包标注的要求（Android 5.2 及以上）。
2. **存储空间**：安装包约 42 MB，加上安装后的占用，建议预留 200 MB 以上可用空间。
3. **允许安装未知来源应用**：这个安装包来自网盘分发，不在应用商店里，安装时系统会要求你授权。不同品牌的入口不一样：
   - 部分手机在**安装时弹窗里**直接点「允许」或「仍要安装」；
   - 部分手机要先去 **设置 → 安全 → 更多安全设置（或安装未知应用）**，给浏览器或文件管理器开「允许安装未知应用」；
   - 原生系统路径一般是 **设置 → 应用 → 特殊应用权限 → 安装未知应用**。

## 三、获取安装文件资源

A9VG 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/aea378b40ec5](https://pan.quark.cn/s/aea378b40ec5)

取包步骤：

1. 在手机或电脑上打开上面的网盘链接；
2. 把文件**转存到自己的夸克网盘**（不转存无法取得文件）；
3. 在夸克网盘客户端里下载该 APK 文件到手机本地。

**下载完建议先校验 MD5**，确认文件在传输过程中没有损坏。Windows 上在命令提示符里执行：

```bat
certutil -hashfile "下载后的完整路径\a9vg_v7.4.7.apk" MD5
```

输出的哈希值与本篇第一节表格里的 MD5 一致（忽略大小写）就说明文件完整。对不上就重新下载一次，反复不一致说明取到的不是这一版。

## 四、安装步骤

1. 在文件管理器里找到下载完成的 APK 文件，点开；
2. 系统弹出「是否安装」时确认，遇到未知来源提示按第二节的方法授权；
3. 等待安装完成，点「打开」直接进入，或回到桌面从图标启动；
4. 首次打开会请求网络等常规权限，按需允许即可。

## 五、iOS 设备怎么办

官网与论坛页面提供过 iOS、Android 双端客户端的下载入口（官网底部与论坛页脚有客户端下载二维码）。iOS 端能否安装、当前版本号，以 App Store 里搜索「A9VG」的实际结果为准，本篇不给出 App Store 之外的 iOS 安装途径。

## 六、装不上时先查这几项

| 现象 | 先检查 |
| --- | --- |
| 提示「解析包错误」 | MD5 是否与第一节一致；不一致就重新下载 |
| 安装到一半失败 | 存储空间是否足够；重启手机后再试 |
| 完全点不动安装 | 未知来源授权是否给到了「你用来打开 APK 的那个应用」 |
| 装上了打不开或闪退 | 系统版本是否达标；详情见 [常见问题与解决方法.md](常见问题与解决方法.md) |

安装成功后，下一步通常是注册或登录账号，见 [账号注册与登录.md](账号注册与登录.md)。
