# EasyTouch 常见问题与解决方法

> 本篇汇总 EasyTouch 用起来最常碰到的几件事：卸载不掉、悬浮球消失、截屏失败、锁屏后指纹失效等，每条都给做法。

## 一、卸载不掉：先取消设备管理器激活

**现象**：在应用列表里长按 EasyTouch，找不到「卸载」，或者点了卸载被系统拒绝。

**原因**：你激活过它的「设备管理器」权限（锁屏功能需要），Android 规定带设备管理器的应用不能直接卸载，不是应用恶意拦截。

**做法**：

1. 打开「设置 → 安全 → 设备管理器（设备管理应用）」，老系统在「设置 → 位置和安全 → 选择设备管理器」。
2. 在列表里找到 EasyTouch，取消激活。
3. 回到应用列表，正常卸载。

不同品牌菜单名略有差别，找不到就在系统设置里搜「设备管理器」。

## 二、悬浮球不见了 / 重启后不出现

按顺序排查，多数在第二步就解决：

1. **是不是被自己隐藏了**：长按悬浮球默认是隐藏动作，重新打开一次 EasyTouch 应用即可找回。
2. **被系统杀后台**：在「设置 → 电池」里把 EasyTouch 设为「不优化 / 无限制」，并给自启动权限（首次启动引导里也建议开）。国产系统的省电策略很激进，不给这两个权限，悬浮球过一会儿就会消失；把最近任务里的 EasyTouch 卡片锁定后台，效果更稳。
3. **悬浮窗权限被收回**：重新到「设置 → 应用 → EasyTouch → 显示在其他应用上层」确认开关还开着，各品牌的路径见[悬浮窗权限与自启动设置.md](悬浮窗权限与自启动设置.md)。
4. 上面都做完还不行：把 EasyTouch 从最近任务划掉重开一次（权限和后台都正常时，重启程序多半就能把悬浮球找回来）；小米这类系统还要在「安全中心 → 权限」里允许「弹出界面」。

## 三、截屏失败或截出来是黑的

- 先确认悬浮窗权限已开，再截一次。
- 截出来是黑的，通常是你在截银行、政务类 App 或有 DRM 保护的画面（视频播放界面），系统禁止截这些内容，换普通界面试。
- 老机型上截屏可能受限，官方说明里提过老版本这类系统级操作在部分机型需要 root 或额外授权。

## 四、锁屏之后指纹 / 人脸失效

用面板里的「锁屏」走的是设备管理器锁屏。Android 的机制是：设备管理器锁屏后，下一次解锁会要求输入密码（PIN / 图案），指纹和人脸会暂时不可用，这是系统限制，不是 EasyTouch 出故障。在意这一点的，可以把一键锁屏的手势换掉，改用电源键锁屏。

## 五、通知不显示

面板的「通知」功能依赖通知使用权：到「设置 → 通知使用权（通知读取权限）」里给 EasyTouch 打开。开了之后各应用的消息才能进它的通知面板。

## 六、其他小问题

- **悬浮球挡住内容**：拖到屏幕角落，或者长按临时隐藏，用完再打开。
- **点悬浮球没反应**：清一下缓存再重来——「设置 → 应用 → EasyTouch → 存储 → 清除缓存」，然后从最近任务划掉重开。
- **面板点开很卡**：加速功能清一次后台再看；主题特效多的话换回简洁主题。
- **想改单击 / 双击的动作**：在「悬浮按钮手势」里改，见[手势与快捷功能设置.md](手势与快捷功能设置.md)。
- 上面都解决不了的，把应用版本、手机型号记下来，通过应用内的反馈渠道联系开发者（联系邮箱 `shereworkshop@gmail.com`）。
