## 一、先对版本：这份安装包是什么

EasyTouch 是安卓上的悬浮球辅助工具，屏幕边缘会浮一个小圆点，点开就是快捷面板，功能类似 iPhone 的 AssistiveTouch。本篇对应的安装包信息如下，装好后可以在「设置 → 应用 → EasyTouch」里核对：

| 项目 | 值 |
| --- | --- |
| 版本 | 4.6.3 |
| 包名 | com.shere.easytouch |
| 安装包大小 | 5.42M |
| MD5 | CF0341AE362E8D8E93CA8E350761F5FE |

应用商店里的版本号会随官方更新变化，以你安装当时页面显示为准；上面这份是本资源包的实测信息。渠道页面对 4.6.3 这一版的更新说明是「界面全面更新、性能提升与问题修复」，界面支持简体中文。

## 二、获取安装包

进入上面的 [EasyTouch 安装文件资源（夸克网盘）](https://pan.quark.cn/s/18eea2cdca93) 链接，把里面的 APK 文件转存到自己的网盘，再从网盘 App 下载到手机存储。也可以先在电脑上下载，再用数据线传到手机，两种方式效果一样。

下载完成后，文件管理器里会看到一个 APK 安装包，接下来按下面的步骤装。

## 三、安装步骤

1. 在文件管理器里点开刚下载的 APK 文件。
2. 系统弹出「未知来源 / 允许安装未知应用」提示时，按提示允许（国产手机一般让你给「文件管理器」或浏览器开这个权限，路径在「设置 → 安全」或安装时直接点允许）。
3. 点「安装」，等进度走完。
4. 系统要求：安装包标注为安卓 5.2 以上，太老的系统在安装时会直接提示不兼容，以手机给出的提示为准。
5. 提示「解析包出现错误」多半是包没下完整：重新下载一次，还是不行就核对文件 MD5 与第一节表格里的值是否一致，对不上就别装。

## 四、首次启动：把权限开起来

装完直接打开 EasyTouch，第一屏是权限引导，照着做即可：

| 引导项 | 说明 | 必须吗 |
| --- | --- | --- |
| 开启悬浮窗权限 | 跳到系统设置里找「显示在其他应用上层 / 在其他应用上方显示」，给 EasyTouch 打开；不开这个，悬浮球根本出不来 | 必选 |
| 开启自启动 | 允许开机自启，重启手机后悬浮球能自动出现 | 建议 |
| 开始使用 | 上面两项设置完，点底部这个按钮 | — |

点「开始使用」后，屏幕边缘会出现一个半透明小圆点，这就是悬浮球。

另外两个按需授予的权限，用到对应功能时系统才会来要：

- **设备管理器（激活）**：面板里的「锁屏」功能需要它。激活后一键锁屏才有效；代价是之后想卸载 EasyTouch，得先去设备管理器里取消激活（详见[常见问题与解决方法.md](常见问题与解决方法.md)）。
- **通知使用权**：想让面板读取各应用的消息通知，要在「设置 → 通知使用权 / 通知读取权限」里授权。

## 五、装好之后先试这几下

- 按住悬浮球拖一拖，能贴边放到任意位置。
- 双击悬浮球（默认手势）展开快捷面板，里面有截屏、锁屏、手电筒这些常用功能。
- 面板里的图标都能换成你自己常用的：长按面板空白处就能编辑，具体见[悬浮球与面板自定义.md](悬浮球与面板自定义.md)。
- 悬浮球没出现、或者过一会儿自己消失了，直接翻[常见问题与解决方法.md](常见问题与解决方法.md)。
