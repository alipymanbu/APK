## 一、悬浮窗权限：悬浮球的前提

Android 把「浮在其他应用上面」算作单独一项权限，多数系统里叫「显示在其他应用上层」。EasyTouch 第一次启动会引导你去开；没开、或后来被系统/安全软件收回，悬浮球就不会出现。

通用路径（多数机型适用）：

```text
设置 → 应用 → EasyTouch → 显示在其他应用上层 → 允许
```

## 二、各品牌的路径差异

| 品牌 / 系统 | 参考路径 |
| --- | --- |
| 华为 / 荣耀（EMUI、HarmonyOS） | 设置 → 应用 → 权限管理 → 应用页签找到 EasyTouch → 悬浮窗 → 允许 |
| OPPO / ColorOS 13 及以上 | 设置 → 应用 → 特殊应用权限 → 悬浮窗 → EasyTouch |
| OPPO / ColorOS 7~12 | 设置 → 应用（应用管理）→ 悬浮窗管理 → EasyTouch |
| vivo / Funtouch | 设置 → 应用 → EasyTouch → 权限里开「显示悬浮窗」；自启动也在同一处 |
| 小米 / MIUI | 手机管家 → 应用管理 → 权限 → 显示悬浮窗；自启动在「应用管理 → 自启动」里开 |
| 三星 / One UI | 设置 → 应用 → EasyTouch → 出现在顶部（部分版本收在「其他权限」里） |

菜单名随系统版本略有差异（以上为截至写作时的常见路径，以手机实际显示为准），找不到就在系统设置顶部的搜索框里搜「悬浮窗」或「在其他应用上层」。

## 三、自启动与电池优化

悬浮球消失的第二大原因，是省电策略把后台清掉了。三件事一起做：

1. **自启动**：允许 EasyTouch 开机自启（应用首次引导里也建议开这一项）。vivo 上自启动被关时，重启手机后悬浮球不出现是典型表现。
2. **电池优化**：设置 → 电池（省电与电池）→ 找到 EasyTouch → 设为「不优化 / 无限制」。
3. **后台锁定**：在多任务界面把 EasyTouch 的卡片下拉（或点锁形图标）锁定，防止一键清理把它顺手清掉。

做完这三步，把 EasyTouch 从最近任务里划掉再重新打开一次，悬浮球一般就回来了。

## 四、权限都开了还是不显示

按这个顺序再查一遍：

1. 是不是长按悬浮球把它隐藏了：重新打开一次 EasyTouch 应用即可找回。
2. 同类悬浮球、清理工具可能在抢悬浮层：临时关掉它们再试。
3. 重启手机：权限刚开时，个别系统要重启一次才生效。
4. 还不行，翻[常见问题与解决方法.md](常见问题与解决方法.md)。
