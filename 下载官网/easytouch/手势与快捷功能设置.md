## 一、四种手势：单击、双击、三击、长按

操作路径：打开 EasyTouch →（悬浮窗权限没开的话先按提示开）→ 在主页点「悬浮按钮手势」→ 点要改的那一手势 → 从动作列表里选一个，返回即生效。

四种手势可以分别指定一个动作，默认分配是：

| 手势 | 默认动作 |
| --- | --- |
| 单击 | 历史 |
| 双击 | 悬浮面板 |
| 三击 | 历史 |
| 长按 | 隐藏按钮 |

每一项点进去都能换成别的动作（打开某个应用、某个开关等），四项互相独立，改哪个都不影响其余三个。常用的搭配思路：

- 单击给「截屏」或「锁屏」，最省事。
- 双击保留「悬浮面板」，这是用得最多的一下。
- 长按不要随便改掉「隐藏按钮」，临时藏悬浮球全靠它。

## 二、快捷面板里的功能

双击悬浮球展开面板，默认是一页九个功能，往左右滑能翻页：

| 功能 | 作用 |
| --- | --- |
| 主题 | 快速进入主题中心换面板外观 |
| 手电筒 | 一键开关闪光灯 |
| 通知 | 展开系统通知栏 |
| 设置 | 跳到系统设置 |
| 截屏 | 当前屏幕截图，自动存本地 |
| 最近 | 打开最近任务列表 |
| 返回 | 相当于按返回键 |
| 主屏 | 回到桌面 |
| 加速 | 清理后台、释放内存 |

面板顶部还有「点击搜索」框，输入名字直接找应用打开，不用一页页翻。

## 三、功能与权限对照

面板里的功能不是都开箱即用，缺权限的点下去系统会提示，对照这张表补（悬浮窗、自启动在各品牌手机里的具体路径，见[悬浮窗权限与自启动设置.md](悬浮窗权限与自启动设置.md)）：

| 功能 | 需要的权限 / 设置 |
| --- | --- |
| 截屏 | 悬浮窗权限；部分系统还要给「出现在顶部」或无障碍授权 |
| 锁屏 | 激活设备管理器（激活后卸载前要先取消，见[常见问题与解决方法.md](常见问题与解决方法.md)） |
| 手电筒 | 相机权限（闪光灯走相机接口） |
| 通知 | 通知使用权（监听通知的服务） |
| 加速 | 无特殊权限，直接可用 |
| 联系人快捷拨打 | 电话权限 |
| 天气 | 定位权限 |

## 四、关于老机型和 root

基础功能（截屏、锁屏、手电筒、快捷开关这些）不需要 root，装上、把悬浮窗权限开起来就能用。两份二手材料的说法可以并列参考：官方 FAQ 提过老版本里电源、截屏、返回、菜单这类系统级操作在部分机型需要 root；第三方渠道的介绍则说 root 之后能解锁关机、重启、强制截屏这类更深的操作。合起来的结论：不 root 不影响日常使用，遇到功能点不动，先按上面的权限对照表补齐授权，再考虑是不是机型限制。

面板功能都用顺了之后，下一步是把悬浮球和面板调成你自己的样子，见[悬浮球与面板自定义.md](悬浮球与面板自定义.md)。
