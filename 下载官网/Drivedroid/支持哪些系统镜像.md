## 一、镜像的三个来源

1. **应用内置下载列表**：官方维护一份可直接下载的镜像清单，覆盖主流 Linux 发行版（Ubuntu、Fedora、Arch、Debian、Linux Mint、openSUSE 等）与工具类镜像（GParted、Clonezilla、FreeDOS、Kali 等）。官方页面称约 35 个系统可选——**数量会变，以应用内当时列表为准**。这些镜像都做过适配，能直接挂载启动。
2. **你自己的 ISO/IMG 文件**：从文件添加进来。**这一类能不能启动，取决于镜像本身**，规则见下一节。
3. **空白镜像**：自己造一个空盘，用途是当普通 U 盘存文件，或让电脑端工具（Rufus 等）往里写系统。

## 二、直接决定成败的一条规则：IMG 都行，ISO 要看是不是 hybrid

DriveDroid 挂载出去时，大多数手机模拟的是 **USB 大容量存储（U 盘）**，少部分模拟**光驱**。镜像能不能启，就看你手机模拟的形态和镜像的口味对不对：

| 镜像类型 | 能否直接用 | 说明 |
| --- | --- | --- |
| 所有 `.img` 文件 | 可以 | 按 U 盘写法做的镜像，模拟 U 盘即可启动 |
| hybrid（混合）ISO | 可以 | 现代主流 Linux 发行版基本都是这种，U 盘、光驱两种介质都能启 |
| 非 hybrid ISO（部分老镜像、Windows 安装镜像） | 不行 | 只认光驱，模拟 U 盘时启不动 |
| 应用内置列表里的镜像 | 可以 | 官方已确认兼容 |

怎么判断手上的 ISO 是不是 hybrid？最省事的判据：**该发行版官方是否推荐用 Rufus/dd 直接写 U 盘**——推荐写的，基本就是 hybrid；只提供光盘刻录说明的老镜像，多半不是。

hybrid 为什么两种介质都能启：这种镜像里**同时带着两套结构**——一套 ISO 9660 文件系统给光驱读，一套 MBR/GPT 引导结构嵌在开头的扇区里给 U 盘用。所以同一个文件，刻成光盘能启、按字节写进 U 盘也能启。

顺带一条实操判据：用电脑上的 Rufus 写镜像时会问你用哪种写法——**DD Image 模式是逐字节照抄发布方给的镜像，可靠性最高**；ISO 模式是解包文件再装引导，兼容性看镜像结构复杂度。手上是 hybrid 镜像就优先选 DD 模式（写完后 Windows 可能显示它"很怪"，重新格式化即恢复，不影响启动）。

## 三、非 hybrid 的 ISO：两条路

**第一条（推荐）：在电脑上转换成 U 盘能启的镜像。** 用 [Rufus](https://rufus.ie/) 之类的工具把 ISO 写到 DriveDroid 创建的空白镜像里，或按官方教程做转换。适合绝大多数人——不动手机，成功率也高。

**第二条：让手机真的模拟成光驱（true CD-ROM emulation）。** 挂载时就能选「CD-ROM」模式，任何 ISO 都能启。代价是：**你的手机内核得支持 CD 仿真**——多数出厂内核只支持 U 盘仿真，需要刷入带相应补丁的内核或第三方 ROM 才有。你手机是否支持，看挂载对话框里有没有 CD-ROM 选项即可判断；没有就是不支持，别再折腾设置。

> Windows 安装镜像属于典型的非 hybrid ISO。想用手机装 Windows，走第一条路转换——**具体到 Windows 的完整操作步骤（建空白镜像、Rufus 写入、启动安装）单独写在 [用手机给电脑装Windows教程.md](用手机给电脑装Windows教程.md)**，本文不展开。

## 四、UEFI 与老 BIOS 都能启吗

官方测试镜像同时兼容 USB、CD 与 UEFI 启动，也就是说**新老电脑都能从手机引导**——前提是镜像本身支持 UEFI（主流发行版都支持）。电脑侧还有两件事要配合：启动菜单里要真的选中手机、Secure Boot 若拦截就先关掉，具体见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、内置列表之外，还有没有别的镜像源

有两类补充渠道：

- **自定义仓库**（付费版功能）：自己配一个镜像仓库地址，把公司或小圈子自制的镜像挂进去共享；
- **手动添加**：任何地方拿到的 ISO/IMG，拷进手机后从文件添加即可——只要满足第二节的规则。

不确定某个镜像行不行时，先用它做个最快验证：挂载 → 电脑重启进启动菜单 → 能进镜像的引导界面就算通过，进不去就按第二节的规则核对镜像类型，再对照 [常见问题与故障排查.md](常见问题与故障排查.md) 逐段排除。
