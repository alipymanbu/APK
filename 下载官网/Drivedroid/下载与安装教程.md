## 一、先确认三个前提，不满足就别装

DriveDroid 不是装上就能用的普通工具，它要动手机内核的 USB 功能。你先对照这三条：

1. **手机已 root**。官方说明写得很直接：这个应用需要 root 权限。没 root 的手机打开也走不下去，向导会在授权那一步卡住。
2. **内核支持 USB 大容量存储（Mass Storage）**。大多数手机支持模拟 U 盘，少数只支持模拟光驱，也有两者都不稳的。这取决于你手机的内核，不取决于应用。
3. **手机上有存放镜像的空间**。一个 Linux 发行版的 ISO 通常是 2~4 GB，你要先确认目标分区放得下。

第二条如果拿不准，可以先装上跑一遍配置向导——向导本身会做设备检测，不兼容会在很早的步骤就告诉你（详见 [常见问题与故障排查.md](常见问题与故障排查.md)）。

## 二、安装包从哪拿

两条路，按你的情况选：

- **Google Play**：官方在商店里有两个包——免费版与付费版，包名分别是 `com.softwarebakery.drivedroid` 和 `com.softwarebakery.drivedroid.paid`。能正常访问商店的话这是首选，后续更新也省事。
- **离线安装包**：拿不到商店时，从 [DriveDroid 安装文件资源（夸克网盘）](https://pan.quark.cn/s/039dab806713) 获取 APK 后直接安装。装之前建议核对一下包名是否为 `com.softwarebakery.drivedroid`，与官方一致再装。

装完先别急着用，首启有个跳不过去的设置流程，见下一节。

## 四、首次启动要过一遍 USB 设置向导

打开应用，首先会提示你开始设置向导。**不要跳过**——向导会依次做这几件事：

1. 检查你的机型是否在已知不兼容的黑名单里；
2. 申请 root 授权；
3. 让你用数据线把手机连上电脑，选一个「USB system」（最可能可用的会排在最上面）；
4. 确认电脑上真的弹出了 U 盘或光驱；
5. 引导你重启电脑、从手机启动一次，验证整条链路通了。

向导中途关掉了也没关系：进设置里的「USB Setup Wizard」可以随时重跑。完整操作步骤在 [手机挂载镜像启动电脑教程.md](手机挂载镜像启动电脑教程.md)。

## 五、装免费版还是付费版

装之前顺手把版本选对，能省掉后面再装一遍的功夫。两版功能差异见 [免费版和付费版有什么区别.md](免费版和付费版有什么区别.md)——如果你只是想拿手机当一次性的启动盘，免费版够用。
