## 一、按症状查表

先对号入座，再看对应小节：

| 症状 | 多半是哪儿 | 跳到 |
| --- | --- | --- |
| 向导第一步就提示机型不兼容 | 机型在黑名单里 | 第二节 |
| 授权 root 时没有弹窗 / 授权后仍失败 | root 环境问题 | 第三节 |
| 电脑上不出现任何盘符 | USB system 选错 / 线与接口 | 第四节 |
| 用 Rufus 写镜像时看不到手机设备 | Rufus 默认不列移动硬盘类设备 | 第四节第 5 条 |
| 挂载时报 `failed to host` | 内核 LUN 配置 / root 掉了 | 第五节 |
| 盘符有了，但启动菜单里选不到手机 | 启动模式 / Secure Boot | 第六节 |
| 只能当 U 盘，没有光驱选项 | 内核只支持 U 盘仿真 | 第七节 |

## 二、向导提示机型不兼容

配置向导会比对已知的不兼容机型名单。命中时的现实选择：

1. 确认你跑的是当前版本（0.10.50 这代修复过 Moto G、OnePlus、Pixel 等一批机型的识别问题），旧版本先升级再试；
2. 换一个 USB system 重跑向导——**名单不是完全刚性的**，不少机型是换了个 USB system 就通了；
3. 仍不行，通过应用设置里的支持入口发邮件求助，附上它自动生成的报告（含镜像目录、root 方案、内核日志片段），比自己描述更有效。

## 三、root 相关

- 打开应用第一步就该弹 root 授权框。**没弹**说明你的 root 方案没接管这个应用：去 root 管理器里确认 DriveDroid 在授权列表、且没有被拒。
- 授权过期的表现是挂载时报错或向导卡在授权步。重新授权一次即可；用 Magisk/SuperSU 之类管理器时，注意别开了「超级用户自动拒绝」。
- 一些新机型的 SELinux 策略更严，root 拿到了也可能读不到镜像目录。表现是列表是空的、目录选不进去——把镜像目录换到内部存储根目录附近再试。

## 四、电脑上不出现盘符

按命中率从高到低试：

1. **换 USB system**：向导里排第一的不一定真对。常见有效的是「Standard Android Kernel」和「Standard Android Kernel (legacy)」之间切换，每次换完都要重新挂载一次看结果。
2. **换线换口**：只充电的线、前置面板、USB HUB 都会坑。用数据线、直插主板后置 USB 口。
3. **确认没被 MTP 占着**：手机连着电脑默认是文件传输模式，DriveDroid 挂载时会尝试自动切换；没切过去就在通知栏手动改。挂载期间别在电脑上打开手机存储里正在被挂载的镜像文件。
4. **换台电脑验证**：两台都不认是手机侧问题；另一台认，就是那台电脑的 USB 口或 BIOS 设置问题。
5. **用 Rufus 写镜像时设备列表里没有手机**：这是另一个常见场景——Rufus 默认不列移动硬盘类设备。点「Format Options」左边的展开箭头，勾选 **List USB Hard Drives** 再刷新（完整写入流程见 [用手机给电脑装Windows教程.md](用手机给电脑装Windows教程.md)）。

## 五、挂载报 failed to host

这个报错的含义是「手机内核没接受这次挂载请求」：

- **root 掉了**：挂载要用 root 写内核接口，先确认授权还在；
- **镜像目录权限掉了**：目录被移走、SD 卡拔了都会这样，重新进设置选一次目录；
- **内核没有可用的 LUN**：USB 仿真要内核留有逻辑单元口。部分机型内核没预留，需要带补丁的内核/ROM——这属于硬件层面的不支持，换设置救不回来；
- **上一次没卸载干净**：先把通知栏里的挂载停掉、重启应用，再重试一次。

## 六、盘符有了，启动菜单里却选不到手机

1. **进对启动菜单**：开机瞬间按厂商的菜单键（常见 F12 / F8 / Esc / F2 / Del，以开机画面提示为准），别只改启动顺序不看设备列表。
2. **认名字**：列表里的条目可能是机型名、`USB HDD`、`Removable Device`，带 `UEFI:` 前缀的是一种、不带的是另一种——**两个都试**，UEFI 机器通常选带前缀的。
3. **Secure Boot 拦截**：非签名引导被拦时进 BIOS/UEFI 把 Secure Boot 设为 Disabled 再试。Ubuntu、Fedora 这类主流发行版一般能带着 Secure Boot 过，冷门镜像多要关。
4. **CSM/启动模式对不上**：老镜像要 Legacy/CSM 模式，新镜像走 UEFI。不清楚就把 CSM 打开，两边都能看见再选。
5. **镜像本身不支持 UEFI**：见 [支持哪些系统镜像.md](支持哪些系统镜像.md)——hybrid 镜像通常两者都行，纯光驱镜像另说。

## 七、只能当 U 盘，没有 CD-ROM 选项

这不是 bug。**多数手机内核只实现了 U 盘仿真**，光驱仿真要内核带相应补丁；内核没有硬编码 CD-ROM 能力时，应用会直接把该选项藏起来。判断标准就一条：挂载对话框里有没有 CD-ROM 项——没有就是你当前内核不支持，想支持只能刷带补丁的内核或第三方 ROM。好消息是：**现代 Linux 的 ISO 基本都按 hybrid 发布，纯 U 盘仿真就够用**（详见 [支持哪些系统镜像.md](支持哪些系统镜像.md)）。

## 八、两条数据安全线

- **SD 卡被电脑挂着时不要操作**：官方明确警告这可能造成数据丢失。挂载前先在电脑上安全弹出手机存储，或直接拔线。
- **别在挂载中强拔**：先在应用里卸载镜像、等通知消失再拔线；挂载中手机断电，正在跑系统的电脑会直接断电。

## 九、还没解决

排查类问题的信息越具体越好。用应用设置里的支持入口发报告（会带上机型、镜像目录、内核日志等），或到官方在 XDA 的讨论帖里搜同款机型——多数机型的坑都有人踩过并留了解法。
