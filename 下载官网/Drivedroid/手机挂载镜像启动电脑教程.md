# 用 DriveDroid 手机挂载镜像启动电脑教程

## 一、整体流程长什么样

一句话概括：**手机里放镜像 → 手机连电脑 → 手机扮演 U 盘或光驱 → 电脑从它启动**。对应到操作上是五步：

1. 跑完 USB 设置向导，确认手机能被电脑认成一个盘；
2. 准备一个 ISO 或 IMG 镜像（应用内下载，或从文件添加）；
3. 在应用里点选该镜像，把它「挂载」（host）出去；
4. 重启电脑，开机时进启动菜单，选中手机；
5. 用完在应用里弹出镜像，拔线。

下面逐步展开。卡在哪一步，直接跳到 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 二、跑 USB 设置向导

首次打开应用会自动进入向导；中途关掉的话，进设置 →「USB Setup Wizard」重跑。向导的关键几步：

1. **设备检测**：先查机型是否在已知不兼容名单里。多数手机能过；如果被标记为不兼容，先别硬试，去排查篇看对应处理。
2. **root 授权**：点「Acquire root」，在弹出的授权框里允许。以后每次挂载镜像也都要用到 root。
3. **设置镜像目录**：选一个文件夹专门存镜像文件。这个目录没配好，向导不放行——建议选内部存储里空间充足的路径；外置 SD 卡也支持，但要给写权限。
4. **连电脑、选 USB system**：用数据线连上电脑，点「I plugged in the USB cable」。可用的 USB system 会列出来，**预测最合适的排在最上面**——先选排第一的那个。
5. **确认电脑识别**：看电脑的文件资源管理器里有没有多出一个 U 盘或光驱。有 → 点「I see a USB/CD drive, proceed」；没有 → 换一个 USB system 重试（常见备选是「Standard Android Kernel (legacy)」）。
6. **验证启动**：按提示重启电脑，进启动菜单选中手机，能进到测试镜像的启动画面，向导就完成了。

一个 USB system 试个两三轮都认不出，别死磕——换线、换 USB 口（优先主板后置口、避免 HUB）再从第 4 步来，仍不行看排查篇。

## 三、准备镜像

向导通了之后，回到主界面准备镜像，三种来源：

- **应用内下载**：点底部的加号 →「Download image」，列表里有 Ubuntu、Fedora、Arch、Linux Mint、GParted、FreeDOS 等（数量与可用性以应用内当时列表为准）。适合手头没有镜像、想快速弄一个 rescue 系统的情况。
- **从文件添加**：先用别的方式把 ISO/IMG 下到手机存储，再点加号 →「Add image from file」，起个名字、选中文件即可。**你自己的镜像走这条路**。
- **创建空白镜像**：生成一个空的 FAT 镜像当作普通 U 盘用——往里拷文件，或者在电脑上用 [Rufus](https://rufus.ie/)、Windows 媒体创建工具把系统写进去。想用它装 Windows，步骤单独写在 [用手机给电脑装Windows教程.md](用手机给电脑装Windows教程.md)。

哪类镜像能直接用、哪类要先转换，见 [支持哪些系统镜像.md](支持哪些系统镜像.md)。

## 四、挂载镜像，让电脑从手机启动

1. **先确认电脑侧没在占用手机**：如果手机存储正以「文件传输 / MTP」模式挂在电脑上，先在通知栏切走或拔线。**尤其不要在 SD 卡被电脑挂载时操作，官方明确警告这可能丢数据。**
2. 在 DriveDroid 主列表里点你的镜像，弹出的对话框里选挂载方式：
   - **Writable USB drive**（可写 U 盘）——模拟 U 盘，多数 Linux ISO 走这个；
   - **Read-only CD-ROM**（只读光驱）——模拟光驱，你的手机内核支持 CD 仿真时才有此项。
   拿不准就先选默认高亮的那个（一般是与你所选 USB system 匹配的选项）。
3. 挂载成功后，手机通知栏会有一条常驻通知，电脑上也会弹出一个盘符。
4. **重启电脑 → 开机瞬间按启动菜单键**（常见为 F12 / F8 / Esc / F2，台式机也常是 Del，具体以你主板开机画面提示为准），在启动设备列表里选中手机。手机在列表里的名字可能是手机型号、`USB HDD`，或带 `UEFI:` 前缀的条目。
5. 看到镜像的启动菜单，就成功了。之后的安装、试用都和用普通 U 盘一样。

## 五、用完之后

- **回手机端弹出**：长按镜像或从主列表的弹出按钮卸载，等通知消失再拔线——直接拔可能让下一次挂载失败。
- **电脑休眠导致挂载中断**：设置里有「Keep awake」开关，挂载期间强制 CPU 不休眠，长时间跑系统时建议打开。
- **换镜像**：先弹出旧的，再点新的挂载，别叠着来。
- 手机没电会让正在运行的系统直接断电——挂载状态下接上充电器更稳妥。
