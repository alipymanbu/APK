# 用手机给电脑装 Windows 系统教程

> Windows 镜像不能直接挂载启动，得先用 Rufus 写进空白镜像——完整步骤在这。
> **相关文档**：[支持哪些系统镜像.md](支持哪些系统镜像.md) · [手机挂载镜像启动电脑教程.md](手机挂载镜像启动电脑教程.md) · [常见问题与故障排查.md](常见问题与故障排查.md)

## 一、先说结论

能装，但**不能像 Linux 镜像那样直接点一下就启**。Windows 的安装镜像不是 hybrid 格式，手机模拟 U 盘时它启不动（原理见 [支持哪些系统镜像.md](支持哪些系统镜像.md)）。可行的做法是：**在 DriveDroid 里建一个空白镜像 → 挂载成可写 U 盘 → 用电脑上的 Rufus 把 Windows ISO 写进去**——写完的镜像就是一块正经的 Windows 启动盘，之后照常从手机启动。

需要准备：一台能正常用的电脑（跑 Rufus）、Windows 安装 ISO、数据线，以及已完成配置向导的手机（见 [手机挂载镜像启动电脑教程.md](手机挂载镜像启动电脑教程.md)）。

## 二、创建空白镜像

1. 手机上打开 DriveDroid，点底部的加号 →「Create blank image...」。
2. 起个文件名（比如 `win11`），大小**设成比 Windows ISO 稍大一点**——Windows 10/11 的 ISO 通常 4~6 GB，空白镜像建议留出余量。
3. **取消勾选「Partition Table (MBR)」，文件系统（filesystem）选 `None`**——这一步别用默认值。分区表和文件系统接下来由 Rufus 决定，你先指定反而会碍事。
4. 等镜像创建完成，回到主列表。

## 三、挂载为可写 U 盘

点中刚建的空白镜像，在弹出的对话框里选 **Writable USB drive**（可写 U 盘）。手机通知栏出现常驻通知、电脑上弹出盘符，就算挂载成功。

## 四、用 Rufus 把 Windows ISO 写进去

1. 电脑上打开 [Rufus](https://rufus.ie/)（免安装，需要管理员权限运行）。
2. **设备（Device）一栏选中你的手机**——它在列表里通常显示为 `NO_LABEL`。
   > 如果列表里看不到手机：点「Format Options」左边的展开箭头，勾选 **List USB Hard Drives**，设备就会刷出来。
3. 「Boot selection」选 **ISO Image**，点右侧光驱图标选中你下载的 Windows ISO。Rufus 扫完会自动填好分区方案等选项。
4. 分区方案拿不准时，先查目标电脑的固件模式再定：Windows 里 `Win + R` → 输入 `msinfo32` → 看 **BIOS Mode** 一项，`UEFI` 对应 GPT、`Legacy` 对应 MBR。多数 2012 年后的电脑选 GPT/UEFI。
5. 点 **Start**，等写入完成（期间别拔线、别让手机熄屏断电）。

> Rufus 的界面措辞随版本略有差异，以你手头版本实际显示为准；写入会清空这个空白镜像里的原有内容。

## 五、从手机启动并安装

写完后重启电脑 → 开机瞬间进启动菜单 → 选中手机（带 `UEFI:` 前缀的条目优先试）→ 进入 Windows 安装界面，之后的分区、装系统与用普通 U 盘装完全一样。启动菜单里找不到手机、或安装界面卡住的排查，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

两条别忘：

- **全程保持供电**：安装 Windows 要几十分钟，手机没电等于直接断电，挂载时把充电线也接上。
- **装完先回手机弹出镜像**再拔线，避免下一次挂载异常。

## 六、另一条路：让手机模拟光驱

如果你的手机内核支持 CD-ROM 仿真，挂载时直接选「Read-only CD-ROM」，Windows ISO 理论上可以不经 Rufus 直接启。但**多数出厂内核不支持光驱仿真**（判断方法见 [支持哪些系统镜像.md](支持哪些系统镜像.md) 第三节），所以对大多数人来说，上面的 Rufus 路线才是走得通的那条。
