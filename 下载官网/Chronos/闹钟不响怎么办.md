# Chronos 闹钟不响怎么排查

## 一、先做个 30 秒定位

动手查权限之前，先设一个**5 分钟后响的测试闹钟**放着：

- **测试闹钟也不响** → 是系统层拦了（下面第二至五节按顺序查）；
- **测试闹钟响、原来那个不响** → 问题出在闹钟本身的设置（见本节末尾）；
- **测试闹钟响了但你没听见** → 直接跳第五节（音量与铃声）。

闹钟本身设置类的低级错误在实际反馈里占比很高，先自查这三项：

1. **重复日**：闹钟只在勾选的星期响 —— 你勾的是不是「工作日」而今天是周末？
2. **上午/下午**：12 小时制下 7:00 可能是晚上 7 点。
3. **开关状态**：闹钟列表里那条的开关是不是被误碰关掉了（列表还在，不等于在响）。

确认设置没问题，再往下查系统层，按顺序过这四项，查到哪项有问题就停在哪项处理：

1. **通知权限没给** —— Android 13 及以上首次安装默认不给通知权限，闹钟到点不弹任何东西。到系统设置里找到 Chronos → 通知，确认已允许。
2. **电池优化把应用杀了** —— 国产 ROM 和部分原生系统会在锁屏后清理后台，被清掉闹钟就排不上。把 Chronos 加入电池优化白名单（见第二节）。
3. **精确闹钟权限被关** —— Android 12 起「闹钟与提醒」是单独开关，被系统关掉后闹钟只能大致时间响或不响。见第三节。
4. **手机重启过** —— Chronos 靠 `RECEIVE_BOOT_COMPLETED` 权限在开机后重排闹钟，这个权限被禁的话，重启后旧闹钟全部失效，要手动重开一遍（见第四节）。

## 二、把 Chronos 移出电池优化

Chronos 在权限说明里明确请求了「忽略电池优化」（`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`），用途就是防止系统杀后台。设置路径因品牌而异：

- **原生 / 近原生系统**：设置 → 应用 → Chronos → 电池 → 选「不受限制」。
- **小米（MIUI / HyperOS）**：设置 → 应用设置 → 应用管理 → Chronos → 省电策略 → 选「无限制」；另在「自启动」里允许。
- **华为 / 荣耀**：设置 → 电池 → 启动管理 → Chronos 改手动，把三项开关全部打开。
- **OPPO / vivo / 一加**：在应用信息页找到「耗电保护 / 后台耗电」，允许后台运行与自启动。

官方在 README 里给的参考是 [dontkillmyapp.com](https://dontkillmyapp.com/) —— 这个站按品牌列出了各自的杀后台开关位置，你的机型查不到时用它。

## 三、检查精确闹钟开关

打开系统设置 → 应用 → Chronos → 「闹钟与提醒」（或「特殊权限 → 精确闹钟」），确认开关是开的。关掉这个开关后，系统会把你的闹钟当「大致提醒」处理，Android 12 以上尤其明显。Chronos 声明了 `USE_EXACT_ALARM` 与 `SCHEDULE_EXACT_ALARM` 两项权限，正常安装后即有，但部分 ROM 会允许用户手动关掉，装完记得确认一次。

## 四、重启手机之后闹钟全没了

Chronos 申请了开机接收权限（`RECEIVE_BOOT_COMPLETED`），用来在开机后自动重排闹钟。若系统把这个权限禁了，重启后已设的闹钟不会响。检查路径：设置 → 应用 → Chronos → 权限 → 「开机接收 / 自启动」，确认允许。部分 ROM 还有一层独立的「自启动」开关（第二节各品牌路径里的那项），两处都要开。

## 五、能响但被静音吞掉

到点有通知、没声音，按这个顺序看：

1. **勿扰（DND）模式** —— 先查它。多数 ROM 的勿扰会连闹钟一起静音，或默认拦下非「闹钟优先」类别的通知。设置 → 声音 → 勿扰，关掉它，或在例外里允许 Chronos 的通知。定时开启的勿扰（睡眠时段自动开）最容易被忘掉 —— 白天测试一切正常、夜里真闹钟被吞，就是这个模式。
2. **闹钟音量通道** —— Android 有铃声、媒体、闹钟三条独立音量，调媒体音量不影响闹钟。设置 → 声音 → 拖动「闹钟」音量条确认不是 0；部分 ROM 在 Chronos 到点响铃时按音量上键也能实时调到闹钟通道。
3. **通知渠道没开声音** —— 设置 → 应用 → Chronos → 通知，找到「闹钟 / Alarm」「计时器 / Timer」这些类别，逐个确认「允许声音」和「震动」开着；类别级开关关掉时，应用内怎么设都没用。
4. **铃声文件是否可读** —— 你选的自定义铃声若在 SD 卡或被其他应用清理掉，播放会静默失败。换回内置铃声验证一次，排查方法见 [主题与铃声自定义.md](主题与铃声自定义.md)。

## 六、白天都正常、只在早上失灵

这种模式基本锁定「夜里系统动了你的应用」：

- **定时勿扰 / 睡眠模式**到点自动开启（见第五节第 1 条），查有没有定时规则；
- **系统夜里清理后台** —— 白天你常打开应用所以杀不掉，夜里长时间锁屏就被回收。第二节的电池白名单就是解这个的；
- **自动重启 / 系统更新重启**：重启后旧闹钟是否还在排程，取决于第四节的开机权限。

## 七、还是不响时的兜底办法

- 关掉 Chronos 再重开一次，重新拨一次闹钟开关，让它重新向系统排程。
- 卸载重装（[下载与安装教程.md](下载与安装教程.md)）—— 重装前注意：换大版本前最好先导出闹钟，规则见 [版本更新注意事项.md](版本更新注意事项.md)。
- 到 [github.com/meenbeese/Chronos/issues](https://github.com/meenbeese/Chronos/issues) 搜同款问题；没有就带上机型、系统版本与复现步骤提一个（开源项目，开发者会看）。
