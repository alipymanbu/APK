## 一、这是个什么应用

Chronos 是一款开源的安卓闹钟应用（包名 `com.meenbeese.chronos`），由开发者 Meenbeese（Kuzey Bilgin）维护，Apache-2.0 许可，源码在 [github.com/meenbeese/Chronos](https://github.com/meenbeese/Chronos)。它做的事和手机自带时钟差不多 —— 闹钟、计时器、秒表，另加睡眠提醒；差别在于界面可定制的程度：主题、背景图、铃声都能换。本篇只负责让你把它装上并跑起来。

## 三、安装步骤

1. 从上表任一来源下载 APK 文件到手机（或先下到电脑再传过去）。
2. 点击 APK 开始安装。系统会弹「禁止安装未知来源应用」—— 这是安装任何商店之外应用的正常提示，按提示进入设置、允许本次安装即可；各品牌手机的入口略有差异，一般在「设置 → 安全/隐私 → 安装未知应用」。
3. 装完打开，第一次进入会依次请求几个权限，见下一节。

## 四、首次运行要给的权限

Chronos 声明的权限都有明确用途，你按自己的用法决定给不给：

| 权限 | 不给会怎样 |
| --- | --- |
| 通知（Android 13+ 的 `POST_NOTIFICATIONS`） | 闹钟、计时器、睡眠提醒到点不弹通知，等于白设 |
| 闹钟相关（`SET_ALARM` / `USE_EXACT_ALARM` / `SCHEDULE_EXACT_ALARM`） | 核心功能，装完即有，不需要你操作 |
| 电池优化白名单（`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`） | 手机杀后台后闹钟可能不响，建议照 [闹钟不响怎么办.md](闹钟不响怎么办.md) 设置 |
| 读取音频（`READ_MEDIA_AUDIO`） | 只影响自定义铃声；不换铃声可以不给 |
| 读取图片（`READ_MEDIA_IMAGES`） | 只影响自定义背景图；不换背景可以不给 |
| 开机接收（`RECEIVE_BOOT_COMPLETED`） | 重启手机后闹钟不会自动重新排上 |

至少把**通知**和**电池优化白名单**两项按 [闹钟不响怎么办.md](闹钟不响怎么办.md) 配好，闹钟才靠得住。

## 五、系统要求

官方仓库没有在介绍页写死最低安卓版本。第三方仓库 IzzyOnDroid 对 2025.3.1 及之后的版本标注**最低 Android 8.0、目标 Android 16**；你装的 2025.1.0 这一版以实际安装时的提示为准 —— 装不上时可以去 [GitHub Releases](https://github.com/meenbeese/Chronos/releases) 换更新的版本试（更新前注意[版本更新注意事项.md](版本更新注意事项.md) 里说的备份问题）。
