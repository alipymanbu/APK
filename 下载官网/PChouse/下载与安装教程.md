## 一、先认清这个包是哪一版

PChouse 是太平洋家居网（[www.pchouse.com.cn](http://www.pchouse.com.cn)，2010 年上线的家居家装资讯平台）推出的手机应用，安卓应用商店里的完整名称是「PChouse太平洋家居-真实家装案例」。装之前先对一下表里的几项，免得和手机里已有的应用搞混，也免得以后把版本记错。

| 项目 | 数值 |
|---|---|
| 版本号 | 5.8.4 |
| 包名 | `cn.com.pcgroup.magazine` |
| 安装包大小 | 55.99M |
| MD5 | `5BD958A5F2328D1A61EE28DE0B247DCE` |
| 系统要求 | 安卓 5.2 及以上 |
| 记录时间 | 2026-09-23 |

两点提醒：

- **包名决定它会不会覆盖你现有的应用**。同包名且签名一致才会覆盖升级；同包名但签名不同，安装时会直接失败（提示应用未安装或签名冲突）。
- 网上能搜到的最新版号可能和上表不一致 —— 网盘里存的是 5.8.4 这一版，**涉及版本号、体积、包名时以上表为准**；商店页当时的版本以商店页面显示为准。

## 二、从网盘拿到安装包并装上

1. 打开 [PChouse 安装文件资源（夸克网盘）](https://pan.quark.cn/s/909f39678866)，把整个文件夹转存到你自己的夸克网盘（需要夸克账号）。
2. 在手机上打开夸克网盘，找到 `PChouse_v5.8.4.apk`，点它。
3. 系统弹「不允许安装未知来源应用」时，跟随提示跳到设置、允许这一次安装来源，再返回点安装。
4. 装完直接打开，按屏幕提示走完首次启动。

若你是在电脑上下载后传到手机，核对 MD5 可在 Windows 上执行：

```powershell
certutil -hashfile "PChouse_v5.8.4.apk" MD5
```

输出应与表格里的 `5BD958A5F2328D1A61EE28DE0B247DCE` 一致（大小写不敏感）。安装被拦、报「解析包时出现问题」这类情况，按 [常见问题与反馈方式.md](常见问题与反馈方式.md) 的顺序排查。

## 三、装完先看这几项权限

应用商店页面列出的权限里，和你日常使用直接相关的就三项，拒绝后对应功能会受限：

- **位置（大概/精确）**：与本地化内容、按城市找设计师一类的功能相关，拒绝后相关推荐可能受限（以 app 内实际表现为准）。
- **相机**：拍照片和视频，用于 app 内需要取景的操作（如发图类动作）。
- **照片与视频读写**：保存图片、选取手机相册里的图。

其余（网络状态、振动、防止休眠等）是常规项，不影响使用。权限可以在装完后随时改：系统「设置 → 应用 → PChouse → 权限」，完整清单以商店页当时显示为准。

## 四、除了网盘，官方还有这些入口

- **官网**：[www.pchouse.com.cn](http://www.pchouse.com.cn)；手机浏览器会落到移动站 [m.pchouse.com.cn](https://m.pchouse.com.cn/)。
- **微信小程序**：「太平洋家居」，不想装 app 可以先用小程序看内容。
