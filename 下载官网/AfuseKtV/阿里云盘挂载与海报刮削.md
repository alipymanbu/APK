# 阿里云盘挂载与海报刮削

> 把阿里云盘接到 AfuseKt 上只需要授权加选文件夹两步，真正费时间的是刮削——文件怎么命名决定了它能不能被认出来。本篇写清添加步骤、命名规则、刮削等待时间与重刮的办法。

## 一、挂载走哪一端

资源库只能在手机端添加，电视端只负责同步。所以下面这些操作在手机上做，做完按 [手机端注册与电视端同步资源库.md](手机端注册与电视端同步资源库.md) 把它同步到电视。

有一处版本口径需要留个心：官方发布页只写了整个电视端最低支持 Android 6，而多个第三方下载站都标注「阿里云盘挂载最低需要 Android 11」。两处说法不一致，以你自己设备上能不能出现「阿里云盘」这个来源为准；WebDAV 这类协议挂载没有这条限制。

## 二、添加阿里云盘的四步

1. 手机端进入资源库页面，选择阿里云盘。
2. 触发授权登录，用阿里云盘账号完成授权，把要用的资源库授权给 App。
3. 授权成功后回到选目录的界面，**选中要挂载的文件夹**（这一步是「选中」而不是「进入」——进到文件夹里点开影片是播放，不是挂载）。
4. 确认后 App 开始扫描并刮削。

几个容易踩的点：

- 授权对象要选对，授权范围给错了会出现「库里没内容」。
- 一次挂载的目录越集中越好。挂一整个大网盘根目录，扫描与刮削都会拖很久。
- 文件夹是层级结构，挂父目录会把子目录一起带进来。

## 三、刮削是怎么被触发的

| 来源类型 | 刮削方式 |
| --- | --- |
| 阿里云盘、WebDAV、Alist、SMB 等 | 添加后 App 自动扫描并刮削 |
| Emby、Jellyfin 等媒体服务器 | 不刮削，直接用服务器上的元数据 |

扫描与刮削是一次性的批量任务，第一次会比较久，元数据多的时候要留意设备可用存储——刮削数据本身也占空间，库很大的话先确认电视上还留得下。

想手动干预有两个入口：

- **整片重刮**：在影片详情页走手动刮削，输入正确的片名重新匹配一次。自动匹配错、或者片名是英文但你想用中文信息时，都靠这一步。
- **单文件刮削**：本地库里打开便捷扫描后，可以逐个文件单独刮，适合只错了一两部片、不想等整库重扫的情况。

## 四、命名规则决定能不能被认出来

刮削靠文件名匹配，命名不规范就会匹配错、或者干脆认不出来。官方手册把这一点写得很绝对：**刮削不识别文件夹，一切都由文件名决定**。也就是说，把片子按「电影」「剧集」分好文件夹并不能帮到识别，起作用的是文件名本身。

社区里通行的一套写法：

**电影**，两种都行：

```
名称.年份.格式
名称(年份).格式
```

**剧集**，必须带 `S01E01` 这种季集标识（`S01` 是第一季、`E01` 是第一集，中间不要加分隔符，大小写不敏感）：

```
名称.S01E01.年份.格式
名称(年份).S01E01.格式
```

文件里没有 `S01E01`，它就会被当成电影识别，之后想改回剧集往往在编辑界面里也找不到对应的剧集信息。剧集命名混乱是刮削失败里最常见的一类。

另外两点经验：

- 电影名不要中英混排，带上年份匹配率明显更高。
- 同一部影片的不同版本（如 1080p 与 4K）命名保持一致，便于归到同一个条目下。

## 五、海报墙与详情页能看什么

刮削完成后，主界面就是海报墙，每部影片有封面、标题、简介等元数据。进详情页还可以看到更多信息，部分版本支持媒体服务详情多图轮播、显示章节、点击 logo 切换艺术图等展示方式。

想少翻列表，可以用聚合搜索：一次同时搜本地库与媒体库里的资源，不用先想清楚影片放在哪个库里。

如果把某个媒体服务设成了首页开屏直达，打开 App 就直接进那个库，适合只用一个库的用户。这个设置与资源库的排序、隐藏一样，属于界面层的调整，改完不会影响已刮削的数据。

## 六、刮完之后的常见状况

| 现象 | 大概率原因 | 处理 |
| --- | --- | --- |
| 影片认成了电影、不认成剧集 | 文件名缺 `S01E01` | 改名后重新刮削该文件 |
| 海报对不上，配了另一部片 | 片名带噪声（压制组后缀、中英混排） | 详情页手动刮削，输入干净片名 |
| 库里缺一部分影片 | 挂载目录选小了，或该目录在扫描后才新增内容 | 检查挂载范围，触发刷新 |
| 扫描很慢、中途像卡住 | 目录太大、元数据多 | 等它跑完；体积大的库分次挂载更稳 |

刮削问题与播放问题常常混在一起报「打不开」，判断边界是：能在海报墙看到条目但点开播不了 = 播放问题（见 [三个内置播放内核怎么选.md](三个内置播放内核怎么选.md)）；海报墙里压根没有 = 刮削问题（本篇）。
