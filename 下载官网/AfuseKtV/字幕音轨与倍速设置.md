## 一、播放界面里能调什么

打开一部影片后，调出播放控制面板，常规可调项如下：

| 项目 | 取值范围 / 选项 |
| --- | --- |
| 倍速 | 1x ~ 3x |
| 字幕 | 内嵌与外挂字幕切换、开启或关闭 |
| 音轨 | 多音轨文件里挑一条 |
| 画面比例 / 视频大小 | 适配屏幕与拉伸比例 |
| 字幕位置与延迟 | 微调对不上口型的字幕 |
| 第三方播放器 | 跳出去用别的播放器播当前文件 |

这些都在播放中生效，不用退回设置页。

## 二、字幕相关的三件事

**一、外挂字幕放在哪。** 官方手册提到本地库可以自动获取同路径下的外挂字幕。最省事的做法是让字幕文件与视频同名、同目录：`影片名.srt`（或 `.ass`）紧挨着视频文件放。名字对不上就不会自动挂，这时用播放界面的字幕入口手动选。

**二、在线字幕有次数限制。** 内置的在线字幕来源是 opensubtitles，官方使用手册写明需要注册 opensubtitles 网站（用 `.com` 后缀那个）并用用户名密码登录，**每天上限 20 次**。所以先自查文件名能不能靠本地字幕解决，别把次数耗在试错上。

**三、ASS 字幕样式。** EXO 内核不支持 ASS 的样式，如果你要的是成品特效字幕，用 MPV 或 VLC；用 MPV 时还可以强制覆盖 ASS 的字体样式，避免字幕被播放器自带样式顶掉。

## 三、音轨与画面

- **多音轨**：文件里带国语/原声两条轨时，在播放界面的音轨入口切换，切完立即生效，不需要重开。
- **HDR 与杜比画面**：画面发灰、发白或没声音，先换内核再谈设置，判断方法见 [三个内置播放内核怎么选.md](三个内置播放内核怎么选.md)。
- **有画面没声音**：优先考虑打开 FFmpeg 开关（播放界面里那个点开后变绿的控制项），细节同样在内核那篇。

## 四、片头片尾怎么跳过

这个功能默认不开，要两步：

1. 先把片头片尾的开关打开；
2. 时长可以自定义。可以在全局设一个默认时长，也可以针对单部剧集单独设——进任意服务的剧集详情页，点「更多」，里面的片头片尾设置只对这一部生效，不会影响全局。

如果用的是 Emby 这类媒体服务，服务端在返回信息里带了片头片尾数据时，打开开关后会自动获取，播放到该位置出现跳过按钮。

## 五、少翻列表的两个开关

- **聚合搜索**：一次同时搜本地库与媒体库里的资源。片库分散在好几个来源时，用它比逐个库点进去找快得多。
- **媒体服务设为首屏直达**：把常用的那个库设成打开 App 直接进入，家里只用一套 Emby 或只用一个网盘的话很实用。

媒体服务资源库支持排序和隐藏；其中排序需要 Emby 服务端为 4.8 或更高版本。

## 六、观看进度与历史

官方手册给出的多设备历史记录同步方式是绑定 Trakt。想实现「电视上看一半、换手机接着看」，先把它绑上；只在一台设备上看的话，不必折腾这一步。

手机端另有主题色可换，电视端主题随系统界面走。
