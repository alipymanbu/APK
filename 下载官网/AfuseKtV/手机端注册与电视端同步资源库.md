# 手机端注册与电视端同步资源库

> AfuseKtV 电视端不提供注册入口，也没有「添加资源库」的按钮——账号在手机端建，资源库也从手机端同步过来。本篇把这条链路按顺序走一遍，并写清卡在哪一步会得到什么现象。

## 一、为什么 TV 端必须先配手机端

官方在电视端发布页里写得很直白：资源库仅支持通过手机端同步，TV 端不提供注册选项。所以电视上你能操作的是「登录」和「同步」，不是「注册」和「添加」。

带来的直接结果：**没有一台安卓手机，这套流程走不完**。官方使用手册里也明确写了 TV 端必须配合手机端使用。手边只有 iPhone 的话，需要先借一台安卓设备完成注册与建库这一步。

## 二、准备清单

| 需要的东西 | 说明 |
| --- | --- |
| 一个可用邮箱 | 注册用它，且后续账号注销要能收到验证码 |
| 安卓手机 | 装手机端 AfuseKt |
| 电视或盒子（已装 AfuseKtV） | 见 [下载与安装教程.md](下载与安装教程.md) |
| 同一个账号 | 两端必须登录同一账号，否则同步列表是空的 |

## 三、手机端注册

1. 在手机上装好手机端 AfuseKt，打开，进入登录页。
2. 选择邮箱注册，填邮箱与密码。
3. 去邮箱收验证邮件，按提示完成校验。
4. 回到 App 登录。

注意：手机端和电视端是两个不同的包，手机端的官方发布页在 [AfuseKt-release](https://github.com/AttemptD/AfuseKt-release)，不要把电视端的 apk 装到手机上。

## 四、在手机端把资源库建好

登录之后，在手机端的资源库页面添加你要用的来源。可选来源分成三类：网盘直连（阿里云盘、百度网盘、115、123、OneDrive 等）、媒体服务器（Emby、Jellyfin、Plex）、协议挂载（WebDAV、SMB、Alist、Local）。哪些版本带哪些来源、各自有什么门槛，见 [支持哪些网盘与协议.md](支持哪些网盘与协议.md)。

添加时有两个差别需要知道：

- **网盘与协议类**（阿里云盘、WebDAV、Alist 等）添加后由 App 自己扫描并刮削，扫描进度取决于文件数量，元数据多的时候要给存储留够空间。
- **媒体服务器类**（Emby、Jellyfin）直接用服务器自己的数据，不走 App 刮削。

以阿里云盘为例的完整添加与刮削步骤，见 [阿里云盘挂载与海报刮削.md](阿里云盘挂载与海报刮削.md)。

## 五、电视端登录并同步

1. 打开电视上的 AfuseKtV，进登录页。
2. 用**刚才手机端那个账号**登录。电视端只能登录，找不到注册入口是正常的。
3. 进入资源库页面，选择「获取资源」/「同步」这一类按钮（不同版本叫法略有差异，位置在资源库页的入口处）。
4. 手机端已建好的资源库列表会出现在电视上，选中后按提示刷新，即可开始刮削。文件多的库，第一次刮削要等几分钟。

同步过来的只是资源库本身，不含手机端已经刮削好的元数据。换句话说，电视端刮削要自己再跑一遍；同步时用手机端的资源库列表把电视端填满，然后由电视端去刮。

两端之间同步观看历史是另一件事，靠 Trakt 完成，见 [字幕音轨与倍速设置.md](字幕音轨与倍速设置.md)。

## 六、这一步常见的三种卡法

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 电视端能登录，但资源库列表为空 | 手机端还没建资源库，或两端不是同一账号 | 回手机端确认资源库存在，再核对账号 |
| 登录后提示权限或功能不可用 | 账号档位不含电视端使用权 | 见下一节说明 |
| 资源库出现了，但点进去没有内容 | 手机端添加后还没扫完，或同步到的只是库的配置 | 在电视端选中该库后手动刷新触发刮削 |

## 七、关于账号档位

官方使用手册给出的口径是：**手机端免费账号可以正常使用；电视端的使用权与资源库同步（不含刮削数据）属于付费档位，电视端不提供免费试用，官方手册列出的形式是永久 PRO**。官方手册同时写明「一经兑换无法退款」。

档位划分、名称与价格都会调整，以官方页面当时显示为准。本页只做事实说明，不代办账号，也不涉及任何绕过授权的方式。

需要注销官方账号的，官方给出的路径是联系作者本人并按要求提供账号信息与邮箱验证码，之后账号与关联数据会从系统中移除。
