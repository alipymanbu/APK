> 汇集 AfuseKtV 在电视端最常见的几类问题：装不上、登录后空库、报错误码、有画面没声音、卡顿闪退。每条给出可执行的判断与处理，按现象查表即可。

## 一、先按这张表定位

| 现象 | 属于哪一类 | 去第几节 |
| --- | --- | --- |
| 电视上装不上、提示来源受限 | 安装 | 二 |
| 能登录，但资源库是空的 | 账号与同步 | 三 |
| 海报墙里没有某部片 | 刮削 | 四 |
| 报 4001 / 4003 之类的码 | 播放 | 五 |
| 有画面没声音、有声没画面 | 播放 | 五 |
| 播放卡、切字幕卡、花屏 | 播放 | 六 |
| 用一会儿闪退 | 稳定性 | 七 |

## 二、装不上

- **提示「未知来源应用」被拦**：进「设置 → 安全 → 未知来源」，把当前文件管理器或安装器放行，再装一次。
- **装完打不开**：多半是架构装错。电视 32 位 / 64 位的包不通用，先换另一个再试，具体判断见 [下载与安装教程.md](下载与安装教程.md)。
- **提示解析包出错**：安装包传输不完整。重新拷一次，用本地 MD5 与文档里那一串（`6173F2121F44B573CFF2F5ED1D6945A6`）比对。
- **系统版本不够**：官方发布页标注 3.x 最低支持 Android 6，Android 5 的设备需要装 2.x 版本。

## 三、登录进去了，资源库却是空的

这是最高频的一类，九成不是故障：

1. **电视端不会自己建库**——资源库必须在手机端 AfuseKt 上添加，电视端只能同步。
2. **两端必须同一账号**，账号不一致时登录也成功，但同步过来什么都没有。
3. 库确实建了，但**手机端那次扫描还没跑完**——大目录第一次扫描需要时间，等它跑完再同步。
4. 电视端进去后**要主动触发一次获取/刷新**，不然列表不会自己冒出来。

还有一种情况：登录后提示功能不可用。官方使用手册的口径是手机端免费账号可用，**电视端的使用权与资源库同步属于付费档位**，官方手册列出的形式是永久 PRO，且不提供免费试用。档位与价格以官方页面当时显示为准。这一步卡住不是设备问题，也不是安装包问题。

## 四、海报墙缺片、认错片

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 剧集被认成电影 | 文件名里没有 `S01E01` 这类季集标识 | 改名后重新刮削 |
| 配了另一部片的海报 | 文件名带了压制组后缀、中英混排等噪声 | 详情页手动刮削，输入干净片名 |
| 整目录都没出现 | 挂载时选中的目录范围不对 | 重新确认挂载的文件夹 |

命名规则与挂载步骤见 [阿里云盘挂载与海报刮削.md](阿里云盘挂载与海报刮削.md)。另外注意：文件名只影响识别，不会影响播放，能播但没海报的片不用重下。

## 五、错误码与声音异常

| 现象 | 先做什么 |
| --- | --- |
| 报 4001 / 4003 | 打开 FFmpeg 开关后重试 |
| 有画面没声音 | 在播放界面打开 FFmpeg（点开后变绿），再试一次 |
| 打开 FFmpeg 后变成有声没画面 | 说明视频轨解不了，关掉 FFmpeg，换另一个内核 |
| 换内核后好了，但另一部片又不行 | 正常现象——三个内核覆盖的编码不同，逐片选即可 |

电视端 FFmpeg **默认关闭**，手机端默认开启，所以同一个文件在手机能播、在电视播不了，往往就是这一个开关的差别。内核选择的完整对照见 [三个内置播放内核怎么选.md](三个内置播放内核怎么选.md)。

## 六、卡顿、花屏、切换慢

1. **确认当前用的是哪个内核**：设备是华为/麒麟芯片而正在用 MPV，直接换成 EXO 或 VLC，官方口径里 MPV 对麒麟芯片基本不可用。
2. **SMB 挂载只能用 VLC**，且官方建议改用 WebDAV。SMB 下反复卡顿、换内核无效，先换协议。
3. **用 MPV 时可以调缓存大小**，网络片源抖动时加大缓存比反复重开有效。
4. **切换时短暂卡顿或花屏**：VLC 本身在切换动作时会有这个表现，属已知情况，不影响继续播放。
5. **网盘直连的片源**：卡顿也可能来自当时的上行带宽，换一部片或换个时段再试即可区分。

## 七、闪退与占用上涨

有用户反馈过长时间播放后内存持续上涨、甚至闪退的情况。可先做这几件事：

1. **清缓存**：在电视的「设置 → 应用」里找到 AfuseKtV，选「清除缓存」。这是 Android TV 上的通用操作，路径随品牌略有差别，一般也能在「存储空间」菜单里统一清缓存。
2. **别顺手点清除数据**：清除数据会把这个应用的本机数据连同登录状态一起清掉。不是走到最后一步不要用。
3. **退出应用后从后台彻底清一次**，再重进。
4. **元数据特别多的库，刮削阶段不要同时做别的重负载操作**。
5. **大文件先下载到本地再播**，比一直走网络直连稳。
6. **换一个内核再观察**——三个内核的内存表现不一样。

若同一部片每次都在同一位置崩，多半与文件本身有关，换一部片验证一下就能区分。

## 八、其他零碎问题

- **在线字幕用不了**：需要注册 opensubtitles（`.com` 后缀那个）并用用户名密码登录，官方手册写明每天上限 20 次，超了要等次日。
- **换电视了要重新配一遍吗**：不用。账号与资源库在服务端，新电视装好 AfuseKtV 登录同一账号，同步一次即可。
- **想注销账号**：官方给出的路径是联系作者本人，按要求提供账号信息与邮箱验证码，之后账号与关联数据会从系统中移除。注销前确认邮箱还能收信，否则这一步走不通。
- **手机端和电视端的区别**：电视端没有注册入口、不能建库，其余播放能力一致。别把电视端的 apk 装到手机上。
