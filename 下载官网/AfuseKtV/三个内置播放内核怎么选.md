# 三个内置播放内核怎么选

> AfuseKtV 内置了 MPV、VLC、EXO 三个播放内核，同一个文件换一个内核往往就能播。本篇给出三者的取舍对照表、切换入口，以及画面或声音不对时该先动哪一个开关。

## 一、怎么切

在影片**详情页**直接选播放器，不需要进设置里改全局。设置里改的是默认值，详情页选的是这一部片用哪个内核。

判断该切哪个之前，先记一条硬约束：**SMB 挂载的资源只能走 VLC**，别的内核播不了。官方使用手册在这一点上给了明确建议——用 SMB 的场景改用 WebDAV。

## 二、三者的取舍

| 维度 | MPV | VLC | EXO |
| --- | --- | --- | --- |
| 格式覆盖 | 几乎全格式，ISO 不行（3.1.0 之前） | 全格式，含 ISO | 取决于设备支持的编码 |
| 性能开销 | 最高 | 中等 | 最低 |
| 参数可调 | 最多，可自定义命令与缓存 | 少，不能动态调参 | 少 |
| 杜比 / HDR | 软解可映射非 P5 杜比 | 软解时能正确播 HDR | 设备支持时可硬解杜比 |
| 芯片适配 | 骁龙友好；麒麟基本不行 | 广 | 跟设备走 |
| 字幕样式 | 可强制覆盖 ASS 字体样式 | 常规 | 基本显示没问题，ASS 样式不支持 |
| 建议场景 | 骁龙设备、想压榨画质 | 兼容优先、要播 ISO | 电视端日常首选 |

展开说三句：

- **MPV**：能做的事最多，代价是性能需求也最大。华为/麒麟芯片的设备上用它大概率卡，官方口径是「友好程度为 0」，这类设备直接跳过它。
- **VLC**：兼容性最宽，ISO 只有它能播。代价是性能一般，切换音轨、字幕之类的动作时可能短暂卡顿或花屏；另外它不能动态调参，MPV 那边开了软解，VLC 会跟着走软解。
- **EXO**：谷歌的内核，能播什么完全取决于你的设备解码能力——设备支持的格式它就流畅，不支持的直接不认。在电视端它通常是最稳的一个。

## 三、ISO 与杜比这两类文件

- **ISO**：官方发布页提到从 3.1.0 开始解决 ISO 播放、并支持杜比/HDR，不必再忍受 VLC 的加载速度。网盘里这一份是 3.0.0-beta2，早于 3.1.0，所以播 ISO 仍要选 VLC。
- **杜比**：设备本身支持杜比时，用 EXO 可以硬解；用 MPV 则要在打开 `gpu-next` 的前提下切到软解（SW），才能映射非 P5 的杜比资源。两条路各有前提，播不出来时先确认设备支不支持，再换内核。

## 四、FFmpeg 开关：什么时候该打开

FFmpeg 在 TV 端**默认是关闭的**（手机端默认开着），它的作用是补上音频解码。三个使用时机：

| 触发场景 | 动作 |
| --- | --- |
| 报 4001 / 4003 这类错误码 | 打开 FFmpeg 后再试一次 |
| 有画面没声音 | 在播放界面找到那个「复杂」按钮，点开变绿即为开启 |
| 开了 FFmpeg 之后变成有声无画 | 说明视频轨道解不了，属于源文件或设备能力问题，关掉它换别的内核 |

不要长期开着它，它是用来兜底的，不是默认加速手段。

## 五、一个排查顺序

按这个顺序试，比来回瞎切快得多：

1. 先确认是哪一个内核在下播（详情页里看当前选中项）。
2. 播不动 → 换 EXO 试；EXO 也不认 → 换 VLC。
3. 有画面没声音 → 开 FFmpeg。
4. HDR / 杜比颜色发灰或没声 → 换内核，或按上一节的前提条件调整。
5. 设备是麒麟/华为芯片且用的是 MPV → 直接换掉 MPV。
6. 都不行，再去看 [常见问题与排查.md](常见问题与排查.md) 里的错误码条目。
