# WO Mic 连接不上或频繁断开怎么排查

> 本篇按先查什么、后查什么的顺序，排查 WO Mic 连不上、连上就断、每隔几分钟断一次的问题；大部分原因出在防火墙和两端的传输设置上。

## 一、先对两头的三项基本设置

连不上时先别怀疑软件坏了，按这三条对一遍，多数问题出在这里：

1. **传输方式是否一致**：手机 App 选的和电脑客户端选的必须是同一种（都选 Wi-Fi，或都选 USB）。
2. **控制端口是否一致**：Wi-Fi、USB、Wi-Fi Direct 三种方式都依赖控制端口，手机端和电脑端必须填同一个值，不一致必然连接失败。媒体端口只在电脑端填，连接时会自动同步给手机，不用两边改。
3. **是否在同一个局域网**：Wi-Fi 方式要求手机和电脑连同一个路由器；一边连手机流量、一边连家里宽带，是连不上的。

## 二、Wi-Fi 连上几秒就断：多半是防火墙

官方 FAQ 对这个现象给的原因很直接：Windows 防火墙拦下了客户端用来接收音频数据的 UDP 端口。尤其是"以前一直好好的、突然就不行了"，基本就是防火墙或杀毒软件开始拦截。

按官方给的三个办法依次试：

1. 把客户端重装到一个新的目录。
2. 把媒体端口从默认值改成别的数（比如 12345）。
3. 把当前网络的属性从"公用"改成"专用"。

## 三、每隔五分钟断一次

官方 FAQ 点名的场景：笔记本用 Wi-Fi 时出现规律性断线。查两个地方：

- **电源计划**：确认系统休眠时不会顺带断开 Wi-Fi。屏幕保持常亮时不断线、一熄屏就断，就是这个问题。
- **网卡驱动**：把无线网卡驱动更新到最新，并检查配置是否正确。

## 四、USB 连不上的检查顺序

1. 手机开发者选项里的 **USB 调试**开了没有。开发者选项隐藏时，进"设置 → 关于手机"连点"版本号"七次打开。
2. 数据线是否支持数据传输。只充电的线插上去电脑什么也发现不了，换一根线再试。
3. 设备管理器（`Windows + X`）→"通用串行总线设备"里有没有 **ADB Interface** 条目。没有就是电脑缺这台手机的 USB 驱动，去手机厂商官网下载安装。
4. 驱动正常仍连不上，换一个 USB 口再试。

## 五、还是定位不了：开调试日志抓一份

客户端能抓日志，自己排查或向官方反馈都用得上：

1. Options → Advanced，勾选 Enable debug mode。
2. 完全退出客户端，重新打开，把问题复现一遍。
3. 复现后再次退出客户端，去"文档"（Documents）目录找 `womic_debug_` 开头的 `.log` 文件。

抓完把 debug mode 取消勾选，平时开着会一直生成日志文件。

## 六、给断线留后路

环境里断线难免时，把客户端 Options → When aborting 里的 Auto reconnect（自动重连）和 Flash window（断线闪窗提醒）都勾上：前者断开后自动重连，后者至少让窗口闪一下提醒你声音已经断了，避免"以为在录、其实早断了"。

排查通了之后，如果声音本身还有杂音或发虚，接着看[声音有杂音或延迟高怎么调](声音有杂音或延迟高怎么调.md)。
