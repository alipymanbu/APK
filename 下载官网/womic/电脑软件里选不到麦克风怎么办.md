# WO Mic 电脑软件里选不到麦克风怎么办

## 一、先确认虚拟设备在不在

WO Mic 的声音通过一个虚拟麦克风设备进电脑，软件里选不到它，先确认设备本身存在：

- 按 `Windows + X` 打开设备管理器，进"声音、视频和游戏控制器"，正常应能看到 **WO Mic Device**。
- 打开 WO Mic 客户端，Help → Statistics，`Driver state: 1` 表示驱动正常；是 0 说明驱动没装好，重跑一遍安装包再查。
- 查一下 Windows 的麦克风隐私开关：设置 → 隐私 → 麦克风，"允许应用访问你的麦克风"要开着。这个总开关关着时，设备在列表里也不会有任何输入电平。

设备在、状态也是 1，继续往下；设备根本没有，重装客户端（安装包里带驱动）。

## 二、两类软件，两种处理

**能自己选输入设备的软件**（录音工具、OBS 这类直播录制软件、多数语音聊天软件）：在音频输入设置里直接选 **WO Mic Device**，用法和真实麦克风一样。

**不允许选设备的软件**：把 WO Mic Device 设成系统默认录音设备。Windows 设置 → 系统 → 声音 → 输入，选 WO Mic Device。之后这类软件会用它收音。

## 三、几类常见软件的具体选法

| 软件 | 怎么选 |
| --- | --- |
| 能选输入设备的录音 / 直播软件 | 音频设置里把麦克风输入选成 WO Mic Device |
| 不给选设备的软件 | 先把 WO Mic Device 设为系统默认录音设备，再打开软件 |
| Skype | 音频设备选"自定义设备"，麦克风单独选 WO Mic Device——Skype 不直接列出它，这是官方 FAQ 点名的方法 |
| 游戏内语音 | 同"不给选设备"的处理，走系统默认设备 |

前提都一样：先按[连接方式与连接步骤](连接方式与连接步骤.md)把手机连上。设备虽然一直在列表里，但没连接时不会有声音。OBS 有全局音频与独立来源两种接法，具体步骤见[在OBS或Discord里怎么用](在OBS或Discord里怎么用.md)。

## 四、一次只能连一台手机

官方明确 WO Mic 只允许一路连接。想换一台手机当麦克风，先断开当前连接再连另一台；两台手机同时给一个电脑供声做不到。

## 五、彻底不行就卸载重装

重装前知道两件事：

1. **卸载会连驱动一起删**：不管从 Windows 设置卸载还是跑卸载程序，虚拟设备驱动会自动移除；装回来时驱动一起装回。
2. **驱动没删干净时手动删**：设备管理器 →"声音、视频和游戏控制器"→ 右键 WO Mic Device → 卸载。

重装后用第一节的方法确认 Driver state 是 1，再重新连接；连不上就按[连接不上或频繁断开怎么排查](连接不上或频繁断开怎么排查.md)处理。
