## 一、官方对个人信息的口径

官方隐私页写明：WO Mic App 不收集姓名、地址、电话、邮箱、精确地理位置这类个人信息；应用内广告由 AdMob（Google 旗下）提供。官方下载页的另一句口径是"只请求最小权限、只实现必要功能"。

## 二、App 请求的权限逐项对照

官方隐私页列出的安卓权限与用途如下：

| 权限 | 官方说明的用途 |
| --- | --- |
| RECORD_AUDIO | 用手机麦克风录音（应用的核心功能） |
| BLUETOOTH / BLUETOOTH_ADMIN | 用蓝牙传输语音；选蓝牙传输时自动打开蓝牙 |
| ACCESS_WIFI_STATE | 查看 Wi-Fi 是否开启、获取当前 IP |
| CHANGE_WIFI_STATE | 选 Wi-Fi 传输时自动打开 Wi-Fi |
| INTERNET / ACCESS_NETWORK_STATE | 手机与电脑之间传输语音数据、检查网络状态 |
| WAKE_LOCK | 传输语音时防止手机锁屏 |
| ACCESS_COARSE_LOCATION | 粗略位置，官方写明用于广告 |

## 三、怎么读这份清单

1. **大多数权限对应四种连接方式**：蓝牙两项对应蓝牙传输，Wi-Fi 两项对应 Wi-Fi 传输，INTERNET 对应所有传输的数据通道，方式怎么选见[连接方式与连接步骤](连接方式与连接步骤.md)。
2. **第一次启动弹的录音权限必须给**——它就是 RECORD_AUDIO，拒绝后服务起不来；拒绝过的话去系统设置里改回"允许"。首次启动的完整流程见[下载与安装教程](下载与安装教程.md)。
3. **"位置"一项不用多想**：粗略位置是广告网络的常规请求，官方写明的用途就是广告。

## 四、订阅怎么取消

官方 FAQ 给了两个路径：

- **安卓（Google Play 安装的）**：Play 商店 → 菜单 → 我的应用 → 订阅，找到 WO Mic 点取消。
- **iPhone**：走苹果官方的订阅管理流程（设置里的 Apple 账户 → 订阅）。

如果是网盘安装的版本，订阅与付费项以你设备上实际显示的界面为准；上面两条路径只适用于对应商店的安装方式。

## 五、电脑端要留意的

- 客户端安装包没有数字签名，Windows 下载与首次运行都会弹安全警告，这是官方说明的预期情况；官方页面自己也提到，对安装包有疑虑可以上传 VirusTotal 复核。
- 不想用了，从 Windows 设置卸载 WO Mic，虚拟设备驱动会一起移除；手动卸载驱动的做法见[电脑软件里选不到麦克风怎么办](电脑软件里选不到麦克风怎么办.md)。
