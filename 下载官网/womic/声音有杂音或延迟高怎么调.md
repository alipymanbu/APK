# WO Mic 声音有杂音或延迟高怎么调

> 本篇处理 WO Mic 连上之后声音不对劲的问题：电流声、声音像机器人、延迟明显，分别对应换音源、换连接方式和查干扰，逐条对照着调。

## 一、先换音源：五个模式逐个试

App 设置里有音源（Audio source）选项，安卓上提供五个模式。官方特别说明：受各家手机硬件和系统定制影响，这些模式在你的手机上不一定都可用，效果也可能与描述有出入，所以要自己逐个试：

| 模式 | 官方给的适用提示 |
| --- | --- |
| Default | 手机内置麦克风，默认用它 |
| Mic mode 1 | 想用外接有线耳机收音时试这个 |
| Mic mode 2 | 其他模式有回声时试这个 |
| Mic mode 3 | 离手机远、或环境嘈杂时试这个 |
| Rear mic | 想收录手机背面方向的声音时试这个 |

电流声、环境噪声被放大的杂音，对应的解法就是这个：换一个音源再试——某个音源对环境噪声太敏感时，杂音就明显。

## 二、声音像机器人：四个动作

官方 FAQ 把"声音断续、像机器人"的解法列了四条：

1. **改用 USB 连接**。官方口径是 USB 比无线稳、延迟更低，无线连出来的声音发虚时换线最有效。
2. **把 WO Mic App 保持在前台**。安卓给前台应用更高的运行优先级，App 切到后台收音就容易碎。
3. **关掉占 CPU 的其他程序**。收音、编码、传输都吃算力，CPU 不够声音就断续，手机和电脑两头都清一清。
4. **蓝牙和 Wi-Fi 别同时开**。两者都用 2.4G 频段，互相干扰很明显；用哪个就把另一个关掉，手机和电脑两头都要关。

## 三、延迟高：先看连接方式

对延迟敏感的场景（游戏语音、直播对音）优先用 USB，官方明确它的延迟低于无线方式。无线方式受现场网络和干扰影响大，信号差时换近一点的路由、或干脆换 USB。

系统层面的音频规格是固定的：48000 Hz 采样、16 bit、单声道（PCM）。这是官方设定的格式，客户端和 App 里都没有可调项，声音不对劲时别在这上面找开关。

## 四、验证改动有没有生效

调完音源或换了连接方式，用客户端的本地试听确认效果：Options → Play in speaker，电脑音箱直接播放手机传来的声音，边调边听。确认完取消勾选，否则录音或开会时会出回声。
