## 一、先弄清要装几样东西

WO Mic 是把安卓手机变成电脑麦克风的工具，开发者是 [Wolicheng Tech](https://www.wolicheng.com/womic/)。它不是装一个软件就完事，而是三样东西配合：

| 组件 | 装在哪 | 干什么用 |
| --- | --- | --- |
| WO Mic App | 安卓手机 | 用手机麦克风收音，把声音传给电脑 |
| WO Mic 客户端 | 电脑 | 连接手机、接收声音数据 |
| 虚拟设备驱动 | 电脑（随客户端一起装） | 把收到的声音伪装成一块真实麦克风，供其他软件调用 |

三样缺一不可：只装手机 App、电脑上没有客户端和驱动，任何软件里都不会出现可用的麦克风。

两点提前说明：

1. **手机和电脑两端都要装**，先后顺序无所谓，但连接前必须两边都就绪。
2. **一个电脑同时只能连一台手机**，官方 FAQ 明确了这一点，没有多台并连。

## 二、手机端：安装 App 与版本核对

网盘里这一版是安卓安装包，动手前先核对几项基础信息：

| 项目 | 这一版（5.3）的情况 |
| --- | --- |
| 适用设备 | 安卓手机 / 平板 |
| 系统要求 | 标注"安卓 5.2 以上" |
| 包名 | com.wo.voice2 |
| 安装包大小 | 6.20 MB |
| 安装包 MD5 | 819BF2C9C9195555877DCE0C9B968434 |
| 官方最新版 | 以[官网下载页](https://www.wolicheng.com/womic/download.html)当时显示为准 |

关于"安卓 5.2"：安卓公开的版本号里并没有 5.2（5.1 之后直接到 6.0），按"Android 5 系及以上"理解即可，能不能装以手机实际提示为准。

安装步骤：

1. 在手机上打开 [WO Mic 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c80f7f0743cf)，转存到自己网盘后下载到手机。
2. 下载完核对文件大小是不是 6.20 MB 上下，差得多的删掉重下。
3. 从手机"文件管理"里点这个 `.apk` 安装。系统提示"不允许安装未知来源应用"时，按提示放行你用来打开它的那个应用，再回安装界面继续。
4. 装完先别急着连——选哪种方式、在哪开服务，见[连接方式与连接步骤](连接方式与连接步骤.md)。

除了网盘这份，官方渠道还有两个入口：Google Play 里的 WO Mic，以及官网下载页的直装 APK。版本号可能与网盘这份不一致，选哪个看你的获取条件。

## 三、电脑端：先补运行库，再装客户端

电脑端只有 Windows 版（官方已不再支持 Linux，游戏主机也不支持），安装包里同时带客户端与虚拟设备驱动。

1. **装 VC 运行库（x86）**。官方要求先装 Microsoft 的 VC 运行库 x86 版（`vc_redist.x86.exe`，官网下载页有微软直链），否则打开客户端会报缺少 DLL 错误；以前装过的跳过。
2. **下载并运行客户端安装包**。从[官网下载页](https://www.wolicheng.com/womic/download.html)获取，截至 2026 年 9 月客户端版本为 6.3、驱动版本为 2.1.0.0（以官网当时显示为准），安装包不到 2 MB。
3. **放行安全警告**。安装包没有数字签名，下载时和首次运行时 Windows 都会弹警告，这是官方说明里明确提到的情况，确认继续即可。

## 四、装完怎么确认装对了

电脑端用下面任一方法确认驱动正常：

- **设备管理器**：按 `Windows + X` 打开设备管理器，进"声音、视频和游戏控制器"，列表里应出现 **WO Mic Device**。
- **客户端自检**：打开客户端，选 Help → Statistics，`Driver state: 1` 表示驱动工作正常；显示 0 说明驱动没装好，重跑一遍安装包再查。

手机端更简单：打开 App 能进主界面、录音权限请求能正常授予，就算就绪。若权限被拒过，去系统设置把 WO Mic 的麦克风权限改回"允许"，否则服务起不来。App 一共请求哪些权限、每项干什么用，见[权限与隐私安全说明](权限与隐私安全说明.md)。

## 五、两个容易忽略的点

1. **卸载是连带驱动一起删的**。不想用了，从 Windows 设置卸载 WO Mic，虚拟设备驱动会跟着移除；没删干净时，设备管理器里右键 WO Mic Device 卸载即可。
2. **电脑端装好后先别在别的软件里乱选设备**。设备要在手机连上之后才有声音，先按连接那篇把两头接起来，再看[电脑软件里选不到麦克风怎么办](电脑软件里选不到麦克风怎么办.md)去具体软件里选它。
