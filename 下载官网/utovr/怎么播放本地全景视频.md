## 一、先把视频弄进手机

UtoVR 播本地视频，前提是视频文件已经在手机存储里。常见做法：

- 数据线连电脑，把 mp4 等视频文件直接拷进「下载」或「视频」目录；
- 聊天工具、邮箱中转后存到本地；
- 网盘 App 下载到手机。

一个容易白找半天的点：**老版本 UtoVR 里的「飞屏」功能（电脑端用飞屏助手把视频推送到手机）在 4.4.2 的更新里被明确删掉了**（官方更新日志原话是「删除飞屏功能」）。网上还能搜到不少飞屏教程，如果照着找却找不到「飞屏」入口，不是你操作错了，是这一版里已经没有这个按钮，走数据线拷贝即可。

## 二、选对播放模式

全景视频拍出来是一整块摊平的画面，播放器得知道「该怎么把它卷回去」。UtoVR 的做法是在播放时让你手动选模式，选错了画面就会畸变或重影。按片源对号入座：

| 你的片源 | 该选的模式 |
| --- | --- |
| 普通电影、电视剧、横屏视频 | 2D 普通视频 |
| 球形全景视频（摊开后宽高比约 2:1 的单画面） | 全景视频 360° |
| 半球全景视频（约 1:1） | 全景视频 180° |
| 全景 3D，画面上下两半一模一样 | 3D 360° / 3D 180° 的「上下」分屏 |
| 全景 3D，画面左右两半一模一样 | 3D 360° / 3D 180° 的「左右」分屏 |

判断技巧：暂停后看画面——上下或左右有重复的一半就是 3D 分屏片源；画面摊平得像一张世界地图就是 360°；只有半圈内容的就是 180°。

## 三、编码与格式

按官方 SDK 页面的口径，播放器支持的常见封装是 MP4、MOV、F4V。官方对移动端播放的片源参数还有更具体的建议（出自官方飞屏助手页面的说明——功能虽已移除，这组数值对本地播放同样适用）：

| 参数 | 官方建议 | 超了会怎样 |
| --- | --- | --- |
| 编码 | H.264 | 官方明确移动端只支持 H.264，其他编码需转码 |
| 帧率 | 30fps | 60fps 在部分设备上体验有问题 |
| 码率 | ≤10 Mbps | 过高时播放容易异常（黑屏、无声等） |
| 分辨率 | 以手机为准 | 有的机型能放 4K，低的只到 2K |

应用更新日志里也提到过本地播放支持 H.265 编码，但老机型未必吃得动，H.265 片源放不动时转成 H.264 最稳。实操建议：

- 从相机（全景相机、无人机）导出的素材，优先用 H.264 编码的 MP4；
- 不常见的封装（mkv 等）不被支持时，用格式工具转成 MP4 再放进来。

## 四、画质与流畅度

- UtoVR 支持软解和硬解，2K/4K 码率可切换；4K 全景视频卡顿时，先降码率或改用硬解，而不是怪手机性能不行——全景视频实际同时渲染的像素量远大于普通视频；
- 手机发热明显属于正常现象，夏天长时间看 4K 全景尤其如此；机身过热触发的降频还会连带让陀螺仪变迟钝；
- 黑屏、花屏、声音正常画面不动这类「放不出来」的问题，见 [常见问题与解决.md](常见问题与解决.md)。

## 五、戴上眼镜看

模式选对后，点播放界面右下角的眼镜图标切成左右分屏，把手机装进 VR 眼镜即可。分屏切换、陀螺仪视角和眼镜适配的细节都在 [分屏与眼镜观看设置.md](分屏与眼镜观看设置.md)；还没装应用的话，先看 [下载与安装教程.md](下载与安装教程.md)；视频还没着落的，看 [全景视频片源哪里找.md](全景视频片源哪里找.md)。
