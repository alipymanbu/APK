## 一、装之前先对一下版本

UtoVR 是一款安卓端的全景（VR）视频播放器，手机装上它，再配一个几十元的手机盒子式 VR 眼镜就能看全景视频；不戴眼镜时也能当普通播放器用。它在安卓应用商店里出现的名字有时写作「utovr」「UtoVR」「uto vr手机播放器」，指的都是同一个包名下的应用。

本篇对应的安装包信息如下。这些是这份包自己的事实；网上能搜到的官方最新版往往已经往前走了几个版本，两者不是一回事：

| 项目 | 值 |
| --- | --- |
| 版本 | 4.4.2 |
| 包名 | com.jietusoft.utovr |
| 安装包大小 | 27.89 MB |
| MD5 | 99708421B3333FD2D8A895203FE4B2BC |
| 开发商 | 上海优土视真文化传媒有限公司 |
| 系统要求 | 安卓 5.2 以上（安装包标注口径，以实际安装提示为准） |

## 二、获取安装文件

安装包从上面的 **UtoVR 安装文件资源（夸克网盘）** 获取：先用夸克 App 或网页版打开分享链接转存到自己的网盘，再下载到手机存储里。也可以先下载到电脑，再用数据线、局域网或聊天工具把 apk 文件传进手机——无论走哪条路，装之前都可以按下一节的方法核对一下文件。

## 三、安装步骤

1. 在手机文件管理器里找到下载好的 apk，点它。
2. 系统提示「禁止安装未知来源应用」时，按提示跳到设置里给「文件管理」或发起安装的那个应用开权限。常见品牌的入口：

   | 品牌 | 大致路径 |
   | --- | --- |
   | 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
   | 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
   | OPPO / 一加 / realme | 设置 → 安全 → 安装未知应用 |
   | vivo / iQOO | 设置 → 安全 → 更多安全设置 → 应用安装 |

   不同系统版本菜单名字会有出入，认「安装未知应用 / 外部来源」这几个关键词即可。
3. 回到安装界面，点「继续安装」，等进度走完。
4. 打开应用，首次启动若弹权限申请（存储等），允许它，否则后面扫不到本地视频。

## 四、顺手校验一下文件

如果下载后安装总是失败，先确认文件本身没坏。在电脑上对 apk 做 MD5：

```powershell
certutil -hashfile utovr_v4.4.2.apk MD5
```

结果应等于第一节表格里的 `99708421B3333FD2D8A895203FE4B2BC`（不区分大小写）。对不上就说明传输或下载过程出了问题，重新获取一份再装。

## 五、装不上时的排查顺序

- **「解析包出现错误」**：多半是文件不完整或损坏，先按上一节校验，对不上就重下。
- **「与已安装的应用签名冲突」**：手机里装过其他渠道的同包名 UtoVR，先把旧的卸载再装这份。
- **提示存储空间不足**：清理出至少几百 MB 再试。
- **装好了但一打开就退**：去 [常见问题与解决.md](常见问题与解决.md) 找对应现象。
