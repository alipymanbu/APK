## 一、三样东西别搞混

同一个名字下其实有三个不同的产物：

| 形态 | 平台 | 给谁用 | 说明 |
| --- | --- | --- | --- |
| 手机 App | 安卓（另有 iOS 版） | 普通用户 | 本套文档的主角，配合手机盒子式 VR 眼镜观看，见 [下载与安装教程.md](下载与安装教程.md) |
| 桌面客户端 | Windows / Mac | 普通用户 | 官网「桌面客户端」页面提供的 zip 包，装在电脑上看全景视频 |
| 播放器 SDK | Android / iOS / Flash / HTML5 | 开发者 | 集成到自家应用里的开发组件，普通用户用不到 |

在官网下载时注意认准「桌面客户端」和「App」是两个不同页面；开发者 SDK 页面的功能对照表（免费版与定制版的区别）也不适用于手机 App。

## 二、桌面客户端能做什么

按官方页面的介绍，桌面客户端的特点是：

- Windows、Mac 双平台，免费下载使用；
- 支持 4K 高清 VR 视频和全景图片播放；
- 支持 VR 视频直播数据流（RTMP、HLS 等流媒体协议的点播与直播）；
- 支持蓝牙手柄操控；
- 官方页面提到适配 Oculus DK1、DK2 外接头显——这两个型号年代久远，如今主流的头显不一定接得上，这条信息只能当历史参考，以官方页面现状为准。

## 三、桌面客户端的配置参考

官方给的高清播放配置建议，看 4K 全景前可以对照一下自己的电脑：

| 项目 | 建议 |
| --- | --- |
| 显卡 | NVIDIA 或 AMD 独立显卡，显存 2G 以上 |
| 内存 | 2G 以上 |
| 片源编码 | H.264 |

「片源编码」这条最容易被忽略：电脑配置再好，片源本身是非标准编码，照样放不出来。片源怎么准备、模式怎么选，思路与手机版一致，参考 [怎么播放本地全景视频.md](怎么播放本地全景视频.md)。

## 四、你该用哪个

- 手里有安卓手机和 VR 眼镜盒子 → 装手机 App，这是最常见也最省事的路线；
- 想在电脑大屏上看全景视频、或者配合头显设备 → 用桌面客户端；
- 只是想找「能播放全景视频的网页播放器」给网站用 → 那是 SDK 的事，不属于本文档范围。

分屏与眼镜相关的设置只存在于手机 App 上，见 [分屏与眼镜观看设置.md](分屏与眼镜观看设置.md)。
