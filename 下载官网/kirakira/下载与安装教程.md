## 一、装机前先确认三件事

| 检查项 | 口径 | 说明 |
| --- | --- | --- |
| 系统版本 | 安卓 5.2 及以上 | 低于该版本的旧机型可能装不上，或打开后界面异常 |
| 存储空间 | 安装包约 5.11M | 装完解压占用会更大，正常余量的手机都够用 |
| 安装来源 | 认准同一份安装包 | 各应用商店收录的同名应用差异很大，见下文第五节 |

这份网盘里的安装包信息如下，装完可以在系统设置的应用信息里核对：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.1 |
| 包名 | ai.chatkira.app |
| 大小 | 5.11M |
| MD5 | 049978C2C978419CFE2DAC114C082502 |

## 二、下载安装包

1. 打开 **[KiraKira 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a1a850e21580)**（即开头那条链接）；
2. 把里面的 APK 文件**转存到自己的网盘**再下载（直接下载通常也能下，转存一份更稳妥，以后换机还能回来拿）；
3. 等下载完成，得到一个 APK 文件。如果文件明显小于 5M，多半是没下完整，重新下一次。

## 三、安装步骤

1. 在手机文件管理里找到刚下载的 APK，点它；
2. 系统提示「禁止安装未知来源应用」时，按提示允许你的文件管理器（或浏览器）安装应用——不同品牌路径不一样，安卓 8 以后一般在 **设置 → 应用管理 → 特殊应用权限 → 安装未知应用** 里，直接在设置里搜「安装未知」最快；
3. 回到文件管理器再点一次 APK，点「安装」；
4. 装完点「打开」，进入首次启动流程。

国产 ROM（小米、华为、OPPO、vivo 等）可能弹安全提示，询问你是否继续安装。是否继续由你自己判断来源可信度；选「仍要安装」后流程照旧。

## 四、核对 MD5（可选但推荐）

MD5 是文件的指纹，用来确认「我拿到的就是这份文件、没坏也没被换过」：

1. 在应用商店搜一个「MD5 校验」类小工具，或用电脑端的校验工具；
2. 对刚下载的 APK 计算一次 MD5；
3. 和第一节表格里的 `049978C2C978419CFE2DAC114C082502` 对比，一致即可放心安装。

不校验也不影响安装，这一步只是给「文件没问题」一个依据。

## 五、关于「商店里的 KiraKira 版本怎么都不一样」

你在各应用商店搜 KiraKira，会看到版本号五花八门（从 1.0.x 到 15.0 的都有）、包名也不一致（有 `ai.chatkira.app`，也有其他拼写）。这是多轮改版和多方收录叠加的结果，没有哪一版是「错版」，但功能与界面可能差别不小：

- 想和本套文档口径一致，就用第一节网盘里那份 v1.0.1；
- 想追最新版，以你所用渠道当时显示的版本为准，本文写的界面细节可能对不上；
- 装了新版后找不到某个功能时，先看看[常见问题排查.md](常见问题排查.md)里「版本差异」那条。

装好之后去哪、怎么选角色开始第一场对话，看[新手怎么开始聊天.md](新手怎么开始聊天.md)；装不上或打开就乱码，直接翻[常见问题排查.md](常见问题排查.md)。
