## 一、安装包从哪里拿

TrAni 以 apk 安装包的形式分发，安装包从这里获取：

1. 打开 [trani 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ab0e5a6d8922)；
2. 把里面的安装包**先转存到自己的夸克网盘**，再从自己的网盘里下载，速度和完整性都更有保障；
3. 在手机上用夸克网盘 App 找到转存的 `trani_v1.1.1.apk`，点击下载；
4. 下载完成后直接点开，按系统提示安装。

这份安装包的基本信息，可以用来核对下载是否完整：

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.1.1 |
| 包名 | com.TrAni.app |
| 大小 | 约 57.75M |
| 语言 | 简体中文 |
| MD5 | `90EC640C31D7E22642AF642FD040FFC3` |

关于版本：网上能搜到的 TrAni 版本号比较杂，不同站点收录的有 1.1.x、1.4.x、1.5.x，官方发布页 `tranimanga.github.io` 标注的又是另一个版本，各渠道并不一致。**以你实际拿到手的安装包为准**，日常使用差异不大，本套文档的操作步骤是按 1.1.1 核对的。

## 二、安装前的准备

- **系统版本**：安装包要求安卓 5.2 及以上（以安装时的系统检查为准），近几年的手机基本都满足；
- **存储空间**：安装包约 57.75M，安装展开后占用更大，建议手机剩余空间在 200M 以上；
- **网络**：安装本身不用联网，装完首次打开才需要。

## 三、安装步骤

1. 点开下载完成的 `.apk` 文件；
2. 系统提示「禁止安装未知来源应用」时，点「设置」进入授权页；
3. 把「允许来自此来源的应用」打开——授权对象是你用来下载的那个应用（比如夸克网盘或浏览器），不是 TrAni 本身；
4. 返回安装页点「安装」，等进度走完；
5. 点「完成」或「打开」。

不同品牌的手机，「允许未知来源」入口的叫法不一样，但基本都是从安装弹窗直接跳过去，不需要自己在设置里翻。如果安装时没弹授权页、直接被拒，看下一节。

## 四、安装被拦截或失败怎么办

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点安装没反应，或提示「禁止安装」 | 没授权「安装未知应用」 | 从弹窗进设置页打开授权；找不到入口就在系统设置里搜「未知来源」或「安装未知」 |
| 小米 / 红米提示「外部来源应用受限」 | MIUI 的纯净模式在拦截 | 系统设置里搜「纯净模式」，关闭后再装 |
| 华为 / 荣耀提示「外部来源应用检查」 | 系统安全检查 | 按提示选择「继续安装」即可 |
| 提示「解析包出错」 | 包没下载完整 | 回网盘重新下载；下载完核对大小是不是 57.75M 左右、MD5 是否与上表一致 |
| 提示「应用未安装」 | 存储空间不足，或之前装坏的半截包冲突 | 清出空间后重试；装过失败半截的先卸载再装 |

如果你的安装包不是上表这份（比如从别处拿的），遇到解析包出错时重点怀疑下载不完整，重下一次通常就能解决。装是装上了、却打不开或频繁闪退，另见 [打不开或闪退怎么办.md](打不开或闪退怎么办.md)。

## 五、装完之后

首次打开 TrAni 会请求存储权限（缓存视频、记录进度要用），建议允许。界面怎么找番、弹幕和缓存在哪，见 [怎么用.md](怎么用.md)；想在大屏上看，见 [怎么投屏到电视.md](怎么投屏到电视.md)；用的时候碰到问题，先翻 [常见问题与解决方法.md](常见问题与解决方法.md)。
