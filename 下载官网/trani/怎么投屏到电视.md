# TrAni 怎么投屏到电视

> 手机屏看番不过瘾时，把 TrAni 投到电视上。本篇讲投屏前的检查、操作步骤，以及搜不到设备、投上卡顿的排查办法。

## 一、投屏前先确认三件事

| 检查项 | 要求 | 不满足的后果 |
| --- | --- | --- |
| 网络 | 手机和电视连**同一个路由器**的 Wi-Fi | 搜不到设备，这是最常见的原因 |
| 电视端 | 智能电视或电视盒子，且支持 DLNA / 多屏互动类协议 | 搜到了也连不上 |
| 路由器 | 没开「AP 隔离」（访客网络、公司网络常默认开启） | 两台设备互相看不见 |

## 二、投屏步骤

1. 在 TrAni 里进入播放页，点出播放器控制栏；
2. 找**投屏图标**（一般是「屏幕 + Wi-Fi 波纹」的样子，在播放器控制栏上；位置以你装的版本实际界面为准）；
3. 点开后等它搜索局域网内的设备，选中你家电视的名字；
4. 等几秒，画面出现在电视上；之后手机可以继续选集、调音量或直接锁屏。

## 三、搜不到设备的排查清单

按命中率从高到低：

1. **手机用了移动数据，或电视根本没连网**——两边必须同一 Wi-Fi；手机开热点给电视连也算同一网络；
2. **路由器开了 AP 隔离**——访客网络、公司网络常见；换回自己家的路由器，或在路由器设置里关掉隔离；
3. **电视端的投屏接收开关没开**——在电视设置里搜「多屏互动」「DLNA」「无线投屏」这些词，打开再试；
4. **电视是老款非智能电视**——它收不了投屏，需要配一个支持投屏接收的电视盒子；
5. **手机省电策略限制了后台搜索**——让投屏搜索页保持在前台，别切走再试。

## 四、投上了但卡顿、掉线

- **离路由器太远**：电视和手机别隔两堵墙，尽量靠近路由器；
- **5G 频段穿墙差**：信号弱的房间让设备改连 2.4G 频段试试；
- **片源本身慢**：网络高峰期片源出流慢，投屏只会放大卡顿，换低清晰度或换个时段再看（见 [常见问题与解决方法.md](常见问题与解决方法.md)「打开一直加载中」一条）。

## 五、实在投不了的两个替代

- **有线直连**：手机支持视频输出（Type-C 带 DP 功能）的话，一根 Type-C 转 HDMI 线接到电视，不挑网络、稳定，成本是一根转接线；
- **缓存离线看**：不折腾投屏，把想看的几集缓存到手机本地看，操作见 [怎么用.md](怎么用.md) 的「缓存与观看进度」一节。
