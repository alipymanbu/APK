## 一、按场景分类的常用动作

动作列表有上百项，逐个翻很费劲，先按你的目的对号入座：

| 你想做 | 可选动作 | 前置条件 |
| --- | --- | --- |
| 一键开应用 | 打开应用、打开应用快捷方式、打开 URL | 无 |
| 替代导航键 | 返回、主页、最近任务、打开菜单、分屏（Android 7.0+） | 无 |
| 控制播放 | 播放/暂停、上一首/下一首、快进/快退 | 无 |
| 控制音量 | 音量加/减、显示音量面板、切换铃声模式、静音（Android 6.0+） | 无 |
| 屏幕操作 | 截屏（Android 9.0+）、锁屏、显示电源菜单、切换横竖屏 | 锁屏/关屏需设备管理员 |
| 手电筒 | 开/关/切换手电筒（Android 6.0+） | 相机权限 |
| 亮度 | 调高/调低/切换自动亮度 | 修改系统设置权限 |
| 勿扰 | 开/关/切换勿扰模式（Android 6.0+） | 勿扰访问权限 |
| 输入内容 | 输入按键、输入文本块、移动光标 | 需配套键盘（见下节） |
| 模拟点按 | 点按屏幕指定坐标 | 见第四节 |
| 语音助手 | 打开语音助手、打开设备助手 | 无 |
| 无操作 | 消费按键事件（拦截但什么都不做） | 无 |

最后那个「无操作」值得单独一提：把误触率高的按键（比如某些机型侧边的 AI 键）映射成「什么都不做」，骚扰就消失了。

## 二、输入按键与文字：需要配套键盘

「输入按键」「输入文本块」这类动作的实现方式比较特殊：它们要借一个输入法来替你「打字」。所以要做两件事：

1. 安装官方配套的 **Key Mapper GUI Keyboard**（独立应用，官方文档站和应用内有入口）。
2. 在系统设置里把当前输入法切到它，或让 Key Mapper 在触发时自动临时切换。

它是个为配合这类动作设计的专用键盘，不适合当日常输入法。常见的用法是把它设成第二输入法——平时用你的主输入法，触发到输入类动作时应用自动切过去、输完再切回来。两个输入法不能同时生效，这是安卓的机制决定的。

## 三、需要 root 的动作

一部分系统级开关在较新的安卓版本上被系统收紧了，不开 root 用不了：

| 动作 | 条件 |
| --- | --- |
| 开关 Wi-Fi | Android 10 起需要 root |
| 开关移动数据 | 需要 root |
| 开关飞行模式 | 需要 root |
| 更改默认键盘 / 显示键盘选择器 | 部分安卓版本需要 root |

普通手机没有 root 的话，直接跳过这一组，上面第一节里的动作足够覆盖绝大多数场景。

## 四、点按屏幕坐标类动作

「点按屏幕坐标」可以让某个按键替你在屏幕的指定位置点一下。两个使用要点：

- 触发这类动作时，**你自己不能同时触摸屏幕**——这是安卓对无障碍模拟点击的限制，那个瞬间你的触摸会被忽略。
- 坐标按屏幕分辨率记录，换分辨率（换机、改显示大小）后需要重新录。

3.1.1 还新增了「与界面元素交互」的动作，与固定坐标点按是两种思路，具体用法以应用内该动作的说明为准。

## 五、悬浮按钮

除了物理按键，你还可以在屏幕上创建**悬浮按钮（Floating Buttons）**：一组摆在任意位置的虚拟按键，行为和实体键一样——也能绑触发器、加约束、派动作。

适合两类场景：

- 手机按键不够用或某个键已经不太灵了，用悬浮按钮顶上；
- 想给某个动作留一个「看得见的入口」，比如在屏幕角落放一个一键截屏的圆点。

悬浮按钮的大小、位置都能调，不用的时候可以整体隐藏。

动作配多了之后，管理成本会转移到「怎么组织映射」上，建议结合 [触发器与约束条件详解.md](触发器与约束条件详解.md) 里的约束机制来收窄每条映射的生效范围；遇到动作不生效，去 [常见问题与解决方法.md](常见问题与解决方法.md) 先查权限。
