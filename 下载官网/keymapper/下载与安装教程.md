## 一、安装包基本信息

Key Mapper 是一款开源的安卓按键映射工具，可以把音量键、导航键、外接键盘按键、手柄按键等硬件按键改成你想要的操作。本篇针对的是下面这份安装包：

| 项目 | 内容 |
| --- | --- |
| 版本 | 3.1.1 |
| 包名 | io.github.sds100.keymapper |
| 安装包大小 | 13.15M |
| MD5 | 501A29BB9070AFEF8D99C92E8EF9D47C |

表格里的版本、大小、MD5 是这份安装包自身的实际信息。官网与各应用商店分发的是持续更新的新版本，版本号可能与这份不同，功能上也会有差异（见第五节）。

## 二、从哪里获取安装包

安装文件资源放在夸克网盘里，获取路径是：打开 [Key Mapper 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0bc74aaebb3b) → 转存到自己的网盘 → 在网盘 App 里下载这个 APK 文件。转存到自己网盘后再下载，不怕原分享失效。

如果你习惯自己跟最新版，也可以走官方渠道：

- 官方文档站：[keymapper.app](https://keymapper.app/)
- 源码与发布页：[github.com/keymapperorg/KeyMapper](https://github.com/keymapperorg/KeyMapper)
- F-Droid（开源应用商店）里搜索 Key Mapper

官方渠道给的是当时最新的版本；网盘这份的价值在于版本固定——你核对过 MD5 之后，装出来的就是上面表格里明确的那一版，不会出现「装完发现和预期不是一个版本」的情况。

## 三、安装步骤

1. 在手机上打开下载好的 APK 文件。系统默认拦截「未知来源应用」的安装，首次安装会弹提示，按提示允许浏览器或文件管理器「安装未知应用」即可（路径大致是：设置 → 应用 → 特殊应用权限 → 安装未知应用，不同品牌叫法略有差异）。
2. 回到文件，点「安装」，等安装完成。
3. 装完先不要急着按音量键试。这个应用必须先开启无障碍服务才会工作，直接开主界面你会看到一条「辅助功能服务」的修复提示——跟着做就行，完整步骤见 [无障碍服务与电池优化设置.md](无障碍服务与电池优化设置.md)。

## 四、核对安装包（可选）

如果你在意拿到的文件和上面表格里的是不是同一个文件，可以校验 MD5：

- 在电脑上：PowerShell 里执行 `Get-FileHash 文件路径.apk -Algorithm MD5`，输出的值（忽略大小写）与 `501A29BB9070AFEF8D99C92E8EF9D47C` 一致即为同一文件。
- 在手机上：部分文件管理器自带「文件校验」或「MD5」功能，入口一般在文件的详情或更多菜单里。

大小写不一致不算异常，MD5 比对本身不区分大小写。

## 五、关于版本差异

- 这份安装包是 3.1.1。官方主线后来已迭代到 4.x，新版本对安卓系统版本的要求也提高了（4.x 要求安卓 8.0 以上），并加入了息屏映射等新能力。
- 3.1.1 对安卓版本的要求以官方页面为准；旧版本对系统的要求比 4.x 宽松，多数近年买的手机都能装。
- 3.1.1 相比更早版本的主要更新包括：时间类约束条件、与界面元素交互的动作，以及对 Minecraft 1.21.80 的按键兼容修复。

如果你装完之后遇到按键不生效、被系统杀后台这类问题，先去 [无障碍服务与电池优化设置.md](无障碍服务与电池优化设置.md) 把两处设置做齐，再对照 [常见问题与解决方法.md](常见问题与解决方法.md) 排查。
