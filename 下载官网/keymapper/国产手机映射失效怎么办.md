# Key Mapper 在国产手机上总失效？按品牌逐项设置

> 电池优化白名单只是第一道防线。小米、华为、OPPO、vivo、三星各有自己的一套后台限制，漏了哪层映射就会「过一阵就失灵」。本篇按品牌列出设置入口。

## 一、为什么「设置过了」还是失效

Key Mapper 的无障碍服务需要常驻后台监听按键，而国产 ROM 的省电策略是**分好几层**的：电池优化只是最基础的一层，下面还有自启动管理、后台冻结、锁屏清理、长期未用自动回收权限等等。任何一层没过，就会出现同一个症状——现在好好的，过几个小时或过个夜就失灵。

本文的设置清单整理自多个公开来源的交叉印证（包括 XDA 论坛的机型讨论、专门收录各品牌后台策略的资料站 DontKillMyApp 等）。各品牌设置入口的名称随系统版本变动频繁，**以下路径以你手机当前系统里实际显示的为准**，对不上就按关键词在系统设置里搜。

## 二、小米 / Redmi（MIUI / 澎湃 OS）

查杀最激进的几档之一，五项要做全：

| 设置 | 入口（常见路径） |
| --- | --- |
| 自启动 | 手机管家（安全中心）→ 应用管理 → 自启动 → 允许 Key Mapper |
| 省电策略 | 设置 → 应用设置 → 应用管理 → Key Mapper → 省电策略 → 无限制 |
| 锁屏清理 | 手机管家 → 省电与电池 → 右上齿轮 → 锁屏后清理内存 → 改为「从不」（或把清理周期拉到最长） |
| 未使用回收 | 应用管理 → Key Mapper → 网络与权限类目下，关闭「未使用时暂停应用活动 / 自动移除权限」类开关 |
| 最近任务锁定 | 最近任务界面，长按 Key Mapper 卡片 → 加锁（挂锁图标） |

小米机型有两个特有的坑：

- 系统把应用杀掉时，会**连无障碍授权一起收走**，重新开启要等一个 10 秒倒计时——遇到「无障碍隔一阵就自动关」，根子就是后台被清，说明上面五项还有漏。
- 系统大版本更新或重启后，个别开关可能被重置，失效了先把这张表再过一遍。

## 三、华为 / 荣耀（EMUI / HarmonyOS）

| 设置 | 入口（常见路径） |
| --- | --- |
| 启动管理 | 设置 → 应用和服务（应用）→ 应用启动管理 → Key Mapper → 关闭「自动管理」，手动允许：自启动、关联启动、后台活动 三项全开 |
| 电池优化 | 设置 → 电池 → 更多电池设置 / 优化，把 Key Mapper 设为不优化；或在应用详情 → 耗电详情 → 启动管理 |
| 锁屏清理 | 部分机型有「休眠时始终保持网络连接 / 锁屏清理后台」类开关，按需关闭 |

旧款 EMUI 机型的对应开关叫「受保护应用」（手机管家 → 电池 → 受保护应用），把 Key Mapper 设为受保护。

## 四、OPPO / 一加 / realme（ColorOS）

| 设置 | 入口（常见路径） |
| --- | --- |
| 自启动 | 手机管家 → 权限隐私 → 自启动管理 → 允许 Key Mapper |
| 后台运行 | 设置 → 电池 → 更多设置（应用耗电管理）→ Key Mapper → 允许后台运行 / 不优化 |
| 后台冻结 | 应用详情 → 耗电管理，关闭「后台冻结 / 检测到异常时自动优化」 |

一加海外版（OxygenOS）的入口在 设置 → Apps → Key Mapper → Battery → 取消优化（Unrestricted）。

## 五、vivo / iQOO（Funtouch OS / OriginOS）

| 设置 | 入口（常见路径） |
| --- | --- |
| 自启动 | 设置 → 应用与权限 → 权限管理 → 自启动 → 允许 Key Mapper（vivo 默认全关，必须手动开） |
| 后台耗电 | 设置 → 电池 → 后台耗电管理 / 更多设置 → Key Mapper → 允许后台高耗电 |
| 最近任务锁定 | 下拉应用卡片加锁 |

## 六、三星（One UI）

三星的策略是「按天记」：几天没用的应用会被自动放进「休眠」名单，服务随之被停。

1. 设置 → 电池 → 后台使用限制，确认 Key Mapper 不在「休眠的应用 / 深度休眠的应用」名单里。
2. 更稳妥的做法是把 Key Mapper 加进「未监控的应用」（Never sleeping apps）白名单。
3. 应用详情 → 电池 → 选「未优化」。

## 七、做完还是失效

- 用第三方资料站对照查漏：[dontkillmyapp.com](https://dontkillmyapp.com/)（Urbandroid 维护，专门收录各品牌后台限制与解法，按机型搜）。
- 把排查顺序过一遍：无障碍是否还开着 → 是否被暂停 → 约束是否满足，见 [常见问题与解决方法.md](常见问题与解决方法.md) 第一节。
- 无障碍与电池优化的基础两步如果还没做，先回 [无障碍服务与电池优化设置.md](无障碍服务与电池优化设置.md) 补课。
