## 一、为什么必须开无障碍服务

Key Mapper 的工作方式是「监听你按下的按键，拦下来，再换成你设置的动作」。在安卓上，监听和拦截按键事件靠的是系统的无障碍（辅助功能）服务——没开它，你创建的任何映射都不会生效。

顺带说明你会关心的一点：按官方的说明，这个无障碍服务不联网、不上传用户数据；你随时可以在系统设置里把它关掉。

## 二、开启无障碍服务的步骤

1. 打开 Key Mapper，主界面顶部会有一条「辅助功能服务」提示，后面跟着一个**修复（Fix）**按钮，点它。
2. 系统会跳到无障碍设置页。不同品牌叫法不同：有的叫「无障碍」，有的叫「辅助功能」，通常在「设置 → 更多设置」或「设置 → 辅助功能」下。
3. 在「已下载的应用 / 已安装的服务」列表里找到 Key Mapper，进入并允许。
4. 回到 Key Mapper 主界面，那条提示应该已经消失或变成已启用状态。

两个常见情况：

- 点「修复」没反应：直接手动走第 2、3 步，效果一样。
- 部分机型（如某些三星设备）会提示开启无障碍服务会关闭「增强数据加密」：这是系统层面的取舍，由你自己决定是否继续。

## 三、电池优化：映射失效的头号原因

无障碍服务开好了，映射还是「用一阵子就失灵」，多半是系统的省电机制把 Key Mapper 的后台服务杀了。官方在主界面专门放了一条「电池优化」提示，就是为了这个。

操作步骤：

1. 在 Key Mapper 主界面找到「电池优化（Battery optimization）」提示，点旁边的**修复**按钮。
2. 系统会打开电池优化的应用列表，把 Key Mapper 切换成「不优化 / 不允许优化 / 全部允许」（不同品牌的表述不同，意思都是让它不受省电限制）。

建议手动去系统设置里再确认一遍。这几类设备尤其要做：

| 设备情况 | 原因 |
| --- | --- |
| 华为、小米等国产 ROM | 后台查杀激进，不设白名单基本必失效 |
| 内存 2GB 及以下的设备 | 系统内存压力大时会优先回收后台服务 |
| 打游戏时用映射 | 游戏模式会额外限制后台应用 |

华为、小米这类机型除了电池优化，往往还要在「自启动管理」里允许 Key Mapper 自启，并在最近任务界面把它锁定，三样都做齐才算稳。

还有一个小米机型上的连带现象值得知道：MIUI 把应用杀掉时，会**连无障碍授权一起收走**，重新开启还得等一个 10 秒倒计时确认——如果你发现「无障碍隔一阵就自动关了」，根子还是后台被清。各家系统的完整设置清单见 [国产手机映射失效怎么办.md](国产手机映射失效怎么办.md)。

## 四、其他权限按需开

Key Mapper 不要求你一次性给全所有权限，用到对应动作时它才会提示你补。常见几项：

| 权限 | 用在哪 |
| --- | --- |
| 无障碍服务 | 必开，所有映射的前提 |
| 电池优化白名单 | 强烈建议，防止后台被杀 |
| 设备管理员 | 锁屏 / 关闭屏幕类动作 |
| 修改系统设置 | 调亮度、切横竖屏类动作 |
| 相机 | 手电筒类动作 |
| 勿扰模式访问 | 切换勿扰（Android 6.0 以上） |

拿不准就先不开：点了某个动作没反应，Key Mapper 会明确告诉你缺哪个权限，再补也来得及。

## 五、设置完之后

两处设置做完，你就可以正式建映射了，从 [创建第一个按键映射.md](创建第一个按键映射.md) 开始最顺。如果之后还是出现映射随机失灵、重启后全部失效，把 [常见问题与解决方法.md](常见问题与解决方法.md) 里的排查清单过一遍。
