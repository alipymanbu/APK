## 一、多键组合：并列与序列

一条映射的触发器不限于单个按键。在同一条映射里继续录制（或添加）按键时，你可以选两种组合方式：

| 组合方式 | 怎么触发 | 典型用法 |
| --- | --- | --- |
| **并列（同一时间）** | 几个键同时按住 | 音量上 + 音量下一起按 → 截屏 |
| **序列（先后按）** | 按顺序依次按键 | 先按 Ctrl 再按 H → 回到桌面 |

几点实操上的提醒：

- 并列组合就是几个键**同时按住**，按下顺序无所谓。
- 序列组合**顺序就是你录制的顺序**，录制时按什么顺序按，之后就得按什么顺序触发。
- 组合键里的按键在映射生效后就归这条映射管，触发时不再执行原功能。想让组合键日常不受干扰，可以把组合设计得冷门一点（比如两个音量键一起按），或用约束条件限定生效场景。
- 不同设备的按键可以混在一起组合，比如蓝牙键盘的 Ctrl + 耳机线控键，外设用户的常用玩法。

## 二、触发方式与判定时长

每条映射可以指定按键的按法，判定参数都能调：

- **短按 / 长按 / 双击**：同一条触发器可以同时配置多种按法，各自绑不同动作。
- **长按判定时长**：按住超过设定时长才算长按，时长可在触发器选项里改。
- **双击判定时长**：两次按键的间隔上限，同样可调。设太短会经常「双击了但没触发」，宁长勿短。
- **重复触发**：适合连点场景，按住不放就持续触发，直到松手。
- **触发时震动**：映射成功触发时给一下震动反馈。戴耳机或看屏幕不方便时很实用，也方便确认「刚才那一下到底触发没触发」。

## 三、约束条件：让映射只在特定场景生效

约束（Constraint）决定这条映射**什么时候算数**。不加约束的映射任何界面下都生效；加了约束，就只在满足条件的场景下生效。

常用的约束条件：

| 约束 | 效果 |
| --- | --- |
| 前台应用 | 只在指定应用打开时生效（比如只在看视频的 App 里把音量键改成快进快退） |
| 媒体播放中 | 正在放音乐/视频时才生效 |
| 屏幕方向 | 仅横屏或仅竖屏时生效 |
| 屏幕状态 | 仅亮屏或仅息屏时生效（3.1.1 息屏后映射不会触发，息屏一侧暂无用武之地） |
| 时间段 | 在指定的时间区间内生效（3.1.1 新增的能力） |

选多个约束时可以设定它们之间是「全部满足」还是「任一满足」。

一个实用组合示例：给「蓝牙键盘 B 键 → 打开 B 站」这条映射加上「前台应用 = 浏览器」的约束——在浏览器里按 B 直达 B 站，在其他任何应用里 B 键照常输入字母，互不打架。

## 四、指纹手势

在支持的机型上，指纹传感器的一部分手势也能当触发器用，比如往某个方向滑动。不是所有机型都支持，能不能用直接实测：新建映射时点录制触发器，然后在指纹传感器上做手势，能识别出来就说明支持。支持机型清单也可以查官方文档站 [keymapper.app](https://keymapper.app/)。

## 五、组合建议

配置复杂了之后容易「自己都忘了哪条映射在哪生效」，给你三条经验：

1. 优先用**约束条件**收窄生效范围，而不是到处堆组合键——限定场景比限定按键更不容易误触。
2. 同一个按键想派多种用场时，用短按/长按/双击分层，并给每一层加约束条件收窄场景。
3. 映射数量上来之后，给每条映射写清楚备注名，换机前记得用应用内的备份功能导出（见 [常见问题与解决方法.md](常见问题与解决方法.md)）。

想查「某类动作具体怎么配」，去 [常用动作清单与用法.md](常用动作清单与用法.md) 对照着找。
