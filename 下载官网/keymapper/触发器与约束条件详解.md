## 一、多键组合：并列与序列

一条映射的触发器不限于单个按键。多键触发器有两种模式：

| 模式 | 怎么触发 | 注意点 |
| --- | --- | --- |
| 并列（同时按） | 所有键同时处于按住状态 | **按下的顺序要按界面列表从上到下**：列表里写的是「音量上 + 音量下」，就得先按音量上再按音量下。长按某个键可以拖动调序 |
| 序列（依次按） | 各键按顺序「按下—松开」，整串限时完成 | 每个键还能各自指定短按/长按/双击 |

两个模式各有一条硬性限制要知道：

- **并列触发器只支持短按和长按**，不能给并列组合配双击；序列触发器里每个键的按法反而可以单独设。
- **序列有超时**，默认 1000 毫秒：一串按键要在 1 秒内按完才触发。手速慢或者组合长，就在这条映射的选项里把「序列触发超时」调大。

## 二、按键级选项：保留原功能与指定设备

- **不重映射（Do not remap）**：默认关闭。给触发器里的某个键打开它，这个键在执行映射动作的同时**照常执行原功能**——比如音量下键既开手电筒、又照常减音量。想让某个组合键日常无感，靠这个选项就够了，不用为「怕影响原功能」放弃组合。
- **指定设备**：每个按键默认绑定「本机」，也就是装了 Key Mapper 的这台设备自己发出的按键。外接设备（蓝牙键盘、手柄等）要先连上才会出现在设备列表里。家里有两个同名蓝牙键盘时，在应用设置里打开「显示设备 ID 前 5 位」再绑定，就不会串到另一台上。

## 三、触发方式与判定时长

三种按法的判定参数都有默认值，改的地方有两处：全局（应用设置）管所有映射，单条映射的选项页只管自己。

- **短按**：按下即触发，不用等松开。
- **长按**：按住超过设定时长才触发，**默认 500 毫秒**。觉得太灵（稍碰就触发）或太钝，改「长按延迟」。
- **双击**：两次按键的间隔小于设定值才算，**默认 300 毫秒**。设太短会经常「明明双击了却没反应」，宁长勿短。
- **触发反馈**：触发时可以震一下（时长可调），也可以在屏幕底部弹一条提示消息。调试期建议先开着，用来确认每条映射「真的触发了」，用稳了再关。

## 四、约束条件：让映射只在特定场景生效

约束（Constraint）决定这条映射**什么时候算数**。不加约束任何界面下都生效；加了就只在满足条件的场景生效。3.1.1 里可用的约束如下：

| 约束 | 生效条件 | 典型用法 |
| --- | --- | --- |
| 前台应用 / 非前台应用 | 指定应用（不）在当前屏幕 | 只在某款应用里改按键行为 |
| 正在播放媒体 / 没有播放 | 任意应用（不）在放音视频 | 播放时把音量键改成切歌 |
| 指定应用正在播放媒体 | 指定应用在放音视频 | 区分「视频 App 在放」和「音乐 App 在放」 |
| 蓝牙设备已连接 / 已断开 | 指定蓝牙设备（不）在线 | 连上车机后启用某组映射 |
| 屏幕方向 | 指定横屏或竖屏 | 横屏看视频时才生效 |
| 手电筒开 / 关（Android 6.0+） | 手电筒（不）亮着 | 按键联动手电筒状态 |
| Wi-Fi 开 / 关 / 已连接 | Wi-Fi 状态匹配 | 在家 Wi-Fi 下才启用某映射 |
| 输入法是 / 不是指定输入法 | 当前输入法匹配 | 只在外接键盘输入法下生效 |
| 设备已锁定 / 未锁定（Android 5.1+） | 锁屏状态匹配 | 注意屏幕得亮着——息屏时本来就检测不到按键 |
| 通话中 / 不在通话 / 来电响铃 | 通话状态匹配 | 来电时线控键改成接听 |
| 正在充电 / 未充电 | 充电状态匹配 | 车载充电时启用导航映射 |
| 屏幕亮 / 灭 | 亮灭屏状态匹配 | **需要 root**，见下 |
| 时间段 | 在指定时间区间内 | 3.1.1 新增；夜里自动换一组按键习惯 |

两个提醒：

- **「屏幕亮/灭」约束需要 root**。免 root 时息屏后根本检测不到按键，这条约束免 root 基本用不上（详见 [常见问题与解决方法.md](常见问题与解决方法.md) 第三节）。
- **约束超过两个时可选 AND / OR 模式**：AND 是全部满足才触发，OR 是满足任意一个就触发。多个「前台应用」约束用 OR 连起来，就是「这几个应用里都生效」。

一个实用组合示例：给「蓝牙键盘 B 键 → 打开 B 站」加上「前台应用 = 浏览器」的约束——在浏览器里按 B 直达 B 站，在其他应用里 B 键照常输入字母，互不打架。

## 五、从外部触发一条映射

每条映射在「选项 / 约束与更多」里还有一组特殊开关，其中一个扩展性很强：**允许其他应用触发这条映射**（2.3.0 起提供）。打开后：

- 可以给这条映射**生成桌面快捷方式**——点图标等于按一次这个组合键，不用真去按键；
- 也可以通过 Intent 触发（action 为 `io.github.sds100.keymapper.ACTION_TRIGGER_KEYMAP_BY_UID`，附带该映射的 UID），Tasker、Automate 这类自动化应用都能直接调用。

换句话说，一条「组合键」不只是物理按键的替身，还能被任何自动化工具当成一个可调用的遥控接口。

## 六、组合建议

配置复杂了之后容易「自己都忘了哪条映射在哪生效」，给你四条经验：

1. 优先用**约束条件**收窄生效范围，而不是到处堆组合键——限定场景比限定按键更不容易误触。
2. 同一个按键想派多种用场时，用短按/长按/双击分层，需要保留原功能的按键打开「不重映射」。
3. 调试期把「触发震动/屏幕提示」打开，跑稳了再关，排查问题时先怀疑约束没满足，再怀疑服务被杀（见 [常见问题与解决方法.md](常见问题与解决方法.md)）。
4. 映射数量上来之后给每条写清楚备注名，换机前用应用内的备份功能导出（见 [常见问题与解决方法.md](常见问题与解决方法.md) 第五节）。

想查「某类动作具体怎么配」和动作的重复/按住等编排参数，去 [常用动作清单与用法.md](常用动作清单与用法.md) 对照着找。
