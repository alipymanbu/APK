## 一、这是个什么应用

SharePoint 安卓版是微软出的手机客户端，用来在手机上看公司的内网站点：读组织的新闻、翻文档库里文件、找同事和链接。它不是独立的网盘，登进去看到的内容全部来自你单位那套 SharePoint 站点。

拿安装包前先确认一件事：**你得有一个能用的账号**。手机客户端只是个壳，没有组织的 Microsoft 365 账号（工作或学校账号），装上也进不去。Microsoft 365 个人版和家庭版订阅里不带 SharePoint。

## 二、安装包信息（本地实测那份）

网盘里这一份是采集好的成品包，装之前可以先核对这几个值：

| 项目 | 值 |
| --- | --- |
| 版本 | 4.00.00 |
| 包名 | `com.microsoft.sharepoint` |
| 大小 | 32.85M |
| MD5 | `ba565cc27622e8c186f14defe61ff721` |

这份包的文件名是 `SharePoint_v4.00.00.apk`，获取入口见下面第四节。MD5 跟上面这串对不上，说明传输中文件变了，别装，重新拿一份。

包名 `com.microsoft.sharepoint` 是判断「装的是不是它」的最硬依据 —— 装完在系统「应用信息」里能看到同一个包名，就是对的。

## 三、手机要满足什么

- **系统版本**：Android 4.4（KitKat）及以上。这是微软给这个客户端标的老下限，现在市面上的手机基本都过线。
- **设备形态**：手机和平板都兼容，横竖屏都能用。
- **网络**：登录和浏览都要联网，且要能连到微软的登录服务。公司如果限制了网络，可能只在公司网络内才连得上自己的 SharePoint 服务器。

版本号会随官方更新变化，上面这条系统要求以微软官方支持页当时显示为准。

## 四、两条获取路径

**路径一：应用商店（官方常规渠道）**

Google Play 商店里搜 SharePoint，或直接打开 `https://play.google.com/store/apps/details?id=com.microsoft.sharepoint`。商店装的好处是以后自动更新，不用担心版本落后。

**路径二：APK 直接装（商店打不开时）**

1. 从 [SharePoint 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6d691e575fb7) 把 `SharePoint_v4.00.00.apk` 下载到手机。
2. 下完先核对大小 32.85M、MD5 `ba565cc27622e8c186f14defe61ff721`。
3. 点这个文件，系统会弹「禁止安装来自此来源的应用」—— 这是安卓对 APK 的默认拦截。你信任这个包的来源，就在弹窗里进「设置」，对当前这个应用（浏览器或文件管理器）打开「允许安装未知应用」，再返回继续装。
4. 装完打开，系统「应用信息」里确认包名是 `com.microsoft.sharepoint`。

两条路径拿到的是同一个应用，区别只在更新：商店版自动更新，APK 版要等下一次手动换包。

## 五、第一次打开会发生什么

1. 启动后先弹账号添加页，它要你登进 Microsoft 365。
2. 输入工作或学校账号的邮箱，跟着页面走完密码、可能的二次验证。
3. 登进去就是「查找」标签页，能看到你有权限的站点和最近文件。

登录这一步是整个应用最容易卡住的地方 —— 选错账号类型、组织开了条件访问策略，都会让你停在半路。换到 [登录不了怎么办.md](登录不了怎么办.md) 里逐条对。

## 六、装完建议顺手确认的三件事

- **通知权限**：系统设置里给它放开通知，组织的共享提醒才推得过来。
- **别急着删手机里的原图**：往站点上传文件后，先回文档库确认文件真的出现了，再考虑清理本地（详见 [手机上传照片和文件.md](手机上传照片和文件.md)）。
- **记住自己单位的站点地址**：形如 `https://单位名.sharepoint.com/sites/站点名`，登不进去时用浏览器直接开这个地址，是最快的分辨手段（见 [常见问题排查.md](常见问题排查.md)）。
