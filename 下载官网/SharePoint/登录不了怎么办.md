## 一、先分清你要登的是哪一种

登录页给你的不是一个入口，是两条完全不同的路。选错那条，后面输什么账号都白搭。

| 你的组织情况 | 该选 | 登录时你要提供什么 |
| --- | --- | --- |
| 用 Microsoft 365（企业版、教育版、政府版） | **SharePoint** | 工作或学校账号的邮箱 + 密码 |
| 自建服务器：SharePoint Server 2019 / 2016 / 2013 | **SharePoint 服务器** | 服务器的网址（URL），形如 `http://portal` |

分辨办法：问同事或管理员「我们是 Microsoft 365 还是自己架的服务器」；或者在电脑浏览器里打开 `http://office.com`，左上角应用启动器里能看到「Microsoft 365」字样的，走第一条路。

**Microsoft 365 个人版和家庭版订阅不包含 SharePoint。** 用个人微软账号（`outlook.com` / `hotmail.com` 那种）在登录页反复试，是登不进去的 —— 不是密码错，是这个账号类型根本不对应。

## 二、正常登录的完整过程

1. 打开应用，停在「添加账户」页。
2. 输入工作或学校账号的邮箱地址。
3. 页面会跳到你组织自己的登录页（地址栏域名通常是 `login.microsoftonline.com` 或组织自定义域名），在那里输密码。
4. 有二次验证（短信、Authenticator 推送、验证码）就照做。
5. 回到应用，进入「查找」标签页。

**注意第 3 步会「跳出应用」再跳回来** —— 中途那个网页登录页是正常的，不是被劫持。别在它出现时直接按返回。

## 三、几个典型卡点

### 卡在「正在带你前往组织的登录页」或白屏

浏览器里能登 `portal.office.com`、应用里就是白屏，这个组合基本指向组织侧的策略而不是你的操作：

- 组织可能开了**条件访问 / 要求受批准的客户端应用**，手机应用与浏览器被区别对待（见 [常见问题排查.md](常见问题排查.md) 的同类条目）。
- 手机系统的 WebView 组件过旧，嵌入式登录页渲染不出来。

先自己排除两件事：**用手机浏览器打开你单位的 SharePoint 网址能不能登**（能登 = 密码没问题，问题在应用侧策略）；**把系统 WebView 和这个应用都更到最新**再试。两条都做完还不行，就得找单位 IT，条件访问策略只有管理员能改。

### 提示「此 Microsoft 账号不存在」

输入的是个人账号，或者邮箱打错了。回到第二节确认账号类型。

### 登进去但站点一片空白

不是登录失败，是权限问题：你账号没被加进任何站点，或组织关掉了 Office Graph（关掉 Delve 会连带关掉个人维度的推荐内容）。让管理员把你加进目标站点，或确认组织是否禁用了相关功能。

### 本地部署连不上

SharePoint Server 那条路只支持 Windows 身份验证（NTLM）和表单身份验证；ADFS、Kerberos、基本身份验证、自签名证书、同一区域多种认证混用，官方明确**不支持**。组织用了这些方式的话，手机应用就是登不上，只能走浏览器（浏览器能不能进也取决于组织配置）。

另外，组织可能限制 SharePoint 服务器只在公司网络内可访问 —— 在家、用流量时连不上属于预期。

## 四、总是被要求重新验证

今天登明天又让输密码、验证推送一天来好几拨 —— 先分清是哪一种：

- **会话到期是设计如此**：组织侧的「登录频率」默认是 90 天的滚动窗口，正常情况下不该天天要密码。频繁出现，多半是组织把这个窗口调短了，或对特定条件（外部网络、非受管设备）单独设了策略。这类策略只在组织层配置，你改不了。
- **验证请求不是你发起的，一律别批**：你自己没在登录却收到验证推送，有两种可能 —— 有某个旧设备 / 邮件客户端拿着旧密码在死循环重试；或者有人在拿你的账号撞密码（所谓「MFA 疲劳轰炸」）。后者的应对就一条：**不批准**，然后去 `mysignins.microsoft.com`（工作或学校账号）查看最近登录记录，有陌生条目就改密码、移除不认识的验证方法，并把情况报给单位管理员查日志。
- **自己这边能做的**：确认手机时间是自动的、验证应用是最新版且通知不静音 —— 验证推送没弹出来导致超时，应用会自动重试，表现出来就是「怎么又问我一遍」。

## 五、多账号与退出

应用支持添加账户。需要换账号时从头像 / 账户入口进，选添加账户或退出当前账户，再走一遍第二节的流程。同一个组织的工作账号在移动端的可叠加数量以应用内实际表现为准 —— 撞到限制时，最稳的办法是退出当前账号再登另一个。

登不进去时别急着重装应用 —— 先用浏览器验证账号本身能不能进（步骤见第三节第一条），再决定问题出在哪一侧。
