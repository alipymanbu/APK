# 手机上传照片和文件到 SharePoint 站点

## 一、先确认你有上传权限

文档库认的是权限，不是登录成功。你能在手机上「看到」某个文件夹，不代表能往里传东西：读取权限和贡献权限是两回事。

判断方法很直接 —— 进到目标文件库，看有没有「添加 / 上传」入口。没有入口就是权限不够，找站点所有者给你加，客户端这边没有绕过去的办法。

## 二、路径 A：从站点内容进文档库（最通用）

这条不依赖站点首页怎么搭，只要你的账号能看到「站点内容」：

1. 在应用里打开目标站点。
2. 打开站点的导航菜单（左上角的菜单入口），找到**站点内容**。
3. 在内容列表里点开要传进的那个文档库。
4. 库打开后点 **+** → **上传** → **选择文件**。
5. 在系统文件选择器里勾选照片或文件，确认。

选完之后**回到文档库列表刷新一下，确认文件真的出现了**，再考虑删手机相册里的原图。上传中断不会给你补偿机制，凭「我点过了」判断会丢图。

## 三、路径 B：从页面上的文档库部件进（传得更快）

如果站点首页放了「文档库」网页部件（管理员或站点所有者配的），你少走两层菜单：

1. 打开那个页面。
2. 在文档库部件里，点库名旁边的**三点**。
3. **上传** → **选择文件** → 挑照片。

这条路径对手机上高频传图的场景（巡检、现场记录）更顺手 —— 不用每次翻站点菜单。页面上没这个部件的话就走路径 A；你是站点所有者、想给团队铺好这条路，可以在网页版编辑页面加「文档库」部件后发布。

## 四、路径 C：浏览器兜底

应用里找不到入口、或某个库在应用里打开就是空的，用手机浏览器直接开站点网址（形如 `https://单位名.sharepoint.com/sites/站点名`），登录后在浏览器里传。浏览器的文件选择器与相册打通得更稳，缺点是小屏幕上点选麻烦。

上传类操作卡住时的取舍顺序：**路径 A/B 先试，不行换浏览器**（[常见问题排查.md](常见问题排查.md) 里列了哪些场景该直接换浏览器）。

## 五、往 SharePoint 传 vs 往个人 OneDrive 传

这两个是不同的目的地，别混：

| | 传到 SharePoint 站点 | 传到个人 OneDrive |
| --- | --- | --- |
| 落在哪 | 组织的站点文档库，站点成员都能看到 | 你个人的工作文件区 |
| 用哪个应用 | SharePoint 客户端 | OneDrive 客户端 |
| 典型场景 | 交巡检照片、共享给团队的资料 | 自己暂存、给自己备份 |

想把照片「清出手机」又暂时不知道给谁，先传个人 OneDrive 再从电脑挪到站点，也是一种常见流程 —— 但最终要给团队看的东西，还是得落到 SharePoint 文档库里。

## 六、几个容易踩的点

- **Forms 表单里的「上传图片」字段在安卓应用里会失败**（表单直接退出、图片传不上去）。这是应用侧的已知限制，不是你的操作问题 —— 换浏览器打开该页面再填（见 [常见问题排查.md](常见问题排查.md)）。
- **一次别攒太多**：手机端大批量传图容易中途断，分批传、每批确认。
- **传完核对文件名和大小**，尤其是从微信、下载目录中转过的文件，可能被改名或压缩。
- 想在手机上改站点里的文档，走 Office 类应用打开再存回；离线状态下的改动会存成新文件，不覆盖原文件（这条以你设备上的实际表现为准）。
