## 一、排查顺序：先分清是哪一层

按这个顺序走，能省掉大量无用功：

1. **浏览器能不能进** —— 手机浏览器打开你单位的 SharePoint 网址（形如 `https://单位名.sharepoint.com`）。能进 = 账号与权限没问题，问题在应用侧；不能进 = 账号/密码/权限问题，先别折腾应用。
2. **应用是不是最新** —— 商店更新或换新包（见 [下载与安装教程.md](下载与安装教程.md)）。旧版本对不上组织的安全策略是常见原因。
3. **是不是这个功能本来就不支持** —— 见下面第三节的清单，别为「本来就没有」的功能耗时间。

## 二、症状对照表

| 症状 | 多半是什么 | 怎么办 |
| --- | --- | --- |
| 白屏、卡在「正在带你前往组织的登录页」 | 组织的条件访问 / 客户端应用限制，或 WebView 过旧 | 浏览器先验证密码；更新 WebView 与应用；仍不行找 IT（详见 [登录不了怎么办.md](登录不了怎么办.md)） |
| 提示「此 Microsoft 账号不存在」 | 用了个人微软账号 | 换成工作或学校账号 |
| 登进去站点一片空 | 没被加进任何站点，或组织关了 Office Graph | 找管理员加权限 |
| Forms 表单一点就退回上一页、传图失败 | Forms 网页部件在移动应用里不支持 | 用手机浏览器打开该页面填写 |
| 找不到改权限的入口 | 应用不提供细粒度权限管理 | 手机浏览器开站点 → 菜单里请求「桌面版网站」→ 在桌面界面里改管理访问 |
| 站点/文件搜不到 | 没权限，或内容不在搜索索引里 | 先确认自己在网页版里能不能看到；能看就换关键词再搜 |
| 老教程里的「热门文件」「最近文件」区找不到 | 官方已移除这几个入口 | 改用搜索栏、稍后保存、我标签页 |
| 传完图手机相册删了、站点里没有 | 上传中断或传错了库 | 先刷新文档库确认，再删本地；操作见 [手机上传照片和文件.md](手机上传照片和文件.md) |
| 自建服务器地址登不上 | 用了 ADFS / Kerberos / 基本认证 / 自签名证书等不支持的方式，或不在公司网络 | 见 [登录不了怎么办.md](登录不了怎么办.md) 的「本地部署连不上」 |
| 一条站点动态都不推送 | 权限/电池限制挡了推送、没关注站点、组织关了通知、或该环境本就不支持 | 按层自查，见 [通知收不到怎么排查.md](通知收不到怎么排查.md) |
| 一天多次被要求输密码/验证 | 组织缩短了登录频率，或有验证请求不是你发起的 | 见 [登录不了怎么办.md](登录不了怎么办.md) 第四节 |
| 文件打开是只读、改不了 | 没从三点菜单进编辑、库要求签出、只有读权限、站点被设只读 | 逐条排，见 [手机上怎么编辑文档和处理离线改动.md](手机上怎么编辑文档和处理离线改动.md) |
| 离线改完的文件别人看不到 | 改完没传回文档库 | 回库刷新核对，见 [手机上怎么编辑文档和处理离线改动.md](手机上怎么编辑文档和处理离线改动.md) |

## 三、应用里「本来就不提供」的功能

这些不是故障，换浏览器或电脑才是正解：

- **Forms 网页部件**：官方说明该部件在 SharePoint 移动应用中不可用。表单里带图片上传的场景，在安卓应用里尤其容易失败。
- **细粒度权限管理**：给某个人/某组改读写权限，要去网页版（手机浏览器 + 桌面版视图可用）。
- **全局浏览菜单**：移动应用不提供网页版站点顶部的全局导航。
- **创建与管理站点**：应用是消费端，建站、改布局、配网页部件这些管理动作在网页版做。

## 四、网络与设备侧的自查

- **公司网络才通**：组织可能限制 SharePoint 服务器只在内网可访问，换了网络连不上属于预期。
- **通知没来**：别只查手机这一层，从系统权限到组织总开关一共六层，逐层过一遍即可 —— 完整清单见 [通知收不到怎么排查.md](通知收不到怎么排查.md)。
- **老设备**：系统要求是 Android 4.4 及以上（以官方支持页当时显示为准），但系统太老时 WebView 无法渲染登录页，会表现成白屏 —— 这种情况升级系统或换浏览器登录。

## 五、还解决不了时找谁

- 组织内部的问题（策略、权限、站点配置）：**单位 IT / SharePoint 管理员**，管理员可在 Microsoft 365 管理中心提支持单。
- 应用本身的疑问：微软官方的 **SharePoint Android 社区**（`answers.microsoft.com` 上的对应版块）可以提问。
- 找社区前先把三件事说清：手机型号与系统版本、应用版本（见 [下载与安装教程.md](下载与安装教程.md) 的安装包信息）、浏览器里能不能正常打开同一站点。
