# Sketchar 常见问题与故障排除

> 本篇按现象归拢 Sketchar 最容易卡住的几类问题：AR 黑屏、线稿对不上纸、墙面模式没反应、装不上、账号同步。前提性的安装问题回 [下载与安装教程.md](下载与安装教程.md)，AR 模式的正确姿势见 [AR描摹怎么用.md](AR描摹怎么用.md)。

## 一、进 AR 模式黑屏、卡住退不出来

这个现象在 App Store 评论里 2021 年就有用户集中反馈过（黑屏且退不出去）。按顺序排查：

1. 确认已给应用**相机权限**（系统设置 → 应用 → Sketchar → 权限）。
2. 看环境光线是否太暗——AR 追踪在暗处基本罢工。
3. 完全退出应用再重开（从最近任务里划掉再进）。
4. 换个表面试：纯白反光的桌面、花哨的桌面图案都会让识别失败，先铺一张普通 A4 纸。
5. 还不行就升级到当前渠道的最新版本再试。

## 二、线稿对不上纸、描着描着漂移

| 现象 | 原因与处理 |
| --- | --- |
| 线稿跟着手机晃、钉不住 | 光线不足或纸面纹理太弱；把纸用夹板固定，挪到亮处 |
| 描到一半整体错位 | 纸被碰动了；重新对准定位再继续 |
| 十字标记识别失败 | 十字铺歪了或出了相机视野；铺正、放回视野中央 |
| 凑近看细节就丢追踪 | 正常现象，退回工作距离再描 |

一句话总结：追踪吃的是「亮、平、稳」，三项里任何一项不满足都会漂。

## 三、墙面模式（Wall View）用不了

墙面模式**要求手机支持 ARCore**，不支持的手机只保证 A4/A5 纸面描摹可用——这不是故障，是设备能力的分界线。先到 ARCore 支持列表 `https://developers.google.com/ar/devices` 确认机型；确认支持还用不了，检查「Google Play 服务（AR）」组件是否已安装、是否被禁用。

想在墙面上起大稿但没有 ARCore 手机，官方的另一条路是 VR 头显版（Meta Quest 3 / Pico 4 Ultra），那是独立硬件方案，与手机配置无关。

## 四、安装包点不开、装到一半失败

按出现顺序查：

1. **下载不完整**：重新下载一遍；能连电脑的先做 MD5 校验（这份包应为 `FDE13D83158E3E0886841D07A3D2487A`），校验命令见 [下载与安装教程.md](下载与安装教程.md) 第二节。
2. **存储不足**：清出比 180.48 MB 更多的空间再装。
3. **未知来源被拒**：安装被系统拦下时，去设置里允许对应来源，具体步骤见 [下载与安装教程.md](下载与安装教程.md) 第三节。
4. **与已装版本冲突**：手机里已有一个 Sketchar 时，包名相同会走覆盖安装（数据一般保留）；若提示签名冲突，需要先卸载旧的再装。

需要重新拿一份完整的包：[Sketchar 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5225386f553b)。

## 五、点功能就弹订阅提示

这不是故障。免费版与订阅版的边界是：内置模板、分步课程、基础画布免费；**用自己的照片当描摹底图、PRO 工具与进阶内容要订阅**（官方 FAQ 口径，完整对照见 [会员订阅与免费区别.md](会员订阅与免费区别.md)）。订阅弹窗出现得频繁是用户评论里抱怨较多的一点，但它不影响免费部分的正常使用——关掉弹窗继续用免费功能即可。

## 六、换手机后作品和进度不见了

作品与课程进度跟账号走，跨设备同步需要你**在新手机上登录同一个账号**。登录后还缺东西，先检查两端是不是登的同一个账号——邮箱登录与第三方登录会被当成两个账号。官方称订阅跨平台通用，但安卓与 iOS 的商店账号互不相通，跨系统的订阅问题直接发邮件问官方（`support@sketchar.io`，Google Play 页面给出的联系方式）。

账号不用了可以在应用或官网里删除，官方条款写明删除会连带清掉用户内容——换号前先把要留的作品导出。

## 七、界面不是中文怎么办

App Store 中国区上架的版本支持中文。若你装的是其他渠道包且默认英文，进应用内设置找「Language」选项切换；找不到语言选项，说明这个版本不带中文界面，换含中文的版本即可。

课程解锁、订阅扣费、画布操作这三类问题不在本篇展开，分别见 [绘画课程与数字画布.md](绘画课程与数字画布.md) 与 [会员订阅与免费区别.md](会员订阅与免费区别.md)。
