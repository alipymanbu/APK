## 一、免费版的规则

你在 Google Play 装到的免费版（包名 `com.safeincloud.free`）规则很简单：

1. 安装后 **14 天内所有功能开放**，包括付费功能，让你先体验完整再决定。
2. 14 天后，下表里的付费功能锁定；已存的密码仍然能看、能手动复制，不会把你锁在门外。
3. 想解锁就在应用内点「Go PRO」**一次性付费买断**——官方在应用描述里明确写了「无订阅、无月费」。
4. 桌面版（Windows / mac）不参与这套收费，本身免费。

14 天试用从安装时开始算，不注册也能用满。

## 二、到期会锁的付费功能清单

下面这些是官方标出的付费（Pro）功能，到期后它们会被锁定：

| 功能 | 你会用到它的场景 |
| --- | --- |
| 云同步 | 多设备互通、换机恢复（见[云同步与多设备同步设置.md](云同步与多设备同步设置.md)） |
| 无限卡片 | 密码条目不设数量上限 |
| 卡片网站图标 | 列表里显示各网站的favicon，翻起来更快 |
| 密码生成器 | 注册新账号时生成随机强密码 |
| 附件图片 | 往卡片里贴截图、证件照片 |
| 快速解锁 | 不输主密码、用指纹/面部直接进应用 |
| 指纹登录 | 同上，依赖设备指纹硬件 |
| 复制到通知栏 | 不切应用就能拿密码 |
| Chrome 自动填充 | 见[自动填充设置教程.md](自动填充设置教程.md) |
| 备份与恢复 | 手动导出数据库备份文件 |
| 剪贴板清理 | 复制的密码过一会儿自动清掉 |
| Android Wear 应用 | 手表上看卡片 PIN 码 |

如果你只是「存密码 + 偶尔查看」，免费版其实够用；一旦你要**云同步、生物解锁、自动填充**这三件里的任何一件，就得买——而这三件正是日常登录时用得最频繁的环节。

## 三、解锁方式与授权形式

截至 2026-09，官方的收费口径有两层，以[官网](https://www.safe-in-cloud.com/en/)当前页面为准：

- **安卓端应用内买断**：老规则，一次付费永久解锁，描述里写明无订阅无月费。
- **订阅 / 终身 / 家庭授权**：官网目前提供个人版订阅、终身授权（一次购买长期使用），以及覆盖 6 个家庭成员的家庭授权（价格约比个人版贵 30%）。官方知识库的文章里也出现了订阅计划（Subscription plans）的提法。

两种渠道买到的都是官方授权，区别在付款方式和覆盖范围。只想给一台手机用，应用内买断最直接；家里多人都用，家庭授权更划算。

## 四、换机与重装后怎么恢复授权

- **免费版应用内买断的**：重装后用同一个 Google 账号登录 Play，授权会跟着账号走；在应用内找「恢复购买」入口点一下即可。
- **付费 Pro 版**：官方支持 Google Play 的家庭共享（Family Sharing），家庭成员免费用你的已购项目——这一条只有付费 Pro 版支持，免费版应用内买断不在其列。
- **找不到恢复入口**：确认手机上登录的 Google 账号和付款时是同一个；还不行就发邮件给官方支持 `support@safe-in-cloud.com`，附上订单号。

## 五、你手上这份安装包是哪一版

本文顶部网盘里的 SafeInCloud 安装文件资源是 **24.9.8 版、包名 `com.safeincloud`**——与 Play 免费版是不同的包名，属于独立安装项。你把它装好后：

- 若这台设备访问不了 Play 商店，这份 APK 就是你最省事的起点，功能状态以应用内实际提示为准。
- 若之后换到 Play 版或升级官方最新版，数据库存在你自己的云里（先按[云同步与多设备同步设置.md](云同步与多设备同步设置.md)配好云），换包名迁移数据不丢。
