# SafeInCloud 云同步与多设备同步设置

> SafeInCloud 不把密码存在官方服务器上，而是加密后放进你自己的云盘账号。本篇讲支持哪些云、手机和电脑分别在哪开启、换新设备时怎么把数据接回来。

## 一、先弄清你的数据存在哪

SafeInCloud 的同步模型和很多密码管理器不一样：**数据库文件存在你自己的云账号里**，官方服务器上没有你的密码。你在手机上改一条记录，应用会把加密后的数据库推到你的云盘，其他设备再从同一朵云拉下来解密。

这带来两个实际后果：

- 你的云账号就是你的备份。手机丢进水里，数据还在云里；只要你记得主密码，任何新设备都能完整恢复。
- 云账号本身被盗也读不出密码——数据库是用你的主密码加密的，云服务商（和官方）拿到的都只是密文。代价是主密码忘不了：忘了没有任何找回渠道。

云同步属于付费功能（见[免费版与付费版区别.md](免费版与付费版区别.md)），免费试用期内你可以先配好再决定买不买。

## 二、支持哪些云

| 云服务 | 说明 |
| --- | --- |
| Google Drive | 安卓手机上最省事的一个，登录 Google 账号即可 |
| Dropbox | 各平台都能用 |
| OneDrive | Windows 用户顺手 |
| WebDAV（「其他云」） | 任何支持 WebDAV 协议的云都能接，包括 NAS（群晖等）、ownCloud、Yandex Disk |

选哪个的原则：**选你已经登录、其他设备也能访问的那个**。同步的载体是云账号，不是应用本身——所有设备必须指向同一朵云，数据才会互通。

## 三、手机端怎么开

以安卓为例，两条路任选：

- **横幅入口**：还没配过云同步时，主界面顶部会有一条横幅，点它跟着向导走。
- **菜单入口**：横幅被你划掉了也不影响，进 **工具 → 设置 → 数据库**，选主数据库，点 **配置云**，选云服务、登录账号，完成。

想用 NAS 或自建云就选列表里的「其他云」，填 WebDAV 地址和账号密码。各家 NAS 的 WebDAV 地址格式不同（群晖一般是 `https://你的地址:5006/` 这类），填之前先在 NAS 端把 WebDAV 服务打开。

配好后你就不用管它了——每一次改动会在几秒内自动推到云里，没有「手动保存」这一步。

## 四、电脑端怎么开

Windows 或 mac 版里，路径是：**选项 → 数据库 → 操作 → 配置云**，选与手机相同的云账号登录即可。

如果你是先在电脑上建的库（比如导入旧密码时，见[旧密码导入与迁移.md](旧密码导入与迁移.md)），配好云之后手机端再按第三节连同一朵云，两边就会合到同一个数据库上。

## 五、换新手机 / 新电脑怎么接

这是云同步最常见的用途，流程固定三步：

1. 新设备上安装应用（安装包见[下载与安装教程.md](下载与安装教程.md)）。
2. 首次启动时选「**连接已有的云数据库**」，登录同一朵云的同一账号。
3. 输入主密码，数据库完整落回新设备。

不需要导出导入文件，也不需要旧设备在场。这也是为什么装机教程里把「配云同步」列为装完第一件事——它是你唯一的灾备手段。

## 六、几个容易疑惑的点

- **两台设备同时改会怎样**：应用按改动时间同步，一般不需要你干预；如果你发现某台设备的数据不是最新，先确认它登录的是不是同一个云账号。
- **云盘里那个文件能删吗**：不能。那是加密的数据库本体，删了等于删备份。
- **换了云服务怎么办**：在新云上重新配置一次同步，再把旧云里的数据库文件迁移或让应用重建，具体以官方说明为准；动手前先把旧云里的数据完整保留。
- **同步要花钱吗**：同步本身不收费，走的是你自己的云盘流量；但云同步这个功能属于付费解锁范围。
