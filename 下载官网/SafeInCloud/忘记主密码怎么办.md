# SafeInCloud 忘记主密码怎么办

> 主密码不存储在任何地方——设备上没有，官方服务器上也没有，所以没有任何找回渠道。本篇按「你还能不能进应用」给出三条路，以及下次怎么避免走到这一步。

## 一、先接受一个前提

官方知识库写得很直白：主密码不存在任何备份，忘了就是忘了，找官方客服也恢复不了——这是数据库用主密码加密的直接后果，改不了。所以下面所有办法的目标都不是「找回密码」，而是「在彻底忘记之前抢救回数据」。

动手前先花几分钟把常用的密码和变体都试一遍：大小写差异、多打的空格、旧密码、不同键盘布局。这是成本最低的一步，不少人卡在这里就解开了。

另外有一类「假忘记」：如果你建过**附加数据库**（多数据库功能），它的密码会自动存成主数据库里的一张卡片——打开主数据库搜附加库的名字就能找到。丢了主库密码的才是真麻烦，继续往下看。

## 二、还能用指纹 / 面部进应用 → 直接改密码

这是最省事的一条路，前提是你**至少有一台设备**还开着生物解锁：

1. 在锁屏界面故意输错主密码 3 次，应用会让你改用生物识别登录。
2. 进去后到 **设置 → 数据库 → 主数据库 → 修改密码**，设一个新密码。
3. 立刻同步到云，让云端换成新密码版本。

其余设备还锁在旧密码上、同步不了，逐台处理：卸载应用 → 重新安装 → 首次启动选「从云恢复数据库」→ 用新密码进入。数据一点不丢。

如果你暂时进不了那台设备上的应用，也可以在任何一台设备上连输 3 次错误密码，选**删除本地数据库**，再从云恢复——前提是云端那份数据库的密码你是知道的。

## 三、刚改过密码、还记得旧的 → 用云的版本历史回滚

如果「忘了新密码、记得旧密码」，可以试试把云端数据库回滚到还用旧密码的那个版本：

1. 在浏览器里打开你的云盘，找到数据库文件 `SafeInCloud.db`（各云的具体位置见[云同步失败排查.md](云同步失败排查.md)第五节）。
2. 右键该文件 → **版本历史记录**（或「管理版本」）→ 下载一个改密码**之前**的版本。
3. 卸载应用再重装（电脑上最省事），随便用个临时密码新建一个空数据库。
4. 到 **选项 → 数据库 → 主数据库 → 恢复**，选中刚下载的文件。
5. 用旧密码登录试试；不行就再换更早的版本。

**两个大坑，先看再动手**：**iCloud 和 Google Drive 的应用文件夹不提供文件版本历史**，数据库存在这两处的走不了这条路；另外动手回滚前，先把当前云端数据留着别删，回滚失败还能退回来。

## 四、什么都不行 → 只能推倒重来

这是最后一步，**会永久清掉所有已存密码**，确认前几条路都走不通再做：

1. 从云盘里删掉数据库文件（位置见[云同步失败排查.md](云同步失败排查.md)第五节）。
2. 卸载应用、重新安装。
3. 新建数据库、设新密码。
4. 密码条目要么手动重录，要么从浏览器重新导入一次（步骤见[旧密码导入与迁移.md](旧密码导入与迁移.md)）。

## 五、下次别再走到这一步

这次的经历值三条预防措施：

- **把主密码写在纸上**，放家里固定的地方。密码管理器的安全前提是「你记得住」，纸质备份不联网、不进云端。
- **至少在一台设备上开生物解锁**。第二节那条路能不能走通，全看它——它是唯一不依赖你记忆的入口。
- **保持云同步开启**。数据只在本地、云上没有备份的话，忘了主密码连「删掉重来保住数据」的机会都没有。
