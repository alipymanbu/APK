# SafeInCloud 自动填充设置教程

> 装好 SafeInCloud 后，日常用得最顺手的是自动填充：登录 App 和网页时不用手动复制粘贴。本篇讲安卓两处开关、Chrome 的新机制、卡片不出现在建议里的排查，以及 iPhone 和电脑端的做法。

## 一、安卓要开两个开关，缺一不可

官方把安卓的自动填充分成两个独立设置，很多「填充不出来」的问题就是只开了一个：

**1. 应用内自动填充**（覆盖你手机上所有 App）

- 应用内路径：**工具 → 设置 → 自动填充 → 应用内**，按提示把 SafeInCloud 设为系统的填充服务。
- 系统路径（效果相同）：手机 **设置 → 密码、通行密钥和账号 → 首选服务**，选 SafeInCloud。

开好后，你在任何 App 里点到账号输入框，SafeInCloud 的建议就会从键盘上方弹出来。

**2. Chrome 自动填充**（Chrome 自己管理填充，要单独接）

- 应用内路径：**工具 → 设置 → 自动填充 → Chrome 内**，按步骤走。
- Chrome 侧：打开 Chrome **设置 → 自动填充服务**，选「**使用其他服务填充**」，然后重启 Chrome。要求 Chrome 131 或更新版本。
- 不生效时开实验开关：地址栏输入 `chrome://flags#enable-autofill-virtual-view-structure`，设为 Enabled，重启 Chrome 后重复上一步。

这两个开关在首次启动向导里都会引导你配，跳过了的话主界面顶部的横幅也能点回去。

## 二、卡片不出现在建议里的三个原因

自动填充建议按「卡片」为单位弹出。一条卡片要被建议，必须同时满足三个条件，缺一个就不出现：

| 条件 | 检查位置 |
| --- | --- |
| 卡片里有 **User name** 字段 | 打开卡片看字段名，字段名不对就手动改 |
| 卡片里有 **Password** 字段 | 同上 |
| 卡片里有 **Website** 字段（网址对得上） | 网址写错域名就不会匹配 |

另外确认卡片详情里的 **Use for Autofill** 开关是打开的。

还有一种情况：**同一个网站存了多个账号，填充时不弹选择框、直接填了其中一个**。这是因为缺了「显示在其他应用上层」（Appear on top）权限——选择框要靠它浮在浏览器上面。去手机 **设置 → 应用 → SafeInCloud → 高级 → 显示在其他应用上层** 打开（三星可能在「特殊权限」下）。只存了一个账号的网站不受影响，所以这个问题通常换机或重装后才会冒出来。

## 三、iPhone 上怎么开

路径和安卓完全不同：打开 iPhone **设置 → 通用 → AutoFill 与密码**，开启「自动填充密码」，并确认来源选的是 SafeInCloud。之后在任意 App 点账号输入框，键盘上方会出现一把钥匙图标，点它就能从 SafeInCloud 里取。

## 四、电脑浏览器扩展

电脑端自动填充靠浏览器扩展，Chrome、Firefox、Edge 各有一个，Safari 不用装（mac 版应用里已内置）：

1. 在扩展商店里装 SafeInCloud 扩展（入口见[下载与安装教程.md](下载与安装教程.md)的官网下载页）。
2. **保持桌面应用在后台运行**——扩展不独立存密码，它连着桌面应用取数据。系统托盘里没有 SafeInCloud 图标就先启动它。
3. 打开登录页，点浏览器工具栏上的 SafeInCloud 图标，选要填的账号。

扩展报「not running」之类的错，把桌面应用升级到较新版本（官方给出的是 Windows 25.3.0+、macOS 25.3.5+）再试。

## 五、Passkeys（通行密钥）的前提

官方知识库写明：Passkeys 支持从 **应用 25.0.0 版 + Android 14** 开始，并且要把 SafeInCloud 设为首选填充服务才会弹出。本文顶部网盘里的安装文件资源是 24.9.8 版（第一代应用），**不含 Passkeys 功能**——需要的话去 Play 升级到最新版（数据库不用迁，前提是先配好云同步，见[云同步与多设备同步设置.md](云同步与多设备同步设置.md)）。

## 六、还是不弹建议时的兜底

按顺序过一遍：

1. 重启一次应用；再不行重启手机。
2. 到 **设置 → 密码、通行密钥和账号** 把首选服务先设成「无」，再设回 SafeInCloud，然后重启应用。
3. 部分国产系统的省电策略会拦后台服务——在系统设置里把 SafeInCloud 移出电池优化（或允许后台运行）。
4. 有些 App 和网站自己不支持系统级自动填充，这要对方开发者适配，换手动复制即可，不是你的设置错了。
