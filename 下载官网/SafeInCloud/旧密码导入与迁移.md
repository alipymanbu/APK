# SafeInCloud 旧密码导入与迁移

> 从浏览器或旧密码管理器搬到 SafeInCloud，不用一条条手抄。本篇讲怎么把旧数据导出成 CSV、在哪一步导入 SafeInCloud、搬完之后怎么收尾。

## 一、先在旧工具里导出 CSV

通用做法是把旧密码导出成一个 CSV 文件，常见来源的导出入口：

| 旧工具 | 导出位置 |
| --- | --- |
| Chrome / Edge（电脑版） | 地址栏进密码管理器（`chrome://password-manager/settings`），找「导出密码」，验证电脑开机密码后存为 CSV |
| Firefox | 设置 → 隐私与安全 → 已保存的登录信息 → 导出登录信息 |
| LastPass | 网页保险库 → 高级选项 → 导出（会发确认邮件） |
| 1Password / Bitwarden / Dashlane / KeePass / Proton Pass | 各自的网页版或桌面版设置里有导出条目，选 CSV 格式 |

各家界面会随版本变化，找不到入口就以对应工具的官方帮助页为准。导出时要输入一次原工具的主密码或电脑密码，这是正常验证，不是异常。

## 二、在哪一步导入 SafeInCloud

官方推荐的导入主力是**桌面版**（Windows / mac，免费，获取方式见[下载与安装教程.md](下载与安装教程.md)）：

1. 电脑上装好并打开 SafeInCloud 桌面应用。
2. 用它的导入功能选择来源——官方说明桌面应用可以自动从其他密码管理器导入数据，支持的来源包括 Chrome、Edge、Firefox、LastPass、1Password、Bitwarden、Dashlane、KeePass、Proton Pass 等几十种（以应用内实际列表为准）。
3. 选中你刚导出的 CSV（或直接选来源应用），等导入完成。

为什么优先桌面版而不是手机：电脑上核对、改错、批量整理都方便，键盘改字段比手机快得多。导完再按[云同步与多设备同步设置.md](云同步与多设备同步设置.md)配上云，手机端就能直接拿到全部数据，不需要在手机上再导一次。

## 三、导入后核对三件事

1. **条数**：旧工具里的条目数和导入后的大致对得上（同名去重后可能略少）。
2. **抽查**：挑两三个不常用的账号，手动登录一次，确认账号密码没有在导出导入过程中变形（特殊字符、开头结尾的空格最容易出问题）。
3. **字段**：自动填充靠 User name / Password / Website 三个字段，见[自动填充设置教程.md](自动填充设置教程.md)——导入的条目如果 Website 是空的，填充不会弹，补上网址即可。

## 四、收尾：把 CSV 删干净

CSV 是**明文**文件——所有账号密码裸写在里面，谁拿到都能读。所以搬完家做三件事：

1. 立刻删除电脑里的 CSV，回收站也清掉。
2. 如果导出时用过 U 盘或聊天工具中转，把中转副本一并删除。
3. 旧工具不再用了的话，从浏览器里移除已保存的密码，避免两处存密码、日后不知道哪份是新的。

搬迁到此完成。之后新增密码都记在 SafeInCloud 里，旧的密码管理器可以卸载了。
