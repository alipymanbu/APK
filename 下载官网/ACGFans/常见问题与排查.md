# ACGFans 常见问题与排查

> 本文汇总 ACGFans 用起来最常碰到的几类问题：闪退白屏、内容加载慢、图片存不下、功能找不到，按现象给排查顺序。

## 一、打不开 / 闪退 / 白屏

按顺序试，每做一步就试一次，能省掉后面的重活：

1. **重启应用**：从后台彻底划掉再打开；
2. **清缓存**：设置 → 应用管理 → ACGFans → 存储 → **清除缓存**（别点清除数据，那会退登录态与本地草稿）；
3. **看剩余空间与内存**：手机存储快满、后台开太多都会让应用异常，清出几个 GB 再试；
4. **核对系统版本**：要求安卓 5.2 以上，系统过低会装不上或装上就崩；
5. **核对安装包**：MD5 与 [下载与安装教程.md](下载与安装教程.md) 表格里的值比对，不一致说明包损坏——重新下载 ACGFans 安装文件资源（夸克网盘）[https://pan.quark.cn/s/2b7e16af5d5f](https://pan.quark.cn/s/2b7e16af5d5f) 再装一遍；
6. **卸载重装**：前五步都无效再走这步，注意重装后要重新登录（见 [注册登录与账号问题.md](注册登录与账号问题.md)）。

如果闪退是**最近一次更新之后**才出现的，多半是新版本本身的问题——等下一次更新修复，或临时回退到之前用着正常的版本。

## 二、内容加载慢 / 一片空白

1. **先分清是网络还是服务**：切换 Wi-Fi 与移动数据各试一次；只有一个网络慢就是网络问题；
2. **换个时段**：晚间是使用高峰，同一页面早晚体验可能差很多；
3. **清缓存**：缓存堆积会让滚动加载变卡，路径同上；
4. **看是否被拦**：用手机热点能打开而家里的 Wi-Fi 打不开，问题在网络侧（路由器拦截或 DNS 异常）。

加载一半的图片显示破图属正常，下拉刷新即可。

## 三、图片下载 / 保存失败

详情页的「下载图片」要把文件写进相册，需要存储权限：

1. **设置 → 应用管理 → ACGFans → 权限**，开启「存储 / 照片与媒体」相关权限；
2. 已经拒绝过权限的，权限列表里把它改成「允许」，再回详情页重试；
3. 权限给了还失败，看**相册剩余空间**——手机存储满了会写入失败；
4. 换一张图试：单张图失败是资源问题，全部图失败才往权限与存储上查。

## 四、功能找不到 / 按钮点了没反应

| 你找不到的 | 位置 |
| --- | --- |
| 登录入口 | 底部导航「我的」，弹窗即登录 |
| 发布按钮 | 导航栏的 + 号 |
| 番剧时间表 | 底部导航「番剧」 |
| 加好友 | 内容或作者主页的「求扩列」 |
| 聊天 | 消息界面（加到好友后出现） |
| 搜索 | 页面顶部搜索框 |

点没反应的通用排查：先确认**登录态**（写入类动作都要登录），再确认网络正常，最后清缓存重开。仍无反应就是应用本身的问题，等更新或通过应用内反馈渠道报障。

## 五、几件事的边界，先知道能省时间

- **番剧不能在线播放**：番剧页只有介绍、更新时间与讨论区，不是播放器（详见 [番剧时间表与追番怎么用.md](番剧时间表与追番怎么用.md)）；
- **未登录只能看不能写**：点赞、评论、发帖、关注、私信都要登录；
- **卸载会丢本地数据**：草稿、本地登录态会清空，服务端的关注与收藏登录后仍在；
- **版本号以安装包为准**：网盘这一份是 1.2.1（82.36M），应用商店与下载站显示的版本可能不同，以你手上那个包的信息为准。
