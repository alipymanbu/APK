# Remax 耳机音效调节与电量显示使用说明

## 一、前提：耳机已在应用里绑定

本篇的所有功能都建立在「应用与耳机已连接」之上。还没连接的先按 [怎么连接蓝牙耳机.md](怎么连接蓝牙耳机.md) 完成配对与绑定，绑好后应用首页会显示当前设备。

注意一点：**不同型号的 Remax 耳机在应用里开放的功能菜单不同**。较新的型号菜单多、可调项全；较早的型号可能只有媒体控制与电量显示。你在自己的界面里找不到某个功能入口时，说明该型号大概率不开放这一项，不必到处找开关。

## 二、音效参数调整

连上耳机后，在设备界面找到音效（EQ）相关入口，按下面的思路调：

1. 选择预设音效（如流行、古典、低音增强这类风格预设，具体预设名以界面为准）；
2. 想自己调的话进入自定义，通过滑杆调整各频段的增益——低频影响鼓点与低音的厚度，中频影响人声的远近，高频影响镲片、气声这类细节的明亮度；
3. 调整时放一段自己熟悉的歌对比，一次只动一个频段，幅度从小往上加，比一次拉满更容易找到舒服的位置；
4. 找到满意的声音后保存，之后连接该设备会沿用这套设置。

觉得怎么调都不对劲时，先把自定义清零或切回默认预设，确认问题出在调音而不是连接质量。

## 三、媒体播放控制

应用内提供对手机音频播放的基础控制：播放 / 暂停、切上一首 / 下一首、调整音量。日常两处会用到：

- 手机不在手边（比如充电时放在远处）时，用应用界面代替手机屏幕操作；
- 想快速切换音源时，直接在应用里点上一曲 / 下一曲，不用解锁手机。

## 四、电量与连接状态查看

应用首页会实时显示当前耳机的**连接状态与剩余电量**，这是它最常用的一个功能：

| 你看到的 | 说明 | 建议动作 |
| --- | --- | --- |
| 电量充足、已连接 | 正常状态 | 直接使用 |
| 电量偏低 | 耳机快没电了 | 尽快放回充电盒充电，避免听歌中途断电 |
| 未连接 / 离线 | 耳机没开机、超出范围或被别的设备占用 | 按 [连不上耳机怎么办.md](连不上耳机怎么办.md) 排查 |

电量数值是耳机通过蓝牙上报的，部分早期型号只报告笼统电量档位（如高 / 中 / 低），能显示精确百分比与否取决于耳机本身。只有一边出声、或单边电量长期异常的情况，见 [耳机一边响一边不响怎么解决.md](耳机一边响一边不响怎么解决.md)。

## 五、辅助功能：通话音频、联系人与音频文件分享

除了上面这些，应用还提供一组蓝牙辅助功能，入口在设备详情菜单里：

- **通话音频管理**：管理耳机在通话场景下的音频通道。需要系统蓝牙配对时勾选了「通话音频」授权（见 [怎么连接蓝牙耳机.md](怎么连接蓝牙耳机.md) 第二节）；
- **联系人共享**：把手机通讯录共享给耳机设备，多见于带显示屏或语音播报来电人的耳机。这一步在系统蓝牙配对时也会单独询问授权；
- **音频文件分享 / 传输**：在设备间分享和传输音频文件。使用这个功能时应用会申请**存储 / 音频文件读取**权限，不给权限会选不了文件。

这三项属于「按需使用」的功能——用不到可以完全不碰，不影响音效、播放控制与电量显示等主要用途。
