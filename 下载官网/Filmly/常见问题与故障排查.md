## 一、安装类问题

安装环节的坑集中在「来源开关」和「包本身」，对照下表：

| 症状 | 原因与处理 |
| --- | --- |
| 电视应用商店搜不到 | 该应用在不少电视品牌的商店未上架，走 U 盘侧载，见 [下载与安装教程.md](下载与安装教程.md) 第三节 |
| 点 apk 没反应 | 「允许安装未知来源应用」没打开；小米在「设置 → 账号与安全」，其他品牌在设置里找「安全」相关项 |
| 提示解析包错误 | 安装包不完整或与系统版本不匹配：重新下载并核对 MD5 `47DA8C5003E9014A1B097354BC97D321`；老设备确认系统满足安卓 5.0 以上 |
| 提示签名冲突 | 装过其他版本的 Filmly/网易爆米花，先卸载再装 |
| 装完打不开、闪退 | 先重启电视（拔掉电源等一分钟再插上效果更彻底）；再进系统设置里清该应用缓存；频繁崩溃才考虑清除数据——那会连登录状态一起清掉，要重新登录 |

首次启动要求登录，用手机号注册即可；登录后手机端与电视端的数据才打通，别两端各用各的账号。

## 二、扫描与识别类问题

**海报墙是空的 / 扫不到视频**，按顺序查：

1. 影片源还挂着吗——去「添加新资源」或资源管理页看来源状态，网盘授权过期会整源失效，重新登录授权一次，接入方式见 [网盘与WebDAV怎么绑定.md](网盘与WebDAV怎么绑定.md)；
2. 勾选的文件夹对不对——确认勾的是视频实际所在的目录，移动过文件位置的要让影片源指向新路径；
3. 格式认不认——mkv、mp4、avi 等主流格式都在支持范围，个别冷门封装扫不出来时先转成 mp4 再试；
4. 还不行就手动刷新一次媒体库，扫描是排队执行的，影片多时等几分钟属正常。

**识别出的海报、简介对不上片，或片子都堆在「其他」分类里**：属于识别匹配问题，处理办法单独成篇，见 [海报识别不对怎么改.md](海报识别不对怎么改.md)（官方命名规范 + 手动编辑步骤都在那篇）。

**刷新后媒体库里少了文件**：去资源库找对应文件看匹配状态，没匹配上的批量手动编辑；具体步骤同见 [海报识别不对怎么改.md](海报识别不对怎么改.md)。

**只想删掉部分影片**：影片跟随影片源走，从资源管理里移除对应来源，它带来的影片就一起消失；单部隐藏的入口在影片详情或长按菜单里找。

## 三、播放类问题

| 症状 | 处理 |
| --- | --- |
| 卡顿、缓冲圈转不停 | 先把清晰度降到低一档，流畅后逐级往上调；官方 FAQ 也是这个口径——受码率、网速、电视硬件多重影响，别一步到位上最高画质 |
| 黑屏有声音 | 降低清晰度、换低码率片源试试；换个片子验证是不是个别片源的问题 |
| 音画不同步 | 退出重进播放；个别片源封装问题，重新封装或换片源 |
| 外挂字幕不显示 | 字幕文件与视频同名放同目录；乱码则把字幕转成 UTF-8 编码的 srt |
| 遥控器按键没反应 | 清一下电视后台或重启电视再试；遥控器本身没电另说 |

网盘片源在线播放走的都是网盘的带宽与服务状态，同一部片子白天流畅晚上卡，通常是网盘限速或高峰拥堵，与你本地关系不大。

## 四、账号与同步类问题

- **电视上看不到手机导入的片子**：确认两端登录同一账号；同步有几秒到几分钟延迟，急用就在电视端手动刷新；
- **换手机后收藏与进度丢了**：观看记录挂在账号上，新手机登录同一账号即可找回；
- **不想用了怎么清干净**：先在影片源管理里移除各来源，再卸载应用；账号层面的注销要走官方渠道的账号注销流程，与卸载是两回事。

上面覆盖不到的问题，可以在应用内「我的」或设置页里找反馈入口提交；版本更新较快，遇到明显问题也可先更新到新版再试。
