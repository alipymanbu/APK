## 一、先弄清楚你要装的是哪一版

Filmly 是网易推出的智能媒体库播放器，2024 年 11 月起中文名定为「网易爆米花」。它有手机版和 TV 版两条线，安装包互不通用：

- **TV 版**：装在智能电视、电视盒子、投影仪上，用遥控器操作，包名 `com.netease.filmlytv`。本篇给的安装包就是这一版。
- **手机版**：装在安卓手机、平板上，应用商店里搜「网易爆米花」或「Filmly」即可，一般不需要侧载安装包。

本文给的这份 TV 版安装包事实如下（版本、大小均以网盘里这份文件为准；各应用商店现在挂的是官方后来更新的新版本，未必是同一版）：

| 项目 | 值 |
| --- | --- |
| 应用名称 | Filmly（网易爆米花） |
| 版本 | 1.3.5.0829 |
| 包名 | `com.netease.filmlytv` |
| 安装包大小 | 47.45M |
| MD5 | `47DA8C5003E9014A1B097354BC97D321` |
| 开发者 | 广州网易计算机系统有限公司 |
| 系统要求 | 安卓 5.0 以上（部分收录页标注 5.2 以上，以官方页面为准） |

官方渠道的新版本迭代很快，功能与界面也会随版本变化；本套文档描述的操作以这类 TV 版的实际行为为参照，个别入口名称以你装到的版本显示为准。

## 二、获取安装包

安装包在 [Filmly 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5d6a88d57bfb) 里，转存到自己的网盘后下载 apk 文件到本地即可。下载完建议核对一下 MD5 是否等于 `47DA8C5003E9014A1B097354BC97D321`，不一致说明文件不完整或不是这一版。

电视本身一般没法直接从网页下载文件，所以常规路径是「手机或电脑下载 → 拷进 U 盘 → 插电视安装」，下一节具体说。

## 三、TV 端安装（U 盘侧载）

不少电视品牌的应用商店里搜不到 Filmly 或网易爆米花，所以 TV 版最常见的安装方式就是 U 盘侧载：

1. **放行未知来源**：进电视「设置」，找到「账号与安全」（小米/红米电视叫这个名）或「安全」「系统安全」之类的栏目，把「允许安装未知来源应用」打开。不开这一项，后面点安装包不会有任何反应。
2. **拷包进 U 盘**：把 apk 文件放在 U 盘根目录，别套多层文件夹，也别解压。
3. **插 U 盘**：U 盘插电视 USB 口，等弹出「检测到移动存储设备」提示后选「打开 U 盘」。没弹窗的话，在电视首页顶部按遥控器「上」键通常能找到 U 盘入口。
4. **找到安装包**：用电视自带的文件管理器打开 U 盘。不同品牌入口叫法不同：小米叫「高清播放器」，创维等多藏在应用分类或「本地媒体」里。
5. **安装**：选中 apk 按确定键，弹出的确认窗口选「继续安装」，等进度走完。
6. **打开**：回到电视首页，「我的应用」里会出现 Filmly 图标。

首次打开时会要求登录（手机号注册或已有账号直接登录），并可能申请存储权限——海报缓存需要它，正常给即可。

## 四、手机端怎么装

安卓手机直接在应用商店搜「网易爆米花」安装官方版即可，不必折腾本篇的 TV 安装包——包名不同，装错了版本电视上也用不了。手机装完登录同一账号后，你在手机端导入的影片源会自动同步到电视端，电视上不用再折腾一遍，具体见 [怎么导入本地视频.md](怎么导入本地视频.md)。

## 五、装不上时的排查

| 症状 | 处理 |
| --- | --- |
| 点安装包没反应 | 「允许安装未知来源应用」没打开，回第三节第 1 步 |
| 提示「解析包时出现问题」 | 文件没下完整，重新下载并核对 MD5；或电视系统版本太低带不动这个包 |
| 提示空间不足 | 安装时需要临时解包，占用比安装包本身大，先清出几百 MB 再装 |
| 提示签名冲突 | 电视上装过别的 Filmly/爆米花版本，先卸载旧的再装 |
| U 盘插上没反应 | 换 USB 口；确认 U 盘是 FAT32/exFAT 格式（部分电视不认 NTFS） |

装完之后用得顺不顺，主要看影片源怎么导入和播放菜单怎么调，接着看 [怎么导入本地视频.md](怎么导入本地视频.md) 和 [播放设置与快捷操作.md](播放设置与快捷操作.md)。
