# Seetong 通道离线与连接失败排查

> 设备加进来了却灰色离线、通道掉线、或画面出不来，多数是通电、网线、网段、密码四类问题。本篇按提示逐个排查。

## 一、先分清是哪一层的「离线」

监控链路是「摄像机 → 录像机 → 云服务器 → 手机」。「通道离线」指某台摄像机与录像机之间断了；App 或云上显示「设备离线」指录像机整体没连上云。两层原因不同，先在 App 里看清楚提示再对症处理。

## 二、设备整体离线（App 显示离线）

- 查录像机电源与指示灯，可断电重启一次；
- 查录像机到路由器的网线两端是否插紧，路由器本身要能上网；
- 设备端密码改过也会导致连接异常，处理方式见 [密码找回与云密码修改.md](密码找回与云密码修改.md)。

## 三、通道离线（录像机上的摄像机掉线）

在录像机显示屏上右键 →「视频管理」，看掉线通道的提示：

**提示「网络断开」**：

1. 对比掉线摄像机与录像机的 IP 第三位网段是否一致；不一致时，右键「系统设置 → 网络」开启多址，把 lan2 的 IP 和网关前三位改成该摄像机的网段，应用后等两分钟左右看是否上线；
2. 网段一致仍断，用「视频管理」里通道旁的诊断按钮 →「网络工具」跑一次检测：丢包 0%、最大回应 10ms 以内算网络良好；出现 Timeout 说明线路不通；
3. 丢包高或时通时断，沿网线检查水晶头与交换机端口指示灯，换个网口、换线或重压水晶头再试。

**提示「用户名或者密码错误」**：

- 摄像机密码被改过：在「视频管理」里双击该提示，输入新密码重新连接；
- 协议为 onvif 的第三方摄像机，密码要找对应厂商确认；
- 天视通自家摄像机改密后找不回，恢复出厂会回到初始密码 123456，再在「视频管理」里重新搜索添加。

**通电与线路基础检查**（两种提示都适用）：确认摄像机通电，断电重启一次；拔插网线两端，或把离线通道与其他正常通道的网线对调，定位问题在线路还是在设备。

## 四、设备在线但画面出不来

- 手机网络波动：切 WiFi / 流量再试，App 支持按不同网络环境选择播放模式；
- 其他通道正常、只有这一个不行：按第三节排查该通道；
- 全部通道都不行而设备在线：重启录像机，仍不行再恢复出厂重新配置；
- 电脑客户端里看图标颜色定状态：灰色 = 连接失败/离线，蓝色 = 在线未播放（双击设备名或 IP 即可预览），红色 = 正在播放。

## 五、电脑客户端连接失败

客户端还没装的，先看 [电脑客户端下载与登录方法.md](电脑客户端下载与登录方法.md)；已装但连不上的按下面排查：

- 搜不到设备：确认设备与电脑在同一局域网、同一网段，且电脑没有同时连多个网络（连了多个的，禁用与设备不同网段的那几个）；
- 搜到但添加后连接失败：多为网段问题，改电脑网段或禁用多余网络；
- 老版本电脑客户端加新摄像头可能连不上，升级客户端版本；
- 带 4G 无忧/免流量套餐的设备不支持在电脑端观看，预览会提示无可用流量套餐。

## 六、还解决不了

官方帮助中心 [app.help.seetong.com](https://app.help.seetong.com) 收录了各型号与报错的官方解答，也可通过官方公众号咨询。找客服或卖家时，报上设备序列号能更快定位机型——天视通设备的序列号以 0 开头、共十六位数字。
