# Seetong 添加设备的三种方法

> 设备要先进到账号里才能远程看。本篇按场景给出三种添加方式：扫二维码、局域网搜索、手动输云 ID，并覆盖添加时报错的两个高频提示。

## 一、三种方式怎么选

| 方式 | 适用情况 | 需要什么 |
| --- | --- | --- |
| 扫二维码 | 录像机接了显示屏，屏幕上能调出二维码 | 录像机已激活上线 |
| 局域网搜索 | 手机和录像机连同一个路由器 | 录像机的系统密码 |
| 手动输云 ID | 老版本设备扫不了码，或人不在设备旁 | 云 ID + 用户名 + 云密码 |

## 二、先确认设备已联网激活

新装的录像机要先联网并激活，否则 App 里怎么搜都会提示「暂未联网云服务器完成注册」：

1. 录像机接显示器，鼠标右键 →「系统配置」→「网络」，把 IP、DNS 配成路由器下发的内网地址（路由器本身要能上网）；
2. 状态栏出现「未激活：点击激活」时点它，按提示设置密码——只能含大小写字母和数字，不能空、不能用 123456；
3. 等几分钟设备连上云服务器；云 ID 在「系统配置 → 网络」或「系统配置 → 系统 → 基本信息」里能看到，二维码也在基本信息里。

## 三、方式一：扫二维码添加

1. 在录像机接的显示屏上进入「系统配置 → 系统 → 基本信息」，屏幕会显示云 ID 和二维码；
2. 打开 Seetong App，用添加设备里的「扫一扫」对准二维码；
3. 需要时输入设备密码，添加成功后设备出现在列表里。

提示「不合法二维码」的，见第六节的对照表。

## 四、方式二：局域网搜索添加

1. 手机连上录像机所连路由器的 WiFi；
2. App 右上角「+」→ 选「网络硬盘录像机」→ 局域网搜索；
3. 搜到设备后点添加，输入录像机的系统密码。

这种方式最常用于扫不了码的老设备，也是「不合法二维码」报错时绕开扫码的路子。

## 五、方式三：手动输入云 ID 添加

老版本录像机可以不扫码，直接手输：

1. 在录像机显示屏上记下云 ID（一串纯数字，例如 6729718）；
2. App 里点「+」手动添加，填云 ID、用户名（默认 admin）和设备密码（激活时设的云密码）；
3. 点「添加」，成功后设备进列表，你自动获得它的查看与管理权限。

## 六、单独添加传统摄像机（不经录像机）

传统枪机、筒机一般接录像机用；要单独绑到手机上远程看，得先在电脑客户端里把它的云平台打开（客户端从哪下、怎么登录，见 [电脑客户端下载与登录方法.md](电脑客户端下载与登录方法.md)）：

1. 电脑客户端在局域网内搜索并添加该摄像机；
2. 选中设备，右键 →「远程配置」→「网络设置」→「云平台设置」，勾选启用并设置云密码（App 添加时要用）；
3. 再在「远程配置 → 网络设置 → 以太网设置」里禁用全网通、开启 DHCP 让设备自动获取 IP；
4. 之后按第三~五节任一方式在 App 里添加。

注意：单独添加的摄像机只能实时预览，看不了录像回放；回放要走录像机。

## 七、添加时报错的两种情况

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 不合法二维码 | 录像机外接显示器分辨率不匹配，二维码变形扫不出 | 右键 →「系统设置」→「常规」→「常规设置」改分辨率；或改用第四节局域网搜索 |
| 此设备暂未联网云服务器完成注册 | 设备没激活或没连上云 | 按第二节激活并设密码；查录像机与路由器的连接；「系统设置 → 网络」里确认已开自动获取 IP（DHCP） |

局域网搜索添加时提示「云密码强度过低」的，要先在设备端改密码再添加，见 [密码找回与云密码修改.md](密码找回与云密码修改.md)；设备加上了却离线或看不了画面，看 [通道离线与连接失败排查.md](通道离线与连接失败排查.md)。
