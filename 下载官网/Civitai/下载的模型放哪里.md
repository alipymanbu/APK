## 一、按类型放对目录

不同类型的模型文件要放进不同目录，放错了工具就识别不到。以两类主流本地工具为例：

| 文件类型 | WebUI（AUTOMATIC1111 / Forge） | ComfyUI |
| --- | --- | --- |
| Checkpoint（大模型） | `models/Stable-diffusion` | `models/checkpoints` |
| LoRA / LyCORIS | `models/Lora` | `models/loras` |
| VAE | `models/VAE` | `models/vae` |
| Embedding（文本反转） | `embeddings` | `models/embeddings` |
| ControlNet 模型 | `models/ControlNet` | `models/controlnet` |

（以上是默认安装的常见位置；如果你改过安装路径或用了整合包，以你那套工具的实际目录为准。）放进去之后，在工具里点刷新或重启一次，模型下拉列表里才会出现。LoRA 多了以后，可以在 `loras` 目录下按基础模型建子文件夹（如 SD1.5 / SDXL / Flux）区分管理。

## 二、下载哪个文件版本

同一个模型页常有多个文件可选，按这三条挑：

1. **格式优先选 `.safetensors`**。老的 `.ckpt` 格式理论上能夹带代码，社区普遍只推荐从可信来源拿 ckpt；safetensors 没有这个问题，Civitai 上传的文件也会经过站方扫描。只有 ckpt 一个格式可选时，先看上传者是否可信、评分评论是否正常。
2. **Checkpoint 选 Pruned / EMA-only 就够用**。它是去掉冗余权重的精简版，出图效果与完整版一致、体积小得多；Full 版是给继续训练微调的人用的，只出图用不上。
3. **精度选 fp16**。fp16 比全精度（fp32）体积几乎减半，出图没有可见差别，是社区通行的默认选择。没有特别理由，就下 Pruned + fp16 的 safetensors 组合。

体积参考：SD1.5 的 checkpoint 精简版约 2GB、SDXL 约 6~7GB，LoRA 通常几十到几百 MB —— 下之前留意磁盘空间，手机流量党尤其注意。

## 三、版本匹配：看 Base Model

模型页会标注基础模型（Base Model）。**LoRA 只能搭配对应的基础模型用**：SD 1.5 的 LoRA 配 SD 1.5 的 checkpoint，SDXL 的配 SDXL 的，跨代混用轻则没效果、重则报错。下载前对一眼：模型页标的基础模型，和你本地正在用的大模型是不是同一家族。这也是「照抄参数却出不了同样的图」的高发原因，完整排查见 [照抄参数出图不一样怎么办.md](照抄参数出图不一样怎么办.md)。

## 四、下载与放置的常见小坑

- 文件后缀是 `.crdownload` 说明还没下完，等浏览器下完再移动。
- 放对目录但列表里没有：先点工具里的刷新按钮（WebUI 左上角的刷新图标），不行就重启工具。
- 文件名乱码或重复：改不影响使用的英文名没问题，工具按文件内容识别，不认文件名。

## 五、商用之前查一眼许可证

模型页底部一般有作者设置的许可证（license）条款，常见限制是商用、再分发或合并模型。个人玩不受影响；要拿生成图做商业用途，先把打算用的那几个模型的许可证逐条看一遍，以模型页当时的标注为准。
