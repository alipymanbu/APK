# Civitai 照抄参数出图不一样怎么办

> 提示词、采样器、步数都抄了，出的图还是和原作差一截。本篇列复现失败的常见原因，按顺序对照排查。

## 一、复现需要哪些东西对上

一张作品页能复制的不只是提示词。完整的「出图配方」包括下面这些，缺一样结果就会偏：

| 项目 | 在哪看 | 常见的漏 |
| --- | --- | --- |
| 提示词 / 负面词 | 作品页参数区 | 只抄了正面提示词 |
| 大模型及其版本 | 参数区或资源列表 | 模型同名但版本不同 |
| LoRA 及其权重 | 资源列表 | 忘了原作叠了 LoRA |
| 种子（seed） | 参数区 | 随机种子没固定 |
| 采样器 / 步数 / CFG | 参数区 | 数值对但采样器不同 |
| 画面尺寸 | 参数区 | 尺寸和原作不一样 |
| VAE | 模型页或参数区 | 用了不同的 VAE |

## 二、按顺序排查五个高发原因

1. **大模型不对或版本不同**。这是最大的变量：同一句提示词，换一个 checkpoint 风格就完全不同；同名模型的 v1 和 v3 出图也常有差距。先确认你本地加载的模型和原作一致（名字 + 版本号都对上）。
2. **LoRA 没装或权重不同**。原作叠了 LoRA 而你没装，人物长相、画风细节就复现不出来；装了但权重值不同也会有偏差。作品页的资源列表里能看出叠了哪些 LoRA。
3. **种子没固定**。种子是随机起点，种子不同，其他全对也一样是不同的图。把 seed 抄成原作的数值再生成。
4. **尺寸不同**。尺寸变了构图必然变。对齐原作的宽高；不同代模型有各自的原生分辨率（如 SD1.5 是 512 一档，SDXL 是 1024 一档），尺寸偏太远还容易出畸形。
5. **采样器或 VAE 不同**。采样器名字对不上时出图质感有差；VAE 不匹配则常见发灰、色彩发闷。都按原作参数对齐。

## 三、推荐的复现顺序

先装对大模型 → 叠上原作的 LoRA → 整组粘贴参数（含负面词）→ 固定 seed 和尺寸 → 生成一次对比。这一步已经和原作接近后，再动提示词改自己的内容；一开始就大改提示词，偏差会层层叠加，说不清是哪个变量造成的。

## 四、这些情况本来就不可能完全一样

- **作者隐藏了参数**：不是每张作品都带完整参数，上传者可以选择不带元数据 —— 参数区是空的就无从复现，只能按提示词重写。
- **模型家族不同**：Flux 这一代模型用自然语言描述、没有负面提示词，SD 系的抄参数习惯（权重括号、负面词堆砌）搬到 Flux 上不起作用，反之亦然。
- **站内生成与本地工具的差异**：同一参数在 Civitai 站内生成器和本地工具（WebUI / ComfyUI）上跑，实现细节有差别，结果允许有小幅出入；差得远就回到第二节逐项对。

模型文件怎么放、版本怎么选见 [下载的模型放哪里.md](下载的模型放哪里.md)；客户端里复制参数的入口见 [手机端使用入门.md](手机端使用入门.md)。
