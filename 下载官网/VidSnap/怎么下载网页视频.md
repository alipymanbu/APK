# VidSnap 怎么下载网页视频

> 本篇讲 VidSnap 的完整下载流程：在浏览器里打开视频、播放、等它把视频流接住，再选清晰度存下来。

VidSnap 的下载入口不是「粘链接、出结果」那种，而是自带浏览器里的请求嗅探器：你把视频页面在里面打开并播放，它去接住页面正在加载的那条视频流。所以整套流程的关键不在点哪个按钮，而在「让视频真的在它自己的浏览器里跑起来」。本篇按顺序拆开讲，顺手说明每一步卡住时的判断依据。

## 一、开始之前，确认三个前提

嗅探这件事对页面环境很挑，先花半分钟排除掉无关因素：

1. **这个视频在普通浏览器里能不能正常播**。先拿系统浏览器或电脑试一下同一个地址。如果那里也播不动，VidSnap 里同样抓不到东西，问题在网站或网络，不在应用。
2. **把「列表页」和「视频页」分开**。嗅探要的是正在播放的那条流，所以得进到具体某个视频的播放页面，而不是停在频道首页、搜索结果页或者合集目录上。
3. **网络能到达那个网站**。部分境外站点在手机网络下打不开，打开后是空白页或转圈，这种情况跟嗅探无关，先解决能不能访问的问题。

顺手提一句使用边界：只保存你有权保存的内容，自己看或者做备份没问题，别拿去二次分发。

## 二、完整流程：六步

1. **切到「浏览器」标签**，在顶部输入框里填视频页面的网址，回车。首页排的那些快捷入口（YouTube、TikTok、Facebook 等）只是省打字，点进去之后照样要自己找视频，不影响流程。
2. **进到具体视频的播放页**，把页面上的播放按钮点一下，让画面真的动起来。这一步是整个流程里最容易省错的地方——不点播放，就没有视频流可接。
3. **等检测完成**。检测不是瞬间完成的，页面开始播放后还要等一会儿，它自带的帮助弹窗里写的等待区间是 **5～50 秒**。中途别离开这个页面，也别把视频暂停。
4. **在检测到的结果上发起下载**。检测成功后会出现下载入口，点它之后，如果这个视频有多种清晰度，会先弹出一个窗口让你选，选完再点一下确认就开始下载。
5. **看下载进度**。切到「下载」标签，能看到任务和进度。下载本身是在后台跑的，切去别的应用不会主动中断，但部分定制系统会按省电策略清理后台应用、把任务掐掉（处理办法见 [常见问题与排查.md](常见问题与排查.md) 第二节）；网络断了再接回来会从断点续传，不用从头重下。
6. **下载完成后直接播放**。视频下载完就出现在「下载」标签里，应用内可以播放。想从文件管理器里另找一份的话，在较新的安卓上多半看不到，原因是系统不允许应用之间互相访问专属目录，见 [下载的视频存在哪.md](下载的视频存在哪.md)。

## 三、为什么必须「在它自己的浏览器里」播放

因为嗅探看的是页面发出的请求，而不是你手里的链接。同一个链接在别处复制过来，VidSnap 也无法直接解析——它要做的是打开那个页面、看页面自己去请求了哪些视频地址。

这也解释了另外两件容易困惑的事：

- **同一个视频，换一台手机或换一个网络，检测结果可能不一样。** 网站给不同环境下的播放器发的流地址本来就可能不同。
- **页面上有广告或者预览片段时，可能先被接住的是那条短的。** 检测期间页面在播什么，它就可能抓到什么，所以要在正片开始播之后再等结果。

## 四、检测完成后的那个窗口

检测到流之后，点下载按钮会出现一个对话框，里面要你选的东西不多：

| 窗口里的项 | 怎么选 |
| --- | --- |
| 分辨率 / 清晰度 | 网站提供了多档才会出现这一项；没提供就只有一个结果，直接下一步 |
| 文件格式或流类型 | 普通的整段视频和分片流在表现上不一样，分片流会先下载一堆小片段再合并，见 [m3u8分片与直播下载.md](m3u8分片与直播下载.md) |
| 文件名 | 可以改，也可以不改；列表里认的是这个名字 |

窗口里选好之后还要再点一次确认按钮才开始下载，只选不做确认是不会动的。

## 五、一次交多个链接

应用说明里明确写了支持多链接批量处理，一次可以交 100 多个视频链接。但如果你的需求只是连着下几条，不必去找批量入口——按上面那六步一条条走完全可行，下载任务会在「下载」标签里排队，前一条没下完也可以先去处理下一条，后台会继续跑。

## 六、这套流程最容易失败的三个环节

- **检测不出来**：占了绝大多数。判断顺序和解决办法都写在 [视频检测不到怎么办.md](视频检测不到怎么办.md)。
- **检测到了但下载下来是坏的**：通常是多线程下载碰上了对分段要求严格的网站，把线程数降下来就行，见 [设置项与嗅探规则怎么调.md](设置项与嗅探规则怎么调.md)。
- **分片流合并失败或直播录了一半**：见 [m3u8分片与直播下载.md](m3u8分片与直播下载.md) 与 [常见问题与排查.md](常见问题与排查.md)。

其余零散问题（打不开网页、找不到刚下的视频、想换手机迁移）统一放在 [常见问题与排查.md](常见问题与排查.md)。
