VidSnap 是一个安卓端的视频下载工具。它自带浏览器，你在里面打开视频页面并点击播放，它就把页面正在加载的视频流接住、存到本地，能处理普通的 MP4、M3U8 这类分片流，也能把正在直播的流边播边录下来。本篇只做一件事：把网盘里这份包装进手机，并让你第一次打开时知道这三个标签各自是干什么的。

## 一、先弄清网盘里这份包是哪一版

网上能搜到的版本信息多是发布时的最新版，而网盘里这份是整理文档时核对过的那一版，两者未必是同一个版本号。下面这些值以网盘里那份包为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | VidSnap |
| 版本号 | 0.0.3 |
| 包名 | `com.vidsnap` |
| 安装包体积 | 47.04 MB |
| MD5 | `8BC4E51124F674639B0DB2F03A3AB8F9` |

下载页把它标注为「免费（应用内购买项目）」：安装和使用本身不收费，应用内另有内购项。另外它不需要注册账号，装上就能用——只有你要下载的那个网站本身要求登录时，才需要在它的浏览器里登录那个网站。

在电脑上下好包后，可以先算一遍 MD5 再往手机里传：和上表一致，说明文件完整；对不上就重新下一遍，别将就着装。手机端直接下载的话不方便校验，那就只对一下体积是不是接近 47.04 MB。

版本号本身不用太在意。这个应用公开资料很少，迭代节奏看不出规律，0.0.3 这个号只是这一版的标识，不代表它一定比别的应用「旧」。

## 二、装之前要核对的两件事

**第一，不需要 root，也不需要刷机。** 它就是一个普通 APK，装上之后所有授权都在系统设置里逐项点一下就能给全。凡是要求你先获取系统最高权限才能用的说法，都跟这个应用无关。

**第二，认包名，别装错。** 应用名叫「视频下载器」的应用一大堆，图标和名字都长得像，但包名各不相同，系统认的是包名。本文这套文档对应的是 `com.vidsnap`，在手机「设置 → 应用 → 应用管理」里能看到已装应用的包名。

系统要求这块要给个提醒：下载页标注的是「Android 5.2 及以上」，但第三方页面互相抄来抄去，最低版本标注彼此并不一致（有的写 5.0、有的写 5.1），这些数字只能当参考。想确认能不能装，最直接的办法是直接装一次——安卓在设备不兼容时会拒绝安装，提示「应用未安装」或「与你的设备不兼容」，不会装上一个半残的版本进去。

## 三、安装步骤

1. **转存并下载**：从 [VidSnap 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c1eba2ef34a7) 把 APK 转存到自己的网盘，再下载到手机。
2. **把包装到手机上**：手机端直接下载最省事；在电脑上下载的，用数据线或任意传输工具拷进手机存储。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统通常把这挡在「安全」或「隐私」分类里。
4. **点开 APK 完成安装**：系统提示「应用未经过安全检测」时选继续安装即可，非应用商店渠道的包都会走这一步。
5. **覆盖安装的前提是版本更高**：安卓不允许用更低版本的安装包覆盖更高版本，会直接报「应用未安装」。手机里已有更高版本时，先卸载再装，代价是应用内的设置和已下载的视频会一并清掉。
6. **装完先别急着找视频**：先花一分钟认识下面三个标签，能省掉不少「下载按钮在哪」的来回。

## 四、第一次打开会看到的三个标签

打开应用，底部固定一条标签栏，只有三个入口：

| 标签 | 是什么 |
| --- | --- |
| 浏览器 | 应用内置的浏览器。顶部一个输入框，可以直接填网址，也可以填关键词走必应搜索；首页还排了一组常用站点快捷入口（YouTube、TikTok、Facebook、Instagram、Twitter、Dailymotion、Pinterest、Twitch.tv 等） |
| 工具 | 一批与下载无关的附加小工具，分「工具合集」和「收藏夹」两栏，另有一个意见反馈入口 |
| 下载 | 下载任务与已下载视频的列表，视频下载完就在这里播放 |

**关键一点：VidSnap 没有「粘贴链接立刻解析」的主界面。** 它的工作方式是先在内置浏览器里把视频放起来，再靠请求嗅探把视频流找出来——所以第一步永远是「在浏览器标签里打开那个视频」。具体怎么走，见 [怎么下载网页视频.md](怎么下载网页视频.md)。

## 五、装完做一次最小验证

不用挑复杂的网站，按这四步走一遍就知道装好没有：

1. 切到「浏览器」标签，在顶部输入框里输入一个能正常播放视频的网页地址，回车；
2. 页面加载出来后，点视频的播放按钮，让它真的开始播；
3. 等几秒到几十秒，看界面上会不会冒出下载按钮，或者弹出可选择的清晰度窗口；
4. 随便下载一个短一点的视频，切到「下载」标签，看它有没有出现在列表里、能不能点开播放。

第 3 步没反应是这类应用最常见的情况，绝大多数时候不是安装包的问题，而是嗅探的开关或网站本身的问题，处理办法集中在 [视频检测不到怎么办.md](视频检测不到怎么办.md)。

## 六、以后出了新版本怎么升级

网盘那份分享是长期有效的：更新版本时换掉的是里面的安装包文件，**分享链接本身不变**，升级不用重新去找地址。

1. 回到本文头部那条分享，看里面的包是不是已经换成比 0.0.3 更新的版本；
2. 直接下载新包点安装。包名相同、版本号更高时，安卓允许覆盖安装，**应用内的设置会保留**；
3. 万一覆盖安装报「应用未安装」，说明新包的签名和手机里那份对不上、或者版本号反而更低。这种情况只能先卸载旧版再装，设置要重配一遍。

还有一点要自己留意：它不是从手机自带应用商店装的，商店不会替你检查更新，想保持新版得隔一段时间回网盘看一眼。也别在同一台手机上同时装本文这份和别的渠道的同包名安装包，签名不一致会直接报「应用未安装」。

装不上、装完打不开、或者升级后设置丢了，都归到 [常见问题与排查.md](常见问题与排查.md) 里逐条查。
