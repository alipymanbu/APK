## 一、上传视频的流程

上传必须先登录账号（见[注册与登录账号.md](注册与登录账号.md)）：

1. 点底部「＋」→ 选「上传视频」。
2. 从相册选视频，或直接现场拍摄。
3. 填标题与描述，选可见性：公开、不公开列出、私享。
4. 点「发布」。

观众是否是未成年人影响默认值与功能：13~17 岁账号的直播默认可见性是不公开列出，18 岁及以上默认公开。发布后的视频在 YouTube Studio 里改标题、缩略图与可见性。

## 二、手机开直播的门槛

手机直播不是装了应用就能开，需要同时满足：

| 条件 | 说明 |
| --- | --- |
| 至少 50 个订阅者 | 低于 50 时手机端没有直播入口 |
| 近 90 天无直播限制 | 频道因违规被限制过直播的，90 天内开不了 |
| 频道已验证 | 用手机号验证频道，一次性操作 |
| 直播功能已开启 | 验证后手动启用 |
| 等待生效 | 首次开播前可能要等 24 小时 |

验证入口在频道设置的状态与功能页里，按提示用手机号收验证码即可。

## 三、开播步骤

1. 点底部「＋」→「直播」。
2. 填直播标题，选可见性与观众限制；可以选「安排时间」预约一场稍后开播的直播。
3. 需要时打开屏幕共享，直接直播手机屏幕（适合演示操作）。
4. 点「开始」开播；结束点「完成」。

结束后会自动在频道生成一场直播的归档视频，隐私设置随时可改、也可删除。

## 四、千人订阅以下的观众限制

订阅数在 50 到 1000 之间时，手机直播还有一个额外限制：

- 观看人数可能被限制；
- 直播归档默认转为私密。

订阅满 1000 后，限制会在几周内解除；掉回 1000 以下限制恢复。手机直播资格只有订阅跌破 50 才会失去。

## 五、开不了直播时先查什么

1. 订阅数够不够 50（入口灰掉多半是这条）。
2. 频道有没有完成验证、直播功能有没有打开。
3. 近 90 天频道有没有收到过直播相关的限制。
4. 第一次开播前等满 24 小时。

以上都正常仍不行，用「头像 → 帮助与反馈」把具体提示发给官方查。
