# HypeRate 直播显示实时心率的设置步骤

> 本篇讲怎么把 HypeRate 的实时心率挂进直播画面：OBS / Streamlabs 浏览器源接入、挂件样式挑选、原生 OBS 插件路线。设备先连好是前提，见 [连接心率设备与配对.md](连接心率设备与配对.md)。

> **HypeRate 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/d8423b5c9f2d](https://pan.quark.cn/s/d8423b5c9f2d)

## 一、整体思路

数据链路是三段：**心率设备 →（蓝牙）→ 手机上的 HypeRate →（会话链接）→ 推流软件里的浏览器源**。手机读到你戴着的设备的心率后，会生成一条带 HypeRate ID 的会话链接；把这条链接挂进 OBS、Streamlabs、Meld Studio 等任何支持浏览器源的推流软件，画面上就会出现实时心跳挂件。Twitch、YouTube、Kick、TikTok 都能这样用——挂件是画面的一部分，与平台无关。

## 二、浏览器源接入（最常用路线）

1. **记下 HypeRate ID**（一串区分大小写的短代码）。它在哪看取决于你的设备：胸带、臂带、小米手环这类由手机 App 连接的，ID 显示在手机 App 里；Garmin、Apple Watch、Wear OS、Fitbit 这类走手表端应用的，ID 直接显示在手表上（见 [连接心率设备与配对.md](连接心率设备与配对.md) 第一节）。
2. 在电脑推流软件里添加**浏览器源**（OBS：来源面板「+」→ 浏览器）。
3. URL 填 `https://app.hyperate.io/你的ID`。
4. 宽高按挂件大小设置（先给 400×200 这类小尺寸，再按画面比例调），点确定。
5. 回到画面拖到想要的位置，看到心跳数字开始跳就是通了。

两个官方反复强调的点：

- **ID 区分大小写**。链接里的 ID 抄错大小写会黑屏，宁可从 App 里复制粘贴，别手敲。
- **同一条链接场场通用**。官方与用户的口径一致：会话链接在直播结束后也不变，这次配好，下次开播不用重新加源。

## 三、挑挂件样式

默认样式之外，官方挂件库在 [hyperate.io/gallery](https://hyperate.io/gallery.html)（一百多种设计，按游戏与画面风格分类，恐怖、MMO、IRL 都有对应主题），挑好后按页面提示套用即可；进阶的动画参数在 [app.hyperate.io/widget-configurator](https://app.hyperate.io/widget-configurator) 里调。浏览器源也支持自定义 CSS 改背景色，想融进现有布局时用得上。

## 四、另一条路线：OBS 原生插件

不想用浏览器源的，官方另有开源的 **OBS HypeRate 插件**（入口 [obs.hyperate.io](https://obs.hyperate.io/)，OBS Studio 30 及以上版本支持，Windows 10/11、macOS 13+、Linux 均有安装包）：

1. 装插件，重启 OBS。
2. 来源里加「HypeRate Heart Rate Input」（它是个无画面的控制源），填同一个 HypeRate ID 连接。
3. 之后可给任意图形（logo、头像框、装饰图）加 Heartbeat 滤镜，让它随真实心跳跳动、发光、震动，也能直接放 BPM 数字显示与心跳音效。

这条路线的效果是「图形随心跳动」，和浏览器源挂件是两种呈现，可以并存；两个都连同一个 ID 即可。插件装好后连不上时，先回手机确认心率还在正常跳动，再翻 [常见问题与排查.md](常见问题与排查.md)。

## 五、想让心率触发点别的

心率之外，官方还维护了一批联动入口（见 [hyperate.io/extensions](https://hyperate.io/extensions.html)，以页面当时列表为准）：Streamer.bot、Touch Portal、Firebot、Lumia Stream、Nanoleaf 灯、LaMetric 时钟等——比如心率超过某个值就让灯变色。开发者还可以直接调它的 API 做自己的东西。这些属于进阶玩法，先用浏览器源把挂件跑起来，再考虑要不要碰。

设备还没连上的先回 [连接心率设备与配对.md](连接心率设备与配对.md)；安装本身的问题在 [下载与安装教程.md](下载与安装教程.md)。
