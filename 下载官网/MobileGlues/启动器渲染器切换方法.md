# MobileGlues 启动器渲染器切换方法

> 本篇讲装好插件后，怎么在 FCL 和 ZalithLauncher 2 里把渲染器切到 MobileGlues，以及切换后怎么确认它真的在跑。

## 一、为什么切了渲染器「看不到 MobileGlues」

最常见的反馈是「装完了，启动器里根本没有这个选项」。原因几乎都是同一个：启动器的渲染器列表是在启动时扫描的，**装完插件不重启启动器，列表就不会刷新**。社区教程里的标准说法叫「大退」——从多任务列表里把启动器彻底划掉，再重新打开。做完这一步再去渲染器列表里找，选项基本都会出现。

还有一个前置条件别漏掉：插件得真正装进系统（能从桌面打开 MobileGlues 图标），只把 APK 下载到手机里是不算数的。

另外，列表里你还会看到 Holy、Zink、LTW 这些别的渲染器名字——它们与 MobileGlues 各自适合什么设备和版本，取舍写在 [Zink与Holy渲染器对比.md](Zink与Holy渲染器对比.md) 里。

## 二、FCL（Fold Craft Launcher）里的切换路径

1. 打开 FCL，进入左侧的「游戏设置」（扳手图标那一栏）；
2. 在设置列表里向下滑，找到「渲染器」一项，点它旁边的选择按钮；
3. 弹出的渲染器菜单里继续向下滑，列表比较长，MobileGlues 排在靠后的位置——社区里有人把它截图成 "mobile glues" 又找不到，其实就是全称这一条；
4. 点选 MobileGlues 即可，选择会自动保存。

FCL 里渲染器有两个改的地方：单个游戏实例的「游戏设置」，以及启动器级的「全局游戏设置」。如果你玩的是带版本隔离的整合包，改实例那一层就够了；只有直接玩没有隔离的原版目录时才需要动全局。社区里的老玩家普遍建议**优先改实例设置、少动全局**，避免影响其他实例。

## 三、ZalithLauncher 2（ZL2）里的切换路径

1. 彻底退出并重新打开 ZL2（原因同上）；
2. 点右上角齿轮进设置，找到「全局渲染器」，展开后选中 MobileGlues；
3. 也可以按实例来改：点该实例的齿轮 → 配置（Configure）→ 渲染器选 MobileGlues；
4. 社区优化包的说明里还提到一步：进 MobileGlues 的渲染器设置，把 MultiDraw 模拟方案选为 prefer multidraw indirect，这一步在多数设备上对帧数有帮助（详见 [渲染参数调整指南.md](渲染参数调整指南.md)）。

## 四、两个启动器的路径对照

| 启动器 | 入口 | 选择项位置 |
| --- | --- | --- |
| FCL | 游戏设置 → 渲染器 → 选择按钮 | 列表向下滑，点 MobileGlues |
| ZL2 | 设置 → 全局渲染器（或实例 → 配置） | 下拉列表选 MobileGlues |

## 五、切换之后怎么确认生效

切完启动一个世界，两个信号说明它在正常工作：

- 游戏能稳定进入世界、没有立刻闪退或黑屏（闪退黑屏的排查在 [常见报错排查.md](常见报错排查.md)）；
- 在支持的环境下，MobileGlues 可以上报 Minecraft 的 GPU 占用百分比，测试光影或调参数时可以留意这个读数。

确认渲染器正常后，下一步通常是开光影或装 Sodium，前提条件与兼容情况见 [光影包支持与开启条件.md](光影包支持与开启条件.md)。
