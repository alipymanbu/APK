## 一、提示「无法加载 MG 配置文件」

这是被提及最多的一类报错，根因是插件没有拿到改写配置所需的系统权限。社区教程给出的处理路径是走无线调试（ADB）授权：

1. 进系统设置，打开开发者选项里的「无线调试」；
2. 打开 MobileGlues 插件，按它的引导进入权限设置界面；
3. 在开发者选项中勾选无线调试相关的授权项并确认，部分机型需要输入 `adb tcpip 5555` 这类命令启用无线调试模式；
4. 等系统完成设置后返回插件，重新进入权限设置完成配对。

不同品牌系统的开发者选项位置与命名差异很大，上面是通用思路；如果插件自带引导页，优先照引导页走。授权成功后报错即消失，不需要重装。

## 二、启动器渲染器列表里找不到 MobileGlues

按顺序检查三件事：

1. 插件是否真的**安装**了（桌面能打开），而不是只下载了 APK；
2. 启动器是否在安装插件之后**彻底重启**过——渲染器列表只在启动器启动时扫描，这是最高频的原因；
3. 列表是否滑到底，MobileGlues 在列表偏后的位置，全称就是 MobileGlues 本身。

还没装插件的话，从 [下载与安装教程.md](下载与安装教程.md) 开始。

## 三、进游戏闪退或黑屏

依次排查：

| 检查项 | 判据 |
| --- | --- |
| 游戏版本 | 1.16.5 及以下基本跑不了，社区口径是 1.17 起才支持；旧版本游戏请换 Holy 这类老方案（对比见 [Zink与Holy渲染器对比.md](Zink与Holy渲染器对比.md)） |
| GPU 能力 | 设备需支持 OpenGL ES 3.0（推荐 3.2），太老的机器会直接黑屏 |
| 光影干扰 | 先关光影进一次游戏，能进说明是光影问题，回去看光影兼容性 |
| 参数改动 | 还原 MultiDraw、ANGLE 两项到默认，再逐项试回 |

## 四、渲染花屏、色块闪烁

先在游戏视频设置里把光影预设降到最低；还花就暂时关光影确认基础画面正常，然后换一个轻量光影（如 BSL 低预设、MakeUp-UltraFast）验证。这类问题多半是「某个光影 × 某类 GPU」的兼容组合问题，官方矩阵里同一光影在不同设备上的结论差异就是证据。参数层面的对应调整见 [渲染参数调整指南.md](渲染参数调整指南.md)。

## 五、查日志定位问题

MobileGlues 的运行日志固定写在设备的 `/sdcard/MG/latest.log`。开着「忽略着色器/程序错误」进一次出问题的场景，再翻这个文件，里面会记下具体是哪条着色器或指令出错——拿着这段日志去社区或项目 issue 区提问，能少绕很多弯路。

## 六、怀疑装到假包

官方正式版发布在 GitHub 的 MobileGL-Dev 组织下，安装包带官方签名（证书 DN 为 `CN=MGDev`，可用 `apksigner verify --print-certs` 核对）。从非官方渠道拿到的包对不上这个签名时，不要使用，回到官方发布页或本文开头给出的安装文件资源重新获取。
