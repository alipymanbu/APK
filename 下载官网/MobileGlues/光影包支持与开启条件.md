# MobileGlues 光影包支持与开启条件

> 本篇讲在 MobileGlues 下开光影需要满足什么条件、哪些光影包被官方矩阵测过、同一光影在不同手机上表现差在哪。

## 一、开光影的两个前提

1. **渲染器已经切到 MobileGlues**。没切换的话，后面所有步骤都无从谈起，切换方法见 [启动器渲染器切换方法.md](启动器渲染器切换方法.md)。
2. **游戏侧要有一个光影加载器**：Iris（Fabric/NeoForge 生态常用）或 OptiFine。光影包本体不直接挂在 MobileGlues 上，而是由这两个加载器加载，MobileGlues 负责把光影的桌面 GLSL 着色器转换成手机能跑的 GLSL ES——包括自动去掉 `layout(binding)` 语法、补齐精度声明这类转换，你不需要手动改光影文件。

## 二、官方矩阵里测过的光影包

MobileGlues 官方仓库维护着一份光影支持矩阵（ShaderSupportMatrix），由不同设备的用户实测回填。截至本文写作时，矩阵覆盖的光影和整体状态大致如下（同一光影在不同设备上结论不同，表里只给大方向，明细以官方矩阵为准）：

| 光影包 | 矩阵里的整体表现 |
| --- | --- |
| BSL / BSL Classic | 测过的设备里基本全绿，各预设均可跑 |
| MakeUp-UltraFast | 基本全绿，轻量，低配机优先考虑 |
| Chocapic13 V6 Lite | 大多数设备可用 |
| iterationT | 大多数设备可用，个别机型黑屏 |
| Photon | 分化明显：新旗舰可用，部分 Mali/老机型闪烁色块或渲染错误 |
| Complementary Reimagined / Unbound | 部分机型完整可用，部分机型「无任何效果」或加载不出最高预设 |
| SEUS PTGI HRR3 | 重量级，只有部分旗舰能跑，且多带小毛病 |
| Lux / Derivative | 测过的设备多数可用 |

从这张表能读出的实用结论：

- **求稳**选 BSL、MakeUp-UltraFast 这类在大量设备上验证过的；
- **求效果上限**再考虑 Complementary、SEUS 这类，同时做好「带不动就换」的预期；
- 想确认自己机型的情况，直接查官方矩阵里的设备行（按设备代号搜索），或在 [渲染参数调整指南.md](渲染参数调整指南.md) 里调 MultiDraw 等参数后再试。

## 三、光影包从哪拿

常见的两个下载渠道是 [Modrinth](https://modrinth.com/shaders) 和 [CurseForge](https://www.curseforge.com/minecraft/search?search=shader) 的光影分区。下载时留意光影包标注的加载器要求（Iris 还是 OptiFine）和 Minecraft 版本范围，跟你的实例对得上再装。

## 四、开了之后不对劲怎么办

- **花屏、色块闪烁**：先把光影切到最低预设看是否恢复；恢复不了就换一个光影验证是光影本身的兼容问题还是设备问题。矩阵里 Photon 在部分机型上的表现就是典型例子。
- **帧数骤降**：降渲染距离、换轻量光影（MakeUp-UltraFast、BSL 低预设）。
- **游戏直接黑屏**：先关光影确认基础渲染是否正常，再按 [常见报错排查.md](常见报错排查.md) 的思路查版本与 GPU 支持。
