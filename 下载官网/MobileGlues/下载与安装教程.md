## 一、装之前先确认三件事

MobileGlues（社区里常叫「MG 渲染器」「我的世界 FCL 渲染器」）**不是游戏本体**，它是一个运行在安卓设备上的图形渲染层插件，作用是把我的世界 Java 版发出的桌面 OpenGL 图形指令，翻译成手机 GPU 能执行的 OpenGL ES 指令。名字的含义就是 "(on) Mobile, GL uses ES"。

1. **手机上得先有一个能跑 Java 版的启动器**。常见的搭配是 Fold Craft Launcher（FCL）或 ZalithLauncher 2（ZL2），没有启动器的话，装了 MobileGlues 也无处可用。
2. **设备 GPU 要支持 OpenGL ES 3.0**，官方推荐 ES 3.2。近几年的手机基本都满足，很老的机器可能会黑屏或闪退。
3. **游戏版本要在 1.17 及以上**。多个社区教程都提到它只支持较新版本，1.16.5 及更早的版本请用启动器自带的旧渲染器方案。

另外提醒一句：官方在 GitHub 上持续更新，版本号一直在往前走；网盘里这份是 **1.3.4**，写作本文时官方发布页的版本已经比它新。功能上大方向一致，具体以 [官方发布页](https://github.com/MobileGL-Dev/MobileGlues-release/releases) 显示为准。

## 二、获取安装包并安装

1. 打开 [MobileGlues 安装文件资源（夸克网盘）](https://pan.quark.cn/s/87f0238fa8be)，转存后下载里面的 APK 文件。
2. 在系统弹窗里允许「安装未知来源应用」（路径因系统而异，一般在安装时按提示跳转授权即可）。
3. 安装完成后，桌面上会出现 MobileGlues 的应用图标。

网盘里这份安装包的核对信息如下，担心文件对不上时可以比一下：

| 大小 | 10.71M |
| MD5 | 6AB4C76A0769303EE09D9FD19580A487 |

## 三、认准官方发布的两个特征

MobileGlues 是开源项目（LGPL-2.1 协议），代码和正式版安装包都发布在 GitHub 的 MobileGL-Dev 组织下；官方还有一个介绍站 [mobileglues.com](https://mobileglues.com/)，功能说明与下载入口都指向官方项目。如果你在别处下载过安装包、想确认是不是官方出品，官方 README 给了签名校验方法：用 Android build-tools 里的 `apksigner` 查看证书，官方正式版的证书 DN 为 `CN=MGDev, OU=MGDev, O=MGDev`。对不上就不建议继续使用。

## 四、装完之后的第一步

装好插件后**先别急着打开它**：

1. 彻底退出启动器（从多任务列表里划掉，俗称「大退」），再重新打开——渲染器列表只有在重启后才会刷新；
2. 到启动器的渲染器设置里找到并选中 MobileGlues，具体路径在 [启动器渲染器切换方法.md](启动器渲染器切换方法.md) 里分启动器写清楚了；
3. 首次运行插件或启动器时如果弹「无法加载 MG 配置文件」之类的提示，属于权限没给够，处理步骤见 [常见报错排查.md](常见报错排查.md)。
