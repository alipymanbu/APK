## 一、基本信息

| 项目 | 参数 |
| --- | --- |
| 产品名称 | 灵童念 NIA-F01（官方与媒体报道里也叫「小念」） |
| 产品类型 | 桌面级 AI 具身人形机器人 |
| 开发商 | 灵童机器人（上海）有限公司 |
| 身高 | 56 厘米（约人类的三分之一大小） |
| 裸机重量 | 不超过 700 克 |
| 皮肤材质 | 软质 PVC |
| 骨架材质 | ABS 与金属 |
| 自由度 | 最高 34 个自由度（自研 6-8 毫米微型数字伺服舵机） |

两个常见的口径差异，核对参数时留意：

- **自由度**：多数报道称「最高 34 个自由度」，另有报道称机体内集成了 35 台定制超迷你关节电机——两种口径都有出处，以官方页面为准；
- **重量**：裸机不超过 700 克是官方口径；有报道称整机（含衣物等）重量不到 1.2 千克，差别在于算不算穿戴件。

官网另有「念 · NIA-FR02」的展示页（约 60 厘米），属于该系列的后续型号，与璇玑蛋（N-E03）的定位区别见[璇玑蛋与NIA系列型号区别.md](璇玑蛋与NIA系列型号区别.md)，参数以官网当时页面为准。

## 二、感知与交互硬件

- 双目摄像头：识别使用者的面部微表情与周边环境；
- 矩阵麦克风：捕捉语音与语气中的情绪；
- 多模态大模型配合情绪动作库，构成「感知—理解—回应」的交互闭环；
- 情感共鸣引擎（ECE）：根据语音语调与表情变化匹配相应的动作与情绪表达。

机器人的人设、音色与动作库向用户开放自定义，具体玩法见[外观与魂卡自定义玩法.md](外观与魂卡自定义玩法.md)。
