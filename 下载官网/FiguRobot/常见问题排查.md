下面的问题按「装不上 → 登不上 → 连不上 → 用着不对」排列，都是先给出可操作的处理顺序，再说明原因。涉及具体政策（价格、型号、售后）的问题，直接找官方渠道确认，联系方式见[NIA-F01机器人参数一览.md](NIA-F01机器人参数一览.md)。

## 一、APK 装不上或装完打不开

按顺序核对：

1. 安装包是否完整：对照 MD5（E12BC07ACB51C8CAB9972C1BB5257101）核对文件是否下载完整，不完整就重新下载；
2. 未知来源权限：系统设置里允许对应来源安装 APK；
3. 存储空间：安装包 28.05 MB，但安装过程需要更多临时空间，留出至少几百 MB 余量；
4. 装完闪退：重启手机再开一次；仍闪退时确认系统版本满足安装包标注的要求（「安卓 5.2 以上」，以官方渠道说明为准）。

安装与登录的基础流程见[下载与安装教程.md](下载与安装教程.md)。

## 二、登录不上

1. 收不到验证码：检查手机号是否输错、短信是否被拦截；等一分钟后再点重发；
2. 密码错误：确认没开大写锁定；忘记密码走登录页的找回入口；
3. 注册收不到回应：换个网络环境（Wi-Fi 与流量切换）再试；
4. 登录成功但功能空白：先完成蓝牙连接，多数功能要在连接机器人之后才可用，见[连接机器人蓝牙配对.md](连接机器人蓝牙配对.md)。

## 三、蓝牙搜不到机器人或频繁断开

1. 搜不到：确认机器人已开机有电、手机蓝牙权限已授予、两者距离够近；把手机蓝牙关开一次再搜；
2. 频繁断开：远离正在使用蓝牙的耳机、音箱；中间不要隔着墙体；
3. 换设备验证：有条件时用另一部手机登录同一账号试连，判断问题在手机还是在机器人；
4. 核对设备型号：璇玑蛋（N-E03）按官方规格走 Wi-Fi 联网，不走蓝牙配对，型号区别见[璇玑蛋与NIA系列型号区别.md](璇玑蛋与NIA系列型号区别.md)；
5. 以上都试过仍不行：联系官方客服（400-997-8611，工作日 09:00-18:00，以官网联系页为准）。

更完整的配对步骤与连接状态说明见[连接机器人蓝牙配对.md](连接机器人蓝牙配对.md)。

## 四、电量与充电提醒

App 会显示机器人电量并在偏低时提醒充电。收到提醒后尽快安排充电，避免互动中断电；长期不用时也建议保持一定电量再收纳。充电器规格与充电时长以官方说明书为准。

## 五、版本与更新问题

| 问题 | 处理 |
| --- | --- |
| 网盘里是 1.3.7，网上说有更新版 | 版本随时间推进，新版本以官方发布渠道为准；本篇安装包信息以本地记录为准 |
| 更新后设置丢失 | 重新登录后再检查；官方资料提到记忆迁移功能可把历史数据转到新设备 |
| 想确认当前版本 | App 内的「关于/设置」页查看版本号，应为 1.3.7 或更高 |

个性化设定相关的问题（外观、魂卡、音色）见[外观与魂卡自定义玩法.md](外观与魂卡自定义玩法.md)。
