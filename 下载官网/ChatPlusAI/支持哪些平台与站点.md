ChatPlusAI 把多个电商平台和渠道的买家消息接到一个后台处理，但「能接哪些」和「哪些站点接不了」是必须先确认的事——加店铺才发现不支持，等于白配一遍。平台清单会随官方接入进度变化，本篇给出的是撰写时官方页面列出的范围。

## 一、目前已接入的平台

官方站点列出的接入对象如下：

| 平台 / 渠道 | 类型 | 常见卖家场景 |
| --- | --- | --- |
| TikTok Shop | 电商平台 | 直播与短视频带货店铺 |
| Shopee | 电商平台 | 东南亚多国站点 |
| Lazada | 电商平台 | 东南亚多国站点 |
| Tokopedia | 电商平台 | 印尼市场 |
| Shopify | 独立站 | 自有站点客服 |
| Mercado Libre | 电商平台 | 拉美市场 |
| Kwai | 短视频 / 电商 | 拉美等市场 |
| WhatsApp | 即时通讯 | 客户在站外找上门 |
| Facebook | 社媒 | 主页私信与评论咨询 |

两点提醒：

- **清单会变。** 官方页面在不同位置列出的接入对象略有出入（较早的说明里只写了电商平台），新增或调整随时可能发生，动手前先看官网当页的接入列表。
- **接的是平台，不是「所有同类平台」。** 表里没有的平台，不代表「迟早能接」，也不代表能用别的方式硬接——官方走的是各平台的官方接口，接口不开就接不了，下一节的例子就是。

## 二、站点限制：以 Shopee 台湾站为例

官方明确写过一条：**Shopee 台湾站由于平台接口未开放，暂不支持**。这条透露了一个判断方法：

- 能不能接，取决于**该平台在该国家/地区站点上的接口是否开放**，而不是这个平台本身支不支持。
- 所以同一个平台，A 国站点能接、B 国站点可能接不了。加店铺前先确认你要接的具体站点。
- 遇到「这个站点加不进来」，先在官方文档或客服那里确认是接口未开放，而不是自己配置错了。

按官方说明，这套系统覆盖的是**东南亚、北美和拉美**方向的市场，与上表的平台分布一致。

## 三、能处理哪些语种

官方说明系统当前支持 8 种语言，可随时切换：

- 印尼语、菲律宾语、泰语、越南语
- 英语、西班牙语、葡萄牙语
- 中文

对客服的实际意义是：**买家用什么语发来，你可以在中文界面下读懂并回复，系统负责来回翻译**。翻译相关的工具与开关在接待界面里，用法见 [多店铺消息聚合与客服分派.md](多店铺消息聚合与客服分派.md)；翻出来的话不准时怎么处理，见 [常见问题与排查.md](常见问题与排查.md)。

## 四、官方接口对接意味着什么

这一点会直接影响你「敢不敢把店铺接进去」，值得单独说清：

| 你担心的 | 官方口径 |
| --- | --- |
| 要不要把平台账号密码给它 | 不要。授权在平台官方页面完成，它拿到的是可撤销的授权凭证 |
| 多店铺会不会被判关联 | 官方说明基于官方 API 接入，不存在关联风险 |
| 日常接待要不要固定网络出口 | 不要。官方说明接待阶段无需本地 IP；但**添加店铺的授权动作是在平台卖家中心完成的，那一步仍要用你平时登卖家中心的同一 IP 环境**，见 [注册登录与添加店铺.md](注册登录与添加店铺.md) |
| 会不会漏消息 | 消息按官方接口同步，不再需要人工盯各个平台的卖家后台 |

这几点是官方说法，购买前建议用免费试用自己跑一遍再决定，见 [套餐计费与免费试用.md](套餐计费与免费试用.md)。

## 五、怎么确认你的店铺能接

按这个顺序查一遍，能省掉后面的返工：

1. 你的平台在不在第一节的表里；
2. 你的站点有没有被官方点名不支持（如 Shopee 台湾站）；
3. 你的买家消息里有没有需要处理的小语种，是否在第三节的 8 种之内；
4. 你的团队有几个人要同时接待——店铺数量不限，但工作子账号受套餐限制，见 [套餐计费与免费试用.md](套餐计费与免费试用.md)。

四项都过了，就可以按 [注册登录与添加店铺.md](注册登录与添加店铺.md) 把店铺接进来。
