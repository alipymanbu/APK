自动跟单处理的是另一种场景：买家并没有来问，但订单状态在变，需要有个人在合适的时点推他一把或者安抚一下。ChatPlusAI 把这套动作做成按场景自动触达，从催下单一直到催好评都覆盖。本篇讲清有哪些场景、额度怎么算、以及怎么开才不出乱子。

## 一、跟单覆盖的场景

官方把跟单拆成一组可按需开启的场景，常见的有：

| 阶段 | 场景 | 触发的大致时机 |
| --- | --- | --- |
| 售前 / 售中 | 催下单 | 买家咨询过、加购或犹豫但没下单 |
| 售前 / 售中 | 催付款 | 订单已生成但未付款 |
| 售中 | 订单确认关怀 | 付款完成后确认订单信息 |
| 售中 | 缺货提醒 | 备货出现缺货需要告知 |
| 物流 | 延迟发货关怀 | 超出承诺时效还没发出 |
| 物流 | 发货关怀 | 包裹发出后告知物流信息 |
| 物流 | 提醒签收 | 包裹接近送达或已到驿站 |
| 物流 | 再次派送提醒 | 首次派送失败后的再次派送 |
| 售后 | 使用引导（签收后） | 签收后引导使用，降低因不会用产生的差评 |
| 售后 | 退单 / 退货退款挽回 | 买家发起取消、退货、退款时尝试挽回 |
| 评价 | 催好评 / 好评关怀 / 好评自动回评 | 交易完成后争取与维护好评 |
| 评价 | 中差评自动挽回 / 中差评自动回评 | 出现中差评时第一时间介入处理 |

官方说明这套场景覆盖的是「从售前到售后」的全链路，不同版本的说法略有差异（一处写 28 个场景、一处写全场景订单自动挽回含 19 个场景），**以你后台里实际能勾选的场景清单为准**。

其中退单挽回有一个时间敏感的点：官方把退款、退货挽回落在一个很短的窗口内处理，越早介入成功率越高——这类场景开起来比人工盯守更划算。

## 二、额度怎么算（容易误解的一处）

跟单的计费单位不是消息条数，而是**服务买家数**：

- **所有跟单场景共享同一个买家数池子**，不是每个场景各有一份额度。催付款用掉一个买家，催好评就不会再重复计同一个买家。
- **额度按月刷新**，按北京时间每月 1 日 0 点重置。
- 不同套餐的每月买家数不一样，从几千一直到不限，档位对照见 [套餐计费与免费试用.md](套餐计费与免费试用.md)。

所以估额度时要按**当月触达过的去重买家总数**去算，而不是按订单数或消息数算。多店铺叠加时，几家店的买家会一起进这个池子。

## 三、按这个顺序开更稳妥

不建议一次性全开。推荐的开启顺序：

1. **先开低风险、和钱直接相关的**：催付款、订单确认关怀、发货关怀、提醒签收。这几类触达理由充分，买家一般不会反感。
2. **再开挽回类**：退单、退货退款挽回、中差评挽回。这类越早介入越有用，但话术要自己过一遍，别用默认的硬推销语气。
3. **最后开好评类**：催好评、好评关怀。这类最容易被当成骚扰，建议控制频次，并且避开买家刚投诉过的订单。
4. **使用引导这类辅助场景**按品类决定要不要开：教程类、需要组装的产品收益明显，标准快消品可以不开。

## 四、开之前要知道的几条边界

- **同一买家被反复触达会适得其反。** 买家数按去重算不代表可以无限制地打扰同一个人，场景之间要错开频次。
- **营销性触达受平台规则约束。** 各平台对卖家主动发消息都有规范，触达内容与频次要留出余地，别把催付做成刷屏。
- **跟单不能代替接待。** 买家一旦回消息，就落回到会话里，该由 AI 或人工接着答，见 [AI客服机器人怎么设置.md](AI客服机器人怎么设置.md)。
- **退单挽回不是承诺。** 官方给的是挽回率提升口径，实际能挽回多少取决于商品、物流和话术，别按「开了就不丢单」预期。

## 五、怎么判断跟单有没有起作用

后台的数据中心提供配套指标，看这几项就够了：

| 指标 | 看什么 |
| --- | --- |
| 销售转化自动计算 | 接待与跟单带来的转化趋势 |
| 订单损耗分析 | 各阶段丢了多少单、主要丢在哪个成因上 |
| 行业水平 | 和同站点同行业相近经营方式的同行比处在什么位置 |

发现某个场景开了很久但损耗没降，先回头看第三节的顺序和话术，而不是继续加场景。这三项指标具体怎么读、怎么对到人和场景，见 [客服绩效与数据看板怎么看.md](客服绩效与数据看板怎么看.md)。

## 六、另一项自动化能力：AI 促销机器人

除了按订单状态触达的跟单，还有一项按「活动」计数的自动化——官方定价页把它叫 **AI 促销机器人**，用来推广店铺的各类促销活动，官方站点对它的描述是「掌握产品卖点与店铺活动、7x24 小时把握销售时机」。需要知道的几点：

- **计费按活动次数，不按买家数。** 官方说明「每新增 1 个促销活动计为 1 次使用」，各档每月给的次数不同（个人版给的次数最少，中级档位起不限次），对照见 [套餐计费与免费试用.md](套餐计费与免费试用.md)。
- **它和跟单是两个池子。** 促销次数用完了不影响跟单的每月买家额度，反过来也一样。
- **内容要自己把关。** 促销推广属于主动营销，平台的营销消息规则、你所在市场的合规要求都要先过一遍，别让活动文案跑在规则前面。

## 七、大促期间怎么安排

大促是跟单收益最集中、也最容易翻车的时候，按这个顺序提前准备：

1. **提前确认额度够不够。** 大促当月触达的去重买家数会明显高于平时，先把上个月的量拿出来对照套餐档位，不够就提前升级，别等月中才发现额度用尽。
2. **把跟单场景按优先级排一遍。** 催付款、订单确认、发货关怀优先保；使用引导这类辅助场景可以临时关掉，把额度让给直接影响成交的场景。
3. **人工重点盯高价值买家。** 强提醒只留给真正需要马上处理的会话，把人工从常规接待里省出来，用法见 [多店铺消息聚合与客服分派.md](多店铺消息聚合与客服分派.md)。
4. **大促结束后做一次复盘。** 看损耗落在哪一段、成因分布有没有变化，见 [客服绩效与数据看板怎么看.md](客服绩效与数据看板怎么看.md)。
