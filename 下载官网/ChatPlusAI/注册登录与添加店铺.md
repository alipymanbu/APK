# ChatPlusAI 注册登录与添加店铺

> 本篇讲账号怎么注册登录、店铺要怎么接进来，以及授权环节最容易踩的 IP 问题。

ChatPlusAI 支持手机号或邮箱注册，注册成功即为超级管理员；登录可以用短信验证码，也可以设密码后账号密码登录。有一步绕不过去：**首次登录必须添加至少一个店铺**，否则进不到主界面——店铺接不进来，这套系统就没有消息可接。

## 一、注册：手机号或邮箱都行

1. **在登录页找「立即注册」**：手机端会跳到浏览器里完成注册，电脑端在登录页左下角。
2. **选手机号或邮箱**：两种都支持，按你顺手的一种填。
3. **邀请码不是必填**：有就填，没有直接跳过。
4. **注册成功默认就是超级管理员**：这个账号管店铺、管员工、看全部数据，别拿它当日常接待账号用。
5. **密码可以后补**：用手机号注册时没设密码，属于正常。先按第二节把店铺加上，之后点左栏顶部头像 → 用户信息，在那里设置密码。

## 二、登录：验证码或账号密码

登录页给两种方式，任选其一：

| 方式 | 怎么用 | 适合谁 |
| --- | --- | --- |
| 手机号 + 短信验证码 | 填绑定手机号，收验证码填入 | 刚注册、平时用手机接待 |
| 账号 + 密码 | 用注册的账号与后补的密码登录 | 电脑上长期挂着、不想每次收验证码 |

两个已知行为：

- **没加店铺会被强制跳去加店铺页**，进不了主界面。这是设计如此，不是账号出问题。
- **换设备不用重新注册**：手机端、电脑客户端、网页后台登的是同一套数据，店铺、会话、配置都跟着账号走。

## 三、添加店铺：四步走完

在店铺管理入口点「添加店铺」，按顺序：

1. **选平台**：从已支持的平台里选要接的那一个，清单见 [支持哪些平台与站点.md](支持哪些平台与站点.md)。
2. **选所属部门 / 分类**：把店铺归到某个部门下，后面按部门分配客服、看绩效都依赖这一步，别随手乱放。
3. **在平台卖家中心完成授权**：ChatPlusAI 需要向平台申请订单、商品、物流、推广等数据的读取权限，并额外授权 ERP 相关数据——因为它不只回消息，还要跟进评价、退货退款这类行为。**授权动作不在 ChatPlusAI 里，而是在平台卖家中心完成。**
4. **回来确认店铺出现**：授权完成后店铺会出现在店铺列表里，该店铺的买家消息随后开始同步。

手机端也能走完这套流程；但授权那一步要跳到平台卖家中心页面，手机浏览器偶尔会遇到页面不适配，**店铺多、账号多时建议在电脑上一次性加完**，手机端留着日常接待。

## 四、授权环节的 IP 注意事项（重点）

官方的用户手册专门提醒过这一点，而它恰好是最容易被忽略的坑：

- **接待阶段没有 IP 要求。** 日常看消息、回消息走的是官方授权接口，在任何能联网的环境下都能用，不需要给设备单独配网络出口，官方也说明不存在店铺关联风险。
- **但授权阶段有。** 因为添加店铺要在**平台卖家中心**里操作，而卖家中心的登录本身是有 IP 风控的。所以：**添加店铺时，用你平时登录该店铺卖家中心的那个网络环境**（同一台电脑、同一条线路），不要在临时网络、公共网络或代运营的陌生 IP 下加店铺。
- **授权完成之后就自由了。** 一旦加店铺成功，后续接待换到哪里都行。

一句话：**加店铺挑环境，加完之后随便用。**

## 五、工作子账号：一个管理员加若干客服

账号体系是「超级管理员 + 工作子账号」的结构：

| 角色 | 数量 | 典型用法 |
| --- | --- | --- |
| 管理员（超级管理员） | 1 个 | 加店铺、加员工、分店铺、看全部数据 |
| 工作子账号（员工） | 随套餐档位不同，从 1 个到 20 个不等 | 只管分配给自己的店铺和会话 |

要点：

- **工作子账号数量由套餐决定**，不是想加多少加多少。官方年付页的档位是 1 / 2 / 4 / 6 / 9 / 20 个递进，档位差别见 [套餐计费与免费试用.md](套餐计费与免费试用.md)。
- **加员工和分店铺一般在电脑客户端或网页后台做**，手机端更适合日常接待。会话怎么优先落到谁那里，规则见 [多店铺消息聚合与客服分派.md](多店铺消息聚合与客服分派.md)。
- **「智能任务分配」与客服绩效报告从初创版起才开放**，人少时手动分也够用；人一多这两项几乎是必需的。绩效怎么读，见 [客服绩效与数据看板怎么看.md](客服绩效与数据看板怎么看.md)。
- **一人只管自己名下的店铺**，绩效才有办法按人算。
- **有人离职时，先把他名下的店铺重新分配给接手的人**，再收回账号，别让店铺悬在一个不再登录的账号上。

## 六、加不上、登不进时的常见处理

| 现象 | 检查顺序 |
| --- | --- |
| 收不到短信验证码 | 确认手机号没填错、信号正常；换一个时点重发；安全软件拦截先关掉试试 |
| 登录后被弹回加店铺页 | 属于正常行为，账号下还没有成功授权过店铺，先把店铺加上 |
| 忘记密码 | 用手机号验证码登录后，到「头像 → 用户信息」里重设 |
| 登录后会话列表空白 | 先确认店铺是否加成功、店铺是否处于离线状态 |
| 添加店铺到授权页就卡住 | 换回平时登卖家中心的电脑与网络环境重试；先在浏览器确认卖家中心能正常登录 |
| 店铺刚加完就显示离线 | 多为授权失效或被平台侧解除，重新走一次授权流程 |
| 同事登进来什么都看不到 | 检查店铺有没有分配给他，以及他拿的是不是工作子账号 |
| 想换绑定手机号 | 属于账号信息变更，走官方客服处理，不要在应用里反复试 |

店铺接进来之后，下一步是把 AI 接待和跟单开起来，见 [AI客服机器人怎么设置.md](AI客服机器人怎么设置.md) 与 [智能跟单与催单催付怎么用.md](智能跟单与催单催付怎么用.md)。
