这套系统的链路是「客户端 → 平台授权接口 → 卖家店铺」，出问题时先判断断在哪一段，比逐个功能瞎试快得多。下面按环节列出常见现象与排查顺序。

## 一、登录与账号

| 现象 | 排查顺序 |
| --- | --- |
| 收不到短信验证码 | 核对手机号是否填错；换时点重发；手机安全软件 / 运营商拦截先关掉试试 |
| 忘记密码 | 用手机号验证码登录后，到左栏顶部头像 → 用户信息里重设 |
| 登录后总被弹去加店铺页 | 正常行为。账号下一个店铺都没授权成功时，加店铺这步无法跳过，见 [注册登录与添加店铺.md](注册登录与添加店铺.md) |
| 工作子账号登进来看不到任何店铺 | 先确认超级管理员有没有把店铺分配给他，再看他的角色是不是工作子账号 |
| 换手机登录后数据不一样 | 确认登的是同一个手机号；换设备不会丢数据，登错号才会「看起来少了」 |
| 想改绑定手机号 | 属于账号信息变更，联系官方客服处理，不要自行反复注册新号 |

## 二、店铺与授权

| 现象 | 排查顺序 |
| --- | --- |
| 添加店铺在授权页卡住 | 先在浏览器里确认该店铺的卖家中心能正常登录；换回平时登卖家中心的电脑与网络环境重试 |
| 提示不支持该站点 | 部分站点平台接口未开放（如 Shopee 台湾站），以官方支持清单为准，见 [支持哪些平台与站点.md](支持哪些平台与站点.md) |
| 店铺显示离线 | 多为授权失效或被平台侧解除，重新走一次授权流程即可 |
| 加完店铺消息不来 | 确认店铺状态是否在线；确认这家店确实有新消息；平台侧接口偶尔延迟，等几分钟再看 |
| 加店铺时提示有风险 / 被拦 | 大概率是当前网络环境与平时登卖家中心的不一致，换回常用环境再试 |

**这一类问题多数出在网络环境上**：接待阶段用哪个网络都行，但加店铺这一步必须在平台卖家中心完成，且要用平时的那套环境。

## 三、消息与会话

| 现象 | 排查顺序 |
| --- | --- |
| 消息比平台后台晚到 | 先刷新会话列表；确认客户端网络正常；偶发延迟通常是平台接口侧，不是客户端丢了 |
| 手机端看到的和电脑端不一致 | 两端同步有极短延迟，下拉刷新即可；长期不一致先确认两端登的是同一个账号 |
| 有消息完全没进来 | 确认店铺是否仍在线、授权是否失效；店铺掉线期间的消息不会自动补进来 |
| 会话列表越来越乱 | 用买家星标标出重点、用打标归类，配合分流规则整理，见 [多店铺消息聚合与客服分派.md](多店铺消息聚合与客服分派.md) |
| 两个人重复回了同一句 | 分流规则没定好，按「按店铺优先」或「按订单优先」重新分一次 |

## 四、收不到提醒

按这个顺序查，基本能定位：

1. **系统通知权限给了没**：进「设置 → 应用 → ChatPlusAI → 通知」，把允许通知打开。
2. **有没有被电池优化杀掉后台**：把 ChatPlusAI 加进「不受限制」的应用列表，或在电池设置里允许后台活动。国产定制系统这一步尤其关键。
3. **应用内提醒开关开了没**：强提醒是分场景配置的，检查需要提醒的场景有没有勾上。
4. **是不是走了站外推送**：如果配了推到外部通讯软件，应用内可能就不高亮，去那个渠道看。
5. **重要消息本就少**：强提醒只覆盖特定场景，普通咨询没提醒属于正常。

## 五、AI 相关

| 现象 | 排查顺序 |
| --- | --- |
| 回答得不准 | 先补知识库 —— 大多数「AI 变笨」其实是知识库里没有对应问法，见 [AI客服机器人怎么设置.md](AI客服机器人怎么设置.md) |
| 该转人工的没转 | 检查服务边界有没有配置；涉及退款、纠纷、改单的问题应明确设为转人工 |
| 机器人不回复 | 确认 AI 接待开关是否开启、该时段是值班模式还是无人值守模式；部分 AI 能力与套餐档位相关，见 [套餐计费与免费试用.md](套餐计费与免费试用.md) |
| 买家觉得是机器人 | 话术里加一句人工兜底入口，或在关键节点主动转人工 |
| 跟单没触达 | 确认场景是否开启、当月买家额度是否用尽（额度按北京时间每月 1 日 0 点刷新） |
| AI 促销机器人没动作 | 它按「促销活动次数」计，额度用完当月不再触发；去套餐页核对当月剩余次数 |
| 翻译出来的话不准 | 小语种与行业术语最容易翻歪，关键信息（金额、地址、规格）发送前人工过一遍 |

## 六、客户端与设备

| 现象 | 排查顺序 |
| --- | --- |
| 打开就闪退 | 先清缓存重进；仍闪退就卸载后重新取包安装 —— [ChatPlusAI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/19cd3484ffe0) |
| 提示「解析包错误」 | 安装包没下完整，按 [下载与安装教程.md](下载与安装教程.md) 第二节重新取一份并核对体积 |
| 后台一会儿就断 | 电池优化把应用冻结了，加进白名单并允许后台运行 |
| 长时间挂机耗电明显 | 接待类应用要保持长连接，属正常范围；不需要随时接单的时段可以把值班交给电脑端 |
| 电脑端能上、手机端不行 | 手机网络问题居多，先用浏览器验证联网；企业网络限制也可能拦掉长连接 |

## 七、还是解决不了

先记下三样东西再去找官方支持，能少走很多来回：

1. **出问题的时间点**和当时的操作；
2. **具体报错文字或截图**（页面提示什么就记什么）；
3. **是哪个店铺、哪个平台、哪个站点**。

官方支持渠道以官网当页公示的为准，见 [www.chatplus.ai](https://www.chatplus.ai)。涉及账号解绑、换绑定手机号、套餐与发票这类事项，走官方客服比在应用里反复试更快。
