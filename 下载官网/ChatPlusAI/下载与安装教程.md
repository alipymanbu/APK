ChatPlusAI 是给跨境电商卖家用的 AI 客服工具：把 Shopee、Lazada、TikTok Shop 等平台的买家消息聚到一个后台，用 AI 机器人接待、自动翻译、自动跟单。这套系统同时有 Windows、Mac 客户端、网页后台和手机端，本篇只讲一个动作——把网盘里这份安卓包完整装进手机并登录成功。

## 一、先确认网盘里这份包是哪一版

应用商店页面显示的是官方当时的最新版，跟网盘里这份往往不是同一个版本号。本篇出现的版本号、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | ChatPlusAI |
| 版本号 | 1.15.9 |
| 包名 | `com.leyantech.mchatpp` |
| 安装包体积 | 74.14 MB |
| MD5 | `1D3C91B6934F970A2572641D4C099450` |
| 适用平台 | Android（手机端 APK） |
| 开发者 | 上海炯信信息科技有限公司 |
| 系统要求 | 本包页面标注「需要支持安卓系统 5.2 以上」，能否安装以安装时系统的提示为准 |

装之前先弄清五件事：

- **认包名，别只认图标和名字。** 跨境客服这一类的工具很多，名字相近的（AskChat、多客、Jekka 之类）都是另一套产品，店铺授权和账号互不相通。这份包的包名是 `com.leyantech.mchatpp`，装好后进「设置 → 应用 → 应用管理」点开 ChatPlusAI 就能看到。
- **版本号是三段式，迭代不算慢。** 官方按 `x.y.z` 递进，小版本更新很频繁：从 App Store 的版本记录看，1.15 系列从 1.15.10 一路更新到 1.15.29，跨度约一年。网盘里这份是 1.15.9，属于这一系列里更早的一版，不是商店页上那一版。
- **安卓包与 iOS 版的版本号不必一一对应**，核对版本时以本页表格为准；想跟本文记的事实对上就用网盘这份，要最新版就去官方渠道取。
- **手机端是「接待端」，不是全部。** 安卓和 iOS 客户端主要负责随时看消息、回消息、收提醒；店铺授权、员工与套餐这些配置项，电脑客户端和网页后台里更全。手机端登录的是同一个账号，见 [注册登录与添加店铺.md](注册登录与添加店铺.md)。
- **手机端要联网才能用。** 消息要跟平台实时同步，断网状态下打开的只是一份旧会话，回复也发不出去。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [ChatPlusAI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/19cd3484ffe0)，用手机夸克 App 打开最省事，也可以先转存到电脑再传到手机。
2. **先转存再下载**：选中安装包，转存到自己的网盘目录，再下载到本机。分享链接以后可能失效，转存过的那份不受影响。
3. **核对体积**：下载完成后看一眼文件体积，应当约 74.14 MB。中途断网重连后体积偏小的话，安装时往往会直接报「解析包错误」。
4. **想校验完整性**：在电脑上把包算一遍 MD5，结果应与上表一致（大小写不敏感）。

```cmd
certutil -hashfile ChatPlusAI_v1.15.9.apk MD5
```

文件名随版本变化，以实际提供的那个为准。

## 三、安装步骤

1. **给文件管理器开「安装未知应用」权限**：进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把用来打开 APK 的那个应用（文件管理器或浏览器）的开关打开。国产定制系统这一项常收在「安全」或「隐私」分类里。
2. **点击 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续，这是侧载安装包的常规提示。
3. **手机上已有更高版本时先卸载**：安卓不允许用低版本覆盖高版本，会直接报「应用未安装」。卸载会一并清掉本机登录状态与缓存，动手前确认没有还没处理完的会话。
4. **报「签名不一致」说明包名撞了**：手机里已经装过同包名的另一个来源版本，处理办法见本篇第五节的表。
5. **留出安装空间**：70 MB 多的包在安装时系统还要再展开一份，建议预留 300 MB 以上可用空间。

## 四、第一次打开要确认的三件事

1. **能联网**：ChatPlusAI 不能离线接待，会话列表、AI 回复、翻译都要联网才动得了。打开后卡在加载页，先用浏览器确认手机能正常上网。
2. **能登录进去**：第一次进入会先弹服务条款与隐私政策，同意后按提示用手机号加短信验证码登录。收不到验证码的处理见 [注册登录与添加店铺.md](注册登录与添加店铺.md)。
3. **放行通知权限**：不放开通知权限，买家新消息和 AI 需要人工接手的提醒都不会响。权限怎么补，见 [常见问题与排查.md](常见问题与排查.md)。

登录成功后如果店铺列表是空的，说明账号下还没绑定店铺——那是下一步的事，按 [注册登录与添加店铺.md](注册登录与添加店铺.md) 里的流程把售卖的店铺接进来，AI 才有消息可接。

## 五、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整 | 核对体积与 MD5，按第二节的步骤重新取一份 |
| 提示「应用未安装：签名不一致」 | 手机里已有同包名、不同来源的版本 | 先在应用管理里卸载旧包，再装这份 |
| 提示「应用未安装」且没有别的原因 | 系统版本低于该版本的要求 | 换一个系统要求更低的版本，或在更新的设备上装 |
| 安装被安全中心拦下 | 侧载包被系统安全策略拦了 | 在安全中心的拦截记录里选「继续安装」 |
| 点安装没反应 | 「安装未知应用」权限没给 | 回到第三节第 1 步补上权限 |
| 装完打开就闪退 | 系统版本过低、存储不足或包残缺 | 见 [常见问题与排查.md](常见问题与排查.md) |

以后换版本或者重装，按第二节的步骤重新取一份即可，安装动作与这次相同；重新登录后店铺与历史会话都在服务端，不用重新配。
