## 一、官方客服渠道：只认这两个

有票务疑问时，官方认可的客服入口只有两个：

| 渠道 | 账号 | 服务时间 |
| --- | --- | --- |
| LINE OA | `@theconcertapp` | 每天 10:00–20:00（曼谷时间 GMT+7），无休 |
| Facebook | [www.facebook.com/theconcertapplication](https://www.facebook.com/theconcertapplication) | 同上 |

演出官宣与动态走官方社媒账号（Instagram、TikTok 均为 `theconcertapplication`，X/Twitter 为 [twitter.com/the_concertapp](https://twitter.com/the_concertapp)），这些账号不处理客诉。

其他任何「客服」——私信你的、发图冒充工作人员的——都不是官方的。查询转票是否到账这类问题，也只通过上面两个渠道自查。

## 二、官方明说的三条防骗底线

The Concert 官方反复强调过三件事，遇到就对号入座：

1. **OTP 验证码打死不给任何人**。官方声明任何情况下都不会向用户索要 OTP；谁跟你要验证码，谁就是骗子。
2. **官方不会主动联系你「核验票据」**。客服没有主动找用户验票的流程，接到自称官方的电话或私信，直接忽略。
3. **平台转票是实时的，没有等待期**。「我已经转了，要等系统处理一下」是经典话术——真实系统里转票即时到账、即时通知，详见 [电子票入场与转票.md](电子票入场与转票.md)。

## 三、平台外交易的坑

- 官方不支持用户之间的私下买卖，票只认平台官方渠道卖出的；
- 「代拍店」「黄牛个人转让」不受任何保障：票可能被重复转卖、到现场刷不出来，钱票两空时官方无从介入；
- 官方在票务链条里的角色是销售中介，演出延期、取消这类变动以主办方公告为准，这也是只在官方平台出票才有维权起点的原因。

买票的正确路径始终是：App 或 [www.theconcert.com](https://www.theconcert.com/) 下单，流程见 [购票流程与支付方式.md](购票流程与支付方式.md)。

## 四、退款与取消

官方口径很明确：订单支付成功、E-Ticket 已经发出的，**不可取消、不可退款**。直播票同样适用。所以下单前把这三项核对清楚：日期场次、座位区域、票数。看错场次不是平台能补救的事。

## 五、常见问题速查

| 状况 | 处理 |
| --- | --- |
| 收不到 OTP 验证码 | 确认手机号/邮箱填对；短信收不到就改用邮箱注册，流程见 [注册与登录步骤.md](注册与登录步骤.md) |
| 选座后来不及付款 | 官方时限是从选座到付款只有 5 分钟，卡信息要提前备好，详见 [购票流程与支付方式.md](购票流程与支付方式.md) |
| 支付页面卡住或失败 | 换一种支付方式（国际卡 / PromptPay / TrueMoney / 支付宝），或切到网页版再试，渠道说明见 [购票流程与支付方式.md](购票流程与支付方式.md) |
| 找不到已买的票 | 进 App 的「我的票 / My Tickets」菜单查看 |
| 一部手机上有多张票 | 自己留一张，其余通过 App 内转票送给同行的人，不能共用一个二维码，操作见 [电子票入场与转票.md](电子票入场与转票.md) |
| 界面看不懂泰语 | 在设置里把语言切成中文，路径见 [下载与安装教程.md](下载与安装教程.md) |
| 疑似被骗 / 票没收到 | 立即通过第一节的官方渠道核实，不要继续和对方私聊交易 |
