# The Concert 购票流程与支付方式

> 本篇讲在 The Concert 上买演唱会门票的完整流程：怎么选演出和场次、坐票与站票的操作差异、支持哪几种支付方式，以及付完钱去哪里找票。

## 一、开抢前把三件事准备到位

1. **账号先注册好并保持登录**：注册流程见 [注册与登录步骤.md](注册与登录步骤.md)，没有账号在选座页面会被拦下来，热门票一分钟内就没了；
2. **网络要快**：官方的建议很直接——有快速的网络就能随时随地下单，抢票当天提前找个信号稳定的位置；
3. **提前看好场次**：同一场演出常有多个场次（不同的日期或时段），先想好要哪一场，开抢时少一次犹豫。

## 二、选演出与选票

1. 打开 App 或 [www.theconcert.com](https://www.theconcert.com/)，进入「演唱会 / Concerts」菜单；
2. 找到想看的演出点进去，先看清楚日期、场馆、票价档位和开售时间；
3. **多场次的演出先选场次**，这是最容易漏的一步；
4. 按票的类型继续（见下表）；
5. 确认订单，进入支付。

| 票型 | 操作方式 |
| --- | --- |
| 坐席票 | 先选区域（zone），再在座位图上选具体座位，按张数重复 |
| 站票 | 不用选座，直接选购买数量 |
| 多场次 | 在选票前先选好日期/时段 |

## 三、支付方式与 5 分钟时限

The Concert 平台支持的支付渠道如下。单场演出实际开放哪些渠道，以下单页显示为准：

| 支付方式 | 说明 | 适合谁 |
| --- | --- | --- |
| 信用卡 / 借记卡（Credit / Debit Card） | 常见的国际卡支付 | 有 Visa/Mastercard 等国际卡的用户 |
| QR PromptPay | 泰国的扫码支付 | 有泰国本地银行账户的用户 |
| TrueMoney | 泰国的电子钱包 | 有 TrueMoney 余额的用户 |
| 支付宝（Alipay） | 部分场次开放 | 国内用户最省事的选择，无需国际卡 |

**从选座到付款只有 5 分钟**：官方教程给出的支付时限是统一的 5 分钟——信用卡/借记卡（连填卡信息的时间都算在内）、PromptPay、TrueMoney 都是如此。抢热门场次时，把用哪种支付提前定好、卡信息放在触手可及的地方，不要等选完座再翻钱包找卡；时限与渠道以支付页当时显示为准。

国内用户没有国际卡时，优先看演出页有没有支付宝选项；都没有的话，办一张国际卡是绕不开的前置条件。

## 四、付完钱，票在「我的票」里

支付完成、订单生成后，电子票（E-Ticket）会出现在 App 的「我的票 / My Tickets」菜单里，不需要取实体票。入场、转给朋友、以及 Presale 实名场次的注意事项，见 [电子票入场与转票.md](电子票入场与转票.md)。

两点提醒：

- **买前核对清楚再付款**：订单完成、电子票发出后不可取消、不可退款，日期和场次看错只能自己承担；
- **只通过 App 或官网下单**：平台外的「代拍」「私人转让」不受官方保障，具体套路见 [常见问题与防骗指南.md](常见问题与防骗指南.md)。
