## 一、电子票在哪看

购票成功后，电子票（E-Ticket）就在 App 的「我的票 / My Tickets」菜单里，不需要打印、也不依赖取票机。

有一点必须先说清楚：**入场靠的是 App 里的实时票面，官方明令禁止截图——截图出来的二维码一律扫不出来**。所以「提前截好图备用」这条路是走不通的，演出当天要做的只有两件事：提前登录 App、提前找到票所在的页面。

## 二、现场入场怎么验票

官方教程给出的出码路径是：进「个人资料 / Profile」页 → 选「演唱会门票 / Concert Tickets」→ 点中要入场的那张票 → 点「显示 QR Code」打开 Full E-Ticket 页面，保持这个页面打开，让工作人员扫二维码即可。

三个细节值得注意：

- **实名场次会核对证件**：Presale 等实名登记的场次，票面姓名要与你的身份证或护照一致，去现场带好对应证件；
- **手机里有多张票不能代扫**：一部手机上留自己用的那一张就行，同行其他人的票必须通过 App 内转票送出去，让他们用自己的手机出码；
- **转来的票当场点「接受」**：别人转给你的票到达时会有实时通知，点接受后票才进入你的「我的票」。

## 三、把票转给朋友：实时到账

The Concert 平台内的转票是实时系统——你这边一发，对方立刻收到通知，中间没有任何等待期。这一点是官方明确强调的，也是防骗的关键判据。

具体操作分两边：

**转出的一方**：

1. 进「个人资料 / Profile」页，选「演唱会门票 / Concert Tickets」；
2. 选中要送出的那张票，点「送票给朋友 / Send ticket to friend」；
3. 填送出数量，再填对方的手机号或邮箱；
4. 核对信息无误后确认送出。

**接收的一方**：

1. 先在 App 或网页版注册并登录（流程见 [注册与登录步骤.md](注册与登录步骤.md)）；
2. 收到「有票寄给你」的通知后点进去；
3. 点「全部接受 / Accept all」并确认，票就进了自己的「我的票」。

防骗上记一条：对方说「已经转了，但要等系统处理 / 有转票时限」，这就是骗局，直接见 [常见问题与防骗指南.md](常见问题与防骗指南.md)；真的转了却没收到通知，自己通过官方客服渠道核实，不要听转票人的一面之词。

## 四、直播票（Live Streaming）的限制

部分演出提供线上直播票，购买时这几条规则要心里有数：

| 规则 | 说明 |
| --- | --- |
| 语言要在买票时选定 | 泰语原声 / 英语配音 / 中文配音等选项，购买时选了之后不能改 |
| 同时只能一台设备观看 | 一个 E-Ticket 同一时间只允许 1 台设备登录收看 |
| 一张票限看一个场次 | 只能看你购买的那一场，不能挪用 |
| 出票后不退不换 | 支付成功、E-Ticket 发出后不可取消、不可退款 |

直播一般会比现场开演提前约 30 分钟开始推流，想看完整暖场就早点进。

## 五、Presale 优先购怎么登记

部分热门演出会开 Presale（预售优先购）环节，先登记、抽中资格才能在公售前买票。登记有两条硬性要求：

1. **只能在网页版 [www.theconcert.com](https://www.theconcert.com/) 登记**，App 里办不了这件事；
2. **必须填真实姓名**，与你的身份证或护照完全一致，入场时按这个核对。

登记后到主办方公布的日子，回「PRESALE EVENT」菜单自查状态，四种结果的含义：

| 状态 | 含义 |
| --- | --- |
| 获得 Presale 资格 | 可以在预售时段内购票 |
| 审核中 | 登记还在核查，等公布 |
| 未获得资格 | 预售买不了，等公售 |
| 登记时间已截止 | 报名通道已关闭 |

拿到资格后同样走 [购票流程与支付方式.md](购票流程与支付方式.md) 的正常下单流程，只是要在规定时段内完成。
