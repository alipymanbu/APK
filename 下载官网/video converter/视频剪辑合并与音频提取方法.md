# Video Converter, Compressor 视频剪辑合并与音频提取方法

## 一、剪视频（Video Cutter）

1. 首页点 **Video Cutter**，选要剪的视频；
2. 设置**开始时间与结束时间**，可以直接输入精确到毫秒的时刻，拖时间轴也行；
3. 两种剪法，看你要留哪头：
   - 默认保留所选区间——掐头去尾、只留中间一段就先框选要的部分；
   - 打开 **REMOVE SELECTED** 开关——变成删除所选区间，适合掐掉中间一段广告或废镜头；
4. 确认后开始处理，输出同样在应用内结果列表里。

音频文件的剪切（Audio Cutter）操作完全一样，入口在首页的音频区。

## 二、拼视频（Video Merger）

1. 首页点 **Video Merger**，勾选要拼的多个片段；
2. 选拼接方式：
   - **顺序拼接**：首尾相连成一条长片（最常用）；
   - **上下拼接**：两条视频各占一半屏，叠成竖向画面；
   - **并排拼接**：左右各占一半，适合对比类画面；
3. 开始处理，输出为一个新文件，原片段不动。

顺序拼接时片段的排列顺序就是勾选顺序，勾错了先删掉重勾再开始。多个片段格式不一致时，先统一转成 MP4 再拼，成功率更高（原理同 [支持的视频格式与参数设置.md](支持的视频格式与参数设置.md) 的格式清单）。

## 三、视频转音频（Video to Audio）

想只留声音——视频里的旁白、BGM、一段采访——用这个入口：

1. 点 **Video to Audio**，选视频；
2. 选输出格式：`MP3` / `M4A(AAC)` / `AC3` / `WAV` / `OGG` / `FLAC`；
3. 可顺手压缩音频体积、选码率（剪辑保存时可任选码率）；
4. 开始处理，得到音频文件。

格式选择参考：要通用选 **MP3**；要无损存档选 **FLAC** 或 **WAV**（体积大）；苹果生态内用 **M4A**。

## 四、单独处理音频（剪 / 转 / 拼）

首页音频区的三个入口：

| 入口 | 干什么 |
| --- | --- |
| Audio Cutter | 剪音频，毫秒级起止点，同样支持「保留所选 / REMOVE SELECTED」两种剪法 |
| Audio Converter | 音频转格式与压缩，支持 MP3、M4A(AAC)、M4B(AAC)、AC3、WAV、OGG、FLAC，可选单声道/立体声 |
| Audio Merger | 把多个音频文件拼成一个 |

采样率、码率这些参数的含义与取值，在 [支持的视频格式与参数设置.md](支持的视频格式与参数设置.md) 第四节。

## 五、这几件事的共同规则

- **所有操作都支持批量**：选文件那一步多勾几个即可；
- **原文件不会被覆盖**：处理结果是新文件，存在应用内结果列表；
- **参数在开始前调完**：中途不能改，跑错了只能重跑一次。
