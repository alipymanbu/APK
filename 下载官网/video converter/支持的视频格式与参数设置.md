## 一、支持的视频格式

转换时可选的视频输出格式（官方商店页面列出的清单）：

```
MP4  MKV  AVI  3GP  FLV  MTS  M2TS  TS  MPEG  MPG  WMV  M4V
MOV  VOB  F4V  WEBM  DAV  DAT  MOVIE  MOD  MXF  LVF  H264
```

日常互转的高频组合：

- **转 MP4**：兼容性最好的选择，发社交平台、发给别的设备基本都认；
- **转 3GP**：老功能机或很旧的安卓设备；
- **从 VOB / MTS / MOD / MXF 这类少见格式转出**：摄像机、监控或剪辑软件导出的格式，很多手机播放器直接打不开，先转成 MP4 再用。

## 二、支持的音频格式

音频转换与视频抽音频可用的输出格式：

```
MP3  M4A(AAC)  M4B(AAC)  AC3  WAV  OGG  FLAC
```

从视频里抽声音时，可作为输入源的视频格式与上面第一节一致。

## 三、分辨率、帧率、码率怎么选

| 设置项 | 可选范围 | 你该怎么定 |
| --- | --- | --- |
| 分辨率 | 预设从 240P 到 4K，也可手填自定义值 | 只是发社交平台，1080P 足够；想压到最小选 480P 一档；不要填得比原片高，放大不会让画质变好 |
| 帧率（FPS） | 预设值或手填 | 保持与原片一致最稳；把 60 降到 30 能省一部分体积 |
| 码率 | 自己指定 | 压缩体积就看它：码率越低文件越小、画质越损。先用中间值试一段 |

分辨率设置里另有 2K / 4K 选项与**硬件加速**开关（新版本加入），硬件加速开着重负载转换会更快，具体哪一版起支持、是否对你设备生效，以官方页面与应用内实际选项为准。

## 四、编码与压缩方式

- **压缩方式选 High quality**：走 x264 编码，输出画质接近原片；
- **压缩方式选 Video Bitrate**：直接指定码率，体积可控；
- **编码模式**：支持 CBR（固定码率）与 VBR（可变码率）两种；
- **音频采样率**：8K 到 48K 可选，一般保持默认即可。

应用支持的编解码器清单（音视频）：

```
视频：h264  mpeg4  mpeg1  mpeg2  flv1  vp8  vp9  wmv1  wmv2
音频：aac  mp3  mp2  ac3  opus  vorbis  flac  alac  wmav1  wmav2
```

## 五、字幕轨与音频轨

- **字幕**：可以选视频里自带的字幕轨，也可以外挂字幕文件，支持 `subrip` / `mov_text` / `srt` / `webvtt` / `vtt`；
- **音频轨**：可以选视频原有的音轨保留，也可以挂外部音频，支持 `mp3` / `aac` / `m4a` / `wav`；
- **声道**：音频转换时可选单声道或立体声。

## 六、旋转与翻转

选中视频后可做 90° 顺/逆时针旋转、180° 旋转，以及水平/垂直翻转——竖拍视频拍反了、监控视频方向不对，都在这里改，不用重新导素材。
