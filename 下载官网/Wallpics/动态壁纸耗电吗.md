## 一、先给结论

动态壁纸**比静态图费电，但费多少完全取决于壁纸怎么动**：屏幕熄灭时安卓会暂停壁纸渲染，全屏应用盖住桌面时也不渲染，所以真正费电的只有「桌面亮着的那段时间」。多份独立测试的结论区间是：现代手机（2021 年后的中高端机）用优化过的动态壁纸，一天下来比静态多耗 **1%~3%**；老机型或入门机可能到 **5%~10%**；而**视频循环类**壁纸是最重的一档，能把差距拉到两位数。下面是具体数据与出处，你可以自己判断信哪个。

## 二、几份公开实测的数据

| 来源与条件 | 测出的差异 |
| --- | --- |
| Androidtudo 实测（2026-05，Galaxy S26，飞行模式 + 120 尼特） | 系统静态壁纸待机 80~95 mA；谷歌自带动画壁纸 105~110 mA；**第三方视频循环壁纸稳定 350 mA**，全天开着约多耗 15%~20% |
| 同一测试里的深色动画 | 大面积暗色 + 少量光点的动画，比亮色满屏视频壁纸**省电约 40%** |
| [visionai.to](https://visionai.to/) 汇总（2026-04） | 2021 年后的旗舰/中端机：动态比静态每天多 1%~3%；2019 年前或入门机：5%~10% |
| lifetips 实测（2026-01，14 款机型） | 平均每天可用时长减少 22~37 分钟——**明显高于上面几份** |

同一问题测出 1%~3% 和「每天少半小时」两种量级，原因是机型、亮度、壁纸类型、亮屏时长都不一样。**别纠结哪个数字「对」，用下面的方法测你自己那台就行。**

## 三、用两天对比法测你自己的手机

别装电池统计 App 猜，安卓自带的就够：

1. 第一天用静态壁纸，正常使用，晚上在 **设置 → 电池 → 电池用量** 里记下全天掉电曲线。
2. 第二天换成动态壁纸，尽量复刻同样的使用方式，再看同一处。
3. 两天差 **5% 以内**：随便用；**5%~10%**：可用，出门前换静态；**超过 10%**：这张壁纸或这个 App 对你这台机器太重，换掉。

另一个速查：在「电池用量」列表里看 Wallpics 有没有进前几名。连榜都进不了说明它不是耗电源头；排第一就按下面的设置处理。

## 四、想省电，按收益排序动这几下

1. **换静态深色壁纸**（收益最大）：AMOLED 屏显示黑色的像素是不发光的，静态 + 深色基本把壁纸这条耗电源头掐掉。
2. **动态只设主屏，锁屏用静态**：锁屏整天被通知反复点亮，动画实际渲染时间远比桌面长。
3. **选「慢动」的而不是「视频循环」的**：第二节的数据里差了三倍多——小幅度位移、粒子缓慢飘这类最省，整段视频循环最贵。
4. **省电模式下自动降档**：多数手机进省电模式后会压低壁纸刷新，出门前开着就行。
5. **别开触碰反馈类特效**（如果应用里有）：它要持续监听触摸，桌面没人碰时也在耗。

## 五、发热与卡顿也算在它头上吗

动态壁纸只在桌面可见时渲染，玩游戏、看视频时它在后台不画帧，正常情况下不该是发热主因。若你**熄屏放着也烫**，问题更可能在壁纸类型（视频循环类持续解码）或后台没被系统挂起——按 [常见问题与排查.md](常见问题与排查.md) 第二、四节先定位，再决定要不要换壁纸。
