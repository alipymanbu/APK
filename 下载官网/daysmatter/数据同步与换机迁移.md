# 倒数日换手机怎么迁移数据（云同步备份与恢复）

> 本篇讲「倒数日 · Days Matter」的事件数据怎么随账号云同步、换手机时怎么把日子完整带走，以及一直没登录账号时的补救办法。

## 一、先弄清楚：你的日子存在哪

两种情况，处理方式完全不同：

| 情况 | 数据在哪 | 换机难度 |
| --- | --- | --- |
| 登录过账号并开启云同步 | 本机 + 云端 | 低，登录即恢复 |
| 从未登录账号 | 只在本机 | 高，见第五节 |

官方对云同步的口径是「云端同步：你的重要日子绝不丢失」，账号体系是 iCity 账号（每日科技的通行账号）。登录入口在「我的 / 设置」里，具体名称以应用内为准。

## 二、换手机的标准流程

1. **旧手机**：打开倒数日，确认已登录账号（设置里能看到账号即已登录）；最近改过事件的话，进设置手动触发一次同步（有同步选项时），等它跑完；
2. **新手机**：先装好 App，安装方法见 [下载与安装教程.md](下载与安装教程.md)；
3. **新手机**：打开 App，用**同一个账号**登录；
4. 登录后事件会从云端拉下来，等首页恢复出全部条目即可。

三个注意事项：

- 新旧手机登录的必须是**同一个**账号，登成两个号就看不到旧数据；
- 云端同步的是事件数据；桌面挂件是系统层面的东西，换机后要在新桌面重新添加，见 [桌面小组件设置方法.md](桌面小组件设置方法.md)；
- 用了隐藏归档的话，新机上若「少了」一些条目，先在设置里把密码保护/归档选项打开再找——归档内容不会直接混在首页里。

## 三、iOS 与安卓之间能互迁吗

官方同时提供 iPhone / iPad 版与安卓版，登录同一套 iCity 账号即可同步。跨平台迁移按第二节同样流程走，迁完花一分钟逐条检查事件内容是否齐全。此能力以官方页面为准，换机前建议先在旧机把事件列表截图留底，万一同步有出入有据可查。

## 四、一直没登录账号，旧机还在手上

趁旧机还能用，现在补救：

1. 在旧机设置里登录 iCity 账号；
2. 保持联网，等首次上传完成（事件多会慢一些，别中途杀后台）；
3. 再按第二节的流程在新机上登录。

## 五、旧机已经刷机或丢失，且从未登录过

事件数据只存在丢失的那台手机里，官方没有提供从本地文件导回的途径，这种情况没有可靠的找回办法。以后养成开云同步的习惯，比任何事后补救都管用。

## 六、同步没动静的排查

1. 确认两端登录**同一账号**；
2. 检查网络：云同步需要联网，代理异常时先切回正常网络；
3. 手动触发：设置里的同步选项（以应用内为准）手动拉一次；
4. 退出登录再重新登录一次，触发全量拉取。

以上都试过还不行，带着「两端账号相同、网络正常」的结论去问官方客服，比干等快。其他常见问题见 [常见问题排查.md](常见问题排查.md)。

## 七、本地备份文件：第二道保险

除了云同步，应用内还有本地备份（设置里的「备份管理」或「备份与恢复」，名称以应用内为准），提供「立即备份 / 导入备份」两个动作：

- 换机前在旧机做一份本地备份，再把备份文件传到新手机（微信文件传输助手、网盘都行），新机装好后用「导入备份」选这个文件恢复；
- 云同步之外多留一份本地备份，账号出问题时还有退路；
- 入口路径各版本略有差异，有教程给出的路径是首页侧栏 → 更多 → 设置 → 备份管理，找不到就逐个翻设置里的条目。
