## 二、从网盘拿到安装包

安装包从这里拿：**倒数日（Days Matter）安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/f595563f6768](https://pan.quark.cn/s/f595563f6768)

1. 打开上面的链接 → 选中安装包 → 点「转存」，先存到你自己的网盘（直接下载分享文件有时会受限，转存后再下最稳）；
2. 在夸克网盘 App 里找到转存后的文件，点「下载」到手机本地存储；
3. 下载完成后在通知栏，或「文件管理 → 夸克/下载」目录里找到这个 APK。

## 三、安装（含「未知来源应用」授权）

APK 不是从应用商店装的，安卓会拦一道，按提示放行即可：

1. 点开下载好的 APK，系统提示「出于安全考虑，已禁止安装未知来源应用」；
2. 点「设置」/「仍要安装」，在弹出的页面里允许**你的浏览器或夸克网盘**「安装未知应用」（部分系统叫「安装未知来源应用」）；
3. 返回安装页，点「安装」，等待完成；
4. 装完点「打开」，或回到桌面点「倒数日」图标。

几个常见拦截点：

- **小米 / 红米**：安装页可能还要在「更多设置」里再点一次「仍然安装」；
- **华为 / 荣耀**：提示「此应用存在风险」时选「继续安装」；
- **vivo / OPPO**：若弹出安全检测，按提示输入锁屏密码或点「继续安装」。

各家系统的拦截文案会随版本变化，以上只列常见形态，以你手机实际提示为准。

## 四、装完先核对一眼版本

打开 App 进「我的 / 设置 → 关于」（入口名称以应用内实际显示为准），确认版本号是 **3.6.61**。如果你拿的是别处另下的一份，包名应该是 `com.clover.daysmatter`——包名对得上才是每日科技的正版「倒数日」，应用市场里有一批同名仿冒的倒计时工具，别认错。

## 五、第一次打开建议做的三件事

1. **允许通知与精确提醒权限**：提醒功能依赖通知权限和「闹钟和提醒」权限，首次启动弹权限框时直接允许；错过了可以到系统「设置 → 应用 → 倒数日 → 通知 / 权限」里补开。
2. **登录账号开云同步**：事件数据只有登录后才有云端备份，换手机迁移也靠它，具体见 [数据同步与换机迁移.md](数据同步与换机迁移.md)。
3. **添加第一个事件**：建一条试试手感，操作见 [添加事件与设置提醒.md](添加事件与设置提醒.md)。

安装过程卡在某一步，先看 [常见问题排查.md](常见问题排查.md) 里安装相关的条目。
