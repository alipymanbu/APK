## 一、功能入口在哪

root 成功后，KingRoot 主界面底部会给出几个功能入口，多份实测资料里出现的文案是「卸载预装」「阻断自启」「净化手机」（不同包、不同版本文案略有差异，认位置不认字）。前提只有一个：[下载与安装教程.md](下载与安装教程.md) 那步已经真正拿到权限 —— 没 root 这些入口点了也白点。

## 二、卸载预装：先分清两栏

点进「卸载预装」后，列表通常分两栏：

| 分栏 | 内容 | 能不能删 |
| --- | --- | --- |
| 预装应用 | 厂商预装的普通应用（浏览器、天气、商店推广位…） | 你用不上的都可以删 |
| 系统软件 | Android 主程序与厂商核心组件 | **界面上会标「不可卸载」，照做别硬删** |

这个分栏是保护机制 —— 有实测报道明确提到，分栏就是为了防止把 Android 主程序删到手机开不了机。操作上：

1. 确认手机里重要数据已备份（同 [下载与安装教程.md](下载与安装教程.md) 第二节的准备）；
2. 挑**你确认自己从没打开过**的预装应用逐个删，第一次别批量全选；
3. 「从没用过」不等于「系统不需要它」—— 第三方教程的通用建议是删系统级组件前先用备份工具（Titanium Backup 一类）把 APK 备份下来，删错了还能装回去；
4. 删完重启一次，确认开机、通话、通知这些基础功能正常，再继续删下一批。

真删错了关键组件，开机异常的恢复方式按机型走官方系统修复路径（华为的入口见 [root后银行app闪退与保修影响.md](root后银行app闪退与保修影响.md) 第四节），其余品牌以官方指引为准 —— 这也是为什么分栏提示要当真。

## 三、阻断自启：关谁、留谁

「阻断自启」列出的是**开机和后台会自己启动的应用**。实测资料里的普遍反馈是：一台正常使用的手机，列表里几乎每个应用都申请过自启动。关法有讲究：

- **必须留自启的**：即时通讯、电话、短信类 —— 关了就收不到消息、接不到电话；
- **建议关的**：视频、浏览器、购物、工具类 —— 它们自启只为了驻留推送，代价是占内存、耗电、偷流量；
- **同步动作**：系统 设置 → 通知 里把同一批应用的通知也关掉，否则自启关了它照样换个方式弹窗；
- 改完不用做任何「加速」操作，重启一次看效果即可。

## 四、净化大师：可选的加强件

「净化」相关功能由独立应用**净化大师**承担（部分包里需要另行下载，不装不影响 root 与上面两个功能）。它能做的事按资料汇总：

1. **应用净化**：按应用设置「防止开机和后台自启」+「智能回收后台进程」两项，一般建议同开 —— 前者拦启动，后者在你不用时回收它占的内存；
2. **通知净化**：拦截应用推送与垃圾信息；
3. **净化记录**：主界面能看到今天拦了什么，逐条可查。

路径大致是：净化大师 → 设置 → 打开纯净模式 → 系统自动净化设置 → 逐个应用勾选。把第二节、第三节的事做完已经覆盖了主要收益，这一步属于按需加装。

## 五、这套操作的风险边界

三句话收尾：

1. **只动你自己看得懂的东西** —— 分栏标了不可卸的系统组件、不认识的框架包，一律不动；
2. **一次改一批，改完重启验证** —— 出问题时才知道是哪一步引入的；
3. 预装删错导致系统异常时的恢复路径、以及这些操作与银行类应用的关系，都在 [root后银行app闪退与保修影响.md](root后银行app闪退与保修影响.md)；想连 root 一起撤，走 [root权限授权管理与彻底卸载教程.md](root权限授权管理与彻底卸载教程.md)。
