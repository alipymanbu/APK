## 一、一张表看懂两条路线

KingRoot 代表的是「一键 root」路线：装个 APK、点按钮、云端下发提权方案，不动 bootloader。Magisk 是当前主流的现代路线：先官方解锁 bootloader，再把修补过的 boot 镜像刷回去获得 root。核心差异如下（截至 2026 年 9 月的公开资料）：

| 对比项 | KingRoot（一键路线） | Magisk（现代路线） |
| --- | --- | --- |
| 操作方式 | 手机上点按钮，几分钟 | 解锁 bootloader + 刷入修补镜像，需 ADB/fastboot 基础 |
| 要不要解锁 bootloader | 不需要 | **需要**，解锁通常伴随清除数据 |
| 有效系统版本 | Android 4–6 主力，7 收效递减，**8 起基本无效** | Android 5.0 起，新系统为主力 |
| 银行/支付类应用 | 撤除后可恢复（见影响篇） | 解锁 + root 后 Play Integrity 校验更难过（2025 年 5 月起 Android 13+ 默认只认锁定 bootloader 的设备） |
| 保修影响 | 彻底撤除后多数厂商仍可保 | 解锁动作本身多被计入保修风险，部分品牌永久记录 |
| 维护状态 | 约 2019 年后停止更新 | 开源、持续更新（版本号以官方仓库为准） |
| 隐藏 root / 模块生态 | 无 | 有（systemless 方式、模块体系） |
| 升级系统 | OTA 后 root 常失效，需重跑 | 模块化修补，升级处理相对干净 |

## 二、怎么选：三个判断

1. **先看系统版本**（[支持的安卓版本和机型对照.md](支持的安卓版本和机型对照.md) 的流程）：Android 4–6 的老机器 → KingRoot 这条路成本最低，不动数据、不用电脑；Android 8 及以上 → 一键路线直接出局，只剩 Magisk 这类现代方案。
2. **看这台机器让不让解锁**：现代路线的前提是 bootloader 可解 —— Pixel、一加国际版、小米（Mi Unlock）这类对开发者友好的机型可以；美版三星等完全锁死的没有折中；**三星 One UI 8 起（截至 2026 年 9 月的资料）已彻底取消 bootloader 解锁**，这类机器两条路都不通。
3. **看这台手机是不是你的主力支付机**：两条路都会让支付类应用变敏感（程度不同，见 [root后银行app闪退与保修影响.md](root后银行app闪退与保修影响.md)）。需要天天刷卡的手乖机，别 root；备用机随便折腾。

## 三、各自的代价，动手前算清

**选 KingRoot 的代价**：工具本身已停更多年，没有新版适配新系统（[支持的安卓版本和机型对照.md](支持的安卓版本和机型对照.md) 第二节）；杀毒软件大概率报毒；root 期间银行 app、支付功能受影响 —— 好在撤除路径干净，见 [root权限授权管理与彻底卸载教程.md](root权限授权管理与彻底卸载教程.md)。

**选 Magisk 的代价**：解锁 bootloader 会**清除手机全部数据**（先备份）；多数厂商视为脱保风险；Google 钱包碰一碰支付、部分银行 app 在解锁/root 状态下拒绝运行；刷入操作本身有变砖风险，步骤必须严格照机型教程走 —— 这超出了本文的范围，官方仓库在 [github.com/topjohnwu/Magisk](https://github.com/topjohnwu/Magisk)，机型教程以对应机型的社区指引为准。

## 四、别做的事：两条路混装

无论选哪条，**同一时间只留一套 root 方案**。一键工具与 Magisk 并存会互相覆盖 su 与授权组件，结果是授权弹窗混乱、root 时有时无 —— 这正是 [root进度卡40%的解决办法.md](root进度卡40%的解决办法.md) 第四节「假成功」的高发成因。换路线前，先把旧的一套按 [root权限授权管理与彻底卸载教程.md](root权限授权管理与彻底卸载教程.md) 撤干净，再开新的。
