## 一、先分清装进来的三个东西

KingRoot 跑完，手机里通常不止一个应用。谁该留、谁该删，搞错会把 root 弄丢：

| 应用 | 作用 | 能不能删 |
| --- | --- | --- |
| KingRoot | 获取 root 的工具，装完就是历史任务 | 可以删 |
| KingUser | 授权管理（相当于 SuperSU），每次授权弹窗都归它管 | **用 root 期间别删** |
| KingMaster | 系统清理类附加工具 | 可以删 |

日常你打交道的其实是 KingUser：应用要 root 权限，弹窗问你放不放行的就是它。KingRoot 本体在 root 到手后即可卸载，不影响已有的权限。

## 二、授权：放行、拒绝与总开关

1. **临时授权**：应用第一次申请 root 时，KingUser 弹窗选择允许 / 拒绝；建议对不熟悉的应用一律先拒绝 —— root 权限等于把整台手机交出去。
2. **改已有决定**：打开 KingUser → Root 授权列表，能看到每个应用的记录，逐个改成允许、拒绝或询问。
3. **总开关**：KingRoot / KingUser 的「通用设置」里有「开启 Root 授权」开关 —— 关掉后**所有**应用的 root 请求一律终止，适合临时把手机交给别人用的场景。
4. **关掉授权通知**：弹窗提醒太多时，路径是 设置 → 应用 → 全部 → KingUser → 关闭通知；授权功能本身不受影响。

给第三方应用开 root 前，想清楚它要这个权限干什么 —— 授权容易，事后才发现它干了别的就晚了。

## 三、彻底移除 root（官方路径）

想让手机回到未 root 状态（送修、出二手、恢复银行 app 都用得上），走 KingUser 内置的移除功能，不要只删桌面图标。**前置准备**：连上 Wi-Fi、电量充到 50% 以上，过程中不要强制关机：

1. 打开 KingUser → 设置 / Root 授权设置；
2. **先取消勾选「备份 Root 权限」**（不取消的话移除不彻底）；
3. 点「彻底删除 Root 权限」（英文界面依次是 `Root authorization setting` → 取消 `Backup Root permission` → `Remove Root permission`）；
4. KingUser 会自行清理并被移除，重启手机生效；
5. 重启后如果 KingUser 还在，允许它请求的 ADB 授权再执行一次，然后手动重启。

**另一个入口，两种说法并列**：部分中文教程给出的路径是 KingRoot → 右上角菜单 → 通用设置 → 「卸载 KingRoot」按钮，并称这样卸载后「手机将恢复到无 root 状态」；而官方 FAQ 的口径是 root 到手后可直接卸载 KingRoot、KingUser 继续保有权限。两个入口效果可能不同 —— **想彻底撤 root 就用上面 KingUser 的移除流程**；只是想给 KingRoot 本体腾地方，直接卸载图标即可（见本篇第五节），别点通用设置里的那个卸载按钮。

**KingRoot 自身也卸不掉时的兜底**（第三方教程口径）：先在系统设置里对 KingRoot「强制停止 + 清除数据」，再重新执行一遍 root，成功后**立即**走上面的彻底移除流程 —— 等于把它送回可卸载的状态再撤。

移除完成后，把残留的 KingRoot、KingMaster 图标一并卸载，手机里就不该再有这三个应用中的任何一个。验证方式：随便开一个以前会要 root 的应用，不再弹 KingUser 授权窗即为已撤干净 —— 恢复情况与银行类应用能否回归，见 [root后银行app闪退与保修影响.md](root后银行app闪退与保修影响.md)。

## 四、换用其他授权管理（可选）

有人 root 到手后想换成 SuperSU 之类的其他授权管理，官方 FAQ 给过路线：装上 SuperSU → 打开并允许其获取授权 → 按提示更新二进制文件 → 最后卸载 KingUser。这条路**只在你确实需要换时才走**；日常授权管理 KingUser 够用，来回换容易把授权环境搞出状态问题（参见 [root进度卡40%的解决办法.md](root进度卡40%的解决办法.md) 第四节的假成功场景）。

## 五、只想删 KingRoot 本体、保留 root

root 已到手时：直接卸载 KingRoot 应用，KingUser 继续管授权，互不影响。哪天连 root 一起撤，再回第三节。**顺序别反** —— 先删了 KingUser，再想撤 root 就没有移除入口了，只能走重刷系统那条路（各厂商恢复方式不同，华为官方提供手机助手/系统修复恢复路径，见 [root后银行app闪退与保修影响.md](root后银行app闪退与保修影响.md)）。
