## 一、这篇按哪份包写

KingRoot 是给安卓手机一键获取 root 权限的工具：装上、点一个按钮、等结果。本篇用网盘里那份 **v5.4.0**（包名 `com.kingroot.kinguser`，10.99M）做基准，从安装前检查讲到确认 root 是否真的到手。动手前先看一眼 [支持的安卓版本和机型对照.md](支持的安卓版本和机型对照.md) —— 系统版本不对，后面全白搭。

| 事实项 | 值 |
| --- | --- |
| 版本 | v5.4.0 |
| 包名 | `com.kingroot.kinguser` |
| 安装包大小 | 10.99M |
| MD5 | `7C519FDDDC48BE74EBE21892EA26BE05` |

网上流传的版本介绍页会写「12.60 MB」之类的体积，那是别的分发渠道的包；**核对这份包时以表里的 MD5 为准**，对不上就不是同一个文件。

## 二、安装前先备齐四样

1. **电量至少 30%**：root 过程中有重启，低电量中途断电比失败本身麻烦得多；
2. **网络保持在线**：KingRoot 按机型从云端下发对应的提权方案，断网会导致失败；
3. **允许安装未知来源应用**：设置 → 安全（新系统在「安装未知应用」里）打开对应开关；
4. **先把重要数据备份掉**：root 本身一般不动你的照片和聊天记录，但任何一次系统级操作都值得先备份。

装之前建议把已有的其他 root 工具卸干净 —— 多套 root 软件并存会互相打架，轻则授权弹窗混乱，重则 root 装完就失效。

## 三、下载与校验

安装文件从这里拿：[KingRoot 安装文件资源（夸克网盘）](https://pan.quark.cn/s/143928ebc505)。

下完在电脑上核一下 MD5（Windows 自带工具即可）：

```powershell
certutil -hashfile "下载目录里的kingroot文件.apk" MD5
```

输出应为 `7c519fdddc48be74ebe21892ea26be05`（不区分大小写）。不一致说明下到的不是这份包，别继续装。

## 四、手机端安装与获取 root 的步骤

1. 把 APK 传到手机，点开安装；若系统拦截「未知来源」，按提示放行这一次；
2. 打开 KingRoot，首页会显示你的机型和当前是否已有 root 权限；
3. 点绿色的开始按钮（不同包里文案可能是「立即开启」「尝试 Root」），等进度走完；
4. 过程中手机会自动重启；没自动重启就手动重启一次；
5. 重启后打开装好的授权管理（KingUser）—— 完成页常见文案是「已获取 root，root 权限监控中」—— 能看到 root 状态即算这一步完成。

整个过程一般几分钟。**进度卡住不动的处理不在本篇**，见 [root进度卡40%的解决办法.md](root进度卡40%的解决办法.md)。

## 五、怎么确认 root 真到手了

「提示成功」不等于真成功 —— 有用户反馈过界面说成功、实际没权限的情况（常见于以前用别的工具装过残留文件）。两个动作确认：

1. 打开 KingUser，看状态页显示已获取 root；
2. 随便开一个会申请 root 的工具（文件管理器、备份工具都行），**弹出的是 KingUser 的授权窗**而不是直接失败，才算真的通了。

两步都过，再进 [root权限授权管理与彻底卸载教程.md](root权限授权管理与彻底卸载教程.md) 学怎么管授权、哪天想撤怎么撤干净；root 到手后第一波操作通常是清预装、关自启，做法与边界在 [root后卸载预装软件和关闭自启动.md](root后卸载预装软件和关闭自启动.md)。

## 六、手机端装不上时：电脑版方式

同一套工具还有 Windows 版：手机打开「开发者选项 → USB 连接电脑」，装好驱动后在电脑端点「尝试 Root」，流程与手机端一致。电脑版安装包同样只建议从可信渠道获取 —— 网盘里这份是**手机端 APK**，电脑版不在其中。部分机型（尤其后续新机型）只有电脑方式才能走通，前提是它还在 [支持的安卓版本和机型对照.md](支持的安卓版本和机型对照.md) 的范围内。
