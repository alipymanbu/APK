## 一、本篇讲什么

决定「这个文件能不能用 Poweramp 播」时查这篇。Poweramp 自带解码器，绝大多数格式不需要转码；真正卡人的是另外两类：带 DRM 的流媒体离线文件，以及 Hi-Res 输出能不能跑满规格——后者取决于你的手机，不取决于播放器。

## 二、音频格式表

| 类别 | 格式 |
| --- | --- |
| 常见有损 | MP3、AAC（MP4/M4A）、OGG、OPUS、WMA |
| 常见无损 | FLAC、WAV、ALAC（含于 M4A）、AIFF |
| 冷门无损 / 压缩 | APE、WV（WavPack）、TTA、MPC、TAK、MKA |
| 高解析 | DSD（.dsf / .dff） |
| 其他 | FLV 音轨、MPGA、模块音乐（IT、S3M、XM 等） |

- 官方当前口径是「MP3、FLAC、ALAC、WAV、APE、DSD、WV、OPUS、WMA、TTA、MKA、TAK、mods 等」；上表是完整并集，以 [powerampapp.com](https://powerampapp.com/) 当时的列表为准。
- 播放 DSD、24bit/192kHz 这类文件时，**能不能按原规格输出由设备决定**：手机芯片、ROM 的音频通路不支持时，播放器会内部降采样——文件照样能播，只是没跑满。规格细节与输出选项见 [均衡器与音效设置指南](均衡器与音效设置指南.md)。

## 三、播放列表与 .cue

| 类型 | 支持情况 |
| --- | --- |
| `m3u` / `m3u8` | 导入、导出 |
| `pls` / `wpl` | 导入 |
| `.cue` | 内嵌与独立文件都认（整轨专辑按曲目切开播） |
| http 流 | 导入含 http 地址的 `m3u`/`m3u8` 可直接播网络流 |

- 一个 FLAC + 一个 `.cue` 的整轨专辑，把两个文件放同目录（或 cue 内嵌进 flac），Poweramp 会按 cue 里的曲目时间切成一轨一轨。
- cue 里的歌名来自 cue 文件本身的文本，显示不对就改 cue，改播放器没用。

## 四、哪些文件播不了

- **流媒体 App 的离线缓存**（各平台加密格式）——那不是普通音频文件，丢进来不会播，也不该绕。
- **格式在表里但播不了**：先确认文件没下完整（大小对不对）、扩展名有没有标错（`.flac` 改成 `.mp3` 这类）。
- **只在文件夹视图里找不到**：文件没问题，是文件夹没勾——见 [扫描不到歌曲怎么办](扫描不到歌曲怎么办.md)。

## 五、播放行为相关的三个开关

这三个不属于「格式」，但直接影响你听这些文件的体验，位置都在 设置 → 音频：

1. **无缝播放（gapless）**：专辑连续曲目、现场录音不留白。
2. **交叉淡化（crossfade）**：曲间淡入淡出；它与无缝互斥，开了交叉淡化就没有无缝。
3. **回放增益（Replay Gain）**：按专辑/曲目标签统一响度，专辑曲目音量忽大忽小时开它。

三者的异常表现（卡顿、爆音）见 [常见问题与故障排查](常见问题与故障排查.md)。
