## 一、入口在哪

播放页或列表里长按/点开曲目菜单，找**「信息 / 标签」**一项进入编辑界面。Poweramp 内置标签编辑器，标题、歌手、专辑这些字段可以直接改。

改之前先知道两件事：

- 标签存在**音频文件本身**里，改完写回文件，换播放器、拷到电脑上看到的都是改后的结果；
- 网络下载的歌曲标签质量参差（歌手字段里塞专辑名、多个歌手分隔符不统一），显示问题多半出在源文件标签上，不是播放器上。

## 二、几个典型场景怎么改

| 场景 | 改法 |
| --- | --- |
| 歌名前面带编号、后缀一串 | 标题字段删掉多余部分 |
| 歌手名显示不统一（有的带 `;`、有的带 `/`） | 歌手字段统一格式；多个歌手的分隔符解析在设置里有对应选项（以界面为准） |
| 网易云/QQ 音乐下载的歌显示「未知艺术家」 | 补歌手与专辑字段，保存后列表按新标签重新归组 |
| cue 切出来的整轨曲目名不对 | 曲目名来自 cue 文件文本，在电脑上改 cue 更快；单曲也能在标签里改 |
| 中文整页乱码 | 先按 [扫描不到歌曲怎么办](扫描不到歌曲怎么办.md) 第三节查编码，编码对了个别条目乱，再手动改 |

## 三、把歌词写进标签

标签里带歌词的歌，播放器直接就能显示，换设备也跟着走。做法：在标签编辑界面的歌词字段里粘贴歌词文本（逐行带时间戳的 LRC 内容也可整体粘入），保存后按 [歌词显示设置](歌词显示设置.md) 的方式调出显示。好处是不依赖同目录文件、不依赖插件联网。

## 四、封面与排序

- 封面显示不出来先看 [扫描不到歌曲怎么办](扫描不到歌曲怎么办.md) 第四节（多数是没扫到，不是标签问题）；
- 改完标签后若列表分组没变，触发一次重新扫描；
- 按歌手/专辑排序不对，多半是同一歌手有多种写法——统一标签写法比在播放器里修排序有效。
