# 扫描不到歌曲怎么办

> 装好了却看不到歌、新歌不出现、中文歌名乱码、封面不出来——按这篇从上到下排查。

## 一、先明确一件事

Poweramp 的音乐库是独立的：它**不读「系统音乐 App 看到什么」，只扫你在自己设置里勾选过的文件夹**。所以「别的播放器有歌、它没有」大概率不是坏了，是勾选与权限问题。按下面顺序走。

## 二、按顺序排查

### 1. 音乐文件夹没勾全（最常见）

设置 → 文件夹 / 媒体库 → 音乐文件夹：

- 看存歌的目录是不是在列表里、是不是打了勾；
- 新建过的文件夹（比如 `Download/Music`、SD 卡新目录）**要手动进来勾一次**；
- 勾完回列表页重新扫描。

### 2. 权限没给

设置 → 应用 → Poweramp → 权限，确认存储 / 音乐与音频权限是「允许」。安卓 13 及以上对媒体权限管得更严，装完随手拒了授权，表现就是空库。

### 3. 触发一次完整重扫

歌明明在勾选的文件夹里却不出现：

1. 列表页菜单里找到「重新扫描 / Rescan」执行一次；
2. 还不行，在应用信息里「强行停止」再打开，让它重建索引；
3. 仍不行，检查文件本身：扩展名是不是在 [支持的音频格式一览](支持的音频格式一览.md) 里、文件有没有下完整。

### 4. 扫描慢、扫到一半卡住

官方 FAQ 的口径是 **SD 卡有问题**（部分损坏、速度过慢）：

- 把卡拔下来在电脑上查错，或换一张卡试；
- 只在特定文件夹卡住：那个文件夹里可能有大量非音频文件，取消勾选它再扫。

### 5. 想排除某些文件夹

游戏音效、通知音这类不想被扫进来：同样在「音乐文件夹」里**取消勾选**对应目录即可，不用删文件。

## 三、中文歌名、歌手显示乱码

标签编码问题，不是文件坏了。旧版教程给的路径：设置 → 文件夹 / 媒体库 → 扫描器设置 → 标签编码，切到 GBK/GB2312 后完整重扫一次。**当前版本的设置项名称与位置可能有出入，以你手机上实际的设置界面为准**；多数新下载的资源用 UTF-8 标签，编码没错时别乱切，切错反而全乱。编码确认没问题、只是个别歌名或歌手不对，直接在播放器里改，见 [歌曲信息与标签编辑](歌曲信息与标签编辑.md)。

## 四、封面不显示

1. 先跑一次完整重扫——多数是没扫到内嵌封面；
2. 封面缺失时 Poweramp 可联网下载，检查是否只允许 Wi-Fi 下载封面的开关关掉了网络；
3. 个别文件标签里就没放封面图，这是文件本身的问题，可手动把图片放同目录或在标签编辑器里补（入口见 [歌曲信息与标签编辑](歌曲信息与标签编辑.md)）。

## 五、还是不行

按「文件夹勾选 → 权限 → 完整重扫 → SD 卡」的顺序仍无解，把问题范围缩小后再查：只有某个文件夹缺歌 = 那个文件夹的问题；所有歌都缺 = 权限或索引的问题。播放阶段的问题（有歌但没声、卡顿）不在本篇，见 [常见问题与故障排查](常见问题与故障排查.md)。
