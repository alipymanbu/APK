## 一、后台放着放着就停了

安卓在省电策略下会杀后台播放。逐项检查（不同品牌路径略有差异，在系统设置里搜关键词即可）：

1. 应用信息 → 电池 → 允许后台活动 / 不受限制；
2. 关掉「闲置时自动管理 / 未使用时优化」对它的限制；
3. 厂商的后台清理、锁屏清理白名单里加上它；
4. 从最近任务里把它下拉加锁（部分机型的必须动作）。

改完锁屏息屏放一首歌实测，能连续播过几分钟才算设好。

## 二、有歌但没声 / 播放卡顿

按症状逐条试：

| 症状 | 先试 |
| --- | --- |
| 卡顿、断续、个别文件必卡 | 关 DVC（设置 → 音频），再关交叉淡化与无缝播放各试一次 |
| 完全没声但进度在走 | 调大媒体音量；再看是否连了蓝牙/输出设备被路由走 |
| 只有某个文件没声 | 文件没下完整或格式不支持，换文件 |
| 打开就没声 | 见 [扫描不到歌曲怎么办](扫描不到歌曲怎么办.md) 先确认库与权限没问题 |

关 DVC、关交叉淡化属于**兼容性排查动作**（有用户反馈可解卡顿），确认是哪个开关引起的后，再决定留哪个——不是日常音质设置。

## 三、音量低、大小声忽高忽低

1. 官方 FAQ 对「音量太低、音量变化异常」给的办法是**先试禁用 DVC**（设置 → 音频）：DVC 在多数中高端机型上默认启用，个别 ROM 与它配合不好就会出怪音量——试完对比，好了再决定留哪个状态；
2. 开了回放增益就先看它的模式（按曲目 / 按专辑），标了不同增益的专辑会不一样；
3. 均衡器整体增益与前级拉太高会造成削顶，把前级归零听一次；
4. 蓝牙下低音一开就破音：按 [均衡器与音效设置指南](均衡器与音效设置指南.md) 第四节处理绝对音量。

## 四、锁屏与桌面小部件不显示 / 不能控制

- 锁屏控制：设置 → 锁屏，启用锁屏播放器，按需开「直接解锁」；
- 小部件：长按桌面加小部件时选 Poweramp 的样式；加了不刷新、变成白块，先重启手机，仍不恢复就删掉重新添加——多半也与第一节的后台限制没放开有关；
- 耳机线控与蓝牙按键：设置 → 耳机/蓝牙，按键行为可重新指派（长按音量键切歌一类可选）；
- 车载与蓝牙专项（Android Auto 列表不显示、连上不自动播、蓝牙破音）见 [车载与蓝牙播放设置](车载与蓝牙播放设置.md)。

## 五、试用到期了

官方渠道的包是 15 天全功能试用。到期后部分功能受限，处理方式就是购买解锁：装 **Poweramp Full Version Unlocker**（Play 商店买断）或走应用内购买入口，价格与规则以官方商店当时显示为准。安装文件的渠道与版本核对见 [下载与安装教程](下载与安装教程.md)。

## 六、升级 / 重装后出问题

- 升级后设置乱了：设置页里有导出/导入设置，先备份再升级；出问题可导入旧备份回滚；
- 覆盖安装不丢库；**卸载重装**会丢播放列表与设置（音乐文件本身不受影响），装完按 [扫描不到歌曲怎么办](扫描不到歌曲怎么办.md) 重新勾选文件夹；
- 新版本的变更说明看官方发布渠道：[powerampapp.com](https://powerampapp.com/) 与官方论坛 `forum.powerampapp.com`——遇到疑似新版引入的问题，先看论坛有没有同款反馈，再决定要不要回退版本。

## 七、还没解决的

把问题收敛成一句话再查更有效：「哪个文件、哪个设备、做了什么之后开始的」。检索无果时，官方论坛（`forum.powerampapp.com`）有按版本分开的讨论区，提问带上机型、安卓版本与已试过的开关，回复会准得多。
