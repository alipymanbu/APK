# RPCS3 安卓版固件安装与游戏导入

> 本篇讲模拟器装好后的两步关键操作：安装 PS3 系统固件、导入游戏文件。没有固件模拟器开不了任何游戏，没有游戏文件它就是个空壳。

## 一、为什么模拟器里什么都没有

装好的模拟器是空的，固件和游戏都不随 APK 一起分发——两者都受版权保护，只能由你自己准备。这不是缺功能，所有 PS3 模拟器（包括电脑版）都是这个规矩：

- **固件**：PS3 主机的系统软件，模拟器靠它才能像真主机一样运行游戏。从索尼官方渠道获取，免费、合法。
- **游戏**：需要来自你自己的正版游戏备份（自己的光盘或主机里导出的数据）。模拟器本身合法，但用别人的盗版游戏文件不在本文讨论范围内。

## 二、下载 PS3 固件（PS3UPDAT.PUP）

固件在 PlayStation 官网免费提供：

1. 用手机浏览器打开索尼官方页面：[https://www.playstation.com/en-us/support/hardware/ps3/system-software/](https://www.playstation.com/en-us/support/hardware/ps3/system-software/)
2. 找到「How to update PS3 system software」这一节，选 **Update using a computer**（用电脑更新）。
3. 点 **Download PS3 Update** 下载固件文件。个别浏览器要点住链接选「在新标签页打开」才能触发下载。
4. 下载得到的就是 `PS3UPDAT.PUP`，体积约 200 MB。放在「下载」文件夹里备用即可。

只认索尼官网这一个渠道就够了，别去第三方「固件下载站」找。

## 三、安装固件

不同移植版本的菜单入口略有差别，流程一致：

1. 打开模拟器，进入主菜单（通常是左上角的三横线按钮）。
2. 找到固件入口。没装过固件时，这里一般显示 **Firmware: None**（固件：无）。
3. 点进去会调起系统文件选择器，定位到你刚下载的 `PS3UPDAT.PUP`，选中它。
4. 等待安装完成。安装要跑一阵子，有的版本进度条会分两次填满，装完界面上固件状态不再是 None 即为成功。

固件只需要装一次，之后升级模拟器版本一般不用重装（个别大版本更新后要求重装，届时再装一遍即可）。

## 四、导入游戏

动手导入前，如果还在纠结先试哪款游戏，公开的实测汇总见 [哪些游戏能玩与实测表现](哪些游戏能玩与实测表现.md)。

### 支持的格式

| 格式 | 特征 | 说明 |
| --- | --- | --- |
| PKG | 单个 `.pkg` 文件 | 需要在模拟器内安装，个别 PKG 还要求配套的激活文件才能启动 |
| ISO | 单个 `.iso` 光盘镜像 | 你自己光盘备份的常见形态，使用最省事 |
| 文件夹 | 含 `PS3_DISC.SFB` 和 `PS3_GAME` 子目录 | 主机硬盘备份的原始目录结构，整包拷进手机即可 |

不同移植版本对格式的支持进度不同，有的只认 PKG、有的三者通吃——以你装的版本的发布说明为准。

### 导入步骤

1. 把游戏文件传到手机（USB、局域网、网盘都行；文件夹格式的游戏要保证整个目录结构完整）。
2. 打开模拟器，点主界面的 **+** 号。
3. 单个游戏选「文件」，去文件选择器里选中那个 ISO 或 PKG；一次导一批就选「文件夹」，选中放游戏的目录。
4. 等待安装/导入完成。PKG 格式安装耗时明显，属于正常现象。
5. 有的版本导完不会自动刷新列表，在游戏列表页**下拉刷新**就会出现。

### 从哪里拿游戏文件

正规来源只有一条路：**备份你自己拥有的游戏**。手里有实体光盘，可以借助能读 PS3 光盘的主机或光驱做成 ISO；主机数字版游戏则从你自己的主机里导出备份。模拟器社区接受的标准就是「你玩你自己的备份」，网络上流传的现成游戏包不属于这个范围，也不在本文讨论范围内。

### 文件摆放的建议

- **游戏文件平铺放在同一个目录里，别一层套一层**。有用户反馈部分移植版本对多层子文件夹的支持不好，嵌套太深会识别不到游戏，直接都放进一个目录最稳。
- **优先用解密好的 ISO**，这是社区反馈里最省事的形态；文件夹格式次之，PKG 最麻烦（可能还要配套激活文件）。
- 手机存储紧张时，游戏文件可以放 microSD 卡（建议格式化成 exFAT），但导入时留意读卡速度对安装耗时的影响。

## 五、导入成功之后

- 游戏首次启动普遍很慢（要编译缓存，见 [常见问题与性能优化](常见问题与性能优化.md) 的缓存一节），黑屏转圈几十秒到几分钟都有可能，别急着关。
- 进入游戏后第一件事是接手柄，操作方式见 [手柄连接与按键映射](手柄连接与按键映射.md)。
- 游戏列表里的游戏开了黑屏、闪退或速度极慢，去 [常见问题与性能优化](常见问题与性能优化.md) 对照处理。
