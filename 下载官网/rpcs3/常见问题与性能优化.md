## 一、症状对照表

| 症状 | 最可能的原因 | 去哪节 |
| --- | --- | --- |
| 游戏列表空白 / 导入后没有游戏 | 固件没装，或游戏格式不被当前版本支持 | 第二节 |
| 点游戏黑屏后直接退回列表 | 固件缺失、机型不达标或该游戏本身不被支持 | 第二、三节 |
| 黑屏很久但没退出 | 首次启动在编译缓存，属正常现象，等 | 第三节 |
| 能进游戏但帧数极低 | 机型接近门槛下限，或没做优化 | 第三、四节 |
| 游戏速度忽快忽慢 | 发热降频，或帧率上限设置不当 | 第四节 |
| 画面花屏、贴图错乱 | GPU 驱动兼容问题 | 第五节 |
| 游戏速度整体偏快 | 帧率上限没有被正确限制 | 第四节 |

## 二、黑屏与识别不到游戏的处理

1. **先确认固件状态**：主菜单里固件入口显示的若还是 None（无），说明固件没装成功，回 [固件安装与游戏导入](固件安装与游戏导入.md) 重装一遍。固件缺失时游戏列表完全无法工作。
2. **再确认游戏格式**：把你手里的文件和模拟器支持列表对一遍。PKG、ISO、含 `PS3_DISC.SFB` 的文件夹是三种主流形态，压缩包（zip / rar）必须先解压出里面的文件再用。
3. **换一个游戏试**：如果所有游戏都黑屏，问题在环境（固件、机型、版本）；只有一个游戏黑屏，多半是这个游戏目前不被支持——PS3 模拟在安卓上还早期，单个游戏跑不起来很正常，去所用移植项目的讨论区查这个游戏的实测情况即可。

## 三、首次启动慢与缓存机制

- PS3 游戏第一次启动时，模拟器要把游戏的代码预编译成当前设备能跑的形态，轻则几十秒、重则几分钟，期间黑屏或卡在启动画面都正常。
- 编译结果会保存为缓存，**第二次启动同一游戏会明显变快**。中途手动杀进程会让这次编译白做，耐心等它跑完第一次。
- 设置里如果有清空 PPU / SPU 缓存的选项，只在游戏更新或模拟器大版本升级后出现异常时才用；日常不用清，清了下次启动又要重新等一轮编译。

## 四、速度慢与发热：能做的优化

按见效程度从大到小：

1. **控制发热**：摘掉手机壳、避开充电时游玩、上散热背夹。移动芯片一热就降频，降频后帧数腰斩是常态，多数「玩十分钟就卡」的原因都在这里。
2. **降低内部分辨率**：设置里找分辨率缩放（Resolution Scale 或类似名称），从默认值往低调（比如降到 100% 以下）。内部分辨率对帧数影响最直接，画面会糊一点但流畅度立竿见影。
3. **限制帧率为 PS3 原生**：游戏速度忽快忽慢或整体偏快时，把帧率上限（Frame Limit）从 Auto 改为 PS3 原生（Native）档，速度表现会稳定下来。
4. **用性能浮层观察**：设置里可打开性能浮层（Performance Overlay）实时看帧数，调参数时开着它对比，别凭体感瞎猜。
5. **关掉后台**：模拟运行时后台挂着微信、视频应用会抢内存，8 GB 内存的机型尤其明显，玩之前清一次后台。
6. **PPU 线程数**：部分移植版本提供 PPU 线程（PPU Threads）设置，社区经验是设成处理器总核心数的一半（8 核机设 4）比默认值更稳；改完用性能浮层对比一下实际帧数再定。

## 五、自定义 GPU 驱动

骁龙机型的进阶优化项：移植版本普遍支持替换 GPU 驱动，社区维护的开源驱动（如 Turnip 系列）对部分游戏的兼容性和帧数比出厂驱动更好。

- 驱动文件是社区按 Adreno 芯片代际发布的压缩包，需要按你的芯片型号（如 Adreno 740）选择对应版本。
- 安装路径一般在 **Settings → Custom GPU Driver**，添加压缩包文件后选中并重启模拟器生效。
- 换驱动有风险：个别游戏反而异常。出现花屏时先切回系统驱动再排查其他原因。
- 天玑 / 麒麟机型没有这条路线（对应社区驱动生态在 Adreno 上）。

## 六、预期管理

最后说清楚边界，免得反复折腾：

- **安卓移植还在早期**，启动崩溃、画面异常、兼容性差是社区自己都承认的现状，问题不在你的设置上时，唯一办法是等版本更新。
- **换设置救不了不达标的机型**：中端机反复调参也到不了可玩帧数，门槛参考 [手机配置要求与机型适配](手机配置要求与机型适配.md)。
- **哪些游戏目前实测能跑**：公开的开发者测试与社区实测汇总见 [哪些游戏能玩与实测表现](哪些游戏能玩与实测表现.md)，先查再试，少走弯路。
- **同一批游戏，电脑版体验好一个量级**：如果手头有电脑，直接用电脑版 RPCS3（官网 `https://rpcs3.net/`）是性价比最高的选择，游戏备份两边的用法相通。
- 安装环节的问题（解析包错误、签名冲突）不在本篇范围，回 [下载与安装教程](下载与安装教程.md) 的第五节对照处理。
