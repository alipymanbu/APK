## 一、PS3 游戏为什么基本离不开手柄

PS3 游戏是按主机手柄设计的：双摇杆、十字键、L1/R1/L2/R2 四个肩键加扳机，触屏方案很难同时模拟这么多输入还不挡屏幕。PS3 时代的游戏又普遍没有触屏适配，用触屏玩动作、竞速、格斗类游戏基本没有可玩性。所以只要游戏能跑起来，接一个蓝牙手柄是最直接的办法。

## 二、连接蓝牙手柄

1. **先在系统层面配对**：手机「设置 → 蓝牙」里打开手柄的配对模式（不同手柄进入配对的方式不同，常见的有长按组合键或专用配对键，以手柄说明书为准），等手柄出现在蓝牙列表里完成配对。
2. **确认系统已识别**：配对成功后，可以在手机的输入设置里按几下按键测试响应。
3. **打开模拟器**：系统层面已经连上的手柄，多数移植版本会自动识别，不需要在模拟器里额外开启什么开关。
4. **按键映射**：第一次连接后必须做一遍映射（下一节），不映射的按键可能对不上号。

社区移植版的手柄支持仍在完善中，有用户反馈过兼容性问题：个别型号连上后无响应、部分按键失灵或震动不可用。不是所有手柄都能一次成功。

## 三、按键映射怎么做

映射的意思是告诉模拟器「手柄上的哪个键对应 PS3 手柄的哪个键」：

1. 在模拟器主菜单里进 **Settings（设置）→ Controls（控制）** 类目（部分版本叫「按键设置」）。
2. 找到键位列表（Key Mappings 或类似名称），逐项点击要映射的条目，再按一下手柄上对应的键。
3. 建议按真实 PS3 手柄的布局对号入座：左摇杆、右摇杆、十字键、四个功能键（□✕○△）、L1/R1/L2/R2、Start/Select（在 PS3 上叫 Start / Select）。
4. 映射完存档，进游戏实测一轮：摇杆方向、肩键扳机是重点检查对象，L2/R2 这类模拟量按键（油门、蓄力）最容易出现识别成普通按键的情况。

两个常见坑：

- **按键全部错位**：多半是手柄被识别成了键盘模式，删掉映射重新来一遍，或换手柄的连接模式（X 模式 / D 模式，取决于手柄型号）。
- **摇杆漂移或反向**：先在映射界面重新校准，无效则可能是手柄硬件本身的漂移问题，与其他设置无关。

## 四、识别不到手柄时的排查顺序

1. 系统蓝牙里还能看到手柄吗？看不到就重新配对。
2. 其他应用（比如系统的按键测试）里手柄有响应吗？没有响应是系统和手柄之间的问题，与模拟器无关。
3. 模拟器重启一次再看——移植版本对热插拔（边玩边连）的支持普遍不好，先连手柄再开模拟器是最稳的顺序。
4. 换一根 USB 线用有线方式试试（支持 OTG 的手机）。有线能识别而蓝牙不行，问题就出在手柄的蓝牙协议上。
5. 还是不行，查你所用移植版本的发布页或讨论区，确认这个手柄型号有没有已知的兼容问题。

## 五、没有手柄时的触屏方案

- 移植版本都自带屏幕虚拟按键，进游戏后默认显示，可以在设置的触控类目里调整按键位置、大小和透明度。
- 把不常用的按键（Select、PS 键之类）挪到屏幕角落并调小，能减少误触。
- 触屏玩轻量的回合制、解谜类游戏勉强够用；动作类、竞速类还是省下时间直接接手柄。
- 部分版本支持隐藏虚拟按键的全屏模式，配合手柄使用时可以在设置里关掉浮层，画面更干净。
