## 一、工具按颜色分组

右侧工具箱里的工具用颜色分了组，认组比认名字快：

| 分组 | 代表工具 | 干什么 |
| --- | --- | --- |
| 笔刷类 | Clay、Brush、Smooth、Layer、Inflate、Nudge、Stamp | 直接在表面加减体积、抹平、堆细节 |
| 移动类 | Move、Drag | 抓住一块区域整体拖动，做大型、调比例 |
| 切割类 | Trim、Split、Project | 按笔画轨迹把模型切开、切掉、投平，像木工 |
| 选择/遮罩类 | Mask、Selection Mask | 圈出一块区域保护起来，只在别处动刀 |
| 绘画类 | Paint、Smudge | 上颜色、抹匀颜色 |
| 构造型 | Tube、Lathe、Insert、Gizmo | 用管状、旋转体、预设几何体快速起稿，再用 Gizmo 摆位置 |

新手最常见的组合是：`Move` 拉大形 → `Clay` 堆体积 → `Crease` 刻出缝隙 → `Smooth` 收拾表面 → `Mask` 圈住局部做精修。

## 二、笔刷参数在哪里调

选中任意笔刷后，左侧两个滑块管最常用的两项——**半径**（笔刷多大）与**强度**（一笔多重）。更细的设置在右上角第一个 `Settings` 图标里，分五个子菜单：

- **Stroke（笔划）**：笔划怎么落在模型上。半径有两种口径——`Screen` 按屏幕像素算（缩放视角它粗细不变），`Constant (3d)` 按模型尺寸算（跟着视角缩放）。做精细活时常切到屏幕口径，做大形时用 3D 口径更直觉。这里还有懒人绳（稳定器）和笔划平滑，手抖时开。
- **Alpha**：用灰度图当笔尖印章，做皮肤纹理、鳞片全靠它。
- **Falloff（衰减）**：笔刷从中心到边缘的力度曲线，决定笔触是圆润的一坨还是硬边的一块。
- **Filter（过滤）**：限制笔刷只作用于朝向你的面、只作用于相连网格等。
- **Pressure（压感）**：配压感笔时管笔尖力度如何映射到半径与强度。

另外两个高频开关：**Sub 模式**（加泥/减泥切换）在左侧工具栏；**对称**的镜像平面在顶部对称菜单里，旋转过物体后记得重新对准轴向。

## 三、起型的几条路子

从零做一个模型，官方「技巧」页给了几条路，按需选：

1. **球体 + 多重细分**：最经典。从球捏起，在需要细节的地方局部加细分，思路和桌面雕刻软件一致；
2. **动态拓扑**：雕刻时自动在笔触经过的地方细分网格，适合边塑边长细节，代价是面数涨得快；
3. **体素重拓扑（Voxel Remesh）**：把当前形状一键重新布线，多块泥揉成整体，起大形阶段非常好用；副作用是重拓扑后表面可能起小疙瘩，用 Smooth 或再 remesh 一次小间距即可压平；
4. **多对象**：头、身体、配饰分开做，各自调整，最后再合并；
5. **管状工具（Tube）**：做手指、尾巴、绳子这类细长结构时先拉出管子，改好截面再验证（Validate），比从球体里抠快得多。

## 四、平板上的性能取舍

Nomad 能把模型做到很高的面数，但你的设备未必扛得住，实操上注意三点：

- 大多数作品把面数控制在 **50 万面以下**，老设备也能流畅刻；几百万面是新平板才玩得起的区间；
- 手机、平板没有主动散热，长时间雕刻或渲染会因发热降频，中途卡顿先想到这个；
- 保存、重拓扑时崩溃基本是**内存不足**，处理办法见 [常见问题与崩溃排查.md](常见问题与崩溃排查.md)；模型上有图层时，合并图层能明显降低内存占用。
