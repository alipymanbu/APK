## 一、界面各区域

打开后屏幕被分成几块，先认清楚位置，后面找功能会快很多：

| 区域 | 位置 | 作用 |
| --- | --- | --- |
| 顶部菜单 | 上方左右两串图标 | 左侧管场景与对象（文件、拓扑、材质、光照等），右侧管工具与笔刷设置 |
| 状态信息 | 顶部一小条 | 当前场景面数、内存占用等，模型变卡时先看这里 |
| 导航立方体 | 右上角 | 显示你正看模型的哪个面；点某个面直接切到正视图，拖动它旋转视角 |
| 工具箱 | 右侧可滚动条 | 所有雕刻工具都在这里 |
| 左侧工具栏 | 左侧 | 半径、强度两个滑块，以及 Sub、Smooth、对称、遮罩、Gizmo、颜色等快捷按钮 |
| 底部工具栏 | 底部 | 撤销、重做、历史记录等常用操作 |

屏幕小的时候顶部两串菜单会合并到一起，别以为功能消失了。左手习惯的人可以在界面设置里把所有工具栏镜像翻转。

## 二、触屏手势

| 想做什么 | 手势 |
| --- | --- |
| 雕刻 | 在模型上单指（或笔）拖动 |
| 旋转视角 | 在模型外的空白处拖动 |
| 缩放 | 双指捏合 / 张开 |
| 平移视角 | 双指按住屏幕拖动 |
| 撤销 | 双指轻点一下，或点左下角撤销按钮 |

对称默认开着，你画左边右边会同步出现笔触，做脸、做手这类对称结构时很省事；做不对称细节时再把它关掉。

## 三、捏出第一件东西

1. 启动后屏幕上有一个球体，用默认的 `Clay`（粘土）工具在上面涂，表面就会鼓起来；
2. 左侧的**半径滑块**控制笔刷大小，**强度滑块**控制一笔下去的分量——新手先把强度调低，慢慢堆，比一笔大力出奇迹好修；
3. 想往里凹，点左侧的 `Sub` 按钮切换成减去模式，再点一次恢复；
4. 表面坑洼了就点 `Smooth` 抹平，抹完再点一次回到普通雕刻；
5. 做砸了双指轻点撤销，底部的历史记录还能往回翻很多步。

照这个「堆泥 → 减泥 → 抹平」的循环，先把一个卡通头的大概轮廓捏出来，再去碰更细的工具——工具箱里的其余笔刷在 [笔刷工具与雕刻技巧.md](笔刷工具与雕刻技巧.md) 里讲。

## 四、切换中文界面

默认界面是英文，切换路径很短：

1. 点屏幕**左上角的 Nomad 图标**，打开设置面板；
2. 向下滑找到 **Language**（语言）；
3. 选择 **Chinese**，然后点一下屏幕任意位置确认，界面文字即变为中文。

切完中文后工具名会变成中文标注，但官方手册里仍大量使用英文工具名（Clay、Crease、Trim…），两种叫法对照着看即可。在线中文手册在 [nomadsculpt.com/manual/zh-hans](https://nomadsculpt.com/manual/zh-hans)，遇到没见过的按钮可以去那里查。

能顺畅旋转视角、加减泥、撤销之后，基础操作就算过关了：想把形捏得更准，翻 [笔刷工具与雕刻技巧.md](笔刷工具与雕刻技巧.md)；做完想把模型拿出来用，翻 [模型导出与格式转换.md](模型导出与格式转换.md)。
