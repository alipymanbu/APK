## 一、试用与付费到底差多少

官方 FAQ 的口径是：

- **有 7 天试用，需要绑信用卡**；
- **试用版与付费版的安全功能完全一样**，不存在「试用阉割」——试用期只是时间到了要订阅继续。

价格会随地区、活动与时间变化，**以官方页面当时显示为准**。第三方评测站曾报过「月付约 $2.79 / 年付约 $24.99」的档位，仅作参考，实际下单前请以结账页为准。另外 ZoneAlarm Mobile Security 也打包在 ZoneAlarm Extreme Security NextGen（多设备套装）里，如果你已订那个套装，手机端可以直接用同一订阅激活。

## 二、不想订阅会怎样

试用期结束未订阅，应用会转为受限状态，防护项会陆续报 Risk。你可以选择继续订阅，或者卸载。换新手机或重装时，安装包仍可从 [zonealarm 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0ff123e21ea8) 获取，登录同一订阅账号即可恢复权益（订阅凭据跟着购买渠道走，不跟着安装包走）。

## 三、常见问题

**1. 网盘里的 3.8-9523 和商店里的最新版不一样，要紧吗？**
不要紧，两者是同一个应用（包名都是 `com.checkpoint.zonealarm.mobilesecurity`）的不同构建。功能集可能有出入，以你装的这版界面为准；想跟官方更新就走 Google Play。版本/包名/大小以上文列出的本地记录为准，商店版本号会持续变化。

**2. 耗电吗？**
官方宣称对电池影响很小。安全类应用的耗电主要来自后台扫描与常驻通知，若发现异常耗电，先在系统「电池 → 应用耗电」里看是不是被系统激进的省电策略反复冻结导致反复重扫，把 ZoneAlarm 设为不优化通常比关功能更划算。

**3. 它和别的杀毒软件能共存吗？**
能装在一起，但两套实时防护会重复拦截、重复扫描，还可能互相报对方是威胁（这是安全软件互扫的常见现象）。你二选一即可；Safe Browsing 与 VPN 的冲突同理，见 [安全浏览打不开与VPN冲突处理.md](安全浏览打不开与VPN冲突处理.md)。

**4. 怎么卸载干净？**
走系统常规卸载：设置 → 应用 → ZoneAlarm Mobile Security → 卸载。卸载前若 Safe Browsing 处于开启状态，建议先按第三篇方案 B 删掉 ZoneAlarm 的 VPN 配置，免得系统里残留一条无效 VPN 条目。

**5. 这个牌子靠谱吗？**
ZoneAlarm 品牌 1997 年就有，2004 年起归 Check Point（企业级安全厂商）旗下，手机端的威胁判定接的是 Check Point 的 ThreatCloud AI。第三方测试方面，AV-Comparatives 2019 年那份 250 款安卓杀毒应用的横评里，`Check Point / ZoneAlarm Mobile Security` 在通过名单中。测评会过期，看结论时留意年份。

**6. 只想扫码查一下链接，不想开着整套防护？**
可以。二维码与链接扫描是独立功能，装好后在应用里找到扫码入口即可用；其余功能保持默认或关闭都不影响它（具体入口以你这版界面为准，功能总览见 [首次设置与功能开启.md](首次设置与功能开启.md)）。
