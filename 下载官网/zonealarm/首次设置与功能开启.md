## 一、先看懂首页

打开应用，首页一般会显示整体安全状态（绿色代表各项已开，出现红色/黄色的「Risk Detected」说明有项没开或有问题）。底部或卡片里能看到设备（Device）、应用（Apps）、网络（Network）三块的异常提示。你处理的顺序通常是：先把红色项逐个点亮成绿色，再按自己的需要关掉用不上的功能。

## 二、设备与应用层功能

| 功能 | 你得到什么 | 在哪开 |
| --- | --- | --- |
| Device Shield（设备防护） | 提示系统里有风险的配置（如开发者选项、未知来源等），并提醒可疑进程 | 首页 Device 卡片 |
| Apps Protection（应用防护） | 扫描已安装应用与更新是否恶意，装到坏应用时给警告（仅安卓） | 首页 Apps 卡片 |
| Anti-Ransomware（防勒索） | 在文件被加密前拦下可疑的勒索行为 | 首页 Apps/Protection 相关卡片 |
| Apps Permission（应用权限） | 汇总各个应用正在使用的摄像头、麦克风、定位等权限，方便你统一收紧 | 首页 Privacy/Permission 入口 |

注意：这些功能多数依赖「使用情况访问权限」（Usage Access）之类的系统授权，首次开启时应用会把你带到系统设置页，允许一次即可。系统「省电策略」把应用限制住后扫描会停摆，建议在系统设置里把它改为不优化/允许后台（不同厂商叫法不同）。

## 三、上网与浏览层功能

| 功能 | 你得到什么 |
| --- | --- |
| Advanced Anti-Phishing（反钓鱼） | 拦已知与未知的钓鱼站点；安卓 11 及以上需要额外开启一项浏览器相关权限 |
| Safe Browsing（安全浏览） | 对所有浏览器生效的恶意站点拦截；**它靠安卓的本地 VPN 机制实现**，不是翻墙 VPN |
| Content Filtering（内容过滤） | 按你设定的类别过滤网页内容 |
| QR Code and Link Scanning（二维码/链接扫描） | 扫码或点链接前先查安全，避免跳到恶意站 |

Safe Browsing 开启时：进应用里的 **My Network（我的网络）** → Safe Browsing 一项显示未启用时点 **Enable VPN Permission** → 在系统弹出的「连接请求」里点 **OK**。开启成功后该项变绿，状态栏出现钥匙图标。如果它反复掉下来、或你手机上还开着别的 VPN，处理办法见 [安全浏览打不开与VPN冲突处理.md](安全浏览打不开与VPN冲突处理.md)。

## 四、Wi-Fi 层功能

| 功能 | 你得到什么 |
| --- | --- |
| Wi-Fi Security（Wi-Fi 安全） | 连上可疑 Wi-Fi 时提醒你可能遭遇中间人攻击 |
| Wi-Fi Ranking（Wi-Fi 排名） | 给周围的热点按安全程度排序，让你先挑最稳的那个连 |
| Anti-Bot（反机器人） | 阻止设备上的程序向外偷偷发送数据 |

## 五、值得先做的三项设置

1. **把首页所有 Risk 项点掉**：每一条红/黄提示点进去就是对应的开关；
2. **开启 Safe Browsing**：这是对日常浏览最直接的一层，前提是你不依赖其它 VPN（见第三篇）；
3. **收紧 App 权限**：在 Apps Permission 里把用不到的摄像头/麦克风/定位权限关掉，减少后台读取。

设置完成后，试用与付费的差异、以及用起来的常见疑问见 [试用订阅与常见问题.md](试用订阅与常见问题.md)。
