## 一、这是什么应用

ZoneAlarm Mobile Security 是 Check Point（ZoneAlarm 品牌的母公司）出的安卓手机安全应用，主要干四件事：扫恶意应用、拦钓鱼链接、检查 Wi-Fi 连接是否危险、盯住系统与应用的可疑配置。你需要的是「把包装到手机上并跑起来」，本篇就讲这条链路；装好之后每个功能怎么开，见 [首次设置与功能开启.md](首次设置与功能开启.md)。

| 渠道 | 说明 | 适合谁 |

| 夸克网盘安装包 | 拿到的是一个固定版本的 APK 文件，版本不再变化 | 手机上没有 Google Play、或想装回特定版本 |

## 三、网盘里这份包的版本事实

网上搜到的多是官方最新版，和网盘里这份未必是同一个版本。**凡涉及版本号、包名、安装包大小，以这份本地信息为准**：

| 项目 | 值 |
| --- | --- |
| 版本 | 3.8-9523 |
| 包名 | `com.checkpoint.zonealarm.mobilesecurity` |
| 大小 | 29.11M |
| MD5 | `9F10C22A8E3BD899C2971ED536735432` |
| 记录时间 | 2026-09-24 |

包名可以用来核对装的是不是同一个应用：装完后在「设置 → 应用 → 应用信息」里看到的包名应该与上表一致。官方商店版本会随更新变化，以官方页面当时显示为准。

## 四、系统要求

- 官方给出的安卓系统要求是 **Android 8.0 或更高**（以官网当时显示为准）；
- 应用分 iOS 与安卓两套，本篇只讲安卓 APK 的安装，iOS 侧走 App Store。

## 五、安装步骤

1. 把网盘里的 APK 下载到手机（用文件管理器找到它）；
2. 点击 APK，系统会提示「禁止安装未知来源应用」—— 按提示进入该来源的授权开关（不同厂商路径略有差异，一般在「设置 → 安全 → 安装未知应用」），对该文件管理器开启允许；
3. 回来继续安装，等进度走完；
4. 打开应用，首次启动会请求若干权限（通知、使用情况访问等），可以先拒绝非必需项，之后按 [首次设置与功能开启.md](首次设置与功能开启.md) 逐项开启。

## 六、安装后先确认两件事

1. **包名对得上**：见第三节，防止装到仿冒包；
2. **MD5 对得上**（可选）：用文件管理器或校验工具算一下 APK 的 MD5，与表中一致说明传输过程中没损坏。

装好并确认无误后，接着看 [首次设置与功能开启.md](首次设置与功能开启.md)。
