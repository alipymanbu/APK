## 一、先弄清楚：手机 App 只是两半中的一半

你搜到的「Home Assistant 安卓版」装到手机上，本身并不能控制任何设备。Home Assistant 分成两半：

- **服务器端**：跑在家里的 NAS、树莓派或虚拟机上，负责连设备、跑自动化；
- **手机端**（Companion App）：负责看面板、收通知、把手机的位置和传感器报给服务器。

手机端最低需要 **Home Assistant 0.104.0 或更高版本**的服务器（官方 companion 文档标注），服务器还没装的话，先从 [www.home-assistant.io/installation/](https://www.home-assistant.io/installation/) 挑一种方式装好，再回来装手机端。

## 三、full 和 minimal 差在哪（选错会缺功能）

官方把安卓端做成两种「口味」，包名都不同：

| | `full` | `minimal` |
| --- | --- | --- |
| 包名 | `io.homeassistant.companion.android` | `io.homeassistant.companion.android.minimal` |
| 依赖 Google Play 服务 | 是 | 否 |
| 位置跟踪 | 支持 | **不支持** |
| Matter 设备配网 | 支持 | **不支持** |
| Activity 类传感器 | 有 | **没有** |
| Wear OS 手表端 | 支持 | 不支持（需 Play 服务） |

网盘里这份是 **full 版**。如果你的手机没有 Google Play 服务、又只想拿它当遥控器看面板，装 minimal 也能用，但「人不在家自动关灯」这类基于位置的自动化就做不了了。

## 四、装之前确认两件事

1. **系统版本**：官方 companion 文档的兼容表写的是 **Android 6 及以上**；开发者文档另标注最低支持 API 21（Android 5.0）。两处口径不完全一致，你的手机在 Android 6 以上就稳妥，具体以 [companion.home-assistant.io](https://companion.home-assistant.io/docs/getting_started/) 页面当时显示为准。
2. **安装未知来源应用**：从网盘或 GitHub 下的 APK 属于「未知来源」，安装前在系统设置里允许一次该来源（文件管理器或浏览器各有一项）。

## 五、安装与首次启动

1. 装好 APK，打开，首页选 **Connect to my Home Assistant server**（连接到我的 Home Assistant 服务器）。
2. App 会搜同一局域网里的服务器；找到一个会直接给你连，找到多个会列出来让你挑。
3. 搜不到（或你人在外面）就点 **Enter address manually**（手动输入地址），填服务器地址。
4. 输入你在 Home Assistant 里创建的用户名密码登录。
5. 给这台手机起个名字 —— 它会变成服务器里实体 ID 的一部分，之后改要逐个改实体，第一次起个能认出来的名字。
6. 位置权限弹窗选 **Share my location**（共享我的位置）后，安卓端还要在系统权限里给到 **始终允许**，并允许「附近设备」，后台位置才会正常上报（详见 [位置不更新怎么排查.md](位置不更新怎么排查.md)）。

连不上是这一步最常见的坑，直接看 [连接不上服务器怎么办.md](连接不上服务器怎么办.md)。

## 六、核对一下包没被改过

官方在文档里公布了签名证书的 SHA-256 指纹，Play 商店与 GitHub releases 版本为：

```
11:19:4B:A8:09:B4:2D:DF:0E:1A:7D:EC:68:42:A5:9C:7F:F1:11:9C:54:82:E9:5F:EB:FF:D5:C6:01:4D:AA:5A
```

用 `apksigner verify --print-certs 应用名.apk` 或者开源工具 AppVerifier 比对即可；也可以先算 MD5 与上面表格里的值比对，能对上说明与网盘里存的那份是同一个文件。指纹本身也会随官方文档更新，以 [Android Flavors 页面](https://companion.home-assistant.io/docs/core/android-flavors) 当时公布的为准。
