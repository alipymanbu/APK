# 桌面上直接控制设备的方法

## 一、四个入口，按使用频率选

| 入口 | 在哪 | 适合放什么 | 系统要求 |
| --- | --- | --- | --- |
| 桌面小部件 | 长按桌面空白处 → 小部件 | 状态展示、一键执行、摄像头画面 | 不限 |
| 快捷设置磁贴 | 下拉通知栏的磁贴区 | 高频开关（灯、场景、脚本） | Android 7.0+ |
| 系统设备控制 | 电源菜单 / 快捷设置里的「设备控制」 | 成排的开关与滑杆 | Android 11+，随厂商有别 |
| 启动器快捷方式 | 长按 App 图标 | 直接跳到某个面板或视图 | 不限 |

这四类都是 App 自带的功能，full 与 minimal 版都有，不需要额外装东西。

## 二、桌面小部件：四种能放什么

添加方式一样：长按桌面空白处 → 小部件列表里找到 Home Assistant → 拖出来 → 按提示配置。已有小部件改配置：Settings → Companion App → **Manage Widgets**（Android 12 以上也可以长按小部件本身点编辑）。服务器是 Home Assistant 2025.12 或更新版本的话，还能在任意实体的 **more info** 页面选 **Add to** 直接生成小部件（仅限支持的实体类型，且只能在要显示的那台设备上操作）。

| 小部件 | 干什么 | 关键配置 |
| --- | --- | --- |
| Action button | 点一下执行一个服务调用，成功打绿勾、失败打红叉 | 可勾选「Require authentication」，点了先要指纹/PIN |
| Entity State | 显示某实体的状态与属性 | 实体 ID、字号、属性与分隔符、点按是切换还是刷新 |
| Media Player | 控制播放器 | 可填多个实体 ID（从左到右优先），可隐藏进度/音量键 |
| Picture | 显示摄像头或图片实体的最新快照 | 每小时自动刷新一次，或点按时刷新 |
| Template | 渲染一段模板 | 内容以能在小部件里放下为准，不能滚动 |

## 三、小部件不刷新、点了没反应

按这几条查，官方口径与实际踩点一致：

1. **数据省流（Data Saver）开着时小部件直接不工作** —— 关掉它，并确认该 App 的「后台数据」是开的；
2. 默认刷新频率是 **亮屏时每 30 分钟一次**，想实时刷新要去系统设置给它「通知读取权限」：**设置 → 通知 → 通知读取、回复与控制（部分机型叫「使用情况访问权限」）→ 找到 Home Assistant → 允许**。开了之后小部件才会随实体变化即时更新，代价是变化频繁的实体会更耗电（与 [手机耗电太快怎么调.md](手机耗电太快怎么调.md) 一起权衡）；
3. 配置改了没生效、状态卡住 —— 删掉小部件重新添加一遍；
4. Action button 一直红叉 —— 先确认 App 本身连得上服务器（见 [连接不上服务器怎么办.md](连接不上服务器怎么办.md)），能开 App 却点小部件失败，多半是该服务调用在服务器侧报错，去服务器日志里看。

部分国产桌面添加小部件时静默失败，去系统权限里给该 App 放开「创建桌面快捷方式」再试一次。

## 四、快捷设置磁贴：下拉一下就切换

在 Settings → Companion App → **Manage Tiles** 里配，最多 40 个；配好后编辑系统的快捷设置面板，把 Home Assistant 的磁贴拖进活动区。可配置项：标签与副标签（Android 10+）、图标、点击振动（失败时振两下）、**Require unlocked device**（锁屏时不许碰）。

支持的域：`automation`、`button`、`cover`、`fan`、`humidifier`、`input_boolean`、`input_button`、`light`、`lock`、`media_player`、`remote`、`siren`、`scene`、`script`、`switch`。点击时磁贴会亮一下表示正在调用服务器，成功就回到实体状态，失败会变成禁用态并给出错误提示。

## 五、系统设备控制：把开关放进电源菜单

Android 11 及以上、且系统支持「智能设备控制」的机器，会自动接管该功能。打开位置因厂商而异，常见在快捷设置面板、通知栏或电源菜单里，选 **Add Controls → Home Assistant**，就能把上面那些域加进去（`light` 有亮度滑杆、`climate` 有温度滑杆、`camera` 快照需 Android 12+、`vacuum` 按机型给启动/回坞）。

**锁屏能不能用是按系统版本分的**（截至官方文档所述，以系统实际为准）：

| 版本 | 锁屏可用性 |
| --- | --- |
| Android 11 | 锁屏可以直接用 |
| Android 12 | 锁屏不能用 |
| Android 13+ | 由你自己定：设置 → 显示 → 锁屏，打开「锁屏时使用设备控制」 |

Android 14 起还能把内置控件换成**整个 Home Assistant 面板**（Settings → Companion App → Manage device controls → 选 Dashboard 并填面板路径，如 `/lovelace/default_view`）。内置控件胜在锁屏策略细、多服务器可分页；面板胜在能力完整、布局随你排。登录了多台服务器时，也可以在同一页把它们拆成各自的页面，需要在 Manage device controls 里打开分页开关（打开后可能要移除再重加一次控件才生效）。

## 六、当平板用：设为默认启动器

把 App 设成手机/平板的默认启动器后，一解锁就是 Home Assistant 面板，墙挂平板场景常用这个做法（官方 2025 年 7 月的 Android 更新说明里确认了这一能力）。代价是原生桌面被替换，日常当平板用的机器不建议这么设。
