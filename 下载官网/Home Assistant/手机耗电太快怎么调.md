# 手机耗电太快怎么调

> 装完之后电量掉得比以前快，先分清是位置、传感器还是连接在烧，再逐项收。**相关文档**：[位置不更新怎么排查.md](位置不更新怎么排查.md) · [手机传感器能做哪些自动化.md](手机传感器能做哪些自动化.md) · [收不到通知怎么排查.md](收不到通知怎么排查.md)

## 一、先确认是不是它在烧

系统设置 → 电池 → 耗电排行，看 Home Assistant 排第几、单位时间耗电占比多少。排不进前列就先去别处找原因（屏幕、其他后台）。确认是它之后，按「位置 → 传感器 → 连接」的顺序查，这三块是手机端仅有的常驻耗电源。

## 二、位置：最大的一块

高精度模式（High accuracy mode）开着时 GPS 按固定间隔持续工作（默认 5 秒一次，可调下限也是 5 秒），官方文档直接标注它「会更快耗尽电量」，还必须挂一条常驻通知。省电的正确姿势不是关掉位置，而是**给它加约束**，让高精度只在需要时开：

- **蓝牙约束**：连上指定设备（车机、耳机）才开；
- **区域约束**：接近某个 zone 才开、进圈后关（配合「触发范围」在外圈提前启动）；
- 两个约束可选「满足其一」或「必须同时满足」。

约束方案的细节在 [位置不更新怎么排查.md](位置不更新怎么排查.md) 第五节。不开高精度时，后台位置本来就是 1~3 分钟一次的常规频率，耗电有限；再往下收就是把不用的位置类传感器在 Manage Sensors 里关掉。

## 三、传感器：上报频率是一档开关

**Settings → Companion App → Sensor Update Frequency** 三档：

| 档位 | 行为 | 用法 |
| --- | --- | --- |
| Normal | 默认频率 | 绝大多数人选这个 |
| Fast While Charging | 充电时才加快 | 白天充电、晚上正常 |
| Fast Always | 每分钟上报一次 | 只在你确实需要高频数据时开 |

官方 troubleshooting 明确给过一条排查口径：怀疑耗电异常时，**把 Sensor Update Frequency 拨回 Normal**，同时检查下面几项。只开你真正用到的传感器同样重要 —— 每多开一个，后台上报就多一路（哪些值得开见 [手机传感器能做哪些自动化.md](手机传感器能做哪些自动化.md)）。

## 四、三个容易被忽略的开关

官方 troubleshooting 里点名的耗电相关项：

1. **Persistent Connection（持久连接 / 本地推送）**：设为 **Never** 时不维持长连接。它是把通知改走本地 WebSocket、不经过 Google 推送通道的功能（见 [收不到通知怎么排查.md](收不到通知怎么排查.md) 第五节），开着会多一条常驻连接与一条可最小化的常驻通知 —— 要速度还是要电，二选一；
2. **Bluetooth Transmitter 类传感器**：别让它常开，用的时候再开；
3. **Single Accurate Location 的 Include in sensor updates**：确认**没**勾 —— 勾上会让每次传感器更新都附带一次定位，上报量明显变大。

## 五、系统侧：不让它被杀，也不让它乱烧

省电与保活是一对矛盾，两边都要设：

- **保活**（防止它被系统杀掉导致位置/通知断链，路径见 [位置不更新怎么排查.md](位置不更新怎么排查.md) 第二节）：电池优化设为「不允许」、允许自启动、多任务卡片加锁；
- **限电**：系统自己的「省电模式 / 低电量模式」该关就关（它会连带延迟通知与定位，见第六节的副作用）；个别机型提供「应用电池限制」，别对该 App 用「受限」档。

以华为机型为例（其他品牌菜单名不同，思路一致，以各系统版本实际菜单为准）：设置里搜「电池优化」→ 该应用设为不允许；设置 → 电池 → 更多电池设置 → 打开「休眠时始终保持网络连接」；多任务界面对该应用卡片下拉加锁；关闭省电模式。

## 六、一条需要权衡的边界

关掉系统省电、放开后台之后，App 不被杀了，待机耗电会小幅上升 —— 这是正常代价：**你用「后台不中断」换「位置准、通知到」**。真正的异常是「什么都没配就掉电明显」，那种情况逐项关回去定位元凶。

另外有社区用户反馈，高精度模式在区域边界反复开关时会出现发热与异常耗电（单一论坛帖，只作参考）—— 遇到边界抖动，把触发范围调大、或直接给约束加上「与蓝牙同时满足」，能明显减少来回切换。
