## 一、按症状对号入座

| 你看到的现象 | 最可能的原因 | 直接跳到 |
| --- | --- | --- |
| 一直转圈，搜不到任何服务器 | 手机与服务器不在同一网段 / 服务器端口没通 | 第二节 |
| 能搜到，点连接就白屏 | 自签名证书没被系统信任 | 第三节 |
| 在家好好的，出门就报 SSL 错误或连不上 | 远程访问没配加密，或 Cloud 开关配错 | 第四节 |
| 登录后没多久又掉线、要求重新登录 | 用了「受信任网络」登录，出门后不认 | 第五节 |
| 界面能开但和电脑上表现不一样 | 不是连接问题，是前端或插件本身 | 第六节 |

## 二、搜不到服务器：先确认网络路径

App 的自动发现只在同一局域网里广播，以下几步按顺序查：

1. **手机和服务器是不是同一个网段**。手机连的访客 Wi-Fi、IoT 专用 Wi-Fi 通常与主网隔离，发现广播过不去 —— 换到主网试。
2. **服务器地址通不通**。同一网络下用手机浏览器访问 `http://服务器IP:8123`（8123 是默认端口），打得开说明服务在，问题在 App 侧；打不开先去看服务器。
3. **VPN / 代理**。手机上开着 VPN 时流量被接管，发现与直连都可能失败，先关掉试一次。
4. 仍不行就点 **Enter address manually**，手动填地址（局域网用 `http://192.168.x.x:8123`，远程用你配好的域名）。

同一网络里有多个 Home Assistant 实例时，App 会列出全部让你选，选错实例也会表现成「登录不上」—— 你输入的账号在那个实例里不存在而已。

## 三、点了连接就白屏：自签名证书

自签名证书（自己给域名签的证书）在安卓上会卡在白屏。处理思路是让系统信任它：

- 正式一点的做法是给域名签一张受信任的证书（Let's Encrypt + Duck DNS 之类的组合是官方文档举的例子），换成正式证书后白屏消失；
- 退而求其次，把证书导入安卓系统的「信任的证书」列表（Android 9 及以上操作方式接近，官方文档有对应步骤）。

URL 本身也要填对：协议、端口、路径少一段都会连不上，先把地址贴到浏览器里确认能打开登录页。

## 四、出门就连不上 / 报 SSL 错误

App **强制要求远程连接走加密通道**。官方排查口径分两种情况：

1. **开了 Home Assistant Cloud 但没开远程访问**：侧边栏 → Settings → Companion App → Settings → Connection，把 **Connect Via Cloud** 关掉，在 **External URL** 里填你自己的远程地址（必须是 https 这类加密连接）。
2. **压根没配 Home Assistant Cloud**：那基本就是远程地址本身不加密。要么开通官方的 Home Assistant Cloud（远程接入是它的订阅功能），要么自己配反向代理 + 证书，二选一。

家里有公网 IP 的话，路由器端口转发 + 证书就能直连；没有公网 IP 就走内网穿透或 Home Assistant Cloud，这三条路各有权衡，选一条稳定用下去即可。

## 五、只有在家才能用：受信任网络的副作用

配置连接时有个安全级别选择：

| 选项 | 行为 | 适合谁 |
| --- | --- | --- |
| **Most secure**（最安全） | 只有在家（连着你确认过的 Wi-Fi）时才允许非加密连接 | 绝大多数家用场景 |
| **Less secure**（较不安全） | 任何网络都允许非加密连接 | 不建议在公共网络用 |

坑在于登录方式：如果你在服务器上开了 Trusted Networks（受信任网络），并且 App 里也是靠它免密登录的，那么离开那张网 App 就没有凭据可用，表现为「出门连不上」。**登录时手动输入用户名密码**，不要走受信任网络免密，这条在官方 getting started 里也是明确建议。

受信任网络与 VPN/以太网也可以作为受信网络加入（安卓支持），后续在 Settings → Companion App → 对应服务器里随时增删。

## 六、连上了但功能不对

界面某个卡片、某个自定义组件在手机上不正常，先做两步区分责任：

1. 手机上把 App 强制停止后重新打开，或在页面顶部下拉刷新；
2. 用手机浏览器（Chrome）打开同一个地址看同样的页面。

浏览器里也不对 → 问题在 Home Assistant 前端或该自定义组件本身，与手机端无关；只有 App 不对 → 才是手机端的问题，可去 [github.com/home-assistant/android/issues](https://github.com/home-assistant/android/issues) 反馈，附上「浏览器正常、App 异常」这个关键信息。

## 七、以上都不管用时的重来一遍

官方给的「从头开始」顺序很挑剔，**照顺序做、别跳步**：

1. 确认 Home Assistant Core、App、系统 WebView 都是新版；
2. 在系统设置里对该 App 执行 **清除存储/清空数据**（不要图省事直接卸载重装，那会触发自动备份恢复，反而把坏状态带回来）；
3. 到服务器的集成面板，把这台设备的 Mobile App 条目移除（有多条就全移除）；
4. 重启 Home Assistant；
5. 重新打开 App 登录，多台设备的话在引导里给这台改名，**用账号密码登录**。

登录后如果发现某些功能仍异常，再回到对应篇目排查：位置类看 [位置不更新怎么排查.md](位置不更新怎么排查.md)，推送类看 [收不到通知怎么排查.md](收不到通知怎么排查.md)。
