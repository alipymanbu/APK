# SoloPi 常见问题与排查

> 本篇按"装不上 → 权限过不去 → 录制定位不准 → 性能测不出数 → 多机不同步"的顺序，整理 SoloPi 使用中最常遇到的故障与处理办法。

SoloPi 的故障有个共同特点：绝大多数不是应用本身坏了，而是**权限、调试通道或机型限制**这三类外部条件没满足。因此排查顺序建议固定为——先确认包和版本对不对，再看权限，最后才怀疑功能本身。下面按环节列出典型症状与处理办法。

## 一、安装与启动阶段

| 现象 | 常见原因 | 处理办法 |
| --- | --- | --- |
| 点击安装包无反应 | 没有给当前应用「安装未知应用」权限 | 到系统设置的应用权限里给文件管理器或浏览器打开该开关 |
| 提示应用未经过安全检测 | 第三方渠道安装包的系统提示 | 选择继续安装，属正常提示 |
| 想确认版本对不对 | 网上信息与手上这份包不一致 | 以 [下载与安装教程.md](下载与安装教程.md) 第二节列出的版本 0.12.0、包名 `com.alipay.hulu`、体积 5.07 MB 为准 |
| 装完想换个版本 | 需要重新取包 | 从 [SoloPi 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9dc1f415070a) 获取 |

## 二、权限与调试通道

这一类问题最集中，也最容易误判成"功能失效"：

1. **重启设备后所有功能都不动作** —— 最常见的原因。它靠设备侧的远程调试端口工作，而这个端口重启后不保留。用数据线连接电脑，重新执行一次 `adb tcpip 5555` 即可恢复。
2. **悬浮窗看不到 / 授权弹窗点了没反应** —— OPPO、vivo 等机型可能无法正确判断悬浮窗是否真正生效。直接去手机管家的应用管理里为 SoloPi 授予悬浮窗权限，再回到 SoloPi 点「我已授权」。
3. **无障碍（辅助功能）校验通不过** —— 先把辅助功能关闭，再重新开启；仍然通不过就重启设备，多数是系统侧状态残留导致。
4. **adb 授权弹窗** —— 勾选「永远允许这台电脑」后再确定，否则每次都会被拦。
5. **一机多控连不上、扫不了码** —— 确认相机与录屏权限已授予；这两项只在进入一机多控时才申请，漏给就会卡在连接环节。
6. **长时间运行中途失效** —— 检查是否已把 SoloPi 加入后台白名单，未加白名单时进程可能被系统回收。

机型专属开关（vivo 的 USB 安全操作、小米的 USB 安装与 USB 调试（安全设置）+ 后台弹出界面、魅族的支付安全）逐项列在 [下载与安装教程.md](下载与安装教程.md) 第五节，排查时对照检查一遍。

## 三、录制回放阶段

| 现象 | 原因 | 处理办法 |
| --- | --- | --- |
| 高亮红框圈中的控件不是想操作的那个 | 当前查找模式不适配该界面 | 切到 **H5 增强模式**重试，混合开发页面尤其常见 |
| 通用模式和 H5 增强模式都找不到控件 | 控件不在视图树里（如游戏画面） | 切到**图像查找模式**，截屏后手动框选操作区域 |
| 点击启动后没有跳到被测应用首页 | 被测应用未正确声明 `android.intent.category.LAUNCHER` | 手动打开被测应用，再继续录制 |
| 悬浮窗图标一直是红色、后续操作没反应 | 上一步动作尚未执行完 | 等图标转为黄色再继续，期间不要连续点击 |
| 回放失败但看不出原因 | 缺少现场信息 | 按顺序看结果页四块：回放概况 → 用例步骤信息（对比目标节点与实际查找节点）→ 应用日志 → 用例截图，详见 [录制回放用例怎么录.md](录制回放用例怎么录.md) 第四节 |
| 日志时间戳早于回放开始时间 | logcat 按进程全量抓取 | 属正常现象，不是故障 |

需要处理"弹窗可能出现也可能不出现"这类分支时，用长按用例的**编辑**功能加入 IF、WHILE 逻辑，比录两条用例更省事。

## 四、性能数据与响应耗时

1. **帧率数值看起来不对** —— 画面接近静止时部分数值会失真，在滑动、翻页等动态场景下测量。
2. **响应耗时偏大** —— 目标页面存在动画会影响计算准确性，对比时保持动画条件一致。
3. **找不到录制好的性能数据文件** —— 数据在 `/sdcard/solopi/records/` 下；没有读写权限时会落到 `/sdcard/Android/data/com.alipay.hulu/files/solopi/records/`。另外注意默认只保留最近 3 天的文件，可在设置页把「自动清理文件」改为 `-1` 关闭清理。
4. **响应耗时结果明显异常或为负数** —— 该次测算失效，重新测算，以多次测算后稳定的结果为准。
5. **结束录制后一直卡在"计算中"** —— 关闭浮窗、退出 SoloPi，重新打开耗时计算工具再测。
6. **结果页有轮播图，耗时被拉长** —— 进入结果页后，在轮播图开始变化之前就点击结束录制。
7. **响应耗时或图像查找功能直接不可用** —— 检查设置页的 Plugin 拉取地址是否已配置为可用地址，这项不配好相关功能不会加载。

指标含义与维度口径（哪些是进程维度、哪些是应用维度、哪些是全局）见 [性能测试指标怎么测.md](性能测试指标怎么测.md)。

## 五、一机多控阶段

- **从机收到连接提示但没有进入受控** —— 主机侧需要再点击一次「连接」才会正式建立连接，只扫码是不够的。
- **从机不回放或回放内容与主机不一致** —— 部分从机会因为弹窗、机型适配等原因产生差异，需要在从机上手动辅助操作，这是多机型测试的正常情况。
- **主机结束后从机悬浮窗没退出** —— 手动退出 SoloPi 即可。
- **自动安装失败（OPPO / vivo）** —— 安装时需要密码，检查设置页的「OPPO/VIVO 密码」是否与实际密码一致，默认值是 `a1234567`。
- **多台设备连线要求** —— Android 目前不支持通过 Wi-Fi 同时调试多台设备，初始化阶段需逐台用数据线执行 `adb tcpip 5555`。

完整的主从机操作流程见 [一机多控做兼容性测试.md](一机多控做兼容性测试.md)。

## 六、还搞不定时

按上面的顺序排查后仍然不通，建议按这个方式收集信息：

1. 记录设备的品牌、型号、Android 版本；
2. 记录单独复现的最小步骤（例如"进录制回放点启动 → 悬浮窗不出现"）；
3. 如果问题出在用例转换环节，先回看 [用例转Appium与Macaca脚本.md](用例转Appium与Macaca脚本.md)，确认导出与转换的前置条件是否满足。

重新安装一遍往往能解决权限状态混乱的问题，安装包始终从 [SoloPi 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9dc1f415070a) 获取，装完按 [下载与安装教程.md](下载与安装教程.md) 第五节重新逐项授予权限。
