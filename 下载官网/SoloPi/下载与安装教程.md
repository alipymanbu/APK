SoloPi 是支付宝开源的一款 Android 测试工具，免 Root，也不用改被测应用的代码，装上就能在手机上做自动化与性能测试。用它的人主要是 App 测试工程师和客户端开发者。本篇只解决一件事：把安装包装进手机，并把各项功能需要的前置条件配好。

## 一、SoloPi 能干什么

它的能力围绕三件事展开，第一次上手可以先确认自己属于哪一类需求：

| 能力 | 解决什么问题 | 被测对象 |
| --- | --- | --- |
| 录制回放 | 手工点一遍流程，就得到一条可重复执行的自动化用例 | 任意 App |
| 性能测试 | 实时观察并录制 CPU、内存、帧率、流量、响应耗时等指标 | 任意 App |
| 一机多控 | 一台主机操作，多台从机同步回放，用于兼容性测试 | 多台设备 |

前两项在单台手机上就能完成，不需要连电脑跑脚本；一机多控需要多台设备处于同一局域网。

## 三、安装步骤

1. **转存并下载**：从 [SoloPi 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9dc1f415070a) 把 APK 转存到自己的网盘，再下载到手机或电脑。
2. **把包送到手机上**：手机端直接下载最省事；电脑上下载的话，用数据线、微信文件传输助手或任意传输方式拷进手机存储均可。
3. **允许安装未知来源应用**：在手机「设置 → 应用 → 特殊应用权限 → 安装未知应用」中，给当前用于打开安装包的应用（文件管理器 / 浏览器）打开开关。国产定制系统里这项通常在「安全」或「隐私」分类下。
4. **点击 APK 完成安装**：若系统提示「应用未经过安全检测」，选择继续安装即可，这是第三方渠道安装包的常规提示。
5. **先不要急着打开**：SoloPi 的部分能力依赖设备侧的调试通道，建议先完成下一节的环境准备，再启动应用。

## 四、首次启动前：准备 adb 调试环境

装完还不能直接用：它要在设备上拿到一套命令行执行能力，所以得先用电脑上的 adb 做一次初始化。这一步比装普通 App 多花几分钟，跳过它后面所有功能都不会动。

### 4.1 电脑端准备 adb

1. 安装 Android Studio，或单独下载 Android SDK 的 `platform-tools` 包；
2. 把 `platform-tools` 目录加入系统环境变量 `PATH`；
3. 打开终端，执行 `adb version`，能输出版本信息即表示环境可用。

### 4.2 手机端打开开发者选项

在「设置 → 关于手机」中连续点击版本号若干次，开启开发者选项，然后进入开发者选项打开 **USB 调试**。

### 4.3 开启无线调试端口

用数据线连接手机与电脑，在终端执行：

```bash
adb devices
```

确认列表中出现 `device` 之后，执行：

```bash
adb tcpip 5555
```

这条命令让设备在 5555 端口开放远程调试，之后才能在手机上独立执行命令。

> 注意：**设备每次重启后都要重新执行一次 `adb tcpip 5555`**，否则 SoloPi 会出现"悬浮窗点不动、功能全部失效"的现象。另外，Android 目前不支持通过 Wi-Fi 同时调试多台设备，所以调试阶段请保持数据线有线连接。

## 五、首次启动要授予的权限

第一次打开时，它会依次弹出下列权限申请 —— 逐项给全，否则后面的功能会中途被打断：

| 权限 / 设置 | 在哪里给 | 不给会怎样 |
| --- | --- | --- |
| 文件读写 | 启动时的系统弹窗 | 数据写入降级目录，后续找录制文件的位置不一样 |
| adb 授权 | 系统弹窗，勾选「永远允许这台电脑」 | 控件获取与事件驱动不可用 |
| 悬浮窗 | 弹窗中「前往授权」，授权后返回点「我已授权」 | 看不到实时数据，也点不动悬浮窗 |
| 后台白名单 | 系统弹窗，建议选择不再提示 | 长时间运行时进程可能被系统回收 |
| 相机、录屏 | 使用一机多控时才申请 | 主从机扫码连接、响应耗时计算无法使用 |

存储位置需要特别记一下：**给了读写权限，数据写在 `/sdcard/solopi`**；没给的话会落到 `/sdcard/Android/data/com.alipay.hulu/files/solopi`，后面凡是出现前者的路径，都按这个换。

部分机型还有额外开关，漏开会导致录制回放与一机多控"看着正常、实际不动作"：

- **vivo**：开发者选项中的「USB 安全操作」需要手动打开；
- **小米**：开发者选项中同时打开「USB 安装」与「USB 调试（安全设置）」，并在应用权限里额外允许「后台弹出界面」；
- **魅族**：若被测应用属于支付、金融类，需要在手机管家中关闭安全支付功能；
- **OPPO / vivo**：悬浮窗授权弹窗可能不响应，直接去手机管家的应用管理里授予悬浮窗权限。

## 六、设置页里建议先改的两项

点击主界面右上角的设置图标进入：

- **Plugin 拉取地址**：如需使用响应耗时与图像查找功能，需配置为可用地址 `https://raw.githubusercontent.com/soloPi/SoloPi/master/<abi>.json`（`<abi>` 按设备架构替换）。这一项不配好，相关功能会直接不可用。
- **自动清理文件**：默认清理修改时间超过 3 天的已下载文件，配置为 `-1` 表示不清理；如果希望保留较久的性能数据文件，先改这里。

另外两项按需使用：**导入外部用例**会从 `/sdcard/solopi/import` 读取 JSON 用例并在导入后删除原文件；**OPPO/VIVO 密码**用于一机多控中的自动安装，默认值可在设置里修改。

## 七、装完做一次最小验证

1. 打开 SoloPi，确认三项权限（读写、adb、悬浮窗）已全部通过；
2. 进入「录制回放」，点击启动按钮，能弹出操作悬浮窗并自动跳到目标应用首页，说明安装与初始化都成功了；
3. 退出悬浮窗，回到主界面即可。

如果卡在这一步，先看 [常见问题与排查.md](常见问题与排查.md)，多数情况是 `adb tcpip 5555` 没重做或悬浮窗权限没真正生效。

安装包与后续版本更新，统一从 [SoloPi 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9dc1f415070a) 取用。
