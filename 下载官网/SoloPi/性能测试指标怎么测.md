不用连 Android Studio，也不用改代码，在手机上边操作边看 CPU、内存、帧率、流量、响应耗时和电流，数据还能录成文件带回电脑分析。常见用法是版本间的性能对比、卡顿定位和耗电回归。

## 一、能看哪些指标

先分清指标的统计维度，否则很容易把进程数据和全局数据混在一起看：

| 指标 | 维度 | 具体内容 |
| --- | --- | --- |
| CPU | 进程 + 全局 | 顶层 Activity 所在进程的 CPU 占用百分比、全局 CPU 占比 |
| 内存 | 进程 + 全局 | 顶层进程的 PSS（实际使用内存）、Private Dirty（私有内存）、全局占用内存 |
| 帧率 | 应用 | 实际帧率、延迟帧数、1 秒内单帧最长延迟、延迟帧数占比 |
| 网络 | 应用 + 全局 | 应用上下行速率与累计流量、全局上下行速率与累计流量 |
| 响应耗时 | 应用 | 点击响应耗时（用户点击到系统首次发出界面更新）、刷新耗时（到界面停止刷新） |
| 电池 | 全局 | 设备瞬时电流与电流均值 |

三个需要提前知道的口径细节：

- **多进程应用会自动跟随顶层进程**。CPU 与内存记的是顶层 UI 进程的数据，进程切换时会跟着切到新进程，不用你手动改。
- **帧率在画面接近静止时数值可能不准**，**建议在滑动、翻页这类动态场景下测帧率**。
- **响应耗时会被动画影响**。目标页面有动画时，测出来的响应耗时会偏大，对比时要在相同动画条件下比。

## 二、实时观察

开始观察前，设备上需要已装好 SoloPi 并授予 adb、悬浮窗、读写三类权限。若这台设备还没装，先从 [SoloPi 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9dc1f415070a) 取包安装，权限逐项怎么给见 [下载与安装教程.md](下载与安装教程.md)。

1. 在性能测试页面勾选要看的性能项，SoloPi 会通过悬浮窗展示对应指标。
2. 进入被测应用之前，显示的是全局指标；进入应用之后，显示的是应用最上层进程的指标。
3. 点击悬浮窗上的应用标题，可以主动切到目标应用，把数据切换为进程维度。
4. 累计类数据（网络、电池）旁边有清零按钮，做分段对比前先清零，避免上一段的累计值干扰。

## 三、把数据录下来

观察只能看趋势，复现问题还得靠录制：

1. 点击悬浮窗的开始按钮（绿色三角）开始录制，然后正常操作被测应用；
2. 结束时点击终止按钮（红色圆形），SoloPi 会提示数据存放位置，文件保存在 `/sdcard/solopi/records/` 下的对应目录；
3. 录制文件是 **CSV 格式，共三列**：第一列 Unix 时间戳，第二列数据数值，第三列额外字段。

录制完成后点悬浮窗右上角的关闭键即可退出，悬浮窗不会自动消失，需要手动回到性能测试页面。

没有文件读写权限时，上面的路径要换成 `/sdcard/Android/data/com.alipay.hulu/files/solopi/records/`。

## 四、回看历史录制数据

在性能测试页面的「录制数据查看」里可以调出之前录过的各项数据，用录制项筛选切换指标，并用图表展示。数据条数多了以后，点右上角删除图标清理旧数据，避免堆积。

## 五、环境加压

SoloPi 支持对 CPU 和内存施加压力，用来复现应用在低性能设备、内存紧张场景下的表现（例如观察卡顿、OOM 的表现差异）。使用时有两个系统层面的限制要注意：

- 应用处于后台时，CPU 加压的比例会被系统调度限制，压不到设定值；
- 内存加压过大时 SoloPi 自身可能被系统回收，导致录制中断。

因此加压测试建议在被测应用处于前台、且压力值从小往大调的过程中观察。

## 六、响应耗时计算工具

它比看日志打点更接近用户的真实感受：录屏后逐帧对比画面变化，自动判定起始点与结束点。

**适用场景**：原生应用、H5、游戏均可；支持启动耗时、页面跳转耗时、列表滑动耗时、动画耗时四类测量。

**操作步骤**：

1. 进入性能测试页面，点击启动耗时计算；
2. 参数一般保持默认即可，点击启动按钮，会弹出录制浮窗；
3. 切换到待测应用，进入操作路径的起始页面。如果不想把细微动画算进去，把二值对比差异设为 2%；
4. 点击开始录制（按钮会变为结束录制），在被测应用上执行待测操作；
5. 页面停止变化后点击结束录制，几秒后显示测试结果。

**三个典型异常与处理**：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 结果明显偏大、偏小或为负数 | 本次测算失效 | 重新测算，结果以多次测算后稳定值为准，不要采信单次异常值 |
| 一直卡在"计算中" | 计算线程阻塞 | 关闭浮窗、退出 SoloPi，重新打开耗时计算工具再测 |
| 结束页有轮播图导致耗时被拉长 | 轮播图持续刷新界面 | 进入结果页后，在轮播图变化之前点击结束录制 |

## 七、把数据送到服务端

设置页里有两个上传地址配置项：**性能数据上传地址**与**响应耗时上传地址**，分别用于把录制回放、一机多控或性能工具产生的数据送到自建服务端做进一步处理。不接服务端时保持留空即可，本地 CSV 已经够做离线分析。

性能数据记录、环境加压与响应耗时计算都在同一个安装包内，可从 [SoloPi 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9dc1f415070a) 获取。
