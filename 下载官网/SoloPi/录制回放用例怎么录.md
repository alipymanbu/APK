> 本篇讲 SoloPi 录制回放的完整流程：控件查找怎么选、一条用例怎么录、回放结果怎么看、用例怎么管理和批量跑。

在手机上正常操作一遍，SoloPi 会把每一步的操作类型和目标控件记下来，之后在本机或别的设备上重放 —— 「回归一次靠人点」就变成「点一遍、跑很多遍」。主要用在这三个场景：功能回归、冒烟验证、兼容性抽查。

## 一、先选对控件查找模式

录制时如果发现红框圈错了控件，第一个该调的就是查找模式。一共三种，按下面的顺序试：

| 模式 | 适用场景 |
| --- | --- |
| 通用模式 | 常规原生控件的 App |
| H5 增强模式 | 混合开发 App 中的 H5 页面、小程序 |
| 图像查找模式 | 游戏，或前两种模式都定位不到的控件 |

选择顺序建议是：先用通用模式录，发现红框与目标控件不符就切到 H5 增强模式，两者都找不到再切图像查找模式。图像查找模式会截取当前屏幕，由你手动框选要操作的区域。

## 二、录制之前

录制回放功能需要 adb、悬浮窗、后台白名单与文件读写四类权限，第一次点击入口时 SoloPi 会逐项申请。若还没装好包或权限没给全，先看 [下载与安装教程.md](下载与安装教程.md)；安装包本身可从 [SoloPi 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9dc1f415070a) 获取。

## 三、录一条用例

1. 进入 SoloPi 的录制回放页面，选择被测应用，点击启动按钮。屏幕上会弹出操作悬浮窗，并尝试自动跳到被测应用的首页。
   - 跳转依赖 Android 的 `android.intent.category.LAUNCHER` 声明，如果被测应用没有正确声明启动页，这一步会失败，需要手动打开应用。
2. 在悬浮窗中点击开始按钮，进入录制状态。
3. 按正常使用习惯操作被测应用。录制过程中你的操作会被拦截、当前点击的控件会被高亮，并弹出操作选择框让你确认这一步记成什么操作。
   - 悬浮窗上的图标变红表示正在执行动作，执行完会转为黄色，动作执行期间耐心等待即可。
4. 需要处理弹窗、跳转 scheme 之类不属于某个具体控件的动作时，点击悬浮窗上的 "π" 图标唤起全局操作选择框（Android 5.0 及以上可直接点击；4.x 设备需要从屏幕底部向上滑动唤起）。
5. 全程录完后，在全局操作选择框中选择结束，回到 SoloPi 录制回放页面，这条用例已经存在本地了。

## 四、回放与结果解读

1. 在录制回放页面点击「查看全部」，进入本地用例列表。
2. 点击任意一条用例，被测应用会被打开并进入准备回放状态，再点开始按钮才真正回放；过程中会高亮待操作的控件。
3. 回放结束后，结果页分成四块，排查失败步骤时按这个顺序看：

| 结果区块 | 里面有什么 | 怎么用 |
| --- | --- | --- |
| 回放概况 | 整体执行情况 | 先看失败总数 |
| 用例步骤信息 | 每一步的执行明细，可对比目标节点与实际查找节点 | 定位是哪一步的控件找错了 |
| 回放应用日志 | 从 logcat 中抓取的目标应用所有进程日志 | 判断是被测应用报错还是用例本身有问题 |
| 用例截图 | 执行过程中的截图 | 直观确认界面停在哪个页面 |

需要留意：日志来自 logcat 全进程抓取，因此会包含一部分开始回放之前的记录，不要被时间戳误导。

## 五、用例列表能做的四件事

在「查看全部」里长按任意一条用例，会弹出四个操作：

- **删除用例**：从本地数据库中移除这条记录；
- **导出用例**：导出到 `/sdcard/solopi/export` 目录，方便备份或迁移到别的设备；
- **重复播放**：反复执行同一条用例，可配置回放次数以及每次执行前是否重启被测应用；跑完后展示批量执行结果，点单项可看单条结果；
- **编辑用例**：对步骤进行增、删、改，并支持在用例中加入 IF、WHILE 逻辑判断，用来处理"某个弹窗可能出现也可能不出现"这类分支场景。

## 六、批量回放

点击页面右上角的「批量回放」，勾选需要执行的若干条用例，确定后依次执行，全部结束后回到批量回放结果页，可以逐条点开查看。适合版本发布前把一批冒烟用例一次性跑完。

## 七、把用例搬到另一台设备

用例以 JSON 形式保存在本机，跨设备迁移走的是文件流：

1. 在源设备长按用例 → 导出，文件落到 `/sdcard/solopi/export`；
2. 把导出的文件拷贝到目标设备；
3. 目标设备上放入 `/sdcard/solopi/import` 目录；
4. 在 SoloPi 设置页使用「导入外部用例」，导入完成后原始文件会被自动删除。

如果没给 SoloPi 读写权限，上面两个目录都要替换为 `/sdcard/Android/data/com.alipay.hulu/files/solopi` 下的同名子目录。

用例录制功能包含在 [SoloPi 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9dc1f415070a) 的同一个安装包里，不需要额外组件。
