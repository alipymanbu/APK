## 一、安装阶段的问题

### 1. 提示「解析包时出现问题」/「安装包已损坏」

下载的 apk 不完整或已损坏。回[下载与安装教程.md](下载与安装教程.md) 第四节核对大小与 MD5（应为 40.60 MB、`42177a71ab96b1de68dbdb4a0b6c1928`），对不上就重新下载。

### 2. 提示「禁止安装未知来源的应用」

安卓不允许安装来源不明的应用。按提示进入**设置 → 允许安装未知来源应用**，给拉起安装的那个应用（文件管理器 / 浏览器 / 网盘）开权限，再返回继续安装。装完可以关掉这个开关。

### 3. 提示「与已安装的应用签名不一致」/「安装失败」

手机里已有一个同包名但**签名不同**的版本（不同渠道的包互不兼容，版本号相同也会冲突）。处理：

1. 先试直接安装，部分系统允许覆盖；
2. 不行就**先卸载旧的再装**——注意卸载会清掉应用本地数据，账号类数据登录后可找回，仅存本地的记录会没；
3. 装完是哪个版本，以**设置 → 应用管理**里显示的版本号（应为 1.9.8.4.5）为准。

### 4. 提示「存储空间不足」

清理手机存储后重装。这个包 40.60 MB，加上安装展开的空间，至少留 200 MB 余量更稳。

### 5. 系统弹「风险应用」「未上架应用」警告

该提示的触发条件是「应用不在当前使用的商店里上架」，不针对文件本身。是否继续由你自己判断；拿不准可以对照 MD5 确认文件没被换过。

## 二、打不开 / 一直加载

### 1. 打开就闪退

按顺序试：

1. **重启应用**：上滑清掉后台再打开。
2. **重启手机**：系统状态异常时这一招常比什么设置都管用。
3. **系统版本太老**：第三方下载页标注需要较新的安卓版本（各页面标注不一，以你装的时候系统不报错为准）。系统过旧、装上就闪退的，考虑升级系统或换设备。
4. **包本身的问题**：换网络重新下载安装包，核对 MD5 后重装（步骤见[下载与安装教程.md](下载与安装教程.md)）。

### 2. 打得开但内容全是空的 / 一直转圈

1. **先确认网络能用**：打开别的联网应用试一下；只有它转圈，问题在应用侧。
2. **切网络**：Wi-Fi 与流量互换。部分网络环境访问不了它的服务器，换一个网络（比如换 Wi-Fi 或开移动数据）通常立刻恢复。
3. **关掉省流量 / 断网拦截**：手机自带的网络管控、流量防火墙可能拦了它的联网请求，到设置里放行。
4. **清缓存**：**设置 → 应用管理 → iwara里站 → 存储 → 清除缓存**（注意别点「清除数据」，那会把登录状态一起清掉）。缓存里存的旧数据有时会把页面卡住，清完重开。
5. **检查是不是权限问题**：网络相关权限被关掉也会表现成「加载不出来」，对照[权限与隐私说明.md](权限与隐私说明.md) 第二节的表格逐项看。

### 3. 封面显示了，点进去正文图裂 / 加载一半

单章内容加载失败，多半是网络抖动。退出重进该章节，或按上一条清缓存；持续裂图则按第 2 条换网络。

## 三、用着不正常

### 1. 收不到更新提醒 / 红点

去**设置 → 应用管理 → iwara里站 → 通知**确认通知权限开着；再看应用内是否把提醒关了。两处都开才有提醒。

### 2. 壁纸保存不进相册

存储 / 相册权限没给。到**设置 → 应用管理 → iwara里站 → 权限**里把存储（或「照片和视频」）改为允许，再保存一次。权限逐项说明见[权限与隐私说明.md](权限与隐私说明.md)。

### 3. 手机换了新版，安装包还是旧的

网盘里这份是 1.9.8.4.5（2026-09-23 的包）。应用商店若已上架更新版本，可直接在商店升级；想继续用网盘这份，就以分享页当时提供的文件为准。**版本号相同但大小不同的包不要混着覆盖装**，会触发签名冲突（见第一节第 3 条）。

### 4. 想卸载干净

**设置 → 应用管理 → iwara里站 → 卸载**。卸载不会删除你相册里已保存的壁纸图片；账号数据在服务端，下次装回登录即可找回收藏。

## 四、内容与账号类问题

以下几条整理自用户反馈，成因多数是关键词、标签或登录状态，不一定是故障：

### 1. 搜索不到想看的内容

1. **换关键词**：作品名打全称、或只用其中的关键词试一次；不同页面对同一作品的标签用词常不一样，换同义词搜命中率更高。
2. **换入口**：搜索框没结果时，改从分类 / 排行 / 书单里翻——榜单与书单是人工整理的，能搜到搜索未必能搜到的内容。
3. **确认没拼错**：输入法带出的全角字符、多余空格都会让搜索落空，删掉重输。

### 2. 收藏、书架的内容突然不见 / 换手机后找不回来

1. 先看**是否掉登录了**——「我的」页面头像是不是空的；未登录时收藏只在本地，页面刷新或网络失败就可能显示为空。
2. 重新登录后等一会儿再看，服务端同步有时延。
3. 还是空的，按上文第二节第 2 条里的清缓存步骤重开（别点「清除数据」，那会退出登录）。
4. **换手机后收藏是空的**：确认新手机上登录的是同一个账号。没登录时的收藏只存在本机，换设备或清数据后不保留——以后收藏前先登录。

### 3. 评论区加载不出来

评论依赖网络请求，先按上文第二节第 2 条检查网络；持续加载失败多为服务端延迟，隔段时间刷新即可，一般与你手机上的设置无关。

### 4. 登录后看到的内容和别人不一样

不同账号的权限、以及服务端按账号做的内容差异，都会造成同一页面显示不同——这类差异属于按账号区分，不是你装错了包。要确认装的是哪一款、以及和别的「i站」有什么不同，见[和i站网页版的区别.md](和i站网页版的区别.md)。
