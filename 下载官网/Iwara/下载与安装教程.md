## 一、先弄清楚你装的是哪一个

网上叫「iwara」「i站」的资料很多，指向的却不是同一个东西：有的指海外的 MMD 视频网站，有的指漫画阅读应用。本文只讲**包名为 `com.youxiang.iwaralz` 的这一款**——应用商店里显示的名称是「iwara里站」，开发者为苏州优像网络科技有限公司，主打漫画阅读与壁纸浏览（商店页的产品介绍见[漫画阅读与壁纸使用指南.md](漫画阅读与壁纸使用指南.md)）。

## 二、从网盘拿安装包

1. 打开 [https://pan.quark.cn/s/8e821bd7742d](https://pan.quark.cn/s/8e821bd7742d)（Iwara 安装文件资源，夸克网盘分享页）。
2. 转存到你自己的网盘，或直接下载到手机 / 电脑。
3. 下载到手机时直接得到 apk 文件；下载到电脑再传手机也一样，用数据线、网盘客户端或局域网传输工具都行。
4. 文件名应为 `Iwara_v1.9.8.4.5.apk`，大小约 40.60 MB。对不上就别装，回分享页重新下。

## 三、安装步骤（Android）

安卓默认不允许安装来源不明的应用，第一次装需要手动放行：

1. 把 apk 文件传到手机上，用文件管理器点它开始安装。
2. 系统若提示「禁止安装来自此来源的应用」，按提示进入**设置 → 允许安装未知来源应用**，给你的文件管理器（或浏览器、网盘 App）临时开一次权限，然后返回继续安装。
3. 安装过程中系统会列出该应用申请的权限，各项是干什么的见[权限与隐私说明.md](权限与隐私说明.md)。
4. 装完先别急着打开，可以先核对一下包名：在**设置 → 应用管理 → iwara里站 → 应用信息**里能看到版本号 1.9.8.4.5；包名可用「设置 → 关于」或第三方查看工具确认是 `com.youxiang.iwaralz`。

> 提示：系统若是较新的安卓版本，安装界面可能提示「风险应用」「未上架应用」之类的警告——这类提示的触发条件是「应用不在你当前使用的商店里上架」，不代表文件本身有问题。是否继续由你自己判断。

## 四、核对安装包没下错

下载大文件时网络中断会留下一个残缺文件，装不上或者装上打不开。两步核对：

1. **对大小**：文件属性里应为 40.60 MB 左右（42,574,728 字节）。
2. **对 MD5**：Windows 上在 apk 所在目录打开 PowerShell，执行：

```powershell
Get-FileHash -Algorithm MD5 ".\Iwara_v1.9.8.4.5.apk"
```

输出的哈希值应为 `42177a71ab96b1de68dbdb4a0b6c1928`。不一致说明文件不完整或不是这份包，重新下载即可。手机上核对可用任意支持 MD5 校验的文件管理器。
