## 一、先说结论

这个应用申请的权限以**网络、存储、安装更新**为主，都是漫画阅读类应用的常见组合；隐私政策（2026-06-03 版）明确列出了收集的设备信息，并集成了友盟、穿山甲、优量汇、百度、快手、抖音等广告与统计 SDK。你在安装和使用时可以逐项拒授，拒授的影响各不相同——本文按权限逐条列出，自己决定给不给。

政策原文在 [ys.iwara.org.cn/iwaralz/privacy.html](https://ys.iwara.org.cn/iwaralz/privacy.html)，有疑问按政策里的联系方式（`yxwlkj66@163.com`）联系运营方。

## 二、应用商店公布的权限清单及用途

以下权限列表来自应用商店页面，用途说明结合隐私政策的描述：

| 权限 | 用来做什么 | 不给会怎样 |
| --- | --- | --- |
| 查看 / 获取网络状态、WLAN 状态 | 判断当前有没有网、是不是 Wi-Fi | 断网或流量提醒类功能失效，联网读内容本身通常仍可 |
| 完全的互联网访问 | 加载漫画、壁纸、接口请求 | **不给就没法用**，这是核心权限 |
| 读取 / 写入外部存储、读取媒体图片 | 保存壁纸图片到相册、缓存内容 | 保存壁纸失败；在线浏览不受影响 |
| 防止手机休眠 | 长时间阅读时屏幕不自动熄灭 | 阅读中屏幕可能按时息屏 |
| 请求安装未知来源应用（`REQUEST_INSTALL_PACKAGES`） | 应用内自动更新时拉起安装 | 自动更新不可用，改手动装新版即可 |
| 读取应用安装列表（`QUERY_ALL_PACKAGES` 等） | 政策称用于安全风控、防作弊与统计 | 部分统计 / 广告功能受影响，看漫看图不受影响 |
| 相机权限（政策提及） | 拍照类操作（如扫码、头像拍摄） | 对应功能不可用 |
| 位置权限（精确 / 粗略，政策提及） | 政策称用于广告投放与反作弊校准 | 推荐与广告相关功能变化，核心阅读功能不受影响 |
| 剪贴板识别（政策提及） | 识别你复制的口令 / 链接 | 复制口令跳转类便捷功能失效 |

> 注意：权限管理在**设置 → 应用管理 → iwara里站 → 权限**里，每一项都可以随时改。改完如果某个功能突然不灵了，先想到是不是这里关错了，对照上表打开即可。

## 三、隐私政策收集了哪些信息

按 2026-06-03 版政策，收集项包括：

- **设备标识类**：设备 MAC 地址、设备序列号、IMSI、Android ID、IMEI、OAID、硬件型号、操作系统版本、唯一设备标识符；
- **网络与日志类**：IP 地址、网络接入方式与类型、网络质量数据、操作日志、服务日志、崩溃与适配性数据；
- **广告与统计**：通过友盟+ SDK 收集 AndroidID、OAID、IDFA、IDFV 等做统计分析与反作弊；
- **使用中主动提供的信息**：账号资料、你主动上传或收藏的内容。

政策里的几个要点：

1. **存储地点在境内**——政策写明境内收集的个人信息存储于中国境内，不传输至境外（除非日后变更并另行告知）。
2. **未满 18 周岁需监护人同意**——政策对未成年人有专门条款。
3. **可撤回**——政策写明你可访问、修改、删除所提供的个人信息；注销账号后，运营方称会对账号信息删除或匿名化处理。
4. **权限可分开拒授**——政策明确：拒绝授予某项权限只影响对应功能，不影响其他基本功能。

## 四、第三方 SDK 有哪些

隐私政策披露的第三方 SDK（按政策列出）：

| SDK | 开发者 | 用途 |
| --- | --- | --- |
| 友盟+ 移动统计 | 友盟同欣（北京）科技有限公司 | 安装与卸载统计、统计分析 |
| 穿山甲广告 | 北京巨量引擎网络技术有限公司 | 广告投放、反作弊、归因 |
| 优量汇 | 深圳市腾讯计算机系统有限公司 | 广告投放、归因、反作弊 |
| 百度移动广告 / oCPX | 北京百度网讯科技有限公司 | 广告投放与转化分析 |
| 快手联盟 | 北京快手广告有限公司 | 广告投放 |
| 抖音 SDK | 北京微播视界科技有限公司 | 广告投放 |

这些 SDK 的数据收集范围以各自隐私政策为准（政策里附了链接）。广告类 SDK 通常意味着应用内会出现广告位——这是免费应用的常见形态，不是异常现象。

## 五、想少给一点，怎么操作

按影响从小到大排，你可以这样取舍：

1. **位置、相机**——与看漫看图关系最远，关掉最省心。
2. **剪贴板**——只在你需要「复制口令打开」这类玩法时才用得上。
3. **通知**——不关则有更新提醒；关了清净但错过追更，自己权衡。
4. **存储**——关了就不能把壁纸存进相册；想存图时再开。
5. **网络、互联网**——不建议关，关了应用等于废掉。

改完权限后如果某个功能异常，先看[常见问题排查.md](常见问题排查.md) 对应条目；功能清单在[漫画阅读与壁纸使用指南.md](漫画阅读与壁纸使用指南.md)。
