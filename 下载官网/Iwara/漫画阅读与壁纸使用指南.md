## 一、这是一个什么应用

Iwara（商店显示名 iwara里站）是国内开发者苏州优像网络科技有限公司出的二次元内容应用，**核心是漫画阅读，附带一个壁纸专区**。应用商店里的产品介绍写得很直白：漫画按热血、玄幻、都市、言情、科幻等类目划分，配有排行榜、书单、完结等分区，首页展示推荐内容；壁纸专区收录手绘风格壁纸，看漫之余可以浏览并收藏。

它是需要联网使用的应用，漫画与壁纸都在线加载；不登录也能浏览大部分内容，登录后才能用收藏、关注这类需要账号的功能。

## 二、首页与底部导航

打开后的信息结构大致是这样用的：

1. **首页**是推荐聚合页，直接往下滑就能看到当日更新与热门内容，不想费劲找就只用这一页。
2. **底部导航**在屏幕下方切换主区域：漫画区、壁纸区（不同版本入口名称略有差异，认图标与文字即可）。
3. **搜索**入口在顶部，想找具体某部作品时用它，比翻分类快。
4. **分类 / 排行 / 书单**通常在漫画区顶部横向排列：按题材筛选（热血、玄幻、都市、言情、科幻）、看排行榜、翻别人整理好的书单。

## 三、找漫画的三条路

| 方式 | 什么时候用 | 怎么操作 |
| --- | --- | --- |
| 首页推荐 | 没有明确目标 | 直接滑动浏览，点进感兴趣的封面 |
| 分类 / 排行 | 想看某一类，或看最近什么火 | 漫画区顶部选题材标签，或切到排行榜 |
| 搜索 | 已知作品名或关键词 | 顶部搜索框输入，从结果里点进详情 |

**书单**和**完结**是两个值得单独用的分区：书单是按主题打包好的一批作品，适合书荒时按单收割；完结分区只列已连载完的作品，想一口气看完不追更的，从这里挑。

搜索有结果但不是你要的、或干脆搜不到时，三条实用改法：

1. **全称搜不到就拆词**：只保留作品名里最有辨识度的两三个字再搜一次。
2. **同一作品各页面的标签用词不同**：换个同义词（或它的题材词，如把人名换成「玄幻」）走分类入口，往往就找到了。
3. **搜完看一眼排序**：结果默认排序可能按热度，切到「最新」能看到刚上架的条目。

## 四、阅读与收藏

1. 点开一部漫画进详情页，再点开始阅读即进入阅读器。
2. 阅读器内一般支持翻页 / 滚动切换、进度跳转；画面操作（放大缩小、双击翻页）按个人习惯调，具体手势以你手上这个版本的实际反馈为准。
3. **收藏 / 加入书架**：详情页或阅读器里有收藏按钮，加入后在「书架」「我的收藏」里能快速找回，新章节更新也从这里跟进。
4. **追更与通知**：收藏的作品有更新时，应用通常会在书架标出红点或角标；若系统拦了它的通知权限，会收不到提醒——处理办法见[权限与隐私说明.md](权限与隐私说明.md)。

## 五、壁纸专区

1. 底部导航切到壁纸入口，进去是手绘风格壁纸的瀑布流列表。
2. 点开单张可查看大图，适合竖屏锁屏的图直接保存到相册即可使用。
3. 壁纸同样支持收藏，存到你的收藏列表里方便日后翻找。
4. 保存图片会用到**存储 / 相册权限**；拒绝授权就保存不了，其他功能不受影响，授权管理见[权限与隐私说明.md](权限与隐私说明.md)。

## 六、账号：不登录能用到什么程度

- **不登录**：浏览首页、分类、搜索、看漫画看壁纸都能用——先装上体验，喜欢再注册。
- **登录后**：收藏、书架同步、关注、评论这类跟账号绑定的功能才可用。注册方式以应用内实际提供的为准（应用内通常在「我的」页面有登录 / 注册入口）。
- 换手机时，登录同一账号即可找回账号内的收藏，前提是数据存在服务端；仅存在本机的记录（如本地下载的图片）不跟着走。

## 七、内容加载不出来时

漫画封面全空白、点进去一直转圈、壁纸图裂了，多数是网络或缓存问题，见[常见问题排查.md](常见问题排查.md)；如果是因为你关掉了某项权限导致的（比如断网权限、存储权限），按[权限与隐私说明.md](权限与隐私说明.md) 里的对应条目打开即可。
