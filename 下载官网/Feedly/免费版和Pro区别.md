## 一、三个档位一张表

Feedly 个人版分 Free、Pro、Pro+ 三档（另有面向企业的 Threat/Market Intelligence 产品线，见第五节）。价格与上限随官方调整会变，下表是 2026 年多家第三方评测汇总的口径，**以官方定价页当时显示为准**：

| 项目 | Free | Pro | Pro+ |
| --- | --- | --- | --- |
| 价格（月付） | 0 | 约 $6.99/月 | 约 $12.99/月 |
| 价格（年付折合） | — | 约 $6/月 | 约 $8.25/月 |
| 内容源上限 | 100 | 1,000 | 更高（有来源写 1,000+，有来源写 2,500） |
| 文件夹数 | 3 | 更多 | 更多 |
| 站内搜索（找回读过的文章） | 无 | 有 | 有 |
| 笔记与高亮 | 无 | 有 | 有 |
| AI 助手 Leo | 无 | 无 | 有 |
| 静音过滤（屏蔽不想看的词/源） | 无 | 无 | 有（第三方汇总约 100 条） |
| 第三方集成（Zapier、IFTTT、Buffer 等） | 无 | 有 | 有 |
| Newsletter 绑定数量 | 以官方页面为准 | 以官方页面为准 | 第三方汇总约 75 个 |

Pro 与 Pro+ 均提供约 30 天试用（以官方页面为准），能不能用上以你账号当时显示的试用入口为准。

## 二、免费版够用的场景

- 订阅来源在 100 个以内、读完即走、不需要回头搜旧文章——免费版就是这个用途。
- 文件夹只有 3 个：按「必读 / 偶尔看 / 消遣」这种粗分法用，别按主题细分（分组方法见 [文件夹和Board怎么用.md](文件夹和Board怎么用.md)）。
- 加满 100 源之后想再加，只能先删旧的（加源方法见 [能订阅哪些内容源.md](能订阅哪些内容源.md)）。
- 免费版的内容流里会夹杂官方放置的赞助内容，付费档没有（多个第三方指南口径，以你的实际显示为准）。

## 三、什么时候会撞到免费版的墙

出现这三个信号之一，说明免费版开始碍事了：

1. **删源换源成了常规动作**——你开始为了凑 100 以内的名额删掉其实还想留的源。
2. **想找回一篇读过的文章找不着**——站内搜索是 Pro 起步的功能，免费版只能靠翻历史或自己存 Board。
3. **想在文章上写笔记、划重点**——同样是 Pro 起步。

## 四、Pro 和 Pro+ 之间怎么选

两者的核心差别是一件事：**Leo（AI 助手）只在 Pro+**。Leo 按你指定的主题、公司、关键词把相关文章顶到前面、把重复报道合并、给长文写摘要、并支持静音过滤（把标题含某词的文章直接压下去）。你每天的阅读量在「扫标题」级别，Pro 够用；你要从大量来源里做信息筛选、靠它跟进行业动态，多花的钱买的就是 Leo 这一层。

## 五、企业产品线一句话

官方另有 Feedly Threat Intelligence / Market Intelligence，面向企业安全与市场团队（价格按团队谈，不在应用内销售——官方应用说明明确写着这类账号要去 feedly.com 注册）。个人读者用不到，知道它是另一条线即可，别在应用里误买。

免费版与付费版都从同一份安装包装起来（见 [下载与安装教程.md](下载与安装教程.md)），差别只在登录后的账号档位；账号与同步机制见 [注册登录与账号同步.md](注册登录与账号同步.md)。
