## 一、没有账号，应用里什么都做不了

Feedly 不是本地阅读器：订阅列表、已读状态、存的文章全都在 Feedly 服务端，跟着账号走。官方应用说明写得很直接——「使用这款应用需要 Feedly 账号，可以在应用内注册，或用已有账号登录」。所以装完（安装步骤见 [下载与安装教程.md](下载与安装教程.md)）打开应用，第一屏就是注册或登录，跳不过去。

## 二、注册与登录

1. 应用内注册：首次打开按引导注册，免费档不需要填任何付费信息。
2. 网页版注册：也可以先在电脑上打开 [feedly.com](https://feedly.com/) 注册，手机端再用同一账号登录。
3. 注册时可用的具体登录选项以你打开的应用版本当时显示为准；第三方教程记录到的选项包括 Google 账号、Apple ID 和邮箱注册。Feedly 没有自己的「账号密码找回之外」的独立体系，你用什么方式注册，以后就用同一种方式登录。

一个最容易踩的坑：**用不同方式注册会生成两个互不相通的账号**。如果你在手机上用邮箱注册、在电脑上误用了另一种方式登录，会看到「订阅全没了」的假象——其实只是登进了另一个空账号。确认两台设备登录方式完全一致，列表就回来了。

## 三、多端同步怎么工作

| 场景 | 行为 |
| --- | --- |
| 手机读了几篇 | 已读状态同步到服务端，网页版打开不再显示它们 |
| 电脑上加了新订阅源 | 手机的订阅列表自动多出这一条 |
| 换新手机 | 安装应用、登录同一账号，订阅与未读状态整体回来 |
| 重装应用 | 同上，本地不存订阅数据，重装不丢东西 |

同步在联网时进行。读到一半要切设备时，把文章存进 Board 或稍后读列表，登录同一账号的另一端就能看到；付费档还支持笔记与高亮（见 [免费版和Pro区别.md](免费版和Pro区别.md)，整理方法见 [文件夹和Board怎么用.md](文件夹和Board怎么用.md)）。

## 四、登录不上先查什么

按顺序查三样：网络是否可用；登录方式是否和注册时一致（见第二节的坑）；应用是否是很旧的版本（网盘里这份是 90.0.38，官方持续发小版本修复，异常持续可去官方商店核对是否有更新）。逐项排查仍解决不了的，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
