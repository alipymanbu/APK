## 一、先取到程序

Windows 版在官网下载页（`https://www.mdict.cn/wp/?page_id=5227&lang=zh`）提供两个版本：1.3 RC4（zip 压缩包）与 2.0.12（7z 压缩包），都是解压即用，不需要安装。7z 格式用 7-Zip、Bandizip 这类解压软件打开。注意网上那份夸克网盘里的 mdict 安装文件资源（夸克网盘）是安卓 APK，电脑版请从官网下载页拿。

## 二、导入词典的两种方式

**方式一：放进 doc 目录。** 把 mdx 和 mdd 放进 MDict 程序目录下的 `doc` 文件夹，程序启动时会自动扫描导入。

**方式二：菜单导入。** 词典放在其他盘符或目录时，打开顶部菜单 Library → Library Manager，选 Import Library，浏览到词典所在文件夹后点 OK；中文菜单版本对应「词库 → 词库管理 → 导入 / 增加」。

mdx、mdd、css 的命名规则与手机版完全一致（同名配对、css 不改名），细节见 [词库下载与导入方法](词库下载与导入方法.md)。

## 三、几个顺手的小操作

以下行为以 1.x 版本的使用说明为准，新版本界面可能不同：

- 直接敲字母，输入焦点会自动跳到输入框，不用先点它；
- Ctrl + 鼠标滚轮：放大缩小单词列表和正文的字体；
- Alt+Ctrl+D：把 MDict 窗口唤到前台（老版本的更新日志提到快捷键激活时会自动查剪贴板里的内容）；
- Esc：最小化到系统托盘；
- 菜单里有全屏/分屏模式，分屏方便一边看原文一边查词；还有过滤模式，可选择不显示例句，让释义短一点；
- 内建简繁转换，繁体系统的词典也能正常查。

## 四、英语之外的拼写矫正

官网单独提供一个拼写矫正数据包（spell_dat.7z），用于英语之外语言的拼写纠错，下载后解压到 MDict 安装目录的 `res` 文件夹里。只用英语查词的话可以不管它。

## 五、和手机版共用词库

电脑上下载的 mdx/mdd 直接复制到手机就能用，摆放位置见 [词库下载与导入方法](词库下载与导入方法.md)。安卓 11 以上的手机有目录限制，复制前先看 [常见问题与解决办法](常见问题与解决办法.md) 里的说明。
