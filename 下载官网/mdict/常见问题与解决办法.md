# MDict 常见问题与解决办法

> 汇总 MDict 用起来最容易卡住的几个问题：打开提示词库为空、安卓 11 之后词典找不到、正文空白或图片不显示、跨应用查词。安装环节的问题见 [下载与安装教程](下载与安装教程.md)。

## 一、打开提示「词典列表为空」

正常现象，不是坏了。MDict 是阅读器，出厂不带词库，先按 [词库下载与导入方法](词库下载与导入方法.md) 下载几本 mdx 放进词典目录，回来就有内容了。

## 二、安卓 11 以后词典放不进去 / 找不到

安卓 11 起系统限制了应用读取存储的权限，词典的摆放位置跟着变了：

- 优先放进 `Android/data/cn.mdict/files/doc/`；
- 这层目录部分文件管理器看不到，连电脑用 USB 复制最稳；
- 用「额外词库目录」指定了别的文件夹的话，实际路径必须和设置里填的完全一致。

同一批 mdx 在旧手机上好好的、换新手机就找不到，基本都是这个原因。这套目录限制只存在于手机上，电脑版有自己的导入方式，见 [Windows电脑版使用入门](Windows电脑版使用入门.md)。

## 三、词条正文空白、图片不显示、排版乱

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 能查到词但正文空白 | 只放了 mdx，正文资源在 mdd 里 | 把同名 mdd 一起放进词典目录 |
| 图片不显示 | mdd 缺失，或没和 mdx 放同一目录 | 补 mdd，并确认同名同目录 |
| 排版乱、样式丢失 | css 被改名或没放进来 | css 保持原样放回，不要重命名 |
| 部分词典正常、部分不正常 | 该词典自身资源不全 | 重新下载完整的词典包 |

## 四、查词没结果

- 查的是「当前词典」而不是分组：切到包含这本词典的分组再查，分组操作见 [词典分组与多词典同时查询](词典分组与多词典同时查询.md)；
- 组内词典确实没收这个词：换一本收词更广的词典或换组；
- 繁体词查不到：MDict 内建简繁转换（PC 版功能列表明确列出，安卓版设置里也有对应选项），切换后再试；
- 记不全拼写：改用模糊/通配符查找缩小范围（多部介绍提及，写法以你版本的帮助为准）；
- 发音不响的问题单独归在 [发音设置与语音库安装](发音设置与语音库安装.md)，这里不重复。

## 五、在别的应用里查词（跨应用查询）

官方列出的能力有两种：「App 内点击取词」是在 MDict 正文里点某个词继续查；「跨 App 查询」是在微信、浏览器等应用里复制或选中词语后，调 MDict 来查。复制后切回 MDict 粘贴查询在任何手机上都可行；跨应用取词可能需要授予悬浮窗等权限，按系统实际弹出的提示操作即可。

## 六、版本与更新

本篇基于安卓版 2.3.7（包名 `cn.mdict`）整理。MDict 更新不算频繁，遇到对不上的新问题，先确认自己的版本，再到官网下载页 `https://www.mdict.cn/wp/?page_id=5227&lang=zh` 看有没有更新。
