## 一、配对的三个前提

连接失败九成出在这三条没同时满足：

1. **手机和电脑在同一个网络**：家里同一个路由器下，别一个走流量、一个连 Wi-Fi；电脑插网线、手机连这个路由器的 Wi-Fi 也算同一网络；
2. **电脑端 Steam 开着且已登录**：Steam 关了或退出登录，手机那边会显示电脑「离线」；
3. **电脑没休眠、没关机**：电脑睡眠中无法被发现。

## 二、配对流程（PIN 那一步）

1. 手机打开 Steam Link，进入「开始」向导；
2. 它扫描后会列出网络里的电脑，点选你那台；
3. 手机屏幕上出现一串 **PIN**，同时电脑上的 Steam 弹出确认窗口；
4. 在电脑上把 PIN 原样输入、确认；
5. 确认通过后配对完成，进入连接测试画面。

这串 PIN 是防止别人抢连你的电脑用的，每次新设备配对都会重新出一串——所以第一次配置时人要坐在电脑前。配对关系建立后，以后打开就直接连，不再问 PIN。

## 三、电脑端要检查的开关

| 位置 | 检查什么 |
| --- | --- |
| Steam 客户端 → 设置 → 远程畅玩 | 「启用远程畅玩」勾上；如果状态异常，取消再重新勾一次 |
| Windows 防火墙 | 允许 Steam 通过防火墙。Steam 或游戏最近更新过的话，防火墙可能重新拦一次 |
| 网络类型 | 把当前网络设为「家庭网络」；有用户反馈用「公用网络」会导致连接不稳（官方排障文档也建议改家庭网络） |

远程畅玩用到的端口（在防火墙里放行）：

- UDP 27031、27036
- TCP 27036、27037
- VR 串流另需 UDP 10400、10401

## 四、电脑压根搜不出来时

按命中率从高到低排：

1. **确认电脑那头没问题**：Steam 开着、登录着、没睡眠——这三件事占了「显示离线」的大多数；
2. **确认是同一网络**：路由器开了「访客网络」或「AP 隔离」时，设备之间互相看不见。你得进路由器设置把「接入点/客户端隔离」关掉；
3. **公共网络用不了**：公司、学校、酒店这类带门户登录或开了客户端隔离的网络，官方明确不支持，换个网络再试；
4. **端口被占**：首次发现用的 27036 端口若被别的程序占用，电脑也不会出现——重启 Steam 再试一次；
5. **临时关防火墙验证**：如果放行规则怎么都不生效，可以先临时关掉防火墙确认是不是它拦的，确认后再开回来并给 Steam 建好例外规则（ZoneAlarm 等第三方防火墙有用户反馈会拦）。

还有一招兜底：在电脑上直接开浏览器访问 [Steam Link 官方排障页](https://help.steampowered.com/zh-cn/faqs/view/3E3D-BE6B-787D-A5D2)，按它的向导逐条走。
