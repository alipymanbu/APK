## 一、为什么停运应用的包要多一道校验

在架应用的安装包有应用商店的扫描与签名机制兜底，而 Bigshot 在 2022 年 4 月停运后，官方不再提供任何下载渠道，你能在网上找到的 APK 都来自第三方存档。第三方渠道的典型问题是：

- **同版本号、不同文件**：多个软件站都标注「v2.6.5.35」，但公开页面上显示的 MD5 并不一致——有的标 `f5b26982…`，有的标 `1cd22a41…`。同版本号出现不同哈希，意味着至少有一部分渠道的文件不是同一份原始包（重打包、二次签名或标注错误都可能）；
- **无官方背书**：没有渠道可以替文件安全性负责，出了问题也没有官方可问；
- **停运应用易被冒用**：有媒体报道过，一些停止运营的 APP 名头被不法分子拿去二次包装、做电信诈骗的工具。对一个早已停更、用户无法从官方渠道核对的应用来说，这道风险只能靠你自己把关。

结论：从哪个渠道拿包不重要，**装之前先校验**才重要。本文配套的 [Bigshot 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9e13ba8313eb) 对应文件的基准值见下表。

## 二、基准值：正版 2.6.5.35 长什么样

| 项目 | 值 |
| --- | --- |
| 版本 | 2.6.5.35（2021-12-08 发布，最后一个版本） |
| 包名 | com.vnision |
| MD5 | F5B269823CE24A5FB7722607DC452D95 |
| 大小 | 60.51 MB |

MD5 一致 = 文件与发布时逐字节相同；不一致 = 下载不完整，或文件被人动过，直接丢弃不要装。

## 三、怎么算 MD5

### Windows（PowerShell，系统自带）

```powershell
Get-FileHash "C:\下载\Bigshot_v2.6.5.35.apk" -Algorithm MD5
```

输出的 Hash 值与基准值比对（字母大小写不同没关系，比较时忽略大小写）。

### Windows（7-Zip 右键）

装了 7-Zip 的话，右键安装包 → 「CRC SHA」→ 「MD5」，弹出的值直接比对，不用敲命令。

### macOS / Linux

```bash
md5sum Bigshot_v2.6.5.35.apk
```

## 四、装上后再确认一次身份

校验通过的包装完，还能在系统里核对应用身份：

1. 系统设置 → 应用管理 → 找到「大片」；
2. 应用详情里的包名应显示 `com.vnision`——包名对不上就不是同一个应用；
3. 版本号应显示 2.6.5.35。

如果安装包声称是「更高版本」但包名不是 com.vnision，那它与本文讨论的这款 Bigshot（中文名「大片」）无关，只是重名的其他应用。

## 五、这几类包直接排除

- 凡宣称「原版没有的付费功能这里都有」或自称「特别版」的安装包——原应用的会员体系早已随停运消失，这类标称本身就是危险信号；
- 体积与 60.51 MB 明显不符的「2.6.5.35」（比如小了一半或大出一截）；
- 要求你额外授权通讯录、短信等与剪辑无关权限的安装流程——正版申请的是存储 / 相册权限；
- 附带「登录修复补丁」「服务器恢复工具」的一律不碰，停运不可逆（原因见 [停运公告与现状说明.md](停运公告与现状说明.md)）。
