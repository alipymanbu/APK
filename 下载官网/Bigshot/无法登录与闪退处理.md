# Bigshot 无法登录与闪退处理

> Bigshot 装上后登录不上、提示网络异常、打不开或闪退时，按本篇的顺序排查。先说结论：登录类失败多半不是你的问题，是服务器已关闭。

## 一、先判断是不是停运导致

对照这张表，先分清「本来就用不了」和「真的出了故障」：

| 现象 | 多半的原因 | 处理 |
| --- | --- | --- |
| 卡启动页、提示网络异常 | 服务器已于 2022-04-01 关闭 | 不是故障，见 [停运公告与现状说明.md](停运公告与现状说明.md) |
| 要求登录但收不到验证码、登录转圈 | 账号体系随停运失效 | 放弃登录，不重试 |
| 剧本 / 在线曲库列表为空 | 内容靠服务器下发 | 属正常，改用本地素材剪辑 |
| 点击某功能直接报错退出 | 功能依赖的服务端没了 | 换不依赖服务器的功能用 |

如果你遇到的是上面这几种，不用往下排查了——这些在停运后无解，任何声称能修复登录的教程都不要信。

## 二、安装失败的排查

真正的「故障」通常出在安装这一步，按顺序检查：

1. **提示「解析包错误」**：先核对安装包的 MD5 是否为 `F5B269823CE24A5FB7722607DC452D95`（这版是 60.51 MB、包名 com.vnision）。不一致说明下载不完整或文件被动过，重新获取再装——校验命令与身份核对方法见 [安装包校验与安全检查.md](安装包校验与安全检查.md)；
2. **提示存储空间不足**：清理出至少 200 MB 余量再装（安装包本体 60.51 MB，安装过程还要临时空间）；
3. **按钮点了没反应**：确认已给文件管理器（或你用来打开 APK 的应用）授予「安装未知应用」权限；
4. **安卓版本过低**：这版要求安卓 5.2 及以上，更老的系统装不上或装上打不开，属于系统限制。

## 三、打不开与闪退的排查

安装成功但启动就退，依次试：

1. **重启手机后再开**——清掉安装后残留的异常状态，多数「点开就闪」到这一步就解决了；
2. **清一次应用数据**：系统设置 → 应用管理 → Bigshot → 存储 → 清除数据，再重新打开（清数据会丢掉应用内的本地草稿，有草稿先导出）；
3. **关闭「自动管理」后手动放权**：部分机型的省电策略会在启动时直接杀掉它，把 Bigshot 加入省电白名单或允许后台运行再试；
4. **重装一遍**：先卸载，再用校验过 MD5 的安装包重装；重装后首次打开记得允许相册 / 存储权限，权限被拒也可能表现为界面空白或退出。

如果 2.6.5.35 在你的机型上始终闪退，没有更高版本可换——这就是该应用最后一个大版本，兼容问题没有后续修复，只能接受或改用其他工具。

## 四、数据与账号的两种遗憾

- **当年存在应用云端的视频**：按公告口径已随服务器一起被删除，找不回来了；
- **当年绑定的账号与会员**：登录通道已关闭，会员权益与退费窗口（2022 年 3 月 1 日至 4 月 1 日）均已过期。

还留在手机相册里的成片不受影响。想在现在剪新视频，装好这份 2.6.5.35 后从 [剪辑功能怎么用.md](剪辑功能怎么用.md) 的本地剪辑流程入手即可；若它在你手机上确实跑不起来，移动端同类剪辑工具还有剪映、快影、VN、InShot 等，可在各官方应用商店自行获取。
