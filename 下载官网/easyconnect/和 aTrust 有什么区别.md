# EasyConnect 和 aTrust 有什么区别

> 深信服有两个远程接入客户端：EasyConnect 和 aTrust，长得像但不是同一个产品，装错了谁也连不上谁。本篇讲清楚两者的关系，帮你确认单位让你用的是哪一个。

## 一、两个是不同的产品

| | EasyConnect | aTrust |
| --- | --- | --- |
| 产品定位 | SSL VPN 客户端，配套深信服 SSL VPN / NGAF 等网关设备 | 零信任访问控制系统客户端，配套 aTrust 设备 |
| 接入逻辑 | 你登录后拿到一张「通往内网的通行证」，隧道内按权限访问资源 | 对每次访问做持续的身份与终端环境校验，按应用逐个放行 |
| 典型登录地址 | `https://VPN地址:4430` 这类带端口的地址 | 单位给的 aTrust 接入地址（也可能是域名） |
| 是否可互换 | **不可**。两个客户端与各自的设备端绑定，不能混用 | 同左 |

一句话判断：单位的 IT 通知里写的是「VPN」「EasyConnect」，就是本篇的主角；写的是「零信任」「aTrust」，你要装的是另一个客户端，去单位通知里找它自己的获取方式。

## 二、为什么有人会被搞混

三个常见混淆点：

1. **名字都带「深信服」**：两个客户端都是深信服的产品，界面风格也相近，但服务端设备完全不同；
2. **新旧换代正在进行**：深信服近年主推 aTrust，新部署远程接入的单位多数直接上 aTrust，老用户继续用 EasyConnect 也完全正常——很多单位 SSL VPN 和 aTrust 并存多年，各自服务不同场景；
3. **都叫「VPN」**：日常口语里大家把远程接入统一叫 VPN，但客户端名字必须跟设备走，问清楚管理员「我们用的是 EasyConnect 还是 aTrust」能省掉一半折腾。

## 三、确认你该用哪个的办法

按顺序做：

1. 看单位的使用通知或 IT 门户：写了「SSL VPN / EasyConnect / 4430 端口」→ 用 EasyConnect；写了「aTrust / 零信任」→ 装 aTrust；
2. 拿不准就试：手上有 EasyConnect 安装包的话（获取见 [下载与安装教程.md](下载与安装教程.md)），填上管理员给的地址连一下——设备不匹配时会直接连不上或提示异常，不会造成任何损失；
3. 还是拿不准，直接问管理员要安装包和登录方式，一句「我们 VPN 用哪个客户端」就能问明白。

装好了之后地址怎么填、登录后怎么用，分别看 [服务器地址怎么填.md](服务器地址怎么填.md) 和 [登录后能干什么.md](登录后能干什么.md)。
