## 一、登录与注册

打开 App 后在「我的」页进入登录入口，按页面提供的方式注册或登录（常见的是手机号 / 邮箱加验证码，具体以你版本里出现的选项为准）。

值得先知道的两点：

- 收藏、追更、播放进度、会员权益都跟账号走，不跟设备走——**换手机、卸载重装，只要账号登得回来，东西都在**；
- 官方公告明确过：网页端停运后，APP 内**完整保留原有账号数据、收藏记录、会员权益**，登录即可正常使用。

## 二、切换账号

多个人共用一台手机时会用到，路径大致是（不同版本菜单名略有差异，认「账号」字样找）：

1. 底部「我的」进入个人主页；
2. 找到「账号管理」（一般在设置或账户信息区域）；
3. 点「切换账号」或「退出当前账号」，再用另一组账号信息登录。

**切换前先确认当前账号已退出干净**：尤其是准备卸载重装或转卖设备时，先在当前账号里退出登录，避免别人拿到你的登录态。相关的卸载注意事项见 [下载与安装教程.md](下载与安装教程.md)。

## 三、会员权益包含什么

官方页面列出的会员权益如下（措辞为官方口径的转述，实际以 App 内开通页显示为准）：

| 权益 | 说明 |
| --- | --- |
| 无广告追番 | 追番过程不展示广告 |
| 超清原画画质 | 解锁更高的画质档位 |
| 新番优先观看 | 新番提前看 |
| 高速离线缓存 | 缓存下载速度更快 |
| 播放进度云端同步 | 多设备接着看 |
| 彩色弹幕标识、专属头像挂件 | 身份展示类装饰 |
| 每月福利礼包、优先客服通道 | 服务类权益 |
| 付费漫画免费阅览 | 漫画区内的付费内容 |

没开会员也能正常安装与使用基础功能；**开不开、开多久、多少钱，官方下载页与 App 内开通页写什么就按什么来**，本文不写死价格——这类信息变动很频繁。

## 四、网页版为什么打不开了

官方发过**网页版停运通告**：网页端在线观看功能已停止运营，番剧、漫画、社区动态等内容改为仅在 App 内浏览，新番与社区活动也会优先在移动端上线。

对你的实际影响：

- 浏览器里打不开网页版 ≠ 你的网络被封，也不是账号出问题；
- 想继续看，装 App 登录原账号即可（安装步骤见 [下载与安装教程.md](下载与安装教程.md)）；
- 官方提示只认 [www.halihaliapp.com](http://www.halihaliapp.com) 这一个官网域名，从别处下载的同名包不受其账号体系与更新保障。

## 五、支持哪些设备

按官网常见问题的口径，目前适配**安卓手机、苹果 iPhone/iPad、Windows 电脑、鸿蒙**四个端，TV 版标注为即将上线（以官网当时显示为准）。各端的安装包获取方式不同，安卓端的获取与安装见 [下载与安装教程.md](下载与安装教程.md)，装好后怎么播放、怎么调设置见 [怎么用_倍速小窗与弹幕设置.md](怎么用_倍速小窗与弹幕设置.md)。
