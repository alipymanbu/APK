## 一、先分清你遇到的是哪一种

不同现象的原因差很远，先对号入座：

| 现象 | 更可能是哪类问题 |
| --- | --- |
| 点图标没反应，或闪一下就回桌面 | 本机问题：安装包不完整、系统版本过低、缓存损坏 |
| 卡在启动画面 / 白屏 | 本机问题或网络问题 |
| 能打开，但首页一直转圈、视频加载失败 | 网络问题，或服务端在维护 |
| 提示登录失败、验证码收不到 | 账号或服务端问题 |
| 以前好好的，今天突然全都不行 | 先查官网公告，再查网络 |

## 二、按顺序做（一般做到第 4 步就能解决）

1. **先确认网络**：切换 Wi-Fi 和移动数据各试一次，或用别的设备连同一网络看能不能打开。首页转圈这类问题，十有八九出在网络这一层。
2. **强行停止再打开**：设置 → 应用 → 哈哩哈哩 → 强行停止，然后重新打开。很多「点了没反应」只是它上次没真正退出。
3. **清一次缓存**：同一个应用信息页 → 存储 → 清除缓存。缓存损坏会让它白屏或一直加载。**先别点「清除数据」**——那会把 App 打回刚装完的状态（登录、设置全没），等下面几步都不管用时再考虑；清缓存与清数据的差别列了张对照表，见 [播放卡顿与加载慢怎么办.md](播放卡顿与加载慢怎么办.md) 第二节。
4. **核对系统版本**：安装包要求安卓系统 5.2 以上。系统版本低于要求，装是装得上、跑起来就会闪退，这种只能换满足要求的设备或等官方适配。
5. **卸载重装**：把 App 卸载，重新从 [哈哩哈哩 Halihali 安装文件资源（夸克网盘）](https://pan.quark.cn/s/456db5ffe723) 或官方下载页拿包安装。卸载前确认账号已登录——只要记得账号，装回来登录即可，收藏与进度是跟着账号走的（见 [账号切换与会员权益说明.md](账号切换与会员权益说明.md)）。
6. **查官方渠道是否在维护**：官网 [www.halihaliapp.com](http://www.halihaliapp.com) 有停运、维护类公告时，页面会直接写出来。这类情况你什么都不用做，等恢复即可。

## 三、两个容易被忽略的坑

- **网页版已经停运**。官方发过「网页版停运通告」：网页端的在线观看功能已停止运营，番剧、漫画、社区等内容**只能在 App 内浏览**。所以如果你是「网页打不开」，那不是你的网络问题，也不是你被封了——按公告就是要用 App。
- **别装到外置存储卡上**。部分手机允许把应用装到 SD 卡，卡的读写不如机身存储稳定，容易出现打开异常。安装时选「内部存储」即可；已经移过去的，先移回机身存储再试。

## 四、什么时候该放弃排查

- 同一时间段很多人都打不开、加载失败 → 大概率是服务端问题，过段时间再试；
- 换了设备、按上面全做完仍然必闪退 → 多半是这个包与该机型不兼容，先看官方下载页有没有适配你机型的新版本（以页面当时显示为准）；
- 只有某一部番打不开、别的都正常 → 不是 App 的问题，换个片源或稍后再试。
