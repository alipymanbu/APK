## 一、能订什么：按板块找

首页把内容分成几大板块，下单前先知道自己要找的东西在哪个板块，比在搜索框里盲搜快得多：

| 板块 | 里面常见的东西 | 什么时候会用 |
| --- | --- | --- |
| 旅游体验 | 景点门票、一日游、韩服租赁、课程与工作坊 | 行程定下来后逐项补 |
| 美食 | 餐厅代订、外卖下单 | 到店排不上队、想叫炸鸡的时候 |
| K-Pop | 演唱会门票、粉丝应援相关体验 | 追星行程 |
| 网卡网路 | SIM 卡、eSIM、随身 Wi-Fi | 出发前或落地后第一时间 |
| 韩系美发 | 染烫、剪发、头皮护理，含艺人常去沙龙 | 想做「韩国同款发型」 |
| K-美容 / 皮肤科 | 护肤、医美比价、个人色彩分析 | 美容行程 |
| 交通 | 机场接送、AREX 机场快线、火车巴士票 | 抵达与城际移动 |
| 住宿 | 酒店、短期住宿 | 订行程的主轴 |
| 金融便利 | 换钱服务、预付卡 | 落地后解决钱的问题 |
| 博客（Trends） | 攻略与本地趋势文章，不可预订 | 行前做功课 |

韩国观光公社（KTO）官网的「韩国旅行必备应用」专题也把 Creatrip 列在其中，定位是给想体验韩国文化的外国人用的平台；官方介绍里还提到韩语学习与社区功能，这部分以应用内实际板块为准。

网卡网路是平台上销量最大的一类目之一，其中 eSIM 的开通有一套自己的流程与坑，单独成篇：[eSIM 激活与上网设置.md](eSIM%20激活与上网设置.md)。

## 二、一次预订的完整流程

1. **搜索**：首页搜索框输入关键词（如「韩服」「SIM 卡」「AREX」），或按第一节表格去对应板块翻列表；
2. **进商品页**：看清楚三个信息——价格与档位（同一商品常有多个选项）、可订日期、评分与评论数；
3. **选规格**：选日期、人数、选项；注意部分商品分「标准价」与「会员价」两档显示；
4. **确认订单**：标有「即时确认（Instant Book）」的商品，付款完成即预订成功；没有这个标的商品要等商家确认，别把两者混为一谈；
5. **支付**：页面按你所在的地区显示货币（简体中文页显示人民币，英文页显示美元），下单前再看一眼实际扣款金额；
6. **拿凭证**：预订成功后在订单里拿到凭证（voucher），到店出示给商家核销。

商品页上的时间多为韩国时间（KST）标示，跨时区对照行程时容易差一小时，别忽略。

## 三、下单前重点看两处

- **取消与退款政策**：每个商品页自带「取消与退款政策」一节，不同商品宽严差别很大（有的支持无条件部分退款，有的一经支付不可退）。先读这一节，再决定要不要下单；
- **库存状态**：售罄（Sold Out）与「即将开放预订」都直接标在列表页，抢手商品（尤其是标了 Creatrip 独家的活动）经常开卖即空，看到合适档位就尽快锁定。

付款前想压低价格，先看 [优惠券与积分怎么用.md](优惠券与积分怎么用.md)，把积分和优惠券的机制弄明白再掏钱，往往能省下一截。

## 四、到店怎么用凭证

预订成功后打开订单详情，向商家出示凭证即可核销；个别商品会要求提前联系商家或打印纸质凭证，以商品页「注意事项」一节的说明为准。到了现场发现对不上号（时间、人数、选项），直接通过订单页联系平台处理，比现场扯皮快。

## 五、订完之后改行程

- 能不能退、退多少：回到商品页「取消与退款政策」对照自己订单的时间点；两条取消路径与退款没到账的处理，见 [退款与取消订单.md](退款与取消订单.md)；
- 改期：能不能改没有统一答案，官方帮助中心对「能否更改预订时间或服务」有成文条目；政策里没写明可改的，稳妥做法是按条款取消后重新预订；
- 有争议先走订单页与官方沟通（联系方式见 [常见问题与解决方法.md](常见问题与解决方法.md)）。
