## 一、安装前先核对这份信息

应用商店里的 Creatrip 会随官方更新换代，而你手上这份安装文件对应的是下面这一版。先核对版本号，能避免「教程里的按钮和我手机上对不上」的困惑：

| 项目 | 值 |
| --- | --- |
| 应用名称 | Creatrip（韩国旅游综合平台） |
| 版本 | 7.1.0 |
| 包名 | `com.creatrip` |
| 安装包大小 | 11.55M |
| MD5 | `5678EA7FE3465F6A0AA36C089C87F4A6` |
| 系统要求 | 安卓 5.2 及以上（以官方商店页面为准） |
| 信息整理日期 | 2026-09-23 |

官方最新版的界面与功能可能与上表不同；涉及版本号与包名，以你手上这份安装文件为准。

## 二、把安装文件存到手机

1. 打开 [Creatrip 安装文件资源（夸克网盘）](https://pan.quark.cn/s/111be258e98c)；
2. 在分享页里把文件**转存到自己的网盘**（未登录会先要求登录夸克账号）；
3. 转存后在「我的网盘」里找到这个 APK 文件，点下载，存到手机存储；
4. 下载完成后，在通知栏或手机「文件管理」里能找到这个 `.apk` 文件。

用电脑操作也行：在电脑浏览器里完成转存与下载，再用数据线或任意传输方式把文件送到手机。

## 三、校验安装包（可选但建议）

如果你在意文件完整性，可以在 Windows 电脑上用系统自带的 `certutil` 核对 MD5：

```powershell
certutil -hashfile "C:\Users\你的用户名\Downloads\Creatrip_v7.1.0.apk" MD5
```

输出中第二行的哈希值与第一节表格里的 MD5 一致，说明文件没有在传输中损坏。部分安卓文件管理器也自带「校验文件 / 计算哈希」功能，手机上直接核对亦可。

## 四、允许安装「未知来源」应用

从商店以外的渠道安装，安卓默认会拦一道。你需要给「替你执行安装的那个应用」放行（浏览器、文件管理器或网盘客户端都可能），而不是全局放开：

1. 点击 APK 时若弹出「禁止安装未知来源应用」，点提示里的「设置」；
2. 找到刚才用来打开这个 APK 的应用，打开「允许安装未知应用」开关；
3. 返回安装界面继续。

不同厂商的入口略有差异：

| 厂商 | 常见入口 |
| --- | --- |
| 原生 / Pixel | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |
| 小米 / 红米 | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / vivo | 设置 → 安全 → 安装未知应用 |

装完之后建议把放行关掉，减少误装其他文件的风险。

## 五、首次启动与登录

1. 打开 Creatrip，首次启动会请求通知、存储等权限，按需允许即可；
2. 选择界面语言，以应用内语言列表实际提供的为准；
3. 注册或登录：可用邮箱注册；当前版本是否提供 Google、Kakao 等快捷登录，以登录页实际选项为准；
4. 登录环节**不需要韩国手机号做实名认证**，用国内手机号与邮箱即可完成（这也是韩国观光公社官方介绍里提到的一点）；
5. 登录后先别急着下单，把底部导航的各板块点一遍，熟悉分类——下一篇 [能订什么与怎么订.md](能订什么与怎么订.md) 就是按这个顺序写的。

## 六、装不上怎么办

按现象对症处理：

| 现象 | 处理 |
| --- | --- |
| 提示「解析包错误」 | 安装包没下完整，回到第二节重新下载并校验 MD5 |
| 提示「存储空间不足」 | 清出至少 200M 空间再装 |
| 点了安装没反应 | 确认第四节里给对应应用开了「允许安装未知应用」 |
| 装完被自动卸载 | 部分手机的安全应用会拦截，到手机管家 / 安全中心里把该应用加入信任 |

登录收不到验证邮件、界面语言不对之类的问题，到 [常见问题与解决方法.md](常见问题与解决方法.md) 里找。
