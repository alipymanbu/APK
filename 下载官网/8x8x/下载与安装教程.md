## 一、安装前先核对这几项

| 项目 | 信息 |
| --- | --- |
| 应用名称 | 8x8x（又称 8x8x影视、8x8x影视播放器） |
| 版本 | 1.6 |
| 安装包大小 | 56.82M |
| MD5 | 858D57533087C3A2EEC7829452E1B2B8 |
| 系统要求 | 安卓 5.2 及以上 |
| 类型 | 影音播放 |

第三方应用市场收录的同一安装包（MD5 一致）显示包名为 `com.dfytaz.qfoexr.trxkuhps`，可以当作区分同名应用的辅助特征。

两点提醒：

- 网上叫「8x8x」的应用不止一个，版本号也各不相同（有 1.6 也有 3.x），它们不是同一份安装包。判断手里这份是不是本文说的那份，看版本 1.6 与 MD5 就够了。
- 安装前确认手机剩余空间不少于 120M：安装包 56.82M，安装过程还需要解压出来的临时空间。

## 二、把安装文件拿到手机上

最直接的方式是从 8x8x 安装文件资源（夸克网盘）获取：[https://pan.quark.cn/s/83cbd91190a3](https://pan.quark.cn/s/83cbd91190a3)，里面是 8x8x v1.6 的安装包（`8x8x_v1.6.apk`），下载完成后在通知栏或文件管理的「下载」目录里能找到它。

用电脑下载也行：把 apk 文件通过数据线、微信文件传输或局域网共享传到手机存储里，效果一样。

## 三、安装步骤

1. 在文件管理里点开刚下载的 `8x8x_v1.6.apk`；
2. 系统弹出「是否允许安装」时选择允许（第一次装会跳到设置页，见第 3 步）；
3. 按手机品牌在设置里放行「安装未知应用」，再返回重新点安装：
   - 小米 / 红米：设置 → 隐私保护 → 特殊权限 → 安装未知应用
   - 华为 / 荣耀：设置 → 安全 → 更多安全设置 → 安装外部来源应用
   - OPPO / 一加：设置 → 安全 → 安装未知应用
   - vivo / iQOO：设置 → 安全 → 更多设置 → 权限管理 → 安装未知应用
4. 等进度条走完，点「完成」或「打开」。

不同系统版本的菜单名称略有差异，以你手机当时显示的为准。第 2、3 步如果弹出「风险应用」「禁止安装」「未经检测」之类的提示，按[安装被拦截的解决方法.md](安装被拦截的解决方法.md)里对应品牌的路径放行；装完建议把授权关回去，做法也在那一篇里。

## 四、校验 MD5（拿不准就查一下）

MD5 用来确认拿到的文件和发布时那份一字不差。部分手机文件管理器自带「文件校验」功能；更常用的是在电脑上核对：

```powershell
certutil -hashfile 8x8x_v1.6.apk MD5
```

输出的哈希值（忽略大小写）与 `858D57533087C3A2EEC7829452E1B2B8` 一致就没问题；对不上说明文件在传输中损坏或不完整，重新下载一次再装。

## 五、装完第一次打开

- 首次启动会请求存储权限：同意后才能把缓存影片写到本地存储；
- 部分机型第一次联网播放会有几秒初始化等待，属正常现象；
- 想直接在大屏上看，参考[投屏到电视的完整步骤.md](投屏到电视的完整步骤.md)；想调清晰度、倍速、字幕，参考[播放设置与画质调整.md](播放设置与画质调整.md)。

安装过程中如果卡在某一步，比如提示「解析包出错」「禁止安装」等，直接翻[常见问题排查.md](常见问题排查.md)对应的条目。
