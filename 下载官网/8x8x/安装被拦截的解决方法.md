# 8x8x 安装被拦截的解决方法

> 本篇讲 8x8x 装到一半被手机系统或安全机制拦下来时，各品牌的放行路径，以及装完怎么把权限收回去。

## 一、先分清「拦的是来源」还是「包有问题」

安卓把所有不从应用商店来的安装包一律按「未知来源」处理，系统默认不放行；不少品牌还在这之上加了自己的安全开关。所以被拦是这类安装包的常态，不代表这份包一定有问题。判断包本身完整不完整，看 MD5：`858D57533087C3A2EEC7829452E1B2B8`，校验方法见[下载与安装教程.md](下载与安装教程.md)。

## 二、各品牌的放行路径

| 品牌 / 机制 | 放行路径 |
| --- | --- |
| 华为 / 荣耀（HarmonyOS 3.0~4.0） | 设置 → 系统和更新 → 纯净模式 → 关闭「增强防护」；安装时若提示「未经检测」，勾选「已了解此应用未经检测，可能存在风险」后继续安装 |
| 华为 / 荣耀（HarmonyOS 5.0 及以上） | 该防护已并入系统基础能力、无法手动关闭，按安装弹窗的提示逐项确认 |
| 华为「文件管理被禁止安装应用」 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 → 文件管理，打开允许安装 |
| 三星（One UI 6.1.1 及以上） | 设置 → 安全与隐私 → 自动拦截程序，临时关闭后重试安装，装完再打开 |
| 小米 / OPPO / vivo 等其他品牌 | 设置 → 安装未知应用，给打开 apk 的那个应用（文件管理或浏览器）授权，路径细节见[下载与安装教程.md](下载与安装教程.md)第三节 |

关键点：给权限要给对对象。「安装未知应用」是**按应用**授权的——你用哪个应用点开的 apk，就给哪个应用授权（用文件管理点开就授权文件管理，用浏览器下载的就授权浏览器），给别的应用授权没用。

## 三、弹「发现有害应用」之类提示时

商店外安装时，系统安全扫描（如 Google Play Protect 或品牌自带的检测）会再拦一道。有的版本会给出「仍要安装」或「不发送」的继续入口，按提示继续即可；若被直接阻止且没有继续选项，先核对上面那个 MD5 确认文件无误，再决定是否换一个获取渠道。

## 四、装完把权限收回去

放行只该是临时的：

- 装完后回到「安装未知应用」里，把刚才授权的那个应用的开关关掉；
- 三星的「自动拦截程序」装完重新打开；
- 华为的「增强防护」装完重新开启。

这些开关平时开着能拦住真正的流氓安装，只在装包的这几分钟关一下，是两全的做法。

## 五、还是装不上的两种情况

- **签名冲突**：手机里已经装过同名的另一个版本（比如之前从别的渠道装过 3.x 的同名应用），新旧两份签名对不上，系统会拒绝覆盖。先卸载旧版再装这份，卸载会一并清掉旧版的本地数据；
- **系统太老**：安卓 7.1.1 及以下的设备没有按应用授权的「安装未知应用」，走的是「设置 → 安全性 → 未知来源」总开关；再老的系统则可能低于本包要求（安卓 5.2 及以上），直接不兼容。

放行之后还出问题的（解析包出错、闪退等），翻[常见问题排查.md](常见问题排查.md)。
