# 8x8x 投屏到电视的完整步骤

> 本篇讲怎么把 8x8x 里正在播的影片投到电视或投影仪上，以及投屏前要满足的三个前提。

## 一、投屏前的三个前提

| 前提 | 怎么确认 |
| --- | --- |
| 手机和电视连的是同一个 Wi-Fi | 手机设置里看当前 Wi-Fi 名，要和电视网络设置里的一致；路由器若开了「AP 隔离」，设备之间互相找不到，需要关掉 |
| 电视支持 DLNA 或已开启投屏服务 | 智能电视一般在「设置 → 网络」或「我的应用 → 无线投屏」里；老电视可以加一个支持 DLNA 的电视盒子 |
| 8x8x 已装好、能在手机上正常播放 | 还没装的话先看[下载与安装教程.md](下载与安装教程.md) |

## 二、五步把画面投上电视

1. 手机和电视都连到同一个 Wi-Fi；
2. 在电视端打开 DLNA / 无线投屏服务（小米电视：我的应用 → 无线投屏）；
3. 打开 8x8x，在搜索框输入片名，进入影片的播放页；
4. 点播放页里的「投屏」按钮；
5. 在弹出的设备列表里选你的电视，连上后电视就开始播了。

投屏成功后手机就是遥控器：进度、清晰度、音量、选集都在手机上操作，你还可以退出播放页去聊天、刷网页，电视上的播放不受影响。

## 三、不同设备的差异

- **小米 / Redmi 电视**：需要在「我的应用」里手动启用「无线投屏」，否则设备列表里不会出现这台电视；
- **支持 AirPlay 的电视（苹果生态）**：走屏幕镜像更省事，从控制中心点「屏幕镜像」选电视即可；
- **老电视 / 不支持 DLNA 的电视**：接一个电视盒子，把盒子当作投屏目标，兼容性通常比电视自带服务更稳。

## 四、投上去了但不理想

- 画面卡顿：把清晰度从 4K 降到 1080P，并关掉家里其他占带宽的下载任务（清晰度在哪里调见[播放设置与画质调整.md](播放设置与画质调整.md)）；
- 有声音没画面：多为该路片源格式特殊，换一条线路或换一部影片试试；
- 看到一半断开：依次重启路由器、电视、手机再重连，多数是网络临时波动。

设备怎么都搜不到这类问题，按[常见问题排查.md](常见问题排查.md)里投屏一节的清单逐条核对。
