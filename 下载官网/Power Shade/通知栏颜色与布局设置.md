## 一、设置从哪进

打开 Power Shade 主界面，除顶部的运行开关外，设置按四个区块排布：**Trigger**（触发条）、**Colors**（颜色）、**Layout**（布局）、**Extras**（附加项）。改任何一项都会立刻反映在下拉面板里，改完随手下拉看一眼即可确认。

前提：滑块已处于 Running 状态。如果还没接管面板，先看[下载与安装教程.md](下载与安装教程.md)。

## 二、Colors：配色与透明度

| 设置项 | 作用 | 怎么用 |
| --- | --- | --- |
| Background color | 面板背景色 | 内置色板选一个，也可进 CUSTOM 自己调色值 |
| Active tile color | 磁贴（Wi-Fi、数据等）激活时的颜色 | 选与背景对比明显的颜色，一眼分得开开/关 |
| 亮度滑条颜色 | 亮度条单独配色 | 想让亮度条与磁贴区分开时改它 |
| Transparent Notifications / Transparent Header | 通知卡片与头部区域变透明 | 配合背景色或背景图使用，拖一下滑块下拉看效果即可 |

透明度这一项在免费版还是 Pro 上存在说法分歧，点开若是购买提示就属于 Pro，详见[免费版与Pro区别.md](免费版与Pro区别.md)。

通知卡片有三种主题思路，对应三种视觉结果：

- **Light**：普通白底卡片，日常最稳；
- **Colored**：卡片背景动态取自该通知自身的颜色（如音乐应用取专辑封面色）；
- **Dark**：纯黑背景，AMOLED 屏幕上省电且夜间不刺眼。

三者的实际观感取决于你手机上的应用发什么颜色的通知，选一个下拉看一眼就能定。

## 三、Layout：行列数与圆角

- **Grid Columns / Grid Rows**：快捷设置磁贴的列数与行数。这两项属于 Pro 功能，免费版不能改行列，见[免费版与Pro区别.md](免费版与Pro区别.md)。
- **头部磁贴数**：第一下拉页里直接显示的磁贴数量。
- **圆角**：面板四角的圆角程度，想要方正一点的老式观感就调小。

磁贴图标本身的形状（圆形、方形、泪滴形、渐变等）在磁贴形状设置里选，形状只影响外观，不影响功能。

## 四、Trigger：屏幕侧边的下拉触发条

长屏手机下拉通知栏要够屏幕顶边，Trigger 就是解决这个的：一条贴在屏幕左缘或右缘的小滑条，从它往下拉即可展开面板。

- **Use trigger**：总开关；
- **Position**：放左缘还是右缘；
- **Color / Size**：触发条的颜色与大小。

不想要时关掉 Use trigger，只保留从屏幕顶部下拉的方式。

## 五、Extras：头像、名称与背景图

- **Choose Profile Picture**：在面板头部显示你选的头像；
- **Custom carrier name**：把运营商名称换成自定义文字；
- **自定义背景图**：从相册挑一张图作为整个面板的背景，配透明度设置一起调，否则图太抢、通知文字看不清。

这几项都是观感层面的，与通知行为无关；通知的延后、清除、回复等操作见[通知管理与快捷回复用法.md](通知管理与快捷回复用法.md)。
