# Power Shade 与Material Notification Shade的区别

> Power Shade 与 Material Notification Shade 出自同一开发者、干的是同一件事（替换通知栏），常被放在一起比较；本篇讲两者的关系、按什么选、以及为什么不能同时装。

## 一、两者是什么关系

Material Notification Shade 是 Treydev 更早的作品：把当时新安卓（Oreo）的通知栏样式带到老系统上。它的限制是**在 Android 8.0 本机上反而跑不了** —— 开发者在回复用户邮件时也承认这一点，并给出了后续作品 Power Shade。所以两者的先后关系是：

| | Material Notification Shade | Power Shade |
| --- | --- | --- |
| 定位 | 前作 | 后作、功能更全的一代 |
| 复刻的系统样式 | Android 8（Oreo） | 上线时对标 Android 9（Pie），后续跟随新版本风格 |
| Android 8.0 本机 | 跑不了 | 可用 |
| 其他安卓版本 | 5.0~7.x 一带可用 | 各版本均可用，老机型（5.0 一带）也有兼容记录 |
| 设置分区 | 较简单 | Trigger / Colors / Layout / Extras 四区，划分更细 |

表里的版本兼容信息来自 2018 年前后的评测与历史商店页，新版本可能已变化，以实际安装为准。

## 二、按什么选

- **系统是 Android 8.0 或更高**：没有选择余地，装 Power Shade（前作在这个版本上跑不了）；
- **系统在 5.0~7.x 之间**：两个都能装。想要 Oreo 时代的观感就试前作；想要后续功能（快捷回复、音乐进度条拖动、四区细化设置）就装 Power Shade；
- **只是想尝鲜、不想折腾付费**：两个的免费部分都够把通知栏换掉，先用免费部分看观感，再决定留哪个。

Power Shade 的完整功能清单见[通知栏颜色与布局设置.md](通知栏颜色与布局设置.md)与[通知管理与快捷回复用法.md](通知管理与快捷回复用法.md)。

## 三、不要同时装

两个应用是**同一层系统界面的替换者**，同时启用会互相抢接管：典型表现是下拉时面板闪烁、样式随机切换，或干脆谁都替换不上。选定一个之后，把另一个的开关关掉（或卸载）再启用这一个。装了其他厂商的同类通知栏替换应用时同理 —— 这一类应用同时只能生效一个，排查思路见[权限开启与后台被杀处理.md](权限开启与后台被杀处理.md)。

## 四、没有 root 时的能力边界

应用早期的介绍里明确说过一点，用之前值得知道：不 root 时，Power Shade 对快捷设置里**部分开关**（移动数据、定位服务这一类）没有直接切换的权限 —— 你在它的面板上点这些磁贴，它**跳转到对应的系统设置页**让你手动开；给 root 权限后才能在面板里直接切换。Wi-Fi、蓝牙、手电筒这类常用磁贴不受此影响。

要不要 root 由你自己权衡；不 root 不影响通知栏的外观替换与通知管理这两条主线，只是部分磁贴多点一步。上锁功能与付费的边界另见[免费版与Pro区别.md](免费版与Pro区别.md)。
