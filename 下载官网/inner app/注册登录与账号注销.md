## 一、注册要填什么

装好打开后按提示创建账号即可（安装见[下载与安装教程.md](下载与安装教程.md)）。官方隐私政策写明，注册与登录需要你提供四项基本信息：

| 必填项 | 说明 |
| --- | --- |
| 手机号码 | 收验证码用 |
| 验证码匹配结果 | 短信验证码校验 |
| 密码 | 注册时自行创建 |
| 昵称 | 展示用 |

头像、出生年月日、个性签名属于**可选补充项**——官方明确写了「不提供这些信息，并不会影响您使用 inner 的基本功能」，可以先跳过。换头像时 App 会请求照片权限与存储权限，这两项权限的作用见[隐私设置与权限管理.md](隐私设置与权限管理.md)。

## 二、账号认证与找回为什么要身份证

按隐私政策，你在申请**账号认证**或**账号找回**时，需要提供真实姓名与身份证号码完成身份认证。两点官方提示值得记住：

- 真实姓名与身份证号码属于**个人敏感信息**，政策原文提醒你「谨慎提供」；
- 拒绝提供将无法获得认证/找回这项服务，但**不影响其他功能**的正常使用。

也就是说，日常浏览、发布都不需要身份证；只有走到「证明这个号是你的」这一步才会要。若非必要，可先走在线客服渠道尝试找回。

## 三、账号注销在哪

注销入口在 App 内，官方隐私政策（2026-09-08 版）给的路径是：

```
【我的】→ 右上角【…】→【设置】→【账号管理】→ 账号注销
```

也可以联系在线客服，或通过隐私政策「如何联系我们」一章列出的反馈渠道提交注销请求。注销之后：

- inner 会停止向你提供服务；
- 官方承诺按你的要求删除个人信息或做匿名化处理（法律法规另有规定的除外）。

注销前先想清楚两件事：**发过的作品与专辑是否还要保留**（注销后账号不可再登录找回）、**有没有绑定的付费记录需要处理**。想清楚再点确认。

## 四、两份协议在哪看

涉及账号的规则以这两份官方文本为准（本篇只摘与你动作直接相关的部分）：

- 《inner 隐私政策》：[inner.pub/xx01x01x0/yszq](https://inner.pub/xx01x01x0/yszq)（本版发布与生效日期均为 2026-09-08）
- 《inner 用户协议》：[inner.pub/xx01x01x0/yhxy](https://inner.pub/xx01x01x0/yhxy)

隐私政策里还挂了三份附录清单（个人信息收集清单、第三方 SDK 合作清单、权限申请与使用情况清单），入口在隐私政策正文末尾，逐项对得上，想核对某个权限干什么用就翻它。
