## 一、关掉内容定向推荐

inner 会按你的浏览与搜索偏好做个性化推荐。不想让推荐跟着你的兴趣走，隐私政策给的关闭路径是：

```
【我的】→ 右上角【…】→【设置】→【隐私设置】→ 关闭【内容定向推荐】
```

关闭后官方的说法是「您看到的 inner 内容推荐将会与您偏好无关」——推荐还在，但不再基于你的偏好画像。这个开关不影响你正常关注、点赞、搜索。

## 二、权限在哪里统一管

同一路径下还有系统权限总开关：

```
【设置】→【隐私设置】→【系统权限】
```

这里能跳转到系统设置逐项开关。要记住的是：**关掉某项权限 = 撤回授权**，App 不再基于该权限收集信息，对应功能也一并失效；此前已收集的不受影响。各类权限关掉后具体失去什么，看下表。

## 三、拒了权限会失去什么（官方口径）

| 权限 | 用在哪些场景 | 拒绝后的实际后果 |
| --- | --- | --- |
| 存储权限 | 上传图片/视频、下载作品到相册、缓存 | **不能上传，也不能下载**图片与音视频；浏览展示不受影响 |
| 照片权限 | 选头像、发图时读相册 | 不能更换头像、不能从相册选图发布 |
| 设备信息相关 | 基础运行、识别账号异常 | 官方提示拒绝可能导致无法使用产品与服务 |

这张表解释了两类高频故障：**「作品死活发不出去」**先去查存储权限有没有被关（排查顺序见[常见问题与解决方法.md](常见问题与解决方法.md)）；**「下载的图找不到」**同理。权限相关的问题先查这里，再怀疑网络。

## 四、App 会收集哪些信息

按 2026-09-08 版隐私政策，主要几类：

- **你主动填的**：手机号、昵称、头像、发布的内容（详见[注册登录与账号注销.md](注册登录与账号注销.md)）；
- **使用过程中产生的**：浏览历史、搜索词与搜索记录、日志信息（IP、访问时间、停留时长等）、设备信息（机型、系统版本、分辨率、设备标识符等）；
- **发布时**：你发布的文字、图片、视频及其展示所需的昵称头像。

政策同时说明：在中国境内收集和产生的个人信息存储在境内；对外共享主要发生在「分享到第三方」和第三方 SDK 两条场景，具体清单可查政策末尾的《个人信息收集清单》《第三方 SDK 合作清单》《权限申请与使用情况清单》。
