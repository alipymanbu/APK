## 一、先弄清楚：这个应用装在手机上，不装在电脑上

很多人搜到这个应用后第一反应是「下到电脑里装」。装错位置，后面全走不通。

Link to Windows（中文界面里叫「连接至 Windows」）是微软出的**安卓端应用**，装在你的安卓手机上；电脑那一头对应的程序叫「手机连接」（Phone Link），Windows 10 / 11 一般自带，不需要你另找安装包。两个程序各自待在自己那台设备上，配对之后才开始互相传数据。

一个例外要提前知道：三星、荣耀、OPPO 的部分机型以及 Surface Duo，出厂就预装了 Link to Windows——从屏幕顶部下滑，在快捷设置面板里能看到「连接至 Windows」的图标。这类手机不用再装一遍，直接进[配对那篇](配对连接与权限设置.md)即可。

## 二、装之前核对：手机和电脑要满足什么条件

| 设备 | 要求 | 说明 |
| --- | --- | --- |
| 手机 | Android 7.0 及以上（官方基础口径） | 较新的功能（如 Windows 11 的「管理移动设备」）要求 Android 10 及以上；具体功能有差异，以官方支持页为准 |
| 电脑 | Windows 10 2019 年 5 月更新或更高，或 Windows 11 | 更老的系统装不上「手机连接」，手机端装了也白装 |
| 网络 | 手机与电脑连同一个 Wi-Fi | 后续也支持移动数据、蓝牙等连接方式，但初次配对建议同一 Wi-Fi |

两个容易忽略的点：

1. **打电话这个功能需要电脑有蓝牙**。台式机没有蓝牙的话，短信、通知、照片不受影响，电话打不了。
2. 微软官方支持页明确写了：手机连接**不支持多个安卓配置文件或工作 / 学校账户**。手机分身、工作资料这类环境可能连不上。

动手前先查一下自己手机的 Android 版本：设置 → 关于手机 → Android 版本。低于上表口径（尤其低于 7.0）时，Play 商店会直接显示「不兼容」，装旧版 App 大概率也连不上 Windows 11 的电脑；电脑端的「手机连接」同样要在 Microsoft Store 里保持更新，旧版电脑端会直接挡住配对。

## 三、安装包从哪来

官方渠道有两个：

- Google Play 商店，搜索「Link to Windows」或直接打开应用页：[play.google.com/store/apps/details?id=com.microsoft.appmanager](https://play.google.com/store/apps/details?id=com.microsoft.appmanager)
- 在手机浏览器里输入电脑上显示的地址 `https://www.aka.ms/yourpc`，会跳到对应的应用商店

如果你的手机装不了 Google Play（国行手机大多如此），或者 Play 商店显示「与此设备不兼容」，可以用网盘里的安装包直接装：[Link to Windows 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4abc6c6a8b38)，转存后把 apk 文件传到手机上安装。

安装包核对信息（以文件实际属性为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.25042.157.0 |
| 包名 | `com.microsoft.appmanager` |
| 大小 | 102.67M |
| MD5 | `C7AE39531D124C69BA917391CAC65C5B` |
| 开发者 | 微软（中国）有限公司 |

核对包名和 MD5 是为了确认拿到的是微软官方包，而不是改过的东西。装之前可以先对一下。

## 四、安装步骤

1. 把 apk 文件放进手机存储（微信 / QQ 发给自己、数据线拷贝、网盘 App 下载都行）。
2. 在手机文件管理器里点开这个 apk。第一次会提示「未知来源应用」，按提示允许浏览器或文件管理器安装应用即可。
3. 等安装完成，打开 App，同意基本条款。
4. 打开 App 后第一步就是登录微软账户——**用和电脑上相同的那个账户**。账户不一致是后面配对失败的常见原因，[排查篇](连接失败与常见问题排查.md)里有专门一节。

装完先别急着研究界面，直接去看[配对连接与权限设置](配对连接与权限设置.md)，把手机和电脑连起来，这个应用才算真正能用。
