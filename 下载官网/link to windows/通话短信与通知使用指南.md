## 一、功能总览：能用什么，看三个前提

电脑端「手机连接」窗口是按标签页组织的（消息 / 通话 / 通知 / 照片 / 应用）。某个标签页能不能用，取决于三件事：**手机给没给对应权限**（见[配对连接与权限设置](配对连接与权限设置.md)第五节）、**电脑硬件是否支持**、**手机系统版本与机型**。先对下表，再去研究某个功能为什么是灰的：

| 功能 | 前提 | 典型不可用原因 |
| --- | --- | --- |
| 短信 | 通知 + 短信 + 联系人权限 | 国行系统对短信权限的限制 |
| 通话 | 电脑有蓝牙 + 电话权限 | 台式机没有蓝牙 |
| 通知 | 通知访问权限 | 权限没给，或手机通知被系统聚合 |
| 照片 | 照片 / 文件权限 | 权限没给 |
| 手机应用 / 投屏 | 特定机型（三星、荣耀等）+ Windows 10 2020 年 5 月更新及以上 + 8GB 内存 + 手机 Android 11 及以上 | 非预装机型；内存不足 |
| 跨设备文件管理（Windows 11「管理移动设备」） | Windows 11 + 手机 Android 10 及以上 + Link to Windows 1.23112.189 及以上 | 系统或 App 版本过旧 |

## 二、短信：在电脑上收发

电脑端进入「消息」标签页，会看到手机上的短信会话列表。你可以：

- 点开会话查看历史，输入框直接回复；
- 搜索会话与联系人；
- 新建短信发给联系人列表里的人。

实际使用中有几个细节值得知道：

1. 电脑上发出的短信走的还是手机的 SIM 卡，运营商照常计费，不会因为「在电脑上发的」就变成网络消息。
2. 彩信的显示与发送在部分系统组合上不稳定，发不出去时改用手机端处理。
3. 验证码短信会同步出现在电脑通知里，这也意味着**共用电脑时要注意屏幕隐私**，看完随手清除。

## 三、通话：电脑当话机

「通话」标签页可以拨打、接听、拒接，还能看通话记录、搜索联系人直接拨号。前提与使用注意：

1. **电脑必须有蓝牙**，这是官方写明的硬条件。台式机没有蓝牙的，加一个 USB 蓝牙适配器即可，无需其他配置。
2. 通话时电脑用自带麦克风和扬声器，也可以在通话中切换到耳机。
3. 拨号走的是手机的网络与号码，跟短信一样，不在电脑上产生独立话路。

## 四、通知：看什么、回什么、怎么不被刷屏

手机通知会同步成电脑右下角的横幅，并进入「通知」标签页。你能做的：点开查看、直接回复（支持的消息类型）、鼠标悬停后清除单条、全部清除、把常看的会话固定。

真正影响体验的是三件事——别太吵、别漏收、知道哪些本来就收不到：

1. **让它别太吵**：电脑端「手机连接」→ 设置 → 通知，可以按应用逐个关掉同步，只留需要的（比如只留微信和验证码）。手机端系统设置里对某个应用关掉通知，电脑端也就收不到了，两边走的是同一条通知通道。
2. **一条都不来**：多半是电脑节电模式 / 专注助手开了，或手机端通知访问权限需要重置，官方修法见[收不到通知怎么办](收不到通知怎么办.md)。
3. **个别通知永远不来**：两类是「设计如此」——Android 15 起系统把验证码、一次性密码类通知标记为敏感并**禁止**同步到电脑（电脑端只显示「隐藏敏感通知内容」，要看只能拿手机）；三星机型的安全文件夹内应用，通知也不出手机。另有部分应用的横幅回复按钮不可用，这是消息类型限制，不是故障。

通知之外还有个附属能力：电脑端可以显示手机正在播放的音频并控制上一曲 / 暂停 / 下一曲（设置 → 个性化 → 「显示当前从我的手机播放的音频」），但声音仍从手机那头出，电脑只当遥控器。

## 五、照片：最近约 2000 张直接拖

「照片」标签页显示手机相册里最近的约 2000 张图。查看之外的两个常用动作：拖拽到电脑任意文件夹完成复制；复制粘贴到聊天窗口或文档里直接发送。

注意它只同步**最近的**照片，翻找很久之前的图还得回手机；想整批导出照片时，数据线或系统级的文件访问（见下一节）更实际。

## 六、手机应用与投屏：为什么你的机型可能没有

「应用」标签页和手机屏幕投射是宣传里最显眼的功能，但**门槛也最高**：官方条件是特定机型（三星、荣耀等预装 Link to Windows 的设备）、电脑 Windows 10 2020 年 5 月更新及以上且 8GB 内存以上、手机 Android 11 及以上。

国产非预装机型上这两个标签页直接不出现，属于机型限制，换任何设置都调不出来。这类机型用户能稳定依赖的还是前四节：短信、电话、通知、照片。

## 七、Windows 11 的「管理移动设备」：另一条入口

除了「手机连接」应用，Windows 11 还有第二个管理入口：「设置」→「蓝牙和其他设备」→「移动设备」。配对后能开启三件事：

1. **在文件资源管理器中显示移动设备**——资源管理器侧边栏出现手机入口，直接浏览、复制手机里的文件和照片；
2. **用作连接的相机**——手机摄像头变成电脑的系统级网络摄像头，视频会议软件里可以直接选用；
3. **获取新照片通知**——手机拍了新照片，电脑弹通知提醒你打开处理。

这条入口要求的版本比基础配对新：手机 Android 10 及以上、Link to Windows 应用 1.23112.189 及以上（本文安装包为 1.25042.157.0，满足）。功能开关都集中在「管理设备」页面里，逐项打开关闭即可。

用下来哪个功能持续不工作，别反复重配，先去[连接失败与常见问题排查](连接失败与常见问题排查.md)按现象找原因。
