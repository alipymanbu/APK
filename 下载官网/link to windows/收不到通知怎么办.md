# Link to Windows 收不到通知怎么办

> 电脑上看不到手机通知，或通知突然停止同步——本篇按「一条都收不到 / 突然停了 / 个别不显示」三种现象给对应修法，全部来自官方支持口径。

## 一、先分清三种现象

修法完全不同，先对号入座：

| 现象 | 直接去 |
| --- | --- |
| 电脑上一条通知都没有 | 第二节 + 第三节 |
| 之前好好的，突然不来了 | 第三节（重置通知访问权限） |
| 其他通知正常，只有个别不显示 | 第四节 |

另外注意：通知同步是**独立**于消息、照片的通道，通知坏了不代表短信坏了，反过来也一样。

## 二、电脑侧：这三个开关会静默吞掉全部通知

1. **节电模式**。电脑电量低或节电模式开着，通知直接不显示。关掉：设置 → 系统 → 电源和电池。
2. **专注助手 / 勿扰**。Windows 的这个模式开着时，横幅一条不弹。关掉：点任务栏右下角的通知图标，切换「勿扰」开关；旧版叫「专注助手」。
3. **后台运行权限**。设置 → 隐私 → 后台应用（旧版本路径），确认「手机连接」允许在后台运行。

## 三、手机侧：重置通知访问权限（官方修法）

通知突然停止同步时，微软官方给的修法是把通知权限关掉再打开，触发重新同步：

1. 手机「设置」里搜索 **通知访问**（部分系统叫「通知使用权」）。
2. 在列表里找到「连接至 Windows」，**关闭再打开**。
3. 弹出确认框时选「允许」。
4. 回电脑打开「手机连接」→「通知」标签页，等它刷新，同步应恢复正常。

顺手再查两项：

- **手机的勿扰模式**要关（设置 → 声音 / 通知）。
- **电池优化**会在后台掐断连接，官方给了两种系统下的路径，哪种走得通走哪种：
  - 设置 → 应用和通知 → 应用信息 → 连接至 Windows → 高级 → 电池 → 管理电池使用情况 → 电池优化 → 把「连接至 Windows」设为**不优化**；
  - 或设置 → 应用 → 连接至 Windows → 电池 → 优化电池使用情况 → 下拉选「全部」→ 找到「连接至 Windows」→ 关闭优化开关。

## 四、个别通知不显示：这几个原因都是「设计如此」

排除了权限问题后，以下几类通知**本来就不会**同步到电脑，不是故障：

1. **Android 15 的敏感通知机制**。Android 15 起系统会用算法识别验证码、一次性密码类通知并标记为敏感，这类通知**不会**出现在电脑端，只会显示一条「隐藏敏感通知内容」。要看内容只能拿起手机。所有 Android 15 及以上设备都受此影响，目前没有绕过开关——验证码场景直接回手机看。
2. **三星安全文件夹**。存放在安全文件夹里的应用，其通知只出现在手机上，电脑端不显示（官方明确说明）。
3. **应用自己的通知被关了**。两边走的是同一条通知通道：某个应用在手机系统里被关了通知，电脑端自然也没有。手机「设置 → 通知」里逐应用检查。

## 五、顺手开启：在电脑上控制手机的音频

和通知配套的一个实用功能：手机上正在播的音乐 / 播客，可以在电脑端控制播放。

开启方法（电脑端）：「手机连接」→ 设置 → 个性化 → 打开「显示当前从我的手机播放的音频」。前提是通知已设置好，且要控制的音频应用在手机上开着通知。

实际边界要知道：电脑上能做的是上一曲 / 播放暂停 / 下一曲和切换音频源，**声音仍然从手机（或手机连的扬声器）放出来**，不会从电脑出声；少数第三方音频应用不显示在列表里，属应用兼容性问题。

通知之外的功能异常，去[连接失败与常见问题排查](连接失败与常见问题排查.md)；各功能怎么用，见[通话短信与通知使用指南](通话短信与通知使用指南.md)。
