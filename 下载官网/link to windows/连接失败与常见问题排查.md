## 一、先看连接状态显示什么

两处状态入口先打开：

- **手机端**：Link to Windows 主界面顶部，会显示当前连接的电脑名称与连接状态；
- **电脑端**：「手机连接」窗口右上角，显示手机是否在线。

「手机端未连接」和「已连接但功能不可用」是两条完全不同的排查路线，先确认你遇到的是哪一种，再往下走对应章节。

## 二、完全连不上：按顺序过这六项

这个顺序按出现频率排，前两项就能解决大半：

1. **两台设备不在同一个网络**。手机连着移动数据、电脑连着另一个路由器的 Wi-Fi，是最常见的原因。初次配对务必让两边连同一个 Wi-Fi；公司或校园网开了 AP 隔离（设备之间互不可见）时，换手机热点试。
2. **微软账户不一致**。手机 App 和电脑「手机连接」登录的不是同一个账户，配对流程会卡在登录环节。两边都退出重新登录同一个账户。
3. **后台被杀**。手机系统把 Link to Windows 当后台应用清掉了。给它开「允许后台运行」、关掉对它的省电限制、在最近任务里锁定——各家系统叫法不同，路径在「设置 → 应用 → Link to Windows → 电池 / 后台」。
4. **电脑端「手机连接」本身没更新或没装好**。Windows 10 需要确认版本在 2019 年 5 月更新以上；应用本体可以从 Microsoft Store 搜索「手机连接 / Phone Link」更新。
5. **蓝牙问题只影响通话**。其他功能连不上与蓝牙无关，别把时间花在这。
6. **时间不对**。手机与电脑系统时间差太多会导致握手失败，开启自动同步时间。

## 三、连上但频繁掉线

掉线多是**省电策略**问题，手机息屏一段时间后系统掐断连接，回电脑上就显示离线：

1. 手机端：关闭对 Link to Windows 的电池优化（设置 → 应用 → Link to Windows → 电池 → 允许后台活动 / 无限制）。
2. Wi-Fi 休眠策略改为「始终保持连接」（部分系统叫「休眠时保持 WLAN 连接」）。
3. 电脑端：「手机连接」→ 设置 → 常规，确认「在后台运行」类开关是打开的；电脑休眠后连接自然断开，唤醒后等它自动重连，或手动点重连。
4. 官方支持页有一句可以当定心丸的话：只要设备开着并联网，即使手机息屏，手机连接的各项功能仍应继续工作——如果你这里息屏就断，几乎可以确定是第 1 项。

## 四、国行手机与区域设置

在中国大陆使用荣耀、三星、OPPO 等机型连接时，微软有一份单独的官方说明，要求比国际版多几条（以下为官方口径，可能有更新，以官方支持页为准）：

| 项目 | 要求 |
| --- | --- |
| 电脑区域设置 | 必须为「中国」：设置 → 时间和语言 → 语言和区域 → 国家或地区 → 中国 |
| 电脑端「手机连接」版本 | 1.21121.231 及以上 |
| 网络 | 手机与电脑同一 Wi-Fi |

电脑区域不是中国时，典型症状是**配对扫码成功后卡在某一步、或手机端一直提示连接失败**。改完区域后建议重启电脑再试。

另外，国行系统普遍对短信、通知权限卡得比国际版紧，权限请求弹不出来时去系统设置里手动授予（路径见[配对连接与权限设置](配对连接与权限设置.md)第五节末尾）。

## 五、功能标签页是灰的或不出现

「应用」「投屏」这类功能不出现，绝大多数是**机型与版本门槛**没到，不是故障：

| 现象 | 原因与处理 |
| --- | --- |
| 「应用」标签页不出现 | 需预装机型（三星 / 荣耀等）+ 电脑 8GB 内存 + Windows 10 2020 年 5 月更新以上 + 手机 Android 11 以上，见[功能总览表](通话短信与通知使用指南.md#一功能总览能用什么看三个前提) |
| 「通话」能用但经常中断 | 电脑蓝牙信号弱，缩短距离或换 USB 蓝牙适配器 |
| 照片标签页空 | 手机端照片权限未授予，或相册里确实没有近期图片 |
| 「管理移动设备」里找不到手机 | Windows 11 专属功能，且要求手机 Android 10 以上、Link to Windows 1.23112.189 以上 |

## 六、权限被拒之后怎么恢复

配对时点了「拒绝」，之后相关功能一直不工作。恢复路径固定：手机「设置 → 应用 → Link to Windows → 权限」，把对应权限改为允许；通知类权限在「通知使用权限」里单独给。授完权不用重配，手机端断开再连一次即可。

## 七、最后手段：卸载重装

前面六节都过了仍然异常，再走这条路：

1. 电脑端「手机连接」→ 设置 → 我的设备 → 移除该手机；手机端 Link to Windows 里同步移除配对。
2. 手机端卸载 Link to Windows，用[下载与安装教程](下载与安装教程.md)里的安装包重装。
3. 重新走一遍[配对流程](配对连接与权限设置.md#二方式一从电脑发起推荐)。

重装后版本会回到安装包对应版本（本文安装包为 1.25042.157.0），联网后 App 会自动提示更新到当前最新版，以官方页面显示为准。
