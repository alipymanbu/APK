# Link to Windows 配对连接与权限设置

> 本篇讲手机和电脑怎么配到一起：从哪边发起、扫码还是输码、每一步要给什么权限、怎么再加一台设备或解绑。

## 一、配对前把四件事确认好

配对本身只要一两分钟，失败基本都是这几件事没到位，先逐条过一遍：

1. 手机已装好 Link to Windows（没装的看[下载与安装教程](下载与安装教程.md)）。
2. 电脑上能打开「手机连接」：任务栏搜索框输入「手机连接」（或 Phone Link）。
3. 两台设备连着**同一个 Wi-Fi**，且距离不远。什么叫「同一个」有讲究——同名双频段、AP 隔离、公共网络都会让「看起来在同一网络」的两台设备互相看不见，细节见[wifi连接与网络环境要求](wifi连接与网络环境要求.md)。
4. 手机和电脑登录**同一个微软账户**。

预装机型（三星 / 荣耀 / OPPO 部分机型）的入口在快捷设置面板：屏幕顶部下滑，点「连接至 Windows」图标即可打开，不用找应用图标。

## 二、方式一：从电脑发起（推荐）

这是官方支持页给的主路径，手机端配合扫码就行：

1. 电脑上打开「手机连接」，选择 **Android**（安卓）。
2. 按提示登录微软账户。
3. 电脑屏幕上出现一个二维码。
4. 手机上打开 Link to Windows，选「连接手机和电脑」，App 会请求相机权限，授权后扫电脑屏幕上的码。
5. 手机上会依次弹出权限请求（下一节有完整清单），逐项允许。
6. 两边都显示完成，电脑端出现你手机的名称，配对结束。

## 三、方式二：从手机发起

手机上已经登录好了账户，也可以反着来：

1. 手机上打开 Link to Windows，登录与电脑相同的微软账户。
2. 电脑上打开「手机连接」，勾选「我已准备好连接至 Windows 应用」，选「与 QR 码配对」。
3. 手机扫码，后续步骤与方式一相同。

另外还有个不依赖 App 的入口：在电脑浏览器打开 `https://www.aka.ms/yourphoneqrc` 可以直接调出配对二维码，适合给**第二台手机**配对时用。

## 四、没有二维码：手动配对

摄像头扫不上码（屏幕反光、摄像头坏了）或者网络环境不支持时，电脑端「手机连接」里选「手动配对」，屏幕会给出一串配对码；在手机的 Link to Windows 里选手动配对方式，把这串码输进去，效果和扫码一样。

## 五、配对时会要哪些权限，各管什么

App 不会一次要完所有权限，而是按你要用的功能逐步来。下面是常见请求与它背后的功能对应关系，方便你判断该不该给：

| 弹出的权限请求 | 对应的电脑端功能 | 不给会怎样 |
| --- | --- | --- |
| 相机 | 扫配对二维码 | 扫不了码，配对无法开始（可改手动输码） |
| 通知访问权限 | 电脑上查看、回复、清除手机通知 | 通知相关功能全部不可用 |
| 短信、联系人 | 电脑上收发短信、显示会话人名 | 短信功能不可用 |
| 电话 | 电脑上拨打、接听电话，查看通话记录 | 电话功能不可用 |
| 照片 / 文件 | 电脑上浏览、拖拽手机最近照片 | 照片与文件传输不可用 |
| 附近设备 / 后台运行 | 维持手机与电脑的持续连接 | 容易被系统杀后台，频繁掉线 |

拿不准的可以少给：权限在系统设置里随时能补，路径一般是「设置 → 应用 → Link to Windows → 权限」。给了之后电脑端功能不会立刻出现，重新开关一次连接即可。

## 六、再加一台电脑或一台手机

- **一台手机连第二台电脑**：在第二台电脑上把「手机连接」走一遍方式一即可；同一部手机可以同时保持与多台电脑的配对。
- **一台电脑连第二部手机**：电脑上打开「手机连接」→ 设置 → 「我的设备」→ 添加新设备，或直接在浏览器打开 `https://www.aka.ms/yourphoneqrc`，用另一部手机扫码完成配对。

## 七、解绑与重新配对

解除配对有两个方向，做其中一个即可：

- **手机端**：Link to Windows 里点当前连接的电脑名称 → 选择移除 / 取消配对。
- **电脑端**：「手机连接」→ 设置 → 「我的设备」→ 选中该设备 → 移除。

账户里挂过的旧设备也可以统一清理：登录微软账户设备管理页 [account.microsoft.com/devices/android-ios](https://account.microsoft.com/devices/android-ios)，能看到并移除所有链接过的手机——换机后旧配对残留在账户里，是「重配总是失败」的一个隐蔽原因。

解绑后重新配对，走第二节的方式一即可。如果是因为反复掉线、功能异常而重配，先去[连接失败与常见问题排查](连接失败与常见问题排查.md)过一遍清单，很多时候问题出在权限或省电策略上，重配解决不了。

配对完成后各类功能怎么用，直接看[通话短信与通知使用指南](通话短信与通知使用指南.md)。
