# Recuva 恢复失败与扫描不到的排查

> 扫描跑完了结果里没有你要的文件？恢复出来的照片打不开？本篇按症状把安卓版 Recuva 最常见的几类「没恢复出来」逐个拆开，给出判断方法和下一步。

## 一、先分清碰到的是哪种情况

症状不同，原因和处理完全不同，动手前先对号入座：

| 症状 | 多半说明 | 先做什么 |
| --- | --- | --- |
| 扫描列表里根本没有目标文件 | 被覆盖了，或扫描位置/方式不对 | 按第二节排查 |
| 列表里有，但缩略图是灰的、碎的 | 文件本体已被部分覆盖 | 按第三节处理，能救多少救多少 |
| 恢复成功，但文件打不开 | 恢复前就已损坏，或保存过程被打断 | 按第三节处理 |
| 点恢复时提示付费 / 任务解锁 | 免费版的功能边界到了 | 按第四节处理，并看 [付费解锁前怎么判断值不值.md](付费解锁前怎么判断值不值.md) |

先说结论：**如果删掉之后手机又重度使用了几天，多数情况下确实找不回来了** —— 这不是操作错误，是数据被新内容覆盖的物理结果。下面的步骤帮你确认「是不是真的没了」，以及「还能捞回多少」。

## 二、扫描不到文件的原因与处理

按顺序核对，每一条都对应一个真实常见的原因：

1. **扫描位置选错了**。照片存在 SD 卡上、你却扫了内置存储（或反过来），结果自然是空的。两个位置各扫一遍再下结论。
2. **只跑了快速扫描**。快扫主要认「最近删除」的记录，删了几天的文件常常不出现在快扫结果里 —— 回主界面换深度扫描再跑一遍，慢，但覆盖面完全不同。
3. **存储权限不足**。扫描范围被权限卡住了，列表看起来「空得奇怪」（连现存的照片都看不见）。去「设置 → 应用 → Recuva → 权限」把存储 / 所有文件访问权限补上，重新扫。装完就没动过权限的，直接看 [下载与安装教程.md](下载与安装教程.md) 第四节。
4. **SD 卡没挂载或接触不良**。扫不到卡上的内容时，先把卡在系统里确认能正常浏览文件，再回来扫；读卡器 / OTG 线接触不好也会是这种表现。
5. **真的被覆盖了**。删除后拍照、下载、装应用、清缓存，都会把那块空间重新分配出去。这种没有补救操作，能做的只有事后把备份补上（文末有具体建议）。

反反复复扫很多遍不会提高成功率 —— 扫描是只读的，结果不会因为重扫变好；但每多拖一天，被覆盖的概率都在涨。

## 三、文件能扫到却打不开，怎么办

缩略图碎裂、恢复出来看不了，原因基本是同一个：**扫描记录还在，但文件本体的部分数据已经被覆盖**。处理思路：

1. 先看预览。预览都显示不全的，恢复出来也大概率不完整，别浪费时间批量恢复这类文件。
2. 换深度扫描再找同一批文件：深扫可能找到同一张照片的另一份残留（相册原图、缓存副本、缩略图副本常常不止一份），其中总有一份相对完整。
3. 部分打开的文件（视频能播前几秒、图片显示一半）就是覆盖的典型结果，第三方工具救不回来，接受现实。
4. 恢复过程本身被打断（中途锁屏、切后台被杀）也会产出坏文件 —— 这种情况重扫重传一次就能解决，属于假性损坏。

另外提醒一句：恢复出来的文件记得存到**另一个位置**再打开验证，别直接往被扫描的原目录里写（原因见 [照片视频恢复步骤.md](照片视频恢复步骤.md) 第四节）。

## 四、免费版的边界：广告、任务与付费提示

这款应用免费可用，但有几道提示你大概率会碰到，都正常，不是文件坏了：

- **看广告**：免费版含广告，扫描、恢复流程中间会插广告，等几秒关掉即可。
- **完成任务解锁恢复**：部分恢复项要求先完成应用内任务（比如试用推荐的应用）再放行，按需决定做不做，不想做就换别的恢复项先试。
- **付费提示**：深度恢复类的功能可能提示付费解锁。要不要买不是扫一眼价格能决定的事 —— 先用免费流程做预览核验，确认「文件确实扫得到、预览正常」，再照 [付费解锁前怎么判断值不值.md](付费解锁前怎么判断值不值.md) 的清单走一遍；别在「扫描都是空的」的状态下付费。

具体哪些功能卡在任务后面、哪些要付费，不同版本不一样，以应用内实际提示为准。

## 五、这几种情况，换工具别硬试

有些数据本来就不该指望恢复应用，早点换正确的路子：

- **微信聊天记录**：先说官方口径 —— 微信服务器不保存聊天记录，内容只存在你的手机和电脑本地，没有备份的手动删除，官方渠道也找不回来。第三方恢复应用更是先天受限：微信的数据存在自己的私有目录里，恢复应用就算拿到了「所有文件访问」权限也进不去（权限边界见 [下载与安装教程.md](下载与安装教程.md) 第四节），能捞的多是图片视频这类落在共享存储里的缓存，文字记录基本捞不动。真要找回聊天记录，按官方渠道的顺序试：
  1. **内置修复**：微信「我 → 设置 → 帮助与反馈」右上角扳手图标 → 故障修复 → 聊天记录（入口名称随版本略有差异）。它本来是修「闪退、数据库出错导致的异常丢失」的，对手动删除不保证有效，但零成本，可以试。
  2. **电脑备份恢复**：以前用电脑微信备份过的话，这是成功率最高的路 —— 电脑微信左下角「更多 → 备份与恢复 → 恢复聊天记录至手机」，手机和电脑连同一个 Wi-Fi，传输走局域网、不耗流量。
  3. **设备间迁移**：旧手机还能登录微信的话，「我 → 设置 → 通用 → 聊天记录备份与迁移」把记录迁到新设备。
  4. 以上都不行的，找对方要关键信息的转发，比任何恢复软件都直接。
- **刚刚误删、手机还没怎么用**：时间窗口珍贵，先把手机静置（开飞行模式），别花半小时装一堆工具；这个应用装好就直接扫，装的过程见 [下载与安装教程.md](下载与安装教程.md)。
- **重要数据、商业数据**：手机进过水、摔过、存储已经报错的，别反复扫描折腾，直接找线下数据恢复机构，软件层面越试越糟。

最后是防复发的部分：相册开云备份、微信记录定期迁移到电脑、重要文件传网盘，任选一样做起来 —— 数据恢复永远是保底手段，不是常规操作。
