## 一、为什么会有两个「Recuva」

「Recuva」这个名字最早属于 Piriform 公司的 Windows 数据恢复软件（Piriform 后来并入 Gen Digital，CCleaner 是它家的另一个产品），名气大，英文搜索结果几乎全是它。

本仓库要装的这个「Recuva」是一款**安卓手机应用**，全名「Recuva 数据恢复助手」，开发者是长沙星纪时代信息技术有限公司。两者重名，但没有隶属关系 —— Piriform 的官方渠道只发布过 Windows 版，没有官方安卓版。

## 二、两者对照表

| 对比项 | Windows 版 Recuva（Piriform） | 安卓版 Recuva（本仓库这份） |
| --- | --- | --- |
| 开发者 | Piriform（现属 Gen Digital） | 长沙星纪时代信息技术有限公司 |
| 运行平台 | Windows 电脑 | 安卓手机 / 平板 |
| 主要用途 | 恢复电脑硬盘、U 盘、存储卡上删除的文件 | 恢复手机里误删的照片、视频、音频、文档等 |
| 怎么获取 | 从 Piriform 官网下载安装到电脑 | 从网盘或应用商店取 apk 装到手机（包名 `procat.data.huifu`） |
| 界面语言 | 英文为主 | 简体中文 |

## 三、你要的是哪一个

按「文件丢在哪」来判断：

- **文件丢在电脑上**（机械硬盘、固态硬盘、U 盘、相机存储卡）→ 那是 Windows 版的活儿，去 Piriform 官网下载电脑版，与本仓库这份无关。
- **文件丢在手机里**（相册照片、录的视频、微信里存的图）→ 需要的是安卓版，也就是从 [Recuva 安装文件资源（夸克网盘）](https://pan.quark.cn/s/de97067d3c4c) 取包装到手机上的这个，装法见 [下载与安装教程.md](下载与安装教程.md)，用法见 [照片视频恢复步骤.md](照片视频恢复步骤.md)。
- **手机存储卡里的文件想用电脑救**：也可以把卡取出来插读卡器接到 Windows 电脑上用 Windows 版扫 —— 这是两条完全不同的路线，选一条就行，别两边都装。

## 四、几个容易混淆的说法，逐个说清

- **「Recuva 出了安卓版」的说法**：你在英文搜索结果里看到的「Recuva for Android」，指的几乎都是「用 Windows 版扫手机存储卡」这种用法，不是有个官方手机 App。Piriform 官方从未发布安卓版。
- **下载站里「桌面版移动端延伸」的介绍**：个别下载站把这个安卓应用的介绍写成「Piriform 桌面版的移动端延伸」，这个说法和它的开发者信息（长沙星纪时代）对不上，别按这个口径理解 —— 认开发者与包名，比认介绍文案靠谱。
- **应用商店里还有别的同名应用**：商店里搜「Recuva」可能出来好几款数据恢复类 App，名字都叫 Recuva，彼此也不是一家的。要装哪一份，以它的包名与开发者为准，别只看名字。
- **教程对不上号**：如果你照着一份英文图文教程找不到界面上的按钮，多半那份教程讲的是 Windows 版 —— 安卓版的操作是另一套，按本仓库文档里的中文界面描述来走。
