## 一、先核对手上这份包

这是一款装在安卓手机上的数据恢复类应用，简体中文界面，主要用来找回误删的照片、视频、音频、文档，附带两台手机之间扫码互传文件和批量清理手机文件的功能。动手安装前先对一下手上这份包：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | Recuva（全名 Recuva 数据恢复助手） |
| 包名 | procat.data.huifu |
| 版本号 | 1.1 |
| 安装包大小 | 24.97 MB |
| 安装包 MD5 | EA38493C830AF2CE1AEEE94F6E294600 |
| 系统要求 | 页面标注「安卓系统 5.2 以上」（安卓没有 5.2 这个正式版本号，别当硬指标，以实际安装为准） |
| 开发者 | 长沙星纪时代信息技术有限公司 |

**版本号别拿别处的来对。** 各大下载站收录的版本与更新时间各不相同，网上搜到的更新日志、体积常常对不上 —— 那是别的渠道的另一份包。判断手上这份对不对只看两项：包名是不是 `procat.data.huifu`，版本号是不是 `1.1`。

**别装错成另一个「Recuva」。** 搜「Recuva」出来的多半是 Piriform 那款 Windows 电脑软件，和这份安卓应用不是一家的东西，两者名字相同、开发者不同、平台也不同。分不清就先看 [同名软件区分指南.md](同名软件区分指南.md)，确认你要的确实是手机上装的这个，再回来继续装。

## 二、从网盘把安装包取到手机

1. 在手机上打开 [Recuva 安装文件资源（夸克网盘）](https://pan.quark.cn/s/de97067d3c4c)。手机浏览器或夸克 App 都能打开，**建议用夸克 App** —— 浏览器下载容易被切后台打断。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存之后就不再依赖原分享链接还在不在。
3. 进自己的网盘找到这个包（形如 `Recuva_v1.1.apk`），点下载，等它落到手机存储里。
4. 下完核对两件事：文件名结尾是不是 `.apk`；大小是不是 24.97 MB 左右。差得多就是没下完整，删掉重来。

习惯在电脑上操作也行：在电脑端网盘下载，再用数据线拷到手机的 `Download` 目录，之后从手机「文件管理」里点它安装，效果一样。

手上有校验工具的话可以顺手算一遍 MD5，和上表的 `EA38493C830AF2CE1AEEE94F6E294600` 比一比：一致说明传输没出错，不一致就重新下一遍。不查也不影响安装。

## 三、安装：系统会拦一次，放行即可

这一份是手动安装的，不是从手机自带应用商店点「安装」装的，所以点安装包时系统会拦一下，提示「不允许安装来自此来源的应用」之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开「文件管理」，进 `Download` 目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，找到你刚才用来打开文件的那个 App 单独放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」，先把第四节的权限理顺再进去，比进去之后反复弹窗省事。

装的时候如果手机上同时装着安全类软件（手机管家、杀毒助手之类），它可能也会弹一次「非商店来源」的提醒，选择「允许」或「信任」即可。

## 四、首次打开：存储权限是关键

数据恢复要扫描手机里的照片、视频、文档，全部功能都建立在「能读到你的存储」上，第一次启动会要授权，建议一次给足：

1. **存储 / 文件权限选「允许」**。安卓 11 及以上通常弹的是「所有文件访问权限」，要把它打开 —— 只给「照片和视频」这类细分权限，扫描范围会缺一截。
2. 授权入口在哪找：弹窗被关掉也没关系，走「设置 → 应用 → 特殊应用权限 → 所有文件访问」，在列表里找到 Recuva，把**允许管理所有文件**的开关打开即可。
3. 这个权限给出去的是什么：按安卓官方的定义，它覆盖共享存储里全部文件的读写，**还包括外置 SD 卡和 USB OTG 设备的根目录** —— 这正是「扫描位置能选到 SD 卡和 OTG」的前提，不开的话这两个位置扫不了。
4. 权限的边界也要知道：即使开着「所有文件访问」，应用**依然进不了其他应用的私有目录**（存储里的 `Android/data` 那一层），微信聊天记录这类数据就在私有目录里 —— 这是第三方恢复类应用对微信文字记录普遍无能为力的根本原因，展开见 [恢复失败与扫描不到的排查.md](恢复失败与扫描不到的排查.md) 第五节。
5. 其余权限（相册、通知等）按提示给。恢复通讯录、短信的入口还会要对应权限，用到时再给也来得及。

权限没给足的典型表现是：扫描页面能打开，但结果一直是空的，或者列表里根本看不到你手机里的照片 —— 先回权限设置补上，再重新扫一次（更多这类现象见 [恢复失败与扫描不到的排查.md](恢复失败与扫描不到的排查.md)）。

## 五、装完先做三步自检

1. **能正常打开主页**：应用首页按类型分块展示恢复入口（照片、视频、音频、文档等），能看到这些分类就算启动正常。
2. **存储权限已开**：进「设置 → 应用 → Recuva → 权限」确认一遍，别只信启动时的弹窗。
3. **找一个不重要的文件试一遍流程**：比如自己拍一张照片删掉，再走一遍 [照片视频恢复步骤.md](照片视频恢复步骤.md) 里的扫描流程，能扫到、能恢复，整条链路就通了。

三步都过就可以正常用了。免费版使用过程中会碰到广告，部分恢复项可能要求先看广告或完成应用内任务，个别功能可能提示付费解锁 —— 这些以应用内实际提示为准，不属于安装环节的问题。

## 六、卸载与换机要注意的

- **卸载前先确认恢复成果已经落袋**：恢复出来的文件要确认在相册或「文件管理」里能看到（也就是存到了普通目录，而不是只在应用里能预览），再卸载应用。
- **换机不靠这个应用搬数据**：聊天记录、通讯录这类要搬到新手机，用微信、手机厂商自带的换机/备份工具更稳，这个应用解决的是「删了想找回来」，不是「搬家」。
- **安装包删了**：任何时候都能回到文首那条 Recuva 安装文件资源的链接重新取一份；已经转存过的不受原分享是否还在影响。
