## 一、离线下载：先把作品存到手机

前提：已登录并完成作品库同步（见 [账号登录与作品库同步.md](账号登录与作品库同步.md)）。

1. 打开一部已购买的作品；
2. 在作品页找到下载入口，选择要下载的范围（整部作品或其中部分文件）；
3. 等下载完成，之后在无网环境（地铁、飞行模式、睡前关数据）也能直接播放。

几个实际使用中的点：

- 下载的内容存在应用自己的空间里，文件管理器里看不到单独的音频文件，清理在应用内进行；应用也没有导出入口——想把这些音频拿去别的用途（设闹钟、导入电脑播放器等），要从 DLsite 网页端把作品文件下载下来，见 [与DLsite Play的区别.md](与DLsite%20Play的区别.md)；
- 空间紧张时，把听完作品的下载内容删掉即可——作品本身一直挂在账号的购买记录里，随时能重新下载；
- 有用户反馈离线播放偶尔不稳定或要求联网，遇到这种情况按 [播放与声音问题排查.md](播放与声音问题排查.md) 的顺序过一遍。

## 二、播放器功能一览

| 功能 | 用来干什么 |
| --- | --- |
| 继续播放 | 上次听到哪里，下次打开接着放，长篇作品不用拖进度条找位置 |
| 睡眠定时器 | 设个时长，到点自动停止播放——睡前听主要靠这个，也省电 |
| ASMR 均衡器 | 6 个预设，针对音声作品的听感调音，戴上耳机逐个试一遍留下顺耳的 |
| 播放列表 | 自由组合不同作品的曲目连着放 |
| 片段播放列表 | 把同一作品里喜欢的段落剪出来单独连放，跳过过场 |
| 隐私锁屏 | 把锁屏上的作品封面换成占位图，公共场合亮屏不尴尬 |
| 本地文件导入 | PurePlay 模式播放手机里已有的音频文件，无需登录 |

官方还在持续加功能（比如每月收听回顾、喜欢的声优/社团出新作时推送通知），某个功能是否可用与你手上的版本有关，以应用内实际显示为准——这份安装文件资源是 2.10.3 版。每月回顾（Playback）另有专属网页 [playback.dlsound.jp](https://playback.dlsound.jp/)，需登录 DLsite 账号查看。

免费试听：不登录也能播放官方放在首页的样例作品，合计 90 分钟以上的双声道音声（官方商店页说明）。

## 三、支持哪些文件格式

- **手机本地文件（PurePlay 模式，无需登录）**：官方口径为 MP3 / AAC / M4A / FLAC / WAV；
- **作品内附带的文件**：音频之外，图片与文本类文件（如 JPEG / PNG / TXT）可以在应用内查看；HTML、EXE 这类文件无法在应用里打开，具体以作品页说明为准。第三方整理的资料提到作品内音频也可能有 WMA，与官方商店口径不完全一致——遇到放不了的文件先怀疑格式，以应用内实际表现为准；
- 不登录、只想播手机里已有的音频文件（PurePlay 模式），见 [本地音频导入播放.md](本地音频导入播放.md)；
- 较新版本开始支持播放作品里附带的视频文件（以官方商店页面的版本说明为准）。

## 四、睡前场景怎么组合

睡前听的用户基本是同一套组合：先把作品下载好 → 播放时开睡眠定时器 → 锁屏后台播放。定时器到点自动停，不用担心半夜循环到天亮；开着隐私锁屏的话，半夜亮屏看到的也只是占位图。哪一环出了问题，去 [播放与声音问题排查.md](播放与声音问题排查.md) 对症查。
