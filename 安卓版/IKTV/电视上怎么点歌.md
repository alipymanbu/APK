## 一、先认识界面

打开应用后，首页可以左右滑动切换不同的功能区，点歌的入口都集中在点歌区。有用户反馈界面顶部提供了动态乐谱、歌手点歌、热歌新歌、主题点歌等约 12 种点歌模式（具体数量与名称以你装到的版本为准）。

**点一次就算点歌**：在歌曲列表里把光标移到目标歌曲上、按遥控器确认键点一下，这首歌就进「已点」列表并开始准备播放，不需要再点什么「确定订购」。

## 二、几种点歌方式

| 方式 | 怎么操作 |
| --- | --- |
| 歌名搜索 | 在搜索框输入歌名关键字，结果里选中即点歌 |
| 首字母点歌 | 输入歌名或歌手的拼音首字母，比如找周杰伦的歌输首字母即可翻出几十页结果 |
| 歌手点歌 | 按歌手浏览，通常分内地、港台、国外等分类，进去按首字母排 |
| 榜单点歌 | 热歌、新歌、主题歌单、综艺歌曲等榜单，直接在榜单里挑 |
| 语种点歌 | 按国语、粤语、英语、韩语、日语等语种筛选 |
| 戏曲专区 | 京剧、评剧、豫剧、秦腔、昆剧、黄梅戏、花鼓戏等剧种单独成类，长辈找戏方便 |
| 手写点歌 | 触屏、鼠标或手写板设备上，直接在屏幕上写字搜歌名、搜歌星 |

实际用哪种看你的设备：带触摸屏的可以手写，纯遥控器的用搜索框输首字母最快。

## 三、已点列表怎么管理

点过的歌都会进「已点」列表，播放过程中你可以：

- 继续往里加歌，排队在后面；
- 调整顺序，把想唱的提前；
- 删掉不想唱的；
- 直接切歌，跳到下一首。

列表怎么打开、按钮在哪，不同版本略有差异 —— 用遥控器在播放界面按确认或菜单键调出选项即可，找不到就看 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 四、播放与全屏

点歌后画面默认在界面下方的 MV 窗口里播放。**点一下 MV 画面就进全屏嗨唱模式**；全屏状态下**双击屏幕可呼出菜单**，切歌、暂停等操作都在这个菜单里。想调原唱/伴唱、变调变速、清晰度，见 [原唱伴唱切换与变调变速.md](原唱伴唱切换与变调变速.md)。

## 五、能用哪些输入设备

IKTV 支持市面上常用的点歌面板、遥控器、鼠标、触摸屏、手写板等设备点歌，装在电视上就用遥控器，装在触屏设备上就能点能写。遥控器按键对不上号时，不用换遥控器 —— 应用内提供可自定义的遥控键码设置，改键码即可适配（见 [常见问题与解决办法.md](常见问题与解决办法.md)）。

不想在电视上一个个输字母，也可以用手机扫码当点歌板，见 [手机扫码点歌怎么用.md](手机扫码点歌怎么用.md)。
