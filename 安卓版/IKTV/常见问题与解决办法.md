# 常见问题与解决办法

> 装不上、扫码连不上、没声音、卡顿、存储被占满 —— 用 IKTV 时最常撞到的问题和对应的处理顺序。

## 一、装不上、闪退、卡顿

| 现象 | 处理 |
| --- | --- |
| 安装时提示解析错误 | 文件没下完整 —— 重新下载，核对大小 86.06M 与 MD5（见 [下载与安装教程.md](下载与安装教程.md)） |
| 装到一半失败/被拦 | 关掉电视卫士、手机管家这类安全软件再装；系统弹「未知来源」时允许本次安装 |
| 打开就闪退 | 确认系统版本够新（各下载页标注不一，以安装提示为准）；有资料建议设备存储剩余 ≥ 2GB，空间不够先清理 |
| 用起来卡 | 别同时运行其他音效/变声类软件，容易冲突卡顿；关掉后台多余应用再试 |

## 二、扫码提示二维码错误，或提示设备端拒绝连接

这两个提示本质是**手机和电视没连上**，按顺序过一遍：

1. 手机与电视/盒子必须在**同一个 WiFi**（访客网络、不同频段分流的网络要归到一起）；
2. 电视端退出二维码页面重新进入，刷新二维码（动态码会过期）；
3. 重启电视端 IKTV 应用；
4. 还不行就重启路由器，再从第 2 步重来。

扫码相关细节见 [手机扫码点歌怎么用.md](手机扫码点歌怎么用.md)。都试过仍连不上，直接用遥控器点歌，不被这功能卡住。

## 三、没有声音

按「先物理、后软件」排查：

1. **先查连接**：电视音量有没有开、外接音响开关与音量、话筒电量/音量；
2. **再查设置**：有资料建议进「设置 → 音频输出」尝试**强制解码**；
3. **最后清数据**：有用户反馈清一下应用数据能解决一部分无声问题（设备上进「设置 → 应用 → IKTV → 清除数据」，注意这会清掉本地缓存与偏好设置，相当于恢复初始状态）；
4. 同时确认没叠开别的音效类软件（见第一节）。

## 四、黑屏、有声无画

先检查 HDMI 线插没插牢、换一根或换个接口试；线没问题再重启设备。持续黑屏但能听到声音，通常是输出链路问题，与应用本身关系不大。

## 五、歌曲加载慢、播着卡

- 歌曲是**边点边下载缓存**的，点太多首会占满带宽 —— 已点列表里删掉暂时不唱的；
- 有资料建议歌曲加载慢就**切到 5G WiFi**（路由器 2.4G/5G 分开的选 5G 那个）；
- 网络本身不稳的，进播放菜单把清晰度调低（见 [原唱伴唱切换与变调变速.md](原唱伴唱切换与变调变速.md)）。

## 六、存储空间被越占越多

每点一首歌都会下载缓存到本地，唱得多了电视自带存储很快见底。三个办法：

1. 在应用设置里打开**自动删除音乐**类开关（有用户反馈该选项存在，以你的版本为准），让旧缓存自动清；
2. 插一个 U 盘，把缓存目录指到 U 盘上（设备支持外置存储的前提下）；
3. 定期进系统「应用 → IKTV → 清除缓存」清一遍 —— 注意**清缓存**不影响设置，**清数据**才会。

## 七、遥控器按了没反应 / 按键错乱

不同品牌遥控器键码不同，IKTV 里提供了可自定义的**遥控键码设置**：进设置找到该项，按提示重新匹配按键即可，不需要换遥控器。触屏、鼠标、手写板设备则可绕开遥控器直接操作（见 [电视上怎么点歌.md](电视上怎么点歌.md)）。

## 八、要不要登录、要不要更新

有用户反馈装上后**无需注册登录**即可直接点歌；启动时弹出的更新提示，也有用户选择「暂不更新」继续使用 —— 更不更新自行决定，以你实际装到的版本表现为准。第三方页面标注的版本号混乱，核对方式见 [下载与安装教程.md](下载与安装教程.md)。
