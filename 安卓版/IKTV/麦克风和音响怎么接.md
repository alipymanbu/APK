# 麦克风和音响怎么接电视

> 在家用 IKTV 唱歌只有伴奏没人声、或者声音小得听不清，多半是话筒音响没接对。本篇讲接口怎么选、系统里要开哪几处。

## 一、先想清楚声音从哪出

唱歌出声分两路：**伴奏和人声从哪个设备出**、**话筒的声音进哪个设备**。最常见的两种组合：

| 组合 | 怎么接 | 适合 |
| --- | --- | --- |
| 电视自带扬声器出声 | 话筒直接接电视（USB/蓝牙/音频口），电视一个口全包 | 设备少、图省事 |
| 外接音响/功放出声 | 电视音频输出切到外接音响，话筒按音响的要求接 | 追求音量和人声厚度 |

接完务必检查一件事：**别让电视自带喇叭和外接音响同时出声** —— 双路发声会叠加出混响噪声，电视声音输出要单独切到外接那一路。

## 二、话筒的三种接法与对应的坑

| 类型 | 接法 | 常见的坑 |
| --- | --- | --- |
| USB 接收器型 | 接收器插电视/盒子的 USB 口 | 插的口只供电不传音频 —— 认准标着 `USB Audio` 或明确支持音频输入的口；部分电视还要在设置里手动打开「USB 音频输入」 |
| 蓝牙型 | 电视蓝牙设置里配对 | 配对成功 ≠ 生效，还要到声音设置里把输入源切到蓝牙麦克风；老设备蓝牙延迟明显，节奏会差半拍 |
| 3.5mm 音频线型 | 插标注 `Audio In` / `Line In` / `MIC In` 的输入口 | **插错成耳机孔（Headphone Out）就没救** —— 耳机孔只出不进，插上必然只有伴奏没人声 |

判断有没有接对，最快的办法是：**对着话筒说话，电视/音响里能不能实时听到自己**。听不到就是链路断在某一环，按下一节的顺序查。

## 三、系统里要开的两处

硬件插上只是第一步，系统里还有两处开关要动：

1. **音频输入**：进电视「设置 → 声音 → 音频输入设备」（有的叫「外部设备音频输入」），把刚接的话筒选上；
2. **音频输出**：进「声音输出/音频输出」，按实际接线选 `HDMI` / `SPDIF` / `AV` —— 选的类型要和你实际插的线一致，接了 HDMI 却选 AV，照样没声。

另外别忘了应用侧：IKTV 第一次运行要授予**麦克风权限**，没给的话软件层拿不到人声（见 [下载与安装教程.md](下载与安装教程.md)）。

## 四、接好之后的三步调试

1. **人声与伴奏平衡**：电视端关掉「自动音量均衡」「虚拟环绕声」这类会压人声的功能；话筒音量先从中间档起步，唱起来不炸不飘再微调；
2. **啸叫（刺耳的尖叫声）**：把话筒增益调小一档、话筒别正对音响喇叭，站位挪开一点，多数啸叫当场消失；
3. **延迟（嘴动了声音慢半拍）**：电视有「游戏模式」的打开它，能压掉一部分音画处理延迟；蓝牙话筒延迟大于有线，介意就换 USB 接收器或音频线方案。

调音效（混响、原唱伴唱、变调变速）本身在应用里做，见 [原唱伴唱切换与变调变速.md](原唱伴唱切换与变调变速.md)。

## 五、接完还是没声

按「线插没插对 → 系统输入有没有选上 → 应用有没有麦克风权限」这三层顺序过一遍，每层都排除了再回头看音响电源和音量。完整排查顺序（含黑屏、清数据等兜底手段）见 [常见问题与解决办法.md](常见问题与解决办法.md)；接好了设备，回头就能正常开唱 —— [电视上怎么点歌.md](电视上怎么点歌.md)。
