## 一、先弄清你要装的是哪一版

搜索引擎给你的 Ticking 是官方商店里的最新版，而网盘里存的是采集当时的那一版，两者不是一回事。这套文档全部以网盘里这一版为准：

| 项目 | 值 |
| --- | --- |
| 应用名称 | Ticking（待办｜计时｜自习室） |
| 版本 | 1.16.9 |
| 安装包大小 | 97.21M |
| 包名 | cn.oboard.todo |
| MD5 | 788D8DC824054A68B32D901FF797E27B |
| 开发者 | 深圳九九云科技有限公司 |

Ticking 官方迭代很快，各商店上架的版本也不同步——截至 2026-09，有的商店还停在 1.18.x，有的已经到 2.2.x。版本不同，界面和功能就会对不上，排查问题时先确认你自己手机上装的是哪一版（应用内「关于」或系统应用信息里能看到）。

## 二、从夸克网盘拿安装包

手机或电脑打开 [Ticking 安装文件资源（夸克网盘）](https://pan.quark.cn/s/662eadf8a225)，把里面的 APK 安装包转存到自己的夸克账号再下载：

1. 打开分享链接，选中安装包（97.21M，文件名形如 `ticking_v1.16.9.apk`），点「转存」；
2. 到自己网盘的对应目录里找到它，下载到手机；
3. 下载完成后，在系统通知栏或「下载」目录里点开这个 APK。

装过 MD5 校验工具的话，可以顺手核对一下文件 MD5 是否为上表中的值；不一致说明文件在传输中出了问题，别装，重新下载。

## 三、安装步骤（含「未知来源」授权）

1. 点开 APK，系统提示「出于安全考虑，已禁止安装未知来源应用」时，按提示去开授权；
2. 不同厂商入口不同：小米在「特殊权限 → 安装未知应用」，其他品牌多在「安全 / 更多设置」里，找「安装未知应用」这一项，给浏览器或文件管理器授权；
3. 回到安装界面点「安装」，等进度走完，点「打开」。

## 四、首次启动的权限该开哪些

官方商店公示的权限列表里，与你日常使用直接相关的有这几类：

| 权限 | 什么场景用到 |
| --- | --- |
| 通知 | 计时结束、待办到点提醒 |
| 精确闹钟 | 让提醒准时响，而不是被系统合并延迟 |
| 悬浮窗 | 计时时在屏幕上挂一个小窗，切到别的应用也能看到计时 |
| 拍摄/录音 | 自习室视频打卡这类需要相机或麦克风的场景（以应用内实际功能为准） |
| 设备信息 | 官方权限列表包含获取手机信息（IMEI 等）的权限，多与账号和设备识别相关；隐私政策里有官方说明（见[常见问题与故障排查](常见问题与故障排查.md)第六节） |
| 自启动/后台运行 | 保证计时与提醒在后台不被掐断 |

可以只给你用得到的那几项；悬浮窗权限不给，小窗功能用不了，其余不受影响。

建议先注册或登录账号（自习室、排行榜、跨设备数据都依赖账号），然后按[待办与专注计时怎么用](待办与专注计时怎么用.md)把待办和计时走一遍。安装报错、解析失败、打开闪退这类问题，去[常见问题与故障排查](常见问题与故障排查.md)按现象排查。
