# Ticking 提醒不响时各品牌手机怎么设置

> 待办到点没动静，多半不是应用坏了，是手机把后台掐了。本篇按品牌列出要检查的设置位置，全部改完再测一条提醒。

## 一、先做两步通用检查

1. 通知权限开着：系统「设置 → 应用 → Ticking → 通知」，允许通知；
2. 精确闹钟权限没被关：安卓 12 及以上在「应用信息 → 闹钟和提醒」里单独有一个开关，允许它。

这两步没过，下面的品牌设置全白搭。安卓厂商对后台应用的限制是提醒被吞的主要原因——这也是所有安卓待办类应用共同的坑，不是 Ticking 一家的问题。

## 二、主流品牌设置对照

各品牌杀后台的叫法不同，入口也随系统版本变。下面给的是方向和搜索关键词——在系统设置顶部的搜索框里直接搜更快：

| 品牌 | 要改的地方 |
| --- | --- |
| 小米 | 允许自启动；省电策略改为「无限制」（搜「自启动」「省电策略」） |
| 华为/荣耀 | 启动管理改为手动，允许自启动、关联启动、后台活动（搜「启动管理」） |
| OPPO/一加 | 允许自启动；电池设置里改为「允许完全后台行为」（搜「电池」） |
| vivo | 允许自启动；允许后台高耗电（搜「后台高耗电」） |
| 三星 | 电池 → 后台使用限制，把它移出深度休眠；加入不受监控的应用列表（搜「电池优化」） |

表里的菜单名以你的系统实际显示为准——同品牌不同系统版本叫法也不一样。改完某一项后顺手杀掉应用重新打开，再进下一项。

## 三、改完怎么验证

1. 加一条 2 分钟后的待办；
2. 锁屏放着别动，别亮屏别充电（充电状态下部分机型行为不同）；
3. 到点看有没有响。没响就回第二节查漏项。

最常见的漏项是「一键清理」：把应用从最近任务里划掉等于杀进程，提醒和计时一起断。在最近任务界面的应用卡片上**下拉（或长按）加锁**，清理时就会被跳过——这一步几乎所有品牌都有，只是叫法不同（锁定任务/保护应用/加锁）。

## 四、还是不响

- 勿扰模式开着的话，任何提醒都会被吞，先关掉再测；
- 改完省电设置后重启一次手机再测，部分机型不重启不生效；
- 都试过仍不行，把机型、系统版本和复现步骤通过应用内「反馈」入口报给官方——提醒属于基础功能，值得报。
