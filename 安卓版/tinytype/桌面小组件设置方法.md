## 一、小组件能做什么

tinytype 提供桌面小组件：添加后不用打开 App，从桌面就能直接进入记录，也能在桌面上看到你的日常记录与摘录内容。官方从首发版本起就带这个能力，商店更新日志里提过的两款是「tsuki 的日记」和「老师傅的摘抄本」——分别对应小猫 tsuki 与乌龟老师傅两种风格。

## 二、添加步骤

不同手机桌面的入口叫法略有差别（有的叫「窗口小工具」），流程一致：

1. 在桌面空白处长按，进入桌面编辑状态；
2. 点「添加小组件」（或「窗口小工具」）；
3. 在列表里找到「排版小动物」，列表长的话直接搜索这几个字；
4. 左右滑动挑选你喜欢的组件样式（比如 tsuki 的日记、老师傅的摘抄本）；
5. 按住拖到桌面空白处松手，添加完成。

放到桌面后点组件即可一键开始写，具体从输入到成卡的流程见[卡片排版使用教程.md](卡片排版使用教程.md)。

## 三、找不到小组件怎么办

按顺序排查这几条：

| 现象 | 检查点 |
| --- | --- |
| 列表里搜不到「排版小动物」 | 确认 App 已安装并至少打开过一次；部分桌面只列出已打开过的应用组件 |
| 有入口但添加失败 | 换个桌面位置重试，或重启手机后重新长按添加 |
| 桌面不支持第三方组件 | 个别精简版桌面（如部分第三方启动器）限制小组件，可换系统自带桌面再试 |
| 添加后不显示内容 | 先进 App 正常写一条记录，回到桌面看组件是否刷新 |

如果以上都试过仍不行，多半是你手上这个版本与手机桌面的兼容问题，可以到应用商店看有没有更新版本。

## 四、删掉或更换组件

长按桌面上的组件，选择「移除」即可删除（不影响 App 内的数据）；想换另一种组件样式，重复上面的添加步骤选另一款即可。
