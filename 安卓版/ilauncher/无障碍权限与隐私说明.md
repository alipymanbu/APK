## 一、无障碍权限拿去做什么

无障碍（Accessibility）服务是安卓给辅助功能用的高级权限，能读取你当前打开的应用，并代为执行「返回、回桌面、锁屏」这类系统动作。iLauncher 用它来实现的功能，官方在 Play 商店页面逐条列过：

| 功能 | 依赖无障碍做的事 |
| --- | --- |
| 手势回桌面、最近任务、返回 | 代你执行系统导航动作 |
| 应用内锁屏 | 触发锁屏动作、接管锁屏界面显示 |
| 控制中心 | 呼出与显示面板 |
| 「动画应用」特效 | 监听应用打开，播放切换动画 |

官方页面同时声明：不收集、不共享通过无障碍权限获取的用户信息。开发者另设有[官方隐私政策页](https://sites.google.com/view/launcher-ios-15-privacy-policy/home)，可自行查阅原文。

## 二、除无障碍外还申请了哪些权限

Play 商店披露的权限清单（第三方对商店数据的统计快照，截至 2026 年 8 月，完整清单以商店页实时显示为准）里，除了无障碍，还包括位置、相机、麦克风、联系人、日历、存储等。从功能对应关系看，多数能对上号：

| 权限 | 对应的常见用途 |
| --- | --- |
| 精确 / 大致位置 | 天气小组件报当地天气 |
| 联系人、日历 | 联系人小组件、日历小组件 |
| 相机、闪光灯类控制 | 控制中心里的手电筒、锁屏相机入口 |
| 存储（照片 / 文件） | 照片小组件、换壁纸与自定义图标选图 |
| 显示在其他应用上层（悬浮窗） | 控制中心、锁屏、悬浮快捷入口 |

具体某一项权限在你手机上被用到哪里，以系统弹窗与说明为准；对着上表对不上号的权限，可以在应用权限页里单独关掉试验，小组件或相应功能失效了再打开。

## 三、在哪里查看与收回

1. 无障碍服务：系统「设置 → 无障碍 → 已下载的应用」里能看到 iLauncher 的服务开关，随时可关——关掉后锁屏、控制中心、手势辅助立即失效，其他基础桌面功能不受影响；
2. 普通权限（相机、位置、联系人等）：系统「设置 → 应用 → iLauncher → 权限」里逐项管理；
3. 悬浮窗：同一权限页里的「显示在其他应用上层」开关。

收回权限不会卸载应用，也不动你的桌面布局，随时可以再开回来。功能失效后要恢复的完整步骤见[常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、使用建议

1. 只从官方渠道（Google Play 或你信任的分发渠道）拿安装包，别图省事装来路不明的改包——权限敏感的应用，改包的风险全在安装包本身；
2. 装完先只开无障碍，试控制中心与锁屏是否正常，再按需补其他权限，用不到的功能就不给权限；
3. 若你的系统在无障碍页对该服务显示「有风险」类提示，这是系统对这一类权限的通用提醒，是否继续由你权衡。
