## 一、有哪些小组件

iLauncher 内置了一批 iOS 风格的小组件，官方列出的样式如下：

| 小组件 | 放桌面上的作用 |
| --- | --- |
| 日历 | 看日期与日程入口 |
| 照片 | 把相册选的图摆上桌面，做照片墙 |
| 电池 | 看电量，配低图标风格的桌面很搭 |
| 天气 | 当前天气与预报 |
| 时钟 / 彩色时钟 | 看时间；彩色时钟可以自己配配色 |
| 联系人 | 把常用联系人钉在桌面上，一键拨出 |

同一款小组件可以放多个，比如两个天气组件分别摆在不同屏，每个用不同配色。

## 二、样式怎么自定义

每个小组件都能调背景颜色、字体，部分还能换成自己的背景图。做法是添加后长按该组件进入编辑（或添加时直接选样式），改到和壁纸、图标配色一致为止。官方没有限制同一个桌面能加多少个组件，堆太多会挤占图标位置，一屏一到两个比较合适。

## 三、怎么加到桌面

1. 长按 iLauncher 桌面空白处，进添加（小组件 / Widgets）入口；
2. 从列表里选想要的那款（日历、照片、电池、天气等）；
3. 选样式与尺寸，放到想要的位置；
4. 长按可以拖动或删除，编辑样式同样从长按菜单进。

找不到入口时，先确认当前用的确实是 iLauncher 桌面（按 Home 会回到它），系统自带桌面上加不了这些组件。

## 四、锁屏设置

iLauncher 自带一套 iOS 风格的锁屏外观，官方描述的功能：

- 锁屏支持密码（passcode）与图案锁两种方式；
- 亮屏时显示时间、日期与最近的应用通知；
- 锁屏壁纸可以换成 iOS 风格的图。

开启路径在 iLauncher 设置里的 Lock Screen（锁屏）选项；因为它要接管锁屏显示，依赖「无障碍」权限（官方在 Play 页面把「设置锁屏」列在无障碍的用途里），权限没开时锁屏不会生效。这个权限的来龙去脉见[无障碍权限与隐私说明.md](无障碍权限与隐私说明.md)。

两点提醒：

1. 这套锁屏属于外观层，设备安全仍以系统锁屏为准，系统锁屏请不要关闭；
2. 忘掉 iLauncher 锁屏密码时，可在系统「设置 → 应用」里对 iLauncher 执行「清除数据」后重进，或先把默认桌面换回系统桌面再处理。

## 五、锁屏或通知不显示时

多数情况是无障碍权限被系统省电策略关掉，或 iLauncher 被清理后台。逐项检查的步骤见[常见问题与解决方法.md](常见问题与解决方法.md)。
