## 一、先备齐两端

投电脑需要两样东西同时就位：

1. **手机端 app**：还没装的话，从 [ApowerMirror 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f6a4f26b75c0)拿安装包，步骤见[下载与安装教程.md](下载与安装教程.md)；
2. **电脑端软件**：去[傲软官网](https://www.apowersoft.cn/phone-mirror/)下载 Windows 或 Mac 版，安装后打开，保持前台运行。

两种设备要能互相发现：WiFi 方式要求手机和电脑在**同一个局域网**；USB 方式只要求一根数据线。

想把电脑画面投到手机上（方向反过来），另见[电脑画面投到手机教程.md](电脑画面投到手机教程.md)。

## 二、三种连接方式怎么选

| 方式 | 延迟与流畅度 | 前提条件 | 适合场景 |
| --- | --- | --- | --- |
| WiFi | 取决于网络质量，可能波动 | 同一 WiFi，路由器不隔离设备 | 看视频、演示文档 |
| USB | 最稳、延迟最低 | 数据线 + 打开 USB 调试 | 玩游戏、反控手机、长时间投屏 |
| 扫码 | 同 WiFi | 电脑端显示二维码 | 不想手动选设备时 |

拿不准就用 USB：省去网络变数，反控功能在有线连接下兼容性也更好。

## 三、WiFi 连接（最常用）

1. 手机和电脑连到**同一个 WiFi**（注意路由器若分 2.4G / 5G 两个名字，连同一个名字）；
2. 电脑端保持打开；
3. 手机端点中间的「投屏」按钮，等它扫描；
4. 设备列表里选名字以 **Apowersoft** 开头、后面跟着你电脑名的那一项；
5. 弹出的窗口里选「手机投电脑」；
6. 手机弹出「即将开始截取屏幕内容」的确认框时点「立即开始」（部分系统叫 START NOW），画面就上电脑了。

系统确认框可以勾选「不再提示」，以后每次直接连。

## 四、USB 连接（最稳，玩手游推荐）

USB 方式需要先打开手机的**USB 调试**，一次性设置：

1. 打开 设置 → 关于手机，找到「版本号」，**连续点击 7 次**，提示已进入开发者模式（小米手机是连点「MIUI 版本 / OS 版本」，部分品牌入口在 设置 → 系统 → 关于手机）；
2. 返回 设置 → 系统 → **开发者选项**，打开「USB 调试」；
3. 数据线连接手机和电脑，手机弹出「是否允许 USB 调试」时勾选「一律允许使用这台计算机进行调试」再点确定；
4. 电脑端 ApowerMirror 保持打开，它会自动检测设备并通过 USB 往手机推送配套组件，等几秒即可；
5. 手机端打开 app，弹出提示后点「立即开始」，投屏开始。

连上没反应时：换一根能传数据的线（部分充电线不传数据）、换一个 USB 口，再看[常见问题排查.md](常见问题排查.md)的 USB 一节。

## 五、扫码连接

1. 电脑端点「无线 WiFi 投屏」，找到「本地投屏扫码连接」的二维码；
2. 手机端点右上角的扫一扫图标，扫电脑上的二维码；
3. 手机确认后直接建立连接，不用手动选设备。

## 六、投上之后：电脑反控手机

连上后电脑窗口里有几个常用操作：

- **鼠标点按、拖动**：直接操作手机画面；
- **键盘打字**：在输入框点一下就能用实体键盘打字，回消息、输账号比手机上快得多；
- **全屏**：把手机画面铺满电脑屏幕。

两点提醒：

- 反控模式**第一次要用 USB 连接激活**：USB 连过一次之后，以后用 WiFi 连接也能反控；反控需要安卓 5.0 以上，少部分机型 WiFi 反控无效、仍需 USB；
- 反控、去水印、全屏等属于会员权益，免费版能连能用但有限制，具体见[免费版与会员区别.md](免费版与会员区别.md)；想在电脑上用键鼠玩手游，键位设置见[电脑玩手游键位设置.md](电脑玩手游键位设置.md)。

## 七、声音怎么办

WiFi 投屏时手机的声音默认还在手机上放，电脑端不一定有声音——安卓系统对第三方应用直接获取手机内部的声音有严格限制，这是安卓投屏类工具共同的坎，不是你的操作问题。常见做法：

- 手机外放，电脑只当大屏幕看；
- 电脑端点「开启声音」按钮尝试打开声音（部分机型与连接方式支持）；
- 对声音同步要求高的场景（直播、放视频），用 USB 连接试一次，声画表现通常好于 WiFi。

若电脑端全程无声且上述办法无效，就是当前机型与版本的组合不支持，别再折腾设置，直接手机外放即可。
