## 一、手机搜不到电脑（或电脑搜不到手机）

按顺序查，多数在前两条就能解决：

| 检查项 | 怎么查 | 处理 |
| --- | --- | --- |
| 是否同一网段 | 看手机 WiFi 名与电脑网络名是否一致 | 连到同一个 WiFi；分 2.4G / 5G 名字的路由器连同一个名字 |
| 路由器隔离 | 连对了还是搜不到 | 关闭路由器的「AP 隔离 / 访客网络 / 无线隔离」，或换手机热点试 |
| 电脑端是否在跑 | 看任务栏 | 打开 ApowerMirror 电脑端并保持前台 |
| 防火墙拦截 | Windows 弹过「是否允许访问网络」被点了取消 | 在 Windows 防火墙里允许 ApowerMirror 的专用与公用网络访问 |
| 手机权限 | 附近设备 / 位置权限 | 系统设置里给 app 授权，见[下载与安装教程.md](下载与安装教程.md)第四节 |

手机开热点、电脑连热点的组合也能用，适合路由器不方便改设置的场合。

## 二、点投屏后一直转圈或连接失败

1. 两端 app 都彻底退出重开（手机端从最近任务里划掉再开）；
2. 路由器和光猫断电十秒再上电；
3. 改用 USB 连接兜底，见[连接电脑投屏教程.md](连接电脑投屏教程.md)第四节——有线不经过无线网络，绕开这一类所有问题。

## 三、USB 连接没反应

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 插线毫无动静 | 线只能充电 | 换一根支持数据传输的线 |
| 电脑识别了但投不上 | USB 调试没开或授权没给 | 开发者选项里确认 USB 调试开着，重插一次在手机上点「一律允许」 |
| 电脑端检测不到设备 | 驱动没装好 | 电脑端保持打开重插；换 USB 口（台式机用后置口）；装手机品牌的电脑端助手补驱动 |
| 反复要求授权 | 授权记录失效 | 勾「一律允许」再确定；还不行就撤销 USB 调试授权后重连一次 |

## 四、投屏卡顿、延迟高

按见效程度从高到低：

1. **改 USB 连接**——一次解决大部分卡顿，尤其玩游戏时；
2. **调低投屏清晰度**——电脑端设置里把画质从最高档降一档，网络差时差别明显；
3. **靠近路由器**——隔一堵墙就可能掉到一半速率；
4. **关掉手机和电脑上占带宽的东西**——网盘同步、下载任务、别的设备的视频；
5. 手机开省电模式会降性能，投屏游戏时关掉。

## 五、画面黑屏（声音还正常）

只有个别 app 的画面是黑的、其他都正常——你投的是一个**有版权保护的内容**（视频类 app 的受保护剧集、部分直播、银行类 app）。安卓系统禁止这类内容被截取投出，黑屏是系统层面的限制，所有投屏工具都一样，换任何设置都没用。这是正常现象，不是故障。

## 六、电脑端没有手机的声音

WiFi 投屏时手机声音默认留在手机上播。安卓系统限制第三方应用直接取内部音频，所以无声在无线投屏下很常见：

- 试试电脑端的声音开关按钮（部分机型支持）；
- 改用 USB 连接再试；
- 都不行就手机外放——这不是设置错误，是当前机型与版本组合的能力边界。

## 七、投屏中途自动断开

三个常见原因，按顺序处理：

1. **手机被系统杀后台**——把 ApowerMirror 锁进最近任务（下拉应用卡片点锁图标），或在电池设置里允许它「无限制后台运行」，各品牌入口叫法不同（华为启动管理、小米省电策略）；
2. **息屏断投**——投屏期间把手机息屏时间调长，或设置里关闭投屏时息屏；
3. **WiFi 休眠**——开发者选项或 WLAN 高级设置里把「休眠时保持 WLAN 连接」设为始终。

## 八、反控手机点不动

- 先确认连接方式：部分机型 WiFi 反控无效，**改 USB 连接**是第一招；另外反控模式第一次要用 USB 连接激活，USB 连过一次后 WiFi 才能反控；
- 反控属于会员权益，免费版有限制，对照[免费版与会员区别.md](免费版与会员区别.md)确认当前权益；
- 个别深度定制系统的机型反控兼容性差，属机型限制，官方也标注了「少部分机型可能无法实现 WiFi 反控」；
- 键鼠能动了、想在游戏里自定义键位，见[电脑玩手游键位设置.md](电脑玩手游键位设置.md)。
