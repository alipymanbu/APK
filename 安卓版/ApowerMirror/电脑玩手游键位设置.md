## 一、前提：把反控链路打通

- 先把手机投屏到电脑（没连上的按[连接电脑投屏教程.md](连接电脑投屏教程.md)操作）；游戏键盘只对安卓手机有效；
- 反控需要安卓 5.0 以上系统；
- **第一次用游戏键盘要走 USB 连接**：USB 连成功过一次后，之后改用 WiFi 连接也能继续用；
- 小米 / 红米机型除了普通 USB 调试，还要在开发者选项里把「USB 调试（安全设置）」一并打开，否则键鼠操作进不了游戏——这是大量用户实测汇总出的坑，官方文档没有单列，卡在这一步的先查这里。

## 二、默认键位：先下载，再自己改

1. 投屏连上后，在手机上打开游戏（吃鸡类会自动触发）；
2. 电脑端弹出「是否下载默认键位」时点「立即下载」；
3. 键位浮层出现在投屏画面上，位置对应游戏里的按钮；
4. 觉得不顺手就点工具栏的「游戏键盘」按钮自己改，改完**点保存**才生效。

官方给出的吃鸡类默认键位（同类游戏大同小异）：

| 键 | 动作 | 键 | 动作 |
| --- | --- | --- | --- |
| 鼠标左键 | 射击 | M | 地图 |
| 鼠标右键 | 开镜 | ~ | 进入瞄准模式 |
| WASD | 移动 | 1 / 2 | 换武器 |
| Shift | 奔跑 | 3 / 4 / 5 / 6 | 药品、手雷 |
| 空格 | 跳跃 | F | 拾取 |
| C | 蹲下 | Q / E | 左右侧身 |
| Z | 趴下 | V | 开关门 |
| R | 换弹 | Tab | 背包 |
| X | 切第一 / 第三人称 | Alt + 鼠标移动 | 自由视角 |

## 三、四类控件怎么摆

点工具栏「游戏键盘」进编辑界面，共九个按钮（删除、刷新、保存、帮助、关闭加四个控件），日常只动这四个：

| 控件 | 拖到哪里 | 绑定之后 |
| --- | --- | --- |
| 摇杆 | 游戏的移动区域 | 默认 WASD 走位；圆圈大小要拖到与游戏摇杆热区吻合，不然会出现划了不动 |
| 按键 | 任意按钮位置 | 输入一个键，按下就等于点那个位置 |
| 瞄准 | FPS 游戏的瞄准区域 | 鼠标控制视角，默认按 ~ 开关；旁边数字改水平 / 垂直灵敏度 |
| 射击 | 开火按钮 | 鼠标左键开火 |

摆完点保存。键位浮层挡视线的话，点「游戏键盘」按钮旁的小箭头，把透明度在 0 到 100 之间调低。

## 四、常见小毛病

| 现象 | 处理 |
| --- | --- |
| 工具栏找不到「游戏键盘」 | 这次的连接没经过 USB。先用 USB 连一次激活，之后 WiFi 也能用 |
| 默认键位一直下载失败 | 官方给的办法：在电脑文件管理器地址栏输入 `%appdata%/apowersoft`，进 ApowerMirror 文件夹删掉 `DefaultGameKeyboard` 与 `GameKeyboard` 两个文件，重启软件重连 |
| 瞄准控件和摇杆打架 | 把瞄准控件挪到屏幕右侧空白区域再保存 |
| 绑好的按键没反应 | 确认改完点了保存；小米机型查「USB 调试（安全设置）」 |

## 五、两个边界

- **iOS 用不了**：苹果设备只能镜像画面到电脑，官方明确暂不支持从电脑反控 iPhone，游戏键盘与 iPhone 无关；
- **自定义键位是会员权益**：免费版只能用固定键位，想按自己习惯改键对照[免费版与会员区别.md](免费版与会员区别.md)确认权益；连不上、投上没反应这类问题归[常见问题排查.md](常见问题排查.md)管。
