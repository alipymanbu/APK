# ProxyPin HTTPS 抓包证书配置

> 只装 ProxyPin 本体抓不到 HTTPS 明文 —— 还要把它的根证书装进系统。本篇按安卓手机的实际情况讲证书怎么装、装完什么能看、什么看不了。

## 一、为什么要装证书

HTTP 请求不加密，装不装证书都看得到内容；HTTPS 内容是密文，不装证书时你只能看到「连了哪个域名」，看不到请求与响应的具体内容。装上 ProxyPin 的根证书并启用 HTTPS 代理后，ProxyPin 才能解开这些流量 —— 证书本质上是你授权它解密的凭据，所以这一步只能你自己亲手做。

## 二、安装根证书的步骤

不同版本的入口名称略有差异，大致路径如下（以你手上的版本界面为准）：

1. 打开 ProxyPin，点右上角的「⋮」菜单；
2. 进入 **HTTPS 代理**；
3. 打开 **启用 HTTPS 代理** 开关；
4. 点 **安装根证书**，选择下载证书；
5. 系统弹出证书安装界面（不同厂商叫法不同：安装证书 / CA 证书 / 从存储设备安装），确认后完成。

装完回到首页点右下角的启动按钮开始抓包，HTTPS 请求应能看到具体内容。

## 三、用户证书的局限：为什么有些 App 还是看不了

安卓 7.0 起，普通应用默认**只信任系统证书，不信任用户证书**。按上面步骤装的是用户证书，所以结果是：

- 浏览器网页的 HTTPS：能看到明文；
- 多数 App 的接口请求：内容看不了，甚至连接直接失败 —— 这是系统安全机制，不是你装错了。

未 root 的设备没有把用户证书升级成系统证书的官方途径，这一步绕不开系统设定。

## 四、证书锁定（SSL Pinning）是另一道墙

有些应用除了不信任用户证书，还在代码里写死「只认自家服务器的证书」（证书锁定 / SSL Pinning）。这类应用即使你把 ProxyPin 证书装成系统证书也解不了 —— 校验不通过时连接被应用自己掐断。银行、支付类与大厂核心应用普遍有这层防护，抓它们时通常只会看到连接建立又立刻断开。

## 五、已 root 设备可以装系统证书

设备已 root 的话，可以把 ProxyPin 根证书放进系统证书目录，让所有应用默认信任它。作者另外维护了一个 Magisk 模块（[gitee.com/wanghongenpin/Magisk-ProxyPinCA](https://gitee.com/wanghongenpin/Magisk-ProxyPinCA)），装完重启生效，具体用法以该模块页面为准。没有 root 就保持用户证书，并按第三节的局限来设定预期。

## 六、怎么确认证书装好了

1. 手机浏览器打开任意 HTTPS 网页，回 ProxyPin 看该请求：能看到完整内容 = 证书链路通了；
2. 网页打得开但列表里仍是密文或显示握手失败 → 回第二节确认「启用 HTTPS 代理」是否打开；
3. 部分系统装证书后会要求先设锁屏密码，按提示设置即可。
