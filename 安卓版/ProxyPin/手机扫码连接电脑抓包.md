# ProxyPin 手机扫码连接电脑抓包

> 手机流量想在电脑大屏上看？ProxyPin 的扫码连接能让手机与电脑互相配对，不用手动改 Wi-Fi 代理、不用抄 IP 和端口。

## 一、什么场景值得这么连

- 手机上操作 App、电脑上同时看请求：屏幕大，复制粘贴、展开长 JSON 都省事；
- 排查「只在手机上出问题」的请求：你在手机上复现动作，在电脑上看细节。

只需要抓手机自身流量的话，跳过本篇，单机模式就够了。

## 二、准备两样东西

1. **电脑装桌面版**：Windows / Mac / Linux 安装包在[官方发布页](https://github.com/wanghongenpin/proxypin/releases)下载，国内也可以走 [Gitee 镜像](https://gitee.com/wanghongenpin/proxypin/releases)；
2. **两台设备在同一局域网**：连同一个 Wi-Fi；电脑插网线、手机连 Wi-Fi 也算同一网络。不在同一网络时扫不上。

## 三、连接步骤

1. 电脑端打开 ProxyPin，找到扫码连接入口（不同版本位置略有差异，认准「扫码连接」字样），界面会显示一个二维码；
2. 手机端打开 ProxyPin，用扫码连接功能去扫这个码；
3. 扫码成功后，代理与证书等配置会自动同步，手机里发起的请求会出现在电脑端列表里。

连接是双向的：所有终端都可以互相扫码连接、转发流量，你也可以反过来从电脑发起配对。

## 四、扫不上或连上没流量时先查这五项

1. 两台设备是否真的在同一网段（不少公司 / 酒店网络对访客设备做了隔离，换手机热点试）；
2. 电脑防火墙是否拦了 ProxyPin 的端口；
3. 手机端抓包开关是否处于启动状态；
4. 手机端证书装了没有 —— 没装证书时 HTTPS 请求只有域名没有内容，配置步骤见 [HTTPS抓包证书配置.md](HTTPS抓包证书配置.md)；
5. 都不行还可以走手动配置的老路：手机 Wi-Fi 的高级设置里手动配 HTTP 代理，主机名填电脑的局域网 IP、端口填 ProxyPin 的代理端口（在电脑端设置里看；这是传统抓包工具的通用做法）。手动只解决「连上」，证书与 HTTPS 代理开关仍要按证书配置篇来，用完记得把手机的 Wi-Fi 代理改回「关闭」。
