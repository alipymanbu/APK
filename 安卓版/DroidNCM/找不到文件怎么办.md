# 提示「找不到文件」的排查方法

> 扫描或选择文件时提示没有找到文件，按权限、路径、文件状态三步排查，多数两分钟内能解决。

## 一、先分清是哪种情况

「找不到文件」通常出现在两种时刻：点信封按钮扫描后列表为空，或手动选择时文件管理器里看不到目标文件。两种情况的根源几乎都出在三处——权限没给够、路径找错了、文件本身不完整。按下面的顺序查，每查完一步就回应用里重试一次。

## 二、第一步：查权限

这是出现频率最高的原因，尤其是刚装完或刚升级过系统之后。

1. 打开手机「设置 → 应用管理 → DroidNCM → 权限」。
2. 把「存储」或「文件和媒体」设为允许；安卓 13 及以上版本留意「音乐和音频」这一项，也要允许。
3. 完全退出应用（从最近任务里划掉）再重新打开。

补充两点：

- 3.1 版的第三方收录说明里提到修复了 Android 13 上的扫描权限异常，如果你的系统是 Android 13 且权限已开却仍然扫不到，先确认版本号，旧版本就换新版安装包再试。
- 文件存在 SD 卡上的机型，除了存储权限还需要在系统里单独允许访问 SD 卡，部分机型要在权限页手动展开选择。

## 三、第二步：查路径

权限没问题还找不到，就是路径的事：

| 现象 | 处理办法 |
| --- | --- |
| 扫描结果为空 | 用文件管理器全局搜索 `.ncm`，确认文件真实存在；存在但扫描不到就改用「选择文件」手动导航到该目录 |
| 文件管理器里也搜不到 | 到网易云「设置 → 下载目录」核对真实存储位置，可能不在你预想的目录 |
| 能看到文件但列表是灰的或不显示 | 文件管理器里开启「显示隐藏文件」再看一次 |
| 文件在 SD 卡 / U 盘 | 先把文件复制到内部存储（如 `Download` 目录）再选，绕开外部存储的访问限制 |

网易云的缓存文件分散在多个子目录的情况也常见，别只翻一个文件夹，直接全局搜索最省事。各目录的含义见 [ncm文件在哪里.md](ncm文件在哪里.md)。

## 四、第三步：查文件本身

前两步都正常，问题可能出在文件上：

1. **文件被占用**：网易云还在后台挂着时会锁定自己的缓存文件，从最近任务里把网易云划掉，再回 DroidNCM 重试。
2. **只是缓存不是完整下载**：试听缓存转出来会失败或内容残缺，回网易云对目标歌曲重新执行「下载」，生成完整 NCM 后再转。
3. **文件损坏**：下载过程中断网或中途取消，会留下不完整的文件。删掉重新下载；如果同一首歌反复失败，换个网络环境再下。

## 五、三步都走完还是不行

按这个顺序再试：

1. 重启手机（清掉所有文件锁与权限缓存），打开应用重试。
2. 把 NCM 文件手动复制到 `Download` 目录，用「选择文件」从那里选。
3. 卸载重装应用，安装与首次授权的完整流程见 [下载与安装教程.md](下载与安装教程.md)，注意装完第一次就把权限给足。

都不行的话，换一台安卓设备装上同一个安装包试试：换了设备能正常扫描，说明是原设备的系统限制（部分深度定制系统的权限管理更严格）；换了设备也不行，那就要回头检查 NCM 文件本身了。

顺带分清两类问题：本篇讲的是**文件还没进应用**（扫描不到、列表为空）；如果文件选得上、转换也点了，但结果报错或输出打不开，那是转换环节的事，处理办法在 [转换失败与输出异常.md](转换失败与输出异常.md)。
