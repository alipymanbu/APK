## 一、先弄清楚：这套东西是两半

SoundWireFree 要两个东西配合才能出声：手机上的 SoundWireFree 客户端（就是网盘里这份安装包），和电脑上的 SoundWire Server（不在安装包里，要去官方页面单独下）。电脑负责抓走系统正在播的声音，手机连着同一张网络把它收下来播放——你的手机就此变成一副无线耳机或一只无线音箱。

它只传音频、不传画面。电脑上放什么，手机就听到什么，用哪个播放器都行。这也意味着播出位置和来源无关：网页、本地播放器、游戏声音，抓的是系统输出。

动手之前先确认手上这份包对不对：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | SoundWireFree |
| 包名 | com.georgie.SoundWireFree.kbinstaller |
| 版本号 | 3.2 |
| 安装包大小 | 5.61 MB（5,880,404 字节） |
| 安装包 MD5 | 4941B12A64F3529271AC9DDAF79AAA40 |
| 适用设备 | 安卓手机、安卓平板；电脑端另装 Server |
| 网络要求 | 手机与电脑要能互相访问（同一 WiFi 最省事） |

版本号只认上面这一个。搜出来的版本号大多是官方当前最新版，和这一份未必是同一版；判断装对没装对，看包名 `com.georgie.SoundWireFree.kbinstaller` 和版本号 3.2 这两项就够了。

**关于最低系统版本**：这份包的记录里把运行要求写成「安卓系统 5.2 以上」，但安卓官方版本序列里并没有 5.2 这个号，这条多半是转述误差。最省事的判断办法是直接装：系统不兼容会当场拦下来（提示「应用与你的设备不兼容」），不会装到一半坏掉。

## 二、把手机端安装包取到手机

1. 在手机上打开 [SoundWireFree 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1678b8c7942c)。建议用夸克 App 打开，手机浏览器下大文件容易被切到后台打断。
2. 点「保存到我的网盘」转存一份。转存之后，下载就不再依赖原分享链接还在不在。
3. 进自己的网盘找到它，点下载，等文件落到手机存储里。
4. 下完核对两件事：文件名结尾是 `.apk`（这一份形如 `SoundWireFree_v3.2.apk`），大小 5.61 MB 左右。差得多的多半是没下完整，删掉重来。

习惯在电脑上操作的，可以电脑端网盘下载好再拷到手机的 `Download` 目录，效果一样。手上有校验工具的话，顺手算一遍 MD5 和上表比对：一致说明传输过程没错，不一致就重下一遍。不查也不影响安装，只是多一层保险。

## 三、安装手机端

这一份是从网盘手动装的，不是在应用商店里点的「安装」，所以点安装包时系统会拦一次，提示「不允许安装来自此来源的应用」之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开「文件管理」，进 `Download` 目录，找到刚下好的 apk，点它。
2. 出现拦截提示时点提示里的「设置」，打开**允许安装此来源的应用**开关。部分机型要去「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，单独给刚才打开文件的那个 App 放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」，等电脑端也准备好再一起试。

首次连接时系统可能索要网络权限（部分机型还会问通知、后台运行白名单），网络相关的要允许，不给的话连不上服务器。

## 四、电脑端装 SoundWire Server

Server 只从官方页面取，地址是 `https://georgielabs.net/`。官方在页面上专门注明：只从该站点或它直接链接的地址下载。按你电脑的系统选对应文件：

| 电脑系统 | 官方页面对应的版本 |
| --- | --- |
| Windows 7 / 8 / 10 / 11 | Windows 版安装包（2.5） |
| Windows XP | XP 专用安装包 |
| Linux 64 位 | 64 位版（3.0，Qt5 界面） |
| Linux 32 位 | 32 位版（2.1.2，Qt4） |
| 树莓派 32 / 64 位 | 树莓派版（3.1 与 2.1.2 都在包里） |

Windows 版下载下来是个压缩包，解压后运行里面的安装程序。**安装过程中系统会弹一次防火墙提示，必须选「允许访问」，并且把专用网络和公用网络都勾上**——这一步跳过，手机永远连不上。Linux 版也是压缩包，解压后按包内 `README.txt` 的说明操作。

装完先让它跑起来：

1. 电脑上先随便放点有声音的内容（音乐、视频、网页都行），别让它静着。
2. 打开 SoundWire Server，选音频输入源。Windows 7/8/10/11 上默认设置通常就能抓到系统正在播的声音（默认多媒体设备）；Windows XP 要选 `Stereo Mix`、`Wave Out Mix`、`What U Hear` 这类名称的输入。
3. 看服务器窗口上的电平表。有声音在播时它应该跟着跳动——这是「声音真的被抓到了」的唯一凭据。电平表不动就先解决输入源，别急着去弄手机。

## 五、第一次连接

1. 手机打开 SoundWireFree，屏幕上是一根盘起来的电线，它就是连接按钮。
2. **地址框先留空**再点那根电线：留空时它会自动在局域网里找服务器。连上后电线会亮起来，电脑端窗口的状态会变成 `Connected`。
3. 自动定位没成功、或你家里不止一台服务器时，改成手动填地址：电脑端窗口左上角显示的就是服务器地址（形如 `192.168.1.201`），鼠标悬停上去还能看到其他候选地址。把它填进手机端的地址框，再点电线。
4. 电脑端地址框旁边有个三角按钮，能翻出最近用过的 4 个服务器地址（长按可清空）。家里地址常变的，这个比每次重填省事。

## 六、装完先确认这三件事

不用急着听完一整张专辑，先花一分钟确认：

1. **电脑端电平表在跳**：说明声音被正确抓取。不跳就回到第四节第 2 步重选输入源。
2. **电脑端状态是 `Connected`、手机端电线是亮的**：说明网络这一层通了。不通看 [手机连不上电脑怎么排查.md](手机连不上电脑怎么排查.md)。
3. **声音从手机里出来**：放一段有人声的内容最容易听出来。有声音但发闷、断断续续，或声音比画面慢半拍，看 [音频延迟与卡顿怎么调.md](音频延迟与卡顿怎么调.md)。

这三步都过了，就可以正常用。想再调音色和低音，见 [均衡器与音质怎么设置.md](均衡器与音质怎么设置.md)；用起来发现界面上有广告、压缩选项只顶一小会儿，那是免费版的正常限制，差别写在 [免费版和完整版差在哪.md](免费版和完整版差在哪.md)。

## 七、升级与卸载

- **升级**：手机端直接装新包覆盖即可，一般不用先卸载。新版本可能增删设置项或改默认值，装完顺手核对一下缓冲大小和压缩这两个开关。
- **卸载**：手机端卸载后就断了；电脑端 Server 不必一起卸，留着不影响别的东西，下次装回来用同样的地址重连即可。
- **安装包删了**：随时回到文首那条 SoundWireFree 安装文件资源的链接重新取一份；已经转存过的，不受原分享是否有效的影响。
