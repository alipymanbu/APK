# SoundWireFree 手机连不上电脑怎么排查

> 连不上、连上了没声音、听一会儿就断，是三种不同的毛病，排查顺序也不一样。本篇按「先电脑抓音、再网络、最后地址与防火墙」逐层排除，每一步都给出判断依据。

## 一、先分清卡在哪一层

连不上的原因几乎总能归到三段链路里的一段：电脑没抓到声音、两台设备不在同一张网、或者地址与防火墙把连接挡住了。本篇把这三段按顺序拆开，每段给你一个能当场验证的判断依据，省得在无关的地方反复折腾。

先按这张表对号入座，再跳到你该看的那一节，别一上来就重装应用。

| 现象 | 坏在哪一层 | 去看 |
| --- | --- | --- |
| 电脑端电平表不动 | 电脑没抓到声音 | 第二节 |
| 电平表在跳，手机点电线没反应 | 网络或地址 | 第三、四节 |
| 电脑端状态显示连接失败 | 地址不对或被防火墙挡了 | 第四节 |
| 连上就有声，过一会儿自己断 | 链路稳定性 | 第五节 |

## 二、第一层：电脑端到底抓到声音没有

**电平表不动 = 后面全都白搭。** 这一层不通，手机端不管怎么点都不会有声。

1. 先在电脑上确认声音真的在出：播放器没静音、系统音量不是 0、输出设备选对了。笔记本插了耳机却还在外放、或者声音被路由到显示器，这两种情况很常见。
2. 看服务器窗口的输入源选项。Windows 7/8/10/11 上选默认多媒体设备通常就对；Windows XP 得选 `Stereo Mix`、`Wave Out Mix`、`What U Hear` 这类名字的输入设备（有些声卡驱动默认把它藏起来了，要在系统的录音设备列表里先把它显示出来）。
3. 如果服务器报出类似「unable to activate audio device」（无法启用音频设备）这样的错，同时电平表也不动，那就是输入源没选成功——**换一个能用的音频输入之前，连接会一直失败**。这不是网络问题，反复重连没有意义。
4. 在 Windows XP 这类老系统上，如果 `Stereo Mix` 这类输入**怎么都调不出来**，那不是设置问题，是声卡硬件本身不支持回采播放端的声音（官方帮助里专门列了这一条）。先试把系统的录音设备列表打开「显示已禁用的设备」，看它是不是只是被禁用了；确实没有这个设备，就用一根两头都是 3.5mm 立体声插头的短线，把电脑的音频输出口与输入口对接，然后在服务器里把输入源改成 `Line In`（线路输入）或 `Microphone`。

判断依据很简单：电平表随声音跳，这一层就算过了，剩下的问题都在网络和手机侧。

## 三、第二层：两台设备在不在同一张网里

自动定位靠的是局域网内的互发现，两台设备必须在能互相访问的同一段网络里。

- **手机开着流量**：自动定位找不到电脑，这是最常见的「连不上」。把手机连到和电脑同一个 WiFi，再试一次。
- **访客网络**：很多路由器把访客 WiFi 隔离了，同一台路由器下也互相看不见。把手机换到主网络。
- **AP 隔离 / 客户端隔离**：部分路由器和公共 WiFi 默认开启，同一 WiFi 内的设备也不能互访。要连上就得关掉这个开关，或改用下面的手动填地址 + 端口可达的方案。
- **VPN**：手机或电脑任一端开着 VPN，流量被改道，自动定位基本失效。排查时先把两端 VPN 都关掉。
- **虚拟机虚拟网卡**：电脑上装过 VirtualBox、VMware 时会多出虚拟网络适配器，它会干扰自动定位，即使虚拟机没在运行也一样。官方给的办法是在系统的「网络连接」里把「VirtualBox Host-Only Network」这类虚拟网卡停用。WSL2 的虚拟网卡也有类似影响。

跨网络用（比如手机在外地、电脑在家）不是不行，官方说明这套东西也支持走 3G / 4G / 5G 和 WAN，但那要自己解决两端网络可达的问题，配置难度和局域网不是一个量级。先用同一 WiFi 把流程跑通，再考虑这种情况。

## 四、第三层：地址对不上，或防火墙挡着

网络在同一张网里之后，还卡着就查这两样。

**地址。** 自动定位失败时最省事的做法是手动填：

1. 看电脑端 SoundWire Server 窗口**左上角**显示的地址，形如 `192.168.1.201`。鼠标悬停能看到其他候选地址——一台电脑装了多个网卡（有线、无线、虚拟网卡）时列出的地址不止一个，**别照着错的填**。
2. 在电脑上打开命令提示符，运行：

```
ipconfig
```

在输出里找当前正在用的那块网卡的 IPv4 地址，和服务器窗口显示的对一下。两边不一致就以实际在用的那块网卡为准。

3. 把地址填进手机端界面上的服务器地址框，再点那根电线。地址框默认只弹数字键盘，如果你要用的是主机名而不是 IP，需要先在设置里打开「Enter alpha server name」才能输字母。
4. 家里有不止一台服务器时，电脑端地址框旁边的三角按钮能翻出最近用过的 4 个地址，直接选比手输稳。

**防火墙。** Windows 自带防火墙如果没放行，包在局域网里就是进不来，手机端表现和「连不上」一模一样。

- 安装时那次弹窗如果点了「取消」，或者只勾了专用网络却没勾公用网络，都要补：在 Windows 防火墙的「允许应用通过防火墙」列表里找到 SoundWire Server，把专用和公网两项都勾上。
- 列表里找不到它，就手动添加程序，选中它安装目录下的可执行文件。
- 换了网络环境（比如从家里搬到办公室）后 Windows 会重新判定网络类型，防火墙规则可能重新拦一次，同一个现象要重新查一遍这里。

**端口要不要单独放行？** 服务器端口可以在 Server 的高级设置里改，说明它并不是写死的一个值。网上有资料把默认端口写成 UDP 59010 / 59011，官方帮助页面里没有给出固定端口号，所以按端口去放行并不可靠。**把 SoundWire Server 这个程序整体放行，比按端口放行稳。**

## 五、连上了又断

能连、能听，但过一段时间自己断，属于链路稳定性问题，不是配置错。

1. 先分清是谁断的：断的瞬间看电脑端状态是不是从 `Connected` 变了、电平表是否还在跳。电平表还在跳而手机没声，是无线侧的问题（转 [音频延迟与卡顿怎么调.md](音频延迟与卡顿怎么调.md) 调缓冲与压缩）；两边状态都掉了，看下一条。
2. 打开设置里的 **Auto reconnect**（自动重连）：连接断开后它会持续尝试重连，弱网下很有用。注意官方特意提醒——开了这个选项，用完一定要正常退出应用或手动断开，否则手机会一直保持唤醒状态耗电。
3. 打开 **Connect on start**（启动即连接）：应用一启动就按上次的地址连上，省得每次手动点。
4. 路由器长时间运行后性能下降是常见原因，官方在排查卡顿时给的第一条建议就是**重启无线路由器**。听之前重启一次，比在应用里反复换参数有效。

## 六、怀疑安装包本身有问题时

上面三层都排干净了还是不工作，才轮到怀疑手机端这份安装包：下载不完整、装的是别的版本、或安装过程被中断。这时候按 [下载与安装教程.md](下载与安装教程.md) 里的清单核对包名和版本号（这一份是版本 3.2、包名 `com.georgie.SoundWireFree.kbinstaller`），对不上就用 [SoundWireFree 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1678b8c7942c) 重新取一份装上。

**先别再重复「卸载重装」这一步。** 连不上的绝大多数原因在电脑端抓音、网络隔离或防火墙，这三处不改，重装多少遍结果都一样。

## 七、一页速查

| 现象 | 最可能的原因 | 先试什么 |
| --- | --- | --- |
| 电平表不跳，手机没反应 | 电脑没抓到声音 / 输入源选错 | 重新选音频输入，确认电脑本身在出声 |
| 电平表在跳，手机点电线没反应 | 两台设备不在同一网络 | 手机连到和电脑同一个 WiFi，关掉 VPN |
| 一直搜不到服务器 | 自动定位被打断 | 手动填电脑端左上角的地址 |
| 填了地址还是连不上 | 防火墙没放行 | 在防火墙里放行 SoundWire Server，勾专用与公网 |
| 换了网就失效 | 网络类型变了、规则重新拦 | 重新确认地址与防火墙放行 |
| 听一会儿自己断 | 链路不稳、路由器状态差 | 重启路由器，打开 Auto reconnect |
