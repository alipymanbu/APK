# Phonto 字体导入方法：把 TTF、OTF 装进应用

> Phonto 自带两百多种字体，但中文样式有限，想用自己下载的字体就得走导入这一步。本篇按官方给出的流程，讲清楚怎么把字体文件装进应用、装完去哪找。

## 一、先分清两个入口

- **内置字体**：应用自带两百多种，点选文字后进字体列表就能逐个试，这部分不用任何设置；
- **My Fonts**：你自己导入的字体全部归到这里。导入成功后，字体列表里会出现这一栏，选中文字后在里面切换。

换句话说，字体列表里看到的不满意时，走下面的导入流程往 My Fonts 里补。

## 二、导入前确认两件事

1. **格式**：Phonto 接受 `.ttf` 和 `.otf` 两种字体文件，`.zip` 压缩包也能直接打开；其他格式（比如某些网站只在电脑上用的字体安装包）要先转成这几种；
2. **许可**：官方页面上专门提醒过 —— 装之前看一眼字体的授权说明。网上搜「FREE FONTS」能找到大量免费字体站，但「免费下载」不等于「任何用途都可用」，商用场景尤其要确认授权范围。

## 三、导入只需要两步

官方给的流程很直接，不需要连接电脑：

1. **拿到字体文件**：用浏览器搜索「FREE FONTS」之类的关键词，挑一个字体站下载你想要的字体，下载完成后通知栏里会出现文件名（`.zip` 或 `.ttf` 结尾）；
2. **在 Phonto 里打开它**：点通知栏里的文件（或在文件管理器里找到它，选「用其他应用打开」再选 Phonto），跳进应用后会弹出一个 Install 按钮，点它。

装好的字体会出现在 **My Fonts** 里，之后选中任何一段文字，都能在字体列表里切换到它。

## 四、点不开字体文件时

- **压缩包打不开**：个别 `.zip` 的打开方式没有被系统认出来，先在文件管理器里手动解压出里面的 `.ttf` 文件，再对它走一遍上面的第二步；
- **列表里找不到「用其他应用打开」**：长按文件选「打开方式」，手动指定 Phonto；
- **装了但列表里没有**：把 Phonto 彻底关掉再重新打开一次，My Fonts 里一般就出现了；还是没有的话，检查文件是不是真的 `.ttf`/`.otf`，见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 五、装好之后怎么用

字体只是样式的一部分。选中文字后，同一个样式面板里还能调颜色、描边、阴影、字距等十几项，各选项的位置与效果见 [文字样式与特效设置.md](文字样式与特效设置.md)；只想快速走通「选图加字保存」的完整流程，翻回 [基础操作入门.md](基础操作入门.md)。

## 六、中文字体怎么办

- **内置字体里中文样式很少**：自带的两百多种以拉丁字体为主，能正常显示中文的不多，这是长期使用者的普遍反馈，也是「导入字体」对这个应用格外重要的原因；
- **判断一个字体支不支持中文**：选中文字切到该字体，中文变成了方框（□）就说明这个字库不含中文字形 —— 字体本身没坏，它只是没画这些字，换一个就是；
- **去哪找中文字库**：搜「开源中文字体」，思源黑体、Noto Sans CJK 这类覆盖完整的字库都可以，下载 `.ttf` / `.otf` 后按第三节的流程走一遍；
- **文件偏大是正常的**：中文字库动辄几千个字，几 MB 到十几 MB 的 `.ttf` 都常见，别当成下载出错。
