# Mimico 在电脑上用模拟器运行

> Mimico 没有官方电脑版，本篇讲怎么用安卓模拟器把网盘里这份 APK 跑在电脑上，以及模拟器里使用时会碰到的四个具体问题。

官方只发布手机端应用，iOS 与 Android 两端，**没有 Windows 或 macOS 版**。想在电脑上用只有一个办法：装一个安卓模拟器，把手机端那份 APK 装进模拟器里跑。这条路可行，但登录、麦克风、性能这三处会比手机麻烦，本篇把它们提前说清楚。

## 一、电脑要满足什么条件

模拟器本质是一台跑在电脑里的安卓设备，所以吃的是本机资源：

| 项目 | 建议值 | 达不到会怎样 |
| --- | --- | --- |
| 系统 | 64 位 Windows 10 及以上（或较新的 macOS） | 装了也起不来 |
| CPU 虚拟化 | 在 BIOS 里开启 VT-x / AMD-V | 模拟器极卡或直接报错，最常见的一处坑 |
| 内存 | 8 GB 以上，给模拟器分 4 GB | 聊天界面滑动掉帧 |
| 磁盘 | 留出 10 GB 以上 | 装到一半失败 |
| 显卡 | 集显可用，有独显更稳 | 界面花屏 |

**先确认虚拟化是否已开**：任务管理器 → 性能 → CPU，看右下角「虚拟化」是否显示「已启用」。显示「已禁用」就要进 BIOS 打开，不同主板按键不同，一般在 Advanced 或 CPU Configuration 里。

## 二、选一个模拟器

主流几款（雷电、MuMu、BlueStacks、夜神等）通常都能把这份 APK 跑起来，但有两条要挑：

- **要带 Google 服务框架（GApps）**。Mimico 的登录走 Google 账号，模拟器不带 GApps 时，登录那一步会直接卡在授权页，见 [登录与账号设置.md](登录与账号设置.md) 第二节。装之前先在模拟器的应用列表里确认有 Google 相关的预装项。
- **要能改分辨率**。竖屏手机比例（如 720×1280）比横屏平板比例更接近手机上的显示效果。

## 三、把 APK 装进模拟器

1. 先在电脑上把安装文件取下来：点开 [Mimico 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cfaf009578a1)，转存后下载到本地（手机端也能存，用夸克 App 转存到自己的网盘再在电脑端下载）；
2. 核对体积约 27.26 MB，具体口径见 [下载与安装教程.md](下载与安装教程.md) 第一节；
3. 打开模拟器，**把 APK 文件直接拖进模拟器窗口**，多数模拟器会自动识别并安装；
4. 拖拽不生效时用共享目录：在模拟器的文件共享设置里指定电脑上的一个文件夹，再从模拟器内的文件管理器里打开那个 APK；
5. 也可以走命令行安装——模拟器安装目录下带 `adb`，SDK 侧的完整路径以实际安装位置为准：

```cmd
adb connect 127.0.0.1:5555
adb install -r Mimico_v2.4.74.apk
```

`-r` 表示覆盖安装，模拟器里已有旧版时用它免去先卸载一步。文件名随版本变化，以实际拿到的为准。

## 四、模拟器里用 Mimico 的四个注意点

| 注意点 | 具体表现 | 怎么处理 |
| --- | --- | --- |
| Google 登录走不通 | 点登录没反应，或授权页一片空白 | 换带 GApps 的模拟器镜像；实在不行就留在访客态用 |
| 麦克风没声音 | 语音输入点了没反应 | 模拟器里给 Mimico 开麦克风权限，同时确认电脑侧允许模拟器访问麦克风 |
| 电脑端听不到角色说话 | 角色回了文字但不出声 | 检查电脑媒体音量与模拟器的音频输出设置；蓝牙耳机连着时特别容易走错输出 |
| 长时间挂机被清 | 切到别的程序后回来要重新加载 | 模拟器设置里调大可用内存，别同时开太多大程序 |

模拟器上跑移动应用还有一条通病值得知道：**它通常拿不到手机上的那套系统级推送**，应用在后台时的提醒多半收不到。想在手机端收角色主动发来的消息，要回手机端检查系统的通知权限，做法见 [常见问题与排查.md](常见问题与排查.md) 第六节。

## 五、模拟器相关的常见报错

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 模拟器启动报「VT-x 未开启」 | BIOS 里虚拟化没开，或被 Hyper-V 占用 | 进 BIOS 开启虚拟化；仍不行就关掉系统的 Hyper-V 相关功能 |
| 安装 APK 报解析错误 | 文件没下完整 | 按 [下载与安装教程.md](下载与安装教程.md) 第二节核体积与 MD5 |
| 模拟器里应用一开就闪退 | 模拟器安卓版本过旧或架构不匹配 | 换成 64 位、安卓 9 以上的镜像 |
| 界面正常但网络一直转圈 | 模拟器网络模式异常 | 切换模拟器的网络模式（桥接/NAT）后重启模拟器 |
| 电脑明显卡顿发热 | 分配资源过高或开了多开 | 把模拟器内存调回 4 GB 以内，关掉多开 |

手机装在身上能随手用，模拟器更适合「坐在电脑前长时间聊」这类场景——两条路并用时记住同一个前提：**账号不绑，记录就只在那一台设备上**，具体见 [登录与账号设置.md](登录与账号设置.md) 第三节。
