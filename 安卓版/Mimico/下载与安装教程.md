Mimico 是一款手机端的 AI 角色对话应用，开发者是 MATRIX MOBILE PTE. LTD.，iOS 与 Android 两端都有上架，界面以「发现、聊天、我的」三块为主：你既可以挑现成的角色开聊，也能自己写一个。它没有电脑版，本篇只做一件事——把网盘里这份安卓包装进手机并正常打开。

## 一、先确认网盘里这份包是哪一版

应用商店里显示的是官方当时的最新版，跟网盘里这份未必是同一个版本号。本篇出现的版本号、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Mimico |
| 版本号 | 2.4.74 |
| 包名 | `com.mimico.chat.apk` |
| 安装包体积 | 27.26 MB |
| MD5 | `ED92CCD15F5A47B56651EB21BB4F6A8F` |
| 适用平台 | Android（手机端 APK） |
| 开发者 | MATRIX MOBILE PTE. LTD. |

装之前先弄清三件事：

- **认包名，别只认图标和名字。** 应用商店和第三方下载站里搜「Mimico」会出来若干同名或近名条目，装错了账号与聊天记录都对不上。装好后进「设置 → 应用 → 应用管理」点进 Mimico，在应用信息页核对包名是否与上表一致（以系统显示为准）。
- **官方渠道有迹可循。** 官方条目名是 `Mimico - Ai friend chat`，开发者署名 MATRIX MOBILE PTE. LTD.；官方隐私政策与使用条款挂在 `mimico.matrixmobile.net` 域名下。近名产品怎么区分，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
- **年龄分级是 18+。** 官方在应用商店把这款应用标为 18+ 分级，装给未成年人用之前先想清楚。
- **最低系统版本与处理器架构没有登记。** 网盘这份的登记信息里只有版本、包名与体积，没写最低安卓版本和 CPU 架构；这两项以应用商店页面上标注的为准，装不上时按第五节的表排。

网盘这份是安卓 APK，iOS 设备装不了，iPhone 请走 App Store。想在电脑上用只能走安卓模拟器，做法与坑见 [在电脑上用模拟器运行.md](在电脑上用模拟器运行.md)。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [Mimico 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cfaf009578a1)，在手机夸克 App 里打开最省事。
2. **先转存再下载**：选中安装包，转存到自己的网盘目录，再下载到本机。分享链接以后可能失效，转存过的那份不受影响。
3. **核对体积**：下载完成后看一眼文件体积，应当约 27.26 MB。中途断网重连导致文件偏小，安装时会直接报「解析包错误」。
4. **想校验完整性**：在电脑上把包算一遍 MD5，结果应与上表一致（大小写不敏感）。

```cmd
certutil -hashfile Mimico_v2.4.74.apk MD5
```

文件名随版本变化，以实际拿到的那个为准。

## 三、安装步骤

1. **给文件管理器开「安装未知应用」权限**：进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把用来打开 APK 的那个应用（文件管理器或浏览器）的开关打开。国产定制系统这项常收在「安全」或「隐私」分类下。
2. **点击 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续，这是侧载安装包的常规提示。
3. **手机上已有更高版本时先卸载**：安卓不允许用低版本覆盖高版本，会直接报「应用未安装」。卸载会一并清掉本机数据，动手前确认聊天记录是否还要留。
4. **报「签名不一致」说明包名撞了**：手机里已装过同包名、另一个来源的版本，处理办法见本篇第五节的表。
5. **留出安装空间**：安装过程中系统还要展开一份文件，建议预留 500 MB 以上可用空间。

## 四、第一次打开要确认的三件事

1. **有网络**：角色列表和对话内容都在服务端生成，应用本身不能离线聊天。打开后一直停在加载状态，就先用浏览器确认手机能正常上网。
2. **走完首次引导**：初次启动会先让你给自己起一个昵称，然后填性别与感兴趣的对象类型，接着挑一个想聊的角色类型。这几步是为了把发现页推得更合口味，填错了不用重装，之后还能改。
3. **能发出一句并收到回复**：随便点进一个角色发一句「你好」，正常收到回复就算装好了。想自己写一个角色，方法见 [怎么创建自己的AI角色.md](怎么创建自己的AI角色.md)；想先登录再聊、或者把记录带到别的手机上，见 [登录与账号设置.md](登录与账号设置.md)。

## 五、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整 | 核对体积与 MD5，按第二节重新取一份 |
| 提示「应用未安装：签名不一致」 | 手机里已有同包名、不同来源的版本 | 先在应用管理里卸载旧包，再装这份 |
| 安装被安全中心拦下 | 侧载包被系统安全策略拦了 | 在安全中心的拦截记录里选「继续安装」 |
| 点安装没反应 | 「安装未知应用」权限没给 | 回到第三节第 1 步补上权限 |
| 装完打开就闪退 | 系统版本过低、存储不足或包残缺 | 见 [常见问题与排查.md](常见问题与排查.md) |

装好之后如果第一句话就发不出去，先别怀疑安装包——那是网络与登录状态的问题，同样在 [常见问题与排查.md](常见问题与排查.md) 里排。
