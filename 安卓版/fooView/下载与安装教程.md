## 一、安装文件信息

本篇对应的安装包，各项参数以下面这份为准：

| 项目 | 参数 |
| --- | --- |
| 应用名称 | fooView（中文名 FV悬浮球） |
| 版本 | 1.6.4 |
| 包名 | com.fooview.android.fooview |
| 安装包大小 | 33.27M |
| MD5 | e767096e2666834535865fa4af5b7a10 |

fooView 由北京浮阅科技有限公司（fooView Inc.）开发，是一颗挂在屏幕边缘的悬浮球：切换应用、截屏、录屏、识别屏幕上的文字、查翻译这些动作，都通过球上的手势完成。官方站点在 [www.fooview.com](https://www.fooview.com)（另有中文页 [fooview.cn](http://fooview.cn/)），版本更新日志在 [www.fooview.com/changelog/](https://www.fooview.com/changelog/)。1.6.4 于 2026 年 3 月发布，更新内容集中在 AI 能力扩充与 Android 16 适配，具体以官方更新日志为准。

## 二、从夸克网盘获取安装文件

1. 打开 [fooView 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1fd98e629fb8)；
2. 把文件转存到自己的夸克账号，再从网盘下载到手机存储；
3. 文件名形如 `fooView_v1.6.4.apk`。

想在电脑上核对文件是否完整，可以用校验工具比对 MD5 是否与第一节表格中的值一致；不一致说明下载过程出了问题，重新下载即可。

## 三、安装步骤

1. 在手机上点开下载好的 APK 文件；
2. 系统提示「禁止安装未知来源应用」时，按提示允许浏览器或文件管理器安装应用（各品牌入口不同，一般在 设置 → 安全 或 应用管理 里）；
3. 点安装，完成后打开。

不从这个 APK 装、而是从应用商店装的话，在应用市场搜「FV」即可，官方说明国内各大应用商店均有上架。商店版与网盘版可能不是同一个版本号，功能节奏会差一到几个小版本，以你手上的实际版本为准。

## 四、装完必点的权限

fooView 装完打开后不会立刻出现悬浮球，需要按新手指引逐个授权。会用到的主要权限与用途：

| 权限 | 用途 | 不给的后果 |
| --- | --- | --- |
| 显示在其他应用上层（悬浮窗） | 悬浮球悬浮在屏幕上 | 悬浮球根本不出现 |
| 无障碍（辅助功能） | 手势返回、拉通知栏、长截图、自动任务 | 一部分手势与长截图失效 |
| 文件 / 存储权限 | 截图保存、内置文件管理 | 截图无法落盘 |
| 麦克风 | 语音输入、语音指令 | 语音相关功能不可用 |
| 相机 | 扫码等拍照类动作 | 相应动作不可用 |
| 电池优化豁免 | 防止系统清理掉悬浮球 | 悬浮球隔一段时间消失 |

各项权限都可以在系统 设置 → 应用 → fooView → 权限 里补开。悬浮窗与无障碍这两项最关键，建议装完第一时间点。

## 五、首次打开后的三件事

1. 跟着新手指引开悬浮窗权限，屏幕边缘出现球体；
2. 开无障碍（辅助功能）权限，手势类动作才完整；
3. 按 [后台被杀与权限重置.md](后台被杀与权限重置.md) 把自启动与电池白名单设好，避免过几天球又不见了。

之后按 [悬浮球手势设置.md](悬浮球手势设置.md) 把七个手势改成自己的用法，或者直接试 [截图与录屏方法.md](截图与录屏方法.md)。
