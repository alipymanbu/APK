# fooView 后台被杀与权限重置

> 本篇解决 fooView（FV悬浮球）最常见的一类故障：悬浮球过一阵自己消失、辅助功能权限被系统反复要求重开、手势突然失灵。多数情况是系统清理后台造成的，按本篇的白名单清单设置一遍即可。

## 一、先判断是不是「被杀后台」

这些现象都指向同一个原因：

- 悬浮球过一阵自己消失，重开应用才回来；
- 明明开过辅助功能（无障碍）权限，隔几天又提示要开；
- 手势突然没反应，重开 fooView 后恢复正常。

悬浮窗类应用常被国产系统的后台清理误伤：系统把 fooView 归进后台应用清掉，清掉的同时按系统规则回收无障碍权限。更绕的一点是 —— **被杀之后，系统设置里显示的辅助功能权限仍是「开」的状态，但实际已失效**（这是系统侧的显示问题），处理办法是把这项权限先关再开一遍，而不是只看一眼开关。

## 二、防杀清单

按顺序设置，做完基本就稳了：

| 步骤 | 操作 | 入口（各品牌叫法有差异） |
| --- | --- | --- |
| 1 | 任务列表里锁定 fooView | 最近任务卡片 → 长按 / 下拉 → 锁定（任务列表里看不到 fooView 时，先打开一次应用再锁） |
| 2 | 允许自启动 | 设置 → 应用管理 → fooView → 自启动 |
| 3 | 电池策略改为不限制 | 设置 → 电池 / 省电 → 应用电池策略 |
| 4 | 加入清理白名单 | 手机管家 / 安全中心 / 智能管理器 → 清理白名单 |
| 5 | 开 fooView 内的其他权限 | fooView 设置里把可选项尽量点上，有助于降低被杀概率 |

用自动 / 定时任务的另有一条：较新版本的 Android 上要给「电池优化豁免」权限，定时才准（1.6.1 更新日志注明）；「应用被杀后自动任务开关自己关闭」的历史问题也在 1.6.1 修复 —— 有这现象先升级版本。

品牌差异参考：华为 / 荣耀看「启动管理」，小米看「神隐模式 / 省电策略」，OPPO / vivo / 一加看「电池 - 更多设置」，三星看「智能管理器」。入口名字各版本不同，找不到就在系统设置里搜「自启动」。

## 三、内存与耗电的正常水平

- **内存**：fooView 主进程常驻内存官方口径在 10~30M 量级；如果你看到它占了上百 M，多半是刚在里面开过网页 —— 系统 WebView 的占用被算在了它头上，关闭后立即释放，属正常现象；
- **耗电**：悬浮球本身耗电很低，电量主要消耗在亮屏、CPU 与网络上；要核对就在系统电池页看 fooView 的占比，持续偏高再回头查白名单有没有设全。

## 四、设了白名单还是丢

1. 确认第 1 步的「锁定」真的做了（有些机型锁定的卡片不显示锁标记）；
2. 检查有没有装第三方清理类应用 —— 它们自己有一套白名单，与系统的互相独立，也要加；
3. 还不行的话，到官方渠道反馈机型与系统版本：官网 [www.fooview.com](https://www.fooview.com) 有常见问题页与反馈邮箱（feedback@fooview.com），中文页 [fooview.cn](http://fooview.cn/) 上有官方 QQ 群（111453733）。
