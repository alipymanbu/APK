> 本篇讲用 fooView（FV悬浮球）做区域截图、全屏截图、长截图和录屏的具体操作，包括录屏怎么结束、截图时右上角的图标是什么这类实际动手时才会碰到的问题。

## 一、区域截图

这是 fooView 最常用的一条路径：

1. 长按悬浮球，往屏幕上拖，出现一个选框；
2. 框住想要的范围，松手；
3. 屏幕上弹出一个悬浮结果窗，显示刚截下来的内容；
4. 在结果窗里直接点保存（存进手机相册或 fooView 的目录），或者继续下一步动作。

关键在于第 4 步不用先保存再切换应用：截图结果窗里可以直接识别文字、翻译、搜索、分享，一气呵成。只想留图就点保存，想认字就走 [文字识别与翻译.md](文字识别与翻译.md) 里的流程。

结果窗还支持「钉住」：钉住之后切到别的应用它也不消失，对照抄步骤、做记录时用得上，多窗搭配见 [悬浮窗与多窗口.md](悬浮窗与多窗口.md)。

## 二、全屏截图

全屏截图没有固定手势，取决于你在设置里把哪个手势绑成了截屏 —— 常见搭配是双击悬浮球截全屏（绑定方法见 [悬浮球手势设置.md](悬浮球手势设置.md)）。

一个系统层面的限制要知道：Android 5.0 以下的系统，第三方应用拿不到屏幕捕获授权，只能在 fooView 应用内部截图，悬浮球上直接截全屏这条路走不通。近十年的机型基本都在 5.0 以上，一般碰不到。

## 三、长截图（滚动截图）

- 入口同样是从框选开始，选长截图模式后页面自动往下滚，滚到想要的位置再停；
- 依赖辅助功能（无障碍）权限，权限被系统回收时长截图会失效，处理办法见 [后台被杀与权限重置.md](后台被杀与权限重置.md)；
- 自动滚动的节奏可以在设置里调（不同页面滚动速度不一样，默认值太快或太慢都可以改）；
- 部分华为机型上，自动滚动间隔的设置弹窗曾被界面遮挡（1.6.1 起修复）—— 找不到这个设置就先升级版本。

聊天记录、网页全文这类一屏装不下的内容，用长截图一次收完，不用一屏一屏拼。

## 四、录屏

1. 长按悬浮球拖动，屏幕上会出现一圈图钉位，把球拖到「录屏」图钉上松手；
2. 系统弹出录屏授权，确认后开始录制；
3. 开始前（或设置里）可选参数。

可调项：

| 选项 | 说明 |
| --- | --- |
| 分辨率 | 决定清晰度与文件大小 |
| 码率 | 越高越清晰，文件也越大 |
| 比例 | 按比例录制 |
| GIF | 直接录成 GIF 动图，省去后期转格式 |

## 五、录屏怎么结束

三种方式任选其一：

- 摇一摇手机；
- 按电源键；
- 下拉通知栏，点停止图标。

录完从结果窗或通知里进，视频 / GIF 直接预览、分享。

## 六、截图时右上角的「电视图标」

截屏瞬间屏幕右上角出现一个小的投屏图标，这是系统在提示「有应用正在读取屏幕」，截图完成几秒后会自己消失。不是异常，也不用在设置里找开关。

## 七、截不到、录不上时的排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 截图黑屏或失败 | 部分银行、视频类应用禁止截屏 | 系统层面拦截，换工具也一样 |
| 悬浮球不见了，手势全失灵 | 后台被系统清理 | 见 [后台被杀与权限重置.md](后台被杀与权限重置.md) |
| 录屏通知不显示 | 个别系统版本的兼容问题 | 升级到新版 fooView（1.6.1 起修复了部分机型的录屏通知问题） |
| 长截图滚一下就停 | 辅助功能权限被回收 | 见 [后台被杀与权限重置.md](后台被杀与权限重置.md) |

截图上想接着认字或翻译的，去 [文字识别与翻译.md](文字识别与翻译.md)。
