## 一、先核对安装包信息

装之前先对一遍包的信息，别把同名但不是同一份的包装进去。网盘里这份包的事实如下（网上各下载站标的版本五花八门，以这份为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 4.6.0 |
| 包名 | com.love.ff |
| 大小 | 18.29M |
| MD5 | 2629eedb63fa02065ee7434dd07f6240 |
| 系统要求 | 安卓 4.4 及以上（发布页标注） |
| 语言 | 简体中文 |
| 文件名 | Love TV_v4.6.0.apk |

Love TV 装好后，手机桌面上显示的应用名是「love追剧」，图标和名字对得上就是装对了。它是一款影视聚合类的追剧应用，装上之后手机、平板、电视都能用（电视端的装法见 [装到电视上怎么操作.md](装到电视上怎么操作.md)）。

## 二、拿到安装包

打开 [Love TV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a5d70abbd50f)，转存到自己网盘后再下载，里面是 `Love TV_v4.6.0.apk`。按你手上的设备挑一条路：

1. **手机 / 平板直接装**：手机上打开链接，转存后下载 apk，留在手机存储里，按第四节装。
2. **电脑中转（最稳）**：电脑浏览器打开链接，转存后下载 apk 到本地；要装电视就接着拷进 U 盘（见第五节）。
3. **电视 / 盒子上有网盘客户端**：设备能装夸克网盘客户端的，直接在设备上转存下载，省去 U 盘。

这个包不需要谷歌服务框架，国产手机和盒子上装都不会因为缺 GMS 报错。

## 三、校验文件是否下载完整

包只有 18 MB，下载很快，但也正因为它小，传输中断后更容易拿到不完整的文件。装完报「解析包错误」十有八九是文件没下完整，先校验再重装。电脑上打开命令提示符或 PowerShell，进入 apk 所在目录运行：

```powershell
certutil -hashfile "Love TV_v4.6.0.apk" MD5
```

输出的 32 位十六进制应与 `2629eedb63fa02065ee7434dd07f6240` 一致（大小写不敏感）。对不上就删掉重下，再验一次；校验还失败，换一条网络环境重新转存下载。

## 四、装到手机 / 平板

1. 在手机文件管理里找到下载好的 `Love TV_v4.6.0.apk`，点开。
2. 系统弹「不允许安装来自此来源的应用」时，点 **设置**，给文件管理器（或浏览器）开启「允许安装未知应用」，返回后继续；新版安卓如果开了未知来源仍被拦（要走安全流程或被纯净模式拦下），按 [安装时被系统拦截怎么办.md](安装时被系统拦截怎么办.md) 处理。
3. 安装页点 **安装**，完成后打开。
4. 首次启动一般会请求存储权限（缓存剧集要用），允许即可。

装完想直接在大屏上看，可以参考电视篇的投屏与安装说明，或者把同一份 apk 用 U 盘装进电视。

## 五、装到电视 / 盒子

电视和盒子上没有应用商店收录这类应用，走 U 盘侧载：

1. 电脑下载 apk 后拷进 U 盘根目录，安全弹出。
2. U 盘插到电视 / 盒子的 USB 口。
3. 打开电视的文件管理（有的叫「文件管理 → 外接存储 / U盘」），找到 apk 按确认键安装。
4. 提示「禁止安装」时，先去 **设置 → 安全** 里开「未知来源」，再回来装。

不同品牌的入口叫法不一样，详细的分品牌步骤、遥控器操作和常见报错，见 [装到电视上怎么操作.md](装到电视上怎么操作.md)。装完打开后怎么找剧、怎么换播放源，见 [追剧与搜索功能怎么用.md](追剧与搜索功能怎么用.md)；装不上、打不开、播放失败之类的排查，见 [常见问题与解决方法.md](常见问题与解决方法.md)。
