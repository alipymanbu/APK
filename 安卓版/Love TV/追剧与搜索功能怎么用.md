## 一、首页和分类怎么翻

打开应用后首页是推荐位和热播剧的卡片流，往下滚是分类入口。资源按 影视 / 电视剧 / 综艺 / 动漫 这几个大类组织，点进大类后再按地区、类型、年份二级筛选。想找的不是新剧就别在首页翻，直接进分类按筛选条件收窄，比一路往下滚快得多。

每部剧的详情页能看到剧集列表、更新到第几集、有哪些播放源。能不能搜到某部剧、更新到哪一集，以应用内实际显示为准 —— 这类聚合应用的资源范围会随时间变化，昨天有的源今天可能就没有了。

## 二、搜剧的几个技巧

1. **剧名记不全也能搜**：搜索框支持模糊匹配和关键词联想，输入剧名里最有辨识度的两三个字，从联想列表里选，比输全名快。
2. **别名 / 简称多试一轮**：一部剧常有多个叫法（台译、港译、网络简称），搜不到时换个叫法再来一次。搜出来没有结果的剧，可能是这个源没收录，先换搜索词、再进对应分类里翻，都找不到就是没收录。
3. **用筛选代替翻页**：分类页里若有年份、地区、类型这类筛选条，先筛再挑，比在长列表里一路往下滚准得多（筛选项有哪些以应用内实际显示为准）。

电视端用遥控器打字太慢，可以先在手机上搜好、记住剧名和集数，再回电视端照着找；或者干脆手机端看，操作都一样。

## 三、卡顿或没画面时换播放源

同一部剧通常挂着不止一个播放源。播放中出现转圈不动、黑屏有声没画面、进度条卡住，第一反应是换源：

1. 点一下屏幕调出播放控制条。
2. 找「播放源 / 线路」字样的按钮，会列出源 1、源 2……或按名字列出的多个线路。
3. 换另一个源，重新加载这一集。

先挑一个和当前线路不同名的源试；一个源整体失效时，这部剧每一集都要在同一个新源下重新点开。换两三个源还都是同样的问题，多半是当前网络到源服务器不通，切一下 Wi-Fi 或流量再试。

## 四、清晰度怎么选

播放控制条里的清晰度按钮可以切换流畅、高清等档位（档位多少以具体源为准，不是每部剧都有多档）。选档参考：

| 场景 | 建议 |
| --- | --- |
| 家里 Wi-Fi，电视 / 平板看 | 高清档 |
| 流量 / 信号一般 | 流畅档，省流量也少卡 |
| 网络不稳又不想缓冲 | 先流畅档看着，稳定后再切回高清 |

## 五、追更：收藏、历史与提醒

- **收藏 / 加入追剧**：详情页点收藏，后续更新会出现在「我的追剧 / 收藏」列表里，不用每次搜索。
- **观看历史**：继续看上一集直接进历史记录点续播，进度会接着上次的位置。
- **播放列表**：把要连看的几集加进列表，连播不用一集一集点。
- **更新提醒**：追连载剧时看应用内有没有更新提醒开关（不同版本功能入口有差异，以你装的应用里实际显示为准），开了之后新的一集更新会提示。
- **换机 / 重装前先知道**：收藏、观看历史这类记录存在本机，换设备或卸载重装后不会自动跟过来；换机前把收藏列表截图留档，重装后照着重新收一遍最省事（缓存同样不会跟过来，见 [怎么缓存下载剧集.md](怎么缓存下载剧集.md) 第三节）。

想在没网的时候接着看，把正在追的剧缓存到本地，见 [怎么缓存下载剧集.md](怎么缓存下载剧集.md)。播放一直失败、应用打不开这类故障，去 [常见问题与解决方法.md](常见问题与解决方法.md) 逐条排查；还没装应用的话先看 [下载与安装教程.md](下载与安装教程.md)，电视端的遥控器操作细节在 [装到电视上怎么操作.md](装到电视上怎么操作.md)。
