## 一、安装类

**提示「解析包错误 / 无法解析」**
文件没下完整，别反复点安装。把 apk 拷回电脑，按 [下载与安装教程.md](下载与安装教程.md) 第三节校验 MD5；对不上就删掉重下再校验，校验通过后再装。

**点开 apk 没有任何反应**
未知来源权限没开对地方。手机上给「用来打开 apk 的那个应用」（文件管理器或浏览器）开「允许安装未知应用」；电视端各品牌的权限入口见 [装到电视上怎么操作.md](装到电视上怎么操作.md) 第三节。

**提示存储空间不足**
先清出空间再装：卸载不用的应用、清一下文件管理里的下载目录。电视端装不上多是这个原因。

**电视 / 盒子装不上或识别不到 U 盘**
换 USB 口、把 U 盘格成 FAT32 再拷包重试；三星 Tizen、LG webOS 系统的电视装不了安卓应用，只能外接安卓盒子。

**开了未知来源还是被系统拦**
新版安卓对侧载加了更严的流程（进开发者选项、按提示等待生效）或被「纯净模式 / 高级保护」类开关拦下，这两种情况的处理见 [安装时被系统拦截怎么办.md](安装时被系统拦截怎么办.md)。

## 二、打开与运行类

**打开就闪退**
按各手机厂商通用的排查顺序来：① 清理后台后重开；② 重启设备；③ 长按应用图标 → 应用信息 → 存储 → **清除缓存**（不动数据），清完再开；④ 检查权限：应用信息 → 权限 → 把「存储」打开，没给存储权限的应用缓存剧集时会异常；⑤ 卸载后重新安装（重装前记住缓存会被清空，见第四节）。系统太老（低于安卓 4.4）装得上也跑不稳，升级系统才有意义。

**启动卡在开屏进不去**
检查网络后杀掉应用重开；老设备第一次启动加载慢，多等十几秒，别连点图标。还不行就按上面闪退的第 ③ 步清一次缓存。

**手机桌面找不到应用图标**
装好的应用名显示为「love追剧」，按这个名字在应用列表里找，别搜「Love TV」。

## 三、播放类

**黑屏、有声没画面、一直转圈**
先换播放源（播放控制条里的「播放源 / 线路」），再降清晰度，还不行就切一下 Wi-Fi / 流量。聚合应用的单条线路随时可能失效，换源能解决大多数播放问题。

**搜不到某部剧、某部剧缺集**
先换剧名的其他叫法再搜一次（台译 / 简称 / 别名）；分类里也翻不到就是当前没有收录。资源范围以应用内实际显示为准，这类聚合应用的收录会随时间变化。

**高峰时段卡顿明显**
晚间网络高峰部分源会变慢，降清晰度、换源或错峰再看。

**投屏按钮找不到或投不出去**
应用内有没有投屏入口、支持哪种投屏协议，以你装的 4.6.0 实际显示为准；投不出去时先确认手机和电视在同一 Wi-Fi 下，再用电视系统自带的投屏功能代替。

## 四、缓存类

**缓存一直卡在某个进度 / 失败**
处理顺序：查剩余空间 → 换网络 → 换播放源 → 删掉这条缓存任务重新添加。完整步骤见 [怎么缓存下载剧集.md](怎么缓存下载剧集.md) 第四节。

**卸载重装后缓存没了**
缓存存在应用内部目录，卸载即清空，重装前先把想看的看完；这也是缓存别攒太多的原因。

**装到电视上缓存很慢**
电视存储和性能都弱于手机，一次只挂一两个任务，或干脆在手机上缓存。

## 五、其他

**要不要升级到更高版本**
网盘里这份 4.6.0 是校验过的完整包，用着正常就先用；升级与否自行决定，升级后以新版本实际表现为准。

**想彻底清掉应用数据**
系统设置 → 应用管理 → love追剧 → 存储 → 清除数据（缓存与登录状态一并清掉）；要连应用一起删就先卸载，安装包保留在网盘里随时可重下。
