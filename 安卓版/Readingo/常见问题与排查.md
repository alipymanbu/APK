## 一、书导不进来 / 扫不到

按顺序过三关，哪关卡住修哪关：

1. **权限关**：自动扫描没结果，九成是文件扫描权限没给。进手机「设置 → 应用 → Readingo → 权限」，把存储 / 文件权限改成允许，再重进扫描页。
2. **格式关**：选文件时格式不在列表里就是不支持。这份包按官方口径支持 TXT、EPUB、PDF，压缩包 RAR / ZIP / 7Z / TAR 可直接导入（详见 [书籍导入与书架管理.md](书籍导入与书架管理.md) 的格式表）。
3. **路径关**：书在 SD 卡或「仅此应用可见」的目录里时系统可能不让读。把文件挪到 `Download` 目录再导入一次。

ZIP 导入报密码错，说明压缩包本身带密码，导入时按提示输入；密码不对拆不开，不是应用坏了。走 WiFi 传书时电脑打不开传书地址的，不在本节——单独一篇：[WiFi传书连不上怎么办.md](WiFi传书连不上怎么办.md)。

## 二、打开了但是乱码 / 排版错

- **整片乱码**：TXT 编码 Readingo 未必猜得中。用电脑把文件转存成 UTF-8 编码再导入一次。
- **段落粘连、换行异常**：同样先试转编码；还不行就在阅读页的排版设置里调行距与段距缓解（见 [阅读主题与排版设置.md](阅读主题与排版设置.md)）。
- **EPUB 图片不显示、偶发闪退**：v1.30 修过 EPUB 闪退与图片显示问题——先确认手上是不是 1.50 这份（核对方法见 [下载与安装教程.md](下载与安装教程.md) 第一节），旧版本覆盖安装新版即可。

## 三、翻页与手势的怪现象

| 现象 | 处理 |
| --- | --- |
| 音量键翻页一次跳两页 | v1.32 已修复；仍在出现时检查是否同时开了手势翻页，关掉一路只留音量键 |
| 手一碰屏幕就误翻页 | 进阅读页配置点击区域大小，或直接禁用手势 / 点击翻页（见 [阅读主题与排版设置.md](阅读主题与排版设置.md)） |

| 打开书时音乐被暂停 | v1.26 已修复，旧版升级即可 |

## 四、听书念一半停了

听书依赖系统 TTS。先按 [听书与阅读统计.md](听书与阅读统计.md) 第一节重开一次；仍不行就换系统 TTS 引擎、调语速再试。听书停住**不会损坏书籍数据**，书签和进度都在。

## 五、闪退或无响应

按代价从小到大试，**每做一步之前先确认备份还在**（见第七节），别一上来就清数据：

1. **强制停止再开**：手机「设置 → 应用 → Readingo → 强制停止」，重新打开，先复现一次看是不是偶发。
2. **清缓存**（不丢数据）：同一位置进「存储」，先点「清除缓存」。缓存是临时文件，清掉不影响书架、笔记和统计——升级系统或升级应用后最容易出脏缓存，这一步能解决相当一部分「升级完就闪」。
3. **重启手机**：内存紧张、后台异常时，单个应用反复崩多半重启就好。
4. **清数据**（会丢应用内数据，**先备份**）：清缓存无效再点「清除数据」。它会把书架记录、分类标签、统计、笔记全部归零——书的原文件还在手机里，重新导入即可，但应用内的整理要靠备份找回。
5. **安全模式定位干扰**：长按电源键 → 长按「关机」进入安全模式（各品牌入口略有差异）。Readingo 在安全模式下不崩了，说明是某个第三方应用在干扰（清理类、主题类、广告跳过类工具最常见），退出安全模式后逐个卸载排查。
6. **覆盖安装同版本**：以上都无效，回 [下载与安装教程.md](下载与安装教程.md) 重新取一份 1.50 的包覆盖安装（不用先卸载，先卸载会清掉应用内数据）。

## 六、主题切换后样式错乱

v1.50 的更新说明里明确修了「主题切换资源回退」「主题索引丢失」「头图展示偏好丢失」三个问题。你若在旧版遇到：

1. 先覆盖安装 1.50 这份包（下载见 [下载与安装教程.md](下载与安装教程.md)）；
2. 升级后把出问题的主题**恢复默认**再重新应用一次；
3. 自制主题错乱时，检查它是不是加密主题——1.50 起加密主题不再提供保存与导出，只能用内置或自己做的主题替代（主题玩法见 [阅读主题与排版设置.md](阅读主题与排版设置.md)）。

## 七、备份、恢复与换机

- **备份前**：确认备份文件实际生成了（去存储里看一眼，别只看应用提示成功）。
- **恢复时**：版本跨度大时先升级到同版本再恢复；v1.48 修过一批备份与恢复的 bug，用旧版备份遇到恢复异常，先升到 1.50 再试。
- **换机顺序**：旧机备份 → 文件传到新机 → 新机装同版本应用 → 恢复。书的原件（TXT 等文件）本身不依赖恢复，没备份也能重新导入；丢的是分类、标签、统计这类应用内数据。
- **笔记与书签**：重要批注别只押在备份上，单独导出一份更稳（做法见 [划线笔记与书签导出.md](划线笔记与书签导出.md)）。

## 八、同步与多设备

iCloud 同步是 iOS 端的能力；安卓这份包的跨设备靠**备份文件 + WiFi 传书**手动搬运，没有账号云同步（WiFi 传书的用法与排查见 [WiFi传书连不上怎么办.md](WiFi传书连不上怎么办.md)）。曾有「部分设备和系统无法同步」的修复记录（v1.23）——若你在 iOS 与安卓之间搬数据出问题，改走导出 / 导入文件这条路，最可控。

另有第三方介绍页称近几个版本加入了 **WebDAV 云端同步**（把书架与笔记同步到自己的 WebDAV 网盘）——官方页面的功能清单里没有列这一项，**两边口径不一致**。以你打开应用后设置里实际有没有 WebDAV 入口为准：有就按它页面上的说明配，没有就走备份文件手动搬。

## 九、还是解决不了

按这个顺序收集信息再去反馈，效率最高：版本号（应为 1.50，核对见 [下载与安装教程.md](下载与安装教程.md)）、手机型号与安卓版本、书的格式、操作到哪一步、报错原文。反馈里把应用名拼写清楚——有一款只差一个字母的 **Readigo** 是别的应用（见 [下载与安装教程.md](下载与安装教程.md) 第一节），别把问题报到那边去。官方入口见 Readingo 官网 [www.readingo.top](http://www.readingo.top)，应用商店页的更新说明也能对照自己是不是旧版。
