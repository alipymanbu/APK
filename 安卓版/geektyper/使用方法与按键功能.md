## 一、30 秒先跑起来

整个应用就一个玩法核心：**你敲什么不重要，屏幕滚什么早写好了**。第一遍照这个顺序走：

1. 过掉首屏的 `I will use responsibly` 确认页（见 [下载与安装教程.md](下载与安装教程.md) 第四节）；
2. 进代码界面后，在屏幕键盘上**随便点一个英文字母**——先手动出几行代码，确认有反应；
3. 点键盘上的 **`AUTO`**——代码开始自动连续滚动，就是「电影黑客」的默认形态；
4. 想停就点 **`STOP`**，画面立刻定住。

`AUTO` / `STOP` 是同一个位置的两个状态按钮：在滚的时候它是停止，在定住的时候它是继续。录视频前先用这两键排练一遍起停时机，比进去现找顺手得多。

## 二、手动模式：字母键和数字键

不开自动时，画面全靠按键触发，两类键分工不同：

| 按键 | 触发效果 |
| --- | --- |
| 字母键 | 滚出一段预设代码，按得越多出得越快——这是手动模式的主力 |
| 数字键 | 弹出预设的效果窗口（进度条、扫描、结果框这类「剧情窗口」） |
| 小键盘上的数字 | 部分教程提到会弹雷达图像、程序关闭窗口这类大特效 |

要点是：**屏幕上的字母与代码内容没有对应关系**。你按 `A` 出来的不是 `a` 的编码效果，代码是提前写好的片段，按键只负责「往屏幕上放料」。所以看不懂英文完全不妨碍用——它的用途本来就是画面，不是内容。

## 三、几个单独说的特效键

不同页面对特效键的说法基本一致，值得一一试：

- **`P`**：弹出一个持续闪烁的红色窗口，像「警报 / 被发现」的效果，画面里最抢眼的一个；
- **`TR`**：切换成另一种成套效果，和 `P` 是不同风格的「大招」；
- **`Enter` / `Alt`**：弹出「拒绝访问 / 允许访问」之类的英文结果窗口，适合当一段表演的收尾——敲半天之后按一下，等于给画面一个「攻破了 / 没攻破」的句号；
- **`TAB`**：显示热键提示，告诉你当前这套界面里哪些键有效。按了没反应也别慌——有的主题开了热键图，有的没开，换个主题再试。

界面上的按钮、图标都可以直接点。它没有「点错了会弄坏什么」的设定，所有按钮都是视觉效果开关，随便试。

## 四、文件夹系统：右上角那一排

开启 **Show Folders** 后，主界面右上角会出现一排文件夹图标，每个文件夹还能展开子文件夹，点进去会触发不同的效果（弹窗、扫描、数据流这类）。这是把画面从「一整屏代码」变成「多窗口作业现场」的关键开关——截静态图时用它，画面信息密度立刻上来。

Show Folders 这个开关的位置随主题略有差异，一般在设置菜单或界面角落；找不到就先把右上角三横的菜单过一遍（主题切换也在那里，见 [主题风格与界面自定义.md](主题风格与界面自定义.md)）。

## 五、键盘收放与画面重置

- **收起键盘**：点右下角的 **`min`**，键盘整块消失，只剩纯画面——给全屏演示或截图时用；
- **恢复键盘**：点同一位置的 **小加号 `+`**，键盘原样回来；
- **重置画面**：**Reset Input** 会把窗口里滚过的所有内容清掉，回到刚打开应用时的样子。上一段演砸了、屏幕堆满了窗口，按它一键归零，不用退出重进。

`min` / `+` 这一对是同一个位置切换，所以收起来之后别到处找按钮——就是刚才 `min` 在的地方。

## 六、按了没反应？先查这三件

1. **是不是停在定住状态**：`STOP` 按下后画面本来就不动，先点一下 `AUTO` 恢复；
2. **是不是键盘被收起了**：看右下角是 `min` 还是 `+`，被收起时你点屏幕当然没输入；
3. **是不是当前主题的键位不同**：按 `TAB` 看热键提示，或换个主题对照（见 [主题风格与界面自定义.md](主题风格与界面自定义.md)）。

三件都排除了还是完全无响应、闪退，转到 [打不开闪退与卡顿排查.md](打不开闪退与卡顿排查.md)。

## 七、输入内容会留下吗

网页版站点自己在首页声明输入内容不会被存储；手机这一侧没有同等的公开说明。可以确定的是：它没有账号、没有保存按钮，画面里的代码也不是你打的字——但**别把「不存储」当成承诺往里输入任何真实敏感信息**，它就是一个画面工具，用途到「好看」为止。
