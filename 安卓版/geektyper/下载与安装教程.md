## 一、先说清这一份是哪个版本

GeekTyper 是一款纯娱乐的手机应用：你随便敲键盘，屏幕上就滚动出电影里那种「黑客在敲代码」的画面，可以换主题、换字体、调颜色，用来拍段子、录视频或给朋友演示。它不执行任何真实命令，也没有编程或安全测试功能。

动手前先对一下手上这份包：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | GeekTyper |
| 包名 | com.blumont.geektyper2 |
| 版本号 | 1.0.1 |
| 安装包大小 | 3.12 MB |
| 安装包 MD5 | D95F00373A29A16F78F82661F23667BC |
| 系统要求 | 安卓 5.2 及以上（以实际安装为准） |
| 开发者 | Blumont Interactive（各下载站资料标注） |

**版本号别拿别处的来对。** 网上同一个包被写成过好几种版本号：有的页面写 1.0.1，有的写 7.8.7，还有的更新日志只有一句「重新发布」。判断手上这份对不对只看两项：包名是不是 `com.blumont.geektyper2`，版本号是不是 `1.0.1`——别处的数字对不上属正常，不代表你这份旧了或错了。

**名字写法也不统一。** 同一个包在不同页面叫 GeekTyper、geektyper、GeekTyper Official、geektyper 黑客模拟器，都是同一个东西；查资料时把包名带上最容易找对，单搜英文名会混进同名网页工具。

**最低系统版本以实际安装为准。** 这一份记录的是「安卓 5.2 以上」，个别页面写 5.0 或 4.4。真不满足时系统会在安装前直接拦下，不会装到一半坏掉。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享。相比在搜索结果里随手点一个「立即下载」，从网盘转存再下载的好处是文件固定，不会被下载站中途换成别的东西。

1. 在手机上打开 [geektyper 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7727b4753776)。手机浏览器或夸克 App 都能开，**建议用夸克 App**——浏览器下大文件容易被切到后台打断。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存之后就不再依赖原分享链接还在不在。
3. 进自己的网盘找到这个包，点下载，等它落到手机存储里。
4. 下完核对两件事：文件名结尾是不是 `.apk`（这一份形如 `geektyper_v1.0.1.apk`）；大小是不是 3.12 MB 左右。差得多就是没下完整，删掉重来。

习惯在电脑上操作也行：在电脑端网盘下载，再用数据线拷到手机的 `Download` 目录，之后从手机「文件管理」里点它安装，效果一样。

手上有校验工具的话可以顺手算一遍 MD5，和上表的 `D95F00373A29A16F78F82661F23667BC` 比一比：一致说明传输没出错，不一致就重新下一遍。不查也不影响安装。

## 三、安装：系统会拦一次，放行即可

这一份是手动安装的，不是从手机自带应用商店点「安装」装的，所以点安装包时系统会拦一下，提示「不允许安装来自此来源的应用」之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开「文件管理」，进 `Download` 目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，找到你刚才用来打开文件的那个 App 单独放行。
3. 回到安装界面点「安装」，等进度条走完。包只有 3.12 MB，几秒就完。
4. 出现「打开 / 完成」时先点「完成」，回桌面找图标再启动，比从安装页直接进更接近日常用法。

## 四、首次打开：点那个英文确认页

启动后第一屏是一整页英文，底部有一个 **I will use responsibly**（我会负责任地使用）按钮——这是进入主界面前的唯一一道确认，点它就进代码界面了。这一页不是登录、也不收集账号，点完即进。

进主界面后建议先按 [使用方法与按键功能.md](使用方法与按键功能.md) 的第一节跑一遍：随便点一个字母键 → 点 `AUTO`，屏幕开始滚动代码就说明装对了。

## 五、权限先看清楚再给

各下载站页面列的权限清单（存储、网络、定位、修改系统设置等）常是页面自动生成的，未必与真实包一致。以你装完后到系统「设置 → 应用 → GeekTyper → 权限」里看到的实际清单为准：

- 这个应用的全部画面都在自己界面里生成，**正常玩法不依赖定位、相机、通知这类敏感权限**；
- 若首次启动弹权限请求，拒绝掉再进主界面试一遍——界面照常出代码，就说明那些权限不是必需的；
- 确实遇到某项功能因缺权限不工作，再按提示单独放行，别一次性全给。

## 六、升级与卸载要注意的

- **升级**：这类应用的版本更新会换一个安装包文件名，届时从同一处网盘取新包装上即可，一般直接覆盖，不用先卸载。它没有账号体系，卸载重装也没有「丢进度」的问题——本来就不保存你的输入。
- **卸载**：桌面长按图标 → 卸载即可，没有需要先关掉的后台服务。
- **安装包删了**：任何时候回到文首那条 geektyper 安装文件资源的链接重新取一份；已经转存过的不受原分享是否还在影响。
- 装完遇到打不开、闪退或动画卡顿，对照 [打不开闪退与卡顿排查.md](打不开闪退与卡顿排查.md) 逐条排。
