# FlyMusic 桌面歌词与播放设置

> 桌面歌词是 FlyMusic 里要多走一步权限的功能，开完不显示也最容易被当成故障。本篇讲清开启路径、不显示时按什么顺序查、播放页上能做哪些操作，以及音效与播放模式怎么调。

## 一、桌面歌词怎么开

1. 在搜歌页搜一首歌，点进去到**歌曲播放界面**（桌面歌词的开关在播放页里，别的页面没有）；
2. 点播放页**右下角的扩展菜单**（三个点的图标）；
3. 在弹出的菜单里点**桌面歌词**；
4. 首次开启会要求授予相关权限，按提示放行；
5. 授权后再点一次，看到「已开启桌面歌词，回退桌面即可显示」这类提示，说明设置成功 —— 此时退到手机桌面就能看到歌词浮在桌面上了。

## 二、开了不显示，按这个顺序查

| 先查什么 | 怎么查 |
| --- | --- |
| 悬浮窗权限 | 手机设置 → 应用 → FlyMusic → 权限，或「特殊应用权限」里的**显示在其他应用上层 / 悬浮窗**，确认已允许 |
| 后台被限制 | 把 FlyMusic 加入电池优化白名单，并允许自启动 / 后台运行。省电模式一开，浮层常被系统直接掐掉 |
| 是不是在锁屏状态 | 多数机型锁屏时不显示桌面歌词，解锁后才出来，这属于正常表现 |
| 应用是否在前台播放 | 播放暂停或退出应用后歌词消失，是设计如此，不是故障 |
| 通知权限 | 少数机型把桌面歌词归到通知里管，通知被关掉时歌词也不出 |

这几项都对仍然不出现，退回应用把桌面歌词关掉再开一次；还不行就按 [常见问题与排查.md](常见问题与排查.md) 第六节走。

## 三、播放页上能做的操作

- **点封面 / 歌名区域**：在封面与歌词之间切换显示；
- **横向滑动**：在歌单内切换上一首、下一首，部分版本支持在播放页左右滑切歌；
- **桌面歌词开关、音质相关选项**：都在右下角的扩展菜单里；
- **匹配歌词**：歌词对不上时，播放页的菜单里能手动换一条歌词匹配；
- **下载不在这里**。播放界面的菜单里通常没有下载入口，要下载回搜歌页的结果列表，见 [搜索歌曲与音质下载.md](搜索歌曲与音质下载.md) 第四节。

上面这些手势与菜单位置在不同版本上不完全一致，长按按钮或点一下看反馈是最快的确认方式。

## 四、音效与均衡器

公开介绍里列出的音效相关设置大致有这么几块：

| 项目 | 说明 |
| --- | --- |
| 均衡器 | 可调低频增益、中频清晰度、高频明亮度这类滑块 |
| 预设音效 | 流行、摇滚、古典这类一键预设，切换后滑块会跟着变 |
| 特色音效 | 介绍里提到的「极光音效」「HI-FI 房间」属于这一类，随版本增减 |

**实际调法**：先在预设里挑一个接近你口味的，再在均衡器上做小幅微调 —— 一次只动一个滑块，听一段再决定要不要留。全部滑块都往上推不会更好听，只会失真。

这几块的具体名称与滑块数量会随版本变化，以你装到的这一版界面上实际显示的为准。

## 五、播放模式与常用设置

播放模式常见的有单曲循环、列表循环、随机三种，在播放界面切换。此外还有一类设置只在特定版本上出现，例如定时关闭、下载音质默认值，看到就按字面意思设即可，没看到说明这一版没有。

## 六、这些设置存在本机

桌面歌词的开关、音效参数、界面设置都保存在当前这台设备上：

- 卸载重装后需要重新设一遍；
- 换手机不会自动带过去；
- 换歌单、换账号也不会让音效设置跟着走。

容易记错的是歌单与收藏：它们和设置不一样，不能想当然地认为一定跟着账号走。换手机前先把本地文件备份出来，歌单是否需要重新整理先确认一遍；「在线收藏」与「本地文件」这两处来源的区别见 [歌单收藏与本地音乐管理.md](歌单收藏与本地音乐管理.md) 第一节。
