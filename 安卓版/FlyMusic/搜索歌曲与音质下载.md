## 一、搜索入口在底部导航的「搜歌」

打开应用，底部导航里有一项是搜歌（有的版本写作「找歌」），点进去，页面顶上是搜索框。

第一次用最常见的误会是：在播放界面里翻菜单找搜索框。搜索入口就是搜歌页那一处，播放页里没有。下载入口同样以搜歌页为主，这条下面第四节单独说。

## 二、关键词怎么写命中率高

这个搜索框认三类东西：**歌名、歌手、专辑名**。三类混着填也认，但优先度不一样，实际用起来差别不小。

| 你想听的 | 建议写法 | 原因 |
| --- | --- | --- |
| 一首具体的歌 | 歌手名 + 歌名（中间留一个空格） | 同名歌、翻唱、不同专辑版本太多，只写歌名会出来一长串 |
| 某位歌手的作品 | 直接填歌手名 | 出来的是这位歌手的集中结果，翻起来比逐首搜快 |
| 只记得专辑 | 直接填专辑名 | 适合听整张专辑的场景 |

搜不到时的换词顺序：

1. **去掉附加后缀再搜一次**：`（Live）`、`伴奏`、`remix`、`feat.xxx` 这类后缀会把匹配卡死，先删掉。
2. **换繁简或换别名**：同一首歌在收录方的标题里可能是繁体，也可能用的是另一个译名。
3. **只保留最有辨识度的几个字**，别把整句歌词粘进去。部分版本另外提供了按歌词找歌的入口，但它的入口位置与命中表现各版本不一致，以你装到的这一版界面上实际看到的为准。

## 三、搜到了但点不动

按这个顺序试，多数情况到第二步就好了：

1. 换一条搜索结果点。同一个歌名常有多条，某一条的源不通是常态，换一条即可。
2. 退出去重进搜歌页，再点一次。
3. 换网络。在线播放依赖网络流媒体，Wi-Fi 与移动数据之间换一下往往能立刻判断出是不是网络侧的问题。
4. 仍然不行，按 [常见问题与排查.md](常见问题与排查.md) 第四节排。

## 四、下载入口在搜索结果那一行，不在播放页

这是本应用最容易找不到的地方，单独说清楚：

1. 在搜歌页搜出结果；
2. 在**结果列表里找到你要的那一行**，点这一行右侧的扩展菜单（三个点或 `...` 的图标）；
3. 弹出的菜单里选音质，选好后即开始下载；
4. 下载完成时应用会给出「下载完成」的提示。

对照一下就容易记：**播放是在结果上点一下，下载是在结果右侧的菜单里点**。播放界面里的菜单管的是桌面歌词、音效这类播放相关的事，通常不含下载入口。

公开的操作说明对这一点写法并不一致：多数说明都把下载放在找歌页的结果菜单里（本文档按这条路径写），也有介绍页称播放页里另有一个下载按钮。两种说法都存在，以你装到的这一版实际看到的为准 —— 播放页里若有下载按钮，直接用即可。

## 五、音质档位怎么选

下载时让你选的音质，档位名称各版本不完全一样，但大致就三档：

| 档位 | 适合什么情况 | 要付的代价 |
| --- | --- | --- |
| 标准 | 手机外放、通勤路上随便听听 | 体积最小，耳机里能听出区别 |
| 高品质 | 日常用耳机听 | 体积明显变大，多数场景的平衡点 |
| 无损 | 接解码器、音箱，或打算长期留存 | 体积最大，普通耳机上未必听得出差别 |

选档位的建议很简单：**只在通勤路上听的，先按标准下几首试试**，觉得不够再删掉下无损。同一首歌换档位重下会占两份空间，所以别一次把整个歌单都按无损下满。手机可用空间小于 2 GB 时，优先下标准档。

另外，部分版本在设置里提供**下载默认路径**这一项：把落点改到 `Music` 或 `Download` 这类公共目录，之后下的歌更容易被文件管理器和别的播放器看到。改路径只影响之后下载的文件，之前下的不会自动搬。界面上没有这一项说明你这一版不支持，替代办法见 [下载下来的歌在手机里怎么找.md](下载下来的歌在手机里怎么找.md) 第五节。

## 六、下载完的文件在哪找

两个地方都能看到：

- 管理页里的**下载完成**列表 —— 按下载记录排列，最直接；
- 首页/本地音乐列表 —— 下载下来的歌会一并出现在这里，和手动导进来的本地文件混在一起。

这两个列表的区别，以及怎么把它们整理成歌单，见 [歌单收藏与本地音乐管理.md](歌单收藏与本地音乐管理.md)。

上面说的都是**在应用内看**。想在手机的文件管理器里直接翻到这些文件，要另说了：下载文件多数落在应用自己的目录里，而 Android 11 起文件管理器默认进不去那个目录。完整的说明与替代做法见 [下载下来的歌在手机里怎么找.md](下载下来的歌在手机里怎么找.md)。

## 七、下载失败或找不到文件的排查

| 现象 | 先做什么 |
| --- | --- |
| 点了下载没反应 | 确认是在搜歌结果那一行的菜单里点的，不是播放页里点的 |
| 进度卡住不动 | 换网络；或退出搜歌页重进再下一次 |
| 提示下载失败 | 看手机剩余空间，空间紧张时先清一批再试 |
| 提示下载完成但列表里没有 | 下拉刷新管理页；仍在的话退出应用重进一次 |
| 文件名显示乱码 | 不影响播放，重命名成正常文字即可 |

多次重试都失败、又肯定不是网络问题的，按 [常见问题与排查.md](常见问题与排查.md) 第五节走一遍。
