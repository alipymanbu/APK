# FlyMusic 同名应用与官方渠道怎么认

> 名字里带 Fly 的音乐应用不止一个，网上搜出来的介绍、安装包与版本号常常对应的是另一个应用。本篇讲怎么靠包名把应用认准、手机上在哪核对、以及为什么同一款应用到处写着不同的版本号。

## 一、认应用先认包名，别看名字

安卓应用的真正身份是**包名**，不是显示在桌面上的名字。同一个显示名可以有很多个互不相干的应用；同一款应用在不同下载页上的中文名也可能不一样。

本文档配套的这份安装包，身份信息是固定的：

| 项目 | 值 |
| --- | --- |
| 包名 | com.yfoo.flymusic.plus |
| 版本号 | 1.3.2 |
| 安装包大小 | 14.45 MB（15,144,870 字节） |
| 安装包 MD5 | D3749FA07C6D987A4DDF22DDD7936FE4 |
| 中文名 | 多写作「Fly音乐Plus」，也有页面只写「Fly音乐」 |

**包名对不上，就是另一个应用**，不管它叫什么名字、界面截图看起来多像。

## 二、公开渠道里几个容易混的条目

| 你在别处看到的写法 | 包名 | 实际是什么 |
| --- | --- | --- |
| FlyMusic / Fly音乐Plus | com.yfoo.flymusic.plus | 本文档讲的这一个，音乐搜索与播放类 |
| Fly音乐 / FlyMusic 飞翔音乐 | com.flymusic.player | 另一个应用，名字几乎一样，包名不同 |
| fly music（应用宝里能搜到） | com.wpfflymt.qgnb | 音频视频剪辑制作类，和上面两个都不是同一个应用 |

另外还会遇到「flymusic音乐剪辑」「Fly音乐播放器」「Fly音乐App」这类写法，它们分别指向上面几个包中的某一个，光看名字分不出来。**遇到任何介绍页，先找它标的包名，再决定要不要照着它的教程操作。**

## 三、怎么在自己手机上核对包名

- **已经装上的**：手机设置 → 应用 → 应用管理，点进 FlyMusic，在应用信息页看版本号；包名有的机型直接显示，有的要点右上角菜单或展开「应用详情」才看得到。
- **还没装的**：在文件管理里找到那个 `.apk`，用「查看详情 / 属性」看包名；或者装完之后按上一条核对。
- **核对什么**：版本号是不是 `1.3.2`，包名是不是 `com.yfoo.flymusic.plus`。两条都对，说明装的就是本文档配套的这一版。

写这一步不是为了形式 —— 装错应用时，后面所有按本文档做的操作都会对不上界面，套教程反倒更费时间。

## 四、官网地址的说法并不统一

公开页面对「官网」这一项的说法自相矛盾：有的页面填的是 `www.flymusicplus.com`，有的直接写「暂无」，两边的可信度都无从判断。因此：

- **不要用域名来判断是不是官方渠道**；
- 判断依据用第二节那张表 —— 包名 + 版本号 + 安装包 MD5，这三项能对上才是同一份东西；
- 想找官方发布页，从应用内的关于 / 设置页里给出的入口进，比在搜索引擎里认域名可靠。

## 五、版本号为什么每个页面都不一样

搜 FlyMusic 的版本号，能看到 1.0.7、1.1.1、1.2.6、1.2.13、1.3.0、1.3.1、1.3.2 一大串，原因有两个：

1. **同一个应用的不同历史版本同时挂在网上**，谁也没下架谁；
2. **第三方下载站会重新打包**：重新签名、塞入自己的渠道标识之后再放出，包的大小甚至 MD5 都变了 —— 同一版本号在不同站点上 MD5 完全不同，就是这么来的。

由此带来一条实用结论：**版本号要认，但别拿别处页面上的 MD5 当基准**。你手上这份的 MD5 是 `D3749FA07C6D987A4DDF22DDD7936FE4`，用它校验自己这次下载是否完整；在别的站点下的包 MD5 不一样是正常的，但那已经不是同一份文件。
