# FlyMusic 下载与安装教程

> FlyMusic 是一款安卓端的在线音乐应用，底部分成搜歌与管理两块：搜歌页搜歌名、歌手或专辑，搜到就能在线播放或下载到本地，管理页管本地文件与下载结果。本篇讲清安装包从哪取、手机上怎么装、装完第一次打开先做什么。

## 一、装之前先对一下这张表

公开渠道里放出的安装包只有安卓一种，没见到 iOS 版，也没见到 Windows / macOS 客户端。动手之前，先对着下面这张表确认自己设备合不合适：

| 项目 | 这一版的情况 |
| --- | --- |
| 软件名 | FlyMusic（中文页面多写作「Fly音乐Plus」） |
| 版本号 | 1.3.2 |
| 包名 | com.yfoo.flymusic.plus |
| 安装包大小 | 14.45 MB（15,144,870 字节） |
| 安装包 MD5 | D3749FA07C6D987A4DDF22DDD7936FE4 |
| 适用设备 | 安卓手机 / 安卓平板 |
| 系统要求 | 各页面口径不一致，见下 |

有两件事值得先说明：

1. **系统要求没有统一说法。** 第三方介绍页上出现过「安卓 4.0」「安卓 4.3 以上」「安卓 4.5 以上」「安卓 5.2 以上」四种写法，互相矛盾。其中「安卓 5.2」这个版本号安卓官方并没有对外发布过（公开版本从 5.1 之后直接到 6.0），这一条按「Android 5 系及以上」理解就行。真正能不能装，以你设备上点下去之后的提示为准。
2. **版本号以本页表格为准，别跟介绍页里的数字比。** 同一款应用在不同下载页上挂的版本号从 1.0.7 到 1.3.2 都有。各页面为什么差这么多、怎么核对，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 二、从网盘把安装包取出来

1. 打开 [FlyMusic 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cec4eb24135c)。手机、电脑上都能操作，用夸克 App 打开更稳。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存之后，下载就不再依赖原分享链接是否还在。
3. 分两种情况取包：
   - **直接装到手机上**：在网盘 App 里下载，文件会落到手机的「下载」目录。
   - **先存电脑再传手机**：电脑端下载后用数据线或聊天工具传过去。安卓的安装包在电脑上不能双击运行，最终还是要回到手机上装。
4. 下完核对两件事：文件名结尾是不是 `.apk`；MD5 是不是 `D3749FA07C6D987A4DDF22DDD7936FE4`。对不上就删掉重下 —— 安卓装到一半报「解析包错误」，绝大多数是包没下完整或被传坏。

## 三、手机上的安装步骤

这个安装包不是你从手机自带软件商店里下下来的，安装时系统会拦一下，属于正常现象，不代表文件有问题。

1. 打开手机的「文件管理」，进 `Download`（下载）目录，找到刚下好的安装包，点它。
2. 系统弹出「不允许安装来自此来源的应用」之类的提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要绕一层：设置 → 应用 → 特殊应用权限 → 安装未知应用，在里面找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」，别急着打开，把下面的权限一次性给对，进去之后就不会反复弹窗。

装完桌面或应用列表里会出现 FlyMusic 的图标。图标没出现的话，先到应用列表里搜一下名字，再按 [常见问题与排查.md](常见问题与排查.md) 第一节往下查。

## 四、装完第一次打开要做的几件事

1. **先认清底部导航**。整个应用的主干就几项：一项是搜歌（有的版本写作「找歌」），一项是管理。后面所有操作都从这两处进，找不到功能时先回想它该归在哪一块。
2. **库里一开始是空的**。这不是故障。想听的歌要么在搜歌页搜出来在线放，要么先把文件放进手机再导进来，见 [歌单收藏与本地音乐管理.md](歌单收藏与本地音乐管理.md)。
3. **先搜一首试播**。在搜歌页输入歌名或歌手，点结果即可播放，具体写法与提高命中率的技巧见 [搜索歌曲与音质下载.md](搜索歌曲与音质下载.md)。
4. **要下载就回搜歌页操作**。下载入口在搜歌结果那一行，播放界面里通常没有，这是第一次用最容易卡住的地方，具体见 [搜索歌曲与音质下载.md](搜索歌曲与音质下载.md) 第四节。
5. **想要桌面歌词，还得单独授权一次**。这是第二个包，不给权限歌词不会出现在桌面上，见 [桌面歌词与播放设置.md](桌面歌词与播放设置.md)。

## 五、装不上时先查哪几处

- 提示「解析包错误」→ 包没下完整，回网盘重下，用 MD5 核对。
- 提示「应用未安装」→ 设备上可能已经装了同包名的旧版、且签名对不上；先卸载旧版再装。
- 提示「系统版本过低」→ 这台机器的安卓版本低于应用要求，换设备或用模拟器，别在原机上硬试。
- **系统直接拒绝安装、又不说原因** → 在很新的安卓系统上装较老的第三方安装包会遇到这一条：Android 14 起会拦下目标 API 级别低于 23 的应用，Android 15 起门槛提到 24。这类拦截在原机上绕不过去，只能换一台系统版本低一些的设备来装。
- 想更新到新版本 → 从同一处重新取一份较新的安装包，直接覆盖安装即可，不必先卸载。若是提示「应用未安装」，说明新旧两份的签名不一致，那就得先卸载旧版再装 —— 卸载会一并清掉应用内的记录与列表，动手前先确认要留什么。
- 点安装包完全没反应 → 打开安装包的那个 App 没拿到「安装未知应用」权限，见第三节第 2 步。
- 装了但打开就闪退 → 先把同名的旧版卸载干净再装一次；仍然闪退的排查顺序见 [常见问题与排查.md](常见问题与排查.md)。

装完确认能启动之后，建议先按 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 核对一下包名与版本号，确认装到的确实是这一个应用 —— 名字相近的安卓应用不止一个。
