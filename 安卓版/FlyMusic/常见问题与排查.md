# FlyMusic 常见问题与排查

> 装不上、搜不到歌、能搜到点不动、下载老是失败、桌面歌词不出来、本地文件导不进去、打开就闪退 —— 按现象查，每条都给出先做哪一步、做完还不行往哪走。

多数问题不是应用坏了，而是网络波动、权限被拦、系统省电限制或文件本身的问题造成的。下面按你看到的现象分组。

## 一、装不上

| 现象 | 先做什么 |
| --- | --- |
| 点了安装包没反应 | 给打开安装包的那个应用开「安装未知应用」权限，再点一次 |
| 提示「应用未安装」 | 手机里已有同包名、签名不同的旧版，先卸载旧的再装 |
| 提示「解析包错误」 | 安装包没下完或下坏了，删掉重新下载完整的一份 |
| 提示「系统版本过低」 | 这台机器的安卓版本低于要求，换设备或用模拟器 |

需要重新取一份安装包时，回 [FlyMusic 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cec4eb24135c) 转存后重新下载，版本与 MD5 的核对步骤见 [下载与安装教程.md](下载与安装教程.md) 第二节。

## 二、装完发现界面跟教程对不上

先核对包名，而不是继续照着改设置。公开渠道里名称接近的音乐类应用不止一个，装到另一个上去，界面自然处处对不上。包名核对的方法、本文档对应的包名与版本号，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 第三节。

确认包名对、界面仍与描述有差别，属于版本差异 —— 同一应用的新旧版本在菜单措辞和入口位置上会调整，按界面上实际看到的找对应功能即可。

## 三、搜不到歌，或搜出来很少

按这个顺序换，一般到第二步就有结果：

1. **换关键词写法**：歌手名 + 歌名一起填；把 `（Live）`、`伴奏`、`remix`、`feat.xxx` 这类后缀删掉再搜。
2. **换繁简和别名**：同一首歌在不同收录方手里标题写法不一样。
3. **取消搜索、重进搜歌页再搜一次**，避免上一次请求还挂着。
4. **换网络**：Wi-Fi 与移动数据互切一次。
5. **确认搜的是内容不是本地文件**：搜歌页搜的是在线内容，本地文件要在管理页看，见 [歌单收藏与本地音乐管理.md](歌单收藏与本地音乐管理.md) 第四节。

完整的搜索技巧与换词顺序见 [搜索歌曲与音质下载.md](搜索歌曲与音质下载.md) 第二节。

## 四、能搜到但点不动、播到一半断

这是最常遇到的一类，处理顺序固定：

1. **换一条搜索结果**（最有效）。同一首歌常有多条记录，某一条不通很常见；
2. 退出播放页重进，或切到另一首再切回来；
3. 换网络，关掉代理类工具；
4. 关掉系统对 FlyMusic 的省电限制，允许后台运行；
5. 清一次缓存（设置 → 应用 → FlyMusic → 存储 → 清除缓存，**不要清数据**，会丢本机记录）；
6. 确认存储空间没接近占满。

「等很久才开播、播几秒又停」也归到这条，多数属于来源侧波动，换一条记录就能绕开。

## 五、下载失败，或下完了找不到文件

| 现象 | 先做什么 |
| --- | --- |
| 在播放页里找不到下载按钮 | 多数情况下下载入口在搜歌页的结果菜单里，见 [搜索歌曲与音质下载.md](搜索歌曲与音质下载.md) 第四节 |
| 点了下载没反应 | 换网络后重试；退出搜歌页重进再下一次 |
| 进度长时间不动 | 换到文件列表里的另一条记录再下一次 |
| 提示失败 | 看手机剩余空间，先清一批再试 |
| 下完了列表里看不到 | 下拉刷新管理页；仍在的话退出应用重进 |
| 应用里能看到、手机文件管理器里找不到 | 正常现象，文件在应用自己的目录里，Android 11 起文件管理器默认进不去，见 [下载下来的歌在手机里怎么找.md](下载下来的歌在手机里怎么找.md) |

## 六、桌面歌词开了不显示

先按这个顺序查：悬浮窗（显示在其他应用上层）权限 → 系统省电与后台限制 → 是不是锁屏状态 → 播放是否正在进行。逐项对照见 [桌面歌词与播放设置.md](桌面歌词与播放设置.md) 第二节。四项都正常时，把桌面歌词关掉再开一次。

## 七、本地音乐加进去不显示

先确认导入动作做全了 —— **选完文件必须长按、再点顶部出现的「打开」**，只是选中返回是加不进来的，步骤见 [歌单收藏与本地音乐管理.md](歌单收藏与本地音乐管理.md) 第四节。动作没问题再从这四项里找：存储权限、文件所在目录太深、文件名带特殊字符、格式不在支持范围。

## 八、打开就闪退、用一会儿变卡

1. 先确认装的是包名为 `com.yfoo.flymusic.plus` 的那一份；
2. 清一次缓存后重开；
3. 卸载重装 —— 重装前先确认账号与歌单是否需要保留；
4. 检查剩余存储空间，接近占满时应用起不来很常见；
5. 有零星用户反馈过搜索与播放时出现卡顿、闪退；反馈条数很少，具体原因无法断定，遇到时先按换记录、换网络的顺序绕开，等版本更新再看是否改善。

## 九、什么时候才该怀疑是应用本身的问题

满足下面两条以上，才值得按版本问题处理（等更新，或换一版重装）：

- 换记录、换网络、换设备都不行，且只在这一个应用上出问题；
- 同一个版本在别人的机器上表现一致；
- 现象出现在某次更新之后，之前是好的。

只是某一首歌、某一条记录、某个时段不行，属于来源侧波动，不是你的设备或应用的问题，换一条记录即可。
