## 一、我在AI 是什么

我在AI 是南京有零科技有限公司出的一款手机应用，把 AI 角色聊天、互动小说剧情、自定义智能体创作和工作学习辅助装进了一个 App。你既可以找现成的智能体直接聊，也可以自己创建角色给别人玩。本篇只负责帮你把它装上并登录成功，装好之后怎么玩见 [角色聊天与剧情玩法.md](角色聊天与剧情玩法.md)。

| 项目 | 信息 |
| --- | --- |
| 应用名 | 我在AI |
| 开发者 / 运营者 | 南京有零科技有限公司 |
| 包名 | `com.chat.qsai` |
| 平台 | 安卓、iOS（iPhone / iPad） |
| 官方分发渠道 | 应用宝、苹果 App Store |

## 二、系统要求

| 平台 | 要求 |
| --- | --- |
| 安卓 | Android 5.2 及以上（第三方商店标注，具体以商店页面当时显示为准） |
| iOS | iOS 13.0 / iPadOS 13.0 及以上 |
| 安装包大小 | 69.43M（v3.1.9 安卓包实测值，其他版本会有出入） |
| 界面语言 | 简体中文、英语 |

安卓包接近 70M，建议在 Wi-Fi 环境下下载；安装后首次启动还需要联网加载角色与剧情内容，纯离线是用不了的。

## 三、从哪里拿安装包

**方式一：网盘获取** —— 你在找的那份安装包就在 [我在AI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/27564de9b2c9) 里，打开链接转存或直接下载 `.apk` 文件即可，版本为 3.1.9。

**方式二：官方应用商店**（会自动装、自动更新）：

- 安卓：[应用宝详情页](https://sj.qq.com/appdetail/com.chat.qsai)
- iOS：[苹果 App Store 页面](https://apps.apple.com/cn/app/%E6%88%91%E5%9C%A8ai/id1672909798)

两条渠道拿到的都是同一个应用（包名一致），区别只在版本推送节奏。想固定用某一版（比如网盘里这份 3.1.9），就走方式一。

## 四、安卓安装步骤

1. 用手机浏览器打开上面的网盘链接，下载 `我在AI_v3.1.9.apk`（或你选的其他版本）。
2. 在文件管理器里点这个 `.apk` 文件开始安装。
3. 如果系统弹出「不允许安装来自此来源的应用」，这是安卓对非商店渠道的默认拦截 —— 按提示进入设置、允许本次安装来源，装完可以再关掉。
4. 安装完成后桌面会出现「我在AI」图标，点开即用。

下载后若提示文件损坏装不上，重新下载一次通常就好；判断文件是否完整的办法见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 五、首次启动与登录

1. 打开应用，进入登录页。
2. 输入手机号、点获取验证码，把收到的短信验证码填进去即可登录。
3. 登录成功后你会看到底部三个入口：**首页**（逛角色和故事）、**对话**（你聊过的都在这）、**创建**（自己做智能体）。

收不到验证码是最常见的第一步卡点，别急着重装 —— 短信拦截、频繁点获取都会导致收不到，排查方法在 [常见问题与解决方法.md](常见问题与解决方法.md)。

登录进去之后，挑一个角色开聊的具体操作，见 [角色聊天与剧情玩法.md](角色聊天与剧情玩法.md)。
