## 一、登录收不到短信验证码

按出现概率从高到低排查：

1. **被短信拦截了** —— 手机的骚扰拦截、第三方安全软件常把验证码短信当垃圾短信吞掉。查一下短信拦截记录，把对应号码加白名单。
2. **点得太勤触发限流** —— 短时间内反复点「获取验证码」，服务端会直接丢弃后续请求。等 60 秒倒计时走完再点一次；如果提示获取已达上限，等 24 小时再试。
3. **网络延时** —— 后台显示已发送但手机没到，多是运营商链路延迟，稍等或读秒结束后重新获取。
4. **手机号填错** —— 回上一步核对号码，别笑，这真的是高频原因。

以上都试过还是收不到，换个时间段再试；持续不行可通过应用内反馈或官方 QQ 群（729803691）反馈。

## 二、应用闪退或卡顿

实际用户反馈里闪退确实出现过，通用处理顺序：

1. 上滑清掉后台，重启应用；
2. 长按应用图标 → 应用信息 → 存储占用 → **清缓存**（注意别点「清除数据」，那会丢登录态与本地记录）；
3. 确认装的是最新版：商店渠道会自动更，手动装的 apk 需要自己下新包覆盖安装；
4. 还不行就卸载重装 —— 重新登录后聊天记录依赖云端账号，一般能恢复，但自建草稿类内容建议提前确认已提交。

## 三、对话里的词变成星号了

你或角色的输出里部分词语被替换成 `*`，这是平台的内容过滤机制在起作用，不是你的输入法坏了。应对方式：

- 换一种说法绕开被过滤的词，通常语义不受影响；
- 写自定义智能体人设时同理，避开敏感表述能减少过滤、也能提高审核通过率（详见 [创建自定义智能体教程.md](创建自定义智能体教程.md)）。

应用商店评论里有用户抱怨过滤偏严、误伤常见词 —— 这属于平台统一策略，个人端没有开关可关。

## 四、自己创建的智能体审核要等多久

提交后需要过审核才能用。应用内标注「3 个工作日」，但应用商店有用户反馈实际等待明显更长。这段时间角色不会消失：它躺在你的创建列表里，通过后自然可用。着急用就先聊现成角色（[角色聊天与剧情玩法.md](角色聊天与剧情玩法.md)），要催进度走 QQ 群联系。

## 五、界面里怎么还有广告

不同版本、不同渠道装出来的表现不一致 —— 应用商店的检测信息标注过「无广告」，但不少用户评论反馈更新后界面出现了广告位、且容易误触。你在哪个版本里看到广告，以那个版本的实际表现为准；误触进了推广页直接返回即可。通知推送嫌多的话，可以在系统设置里关掉该应用的通知权限。

## 六、会员与内购

我在AI 免费安装，但应用内提供付费项（是否需要、价格多少以你安装版本的页面显示为准）：

- **iOS 端会员**：App Store 页面标注连续包月 18 元/月、连续包季 50 元/季；
- **iOS 端单次内购**：复活卡 x1 为 1.00 元、x5 为 2.80 元，灵感卡 x5 为 2.80 元（App Store 商品列表价，以页面当时显示为准）；
- **取消自动续订（iOS）**：设置 → 通用 → iTunes Store 与 App Store → Apple ID → 查看 Apple ID → 订阅 → 选中我在AI → 取消订阅。**要在当前周期到期前 24 小时以上关闭**，否则会再扣一轮。

订阅规则与隐私政策的链接在应用内「会员」页和商店页面里都有，以页面当时提供的版本为准。安卓端的付费入口与 iOS 不完全相同，见到支付确认前先看清计费周期。

## 七、其他零散问题

| 现象 | 处理 |
| --- | --- |
| 装包时提示解析错误 | 安装包没下完整，重新下载（见 [下载与安装教程.md](下载与安装教程.md)） |
| 拿不准装的是不是正版 | 进系统设置 → 应用管理 → 我在AI，看包名是否为 `com.chat.qsai`；不是就是下错了 |
| 聊着聊着角色脱离人设 | 重发一条更明确的指令把它拉回来，或重新点开该角色开新对话 |
| 登录后历史对话不见了 | 确认换回了同一个手机号账号；换号登录是两套记录 |
| 想反馈 bug / 催审核 | 官方 QQ 群 729803691，或应用内的反馈入口 |
