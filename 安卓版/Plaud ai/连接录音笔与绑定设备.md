## 一、绑定前先检查四件事

设备搜不到、连不上，绝大多数是下面四条没满足，先逐条核对：

1. App 已装好，且蓝牙、位置权限已按 [下载与安装教程.md](下载与安装教程.md) 第四节设置过。
2. 手机蓝牙总开关已打开。
3. 录音笔有电（电量很低时灯会闪紫色，先充电）。
4. 这台录音笔还没被别的账号绑走（二手或家人用过的设备尤其注意，见第五节）。

## 二、注册并登录账号

打开 App，在登录页注册或登录：

- **邮箱注册**：输入邮箱 → 收验证码 → 设置 6~16 位密码。收不到验证码时先翻邮箱的垃圾/广告文件夹，还不行就换一个邮箱再试。
- 不同版本的 App 也提供用 Google 或 Apple 账号直接登录的入口，能不能用、显示在哪以你手机上的 App 实际界面为准。

App 界面语言跟随手机系统语言，支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语。

## 三、绑定设备的步骤

1. 短按录音笔正面的录音键开机，设备白灯开始闪烁，表示处于待连接状态。
2. 在 App 里点左上角的「Connect（连接）」。
3. 等 App 搜出你的设备，选中并点连接，绑定完成。

两个常见疑问：

- **还没绑就按了录音键怎么办**：设备没绑定账号时按录音键，白灯会一直闪，不影响后续绑定，按上面步骤绑即可。
- **录音不需要每次都重新连接**：设备是独立录音的，绑一次就行，之后录完音 App 连上时录音文件会自动同步过来（同步细节见 [录音与电话录音操作.md](录音与电话录音操作.md)）。

## 四、指示灯对照表

录音笔只有一个指示灯，状态含义官方用户手册写得很全，抄成对照表如下（以 Plaud Note 为例，其他型号基本一致）：

| 灯的状态 | 含义 |
| --- | --- |
| 白灯闪烁（约 30 秒） | 未绑定账号，等待连接 |
| 白灯常亮（约 5 秒） | 已绑定账号 |
| 紫灯闪烁（约 5 秒） | 电量低 |
| 紫灯常亮 | 充电中 |
| 绿灯常亮 | 充电完成 |
| 红灯常亮 | 录音中 |
| 蓝灯闪烁 | Wi-Fi 已开启，等待连接 |
| 青灯闪烁 | 固件（FOTA）更新中 |
| 黄灯闪烁（约 5 秒） | 存储空间已满 |

看到黄灯说明录音已存满 64GB 的本地空间，需要在 App 连接同步后清理旧录音，否则设备会停止写入新录音。

## 五、一个账号可以绑多台设备

同一个 PLAUD 账号下可以绑定多台录音笔。进入 App 的「My（我的）」页面，在「My PLAUD NOTE」之类的设备列表里能看到这台账号名下的所有设备。

如果搜不到自己的设备、或者提示已被绑定，多半是它已经挂在别人的账号下，处理思路写在 [常见问题排查.md](常见问题排查.md)。绑定顺利的话，直接去 [录音与电话录音操作.md](录音与电话录音操作.md) 开始录第一段。
