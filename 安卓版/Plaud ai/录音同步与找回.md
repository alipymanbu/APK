## 一、录音文件走的是哪条路

一段录音的旅程分三站，卡在任何一站都会表现为「找不到」：

1. **设备本地**：录音先存在录音笔的 64GB 存储里。
2. **手机 App**：设备连上 App 后自动传输过来。
3. **云端与网页端**：App 开启 Private Cloud Sync（私有云同步）后，录音再上传到你的 PLAUD 云端，网页版和桌面版才能看到。

一个常见误会：把录音笔用线插到电脑上，期望像 U 盘一样翻出录音文件——看不到是正常的，设备的存储不这样暴露，录音只能通过 App 读取。

## 二、App 里等不到新录音，先在安卓端做这几步

安卓端的传输逻辑和 iPhone 有差别：Note Pro 的「自动传输」（不开 App 也能后台传）是 iOS 专属功能，安卓端录音要等你打开 App、设备连上后才开始传。所以：

1. 打开 App，等设备连接成功，让 App 保持前台几分钟，传输完成后录音列表才会出现新条目。
2. 设备支持 Wi-Fi 时，可在 App 的传输设置里开 Wi-Fi 快传，比纯蓝牙快得多；快传失效时先按官方支持页的快传排查步骤处理，或直接退回蓝牙传，别卡死在这一步。
3. 传输瞬间别拔设备、别杀 App；一次长录音（几小时）传完需要的时间不短，看着没动就多等一会。

如果设备电量彻底耗尽后才充电，设备内部时钟会停走，传出来的录音日期时间可能错乱——找不到「今天」的录音时，按录音时长排序翻一翻前几天的条目。

## 三、App 里有，网页版 / 桌面端没有

官方支持页给的排查顺序：

1. **确认网页端登录的是同一个账号**（邮箱、Google、Apple 登录方式混用最容易登错号）。
2. **在手机 App 里开启 Private Cloud Sync**：不开这个开关，录音只停在手机里，不会上云。
3. **刚录完的条目上传要几分钟**：App 保持联网开着，等传输完成再刷新网页端；还不行就退出网页端重新登录。
4. **公司网络与防火墙可能拦掉同步**：换手机热点试一次，能同步就是网络问题。

## 四、录音找不到了的排查清单

按官方支持文章的思路，出问题先过这五条：

| 检查点 | 怎么做 |
| --- | --- |
| 当时真录上了吗 | 回忆当时是否感到「1 次振动」（开始录音的反馈），没振过就是没录 |
| 按时长找 | 在文件列表里按录音时长对照翻找，别只看日期 |
| 日期错乱 | 设备曾彻底没电的话，录音可能挂在错误的日期下，翻前后几天的条目 |
| 登错账号 | 手机里有多个 PLAUD 账号时，确认登录的是设备绑定的那个 |
| 查转写记录 | 如果那段录音转过文字，在 App 的 Usage history（使用记录）里按消耗记录找 |

五条都落空再联系官方客服，一次性附上账号邮箱、设备型号、录音的大致时间与时长、App 版本，少一轮来回。

## 五、换手机时录音怎么办

新手机装 App 登录同一账号，云端有备份的录音会跟着账号走；设备本身重新连一次 App 即可。旧手机里只存在本地、还没上云的录音，先按第三节把 Private Cloud Sync 打开传完，再处理旧手机——顺序别反。

卸载 App 的数据风险与充电、地区服务等问题，集中在 [常见问题排查.md](常见问题排查.md)；录音到齐之后，转文字的操作见 [转文字与摘要生成.md](转文字与摘要生成.md)。
