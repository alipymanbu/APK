## 一、先有一个可以聊的角色

登录后进入聊天页就能开始对话。想按自己的想象来，就走角色定制：可自定的范围包括外貌、性格、背景故事、互动场景，以及你们之间的关系与称谓（关系怎么定、怎么改都由你说了算）。角色资料补充得越具体，对话里 ta 的言行越贴你的设定。

角色聊久了记下的东西、以及它写的故事日记，见[记忆功能与角色故事.md](记忆功能与角色故事.md)。

## 二、聊天时能做什么

| 你想做的事 | 对应操作 |
| --- | --- |
| 日常文字聊天 | 输入框直接发消息，支持一次连发多条 |
| 发表情包 | 聊天框里的表情入口 |
| 发图片 | 从手机相册选图发送 |
| 发语音消息 | 按住说话（需要麦克风权限） |
| 语音通话 | 聊天页的通话入口（需要麦克风权限） |
| 自定义聊天气泡 | 在聊天设置里换气泡样式 |
| 收角色主动发来的消息 | 角色会主动找你，前提是给了应用通知权限 |

以上为 1.4 系列已具备的功能；个别入口的名称与位置随版本微调，以应用内实际显示为准。

## 三、角色状态与时间

- 角色有在线 / 忙碌状态，不是随时都秒回。
- 忙碌时的回复速度分三档可调——嫌角色回得慢，就把这一档调快。
- 角色的时钟与现实世界同步，目前对的是北京时间：你深夜发消息，角色也知道是深夜。人在海外时区使用时留意这一点，角色口中的「现在」是北京时间。

## 四、动态：像朋友圈一样记录

角色会发动态，你也可以发——倾诉情绪、分享日常都落在动态流里，翻起来像看朋友圈。想管理角色自动记下的内容（编辑或删除记忆），见[记忆功能与角色故事.md](记忆功能与角色故事.md)。
