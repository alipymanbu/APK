# DreamLove 常见问题排查

> 汇总 DreamLove 最常碰到的几个问题：登录不上、回复异常、语音通话不可用、收不到通知，以及版本与数据的判断。

## 一、登录不上或一直转圈

1. 先确认手机能正常上网——应用需要联网才有回复。
2. 提示密码错误：如果你这版是自定义用户名密码登录，除了真的输错，还有一种可能是这个用户名已被别人占用——换一个用户名再试。
3. 密码忘了：有用户反馈目前没有找回密码的入口，只能换个新用户名重新开始；这更说明注册时要把密码记牢。
4. 还是进不去：卸载后重装一次（安装包获取见[下载与安装教程.md](下载与安装教程.md)），用同一账号登录。

## 二、发消息没有回复 / 回复特别慢

- 角色有在线与忙碌状态，忙碌时回复会变慢；到聊天设置里把忙碌回复速度调快一档。
- 聊天会消耗「梦元」——这是应用内的代币，耗尽时对话就发不出去。怎么领、怎么省，专门写了一篇：[梦元获取与消耗.md](梦元获取与消耗.md)。

## 三、语音与通话不可用

- 语音通话是 1.2.9 加入的，语音消息是 1.3.5 加入的；更老的包没有这些入口，先确认版本。
- 发语音、打通话需要麦克风权限：系统设置 → 应用 → DreamLove → 权限，允许麦克风。

## 四、收不到角色主动发来的消息

角色主动发消息依赖系统通知。安卓 13 及以上，装完应用默认不发通知，需要到 设置 → 通知 里手动允许 DreamLove 发通知；应用内的通知开关也要打开。

## 五、版本太老，找不到新功能

功能是随版本逐步加进来的，对照下表判断你的版本该不该有：

| 功能 | 加入版本（官方更新日志） |
| --- | --- |
| 虚拟转账 | 1.2.3 |
| 语音通话、每日领梦元 | 1.2.9 |
| 记忆与故事的编辑删除、关闭角色主动发言 | 1.3.0 |
| 签到领梦元、互拍领梦元 | 1.3.2 |
| 语音消息 | 1.3.5 |
| 小剧场 | 1.6.0 |

注：上表按官方（iOS 端）更新日志整理，安卓端的上线节奏可能略有先后，以应用内实际为准。想升到官方最新版，走[下载与安装教程.md](下载与安装教程.md)里的官方渠道。

## 六、换机、重装后数据还在吗

角色、记忆这些数据跟账号走：换机或重装后用同一账号登录即可。登录后发现记忆缺失，先看[记忆功能与角色故事.md](记忆功能与角色故事.md)里记忆的查看与编辑办法；仍解决不了，通过官方渠道反馈。
