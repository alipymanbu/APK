## 一、免费版能用到什么

你不订阅也能用，但每一类功能都有限额。按官网订阅页列出的口径，免费版每天的额度大致是：

| 功能 | 免费版限制 |
| --- | --- |
| 学TA修图 | 限时限量体验 |
| 指令修图（语义修图） | 限量体验 |
| 灵感广场预设 | 每天限量体验 |
| 修图张数 | 每日赠送一定张数 |

这几个「限量」的具体数值官方页面没有写死，会随活动调整，以你打开应用时显示的剩余次数为准。轻度使用（每天修几张人像）免费额度基本够；一旦要批量出片，额度会很快用完。

## 二、订阅解锁什么

官网把订阅分成月度与年度两档，权益基本一致，差别在赠送的「学我修图」模型训练次数：

| 权益 | 说明 |
| --- | --- |
| 学我修图模型 | 月方案赠送 1 次训练、年方案赠送 3 次，不满意可免费重新训练 |
| 学TA修图 | 解锁全部风格，不限量畅修 |
| 灵感广场预设 | 随心用，每周更新 |
| 指令修图 | 每月可修 3000 张 |
| 批量修图 | 多图同时处理 |
| 导出 | 无水印、无限导出 |

另外，近期的版本更新日志里官方还在持续加额度（比如 1.25.x 那次更新写明「会员权益升级：解锁更多额度套餐，支持更多批量修图」），订阅前顺手看一眼当前版本内的权益列表。

## 三、价格参考

按 2026 年 9 月官网与 App Store 页面显示的口径（以应用内订阅页当时显示为准，活动期常变动）：

| 方案 | 国内（picchi.cn / App Store 中国区） | 国际版（picchi.ai） |
| --- | --- | --- |
| 连续包月 | ¥28/月（页面标注原价 ¥38） | $14.99/月（标注原价 $19.99） |
| 包年 | 约 ¥218/年（页面标注原价 ¥298） | 以国际站页面为准 |

支付渠道按官网常见问题的口径：主流信用卡、借记卡，以及 App Store / Google Play 提供的官方本地支付渠道；国内安卓用户实际走应用内支付页。

## 四、怎么取消订阅

- **iOS**：打开系统「设置」→ 点顶部你的 Apple 账户 → 「订阅」→ 找到 Picchi → 取消订阅；
- **Android**：在应用内「我的 / 会员」相关页面按提示取消自动续费，具体入口以当前版本界面为准。

取消后当期权益继续有效，到计费周期结束才停止 —— 这是官方常见问题页给出的口径。

## 五、订阅前想清楚的三件事

1. 你主要用「学TA修图」套现成风格，还是想训练自己的「学我修图」模型？前者月付就够，后者要注意赠送的训练次数差异；
2. 月修 3000 张的上限对个人用户通常用不完，但对带货、写真实多人像批量场景要心里有数；
3. 连续订阅默认自动续费，不想续就在到期前取消，见上一节。

额度用完、扣费有疑问之类的具体问题，去[常见问题与故障排查.md](常见问题与故障排查.md)对号入座；两种核心玩法的操作思路见[学我修图与学TA修图怎么用.md](学我修图与学TA修图怎么用.md)。
