# EtchDroid 制作启动盘完整步骤

> 从插 U 盘到写完拔盘，整个流程在手机上就能走完，全程不需要电脑参与，也不用 root。

## 一、先把这五样东西凑齐

| 准备项 | 要求 |
| --- | --- |
| 安卓手机 | 支持 OTG；还没装应用的话先看 [下载与安装教程.md](下载与安装教程.md) |
| U 盘 | 容量不小于镜像文件；**里面的数据会被整盘清空**，先备份 |
| OTG 转接头 | Micro-USB / Type-C 转 USB-A，双头 Type-C U 盘可省 |
| 系统镜像 | 提前下载到手机存储；ISO 或 IMG 格式（哪些镜像能写见 [支持的镜像与设备清单.md](支持的镜像与设备清单.md)） |
| 电量 | 写盘中途手机断电会导致写入失败，开始前把电留足 |

镜像文件可以直接在手机浏览器里从发行版官网下载（Ubuntu、Debian、Fedora 等都有手机可访问的下载页），2 GB 左右的镜像注意留够手机存储。

## 二、写盘四步

以下以 1.5.1 的界面为准（2.x 界面重做过，但流程一致）：

1. **插上 U 盘**。手机可能弹出「是否允许应用访问 USB 设备」的系统确认框，点允许；有的系统还会弹出文件管理跳转，忽略即可。
2. **打开 EtchDroid，选镜像**。主界面点「Write image」（写镜像），在文件选择器里选中提前下好的 ISO/IMG 文件。文件在下载目录找不到时，用选择器侧边栏切到「下载」或你存放的位置。
3. **选中目标 U 盘**。列表里会出现刚插上的 U 盘，点它。
4. **确认并等待写完**。确认覆盖后开始写入，进度在应用内和通知栏都有显示。写入期间尽量别操作手机、别拔盘、别从后台划掉应用。速度取决于 U 盘和镜像大小，几 GB 的镜像写上十几分钟很正常。

写完后拔下 U 盘。**这时候手机和电脑大概率都「打不开」这个 U 盘，甚至提示 U 盘损坏——这是正常现象**，不是写坏了，原因和处理见 [常见问题解答.md](常见问题解答.md)；用完想把 U 盘恢复成普通存储盘，四平台的格式化步骤见 [写完的U盘怎么恢复.md](写完的U盘怎么恢复.md)。

## 三、拿去目标电脑启动

1. U 盘插进要装系统的电脑。
2. 开机时按启动菜单键（常见 F12 / F9 / Esc / Del，以机型为准）或进 BIOS 设置，把启动顺序切到 U 盘。
3. 出现 Linux 发行版的启动菜单即成功，后面的安装跟着发行版安装器走即可。

## 四、几个容易翻车的点

- **树莓派镜像要先解压**：官方提供的多为 `.img.xz` 压缩包，先用解压应用解出 `.img` 文件再写，直接选压缩包会失败。
- **U 盘插上没反应**：换转接头、换 U 盘试一次；还不行就完全重启手机再插。部分老机器需要在系统设置里手动打开 OTG 开关。
- **写入中断失败**：多半是 U 盘质量或供电问题，换一个 U 盘或插在手机上不接其他耗电外设再试。
- **想写 Windows 官方 ISO**：直接写是启动不了的，这不是操作问题，详见 [支持的镜像与设备清单.md](支持的镜像与设备清单.md) 里的说明。
