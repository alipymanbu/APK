# 写完的 U 盘怎么恢复成日常用的存储盘

> 用 EtchDroid 写过系统镜像后，U 盘在手机和电脑上往往「读不出来」甚至被提示损坏。这篇讲清楚原因，以及怎么在手机、Windows、Linux、Mac 上把它格式化回来。
> **相关文档**：[常见问题解答.md](常见问题解答.md) · [制作启动盘完整步骤.md](制作启动盘完整步骤.md)

## 一、U 盘没坏，只是系统「不认识」

多数系统镜像的分区表和文件系统（比如 Linux 镜像常用的 ISO9660 一类布局）本来就是给启动用的，安卓和 Windows 平时都不认这种格式，所以写完之后插上去要么没有盘符，要么弹出「U 盘有问题 / 需要格式化」的提示。**镜像本身没写坏，拿去目标电脑照样能启动**；一些安卓版本还会常驻一条「USB 设备不受支持」的通知，同样可以忽略。

想让它重新当普通 U 盘用，格式化一遍就行。以下方法按省事程度排序，官方在恢复指南里也是这个建议顺序（指南地址：`https://etchdroid.app/broken_usb/`）。格式化会清掉 U 盘上所有内容，动手前确认里面没有要留的东西。

## 二、在手机上格式化（最省事）

1. 退出 EtchDroid，把 U 盘插回手机。
2. 点开系统弹出的「USB 设备不受支持」或「U 盘有问题」通知，直接选格式化。
3. 没看到通知的话：打开**设置 → 存储**，点 U 盘的名称；如果跳到文件管理器，点右上角菜单 → **存储设置 → 格式化**。
4. 拔盘前先在存储设置里「弹出」，再拔。

## 三、在 Windows 上格式化

Windows 图形界面处理这种「无分区」的 U 盘经常灰掉格式化按钮，官方给的路径是先动命令行再回图形界面：

1. 开始菜单搜「命令提示符」，右键**以管理员身份运行**。
2. 输入 `diskpart` 回车。
3. 输入 `list disk`，记住 U 盘对应的磁盘编号——**这一步务必核对容量反复确认，选错盘会清掉别的硬盘**。
4. 输入 `select disk 编号`（比如 `select disk 1`）。
5. 输入 `clean` 清掉旧分区表。
6. 输入 `convert mbr` 建新分区表（用 `convert gpt` 也行，效果对普通使用没差别）。
7. 输入 `exit` 退出，关掉命令行窗口。
8. 打开「此电脑」右键 → **管理 → 磁盘管理**，找到刚才那块显示「未分配」的磁盘。
9. 右键它选**新建简单卷**，一路下一步，文件系统选 **FAT32**（兼容性最好；单个文件超过 4 GB 的需求就选 exFAT）。
10. 完成后 U 盘恢复出现在资源管理器里。

## 四、在 Ubuntu（GNOME 桌面）上格式化

1. 打开 Activities 搜「Disks」（磁盘）。
2. 左侧选中 U 盘；如果下面有带「播放」图标的卷，先点它再点「停止」。
3. 右上角菜单选**格式化磁盘**，默认设置确认即可（默认 MBR，想用 GPT 在这一步改）。
4. 点新建的「空闲空间」，按 **+** 号建新卷，大小保持默认。
5. 卷名随意，类型选「所有系统和设备通用（FAT32）」，确认创建。

其他 Linux 桌面找不到 Disks 的话，用 `mkfs` 类命令行工具，或者干脆按第二节的方法拿手机格。

## 五、在 macOS 上格式化

1. 打开「磁盘工具」。
2. 左侧选中 U 盘（选最上层的设备，不是它下面的卷）。
3. 点工具栏的**抹掉**。
4. 格式选 **MS-DOS (FAT)** 或 **ExFAT**，确认抹掉。

---

恢复好之后这个 U 盘就正常了，下次要做启动盘直接再写一遍即可，流程见 [制作启动盘完整步骤.md](制作启动盘完整步骤.md)。写完又「打不开」属于每次都会发生的正常现象，不用反复怀疑 U 盘质量；其他异常情况（列表里找不到设备、写入卡住）见 [常见问题解答.md](常见问题解答.md)。
