## 一、写完后手机提示「U 盘有问题 / 不受支持」

**直接忽略，这是正常现象。** 多数系统镜像用的分区表和文件系统安卓本来就不认识，系统照例弹个警告而已，镜像本身没写坏，拿去目标电脑照样能启动。

用完之后想把 U 盘恢复成日常存储盘，格式化一遍即可：

- **在手机上**：点开那条「U 盘有问题」的系统通知（没有就进 设置 → 存储 → 点 U 盘名称），选格式化即可，这是最省事的一条路。
- **在电脑上**：Windows 用磁盘管理删除全部分区后新建简单卷（文件系统选 FAT32 或 exFAT）；Linux 桌面用「磁盘」（Disks）工具格式化。

格式化前想清楚 U 盘上没有要留的东西，格式化是不可逆的。

## 二、列表里找不到 U 盘 / SD 卡

按顺序排查：

1. **换转接头再插一次**——OTG 头接触不良是最常见原因。
2. **老机型检查系统设置里的 OTG 开关**——部分品牌默认关闭。
3. **给树莓派写卡的用户注意**：手机**内部** SD 卡槽不会被识别，这是安卓系统的限制，官方也明确不通过 root 绕过；必须用「USB 读卡器 + SD 卡」的组合。
4. **树莓派镜像先解压**：`.img.xz` 压缩包直接选会失败，先解出 `.img` 文件。

## 三、一点 U 盘就卡住 / 应用无响应

多半是上一次写入中途崩溃，应用没来得及清理 USB 接口，接口状态不一致导致的。处理办法：拔掉 U 盘 → 完全退出应用（从后台划掉）→ 重新插上 U 盘 → 重新打开应用。

## 四、写入速度很慢，或者中途失败

- 写入速度几乎完全取决于 U 盘本身，手机上常见的十几分钟到半小时属于正常范围，太慢就换读写快一点的 U 盘。
- 中途失败多为 U 盘质量或供电问题：直插手机别经扩展坞、不要同时挂其他耗电外设，再不行换 U 盘。
- 写入后自动校验数据是官方 2.x 才加入的功能；1.5.1 写完没有这一步，重要的启动盘建议直接拿到电脑上试启动一次再收起来。

## 五、能用来装 Windows 吗

微软官方 ISO 写进去也无法启动（UDF 文件系统的原因，详见 [支持的镜像与设备清单.md](支持的镜像与设备清单.md)），这个应用的主战场是 Linux 发行版镜像和树莓派镜像。社区重制的 Windows 镜像官方明确提示可能夹带病毒，不建议碰。

## 六、需要 root 吗

不需要。应用全程走安卓系统提供的 USB 接口，官方 FAQ 里明确写了不要求 root、以后也不会加入这个要求，所以对手机系统没有任何改动风险。
