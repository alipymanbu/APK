Qiz 是一个以兴趣标签为核心的社交应用：填好自己的兴趣标签后，可以按语音、快速、同城等方式匹配聊天，也能在交友墙和兴趣广场里浏览、发布内容。它走的是手机端安装包路线，需要自己把 APK 装进手机。本篇只做一件事——把网盘里这份包装好并正常打开。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本信息通常是官方当时的最新发布版，与网盘里这份未必是同一个版本号。本文出现的版本号、包名、体积都以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Qiz |
| 版本号 | 1.0.1 |
| 包名 | `com.yueai.fori` |
| 安装包体积 | 57.12 MB |
| MD5 | `E0B35F5F039B38C058A76B0392AEAB69` |
| 适用平台 | Android（手机端 APK） |
| 开发者 | 海南悦爱科技有限公司 |

安装包本体在头部那条 Qiz 安装文件资源里，转存到自己网盘后下载即可。下面几点先说明白：

- **官方写法就是 `Qiz`**：首字母大写、后面小写。官网是 [www.yaqiz.cn](https://www.yaqiz.cn)，官方公众号名是 `QizApp`。在各应用市场里能搜到全大写或全小写的写法，指的都是它。
- **这份属于 1.0.x 系列**。网上还能搜到 2.x 的版本号，那是官方后来发布的新版，与网盘里这份不是同一版。本文只描述网盘里这一版；官方后续编号到哪一位，以官网当时显示的为准。
- **包名是 `com.yueai.fori`**。同名应用在不同渠道可能挂着别的包名，包名不同在系统里就会被识别成两个不相干的应用，**不能互相覆盖安装**，账号与本地数据也各算各的。装之前可以在「设置 → 应用 → 应用管理」里点进该应用核对包名。
- **版本号、包名、体积以网盘里这份为准**；系统要求、会员价格这类会变的信息，以官方页面当时显示的为准。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [Qiz 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8e5eb0126837)，在手机夸克 App 里打开最省事。
2. **先转存再下载**：选中安装包，转存到自己的网盘目录，再下载到本机。分享链接以后可能失效，转存过的那一份不受影响。
3. **确认下载完整**：下载完成后看一眼体积是否约 57.12 MB。中途断网重连后体积偏小的话，装的时候会直接报「解析包错误」。
4. **想校验完整性**：在电脑上对包算一遍 MD5，结果应当与上表一致。

```cmd
certutil -hashfile Qiz_v1.0.1.apk MD5
```

（文件名随版本变化，以网盘里实际提供的那份为准。）

## 三、安装步骤

1. **让文件管理器拿到安装权限**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，把用来打开 APK 的那个应用（文件管理器或浏览器）的开关打开。国产定制系统这项常收在「安全」或「隐私」分类下。
2. **点击 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续——这是侧载安装包的常规提示，不代表文件有问题。
3. **回装低版本要先卸载**：安卓不允许用更低版本覆盖更高版本，会直接报「应用未安装」。如果手机里已经装了更高的版本号，先卸载再装这份，卸载会一并清掉仅存在本机的数据。
4. **系统版本要对得上**：应用要求 **Android 7.0 及以上**（应用宝、豌豆荚当时标注，以官方页面为准）。系统过低时安装按钮可能点不动，或装上后打开即退。

## 四、第一次打开要确认的三件事

1. **能联网**：兴趣标签、匹配、广场内容都要走网络，卡在加载页时先在浏览器里确认手机能正常上网。
2. **能注册或登录**：第一次进入需要账号，主流做法是手机号加短信验证码。收不到验证码的排查见 [注册登录与账号设置.md](注册登录与账号设置.md)。
3. **能看到内容**：填完兴趣标签后，匹配页或广场里刷得出人像卡片与动态，说明数据侧通了。装好后别忘了按提示给通知、麦克风、定位这几项权限，不然语音匹配和「附近的人」用不起来，具体见 [权限与隐私怎么设置.md](权限与隐私怎么设置.md)。

## 五、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包下载不完整 | 核对体积与 MD5，从网盘重新下载一次 |
| 提示「应用未安装：签名不一致」 | 手机里已装同包名的另一个渠道版本 | 先卸载旧包再装；卸载前想清楚本机数据会一起没 |
| 点安装没反应，或安装到最后只报「应用未安装」 | 在回装更低的版本号 | 先卸载高版本，或直接装更高的那一版 |
| 安装被安全中心拦截 | 侧载安装包被系统安全策略拦下 | 在安全中心的拦截记录里选择「继续安装」 |
| 装上后打开就退 | 系统版本过低、内存不足或安装残缺 | 见 [常见问题与排查.md](常见问题与排查.md) |

后续换版本或重装，仍然从同一份 Qiz 安装文件资源里取用，取之前记得先核对版本号是否变了。
