官方文档不会告诉你的一件事是：**同一个问题走错渠道，可能等一周都没人理，也可能当时就解决**。比如付款争议找应用客服往往白等，因为钱根本不在应用这边收；而内容被删只有应用内有申诉入口。本篇按问题类型把路径排清楚。

## 一、四条官方渠道，各管一段

| 渠道 | 入口在哪 | 适合的问题 | 不适合的问题 |
| --- | --- | --- | --- |
| 应用内反馈 | 「我的 → 帮助与反馈」或设置里的反馈入口 | 账号登录异常、功能报错、内容审核申诉、举报处理进度 | 付款争议（钱不在应用侧收） |
| 官网联系入口 | [www.yaqiz.cn](https://www.yaqiz.cn) 页面底部的「联系我们」 | 商务合作、隐私相关请求、正式投诉 | 着急的账号问题 |
| 官方公众号 | 微信里搜索 `QizApp` | 看公告、活动通知、版本更新说明 | 需要快速一对一响应的问题 |
| 应用商店开发者页 | 商店里 Qiz 详情页的开发者信息 | 核对是不是官方主体、看更新日志 | 处理具体工单 |

## 二、按问题类型选渠道

- **扣费了会员没生效、想退款** → 找付款渠道，不是找应用客服。苹果走「设置 → Apple 账户 → 购买记录」里的申诉入口，微信、支付宝走各自的交易投诉。理由见 [会员与金币怎么算.md](会员与金币怎么算.md)。
- **登录不上、收不到验证码** → 走应用内反馈，说明手机号与收不到的时间点。**别只写「登不上」**，客服无法据此定位。
- **内容被删、账号被限制** → 走应用内申诉，附上被判违规的那条内容截图。
- **要行使查、删、注销这类隐私权利** → 按官方隐私政策里给出的请求途径走，协议里写明了受理方式。
- **疑似诈骗、被人骗了钱** → **报警优先**，平台举报同步做。平台举报能处理账号，处理不了资金。做法见 [交友安全与防骗.md](交友安全与防骗.md)。

## 三、提交前把这几样准备好

一次说清比来回解释省时间得多。按下面清单整理，一条一条贴过去：

| 要准备的信息 | 为什么必须 |
| --- | --- |
| 注册用的手机号 | 唯一能定位到你账号的标识 |
| 手机机型与系统版本 | 排除系统兼容类问题 |
| 应用版本号 | 网盘里这份是 1.0.1，版本不同处理方式可能不同 |
| 问题发生的时间点 | 便于对方回查日志 |
| 报错截图或订单号 | 有截图或单号，对方不必反复追问细节 |
| 你已经试过哪些办法 | 避免收到「你先试试清缓存」这类无效回复 |

## 四、多久算合理，什么时候催

- **应用内反馈**：通常按工作日计，碰上版本发布高峰期会慢一些。
- **付款渠道**：苹果的购买问题一般 24~48 小时内给答复，微信、支付宝按各自投诉流程走。
- **超过一周没有任何回音**，换一条渠道再提交一次，并在内容里写明上次提交的时间，比在同一条上反复追问有效。
- **别重复刷同一条**：反复提交会被当成刷屏，反而往后排。

## 五、假客服长什么样

这一条比前四条都重要。真正的官方渠道**不会主动来找你**。

| 假客服的典型动作 | 背后目的 |
| --- | --- |
| 主动私聊或加你好友，自称官方客服 | 官方不会主动私聊用户 |
| 说你的账号异常，要你报验证码核实 | 拿到验证码就能登你的号 |
| 让你加私人微信/QQ 处理业务 | 脱离有记录的平台，方便赖账 |
| 让你下载远程协助类应用「帮你操作」 | 远程控制你的手机 |
| 说能内部帮你退会员、退金币 | 先收一笔手续费就消失 |

**一条判断就够了：凡是要验证码、要你转账、要你装远程软件的，都不是客服。** 拉黑并举报。

## 六、怎么核对一个渠道是不是官方

- **主体**：Qiz 的开发与运营方是**海南悦爱科技有限公司**，应用商店详情页里的开发者名称应当与之一致。
- **写法**：官方名统一写作 `Qiz`；官网是 [www.yaqiz.cn](https://www.yaqiz.cn)；官方公众号名是 `QizApp`。名字多一个字母、少一个字母的，都是仿冒。
- **协议位置**：官方的隐私政策与会员充值服务协议都挂在 `api.yaqiz.cn` 这个域名下，能从这里打开的协议才是官方文本。
