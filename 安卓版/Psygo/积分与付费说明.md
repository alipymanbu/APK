## 一、免费还是收费

应用本体免费下载，注册登录不花钱。日常问答、简单任务有免费额度可以用；派复杂任务（长报告、成体系的文档）消耗更快。额度怎么算、每项任务扣多少，应用内「钱包」页面会显示你的当前余额，以那里的实际数字为准——第三方介绍称可免费使用，但没有任何来源公开过具体额度数值，网上写死的具体数字都别当真。

## 二、付费档位有哪些

截至 2026-09，App Store 中国区页面公示的内购项目包括（价格与档位随时可能调整，以你打开商店那一刻显示的为准）：

| 项目 | 检索时显示的价格 |
| --- | --- |
| 天卡（单日套餐） | ¥35 |
| 基础版 | ¥119 |
| 高级版 | ¥238 |
| 专业版 | ¥598 |
| 永久积分包 | ¥23.8 |
| 积分包（2000 / 3000 / 4000 / 8000 积分等档位） | ¥8 ~ ¥80 不等 |

两点提醒：不同档位的单价不线性（积分多的档位未必更划算），买前先算一下；「天卡」这种按天计费的形式适合短期突击用，不需要长期持有。

## 三、安卓手机从哪里买

1. 打开 PsyGo，进入「我的」或「钱包」页面。
2. 选择套餐或积分包，按提示支付——支付方式以应用内实际提供的为准（新版本安装包里出现过支付宝付款相关功能）。
3. 支付完成后回到钱包确认余额到账，再继续派任务。

新版本（0.3.x 起）钱包支持**按需批量购买单日套餐**，用一天买一天，不必一次买大套餐；你手上如果是更早的版本（包括资源里的 0.2.2），没有这个入口，属正常。

## 四、券包与优先消费顺序（仅新版本）

0.3.x 起钱包里多了**券包管理**：积分券、搭档工位券可以手动启用、停用，还能调整优先消费顺序——比如先消耗即将过期的券，再扣积分。如果你有活动赠送的券，记得去钱包里确认它们处于启用状态，否则付款时会直接扣积分。

## 五、买之前的三条判断

1. **先用满免费额度再掏钱**：把日常零散任务都派一遍，感受一下消耗速度，再决定买哪档。
2. **短期需求买天卡**：临时赶一份报告、用一两天，天卡比月度档位划算。
3. **注意余额和到期**：套餐与券有周期，续费入口会显示实际续费周期（新版本行为）；买大额积分包前先确认自己近期的用量撑得起来。

积分买了怎么花得值，见 [派任务与团队协作.md](派任务与团队协作.md) 的派单写法；扣费异常、余额没到账这类问题先翻 [常见问题排查.md](常见问题排查.md)，解决不了走应用内反馈入口。
