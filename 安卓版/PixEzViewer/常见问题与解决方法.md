# PixEz 常见问题与解决方法

> 本篇汇总 PixEz 日常使用里最常见的几个问题：界面变英文、异形屏遮挡、图打不开、以图搜图和动图的入口、保存失败，以及去哪反馈。

## 一、界面全是英文

到设置里找语言（Language）选项，选 `zh-CN` 简体中文，完全退出并重新打开应用，界面就是中文了。菜单路径在不同分支略有差异（有的在 Settings > Preferences 里），认准语言选项即可。

## 二、异形屏（挖孔屏）图片顶到状态栏

设置 > 偏好设置里找「异形屏」之类的界面适配选项并勾选，详情页的插画就不会再铺到状态栏底下（该选项是否存在以你的版本为准）。

## 三、某张图打不开

按可能性对号入座：

| 现象 | 原因 | 能不能解决 |
| --- | --- | --- |
| 只有个别图看不了 | 画师把作品删了或设为隐藏 | 应用侧无解；可以试试用搜索引擎的快照找存档 |
| R18 作品显示受限占位图 | 账号未开启 R18 浏览 | 网页端与应用内两层开关都要开，步骤见 [登录与账号设置.md](登录与账号设置.md) |
| 大面积刷不出图 | 网络与直连问题 | 按 [直连与网络设置.md](直连与网络设置.md) 的顺序排查 |

## 四、以图搜图在哪

在设置页面右上角的放大镜图标里，想找某张图的出处或画师主页时用它（这个搜索走 SauceNAO，由公开的构建说明注明）。入口位置各版本调整过，如果你那版设置页里没有，去搜索页面找放大镜旁的入口。

## 五、动图怎么播、怎么存

- **播放**：动图详情页里有播放按钮（不同版本位置略有差异），点击后应用会加载动图内容并开始播放。
- **保存**：在动图上长按，确认合成提示；合成开始与结束各有一次提示（encoding / encode success），完成后到保存目录里拿文件。较新的构建还能保存动图的原始帧图片。保存目录没设好的先看 [图片下载与保存路径.md](图片下载与保存路径.md)。

## 六、保存图片失败

十有八九是目录问题：保存目录的文件夹被清理软件删了，或者选的路径里带了 `Download` 目录。处理办法与 SAF / 传统模式的选择见 [图片下载与保存路径.md](图片下载与保存路径.md) 的第二、三节。

## 七、打开就白屏，提示「程序出错，即将退出」

两种可能：系统低于安卓 5.0（与应用的组件库不兼容）；或者拿到的是从 Play 渠道分享、提取出来的残缺包（缺资源 APK）。后者去 GitHub Release 页下载完整 APK 重装即可，步骤见 [下载与安装教程.md](下载与安装教程.md) 第五节。

## 八、其他问题与官方反馈渠道

- 大部分功能开关都在设置里，找不到选项时先把设置翻一遍。
- 你这份 2.2.5 所属分支的反馈渠道（官方 README 列出）：邮件 [Pix-Ez@outlook.com](mailto:Pix-Ez@outlook.com)、[GitHub Issues](https://github.com/ultranity/Pix-EzViewer/issues)、QQ 群 815791942、[Telegram @PixEzViewer](https://t.me/PixEz_Viewer)。Flutter 主线另有渠道，对照见 [新旧版本怎么选.md](新旧版本怎么选.md)。
- 提问前带上版本号与具体现象：你这份安装包是 2.2.5，若已升级则以应用内「关于」里显示的为准。
