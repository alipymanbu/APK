## 一、两个分支对照

| 项目 | Pix-EzViewer（原生延续版） | PixEz（Flutter 主线） |
| --- | --- | --- |
| 来源 | 初代安卓客户端；原作者停更后由 Ultranity 基于原代码接手维护（Kotlin+Jetpack） | 原作者用 Flutter 重写、现在主推的主线 |
| 版本线 | 2.x（你这份 2.2.5 就是这一支） | 0.9.x（持续更新，以官方页面为准） |
| 包名 | `com.perol.asdpl.play.pixivez`（F-Droid 版多一个 `.libre` 后缀） | `com.perol.play.pixez`（Play 渠道） |
| 发布渠道 | [GitHub Releases](https://github.com/ultranity/Pix-EzViewer/releases)、[F-Droid](https://f-droid.org/packages/com.perol.asdpl.play.pixivez.libre/) | [Google Play](https://play.google.com/store/apps/details?id=com.perol.play.pixez)、[GitHub Releases](https://github.com/Notsfsssf/pixez-flutter/releases)，另有 iOS 与 Windows 版 |
| 反馈渠道 | 邮件 [Pix-Ez@outlook.com](mailto:Pix-Ez@outlook.com)、[GitHub Issues](https://github.com/ultranity/Pix-EzViewer/issues)、QQ 群 815791942、[Telegram @PixEzViewer](https://t.me/PixEz_Viewer) | 邮件 [PxezFeedback@outlook.com](mailto:PxezFeedback@outlook.com)、[Telegram @PixEzChannel](https://t.me/PixEzChannel)、[Discord](https://discord.gg/Em9AeJbg) |

网上 PixEzViewer、Pix-EzViewer、PixEz 几种写法都指这个家族。分不清自己装的是哪一支时，看包名最准：设置 > 应用 > 该应用的详情页里能看到包名，带 `asdpl` 的是原生延续版。

## 二、怎么选

- **手头已经有这份 2.2.5**：直接用，不必为了「新」换到另一支。原生延续版的功能面并不窄——批量下载、动图播放保存、以图搜图（SauceNAO）、一键收集（下载收藏关注三连）、多账号切换、绕过 SNI 直连都在。
- **想跟着原作者的主线更新，或需要 iOS / Windows 版**：去装 Flutter 主线（渠道见上表）。
- **两支不要混着升级**：包名与签名都不同，互相覆盖安装会被系统拒绝；`.libre` 版与 GitHub 版包名也不同，会并存成两个应用。
- **账号数据通用，本地数据不互通**：收藏、关注这些都记在你的 pixiv 账号上，换哪一支登录都在；但下载历史、浏览历史、应用内设置是各自存在手机本地的，换支重装不会带过来。

## 三、两支的设置项叫法不一样

同一个目的，两支的开关名字不同，对照着找：

| 目的 | 原生延续版（你这份） | Flutter 主线 |
| --- | --- | --- |
| 关闭内置直连、走自己的代理 | 开「不启用直连」 | 开「不要绕过 SNI 嗅探」（新版本改成了「连接模式」选项） |
| 解除 R18 缩略图占位 | 设置里的「遮罩」选项 | 「H是可以的!」开关 |

具体操作见 [直连与网络设置.md](直连与网络设置.md) 与 [登录与账号设置.md](登录与账号设置.md)。
