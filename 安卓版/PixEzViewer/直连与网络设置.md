## 一、默认不用开代理

pixiv 在国内网络环境下通常无法直接访问，而这个家族的两代应用都支持免代理直连：应用内置了绕过 SNI 审查的直连方案（不是代理服务器），你不需要为了刷 pixiv 再单独挂一个代理工具。

关键是一个容易拧反方向的开关。你这份原生延续版里，它叫**「不启用直连」**：

| 开关状态 | 效果 |
| --- | --- |
| 关闭（默认） | 走应用内置直连 |
| 开启 | 不用内置直连，流量走你自己解决的网络通道（比如代理工具） |

所以：**想用直连就保持默认关闭**；你本来就有代理、想让流量走自己的代理，才去开启它。Flutter 主线的同一个开关叫「不要绕过 SNI 嗅探」（新版本改成了「连接模式」选项），名字同样绕——两支的叫法对照见 [新旧版本怎么选.md](新旧版本怎么选.md) 第三节。

## 二、什么时候考虑关掉直连

- **直连速度慢、图片刷半天**：直连快不快取决于你所在地区与运营商，官方 FAQ 也说明墙的策略可能变、pixiv 服务器自己也会出状况，直连不是永远稳定。你自己的代理更快时，开启「不启用直连」把流量交出去。
- **排查登录问题**：官方 FAQ 的排查思路就是先用代理做对照测试，确认问题出在哪一侧，具体步骤见第四节。

## 三、其他相关设置

设置里还有两组排查时容易被翻出来的选项（不同版本入口位置可能不同，以你手上的版本为准）：

- **DoH（加密 DNS）与自定义 API 端点**：公开的构建说明列有「自定义 API 镜像 / 代理网站 / DoH / IP」的支持，用于对抗 DNS 污染或自定义接入点。普通直连场景保持默认，除非你清楚自己在改什么——改错端点的结果就是什么都刷不出来。
- **谷歌翻译**：评论与作品简介的翻译功能依赖设备上装有 Google 翻译应用，没装的话翻译按钮没反应，这不是网络问题。

## 四、图片大面积加载不出来的排查顺序

官方 FAQ 给的排查思路，按这个顺序走：

1. **查开关**：「不启用直连」是否被误开。没动过设置的话，默认直连就应该能用。
2. **用代理做对照**：有代理工具的话，开启「不启用直连」后重试。仍不行时先在浏览器里测两件事——能不能打开 Google（证明代理本身正常）、能不能打开 pixiv 官网（证明代理 IP 没被 pixiv 拒绝，Vultr 一类服务商的 IP 段常被禁）。两项都正常还刷不出图，才轮到怀疑应用本身。
3. **换网络对比**：Wi-Fi 与移动数据互切，判断是不是当前运营商的问题。
4. **升级应用**：旧版本的接口会随 pixiv 服务端调整而失效，按 [下载与安装教程.md](下载与安装教程.md) 的渠道更新。
5. **登录本身报错的**（400 / 103），见 [登录与账号设置.md](登录与账号设置.md)；其余现象汇总在 [常见问题与解决方法.md](常见问题与解决方法.md)。

另外提醒：多年前停更的初版原生客户端，直连方案早已失效，刷不出图不是设置能救的——用持续维护的版本（你这份 2.2.5，或 Flutter 主线）。
