## 一、默认不用开代理

pixiv 在国内网络环境下通常无法直接访问，而 PixEz 官方说明里明确支持中国大陆地区直连：应用默认自带直连方案（绕过 SNI 嗅探的实现，不是内置代理服务器），你不需要为了刷 pixiv 再单独挂一个代理工具。

关键是一个容易拧反方向的开关：**设置 > 偏好设置里的「不要绕过 SNI 嗅探」**。

| 开关状态 | 效果 |
| --- | --- |
| 关闭（默认） | 绕过 SNI，走应用内置直连 |
| 开启 | 不绕过，流量走你自己解决的网络通道，应用启动也会快一点 |

所以：**想用直连就保持默认关闭**；你本来就有代理工具、想让流量走自己的代理，才去开启它。名字里的「不要」是这个开关最绕的地方，官方 FAQ 也专门解释过这一条。

## 二、什么时候考虑关掉直连

- **直连速度慢、图片刷半天**：直连快不快取决于你所在地区与运营商，官方 FAQ 也说明直连速度可能比较慢。你自己的代理更快时，开启「不要绕过 SNI 嗅探」把流量交出去。
- **在意启动速度**：关闭内置直连后启动会快一些。

## 三、其他相关设置

设置里还有两组排查时容易被翻出来的选项（不同版本入口位置可能不同，以你手上的版本为准）：

- **DoH（加密 DNS）与自定义 API 端点**：公开的构建说明里列有「自定义 API 镜像 / 代理网站 / DoH / IP」的支持，用于对抗 DNS 污染或自定义接入点。普通直连场景保持默认即可，除非你清楚自己在改什么——改错端点的结果就是什么都刷不出来。
- **谷歌翻译**：评论与作品简介的翻译功能依赖设备上装有 Google 翻译应用，没装的话翻译按钮没反应，这不是网络问题。

## 四、图片大面积加载不出来的排查顺序

1. **先查开关**：如果你开过「不要绕过 SNI 嗅探」又没有可用的代理，先把它关回去恢复默认直连。
2. **换个网络对比**：Wi-Fi 与移动数据互切，判断是不是当前运营商的问题。
3. **升级应用**：旧版本的接口会随 pixiv 服务端调整而失效，按 [下载与安装教程.md](下载与安装教程.md) 的渠道更新到新版本。
4. **登录本身报错的**（比如代码 103），见 [登录与账号设置.md](登录与账号设置.md)；其余现象汇总在 [常见问题与解决方法.md](常见问题与解决方法.md)。

另外提醒一句：如果你手机里装的还是**旧原生版** Pix-EzViewer，它的直连方案早已失效，刷不出图不是设置能救的——换现行 Flutter 版，迁移注意点见 [下载与安装教程.md](下载与安装教程.md) 第一节。
