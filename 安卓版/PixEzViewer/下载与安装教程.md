## 一、先分清两个「PixEz」

搜这个名字时你多半会撞见两代应用：

| 名称 | 说明 | 现状 |
| --- | --- | --- |
| Pix-EzViewer（旧原生版） | 最早的安卓原生客户端 | 已停止维护，旧版直连也已失效 |
| PixEz（现行版） | 官方用 Flutter 重写的版本，界面与功能全面替换旧版 | 持续更新 |

两代签名不同：如果你之前装的是旧原生版，不能直接覆盖安装，要先卸载旧版再装新版。网上看到 Pix-EzViewer、PixEzViewer、PixEz 几种写法，一般都指同一个项目家族，现行以 Flutter 版为准。

本文讲的是现行版，你手头这份安装包的信息：

| 项目 | 内容 |
| --- | --- |
| 应用名称 | PixEz |
| 版本 | 2.2.5 |
| 安装包大小 | 10.18 MB |
| 包名 | `com.perol.asdpl.play.pixivez` |
| MD5 | `A9A1A70B9981221A7C5BE00DCBEF0938` |
| 系统要求 | 安卓 5.0 及以上 |

两点说明：

- 官方渠道会持续发新版本，上面的版本号是这份安装包对应的版本（2026-09-23 采集），不保证与官方当下最新版一致；想追新版去官方 [Releases 页](https://github.com/Notsfsssf/pixez-flutter/releases)看。
- 系统要求取自 2.2.5 版的公开构建信息（F-Droid 收录的 2.2.5 同版本线标注 Android 5.0+），个别老设备以实际安装为准。

## 二、从哪里拿安装包

官方列出的安卓渠道：

| 渠道 | 地址 | 说明 |
| --- | --- | --- |
| Google Play | [Play 商店 PixEz](https://play.google.com/store/apps/details?id=com.perol.play.pixez) | 需要设备能访问 Play 服务 |
| GitHub Releases | [github.com/Notsfsssf/pixez-flutter/releases](https://github.com/Notsfsssf/pixez-flutter/releases) | 官方 APK 发布地；国内直连下载可能较慢 |
| F-Droid | [Pix-EzViewer (libre)](https://f-droid.org/packages/com.perol.asdpl.play.pixivez.libre/) | 社区构建的自由版，包名带 `.libre` 后缀，与上面两个渠道的应用不能互相覆盖安装 |
| 蓝奏云 | [wwa.lanzoui.com/b0ded45id](https://wwa.lanzoui.com/b0ded45id) | 官方 README 标注「临时，不推荐」 |

如果只是想省事拿一份能用的，直接取 PixEzViewer 安装文件资源（夸克网盘）里的这份 2.2.5：转存到自己的网盘再下载，不用在 GitHub 上对着一堆版本号挑。

顺带一提：这个项目还有 iOS 版（[美区 App Store](https://apps.apple.com/us/app/pixez/id1494435126)）与 Windows 版（官方 GitHub Actions 构建的 Nightly MSIX），本篇只覆盖安卓。

## 三、安装步骤

1. 从上面任一渠道拿到 APK，下载到手机；文件大小在 10 MB 上下，明显偏小的多半是没下完整。
2. 在文件管理器里点开 APK。第一次从商店外安装时，系统会要求你给文件管理器授权「安装未知应用」，按提示放行即可。
3. 想核对文件有没有损坏，把 APK 的 MD5 与第一节的 `A9A1A70B9981221A7C5BE00DCBEF0938` 对一下；不一致就重新下载。
4. 装完点「打开」。

覆盖安装的几种情况：

- 同为现行版之间升级，一般直接覆盖安装即可。
- 从旧原生版（Pix-EzViewer）迁移：签名不同，直接装会被系统拒绝，先卸载旧版；应用内数据（浏览历史、下载记录等）不会带过来。
- 包名不同的构建（比如 F-Droid 的 `.libre` 版）与 Play / GitHub 版互不覆盖，会装成两个独立应用，选一个用就行。

## 四、第一次打开要做的事

1. 界面默认可能是英文：点右下角 Settings → Preferences → 语言选 `zh-CN`，重启应用即变中文，细节见 [常见问题与解决方法.md](常见问题与解决方法.md)。
2. 登录你的 pixiv 账号，没有账号怎么注册、报错 103 怎么处理，见 [登录与账号设置.md](登录与账号设置.md)。
3. 国内网络保持默认设置即可直连使用，相关开关的方向别拧反，见 [直连与网络设置.md](直连与网络设置.md)。
4. 存图前先把保存目录设好，官方推荐 `Pictures/PixEz`，具体步骤与注意事项见 [图片下载与保存路径.md](图片下载与保存路径.md)。

之后的日常使用里，你用得最多的动作是长按下载与逛排行榜，都整理在 [图片下载与保存路径.md](图片下载与保存路径.md)；碰到具体报错先翻 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 五、装不上怎么办

- **提示签名不一致 / 无法覆盖安装**：先卸载设备上同包名的旧版再装。
- **提示解析失败或安装包损坏**：重新下载并核对 MD5，半截包装不上。
- **存储空间不足**：清理后重试；应用本体不大，一般不是它吃掉的。
- **装好了但一直转圈刷不出图**：多半是网络与直连设置问题，按 [直连与网络设置.md](直连与网络设置.md) 排查。
