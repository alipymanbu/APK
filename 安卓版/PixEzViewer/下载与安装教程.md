## 一、先分清你装的是哪一代

| 名称 | 说明 | 现状 |
| --- | --- | --- |
| Pix-EzViewer（原生延续版） | 初代安卓客户端；原作者停更后由 Ultranity 接手，基于原代码继续维护 | 2.x 版本线，你这份 2.2.5 就是这一支 |
| PixEz（Flutter 主线） | 原作者用 Flutter 重写、现在主推的版本 | 持续更新，版本号是另一套（0.9.x 线，以官方页面为准） |

两支的包名与签名都不同，不能互相覆盖安装，本地数据也不互通；详细对照与选择建议见 [新旧版本怎么选.md](新旧版本怎么选.md)。网上 PixEzViewer、Pix-EzViewer、PixEz 几种写法一般都指这个家族。

你手头这份安装包的信息：

| 项目 | 内容 |
| --- | --- |
| 应用名称 | Pix-EzViewer（PixEz 阅读器） |
| 版本 | 2.2.5 |
| 安装包大小 | 10.18 MB |
| 包名 | `com.perol.asdpl.play.pixivez` |
| MD5 | `A9A1A70B9981221A7C5BE00DCBEF0938` |
| 系统要求 | 安卓 5.0 及以上 |

两点说明：

- 版本号是这份安装包打包时的版本（2026-09-23 采集）；这一支的后续更新发布在其 GitHub Releases 与 F-Droid 页面，是否已有新版以项目页面为准。
- 安卓 5.0 以下的系统装上会有问题——官方 FAQ 明确低版本系统与应用用到的多个组件库不兼容，表现为打开就白屏报错。

## 二、从哪里拿安装包

| 渠道 | 地址 | 说明 |
| --- | --- | --- |
| GitHub Release | [github.com/ultranity/Pix-EzViewer/releases](https://github.com/ultranity/Pix-EzViewer/releases) | 这一支的完整 APK 官方发布页 |
| F-Droid | [Pix-EzViewer (libre)](https://f-droid.org/packages/com.perol.asdpl.play.pixivez.libre/) | 同一份源代码、由 F-Droid 构建，包名带 `.libre` 后缀，与 GitHub 版不能互相覆盖 |
| Flutter 主线 | [Google Play](https://play.google.com/store/apps/details?id=com.perol.play.pixez) / [GitHub Releases](https://github.com/Notsfsssf/pixez-flutter/releases) | 如果你想要的其实是原作者那条主线（包名不同，装上是另一个应用） |

如果只是想省事拿一份能用的，直接取 PixEzViewer 安装文件资源（夸克网盘）里的这份 2.2.5：转存到自己的网盘再下载，不用在几个渠道之间对版本号。

顺带一提：PixEz 家族的 iOS 版（美区 App Store）与 Windows 版出自 Flutter 主线，原生延续版只有安卓端，渠道对照见 [新旧版本怎么选.md](新旧版本怎么选.md)。

## 三、安装步骤

1. 从上面任一渠道拿到 APK，下载到手机；文件大小在 10 MB 上下，明显偏小的多半是没下完整。
2. 在文件管理器里点开 APK。第一次从商店外安装时，系统会要求你给文件管理器授权「安装未知应用」，按提示放行。
3. 想核对文件有没有损坏，把 APK 的 MD5 与第一节的 `A9A1A70B9981221A7C5BE00DCBEF0938` 对一下；不一致就重新下载。
4. 装完点「打开」。

覆盖安装的几种情况：

- 同一支之间升级，一般直接覆盖安装即可。
- 从另一支迁移（原生版换 Flutter 主线或反过来）：签名不同，直接装会被系统拒绝，先卸载旧版；应用内数据（浏览历史、下载记录、设置）不会带过来，pixiv 账号本身不受影响。
- `.libre` 版与 GitHub 版包名不同，会装成两个并存的应用，选一个用就行。

## 四、第一次打开要做的事

1. 界面默认可能是英文：到设置里找语言（Language）选项，选 `zh-CN` 简体中文，重启应用生效，细节见 [常见问题与解决方法.md](常见问题与解决方法.md)。
2. 登录你的 pixiv 账号，报错 400 / 103 怎么处理见 [登录与账号设置.md](登录与账号设置.md)。
3. 国内网络保持默认设置即可直连使用，别把直连开关的方向拧反，见 [直连与网络设置.md](直连与网络设置.md)。
4. 存图前先把保存目录设好，推荐 `Pictures/PixEz`，步骤与注意事项见 [图片下载与保存路径.md](图片下载与保存路径.md)。

之后的日常使用里，你用得最多的动作是长按下载与逛排行榜，都整理在 [图片下载与保存路径.md](图片下载与保存路径.md)；碰到具体报错先翻 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 五、装不上或打开就出问题

- **打开就白屏、提示「程序出错，即将退出」**：两种可能。一是系统低于安卓 5.0，与应用用到的多个组件库不兼容；二是拿到的是从 Play 渠道分享或提取出来的残缺包（缺资源 APK）。前者只能换设备或换系统，后者去 GitHub Release 页下完整 APK 重装。
- **提示签名不一致 / 无法覆盖安装**：先卸载设备上同包名的旧版再装。
- **提示解析失败或安装包损坏**：重新下载并核对 MD5，半截包装不上。
- **存储空间不足**：清理后重试；应用本体不大，一般不是它吃掉的。
- **装好了但一直转圈刷不出图**：多半是网络与直连设置问题，按 [直连与网络设置.md](直连与网络设置.md) 排查。
