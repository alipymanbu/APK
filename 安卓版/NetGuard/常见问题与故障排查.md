## 一、开了 NetGuard 后别的 VPN 连不上

安卓**同时只允许一个应用占用 VPN 通道**，这是系统限制，不是 NetGuard 的毛病。开 WireGuard、代理客户端或任何其他 VPN 时，NetGuard 会失去对流量的控制、规则全部失效；反过来先开的另一个 VPN 也会让 NetGuard 连不上。

- 两个都要用的场景只能二选一切换：用 NetGuard 时断开另一个，用代理时关掉 NetGuard 总开关；
- 检查系统设置里「VPN → 始终开启的 VPN」有没有指到别的应用——设了「始终开启」的一方会抢占通道，NetGuard 就一直起不来。

## 二、通知栏那条常驻通知能去掉吗

那是安卓对前台服务（VPN 类应用）的强制要求，**应用内没有「隐藏通知」的开关**。变通办法：

- 长按这条通知进系统通知设置，把 NetGuard 的「VPN」通知类别关掉（安卓 8 及以上各品牌路径叫法不同，一般叫「通知管理」）；
- 关掉后状态栏的 VPN 钥匙图标可能仍然显示，那是系统的，去不掉；
- 不建议把通知渠道整个静音到看不见状态——排查「规则怎么失效了」时，这条通知是不是还在是个快速判据。

## 三、规则时灵时不灵 / 重启后失效

按这个顺序查：

1. **总开关还在不在**——通知栏没有那条常驻通知 = 防火墙没在跑，先回应用里打开；
2. **省电策略**——把 NetGuard 加进系统电池优化的白名单（设置 → 电池 → 应用耗电管理里选「不限制」；小米、华为、OPPO 等还有各自的「自启动」与「后台运行」开关，逐个允许）；
3. **多开冲突**——见第一节，有没有别的 VPN 抢了通道；
4. **重启后没自启**——设置里开启「开机后自动启动」类的选项（部分系统要求配合自启动权限）。

另外注意两种「看起来像故障、其实是设计如此」的情况：

- **锁屏后收不到推送**——开了「仅在屏幕开启时允许」就会这样，见[应用联网规则设置方法.md](应用联网规则设置方法.md)第四节；
- **某应用彻底没网**——先去应用列表看它的图标是不是被你划了拦截，再想是不是 hosts 列表误伤（见[hosts屏蔽广告配置方法.md](hosts屏蔽广告配置方法.md)第四节）。

## 四、开热点时其他设备的流量管不管得住

NetGuard 支持网络共享场景，但**规则只对本机流量可靠生效**；通过热点接进来的其他设备（笔记本、平板），其流量在部分安卓版本上过滤不到。拿它给热点设备控流量的话，别假设全覆盖，用前先在热点设备上验证一次。官方 FAQ（[FAQ.md](https://github.com/M66B/NetGuard/blob/master/FAQ.md)）对 tethering 的行为有逐版本说明。

## 五、装完某应用后它一联网就弹通知

那是「有应用访问网络时通知」选项在起作用，属于提醒不是故障。短期观察用完就关：设置里找到对应选项关掉；否则系统里每个应用每次联网都会弹。

## 六、现象速查表

| 现象 | 先查什么 |
| --- | --- |
| 规则完全不生效 | 总开关 → 是否被其他 VPN 抢占 |
| 个别应用还有网 | 应用列表图标状态 → 是否开了「屏幕开启时才允许」 |
| 推送收不到 | 是否开了锁屏断网 |
| 重启后全失效 | 电池优化白名单 → 自启动权限 |
| 广告没少反而应用报错 | 「屏蔽域名」与 hosts 列表（见第四节） |
| 装新应用弹个不停 | 「有应用访问网络时通知」开关 |
