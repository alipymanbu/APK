## 一、免费版能覆盖的日常场景

免费版没有使用期限，下面这些常用的都不锁：

- 按应用放行 / 拦截 Wi-Fi 与移动数据（核心功能，见[应用联网规则设置方法.md](应用联网规则设置方法.md)）；
- 亮屏才允许联网、漫游时拦截、管控系统应用；
- 有应用访问网络时弹通知提醒；
- 按应用、按地址记录网络用量；
- 支持网络共享（热点）、IPv4/IPv6、TCP/UDP；
- 明暗两套主题。

只做「按应用断网、省流量省电」这件事，免费版就够了。

## 二、Pro 功能清单

Pro 按功能单独列在官方页面上（[www.netguard.me](https://www.netguard.me/)）：

| Pro 能力 | 用来干什么 |
| --- | --- |
| 查看流量日志 | 记录全部出站连接，可搜索过滤；能导出 PCAP 文件，用 Wireshark 打开分析 |
| 过滤网络流量 | 按域名 / 地址对单个应用放行或拦截；**hosts 列表屏蔽广告依赖它** |
| 新应用通知 | 装了新应用弹通知，当场决定拦还是放，不用去列表里找 |
| 网速通知 | 在状态栏通知里显示实时网速曲线（官方为省电只在亮屏时显示，刷新频率可在设置里调低） |
| 外观主题 | 在明暗两套之外再多 5 套配色 |

其中「过滤网络流量」最常被需要——想屏蔽广告域名就必须激活 Pro，流程见[hosts屏蔽广告配置方法.md](hosts屏蔽广告配置方法.md)。

## 三、激活方式：两条路

| 路径 | 做法 | 限制 |
| --- | --- | --- |
| Google Play 内购 | 在商店版里直接购买 | 只能激活 Play 版；商店政策不允许把这笔购买用在其他渠道的版本上 |
| 官网捐赠激活 | 官网用 PayPal 或信用卡捐赠，激活码发到邮箱 | 给 GitHub / F-Droid 版用；捐赠 0.10 欧起可激活**一台**设备，7 欧起可激活你本人所有的设备 |

Play 内购是一次性买断（有第三方评测口径提到约 5 美元，以商店页面当时显示为准）。捐赠的具体档位与规则以官方页面为准（官方口径提到开发投入超过 3000 小时，7 欧以下的捐赠只允许激活一次，重装系统后可能需要重新激活）。没有 Google 服务的设备（部分国产机、平板）走第二条路。

## 四、要不要激活，按需求判断

- 只是给几个应用断网、省流量 → 免费版足够，不必激活；
- 要屏蔽广告域名 → 必须激活（依赖「过滤网络流量」）；
- 想搞清楚某个应用半夜连了哪些地址 → 流量日志 + PCAP 导出那套；
- 常装新应用想顺手管控 → 新应用通知省事。
