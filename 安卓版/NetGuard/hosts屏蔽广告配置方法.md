## 一、先确认你的版本支持

hosts 屏蔽广告这个能力**不是所有渠道的 NetGuard 都有**：

- **Google Play 版没有**——商店政策不允许，Play 版里找不到下载 hosts 列表的相关选项；
- **GitHub 上的 apk 版有**——同一个开源项目，官方单独发布的版本，多了 hosts 列表下载与域名过滤能力。

所以先看应用信息里的来源：从商店装的想用这功能，需要改装 GitHub 版（发布页：[github.com/M66B/NetGuard/releases](https://github.com/M66B/NetGuard/releases)）。改装前先备份规则截图，卸载重装后规则要重新设。各渠道差别见[下载与安装教程.md](下载与安装教程.md)。

官方对这功能的说明集中在仓库里的 [ADBLOCKING.md](https://github.com/M66B/NetGuard/blob/master/ADBLOCKING.md)，步骤细节以它为准。

## 二、前提条件

两个前提缺一不可：

1. **激活「过滤网络流量」能力**——这是 Pro 功能，没激活的话 hosts 列表下载了也不生效。免费版与 Pro 的边界见[Pro功能与免费版区别.md](Pro功能与免费版区别.md)；
2. **总开关处于开启状态**——域名拦截和按应用断网一样，都在防火墙运行时才起作用。

## 三、配置步骤

1. 在设置里找到「过滤流量 / Filter traffic」，确认已开启（部分版本用通知磁贴也能快速开关，安卓 7 以上可用）；
2. 找到「下载过滤文件」类的设置项，填入一个 hosts 列表地址并下载。列表选常见的公共汇总 hosts（聚合广告、统计、追踪域名的那种）即可，GitHub 上搜 `hosts` 排名靠前的几个维护活跃的列表都能用；
3. 开启「屏蔽域名 / Block domain names」开关——**这步最容易漏**。只下载文件不开这个开关，NetGuard 不会处理列表，广告域名照常放行，这是多个用户反馈里最常见的「配了没效果」原因；
4. 打开一个平时广告多的应用或网页验证：被拦的域名会解析失败，广告位空白或直接消失。

 hosts 列表是**全局性**的域名拦截，与按应用的断网规则（见[应用联网规则设置方法.md](应用联网规则设置方法.md)）叠加使用：前者管「哪些域名谁都不许连」，后者管「哪个应用彻底断网」。

## 四、屏蔽之后的常见状况

- **个别应用加载不出内容**——列表太狠误伤了它依赖的域名。处理：在该应用的过滤规则里把这个域名放行（需要 Pro 的按地址放行能力），或换个宽松些的列表；
- **网页完全打不开**——先关「屏蔽域名」开关对比一次，恢复 = 列表问题，换列表或换宽松版本；
- **系统里设了「私人 DNS」（自定义主机名那种）**——它和这类 VPN 型过滤可能抢 DNS 解析，出现大量域名解析失败时，先把私人 DNS 调回「自动」对比一次再下结论；
- **广告位变成一块空白**——域名拦截只能让广告内容加载不出来，清不掉页面里的占位框，这与广告伪装成正常内容、和应用内容走同一域名的情况一样，属于此类方案的能力边界，不是配置错了；
- **用一段时间后又开始出现广告**——广告域名会换，列表靠维护者更新，隔段时间回设置里重新下载一次列表；
- **想临时停用**——关掉「屏蔽域名」开关即可，不必卸载列表，下次再开。

## 五、这个方案的能力边界

- 拦的是**域名解析**：广告域名解析失败，广告位自然出不来；对「广告与应用内容走同一域名」的场景无能为力；
- 只在本机生效：浏览器、应用内的广告都能拦到一部分，但拦不了走 CDN 与正常业务域名混发的内容；
- 视频前贴片类广告大多拦不住——它们与视频流走同一服务，这是 hosts 方案的通病，不是配置错了。
