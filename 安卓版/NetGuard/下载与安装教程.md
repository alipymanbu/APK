## 一、四个获取渠道

| 渠道 | 拿到的版本 | 适合谁 |
| --- | --- | --- |
| 夸克网盘资源 | 2.329（本网盘包对应的版本） | 想直接装 apk、或不方便访问 Google Play 的设备 |
| Google Play | 官方最新版 | 能正常访问商店、想跟着官方更新的设备 |
| GitHub Releases | 官方最新版（apk 直下） | 想用 hosts 屏蔽广告功能的设备 |
| F-Droid | 官方仓库收录的版本 | 习惯用 F-Droid 客户端自动更新的设备（版本比 GitHub 略滞后，以 F-Droid 页面为准） |

上面几条渠道装出来的核心防火墙能力一致：按应用放行或拦截 Wi-Fi 与移动数据、无需 root。差别集中在一点——**Google Play 版不能加载 hosts 屏蔽列表**（商店政策限制），想用这功能要装 GitHub 上的 apk 版，原因与步骤见[hosts屏蔽广告配置方法.md](hosts屏蔽广告配置方法.md)。

- 开发方：FairCode B.V.（Marcel Bokhorst），项目开源，许可证 GPL v3；
- 官网：[www.netguard.me](https://www.netguard.me/)；源码与发布页：[github.com/M66B/NetGuard](https://github.com/M66B/NetGuard)；
- 官方常见问题汇总：[FAQ.md](https://github.com/M66B/NetGuard/blob/master/FAQ.md)。

网盘里这份与官方最新版不是同一版，装之前先对清楚：

| 对比项 | 网盘这份 | 官方最新版（2026-09） |
| --- | --- | --- |
| 版本号 | 2.329 | 2.33x（2026 年 8 月更新，以官方发布页为准） |
| 安装包大小 | 2.86M | 以官方发布页为准 |
| 系统要求 | 安卓 5.2 以上（按本包安装信息） | 官方标注支持安卓 5.1 及以上 |

按应用断网、漫游拦截、亮屏才放行、系统应用管控这些常用功能两版都有；新版主要是 Android 15+ 兼容性改进。装哪版看你的需要：想稳定用现成功能装网盘这份即可，以后想跟新版再去 GitHub 或商店更新。

从网盘拿安装包：打开 [NetGuard 安装文件资源（夸克网盘）](https://pan.quark.cn/s/adb563401afd)，先转存到自己网盘，再把 apk 下载到手机存储。

## 二、安装步骤

1. 把 apk 下载到手机存储（「下载 / Download」目录即可）；
2. 用文件管理器点开这个 apk；
3. 系统提示「禁止安装未知来源应用」时，按弹窗指引允许「来自此来源的应用」——这是安卓对非商店 apk 的常规确认，不同品牌叫法略有差别（小米叫「安装未知应用」，华为叫「允许安装未知应用」，入口都在系统设置的「应用管理」附近）；
4. 回到安装界面点「安装」，完成后点「打开」；
5. 第一次打开会出现使用条款，同意后进入主界面；
6. 点顶部的总开关，系统弹出「连接请求」——NetGuard 要建立一个**本机 VPN 连接**才能拦截流量，点「确定」。

连接成功后通知栏会多一条常驻通知（带钥匙图标）。这是安卓对 VPN 类应用的要求，去掉不掉属正常，处理办法见[常见问题与故障排查.md](常见问题与故障排查.md)第二节。装完想开机自动生效，把 NetGuard 设成系统「始终开启的 VPN」即可，见[始终开启VPN与重启防护设置.md](始终开启VPN与重启防护设置.md)。

## 三、装完先做两件事

1. **确认总开关是开的**——NetGuard 所有规则都在总开关开启时才生效；
2. **决定默认策略**——是「默认放行、个别应用断网」还是「默认全拦、逐个放行」，两种路线的取舍见[应用联网规则设置方法.md](应用联网规则设置方法.md)。

## 四、核对安装包

在意拿到的包是不是原始那份的话，可以核对这三个值：

| 项目 | 值 |
| --- | --- |
| 包名 | `eu.faircode.netguard` |
| 大小 | 2.86M |
| MD5 | `9A8B8156E3DA6EC61CB893F6FB7DEAF7` |

包名在系统「设置 → 应用 → NetGuard → 应用信息」里能看到；MD5 需要用电脑或第三方校验工具计算。系统要求按网盘这份的安装信息是安卓 5.2 以上，官方口径为安卓 5.1 及以上，以官方页面为准。
