## 一、发现页是个什么入口

首页只放当天那「一个」，想按类型翻旧内容、找某一类东西，就切到底部的「发现」。多份公开使用教程的描述一致：发现页下分阅读、图文、专题、热搜榜、问答、音乐、影视等专栏，另有连载、小记、电台等板块。不同版本的栏目名与排列会有出入，以你装的这版实际显示为准。

## 二、各栏目怎么用

| 栏目 | 你在这里能做什么 |
| --- | --- |
| 阅读 | 按文章列表翻短篇故事、散文、诗歌、访谈，可点进全文与评论 |
| 图文 | 看每日摄影图与配文的历史内容 |
| 专题 | 按主题（治愈、成长、情感等）打包好的系列文章，适合一口气读同调性的内容 |
| 问答 | 每天一个问题与回答的合集，可按时间往前翻 |
| 热搜榜 / 热榜 | 当月各专栏的内容排名，快速找当下热度最高的文章与用户笔记 |
| 连载 | 按年份、月份筛选的长篇连载文章 |
| 音乐 | 每日配乐与歌手故事，可直接播放试听 |
| 影视 | 影评与影片相关内容 |

## 三、小记是什么

「小记」是用户自己发布的短句、心情记录板块，你在里面刷到的是别人写的小记。早年版本的记录是：编辑时拿一张图当封面，配下面的文字，文字上限 2000 字，写完可选择只存个人中心或同时存到手机 —— 具体字数与选项以你这版的编辑页为准。发布前注意选对可见范围（公开 / 仅自己），两派说法见 [能不能加好友与怎么关注作者.md](能不能加好友与怎么关注作者.md) 第三节。

## 四、电台怎么听

电台（也叫「ONE 收音机」，早年叫「深夜电台」）是音频板块，收录故事朗读、人物访谈、散文朗读这类长音频。公开教程提到它支持后台播放与离线缓存：通勤或睡前把节目缓存下来，锁屏后继续放，没网也能听。缓存的音频文件会占空间，清理办法见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 五、和每日内容的关系

首页的「当天一个」是主菜，发现页是库房 —— 往期文章、往期问答、专题合集都在这里按栏目归档。两者的浏览手势与收藏方法是同一套，见 [每日内容和往期文章怎么看.md](每日内容和往期文章怎么看.md)。还没装应用的先看 [下载与安装教程.md](下载与安装教程.md)。
