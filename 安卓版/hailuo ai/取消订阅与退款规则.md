## 一、在哪买的就在哪取消

Hailuo AI 的订阅走的是应用商店或支付渠道的自动续费，取消入口不在 App 里，而在你付款的那个渠道：

| 扣款渠道 | 取消路径 |
| --- | --- |
| iOS App 内购 | App Store → 点头像 → 账户 → 订阅 → 选 Hailuo AI → 取消订阅 |
| Google Play | Play 商店 → 头像 → 付款和订阅 → 订阅 → 选 Hailuo AI → 取消 |
| 支付宝（国内版） | 支付宝 → 我的 → 设置 → 支付设置 → 免密支付/自动续费 → 关闭 |
| 微信（国内版） | 微信 → 我 → 服务 → 钱包 → 支付设置 → 自动续费 → 关闭 |

官方自动续费规则里有一条容易吃亏：**取消前已经生效的扣款指令仍然有效**，也就是说刚好卡在扣款当天去关，那笔已扣的钱按规则不退。想止损，在当前订阅期结束前几天就动手取消。

## 二、取消后还剩多少权益

按官方订阅条款：

- 取消（终止）在**下一个计费周期开始时生效**，当前周期内权益照常可用——积分、无水印、队列优先都能用到期；
- **已支付的费用不退**。没有「用两天不满意退全款」这回事，月底取消不退、月中取消也不退；
- 换更低档位同理：降级要等当前订阅期结束才生效。

所以「取消订阅」和「立刻失效」是两件事：取消只是关掉自动续费，把权益用到到期日再走，一分都不浪费。

## 三、生成失败，积分自动退

这是官方条款里写得最明确的一条：**视频生成失败、或内容没过审核，系统自动退回本次消耗的积分**，不需要人工申请。操作上核对两处：

1. 任务列表里确认任务状态确实是「失败」而不是「生成中」；
2. 积分流水里看有没有到账退回，个别情况有延迟，等一会儿再刷。

如果积分没退、任务卡在「生成中」不动，去[常见问题与故障排查](常见问题与故障排查.md)的排队一节处理。

## 四、什么情况钱退不了

把规则说全，免得产生错误预期：

- 订阅费**一经支付不退**（终止只在下个周期生效，这是官方条款原文）；
- 当月没用完的会员积分**清零不补**；
- 因为支付渠道风控导致的退款，付费权益会被收回，账号还可能被处置；
- 国内版（海螺AI）与海外版（Hailuo AI）是两套独立的服务与支付体系，在海外版订阅的不能找国内版退款，反过来也一样。

争议金额较大或确实属于扣款异常（比如取消后仍被扣款），保留扣款凭证，通过 App 内反馈入口或支付渠道的客服申诉，渠道侧（App Store / Google Play）对误扣款有自己的仲裁流程，成功率比找 App 内客服高。

## 五、不想月月被扣，又不想马上失去权益

如果只是不想被自动扣款，又想保留付费权益用到月底：取消订阅不会立刻断权益（见第二节），所以**直接取消是最好的方案**；下个月想用再单独买积分（$1 约 70 积分，有效期长），比重新订阅灵活——这笔账怎么算，见[积分与订阅说明](积分与订阅说明.md)。
