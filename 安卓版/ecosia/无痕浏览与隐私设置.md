## 一、开一个无痕标签

1. 打开 Ecosia 应用。
2. 点右上角**三个点**打开菜单。
3. 选 **New Incognito tab**（新建无痕标签）。
4. 用完退出时，把无痕标签全部关掉，或在菜单里选 **Close all incognito tabs**。

无痕标签和普通标签在界面上是分开的，你可以来回切换着用。

## 二、无痕模式挡得住什么、挡不住什么

官方帮助里把这个边界写得很直白，值得在你决定「信不信它」之前先看一遍：

| 无痕模式做的事 | 无痕模式不做的事 |
| --- | --- |
| 浏览历史不留在设备上 | 不对网站、运营商、单位网络隐藏你的访问 |
| 关闭标签后 cookie 和站点数据清掉 | 不等于匿名上网 |
| 会话结束后不再保持登录状态 | 不隐藏 IP 和位置 |
| 搜索词和表单输入不保存 | 不能防恶意软件和钓鱼网站 |

一句话：它是「本机隐私」，不是「全网隐身」。共用设备、借手机给人用一下这类场景它够用；想对网络层面隐藏，它不管。

## 三、内置的广告拦截

应用自带广告拦截，官方口径是拦截侵入式和垃圾广告。有一个事实需要知道：Ecosia 的收入来自广告，所以**非侵入式的广告仍然会显示**——这不是拦截功能坏了。如果你发现某些站点还是出现广告，属于正常现象，不用反复去排查设置。

## 四、两个跟搜索记录有关的开关

1. **个性化搜索结果**：在 Ecosia 搜索设置里可以关闭。开启状态下，Ecosia 会向其搜索服务商（Bing）传一个匿名标识，用来根据你过去的搜索微调结果；官方说明不长期存储 IP 和该标识。关闭路径：进 [ecosia.org/settings](https://www.ecosia.org/settings)，把 Personalized search results 关掉；或者在你的浏览器里开启 **Do Not Track**（不跟踪）请求，官方也会据此关闭个性化。
2. **搜索请求加密**：官方商店页说明搜索经 SSL 加密传输。这是默认行为，不需要你打开任何开关。

这两个设置和语言、区域设置一样存在 cookie 里，清了浏览数据就会回到默认。

## 五、主动清一次浏览数据

想把留在本机的历史、cookie 清掉（比如把手机转给别人之前）：

1. 点右上角**三个点**。
2. 选 **Clear browsing data**（清除浏览数据）。
3. 勾选要清的项目（历史、cookie、缓存等），确认执行。

只想清某个网站的数据而不是全部，走「Settings > Site settings > All sites」，搜索对应站点后单独清除。各项目的具体影响见[打不开或闪退怎么办.md](打不开或闪退怎么办.md)第二、三节——排查故障和主动清理用的是同两条路径。
