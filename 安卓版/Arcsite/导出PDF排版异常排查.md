# ArcSite 导出 PDF 排版异常排查

> 本篇解决三类导出怪象：整张图缩得很小、页面上大片留白或图被裁掉、文字忽大忽小，每类都给出从成因到操作的完整路径。

## 一、整张图缩得很小：先找画布上的「流浪对象」

导出范围默认覆盖画布上的**所有**内容，哪怕是一个不小心甩在千里之外的单条线或文字，也会把导出边界撑大，主体图随之缩成一角。

排查与处理：

1. 打开图纸，用框选（Box Select）把主体图全部选中；
2. 双指缩小视图，观察选区之外还有没有高亮对象；
3. 删掉那些不想要的孤立对象；
4. 重新导出。

赶时间的话有个捷径：导出时把「导出范围」改成 **Visible Portion（当前可见部分）**，直接无视画布外的杂物。临时截取用它，正式交付还是建议清干净画布。

## 二、大片留白或图被裁掉：比例和纸型不匹配

这是「导出比例」的问题，不是画布校准错了。固定纸型塞不下当前比例的图，就会留白或切边。按顺序试：

1. 比例选 **Fit to Page**（铺满页面）；
2. 或改用更小的比例（如 1:100 → 1:200）；
3. 或换更大的纸型（如 A4 → 11×17）；
4. 每改一项就预览一次，合适再导出。

两个比例别混淆：**画布校准**决定图里的尺寸准不准（1 段线 = 现场多少米），**导出比例**只决定印在纸上多大。导出看着不对就调导出比例，别去动校准，细节见 [画布比例校准方法.md](画布比例校准方法.md)。

## 三、文字忽大忽小：关掉自动文字高度

标注是在不同缩放级别下添加的，文字会随当时视图大小自动缩放，导出到同一张 PDF 上就大小不一。

- **让之后的文字都保持固定大小**：进「Annotate（标注）→ Color & Styles（颜色与样式）」，关闭 **Automatic Text Height**；
- **把已有文字改到统一大小**：选中文字 → 底部工具栏 Color & Styles → Text Height → 输入目标值。

## 四、导出前的三个习惯

- 交付前先预览，别等对方打回来才发现排版崩了；
- 只要图纸的一部分时，用 Visible Portion 而不是手动擦掉其余内容；
- 线条太细打印看不清，把导出参数里的「线宽比例」滑杆调粗，见 [图纸导出与分享.md](图纸导出与分享.md) 的参数表。

这里没覆盖到的失败（DXF/DWG 灰色、文件太大发不出去等）集中在 [常见问题排查与技巧.md](常见问题排查与技巧.md) 的导出一节。
