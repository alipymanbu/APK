## 一、四种导出格式怎么选

画布右上角点「导出」图标，可用的格式有四种：

| 格式 | 用途 | 订阅要求（以应用内显示为准） |
| --- | --- | --- |
| PNG | 发微信、贴进报告的图片 | 基础档可用 |
| PDF | 打印、正式交付、保留排版 | 基础档可用 |
| DXF | 交给 AutoCAD 等 CAD 软件继续编辑 | 试用期内可用，之后需要付费订阅（Draw Pro 档及以上） |
| DWG | 同上，AutoCAD 原生格式 | 同 DXF |

两个边界要知道：

- 只能导出**整张图纸**，图形库里的单个图形不能单独导出；
- DXF/DWG 的订阅口径以你当前版本的应用内提示为准，试用期到期后再导出被拒，多半就是这条限制。

## 二、导出 PDF 时那些参数各管什么

PDF 是参数最多的一种，逐项说明（界面文字以你的版本为准）：

| 参数 | 作用 | 建议 |
| --- | --- | --- |
| 方向 | 横向 / 纵向 | 长条户型用纵向，宽场地用横向 |
| 纸张尺寸 | 输出纸型 | 对准你要打印的纸 |
| 页边距 | 输出留白 | 打印机有不可打印区时调大 |
| 比例 | 按建筑制图比例（1:50 等）输出或自定义 | 设一次会成为之后的默认导出比例 |
| 导出范围 | 整张图纸或仅当前屏幕所见 | 交付用整张，临时截取用当前视图 |
| 包含定位照片 | 是否把挂在图上的现场照片一并排进 PDF | 照片多会显著增大文件 |
| 每页照片数 | 每页排几张定位照片 | 照片多时调大每页张数减少页数 |
| 位置标记尺寸 | 图上照片编号圆标的大小 | 打印后要人工翻照片就调大 |
| 网格 | 不显示 / 浅色 / 深色 | 交付件一般关掉 |
| 线宽比例 | 滑杆调整线条相对粗细 | 手机上看不清细线时调粗 |

比例那一栏还有个 **Fit to Page**（铺满页面）选项：当前比例塞不进所选纸型、出现大片留白或图被裁切时，选它最快。导出后整张图缩得特别小，多半是画布远处有孤立对象撑大了导出边界，清理步骤见 [导出PDF排版异常排查.md](导出PDF排版异常排查.md)。

## 三、交给 AutoCAD / Revit 的交接路径

1. 确认你的订阅档支持 DXF/DWG 导出（见第一节与 [账户注册与订阅方案.md](账户注册与订阅方案.md)）；
2. 导出 DXF 或 DWG，通过邮件、保存到文件等方式拿到本地；
3. 在桌面 CAD 软件里打开，图元为可编辑的线条与图形。

注意导出前把画布比例校准好（方法见 [绘图入门与测量操作.md](绘图入门与测量操作.md)），否则交接过去的尺寸要全部返工。

## 四、用链接分享给没装应用的人

整张图纸可以直接生成一个网页查看链接，对方不需要安装任何东西：

1. 打开要分享的图纸，点「Share Viewable Link」（分享查看链接）；
2. 应用会先把图纸发布到云端，然后给你两个开关：
   - **任何有链接的人可查看**：关掉后链接失效；
   - **允许下载**：开着也不等于随便下——收件人要先登录或注册 ArcSite 账号才能下载 PDF/PNG/DXF/DWG，没登录的人只能看；
3. 点「Copy Link」复制链接，或直接用应用内邮件发送。

这条路径还有个隐藏用途：**现场照片多导致 PDF 太大、邮件发不出去时**，改发链接让对方自己下载，绕开邮箱附件上限。

## 五、导出失败时的排查顺序

1. **DXF/DWG 选项是灰的或提示升级**：订阅档不够或试用已过期，对照第一节；
2. **PDF 体积大到发不出去**：关掉「包含定位照片」再导一次，或改用链接分享；
3. **导出的图特别小 / 大片留白 / 被裁切**：清画布孤立对象、比例换 Fit to Page，分步排查见 [导出PDF排版异常排查.md](导出PDF排版异常排查.md)；
4. **导出的图比例不对**：先查画布校准（方法见 [画布比例校准方法.md](画布比例校准方法.md)），再在导出对话框里核对导出比例项；
5. **导出列表里找不到文件**：换「保存到文件」路径，再从手机文件管理里取。

被导出挡住时，更多同类问题的排查集中在 [常见问题排查与技巧.md](常见问题排查与技巧.md)。
