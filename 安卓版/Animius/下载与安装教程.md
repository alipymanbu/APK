## 一、这套文档对应的安装包

Animius 只有安卓版，没有在应用商店上架，安装方式是下载 `.apk` 文件后手动安装。本套文档对应的那份包信息如下，装之前请先对一遍：

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.3.4 |
| 包名 | `com.lanlinju.animius` |
| 安装包大小 | 约 4.35 MB |
| MD5 | `7AE4CCB657D4CBC83B9A9C3B028001EB` |

需要先说明一点：开源项目的发布节奏比较快，官方仓库上可能已经有更高版本（写作时最新为 1.3.5）。**版本号对不上不代表装错了**，只要包名是 `com.lanlinju.animius`，就是同一个应用。

安装完成后，在手机的「设置 → 应用 → Animius → 应用信息」里能看到安装后的版本号；MD5 要在电脑上算，Windows 可以用 `certutil -hashfile <文件名> MD5` 核对（PowerShell 里用 `Get-FileHash -Algorithm MD5 <文件>`）。MD5 对不上说明文件在传输或下载过程中损坏了，重新下一遍。

## 二、把安装包拿到手机

三种常见做法，任选其一：

1. **手机夸克网盘 App 直接下载**：打开分享链接 → 转存到自己的网盘 → 在 App 内下载 APK，然后点开安装。
2. **先在电脑上保存再传手机**：电脑端打开链接保存文件，用数据线或局域网传到手机存储里，再用手机的文件管理器点击安装。
3. **直接点开分享链接里的文件**：部分浏览器会提示「用网盘 App 打开」，跟着走即可。

安装文件资源入口见本篇头部的 [Animius 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ca1c64bdd1fa)。下载完先别急着装，回到第一节把版本和大小对一眼，尤其是从别处拿到的包。

## 三、安装步骤

1. 在手机文件管理器里找到刚下载的 `.apk` 文件，点击它。
2. 系统通常会弹「为保护你的手机，禁止安装未知来源的应用」，这是没有上架应用商店的应用必然遇到的提示，不是文件有问题。
3. 点提示里的「设置」，把**你用来打开这个文件的来源**（通常是你用的浏览器或文件管理器）的「允许安装未知应用」开关打开。
4. 返回后继续安装，进度条走完点「打开」。
5. 首次启动会请求通知、存储等权限。存储权限要允许，否则番剧下载和本地缓存没有地方放。

## 四、装不上时的对照排查

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包出错」 | 安装包下载不完整或在传输中被改坏 | 重新下载；有条件就按第一节的方法核对 MD5 |
| 提示「应用未安装」 | 手机上已有同包名的旧版本，签名对不上 | 先卸载旧的 Animius，再装这一份 |
| 点安装没反应、卡在安装界面 | 安装未知来源的权限没给到当前这个来源 | 按第三节第 3 步把正确的来源打开 |
| 装完点开就闪退 | 系统版本低于这个版本支持的范围 | 见下一节，换低版本专用的那份包 |
| 安装后出现两个 Animius 图标 | 新旧版本包名不同，同时保留了 | 官方在 1.2.6 的更新记录里就提醒过：安装新版后，建议手动卸载旧版 |

## 五、低版本安卓和电视盒子要用哪一版

官方 README 里写得很明确：**Android TV 或者系统版本低于 Android 8.0 的设备，需要改用 v1.2.1 这一版**。

也就是说，如果你的设备是电视盒子、投影仪，或者手机系统很老，别直接装本篇对应的 1.3.4 —— 去官方发布页找 v1.2.1 的安装包。这条信息如果和你手上那份包的说明不一致，以官方发布页当时显示的为准。

电视端还有两个已知短板，装之前先有个心理准备：

- **遥控器操作不完整。** 官方仓库里有人提过「TV 端按遥控器 OK 键不能暂停播放，不能唤出播放条」；同时也能看到「Android TV 遥控器支持与播放器控制栏重构」这类改进提案，说明这块还在补。
- **个别电视上会黑屏。** 仓库里有用户反馈在 TCL 电视上运行时整机黑屏。这类现象和具体型号、系统版本强相关，遇到时先确认装的是 v1.2.1、再换台设备对比一下。

如果你的主力是电脑或手机、只是想偶尔投到大屏，这条路走不通 —— 官方功能列表里没有投屏功能，可对照[和 Kazumi、Animeko 有什么不一样.md](和 Kazumi、Animeko 有什么不一样.md)第三节。

## 六、以后怎么更新

官方在 1.2.6 的更新记录里写明，应用内增加了自动检测版本更新的功能，间隔周期为每三天。检测到新版本后应用会给出提示，但**实际的下载和安装还是要你自己来**，因为这类应用没有应用商店的自动更新渠道。

手动更新就是重复第三节的步骤，直接覆盖安装即可。另外，本套文档对应的安装文件资源是分享链接形式，后续换了版本号，文件夹分享入口本身不变。

## 七、装完后的两项初始设置

- 进设置把「下载目录」选一次，避免下载的番剧散落在系统默认位置，见[离线下载与下载目录怎么设置.md](离线下载与下载目录怎么设置.md)。
- 打开任意一部番剧试播一下。换个源、切个线路是否正常，直接决定后面用起来顺不顺，见[动漫源切换与播放打不开怎么排查.md](动漫源切换与播放打不开怎么排查.md)。
