# 动漫源切换与播放打不开怎么排查

> Animius 只是聚合第三方动漫源，本身不存视频，所以「打不开」多数是源或线路的问题，而不是应用坏了。本篇按「应用 → 数据源 → 线路」三层给排查顺序，并配一张现象对照表。

## 一、先分清是哪一层出问题

播放链路其实是三段，卡在哪一段，处理方式完全不同：

1. **应用本身**（界面、搜索、时间表能不能正常打开）；
2. **数据源**（这个源还能不能拿到番剧列表和剧集列表）；
3. **具体线路**（这一集的实际播放地址通不通）。

排查顺序就是从上往下。如果连首页都刷不出来，先别怪源；如果首页正常、某部番点进去是空的，那是源的问题；如果番剧详情和剧集列表都正常，只有点播放转圈，那大概率是线路问题。

## 二、换源：官方更新记录里出现最多的一类修复

官方每次更新的条目里，「修复某动漫源」是出现频率最高的一类 —— 这说明**源失效是这类应用的日常，不是异常**。你手上的 1.3.4 相对于更早的版本，就包含「增加新的动漫源」这类改动。

具体做法：

1. 在应用里找到数据源切换入口（一般在设置里，也可能在番剧详情页；不同版本位置和措辞会有差异，以你手机上实际显示为准）。
2. 换成另一个源，回到同一部番，重新打开详情页。
3. 列表能出来、剧集能列全，就说明新源可用，正常播放即可。

官方在 1.2.8 的更新记录里提到优化过数据源切换对话框的样式 —— 如果你在界面上看到一个切换源的弹窗，那就是这个入口。

需要明确一点：**能换的只有应用内置的那几条源**。官方功能列表里没有自定义源、导入规则、安装扩展这类功能，仓库里也一直有人提「可以添加播放源的功能」「增加番剧源」这样的需求 —— 说明截至写作，源由作者随版本维护。所以「换源」这个动作的边界很清楚：

- 换内置的另一条源，看能不能用；
- 内置的都试过还不行，就只能等作者在下一个版本里换掉它。

源数量不是固定值，会随版本增减，以你当前版本里实际列出的为准。如果你要的正是「源我说了算」，那这条路线的工具本身就不合适，对照见[和 Kazumi、Animeko 有什么不一样.md](和 Kazumi、Animeko 有什么不一样.md)第三节。

## 三、同一部番有多条线路时怎么选

从 1.2.7 起，应用增加了**剧集多线路选择**的功能。同一个源里，一集往往有不止一个播放地址，表现差别很大。

- 默认线路播放异常时，在播放页找线路切换（列表或按钮形式），逐个往下试；
- 不用一开始就试全部，试到能正常出画面、不频繁缓冲的那条就固定用它；
- 一部番换源之后，线路也要重新选一次，不要沿用上一个源的判断。

## 四、按现象对照处理

| 现象 | 先做什么 | 为什么 |
| --- | --- | --- |
| 首页能刷出来，某部番详情页空白 | 换源 | 这个源缺这部番的元数据 |
| 详情页正常，剧集列表缺集或只有几集 | 换源 | 该源的剧集列表抓取不全，官方更新记录里也有过同类修复 |
| 剧集列表完整，点播放一直转圈 | 换线路 | 该播放地址不通或响应太慢 |
| 播了几秒卡住、反复缓冲 | 换线路；仍不行就换源 | 单条线路带宽不足 |
| 有声音没画面、或者黑屏 | 换线路；不行就改用外部播放器播放 | 内置播放器与该编码不兼容时会这样，详见[播放倍速与外部播放器怎么设置.md](播放倍速与外部播放器怎么设置.md) |
| 老番能播，当季新番播不了 | 隔一段时间再看，或换源 | 新番上线到源更新有延迟 |
| 每个源、每一集都不行 | 查手机网络本身 | 应用能打开首页说明网络通，但播放走的地址可能被当前网络拦了，换个网络（比如切到移动数据）试试 |

## 五、播放没声音、弹幕也不显示

这两种现象常常一起出现，但原因不同：

- **没有声音**：先确认是不是外放了其他设备（蓝牙耳机连着），再换线路试。线路本身音轨缺失也会导致没声音。
- **弹幕不显示**：弹幕和播放地址是两条链路，换源能解决播放不代表弹幕也会恢复。官方在 1.3.1 修过一次「弹幕无法播放」，在 1.3.0 起本地缓存的视频也支持弹幕。具体处理见[弹幕怎么开与不显示怎么办.md](弹幕怎么开与不显示怎么办.md)。

## 六、反馈前先做的两件事

官方在更新记录里对反馈的要求是：**先更新到最新版，再带日志反馈**。所以在去仓库 Issues 提问题之前：

1. 确认你用的是不是最新版本（本篇对应的 1.3.4 写作时官方已发布 1.3.5，先比对一下）；
2. 记清楚是「哪个源、哪部番、第几集、什么现象」，这几项缺一个，别人都很难复现。

顺带一提，官方在 1.2.5 的更新记录里提到增加过崩溃日志报告功能，出现闪退类问题时可以从应用里把日志导出，附在反馈里。
