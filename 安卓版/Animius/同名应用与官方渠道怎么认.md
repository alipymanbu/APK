## 一、先记住三条硬标识

「Animius」这个词被不止一个产品用过，光看名字分不出来。认这个看番应用，认下面三条：

| 标识 | 值 | 说明 |
| --- | --- | --- |
| 包名 | `com.lanlinju.animius` | 最可靠的一条，装好后在应用信息里能看到，改不了 |
| 来源仓库 | `https://github.com/lanlinju/Animius` | 开源项目本体就在这，许可为 GPL-3.0 |
| 平台 | 只做安卓 | 项目只有安卓版，没有 iOS 版 |

反过来也能用来排除：**凡是提供 iOS 版本下载的所谓「Animius 官网」，都不是这个开源项目**。有些站点会把它写成「二次元创作工具」「动漫创作平台」，还配一个 iOS 下载按钮，那描述的对象和这个看番应用不是一回事。

## 二、官方渠道只有 GitHub 那一处

这个项目没有独立官网域名（仓库里也没有填官网地址），官方的资料与安装包都挂在 GitHub 上：

- 项目首页：`https://github.com/lanlinju/Animius`
- 发布页（找安装包的地方）：`https://github.com/lanlinju/Animius/releases`
- 问题反馈：仓库的 Issues 页

有几个容易让人误判的点，提前说清楚：

1. **README 里的下载链接指向的是旧仓库名。** 官方 README 的下载地址写的是 `https://github.com/lanlinju/Anime/releases/latest`，仓库改过名，GitHub 会自动跳到 `Animius`。看到链接里是 `Anime` 不用怀疑，点进去落到哪就是哪。
2. **应用在 1.2.6 改过一次名称。** 官方更新记录里写明「修改应用的名称为 Animius」，并提示安装新版后手动卸载旧版。所以你可能在手机里见过两个图标或两个名字，这是改名前后的版本同时存在导致的。
3. **GitHub 上的星标数、更新日期都是公开可查的**，别人转发的截图、第三方下载站里的介绍无法核实，不要拿来当判断依据。

## 三、第三方下载站的三个坑

搜索引擎前排经常是各种软件下载站。它们的内容大多是拼凑的，实际踩过的坑有三类：

- **包被二次处理过**。有些下载站会放重新打包过的包，用吸引点击的标题引流，签名和官方的不一致。这类包不要装 —— 一是来路不明，二是以后想装官方新版会因为签名冲突装不上，得先卸载。
- **大小对不上**。同一个版本号，不同站点给出的安装包大小能差十倍（例如把 4 MB 出头的包标成 40 MB 级别）。大小对不上，基本可以判断不是同一个文件。
- **版本号和内容对不上**。写作时官方发布页最新为 1.3.5，而不少站点的页面还停在 1.3.4 甚至更早，却写着「最新版」。版本以官方发布页为准。

判断方法很简单：**拿到任何一份包，先看包名是不是 `com.lanlinju.animius`**。从本套文档给出的 [Animius 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ca1c64bdd1fa) 取到的那份，包名与版本号对照见[下载与安装教程.md](下载与安装教程.md)第一节。

## 四、装完了怎么再确认一次

安装之后按这个顺序看一遍，三步都能对上就没有认错：

1. 系统「设置 → 应用 → Animius → 应用信息」，看版本号是不是 1.3.4；
2. 同一个页面往下找包名，是不是 `com.lanlinju.animius`；
3. 打开应用，看首页是不是番剧推荐 + 底部有搜索、时间表这类入口。如果打开后是绘图、生成图片之类的界面，那就是另一个同名产品，卸载即可。
