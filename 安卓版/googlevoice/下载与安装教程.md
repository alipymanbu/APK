```powershell

```

## 二、安装步骤

1. 手机打开 **设置 → 应用 → 特殊应用权限 → 安装未知应用**，给文件管理器（或你用来打开 APK 的那个应用）开启安装权限；不同品牌手机的路径叫法略有差别，找「未知来源」「安装未知应用」字样即可。
2. 用文件管理器点开下载好的 `.apk`，确认界面上显示的包名是 `com.google.android.apps.googlevoice`，点安装。
3. 装完先别急着申请号码，先把下面两节的系统要求与权限看完。

## 三、系统要求

- 官方帮助给出的支持范围是 **Android 最近 2 个大版本**，同时支持 Chrome OS、macOS、Windows；其他平台可能只有部分功能。
- 网页端（`voice.google.com`）支持 Chrome、Edge、Firefox、Safari 的当前版本与前一个大版本。
- 各第三方下载站标注的「最低 Android 版本」并不一致（有的写 Android 8.0，有的写 Android 12），与官方口径对不上时**以官方页面显示为准**。

## 四、首次打开

1. 登录你的 Google 账号 —— 号码与全部设置都绑在这个账号上，登录前先确认右上角是哪个账号，用错了以后换绑比较麻烦。
2. 应用会申请三类权限：**麦克风**（通话要用）、**联系人**（拨号与搜索用）、**通知**（来电和短信提醒）。这三项直接决定电话能不能响、有没有声音，建议全部允许。只允许通话却拒绝通知，来电就只会变成「未接」。
3. 登录后看不到号码是正常的 —— 号码要按 [注册与选号流程.md](注册与选号流程.md) 单独申请。
4. 装完出现闪退、卡在登录页或打不开，按 [收不到来电和短信的排查.md](收不到来电和短信的排查.md) 从上往下走一遍。
