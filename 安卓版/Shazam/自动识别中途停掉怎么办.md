# Shazam 自动识别中途停掉怎么办

> 自动识别明明开着，认出一两首之后就没动静了，或者锁屏几分钟后彻底安静——本篇讲清是哪个机制在背后掐断它，以及怎么在你自己的手机上把这个限制放开。

## 一、先确认它确实是被"掐断"了

自动识别失效的表现通常不是报错，而是**安静地停下**：开头几分钟还能一首接一首地认，之后就没了动静；或者屏幕一锁、切到别的应用一会儿，回来发现这一段里的歌一首都没记上。应用本身没被关掉，通知栏那条常驻提示可能还挂着，它就是不再认了。

判断办法：开着自动识别（连续模式），锁屏放在一直在放歌的地方，过十分钟回音乐库看多了几首。**只多了开头一两首、后面全断**，就可以确定是系统在后台把它限制住了，而不是收音或曲库的问题。

先排除一种"假故障"：如果开的是**单一结果模式**，它认出一首就自动关闭，那是设计如此，不是被掐断。两种模式的差别见 [自动识别与浮窗通知设置.md](自动识别与浮窗通知设置.md) 第一节。

## 二、谁在掐它

两层机制叠在一起，都会落在自动识别头上：

1. **安卓系统自身的省电机制**：屏幕关闭、设备静止一段时间后，系统会削减后台进程和网络访问。
2. **厂商额外加的一层省电策略**：小米、华为、三星、OPPO、vivo 等都在原生之上又加了自己的后台管理，比原生严得多，典型做法是"一段时间不用就进入休眠"或直接冻结后台。

自动识别要一直用麦克风、还要持续发网络请求，正好是这两层都盯着的对象，所以它属于最容易被掐断的一类功能。这不是 Shazam 特有的毛病——消息应用的推送迟到、闹钟不响，根子是同一套机制。

## 三、通用兜底：三件事

在系统设置里**直接搜关键词**，比一层层点进去快得多。三个关键词：`电池优化`、`应用启动管理`（有些系统叫 `自启动`）、`后台`。

1. **允许后台活动**：进"应用启动管理"，关掉 Shazam 的"自动管理"开关，在随后弹出的选项里勾上"允许后台活动"。很多国产系统默认的自动管理会限制后台，这一步是关键。
2. **取消电池优化**：进"电池优化"，把 Shazam 设为"不允许优化"（也就是允许它不受省电限制）。
3. **锁定后台卡片**：打开一次 Shazam，进多任务界面，把它的卡片下拉到底直到出现锁图标。锁住的卡片不会被"一键清理"带走。

## 四、各品牌的入口大致在哪儿

系统版本不同，路径会变。下表只是大致位置，找不到就回上一节用关键词搜索——搜索通常比找路径快。

| 品牌 / 系统 | 大致路径 |
| --- | --- |
| 原生 Android（Pixel 等） | 设置 → 应用 → Shazam → 电池 → 不受限制 |
| 小米 / Redmi / POCO（MIUI、HyperOS） | 设置 → 应用设置 → 应用管理 → Shazam → 省电策略设为"无限制"；安全中心 → 自启动 → 打开 Shazam |
| 三星（One UI） | 设置 → 电池和设备维护 → 电池 → 后台使用限制，把 Shazam 排除在"自动进入休眠"之外；应用电源管理里设为"不受限制" |
| OPPO / realme / 一加（ColorOS） | 设置 → 电池 → 应用耗电管理 → Shazam → 允许后台运行 |
| vivo / iQOO | 设置 → 电池 → 后台耗电管理 → Shazam → 允许后台高耗电；i 管家 → 自启动管理 → 允许 |
| 华为 / 荣耀 | 设置 → 应用 → 应用启动管理 → 关掉自动管理 → 勾选"允许后台活动"；设置 → 电池 → 电池优化 → Shazam 设为"不允许" |

华为与荣耀的官方帮助里还额外列了一条容易漏的：**"休眠时始终保持网络连接"**（设置 → 电池 → 更多电池设置）。自动识别要联网比对，这一条关掉的话，锁屏后就传不出去了，认了也白认。

以上路径截至本篇写作时的系统版本，之后系统改版可能会挪位置，以你手机上实际显示为准。

## 五、改完怎么验证

1. 开自动识别（连续模式），锁屏放在持续放歌的环境里。
2. 过十分钟回音乐库看：**应该是每隔一段时间就多出几首**，而不是只在开头多一两首。
3. 还是断在开头，就回第四节把该品牌的项再核一遍。最常见的漏项是"自启动"没开——部分系统重启之后会把它复原。

## 六、几个提醒

- **重启后复查一遍**。这类后台设置在系统更新或重启后有被重置的情况。
- **超级省电模式会覆盖上面的设置**。开着它，自动识别必然停。
- **第三方管家类应用是另一层拦截**。"加速 / 省电 / 清理"这类工具往往自己也在清后台，把它对 Shazam 的限制一并放开，或者干脆不用它清后台。
- **只在需要时开自动识别**。放开后台限制之后它确实会持续工作，也就意味着持续耗电——"要连续识别的时候开、认完就关"，是既留住功能又不让它失控的做法。
- 上面都做对了还是不稳，就照 [常见问题与排查.md](常见问题与排查.md) 里"耗电明显变快"和"权限给过了，还是收不到声音"两节交叉排一遍。
