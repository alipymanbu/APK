# Shazam 识别不出来怎么排查

> 本篇专讲一个场景：明明按了识别，却没结果。先按现象分类，再按顺序排查六步，另外交代断网时的"待识别"机制、曲库与地区差异，以及最后怎么用换一份安装包来排除变量。

## 一、先分清是哪一种"认不出"

同样是"认不出来"，现象不同，原因和该走的顺序也不同。先对号入座，比一股脑把能试的都试一遍快得多：

| 现象 | 大概是什么 |
| --- | --- |
| 一直转圈，停在聆听状态不结束 | 收音或网络卡住了 |
| 听了几秒，直接提示没认出来 | 收到了声音，但曲库里没匹配上 |
| 按下去完全没反应，连聆听状态都不出现 | 麦克风权限或被占用的问题 |
| 出了结果，但不是正在放的那首 | 环境太吵，或者认到的是同一段旋律的另一个版本 |

后面几节按这个分类往下写，碰到你这个现象就跳到对应那一节。

## 二、按这个顺序排查六步

从最常见、最省事的开始，前一步过了再走下一步：

1. **麦克风权限还在不在**。去"设置 → 应用 → Shazam → 权限 → 麦克风"确认是"允许"。之前给过不代表现在还在——安卓会重置长期不用应用的权限，权限管家类的应用也可能把它收走。这里有一个当场就能用的判据：**安卓 12 及以上会在状态栏显示一个麦克风使用中的小图标**；按了识别却看不到这个图标，就说明声音根本没进来，问题一定在权限或占用上，不用再怀疑网络和曲库。
2. **有没有别的应用正占着麦克风**。通话、语音消息、视频会议、录音这些一旦在跑，麦克风就被它们占住，识别收不到任何声音。挂掉电话、关掉会议应用再试一次。
3. **网络通不通**。曲库匹配在服务端完成，断网，或者连着一个受限的公共无线网络（酒店、机场那种要先在网页上点"同意"才能上网的），识别会卡住或直接失败。这种"认证页网络"最容易骗人：手机信号栏显示已连接，但应用的请求全被拦在登录页上，界面看起来就是一直在转圈。换到自己手机的热点或家里的无线网络试一次就能排掉。
4. **麦克风有没有被挡住或脏了**。手机壳开孔不对齐、贴膜盖住了收音孔、听筒附近积了灰，收到的声音都会变得很差。用软毛刷清一下，别拿金属东西去捅。想快速验证，把手机从壳里取出来、立起来拿在手上试一次。
5. **姿势和环境**。把手机靠近音源；避开前奏、间奏、纯鼓点，专挑人声或主旋律进来的那一段；你同时在说话、或者旁边有人聊天，成功率都会掉。
6. **确认这不是本身就难认的歌**，见第四节。

这六步都过了还认不出，再往下看第三节（断网）和第五节（手机自己在放歌）。

## 三、断网时为什么会出现"待识别"

没有网络的时候，Shazam 仍然能记录：它把听到的这一段先在本机生成数字指纹存下来，等你重新联网时再去曲库匹配，匹配上了就进音乐库。所以断网时按下去未必立刻报错，可能只是先把这件事记下来了。

两点要知道：

- **重新联网后不会立刻自动出全部结果**，需要给它一点时间；如果某首歌最终没匹配上，它会从待识别列表里消失，不会一直挂着误导你。
- **离线只解决"记下来"这一步，不解决"认出来"**。指望在飞机上把一整张专辑认完，是不现实的。

## 四、有些歌，本来就更容易认不出

同一段旋律在这个工具上认不出、换个识曲工具认出来了，或者反过来，都是常事。下面几类会明显更难认：

- **太新的歌**：曲库收录和上架有时间差，刚发布不久的曲子未必认得出。
- **冷门曲、翻唱、纯器乐**：官方原版好认，改编版、翻弹版、纯钢琴版差别就大。
- **现场版、混音版**：同一首歌的不同版本，容易被认成原版，或者干脆认不出。
- **翻录出来的声音**：隔着耳机外放、隔着一段直播录音，音质掉了，匹配也跟着掉。
- **你是在哼，不是在放**：Shazam 比对的是**正在播放的录音**的音频指纹，不是旋律本身。所以对着它哼一段调子、清唱、吹口哨，都认不出来——这是能力边界，不是设置问题。官方对它的定位也是"识别周围正在播放的音乐"，不含哼唱找歌这一项；想靠哼唱找歌，得换支持这类搜索的工具。

还有一层是地区：**能用的功能、能连的音乐服务在不同国家和地区并不一致**。所以"别人那认出来能直接跳去听，我这不行"未必是你装错了，可能只是这个功能在你所在地区不可用——官方说明里也明确写了功能可用性因国家/地区而异。

一句话概括：识别率这件事任何识曲工具都拿不稳，个别歌认不出不等于手机或应用坏了。

## 五、手机自己放出来的声音，主按钮听不到

如果音乐是从你手机里放出来的——短视频、直播、播客、音乐 App，哪怕插着耳机——用主按钮那套"听环境音"的做法是识别不到的：声音根本没进麦克风。

这种情况要换成弹出式 Shazam 或自动识别，它们取的是设备内部正在播放的音频。开启步骤见 [自动识别与浮窗通知设置.md](自动识别与浮窗通知设置.md)。要留意的是，弹出式那条路对"背景音乐 + 人声解说"混在一起的音频同样吃力，认不出属于正常范围。

## 六、最后一步：把安装包这个变量排掉

上面全试过还是不行，就排除掉"安装包本身有问题"这个可能：回到文首那条 [Shazam 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9b9353c62aed) 取一份完整的包，覆盖安装一次。**覆盖安装不用先卸载——卸载会丢掉本地历史**；覆盖安装的做法与注意事项见 [下载与安装教程.md](下载与安装教程.md) 第六节。

**这一步是排除法，不是断言你手上那份包一定有问题。** 覆盖装好之后如果正常了，说明之前那份包在下载或安装环节出了问题；如果还是不行，原因就在系统侧或环境侧，别再反复重装了。装完仍然不行的，照 [常见问题与排查.md](常见问题与排查.md) 往下看。
