## 一、音乐库：识别过的歌都在这

识别历史的正式名字是"音乐库"：在 Shazam 里划到音乐库，或者点音乐库按钮，就能看到所有识别记录。列表按时间排，用自动识别认出来的会按日期分组——一集剧看完，去那一组里能一次找齐，这是它比手工记录省事的地方。

每条记录点开能看到歌名、艺人、专辑，并可看歌词、看 MV、跳到音乐 App 播放，另外还有相似推荐和这位艺人的其他热门曲目。这些内容怎么用，见 [识别的歌去哪听与歌词视频.md](识别的歌去哪听与歌词视频.md)。

单条不想要了：在这首歌旁边点更多操作，选"从音乐库中移除"。

## 二、不登录也能用，但存不住

先把一件事说清楚：**不登录照样能识别，功能一点都不少**。登录要解决的不是"能不能用"，而是"认下来的这些歌归谁、能不能带走"。安卓端的官方口径是：只有登录账号，识别到的歌才会保存进账号下的音乐库；不登录时，数据挂在一个不关联你个人身份的随机 ID 下。

这带来两个很实际的后果：

- **不登录的历史只存在这台手机上**，下面这几件事都会让它消失：卸载应用（安卓默认连应用私有目录一起删）、换手机或恢复出厂设置、系统清理工具把应用数据清掉；
- **没法跨设备看**，也没法在网页端查，因为它不属于任何一个账号。

**"卸载重装一下试试"这个习惯动作，对识别历史来说是有代价的。** 出现异常时的第一反应不该是卸载重装——覆盖安装就能解决大多数问题，而且不动历史（覆盖安装的做法与"为什么不丢历史"，见 [下载与安装教程.md](下载与安装教程.md) 第六节）。在意的历史，先登录账号同步走，再做其它操作。

## 三、登录：Google 账号或邮箱都行

登录之后历史会归到账号下，之后识别到的歌也会自动同步进去。操作就三步：

1. 进 Shazam，划到音乐库，点设置按钮。
2. 点"注册 / 登录"。如果已经登录，这一项不会显示。
3. 两条路选一条：
   - **用 Google 账号**：点"使用 Google 登录"，跟着提示走完；
   - **用邮箱**：点"使用电子邮件地址登录"，输入邮箱 → 用同一台设备去收信 → 点邮件里的确认链接。没收到就回应用里点"重新发送"，或者从头再走一次。

登录本身是免费的，只用于保存和同步识别记录。

有一个容易忽略的点：**退出登录之后，之前识别过的歌仍然留在账号里，但新认到的歌不会再加进去了**。所以"先退出登录试试"这类排查动作，别在你还想留着的历史上做。

## 四、跨设备与网页端

同一个账号在另一台安卓设备上登录，音乐库就跟着过去。想在电脑上看，用同一账号登录 [www.shazam.com/myshazam](https://www.shazam.com/myshazam) 也能看到自己识别过的歌——想把很久以前认到的一首歌名复制到别处，走这里最快。

有一点必须提前说清：**账号入口是按平台分开的**。安卓端用的是 Google 账号或邮箱，iPhone 端用的是 Apple 账号，两边不是同一个入口。所以"我在 iPhone 上识别过的歌能不能在安卓上看到"，取决于当初有没有把两边挂到能互通的账号体系上，不能想当然地认为一定同步。

## 五、删一条 / 删账号 / 导出数据

| 你想做的事 | 怎么做 |
| --- | --- |
| 删掉一首 | 音乐库里找到该条 → 更多操作 → 从音乐库中移除 |
| 删除账号 | 音乐库 → 设置 → 划到底部点"退出登录"，并且在其它设备上也退出登录；然后访问 [www.shazam.com/privacy](https://www.shazam.com/privacy)，在页面底部找"删除你的账号"，用要删的那个账号登录后确认 |
| 拿一份自己的数据 | 访问 [www.shazam.com/privacy](https://www.shazam.com/privacy)，点"下载你的数据"，登录后按提示填写接收邮箱，数据会发到邮箱里 |

关于删除账号要留个底：**账号删掉之后，挂在它下面的识别历史也一起没了**，恢复起来不现实。删除之前建议先导出数据，或者把要留的歌名记到别的地方。官方说明里提到，关联服务中的个人可识别信息会在删除后 30 天内清理完毕。

## 六、换手机怎么不丢历史

1. **旧手机上先登录账号**（如果一直没登录），等历史同步上去。这一步不能跳：本地记录不会自己跟着账号走，得先传上去。
2. 新手机上装好 Shazam（见 [下载与安装教程.md](下载与安装教程.md)），用**同一个账号**登录。
3. 打开音乐库核对条数。差得多的，回旧手机确认它是否已经登录并完成同步。
4. 确认无误之后再处理旧手机上的应用。

这个顺序就是全篇最要紧的一句话：**先登录、后卸载**。反过来做，存在本地的那部分记录就带不过去了。
