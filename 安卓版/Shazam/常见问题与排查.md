## 一、装不上：提示"应用未安装"或"解析包出现问题"

装不上大多不是"文件有问题"，而是下面这五种情况之一；按出现的可能性从高到低排，一条一条往下查就行。识别本身认不出、而不是装不上的排查，另见 [识别不出来怎么排查.md](识别不出来怎么排查.md)。

1. **包没下完整**。回头核对文件大小是不是 43.22 MB 左右（对照表在 [下载与安装教程.md](下载与安装教程.md) 第一节）。差得多就重新下一遍，这是最常见的原因。
2. **系统版本太低**。系统会直接拦下来，判断办法见同一节的说明，不用猜。
3. **装过一个签名不同的同名应用**。之前装过从别处来的 Shazam，和这一份签名不一致，系统会拒绝覆盖。这种情况只能先卸载旧的再装这一份——**卸载会清掉本地历史**，在意的话先去应用里登录账号同步（见 [识别历史与账号同步.md](识别历史与账号同步.md)）。
4. **存储空间不够**。这一份安装包本身只有 43.22 MB，装完之后还要加缓存和识别数据，实际占用会更大，所以装之前要让手机留出明显富余的可用空间。想看它到底占了多少，装好后去"设置 → 应用 → Shazam → 存储"看总量。
5. **安装来源没放行**。回看 [下载与安装教程.md](下载与安装教程.md) 第三节，"允许安装此来源的应用"要单独给"你用来打开文件的那个 App"开权限，只给文件管理器开是不够的。

## 二、打开就闪退

1. **先重启一次应用**：从最近任务里划掉，重新打开。
2. **清一次缓存，但不要清数据**：系统"设置 → 应用 → Shazam → 存储 → 清除缓存"。清缓存不动识别历史，清数据会动，别点错。
3. **覆盖安装一次**：到文首那条 Shazam 安装文件资源的链接重新取一份装上去，把"安装包在下载中被改坏"这个变量排掉。覆盖安装不用先卸载，历史不丢。
4. **还不行就换设备验证**：装到另一台手机上对比，能确认是这台设备的系统兼容问题还是普遍问题。

## 三、权限给过了，还是收不到声音

- **权限可能被系统收回了**。安卓会重置长期不用应用的权限，权限管家类应用也会额外拦一层。去"设置 → 应用 → Shazam → 权限"把麦克风再看一遍。
- **有别的应用在占用麦克风**。通话、录音、视频会议、常驻监听的语音助手都会占住它，全部关掉再试。
- **物理遮挡**。手机壳、贴膜、平放在桌面上都可能堵住收音孔。取掉壳、立起来拿在手上试一次，有变化就是遮挡问题。
- **隐私保护模块在拦截**。部分国产系统自带这类模块，会单独限制应用权限，把它对 Shazam 的限制放开。

## 四、识别历史不见了

先回答一个问题：**你之前登录过账号吗？**

- **没登录过**：历史只在这台手机的本地，卸载、清数据、换机都会丢，且恢复不了。以后想留有，先登录（见 [识别历史与账号同步.md](识别历史与账号同步.md)）。
- **登录过**：在新设备上、或者网页端用同一个账号登录看，历史一般还在。看不到就确认登录的是当时那个账号（Google 账号或邮箱），别一个账号查另一个账号的记录。
- **只在网页端看不到**：官方网页端入口是 [www.shazam.com/myshazam](https://www.shazam.com/myshazam)，用对应账号登录后再查。

## 五、弹出式的浮窗按钮找不到了

- **先确认开关还开着**：Shazam → 设置 → "弹出式 Shazam"。系统更新、权限被重置都可能把它关掉。
- **确认"允许在其他应用上层显示"还给着**：这是浮窗能显示的前提，被系统收回之后按钮会直接消失，应用里也未必提示原因。
- **手动把按钮叫回来**：从屏幕顶部下拉，点那条 Shazam 通知，浮窗会回到屏幕上。
- **别把按钮拖到 X 上**：拖到屏幕底部的 X 是"移除"操作，移除之后要按上一条的办法叫回来。详细步骤见 [自动识别与浮窗通知设置.md](自动识别与浮窗通知设置.md)。

## 六、耗电明显变快

最常见的原因是自动识别一直开着——它要持续使用麦克风。按顺序处理：

1. 不用的时候把自动识别关掉（做法见 [自动识别与浮窗通知设置.md](自动识别与浮窗通知设置.md)）。
2. 改用"单一结果模式"，认出一首就停，比连续模式省得多。
3. 把浮窗和通知栏常驻入口也关掉，常驻的东西一直在，多少都有代价。
4. 在系统的电池用量排行里核对一下 Shazam 的位置。关掉自动识别之后它还排在前列，再考虑清缓存、覆盖安装。

"按一下才识别"这种用法本身耗电很少，不用为它担心。

## 七、自动识别开着开着就停了

表现是：开头能认出一两首，之后就没动静了；或者锁屏一会儿，回来发现这一段的歌一首都没记上。**这多半不是应用坏了，而是系统在后台把它限制住了。**

安卓的省电机制会削减后台进程，各厂商（小米、华为、三星、OPPO、vivo 等）还各自加了一层更严的后台管理，自动识别这种"要一直用麦克风、一直联网"的功能正好是被限制的头号对象。处理就三件事：允许后台活动、取消电池优化、锁定后台卡片；各品牌的具体入口见 [自动识别中途停掉怎么办.md](自动识别中途停掉怎么办.md)。

先排除一种假故障：如果你开的是**单一结果模式**，它认出一首就自动结束，那是设计如此，不是被掐断。

## 八、通知栏一直挂着一条 Shazam

这是设置里"通知栏"那一项的效果，不是出错，也不是卡住了——它就是让你在任何界面下拉一下就能识别。

不想要：进 Shazam → 设置 → 把"通知栏"关掉，那条常驻通知就消失了。关掉之后仍然有主按钮、桌面图标菜单、快速设置和小组件这几个入口可用，见 [识别歌曲的几种方式.md](识别歌曲的几种方式.md)。

## 九、有些功能在别人那有，我这里没有

先分清是哪一类原因，再决定要不要折腾：

| 你的感觉 | 常见原因 |
| --- | --- |
| 找不到某个功能 | 安卓版和 iOS 版的功能并不完全一样；你所在地区可用的功能也可能不同 |
| 跳转听歌失败 | 对方音乐 App 没装、没登录，或者不是它的订阅用户 |
| 看不到歌词 | 这首歌本身就没提供歌词 |
| 没有"我的 Shazam 曲目"歌单 | 平台或地区差异，或者音乐 App 还没接上 |
| 手表上不能识别 | 手表不是 Wear OS 系统，或者手表上没装对应组件 |

**功能可用性因国家/地区而异**这件事，官方说明里就写了，所以"同一版本在不同地方表现不一样"属正常，不必反复重装试。

## 十、版本号和别处看到的不一样

在网上看到 Shazam 是另一个版本号（比如比这一份更新的 16.x，或者跨平台页面上的另一套编号），这不是出错：

- 网上写的一般是**官方当前最新版**，而这一份包里是发布时的那一版，两者常常不是同一个；
- **安卓版和 iOS 版用的不是同一套版本号**，跨平台对比没有意义。

判断手上这份是不是本套文档对应的版本，只看两项：包名 `com.shazam.android`，版本号 `16.51.0-260716`。

## 十一、安装包删了、找不到了

随时回文首那条 [Shazam 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9b9353c62aed) 重新取一份。之前已经转存到自己网盘里的，不受原分享是否还在影响；这一份的版本、包名、大小与 [下载与安装教程.md](下载与安装教程.md) 第一节的对照表一致。

想确认手机上装的是不是同一份，在应用里点"设置 → 关于"，核对它显示的版本号即可。
