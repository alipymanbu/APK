## 一、先说清这份包是哪一个版本

Shazam 是一款音乐识别应用，装着它的手机听几秒周围的声音，就能告诉你这是什么歌、谁唱的，并给出歌词、MV 和相关推荐。它免费，装机本身也不复杂，真正容易卡住的只有两处：安装包从哪来，以及权限怎么给对。

动手之前，先对着下表确认你手上这一份是不是对的：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | Shazam |
| 开发者 | Apple Inc. |
| 包名 | com.shazam.android |
| 版本号 | 16.51.0-260716 |
| 安装包大小 | 43.22 MB |
| 安装包 MD5 | b1b88005dac673998f40232ee45e8221 |
| 适用设备 | 安卓手机、安卓平板（另有 Wear OS 手表上的用法） |
| 是否需要联网 | 识别、看歌词、跳转听歌、同步历史都要网络；断网时能先把这一段记下来，联网后再出结果 |

**版本号要对得上，但别拿别处的版本号来对。** 你在搜索结果里看到的 Shazam 版本号，大多是官方当前最新版，和这一份未必是同一个；安卓版和 iOS 版用的甚至不是同一套编号。判断"我装的对不对"，只看两项：包名是不是 `com.shazam.android`，版本号是不是上面这一个。

**这里不写死最低系统版本。** 各家第三方页面标注的最低安卓版本互相矛盾（从 Android 6.0 到 11 都有人写），都不是官方口径。最省事的判断办法是：先在手机上打开 [Google Play 上的 Shazam 页面](https://play.google.com/store/apps/details?id=com.shazam.android)，如果显示"此应用与你的设备不兼容"，那就是装不上；能点"安装"，说明你的系统版本够用。真装不上时系统会自己拦下来，不会装到一半坏掉。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享。相比在搜索结果里随手点一个"立即下载"，从网盘转存再下载的好处是：这一份链接是固定的，文件不会被下载站中途替换成别的东西。

1. 在手机上打开 [Shazam 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9b9353c62aed)。手机浏览器或夸克 App 都能打开，**建议用夸克 App**——浏览器下大文件容易被切后台打断。
2. 点"保存到我的网盘"，把文件转存到自己账号下。转存之后，之后下载就不再依赖原分享链接还在不在。
3. 进自己的网盘找到这个文件，点下载，等它落到手机存储里。
4. 下完核对两件事：文件名结尾是不是 `.apk`（这一份的名字形如 `Shazam_v16.51.0-260716.apk`）；大小是不是 43.22 MB 左右。差得多的，多半是没下完整，删掉重来。

如果你更习惯在电脑上操作：在电脑端网盘把文件下载下来，再用数据线拷到手机的 `Download` 目录，效果一样；之后从手机的"文件管理"里点它安装即可。

手上有校验工具的话，可以顺手算一遍 MD5，和上表的 `b1b88005dac673998f40232ee45e8221` 比一比。一致说明传输过程没出错，不一致就重新下一遍。不查也不影响安装，这只是多一层保险。

## 三、安装：系统会拦一次，放行即可

这一份是通过网盘分发、手动安装的，不是从手机自带的应用商店里点"安装"装的，所以点安装包时系统会拦一下，提示"不允许安装来自此来源的应用"之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开"文件管理"，进 `Download`（下载）目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的"设置"，打开**允许安装此来源的应用**开关。
   - 部分机型要去"设置 → 应用 → 特殊应用权限 → 安装未知应用"里，找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独给它放行。
3. 回到安装界面点"安装"，等进度条走完。
4. 出现"打开 / 完成"时，先点"完成"。首次启动前把权限一次性理顺，比进去之后反复弹窗省事。

## 四、首次打开要给的权限

第一次打开时，系统会依次弹权限申请。哪些该给、为什么，对照下表：

| 权限 | 用途 | 建议 |
| --- | --- | --- |
| 麦克风 | 识别歌曲的唯一入口——收不到声就认不出任何东西 | 必须给。给过之后想收回，去"设置 → 应用 → Shazam → 权限 → 麦克风" |
| 通知 | 自动识别的常驻入口、识别结果提示 | 建议给。不给的话自动识别和通知栏那两个入口都用不了 |
| 位置 | 记录你是在哪儿识别到这首歌，结果页上会标出地点 | 可给可不给。拒绝只影响"识别地点"这一项，识别本身照常 |

一个实际会遇到的情况：权限弹窗点快了、误点了"不允许"，之后按识别按钮会没有任何反应。这时不用重装，去系统设置里把麦克风改回"允许"就行。

## 五、装完先做三步自检

不用急着找歌听，先花一分钟确认这三件事，后面出问题也好定位：

1. **能打开、不闪退**：点图标能进到主界面，看到中间那个大按钮。反复闪退的话，看 [常见问题与排查.md](常见问题与排查.md) 里"打开就闪退"那一节。
2. **收得到声音**：用另一台设备外放一段音乐，对着按一下主按钮，看界面有没有进入"正在聆听"的状态。这一步同时验了麦克风权限和收音是否正常。
3. **能出结果**：上一步如果认出了歌名，说明网络和曲库匹配都通了。认不出也不要紧，先照 [识别不出来怎么排查.md](识别不出来怎么排查.md) 走一遍。

三步都过，就可以正常用了。识别不止"打开应用按按钮"这一种做法，其余入口见 [识别歌曲的几种方式.md](识别歌曲的几种方式.md)。

## 六、升级与卸载要注意的

- **升级**：新版本会换一个安装包文件名，直接装新包覆盖即可，一般不用先卸载。**先卸载再装，反而会把没同步走的历史清掉**——安卓默认连应用私有目录一起删。
- **卸载**：卸载会清掉本地保存的识别历史。要留着，先在应用里登录账号（见 [识别历史与账号同步.md](识别历史与账号同步.md)），不要指望卸载重装后数据还在。
- **安装包删了**：任何时候都能回到文首那条 Shazam 安装文件资源的链接重新取一份；已经转存过的不受原分享影响。
