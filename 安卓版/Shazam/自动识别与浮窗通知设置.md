## 一、自动识别：不用一直按着

自动识别解决的是一个具体麻烦：眼前的音乐不是一首就完，而是一首接一首——一集剧的配乐、一家店里的播放列表、一场演出的串场。这种场合如果每首都要你按一下，基本等于放弃。

打开方式：进 Shazam，**长按中间那个大按钮**，弹出模式选择，两个选项的差别是：

| 模式 | 行为 | 适合的场合 |
| --- | --- | --- |
| 单一结果模式 | 认出一首之后自动关闭 | 只想把眼前这一首认出来 |
| 连续模式 | 一直听，连续识别附近播放的音乐 | 一集剧、一场演出、店里连着放好几首 |

选好确认，自动识别就开始工作。**这期间你切到别的应用、甚至把屏幕锁上，它照常识别。**

想关掉，任选一种：

- 回 Shazam 里按一下那个大按钮；
- 长按桌面上的 Shazam 图标，点菜单里的"Auto Shazam"；
- 从屏幕顶部下拉出通知，在自动识别那条通知上点更多操作，选关闭；同一条通知上还能在两种模式之间来回切换。

用自动识别认出来的歌同样进音乐库，并且**按日期分组**。这件事的实际好处是：一集剧看完，去那一组里能一次把认过的歌全找出来，不用逐条翻。

还有一个前提要提前知道：**自动识别需要应用能在后台活下来**。安卓的省电机制加上各厂商自己加的一层后台管理，会在一段时间后把它掐断，表现就是"认出一两首之后就没动静了"。这件事有单独的排查办法，见 [自动识别中途停掉怎么办.md](自动识别中途停掉怎么办.md)。

## 二、弹出式 Shazam：在别的应用里识别

手机自己正在播放的声音——刷短视频、看直播、听播客，哪怕插着耳机——主按钮那条路走不通，因为它听的是环境音。这种情况用弹出式 Shazam：屏幕上浮出一个可拖动的小按钮，点它就识别当前正在播放的音频。

开启步骤：

1. 打开 Shazam，划到音乐库，点设置按钮。
2. 打开"弹出式 Shazam"，按提示进系统设置，在 Shazam 这一项里打开**允许在其他应用上层显示**。
3. 之后在别的应用里，屏幕边缘会出现那个浮动按钮，点它开始识别。
4. 不想留着它，把按钮拖到屏幕底部的 X 上移除。

浮窗按钮不见了想找回来：从屏幕顶部下拉，点那条 Shazam 通知，它会重新回到屏幕上。前提是"弹出式 Shazam"这个开关还开着、"允许在其他应用上层显示"还授权着——这两项任何一项被系统收回，按钮都会直接消失。

有一点要提前知道：**背景里同时有解说和音乐时，认出来的成功率会下降**。有用户反馈，短视频里配的录音室版本曲子一般能认出来，混着人声解说、或者背景音乐压得很低的那种，常常认不出。这不是设置没配好，换用自动识别连续模式也不会更灵。

## 三、通知栏常驻入口

在设置里打开"通知栏"之后，通知栏里会常驻一条"轻点开始识别"的入口。它的用处是：你在任何应用里，下拉通知栏点一下就能开始听，不用切回 Shazam。

它一直挂在那里是设计如此，不代表应用出错或者卡住了。不想看到它，回 Shazam 设置里把"通知栏"关掉即可；关掉之后仍然有主按钮、桌面图标菜单、快速设置和小组件这几个入口可用，见 [识别歌曲的几种方式.md](识别歌曲的几种方式.md)。

## 四、设置页里其余开关逐项说明

进 Shazam → 设置（音乐库里点设置按钮），除了上面两项，还有这些：

| 设置项 | 作用 | 什么时候值得动它 |
| --- | --- | --- |
| 提示和推荐 | 显示优化使用体验的建议，比如加入 Apple Music、把 Shazam 加进快速设置 | 用熟了嫌烦就关掉 |
| 启动应用时自动开始识别 | 一打开应用就开始听，不用按按钮 | 习惯"打开即听"再开；不希望打开就占麦克风就关 |
| 振动提示结果 | 识别成功或失败时震动一下（支持的设备） | 嘈杂场合、手机放兜里时有用 |
| 自动播放视频 | 结果页自动播视频预览，三档：启用 / 仅无线局域网 / 禁用 | 流量紧张就选"仅无线局域网"，在外面不会自动放视频 |
| 外观 | 界面深浅色：深色 / 浅色 / 跟随系统 | 按个人习惯 |
| 管理通知 | 跳到系统里设 Shazam 的通知权限 | 通知不弹、识别完没提示时来这里查 |
| 音乐应用程序偏好 | 点结果里的播放入口时，用哪个音乐 App 打开 | 见 [识别的歌去哪听与歌词视频.md](识别的歌去哪听与歌词视频.md) |
| 关于 | 显示当前版本号，另有诊断报告、重置安装 ID 的入口 | 核对版本号、排查问题时用 |

对照 [下载与安装教程.md](下载与安装教程.md) 第一节那张表，"关于"里显示的版本号是手机上核对"装的是不是这一份"最直接的入口。

## 五、开着自动识别的代价

开着自动识别，等于让麦克风和分析程序持续工作，比"按一下才听"更费电；开得越久、连续识别得越频繁，差别越明显。几条实用做法：

- **不用的时候关掉**。自动识别一整天开着，是最常见的耗电原因。
- **只在确实需要连续识别的场合开**，比如看一集剧、逛一家一直放歌的店。
- **优先用"单一结果模式"**，认出一首就停，比连续模式省电也省流量。
- 想核实是哪在耗电，去系统的电池用量排行里看 Shazam 的位置；关掉自动识别之后它应该明显往后排。

要留意一个反方向的取舍：如果为了省电去限制它的后台（厂商的省电策略默认就会做这件事），结果往往是自动识别先失效，而不是先省电。一边要用、一边要省，得靠"用的时候开、不用的时候关"来平衡，后台限制的具体放开办法见 [自动识别中途停掉怎么办.md](自动识别中途停掉怎么办.md)。

曲库匹配是联网完成的，所以自动识别开着也在持续产生网络请求。用流量的场景下，顺手留意一下数据用量。

## 六、它听到的东西会被存下来吗

官方口径明确：**Shazam 不录制也不存储它听到的音频**，Apple 也访问不到设备上捕捉到的声音。识别过程是把听到的片段生成一段数字指纹，拿去和曲库比对，比对完就结束。

真正被留下来的，是识别结果本身：歌名、艺人、识别时间，以及（如果你给了位置权限）识别地点。这些组成你的音乐库，管理、同步、删除的办法见 [识别历史与账号同步.md](识别历史与账号同步.md)。

设置里"关于"页提供的诊断报告提交与安装 ID 重置，属于排查手段，改动它们不会影响你的识别历史。
