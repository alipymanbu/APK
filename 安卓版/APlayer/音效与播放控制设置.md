## 一、均衡器：先用系统那套

官方说明里均衡器有内置和系统两档，入口在设置里。

- **不确定选哪个就用系统均衡器。** 它与手机自带的音效框架走同一套，和蓝牙耳机的兼容性一般更好；内置那一套适合想单独调、不受系统音效干扰的场景。
- **调之前先选一个中性预设**（如「原声」「平直」一类的档位），再动具体频段。上手就拉两端（大幅提低音、提高频）容易听出失真。
- **改完没变化**：确认改的是**正在生效的那一个**均衡器（内置 / 系统里只有一个是启用状态），以及当前输出设备是不是蓝牙耳机 —— 部分耳机会在连接时接管音效，播放器侧的调整被覆盖。
- 更新日志里出现过均衡器界面单位显示错误被修掉（1.5.9.0 版）与均衡器多处 bug 修复（1.1.8.2 版）的记录，早期版本上数值显示异常属于老问题。

## 二、倍速播放与睡眠定时

- **倍速**：官方说明里播放速度可调，常见用途是听播客、有声书时加速。语速类内容建议 1.2～1.5 倍之间试，音乐类内容加速会明显改变听感。播放页上还有一个临时加速的手势（边缘长按），见 [播放界面手势与快捷操作.md](播放界面手势与快捷操作.md)。
- **调音量**：播放页内可以直接调音量，不用按手机侧键，戴着耳机、手机不在手上时更方便。
- **睡眠定时**：官方说明里这一项在音效与控制里。设置逻辑上有一点值得留意 —— 从 1.1.7 版的更新日志看，**如果正在播放，定时到点会在当前歌曲播完之后才停**，不会在副歌中间突然断掉。
- 两者可以同时开：睡前听书用 1.2 倍速 + 30 分钟定时，是最常见的组合。
- **定时开始之后要改时间**：在计时中再点一次定时按钮即可进去重设或关闭，不用等它走完。

## 三、「淡入淡出」建议先关掉

有用户整理过这一版的一个已知问题：**开启「淡入淡出」效果后，出现「播放 → 暂停 → 切到下一首」这个动作序列时，歌曲在播、时间轴在走，但听不到声音**；把淡入淡出关掉就正常。

遇到「有界面没声音」先按这个顺序处理：

1. 进设置找到「淡入淡出」，关掉它；
2. 回到播放页重新播放一遍；
3. 换歌再试一次，确认是切歌链路的问题还是这一首歌的问题。

这条属于用户反馈的已知行为，不是你的设备坏。同一个问题的其它表现（完全无声、蓝牙耳机没声音）见 [常见问题与排查.md](常见问题与排查.md)。

## 四、「忽略音频焦点」：来电时会不会自动暂停

音频焦点决定「别的 App 出声时，播放器要不要让路」：

- **默认（不忽略）**：来电话、微信语音、短视频起播时，音乐自动暂停或压低音量；
- **打开「忽略音频焦点」**：播放器不让路，音乐继续放 —— 想边听歌边导航播报的人会用到这个选项。

从 2.0.8.0 版的更新日志看，这一版修过「启用忽略音频焦点时来电不暂停播放」的问题。也就是说这个开关的行为在不同版本上不一致，装的是早期版本时，来电后没暂停属于已知缺陷，不是设置没生效。

导航场景下的实际取舍：想让导航语音听得清，就别忽略音频焦点；想让音乐不断，就打开它，并接受导航播报可能被音乐盖住。

## 五、锁屏、通知栏与耳机按键

- **锁屏与通知栏控制**：官方说明里都有。锁屏上不显示或按钮点不动，多半是后台被系统清理了，处理办法见 [常见问题与排查.md](常见问题与排查.md) 里后台被杀那一条。
- **耳机按键**：蓝牙和有线耳机的播放/暂停、上一首/下一首按键都由播放器接管。按键没反应时，先确认耳机连着的是这台手机（多设备同时在连的情况很常见），再确认没有别的音乐类 App 在前台抢焦点。

## 六、界面与主题

| 可调项 | 说明 |
| --- | --- |
| 主题色 | 多种配色可选；官方说明里提到界面颜色会跟着专辑封面动态变化，纯黑（AMOLED）模式适合 OLED 屏省电 |
| 暗色 / 纯黑 | 跟随系统或手动指定 |
| 首页 Tab | 歌曲、艺术家、专辑、文件夹、播放列表、远程（WebDAV）自己决定显示哪些；不想看的项关掉，主界面更清爽 |
| 播放页横屏 | 官方更新日志里提到过横屏播放页的界面优化，平板与车机上横屏更实用 |

主题设置只作用于界面外观，与曲库内容、歌单无关。歌词相关的显示设置见 [歌词显示与桌面歌词设置.md](歌词显示与桌面歌词设置.md)。
