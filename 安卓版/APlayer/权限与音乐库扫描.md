# APlayer 权限与音乐库扫描

> 装完 APlayer 打开是空的，这是本地播放器的正常状态 —— 歌得先放进手机，再让播放器把系统媒体库读一遍。本篇讲清媒体权限怎么给、三种扫描方式分别什么时候用、刚下载的歌为什么不出现，以及标签和封面怎么改。

## 一、先分清三件事

「歌没显示出来」有三种完全不同的原因，混在一起排查会一直绕圈：

| 现象 | 大概率原因 | 先查什么 |
| --- | --- | --- |
| 整个库是空的，一首都没有 | 媒体权限没给 | 系统设置里 APlayer 的权限页 |
| 系统文件管理器里能看到歌，播放器里没有 | 文件没进系统媒体库 | 用播放器里的手动扫描 |
| 文件夹视图里能看到，歌曲/专辑列表里没有 | 该文件夹被排除或不在扫描范围内 | 文件夹视图里的目录状态 |

三种情况都能在 APlayer 内部解决，不用重装、不用换文件管理器。

## 二、媒体权限怎么给

APlayer 读的是系统媒体库，权限口径跟着安卓版本走：

- **安卓 13（API 33）及以后**：权限页上出现的是「音乐和音频」，授予它即可。这一档系统把照片、视频、音频拆成了三个独立权限，所以你可能在别的 App 上见过「照片和视频」，那跟播放器无关。
- **安卓 12 及以前**：常见的是「文件和媒体」或「存储」一类的合并权限，授予之后按提示选择允许读取音频文件。

入口不统一，任选一条路走通即可：

1. 设置 → 应用 → APlayer → 权限 → 找到音频/音乐相关的那个开关打开；
2. 或者设置 → 隐私 → 权限管理 → 音乐和音频 → 找到 APlayer 打开。

给完权限回到 APlayer，如果列表还是空的，下拉刷新或退出重进一次，再走下面的手动扫描。

## 三、三种扫描方式，什么时候用哪种

| 方式 | 在哪 | 适合什么情况 |
| --- | --- | --- |
| 自动扫描媒体库 | 打开 App 时自动进行 | 日常；新歌进系统媒体库后会被带进来 |
| 手动扫描目录 | 设置里的手动扫描入口 | 刚放进手机的歌没出现、或换了存储卡之后 |
| 文件夹视图 | 首页 Tab 之一（需要在 Tab 配置里打开） | 你按目录管理音乐，想直接进某个文件夹听 |

首页的 Tab 是可配置的 —— 歌曲、艺术家、专辑、文件夹、播放列表、远程（WebDAV）这几项可以自己决定显示哪些。如果找不到「文件夹」，先去 Tab 配置里把它打开，配置方式见 [音效与播放控制设置.md](音效与播放控制设置.md) 里界面那一节。

手动扫描是排查「歌不显示」最直接的一招：确认歌已经在手机的存储里（一般放 `Music`、`Download` 这类公共目录最省事），然后在设置里触发一次全量扫描。

## 四、刚下载的歌为什么不出现

有用户整理过这一版的一个已知行为：**播放器读的是安卓系统的媒体扫描服务**，刚拷进手机的文件有时不会立刻被系统收录，得等系统自己扫到，或者由你在播放器里手工全盘扫描一次。

按这个顺序处理：

1. 等几分钟，重新打开 APlayer；系统扫描是后台异步的，慢的时候能拖很久。
2. 还不行就手动触发一次全量扫描（见上一节）。
3. 仍然不行，检查文件本身：扩展名是不是这一版能识别的音频格式，文件是不是 0 字节（下载中断会留下这种残包）。
4. 最后才考虑换存放位置：把歌挪到 `Music` 目录再扫一次。

**能识别的格式**：官方 README 没有列格式清单。有用户整理过一份实测清单，包含 `mp3`、`aac`、`m4a`、`flac`、`ogg`、`opus`、`webm`、`wav`、`3gp`、`amr`、`ts`、`mkv` 等常见格式，并提到当时的版本**不支持 `wma`**。这份清单不是官方口径，遇到具体文件还是以你设备上的实测结果为准。

## 五、改标签和封面

播放器自带标签编辑器，能改标题、歌手、专辑和内嵌歌词；专辑、艺术家、播放列表的封面也支持手动指定或自动下载。

- **入口**：在歌曲上长按或点右侧的更多按钮，找「编辑标签」一类的条目；
- **改完不生效**：有用户反馈过部分 mp3 文件改完标题、歌手保存后不生效的情况，用第三方标签编辑工具改好再让 APlayer 重扫一次即可绕过；
- **封面不显示**：先确认网络通不通 —— 自动下载封面需要联网；本地已有封面图的话，看它是否被正确嵌入到文件里（同目录下放一张同名图片通常不会被识别）。
- **歌名是一串数字或者乱码**：更新日志里出现过「显示文件名」这类开关，作用是先把文件按真实文件名显示出来，方便你认出它再手动改名；歌名、排序、最近添加之间的关系见 [曲库排序与最近添加.md](曲库排序与最近添加.md)。

标签和歌词是互相影响的：在线歌词靠歌曲名、歌手去匹配，标签不准匹配基本会失败，这一层见 [歌词显示与桌面歌词设置.md](歌词显示与桌面歌词设置.md)。
