# APlayer 歌单导入导出与 WebDAV 远程播放

> 歌单在 APlayer 里是自己管的一块，能建、能改、能导入导出；再往上一层是 WebDAV —— 把音乐放在自己的云盘或 NAS 上，播放器直接串流，手机不用再存一份。本篇讲清这两件事怎么配起来，以及连不上时先查哪几处。

## 一、歌单和播放列表在哪儿

官方说明里，歌单能力包括创建、编辑、导入、导出，并且**每个歌单可以单独排序** —— 也就是说一个歌单按添加时间排、另一个按歌名排，互不影响。

首页的 Tab 可配置，播放列表是其中一项；如果你在主界面找不到它，先去 Tab 配置里把「播放列表」打开。

## 二、导入歌单

入口在**设置 → 歌单导入**（不同版本层级可能不同，找不到就在设置里搜「导入」）。可选的方式有两类：

| 方式 | 用来做什么 |
| --- | --- |
| 从外部存储导入 | 手机里已经有一份歌单文件，直接读它 |
| 从已有播放列表导入 | 把某个列表里的歌整体搬到另一个列表 |

几点实际做法：

- 从 1.6.2.0 版的更新日志看，导入歌单时**默认用文件名当作新歌单的名字**，导入完记得确认一下名字，需要的话在列表里改。
- 从 1.6.4.0 版的更新日志看，这一版起支持**多选导入**，一次挑多个歌单文件即可，不用一个个来。
- 导入的是「歌单条目」而不是音频文件：如果歌单里指向的文件不在手机存储里，导进来也是空壳，得先把歌放进去再扫一次媒体库，见 [权限与音乐库扫描.md](权限与音乐库扫描.md)。

## 三、导出歌单

官方说明里导出是歌单功能的一部分，作用是把当前歌单落成文件，方便备份或换设备时带走。

- **导出后建议立刻试一次导入**，能重新读回来才算导出成功，确认之后再删手机里的旧列表。
- **删错歌单条目不用慌**：从更新日志看，「删除歌曲」的动作是从曲库移除、不动本地文件，重扫一次就回得来；这一层的更多情况见 [曲库排序与最近添加.md](曲库排序与最近添加.md)。
- 换手机时的完整迁移顺序：先导出歌单 → 把音频文件按原来的目录结构拷到新手机 → 新机上装好 APlayer、给权限 → 导入歌单 → 扫一次媒体库。跳过「保持目录结构」这一步，歌单里的路径多数会对不上，导入后就会出现一堆空条目。

## 四、WebDAV 远程播放怎么配

WebDAV 让你不用把歌存到手机里，播放时直接从云盘或 NAS 拉流。官方说明里这一项出现在首页 Tab 的「远程（WebDAV）」里。

配之前要分两头看：

**服务端（先做好这一步）**

| 服务类型 | 要做的事 |
| --- | --- |
| 群晖等 NAS 上的 WebDAV 服务 | 在套件里启用 WebDAV，默认 HTTP 端口 `5005`、HTTPS 端口 `5006`，可按需改；确认账号对目标共享文件夹有读取权限 |
| 坚果云一类支持 WebDAV 的网盘 | 在网页端的「账户信息 → 安全选项 → 第三方应用管理」里**生成一个应用密码**，用它代替登录密码，不要用主密码 |

**播放器端**

1. 确保首页 Tab 里「远程（WebDAV）」是打开的。
2. 进远程页面添加服务器，一般要填：地址（含端口）、账号、密码（网盘那边就是上一步生成的应用密码）、路径（可留空）。
3. 连上之后浏览目录、点歌即播，不需要先下载到本地。

三点提醒：

- **地址要带端口**，形如 `http://你的域名:5005/`，漏掉端口是最常见的连不上原因。
- **家里能用不等于外面能用**：NAS 的 WebDAV 一般只在局域网内可达，要在移动网络上用，得自己另外做端口映射或内网穿透，这属于网络设置，不在播放器这一侧。
- **免费网盘有访问频率限制**。以坚果云为例，其官方帮助页写明免费版用户 WebDAV 每 30 分钟不超过 600 次请求、单次请求返回文件数上限 750 个，且当前客户端与网页端上传大小上限一致（默认 500 MB）。大目录反复翻页、频繁切歌时容易撞到这些限制。

## 五、WebDAV 连不上 / 播放卡怎么查

按从外到内的顺序排：

1. **先用电脑验一遍同样的地址。** 在电脑上用支持 WebDAV 的文件管理器或映射网络驱动器的方式连一次，能连上说明服务端没问题，问题在手机这侧；连不上就先查服务端。
2. **报 401 / 密码错误**：网盘用户十有八九是填了登录密码而不是应用密码；NAS 用户检查账号对该目录的权限。
3. **报连接超时**：看地址里的端口对不对、手机当前网络能不能访问到那台服务器（先在同一 WiFi 下试）。
4. **能列出目录但歌不能播**：换一首试，确认是不是个别文件的问题；再从 1.6.4.0 版的更新日志看，该版本修过「WebDAV 无法播放 flac、无法正确读取目录」的问题 —— 如果你装的是更早的版本，这类现象更可能是版本本身的缺陷，而不是配置错。
5. **边播边卡**：串流的稳定性取决于网络与服务器上行带宽，和本地播放不是一回事。歌放本地时的均衡器与倍速设置见 [音效与播放控制设置.md](音效与播放控制设置.md)。
