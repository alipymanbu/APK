## 一、安装包与安装

| 现象 | 原因方向 | 怎么做 |
| --- | --- | --- |
| 提示「解析包错误」 | 包没下完整或被传坏 | 删掉重下，再核一次 MD5 是否为 `C8329DAFE26E6CC822B1EFA45E6C7329` |
| 提示「应用未安装」 | 已装同包名（`remix.myplayer`）的旧版且签名不同 | 卸载旧版再装 |
| 提示「与设备不兼容」 | 系统版本低于这一版要求 | 换更高版本的安卓设备，或到官方渠道看你那版系统能装的最新包 |
| 装完图标不出现 | 桌面启动器分组或应用列表没刷新 | 在应用列表里搜 `APlayer`；部分机型的应用抽屉需要下拉刷新 |
| 车机上禁止安装 | 车机系统限制第三方应用 | 见下面「车机相关」一节 |
| 装完打开就闪退 | 应用数据异常，或这一版与当前系统不兼容 | 在应用信息里清一次缓存与数据再进；仍然闪退就换官方渠道更新的版本 |

**MD5 怎么核**：电脑上把包下好，用系统的命令行工具算一次摘要，和上面那串 32 位字符逐字比对；结果一致说明文件完整。重新取包的入口在 [APlayer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6abc188ed085)，先转存到自己账号再下载更稳。

## 二、扫不到歌 / 库是空的

- **先查权限**：安卓 13 及以后要的是「音乐和音频」权限，不是「照片和视频」。给权限的入口和三种扫描方式见 [权限与音乐库扫描.md](权限与音乐库扫描.md)。
- **刚下载的歌不出现**：有用户整理过，播放器读取的是系统媒体库，新文件要等系统扫描收录，慢的时候要手动触发一次全量扫描。
- **歌在文件夹视图里有、在专辑列表里没有**：这首歌的标签（专辑、歌手）是空的，播放器按标签归类就归不进任何分组。用标签编辑器补一下，或者直接走文件夹视图听。
- **歌名乱码**：文件标签的编码与系统不一致，用标签编辑器重写一次标题、歌手；先开「显示文件名」把歌认出来再改更快，细节见 [曲库排序与最近添加.md](曲库排序与最近添加.md)。

## 三、没声音 / 声音异常

按这个顺序排，前两条覆盖了多数情况：

1. **先关「淡入淡出」。** 有用户整理过：开着这个效果时，「播放 → 暂停 → 切下一首」会出现有界面、时间轴在走但没声音的情况，关掉即恢复。
2. **看是不是被别的 App 抢了输出。** 短视频、语音通话、导航在后台时，声音可能被它们占用；关掉它们再试。
3. **蓝牙耳机场景**：断开再重连一次；有的耳机在切换编解码时会静音一段时间。
4. **只在某个文件上没声音**：文件本身可能损坏（下载中断的残包），换成同目录下另一首歌对照一下即可判断。
5. **来电后音乐停了没自动恢复**：与「忽略音频焦点」这个开关有关，不同版本行为不一致，见 [音效与播放控制设置.md](音效与播放控制设置.md)。

## 四、歌词相关

- **显示乱码**：本地歌词文件编码问题。早期版本只认 UTF-8，2.0.2 版起兼容 GBK、GB2312，把文件另存为 UTF-8 是最稳的做法。
- **本地歌词读不出来**：从更新日志看，安卓 11 及以上要求歌词文件放在公共目录（如 `Downloads`、`Music`），放私有目录可能读不到。
- **整首歌词快半拍或慢半拍**：歌词文件的时间轴与音频版本不匹配，换一份歌词即可。
- **双时间戳的歌词读不了**：形如 `[mm:ss.xx,mm:ss.xx]` 的非标准写法不被支持，需先转成单时间戳的标准 LRC。
- **桌面歌词不显示**：多数是缺「显示在其他应用上层」权限，或者被车机系统限制；详细设置见 [歌词显示与桌面歌词设置.md](歌词显示与桌面歌词设置.md)。

## 五、后台被清理 / 锁屏控制失效

表现为：锁屏上没有播放控制、听一会儿自己停、桌面歌词跟着消失。这是手机电源管理在清后台，不是播放器崩了。

- 设置 → 应用 → APlayer → 电池，改为**不受限制**或不优化；
- 在多任务界面把 APlayer 的卡片**加锁**（部分机型支持），避免一键清理时被带走；
- 有必要时单独给 APlayer 开自启动权限。

## 六、车机相关

- **装不上**：部分车机系统直接禁止第三方安装，这种限制在车机侧，应用本身帮不上忙。
- **桌面歌词浮不出来**：车机限制了悬浮层叠加，可以退回播放页看歌词。
- **按键/方向盘控制不生效**：车机对媒体按键的映射各家不同，属于车机侧行为。

## 七、已知但未修的问题（用户整理，供对照）

以下是用户在其整理的文档里列出的、当时版本（2.0.7）仍然存在的现象。你手上这一版是 2.0.9.0，是否仍在，以你设备上的实测为准：

| 现象 | 说明 |
| --- | --- |
| 刚从文件管理器里点开播放的文件有时播不了 | 播放器依赖系统媒体扫描服务，文件还没被系统收录；手动全盘扫描一次通常能解决 |
| 部分 mp3 改完标题、歌手保存不生效 | 用第三方标签编辑工具改好，再让播放器重扫一次 |
| 非标准双时间戳歌词不被识别 | 需先转换为标准单时间戳 LRC |
| 淡入淡出开启时的切歌无声 | 关闭该效果即可规避 |

另外，2.0.8.0 版的更新日志里修掉的问题（深色模式状态栏配色、应用重启后小部件封面不刷新、忽略音频焦点时来电不暂停）如果在你的版本上仍然出现，说明你装的包比 2.0.8.0 更早，回 [下载与安装教程.md](下载与安装教程.md) 核一下版本号。

## 八、手势不生效 / 流量与隐私

- **某个手势按下去没反应**（左滑便签、边缘长按倍速、摇一摇切歌）：手势是逐版加进来的，早于该版本的包就没有；哪些手势属于哪一版、误触了怎么关，列在 [播放界面手势与快捷操作.md](播放界面手势与快捷操作.md)。
- **不想让它联网**：在线歌词、封面自动下载、WebDAV 这三项会用到网络，关掉之后飞行模式下也能照常听本地歌；改法见 [联网功能与隐私说明.md](联网功能与隐私说明.md)。
- **想确认有没有后台流量**：用手机自带的流量统计看一段时间内 APlayer 的数据用量，比任何说明都直接。
