## 一、先说结论：不用账号，能全离线用

APlayer 没有注册、登录这一步，官方说明里也没有在线曲库、云同步这类条目。它的主线功能 —— 扫描本地音乐、播放、标签编辑、歌词、均衡器、桌面歌词 —— 都不依赖账号。

**收费上也不用担心**：听本地音乐免费，没有会员体系；应用内只有一个「支持我们」页面（赞助入口与广告位都在那一页），点不点由你决定。

会用到网络的是另外几项附加功能，见下一节；不想联网就把它们关掉，播放本身不受影响。

## 二、哪些操作会联网

| 功能 | 为什么需要网络 | 不联网时的表现 |
| --- | --- | --- |
| 在线歌词 | 按歌名、歌手去在线歌词源匹配（官方说明里提到网易、酷狗、QQ） | 只有内嵌歌词与本地歌词可用 |
| 封面自动下载 | 到网上取专辑、艺术家封面 | 已有内嵌封面的照常显示，缺的留空 |
| WebDAV 远程播放 | 音频本身就在你的云盘或 NAS 上 | 远程 Tab 无法使用，本地库不受影响 |
| 「支持我们」页面 | 该页面含广告位 | 不打开这个页面，这部分内容就不会被加载 |

关于最后一条，更新日志里写过：1.6.1.0 版新增了广告，并注明「不影响日常使用，仅存在于『支持我们』页面」。也就是广告不在播放界面出现，而是集中在赞助那一页。**你装的那一版具体长什么样，以实际界面为准。**

## 三、想彻底离线用怎么设置

按下面三处改一遍，播放器在飞行模式下也能正常听歌：

1. **歌词搜索优先级里把「在线」往后放**，或者只用内嵌、本地歌词 —— 优先级设置在 [歌词显示与桌面歌词设置.md](歌词显示与桌面歌词设置.md) 里讲。
2. **关掉封面自动下载**。代价是缺封面的专辑会保持空白，可以自己往文件里嵌图补上。
3. **不用 WebDAV 就不加远程服务器**，首页 Tab 里也可以把「远程（WebDAV）」这一项关掉，见 [音效与播放控制设置.md](音效与播放控制设置.md)。

改完之后如果想确认真的没在联网，用手机自带的流量统计或系统防火墙看一段时间内 APlayer 的后台流量即可 —— 这比任何说明都直接。

## 四、权限与数据

- **权限**：主线只有读取音频/媒体这一项，桌面歌词需要额外的「显示在其他应用上层」。权限清单在系统设置的应用信息页能看到，装完之后对照一下即可，职责对不上的权限可以关掉。
- **数据在本机**：歌单、便签、播放记录这类内容跟着应用存在本机；没有账号体系，也就没有云端副本，换手机要靠自己迁移，见 [歌单导入导出与WebDAV远程播放.md](歌单导入导出与WebDAV远程播放.md)。
- **卸载之后**：应用内数据一般会随卸载一起清掉，音频文件仍在你的存储目录里不受影响。

## 五、想进一步核实的话

APlayer 以 GPL v3 开源，源码与说明在 [github.com/rRemix/APlayer](https://github.com/rRemix/APlayer)。开源的意义是：上面这些关于「联不联网」的判断可以自己去看代码确认，而不是只能听介绍页说。

- 遇到疑似异常联网、权限越界，可以在该仓库提 Issue；
- 官方 README 里也给了开发者邮箱与 Telegram 群作为反馈渠道；
- 本文的结论基于官方说明与公开的更新日志，**涉及具体网络行为的部分，以你装的那一版的实测与源码为准**。
