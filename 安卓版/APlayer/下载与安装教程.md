# APlayer 下载与安装教程

> APlayer 是一款安卓端的本地音乐播放器，由开发者 rRemix 维护、代码在 GitHub 上以 GPL v3 开源，官方对自己的说明是「基于 Jetpack Compose 构建的音乐播放器」。本篇讲清安装包从哪取、手机上怎么装、装完第一次打开要先把哪几件事做对。

## 一、装之前先对一下这张表

| 项目 | 这一版的情况 |
| --- | --- |
| 软件名 | APlayer |
| 版本号 | 2.0.9.0 |
| 包名 | remix.myplayer |
| 安装包大小 | 7.47 MB（7,837,657 字节） |
| 安装包 MD5 | C8329DAFE26E6CC822B1EFA45E6C7329 |
| 适用设备 | 安卓手机 / 安卓平板 / 安卓车机 |
| 系统要求 | 整理这一版时记录到的是「需要支持安卓系统 5.2 以上」 |
| 开发者 | rRemix |
| 许可 | GPL v3 |
| 收费情况 | 免费使用；应用内有「支持我们」页面（赞助入口与广告位都在这页），是否点开由你决定 |

两件事值得先说明：

1. **「安卓 5.2」这个写法不必纠结。** 安卓官方并没有对外的 5.2 版本（公开版本是 5.0、5.1，之后直接跳到 6.0），这句话按「Android 5 系及以上」理解就行。另有第三方应用页把它写成 Android 5.1 以上，两边口径并不一致 —— 真正能不能装，以你设备上点下去之后的提示为准。
2. **版本号以本页表格为准，别跟网上介绍里的数字比。** 官方在 Google Play 与 IzzyOnDroid 上发布，源码与说明在 [github.com/rRemix/APlayer](https://github.com/rRemix/APlayer)，那边挂着的是更新的版本；网上各种介绍页写的多半也是官方某个时点的最新版。它们和你手上这个包不一定是同一版，所以本文提到的设置项名称、界面位置都以你装的那一版实际显示为准。

## 二、从网盘把安装包取出来

1. 打开 [APlayer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6abc188ed085)。手机、电脑上都能操作，用夸克 App 打开更稳。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存之后，下载就不再依赖原分享链接是否还在。
3. 分两种情况取包：
   - **装到手机上**：直接在网盘 App 里下载，落到手机的「下载」目录即可；
   - **装到车机上**：更省事的做法是在电脑端网盘下载，再用 U 盘拷进车机（车机上操作网盘 App 麻烦，也不容易确认下载是否完整）。
4. 下完核对两件事：文件名结尾是不是 `.apk`；MD5 是不是 `C8329DAFE26E6CC822B1EFA45E6C7329`。对不上就删掉重下 —— 安卓装到一半报「解析包错误」，绝大多数是包没下完整或被传坏。校验 MD5 的详细做法见 [常见问题与排查.md](常见问题与排查.md)。

## 三、手机上的安装步骤

这个安装包不是你从手机自带的软件商店里下下来的，安装时系统会拦一下，属于正常现象，不代表文件有问题。

1. 打开手机的「文件管理」，进 `Download`（下载）目录，找到刚下好的安装包，点它。
2. 系统弹出「不允许安装来自此来源的应用」之类的提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要绕一层：设置 → 应用 → 特殊应用权限 → 安装未知应用，在里面找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」，别急着打开 —— 先把下面的权限一次性给对，进去之后能少弹几次权限窗口。

装完桌面或应用列表里会出现 APlayer 的图标。

## 四、装完第一次打开要做的几件事

1. **不用注册、不用登录。** APlayer 是纯本地播放器，官方说明里也没有在线音乐这一项，打开直接进主界面。
2. **先把媒体权限给掉。** 安卓 13 及以后要的是「音乐和音频」这一类权限，给完之后播放器才看得到你手机里的音频文件。入口和系统版本差异见 [权限与音乐库扫描.md](权限与音乐库扫描.md)。
3. **等它扫一次媒体库。** 首次进入会自己扫一遍，库里歌多的时候要等一会儿；没扫到东西不用慌，手动扫描的入口也在设置里，同样见 [权限与音乐库扫描.md](权限与音乐库扫描.md)。
4. **挑一个主题色。** 界面配色、暗色/纯黑模式都能改，改动的入口与取舍见 [音效与播放控制设置.md](音效与播放控制设置.md)。
5. **想开桌面歌词的话，还要额外给一次「显示在其他应用上层」权限。** 这一项在 [歌词显示与桌面歌词设置.md](歌词显示与桌面歌词设置.md) 里说。

## 五、装不上时先查哪几处

- 提示「解析包错误」→ 包没下完整，回网盘重下，用 MD5 核对。
- 提示「应用未安装」→ 设备上可能已经装了同包名（`remix.myplayer`）的旧版，且签名对不上；先卸载旧版再装。
- 提示「无法安装，与设备不兼容」→ 你的系统版本低于这一版的要求；可以换更高版本的安卓设备，或到官方渠道看你那版系统能装的最新包。
- 装完打开就闪退 → 先在应用信息里清一次缓存与数据再进；仍然闪退的话，看 [常见问题与排查.md](常见问题与排查.md) 里安装那节的闪退一条。
- 车机上提示禁止安装、或装了但图标不出现 → 见 [常见问题与排查.md](常见问题与排查.md) 的车机那一节。
