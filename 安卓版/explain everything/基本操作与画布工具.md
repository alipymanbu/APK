## 一、底部导航栏的四个入口

应用界面的最下面一排是主导航，四个标签各管一摊：

| 标签 | 你在这里能做什么 |
| --- | --- |
| Home | 启动后的首页：新建项目、邀请别人进你的项目、用 CODE 加入别人的协作、把项目分享出去 |
| Library | 所有项目都存在这：按创建时间或名称排序、缩略图/列表切换、建文件夹归类、复制、移动、删除、合并 |
| Learn | 官方的学习入口：短视频教程、博客文章、帮助中心、联系支持 |
| Search | 按名字找项目；手上有别人给的 CODE 时，也在这里输进去直接跳到那个项目 |

第一次用建议先把 Library 看一遍 —— 你之后一半的时间都花在这里，项目存在哪、怎么整理都从这开始。

## 二、画布是无限的

白板画布没有边界，双指张开缩小就能看到更大的工作区，两个手指拖动则平移视野。空间不够用时不用新建项目：缩小、把已有内容挪到一边，接着往下写就行。

被选中的对象可以随意移动、缩放、旋转。录制视频时你对画布做的缩放和平移也会被录进去，等于自己当镜头（见 [录制讲解视频并导出.md](录制讲解视频并导出.md)）。

## 三、工具栏里的常用工具

从工具栏拿起工具，就能在画布上直接操作：

| 工具 | 用途 | 外接键盘快捷键 |
| --- | --- | --- |
| 手型工具 | 拖动、选中、缩放对象 | `V` 或 `1` |
| 画笔 | 手写手画，有笔与铅笔两种质感 | `D` 或 `2` |
| 荧光笔 | 半透明划重点 | `H` 或 `3` |
| 橡皮 | 擦掉笔迹 | `E` 或 `4` |
| 油漆桶 | 给闭合区域填色 | `G` 或 `5` |
| 形状 | 画规整的几何图形 | `S` 或 `6` |
| 文本 | 插入文字框 | `T` 或 `7` |
| 裁切 | 抠出一块内容单独搬走 | `C` 或 `8` |
| 激光笔 | 讲解时指重点，不留痕迹 | `P` 或 `9` |
| 添加媒体 | 插图片、文档、视频等 | `A`、`§` 或 `` ` `` |

颜色面板给的是完整调色板：可以调不透明度、用吸管从画布上取色、直接输入 HEX 或 RGB 数值，描边色和填充色分开设置，另有 4 组常用取色器方便快速切换。

## 四、幻灯片

一个项目可以有多张幻灯片，一页写不下就翻页接着写。外接键盘时：`Ctrl + M` 新增一页，`Ctrl + ←` / `Ctrl + →` 翻页，`Ctrl + Shift + →` 直接跳到最后一页。

注意免费版每个项目只能放 1 张幻灯片，多页功能要升级方案才开放，具体见 [免费版限制与常见问题.md](免费版限制与常见问题.md)。

## 五、选中后的编排操作

选中一个或多个对象后，可以做这些整理动作：

- **组合 / 解组**：`Ctrl + G` 把散件捆成一个整体，`Ctrl + Shift + G` 拆开；
- **锁定**：`Ctrl + L` 把对象钉在原位，避免画到一半误拖；
- **图层顺序**：`]` 置顶、`[` 沉底，`Ctrl + ]` 上移一层、`Ctrl + [` 下移一层；
- **复制粘贴**：`Ctrl + D` 原地复制，`Ctrl + C` / `Ctrl + V` 跨页粘贴；
- **精确移动**：方向键轻移，`Shift + 方向键` 更细地微调，`Alt + 方向键` 旋转。

## 六、快捷键速查

手边接了键盘（安卓平板、Chromebook）时，这几组最常用：

| 想做什么 | 按键 |
| --- | --- |
| 撤销 / 重做 | `Ctrl + Z` / `Ctrl + Shift + Z` |
| 全选 / 取消选择 | `Ctrl + A` / `Ctrl + Esc` |
| 显示全部内容 | `0` |
| 复位到 100% 缩放 | `Ctrl + 0` |
| 缩放 | `+` / `-`，按住空格临时变缩放 |
| 完成当前笔迹 | `Ctrl + Enter` |
| 给闭合笔迹填色 | `Ctrl + Shift + Enter` |

完整的键位表可以在应用内的 Learn 标签找到官方帮助文章；触屏操作时这些键位用不上，长按对象弹出的菜单里有同类功能。
