# Explain Everything 怎么录制讲解视频并导出

## 一、录制入口在哪

录制按钮在屏幕底部中间的位置，一个圆点形状的控件。点它就开始录，再点一次结束。

开录前先做三件事：

1. **给应用麦克风权限**（系统设置 → 应用 → Explain Everything → 权限），否则录出来只有画面没有讲解声；
2. **把素材摆上画布**：要讲的图片、PDF、笔记先放好，别录到一半才回头翻文件；
3. **用本地项目录**：安卓版的「录一段新视频插进画布」只在本地项目里可用，存在云端的项目没有这个选项。

## 二、录的时候你能控制什么

- 你的笔迹、拖动、缩放和说话声会被一起录下来；
- 镜头由你掌握 —— 边讲边缩放到细节、再拉回全局，成片会有镜头感；
- 激光笔只在录制时指重点，不会把标记留在画布上。

录完之后内容并不定型，还可以再改。

## 三、录完怎么剪

结束录制后会进入时间线编辑，这一版你能做这些操作：

| 操作 | 说明 |
| --- | --- |
| 剪掉某一段 | 选中时间线上的片段直接裁掉讲废的部分 |
| 平滑移动 | 让录进去的对象移动轨迹更顺，减少手抖造成的抖动 |
| 音频淡入 | 给选中的音频片段加淡入，声音不会突然砸出来 |

平台差异提醒：**加速播放选中片段、往时间线直接插音视频片段这两项，安卓版没有**（官方平台差异表把它列在苹果版一侧）；网页版则不支持「插入式录制」这种模式。做的时候别照着苹果版的教程找按钮。

## 四、导出成什么格式

录完点右上角的分享按钮，选「导出」。安卓版能走的格式：

| 类型 | 安卓版 | 说明 |
| --- | --- | --- |
| MP4 视频 | 支持 | 最常用的成品格式，直接发出去就能播 |
| GIF | 支持 | 适合发到不支持视频的场合，无声 |
| 本地保存 | 支持 | 导出的文件落在设备本地 |
| MOV 视频 | 不支持 | 该格式只有苹果版能导 |
| JPG 单图 | 不支持 | 单张图片导出只有苹果版有 |

导出对话框里还会有图像、PDF、项目文件等类别，具体可选项随版本略有变化。**图像、PDF 和「网页视频链接」这三类分享在新一些的版本里带导出设置**，可以调格式与质量。

「网页视频链接」是生成一条能在线播放的链接，需要联网；不想传到网上就用 MP4 存本地。

## 五、免费版的视频长度

免费版单段视频最长 **3 分钟**，录到 3 分钟会到顶。要录更长的完整课程，得升级到付费方案（无限视频长度），方案差别见 [免费版限制与常见问题.md](免费版限制与常见问题.md)。

一个实用的绕法：把一节内容拆成多个 3 分钟内的短视频分段交付，这不算绕过限制 —— 免费版本来就允许你建多个项目、反复导出。

## 六、导出后文件在哪

导出成功时应用会给提示，文件保存在设备本地。用系统文件管理器按导出时间找，或者打开相册看最新一项；找不到就在应用的分享/导出记录里再导一次，导出时注意看提示里的保存路径。

## 七、录出来没有声音

画面正常、回放是静音的，按这个顺序查（从最常见到最少见）：

1. **应用的麦克风权限**：系统「设置 → 应用 → Explain Everything → 权限」里，麦克风必须是允许。安卓在应用更新或清过数据后可能把权限改回拒绝。
2. **系统级的麦克风开关**：下拉快捷开关面板，确认「麦克风」总开关没有被关掉 —— 它一关，所有应用都收不到声音，看起来像应用坏了。
3. **是不是被耳机占着**：连着蓝牙耳机或插着有线耳机时，声音可能被路由到耳机的麦克风上。断开耳机再录一次试试。
4. **别的应用占着麦克风**：后台挂着会议、语音类应用会锁住音频通道。把后台应用全部划掉，重启手机后再录。
5. **在系统录音机里试一次**：系统自带录音机能录出声，说明硬件没问题，问题在权限或应用侧；系统录音机也没声，那就是手机麦克风本身的事（堵塞、进灰或硬件故障）。

以上是多个通用安卓排查资料交叉印证的步骤，按顺序做完基本能定位到具体环节。
