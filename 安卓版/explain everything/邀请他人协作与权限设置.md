# Explain Everything 邀请他人协作与权限设置

> 这篇讲怎么把你的白板项目发给别人一起画、CODE 和邀请链接怎么用、以及三种访问权限分别给对方什么能力。

## 一、先满足一个前提：项目得在云端

邀请协作只能对**云端项目**（存在 Explain Drive 上的）发起。如果你手上是个存在本机的本地项目，点邀请时应用会提示你先把它复制到 Explain Drive —— 按提示复制一份再继续，原始的本地文件不受影响。

原因很直接：改动要实时同步给所有人，项目就必须放在大家都能访问的地方。

## 二、两种邀请方式

**方式一：邀请链接（对方没账号也能用）**

1. 在项目里点右上角的 **Invite（邀请）** 图标；被问到时选 Copy，把项目复制到 Explain Drive；
2. 在 Collaboration（协作）菜单里，找到 Invite Link（邀请链接）并选 Share 或 Copy；
3. 把链接粘到聊天窗口、邮件里发出去。

对方点开链接就能直接进项目；他设备上装了 Explain Everything 的话，链接会直接唤起应用。

**方式二：CODE（适合当面或口头告诉对方）**

每个云端项目都有一个专属的访问 CODE。对方的操作路径：打开应用 → 底部导航的 **Search** 标签 → 输入 CODE → 进入项目。他需要登录自己的账号。

CODE 也能当链接用：把它变成 `exp.ai/<你的CODE>` 这种形式发出去（把 `exp.ai/` 拼在 CODE 前面），就是一个可点击的地址。

面对面的场合还有个更省事的办法：邀请界面里可以**展示二维码**，对方扫一下即可，不用手输 CODE。

## 三、权限：谁能进、进来能干什么

发邀请前先把两组设置看一眼，都在项目内的 **Invite/CODE → Access permissions** 里。第一组决定谁能打开项目，第二组决定他进来后能做什么：

| 谁能访问 | 说明 |
| --- | --- |
| Anyone with the link | 拿到链接或 CODE 的人都能进，适合发给班群、公开分享 |
| Anyone at my organization | 只有你所在 Group 账户内的成员能进（Group 账户才有这项） |
| Only specified people | 只有你填了邮箱或用户名的人能进；一个人都不填 = 项目私有 |

| 访问类型 | 对方进来后 |
| --- | --- |
| View only（仅查看） | 只能看。工具、缩放、录制按钮对他全部不可用，也不能下载 |
| View and download（查看并下载） | 能看，也能把项目文件下载到自己设备，但改不了你的原项目 |
| Edit（编辑） | 能用全部工具、能改内容、能自由移动画布；你退出后他成为主持人 |

选型的实际判断：**只给人看演示或发笔记 → 仅查看；想让对方拿你的模板去自己用 → 查看并下载；要一起头脑风暴、共同做课 → 编辑。**

可以给整个项目设一个通用权限，也可以对某个受邀者单独指定 —— 比如大部分链接进来只能看，唯独搭档是编辑。

## 四、人数与时间的硬限制

- **免费版**：一次只能和 1 个人协作，每次最多 15 分钟，到点断开。要延长时间得升级方案，各档差异见 [免费版限制与常见问题.md](免费版限制与常见问题.md)。
- **同时在线人数**：官方说明是上限 25 人，但**建议控制在 8 人以内**，人越多对网络质量越敏感（官方原文的措辞是「目前建议较小的团队，8 人时效果最好」）。这条随官方调整会变，以 [帮助中心](https://help.explaineverything.com/hc/en-us) 为准。
- **Class / School 方案有额外限制**：出于学生隐私保护，这类账户**不能邀请组织外的人**，学生账户也只能邀请管理员和老师。

## 五、协作时你用得上的几个开关

- **协作者的麦克风**：参与者列表里可以静音/取消静音，语音讨论靠它控制；
- **权限随时可改**：中途发现有人不该改你的稿子，进 Access permissions 把他从编辑降成仅查看即可，不用踢人；
- **改动都留在云端**：谁改的都会同步上去，你事后打开项目看到的就是最新版，不存在「他本地那份没传上来」的问题；
- **录下整场协作**：协作中点 Record 可以把全过程录成视频，给没到场的人补看，导出方式与 [录制讲解视频并导出.md](录制讲解视频并导出.md) 相同。

## 六、对方进不来时查这三条

1. 项目是不是本地项目 —— 本地项目没有 CODE 可言，先按第一节复制到云端；
2. 权限对不对 —— 你选的是不是「指定的人」而对方不在名单里；
3. 免费版时长 —— 15 分钟到了会自动断开，不是对方操作有问题。
