## 一、安卓版能导入的格式

官方格式表里，安卓与 ChromeOS 一栏列出的可导入类型如下（网页版另有出入，这里不混着讲）：

| 类别 | 支持的扩展名 |
| --- | --- |
| 图片 | `.png` `.jpg` `.jpeg` `.bmp` `.svg` |
| 文档 | `.pdf` `.ppt` `.pptx` `.doc` `.docx` `.csv` `.rtf` `.txt` `.xls` `.xlsx` `.odp` `.ods` `.odt` |
| 视频 | `.mp4` `.mov` `.m4v` |
| 音频 | `.mp3` `.aac` `.m4a` `.wav` |

几个要注意的点：

- **`.gif` 不在安卓版的图片清单里**（苹果版会把 gif 当静态图导入）。想在画布上放动图，先把它转成 mp4 视频再插入。
- **`.iwb` 这类 ActivInspire 白板文件只列在苹果版一栏**，安卓版的清单里没有它，别指望安卓上能直接打开。
- 文档导入后会被转成通用格式，你在安卓上做好的项目发给用 iPad 或网页版的人，对方照样能打开，不受他自己设备是否支持该格式影响。
- 官方这份清单会随版本更新，动手前可以到 [帮助中心](https://help.explaineverything.com/hc/en-us) 的格式文章里再核一眼当前版本。

## 二、添加媒体的入口

工具栏上的「添加媒体」是所有素材的入口（外接键盘按 `A`、`§` 或 `` ` ``）。安卓版这一栏里你能用的：

| 选项 | 说明 |
| --- | --- |
| 浏览器 | 直接在应用内打开网页，把网页内容取进画布 |
| 占位符 | 放一个占位框，先占住版面位置 |
| 方程 | 插入数学公式 |
| 插入视频文件 | 从设备里选现成的视频放进画布 |
| 录制新视频 | 现场拍一段插进来，**仅本地项目可用** |

**安卓版没有的**（别按苹果版教程去找）：Unsplash 图库、Sketchfab 3D 模型、直接把音视频片段插到时间线上、现场录一段新音频。这些在官方差异表里归苹果版或网页版。

## 三、从云盘取文件

安卓版支持的云来源只有两个：

- **Google Drive**
- **Dropbox**

在添加媒体里选对应来源，登录你的账号就能把云端文件直接取进画布。WebDAV、Evernote、Box、OneDrive、Edpuzzle 这几项官方差异表列在苹果版一侧，安卓上看不到入口。

设备本地的文件则走系统的文件选择器，跟普通应用选附件是一样的操作。云来源都需要联网，断网时只有本地文件可选。

## 四、导入失败时先查这几条

1. 扩展名对不对 —— 照第一节的清单核一遍，不在清单里的先转换格式；
2. 登录状态 —— 账号未登录时，文档类导入可能受限（帮助中心注明除 PDF 外的文档导入有登录要求，具体以你当前版本的实际提示为准）；
3. 文件本身能不能打开 —— 换个别的文件试一下，单个损坏的文件和格式不支持的表现是一样的；
4. 云端来源连不上 —— 先确认网络，再确认那个云服务的授权没过期。

排查完还有问题，可以把现象带到 [免费版限制与常见问题.md](免费版限制与常见问题.md) 里对照那篇的 FAQ。
