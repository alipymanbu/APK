# Joyose 常见问题与解决办法

> 这篇讲跟 Joyose 有关的几个典型故障：更新后发热耗电、游戏掉帧锁帧、报错闪退、安装被拦，以及每种情况该清数据还是删更新。

## 一、先记住两个「万能动作」

排查任何 Joyose 相关问题，都是在这两个动作之间做选择，路径都是「设置 → 应用设置 → 应用管理 → 右上角菜单勾选**显示全部应用** → 搜 `Joyose`」：

| 动作 | 做法 | 适用场景 | 风险 |
| --- | --- | --- | --- |
| **清除数据** | 点进去 →「清除数据 → 清除全部数据」 | 行为异常但版本没错：发热、掉帧、报错 | 低，配置会重新拉取 |
| **删除更新** | 点进去 → 右上角菜单 →「卸载更新」（有的系统叫「删除更新」） | 刚更新完就出问题，怀疑版本本身 | 低，回到出厂版本 |

**判断顺序**：先清数据 → 没用再删更新 → 还没用再考虑手动装一个已知正常的版本（见 [下载与安装教程.md](下载与安装教程.md)）。真要禁用或卸载，看 [禁用与卸载方法.md](禁用与卸载方法.md)，那一步不可逆性更高，放最后。

## 二、更新完手机发热、耗电变快

社区里被反复验证的处理顺序：

1. **清 Joyose 的数据**：按上面路径找到它，清除全部数据。清完重启一次手机，让它重新拉配置。
2. **顺手清「电量和性能」的数据**：同一页面搜索「电量和性能」（有的系统叫「电量和性能服务」），一并清除。这两个组件是配合工作的，只清一个有时没效果。
3. **还不行 → 删除更新**，回退到出厂预置版本。
4. 用一两天观察，仍异常再手动装一个别的版本试试（版本怎么选见 [下载与安装教程.md](下载与安装教程.md) 第二节）。

注意：清完数据后短期内手机可能「重新学习」你的使用习惯，头一两天的表现不代表最终结果。

## 三、游戏掉帧、锁帧

表现是：明明手机性能不弱，游戏却被锁在 60 帧甚至更低，或帧率忽上忽下。Joyose 是游戏调度链路的一环（见 [是干什么的.md](是干什么的.md) 第二节），排查从它开始：

1. 按第二节清一遍 **Joyose + 电量和性能** 的数据；
2. 检查游戏自身的设置：帧率档位有没有被系统「均衡模式」压住 —— 小米的均衡模式温控限制更严，切到**性能模式**（设置里「省电与电池」相关选项）再试；
3. 游戏空间（Game Turbo）里这个游戏的设置也看一眼：社区里常见的做法是把游戏从列表移出再加回，或干脆不把它放进游戏空间；
4. 以上都无效，删除更新回退版本。

这些是社区里流传较广、复现率较高的做法，**不保证对每个机型每个系统版本都有效** —— 掉帧也可能是温控本身在起作用（机身已经很烫时降帧是正常保护），先摸一下机身温度再往下查。

## 四、提示「Joyose 已停止运行」或后台反复报错

1. 先清数据（路径同上），重启；
2. 如果报错是在**刚更新完**出现的 → 删除更新，回出厂版本；
3. 如果是你**手动装 APK 之后**出现的 → 大概率是包不对：核对版本号与 MD5（[下载与安装教程.md](下载与安装教程.md) 第二、五节），或回退出厂版本后重装。

单独一个组件报错、手机其余功能正常的话，不用慌；清数据基本都能解决。

## 五、安装时被拦：签名冲突 / 解析包失败

- **解析包失败、安装中断**：几乎都是包下载不完整，重算 MD5 对不上就重下。
- **签名冲突 / 应用未安装**：这个包用小米平台签名，先在设置里「删除更新」回到出厂版本，再装你要装的那份；区域版本不匹配的包（比如拿别的市场的构建）同样会撞这个错。

具体步骤见 [下载与安装教程.md](下载与安装教程.md) 第六节。

## 六、我把它禁用/卸载了，现在想恢复

最省事的一条：**设置里重新安装它** —— 系统预置应用被你手动卸载过的话，应用管理里通常还留着入口，点「安装」或「恢复」即可；用 adb 卸载的则执行：

```bash
adb shell pm install-existing com.xiaomi.joyose
```

完整的禁用 / 卸载 / 恢复命令与各自后果，见 [禁用与卸载方法.md](禁用与卸载方法.md)。

## 七、什么时候该放弃自己修

系统大面积异常（所有应用都闪退、重启循环）就不是 Joyose 一个组件的问题了，官方通用建议是备份数据后走系统重置或刷完整包。只揪着一个组件反复折腾，反而耽误时间。
