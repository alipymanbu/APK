## 一、先弄清楚你要装的是什么

Joyose 是小米给小米 / Redmi / POCO 手机预置的一个**后台系统组件**，包名 `com.xiaomi.joyose`，开发方登记为北京小米移动软件有限公司。它在桌面上**没有图标、没有可打开的界面**，你平时看不到它，但它一直在后台跑，管的是性能调度、游戏加速这类底层活儿（具体管什么见 [是干什么的.md](是干什么的.md)）。

所以「安装 Joyose」这件事只在两种情况下有意义：

1. 你的手机上这个组件被更新坏了（发热、卡顿、报错），想**手动装回一个已知正常的版本**；
2. 你想把它**升级到比系统推送更新的版本**。

手机一切正常的话，它会随系统 OTA 自动更新，你不需要手动装。

## 二、本篇用的安装包事实

本篇以下内容全部基于这份包（**以这份包为准** —— 网上能搜到的官方最新版一直在往前走，跟这份不是同一个版本，界面和行为可能有出入）：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.3.42 |
| 包名 | `com.xiaomi.joyose` |
| 安装包大小 | 1.85M |
| MD5 | `C8B967CAF37F67715A5E57888DF63E95` |
| 采集时间 | 2026-09-23 |

补充两条版本背景：按公开的版本索引，2.3.42 属于 2024 年 8 月前后的构建；而截至 2026 年 9 月，公开渠道能见到的版本已经走到 2.5.x 系列。**你要装哪一版，以官方页面当时显示的为准** —— 系统组件不是越新越好，跟你的系统版本匹配才重要。

## 三、拿安装包

从上面的夸克网盘链接取（[Joyose 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3d104ae87984)）：转存到自己的网盘再下载，拿到的就是上表这版 2.3.42，版本号、体积、MD5 都能逐项对上。

**核对 MD5（推荐）**：这包只有 1.85M，下载中断的概率不小。下载完在电脑上算一遍 MD5，与表格里的值逐字符比对，不一致就重新下载 —— 装一个残缺的包只会引出新问题。

如果你不需要固定版本，也可以等手机系统自己推送更新，或从系统内置的应用更新入口升级，不必手动装。

## 四、安装步骤

1. 把 APK 拷到手机上（或在手机浏览器里直接下载）。
2. 点 APK 开始安装。系统会拦一道「禁止安装来自此来源的应用」，这是正常的安全提示，点进去允许本次安装（不同品牌措辞略有差别，一般在「设置 → 安全/隐私 → 安装未知应用」里）。
3. 装完**桌面上不会多出任何图标** —— 这是正常现象，它本来就没有界面，不代表没装上。
4. 确认版本（见下一节）。

## 五、装完怎么确认版本

**方法一：在设置里看**

1. 打开「设置 → 应用设置 → 应用管理」；
2. 右上角菜单里勾选「显示全部应用」（它被归在系统应用里，默认搜不到）；
3. 搜索 `Joyose`，点进去，页面上会显示版本号，与 2.3.42 对得上就是装对了。

**方法二：用 adb 看**（手机连电脑、开了 USB 调试）：

```bash
adb shell dumpsys package com.xiaomi.joyose
```

在输出里找 `versionName` 那一行，就是当前版本号。

## 六、装的时候撞上签名冲突

Joyose 用的是小米的平台签名，跟系统预置版本同一套证书。你装的时候如果弹「应用未安装」「签名冲突」这类提示，通常是这两种情况：

- **下载的包不完整**：先按第三节重算 MD5，对不上就重下；
- **新旧版本签名或区域不匹配**：先按 [禁用与卸载方法.md](禁用与卸载方法.md) 里的做法在设置里「删除更新」，回到出厂版本再装这份。

别的安装报错（闪退、解析包失败）的排查见 [常见问题与解决办法.md](常见问题与解决办法.md)。
