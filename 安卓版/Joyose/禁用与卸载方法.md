# Joyose 禁用与卸载方法

> 这篇讲怎么在设置里回退 Joyose、怎么用 adb 禁用或卸载它，以及每种做法的后果和恢复命令。

## 一、动手前先想清楚

Joyose 管的是游戏调度、性能与功耗分配（见 [是干什么的.md](是干什么的.md)）。禁用或卸载它之后，社区反馈里比较常见的连带现象有：游戏加速 / 游戏空间相关功能异常、耗电统计不准、个别系统调度行为变化。**不同机型、不同系统版本的表现差别很大** —— 有人卸载后一切正常，也有人立刻出问题，所以下面的做法一律按「可逆」来选：先用最轻的手段，出问题能一步退回来。

建议的顺序：**清数据 → 删除更新 → adb 禁用 → adb 卸载**。前两步在设置里就能做、随时可逆；后两步才需要电脑。

## 二、设置里能做的两件事（无需电脑）

路径：「设置 → 应用设置 → 应用管理」→ 右上角菜单勾选**显示全部应用** → 搜 `Joyose`。

1. **清除数据**：配置回到初始状态，联网后会重新拉取。排查发热、掉帧、报错的第一选择（详见 [常见问题与解决办法.md](常见问题与解决办法.md)）。
2. **删除更新**（有的系统显示为「卸载更新」）：把手动装过的版本退回**出厂预置版本**。这是「回退新版本」唯一正规的入口 —— 系统预置应用没法在设置里彻底删除，只能退到出厂状态。

这两个动作做完，组件还在、功能还在，属于零风险操作。

## 三、用 adb 禁用（可逆，推荐的「彻底停用」方式）

适合想让它彻底停止运行、又留一条后路的情况。准备工作：电脑装好 adb、手机开启 USB 调试并授权电脑。

**停用**（对当前用户生效，服务立刻停止）：

```bash
adb shell pm disable-user --user 0 com.xiaomi.joyose
```

**恢复**：

```bash
adb shell pm enable com.xiaomi.joyose
```

停用期间它不再运行；系统更新或手动恢复后可重新启用。

## 四、用 adb 卸载（对当前用户移除）

比禁用更进一步：当前用户下直接移除，但**系统分区里的 APK 还在**，所以能完整恢复。

**卸载**（`-k` 表示保留数据）：

```bash
adb shell pm uninstall -k --user 0 com.xiaomi.joyose
```

**恢复**：

```bash
adb shell pm install-existing com.xiaomi.joyose
```

要不要加 `-k`：想以后原样恢复就带着 `-k`；不在乎残留数据可以去掉。恢复后建议顺手进设置核对一下版本号（方法见 [下载与安装教程.md](下载与安装教程.md) 第五节）。

**注意**：部分 HyperOS / MIUI 版本限制了对系统应用的禁用与卸载操作，命令会直接报错拒绝 —— 这是系统策略，不是你操作错了，遇到就说明这条路在你这台机器上走不通，用第二节的「删除更新」替代。

## 五、几种做法对照

| 方式 | 命令 / 入口 | 效果 | 恢复方式 | 何时用 |
| --- | --- | --- | --- | --- |
| 清除数据 | 设置 → 应用管理 | 配置归零，组件照常运行 | 联网自动重建 | 行为异常的第一步 |
| 删除更新 | 设置 → 应用管理 → 卸载更新 | 退回出厂版本 | 手动装 APK 或等推送 | 新版本有问题 |
| adb 禁用 | `pm disable-user --user 0 …` | 停止运行，不占后台 | `pm enable …` | 想彻底停用、留后路 |
| adb 卸载 | `pm uninstall -k --user 0 …` | 当前用户移除 | `pm install-existing …` | 确定长期不要它 |

## 六、系统更新会把你的改动还原

无论用哪种方式，**下一次系统 OTA 大概率会把组件恢复成官方版本** —— 这既是麻烦也是保险：你改坏了，等一次系统更新就自动回到官方状态；你改好了，更新后要重新做一遍。所以每次系统更新后，花十秒进设置核对一次版本与状态，能省掉后面一堆排查（版本核对方法见 [下载与安装教程.md](下载与安装教程.md) 第五节）。
