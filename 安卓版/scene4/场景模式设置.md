## 一、场景模式解决什么问题

同一部手机，玩游戏想要高性能高亮度，看小说想要低亮度还希望消息别弹脸——手动来回切很烦。场景模式的做法是给每个应用立一条规则：打开这个应用，Scene4 按你预设的动作自动调整；退出后恢复原样。

使用前提有两处：

- 在系统设置的「无障碍」（辅助功能）里，开启名为「Scene - 场景模式」的服务，否则 Scene4 感知不到你在前台开了哪个应用；
- 在系统的电池 / 自启动管理里，允许 Scene4 自启动并保持后台运行——后台一旦被系统杀掉，规则就不会触发了。

性能类调整（切性能模式、调调度）还需要工作模式权限到位：基础模式只能看，规则要真正生效一般需要 ADB 或 Root 模式，激活方法见 [ADB模式激活方法.md](ADB模式激活方法.md)。

## 二、给一个应用建立规则

以「打开游戏时自动切高性能、屏蔽通知」为例，路径是：场景模式 → 应用场景 → 找到目标应用 → 勾选想要的行为：

1. 进入「场景模式」的「应用场景」列表，搜索或翻到目标应用。
2. 勾选需要的动作，比如「性能模式」「独立屏幕亮度」「通知屏蔽」。
3. 对带参数的项目（如亮度值）设置具体数值。
4. 回桌面打开那个应用验证：规则生效时通常会有临时切换的痕迹（亮度变化、通知不再弹出）。

同一个应用勾的多项规则会同时生效；给所有应用都勾「高性能」没有意义，只给真正需要的几个配即可。

## 三、应用场景里可以配哪些动作

| 动作 | 作用 | 典型用途 |
| --- | --- | --- |
| 专属设置 | 给该应用单独指定性能模式等参数 | 打开游戏自动切高性能 |
| 独立屏幕亮度 | 进入该应用时用另一档亮度 | 夜里看小说压低亮度 |
| 通知屏蔽（游戏勿扰） | 该应用在前台时不让通知打扰 | 游戏对局不被弹窗打断 |
| 自动切换 GPS | 进入应用时改变 GPS 开关状态 | 导航类应用自动开、退出自动关 |
| 按键屏蔽 | 屏蔽指定的物理按键 | 游戏时误触虚拟键 / 侧键 |
| 特殊权限管理 | 按应用调整权限行为 | 对个别应用收紧或放宽权限 |
| 偏见应用 | 勾选后区别对待该应用的后台行为 | 想让某个应用更好或更难被清理时用 |

具体某一项在你的机型上是否可配，以应用内实际显示为准——不同系统开放的能力不同。

## 四、全局性能配置与能源适配

除了按应用配，还有一套不区分应用的全局配置（在「性能配置」里）：

- **应用配置**：批量勾选应用并指定模式，适合一次给一批应用统一设置。
- **配置文件**：挑选整套调节风格，对应不同的性能 / 省电取向。
- **允许更高性能**：配合性能模式一键切换使用，放开上限。
- **能源适配**：电量不足时强制省电模式，电量充足时强制极速模式。开着它就不用手动在省电和性能之间来回切了。

## 五、后台管理：离开销毁与缓存清理

和场景模式并列的还有「后台管理」两项，都依赖无障碍服务配合：

- **离开销毁**：被勾选的应用离开主界面后，立即销毁其相关进程。注意它不能阻止应用随后自动重启，对带自启唤醒的应用效果有限。
- **缓存清理**：每次应用切换后执行一次缓存清理，内存可用会变高，但可能略耗电——在意续航的话只勾常用的几个重型应用。

这两项属于「顺手偷点内存」的小工具，别指望它替代系统自身的后台管控。
