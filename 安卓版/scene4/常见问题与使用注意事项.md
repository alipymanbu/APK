## 一、需要 Root 吗

不强制。基础模式和 ADB 模式免 Root 就能用，看帧率、测充电速度、按应用配场景规则都够用。只有 ROOT 模式那一层（GPU 负载、运闪存清理、充电速度设置、游戏调度）才需要 Root 权限。

没有玩机经验不建议为了 Root 而 Root：解锁 Bootloader 本身有门槛，部分机型还会影响保修。先从基础模式用起，发现确有需要再升级，激活路径见 [ADB模式激活方法.md](ADB模式激活方法.md)。

## 二、收费吗

按官方站点现行口径：基础模式与 ADB 模式免费、免注册；ROOT 模式的全部功能可试用 15 天，到期后酌情购买。所有模式均无广告。以你设备上应用内实际提示为准——这属于可能随版本变化的信息。

## 三、打开就闪退 / 功能点了没反应

按出现频率排查：

1. **权限没给全**：存储、悬浮窗（显示在其他应用上层）两项最常见，到系统设置 → 应用 → Scene4 → 权限里逐项检查；无障碍服务没开时场景模式不工作，见 [场景模式设置.md](场景模式设置.md)。
2. **后台被杀**：数据类功能断断续续、悬浮窗自己消失，到电池 / 自启动管理里允许 Scene4 后台运行。
3. **模式选错**：帧率记录、卸载系统应用这些只在 ADB / ROOT 模式下有，基础模式下灰着或没有属正常。
4. **反复闪退**：卸载后重装一次最新可用的安装包（获取入口见 [下载与安装教程.md](下载与安装教程.md)）；仍闪退则可能是系统兼容问题，去官方渠道反馈机型与系统版本。

另有一类高频故障单独成篇：悬浮窗出不来、帧率恒为 0（含新系统适配问题），见 [帧率显示为零与悬浮窗排查.md](帧率显示为零与悬浮窗排查.md)。

## 四、重启手机后功能失效

正常现象。ADB 调试通道随重启关闭，重新激活一次即可（配对不用重做），详见 [ADB模式激活方法.md](ADB模式激活方法.md) 的「重启之后又失效了」一节。

## 五、动系统功能之前，这几条先记住

1. **卸载系统应用要克制**：ADB / Root 模式下可以卸载系统应用，误删关键组件可能导致异常甚至需要恢复出厂。卸之前先确认它不是系统依赖（拿不准就先「停用 / 冻结」而不是卸载，还能恢复）。
2. **调频率、改温控类操作有代价**：把 CPU 频率压太低会卡顿甚至死机，绕开温控限制则有过热风险——追求稳定就别动这两类。
3. **DPI 调整仅适合特定分辨率设备**，改错会出现界面错乱，改之前记下原值。
4. **重大操作前备份数据**：保留数据降级安装、刷入 Boot / Recovery 镜像这类功能，一旦出错可能要进恢复模式处理。

## 六、卸载会留下残留吗

按官方口径，Scene4 不做破坏性的系统修改，正常流程是：退出 ADB / Root 相关功能、卸载应用、重启手机，一切恢复如初。你建立的场景规则、统计记录随卸载一起消失，有需要的数据先在应用内导出。
