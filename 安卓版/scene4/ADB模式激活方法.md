# Scene4 ADB 模式激活方法（免 Root）

> 本篇讲怎么在不 Root 的前提下，用 Shizuku、黑阈或电脑 adb 把 Scene4 激活到 ADB 模式，以及重启后失效怎么处理。

## 一、先弄清楚 ADB 模式值得激活在哪

基础模式只是「看」：运存负载、电池温度、充电速度这些数据直接读。激活 ADB 模式后，多出来的主要是这几类：

- CPU 实时负载与温度（性能监视器的数据更全）；
- 帧率记录（测游戏帧数的主力功能）；
- 卸载系统应用、保留数据降级安装。

ADB 模式免费、免注册，也不改系统文件——它借的是安卓自带的调试通道，重启后通道关闭，需要重新激活一次，这是正常现象，不是坏了。

## 二、激活前的公共步骤：开无线调试

三条路径都要先做这一段。注意无线调试（免电脑激活的前提）只存在于 Android 11 及以上系统，更旧的系统只能走第五节的电脑 adb：

1. 打开系统设置 → 关于手机 → 连续点击「版本号」数次，直到提示已进入开发者模式。
2. 返回设置，进入「开发者选项」，打开「USB 调试」和「无线调试」（有的系统叫「WLAN 调试」）。

小米 / MIUI 用户多一步：先到 设置 → 通知与控制中心 → 通知显示设置，把样式改成「原生样式」，否则下面配对用的通知弹不出来。

## 三、路径一：Shizuku（推荐）

这是目前最常用的方式，需要先装一个叫 Shizuku 的应用：

1. 安装并打开 Shizuku，选择「通过无线调试启动」，点「配对」。
2. 回到开发者选项 → 无线调试 → 「使用配对码配对设备」，会显示一个 6 位配对码。
3. 下拉通知栏，找到 Shizuku 发出的配对通知，输入配对码发送，提示配对成功。
4. 回 Shizuku 主界面点「启动」，几秒内启动页自动关闭即代表服务在跑。
5. 打开 Scene4，选「ADB 模式」，在弹出的风险提示里点同意，再允许 Scene4 使用 Shizuku，进入主界面即激活完成。

## 四、路径二：黑阈

手机上装了黑阈的可以走这条路：

1. 把系统设置和黑阈分屏摆放（或者来回切换），在黑阈里点「无线调试端口」。
2. 到开发者选项 → 无线调试 → 「使用配对码配对设备」，把配对码输入黑阈弹出的通知里。
3. 配对成功后，在黑阈的「执行命令」里粘贴并执行下面这条命令：

```bash
sh /data/user/0/com.omarea.vtools/files/up.sh
```

4. 看到 `Scene-Daemon OK!` 字样即成功，回到 Scene4 选「ADB 模式」进入即可。

## 五、路径三：电脑 adb

手边有电脑、装了 adb 工具的话：

1. 手机和电脑连同一个 Wi-Fi，先按第二节的步骤打开无线调试。
2. 用无线调试的配对码完成手机与电脑的配对（`adb pair IP:端口`，IP 和端口以手机「使用配对码配对设备」页面显示的为准）。
3. 配对后执行 `adb connect IP:端口` 连上手机。
4. 打开 Scene4 选 ADB 模式时，应用内会显示一条需要执行的命令，把它放进 `adb shell` 里执行即可。命令以应用当时显示的为准，不要照抄别人的旧命令。

## 六、重启之后又失效了

重启手机后 ADB 调试通道会关闭，Shizuku 服务也会停——这时 Scene4 的 ADB 功能用不了，重新走一遍上面的启动流程即可（Shizuku 只需要重新点「启动」，配对不用重做）。嫌麻烦的做法是：需要 ADB 功能的那天顺手激活一次，平时用基础模式不受影响。

## 七、激活过程卡住怎么排

Shizuku 官方手册点名的几个高频卡点，按现象对号入座：

| 现象 | 原因与处理 |
| --- | --- |
| 一直显示「正在搜索配对服务」 | Shizuku 需要在后台访问本地网络，而不少厂商在应用切到后台后立刻断它的网。到电池 / 后台管理里允许 Shizuku 后台运行，保持屏幕亮着操作 |
| 点「输入配对码」立刻提示失败 | 先试 Shizuku 官方给的做法：把无线调试关掉再重新打开，然后重试；MIUI 上再核对通知样式是否已改为「原生样式」 |
| 点「启动」没反应或启动失败 | 同样先关掉再打开无线调试再点启动；还不行就重启手机后再来一遍 |
| Shizuku 用着用着自己停了 | 后台被系统清理所致，到电池管理里给它「无限制」；部分系统对 adb 权限有额外限制，只能以官方手册说明为准 |

激活顺利但帧率读不出来、悬浮球出不来这类「激活成功之后的故障」，排查思路在 [帧率显示为零与悬浮窗排查.md](帧率显示为零与悬浮窗排查.md)。
