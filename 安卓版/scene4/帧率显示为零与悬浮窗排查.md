## 一、悬浮球 / 悬浮窗出不来

表现是：勾选了帧率记录器，屏幕上却没有半透明悬浮按钮；或监视器窗口「点了没反应」。这几乎都是悬浮窗权限没真正开成功，按下面顺序查：

1. **权限开关的位置**：各品牌把它藏得不一样——多数系统在 设置 → 应用管理 → Scene4 → 权限；小米、华为等把它归在「特殊权限」或「显示在其他应用上层」单独一项里，不在普通权限列表里，翻普通权限页是找不到的。
2. **被标记为「受限应用」**：部分系统（荣耀 MagicOS 等）给悬浮窗权限时会提示「受限应用」并拒绝授权。要到该应用的权限详情里先「解除限制」，再开悬浮窗。
3. **后台被杀**：权限开了、悬浮窗短暂出现又消失，多半是 Scene4 的后台被系统清掉了。到电池 / 自启动管理里把它设为「不限制」或允许后台运行。

三步都做完仍不出悬浮窗，重启一次手机再试；还是不行就到「功能」里重新勾选一次帧率记录器（有时是勾选状态没刷新）。

## 二、悬浮窗正常，但帧率一直是 0

悬浮球在、游戏里数字恒为 0，或测完没有帧率数据——这不是悬浮窗问题，而是**取帧率的授权链路断了**。按命中率从高到低排查：

1. **ADB 授权没生效**：帧率记录依赖 ADB / Shizuku 授权链路。先确认 Shizuku 状态是「运行中」，再确认 Scene4 的 ADB 模式当天已激活过（重启手机后授权失效，帧率就会读不出来）。激活步骤见 [ADB模式激活方法.md](ADB模式激活方法.md)。
2. **Shizuku 与 Scene4 版本太旧**：有用户反馈在新系统上（Android 15 / 16、荣耀 MagicOS 9 等机型）旧版组合下帧率恒为 0，把 Shizuku 和 Scene 都更新到较新版本后恢复正常——新系统与旧应用之间有接口差异。装的是 4.7.3 这类旧版线、又在新系统上遇到恒 0，这是一个值得先试的方向。
3. **悬浮窗权限虽开但仍受限**：个别系统即使开了悬浮窗，仍会在后台把 Scene4 标记为受限，数据层被拦截。回权限页确认没有「受限」标记。

## 三、排除之后还不行

上面三步都做完帧率仍为 0，剩下的可能性是机型 / 系统版本的兼容问题，这类问题没有本地可修的办法：

- 换一个游戏试测，排除个别游戏界面特殊导致的取样失败；
- 到应用的反馈渠道带上机型、系统版本说明情况；
- 如果只是想看帧数又一直修不好，用系统自带的游戏工具箱（多数品牌都有）作为替代的帧数显示方案。

顺带说明：帧率记录正常时，测完的报告里通常能看到最大 / 最小 / 平均帧率、帧率波动曲线、CPU 占用曲线以及最高与平均温度，具体指标以应用内实际显示为准——如果连这些字段都没有出现，基本可以确认数据没采上来，回到第二节继续排查。
