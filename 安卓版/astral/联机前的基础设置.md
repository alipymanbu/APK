# Astral 联机前的基础设置

> 用户名、服务器、延迟优先这几项配好再开房间，能省掉大半"连不上"的麻烦；本篇按官方基础设置流程逐项列出。

## 一、为什么先做这些设置

官方文档把话挑明了：大部分联机失败不是软件坏了，而是几项基础设置没对齐——尤其是"所有人必须选同一台服务器"这一条。下面四件事做完再开房间；已经开过房但连不上的，也建议回头把第六节的清单逐项核对一遍。

## 二、设置用户名

1. 打开 Astral，在主页找到用户信息区域。
2. 输入一个用户名，要求只有两条：不与房间内其他人重复；能一眼分清谁是房主、谁是房员（比如在名字后面带个"HF"或"房主"标记）。

重名的后果是实打实的：官方明确说明可能导致无法连接或功能异常。房主最好在开房前就提醒每位房员改好。

## 三、选择服务器（最关键的一项）

1. 进入"服务器"页面，点右下角的地球图标。
2. 从列表里选服务器并点"启用"——官方建议直接选列表最上方三台。
3. 点"启用"按钮旁的"编辑服务器"，确认同时勾选了 TCP 和 UDP 两种协议。

三条注意：

- **所有人选同一台**：房主和房员选的服务器必须一致，地址要逐字核对，否则连不上。这是官方反复强调的前提，也是新手翻车最多的一条。
- UDP 协议需要服务器支持；勾选协议这项设置只对转发模式生效。
- 挑哪台的标准：延迟优先，选延迟数值最低的；同延迟下选物理距离近的。

## 四、开启"延迟优先"

进入"设置 → 网络设置"，打开"延迟优先"开关。官方给它的定位是优化路由、降低连接延迟，属于开了不亏的选项，建议所有人统一开启。

## 五、防火墙与安全软件

官方把"关闭防火墙"列为基础设置的第一步，并说明大部分联机问题由防火墙引起：防火墙会拦 P2P 连接请求、限制应用使用必要的网络端口、拖高延迟。这条主要针对 Windows 端（Astral 桌面版里自带临时关闭防火墙的入口）；安卓端对应的是：

- 系统自带的联网管控、流量防火墙类功能；
- 第三方安全 App 的联网拦截。

安卓上一般不需要关掉整个防护，联机异常时把这些拦截项对 Astral 放行即可。等熟悉了它需要哪些端口，也可以只给特定端口配放行规则，不必全关。

## 六、开联机前的核对清单

| 检查项 | 合格标准 |
| --- | --- |
| 用户名 | 已设置，不与房内其他人重名，能区分房主/房员 |
| 服务器 | 已启用，且所有人选的是同一台 |
| 协议 | 编辑服务器里 TCP、UDP 都勾上 |
| 延迟优先 | 已开启（建议全员统一） |
| 防火墙/安全软件 | 未拦截 Astral 的连接 |

都打勾了，就去开房：你是房主走[创建房间和邀请好友联机.md](创建房间和邀请好友联机.md)，你是房员走[加入房间开始游戏.md](加入房间开始游戏.md)。核对时发现哪项对不上、改完还是不行，翻[联机常见问题排查.md](联机常见问题排查.md)。
