## 一、在哪看自己的 NAT 类型

连上任意房间后，进入"房间"页面：本机信息下方是你在虚拟局域网里的 IP，旁边显示的就是 NAT 类型（比如"端口受限锥型"）。NAT 是路由器做地址转换的方式，类型不同，两台设备能不能直接打通差别很大——官方文档站为它专门写了一页说明（[astral.fan/troubleshooting/nat-types](https://astral.fan/troubleshooting/nat-types)），本篇把要点整理成能直接动手的形式。

## 二、各类型是什么意思

| NAT 类型 | 官方口径 | 直连成功率（官方给的量级） |
| --- | --- | --- |
| 开放网络 / 无 PAT（OpenInternet / NoPat） | 设备直接连互联网、无转换，通常只有服务器或专线才有 | 95% 以上 |
| 全锥形（FullCone） | 主动连过外部，外部就能随时连回来 | 85% 以上 |
| 受限锥形（Restricted） | 只有主动联系过的 IP 能连回来 | 70% 以上 |
| 端口受限锥形（PortRestricted） | 只有主动联系过的 IP 和端口能连回来 | 60% 以上 |
| 对称型（Symmetric 及递增/递减变体） | 每次连接外部都用不同端口，P2P 最难打通 | 30% 以上 |
| 对称 UDP 防火墙（SymUdpFirewall） | UDP 通信被防火墙拦住 | 10% 以上 |
| 未知（Unknown） | 检测失败，可能网络本身异常 | 视网络而定 |

这张表的用法：延迟突然变高但还连得上，多半是"打洞失败、流量走了中继"——对称型网络的典型表现。能玩，但延迟比直连高，改善方向见下一节。锥形类是家用路由器最常见的类型，P2P 友好，一般不用动。

## 三、家用网络怎么改善

按动手成本从低到高：

1. **重启路由器**：有时能换到一个更好的 NAT 类型，最便宜的一招。
2. **开 UPnP**：路由器管理界面里找 UPnP 开关。各品牌路径参考（以路由器实际界面为准）：

| 路由器品牌 | 设置路径参考 |
| --- | --- |
| TP-Link | 高级功能 → NAT转发 → UPnP |
| 华为/荣耀 | 更多功能 → 网络设置 → UPnP |
| 小米 | 常用设置 → 端口转发 |
| 华硕 | 外部网络 → 端口转发 |

3. **端口转发或 DMZ**：把你设备的内网 IP 在路由器上做端口映射，或设为 DMZ 主机。动手前记录原始设置，方便恢复。
4. **升级路由器固件**，或换支持 NAT 优化的路由器。
5. **找运营商要公网 IP**：电话客服可以申请，很多地区免费；另外"光猫拨号 + 路由器再拨号"这种多层 NAT 也是对称型的常见来源，改成光猫桥接有可能改善。

改路由器前确认你有管理员权限，并记下原配置。

## 四、校园网与公司网：官方明确不适合

官方说明写得很直接：Astral 专为个人用户设计，不适合企业或校园网络环境。这两类网络通常是对称型 NAT 加防火墙，UDP 被拦得很死。在宿舍或办公室想联机，官方的建议是用手机流量开个人热点，或换到家庭网络。

## 五、手机端的四条官方建议

官方 NAT 说明页给移动设备用户的建议，逐条可执行：

1. 优先用 WiFi，避免用移动热点当联机网络；
2. 了解你的运营商是否提供公网 IP；
3. 保持网络连接稳定，联机时别在 WiFi 和流量之间来回切；
4. 关闭 Astral 的电池优化以保持网络连接——系统省电策略掐掉后台连接也是掉线的常见原因，具体放行步骤见[安卓后台掉线与省电设置.md](安卓后台掉线与省电设置.md)。

## 六、实在改不动怎么办

NAT 类型不是判决书：官方明确说服务器中继可以解决大部分连接问题，代价是延迟可能偏高。所以对称型网络照样能联机，只是体验打折；配合"延迟优先"、选近的服务器（见[联机前的基础设置.md](联机前的基础设置.md)），多数局能开下去。改完路由器后回房间页再看一眼 NAT 类型有没有变化；没变化、连接还是不顺，按[联机常见问题排查.md](联机常见问题排查.md)的分层思路继续查。
