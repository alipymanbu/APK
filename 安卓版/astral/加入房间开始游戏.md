# Astral 加入房间开始游戏教程

> 你是房员时看这篇：拿到房间号或分享码后怎么进房、怎么确认自己连上了、以及在 Minecraft、Terraria 这些游戏里怎么连到房主。

## 一、加入前先对齐三件事

进房之前跟房主核对：

1. **服务器**：你选的服务器必须和房主完全相同，这是能否进房的关键前提；怎么选见[联机前的基础设置.md](联机前的基础设置.md)。
2. **用户名**：别和房间里任何人重名，否则可能连不上或功能异常。
3. **材料**：房间号+密码，或者房主发的分享码——两样有一即可。

## 二、两种进房方式

**用房间号加入**（房主没开保护模式时）：

1. 进入"房间"页面，点右下角加号。
2. 房间名称随便起（不用和房主一样）；房间号填房主给你的；有密码就填密码。
3. 点"确定"，房间出现在你的列表里。

**用分享码加入**（推荐；房主开了保护模式时只能用这个）：

1. 进入"房间"页面，点右下角的"任务板"图标。
2. 把房主发的分享码整段粘贴进去，点"确定"。
3. 房间信息自动配好，直接出现在列表里。

## 三、连接并确认自己进来了

1. 在房间列表点选房间，让它处于选中状态。
2. 回主界面点"连接"，等状态变成"已连接"。
3. 回到房间页面对照三样东西：
   - 用户名下方就是你的虚拟 IP，形如 `10.126.126.2`（最后一位每人不同）；
   - 能看到房主和其他成员，说明人已经在一个网里了；
   - 连接状态一栏左边是延迟、右边是丢包。

手机还有一个特有的坑：锁屏或切后台几分钟后就掉线，那是系统省电策略在杀后台连接，不是你网络的问题，放行方法见[安卓后台掉线与省电设置.md](安卓后台掉线与省电设置.md)。

## 四、在游戏里连到房主

连上之后，游戏里的事就是"局域网联机"那一套。房主会把他的虚拟 IP（`10.126.126.x`）发给你，你在游戏的多人模式里直接连接这个 IP 即可。常用游戏的连接方式参考（端口以游戏实际为准）：

| 游戏 | 端口 | 连接方式 |
| --- | --- | --- |
| Minecraft | 25565 | 多人模式直接连接 |
| Terraria | 7777 | 游戏内加入 |
| 7 Days to Die | 26900 | 服务器浏览器 |
| Valheim | 2456-2458 | Steam 邀请 |
| ARK | 7778 | 服务器浏览器 |
| Rust | 28015 | F1 控制台 |

两个高频翻车点：一是游戏版本或 Mod 列表和房主不一致，房里搜不到世界；二是部分游戏要把网络模式设成"局域网/LAN"才能发现对方。遇到这两种情况，直接翻[联机常见问题排查.md](联机常见问题排查.md)第二节的排查顺序。

## 五、先 ping 一下再进游戏

游戏里连不上时，先分清是"Astral 的网不通"还是"游戏的问题"：

```
ping 10.126.126.x
```

把 `x` 换成房主虚拟 IP 的末位。ping 得通，说明网络这层没问题，去查游戏版本、Mod 和端口；ping 不通，说明虚拟局域网本身没打通，回到[联机常见问题排查.md](联机常见问题排查.md)按房间连接类问题处理。

ping 通了但游戏还是连不上，再测端口：`telnet 10.126.126.x 25565`（IP 换成房主的、端口换成对应游戏的；Windows 需先在"启用或关闭 Windows 功能"里勾选 Telnet 客户端）。端口不通，问题出在防火墙或游戏没在该端口上监听。
