## 一、收不到短信验证码

银联即时认证、登录二次验证都依赖短信验证码，收不到时按可能性排查：

1. **确认手机号是注册时填的那个**，且能正常收其他短信（运营商拦截常被忽略，去拦截记录里翻一下）。
2. **等够时间再重发**，连续点重发反而容易触发频控。
3. 换网络环境（Wi-Fi 与移动数据互切）后重试，部分请求对网络质量敏感。
4. 仍收不到就改走另一条认证路：有国际信用卡的改用账单码认证（等 2~3 个工作日查账单），流程见 [注册与账户认证流程.md](注册与账户认证流程.md) 第三节。

## 二、登录不上或反复要求验证

- **密码错误**：用官网找回流程重置，不要连续试错，错多了账户可能被临时锁定。
- **反复弹出安全验证**：换设备、换网络、长时间不用后首次登录都可能出现，属于正常风控，按页面提示完成即可。
- **登录成功但页面空白/加载慢**：先切网络重试；应用内功能因所在市场而异（官方页面明确标注），个别板块在你的账户所在市场可能根本不提供，这不是故障。

## 三、账户被限制怎么办

账户被限制（无法付款、无法提现、要求补充资料）时，先按 [账户被限制与资金处理.md](账户被限制与资金处理.md) 分清是临时限制还是更重的情形，临时限制的解除路径是固定的：

1. 登录网页版看「待办事项 / 通知中心」，官方会写明限制原因与需要提供的材料。
2. 按清单提交资料（通常是身份证明、地址证明类文件），等审核。
3. 审核期间不要重复提交、不要新开账户，同一个人多账户反而加大风控概率。

防患于未然的一条：注册时就按证件信息填写（中文姓名、真实出生日期与地址），认证与绑卡也用本人同名卡，账户资料的每一环都对得上，被风控的概率就低得多——具体要求见 [绑卡与提现教程.md](绑卡与提现教程.md) 的同名要求。

## 四、安装包校验（MD5）

用安装包安装后若怀疑文件不完整（安装报错、闪退），在电脑上核对 MD5。Windows 自带工具即可：

```powershell
certutil -hashfile "D:\下载\paypal_v8.57.1.apk" MD5
```

输出的哈希值与下面这条逐字比对（写教程时所用安装包的实测值）：

| 项目 | 值 |
| --- | --- |
| 版本 | 8.57.1 |
| 大小 | 181.15M |
| MD5 | 6117B58284CB4A76F503D7752485227C |

对不上就是文件传输过程损坏，重新获取一份再装；安装步骤本身见 [下载与安装教程.md](下载与安装教程.md)。

## 五、收款金额对不上 / 费用疑问

到手金额与预期不符时，多半不是「扣错了」，而是三个环节各扣了一部分：商品交易费率、跨境附加、币种折算。逐项打开交易详情核对，判断方法与查官方费率的入口见 [手续费与汇率注意事项.md](手续费与汇率注意事项.md) 第二节。

至于买东西货没收到、或收到的东西与描述不符要拿回钱，那走的是官方买家保障的争议流程，时限与操作见 [买家保障与退款纠纷处理.md](买家保障与退款纠纷处理.md)。

## 六、更新与重装

- 通过安装包安装的版本不会自动更新，需要新版时重新获取安装包覆盖安装，账户数据在服务端，重装不丢。
- 覆盖安装失败（提示签名或解析错误）时，先卸载旧版再装，登录原账号即可，资产与交易记录不受影响。
