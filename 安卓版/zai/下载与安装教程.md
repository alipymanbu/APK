## 一、先核对手上这份包

ZAI 是一款**双向授权的实时位置分享应用**：你和对方都装上、互加好友并同意之后，才能在地图上互相看到位置，情侣、家庭、学生用得比较多。官方主体是深圳市生活必需品科技有限公司，安卓与 iOS 都有版本。

动手前先对一下手上这份包：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | ZAI |
| 包名 | com.xycz.zmhx |
| 版本号 | 1.0.3 |
| 安装包大小 | 24.98 MB |
| 安装包 MD5 | 8E0290A1B5D0FB1F579E58E15733F8B8 |
| 系统要求 | 页面标注「安卓 5.2 以上」（安卓没有 5.2 这个正式版本号，别当硬指标，以实际安装为准） |

**版本号别拿别处的来对。** 应用商店与各大下载站上的 ZAI 已经更新到 2.x 版、包名也与这份不同（商店那份是 `com.zai.app`），网上搜到的更新日志、体积同样对不上 —— 那是官方渠道的另一份包，不是你手上这一份。判断手上这份对不对只看两项：包名是不是 `com.xycz.zmhx`，版本号是不是 `1.0.3`。

**别下成同名的别的软件。** 「ZAI」这个名字短、容易撞，搜索时认准包名与体积；拿不准就只从下面的网盘取，别在搜索结果里随手点「立即下载」。

## 二、从网盘把安装包取到手机

1. 在手机上打开 [ZAI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6ab6f489f242)。手机浏览器或夸克 App 都能开，**建议用夸克 App** —— 浏览器下大文件容易被切到后台打断。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存之后就不再依赖原分享链接还在不在。
3. 进自己的网盘找到这个包（形如 `zai_v1.0.3.apk`），点下载，等它落到手机存储里。
4. 下完核对两件事：文件名结尾是不是 `.apk`；大小是不是 24.98 MB 左右。差得多就是没下完整，删掉重来。

习惯在电脑上操作也行：在电脑端网盘下载，再用数据线拷到手机的 `Download` 目录，之后从手机「文件管理」里点它安装，效果一样。

手上有校验工具的话可以顺手算一遍 MD5，和上表的 `8E0290A1B5D0FB1F579E58E15733F8B8` 比一比：一致说明传输没出错，不一致就重新下一遍。不查也不影响安装。

## 三、安装：系统会拦一次，放行即可

这一份是手动安装的，不是从手机自带应用商店点「安装」装的，所以点安装包时系统会拦一下，提示「不允许安装来自此来源的应用」之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开「文件管理」，进 `Download` 目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，找到你刚才用来打开文件的那个 App 单独放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」，先把第四节的权限理顺再进去，比进去之后反复弹窗省事。

## 四、首次打开：定位与后台权限是关键

ZAI 的全部功能都建立在「持续拿到你的位置」上，第一次启动会连着弹几项授权，建议一次给足：

1. **定位权限选「始终允许」**，不要只选「仅使用期间」。只给前台定位的话，你锁屏或切到别的应用后位置就停更了 —— 对方看到的你会一直钉在上次的位置。
2. **打开「始终定位」和运动权限**。官方说明里明确要求这两项都开，位置才会持续刷新；运动权限用于判断你是在走还是在停，配合轨迹功能。
3. **允许自启动 / 后台运行**。安卓的省电策略默认会杀掉后台应用，ZAI 需要在后台保持活跃才能实时更新位置 —— 各机型入口不同，整套设置（含华为、小米、OPPO、vivo 的具体路径与验证方法）按 [各品牌手机后台保活设置.md](各品牌手机后台保活设置.md) 走一遍。
4. **悬浮窗权限建议给**。你在改后台设置时，它会在别的界面顶层弹配置指引，照着点更快。
5. 其余权限（存储、录音、相机、电话）都是聊天与账号相关的，按需给；不给聊天里的对应功能用不了，但定位不受影响（各项用途见 [常见问题与隐私权限说明.md](常见问题与隐私权限说明.md)）。

## 五、装完先做三步自检

1. **账号能不能登进去**：打开应用，按提示用手机号完成注册 / 登录（收不到验证码先检查信号与短信拦截）。
2. **定位权限对不对**：进手机「设置 → 应用 → ZAI → 权限」，确认位置是「始终允许」，不是「仅使用期间」。
3. **找个熟人走一遍加好友**：两边都装好、互加好友并等对方同意（入口和步骤见 [加好友与实时位置共享.md](加好友与实时位置共享.md)），对方头像能在地图上出现就算通。

三步都过就可以正常用了。对方位置不更新、地图上位置乱跳这类问题，对照 [位置不更新与定位不准怎么办.md](位置不更新与定位不准怎么办.md) 排查。

## 六、升级与卸载要注意的

- **升级**：商店里的官方版与这份是不同的包，直接拿商店版覆盖装，可能提示签名不一致、装不上；真要换版本，先卸载再装，卸载前注意下面这条。
- **卸载会清掉应用内数据**：好友关系、聊天记录、你设过的提醒区域都跟着没，重新装完要重新加好友、重设提醒。装新版本前先确认这些重来一遍能不能接受。
- **安装包删了**：任何时候都能回到文首那条 ZAI 安装文件资源的链接重新取一份；已经转存过的不受原分享是否还在影响。
