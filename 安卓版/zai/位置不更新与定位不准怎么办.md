## 一、官方对「位置不更新」的结论先摆出来

官方在应用商店页与应用说明里反复给同一条判断：**对方位置不更新，大概率是对方没按要求设置好自己的手机**，而不是服务挂了。ZAI 的设计是「双方都开对权限，位置才持续刷新」，任何一边掉链子，另一边看到的就是旧位置。

所以排查的主语永远是**对方的手机**（当然，你也顺手核一遍自己的）。按下面顺序走，多数问题在前两步就解决。

## 二、四步排查清单

按顺序做，每步都给出明确动作：

1. **看时间戳，先定位问题性质**
   点对方头像，看面板上的「N 分钟前更新」。
   - 几分钟内 → 正常，位置本来就是按需刷新的，稍等即可；
   - 几小时甚至更久 → 是故障，继续往下查。

2. **对方的定位权限是不是「始终允许」**
   手机「设置 → 应用 → ZAI → 权限 → 位置」，必须是**始终允许**。选成「仅使用期间允许」时，对方一锁屏或切走，位置就停更 —— 这是最高发的原因。
   同一页面再确认应用内的**「始终定位」与运动权限**也开着（官方说明明确要求这两项）。

3. **后台有没有被省电策略杀掉**
   安卓的电池优化默认会杀后台应用。官方在应用商店描述里的原话是：**「位置会在后台更新，请按照应用内指引为 ZAI 打开自启动、忽略省电等设置，才能确保你没打开 ZAI 时的持续定位。」** 逐项核对：
   - 「设置 → 应用 → ZAI → 省电策略」改为**不限制 / 允许后台运行**；
   - 「设置 → 应用 → 权限 → 自启动管理」里打开 ZAI 的自启动 —— 隐私政策里写明 ZAI 需要自启动服务来保持后台定位活跃，关掉它位置就没法在后台更新；
   - 部分机型还要把 ZAI 加进「最近任务锁定」（多任务列表里下拉加锁），防止一键清理把它清掉；
   - 手机的**省电模式要关掉** —— 它生效时会把上面几项一起压制。

   四项的**各品牌具体入口**（华为、小米、OPPO、vivo 分开写）与设完怎么实测，见 [各品牌手机后台保活设置.md](各品牌手机后台保活设置.md)。

4. **网络与手机状态**
   没网、开飞行模式、手机没电关机，位置都发不出来。看一眼对方电量（地图面板上就有）：电量耗尽自动关机时，位置会永远停在关机前那一刻。

前三步做完仍不更新，再用应用内的客服通道（见第四节）。

## 三、位置乱跳、偏得远：哪些是正常物理限制

地图上位置一会在这、一会在那，先分清是环境问题还是应用问题：

| 现象 | 原因 | 你该做什么 |
| --- | --- | --- |
| 室内位置偏几十到几百米 | 室内收不到卫星信号，靠 WiFi / 基站估算 | 到窗边或室外刷新看是否恢复 |
| 高楼群之间来回跳 | 卫星信号被建筑反射（多路径效应） | 走到开阔处再看 |
| 长时间纹丝不动 | 后台被杀，见第二节第 3 步 | 按第二节省电设置处理 |
| 位置停在旧地点 | 对方还没出发或权限没给全 | 看时间戳，再走第二节 |

定位靠的是 GPS 加 WiFi / 基站辅助，**误差范围是物理决定的**，地图缩放级别也影响观感：放得越大，看到的点越「像精确到门牌」，实际精度并没有变。看位置请以面板上的地点名和更新时间为准，别只盯小人站哪。

## 四、自己这边该做的两件事

- **把自己的权限开对**：你位置停更，对方看到的同样是旧的。对照 [下载与安装教程.md](下载与安装教程.md) 第四节把定位、始终定位、运动权限、自启动四项一次做完。
- **别用「卸载重装」当万能解**：重装会清掉好友关系与设置，装完还得重新加好友（见 [加好友与实时位置共享.md](加好友与实时位置共享.md)），除非确认是安装包损坏，否则先走完第二节四步。

## 五、什么时候该找客服

走完第二节仍不更新，且**你自己这边确认权限全对**，就不是设置问题了，用官方客服通道：

- 应用内：「设置 → 联系客服」直接发起会话；
- 微信号：`supappcn`（添加后把问题、机型、系统版本发过去）；
- 微信公众号：**ZAI App**（原名 zaiappcn），公众号里有配置视频与常见问题解答 —— 手机机型设置步骤不明确时，先看它的配置视频比自己猜快。

提供三样信息能省一轮来回：双方的手机型号与系统版本、面板上「多久没更新」、第二节里你已经确认过哪几步。
