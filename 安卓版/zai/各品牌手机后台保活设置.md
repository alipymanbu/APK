# ZAI 后台保活设置（各品牌）

## 一、为什么要做：官方原话就写在应用说明里

ZAI 官方在各应用商店的描述里明确要求：**「位置会在后台更新，请按照应用内指引为 ZAI 打开自启动、忽略省电等设置，才能确保你没打开 ZAI 时的持续定位。」** 你锁屏之后位置还在刷新，靠的不是应用本身，而是手机系统允许它活着。

安卓各品牌的后台策略都很激进：应用退到后台几分钟，系统就可能把它冻结或杀掉 —— 这是省电设计，不是针对 ZAI。所以不管哪个品牌，保活都是同一组三件事：

| 要开的设置 | 作用 |
| --- | --- |
| 自启动 | 手机重启、应用被清后，系统允许它自己把定位服务拉起来 |
| 后台不限制（忽略省电） | 不因省电策略冻结它的后台活动 |
| 锁定后台（多任务加锁） | 你一键清理后台时不把它清掉 |

**还有一条所有品牌通用的前提：关掉省电模式。** 省电模式（含「超级省电」）生效时，上面三项设置会被整体压制 —— 先在「设置 → 电池」里把它关掉，改用均衡或性能模式。

下面按品牌给入口，找不到对应项就以你系统里的实际叫法为准（各机型 UI 常调整，以设置里能搜到的关键词为准）。

## 二、华为 / 荣耀（HarmonyOS / EMUI）

1. **启动管理**：「设置 → 应用 → 应用启动管理」，找到 ZAI，把「自动管理」关掉，切到**手动管理**，弹出的三项（允许自动启动、允许关联启动、允许后台活动）**全部打开**。
2. **电池优化放行**：「设置」里搜索「电池优化」，切到「不允许」列表或全应用列表，把 ZAI 设为**不允许优化**（Don't allow）。
3. **锁定后台**：调出多任务界面，把 ZAI 卡片**向下滑**，卡片出现小锁图标 —— 一键清理就不会清掉它。
4. **休眠时保持联网**：「设置 → 电池 → 更多电池设置」里打开「休眠时保持网络连接」，否则锁屏断网，位置发不出去。

## 三、小米 / Redmi（MIUI / HyperOS）

1. **自启动**：「设置 → 应用设置 → 授权管理 → 自启动管理」，打开 ZAI；或在「应用管理 → ZAI → 自启动」里开。
2. **省电策略**：「应用管理 → ZAI → 省电策略」，选**无限制**（有的版本叫「不限制后台活动」）。
3. **锁定后台**：多任务界面**长按**（或下滑）ZAI 卡片，点锁头图标锁定；也可走「手机管家 → 优化加速 → 设置 → 锁定任务」打开 ZAI。
4. **关省电模式**：「省电与电池」里退出省电模式 —— 小米的省电策略最激进，不开这一条前三步可能白设。

## 四、OPPO / 一加 / realme（ColorOS）

1. 「设置 → 应用管理」找到 ZAI，打开**自启动**。
2. 同一页面进「电池 / 耗电保护」，选项通常是「智能限制 / 允许后台运行 / 禁止后台运行」，选**允许后台运行**。
3. 多任务界面锁定 ZAI 卡片；系统「省电模式」关掉。

## 五、vivo / iQOO（OriginOS / Funtouch OS）

1. 「i 管家 → 应用管理 / 权限管理」，给 ZAI 打开**自启动**。
2. 「i 管家 → 电池管理」，把 ZAI 加进**后台高耗电白名单**（有的版本叫「后台白名单」），允许它在后台持续运行。
3. 多任务界面锁定 ZAI 卡片；省电模式关掉。

## 六、设置完怎么验证

别只看开关是开了 —— 用一次实测：

1. 让对方（或你自己另一台装了 ZAI 的手机）打开地图，记下面板上的「N 分钟前更新」；
2. 锁屏、把 ZAI 从最近任务里划掉（**不要**划掉后不管，正好验证自启动），带着手机走动 5~10 分钟；
3. 再打开地图看时间戳：刷新了、位置跟着你走了，说明保活生效；还是旧位置，回到 [位置不更新与定位不准怎么办.md](位置不更新与定位不准怎么办.md) 第二节逐条对照，或回本篇核对品牌章节是否漏了哪一步。

常见漏项按命中率排：**省电模式没关** > **省电策略仍是「智能限制」** > **多任务没锁定** > **自启动没开**。

## 七、代价与边界

- **耗电是必然的**：后台持续定位 + 常驻网络，电量会比没装 ZAI 掉得快，这是功能本身的成本。省电只能靠关掉用不到的通知、不用时退出登录，不能靠开省电模式（开了保活就失效）。
- **杀毒 / 清理类工具会帮倒忙**：第三方清理工具常把「无自启动」的应用一律清掉，把 ZAI 加入它们的白名单，或干脆别用一键清理。
- **系统大版本升级后设置会重置**：升级完 ZAI 版本或手机系统后，回头把本篇三件事再核对一遍，位置突然不更新多半就是哪一项被重置了。
