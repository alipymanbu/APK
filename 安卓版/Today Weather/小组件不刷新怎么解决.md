# Today Weather 小组件不刷新怎么解决

> 小组件数值不变、空白、卡在 Loading、时间不对，这篇按从易到难的顺序给你排查路径。
> **相关文档**：[小组件样式与添加方法.md](小组件样式与添加方法.md) · [通知与状态栏温度设置.md](通知与状态栏温度设置.md)

## 一、先用应用里自带的排障入口

这是官方给出的第一站：打开 Today Weather → 设置 → Troubleshooting（排障），按里面的步骤逐项做。安卓的电池与后台限制会拖慢小组件更新，排障入口就是把常见的限制项集中列给你去放开。**做完记得重启手机**，很多设置要重启后才生效。

## 二、空白或卡在 Loading

按官方口径，处理顺序是：

1. 重启手机；
2. 重启后把小组件重新添加或刷新一次；
3. 还是空白的话，联系开发者时带上：设备型号、安卓版本、应用版本、小组件编号或类型。

## 三、只有手动刷新才更新：查后台限制

小组件只在你点开应用时才更新，多半是系统把应用的后台活动限制住了。按你手机的牌子对号入座：

| 设备 | 要动的地方 |
| --- | --- |
| 三星（One UI） | 应用电池改为「不受限制」；从「睡眠应用」「深度睡眠应用」列表移出；支持的机型把它加进「从不睡眠应用」 |
| 小米 / Redmi / POCO | 打开「自启动」；省电策略改为「无限制」；在最近任务里把应用锁定 |
| Pixel / 原生系统 | 系统设置 → 应用 → Today Weather → 电池 → 改为「不受限制」（有这个选项的话） |

以上都来自官方 FAQ 的分品牌指引，每一项做完都要重启手机再看效果。

## 四、时间或日期显示不对

进 Today Weather → 设置 → Troubleshooting，确认系统开了自动获取日期、时间与时区。改完还错的话，反馈时要带上小组件编号、系统「日期和时间」设置页的截图。

## 五、反馈问题时带什么

官方列的清单是：截图或短录屏、设备型号、系统版本、应用版本、出问题的城市（如相关）、所用数据源（如相关）、小组件编号或类型（如相关）。带齐这几样能省掉一轮来回追问。反馈邮箱见[常见问题排查](常见问题排查.md)。

顺带一提：后台限制同样会拖累通知与状态栏温度的刷新，如果通知也不来，把第三节那几项一起放开即可，详见[通知与状态栏温度设置](通知与状态栏温度设置.md)。
