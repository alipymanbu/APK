## 一、哪些现象是后台被限制引起的

下面这些现象看起来各是各的毛病，根源常常是同一个：

| 现象 | 对应的处理篇 |
| --- | --- |
| 小组件数值不变、只在你点开应用后才更新 | [小组件不刷新怎么解决](小组件不刷新怎么解决.md) |
| 状态栏温度消失、常驻通知不见 | [通知与状态栏温度设置](通知与状态栏温度设置.md) |
| 降雨提醒该来的时候不来 | 同上 |

安卓的电池与后台限制会拖慢这类定时更新，这是官方 FAQ 的口径。所以遇到「时间性功能集体失灵」，先从后台限制查起，而不是挨个重装。

## 二、动手前先跑一次应用内排障

打开 Today Weather → 设置 → Troubleshooting（排障）。它把常见的限制项集中列出来，按里面步骤逐项做。**做完重启手机** —— 很多电池设置要重启后才生效，不重启会以为没效果又去瞎折腾。

## 三、分品牌放开后台限制

按你手机的牌子对号入座，以下出自官方 FAQ 的分品牌指引：

| 设备 | 要动的地方 |
| --- | --- |
| 三星（One UI） | 设置 → 应用 → Today Weather → 电池 → 改为「不受限制」；再到设备电池设置里，把它从「睡眠应用」「深度睡眠应用」列表移出，支持的机型加进「从不睡眠应用」 |
| 小米 / Redmi / POCO | 打开「自启动」；应用省电策略改为「无限制」；在最近任务卡片上把应用锁定 |
| Pixel / 原生系统 | 设置 → 应用 → Today Weather → 电池 → 改为「不受限制」（有这个选项的话） |

表格里的每一项做完，都要重启手机再看效果。

## 四、放开之后怎么验证

1. 桌面上放一块时钟天气小组件；
2. 锁屏正常使用一段时间（半天左右足够），期间不要手动打开应用；
3. 回来看小组件数值有没有自己变过，常驻通知还在不在。

还是不行的话，按[小组件不刷新怎么解决](小组件不刷新怎么解决.md)第五节的清单把设备信息收集齐，直接联系开发者。
