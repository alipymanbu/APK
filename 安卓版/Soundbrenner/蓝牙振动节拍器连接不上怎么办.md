## 一、先说结论：没有手表的人不需要看这篇

节拍器、练习记录、调音器这些核心功能全在手机里就能用，见[节拍器怎么调速度和拍号.md](节拍器怎么调速度和拍号.md)。这篇只服务一类场景：你有 Soundbrenner 的振动节拍器（Pulse、Core、Spark 之一），想让它戴在手腕上跟着应用一起震。它的典型症状是「连上了但没反应」，九成是连接方式错了，往下看。

## 二、正确的连接方式：只在应用里连

**不要先在手机系统的蓝牙设置里配对手表**，这是最常见的错法。正确顺序：

1. 打开 Soundbrenner 应用，进入设备连接入口；
2. 让应用搜索并直接连接手表；
3. 配对关系由应用管理，系统蓝牙列表里没它是正常的。

如果你已经先在系统蓝牙里配对过（或手表已经出现在系统蓝牙列表里），先到系统「设置 → 已连接的设备 / 蓝牙」里把它**移除或忘记**，再回到应用内重新连接。一个手表同一时间只能连一台手机，换手机前要先在旧手机上断开。

## 三、症状对照排查

| 症状 | 处理 |
| --- | --- |
| 手表一直停在 120 BPM、不响也不震 | 就是没在应用里正确连接。按上一节：先从系统蓝牙删除，再进应用内重连 |
| 应用里显示已连，改 BPM 手表不跟 | 同上，先忘记再重连；仍不行就重启手表（见下） |
| 安卓上连一会儿就断 | 多半是权限或省电限制，见第四节 |
| 手表完全没反应 | 重启手表：取下表带，表带遮住的位置有个小圆孔，用针之类尖物捅一下，成功会短暂亮灯 |

## 四、安卓机型重点：权限与省电

安卓会严格限制后台蓝牙和后台进程，连接不稳优先查这几项（路径因机型略有差异）：

1. 系统「设置 → 应用 → Soundbrenner → 权限」，确认**蓝牙 / 附近的设备**已允许；有的系统版本还要求**位置权限**（选「始终允许」更稳）。
2. 关掉该应用的**电池优化**，并允许后台运行；部分厂商系统还有单独的「后台限制」项，设为无限制。
3. 应用去商店检查有没有更新，先升到最新版再排查硬件问题。

## 五、手表侧的日常注意

- 充电：磁吸线接上后指示灯闪橙色为充电中，充满转常亮绿；长期不用别放超过三个月不充电，锂电池会过放损坏。
- 手表固件与应用版本要配套，连接异常时先升应用、再重启手表，多数问题到此为止。
- 还是连不上时，通过官网 [www.soundbrenner.com](http://www.soundbrenner.com) 的联系支持入口找官方协助；订阅与账号类问题见[常见问题与使用技巧.md](常见问题与使用技巧.md)。
