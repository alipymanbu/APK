## 一、下载卡在 0%

按出现频率从高到低排查：

1. **确认已登录**：没登录账号时下载不会真正开始，先到「我的」登录。
2. **断开加速器 / VPN**：挂着代理时下载通道经常连不上，断开再试 —— 各家常见问题解答都把它列在第一位。
3. **检查手机网络**：切一下 Wi-Fi 与流量，或换个网络环境试。
4. **重启应用**：把游咔从后台彻底关掉再打开，重新点下载。
5. **换下载通道**：详情页里在普通下载与极速下载之间换一种（两种方式的区别见 [游戏下载与积分任务.md](游戏下载与积分任务.md)）。

以上都试过仍卡住，先放一放，过段时间资源侧恢复再下 —— 卡 0% 很多时候是资源端临时问题，不是你手机的故障。

## 二、点下载下不了

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 极速下载点了一直失败 | 积分余额不足 | 去「我的」→「积分任务」攒积分，或改用普通下载 |
| 所有方式都下不动 | 资源过了时效、链接失效 | 该资源需要补档，在游戏页反馈或到社区求助 |
| 普通下载复制了链接打不开 | 链接没完整复制 / 粘错了位置 | 重新复制一次，粘到浏览器地址栏 |

## 三、游戏装不上 / 安装包打不开

1. **存储空间不够**：先确认手机剩余空间大于安装包体积，清出余量再下。
2. **系统版本过低**：游戏对系统有最低要求时，低版本机会被安装器直接拦下，换设备或升级系统。
3. **没给安装权限**：安卓默认拦「未知来源」安装 —— 按 [下载与安装教程.md](下载与安装教程.md) 第三节授权后重试。
4. **包没下完整**：下载中断会产生残缺文件，删掉重新下载一遍。

## 四、游咔本身闪退 / 打不开

- 先确认装的是完整包：版本、包名、MD5 与 [版本号与包名核对.md](版本号与包名核对.md) 里的表格一致，不一致说明拿到的不是这份文件。
- 手机内存吃紧时先清后台再开。
- 安装包正常却反复闪退，卸载后从 [下载与安装教程.md](下载与安装教程.md) 的入口重新装一遍，装好用原手机号登录回来即可。

## 五、下载速度慢、更新不了

| 症状 | 按顺序试这几步 |
| --- | --- |
| 下载能走但很慢 | ① Wi-Fi 与流量互切一次；② 详情页换一条下载线路（普通 / 极速本来就是两条通道）；③ 关掉后台占带宽的应用；④ 错开晚间高峰再下 |
| 应用或游戏更新一直失败 | ① 换网络模式（无线切流量）再试；② 避开服务器维护或高峰时段，过一两个小时重试；③ 清理存储空间，更新包也要占地方 |

清出存储空间这一步在两栏都适用：空间不足既会让下载走不动，也会让更新装不上去。

## 六、账号相关

注册、登录报错、换手机找回、注销账号的完整步骤都在 [账号注册与注销.md](账号注册与注销.md)，这里只列最快的判断：

| 问题 | 一步处理 |
| --- | --- |
| 注册收不到验证码 | 检查手机号输入、信号；稍等后重发，频繁重发会被限流 |
| 登录提示账号或密码错误 | 改用验证码登录，绕开记错的密码 |
| 提示维护 / 服务器异常 | 不是你一个人的问题，等一两个小时再试 |
| 换手机后登录不上 | 用原手机号重新验证登录即可 |

## 七、找不到想要的游戏、资讯像是旧的

- 搜索结果与首页推荐按热度排序，长尾小众游戏用**精确名称**搜更准。
- 每日新上架的内容会排在前面；你看到「不是最新的」，多半是该条目排在了旧列表里，进详情页看更新时间即可。
- 某款游戏彻底搜不到：属于资源缺失，不是你操作的问题，处理方式同第二节。

## 八、还是解决不了

先做两件事再求助：① 用 [版本号与包名核对.md](版本号与包名核对.md) 确认自己装的确实是这份 4.0.7 的包；② 记下「哪一步、点了什么、提示什么」。带着这三条信息去游戏页反馈或社区发帖，别人才能接得上话。
