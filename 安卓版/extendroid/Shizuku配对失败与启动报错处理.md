# Shizuku 配对失败与启动报错处理

> Extendroid 开不出窗口，查下来是 Shizuku 本身配对不上、启动报错或中途停止 —— 本篇按报错现象给出处理办法。
> **相关文档**：[Shizuku激活与授权设置.md](Shizuku激活与授权设置.md) · [常见问题排查.md](常见问题排查.md) · [息屏保活与后台运行设置.md](息屏保活与后台运行设置.md)

先分清两种失败：**配对**是把手机与 Shizuku 绑定，成功一次就够；**启动**是让服务跑起来，每次重启手机后都要重做，但不用重新配对。Extendroid 依赖 Shizuku 处于运行状态（基础设置见 [Shizuku激活与授权设置.md](Shizuku激活与授权设置.md)），下面各条整理自 Shizuku 官方手册（[shizuku.rikka.app/zh-hans/guide/setup](https://shizuku.rikka.app/zh-hans/guide/setup/)），按你遇到的报错对号入座。

## 一、一直显示「正在搜索配对服务」

1. 允许 Shizuku 在后台运行；
2. 确认 Shizuku 能访问本地网络 —— 搜索配对服务需要访问本地网络，不少厂商会在应用退到后台后立刻禁止它联网（各品牌入口不同，可按机型搜索「允许应用后台联网」）。

## 二、点「输入配对码」后立刻提示失败

MIUI（小米、POCO）：系统设置 →「通知管理」→「通知显示设置」，把通知样式切换为「原生样式」。配对码要填进 Shizuku 的通知里，系统自定义的通知样式会让这一步失败。

## 三、提示 adb 权限受限

| 系统 | 开发者选项里的开关 |
| --- | --- |
| MIUI（小米、POCO） | 开启「USB 调试（安全设置）」——注意它与「USB 调试」是两个分开的选项 |
| ColorOS（OPPO、OnePlus） | 关闭「权限监控」 |
| Flyme（魅族） | 关闭「Flyme 支付保护」 |

## 四、Shizuku 随机停止

先做对所有设备通用的四件事（同样来自官方手册）：

- 保证 Shizuku 可以在后台运行；
- 不要关闭「USB 调试」和「开发者选项」；
- 开发者选项里把 USB 使用模式改成「仅充电」（Android 9 及以上是「默认 USB 配置」→「不进行数据传输」）；
- Android 11 及以上，启用「停用 adb 授权超时功能」。

特定品牌另要注意：

| 品牌 | 注意事项 |
| --- | --- |
| EMUI（华为） | 开发者选项里开启「“仅充电”模式下允许 ADB 调试选项」 |
| MIUI（小米、POCO） | 别用「手机管家」的扫描功能，它会禁用开发者选项 |
| Sony | 别点连接 USB 后弹出的对话框，那会改变 USB 使用模式 |

Shizuku 活得稳，Extendroid 的息屏保活才立得住，两者关系见 [息屏保活与后台运行设置.md](息屏保活与后台运行设置.md)。

## 五、都处理好了之后

回到 Shizuku 重试配对或启动，主界面显示「运行中」后，打开 Extendroid 确认首页设置项已完成。Extendroid 本身的其他症状再去 [常见问题排查.md](常见问题排查.md) 对一遍。
