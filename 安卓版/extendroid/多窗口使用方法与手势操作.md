Extendroid 的多窗口操作集中在两处：控制菜单（选应用、看预览）和窗口本身（移动、缩放、全屏）。全部动作只靠点按和拖拽完成，不需要进系统设置。前提是 Shizuku 已就绪（见 [Shizuku激活与授权设置.md](Shizuku激活与授权设置.md)），否则控制菜单里选了应用也不会有预览。

## 一、打开控制菜单

两个入口，效果一样：

- 下拉通知栏，点 Extendroid 的通知；
- 点屏幕上的悬浮球。

## 二、选一个应用

控制菜单里有两个标签：

| 标签 | 用途 |
| --- | --- |
| ☆ | 最近打开与常用的应用，日常从这里进最快 |
| ＋ | 全部已安装应用，找不常用的用这个 |

选好应用后进入 Preview 标签，能看到这个应用的实时画面。

## 三、Preview 标签：开窗与关闭

在预览画面上可以执行四种操作：

| 操作 | 效果 |
| --- | --- |
| 点应用预览 | 把应用以弹窗形式打开 |
| 长按应用窗口 | 切换成全屏 |
| 点 ◇ 按钮 | 直接在预览窗口里使用应用 |
| 长按 ◇ 按钮 | 关闭这个应用 |

## 四、弹窗窗口上的手势

| 手势 | 作用 |
| --- | --- |
| 拖顶部把手 | 移动窗口位置 |
| 点顶部把手 | 展开 / 收起按钮组：最小化、最大化、返回、关闭 |
| 从底部两角拖动 | 把窗口缩放成任意大小与比例 |

窗口可以同时开多个，各自独立缩放位置 —— 比如左边一窄条社交应用、右边一个视频窗口，拖到底部两角就能调出想要的比例。

## 五、最小化与悬浮球

点顶部把手里的「最小化」，窗口收起，应用回到 Preview 预览列表并留在悬浮球里，应用本身不退出。按官方说明，最小化不会打断应用里的播放 —— 边挂视频边开别的应用就这么用。息屏时也想让应用继续跑，见 [息屏保活与后台运行设置.md](息屏保活与后台运行设置.md)。
