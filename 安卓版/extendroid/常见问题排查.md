# Extendroid 常见问题排查

> 开不出窗口、预览加载失败、重启后失灵、息屏被杀 —— 本篇按「症状 → 检查 → 处理」列 Extendroid 的常见坑。
> **相关文档**：[Shizuku激活与授权设置.md](Shizuku激活与授权设置.md) · [Shizuku配对失败与启动报错处理.md](Shizuku配对失败与启动报错处理.md) · [息屏保活与后台运行设置.md](息屏保活与后台运行设置.md) · [Echo远程访问入门.md](Echo远程访问入门.md)

---

Extendroid 的故障大多能归结到三件事：Shizuku 没就绪、系统权限被收走、省电策略杀后台。下面按症状排查，多数问题两三步就能定位。

## 一、选了应用，预览一直加载不出来

1. 打开 Shizuku 应用，确认服务显示「运行中」；
2. 确认 Extendroid 在 Shizuku 的授权列表里；
3. 都正常仍不行，回到 Extendroid 首页把设置项重新过一遍。

Shizuku 是官方列出的硬性前提，排查窗口问题时先查它，详细步骤见 [Shizuku激活与授权设置.md](Shizuku激活与授权设置.md)。如果是 Shizuku 本身配对不上、启动报错或频繁停止，处理办法单列了一篇：[Shizuku配对失败与启动报错处理.md](Shizuku配对失败与启动报错处理.md)。

## 二、小米 / Redmi 设备窗口弹不出来

官方特别注明小米设备需要「弹窗（悬浮窗）」权限：

系统设置 → 应用管理 → Extendroid → 权限管理，把「显示悬浮窗 / 后台弹出界面」一类开关打开（MIUI 各版本入口名称略有差异）。

## 三、重启手机后开不出窗口

正常现象：Shizuku 服务随手机重启而停止。重新启动 Shizuku 即可恢复；Root 方式启动的可以设开机自启，避免每次手动操作。

## 四、窗口操作不熟练：全屏、关闭怎么按

| 想做的事 | 手势 |
| --- | --- |
| 全屏 | 长按应用窗口 |
| 关闭单个窗口 | 长按 ◇ 按钮 |
| 最小化 / 最大化 / 返回 | 点顶部把手展开按钮组 |
| 缩放窗口 | 从底部两角拖动 |

完整手势表见 [多窗口使用方法与手势操作.md](多窗口使用方法与手势操作.md)。

## 五、息屏后任务停了

两件事一起做：

1. 用 Preview 标签右上角三点菜单的「息屏且应用保持运行」，而不是直接按电源键；
2. 把 Extendroid 和 Shizuku 的系统电池策略放宽到「无限制 / 不优化」。

详见 [息屏保活与后台运行设置.md](息屏保活与后台运行设置.md)。

## 六、Echo 扣了 Boosters，是乱扣吗

按官方口径，每次建立连接至少扣 0.05 Boosters；纯本地 P2P 直连不追加，只有连接部分或全部经过中继服务器时才按程度追加。对不上账时以官方计费页的说明为准，见 [Echo远程访问入门.md](Echo远程访问入门.md)。

## 七、网上的版本号、体积和我手上的对不上

正常现象：网上写的是官方最新版。重装或核对包信息时，以你手上安装包的实际情况为准（网盘里这份为 1.0.5 版、约 60.64M、MD5 `92CB08E6B74916630887E5E82D384BC8`）。需要重新获取安装包：[Extendroid 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a5ac7f82b356)。
