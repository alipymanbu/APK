# 手机与电脑怎么同步笔记

> 本篇对比 Logseq 文件版（0.10.x 一代）在手机与电脑之间同步笔记的几条路：官方 Sync、Git 仓库、网盘镜像，各自要花什么、可靠到什么程度、适合什么人。数据本身长什么样先看[笔记数据存在哪里与怎么备份](笔记数据存在哪里与怎么备份.md)。

## 一、先看对比：四条路怎么选

| 方案 | 花费 | 可靠性前提 | 适合谁 |
| --- | --- | --- | --- |
| 官方 Logseq Sync | 订阅（见下文） | 按官方指引配置 | 不想折腾、手机电脑两头用 |
| Git 仓库 | 免费 | 会用 Git | 愿意为 100% 可控付出手动操作 |
| 网盘 / 文件镜像 | 免费 | 严守「同一时间只用一台」 | 只在设备间搬运、不追求自动 |
| 手动复制文件夹 | 免费 | 记得拷 | 偶尔才需要在另一台设备上接着写 |

先说一条官方文档里写明的底线：**同一时间只在一台设备上使用同一个 graph**。文件版在运行时持续写文件，两台设备同时写，任何同步方案都救不了。换设备前，让旧设备先完成上传，再打开新设备。

## 二、官方 Logseq Sync：省心但要订阅

官方自带的同步服务，截至本文口径（以官方页面为准）：

- **价格**：处于 beta 阶段，面向 Open Collective 上的赞助者开放——月捐 5 美元（Backer）或 15 美元（Sponsor）可获使用资格；
- **版本要求**：桌面与手机至少 0.9.11，网盘里这份 0.10.15 满足；
- **开启位置**：设置（Settings）→ 功能（Features）→ 打开 Sync 开关，登录账号（用你赞助时留的邮箱注册）；
- **官方自己的三条提醒**：第一次配置远程 graph 建议在桌面端做；beta 阶段不支持多人协作；仍要定期备份。

两个容易踩的点：手机端建 graph 时**不要选在 Google Drive 这类同步目录里**（官方博客明确提醒，双重同步会互相打架）；另外它同步的是 graph 数据本身，加密传输，与网盘镜像是两套机制，别混着用。

## 三、Git 仓库方案：免费、可靠、要动手

原理：把 graph 文件夹变成一个 Git 仓库，推到 GitHub 等平台的私有仓库，各设备从这里拉取推送。社区里成熟的做法是「桌面自动 + 手机手动」：

- **电脑端**：装 Git 插件（插件市场搜 git），配置成定时自动 commit + push，之后基本无感；
- **手机端**：手机版不支持插件，需要装一个 Git 客户端应用（如 MGit）。操作纪律是**两条**：打开 Logseq 之前先 pull；写完退出后 commit + push。

这套方案的额外好处是每次提交都是一版历史，误删了能找回。代价是手机端每次都要手动两步，忘了 push 换设备就会看到旧内容（不是丢了，还在没 push 的那台手机里）。动手配置前可以照着社区整理的逐步教程走一遍：[Logseq-Git-Sync-101](https://github.com/CharlesChiuGit/Logseq-Git-Sync-101)，覆盖 Windows、macOS、Linux 的自动同步配置，官方论坛文档也推荐过它。

## 四、网盘 / 文件镜像方案：能用，但要守规矩

把 graph 文件夹放进坚果云、Synology Drive 这类同步目录，各设备自动镜像。**坏消息要先讲**：社区里有用户长期实测后反馈，多台设备同时开 Logseq 时，这类文件级镜像会频繁产生冲突副本（`bak` 目录里冒出 conflict 文件）甚至丢块，结论是「实时镜像 + 多设备并发」基本不可靠。它不是某一家网盘的锅，是文件版持续写文件的特性和镜像机制天生合不来。

要用它，就守这几条纪律：

1. 同一时间只在一台设备上打开这个 graph（第一节那条底线，在这里是生死线）；
2. 换设备前手动触发一次同步、等它完成，再打开另一台；
3. 同步应用若提供「保留冲突副本」选项，选保留而不是覆盖，出了问题还能从副本里捞；
4. 在电脑端改完文件后，手机端刷新即可看到，个别情况需要重开 graph。

偶尔在手机电脑之间搬一搬、从不同时开，这套零成本方案就够用；想全自动多设备并发，请回退到官方 Sync 或 Git。

## 五、不管选哪条：先有备份

同步解决「各设备都有」，不解决「删错了能找回」——同步会把你的误删也同步过去。所以备份独立于同步存在：定期把整个 graph 文件夹复制一份到同步体系之外的地方，方法见[笔记数据存在哪里与怎么备份](笔记数据存在哪里与怎么备份.md)。切换同步方案时（比如从网盘镜像迁到官方 Sync），也先做一次全量备份再动手；中途出现内容对不上，按[常见问题与故障排查](常见问题与故障排查.md)的冲突一节处理。
