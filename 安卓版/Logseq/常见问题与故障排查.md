## 一、官网上的版本号和我装的对不上

你装的 0.10.15 属于**文件版**（0.10.x 一代），而官网下载按钮如今给的是 **2.x 数据库版**（截至本文写作时是 2.0.1 beta）。两条线并存，数据形态不同：

- 文件版：笔记是 Markdown 文件夹，可以直接看、直接备份、用别的编辑器打开；官方已宣布它进入维护模式（只修安全与兼容问题，不再加新功能）；
- 数据库版：数据存数据库，手机上的数据放在应用私有目录里，文件管理器翻不到；支持导入文件版的 graph，官方与社区都建议先在新 graph 上试用熟悉，再导入旧数据。

查自己装的是哪版：系统「应用信息」里看版本号；判断是哪条线看大版本号（0.x = 文件版，2.x = 数据库版）。官方各版本发布记录在 [GitHub 发布页](https://github.com/logseq/logseq/releases)。没想好要不要迁数据库版之前，留在文件版完全没问题——日常的记录、链接、搜索、备份它都支持，这也是本套文档通篇的口径。

## 二、手机版装不了插件

**这是现状，不是你的操作问题**：插件市场（Plugins）是桌面端的功能，手机版没有。同理，桌面端的白板（Whiteboards）在手机版上也没有。你在教程里看到「装个插件就能……」的内容，默认说的是电脑端。

手机端的替代思路：主题外观类需求进设置里找；编辑类需求多半能靠 `/` 命令菜单里自带的能力覆盖（见[手机上怎么写大纲与双链笔记](手机上怎么写大纲与双链笔记.md)）。提醒类需求同样卡在这里——手机没有插件可用，具体替代思路见[任务到点没有提醒怎么办](任务到点没有提醒怎么办.md)。

## 三、PDF 打不开或没法批注

文件版这一代，PDF 的阅读与批注能力主要在**桌面端**；手机版对 PDF 的支持长期是社区反馈的短板（打不开、或只能看不能标）。手上拿着文献想在手机上标注的话，现实的做法是：手机上只记要点和 `[[文献名]]` 链接，PDF 批注回到电脑端做，之后点开同一个页面就能对上。

另外 0.10.15 这个版本本身修复了 YouTube 视频嵌入打不开的问题——遇到嵌入内容显示异常，先把版本确认到 0.10.15 或更新。

## 四、笔记里出现 .bak / conflict 文件，内容好像丢了

这类文件几乎都是**同步冲突**的产物：两份设备各写了一份，镜像工具把其中一份改名存档。处理顺序：

1. 先停下所有设备上的 Logseq 和同步应用，别让冲突继续繁殖；
2. 找出各设备上最新的那份 graph（看文件修改时间），以它为准；
3. 从 `.bak` / conflict 副本里把缺失的段落手动抄回来，确认无缺再删副本；
4. 以后按[手机与电脑怎么同步笔记](手机与电脑怎么同步笔记.md)的纪律来：同一时间只用一台、切换前等同步完成。

如果丢的内容在 `journals/` 里以日期命名的文件中找不到，去桌面端看看该 graph 的历史版本（用 Git 方案同步的话，从提交历史找回）。

## 五、界面是英文，怎么换中文

进设置（Settings），找语言（Language）项切换为中文——应用内置中文翻译，官方讨论区的答复也确认设置里可以改。手机版设置项比桌面端少，找不到语言项时先确认自己的版本，再翻设置的各个分组。

## 六、安装报错、打开闪退

| 现象 | 先查什么 |
| --- | --- |
| 安装器提示「无法解析」或文件损坏 | 重新下载安装包，核对 MD5（方法见[下载与安装教程](下载与安装教程.md)第二节） |
| 提示系统版本过低 | 手机安卓版本低于安装包要求，升级系统或换设备 |
| 一打开就闪退 | 重启手机再试；仍闪退则清除应用数据后重开（注意：会连 graph 列表一起清，先确认笔记文件夹在应用外的存储里安然无恙） |
| graph 打不开、一直加载 | 文件夹被移动过或正被同步应用占用；移回原位、暂停同步后重开 |

闪退类问题排除后仍复现，带上「系统版本 + 应用版本」两个信息去官方讨论区搜相似案例。最后再提醒一次：动手排查前先备份整个 graph 文件夹（[笔记数据存在哪里与怎么备份](笔记数据存在哪里与怎么备份.md)），排查动作本身不该变成丢数据的动作。
