## 一、先弄清楚要装什么

WPS AI 不是手机桌面上的独立应用，它是 WPS Office 手机版里内置的 AI 能力 —— 装好 WPS Office，打开文档或在功能菜单里就能用到 AI。所以本篇要装的就是 WPS Office 手机版安装包（安卓 APK）。

这份安装包的基本信息如下，可作为安装前的核对依据：

| 项目 | 值 |
| --- | --- |
| 应用版本 | 14.41.1 |
| 包名 | `cn.wps.moffice_eng` |
| 安装包大小 | 166.77 MB |
| MD5 | `3FE3F9FB53AB4B20A9228ADAAC0A9DB2` |
| 系统要求 | Android 5.0 及以上（官方下载页标注，以官方页面为准） |

官方会持续发布新版本，如果你在应用商店或官网看到更高的版本号，属于正常情况 —— 功能入口的位置可能随版本略有差异，但进入方式是一样的。

## 二、下载安装包

安装文件从这里拿：[WPS AI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3ca78fa0f78f)。步骤：

1. 打开上面的网盘分享页，把文件**转存到自己的网盘**（转存后链接长期有效，之后随时可再取）；
2. 在夸克网盘 App（或网页版）里找到转存后的 APK 文件，**下载到手机本地存储**；
3. 下载完成后，APK 一般位于手机的 `Download`（下载）目录，文件名形如 `wpsai_v14.41.1.apk`。

## 三、安装步骤

1. 打开手机的「文件管理」，找到刚下载的 APK 文件，点按它；
2. 系统会提示「不允许安装未知来源应用」，按手机指引允许一次 —— 不同品牌的路径不同，一般在「设置 → 安全（或：应用设置）」里给「文件管理」或下载来源授权；
3. 返回继续安装，等待完成，点「打开」；
4. 首次打开按提示授予存储等必要权限，然后登录 WPS 账号。

## 四、安装时可能遇到的提示

| 提示 | 原因与处理 |
| --- | --- |
| 存在风险 / 未知来源提醒 | 安卓对商店外安装的正常提醒。文件来自你自己转存的网盘，继续安装即可 |
| 解析包出现问题 | 多半是下载不完整。重新下载一次，并核对 MD5（见下） |
| 与已安装应用冲突 / 签名不一致 | 手机上已装过其他渠道的 WPS Office。先卸载旧版再装（卸载会清除其本地数据，重要文档先移到云端或备份） |
| 存储空间不足 | 安装包约 167 MB，加上运行所需空间，清理出足够剩余空间后重试 |

MD5 核对方法：部分手机的文件管理器自带「文件校验」，没有的话用任一 MD5 校验工具读取 APK 文件，比对结果是否等于上表中的 `3FE3F9FB53AB4B20A9228ADAAC0A9DB2`（不区分大小写）。

## 五、装好之后

打开 WPS Office，登录账号（AI 能力需要登录后按账号权益使用），然后按场景找入口。装完第一步去哪里点，见[在哪里打开与怎么用.md](在哪里打开与怎么用.md)；如果安装或使用中卡住了，翻[常见问题与解决.md](常见问题与解决.md)。
