## 一、支持与不支持清单

口径来自官方 wiki 的 [Supported Audio Formats](https://github.com/OxygenCobalt/Auxio/wiki/Supported-Audio-Formats) 页（截至 2026 年 9 月，后续以该页为准）：

| 格式 | 能不能播 | 备注 |
| --- | --- | --- |
| MP3 | 能 | 标签读 ID3；部分文件拖动定位是近似值 |
| FLAC | 能 | Android 8.1 以下走内置解码兼容 |
| WAV | 能 | 标签读 ID3 |
| M4A / MP4 | 能 | 容器内是支持的编码即可，装 AAC 的最常见 |
| AAC | 能 | 独立文件或装在 M4A 里都行；拖动定位是近似值 |
| ALAC（苹果无损） | 能 | |
| OGG / Vorbis | 能 | 以容器形式读取 |
| Opus | 能 | 以容器形式读取；裸 .opus 文件在 Android 10 以下不识别，见下 |
| MKA | 能 | 容器内是支持的编码即可 |
| APE / WMA / AIFF / DSD / WAVPack / MP1 / MP2 | 不能 | 官方明确列为不支持 |

一句话结论：手机上最常见的 MP3、FLAC、WAV、M4A 全都没问题；APE、WMA 这类小众无损播不了，先在电脑上转成 FLAC 再拷进手机，别反复试。

## 二、三个容易踩坑的细节

- **裸 .opus 文件在 Android 10 以下消失**：Opus 编码本身支持，但以 .opus 单文件存在时，低版本系统不认这个扩展名。转成 M4A 或 FLAC，或把系统升到 Android 10 以上；
- **AAC 与 MP3 拖进度条是近似定位**：编码方式所致（官方注明属于播放内核的通用限制），表现为偶尔差一两秒，不是 bug，也不是设置问题；
- **M4A 里装什么编码决定能不能播**：容器只是外壳，AAC、ALAC 都行；遇到播不了的 M4A，先看里面装的什么编码。

## 三、ReplayGain 标签与格式的关系

打算用音量均衡的话，不同格式写标签的位置不一样：MP3 写在 ID3v2 扩展字段，OGG 系写 Vorbis 注释，MP4 写专用原子，OPUS 用 R128 变体。打标签的工具与开关位置见 [播放设置与音量均衡.md](播放设置与音量均衡.md)；格式不支持导致的「扫不出来」，排查思路见 [常见问题与故障排查.md](常见问题与故障排查.md)。
