## 一、装之前先确认这几件事

| 项目 | 说明 |
| --- | --- |
| 系统版本 | Android 7.0 及以上；低于 7.0 装不上（4.1.x 版的要求，后续以官方发布页为准） |
| 安装包体积 | 约 10.6 MB，网盘里这版 4.1.4 实测 10.63 MB |
| 包名 | org.oxycblt.auxio |
| 支持架构 | arm64-v8a / armeabi-v7a / x86 / x86_64，市面常见手机全部覆盖 |
| 是否免费 | 免费开源（GPL-3.0），没有付费版与内购 |

Auxio 是只读本地音乐的播放器，不带联网功能，装完也不会要求网络权限，不用担心流量与隐私问题。

## 二、从夸克网盘拿安装包

网盘里放的是 4.1.4 版（2026 年 7 月底发布），获取步骤：

1. 打开 [Auxio 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b4bfb9ea3a52)；
2. 把分享内容**转存到自己的网盘**（直接下载在部分账号上会受限，转存后最稳）；
3. 从自己网盘里把 APK 下载到手机本地存储；
4. 校验无误后按第四节安装。

如果你在意文件完整性，可以核对这版 APK 的 MD5：`d87aacd1e037c532f8ab8cbf87efb12e`（用任意文件校验工具比对即可，对不上就别装）。

## 三、官方渠道有哪些

Auxio 由开发者 OxygenCobalt 维护，官方分发渠道有三处，都可以拿到正版安装包：

| 渠道 | 地址 | 适合谁 |
| --- | --- | --- |
| F-Droid | [f-droid.org/packages/org.oxycblt.auxio](https://f-droid.org/packages/org.oxycblt.auxio/) | 已经在用 F-Droid 客户端、想自动更新的人 |
| Accrescent | [accrescent.app/app/org.oxycblt.auxio](https://accrescent.app/app/org.oxycblt.auxio) | 用 Accrescent 商店的人 |
| GitHub 发布页 | [github.com/OxygenCobalt/Auxio/releases](https://github.com/OxygenCobalt/Auxio/releases) | 想直接下 APK、跟进每个版本更新说明的人 |

这几个渠道的版本可能比网盘里这版新（写这篇时官方最新是 4.1.5）。想省事不折腾渠道，直接用第二节网盘里那版即可；想自动跟进后续更新，用 F-Droid 客户端安装更省心。

## 四、安装步骤

1. 打开下载好的 APK 文件（在手机通知栏或文件管理器里点它）；
2. 系统第一次会问「是否允许安装未知应用」——在你用的文件管理器/浏览器那一项里允许即可，装完可以再关掉；
3. 点「安装」，几秒后完成；
4. 若手机上已装过旧版 Auxio（同包名 org.oxycblt.auxio），直接覆盖安装，曲库与设置会保留。

## 五、第一次打开要授的权限

按提示逐个给就行，全部与播放音乐直接相关，没有任何联网类权限：

- **音频文件读取**（Android 11 以上是「音乐和音频」）：用来扫描并播放你手机里的音乐文件，不给的话曲库会是空的；
- **通知**（Android 13 及以上才会问）：用来显示播放控制通知，拒了之后后台播放仍可用，但通知栏看不到控制按钮。

授权完成后应用会立刻开始扫描音乐库。接下来怎么用，看 [使用入门指南.md](使用入门指南.md)；装不上、曲库空白之类的问题，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
