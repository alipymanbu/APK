## 一、先说清这件事的性质

Auxio 把「功能克制」当成生存策略。官方 wiki 有一篇专门的 [Why Are These Features Missing?](https://github.com/OxygenCobalt/Auxio/wiki/Why-Are-These-Features-Missing%3F)，逐条解释为什么这些功能不会加——不是没排上，而是有意不做。所以下面的清单短期内不会变（截至 2026 年 9 月，以官方 wiki 为准）。

## 二、明确不会有的功能与对应办法

| 功能 | 状态 | 有需求时怎么办 |
| --- | --- | --- |
| 歌词显示（含同步歌词） | 不会加，官方说明其复杂度与定位冲突 | 需要歌词显示只能换用别的播放器；歌词留在文件标签里不冲突 |
| 内置均衡器 | 不会加 | 用外部均衡器配合，见 [播放设置与音量均衡.md](播放设置与音量均衡.md) 第四节 |
| 淡入淡出（crossfade） | 不会加，官方说明受底层播放内核时间线模型限制 | 无解，只能接受 |
| 睡眠定时器 | 不会加 | 播放器内没有停止机制，睡前手动停，或依赖系统定时提醒（不一定对它生效） |
| 倍速播放 | 不会加，定位是听歌不听播客 | 有声书、播客换专门的应用 |
| 内置标签编辑器 | 不会加 | 电脑端用 [MusicBrainz Picard](https://picard.musicbrainz.org/)、[kid3](https://kid3.kde.org/)、[Beets](https://beets.io/)；手机端有 [Automatag](http://automatag.com/) |
| Last.fm 记录 / 联网元数据 | 不会加，与完全离线的定位一致 | 无 |
| 算法推荐页（「为你推荐」） | 不会加 | 直接进曲库，这本来就是它的设计 |
| 「最近添加 / 最常播放」智能列表 | 不会加 | 用「按添加日期排序」覆盖最近添加的场景 |
| 更多小部件样式 / 播放页主题 | 不会加，集中维护一套 | 无 |

## 三、怎么判断你遇到的「缺失」属于哪类

- 行为反常（曲库空、封面缺、后台被杀）→ 这是故障不是缺失，去 [常见问题与故障排查.md](常见问题与故障排查.md) 排查；
- 格式播不了 → 查支持清单，见 [支持哪些音频格式.md](支持哪些音频格式.md)；
- 想要的功能上面表格没有 → 去 GitHub 仓库搜 issue（[github.com/OxygenCobalt/Auxio/issues](https://github.com/OxygenCobalt/Auxio/issues)），带 wontadd 标签的就是官方明确拒绝的，不用等。
