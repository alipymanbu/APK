## 一、打不开 / 卡在启动页

1. **装完一直停在开屏**：先等 10 秒以上（首次启动要拉数据）；还卡就杀掉进程重开，再不行清一次应用缓存；
2. **装不上**：确认已在系统设置里允许「未知来源安装」，见 [下载与安装教程.md](下载与安装教程.md)；
3. **装上就闪退**：多半是包下坏了——用网盘里那份重下一遍，核对 MD5 `da976b7f28ed9d992cff8d2e4ec87142`；
4. **老设备装不上**：第三方页面对最低安卓版本标注不一，设备太旧时可能确实不支持。

## 二、注册 / 登录问题

- **注册后登录不了**：大概率是邮箱没激活。用浏览器登录网页版邮箱手动点激活链接（应用内点会跳转失败），全流程见 [注册登录与邮箱激活.md](注册登录与邮箱激活.md)；
- **收不到激活信**：查垃圾邮件箱、确认地址没写错、等几分钟再刷，仍收不到就换邮箱重注一个；
- **忘记密码**：走登录页的找回入口，靠邮箱重置。

## 三、AI 回复失败 / 一直转圈

按这个顺序试，通常走到第三步就好：

1. **换网络**：Wi-Fi 和移动数据各切一次——弱网是回复中断最常见的原因；
2. **重开会话**：退出当前对话再进，或重启应用；
3. **精简角色设定**：人设、世界书写得过长会让单次请求超时，把最影响性格的几条留下、其余删掉或挪进世界书；
4. **切模型/查 Key**：见 [AI模型与API密钥配置.md](AI模型与API密钥配置.md)——中转 Key 不被支持、Key 被限流都会表现为「发出去没反应」；
5. **清缓存**：系统设置 → 应用 → QuackAI → 清除缓存（不清数据，聊天记录还在）。

## 四、界面与输入问题

| 现象 | 处理 |
| --- | --- |
| 输入框偶尔无法聚焦、点不进去 | 旧版本的已知问题，1.8.x 后续版本已修；仍在复现就升级到 [下载与安装教程.md](下载与安装教程.md) 里的新版 |
| 默认字号太小、看着糊 | 早期版本的反馈；先在应用内/系统显示设置里调字号，不行就升级版本 |
| 聊天记录找不到 | 聊天列表顶部的记录入口进入；换账号登录看不到旧记录是正常的，记录挂在账号上 |
| 不小心清空了对话 | 聊天里的「清空」不可撤销；重要剧情可提前把关键段落复制出来存着 |

## 五、更新与版本

- 网盘里这份是 1.8.10（193.24M，包名 `im.quack.app`）；网上下载站标 1.9.x、1.10.x 的是**改版后的新包**，包名不同，别当同一个应用来回覆盖；
- 升级、降级、覆盖安装的注意事项统一在 [下载与安装教程.md](下载与安装教程.md)；
- 更新后设置项找不到（模型列表、入口名称变了）属正常，官方会调整菜单，以应用内实际布局为准。

## 六、还没解决怎么办

自查顺序：**网络 → 重启应用 → 清缓存 → 查 Key → 升级版本**，五步都试过仍不行，就在官方站点 [www.quack.im](https://www.quack.im/) 或文档站 [docs.quack.im](https://docs.quack.im/) 找反馈入口，描述问题时带上你的版本号（1.8.10）和机型。
