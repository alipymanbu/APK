## 一、先看结论

QuackAI 不是「不付费完全不能用」的应用：注册后每天登录就有免费额度，轻度聊天基本够。但**不同资料对它收不收费的说法互相矛盾**，两边都摆出来你自己判断（截至 2026-09 检索到的资料）：

| 来源口径 | 说法 |
| --- | --- |
| 官方文档站 FAQ（docs.quack.im） | 每天登录送免费「小鱼干」，不付费也能开聊；签到与互动继续得 |
| 1.8.10 版下载页（游戏狗） | 「全功能免费畅用、无使用次数限制」 |
| 同为 1.8.10 版下载页（七匣子） | 资费标注「游戏内充值购买」 |
| 部分版本的应用商店条目 | 「免费（软件内购买项目）」 |

同一版本一个说全免费、一个标内购，官方也没给统一说法 —— 实际以**你装的这版应用里的提示为准**：如果聊天时弹出要消耗额度/充值的提示，那就是这一版的口径。

## 二、小鱼干、钻石、星尘是什么

新版本（官方文档站现列的积分体系）里有三种货币，用途分工是：

- **小鱼干**：主力消耗品。据第三方页面描述，对话会消耗免费次数，「深入聊天」要花小鱼干；每天登录送一批，日常任务、新手任务、签到也能拿；
- **钻石、星尘**：积分体系的另外两项，具体兑换比例与用途**没有查到可靠的公开说明**，以应用内页面显示为准（本文不猜）。

**赚额度的稳定动作就三个**：每天登录、坚持签到、做日常/新手任务。想白嫖就围绕这三件事来。

## 三、什么情况要花钱

1. **额度用完**：免费小鱼干烧完后，要么等每日登录补发，要么充值（若你这版提供内购入口）；
2. **会员订阅**：有第三方页面提到订阅可解锁高级模型额度、专属角色与高峰优先 —— 属单一来源说法，价格与权益**没查到官方公布**，不作数，看到应用内的会员页再确认；
3. **自己配 API Key**：这条是确定的 —— Key 按厂商计费，与应用内购无关，成本边界见 [AI模型与API密钥配置.md](AI模型与API密钥配置.md)。

## 四、1.8.10 这版怎么判断

网盘里这份 1.8.10 的资料（游戏狗同版本页）标的是全功能免费无限制；同期七匣子页面却标内购。最直接的验证方法：装上 → 注册登录 → 找一功能聊几轮，看有没有弹额度提示 —— 有就是消耗制，没有就是免费制。装完打不开或注册卡住，先走 [常见问题与故障排查.md](常见问题与故障排查.md)。
