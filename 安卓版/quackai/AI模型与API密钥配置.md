## 一、先分清两种用法

QuackAI 里每条回复背后都是一个模型在跑，模型来源有两条：

1. **自带额度**：直接用应用提供的模型，不配 Key 也能聊（官方文档站写了每天登录送「小鱼干」、签到互动还能继续拿；这套积分还包含钻石、星尘等项，具体数值以 [docs.quack.im](https://docs.quack.im/) 页面当时显示为准）；
2. **自己的 API Key**：接入模型厂商的官方 Key，回复质量与速度看你选的模型和 Key 本身。

你现在用的 1.8.10 版界面上能选到哪些，以应用内列表为准 —— 下面两类信息**来自不同时期的资料**，都列出供对照：

| 来源 | 能选的模型 |
| --- | --- |
| 1.8.10 前后的第三方页面 | QuackAI 自有模型、Claude、Cohere、DeepSeek、Gemini、Grok |
| 官方文档站（当前） | 自营模型开箱即用，另接 GLM、Kimi、Gemini、Claude 等，支持厂商 API 与自定义 API |

模型列表官方调整很勤（有版本就精简过一批不稳的选项），**以你应用里实际看到的为准**。

## 二、Key 从哪拿、怎么填

- 官方给了获取 Key 的说明页：[docs.quack.im/getkey](https://docs.quack.im/getkey/)（按页内指引到对应厂商申请，页面打不开就从 [docs.quack.im](https://docs.quack.im/) 首页进）；
- **切换模型的入口**（有明确步骤的第三方教程）：聊天页右上角 **三个点** → 展开侧栏 → **模型** → 列表里选；同处也能自行导入 API；
- 拿到 Key 后在模型/API 设置里粘贴保存，之后聊天中就能切到对应模型；
- 一个要点：**只认厂商官方 Key，不支持中转站、代理站发的第三方 Key**（第三方页面原文口径）。填了中转 Key 出现 401/无权限，先确认 Key 来源；
- 另有页面提到每个账号配**唯一 API Token、接口兼容 OpenAI**（可接进自有应用）——两个来源互相印证，但入口位置没查到，需要的话在模型设置与官方文档里找，找不到就不必深究。

## 三、多 Key 轮询

同一模型**最多可配 10 个 API Key 轮询**。用处很实际：单个 Key 有速率限制，多放几个会轮流用，单个被限流时聊天不容易整体卡住。手里有多个账号的 Key 就都填上；只有一个就单个用，不影响功能。

## 四、额度与成本怎么控

- 不想配 Key：靠每日登录与签到拿的免费额度度日，够轻度聊天用；额度体系、什么时候要花钱的完整口径（各来源说法还有冲突）见 [免费额度与收费说明.md](免费额度与收费说明.md)；
- 配了 Key：按厂商计费，长回复、频繁切换角色会更快烧掉额度；
- 聊天里可以随时**切模型**——日常闲聊用便宜快的，写长剧情再切强的，是最直接的省钱方式；
- 觉得回复不对劲（风格突变、变慢、报错），先切一次模型再看，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、配完之后

模型只是引擎，故事还得靠人设。回到 [捏崽鸭创建角色教程.md](捏崽鸭创建角色教程.md) 把角色、开场白和世界书配齐，再用「指导」类设置约束回复方向，效果比单纯堆模型明显。
