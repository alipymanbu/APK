## 一、先弄清「添加」是怎么回事

BlackBox 是个容器：你手机上原本装好的应用它不会自动接管，需要你手动「添加」一次。添加后，黑盒里会生成一份这个应用的独立副本 —— 它有自己的数据目录，和手机上原版互不干扰，所以同一款应用可以原版、黑盒版各登一个账号。

你在黑盒里添加的应用有两个来源：手机上已经装了的（直接引用），或者手机上没装的（提供 APK 文件）。两种都走下面同一个入口。

## 二、添加第一个应用

1. 打开 BlackBox，主界面是一个应用列表，初始为空。
2. 点右下角的 **「+」按钮**，进入应用选择列表。
3. 在列表里找到你要多开的应用，点击，等它完成安装。这一步没有任何系统弹窗 —— 应用是装进黑盒内部的，不是往手机里装。
4. 装完回到主界面，点图标即可在黑盒里启动它。

**列表里找不到你要的应用？** 两个原因按顺序排查：

- 这个列表一般只列手机上已经装好的应用。手机上没装的那个，先把它的 APK 放到手机存储里，再在 BlackBox 里走从文件安装的路子。
- 应用是 32 位库的，而你的 BlackBox 是 64 位版 —— 换 32 位版 BlackBox 再试（两种架构的差别见 [下载与安装教程.md](下载与安装教程.md) 第四节）。

另据使用者反馈：在主界面空白处由左向右滑动，可以再次克隆同一个应用、生成新实例，原则上次数不限；要给同一应用开三个以上的号，先试试这条路。多开账号之前建议先过一眼 [多开与账号安全注意事项.md](多开与账号安全注意事项.md)。

## 三、左上角的 user 0 是什么

主界面左上角显示的 `user 0` 是黑盒内部的一个「用户」概念，你可以点它改名。它的实际作用是**分账户管理应用**：不同 user 下的应用实例彼此独立。

日常一两个账号的话不用管它，全部放在 user 0 里即可。引擎层面本身支持多用户（官方文档里有读取用户列表的接口），同一应用可以装进不同用户下各跑一份、数据完全隔离；界面上的用户入口以你手里版本的实际显示为准 —— 版本与版本之间这里差异不小。

## 四、长按图标建桌面快捷方式

黑盒里的应用每次都要先进 BlackBox 再点开，略麻烦。官方给的办法：**在 BlackBox 主界面长按某个应用图标，可以创建桌面快捷方式**，以后直接从手机桌面点这个快捷方式启动黑盒内的应用，省掉先进容器的步骤。

注意三点：

- 快捷方式只是入口，实际还是在黑盒环境里运行，别指望它变成独立应用。
- 据使用者反馈，桌面快捷方式依赖系统的「创建桌面快捷方式」权限 —— 建不出来时，先到系统设置里检查 BlackBox 的权限，把这项允许了再试。
- 个别第三方桌面启动器对快捷方式支持不好，建出来不显示的话，换系统自带桌面试试。

## 五、数据会怎样

- 黑盒内应用的数据存在 BlackBox 自己的数据目录里；**卸载 BlackBox = 黑盒内所有应用及其数据一起没了**，换手机也不会自动带走。
- 重要应用（如游戏账号、聊天记录）该用应用内自带的备份/绑定功能做备份，BlackBox 本身不提供整箱导出。
- 添加进黑盒的应用不会自动更新，更新 = 在黑盒内重新装一遍新版 APK。另外原版应用在手机上升不升级，和黑盒里那份无关。

## 六、添加后打不开 / 闪退

多数闪退和应用本身的架构、系统版本有关，逐条排查见 [常见问题与已知缺陷.md](常见问题与已知缺陷.md)。如果你添加应用的目的就是为了让某个模块生效，先确认框架开关已打开，步骤在 [Xposed模块使用方法.md](Xposed模块使用方法.md)；需要改定位的应用则看 [虚拟定位设置方法.md](虚拟定位设置方法.md)。
