## 一、先确认这是你要的那个 BlackBox

网上叫 BlackBox 的软件不止一个。本套文档写的是安卓上的开源虚拟引擎「黑盒 BlackBox」，用途是在一台手机里克隆、多开应用，免 Root 使用 Xposed 模块，官方源码仓库在 [https://github.com/BlackBoxing/BlackBox](https://github.com/BlackBoxing/BlackBox)。如果你要找的是别的东西（比如某个 AI 工具），这篇对你没用。

本篇对应的是 **64 位版**（安装包约 5.72M，版本 2.2.0）。BlackBox 官方把 32 位和 64 位做成了两个不同的 app，装错架构是最常见的「用不了」原因，下一节展开。

## 二、安装前的三个事实

| 项目 | 数值（以安装包实际为准） |
| --- | --- |
| 版本 | 2.2.0 |
| 安装包大小 | 约 5.72M |
| 支持系统 | 安卓 5.0 ～ 12.0，不支持安卓 4.x |
| 是否需要 Root | 不需要 |
| 安装包 MD5 | B34809331AC24F3E5BD1B759379DDC25 |

两点提醒：

- 官方在项目说明里写明「稳定性未经大量测试，仅供学习交流」，也就是说它是实验性工具，别把唯一的工作账号放进去跑关键业务。
- 安卓 13 及以上系统不在官方明确支持列表里，能不能用要看你的具体机型，装上闪退属正常现象，参考「常见问题与已知缺陷」。

## 三、获取与安装步骤

1. 从上方网盘地址转存 **Blackbox 安装文件资源** 后下载 APK（文件名类似 `Blackbox_v2.2.0.apk`，以网盘内实际显示为准）。
2. 在手机上点开这个 APK。系统会提示「未知来源应用」，允许来自你所用文件管理器（或浏览器）的安装请求即可。
3. 等安装完成，桌面出现 BlackBox 图标。

如果你是从官方 GitHub 自己编译的版本，那么包名会一致，但签名可能不同；先卸载旧版再装新版，否则会报「签名冲突」类错误。

**顺手校验一下安装包（可选但推荐）**：这份安装包的 MD5 是 `B34809331AC24F3E5BD1B759379DDC25`。Windows 上在文件所在目录执行：

```powershell
certutil -hashfile "Blackbox_v2.2.0.apk" MD5
```

（文件名以实际为准。）手机端不少文件管理器在「文件详情/属性」里也直接给出 MD5。比对时大小写无所谓，值对上就说明文件在传输中没损坏；对不上就重新转存下载一次。

另外，据使用者反馈，后续出更高版本时**覆盖安装**即可升级，不必先卸载（卸载会连黑盒内应用与数据一起清掉）；稳妥起见覆盖前先做重要数据的应用内备份。

## 四、32 位与 64 位怎么选

BlackBox 把两种架构做成了两个独立的 app：

- **64 位版**（本篇）：包名 `top.niunaijun.blackboxa64`，2020 年之后的绝大多数手机都是这一类。
- **32 位版**：少数老机型、部分低端机，或个别只有 32 位库的应用需要它。

判断方法很简单：**装 64 位版，往里面添加应用时如果在已安装列表里找不到你要的那个 app，说明那个应用需要 32 位环境，换 32 位版再试**。官方 README 也是这么建议的。两个版本数据互不相通，应用要分别添加。

## 五、装好之后

装完打开 BlackBox，界面上还没有任何应用 —— 它本身只是个「容器」，你需要把想多开的应用添加进去。具体操作见 [添加应用与多开步骤.md](添加应用与多开步骤.md)；想用 Xposed 模块的先看 [Xposed模块使用方法.md](Xposed模块使用方法.md)；装好或添加应用后遇到闪退、卡顿，直接翻 [常见问题与已知缺陷.md](常见问题与已知缺陷.md)。
