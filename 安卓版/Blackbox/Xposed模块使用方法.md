# BlackBox 内启用 Xposed 模块的方法

> 本篇讲在不 Root 的前提下，用 BlackBox（黑盒）内置的 Xposed 框架加载模块的完整流程：启用框架、导入模块、重启生效。

## 一、为什么要在黑盒里用 Xposed

传统玩法里，用 Xposed 框架必须解锁 Bootloader、刷入框架、多数情况还要 Root，一套下来有变砖风险还丢保修。BlackBox 把框架直接内置在自己的容器里：你不用动系统，模块只作用于**黑盒内**的应用，手机原系统和原版应用完全不受影响。这是它和「在系统层刷 Xposed」最本质的差别 —— 也是它的边界：只能影响装进黑盒里的那份应用。

## 二、启用框架的步骤

1. 打开 BlackBox，点**右上角三个点**进入设置。
2. 找到 **启用 Xposed 框架** 的开关，打开。
3. **重启 BlackBox**（从最近任务里划掉再打开，不是重启手机）。官方明确要求首次启用后必须重启软件，框架才会真正生效。
4. 重启后回到设置，能看到框架状态已是启用。

## 三、导入与勾选模块

1. 先把模块 APK 装进黑盒：方式和你添加普通应用一样，点主界面右下角 **「+」**，从列表选或从 APK 文件安装（流程见 [添加应用与多开步骤.md](添加应用与多开步骤.md)）。
2. 在设置里进入模块管理，把要用的模块**勾选启用**。
3. 再重启一次 BlackBox，让模块挂载生效。
4. 打开模块自己的界面做配置（每个模块的配置项各不相同，看模块的说明）。

顺序记不清时就记一句：**装模块 → 勾选 → 重启**，任何一步动了框架相关的东西，都重启一次 BlackBox 再试。

模块勾了却不生效，按这张表核对（每一条都是实际会踩的）：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 勾选后毫无反应 | 没重启容器 | 重启 BlackBox 再试 |
| 模块界面在、功能不生效 | 目标应用没装进黑盒，或模块与目标应用不在同一个环境里 | 把模块和目标应用都装进 BlackBox —— 这是同类容器的通用规则，装在手机系统上的那份互不相干 |
| 模块管理里根本没出现 | 模块 APK 装到了手机系统而不是黑盒里 | 按「+」重新装进黑盒 |
| 模块功能与系统界面相关（主题、状态栏等） | 容器改不了系统 | 这类模块在所有应用级容器里都无效，不是操作问题 |

## 四、两个常见的落差，提前知道

- **不是所有模块都能用**。模块改的系统接口若在黑盒容器外（比如全局改系统界面的模块），在黑盒里没有作用对象，装了也白装。挑模块时优先选「针对单个应用功能增强」类型的。
- **作用范围只在黑盒内**。你手机上原版装的同款应用不受任何影响；想让它生效，用黑盒里那份应用。

## 五、关于「隐藏」

官方项目说明里提到，黑盒内的 Xposed 框架经过处理，常见的检测工具（Xposed Checker、XposedDetector）测不出来。对你来说要知道的是：这是容器层面的特性，没有开关让你操作；同时官方 README 写明整个项目「仅供学习交流」，稳定性未经大量测试 —— 重要账号放进去跑模块之前自己权衡。启用框架后遇到闪退增多，先关框架对比排查，其余见 [常见问题与已知缺陷.md](常见问题与已知缺陷.md)。
