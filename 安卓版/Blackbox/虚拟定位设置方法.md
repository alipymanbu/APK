# BlackBox 虚拟定位设置方法与局限

> 本篇讲在 BlackBox（黑盒）里给应用单独设置虚拟位置的操作，以及为什么有的应用改了位置仍然不生效 —— IP 定位那一层黑盒管不了。

## 一、入口在哪

虚拟定位是 BlackBox 自带的功能，不用装任何模块：

1. 打开 BlackBox，点**右上角**进入虚拟定位功能。
2. 在地图上选一个位置（或搜索），保存。
3. 定位是**按应用分别设置**的：你可以给 A 应用设一个位置、B 应用设另一个位置，互不影响。

设置完回到黑盒里启动对应应用，它读到的 GPS 位置就是你设的那个。没生效的先确认：应用是从黑盒里启动的，不是从手机桌面点原版图标。

## 二、它改的是 GPS 这一层

官方说明里写清楚了原理边界：黑盒的做法是**禁用基站定位和 Wi-Fi 定位（WPS/LBS），只提供修改过的 GPS 位置**。也就是说：

| 定位方式 | 黑盒能否干预 |
| --- | --- |
| GPS 定位 | 能，改成你设置的位置 |
| 基站定位 | 直接禁用 |
| Wi-Fi 定位 | 直接禁用 |
| 按 IP 的网络定位 | **不能干预** |

第三行就是「改了没用」的最常见原因：网络定位是服务端根据你上网的 IP 反推的，黑盒作为手机上的客户端管不着 IP。

## 三、应用走 IP 定位时怎么办

官方给出两条思路，都是围绕「换个 IP」：

1. 禁用手机 Wi-Fi，改用移动数据上网。Wi-Fi 环境下 IP 定位很准（能到街道级），移动网络的 IP 通常只能定位到城市级，误差大很多。
2. 用 VPN 走流量改变出口 IP，让服务端按 VPN 节点的位置反推。

想验证某个应用到底在用哪层定位，可以先看自己当前 IP 被定位到哪（网上搜「IP 定位查询」类工具即可），再对比应用内显示的位置：两者一致 → 应用走的是 IP 定位，黑盒的虚拟定位对它无效；不一致且接近你设的位置 → GPS 层生效了。

## 四、顺带一提：设备伪装不是这个入口

BlackBox 还能改设备信息（机型、厂商等），但**目前是硬编码实现，没有用户界面**，普通使用者碰不到这个功能；官方自己也标注了仅小米机型测试成功、华为机型失败。别在设置里到处找「设备伪装」开关，找不到是正常的，不是你漏了。

另外，虚拟定位配合 Xposed 模块会有个别应用同时读两套位置的情况，模块相关操作见 [Xposed模块使用方法.md](Xposed模块使用方法.md)；设置完位置应用反而闪退之类的，翻 [常见问题与已知缺陷.md](常见问题与已知缺陷.md)。
