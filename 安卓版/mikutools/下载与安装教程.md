网上流传的 mikutools 安卓包版本很杂，不同渠道的包名、体积都不一样。下面这一份是本篇教程对应的安装包，装之前先对照：

手机上的文件管理器一般都能看到 APK 的版本号与大小；包名和 MD5 需要用工具查看，其中 MD5 是最省事的核对方式，方法在第三节。

## 三、核对 MD5（可选但建议做）

如果不放心安装包的来源，下载完先算一次 MD5，与第一节表格里的值比对，一致才继续装。

**在电脑上核对**：把 APK 和 `certutil` 命令放在同一目录，在 PowerShell 里执行：

```powershell
certutil -hashfile mikutools_v1.6.apk MD5
```

输出的十六进制串（忽略大小写和空格）与 `076D215E3EDBC38CD267BAAA9C00A241` 一致即为原包。

**在手机上核对**：用支持哈希计算的文件管理器（如一些主流文件管理工具自带的「文件校验」功能）对 APK 做 MD5 校验，操作路径因工具而异。

## 四、安装步骤

mikutools 不在应用商店分发，属于「未知来源应用」，安卓会默认拦一下，按下面走：

1. 点击下载好的 `mikutools_v1.6.apk`，系统会提示「不允许安装未知来源应用」；
2. 点提示里的「设置」，打开「允许此来源安装应用」的开关（各家叫法不同：小米叫「安装未知应用」，华为叫「允许安装未知应用」，vivo/OPPO 在「权限与隐私」里）；
3. 返回安装界面，点「安装」，等待十几秒；
4. 出现「已安装」后点「打开」，或回到桌面找到 mikutools 图标。

**安装被拦截的常见情况**：

- 提示「检测到风险」：部分国产系统的安全扫描会对商店外 APK 弹风险提示，点「继续安装」即可；若被强制阻止，去系统安全 App 里关闭「应用安装拦截」再试；
- 提示「解析包错误」：多半是下载不完整，删掉重下，或按第三节核对 MD5；
- 手机存储不足：31.76M 的包本身不大，但要给安装过程留出至少几百 MB 空间。

## 五、装完先做什么

1. 首次打开会看到工具列表，顶部搜索框可以直接搜功能名（比如搜「原神」定位语音合成）；
2. 个别调用摄像头或传感器的工具，首次使用会弹权限申请，按需允许即可，不允许也不影响其他工具；
3. 语音合成、AI 画图这类功能需要联网使用，本地工具（尺子、指南针、手电筒等）离线就能用；
4. 需要账号的功能按提示用邮箱注册登录，具体见[常见问题与解决办法.md](常见问题与解决办法.md)第一节；
