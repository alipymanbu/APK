## 一、先分清两个形态

- **网页版**：一个浏览器里打开就能用的在线工具集合，项目名叫 MikuTools，口号是「一个轻量的工具集合」；
- **手机版**：安卓 App，把网页版的一部分联网工具装进手机，另带一批利用手机传感器的本地工具。

网上搜「mikutools」时两类结果混在一起，很多教程其实是讲网页版的。先弄清你要的是哪种，再看下面对照表。

## 二、网页版：入口与域名

- 主入口：[https://tools.miku.ac](https://tools.miku.ac)（这是项目主页里给出的备用域名）；
- 原站地址：`https://miku.tools`（项目介绍里写明，备用域名用于主站无法访问时）。

网页版覆盖的工具门类很广，举几个有代表性的：屏幕录制、番茄时钟、亲戚关系计算器、二维码生成与解析、九宫格切图、Logo 生成、微博生成器、数字转大写中文、摩斯电码转换、进制转换、时间戳转换、JSON 编辑器、以图搜图等。站点自述无广告、无需登录、打开即用——多数纯本地计算的工具确实如此，涉及服务端的功能（如语音合成）则以页面实际提示为准。除这些纯计算类工具外，网页版还有一批 AI 功能（图像生成、音频转文字等），这类按积分消耗，口径见[积分和会员怎么算.md](积分和会员怎么算.md)。

## 三、手机版：本地工具是网页版给不了的

安卓 App 的特色在「本地工具」这一层，它调用的是手机硬件：

- 测量类：尺子测量、角度测量、高度测量、指南针；
- 实用类：全屏时钟、放大镜、手电筒、计算器；
- 计算类：日期计算、房贷计算、温度换算。

这些工具离线就能用，不需要账号。按安装包的介绍，App 不做后台唤醒和推送打扰。联网类功能（原神语音合成、AI 画图等）在 App 里同样有，用法与网页版一致。

**手机版从哪装**：安装包放在夸克网盘里，入口和安装步骤见[下载与安装教程.md](下载与安装教程.md)。

## 四、对照表：什么时候用哪个

| 你的情况 | 更合适的选择 |
| --- | --- |
| 临时用一次工具（转个进制、切个九宫格） | 网页版，开浏览器即用即走 |
| 电脑上处理任务，懒得传文件到手机 | 网页版 |
| 要用尺子、指南针、手电筒这类硬件工具 | 手机版，网页版没有传感器 |
| 想把合成语音设成手机铃声、闹钟 | 手机版，音频文件直接就在手机里 |
| 在意后台常驻和推送 | 手机版（按包介绍无后台唤醒），或干脆用网页版 |

两个形态可以并存：手机上装 App 应急，电脑浏览器收藏网页版处理杂活。

## 五、它还是个开源项目

网页版在 GitHub 上开源：[https://github.com/Ice-Hazymoon/MikuTools](https://github.com/Ice-Hazymoon/MikuTools)，MIT 许可。项目说明里提到，这是原站 `miku.tools` 的开源版本，保留了其中无需后端的功能——这解释了为什么网页版里纯计算类工具离线友好，而语音合成这类功能依赖服务端。

想自己搭一份私用的，可以按仓库 README 的说明本地部署；只是普通使用的话，直接访问第二节里的在线入口就够了。

用哪个形态遇到问题了，先去[常见问题与解决办法.md](常见问题与解决办法.md)查一遍；网页版某个具体功能怎么操作，可以看[原神语音合成怎么用.md](原神语音合成怎么用.md)，步骤两边通用。
