## 一、这个功能在哪、能干什么

音频转文字是网页版提供的工具之一（网页入口见[网页版与手机版怎么选.md](网页版与手机版怎么选.md)），把音频或视频文件转录为文本，常用于给视频配字幕、整理会议和访谈录音。App 里是否有这个入口视你装的版本界面而定，电脑上处理大文件也更方便，优先建议在网页版用。

## 二、支持的格式与大小限制

按该工具页面的说明（截至本文参考时，以实际页面为准）：

| 类型 | 支持格式 |
| --- | --- |
| 音频 | MP3、WAV、FLAC、AAC、OPUS、OGG、M4A |
| 视频 | MP4、MPEG、MOV、WebM |
| 大小限制 | 单文件最大 100MB |

超过 100MB 的文件，先用音频工具压缩或分段处理再上传。

## 三、输出格式怎么选

转录结果提供五种输出格式，选哪种取决于你接下来拿它做什么：

| 输出格式 | 适合的用途 |
| --- | --- |
| Text | 直接阅读、粘贴进文档继续编辑 |
| SRT | 最通用的字幕格式，Premiere、Final Cut、剪映和多数播放器都认 |
| VTT | 网页视频字幕，配合 HTML5 的 video 标签使用 |
| JSON | 结构化输出、带分段信息，给程序处理用 |
| 详细 JSON | 额外含时间戳与说话人信息，数据最全 |

两点容易踩的坑：**词级时间戳**只在「详细 JSON」格式下可开；**说话人识别**的完整标注也依赖「详细 JSON」。

## 四、说话人识别与提示词

- **说话人识别**：开启后工具会尝试区分不同说话人并标注。两人对话把最少、最多说话人都设为 2；多人会议把最少设为 3、最多适当放宽（如 8–10）。声音特征越明显、越少互相抢话，区分效果越好；
- **提示词字段**：它不是搜索关键词，而是告诉模型音频里可能出现的特定词汇，帮它认对词——专业术语缩写（如 `NFT, DeFi`）、人名品牌名、一句背景说明（如「这是一场关于前端开发的技术分享」）都可以填；
- **翻译为英文**：勾选后在转录的同时把内容翻成英语输出，注意这是单向翻译（其他语言转英文），不支持反向，结果发布前需要人工核校。

## 五、识别准确率怎么提高

有利因素：人声清晰、背景噪声低、语速适中、全程主要讲一种语言。不利因素：强烈口音、背景音乐压过人声、多人同时说话、音频压缩失真严重。录音前尽量选安静环境，比事后调参数管用。

## 六、积分消耗

按工具页面标注，费用按音频时长计算，与格式和文件大小无关，参考值为每 10 分钟消耗 10 积分（以你打开时的页面为准）。免费账户每月自带积分额度，轻度转录未必需要付费，口径见[积分和会员怎么算.md](积分和会员怎么算.md)。上传卡住或转录失败时，先检查文件是否超限、网络是否稳定，更多排查见[常见问题与解决办法.md](常见问题与解决办法.md)。
