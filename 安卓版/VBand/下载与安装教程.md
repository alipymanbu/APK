## 一、V Band 是什么

V Band 是深圳新蕊科技有限公司给自家智能手环、智能手表做的配套 App：手环把计步、睡眠、心率这些数据通过蓝牙交给手机，你在 App 里看曲线、开提醒、换表盘。采用新蕊方案的不少手表只能配它（产品手册里写明「只能使用 V Band 应用，不兼容其他运动 App」），包装里扫码下来的就是这个 App。

你手上如果是安卓机，装一个 APK 就能用；iPhone 在 App Store 搜 `V Band` 也有官方 iOS 版（与安卓包是两个文件）。

## 二、先确认版本信息

下面这组是可核对的事实，安装前后都可以拿来比对，防止装到改过包的文件：

| 项目 | 值 |
| --- | --- |
| 版本号 | `v1.2.1_54` |
| 包名 | `com.xincore.tech.app` |
| 安装包大小 | 129.03 MB |
| MD5 | `D58E0A6A37619E490ED2C699147B8FDB` |
| 采集时间 | 2026-09-23 |

注意两点：

- 网上商店页显示的版本会随更新变化（比如应用宝曾显示 1.2.1_34），**和上面这组不是一回事** —— 网盘里发出去的就是上表这一版，以表里的为准；
- 两个平台的版本号是两套体系：安卓沿用 `1.2.1_xx` 这种写法，iPhone 端 App Store 显示的是 2.2.10 这类三段式（截至 2026-08），**数字大小不能横比**，各自的更新记录以各自商店页为准；
- 校验 MD5 用任意带校验功能的文件管理器就行；对不上说明文件在传输中变了，重新拿一次。

## 三、获取安装包

**方式一：网盘（上表这一版）**

[V Band 安装文件资源（夸克网盘）](https://pan.quark.cn/s/63a9e6dc6d76)，打开后把整个应用文件夹转存到自己的网盘再下载，文件夹里的 APK 直接下到手机安装即可。

**方式二：官方渠道（拿最新版）**

- 安卓：新蕊官网 [xincore.com](https://xincore.com) 的 APP 下载页，或应用商店搜 `V Band`；
- iPhone：App Store 搜 `V Band`（开发者显示创升 范，实际运营方是深圳新蕊科技有限公司）。系统要求 **iOS 13.0 或更高**（截至 2026-08 的 App Store 页面，以页面当时显示为准），页面标注体积 164.2 MB，与安卓包不是同一个文件。

想用手环的全部功能，最新版和网盘这版都能配对，按你自己的习惯选。

## 四、安装步骤（安卓）

1. 把 APK 传到手机（下载到手机、数据线拷过去、或用系统自带的分享功能都行）。
2. 点击 APK 文件开始安装。系统会弹「不允许安装未知来源应用」—— 这是正常的，点「设置」，允许**当前安装来源**（浏览器或文件管理器）安装，再返回继续。
3. 装完先别急着打开，去系统设置里确认位置、通知、蓝牙三个权限已经给了（有的机型要在装完后手动开）。
4. 打开 App，按提示选语言、填个人资料（生日、身高、体重、性别 —— 这几项直接影响卡路里和睡眠的估算，别乱填）。

iPhone 没有这一步，在 App Store 直接获取即可。

## 五、首次打开要给的权限

App 的这些功能都依赖系统权限，哪一项没给，对应功能就是哑的：

| 权限 | 不给会怎样 |
| --- | --- |
| 蓝牙 | 搜不到手环，什么都连不上 |
| 位置 | 部分安卓机型搜蓝牙设备必须开（系统要求，不是要定位你）。App Store 页面还标注该 App「即使未打开时也可能会使用你的位置信息，可能会影响电池续航」—— 不想被后台定位就关掉，代价是上述机型搜不到设备 |
| 通知 | 手环收不到微信、短信、来电提醒 |
| 身体活动 / 健康 | 计步、睡眠统计不完整 |
| 通讯录、电话状态 | 来电显示只报号码不报姓名 |
| 相册 | 自定义表盘选图失败时，先回这里确认权限给没给（见 [表盘更换与固件升级方法.md](表盘更换与固件升级方法.md)） |

权限给全之后，绑定手环才不会卡在半路 —— 绑定流程见 [手环绑定与连接方法.md](手环绑定与连接方法.md)。

## 六、装完连不上手环

多数「装好了却用不了」的问题出在后台权限：安卓系统会把没自启动权限的 App 直接杀掉，手环在你不知情时就掉线了。装完建议顺手做两件事：

1. 在系统「应用启动管理」里给 V Band 打开自启动、允许后台运行；
2. 关掉系统对它的电池优化（省电模式下蓝牙会被限制，手环自然连不回）。

具体症状对应的排查见 [常见问题与解决方法.md](常见问题与解决方法.md)。
