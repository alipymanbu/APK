# V Band 消息提醒和久坐提醒怎么设置

> 讲来电、短信、微信怎么推到手环上，以及闹钟、久坐、喝水提醒怎么开。

## 一、提醒不响，先查权限再查开关

手环震动需要两条链路都通：**手机把通知交出来**（系统权限）+ **App 把它转发给手环**（App 内开关）。任何一条断了都不响，所以排查永远按这个顺序来。

绑定了手环但一条提醒都收不到的，先看下面这节；提醒本身在哪个页面开的，直接跳到第三节。

## 二、系统侧：把通知权限给全（安卓）

1. 系统设置 → 通知 → 找到 V Band → 允许通知，**并打开「允许通知使用权 / 读取通知」**—— 这一项是转发微信、QQ 这类第三方消息的前提，没开就只能收到来电短信；
2. 系统设置 → 应用 → V Band → 权限，把**通知、通讯录、电话**都设为允许（通讯录不给，来电只显示号码不显示姓名）；
3. 同一页把「自启动」「后台运行」打开，并关掉电池优化 —— App 被杀掉的那一刻，手环就是块表；
4. 省电模式、勿扰模式会拦通知，用提醒的时候别开着。

iPhone 侧对应的是：系统设置 → 通知 → V Band → 允许通知；以及 蓝牙 → 该设备 → 打开「共享系统通知」。首次绑定时系统弹的配对请求也要点「配对」，否则通知同步不上去（见 [手环绑定与连接方法.md](手环绑定与连接方法.md) 第二节）。

## 三、App 内：开具体要提醒的项目

进 V Band 的设备页，找**消息提醒 / 通知提醒**：

1. 打开总开关；
2. 在应用列表里勾选要推的 App（微信、QQ、短信等）—— 不勾的不推；
3. 来电提醒单独一项，可以顺手开来电拒接；
4. 手机或手环开了勿扰、静音时通知会被吞掉，两侧都检查一下。

设置只在**手环连着时**才会下发，改完看到手环震一下才算生效。

## 四、闹钟、久坐、喝水提醒

这几个在设备页里是独立开关，各自的设置项：

| 提醒 | 设在哪 | 怎么用 |
| --- | --- | --- |
| 闹钟 | 设备页 → 闹钟 | 设时间、选重复日；手环震动叫醒，不走手机铃声 |
| 久坐提醒 | 设备页 → 久坐提醒 | 设活跃时段与间隔，坐够时长手环就震 |
| 喝水 / 补水提醒 | 设备页 → 对应开关 | 设间隔，到点震一下 |
| 找手机 | 首页或设备页工具里 | 手环连着时点一下，手机响铃帮你找 |

全部依赖连接：手环掉线时这些提醒不会补发，所以后台保活那几项（第二节第 3 步）值得顺手做掉。

## 五、手环上的小工具

手表类型号还带几个不依赖手机的工具，在手环功能菜单里翻：闹钟、计算器、秒表、遥控拍照、蓝牙音乐控制（控制手机播放/切歌，音频本身走系统蓝牙，配对方法见 [手环绑定与连接方法.md](手环绑定与连接方法.md) 第三节）。有没有这些，看你手环的菜单，App 里设备页也会列出可用功能。

## 六、提醒相关的常见症状

- **微信不推、来电却推** → 通知使用权没开，回第二节第 1 步；
- **设置保存不了** → 手环当时没连上，等连上再改一次；
- **改完当天正常、第二天不响** → App 被系统清理了，补自启动和电池优化；
- **手环震动了但不显示内容** → 通知只开了震动没开内容显示，或手机锁屏时不允许显示详情。

更完整的症状清单在 [常见问题与解决方法.md](常见问题与解决方法.md)。
