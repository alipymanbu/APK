## 一、打开后报错或加载不出来

Wplace 的服务器在人多的时候压力很大，出现 server error、地图白屏、像素加载不出来这类问题，多数不是你这边的问题：

1. **等几分钟再刷新**——高峰期的报错通常自己就好了；
2. **换网络环境**——App 端一直转圈时，切 Wi-Fi / 流量对比一下，能定位是不是网络到服务器不稳；
3. **App 端不行就开网页版**——浏览器打开 [wplace.live](https://wplace.live/) 就是同一个平台，App 侧出问题时可以先去网页版确认是不是服务端在抖。

## 二、地图卡顿

卡顿的常见原因是一屏里塞进了太多像素（渲染压力大）：

- **放大视野**：只看一个街区，而不是整座城市；
- **关掉多余标签页**：浏览器端尤其明显；
- **降低渲染负担**：浏览器端可以试试在设置里关掉硬件加速。

手机配置一般的话，App 端同样遵循「放大再操作」的原则，流畅度会明显改善。

## 三、放不了像素

按顺序检查三件事：

| 检查点 | 判断方法 |
| --- | --- |
| 缩放层级不够 | 10 级以上才显示像素网格，点「Zoom in to see the pixels」按钮直接到位 |
| 像素点用完了 | 看池子数字是否为 0，每 30 秒回 1 点，急用水滴可买「立即回 30 点」（见 [配额与水滴获取攻略.md](配额与水滴获取攻略.md)） |
| 没登录 | 不登录只能看，登录后才能画 |

## 四、像素点不恢复 / 数字对不上

- 池子满了之后恢复的点会被直接丢掉——这不是 bug，是机制，见 [配额与水滴获取攻略.md](配额与水滴获取攻略.md) 第一节的「别浪费」；
- 恢复速度固定为每 30 秒 1 点，急用只能用水滴买「立即回 30 点」临时补。

## 五、规则红线：这些行为会封号

社区规则是多来源交叉确认过的，违反的处理都很干脆：

| 行为 | 后果 |
| --- | --- |
| 一人多号 | 封号（明确禁止开小号刷水滴） |
| 用脚本 / 自动工具代画 | 触发 IP 封禁，有用户反馈十几分钟内就会被检测到 |
| 成人内容、仇恨言论 | 删除并封禁 |
| 恶意涂毁他人作品 | 社区抵制 + 官方处罚 |

正常游玩（手动画、覆盖空地、参与协作项目）完全没有问题；灰色的「挂机脚本只是帮我点」也在禁止之列，不值得赌。需要「照着图精准铺像素」的正当需求，用 Blue Marble 这类只提供参考线、仍由你手动画的模板工具是公认的安全做法，装法和用法见 [BlueMarble模板铺图教程.md](BlueMarble模板铺图教程.md)。
