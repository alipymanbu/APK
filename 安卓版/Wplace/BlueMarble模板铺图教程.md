## 一、Blue Marble 是什么、为什么不会被封

Blue Marble 是一个免费开源的浏览器用户脚本（项目在 GitHub 的 `SwingTheVine/Wplace-BlueMarble` 仓库，代码公开可查），功能是把你的图片作为**半透明模板**盖在 Wplace 画布上，你照着描着铺像素。

它和封号红线里说的「自动脚本」是两回事：**它不替你放任何像素**，只提供参考线、坐标、逐色过滤这些视觉辅助——像素仍然要你一格一格手点。这也是它被社区广泛接受的原因。反过来，凡是宣称「自动铺完 / 挂机代画」的工具，无论包装成什么名字，都不要碰（见 [常见问题与报错处理.md](常见问题与报错处理.md) 的规则一节）。

## 二、桌面安装（Chrome / Edge）

以 Chrome 为例，Edge 步骤相同（Tampermonkey 在 Edge 商店也有）：

1. 在 Chrome 应用店安装 Tampermonkey 扩展；
2. 右键 Tampermonkey 图标 → 「管理扩展」→ 打开**开发者模式**和**允许用户脚本**两个开关（不打开这两个，用户脚本装不上）；
3. 打开 Blue Marble 的 GitHub Releases 页，下载最新的 `BlueMarble.user.js`；
4. 把下载的 js 文件拖进 Tampermonkey 的管理面板，点安装并启用；
5. 刷新 [wplace.live](https://wplace.live/)，页面上会出现 Blue Marble 的面板。

Chrome 应用店也有 Blue Marble 的扩展版，不想折腾用户脚本的可以直接装扩展。Firefox 支持情况因版本而异，以项目发布页的说明为准。

## 三、手机端安装（非官方方案）

手机浏览器默认装不了扩展，需要用**支持 Chrome 扩展的安卓浏览器**（如 Kiwi）：在 Kiwi 里按桌面端的步骤装 Tampermonkey 和 Blue Marble，再打开 wplace.live 即可。这是社区验证过的非官方方案，能用与否取决于浏览器版本，手机上体验也不如桌面顺手——铺大图还是建议用电脑。

## 四、从上传到铺完的五步

1. **先把图转成 Wplace 色板色**：用社区的「图转像素 / 转色板」工具处理一遍（搜索 wplace converter 能找到一批），让图里的每个颜色都对上 64 色板——直接丢原图会导致模板颜色和画布对不上（见 [调色板颜色与解锁顺序.md](调色板颜色与解锁顺序.md)，缺付费色的提前解锁）；
2. **上传模板**：支持 PNG / WEBP；模板里想「镂空」不铺的区域用 `#deface` 这个特殊颜色填充，它会被当作透明处理；
3. **定坐标**：把地图移到目标位置，用面板里的图钉（pin）工具点一下模板**左上角**应该落的位置，坐标会自动填进去。坐标系分两层：瓦片坐标（Tl X / Tl Y）+ 瓦片内像素坐标（Px X / Px Y），不用自己换算；
4. **生成覆盖层**：点 Create，模板就以半透明形式贴在画布上了；
5. **逐色铺完**：用颜色过滤功能只显示模板中的某一种颜色，照着铺；吸管可以直接从模板像素上取色。铺一种关一种，比全图一起对照快得多。

## 五、模板不显示 / 颜色不对

| 现象 | 原因与处理 |
| --- | --- |
| 模板部分像素不显示 | 图没有先转成 Wplace 色板色，回第 1 步重新转换 |
| 模板位置偏了 | 左上角坐标没对准，重新用 pin 工具定点 |
| 装完刷新没有面板 | Tampermonkey 的「开发者模式 / 允许用户脚本」没开，或脚本在面板里被禁用了 |
| 手机上装不上 | 浏览器不支持扩展，换 Kiwi 一类支持桌面扩展的浏览器 |

## 六、玩大图的顺序建议

- 小图（几十格）：不需要模板，看着画就行（流程见 [怎么玩入门教程.md](怎么玩入门教程.md)）；
- 中型图（几百到几千格）：转色板 + Blue Marble 逐色铺，一个人几天能铺完；
- 大型协作项目：项目组织者会统一发模板文件和**同一条坐标**，所有人把模板定到同一位置分色开工——所以别自己挪坐标，拿组织者给的数字照填。
