Desmos 的表达式列表每行都能放一种「东西」：函数、不等式、点、参数方程都行，输完立即出图。本篇把这些写法整理成对照表，照着抄一遍就能上手。

## 一、各类表达式写法对照

| 想画什么 | 输入示例 | 说明 |
| --- | --- | --- |
| 函数曲线 | `y=2x+3` | 一次函数 |
| x 关于 y 的曲线 | `x=y^2` | 抛物线开口朝右 |
| 圆（隐函数） | `x^2+y^2=1` | 不必解出 y |
| 不等式（带阴影） | `y>2x+1` | 严格不等号画虚线 |
| 限制范围 | `y=2x{0<x<3}` | 花括号套在式子尾部，只画 0<x<3 那一段 |
| 分段函数 | `y={-1<x<1:-1, 1}` | 按「条件:值」成对写 |
| 极坐标 | `r=sin(5θ)` | 含 r 与 θ 自动按极坐标处理 |
| 参数方程 | `(sin(2t), cos(3t))` | 形如点的写法，t 是参数 |
| 单个点 | `(1,0)` | 圆括号坐标 |
| 一串点 | `(1,1), (2,2), (3,3)` | 逗号隔开，一行多点 |
| 参数点（可拖动） | `(a,b)` | 拖动改变 a、b 的值 |
| 数据回归 | `y1~m*x1+b` | 波浪号替代等号，见 [数据表格与回归拟合.md](数据表格与回归拟合.md) |

## 二、定义函数与求值

1. 一行写 `f(x)=x^2-3`，定义函数；
2. 新一行写 `f(5)`，直接得到函数值；
3. 函数可以参与运算：`f(x)+g(x)`、`f(g(x))` 都能画出来。

想一次看多个输入对应的输出，把函数转成表格最直观——方法在 [数据表格与回归拟合.md](数据表格与回归拟合.md)。

## 三、分数与小数互转

- **输入分数**：用 `/` 键（专用键盘上的 ÷ 位置），分子分母上下排布；
- **小数转分数**：算出小数结果后，点结果旁的 Convert，直接变成最简分数。

## 四、花括号限制的进阶写法

- 限制可以叠在等式、不等式后面：`y=x^2{-2<x<2}`；
- 分段函数就是「多组条件:值」：`y={x<0:-x, x>=0:x^2}`；
- 较新版本支持用 `and` / `or` 组合条件（如 `{x>0 and y>0}`），以官方更新说明为准。

## 五、输入效率

- 平方、立方这类常用指数，专用键盘上有独立按键；一般指数用 `^`；
- 下标用 `_`：`x_1` 打出 x₁（回归里引用表格列名要靠它）；
- 常用词直接打：`sqrt`、`cbrt`、`nthroot`、`pi`；
- 中文输入法状态下的全角逗号、括号可能让表达式没反应，输公式时切回英文键盘。

## 六、输入了却不出图的三个常见原因

1. **视野之外**：图形存在但不在当前窗口里——缩小视图或回默认视野；
2. **全角符号**：标点输成了中文全角；
3. **未定义的变量**：表达式里有没定义的字母，先给它加滑动条（方法见 [滑动条与动画.md](滑动条与动画.md)）。
