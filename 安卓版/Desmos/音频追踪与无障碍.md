# Desmos 音频追踪与无障碍功能（安卓版）

Desmos 支持用耳朵「看」图：音频追踪（Audio Trace）会把曲线的走势播成声音，主要面向视障用户，普通人也能拿它听出函数的增减与交点。安卓应用里就能直接用。

## 一、声音线索代表什么

- **音高变化方向 = 斜率方向**：从左往右音调升高，说明函数在增；降低说明在减；
- **杂音（静态噪声）= y 值为负**：声音干净说明 y 为正；
- **爆点声 = 曲线相交**：两条曲线相遇时会「啵」一声；
- 圆这类上下两支的曲线会同时从左往右播两遍。

## 二、怎么打开

- **手机应用**：点键盘图标呼出专用键盘，在键盘里找声音（Sound）键进入音频追踪；再操作一次退出；
- **网页版**（[www.desmos.com/calculator](https://www.desmos.com/calculator)）：焦点在表达式行或图上时按 `Alt+T`（Mac 为 `Option+T`），再按一次退出。

## 三、进入音频追踪后的操作

以网页键盘命令为准（应用内用屏幕按键对应）：

| 按键 | 作用 |
| --- | --- |
| `H` | 听整条曲线 |
| 左 / 右方向键 | 移动描点位置 |
| `Tab` / `Shift+Tab` | 跳到下一个 / 上一个兴趣点（截点、交点等） |
| `V` / `Shift+V` | 音量加大 / 减小 |
| `Alt+1` ~ `Alt+0`（Mac 为 `Option+数字`） | 播放速度：1 最慢、0 最快 |
| `S`（曲线挂着滑块时） | 把滑块接到方向键上，边拖边听（滑块本身见 [滑动条与动画.md](滑动条与动画.md)） |

注意：**考试版的 Desmos 通常关闭声音功能**，音频追踪只能在标准版里用。

## 四、给低视力用户的显示设置

打开图纸的设置菜单（扳手图标），有两个常用开关（名称以你的版本界面为准）：

- **放大显示**：一个「小 A / 大 A」图标的开关，文字与曲线整体变大变粗，比单纯的缩放更清楚；
- **反转对比（Reverse Contrast）**：深底浅字，配合系统深色模式用。

投屏讲课用的「投影模式」是另一个设置，见 [图形计算器怎么用.md](图形计算器怎么用.md) 的设置一节。

## 五、读屏与盲文

- Desmos 支持主流屏幕阅读器：安卓的 TalkBack、iOS 的 VoiceOver，以及 Windows 上的 NVDA / JAWS / Narrator 等；
- 表达式按数学读法朗读：读「cosine」而不是字母 C-O-S，读「x 平方」而不是「x 上标 2」；
- 支持可刷新盲文显示器（Nemeth / UEB 盲文码），官网 [www.desmos.com/accessibility](https://www.desmos.com/accessibility) 有各平台的读屏配置教程；
- 图形还能导出成供盲文压印机打印的格式（在官方帮助中心查 Embossing Graphs 一文）。
