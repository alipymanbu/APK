# Desmos 考试模式怎么用（Test Mode）

> 本篇讲考试专用的 Desmos Test Mode：它和平时装的计算器不是同一个应用、安卓上怎么锁屏开考、考试版少了哪些功能，以及数字 SAT 里的 Desmos。

平时装的这个 Desmos 图形计算器**不是**考试当天用的那个。正式考试用的是另一款独立的 Test Mode 应用，配置跟考试方锁定的版本一致。本篇讲清两者的区别、练习方法与安卓上的锁定步骤。

## 一、平时版和考试版是两个应用

| | 平时用的（本套文档讲的应用） | 考试用的 Test Mode |
| --- | --- | --- |
| 用途 | 日常练习、做作业 | 考试当天 + 考前练习 |
| 锁定 | 无 | 屏幕固定，考试期间出不去 |
| 功能 | 全部开放 | 按考试要求裁剪（见第四节） |
| 配置 | 默认 | 可按具体考试选择 |

考试版在安卓上目前是 Beta 应用，包名 `com.desmos.secure`，与 `com.desmos.calculator` 互相独立、可以并存。想日常画图，装 [下载与安装教程.md](下载与安装教程.md) 里那个就够；想练考试环境，再去 Google Play 装 Desmos Test Mode。

## 二、用 Test Mode 练习

1. 打开 Test Mode，默认给你三类考试计算器：四功能、科学、图形；
2. 想练具体某场考试，点 **Choose Assessment（选择考试）**，按名字或地区找到你那场，它会配成与考试当天完全相同的计算器；
3. 注意：每次打开应用都要重新选一次考试，它不会记住上回的选择。

官方还有网页练习页 [www.desmos.com/practice](https://www.desmos.com/practice)，不用装应用也能练。

## 三、安卓上锁定开考：屏幕固定

官方给安卓的流程（屏幕固定模式）：

1. 关掉手机 WiFi；
2. 打开飞行模式；
3. 屏幕上出现「开始考试」按钮，点它；
4. 按系统提示把应用固定在屏幕上（别取消固定）；
5. 考完试，看应用内的时钟——它记录了屏幕处于固定状态的时间，用来向监考证明全程没离开。

## 四、考试版比标准版少了什么

各场考试的裁剪不一样，官方对每场考试都发一份 PDF 对照表（在 [www.desmos.com/testing](https://www.desmos.com/testing) 选你的考试就能查）。常见的裁剪有：

| 功能 | 标准版 | 考试版常见配置 |
| --- | --- | --- |
| 图片、文件夹、注释、链接 | 可用 | 关闭 |
| 默认角度单位 | 弧度 | 角度（度） |
| 部分三角 / 统计 / 几何函数 | 可用 | 按考试关闭 |
| 声音（音频追踪、tone） | 可用 | 关闭 |

## 五、数字 SAT 与其他大考里的 Desmos

Desmos 官方公布其计算器用于 SAT 系列与 AP、ACT 在线测评、IB 等多项考试——这些考试的考试软件里**内置**了 Desmos，不用自己装，入口在考试工具栏的计算器图标；具体形态以考试方当天的说明为准。考前建议直接在 Test Mode 里选对应考试练手，因为内置版同样是裁剪过的配置。

界面上这些计算器的操作方法与平时版一致，不熟的先过一遍 [图形计算器怎么用.md](图形计算器怎么用.md)。
