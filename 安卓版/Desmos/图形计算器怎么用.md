Desmos 图形计算器的用法可以概括成一句话：一行一个表达式，输入什么画什么。本篇带你在手机上把界面认全——表达式列表、图纸手势、图上的兴趣点、左侧圆点菜单和专用键盘，最后用五个动作画出第一张图。

## 一、界面布局：表达式列表 + 图纸

- **表达式列表**：编号的一行行输入框，每行放一个表达式、坐标点或函数定义，输完立即出图。
- **图纸区**：占屏幕大部分的坐标纸，图形画在这里。
- **添加项（加号）**：在表达式列表里添加新行、表格、文件夹；部分版本还支持图片与注释，以你的界面为准。
- **键盘图标**：呼出 Desmos 专用键盘（见第六节）。
- **设置图标**：图纸与角度设置（见第五节）。

## 二、基本手势：缩放与平移

| 动作 | 操作 |
| --- | --- |
| 放大 / 缩小 | 双指捏合，或点图纸角落的 + / − 按钮 |
| 平移 | 单指按住图纸拖动 |
| 回到默认视野 | 点缩放按钮下方的默认视图按钮 |

输入公式后图上没东西，多半是图形落在当前视野之外——先缩小看全貌，或到图纸设置里改 x、y 轴的上下界。

## 三、兴趣点：交点、截点、最值

1. 点一下某条曲线，图上出现灰色圆点——它们是与坐标轴的交点、曲线之间的交点、极大 / 极小值点。
2. 点灰色圆点显示坐标；再点一次隐藏。
3. 想把某个点的坐标拿去参与计算，选中它再选「导出到表达式列表」，坐标会写进新的一行。

注意：参数方程（如 `(sin(2t), cos(3t))`）不显示兴趣点；想读隐函数、极坐标曲线上的具体点，用表格或可拖动点更直接。

## 四、表达式左侧的圆点菜单

每行表达式左边有一个彩色圆点：

- **单击**：显示 / 隐藏这条曲线（表达式还在，只是不画出来）。
- **长按**：打开选项菜单——换颜色、改线型（实线 / 虚线 / 点线）、显示标签、把静态点改成可拖动点。

## 五、图纸与角度设置

| 设置项 | 用途 |
| --- | --- |
| 角度单位 | 弧度 / 角度切换，默认弧度（考试专用版默认角度，差别见 [考试模式怎么用.md](考试模式怎么用.md)） |
| 网格 | 方格 / 极坐标网格，坐标轴可显示或隐藏 |
| 轴范围 | 给 x、y 轴设置上下界 |
| 投影模式 | 线条加粗、数字变大，投屏讲课时后排也看得清 |
| 语言 | 界面语言切换，入口在设置菜单里（以你的版本界面为准） |

## 六、专用键盘

键盘分几页：数字与常用运算、ABC（字母）、函数（sin、cos、tan 等）。找不到的符号直接在 ABC 页把名字当词打出来：

| 输入 | 得到 |
| --- | --- |
| `sqrt` | √ |
| `cbrt` | ∛ |
| `nthroot` | n 次根 |
| `pi` | π |
| `<=` / `>=` | ≤ / ≥ |
| `/` | 分数 |
| `^` | 上标（指数） |

键盘里还有一个声音（Sound）键——用它把曲线「听」出来，是无障碍功能的一部分，用法见 [音频追踪与无障碍.md](音频追踪与无障碍.md)。

## 七、画第一张图：五个动作

1. 第一行输入 `y=2x+3`，直线出现；
2. 第二行输入 `y=x^2`，抛物线出现；
3. 点直线，看到灰点后点交点，读出坐标；
4. 长按两行的圆点，给两条曲线换成不同颜色；
5. 想留着这张图，看 [保存与分享.md](保存与分享.md)。

表达式能写的类型远不止这些——不等式、分段、极坐标都在 [函数表达式输入技巧.md](函数表达式输入技巧.md) 里；让图动起来的滑块见 [滑动条与动画.md](滑动条与动画.md)。
