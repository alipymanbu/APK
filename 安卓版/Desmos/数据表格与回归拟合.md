散点数据要描点、连线、找拟合曲线，在 Desmos 里全靠「表格」完成：建表、粘数据、一键回归，三步出结果。手机上做作业里的数据题，这一篇够用。

## 一、建表与描点

1. 在表达式列表点添加项 → **表格**，或直接在行里输入 `table`；
2. 默认两列 x₁、y₁，每输一行就在图上描一个点；
3. 点 **Zoom Fit（缩放至适合）**，视野自动框住全部数据点。

## 二、从 Excel / Google Sheets 粘贴

- 在表格软件里选中两列数据复制，回到 Desmos 点一个空表达式行直接粘贴，自动生成表格；
- 列标题不会跟着过来；数据最多粘 1 万行，超出会拆成多张表。

## 三、表格的进阶用法

| 想做什么 | 做法 |
| --- | --- |
| 连线 | 长按列头（或左侧圆点）打开选项菜单，把样式从「点」改成「线」或「点 + 线」 |
| 连成多边形 | 新一行输入 `polygon(x_1, y_1)`，按表格顶点画封闭图形 |
| 自动算一列 | 第二列的列头写函数，如 `x_1` 配 `sin(x_1)`，整列自动填充 |
| 函数求值表 | 行里已有 `f(x)=...` 这类式子时，点「编辑列表 → 创建表格」，按输入值列表 |
| 计算列 | 列头写成 `2*x_1` 这样的算式，整列变灰底计算结果，不可手改 |

## 四、一键回归

1. 数据进表格后，点表格下方的 **添加回归（Add Regression）**，默认先给线性回归；
2. 点「线性回归」几个字打开模型下拉菜单，可换二次、指数、对数等常见模型（以界面里的列表为准）；
3. 看统计量：线性模型看相关系数 r，非线性模型看决定系数 R²；
4. 点 **Plot（绘制残差）** 把残差画出来，检验拟合质量；
5. 回归参数（m、b 等）会存成变量，可在别的行引用——比如定义 `f(x)=m*x+b` 后算 `f(10)` 做预测。

想自己定模型：把等号换成波浪号 `~`，引用列名写式子，如 `y_1 ~ a*x_1^2 + c`，Desmos 会找出最符合数据的 a 和 c。波浪号在键盘的 ABC 符号页里。

## 五、回归不收敛、R² 是负数怎么办

- 非线性回归靠数值迭代，模型不合适时会找不到解——先换一个内置模板再试；
- R² 出现负数不是显示错误，官方帮助中心有专文解释（[help.desmos.com](https://help.desmos.com/hc/en-us/articles/202529139-Why-am-I-seeing-a-negative-R-2-value)）；
- 在表格选项里打开 **Drag（拖动）** 后，图上的点可以直接拖，回归线即时重算——讲课时很直观（滑块的其他玩法见 [滑动条与动画.md](滑动条与动画.md)）。
