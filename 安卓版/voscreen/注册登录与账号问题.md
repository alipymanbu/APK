## 一、注册需要什么

多方第三方收录的注册流程一致：在登录页点「注册」，填四项——邮箱、用户名、国家、密码，提交后用邮箱加密码登录即可。如果界面上没看到手机号注册入口，就是只支持邮箱注册。

几点提醒：

- 邮箱要填你能正常收信的，找回密码走邮箱；
- 用户名会出现在排行榜里，不想露真名就起个昵称；
- 国家选项影响排行分组等口径，按自己真实所在选即可。

## 二、不注册能不能用

有第三方介绍称可以不登录先试玩，但学习记录、积分、排行榜和收藏都要挂在账号上才保留。打算长期练，就先注册再开始；只想看看题目长什么样，可以直接进主界面试几题。

## 三、换设备与进度同步

学习进度、生词本、收藏以账号为准：同一账号在新手机上登录后，记录会从云端拉回来。第三方收录的 v3.5.2 更新说明里提到过「修复登录后无法同步收藏夹的问题」——你用的版本如果遇到收藏不同步，先确认两端登录的是同一个账号，再考虑更新版本。

## 四、登录常见问题

| 现象 | 处理思路 |
| --- | --- |
| 反复要求登录 | 更新说明里提到后续版本修复过「反复登录」问题；先重装一次当前版本，仍复现就关注更新 |
| 密码错误 / 忘记密码 | 走登录页的找回入口，重置邮件发到注册邮箱 |
| 收不到验证 / 重置邮件 | 翻垃圾箱；部分邮箱服务商会延迟，隔几分钟再试 |
| 登录后一直加载 | 多数是网络到视频服务器不畅，排查步骤见 [视频加载慢与卡顿排查.md](视频加载慢与卡顿排查.md) |

## 五、退出登录与切换账号

在「我的 / 个人」这类页面里找设置入口，退出后用另一个账号登录即可。切换账号后本地未同步的记录不保证保留，换号前先确认当前账号的进度已经同步。
