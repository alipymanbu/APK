## 一、安装前先确认三件事

| 项目 | 要求 / 参考值 |
| --- | --- |
| 系统版本 | 安卓 5.2 及以上（安装包信息标注） |
| 剩余空间 | 安装包约 175.16M，建议再留出等量以上的剩余空间 |
| 安装来源 | 从网盘下载 APK 安装，需要允许「安装未知来源应用」 |

这份安装包对应版本 3.5.2、包名 `com.yigou.one`，开发者标注为上海异构网络科技有限公司。应用市场或官网上可能看到更新的版本号，装哪一版由你自己决定；本篇的版本号与体积一律以这份安装包为准。

## 二、获取安装包

1. 打开 [voscreen 安装文件资源（夸克网盘）](https://pan.quark.cn/s/45adcbe4a025)；
2. 转存到自己的夸克网盘（未登录会先要求登录）；
3. 在夸克网盘 App 或网页版里对该文件选择「下载」；
4. 下载完成后得到一个 `.apk` 文件（文件名以网盘内显示为准，类似 `voscreen_v3.5.2.apk`）。

用电脑操作也一样：先转存，再在网盘网页版把文件下载到本地。

## 三、安装步骤

1. 在手机上点开下载好的 `.apk` 文件；
2. 系统提示「禁止安装未知来源应用」时，按提示允许**来自当前来源**的安装（安卓 8 及以上按「来源」授权，装完可以再关掉）；
3. 等安装完成，点「打开」。

装完如果桌面没有图标，多数是安装动作被手机上的安全软件拦截了，去安全软件的拦截记录里放行一次再装。

## 四、（可选）校验安装包

担心文件在传输中被改动的话，可以核对 MD5。Windows 电脑上在文件所在目录执行：

```powershell
certutil -hashfile "voscreen_v3.5.2.apk" MD5
```

输出的值与下面一致，就说明文件完整：

| 校验项 | 值 |
| --- | --- |
| MD5 | 75F1C51123E86B588907E71667B5B5BD |
| 体积 | 175.16M |
| 包名 | com.yigou.one |

## 五、首次启动

首次打开一般先进入登录/注册页，同时可能弹出权限申请（有渠道介绍提到存储这类权限用于缓存视频素材），按需授予即可。要不要注册、怎么注册，见 [注册登录与账号问题.md](注册登录与账号问题.md)；登录之后主界面就是刷视频答题的训练流，具体玩法见 [听力训练玩法详解.md](听力训练玩法详解.md)。
