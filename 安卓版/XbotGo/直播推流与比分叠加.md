## 一、直播和普通拍摄差在哪

前文说过，追踪和录制走的是设备到手机的局域热点，不需要外网；**直播是唯一强制需要外网的动作**——手机要把上传带宽实时交给推流。开直播前先确认三件事：

1. 手机的网络稳定。体育场地在室外时，用流量还是场馆 WiFi 要提前测一次，别等开赛才发现上行带宽不够。
2. 直播目标平台的账号已登录（YouTube、Facebook 各自要授权一次）。
3. 设备连接正常、运动类型已选好，直播画面沿用你当前的拍摄配置。

另外别忘了：手机一边接收设备回传、一边往上推流，耗电比单纯录制快得多，长时间直播给手机接个充电宝。

## 二、一键推流到 YouTube / Facebook / XbotGo Live

应用内置了三个一键目标：

| 目标 | 特点 | 适合 |
| --- | --- | --- |
| YouTube | 授权后直接开播，链接可分享给亲友 | 最常用的远程观赛方案 |
| Facebook | 授权后开播，走你自己的主页 / 群组 | 队伍社群已有 Facebook 习惯的 |
| XbotGo Live | 官方自己的直播页，无需第三方账号 | 不想折腾平台注册，只求最快开播 |

操作路径都是从拍摄界面进直播选项，选平台、授权、给比赛起个标题，然后开始推流。观众拿到链接在手机或电脑上就能看。

## 三、推到别的平台：自定义 RTMP

如果你的联赛、俱乐部有自己的直播服务器，或想用 OBS 做二级加工再分发，走 RTMP 通道：

1. 在直播选项里选自定义 / RTMP 推流。
2. 填入目标平台给的 **推流地址（RTMP URL）** 和 **推流密钥（Stream Key）**，两串都从目标平台的直播后台复制，别手抄。
3. 开始推流，再回到目标平台的后台确认收流正常。

常见的出错点都出在粘贴环节：地址末尾多了空格、密钥复制成了「观看地址」、平台后台没先点「开始直播」等收流。推流失败时先检查这三处。

## 四、ScoreSync：把比分叠进画面

ScoreSync 是直播和录制通用的比分叠加功能：你在应用里维护当前比分，画面上就会实时压一条比分栏，观众看直播、赛后回看录像都能看到分数脉络。家族观赛、联赛直播、赛后复盘对账都用得上。

用法：直播或录制过程中，在应用的直播/拍摄面板里开启 ScoreSync，随比赛进程手动加减比分即可。

## 五、直播常见失败点速查

| 现象 | 先查什么 |
| --- | --- |
| 一开播就断 | 手机上行带宽；换网络或降低推流档位 |
| 画面卡顿花屏 | 设备到手机的热点是否被其他 WiFi 干扰；离设备近一点 |
| 平台后台收不到流 | 推流地址与密钥是否填对；平台是否点了等待收流 |
| 直播没声音 | 应用的麦克风权限是否被拒（见 [下载与安装教程.md](下载与安装教程.md)） |

其他异常集中见 [常见问题与故障排查.md](常见问题与故障排查.md)。
