## 一、先核对机型再动手

XbotGo 应用本身是个「遥控 + 监看 + 剪辑」的控制器，主要服务对象是 XbotGo Chameleon（手机夹持云台）和 Falcon（一体式 4K 相机）这两类硬件。手机在硬件体系里承担三件事：跑应用、（Chameleon 模式下）贡献自己的摄像头当拍摄主机、存录像。所以机型要求比一般应用高：

| 项目 | 要求 |
| --- | --- |
| 系统版本 | 安卓 10 及以上（官方用户手册口径） |
| 处理器 | 官方推荐骁龙 888 或更新的芯片 |
| 常见适配机型 | Samsung Galaxy S21 及之后、Google Pixel 7 及之后、OnePlus 9 及之后、Xiaomi 11 及之后等 |
| 夹持尺寸（Chameleon） | 手机对角线不超过 180 mm，宽 55–90 mm，厚不超过 9.5 mm |
| 不支持 | 平板、iPad、折叠屏（如 Galaxy Z Fold 系列） |

两点提醒：

- 摄像头就是拍摄主机（Chameleon 模式），拍摄时发热和耗电都集中在手机上，中端机型长时间录制容易降频掉帧。
- 官方明确建议录之前摘掉手机壳，一是为了夹持稳妥，二是为了散热。

下面是本篇对应的那份安装包的实际信息，你拿到手后可以用 MD5 核对是不是同一份文件：

| 项目 | 值 |
| --- | --- |
| 版本号 | 4.0.1 |
| 包名 | com.blink.blinkfocos |
| 安装包体积 | 约 325.84 MB |
| MD5 | 93CF0BDA884538503221BA266A71F875 |

包名里的 `blinkfocos` 是 XbotGo 的前身品牌 Blink Focos 的痕迹，这个应用就是从 Blink Focos 更名来的，所以应用商店里的老链接、手机里的老版本可能还挂着旧名字，别当成两个应用。

版本号以你实际拿到的安装包为准：官方在 Google Play 上持续更新，更新到 4.x 阶段后功能推进较快（官方博客披露过的更新方向包括 AI 剪辑套件、高机位模式等），网上看到的最新版号和新功能几乎总会比上面这一行新，你装到的那一版不一定带这些新功能，以实际界面为准。

## 三、获取安装包并安装

获取入口：

- **XbotGo 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/d358f749a7d0](https://pan.quark.cn/s/d358f749a7d0) —— 转存到自己网盘后下载 APK 到手机。
- 也可以在 [Google Play 上的 XbotGo 页面](https://play.google.com/store/apps/details?id=com.blink.blinkfocos) 安装官方上架版本。

安装 APK 的步骤：

1. 把 APK 文件下到手机存储（或先下到电脑再传过去）。
2. 在文件管理器里点开这个 APK。系统第一次会提示「不允许安装未知来源应用」，按提示允许对应文件管理器的安装权限。
3. 等安装完成。包体积不小，手机存储空间至少留出 1 GB 余量，给应用本体和后面要存的录像都留位置。
4. 装完先别急着打开，确认手机蓝牙已开启——下一步配对就要用。

如果安装中途报「解析失败」或「安装包损坏」，先核对一遍上面的 MD5，对不上就是文件在传输中损坏了，重新下载一次即可；更多安装类问题见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、首次启动：权限与账号

第一次打开应用，会依次碰到这几类系统弹窗，建议都允许，否则配对和拍摄会卡在半路：

| 权限 | 用途 | 不给的后果 |
| --- | --- | --- |
| 蓝牙（含附近设备） | 搜索并配对 Chameleon / Falcon | 设备列表里根本刷不出设备 |
| 位置 | 安卓系统要求：蓝牙扫描需位置权限 | 同上 |
| 本地网络 / WLAN | 与设备建局域网热点连接传数据 | 能配对但画面回传、控制会失败 |
| 相机、麦克风 | Chameleon 模式用手机摄像头拍摄；直播收音 | 无法录制或直播没声音 |
| 存储的照片和视频 | 保存录像与集锦到相册 | 拍了存不下来 |

权限之后是注册账号：手机号或邮箱注册登录。登录不是摆设——固件升级入口、云端存储这些功能都挂在账号上，建议开拍前先登录好。
