## 一、先说结论：免费可以一直用，付费买的是「量」

Nomi 免费下载、免费注册，不绑卡也能长期使用（官方原话是不需要信用卡即可开始聊天）。免费与付费的差别不在「功能有没有」，而在**用量与解锁范围**：免费档有每日额度，付费订阅放宽额度并解锁部分进阶玩法。

官方 FAQ 的原话口径：**免费账号包含每日消息与图片额度**（网页、iOS、安卓通用）；**语音通话、无限消息与更深的自定义属于订阅**。网上部分第三方页面把语音也归入免费档，口径不一——以你手机上应用内实际显示为准。

付费形式有两种，都是应用内购买：

- **订阅**：按周期付费解锁更多用量，官方提供过月付与年付，1.7.0 版本起还增加了按季订阅；
- **Nomi Credits（点数）**：1.10.0 版本加入的充值型内购，用于按量兑换部分功能消耗。

具体价格与各档位包含的额度，官方会调整，本文不写死数字——**以你手机上应用内订阅页当时显示的为准**。

## 二、免费档的额度都卡在哪

免费档的每日限制分布在几个互不通用的池子里，留意别混着算：

| 功能 | 免费档表现 |
| --- | --- |
| 文字聊天 | 每天有消息条数上限，用完当天只能等次日恢复 |
| 语音消息 / 通话 | 官方 FAQ 口径属订阅功能；免费档能否试用以应用内为准 |
| 角色自拍 | 每天限量（图片额度的一部分），用完当天不再生成 |
| AI 绘画 | 有次数限制（同属图片额度） |
| 创建角色数量 | 有限，多开前先看应用内提示 |
| 群聊 | 受角色数量与消息额度双重限制 |

每日额度的恢复节奏以应用内说明为准。实测思路是：**文字聊天额度最容易被吃满**，如果你一天聊得很多，免费档大概率先在这里碰到墙。

## 三、什么人值得付费，什么人不必

**可以先不付费的情况**：

- 一天聊十几条消息就够，也不太玩语音和自拍；
- 只想养一个角色，对多开没兴趣；
- 还在观望期——先用满几天免费额度，确认自己真的会持续用。

**值得考虑订阅的情况**：

- 每天长聊，文字额度频繁见底；
- 主要玩语音通话或自拍，免费额度明显不够一天用；
- 想同时养多个角色、跑群聊剧情。

**点数适合谁**：不想背月费、只想偶尔补一点用量的轻度用户。按需充，用完再充，成本比固定订阅低；天天重度使用的话，订阅通常比反复买点数划算。

## 四、付费前花两分钟确认的三件事

1. **打开应用内的订阅页**，看当前档位、价格与你所在地区的结算货币，别按网上别人说的价格付款——价格随版本和地区变。
2. **确认自动续费周期**：订阅默认到期自动续订，想只买一个月，付款前看清续费条款，用完及时在应用商店的订阅管理里关掉。
3. **先试再买**：免费档足够你判断自己卡在哪个额度上——卡在哪，就买解锁哪一项，不用为用不到的功能升级最高档。
