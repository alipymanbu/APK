## 一、先确认你要装的是哪个版本

Clean Master 是猎豹移动（Cheetah Mobile）出品的安卓清理优化工具，国内版与国际版走两条不同的版本线，包名也不同。本文提供的安装包是**国内版**，版本事实如下：

| 项目 | 值 |
| --- | --- |
| 版本号 | 6.22.9 |
| 包名 | com.cleanmaster.mguard_cn |
| 安装包大小 | 50.62 MB |
| MD5 | DE8E35EABF5451E36EBF5B578ABF21F7 |
| 系统要求 | 安卓 5.2 以上（以安装包标注为准） |

注意两点：

1. 网上能搜到的官方最新版是国际版（版本号已推进到 9.x，以官方页面为准），和你装的这个国内版**不是同一条版本线**，界面上看到的版本号对不上是正常的。
2. 官方对国内版仍保留介绍页（[https://cn.cmcm.com/cleanmaster/](https://cn.cmcm.com/cleanmaster/)），但版本更新节奏以官方页面实际显示为准，本篇不承诺网上描述的新功能在 6.22.9 里都有。

## 二、获取安装包

安装包已经放在网盘里，转存后下载即可：

> [Clean Master 安装文件资源（夸克网盘）](https://pan.quark.cn/s/db92eb6bded1)

操作路径：打开上面的链接 → 登录夸克账号 → 点「保存到网盘」转存到自己的空间 → 在网盘里找到这个 apk 文件下载到手机。不转存直接下载某些情况下会被限制，建议先转存。

下载完成后建议核对一下文件，确认没下错、没下了一半：

- 文件大小应为 50.62 MB 左右；
- 有条件的可以用 MD5 校验工具比对，MD5 值为 `DE8E35EABF5451E36EBF5B578ABF21F7`，一致说明文件完整。

## 三、安装步骤

这个安装包来自网盘而非应用商店，安卓会把它当「外部来源应用」处理，流程如下：

1. 在手机上点开下载好的 apk 文件；
2. 系统弹出「是否允许安装」或「禁止安装未知来源应用」提示时，按手机引导去开启对应权限：
   - 部分手机（多为小米/华为/OPPO/vivo 等国产系统）会跳到「安装未知应用」设置页，找到你用来打开 apk 的那个应用（浏览器或文件管理器），打开它的「允许安装未知应用」开关；
   - 部分手机还会额外要求关闭「纯净模式」（小米）或通过安全验证，按屏幕提示操作即可；
3. 回到安装界面，点「安装」，等待完成；
4. 点「打开」直接进入应用，或回桌面点 Clean Master 图标。

## 四、首次启动要给的权限

第一次打开 Clean Master 会陆续请求几类权限，它们和功能的对应关系如下，你可以按需决定给不给：

| 权限 | 对应功能 | 不给会怎样 |
| --- | --- | --- |
| 存储（照片/文件） | 扫描垃圾文件、安装包、大文件 | 垃圾清理完全不可用，建议给 |
| 电话（设备信息） | 识别机型与系统版本做兼容判断 | 基础清理通常仍可用 |
| 悬浮窗 | 桌面加速球、游戏内悬浮加速 | 主功能可用，只是没有悬浮球，开启方法见[悬浮窗与自启动权限设置](悬浮窗与自启动权限设置.md) |
| 通知使用权 | 通知栏垃圾通知清理 | 通知清理功能不可用 |
| 应用列表 | 应用管理、卸载残留扫描 | 应用管理与残留扫描不可用 |

按界面提示逐个授权即可；跳过的权限以后想补，到系统「设置 → 应用管理 → Clean Master → 权限」里随时能开。

## 五、装不上或启动异常的排查

| 现象 | 常见原因与处理 |
| --- | --- |
| 提示「解析包错误」 | 下载不完整（重新下载并核对 MD5）或安装包与系统架构不兼容（换设备或换版本） |
| 安装按钮灰色、卡在「正在安装」 | 手机剩余空间不足，先腾出至少 200 MB 再试 |
| 提示「禁止安装未知来源应用」 | 按第三节第二步去开对应应用的安装权限，注意开的是「浏览器/文件管理器」的权限，不是 Clean Master 的 |
| 装完闪退 | 多为系统版本过旧或权限被安全软件拦截，先重启手机再试；仍闪退就卸载重装，方法见[卸载与常见问题处理](卸载与常见问题处理.md) |
| 老设备（安卓 5.x/6.x）安装慢或卡首屏 | 属于老机型正常现象，首次启动要初始化扫描引擎，等它跑完一次就好 |

装好之后，清理操作的完整流程在[怎么清理垃圾与手机加速](怎么清理垃圾与手机加速.md)里逐个讲。
