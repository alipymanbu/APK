## 一、哪些功能需要这些权限

清理类应用有几个功能依赖「随时能在后台活动」，权限没给全时表现各不相同：

| 现象 | 缺的权限 |
| --- | --- |
| 桌面没有加速球，游戏里也呼不出悬浮窗 | 悬浮窗权限 |
| 清理应用隔一会儿就被系统杀掉，再打开要重新初始化 | 自启动/后台运行权限 |
| 通知栏里它的常驻图标消失 | 通知权限被关，或被系统省电策略干掉了 |
| 通知栏清理不工作 | 「通知使用权」没开 |

下面逐个说去哪里开。所有路径以你手机的系统设置实际显示为准——国产系统菜单改版频繁，名字可能略有出入，但层级大同小异。

## 二、悬浮窗（加速球）开启

开启路径固定是两段式：先在 Clean Master 里触发，再到系统里授权：

1. 打开 Clean Master，进入「设置」或「通用」，找到「悬浮窗」/「加速球」开关，打开时它会提示「需要悬浮窗权限」；
2. 点提示直接跳转系统设置（或手动去：**设置 → 应用管理 → Clean Master → 权限 → 悬浮窗**，部分系统在「特殊权限」或「其他权限」里）；
3. 打开开关，返回应用，桌面上就能看到加速球。

加速球支持拖动位置，点一下显示可用内存并一键加速。嫌它挡视线可以在应用设置里改成「仅在游戏时显示」或直接关掉。

## 三、自启动与后台保活

国产手机系统对后台管控很激进，清理应用经常被杀。想让 Clean Master 的常驻功能稳定工作，到系统设置里做三件事：

1. **开自启动**：设置 → 应用管理 → Clean Master → 「自启动」开关打开（小米在「应用管理 → 自启动管理」，华为在「应用启动管理」，OPPO/vivo 在「权限管理 → 自启动」）；
2. **允许后台运行**：同一页面里把「后台弹出界面」「关联启动」按需打开，省电策略选「不限制」或「无限制」（华为叫「手动管理」并全开三项）；
3. **加电池白名单**：设置 → 电池（或「省电与电池」）→ 找到「应用智能省电」/「后台高耗电」，把 Clean Master 设为允许后台活动。

反过来说，如果你**不需要**它的常驻功能、只用的时候打开手动清一下，那么上面这些一个都不用开——被杀就杀掉，反而省电。这是个取舍：常驻方便但占后台，不常驻省电但每次要手动开。

## 四、常驻通知的取舍

Clean Master 会在通知栏放一条常驻通知（显示可用内存、快捷清理入口）。这条通知本身就是它的「保活」手段之一：

- 想保留快捷清理入口，就留着它；在系统设置里对它单独关通知会连带影响后台存活；
- 嫌它碍眼，可以在 Clean Master 自己的「设置 → 通知栏」里关掉常驻开关（比系统层面关闭更温和，不影响其他功能）。

设置完这些，如果发现清理之后还有各种不对劲（空间没变大、误删了东西），去[卸载与常见问题处理](卸载与常见问题处理.md)对号入座。
