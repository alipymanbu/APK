## 一、正常卸载步骤

卸载本身没有特殊之处，和其他应用一样：

1. 到系统 **设置 → 应用管理 → Clean Master**，先点「清除数据」（可选，能顺便清掉它自己产生的缓存）；
2. 回到应用信息页点「卸载」；
3. 如果卸载按钮是灰的，检查是否开了「设备管理器」权限：**设置 → 安全 → 设备管理器**（部分系统叫「设备管理应用」），取消 Clean Master 的激活后再卸载。这是它做某些深度清理时可能申请的权限，忘了关就会卸不掉。

想在重装前把旧数据清干净，卸载后用文件管理器检查这两个目录，有残留就手动删掉：

```text
Android/data/com.cleanmaster.mguard_cn/
Android/obb/com.cleanmaster.mguard_cn/
```

（目录名里的包名对应本文安装包的版本，其他版本线的包名不同，见[下载与安装教程](下载与安装教程.md)的版本对照。）

## 二、清理后空间没变大，怎么回事

点了「已释放 2 GB」，系统存储里却看不出变化，通常是这几个原因之一：

| 原因 | 判断与处理 |
| --- | --- |
| 清的是缓存，会自动回涨 | 正常现象，看几小时后的趋势而不是当下数值 |
| 算的是累计值 | 有些界面显示的是「累计已清理」，和本次释放是两回事，看清文案 |
| 删的文件在回收站里 | 若应用内提供「回收站」功能，个别清理项会先暂存再真正删除，去应用里找到回收站并彻底清空 |
| 存储统计没刷新 | 系统存储统计有延迟，重启手机后再看 |
| 清的对象在 SD 卡 | 部分机型外置存储统计与内置分开显示 |

如果每次清理扫描出来的垃圾体积大得离谱（比如永远 10 GB 以上），多半是聊天软件的图片视频缓存，去专清里按[怎么清理垃圾与手机加速](怎么清理垃圾与手机加速.md)第三节的清单核对后再删。

## 三、误删了东西还能找回来吗

分情况，越早处理希望越大：

- **照片/视频**：先看系统相册的「最近删除」（一般保留 30 天），这是最可靠的找回渠道；被微信专清删掉的聊天图片视频是例外，相册里没有，补救路径见[微信专清误删与聊天记录恢复](微信专清误删与聊天记录恢复.md)；
- **聊天图片/视频**：让对方重新发一次是最快的办法；聊天记录文字部分不受清理影响；
- **文件类**：安卓没有通用的反删除工具，没备份基本找不回来，所以预防比补救重要——清理前把不想丢的先备份，常用应用缓存提前加白名单（方法同[怎么清理垃圾与手机加速](怎么清理垃圾与手机加速.md)第六节）。

## 四、常驻通知、自动弹窗去不掉

清理类应用容易让人觉得「它自己才是噪音来源」，对应的关法：

- **通知栏常驻图标**：在应用内「设置 → 通知栏」里关，别用系统层面拉黑（会连带杀后台）；
- **通知栏垃圾提醒**：不需要通知清理功能的话，到系统设置里关闭它的「通知使用权」；
- **锁屏广告类弹窗**：到系统「设置 → 通知」里按应用逐项关闭「锁屏通知」「横幅通知」；
- **悬浮球挡操作**：应用内设置里改「仅在游戏时显示」，或直接关掉（方法见[悬浮窗与自启动权限设置](悬浮窗与自启动权限设置.md)）。

## 五、什么时候该卸载它

两种情况建议直接卸载，不必留着：

1. **新手机自带管家已够用**：近几年的国产手机系统都内置了清理与省电模块，日常缓存清理它已经覆盖。第三方清理工具的价值主要在老设备、或者你需要微信/QQ 专清、安装包管理这类更细的功能；
2. **你从不用它的常驻功能**：如果一个应用对你只剩下「偶尔手动清一次缓存」，卸掉重装也很方便，不必让它常驻后台。

想重新安装随时可以从 Clean Master 安装文件资源（夸克网盘）获取，链接在[下载与安装教程](下载与安装教程.md)的头部与正文里。
