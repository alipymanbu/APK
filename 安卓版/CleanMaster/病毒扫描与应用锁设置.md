## 一、病毒扫描

杀毒入口在主界面的「病毒扫描」（部分版本叫「安全扫描」），点一下开始扫描，会检查已安装应用、安装包和系统环境。使用中你会遇到的几个实际点：

1. **首次扫描会请求权限**：需要应用列表权限来核对安装的应用，按提示给即可；
2. **扫描结果的处理**：报出风险项后不要无脑点「立即处理」——如果它把某个你明确知道用途的应用（比如自己装的老版本工具）标记为风险，先看提示的具体路径和名称，确认再处理；
3. **误报的处理方式**：确认是误报的条目可以加入信任名单，之后不再提示；
4. **病毒库更新**：扫描前它会联网更新病毒库，手机长期离线的情况下扫描结果参考价值有限。

历史成绩可以做个参考：Clean Master 的杀毒引擎曾多次在 AV-TEST 安卓安全评测中拿到高分，这是官方及媒体广泛报道过的事实。不过对普通用户来说，它更像「顺手带一份基础防护」，别把它当成唯一的安全依赖。

## 二、应用锁：给单个应用上密码

应用锁用于给微信、相册这类应用单独加一道手势或数字密码，别人拿到你手机也打不开。设置路径：

1. 进入「应用锁」功能，首次使用会让你设置一个手势图案（或数字密码）；
2. 在应用列表里把要保护的应用开关打开；
3. 之后每次打开被锁应用，都要先画手势。

两个实用提醒：

- **解锁方式别忘了**：手势密码忘了会很麻烦，设置时留意有没有让你绑定找回方式（如安全问题），有的话务必填；
- **加锁对象选少不选多**：锁两三个真正隐私的应用即可，全锁上每天解锁几十次，最后你会自己关掉它。

## 三、应用管理与软件搬家

「应用管理」列出所有已装应用，按体积、使用频率排序，方便你找出占空间大又不常用的应用直接卸载。这部分功能受系统限制分三档：

| 你的设备状态 | 能做到什么 |
| --- | --- |
| 普通手机（未 root） | 卸载自己装的应用、清理安装包与卸载残留 |
| 部分 Android 6.0 以前的老设备 | 可把应用移到 SD 卡（「软件搬家」），给机身存储腾地方 |
| 已 root 的设备 | 才能卸载预装应用、把应用数据搬到 SD 卡 |

也就是说，网上教程里提到的「卸载预装」「软件搬家」在多数新手机上是**用不了的**——那是 root 或老系统的专属能力，官方许可协议里也写明这类操作会用到系统管理员权限、由你自行承担风险。新手机想给系统减负，现实的做法是：停用（而非卸载）预装应用——长按图标或到系统设置 → 应用管理里找「停用」按钮。

## 四、隐私痕迹清理

安全板块里通常还带一个「隐私清理」，扫的是浏览器历史、剪贴板、通话记录痕迹这类内容。用它的原则和垃圾清理一样：

- 清「浏览历史」「搜索记录」这类痕迹没有损失，随用随清；
- 清单里出现「通话记录」「短信」类目时**逐条看清楚再删**，别整类勾选，验证码短信、订单短信删了补不回来。

应用装好后的第一件事其实是把悬浮窗和后台权限配好，否则加速球和常驻功能都用不顺，具体设置在[悬浮窗与自启动权限设置](悬浮窗与自启动权限设置.md)。
