## 一、怎么转到人工客服

应用内自带的客服入口是最直接的路径，步骤如下：

1. 打开 Nico，进入右下角「我的」页面；
2. 找到并点击「联系客服」；
3. 在客服对话页点击「转人工」；
4. 排到之后把你的问题一次性说清楚（账号信息 + 发生了什么 + 你希望怎么解决），减少来回追问。

人工客服有在线时段，深夜可能排不到，问题不急的话白天再发。官方的其他联系渠道：

| 渠道 | 信息 |
| --- | --- |
| 官网 | [inicoapp.com](https://inicoapp.com/) |
| 官方邮箱 | `support@rhino-mobile.com` |
| 微信服务号 | NicoApp（ID：nicoapp） |
| 新浪微博 | @NicoApp、@Nico小狐狸 |
| 小红书 | NicoAPP |

## 二、账号被封了怎么办

协议里列明的处罚形式有四种，轻重差别很大：**警告、账号封禁、设备封禁、功能封禁**。其中设备封禁意味着处罚落在设备上——同一台手机换个账号也未必能用，被封后评估「要不要重新注册」之前先想清楚这一层。另外，被封禁过的手机号不能重新注册，换号前同样要留意。

被封后的正规申诉路径只有一条：**在 App 内向客服提交申诉**，官方审查后自行判断是否变更处罚。申诉时的注意点：

- 把注册手机号、封禁提示截图、事情经过一次性给全，减少来回追问；
- 别在短时间内刷屏式重复申诉，也别相信任何第三方的「解封服务」——要求先交钱的都是骗局；
- 是否解封、怎么解，以官方审查结果为准。

有一条被官方客服确认过的解封路径：**因未满 18 周岁被封的账号，成年之后可以在 App 内完成实名认证，认证成功即可解封**——这是官方客服在投诉平台的答复口径（2024 年案例，具体以客服当时答复为准）。所以当年因年龄被封、现在已经成年的话，实名认证是值得一试的正路。

其余常见封禁情形：

- **资料或内容违规**：发布违规内容、冒用他人身份、恶意操作被系统判定，走上面的申诉流程，把整改态度与情况说明写清楚；
- **账号被误伤**：确认自己没有违规仍被封的，同样通过申诉渠道提交，附上注册手机号与封禁提示截图。

预防大于申诉：协议里约定平台有权限制或封禁违规账号，且内容会同步到关联平台发布，发东西之前想清楚这条。

## 三、验证码收不到

按出现概率排查：

1. 检查手机短信的骚扰拦截文件夹，验证码短信常被误归类；
2. 确认手机号本身能正常收短信（欠费停机、双卡装反都会导致收不到）；
3. 等 1~2 分钟再点重发，别连续狂点（触发频控后会更收不到）；
4. 换个时间段再试，仍然不行就走人工客服。

换手机号前先在应用内完成换绑（见 [注册登录与账号设置.md](注册登录与账号设置.md) 的账号安全部分），旧号一旦停用，验证码这条路就断了。

## 四、充值与扣费问题

- **充了没到账**：先完全退出应用重新登录再看，多数是同步延迟；仍不到账就把支付订单号准备好找人工客服；
- **被自动扣款**：连续订阅到期会自动续扣，想关掉的方法在 [会员与充值说明.md](会员与充值说明.md) 第四节有逐渠道步骤；已经被扣的，以「非本人意愿续订」为由联系客服协商；
- **想退款**：官方协议口径是会员、N 币、礼物、匹配卡等充值类商品一律不退——付款前先看 [充值退款与扣费须知.md](充值退款与扣费须知.md)，里面有完整的官方口径、凭证保留方法与误购预防；
- **充值记录**：支付宝/微信的账单里能查到每一笔扣款的商户单号，申诉时直接引用。

## 五、安装与使用异常

- **装不上、解析包错误**：多数是安装包下载不完整，重新下载再装，完整排查见 [下载与安装教程.md](下载与安装教程.md)；
- **闪退、打不开**：先清一下应用缓存，仍不行就卸载重装；重装不影响账号本身，聊天记录以服务器端为准；
- **匹配类功能不可用**：检查系统设置里 Nico 的位置权限是否被关了，这类功能依赖位置授权；
- **人格测试测到一半退出**：重新进入「我的人格」页面接着测即可，已答的题目一般会保留，以应用内实际显示为准。

遇到本篇没覆盖的问题，直接走第一节的人工客服，比在社区里问更快。
