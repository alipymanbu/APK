## 一、安装前先看清这份包的信息

几点说明：

- 版本号是本文写作时核对到的这份安装包的版本。Nico 官方更新比较频繁，等你看到这篇时官方可能已经出了更新的版本，具体以官方渠道当时显示为准。

## 二、把安装包拿到手机上

安装包从上面头部那处「Nico 安装文件资源（夸克网盘）」获取：打开链接 → 转存到自己的网盘 → 在手机上装夸克 App（或直接用手机浏览器打开网盘页面）→ 找到 `nico_v8.36.0.apk` 下载到本机。

下载完成后手机通知栏会出现安装提示，也可以在「文件管理 → 下载」目录里找到这个 apk 文件。

## 三、安装步骤与未知来源授权

安卓默认不允许安装应用商店之外的安装包，第一次装需要手动放行一次：

1. 点击下载好的 apk，系统会弹出「禁止安装未知来源应用」的提示；
2. 点「设置」或「仍要安装」，跳转到对应权限页；
3. 允许「来自此来源的应用」（不同品牌叫法略有差异，小米叫「安装未知应用」，华为叫「外部来源应用下载」）；
4. 返回安装界面，点「安装」，等进度条走完；
5. 点「打开」直接进入，或回到桌面点 Nico 图标。

几个可能卡住的点：

- **装到一半提示「解析包错误」**：多半是下载没下完整，回到网盘重新下载一次，装之前可以核对文件大小是否约 116 MB。
- **提示「与应用不兼容」**：说明你的安卓系统版本低于应用要求，具体系统要求以官方应用商店页面标注为准。
- **空间不足**：安装包约 116 MB，装完还会产生聊天记录、图片缓存等额外占用，建议手机至少再留 1 GB 空闲。

## 四、想核对安装包有没有被动过

如果你在意安装包的完整性，可以在电脑或手机上用 MD5 校验工具算一遍文件指纹，与第一节表格里的 MD5 值比对，完全一致说明文件没有变化。手机端可以在「文件管理」里长按文件查看属性，部分机型自带校验功能；电脑端可以在 PowerShell 里执行：

```powershell
Get-FileHash "nico_v8.36.0.apk" -Algorithm MD5
```

输出的 Hash 与表格里的值一致即可。

## 五、装好之后的第一步

打开 Nico 后会先要求同意用户协议，然后就是注册登录。注册必须用手机号，而且要授权地理位置（这是一款基于位置的社交应用，不给位置基本没法用），流程和注意事项见 [注册登录与账号设置.md](注册登录与账号设置.md)。装完打不开、闪退之类的问题，先去 [常见问题与客服.md](常见问题与客服.md) 对照排查。
