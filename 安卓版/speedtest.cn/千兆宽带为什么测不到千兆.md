# 千兆宽带为什么测不到千兆

> 办了千兆宽带，手机上测出来只有几百兆？这一篇按「光猫 → 网线 → 路由器 → 手机」逐段找短板，并给出最能服众的测速方法。

## 一、先定一个合理预期

千兆宽带签约的是 1000Mbps，折算成下载软件里的速度上限约 125MB/s。但要把这段话记住：**即使你家所有设备都达标，有线直连测出的结果通常也在 850~940Mbps 之间波动**，走 Wi-Fi 还要再打折扣（一般是有线水平的七至九成）。所以手机上测出「800 多」不代表没跑满，这就是这类测速的常规水平。此区间是多个公开资料的常见口径，具体以你自己的线路实测为准。

## 二、逐段检查家里的「短板」

家庭网络从光纤入户到手机，是一条链，任何一段只有百兆能力，整条链就只有百兆：

| 环节 | 达不到千兆的典型原因 | 怎么确认、怎么解决 |
| --- | --- | --- |
| 光猫 | 老光猫的网口只有百兆 | 看网口旁的标注；办了千兆套餐可主动找运营商更换千兆光猫，通常免费 |
| 网线 | 五类线被多数资料划在百兆档；水晶头接触老化 | 看线皮印字：`CAT5E`（超五类）及以上才稳妥；也有运营商资料称五类线短距离可跑更高——口径有出入，拿不准就换超五类，成本很低 |
| 路由器 | 网口是百兆口、Wi-Fi 标准老旧 | 登录路由器管理后台看 WAN/LAN 口协商速率；千兆宽带配千兆网口、支持 5GHz 的路由器 |
| 手机 / 电脑 | 老设备的网卡只有百兆 | 电脑在设备管理器里看网卡，出现 `Gigabit`、`GBE`、`10/100/1000M` 字样才是千兆网卡；百兆网卡的上限就是约 12.5MB/s |
| Wi-Fi 链路 | 2.4GHz 频段慢、隔墙衰减、邻居信道拥挤 | 近距离优先连 5GHz 频段；路由器放在家里开阔居中的位置，别塞进弱电箱 |

## 三、怎么定位瓶颈在哪一段

1. 用超五类以上的网线把电脑**直连光猫的千兆网口**，关掉电脑 Wi-Fi 和一切占带宽的程序，用浏览器打开 `https://www.speedtest.cn` 测一轮；
2. 直连能到 850M 上下 → 线路本身没问题，瓶颈在你家内网（路由器、网线、Wi-Fi），回到第二节逐段换；
3. 直连也明显低 → 带着这个结果去找运营商。有线直连测速是《宽带速率测试方法》系列行业标准认可的评判方式，也是沟通中最有说服力的证据。

## 四、和运营商沟通不通怎么办

- 准备好证据链：**不同时段的多轮测速截图**（看清时间、数值）、有线直连的结果、与客服的沟通记录；
- 要求运营商派技术人员上门检测，并出具检测报告；
- 仍无果，可向**工信部电信用户申诉受理中心**（电话/网站/小程序均为 12300）申诉，附上上述证据——这是处理宽带速率争议的正规渠道，具体受理方式以 12300 官方页面为准。

设备各环节都达标之后，Wi-Fi 环境下测出的数字该怎么读，见 [测速结果怎么看.md](测速结果怎么看.md)；一般性的偏低排查顺序见 [测速结果偏低怎么办.md](测速结果偏低怎么办.md)。
