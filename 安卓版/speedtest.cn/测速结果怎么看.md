## 一、五个数字各管一件事

| 指标 | 单位 | 它在量什么 | 你什么时候要看它 |
| --- | --- | --- | --- |
| 下载 | Mbps | 数据从网上进到手机的速度 | 刷视频、下文件、开网页快不快 |
| 上传 | Mbps | 数据从手机发出去的速度 | 发大文件、视频通话、直播 |
| Ping | ms | 一来一回的反应时间，越低越跟手 | 网游、实时对话 |
| 抖动 | ms | Ping 值稳不稳（波动大小） | 通话会不会一卡一卡 |
| 丢包 | % | 发出去的数据有多少没到 | 网络质量差的总信号 |

大多数人的疑问都集中在下载速度上；另外四项在「网页能开但通话总卡」这类疑难场景里才真正派上用场。

上传远小于下载也不用奇怪：家庭宽带普遍对上行做了限速——按运营商公开的口径，家宽的下载速率按套餐配置，上传限速一般只有 20~300Mbps。这是套餐设计如此，不是你家网络出了毛病。

## 二、Mbps 和 MB/s：为什么数字对不上

测速结果用 **Mbps**（兆比特/秒），而手机下载工具、应用商店显示的是 **MB/s**（兆字节/秒）。1 字节 = 8 比特，换算就是除以 8：

| 测速结果 | 对应下载软件里的速度 |
| --- | --- |
| 100 Mbps | 约 12.5 MB/s |
| 300 Mbps | 约 37.5 MB/s |
| 500 Mbps | 约 62.5 MB/s |
| 1000 Mbps（千兆） | 约 125 MB/s |

所以测速 300 Mbps、应用商店却只显示 30 多 MB/s，不是哪个环节骗了你，单位不同而已。

## 三、Ping 为什么测了三次

测速过程中，Ping 会分三个阶段各测一次：

- **空闲**：网络没干活时的基础反应时间，代表「裸网络」的水平；
- **下载中**：一边满速下载一边测，看下载会不会拖慢响应——家里有人在下游戏时你打游戏变卡，就体现在这个数上；
- **上传中**：同理，看上传任务（比如手机自动往云端备份照片）会不会拖慢响应。

三个数都低，说明网络在满负荷时依然跟手；只有空闲时好看、下载/上传中飙升，说明网络一跑大流量就卡。

## 四、多少算够用

下面是大致参考，视频平台码率各不相同，以实际体验为准：

| 场景 | 大致需求 |
| --- | --- |
| 聊天、网页浏览 | 1~2 Mbps 就够 |
| 高清（1080p）视频 | 5 Mbps 以上 |
| 4K 视频 | 25 Mbps 以上 |
| 视频通话 | 上传 1.5 Mbps 以上，且更看重抖动小 |
| 网络游戏 | 带宽要求不高，但 Ping 和抖动要小 |

玩网游的人常把 Ping 50ms 当及格线，越低越跟手；100ms 以上在动作类游戏里就能感觉到迟滞了。

## 五、数字不好看怎么办

先别急着找运营商。服务器远近、Wi-Fi 信号、后台占用都会压低结果，按 [测速结果偏低怎么办.md](测速结果偏低怎么办.md) 的顺序过一遍再说；换一个测速点做对比也有必要，步骤见 [测速服务器怎么切换.md](测速服务器怎么切换.md)。
