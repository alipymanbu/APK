## 一、先分清两个程序

ExtensoDesk 由成都万有码力科技有限公司开发，不是单端应用，你要装两份：

| 程序 | 装在哪 | 作用 |
|---|---|---|
| Windows 服务端 | 电脑（Windows） | 把电脑上的画面传给平板显示 |
| 安卓客户端 | 平板 / 手机（Android） | 接收画面，把平板变成电脑的副屏 |

两端都装好之后再建立连接，连接步骤见 [WiFi与USB连接方法.md](WiFi与USB连接方法.md)。

## 二、安装前核对系统要求

| 组件 | Windows 服务端 | 安卓客户端 |
|---|---|---|
| 操作系统 | Windows 10 2004 及以上 | Android 5.0 及以上 |
| 显卡 | 显卡驱动 27.x.x.x 及以上 | 无要求 |

以上以官网文档页当时显示的要求为准：[www.extensodesk.cn 文档页](https://www.extensodesk.cn/pages/zh-cn/documentation.html)。显卡驱动过旧是连不上、画面异常的常见原因，装之前建议先把电脑的显卡驱动升到最新。

## 三、电脑端：Windows 服务端安装

1. 从官网下载页获取安装包：[www.extensodesk.cn 下载页](https://www.extensodesk.cn/pages/zh-cn/download.html)。官方说明 Windows 版暂未上架 Microsoft Store，别在商店里找；开发者另在 [SourceForge 项目页](https://sourceforge.net/projects/extensodesk/)维护发布，需要时也可以从那里获取。
2. 安装包约 33 MB（以官网当时显示为准）。官网同时提供 SHA256 校验码，下载后可在 CMD 里核对：

   ```
   certutil -hashfile 下载的安装包文件名.exe SHA256
   ```

3. **以管理员身份运行安装程序**，按向导完成安装。
4. 安装或首次运行时，**允许程序通过系统防火墙**——拦掉的话平板端会搜不到电脑。

补充一个容易混淆的点：微软商店的中国区存在一个"由腾讯应用宝提供"的 ExtensoDesk 页面，这与官方文档"暂未上架 Microsoft Store"的说法并存——商店页走应用宝渠道、仅限中国区可见。两边口径官方没有进一步说明，需要 Windows 服务端时优先走官网直链，商店页的版本新旧以页面当时显示为准。

## 四、平板端：安卓客户端的两种安装来源

### 来源一：应用商店

官方推荐从应用商店安装，可以获得自动更新。官网下载页列出过 Google Play、三星、小米、华为等商店，腾讯应用宝也有收录（以官网下载页当时列出的为准）。方法：打开商店，搜索 ExtensoDesk，安装即可。

### 来源二：APK 安装包直装

平板上没有这些商店，或想安装与本文配套的这一份时，可以用 APK 直装。

**ExtensoDesk 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/cd4860dc8c5d](https://pan.quark.cn/s/cd4860dc8c5d)

这份 APK 的实际信息：

| 项目 | 值 |
|---|---|
| 版本 | 1.3.5（安卓客户端） |
| 包名 | `com.ultramali.extensodesk` |
| 大小 | 27.12 MB |
| MD5 | `F235C1B821B9A2F054CE5ED6ACA7DCF1` |

下载后在 CMD 里核对 MD5（文件名以你实际下载到的为准）：

```
certutil -hashfile ExtensoDesk_v1.3.5.apk MD5
```

APK 直装步骤：把 APK 传到平板 → 点击安装 → 系统提示"未知来源"时允许该来源安装 → 完成后在桌面出现 ExtensoDesk。不同品牌平板的这个开关位置不同，有的叫"安装未知应用"，在系统设置的权限或安全分类下。

## 五、网盘这份 1.3.5 与官方最新版的差异

截至 2026-09，官方最新版本为 Windows 服务端 1.3.5、安卓客户端 1.4.3（以[官网下载页](https://www.extensodesk.cn/pages/zh-cn/download.html)当时显示为准）。网盘里这份是 1.3.5 的安卓客户端，比最新版旧，下面这些功能它没有：

| 功能 | 需要的版本 |
|---|---|
| 扫码连接 | 安卓客户端 1.3.9 及以上 |
| 在客户端里切换扩展 / 镜像模式 | 客户端 1.4.2 及以上，且服务端 1.3.5 及以上 |
| 在客户端里自主调节横竖屏 | 客户端 1.4.2 及以上，且服务端 1.3.5 及以上 |

也就是说：1.3.5 客户端里找不到"扫码连接"入口，模式切换要去电脑端服务端里调。需要这些功能就去应用商店装最新版；只想尽快把副屏用起来，1.3.5 配官网当前的 1.3.5 服务端即可正常连接使用。

## 六、装完之后

两端都装好后，回到 [WiFi与USB连接方法.md](WiFi与USB连接方法.md) 建立第一次连接；连不上或报错时查 [常见问题与报错排查.md](常见问题与报错排查.md)。
