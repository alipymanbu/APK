## 一、错误码对照

| 报错 | 原因 | 下一步 |
|---|---|---|
| `-1` | USB 驱动未正常加载（部分平板机型不加载驱动） | 换 USB 口和数据线；升级两端版本（服务端 1.2.3 起修过一批机型）；客户端 1.2.0+ 按内置的 USB 自排查提示逐项处理 |
| `-2` | 同属 USB 驱动类问题 | 同上；服务端 1.2.0 起专门减少过 -1、-2 的出现 |
| `11` | 连接过程出错（客户端 1.3.0 修复过触发条件） | 升级客户端后，**重启电脑端软件**再连 |
| `503` | 服务端早期版本的连接报错 | 服务端 1.0.9 已修复，把两端都升到当前版本即可 |
| 注册表错误 | 服务端写入显示配置失败 | 服务端 1.2.7 已修复，升级服务端 |

## 二、连接类问题

**平板搜不到电脑端服务端**：确认两端在同一网络；关掉路由器的 AP 隔离；在客户端手动输入服务端显示的 IP。防火墙拦截是最常见原因——安装服务端时允许过防火墙，就少这一步。

**提示 Device not paired（设备未配对）**：偶发于旧版本（客户端 1.2.0 修复过），在两端重新输入配对用户名和密码即可。

**频繁要求重新输入用户名密码**：旧版本的已知问题（客户端 1.3.3 修复过一轮）；1.3.5 及以上仍出现，就重启两端程序再配对。

**想拔线自动转 WiFi**：客户端 1.3.2 起有"USB 断开时自动连接 WiFi"选项，开启后拔线不用手动重连。

## 三、画面类问题

**扩展屏变成克隆屏**：偶发于旧版服务端（1.2.3 修复过）；遇到时到 Windows 显示设置里把"复制这些显示器"改回"扩展这些显示器"。

**平板显示不满屏**：用客户端 1.2.5 起的缩放选项实现全屏，见 [画质与显示设置.md](画质与显示设置.md) 第一节。

**HDR 开了颜色不对**：部分机型不支持，直接关闭，见 [画质与显示设置.md](画质与显示设置.md) 第三节。

## 四、卡顿排查（按顺序做）

1. 打开客户端的**连接质量分析**（1.1.6 起），先定位瓶颈在网络还是解码；
2. 网络问题：换 5GHz WiFi，或直接换 USB 有线；
3. 解码问题：客户端 1.2.1 起更换解码器选项，换一个试试；
4. 服务端开**极限性能**模式（1.3.1 起）；
5. 双显卡电脑在服务端选高性能 GPU 渲染（1.1.1 起）；
6. 把显卡驱动升级到最新（官方文档反复强调，部分异常就是旧驱动引起）；
7. 海思芯片机型延迟偏大的问题在客户端 1.1.5 修过一批，老客户端先升级。

## 五、版本配对速查

两端版本差代时会出现连不上、功能缺失，对照下表：

| 组合 | 结果 |
|---|---|
| 安卓客户端 1.1.4 及以上 配 Windows 服务端 1.0.7 及以下 | 不兼容，连不上 |
| Windows 服务端 1.0.8 及以上 配安卓客户端 1.1.3 及以下 | 不兼容，连不上 |
| 服务端 1.3.5 + 客户端 1.4.2 及以上 | 解锁客户端内切换模式、自主调横竖屏、克隆屏性能提升 |
| 扫码连接 | 需客户端 1.3.9 及以上（1.3.5 客户端没有） |

截至 2026-09，官方最新为 Windows 服务端 1.3.5、安卓客户端 1.4.3，以 [官网下载页](https://www.extensodesk.cn/pages/zh-cn/download.html) 当时显示为准。网盘里那份 1.3.5 客户端可与官网当前 1.3.5 服务端直接配对使用，只是上表后两行的功能不可用。

确实需要回退时（最新版遇到问题、或手头只有旧设备），官方更新日志页为 Windows 端 1.0.7 与安卓端 1.1.3 这两个"兼容性版本"保留了下载入口，两个版本需相互配套使用：[官网更新日志](https://www.extensodesk.cn/pages/zh-cn/updatelog.html)。

## 六、其他

**高级功能开关自己关掉 / 状态不对**：会员状态刷新不及时会导致高级功能开不了（客户端 1.2.1、1.2.3 修复过相关 Bug），先升级客户端，再确认应用内的会员状态显示是否正常。

**手写笔、Photoshop 画笔问题**：见 [触摸与手写笔设置.md](触摸与手写笔设置.md) 第三节的修复选项与测试工具。

**在应用里直接反馈**：客户端内置反馈入口（客户端 1.3.0 修复过反馈提交失败的问题），本篇的办法都试过仍无解时，在应用内提交反馈，并写上两端各自的版本号。
