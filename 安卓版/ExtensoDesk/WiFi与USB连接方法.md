# ExtensoDesk 怎么连接电脑（WiFi 与 USB 两种方式）

> 平板要变成电脑副屏，先得让两端连上。本篇覆盖 WiFi 无线与 USB 有线两种连接方式的完整步骤与注意点。

## 一、连接前的检查清单

- 电脑装好 Windows 服务端并已启动，平板装好安卓客户端（没装先看 [下载与安装教程.md](下载与安装教程.md)）；
- WiFi 方式：两端连**同一个路由器**（同一网段）；
- USB 方式：一根能传数据的数据线——部分充电线不传数据，插上没反应先换线；
- 防火墙放行过服务端（安装时拦掉了，平板就搜不到电脑）。

## 二、WiFi 无线连接

1. 电脑端启动服务端。它会自动列出本机 IP 并自动刷新列表，不需要手动刷新。
2. 平板端打开 ExtensoDesk，稍等片刻，同一网络里的服务端会出现在设备列表中。
3. 点击服务端条目建立连接。首次连接需要输入配对的用户名和密码，在电脑端服务端界面上查看；密码可在服务端里修改。
4. 连接成功后，Windows 会多出一块显示器；扩展还是镜像，可在服务端里选模式，也可以到 Windows 显示设置里调整。

**列表里搜不到服务端时**，按顺序检查：

- 两端是否真的在同一网络——访客网络、5GHz / 2.4GHz 分开命名的路由器，常把设备分到不同网段；
- 部分路由器的"AP 隔离 / 访客隔离"功能会直接禁止设备互访，关掉再试；
- 还不行就在客户端里手动输入电脑端显示的 IP 连接。

**没有外接显示器也能连**：电脑一台显示器都没插时服务端也能工作（服务端 1.1.5 起支持），适合把闲置笔记本当主机、平板当唯一屏幕的场景。

## 三、USB 有线连接

1. 用数据线把平板接上电脑，两端程序都开着。
2. 在平板客户端的连接方式里选择 USB 项。
3. 连接成功后同样按需选择扩展或镜像。

USB 方式不受网络波动影响，稳定性和延迟通常比 WiFi 好，网络环境拥挤时优先选它。服务端 1.1.3 起能直接看出当前连接跑在 USB 2.0 还是 3.0——怀疑速度瓶颈时先从这里确认。

**USB 插上报错或没反应**：

- 客户端 1.2.0 起内置 USB 状态自排查提示，按提示逐项处理；
- 报错 `-1`、`-2` 多是 USB 驱动没加载好，换 USB 口、换线，或升级两端版本再试，详见 [常见问题与报错排查.md](常见问题与报错排查.md) 的错误码对照。

## 四、断线重连

- 客户端 1.2.8 起有**自动重连**选项，开启后短暂断开会自己接上；
- 客户端 1.3.2 起有**USB 断开时自动连接 WiFi** 选项——拔了线自动切无线，适合在两种方式之间来回挪动使用；
- 重连一直失败：先重启两端程序，再对照 [常见问题与报错排查.md](常见问题与报错排查.md) 的版本配对速查表，确认两端版本没有差代。

## 五、多设备与移动使用

- **手机也能当副屏**：安卓客户端同样支持手机，把客户端装到手机上就能连同一台电脑，临时要一块小屏时不必等平板在手边；
- **无线连接不受桌子约束**：WiFi 连接下平板不必和电脑摆在一起，同一网络覆盖的范围内都可以随时查看电脑上正在显示的内容——坐着核对文档、把参考窗口挪到手边都可行；
- **多台设备一起看**：服务端 1.1.3 起支持会议模式，多个客户端可以同时克隆同一块屏幕，适合把演示画面分给几个人同时看。

## 六、连接之后调什么

画面发虚、想调分辨率或帧率，看 [画质与显示设置.md](画质与显示设置.md)；想把平板当数位板用（触摸、手写笔），看 [触摸与手写笔设置.md](触摸与手写笔设置.md)。
