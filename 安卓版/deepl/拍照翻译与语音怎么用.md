## 一、实时相机翻译：对着文字直接看译文

适合在外看路牌、菜单、说明书这类场景，不用拍照再等处理：

1. 打开应用，进入 `Translate` 标签；
2. 选好源语言与目标语言（也可以让应用自动检测源语言）；
3. 点 `Camera` 按钮，把镜头对准文字；
4. 译文会实时叠加在原文位置上。

拍之前尽量让文字**清楚、光线充足**——官方明确提示：字体小、光线暗、手写或艺术样式的文字都会影响识别与翻译质量。

## 二、图片翻译：翻译相册里的照片

已经拍好的照片、截图也一样能翻：

1. 进入 `Translate` 标签；
2. 点 `Camera` 按钮，再点 `Image` 按钮；
3. 从相册里选一张图片；
4. 译文会覆盖显示在原文上。

拿到结果后你还有几个可用的操作：

| 操作 | 作用 |
| --- | --- |
| 关闭叠加 | 看回原图，不显示译文覆盖 |
| 全选文字 | 把原文与译文分开成两段查看 |
| 旋转图片 | 摆正拍摄歪斜的图 |
| 复制 | 把译文复制到剪贴板 |

**一条硬限制**（官方帮助中心写明）：图片翻译**不支持以希腊语、以及使用西里尔字母的文字作为源语言**。遇到这两种文字的图片，只能先转成别的源语言再翻，或改用文本输入。

## 三、听写：说出的话直接变译文

不想打字就直接说，步骤是：

1. 点 `Translate`，选好源语言与目标语言；
2. 点麦克风图标；
3. 对着手机用**源语言**说话；
4. 说完点红色按钮结束，识别出的文字会进入翻译流程。

想润色自己写的文字而不是翻译，就切到 `Write` 标签，其余步骤相同（选源语言 → 点麦克风 → 说话 → 停止）。

几个使用前提：

- **首次使用要确认授权**：免费用户与 Pro 用户都需要确认一次，允许应用访问麦克风；你随时可以在手机设置里撤销。
- **识别语言由手机的语音服务决定**：支持哪些语言取决于你的设备，首页能看到麦克风图标才说明当前可用。
- **识别不工作时**：先检查手机的语音服务是否有麦克风权限（在手机的隐私/权限设置里看）。

## 四、朗读译文与调节语速

翻译结果可以朗读出来，语速在应用内可调：

1. 进入应用设置；
2. 找到 `Translation`（翻译）分区下的 `Voice Speed`；
3. 选一个速度，会立即播放预览：

| 档位 | 说明 |
| --- | --- |
| 0.5 | 最慢 |
| 0.75 | 慢 |
| Standard | 标准（默认） |
| 1.25 | 最快 |

设置会保存给以后的翻译使用，随时可以再改。

## 五、在别的应用里选中文字，直接发给 DeepL

看网页、聊微信时看到一段外文，不必复制粘贴切换应用：

1. 在原应用里选中要翻译的文字；
2. 长按选中部分；
3. 在弹出菜单里选 `DeepL`（没看到就点「更多」展开），或者选「分享」再选 `DeepL`（部分机型是 `Translate with DeepL`）；
4. 文字会自动进入 DeepL 并显示翻译。

如果分享菜单里一直找不到 DeepL，到应用设置里的 **Share to translate**（分享即翻译）项把 DeepL 加进常用应用即可——具体路径以机型为准，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 六、收藏与历史：翻过的东西能找到

- **收藏（Favorites）**：把常用的词语、短语存起来，之后反复调用；官方页面提到收藏内容可在离线时查看。
- **历史（History）**：过往翻译自动留档，可以从里面找回、修改、再次使用。

## 七、短句不满意？看备选翻译

短词、短句的翻译结果会一并给出**其他翻译结果（备选翻译）**——同一个原文给几种不同译法，可从中挑一个替换。拿不准哪个词更贴切时，与其改原文反复试，不如直接翻一遍看备选列表；正式场合选更书面的那一版，口语场景选更直白的那一版。

需要整段文件的翻译（比如 PDF），走的是另一条路径，见 [怎么翻译PDF和文档.md](怎么翻译PDF和文档.md)；应用还没装好则先看 [下载与安装教程.md](下载与安装教程.md)。语音授权与数据走向的完整说明在 [隐私与数据安全要注意什么.md](隐私与数据安全要注意什么.md)。
