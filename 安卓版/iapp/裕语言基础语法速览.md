## 一、iApp 里不止一种语言

同一个项目里可以混用几种语言：

| 语言 | 说明 |
| --- | --- |
| iyu（裕语言） | iApp 的主力语言，本篇只讲它 |
| i-js | 基于 JavaScript 语法，并融合裕语言代码 |
| i-lua | 基于 Lua / LuaJava 语法，并融合裕语言代码 |
| i-java | Java 风格写法，可调用系统能力 |

新手建议先只用 iyu 把流程跑通，需要时再混用其他语言。

另外，裕语言本身有版本线（V3.0、V5.0、V7 等），下一节专门讲怎么选。

## 二、V3 / V5 / V7 怎么选

新建项目时选的版本决定你的指令集与打包能力。综合官方教程目录与更新日志（细节以软件内为准）：

| 版本线 | 特点 | 适合 |
| --- | --- | --- |
| V3 | 出现最早，网上现成的例子与教程最多；曾随版本升级兼容 Android 8.0+ 系统 | 跟着社区例子学的新手 |
| V5 | 加了中文编程（配中文手册）、SDK 导入、自定义控件等能力 | 想要更多类库与原生编译能力的进阶用户 |
| V7 | 跨平台线：教程里有打包成手机 App、电脑 App、网站 H5 的课程；鸿蒙端、iOS 端打包出现在更新日志里 | 想一份代码打多个端的用户 |

不确定就用 V3 起步——它最容易找到能抄的例子；等你要的能力（中文编程、SDK、跨平台）明确了，再按能力选版本线。各版本的指令差异是导入别人源码时最容易踩的坑，见[常见问题与解决办法.md](常见问题与解决办法.md)。

## 三、官方手册就躺在安装目录里

iApp 安装后，在它的目录下自带几份 txt 手册（文件名以你手机里实际看到的为准）：

- `iyu-helpV3.0.txt` —— V3.0 裕语言帮助
- `iyu-helpV5.0.txt` 与 `iyu-中文编程V5.0.txt` —— V5.0 帮助与中文编程手册
- `igame-helpV1.0.txt` 与 `igame-中文编程V1.0.txt` —— iGame 游戏模块的手册

写代码卡住时先翻手册，这是最不容易出错的一手资料。

## 四、高频指令对照

下表整理的是官方视频教程与社区示例里反复出现的指令（不同版本的参数写法可能有出入，以手册为准）：

| 指令 | 用途 | 示例 |
| --- | --- | --- |
| `s` | 赋值 / 定义变量 | `s a="123"` |
| `syso` | 打印调试信息 | `syso(a)` |
| `tw` | 弹出提示 | `tw("你好")` |
| `f` | 判断 | `f(a=="123"){ }else{ }` |
| `w` / `for` | 循环（条件循环 / 遍历循环） | 写法见手册对应章节 |
| `t` | 开线程，包住耗时动作 | `t(){ }` |
| `ss` | 字符串操作（拼接、截取等） | `ss(a+"px",b)` |
| `hs` | 获取网页源码 | `hs("https://example.com",a)` |
| `hw` / `hd` | 访问网页 / 下载文件 | `hw("https://example.com")` |
| `us` | 设置控件属性 | `us(1,"text","点我")` |
| `fl` / `fs` | 列目录 / 查文件大小 | 配合文件操作用 |

把变量值存进控件显示用 `us`，反过来从控件取值另有对应指令——取和存是成对的，手册里挨着写。

## 五、线程与提示为什么要一起学

如果你在事件里直接写一个耗时的网络请求，运行起来界面会顿住。官方教程把「t 线程」与「tw 提示」放在同一课，就是这个原因：把耗时动作包进 `t` 里，完成后再用 `tw` 或改控件属性把结果反馈出来。记住这个搭配即可——**耗时的动作包进 t，结果出来再提示**。

## 六、照着别人写好的学

- **官方视频教程**：打开 iApp → 互动 → 看教程，第一条就是官方裕语言零基础系列，覆盖变量、判断、循环、线程、文件、网络、控件、布局、列表、数据库、动画等几十课，全部免费；V3、V5、V7 各有一条入门线，还有 iGame 游戏开发的专门教程；
- **共享空间**：导入别人分享的源码项目，对照界面和代码看「这一行对应屏幕上哪个效果」。反过来，把你的项目上传到共享空间是公开分享，别人搜得到也能导入——只想自己留档的走备份，见[项目备份与换机迁移.md](项目备份与换机迁移.md)；
- **官方账号**：抖音与 B 站搜 `iappgf`，西瓜视频与 QQ 频道搜 `iApp`（账号名以平台实际显示为准）。

写出来的代码报错看不懂时，先去[常见问题与解决办法.md](常见问题与解决办法.md)对一对常见坑。
