## 一、安装阶段的报错

| 现象 | 原因与处理 |
| --- | --- |
| 解析包时出错 / 安装包损坏 | 下载不完整。回网盘重新下载，下完按 [下载与安装教程.md](下载与安装教程.md) 第二节核对 MD5 |
| 已安装应用未安装 / 签名冲突 | 手机上装过来源不同的同款应用。先卸载旧版再装这份 |
| 存储空间不足 | 清出比安装包体积大一截的空间，别只删安装包 |
| 系统版本过低 | 这份包标注需安卓 5.2 以上；低于它装不上，只能换设备或改用网页版 |

## 二、闪退、卡顿、白屏

按代价从小到大试，通常前两步就能解决：

1. 重启手机再打开；
2. `设置 → 应用 → Game Jolt → 存储` 里**清除缓存**（不清数据，登录状态还在）；
3. 清缓存无效再**清除数据**，代价是要重新登录一次；
4. 还不行就卸载重装——账号内容存在服务端（见 [注册与登录账号.md](注册与登录账号.md)），重装后登录即可恢复关注与聊天；
5. 顺手看一眼系统有没有待装更新，以及官方有没有发新版。

闪退之外的「打开才正常、关掉就断」类问题（推送收不到、通知延迟）不在这一节，按 [收不到推送通知怎么办.md](收不到推送通知怎么办.md) 的顺序查。

持续白屏/加载不出来大概率是网络问题：换 Wi-Fi 与流量各试一次，判断是站点访问不通还是你这条网络被限制（这类问题与本机无关，只能换网络环境再试）。

## 三、登录失败、一直要求确认设备

- **提示登录失败**：先分清你填的是**密码**还是 **Token**——两者不通用，Token 填进密码框必然失败（Token 的说明在 [注册与登录账号.md](注册与登录账号.md) 第六节）。再检查用户名有没有拼错。
- **换设备后卡在「确认设备」**：按提示到注册邮箱里点确认链接；收不到就先翻垃圾邮件箱。
- **确认邮件死活不来**：确认你用的是注册时那个邮箱、并且没有把官方邮件域名拦掉；仍收不到时换网络/换邮箱客户端再试一次。
- **老账号登不进、邮箱也丢了**：官方的答复是——只能请邮箱服务商帮你恢复邮箱；恢复不了就重新注册一个新账号，没有别的通道。

## 四、收不到验证 / 找回邮件

账号相关的邮件只认注册邮箱。按顺序查：① 收件箱没有 → 垃圾邮件/订阅邮件文件夹；② 被过滤规则拦了 → 去邮箱里给 `contact@gamejolt.com` 加白名单后重发；③ 邮箱本身收信异常 → 换个客户端或网页版邮箱看。三步都试过还没有，就是邮箱侧的问题，官方帮不上忙。

## 五、App 里找不到游戏下载

这不是故障，是官方设计：**手机 App 不分发游戏**（官方在商店答复里明确说明受限制）。想玩游戏，去 [gamejolt.com](https://gamejolt.com) 网页版或下载桌面客户端；App 用来刷动态、聊天、领任务（见 [新手使用指南.md](新手使用指南.md) 第一节）。

## 六、被禁言、封号、内容被删

- 论坛内无法自助解禁——官方 FAQ 写明**只能发邮件** `contact@gamejolt.com` 申请复核；
- 一定要**用注册邮箱发**，并说明你认为的误判情况，否则官方无法核对身份；
- 游戏被下架/收到版权（DMCA）通知的疑问，同样发这个邮箱。

## 七、订单与购买问题

在商店买过东西出问题（付款了没到账、买错了），发邮件到 `contact@gamejolt.com` 并**附上订单 ID**；市场准入（Marketplace）申请没收到回复的，官方 FAQ 说只回复通过审核的人，但你发邮件询问进度他们会给状态。价格与商店规则会变，以官方页面当时显示为准。

## 八、什么时候该直接找官方

上面都试过还没解决，就发邮件 `contact@gamejolt.com`：说明你用的设备与系统版本、应用版本（这份包是 1.15.17）、问题复现步骤。桌面客户端彻底跑不起来的情况，官方 FAQ 给的建议是先卸载重装，仍不行就在客户端里提交系统报告——**系统报告的入口在客户端页面底部**（页脚的小链接，官方说明它是匿名的，用来定位你的问题）；客户端当前版本号同样看页脚。另外注意官方 FAQ 明说**有一部分游戏就是无法通过客户端启动**，这类游戏网站下载后直接运行是正常的，不是你装错了。

## 九、界面能改成中文吗

对多数中文用户来说界面看到的是英文，能不能改、去哪改，公开材料的说法不一致，先照实说：

- 有用户反馈网页端存在语言入口，但**位置说法互相矛盾**（页面底部、登录页的下拉菜单、动态流左上角三点里的 Change Language 各有人提到），且有反馈称**翻译长期没有更新**、中文也不完整；
- 也有用户反馈**手机 App 上找不到语言入口**；
- 还有一种说法是语言选择跟随浏览器设置而非账号（该说法来源较旧）。

结论按证据等级只能写到这：**入口以你当时看到的界面为准，找不到就说明当前版本没提供**。别为找这个入口翻遍设置——真需要中文帮助，配合本套文档与浏览器的网页翻译功能即可。以上均为用户反馈与旧帖口径，不是官方承诺。
