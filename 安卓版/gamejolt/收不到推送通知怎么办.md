# Game Jolt 收不到推送通知怎么办

> 按症状分流的排查顺序：完全没通知、打开应用才来、来了没声音、锁屏看不到，各自的修法不同。

## 一、先确认是哪种「收不到」

安卓的推送要经过系统权限、电池策略、网络、以及应用内开关四道关，任何一道掐了都表现为「没通知」。先对号入座，别一上来就乱改设置：

| 症状 | 最可能的卡点 |
| --- | --- |
| 一条都不来 | 通知权限没给，或应用内/邮箱侧关了这类提醒 |
| 只有打开应用后才看到 | 后台被系统限制（电池优化、后台数据） |
| 有通知但不响 | 通知类别被设成静音，或勿扰/音量问题 |
| 只有锁屏上看不到 | 锁屏隐私设置，不是推送本身的问题 |
| 别的 App 也一起哑了 | 勿扰模式、省电模式、飞行模式这类全局开关 |

## 二、系统层：按顺序查这五处

路径名各品牌略有差异（三星、小米、OPPO、vivo 措辞都不同），找不到就在设置里直接搜关键词。

1. **通知权限**：`设置 → 通知 → 应用通知` 里找到 Game Jolt，打开「允许通知」。安卓 13 及以上首次安装会弹询问，当初点了「不允许」就是这里一片灰。
2. **通知类别**：权限打开后往下看，具体类别（私信、提醒等）可能单独被关。只关了某一类，就只有那一类收不到。
3. **电池策略**：`设置 → 应用 → Game Jolt → 电池`，选「不受限制」。症状「打开才来」基本就是它——系统把后台活动掐了，应用收不到推送。三星另有一处 `设置 → 电池 → 后台使用限制`，检查本应用有没有被丢进「深度睡眠应用」。
4. **后台数据**：`应用 → Game Jolt → 移动数据与 Wi-Fi`，打开「后台数据」；若开了省流量模式，把本应用加入豁免。Wi-Fi 下正常、流量下没通知，查这条。
5. **全局开关**：下拉快捷面板看勿扰、省电模式有没有开着；音量键把「铃声与通知」音量拉起来。只有一类通知不响，回第 2 条把那个类别从「静音」改成「提醒」。

国产手机还多一道**自启动**：小米在 `设置 → 应用设置 → 自启动`、OPPO/vivo 在「权限管理/电池」的类似选项里，把 Game Jolt 打开；不开的话推送经常要等你手动打开应用才补进来。

## 三、应用内与账号侧

系统全开还是收不到，就轮到应用自己这一层：

- **应用内通知开关**：打开 Game Jolt，进设置看通知相关选项有没有被关掉（界面偶尔调整，以当时界面为准）。
- **邮件通知**：官方说明邮件通知完全可自定义——如果你改过设置，把要的类别重新勾上。账号安全类邮件（验证、找回）走的是注册邮箱，收不到时按 [常见问题与故障排查.md](常见问题与故障排查.md) 第四节查垃圾箱与白名单，那是另一条链路。
- **登录状态**：被登出、或卡在设备确认（见 [注册与登录账号.md](注册与登录账号.md) 第四节）时，推送也可能断——先确认自己确实处于登录状态。

## 四、都不行再动应用本身

按代价从小到大：清缓存 → 重启手机 → 清数据重登 → 卸载重装（重装后首次启动记得**在系统弹窗里点允许通知**，别又点了拒绝）。应用本体的问题（闪退、卡顿）另有排查顺序，见 [常见问题与故障排查.md](常见问题与故障排查.md) 第二节。

## 五、什么时候不用再修

只有个别类型的提醒没来、其余正常时，通常不是故障，而是应用内或系统里那一类被单独关了（第二节第 2 条）；反过来，如果全机所有应用同时收不到通知，问题在系统全局开关或网络，不在这个应用。判断清楚再动手，能省掉一轮乱改。
