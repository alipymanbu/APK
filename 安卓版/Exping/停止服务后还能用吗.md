# exping 停止服务后还能用吗

先给结论：**exping 的服务器已经关了，一切需要登录、联网、同步的功能都用不了**。安装包本身还能装，但装上之后大概率停在登录这一步。如果你是想找回当年的地图数据，直接翻[地图数据导出与备份](地图数据导出与备份.md)。

## 一、停服时间线

| 时间 | 事件 |
| --- | --- |
| 2022-03-21 | exping 上线（iOS / Android 先行，网页版 2023 年推出） |
| 2024-10-24 | 官方发布告别公告，同日推出最后一个版本 1.9.11 |
| 2024-12-31 | 正式停止服务 |

停服原因，官方在公告里说得直白：小团队经营困难，无力继续承担运营成本。同时承诺了两件事——

- **exp+ 订阅用户退款**：对无法继续兑现的会员服务进行退款处理；
- **开放数据导出**：兑现「数据自由」的承诺，让用户在停服前把地图数据备份出来。

退款的具体操作口径（怎么登记、走什么渠道）公告之外没有留下更多说明，客服渠道也随停服一起关闭了——如果你是当年的 exp+ 订阅用户且至今没收到退款，只能从当时的公告与社媒官方账号（即刻等）留存的联系方式入手，没有其他通道。

当时的官方告别公告挂在 `exping.world/goodbye`，后来随域名改版一起下线了。创始人 Clu Soh 在个人网站另写了一篇告别文，目前还能访问：[Dear, exping](https://clu.so/blog/to-dear-exping)。顺带一提背景：这款应用上线一周就被 App Store 收录进「本周编辑推荐」（官方自述），停服时不少用户在社媒表达惋惜——它不是一款没人用的应用，只是没撑过去。

## 二、现在还能做什么、不能做什么

| 功能 | 停服后的现状 |
| --- | --- |
| 安装 APK | 安装包本身仍可安装，能否进入主界面取决于客户端对登录的依赖程度，无法一概而论 |
| 注册 / 登录 | 服务端已关闭，新账号注册与老账号登录都无法完成 |
| 地图创作、云同步 | 无法使用，云端已无服务可同步 |
| 多人协作、实时位置共享 | 无法使用 |
| 社区（探索、精选地图） | 无法使用，当年的公开地图内容也不可再访问 |
| 数据洞察（浏览趋势等） | 无法使用 |
| 海报导出、图片分享 | 属客户端本地生成能力，能否离线使用无法确认，以你手机上的实际表现为准 |
| 当年的 Web 分享链接 | 已失效——`exping.world` 域名现在展示的是另一款产品，老链接指向的内容不存在了 |

一句实话：这款应用的核心体验都建立在账号与云端之上，停服后「能用的部分」非常有限。如果你是听说它好用才找来装，建议先读完这张表再决定要不要花这个下载时间。

停服之后，社区里有用户提到过一款玩法相近的新应用 Placify（iOS 端），称它支持导入 exping 的分享链接，猜测与原团队有关——这只是个别用户的观察，是否同一团队没有任何官方说法，这里仅记录这个线索，不替你下结论。想自己找替代的话，更稳的路子是带着格式走：把数据导成 GeoJSON 或 KML，选哪家先看它支持导什么，见[地图数据导出与备份](地图数据导出与备份.md)。

留档、研究或怀旧的需求都合理。安装包还在：[exping 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9b92b8fe5bdd)，转存到自己网盘后下载即可，具体的安装步骤与排错见[下载与安装教程](下载与安装教程.md)。
