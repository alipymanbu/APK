# exping 地图数据导出与备份

> exping 支持把地图导出为 Excel、HTML、Markdown、GeoJSON、KML 等格式，也支持从其他平台导入地点。本篇整理导出与导入的完整口径，以及停服之后这条路还剩多少。

exping 官方在停服公告里称「始终坚持数据自由的理念」，并把导出当作兑现承诺的方式。下面按「导出格式 → 导入来源 → 误删恢复 → 停服后的现实」四段讲。

## 一、导出支持哪些格式

官方应用介绍在停服时（末版 1.9.11）列出了这五种导出格式：

| 格式 | 适合拿去做什么 |
| --- | --- |
| GeoJSON | 标准地理数据格式，坐标与属性齐全，适合导入其他还在维护的地图工具 |
| KML | Google 地图系工具通用，也方便归档 |
| Excel | 表格化整理地点清单，做行程表、台账 |
| HTML | 保留网页样式，双击就能在浏览器里回看 |
| Markdown | 转进笔记软件（Notion、Obsidian 等）继续编辑 |

导出支持**单张地图**和**多张地图批量**两种粒度。另外在 1.7.x 版本时期，官方更新日志就写过「支持批量导入/导出 KML 文件，方便数据迁移」——KML 是它早期就有的迁移通道。

## 二、从别的平台导入地点

反过来，把别处收藏的地点搬进 exping 也是官方主推的用法：

- 把**小红书笔记、大众点评专辑、苹果指南**等内容的分享链接复制下来；
- 在地图里点「导入」—「从其他平台导入」，粘贴链接；
- 应用识别出地点列表后，点「添加到地图」，一次性生成标记，再继续编辑。

当时的第三方旅行工具（比如及游册）也专门写过把分享链接粘进 exping 一键生成旅行地图的教程——这类「链接进、地点出」的导入是它后期的主打功能之一。当然，这条路现在随服务关闭一并终止了。

## 三、误删恢复的时限

官方更新日志提到过删除保护机制：删除地图采用倒计时机制，误删后 **72 小时内**可以恢复。这个机制依赖账号服务，如今只在一种场景下还有意义——手机里还留着停服前的旧版本和登录态。超过时限或账号已无法登录，就没有恢复通道了。

## 四、停服之后，导出这条路还剩多少

按数据存在哪，分两种情况：

1. **数据在云端（多数人的情况）**：地图随账号存在服务器上，2024-12-31 停服后服务器已关，云端数据随之不可访问。官方建议的「导出备份」只在停服前有效，现在没有通道能再拿到云端那份。
2. **手机里还留着旧版本**：如果你当年装过 exping 且一直没卸载，本地可能还有缓存或数据库副本。客户端的导出若为本地生成，理论上可以尝试打开后导出 GeoJSON / KML；但登录态大概率已失效，能不能进到导出入口，只能以你手机上的实际表现为准——这一点官方没有留下停服后的说明，无法替你确认。

无论哪种情况，**先别卸载旧版本**，卸载之前值得按上面第 2 条试一遍。如果你手里只有安装包、想装回来看看，包在这：[exping 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9b92b8fe5bdd)，安装步骤见[下载与安装教程](下载与安装教程.md)。

导出格式里最值得先试的是 **GeoJSON**——坐标、路线、属性都在，换到任何还在维护的地图工具里都能接着用。GeoJSON 和 KML 都是通用地理格式，Google My Maps 这类仍在服务的地图工具支持导入（各家当前支持哪些格式，以其官方说明为准）。至于停服后的整体现状，另见[停止服务后还能用吗](停止服务后还能用吗.md)。
