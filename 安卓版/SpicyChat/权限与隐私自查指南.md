## 一、权限按「用得到才给」处理

这类应用通常会在首次启动或首次用到某功能时弹权限申请。处理原则一句话：**这项功能我不用，就拒绝**。对照关系是这样的：

| 权限 | 对应功能 | 不给的后果 |
| --- | --- | --- |
| 存储 / 相册 | 发图片、保存角色头像 | 只能纯文字聊天 |
| 麦克风 | 发语音消息 | 只能打字 |
| 相机 | 拍照发送 | 从相册选图仍可用 |
| 通知 | 新消息提醒 | 需要自己打开应用看 |

**位置、通讯录、电话、短信**这类与聊天无关的权限，任何情况下都不必给 —— 若应用坚持索要且拒绝后无法继续，记下这点（见第三节的处理）。

具体某次申请对应哪个功能，以弹窗文案为准；不同版本的措辞会变，判断标准始终是「我要不要用这个功能」。

## 二、查看与收回已给的权限

随时能改，两步：

1. `设置 → 应用 → SpicyChat → 权限`（部分机型路径是 `应用管理`）。
2. 逐项点开，改成**允许**、**仅在使用中允许**或**拒绝**。

建议的稳态是：只留聊天真正要用的两三项，其余全拒。改完立刻回应用试一下对应功能 —— 能用说明给对了，不能用再单独放开那一项。

## 三、装完之后手机变卡、广告变多：自查顺序

**先说明证据层级**：关于这类 AI 聊天应用「耗电变快、弹窗广告变多、索要多余权限」的说法，在公开论坛与评测里能搜到多条**用户反馈**，但没有针对本安装包（`ai.spicy.spicychat.mate`）的验证结论，本机也未实测 —— 所以下面给的是**自查步骤**，不是「这个应用会这样」的定论：

1. **定位时间点**：异常是安装后才出现的吗？先在 `设置 → 电池` 里看耗电排行，SpicyChat 若不在前列，问题多半另有来源。
2. **查最近变更**：`设置 → 应用` 里按安装时间排序，看异常时段还装了什么 —— 广告类问题的元凶经常是同批装的另一个应用。
3. **收紧权限**：按第一节把无关权限全关掉，观察一到两天。
4. **清缓存**：`设置 → 应用 → SpicyChat → 存储 → 清除缓存`。缓存清掉不影响聊天记录，先做这一步。
5. **对照实验**：仍异常就卸载，观察是否恢复；恢复了再决定要不要重装（重装前先看 [下载与安装教程.md](下载与安装教程.md) 的包信息核对）。

顺序别乱：**先查别的应用，再动权限和缓存，最后才考虑卸载** —— 直接卸载会把本地记录一起清掉（见 [常见问题与解决方法.md](常见问题与解决方法.md) 第四节）。

## 四、聊天内容的自我保护

AI 聊天应用的对话属于「你发出去的内容」，按最低限度保护自己：

- **不输入真实身份信息**：真名、住址、单位、手机号、账号密码、支付信息，一个都别发。
- **手机借人前**：退出登录或用系统应用锁锁住它（`设置 → 安全 → 应用锁`，机型不同叫法不同）。
- **彻底清空**：转手手机或不想留痕时，`设置 → 应用 → SpicyChat → 存储 → 清除数据`（等于恢复到刚装好的状态，账号需重新登录），再按需卸载。
- **安装包留档**：怀疑下载的包被人动过，用下面的方法核对。

```cmd
certutil -hashfile "C:\下载\SpicyChat_v1.1.4.apk" MD5
```
