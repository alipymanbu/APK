## 一、先确认你能不能用：订阅版专属

Grindr Web 是官方的浏览器版本，在电脑上打开就能聊天、看附近的人，不用装任何东西。但它**只对 XTRA 和 Unlimited 订阅用户开放**，免费账号无法登录网页版；订阅档位对照见 [XTRA与Unlimited订阅区别.md](XTRA与Unlimited订阅区别.md)。

还有一条硬性限制：**网页版不能注册新账号**，新账号只能在手机 App 里创建。所以正确顺序是先用手机注册（必要时参照 [下载与安装教程.md](下载与安装教程.md) 装好 App），再上电脑登录。

## 二、支持的浏览器

官方给出的最低版本要求（截至官方帮助中心口径）：

| 浏览器 | 最低版本 |
| --- | --- |
| Chrome | 111.0.5 以上 |
| Firefox | 111.0.1 以上 |
| Microsoft Edge | 111.0 以上 |
| Safari | 16.3 以上 |

## 三、登录步骤

1. 在电脑浏览器打开 `https://web.grindr.com/login`；
2. 用与 App 相同的凭据登录（邮箱密码，或 Google / Apple 等第三方账号）；
3. 浏览器弹出位置权限时选**允许**——网页版必须拿到位置才能加载附近列表，同时要在浏览器设置里允许该站点的弹出窗口；
4. 登录后有个「Stay Logged In」开关：开着可保持登录；关掉的话，15 分钟不活动就会自动退出。**在公用或借用的电脑上，建议关掉**。

电脑和手机可以同时在线，但两边同时收发消息时通知容易混乱，建议主用一边。

## 四、网页版独有的三个隐私功能

- **Escape Hatch（逃生开关，仅桌面）**：快速连按三次 `ESC` 键，页面立刻切换成一个 Google 搜索页，同时清掉这个站点的浏览记录——有人走近电脑时的应急开关；
- **Approximate Location（模糊位置）**：在网页版设置里开启后，别人看到的你的距离是 500~1500 米内随机的一个数，不是精确位置；开启过程对方无从察觉；
- **Office Mode（办公室模式）**：把头像都换成简洁图标，界面看起来不像在用社交软件；多位第三方教程提到它在网页版设置里开关（官方帮助中心对这一项着墨不多，以你登录后看到的实际设置项为准）。

## 五、网页版和手机 App 的功能差异

官方明确列出了只能在 App 里做的事，上电脑前先知道哪些操作做不了：

| 功能 | 网页版 | 说明 |
| --- | :-: | --- |
| 浏览附近、聊天 | 可用 | 桌面网格更大，资料页可全屏浏览 |
| 查看私密相册 | 桌面可看 | 手机浏览器反而看不了 |
| 注册新账号 | 不可 | 只能用 App |
| 查看阅后即焚照片/视频 | 不可 | 只能在 App |
| 管理/购买订阅 | 不可 | 到 App 或商店账户里操作 |
| Fresh / Explore 网格 | 不可 | 只能在 App |
| 录语音消息 | 仅 Safari | 其他浏览器发不了 |
| 视频聊天、消息翻译、置顶会话、保存短语 | 不可 | 只能在 App |

另外，个人数据可以从网页版导出：点头像缩略图 → Settings → Security and Privacy → Download Data，按提示填接收邮箱，收验证码后官方会把数据打包发过去。

## 六、网页版刷不出来怎么办

- 先确认订阅状态有效（免费账号登录不了网页版）；
- 浏览器版本不够就先升级，老版本直接白屏或加载失败；
- 检查浏览器的位置权限和弹出窗口设置，两项都被官方列为必需；
- 公司电脑有时在系统层面禁用了定位，浏览器权限给了也没用，换网络或换设备试；
- 其他登录类问题（密码、第三方登录、限流）与 App 端相同，参照 [登录失败与报错排查.md](登录失败与报错排查.md) 处理。
