## 一、注册前要知道的四件事

1. **必须年满 18 周岁**。注册时要填出生日期，未成年人无法通过；如果你曾以未成年身份尝试注册，官方会留下标记，成年前都无法注册（有用户反馈这种情况会一直报注册错误）。
2. **一个邮箱对应一个账号**。报「Maximum number of accounts」就是当前邮箱建号数量到顶了，官方的建议是登录旧账号，或者换一个新邮箱再注册。
3. **注册必须在手机 App 里完成**。网页版（Grindr Web）不支持注册新账号，只能登录已有的。
4. **登录邮箱区分大小写**，官方建议全部用小写字母输入。

## 二、注册步骤

1. 打开 Grindr，选择注册方式：
   - 邮箱 + 密码（最通用）；
   - 用 Google / Apple / Facebook 账号快捷注册（要确认手机上登的是哪个第三方账号，注册后只能用同一账号登录）；
   - 部分地区可用手机号注册。有用户反馈虚拟运营商号码、VoIP 网络电话号码常收不到验证码，普通手机卡的短码短信也可能被运营商默认拦截。
2. 填出生日期（18+ 校验）；
3. 上传头像照片；
4. 按提示填昵称等基础资料，进入主界面。

如果某一步报错（常见的有「Registration error」「Something went wrong」加一串代码），跳到 [登录失败与报错排查.md](登录失败与报错排查.md) 对照处理。特别地，因填错出生年份被打了未成年标记的话，普通重试没用，只能走申诉并准备身份证件验证（有用户反馈这条路成功率也不高），详见排查篇的封禁申诉一节。

## 三、头像审核：为什么照片一直「待审核」

所有头像都要过一轮人工或机器审核，通常很快，高峰期会慢一些。官方社区准则明确**禁止裸露和性行为描述的照片**，这类照片会被拒绝。想少踩坑：

- 用清晰的真人照或能代表你的图片；
- 别在头像里放联系方式（微信号、手机号这类容易被判违规）；
- 审核没过换一张重新传就行，不影响账号本身。

## 四、资料页值得认真填的几项

| 项目 | 作用 |
| --- | --- |
| About Me（关于我） | 自由文本，写清你想找什么，能明显减少无效搭讪 |
| Tribes（族群） | 社群身份标签，如 Bear、Jock、Twink、Otter 等，也可以选择不透露；别人可以按 Tribe 筛选你 |
| Tags（兴趣标签） | 自己添加关键词，别人搜同一个标签就能找到你 |
| 基础数据（身高体重等） | 按真实情况填，筛选时会用到 |
| What I'm looking for | 交友/约会/聊天等意向选项，是别人决定是否跟你打招呼的重要依据 |

资料不必一次填完，先填头像和意向就能开始用，其余的后面慢慢补。

## 五、隐私开关：哪些信息可以藏起来

在设置里你可以控制别人看到什么：

- **隐藏距离**：别人看不到你与他的精确距离（但你的资料仍会按相对远近出现在他的附近列表里）；
- **隐藏年龄**：资料页不显示年龄；
- **不上传头像也能用**：可以用字母头像保持匿名，等聊得放心再换真人照。

想连「出现在别人的网格里」都避免，那是订阅版的隐身模式（Incognito），详见 [XTRA与Unlimited订阅区别.md](XTRA与Unlimited订阅区别.md)。
