## 二、把安装包下到手机

1. 打开上面的 **LOVEAI 安装文件资源（夸克网盘）** 链接，登录夸克账号后先「转存」到自己的网盘；
2. 手机上装好夸克 App，在「我的网盘」里找到刚转存的文件夹；
3. 点其中的 APK 文件下载到手机存储，等进度走完；
4. （可选）校验文件完整性：把手机连到电脑，在命令行执行下面的命令，输出的 MD5 应与上表一致。

```bat
certutil -hashfile "LOVEAI_v1.3.8.apk" MD5
```

文件名以你实际下载到的为准。MD5 对不上说明下载不完整，删掉重下即可。

## 三、安装步骤

1. 在文件管理器里点刚下载的 APK；
2. 首次安装会提示「禁止安装未知来源应用」，按系统引导去设置里**允许夸克或你的文件管理器安装应用**（各品牌入口不同：设置里直接搜「未知来源」或「安装未知应用」最快）；
3. 回到安装页点「安装」，等进度条走完；
4. 打开应用，首次进入会申请网络等权限，界面里也会出现「内容由 AI 生成，使用时请遵守平台社区公约」的提示——这是正常的合规提示，点掉即可。

## 四、装不上怎么排查

| 现象 | 处理办法 |
| --- | --- |
| 提示「解析包错误 / 解析失败」 | 多数是下载不完整，先核对 MD5（见第二节），对不上就删掉重下 |
| 提示存储空间不足 | 清出至少 1 GB 空闲空间再装（安装过程需要比包体更大的临时空间） |
| 「安装」按钮置灰点不了 | 检查是否还有别的安装任务在进行；或关掉「纯净模式 / 安装守护」类开关后再试 |
| 覆盖安装失败、提示签名冲突 | 手机里已有别的来源的同名应用时会出现，先卸载旧的那个再装（卸载会清掉仅存在本机的聊天记录，动手前先看[注册登录与账号同步.md](注册登录与账号同步.md)里的云同步说明） |
| 装上了但一打开就闪退 | 重启手机再试；仍闪退多半是系统版本或兼容问题，见[常见问题与解决方法.md](常见问题与解决方法.md) |

装好之后的下一步是注册登录，见[注册登录与账号同步.md](注册登录与账号同步.md)；想先了解能玩什么，可看[聊天模式与心动卡牌.md](聊天模式与心动卡牌.md)。
