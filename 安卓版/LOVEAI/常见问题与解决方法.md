## 一、回复变慢或没反应

AI 回复的延迟主要来自两处：你的网络环境、服务器瞬时压力。对应处理：

1. 切换网络（Wi-Fi 与流量互换）再发一次；
2. 高峰时段（晚上）慢一点属正常，隔几分钟再聊；
3. 长时间无回复时杀掉应用重开再试。

## 二、语音相关

不同版本在语音上的表现差异较大，按你手机里的实际情况对照：

- 截图版本以**文本对话为主**；角色音色可在创建 / 编辑页设置，见[角色创建与音色设置.md](角色创建与音色设置.md)；
- 部分资料提到语音能力在后续版本逐步加入，也有用户反馈早期语音偶有卡顿——你的版本里有没有语音条、好不好用，以实际界面为准；
- 想要语音体验而当前版本没有时，先按[下载与安装教程.md](下载与安装教程.md)确认自己的版本，再留意应用内更新提示。

## 三、聊天记录与隐私边界

口径整理（以应用内「隐私政策」全文为准）：

| 问题 | 口径 |
| --- | --- |
| 记录存哪 | 默认保存在手机本地 |
| 会同步到云端吗 | 仅在你主动开启云同步 / 云备份后 |
| 平台会查看记录吗 | 官方口径为不主动查看聊天内容 |
| 记录会被公开或挪作他用吗 | 官方口径为加密存储、不公开、不作其他用途 |

实操建议：证件、银行卡、住址这类信息不要出现在与 AI 的对话里；换机或卸载前先确认云同步已开启，流程见[注册登录与账号同步.md](注册登录与账号同步.md)。

## 四、要不要花钱

各渠道对付费的说法**不一致**，两种口径都列给你，别只信其中一种：

| 口径 | 说法 | 出处类型 |
| --- | --- | --- |
| 口径 A | 角色挑选、日常对话、情感陪伴等核心功能免费；专属剧情解锁、特殊角色体验等高阶内容轻度付费，不影响基础体验 | 多个渠道的常见问题解答 |
| 口径 B | 采用订阅制，需选周付或月付计划才能使用完整功能，价格因地区而异 | 个别渠道的介绍页 |

两种说法可能对应不同时期、不同版本的应用内政策。动付费之前，以**你手机里应用内实际展示的价格页**为准：先免费把基础角色和剧本玩起来，遇到确实想要的付费项再决定，本文不给具体数字。

不想花钱也能玩得完整：把精力放在免费角色与免费剧本线上，收费项多是外观类或剧情包，按需决定。

## 五、对话重复、角色出戏

- 连续多轮后角色回答开始套话：换个话题方向，或切到新的剧情场景刷新语境；
- 角色回复与设定不符：回编辑页把背景故事写得更具体（场景化的设定比形容词有效，见[角色创建与音色设置.md](角色创建与音色设置.md)）；
- 群聊里角色抢话混乱：减少同场角色数量，两三个角色的群最稳定；
- 界面顶部「内容由 AI 生成」的提示也意味着：回复质量有波动是常态，不满意就换个问法重发。

## 六、其他速查

| 问题 | 处理 |
| --- | --- |
| 应用打不开 / 闪退 | 重启手机；核对系统版本是否过旧；重装（先确认云同步） |
| 想换手机 | 旧设备开云同步 → 新设备装应用登录同账号，见[注册登录与账号同步.md](注册登录与账号同步.md) |
| 安装或解析失败 | 多为下载不完整，按[下载与安装教程.md](下载与安装教程.md)核对 MD5 后重下 |
| 找不到心动卡牌入口 | 点底部小人图标进「我的」再找，玩法见[聊天模式与心动卡牌.md](聊天模式与心动卡牌.md) |
