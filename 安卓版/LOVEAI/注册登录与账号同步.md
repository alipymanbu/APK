## 一、注册方式：邮箱加验证码

LOVEAI 的注册入口是**邮箱验证码**，不需要填一大堆资料：

1. 打开应用，进入登录页；
2. 输入你的邮箱地址，点「获取验证码」；
3. 去邮箱里收验证码邮件，把数字填回应用；
4. 验证通过即完成注册并直接登录。

几点提醒：

- 验证码邮件偶尔会慢几分钟，别连续狂点「重新发送」，间隔一会儿再试；
- 用常驻邮箱（QQ 邮箱、163、Gmail 等都可以），别用一次性邮箱——账号是用来在换设备时找回聊天记录的；
- 各渠道教程的注册口径并不一致：多数写邮箱验证码，也有一部分写手机号加短信验证码——不同版本的注册入口可能不同，以你打开的登录页实际显示为准；
- 部分分发渠道在应用页标注「年满 18 周岁」，恋爱向剧情内容居多，未成年人使用前自行留意。

## 二、验证码收不到怎么办

按顺序排查：

1. **翻垃圾箱 / 拦截列表**：验证码邮件被误判为营销邮件是收不到的最常见原因；
2. **核对邮箱拼写**：多一个字母邮件就发去了别人的邮箱；
3. **等 3~5 分钟**：邮件通道偶尔拥堵，超时后验证码失效的，重新获取一次新的（旧码作废，以最新一封为准）；
4. **换网络**：从流量切 Wi-Fi 或反过来，再点一次获取；手机号注册的可以开关一次飞行模式刷新网络；
5. **手机号侧的拦截**：短信验证码收不到时，翻短信的骚扰拦截 / 黑名单记录，被误拦的验证码移出来；部分安卓手机的「验证码安全保护」功能也会拦，关掉再试；
6. 以上都试过仍收不到，隔天再试或换一个邮箱 / 号码注册。

## 三、换手机 / 重装后，聊天记录怎么找回

聊天记录的保存分两层：

- **默认存本机**：日常聊天记录保存在手机本地；
- **云端同步要自己开**：开启云同步并登录同一账号后，在平板或另一台手机上也能看到之前的对话（官方更新说明中列有该功能，入口以你应用内的设置页为准）。

所以换机 / 卸载重装前，先做一件事：**进设置确认云同步已开启**。没开就先开着等它同步完，再卸载旧设备上的应用；只存在本机的记录一旦卸载就找不回来了。

## 四、隐私口径：记录谁能看到

综合各渠道的公开说明，LOVEAI 的隐私口径是：聊天数据默认保存在本机、开启云端备份需要你主动授权、平台不主动查看聊天内容。这些属于官方承诺，实际条款以应用内「隐私政策」全文为准。

另外注意两点：

- 聊天界面顶部有「内容由 AI 生成，使用时请遵守平台社区公约」的常驻提示——你在对话里发什么，同样受平台规则约束；
- 与 AI 的对话属于生成内容，别把它当成私密性有法律保障的渠道，敏感个人信息（证件号、银行卡、住址）不要往对话里发。

## 五、常见账号问题速查

| 问题 | 处理 |
| --- | --- |
| 换了邮箱想改绑定 | 进「我的 / 个人中心」找账号设置，无入口则联系应用内客服反馈 |
| 登录后记录是空的 | 确认登录的是同一个邮箱账号；再确认旧设备上是否开过云同步 |
| 验证码一直失效 | 邮箱时间与时区不准会导致判超时，校准手机时间后重试 |
