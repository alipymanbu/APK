## 一、创建角色的入口

按第三方教程与界面截图的口径：

1. 登录后进入首页；
2. 点底部导航中间的「+」按钮，选择「创建角色」；
3. 填完设定保存，角色就会出现在你的列表里。

想改的是**已有的角色**时，不走这条路：进那个角色的详情页，选「编辑」即可。部分预设角色是否开放编辑以详情页实际按钮为准。

## 二、能自定义哪些东西

| 定制项 | 说明 |
| --- | --- |
| 名字 | 随便起，注意别带特殊符号（见第四节） |
| 头像 | 可以从相册选；部分版本支持由文字描述生成头像 |
| 性格 | 温柔、活泼、高冷等倾向性描述，写越具体对话风格越贴近预期 |
| 背景故事 | 决定角色「是谁」：身份、经历、与你的关系设定 |
| 音色 | 说话的声音风格，见下一节 |

写背景故事有个实用技巧：与其写「她性格温柔」，不如写「她是你在图书馆认识的学姐，说话轻声，习惯用书里的比喻」——场景化的设定比形容词更能让对话进入状态。

## 三、音色怎么设置

1. 在角色创建 / 编辑页面里找到「音色」选项（部分版本里标注为「声音」或「声线」）；
2. 从预设音色里勾选喜欢的风格，常见分类有温柔、活泼、沉稳等；
3. 点「确定 / 下一步」继续完成其他设定，最后保存，角色即带上这个音色。

补充说明：

- 音调、语速这类细粒度参数是否可调、是否需要更高版本，各版本不一致，以你编辑页里实际给出的滑块和开关为准；
- 截图版本以文本对话为主，部分资料提到语音能力在后续版本逐步加入——你手机里有没有语音条入口，以聊天界面实际显示为准。

## 四、创建失败怎么排查

保存角色失败时，按命中率从高到低查：

1. **名字或设定文本里带了特殊符号 / 敏感词**：把表情、生僻符号去掉，设定文本改用常规表述再保存；
2. **版本太旧**：早期版本创建功能不完整，按[下载与安装教程.md](下载与安装教程.md)更新到当前版本；
3. **网络波动**：保存请求超时会报失败，切稳网络重试；
4. **头像图过大**：换一张常规尺寸的图再试。

## 五、角色能记住你们聊过什么

角色会记住你们之前的对话内容，并在后续互动里引用——上次聊到的事，隔几天再提一句它能接上。这是同一账号下持续对话的体验，重置角色或换新角色不会继承这段记忆。

给角色的设定（背景故事、性格）会长期影响它的说话方式，所以创建时多花两分钟写设定，比事后反复纠正更省事。
