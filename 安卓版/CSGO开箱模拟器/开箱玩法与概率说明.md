## 一、开箱的基本流程

这是一次开箱从头到尾要做的动作：

1. 在主界面的武器箱列表里选一个箱子；
2. 点「探索皮肤」（或箱子页右上角的预览按钮）先看这个箱子里有哪些武器；
3. 点绿色的「打开武器箱」，等转盘停下；
4. 停在哪件物品上就是哪件 —— 你可以选择**保存进库存**或者**出售**换游戏币。

开箱没有次数限制，所有标准武器箱都可以免费开、不用等冷却。开箱界面会实时显示这次开箱的花费与所得物品的价格，方便你算账。

## 二、稀有度与出金概率

模拟器里的物品沿用 CS:GO 的品质层级（军规级 → 受限级 → 保密级 → 隐秘级 → 极其罕见特殊物品），开出什么按层级概率决定，不是每件物品概率均等。按公开的 CS:GO 开箱规则整理，一格品质的分布大致是：

| 品质 | 大致概率 |
| --- | --- |
| 军规级（蓝） | 约 79.91% |
| 受限级（紫） | 约 15.98% |
| 保密级（粉） | 约 3.2% |
| 隐秘级（红） | 约 0.65% |
| 极其罕见（刀/手套） | 约 0.26% |

另外几条规则：

- 「极其罕见特殊物品」与「隐秘级」之间的产出比为 2:5；
- 隐秘级及以下品质里，本级与低一级的产出比为 1:5；同一品质内各件物品概率相同；
- 能产出 StatTrak（暗金）版本的物品，开出暗金的概率为 1/10。

以上是按公开规则整理的参考值，模拟器实际数值以游戏内为准。想验证自己是欧还是非酋，游戏内的全时统计页会分「总体 / 小游戏 / 娱乐场」三块记录你的开箱数据。

## 三、磨损与价格

- 每件皮肤有自己的磨损值（Float），单选模式下点物品页右上角可以显示磨损；
- 皮肤价格会自动对照 Steam 市场显示，出售、押注时都能看到当前估值；
- 开箱过程支持 3D 预览，开出来后可以旋转、缩放查看皮肤细节。

## 四、库存管理

虚拟库存从主界面**侧滑菜单**进入（开箱页右上角也能进），管理动作：

- **长按**物品进入复选模式，批量汰换或删除；
- 单选模式下点右上角查磨损与市场价格；
- 想凑特定皮肤，可以在**市场**里按名称搜索、或按武器类别浏览直接买（用游戏币）；
- **合同（以次换好）**：把 10 件低品质皮肤合成一件更高品质的（可出 StatTrak 版本），是清库存换升级的主要手段。

要注意的口径：模拟器里的皮肤**没有真实货币价值，也不能转入你 CS2 / CS:GO 的真实库存**（官方页面明确声明）。这里的一切数值都是游戏内的收藏与玩法数据。

## 五、箱子从哪来

除经典武器箱外，市场里还有收藏品、贴纸胶囊、纪念品、特价、自定义等类型的箱子/胶囊。箱子既可以开出来，也可以在市场里买卖；每日转盘也能摇到免费箱子与皮肤。更多玩法见 [小游戏与升级玩法指南.md](小游戏与升级玩法指南.md)。
