## 一、从哪进设置

装好并授权后（没拿到权限先看 [下载与安装教程.md](下载与安装教程.md) 第五节），在 AeroScope 主页点【浮窗设置】进入设置界面，改完点【保存】生效。设置里的项目分四类：显示哪些指标、刷新多快、配色主题、日志记录。

## 二、显示哪些指标：按需开关，别堆满

浮窗能显示的指标有：CPU 使用率、帧率（FPS）、内存占用、网络速率（上传/下载）、电量、温度、运行时长。设置里每一项都能单独开启或隐藏 —— 别把所有指标都堆上去，浮窗一长就遮内容、你也看不过来：

| 你想干什么 | 建议只留 |
| --- | --- |
| 看游戏掉帧 | 帧率、温度 |
| 排查「一热就卡」 | 温度、CPU 使用率 |
| 挂下载盯进度 | 网络速率（上传/下载） |
| 后台耗电疑虑 | 电量、温度 |

GPU 利用率这一项也在可选指标里，但部分机型上读不到（与 Root 与否有关，见 [悬浮窗不显示怎么排查.md](悬浮窗不显示怎么排查.md) 的说法并列），读不到就别留着空占位置。

## 三、刷新频率与低耗模式

- **刷新频率**可以自己调。默认秒级刷新，肉眼跟得上数字变化；调得越高，浮窗数据越「实时」，工具本身也越耗电。
- **低耗模式**打开后会降低刷新频率、关掉一部分负载较重的指标，用轻微的延迟换资源占用。你只是偶尔瞟一眼、或者手机本来续航就紧张时，把它打开。

需要连续观察数值变化（比如测一局游戏的帧率波动）时关掉低耗模式，测完再开回来。

## 四、三套主题

设置里预置三套配色：**海雾蓝、曜夜黑、樱花粉**。选哪套纯看场景与个人口味 —— 夜里或深色游戏画面里用曜夜黑，浮窗更不扎眼；白天日常用海雾蓝；樱花粉偏浅色界面。主题只改配色，不影响显示内容与刷新逻辑。

## 五、浮窗手势速查

浮窗本体支持这几个操作，全部在浮窗上直接做，不进设置：

| 手势 | 作用 |
| --- | --- |
| 拖拽 | 移动位置，可拖到屏幕任意一侧 |
| 缩放 | 调整浮窗尺寸 |
| 双击 | 在预设尺寸之间切换 |
| 单击 | 折叠 / 展开浮窗 |

拖到屏幕边缘时会自动限位，不会整个飞出屏幕外；看视频、玩游戏时把浮窗折叠或拖到边角，就不会挡住画面核心区。具体挡不挡，以你手上这个版本的实际表现为准。

## 六、改完不生效怎么办

改了设置但浮窗没变化：先确认你点了【保存】，再把【启动性能浮窗】关掉重开一次。仍不生效、或者浮窗整个不出现，走 [悬浮窗不显示怎么排查.md](悬浮窗不显示怎么排查.md)。
