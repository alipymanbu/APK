## 一、点了「启动性能浮窗」但屏幕上什么都没有

按出现频率从高到低查这四处：

1. **悬浮窗权限没给**。回系统设置搜「显示在其他应用上层」（或「悬浮窗」），确认 AeroScope 这一项是开着的。首次启动只弹一次授权，当时点了拒绝，之后就得手动去设置里开（步骤见 [下载与安装教程.md](下载与安装教程.md) 第五节）。
2. **权限被系统收回了**。部分厂商系统在你清理后台、省电优化之后会把悬浮窗权限一并关掉，之前能用、突然不显示多半是这个。去权限页看一眼开关是否还亮着。
3. **没真正启动**。回 App 主页确认【启动性能浮窗】处于开启状态，改完设置要先点【保存】再重启浮窗（见 [浮窗设置与主题怎么调.md](浮窗设置与主题怎么调.md) 第六节）。
4. **浮窗被折叠了**。单击浮窗会折叠，先在屏幕边缘找找有没有折叠起来的小条。

## 二、浮窗出现一会儿就消失

典型原因是系统把它当成后台应用杀掉了。你可以：

- 在系统的「最近任务」列表里把 AeroScope 上锁（部分系统叫「锁定后台」），不让一键清理把它划掉；
- 到系统设置的电池 / 省电选项里，把它对这个应用的限制改成「无限制」（各品牌叫法不同，找电池或应用耗电管理那一项）；
- 不用的时候手动把【启动性能浮窗】关掉，用的时候再开，避免长期驻留。

## 三、需要 Root 吗：两种说法并列

关于 Root，公开渠道的口径不一致，两边都摆出来，你自己对照：

| 说法 | 出处类型 | 含义 |
| --- | --- | --- |
| 无需 Root，普通安装即可用核心监控功能 | 多个独立下载页一致 | 装完就能看 CPU、帧率、内存、网络、电量、温度 |
| 需要获取 Root 才能正常使用、可看 GPU 占用等深层数据 | 个别简介页 | 只有给 Root 才有全部数据 |

可执行的结论是：**先不给 Root 直接用** —— 核心指标（CPU、帧率、温度这些）在非 Root 下就能显示；若某一项（最常见是 GPU 利用率）一直空着，而你又确实需要它，再考虑你自己设备上的 Root 方案。是否 Root 是你对自己设备的决定，与工具本身能否安装运行无关。

## 四、某几项指标一直空着 / 数值不更新

- **个别深层数据（如 GPU 利用率）空着**：大概率与上面的 Root 口径有关，非 Root 下读不到属正常现象。
- **整块浮窗数字都不动**：确认没开低耗模式（它会降低刷新频率），再把刷新频率调回默认；仍不动就关掉浮窗重开一次。
- **网络速率不动**：确认手机当时确实在收发数据；挂个下载试一下就有数了。

## 五、装不上 / 装完闪退

- **安装按钮置灰或被拦**：系统版本低于包内声明的下限（登记为安卓 5.2 以上、公开页标注 Android 8.0+，以你设备实际为准）、存储不足、或厂商纯净模式拦截 —— 清空间、放行后重试。
- **装完闪退**：先重启手机再打开；不行就重新从 [AeroScope 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4e82b320c435) 转存一次，按 [下载与安装教程.md](下载与安装教程.md) 第三节核对包名与 MD5，排除下载环节把文件弄坏的可能。
