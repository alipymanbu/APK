## 一、界面就两个标签页

打开应用后，主界面分两块：

- **录音标签**：录音界面，放着你录完之前要用的所有东西；
- **录音列表标签**：查看已保存的录音，剪辑、共享、删除都在这里做。

录音界面上能看到的控件：设定菜单、**麦克风测试**、单声道/立体声音质开关、时间计数器、开始键、停止键、回放键，以及**音质选项**。第一次用建议先花十秒做个麦克风测试，确认进来的声音正常再正式录。

## 二、开始、暂停、停止的手势

这个应用的操作手势有一个特点：**部分动作是长按，不是点按**。

| 动作 | 手势 |
| --- | --- |
| 选择音质选项 | 长按该选项 2 秒 |
| 开始录音 | 点按开始键 |
| 暂停录音 | 长按停止键 2 秒 |
| 停止录音 | 长按停止键 2 秒 |
| 回放刚录完的这条 | 点按回放键 |

录音时长由时间计数器显示，录音本身**没有时长限制**，录一场两小时的会议也没问题。中途暂停不会分段保存，继续录还是同一条文件。

## 三、单声道还是立体声

录音界面上可以在单声道与立体声之间切换，怎么选取决于内容：

| 场景 | 建议 |
| --- | --- |
| 会议、课堂、口述备忘 | 单声道足够，文件也更小 |
| 采访、现场音乐、需要分辨左右方位的声音 | 立体声 |
| 接了外接立体声麦克风（如索尼 STM10） | 立体声，否则浪费了硬件 |

单声道只录一路信号，人声类内容完全够用；立体声分左右两路，适合表现空间感。

## 四、WAV 与 MP4：音质选项决定文件格式

选音质时要注意一件事：**你选的音质选项决定了最终保存的文件格式**。

- 选高音质（无损类）选项，保存为 **WAV** 文件；
- 选压缩类选项，保存为 **MP4** 文件。

两种格式的实际差别体现在文件体积和兼容性上，导出和传电脑时的注意事项见 [录音文件保存位置与导出.md](录音文件保存位置与导出.md)。录完想改格式只能重录，应用里的处理功能（见 [录音剪辑与降噪.md](录音剪辑与降噪.md)）不提供格式转换，所以正式录之前先把音质选项定下来。

## 五、录完先回放一遍

停止录音后点回放键就能听刚录的这条。建议每次重要录音都当场回放几秒确认：一是确认没录成空音（麦克风权限被拦时最常见，见 [常见问题排查.md](常见问题排查.md)），二是确认音量合适。 Xperia 用户如果接了外接麦克风，回放还能帮你判断左右声道有没有接反，相关设置见 [Xperia外接麦克风搭配.md](Xperia外接麦克风搭配.md)。
