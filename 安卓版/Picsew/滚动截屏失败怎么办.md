# 滚动截屏失败怎么办

> 本篇专门处理「滚动截屏拼出来的长图断层、错位、重复、半路停下」这类问题：先按现象对号入座，再动手重试。

## 一、先对照现象找原因

滚动截屏靠的是「相邻两帧画面之间的重叠区域」找拼接点，所以凡是破坏画面连续性的因素都会让它失败。这一规律对各类拼接工具通用：

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 拼接处错位、重复一大段 | 滑动过快，相邻两帧之间没有重叠 | 放慢速度重录，匀速朝一个方向滑 |
| 长图某段内容缺失或发虚 | 页面懒加载没完成，截到的是空白占位 | 先把页面完整滚到底让内容加载，再回起点重新截 |
| 拼到一半自动停了 | 画面里有悬浮窗、弹幕、轮播图、正在播放的视频等动态内容 | 暂停或关闭动态元素，退出横屏，再重新截 |
| 某些页面怎么截都错位 | 吸顶导航栏、浮动广告反复出现在帧与帧之间 | 截前关掉弹窗；仍不行就改用分段截图手动拼（见下） |
| 银行、支付类应用里截不了 | 应用出于安全考虑禁止截屏录屏 | 无解，属应用自身的限制 |

## 二、动手前先做的三件事

1. **先把页面加载完整**：从头到尾滚一遍，等图片、评论这类懒加载内容都出来，再回到起点开始正式截——这是性价比最高的一步，能消掉大半失败；
2. **清理画面里的干扰**：关掉悬浮球、弹窗，暂停视频和动图；滚动过程中别去点其他按钮、别切应用；
3. **保持匀速、单向**：不要快滑、不要来回翻，滑到想结束的位置停手即可。

## 三、实在拼不上：退回手动拼接

对结构复杂、怎么截都出错的页面（论坛长帖、表格密集页），与其反复重试，不如换思路：

1. 用系统普通截图把页面分段截好，**相邻两张之间保留一两行的重叠**，方便对位；
2. 进 Picsew 的「长图拼接」，把这些分段截图按顺序选进去；
3. 自动对齐不理想时，手动调整每张图的位置和裁剪范围，长按拖动交换顺序；
4. 保存成一张完整长图。

分段手动拼多花几分钟，但每一处接缝都由你确认，复杂页面的成功率反而更高。各入口的具体位置见 [长截图与拼接方法.md](长截图与拼接方法.md)；拼完保存不到图片的话，先查权限，见 [常见问题与注意事项.md](常见问题与注意事项.md)。
