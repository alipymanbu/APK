## 一、首屏功能入口一览

打开应用后能直接看到这些入口（2.2.6 版本界面）：

| 入口 | 干什么用 |
| --- | --- |
| 图片处理 | 编辑、多格切图、长图拼接 |
| 台词拼接 | 电影台词图 |
| 海报制作 | 电商海报、公众号封面、名片、营销图 |
| 网页截图 | 粘贴网址生成长图 |
| 视频剪辑 | 变速、加音乐、倒放、拼接 |

## 二、基础编辑

在图片处理里选一张图后，可以做的常规操作：

- 裁剪、旋转、翻转、缩放；
- 加滤镜、贴纸、文字、涂鸦；
- 换背景色或自定义背景图；
- 压缩照片体积——发群、上传有大小限制时用得上。

贴纸风格比较多（贱萌、可爱、街拍、清新一类），也可以直接加 emoji 表情。旋转、翻转、缩放之外，长按拖动可以交换图片位置，多图排版时常用。

## 三、抠图与换背景

官方介绍里把「抠图、切换背景」列为不要求掌握复杂修图技术的能力，实际用途集中在两类：

1. 商品图 / 人物主体抠出来，垫一块纯色或自定义背景，做名片、海报底图；
2. 把主体挪到另一张背景图上，做餐饮菜单图、新媒体配图。

抠完的边缘是否符合你的要求，建议拿一张不重要的图先试一次——抠图效果和主体轮廓复杂度直接相关，没有哪个工具对所有图都干净。换背景时挑与主体颜色差异大的背景色或背景图，轮廓上细小的瑕疵最不显眼。

## 四、多格切图（九宫格）

把一张大图切成多个方格，对应社交平台发九宫格的用法：选图 → 多格切图 → 按提示保存各格。切之前先确认原图够大，切出来的每格清晰度取决于原图分辨率。

## 五、排版与海报

海报制作入口提供布局和模板，配合上面的抠图、贴纸、文字，覆盖官方介绍里的几类场景：电商海报、营销长图、公众号封面、名片、新媒体配图、餐饮美食营销图。模板能改背景色和素材，不是只能套死。

## 六、GIF 与视频剪辑

- **GIF**：选几张静态照片，按顺序合成一张动图；
- **视频剪辑**：对视频做变速、加音乐、倒放、拼接，完成后单独保存。

这两块和图片处理是分开的入口，处理视频时注意手机剩余空间——视频文件的体积比图片大得多，导出前先看一眼存储余量。

装了 2.2.6 之外更高版本的话，入口可能有增减，以实际界面为准。安装来源见 [下载与安装教程.md](下载与安装教程.md)。
