## 一、先确认你找的是哪个 Picsew

搜「Picsew」会同时撞到两个应用，装之前先对一下：

| | 本文讲的安卓版 | 同名的 iOS 版 |
| --- | --- | --- |
| 平台 | Android 手机 | iPhone / iPad |
| 包名 | `com.kun.picsew` | App Store 独立分发 |
| 开发者 | 深圳市全美联合科技有限公司 | 另一位独立开发者 |
| 中文名 | 常写作「Picsew长拼图」「picsew长截图」 | Picsew |

两者名字相同、平台不同、开发者不同，功能有重叠（都是长截图 / 拼图类），但界面和功能清单并不一致。安卓手机用户请认准包名 `com.kun.picsew`。

## 二、安装前先核对这几项

下面是这份安装包自身的信息，与网上宣传的最新版本号可能不是一回事：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.2.6 |
| 安装包大小 | 206.84M |
| 包名 | `com.kun.picsew` |
| MD5 | `46FEFC18B8F95F415DC8649B983B0B14` |
| 语言 | 简体中文 |
| 厂商 | 深圳市全美联合科技有限公司 |

系统要求：采集记录里标注为支持安卓 5.2 以上，实际以你手机安装时的检测为准；近几年主流安卓机型一般都能装。

核对方法（可选但推荐）：把下载得到的 apk 文件用 MD5 工具算一次哈希，和上表比对。电脑上用 PowerShell 执行：

```powershell
certutil -hashfile "Picsew_v2.2.6.apk" MD5
```

输出的哈希值与表里一致（不分大小写），说明文件没下坏。同一版本号在不同渠道流传的包哈希可能不同，以你实际拿到的那份为准。

## 三、获取安装文件的步骤

1. 打开 [Picsew 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c1d95131d70b)；
2. 选择文件**转存到自己的夸克网盘**（需要登录夸克账号）——先转存再下载，别停留在在线预览页；
3. 在夸克网盘 App（或网页端）里把文件下载到手机；
4. 得到 `Picsew_v2.2.6.apk`，进入下一步安装。

## 四、安装步骤

1. 在手机文件管理器里找到刚下载的 apk，点它；
2. 系统弹出「是否允许安装未知来源应用」时，按系统提示允许（安卓 8 以上是按「来源应用」逐个授权，不用全局放开）；
3. 等安装完成，点打开；
4. 首次启动会请求存储相关权限——拼接和保存长图都要读写相册，拒绝的话核心功能用不了。

## 五、装不上时先查这几件事

| 现象 | 先查什么 |
| --- | --- |
| 提示「解析失败 / 安装包已损坏」 | 用第二节的 MD5 方法核对文件是否下完整；不完整就重新下载 |
| 提示签名冲突 | 之前装过另一个签名的同名应用，先卸载旧版再装 |
| 空间不足 | 206.84M 的安装包在安装时还要额外的解压空间，留出至少 1GB 再试 |
| 被手机自带的安全组件拦下、提示风险 | 这是对非应用商店来源安装包的一般性提示；是否继续由你自行判断，可先核对接第二节确认文件无误 |
