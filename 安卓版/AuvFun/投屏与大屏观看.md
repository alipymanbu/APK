# AuvFun 投屏到大屏观看教程

> 本篇讲怎么把 AuvFun 正在看的番剧投到电视上，以及搜不到设备、连接失败时怎么排查。
> **相关文档**：[换源与播放画质.md](换源与播放画质.md) · [常见问题排查.md](常见问题排查.md)

AuvFun 自带应用内投屏，不用另装工具。前提只有两个：手机和电视连着同一个 Wi-Fi，电视端的投屏 / 多屏互动开关处于打开状态。

## 一、三步投出去

1. 搜索或从收藏进入想看的番剧，进到播放页面。
2. 点播放界面的投屏图标。
3. 等列表刷出你的电视，点选连接；连上后播放画面就到了大屏上。

「同一个 Wi-Fi」是硬前提：路由器把 2.4 GHz 和 5 GHz 分成两个名字的，手机和电视要连同一个名字 —— 一个连 2.4、一个连 5，就算不在一个网里。

## 二、搜不到设备，按这张表查

| 现象 | 排查 |
| --- | --- |
| 列表里始终没有电视 | 两端连同一 Wi-Fi、同一频段；到电视设置里打开「投屏」「多屏互动」「无线显示」这类开关（各品牌叫法不同） |
| 之前能投，现在搜不到 | 重启电视和路由器，重新打开 AuvFun 的投屏搜索 |
| 连上就断、画面卡顿 | 手机离路由器近一点；5 GHz 频段穿墙差，隔了两堵墙就换 2.4 GHz 试试 |
| 系统提示权限不足 | 到系统设置里给 AuvFun 重新授予「附近设备」「WLAN」权限，部分系统升级后会收回这类授权 |

## 三、反复失败的两条替代路

1. **系统级镜像投屏**：从手机快捷开关里直接投整个屏幕，绕开应用内的投屏协议，兼容性问题最少。代价是费电，而且通知横幅也会被投出去，追番前先开勿扰。
2. **换播放设备**：电视端协议不支持时，用平板或另一台手机接着看也是一条路 —— 进度跟账号走，换设备能从上次的位置续上。

## 四、投出来也卡

投屏卡顿多半是源头就卡：先在手机上直接播放确认流畅度。手机上就卡的，先按 [换源与播放画质.md](换源与播放画质.md) 换条线路；手机上流畅、投出来才卡的，才是网络或电视端的问题。应用整体的异常排查见 [常见问题排查.md](常见问题排查.md)。
