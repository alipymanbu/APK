AuvFun 是一款面向二次元用户的安卓追番应用，把多条番剧播放线路聚在一个客户端里，手机竖屏使用。本篇按「确认版本 → 获取安装包 → 安装 → 装不上再排查」的顺序走一遍。装好后建议先登录账号，流程见 [注册登录与转正答题.md](注册登录与转正答题.md)。

## 一、先确认版本信息

| 项目 | 信息 |
| --- | --- |
| 版本 | 2.1.2 |
| 安装包大小 | 约 40.28 MB |
| 包名 | com.auvfun |
| 系统要求 | Android 5.2 以上（以安装包标注为准） |
| 文件 MD5 | 96198D879AE5758CD9EB5EBEBC6F8CB2 |

上表是本篇所对应安装包的实际情况。AuvFun 迭代较快，官方会不定期发布新版本：装好后可以在应用内「我的」页面下拉找到「版本更新」入口检查升级，也可以去官网 [www.auvfun.com](https://www.auvfun.com) 拿最新安装包，站内还带有「软件教程」与常见问题板块，遇到没写进本文的问题可以先去那里翻。

## 二、安装包从哪获取

两条常见渠道，任选其一：

1. **官网下载**：打开 [www.auvfun.com](https://www.auvfun.com)，首页点「立即下载」，浏览器会直接拉取 apk。手机浏览器下大文件偶尔中途断掉，断了重下即可。
2. **AuvFun 安装文件资源（夸克网盘）**：把 [https://pan.quark.cn/s/c5728109e844](https://pan.quark.cn/s/c5728109e844) 转存到自己的夸克网盘，再用客户端把 apk 下到手机安装。适合手机浏览器下载不稳定，或者想在电脑上先下好再传手机的情况。

无论走哪条渠道，拿到 apk 后都可以顺手核对一下 MD5，对得上说明文件完整。

## 三、安装步骤

1. 把 apk 放到手机存储里（走网盘渠道直接在手机上下载则跳过这步）。
2. 在文件管理器里点击这个 apk，系统会弹出安装确认。
3. 首次安装第三方 apk 会提示「禁止安装未知来源应用」，按提示到设置里允许对应应用（浏览器 / 文件管理器 / 网盘客户端）安装。不同品牌的入口叫法不一样，一般在「设置 → 安全」或「设置 → 更多设置」附近。
4. 部分品牌（如小米）的系统自带「纯净模式」或安装拦截，被拦时按系统提示到对应开关放行，装完可以再关回去。
5. 回到安装界面点「安装」，进度走完后点「打开」。

## 四、安装失败按这个顺序排查

| 现象 | 先做什么 |
| --- | --- |
| 提示解析包错误 / 文件损坏 | 重新下载一遍安装包，下载中断最容易出这种问题；必要时核对 MD5 |
| 提示存储空间不足 | 清出至少 1 GB 空间再装（安装包 40 MB，但安装与首次运行还需要临时空间） |
| 点了没反应 / 一闪而过 | 确认系统版本满足 Android 5.2 以上；重启手机再试 |
| 提示与已安装应用冲突 / 签名冲突 | 手机里装过同包名但来源不同的版本（官方把签名冲突列为安装失败的常见原因之一），先卸载旧版再装 |
| 一直被系统拦截 | 关闭「纯净模式」/ 安装拦截，或到「外部来源应用下载」里给对应应用授权 |

## 五、iOS 设备能用吗

装上之后如果打开就闪退、黑屏，属于运行问题，去 [常见问题排查.md](常见问题排查.md) 对照处理；想直接开始追番的，跳到 [追番操作入门.md](追番操作入门.md)。
