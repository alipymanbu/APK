# AndroidIDE 常见问题与解决方法

> 汇总你实际用 AndroidIDE 会撞上的坑：装不上、装不了工具、编译失败、下载慢各怎么办。

## 一、安装 APK 时报签名冲突

**现象**：覆盖安装时系统提示签名不一致、安装失败。

**原因**：F-Droid 打包的版本与 GitHub 发布的版本**签名不同**，两者不能互相覆盖安装（官方在 v2.7.1-beta 的发布说明里专门警告过这一点）。

**处理**：先卸载旧版再装新版，别指望覆盖。卸载会清掉构建工具和项目文件，装回后按 [构建工具安装与配置](构建工具安装与配置.md) 重装一遍环境。

## 二、`idesetup: command not found`

**现象**：终端里敲 `idesetup -c` 提示找不到命令。

**处理**：手动把脚本下载到系统路径再执行：

```bash
wget https://raw.githubusercontent.com/AndroidIDEOfficial/androidide-tools/main/scripts/idesetup -O $SYSROOT/bin/idesetup && chmod +x $SYSROOT/bin/idesetup
```

这条命令与官方文档给出的补救方式一致，装完再跑 `idesetup -c`。

## 三、Gradle 同步失败：项目 AGP 版本太旧

**现象**：导入项目后同步直接报错，日志里能看到 Android Gradle Plugin 版本相关的异常。

**判据**：AndroidIDE **要求项目使用 AGP 7.2.0 及以上**（v2.6.0 起已支持到 AGP 8.2.x）。项目里的 `com.android.tools.build:gradle` 版本低于 7.2.0 就过不去。

**处理**：把项目在电脑端升到 AGP 7.2+ 再同步。这是硬门槛，改设置绕不过去。

## 四、想用 NDK：装不了

**现象**：在终端里跑 `SDK Manager` 想装 NDK，找不到或装不上。

**原因**：官方没有为安卓平台构建 NDK，`SDK Manager` 能装的只限本身就支持安卓的那部分工具。C/C++ 项目在 AndroidIDE 里没有官方支持，别在这上面耗时间。

## 五、编译时 Gradle 进程被杀 / 内存不够

**现象**：同步或编译进行到一半突然中断，日志里是 Gradle Daemon 消失或进程被杀。

**判据**：官方要求至少 **1.5GB~2GB 空闲 RAM** —— 是「空闲」，不是整机内存。手机开了大量后台、或机型本身 4GB 以下时，系统会优先杀掉占内存的编译进程。

**处理**：编译前清掉后台应用；在 IDE 设置里把能关的内存大户（如日志服务）关掉；换内存更大的设备是根本解法。

## 六、构建工具或依赖下载到一半失败

**现象**：`idesetup` 卡住、超时，或 Gradle 拉依赖时反复失败。

**判据与处理**：

- 首次安装**必须联网**且官方建议 WiFi，移动网络下中断概率更高 —— 换到稳定的 WiFi 重试；
- 下载源在 GitHub 与 Gradle 官方源，**国内有用户反馈直连慢甚至失败**（多见于构建工具与依赖仓库），网络高峰期重试、错峰安装更省事；
- 存储空间先自查：基础安装就要约 1GB，完整环境官方要求留出 **4GB 可用空间**，满了同样表现为「下载失败」。

## 七、项目还在维护吗

截至 2026-09，**AndroidIDE 官方仓库首页挂着「THIS PROJECT IS NOT MAINTAINED ANYMORE」的警示**，即项目已停止维护。这对你意味着：

- 能装到的最新版本就是 v2.7.1-beta 这类已发布版本，别指望有修复新问题的版本更新；
- 遇到 bug 先翻 [Issues](https://github.com/AndroidIDEOfficial/AndroidIDE/issues) 历史记录，多半有人报过、讨论里有可行的绕法；
- 已装好的环境不会因为停维护而失效，Gradle、JDK、SDK 都是独立下载的，能继续用。

这条结论以官方仓库当时显示为准；日后若官方页面有变化，以仓库为准。
