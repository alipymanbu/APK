# AndroidIDE 新建项目与编译出APK

## 一、开工前的两个前提

这篇默认你已经完成两件事：AndroidIDE 装好了（见 [下载与安装教程](下载与安装教程.md)），构建工具也装完并用 `java --version` 验证过（见 [构建工具安装与配置](构建工具安装与配置.md)）。缺任何一件，下面的步骤都会在某一步停住。

另外先明确一个项目门槛：**项目用的 Android Gradle Plugin（AGP）必须是 7.2.0 或更高**，老项目要先在电脑上把 AGP 升上来才能导入。带 C/C++ 的工程用不了 —— 官方没有为安卓构建 NDK，`SDK Manager` 里也装不了这类工具。

## 二、创建项目

1. 在 AndroidIDE 主界面点 `Create project`。
2. 选一个项目模板（有 Java / Kotlin、带不带 AndroidX 等组合）。
3. 填应用名与包名，点 `Create project`，工程会自动打开。

想拿现成代码练手的话，你也可以不新建，直接从 Git 克隆一个仓库进来。

## 三、第一次同步要等多久

工程打开后 IDE 会立刻跑 Gradle 同步 —— 它要拉 Gradle 发行版和项目依赖，好给编辑器提供补全与跳转信息。**第一次构建按官方说法可能要 10~15 分钟**，之后再编译只增量下载新依赖。

同步期间从底部上滑拉出面板，能看到 Gradle 输出的实时日志；同步成功会有明确的配置完成提示。网络慢或内存不够时最容易在这一步失败，排查路径在 [常见问题与解决方法](常见问题与解决方法.md)。

## 四、编译并安装

同步成功后：

1. 点工具栏的 `Quick run` 按钮，它实际执行的是 `assembleDebug` 任务，编 debug 变体的包；
2. 底部面板照旧输出构建日志，出错就从最后一段错误往回看；
3. 构建成功会弹安装提示 —— 此时需要用到首次启动时授的「安装应用」权限（安卓高版本会再拦一次，去系统设置里允许 AndroidIDE 安装未知应用即可）；
4. 装完可直接选择打开，跑起来的就是你刚写的那个应用。

## 五、看运行日志

应用跑起来后，IDE 自带的 Log reader 会实时显示你这个应用打出来的日志，不用另开 `adb logcat`。写代码、编译、看日志这三件事都能在手机上闭环完成 —— 这也是它和「只能写不能编」的代码编辑器最大的区别。
