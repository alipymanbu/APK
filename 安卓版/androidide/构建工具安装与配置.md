## 一、APK 装好 ≠ 环境装好

你装到手机上的 AndroidIDE 本体只是编辑器和界面，真正用来编译的东西 —— JDK、Android SDK、Gradle 所需的工具包 —— 都要在应用里**再下载一次**。官方文档把这一步叫「安装构建工具」，没装它之前你只能写代码，点编译不会有反应。首次安装全程需要网络，且下载量不小，建议连 WiFi 并一次性装完。

## 二、三种安装方式怎么选

| 方式 | 适合谁 | 怎么触发 |
| --- | --- | --- |
| GUI 自动安装 | 绝大多数人，第一次装就选它 | 首次启动的引导页里配置好选项，点开始即可（v2.7.0-beta 起提供） |
| `idesetup` 脚本 | 想自定义 SDK 版本、JDK 版本 | 在应用内终端执行 `idesetup -c` |
| 完全手动 | 已经下好工具包、或要反复重装 | 对照官方[手动安装文档](https://docs.androidide.com/tutorials/manual-installation.html)自己摆放文件 |

GUI 方式本质上就是在终端里替你跑了 `idesetup` 脚本，所以两条路装出来的东西一样。

## 三、用 `idesetup` 安装

在应用的终端里执行：

```bash
idesetup -c
```

`-c` 表示连同命令行工具一起下载 Android SDK。脚本会先打印一份配置摘要（安装目录、SDK 版本、JDK 版本），核对无误后输入 `y` 回车确认；中途还会再问一次是否安装 JDK 17，同样输 `y`。可选参数（`idesetup -h` 可随时查看）：

```text
-i   安装目录，默认 $HOME
-s   要下载的 Android SDK 版本
-c   连同命令行工具一起下载 SDK
-j   选 JDK 17 还是 JDK 21（默认 17）
-m   清单文件地址，默认取 androidide-tools 仓库的 manifest.json
```

官方的建议是**保持默认配置**，除非你确知自己要哪个 SDK 版本。如果终端报 `bash: idesetup: command not found`，手动补装脚本即可：

```bash
wget https://raw.githubusercontent.com/AndroidIDEOfficial/androidide-tools/main/scripts/idesetup -O $SYSROOT/bin/idesetup && chmod +x $SYSROOT/bin/idesetup
```

## 四、装完验证

安装结束后执行：

```bash
java --version
```

能打印出 `openjdk version "17-internal"` 一类的输出就说明 JDK 就位了。验证过后**建议把 AndroidIDE 整个重启一遍**，编辑器的语言服务与构建配置才会按新环境重新加载。

之后如果想换 JDK 版本（比如已装了 21），在 IDE 的 `Preferences → Build & Run → JDK version` 里切换，改动同样要重启才生效（该选项自 v2.7.1-beta 起提供）。

## 五、卡住了怎么办

构建工具下载依赖 GitHub 上的工具仓库，网络不稳时会中断或极慢；遇到报错先看 [常见问题与解决方法](常见问题与解决方法.md)，那里按「下载失败」「内存不足」「空间不够」分别给了判据与处理方式。工具装齐之后，就可以去 [新建项目与编译出APK](新建项目与编译出APK.md) 出第一个包了。
