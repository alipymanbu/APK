## 一、先确认设备能不能跑

AndroidIDE 是在安卓手机、平板上直接写代码并编译出 APK 的 IDE，它对设备的要求比一般应用高，官方文档给出的底线是这三条：

| 项目 | 官方要求 |
| --- | --- |
| CPU 架构 | `arm64-v8a`（64 位 ARM）、`armeabi-v7a`（32 位 ARM）、`x86_64` 三选一 |
| 可用内存 | 编译时要跑 Gradle，建议至少留出 **1.5GB~2GB 空闲 RAM**，否则编译进程容易被系统杀掉 |
| 存储空间 | 至少 **4GB 可用空间**；只装基础构建工具（不含依赖与 Gradle 发行版）约占用 1GB |

另外两条也别忽略：**首次安装构建工具必须联网**，官方建议用 WiFi；x86_64 架构是 v2.7.0-beta 起才支持的，模拟器和 Windows 子系统（WSA）也能装。系统版本方面以官方发布页当时显示为准。

## 二、安装包从哪拿

官方给出的可信渠道有三个：官网 [androidide.com](https://androidide.com/)、[GitHub Releases](https://github.com/AndroidIDEOfficial/AndroidIDE/releases)、[F-Droid](https://f-droid.org/packages/com.itsaky.androidide/)，三处都是免费下载，选一个就行。

如果你手边没条件访问官方渠道，本篇头部的 [AndroidIDE 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cc7394f1f49b) 里存的是同一款应用的安装包，事实如下：

- 版本：`v2.7.1-beta`
- 包名：`com.itsaky.androidide`
- 大小：80.45M
- MD5：`5D6BBA2EF6DFD8ED62508A4706BE37FC`

拿到包后可以自己算一遍 MD5，与上面这串对得上才说明文件完整、没下残。

## 三、安装步骤

1. 把 APK 文件拷到手机上（或用文件管理器直接点开网盘里下载好的包）。
2. 首次安装第三方来源的 APK，系统会要求你允许「安装未知应用」，给你的文件管理器或浏览器授一次即可。
3. 点击 APK 按提示安装，装完先别急着打开 —— 构建工具还没装，应用内暂时干不了编译的活。
4. 打开 AndroidIDE，按引导逐页授权（见第五节）。

## 四、不同来源的包不能互相覆盖

同一个版本，F-Droid 打出来的包和 GitHub 发布的包**签名不一样**：你在 GitHub 版之上覆盖安装 F-Droid 版（或反过来）会直接安装失败，系统只允许先卸载再装。卸载会丢掉已装好的构建工具和项目文件，所以第一次装就先选定一个渠道，之后更新也走同一个渠道。这条踩坑详情见 [常见问题与解决方法](常见问题与解决方法.md)。

## 五、首次启动要授的权

打开应用后的引导页会依次找你要三个权限，缺一个后面都会卡：

- **存储**：读写项目文件，没有它连工程目录都建不出来；
- **安装应用**：编译出 APK 后要调起系统安装器，没授权时编译成功也装不上；
- **通知（Android 13 及以上）**：`POST_NOTIFICATION` 权限，用来在后台构建时展示进度通知。

授权完成后就进入构建工具安装界面了，那一步怎么走、卡住了怎么办，接 [构建工具安装与配置](构建工具安装与配置.md)。
