## 一、先核对：记录到底在不在

官方给的查证入口是「My」标签页右上角的代币图标，点开能看到代币余额、购买记录和已解锁的话数列表。先来这里确认是「真的没了」还是「换个地方放着」。

## 二、官方列出的六种「找不到」

| 情况 | 说明 |
| --- | --- |
| 把免费话当成了解锁话 | 免费话本来就能读，不代表花过代币；以代币图标里的历史为准 |
| 登录了另一个账号 | 换一种登录方式（比如原邮箱注册、后来点 Google 登录）可能生成了新账号；用原来的方式重新登录 |
| 安卓与 iOS 代币不互通 | 官方明确两个平台的代币不能互用，换系统前把代币用掉 |
| 应用语言与购买平台不一致 | 在英文平台买的代币，切到其他语言平台就看不见；把内容语言切回购买时的语言 |
| iOS 游客（未登录）购买 | 不挂账号的购买只存在本机，登出即丢，客服也难兜底 |
| 支付没完成 | 付款流程中断时代币不会到账，但钱也没扣；有争议找 Google Play 或 Apple 处理 |

## 三、未登录时买的东西最危险

官方帮助中心的口径很直白：未登录状态下购买的代币和内容，会在你登录账号或卸载应用时被删除，删了无法恢复，也不能转移到别的账号。所以花钱之前，先确认自己处于登录状态。

## 四、不花钱拿代币的正规途径

- **Coin Hunter 任务**（官方功能）：入口在首页右上角，或读到需要代币的地方；里面有 Adison、Playtime 两个任务页，按任务说明完成后代币会打进「My Coins」，有应用通知到账提醒。官方列出的开放地区包括美国、加拿大、法国、印尼、台湾、泰国、印度、马来西亚、菲律宾等，以官方页面为准。
- **官方活动**：阅读任务、节庆活动会不定期送免费代币，规则与有效期以活动页标注为准。
- **兑换码**：不定期有 Code Promo 活动，入口在代币商店（有用户整理的口径）；码有时效，以官方发放时的说明为准。

## 五、都试过还是找不到

官方帮助中心「Coins and Unlocking Episodes」分类下有逐条的对应文章；按上面六种情况核对过仍异常，就提交工单给社区支持团队。解锁话数「又变回上锁」也属于这一类问题，同样先从账号与语言两个变量查起。
