## 一、先记住一句话

Slidebox 里「丢进回收站」和「彻底删除」是两个完全不同的动作：前者随时能撤回，后者**不可恢复**（官方 Android FAQ 明确说明，删掉的照片无法找回）。批量清理时真正要盯的是后者。

## 二、删除的三步流程

1. **上滑 → 进回收站**：只是在 Slidebox 里标记为「已丢弃」，照片不再出现在「未整理」中，可点回收站图标查看。此时照片在系统相册里的状态不变（未应用更改前）。
2. **撤销 → 随时反悔**：还在整理阶段时，用撤销把照片放回「未整理」，等于这一步没发生过。
3. **清空回收站 → 永久删除**：执行后照片从设备上彻底删除，Slidebox 官方 FAQ 写明**无法恢复**，系统相册的回收站也不会替你兜底。

注意区分一个平台差异：iOS 端删除后系统相册有 30 天「最近删除」可捞，**安卓端没有这层保护**——安卓上以「彻底删除即没了」为准（官方 FAQ 口径，截至 2026-09）。

## 三、相册的增删改怎么同步

Slidebox 直接操作你手机自带的相册，改动规则如下（来源：官方 Android FAQ）：

| 你的操作 | 结果 |
| --- | --- |
| 在 Slidebox 里新建相册 | 系统相册里同步出现该相册 |
| 把照片归入相册 | 照片在系统相册里被移动过去 |
| 在 Slidebox 里重命名相册 | 系统相册里同步改名 |
| 从 Slidebox 移除一个已有相册 | 系统相册**不动**，里面的照片在 Slidebox 里重新算作「未整理」 |
| 删除相册里的某张照片 | 照片从设备**永久删除** |
| 在系统相册里直接改（不经 Slidebox） | Slidebox 可能**感知不到**，两边会不同步 |

最后一行是最容易踩的坑：**已经在 Slidebox 里建过或加过的相册，改动尽量在 Slidebox 里做**，否则照片和相册容易对不上号。

## 四、误操作的挽回窗口

| 情形 | 能否挽回 | 怎么做 |
| --- | --- | --- |
| 刚上滑，还没应用更改 | 能 | 撤销，照片回「未整理」 |
| 已进回收站，未清空 | 能 | 打开回收站恢复，照片回到「未整理」 |
| 已清空回收站 | 不能 | 安卓端无系统级回收站可捞 |
| 归类归错了相册 | 能 | 撤销，或在系统相册里把照片移回去 |
| 卸载了 Slidebox | 照片不受影响 | 所有改动都直接做在系统相册里，卸载应用不会带走照片 |

## 五、和其它应用的关系

你在 Slidebox 里整理完，系统相册、文件管理器、其它看图应用看到的结果是一样的——改动直接落在系统相册上，不是应用内的私有分类。反过来说：**别的应用删了照片，Slidebox 里也看不到它**（它不保存照片副本）。整理到一半的照片与相册状态，见 [照片不显示与常见问题.md](照片不显示与常见问题.md) 的排查。
