## 一、安装前先弄清版本口径

LynkCo 是领克汽车官方的车主服务 app（应用商店里通常叫「领克」），开发者是领克汽车销售有限公司。你在官方应用商店搜到的往往是最新版，而本文讲的安装包是下面这一版：

| 项目 | 信息 |
| --- | --- |
| 版本 | 3.5.5 |
| 包名 | com.lynkco.customer |
| 安装包大小 | 207.21 MB |
| MD5 | C212691D5C768A22BCE9A5B80D5D6B97 |
| 核对时间 | 2026-09-27 |

两点提醒：

- 第三方应用商店对 4.x 新版本的系统要求标注为 Android 7.0 以上；旧版本的实际要求以安装时的系统提示为准。
- 版本 3.5.5 与官方商店的最新版不是同一版，功能细节可能有出入。想用新功能就装商店里的新版，想装这一版就按本文走。

## 二、安装包从哪里拿

[https://pan.quark.cn/s/56e0d8ed7a32](https://pan.quark.cn/s/56e0d8ed7a32) 是本文对应的 LynkCo 安装文件资源（夸克网盘）。操作路径：打开链接 → 转存到自己的网盘 → 在手机上装夸克网盘 app（或用电脑端）把 APK 文件下载到手机存储里。

下载下来的是一个 `.apk` 文件，文件名里通常带着版本号，别跟其他软件的安装包搞混。

## 三、安装步骤

1. 先在系统设置里允许「安装未知来源应用」——不同品牌手机的入口不一样，常见位置是「设置 → 安全 → 更多安全设置 → 安装未知应用」，或者安装时系统会当场弹窗让你给某个文件管理器授权。
2. 用文件管理器找到刚下载的 APK，点它。
3. 系统提示「是否安装此应用」时点确认，然后等进度条走完。安装包超过 200 MB，解析和写入需要一点时间，别以为卡死了就取消。
4. 装完点「打开」，第一次启动会陆续申请存储、网络等权限，按需同意。

## 四、校验安装包（可选但建议）

如果下载后安装报「解析包错误」或「文件损坏」，先怀疑文件没下完整。用文件管理器或专门的校验工具查看 APK 文件的 MD5 值，应与第一节的 `C212691D5C768A22BCE9A5B80D5D6B97` 一致；对不上就重新下载一遍。

## 五、安装失败的常见原因

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 文件不完整或下载中断 | 核对 MD5 后重新下载 |
| 安装按钮置灰 / 提示来源不允许 | 没给文件管理器「安装未知应用」授权 | 按第三节第 1 步补授权 |
| 提示存储空间不足 | 安装包加解压写入需要 2~3 GB 余量 | 清理存储后重试 |
| 系统提示版本过低不支持 | 手机系统版本太旧 | 升级系统或换用商店里要求更低的版本 |
| 覆盖安装失败（从旧版升级时） | 旧版本签名信息不一致 | 卸载旧版再装；注意先确认账号密码可用，见[常见问题与故障排查.md](常见问题与故障排查.md) |
