## 一、app 里能远程做的事

前提是你已经登录并把车绑进 app（流程见[账号注册与车辆绑定.md](账号注册与车辆绑定.md)）。之后常见能用的功能：

| 功能 | 说明 |
| --- | --- |
| 远程解锁 / 上锁 | 人在别处也能给车门开锁、落锁 |
| 鸣笛闪灯 | 找不到车时让车「自报家门」 |
| 车窗控制 | 部分车型支持远程关窗（夏天暴雨场景实用） |
| 远程启动 / 空调 | 提前开空调制冷或预热；不同车型支持的深度不同 |
| 车况查询 | 里程、油量 / 电量、胎压等状态，异常时 app 会提示 |
| 智能寻车 | 在大型停车场定位车辆位置 |
| 充电相关 | 插电混动 / 纯电车型可查看电量与周边充电站信息，合作站点还能在 app 里降地锁（细节见[用车服务与车主权益.md](用车服务与车主权益.md)） |

除了通过网络下发的远程功能，还有一套不依赖网络的近距离解锁方式——手机蓝牙钥匙 / NFC 钥匙，开通与配对方法见[数字钥匙与蓝牙钥匙.md](数字钥匙与蓝牙钥匙.md)。

功能可用性**因车型、年款和配置差异很大**——同是领克，01、02、03 乃至同一车型的不同年份，app 里显示的控车按钮都不一样，以你的 app 实际显示为准。

## 二、远程功能的使用前提

控车不是装上 app 就能用，四件事缺一不可：

1. **账号已绑定车辆**（见上文）；
2. **车联网服务处于激活状态**——购车时一般会激活，若中途退订或到期，远程功能会失效；
3. **车辆有网络**——车机联网正常才能收到指令，停在地库深处或网络盲区时容易超时；
4. **手机能正常上网**——app 与云端通信需要网络，别在飞行模式下试。

## 三、控车失败时先查这几点

| 现象 | 先查什么 |
| --- | --- |
| 按钮点了转圈后提示超时 | 车辆是否停在网络盲区（地下车库常见）；稍后重试 |
| 提示车辆离线 | 车联网服务是否到期；车辆长时间停放后电瓶电压低也会离线 |
| 功能按钮是灰的 | 该配置不支持此功能，或车型不适用（正常现象，不是故障） |
| 状态数据不刷新 | app 与车辆的数据同步有延迟，退出 app 重进 |

反复失败且排除了网络因素，重装 app 也是一个选项，安装包可从 [LynkCo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/56e0d8ed7a32) 获取；仍不行就走 app 内客服反馈。

## 四、安全方面要知道的

- 远程解锁后车辆保持解锁状态，直到你再次上锁或车辆自行落锁，解锁后记得确认。
- 把 app 账号借给别人等于把控车权交出去，账号安全（密码、验证码）别大意。
