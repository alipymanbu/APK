## 一、安装类

**症状：点 APK 提示「安装失败」**
- 确认已给安装来源授「允许安装未知来源应用」（见 [下载与安装教程.md](下载与安装教程.md) 第二节）。
- 看手机存储是否不足 —— 52.17M 的包解包安装需要更多空余空间，先清出几百 MB 再装。
- 手机上装过别的渠道的同名应用会因签名冲突失败：先卸载旧的再装（卸载前确认账号还能登回去）。

**症状：装完图标打不开、秒退**
- 多半是包没下完整。用电脑算 MD5 与 `082829e1ca31942509f21b8892b1ca6f` 比对，不一致就回网盘重新下载。
- 少数老机型系统版本过低装得上但跑不起来，这种属于设备不满足要求，换新一点的手机再试。

## 二、启动类

**症状：一直停在 xAI 启动页转圈，进不去注册页**
- 首次启动本来就要多等一会儿（页面会写「首次启动需要耐心等待」），先给它 1~2 分钟，别反复杀进程重开。
- 超过两三分钟还不动，退出应用重开一次。
- 还不行基本是网络没通：Grok 要连海外服务器，确认当前 Wi-Fi / 数据能正常打开其他网页，换个网络环境（比如 Wi-Fi 换数据）再试。
- 网络始终不通的问题不在这份安装包，参考本篇第三节。

**症状：启动页闪一下退回桌面**
- 走「安装类」的 MD5 核对，确认包完整；完整包仍闪退就重新下载一次覆盖安装。

**症状：进了主界面但一直白屏 / 转圈，重开也没用**
- 多半是旧缓存和新版本对不上。安卓路径：**设置 → 应用 → Grok → 存储 → 清除缓存**（先只清缓存，别点「清除数据」—— 清数据会把登录状态一起清掉）。
- 清完重开仍不行，再考虑清数据后重新登录；都无效就按 [下载与安装教程.md](下载与安装教程.md) 重装一遍。

## 三、网络与连接类

**症状：注册页能出来，但一发消息就转圈/失败**
- Grok 的服务与账号体系都在海外，国内网络直连经常不通或很慢 —— 这不是应用坏了。确认网络能访问海外服务后再试；换了网络环境还是不通，说明当前网络到服务端的链路就是断的，只能换网络再试。
- 高峰期服务端本身也会排队，隔一会儿重发比反复点更有用。

**症状：提示 High Demand / Heavy Usage / Something went wrong**
- 这类提示是**服务端过载**，不是你操作错了。多数情况等 5~15 分钟重试即可；有用户反馈高峰期免费账户发几条就撞到，歇一会儿再发。
- 想确认是不是全员故障，看官方状态页 [status.x.ai](https://status.x.ai/)：显示有事故就不用排查本地了，等恢复。
- 状态页正常但你持续报错 —— 2026 年多个来源的用户反馈都提到状态页与实际体验会有出入，这时按上一条查自己的网络，网络没问题就隔段时间再试，本地没有更多可修的。

**症状：昨天还好好的，今天突然全部回复失败**
- 先退出登录再重新登一次 —— 登录会话会在后台静默过期，界面看着还登着，实际凭证已失效，重登通常当场解决。
- 重登无效再依次试：清缓存（路径见「启动类」）→ 换网络 → 重装。

**症状：收不到验证邮件**
- 先翻垃圾邮件 / 垃圾箱文件夹；确认注册时邮箱地址没拼错。
- 隔几分钟再触发一次验证；仍收不到就换一个邮箱重新注册（见 [注册与登录教程.md](注册与登录教程.md)）。

## 四、账号类

**症状：登录不上、或登录后发现「账号没了」**
- 想起当初是用哪个入口注册的（X / 邮箱 / Apple / Google 四选一），从 Sign in 走同一入口 —— 四个入口是四套独立账号，换入口当然找不到。细节见 [注册与登录教程.md](注册与登录教程.md)。
- 忘记邮箱注册的密码：走登录页的找回密码流程，靠注册邮箱重置。

**症状：提示额度用完 / 功能被限制**
- 免费账户的聊天、图片生成各有独立限额，到顶会提示，等窗口刷新即可。数字与规则见 [免费额度与订阅说明.md](免费额度与订阅说明.md)。

**症状：想删的记录删不掉 / 找不到删除入口**
- 删除对话与生成图片的入口在 Settings → Data Controls，完整路径与「删历史 ≠ 关训练」的差别见 [聊天记录删除与隐私设置.md](聊天记录删除与隐私设置.md)。
- 设置页能打开但按钮没反应，按「启动类」的清缓存路径处理后再进一次。

## 五、生成类

**症状：图片生成失败、或出的张数比描述里少**
- 先重试一次排除偶发；再看是不是描述触发了内容过滤 —— 换成更具体、常规的场景描述。
- 老是失败又不提示网络错误，多半是额度耗尽，按 [图片生成与编辑教程.md](图片生成与编辑教程.md) 第四节核对。

**症状：生成的结果和描述差很远**
- 描述里补上主体、场景、风格、比例四个要素，小步修改而不是整段重写；改图类需求走首页「编辑图像」入口更稳（用法见 [图片生成与编辑教程.md](图片生成与编辑教程.md)）。
