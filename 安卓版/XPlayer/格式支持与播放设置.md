## 一、能播的格式

XPlayer 的官方口径是支持所有视频格式，你手上常见的文件对号入座：

| 你手上的文件 | 情况 |
| --- | --- |
| MP4 / M4V / MOV | 直接播，手机录制和主流下载视频多为此格式 |
| MKV / TS | 直接播，高清剧集、录播文件常见 |
| AVI / WMV / RMVB / FLV / 3GP | 直接播，老视频、网络视频常见 |
| 4K / 超高清 | 支持，播得流不流畅取决于手机性能 |

字幕文件（srt、ass 等）不算视频格式，但有配套支持，单独写在[字幕下载与设置方法.md](字幕下载与设置方法.md)里。

## 二、画面卡顿先动解码设置

播 4K 或高码率视频卡顿时的处理顺序：

1. 进播放界面的设置菜单，确认「硬件加速」处于开启状态；
2. 仍卡，把解码方式在硬解与软解之间切换再试——软解更吃处理器，但兼容性好，个别片源硬解异常时切软解能解决花屏、绿屏；
3. 低端设备播 4K 卡属正常，换成 1080p 片源立竿见影。

还伴随发热明显，清掉后台等机身降温再播。以上排查无效时按[常见问题与故障排查.md](常见问题与故障排查.md)第三节继续查。

## 三、播放界面的手势

音量、亮度、播放进度都能在播放界面直接滑动调节，不用退出去按物理键。误触是个隐患：播放中用「锁屏」功能锁掉触控，口袋里、哄孩子时不怕乱按。菜单里还有「快速静音」按钮，来电话、有人说话时一下关掉声音。

## 四、倍速、夜间模式与画面

- **倍速**：0.5 到 2.0 之间调，网课加速听、慢动作看细节都用它；
- **夜间模式**：暗光环境降低刺眼感；
- **自动旋转 / 画面比例**：横竖屏可跟随或锁定；比例能选适应、拉伸等模式，手机上看宽银幕电影按需切换。

## 五、后台播放、悬浮窗与分屏

| 模式 | 怎么用 | 适合场景 |
| --- | --- | --- |
| 后台播放 | 播放菜单里开启后退到桌面或锁屏，声音不断 | 听播客式追剧、听网课 |
| 悬浮窗（小窗） | 开启后视频缩成小窗浮在其他应用上，可拖动、缩放；首次使用系统会要求「显示在其他应用上层」权限 | 边回消息边看视频 |
| 分屏 | 配合系统分屏功能各占一半屏幕 | 一边看视频一边记笔记 |

切后台或锁屏后声音过几分钟被掐断，多半是系统电池优化在限制后台活动，处理步骤见[常见问题与故障排查.md](常见问题与故障排查.md)第五节。

## 六、多音轨与音效

双语或多音轨文件（常见于 MKV）在播放菜单里切换音轨；均衡器可调音效风格，具体可调项以你装的版本界面为准。
