# XPlayer 常见问题与故障排查

> 本篇汇总 XPlayer（安卓版）最常碰到的几类问题：视频列表为空、没声音、卡顿、投屏搜不到电视，按顺序排查即可。

## 一、列表里没有视频

按顺序查：

1. **存储权限**：系统「设置 → 应用 → XPlayer → 权限」，把「照片和视频 / 媒体」设为允许；安卓 11 及以上部分机型还要「所有文件访问权限」，位置在权限页的「文件和媒体」里；
2. **视频在 SD 卡**：确认手机能读到卡；应用会自动扫本机与 SD 卡，读不到卡自然也扫不到；
3. **目录太深或扩展名冷门**：切到应用内的文件夹视图按目录翻，确认文件确实在设备上；
4. **被移进了隐私文件夹**：公共列表里消失是正常的，用密码进隐私文件夹确认。

权限刚补开完还看不到，把应用彻底退出重开一次再等它扫完。

## 二、有画面没声音

1. 先确认没开着快速静音，音量也不是被手势调到零了；
2. 多音轨文件（常见于 MKV）：播放菜单里换一条音轨再试；
3. 冷门音频编码的片源：把解码方式在硬解与软解之间切换（见[格式支持与播放设置.md](格式支持与播放设置.md)第二节）；仍无声基本可判定是片源音轨本身的问题，换个片源验证。

## 三、播放卡顿

1. 确认硬件加速已开，必要时硬解软解互切；
2. 低端设备播 4K 卡属正常，换 1080p 片源；
3. 发热明显时清后台、降温后再播。

处理顺序与细节见[格式支持与播放设置.md](格式支持与播放设置.md)第二节。

## 四、投屏搜不到电视（Chromecast）

投屏要同时满足三个前提，缺一个就搜不到设备：

1. 手机与电视连**同一个 Wi-Fi**——很多路由器的 2.4G 与 5G 是两个独立网络，名字相似但互不相通，两台设备必须连同一个；
2. 电视端支持 Chromecast（内置 Cast 功能的安卓电视，或外接 Chromecast 设备）；
3. 路由器没开「AP 隔离 / 访客网络隔离」，开了设备之间互相不可见。

都满足后：播放界面点投屏图标，等设备出现后选中。能连上但卡，先查 Wi-Fi 信号强度，投 4K 对网络要求比 1080p 高得多。

## 五、字幕问题速查

不同步就在字幕菜单里调时间轴；搜不到先改视频文件名再搜；本地 srt 放视频同目录并改成同名。完整步骤在[字幕下载与设置方法.md](字幕下载与设置方法.md)。

## 六、其他

- 想边聊天边看：用悬浮窗模式，见[格式支持与播放设置.md](格式支持与播放设置.md)第五节；
- 锁屏后声音断了或想让它继续：后台播放开关在播放菜单里；
- 上面都没解决：到官方邮箱 `xplayer.feedback@gmail.com` 反馈，写清机型、系统版本与现象；
- 私密视频消失这类问题先看[隐私文件夹使用说明.md](隐私文件夹使用说明.md)第四节，多数是误卸载或没移出导致。
