## 一、转存前要准备什么

- 一个夸克账号（手机号即可注册），未登录只能预览、不能保存；
- 手机装好夸克 App，或在电脑浏览器打开 `pan.quark.cn`；
- 顺手看一眼网盘剩余空间（安装包约 24 MB，很小，但别卡在这一步）；
- 如果分享设置了提取码或有效期，先拿到提取码、在有效期内操作。

## 二、把分享资源转存进自己的网盘

1. 打开上面提示块里的 **Aniwave 安装文件资源（夸克网盘）** 链接；
2. 页面列出分享的文件后，点「保存到我的网盘」（部分版本叫「转存」）；
3. 选保存位置（默认放进「来自分享的文件」目录），确认；
4. 提示转存完成即可 —— 资源已经是你网盘里独立的一份，之后原分享是否失效都与你无关。

转存是云端对云端的复制，不消耗下载流量，也不用「先下载再上传」；保存按钮的位置随 App 版本更新会变，认准「保存 / 转存」字样就行。

## 三、从自己的网盘下载到手机

1. 打开夸克 App，从底部进入「网盘」，找到刚转存的文件；
2. 点文件旁的「下载」，选好本机保存路径；
3. 下载完成后在通知栏或「下载」目录里找到 `aniwave_v1.0.0-debug.apk`，接下来按 [下载与安装教程.md](下载与安装教程.md) 校验与安装。

电脑网页版也能下载，但安装包最终要装进手机，中途还要传一次；手机上直接下最省事。

## 四、转存与下载的常见小问题

| 情况 | 处理 |
| --- | --- |
| 找不到「保存到我的网盘」按钮 | 先确认已登录；按钮位置随版本变化，认「保存 / 转存」字样 |
| 提示空间不足 | 清理网盘或扩容后再转存 |
| 分享链接提示失效 | 转存过的不受影响；没来得及转存的只能等新的分享 |
| 下载中途断了 | 删掉下载任务重新下；装包前按安装教程的 MD5 校验再走一遍 |
| 下载完成但装不上 | 属于安装环节的问题，按 [常见问题与播放故障排查.md](常见问题与播放故障排查.md) 排查 |

对这份安装包本身的真实性有疑问（为什么要核对 MD5、`-debug` 是什么意思），先读 [来源与安全注意事项.md](来源与安全注意事项.md)。
