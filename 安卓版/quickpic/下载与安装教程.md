## 一、先核对你要装的是哪一个

QuickPic 是 Android 上的老牌图库应用，中文圈常叫它「快图浏览」，原由 `alensw.com` 开发，后由猎豹移动（Cheetah Mobile）接手运营。搜索时会撞见一批名字带 QuickPic 的图库应用，认准包名 `com.alensw.PicFolder` 才是本文档对应的这一套。

本套文档按下面这份安装包的实物信息记录，网上能搜到的是官方最新版，两者可能不是同一个版本：

| 项目 | 记录值 |
| --- | --- |
| 版本 | 4.7.2.2421 |
| 包名 | com.alensw.PicFolder |
| 安装包大小 | 3.13 MB |
| MD5 | DFC1093208E288857555509861D2765B |

下载完成后可以对照 MD5 核一下安装包是否完整；装好后进系统「设置 → 应用」也能看到对应的版本号。

## 二、从哪拿到安装包

[QuickPic 安装文件资源（夸克网盘）](https://pan.quark.cn/s/88f8dd9a995d) 里存的就是上面表格对应的那一份。打开链接转存到自己的网盘，再把 APK 下载到手机，「拿包」这一步就完成了。

## 三、安装步骤

1. 把 APK 传到手机（网盘客户端直接下载，或电脑下载后数据线拷贝）。
2. 在文件管理器里点这个 APK；系统提示「未知来源」时，按提示允许对应的文件管理器「安装未知应用」。
3. 点「安装」，装完打开。

装不上时按报错对号入座：

| 现象 | 处理 |
| --- | --- |
| 提示解析失败 | 安装包没下完整，重新下载并核对 MD5 |
| 提示与已有应用冲突 | 手机里已装过同包名应用且签名不同，先卸载旧的再装 |
| 提示存储空间不足 | 清出比 3.13 MB 富余得多的空间再装 |

## 四、装完先做两件事

1. **给存储权限**：第一次打开 QuickPic 会要读写照片的权限，不给它扫不出任何图片。
2. **对一下系统要求**：各收录页对这份 4.x 老版本的最低系统标注不一（从 2.3 到 5.x 都有），总体对老机型宽容，以你设备实际安装结果为准。老机器实在装不上，别反复重试，直接换版本线（见 [版本历史与更新说明.md](版本历史与更新说明.md)）。

第一次扫描完相册后，如果发现某些文件夹没出来，去 [图片不显示与文件夹排除.md](图片不显示与文件夹排除.md) 对症处理；想先把私密照片藏起来的，看 [隐藏照片与密码保护.md](隐藏照片与密码保护.md)。
