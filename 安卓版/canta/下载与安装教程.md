## 一、Canta 是一个什么软件

Canta 是一款开源的安卓卸载工具：它通过 Shizuku 拿到 adb 级别的权限，让你直接在手机上卸载预装的系统应用，不需要 root，也不需要连电脑敲命令。如果你手上的新手机塞了一堆用不到的预装软件，设置里对它们只有「停用」没有「卸载」，又不想为了删几个应用去解锁刷机，可以拿它来删。本篇到装完为止，装完怎么把它和 Shizuku 接上，见 [Shizuku连接失败怎么解决.md](Shizuku连接失败怎么解决.md)。

官方资料里能查到的硬事实：

- 开源协议 LGPL-3.0，源码与发布页在 [github.com/samolego/Canta](https://github.com/samolego/Canta)；
- 官方文档站为 [samolego.github.io/Canta](https://samolego.github.io/Canta/)，安装、使用、设置、预设四页是它的全部说明；
- 系统要求 **Android 9.0（SDK 28）及以上**，不需要 root，权限靠 Shizuku 提权；
- 应用本身不带统计与追踪，**不联网也能完成卸载**；列表里的安全徽章与应用描述是联网时才从 GitHub 上的社区清单拉取的（见 [卸载失败与显示异常排查.md](卸载失败与显示异常排查.md)）。

一个容易踩的版本落差：**Canta 本体要 Android 9+，但「免电脑启动 Shizuku」要 Android 11+**（无线调试是 Android 11 才加入系统的）。你的手机是 Android 9 或 10 的话，装得上 Canta，却没法在手机上独立完成 Shizuku 的启动，得按 Shizuku 官方文档用电脑 adb 跑一次启动命令 —— 两条路的取舍见 [和电脑ADB卸载相比怎么选.md](和电脑ADB卸载相比怎么选.md)。

## 二、你要装的是两个应用

Canta 自己不带任何系统权限，所有卸载动作都由 Shizuku 代为执行，所以两个都得装：

| 应用 | 在这套流程里干什么 | 少了它会怎样 |
| --- | --- | --- |
| Canta | 提供应用列表、安全徽章、勾选与卸载界面 | —— |
| Shizuku | 以 adb 级权限替 Canta 执行卸载命令 | Canta 里点垃圾桶没有任何反应 |

Shizuku 是一个独立的第三方开源应用，不是 Canta 的插件，两个都要在手机上长期留着。

## 四、Shizuku 从哪里拿

Shizuku 与 Canta 是两个项目的产物，下载地址也分开：

- 官方发布页：[github.com/RikkaApps/Shizuku/releases](https://github.com/RikkaApps/Shizuku/releases)
- Google Play：[moe.shizuku.privileged.api](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api)
- **Android 16 及以上**：Canta 官方安装页注明要用分支版本 [github.com/thedjchi/Shizuku](https://github.com/thedjchi/Shizuku)，原版在这一档系统上按官方说法走不通。

## 五、安装步骤

1. **先装 Shizuku**：从上一节任一渠道拿到安装包，点开安装；装完先放着，它的配置放在下一篇做。
2. **再装 Canta**：拿到 APK 后在手机上点开，系统若弹「允许安装未知应用」，给来源（文件管理器或浏览器）授一次权即可。
3. 装完打开 Canta 确认能进主界面、能看到应用列表 —— 到这里安装就完成了。
4. **别急着卸载 Shizuku，也别急着删 Canta 的安装包**：Shizuku 是每次使用都要用到的通道，安装包留着方便换机重装。

如果你点 Canta 里的卸载按钮没反应，不是安装出了问题，是 Shizuku 还没接上，直接走 [Shizuku连接失败怎么解决.md](Shizuku连接失败怎么解决.md)。

## 六、装之前核对一遍包

网盘里这份包的事实如下，装之前对一眼，包名对不上说明拿错了文件：

| 项目 | 值 |
| --- | --- |
| 版本 | 3.2.2 |
| 包名 | `io.github.samolego.canta` |
| 大小 | 4.48M |
| MD5 | `AA7F3FC6CE98284CBE3CBD6F1C4EEBD4` |
| 留存于 | 2026-09-23 |

三点提醒：

- **官方最新版不等于 3.2.2**。官方发布页的最新版本以 [GitHub Releases](https://github.com/samolego/Canta/releases/latest/) 当时显示为准，网盘这份是留存的某一版，两者常常不是同一个版本，所以本文档里涉及界面与行为的描述以你实际装上的版本为准。
- 包名是唯一可靠的身份证，文件名与版本号都可能被改，`io.github.samolego.canta` 不会变。
- 想校验文件有没有被改动，用手机上的文件校验工具算 MD5 与上表比对；对不上就不要装，换 [GitHub Releases](https://github.com/samolego/Canta/releases/latest/) 重新拿一份。
