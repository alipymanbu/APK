## 一、预设是什么

预设（Preset）是 Canta 里的一个本地存档功能：把一批应用的**包名**连同名称、描述、创建时间、格式版本存成一份 JSON。它不上传任何地方，存的是纯文本清单，所以能复制、能发给别人、能在换机后重新导入。一份预设长什么样见第五节的 JSON 样例。

## 二、什么时候值得建一个

- **多台设备清一样的东西**：家里两台同品牌的手机，把第一台删完的清单直接搬到第二台。
- **系统大更新前留底**：记下「我已经删了哪些」，更新后要还原哪个都有据可查。
- **把经验发给别人 / 抄别人的清单**：预设的导入导出就是为这个设计的。

## 三、创建预设（从已卸载的应用生成）

预设是**从「已经删掉的应用」反向生成的**，所以顺序不能反：

1. 先按 [卸载系统应用与恢复误删.md](卸载系统应用与恢复误删.md) 把要进清单的应用都卸载掉；
2. 切到 Canta 的**预设标签页**，点 **Create Preset**；
3. 填名称（必填），描述可选（写清这份清单是给什么机型删什么的）；
4. 点保存。

注意：创建时 Canta 会**自动抓取当前设备上全部已卸载的应用**塞进这份预设 —— 保存前确认当前已卸载的集合就是你要的，多删过的东西也会一起进去。

## 四、应用预设（换机后照单重删）

1. 在预设列表里找到目标清单，选 **Apply Preset**；
2. Canta 会去勾选清单里的包，**本机上不存在的包会被自动跳过**；
3. 回主列表核对被选中的那批（这里有机会再删掉不该删的）；
4. 照常点垃圾桶确认卸载。

「没生效」和「被跳过」要区分开：本机没有的包不会报错，只是不选中 —— 换品牌、换系统版本后清单对不上是常态，逐条核对选中项比看到失败提示更可靠。

## 五、导入与导出

- **导出**：在预设列表里找到它，点 **Share**，JSON 会被复制到剪贴板，粘到聊天窗口或记事本就能发出去。
- **导入**：点 **Import Preset**，有两个入口 —— **Clipboard** 标签直接粘 JSON、**Text** 标签手动贴文本，然后点 Import。

导出的 JSON 格式（官方样例）：

```json
{
  "name": "Samsung Bloatware",
  "description": "Removes Samsung's duplicate apps and unnecessary services",
  "createdDate": 1699123456789,
  "version": "1.0",
  "apps": [
    "com.samsung.android.bixby.agent",
    "com.samsung.android.app.spage"
  ]
}
```

`apps` 里放的全是包名，所以一份清单在不同品牌之间没法直接用（包名对不上），同品牌同系列才是它的主场。

## 六、拿别人的预设先看包名

两个必须知道的边界：

1. **预设能绕过「不安全」限制**。Canta 设置里「允许不安全选择」默认是关的，紫色 Unsafe 应用勾不中；但官方设置页写明，**用预设也能把这类应用带进来**。也就是说：别人给你的清单里可能包含紫色项，应用之前打开 JSON 把 `apps` 逐个看一遍，别直接点确认。
2. **导入不等于执行**。导入只是把清单存下来，真正删除仍要走 Apply → 核对 → 垃圾桶那三步，中间任何一步都可以反悔。

清理完想回头检查哪些设置影响行为，见 [卸载失败与显示异常排查.md](卸载失败与显示异常排查.md) 的设置项一节。
