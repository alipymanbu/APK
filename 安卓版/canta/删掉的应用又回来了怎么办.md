# 删掉的预装应用重启后又回来了怎么办

> 删完的应用再出现，通常是这四种情况之一：系统大版本更新、恢复出厂、应用商店/运营商自动重装、工作资料与分身。逐条对应找回或再删的办法。

## 一、先确认「回来」是哪一种

Canta 的卸载只对当前用户生效，被删的 APK 一直留在系统分区里 —— 所以**只要系统层面做一次整体动作，把它重新放回当前用户，它就回来了**。这不是 Canta 没删干净，多个独立来源对这一点的描述一致：

| 场景 | 为什么回来 | 怎么办 |
| --- | --- | --- |
| 普通重启、关机再开 | 不会回来 | 若真回来了，见第四节按「异常」排查 |
| 系统大版本更新 | 更新会按出厂镜像把预装应用重新放回用户空间 | 重新删一遍即可，这是标准流程 |
| 恢复出厂设置 | 全部回到出厂状态，系统应用全数回归 | 删之前用预设留了底，照清单重删很快 |
| 应用商店/云备份自动装回 | 商店的「自动安装/恢复」把以前装过的应用拉回来 | 关掉商店的自动恢复选项，再删一次 |
| 运营商版本的自动重装服务 | 部分合约机会自动补装预装应用 | 有用户反馈此类机型删了会反复回来，需在系统设置里关掉对应服务 |
| 工作资料、手机分身、安全空间 | 你删的是主用户，副本空间里它一直都在 | 在那个空间里单独处理（Canta 按当前用户操作） |

## 二、系统更新后重删的标准流程

1. 更新完先别急着装东西，打开 Shizuku 点「启动」（重启后服务必掉，见 [Shizuku连接失败怎么解决.md](Shizuku连接失败怎么解决.md) 第五节）；
2. 打开预设标签页，选中你更新前导出的那份清单，**Apply Preset**；
3. 回主列表核对选中项 —— 更新后新增的预装应用可能不在旧清单里，用徽章过滤「推荐」再补选几个；
4. 照常点垃圾桶确认。

这正是 [预设导入导出与批量卸载.md](预设导入导出与批量卸载.md) 存在的理由：一次导出，之后每次更新后照着重删，不用再从头一个个找。

## 三、商店拉回来的：先关自动恢复

如果应用是过了一阵子自己冒出来的（而不是更新后立刻回来），更像商店或云备份干的：

- Google Play：设置里关掉「备份/自动安装应用」相关选项；
- 各品牌商店（三星 Galaxy Store、小米应用商店等）：关掉「自动更新已删应用」一类的开关。

关掉之后再删一次。有三星用户反馈，Galaxy Store 的通知点进去会把已卸载应用重新装上 —— 这类行为与机型、账号设置有关，以你自己设备上的设置项为准。

## 四、不是上面任何一种：按异常排查

- **只是图标在、点不开**：可能只是桌面残留的快捷方式，去设置 → 应用列表确认它是否真的装着（见 [卸载失败与显示异常排查.md](卸载失败与显示异常排查.md) 第一节的对照表）。
- **Canta 的已卸载列表里还有它，但桌面又有图标**：以设置里的应用列表为准，两边不一致时重启一次再看。
- **想确认到底删没删掉**：Canta 第二个标签页（已卸载）里能找到，就是删成功了；找不到又出现在主列表，说明它被重新装回当前用户。

## 五、电脑兜底：一条命令装回来

万一你手边有电脑、又需要把某个包按原样放回当前用户（而不是从商店重装），adb 里有对应命令：

```bash
adb shell cmd package install-existing com.example.app
```

它不会重新下载应用，只是把设备上已有的包重新对当前用户生效，执行后应用立刻回到桌面。这条属于电脑侧操作，整条电脑路线的取舍见 [和电脑ADB卸载相比怎么选.md](和电脑ADB卸载相比怎么选.md)；日常用 Canta 的话，走第二节的预设流程就够了。
