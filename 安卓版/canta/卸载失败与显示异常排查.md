## 一、先按症状对号入座

| 你看到的现象 | 多半是这个原因 | 去哪解决 |

| 点垃圾桶没任何反应 | Shizuku 没运行或没授权给 Canta | [Shizuku连接失败怎么解决.md](Shizuku连接失败怎么解决.md) |

## 二、徽章与描述为什么不显示

徽章（推荐 / 进阶 / 专家 / 不安全）和点开应用看到的那段说明，来自 GitHub 上的社区预装应用清单，**联网时才拉取**：

- 断网状态下卸载功能照常能用，缺的只是分级参考 —— 这时候更要按「只删认识的」来（见 [卸载系统应用与恢复误删.md](卸载系统应用与恢复误删.md) 第二节）；
- 设置里「**自动更新 Bloat List**」开着（默认开），Canta 会自己去拉最新分级，包括新发现的预装应用与修订过的建议；
- 关掉这个开关就只用本地那份旧数据，新机型上会出现「很多应用没分级」的情况，一般不该关。

## 三、设置项逐条

打开 Canta 的设置页，值得你动手的只有一项，其余保持默认：

| 设置 | 默认 | 建议 |
| --- | --- | --- |
| 自动更新 Bloat List | 开 | 保持开，分级数据才跟得上 |
| 卸载前确认 | 开 | 保持开，关掉后点垃圾桶直接删、不弹数量确认框 |
| 允许不安全选择 | 关 | 除非明确知道自己要删紫色项及其后果，否则别开 —— 开了就能勾 Unsafe，删错有开不了机的风险 |
| Bloat List URL | 官方清单仓库地址 | 不改，它是给自建分级数据库的人用的 |
| Commits URL | 官方清单的提交接口 | 不改，配合上一项判断分级数据有没有更新 |

「允许不安全选择」还有一个绕过口子：设置里关着，**走预设照样能把 Unsafe 包带进来**，详见 [预设导入导出与批量卸载.md](预设导入导出与批量卸载.md) 第六节。

## 四、藏起来的「全选」

Canta 有一个隐藏开关：在设置页**连续点多次版本号**，会解锁「全选」—— 它出现在你把过滤器切到「推荐」之后，一键勾中全部推荐项。

用它之前先确认两件事：过滤器确实是「推荐」而不是「全部」；确认框里的数量与你预期一致（开着「卸载前确认」就能看到这个数字）。批量删除的事故基本都出在「以为筛过了、其实没筛」。

## 五、隐私与离线能力

按官方功能页的说法：Canta 可以完全离线使用，应用内不含任何统计与追踪，也不会上传你的数据；联网时拉取的只有徽章与描述这类公开清单。也就是说这台手机上删了哪些应用，不会因为用它而外传。
