## 一、先说清楚：哪些店能在线订

Tabelog 上大部分店只给电话，**带「网络预约」入口的店才能在 app 里直接订**（官方页面的表述是网络预约签约店铺，截至 2026 年 6 月官方统计约 9.8 万家）。搜店时用「日期 + 人数」筛选，能筛出当前有空位的店。没有网络预约入口的店，只能打店里电话，或到店碰运气。

预约前你需要：一个 Tabelog 账号（见 [账号注册与登录问题](账号注册与登录问题.md)）和一张能付外币的卡。

## 二、在线预约四步（官方流程）

1. **输入预约详情**：选日期、时间，然后选「只订座位」还是「订套餐」——套餐内容在这一步能看到。
2. **登录 / 注册**：
   - 已有账号：填注册邮箱 → 邮箱收到验证码 → 回 app 输入。
   - 新账号：先填预约人信息，再填邮箱 → 同样收验证码输入。
   - 邮箱里的大写字母会自动转成小写，不用纠结大小写。
3. **填支付信息**：选支付方式，输入后可能弹一次安全认证（输密码之类）。这笔信息用于两项扣款：
   - **系统使用费：每人 440 日元**；
   - 违反取消政策时的取消费。
4. **确认并完成预约**：核对内容 → 完成 → 收到**预约确认邮件**。这封邮件务必看，里面的预约号码后面改期、取消都要用。

## 三、费用与规则的几个坑

| 事项 | 规则 |
| --- | --- |
| 系统使用费 | 每人 440 日元，预约时收取 |
| 取消预约 | **系统使用费不退** |
| 店家取消政策 | 违反政策取消，店家可能另收取消费（各店不同） |
| 能改什么 | 只能改**日期、时间、人数**三项 |
| 改不了的信息 | 需要直接联系店家（预约由店家管理，Tabelog 不代改） |

另外两条本地经验（第三方文章）：日本餐厅普遍重视准时，迟到十几分钟可能被取消席位；高分店（3.8 以上）的热门时段常要提前一周到一个月订。**以店铺页面显示的可订情况为准。**

## 四、改期与取消怎么操作

改期和取消走同一个入口，不依赖 app 内菜单，邮件里就能办：

1. 打开**预约确认邮件**，点底部「确认 / 更改 / 取消预约」的链接。
2. 输入邮件里那串 **10 位预约号码** → 发送。
3. 收到**电话验证邮件**，点邮件里的链接 → 输入预约时填的电话号码 → 认证进入确认页。
4. 之后：
   - **改期**：改日期、时间、人数 → 提交 → 收到变更确认邮件。
   - **取消**：勾选条款 → 点「取消预约」→ 收到取消确认邮件。

在线操作不成功时，**直接打店家电话**——预约管理在店家手里，官方明确写了 Tabelog 不代为处理。

## 五、收不到确认邮件

按顺序排查：

1. 邮箱地址是不是填错了（确认一下注册邮箱）。
2. 看垃圾箱、广告箱。
3. 如果设了域名白名单，放行 `@tabelog.com` 的邮件。
4. 都没有 → 按官方说法重新走一遍，或直接联系店家确认。

注意：**确认邮件一到，预约才算落实**。没收到邮件不要默认订上了，先查邮件，再按第四节的方式查预约状态。
