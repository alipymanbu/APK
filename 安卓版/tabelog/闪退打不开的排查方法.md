# Tabelog 闪退打不开的排查方法

> 点图标没反应、打开就退、卡在启动画面，按这篇从最省事的往下试，多数问题在前三步就解决。

## 一、先判断是哪种「打不开」

| 现象 | 更可能的原因 |
| --- | --- |
| 点图标立刻退回桌面 | 版本与系统不兼容、数据损坏 |
| 停在启动画面转圈 | 网络连不上（应用启动要联网） |
| 能开但一点搜索就退 | 权限被拒、内存不足 |
| 装的时候就提示失败 | 系统版本过低、空间不够、与已有版本冲突 |

装不上或一直闪退，先回到 [下载与安装教程](下载与安装教程.md) 核对系统要求与包信息——本地这份安装包要求安卓 5.2 以上，官方商店推荐 Android 9.0 以上，低于推荐版本官方明说可能无法正常动作。

## 二、按顺序试（每试一步就打开一次看结果）

1. **强制停止再打开**：设置 → 应用 → Tabelog → 强制停止，然后重开。卡住的进程会被清掉。
2. **重启手机**：临时性的内存错误、后台进程异常，重启基本能清干净。
3. **检查网络**：启动画面转圈多数是网络问题。切一次 Wi-Fi / 流量；确认能正常打开 Google 系服务（应用的地图与登录依赖它）。
4. **清缓存**：设置 → 应用 → Tabelog → 存储 → **清除缓存**。缓存是临时文件，删了不丢登录和收藏。**别急着点「清除数据」**——那会把登录状态一起清掉。
5. **看存储空间**：手机可用空间见底时，应用存不下临时数据就会启动失败。先清出几百 MB 再试。
6. **检查权限**：设置 → 应用 → Tabelog → 权限，把位置、通知、存储（照片/文件）打开。拒了必需权限，有的应用会直接退。
7. **关掉省电限制**：设置 → 电池 → 把 Tabelog 的电池策略改成「不受限制」。厂商的后台清理会杀掉正在运行的应用，也是收不到通知的头号原因。
8. **升级系统与应用**：系统设置里检查系统更新。这份包是 10.13.0，商店里的官方版会更新（页面见过 10.38.0）；能连上商店就用商店版，更新日志里常写着修复了哪类问题。
9. **卸载重装**：以上都不管用再做。卸载会丢本机登录状态，重装后用原账号登录即可找回收藏与预约（见 [账号注册与登录问题](账号注册与登录问题.md)）。

## 三、通知收不到

不是闪退，但常一起出现：

1. 系统设置 → 应用 → Tabelog → 通知，总开关打开。
2. 通知分类里确认「预约结果」「提醒」这类没被单独关掉。
3. 关掉省电模式与该应用的后台限制（见第二节第 7 步）。
4. 网络正常才有推送——飞行模式、弱网都会吞掉。

## 四、还没解决

按这个顺序收敛：

- 登录环节的问题（点了没反应、验证码不来）→ [账号注册与登录问题](账号注册与登录问题.md)。
- 界面语言相关 → [设置中文界面](设置中文界面.md)。
- 应用本身的功能性故障 → 官方支持邮箱 `tabelog_support@kakaku.com`（Google Play 应用页上公布的联系方式）。

想换一个已知可用的安装包重来一遍，网盘里的 Tabelog 安装文件资源见 [下载与安装教程](下载与安装教程.md) 第三节。
