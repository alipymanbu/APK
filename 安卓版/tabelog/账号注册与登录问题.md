## 一、注册流程（app 内）

按官方帮助给的步骤：

1. 首页 → **我的页面** → **免费会员注册 / 登录**。
2. 选一个用来登录的服务（第三方账号或邮箱），按提示完成该服务的登录/认证。
3. 进入注册页 → 同意利用规约 → 点注册。
4. 注册邮箱收到**验证码** → 回 app 输入 → 注册完成。

邮箱里的大写字母会自动转小写，直接输就行。看点评、搜店不用注册；**在线预约必须注册**；订阅 Premium 也需要登录（见 [会员订阅与取消](会员订阅与取消.md)）。

## 二、登录是怎么回事：靠第三方账号

Tabelog 自己不发密码，登录靠你绑定的第三方服务（Google 等）。两条官方要点：

- **Facebook 登录已于 2024 年 8 月 5 日终止**。以前用 Facebook 登的，现在登不上是服务下线，不是你的问题——按下面第四节的「临时登录」换绑。
- 绑定可以有多个，但**解绑有条件**：只有绑定 2 个以上服务时才能解绑，解绑到只剩 0 个会彻底登不进去。

## 三、注册/登录收不到验证码

按命中率排序排查：

1. **地址填错了**——验证码只发到你填的那个邮箱。
2. **进了垃圾箱 / 广告箱**。
3. **域名白名单**——设了指定域名接收的话，放行 `@tabelog.com`。
4. **邮箱已注册过**——收到「Tabelog 账户通知邮件」说明该邮箱已有账号，用原来的登录方式登。
5. **账号已注销**——退会过的邮箱收不到任何验证邮件。

验证码有有效期，过期了就从头再走一遍。

## 四、忘了当初用哪个账号登录：临时登录

官方叫「仮ログイン」，作用是临时进账号看当前绑的是哪个服务，然后重新绑：

1. app 右上角三根线 →（若已登录先登出，再打开预约履历）→ **免费会员注册 / 登录** → **无法登录时**。
2. 选 **临时登录表单** → 输入注册邮箱 → 发送。
3. 邮箱收到标题为「[食べログ] 仮登录邮件」的信，里面有 **8 位认证码**（有有效期）。
4. 回 app 输入认证码 → 验证，进入「登录（账号绑定）」页，这里会列出当前已认证的服务。
5. 想换用别的服务，点该服务右侧的 **绑定**，按流程走完。
6. 返回登录页，用刚绑好的服务正常登录。

## 五、点了 Google 登录没反应 / 报错

先分清是「Google 那边」还是「app 这边」：

| 现象 | 先查什么 |
| --- | --- |
| 点了转圈、停住 | 网络能否正常访问 Google 服务；切 Wi-Fi / 流量试 |
| 提示认证失败 | 手机上的 Google Play 服务是否停用或过旧；系统日期时间是否为「自动」 |
| 找不到账号列表 | 手机设置 → 账号 → Google 该账号的同步是否打开；试着重登一次该账号 |
| 反复失败 | 清一次 app 缓存（设置 → 应用 → Tabelog → 存储 → 清除缓存），再重试 |

清缓存不会丢登录与收藏；**清除数据才会**（要重新登录）。仍不行就走第四节的临时登录，或换绑另一个服务。

## 六、换了手机，数据还在吗

收藏、预约记录、点评都挂在**账号**上，不跟手机走。新手机装好 app（见 [下载与安装教程](下载与安装教程.md)）、用原来绑定的服务登录，就都回来了。装完顺手把界面切成中文，见 [设置中文界面](设置中文界面.md)。
