## 一、先说结论

你手上这份安卓安装包，和搜索引擎里占主流的「ComfyUI 官方教程」不是同一套东西：

- **电脑版**：官方项目本体，开源的节点式 AI 图像/视频创作工具，装在 Windows / Mac 上，靠连节点搭工作流；
- **安卓版**：面向手机用户的独立安卓应用，不用搭节点，按应用内的界面输入描述或上传参考图来生成。

想清楚这一点，看教程就不会串台——网上大量「ComfyUI 教程」讲的是电脑版的节点操作，对安卓版并不适用；同理，网上搜到的 ComfyUI 故障排查文章也几乎都是电脑版向的（讲显卡驱动、显存、节点报错那些），安卓版出了问题参考价值有限，排查思路见[常见问题解答.md](常见问题解答.md)。

## 二、官方 ComfyUI 是什么

按官方渠道（官网 `https://www.comfy.org/` 与文档 `https://docs.comfy.org/`，代码仓库 `https://github.com/comfyanonymous/ComfyUI`）的信息：

- 开源（GPLv3 许可），图像与视频生成都能做；
- 核心形态是**节点画布**：你把模型、参数、输出等节点连线组成工作流，每一步可见、可改、可复用；
- 提供桌面客户端（Windows / Mac）与网页云端两条路，截至本文检索时没有官方原生安卓客户端，以官方页面为准；
- 社区工作流数量庞大，学习曲线偏陡，官方也提供了把工作流简化成表单界面的「App 模式」降低使用门槛。

## 三、安卓版与电脑版对照

| 维度 | 安卓版（本篇讨论的安装包） | 电脑版（官方桌面客户端） |
| --- | --- | --- |
| 运行位置 | 手机 / 平板 | Windows / Mac 电脑 |
| 操作方式 | 应用内界面，输入描述、上传参考图 | 节点画布，连线搭工作流 |
| 上手门槛 | 低，会打字就能试 | 偏高，需要理解节点与模型概念 |
| 硬件依赖 | 手机本身 | 通常需要较好的显卡，或转用官方云端 |
| 获取方式 | 本篇头部的网盘链接 | 官网下载页 |
| 版本节奏 | 以安装包为准（网盘里为 0.0.5） | 官方更新频繁，以官网为准 |

## 四、怎么选

- **只想在手机上随手出图**：装安卓版，装好即用，见[下载与安装教程.md](下载与安装教程.md)；
- **想精确控制每一步、接 LoRA / ControlNet 之类的能力**：上电脑版，或用官方云端——这些是节点生态里的玩法，安卓版没有；
- **两边都要**：不冲突，安卓版管碎片时间出图，电脑版管需要精细控制的项目。两套的界面与操作互不通用，教程分开找。

## 五、版本差异怎么理解

安卓版与电脑版各自独立迭代，版本号没有对应关系：

- 网盘里这份安卓包对应 2026-09 时点的版本（0.0.5），之后官方或发布渠道是否出新版以当时的发布页面为准；
- 电脑版的版本号更新很快，网上教程里出现的版本号比你的新是常态，核心概念不变；
- 凡涉及你本地这份包的版本号、体积、MD5，以[下载与安装教程.md](下载与安装教程.md)第一节列出的信息为准。

还有拿不准的问题（收费、生成失败等）可以去[常见问题解答.md](常见问题解答.md)查。
