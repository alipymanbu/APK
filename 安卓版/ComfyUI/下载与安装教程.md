## 一、安装前先确认这几点

这份安卓安装包的本地信息如下，装完可以据此核对：

| 项目 | 内容 |
| --- | --- |
| 版本号 | 0.0.5 |
| 安装包大小 | 约 6.52 MB |
| MD5 | `DBAF0CE83FC63C3879EB149D9EAAA323` |
| 系统要求 | 安卓 5.2 及以上（以安装包标注为准） |
| 包名 | `com.example.demo` |

两点说明：

1. 这是安卓端应用，装在手机或平板上，不是电脑版。两者是不同的东西，区别见[手机版与电脑版有什么区别.md](手机版与电脑版有什么区别.md)。
2. 网盘里保存的是上面这一版。官网或应用商店里的版本号可能已经往前走了，版本号对不上是正常现象，不影响安装使用。

## 二、把安装包转到手机

安装包通过夸克网盘分享获取：[ComfyUI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/01ac88bfb7cf)。分成「转存」和「下载」两步。

**手机上直接操作**：

1. 在手机浏览器或夸克 App 里打开上面的网盘链接；
2. 勾选 APK 文件，选择「转存」，存到你自己的网盘空间；
3. 转存完成后，从自己的网盘里把 APK 下载到手机存储。

**电脑中转**（手机直连不方便时）：

1. 电脑浏览器打开链接并登录，转存后把 APK 下载到电脑；
2. 用数据线、微信文件传输助手或任意你习惯的方式，把 APK 传到手机存储里。

转存后链接就是你自己网盘里的一份副本了，之后随时可以重新下载。

关于夸克网盘本身的几个常见疑问：转存需要先登录夸克账号（没有就现场注册一个）；免费空间的初始容量就有 10GB，这份安装包只有 6.52 MB，容量完全不用操心；免费账号的下载速度对单个 APK 也绰绰有余。容量与速度规则以夸克当前公布为准。

## 三、安装步骤

安卓默认不允许安装应用商店之外的安装包，需要先放开一次权限：

1. 在手机上点开下载好的 APK 文件；
2. 系统弹出「禁止安装未知来源应用」之类的提示时，点「设置」，找到「允许从此来源安装」或「允许安装未知应用」并打开；
3. 返回安装界面，点「安装」，等进度走完。

不同品牌手机的菜单叫法不一样：小米/Redmi 在「更多设置 → 开发者选项」附近，华为/荣耀在「更多安全设置」里，OPPO/vivo/iQOO 的入口在弹出的安装对话框里直接给。找不到就回到第二步的安装弹窗里点「设置」跳过去，最直接。

## 四、安装后核对

装完打开应用，可以先核对两处：

- **版本号**：在应用的「关于」「设置」之类的页面看版本，应为 0.0.5；
- **文件校验**（可选）：如果你保留了原始 APK 文件，可以用手机上的校验类工具对它算一次 MD5，与第一节的 `DBAF0CE83FC63C3879EB149D9EAAA323` 比对，一致说明文件没在传输中损坏。

核对完就可以开始用了，第一次生成的流程见[文生图与图生图上手教程.md](文生图与图生图上手教程.md)。

## 五、装不上怎么办

按现象对症：

| 现象 | 常见原因与处理 |
| --- | --- |
| 提示「解析包出现问题」 | 文件没下完整，回网盘重新下载一遍再装；仍报错则确认下载的就是 APK 文件本身，不是网页保存下来的快捷方式 |
| 系统要求不满足 | 对照第一节「系统要求」，太老的系统装不了 |
| 安装按钮点不动 / 进度卡住 | 存储空间不足，清出至少几百 MB 再试 |
| 被手机管家拦截 | 选择「仍要安装」或在安全设置里临时放开该来源 |
| 转存失败 / 链接失效 | 稍后重试；资源以网盘页面的实际状态为准 |

装好之后遇到使用层面的问题（收费、生成失败、版本差异等），见[常见问题解答.md](常见问题解答.md)。
