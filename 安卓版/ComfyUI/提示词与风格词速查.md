## 一、一个够用的句式

把一句话按这个顺序填满，多数场景就够了：

```text
主体 + 动作/状态 + 场景 + 风格 + 细节强化
```

套两个例子感受差别：

| 写法 | 描述 | 预期差别 |
| --- | --- | --- |
| 太笼统 | 一只猫 | 内容全靠模型自由发挥，每次都不一样 |
| 填满句式 | 一只橘猫，蜷在窗台上晒太阳，午后客厅，写实风格，柔和光线，毛发细节清晰 | 主体、氛围、画法都被你定了，结果可控 |

不需要每次都五个成分全有，但**至少给齐主体和风格**这两项，出图方向就不会跑偏。

## 二、风格词对照表

风格词决定整张图的画法，换风格时优先动它：

| 你想要的效果 | 可以试的写法 |
| --- | --- |
| 照片般的真实感 | 写实、摄影风格、真实照片质感 |
| 二次元 / 动漫 | 动漫风格、日系插画、赛璐璐 |
| 手绘感 | 水彩、彩铅、手绘插画 |
| 未来感 / 酷炫 | 赛博朋克、霓虹光效、科幻场景 |
| 复古 | 胶片质感、老照片、复古海报 |
| 简洁设计感 | 极简、扁平插画、矢量风格 |
| 游戏感 | 像素风、3D 渲染、游戏原画 |

同一句描述换风格词多跑几张，是摸清当前版本「吃哪套词」最快的办法。

## 三、中文还是英文

- 中文描述通常可以直接用，先写中文；
- 某类描述反复画不对时，把关键成分换成简短英文关键词（如 `cyberpunk city, neon light`）再试；
- 两种都试过后，固定用效果稳定的那种；混着用也可以——主体中文、风格词英文，是常见的折中写法。

## 四、结果不满意时的迭代方法

三条纪律，比多写一堆词更有用：

1. **一次只改一处**。想换风格就只动风格词，想改动作就只动动作，改完立刻能知道是哪句起了作用；
2. **风格词先跑稳**。同一句风格描述连跑两三张，确认画法稳定了，再换主体和场景；
3. **同类描述连翻车就绕开**。换个说法表达同一个意思，不必跟一句词死磕。
