## 一、有哪几种登录方式

打开 App 或网页版，登录页会给出这几类入口：

| 登录方式 | 说明 |
| --- | --- |
| 手机号 | 中国大陆手机号 + 短信验证码，也可设置密码后用密码登录 |
| 网易邮箱账号 | 用已有的网易邮箱体系账号直接登录（LOFTER 属于网易，两边账号打通） |
| LOFTER ID | 早期注册的站内 ID 账号 |
| 第三方授权 | QQ、微信、微博授权登录，不用单独设密码 |

没有账号时，任选一个入口按提示注册即可；用第三方方式首次登录会直接帮你建号。按官方服务协议，注册应使用真实身份信息，未成年人需在监护人陪同下阅读协议。

## 二、忘记密码怎么办

处理方式取决于你当初用哪种方式登录，对号入座：

| 你用哪种方式登录 | 找回途径 |
| --- | --- |
| 手机号 | 登录页点「忘记密码」，输入手机号收短信验证码重置 |
| 网易邮箱账号 | 到网易账号中心（[reg.163.com](https://reg.163.com)）按提示找回 |
| LOFTER ID | 登录页点「忘记密码」，绑定过手机或邮箱的可以自助重置 |
| QQ / 微信 / 微博 | 密码归对应平台管，去对应平台的账号中心改；改完回 LOFTER 继续用授权登录 |

两个提醒：

- 多数「登不上」其实是登录方式选错了 —— 一直用微信授权登录的人，用手机号 + 密码是登不进去的，反过来也一样。先回想当时用的是哪种方式。
- 账号注销后就找不回来了。如果只是想换绑或改密码，不要走注销。

## 三、想注销账号时

App 内路径：**我的 → 设置 → 注销账号**，按页面提示确认即可（不同版本入口名称可能略有差异，找不到时在设置里搜「注销」）。注销前注意：

- 注销不可逆，账号下的文章、图片等数据会一并处理掉；
- 有用户反馈注销后想反悔基本无法恢复，动手前把还想留的内容先导出；
- 官方服务协议明确要求妥善保管账号密码，账号不得赠与、借用、租用、转让或售卖。

## 四、账号安全的几条实务建议

- 绑定手机或邮箱，忘记密码时才有自助找回的抓手；
- 不要在来路不明的第三方客户端里登录账号 —— 官方协议也不允许用未经授权的第三方软件登录，账号出问题时申诉也没有凭据；
- 怀疑被盗就立刻改密码，改不掉再走客服申诉，申诉时需要能证明身份的材料。

账号搞定、第一次进社区后，想找内容先看 [标签搜索与订阅方法.md](标签搜索与订阅方法.md)，想发东西看 [发布内容与互动入门.md](发布内容与互动入门.md)。
