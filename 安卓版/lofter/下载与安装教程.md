## 一、安装前先确认这几件事

LOFTER（昵称「老福特」）是网易旗下的兴趣社区应用，安卓手机版以 APK 安装包方式安装。动手之前先核对你的手机：

| 项目 | 要求 / 说明 |
| --- | --- |
| 操作系统 | 安卓 5.2 及以上（以安装包登记信息为准，安装时手机会再自行校验） |
| 可用存储空间 | 安装包约 174 MB，安装后占用更大，建议预留 2 GB 以上 |
| 网络 | 下载安装包与首次登录都要联网，包体较大建议用 Wi-Fi |

这份网盘安装包的登记信息如下，装完后想核对是否为同一份包，可以对照这几项：

| 项目 | 值 |
| --- | --- |
| 版本号 | 8.3.50 |
| 包名 | com.lofter.android |
| 安装包大小 | 173.53 MB |
| MD5 | 930904C4E27394272712962C4E0424DD |

各应用商店提供的版本号通常比这更新，这很正常 —— 版本只说明发布时间不同，不影响安装使用。

## 二、下载安装文件

1. 打开 [LOFTER 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0930863160fe)。
2. 按网盘页面提示把文件转存到自己的网盘账号，再从网盘下载到手机（手机上装夸克 App 操作更顺）。
3. 下载完成后得到一个 `.apk` 文件，例如 `lofter_v8.3.50.apk`。

## 三、安装步骤

1. 在手机文件管理里找到刚下载的 `.apk` 文件，点它。
2. 第一次装非商店应用时，系统会提示「不允许安装未知来源应用」—— 按提示允许当前文件管理器（或浏览器）安装应用即可，各品牌叫法略有差异，一般在弹窗里点「设置」→ 打开「允许安装」。
3. 回到安装界面，点「安装」，等进度条走完。
4. 点「完成」或「打开」，桌面上会出现 LOFTER 图标。

## 四、安装失败怎么排查

装不上时，按出现概率从高到低排查：

| 现象 | 常见原因 | 处理办法 |
| --- | --- | --- |
| 提示「解析包出现问题」 | 安装包没下载完整，或系统版本低于要求 | 删掉重下一遍；确认安卓版本满足第一节的要求 |
| 提示存储空间不足 | 剩余空间不够 | 清出 2 GB 以上空间再装 |
| 提示「已存在同名应用」或安装被跳过 | 手机上装过 LOFTER，签名信息不一致 | 先卸载旧版再装（卸载会清掉本地数据，需要留的内容先导出） |
| 下载到一半速度归零 | 网络波动 | 换 Wi-Fi / 流量，或重进网盘继续下载 |

## 五、装好之后第一次打开

首次打开会先要基础权限（存储、通知等，按需允许），然后进入登录页。LOFTER 支持手机号、网易邮箱账号以及 QQ、微信、微博等第三方方式登录，各方式差别与忘记密码的处理见 [注册登录与账号问题.md](注册登录与账号问题.md)。

登录时会让你先选几个感兴趣的内容方向，选得越准，首页推给你的内容越对口味，之后随时可以在设置里改。装完遇到图片加载不出来之类的情况，处理步骤在 [常见问题与解决办法.md](常见问题与解决办法.md)。
