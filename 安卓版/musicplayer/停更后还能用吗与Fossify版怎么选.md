## 一、发生了什么：一条时间线

先给结论：**你手上这个应用还能用，但它的原开发团队确实不再维护它了**，社区另开了一个分支项目在继续开发。已核实的事实按时间排列：

| 时间 | 事件 | 证据来源 |
| --- | --- | --- |
| 2023 年底 | Simple Mobile Tools 被出售给 ZipoApps | 多个独立社区来源互相印证（GrapheneOS 论坛、MalwareTips 等） |
| 2024 年初 | 社区从停更前的代码分支出去，成立 Fossify 项目 | Fossify 官网与 GitHub 组织页 |
| 持续至今 | Fossify 版持续发新版本 | Fossify 官网显示 2026 年 2 月已发布 v1.8.1 |

Fossify 官网的原话是「SimpleMobileTools 已停止维护（discontinued / no longer maintained）」，这是分支项目自己页面上的说法。同时 Google Play 上原包名的应用仍显示有更新记录——**两边并列存在，不替你选边**：Play 上的更新由谁在发，公开渠道没有给出可核实的官方说明。

## 二、现状对照：原版 vs Fossify 版

截至 2026 年 9 月检索时的信息（之后以各页面当时显示为准）：

| 对照项 | 原版（本套文档讲的这个） | Fossify 版 |
| --- | --- | --- |
| 包名 | `com.simplemobiletools.musicplayer` | `org.fossify.musicplayer` |
| 开发方 | Simple Mobile Tools（原团队已停更） | Fossify 社区 |
| 官方站点 | `simplemobiletools.com` | [www.fossify.org](http://www.fossify.org) |
| GitHub | `SimpleMobileTools/Simple-Music-Player`（不再更新） | `FossifyOrg/Music-Player`（持续更新） |
| 商店版本 | 已到 6.1.x（原渠道口径） | 已到 1.8.x |
| 开源许可 | GPL-3.0 | GPL-3.0 |
| 广告 | 无 | 无 |
| 网盘里的版本 | 5.10.1（见 [下载与安装教程.md](下载与安装教程.md)） | 不适用 |

功能面两者同源：离线播放、均衡器、睡眠定时、播放列表、可自定义颜色的小部件——这些在 Fossify 版的官方介绍里都能对上。

## 三、判断依据：什么情况留在原版

**留在原版（继续用 5.10.1 或商店版）的理由**：

- 现在这版工作正常，你的诉求只是听本地歌，没有必须新版本才能解决的问题；
- 你已经建好了播放列表、调好了设置，换应用意味着重新配置（两个包名不同，是两个独立应用，**播放列表和设置不会跟着迁移**，只能手动重建）；
- 原版停更不等于不能用：它不联网、无广告，停更的风险面比联网应用小得多。

**考虑换 Fossify 版的理由**：

- 你碰到了原版在新系统上的 bug，而它已不会再有修复（排查完确实无解时，见 [歌曲不显示与播放异常怎么办.md](歌曲不显示与播放异常怎么办.md)）；
- 你希望以后还有版本更新和问题响应；
- 你在意「由社区继续维护」这一点本身。

**怎么换**：两个应用包名不同，可以共存。装上 Fossify 版 → 在文件管理器里把歌单顺序记一下 → 装好后重建列表 → 确认能正常播了，再卸载原版。歌单里歌曲文件本身不受影响（参照 [播放列表与歌曲标签编辑.md](播放列表与歌曲标签编辑.md) 的说明，从列表移除不删文件）。

## 四、不建议做的事

- **不要从来路不明的渠道获取来路不明的安装包**：本套文档只走官方与自有网盘的正常安装包（[Simple Music Player 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c91a9106b2be)），其他渠道的包有没有被改过，你无从核实，风险自负；
- **不要因为「停更」就恐慌卸载**：判断依据在第三节，够用就继续用；
- **不要同时装一堆同类播放器**：它们会同时扫描媒体库、抢音频焦点，表现出来就是「歌单重复显示」「播放自己切歌」，排查起来反而绕（见 [歌曲不显示与播放异常怎么办.md](歌曲不显示与播放异常怎么办.md)）。
