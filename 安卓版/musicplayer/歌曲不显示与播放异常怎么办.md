## 一、先定位问题属于哪一类

这篇只覆盖**本地播放器**会遇到的问题，按现象分三类，对号入座：

| 现象 | 大概率原因 | 跳到 |
| --- | --- | --- |
| 列表里少歌 / 整个列表是空的 | 存储权限、扫描时机、文件本身不支持 | 第二节 |
| 播放中途停、锁屏后断 | 系统后台限制、电池优化 | 第三节 |
| 桌面小部件不显示或不更新 | 小部件被移除、应用被系统清理 | 第四节 |

装不上、装完闪退的问题不在本篇，见 [下载与安装教程.md](下载与安装教程.md)。

## 二、歌曲不显示：按顺序查这四步

**第 1 步：确认存储权限还在。**
应用扫歌靠的是读取存储的权限。系统更新、或你曾在设置里清理过权限，都可能把它收回。路径：手机「设置 → 应用 → 找到本应用 → 权限」，确认「音乐和音频」（或「文件和媒体」，不同系统叫法不同）是允许状态。改完回到应用重新进入一次。

**第 2 步：手动重新扫描。**
权限没问题的话，在应用内触发一次重新扫描（歌曲列表下拉刷新，或设置里的「重新扫描」类入口）。两个影响扫描结果的实际因素：

- **文件格式**：它扫的是系统媒体库识别的常见音频格式；一个不被识别的文件不会出现在任何分组里；
- **放在深层目录或 `.nomedia` 目录里**：这类位置会被媒体库跳过，把歌移到普通音乐文件夹再扫一次。

重扫仍然少歌时，先清一次缓存再扫：「设置 → 应用 → 本应用 → 存储 → 清除缓存」。清缓存不会动你的歌曲文件和播放列表，它只是丢掉临时索引，让扫描从头构建一遍。

**第 3 步：确认歌真的在。**
用文件管理器打开你放歌的文件夹，确认文件在、文件名后缀是音频格式、文件大小不是 0。文件本身有问题（下载中断、实为其他格式改后缀），播放器扫到了也放不出来——这种在 [播放列表与歌曲标签编辑.md](播放列表与歌曲标签编辑.md) 里改标签没用，得先换一个好的文件。

**第 4 步：SD 卡的情况。**
歌在 SD 卡上时，多一步：确认 SD 卡没有被系统卸载为「便携存储」以外的模式，且权限授权的是「SD 卡」而非仅内部存储。刚插的卡要重启一次应用才会被扫到。

> 只有「少了几首」而不是「全空」时，重点查第 2 步；「全空」重点查第 1 步。

## 三、播放中途停、锁屏后断

这个应用本身**不需要联网**（官方口径：完全离线播放），所以断播跟网络无关，几乎都是系统在省电时把它杀了。按顺序处理：

1. **关掉对它的电池优化**：手机「设置 → 电池 → 电池优化」（或「省电策略」），把它设为「不优化」。不同品牌叫法不同：小米叫「省电策略」、华为/荣耀叫「关闭电池优化」、OPPO/vivo 在「个性化设置」附近。原则一样——别让系统在锁屏后限制它。
2. **允许后台运行**：在应用信息页把「后台活动」或「自启动」打开（部分系统还需要在「最近任务」里给卡片上锁，防止一键清理误杀）。
3. **检查是不是你自己切了歌**：耳机线控的下一曲键误触、蓝牙设备抢焦点，都会表现成「自己跳歌」。拔掉耳机用外放验证一轮即可区分。
4. **通知栏控制还在不在**：正常播放时下拉通知栏应有播放控制条。它消失说明服务被杀了，回到第 1、2 步。

排查期间可以对照 [均衡器与睡眠定时设置.md](均衡器与睡眠定时设置.md) 排除「睡眠定时到点自动停」——那不是故障，是定时在按设计工作。

**锁屏上没有播放控制条**是同一类问题的另一个表现，单独按这三步查：

1. **通知权限**：媒体控制条本质是一条通知。到「设置 → 应用 → 本应用 → 通知」确认没有被整体关闭，「媒体播放」类别的通知要开着；
2. **勿扰模式**：系统开了勿扰或专注模式时，媒体通知可能被一并压掉——播放音乐时下拉通知栏看看控制条在不在，就能区分是不是这个原因；
3. **锁屏通知显示设置**：「设置 → 通知 → 锁屏通知」需允许显示，否则解锁前看不到。

这三步都正常、只有锁屏不显示而通知栏里有，属于系统版本的显示行为差异，不影响播放本身。

## 四、桌面小部件不更新

小部件（播放控件挂件）怎么添加、颜色怎么改，在 [桌面小部件添加与颜色设置.md](桌面小部件添加与颜色设置.md)；状态不刷新则按这个顺序查：

1. **小部件还在不在桌面上**：系统更新后部分小部件会整体丢失，长按桌面 → 添加小部件，重新拖一个出来；
2. **点了没反应**：先打开一次应用本体——应用被系统清理后，小部件的点击会先拉起应用；
3. **显示的是上一首的信息**：手动暂停再播放一次，看信息是否跟着刷新；不刷新则回到第三节把后台限制关掉；
4. **颜色看不清**：小部件的文字和背景颜色可以在应用设置里改，这不是坏了，是配色问题。

## 五、什么时候该考虑重装

上面都试过、问题依旧，且你确认**别的播放器能正常放同一批歌**（用系统自带播放器验证即可），才轮到重装：

1. 记下你的版本信息（对照 [下载与安装教程.md](下载与安装教程.md) 的表格）；
2. 卸载本应用——**播放列表会随卸载一起没**，歌曲文件本身不受影响；
3. 重新安装对应版本，首次授权后再扫一次。

若换个播放器也放不了同一批歌，问题在文件或系统解码，不在这个应用，无需重装。
