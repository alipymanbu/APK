## 一、先确认你要装的是哪一个

Android 上叫「Music Player」的应用有几十个，商店里同名的甚至不是同一个开发者的产物。本篇讲的这个，识别特征是这三条，缺一不可：

| 项目 | 值 |
| --- | --- |
| 官方名称 | Simple Music Player |
| 包名 | `com.simplemobiletools.musicplayer` |
| 开发者 | Simple Mobile Tools |

装之前你可以先看一眼安装来源给的包名；装完后在「设置 → 应用 → 应用信息」里也能看到这个包名，对得上才是本篇讲的那个应用。

## 二、从网盘拿安装包

[Simple Music Player 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c91a9106b2be) 里存的安装文件版本固定，核对信息如下（以这份为准；网上商店里的版本会更新，不一定是同一个）：

| 项目 | 值 |
| --- | --- |
| 版本号 | 5.10.1 |
| 包名 | `com.simplemobiletools.musicplayer` |
| 安装包大小 | 7.73M |
| MD5 | `BA02A80D0F600C66A6DA5F8D0AE57498` |

下载完成后，可以用文件管理器看一下文件大小是否接近 7.73M；对不上说明下载不完整，重新下一次即可。文件夹里还有一份防失效说明，建议先转存到自己的网盘再下载，链接失效时不至于拿不到文件。

## 三、安装步骤

1. 在手机上打开网盘链接，把安装包转存并下载到本机（也可以先传到手机）。
2. 点击 `.apk` 文件开始安装。
3. 如果系统弹出「禁止安装来自此来源的应用」，这是系统对「非商店渠道安装」的常规拦截：按提示进入「安装未知应用」的授权页，给你的浏览器或文件管理器打开该权限，再返回安装一次。
4. 装完打开应用，首次启动会请求访问音乐文件的权限，点允许——不允许的话它扫不到你手机里的歌。

这个安装包要求安卓系统 5.2 以上。如果你的设备系统版本更低，安装时会直接提示失败。

## 四、首次打开：它怎么找你的歌

第一次进入后，应用会扫描手机内部存储和 SD 卡里的兼容音频文件，扫完直接按「歌曲 / 艺术家 / 专辑」等标签分好类，不需要你手动导入。几个首次使用的要点：

- **歌放在哪都行**，只要在它能访问到的存储里（内部存储或 SD 卡均可），不要求特定文件夹。
- 扫完如果发现少了几首，多半是权限或扫描时机问题，按 [歌曲不显示与播放异常怎么办.md](歌曲不显示与播放异常怎么办.md) 排查。
- 界面默认深色主题，颜色可以在设置里改；播放页上一曲/下一曲、随机、循环都在底部一排。

## 五、版本怎么看、要不要更新

应用内查看版本号的位置在「设置 → 关于」（不同系统入口文案可能略有差异）。拿它和下表对照，能确认你手上是哪个版本：

| 渠道 | 版本情况 |
| --- | --- |
| 本篇网盘里的包 | 5.10.1，固定不变 |
| Google Play | 版本持续迭代，已高于 5.10.1（检索时已到 6.1.3，之后以官方页面为准） |
| F-Droid | 开源渠道，同样在更新 |

几点关于更新的事实，供你判断：

- 这个应用是开源的（GPL-3.0 许可），代码托管在 GitHub 的 `SimpleMobileTools/Simple-Music-Player` 仓库。
- **原开发团队已停止维护这套应用**：2023 年底 Simple Mobile Tools 被出售，此后官方仓库不再更新；社区从停止维护前的代码分支出去，另开了 Fossify 项目继续迭代（Fossify 官网原话是「SimpleMobileTools 已停止维护」）。所以商店里能看到新版本号，但维护方的情况已经变了——这属于第三方文档记录的公开事实，最新状态以各渠道页面当时显示为准。**停更的来龙去脉、要不要换 Fossify 版**，单独写在 [停更后还能用吗与Fossify版怎么选.md](停更后还能用吗与Fossify版怎么选.md)。
- 你如果只是想稳定听歌、不折腾，网盘里这版 5.10.1 装上就能用；要追新版本再考虑商店渠道。
