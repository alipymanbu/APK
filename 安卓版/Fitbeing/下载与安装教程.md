## 一、安装前先确认两件事

Fitbeing 是智能手表的配套 App，装在**手机**上，不装在手表里。你的手表能否用它配对，以购买设备时附带的说明书或包装标注为准——Fitbeing 官方渠道列出的适配机型覆盖多款智能手表（例如 EELUCK X1 / F5 / W2 / C2 / S3 / S4 等型号），不同批次固件要求可能不同。

第二件事是系统版本。较新版本的 Fitbeing 对安卓系统版本要求逐步提高，安装前以应用商店页面或安装包实际提示为准；手机系统太旧时，装上后可能闪退或搜不到蓝牙设备。

## 三、安装步骤

1. 在手机上打开夸克网盘，把分享内容转存到自己的网盘，再下载 APK 文件（约 165 MB，建议在 Wi-Fi 下进行）。
2. 在手机文件管理器里点开下载完成的 APK。首次安装本机来源的应用时，系统会提示「允许安装未知来源应用」，按提示允许当前文件管理器或浏览器的安装权限。
3. 点「安装」，等待进度结束。安装包较大，低配手机上安装过程可能持续一两分钟，不要中途退出。
4. 安装完成点「打开」。首次启动会依次申请位置、蓝牙、附近设备、通知等权限，建议逐项允许（原因见下一节）。

不想用 APK 安装的话，也可以在国内主流应用商店（腾讯应用宝、小米应用商店等）搜索「Fitbeing」安装官方最新版，两者包名相同，都是 `com.watchic.app`。装完打不开、闪退这类安装侧的问题，见 [常见问题与排查.md](常见问题与排查.md) 第五节。

## 四、权限说明：拒绝哪项就少哪个功能

Fitbeing 申请的权限比较多，这是手表配套应用的常态——手表上接打电话、收通知、换表盘，都要靠手机这边授权。官方在应用商店页面给出的对应关系如下，拒绝某项权限后相关功能会不可用：

| 权限 | 用途 | 不给的后果 |
| --- | --- | --- |
| 联系人 | 手表上查看、接打电话 | 手表无法同步通讯录与来电联系人 |
| 短信 | 通过手表接收、回复短信 | 手表收不到、回不了短信 |
| 存储与照片 | 设置照片表盘、反馈时上传图片 | 不能自定义照片表盘 |
| 位置（含后台位置） | 天气同步、地区选择、运动轨迹 | 手表天气不准、户外运动画不出轨迹 |
| 相机 | 拍照表盘、反馈时拍摄 | 这两项功能不可用 |
| 通知 | 把手机通知推到手表 | 手表收不到任何 App 推送 |
| 附近设备 / 蓝牙 | 搜索并连接手表 | 直接无法配对 |

装完可以先全部允许，用一段时间后再按需收紧；唯独「位置」和「附近设备/蓝牙」两项建议保持开启，它们是连接手表的基础。

## 五、装好之后做什么

首次打开 App 后，主页上点「设置手表」（部分版本叫「添加设备」），用蓝牙搜索功能把手表连上，这一步的完整流程和常见失败原因在 [手表配对与连接.md](手表配对与连接.md) 里展开。连上之后，可以到 [通知与表盘设置.md](通知与表盘设置.md) 配置哪些 App 的消息推到手表，再到 [健康监测与运动记录.md](健康监测与运动记录.md) 看怎么看睡眠、心率这些数据。
