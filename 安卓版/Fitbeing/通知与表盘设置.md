## 一、通知同步：安卓和 iPhone 的设置路径不一样

前提都一样：手机蓝牙开着、手表在 10 米内、Fitbeing 已拿到「通知」权限（权限对照见 [下载与安装教程.md](下载与安装教程.md)）。在此基础上：

**安卓手机：**

1. 确认 Fitbeing 拿到了蓝牙、位置、通知三项权限。
2. 在 Fitbeing 里进入通知设置，勾选哪些 App 的消息要推到手表（微信、来电、短信可以单独开关）。
3. 让 Fitbeing 保持后台运行——安卓系统杀后台后通知就断了，这是「手表收不到微信」的最常见原因。在系统设置里给 Fitbeing 开「允许自启动」「允许后台运行」，有「电池优化」选项的设为不优化。

**iPhone：**

1. 手机蓝牙开启且在手表连接范围内。
2. 在手机的蓝牙设置里，为手表开启「共享系统通知」权限。
3. 同样在 Fitbeing 里选择要推送的 App。

两边设置完可以当场验证：让朋友发条消息，看手表几秒内有没有震动提示。收不到时按「权限 → 后台存活 → 勿扰模式」的顺序查——手表控制中心开了勿扰或专注模式时，通知是静默的，看起来就像没同步。完整的通知排查链路（含两个容易被忽略的场景：正停留在手机聊天界面、同一 App 在电脑端登录时，消息都不会推到手表）见 [常见问题与排查.md](常见问题与排查.md)。

## 二、表盘：自带表盘与照片表盘

换表盘在 App 里操作：进入表盘模块挑选，点应用即可推送到手表。想用自己的照片做表盘，选照片表盘类型，从手机相册选图——这一步需要 App 有存储权限，拒绝过权限的回 [下载与安装教程.md](下载与安装教程.md) 的权限表里补。

App 里的表盘库会不定期上新，挑不到合适的隔段时间再看看。

## 三、控制中心：上滑即达的常用开关

手表主表盘界面上滑，调出控制中心。这一排开关日常用得最多，逐个说明：

| 开关 | 作用 |
| --- | --- |
| 睡眠 / 勿扰 / 专注 | 三档静音：睡眠档同时关闭抬腕亮屏与常显；勿扰档静音消息和来电（闹钟仍响）；专注模式按需选 |
| 常亮显示 | 开启后屏幕暗态也保持显示，更耗电 |
| 抬腕亮屏 | 抬手自动亮屏 |
| 手电筒 | 全屏白光照明 |
| 锁定 / 防水锁 | 游泳洗手前开启防误触，出水后长按表冠解锁 |
| 查找手机 | 让手机响铃，找就近放着的手机 |
| 声音提醒 | 关闭即切换静音 |
| 屏幕亮度 | 手动调节 |

## 四、手表上的基本操作

操作围绕表冠和触屏两套进行，花一分钟记住这几下，后面都用得上：

- **按表冠**：灭屏时按一下亮屏；在主表盘时按一下进应用中心；在应用里按一下相当于返回/退出。
- **旋转表冠**：在列表和菜单间滚动；通话时调音量。
- **侧边按钮**：按一下快速开始运动；**长按触发 SOS 紧急求助**，放口袋里时注意别误长按。
- **触屏**：四个方向滑动加点击，上滑控制中心、下滑通知列表，左右滑切换卡片。

语音方面，对着手表可以直接语音启动手表功能或做简单查询（部分型号支持）。设置类操作（表盘、通知范围、固件升级）都回 App 端做，手表端只留快捷开关，这与 [数据同步与第三方平台.md](数据同步与第三方平台.md) 里「固件在 App 里升级」是同一个逻辑。
