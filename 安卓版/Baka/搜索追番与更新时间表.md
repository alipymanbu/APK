## 一、首页能刷到什么

打开 Baka 进入首页，内容大体分三类：

- **推荐与热门**：当前热度较高的作品卡片，直接点进详情页。
- **分类**：按地区（日本、国产、欧美等）、题材（热血、恋爱、冒险、日常等）划分，适合「不知道看什么、随便逛逛」的场景。
- **榜单**：日榜、月榜、季榜、总榜分档统计，想补热度高的老番时直接翻总榜比在分类里翻页快。

首页内容来自你在用的番剧源，**源不同，首页刷到的东西就不同**。某个源挂了或被你关掉，对应的内容会从首页消失，这不是应用坏了——先去[番剧源与站点管理](番剧源与站点管理.md)确认源的启用状态。

## 二、搜索：怎么搜才搜得到

点顶部搜索框输入关键词即可。几个提高命中率的做法：

| 情况 | 做法 |
| --- | --- |
| 记得完整名 | 直接输全名，如「葬送的芙莉莲」 |
| 只记得片段 | 输最有辨识度的两三个字，输全名错一个字反而搜不到 |
| 搜不到 | 换一个源再搜；不同源的收录范围不一样，这个源没有的另一个源可能有 |
| 名字有别名 | 日番常有多种译名，换常用译名再试一次 |

搜不到时先别怀疑应用：**Baka 本身不存任何番剧，搜索是在各个源之间跑的**。排查顺序是：确认网络通 → 确认源可用 → 换源重搜。具体操作见[番剧源与站点管理](番剧源与站点管理.md)，源失效的判断见[常见问题与排查](常见问题与排查.md)。

顺带一句版本差异：「自动别名搜索」（搜译名也能命中）是 4.6.0 起新版才有的能力；4.4.0 里碰到译名问题，就得靠你手动换说法。

## 三、更新时间表：每天更了什么

详情页之外的另一个追番入口是**更新时间表**：按星期排列正在连载的番剧，哪天更新哪部一目了然。追当季新番时，它的用法是：

1. 进更新时间表，看你追的番排在周几。
2. 到点后直接从时间表点进去看最新一集，不用每次都搜索。
3. 配合收藏（追番）使用——把连载中的番加入收藏，比每次翻时间表更省事。

已完结的老番不会出现在更新时间表里，补老番用搜索或榜单。

## 四、收藏与观看记录：看了一半的番怎么找回

- **收藏（追番）**：详情页里把番加入收藏，之后在「我的」相关入口里集中管理，追的番更新了你也能更快注意到。
- **观看记录**：看过的每一集都会留下进度，下次打开接着上次的位置继续播，不用自己记集数。
- **登录同步**：本地记录换机或重装就没了；注册并登录账号后，观看历史可以在设备间同步。登录入口在「我的」页面点头像进入。

看一半的番突然找不到时，按这个顺序找：收藏列表 → 观看记录 → 搜索原名。三处都没有，多半是源失效或换源导致条目对不上，去[番剧源与站点管理](番剧源与站点管理.md)换回原来的源通常就能找回来。

## 五、追番的典型一天

把上面几条串起来，追当季新番的完整动线是：

1. 开播前：搜索番名 → 进详情页 → 加入收藏。
2. 每次更新：打开应用 → 从收藏或更新时间表进详情 → 播最新一集。
3. 播放时：开弹幕、调倍速、切线路（操作见[弹幕与播放器设置](弹幕与播放器设置.md)）。
4. 出门前：把没看的新集缓存到本地（见[离线缓存与下载管理](离线缓存与下载管理.md)）。
