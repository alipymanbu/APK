## 一、首页刷不出来 / 一直转圈

排查顺序从便宜到贵：

1. **确认手机能上网**：开浏览器随便开个网页。别的应用也不行就是网络问题，与 Baka 无关。
2. **换网络再试**：Wi-Fi 和移动数据各试一次。某些校园网、公司网会对这类站点的访问做限制，换网立刻恢复就说明是网络侧拦的。
3. **确认源的状态**：首页内容来自各番剧源，源全挂了首页就是空的。去「我的」的源管理入口看启用状态，按[番剧源与站点管理](番剧源与站点管理.md)第五节处理。
4. **彻底重启应用**：从后台划掉重开，让规则和网络状态重新初始化。

## 二、番剧搜不到 / 详情打不开

- **先换源搜**：同一关键词换个源能搜到，就是原源没收录或失效，不是你的问题。
- **换译名**：日番译名多，换通行译名再搜一次。
- **详情页打不开但列表正常**：这一条目的源侧页面变了，换源看同一部番。
- **一切都搜不到**：回到第一节，是网络或规则更新的问题——规则的更新依赖对 GitHub 加速节点、jsDelivr 的访问，官方做了自动回退，但你这边网络把这三个地址全拦住时规则就更新不动。

## 三、播放失败 / 频繁卡顿

| 现象 | 多半是 | 先做什么 |
| --- | --- | --- |
| 点播放转圈后报错 | 这条线路/源解析失效 | 换线路、换源 |
| 能播但频繁缓冲 | 线路慢或网络抖 | 换线路；Wi-Fi 换 5G 频段 |
| 画面糊 | 片源本身清晰度低 | 换源找高清版本，播放器调不回来 |
| 有声音没画面 / 反之 | 解码兼容问题 | 换线路；重启应用 |
| 播放中整个应用卡死 | 有用户反馈过的情况 | 后台划掉重开；反复出现就清应用缓存、换线路，仍不行考虑升级 |

弹幕没显示不在这张表里——冷门番弹幕池没有数据是常态，见[弹幕与播放器设置](弹幕与播放器设置.md)第四节。

## 四、登录与数据同步

- **注册收不到验证码**：换网络再试；注册这类操作走的是社区服务器，网络对它不通时就收不到。
- **忘记密码**：项目仓库里有多条忘记密码的用户反馈，未见公开的自助找回办法；实在找不回就重新注册一个，代价是原账号里同步过的历史跟不过去。
- **换机后记录没了**：本地记录不跨设备，登录账号且开过同步的才会跟着账号走。登录入口在「我的」→ 头像。
- **同步不上或不及时**：也有用户反馈过历史与收藏同步的问题。先确认两端登录的是同一账号、网络通，进对应页面下拉刷新；仍不行就退出登录重新登录一次。
- **下载缓存换机后消失**：缓存是本机文件，不随账号同步，换机只能重新下（见[离线缓存与下载管理](离线缓存与下载管理.md)）。

## 五、这个应用联网都在干什么

你在意隐私的话，官方源码里写明了主要网络行为，这里转述给你判断：

- **启动时上报一个匿名安装标识**：应用首次运行时在本地随机生成、不含账号和硬件信息，只用于统计各平台日活跃安装量。
- **番剧数据**：搜索、详情、播放请求都发往你当前所用规则对应的第三方站点——你看哪家的内容，就访问哪家。
- **规则与版本**：规则更新走 GitHub 加速节点（失败自动回退 jsDelivr、GitHub），版本检查走官方的版本信息端点。
- **社区功能**：登录、评论、历史同步发往默认社区 API；官方在设置里留了替换服务器的选项，进阶用户可以换成自己的。

以上每一条都能在开源仓库里核对，介意的话按自己的判断取舍。

## 六、重装与升级前看这里

卸载重装会同时丢掉两样东西：**本地缓存的视频**和**没同步过的观看记录**。所以动手前：

1. 确认账号已登录、同步已开，历史记录能找回来。
2. 接受缓存丢失（或先把要看的看完）。
3. 再卸载，然后从 [Baka 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7cb2e1e5983a)重新转存下载，按[下载与安装教程](下载与安装教程.md)装回。

升级到官方新版同理。新版本的安装包从项目 [GitHub Releases 页面](https://github.com/AniBakaBaka/AniBaka/releases)获取，各版改了什么、哪些修复治你正遇到的毛病，见[更新了什么与要不要升级](更新了什么与要不要升级.md)；版本差异（TV 端、WebDAV 等）在[下载与安装教程](下载与安装教程.md)第一节也有说明。
