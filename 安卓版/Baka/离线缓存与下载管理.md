## 一、下载前先登录，这是硬性的一步

和在线播放不同，**下载缓存需要先登录账号**。没登录时点下载会提示先登录，这是流程要求，不是出了故障。

注册登录的入口：打开「我的」页面 → 点头像进入 → 按提示注册并登录。登录之后除了解锁下载，观看历史也能在设备间同步——换手机、卸载重装时，同步过的记录能找回来（本地缓存的视频文件除外，见第四节）。

## 二、下载一部番的完整步骤

1. 搜索或从收藏进入番剧详情页，确认这个源有你要的集数。
2. 进播放页或详情页的下载入口，点下载按钮。
3. 选要缓存的集数。4.4.0 是一集一集下；一次勾选多集的批量下载是 5.0.0 起新版才有的能力。
4. 确认后任务进入下载队列，等进度走完。

两个影响成败的点：

- **下载走的是当前源**：这个源对这几集解析正常，下载才能成。列表里能播的集，下载基本都能成；下载报错的集，先在线播一下试试——播不了的就是源侧失效，换源再下。
- **给足存储空间**：一集番几百 MB 很常见，一次缓存十几集前先看一眼剩余空间，存储满了任务会中途失败。

## 三、下好之后在哪里看

下载完成的内容进应用里的下载管理（或缓存）入口集中存放：

- 列表按番剧分组，点开直接离线播放，不需要网络。
- 看完想腾空间，在下载管理里删除对应番剧或集数，存储随之释放。
- 缓存的内容只在 Baka 里能播，是应用自己的缓存格式，不要指望从文件管理器里把它拷给别人用。

## 四、什么场景该用缓存

| 场景 | 建议 |
| --- | --- |
| 通勤、出差路上网络不稳 | 提前把要看的几集缓存好，最稳 |
| 家里 Wi-Fi 快、流量金贵 | 大体积剧集连 Wi-Fi 下，别用移动数据硬下 |
| 追连载、当天就看 | 直接在线播，不必下载占空间 |
| 想在别的设备/播放器里看这个视频文件 | 缓存做不到，它是应用内缓存 |

## 五、下载常见失败与处理

- **点下载提示登录** → 回第一节，先注册登录。
- **任务卡在排队或进度不动** → 检查网络；进下载管理看有没有失败任务，失败的删掉重下。
- **整部番都下不了** → 当前源对该番的解析失效，按[番剧源与站点管理](番剧源与站点管理.md)第五节的顺序换源。
- **下载成功但播不出来** → 先在下载管理里确认状态是完成；仍不行就删掉这份缓存重新下，反复不成的去[常见问题与排查](常见问题与排查.md)对照处理。
