## 一、Baka 是什么，这份包是哪个版本

Baka（开源项目名 AniBaka）是一个跨平台的番剧聚合与弹幕播放客户端：你用它搜索和播放来自多个番剧源的内容，播放时可以加载、发送弹幕，也能把剧集缓存到本地离线看。它是 GPLv3 开源项目，源码和预构建安装包都在 GitHub 上公开，安卓手机版是其中最常用的一种形态。

动手之前，先对照下表确认你手上这一份包：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | Baka |
| 所属项目 | AniBaka（开源，GPLv3 许可） |
| 包名 | `ani.baka` |
| 版本号 | 4.4.0 |
| 安装包大小 | 31.38 MB |
| 安装包 MD5 | `2446F6F0ADDEFF74E356E4E698B4EAEB` |
| 系统要求 | 安卓 5.2 及以上（安装包标注口径） |

**版本号别拿网上搜到的来对。** 你搜索时看到的 4.5.x、5.x 是官方后来发布的新版，和这一份不是同一个包。判断装的对不对，只看两项：包名是不是 `ani.baka`，版本号是不是 4.4.0。官方标签在版本号后面还带一段加号日期码（如 `4.4.0+0131`），对版本时只看加号前的部分。

顺带说清版本差异，免得你看别的教程时对不上：官方 4.5.2 的更新说明里才提到适配安卓 TV 设备、支持 WebDAV 本地流媒体、重构源管理页面、新增 BGM 聚合搜索。也就是说，**这份 4.4.0 里没有 TV 端界面和 WebDAV 播放**，设置页里的「源管理」长得也和 4.5.2 之后的截图不一样——遇到这类描述时不要怀疑自己装错了。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享。相比在搜索结果里随手点一个「立即下载」，从网盘转存再下载的好处是：文件是固定的一份，不会被下载站中途替换或捆上别的东西。

1. 在手机上打开 [Baka 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7cb2e1e5983a)。浏览器和夸克 App 都能打开，**建议用夸克 App**——浏览器下载大文件容易被切后台打断。
2. 点「保存到我的网盘」转存到自己账号。转存之后再下载就不依赖原分享链接是否还有效。
3. 进自己的网盘找到这个 apk 文件，点下载，等它落到手机存储。
4. 下完核对两件事：文件扩展名是 `.apk`；大小在 31.38 MB 左右。明显偏小的多半没下完整，删掉重下。

有校验习惯的话，可以算一遍 MD5 和上表比对，一致说明传输没出错；不查也不影响安装。

## 三、安装：系统会拦一次，放行即可

这份包是手动安装的，不是从应用商店点的，所以点击安装包时系统会提示「不允许安装来自此来源的应用」。这是安卓对非商店来源的常规限制，不代表文件有问题。

1. 打开「文件管理」，进 `Download`（下载）目录，点刚下好的 apk。
2. 出现拦截提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型的路径是「设置 → 应用 → 特殊应用权限 → 安装未知应用」，找到你用来打开文件的那个 App（文件管理或浏览器），单独给它放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」，把首次启动的权限一次理顺再进去。

## 四、首次打开：权限与初始状态

第一次打开 Baka，主要会碰到这几件事：

- **网络权限**：搜索、加载番剧源、拉取弹幕都依赖网络，正常放行即可。
- **存储权限**：离线缓存和下载要把视频写进本地存储，用到下载功能前会给到这个申请；暂时只用在线播放可以拒绝，之后再给也行。
- **通知权限**：更新提醒类功能会申请通知，不看推送可以拒绝，不影响播放。
- **无需登录就能看**：浏览、搜索、在线播放不要求注册账号；只有下载缓存、同步观看历史这类功能才需要登录（见[离线缓存与下载管理](离线缓存与下载管理.md)）。

装完进首页能刷出番剧列表，就说明装好了。如果首页一直转圈或报网络错误，多半是当前网络访问源站点不通，处理思路见[番剧源与站点管理](番剧源与站点管理.md)和[常见问题与排查](常见问题与排查.md)。

## 五、想用新版本时去哪儿

这一份固定在 4.4.0。想跟进官方新版本，去项目的 [GitHub Releases 页面](https://github.com/AniBakaBaka/AniBaka/releases)按你的系统和 CPU 架构选对应安装包，官方新功能的说明也以各条 Release 附带的信息为准；这几个月各版都改了什么、值不值得升，[更新了什么与要不要升级](更新了什么与要不要升级.md)按官方说明逐版列了。项目官网与版本信息入口在 [https://app.anibaka.com](https://app.anibaka.com/)，开发者文档在 [https://docs.anibaka.com](https://docs.anibaka.com/)。升级前注意：卸载重装会丢掉本地缓存和未同步的观看记录，先看[常见问题与排查](常见问题与排查.md)里的重装一段再动手。
