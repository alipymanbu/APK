## 一、添加设备要填哪几项

装好 OPAssistant 后，先在设备列表里添加一台设备。要填的是主机地址、端口、用户名、密码（以 App 实际界面为准，不同版本字段名可能略有差异）。

理解这些字段的关键：**OPAssistant 连的是 OpenWrt 的管理界面（LuCI）**——就是你平时在浏览器里打开的那个路由器管理页。所以端口、用户名、密码与你登录管理页用的是同一套：

| 字段 | 填什么 | 常见值 |
| --- | --- | --- |
| 主机地址 | 路由器的管理 IP | 局域网常见 `192.168.1.1`，以手机 Wi-Fi 详情里的「网关」为准 |
| 端口 | 路由器网页管理页的端口 | 默认 `80`；启用 HTTPS 后为 `443`；自己改过就填改过的 |
| 用户名 | 路由器管理员用户名 | 一般是 `root` |
| 密码 | 路由器管理员密码 | OpenWrt 管理页登录用的那个，不是 Wi-Fi 密码 |

填完保存，App 会去连这台路由器。连上后就能在手机上看状态数据了。

两点补充：

- 主机地址除了填 IP，也**支持填域名**（作者说明的功能口径）——配合 DDNS 做远程连接时正好用得上；
- 密码从没设置过的话，先用浏览器登录 LuCI，在「系统 → 管理权限」里设置一个，再回到 App 里填。

## 二、局域网连接（最常见的用法）

前提：**手机与被管理的路由器在同一个网络里**——手机连着这台路由器的 Wi-Fi，或者连在它下面的局域网。

最不容易填错的做法：打开手机的 Wi-Fi 详情，看「网关 / 路由器」那一栏的 IP，把它填进主机地址。这个地址就是你浏览器里打开管理页用的地址。

## 三、公网远程连接

官方介绍说明支持通过公网 IP 地址远程管理，并支持 IPv6——也就是人不在家也能管家里的路由器。但前提是路由器得能从公网到达，这个条件要你自己满足：

- **有公网 IPv4**：宽带运营商分配的是公网地址（多数家庭宽带默认没有公网 IPv4）；
- **或走 IPv6**：运营商和路由器都启用了 IPv6，手机在外用流量时也有 IPv6 地址；
- 两样都没有（内网地址、NAT 后面）时，需要先自行搭内网穿透或端口映射，OPAssistant 本身不负责这一段。

**安全提醒**：管理端口对公网开放，意味着任何人都能访问到你路由器的登录页。开远程之前先确认：管理密码是强密码、没有用默认密码；有条件的话在防火墙里限制允许访问的来源。是否长期对公网开放，想清楚再开。

具体到 OpenWrt：默认防火墙本来就拦掉来自 WAN 侧的入站连接，所以「外网连不上管理页」是默认状态。要让 App 从外面连进来，你需要自己加一条放行规则或端口转发；操作的位置在 LuCI 的「网络 → 防火墙」。顺手把固件更新到当前稳定版也是同一件事的一部分——旧固件的已知漏洞不会自己修好。

## 四、IPv6 地址的填法

设备列表支持直接添加 IPv6 地址。在启用了 IPv6 的家庭宽带下，路由器通常会分到一个 `2` 或 `240` 开头的公网 IPv6 地址，把它填进主机地址即可。

注意：家庭宽带的 IPv6 地址在前缀变化（重新拨号等）后会跟着变，地址失效、原来加的设备连不上时，先重新确认路由器当前的 IPv6 地址。

## 五、管理多台路由器

设备列表可以添加多台 OpenWrt 设备，在 App 里切换查看。典型场景：

- 主路由 + 旁路由各一台，分开监控；
- 家里和公司各一台；
- 树莓派、x86 软路由、OpenWrt One、GL.iNet 等设备上跑的 OpenWrt，各自添加管理地址即可。

## 六、兼容性口径

官方页面的口径：兼容 **21.02 之后的所有 OpenWrt 版本，支持所有机型**。作者在发布说明里补充过更细的一条：**只要 LuCI 是 2.0 的都支持**，闭源固件或过老的固件不支持管理；App Store 的介绍则提到上网行为管理（OAF）相关功能需要 OpenWrt 19.07 以上并配较新版本的 LuCI。官方材料里列到的硬件有 OpenWrt One、GL.iNet flint2、树莓派、x86 等。

你的 OpenWrt 版本特别老（比如 18.06 那一代）或用的是闭源固件时，作者口径里明确不在支持范围，建议先升级固件再连。

## 七、连不上时的快速排查

按这张表过一遍，解决不了再看 [常见问题解答.md](常见问题解答.md)：

| 现象 | 先查什么 |
| --- | --- |
| 连接超时 | 手机和路由器是否同一局域网；主机地址是否填错 |
| 密码错误 | 用户名是不是 `root`；密码是管理页那个，不是 Wi-Fi 密码 |
| 端口不通 | 端口与管理页是否一致（80 / 443）；路由器是否禁用了 Web 管理 |
| 之前能连现在不行 | 路由器 IP 是否变了（重新拨号、DHCP 重新分配），重新确认网关地址 |
| 用 IPv6 连不上 | 路由器 IPv6 地址是否已变，重新查一次 |
