# AmazFaces 怎么把表盘装到手表

## 一、前提条件

- 手机上已装好 AmazFaces，并且**选对了手表型号**（型号错了，目录里的表盘跟你的手表对不上）。还没装的话先看 [下载与安装教程.md](下载与安装教程.md)。
- 手表蓝牙处于开启状态，手机蓝牙也开着。传输走的是手机与手表之间的蓝牙通道，全程在 AmazFaces 里完成，手表端不需要额外装东西。
- 手表电量别太低，传输过程中保持手表在手机附近。

## 二、挑一个表盘

目录里的表盘数量很大（官方页面标称超过 20 万款，截至 2026-09），几个找表盘的路子：

| 方式 | 怎么用 | 说明 |
| --- | --- | --- |
| 分类浏览 | 按目录页翻 | 最直观，适合随便逛 |
| 搜索 | 输关键词 | 适合有明确目标（比如「数字时钟」） |
| 标签 | 按标签筛选 | 快速缩小风格范围 |
| 语言筛选 | 选表盘支持的语言 | 排除看不懂的表盘 |
| Top 100 | 按月 / 年 / 全部时间排 | 想装「大多数人在用的」直接看这里 |
| 随机 | 随机展示 | 没有目标时碰运气 |

两点注意：

- **游客身份可以浏览、搜索、安装**；想把某个表盘存进收藏夹，才需要注册账号。
- 表盘页一般带预览图和作者标注，有的作者会标明适用系统版本，装之前扫一眼能少走弯路。

## 三、安装到手表

1. 在表盘详情页点安装（下载）按钮，手机会先取回表盘文件。
2. 按提示建立与手表的蓝牙连接。首次连接时手表上可能弹出配对确认，在手表上确认即可。
3. 等传输完成。表盘文件不大，一般几十秒内完成；期间别让手机离手表太远，也别切走 AmazFaces 去干别的。
4. 传输完成后，表盘会出现在手表的表盘列表里。

## 四、在手表上启用新表盘

装完不会自动替换当前表盘。在手表上：**点亮屏幕，长按表盘**，进入表盘选择页，左右滑动找到刚装的那个，点选即可启用。想切回旧表盘，同样长按切换。

## 五、Lite 版的安装方式不一样

如果你装的是官方的 **AmazFaces Lite**（只含免费表盘、不用注册的精简版），安装不走上面的蓝牙流程：在 Zepp App 里开启开发者模式（我的 → 设置 → 关于，连点 Zepp 图标 7 次直到弹出提示），再用 Zepp 的扫一扫扫表盘页二维码，表盘经 Zepp 通道进手表。本文网盘包是正式版，直接按第三节的蓝牙步骤走。两条通道的完整对比见 [和Zepp商店装表盘有什么区别.md](和Zepp商店装表盘有什么区别.md)。

## 六、传输不顺时按现象排查

- 手表一直搜不到 / 连不上：先在系统蓝牙里忽略掉旧配对记录再试，逐条对照 [常见问题与解决办法.md](常见问题与解决办法.md)。
- 传到一半失败：把手表和手机靠近一点，关掉手机上其他占用蓝牙的应用（比如正在连耳机的音乐 App）再传一次。
- 传完了但手表上找不到新表盘：确认当初选的型号和手表实际型号一致，对照 [适配手表型号一览.md](适配手表型号一览.md) 核对；型号选错的表盘手表不会显示。
