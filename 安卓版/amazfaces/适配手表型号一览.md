## 一、先确认你的手表属于哪一类

AmazFaces 面向的是**华米系（Amazfit / Zepp）智能手表**，以及少数小米手环型号。判断方法很简单：

- 手表配套的手机 App 是 **Zepp**（原 Amazfit/华米助手）→ 大概率在适配范围内，往下对照清单；
- 手表是 Apple Watch、Wear OS（如 TicWatch）或其他品牌 → 不适用，这款应用装了也用不上。

## 二、官方列出的适配型号

下面是官方商店描述里列出的型号，**截至 2026-09，以官方页面为准**——新款手表发布后官方会更新这个清单，更新日志里就能看到轨迹（4.8.432 版新增 Bip Max，4.8.434 版新增 Balance 3 与 Balance Ultra）：

| 系列 | 型号 |
| --- | --- |
| Bip | Amazfit Bip、Bip S、Bip U、Bip 3、Bip 5、Bip 6、Bip Max |
| GTR | GTR（47mm / 42mm）、GTR 2、GTR 3、GTR 3 Pro、GTR 4、GTR Mini |
| GTS | GTS、GTS 2、GTS 2 mini、GTS 3、GTS 4、GTS 4 mini |
| T-Rex | T-Rex、T-Rex 2、T-Rex Pro、T-Rex Ultra、T-Rex Ultra 2、T-Rex 3、T-Rex 3 Pro（44mm / 48mm） |
| Active / Balance | Active、Active Edge、Active 2（圆表盘 / 方表盘）、Active Max、Active 3 Premium、Balance、Balance 2、Balance 3、Balance Ultra |
| Cheetah / 其他 | Cheetah、Cheetah Pro、Cheetah 2 Pro、Cheetah Square、Falcon、Verge Lite |
| 小米手环 | 小米手环 4、小米手环 5（即 Amazfit Band 5）、小米手环 7 |

说明：

- 表盘是**按型号划分**的，一个表盘文件只对它标注的型号有效；同名系列的不同代（比如 GTR 2 和 GTR 3）互不通用。
- 同一型号如果存在圆屏 / 方屏两个变体（如 Active 2），表盘也不通用，选型号时注意别选错形态。

## 三、型号在 App 里起什么作用

首次启动时选定的型号，决定了你在 AmazFaces 里看到的一切：

- 目录、搜索结果、Top 100 都只展示**这个型号能用的表盘**，所以选对型号比什么都重要；
- **App 版本太旧会找不到新型号**：新增型号支持是随应用更新发布的，本文网盘里的 4.6 版发布早于上面提到的那几次更新，型号列表里可能没有 Bip Max、Balance 3、Balance Ultra 这些较新款。手表较新、App 里却翻不到型号，说明该换版本了——处理办法见 [常见问题与解决办法.md](常见问题与解决办法.md) 的版本一节；
- 如果发现搜索结果里混进了别的型号的表盘、装不上，这在该系列旧版本里是已知问题（官方在 4.7.408 版更新说明里提到修复了「搜索结果混入其他型号」的缺陷）；遇到时优先确认型号选择，再考虑换更新的版本。

## 四、清单里没有的型号

- **较新的型号**：官方页面上的适配清单更新得比应用商店描述勤，直接到官方页面核对，别只看本篇清单。
- **较老的型号**：清单里没列就不保证能用；装上后搜不到手表或传输失败，多半就是不适配。
- 部分仅支持二维码安装的场景（官方的 Lite 版走这条通道）需要在 Zepp App 里开启开发者模式后扫码，与本篇清单的型号无关，属于另一种安装方式。
