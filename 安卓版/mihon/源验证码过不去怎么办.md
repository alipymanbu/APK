# Mihon 源验证码过不去怎么办

> 打开源时弹「Failed to bypass Cloudflare」或一直转圈，按本文从手动过验证到网络设置逐级排查。

## 一、这个错误是什么

很多漫画网站前面架着 Cloudflare 这类反机器人验证：它分不清你是真人还是程序，就会弹验证码或直接拦下。Mihon 靠内置的 WebView（浏览器内核）去自动通过这些验证，**过不去时报的就是「Failed to bypass Cloudflare」**——这说明是「网站把你拦了」，不是应用本身坏了，也不是你的扩展装错了。

按下面顺序逐级处理，多数情况在前两步就能解决；每一步都做完再进下一步。

## 二、第一步：用 WebView 手动过验证

让真正的浏览器窗口替你过一次验证，是各份排障资料都排在第一位的做法：

1. 底部导航进 **浏览**，点开报错的那个源；
2. 点工具栏上的 **WebView 图标**，会弹出一个浏览器窗口；
3. 等验证页出现，把人机验证点掉（或等它自动通过）；
4. 点左上角 **X** 关闭窗口，回到源里重新加载。

在作品详情页里也可以走 **右上角 ⋮ → WebView**，效果一样。过完一次验证，站点一般会记住一段时间。

## 三、还不行：检查用户代理字符串

Cloudflare 会比对应用发出的 User-Agent 与 WebView 实际的浏览器版本，**两边对不上就会被当成机器人**（这一条在多个社区排障来源里说法一致）：

1. **更多 → 设置 → 高级**，找到 **默认用户代理字符串（Default user agent string）**；
2. 先在同一屏的调试信息里看你的 WebView 版本号，把字符串里的 Chrome 版本改成与它一致的；
3. 保存后完全退出、重启 Mihon，再试该源。

不确定该填什么：用手机浏览器搜 `what's my user agent`，复制查出来的完整字符串粘进去。改完仍失败就换别的版本试——不同站点认的版本不同，这是逐个试出来的，不是一次配对就全好。

## 四、网络层：换一个公共 DNS

部分地区的运营商 DNS 解析不了某些源的域名，表现是「扩展装着、点开就连接失败」。处理：

1. 打开手机 **设置 → 连接（或「网络和互联网」）→ 私人 DNS（Private DNS）**；
2. 选「私人 DNS 提供程序主机名」，填 `dns.adguard.com` 或 `dns.google`；
3. 保存后重启 Mihon 再试。

各家手机菜单名略有差异，在设置里搜「DNS」最快。

## 五、只有一个源这样、其他源正常

那就不是你的网络或设置问题，是**这一个站点在调整防护或这个扩展落后了**：

- 换收录同作品的其他源顶上（见 [常见问题排查.md](常见问题排查.md)）；
- 到 **浏览 → 扩展** 看它有没有 **更新** 按钮，有就更新；没有就卸载重装（步骤见 [扩展源添加教程.md](扩展源添加教程.md)）；
- 站点封得正狠时只能等社区更新扩展，反复重装应用不会让它提前解封。

## 六、有用户反馈的两个诱因（供参考）

社区排障帖里还有两种说法，**属单一来源反馈、未见官方确认**，你可以在上面几步都无效时顺手检查：

- **一次下太多触发拦截**：短时间内批量下载几十章，请求模式容易被识别——去 [阅读与下载设置.md](阅读与下载设置.md) 把下载并发调低、分批下；
- **网络出口信誉差**：公共 Wi-Fi 或某些代理出口的 IP 被 Cloudflare 低信誉标记，换回正常移动网络或家庭网络试试。
