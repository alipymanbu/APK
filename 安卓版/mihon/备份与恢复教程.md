# Mihon 备份与恢复教程

> 换手机、重装、从 Tachiyomi 迁移之前，先把书架和进度备份下来——本文讲备份里有什么、怎么备、怎么恢复。

## 一、备份里有什么、没有什么

**有**：书架作品与分类、追踪绑定、阅读历史与进度、应用与阅读器的各项设置。

**没有**：已下载的章节文件和本地漫画文件（它们就是你存储目录里的 `downloads/`、`local/` 文件夹），也不含扩展本身——恢复备份后要按 [扩展源添加教程.md](扩展源添加教程.md) 重新把仓库和扩展装回来。

一句话：**备份管「你的数据」，文件夹管「下载的图片」**，两者分开保存才稳妥。

## 二、手动创建备份

1. **更多 → 设置 → 数据（Data）**，点创建备份。
2. 备份文件生成在存储位置的 `autobackup/` 目录里，扩展名 `.tachibk`，文件名带日期时间，形如 `app.mihon_2026-09-26_12-00.tachibk`。
3. 把这个文件**复制一份到网盘或电脑**——只留在手机里的备份，手机坏了就一起没了。

## 三、开启自动备份

在 **设置 → 数据** 里可以开启自动备份并设置间隔与保留数量，应用会按时把 `.tachibk` 写进 `autobackup/` 目录。注意两点：

- 自动备份也只写在手机存储里，**定期把它拷出去**才算真正的异地备份；
- 这也是官方建议的日常习惯（Nightly 开发版尤其依赖它）。

## 四、恢复备份

1. 装好 Mihon（版本越新越好，旧版可能读不了新版备份）、按提示选好存储位置。
2. **更多 → 设置 → 数据 → 恢复备份**，选中你的 `.tachibk` 文件。
3. 恢复完成后书架、分类、追踪、进度都回来了；扩展不在备份里，重新添加仓库与扩展即可。
4. 下载过的章节要能离线读，需要 `downloads/` 文件夹还在原存储位置（或你换机时把它一起拷了）——换了位置就先在 **设置 → 高级** 里重新索引。

## 五、从 Tachiyomi 迁移过来

Mihon 与 Tachiyomi 用**同一套 `.tachibk` 备份格式**，迁移很直接：

1. 在旧 Tachiyomi 里创建备份，拿到 `.tachibk` 文件。
2. 安装 Mihon（安装步骤见 [下载与安装教程.md](下载与安装教程.md)）。
3. 恢复备份（操作同上）。
4. **存储位置**这一步直接选原来的 `Tachiyomi` 文件夹：旧的 `downloads/`、`local/` 能继续被识别。若你之前用的是旧版默认位置，官方 FAQ 的提示是——选中已有 `downloads` 文件夹时要选它的**父目录**（别选根目录也别选它自己），或者干脆先把下载文件挪到新位置。

备份文件名前缀（`app.mihon_`）是 Mihon 特意与各分叉版本区分开的，所以同一目录里 Tachiyomi、Mihon 各自的自动备份不会互相覆盖。
