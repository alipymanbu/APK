## 一、这份安装包是什么

Mihon 是一个开源的安卓漫画阅读器（Apache 2.0 许可），由原 Tachiyomi 团队的贡献者在原项目停止开发后继续维护，官网是 [mihon.app](https://mihon.app/)，源码在 [github.com/mihonapp/mihon](https://github.com/mihonapp/mihon)。下表是**网盘里那一份**的事实，与官网当前最新版可能不是同一版（官网版本会持续更新，以官网当时显示为准）：

| 项目 | 值 |
|---|---|
| 版本 | 0.20.0 |
| 包名 | app.mihon |
| 安装包大小 | 61.06M |
| MD5 | `f6c50e0c4f8d791e0f31c47034769fba` |
| 系统要求 | Android 8.0 及以上 |
| 记录于 | 2026-09-23 |

版本号格式就是普通的 `x.y.z` 递增；另有 Nightly 构建（开发版，更易出 bug），日常使用装稳定版即可。装好后你也可以用它直接覆盖安装更高版本来升级，包名一致就能保留数据。

## 二、从网盘拿到安装包

1. 打开 [Mihon 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8266d21487cf)，把文件夹转存到自己的网盘。
2. 在网盘里下载 `mihon_v0.20.0.apk` 到手机（或先下到电脑再传到手机）。
3. 下载完成后可核对一下 MD5 是否与上表一致，防止传输中文件损坏。

## 三、安装

1. 点击 APK 文件开始安装。
2. 系统会提示「禁止安装来自此来源的应用」——这是所有商店外应用都会遇到的提示。你在用哪个应用打开 APK（浏览器、文件管理器），就在设置里允许**那个应用**安装未知应用（Android 8.0 起是按应用单独授权）。
3. 安装过程中 Google Play Protect 可能弹「有害应用」警告并阻止安装。Mihon 不在 Play 商店上架（原因见官方 FAQ：APK 扩展机制与 Play 内容政策冲突），这类警告对商店外应用是常态；你确认安装包来源没问题后选择继续安装即可。
4. 装完打开应用。

## 四、首次启动：存储位置是第一个坑

第一次打开 Mihon 会进入设置向导，其中**存储位置**这一步最关键，选错了之后备份、下载、本地漫画都会出问题：

1. 先在手机存储**根目录**新建一个 `Mihon` 文件夹（即 `/内部存储/Mihon/`）。
2. 向导里把这个 `Mihon` 文件夹授权给应用——授权的是这个文件夹本身，不是它里面的子文件夹。
3. **不要**选系统自带的 `Download`、`Documents` 这类文件夹，它们被安卓系统限制访问，Mihon 后续读写会出错。

选完后，应用会在里面自动维护这样的结构：

```text
Mihon/
├─ autobackup/    自动备份（.tachibk 文件）
├─ downloads/     已下载章节（源名 → 作品 → .cbz）
└─ local/         本地源漫画（自己放进去的文件）
```

向导的其余几步（数据与隐私说明等）按需选择即可。如果你是从老版 Tachiyomi 迁移过来的，存储位置直接选原来的 `Tachiyomi` 文件夹，旧的下载与本地漫画还能继续被识别，详见 [备份与恢复教程.md](备份与恢复教程.md)。

## 五、装完先知道的两件事

- **打开后浏览页是空的，这是正常的**。Mihon 本体不带任何内容源，你需要先添加仓库、安装扩展才有东西可看，步骤见 [扩展源添加教程.md](扩展源添加教程.md)。
- **怎么升级**：官方只通过 [mihon.app 下载页](https://mihon.app/download/) 与 GitHub Releases 发布 APK，没有应用商店渠道。下载新版 APK 直接覆盖安装即可，书架与设置都保留。若升级后遇到异常，先对照 [常见问题排查.md](常见问题排查.md)。
