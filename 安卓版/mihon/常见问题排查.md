## 一、打开后浏览页一片空白

不是故障。Mihon 本体不带内容源，你还没添加扩展仓库。按 [扩展源添加教程.md](扩展源添加教程.md) 加仓库、装扩展后，来源就会出现。

## 二、扩展装不上 / 点安装没反应

- 首次安装扩展会弹权限请求：进系统 **设置 → 安装未知应用**，允许 Mihon 安装未知应用，再回应用里点安装（Android 8.0 及以上是按应用单独授权的）。
- 已经允许过还失败：先确认仓库地址粘贴无误（刷新扩展列表能正常加载 = 仓库没问题），再卸载该扩展重装。
- 极少数手机的「纯净模式」「MIUI 安装拦截」等厂商安全功能会额外拦一道，在系统设置里对 Mihon 放行安装即可。

## 三、源打不开、章节加载失败、图片不出来

扩展连的是具体的漫画网站，官方 FAQ 的口径很明确：**源慢、宕站、缺章、画质差，责任在源本身，与 Mihon 无关**。你的处理顺序：

1. 换一个源看同一部作品（很多作品多源都有收录）；
2. 站点临时故障就过段时间再试，光重装应用没用；
3. 报「Failed to bypass Cloudflare」或验证码一直转圈 → 按 [源验证码过不去怎么办.md](源验证码过不去怎么办.md) 逐级排查；
4. 只有某个扩展一直坏、其他正常时，先看 [扩展源添加教程.md](扩展源添加教程.md) 里有没有可用更新，再卸载重装那个扩展，或等社区更新。

## 四、搜索找不到某部作品

- **换拼写**：很多源用日语罗马音标题（`Boku no Hero Academia` 而非 `My Hero Academia`），或大小写、连字符不同（`3-gatsu no Lion` vs `Sangatsu no Lion`）。
- **换源搜**：不同源收录范围不同，A 源没有不代表 B 源没有；
- **全局搜索**：**浏览** 页顶部停在 **来源** 标签、点搜索图标，可以一次搜遍你装的所有源。

## 五、应用商店里搜不到 Mihon

正常。官方明确 **Mihon 不会上架 Google Play**（APK 扩展机制与 Play 内容政策冲突），也**没有 iOS/iPadOS 版本且没有移植计划**——任何自称「Mihon for iOS」的都不是官方产品。你只从 [mihon.app](https://mihon.app/) 下载页或 GitHub Releases 拿安装包就对了。

## 六、升级或重装时数据会丢吗

- **覆盖安装升级**（包名一致）：书架、设置、阅读进度全保留，直接装新 APK 即可。
- **卸载重装**：必须先有备份才不丢数据——按 [备份与恢复教程.md](备份与恢复教程.md) 提前创建 `.tachibk`。
- 想找回网盘里那一份安装包（版本 0.20.0，用于回装或给别的手机装）：[Mihon 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8266d21487cf)。

## 七、删了章节/本地列表对不上、SD 卡上操作很慢

安卓 11 起的分区存储让本地文件操作天然有延迟，内置存储明显更流畅。文件列表与实际不一致时，去 **更多 → 设置 → 高级 → 重新索引下载（Reindex downloads）** 让应用重扫；长期大量下载或存本地漫画的，建议把存储位置放内置存储而不是 SD 卡（详见 [阅读与下载设置.md](阅读与下载设置.md)）。

## 八、下载一半断掉、后台更新不触发

先排除网络原因（见 [源验证码过不去怎么办.md](源验证码过不去怎么办.md)），还断就是手机在杀后台——安卓的省电机制会限制后台联网，国产厂商的限制更狠，逐项检查：

1. **电池优化豁免**：手机 **设置 → 应用 → Mihon → 电池**，选「不优化」或「无限制」（各家措辞不同，意思一致）；
2. **后台数据**：同一屏确认没开「限制后台流量」；
3. **厂商后台管理**：小米/红米要开「自启动」并允许后台，华为/荣耀要把 Mihon 加进「受保护的应用名单」，三星检查有没有把它「置于睡眠状态」，vivo/OPPO 一般在「后台高耗电」里放行；
4. 改完把 Mihon 从最近任务里划掉重开，再发起一次批量下载验证。

仍频繁中断时，把下载拆小批、屏幕保持亮着下完这一批——先确认是后台限制还是源的问题，再决定要不要深挖。
