陌生社交应用的隐私风险不在应用本身，而在「你把什么交出去」和「对面是谁」这两件事上。zono 这类应用的账号绑着你的手机号，聊天记录、动态和定位又都带个人信息，所以装好之后第一件事是收权限、第二件事是收住嘴。本篇给的都是可以照着做的动作。

## 一、权限按需给，不要一次全同意

| 权限 | 什么时候才真需要 | 建议 |
| --- | --- | --- |
| 网络 | 全程 | 必需 |
| 麦克风 | 语音通话、语音动态 | 要用再给；不用语音可以关掉 |
| 摄像头 | 视频通话 | 要用再给；只在文字聊天阶段可以先不开 |
| 位置 | 按距离推荐（如「附近的人」，视版本而定） | **可选**，不想被按距离推荐就拒绝；关了不影响正常聊天 |
| 通知 | 收到新消息提醒 | 介意被打扰可以只留声音、不留横幅 |
| 存储/相册 | 保存头像、发动态配图 | 只在发图时给，别开全盘读写 |

国产安卓系统里，权限被拒绝一次后应用通常不会再弹窗，要自己到「设置 → 应用 → zono → 权限」里补开，别以为是应用坏了。

## 二、个人资料和动态里的红线

以下内容一旦发出去就很难收回，发之前先过一遍：

- **证件类**：身份证、护照、驾驶证、工牌、快递面单、机票车票。
- **位置类**：门牌号、常去的健身房与店铺、带地标和时间的打卡照、实时位置。
- **关系类**：家人的正脸照和姓名、孩子的学校和班级、同事与领导的信息。
- **资金类**：银行卡、支付截图、余额截图、含订单号的截图。

真要用照片做头像或配图，用一张构图普通、看不出住处和单位的生活照就够了。

## 三、这几种情况一律按骗子处理

交友类应用里，下面的套路反复出现，遇到直接停止交流并举报：

1. **索要验证码、支付密码、银行卡信息的人**。任何自称「客服」「审核员」「官方人员」并要这几样东西的，都是骗子；平台不会向用户索要验证码。
2. **先让你充值、送礼、刷礼物才肯继续聊的人**。有媒体调查报道过同类应用里的「聊天员」模式：账号由雇来的人运营，目的就是让你不断花钱维持对话。对方不断把话题引向「送个礼物」「开通会员才能视频」，就该警惕了。
3. **引导你离开应用、去站外私下交易的人**。一旦转到别的聊天工具，平台既救不了你，也留不下证据。
4. **谈钱、谈投资、谈"带你赚钱"的人**。刷单、博彩、虚拟币、代购代付，是这类平台上金额最大的骗局，形式换了很多轮，内核一直是「先让你尝到小甜头」。
5. **开口借钱的"知心好友"**。聊了没几天就诉苦要钱，且拒绝视频、拒绝见面。
6. **说要曝光你、拿你照片或聊天记录威胁你的人**。不要转账，保存证据后按第五节的流程处理。

## 四、真要花钱，先看清这四项

zono 的基础功能可以免费用，增值服务、虚拟礼物这类需要付费（**具体项目与价格以应用内实际显示的为准**）。付款前确认：

- **单价**：是不是按次、按分钟，还是按天数算。
- **是否自动续费**：默认勾选的续费项要手动取消，别等扣款了才发现。
- **退款规则**：虚拟商品一般不支持退款，下单前想清楚。
- **渠道**：只在应用内的官方支付流程里付，不要转给个人账户或扫码给陌生人。

## 五、被骚扰或被威胁后的处理顺序

1. **先停手，不回应**。回骂和解释只会给对方更多素材。
2. **保留证据**：截图对方主页、聊天记录、转账要求，记下时间。
3. **在应用内举报并拉黑**。举报入口一般在对方主页或聊天界面的菜单里，路径以应用内实际为准。
4. **涉及金钱或人身威胁的，直接报案**：拨打 110，或通过国家反诈中心 App 提交线索；已经转账的越早报案越好。

## 六、不打算用了，要做的是注销而不是卸载

卸载只是把应用从手机上删掉，账号、手机号、聊天记录还留在平台侧。要退出就把账号注销掉，注销的路径和注意事项见 [注册登录与账号设置.md](注册登录与账号设置.md)；如果某个功能一直不对、或者怀疑账号被盗，先看 [常见问题与排查.md](常见问题与排查.md)。
