搜「zono」会同时搜出一堆拼写相近、却跟这款安卓社交应用毫无关系的东西——有面向企业的英文服务，也有只差一个字母的 Zeno。名字像，产品完全不是一回事。本篇给一个可靠的身份判据：**包名**，并说清在哪看、看到什么算对上。

## 一、唯一可靠的判据是包名，不是名字

名字可以照抄，图标可以仿，包名在系统里是唯一的：

| 项目 | 这款 zono 的值 |
| --- | --- |
| 包名 | `com.zvdglks.ljwfg` |
| 开发者 | 四川楚慧天星科技有限公司 |
| 版本（网盘里那份） | 4.0.33 |
| 适用平台 | Android |

只要包名不是 `com.zvdglks.ljwfg`，装的就不是这份包，无论它叫什么、图标长什么样。

## 二、在哪核对包名

- **装好后看**：进「设置 → 应用 → 应用管理 → zono → 应用信息」，部分系统在这个页面直接显示包名；不显示的，点进「应用详情」也能找到。
- **装之前看不太准**：安装界面一般只显示应用名和图标，**不一定显示包名**，所以更稳的做法是装完再核对一次。
- **退一步看开发者**：应用信息页的开发者/发行商一栏写着「四川楚慧天星科技有限公司」，基本就能确认是同一款。

## 三、几种常见的认错

1. **英文的同名服务**。搜索排在前面的一些 zono / Zeno 是面向企业的海外产品或营销工具，面向公司客户、界面是英文，与手机端的社交应用没有关系。
2. **只差一个字母的 Zeno**。多一个字母或少一个字母，不是同一个产品。
3. **同名的另一个安装包**。应用市场或下载站上可能出现同名的包，但包名不同；核对包名是对付这类包最直接的办法。
4. **同一款的不同版本**。包名对得上、版本号不一样，属于正常情况——网上流传的多是官方最新版，网盘里那份是 4.0.33，两者差别见 [下载与安装教程.md](下载与安装教程.md)。

## 四、由此带来的两个实际影响

- **包名相同不能共存，包名不同会并排出现**。包名相同时，后装的会要求先卸载旧包，账号与本地数据是同一份；包名不同，桌面上就会多出一个同名图标——想留下这一款，认准包名 `com.zvdglks.ljwfg`、把另一个卸载就行。
- **账号只属于装它的那一个包名**。换一个包名的应用，原账号登不进去，手机号登录的规则见 [注册登录与账号设置.md](注册登录与账号设置.md)。

不确定手里这份是哪一版时，回到 [下载与安装教程.md](下载与安装教程.md) 第二节，按体积与 MD5 再对一遍。
