## 一、先核对网盘里这份是哪一版

搜索引擎给的版本号多是官方当时的最新版，与网盘里这份未必是同一个版本号。下文出现的版本号、包名、体积一律以下表为准：

| 应用名 | zono（官方写法就是全小写） |
| 版本号 | 4.0.33 |
| 包名 | `com.zvdglks.ljwfg` |
| 安装包体积 | 113.94 MB |

| 适用平台 | Android 手机端（APK） |

这份是安卓手机端的安装包（APK），**iPhone 和 iPad 装不了**；电脑上要用只能借助安卓模拟器。本文只讲手机端这一份包。

几点先说明白：

- **这份属于 4.0.x 系列**。网上还能看到 4.2.x 这类编号，那是更晚发布的版本，与网盘里这份不是同一版。官方后续编号到哪一位，以官方渠道当时显示的为准。
- **包名是 `com.zvdglks.ljwfg`**。同名或近名的应用在不同渠道可能挂着别的包名，包名不同，系统就当成两个不相干的应用，**不能互相覆盖安装**，账号与本地数据也各算各的。
- 网盘里那份的文件名形如 `zono_v4.0.33.apk`；文件名会随版本变化，以实际提供的那份为准。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [zono 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2ba90468bc83)，在手机夸克 App 里打开最省事。
2. **先转存再下载**：把安装包转存到自己的网盘目录后再下载。分享链接以后可能失效，转存过的那一份不受影响。
3. **确认下载完整**：下载完成后看一眼体积是否约 113.94 MB。中途断网重连、体积明显偏小的，装的时候容易直接报「解析包错误」。
4. **想校验完整性**：在电脑上对包算一遍 MD5，结果应当与上表一致。

```cmd
certutil -hashfile zono_v4.0.33.apk MD5
```

## 三、安装步骤

1. **让文件管理器拿到安装权限**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，把用来打开 APK 的那个应用（文件管理器或浏览器）的开关打开。国产定制系统这项常收在「安全」或「隐私」分类下。
2. **点击 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续——这是侧载安装包的常规提示，不代表文件有问题。
3. **回装低版本要先卸载**：安卓不允许用更低版本覆盖更高版本，会直接报「应用未安装」。手机里已经装了更高版本号的，先卸载再装这份；卸载会一并清掉只存在本机的数据。
4. **系统版本要对得上**：这份安装包的信息里没有标出最低系统版本，装之前请以应用商店页面当时标注的为准。系统过低时，安装按钮可能点不动，或装上后打开即退。

## 四、第一次打开要确认的三件事

1. **能联网**：匹配、动态、通话都要走网络，卡在加载页时先在浏览器里确认手机能正常上网。
2. **手机号能收到验证码**：首次进入要用手机号加短信验证码登录，收不到验证码的排查见 [注册登录与账号设置.md](注册登录与账号设置.md)。
3. **能看到内容**：填完兴趣标签后，推荐列表或动态里刷得出其他用户，说明数据侧通了。装好后按提示给通知、麦克风这几项权限——不给麦克风，语音通话和语音动态都用不起来，具体见 [隐私安全与交友防骗.md](隐私安全与交友防骗.md)。

## 五、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包下载不完整 | 核对体积与 MD5，从网盘重新下载一次 |
| 提示「应用未安装：签名不一致」 | 手机里已装同包名的另一个渠道版本 | 先卸载旧包再装；卸载前想清楚本机数据会一起没 |
| 点安装没反应，或安装到最后只报「应用未安装」 | 在回装更低的版本号 | 先卸载高版本，或直接装更高的那一版 |
| 安装被安全中心拦截 | 侧载安装包被系统安全策略拦下 | 在安全中心的拦截记录里选择「继续安装」 |
| 装上后打开就退 | 系统版本过低、内存不足或安装残缺 | 见 [常见问题与排查.md](常见问题与排查.md) |

## 六、装完再核对一次是不是这一版

装好打开后，进「设置 → 应用 → 应用管理 → zono → 应用信息」，核对两处：版本号是否为 `4.0.33`、包名是否为 `com.zvdglks.ljwfg`（部分系统要再点一层「应用详情」才显示包名）。对不上，说明装的不是网盘里这份包。

名字相同不代表是同一款——判据只看包名，完整说明见 [同名产品与官方渠道怎么认.md](同名产品与官方渠道怎么认.md)。
