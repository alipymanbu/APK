这份清单按发生顺序排列：装不上、进不去、用不了、收不到，最后是账号与数据。每条都给出「先查什么」，能自己解决的先自己解决，涉及账号归属的才需要走客服。下文里涉及的版本号、包名、体积以安装那篇的表格为准。

## 一、安装类

| 现象 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包大小是否约 113.94 MB | 下载不完整，从网盘重新下；想确认就在电脑上算一遍 MD5 |
| 提示「应用未安装：签名不一致」 | 手机里是否已有同包名应用 | 卸载旧包再装，注意本机数据会一起清掉 |
| 安装按钮点不动 | 「安装未知应用」权限给了没有 | 在「设置 → 应用 → 特殊应用权限」里给文件管理器开权限 |
| 被安全中心拦下 | 拦截记录 | 在安全中心的记录里选「继续安装」 |
| 装上后打开就退 | 系统版本、可用内存、安装是否残缺 | 先重启手机再打开一次；仍退就卸载后从网盘重下、核对体积与 MD5；系统版本过低则只能换设备 |

完整的安装流程与校验方法见 [下载与安装教程.md](下载与安装教程.md)。

## 二、登录类

**收不到验证码**，按这个顺序查：

1. 手机是否欠费、是否开了飞行模式。
2. 短信拦截箱里找一遍——很多系统把应用短信和营销短信丢在同一处。
3. 是否短时间内反复点「获取验证码」，触发了发送次数限制，等几分钟再试。
4. 换一下网络（Wi-Fi 与移动数据互换）后重试。
5. 以上都排除还是收不到，换一台手机装同一个号试一次，能收到说明是本机短信通道问题。

**提示验证码错误或已过期**：验证码有时效，收到后尽快填；反复失败就重新获取一条，不要拿旧的那条反复试。

**换了手机号登不进去**：手机号就是账号，旧号停用后无法自助收码。先在应用内的客服/申诉入口提交材料，具体通道以应用内实际为准，账号规则见 [注册登录与账号设置.md](注册登录与账号设置.md)。

## 三、通话与语音类

| 现象 | 多半是什么原因 | 怎么办 |
| --- | --- | --- |
| 说话对方听不到 | 麦克风权限没给 | 到「设置 → 应用 → zono → 权限」里补开麦克风 |
| 视频时画面对面看不到 | 摄像头权限没给 | 同上，补开摄像头 |
| 语音断续、卡成机器人音 | 网络抖动 | 切到 Wi-Fi 或信号好的移动网络再试 |
| 背景全是回声 | 外放导致 | 戴耳机，效果立竿见影 |
| 接通后秒断 | 一方网络刚切换过 | 双方都停在一个网络下重拨一次 |
| 听筒没声音，走的是扬声器 | 接听时贴近耳朵的策略差异 | 通话中手动切「扬声器 / 听筒」开关 |

对方一直不接不等于故障——对方可能只是在忙或不想接；连续几次被同一个人拒绝，换个人聊就好。

## 四、消息与动态类

- **收不到新消息通知**：先确认系统没把 zono 的「通知」权限关掉，再看是否开了省电模式把后台冻结；国产系统的「自启动」「后台运行」白名单里把 zono 放进去，能明显改善漏提醒。
- **发出去的动态看不到**：动态要过平台审核才展示，等一会儿再看；长时间不出现，去动态列表看有没有被退回的提示，见 [怎么发动态和互动.md](怎么发动态和互动.md)。
- **动态发出去了但只有自己能看到**：检查可见范围设置，是否设成了「仅自己可见」。
- **聊天记录丢了**：换设备、清应用数据、卸载重装都会清掉只存在本机的聊天记录，重装后回到账号也找不回本机那部分。

## 五、账号与数据类

- **怎么注销账号**：路径通常是「我的 → 设置 → 账号安全 → 注销账号」，以应用内实际为准；注销不可恢复，动手前先结清付费权益，见 [注册登录与账号设置.md](注册登录与账号设置.md)。
- **删了应用是不是就注销了**：不是。卸载只清本机数据，账号还在平台侧。
- **怀疑账号被盗或被换绑**：先看能否用原手机号重新登录；不能的话尽快走申诉通道，同时检查是否有陌生设备登录记录。
- **换了手机想找回账号**：用原手机号重新登录即可，前提是该号仍能用。
- **桌面上多出一个同名图标**：说明装了两个包名不同的包。想留下这款，就认准包名 `com.zvdglks.ljwfg`，把另一个卸载；判断办法见 [同名产品与官方渠道怎么认.md](同名产品与官方渠道怎么认.md)。

## 六、安全类

遇到索要验证码、诱导充值送礼、拉你站外交易、谈投资借钱这几类情况，一律按骗子处理并举报，处理顺序（停手 → 存证 → 举报拉黑 → 涉及金钱就报警）见 [隐私安全与交友防骗.md](隐私安全与交友防骗.md)。这类问题不属于应用故障，不用等版本更新来解决。
