## 一、先配对，才有数据可看

这个应用本身不产生健康数据——步数、心率、睡眠都是**手表 / 手环采完同步过来**的。所以还没连设备的话，先走[手表怎么配对连接](手表怎么配对连接.md)；连上之后，应用底部两个页签就是你日常要去的地方：**首页（健康数据）**与**设备页（管表）**。

数据不同步时先看[手表老是断开连接怎么办](手表老是断开连接怎么办.md)——多半是连接断了，不是数据丢了。

## 二、首页：步数、心率、睡眠都堆在这一页

首页是一张卡片流，常见卡片有：

| 卡片 | 你能看到什么 |
|---|---|
| 活动 / 步数 | 今日步数、活动时长、消耗，点进去看按小时的曲线与达标情况 |
| 心率 | 当前与全天心率曲线，静息心率；异常偏高偏低时手表会振动提醒 |
| 睡眠 | 昨晚的入睡时间、分期（深睡 / 浅睡 / 快速眼动）、睡眠质量评分 |
| 血氧 | 全天血氧记录（具体看手表型号支持哪些监测项） |
| 运动 | 最近的运动记录入口，跑步、骑行等每次的轨迹与指标 |

点任何一张卡片进详情页，可以看日 / 周 / 月的跨度。**前提是手机与手表保持连接**——数据躺在手表里没同步过来时，卡片会停在上次的时间点，连上等它自己刷即可。

一个口径问题提前说清：手表测的心率、血氧**只作参考，不构成医疗结论**，官方在功能页也是这么标注的。身体不适请以医用设备和医生意见为准。

## 三、运动记录：开始运动在哪、结果存哪

- **发起运动**：多数运动直接在手表上开始（按表冠进运动列表，或按下键快捷进入）；跑步这类也可以在手机应用里发起、跟着语音指导跑。
- **过程数据**：配速、心率区间、轨迹由手表记录，跑完在手表上直接看摘要。
- **完整报告**：连上手机后，进首页的运动卡片看详细报告——分段配速、心率曲线、跑姿类高阶数据（支持的型号才有）。
- **自动识别**：跑步、健走、骑行这类规律运动，戴久了手表会自动识别并补记一次，你可以在设备设置里开关它。

## 四、设备页：表盘、通知、电量都在这管

设备页是「这块表的控制台」，进去之后常用的几件事：

1. **看电量与连接状态**：卡片顶部就是电量百分比与连接状态，断开时会明示，并有「重新连接」按钮。
2. **换表盘**：进「表盘」挑官方表盘商店里的样式，装到手表上；部分型号还支持把自定义照片设成表盘（入口在表盘页里）。
3. **同步手机通知**：「更多 > 同步手机通知」打开，并在系统弹窗里授权——微信、短信、来电提醒都靠它。哪个应用要提醒、哪个不要，在同一个页面里按应用单独勾。
4. **更多功能**：闹钟、天气、久坐提醒、找手表、防断连设置（非 OPPO 手机）等开关都收在「更多功能」里，按需打开。
5. **取消配对 / 解绑**：换手机、出手表前，从这里解绑，别直接在系统蓝牙里忽略——那样容易留下残留条目，下次连不上，见[手表老是断开连接怎么办](手表老是断开连接怎么办.md)第四节。

## 五、数据给家人看

应用里有「家人健康」入口：在家人健康卡片里添加家人的欢太账号，**对方同意并设置共享**之后，你才能在他的设备同步后看到他的步数、心率等数据；双方都有手表时，还能互相收到活动达标、心率异常之类的提醒。注意这条链路是双向授权的——对方不点头，你这边看不到任何数据。
