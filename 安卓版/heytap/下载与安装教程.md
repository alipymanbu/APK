## 一、这是什么应用，装之前先认清名字

这是欢太科技（广东欢太科技有限公司）出的一款运动健康类手机应用，包名 `com.heytap.health`，主要用途是搭配 OPPO、realme 等品牌的智能手表 / 手环用：配对之后，步数、心率、睡眠这些数据会在手机上看，表盘、消息通知也在手机上管。

装之前先理清它的几个名字，免得你搜到的和装的不是同一个东西：

| 你看到的名字 | 是什么 |
|---|---|
| 欢太健康 / HeyTap Health | 国内过去的名字，也是这个包名对应的应用 |
| OPPO 健康 | 国内现在的名字（官方隐私政策写明「OPPO 健康（原欢太健康）」） |
| heytap | 应用在部分渠道里的简写，包名与前两者一致 |
| OHealth | 国际版的现名，与国内版不是同一个包 |

你从网盘拿到的这份是安卓 APK，版本 4.10.7、体积 97.03M。手机应用商店里的官方最新版可能已经是更高的版本号——这没关系，两者是同一个应用，装哪个都能用；只是**版本号、包名、体积这类事实，本文一律以手头这份安装包为准**（下文第三节有对照）。

## 二、下载与安装步骤

1. 打开 [heytap 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bf786866a845)，把安装包转存到自己的网盘后下载到手机；也可以在电脑上下载好再传到手机。
2. 在手机文件管理器里点这个 APK 开始安装。
3. 如果系统弹出「禁止安装来自此来源的应用」，这是正常的拦截：按提示进入设置、允许本次安装来源即可（不同品牌手机措辞略有差别）。
4. 装完打开应用，按引导授予它要的权限（通知、蓝牙、位置这些——不给的话后面配对手表会卡住，可以在系统设置里随时改回来）。
5. 用手机号注册 / 登录欢太账号（OPPO 账号体系）。不登录也能看界面，但配对手表、同步数据都要登录后才能用。

装好之后，下一步就是把手表或手环连上来，见[手表怎么配对连接](手表怎么配对连接.md)。

## 三、系统要求与包信息

以手头这份安装包与公开资料为准（信息截至 2026-09）：

| 项目 | 值 |
|---|---|
| 版本号 | 4.10.7 |
| 包名 | `com.heytap.health` |
| 安装包体积 | 97.03M |
| 开发者 | 广东欢太科技有限公司 |
| 手机系统 | 安卓（最低版本以官方应用商店页面为准；官方配对文档给出的手机要求是 Android 10.0 及以上 / iOS 14.0 及以上，**且随手表型号不同**） |

两点提醒：

- **手机系统要求随手表型号变化**。同一品牌的手表，新款要求的手机系统版本更高（例如部分新款标注 Android 10.0 起），老款要求更低。买手表时的官方页面写什么就按什么来，不要拿别的型号的要求硬套。
- **iOS 上不叫这个名字**。苹果手机配对 OPPO 手表走的是 App Store 里的对应应用，界面与安卓版会有差异，本文以下内容均按安卓版叙述。

## 四、安装后没见到功能，多半是这两种情况

- **应用商店搜不到**：国内 OPPO / realme 手机的自带应用商店里可以搜「OPPO 健康」或「欢太健康」直接装，比手动装 APK 还省事；搜不到时用网盘里的 APK 即可。
- **界面里没有手表相关功能**：正常——这个应用的健康数据、表盘管理都建立在「先配对一个设备」上，空着手表时它只有基本介绍页。先去[手表怎么配对连接](手表怎么配对连接.md)把手表连上，功能才会出现。
- **之后怎么升级应用**：应用内自己带检查更新的入口（「管理 > 设置 > 版本号」一类路径，随版本略有差异），商店渠道装的走商店更新即可。装的是网盘这份 4.10.7 的话，后续新版本以官方渠道发布为准。
