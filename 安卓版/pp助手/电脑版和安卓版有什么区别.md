## 一、先说结论

「PP助手」这个名字下有两个完全不同的东西：

| | 安卓手机版 | 电脑版（PC/Mac） |
| --- | --- | --- |
| 装在哪 | 手机上 | Windows / Mac 电脑上 |
| 形态 | 应用商店 App，包名 `com.pp.assistant` | 桌面程序，安装包约 44MB |
| 版本号 | 8.5.x.y 四段式 | 5.9.7.x 起头，与手机版完全是两套编号 |
| 干什么 | 在手机上直接搜、下、装应用和游戏 | 用数据线连手机，传文件、装应用、导铃声、备份 |

本套文档写的是**安卓手机版**。你在 [下载与安装教程](下载与安装教程.md) 里拿到的那个 8.5.6.0 安装包也是手机版的。

## 二、各自主打什么

**安卓手机版**就是手机里的应用商店：打开就能搜资源、下游戏、更新和卸载应用，全程不需要电脑，前面几篇讲的操作全发生在这一个 App 里。

**电脑版**是另一套软件，主打「用电脑管手机」：

- 用 USB 线把手机连上电脑，在电脑屏幕上管理手机里的应用、图片、视频、铃声；
- 给 iPhone 用户提供不越狱装应用、固件下载这类 iOS 专属功能（这是它早年出名的原因）；
- 也能给安卓手机装 APK：在电脑版里进「应用管理 → 我的应用 → 安装应用」，选电脑上已下载的 `.apk` 文件即可（操作步骤取自 ZOL 的教程，版本不同入口名可能略有差异）。

## 三、怎么判断该用哪个

- 你的诉求是**在手机上直接找资源下载** → 只装安卓手机版，电脑版帮不上忙；
- 你的诉求是**把电脑里的文件传到手机 / 用大屏管理手机** → 用电脑版，手机上不用装任何东西；
- 两者**不冲突也不通用**：手机版的账号、设置与电脑版互不相通，电脑版的 5.9.7 版本号也和手机版的 8.5.x 没有对应关系，别拿一边的版本去对另一边。

## 四、下载时容易拿错包

两个形态在下载站常常混排在同一个页面里，看清楚再点：

- 手机上装的那份，文件后缀是 `.apk`、大小 30MB 上下、在手机浏览器里下载；
- 电脑版的安装包是 `.exe`，大小 44MB 上下，装到电脑上才有意义 —— 把它传到手机上是装不起来的。

只想装手机版的话，直接用 [PP助手 安装文件资源（夸克网盘）](https://pan.quark.cn/s/773996f9e52e) 里那份固定版本，或者走 [下载与安装教程](下载与安装教程.md) 里的官网渠道，绕开下载站的混排页面。
