# LuckyCam 怎么连接行车记录仪

> 手机和记录仪靠 WiFi 热点配对，本篇给出从开热点到出画面的完整步骤，以及连上之后怎么保持稳定。

## 一、先确认这三件事

1. **记录仪通电开机**：接车载电源、点火后记录仪才会工作；熄火状态下热点可能不亮。
2. **记录仪的 WiFi 已开启**：不少机型的热点是手动开的——短按一次电源键开启 WiFi（说明书里的通用做法）。热点开着时记录仪本体一般不能按键操作，属于正常设计。
3. **手机在热点范围内**：靠近记录仪 5 米以内，越近越稳，下载时最好 1 米内。

## 二、配对步骤（先连 WiFi，再开 App）

这是各品牌说明书里一致的顺序，反过来做 App 里会一直显示连不上：

1. 打开手机的「设置 → WLAN（WiFi）」，在列表里找记录仪的热点名。常见命名有两种：`CARDV_*****` 开头，或直接是记录仪型号名（如 `M08_xxxxxxxx`、`GS63H`）。
2. 输入密码连接。**初始密码通常是 `12345678`**（以你记录仪说明书上写的为准；改过就用你自己改的那个）。
3. 连上热点后再打开 LuckyCam，首页就会出现记录仪的实时画面。

如果你的记录仪是「在 App 里添加设备」的流程：打开 App 点「添加设备」，在设备列表里选中 `xxxx车录_XXXX` 这类名字，再输默认密码即可。两种流程结果一样，按你机型的说明书走。

## 三、改 WiFi 名称与密码的注意点

连上之后你可以在 App 的设置里改热点名称和密码，但两条提醒：

- **改完把新密码记牢**。忘了就得把记录仪恢复出厂设置才能找回默认密码。
- 有厂商技术支持明确建议**不要在 App 里改设备名称**，否则手机可能再也搜不到原来的热点、需要返工才能改回来（单一来源说法，不同机型表现可能不同——拿不准就别改名，只改密码）。

## 四、连上之后怎么保持稳定

记录仪热点是点对点连接，手机的系统行为很容易把它掐断。按下面调一遍，能挡掉大部分「连着连着就断」的情况：

| 场景 | 你要做的事 |
| --- | --- |
| 安卓连上后总自己断 | WLAN → 高级设置里打开「保持 WLAN 连接」；关掉「自动切换移动数据 / WLAN 助手」这类功能 |
| 手机一锁屏就断 | 看视频、下载时保持屏幕常亮（开发者选项里的「充电时屏幕不休眠」，或把自动锁屏调到最长） |
| 画面卡、延迟高 | 手机靠近记录仪 1 米内；关掉手机蓝牙与车载蓝牙；车上装了 ETC 的可临时断电试一次 |
| iOS 连不上或秒断 | 系统版本升到最新；确认给 LuckyCam 开了定位/无线局域网权限 |
| 连上热点没网被切走 | 记录仪热点本身不通外网，手机会提示「已连接，无互联网」——**不要点「切换到移动网络」**，留在这个热点上 |

有一点要提前知道：连记录仪热点期间手机不能同时用移动数据上网，回微信、导航都走不了流量（关掉 App 之外的后台重应用还能减少抢带宽导致的画面卡顿）。

## 五、时间不同步怎么处理

汽车电瓶断电重启记录仪后，记录仪的日期时间可能归零。解决办法：连上 App 之后在设置里做一次时间同步（有的机型连上即自动同步），否则录像文件的时间戳会是错的，事后取证对不上时间就麻烦了。

连不上、搜不到热点时，按 [连不上记录仪怎么办.md](连不上记录仪怎么办.md) 逐条排查；连上之后的回放与下载操作看 [回放与下载视频.md](回放与下载视频.md)。
