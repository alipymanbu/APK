# LuckyCam 连不上记录仪怎么办

> 按症状排查：搜不到热点、连上没画面、画面卡顿、App 打不开、视频下不动、存储卡报错，逐条对号入座。

## 一、手机搜不到记录仪热点

按顺序试，每做一步去 WLAN 列表刷新一次：

1. 确认记录仪已通电开机，且热点是开的——短按一次电源键开启 WiFi（很多机型热点不常亮，得手动开）。
2. 手机靠近记录仪 5 米内，关掉手机蓝牙和车载蓝牙再扫。
3. 重启记录仪（断电再上电）和手机，再扫一次。
4. 换一部手机连：新手机能搜到，说明原手机的 WiFi 设置有问题；都搜不到，多半是记录仪热点故障，联系售后并准备好 SN 码、固件版本信息。

## 二、连上了热点，但 App 里显示未连接

1. 在 WLAN 列表点开这个热点，确认它状态是「已连接」——App 只认系统已连上的热点。
2. 手机系统设置里给 LuckyCam 补权限：**安卓**到「应用管理 → LuckyCam → 权限」，把 WLAN 状态、位置权限（部分机型把 WiFi 扫描归在这里）、存储权限都放开；**iOS** 到「设置 → LuckyCam」确认定位与无线局域网权限已给。
3. 忘记该 WiFi 后重连一次（WLAN 列表长按 → 忘记网络），密码确认没输错：初始一般是 `12345678`。
4. 关掉「自动切换移动数据 / WLAN 助手」——记录仪热点不通外网，这类功能会把它当坏网络踢掉（另见 [连接行车记录仪步骤.md](连接行车记录仪步骤.md) 的对照表）。
5. 还不行就清一次 App 缓存（设置 → 应用 → 存储 → 清除缓存），再不行卸载重装。

## 三、有画面但卡顿、频繁掉线

- 手机凑到记录仪 1 米内，中间别隔金属物。
- 后台少开几个重应用，抢带宽会让预览卡。
- 关蓝牙、ETC 临时断电，排除 2.4GHz 干扰（这些热点都工作在 2.4GHz）。
- 下载和看回放时**保持屏幕常亮**：锁屏断 WiFi 是这类 App 的通病。
- 以上都做了还掉线，把 App 升到商店里的最新版；再不行换部手机试，锁定是个别机型兼容问题还是记录仪本身。

## 四、App 打不开、闪退、更新后不能用

这类反馈在用户评价里相当集中（属「有用户反馈」，不是普遍定论）：

1. 强制停止 App 后重开；不行就重启手机。
2. 清除缓存；仍不行「清除数据」再重来（会丢本地已下载列表，卡内文件不受影响）。
3. 卸载后重装最新版：安卓安装包可重新取 [LuckyCam 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1c0d0aa91c93)，或在应用商店搜 `com.ntk.LuckyCam`。
4. 重装依旧打不开，换部手机验证——单机问题与全机型问题的处理方向完全不同。

## 五、回放能看，但视频下载失败

1. 先停止录制再下载（录制中部分机型禁下载）。
2. 保持屏幕常亮、手机贴近记录仪；锁屏或走远都会断传。
3. 一次别勾太多大文件，分批下。
4. 检查相册权限是否给了——权限被拒时传输看似成功，实际文件没落盘。
5. 下载前把卡内文件列表刷新一次，文件若是损坏条目（断电产生的半截文件），删除或格式化卡后重试。

## 六、记录仪本身的异常（App 里看得见）

| 现象 | 处理 |
| --- | --- |
| 指示灯红灯常亮 | 无卡或卡错误：取出重插 TF 卡，不行就格式化；换正规 Class10 卡 |
| 开机不录像 | 重插/格式化 TF 卡；确认卡速够 |
| 时间错乱 | 连上 App 后做一次时间同步（电瓶断电重启后必做） |
| 锁定文件堆满卡 | 格式化存储卡（先下载要留的视频）；把重力感应调到中/低 |
| 画面模糊 | 擦镜头和挡风玻璃内侧 |

存储相关的条目（卡容量不达标、速度不够、格式不对）各有具体成因与对策，集中在 [存储卡怎么选与格式化.md](存储卡怎么选与格式化.md)。

## 七、都不行的时候

依次做：记录仪恢复出厂设置 → 升级固件（设置菜单里找「固件升级」，有更新就升）→ 换手机 → 联系记录仪品牌售后，报上机型、SN 码、固件版本与 App 版本（安卓这份是 5.4.3）。绝大多数连接问题停在前三步以内；走到联系售后，说明硬件嫌疑更大。

安装与权限没弄对导致的「连不上」，回头对照 [下载与安装教程.md](下载与安装教程.md)；正常配对流程在 [连接行车记录仪步骤.md](连接行车记录仪步骤.md)。
