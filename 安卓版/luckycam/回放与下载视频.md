## 一、界面就四个入口

App 底部导航一般是四项，先认清再操作：

| 入口 | 你进去能干什么 |
| --- | --- |
| 录像 | 实时预览记录仪正在录的画面，可看到是否在录制 |
| 拍照 | 对着当前画面拍一张，存进记录仪卡或手机（看你的选择） |
| 文件夹 | 回放：浏览卡内（DVR）与已下载到手机（本地）的视频、照片 |
| 设置 | 改记录仪参数：WiFi、分辨率、循环时长、重力感应等 |

操作 App 时最好先让记录仪**停止录制**（在车辆停稳、周边安全的前提下），部分操作在录制中会被限制。

## 二、怎么看回放

1. 进「文件夹」，列表右上角有切换按钮，可在**记录仪卡内文件（DVR）**与**手机本地文件**之间来回切——相机图标代表卡内文件，手机图标代表已下载到手机的文件。
2. 列表可按视频/照片筛选，点任意一条就在线播放。
3. 带**锁形图标**的文件是紧急锁定文件（碰撞、手动锁定触发），循环录制不会覆盖它们；也正因为锁得多、卡会被占满，见下面第五节。

## 三、怎么把视频下载到手机

1. 先停止录制，回到「文件夹」，切到 DVR 列表。
2. 点右上角的选择按钮（对勾），勾选要下的文件，支持多选批量下载。
3. 点下载，进度走完后切到手机图标那一侧，就能在本地列表里看到并播放；相册权限给过的话，也会出现在系统相册里。

两个实际经验：

- 下载走的是记录仪热点，**不消耗手机流量**；把手机凑到记录仪 1 米内，有教程实测下载速度约 3MB/s（单一来源数据，机型与环境不同会有出入）。
- 下载时保持屏幕常亮、别切后台——锁屏会断热点，传输中断就得重来（这也是用户差评里最常见的场景之一，见 [连不上记录仪怎么办.md](连不上记录仪怎么办.md)）。

录到的关键片段（事故、路怒、沿途风景）下载到手机后，用 App 的分享功能可以直接发到社交平台；带 GPS 模块的机型还能在回放里叠加行驶轨迹（以你的机型是否带 GPS 为准）。

## 四、设置里常改的几项

不同机型菜单略有增减，以下是说明书列出的典型项目与默认值：

| 设置项 | 默认值 | 怎么选 |
| --- | --- | --- |
| WiFi 名称 | `CARDV_*****` | 可改；改名有连不回的风险，见 [连接行车记录仪步骤.md](连接行车记录仪步骤.md) |
| WiFi 密码 | `12345678` | 建议改掉并记牢 |
| 循环录像周期 | 3 分钟 | 保持默认即可；越短文件越碎，越长单文件越大 |
| 重力感应 | 中 | 调太敏感，过个减速带就锁文件，卡很快被锁定文件占满；城市路况建议中或低 |
| 视频分辨率 | 1920×1080 | 卡小（8GB 以下）或卡慢时降 720P，减少漏录 |
| 语音提示 | 开 | 嫌吵可关，不影响录制 |
| 麦克风 | 开 | 不想录车内声音就关 |
| WDR | 开 | 逆光、隧道出入口场景保持开 |
| 曝光补偿 | 按场景调 | 夜间画面过暗/过曝时微调 |

改完设置当场回录像画面确认生效，别等出了事才发现参数没存上。

## 五、卡满了怎么清

列表里删不掉的那些带锁文件，最终都要靠格式化清（菜单名称以你的机型为准），动手前先按第三节把要留的视频下载到手机。至于卡该买多大、多久格式化一次、格式化为什么要在记录仪里做而不是电脑上，统一在 [存储卡怎么选与格式化.md](存储卡怎么选与格式化.md) 里讲，这里不重复。

日常要调连接、遇到连不上的问题，分别看 [连接行车记录仪步骤.md](连接行车记录仪步骤.md) 和 [连不上记录仪怎么办.md](连不上记录仪怎么办.md)；App 还没装，从 [下载与安装教程.md](下载与安装教程.md) 开始。
