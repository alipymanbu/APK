## 一、模型列表分四大板块

模型列表按分级浏览，从上到下四档：

| 板块 | 里面是什么 | 适合谁 |
| --- | --- | --- |
| QuackAI | 自带的入门模型 | 刚上手，先免费聊起来 |
| 高级模型 | 更强的第三方模型（Claude、Gemini、GLM、KIMI 系列等） | 要更好的剧情质量，接受按量或按次付费 |
| 厂商 API | 接入的厂商接口（如 OpenRouter） | 有对应厂商账号、想用特定模型的人 |
| 自定义 API | 自己填接口地址 | 想用自己的 API 额度的人 |

模型卡片上标了计费标签（按使用量、按次、PLUS 免费、推荐等），选之前看一眼标签就知道这条要不要花钱。内置模型里有免费可用的档位（QuackAI 基础版等，另有 Tanka、Renga 两个 beta 模型），不花钱也能正常开聊。

模型阵容和价格会随版本更新调整（比如高级模型调价、新旧模型更替都发生过），以 App 内实时显示为准，别按网上的旧帖估。

## 二、聊天中怎么切换模型

1. 在聊天页点右上角的「⋯」；
2. 选「模型」；
3. 从列表里挑一个切换，对话可以接着聊，不用开新会话；
4. 有自己的 API 的话，在这一步选导入 API，按提示填入即可。

切换不影响已有剧情；同一段对话里前后用不同模型是允许的，有人习惯日常闲聊用免费档、关键剧情换高级档。

## 三、PLUS 与付费档位

- 应用本身免费下载使用，付费点在模型调用（应用内购买）；
- 免费档位日常闲聊基本够用；
- 会员（PLUS）主要换来的是：更强模型的调用额度、高峰期的优先响应；会员中心有权益对比页，模型权益栏带实时价格查询入口；
- 高级模型按使用量或按次计费，价格在 App 内实时显示，消费前先在模型卡片上确认标签。

## 四、模型下架、维护与异常

- **默认模型失效自动救援**：模型下架时，个人模型页会弹窗引导你换成推荐模型；聊天中识别到失效模型，会自动弹出选择面板，可以一键设为新默认；
- **维护状态标识**：维护中的模型会有标注，这段时间别选它，免得白发消息；
- **令牌绑定**：模型异常时令牌会被标成无效，聊天抽屉里的无效选项也会标红提醒，按提示修复或换模型即可。

模型一直报错、换一个就好的排查思路，见 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 五、上下文长度

默认上下文长度为 50,000 token（官方更新日志口径，以你手上版本的设置为准）。长剧情聊到后面角色「忘事」，先检查当前模型的上下文设定，再考虑换上下文更长的模型。

## 六、思考模式（Renga）

Renga 模型带「思考模式」（Think Mode）：正式回复前先把时间、地点、人物和各方心态理一遍再落笔。对你的直接影响是——

- 服装、伤势这类细节前后一致，不会这一轮还带着伤、下一轮就满血；
- 上一轮没写完的动作、留了尾巴的情节，下一轮会自动接上；
- 官方公告口径：只出思考不出正文、回复中断这类情况已大幅减少，模型停在了思考段时系统会自动续写正文，不用手动重发。

偶尔还会碰到回复不完整，点「重新生成」补这一轮就行；频繁复现按 [常见问题与解决办法.md](常见问题与解决办法.md) 第三节排查。
