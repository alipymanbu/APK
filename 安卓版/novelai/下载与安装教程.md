## 一、这是个什么应用

novelai 对应的是 NovelAI 这一家人工智能创作服务的安卓端入口：你在手机上输入英文标签式的文字描述（提示词），由云端模型生成动漫风格的图片，或者让 AI 帮你续写故事。它本身只有 0.31M——这个体积说明安装包里并不包含模型与生成能力，装好后所有生图、写文都要**登录 NovelAI 账号**之后联网完成；订阅与计费在官方网页 `novelai.net` 上管理，手机端做的事是把这项网页服务装进一个应用图标里。

**本篇用的安装包信息（以本地文件为准，网上各下载页的版本信息可能对不上）：**

| 项目 | 值 |
| --- | --- |
| 应用名 | novelai |
| 版本 | v1.0 |
| 包名 | `com.novelai.android` |
| 安装包大小 | 0.31M（326,957 字节） |
| MD5 | `0C5F3A7D74D53789410F0A078709FC10` |
| 系统要求 | 安卓 5.2 以上（下载页标注，以安装时系统提示为准） |

先提醒一句：安卓市场上挂着「NovelAI」之名的安装包不止一个，体积与包名各不相同，下手前建议先看 [同名应用与仿冒包区分.md](同名应用与仿冒包区分.md)，确认你要的是包名 `com.novelai.android` 的这一份。

## 二、获取安装包并安装

1. 打开 [novelai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/92a397af89f8)，把 APK 下载到手机（或先转存到自己的网盘再下）。
2. 下载完核对大小：约 0.31M。对不上说明下错文件了，回网盘重新下。
3. 点击 APK 安装。安卓会弹「不允许安装未知来源应用」，按提示允许该来源（不同系统路径略有差异，一般在 设置 → 安全/安装未知应用 里给文件管理器或浏览器授权）。
4. 装完桌面会出现 novelai 图标。它不是装完就能白用的离线工具，接下来还有账号这一关，见下节。

## 三、第一次打开前：先想清楚账号的事

novelai 背后是 NovelAI 的订阅制服务：

- 没有账号时，你进不了正式的创作界面；
- 注册本身免费，新账号会有一小笔试用额度（有多少、怎么拿，见 [注册登录与免费试用额度.md](注册登录与免费试用额度.md)）；
- 试用额度用完还想继续生图，就要订付费档（档位与消耗规则见 [订阅方案与Anlas消耗.md](订阅方案与Anlas消耗.md)）。

所以第一次打开前，先准备一个能正常收信的邮箱。注册既可以在应用里走，也可以先用手机浏览器去官网注册好、再回来登录，两条路等价。

## 四、装完打不开、白屏怎么办

0.31M 的客户端本身几乎没有可坏的部分，出问题多半出在「它要联网加载的那个服务」上。按这个顺序排查：

1. **核对安装包**：确认装的是 0.31M、包名 `com.novelai.android` 的这份；如果你装的是别的同名包（比如市场上另一种几 MB 到几十 MB 的），下面几步对它不通用，先按 [同名应用与仿冒包区分.md](同名应用与仿冒包区分.md) 认清装的是什么。
2. **先看网络**：一直转圈、白屏，大多是网络没通。先在浏览器里确认手机能正常打开官网 `novelai.net`；官网都打不开，就是网络环境问题，不是应用的问题，先解决网络再进应用。
3. **官网能开、应用里不行**：清一下这个应用的缓存再试，或退出账号重新登录。
4. **重装一次**：卸载后从上面的网盘链接重新下载安装，排除下载中断导致的包损坏。
5. **看系统版本**：下载页标注要求安卓 5.2 以上，系统过旧可能直接起不来。

按上面都试过还是不行，换个时间再试——服务端维护或高峰期加载失败，本地做什么都没用。
