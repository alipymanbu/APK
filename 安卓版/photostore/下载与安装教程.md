## 一、先看清这是个什么应用

photostore（全小写，官方页面即此写法）是一款安卓端相册管理 + 图片/视频编辑应用，开发者与运营者同为合肥君舒商贸有限公司。它不是相机，也不做云备份，管的是你手机里已有的照片和视频：分类整理、放进私密相册，再做裁剪、滤镜、拼图、视频剪辑这类加工。

装之前先核对参数，两个商店页与网盘里的包可能不是同一口径：

| 项目 | 值 | 说明 |
|---|---|---|
| 应用名 | photostore | 官方写法全小写 |
| 包名 | `com.psto.junshu` | 全渠道唯一，识别同一应用靠它 |
| 版本 | 1.1 | 网盘安装包的口径 |
| 安装包大小 | 58.93M | 网盘那份的大小；豌豆荚页面标 57.99MB，见下文 |
| 系统要求 | 标注需安卓 5.2 以上 | 豌豆荚页面标 Android 5.0 以上，两处不一致，以安装时的提示为准 |
| 商店分类 | 图库相册 / 摄影图像 | 应用宝、豌豆荚口径 |

1.1 版本的更新内容，豌豆荚页面写的是「增加相册管理功能」。商店页面信息会变，以你打开时看到的为准。

## 二、安装包从哪拿

两条路都可以，任选其一：

1. **夸克网盘**：打开 [photostore 安装文件资源（夸克网盘）](https://pan.quark.cn/s/481f8abe0bf1)，转存后在里面找到 `photostore_v1.1.apk` 下载即可。这份就是按上表参数（版本 1.1、58.93M）保存的那份包。
2. **应用商店**：
   - 应用宝：[sj.qq.com/appdetail/com.psto.junshu](https://sj.qq.com/appdetail/com.psto.junshu)，页面显示版本 1.1、更新时间 2026.1.3；
   - 豌豆荚：[m.wandoujia.com/apps/8432221](https://m.wandoujia.com/apps/8432221)，页面显示版本 1.1、57.99MB。

两个商店的 photostore 页面下载量都不高、也没有用户评论可参考（截至 2026-09，应用宝显示 0.0 分且暂无评论）。想拿到与上表参数完全一致的那份包，用上面第 1 条的网盘资源。

## 三、怎么装到手机上

1. 把 `.apk` 文件传到手机（数据线、文件传输、网盘 App 下载均可）。
2. 用文件管理器点它安装。系统弹「禁止安装未知来源应用」时，按提示跳到设置里允许本次来源（不同品牌手机入口名字略有差异，一般在「设置 → 安全/隐私」或安装弹窗上直接给按钮）。
3. 装完打开，若提示系统版本不满足，先核对你的安卓版本 —— 安装包标注需要安卓 5.2 以上。
4. 首次启动按第四节给权限。

从商店 App 内直接下载安装的，走商店自己的安装流程，不需要动「未知来源」开关。

## 四、首次启动该给哪些权限

应用商店页面公示过它的敏感权限及用途（豌豆荚「敏感权限获取说明」），先知道每一项是干什么的再决定给不给：

| 权限 | 商店页公示的用途 | 建议 |
|---|---|---|
| 存储 | 读写手机内部/外部存储，保存应用的图片及缓存、读取已存图片 | **必给**，不给应用读不到也存不了照片 |
| 读取视觉媒体 | 读取已存储的视觉媒体，供你编辑查看 | **必给**，编辑功能全靠它 |
| 位置 | 接收卫星定位，用于广告 SDK 按位置匹配广告 | 可拒绝；只想整理照片的话用不上 |
| 电话（读取手机状态） | 获取设备序列号/设备 ID，用于账号、网络安全与数据统计 | 可拒绝 |
| 系统设置 | 跳转系统设置页面，供用户设置权限 | 按需 |

商店页没有公示「拒绝后会发生什么」，拿不准就先只给存储和视觉媒体两项，其余用到时再说。调整入口在系统「设置 → 应用 → photostore → 权限」，随时能改，见 [常见问题与排查.md](常见问题与排查.md)。

## 五、核对你下载的包是否同一份

下载完可以对一下参数，避免装错应用或拿到旧包。Windows 上对 `photostore_v1.1.apk` 算 MD5：

```powershell
Get-FileHash -Algorithm MD5 .\photostore_v1.1.apk
```

期望结果：`7F4AF4715DFA09C9A5D649CB5E6DD445`；大小 58.93M（约 61,797,528 字节）；版本 1.1、包名 `com.psto.junshu`。对不上说明不是这份包，安装后「设置 → 应用」里的包名应显示 `com.psto.junshu`。
