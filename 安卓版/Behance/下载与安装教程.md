## 一、装之前先对一遍这份包的信息

Behance 是 Adobe 旗下的创意作品社区：一边看别人的项目找灵感，一边把自己的作品整理成项目发出去。开发商是 Adobe，账号与 Adobe 体系打通，用起来不收费。下面这张表是网盘里那份安装包的实际信息——网上搜到的「最新版」往往已经是另一个版本号，装之前以这张表为准，装完在应用信息里核对也对得上。

| 项目 | 值 |
| --- | --- |
| 应用名 | Behance |
| 包名 | `com.behance.behance` |
| 版本 | 7.4.9 |
| 安装包大小 | 74.68M |
| 安装包 MD5 | `142fef81cc1c440e99f1911f6c6ee6f0` |
| 系统要求 | 本包标注为 Android 5.2 及以上；Google Play 上当前在架的版本要求 Android 8.0 及以上。两处口径不同，以你手机上安装时的实际提示为准 |
| 适用形态 | 安卓手机 / 平板 |

先看这几点：

- **能不能装，按系统版本分两档判断**：Android 8.0 及以上，按本页流程装即可；Android 5.x ~ 7.x 属于不确定区，装的过程中被系统拦下、或者装完打不开，就说明这台设备不行，别在这台机器上耗时间，直接用网页版。
- 这包不小，装之前留出 **150M 以上**空闲空间比较稳妥：包本身 74.68M，安装时系统还要再解压一份。
- Behance 还有网页版（[www.behance.net](https://www.behance.net)）与 iPhone 版，登录同一个账号内容互通；本套文档只针对网盘里这份安卓包。
- 浏览过的作品图片会缓存在手机里，翻得多了占用会明显上涨。清缓存的路径和「清了之后要不要重新登录」见 [常见问题与排查.md](常见问题与排查.md)。

## 二、把安装包从网盘取到手机

1. 手机上打开 [Behance 安装文件资源（夸克网盘）](https://pan.quark.cn/s/632ef959e5f9)。
2. 先点「保存到我的网盘」，再下载。直接下载也能用，但转存到自己网盘之后，原分享链接以后失效了也不影响你。
3. 下载完成后记一下文件位置，多数浏览器会放进「下载」或 `Download` 目录。
4. 文件名形如 `Behance_v7.4.9.apk`，以网盘里实际显示的名字为准。

打开链接提示失效或要提取码，说明这条分享已经不是当前状态，换最新的一条再试。

## 三、动手装之前校验一下包

安装包从网络传到手机，中途出过错的话，装的时候会报「解析包错误」。花半分钟校验一次，能省掉后面一堆莫名其妙的排查。

用电脑校验最省事：把 APK 拷到电脑上，在它所在目录打开 PowerShell 执行：

```powershell
certutil -hashfile "Behance_v7.4.9.apk" MD5
```

输出的十六进制串去掉空格后，应该和第一节表里的 `142fef81cc1c440e99f1911f6c6ee6f0` 完全一致（大小写不敏感）。手机上也可以用带 MD5 校验功能的文件管理器做同样的事。

对不上就重新下载一次，别将就着装。

## 四、先去系统里放行「未知来源」

网盘里的包不是从应用商店装的，安卓默认会拦一次。要先给负责下载它的那个应用（浏览器或夸克）开安装权限，各品牌路径不一样：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 权限管理 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装外部来源应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 生物识别和安全 → 安装未知应用 |
| 原生安卓 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

路径记不住也没关系，在设置顶部的搜索框里搜「未知应用」或「外部来源」，基本都能跳到同一页。找到负责下载的那个应用，把开关打开。

## 五、安装与第一次打开

1. 从通知栏点刚下载完的文件，或者打开文件管理器找到那个 `.apk` 点它。
2. 弹出安装界面点「安装」，等进度走完，桌面出现图标，名称显示为 Behance。
3. 首次启动会弹权限申请。这个 App 真正需要的是这几项：

| 权限 | 不给会怎样 |
| --- | --- |
| 网络 | 首页、搜索结果、作品图片全部拉不到，只剩一个空壳 |
| 存储 / 照片和视频 | 上传自己的作品、保存图片这类操作会失败 |
| 通知 | 只影响关注和消息的提醒，不影响浏览 |
| 相机（按需） | 想直接拍照上传项目时才会用到，不给可以改用相册里已有的图 |

具体弹哪几项、叫什么名字，以你手机上实际弹出的为准，上表只是它们各自的用途。

4. 启动后先看到的是内容流，不需要登录就能往下翻。要发作品、关注人、存画板、发私信，都得先登录，登录方式见 [注册登录与账号设置.md](注册登录与账号设置.md)。
5. 首页顶部是为你推荐的内容，往下翻就是各个创意领域的作品。想让它推得更准，先关注几个你感兴趣的标签或作者，做法见 [搜索筛选与找灵感.md](搜索筛选与找灵感.md)。

## 六、装不上或者装完打不开

按这个顺序自查，比反复重装有效：

- 提示「解析包错误」「应用未安装」→ 回到第三节重新校验 MD5，文件多半没下完整。
- 提示「已被阻止安装」→ 第四节的未知来源权限没开，或者开了但给错了应用（要给它下面载这个包的那个应用）。
- 装好后点图标没反应、闪一下退回桌面 → 先看系统版本是否低于本包支持的范围；仍然不行，到 [常见问题与排查.md](常见问题与排查.md) 里按「打开就闪退」一条往下排。
- 提示空间不足 → 清出不小于安装包大小的空闲空间再试，安卓在安装时要额外留出余量。
- 应用信息里显示的版本比商店里的小 → 这是正常的：商店里滚到的是持续更新的新版本，网盘里这份是 7.4.9。功能上差异有多大以官方更新日志为准，不影响使用。
