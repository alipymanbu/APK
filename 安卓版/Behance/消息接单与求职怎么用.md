# Behance 消息接单与求职怎么用

> 本篇讲怎么在 Behance 上收发私信、把「可接单」状态挂出来、向需求方发提案收款，以及用 Jobs 找工作。

## 一、先把自己的状态标出来

平台上有大量的招募动作是「按状态找人的」，你什么都不标，就等于默认「暂不接活」。进个人资料设置，把可用状态（Availability）调到对应的一项：

| 状态 | 什么时候选 |
| --- | --- |
| 可接自由职业 / 兼职 | 有空档，愿意沟通零散项目 |
| 寻找全职机会 | 求职期，希望被招聘方看到 |
| 暂不接洽 | 手上排满，或不想被联系 |

这个状态会显示在你的主页上，是访客判断「要不要发这条私信」的第一依据。**换状态要跟着实际情况改**，一直挂着「可接单」却不回消息，比不挂更伤。

## 二、私信怎么发才有人回

私信（Inbox）能发文字，也能发图片、视频和文件，所以报价表、参考图、需求文档都能直接给出去。发之前注意三点：

- **开口就说事**。第一句写明「看到了你的哪个项目」「想委托什么类型」「大致时间与预算区间」，比一句「在吗」有效得多。
- **带上你的项目链接**。对方点一下就能判断你是否合适，省掉一轮来回。
- **附件别太大**。询价阶段给参考图或文档摘要就够，成片视频用链接，别一上来甩一个几百兆的文件。

## 三、接单：从收到询价到成交流程

平台把「接单」做成了一条站内流程，大致是：

1. 需求方（或你）发出合作意向；
2. 双方在站内沟通需求；
3. 向需求方发出提案（Proposal），把交付内容、周期、报价写进去；
4. 需求方确认后，通过平台完成付款，你按平台流程收款。

这样做的好处是**沟通记录和付款都在站内**，出了问题有据可查。收款这一环要在站内先绑定 **Stripe 账户**并保持连接——官方条款把「解除 Stripe 账户与 Behance 的关联」列为会影响创作者付费功能的情况，所以绑定之后别中途去解绑。支持的国家和地区、结算周期与手续费会变，**以平台当前的收款说明为准**，别照别人的旧经验准备。

如果对方一上来就要求「先加微信/邮箱，钱走线下」，你有权要求走站内流程；对方拒绝的话，这个活接不接自己权衡。

## 四、找工作：Jobs 与招聘方找人

Behance 的资源里有一块是面向招聘的：

- **Jobs 列表**：按创意领域、地点、雇佣类型筛职位，看到合适的可以直接通过你的主页投递。
- **被招聘方找到**：招聘方和创意总监会在平台上按领域、工具、地区搜人，你的主页和项目就是被搜到的依据。所以**作品集的质量直接决定你能不能进这个池子**，不是你多发几条私信能补上的。
- **求职方向的主页设置**：把「寻找全职机会」的状态打开，简介里写清你的岗位方向、所在地、可到岗时间。

## 五、主页就是简历，这几项别空着

被联系的概率基本由主页决定，按重要性排：

1. **三到五个完整项目**。宁少勿杂，一个讲透的案例比十个只有成品图的项目有用。
2. **简介写清能做什么、在哪个城市、怎么联系**（简介上限 1000 字符，不用写满）。
3. **可用状态**，见第一节。
4. **联系方式**，别只留平台私信，邮箱这类也补上，方便正式往来。

## 六、几条基本的判断

- **报价与交付范围先谈定再动手**，尤其是改稿次数和版权归属这两项——这两条最常起分歧。
- **收到来历不明的「大单」私信要留个心眼**：对方回避具体需求、催你尽快出图或先付任何名义的费用，先核实对方主页与已发布作品再做决定。
- **平台外的支付方式没有平台兜底**，站内流程能覆盖的尽量走站内。
- **别群发私信**。向大量用户发送相同内容在平台条款里属于骚扰行为，账号可能被限制功能甚至停用；一次只联系真正相关的人，比撒网发一百条安全也有效。
- **主页用真实姓名或本人艺名**。条款要求这么写，被判定为冒充他人时，账号可能被转移给对方或被关闭，之前积累的作品和关注会一起受影响。

账号登录不上、私信收不到提醒这类问题，见 [常见问题与排查.md](常见问题与排查.md)。
