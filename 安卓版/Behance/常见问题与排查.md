# Behance 常见问题与排查

> 本篇按症状归类排查 Behance 上最常遇到的几类问题：打不开、加载不出来、登录不上、传不上去、显示不对。

## 一、先按症状定位

大部分问题不用逐条试，先看是哪一类：

| 症状 | 走哪一节 |
| --- | --- |
| 点图标就退、白屏 | 第二节 |
| 能进界面，但图片/内容一直在转圈 | 第三节 |
| 登录页反复跳回、验证码收不到 | 第四节 |
| 传图传视频失败、进度卡住 | 第五节 |
| 封面糊、视频变模糊、颜色不对 | 第六节 |
| 关注和消息没有提醒 | 第七节 |
| 作品不见了、提示账号被限制 | 第九节 |
| 压根装不上 | 第八节 |

## 二、打开就闪退、白屏

按这个顺序排：

1. **确认系统版本**。这份包标注的系统要求是 Android 5.2 及以上，系统太老会出现打开即退。到「设置 → 关于手机」看一眼版本号。
2. **清一次应用数据**。设置 → 应用 → Behance → 存储 → 清除缓存；还是不行就清除数据（会退出登录，重新登录即可）。
3. **给它开网络权限**。部分国产系统会默认关掉新装应用的联网权限，表现就是白屏。
4. **重新装一遍**。从 [Behance 安装文件资源（夸克网盘）](https://pan.quark.cn/s/632ef959e5f9) 重新下一份，先校验 MD5 再装，具体步骤见 [下载与安装教程.md](下载与安装教程.md)。

**以上四步都做过、MD5 也是对的，打开仍然闪退**：说明问题不在安装包，而是这份 7.4.9 的包与你的机型或系统版本合不来。可以做的只剩两件——换一台系统版本更高的设备试装，或者先用网页版（[www.behance.net](https://www.behance.net)）浏览与发布作品，网页版和 App 是同一套账号与数据。这类兼容问题，重装多半也不会有变化。

## 三、内容加载不出来

首页能打开但图片一直是灰块或转圈，通常是网络到图片服务器这一段的问题：

- **先换网络试**：从 Wi-Fi 切到流量，或反过来。这是最快能区分「网络问题」还是「应用问题」的一步。
- **关掉代理或 VPN 再试**：图片服务器对某些线路响应很慢，代理反而更慢。
- **开了省流/无图模式的话关掉**：部分系统浏览器或省流工具会拦掉图片请求。
- **只有个别作品打不开**：多半是作者那边图片体积过大或已被删除，换一个作品验证。
- **整页都是空白且顶部有报错提示**：退出账号重新登录，多为一登录态的临时问题。

## 四、登录不上与验证码问题

Behance 登录走 Adobe 账号，这一段的问题基本落在验证码和密码上：

- **验证码没收到**：先等几分钟，短信和邮件都会有延迟；用邮箱收的，翻一下垃圾邮件文件夹。
- **验证码过期**：有效期只有 10 分钟，超时点「重新发送验证码」拿新的，别反复输旧码。
- **换一种接收方式**：验证页面可以切换短信与邮箱，一种收不到就换另一种。
- **密码反复报错**：注意大小写；在 Adobe 账号登录页点「忘记密码」重设一次。
- **提示没有这个邮箱对应的账户**：你可能用了另一个邮箱注册。打开 [account.adobe.com](https://account.adobe.com/)，选「获取登录帮助」→「查找我的账户」，输入可能用过的邮箱或手机号即可确认。
- **两步验证把你挡住了**：需要能同时碰到绑定的邮箱、绑定的手机号、Adobe Account Access 应用里的至少两项才能找回，说明见 [注册登录与账号设置.md](注册登录与账号设置.md)。

## 五、上传失败

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 单张图片传不上 | 超过 50M | 压到 1400 像素宽、50M 以内再传 |
| 视频传到一半失败 | 文件超过 1G 或网络中断 | 换 Wi-Fi 重传；更长的片子改用 YouTube / Vimeo 嵌入 |
| 传完内容没了 | 中途退出或切后台被杀 | 重新进项目编辑页检查，重新上传 |
| 一直卡在「处理中」 | 服务端在处理大文件 | 等几分钟再刷新；仍未完成就删掉重传 |

一部手机同时开着省电模式、后台被频繁清理时，长时间上传很容易被打断，传大文件时把省电模式关掉。

## 六、显示与画质问题

- **封面在列表里糊**：封面最小要 808 × 632 像素，低于这个尺寸会被拉伸。换成 1400 像素宽左右的图。
- **封面被裁掉了主体**：封面在列表里按固定比例显示，主体别贴边，留出余量。
- **视频明显变糊**：直接上传的视频宽度会被压到 1280 像素左右，4K 成片要用外部平台嵌入，见 [上传作品与项目管理.md](上传作品与项目管理.md)。
- **颜色发灰、偏色**：原图是 CMYK 色彩模式，上传前转成 RGB。

## 七、通知收不到

- 系统设置里给 Behance 开通知权限；
- 国产系统还需要额外的「自启动」「后台运行」白名单，否则进程被清掉就收不到推送；
- 只在 App 内能看到红点、系统通知栏没提示，多半是后台被限制，把 Behance 加进电池优化的例外名单。

## 八、压根装不上

提示「解析包错误」「应用未安装」「已被阻止安装」，都不属于 App 内部问题：

- 回到 [下载与安装教程.md](下载与安装教程.md) 第三节重新校验一次安装包；
- 确认「安装未知应用」权限给的是**负责下载这个包的那个应用**；
- 空间不足就先清出 150M 以上再装；
- 应用信息里的版本是 7.4.9，比应用商店里滚到的版本小是正常的，不是装错了。

## 九、作品不见了，或者提示账号被限制

- **某个项目不见了**：先确认不是自己误删；确实没删过，就是被平台处理了。原因分类与申诉材料清单见 [作品被下架与账号限制申诉.md](作品被下架与账号限制申诉.md)。
- **登录后提示「无权访问 / Access Denied」**：有用户反馈在部分地区的账号会碰到这条提示，表现为 Adobe 账号本身能用、但进不了 Behance。这类限制在账号层面，重装 App、换网络、换设备都不会改变结果，只能通过 Behance 帮助中心的请求表单问清楚原因与处理方式。
- **发布、私信这类按钮被限制**：多与群发私信或反复收到侵权投诉有关，处理思路与上一条相同；先停止可能有问题的行为，再提交申诉。
