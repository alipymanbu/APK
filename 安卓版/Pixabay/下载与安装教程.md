## 一、先确认你要装的是哪一版

| 项目 | 信息 |
| --- | --- |
| 应用名称 | Pixabay（图库网站 Pixabay.com 的官方安卓客户端） |
| 版本 | 1.2.15.1 |
| 包名 | com.pixabay.pixabayapp |
| 安装包大小 | 1.59 MB |
| MD5 | FD40C6E7767FFA154CC68B801895F8E7 |
| 系统要求 | 安卓 5.2 及以上（以实机安装为准） |
| 开发者 | Pixabay.com |

三点背景，帮你判断这份包适不适合你：

- 1.2.15.1 是官方 1.x 版本线的最后一版（2021 年 7 月），这一版的更新内容就一条：下载成功后会发系统通知。界面是 2021 年改版后的样子，功能围绕搜图、看图、下载与收藏，上传作品也支持（1.2.14 起可相机直传）。
- 官方在 2025 年发布了整个重写过的 2.0 大版本，补齐投稿比赛、线上工作坊等社区功能与新的登录方式。商店渠道装到的会是 2.0，版本号与本篇的安装包不同——两者用的是同一个图库，搜图与下载的核心体验一致。
- 包只有 1.59 MB，属于典型的「客户端小、素材在云端」：不下载图片时几乎不占空间，图片缓存才是空间大头。

## 二、拿到安装包

安装包放在夸克网盘里，获取路径是：打开 [Pixabay 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1efcb6c88f3f) → 转存到自己的网盘 → 在网盘客户端里下载，得到 `Pixabay_v1.2.15.1.apk`。

手机上直接下载即可；也可以先在电脑上下载，再用数据线或其他方式传到手机安装。

## 三、核对安装包（可选但建议）

如果你对文件来源比较在意，下载完可以先核对 MD5，对得上再装。Windows 上用自带命令：

```powershell
certutil -hashfile "Pixabay_v1.2.15.1.apk" MD5
```

输出的哈希值应与 `FD40C6E7767FFA154CC68B801895F8E7` 一致（不区分大小写）。

## 四、安装步骤

1. 在文件管理器里点开刚下载的 `.apk` 文件。
2. 系统弹出「未知来源」提示时选择允许。安卓 8 及以上会按提示跳到设置页，给「文件管理器」或你用来下载的那个应用打开「允许安装未知应用」开关，返回后重新点安装。
3. 部分国产手机会再多一道拦截：
   - 小米：可能提示「纯净模式」，按提示选择继续安装，或在设置里临时关闭；
   - 华为/荣耀：可能提示「外部来源应用检查」，按提示允许；
   - 其他品牌：按弹窗文字操作即可，各机型菜单位置有差异。
4. 等安装完成，点打开。

## 五、装完先做这两件事

1. **切中文**：默认界面是英文，右上角菜单最底部有语言选项，两分钟搞定，步骤见 [怎么设置中文.md](怎么设置中文.md)。
2. **确认能联网**：素材全部在线加载，首次打开要拉取图片列表，网络不通会一直转圈。搜索或下载遇到问题，先翻 [常见问题与解决办法.md](常见问题与解决办法.md)；想直接开搜，见 [素材搜索与下载方法.md](素材搜索与下载方法.md)。
