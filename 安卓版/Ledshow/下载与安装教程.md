Ledshow 是上海仰邦科技配套自家 LED 控制器发布的手机端控制软件：手机先连上控制器发出的 WiFi，之后就能改屏参、编节目发到屏上、调亮度、对时、开关屏。它必须配上仰邦的控制器才有意义——不接控制器只装 App，界面能打开，但搜不到任何设备。本篇只解决「把包装进手机」这一步，连控制器看 [怎么连上控制器和添加屏幕.md](怎么连上控制器和添加屏幕.md)。

## 一、先弄清网盘里这份包是哪一版

网上搜到的是官方下载页当前挂的版本，网盘里这份是整理文档时核对过的一版，两者未必是同一个版本号。凡涉及版本号、包名、体积，本文一律以这张表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Ledshow（手机 APP） |
| 版本号 | 3.0.12 |
| 包名 | `com.onbonbx.ledshowtw` |
| 安装包体积 | 47.46 MB |
| MD5 | `ff6a8a569ccd46160b00fadbf22bf113` |
| 适用平台 | Android（iPhone / iPad 另有单独版本，见第四节） |

作为对照：仰邦官方下载页「LedshowTW 单双色/6Q」分类下挂的安卓版是 **V3.0.10/20231123**、页面上标称 47.46M，网盘里这份 3.0.12 比页面上挂的那一版新。官方页面会持续更新，具体以你打开时的显示为准。

安卓端的版本号是「主版本.次版本.修订号」三段式，iOS 端另有自己的一套编号，两边的数字对不上属于正常，不要拿 iPhone 的 1.1.x、1.2.x 去比安卓的 3.0.x。

**关于系统版本**：官方下载页只写了支持哪些控制器系列，没有标注安卓最低版本，所以「我这台手机能不能装」要到装的时候看系统怎么说——如果提示「应用与设备不兼容」，或者装完打不开，通常是系统版本太低或 CPU 架构不符，换一台设备再试。苹果端官方标注的是 iOS 9.0 及以上。

## 二、它和电脑端的 LedshowTW 不是同一个软件

搜「Ledshow」会同时出来几个结果，动手前先分清：

| 你手上的东西 | 配套的是什么 | 对本文的意义 |
| --- | --- | --- |
| 手机上的 Ledshow APP | 就是网盘里这份包，安卓手机或 iPhone/iPad 用 | 本文主体 |
| 电脑上的 LedshowTW 图文编辑软件 | Windows 软件，安装包两百多 MB，编节目能力比手机端全 | 不是本文这份包 |
| LedshowYQ、Ledshow Suite | 配仰邦 Y 系列多媒体播放器等另一类硬件 | 与本文这套不通用 |

三者名字都带 Ledshow，但适配的控制器、运行平台、能做的事都不一样，装错了会出现「软件搜不到控制器」这类看起来像故障、其实是不配套的情况。怎么确认自己的控制器该配哪套，见 [支持哪些控制器型号.md](支持哪些控制器型号.md)；如果还在犹豫该用手机端还是电脑端，见 [手机端和电脑端分别适合什么情况.md](手机端和电脑端分别适合什么情况.md)。

## 三、Android 手机安装步骤

1. **转存并下载**：从 [Ledshow 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3177a052491a) 把安装包转存到自己的网盘，再下载到手机；也可以在电脑上下好，用数据线或互传工具拷进手机存储。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，把用来打开安装包的那个 App（文件管理器或浏览器）的开关打开。国产定制系统常把这一项收在「安全」或「隐私」分类下面。
3. **点安装包完成安装**：过程中提示「未经安全检测」「建议前往应用市场下载」属于第三方渠道安装包的常规提示，选择继续安装即可。
4. **覆盖安装先看版本**：如果手机上已经装过 Ledshow，安卓不允许用更低的版本号覆盖更高的版本，会直接报「应用未安装」，这时先卸载旧版再装。卸载会一并清掉手机上保存的节目与屏幕配置，介意的话先做一次云备份，做法见 [节目怎么编辑和发送.md](节目怎么编辑和发送.md) 最后一节。
5. **装完先别急着开**：先把下一节的权限过一遍，否则第一次连控制器时容易出现搜不到 WiFi 的情况。

## 四、iPhone / iPad 上怎么装

苹果端在 App Store 里叫 **ledshowtw**，开发者写的是 onbon（上海仰邦科技），直接搜索即可，页面上标注要求 iOS 9.0 及以上、专为 iPhone 与 iPad 设计，体积比安卓版大不少（现为一百多 MB，具体以 App Store 当时显示为准）。

两点区别先记住：

- 网盘里这份是安卓的 APK，装不到 iPhone 上；苹果设备走 App Store，安装包不从网盘取。
- 苹果端的版本号与安卓端不同步，界面细节也略有差异；遇到具体按钮叫法不一样时，以你手上那端的界面为准。

## 五、第一次打开会要什么

| 权限 | 用途 | 不给会怎样 |
| --- | --- | --- |
| 存储 / 文件 | 保存节目、模板与备份用的临时文件 | 保存节目、导出模板时报错 |
| 定位（部分机型） | 安卓从 6.0 起，扫描并连接指定 WiFi 需要它才能拿到 WiFi 列表 | WiFi 列表里看不到 `BX` 开头的控制器热点 |
| 相机 | 扫码或现场取材时用 | 仅影响这两个入口，不影响控制屏 |

第一次进到主界面时，里面是空的：没有屏幕、没有节目。这是正常状态——屏幕必须在连上控制器之后才能添加，接着做 [怎么连上控制器和添加屏幕.md](怎么连上控制器和添加屏幕.md)。

## 六、装完做一次最小验证

1. 打开 App 能进到主界面，没有卡在权限弹窗上；
2. 手机 WiFi 列表里能看到形如 `BX` 开头的热点（控制器要事先通电）；
3. 能进主界面的设置菜单并看到屏参、亮度、校时这些入口，说明 App 本身没问题，剩下的都是控制器那边的事。

第 2 步找不到热点，先别怀疑 App，直接看 [连不上或搜不到控制器怎么排查.md](连不上或搜不到控制器怎么排查.md)。
