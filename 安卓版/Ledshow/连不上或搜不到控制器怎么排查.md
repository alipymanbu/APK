# Ledshow 连不上或搜不到控制器怎么排查

> 按现象排查：手机 WiFi 里找不到控制器热点、连上了却提示无互联网、搜不到设备、发送了屏上没反应、忘记 WiFi 密码。

这套系统的链路是「控制器发热点 → 手机连热点 → App 搜设备 → 发送节目」，任何一环断了表现都差不多：屏上没反应。下面按你实际看到的现象分头查，从最容易排除的开始，每一步都给出判断依据，不要一上来就复位或重装。

## 一、手机 WiFi 列表里找不到 `BX` 开头的热点

按顺序排除：

1. **控制器有没有上电**：看控制器上的指示灯。没上电一切免谈，屏亮不代表控制器一定在跑无线模块。
2. **手机离得够不够近**：板载天线型号官方建议无遮挡 20 米以内，控制器装进屏体后更保守，按 15 米左右留余量。隔着几堵墙或站到屏体背面，信号会被挡住。
3. **定位权限给没给**：安卓从 6.0 起，扫 WiFi 列表需要定位权限，权限关着时列表里会少很多热点，包括控制器的。这一条在 [下载与安装教程.md](下载与安装教程.md) 第五节有说明。
4. **手机是不是刚连过别的 WiFi**：系统偶尔会卡在扫描上，关一次 WiFi 再开、或者重启手机即可。
5. **控制器是不是被设成了不广播**：改过 WiFi 名称与密码之后，如果没在手机上「忘记网络」，会出现看得见却连不上的情况，见第四节。

## 二、连上了，但系统提示「无法访问互联网」

这不是故障。控制器热点本身不提供外网，系统会弹一句「此 WLAN 网络无法访问互联网，是否继续连接」，选**继续连接**即可，之后搜索设备、发送节目都正常。

选了取消，等于没连上，接下来搜设备必然是空的。

## 三、连上了热点，App 里却搜不到设备

1. **确认连的是控制器热点**：手机 WiFi 里当前连接的名称应该是 `BX...` 或一串条码；连着家里路由器时搜不到控制器，因为两者不在同一个网络里。
2. **点一次重新搜索**：搜索入口在 App 主界面上（自动搜索在线控制器）。搜到之后会回读屏参，再点确定加屏。
3. **核对软件与控制器是否配套**：Y 系列播放器、视频处理器那几类硬件配的是别的软件，用 Ledshow 连当然搜不到，见 [支持哪些控制器型号.md](支持哪些控制器型号.md) 第四节。
4. **给控制器断一次电**：长期通电的控制器无线模块偶发卡死。做法是**先把供电断掉、等屏上所有灯珠都熄灭，再重新上电**做一次初始化——现场维修资料里把这一步列为基础动作，不少偶发问题靠它解决。
5. **换一台手机试**：换手机能搜到，问题在原来那台手机的权限或系统设置上；换手机也搜不到，问题在控制器侧。

## 四、改过 WiFi 名称或密码之后连不上

改完必须做一步：**先在手机系统的 WiFi 列表里「忘记」这个网络，再用新密码重新连**。不忘记的话，手机会一直拿旧密码去连，界面上的表现就是反复连、反复失败。

忘记了新密码，就走下一节的硬复位。

## 五、忘记了控制器 WiFi 密码

官方给出的复位办法：

1. 找到控制器上的 `WIFI RST` 复位键；
2. **按住约 10 秒**，直到控制器 WiFi 指示灯变成红色闪烁，再松开；
3. 复位后密码恢复为出厂状态（默认仍是条码后 8 位），按默认密码连上后可以重新设置名称与密码。

复位只影响 WiFi 模块的名称与密码，改之前屏上的节目不会因此消失；但复位后要按 [怎么连上控制器和添加屏幕.md](怎么连上控制器和添加屏幕.md) 重新连一次。

## 六、提示发送成功，屏上却没变化

按可能性从高到低查：

1. **亮度被拉到最低**：屏是亮的但几乎看不见内容，先把亮度调上去；
2. **屏幕被锁定了**：锁定状态下现场改不动，App 侧要解锁后再发；
3. **屏幕被关掉了**：App 里可以直接开关屏，也可能是定时开关屏到点把屏关了；
4. **发的不是当前这块屏**：多块屏的场景下手机连的是另一台控制器，屏上自然不会变，切回正确控制器再发；
5. **屏上只跳出控制器型号**：屏参里的型号与实际控制器不一致、或者数据没传完整时会这样。先核对屏参里的型号，再重发一次；
6. **屏参或扫描方式与屏体不匹配**：表现通常是画面被压成横带、错位或只亮一部分，按 [屏幕参数与扫描方式怎么设置.md](屏幕参数与扫描方式怎么设置.md) 第一、二节逐项核对；出现文字反白、整屏全亮或一行亮一行暗，则是极性反了，见同一篇第三节。

## 七、发送过程本身就失败

- **信号弱**：离控制器远、隔墙，发送到一半就断，靠近再发；
- **手机切到了别的网络**：发送期间手机如果自动连回家里的路由器，链路会断，先把手机 WiFi 的自动切换关掉或靠近控制器再发；
- **控制器忙**：正在接收上一次发送时再次发送容易失败，等上次的提示出来再发。

排查走完还是不通，把三样东西记下来再找安装方或厂家：控制器型号、App 里回读出来的屏参、复现问题的具体步骤。这三样能省掉大量来回。
