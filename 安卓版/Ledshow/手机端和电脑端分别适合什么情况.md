# Ledshow 手机端和电脑端分别适合什么情况

> 同一块屏，手机 App 和电脑上的 LedshowTW 都能改。本篇讲清两者各能做什么、什么时候手机上就够、什么时候必须坐到电脑前。

控制器里存的只是「最后发过去的那一屏内容」，用手机还是用电脑发，结果一样，差别在于各自适合的活不一样。判断办法很简单：只改文字、调亮度、开关屏，手机就够；要在一屏里摆好几块区域、插图片、导文档，用电脑。本篇把两边各自能做的事列清楚，由你按手头的活挑。

## 一、两边各是什么

| 对比项 | 手机端 Ledshow APP | 电脑端 LedshowTW 图文编辑软件 |
| --- | --- | --- |
| 运行平台 | Android、iOS | Windows（官方手册列出的适用系统是 XP / Win 7 / Win 8 / Win 10） |
| 安装包体积 | 手机版几十 MB | 官方下载页标称 250M 上下，以页面当时显示为准 |
| 连接方式 | 手机 WiFi 直连控制器 | 电脑需要无线网卡（PCI 或 USB 均可）去连控制器 WiFi |
| 首次配置 | 装完连上控制器就能改字 | 先装软件，再确认电脑有可用的无线网卡 |
| 版本编号 | 安卓 3.0.x 一档 | 按日期编号，如 23.08.16.00 这一档 |

## 二、这些事手机上就够了

- 改屏上滚动的通知、店名、欢迎语这类纯文字；
- 调亮度和开关屏，现场临时应付一下；
- 对时、看屏参、改扫描方式；
- 发一屏简单内容，比如「今日休息」这种临时告示；
- 手机上连着的就是控制器热点，改完当场就能看到效果，不用来回搬电脑。

## 三、这些事还是得用电脑

- **节目里有图片、动图、视频片段**：手机端的区域类型有限，素材类的编排能力主要在电脑端；
- **一屏要摆好几块区域、位置要精确**：电脑端可以拖拽区域、拉边框、开区域最大化预览，做版式比在手机上点快得多；
- **要导入现成的文档当内容**：电脑端支持直接打开或添加 docx、xlsx 一类的文档；
- **要用天气预报这类联网素材**：这部分功能在电脑端；
- **要把节目存到 U 盘里**：U 盘下载节目是电脑端的做法；
- **节目多、要复制粘贴和调整播放顺序**：电脑端有节目上移下移、复制粘贴，批量整理更顺。

以上能力来自官方手册与软件说明页的表述，不同版本会有出入，动手前以你那一版的界面为准。

## 四、电脑端连控制器的流程

官方手册给的步骤（以无线连接为例）：

1. 电脑装上 LedshowTW 2017 软件，并确认电脑有可用的无线网卡（内置或 USB 外接都行）；
2. 连上控制器发出的 WiFi，热点名仍是 `BX` + 条码 或条码本身；
3. 进「设置 → 设置屏参」，按手册要求输入进入密码（官方手册里的例子是 `888`）；
4. 选控制器型号、填屏宽屏高，点「上传参数」把屏参写给控制器；
5. 编辑节目（文本区、字幕区、时间区、天气区、传感器区这些在电脑端都能加），点发送。

屏参这几项的含义与手机端一致，逐项怎么判断见 [屏幕参数与扫描方式怎么设置.md](屏幕参数与扫描方式怎么设置.md)；型号能带多少点见 [支持哪些控制器型号.md](支持哪些控制器型号.md)。

## 五、两边可以混着用

- 屏上的内容是**最后一次发送的结果**：手机发过之后再用电脑发，屏上显示的就是电脑那份，反之亦然，谁最后发谁生效；
- 现场用手机应付临时通知、回到办公室用电脑做正式节目，是很常见的用法，两者不冲突；
- 想统一保存在云端、换设备也能取回，走 App 里的云备份，或用仰邦的 iLEDCloud 信息发布平台，见 [节目怎么编辑和发送.md](节目怎么编辑和发送.md) 最后一节。
