# Ledshow 节目怎么编辑和发送

> 本篇讲清一个节目由什么组成、「单区文本自适应分区」和「自由分区」两种编辑模式该用哪种、文本和时间类区域能改哪些项，以及怎么把节目发送到屏上。

节目就是「要显示在屏上的一屏内容」。App 里可以存多个节目，按顺序轮流播放，也可以只发其中一个。编辑动作集中在三件事上：选编辑模式、往节目里加区域、调区域里的内容与效果。屏参没设对之前先别急着编节目，否则改了半天也发不出去，见 [屏幕参数与扫描方式怎么设置.md](屏幕参数与扫描方式怎么设置.md)。

## 一、一个节目里有什么

一个节目由若干**区域**拼成，区域是屏上的一块显示范围，各自独立设置内容。常见区域类型：

| 区域类型 | 用来显示什么 | 典型用法 |
| --- | --- | --- |
| 文本区 | 你输入的文字 | 门店名称、通知、欢迎语 |
| 时间区 / 数字时钟 | 日期、时间、星期 | 屏角上的时钟 |
| 表盘区 | 模拟表盘 | 需要时钟但不想要数字的场合 |
| 计时区 | 正计时或倒计时 | 活动倒计时、工期天数 |
| 语音区 | 语音播报内容 | 配了语音播报功能的屏 |
| 温湿度区 | 接入传感器后的温湿度读数 | 库房、机房、车间 |
| 图片区 | 图片内容 | 需要图形标识的场合 |

不是每种控制器都支持全部区域类型，型号越新、支持的区域越多。加了区域却发不过去，先回去核一下型号支持范围，见 [支持哪些控制器型号.md](支持哪些控制器型号.md)。

## 二、两种编辑模式该选哪个

App 提供「**单区文本自适应分区**」和「**自由分区**」两种编辑模式，区别在谁来定位置：

- **单区文本自适应分区**：你只管打字，区域位置与大小由 App 按文字自动排。屏上只有一两行字、内容经常换（通知、叫号、欢迎语）时用这个，改起来最快。
- **自由分区**：区域的位置、宽高、图层关系全部由你指定，可以在一个节目里摆好几块区域（左边时间、右边通知、上加边框）。需要固定版式、内容分区明确时用这个。

判断标准很简单：**改完不想再微调位置 → 用自适应；需要精确控制每块区域的位置与大小 → 用自由分区。**

## 三、文本能改哪些项

文本区里可调的样式项，官方列出的有：

| 类别 | 可调项 |
| --- | --- |
| 字体 | 字体类型、字号 |
| 颜色 | 文本颜色（八种可选） |
| 字形 | 加粗、倾斜、下划线 |
| 间距 | 行间距、字间距 |
| 形变 | 拉伸、压缩、旋转 |
| 排布 | 显示行数、文字方向 |

几点实际影响：

- **字号与行数一起看**。屏高固定时，字号调大、行数又设成两行，第二行会被挤掉或压住第一行；先把行数定下来，再调字号。
- **颜色种类有限**，单双色屏实际能显示的只有屏体本身支持的颜色，界面上可选的项比屏上能出的颜色多，选了不显示不要当成故障。
- **拉伸压缩是把字形变形**，不是改字号，用来把一行字塞进固定宽度的区域里。

## 四、节目的播放效果

在节目属性里可以调：

- **特技方式**：官方应用说明里列出的特技有 70 种左右（连续左移、翻页、闪烁之类），具体清单以你那份包里的列表为准；
- **速度等级**：控制特技的快慢，可调范围与型号有关，新版还专门优化过最快档；
- **停留时间**：一个画面显示多久再切下一个；
- **边框**：可给节目或区域加边框，边框速度同样可调。

多节目依次播放时，节奏由「停留时间 + 特技速度」共同决定。屏前人看着觉得切换太快或太慢，通常先调这两项，而不是去动亮度。

## 五、发送到屏上

1. 选中要发的节目；
2. 点发送；
3. 等提示出现——加屏成功、发送成功的提示文案参考官方手册的 `download program successfully`「节目发送成功」这一类，不同端文案略有差别，看到成功提示即表示控制器已收到。

发送不成功、或者提示成功但屏上没变化，分两种情况：**手机当前连的不是这块屏的控制器**，或者**屏参/扫描方式不对**。前者重新连控制器再发，后者见 [屏幕参数与扫描方式怎么设置.md](屏幕参数与扫描方式怎么设置.md)。反复重发同一个节目不会解决问题，先按 [连不上或搜不到控制器怎么排查.md](连不上或搜不到控制器怎么排查.md) 定位。

## 六、多块屏怎么发

- 节目列表支持**多选**，选好几个节目可以一次群发，适合同一块屏上批量更新；
- 多块屏内容相同时，官方给出的做法是利用**节目自适应**：一份节目按不同屏的屏参自动适配后群发，不用为每块屏各编一份；
- 多块屏内容不同时，把手机 WiFi 切到对应控制器上分别发送，切之前确认连的是哪一块屏。

## 七、模板与云备份

- **模板编辑**：把常用的版式（比如固定的门店名 + 时间 + 通知三块区域）存成模板，下次新建节目时直接套用，不用从零摆区域。
- **云备份**：主界面的 CLOUD 入口登录后，可以把节目备份到服务器、也可以从服务器把备份取回来。换手机、重装 App、或者另一台手机也要发同样的内容时，这条路径比重新编一遍省事。

云备份走的是仰邦的云平台账号（iLEDCloud 信息发布平台，中国站入口是 [www.iledcloud.cn](https://www.iledcloud.cn)，国际用户对应 `.com` 域名）。注册口径按官方平台帮助中心：

| 账号类型 | 注册要提供什么 | 能否马上用 |
| --- | --- | --- |
| 个人用户 | 手机号或邮箱 + 验证码 | 手机号注册验证通过即可登录；邮箱注册的按平台提示完成验证 |
| 企业用户 | 公司名称、组织机构代码 / 统一社会信用代码 + 手机号或邮箱 | 需要平台审核开通后才能登录 |

登进去之后，屏幕在「资源管理 → 屏管理」里看，节目在「节目管理」里看；模块名称与位置以平台当时显示为准。

两个操作上的注意点：

- **先确认控制器在线**再备份，否则可能只备份了节目、没带上屏幕配置；
- 恢复时如果平台上的屏幕与现场控制器对不上（换过控制器、改过条码），先把屏幕重新加一次，再下发节目。
