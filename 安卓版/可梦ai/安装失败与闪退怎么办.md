## 一、点 APK 后提示「解析包时出现问题」

**原因**：APK 文件损坏或没下完整（最常见，136.65M 的包断网一次就废了）。

**处理**：

1. 确认下载的文件大小约 136.65M，明显偏小就是残包；
2. 直接删掉重新下 —— 重新下载请走 **[可梦AI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e2f04f9903b8)**，从网盘重新转存下载一遍；
3. 下完先别急着装，校对 MD5（`cc7e0d06857176d29d4a5668396bd5be`），一致再点安装，方法见 [下载与安装教程.md](下载与安装教程.md) 第二节。

## 二、提示「应用未安装」

按出现概率从高到低排查：

| 现象/提示 | 原因 | 处理 |
| --- | --- | --- |
| 装完立刻提示未安装 | 没给「安装未知应用」权限 | 按 [下载与安装教程.md](下载与安装教程.md) 第四节开一次权限后重试 |
| 装到一半失败 | 存储空间不足（136.65M 的包解压需要约 1.5~2 倍空间） | 清出至少 500M 可用空间再装 |
| 手机上已装过同名应用 | 新旧包**签名不一致**或**版本更低** | 先卸载手机上旧的那版，再装这份（注意：卸载会清掉应用内本地数据） |
| 老机型装不上 | 系统版本过低 | 第三方页面标注要求安卓 5.2 以上；系统低于此的设备无法安装 |

## 三、一直卡在「安装中」或安装按钮点不动

1. 重启手机后重试 —— 安装器进程残留会让第二次安装卡死；
2. 换个安装入口：用文件管理器直接点 APK，别用浏览器的「打开」；
3. 华为/鸿蒙机型检查：设置 → 系统和更新 → **纯净模式**，开着会拦第三方 APK，先关掉；小米等机型在「安全中心」里也可能有安装拦截。

## 四、打开就闪退 / 闪一下就退

按顺序做，做到哪步好了就停：

1. **清后台重开**：上滑清掉全部后台应用，再点图标启动；
2. **清缓存**：桌面长按图标 → 应用信息 → 存储占用 → **清缓存**（先别点「清数据」，清数据会丢本地记录）；
3. **检查权限**：应用信息 → 应用权限，把存储（照片/文件）、相机这类权限给上 —— 生成完要保存图片时缺权限最容易崩；
4. **切换网络试**：Wi-Fi 和移动数据换着来，排除当前网络被墙或 DNS 异常（应用**必须联网**才能跑，弱网下也容易白屏退出）；
5. **升级系统**：系统版本过低或 WebView 组件过旧都会导致启动即崩，把系统更新到最新再试；
6. **卸载重装**：以上都无效就卸载，重新走一遍 [下载与安装教程.md](下载与安装教程.md)（记得 MD5 核对）。

## 五、能打开但功能用不了：转圈、生成失败

这类问题通常**不在你的手机上**：

- **先看网络**：随便在「AI 对话」里发一句话，能回复说明网络通；发了没反应先切网络。
- **生成失败、一直排队**：AI 出图出视频是云端服务，高峰时段或服务端异常时会失败率升高 —— 这类情况等一会儿重试即可，换个时间段往往就好了。
- **额度用完**：出图/出视频前应用会显示本次消耗，若按钮变灰或提示额度不足，到应用内额度页面确认（资费以应用内当时显示为准）。

## 六、还是不行的兜底顺序

1. 核对包：版本 1.0.4、包名 `com.gxhqws.yramsuc`、MD5 `cc7e0d06857176d29d4a5668396bd5be`；
2. 卸载旧版 → 重启手机 → 重新从网盘下载 → 校验 MD5 → 开未知来源权限 → 安装；
3. 装好后版本号仍不对、或安装器反复报错，换一台手机试 —— 能装则说明是原设备的系统限制，不能装则说明包有问题，回 [下载与安装教程.md](下载与安装教程.md) 重新拿包。

装好之后怎么用，看 [AI绘画与视频生成使用教程.md](AI绘画与视频生成使用教程.md)。
