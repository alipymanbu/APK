## 一、三件容易混的事

「隐身」管的是**别人能不能看到你在线**；「隐身访问」管的是**你逛别人主页会不会留下痕迹**；「访客记录本」则是反过来**记录谁看过你**。三个开关位置不同、作用相反，本篇挨个说清，最后补上隐私设置与账号注销的路径。

## 二、隐藏在线状态（隐身）

1. 打开 App，点**首页左上角的状态按钮**（就是显示你当前在线状态的那个）。
2. 在弹出的状态列表里点「隐身」，状态即切换。
3. 切换后你对别人显示为不在线；对方给你发消息仍能送达，你照常能收发。

再点一次切回在线即可恢复。这个开关是即时生效的，不需要重启 App。

## 三、隐身访问与访客记录本

- **隐身访问**：开着它，你点进别人的个人主页不会在对方的访客列表里留下你的记录。
- **访客记录本**：在你自己的主页上，能看到最近谁来过 —— 想知道有没有人对你感兴趣，靠的就是它。

两者是一对：别人隐身访问，你就看不到他；你隐身访问别人，别人也看不到你。谁也没有必胜的一方。

**收费情况**：官方 iOS 版的内购说明里，「访客记录本」与「隐身访问」都提供**连续包月**的订阅项（各 1 个月为期）。价格与是否限时免费以 App 内购买页当时显示为准，这里不写死数字。开连续包月前看一眼续费规则，不需要时去系统「订阅管理」里关掉自动续费，避免到期自动扣款。

## 四、其他隐私开关在哪

官方隐私政策给的路径是：

```
我的 → 设置 → 通用 → 隐私设置
```

在这里管理个性化内容推荐等开关；个人信息（昵称、头像、签名等）在「设置 → 个人信息」里改。另外记住两条：

- **位置权限**决定你出不出现「附近」的匹配里 —— 想完全不被附近的人刷到，去系统权限里把定位关掉最彻底。
- **匿名匹配时**对方看不到你的资料，但这只是产品机制，不是安全承诺 —— 住址、单位、学校这些信息任何时候都别在聊天里给出去。

## 五、账号注销

```
我的 → 设置 → 账号与安全 → 注销账号
```

提交后进入平台审核处理流程，官方口径未公布固定处理时长，一般需要几天（以 App 内提示为准）。注销前注意：

- 注销的是**手机号绑定的这个账号**，动态、好友关系会一并清掉，不可恢复。
- 若开着连续包月订阅，先去系统「订阅管理」取消，否则账号没了扣款还在。
- 只是想避风头，用第二节的隐身就够了，不用走到注销这一步。

## 六、隐私相关问题的反馈入口

对隐私设置有疑问、或认为个人信息被不当处理，走 App 内反馈：**设置 → 帮助与反馈 → 我要反馈**，进入会话窗口直接提。邮箱渠道按你装的版本对应的隐私政策找，公开政策里出现过两个：

- `huohuafeedback@xiaochuankeji.cn`（现行完整版隐私政策留的邮箱）
- `2703912502@qq.com`（早期版本隐私政策留的邮箱）

两个都发一遍即可，哪条通以回复为准。隐私政策原文入口在 App 内「设置 → 关于/隐私政策」，或官网 [www.huohuahudong.com](https://www.huohuahudong.com/) 页面底部。另外，各版隐私政策的运营主体署名并不统一（有过多家公司名），核对正版包别看这个，看包名 —— 见 [好几个同名App怎么分清.md](好几个同名App怎么分清.md) 第三节。更多反馈与账号异常的处理见 [匹配不到人怎么解决.md](匹配不到人怎么解决.md)。
