## 一、你在跟谁聊、聊什么

火花Chat 的主战场是**陌生人一对一 + 多人语音房间**：你先通过匹配或房间认识人，再转到私聊继续。装好、注册好（见 [下载与安装教程.md](下载与安装教程.md)）之后，先花两分钟认清界面，后面所有玩法都从这五个入口出。

## 二、底部五个模块分别是什么

| 模块 | 你在这里做什么 |
| --- | --- |
| 遇见 | 匹配入口：按兴趣标签和在线状态给你适配聊天对象，点进去就能摇人 |
| 派对 | 列出别人开好的主题语音房间，点进去直接加入；也能自己开房间 |
| 动态 | 别人分享的日常与心情，看到顺眼的可以直接点进对方主页开聊 |
| 信息栏 | 所有私聊消息的收发中心，好友消息、互动提醒都汇总在这 |
| 我 | 自己的主页：已发动态、个性空间入口，以及设置、隐私、账号管理 |

## 三、遇见：怎么匹配到一个人

1. 点底部「遇见」。
2. 系统按兴趣标签、在线状态这些条件给你推人，看中就发起聊天；不想等推荐也可以在搜索/筛选条件里自己设偏好再找人。
3. 匹配成功后直接进一对一聊天，文字、图片、表情包都能发。

两个配套机制：

- **假装情侣**：匹配成功后可以解锁虚拟情侣身份，本质是给陌生人聊天加一层关系设定与互动任务，随时可退，不影响你继续当普通好友聊。
- **附近小火人 / 同城**：在「遇见」里写一条「找搭子」喊话或打开定位，能刷到附近的人。定位权限被拒时这条用不了，其余匹配不受影响。

匹配完一直没人回、或压根匹配不出来，别在这一页死点 —— 原因和处理见 [匹配不到人怎么解决.md](匹配不到人怎么解决.md)。

## 四、派对：多人语音房间怎么进

1. 点底部「派对」，列表里全是用户自己开的主题房间（闲聊、开黑、话题局都有）。
2. 点房间卡片直接进房，进去就能听；要说话需要麦克风权限，点麦位上麦。
3. 房间里有互动小游戏，比如「桌球」（2026 年上半年的更新加进来的），在派对房内直接开一局，用来破冰比干聊自然。
4. 冷场时换个房间比硬聊快 —— 房间是按主题分的，进错了主题，人再多也聊不起来。

## 五、加好友、私聊与语音通话

- **主动找人**：聊天页右上角的好友按钮 → 加好友 → 按昵称搜索添加。
- **发语音/打电话**：进私聊，右下角就是通话按钮，可发起语音或视频通话；不想露脸可以用「蒙面语音」。
- **消息管理**：所有私聊都收在「信息栏」，未读、提醒都在这里汇总。

## 六、几个容易踩的点

- 匹配、私聊、发动态都要**先注册**，游客状态点这些入口会被要求先登录。
- 上麦、开摄像头、发语音前，先确认系统权限已给（权限清单见 [下载与安装教程.md](下载与安装教程.md) 第六节）。
- 匿名匹配时对方看不到你的真实资料，别因为在匿名状态里就放松警惕 —— 该不给的信息（住址、学校、单位）任何时候都别给。
- 遇到骚扰或不适内容，用聊天页与动态页的举报入口直接举报，配合拉黑使用；平台侧有「火花小卫士」做内容审核。

主页装修与发动态的玩法见 [动态广场与个性空间使用技巧.md](动态广场与个性空间使用技巧.md)；想让别人看不到你在线，见 [隐身访问与访客记录设置.md](隐身访问与访客记录设置.md)。
