## 一、火花Chat 是什么

火花Chat 是一款面向年轻用户（官方文案主打 00 后）的陌生人社交 App，包名 `com.huohua.android`，安卓端为主。你用手机号注册后，可以通过「遇见」匹配陌生人一对一聊天、进「派对」语音房间多人开聊、在「动态」广场发动态，也能开匿名匹配、假装情侣这些玩法。本篇只讲**拿到安装包并装上**这件事；装好之后怎么玩，见 [遇见匹配与派对房间玩法.md](遇见匹配与派对房间玩法.md)。

## 二、从哪里拿安装包

三条路，按省事程度排：

1. **官方下载页**：官网 [www.huohuahudong.com](https://www.huohuahudong.com/) 首页就有「iPhone 下载」「Android 下载」两个入口，扫码或点按即可；官方 H5 页面 [h5.iupvideo.net](http://h5.iupvideo.net) 也挂着同一个包的下载入口。
2. **应用商店**：腾讯应用宝搜索「火花Chat」，App Store 里对应的是「火花Chat - 擦出不一样的小火花」（iOS 版体积与安卓版不同，是两个包）。
3. **[火花Chat 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2fd1079d66a1)**：想先把包存到自己网盘、或应用商店里搜不到时，用这条分享链接转存即可，转存后在网盘里直接下载 APK。

三条路拿的都是同一个应用，区别只在更新快慢：应用商店通常跟得最快，官网次之。

## 三、网盘里那份包的具体信息

网盘里发出去的是**某个时间点存下来的那一版**，和你现在从应用商店下的最新版未必是同一个版本。装之前先对一眼：

| 项目 | 值 |
| --- | --- |
| 版本 | 3.6.9 |
| 包名 | `com.huohua.android` |
| 大小 | 145.69M |
| MD5 | `6683B4C24C0D4CA9C87B9F63ADF8ED76` |
| 记录时间 | 2026-09-21 |

- **版本号**：3.6.9 属于 3.6.x 系列；截至 2026 年 9 月下旬，应用宝等渠道显示的最新版已到 3.6.26（以官方页面当时显示为准）。想要最新功能，装完在 App 内更新，见第七节。
- **核对 MD5**（可选）：文件下完后用任意校验工具算一遍 MD5，与上表一致说明文件完整没损坏；不一致就重新下载一次。
- 装完想确认版本：进 App 的「我 → 设置」里看版本号，应显示 3.6.9。

## 四、安装步骤

1. 从上面任一渠道把 APK 下载到手机。
2. 若是浏览器或网盘下载的包，点开文件时系统会提示「禁止安装未知来源应用」——这是安卓对**非商店来源安装**的统一拦截，不是这个包有问题。按提示进入「设置 → 允许此来源」（不同品牌手机叫法略有差别，有的在「安装未知应用」里按来源 App 授权），再返回继续安装。
3. 安装完成后打开，按提示允许必要的权限（见第六节）。
4. 手机自带的「纯净模式」「安装保护」若弹出风险提示，确认是要装的包后再选择继续安装。

## 五、注册与登录

- **必须用手机号注册**：打开 App 后用本人手机号收验证码注册。按隐私政策的口径，注册时会收你的昵称、头像、手机号码、出生日期、性别；后几项里出生日期、性别属选填，填不填不影响账号可用。
- **不注册基本没法用**：按官方隐私政策的说明，未注册状态下不能发动态、评论、不能用火花卡、遇见匹配、加好友、私聊、音视频通话和蒙面语音 —— 也就是说整套社交功能都锁在账号后面。
- 手机号属于实名制要求的必要信息，不提供就用不了服务；出生日期建议如实填，部分内容会按年龄分发。

## 六、首次运行会要哪些权限

官方《应用权限说明》与隐私政策列的主要是这几项，都是围绕具体功能开的：

| 权限 | 官方写明的用途 | 拒绝后的实际后果 |
| --- | --- | --- |
| 相机 | 拍照、录制小视频、发布语音帖与语音评论、音视频通话 | 发不了带拍摄件的内容，纯文字聊天不受影响 |
| 录音/麦克风 | 语音私信、语音/视频通话、派对上麦、蒙面语音 | 能听不能说 |
| 相册/存储 | 下载视频、音频、图片等内容，传头像 | 站内内容存不下来，发图受限 |
| 位置 | 「附近」服务：附近的人、同城推荐 | 只是用不了附近这条匹配路径 |
| 悬浮窗（显示在其他应用上层） | 打电话时缩小成浮窗，边聊边切别的 App | 通话中无法缩小浮窗，通话本身不受影响 |
| 电话（设备信息） | 推送与账号安全相关 | 可能收不到消息通知 |

你可以先全拒再按需开，逐项对照上表按自己要用的功能给。后续想改，在系统「应用管理 → 火花Chat → 权限」里随时调整。

**系统要求**：各渠道标注不一（Android 5.0 或更高 / Android 4.0 以上），以官方下载页当时显示为准；实际安装时若包版本较新而手机系统过旧，安装器会直接拦下，升级系统或找旧版本包二选一。

## 七、怎么更新到最新版

- **App 内更新（推荐）**：进「我 → 设置」，找版本更新入口，有新版会直接提示下载。有用户在应用宝评论区反馈「更新不到最新版本」，另一位用户回复「在软件里面直接更新」—— 商店包与官网包的更新通道有时不同步，App 内自更新是最稳的路。
- **重新下载**：App 内没有更新入口时，回第二节的官方下载页或应用商店再下一个新包覆盖安装，聊天记录与账号数据保留。
- 更新前不需要手动备份；但如果你装的是网盘里 3.6.9 这种历史版本，更新完可以再看一眼版本号确认到位。
