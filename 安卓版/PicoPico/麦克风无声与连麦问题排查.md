## 一、先分清是哪一种「没声音」

| 表现 | 大概率原因 | 从哪节查 |
| --- | --- | --- |
| 你说话，别人听不见 | 麦克风权限没给 / 被房主禁麦 / 房间静音 | 第二节 |
| 你听不到别人 | 媒体音量太低 / 蓝牙耳机抢音轨 | 第二节、第三节 |
| 声音断断续续 | 网络不稳 / 后台占用带宽 | 第三节 |
| 匹配雷达半天推不出人 | 资料太空 / 时段不对 / 定位没给 | 第四节 |

## 二、麦克风没声音的排查清单

按顺序做，做完一步试一步：

1. **系统设置里查权限**：手机设置 → 应用管理 → PicoPico → 权限，确认麦克风是「允许」。第一次连麦时弹窗点了拒绝，后面全靠这里补开。
2. **关掉抢麦克风的设备**：关闭其他占用录音的应用（游戏语音、通话录音、直播软件），蓝牙耳机断开重连一次，确认声音走的是你想要的设备。
3. **房间内查音量条**：连麦界面看自己的音量条动不动；静音开关开着的先关掉。
4. **确认没被禁麦**：房主可以禁麦，被禁时你说话房间听不见，联系房主解除。
5. **重启应用**：以上都对还不行，杀掉应用重新进房。

「匿名来电」这类一对一语音玩法用的也是同一个麦克风权限，权限没给时对方一样听不见你，先做完第 1 步再进这些功能。

## 三、连麦卡顿、断断续续

- **切换网络对比**：WiFi 与流量互换着试，哪边稳用哪边；WiFi 慢就离路由器近一点。
- **让后台让路**：下载、投屏、视频应用在后台抢带宽，先停掉。
- **进人少的房**：人数爆满的房连麦容易卡，换一个同主题的房试试。

## 四、匹配雷达一直匹配不到人

1. 完善个人资料：声线介绍、兴趣标签越具体，权重越高；
2. 避开凌晨等低在线时段，晚间在线人数多、推得快；
3. 检查定位权限是否给了，想换城市就在应用内把定位改过去；
4. 把应用更新到最新版、清一次缓存再重试。

以上都做了还是推不动，大概率是账号资料过于空白（没头像、没语音介绍、没标签），先把基础资料补齐再等推送。匹配入口与玩法的整体说明见 [匹配与CP玩法说明.md](匹配与CP玩法说明.md)；嫌一对一等得慢，也可以直接进语音房，见 [语音房与家族怎么玩.md](语音房与家族怎么玩.md)。
