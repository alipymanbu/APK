## 一、匹配入口有哪几种

| 入口 | 形式 | 适合 |
| --- | --- | --- |
| 匹配雷达 | 系统持续推人，可直接语音连麦 | 想被动等匹配、聊天秒回的人 |
| 甜蜜合拍（部分版本叫心跳合拍） | 异步语音问答，像两人隔空合拍对话 | 不好意思先开口、想先听声音再聊的人 |
| 恋人留声机 | 听陌生人提前留下的语音留言 | 声控，想慢慢挑 |
| 扩列闪聊 | 15 分钟限时车厢，系统主持破冰活动 | 想一次认识多个人 |
| 立即闪聊（部分版本有） | 一键随机匹配一个人开聊 | 不想等推荐、想马上有人说话 |
| 匿名来电（部分版本有） | 与匹配对象匿名语音对话 | 不想露身份先听听声音 |

不同版本的入口名称与位置会有出入，找到哪个用哪个，玩法本质不变。

## 二、匹配雷达怎么用好

1. **允许定位**：想匹配同城，第一次打开应用时允许 GPS 定位权限；给了定位才会出现同城板块，找不到入口就先检查权限。
2. **把筛选调好**：雷达入口旁的漏斗图标里有三组条件——对方性别、年龄偏好、距离（优先同城/都可以），具体选项见 [资料编辑与匹配筛选怎么设置.md](资料编辑与匹配筛选怎么设置.md)。
3. **把资料填满**：声线介绍、兴趣标签写得越具体，匹配权重越高；头像、昵称这些资料的改法也在上面那篇里。
4. **挑时段**：凌晨等低在线时段本来就推得慢，白天和晚间在线人多。
5. **连麦前先试声**：雷达推来的人可以直接发起语音连麦；连麦没声音先看 [麦克风无声与连麦问题排查.md](麦克风无声与连麦问题排查.md)，别急着下结论是对方的问题。

## 三、CP 怎么结、怎么解

CP 是比朋友近一档的关系玩法，官方分过甜甜恋爱、亲亲群聊、兄妹互宠、暖心陪伴等模式；另一批版本的介绍里又写成心动、一周、夜晚、奔现、周末、游戏 CP。同一个玩法，叫法随版本换，以你界面上的为准。**结成方式：向对方赠送指定的 CP 礼物即可绑定**，绑定后解锁双人专属页面与情侣打卡任务。CP 关系有短期限时和长期契约两种，解除在 CP 页面内操作，具体规则以应用内提示为准。

送 CP 礼物要消耗虚拟货币，货币种类与充值注意见 [充值礼物与常见问题.md](充值礼物与常见问题.md)。

## 四、匹配之后不合适怎么办

- 不想再被某个人打扰：聊天页或资料页找拉黑入口，拉黑后对方无法再向你发起互动；
- 遇到诱导转账、发广告、言语骚扰：直接举报，不用对线；
- 匹配来的都是陌生人，涉及金钱、线下见面的要求一律先存疑，底线清单见 [充值礼物与常见问题.md](充值礼物与常见问题.md) 的账号安全一节。

想在房间里认识人，比一对一匹配氛围更松，玩法见 [语音房与家族怎么玩.md](语音房与家族怎么玩.md)。
