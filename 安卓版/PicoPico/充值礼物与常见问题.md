## 一、虚拟货币与礼物

PicoPico 的虚拟经济围绕两类东西：**充值货币**（买礼物、开匹配特权、创建家族都要消耗）与**礼物**（语音房与 CP 玩法里的互动道具）。不同版本对货币的叫法可能不同（如钻石、月亮币等，具体面值与兑换规则以应用内说明为准），入口在个人中心的钱包或充值页。

**充值只走应用内官方渠道**：App 内的支付按钮走的是应用商店或官方收银台。**不要找第三方代充**——低价代充常见两种坑：扣款后不到账，或用异常渠道充值导致账号被处理。

官方对外的固定渠道还有微信公众号「PicoPico的快乐爱星球」——官方介绍里写明它承担资讯展示与售后职能，应用内客服没响应时可以换这里问。

## 二、礼物花在哪

| 场景 | 花法 |
| --- | --- |
| 语音房互动 | 给上麦的人送礼物 |
| 结 CP | 送指定的 CP 礼物绑定关系 |
| 家族 | 创建家族、家族活动消耗 |
| 匹配特权 | 部分匹配玩法有付费加成 |

先小额试一次，确认到账、效果符合预期再考虑后续。iOS 走 App Store 内购，安卓走各商店支付渠道，两边的账单是分开的。

## 四、账号安全提醒

语音社交平台陌生人多，这几条是通用底线：

1. **不转账**：任何以「处 CP」「见面」「纪念」为名要钱、要红包的都当骗子处理；
2. **不给验证码**：对方说「帮我收个码」一律拒绝——验证码等于账号钥匙；
3. **不点陌生链接**：语音或私信里发的网址、二维码不点不扫；
4. **会用举报和拉黑**：聊天页与资料页都有入口，遇到骚扰直接处理。

充值没到账、误充这类消费纠纷，走应用内在线客服要答复，别信第三方「帮你退款」的人。
