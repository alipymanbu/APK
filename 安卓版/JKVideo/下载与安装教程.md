## 一、先确认你要装的是哪个版本

JKVideo 是一个开源的第三方 B 站客户端，源码公开在 GitHub（[github.com/tiajinsha/JKVideo](https://github.com/tiajinsha/JKVideo)，此处仅作来源说明）。你手边这份安装包的信息如下，装之前可以对着核对：

| 项目 | 信息 |
| --- | --- |
| 版本号 | 1.0.19（项目的最终版本，官方已宣布停止维护） |
| 安装包大小 | 97.42 MB |
| 包名 | com.anonymous.jkvideo |
| MD5 | 57B00DF3C6731CAA5407A179317773CF |
| 系统要求 | Android 5.2 及以上（按安装包登记口径） |

三点说明：

- **不会再有新版本**：项目方已在 2026 年宣布停止维护，1.0.19 就是最后一版。网上如果出现更高的版本号，出处与安全性都无从核实，不建议安装。
- **别拿网上资料对版本**：搜索结果里常见的 1.0.6、1.0.15 等都是更早的版本，功能与这份有出入。核对版本以你手里这份安装包为准。
- **与官方 B 站客户端互不干扰**：两者包名不同，可以同时装在同一部手机上，登录与数据各自独立。

## 二、安装步骤（安卓手机）

整个过程不需要电脑，手机上直接完成：

1. 先从上面的 **JKVideo 安装文件资源（夸克网盘）** 把安装包转存到自己网盘，再下载到手机存储里；文件名形如 `JKVideo_v1.0.19.apk`，约 97 MB，下载前确认存储空间够用。
2. 在文件管理器里点开这个 APK，系统会提示「禁止安装未知来源应用」，点提示里的「设置」进入对应开关页，允许来自该来源的安装后返回继续。
3. 等安装完成，点「打开」直接进入应用；主界面不登录也能看，想用关注、收藏等功能先扫码登录，步骤见 [扫码登录与账号数据同步.md](扫码登录与账号数据同步.md)。

不同品牌手机「未知来源」开关的位置略有差异：多数在 设置 → 应用管理 → 特殊应用权限 → 安装未知应用 下，按刚才弹窗里指到的那个应用（通常是文件管理器或浏览器）去开，而不是全局开关。

## 三、装不上或提示风险，按这几种情况处理

| 现象 | 处理 |
| --- | --- |
| 点安装没反应 | 确认 APK 已完整下载（97 MB 左右，文件明显偏小说明没下完，重新下载） |
| 提示「解析包出现问题」 | 安装包损坏或下载不完整，删除后重新下载一次 |
| 手机自带安全软件拦截 | 这类客户端不在应用商店上架，被拦属常见现象；确认来源可信后选择「仍要安装」，介意的话可以先核对 MD5 再装 |
| 提示系统版本过低 | 说明手机系统低于安装包要求，见下方第四节 |
| 覆盖安装失败（手机里已有旧版） | 先卸载旧版本再装；注意卸载会清掉应用内的登录状态与下载记录，收藏等云端数据不受影响 |
| 安装成功但点开就闪退 | 多与系统版本或权限设置有关，逐项排查见 [常见问题与故障排查.md](常见问题与故障排查.md) 第一节 |

安装时被安全软件报「未知应用」与报「病毒」是两回事：前者是所有非商店安装包都会遇到的正常提示，允许即可；后者如果出现，建议先核对上面表格里的 MD5 值，对不上就不要装。

## 四、系统与空间要求

- **系统版本**：按安装包登记口径，需要 Android 5.2 及以上；实际能否流畅运行还与机型性能有关，太老的机型可能加载偏慢。
- **存储空间**：安装包约 97 MB，安装后占用还会更大，另外下载视频也要占空间，建议至少预留 1 GB。
- **网络**：首次打开会加载首页内容与图片，建议在 Wi-Fi 环境下完成第一次启动。

装好之后，画质与清晰度的选择规则见 [画质清晰度与弹幕设置.md](画质清晰度与弹幕设置.md)，遇到打不开、闪退等情况直接翻 [常见问题与故障排查.md](常见问题与故障排查.md)。
