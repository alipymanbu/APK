# JKVideo 扫码登录与账号数据同步

## 一、什么时候需要登录

不登录也能用 JKVideo 看推荐、热门、直播和搜索，这部分不需要任何账号。但下面这些内容依赖你的 B 站账号，登录后才会出现：

- 自己的关注列表和 UP 主动态
- 收藏夹
- 观看历史与断点续播
- 点赞、评论等互动操作

也就是说，如果你只是偶尔搜个视频看，可以一直不登录；想把它当常用客户端用，第一步就是扫码登录。

## 二、扫码登录步骤

登录用的是「手机上扫码」这一种方式，全程约半分钟：

1. 打开 JKVideo，点击主界面左上角的头像（或小人）图标，进入登录页，屏幕上会出现一个二维码。
2. 在同一部手机上打开 B 站官方客户端，进入「扫一扫」（我的页面右上角）。
3. 用 B 站客户端扫描 JKVideo 里的二维码，在手机上确认登录。
4. 返回 JKVideo，页面会自动刷新为已登录状态，左上角头像变成你的账号头像。

**同一部手机怎么扫自己的码**：二维码页面通常支持长按识别或「在本机打开」之类的入口，如果都没有，可以先用另一台设备扫码，或把二维码截图后用 B 站客户端的相册识码功能识别。

## 三、二维码过期了怎么办

登录二维码的有效期很短，超时后页面不会自动换新码，表现为扫了没反应或提示失效。处理方法：

- 关闭登录页，重新点左上角头像进入，会生成新的二维码；
- 扫码前先把二维码页面停在屏幕上，再去开 B 站客户端，动作快一点基本不会过期；
- 如果反复提示过期，核对手机系统时间是否准确（开启「自动获取网络时间」），再切换 Wi-Fi / 流量重试。

各种登录失败现象的完整排查表在 [扫码登录失败排查.md](扫码登录失败排查.md)。

## 四、登录后哪些数据会同步

登录后，JKVideo 读取的是你 B 站账号的云端数据，两边是同一份：

| 数据 | 登录后的表现 |
| --- | --- |
| 关注列表 | 「我的关注」与你 B 站账号一致，在官方端取关后这边同步消失 |
| 收藏夹 | 收藏的视频与默认收藏夹、自建收藏夹都会读过来 |
| 观看历史 | 与官方客户端共享同一份历史记录，支持断点续播 |
| 点赞/互动记录 | 点赞过的视频、发过的评论同步显示 |

注意两点：同步是「读云端」，不是双份存储，删除收藏这类操作会直接作用于你的 B 站账号；会员相关权益跟着账号走，你账号本身有大会员，这边也能选对应的最高画质，具体见 [画质清晰度与弹幕设置.md](画质清晰度与弹幕设置.md)。

## 五、退出登录与切换账号

进入应用内的设置页，最底部有退出登录入口；退出后回到未登录状态，重新登录按第二节流程再扫一次码即可。多账号轮换就是「退出 → 再扫」这个循环，没有账号数量限制。

登录环节卡住（二维码一直转、确认后不刷新头像）属于常见故障，处理步骤统一整理在 [常见问题与故障排查.md](常见问题与故障排查.md) 的登录一节。
