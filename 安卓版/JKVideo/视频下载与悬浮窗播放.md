## 一、怎么下载视频

下载入口在视频播放页，步骤三步：

1. 进入目标视频的播放页，点右上角的下载（向下箭头）图标。
2. 弹出清晰度选择框，档位与在线播放一致（360P 到 4K），点选想要的画质后确认，任务进入后台下载。
3. 回到主界面的「下载」管理页，能实时看到已下载与正在下载的列表。

画质选择的规则与在线播放相同：1080P+、4K 这些高码率档位需要登录大会员账号才能选，普通账号最高下到 1080P，详见 [画质清晰度与弹幕设置.md](画质清晰度与弹幕设置.md)。

几点实用提示：

- 下载任务在后台进行，切出去刷别的视频不影响进度；
- 建议在 Wi-Fi 环境批量下载，高画质视频一个就可能几百 MB；
- 下载完成的视频在应用内随时离线播放，不消耗流量。

## 二、下载管理页能做什么

「下载」页面集中管理所有本地视频：

| 操作 | 位置与效果 |
| --- | --- |
| 播放 | 点列表中的条目直接离线播放，不需要网络 |
| 删除 | 删除后释放对应空间，云端收藏不受影响（下载与收藏是两套数据） |
| 查看进度 | 正在下载的条目显示进度与清晰度，可取消单个任务 |
| 局域网分享 | 下载页支持生成局域网二维码，同一 Wi-Fi 下的其他设备扫码即可播放已下载的视频 |

局域网分享这一条适合「手机下好了、想在平板或电脑上看」的场景：两台设备连同一个 Wi-Fi，在下载页打开分享二维码，用另一台设备扫码就能直接播放，不需要传文件。

## 三、悬浮小窗与后台播放

JKVideo 带全局悬浮迷你播放器，这是它和官方客户端在使用体验上差异最大的功能之一：

- **视频页切走不中断**：播放中按返回或切换到应用其他页面，视频会缩成底部悬浮小窗继续播，你可以同时刷推荐、搜视频、看动态；
- **小窗操作**：悬浮窗可以拖动位置、点击展开回播放页、关闭即停止播放；
- **边看边干别的**：小窗悬浮在应用界面之上，回微信、查资料时视频照常播，适合听讲解类、访谈类内容；
- **后台播放**：切出应用后支持继续播放；如果切出去就停了，多半是系统限制了后台活动，在电池/自启动管理里允许 JKVideo 后台运行即可。

如果小窗功能没生效，先检查系统是否给 JKVideo 授予了「显示悬浮窗 / 在其他应用上层显示」权限（设置 → 应用管理 → JKVideo → 显示在其他应用上层），国产系统默认关这个权限的现象很常见。

下载了视频却播放失败、或者小窗黑屏只有声音，多与解码和权限有关，对应处理步骤见 [常见问题与故障排查.md](常见问题与故障排查.md)。
