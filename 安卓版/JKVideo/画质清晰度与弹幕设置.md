## 一、播放页里有哪些画质可选

点开任意视频进入播放页，点播放器右上角（部分机型在右下角）的画质按钮，会弹出清晰度列表。可选档位与 B 站官方客户端一致：

| 档位 | 说明 |
| --- | --- |
| 360P / 480P | 流畅档，流量或弱网环境够用 |
| 720P | 日常观看的主流选择 |
| 1080P | 需登录 B 站账号 |
| 1080P+（高码率） | 需登录**大会员**账号 |
| 4K | 需登录**大会员**账号 |

几个实用判断：

- **没登录时**画质普遍锁在低档位，先完成扫码登录再谈画质，步骤见 [扫码登录与账号数据同步.md](扫码登录与账号数据同步.md)。
- **1080P 与 1080P+ 是两回事**：前者普通账号就有，后者是高码率版本，只有大会员账号能选。
- **4K 内容本身要满足两个条件**：你登录的是大会员账号，且这个视频的 UP 主上传了 4K 片源。两个条件缺一个，列表里都不会出现 4K 项。
- 高画质档位对网络要求高，Wi-Fi 下选 1080P 及以上，流量环境建议 720P 以下，避免频繁缓冲。

## 二、弹幕的开关与样式

播放页与 B 站一样支持完整弹幕，控制项都在播放器工具条上：

- **开/关弹幕**：播放器下方的弹幕开关，关掉后画面干净，再点一次恢复。
- **显示密度**：觉得弹幕太密挡画面时，把密度调低，同屏条数会减少。
- **弹幕样式**：样式与显示密度都可在弹幕设置里调整，具体可调项以应用内设置页为准，按个人习惯设一次即可。
- **发弹幕**：登录后点弹幕输入框即可发送，不登录只能看不能发。

直播间的弹幕是实时滚动的独立通道，进入直播页后在下方输入区发送，同样需要登录。

## 三、倍速、横竖屏与播放中的常用操作

- **倍速**：播放器设置里可选 0.5x 到 2.0x。
- **横竖屏**：点全屏按钮或旋转手机切换横屏，横屏下弹幕与控制条布局自动重排。
- **进度拖动**：拖动进度条即可跳转；看了一半的视频接着上次位置继续播（断点续播需要登录）。
- **迷你播放**：切到别的页面或应用时，视频可以缩成悬浮小窗继续播，具体玩法见 [视频下载与悬浮窗播放.md](视频下载与悬浮窗播放.md)。

## 四、画质相关的小问题

**画质列表里明明登录了却选不了 1080P+**：先确认账号本身是不是大会员，普通账号在任何客户端都选不了这个档位；确认是会员还选不了，退出重新扫码登录一次刷新账号信息。

**选了高画质一直转圈**：多数是网络带宽跟不上，把画质降一档立刻能播；如果低画质也卡，问题在网络而不在设置，处理思路见 [常见问题与故障排查.md](常见问题与故障排查.md)。

**下载视频时怎么选清晰度**：下载与在线播放的画质档位是同一套，会员账号才能下高码率版本，操作细节在 [视频下载与悬浮窗播放.md](视频下载与悬浮窗播放.md)。
