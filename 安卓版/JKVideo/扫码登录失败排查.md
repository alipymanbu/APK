## 一、先排除环境问题（一分钟）

登录失败的多数原因在环境而不是账号，按顺序过一遍，每步做完直接重试扫码：

1. **核对手机系统时间**：时间不准会导致登录凭证校验异常，到设置里开启「自动获取网络时间」后重试。
2. **关闭代理与加速器**：VPN、加速器类工具会改变网络请求的路径，先全部关掉；条件允许的话把路由器也重启一次。
3. **换网络**：Wi-Fi 与流量互切一次，排除当前网络环境对访问的限制。
4. **强制停止后重开**：设置 → 应用管理 → JKVideo → 强制停止，再打开重新进登录页。

## 二、按现象对号入座

| 现象 | 处理 |
| --- | --- |
| 二维码一直不出现 | 多为网络不通，按第一节换网络后重进登录页 |
| 二维码出现但很快过期 | 有效期本来就短，进登录页后尽快扫；反复如此则核对系统时间 |
| 扫码确认后没反应 | 杀掉应用重开，重新走一遍扫码流程 |
| 登录成功但头像、收藏不刷新 | 退出登录重新扫码；仍不行就清缓存（设置 → 应用管理 → JKVideo → 存储 → 清除缓存，不要点清除数据） |
| 隔几天就要重新登录 | 见下一节 |

登录的正常流程与登录后哪些数据会同步，见 [扫码登录与账号数据同步.md](扫码登录与账号数据同步.md)，此处不再重复步骤。

## 三、反复掉登录是怎么回事

已登录后隔几天就要求重新登录，通常不是你操作错了：

- **登录凭证本身有有效期**，到期需要重新扫码，这一点所有客户端都一样；
- JKVideo 已停止维护（背景见 [常见问题与故障排查.md](常见问题与故障排查.md) 第五节），它对接的 B 站接口如果发生调整，登录功能可能受影响。同类第三方 B 站工具在接口调整后出现过二维码无法登录的先例（有用户反馈），这类问题只能靠兼容修复解决——而本项目不会再发新版本，能做的只有重新扫码、清缓存后重试，或者这段时间改用官方客户端。

如果掉登录的同时收到「账号在其他设备登录」之类的提示，先确认账号密码没有外泄；不放心可在 B 站官方客户端修改密码，修改后所有已登录设备会被强制下线，重新扫码登录即可。

## 四、关于账号安全的两个习惯

扫码登录的设计是把「确认权」留在你自己的 B 站官方客户端里：JKVideo 只负责展示二维码，你在官方端确认，全程不需要把账号密码输入给第三方应用。配合两个习惯更稳妥：

- 只在自己的设备上完成扫码确认，任何要求你「输入账号密码登录」的第三方页面都不要理会；
- 长期不用 JKVideo 时，在它的设置页退出登录，或直接卸载应用。
