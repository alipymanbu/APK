## 一、应用打不开、闪退

按从轻到重的顺序排查，多数情况在前三步内解决：

1. **重启手机**：临时性进程冲突导致的闪退，重启后大多消失。
2. **强制停止后再打开**：设置 → 应用管理 → JKVideo → 强制停止，然后重新打开；比重启手机更快的排除手段。
3. **清缓存**：同一页面点 存储 → 清除缓存（先试「清除缓存」，不要直接点「清除数据」，后者会清掉登录状态和下载记录）。
4. **查应用权限**：部分系统在存储等权限被禁用时会直接闪退，到 JKVideo 的应用权限页把存储权限打开。
5. **重装应用**：卸载后用安装包重新安装一遍；重装会丢登录状态与本地下载，收藏等云端数据不受影响。
6. **查系统版本**：安装包要求 Android 5.2 及以上，系统太老会直接闪退，只能升级系统或换设备。
7. **查存储空间**：可用空间建议保持在总容量的 20% 左右，长期贴着上限用容易异常，清理后再试。

如果只有播放 4K 或高码率视频时才闪退，把画质降到 1080P 以下再试（见 [画质清晰度与弹幕设置.md](画质清晰度与弹幕设置.md)），弱机型解码高码率流吃力是常见诱因。

## 二、扫码登录的问题

| 现象 | 原因与处理 |
| --- | --- |
| 扫码后没反应 | 二维码过期（有效期很短），关闭登录页重新进入生成新码再扫 |
| 提示登录失效 | 网络波动导致确认结果没传回来，切 Wi-Fi / 流量后重新扫码 |
| 扫了确认了但头像没变 | 杀掉应用重新打开，再登录一次即可 |
| 想换账号 | 设置页退出登录，再按扫码流程登录新账号 |
| 二维码打不开、反复掉登录、怀疑账号安全 | 逐项排查见 [扫码登录失败排查.md](扫码登录失败排查.md) |

扫码登录的完整步骤与本机自扫的技巧在 [扫码登录与账号数据同步.md](扫码登录与账号数据同步.md)。

## 三、视频加载慢、转圈不播

- **先降画质**：4K / 1080P+ 对带宽要求高，降到 720P 以下能立刻判断是网络问题还是应用问题；
- **换网络**：Wi-Fi 与流量互切一次，路由器重启也值得试；
- **直播打不开**：直播走的是 HLS 流，个别直播间源不稳定属正常现象，换一个直播间对比就知道是个例还是普遍问题；
- **首页图片加载不全**：首次启动要拉取大量封面图，慢一点正常，等一次加载完后面会快。

## 四、画质灰着选不了 / 下载任务失败

- 1080P+ 与 4K 灰色不可选：这两档需要**大会员账号**，普通账号登录了也选不了，与客户端无关；
- 下载一直 0%：检查存储空间与网络，取消任务重新添加；高画质任务在弱网下容易卡住，降档重下更快；
- 下载完成的视频不见了：确认没点过「清除数据」或卸载重装，本地下载没有云端备份，删了就没了。

## 五、为什么一直停在 1.0.19，没有更新

JKVideo 的项目方已在 2026 年公开宣布停止维护，**1.0.19 就是最终版本**，之后不会再有功能更新与问题修复。这个背景下有两点值得知道：

- 已安装的版本仍然可以正常使用，登录、观看、下载等功能不依赖项目方维护；
- 遇到上面这些小毛病，不会有修复版发布，只能靠本文的通用手段（清缓存、降画质、重装）绕过，部分问题可能长期存在。

网上若出现「2.x」「最新修复版」等说法，均非官方发布，不要安装。

## 六、它和 B 站官方客户端是什么关系

JKVideo 是开源社区做的第三方客户端，数据与官方账号互通（登录后同步关注、收藏、历史，见 [扫码登录与账号数据同步.md](扫码登录与账号数据同步.md)），界面比官方精简，没有商城、会员购等模块。会员权益、账号安全等一切账号层面的规则都以 B 站官方为准。
