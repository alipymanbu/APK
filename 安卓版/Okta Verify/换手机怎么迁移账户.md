# Okta Verify 换手机怎么迁移账户

> 换了新手机，旧的 Okta Verify 账户怎么办？本篇按你的实际情况分三种情形：旧机还在、旧机没了但有别的验证方式、什么都没了。先对号入座再动手。

## 一、先对号入座：三种情形

| 你的情况 | 能做什么 |
| --- | --- |
| 旧手机还在手边 | 蓝牙导出导入（见第二节），不用麻烦 IT |
| 旧机没了，但有别的验证方式（短信、安全钥匙，或另一台设备上的 Okta Verify） | 自己从仪表盘重新注册（见第三节） |
| 旧机没了，也没有任何其他验证方式 | 只能联系公司/学校帮助台重置，无法自助（官方 FAQ 明确口径） |

## 二、旧机还在：蓝牙导出导入

先明确一件事：Okta Verify 的账户**不走云备份**——换手机后没有「从 Google 账号恢复」这条路，密钥绑定在设备上，官方给的迁移路径只有两条：蓝牙导出导入（本节）和重新注册（第三、四节）。

这个流程把账户从旧手机直接「搬」到新手机，全程不用登录组织后台。

**条件先核对**（官方要求）：

- 账户已启用 Okta FastPass；
- 新手机已设置锁屏或生物识别；
- 两台手机的蓝牙都已打开；
- 旧机应用里这个账户没有报错或警告；
- 旧机是 Android 11 或更老系统时，要在系统设置里打开定位——官方说明 Okta 不收集位置信息，这是 Android 蓝牙权限的要求。

**操作步骤**：

1. 旧手机：打开 Okta Verify → 点账户 → Account details → Export account，允许蓝牙导出。应用生成一个二维码和一个 8 位字母数字码。
2. 新手机：装好 Okta Verify（安装包可从这份 **Okta Verify 安装文件资源（夸克网盘）** 获取：[https://pan.quark.cn/s/41fd41120bd2](https://pan.quark.cn/s/41fd41120bd2)）→ 打开点 Import account → 允许蓝牙 → 扫旧机屏幕上的二维码；扫不了就点 Enter Code Manually，手动输入那 8 位码。较新的版本（官方 8.26.0 起的版本说明）还允许用系统自带的相机应用来扫，不必非在 Okta Verify 应用里扫，以你手机上应用的实际界面为准。
3. 新手机上出现一个 6 位 PIN，把它输进旧手机里，确认配对的确实是这两台设备。官方特别提醒：**不要输入别人发给你的 PIN**——这串数字只该出现在你自己的两台设备之间。
4. 按提示完成设置，新手机就能正常验证了。

出处：[官方蓝牙导入导出教程（Android）](https://help.okta.com/eu/en-us/content/topics/end-user/ov-andr-add-acc-bluetooth.htm)。

## 三、旧机没了但有别的验证方式：仪表盘重新注册

1. 在任意浏览器打开组织的登录地址，用账号密码登录，选短信、安全钥匙等其他验证方式通过验证。
2. 进 End-User Dashboard（应用面板）后，点右上角你的名字 → Settings。
3. 找到 Security Methods（或旧版界面的 Extra Verification），把旧手机上那条 Okta Verify 记录 Remove 掉。
4. 再点 Okta Verify 的 Set up，电脑屏幕出现新二维码，用新手机按[添加账户与扫码注册.md](添加账户与扫码注册.md)第三节的扫码流程走一遍。

## 四、什么都没了：只能走帮助台

官方 FAQ 的口径很明确：旧机没了、没有另一台设备上的 Okta Verify、也没有短信或安全钥匙等其他验证方式时，你**无法**自己重装恢复，联系公司帮助台由管理员重置。重置之后你会收到新的注册邀请邮件，再从头走一遍添加账户流程。

恢复访问之后顺手做一件事：把短信验证码或安全钥匙这类备用验证方式补上，下次换机不至于再次卡死。
