# Okta Verify 添加账户与扫码注册

> 装好应用只是第一步，账户没添加进去什么都验证不了。本篇讲把账户添加进 Okta Verify 的几种方式：扫码（最常见）、邮件/短信激活链接、密钥手动录入，以及注册时绕不开的锁屏确认。

## 一、开始前先备齐三样东西

1. **组织登录地址**（sign-in URL）：形如 `https://你的组织名.okta.com`，一般在 IT 发给你的欢迎邮件里，找不到就问公司/学校帮助台。
2. **账号密码**：通常就是你的工作邮箱和密码。
3. **一台电脑**：最常见的注册方式是在电脑浏览器里发起、再用手机扫码，两台设备一起操作。

## 二、选对账户类型

应用里点加号（+）添加账户时，会让你先选类型：

| 类型 | 什么时候选 |
| --- | --- |
| Organization | 公司、学校或机构发的 Okta 账户（绝大多数人是这种） |
| Other | 给 GitHub、Google、Facebook 这类网站的二步验证当验证器 |

两条路的后续操作完全不同：Organization 走组织注册流程（扫组织给的二维码或激活链接），Other 走普通验证器流程（扫网站自己给的设置二维码，和你用过其他验证器应用一样）。

## 三、扫码注册（默认流程）

以最常见的「电脑发起、手机扫码」为例：

1. 电脑浏览器打开组织登录地址，输入账号密码登录。
2. 登录过程中出现「Set up security authenticators / 设置安全验证方式」页面时点 Set up，电脑屏幕上出现二维码。
3. 手机打开 Okta Verify，点添加账户（+）→ 选 Organization。
4. 应用提示「从另一台设备添加账户」时，没有特殊需要就选跳过（Skip）。
5. 点 Yes, ready to scan，对准电脑屏幕上的二维码。
6. 应用提示 Account Added 即注册完成，回到电脑页面点 Next 确认。

二维码只在注册这一次用；账户日后被重置的话，要重新扫一个新码。

## 四、扫不了码的三条替代路

二维码扫不出来时，在电脑页面二维码下方点 Can't scan?，有三条路（具体开哪几条取决于组织的配置）：

1. **邮件激活链接**：让系统把激活链接发到你收欢迎邮件的那个邮箱，手机邮件里点 Activate Okta Verify Push，应用被拉起并完成激活。
2. **短信激活链接**：填自己的手机号，在短信里点注册链接。
3. **密钥手动录入**（Set up manually without push notification）：电脑上会显示一串密钥（Secret Key），手机上选 Enter key manually，把账户名和密钥填进去。

第三条路有个代价要知道：手动录入的账户**之后只能用六位码验证，收不到推送通知**。密钥要在当时抄下来或截图保存，那个页面关掉就找不回来了。

出处：以上步骤与限制取自官方帮助文档[「用激活链接或密钥设置 Okta Verify（Android）」](https://help.okta.com/eu/en-us/content/topics/end-user/ov-new-setup-no-qr-android.htm)。

## 五、锁屏与生物识别确认

注册过程中应用很可能要求你开启屏幕锁定（Screen lock confirmation）或生物识别（指纹/面容），这不是多余的弹窗，背后是组织策略：

- 管理员可以把确认档位设为三档：Preferred（建议开）、Required（必须开）、Required with biometrics only（必须生物识别）。
- 设成 Required 时，不开锁屏就走不完注册流程，应用会直接引导你去系统设置里先补上。
- 设成 biometrics only 时，没有指纹/面容硬件的设备会提示设备不受支持，注册不了。
- 已注册的用户后来关掉锁屏的话，账户详情页会出现修复提示，且在应用内关不掉这个确认。

如果你的设备卡在这一步，让管理员核对策略档位；其他登录问题见[常见问题与故障排除.md](常见问题与故障排除.md)。

出处：三档确认对应的用户体验差异见[官方说明](https://help.okta.com/oie/en-us/Content/Topics/identity-engine/authenticators/ov-user-verification-exp.htm)。
