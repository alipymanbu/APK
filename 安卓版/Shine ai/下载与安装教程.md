## 一、装之前先确认三件事

| 检查项 | 说明 |
| --- | --- |
| 手机系统 | 这是安卓版应用，需要一台安卓手机；官方页面未标明最低安卓版本，以官网说明为准 |
| 存储空间 | 本文对应的安装包约 180.07 MB，加上安装后的占用与后续聊天数据，建议预留 2 GB 以上空闲空间 |
| 安装权限 | 安装包不来自应用商店，手机会要求「允许从此来源安装应用」，装完可以把该权限关掉 |

Shine AI 是一款 AI 虚拟角色互动应用，整体模拟一台智能手机的形态，短信、来电、社交圈这类日常功能都在应用里还原了一遍。第一次打开后的注册步骤单独写在 [注册登录指引.md](注册登录指引.md)。

## 二、拿到安装包

上面的夸克网盘链接就是 **Shine ai 安装文件资源** 的入口。网盘分享无法直接下载到手机安装的场合，常规做法是：

1. 打开网盘链接，先把文件**转存到自己的网盘**；
2. 在手机上装夸克网盘客户端并登录同一账号；
3. 在客户端里找到刚转存的 `Shine ai_v1.2.4.apk`，点下载；
4. 下载完成后直接点「打开」进入安装，或到手机通知栏/下载列表里点这条记录。

也可以在电脑上转存后用数据线把 apk 拷到手机，效果相同。

## 三、安装步骤

1. 在手机文件管理器里找到下载好的 apk 文件（文件名类似 `Shine ai_v1.2.4.apk`）；
2. 点按安装，系统弹出「未知来源」提示时，选择允许该来源安装；
3. 等进度走完，点「打开」或回桌面点图标启动；
4. 第一次启动会请求网络、存储等权限，按需允许，随后进入邮箱注册页。

装完先去系统设置的权限管理里确认两项：**网络访问**与**文件存储**。有用户教程提到，安卓 11 及以上系统还需要允许「所有文件访问权限」，否则可能无法保存聊天存档、读取历史对话记录。

注册环节（邮箱、验证码、邀请码）在 [注册登录指引.md](注册登录指引.md) 里有逐步说明；注册完成后直接看 [新手入门指南.md](新手入门指南.md) 就能发出第一句话。

## 四、核对安装包

如果你拿到的那份安装包对不上号，多半是版本不同。本文对应版本的指纹如下：

| 项目 | 值 |
| --- | --- |
| 应用名 | Shine AI |
| 版本 | 1.2.4 |
| 安装包大小 | 180.07 MB |
| 包名 | `com.xinghe.shine` |
| MD5 | `A2B63A6A1450D3845AFC35A06B708BC1` |

版本号、包名与体积以本地这份安装包为准；官网此后发布的更新版本会更大、编号更高，属正常现象。按公开的更新日志，1.2.4 是一个补丁版本，主要修复语音不播放的问题；它前面的 1.2.3 是一次内容大更新（新增限时剧情玩法、购物体验等），以官方更新说明为准。

## 五、装不上时的排查

按出现频率从高到低：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「解析包出错」 | 文件没下完整，或手机安卓版本过低 | 先删掉半截文件重新下载；反复出现则确认手机系统版本是否过旧 |
| 提示「已存在同名应用」/ 安装被覆盖失败 | 手机里已经装过别处来的旧版本 | 先卸载旧版再装；卸载会连带清掉本地聊天记录，介意的话先想清楚 |
| 进度条走一半失败 | 存储空间不足 | 清理空间后重装 |
| 安装按钮灰着不动 | 浏览器/文件管理器没拿到「安装应用」权限 | 去系统设置里给对应工具授「安装未知应用」权限 |

装好并注册完成后，如果对话、领取奖励这些环节遇到问题，翻 [常见问题解答.md](常见问题解答.md)。
