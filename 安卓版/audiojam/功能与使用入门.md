## 一、它是给谁用的

Audio Jam 是广州市奇乐库科技有限公司开发的音乐练习工具，你把自己的歌曲或课件音频导进去，它帮你把一首混好的歌拆成几条乐器轨，再配合降速、循环、变调这些手段，让你跟着练乐器或扒谱。典型使用者是学吉他、贝斯、鼓、键盘的人，以及想把自己唱的 key 调到舒服位置的翻唱练习者。

除了安卓，它还有 Windows、macOS、iOS 版和网页版，多个设备之间靠云同步接续练习。

## 二、核心功能一览

| 功能 | 你能拿它做什么 |
| --- | --- |
| AudioAI 分轨 | 把任意一首歌分离成人声、鼓、贝斯、键盘/钢琴、吉他和其他乐器轨，每条轨单独调音量，一键静音或独奏 |
| 吉他细分 | 吉他会再拆出主音吉他和节奏吉他两条轨 |
| 和弦检测 | 播放时实时显示和弦，官方称准确率 95% 以上、可识别 700 多种和弦类型（宣传口径，实际效果因歌而异）；免费版每次分析限一分钟以内的内容，不限量在 Pro |
| AB 循环 | 圈定起点 A 和终点 B，反复播放这一段 |
| 速度调整 | 变速不变调，慢速跟练不跑音；完整 0.5x~2.0x 的可调范围属于 Pro，免费版只有约 0.9x~1.1x |
| 音调调整 | 整体升降 key，适配你的音域或乐器调弦 |
| 智能节拍器 | 按原曲自动找拍点生成节拍轨，不用自己对拍子 |
| 三段 EQ | 增减高、中、低频段，把想听的乐器从混音里凸出来 |
| 音频书签 | 在歌曲任意位置插书签，之后一键跳回 |
| 倒数进入 | 跟着节拍倒数几拍再开练，方便跟歌对齐 |
| Play & Back | 长按从选定位置试听，松手回到起点，适合反复比对复杂乐句 |
| 乐谱预览 | 导入 Guitar Pro 或 MusicXML 乐谱，播放时同步看谱 |
| 云同步 | 手机上练一半，换电脑接着练 |

## 三、第一次上手按这个顺序走

1. **新建项目并导入音频**：打开 App，新建一个项目，从手机里选一首 mp3 或其他支持的音频（能导哪些格式、每次导多长，见 [支持的音视频格式与导入方法.md](支持的音视频格式与导入方法.md)）；
2. **跑一次分离**：对导入的曲目启动 AudioAI，等它把各轨拆出来。免费版每月有次数限制，先拿一首最想练的歌试；
3. **选轨开练**：把人声轨静音、鼓轨音量拉大，配上 AB 循环和降速，就开始跟着练了。具体怎么组合这些手段，[扒谱与歌曲练习技巧.md](扒谱与歌曲练习技巧.md) 里有几套现成的练法。

## 四、安卓端要知道的两点

- 多设备是靠云同步接续的：手机上练到一半的项目，回到电脑上打开能接着练，反过来也一样；
- 项目数量在免费版下有上限，练完不想留的项目记得删掉再建新的，权益细节见 [免费版与 Pro 会员权益对照.md](免费版与 Pro 会员权益对照.md)。
