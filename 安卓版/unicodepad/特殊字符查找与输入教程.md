# UnicodePad 特殊字符查找与输入教程

UnicodePad 的用法是「先选后贴」：你在字符列表里把要的符号挑进顶部输入栏，攒成一串后复制，再到目标应用里粘贴。本篇按这个顺序讲：界面怎么分区 → 怎么找到字符 → 点与长按的区别 → 怎么送出去 → 常用字符做收藏。

## 一、界面从上到下三块

- **顶部输入栏**：你挑出来的字符会依次落到这里，可以像普通输入框一样手动删改；
- **字符列表**：按 Unicode 区段排布的字符网格，上下滚动浏览；
- **标签页**：列表、历史、收藏几个面板，左右滑动（或点标签）切换；历史里留着你最近用过的字符。

界面右上角的菜单 / 工具图标里是设置，字体、字号这类显示相关的选项都在那里改。

## 二、找到字符的三条路

1. **按分类跳转**：列表按 Unicode 区段划分，从列表顶部的分类入口直接跳到目标区段（箭头、上标、注音符号这类），比从头滚快得多；
2. **按名字或码位搜索**：知道字符叫什么就搜名字；知道码位就输十六进制码位。还有一个反查技巧 —— 把现成字符粘进顶部输入栏再点搜索，能看到它对应的码位；
3. **按区段顺序滚**：只记得「大概在符号区」时，先用分类跳转缩短范围，再手动翻。

从 2.18.0 起，汉字多出两条检索维度：部首笔画索引页，以及按释义、读音搜索（官方更新日志）；版本较旧就只有前三种方式。

## 三、点一下、长按一下，是两回事

| 操作 | 结果 |
| --- | --- |
| 点一下字符 | 字符进顶部输入栏 |
| 长按字符 | 打开详情：放大的字形 + 码位，可从这里加进收藏 |

你选中某个字符后，能看到它在列表里的确切位置（官方说明写明的功能），方便顺藤摸瓜找到同区段的邻居。

## 四、把字符送进目标应用

按场景三选一：

1. **复制 + 粘贴（最通用）**：在顶部输入栏整理好字符串，点复制，到目标应用长按粘贴 —— 聊天、笔记、文档都走这条；
2. **分享**：通过系统分享面板把字符串发给其它应用；
3. **Mushroom 直接输入（少数输入法才有）**：如果你的日文输入法带 Mushroom 接口（一种让输入法调用外部字符应用的扩展），输入过程中就能调起 UnicodePad，选完点「确定」，字符直接落回原输入框，省掉复制粘贴。国内常用输入法一般不提供这个接口，多数人按前两条走就够。

## 五、常用字符做成收藏

长按字符 → 详情里选收藏，之后切到收藏标签反复取用，不用每次重新找。高频符号（数学记号、破折号变体这类）都值得收进来；收藏数据存在应用内，换设备或重装不会自动跟着走（见 [下载与安装教程](下载与安装教程.md) 里换渠道卸载的注意事项）。

## 六、看到方框先别怪操作

字符挑出来了、贴出去却是 □，问题不在你这一步 —— 判断与处理拆解在 [字符显示方框怎么办](字符显示方框怎么办.md)。搜索找不到想要的字、或粘贴后表现异常，对照 [常见问题与更新日志](常见问题与更新日志.md)。
