本篇给你一条可核对的安装路径：先确认手里的 APK 参数，再从网盘取文件、在手机上装好，最后用版本号与 MD5 确认装对了。UnicodePad 是免费的字符输入工具，Apache License 2.0 开源，作者 Ryosuke839。

## 一、这份安装包的参数（装前装后都能核对）

网盘里保存的那份 APK，记录参数如下：

| 项目 | 值 |
| --- | --- |
| 版本号 | 2.19.3 |
| 包名 | `jp.ddo.hotmist.unicodepad` |
| 安装包大小 | 16.93 MB |
| MD5 | `fca9013cfb8f5fc993667729bdcd9471` |
| 记录时间 | 2026-09-23 |

文件在网盘里的位置：文件夹 `unicodepad（先保存再下载）`，APK 文件名 `unicodepad_v2.19.3.apk`。

## 二、从网盘获取安装包

1. 打开 [UnicodePad 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7ce6965f21dc)，把分享转存到你自己的网盘；
2. 在手机的夸克里把 `unicodepad_v2.19.3.apk` 下载到手机本地存储；或者在电脑上转存后，把 APK 拷进手机；
3. 下载完先对一眼大小：应为 16.93 MB 左右，明显对不上的文件不要装。

## 三、手机上安装

1. 用手机自带的文件管理器找到下载好的 `.apk` 文件，点它；
2. 如果系统弹出「禁止安装来自此来源的应用」，按提示进入设置，把「允许」只对这次的来源打开；
3. 点「安装」，装完直接打开。首次启动会加载完整字符数据，稍等片刻属正常。

启动等待时间的更多说明在 [常见问题与更新日志](常见问题与更新日志.md)。

## 四、核对装的是不是同一个包

三层核对，按需取用：

- **看版本**：设置 → 应用 → UnicodePad → 应用信息，版本号应显示 2.19.3（不同手机路径略有差异）；
- **看包名**：部分机型的应用信息页会显示包名，应为 `jp.ddo.hotmist.unicodepad`，这是该应用在安卓系统里的唯一标识；
- **验 MD5**（最严格）：在电脑上对下载的 APK 执行：

```powershell
certutil -hashfile "D:\下载\unicodepad_v2.19.3.apk" MD5
```

输出应与表格里的 `fca9013cfb8f5fc993667729bdcd9471` 完全一致；不一致说明文件在传输中损坏或被改动，重新下载。
