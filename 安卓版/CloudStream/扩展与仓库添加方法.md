# CloudStream 扩展与仓库添加方法

> 本篇讲 CloudStream 最关键的一步：添加仓库（Repository）并安装扩展（Extension）。不装扩展，应用搜不到任何东西。

## 一、仓库和扩展是什么关系

按官方文档的说法：**仓库是一张清单，扩展才是功能本体**。你先添加一个仓库地址，应用会从这张清单里列出它收录的所有扩展，你再挑着装。扩展决定应用能搜索哪些站点、支持哪些内容类型——所以装了什么扩展，应用就有什么能力；一个扩展都不装，主界面就是空的。

一句要放在最前面的话，来自官方 README：**请不要创建或使用托管受版权保护媒体的扩展**。CloudStream 本体只是播放器与搜索框架，具体内容的合法性取决于你添加的来源，这一责任在使用者一侧。

## 二、添加仓库的两种方式

### 方式 A：从官方推荐列表点进去装

官方文档维护了一个仓库列表页（[Repositories](https://recloudstream.github.io/csdocs/repositories/)），列表里每条都附带可直接跳转的链接。在手机上打开这个页面，点某条仓库的链接，CloudStream 装好时系统会询问是否允许该页面打开应用，同意后应用自动完成添加。

### 方式 B：手动粘贴仓库地址或短码

1. 打开 CloudStream，进入 **Settings → Extensions**；
2. 点 **Add Repository**；
3. 在 **Repository URL** 一栏粘贴仓库地址（或短码），点 **Add Repository** 确认。

短码的好处是电视遥控器上好输：几个字母就能代替一长串网址。两种方式最终效果一样，选顺手的即可。

## 三、从仓库里安装扩展

仓库加进来后：

1. 停留在 **Settings → Extensions** 页面，点开你刚添加的那个仓库；
2. 里面会列出该仓库收录的全部扩展，每个后面有 **Install** 按钮，点即安装；
3. 装多少个、装哪几个完全由你决定，随时可以回来卸载（点扩展后面的按钮即可移除）。

## 四、让扩展出现在主界面

装完扩展不是马上就能用，还要在首页把它选为入口：

1. 回到 **Home** 主界面；
2. 点右下角目前写着 **None** 的按钮；
3. 在弹出的列表里选扩展所属的分类，再选中扩展。

选完之后，主界面就会出现这个扩展提供的板块与内容目录，顶部搜索也会覆盖它。想换入口，重复上面操作即可；右侧那排入口按钮可以放多个。

## 五、仓库添加失败的最常见原因

**你的网络运营商屏蔽了 GitHub 的 raw 地址**——仓库清单几乎都托管在 GitHub 上，这是国内环境里「Add Repository 没反应 / 列表加载不出来」的头号原因。官方故障排查页给的对策是换一条网络通道再试，操作细节与其它排查手段集中在 [常见问题与解决方法.md](常见问题与解决方法.md) 的「仓库加载失败」一节。

扩展装好、入口选好之后，就到播放环节了。播放器本身的一些设置（字幕、倍速、缓存、换外部播放器）整理在 [字幕与播放器设置.md](字幕与播放器设置.md)。
