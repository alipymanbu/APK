## 一、装之前先弄清楚：它默认是个「空壳」

CloudStream 是一款开源的安卓应用（GPL-3.0 协议，代码在 [GitHub - recloudstream/cloudstream](https://github.com/recloudstream/cloudstream)），本身是一个媒体中心与播放器界面。装完打开，它**不带任何内容源**——这是官方在 README 里明确写过的警告，不是你下载的包有问题。你想让它能搜索什么、播放什么，全靠后面往里添加「仓库（Repository）」和「扩展（Extension）」，那部分流程见 [扩展与仓库添加方法.md](扩展与仓库添加方法.md)。

如果你打算在电视或盒子上用，直接跳到 [安卓电视与电视盒子安装.md](安卓电视与电视盒子安装.md)，那边的装法和手机不太一样。

## 三、从网盘转存并取出安装包

手机浏览器打开上文网盘链接，转存到自己的夸克账户后，在夸克 App 里把它下载到手机本地。下载下来的是一个 `.apk` 文件，即安装包本体。整个过程不需要注册 CloudStream 的任何账号——这款应用本身也从不要求登录。

## 四、允许「安装未知应用」

CloudStream 不在应用商店上架，安卓会默认拦下这种来源的安装。按你手机系统的新旧，处理方式二选一：

- **安卓 8.0 及以上**：点安装包安装时，系统会弹出「出于安全考虑，已禁止安装未知应用」的提示，点「设置」→ 打开「允许来自此来源的应用」（个别系统的路径是 设置 → 应用 → 特殊应用权限 → 安装未知应用）。
- **安卓 7.x 及更早**：需要打开 设置 → 安全 → 「未知来源」总开关。

允许之后回到安装界面重试即可。装完这步权限可以关回去，不影响已装好的应用运行。

## 五、安装与首次启动

1. 在文件管理器里点开 `.apk`，确认「包名」显示为 `com.lagradost.cloudstream3` 后点安装；
2. 装完点打开，首次启动会让你选界面语言，选完进入主界面；
3. 主界面此时基本是空的，右下角可能显示「None」——这是正常的，表示你还没有可用的扩展；
4. 先进 设置 看一眼：设置 → Provider（语言/分级）等选项里有地区相关设置，按需调整。

接下来你要做的第一件事就是添加扩展，让主界面「活」过来——具体步骤见 [扩展与仓库添加方法.md](扩展与仓库添加方法.md)。装好扩展后如果遇到搜索不出结果、播放卡住等情况，再去翻 [常见问题与解决方法.md](常见问题与解决方法.md)。
