## 一、装之前先弄清楚：它默认是个「空壳」

CloudStream 是一款开源的安卓应用（GPL-3.0 协议，代码在 [GitHub - recloudstream/cloudstream](https://github.com/recloudstream/cloudstream)），本身是一个媒体中心与播放器界面。装完打开，它**不带任何内容源**——这是官方在 README 里明确写过的警告，不是你下载的包有问题。你想让它能搜索什么、播放什么，全靠后面往里添加「仓库（Repository）」和「扩展（Extension）」，那部分流程见 [扩展与仓库添加方法.md](扩展与仓库添加方法.md)。

如果你打算在电视或盒子上用，直接跳到 [安卓电视与电视盒子安装.md](安卓电视与电视盒子安装.md)；手头只有电脑也没有安卓设备，装法在 [电脑上运行方法.md](电脑上运行方法.md)。

## 三、从网盘转存并取出安装包

手机浏览器打开上文网盘链接，转存到自己的夸克账户后，在夸克 App 里把它下载到手机本地。下载下来的是一个 `.apk` 文件，即安装包本体。整个过程不需要注册 CloudStream 的任何账号——这款应用本身也从不要求登录。

## 四、允许「安装未知应用」

CloudStream 不在应用商店上架，安卓会默认拦下这种来源的安装。按你手机系统的新旧，处理方式二选一：

- **安卓 8.0 及以上**：点安装包安装时，系统会弹出「出于安全考虑，已禁止安装未知应用」的提示，点「设置」→ 打开「允许来自此来源的应用」（个别系统的路径是 设置 → 应用 → 特殊应用权限 → 安装未知应用）。
- **安卓 7.x 及更早**：需要打开 设置 → 安全 → 「未知来源」总开关。

允许之后回到安装界面重试即可。装完这步权限可以关回去，不影响已装好的应用运行。

## 五、安装与首次启动

1. 在文件管理器里点开 `.apk`，确认「包名」显示为 `com.lagradost.cloudstream3` 后点安装；
2. 安装过程中如果弹出 **Play Protect**（谷歌play保护机制）的拦截提示，选「仍要安装 / Install anyway」继续——这类商店外安装包被它扫一遍是常规流程；
3. 装完点打开，首次启动是一个向导：先选界面语言；接着它会提示你安装仓库/站点，这一步可以直接跳过（仓库要你先有地址，流程见 [扩展与仓库添加方法.md](扩展与仓库添加方法.md)）；再往下选内容偏好与首页布局（网格/列表），选完进主界面；
4. 主界面此时基本是空的，右下角可能显示「None」——这是正常的，表示你还没有可用的扩展；
5. 先进 设置 看一眼：设置 → Provider（语言/分级）等选项里有地区相关设置，按需调整。

接下来你要做的第一件事就是添加扩展，让主界面「活」过来——具体步骤见 [扩展与仓库添加方法.md](扩展与仓库添加方法.md)。装好扩展后如果遇到搜索不出结果、播放卡住等情况，再去翻 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 六、以后怎么更新到新版本

装完不是一劳永逸：应用有新版时，CloudStream 自己会在应用内弹更新提示，按提示走即可；提示没弹或你想换这份网盘里的版本时，手动更新就是「拿一份新 APK 再装一遍」：

- **常规做法是覆盖安装**：直接点开新 APK 安装，系统会把它当作升级，你的书签、设置、已装扩展一般都原样保留，不用卸载旧版；
- **覆盖安装报错时再卸载重装**：个别情况（版本回退、包校验异常）系统会拒绝覆盖，这时先卸载旧版再装新版——注意先在应用设置里导出备份，重装后再导入，别白丢观看记录。

两个说法都常见，原因在上面括号里：覆盖安装是安卓的标准行为，卸载重装是覆盖失败时的兜底。新 APK 的来源与第一次安装相同；版本号是否更高，对照官方发布页确认即可。更新后扩展和仓库不需要重装，若个别扩展加载异常，进 Extensions 里重装那一个扩展就行。
