# CloudStream 安卓电视与电视盒子安装

> 本篇讲怎么把 CloudStream 装到 Android TV、Fire TV 和电视盒子上：遥控器没有浏览器也能装的两种办法，以及 TV 端添加仓库的注意点。

## 一、电视端和手机端是同一个应用

CloudStream 官方支持手机与电视两套界面，TV 端有专门的遥控器布局（官方 README 列出的特性里就有 Phone and TV support）。装在电视上的仍是同一个安装包，版本信息与手机那份一致（本文对应 4.7.0）。电视端的前提条件只有两条：

1. 电视/盒子的系统是安卓（Android TV、Google TV 或 Fire TV 系统）；
2. 允许安装商店之外的应用——路径通常是 设置 → 设备偏好设置 → 安全和限制 → 把「未知来源」对下面要用的工具开启；Fire TV 则是 设置 → My Fire TV → 开发者选项 → 允许安装未知应用。

## 二、方法一：用 Downloader 应用直接下载安装

这是官方文档推荐的电视端装法，用一个叫 **Downloader** 的下载工具代替电视浏览器：

1. 在电视的应用商店里装 **Downloader**（Google Play 和 Amazon 商店里都有这个应用）；
2. 打开 Downloader，在地址框里输入短码 `532423`，等几秒；
3. 弹出安装确认后点 **install**，再点一次 **install** 确认装 CloudStream 本体；
4. 装完点 **Launch** 启动。

短码省去了在遥控器上输入长网址的麻烦。如果你更习惯输网址，也可以把官方发布页地址（`https://github.com/recloudstream/cloudstream/releases`）直接填进 Downloader，到页面里点 APK 链接，效果相同。

## 三、方法二：手机下载后用 Send Files to TV 传过去

电视网络不给力或者 Downloader 装不了时，让手机当搬运工：

1. 手机和电视都装上 **Send Files to TV**（两台设备都从应用商店装）；
2. 手机上先拿到 CloudStream 安装包（从 [CloudStream 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c59418399850) 转存下载）；
3. 手机与电视连**同一个 Wi-Fi**；
4. 手机端选「发送」并选中 `.apk` 文件，电视端选「接收」；
5. 传输完成后在电视上点开收到的文件安装。

这个方法不依赖电视侧的网络下载速度，局域网直传一般几十秒就能传完 67M 的安装包。

## 四、TV 端添加仓库与扩展

装好后要做的还是添加仓库那套流程（详见 [扩展与仓库添加方法.md](扩展与仓库添加方法.md)），电视上有两点不同：

- **优先用短码方式**：Settings → Extensions → Add Repository，用遥控器输短码比输长地址现实得多；
- **电视浏览器基本不可用**：官方文档也承认电视浏览器经常打不开网页，所以「从列表页点链接拉起应用」这条路在电视上别指望，都走手动添加。

另外提醒一句：仓库清单托管在 GitHub 上，部分网络环境访问不到（手机端也一样），仓库加载不出来时先解决网络问题，排查思路见 [常见问题与解决方法.md](常见问题与解决方法.md)。
