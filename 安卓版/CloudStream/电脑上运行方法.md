# CloudStream 电脑上运行方法

> 本篇讲没有安卓设备时怎么在电脑上用 CloudStream：安卓模拟器与 WSA 两条路线的装法、各自的坑。

## 一、先明确：它没有 Windows 原生版

CloudStream 只发布安卓安装包（`.apk`），没有 Windows / macOS 原生程序。想在电脑上用，你是在给电脑造一个「安卓环境」，然后把 APK 装进去。两条路：

| 路线 | 上手难度 | 适合谁 |
| --- | --- | --- |
| 安卓模拟器（BlueStacks 等） | 低 | 只想装上就用的人，普通家用电脑即可 |
| WSA（Windows 安卓子系统） | 中高 | 追求系统级集成的人，对电脑配置有硬要求 |

手机/电视端的装法不适用本篇，见 [下载与安装教程.md](下载与安装教程.md) 与 [安卓电视与电视盒子安装.md](安卓电视与电视盒子安装.md)。

## 二、路线一：安卓模拟器（推荐先试这条）

1. 从模拟器官网下载安装 BlueStacks 或同类模拟器（官网是 [bluestacks.com](https://www.bluestacks.com)）；
2. 把 CloudStream 安装包拿到电脑上（从上文网盘资源转存后下载，或直接在电脑浏览器里转存）；
3. 把 `.apk` 拖进模拟器窗口，或在模拟器里用内置文件管理器点开它，安装流程与手机一致（可能同样要允许「安装未知应用」，在模拟器的系统设置里开）；
4. 装完在模拟器桌面点开 CloudStream，后续添加仓库与扩展的流程见 [扩展与仓库添加方法.md](扩展与仓库添加方法.md)。

模拟器方案的两个注意点：模拟器本身会占用不少资源，8G 内存以下的电脑体验一般；个别模拟器对这类第三方 APK 会弹安全提示，属模拟器自己的策略，按它的引导放行即可。

## 三、路线二：WSA（Windows 安卓子系统）

官方文档给了两条 WSA 装法，写本篇时都在文档里保留着，先看时效再选：

- **微软商店官方版**（带 Amazon Appstore 那个）：微软已宣布停止对 WSA 的支持，商店版随系统版本可能已不可安装，以官方文档当时的说明为准；
- **社区构建版**（[WSABuilds](https://github.com/MustardChef/WSABuilds)）：社区维护的构建，官方文档现行主推的就是它。

### 社区构建版安装步骤（官方文档口径）

1. 到 WSABuilds 的发布页下载 WSA 压缩包（不要下成「Source code」）；
2. 解压后进入文件夹，运行 `Run.bat`；
3. 安装过程会弹 PowerShell 窗口，等它跑完，首次安装会弹诊断信息授权窗（可能弹两个，都点 OK）。

装好后的硬性要求（官方文档列的）：Windows 10 22H2 / Windows 11 build 22000.526 以上；内存 6G 起（推荐 16G）；系统盘为 NTFS 分区（exFAT 不行）；BIOS 里开了虚拟化。显卡方面官方特别点名：**Nvidia 显卡容易出问题**——WSA 启动失败或画面花屏时，官方给的办法是在 WSA 设置里切换到另一块 GPU 或 Microsoft Basic Renderer。

### 把 APK 装进 WSA（侧载）

1. 装 [WSA Pacman](https://github.com/alesimula/wsa_pacman/releases)（或 WSA Sideloader）这类侧载工具；
2. 在 WSA 设置 → Developer（开发者）里打开**开发者模式**，并给侧载工具 adb 权限；
3. 双击 `.apk`，WSA Pacman 会弹出安装界面完成安装。

一个小坑：如果 WSA Pacman 里的「Install」按钮是灰的，先打开 WSA Pacman 把 WSA 启动起来再装。

## 四、装完之后

电脑端与手机端的应用本体没有区别：选语言 → 加仓库 → 装扩展 → 选首页入口，流程完全照 [扩展与仓库添加方法.md](扩展与仓库添加方法.md) 走。装扩展时连不上 GitHub 的问题在电脑上同样存在，排查思路见 [常见问题与解决方法.md](常见问题与解决方法.md)。

提示：WSA 的安装与运行故障品类繁多（弹窗闪退、Hyper-V 冲突、显卡兼容），官方排查页有一节专门的 WSA 处方，遇到问题带着报错信息去对，比盲试快得多。
