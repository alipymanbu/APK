## 一、先做两件通用的事

不管碰到什么问题，先过这两步，多数软性故障到这就好了：

1. **完全退出再打开**：不是退回桌面，是从后台任务里划掉 App 再启动；
2. **核对版本与网络**：网盘这份安装包是 v1.0.7（整理于 2026-09）。如果网上描述的功能你找不到，先核对版本差异。网络在 WiFi 和移动数据之间切一次再试。

## 二、按现象排查

| 现象 | 先查 | 处理 |
| --- | --- | --- |
| 点 apk 提示无法解析 | 包是否下载完整 | 重新下载安装包，核对 MD5 后再装 |
| 安装中途失败 | 存储空间、未知来源授权 | 清空间，给文件管理器授权后重试 |
| 打开就闪退 | 系统版本 | 安装包标注需 Android 5.2 以上；不达标只能升级系统或换设备 |
| 视频加载不出来 | 网络与时段 | 切换网络重试；高峰时段换时间再看 |
| 验证码收不到 | 短信拦截 | 查骚扰拦截箱，等 60 秒再重发 |
| 登录后进度不对 | 是否同一账号 | 退出后用常用账号重登 |
| iPhone / iPad 装不上 | 系统版本 | App Store 版要求 iOS / iPadOS 12.0 以上（以 App Store 页面为准） |

安装环节的详细处理见[下载与安装教程.md](下载与安装教程.md)第七节，登录细节见[注册登录与账号问题.md](注册登录与账号问题.md)。

## 三、缓存与重装

看课看久了缓存会堆（视频、图片都在里面）。Android 通用路径：系统「设置 → 应用管理 → VipSkill → 存储 → 清除缓存」。注意**清除缓存不等于清除数据**——只清缓存一般不影响账号与已下载内容；「清除数据」和卸载则会清掉本机内容，动手前想清楚。

重装前后要做的事：

- 重装前先确认账号还能在别处正常登录（记住账号密码）；
- 卸载会连带删掉离线缓存，重装后需要重新联网加载；
- 装完用原账号登录，再检查内容是否都在（是否跨设备同步以 App 实际表现为准）。

## 四、找官方

自己排不出的问题别硬耗。官方渠道：

- 官网 [www.vipskill.com](https://www.vipskill.com/)；
- 微信公众号（以微信搜索「VipSkill」的结果为准）；
- 付费学员优先走报名时的对接人或答疑群。

反馈时把信息说全：App 版本号（网盘这份是 1.0.7）、Android 系统版本、手机型号、具体现象与截图。信息全，来回能少很多轮。
