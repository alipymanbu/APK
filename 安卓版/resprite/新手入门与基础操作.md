## 一、先认识这套界面

安卓版与 Windows/macOS 桌面版共用同一套界面逻辑，官方文档把它们归为同一条产品线（文档里标注 DA，即 Desktop & Android）。所以你在安卓上看到的是带完整工具栏、图层与时间轴面板的专业软件布局，而不是简化的手机应用。打开应用后首先进入美术馆，它管理你的全部作品文件。

## 二、新建一个画布

1. 在美术馆点新建（New Sprite）；
2. 填文件名；
3. 选预设尺寸，或手输宽高；
4. 确认后进入画布。

两点提示：

- 桌面端与安卓端会记住你之前用过的自定义尺寸，新建对话框里可以直接选，不用每次重输；
- 如果想从第一笔就录制绘画过程，新建对话框里有缩时录制（timelapse）的开关；之后也可以在精灵设置里再改。

尺寸按需要取：官方提示画布越大，内存占用与播放开销上升越快，如果打算叠很多图层、做较长的时间轴，尺寸保守一点更稳。

## 三、常用工具一览

| 工具 | 用它做什么 |
| --- | --- |
| 画笔 | 主力工具，支持完美像素线条，笔刷尺寸在工具控件上拖动调节 |
| 橡皮 | 擦除像素 |
| 油漆桶 | 区域填充 |
| 取色 | 长按画布也能快速吸色 |
| 选区与变换 | 框选后移动、缩放、旋转、斜切 |
| 渐变 | 渐变填充 |
| 模糊/喷枪 | 做柔和过渡 |
| 对称 | 轴对称辅助（高级版功能） |
| 文字 | 插入文字（高级版功能） |
| 图形/轮廓 | 画直线、矩形、圆形等，高级轮廓能力属于高级版 |

抖动（dithering）纹理不是单独的工具：画笔、橡皮、油漆桶、渐变、着色、图形工具都共用一套抖动图案库，做复古颗粒感时直接在这些工具的选项里切换。

表中对称、文字与高级轮廓属于高级版解锁项，解锁范围与付费方式见[高级版与账号常见问题.md](高级版与账号常见问题.md)。

## 四、画着画着常用的几个操作

- **撤销/重做**：两指轻点画布撤销，三指轻点重做；外接键盘是 Ctrl+Z / Ctrl+Shift+Z；
- **取消选区**：外接键盘按 Ctrl+D；
- **外接键盘常用键**：B 铅笔、E 橡皮、G 油漆桶、I 取色器、M 矩形选区，Ctrl+S 保存、Ctrl+E 导出；完整清单与改键在 设置 ▸ 键盘 ▸ 配置键盘快捷键；
- **取色**：长按画布或参考图直接吸色；
- **调笔刷大小**：在画笔工具的尺寸控件上左右或上下拖动；
- **删除调色板里的颜色**：先选中色块，再点删除按钮（这一点与 iOS 的拖出窗口操作不同）。

## 五、图层基础

- 双击图层头部打开图层菜单，选"新建图层"；
- 长按图层头部拖动，可以调整顺序或拖进图层组；
- 图层支持混合模式、不透明度、剪贴蒙版，以及 Alpha Lock（锁定透明像素，只画在已有形状上）与描边、投影这类图层样式。

动画相关的帧操作在时间轴上，见[动画制作入门.md](动画制作入门.md)。

## 六、画布级的调整

打开 菜单 ▸ Sprite（精灵设置），常用的几项：

| 设置项 | 作用 |
| --- | --- |
| 帧率 | 动画预览与导出的播放速度 |
| 精灵尺寸 | 整体缩放已有作品 |
| 画布尺寸 | 扩大或裁掉边界，不缩放已有像素 |
| 旋转/翻转 | 对所有帧统一变换 |
| 裁剪到选区 | 把画布裁到当前选区大小 |
| Trim | 去掉作品四周的空白 |

画完的东西往哪儿存、怎么导出，见[文件保存与导出格式.md](文件保存与导出格式.md)。
