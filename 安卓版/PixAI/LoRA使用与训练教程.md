## 一、LoRA 是什么、什么时候需要它

LoRA 是挂在基础模型上的小型附加包，专门教模型认一个具体的东西：某个角色、某套服装、某种画风、某个姿势。基础模型决定「整体画成什么样」，LoRA 决定「画面里出现这个特定的东西」。

需要它的典型场景：

- 基础模型怎么提示都画不出你想要的那个角色或服饰细节；
- 想让同一个人物在多张图里长得一致——先训练一个角色 LoRA，之后每张图挂上它；
- 想要一种社区里已经有人调好的小众画风，没必要自己从头训。

「长一张一样的脸」到底能到什么程度？有第三方做过实测：固定 Seed、写好提示词、挂上角色 LoRA，连出 20 张里大约 15 到 16 张能保持同一张脸。达不到 100%，但比只用提示词硬描述稳定得多——这正是 LoRA 的价值区间。

## 二、去哪找、怎么挂

PixAI 内置 LoRA 市场，按角色、风格、用途等筛选，也可以直接搜名字。挂在生成页的 LoRA 栏里，一次可以叠加多个：

| 档位 | 单次可挂 LoRA 数 |
| --- | --- |
| 免费版 | 3 |
| Starter | 5 |
| Plus | 10 |
| Premium | 15 |

（额度以官方会员页当前说明为准。）

叠加不是越多越好：多个 LoRA 会互相抢画面控制权，一个强的能把其他几个的存在感全吃掉。常见做法是**一次主打一个**，确认效果后再考虑加第二个。

## 三、权重与触发词

挂上 LoRA 后有两个东西决定它「出不出力」：

- **触发词**：一段要写进提示词的关键词，相当于喊这个 LoRA 的名字。多数情况下你把 LoRA 加进生成页时，PixAI 会自动把推荐触发词填好；没自动填的，去该 LoRA 的详情页找作者写的说明；
- **权重**：LoRA 的影响强度。官方文档给的排查区间是 **0.6 到 0.9**：太低没存在感，太高会把整个画面带歪、盖过你提示词里的其他内容。

调整顺序建议：先确认触发词写对了，再从 0.7 左右起试，按出图效果上下微调。

## 四、挂了没反应，按这个顺序排查

官方文档给出的排除顺序如下，逐条做：

1. **查触发词**：确认提示词里已经包含 LoRA 作者提供的触发词，拼写和格式都没错。这是最常见的原因；
2. **调权重**：提到 0.6 到 0.9 区间测试；
3. **减少数量**：同时挂了多个 LoRA 时，只留一个测，确认它单独是有效的再逐个加回来；
4. **查提示词冲突**：提示词里有与 LoRA 目标相反的描述（比如 LoRA 是旗袍、提示词里写了制服），画面就会来回打架；
5. **查基础模型匹配**：LoRA 是针对某个基础模型系训练的，配错了系会失灵或完全无效——LoRA 详情页一般标了适配的模型，选同一系的。

按顺序走完这五步还没效果，多半是那个 LoRA 本身质量差，换一个同类就是了。

## 五、训练自己的 LoRA

PixAI 支持在网页或 App 里直接在线训练，全程不用本地装任何东西：

1. **准备图片集**：同一角色或同一风格的图，**最少 10 张、最多 100 张**。角色 LoRA 要覆盖不同角度、表情、光线，画风 LoRA 则要风格统一、内容多样；
2. **在训练页上传**并给数据集打标；
3. **选基础模型**：决定你的 LoRA 之后配哪个模型系用，这步要和上面第四节说的匹配问题一起想清楚；
4. **设触发词**：起一个不容易和常用词撞车的自定义词，之后生成时靠它召唤；
5. 提交排队等训练完成。第三方实测反馈通常在 20 分钟上下，具体看排队情况。

**费用与名额**：训练消耗点数或占用会员的每月免费名额——免费档**没有免费名额**（想训就花点数），Starter 每月 3 个、Plus 5 个、Premium 10 个（以官方会员页为准）。名额制度对打算批量做角色库的人更划算，档位差异见 [免费版限制与付费版区别.md](免费版限制与付费版区别.md)，点数账目见 [免费点数获取方法.md](免费点数获取方法.md)。

训出来的 LoRA 可以设为私有自己用，也可以公开发布到市场——发布后被使用、被点赞，同样能给账号带来曝光和互动收益。
