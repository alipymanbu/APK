## 一、动手前先对上这张表

Suno 是一款跑在 Android 手机上的 AI 音乐创作应用：你给它一段文字描述——想要的曲风、题材、情绪——它会生成一首带人声和伴奏的完整歌曲，一次生成通常一到三分钟。不需要会乐器，也不需要乐理基础，操作基本就是「写描述、点创作、试听」。

安装本身不难，容易出问题的是**装错版本**：同一个名字在网络上可能有多个来源的包，版本号、体积、包名都不一样。所以先核对事实。

| 项目 | 值 |
| --- | --- |
| 应用名称 | Suno |
| 版本号 | 1.4 |
| 包名 | `com.xcdjl.wyyytyq` |
| 安装包大小 | 114.23M |
| 文件校验值（MD5） | `4194E28066D722B3E8C581F1B7CBD172` |
| 系统要求 | 需要支持安卓系统 5.2 以上 |

其中**包名**和**版本号**最该看：包名是应用在系统里的身份，版本号决定你拿到的功能对不对得上本文的描述。网上还能搜到同一应用的更高版本（例如 1.5、体积 129.47M），那是后来发布的包，与本文对应的 1.4 不是同一份文件——两边的数字不要混着用，以你实际拿到的那一份为准。

## 二、把安装包取到手机里

1. 在手机上打开 [Suno 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a230043be40f)，进入分享页。分享页里带的是应用所在的那一层目录，进去后取里面的安装包文件。
2. 没有网盘账号的先按提示注册或登录，已有账号的直接「保存到网盘」，把目录转存进自己的空间，再从自己的网盘里下载。转存后下载比在线直接打开稳：分享页刷新、网络波动都不会把下载打断。
3. 下载完的文件名形如 `suno_v1.4.apk`。**别在网盘里直接点「打开」**，那只会触发在线预览；要选「下载」，等文件完整落到手机的下载目录。
4. 想确认文件有没有下坏，用上一节的 MD5 对一遍：`4194E28066D722B3E8C581F1B7CBD172`。许多文件管理器自带校验入口，算出来的字符串与这串完全一致，就说明文件完整。

这一步如果卡在「网盘打不开」或速度极慢，先换手机流量、或者等网络空闲时段再试，这类情况基本与安装包本身无关。

## 三、允许这个来源安装应用

Android 默认不允许安装来自浏览器或网盘的文件，第一次装通常会弹「已阻止安装」。打开方式按系统版本分两种：

| 系统版本 | 操作路径 |
| --- | --- |
| Android 8.0 及以上 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 → 选中你下载用的浏览器或网盘 App → 打开开关 |
| Android 7.x 及以下 | 设置 → 安全 → 打开「未知来源」 |

开关打开后回到文件管理器，点 `suno_v1.4.apk` 继续。装完建议把开关关回去，以后需要临时开启即可。

## 四、安装时的几种提示怎么处理

| 提示 | 含义与处理 |
| --- | --- |
| 「解析软件包时出现问题」 | 文件没下完或已损坏。删掉重新下载，并按第二节的 MD5 再校验一遍 |
| 「应用未安装」 | 手机上已存在同一个包名的其他版本。先在设置里卸载旧的那个，再装这一份 |
| 安全软件提示风险 | 非应用商店来源的常见提醒。确认文件来自你信任的渠道后继续 |
| 装完桌面上没有图标 | 部分启动器需要几秒刷新；回桌面下拉一次，或在应用列表里搜索「Suno」 |

## 五、第一次打开要做三件事

1. **同意隐私政策与用户协议**。首次启动会先弹这两份文本，读完同意才能进主界面。
2. **处理权限申请**。应用会申请存储或媒体相关权限，用途是保存生成的音频、播放本地文件。全部拒绝的话，生成好的歌可能保存不下来，建议按提示允许。
3. **按需登录**。进入主界面后，界面中间通常是创作入口；部分功能需要账号才能使用，按提示注册或登录即可。登录环节的异常处理收在 [常见问题与排查.md](常见问题与排查.md)。
