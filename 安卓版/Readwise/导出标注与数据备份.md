## 一、官方承诺能带走什么

按官方页面的口径（截至写作时，以官方页面当时显示为准），账号里的数据可以整包导出：

| 数据 | 导出格式 |
| --- | --- |
| 每一篇文档 | CSV |
| RSS 订阅源 | OPML |
| 你上传的文件 | ZIP 压缩包 |
| 每一条标注与笔记 | Markdown |

导出入口在 Readwise 主应用的网页端（[readwise.io](https://readwise.io/)），具体菜单位置以官方帮助文档为准。

## 二、自动同步到笔记软件

手动导出之外，更常用的方式是让标注自动流向你的笔记库：

1. 在 Readwise 主应用的设置里选择导出目标（Notion、Obsidian、Evernote 等，各自有官方接入说明）；
2. 完成授权后，Reader 里每做一条新标注都会自动同步过去，不需要手动搬运；
3. 换笔记软件时改一下导出目标即可，历史标注也能重新推送。

这一步用的是 Readwise 主应用的能力，前提是你订阅的档位包含完整版（见[注册试用与订阅方案](注册试用与订阅方案.md)的档位表）。

## 三、Zapier 与 API

- **Zapier**：2025 年底官方接入了 Zapier，可以把标注流转接到更多应用，适合想搭自动化流程的人；
- **API**：官方提供开发者接口（入口 [readwise.io/api](https://readwise.io/api)），想自己写脚本处理标注的人可以从这里开始，具体能力以官方文档为准。

## 四、订阅源搬家是双向的

OPML 是 RSS 订阅源通用的搬运格式：

- **迁入**：从别的 RSS 阅读器换过来，直接导入你的 OPML 文件（导入方式见[保存文章与导入内容的方法](保存文章与导入内容的方法.md)）；
- **迁出**：订阅源也能导出成 OPML 带走，换回其他阅读器时不会丢订阅关系。

## 五、试用结束前留一份备份

试用期内账号是完整状态，随时可以按第一节的格式整包导出一份备份，成本只是几分钟。到期后账号与数据的保留政策属于会变动的信息，以官方当时说明为准——所以在决定是否续费之前，先把备份拿在手里更稳妥。

标注在笔记软件里的后续用法（标签、复习节奏）见[标注笔记与听读技巧](标注笔记与听读技巧.md)。
