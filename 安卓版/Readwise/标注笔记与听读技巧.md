## 一、手机端：双击即划线

- 在正文某一段上**双击**，就完成一次高亮，这是安卓端最快的划线方式；
- 长按可以选中任意范围再划线，也能在划线上补笔记；
- 底部右侧的 `...` 菜单里有听读（Listen using text-to-speech）与 Ghostreader 的入口。

阅读界面本身的排版怎么调（分页、字体、双栏、音量键翻页），见[电子书排版与阅读视图](电子书排版与阅读视图.md)。

## 二、网页端：键盘为主

| 按键 | 作用 |
| --- | --- |
| `h` | 高亮当前聚焦的段落 |
| `n` | 高亮并开始写笔记 |
| `z` | 撤销（可连续撤销多步） |
| `[` / `]` | 收起或展开左右侧栏，进入专注阅读 |
| `U` | 打开文件上传 |
| `Cmd/Ctrl + K` | 命令面板，几乎所有操作都能从这里搜到 |
| `?` | 快捷键速查表 |

## 三、标注最终会去哪

你在 Reader 里做的每一条划线与笔记，都会同步到 Readwise 主应用；再由 Readwise 自动导出到 Notion、Obsidian、Evernote 等笔记软件。也就是说：手机上随手划的一条线，最终会出现在你的笔记库里，中间不需要手动搬运。标注的整包导出与备份方式见[导出标注与数据备份](导出标注与数据备份.md)。

## 四、听读（TTS）

- 网页端：文档右上角 Listen 按钮，`P` 播放/暂停；
- 手机端：普通文章点右上角播放按钮即从当前位置开始读；EPUB 与长文阅读模式下入口在 `...` 菜单 → Listen using text-to-speech；
- 换语言：播放条左侧的波形图标 → View all languages；
- 耳机手势：Account settings → Headphone gestures，可以把耳机的双击/三击改成触发高亮；
- 两个限制要知道：TTS 是即时生成语音的，**离线用不了**；PDF 只在文本视图下能听，在原版视图点播放会自动切换。

## 五、Ghostreader：对着文档提问的助手

- 网页端快捷键 `Shift + G`，手机端在 `...` 菜单里；
- 典型用法：查词义、总结全文、就当前文档提一个具体问题让它回答；
- 网页端在 2025 年底升级成了聊天式界面，回答会附上所引用原文的位置，也支持预设提示词；
- 不想用可以在设置里关掉，不打扰阅读。

## 六、离线缓存怎么配

打开过的文档正文会自动缓存，之后没网也能接着读。缓存范围可以手动控制：Account 标签 → Offline documents，把想离线读的分区开关打开（Feed 默认关闭，它也是最容易把应用体积撑大的部分）。

这份安卓安装包本身约 341 MB，如果设备空间紧张，装完第一件事就是到 Offline documents 里关掉不需要的分区。

## 七、划过的线怎么复习

Readwise 主应用的 Daily Review 会按间隔重复的节奏，把你的旧标注推回来给你看，App 与每日邮件都能收。这个功能属于 Readwise 主应用而不属于 Reader，包含在[注册试用与订阅方案](注册试用与订阅方案.md)里列出的完整版套餐中。

听读没声音、Ghostreader 没反应这类问题，先翻[打不开与同步失败的排查](打不开与同步失败的排查.md)。
