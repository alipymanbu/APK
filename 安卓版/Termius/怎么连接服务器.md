## 一、连接前要备齐的信息

无论用什么客户端，SSH 连接都需要这几样，先在服务器提供商的后台确认好：

| 信息 | 说明 | 常见值 |
| --- | --- | --- |
| 地址（Address） | 服务器的 IP 或域名 | `123.45.67.89`、`vps.example.com` |
| 端口（Port） | SSH 服务监听的端口 | 默认 `22`，有些商家改成了别的 |
| 用户名（Username） | 登录用的账号 | 云主机常是 `root`，Ubuntu 常是安装时建的用户 |
| 认证方式 | 密码，或 SSH 密钥 | 密钥登录见[SSH密钥配置](SSH密钥配置.md) |

## 二、把服务器登记成主机

1. 打开 Termius，进 **Hosts** 页，点 **+**（Add Host）；
2. 填 Label（备注名，随便起，比如「我的VPS」）、Address、Port、Username；
3. 认证方式选 Password 就填密码；想用密钥就先去 Keychain 建好密钥再回来选；
4. 保存后主机出现在列表里。

多台服务器建议顺手分组（Group），比如按用途分成「生产」「测试」，列表长了以后好找。点条目右侧的编辑还能给整组统一改设置。

连的不是云服务器而是家里的群晖 NAS、树莓派这类设备时，得多一步「先在设备端开启 SSH」，具体见[连接群晖NAS与树莓派](连接群晖NAS与树莓派.md)。

## 三、连上去并确认主机指纹

1. 在 Hosts 里**点一下**主机条目，Termius 开始连接；
2. **第一次连接**会弹出主机指纹（host key fingerprint）让你确认——这是服务器出示的身份凭证，确认后就记进已知主机列表，下次不再问。在意安全的话，可以到服务器上执行 `ssh-keygen -l -f /etc/ssh/ssh_host_ed25519_key.pub` 之类命令比对指纹再点确认；
3. 出现命令行提示符（如 `root@vps:~#`）就是连上了。

指纹对不上时会报「host key changed」之类的错误并拒绝连接，这通常是服务器重装系统导致的，处理办法见[连接失败排查](连接失败排查.md)。

## 四、在手机屏幕上敲命令

手机没有实体键盘，Termius 的补偿手段都在终端界面里：

- **快捷键条（shortcut bar）**：终端下方一排常用键（Esc、Tab、方向、Ctrl、`-`、`/` 等），可自定义换成你最常用的；
- **方向键手势**：长按屏幕任意处拖动即发送方向键；按住空格键拖动只左右移光标。按住不放会连续输出，越拖越快；
- **Tab 补全**：快捷键条上有 Tab 键，用来补全命令和路径；
- **字号**：双指捏合缩放；
- **复制粘贴**：长按选择文字后点 Copy / Paste；
- **长命令**：切换到终端上方的 Paste 模式再粘，或者用语音输入一次成段；
- **外接键盘**：蓝牙键盘连上即用，Esc / Ctrl / Tab / 方向都正常，体验接近电脑。

常用命令别反复手打——存成 Snippet，点一下就整条发送（比如 `df -h`、`systemctl restart nginx`）。

## 五、两个让它更好用的进阶设置

- **启动命令（Startup Command）**：在主机编辑页里加一条，比如 `tmux attach -t work || tmux new -s work`，每次一连上就自动进入 tmux 会话。配合 tmux，手机断线、锁屏都不影响服务器上跑的任务，重连后原样恢复；
- **Mosh**：在地铁、基站切换这种网络频繁变动的环境里，普通 SSH 会频繁掉线。服务器上装好 mosh 包后，在主机详情里启用 Mosh，它会话能跟着网络切换自动续上。

连上之后想传文件或把服务器上的网页服务映射到手机浏览器看，接着读[SFTP传文件与端口转发](SFTP传文件与端口转发.md)；连接报错则翻[连接失败排查](连接失败排查.md)。
