# Termius 连接群晖 NAS 与树莓派：家用设备 SSH 教程

> 本篇讲两类最常见的家用 SSH 设备——群晖 NAS 和树莓派——怎么先在设备端把 SSH 打开、再用 Termius 连上去。设备端设置是这类连接成败的关键，通用的客户端操作见[怎么连接服务器](怎么连接服务器.md)。

## 一、共同的前置：设备端要先开 SSH

家用设备和云服务器不一样：**很多设备出厂默认关闭 SSH**，客户端这边配置得再对也连不上。所以流程永远是「先在设备端开启 SSH 服务 → 再回 Termius 添加主机」。两台设备连不上时，第一件事就是回头确认设备端服务状态，其余排查见[连接失败排查](连接失败排查.md)。

## 二、连接群晖 NAS

### 设备端：在 DSM 里开启 SSH

以 DSM 7 为例（以你的 DSM 版本界面为准）：

1. 用管理员账号登录 DSM 网页界面；
2. 打开 **控制面板 → 终端机和 SNMP → 终端机**；
3. 勾选 **启用 SSH 功能**，端口默认 `22`，点应用。

改过端口的话，Termius 主机里的 Port 也要跟着改。

### 账户与权限的三条硬规则

- **不是所有账号都能 SSH 登录**：DSM 只允许属于 **administrators（本地管理员）** 群组的账户通过 SSH 登录，普通共享账号连不上是正常现象；
- **默认没有 root 直登**：先用管理员账号连上，再执行 `sudo -i` 切到 root（输入的是当前管理员的密码）；
- **密码不能为空**：空密码的账户一律拒绝 SSH 登录。

### 一个容易踩的坑

在 DSM「高级设置」里把 SSH 加密算法安全等级调到最高、或只勾选硬件加速算法后，**部分 SSH 客户端会因算法不兼容而连不上**。手机上连群晖报握手类错误时，先把安全等级调回默认再试。

### 传文件：SFTP 直接可用

群晖的 SFTP 在 **控制面板 → 文件服务 → FTP** 里启用（端口同为 22）。开启后 Termius 的 SFTP 双栏界面就能直接浏览共享文件夹，和服务器用法一致，见[SFTP传文件与端口转发](SFTP传文件与端口转发.md)。

顺带两个 DSM 常用端口，方便对照：DSM 网页是 `5000`（HTTP）/`5001`（HTTPS），SSH/SFTP 是 `22`。

## 三、连接树莓派

### 第一步：把 SSH 打开

树莓派官方系统的 SSH **默认关闭**，开启方式按你的条件选：

- **有屏幕键盘**：桌面菜单 → Raspberry Pi 配置 → 接口 → 启用 SSH；或执行 `sudo raspi-config`，在 Interface Options 里启用；
- **纯命令行**：`sudo systemctl enable ssh`，然后 `sudo systemctl start ssh`；
- **无屏幕无键盘（headless，最常见）**：把烧好系统的 SD 卡插回电脑，在 boot 分区根目录新建一个名为 `ssh` 的**空文件**（全小写、无扩展名），弹卡插回树莓派上电，系统首次启动检测到该文件就自动开启 SSH 并删除它。

### 第二步：找到它的 IP

- 手机和树莓派连**同一个局域网**，这是后面一切的前提；
- 路由器管理页的设备列表里找名为 `raspberrypi` 的条目；
- 或者在任何能跑命令的设备上 `ping raspberrypi.local`（新版 Raspberry Pi OS 自带 mDNS，默认主机名 `raspberrypi`）；
- 树莓派接了屏幕的话，直接执行 `hostname -I` 看。

### 第三步：确定账号密码

- **旧版系统**（2022 年前）默认账户是 `pi`、密码 `raspberry`，官方早已建议首次登录后立刻改密；
- **新版 Raspberry Pi OS 已取消默认账户**：刷系统时需要用官方 Raspberry Pi Imager 预先设置用户名和密码（Imager 的高级设置里填），没设的话进不了系统；
- 连上后第一件事改成自己的强密码，家用设备暴露在内网里被扫的情况并不少。

## 四、连上之后

- 想免密登录，给 NAS 或树莓派部署公钥的流程和普通服务器完全一样，见[SSH密钥配置](SSH密钥配置.md)；
- NAS 上跑的下载工具、树莓派上的 Web 服务（比如 Home Assistant 的 `8123` 端口），都能按[端口转发](SFTP传文件与端口转发.md)的 Local 规则映射到手机浏览器看。
