# Termius SSH密钥配置：生成、导入与免密登录

> 本篇讲在安卓手机上用 Termius 的 Keychain 生成或导入 SSH 密钥，并把服务器改成密钥登录——以后连接不再输密码。

## 一、为什么值得折腾密钥

密码登录有两个麻烦：手机上输复杂密码很痛苦；开着密码登录的服务器整天被扫。换成密钥登录后，认证靠「你手机里的一把私钥」，不用输密码，服务器还可以干脆关掉密码登录，风险小一截。

原理一句话：**公钥放服务器，私钥留手机**。服务器用公钥验证请求，配对的私钥才能通过，私钥从头到尾不离开你的设备。

## 二、在 Termius 里生成一把密钥

1. 打开 Termius，点 **`< All vaults`** 回到 Vaults 页，进 **Keychain**；
2. 点 **`+`**，在菜单里选 **New SSH Key**，再选 **Generate new SSH Key**；
3. 填 Label（如 `phone-key`），类型选 **ED25519**（现在的主流选择；老服务器不认再退回 RSA 2048 以上）；
4. 建议设一个 passphrase 给私钥再上一道锁，开启 Save passphrase 后连接时不用重复输入；
5. 保存。密钥就留在 Keychain 里了。

生成后点开这把密钥，能看到**公钥**内容（`ssh-ed25519` 开头的一长串）。

## 三、把公钥装到服务器上

密钥登录要服务器「认识」你的公钥，也就是把它追加进服务器的 `~/.ssh/authorized_keys`。常见三种做法，挑一个：

- **最省事**：先用密码在 Termius 连上服务器（见[怎么连接服务器](怎么连接服务器.md)），复制公钥，在服务器上执行：
  ```bash
  echo "ssh-ed25519 AAAA...你的公钥内容" >> ~/.ssh/authorized_keys
  chmod 600 ~/.ssh/authorized_keys
  ```
- **有电脑在旁边**：电脑上执行 `ssh-copy-id root@服务器地址`，如果这把密钥也在电脑上，一次搞定；
- **服务器面板**：不少云厂商（阿里云、腾讯云、Vultr 等）控制台里能直接粘贴公钥，绑到实例上。

## 四、让主机用这把密钥连接

回到 Hosts，编辑目标主机：认证方式从 Password 改成 **Key**，选中刚才那把密钥，保存。断开重连一次验证：不再提示输密码、直接进到命令行，就说明配置生效了。

验证通过后，如果这台服务器只有你自己用，可以在服务器上关闭密码登录作为加固：编辑 `/etc/ssh/sshd_config`，把 `PasswordAuthentication` 设为 `no`，重启 sshd 服务。**改之前先确认密钥能登**，不然会把自己锁在门外。

## 五、导入已有的密钥

电脑上已经生成过密钥（比如 `~/.ssh/id_ed25519`）想搬到手机？在 Keychain 的 **New SSH Key** 菜单里选导入，粘贴**私钥文件的完整内容**（`-----BEGIN OPENSSH PRIVATE KEY-----` 到 `-----END OPENSSH PRIVATE KEY-----` 整段）即可。

两点提醒：

- 能在 Termius 里重新生成一把新密钥再部署公钥的话，优先选这条路——私钥复制的环节越少越安全，旧密钥泄露了也不用连坐；
- 导入后连接报「Permission denied (publickey)」，多半是粘贴时丢了首尾行或多了换行，对照[连接失败排查](连接失败排查.md)的密钥一节核对。

## 六、日常维护

- **备份**：重装手机前，确认私钥还有别的去处（电脑、加密备份），否则服务器上得重新部署公钥。换手机想带走主机列表和密钥：订阅了云同步的，新手机登录同一账号、输入加密密码即可整体还原；只用免费版的话，截至本篇整理时公开文档里没有本地一键导出入口，现实做法就是在新手机上重录主机、重新生成或粘贴密钥并重新部署公钥（所以每台服务器的 `authorized_keys` 里多留一行新公钥不亏）；
- **多服务器共用**：一把密钥可以部署到多台服务器的 `authorized_keys`，也可以每台一把、按密钥名区分，后者一台手机丢了只需在对应服务器上删掉那行公钥；
- **撤销**：不再使用的密钥，去服务器 `authorized_keys` 里删掉对应行即可立即失效。
