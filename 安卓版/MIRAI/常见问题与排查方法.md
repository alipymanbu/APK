## 一、先确认装的是哪个「MIRAI」

排查之前先花十秒认准应用：名字带 Mirai 的应用不止一个，MiraiMind、MirAI 都是别的产品，界面和玩法不通用 —— 对照表与包名核对方法见 [同名应用区分与下载认准.md](同名应用区分与下载认准.md)。确认包名是 `app.mirai.fun` 再继续往下查，能省掉一大半白折腾。

## 二、安装报错（应用未安装 / 解析包出错）

按顺序排查：

1. **核对 MD5**：安装包损坏是最常见的原因。Windows 上运行 `certutil -hashfile MIRAI_v1.2.2.apk MD5`，输出应等于 `60218fd5b86b38cf4f3a00d99ca8aff7`；不一致就重新下载（安装包事实表见 [下载与安装教程.md](下载与安装教程.md) 第二节）。
2. **存储空间**：安装包 74.66M，安装过程还要展开临时文件，可用空间不足会直接失败，至少留 200M。
3. **来源权限**：报「禁止安装」时，去「设置 → 安全/隐私 → 安装未知应用」给下载用的浏览器或文件管理器授权。
4. **系统过旧**：安装包信息未标注最低安卓版本，系统过旧时安装器可能直接拒绝；这种情况只能换设备或用商店版。

## 三、打开就闪退 / 黑屏

- 先重启手机再开一次，排除临时性故障；
- 在「设置 → 应用 → MIRAI」里清一次缓存（别急着清数据，会丢本地记录）；
- 手机剩余空间太小时部分机型会闪退，清理后再试；
- 还是闪退就卸载重装 —— **重装前先确认你的账号与数据情况，见第六节**。

## 四、对话发不出去 / 一直转圈

MIRAI 的对话要联网才能用，离线打不开剧情：

1. 确认手机能正常上网（开个网页试试）；
2. 换一次网络 —— Wi-Fi 与移动数据互换是最快的定位办法；
3. 挂了代理 / 加速器的先关掉再试，AI 类应用对连接稳定性敏感；
4. 应用内报网络错误但其他应用正常，等多一会再试，多半是服务端波动。

## 五、界面是英文，有中文吗

- 安卓包与多个渠道页标注支持简体中文；iOS App Store 页标注的语言是英语、韩语。你手机上装到的是哪个界面语言，以打开后的实际显示为准；
- 界面显示英文时，先在应用内找设置（Profile / Settings 一类的入口）里的 Language 选项，有中文选项就切过去；没有语言选项的，以应用当前版本实际提供的为准；
- **对话内容的语言跟随你的输入**：你用中文聊，回复一般也是中文；角色开场白若是英文，用中文发一句，多数时候它就切过来了。

## 六、重装 / 换机后，聊天记录还在吗

官方没有公开说明数据保留机制，这点以应用内实际表现为准。稳妥的做法是：

- **卸载或换机前**，先确认是否已登录账号（找到应用内的账号入口看一眼），别在未登录状态下直接卸载；
- 重装后如果发现记录没了，先确认登录的是不是同一个账号，再判断是不是真的丢了；
- 不放心就把重要剧情截图存本地，这类应用的对话内容不值得赌。

## 七、隐私与数据收集

App Store 的隐私标签显示，该应用可能收集标识符、使用数据、诊断信息，且部分数据会与你的身份关联（用于应用功能，如购买记录、联系方式、用户内容）。具体口径以官方隐私政策为准：[https://docs.mirai.fun/mirai/policy](https://docs.mirai.fun/mirai/policy)（条款见 [https://docs.mirai.fun/mirai/terms](https://docs.mirai.fun/mirai/terms)，以官方页面为准）。在意隐私的话，聊天时别把真实姓名、住址、证件信息写进对话。

## 八、还是解决不了

官方渠道就两处：官网 [www.mirai.fun](https://www.mirai.fun/)（应用介绍与更新信息）、官方文档站 [docs.mirai.fun](https://docs.mirai.fun/)（条款、隐私、创作者指南）。充值扣款类问题优先看 [充值与积分使用说明.md](充值与积分使用说明.md) —— 那类问题多数要走应用商店的订单渠道，应用内客服解决不了。
