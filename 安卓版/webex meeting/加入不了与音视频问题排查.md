## 一、四个先查一遍的通用项

不管什么症状，先过这四条，一半的问题出在这里：

1. **系统时间**：官方系统要求文档专门提醒「确保系统时间正确，否则可能影响加入会议或通话」。开「自动获取时间」，别手动改。
2. **网络**：视频会议对上行带宽敏感，切到 Wi-Fi 或信号好的位置再试；公司内网可能限制会议端口，换手机流量对比一下就能判断是不是网络封了。
3. **应用版本**：官方对加入前的选项做过改版，**旧版应用看不到新的加入入口**，表现就是「界面跟教程对不上」。对着官方最新版更新一下：网盘块里的 **Webex Meetings 安装文件资源（夸克网盘）** 可直接换装。
4. **权限**：麦克风、摄像头权限被系统「仅本次」或永久拒绝，音频视频都会静默失败，去系统设置里核对应用权限。

## 二、点「加入」没反应 / 一直等不到会议开始

| 症状 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| 输了会议号提示找不到 | 号码抄错、缺位 | 对着邀请邮件逐位核对；电话里口头记的号最易错 |
| 提示密码错误 | 大小写、易混字符（O/0、l/1） | 直接从邮件里复制粘贴，别手敲 |
| 卡在等候区很久 | 这是**个人会议室**的正常机制，主持人没放你进来 | 点「通知主持人」催一下；主持人开了「允许先加入」的会才不用等 |
| 显示「会议未开始」 | 主持人还没点开始 | 等主持人；到点没动静就联系会议发起人核对时间 |
| 用邮件链接点了没反应 | 链接没拉起应用 | 手动打开应用，用会议号加入兜底 |
| 「我的会议」列表里找不到这个会 | 没开日历服务（Hybrid Calendar）时，转发来的邀请、别的站点的会、个人会议室会都不进列表 | 别等列表，直接用会议号手动加入 |
| 日历里的会不显示 | 设备语言与会议语言不一致；三星机型 S Planner 版本 ≤ 3.11.57 | 把设备语言临时改成与会议一致再重开应用（看完改回来）；三星升级 S Planner 到新版 |

## 三、听不到声音 / 别人听不到你

- **你自己没声**：进会时选了「不连接音频」，或者音频压根没接上。点音频连接选项菜单，重新选「使用互联网进行音频」。
- **拨入用户的通病**：电话拨入后没输**与会者 ID**，你的声音在列表里是独立的「呼入用户」，应用里按静音管不到它；没 ID 就按 `#` 等人放行。要彻底摆脱这个坑，改用网络音频。
- **麦克风失灵**：安卓上常见是别的应用占着麦克风（录音机、语音助手），关掉再试；蓝牙耳机连了但没当通话设备用，去蓝牙设置里确认「通话音频」已启用。
- **全场声音变差**：官方说明过一个机制——只要有一个人用不支持宽带音频的设备入会，**全场音频都会被降级，且不会有任何提示**。这不是你设备坏了，人齐后质量自己会回升。
- **切后台就断声**：官方移动端已知问题里提到，用**拨入/回拨**方式接音频时，离开应用会被断开；留在应用里别切走，或改用网络音频（切后台能保持连接）。锁屏也被断是省电策略，见第四节。
- **拨入链接点不开**：从日历或邮件里点「仅音频拨入」的号码链接，部分机型没反应——系统电话应用传不了拨入号和会议号。先进会用，再从「通过电话加入」的号码列表里手动拨。
- **找不到「使用互联网进行音频」这个选项**：官方说明是设备不在其 VoIP 支持范围（多为老机型、低性能处理器），这时仍能用电话方式接音频，只是要接受拨入那一套（与会者 ID、等候区）。

## 四、锁屏或切后台后被断开

视频会议是少数需要「一直活着」的后台应用，而省电策略的目标恰好相反——不给后台应用保活。被系统杀掉的表现是：锁屏一会儿回来会议没了、切去回微信回来音频断了。处理思路统一是**给这一个应用开后台白名单**：

- **华为/荣耀**（华为官方支持页给的两条路）：设置里搜「应用启动管理」，关掉该应用的自动管理并勾选「允许后台活动」；或搜「电池优化」，把它设为「不允许」优化。开会时还可以在多任务界面下拉卡片**加锁**，系统就不会清理它。
- **其他品牌**：都在「设置 → 应用 → 电池」一带，找「无限制 / 不优化 / 允许后台运行」这类开关给 Meetings 打开；厂商自己的省电模式（超省电、深度休眠名单）记得把会议应用排除在外。

入口名称随系统版本会变，找不到就搜设置里的「电池优化」。开会前顺手插上电源，配合白名单基本不会再被杀。

## 五、视频黑屏 / 画面卡

- 摄像头权限没给（见第一节第 4 条）；
- 带宽不够时官方策略是**先保音频**，画面自动降质或冻结，别反复开关视频，那只会更卡；
- 看桌面端共享的**视频文件**时只有画面没声音，或画面极小——这是移动端格式支持的已知限制（详见[会议中常用操作.md](会议中常用操作.md)第二节），不是故障。

## 六、以上都试过还是进不去

从这几步收尾：

1. 让发起人重发一份**完整邀请邮件**（带会议号、密码、链接的那种），排除口头传话的错漏；
2. 确认会议用的平台——如果对方的会跑在新版 Webex（Webex Suite 平台）上，经典 Meetings 应用可能进不了，按官方建议装新版 Webex 应用再试；
3. 公司自建站点（CWMS 2.6 及以上）进不去会，官方给的绕法是**先登录应用再点加入**，别用游客方式直进；
4. 版本太旧就换最新安装包重装一遍（数据不会丢，重新登录即可）；
5. 都不行就是会议侧的问题，联系会议主持人核对会议号、密码与开始时间；
6. 报错弹窗里带数字代码（`508`、`701` 这类）的，直接对[报错代码对照与处理.md](报错代码对照与处理.md)逐条处理。
