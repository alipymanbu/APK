# AndWobble 常见问题与解决方法

> 本篇汇总 AndWobble 用起来最容易卡住的几类问题：设不上壁纸、没有摆动效果、重启后失效、闪退卡顿、分享失败、旧版积分转移。

## 一、设不上动态壁纸

先查权限。到 **设置 → 应用 → AndWobble → 权限**，确认「照片 / 存储」已允许——读不了图，设壁纸这一步就无从谈起；「设置壁纸」的授权要在弹窗出现时点允许，之前若点过拒绝，也在同一页里改回来。

权限没问题仍设不上，就换个角度验证：换一张图重做一遍完整流程（导入 → 画区域 → 保存 → 设为壁纸），能定位是图的问题还是流程漏了某步。

## 二、选完图没有摆动效果

按顺序查三处：

1. **画没画区域**——效果只作用在你涂抹出的摆动区域上，没画区域整张图都是静态的；
2. **重启应用**再进一次，个别情况下渲染没起来，重开就恢复；
3. **换一张图**试——问题只出现在某张图上，多半是那张图本身尺寸或格式特殊。

## 三、摆动区域点不动、拖不动

点按、拖动、捏合只对**已绘制且被选中的区域**生效。先确认当前处于编辑状态、手指落在区域范围内；不行就把原区域删掉，重新画一块、拖动缩放一次。换了操作方式仍然毫无反应，换一台设备装同版本试一下，能区分是兼容性问题还是操作问题。

## 四、重启手机后壁纸变回静态

部分机型的省电策略会清掉常驻的后台服务，动态壁纸恰属此类。逐项试：

- 重新进入系统壁纸设置，**再选一次** AndWobble 的动态壁纸；
- 在系统设置里给 AndWobble 关掉电池优化 / 允许自启动（各机型入口不同，搜「自启动」或「电池优化」）；
- 仍频繁复现，说明该机型对动态壁纸服务限制较狠，日常用静态、想看效果时再切回来更省心。

这组开关同时也影响耗电——保活与省电的取舍见[动态壁纸耗电与省电设置.md](动态壁纸耗电与省电设置.md)第五节。

## 五、闪退或卡顿

从轻到重试：

1. 清理后台，只留 AndWobble；
2. **设置 → 应用 → AndWobble → 存储 → 清除缓存**（别点「清除数据」，做了会丢做好的作品）；
3. 确认手机剩余存储充足——空间不足是老应用闪退的常见诱因；
4. 卸载重装。重装前不用找包，AndWobble 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/022bc6f3eebb](https://pan.quark.cn/s/022bc6f3eebb)，转存下载即可。

## 六、分享或发布作品失败

分享分两种路径：发布到 AndWobble Library（应用内的公开图库），以及把图库作品的链接用短信、邮件发给别人。发不出去时先确认网络可用，再重开应用试一次；发布到公开图库属于上传行为，网络不稳定时最容易中断，换个时段再发即可。不想用公开图库，作品保存到本地后用系统相册的分享功能发给好友，是更稳妥的路。

## 七、旧版的积分怎么转到新版

按官方说明：先用**旧版 AndWobble 应用**在 Credit Balance（积分余额）界面注册你的邮箱，再在新版应用里**登录同一个邮箱**，积分即可转移到新应用。手里还留着旧版且买过 Premium 的，同样按这条路走；新旧版本是两个独立应用，可以并存，不放心就先别卸载旧版，转完再删。

## 八、想换回普通静态壁纸

在桌面空白处长按 → **壁纸 / 壁纸与样式**（各机型叫法不同）→ 从相册或系统自带图库里选一张静态图，设为主屏和锁屏即可。换掉的瞬间 AndWobble 的壁纸服务就不再运行，不需要先卸载应用；你做好的作品仍留在应用里，之后随时能回来重设。换静态之前如果还在纠结耗电账，先看[动态壁纸耗电与省电设置.md](动态壁纸耗电与省电设置.md)第一节——查清是不是它耗的，再决定换不换。
