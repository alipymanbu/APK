## 一、先查账，再优化

动态壁纸会常驻渲染，但「感觉耗电」不等于「是它耗的」。先到系统电池页查账：**设置 → 电池 → 电池用量**（三星在「电池和设备维护 → 电池」，各机型叫法略有差异），按过去 24 小时排序，找 AndWobble。两个读法要弄对：

- 列表里的百分比是**占总耗电的比例**，不是占总电量——手机今天掉了 15%，某项标 22%，指的是那 15% 里的 22%；
- 点进条目看**前台 / 后台**拆分：壁纸类应用的后台占比天然偏高（它就是在后台画桌面的），真正有意义的对比是**换壁纸前后**这份榜单的变化。

拿不准就做个对照：先用静态壁纸记一天，再换回 AndWobble 用一天，使用强度接近时对比这两天的掉电。单看某一小时的体感偏差很大，别用它下结论。

## 二、多耗多少：把不同来源的数字并列放这

公开资料对动态壁纸额外功耗的说法差别不小，直接并列，不替你选边（均为各自机型与测试条件下的口径，截至 2026-09 查询，以自己手机的电池统计为准）：

| 来源口径 | 相对静态壁纸的额外功耗 |
| --- | --- |
| 中文机型问答（荣耀某机型实测） | 整机功耗约 +8%~12% |
| 中文机型问答（iQOO 某机型） | 日均电量约 +3%~5% |
| 英文壁纸类博客（泛安卓经验） | 优化良好的每天约 +2%~3%，复杂 3D / 视频类才明显 |

AndWobble 属于「小区域摆动」这类轻量效果，通常落在偏低一档；把幅度调大、区域铺满全屏，消耗就往上走。

## 三、AndWobble 这边能收的三档

按见效程度排，参数怎么调见[摆动效果参数调整.md](摆动效果参数调整.md)：

1. **摆动幅度调小**——影响最大的单项；
2. **频率调低**——每秒渲染的变化随之减少；
3. **关掉重力感应**——传感器不再常开读数。

三档全收还是「小幅 + 低频 + 关重力感应」，观感上仍保留主体会动的核心效果。

## 四、系统这边能动的

- **动态只给主屏，锁屏用静态图**：锁屏一天被点亮的次数远多于你主动看主屏，锁屏保持静态能把渲染时间砍掉一大截（这是动态壁纸的通用经验，不是 AndWobble 的专属设置）；
- **OLED 屏配深色素材**：自发光屏幕的黑色像素几乎不耗电，选图偏暗整体更省；
- 想长期保留画面又怕耗，有个折中做法：把做好的 AndWobble 壁纸**截屏存成静态图**设回去，风格保留、渲染开销归零（有用户在机型问答里这么建议，属于个人经验做法）。

## 五、保活与省电是反着来的

[常见问题与解决方法.md](常见问题与解决方法.md)第四节建议给 AndWobble 允许自启动、关电池优化——那是防重启后壁纸失效；省电思路又要把它的后台管起来。两边动的是同一组开关，按你的情况取舍：

| 你的情况 | 建议 |
| --- | --- |
| 重启后壁纸经常变回静态 | 允许自启动 + 关电池优化，先保住保活 |
| 壁纸一直正常，只是想省电 | 保持默认电池策略，靠第三节的应用内参数收着用 |
| 在意续航且有静态备选 | 直接换静态壁纸，想看效果时再切回来 |

换回静态壁纸的具体操作在[常见问题与解决方法.md](常见问题与解决方法.md)第八节；应用里的作品不会因为换壁纸而丢。
