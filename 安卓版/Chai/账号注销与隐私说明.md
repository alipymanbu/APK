## 一、注销账号的准确路径

官方隐私政策（Chai Research Corp.，2026-07-02 版）写明：所有用户都可以直接在应用内删除账号与关联的个人数据，路径是——

1. 登录你的账号；
2. 进入 **Profile（个人资料）**；
3. 打开 **Settings（设置）**；
4. 点 **Delete Account（删除账号）**。

这是永久删除，**不可撤销**。聊天记录、创建的角色都会跟着没，删之前先确认下面两节。

## 二、删之前必须做的两件事

1. **先取消订阅**。续费挂在你付款的应用商店账号上，不在应用里——不取消的话，账号没了订阅还在扣。取消路径见 [订阅价格与广告说明.md](订阅价格与广告说明.md) 第六节。
2. **确认你不再需要里面的记录**。删除后你无法再登录这个账号取回任何会话；还想留着，就只是退出登录（[怎么登录账号.md](怎么登录账号.md)），别点删除。

## 三、删完之后数据还留多久

官方隐私政策的口径：数据的保存期「不超过账号存续期，以及账号删除后五年」，此外为应对法律程序也可能按法定要求延长。也就是说：**删除 = 账号立即不可用 + 数据在保留期后清除**，不是点完那一秒就物理抹掉。

## 四、平时你的数据被怎么用

摘自官方隐私政策中与你直接相关的几条：

| 数据 | 用途 |
| --- | --- |
| 邮箱、关联账号信息 | 建账号所必需 |
| 聊天内容 | 保存在服务端用于维持会话；去除个人标识后也用于改进模型 |
| 设备与连接信息（IP、系统、访问时间等） | 保障服务运行与排障 |
| 广告 | 免费版向你展示广告；从广告下载的用户，部分使用数据会分享给广告合作方做投放归因 |

数据存储在美国。不想被用于广告的，可以在系统或商店侧限制广告跟踪；聊天里别主动写入真实姓名、住址、手机号等敏感信息——这是你自己能做的最有效的一层保护。

## 五、联系方式

| 事项 | 邮箱 |
| --- | --- |
| App 内问题、账号与隐私（App 隐私政策所留） | `hello@chai.ml` |
| Web 版问题（Web 隐私政策所留） | `support@chai-ai.com` |

发邮件写清你的登录方式、问题描述与已尝试的步骤，不要附密码或验证码。邮件之外，官方没有公开的电话客服渠道——凡是网上标着「Chai 客服电话」要你打电话的页面，都别信。
