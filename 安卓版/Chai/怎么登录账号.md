# Chai 怎么登录账号

> Chai 没有传统用户名密码，全靠第三方账号登录；本篇讲登录方式、换设备后怎么找回会话、登录失败怎么处理。

## 一、支持哪几种登录方式

按官方隐私政策的口径，你只能通过第三方账号进入应用，没有单独注册的用户名密码：

| 登录方式 | 说明 |
| --- | --- |
| Google | 最常用的一种，官方 FAQ 也以 Google 登录为例介绍新用户上手 |
| Facebook | 用 Facebook 账号授权 |
| Apple | iOS 上常见，安卓端是否展示以应用内实际界面为准 |

你只需要在启动页出现的选项里挑一个，跟着授权流程走完即可。

## 二、首次登录步骤

1. 打开应用，进入登录页。
2. 选一个你常用、并且确定以后不会弃用的账号方式（Google / Facebook / Apple）。
3. 跳转授权页 → 确认授权 → 自动回到应用，登录完成。

关键只有一条：**以后每次换手机、重装应用，都要用同一个方式登录**，否则你看到的会是一个全新账号。

## 三、换手机、重装后怎么找回

你的对话数据存在 Chai 的服务器上（官方隐私政策明确写了聊天记录会保存在他们的系统里），所以找回的唯一动作就是登录回原账号：

1. 在新手机上装好应用（见 [下载与安装教程.md](下载与安装教程.md)）。
2. 用**原来那个**登录方式登录。
3. 登录成功后，之前的会话会跟着账号回来；如果发现是空的，先确认登录用的 Google / Facebook 账号是不是选错了。

换过登录方式、或原来用的第三方账号本身登不着了，应用侧无法帮你合并或找回——只能从那个第三方账号入手（比如 Google 账号的找回在 `https://accounts.google.com/signin/recovery`）。

## 四、登录不上去的排查顺序

1. **先确认网络能通**。登录要连 Chai 的服务器，网络不通时授权页会卡住或报错——先按 [常见问题与故障排查.md](常见问题与故障排查.md) 把网络问题排除掉。
2. **确认第三方账号本身能登**。手机上先单独打开 Google / Facebook 应用或网页，确认那个账号登得进去。
3. **检查系统时间**。手机时间与网络时间差太多会导致安全连接失败，到 `设置 → 日期和时间` 打开自动确定。
4. **重新授权一次**。退出登录后重启应用，重新走一遍授权流程，往往能解决授权页缓存残留的问题。
5. **提示账号被停用/无权访问**：这不是网络问题，是账号侧的处置，处理办法见 [常见问题与故障排查.md](常见问题与故障排查.md) 第六节。
6. 以上都不行，按官方隐私政策留的联系方式发邮件：App 内问题发到 `hello@chai.ml`，写清你的登录方式、手机型号与报错原文，不要在邮件里附密码。

## 五、退出登录

在应用的个人资料（Profile）页里可以退出当前账号。退出前想清楚两件事：聊天记录跟着账号走、不跟手机走；如果你还想保留账号，**别顺手点注销**——注销是另一件事，见 [账号注销与隐私说明.md](账号注销与隐私说明.md)。
