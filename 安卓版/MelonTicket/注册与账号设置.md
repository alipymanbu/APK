## 一、先分清两个站，再决定走哪条路

Melon Ticket 对内对外是两套前台，注册门槛差别极大，先看你要买的演出挂在哪个站：

| | 全球站（Global） | 韩国站（韩国国内） |
| --- | --- | --- |
| 网址 | `https://tkglobal.melon.com/` | `https://ticket.melon.com/` |
| 语言 | 英、日、中、韩多语 | 韩文为主 |
| 注册要求 | 邮箱 + 密码，不需要韩国手机号 | 需要 Melon 会员，多数购票场景还要求「本人认证」 |
| 认证方式 | 部分演出要求护照认证 | 韩国手机号或 I-PIN 等韩国式实名认证 |
| 支付 | 以国际信用卡为主 | 韩国信用卡、无存折汇款、手机小额支付、KakaoPay 等 |

结论很直接：

- **人在海外、没有韩国手机号**：走全球站。全球站注册页（`https://gaccounts.melon.com/ticketGlobal/join`）只要邮箱和密码。
- **住在韩国、有 ARC（外国人登录证）和韩国手机号**：两个站都能用，韩国站的演出选择明显更多。
- **要先确认演出挂在哪个站**：售票平台由演出主办方决定，同一个艺人的巡演可能这场在全球站、那场只在韩国站。买票前以演出官方公告里写的售票平台为准。

安卓应用本身主要承载韩国站的购票流程，应用内下单需要 Melon 会员和本人认证；没有韩国手机号的话，海外用户购票建议直接用全球站网页端，具体以应用内实际提示为准。

## 二、全球站注册：每个字段都有硬规则

全球站注册页对字段的限制是写死在页面上的，填错会直接卡住：

| 字段 | 规则 |
| --- | --- |
| 邮箱 | 只接受指定域名：`gmail.com` / `qq.com` / `yahoo.co.jp` / `icloud.com` / `outlook.com` / `hotmail.com`（以注册页当时显示的名单为准） |
| 姓名 | First Name / Last Name 按护照上的英文拼写填，注册页明确写着**注册后不能修改** |
| 密码 | 8~20 位，须同时包含英文字母、数字和特殊字符 |

姓名这一栏值得单独强调：注册页的原话是「如果你的姓名与护照不一致，取票时可能出问题」。现场取票时工作人员会拿护照核对订单姓名，所以：

- 按护照机读区的拼写逐字填，不要用昵称、英文名缩写；
- 带音标符号的名字（如 `Chloé`）不要随手写成 `Chloe`——有用户反馈这类不一致在现场核验时造成过麻烦；
- 如果你在别的购票平台（如 NOL、YES24）也有账号，各平台的姓名拼写保持完全一致，多平台抢同一场演出时才不会乱。

填错已经提交了怎么办？官方口径是注册后不可修改。错得离谱（比如姓名颠倒）时，常见的补救做法是换一个邮箱重新注册一个账号、旧账号弃用；想保留原账号就联系客服处理（渠道见[常见问题与注意事项.md](常见问题与注意事项.md)）。

## 三、注册完成后建议马上做的几件事

1. **补一个接收通知的手机号**。注册流程会让你填手机号用于接收订票短信。不需要是韩国号码，有用户反馈填本国号码（如 +33、+86 开头）能正常收到确认短信。
2. **正式购票前一天登录一次**。确认密码没忘、账号没被风控，比在开票时刻发现登不上强得多。
3. **有粉丝俱乐部先购资格的，提前完成认证**。先购（선예매）需要在演出公告给定的认证期间内，用本人名义的 Melon Ticket 账号完成 FC 认证——公告通常要求账号姓名与粉丝俱乐部会员姓名完全一致，用别人名义的账号认证即使买到了票，入场核验也会出问题。第三方平台（如 Weverse）联动认证时，一个第三方账号只能绑定一个 Melon Ticket 账号；有用户观察到联动窗口经常只有 24~48 小时、错过无法补办，公告一出就办。
4. **部分全球站演出要求护照认证**。具体流程和判断方法见[常见问题与注意事项.md](常见问题与注意事项.md)，属于开票前就要办完的事。

## 四、韩国站账号与「本人认证」

韩国站的购票前提是 Melon 会员加本人认证（본인인증）。这一步用的是韩国运营商的手机实名体系或 I-PIN：

- 没有韩国手机号基本无法自行完成，这是海外游客在韩国站最大的门槛，多方攻略对此口径一致；
- 长期居住韩国的外国人，用绑定 ARC 的韩国手机号可以完成；
- 与其反复尝试绕过认证，不如先查清演出是否在全球站有售——没有韩国实名又只在韩国站开售的演出，个人渠道确实买不了。

## 五、注册环节的三个高频问题

| 现象 | 原因与处理 |
| --- | --- |
| 邮箱填了却提示不可用 | 域名不在官方接受的名单里，换名单内的邮箱（如 Gmail、QQ 邮箱） |
| 密码设了却过不了 | 检查是否 8~20 位、是否三种字符齐全 |
| 注册页填一半刷新后全没了 | 注册页有会话限制，中途关闭或长时间搁置要重填；一次性填完再提交 |
