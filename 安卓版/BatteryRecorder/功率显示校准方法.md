# 功率显示不准怎么校准

> 功率显示 0.00W、状态总是「未知 / 未充电」、总是没有记录文件 —— 这类问题基本都靠校准解决，本篇讲四个校准项分别管什么、什么时候动哪一个。

## 一、什么情况下需要校准

遇到下面任意一条，就该进设置页做校准了：

- **首次使用软件**（官方把这条列在最前）；
- 功率数值明显异常，和你对设备的常识对不上；
- 功率数值直接显示 **0.00W**；
- 「当前记录」状态总是显示**未知**或**未充电**；
- 总是无记录文件（列表里一直空的）。

校准错了会怎样，官方文档说得很直接：电流校准影响 App 内展示的功率换算结果，**显示口径不对，软件所有功能都将无法正常使用**；状态校准影响记录器对电池状态的判定，判定错可能导致**总是无记录文件**。所以这一步不是可选优化，是可用性的前提。

## 二、四个校准项分别管什么

入口：**设置页 → 「常规」分组**，你会看到四项：

| 配置项 | 管什么 | 什么时候动 |
| --- | --- | --- |
| 串联双电芯 | 匹配双电芯设备的显示换算 | 设备确实是串联双电芯才开；**不是就不要随意打开** |
| 放电也显示正值 | 只改展示的正负号，方便阅读 | 纯阅读偏好，不改采样逻辑，随便开关 |
| 电流单位校准 | 改变电流换算口径，**直接影响功率数值大小** | 功率明显异常、显示 0.00W 时调整它修正 |
| 电池状态校准 | 影响记录器对电池状态的判定 | 总是无记录文件、状态总显示未知/未充电时用 |

两句话记住分工：

- **数值不对（0.00W / 大得离谱）→ 动「电流单位校准」**；
- **状态不对（未知 / 未充电 / 没有记录文件）→ 动「电池状态校准」**。

## 三、操作顺序建议

1. 先确认服务真的起来了（首页有「当前记录」），见 [启动服务与开始记录.md](启动服务与开始记录.md) —— 服务没跑，校准无从谈起。
2. 进设置 → 常规，按上表对号入座改一项、回首页看一眼效果，**一次只动一项**。
3. 状态类问题修好后，记得回头确认记录文件开始正常产生（充电总结/放电总结里能看到新条目，见 [历史记录导出与图表操作.md](历史记录导出与图表操作.md)）。
4. 校准正常了再去看续航预测 —— 口径不对时预测同样是废数据，见 [续航预测数据不足怎么解决.md](续航预测数据不足怎么解决.md)。

**注意**：校准只影响展示与判定口径，不会改写已经采到的原始数据；也别把「放电也显示正值」当成修数据的手段，它只换正负号。如果校准后状态仍持续异常，可能是息屏/前台判断的兼容问题，见 [常见问题与兼容设置.md](常见问题与兼容设置.md)。
