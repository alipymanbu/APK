# 同名软件与版本怎么分辨

> 搜索结果里既有同名的 Windows 工具、也有功能介绍对不上的下载站页面，还有 MD5 不同的旧版本。本篇教你三两下认准哪一个才是这套。

## 一、先认准三个特征

拿到一个安装包，对上这三条就基本不会认错：

| 特征 | 值 | 说明 |
| --- | --- | --- |
| 包名 | `yangfentuozi.batteryrecorder` | 安装前系统会显示，装完也可在「应用信息」里核对 |
| 来源 | [github.com/Itosang/BatteryRecorder](https://github.com/Itosang/BatteryRecorder) | 开源仓库，Release 页的版本号与下载量都可查 |
| 功能 | 功率记录 + 续航预测 | 起服务、校准、看充放电图表 —— 不是「温度监控」软件 |

网盘里这份包的完整指纹（以 [下载与安装教程.md](下载与安装教程.md) 里的表格为准）：版本 `2.1.3-alpha719`、MD5 `3839A8DE7C635149DBD832A8F8A6D8F1`。

## 二、搜索结果里的三类坑（截至 2026-09 检索）

**同名不同物**：搜索时会撞见一个「专为 Windows 平台设计的电池记录工具」的介绍页 —— 那套描述（TXT/CSV 导出、低电量告警、电脑睡眠后续采）和本篇讲的安卓 App 不是一回事，页面上却挂着同一个名字。遇到描述「平台对不上」的，直接跳过。

**下载站文案与实际功能不符**：几家应用站把本软件介绍成「实时温度曲线、30 天历史回溯、开机自启动、Android 8.0+」的温度监控工具 —— 这些说法与开源项目的实际功能（功率记录、息屏记录、续航预测、Root/ADB 服务）对不上，多半是套模板生成的文案。**介绍文案不等于功能清单**，功能以官方使用文档 [battrec.itosang.com](https://battrec.itosang.com/) 为准。

**旧版本混在结果里**：常见的是 `v1.3.8-prerelease1`（3.46M），它的 MD5 是 `B4B69D2D286015D513C1A9C4709F4A4C`，与网盘这份完全不同：

| | 网盘这份 | 搜索结果里的旧版 |
| --- | --- | --- |
| 版本 | 2.1.3-alpha719 | 1.3.8-prerelease1 |
| 大小 | 3.67M | 3.46M |
| MD5 | `3839A8DE7C635149DBD832A8F8A6D8F1` | `B4B69D2D286015D513C1A9C4709F4A4C` |

想确认手上这份对不对，拿 MD5 一比就知道（怎么拿、装哪份，见 [下载与安装教程.md](下载与安装教程.md)）；想拿最新版，去官方仓库的 Releases 页，以官网当时显示为准。

**顺带一提**：下载站里的站内评分、下载量、用户评价数字各算各的、口径互不相通，参考意义有限，别拿它当选择依据。

## 三、装完还能再验一次

装好后进系统「应用信息」，看两条：

1. **包名**是不是 `yangfentuozi.batteryrecorder`；
2. 打开后首页是不是**「未连接服务」的功率记录界面**（要起服务才开始记录，见 [启动服务与开始记录.md](启动服务与开始记录.md)）。

对得上就是装对了。打开后功能和 [常见问题与兼容设置.md](常见问题与兼容设置.md) 里描述的设置分组（常规 / 服务 / 日志 / 预测）一致，也进一步说明没装错。
