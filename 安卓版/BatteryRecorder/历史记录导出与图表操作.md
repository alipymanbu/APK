## 一、历史记录从哪进

在首页点下面两个入口之一，进入对应的历史记录列表：

- **充电总结**：充电时段的记录；
- **放电总结**：放电时段的记录 —— 续航预测吃的就是这部分样本，删之前想想 [续航预测数据不足怎么解决.md](续航预测数据不足怎么解决.md) 里「至少 3 条有效记录」的门槛。

列表里的每条记录都带时间范围与统计信息，点内容区域就进详情页。

## 二、列表里的滑动操作

历史记录列表支持双向滑动，方向决定动作：

| 操作 | 效果 | 说明 |
| --- | --- | --- |
| **右滑**某条记录 | 导出 | 会让你选输出位置，记录以**文本文件**形式导出 |
| **左滑**某条记录 | 删除 | 删除后该条从列表移除 |

导出的文本适合拿去做长期对比或贴给别人看；删除不可恢复，且会减少预测样本，动手前确认这条确实不要了。

## 三、详情页里有什么

点开一条记录，详情页展示：

- 时间范围与时长
- 平均功率
- 电量变化
- 亮屏 / 息屏时长
- 功耗、电量、温度相关图表

## 四、底部图例怎么点

图表底部有一排图例，**前三个可以点击**，后两个只是颜色说明：

| 图例 | 点击行为 |
| --- | --- |
| **功率** | 循环切换：`原始曲线(Raw) → 趋势曲线(Fitted) → 隐藏` |
| **电量** | 隐藏 / 恢复电量曲线 |
| **温度** | 隐藏 / 恢复温度曲线 |
| 亮屏、息屏 | 不可点，只说明图表里对应色块的含义 |

实用技巧：**只想看某一条线时，先把其他图例点掉**。什么时候切功率曲线：

- 想看瞬时波动 → 停在 `原始曲线`；
- 想看整体走势 → 切到 `趋势曲线`；
- 图上太乱 → 把暂时不关心的曲线隐藏掉。

## 五、和预测、排查的衔接

- 记录能导出、能正常进详情，说明采集链路是通的；如果列表一直是空的，先查服务与校准，见 [启动服务与开始记录.md](启动服务与开始记录.md) 与 [常见问题与兼容设置.md](常见问题与兼容设置.md)。
- 放电记录攒够 3 条以上，首页预测卡片才会出结果，见 [续航预测数据不足怎么解决.md](续航预测数据不足怎么解决.md)。
