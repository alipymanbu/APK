## 一、这是个什么软件

你在找「手机电池到底怎么掉电、还能撑多久」的答案时，系统自带的电池页只给个百分比曲线，说明不了问题。BatteryRecorder 的做法是**把功率数据持续记下来**，再基于历史放电记录给你一个续航预测。它是开源项目，代码在 [github.com/Itosang/BatteryRecorder](https://github.com/Itosang/BatteryRecorder)，官方使用文档在 [battrec.itosang.com](https://battrec.itosang.com/)。

几个你会先碰到的事实：

- **开源、免费**，无内购无广告；发布渠道是 GitHub Releases 与 GitHub Actions 构建产物。
- **界面以中文为主**：早期版本只有中文，2026-07 的 2.1.6-alpha960 起加入了英文翻译（以官方仓库更新记录为准）。
- **它需要一个「服务进程」来采集数据**，装完 App 只是第一步，不启动服务什么都不会记录 —— 这是它和普通「电池管理 App」最大的区别，见 [启动服务与开始记录.md](启动服务与开始记录.md)。

## 二、安装包从哪拿、装完怎么开始

拿安装包最省事的入口是本篇头部那条 **BatteryRecorder 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/20551fc7dd73](https://pan.quark.cn/s/20551fc7dd73) —— 转存后在网盘里下载 apk，装完即可用。

本地留存的这份包的固定信息（**以它为准**，别拿网上搜到的最新版来对）：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.1.3-alpha719 |
| 包名 | `yangfentuozi.batteryrecorder` |
| 大小 | 3.67M |
| MD5 | `3839A8DE7C635149DBD832A8F8A6D8F1` |
| 系统要求 | 安卓 5.2 以上（以采集记录为准） |

安装步骤：

1. 下载 apk 后点开安装。安卓会提示「安装未知来源应用」，对这个包放行即可（包名 `yangfentuozi.batteryrecorder`，可对照上表核对）。
2. 装完打开，首页会提示「未连接服务」—— 此时它还不会记录任何数据。
3. 按首页提示选一种方式把服务跑起来，见 [启动服务与开始记录.md](启动服务与开始记录.md)；起服务前建议先看 [功率显示校准方法.md](功率显示校准方法.md)，校准不对记录也是白记。

**版本口径注意**：网盘里这份是 `2.1.3-alpha719`，官方 Releases 上的版本号（如 `2.1.5-prerelease1`、`2.1.6-alpha960`）常常比它新，两者不是同一个包。要把手上这份装起来用，以上表为准；要拿最新版就去官方仓库的 Releases 页下载，以官网当时显示为准。

**搜索时容易认错**：搜索结果里还混着同名的 Windows 工具、功能介绍对不上的下载站文案、MD5 不同的旧版本（如 `1.3.8-prerelease1`），怎么逐一排除见 [同名软件与版本怎么分辨.md](同名软件与版本怎么分辨.md)。

## 三、要留意的权限

安装时以及首次使用中，它会申请几类权限，都是有用途的：

- **查询已安装应用 / 请求安装包权限**：用于读取应用列表（预测里「排除高负载 App」要按应用名选）。第三方应用市场对它的扫描也提到这类权限「比一个记录工具的Core功能要宽」，你不放心可以自己在系统设置里核对。
- **通知权限**：服务跑起来后可以用「实时功率通知」常驻显示当前功率，不给通知权限这个功能就没了（Shell 通知被系统禁用时怎么办，见 [常见问题与兼容设置.md](常见问题与兼容设置.md)）。
- **无障碍（仅 App 启动方式需要）**：三种启动方式里只有最低配的「App 启动」依赖无障碍，见 [启动服务与开始记录.md](启动服务与开始记录.md)。

数据全部存在手机本地，不上传；历史记录可以手动导出成文本文件，见 [历史记录导出与图表操作.md](历史记录导出与图表操作.md)。

## 四、装完之后从哪开始

正常动线是：

1. **启动服务** —— Root / ADB / App 三选一，首页出现「当前记录」才算跑起来，见 [启动服务与开始记录.md](启动服务与开始记录.md)；
2. **校准** —— 首次使用先过一遍校准，功率不是 0.00W、状态不是「未知」，见 [功率显示校准方法.md](功率显示校准方法.md)；
3. **用起来** —— 充放电历史与图表见 [历史记录导出与图表操作.md](历史记录导出与图表操作.md)，预测出不来「数据不足」时看 [续航预测数据不足怎么解决.md](续航预测数据不足怎么解决.md)；
4. 出了别的毛病，先翻 [常见问题与兼容设置.md](常见问题与兼容设置.md)。
