## 一、先看网点再下单

GoFun 是指定网点借还，不能像共享单车那样随停随还。打开 App 后地图会显示附近网点：标「还」的网点可以还车，标「满」的网点车位已满。你可以在下单时同时选好还车网点；也支持异地还车（在别的网点还），部分情况会收额外费用，金额以下单页显示为准。

## 二、取车步骤

1. 在地图上点选车辆，查看车型、剩余电量/续航、费用预估；
2. 点「预约用车」，在规定时间内到达车辆位置（预约超时会失效，需要重新预约）；
3. 到停车场后按 App 导航走，或用「寻车」功能让车灯闪烁、鸣笛帮你定位；
4. 按提示拍车身照片上传（一般 3 张：左前 45°、右前 45°、正后方），车身上已有的划痕最好也拍进去留证；
5. 点「智能开锁」开门上车。

取车时若发现车内设备损坏或物品遗失，立即拍照上传并联系客服反馈，否则巡检或下一位用户报损时可能算到你头上。

## 三、行车中留意这几件事

| 情况 | 说明 |
| --- | --- |
| 电量低于 30% | 车辆会出提示音，仪表盘电量指针进红区，尽快补电或开回网点 |
| 开空调 | 空调会明显吃续航，规划里程时留出余量 |
| 低速提示音 | 车速低于约 30 km/h 时「滴滴」响是车辆的安全设计（提醒行人），不是故障 |
| 车内吸烟 | 不要，车内禁烟 |
| 半路没电 | 就近找充电桩补电；因未及时充电导致无法行驶的，救援是收费的 |
| 发生事故 | 先报警、报保险，再联系平台客服，按 [事故处理与保险理赔.md](事故处理与保险理赔.md) 的顺序处理，别私了别弃车 |

## 四、还车结算（七步）

1. 把车停进还车网点的指定区域；
2. 关闭大灯、空调、收音机；
3. 钥匙、行驶本、保单复印件归位放好；
4. 带齐随身物品；
5. 带走车内垃圾；
6. 关车窗、锁车门；
7. 回 App 点「立即结算」。

还车时按提示上传照片（含仪表盘），账单出来确认金额即结束订单。车内太脏或留有垃圾会影响下一位用户，可能被收清洁费，具体见 [计费规则与费用构成.md](计费规则与费用构成.md)。

结算时遇到账单异常、没弹出账单等情况，处理办法整理在 [常见问题与故障处理.md](常见问题与故障处理.md)。
