## 一、安装前先核对这几项

| 项目 | 信息 |
| --- | --- |
| 安装包版本 | 6.5.1（网盘内这一份的版本；官方可能已发新版，以官方发布为准） |
| 安装包大小 | 约 134.24 MB |
| 包名 | com.gvsoft.gofun |
| 系统要求 | Android 5.2 及以上（以安装包信息为准） |
| 开发者 | 北京首汽智行科技有限公司 |

手机剩余存储建议留出安装包体积两倍以上的空间，安装过程中会产生解压与缓存文件。

## 二、获取安装文件

1. 打开 [GoFun出行 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cd6d843fc23e)，把文件转存到自己的夸克网盘；
2. 在手机上用夸克 App（或网页版）找到转存后的文件，下载 APK；
3. 下载完成后点开 APK 开始安装。

## 三、安装步骤

1. 点开下载好的 APK 文件；
2. 系统提示「未知来源应用」或「禁止安装」时，按提示允许该来源安装（入口因手机品牌而异，一般在 设置 → 安全 或 设置 → 应用管理 里）；
3. 等安装完成，打开 App。

## 四、装不上怎么办

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包出现问题」 | APK 没下载完整 | 删掉已下载的文件重新下载，确认文件大小接近 134 MB 再装 |
| 提示存储空间不足 | 剩余空间小于安装所需 | 清理出足够空间后重试 |
| 手机里已有旧版但无法覆盖安装 | 版本来源不同导致签名不一致 | 先卸载旧版，再安装新包 |
| 安装到一半中断 | 省电策略把安装进程杀了 | 安装时保持亮屏前台操作，别切走 |

## 五、装好之后

首次打开会申请定位、相机、存储等权限：定位用于在地图上找附近网点与车辆，相机用于取还车拍照，建议逐项允许，否则后面的认证与用车环节会被卡住。权限给完就可以按 [注册认证与押金说明.md](注册认证与押金说明.md) 完成实名认证，再按 [取车还车操作步骤.md](取车还车操作步骤.md) 开始第一次用车。
