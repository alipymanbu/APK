# 转让票券给朋友

> 本篇讲怎么在 KKTIX App 里把自己名下的电子票转给朋友、朋友怎么接收、以及哪些情况转不了。

## 一、先确认这场能不能转

- 转让是**电子票券**之间的事：全家取票、邮寄、现场取票这类取票方式不适用。
- 每场活动开放转让的日期不同，有的临近演出才开 —— 以该活动页说明为准。
- **你和接收方都必须是 KKTIX 会员**；对方还没账号的，先注册并完成验证，见 [注册与购票付款流程.md](注册与购票付款流程.md)。
- 转让时你购票填的报名资料会同步显示在对方的票券里，不用他重新填一遍。

## 二、你这边：发起转让

1. App 首页 →「票券」→ 切到「进行中」的活动卡片，点进去。
2. 票券资讯页直接显示二维码，点**右下角「更多」按钮** →「转让票券」。
3. 记下生成的**票券编号**和**转让票券代码**，私发给朋友（别公开发到群里，拿到代码的人就能收走你的票）。
4. 发起后你自己的二维码**立即失效**；转错了或反悔，在同一位置点「取消转让」。

## 三、朋友那边：接收票券

1. 用他自己的 KKTIX 账号登录 App → 首页「票券」→「接收票券」。
2. 输入你给的**票券编号**与**转让票券代码**，核对活动名称。
3. 接收成功自动跳到票券资讯页，这张票从此在他账号里，二维码入口见 [电子票券二维码怎么用.md](电子票券二维码怎么用.md)。

## 四、几条硬规则

| 规则 | 说明 |
| --- | --- |
| 48 小时限时 | 接收方须在发起后 48 小时内完成接收，逾期就要重新发起转让 |
| 原码作废 | 转让一发起，你这边的二维码立刻失效 |
| 报名资料跟着走 | 购票时填的报名资料同步显示在接收方的票券信息里 |
| 可反悔 | 「更多」→「取消转让」，转让代码作废，票券恢复未转让状态 |

**一处口径冲突要留意**：官方客服公告的「注意事项」把「票券已显示二维码」与取票方式为全家取票、邮寄、现场取票的票券都列进了「无法进行转让」；而同一份公告的操作步骤，又让你在显示二维码的票券资讯页点「转让票券」。两处字面并不一致，遇到具体活动，以该活动页说明与客服答复为准。

## 五、什么时候转、转完检查什么

演出前提早转，别拖到当天 —— 场馆门口网络拥堵时再操作，容易卡在最后一步。转完让朋友当场登录、打开一次票券页，确认二维码能显示再各自出发。

转不了又去不了的情况，另一条路是退票，规则见 [退票退款规则说明.md](退票退款规则说明.md)；接收环节出问题的排查在 [常见问题与故障排查.md](常见问题与故障排查.md)。
