# SARGO 视频导出到电脑的方法

> 相机里的视频除了用 App 走 WiFi 传到手机，还有数据线连电脑、OTG 传手机两条路。大批量导出时后两条更快，本篇讲三种方式怎么选、怎么操作。

## 一、三种导出方式怎么选

| 方式 | 适合场景 | 前提 |
| --- | --- | --- |
| App WiFi 下载 | 挑几个片段发手机、发朋友圈 | 已按 [手机连接相机步骤.md](手机连接相机步骤.md) 连上相机 |
| 数据线连电脑 | 整卡素材导出、剪辑备份 | 原装数据线 |
| OTG 传手机 | 出门在外没有电脑，大量文件传手机 | 手机支持 OTG、OTG 线 / 读卡器 |

WiFi 下载方便但速度受相机热点限制，几十 GB 的素材不值得；整批导出交给数据线，应急用 OTG。

## 二、数据线导出到电脑

官网对每款型号都单独配了「电脑导出教程」，共同点是**需要使用原装数据线**——A 系还分触屏版与按键版两种流程，G 系触屏款（G20 / G21）另有对应教程。通用流程：

1. 用原装数据线把相机关机状态（或按教程指定的状态）连到电脑 USB 口；
2. 相机会被电脑识别成一个存储设备（或按屏幕提示选择「U 盘 / 存储模式」）；
3. 打开盘符，进 `DCIM` 之类的视频目录，把文件复制到电脑；
4. 复制完再拔线，不要在传输中途断开。

电脑不识别相机时，先换一个 USB 口、换回原装线再试——不少第三方线只能充电、不能传数据。

## 三、G10+ 可以直接当电脑摄像头

拇指相机 G10+ 官网另有「电脑摄像头使用教程」：连上电脑后可把相机当作网络摄像头使用，适合直播、网课这类需要外接机位的场景。其他型号没有这个模式的公开说明，能不能当摄像头以说明书为准。

## 四、OTG 传到手机

部分型号支持 OTG 直连：用 OTG 线把相机（或直接把相机的存储卡插进读卡器）接到手机，文件不经电脑直接进手机相册。两个注意点：

- **部分手机需要在设置里手动打开 OTG 功能**，搜不到设备时先去设置搜「OTG」；
- 传输大量视频时手机要保持供电，掉电快的手机插着充电线再导。

导出环节出了问题（识别不到设备、传一半断开），和连接类的排查思路相通，见 [连接不上常见问题.md](连接不上常见问题.md)；存储卡本身的读写问题则看 [存储卡与充电注意事项.md](存储卡与充电注意事项.md)。
