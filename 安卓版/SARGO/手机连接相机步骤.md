# SARGO 手机连接相机步骤

> 从相机打开 WiFi 到手机上看到实时画面，一共六步。山狗各型号（A 系、P10、G 系、T50）流程一致，差别只在 WiFi 名称的开头几个字母。

## 一、连之前先备齐三样

- 相机有电、能正常开机（电量低时相机可能不广播 WiFi 信号，先充满电再连）；
- 手机已装好 SARGO App，还没装的看 [下载与安装教程.md](下载与安装教程.md)；
- 手机的「网络加速 / WLAN 助理 / 双 WiFi 模式」已关闭（安卓机）。这条是官方教程明确要求的，不关的话相机热点会被系统当成「不可上网的 WiFi」自动切走。

## 二、六步连上相机

以下步骤按官方各型号教程整理：

1. **打开相机 WiFi**：相机开机后，快速连按两下按键，相机震动一次、亮起黄色（或绿色）灯，表示 WiFi 已开启；
2. **记下热点信息**：相机 WiFi 名称以型号开头，例如 P10 机型的热点叫 `P10***`、G10 机型的叫 `G10***`；默认密码是 `12345678`（改过就以改过的为准，说明书上也有标注）；
3. **App 里点「添加设备」**：打开 SARGO App，在首页点添加设备，App 会引导你进入下一步；
4. **去手机 WLAN 设置连相机热点**：退出 App 不会打断流程 —— 到手机的 WLAN 列表里找到相机热点名，输入密码连接。手机弹出「此网络无法访问互联网，是否使用」时，选「使用 / 仍要连接」，不要点取消；
5. **回到 App 进入设备**：WiFi 连上后返回 App，点进刚添加的设备，就能看到相机实时画面，在这里可以控制录制、调整拍摄参数；
6. **用完退出 WiFi**：再快速连按两下相机按键即可关闭 WiFi 模式，相机回到普通拍摄状态。

## 三、各型号热点名速查

| 相机系列 | 热点名形式（示例） | 默认密码 |
| --- | --- | --- |
| P10 | `P10***` | 12345678 |
| G10 / G10+ | `G10***` | 12345678 |
| A 系（A7 / A9PRO / A11 / A13） | 以型号开头的同名热点 | 以说明书为准 |
| T50（全景） | 以型号开头的同名热点 | 以说明书为准 |

热点名里的 `***` 是流水号，每台相机不一样，认开头字母数字就行。个别型号的默认密码可能与表中不同，以相机随附说明书或机身标注为准。

## 四、连上之后能做什么

进入设备后的实时画面只是第一步：在线回放相机里的录像、把文件批量下载到手机、对着画面拍照，这些操作都在 App 内完成，具体见 [实时预览与文件下载.md](实时预览与文件下载.md)。

连不上、画面卡、手机一直切网，直接对照 [连接不上常见问题.md](连接不上常见问题.md) 逐条排查，多数问题出在手机 WiFi 设置而不是相机。
