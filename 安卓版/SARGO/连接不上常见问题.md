# SARGO 连接不上常见问题

> 手机搜不到相机热点、提示无网络、画面卡顿、App 连不上 —— 山狗相机 WiFi 连接环节的高频问题都汇总在这，多数解决办法只是改一个手机设置。

## 一、手机提示「无网络 / 无法访问互联网」

连上相机热点后，手机几乎一定会提示「此网络无法访问互联网」。**这是正常现象，不是故障** —— 相机发出的 WiFi 只用于相机和手机之间传数据，本来就不通互联网。

此时要做的是：

- 弹窗选「使用 / 仍要连接」，不要点取消；
- 不要切换到其他网络、也不要插回 SIM 卡流量，一旦手机切走，App 立刻断连；
- 用完相机 WiFi 想恢复上网，关掉相机 WiFi 或在 WLAN 列表切回家里的网络即可。

## 二、实时画面卡顿、掉帧

官方给的对应办法：**关闭手机的流量数据 / 蜂窝数据**再连。手机同时在两条网络之间摇摆时，视频流会受影响，只留相机 WiFi 这一条通道就顺了。

配合检查两点：

- 手机离相机别太远，隔几堵墙时信号会明显衰减；
- 确认「网络加速 / WLAN 助理 / 双 WiFi 模式」已关闭（见下一条）。

## 三、安卓机：热点被自动切走、连不稳

安卓手机的「网络加速」「WLAN 助理」「双 WiFi 模式」会在检测到当前 WiFi 不能上网时，自动切换到另一条可用网络 —— 而相机热点恰恰就是「不能上网」的，于是被系统反复切走。

处理：进手机设置，把这三类功能全部关闭，再重新连相机热点。不同品牌叫法不同（华为叫 WLAN+，部分机型叫双通道网络加速），认准「网络加速 / 智能切换」类的开关即可。

## 四、华为 / 鸿蒙手机：App 装不上或装完异常

华为手机需先关闭纯净模式的增强防护再安装 App：**设置 → 系统和更新 → 纯净模式 → 关闭增强防护开关**。装完如果连接环节还有问题，先确认这一步确实做了，再按本篇其他条目排查。

## 五、手机搜不到相机热点

按顺序核对：

1. **相机 WiFi 是否真的开了**：开机后快速连按两下按键，相机震动一次、亮黄（绿）灯才是打开成功，只按一下是开始录制；
2. **热点名认对没有**：热点以型号开头（如 `P10***`、`G10***`），完整名称每台相机不同；
3. **离近一点**：相机 WiFi 覆盖距离有限，贴近到几米内再看列表；
4. **重启相机再试**：关机重开后重新双击按键开 WiFi；
5. **重启手机 WLAN**：关掉再打开手机 WLAN 开关，等列表刷新。

## 六、看指示灯和震动判断相机状态

排查「连不上」之前，先弄清相机现在处于什么状态。以下以 G10 系列说明书为准（其他型号灯效细节以各自说明书为准）：

| 你看到的 | 相机实际状态 |
| --- | --- |
| 长按后震动两次、蓝灯长亮 | 开机成功 |
| 短按后震动一次、蓝灯闪烁 | 正在录像（此时按两下才切 WiFi，注意先停录） |
| 快速连按两下、震动一次、黄（绿）灯亮 | WiFi 已打开 |
| 蓝灯 + 黄（绿）灯同时长亮 | WiFi 已被手机连上 |
| 红灯长亮 | 正在充电；红灯熄灭 = 充满 |
| 震动两次、红灯快闪 10 下后关机 | 电量耗尽自动关机，先充电 |
| 震动五次、红灯快闪 10 次、约 10 分钟后自动关机 | 没插卡或卡错误——不插卡相机不会一直开着 |

「WiFi 开了但手机搜不到」最常见的原因，其实是对应到了上表的第 2、7 行：相机在录像中、或没插卡处于即将关机状态。对着表确认灯效，再回到第五条排查。

## 七、密码不对、连上又掉

- 相机热点默认密码是 `12345678`，输错会一直要求重输；改过密码的以改过的为准，说明书上有标注；
- 连上后频繁掉线，多与手机「智能切网」有关，先做第三条的设置关闭；
- 热点彻底连不上且排除以上原因，把相机恢复出厂或联系售后处理。

## 八、相机死机、没反应

官方教程明确：使用中出现死机，**按复位键重启**即可（P10 这类可拆电池的机型也可以拔出电池再装回），此操作不影响机器性能。复位后重新走一遍 [手机连接相机步骤.md](手机连接相机步骤.md) 的六步流程。

## 九、这些现象都不算故障

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 连 WiFi 后提示无网络 | 相机 WiFi 本来就不通互联网 | 选「仍要连接」，别切网 |
| 画面卡顿 | 手机流量与相机 WiFi 抢通道 | 关闭流量数据 |
| 热点突然消失 | 相机 WiFi 被手动关闭或没电 | 重新双击按键开启 / 充电 |
| 下载大文件很慢 | 走的是相机直连通道，速度有限 | 换数据线导出到电脑 |
| 录像中途自动停、提示卡错误 | 存储卡速度不够或没格式化 | 换高速卡并在相机里格式化 |
| 用一会儿机身发烫 | 连续录像的正常发热 | 不影响使用，注意散热即可 |
