# TagInfo 可以写卡吗

## 一、直接回答：不能，它就是个只读工具

TagInfo 里没有任何「写入标签」的入口——这不是版本问题，而是应用定位：它是**读取与分析工具**。想往标签里写内容，用 NXP 官方的另一款应用 **NFC TagWriter**（与 TagInfo 同为恩智浦出品）。开发者圈里的常见搭配就是「TagWriter 写、TagInfo 读回来验」。

## 二、读与写的分工对照

| 你想做的事 | 用哪个 |
| --- | --- |
| 读出标签内容（NDEF）、芯片型号、存储布局 | TagInfo（本篇讲的这个） |
| 校验芯片原厂真伪 | TagInfo，见 [原厂真伪校验怎么用.md](原厂真伪校验怎么用.md) |
| 导出分析报告、回看扫描历史 | TagInfo |
| 往标签写文本 / 网址 / 联系人 / Wi-Fi 配置 | TagWriter |
| 擦除、格式化、写保护标签 | TagWriter |
| 复制一张空白标签的内容到另一张 | TagWriter（仅限你自己的、未加密的标签） |

## 三、写完之后用 TagInfo 验收

1. 用 TagWriter 把内容写进你自己的空白标签（写入向导里选数据类型，按提示贴近手机完成）。
2. 打开 TagInfo，把刚写好的标签贴上来扫一次。
3. 对照 [扫描结果怎么看.md](扫描结果怎么看.md) 第二节：NDEF 内容区能完整显示你写进去的内容 = 写入成功；显示为空或与预期不符 = 写入没生效，回到 TagWriter 重写。

这个「写完读回」的习惯也顺带解决了另一个问题：标签到底支持不支持写。读回来是空的、再写还是空的，多半是标签本身不兼容或已写保护——对照 [支持哪些NFC标签和交通卡.md](支持哪些NFC标签和交通卡.md) 的清单确认型号。

## 四、哪些卡永远写不了（预期管理）

- **加密卡 / 带安全机制的卡**：门禁卡、银行卡、交通卡这类，没有发行方密钥的工具既读不出内容也写不进去。任何正规手机应用都做不到，与用哪款软件无关。
- **已写保护的标签**：存储布局里锁定的区无法改写，除非先解除保护（部分标签的保护是不可逆的）。
- **只动你自己的卡和标签**：写入功能用来制作自己的标签（桌面开关、网址签、分享 Wi-Fi 的贴纸），别人的卡不要去动。

## 五、TagInfo 这边相关的只读能力

装了 TagInfo 之后你仍能做这些**不需要写入**的事：扫码看内容、看芯片与内存、跑原厂真伪校验、导出报告——覆盖了「这张卡是什么」的全部问题。写入需求出现时再装 TagWriter 即可，两者不冲突，可同时留在手机上。
