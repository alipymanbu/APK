## 一、先分清是哪种「读不到」

| 现象 | 更可能出问题的层次 |
| --- | --- |
| 贴上去完全没动静（无震动无提示） | 手机 NFC 没开 / 位置没贴对 / 卡不是 NFC |
| 别的 App 能弹「发现 NFC 标签」，TagInfo 里没结果 | 应用权限或版本问题 |
| 有震动、有识别，但内容区是空的 | 卡片本身加密（预期行为） |
| 有时行有时不行、距离要很近 | 天线对位、手机壳、金属干扰 |

对号入座后再往下走，别跳步——第一步就能解决的情况占大多数。

## 二、第一层：手机与系统

1. **确认 NFC 开关是开的**：下拉快捷面板看 NFC 磁贴，或进「设置 → 连接 / NFC」。部分机型还要把「NFC 付款 / 默认钱包」设为任意应用，读卡通道才生效。
2. **确认手机真有 NFC 硬件**：设置里找不到 NFC 选项的机型就是没有，装任何读卡 App 都没用。
3. **开关重开一次**：NFC 长时间使用后偶发异常，关掉等两秒再开，能解决不少「突然读不了」。
4. **重启手机**：前三步都试过仍无反应时做一次。

## 三、第二层：贴卡位置与配件

1. **找对天线位置**：多数手机 NFC 天线在背面摄像头附近，把卡贴在那一片，间距 1~2 cm，贴住不动 1~2 秒——扫卡不是「刷一下」，是要停住的。
2. **摘掉手机壳**：带磁吸环、卡槽、金属片的壳会明显衰减磁场。磁吸壳用户十有八九是这个问题。
3. **避开金属与磁性物**：卡片直接压在金属桌面上、和钥匙串贴在一起扫，磁场会被干扰；垫个非金属面再试。
4. **屏幕状态**：部分机型熄屏后前台应用被挂起，先亮屏打开 TagInfo 再贴卡。

## 四、第三层：卡本身

1. **确认卡是 13.56 MHz 的 NFC 卡**：门禁、公交卡大多符合；但老式 **125 kHz 的低频 RFID 卡长得一模一样、完全不兼容**——这种卡贴多少次都不会有反应，是排查里最常见的一种「不是故障的故障」。
2. **卡坏了**：同一张卡换台手机也读不出，基本可以判断卡的问题，与应用无关。
3. **能识别但内容为空**：对照 [扫描结果怎么看.md](扫描结果怎么看.md) 第三节——加密卡的应用区本就不开放，属于预期，不算读取失败。
4. **能读出芯片但查不到余额**：见 [支持哪些NFC标签和交通卡.md](支持哪些NFC标签和交通卡.md) 第四节，多半是该卡系统没开放，不是你的操作问题。

## 五、第四层：应用本身

1. **权限**：首次启动时如果拒绝了 NFC / 相关权限，去「设置 → 应用 → TagInfo → 权限」里补开。
2. **重装**：结果页反复闪退、扫描页卡死时，卸载后从 [taginfo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/15e32b7370fe) 重新下载安装；装前可核对 MD5（见 [下载与安装教程.md](下载与安装教程.md) 第二节）确认包完整。
3. **多个读卡应用冲突**：手机上装了多款读卡/写卡 App 时，系统可能把标签事件分发给别的应用。先只留 TagInfo 在前台测试。

## 六、一个通用的分层判据

拿一张**已知能读的卡**（比如自己刚写过内容的 NTAG 贴纸）当基准：基准卡也读不到 → 问题在手机侧（第一、二层）；基准卡正常、目标卡不行 → 问题在卡（第三层）；基准卡偶尔灵偶尔不灵 → 大概率是对位与配件（第二层）。用这个判据可以把排查范围一次砍掉一半。
