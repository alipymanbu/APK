# 地图模式与传送怎么用

## 一、先进到地图

存档能列出来了（列不出来先看 [存档读不到怎么办.md](存档读不到怎么办.md)），点存档条目就进俯视地图。几个高频手势先记下：

| 操作 | 效果 |
| --- | --- |
| 双指缩放 / 拖动 | 放大缩小、平移地图 |
| 点击地图上任意一点 | 显示该处方块坐标 |
| 长按地图某处 | 呼出该位置的操作菜单 |
| 从屏幕左缘右拉 | 拉出侧边栏（模式、功能入口都在这） |
| 底部「+」号 | 打开功能按钮（含创建超平坦世界入口） |

地图只画**已保存**的地形，没探索过的区域是空白，不是出错。

## 二、有哪些地图模式

侧边栏里切换叠层，常用的几类：

| 模式 | 你看到什么 | 典型用法 |
| --- | --- | --- |
| 主世界 / 下界 / 末地 | 各维度的地表俯视图 | 找结构、看整体布局 |
| 洞穴 | 地表以下的洞穴走向 | 找洞、规划矿道 |
| 史莱姆区块 | 高亮会刷史莱姆的区块 | 想挂机刷史莱姆就在这建场 |
| 生物群系 | 各群系分布着色 | 找特定群系（蘑菇岛、丛林等） |
| 高度图 | 地形高低配色 | 看山脉、洼地走势 |
| X光 / 光照等 | 矿物、光照分布类视图 | 找矿、找暗区 |

不同游戏版本下部分叠层的数据完整度不一样，显示不全时先确认游戏版本，别当成工具坏了。两个具体例子：

- 1.9.4 的更新说明把**下界群系**支持标为「实验性」—— 下界地图只画出一部分、群系着色对不齐时，先按这个预期看问题；
- 老版本说明里提过：游戏 1.1 那个时期，**光照（Light）视图不受支持、下界地图只部分支持**（当时游戏的优化限制了能读到的数据）。你的游戏版本越新，这类缺口越可能换个位置出现。

## 三、标记与网格

- 地图上会标出**生物、出生点、玩家、自定义标记**的位置；
- **箱子标记默认是关的** —— 在标记过滤里手动打开，世界箱子多时全开会很乱；
- 网格（区块边界线）可开关，判断区块范围、对齐史莱姆区块时打开它更直观；
- 标记整体可以切换显示/隐藏，截图前关掉能拿到干净的图。

## 四、看坐标并传送

1. 点地图上任意一点，弹出该点坐标；
2. 用传送功能把**本地玩家**直接移动过去 —— 不用走过去、不用敲 `/tp` 指令；
3. 传送改的是存档里玩家的位置数据，回到游戏加载该存档就生效（改完记得保存，见 [区块查找替换与重置教程.md](区块查找替换与重置教程.md) 的保存说明）。

传送前留意落点：传到高空会摔、传进密闭岩层会闷在里面，先用洞穴模式或高度图看一眼周围再传。

## 五、截图与全屏

地图有沉浸（全屏）模式，用来截整张世界图；配合上面说的「隐藏标记、关网格」，导出的就是一张干净的全景图。需要把地图或结构数据导出成图片/文件分享，也在地图界面的相关菜单里。
