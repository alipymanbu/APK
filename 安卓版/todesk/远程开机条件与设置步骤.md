## 一、先看条件，缺一个就点不亮

远程开机（WOL，网络唤醒）不是 ToDesk 单方面就能做的事，官方列的条件凑不齐就别折腾了：

| 条件 | 具体要求 |
| --- | --- |
| 被控系统 | 目前只有 **Windows** 能被远程唤醒 |
| 局域网内有一台"辅助开机设备" | 被控电脑所在路由器下，要有**另一台设备**登录着 ToDesk 并保持在线——另一台电脑、Android 手机、iPhone 都行；用手机当辅助设备时，要在 App 设置里开启远程开机支持 |
| 被控电脑的硬件支持 WOL | 主板和**有线网卡**要支持网络唤醒；笔记本一般不支持，无线网卡通常不行 |
| 辅助设备显示在线 | 设备列表里那台辅助设备必须是"在线"状态，离线发不出唤醒包 |

思路是：唤醒包走局域网，由那台在线的辅助设备替你"喊"关机的电脑起床。所以辅助设备常年在线是前提——很多人拿一台旧手机或平板挂在家里当这个角色。手机端发起连接的日常操作见 [手机控制电脑连接步骤.md](手机控制电脑连接步骤.md)。

## 二、主板 BIOS：打开 WOL 开关

1. 开机时按 `Del` 或 `Esc` 进 BIOS；
2. 在 `Power Management`（电源管理）一类菜单里找到 WOL 相关选项，设为 `Enabled`；
3. `F10` 保存重启。

不同主板叫法不一，见到这些字眼任一个都是它：`Wake on LAN`、`Boot on LAN`、`Resume on LAN`、`Power on PME`、`Power On by PCI-E/PCI Devices`、`Power On by Onboard LAN`、`Resume by MAC LAN`。近五年生产的主板基本都带这功能，找不到就翻主板说明书。

以华硕主板为例的路径：Advanced mode → Advanced → APM Configuration → Power On By PCI-E 设为 Enabled。

## 三、系统里还要设两处

**1. 网卡属性（设备管理器里）**

右键开始菜单 → 设备管理器 → 找到有线网卡 → 属性：

- 「电源管理」选项卡：勾选「允许此设备唤醒计算机」；
- 「高级」选项卡：把「关机网络唤醒」「魔术封包唤醒」设为「开启」。不同厂商驱动的选项名有出入（如 `Wake up by Magic Packet`），认准 Magic Packet / 网络唤醒字样。

**2. 关闭快速启动**

控制面板 → 电源选项 → 选择电源按钮的功能 → 更改当前不可用的设置 → 取消勾选「启用快速启动」。Win10/11 上快速启动会让关机后网卡彻底断电，WOL 失效相当一部分是这个原因；如果你的电源选项里没有这项，就不用管。

## 四、关机几分钟后就唤不醒：路由器 ARP 绑定

典型症状：刚关机几分钟内能远程开机，过个十几分钟就不行了。原因是路由器的 IP-MAC 对应表有生存期，超时后唤醒包找不到目标。

处理：登录路由器管理界面，找「ARP 绑定」或「MAC 地址绑定」功能（小米路由器叫 IP 与 MAC 绑定，TP-Link 叫 ARP 绑定），把被控电脑的 IP 和 MAC 地址手动绑一条。绑完关机再久也能唤。

## 五、设置完连不上？按这个顺序自查

1. 被控电脑关机后，网卡指示灯还亮吗？——不亮多半是 BIOS 或快速启动没设对；
2. 辅助开机设备在线吗？——列表里它是离线状态就发不出唤醒包；
3. 被控电脑是不是笔记本或走 Wi-Fi？——换台式机 + 网线再试；
4. 唤醒成功后 ToDesk 连不上？——检查被控电脑有没有勾「开机自动启动」，以及固定密码设了没（见 [无人值守访问与安全设置.md](无人值守访问与安全设置.md)）。

其他连接类故障（能开机但连不上、访问被拒绝等）在 [连接失败与常见问题排查.md](连接失败与常见问题排查.md) 里按报错对照；客户端安装见 [下载与安装教程.md](下载与安装教程.md)。
