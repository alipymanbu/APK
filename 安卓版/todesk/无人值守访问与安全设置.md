## 一、什么时候需要无人值守

默认情况下，被控电脑显示的**临时密码每小时自动刷新一次**——你在手机上刚记下密码，回到座位它就换了，人不在电脑跟前就没法连。无人值守要解决的就是这件事：给被控电脑设一个**固定的安全密码**，再保证它开机后 ToDesk 自动运行、不休眠，你随时随地都能从手机连上去（日常连接方法见 [手机控制电脑连接步骤.md](手机控制电脑连接步骤.md)）。

典型场景：下班后或出差时连公司电脑、连家里那台挂机下载的机器、帮父母处理后，不指望他们帮忙点"同意"。

## 二、被控电脑上的四步设置

在被控的那台电脑上操作，前两步是保命配置，第三步是核心，第四步最容易漏：

| 步骤 | 在哪设 | 设什么 |
| --- | --- | --- |
| 1. 登录账号 | 客户端主界面 | 注册并登录 ToDesk 账号，无人值守必须在登录状态下用 |
| 2. 开机自启动 | 高级设置 → 基本设置 | 勾选「开机自动启动」，防止断电重启后连不上 |
| 3. 安全密码 | 高级设置 → 安全设置 | 设一个固定密码，验证方式勾「仅使用安全密码」或「都可以使用」 |
| 4. 关闭自动休眠 | 系统设置（不是 ToDesk 里） | 电脑一休眠就断网，无人值守直接失效 |

第 4 步具体操作：

- **Windows（Win10/11 为例）**：设置 → 系统 → 电源和睡眠，把「屏幕」和「睡眠」都改成「从不」（或足够长的时间）；
- **macOS**：系统设置 → 电池 / 节能器，在「电池」和「电源适配器」两个选项卡下都防止自动进入睡眠。

设置完从手机连一次验证：输设备代码 + 你刚设的安全密码，能进桌面就通了。

## 三、把「谁能连我」收窄：连接权限四档

安全设置里的「允许连接权限」下拉菜单有四档，从松到紧：

| 选项 | 效果 | 适合 |
| --- | --- | --- |
| 允许任意账号连接 | 任何知道设备代码 + 密码的账号都能发起连接 | 不推荐长期开 |
| 非同账号连接时需请求同意 | 自己的账号直接进；别人连要电脑前点同意 | 偶尔要帮别人看电脑 |
| 仅允许同账号连接 | 只有登录同一账号的设备能连 | 只有自己的手机和电脑在用，最省心 |
| 不允许任何连接 | 全部拒之门外 | 临时禁用远程入口 |

自己用的机器选「仅允许同账号连接」，等于把入口收成一条：只有你手机上的 ToDesk 能连。

## 四、再上两道锁

- **设备锁屏校验**：开了之后，就算对方答对了 ToDesk 密码，还要再输这台电脑的系统锁屏密码才能进桌面。公司电脑建议开。
- **二次验证保护**：在手机 App「我的」→「安全中心」里开启「移动端主设备安全验证」。开启后，新设备登录你的账号、或连接开了二次验证的设备，都要你的手机当场授权——你的手机就成了账号的总闸。手机丢了第一时间联系官方客服解绑主设备。
- **黑白名单**：安全设置里把信任的设备 ID 加进白名单（只有它们能连），或把可疑 ID 拉黑。
- **连接日志**：消息中心能看到登录通知和连接记录，绑定微信后异地登录、设备上线会推提醒。定期扫一眼，发现没印象的连接记录立刻改密码、收紧权限。

## 五、临时密码的刷新频率

不设固定安全密码的话，临时密码的更新频率也能调：安全设置 → 临时密码更新频率，可选「每次远控后」「每小时」「每日」「手动刷新」。临时给同事远程过一次之后想作废密码，选「每次远控后刷新」或手动刷新一次即可。

机器关机后想直接远程叫醒它，是另一套配置（主板 BIOS 和网卡设置），见 [远程开机条件与设置步骤.md](远程开机条件与设置步骤.md)；连不上的排查思路在 [连接失败与常见问题排查.md](连接失败与常见问题排查.md)，其中"无人值守突然连不上"八成是休眠或密码刷新两件事。还没装客户端的从 [下载与安装教程.md](下载与安装教程.md) 开始。
