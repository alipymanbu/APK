## 一、生成图片：怎么描述出图更准

Copilot 内置文生图能力（图像生成走的是微软 Designer 一路的技术）。你用文字描述想要的内容，它直接在对话里返回生成的图片。入口就是普通聊天框 —— 你把需求写成一段话发出去即可，例如「画一只戴眼镜的橘猫，在书桌上批改作业，卡通风格」。

描述里写清这几样，出图命中率明显更高：

| 要素 | 例子 |
| --- | --- |
| 主体 | 「一只戴眼镜的橘猫」（而不是「一只猫」） |
| 场景 | 「在书桌上，旁边放着书本」 |
| 风格 | 「卡通 / 水彩 / 像素风 / 写实照片风」 |
| 构图 | 「特写 / 俯视 / 左侧留白（方便加文字）」 |

生成不满意就改描述重发，别只点重新生成 —— 换掉其中一个要素（比如把「写实」换成「水彩」）通常比原样重试变化更大。生成数量、每日频次有限制，具体数值以界面当时提示为准，触顶时换一天再用。

**用图提醒**：生成结果可用于个人场景没问题；拿去商用前注意两点 —— 一是别让它模仿在世艺术家签名风格或真人肖像去「冒名」，二是别生成带他人商标、logo 的图拿去做宣传。涉及权利的边界以微软服务条款为准。

## 二、识别图片：传图提问的几种场景

输入框旁的图片/相机图标用来上传照片，你可以在发图的同时补一句问题。高频场景：

- **拍不认识的植物、虫子、商品**：「这是什么植物，怎么养」；
- **翻译**：拍外文菜单、路牌，「把图里的英文翻译成中文，保留原文顺序」；
- **解题与公式**：拍一道数学题，「解第二小题，给出步骤」；
- **截图诊断**：手机报错截图发过去，「这个报错是什么原因，怎么处理」；
- **提取信息**：拍手写笔记或表格，「把图里的表格整理成文字」。

两张小技巧：

1. **一次问一个明确的问题**。同一张图先问「这是什么」，答案出来再追问「那我该怎么做」，比一句话塞三个问题效果好。
2. **拍清楚关键区域**。手抖、反光、字太小的图，识别准确率会明显下降；文档类尽量正对拍摄、光线充足。

## 三、两个能力配合着用

识图与生图可以串成一个流程：先传图问「分析这张海报的配色和排版」，再接「按同样的配色风格，生成一张主标题为『周年庆』的新海报」。聊天上下文还在同一个对话里时，第二句不用重新描述风格。

生成图下载后保存在手机相册；传图只发送你选中的那一张，发之前留意截图里有没有不想给出去的隐私信息（验证码、聊天记录、地址等），发出去就收不回来了。
