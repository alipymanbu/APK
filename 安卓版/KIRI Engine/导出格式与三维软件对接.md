## 一、导出前先做两件事

导出的文件直接决定下游用起来顺不顺，导之前花两分钟：

1. **减面**。扫描出来的网格面数很高，直接导出的文件动辄上百 MB。用动态减面工具选一个目标面数档位；如果只是网页展示或预览，低档位完全够用，要雕刻修改就留高档。
2. **贴图分辨率**。导出时可以选贴图分辨率，最高支持 8K（以应用内选项为准）。3D 打印用不到贴图，选低档省空间；上引擎或渲染就按需求选。

## 二、格式怎么选

官方支持的导出格式包括 OBJ、STL、FBX、GLTF、GLB、USDZ、PLY、XYZ，按用途对号入座：

| 你要干什么 | 选什么格式 | 理由 |
| --- | --- | --- |
| 3D 打印 | STL | 切片软件（Cura、PrusaSlicer 等）的标准输入，只含几何不带贴图 |
| 导入 Blender | GLTF/GLB 或 OBJ | GLTF 单文件带贴图最省事；OBJ 兼容性最广但贴图是单独文件夹 |
| 进 Unreal / Unity 做资产 | FBX | 两个引擎对 FBX 支持最成熟 |
| iOS / AR 展示 | USDZ | 苹果生态的 Quick Look 与 AR 快速预览用这个 |
| 网页展示、发给别人看 | GLB | 单文件、体积小、浏览器直接预览 |
| 只要几何数据做后处理 | PLY / OBJ | PLY 还能带点云数据 |

记不住就记两条：**上打印机选 STL，其他情况先试 GLB**。

## 三、导出步骤

1. 在应用内打开完成的扫描项目。
2. 找导出（Export）入口，先选格式，再按需调整面数与贴图档位。
3. 提交后等服务器打包，完成后把文件存到手机本地，或直接分享出去。
4. 也可以在官方网页版里对同一账号的扫描项目做导出，电脑上直接下载，省去从手机传文件的步骤。

上传设置里还有一个「纹理平滑」（Texture Smoothing）开关：打开后能改善照片模糊区域的贴图、让纹理接缝更连贯，代价是整体锐度略降；拿模型做精确取材或专业用途时建议关掉它（官方 API 文档同口径）。

导出的模型文件是包含贴图的（OBJ 会把贴图放在配套文件里，注意别只拷一个 .obj 就走）。要不要把贴图一起带上，可以在导出选项里确认。

## 四、几个下游场景的对接要点

**Blender**：GLB 直接拖进窗口即可。扫描模型的贴图是照片投影生成的，做资产前通常要在 Blender 里重新展 UV 或烘焙，扫描件的 UV 不是为手绘贴图准备的。

**3D 打印**：STL 不带颜色，打出来是单色件。想打彩色件需要带贴图的格式（如 OBJ）并使用支持全彩打印的服务。扫描件直接打印还常栽在尺寸不对和破洞上，打印前的校尺寸与补洞步骤单独整理了一篇：[3D打印前的尺寸与破洞处理.md](3D打印前的尺寸与破洞处理.md)。

**游戏引擎**：面数记得先减到引擎能用的范围；扫描模型的 PBR 材质（粗糙度、法线这些贴图）属于 Pro 的 AI 材质生成功能，免费版导出的主要是颜色贴图，进引擎后质感要自己调。

**Sketchfab / Thingiverse 分享**：应用内支持直接把模型分享到这类平台，不想手动倒腾文件的可以走这条路。

## 五、一个特殊类型：3DGS 扫描的导出

如果你用的是 3D 高斯泼溅（3DGS）这类视频扫描模式（Pro 功能），产物和普通网格模型不一样：它记录的是场景的视觉效果表达，普通三维软件打开会是一团乱点或根本打不开，这属于正常现象而不是文件坏了。两种出路：

- 用支持 3DGS 的查看器或引擎插件看；
- 用官方提供的「含网格导出」选项把它转成普通网格（如 OBJ），转出来的模型保留了可编辑的几何，但视觉精细度不如原生 3DGS。

免费版用户接触不到这一节，可以先跳过，功能边界见 [免费版和Pro的区别.md](免费版和Pro的区别.md)。
