## 一、照片扫描的原理一句话

你绕着实物拍一圈照片，应用把照片传到官方服务器，由服务器算出 3D 模型再回传到手机。手机本身的性能不重要，重要的是**照片质量**——所以同一台手机，会不会拍，出来的模型天差地别。

## 二、动手前：挑一个容易成功的对象

第一次练手，选错了对象很容易怀疑人生。容易成功的：

- 表面纹理丰富的哑光物体：石雕、木雕、陶器、旧工具、编织物
- 拇指到手掌大小到半米左右的尺寸
- 不会动的、不透光的

第一次尽量别碰的：

- 透明物体（玻璃杯）、镜面或亮面反光物体（金属抛光件、釉面瓷器）——传统照片扫描对这类东西基本无解，官方另有一种专门的扫描模式（Pro 功能）来对付它们
- 纯白纯黑、表面几乎无纹理的物体
- 毛绒玩具、植物这类细节会晃动的对象
- 太大扫不全（整间屋子），或太小的（戒指内壁那种尺度）

## 三、拍摄手法（决定成败的一步）

拍照时绕物体走一整圈，让相邻照片之间有足够重叠。具体要点：

| 要点 | 怎么做 |
| --- | --- |
| 角度覆盖 | 先绕一圈平视拍，再蹲低仰拍一圈，最后俯拍补顶部；物体底部贴桌面扫不到，需要的话单独处理（见常见问题篇） |
| 照片数量 | 越多细节越好，免费版单次最多传 150 张；日常小物件 30~60 张通常够 |
| 对焦与曝光 | 每张都要清晰，别手抖；光线尽量均匀，阴天散射光或室内开顶灯都行，避免一边亮一边黑 |
| 背景 | 背景越素越好；应用有自动抠物体功能，能把背景从模型里剔掉，拍摄中甚至可以转动物体再接着拍 |
| 别变焦 | 走近拍，别用数码变焦 |

应用内还有手动相机控制（快门、ISO、对焦），光线复杂时比自动模式稳。

## 四、上传与等待

1. 拍完在应用内新建扫描项目，勾选刚才的照片（传错了的单张可以先删掉再传）。
2. 提交后就是等待云端处理。小项目通常几分钟出结果；排队时间随服务器负载浮动，高峰期会慢，免费用户排队优先级低于 Pro 用户，见 [免费版和Pro的区别.md](免费版和Pro的区别.md)。
3. 处理是排队制，中途可以关掉应用，回来看结果列表就行。

## 五、官方点名的三大失败原因

扫出来的东西缺角、破碎或者干脆报错，官方 FAQ 把原因归为三类，对着自查：

1. **覆盖不足**：算法靠相邻照片里表面特征的重叠来重建，角度变化太少就凑不够数据。对策就是第三节那套绕圈+换高度。
2. **特征点不足**：亮面、反光、纯色、透明、半透明的表面缺少可识别的独有特征点，照片扫描对这类材质先天无力，换对象或改用 Pro 的无特征物体扫描（见 [免费版和Pro的区别.md](免费版和Pro的区别.md)）。
3. **拍摄中动过物体却没开自动抠物**：转着拍、换位拍都允许，但上传时要把 Auto Object Masking（自动抠物）打开，服务器才能把主体从背景里剥出来，否则移动物体的照片会毁掉整个项目。

补洞与修复的具体操作在打印场景下讲得最细，见 [3D打印前的尺寸与破洞处理.md](3D打印前的尺寸与破洞处理.md)。

## 六、拿到模型之后

结果出来先在应用内 3D 视图里转一圈检查：

- **有破洞、缺一块**：多半是照片没覆盖到那个角度，补拍重扫一次比修模型快
- **边缘带了桌面或背景**：用应用内裁剪工具把多余部分切掉
- **面数太高**：导出前用减面工具降到合适档位，还能顺便选贴图分辨率（最高支持到 8K，以应用内选项为准）

模型满意后就要拿出去了：存档、进 Blender 或引擎、上 3D 打印机，各自的格式选择和导出步骤见 [导出格式与三维软件对接.md](导出格式与三维软件对接.md)。

## 七、网页版是条捷径

如果照片是用相机或无人机拍的，不用经手机中转：官方网页版支持从电脑直接上传照片做同样的照片扫描，同一个账号通用。手机拍的就地取材即可，相机拍的建议走网页版，省去把几十张原图倒进手机的功夫。
