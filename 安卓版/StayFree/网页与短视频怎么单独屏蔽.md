# StayFree 网页与短视频怎么单独屏蔽

> 官方把屏蔽分成两套：手机端管应用，浏览器扩展管网站，以及网页里那些具体模块（YouTube 的 Shorts、推荐流、评论区之类）。本篇讲扩展怎么装、网站限额怎么设、哪些效果只存在于扩展端。

## 一、先弄清楚哪套管哪一块

| 你想管的东西 | 在哪设 |
| --- | --- |
| 手机里某个 App 能用多久 | 手机端「用量上限」 |
| 电脑上某个网站能用多久 | 浏览器扩展的「网站限额」 |
| YouTube / TikTok / Instagram 等平台里的短视频、推荐流、评论区 | 浏览器扩展的「应用内屏蔽」 |
| 手机浏览器里访问了哪些网站 | 手机端只能看到「浏览器」一条，网站粒度在扩展端 |

一句话记住：扩展管浏览器里发生的事，手机端管装在手机里的应用。

## 二、装扩展并连上设备

1. 在电脑浏览器里打开扩展商店，搜 StayFree（Chrome、Edge、Firefox 都有条目，Safari 也有独立版本），点安装。
2. 首次打开扩展会引导你进入统计页。官方说明里强调跨设备看总量「不需要注册账号」也能实现，具体以扩展当前版本的引导为准。
3. 想让手机和电脑的数据合在一起看，进设置的「管理设备」把几台设备关联起来。
4. 关联好之后，首页总时长是合并值；取消关联就只算当前这台。

## 三、给网站设限额

1. 点扩展图标 → 设置 → 网站限额。
2. 填域名和每天的额度。比如想给 YouTube 定每天 30 分钟，就加一条 `youtube.com`、额度填 30 分钟。
3. 保存。到点之后，这个站点的标签页会被拦下来。

不打算一上来就把每日额度定死，可以用「当下限额」：每次打开该网站时先输入这一次允许多久，时间到就拦——官方使用说明把它单列为一节（Limits on the Go），适合还没想清楚该给多少额度的阶段。

## 四、网页里只屏蔽「刷不完的那部分」

扩展的「应用内屏蔽」可以按平台勾具体模块，官方列出的范围如下：

| 平台 | 可以单独隐藏的内容 |
| --- | --- |
| YouTube | Shorts、评论、推荐视频、首页、订阅、搜索栏、自动播放、信息卡、探索 |
| TikTok | 探索标签、直播标签、评论区、搜索框 |
| Instagram | Reels、故事、探索标签、评论、推荐帖子 |
| Facebook | 故事、Reels、商城 |
| X（Twitter） | 探索、热门话题、通知标签、列表、社群 |
| Snapchat | 故事、Spotlight、聊天 |

同一页还有「黑白模式」，把整站变灰，降低继续刷的吸引力。这套开关只在你装了扩展的浏览器里生效，不改变手机 App 自身的行为。

## 五、几个值得先动的设置

1. **忽略的网站**：把工作要用的站点（后台、文档、邮件）排除掉，日报里的数字才不会被工作占用拉高。
2. **后台播放音视频的标签页**：默认计不计入，各版本不一样；一边听歌一边干活的人，这一项直接决定时长看着准不准。
3. **关键词屏蔽**：命中关键词的页面自动拦掉，适合临时挡一类站点。
4. **自定义新标签页**：把新标签页换成统计面板，顺手就能看到今天用了多久。

## 六、扩展端要知道的几条边界

1. **已经打开的页面不会被强行关掉。** 到点之后新开标签页会被拦；停在原页面不动的，通常不会被打断。
2. **手机自带浏览器装不了扩展。** 想统计手机上的网站粒度，得在支持扩展的手机浏览器里装，普通浏览器看不到。
3. **两端的规则可能不同步。** 有用户反馈手机端与扩展端的拦截范围会出现不一致，遇到就分别核对两边的规则表。
4. **不装扩展就没有网站数据。** 手机端永远只显示「浏览器」这一条，这不是统计出错。

## 七、装了扩展之后页面变慢怎么办

扩展会往页面里注入脚本，少数机器上会出现视频加载变慢、自动播放异常这类情况。判断是不是扩展引起的，用这个顺序：

1. 开一个无痕窗口（扩展在无痕里默认不生效），打开同一个页面比一次。
2. 无痕下正常、普通窗口卡，基本可以确定是扩展这边引起的。
3. 回普通窗口，把扩展逐个关掉再试，锁定是哪一个；确认之后，考虑给管时间换个浏览器，或者只在需要管控的时段把扩展开着。
4. 如果每个窗口都卡，先看是不是标签开太多、浏览器缓存过期，清一次缓存、更新浏览器版本再试。
