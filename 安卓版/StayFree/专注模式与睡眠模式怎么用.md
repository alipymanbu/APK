# StayFree 专注模式与睡眠模式怎么用

> 用量上限管的是「用了多久」，专注模式和睡眠模式管的是「什么时候不许用」。前者是额度，后者是禁区，两者叠起来才比较难绕。本篇讲各自怎么建、什么场景用哪个、以及怎么不把自己锁死。

## 一、三种限制方式的分工

| 方式 | 触发依据 | 适合的场景 |
| --- | --- | --- |
| 用量上限 | 当天累计用了多久 | 某个应用一天只给 30 分钟 |
| 专注模式 | 到了设定的时间段 | 上午写东西的两小时不许碰社交和短视频 |
| 睡眠模式 | 到了设定的夜间时段 | 睡前 1 小时到起床之间，娱乐类应用不可用 |

专注模式和睡眠模式都是按时间来，不用手动开关：时间段开始自动锁，结束自动解除。

## 二、建一条专注计划

1. 首页左上角菜单 → 「专注模式」。
2. 点新建，先给这段时间起个名字，比如「写方案」。
3. 设时间段。多数版本支持工作日与周末分别设置，一段计划里也可以加多段。
4. 选要屏蔽的对象：可以只勾几个应用，也可以整类勾（社交、娱乐、游戏）。
5. 确认「定时生效」是开着的，保存。

配完之后当天就能验证：到了时间点，去点被勾中的应用，看是不是进不去。

## 三、睡眠模式怎么配

1. 菜单里进「睡眠模式」。
2. 设上床时间与起床时间，选生效的星期。
3. **定下这一段里允许留下哪些应用。** 电话、闹钟、地图、支付这类通常要留在外面，否则第二天早上闹钟不响、出门扫不了码。
4. 保存后第二天检查一次：到点是不是真的锁住，起床时间是不是真的解开。

## 四、三条合用建议

1. **同一时段别叠两条互相矛盾的规则。** 先只加一条，确认行为符合预期，再叠加第二条；一起建容易分不清是哪条在起作用。
2. **专注模式的屏蔽范围要比用量上限更狠。** 用量上限是留了额度的，专注模式是整段禁区；禁区里允许用的应用越少，越不容易顺手溜进去。
3. **工具类应用放进允许清单。** 地图、相机、支付、扫码这些留着，不然自己先被折腾一遍。

## 五、到点没生效先查这几处

| 现象 | 先查 |
| --- | --- |
| 时间段到了，应用照样能打开 | 通知与无障碍服务是否还在（见 [首次打开要开的权限.md](首次打开要开的权限.md)） |
| 到点锁住了，过一会儿自己解开 | 系统把 StayFree 的后台清了，按厂商设置加白名单 |
| 时间对不上、差一个小时 | 系统时区设置，以及每日重置时间的配置 |
| 电脑上锁住了、手机没锁 | 两端的规则各管各自范围，见 [网页与短视频怎么单独屏蔽.md](网页与短视频怎么单独屏蔽.md) |
| 锁住之后自己也被关在外面 | 用暂停开关临时放行，别删规则（见 [用量上限与提醒怎么设.md](用量上限与提醒怎么设.md) 第五节） |
