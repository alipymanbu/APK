## 一、认包名最快

安卓上判断「是不是同一个应用」最硬的依据是包名，跟名字、图标、版本号都无关：

| 判据 | 这个应用的值 |
| --- | --- |
| 包名 | `com.burockgames.timeclocker` |
| 官方站点 | [stayfreeapps.com](https://stayfreeapps.com/) |
| 官方用户说明 | [userguide.stayfreeapps.com](https://userguide.stayfreeapps.com/) |
| 商店条目名 | 应用商店里的「StayFree - Screen Time」 |

装完之后在「设置 → 应用 → StayFree」里能看到包名，和上表对不上，就不是同一套东西。搜索时还会碰上一个同名的女性护理用品品牌，两者毫无关系，看包名和域名就能分开。

## 二、开发者署名为什么有好几个

同一个产品在不同渠道的署名并不一致，查证时能同时碰到这几种：

| 看到的署名 | 出现在 |
| --- | --- |
| Sensor Tower | 官网与隐私政策、苹果应用商店条目 |
| ST Pulse | 部分安卓下载站标注的厂商 |
| Burak Kuyucu | 第三方安卓商店的开发者栏 |

包名只有一个，署名会随账号显示名变化，所以判断同一性别看署名，看包名。

## 三、「中文版」下载页怎么看

搜索里能看到大量「StayFree 中文版」页面，这类页面的共同点：

1. **它们不是官方发布渠道。** 官方入口只有官网和各大应用商店；中文界面是应用自身的语言选项，不需要专门的「中文版」安装包。
2. **包名写的是同一个，文件却各不相同。** 同一个包名被不同站点重新打包，文件大小与 MD5 对不上——这恰好说明它们不是同一份文件。
3. **版本号与文件经常对不上。** 页面标 v20.x，下载下来的可能还是旧包。核对办法就两步：看包名，再按 [下载与安装教程.md](下载与安装教程.md) 第二节核 MD5。
4. **别顺手装「加速器」「必装组件」之类的东西。** 装包只需要那个 `.apk` 文件。
5. **页面写「完全免费」的别当准话。** 免费档与订阅档的差别、怎么判断自己那一版，见 [免费版和付费版有什么区别.md](免费版和付费版有什么区别.md)。

## 四、官网之外还有哪些正规入口

| 平台 | 官方渠道 |
| --- | --- |
| 安卓 | Google Play（条目名 StayFree - Screen Time，包名 `com.burockgames.timeclocker`） |
| iOS / iPadOS / macOS | App Store 里的 StayFree 系列条目 |
| 电脑端 | 官网下载页给出的 Windows、macOS、Linux 三个桌面版本 |
| 浏览器扩展 | Chrome、Edge、Firefox 的扩展商店，Safari 另有独立版本 |

需要提醒的是：网盘里这一份是安卓安装包，版本号和商店当前版本常常不同（这份是 19.17.0，商店同期已是 20.x），取值一律以 [下载与安装教程.md](下载与安装教程.md) 第一节的表格为准。

## 五、桌面端与扩展端是不是同一套

是同一个产品的不同端，功能各有侧重：电脑端负责电脑上的应用使用统计，浏览器扩展负责网页统计与网页内的屏蔽。三端之间的数据可以关联合并，也能分开看。具体差异见 [网页与短视频怎么单独屏蔽.md](网页与短视频怎么单独屏蔽.md)。
