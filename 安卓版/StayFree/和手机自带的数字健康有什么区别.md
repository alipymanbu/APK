# StayFree 和手机自带的数字健康有什么区别

> 安卓系统自带的「数字健康与家长控制」也能看每日应用时长、给应用设定时器。本篇把两边各自能做什么、做不到什么列清楚，方便判断要不要再装一个，以及两边数字对不上时该信谁。

## 一、系统自带的那套能做什么

1. **用法**：进 设置 → 数字健康与家长控制，就能看到当天各应用的使用时长。
2. **应用定时器**：给单个应用设每日时限，到了之后该应用暂停、通知静音。
3. **就寝模式与专注模式**：到点让屏幕变灰、把打扰静音（这两项各机型的叫法与入口略有差异）。
4. **可用机型**：安卓 9 及以上大多数机型都有这一项；较早的系统或个别定制机型里没有，设置里搜不到就是没有。
5. **家长那条线是另一套产品**：Google Family Link 能在家长手机上设每日时长与就寝时间，它和数字健康不是一回事，别混着看。

## 二、系统自带做不到什么

| 做不到的事 | 说明 |
| --- | --- |
| 导出使用记录 | 界面里没有导出入口，只能截图或手抄 |
| 长期翻旧明细 | 逐日明细保留时间有限，具体能往前翻几天，以你机器上实际能翻到的最早日期为准 |
| 看到网站粒度 | 浏览器只算成一条记录，看不到具体网站 |
| 合并多台设备 | 只统计当前这台设备 |
| 只改网页里的某一块 | 单独隐藏短视频、推荐流、评论区这类开关，系统层没有 |
| 把某些站点从统计里剔除 | 不能把工作用的站点排除在统计之外 |

## 三、这套应用多出来的部分

1. **记录可以导出**成 CSV 或表格文件，拿去做汇总和长期对比，方式见 [使用记录导出与卸载前的准备.md](使用记录导出与卸载前的准备.md)。
2. **网站粒度**要装了浏览器扩展才有：能对单个网站设额度，也能只隐藏某个平台里刷不完的那几块，见 [网页与短视频怎么单独屏蔽.md](网页与短视频怎么单独屏蔽.md)。
3. **多设备关联**：手机、电脑、浏览器、手表的数据可以合在一起看，断开关联就只看本机。
4. **按分类设上限**：社交类一共 30 分钟这种设法，不必逐个应用设，见 [用量上限与提醒怎么设.md](用量上限与提醒怎么设.md)。

代价是它更依赖系统权限与后台保活，权限被动过、后台被清掉，统计和拦截都会出问题。

## 四、两边数字对不上时看哪里

结论先说：系统那套不受省电策略影响，但只有本机数据、不能导出；这套更细，但依赖权限和后台。逐条的口径差异与排查顺序在 [统计不准怎么排查.md](统计不准怎么排查.md) 第三节，需要对照具体条目时再看。

## 五、什么时候只用系统自带的就够

只是想知道今天用了多久、给一两个应用设个定时器，系统自带的那套不用额外授权、也不占后台，够用。需要跨设备合并、网站级统计、导出记录长期跟踪这几件事时，再加装一个更合适。两边都留着也没冲突，数字对不上时还能互相参照。
