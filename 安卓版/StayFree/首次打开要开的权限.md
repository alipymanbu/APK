# StayFree 首次打开要开的权限

> StayFree 的使用统计、到点拦截、提醒分别依赖不同的系统权限。权限没给全，典型表现是「数据一片空白」「时间到了不拦」「提醒不响」。本篇按顺序列出要开的四项、各自在哪开、不开会怎样，以及各家手机上后台保活怎么设。

## 一、四项权限，各管一件事

| 权限 | 在哪开（原生安卓的叫法） | 不开会怎样 |
| --- | --- | --- |
| 使用情况访问权限 / 有权查看使用情况的应用 | 设置 → 应用 → 特殊应用权限 → 使用情况访问权限 → 找到 StayFree → 允许 | 统计页看不到任何应用，或只有零星几条记录 |
| 无障碍服务 | 设置 → 无障碍 → 已安装的服务 → StayFree → 开启 | 网页类拦截不起作用，限额的可靠性也会下降 |
| 通知 | 首次启动时的弹窗，或 设置 → 通知 → 应用通知 → StayFree | 到点提醒不出现，弹窗式限额也弹不出来 |
| 电池与后台（自启动 / 省电白名单） | 各家名称不同，见第三节 | 后台被系统清掉，统计出现大段空白，限额到点不触发 |

无障碍服务这一项，官方在商店页写了用途：用来识别你当前在哪个网页，并据此执行你设过的网站拦截，相关数据按官方隐私政策处理。要不要授予，你自己权衡；不给的话，网页端的拦截基本指望不上。

## 二、首次打开的推荐顺序

1. **先给使用情况访问权限。** 没有这一项，后面所有页面都是空的。
2. **再给通知权限。** 首次弹窗直接点「允许」。已经点过「不允许」的，去 设置 → 通知 → 应用通知管理 → StayFree 里补上。
3. **最后开无障碍服务。** 系统会弹一段说明，读一遍再确认。
4. **回来验证。** 打开 StayFree 首页，等十几秒，看有没有出现按应用排列的时长列表。出现了，说明前两项已经生效。
5. **配一条最简单的限额做测试。** 挑一个不重要的应用，设 1 分钟上限，触发方式选「不准继续使用」，然后去用它。到点被拦住，说明权限与限额这条链路是通的；测完把这条规则删掉。

## 三、后台保活：各家叫法不一样

国产系统对后台的限制比原生安卓严，不设白名单，统计会断断续续。

| 品牌 | 大致在哪找 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → StayFree → 省电策略（选「无限制」），并允许自启动 |
| 华为 / 荣耀 | 设置 → 应用 → 应用启动管理 → StayFree → 关掉「自动管理」，手动勾上自启动与后台活动 |
| OPPO / 一加 / realme | 设置 → 电池 → 应用耗电管理，或 设置 → 应用管理 → StayFree → 允许后台运行 |
| vivo / iQOO | 设置 → 电池 → 后台高耗电 / 自启动，允许 StayFree |
| 三星 | 设置 → 电池与设备维护 → 电池 → 后台使用限制，把 StayFree 移出「休眠应用」 |
| 原生安卓 / Pixel | 设置 → 应用 → StayFree → 电池 → 不受限制 |

各家叫法都不一样，最省事的办法是在系统设置顶部的搜索框里直接搜「自启动」「后台」「省电」，搜到哪一项就改哪一项。

## 四、怎么确认权限一直有效

1. **系统升级后回头看一遍。** 部分机型升级会重置权限，四项里最容易掉的是使用情况访问和无障碍。
2. **别让第三方清理工具清掉它。** 装了「手机管家」这类工具，注意别把 StayFree 加进一键清理或深度睡眠名单。
3. **发现统计断档先排查，别急着卸载重装。** 卸载会一并带走应用内的历史统计和你配好的限额规则，排查顺序见 [统计不准怎么排查.md](统计不准怎么排查.md)。
4. **改过权限后重测一次限额。** 权限被动过之后，之前配的规则最好用第二节第 5 步的方法再验一遍。
5. **关于耗电与占用。** 官方在功能介绍里写的是不影响续航，第三方评测里也有类似说法；能确定的一点是，统计要想连续，它就得留在后台，所以各家系统的省电策略怎么设，直接决定这两件事（数据连续 / 省电）你更偏向哪一边。安装包本身 55.18 MB，装完之后还会随历史记录增长，长期用下来留出几百 MB 空间更稳妥。
