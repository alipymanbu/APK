## 一、导出什么格式

官方把「导出使用记录」列为功能之一，导出的文件是 CSV（部分版本可另选 Excel 表格）。打开后是逐条记录，一般能看到时间戳、应用包名与单次使用时长这几类字段——也就是「什么时候、哪个应用、用了多久」，具体以你导出的那份实际表头为准。

1. **手机端**：菜单 → 设置，找「导出」相关的一项，按引导选时间范围与格式。
2. **浏览器扩展端**：官方使用说明给出的路径是 设置 → 备份与恢复 → Export Data，导出的是一份包含使用统计与设置的文件。
3. **存哪**：导出的文件落在本机（下载目录一类）。想长期留着，导完自己再拷一份到网盘或电脑。

## 二、备份与恢复（扩展端）

官方使用说明里，扩展端有一节 Backup & Restore，四项操作的含义与风险如下：

| 操作 | 作用 | 注意 |
| --- | --- | --- |
| Export Data | 导出一份数据与设置的副本 | 建议平时就导，别等要换机才想起来 |
| Import Data | 把之前导出的文件导回来 | 换浏览器或重装扩展之后用 |
| Delete History | 清掉全部使用统计 | 不可撤销 |
| Reset to Default | 把设置恢复成初始状态 | 不可撤销，动手前先导出 |

手机端不一定有齐这几项，以你界面上实际存在的为准。手机端如果没有导入，换机时能带走的主要是使用习惯，历史统计带不过去。

## 三、换设备时能带走什么

| 想带走的东西 | 能不能带 | 怎么做 |
| --- | --- | --- |
| 历史使用统计 | 看版本，多数情况要手动导出 | 导出成 CSV 后自己留着，应用内的记录不会自动搬到新机 |
| 限额规则与专注计划 | 要重新配 | 卸载前先把规则清单抄下来，见下一节 |
| 多设备合并统计 | 可以 | 在「管理设备」里把新设备关联进来 |
| 密码 / PIN | 不跟着走 | 新机要重新设置 |

多台设备之间的合并与关联，具体表现见 [统计不准怎么排查.md](统计不准怎么排查.md) 第一节第 5 条。

## 四、卸载之前

1. **先导出或至少抄下关键设置。** 卸载会删掉应用数据：历史统计、你配的限额规则、密码都在里面，恢复不回来。
2. **把这几个参数记下来再卸**：设了哪些应用的上限、各是多少分钟；专注模式与睡眠模式的时间段；密码本身。重配一遍比想象的费事。
3. **只是想临时不用**：优先用暂停开关，或者把限额规则逐条关掉，不必卸载。
4. **想换版本**：先卸载旧版再装新版。直接拿不同来源的包覆盖安装，常见结果是「应用未安装」，判断手上的包是不是同一套东西见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
5. **准备把手机给别人用**：先把「管理设备」里的这台设备移除，再把系统权限收回，最后卸载。

## 五、导出的文件怎么打开

1. **CSV 用表格类工具直接打开**（Excel、WPS、在线表格都行）。用 Excel 打开全是乱码时，改用「数据 → 从文本 / CSV 导入」，编码选 UTF-8。
2. **表里一行是一条使用记录**，按时间先后排列。想算「某个应用一天总共用了多久」，用数据透视表按包名一列汇总时长最快；包名对照应用名，看一条就知道是哪个 App。
3. **别指望改表能改回应用里的数字。** 导出是单向的，两者不联动；删掉导出的文件也不影响应用内的记录。
4. **想长期跟踪就定期导。** 这份文件的用途是长期对比（比如按周看趋势），所以导出频率按你的复盘节奏来，一周一次或一月一次都行。
