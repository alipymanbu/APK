# StayFree 免费版和付费版有什么区别

> 搜索结果里两种说法都有：一边是「完全免费、无广告」，另一边是「有付费版、免费版功能受限」。本篇把两边的出处摆出来，给出判断自己那一版处于什么状态的办法，以及不想用了怎么退订。

## 一、三种说法，各自出自哪里

| 说法 | 出处 |
| --- | --- |
| 商店里标为免费，官方功能介绍里写明完全无广告，没有提订阅档位 | 官方商店条目与应用介绍 |
| 存在付费档：解锁更细的分析报表、主题、无广告体验，或「不限条数的限额」 | 若干第三方应用介绍页与聚合站的常见问题栏 |
| 核心功能免费：时长统计、应用锁定、专注模式、数据导出 | 若干中文介绍页的问答栏 |

这三种说法彼此不完全一致，也都不来自官方的价格说明页。**所以本篇不写价格，也不断言哪个功能一定要付费**：档位和功能边界会随版本、地区变化，以你自己设备上的显示为准。

## 二、怎么判断自己这一版

1. **看设置里有没有账户 / 订阅类条目。** 进设置找「账户」「订阅」「升级」一类入口，有的话点进去，页面上会写清当前档位与可选项目。
2. **看功能入口上的角标。** 限额条数上限、部分报表、主题皮肤这类功能，常被放在付费档，入口上会有锁或升级标记。
3. **两套说法的冲突就这样处理**：以你设备上实际看到的为准，官方说明与第三方说法不一致时不替任何一方下结论。

## 三、不想用了怎么退订

订阅类购买由商店代管，退订也在商店里操作，不在应用内部：

| 平台 | 退订路径 |
| --- | --- |
| Google Play | 打开商店 App → 点头像 → 付款和订阅 → 订阅，找到这一项取消 |
| App Store | 设置 → 点自己的 Apple 账户 → 订阅，找到这一项取消 |

取消之后，当前已付费的周期通常还能用到到期为止；退款不由应用处理，按商店的退款规则走。应用内如果也有「管理订阅」入口，点进去最终也是跳到商店同一个页面。

## 四、免费档大概够用到哪一步

按官方公开列出的功能清单，日常真正会用的几项——时长统计、给应用设上限、专注与睡眠模式、记录导出——都在基础能力范围内。可能撞到付费墙的，通常是后加的那几项：更细的分析报表、更多主题、限额条数上限。

更实际的做法是先按 [用量上限与提醒怎么设.md](用量上限与提醒怎么设.md) 配一条规则用一两周，撞到限制再决定要不要升；一上来就买，很难判断多出来的那几项自己会不会真的用。

## 五、付费与账号的关系

1. **跨设备查看不需要注册账号。** 官方说明里强调这一点，设备之间靠关联完成，所以即使不买付费档，多设备合并看统计这件事也能做。
2. **订阅一般绑账号或商店账户。** 换手机时，付费档能不能跟着走取决于当初的购买方式（应用商店内购还是账号内订阅），换机前先在旧机上确认一次购买凭证。
3. **卸载前先导出。** 无论免费还是付费，卸载都会带走本机的历史统计，步骤见 [使用记录导出与卸载前的准备.md](使用记录导出与卸载前的准备.md)。
