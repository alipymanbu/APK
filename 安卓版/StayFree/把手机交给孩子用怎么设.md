# StayFree 把手机交给孩子用怎么设

> 给孩子的设备配这套应用，重点不在看数据，而在「配完之后他改不动」。本篇给出一套可照做的顺序：权限 → 限额与时间段 → 密码保护 → 封住绕过的入口 → 定期检查。

## 一、先装好权限，再谈规则

权限没配齐，后面所有拦截都会时灵时不灵。使用情况访问、通知、后台白名单这三项必须做完，办法见 [首次打开要开的权限.md](首次打开要开的权限.md)。另外，孩子的手机上装的如果是国产系统，省电策略这一项尤其要注意，否则统计会断断续续。

## 二、配置顺序

1. **设每日上限。** 给娱乐类应用设「每天最多 30 分钟」，触发方式选「不准继续使用」——只提醒或只弹窗不阻断使用，起不到管控作用。做法见 [用量上限与提醒怎么设.md](用量上限与提醒怎么设.md) 第三节。
2. **设时间段。** 用专注模式或按日程阻断，把「放学后写作业的两小时」和「晚上 10 点以后」这两段封起来，做法见 [专注模式与睡眠模式怎么用.md](专注模式与睡眠模式怎么用.md)。
3. **给系统「设置」应用也加一条永久阻断。** 有一种做法是把系统设置一起锁住，避免从系统层面关掉权限或卸载；加之前先确认你自己不会被关在外面（先试一次还能不能进设置）。
4. **开密码或 PIN 保护。** 开启之后，改动限额、删规则都要先输密码。这一步是关键——不做的话，前面几条几分钟就能被改回去。
5. **定期检查。** 每周看一次：权限有没有被系统回收、后台有没有被清理、限额规则是不是还在。

## 三、几个会碰到的情形

| 情形 | 怎么处理 |
| --- | --- |
| 「作业要用这个应用」 | 单独建一条规则把学习类应用排除在外，而不是整段关掉限额 |
| 闹钟、电话被一起锁住 | 睡眠模式的允许清单里把电话、闹钟、地图留出来，别整夜封死 |
| 密码被猜到 | 换成与生日、门牌号无关的；密码另记一处，忘了只能重装 |
| 对方直接把应用卸了 | 这就是第 3 步要封入口的原因，只设限额不防卸载 |
| 自己也被锁在外面 | 用暂停开关临时放行（见 [用量上限与提醒怎么设.md](用量上限与提醒怎么设.md) 第五节），别删规则 |

## 四、别把它当唯一的管控手段

这套东西的定位是「自己管自己」的工具：查看要在设备上打开应用，规则也在设备上改，官方没有提供面向家长的远程面板。真要远程管，安卓那边还有 Google Family Link 这条线（家长端产品，与本机应用不是一回事），可以两边一起用：Family Link 管每日总时长与就寝，本机应用管得细一些——具体怎么分工见 [和手机自带的数字健康有什么区别.md](和手机自带的数字健康有什么区别.md)。

## 五、和孩子的约定比开关更重要

1. **规则一起定。** 单方面设限、被发现后偷偷改，最容易变成一场拉锯。把上限时间摆在桌面上谈一次，比事后加密码有用。
2. **给出替代方案。** 只堵不放，孩子会去找别的设备。把能看的时段、能用的应用留出来，规则才守得住。
3. **留一个申请口子。** 「考试周多给 20 分钟」这类调整预先说好条件，比临时解锁更不容易破例。
