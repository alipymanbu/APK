# StayFree 中文界面与桌面小组件怎么设置

> 装完是英文界面的，可以在设置里切到中文；今天用了多久，用桌面小组件扫一眼就行，不必每次打开应用。本篇给出语言切换路径、主题与小组件的位置。

## 一、切到中文

1. 打开 StayFree，点左上角的功能菜单（三条横线）。
2. 进「Settings / 设置」。
3. 找到「Customization / 自定义」这一类，里面有一项语言设置。
4. 在语言列表里选「中文」/「简体中文」。界面即时切换，不用重启。

不同版本的菜单层数与名称略有差别，找不到就把设置页逐项翻一遍，带 Language 字样的那一项就是。官方在浏览器扩展的语言列表里明确列出了简体中文；手机端多个教程给出的路径与上面一致。如果这一版界面里就是没有中文选项，说明该版本的界面还没包含中文，按英文菜单里相同含义的项去找也能操作。

## 二、不用专门的「中文版」安装包

中文是应用自带的语言选项，不是另一个安装包。搜索里那些标着「StayFree 中文版」的下载页，给的基本是同一个包名的重新打包件，文件大小和 MD5 往往和官方发布的不一致。认渠道的办法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 三、主题与外观

1. 设置 → 自定义，里面有主题选项。
2. 官方在不同平台的说明里给出的主题数量不一样（浏览器扩展端写的是 13 款，手机端早期说明写的是 5 款），以你装的那一版界面上实际列出的为准。
3. 主题只改配色，不改统计口径，也不影响限额规则。

## 四、桌面小组件

1. 长按桌面空白处 → 小组件 / 小部件。
2. 在列表里找 StayFree，选一个尺寸拖到桌面。
3. 小组件显示的是今日累计使用时间和用得最多的几个应用，具体展示哪些取决于你选的尺寸。
4. 添加之后数字长时间不变，多半是后台被限制了，按 [首次打开要开的权限.md](首次打开要开的权限.md) 加白名单。
5. 部分机型需要在桌面设置里允许小组件刷新，否则只在你打开应用后才更新一次。

## 五、手表上也能看

官方提供 Wear OS 版本，装到手表之后可以直接在腕上看到手机的使用统计，不用掏手机。手机与手表之间同样要关联设备，配好之后两边数字一致。官方对它的说明是「查看统计」，改限额规则还是在手机或电脑上改。

## 六、首页底部那句话

首页底部会显示一句鼓励少用手机的短句，属于展示内容，和限额、屏蔽都不相关；不喜欢看就往下翻过去，它不影响任何统计数字。
