## 一、这份安装包的基本信息

| 项目 | 这一份的情况 |
| --- | --- |
| 软件名 | StayFree |
| 版本号 | 19.17.0 |
| 包名 | `com.burockgames.timeclocker` |
| 安装包大小 | 55.18 MB（文件字节数 55,894,842） |
| 安装包 MD5 | `57BD335309B2C5FB39FDF5DDA5E8FF9D` |
| 适用设备 | 安卓手机 / 安卓平板 |
| 官方站点 | [stayfreeapps.com](https://stayfreeapps.com/) |

两点说明：

1. **版本号以本页表格为准。** 官方商店里同期已经是 20.x 一档（本文查证时为 20.12.0），这份是 19.17.0，两者不是同一版。搜索引擎上翻到的介绍页写的版本号，不必拿来跟手上的包对照。
2. **最低安卓版本各家说法不一致。** 官方商店页没有给出明确的系统版本门槛，第三方下载页给出的门槛从安卓 4.4 到安卓 11 不等、彼此矛盾，所以本篇不写具体数字。能不能装，以你点下安装包之后系统的提示为准；装不上就换一版更新的安装包再试。

## 二、从网盘取包并核对

1. 打开 [StayFree 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a9958a77bbe9)。手机、电脑都能打开，用夸克 App 操作更稳。
2. 点「保存到我的网盘」转存到自己账号下。转存之后，后续下载不再依赖原分享链接是否还在。
3. 下载到本地，确认文件名结尾是 `.apk`。
4. 核对 MD5，应当等于 `57BD335309B2C5FB39FDF5DDA5E8FF9D`。在电脑上下载的话，Windows 可以在文件所在目录用下面这条命令算一遍，文件名换成你实际下到的那个（文件名里有空格时整段用英文双引号包起来）：

```powershell
certutil -hashfile "你下到的文件名.apk" MD5
```

5. 对不上就删掉重下。安卓装到一半报「解析包错误」，多数情况是包没下完整或传输被截断。

## 三、安装步骤

这个包不从手机自带软件商店里装，安装时系统会拦一下，属于正常现象，不代表文件有问题。

1. 打开手机的「文件管理」，进 `Download`（下载）目录，找到刚下好的安装包，点它。
2. 弹出「不允许安装来自此来源的应用」时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要绕一层：设置 → 应用 → 特殊应用权限 → 安装未知应用，在里面找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」——进去之后它马上会要权限，先按 [首次打开要开的权限.md](首次打开要开的权限.md) 准备好再打开。

这个包不需要 root，也不需要连电脑，装法就是普通 APK 的装法。

## 四、装完先确认三处

| 要确认什么 | 从哪看 |
| --- | --- |
| 版本号是不是 19.17.0 | 设置 → 应用 → StayFree，看版本信息 |
| 有没有和别的同名应用装重 | 应用列表里搜 StayFree，看是不是只有一个、图标是不是同一个 |
| 该给的权限给上没 | 见 [首次打开要开的权限.md](首次打开要开的权限.md) |

版本号和第一节的表格对不上，多半是手机上还留着别的渠道装的同名应用，判断方式见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

还有一点要有心理准备：统计是从装上那一刻开始记的，装之前的使用不会被补算。所以装完当天打开只看到最近几小时的数据，是正常现象，第二天再看才是完整的一天。

## 五、装不上时先看这张表

| 现象 | 大概率原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 包没下完整、传输被截断 | 重新下载，按第二节核对 MD5 |
| 「应用未安装」 | 设备上已有同包名旧版，签名对不上 | 先卸载旧版再装。卸载会带走应用内的统计与设置，能覆盖安装就别卸载 |
| 提示不允许安装未知应用 | 系统的来源限制 | 见第三节第 2 步 |
| 装完图标找不到 | 装到了当前用户之外的空间 | 到系统「应用管理」里搜 StayFree，能找到就说明装成功了，从那里打开 |
| 打开就闪退 | 系统版本过低，或包在传输中损坏 | 换一台设备试，或重新下载原包后再装 |
| 装完统计一片空白 | 使用情况访问权限没给 | 见 [首次打开要开的权限.md](首次打开要开的权限.md) |
| 装完想先从旧手机把记录带过来 | 历史统计不一定能迁移 | 见 [使用记录导出与卸载前的准备.md](使用记录导出与卸载前的准备.md) |

## 六、网盘里这一份只有安卓包

同一个产品在别的平台是另外的东西，这个包里没有：

| 你想要 | 从哪拿 |
| --- | --- |
| 手机 / 平板 | 就是网盘里这一份安卓安装包 |
| 电脑端（Windows / macOS / Linux） | 官网下载页 [stayfreeapps.com](https://stayfreeapps.com/)，按系统选安装程序 |
| 浏览器扩展 | Chrome、Edge、Firefox 的扩展商店，Safari 另有版本 |
| 手表端（Wear OS） | 应用商店里的手表版本，用来在腕上直接看统计 |

三端的数据可以关联起来合并查看，做法见 [统计不准怎么排查.md](统计不准怎么排查.md) 第一节第 5 条。电脑端与扩展端各自管什么，见 [网页与短视频怎么单独屏蔽.md](网页与短视频怎么单独屏蔽.md)。
