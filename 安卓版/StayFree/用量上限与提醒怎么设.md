# StayFree 用量上限与提醒怎么设

> 用量上限是 StayFree 的核心动作：给某个 App、某一类应用或某个网站设一条时长或时间段规则，到点提醒、弹窗或直接不让用。本篇给出设置路径、三种触发方式的差别、以及防止自己临时改回去的做法。

## 一、一条上限规则由四个选择构成

| 选择 | 可选项 | 说明 |
| --- | --- | --- |
| 管什么 | 单个 App / 一类应用（社交、娱乐、新闻等）/ 网站 | 网站类要配合浏览器扩展才有细粒度，见 [网页与短视频怎么单独屏蔽.md](网页与短视频怎么单独屏蔽.md) |
| 怎么限 | 每天累计时长上限 / 指定时间段内禁止 / 一直禁止 | 时长上限按当天累计算，过了每日重置时间归零 |
| 限多少 | 分钟数，或起止时间 | 输入方式以你界面上实际提供的为准 |
| 到点怎么办 | 发出提醒 / 弹出视窗 / 不准继续使用 | 差别见第二节 |

## 二、三种触发方式的实际差别

1. **发出提醒**：只推一条通知，不影响继续用。适合先观察自己到底用了多久。
2. **弹出视窗**：到点跳一个提示窗，点掉之后还能接着用。比提醒强一点，但仍然不阻断。
3. **不准继续使用**：到点之后应用被锁住，想再用就得回 StayFree 改规则。真正能拦住人的是这一种。

前两种都不阻断使用，指望它们减时长通常落空。更实际的做法是：先用提醒或弹窗跑一周，看清哪些应用最耗时间，再把最该管的那个改成第三种。

到点之后想再要几分钟，不同版本的拦截页处理方式不一样：有的直接拦住、只能回应用改规则，有的给了短暂的延期入口。能延几次、有没有这个入口，以你那台设备上实际显示为准；别把「有延期入口」当成可以不用上限的理由。

## 三、设置步骤

1. 打开 StayFree，点左上角的功能菜单（三条横线）。
2. 进「用量上限」。
3. 点「新增用量上限」。
4. 选类型：App / 分类 / 网站。
5. 选中具体对象。要管一整类，就在分类里挑「社交」「娱乐」这类；要给所有应用都设一条，用列表里的全选。
6. 填限制：
   - 每天最多用多久 → 选「设置每日使用上限」，填分钟数；
   - 某个时间段不许用 → 选「按日程阻断」，选星期几、填起止时间，比如 09:00–12:00；
   - 一直不许用 → 选「永久阻断」。
7. 选到点行为（第二节那三种），保存。

不确定自己用的是免费档还是付费档、哪些功能要订阅，见 [免费版和付费版有什么区别.md](免费版和付费版有什么区别.md)；哪些功能在电脑或浏览器上而不是在手机端，见 [网页与短视频怎么单独屏蔽.md](网页与短视频怎么单独屏蔽.md)。

要设互补的两段时段（比如 09:00–12:00 和 20:00–22:00 各一段），可以建两条同样的规则分别填时间；部分版本支持长按已有规则复制一份再改时间，界面上没有这项就手动再建一条。

## 四、别忘了每日重置时间

上限是按「当天」算的，所以「当天从几点开始」会直接影响判定结果。夜里用得多的，把重置时间放在凌晨两三点而不是 0 点——否则 23:50 刷掉的时间算进前一天，第二天 0 点一过又有新额度。

设置里有「每日重置时间」一项，改成你要的时点即可（浏览器扩展端同样有这一项，官方使用说明里单列了一节）。

## 五、防止自己临时改回来

1. **开密码或 PIN 保护。** 官方把「修改设置需要密码」列为功能之一：在设置里找到锁定或 PIN 相关项，开启后改动限额都要先输一遍。
2. **密码别选顺手能敲出来的那串。** 忘了密码的代价不小——只能卸载重装，而重装会带走历史统计，所以密码建议另外记一处。
3. **给家人用（比如孩子的设备）时**，除了上面两条，还可以把系统「设置」应用也加进永久阻断，避免从系统层面绕过；这么做之前先确认不会把自己也锁在外面。整套配置顺序见 [把手机交给孩子用怎么设.md](把手机交给孩子用怎么设.md)。
4. **临时想用一下**：有的版本提供了暂停类的开关，用它比删规则安全——暂停到期会恢复，删掉就得重设。

## 六、到点没反应先查这两处

| 现象 | 先查 |
| --- | --- |
| 到点没有提醒，也没有拦 | 通知权限是否给了；无障碍服务是否还开着 |
| 提醒有、但应用照用不误 | 触发方式是不是选成了提醒或弹窗，而不是「不准继续使用」 |
| 数字归零的时间点不对 | 每日重置时间设置 |
| 只在电脑上生效、手机上不生效 | 两端的规则各管各自范围，见 [网页与短视频怎么单独屏蔽.md](网页与短视频怎么单独屏蔽.md) |
