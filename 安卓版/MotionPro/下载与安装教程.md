## 一、先确认你要装的是不是它

MotionPro 是 Array Networks 出品的企业 SSL VPN 客户端，配合单位部署的 AG 系列安全接入网关使用，让你在外面安全地连回内部网络。它不连接公共 VPN 服务，也没有「随便填个地址就能用」的玩法 —— 没有单位提供的网关地址和账号，装上也用不了。

适合的情况：

- 单位 IT 通知你用 MotionPro 连公司内网（OA、邮件、内部系统）；
- 学校网络中心要求用 MotionPro 在校外访问图书馆数据库、教务系统等校内资源；
- 你拿到一个形如 `vpn.xxx.com:443` 的网关地址和一套账号密码。

不属于上面任何一种的话，先问清楚发你链接的人这是什么再装。

安卓客户端可以从这几个渠道拿：

| 渠道 | 说明 |
| --- | --- |
| 应用市场 | 在手机自带应用市场（华为市场、安卓市场、360 应用市场等）搜 `MotionPro`，认准开发者 Array Networks |
| 官方下载页 | [client.arraynetworks.com.cn:8080/zh/troubleshooting](https://client.arraynetworks.com.cn:8080/zh/troubleshooting)，Array Networks 中国区的客户端下载页，桌面版与移动版都在这里 |
| 官方安卓安装页 | [client.arraynetworks.com.cn:8080/zh/troubleshooting/motionpro_plus](https://client.arraynetworks.com.cn:8080/zh/troubleshooting/motionpro_plus)，官方移动客户端安装页，手机浏览器直接打开即可安装 |
| 本页网盘资源 | [MotionPro 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5043c5bf1482)，适合手机上没有应用市场、或市场里搜不到指定版本的情况；按页面提示先转存到自己网盘再下载 |

## 四、系统要求

- 手机端：需要安卓系统。官方对相邻版本 3.1.7 的发行说明标注兼容 Android 7.0 至 15.0（截至 2025 年 7 月），其他版本的兼容范围以官方发行说明为准。
- 服务端：要求单位的 AG 网关为 9.4 或更高版本。这由单位决定，连不上且排查无果时，可以提醒 IT 核对一下网关版本。
- 官方发行说明发布在 [support.arraynetworks.net](https://support.arraynetworks.net)，部分文档需要账号，找单位 IT 要。

## 五、安装步骤

1. 从上面任一渠道下载 APK 安装包；
2. 点开安装包。手机提示「禁止安装未知来源应用」时，按提示允许本次安装（开关在系统设置的「应用管理」或「安全」里，各品牌叫法不同）；
3. 装完打开 MotionPro，会看到「添加站点 / 添加网关」的入口 —— 先别急着乱填，去读 [添加站点与首次登录.md](添加站点与首次登录.md)；
4. 第一次连接成功前，系统会弹「是否允许创建 VPN 连接」，必须点允许，否则隧道起不来。

安装本身没有别的门槛，卡住的地方基本都出在「添加站点」和「系统 VPN 授权」这两步，遇到问题直接看 [连不上与登录失败排查.md](连不上与登录失败排查.md)。
