## 一、「安全隧道」是什么

登录成功后，MotionPro 的「网关」页面有一个「安全隧道」开关。勾上它，手机会建立一条到单位 AG 网关的加密通道（L3 VPN），此后你访问内网 IP、内网域名的流量都从这条通道走 —— 效果等同把手机临时接进了办公区网络。

桌面版连上后任务栏会出现红色「A」图标；安卓版没有这个图标，状态一律以「安全隧道」一行的显示为准。

## 二、连上之后能访问什么

取决于单位给你这个账号开了哪些权限，常见的是：

- 内网 Web 系统：OA、财务、人事、教务 / 选课系统等；
- 内部服务器：用内网 IP 或域名访问的测试机、文件服务；
- 图书馆数据库：高校场景下最常见的用途；
- 远程桌面与企业应用：单位若启用了相应资源，客户端里会出现「桌面」「应用」等入口（由管理员发布，没看到就是没开）。

连上却打不开某个系统，多半是这个资源没加进你的授权组，不是手机的问题 —— 找管理员把资源加进你所属的组即可。

## 三、为什么连着隧道上网会变慢

隧道开着时，你的全部流量都要绕经单位网关再出去，速度受单位出口带宽影响，访问普通网站反而比直连慢；对外显示的出口 IP 也是单位的。这不是故障，是全局隧道的工作方式。两条建议：

- 只在需要内网资源时连，用完就断；
- 如果日常只访问少数几个内网系统，可以问管理员能否按应用 / 按网段做拆分隧道（需要服务端配置支持，客户端侧改不了）。

## 四、安全浏览器与企业应用门户

管理员还可以在网关侧发布两个可选入口：

- **安全浏览器**：在内网 Web 应用里打开页面，数据留在受控环境里。一个官方确认过的行为要留意：若在退出登录前直接杀掉进程或卸载应用，安全浏览器里已下载的文件不会被自动清掉 —— 敏感文件建议手动删；
- **企业应用门户**：单位把内部 App 发布进来，从这里下载安装。安卓系统要求你手动确认安装，点确认即可。

这两个入口在不在、叫什么名，完全看单位的配置，没看到就是没启用，不必自己找。

## 五、常见状态对照

| 现象 | 含义 | 怎么办 |
| --- | --- | --- |
| 安全隧道已连接，内网打得开 | 正常 | 用完断开 |
| 已连接，但内网打不开 | 资源未授权或服务端未配置 | 找管理员核对授权组 |
| 隧道开关点了没反应、或按钮不显示 | 客户端异常或系统 VPN 授权被关（部分为已知客户端问题，3.1.7 修复） | 见 [连不上与登录失败排查.md](连不上与登录失败排查.md) |
| 登录成功但只有隧道、没有任何资源入口 | 单位只开了隧道、没发布门户资源 | 属正常，直接用手机浏览器访问内网地址 |
| 反复连接但隧道始终建不起来 | 单位只发布了桌面 / 远程应用资源时，客户端不会建立隧道（官方已知限制） | 找管理员核对发布的资源类型 |
