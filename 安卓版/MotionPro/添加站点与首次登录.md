# MotionPro 添加站点与首次登录

> 本篇讲第一次使用 MotionPro 时怎么填网关信息、怎么完成系统授权，以及连上之后怎么断开。

## 一、动手前先准备三样东西

MotionPro 里要填的东西全部来自单位 IT 或学校网络中心，不是自己能猜出来的：

| 需要准备 | 长什么样 | 问谁拿 |
| --- | --- | --- |
| 网关地址 | `vpn.xxx.com`，或带端口的 `vpn.xxx.com:443` | 单位 IT / 网络中心 |
| 账号密码 | 一般是你的工号 / 学号对应密码，有的单位另发 VPN 账号 | 同上 |
| 认证方式 | 只要密码，还是要短信码、动态口令 | 同上 |

端口不确定时先不加，客户端默认走 443；学校的配置说明里一般会写全，照抄即可。

## 二、添加站点（安卓端）

1. 打开 MotionPro，点右上角的「+」（添加站点 / 添加网关）；
2. 逐项填写：
   - **标题**：自己起，方便认就行，比如「公司」「学校」；
   - **网关（主机）**：填 IT 给的地址，带端口就连端口一起填；
   - **用户名**：工号 / 学号 / IT 给的 VPN 账号；
   - **保存密码**：私人手机可以勾；公用或借来的设备建议不勾；
3. 点「存储 / 保存」，站点列表里会出现刚建好的这一条。

部分单位会发 `profile.ini` 之类的配置文件让你导入（桌面端常见），安卓端一般手动填这几项就够了；两种方式都给你时，任选其一，别重复建。

## 三、首次登录与系统授权

1. 在站点列表里点刚建的那一条；
2. 输入密码登录。若单位启用了短信验证码或动态口令，按页面提示继续填（见 [动态口令与二次认证.md](动态口令与二次认证.md)）；
3. 第一次连接时，安卓系统会弹「是否允许创建 VPN 连接」——点允许。不允许的话，账号密码再对隧道也起不来；
4. 登录成功的标志：回到「网关」页面，「安全隧道」一行显示已连接。

连上之后能访问什么、为什么上网变慢，看 [安全隧道与内网访问.md](安全隧道与内网访问.md)。

## 四、用完记得断开

- 在「网关」页面点右上角的退出按钮（部分版本是电源样式的按钮）即可断开；
- 断开后内网资源立刻不可访问，手机恢复正常的直连上网。

不少单位给的是全局隧道：开着的时候你的全部上网流量都绕经公司网络。挂着不断既费电又拖慢日常上网，用完就断是个值得保持的习惯。

## 五、登录不上去怎么办

先对照 [连不上与登录失败排查.md](连不上与登录失败排查.md) 按症状过一遍。账号被锁、权限没开、动态口令要重绑这类问题客户端这边解决不了，直接找单位 IT。
