## 一、先记结论：设置默认不会被任何云备份带走

模块的配置存在手机本地，**不随三星账号同步**；三星云备份与 Smart Switch 整机备份通常也不包含 Good Lock 各模块的设置（多个独立来源一致；个别模块可能例外，以它自己的说明为准）。这意味着：恢复出厂、换机恢复备份、卸载重装之后，**布局和开关基本都要重配一遍**。想减少损失，靠下面几招提前留底。

## 二、动手前先留底（三招，按保真度排）

1. **用 Home Up 自带的备份功能**（仅限 Home Up 管的那些设置）：进 Home Up 找备份选项，把配置存成文件，之后可回读恢复。
   - **已知坑（截至 2026-09）**：如果你给文件夹标签设过自定义颜色，备份会失败并提示文件损坏 —— 三星社区版主确认了这个问题、修复要等后续版本更新；**临时办法是先把文件夹标签颜色恢复默认，再做备份**（据 Android Authority 2026-09-23 报道与三星社区答复）。
2. **用 Galaxy To Share（GTS）导出设置**：社区指南的用法是装好 Good Lock 与 GTS 模块 → 在 GTS 里新建「我的 GTS」→ 勾选要导出的模块设置（LockStar、HomeUp、ThemePark、QuickStar 等）→ 生成链接或二维码。对方也得是三星设备 + 装了 Good Lock 和 GTS 才能导入；具体以 GTS 应用内说明为准。
3. **截图留档**：对每个改过的关键项截一张图。保真度最低，但换机、恢复出厂都带得走，重配时照着点即可。

## 三、各种情况下设置会发生什么

| 你做了什么 | 设置的下场 |
| --- | --- |
| 关掉某个模块的总开关 | 该模块的效果立刻消失，恢复系统默认；配置项还在，重新打开一般能接着用 |
| 卸载某个模块 | 该模块的全部配置一并清掉，重装后是初始状态（有用户反馈：重装后不会自动恢复原设置） |
| 只卸载 Good Lock 本体 | 已装模块不受影响，界面效果照旧 —— 要彻底回到默认，得把模块逐个卸掉 |
| 恢复出厂 / 换机 | 本地配置全部消失；云备份恢复回来的整机数据里通常也没有模块设置，按第二节重配 |
| One UI 大版本更新 | 可能只重置一部分模块（常见于锁屏、桌面类），按下一节的顺序重设 |

## 四、系统大更新后被重置了，按什么顺序重设

有用户社区（韩国 Good Lock 社区）总结的重设顺序，避免边设边冲突：

1. 先确认 Good Lock 本体已更新到最新；
2. 把已装模块逐个更新到最新；
3. 按 LockStar（锁屏）→ Home Up（桌面与后台）→ Theme Park（主题重应用）→ NavStar（导航）→ Routines+（自动化规则检查）的顺序重开与重配；
4. 每设完一个就回界面验证一次，出问题好定位是哪个模块。

配好之前系统还在跑旧组件的情况，处理见 [用不了和模块失效怎么办.md](用不了和模块失效怎么办.md) 的第二节。

## 五、卸载前的两个提醒

- 卸载模块可逆（随时从商店重装），但配置不可逆 —— 想保留就先按第二节备份。
- 要卖手机、转手给别人之前想清掉所有定制：逐个卸载模块即回到 One UI 默认状态，不需要恢复出厂 —— 卸载后界面立即复原（多个独立来源一致）。具体卸载入口见 [常用模块设置教程.md](常用模块设置教程.md) 的回退一节；从头装回来的过程在 [下载与安装教程.md](下载与安装教程.md)。
