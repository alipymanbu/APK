# Good Lock 用不了和模块失效怎么办

## 一、商店里搜不到 Good Lock，或显示「不兼容」

按这个顺序排，命中率从高到低：

1. **机型没被收录**：官方明确写了「部分设备可能不支持」，并不是所有三星机型都有。先确认你的是三星、且在 Galaxy Store 里搜得到页面 —— 搜不到就是没上架到你这台，不是操作问题。
2. **地区问题**：它并非在所有国家/地区都上架，商店会按账号地区与固件地区显示。页面在、但你换过账号地区或用的是非本地固件时，可能出现能搜到却装不了。
3. **系统版本太旧**：官方更新日志写明 3.X.X 系列支持 One UI 4.0 及以上设备。去「设置 → 软件更新」把系统更到最新再看。
4. **Galaxy Store 本体太旧**：商店客户端旧了会拿不到新的兼容数据。先更 Galaxy Store 自己（商店 → 菜单 → 设置 → 关于 Galaxy Store），再回来搜。

## 二、系统更新之后，模块集体不灵了

大版本更新（尤其是 One UI 升级）后这是高频现象，典型症状是本体能开、但模块打不开、闪退回桌面或改的效果消失：

1. **先更系统、再更本体、最后更模块**：顺序反了会出现「本体新、模块旧」的版本错配，模块就跑不起来。去 Galaxy Store 的更新列表把 Good Lock 与已装模块全部更到最新。
2. **重启一次手机**：更新完不重启，系统经常还在跑更新前的那套组件，效果就对不上。
3. **清缓存兜底**：「设置 → 应用 → Galaxy Store → 存储 → 清除缓存」，再对 Good Lock 本体做一次同样的操作，然后重新进模块。
4. 还不行就**把出问题的模块卸了重装**（见 [模块安装与启用步骤.md](模块安装与启用步骤.md) 的回退一节）。

## 三、模块卡在「安装中」、安装失败或一直转圈

- **商店下载失败的通用三板斧**：检查网络（换个 Wi-Fi 或流量试）→ 检查剩余空间（官方建议至少留 1.5 GB）→ 清 Galaxy Store 缓存与数据后重试。
- **更新 Good Lock 本体时说无法更新插件**：官方在 3.0.16.x 系列的更新日志里明确修过「部分环境下无法更新 Good Lock 插件」的问题 —— 先把本体升上去，再更插件。
- **显示已安装、界面却不刷新**：同样在近期更新日志里修过；碰到就强杀一次 Good Lock 再进。
- 用 APK 方式装的本体（见 [下载与安装教程.md](下载与安装教程.md)）本身不负责模块分发，模块仍要走商店 —— 商店不通时模块装不了，先解决商店问题。

## 四、装好的设置突然恢复默认

- 模块更新或 One UI 更新会重置一部分配置，进各模块检查一遍开关即可。
- 在 Good Lock 的「我的空间」里能集中查看各模块设置状态；改乱了也从这里重置（见 [常用模块设置教程.md](常用模块设置教程.md) 的回退一节）。

## 五、和别人界面不一样、找不到我说的选项

这通常不是你装错：**能看见哪些模块、模块里有哪些选项，取决于机型、地区和 One UI 版本**；官方也说明模块清单会随时增减，部分模块只有英文界面。对照 [模块安装与启用步骤.md](模块安装与启用步骤.md) 的清单确认模块名，名字对得上但选项没有，就是版本差异 —— 更新到最新再看（版本口径见 [版本号怎么看与更新节奏.md](版本号怎么看与更新节奏.md)）。

## 六、非三星手机能用吗

不能。Good Lock 深度绑定三星自己的 One UI 与系统服务，其他品牌手机即使强行装上本体，模块也装不齐、跑不了。网上若有声称「通用版」的介绍，以你实际能不能装上模块为准。
