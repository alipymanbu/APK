## 一、本体和模块是什么关系

Good Lock 本体不提供任何定制功能，它只是「应用列表 + 更新管理」：你打开它，看到的是一排排模块，每个模块右侧有自己的安装按钮。**改锁屏的是 LockStar、改后台布局的是 Home Up，跟本体是三个独立的包** —— 只装本体、不装模块，等于什么都没装。反过来，多数模块装好后就是一个独立应用，你会在应用列表里看到它的图标，从 Good Lock 里进、从应用列表进都一样；少数模块只在 Good Lock 内部出现。

## 二、分类：两摞模块各管什么

官方把模块分成两大类（不同语言界面叫法不同，以你手机上显示为准）：

- **外观类（Make up）**：管「看起来怎么样」—— 锁屏、时钟、主题、状态栏、键盘外观、动效壁纸。
- **便利类（Life up）**：管「用起来怎么样」—— 后台多任务、手势、截屏、音量面板、通知管理、自动化例程。

3.0.10 版起本体换了新界面，分类比以前更细，还加了收藏、更新历史、「我的空间」（集中查看和重置各模块设置）。

## 三、装模块的步骤

1. 打开 Good Lock，在列表里找到想装的模块，点它右侧的安装按钮（一个向下的箭头图标）。
2. 实际下载走的是应用商店（Galaxy Store / Google Play），会跳转一次确认，等进度走完。
3. 装完回到 Good Lock，按钮变成「打开」或出现开关 —— 点进模块内部，**先把模块总开关打开**（有的模块开屏是 `Start` 按钮），再按提示授权。
4. 授权弹窗要认真看：比如 Home Up 首次启动会要求访问照片与视频，不授权它的功能就是灰的。
5. 验证是否生效：回桌面或锁屏看对应位置有没有变化；没变化多半是开关没开或模块没更新，排查见 [用不了和模块失效怎么办.md](用不了和模块失效怎么办.md)。

**按需装，不用全装。** 模块是一个个独立应用，装得越多占的存储和后台越多；不确定要不要的，先不装，等真有需求再回来装。

## 四、常见模块清单

下表按「你想改什么」列，只写读者用得上的入口（每个模块的详细设置步骤在 [常用模块设置教程.md](常用模块设置教程.md)）：

| 你想改什么 | 用哪个模块 |
| --- | --- |
| 最近任务（后台）的布局 | Home Up（内含 Task Changer） |
| 锁屏布局、锁屏小组件 | LockStar |
| 锁屏 / 息屏显示的时钟样式 | ClockFace |
| 状态栏图标、快捷面板配色 | QuickStar |
| 全局配色与主题 | Theme Park |
| 桌面布局、文件夹样式 | Home Up |
| 键盘外观与按键音效 | KeysCafe |
| 导航栏按钮与手势 | NavStar |
| 动态壁纸效果 | Wonderland |
| 侧边手势、单手操作 | One Hand Operation+ |
| 音量面板、单个应用音量 | Sound Assistant |
| 截屏与录屏的细节 | NiceShot |
| 通知搜索与管理 | NotiStar |
| 侧键长按、背面双击 | RegiStar |
| 自动化规则 | Routines+ |

实际能看到哪些模块取决于机型、地区与 One UI 版本，列表会增减 —— 手上没有的模块不是你装错了。
