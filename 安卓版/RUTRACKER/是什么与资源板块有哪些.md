## 一、一句话认识 RUTRACKER

RUTRACKER 是一款安卓端的资源访问工具，对应的资源站是 `rutracker.org`——一个以俄语为主的大型 BitTorrent 资源社区。你在应用里按板块浏览，找到想要的资源后，通过 BT 协议（种子 / 磁力链接）下载。它是否为该站的官方出品，公开资料没有明确说明，以应用内的实际说明为准。

## 二、背景：rutracker.org 是什么站

几个关键事实，帮你判断这个应用适不适合你：

| 项目 | 情况 |
| --- | --- |
| 上线时间 | 2004 年 9 月（前身 torrents.ru，2010 年起启用 `rutracker.org` 域名） |
| 语言 | 界面与内容以俄语为主，部分标题带英文 |
| 内容范围 | 影视、音乐、书籍、软件、游戏、学习资料等 |
| 下载方式 | BitTorrent 协议：.torrent 文件或磁力链接 |
| 账号 | 下载 .torrent 文件需要注册并登录；磁力链接无需登录即可使用 |
| 每日限额 | 登录用户每天最多下载 1000 个 .torrent 文件（群组成员上限 10000） |
| 分享率 | 无分享率（ratio）考核，统计数据仅作参考 |
| 站内搜索 | 需登录后使用；结果列表会显示体积与做种数，可按做种数排序 |

时间线上有三件事值得记住：2004 年上线、2010 年更换域名、2016 年起在俄罗斯境内被运营商屏蔽（站点本身仍在运营，域名能否直连取决于你所在地区的网络）。这也是为什么网上会同时出现 `rutracker.org`、`rutracker.net` 等好几个域名。

## 三、应用里的资源板块

按应用介绍，RUTRACKER 内部分成 11 个板块：

动画、番剧、音乐、舞蹈、游戏、科技、生活、鬼畜、时尚、娱乐、影视

板块偏重视频与娱乐类资源的浏览入口，找资源主要靠板块导航加站内搜索。具体的搜索姿势见 [中文界面与语言设置.md](中文界面与语言设置.md)——站点内容标题以俄语为主，直接搜中文关键词命中率不高。

## 四、下载是怎么回事：种子与磁力

- **磁力链接（magnet）**：一串以 `magnet:?xt=` 开头的链接，不登录站点也能使用；
- **.torrent 文件**：需要登录后下载，计入上表的每日限额；
- **速度**：BT 下载的速度取决于同一资源当前做种（上传）的人数，做种越多越快，跟你的宽带与网络环境也有关系；
- **承接的下载器**：资源通过 BT 协议传输，手机端通常要有能处理种子 / 磁力的下载器来承接。用应用内置的下载还是交给外部下载器，以你手上版本的实际界面为准。

账号怎么注册、登录后能多做什么，见 [账号注册与登录教程.md](账号注册与登录教程.md)；装应用本身的步骤见 [下载与安装教程.md](下载与安装教程.md)。
