RUTRACKER 是一款安卓端的资源访问工具，对应俄语资源站 `rutracker.org`，应用内按动画、番剧、影视、游戏等板块浏览资源。本篇按「了解安装包 → 获取 → 核对 → 安装 → 装完先做什么」的顺序走一遍，几分钟就能装好。

## 一、安装前先了解这几个信息

下面这些是这份安装包本身的事实，装之前核对一遍能省掉大部分「装不上」的麻烦：

| 项目 | 内容 |
| --- | --- |
| 安卓包名 | `com.android.ftpeasy` |
| 版本 | 4.1（2026-09 采集） |
| 安装包大小 | 6.82 MB |
| MD5 | `95CAE9BF824CB14003005B4B63F545F6` |
| 系统要求 | 安卓 5.2 及以上（以安装包信息为准） |

版本号会随更新变化，网上搜到的往往是官方最新版；网盘里这一份就是上表的版本，先看清楚再装。

## 二、从网盘获取安装包

安装包放在夸克网盘里，转存到自己的网盘后就能下载：

[RUTRACKER 安装文件资源（夸克网盘）](https://pan.quark.cn/s/77f92f34481f)

操作路径：打开上面的分享链接 → 「保存到我的网盘」→ 在自己网盘里找到该文件夹 → 把 APK 下载到手机。在电脑上操作也一样：先转存下载，再用数据线或局域网共享把文件传到手机。

## 三、核对安装包（可选但建议）

如果下载下来的文件大小和表格里的 6.82 MB 对不上，或者安装时反复报「解析包错误」，先核对 MD5 确认文件完整：

- Windows：`certutil -hashfile 文件名.apk MD5`
- macOS / Linux：`md5sum 文件名.apk`

算出来的值应该等于 `95CAE9BF824CB14003005B4B63F545F6`（大小写不敏感）。不一致就重新下载一遍，多半是中途断传导致文件不完整。

## 四、安装步骤

1. 在手机文件管理器里找到下载好的 APK，点它；
2. 第一次从浏览器 / 文件管理器装应用时，系统会提示「不允许安装未知来源应用」，按提示进入设置，给发起安装的那个应用打开「允许安装未知应用」；
3. 回到安装界面点「安装」，等待完成。

安卓 8 及以上系统的「未知来源」授权是**按应用逐一授权**的：从哪个应用发起安装就给哪个应用开开关，不需要也不应该全局放开。覆盖升级（之前装过旧版）时直接安装即可，数据会保留，不用先卸载。

## 五、装完先做两件事

1. **确认界面语言**：如果打开后界面不是中文，先去语言设置里切一下，入口和找法见 [中文界面与语言设置.md](中文界面与语言设置.md)；
2. **了解账号要求**：浏览板块不需要账号，但要拿资源就会碰到站点账号与登录的问题，先看 [账号注册与登录教程.md](账号注册与登录教程.md) 心里有数。

装好之后这个应用能看什么、资源是怎么组织的，见 [是什么与资源板块有哪些.md](是什么与资源板块有哪些.md)；之后在手机上把资源真正下载下来的一整条链路（拿磁力、交给哪个下载器），见 [手机端怎么下载资源.md](手机端怎么下载资源.md)。
