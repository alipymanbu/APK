## 一、先说结论：站点本身没有中文

`rutracker.org` 的界面语言是俄语，官方没有提供中文界面，多个来源口径一致。所以「调成中文」实际走两条路：网页靠浏览器翻译，应用靠应用内的语言设置（如果有）。

## 二、网页翻译：浏览器自带功能就够

用浏览器打开站点时：

- **电脑 Chrome / Edge**：打开页面后浏览器一般会自动弹出「是否翻译此页」，选翻译成中文即可；没弹就在页面上点右键，选「翻译成中文」；
- **手机浏览器**：主流手机浏览器的菜单里都有「网页翻译」或「工具箱 → 翻译」，找不到时在菜单或设置里搜「翻译」两个字；
- 整页翻译对板块名、表格、规则页同样生效，看规则、填注册表够用了。

注册这类需要精确理解的操作，翻译结果仅供参考：邮箱、密码这类关键字段以你自己核对过的输入为准，别照着译文猜。

## 三、站内高频俄语词速查

翻译整页之前，这几个词先认个脸，基本能覆盖日常操作：

| 俄语 | 意思 | 常出现在 |
| --- | --- | --- |
| Регистрация | 注册 | 注册按钮 |
| Вход | 登录 / 进入 | 登录页与登录按钮 |
| Поиск | 搜索 | 搜索按钮 |
| Загрузить | 下载 | 下载按钮 |
| Торрент | 种子 | 下载入口 |
| Правила | 规则 | 注册页、论坛规则 |

## 四、应用内语言怎么切

安卓应用的语言设置一般在两处：

1. 应用自己的设置里找 **Language / 语言 / Язык** 选项；
2. 应用没有独立设置时，走系统入口：安卓 13 及以上，系统设置 → 应用 → 该应用 → 语言，可以直接给单个应用指定语言；更低版本的安卓只能改整个系统语言。

注意：不同版本的客户端菜单不完全一样。网上能搜到的「齿轮图标 → 地球标志 → 简体中文（Chinese Simplified）」这类步骤，是针对另一版本客户端的描述，你手上这份以实际界面为准——找不到语言选项，就说明这个版本可能不支持应用内切换，只能走系统级方案。

## 五、搜资源用什么语言

- 站点内容标题以俄语为主，部分标题带英文；**直接搜中文关键词命中率很低**；
- 实用做法：先把想找的名字用翻译工具译成俄语（或直接用它的英文名），再去站内搜索；
- 搜出来的页面看不懂，同样用浏览器整页翻译解决。

搜到资源之后要不要登录、怎么下载，见 [账号注册与登录教程.md](账号注册与登录教程.md)；下载没速度之类的运行问题归 [常见问题与故障排查.md](常见问题与故障排查.md) 管。
