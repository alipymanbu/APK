## 一、入口在哪

1.0 版就带这个功能（官方介绍写的是「自定义 ffmpeg 指令及其结果回调」），入口在应用的**「设置」里的「FFmpeg 指令」**：写好指令后执行，输出信息会回显出来，报错也能看到原因。指令支持编辑、保存与反复执行，常用的写法存起来下次直接调。

## 二、一条指令长什么样

ffmpeg 命令的通用结构是三段：输入、参数、输出。

```bash
ffmpeg -i 输入文件.扩展名 -参数 输出文件.扩展名
```

写之前记住三件事：

- `-i` 后面跟你要处理的源文件名，**最后一段是输出文件名，漏写会报错**；
- 文件名按你在手机里的实际文件名写，带扩展名；
- 每个参数的含义可以查 ffmpeg 官方文档（[ffmpeg.org](https://ffmpeg.org)）。

## 三、音频场景常用指令

下面都是 ffmpeg 的通用语法，在 ATool 的指令入口里同样适用。把 `input`、`output` 换成你自己的文件名。

**格式转换**（换成什么格式就写什么扩展名）：

```bash
ffmpeg -i input.m4a output.mp3
```

**指定采样率与声道**：

```bash
ffmpeg -i input.wav -ar 44100 -ac 2 output.wav
```

**截取一段**（从第 10 秒到第 40 秒）：

```bash
ffmpeg -i input.mp3 -ss 00:00:10 -to 00:00:40 output.mp3
```

**变速**（1.5 倍速）：

```bash
ffmpeg -i input.mp3 -filter:a atempo=1.5 output.mp3
```

`atempo` 的取值有范围限制（以你使用的版本为准），超出范围的倍速要把多个 `atempo` 串联起来写。

**变调**（升调的写法，降调把系数改小）：

```bash
ffmpeg -i input.mp3 -filter:a asetrate=44100*1.25,aresample=44100 output.mp3
```

**淡入淡出**（开头 2 秒淡入、从第 28 秒起 2 秒淡出）：

```bash
ffmpeg -i input.mp3 -filter:a afade=t=in:st=0:d=2,afade=t=out:st=28:d=2 output.mp3
```

**从视频里提取音轨**（`-vn` 表示不要画面；`-acodec copy` 表示直接搬音频流、不重新编码）：

```bash
ffmpeg -i input.mp4 -vn -acodec copy output.m4a
```

**调整音量**（放大到 1.5 倍）：

```bash
ffmpeg -i input.mp3 -filter:a volume=1.5 output.mp3
```

## 四、报错了怎么排查

执行结果会回显输出，按出现频率从高到低查：

1. **输出文件名漏写**——指令最后一段必须是输出文件；
2. **输入文件名不对**——对照文件管理器里的实际文件名，注意扩展名；
3. **参数拼写错误**——ffmpeg 的参数对拼写敏感，对照官方文档逐个核对；
4. **参数取值越界**——比如 `atempo` 超范围、时间点超出音频时长。

## 五、什么时候用指令、什么时候用界面

界面功能覆盖得到的（转换、裁剪、变速变调、淡入淡出、混音合并，见 [音频提取与格式转换.md](音频提取与格式转换.md)、[混音与合并操作.md](混音与合并操作.md)）优先用界面，点几下就完；需要精确到参数的场合（特定采样率、精确时间点、音量倍数）再上指令。指令执行完的文件去哪了、列表没刷新，排查思路见 [常见问题与自定义指令.md](常见问题与自定义指令.md)。
