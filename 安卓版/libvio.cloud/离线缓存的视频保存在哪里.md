## 一、先把片子缓存下来

进入想看的剧集播放页，找**缓存 / 下载入口**（有的版本在详情页，图标可能是向下箭头或「离线缓存」字样），勾选要存的集数后开始下载。缓存走分段下载，支持后台进行 —— 锁屏、切到别的应用都会继续，前提是没有中断网络。缓存适合通勤、坐车、飞行这类没网的场景，提前在 Wi-Fi 下存好（与 [播放卡顿与换源解决办法.md](播放卡顿与换源解决办法.md) 里「弱网提前缓存」是同一件事）。

## 二、为什么文件管理器里找不到

缓存完成的片子**不在**「下载」「Movies」这类公共目录里，而是在应用自己的私有数据目录（`Android/data/` 下对应 `lab.vie.two` 的目录）。安卓从 10 起收紧了对应用私有目录的访问：文件管理器默认看不到内容，其他播放器也打不开 —— 这是系统行为，不是缓存丢了，也不用去找「隐藏文件」。

想看它占了多少空间，走系统入口而不是文件管理器：

**设置 → 应用 → libvio.cloud → 存储**，这里能看到应用总占用（含缓存的视频）。

## 三、哪些操作会把缓存抹掉

| 操作 | 离线视频还在吗 |
| --- | --- |
| 在应用内删除缓存的剧集 | 只删你勾选的那几集 |
| 清理缓存（设置 → 应用 → 存储 → 清理缓存） | 一般只清临时文件，看片记录与已缓存的剧通常保留 |
| **清除数据**（同一个页面里更重的那一项） | **全没** —— 观看记录、登录状态、离线视频一起清空 |
| **卸载应用** | **全没**，且重新安装后不会自动恢复 |

所以排查闪退、加载异常时，[闪退与安装失败怎么办.md](闪退与安装失败怎么办.md) 反复强调「清缓存、别清数据」—— 差一个字，离线视频的下场完全不同。

## 四、空间不够时怎么腾

1. 先在 **设置 → 应用 → libvio.cloud → 存储** 里看真实占用，确认是不是缓存吃掉的。
2. 回到应用内，把**已经看完的剧集**从缓存列表里删掉 —— 逐集删最可控，也顺手保住没看完的。
3. 应用占用仍然异常大（几个 GB 而你看的片没这么多）时，说明旧缓存没被正常回收：先在应用里清一遍缓存列表，再考虑「清理缓存」；到「清除数据」这一步就是前功尽弃，只在应用彻底异常时才用。
4. 手机总存储长期吃紧时，缓存前先算账：单集体积随清晰度差别很大，Wi-Fi 下只存接下来一两集要用的量，比一次缓存整部剧更省空间。
