## 一、从夸克网盘获取安装包

安装包不走应用商店，统一从分享链接转存到自己的网盘再下载：

1. 打开 [libvio.cloud 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c6bc94d641d9)，按提示把分享内容**保存到自己的网盘**（需要装夸克 App 或登录网页版）。
2. 转存后在自己网盘里找到该应用的文件夹，里面是安装包 `libvio.cloud_v2.2.0.apk` 与一个说明 txt。
3. 手机上用夸克 App 直接点 APK 下载并打开安装；也可以先在电脑上下载，再通过数据线、局域网传输或聊天工具把文件发到手机。
4. 下载完成后**先别急着装**，先做下一节的核对。

传输过程要注意保持文件完整：手机在下载中途断网、或传输工具截断了文件，都会得到一个装不上的残包。

## 二、核对安装包信息

网盘里这一份的事实信息如下（以这份为准，网上其他渠道的同名包不一定相同）：

| 项目 | 值 |
| --- | --- |
| 版本号 | 2.2.0 |
| 包名 | `lab.vie.two` |
| 文件大小 | 27.87 MB |
| MD5 | `BFDE87D9F31B3F86A88BC231E0398F89` |

MD5 是文件的「指纹」，两边一致就说明下载完整、文件没被改动过。在 Windows 电脑上核对：

```powershell
certutil -hashfile "C:\路径\libvio.cloud_v2.2.0.apk" MD5
```

把输出的 32 位十六进制与上表比对（不区分大小写）。手机上没有现成的校验工具时，可以跳过这一步直接安装 —— 装不上或装上闪退，再按 [闪退与安装失败怎么办.md](闪退与安装失败怎么办.md) 排查。

## 三、允许安装未知来源的应用

安卓默认只允许装应用商店里的包，装 APK 前要先给安装来源放行。不同品牌入口略有差别，都是在「设置」里找：

- **小米 / Redmi**：设置 → 隐私保护 → 特殊权限 → 安装未知应用，给你的文件管理器或浏览器授权。
- **OPPO / realme / 一加**：设置 → 安全 → 安装外部来源应用（或设置 → 应用管理 → 特殊应用访问）。
- **vivo / iQOO**：设置 → 安全与隐私 → 更多安全设置 → 允许安装未知应用。
- **华为 / 荣耀**：设置 → 安全 → 更多安全设置 → 安装外部来源应用。

安卓 8.0 以后是**按应用逐个授权**的：你用哪个 App 点开的 APK，就给哪个 App 开权限。授权页通常会提示风险，确认是你自己刚下载的文件再继续。

## 四、安装与首次启动

1. 在文件管理器或夸克里点开 `libvio.cloud_v2.2.0.apk`，系统弹出安装界面后点「安装」。
2. 系统要求：这份包的登记信息标注**需要安卓 5.2 以上**，个别下载页标注 4.4 以上，两处口径不一致 —— 以你手机上实际弹出的提示为准，装不上多半就是这一步被拦。
3. 装完首次打开，按弹窗逐项允许权限。播放类应用通常要**存储权限**（读缓存、存观看记录）与**网络权限**；如果第一次全点了拒绝，之后出现黑屏、无法记录进度，去 设置 → 应用 → libvio.cloud → 权限 里补开。
4. 首次启动会拉取片库数据，建议在 Wi-Fi 下打开一次再开始用。

## 五、以后怎么更新

- 新版安装包仍从上文网盘文件夹里取（文件名带版本号，新版本会是新文件名）。
- 同一个包名（`lab.vie.two`）**签名一致**时，直接点新 APK 就能覆盖安装，观看记录和缓存都保留。
- 安装时如果提示「与已安装的应用签名不一致」，说明两份包不是同一个签名，系统不允许覆盖 —— 这种情况只能先卸载旧版再装新版，卸载会清掉本地记录，装回后需要重新积累观看历史。
- 版本号会随时间变化，网盘里当时那份以文件名与本文表格为准；应用内显示的版本以实际安装到的包为准。
