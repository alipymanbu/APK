## 一、打开后你会看到什么

首屏就是「主页」：顶部两个入口——「机器人商店」（挑更多现成机器人）和「添加机器人」（自己新建，见 [自定义机器人怎么创建.md](自定义机器人怎么创建.md)）；中间是已有的机器人卡片；右下角悬浮着一个「开始」按钮；底部三个标签：**主页 / 历史 / 设置**。

- **主页**：机器人列表，就是下面说的这些卡片。
- **历史**：跑过的任务记录，回看之前让 AI 处理过的内容。
- **设置**：模型、权限等全局选项。

## 二、内置机器人分别干什么

装好后自带一批预设机器人，每个卡片对应一类文本任务：

| 机器人 | 你得到什么 |
| --- | --- |
| 重写 | 保持原意不变，换一种表达方式改写你的文本 |
| 总结 | 在原文语言里提炼出简明版本，保留关键信息 |
| 翻译 | 把你给的文本快速翻译成目标语言 |
| 电子邮件 | 帮你起草、回复邮件类文本 |
| 解释 | 把复杂概念或不熟悉的术语讲清楚 |
| 语法检查 | 从语法和风格两方面给修改建议，提升成文质量 |
| 扩展 | 把一句短语或几条要点扩写成完整段落 |
| Facebook帖子优化 | 按社交平台的表达习惯润色帖子文案 |

实际列表以你装的版本为准，卡片按主页排布往下还会滚动出现；缺哪个、多哪个都正常。

## 三、一次完整操作怎么走

典型用法是「先选机器人，再处理文本」：

1. 在主页点中你要用的机器人（卡片会进入它的编辑/说明页，确认这就是你要的那类任务）。
2. 回到主页，点右下角的**开始**按钮启动服务。
3. 到你要处理内容的地方（聊天窗口、输入框、浏览器页面），把文字交给它处理——输出结果可以在「历史」里找回。

处理前把要改的那段文字准备清楚，一次给全，比零碎地分多次丢进去效果稳定。

## 四、触发方式：用特殊字符当场唤起

每个机器人可以设置一个**触发方式**——在输入时敲一串特殊字符，就直接触发这类 AI 任务，不必每次都回 Infuse 主页点卡片：

- 触发字符在机器人的编辑页里配置（见 [自定义机器人怎么创建.md](自定义机器人怎么创建.md)）；
- **把触发字符清空 = 关掉这个机器人的快捷触发**，清空后它不会被字符唤起，只能从主页手动选。

如果你发现「敲了字符没反应」，先去对应机器人的编辑页看看触发方式是不是被清空了。

## 五、聊天模型怎么选

编辑页里的「聊天模型」决定这次回答的质量与速度。按界面自己的说明：**更强的模型可能产出更好的结果，但响应时间可能更长**。所以：

- 改写、翻译这类短任务——默认模型就够，快；
- 总结长文、扩写这种吃理解力的任务——换更强的模型更划算。

具体有哪些可选模型以你版本里下拉列表显示的为准。

## 六、几个提高命中率的用法

- **一个机器人只干一类事**：翻译就纯翻译，别又让它润色——要两种效果就分别调用两个机器人（或建两个自定义的，见下一篇）。
- **给足上下文**：让「重写」改一封邮件时，把收件人是谁、要什么语气一并说清，比只丢一句「改一下」得到的结果可用得多。
- **先看历史再重跑**：同类型任务重复出现时，翻「历史」找到上次的输入输出，稍作修改重发，比从零描述省事。
