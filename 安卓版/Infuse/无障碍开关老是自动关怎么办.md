# 安卓无障碍开关老是自动关怎么办

> 无障碍服务刚打开就被系统弹回、用着用着自己关了——这是系统杀后台，不是应用坏了，按品牌对症修。

## 一、先确认是这个问题

症状对上这几条，就是系统在后台把服务掐了，跟 Infuse 本身无关：

- 无障碍里刚把开关打开，**立马自动弹回关闭**；
- 明明开着，锁屏一次或重启手机后**自己关了**；
- 用着用着突然读不到屏幕文字，回去一看开关是关的。

原因：安卓的省电机制会把「长期驻留后台」的应用当成多余进程停掉，而无障碍服务恰恰必须一直活着。厂商的后台管理越激进（MIUI / ColorOS 最典型），越容易出现。小米社区的官方反馈帖里，开发组给出的解法也是同一套：**省电策略设无限制 + 开自启动 + 加入后台白名单**。

## 二、通用修法（所有品牌先做这三步）

1. **关掉电池优化**：设置 → 应用 → Infuse → 电池（耗电详情）→ 选「无限制」/「不优化」/「允许后台活动」（各叫法不同）。
2. **允许自启动**：同一页面打开「自启动」开关；有的品牌在「应用启动管理」里手动改成手动允许。
3. **最近任务里加锁**：呼出最近任务卡片，对 Infuse 长按或点锁形图标把它锁定，防止一键清理把它扫掉。

改完回无障碍重新打开开关，锁屏再解锁验证一次——还掉就是品牌特有的限制，往下对号入座。

## 三、小米 / Redmi（MIUI、澎湃 OS）

- 应用信息页 → **省电策略** 改「无限制」（默认的「智能限制后台运行」就是凶手）；
- 打开**自启动**；
- 安全中心 → 电池 → 设置里把「锁屏后清除缓存」设为**从不**（不清后台就不会连带停服务）；
- 应用信息 → 权限 → 关闭「**闲置时删除权限或释放空间**」（有的版本叫「暂停非活跃应用」），否则长期不用会被系统自动收权；
- 系统更新后权限可能被重置，升级完回无障碍看一眼开关还在不在。

小米社区反馈帖里还有用户补充：改完设置仍偶发被杀，那就配合后台加锁一起用。

## 四、OPPO / 一加 / realme（ColorOS、realme UI）

ColorOS 有「**权限监控**」，部分版本开了无障碍会**当场弹回**：

1. 设置 → 关于手机 → 版本信息 → 连点「版本号」多次开启开发者模式；
2. 系统设置 → 开发者选项 → 打开「**禁用权限监控**」；
3. 回无障碍再开一次；还不行就先卸载，用自带文件管理器重装，**装完别先打开应用**，直接去无障碍里开启，再启动应用。

无障碍入口按版本不同（截至 2026-09，OPPO 官方支持页面口径）：ColorOS 14.1-15 在「设置 → 辅助功能 → 无障碍」，ColorOS 13-14.0 在「设置 → 其他设置 → 无障碍」，ColorOS 12 在「设置 → 系统设置 → 无障碍」；找不到直接搜「无障碍」。

## 五、三星及其他品牌

- 三星：设置 → 电池 → 后台用量限制里确认 Infuse 不在受限名单；「设备维护 → 电池」里同样设为不优化；
- 通用排查：设置里搜「电池优化」，切到「全部应用」，把 Infuse 排除掉；再检查是否有「睡眠应用 / 深度休眠」名单，从中移除。

## 六、验证修好了没有

改完别急着用，做个完整验证：

1. 打开无障碍，确认 Infuse 开关是开的；
2. 锁屏 → 解锁 → 回去看开关；
3. 重启手机 → 回去看开关；
4. 隔半天再看一次。

四步都还开着才算修好。另外注意：**系统大版本更新会重置部分权限**，升级后按上面的步骤复查一遍即可（见 [常见问题与排查.md](常见问题与排查.md)）。介意耗电的，用完 Infuse 的跨应用功能时手动把无障碍关掉、要用再开，比放任系统反复杀它更省心。
