## 一、这是什么应用

Infuse 是一款安卓端的 AI 助手工具，Google Play 上的包名是 `com.sapiens.assistant.ai`，开发者为 Sapiens Labs，官网在 [infuse.sapiens8.com](https://infuse.sapiens8.com/)。它的用法是：你在刷社交软件、写邮件、读外语内容时，直接调用 AI 帮你改写、总结、翻译，不用切到另一个聊天应用里去。本篇只讲安装：拿包、核对、装上、开权限；装好之后怎么用见 [机器人怎么用.md](机器人怎么用.md)。

注意别弄混：iOS / macOS 上还有一款同名的视频播放器 Infuse（Firecore 出品），与本文讲的完全不是一个应用——搜教程、对包名时认准 `com.sapiens.assistant.ai`。

## 三、下载与安装步骤

1. 打开 [Infuse 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cfdd33bcdeac)，把安装包转存到自己的网盘再下载到手机（直接在线播放/预览拿不到可安装的文件）。
2. 在手机的文件管理器里点这个 `.apk` 开始安装。
3. 如果系统弹出「禁止安装来自此来源的应用」，是正常的拦截——到设置里允许当前来源（浏览器或文件管理器）一次，再回来点安装。各品牌入口略有差别，一般在「设置 → 应用 → 特殊权限 → 安装未知应用」。
4. 装完打开，首次启动会请求联网等基础权限，按提示允许即可。

## 四、系统要求

- **安卓 8.0 及以上**（Google Play 页面标注，截至 2026-09；以官方页面为准）。
- **保持网络可用**：AI 的回答来自在线模型，断网时不会返回结果。
- 无障碍权限：应用要读取你屏幕上的文字才能在其他应用里替你干活，具体开启方式与影响见 [常见问题与排查.md](常见问题与排查.md)。

## 五、装好后先做的第一件事：开启无障碍权限

应用在需要读取屏幕文字时会引导你开启无障碍权限。系统里的路径一般是：

```
设置 → 无障碍（辅助功能）→ 已安装的应用 → Infuse → 开启
```

各品牌入口与叫法不同，找不到就直接在设置里搜「无障碍」。几条实测路径（截至 2026-09，以系统版本为准）：

| 品牌 | 无障碍路径 |
| --- | --- |
| OPPO / 一加 / realme | ColorOS 14.1-15：设置 → 辅助功能 → 无障碍；ColorOS 13-14.0：设置 → 其他设置 → 无障碍；ColorOS 12：设置 → 系统设置 → 无障碍 |
| 小米 / Redmi | 设置 → 更多设置 → 无障碍 |
| 三星 | 设置 → 无障碍 |
| 原生类 | 设置 → 无障碍 → 已安装的应用 / 已下载的服务 |

没开这个权限时，应用本体能打开、机器人列表能看，但跨应用读文字的功能不会生效；开了之后如果**开关自己弹回、用着用着自动关**，那是系统杀后台，不是装坏了——按 [无障碍开关老是自动关怎么办.md](无障碍开关老是自动关怎么办.md) 修。其余权限问题见 [常见问题与排查.md](常见问题与排查.md)。

## 六、更新与卸载

- 官方发新版后，重新从官方渠道或网盘拿新包覆盖安装即可，覆盖安装不会丢掉已有的机器人配置；卸载重装才会丢。
- 想确认自己装的是哪个版本：设置里找到 Infuse 的应用信息页，版本号与包名都在那里，可对照第二节的表格。
