## 一、打开就闪退 / 停在权限页进不去

按出现频率从高到低排：

1. **Android 13+ 停在权限提示页**：这不是闪退，是设计如此——没拿到「所有文件访问」权限就不放你进主页。去系统设置把权限给上，再重开 app。
2. **Android 10 上闪退**：官方给过的应对是「重新进入一次，等软件公告出现后再操作」。原因是首次启动要拉取一条公告内容，节点没取到就崩。
3. **取节点失败导致的反复闪退**：官方提到部分地区访问不到公告接口。换成移动数据再试一次（Wi-Fi 切流量），能进就说明是当前网络到该接口不通。
4. **装完就闪退且以上都不沾**：核对安装包 MD5 是否为 `0c1cf37e03f2e4b512e62ae516111616`（3.1.0 / 78.66M）——文件不完整会表现为安装成功但一打开就退。核对方法见 [下载与安装教程.md](下载与安装教程.md)。

## 二、粘贴链接后解析不出内容

| 现象 | 判断 | 动作 |
| --- | --- | --- |
| 输入框粘贴后毫无反应 | 粘的不是可识别的链接/编号 | 换成分享面板里的「复制链接」原文，或直接输 BV 号 |
| 卡片出来了但点进去空白 | 网络到 B 站接口不通 | 切换网络（Wi-Fi ↔ 流量）重试 |
| 番剧/付费内容解析后没有可选画质 | 账号权益不够 | 用大会员账号登录，见 [账号登录与画质限制说明.md](账号登录与画质限制说明.md) |
| 分享给 app 没反应 | 手机的分享列表排序问题 | 改用「复制链接 → 粘贴」这条更稳 |

多子集视频还要注意：解析弹窗**默认选第一集**，想下别的集先切子集再确认，否则你下到的永远是第一集。

## 三、登录不上 / 登录后没生效

- **二维码扫了提示失败**：二维码有有效期，点刷新重新走一遍「下载二维码 → 跳转扫码 → 相册选图」；
- **确认扫码成功但 app 仍显示未登录**：回到 app 点「完成登录」——这一步是手动的，漏了就停在半路；
- **弹出的登录模式里「云端登录」点不了**：该功能按官方说明未开放，选 **BILIBILIAS 扫码**；
- **换手机后要重新登录**：凭证只存本地，不跨设备同步，属正常现象；
- **老版本（2.1.0 及以前）强制要求登录**：只能走完登录流程才能进主界面。

## 四、画质档位不对

先建立正确预期：**档位 = 你的账号权益 ∩ 视频本身提供的规格**（详见 [账号登录与画质限制说明.md](账号登录与画质限制说明.md)）。排查顺序：

1. 登录了吗？没登录就是 480P 封顶；
2. 是大会员吗？1080P60、4K、HDR 都要大会员权益；
3. 是付费番剧吗？付费内容必须大会员账号；
4. 视频本身有这个档位吗？稿件最高 720P，什么账号都下不出 4K；
5. 以上都满足还是没有？刷新页面重新解析一次，让档位列表重新拉取。

## 五、文件下好了但找不到

1. 确认 app 里任务状态是「完成」而不是「进行中」；
2. 按 [下载文件保存位置与管理.md](下载文件保存位置与管理.md) 第一节的路径去找；
3. **最近改过保存路径**？旧文件还在旧目录，新文件才去新目录——两头都看一眼；
4. 开了「合并/导入 B 站后删除原文件」？成品可能已被搬进 B 站的缓存体系，或者原文件已被删掉。

## 六、删除失败 / 残留文件

历史版本存在「改过存储路径后删除失败」的情况：app 里点删除，文件却还在。处理办法是绕过 app——直接去对应目录手动删。删除前确认文件确实不再需要，这一步没有回收站。

## 七、安装与更新的坑

- **提示「解析错误」**：下载的 apk 不完整或损坏，重新下载；
- **提示「与已安装版本签名不同」**：你手头的包与手机上已装的不是同一签名来源，先卸载旧的再装新的（卸载会丢数据，重要文件先备份）；
- **1.x 老版本直接升 2.x/3.x**：官方建议先卸载再装，跨大版本升级可能要求清空数据，务必先把已缓存的文件拷出来。

## 八、还想问 / 想反馈

项目已停止公开发布与维护（时间线与影响见 [下载与安装教程.md](下载与安装教程.md) 第二节），因此**没有官方客服可找**。历史上的反馈渠道是 BILIBILIAS 的 QQ 频道（早年在腾讯兔小巢，该平台转收费后迁出），去那儿能翻到其他用户遇到过的同类问题——但停止维护后是否还有人答复，以频道内实际状态为准。

对于仍在正常使用的情况，多数问题都能在本文前七节里对上号：先按症状找条目，再回头看对应专题篇。
