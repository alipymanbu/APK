## 一、打不开 / 闪退 / 白屏

按代价从小到大试，**每做完一步就试一次**，能开就停：

1. **确认不是网络问题**：换个 Wi-Fi 或切到流量打开 —— Keep 的内容要在线拉，网络本身不通时表现就像打不开。
2. **强行停止再开**：设置 → 应用 → Keep → 强行停止，再点图标。
3. **清缓存**：设置 → 应用 → Keep → 存储 → **清除缓存**（别点「清除数据」，会清掉本机记录与登录态）。
4. **看有没有新版本**：商店页当时若有新版就先更，崩溃类问题多数在新版本里修 —— 更新节奏以官方页面为准。
5. **重启手机**再试。
6. **重装**：卸载后重新安装 APK（记录都在账号云端，本地缓存的课程视频会没）。装完闪退或报「解析包时出现问题」，基本是包没下完整，重新下一份，见 [下载与安装教程.md](下载与安装教程.md)。

## 二、登录不上 / 收不到验证码

- **收不到短信验证码**：先确认手机没欠费、没开短信拦截；隔一会儿重发；还是收不到就改用微信/QQ/微博等第三方登录顶上。
- **忘了用什么登录的**：按手机号、邮箱、第三方账号逐个试 —— Keep 支持手机号、邮箱、微信、QQ、微博、Apple ID 这些方式（依据官方隐私政策）。
- **换号了**：在「我的 → 设置 → 账号与安全 / 更换手机号」里按提示换；原号码已停用换不了的，走 App 内在线客服或服务热线 400 632 1666。想彻底销号的路径与注意事项见 [注销账号与换手机登录.md](注销账号与换手机登录.md)。
- 邮箱登录后官方会要求补绑手机号（实名制要求），按提示绑一次即可。

## 三、记录 / 数据不对

| 症状 | 去哪查 |
| --- | --- |
| 跑步轨迹画歪、距离虚高虚低、跑一半断了 | [跑步轨迹不准怎么调.md](跑步轨迹不准怎么调.md) |
| 手环/手表数据没进 Keep | [手环和运动数据同步设置.md](手环和运动数据同步设置.md) |
| 课程点了没反应、视频加载不出来 | 网络 → 清缓存 → 更新，按第一节顺序走 |
| 会员开了权益没到账 | [会员价格与自动续费取消.md](会员价格与自动续费取消.md) |

通用一条：本地缓存异常时「清缓存 + 重启」能解决大部分小毛病；**不要随便点「清除数据」**，那等于把登录态和本机记录一起抹掉。

## 四、权限被拒了怎么补

系统设置 → 应用 → Keep → 权限，逐项检查：

- **位置**：户外跑必需（不给就记不了轨迹）；
- **存储/文件**：下载课程、缓存视频；
- **相机**：扫自家设备二维码、拍照记食物；
- **蓝牙**：连手环、体脂秤、跑步机；
- **通知**：训练与直播提醒；
- **身体活动**：步数、活动量统计。

部分手机还要额外做「后台运行 / 电池优化白名单」设置，否则息屏后被系统杀掉，做法见 [跑步轨迹不准怎么调.md](跑步轨迹不准怎么调.md) 第二节。

## 五、官方文档入口

需要权威说法时看这几处（官方页面，内容会更新，以当时显示为准）：

- 官网：[keep.com](https://keep.com)；官方下载页：[www.calorietech.com](https://www.calorietech.com)
- 隐私政策：[show.gotokeep.com/privacy](https://show.gotokeep.com/privacy)（数据怎么收集、怎么注销账号都在里面）
- 应用权限说明：[m.gotokeep.com 权限文档](https://m.gotokeep.com/fd-page/document/show?param=appAuth)
- 应用功能说明：[m.gotokeep.com 功能文档](https://m.gotokeep.com/fd-page/document/show?param=appIntro)
- 服务热线：**400 632 1666**；隐私相关邮箱：privacy@keep.com

排查到这还解决不了的，直接在「我的 → 客服」里描述问题（带上版本号与截图），比自己反复重装快。
