# 手环和运动数据同步设置

> 这篇讲华为运动健康、小米手环上的运动数据怎么并进 Keep，以及 Keep 自家硬件怎么绑。

## 一、先说结论

Keep 自己不产所有硬件：华为手环/手表的数据要经**华为运动健康云**中转授权进来，小米手环要先在**小米运动健康**里授权，Keep 自家的手环、手表、动感单车、跑步机、体感运动主机则直接在 Keep 里蓝牙绑定。授权是**有时效的**，隔几个月不同步，多半是授权过期了。

## 二、华为运动健康 → Keep

路径取自华为官方客服文档（HarmonyOS 4.3 及以下、三方安卓、iOS 与 HarmonyOS 5 的入口略有差异）：

1. Keep 内：**运动 → 装备 → 本次运动装备 → 数据源 → 心率 → 添加设备**，上滑到「第三方与服务」选**华为运动健康 → 去授权**，用同一华为账号登录完成绑定。
2. 华为侧确认两个开关打开：**「同步运动数据到云」**（HarmonyOS 4.3 及以下在「我的 → 隐私管理」，5.0 在「我的 → 设置 → 运动健康数据管理」）与**「自动同步健康数据到云」**。
3. 手环的数据要**先同步进华为运动健康、再上传到云**，第三方读取不是实时的 —— 急着看就先在华为侧点手动同步，再到 Keep 里手动同步一次。

三条限制（华为官方说明）：

| 限制 | 内容 |
| --- | --- |
| 绑定有效期 | 单次授权一般 **6 个月**，到期要重新授权 |
| 同步范围 | **只有授权之后产生**的运动数据；只同步部分穿戴设备的运动类型（户外跑、室内跑、骑行、登山、爬楼、走路、跑步机、室内单车、开放水域游泳、自由训练等），且**不带轨迹** |
| 账号 | 儿童账号不支持同步到第三方 |

想通过「华为运动健康服务」方式绑定来同步全部运动类型（含轨迹），按华为文档在数据分享与授权里走对应入口；两种绑定方式的差别以华为页面当时说明为准。

## 三、小米手环 → Keep

公开教程的路径如下（单一来源，各版本入口名称可能不同，以你手机上实际界面为准）：

1. 先在**小米运动健康** App 里把手环绑好、固件为最新；
2. 小米运动健康 →「我的」→ 第三方接入 / 数据共享 → 选 **Keep** → 授权（可能要求登录 Keep 账号）；
3. 回到 Keep：「我」→ 智能硬件 / 设备管理 → **添加设备** → 找到你的手环型号 → 确认同步权限。

连不上先检查：手机蓝牙开着、两个 App 都是最新版、手环电量够；仍失败就解绑重连一次。同步内容一般包括步数、卡路里、心率、睡眠和运动记录，具体范围以两边 App 的说明为准。

## 四、Keep 自家硬件

Keep 手环、Keep 手表、动感单车、跑步机、体感运动主机这类自家设备，在 Keep 内直接绑定：**蓝牙 + 相机扫码**（扫设备上的二维码完成匹配），入口一般在「我 → 设备 / 智能硬件 → 添加设备」。绑定需要给 Keep 蓝牙和相机权限，拒绝了就搜不到设备。

动感单车的直播课、自动调阻依赖会员权益，权益分层见 [会员价格与自动续费取消.md](会员价格与自动续费取消.md)。

## 五、同步不进来时按这个顺序查

1. 云侧有没有数据：打开对应运动 App 看记录是否已同步完成，没有就先手动同步它自己；
2. Keep 里的授权状态：设备/数据源列表里那条还在不在，掉了就重新授权（6 个月到期是正常原因）；
3. 权限：位置、蓝牙、通知有没有被系统收回；
4. 两边 App 都更到最新版再试；
5. 还不行就解绑 → 重绑一次，重启手机。

同步的是**你自己的设备在你自己账号下的运动数据**，只在你自己的账号里查看。整体故障排查见 [常见问题与解决方法.md](常见问题与解决方法.md)，轨迹本身画不准的部分见 [跑步轨迹不准怎么调.md](跑步轨迹不准怎么调.md)。
