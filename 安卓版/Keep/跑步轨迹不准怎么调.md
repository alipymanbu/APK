# 跑步轨迹不准怎么调

> 这篇讲 Keep 户外跑轨迹画歪、距离对不上、跑到一半不记录时，你能在手机上改哪几个设置。

## 一、先说结论

轨迹不准九成出在**权限和省电**上，不在 App 本身：定位权限没给足、手机省电模式把 Keep 的后台杀了、在楼群里跑信号被挡。按下面第二节的清单设一遍，多数情况能明显改善；剩下的误差是 GPS 的物理极限，谁都躲不掉。

## 二、跑之前把这几项设对

1. **定位权限**：系统设置 → 应用 → Keep → 权限 → 位置信息，选**始终允许 / 使用期间允许**（不同品牌措辞不同），并且选**高精度模式**（同时用 GPS + Wi-Fi + 基站）。只给「仅使用期间」在息屏后可能被系统回收。
2. **关掉省电模式**：跑的时候别开系统的省电/低电量模式 —— 它会降频并限制后台定位，这是「跑到一半断了」「整段直线」最常见的原因。
3. **电池优化白名单**：系统设置 → 电池 → 电池优化（或「省电策略」），把 Keep 设为**不优化 / 允许后台运行**；部分品牌还要在「应用启动管理」里改成手动、允许自启动与后台运行。
4. **保持运动页在前台**：尤其第一次这样跑，让 Keep 的运动记录页亮着屏跑完一次；确认正常后再试息屏。
5. **网络别断**：轨迹点要靠网络上传，跑前确认数据或 Wi-Fi 可用。

## 三、跑的时候怎么减少偏差

- **等定位锁定再出发**：开始前站在开阔处，等它提示卫星就绪；在楼道、地库里点开始，前几百米必飘。
- **手机固定好**：臂包放上臂外侧、腰包放腰间，别攥在手里甩 —— 剧烈晃动会让定位点跳。
- **路线选开阔的**：高楼夹道、桥下、隧道、密林是漂移重灾区；沿河边、公园步道跑信号最稳。
- **电量留够**：低于 30% 时很多手机会自动进省电策略，顺手把这一项也查了。

## 四、距离「虚高」和「虚低」分别怎么回事

以下来自用户实测反馈（非官方口径），两边都可能遇到：

| 现象 | 常见原因 | 怎么办 |
| --- | --- | --- |
| 距离偏长、轨迹呈锯齿/蛇形 | GPS 在楼群里漂移，点位来回跳 | 换开阔路线；对照地图复核，别拿它算配速成绩 |
| 跑道上距离偏短（400 米一圈显示不足） | 跑道小半径下定位点被「切直线」 | 跑道场景的数值只能当参考 |
| 公园绕圈总里程缩水 | GPS 直连抄近路，判定穿了绿地 | 同上；要准就以手表/操场圈数为准 |
| 用了心率带/手表还是不准 | 手表与手机是两套定位，各有偏差 | 见 [手环和运动数据同步设置.md](手环和运动数据同步设置.md) |

有用户反馈同时开手机 App 和运动手表交叉对比更可靠 —— 这是使用经验，不是官方结论。

## 五、设了还不行的排查顺序

1. **重启定位**：系统设置里关掉再打开「定位服务」；
2. **清缓存**：设置 → 应用 → Keep → 存储 → 清除缓存（**别点清除数据**，那会把本机记录和登录态一起清掉）；
3. **确认权限没被系统「自动重置」**：部分安卓版本更新后会收回后台定位权限，重新给一次；
4. **更新版本**：定位类 bug 常在新版本修掉，官方更新以商店页当时显示为准；
5. **重启手机**再跑一次测试。

都不行、且每次都断在同一个位置，多是环境信号问题而非 App 问题；整个 App 层面的故障排查见 [常见问题与解决方法.md](常见问题与解决方法.md)。
