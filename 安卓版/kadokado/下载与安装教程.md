## 一、安装前先确认三件事

1. **系统版本**：安装包要求安卓 5.2 及以上（以安装包信息为准）。系统太旧会在安装时报「解析包时出现问题」，或者文件管理器里压根不出现「安装」按钮。
2. **存储空间**：安装包本体只有 16.05 MB，占用很小，但建议预留 100 MB 以上给运行缓存。
3. **允许安装未知来源应用**：从网盘拿到的 APK 不经过应用商店，安卓默认会拦截。点开安装包时系统会弹一次授权提示，按提示允许即可。不同品牌的叫法不同：「安装未知应用」「允许来自此来源的应用」指的都是它，授权对象选你用来打开 APK 的那个文件管理器或网盘 App。

## 二、获取安装包

先在电脑或手机浏览器打开 [https://pan.quark.cn/s/60d2c9d29385](https://pan.quark.cn/s/60d2c9d29385)（KadoKado 安装文件资源，夸克网盘）：

1. 手机上装好「夸克」App 并登录；
2. 打开上面的分享链接，点「保存到网盘」把它转存进自己的网盘；
3. 在夸克 App 里找到转存后的 `kadokado_v1.8.67.apk`，点下载，下载完成后直接点开即可进入安装。

拿到包之后，建议先核对一遍基本信息，确认下载完整：

| 项目 | 值 |
| --- | --- |
| 文件名 | kadokado_v1.8.67.apk |
| 版本 | 1.8.67 |
| 大小 | 16.05 MB |
| MD5 | A2C382740914A33DF5B4F18809C4B755 |
| 包名 | com.kadokawa.kadokado |
| 开发者 | KADOKAWA TAIWAN CORPORATION（台湾角川） |

大小对不上、点开就报解析错误，多半是下载中断了，重新下载一次再装。

## 三、安装步骤

1. 在文件管理器（或夸克 App 的下载列表）里点 `kadokado_v1.8.67.apk`；
2. 系统弹出「是否允许安装」→ 点允许；
3. 等进度条走完，点「打开」或回桌面点 KadoKado 图标。

安装卡住的对照：

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 解析包时出现问题 | 下载不完整 / 系统版本过低 | 重新下载并核对大小与 MD5；确认安卓版本达标 |
| 提示存储空间不足 | 剩余空间太小 | 清出空间后重装 |
| 安装到一半被中断 | 手机管家类软件拦截 | 在安全软件里放行，或暂时关闭拦截再装 |
| 覆盖安装失败 | 手机上已有签名不同的旧版 | 卸载旧版后再装（收藏与购买记录跟账号走，卸载不丢） |

装不上并且对照表里没有的情况，去 [常见问题排查.md](常见问题排查.md) 里找更细的处理办法。

## 四、首次启动

- 需要联网才能加载内容，首次启动建议在 Wi-Fi 下进行；
- 不登录也能浏览部分内容，但收藏、追更推播、购买章节都需要账号，注册与登录步骤见 [注册登录与序号兑换.md](注册登录与序号兑换.md)；
- 首次启动会请求通知权限，如果你打算追连载，建议允许——收藏作品的更新提醒靠它送达（详见 [找书与阅读功能.md](找书与阅读功能.md) 的收藏与推播一节）。

## 五、版本与更新说明

- 本篇对应的 1.8.67 是资源打包时的版本，官方会持续更新，最新版本号以官方渠道当时显示为准；
- 装了新版本不需要先卸载，直接用新安装包覆盖安装即可；
- 收藏记录与付费章节的阅读权限绑定在账号上，换手机后登录同一账号就能继续读。
