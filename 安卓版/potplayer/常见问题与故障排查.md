# 常见问题与故障排查

> potplayer 安卓版用起来会碰到的问题按症状分好类：黑屏有声无画、扫不出视频、闪退打不开、字幕不显示等。

## 一、排查前先做三步

不论哪种症状，先做这三步能筛掉一大半问题：

1. **先分清是「所有视频」还是「某一个文件」出问题** —— 只有某个文件坏，换一个文件播就正常，问题在文件本身，不在播放器；
2. **确认权限没被系统收回** —— 手机「设置 → 应用管理 → potplayer → 权限」里，存储权限仍是允许状态（系统更新或清理软件常会悄悄收回）；
3. **还是不行就覆盖安装一次网盘里的版本**（见 [下载与安装教程.md](下载与安装教程.md) 第六节），排除装到一半的坏包。

## 二、播放黑屏但有声音

声音正常、进度条在走、画面全黑 —— 多半是横竖屏适配或解码路径的问题，按顺序试：

1. 点画面呼出控制栏，点进度条最右侧的方框图标，**把横屏强制播放切成竖屏自适应**，退出该视频重新进入；
2. 仍黑屏：开手机的自动旋转，把手机横竖换一次方向再切回来；
3. 只有某一个文件黑屏：该文件的编码或本身损坏，换播放器打开验证一下；所有文件都黑屏：清一次应用缓存（设置 → 应用管理 → potplayer → 存储 → 清除缓存），再按第 1 步重试；
4. 改过解码 / 渲染设置后才出现的，把播放器设置恢复默认值再试。

## 三、首页扫不出视频 / 少了文件

- 存储权限没给或被收回 → 去系统设置里打开（这是最常见的原因）；
- 刚下载完的文件还没被扫到 → 列表下拉刷新，或退出重进一次；
- 文件在受保护目录（部分品牌手机的「隐私保护」会隐藏目录）→ 到系统设置里对该目录放开访问；
- 某些冷门格式没被识别 → 用「打开文件」手动选中播放，能播就只是没被扫进来；
- 视频本身损坏 → 换一个文件验证。播放列表里的手动删除也会让文件「消失」，注意别误删。

## 四、打不开、闪退、卡死

| 现象 | 先查什么 |
| --- | --- |
| 点图标没反应 / 秒退 | 存储空间是否不足；清一次应用缓存；仍闪退就按 [下载与安装教程.md](下载与安装教程.md) 覆盖重装 |
| 播到某个文件必闪退 | 该文件损坏或编码特殊，跳过它即可；所有文件都闪退才需要重装 |
| 播放卡顿 | 先关小窗与其他占内存的应用；4K / 高码率文件在低端机上卡属性能不足，换更低码率的文件 |
| 后台被杀、切出去就停 | 到手机设置里给 potplayer 开「后台运行 / 省电策略设为不限制」，各品牌路径不同，按你手机的设置项找 |
| 安装时提示「应用未安装」 | 见 [下载与安装教程.md](下载与安装教程.md) 第五节 |

## 五、字幕相关

- **字幕不显示**：外挂字幕文件是否与视频**同名、同文件夹**；存储权限是否给了；字幕文件本身是否完整；
- **字幕比画面早 / 晚**：在字幕设置里调「时间偏移」，正负逐段试；
- **字幕超出屏幕、字号过大**：调字幕大小与位置参数，切回默认样式即可复原；
- 某些机型上个别外挂字幕加载不出来（新系统上时有发生）→ 先覆盖升级到网盘里的最新一份，再试；仍不行就把字幕转成 `.srt` 格式同名放置。

## 七、改乱了设置怎么恢复

手势灵敏度、解码模式、字幕样式这些改坏了不要紧：进播放器**设置 → 恢复默认值**（找不到这项就清缓存，设置会回到初始状态）。恢复只影响播放器偏好设置，**不会删你手机里的视频文件**，最多丢掉播放记录和自定义手势。
