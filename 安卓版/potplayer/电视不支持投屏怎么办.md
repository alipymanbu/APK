# 电视不支持投屏怎么办

> 电视搜不到、是老电视、没有投屏功能时的几条出路：装接收端应用、走系统镜像、有线直连，各自适用什么情况。

## 一、先判断你的电视属于哪种

在 [投屏到电视的方法.md](投屏到电视的方法.md) 里按步骤搜了、列表始终是空的，先分清电视是哪一类：

| 电视情况 | 判断依据 | 走哪条路 |
| --- | --- | --- |
| 智能电视，但搜不到 | 电视能自己装应用、能上网 | 多半是投屏服务没开或网络问题，先回投屏篇第三节排查；仍不行装接收端应用（见下） |
| 老电视 / 非智能电视 | 不能装应用，只有 AV 或 HDMI 输入 | 有线直连或投屏棒（见第四节） |
| 电视有投屏功能但要会员 | 打开投屏应用弹付费提示 | 换系统级镜像（见第三节），或装第三方接收端应用 |

**电视到底支不支持无线投屏，看它有没有这两种能力**：DLNA（应用内把音视频推给电视播）与 Miracast（整屏镜像）。官方客服的说法是：搜不到设备即说明电视这两者都不支持，此时在手机端与电视端各装一个第三方投屏类应用即可 —— 这是厂商支持文档给出的正式口径。

## 二、最省事的一条路：两端都装投屏应用

手机和电视（或电视盒子）都装同一个第三方投屏应用，两边连同一 WiFi：

1. 先在电视上装 —— 电视自带应用商店搜「投屏」「乐播」一类；电视商店搜不到的，从电脑下载电视端 apk 拷进 U 盘，插电视上安装；
2. 手机装同一应用的手机版；
3. 两端都打开、连同一 WiFi，在手机端选电视设备。

这条路对老电视也适用（只要电视能装应用），是官方客服建议的兜底方案。**注意**：投屏应用只是打通链路，播的还是 potplayer 里的文件 —— 先在 potplayer 里把视频播起来，再用它的投屏图标，或者用手机端投屏应用「投本地视频」。

## 三、系统级镜像：把整块屏幕投上去

应用内投屏（potplayer 右上角图标）推的是**那一个视频**；系统镜像（Miracast）投的是**整块手机屏幕**，你在手机上干什么电视上都显示。

- **在哪开**：手机「设置 → 连接与共享 / 投屏 / 无线显示」（各品牌叫法不同），打开后搜设备；
- **和应用内投屏的区别**：镜像走 WiFi Direct、不依赖路由器质量，画面跟手；代价是手机屏幕必须亮着、通知也会投到电视上；
- **适合谁**：电视端不认 potplayer 的应用内投屏、但支持 Miracast 的情况；以及要播电视上没有的应用里的内容。

DLNA 与 Miracast 的差别一句话：**DLNA 只推音视频、手机可以锁屏干别的；Miracast 是整屏复制、手机得一直亮着**。potplayer 的投屏图标属于前者这一类（推内容），系统设置里的投屏开关属于后者。

## 四、有线与硬件：最稳的兜底

- **HDMI 直连**：手机支持视频输出（多为 USB-C）的，一根转接线连电视 HDMI 口，电视切到对应信号源就是有线镜像 —— 零延迟、不受 WiFi 影响；
- **投屏棒 / 电视盒子**：插电视 HDMI 口的接收设备（当贝、小米盒子一类），装上后既有了投屏接收能力，也有了装应用的系统，老电视一次解决两个问题；
- **AV 转接的老电视**：走投屏棒更现实，转接线方案画质损失明显。

## 五、投上了但体验差怎么处理

- **卡顿、掉线**：先回 [投屏到电视的方法.md](投屏到电视的方法.md) 第三节做网络排查（同网段、关 AP 隔离、重启路由）；
- **音画不同步**：镜像模式下常见，改用应用内投屏（推内容而非镜像）通常更稳；
- **直播源投上去卡**：源本身不稳，先按 [导入m3u直播源的方法.md](导入m3u直播源的方法.md) 第四节确认源能不能播，再谈投屏；
- **黑屏、闪退**：手机端的问题归 [常见问题与故障排查.md](常见问题与故障排查.md)。
