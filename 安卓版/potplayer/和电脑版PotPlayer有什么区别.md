# 和电脑版PotPlayer有什么区别

> 安卓手机上这款 potplayer 和电脑上那款知名的 PotPlayer 是不是同一个？本篇按发行方、包名、平台逐项对照，帮你分清再装。

## 一、为什么会有这篇

电脑上那款 PotPlayer 是老牌 Windows 播放器，官网 [potplayer.tv](http://potplayer.tv) 只提供 Windows 安装包（x86 / x64 / ARM64）。而你在安卓应用市场和各种下载页看到的「potplayer」，包名是 `com.potplayer.sc.qy.cloud`，分发页标注的厂商是成都恒盛青云科技有限公司。**两者同名，但发行主体与目标平台并不相同**，装之前分清楚，才不会拿电脑版的使用习惯来套手机版，也不会下错安装包。

## 二、逐项对照

| 对照项 | 电脑版 PotPlayer | 本篇讲的安卓版 potplayer |
| --- | --- | --- |
| 平台 | Windows 7/8.1/10/11 | Android |
| 官网入口 | [potplayer.tv](http://potplayer.tv)（提供 Windows 安装包下载） | 无公开独立官网，安装包见下方网盘 |
| 分发页标注厂商 | Kakao（韩厂，官网下载链接走 `kakaocdn.net`） | 成都恒盛青云科技有限公司 |
| 安装包形态 | `PotPlayerSetup.exe`（电脑安装程序） | `.apk`（手机安装包） |
| 包名 | 不适用 | `com.potplayer.sc.qy.cloud` |
| 操作方式 | 鼠标右键菜单 + F5 设置面板 + 快捷键 | 触屏手势 + 控制栏图标 |
| 典型用法 | 桌面本地视频、快捷键切台、各种渲染器设置 | 手机本地视频、手势调音量亮度、投到电视、导入 m3u 源 |

**同名不代表同一家**：网上不少介绍页面把两者混着写（甚至直接说手机版由韩国厂商开发），而分发页的厂商信息与官网下载域名对不上。这属于公开资料本身口径不一，本篇只把两边的事实并排列出，不替你下结论 —— 你只要知道：**要在手机上装，认准包名 `com.potplayer.sc.qy.cloud` 就不会错**。

## 三、你该装哪个

- 想在**手机**上播本地视频、投电视、导入直播源 → 装安卓版，安装步骤见 [下载与安装教程.md](下载与安装教程.md)；
- 想在**电脑**上用 → 去 [potplayer.tv](http://potplayer.tv) 下 Windows 安装包，那款的设置界面（F5 面板、渲染器、快捷键）和手机版完全不同，别照搬；
- 想两个都用 → 各装各的，互不影响，但**播放记录、设置不互通**，电脑上配好的字幕样式不会带到手机。

## 四、装错了会怎样

- 把 `.exe` 传到手机上点 → 装不了，安卓只认 `.apk`；
- 装到同名但不同包名的另一款播放器 → 设置项和本篇描述对不上号，用 [下载与安装教程.md](下载与安装教程.md) 第二节的包名核对法验证一下；
- 想把电脑版的设置导出给手机版用 → 做不到，两边不是同一个产品，设置格式也不同。

装好后界面怎么走、手势和倍速在哪，见 [本地视频播放与手势设置.md](本地视频播放与手势设置.md)；出问题先翻 [常见问题与故障排查.md](常见问题与故障排查.md)。
