## 一、投屏的前提条件

三个条件缺一个都投不出去，先逐条对：

1. 手机和电视 / 电视盒子连在**同一个 WiFi** 下（连的是 2.4G 还是 5G 频段无所谓，但必须是同一个路由器发出的网络；手机用流量、或电视插网线接到别的网络都不行）；
2. 电视端有可用的投屏接收能力（智能电视自带的投屏功能、或外接盒子的投屏应用）；
3. 手机端 potplayer 已给网络权限 —— 它靠网络扫描设备。

## 二、投屏步骤

1. 打开 potplayer，在首页选一个视频点开播放；
2. 点视频**右上角的投屏图标**（TV 样式的图标）；
3. 界面进入「投屏到电视」，等它搜索周边设备，一般几秒内出列表；
4. 在列表里点你的电视名称，手机画面即同步到电视上。

投屏成功后可以锁屏、切到后台，电视端继续播，不影响手机干别的。

## 三、搜索不到投屏设备时的排查

按顺序做，做到哪一步出结果就停：

1. **确认同一个 WiFi** —— 手机连的 WiFi 名和电视连的是否一致；家里有「主路由 + 子路由 / 访客网络」的，手机和电视要落在同一个网段。这是最常见的原因；
2. **重启电视端**：把电视（或盒子）断电重启；电视端的投屏接收应用若是旧版，先升级到最新版再试；
3. **重启手机与路由器**：手机重启后重开投屏搜索；路由器也断电重启一次 —— 路由器的「AP 隔离 / 访客网络」功能会拦住设备互相发现，进路由器设置把它关掉；
4. 换一个视频再试一次：个别在线流地址本身不支持投屏协议，本地视频不受此限制。

**几轮都搜不到，说明电视那侧不支持应用内投屏** —— 换接收端应用、系统镜像、有线直连这几条路，见 [电视不支持投屏怎么办.md](电视不支持投屏怎么办.md)。

## 四、两种投屏方式的区别（选错会以为坏了）

手机上其实有两个「投屏」，行为不同，别混用：

| | potplayer 里的投屏图标（应用内投屏） | 系统设置里的投屏 / 无线显示（屏幕镜像） |
| --- | --- | --- |
| 投出去的是 | 只有那一个视频（走 DLNA 一类的内容推送） | 整块手机屏幕，所有界面都跟着显示 |
| 投出去后手机 | 可以锁屏、切去干别的 | 得一直亮屏，通知也会出现在电视上 |
| 依赖 | 手机与电视同一路由器网络 | 走 WiFi 直连，对路由器依赖更低 |
| 适合 | 正常看片（推荐走这条） | 电视不认应用内投屏、或要投别的应用的画面 |

**先在 potplayer 里播起来，再点它的投屏图标** —— 这条路投出去的是内容，手机可以随手放一边；只有它走不通时才考虑系统镜像，那样手机就得留在亮屏状态。

## 五、常见疑问

**投上了但画面卡 / 音画不同步**：多为 WiFi 信号弱或带宽被占，让手机靠近路由器、关掉正在下载的大文件再试；在线视频源本身不稳时，本地文件投屏比在线流稳定。

**投屏成功但电视端没声音**：电视一般会切成对应的音频输出，检查电视音量有没有被调到 0、是否接了蓝牙音箱；手机端音量条只管手机本身。

**想投的是 m3u8 直播源**：先按 [导入m3u直播源的方法.md](导入m3u直播源的方法.md) 把源加进来播起来，再点投屏图标，流程相同；直播源自身不稳定时投屏端会跟着卡。

**播放中的其他操作**（手势、倍速、小窗）见 [本地视频播放与手势设置.md](本地视频播放与手势设置.md)；投屏本身反复失败、或点开视频就退，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
