## 一、vivo 为什么要走专门流程

老 vivo 机型把主题文件放在你访问得到的目录里；主题应用（i 主题）7 版之后改存到受保护目录（`/data/bbkcore/theme/.dwd`），普通应用写不进去，只有 vivo 自家的部分系统应用能访问。zFont 3 的 Vivo 方法就是借用这两个系统应用完成写入：

- **vivo 文件管理**（File Manager）：需要 6.11.4.1 或更早版本
- **vivo 文档**（Documents）：约 4.2.2.2 版本

官方实测通过的环境是：vivo V27E，FunTouchOS / OriginOS 的 Android 13–15，文件管理 6.8.3.2、文档 4.2.2.2、主题应用 11.0.7.0 与 17.6.8.2。你的机型不在名单里也可能能用，但要有「版本组合不对就失败」的心理准备；机型与系统版本的总体情况见[免root机型兼容清单](免root机型兼容清单.md)。

## 二、操作步骤

1. 安装上面两个 vivo 应用之一，版本对号入座。
2. 用「文件管理」的话：打开文件管理 → 右上角三点菜单 → 设置 → 打开「显示隐藏目录和文件」。这一步不开，后面必然报错。
3. 打开 zFont 3，在方案里选 Vivo 方法，严格按界面提示逐步执行——一步完成再做下一步，不要跳步、不要并行点。
4. 走完后到系统「设置 → 显示 → 字体」确认新字体出现并选中（成功后的验证方式与普通流程一致，见[换字体步骤详解](换字体步骤详解.md)）。

## 三、排错对照

| 现象 | 处理方法 |
| --- | --- |
| 提示「目标文件夹不存在」 | 先确认文件管理已开「显示隐藏目录和文件」；仍不行，把文件管理换成 6.11.4.1 以下的旧版本再试 |
| 注入步骤反复循环停不下来 | 系统设置 → 应用管理 → 主题（Themes）→ 强制停止 → 清除数据，然后从第一步重新来 |
| 一直失败 | 换不同版本的文件管理 / 文档组合再试；官方明确说明此方法不保证覆盖所有机型，最后可向 vivo 客服反馈希望开放自定义字体 |

## 四、Android 12 及以下不需要这篇

官方兼容口径里，vivo / iQOO 的 Android 12 及以下直接走普通应用流程即可，不用本篇的专门方法；这篇针对的是 Android 13 及以上的 FunTouchOS / OriginOS。换 emoji 的需求与字体同机制，见[emoji表情更换与常见问题](emoji表情更换与常见问题.md)。
