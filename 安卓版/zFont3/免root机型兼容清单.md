## 一、先看品牌，再看系统版本

免 root 换字体依赖各厂商主题系统的漏洞或开放接口，所以支持情况由「品牌 + 系统版本」共同决定。下面是官方帮助页给出的对照（截至检索时，以官方页面为准）：

| 品牌 / 系统 | 免 root 支持情况 |
| --- | --- |
| 三星（One UI） | 支持范围最广（Android 4.4 至 Android 14），但 2026 年 3 月补丁起免 root 通道被系统签名校验拦下，详见[三星OneUI更新后字体失效怎么办](三星OneUI更新后字体失效怎么办.md) |
| 小米 / POCO / Redmi（MIUI、HyperOS） | 全版本支持 |
| 华为（EMUI、HarmonyOS） | 全版本支持 |
| 荣耀（EMUI、Magic UI） | 全版本支持 |
| LG（LG UX） | 全版本支持 |
| vivo / iQOO（Funtouch OS、OriginOS） | Android 12 及以下支持；Android 13 起要按专门方法操作，见[vivo机型换字体方法](vivo机型换字体方法.md) |
| OPPO / realme（ColorOS） | Android 9 及以下支持；Android 10 起需满足地区条件 |
| 一加（OxygenOS） | 需设备带主题商店、且设置里能切换地区 |
| Tecno / Infinix（hiOS、XOS） | 需系统设置里提供「字体」选项 |
| ASUS | 兼容性不定，需实测 |

你的机型不在上表或标记为「不确定」时，可以先用应用内的字体试一次：应用失败通常会有提示，不会造成系统损坏；实在不行就走 root 模块路线（见第四节）。

## 二、OPPO / realme / 一加的地区限制

Android 10 之后，ColorOS 对主题字体加了地区限制。官方说明的处理方式是：如果系统设置里能找到「切换地区」选项，把地区切到**缅甸（Myanmar）**，主题字体接口就会放开。

你要付出的代价是：系统的应用商店、部分本地化内容会跟着切到缅甸区。换完字体后可以切回原地区，但部分机型切回后字体也会跟着还原，需要自己权衡。切换入口一般在「设置 → 其他设置（或系统）→ 地区」。

## 三、vivo / iQOO 从 Android 13 起的情况

OriginOS 在 Android 13 之后收紧了主题接口，官方口径是「兼容性可能有所不同」。实测是否可用只能以你自己的机型为准：装上后选一款字体直接应用，失败再考虑其他方法。

## 四、已 root 设备：任何机型都行

如果你的设备已经 root，zFont 3 可以生成 systemless 模块（支持 Magisk、KernelSU、APatch 三种框架），在模块管理器里刷入后即可全局换字体和 emoji，不受上面任何品牌限制。模块的生成与字体映射规则见[自定义字体导入教程.md](自定义字体导入教程.md)。

root 有失去保修与系统变砖的风险，不熟悉的话不要轻易尝试；免 root 路线走不通时，也可以先试[Shizuku授权与文件处理器设置.md](Shizuku授权与文件处理器设置.md)里的方案，它不需要 root。

## 五、小米 / 华为 / 荣耀等主题系统机型的额外一步

小米（MIUI、HyperOS）、华为、荣耀、Tecno、Infinix 这几家的主题系统把字体文件放在 `Android/data` 目录里，Android 11 起系统限制普通应用读写这个目录，所以应用字体前你要先给 zFont 3 配一个「文件处理器」——这一步不做，字体应用会卡在最后写入那一步。具体配置见[Shizuku授权与文件处理器设置.md](Shizuku授权与文件处理器设置.md)。

三星、LG、OPPO、vivo 等走主题商店接口的机型不涉及这个目录，装完即用。
