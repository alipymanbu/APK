## 一、这是什么应用

zFont 3 是一款安卓换字体工具，开发者是 Khun Htetz Naing。你在不获取 root 权限的情况下，可以用它把系统全局字体换成内置字体库里的其他风格，也可以导入自己的 TTF/OTF 字体文件；它还能把系统 emoji 换成 iOS、Twitter 等风格的表情包。

它主要面向想给手机换字体、又不想动系统分区的普通用户。你的机型是否受支持直接决定能不能免 root 使用，动手前建议先核对[免root机型兼容清单](免root机型兼容清单.md)。

## 三、系统要求与兼容性

- 第三方应用市场标注 zFont 3 最低要求 Android 7.0，实际使用时以官方页面与你的机型实测为准。
- 免 root 换字体对品牌和系统版本都有要求：三星、小米/POCO/Redmi、华为/荣耀、LG 支持较好；vivo/iQOO 支持 Android 12 及以下；OPPO/realme/一加在新系统上需要设备提供切换缅甸地区的选项才能用。具体逐条对照见[免root机型兼容清单](免root机型兼容清单.md)。
- 已获取 root 的设备不受品牌限制，任何安卓手机都能通过 zFont 3 生成 Magisk / KernelSU / APatch 模块来换字体。

## 四、获取与安装步骤

zFont 3 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/f5045645f27d](https://pan.quark.cn/s/f5045645f27d)。转存到自己网盘后下载 APK，按下面步骤装：

1. 打开下载好的 APK 文件。系统会提示「不允许安装未知来源应用」，点设置项跳转，允许你的浏览器或文件管理器「安装未知应用」。
2. 回到安装界面，点「安装」，等待完成。
3. 安装完成后先不要急着点打开，确认手机剩余存储空间足够（字体包从几 MB 到几十 MB 不等，安装多几个就按倍数预留）。

如果你的系统是 HyperOS/MIUI 较新版本，安装第三方 APK 时若被「纯净模式」或应用安装校验拦下，先在系统设置里暂时关闭它再装，装完按需打开。

装好后想确认有没有官方新版时，去官方渠道核对：官方网站 [zfont.app](https://zfont.app/) 与 Google Play 商店页。官方同时提醒不要从第三方镜像站获取安装包，避免装到被改过的版本；本文网盘资源对应的是第二节列明的那一版。

## 五、首次启动要做的两件事

1. **授予权限**：首次打开会弹权限请求，选「仅在使用中允许」；后续应用字体时还会再请求存储相关权限，按提示给即可。
2. **跳过新手教程**：启动后会出现全英文的新手教程引导，不熟悉英文可以点右下角的 `done` 跳过，再按屏幕箭头提示点两下进入主界面。

进入主界面后，你就能在 Home 页看到字体分类与 emoji 入口。接下来怎么选字体、怎么应用，看[换字体步骤详解](换字体步骤详解.md)；想换 emoji 的看[emoji表情更换与常见问题](emoji表情更换与常见问题.md)。

## 六、装完打不开或闪退怎么办

- **提示「未安装」或安装中断**：先核对安装包 MD5 是否为 `a5eb5c1b4f56c8d6fd647a367f763a24`，不一致说明文件在传输中损坏，重新下载一份。
- **打开即闪退**：确认系统版本不低于 Android 7.0；部分厂商系统（如老版 EMUI）对无障碍权限管控较严，可在系统设置里手动给 zFont 3 打开「显示在其他应用上层」与存储权限后再试。
- **权限弹窗一闪而过**：到系统「设置 → 应用管理 → zFont 3 → 权限」里逐项手动开启。
