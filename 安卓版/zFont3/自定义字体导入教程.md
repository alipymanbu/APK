## 一、导入入口在哪

导入入口在应用的 **Downloads（下载）** 标签页。把字体文件放进手机存储后，在这个页面里浏览选中即可导入。zFont 3 能识别的容器不止 TTF/OTF 裸文件：

- `.ttf` / `.otf` 字体文件本体
- 装着字体文件的 `.zip` 压缩包
- 其他应用的主题文件（`.apk`、主题包）里嵌的字体

也就是说，你从网上下到的是主题包或压缩包时，不用先解包提取字体，直接丢进 Downloads 页让应用自己找。

## 二、字体文件从哪来

两个常用的免费字体站点：

- [fonts.google.com](https://fonts.google.com)：Google Fonts，支持中文的开源字体（思源黑体、Noto 系列等）都在这里，按语言筛「Chinese」能快速定位。
- [www.dafont.com](https://www.dafont.com)：DaFont，英文艺术字体居多，适合做标题与个性排版。

下载字体时注意两件事：一是确认字体的授权条款允许个人使用（多数免费字体可以，商用前要看授权页）；二是中文用户要确认字体**包含中文字形**——只含英文的字体应用到系统后，中文会回落到默认字体，效果是「英文变了、汉字没变」。

## 三、导入后怎么应用

导入的字体和内置字体走同一套应用流程：在 Downloads 页选中导入的字体 → 预览 → 应用 → 按机型提示在系统字体设置里确认（或重启）。详细步骤与机型差异见[换字体步骤详解](换字体步骤详解.md)；小米、华为等机型记得先配好文件处理器（见[Shizuku授权与文件处理器设置](Shizuku授权与文件处理器设置.md)）。

应用后中文没变化，几乎都是字体文件本身不含中文字形，换一个含中文的字体包即可。

## 四、把字体导出去用在别处

zFont 3 下载过的字体可以从应用里导出，拿到设计软件（如 Photoshop、Canva）或视频剪辑应用里用，让电脑作品与手机界面用同一套字体。导出入口同样在 Downloads 页的字体详情里。

## 五、已 root 设备：生成字体模块

root 设备不受品牌限制，可以走 Magisk / KernelSU / APatch 模块路线。在 zFont 3 里点 **Create Module**，应用会自动完成模块制作；生成后在对应的模块管理器里刷入并重启。

自己做模块时有一个关键规则：字体映射必须**四种字重配齐**，只映射 Regular 不会全局生效：

| 你的字体文件 | 映射到的系统字体 |
| --- | --- |
| MyFont-Regular.ttf | Roboto-Regular.ttf |
| MyFont-Bold.ttf | Roboto-Bold.ttf |
| MyFont-Italic.ttf | Roboto-Italic.ttf |
| MyFont-BoldItalic.ttf | Roboto-BoldItalic.ttf |

中文等其他语言要映射到对应的系统字体族（比如缅甸文映射 `NotoSansMyanmar` 族），具体族名到你系统字体目录里核对。root 操作有失保与变砖风险，不熟悉的用户建议仍走免 root 路线。
