## 一、换 emoji 的操作

1. 打开 zFont 3，在 Home 页点 **emoji** 入口。
2. 点 **See All** 浏览全部表情包，常见的有 iOS 风格、Twitter（Twemoji）风格等，选一个点开。
3. 下载后按提示应用，部分机型需要重启后全局生效。

emoji 更换和字体更换走的是同一套主题写入机制，所以机型兼容性、文件处理器配置的要求完全一致：小米、华为、荣耀等机型同样要先配好文件处理器（见[Shizuku授权与文件处理器设置](Shizuku授权与文件处理器设置.md)），OPPO/realme 新系统同样受地区限制约束（见[免root机型兼容清单](免root机型兼容清单.md)）。

## 二、为什么微信、WhatsApp 里 emoji 没变

最常见的疑问。原因：Instagram、TikTok、WhatsApp、Facebook 这类应用**自带一套 emoji 图标**，不读取系统 emoji，所以你换的系统级 emoji 对它们无效——这不是应用出了故障。

受影响的是「读系统 emoji」的应用：系统自带短信、浏览器、备忘录，以及多数直接调用系统键盘表情的国内应用。

想让自带 emoji 的应用也换掉，只有 root 路线：用 zFont 3 生成 systemless emoji 模块刷入，可以覆盖到这些应用。此操作有失保风险，且需要你熟悉 root 流程，普通用户不建议为此专门 root。

## 三、常见问题速查

| 问题 | 原因与处理 |
| --- | --- |
| emoji 应用后没变化 | 先重启一次；仍无效则检查机型是否在支持列表、文件处理器是否在运行 |
| 部分应用里 emoji 没变 | 这些应用自带 emoji 图标，系统级更换无效，见第二节 |
| 换完想换回原版 | zFont 3 的 Settings 标签页里点 Reset Font，按提示操作；emoji 同样在这里恢复 |
| 字体和 emoji 能同时换吗 | 能，两者独立写入，互不影响；先换字体确认生效后再换 emoji 更容易定位问题 |
| 应用 emoji 时提示失败 | 与字体失败同因：Android 11+ 主题目录写入受限，先去配文件处理器 |

## 四、恢复与善后

- **恢复系统默认**：Settings 标签页里的 Reset Font 同时负责恢复字体与 emoji 的原厂状态，操作后按提示重启。
- **清理已下载的表情包**：Downloads 页里长按（或字体详情内）可删除已下载项，释放存储空间。
- **换字体后想顺带调整 emoji**：直接在 Home 页重新进 emoji 入口选另一款即可，不需要先恢复再换。

字体更换的完整流程与验证方法见[换字体步骤详解](换字体步骤详解.md)；如果连应用都装不上，先看[下载与安装教程](下载与安装教程.md)第六节。
