## 一、先排除一个最常见的原因

连接不上的头号原因不是软件问题：**两台设备不在同一个网络里**。控制端连了 WiFi、被控端还在用移动数据，或者两台设备连的是两个不同的路由器，都会连不上。先把两台设备的 WLAN 状态都确认一遍，再往下查。

## 二、按症状排查

| 症状 | 先查什么 | 再怎么办 |
| --- | --- | --- |
| 输入 IP 点「开始」，一直连不上 | 两台设备是否连了同一个 WiFi | 都是 WiFi 后，核对 IP 有没有输对：被控端每次重连网络后 IP 可能变（路由器会重新分配），回被控端重新查一次再输 |
| 同上，IP 确认无误 | 被控端的无线调试开关是否还开着 | 关掉再重新打开一次，然后重连；部分系统会在一段时间后自动收起这个开关 |
| 同上，开关也确认开着 | 路由器是否开了「AP 隔离 / 设备隔离 / 访客网络」 | 这类功能会禁止路由器下的设备互相访问，把两台设备移出访客网络或关掉隔离再试 |
| 被控端弹不出 ADB 授权提示 | 被控端无线调试是否真的开了 | 重开一次被控端的无线调试开关，控制端重新点「开始」；部分自定义系统本来就不弹这个提示，直接等画面 |
| 连接成功了，但画面全黑 | 被控端屏幕是否处于息屏锁定状态 | 先把被控端手动点亮解锁，再重新连一次 |
| 连接成功，但画面卡顿、延迟明显 | 码率或分辨率超出了当前网络承受能力 | 把码率降到 2Mbps、分辨率降到 1280x720，两台设备靠近路由器，详见 [分辨率与码率怎么设置.md](分辨率与码率怎么设置.md) |
| 之前连得好好的，今天连不上 | 被控端 IP 是不是变了 | 大多数家用路由器给设备分配的 IP 会变化，按上面的方法重新查 IP 再连；想固定地址的看 [投屏时IP地址老是变怎么办.md](投屏时IP地址老是变怎么办.md) |

## 三、排查完还是不行

按这个顺序把环境重置一遍，每一步之后都重试一次连接：

1. 关闭再打开被控端的无线调试开关；
2. 两台设备都断开 WiFi 再重新连入；
3. 重启两台设备后再连。

连上之后发现操作不顺手或画面质量不满意，分别看 [两台安卓手机互相投屏的方法.md](两台安卓手机互相投屏的方法.md) 第三节的手势说明和 [分辨率与码率怎么设置.md](分辨率与码率怎么设置.md)。
