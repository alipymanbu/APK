# scrcpy 手机版两台安卓手机互相投屏的方法

> 本篇讲怎么用装在安卓设备上的 scrcpy 手机版，把另一台安卓设备的屏幕投过来并直接操作：准备工作、连接步骤、连上之后的手势，一次走完。

## 一、开始前要备齐的三样东西

| 要准备什么 | 具体要求 | 说明 |
| --- | --- | --- |
| 两台安卓设备 | 一台当控制端（装 scrcpy 的这台），一台当被控端（被投屏的那台） | 平板一般也可以当控制端 |
| 同一个局域网 | 两台设备连同一个 WiFi；用其中一台开热点、另一台连它也可以 | 最常见的翻车点就是一个连了 WiFi、一个还在用流量 |
| 被控端已开无线调试 | 开发者选项里名为「无线调试 / ADB 调试 / ADB over network」的开关 | 开启路径见 [下载与安装教程.md](下载与安装教程.md) 第四节 |

不需要 root：多份公开介绍都写明绝大多数功能在未获取 root 权限的设备上就能用。

## 二、连接步骤

1. 查出被控端的 IP 地址：在「设置 → WLAN」里点开当前已连接的网络看详情；如果被控端用的是「无线调试」开关，那个页面上通常也会直接显示 IP。家用网络的 IP 一般以 192.168 开头。查到的地址连不上或总是变，见 [投屏时IP地址老是变怎么办.md](投屏时IP地址老是变怎么办.md)。
2. 在控制端打开 scrcpy 手机版，输入被控端的 IP 地址。
3. 从下拉菜单中选择显示参数和比特率；多份公开介绍都推荐 1280x720 与 2Mbps 这一组合，各项怎么取舍见 [分辨率与码率怎么设置.md](分辨率与码率怎么设置.md)。
4. 如果被控端只有硬件导航按键（屏幕上没有返回、主页这些虚拟键），把导航栏开关打开。
5. 点「开始」按钮。
6. 被控端会弹出 ADB 调试授权提示，勾选「始终允许使用这台计算机进行调试」再点允许（部分自定义系统没有这个弹窗，没有就直接等画面出现）。
7. 控制端显示出被控端的屏幕，连接完成。

## 三、连上之后怎么操作

- 在控制端的镜像画面里直接点、滑，就是在操作被控设备。
- 想找回控制端自己的系统导航栏：从屏幕底部边缘向上滑（多份介绍提到这个手势，用于镜像时恢复本地导航栏）。
- 被控端息屏后想唤醒它：双击镜像画面的任意位置；唤醒与息屏的完整操作见 [远程唤醒与息屏操作.md](远程唤醒与息屏操作.md)。

## 四、连上了但不流畅

先别急着怀疑设备，按这个顺序调：把码率降到 2Mbps、分辨率降到 1280x720，然后让两台设备都靠近路由器再试。具体的调节思路见 [分辨率与码率怎么设置.md](分辨率与码率怎么设置.md)。

以上步骤走完仍然连不上的，直接对照症状查 [连接失败排查方法.md](连接失败排查方法.md)。
