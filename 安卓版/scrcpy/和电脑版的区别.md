# scrcpy 手机版和电脑版的区别

> 搜「scrcpy」会同时撞到两套东西：装在电脑上的官方开源项目，和装在手机上的安卓应用。本篇把两者分清楚，帮你确认手上的安装包该装到哪、别照错教程操作。

## 一、一张表分清两套

| | 电脑版（官方开源项目） | 手机版（本套文档讲的这份） |
| --- | --- | --- |
| 装在哪 | Windows / macOS / Linux 电脑 | 安卓手机或平板 |
| 谁控制谁 | 电脑上的鼠标键盘控制手机 | 一台安卓设备控制另一台安卓设备 |
| 作者 | Genymobile 的开源项目 | 社区开发者基于开源项目做的安卓应用 |
| 安装形式 | 官方发布页的压缩包或系统包管理器 | `.apk` 安装包 |
| 操作方式 | 命令行或双击启动，配合命令参数 | 打开应用、输入 IP、点开始 |
| 依赖 | 电脑上要有 ADB 环境（Windows 版自带） | 两台设备同一局域网，被控端开无线调试 |

本套文档（含网盘里那份 `.apk`）讲的都是右列的手机版。

## 二、别照电脑版的教程操作手机版

电脑版的资料占了大头，搜到的教程十有八九在讲它，两套的操作完全不同：

- 电脑版要你在电脑命令行里敲 `adb tcpip 5555`、`adb connect 设备IP` 这类命令再启动；手机版不敲命令，在界面上输入被控端 IP 就行；
- 电脑版网上常见的 `--max-size`、`--bit-rate` 这类命令行参数，在手机版里对应的是连接前下拉菜单里的显示参数和比特率选项，选法见 [分辨率与码率怎么设置.md](分辨率与码率怎么设置.md)；
- 手机版的无线唤醒、息屏手势是它自己的操作逻辑，见 [远程唤醒与息屏操作.md](远程唤醒与息屏操作.md)，电脑版对应的是另一套快捷键体系。

如果你实际想找的是电脑版（在电脑上控制手机），那应该去官方项目的发布页拿电脑端安装包，本文的网盘 `.apk` 对你没有用。

## 三、几个数字别张冠李戴

电脑版官方项目页给出的性能数据（30~60 fps、35~70 ms 延迟）说的是**电脑端**在它官方测试条件下的表现；手机版的实际流畅度取决于你的两台设备与局域网状况，公开介绍里没有给出对等的数据，别把前者的数字当成手机版的指标。

系统要求同理：官方开源项目要求安卓 5.0（API 21）以上；手机版这份安装包的发布信息标注为安卓 5.2 以上。两套各按各的口径。
