## 一、先确认你要装的是哪一版

搜「scrcpy」时你会同时看到两种东西，装的目的一样是投屏，但运行的位置完全不同：

| | 电脑版 scrcpy | 手机版 scrcpy（本篇讲的这份） |
| --- | --- | --- |
| 装在哪 | Windows / macOS / Linux 电脑 | 安卓手机或平板 |
| 谁控制谁 | 电脑控制手机 | 一台安卓设备控制另一台安卓设备 |
| 来源 | Genymobile 官方开源项目 | 社区开发者基于同一开源思路做的安卓应用 |

如果你手上拿到的是 `.apk` 安装包，要装进手机，那就是手机版。两者的详细差异见 [和电脑版的区别.md](和电脑版的区别.md)。

## 二、安装包信息

本文涉及版本、包名、大小的地方一律以这份安装包本身为准（网上商店标的是各自的最新版，和你实际装到手的可能不是同一个版本）：

| 项目 | 内容 |
| --- | --- |
| 版本 | 2.1 |
| 包名 | org.las2mile.scrcpy |
| 大小 | 0.32 MB |
| MD5 | E560CAA1688E453CC554439672EE26C8 |
| 信息确认时间 | 2026-09-27 |

想核对到手文件是不是这一份，可以在电脑上算一下 MD5 再比对上表（Windows 下在命令行执行 `certutil -hashfile 文件名 MD5`；macOS / Linux 用 `md5 文件名` 或 `md5sum 文件名`）。

## 三、获取与安装步骤

1. 转存 **[scrcpy 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7b593b165fe7)** 到自己的网盘账号，再把 `.apk` 下载到手机本地存储。
2. 在手机文件管理器里点开这个 apk 安装。系统若提示「禁止安装未知来源应用」，按提示允许「来自此来源的应用」后再继续——不同系统的入口名称略有差别，一般在设置的应用权限或安全菜单里。
3. 装完先不要急着连，控制端（装 scrcpy 的这台设备）到这里就绪了。

## 四、被控端提前开好无线调试

真正连接前，被镜像的那台安卓设备要先打开无线调试，否则后面一步都走不下去：

1. 打开「设置 → 关于手机」，连续点击「版本号」7 次，开启开发者选项（部分系统的入口叫「软件信息」）。
2. 回到「设置 → 开发者选项」，找到「无线调试」并打开；如果你的系统没有这项，找名称类似「ADB 调试 / ADB over network / 网络调试」的开关。
3. 记下被控端的 IP 地址和端口：有「无线调试」页面的，页面上会直接显示；用「ADB over network」这类开关的，从 WLAN 网络详情里查 IP。连接时要用。

不同系统对这个开关的命名和位置不完全一样，找不到就在系统设置里直接搜「调试」。开好之后，按 [两台安卓手机互相投屏的方法.md](两台安卓手机互相投屏的方法.md) 走连接流程；连不上再去查 [连接失败排查方法.md](连接失败排查方法.md)。
