# scrcpy 手机版投屏时 IP 地址老是变怎么办

> 本篇讲被控端 IP 反复变化导致 scrcpy 手机版时连时不连的原因与两个解法：每次连接前重新查一遍，或在路由器里把地址固定下来。

## 一、IP 为什么会变

家用路由器给每台设备分配 IP 靠的是 DHCP 机制：设备每次接入网络时，路由器从地址池里挑一个分给它，并不保证和上次相同。所以被控端出现过这些情况后，IP 都可能变：

- 手机重启、开关一次飞行模式、断开重连 WiFi；
- 路由器重启或断电再来电；
- 设备长时间休眠后重新唤醒联网。

IP 变了之后，你还在按老地址连，自然连不上——这不是应用出了故障，是地址过期了。

## 二、最省事的办法：每次连接前重新查一遍

连接前花十秒钟确认当前地址，多数情况下这就够了：

1. 在被控端打开「设置 → WLAN」，点当前已连接的网络看详情，里面列着 IP 地址；如果被控端用的是「无线调试」，那个页面上通常也直接显示。
2. 拿这个新地址到 scrcpy 手机版里连接。

## 三、想一劳永逸：在路由器里绑定固定地址

路由器普遍支持把某台设备固定在某个 IP 上（常叫「静态 IP 分配 / DHCP 地址保留 / 地址绑定」），绑定后无论怎么重连，分给它的都是同一个地址：

1. 在电脑或手机浏览器里打开路由器管理页面，常见地址是 192.168.0.1 或 192.168.1.1，具体以路由器机身标签上印的为准；
2. 登录后找「局域网设置 / DHCP 服务器」一类的菜单，不同品牌的入口名称和位置不一样；
3. 在静态分配（地址保留）列表里新增一条：选中被控端设备（按设备名或 MAC 地址认），指定一个地址池范围内的固定 IP，保存；
4. 让被控端断开 WiFi 再重连一次，之后它拿到的就是绑定好的地址。

绑定后把 scrcpy 手机版里存的地址更新成这个固定 IP，以后就不用每次重查了。改过之后仍连不上的，按 [连接失败排查方法.md](连接失败排查方法.md) 的症状表逐条查；连接步骤本身不清楚的，回 [两台安卓手机互相投屏的方法.md](两台安卓手机互相投屏的方法.md) 第二节。
