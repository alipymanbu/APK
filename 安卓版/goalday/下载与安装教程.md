## 一、安装前先核对这几个信息

网盘里那份安装包的基本信息如下，装完可以对照应用内「设置 / 关于」确认是不是同一个包：

| 项目 | 本文口径 |
| --- | --- |
| 应用名称 | Goalday |
| 开发者 | 一时三刻（宁波）科技有限公司 |
| 安装包版本 | Version 2.6.6（安卓） |
| 包名 | com.first.goalday |
| 安装包大小 | 45.31 MB |
| MD5 | a0b89aad92bb5386ac23c04afc7b587a |
| 安装包归档日期 | 2026-09-23 |

说明：网盘里这份是上面这个版本，不等于官方渠道当前的最新版。官方迭代很快（几乎每个月都有修复版本），新版本功能有增减时以应用内实际表现为准。

## 二、从网盘拿到安装包

1. 打开上面的 [goalday 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6b5b721e28bd)；
2. 用夸克网盘客户端转存到自己的网盘，再从网盘下载到手机（网页端也可以直接下载，客户端更稳）；
3. 下载完成后得到一个 `.apk` 文件，大小约 45.31 MB，明显小于这个数说明没下完整，重新下载一次。

介意文件被改动过的话，可以把下载好的文件算一遍 MD5，与第一节表格里的值比对，一致才是原始包。

## 三、安装步骤

1. 在手机文件管理里点开下载好的 `.apk`；
2. 系统提示「禁止安装未知来源应用」时，按提示允许该来源安装（入口名称各品牌不同，一般在 设置 → 应用管理 或 安装 那一层）；
3. 等安装完成，点「打开」进入应用；
4. 首次启动若出现功能引导页，按需看完或跳过；系统询问通知等权限时，按你自己的需要决定给不给，不给也能正常记录。

装好后第一天从哪开始，见 [上手第一周.md](上手第一周.md)。

## 四、装不上时按这个顺序排查

| 现象 | 先做什么 |
| --- | --- |
| 提示「解析包错误 / 无法安装」 | 多半是安装包没下完整，重新下载并比对 MD5 |
| 提示存储空间不足 | 45.31 MB 只是安装包体积，安装过程还需要额外空间，清出几倍余量再装 |
| 安装中途被手机管家拦截 | 查看拦截详情里的包名是否为 com.first.goalday，确认后选择信任再装 |
| 装上但打不开 | 重启手机再试；仍不行说明该版本与这台设备不兼容，去官方渠道确认最低系统要求 |

关于最低安卓版本：不同第三方下载页分别标注过 Android 4.4 与 4.5，互相不一致，官方渠道也没有标注。实际影响不大——近几年出厂的安卓手机系统版本都远高于这条线，装不上的原因基本出在安装包完整性和存储空间上。

以上排查覆盖不了的情况，可以参考 [常见问题解答.md](常见问题解答.md) 里的联系方式直接问开发者。

## 五、iPhone 用户怎么办

Goalday 在 App Store 上架了 iPhone 版，搜索 Goalday、认准开发者「一时三刻（宁波）科技有限公司」即可。iOS 版与安卓版的功能主线一致（周计划、日记、清单、习惯），但两边版本号各自发版、不同步。截至 2026-09 检索时，iOS 版标注免费、含应用内购买、支持中文等 5 种语言，安装包体积几十 MB（不同页面显示 66~71 MB 不等，随版本更新），具体以 App Store 页面为准。
