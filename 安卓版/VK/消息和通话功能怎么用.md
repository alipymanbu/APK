## 一、消息入口在哪里

登录后底部的对话气泡图标就是消息列表，右上角可以新开对话。第一次使用时它会申请通讯录权限——同意之后，通讯录里同样在用 VK 的联系人会被自动列出来，加好友最省事的方式就是从这里挑。

不想给通讯录权限，就按名字或 ID 在顶部搜索里找人，进对方主页点「添加好友」，对方通过后你们就是好友关系。别人单方面关注你只会成为「订阅者」，看不到仅好友可见的内容——好友和订阅者是两拨人，这是 VK 和微信不一样的地方。

## 二、单聊和群聊里能做什么

- 文字、图片、语音条、贴纸、文件都能发；
- 对话可以拉群：新建对话时多选几个人就行，群内同样支持音视频；
- 收到看不懂的俄语消息：消息菜单里有**翻译**选项，翻成你的界面语言即可——对中国用户这是高频功能，对方的俄语大概率读不了；
- 某个对话太吵：在该对话的设置里单独静音，不影响其他消息。

## 三、语音和视频通话

聊天窗口里有拨语音通话和视频通话的按钮；群聊里可以把成员拉进群通话，视频通话里还能给镜头套上滤镜面具。通话走流量，不在 Wi-Fi 下时留意流量套餐。

通话接不通先确认双方网络都能正常打开 VK——「消息发不出去、一直转圈」很多时候是网络访问的问题，排查思路见[打不开或内容不可用排查.md](打不开或内容不可用排查.md)。

## 四、通知别漏接

VK 的消息推送要两层都打开才算数：

1. 应用内：设置 → 通知与声音，把消息类别打开；
2. 系统侧：手机设置 → 应用 → VK → 通知，允许通知。小米 / 华为 / OPPO 这类国产系统还要在省电策略里允许它后台自启，否则杀后台之后推送就断了。
