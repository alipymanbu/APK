## 一、先弄清 VK ID 和 VK 的关系

你登录 VK 用的那套账号密码其实是 VK ID——VK 官方统一的登录体系，VK 音乐、OK 等官方服务也认它。所以安全设置不在 VK 应用里逐项找，而是集中在 VK ID 的个人中心：浏览器打开 [id.vk.com](https://id.vk.com) 登录，或在 [vk.com](https://vk.com) 右上角头像 → 管理 VK ID 进入。「安全与登录」这一栏就是全部安全选项的所在。

## 二、开两步验证（登录确认）

开了之后，新设备登录除了密码还要多输一个一次性确认码。入口：**安全与登录 → 登录方式 → 两步验证 → 启用**。

确认码有四种拿法：

| 方式 | 说明 |
| --- | --- |
| 短信 | 发到绑定的手机号 |
| 推送 | 已登录的旧设备上弹窗确认 |
| 来电 | 系统打来一通电话给出码 |
| 验证器应用 | Google Authenticator 之类，扫码绑定后离线出码 |

三个官方口径要注意：

1. 发码方式由系统自动选择，**不能手动指定**——所以绑定的手机号和邮箱必须都是最新的，不然系统选了一个你收不到的方式就麻烦了；
2. 想给账号**设置密码**，必须先开两步验证，这是官方的强制顺序；
3. 启用时会生成一组**一次性备用码**——手机丢了、短信收不到时的最后手段，抄在纸上或存到离线的地方，别只存在手机里。

## 三、修改密码与免密登录

改密码入口：[vk.com](https://vk.com) 右上角头像 → 管理 VK ID → **安全与登录 → 密码**，按系统提示走。两个容易卡住的点：

- **找不到密码区块**：你的账号可能开着免密登录（不设密码，靠一次性码登录）。想改用密码登录，得先开两步验证，密码选项才会出现；
- **密码明明对却提示错误**：重要操作（比如改密码）要求用**当初设置密码时的键盘布局**重新输入。切换一下中英文输入法再试，多数是这个问题。

官方现在把「删掉密码、只用一次性码登录」也列为推荐做法之一：码通过短信、推送、来电或验证器应用生成，每次登录都是新的，密码泄露这条路直接堵死——代价是每次登录都要收码，看你取舍。

## 四、换手机号怎么改绑

入口：VK ID 个人中心 → **我的资料 → 电话** → 更改，输入新号并用短信码确认。

- **旧号还能收短信**：确认旧号后立刻换绑，几分钟的事；
- **旧号已注销 / 停用**：系统会让你**等 7 天**自动换绑；等不了就走官方恢复表单 [vk.com/restore?act=return_page](https://vk.com/restore?act=return_page)；
- **旧账号开着两步验证**：先把两步验证关掉，才能把号码移走；
- **绑定次数有上限**：一个号码能绑的次数有限，反复解绑重绑、借给亲友绑号都会把额度烧光——烧光之后这个号就再也绑不上任何 VK 账号，只能写工单人工处理。

换完号记得回头做两件事：重新生成一份备用码，确认绑定邮箱还能收信。

## 五、日常四个好习惯

- 绑定邮箱并保持可用：有人尝试登你的账号时，系统会发邮件提醒；找回密码也靠它；
- 换手机号的第一时间去 VK ID 改绑定号——号码被运营商回收再放出去，下一个机主就有机会重置你的账号（改绑步骤见第四节）；
- 在个人主页放几张能认出你的真人照片：账号万一被锁，人工申诉时要靠这些照片证明「你是你」；
- 每隔一阵翻一遍**安全与登录 → 设备与活动 → 活动历史**，陌生设备的会话踢下线；「服务与网站」里授权过的第三方应用顺手清一清，不用的全部断开。

## 六、登不上了怎么找回

- 手机还在、只是密码忘了：登录页走恢复流程（来电后输出来电号码的后 4 位，或用绑定邮箱收 8 位码），步骤见[注册与登录教程.md](注册与登录教程.md)第三节；
- 手机号和邮箱都不可用：走官方恢复表单 [id.vk.com/restore](https://id.vk.com/restore/#/resetPassword) 提交扩展申诉，按页面要求提供身份信息，资料越全越容易过；
- 收不到两步验证的确认码：先确认短信没被拦截、网络正常；发码方式系统自动选，你没法换一种收——这正是第二节强调备用码的原因。
