## 一、结果卡上有什么

一次快速基准跑完，结果卡上除了总分，通常还能展开看到 Graphics（图形）与 Physics（物理）分项图表（哪些测试带物理分项以实际界面为准，专注 GPU 的测试如 Wild Life、Solar Bay 主要看图形成绩）。比总分更重要的是这几个参照物：

- **同机型的其他用户平均分**：和你用同一款手机的人跑出来的分布；
- **全部设备的平均分**：上一季度所有参与测试设备的整体水平；
- **你的最佳成绩在其中的位置**。

同一款手机的分数天然有一个分布区间，你的成绩落在区间内就是正常的。区间形状本身也有信息量：分布窄说明这台机器发挥稳定；出现多个分散的峰值，说明它只有在少数条件下才能跑出最佳成绩。

官方没有公布过「多少分算及格」——参照系只有同机型分布和你自己的历史趋势；综合类跑分（安兔兔等）与 3DMark 之间也不存在换算关系，见 [和安兔兔有什么区别.md](和安兔兔有什么区别.md)。

## 二、My results：本机的历史成绩

「My results」页列出这台设备上的全部跑分记录，点任意结果卡进入详细结果视图。设备信息是绑定在本机的，重装应用或卸载单个测试不会清掉历史分数。

每张卡片右上角有分享图标，可以把当前卡片生成为图片保存或发给别人，适合发到群里对比或留档。

## 三、My device：四张数据卡

「My device」页回答的问题不是「我跑了多少分」，而是「我的设备到底处于什么水平」。四张卡按用途分：

| 卡片 | 能回答的问题 | 怎么用 |
| --- | --- | --- |
| Performance snapshot | 我的设备在市场上排什么位置？ | 下拉切换测试与 API；总分布里同时画着同机型均值与上一季度全设备均值 |
| Performance range | 我的设备发挥稳不稳？ | 峰值是同机型最常见的分数区间；分布窄=稳定，分布宽=发热或多任务时会掉速 |
| Performance by OS version | 系统更新对性能有影响吗？ | 按系统版本画平均分；升级前后跑一次就能对上号 |
| Specification | 这台机器的硬件是什么？ | SoC、CPU、GPU、内存、存储、屏幕类型/尺寸/分辨率、尺寸重量 |

看分数是否偏低之前，先在这页确认自己的成绩相对「同机型分布」处在什么位置，而不是直接跟全网平均分硬比——这也是 [跑分偏低的常见原因.md](跑分偏低的常见原因.md) 里的第一条排查项。

## 四、把分数当参考而不是结论

跑分衡量的是特定负载下的表现，不是日常体验的全部。三个实用口径：

- **跨设备对比**：只在同一测试、同一 API（必要时同一渲染模式）之间比，跨平台比分还要考虑 API 开销差异（见 [测试项目与设备要求.md](测试项目与设备要求.md) 第四节）。
- **同设备纵向对比**：关注趋势而不是单次绝对值——系统更新前后、清后台前后各跑一次，用 [压力测试怎么做.md](压力测试怎么做.md) 的稳定率看长时间表现，比单次分数更能反映真实水平。
- **多台机型放在一起比**：换机前想把几台候选机型加入同一张对比图，操作见 [换新手机怎么对比性能.md](换新手机怎么对比性能.md)。
