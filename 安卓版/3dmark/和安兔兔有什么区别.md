# 3DMark 和安兔兔有什么区别

> 两个都是跑分应用，但量的东西不一样：安兔兔给的是覆盖 CPU、GPU、内存、体验的综合总分，3DMark 专测图形性能。本篇讲两者的定位差异、分数为什么不能互比、以及怎么配合着用。

## 一、两边各量什么

| | 3DMark | 综合类跑分（以安兔兔为代表） |
| --- | --- | --- |
| 侧重点 | GPU 图形性能专项 | CPU、GPU、内存、存储、体验的综合总分 |
| 测试构成 | 多个独立的图形测试（见 [测试项目与设备要求.md](测试项目与设备要求.md)） | 一套打包测试合成一个总分 |
| 跨设备范围 | Android、iOS、Windows 之间同测试可比 | 以安卓机型为主 |
| 成绩参照 | 同机型分布、上季度全网均值（应用内） | 各自榜单与机型库 |

一句话区分：想知道「这台手机打游戏（图形负载）行不行、撑不撑得住」，看 3DMark；想知道「整机综合水平大概在什么档位」，综合类跑分给的是另一张图。两个数字回答的不是同一个问题。

## 二、分数为什么不能互比

三类常见的错误比法，都别犯：

1. **跨软件比**：安兔兔总分和 3DMark 分数之间没有任何换算关系，量纲、负载、合成方式都不同。
2. **跨测试比**：3DMark 内部，Sling Shot 系与 Wild Life 系也不可比（API 与分辨率都不同）。
3. **跨版本比**：跑分应用大版本更新后，新旧分数通常不可直接比较——综合类跑分应用的官方更新公告里也强调过这一点；3DMark 侧则由官方在更新日志中注明分数是否受影响。

## 三、关于「哪个更准」

这个问题没有官方答案，也超出了本篇能替你下结论的范围。可以核实的事实只有这些：

- UL 对参加排名的设备厂商有书面的基准规则（见 [benchmarks.ul.com/support/benchmark-rules](https://benchmarks.ul.com/support/benchmark-rules)），对测试项与防作弊手段有明确约束；
- 3DMark 的跨平台可比性来自它自己在各平台使用同一套测试（安卓与 Windows 用 Vulkan、苹果设备用 Metal）；
- 综合类跑分覆盖面更广，但单一总分里各子项的权重由厂商定，读者看不到逐项细节。

至于哪个数字更接近你的真实体验——最可靠的办法是拿你自己的使用场景验证：跑分之后实际玩几天你常玩的游戏，见 [跑分结果怎么看.md](跑分结果怎么看.md) 第四节的「把分数当参考」口径。

## 四、怎么配合着用

换机或验机时，两个都跑不冲突，但各看各的：

1. **综合类跑分**看整机档位，用于海选；
2. **3DMark** 看 GPU 峰值（快速基准）与长时间稳定性（压力测试，见 [压力测试怎么做.md](压力测试怎么做.md)），用于决选；
3. 两边的分数分开记录，别放进同一张对比表。
