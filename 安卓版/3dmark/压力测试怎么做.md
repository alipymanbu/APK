## 一、压力测试和快速基准的区别

同一个测试通常有两种跑法：

| | 快速基准 | 压力测试 |
| --- | --- | --- |
| 模拟场景 | 手游里一段段短促的高负载 | 一次完整的长局游戏 |
| 时长 | 几分钟 | 约 20 分钟（20 个循环） |
| 结果 | 一个总分 | 性能曲线 + 稳定率 |

快速基准回答「这台机器峰值多强」，压力测试回答「这台机器能维持多久」。买前验机、系统更新后对比、玩游戏掉帧怀疑过热降频，都应该跑后者。

## 二、操作步骤

1. 在「My tests」里进入测试详情页（如 Wild Life、Steel Nomad Light、Solar Bay 都提供压力测试入口）。
2. 选压力测试，点运行。整个流程约 20 分钟。
3. 测试期间把手机放在一边：别锁屏、别切后台、别边充电边跑，机身散热条件尽量接近你平时玩游戏的场景。

跑完的结果页会给出 Best loop score（表现最好的循环）、Worst loop score（表现最差的循环）和 Stability（稳定率）三项，外加一条全程的性能曲线。

## 三、稳定率怎么算

官方对压力测试的判定口径（以 Windows 版帮助文档为准，安卓版结果页给出同样的三项数据）：

```text
稳定率 = 最差循环平均帧率 / 最好循环平均帧率 × 100%
通过条件：稳定率 ≥ 97%，且全部循环完整跑完
```

换句话说，稳定率衡量的是「最差的那一圈离最好的一圈有多远」。一台峰值分很高但稳定率只有八成的机器，长时间游戏体验通常不如峰值略低但稳定率 97% 以上的机器。

## 四、三种典型曲线

压力测试的主产物是那条性能曲线，常见的三种形态：

- **平稳一条线**：性能从头到尾几乎不变，是最理想的结果，说明散热跟得上负载。
- **周期性骤降**：每隔一段时间曲线突然下坠再回升——典型的过热降频，降频、回温交替出现，属于体验最差的一种。
- **缓慢下滑**：起步高，之后逐步走低然后企稳，性能损失温和，多数机型属于这类，尚可接受。

结合曲线和稳定率看：曲线平稳、稳定率 97% 以上，说明长时间高负载没问题；曲线坐过山车，说明该考虑散热背夹这类外部手段，或者接受降亮度降帧率的事实。

## 五、跑完之后

- 稳定率不理想时，按 [跑分偏低的常见原因.md](跑分偏低的常见原因.md) 的清单逐项排查（省电模式、后台任务、散热条件都直接影响这条曲线）。
- 想知道自己的设备在同机型里算不算「发热就掉速」的那一批，看 [跑分结果怎么看.md](跑分结果怎么看.md) 里 Performance range 卡片的分布形态。
