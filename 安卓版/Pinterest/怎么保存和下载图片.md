# Pinterest 怎么保存和下载图片

## 一、先把两个概念分开

Pinterest 里「保存」和「下载」是两件事，很多人第一个月都在混用：

- **保存（Save）** = 把这张图收进你账号里的某个**画板（Board）**，图存在 Pinterest 云端，换手机登录还在，但手机相册里没有；
- **下载** = 把图片文件存进**手机相册**，离线能看，但只存在本机，换手机就没了。

想建立自己的灵感库用「保存」；想把图发给朋友、当壁纸用「下载」。两个都做也没冲突。

## 二、保存一张图到画板

1. 在首页或搜索结果里点开一张图，进入大图页；
2. 点红色的 **Save（保存）** 按钮；
3. 第一次保存会弹画板选择框：选一个已有画板，或点 **+ Create board（新建画板）** 现场建一个——输入画板名，点右上角创建。

不选画板直接存的话，图会落进默认的「已保存 / All Pins」里，攒多了很难翻。**建议从第一张图就开始分画板**：按项目（婚礼筹备）、按用途（客厅装修）、按季节（秋冬穿搭）分都行，后面才会越用越顺手。

## 三、建画板与整理画板

- **新建画板**：个人资料页 → 画板列表右侧的加号，或保存图片时的「Create board」。
- **重命名 / 删除画板**：进入画板 → 右上角的「…」→ 编辑或删除。删除画板不会删除账号，画板里的图会退回「已保存」。
- **把图挪到别的画板**：开图 → 点 Save → 换目标画板再存一次，然后去原画板把旧的那条取消保存（Unsave）。
- **私密画板**：新建或编辑画板时可设为 Secret，只有你自己看得到，公开主页上不显示。

## 四、把图片下载到手机相册

1. 点开想下载的图，进入大图页；
2. 点右上角的「…」（更多操作）；
3. 选 **Download image（下载图片）**；
4. 第一次用会弹**存储权限**申请，允许后图就进了相册。

几点注意：

- 视频类 Pin 的「…」菜单里未必有下载项，菜单里没有就是该 Pin 未开放下载；
- 下载得到的就是这张 Pin 对应的图片文件，分辨率以实际保存下来的为准；
- 如果点了没反应，多半是存储权限被拒了：去**系统设置 → 应用 → Pinterest → 权限 → 存储/照片和视频**，改成允许，重进 App 再下一次。权限路径也见 [下载与安装教程.md](下载与安装教程.md) 的首次启动说明。

## 五、从别的 App 里直接保存进来

看到微信、浏览器里有想收的图，不用先存相册再上传：

1. 在那个 App 里点**分享**按钮；
2. 在系统分享菜单里找到 Pinterest（第一次可能要滑到「更多」里勾选）；
3. 选目标画板，完成。

反过来，把 Pinterest 的图分享出去：大图页「…」→ Share，可以复制链接或发给其他应用。

## 六、保存过的图去哪找

**个人资料页 → 已保存（Saved）**，这里按画板分组列出你存过的全部内容。找单张图可以：

- 进对应画板用内部筛选；
- 或回首页用搜索——搜你记得的关键词，配合 [搜索与首页推荐调整.md](搜索与首页推荐调整.md) 里的搜索历史技巧。

## 七、下载的图找不到？

按顺序查：

1. 相册里翻最新的日期分组，或用文件管理器看 `Pictures` / `Download` 目录；
2. 权限问题——系统没给 Pinterest 存储权限时，下载会静默失败（见第四节）；
3. 图能存进画板但下载总失败 → 大概率是应用缓存或版本问题，按 [打不开闪退白屏怎么解决.md](打不开闪退白屏怎么解决.md) 清缓存后重试。
