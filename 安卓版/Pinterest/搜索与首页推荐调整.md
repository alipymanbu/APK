## 一、关键词搜索

点底部的**搜索栏**，输入词直接搜。几个提命中率的技巧：

- **用具体词，别用句子**：「北欧风客厅地毯」比「我想买个放在客厅的地毯」出的结果准得多；
- **中英文都试**：同一主题中文词与英文词的结果池不一样，英文词常能搜到更多源内容；
- **搜到好图后顺着「相关 Pin」往下挖**：大图页下滑出现的关联推荐，往往比关键词本身更对味。

搜完想清掉记录，见下文第四节。

## 二、拍照搜图（Lens）

看到现实中或别的页面上有一张图，想找出同款/相似款：

1. 点搜索栏，输入框旁边有个**相机图标**，点它；
2. 允许相机权限（首次会弹）；
3. 对准目标拍摄，或从相册选一张已有的图；
4. Pinterest 返回视觉上相似的一组 Pin。

典型用法：对着家具、穿搭、菜品、绿植拍，找同款或平替。识别效果受光线和主体清晰度影响，主体占画面比例太小就多拍近一点。

## 三、首页怎么全是不感兴趣的内容

首页推荐由你**选过的话题、存过的图、看过的 Pin、关注的人**共同决定，所以调整也从这几处下手：

1. **改兴趣话题**：个人资料页 → 右上角「…」→ **Settings（设置）→ Home feed tuner（首页调优）→ Topics**；
2. 点 **Add topics** 加新话题，点已有话题上的勾选标记可移除；
3. **多存、多点**：保存和点击是最强的信号——首页偏了就连续存几张你真想要的类型，几十条互动后推荐会明显转向；
4. **取关污染源**：关注的人发布的内容占比很高，取关几个也能立刻改变走向。

改完不用等，下拉刷新首页看效果。

## 四、查看与清除搜索历史

1. **头像 → 设置 → 隐私与数据（Privacy and data）**；
2. 找到**清除搜索历史（Clear search history）**，确认清除。

注意两点：清的是**记录本身**，之后的搜索仍会被继续记录（Pinterest 没有关闭搜索记录的开关）；搜索历史只有你自己能看到，别人看不到。另外，搜索栏点开时下拉出现的「最近搜索」，单条可以长按或点旁边的小叉逐条删。

## 五、隐私与个性化开关

同样在 **设置 → 隐私与数据** 下，这几个开关决定推荐吃多少你的数据：

| 开关 | 关掉后的效果 |
| --- | --- |
| 基于你访问的网站做个性化 | Pinterest 不再用你在别处的浏览痕迹给你推内容 |
| 基于合作伙伴数据做个性化 | 减少广告与内容对第三方数据的引用 |
| 搜索隐私（Search privacy） | 打开后你的资料页不出现在 Google 等搜索引擎里 |
| 保存你的联系人 | 关掉后 Pinterest 不再读取手机通讯录 |

只想让推荐「少点广告味」，关前两项；想彻底隐身，再把搜索隐私打开。开关改动即时生效，不需要重启应用。

## 六、搜索转圈、结果空白

搜索依赖实时联网，首页能开但搜索转圈，通常是这几种情况：网络不稳（切一下 Wi-Fi/流量）、开了 VPN 或广告拦截挡了请求、Pinterest 服务端在抽风。逐条排查步骤在 [打不开闪退白屏怎么解决.md](打不开闪退白屏怎么解决.md) 的搜索章节。
