## 一、注册一个新账号

Pinterest 没有免登录的浏览模式，装好后第一件事就是注册。在登录页点「注册」，按屏幕提示依次填：

1. 邮箱地址 → 点继续；
2. 设置密码 → 下一步；
3. 填姓名 → 下一步；
4. 填年龄 → 下一步；
5. 选择性别、所在国家；
6. **选 5 个以上感兴趣的话题**（美食、家居、穿搭、旅行……），选完进入首页。

也可以在登录页直接点 **Continue with Google** 或 **Continue with Facebook**，用现成的社交账号一键建号——这条路少填一堆表，但你以后每次登录都要走同一个入口。

注意：第 6 步选的话题直接喂给首页推荐，随手乱选会导致首页全是不感兴趣的内容。选完之后也能改，方法见 [搜索与首页推荐调整.md](搜索与首页推荐调整.md)。

## 二、三种登录方式怎么选

| 方式 | 操作 | 适合谁 |
| --- | --- | --- |
| 邮箱 + 密码 | 输入注册邮箱与密码，点登录 | 最通用，换手机、换社交平台都不受影响 |
| Continue with Google | 选一个 Google 账号授权 | 手机上已登录 Google 的人，最快 |
| Continue with Facebook | 用 Facebook 账号授权 | 绑过 Facebook 的老账号 |

**同一个邮箱 = 同一个账号**。用 Google 或 Facebook 登录时，选中的邮箱必须与 Pinterest 账号注册邮箱一致；不一致的话 Pinterest 会提示新建一个账号——那不是你原来那个，画板都不在里面，退出来换正确的账号再登。

如果你原来用邮箱注册、后来想加社交登录：登录后进**头像 → 设置 → 账户管理**，在「已连接的账号 / 登录选项」里点连接即可。反过来解绑也走同一路径，但**解绑前先确认账号本身设了邮箱密码**，否则会把自己锁在门外。

## 三、忘记密码怎么重置

1. 在登录页点 **Forgot your password?（忘记密码）**；
2. 或直接打开 [pinterest.com/password/reset](https://www.pinterest.com/password/reset/)，输入注册邮箱、用户名或姓名，点搜索；
3. 从结果里选中你的账号，去邮箱找 Pinterest 发来的重置邮件，点邮件里的 **Reset password**；
4. 设一个新密码提交。

几个常见坑：

- 重置邮件没到 → 先翻垃圾邮件箱，再确认输的邮箱确实是注册那个（**大小写与拼写都要对**）；
- 收不到邮件且邮箱已废 → 试试用绑定过的 Google / Facebook 入口直接登录（前提是你当初绑过）；
- 重置链接点开报错 → 换无痕窗口再开一次；
- Pinterest 不允许复用最近用过的密码，别把旧密码改回来。

## 四、主动改密码

登录状态下：**头像 → 设置 → 账户管理（或安全与登录）→ 修改密码**，输入当前密码 + 新密码后保存。新密码建议字母大小写、数字、符号混用，避开生日、连续字符这类好猜的组合。

## 五、开两步验证

两步验证是「密码之外再要一个验证码」，能挡住大部分盗号：

1. **头像 → 设置 → 安全与登录**；
2. 找到 **两步验证** 开关打开；
3. 前提条件：你的邮箱已在 Pinterest 上确认过，且账号设有密码——两项缺一项开关是灰的，先去补齐。

开启时 Pinterest 会给你一组**恢复码**，存到离线的地方（截图放相册也行）。手机丢了或换号时，全靠这组码登录。

## 六、登录不上去，按症状对号入座

| 症状 | 原因与处理 |
| --- | --- |
| 提示「找不到这个邮箱对应的账号」 | 当初可能用了别的邮箱注册，或走了社交登录；把几个可能的邮箱、以及 Google/Facebook 入口都试一遍 |
| 输完邮箱反而弹「Create an account」 | Pinterest 在提示你新建账号，不是在登录你旧账号——看清楚按钮，别误点建了个空号 |
| 收不到验证码 / 重置邮件 | 查垃圾箱；确认邮箱地址逐字符无误；换网络再试 |
| 两步验证要验证码但收不到 | 用开启时保存的恢复码；没有恢复码就走 [重置密码流程](#三忘记密码怎么重置) |
| 登录页一直转圈 | 网络问题居多，切一下 Wi-Fi / 流量；持续转圈按 [打不开闪退白屏怎么解决.md](打不开闪退白屏怎么解决.md) 排查 |

## 七、收到「你改了没改过的东西」的邮件

如果你收到邮箱、用户名或密码被修改、或异地登录提醒，而这些操作不是你做的——账号可能被别人进了。按顺序做：

1. 在那封邮件里点 **Lock my account（锁定账号）**，先把人踢出去；
2. 立刻走 [重置密码流程](#三忘记密码怎么重置) 设新密码；
3. 登录后进 **设置 → 安全与登录**，检查登录设备列表，移除不认识的会话；
4. 确认两步验证处于开启状态（见第五节）。

如果你自己被异常活动检测误伤（Pinterest 会自动重置密码并全端登出），按邮件指引重新设密登录即可，画板数据不受影响。
