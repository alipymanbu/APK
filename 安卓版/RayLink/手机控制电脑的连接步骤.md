## 一、开始前的准备

两端各装一份 RayLink，且都能上网：

- **电脑（被控端）**：装 Windows 或 macOS 版；
- **手机（控制端）**：本篇的安卓版。

电脑端装好后不用额外配置，它会在主界面直接显示本机的**设备码**和**访问密码**。

## 二、登录账号

手机端打开 RayLink，用手机验证码登录。后续版本也提供了微信、邮箱登录入口（以你的版本界面为准）。两端登录同一个账号的好处是常用设备会记在设备列表里，下次不用反复输入设备码。

## 三、发起连接

1. 在**电脑端** RayLink 主界面读下设备码和访问密码（临时密码可能会定期刷新，连之前看一眼最新的）。
2. 在**手机端**输入这串设备码和访问密码，点「远程连接」。
3. 网络正常时几秒内即可连上，手机屏幕会显示出电脑桌面。

不想记密码也有另一条路：让电脑端保持打开，手机端只输设备码发起请求，电脑端点一下「接受」即可。要连的是一台**没人值守**的电脑（比如出门在外连家里那台），提前按[免密连接与无人值守设置.md](免密连接与无人值守设置.md)配好固定密码和自启动，就不用等人配合了。

## 四、连上之后怎么操作

| 你想做的事 | 手机上的操作 |
| --- | --- |
| 移动鼠标、点按 | 直接点手机屏幕，或切到鼠标模式用虚拟光标 |
| 打字 | 调出虚拟键盘输入，支持输入法切中英文 |
| 滚动页面 | 单指滑动；缩放画面用双指捏合 |
| 传输文件 | 悬浮工具栏里的文件传输入口，两端互传，细节见[手机电脑互传文件的方法.md](手机电脑互传文件的方法.md) |
| 调画质 | 悬浮工具栏里切清晰度与帧率档位，网络不好先降档 |
| 看连接质量 | 功能栏显示当前延迟、带宽、帧率与连接方式，卡顿时先看这里 |
| 防止旁边人看到 | 见[被控端设置与防窥模式.md](被控端设置与防窥模式.md) |

关于画质选项：RayLink 提供高帧率模式和 4:4:4 色彩模式，入口在连接后的顶部工具栏；部分增强选项与账号版本权益有关，以实际显示为准（版本差异见[免费版功能与收费说明.md](免费版功能与收费说明.md)）。

玩游戏的场景（手机远程玩电脑上的游戏）同样走这条连接流程，连接后 RayLink 支持外接手柄操作。

## 五、用完之后

养成两个习惯：

- 控制结束在工具栏里断开连接，别只是切走 App；
- 如果是临时帮别人修电脑，用完让对方改一下访问密码。

连不上、频繁掉线或画面卡顿，按[连接失败与卡顿排查.md](连接失败与卡顿排查.md)逐条对照。
