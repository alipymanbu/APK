## 一、按现象对号入座

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示密码错误 | 被控端临时访问密码已刷新 | 回被控端主界面重新读一次密码再连 |
| 提示设备码不存在 | 两端装的不是同一款软件，或设备码抄错位数 | 核对设备码；确认被控端装的是 RayLink 而非同名应用 |
| 一直转圈连不上 | 一方网络受限（公司/校园网常拦远程端口） | 换网络再试：手机换流量、电脑换热点 |
| 能连但很快掉线 | 被控端息屏、省电策略杀了后台 | 给 RayLink 关掉电池优化、允许后台运行；被控电脑关闭睡眠 |
| 画面卡、操作延迟大 | 带宽不足或网络抖动 | 双方都改用 5GHz Wi-Fi 或有线；在工具栏里把清晰度降到流畅档、降帧率 |
| 画面黑屏或静止 | 被控端权限被系统回收（录屏/悬浮窗） | 回系统设置补授权，重新发起连接 |
| 电脑控手机时手机端黑屏 | 可能是开了防窥模式 | 关掉防窥开关，见[被控端设置与防窥模式.md](被控端设置与防窥模式.md) |

## 二、网络层面的四个动作

远程控制的体验九成取决于网络，按顺序做：

1. **测两端的基础网络**：任一端刷视频都卡，先解决网络本身；
2. **看功能栏的连接指标**：连接后功能栏会显示当前延迟、带宽、帧率与连接方式，是判断卡顿出在带宽还是画质设置的第一手依据；
3. **同一局域网时用直连**：手机和电脑连同一个路由器时，同网段点对点连接通常更稳、延迟更低，文件传输也快（差别见[手机电脑互传文件的方法.md](手机电脑互传文件的方法.md)）；
4. **避开受限网络**：有些办公网禁止设备互连，这不是软件设置能绕开的，换网络最直接。

## 三、还解决不了

- 两端都升到最新版本再试（版本差异有时就是问题的来源）；
- 到官网 [www.raylink.live](https://www.raylink.live/) 查公告与帮助内容，官方还有公众号「RayLink远程控制软件」可反馈；
- 涉及账号与权益的疑问，先看[免费版功能与收费说明.md](免费版功能与收费说明.md)再反馈。
