## 一、它是一个聚合多家大模型的助手

Chat Smith 由 Smart Widget Labs Co Ltd 开发，你在应用里对话时，背后可以切换多家第三方大模型（不同版本里可选的模型名单会变，默认模型也会随版本升级更换——官方更新说明里出现过「默认聊天模型已升级为 GPT-6 Luna」这样的条目，以应用内实际列表为准）。除了聊天窗口，它把常见任务做成了模板和专用入口；手机装一份，网页端 [chatsmith.io](https://chatsmith.io) 用同一账号也能接着聊（网页端有什么见 [网页版与多端同步.md](网页版与多端同步.md)）。

模型名单和功能入口都集中在一个应用里，功能用量则按订阅区分，具体见 [订阅与收费标准.md](订阅与收费标准.md)。

## 二、按场景找功能

| 你想做这件事 | 去哪里找 | 怎么用 |
| --- | --- | --- |
| 写邮件、周报、作文、文案 | 写作助手 / 邮件生成 | 选对应模板，把主题和语气要求说清楚，生成后逐段改 |
| 总结 PDF、文档、YouTube 视频 | 总结类入口 | 上传文件或粘贴视频链接，让它输出要点；PDF 也能直接提问 |
| 查资料并要来源 | 实时搜索 / Deep Research | 提问时打开联网或深度研究开关，回答会附带参考来源 |
| 生成图片 | AI 图像生成 | 输入文字描述或上传照片再加工，出图质量与数量一般和订阅档位挂钩 |
| 翻译、练外语 | AI 翻译与语言练习 | 直接输入或粘贴原文；练口语对话就让它扮演对话方 |
| 写代码、看报错 | Code Guru | 粘贴报错或描述需求，让它生成、解释或调试代码 |
| 解数学题、辅导作业 | AI 数学解题 / 作业助手 | 拍照或输入题目，要求分步解释 |
| 做简历、求职材料 | 简历与 CV 生成 | 填入经历，生成简历与自荐信草稿，再按岗位微调 |
| 输入法里改语法、润色 | AI Keyboard | 启用键盘后在任意输入框调用改写与纠错 |
| 做 Logo、海报、名片等物料 | Design Studio（网页端模板库） | 选模板，把品牌名和内容交给它排版生成 |
| 管日程、邮件、待办 | Daily Smith（Co-Work Agent） | 连接后让它汇总当天事项、起草回复，具体连接方式以应用内提示为准 |

表里同一件事往往有两个入口：模板适合「不知道怎么开口」的场景，直接聊天适合你已经能描述清楚需求的时候。

另有一批功能是官方商店新版本里才标注的：AI Humanizer（把 AI 生成的文本改写得更像人写的）、AI Detector（检测内容是否 AI 生成）、AI Logo Design（AI 生成 Logo）、Calendar Smith Agent（用一句话安排日程与提醒）。网盘里这份 8.260406.2 不一定带这些，想要就到商店升级到新版；功能入口位置以你手上的版本为准。

## 三、哪些功能容易踩到付费墙

- 图像生成、深度研究这类高消耗功能，通常对免费额度限制最明显；
- 免费额度常见形式是按条数或按天的对话/提问限制，具体数值随版本调整，以应用内提示为准；
- 订阅后各模型的可用量也未必全部对齐，档位差异以订阅页说明为准。

具体价格与取消方法见 [订阅与收费标准.md](订阅与收费标准.md)。

## 四、和直接用官方应用有什么不同

只列事实差异，不替你做选择：

- 模型来源：官方应用一家一个，Chat Smith 把多家模型放在一个界面里切换；
- 任务模板：写作、简历、总结等高频任务在 Chat Smith 里有现成模板，官方应用多数要自己写提示词；
- 网页同步：手机与 [chatsmith.io](https://chatsmith.io) 网页端共用账号，换设备不用导出记录；
- 计费：Chat Smith 走自己的订阅（美区参考价约 $6.99/周、$9.99/月、$49.99/年），官方应用各有各的免费额度与会员体系。

## 五、装好之后从哪开始

还没装的话先看 [下载与安装教程.md](下载与安装教程.md)。打开应用后，建议按这个顺序试：先用普通对话问一个问题感受默认模型，再试一次总结（扔个 PDF 进去），最后试图像生成——这样免费额度够不够、值不值得订阅，你半天内就能自己判断出来。
