## 一、发消息与附件

进入聊天对话后，点 + 号可以附加：

- 照片与视频
- 你的位置
- 联系人
- 链接
- 文档

文件类附件点回形针（Clip）图标选择。能附加哪些内容取决于你给应用开的权限与系统版本——发不了照片通常是存储权限没给。

## 二、找回发过的内容

- **会话内搜索**：打开对话 → 安卓点右上角三点（iPhone 点对方名字）→ 进入资料信息 → Search。支持按关键词搜，也支持按日期翻。
- **Shared Media（共享媒体）**：在联系人或群聊的资料信息里打开，集中列出这个对话里发过的图片、文档与链接，比翻聊天记录快。

## 三、语音与视频通话

三种发起入口：联系人资料页点 Call / Video；聊天窗口右上角的通话图标；或在 Calls 标签的通话记录旁点 (i) 后重拨。

| 状态 | 含义 |
| --- | --- |
| Calling | 正在发起 |
| Ringing | 对方手机在响 |
| 计时数字 | 已接通 |
| Answering | 呼叫出错，直接重拨 |

对方接通前显示 Answering 而不是 Ringing，按官方帮助口径属于呼叫异常，重拨一次即可。

## 四、弱网与省流量

官方把「网络差」列为消息发不出、通话失败的首要原因。官方页面称通话与消息在慢速或不稳定的网络下仍保持可用；具体到操作层面，你可以用这几个手段：

1. **切换网络**：通话不稳，先在 Wi-Fi 与移动数据之间切换试试。
2. **低数据用量模式（Low Data Usage）**：在设置里打开，牺牲一部分画质换取通话可用性，适合流量有限的场景。
3. **看消耗**：拨打出去的通话结束后，应用会显示这次用了多少 KB 或 MB，方便你对照自己的套餐。

消耗能低到什么程度？官方在省数据模式的说明里给过一组参考值：1 MB 流量大约够 7 分钟语音通话，或 2 分钟视频通话（以官方口径为准，实际取决于网络与画质）。

有用户反馈过「只在 Wi-Fi 下正常、移动数据发不出消息」的情况（App Store 用户评价，非官方结论），遇到类似现象优先检查应用的网络权限与系统省流量策略，再走 [常见问题与故障排查.md](常见问题与故障排查.md) 的排查步骤。

## 五、群聊与限时内容

- 可以建群聊天；群聊同样支持共享媒体与搜索。
- 群里的语音/视频会议（群通话）也能开，但免费版有人数上限——多篇评测提到免费版最多 8 人，Premium 提升到 1000 人（单一来源信息，以应用内实际提示为准）。两档的完整差别见 [Premium 订阅与免费版差别.md](Premium%20订阅与免费版差别.md)。
- 较新版本加入了一次性查看的媒体（照片、语音、视频看一次即失效）与限时语音消息；这些选项是否出现在你的版本里，以应用内附件菜单实际显示为准。
- 文件传输方面，官方页面的口径是支持大文件、且传输中断后能从断点继续；单文件的具体大小上限以官方页面与应用内实际提示为准。

## 六、备份与数据保留说明

Zangi 没有云端备份：聊天记录在本机，卸载应用或换手机后不会恢复。要留下重要内容，靠截图或手动转移文件。这与多数通讯应用的「云端漫游」是相反的设计，用之前先想清楚自己的需求。

通话、消息连续失败时的完整排查步骤见 [常见问题与故障排查.md](常见问题与故障排查.md)。
