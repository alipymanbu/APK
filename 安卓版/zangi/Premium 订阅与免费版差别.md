## 一、免费版与 Premium 的功能差别

综合官方口径与多篇独立评测（截至 2026-09，以应用内实际显示为准）：

| 功能 | 免费版 | Premium |
| --- | --- | --- |
| 文字聊天、语音与视频通话 | 可用 | 可用 |
| 群聊、群会议 | 可用（会议人数有上限） | 会议人数上限提升（有评测称可达 1000 人） |
| 资料页名字旁的徽章 | 无 | 有 |
| 用 PIN 码锁单独的聊天 | 无 | 有 |
| 文件按原尺寸发送（不压缩） | 无 | 有 |
| 低数据用量模式、阅后即焚类内容 | 可用（随版本提供） | 同样可用 |

两点说明：

- 免费版群会议的人数上限，有评测称是 8 人；这一数字来自单一来源，以你应用里实际提示为准。
- 「紧急情况下用秘密代码一键抹除本机数据」被个别评测列为 Premium 功能，同样属于单一来源信息，购买前先在应用内确认。

## 二、价格口径

价格随平台与促销变化，查到的口径如下（查证时间 2026-09）：

| 来源 | 口径 |
| --- | --- |
| iOS App Store 内购列表 | $5.99 / $14.99 / $49.99 三档 |
| 多篇评测 | 每月约 6 欧元，或每年约 45 欧元 |

三档内购一般对应月付、季付（或类似中间档）与年付，具体每档时长以订阅页显示为准。Android 端的价格与档位以 Google Play 内购页为准，可能与 iOS 不同。

## 三、要不要订阅的判断依据

对着上表核对就够了：

- 只用文字聊天、语音视频通话、小群沟通——免费版已经覆盖这些，订阅不会给这几项带来变化。
- 要发原尺寸的大文件（照片、视频不压缩）、要锁住某几个聊天、要开人数多的会议——这几项只在 Premium 里有。
- 订阅在应用内购买，走的是应用商店的支付渠道；订阅管理与退订入口在应用商店的订阅设置里。
