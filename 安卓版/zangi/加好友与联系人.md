# Zangi 怎么加好友与添加联系人

> Zangi 没有手机号、也不提供「按昵称搜索陌生人」，找人只靠 Zangi Number。本篇讲三种把人加进来的方式、邀请还没装的朋友，以及为什么你搜不到某个人。

## 一、三种找人方式对照

| 方式 | 适用场景 | 入口 |
| --- | --- | --- |
| 添加联系人 | 对方已在用 Zangi，你拿到了号码 | Contacts 标签 → 加号图标 → 输号码 → 保存 |
| 直接开聊 | 临时联系一次，不保存联系人 | Chats 标签输入号码，或 Calls 拨号盘输入号码 |
| 邀请注册 | 对方还没装 | Invite Friends → 短信或其他应用分享 |

## 二、添加联系人（对方已有号码）

1. 让对方把他的 Zangi Number（10 位数字）发给你。
2. 打开 Contacts（联系人）标签，点添加联系人图标（+）。
3. 输入对方的 Zangi Number，保存。
4. 之后在联系人列表或搜索框里找到这个人，打开资料页就能聊天、打电话、视频。

也可以从 Chats（聊天）标签直接开始：安卓上是铅笔图标，iPhone 上是 + 图标，输入对方的 Zangi Number 即可。

## 三、不保存联系人，直接开聊

官方还提供「直接号码发起」的方式：

1. 打开 Calls（通话）标签，进入 Keypad（拨号盘）。
2. 输入对方的 Zangi Number。
3. 点呼叫按钮后可以选择 Chat（聊天）、Call（语音）、Video（视频）。

这样适合一次性联系：不用先建联系人，聊完不留列表项。

## 四、邀请还没装的朋友

1. 在应用里点 Invite Friends（邀请好友）。
2. 选 Via SMS（短信）或 Share via（其他应用分享）。
3. 选短信时需要给 Zangi 通讯录权限——按官方说明，这一步通讯录数据不会离开你的手机，只在本地用来匹配你要发的对象。
4. 应用会生成一段带链接的邀请文本，发给对方即可。

对方注册后会把他的 Zangi Number 给你，再按第二节的步骤加成联系人。

## 五、为什么你搜不到某个人

这是 Zangi 与多数通讯应用最大的行为差异，先说结论：

- **你搜不到、也找不到任何陌生人。** 资料不会被公开检索，只有知道你确切 Zangi Number 的人才能联系到你。
- **对方同理。** 你拿不到号码，就联系不上对方。
- **一个联系人可能对应多个号码。** 如果联系人名下不止一个 Zangi 号码，应用会在你发消息或打电话前先问你用哪个。

所以「加不上好友」多数不是故障，而是号码没拿对：先把 10 位号码逐位核对（多打、漏打一位都对不上），再按第二节的步骤走。

号码是怎么分配的见 [注册与账号设置.md](注册与账号设置.md)；加上之后聊天与通话的具体玩法见 [聊天与通话功能.md](聊天与通话功能.md)。
