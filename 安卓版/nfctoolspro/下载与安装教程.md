## 一、安装前先确认三件事

1. **手机有没有 NFC**：这个应用读写的是 NFC 标签，手机本身得带 NFC 硬件。最快的判断方法是打开系统设置，在搜索框里搜「NFC」，能搜到开关就是有；搜不到多半是没有。也可以到 [devices.nfc.help](http://devices.nfc.help/) 按机型查询，这个站还能顺便告诉你你的机型支持哪些标签芯片。
2. **系统版本够不够**：安装包标注的系统要求为 Android 5.2 及以上（以安装时手机弹出的提示为准）。现在在售的安卓机基本都满足。
3. **存储空间**：安装包约 8.48M，加上安装后的占用，留出几十 MB 就足够。

## 二、安装步骤

还没有安装包的话，先从 [NFC Tools - Pro Edition 安装文件资源（夸克网盘）](https://pan.quark.cn/s/76b32531172c)转存到自己的网盘，再下载到手机。之后的步骤：

1. 打开下载好的 APK 文件（文件名形如 `nfctoolspro_v9.1.apk`）。
2. 如果系统弹出「不允许安装未知来源应用」的提示，按提示进入设置，给「文件管理」或浏览器这一类来源授权，然后返回重试。
3. 点「安装」，等进度条走完。
4. 装完点「打开」，首次启动会直接进入主界面，不需要注册账号。

安装包的核对信息如下，担心文件不对时可以比一下：

| 项目 | 值 |
| --- | --- |
| 版本 | 9.1 |
| 包名 | `com.wakdev.nfctools.pro` |
| 大小 | 8.48M |
| MD5 | `B93B95695CFB25C8AA0B1CEC64F10808` |

包名这一项有个实际用途：Pro 版和免费版 NFC Tools 是两个独立应用（免费版包名是 `com.wakdev.wdnfc`），可以在同一部手机上共存。装完后到系统「应用信息」里看包名，就能确认装的是 Pro 版而不是免费版。

## 三、装完第一件事：打开 NFC 开关

应用本身不负责开 NFC，这个开关在系统设置里：

1. 打开系统设置，进入「连接」（部分机型叫「更多连接方式」或「无线和网络」）。
2. 找到 NFC 开关并打开。

开好之后打开应用，切到「读取」页，拿一张任意 NFC 卡片或标签贴到手机背面，能读出信息就说明整条链路是通的。读不出来先看 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、版本说明

网盘资源里这份安装包的版本是 **9.1**。按官方更新日志，9.1 这一版的内容是：更新 API 与 SDK（36）、新增自适应应用图标、若干修复与改进。

官方对 NFC Tools 系列的更新比较频繁，目前发布页已有更新的 9.x 版本。版本差异主要影响新标签芯片的识别和个别记录类型，读写的基本用法没有变化；需要看最新版改了什么，可以查官方发布页 [release-notes.nfctools.wakdev.com](http://release-notes.nfctools.wakdev.com/)，以官方页面为准。

## 五、安装阶段的常见报错

- **提示「解析包出现问题」或「安装失败」**：多半是下载过程中文件损坏，重新下载一遍再装；确定文件没问题的话，核对一下上表的 MD5。
- **安装时提示存储空间不足**：清一下手机存储再来。
- **装好了但打开就闪退**：先确认 NFC 硬件确实存在（个别改装系统或模拟器没有 NFC，这类设备上无法使用）。
- **想知道读写标签怎么上手**：直接看 [NFC标签读写入门.md](NFC标签读写入门.md)，从「读取」页开始试。
