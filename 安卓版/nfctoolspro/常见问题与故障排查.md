## 一、标签读不出来，按顺序排查

读不到时，常见原因按出现概率排：

1. **手机不支持这种芯片**：不是所有 NFC 手机都认所有标签技术，典型例子是不少手机读不了 MIFARE Classic。这时应用会直接提示 **Not supported**——这不是应用的问题，是硬件层面的限制。
2. **标签是只读的**：被锁定过、设了密码、或者本身出厂就是只读的芯片。
3. **标签坏了**：反复摩擦、弯折、消磁都会导致芯片损坏，换一张试试就能排除。
4. **它根本不是 NFC**：很多 RFID 卡（老式工卡、部分门禁卡）长得一样但不是 NFC 协议，手机读不出来是正常的。
5. **位置没对**：NFC 感应区一般在手机背面摄像头附近，各机型位置不同，贴上去小范围慢慢挪。

先拿一张确定正常的 NTAG 标签读一遍：读得出来，说明手机没问题，问题在那张读不出的标签上；读不出来，先检查系统 NFC 开关是否打开。

## 二、Not supported 提示

提示 Not supported 就一条路：手机硬件不支持该标签技术，应用侧无解。能做的是换标签——买 [NFC标签读写入门.md](NFC标签读写入门.md) 第四节推荐的 NTAG21x 系列，这类标签几乎所有 NFC 手机都认。

想提前确认自己的机型支持什么，可以到 [devices.nfc.help](http://devices.nfc.help/) 按机型查。

## 三、写入失败

- **写一半拿开了**：写入过程手机必须贴着标签不动，直到提示完成。这是最常见的原因。
- **标签容量满了**：先读一遍看已用容量，删掉几条记录再写，或换大容量标签（三档常用型号的用户可写区为 144 / 504 / 888 字节，对照见 [NFC标签选购与容量对照.md](NFC标签选购与容量对照.md)）。
- **标签设了密码**：不知道密码就写不了，跳到下一节。
- **标签被锁定**：锁定是不可逆的，这张标签只能读，换新标签。
- **手机壳太厚或标签贴在金属上**：隔着厚手机壳、或者标签贴在金属面上时，读写都会变得不稳定，处理办法见第五节。
- **系统弹窗打断了写入**：写入时如果弹出通知或来电，等处理完重新写一遍即可，写坏的内容用「擦除」清掉重写。

## 四、锁定与密码的两个坑

- **锁了就解不开**：官方 FAQ 明确说明锁定操作没有后悔药，变成只读后任何工具都改不回来。想保留改动的余地，用密码保护代替锁定。
- **密码忘了等于标签报废**：密码保护只对 NTAG21x、MIFARE Classic 这类支持密码的芯片有效，忘了密码就没有写入通道了。给公共场合的标签上密码前，先把密码记在可靠的地方。

对于已经被锁死或设备不支持的标签，官方另有一个免费插件 **NFC Tools Plugin - Reuse Tag**，可以尝试重新利用这类标签，具体支持范围以插件页面说明为准。

## 五、手机壳与金属面

NFC 的有效读取距离本来就只有几厘米，下面两种情况会把它进一步压到不可用：

- **手机壳**：超过 3 毫米的厚壳、金属边框壳、带磁吸片的壳都会明显削弱信号。排查时先摘掉手机壳贴一次，读得出来就是壳的问题。
- **金属表面**：标签直接贴在金属上（铁柜、金属桌面、车载支架、设备外壳）会整张失效。原因是金属会把标签天线的磁场耗散掉，换手机换应用都救不回来。

金属面的出路有两条：换购带铁氧体隔层的「抗金属」标签，或者给普通标签垫几毫米的非导电垫层（泡沫胶、亚克力片）。芯片型号与抗金属无关，选购细节见 [NFC标签选购与容量对照.md](NFC标签选购与容量对照.md) 第三节。

一个快速定位方法：把标签从贴装面上拿起来，悬空再读一遍。悬空读得出来、贴回去就读不出，就是金属面的问题，标签本身没坏。

## 六、用 NFC 标签解锁手机：走 Smart Lock

想拿 NFC 标签当解锁钥匙，不需要复制什么卡，安卓系统自带这条通道：

1. 打开系统设置 → 安全（部分机型在锁屏设置里）→ **Smart Lock**（需先设好锁屏密码/图案才会出现）。
2. 选择「受信任的设备」，添加你的 NFC 标签。
3. 之后手机检测到这张标签在旁边，就保持解锁状态。

这个功能从 Android 5 就有了，和 NFC Tools 无关，但和它配合很自然：标签交给 NFC Tools 管内容，解锁交给系统管。

## 七、隐私与数据

按 Google Play 上开发者提交的数据安全声明（截至本篇整理时，以商店页面为准）：NFC Tools - Pro Edition **不收集数据、不与第三方共享数据**。读写标签产生的数据都留在你手机本地。官方支持邮箱是 `apps@wakdev.com`，遇到应用本身的问题可以发邮件反馈。

## 八、常见误解快答

- **能复制门禁卡/公交卡/银行卡吗**：不能，这类卡读保护，任何常规应用都复制不了，详见 [Pro版独有功能.md](Pro版独有功能.md) 第七节。
- **免费版和 Pro 版能同时装吗**：能，两者包名不同，是两个独立应用。
- **iPhone 能用吗**：wakdev 另有 iOS 版 NFC Tools，但那是独立的应用和购买，安卓安装包装不到 iPhone 上。
- **任务不执行**：检查装没装 NFC Tasks、权限给没给全，步骤见 [任务自动化设置.md](任务自动化设置.md) 第一节。
