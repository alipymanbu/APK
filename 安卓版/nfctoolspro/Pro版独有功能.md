## 一、和免费版的差别在哪

Pro 版不是另一个应用，它把免费版 NFC Tools 的全部能力都包含在内，再放开所有限制并追加几项独有功能。对照关系如下：

| 能力 | 免费版 | Pro 版 |
| --- | --- | --- |
| 读标签、写记录（网址/文本/Wi-Fi 等） | 有 | 有 |
| 擦除、锁定、密码保护 | 有 | 有 |
| 往标签写任务（配合 NFC Tasks 执行） | 部分任务 | 全部 200+ 任务 |
| 保存配置文件（profiles），重复使用 | 无 | 有 |
| 从已有标签导入记录和任务 | 无 | 有 |
| 不用标签，从桌面快捷方式直接执行任务 | 无 | 有 |
| 用手机模拟 NDEF 标签 | 无 | 有 |
| 条件块（if/else 式的任务逻辑） | 无 | 有 |

如果只是偶尔往标签写个 Wi-Fi 密码，免费版就够；要反复调整标签内容、或者想把任务组合成一套流程，Pro 版省的是返工时间。

## 二、配置文件：把一套内容存起来反复用

日常最常见的场景是「同一套记录和任务，要写好几张标签」，或者「写错了想改了重写」。Pro 版的配置文件就是干这个的：

1. 把记录、任务按平时那样加好。
2. 存成一个配置文件（profile），起个能认出来的名字。
3. 下次要写新标签时直接调出这套配置写入，不用一条条重新加。

配置文件也适合做「版本管理」：给标签内容做一版存档，之后改坏了能随时调回上一版重新写入。配置文件还支持导出与导入（官方描述明确列了这一项），换新手机或多台设备共用同一套标签内容时，导出成文件再在另一台手机上导入即可，不用重建；具体入口位置以应用内为准。

## 三、从已有标签导入

拿到一张别人写好的标签，或者自己半年前写的标签想改：

1. 「读取」页先读一遍，确认里面的内容。
2. 用导入功能把标签上的记录和任务原样搬进应用。
3. 增删改之后重新写回同一张标签。

没有这一步的话，旧内容只能手抄一遍再重新添加，任务多了非常折腾。

## 四、不用标签直接跑任务

写在标签里的任务，Pro 版可以脱离标签执行：给某个任务组合建一个桌面快捷方式，点图标就跑，不用碰任何标签。适合那些「本来就不需要实体触发」的场景，比如出门前点一下就静音加开勿扰。

要理解这个功能的边界，得先分清两类东西：记录（网址、文本等）写在标签上是给别人读的；任务（开关蓝牙、调音量等）是给执行器跑的。桌面快捷方式只对任务类内容有意义。

## 五、用手机模拟 NDEF 标签

Pro 版能把「写入」页里的记录（NDEF 格式）通过手机本身的 NFC 模拟出去——你的手机在别的读卡器眼里就是一张写好了内容的标签。比如把一张电子名片存进模拟标签，对方的支持 NDEF 读取的手机碰一下就能收到。

适用范围以官方说明为准：能模拟的是 NDEF 记录，不是任意卡片。

## 六、条件块：给任务加判断

条件块让你按条件决定任务走哪条路，比如「如果是周末就只静音不勿扰」「Wi-Fi 已连接就跳过开流量」。设置方式类似积木：在任务列表里插入条件块，把满足条件时执行的动作和不满足时执行的动作分别填进去。具体能用的条件类型以应用内「任务」页实际提供的为准。

条件块配合任务的具体写法，见 [任务自动化设置.md](任务自动化设置.md)。

## 七、能不能复制门禁卡：不能

这是搜索里最常见的误解，直接给结论：**门禁卡、公交卡、银行卡复制不了**。这类卡片出于安全设计，敏感扇区都是读保护的，手机读不到完整数据，任何常规应用都做不到整卡复制。

Pro 版能做的「模拟」只有上一节说的 NDEF 记录模拟，对象是网址、文本这类公开数据。市面上有专门的硬件工具去做全卡模拟，那是另一个话题，不是这个应用的用途范围。想用 NFC 标签做门禁替代、解锁手机这类事，能走的正路见 [常见问题与故障排查.md](常见问题与故障排查.md) 里的 Smart Lock 一节。
