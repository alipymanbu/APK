## 一、读取：贴上去能看懂什么

打开应用切到「读取」页，把标签贴在手机背面（摄像头附近的位置，不同手机感应区不一样，贴上去慢慢挪一下），读出来大致是这些信息：

| 信息项 | 说明 |
| --- | --- |
| 厂商与标签类型 | 例如 NTAG215、MIFARE Ultralight |
| 序列号（UID） | 标签的出厂唯一编号，例如 `04:85:c8:5a:40:2b:80` |
| 技术与标准 | 例如 NFC A、NFC Forum Type 2 |
| 容量 | 总容量和已用容量，决定你还能写多少东西 |
| 可写状态 | 标签是否还能写入，还是已被锁定为只读 |
| NDEF 数据 | 标签里已经存的内容，会逐条列出来 |

先拿手边随便什么 NFC 卡读一遍，熟悉一下界面，再动手写。

## 二、写入：支持哪些记录类型

切到「写入」页，点「添加记录」，常用的类型有：

| 记录类型 | 典型用途 |
| --- | --- |
| 文本 | 一句备忘，碰一下就显示 |
| 网址 | 贴在店门口让顾客碰一下打开网页、贴在家里路由器上打开管理页 |
| 联系人（vCard） | 名片标签，碰一下保存联系方式 |
| Wi-Fi 配置 | 客人碰一下就连上你家 Wi-Fi，不用报密码 |
| 电话 / 短信 | 贴在老人机旁一键拨号 |
| 邮件 | 预填收件人和主题 |
| 地址 / 定位 | 碰一下打开导航 |
| 社交主页 / 应用 | 打开某个社交资料页或应用 |
| 自定义数据 | 存任意数据，配合支持的设备使用 |

一张标签可以叠加多条记录，点「写入」后把手机贴上标签，保持不动直到提示写完。写入时手机别拿开，中途移开是最常见的失败原因。

## 三、擦除、锁定与密码

「其他」页里是这几个管理操作，用之前把区别弄清楚：

- **擦除**：清掉标签里写的内容，标签还能继续用。
- **锁定**：把标签变成永久只读。**这一步不可逆**，锁了就再也写不了，应用会在你确认前弹红色警告，想清楚了再点。
- **密码保护**：给标签设一个密码，之后没有密码就写不进去，比锁定灵活。注意只有部分芯片支持，典型的是 NTAG21x 系列和 MIFARE Classic；NTAG21x 的密码是 4 字节（十六进制 8 位，从 `00000000` 到 `FFFFFFFF`，约 43 亿种组合），暴力尝试基本不现实。**密码忘了，标签也就写不了了**，设完记下来。

拿到一枚来路不明的旧标签，先「读取」看可写状态，再决定擦除还是直接换新的。

## 四、买标签时的挑选建议

- **优先买 NTAG21x 系列**（NTAG213、NTAG215、NTAG216 是最常见的三档，容量从小到大）。这是官方 FAQ 里点名推荐的通用型号，兼容性最好，还支持密码功能；三个型号的容量对照与按用途的选择方法，见 [NFC标签选购与容量对照.md](NFC标签选购与容量对照.md)。
- 贴纸卡、卡片、滴胶卡内容物都一样，选外形按用途来：贴固定位置的买贴纸，放钱包的买卡片。
- 官方测试过的芯片覆盖面很广，除了 NTAG 系列，还包括 MIFARE Ultralight、ICODE、DESFire、ST25TV、FeliCa、Topaz 等；具体清单见官方知识库的[推荐芯片列表](https://www.wakdev.com/en/knowledge-base/nfc-basics/nfc-chips-for-nfc-tools.html)。
- 标签买回来先读一遍确认能被识别，再贴到撕不下来的位置。

写入这块没问题之后，下一步通常是让标签替你干活——切设置、开应用那类自动化，见 [任务自动化设置.md](任务自动化设置.md)；Pro 版比免费版多了什么，见 [Pro版独有功能.md](Pro版独有功能.md)。
