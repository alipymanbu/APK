## 一、先装配套的 NFC Tasks

写在标签里的任务不是 NFC Tools 自己执行的。执行它们的是官方另一个免费应用 **NFC Tasks**（包名 `com.wakdev.nfctasks`，Google Play 直接搜名字就能装）。

分成两个应用是刻意的设计：执行任务需要一堆敏感权限（改音量、开关连接、发短信等），而读写标签只需要 NFC 一个权限。wakdev 把两者拆开，让你不用任务功能时，NFC Tools 只需要最少的权限。所以：

- 只想读写记录（网址、文本、Wi-Fi）→ 不用装 NFC Tasks。
- 想要碰一下标签就自动改设置 → 必须装 NFC Tasks，执行时会向它申请相应权限。

## 二、写一个自动化任务的完整步骤

以「床头贴一张标签，睡前碰一下就静音并设好闹钟」为例：

1. 在 NFC Tools 切到「任务」页，点「添加任务」。
2. 从分类里挑动作，比如「声音」类里的静音、「时钟」类里的设置闹钟；一个标签可以叠多个动作，按顺序执行。
3. 切到「写入」页（任务和记录可以写进同一张标签），点「写入」，把手机贴上标签直到写完。
4. 确认手机上装好了 NFC Tasks，把手机重新碰一下这张标签——NFC Tasks 会接手并按顺序执行里面的动作。
5. 第一次执行时系统会逐项弹权限，允许之后以后就会静默执行。

测试时建议拿一张便宜标签练手，流程跑通了再写正式用的那张。

## 三、常用任务清单

任务有 200 多个，按分类组织。挑读者最常用的列出来：

| 分类 | 典型动作 |
| --- | --- |
| 连接 | 开/关/切换蓝牙、Wi-Fi，配置指定 Wi-Fi 网络 |
| 声音 | 静音/振动/正常模式切换，调铃声、媒体、通知音量 |
| 屏幕 | 调亮度 |
| 时钟 | 设闹钟、计时器，往日历插一条事件 |
| 应用 | 启动指定应用，打开网址/URI |
| 通讯 | 发短信、拨打电话、语音朗读一段文字 |
| 设备 | 录音、播放声音 |

同一个任务组合里动作是按顺序执行的，排在前面的先跑。全部任务以应用内「任务」页实际列出的为准。

## 四、Pro 版在自动化上的三处增强

- **条件块**：给任务加「如果……就……否则……」的判断，详见 [Pro版独有功能.md](Pro版独有功能.md) 第六节。
- **免标签执行**：把任务组合建成桌面快捷方式，点图标就跑，不依赖实体标签。
- **全部任务解锁**：免费版只开放部分任务，Pro 版 200+ 全部可用，组合数量不受限制。

另外，写在标签里的任务别人也能触发——任何人拿手机碰到标签，NFC Tasks 都会执行。所以别把「发短信给某人」这类动作贴在公共场合的标签上；NFC Tasks 里有确认相关的选项，敏感动作建议开着确认执行。

## 五、贴在哪：几个经过验证的位置

- **床头**：睡前碰一下，静音 + 闹钟；早起那面再贴一张，关闹钟 + 开 Wi-Fi。
- **车载支架**：上车一放，开蓝牙 + 打开导航应用。
- **路由器/机顶盒**：贴上写有管理页网址的标签，配置网络时不用翻说明书。
- **玄关**：出门碰一下，关 Wi-Fi、开流量、开静音。
- **客人 Wi-Fi 卡**：写好 Wi-Fi 配置放在客厅，客人碰一下就连上，密码不用念第二遍。

标签贴到墙上之前，先拿在手机上验证一遍所有动作都正常，因为贴牢之后再想改内容就得抠下来了。写入操作本身不熟的话，回 [NFC标签读写入门.md](NFC标签读写入门.md) 过一遍第二节。
