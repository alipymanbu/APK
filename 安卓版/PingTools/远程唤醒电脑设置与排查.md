# PingTools Pro 远程唤醒电脑设置与排查

> 手机发个「魔术包」就能把家里关机的电脑开起来，但 Wake on LAN 以「十有八九第一次不通」闻名——因为要在目标电脑上同时改对好几处设置。本篇按顺序把条件列全，再给一份失败排查清单。

## 一、先说三个容易翻车的前提

动手设置之前，先确认你的场景做不做得到：

1. **目标电脑用网线**——WoL 在有线以太网上最可靠；Wi-Fi 网卡大多不支持断电唤醒，即使支持也不稳定。能用线就把线插上；
2. **电脑没有彻底断电**——网卡唤醒靠的是关机后的待机电流，电源线拔了、或插排开关关了，一切免谈；笔记本要接电源或电量充足；
3. **不是所有电脑都支持**——部分超薄本、低价主板在固件里直接砍掉了 WoL，这种硬件层面无解，查你主板的说明书确认。

## 二、目标电脑要改的四处（以 Windows 为例）

按顺序逐处核对，缺一处就唤不醒：

| 位置 | 要做的事 |
| --- | --- |
| BIOS/UEFI | 开启 Wake on LAN / Power On by PCI-E / Resume by LAN（各品牌叫法不一）；若固件里有 **ErP / Deep Sleep** 选项，**关掉**——它会在关机后切断网卡供电 |
| 设备管理器 → 网卡 → 电源管理 | 勾上「允许此设备唤醒计算机」和「只允许魔术包唤醒计算机」 |
| 设备管理器 → 网卡 → 高级 | 把 **Wake on Magic Packet**（或 Shutdown Wake-On-LAN 等同类项）设为启用；有 **Energy-Efficient Ethernet（节能以太网）** 选项的也建议关闭 |
| Windows 电源选项 | **关闭「快速启动」**——快速启动下的「关机」不是真关机，网卡不处于可唤醒状态 |

以上为 Windows 通用路径（各 OEM 官方支持文档口径一致）；MAC/Linux 目标机的做法不同（Linux 用 `ethtool` 把网卡 Wake-on 设为 `g`），不在本篇展开。设置改动较大时，改完**正常开机一次再正常关机一次**再测。

## 三、在手机端发送：先抄 MAC，再发魔术包

1. 目标电脑**开机且联网**时，先用 PingTools 的「局域网」工具扫一遍，在列表里找到这台电脑，**抄下它的 MAC 地址**——魔术包就是发给这个地址的。注意要抄**有线网卡**的 MAC，别抄成 Wi-Fi 的（多数机器两个网卡 MAC 不同，这也是常见的失败原因）；
2. 打开 Wake on LAN 工具，填入 MAC，同一局域网内直接发送；
3. 电脑应在几秒内启动。把这台设备**保存为收藏**，下次一键发送。

发不出去（应用层面就报错）的情况不同于「发了没反应」：前者多半是手机网络环境问题，后者是目标机条件没备齐，看下一节。

## 四、发了没反应：逐条排查

按命中率从高到低：

1. **ErP / Deep Sleep 还开着**——固件里把网卡电断了，其余设置全对也没用；
2. **快速启动没关**——控制面板 → 电源选项 → 选择电源按钮的功能里取消勾选；
3. **MAC 抄错**——重新扫描局域网，对着有线网卡抄一遍；
4. **目标在睡眠而非关机时也唤不醒**——检查是否用了 Modern Standby 的特殊电源状态，以主板文档为准；
5. **先验证基本连通**——用 PingTools ping 一下目标电脑的 IP，能 ping 通再发包；ping 都不通说明根本不在一个网段或被隔离了；
6. **电脑被拔过电**——断过市电的机器常需要再正常关机一次才恢复可唤醒状态。

## 五、人在外面怎么唤醒家里的电脑

魔术包是广播包，**默认出不了路由器**，人在外网时两条路：

- **VPN 连回家再发**（多数家用路由器支持）——连上后手机等于在家里局域网，发法和室内一样。这是推荐做法，不对外暴露端口；
- **路由器上做 UDP 端口转发指向广播地址**——可行，但等于给公网开了一条唤醒通道，安全上要掂量，能用 VPN 就别用这条。

跨子网（公司网络里隔着 VLAN）同理：需要路由器/三层设备配合转发广播，默认配置基本不通，找网管。
