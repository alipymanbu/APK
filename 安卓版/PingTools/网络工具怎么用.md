## 一、工具总览：按你想干的事找

| 你想干什么 | 用哪个工具 |
| --- | --- |
| 看本机网络状态、路由器 IP、运营商 | Info |
| 一直盯着某台服务器/摄像头/NAS 掉没掉线 | Watcher |
| 查局域网里有哪些设备 | 局域网（LAN）、子网扫描器 |
| 认出某台设备是什么（路由器/游戏机/NAS） | UPnP 扫描器、Bonjour 浏览器、端口扫描器 |
| 测某台主机通不通、延迟多少 | Ping（ICMP/TCP/HTTP 三种） |
| 看数据包走了哪条路、在哪个节点卡住 | Traceroute |
| 看你的网站在别的国家能不能访问 | GeoPing |
| 测内网/VPN 链路带宽 | iPerf、SpeedTest |
| 查域名解析、注册信息、子网参数 | DNS Lookup、Whois、IP 计算器 |
| 远程开机局域网里的电脑 | Wake on LAN（WoL） |
| 看周围 Wi-Fi 信号、选信道 | Wi-Fi 扫描器 |

局域网类的四个工具（LAN/子网/UPnP/Bonjour）操作细节较多，单独放在[局域网扫描与蹭网排查.md](局域网扫描与蹭网排查.md)里讲，本篇不重复。

## 二、测连通性：Ping

这是最常用的入口。PingTools 的 Ping 不只 ICMP 一种：

- **ICMP**：标准 ping，测最基础的可达性与延迟；
- **TCP Ping**：向指定端口发起连接测试，目标禁 ping（禁 ICMP 回应）时用它；
- **HTTP/HTTPS Ping**：直接测网页服务能不能打开，适合盯网站。

关键设置在测试参数里：间隔、次数、超时都能调。开启**后台工作与声音通知**后，你可以把手机放一边，掉线时它会用声音提醒你——盯路由器重启是否恢复、盯远程服务器是否掉线，都靠这一招。

遇到 ping 不通但网页打得开的情况，先换 TCP Ping 再下结论，见[常见问题与排查.md](常见问题与排查.md)第二节。

## 三、看路由与全球可达：Traceroute 与 GeoPing

**Traceroute** 显示数据包从你手机到目标主机经过的每一跳。自带的可视化模式会把路径标在地图上，一眼能看出是在国内骨干网慢、还是出境后慢。协议可选 UDP 或 ICMP，默认设置不通用时再换。

**GeoPing** 解决的是另一个问题：你的服务「在别的地方」能不能被访问。选一个目标（比如你自己的网站），它会从全球多个位置发起检查，一次点完就能看到新加坡、美国等各地的可达情况。面向多个地区用户的网站或 API，上线前后都可以用它抽查一遍各地区的可达性。

## 四、持续监控：Watcher

Watcher 是「定时自动跑的 Ping」。你把要盯的主机加进去、设好检查周期，它就按计划轮询，状态一变（通→断或断→通）就发通知。

典型用法：

- 盯家里路由器/NAS：半夜掉线早上能看到通知记录；
- 盯单位某台业务主机：设短间隔（如 1 分钟），状态变化第一时间知道；
- 配合声音通知做无人值守监测。

注意 Watcher 的计划存在应用本地数据里，清除应用数据会全部丢失，重装/换机前先把配置记下来。

## 五、测内网带宽：iPerf 与 SpeedTest

这组工具测的是**链路本身**的吞吐（手机到另一台设备之间），不是公网下载速度：

- **iPerf** 基于 iperf3，支持服务端与客户端两种模式：在电脑或另一台手机上跑一个 iperf3 服务端，手机这端填对地址就能压出真实带宽。测 Wi-Fi 实际速率、测 VPN 隧道损耗都用它；
- **SpeedTest** 是基于 iPerf 的简化版，适合快速测一遍。

测出来的结果里带丢包率等细节。注意 iperf 测试需要对端有服务端程序，只有一台设备时这组工具用不了。

## 六、查域名与地址：DNS Lookup、Whois、IP 计算器

- **DNS Lookup**：查一个域名解析到哪些 IP、MX 邮件记录等，支持反向解析（IP 反查域名）。换 DNS 服务商后想确认记录是否生效，用它最快；
- **Whois**：查域名的注册人、注册时间、联系信息，判断一个陌生域名靠不靠谱时有用；
- **IP 计算器**：输入 IP 和子网掩码，算出网段范围、可用地址数。给路由器划 VLAN、写 ACL 时省得手算。

## 七、结果保存与分享

官方对整个应用的定位里有一条贯穿各工具：**所有数据都可以保存或分享**。Ping 结果、扫描列表、测速记录都能导出给需要的人——报修、交接、存档时不用截图手抄。分享入口在各工具的结果页里找。收藏的设备与网络还能经官方的 PingCloud 服务在多台设备间同步，不用同步可以在设置里关掉，开关位置见[常见问题与排查.md](常见问题与排查.md)第七节。

各工具有些共同的坑（切网卡顿、旋转清结果等），集中记在[常见问题与排查.md](常见问题与排查.md)。想用 Wake on LAN 远程开机电脑的，条件都设在目标电脑上，步骤见[远程唤醒电脑设置与排查.md](远程唤醒电脑设置与排查.md)。还没装应用的话，从[下载与安装教程.md](下载与安装教程.md)开始。
