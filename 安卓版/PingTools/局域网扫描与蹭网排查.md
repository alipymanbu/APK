## 一、开工前的三个前提

扫描结果为空或明显偏少，多半不是应用的问题，先核对：

1. **手机连的是目标 Wi-Fi**——用移动数据做不了局域网扫描，连在访客网络里也看不到主网络的设备；
2. **关掉手机上的 VPN**——开着 VPN 时扫描流量会被引走，结果不可信；
3. **路由器没开 AP 隔离（无线隔离）**——开了隔离的 Wi-Fi 里，无线设备互相不可见，扫描只能看到网关。需要先在路由器管理页把它关掉。

## 二、先看一遍都有谁：局域网（LAN）工具

主界面进「局域网」，它会列出当前网段里所有在线设备，通常包括：

- 设备的 IP、主机名、MAC 地址；
- **硬件厂商**——由 MAC 地址前缀推出来，一眼能区分是手机厂商、路由器厂商还是别的什么；
- 设备上正在运行的服务。

核对方法很简单：把列表和自己名下的设备对一遍——家人的手机、电视、平板、智能音箱……对得上的划掉。剩下对不上的，进第三节确认。

这个列表顺便也能回答「我家路由器的管理 IP 是多少」这类问题：网关那一行就是。另外顺手记下需要远程开机的电脑的 MAC 地址——[远程唤醒电脑设置与排查.md](远程唤醒电脑设置与排查.md)里的魔术包就是发给它的。

## 三、逐段确认陌生设备：子网扫描器

LAN 工具一次扫默认网段；如果你想指定范围（比如网段里有多个子网，或只想扫一段），用**子网扫描器**：

1. 打开子网扫描器，默认会填好当前 Wi-Fi 的子网范围，可手动改成任意 IP 段；
2. 选择探测方式：**Ping**（最通用）或**检查多个 TCP 端口**（更准，能穿透禁 ping 的设备）；
3. 扫描结果里能看到哪些主机活着、哪些开着服务。

一个实用技巧：只扫 22 端口可以找出网段里哪台设备开着 SSH，只扫 80/443 能找出带网页管理界面的设备——这对判断「这台陌生设备是什么」很有用。

## 四、认出设备是什么：UPnP、Bonjour、端口扫描器

对上不了名的设备，用这三个工具交叉确认：

| 工具 | 你能认出什么 |
| --- | --- |
| UPnP 扫描器 | 路由器、游戏机（Xbox/PlayStation）、媒体服务器，以及 DLNA 电视与机顶盒（如三星 AllShare、LG SmartShare） |
| Bonjour 浏览器 | 苹果系设备（iPhone/Mac）和照搬 Bonjour 协议的设备（打印机等），Bonjour 服务通常带设备名 |
| TCP 端口扫描器 | 对着 IP 扫一遍常见端口，大多数端口带用途说明——开 8009 的大概率是电视盒子，开 5555 的可能是调试中的安卓设备 |

先 UPnP/Bonjour（快、结果可读性好），认不出的再用端口扫描补刀。

## 五、确认蹭网之后怎么办

排查的目的是发现，处置手段在你自己的路由器上，不在 PingTools 里：

- **改 Wi-Fi 密码**是最直接的一条，改完所有旧设备都要重连一次；
- 顺手**关闭 WPS**（一键连接），它的 PIN 验证方式相对容易被攻破；
- 在路由器管理页把陌生设备的 MAC 加入**黑名单**（或开启白名单模式）；
- 拿不准的设备可以先拉黑观察——如果家里有人抱怨连不上网，那多半是自己的设备。

处置前可以再跑一遍第三节的全段扫描，把陌生设备的 IP/MAC/厂商记录下来留证。
