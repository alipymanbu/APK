## 一、开启相机备份的步骤

1. 打开 OneDrive，点左上角的**账户头像**。
2. 在「相机备份已关闭」下方点**开启**，按提示确认。
3. 系统会弹照片与视频的权限申请——**要选「始终允许」这类后台可用的授权**，只给「使用时允许」的话应用退到后台就不传了。
4. 若提示选择账户，确认选的是你想存照片的那个（备份一次只能挂在一个账户上）。

开完之后新拍的照片、视频会自动往云端传，你不用每天手动操作。

## 二、三个开关按你的网络条件调

进入路径：头像 → **设置** → **相机备份**。

| 开关 | 什么时候开 | 说明 |
| --- | --- | --- |
| 上传方式（仅 Wi-Fi / Wi-Fi 和移动网络） | 流量充足、出门也要传 | 只在 Wi-Fi 传的话，出门一整天照片都堆在本地 |
| 仅在充电时备份 | 流量少、在乎耗电 | 一直插着电才传；平时拍照多的话建议关掉，否则相册长期缺货 |
| 包括视频 | 想连视频一起备份 | 视频体积大，5GB 免费空间很快会满，见 [存储空间与套餐选择.md](存储空间与套餐选择.md) |

## 三、把其他照片文件夹也纳入备份

默认只备份相机胶卷。微信保存的图、其他修图 App 的输出在别的文件夹里，要单独勾：

头像 → **设置** → **相机备份** → **备份设备文件夹** → 打开列表里的目标文件夹。

下面还有一个「保留原文件夹结构」的分类开关：打开就按原文件夹存；关掉则全部照片归进一个「相机胶卷」文件夹。想日后好找就开着。

## 四、备份是单向的

官方明确说明：本机照片**只备份到云端，不双向同步**。你在手机上删掉某张已备份的照片，云端那份不受影响。反过来，电脑或网页端删了云端文件，手机相册里的原图也还在 —— 这不是漏删，是设计如此。

正因为单向，「传完就删本地」才是安全的腾空间手法：备份确认完成后删掉手机里的原图，云端副本照常保留。具体入口与触发条件见 [手机空间不够用怎么腾.md](手机空间不够用怎么腾.md)。

## 五、Samsung 相册 2026-09-30 起停止直连

用三星手机的注意：**从 2026 年 9 月 30 日起，Samsung Gallery 不再直接与 OneDrive 同步**，之后新用户无法再关联两个账户。官方给的迁移办法就是改用 OneDrive 自己的相机备份：

1. 打开 OneDrive 并登录（可能是微软账户，与三星账户不是同一个）。
2. 头像 → **相机备份** → 确认账户无误 → 打开开关 → 授予照片视频权限。

已经通过旧通道传上去的照片不受影响，云端都在；只是三星相册应用里不会再显示云端那部分，要看旧照片去 OneDrive 应用或网页端。详见官方说明 [Samsung Gallery 和 OneDrive](https://support.microsoft.com/zh-cn/onedrive/changes-to-samsung-gallery-sync-and-onedrive)（以官方页面为准）。

## 六、备份没跑起来怎么办

九成是开关或账户问题，按顺序核对（这也是官方排查清单的顺序）：

1. 头像 → 设置 → 相机备份，确认**开关是开的**；
2. 确认**备份账户**是你想要的那个；
3. 非 Wi-Fi 环境下，确认上传方式含**移动网络**；
4. 确认**仅在充电时备份**没有勾着；
5. 视频没传，确认**包括视频**开了；
6. 应用被划掉关闭后备份会停 —— 保持应用在后台活着。
