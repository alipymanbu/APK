# OneDrive 安卓版文件共享与离线使用

## 一、上传文件与新建文件夹

1. 打开 OneDrive，点屏幕底部的 **+** 图标。
2. 选**上传** → 在手机文件列表里勾选要传的文件（或照片）。
3. 要建目录就点 + 选**文件夹**，输入名称后确定。

传之前先看一眼右上角的剩余空间提示，空间不够文件会被直接拒收，处理办法见 [存储空间与套餐选择.md](存储空间与套餐选择.md)。

## 二、把文件发给别人

1. 找到目标文件，点右侧的**三个点（...）**。
2. 选**共享**。
3. 在弹出的渠道里选一种：邮件、复制链接、或直接调起微信等其他应用。

链接发出去之前，注意共享菜单里可选的权限范围（可编辑 / 只读）——对方拿到什么权限以你发送时的选择为准。对方不需要装 OneDrive 也能通过链接打开文件。

## 三、没网也能看：设为脱机可用

1. 目标文件（或文件夹）右侧**三个点（...）** → **设为脱机可用**。
2. 标记过的文件会下载到本地，飞机上、地铁里照样打开。

对应的反向操作是「移除脱机副本」：文件还在云端，只是本地不再占空间。判断一个文件当前是不是离线可用，看它旁边有没有离线标记，以应用内实际显示为准。

## 四、删除与找回

- **删除**：长按文件（多选就逐个勾圆圈）→ **删除** → 确定。文件进回收站，不立刻消失。**安卓端一次最多删 20 个**，批量超过就去网页端删。
- **找回**：点右下角「我」图标 → **回收站** → 找到文件点 **还原**。文件回到原位置。
- **清空回收站**：回收站视图里选中后删除即永久删除；安卓端右上角有**全部删除**一键清空。

**保留期（官方口径）**：

| 登录的账户类型 | 回收站保留 |
| --- | --- |
| 个人微软账户 | **30 天**后自动删除 |
| 工作或学校账户 | **93 天**（管理员可改） |
| 回收站已满 | **3 天**后自动删最早进来的项目 |

注意：**回收站里的文件照占你的配额**，想腾空间必须永久删除或还原（见 [存储空间与套餐选择.md](存储空间与套餐选择.md) 第四节）。误改比误删更难救 —— 个人账户还能在网页端取回同一文件**最近 25 个版本**的历史版本（来源：微软社区支持答复，规则以官方页面为准）。合同、证件这类敏感文件平时建议直接放[个人保管库](应用密码与个人保管库.md)，多一道二次验证。

## 五、扫描纸质文件

手机相机直接扫文档存 PDF 是 OneDrive 移动端自带的能力（官方产品页把它列为手机端核心用途之一）：在新建（+）菜单里找扫描入口，对准纸张拍摄、裁边、保存，产出直接落在你的云端目录里。入口名称与可用性以应用内实际版本为准，找不到入口可升级到官方商店最新版。
