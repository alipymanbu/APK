## 一、两道锁的区别

| | 应用密码 | 个人保管库 |
| --- | --- | --- |
| 防什么 | 别人拿起你手机直接打开 OneDrive 翻文件 | 就算账户被登着，敏感文件再加一道身份验证 |
| 验证方式 | 6 位 PIN（可换指纹） | 二次验证：短信 / 邮箱验证码 / Microsoft Authenticator 等 |
| 作用范围 | 整个应用 | 只有「个人保管库」这一个文件夹 |
| 成本 | 免费，开就能用 | 官方标注适用于 OneDrive Basic / Personal / Family 档 |

日常防随手翻用第一道；证件、合同这类放第二道。两道可以同时开。

## 二、给应用加启动密码

1. 头像 → **设置** → **密码** → 打开**需要验证码**；
2. 输入 6 位代码，再输一遍确认；
3. 开启后可调的选项：
   - **需要代码**：随时开关这道锁；
   - **更改代码**：换 6 位数字；
   - **密码超时**：多久没动重新要码，可选 5 秒 / 10 秒 / 30 秒 / 1 分钟 / 2 分钟；
   - **使用指纹进行身份验证**：嫌输码烦就开这个，解锁走指纹。

超时设短了每次切后台回来都要输码，按自己使用频率调。

## 三、启用个人保管库

个人保管库是 OneDrive 里的一个受保护文件夹，每台设备要**单独设置一次**：

1. 在应用里找到**个人保管库**文件夹，首次会提示**开始**（没看到提示就直接点该文件夹）；
2. **验证身份**：核对账户邮箱 → 验证；
3. 选验证方法（如短信），收到验证码填入；
4. 设置 PIN 完成启用。

之后每次进保管库都要过一遍所选的验证方式。文件放进去的办法：选中文件 → **移动到** → 个人保管库；也能在手机上直接**扫描文档、拍照、录像直接存进保管库**，不经过相机胶卷。

## 四、自动锁定与容量

- **不活动 3 分钟自动锁**（移动端默认）；改法：**我 → 设置 → 个人保管库 → 自动锁定/非活动锁定**，换别的时长。
- 容量就是你的账户总空间，订阅档可放任意数量文件直到占满配额；旧资料里「保管库只能放几个文件」的说法已过时。
- 可用范围截至官方页面说明：Web、移动应用、Windows 电脑；订阅档为 Basic / Personal / Family（以 [官方个人保管库说明](https://support.microsoft.com/zh-cn/onedrive/protect-your-onedrive-files-in-personal-vault) 为准）。

## 五、连带的两个细节

- **回收站里的保管库文件**：默认看不到，要在回收站里用「显示个人保管库项目」命令解锁后才列出（见 [文件共享与离线使用.md](文件共享与离线使用.md) 第四节）。
- **收不到验证码**：先检查账户安全信息里绑没绑手机号（头像与账户设置里补），这是最常见的原因。
