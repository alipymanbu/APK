## 一、搜索与筛选

主页左上角放大镜输入番名回车即可搜索。搜索结果页有两个按钮决定你看到什么：

- **排序方式**：按热度、排名、评分、匹配程度排序；
- **筛选番剧**：按题材标签、放送时间、评分与排名筛选。

搜索依赖已启用的规则（见 [规则导入与视频源管理.md](规则导入与视频源管理.md)）：规则没启用或失效时搜索会空手而归，先检查规则再怀疑软件。

## 二、时间表：这周哪天更新什么

主页 → `时间表`，按星期序列查看本周每天更新的番剧：

- 上方星期序列切换到具体某天；
- 左上角 `切换放送季度` 可以换放送季度（追旧季度或看新季度排期）；
- 右上角 `排序与筛选` 可按热度、评分、匹配程度排序，也可以「隐藏看过」「隐藏抛弃」「保留正在追的番剧」——把时间表过滤成只看你关心的那批。

## 三、追番状态：五档标记

在番剧详情页可以给番剧打标记，一共五档：

| 状态 | 用在哪 |
| --- | --- |
| 在看 | 正在追、还没完结的 |
| 想看 | 想看但还没开始的 |
| 看过 | 补完的 |
| 搁置 | 暂时不想追、又不舍得删的 |
| 抛弃 | 看了几集不合适的 |

顺带说详情页本身：页面展示的是由 Bangumi 提供的番剧信息（简介、标签、吐槽、角色、关联），右上角按钮可跳到该番在 Bangumi 的页面看更全的资料——挑番时先看这里，比只看封面准。

打完标记，主页 → `追番` 就是你的清单页；点番剧卡片上的 `观看状态` 按钮可以直接改标记，不用再点进详情。

## 四、历史记录与观看统计

- **历史记录**：`我的` → `历史记录`，记录你看过哪些、看到哪，是续播的入口；
- **观看统计**：`我的` 页面上方展示 `看过番剧` 数与 `观看集数`，就是个数字概览，看个乐。

追番、历史、统计默认都存在**本地设备**，不登录任何账号。要跨设备接着看，往下看。

## 五、多设备同步：WebDAV

Kazumi 的同步不走官方账号体系（它没有账号），走的是 **WebDAV**——你自己填一个 WebDAV 服务器（Nextcloud、ownCloud 或任何兼容 WebDAV 的存储都行）。设置项在偏好设置的 WebDAV 同步一节：

| 设置项 | 说明 |
| --- | --- |
| 连接你的云盘 | 填服务器地址、用户名、密码或应用授权码 |
| 启用 WebDAV | 总开关，**默认关闭** |
| 观看记录 | 同步播放进度与历史记录，**默认关闭** |
| 收藏 | 在收藏页同步所有追番分类 |
| 弹幕屏蔽词 | 同步你设置的弹幕屏蔽词 |

用法：两台设备填**同一个 WebDAV 服务器与账号**，把三个同步开关打开，进度和收藏就会往同一份数据上合并。换新手机时也是这条路——先在旧机开同步、新机登录同一个 WebDAV，数据就接过来了。

另外偏好设置里还有一个 **Bangumi 同步**（修改追番状态时同步到 Bangumi），默认关闭，用 Bangumi 记录的人再开。

## 六、外观与顺手的小设置

电脑端（以及部分安卓端）在 `我的` → 外观设置 里可以调深色模式（默认跟随系统）、配色方案、动态配色（仅安卓 12 及以上与桌面平台）、OLED 优化（深色模式下纯黑背景，省 OLED 屏的电）。这些纯属个人偏好，按需开即可。
