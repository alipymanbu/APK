## 一、规则是什么，为什么没有它 Kazumi 就是空壳

Kazumi 自己不存任何视频。你搜番、出列表、拿到播放页，这一整条链路是靠「规则」驱动的：一条规则负责**按关键词返回作品列表**，再**按你选中的作品返回播放线路和剧集页面**，视频地址的提取由 Kazumi 内部完成。

所以「搜不到」「播不了」这类问题，绝大多数不是软件坏了，而是规则失效或缺规则。反过来，某个资源站改版导致看不了，你换一条规则就能恢复，**不需要等软件更新**——这是把内容源做成规则的意义。

## 二、规则管理在哪，怎么导入

入口：`我的` → `规则设置`（规则管理界面）。软件安装时自带了部分规则，在这个列表里能直接看到。

点右上角的 `+`（添加规则），有四种添加方式：

| 方式 | 什么时候用 |
| --- | --- |
| 从规则仓库添加 | 最常用。规则仓库建在 GitHub 上，通过 raw 直链拉取，列表里选中一条点安装即可 |
| 从剪贴板添加 | 别人发给你一段规则文本，复制后直接粘贴导入 |
| 从 JSON 文件添加 | 手上有 `.json` 规则文件（比如网盘里、论坛里下到的） |
| 新建规则 | 自己写规则，见 [XPath规则编写教程.md](XPath规则编写教程.md) |

官方规则托管仓库是 [github.com/Predidit/KazumiRules](https://github.com/Predidit/KazumiRules)——「从规则仓库添加」列出的就是它的内容，客户端会自己拉取，你只管挑、只管装，不用关心 raw 地址。

导入完成后，规则出现在列表里，启用它就能在搜索和播放时用上。

## 三、规则失效了怎么办

规则对接的是外部资源站，**站点改版、换域名、加防护都会让规则失效**，表现为搜索无结果、列表空白或播放解析失败。处理思路按成本从低到高：

1. **换线路**：能搜到但这条线路播不了，先在详情页/播放页切换其他线路试试——一条规则往往对应多个播放线路。
2. **换规则**：多导入几条覆盖同类站点的规则，哪条活着用哪条。规则可以并存，也可以随时停用。
3. **更新规则**：从规则仓库重新拉一次同名规则，覆盖旧版。
4. 换了规则还是搜不到，才轮到排查软件本身，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

日常建议：不要只留一条规则。规则失效是常态，手里有备用规则，出问题就是一次点击的事。

## 四、想自己写规则，先知道这几件事

Kazumi 的规则有两种类型，**搜索和选集可以各自独立选类型**，同一条规则里可以混用（比如 XPath 搜索 + API 选集）：

- **XPath 规则**：请求网页 HTML，用 XPath 定位搜索结果、播放线路和剧集链接，适合服务端直接输出完整 HTML 的传统站点；
- **API 规则**：直接请求站点的 JSON 接口，用 JSONPath 提取信息，适合前端靠接口加载内容的站点。

新手起步的几条硬约束（来自官方规则开发文档的口径）：

- XPath 选择器**只支持以 `//` 开头的写法**，其他开头的表达式当前不支持——自定义规则检索不了，多半是这里写错了；
- 搜索地址里关键词位置替换成 `@keyword`，Kazumi 执行搜索时会替你编码填入；
- 规则字段就几个：`Name`、`Version`、`BaseURL`、`SearchURL`、`SearchList`、`SearchName`、`SearchResult`、`ChapterRoads`、`ChapterResult`，照着官方示例规则抄一遍最快；
- 规则写完发现**能搜到但播不了**：试着关掉这条规则的「使用内置播放器」选项，改用 webview 播放可以提高兼容性；内置播放器能用时建议开着，弹幕和流畅度都更好。

字段逐个怎么填、开发者工具怎么取选择器、写完怎么调试，完整的动手步骤在 [XPath规则编写教程.md](XPath规则编写教程.md)。官方也有规则开发教程与示例（[kazumi.app 的规则开发文档](https://kazumi.app/docs/rules/introduce-rules)），写好的规则可以提交到官方规则仓库分享，是否留你的 ID 自己决定。
