## 二、安装包从哪拿

按省事程度排序，你挑一种：

1. **夸克网盘**：用本篇头部的 [Kazumi 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8521d759d695) 转存后直接下载，适合国内网络直连 GitHub 不稳的情况。网盘里的版本是上表那份 2.2.7。
2. **官方下载页**：[kazumi.app/download](https://kazumi.app/download) 选择 Android 平台，页面给出当前发布版本的 APK 直链；下载慢时页面提供镜像切换（镜像同步可能晚于 GitHub，版本会滞后一点）。
3. **GitHub Releases**：[github.com/Predidit/Kazumi/releases](https://github.com/Predidit/Kazumi/releases) 是全部历史版本的权威存档，页面上写的版本号以官方当时显示为准。
4. **F-Droid**：[f-droid.org/packages/com.predidit.kazumi](https://f-droid.org/packages/com.predidit.kazumi)，走 F-Droid 仓库更新，适合本来就用 F-Droid 的人。

四条渠道拿到的都是同一个包名 `com.predidit.kazumi` 的应用，互相覆盖安装不会变成两个应用。

## 三、安装步骤

1. 下载 APK 文件到手机（浏览器下载或网盘客户端下载均可）。
2. 在文件管理器里点这个 APK，系统会弹「不允许安装来自此来源的应用」——这是安卓对未知来源应用的默认拦截。
3. 按提示进入该来源的授权开关（不同品牌手机叫「安装未知应用」或「允许来自此来源的安装」），对你的浏览器或文件管理器开启授权。
4. 返回继续安装，按系统提示允许安装完成。
5. 装完打开，包名可用来核对装的是不是同一个应用：设置 → 应用 → Kazumi → 显示 `com.predidit.kazumi`。

如果安装时提示「解析错误」或「应用未安装」，通常是下载的包不完整，重新下载一次；判断文件是否下全可以用 MD5 对比（上表那一串），不一致就说明文件在传输中损坏了。

## 四、第一次打开要做的事

装好后你会发现，Kazumi **本身不带任何视频内容**——你搜到的每一部番都来自「规则」对接的资源站。所以首次启动后的第一件事是确认规则可用：

1. 打开应用，进入 `我的` → `规则设置`（即规则管理界面）；
2. 看列表里有没有自带规则，没有就按 [规则导入与视频源管理.md](规则导入与视频源管理.md) 导入一条；
3. 回到主页左上角放大镜搜一部番名，能出结果就说明链路通了。

搜索有结果但播放出问题，属于规则或线路层面的事，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、关于版本更新

Kazumi 的版本号按 release 递增（如 2.2.7、2.3.x），官方发布节奏不定，**具体当前最新版以 [官方下载页](https://kazumi.app/download) 或 GitHub Releases 当时显示为准**。应用内有在线更新功能；你也可以随时回到 Kazumi 安装文件资源或官方渠道手动覆盖安装，数据（追番、历史）会保留。
