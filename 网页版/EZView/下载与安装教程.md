## 一、先确认你要装的是哪一个 EZView

EZView 是浙江宇视科技（Zhejiang Uniview Technologies）推出的手机监控客户端，定位是中大型监控场景的「专业版」移动应用，需要配合宇视的摄像头（IPC）、录像机（NVR）或视频管理系统（VMS）使用——它不能单独当摄像头用，也不接入其他品牌的监控设备。

搜索时注意两点：

- 应用商店里搜 `EZView` 会出来不少同名或相似名字的应用，认准开发者显示为 **Zhejiang Uniview Technologies Co., Ltd.** 的那个（国际市场商店列表有的地区显示为 **EZView UNV**）。
- 宇视自己还有面向家庭、小微店铺的简化版应用（界面和功能定位不同）。如果你手头是多路数的商超、连锁店、厂区设备，用 EZView 这类专业版；如果只是家里一两台摄像头，先确认设备说明书推荐的是哪一款，别装混。

## 二、官方下载渠道（四种，任选其一）

官方手册列了四种获取方式：

| 渠道 | 操作 | 适合谁 |
| --- | --- | --- |
| 应用商店 | Google Play（安卓）/ App Store（iOS）搜 `EZView` | 手机能正常访问商店的人 |
| 设备机身二维码 | 扫描设备机身贴纸上的二维码 | 手边就有宇视设备 |
| 设备 Web 管理界面 | 登录设备网页管理界面，进 `Setup > Network > EZCloud`，扫页面上的二维码 | 设备已联网、能开管理页 |
| 官方云平台站点 | 国际版 `https://global.ezcloud.uniview.com`（国内为宇视云 `https://ezcloud.uniview.com`），站内有应用下载入口 | 想从官方网页直接拿 |

建议用 Wi-Fi 环境下载，安装包几十 MB，走流量容易超套餐。商店里能直接装的就走商店，后面升级也方便。

## 三、网盘里这一版的事实信息（安卓 APK）

如果手机上没法用 Google Play（比如安卓电视盒、无服务商店的国产手机），可以从 [EZView 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5e1d01f994f5) 转存这一版 APK。它和你搜到的官方最新版可能不是同一个版本号，以下是这一版包的真实参数：

| 项目 | 值 |
| --- | --- |
| 版本号 | 2.59.5 |
| 包名 | `com.uniview.app.smb.phone.en.ezview` |
| 安装包大小 | 54.89 MB |
| MD5 | `C878C23160DCAAE8451B5E666C91E2DA` |
| 系统要求 | 安卓 5.2 及以上（以应用商店当时标示为准） |
| 信息核对日期 | 2026-09-24 |

转存后建议核对一下 MD5：手机文件管理器大多带「文件校验」功能，电脑上可以用 `certutil -hashfile 文件名.apk MD5`（Windows 自带命令）生成比对，两者一致说明文件没在传输中损坏。

安装时系统会提示「允许安装未知来源应用」，按手机提示对文件管理器或浏览器放行一次即可，装完可以关回去。

## 四、首次启动会经过哪些步骤

按官方手册与实际安装流程，第一次打开 EZView 会依次遇到：

1. **权限申请**：定位权限（安卓扫描同一 Wi-Fi 下的设备需要它）、存储/媒体权限（保存截图和录像片段）、通知权限（接收告警推送）。想清楚再选——拒绝定位会影响「自动搜索局域网设备」这一步。
2. **隐私政策**：需要点同意才能继续使用。
3. **新手引导页**：左右翻页看功能简介，点「开始使用」进入。
4. **登录页**：已有账号直接登录；没有就注册（见[云账号注册与设备添加.md](云账号注册与设备添加.md)）。不注册也有办法用，但功能受限，同样是那篇里讲。密码忘了不用重装，走找回流程（见[密码找回与重置方法.md](密码找回与重置方法.md)）。

进到主界面后，下一步就是把你的摄像头/录像机加进来。

## 五、装不上时的几个常见原因

- **系统版本太低**：这一版要求安卓 5.2 以上，老手机先在「设置 > 关于手机」里确认系统版本。
- **安装包损坏**：下载中断的包装到一半会报「解析失败」，用第三节的 MD5 校验核对，不对就重新下载。
- **商店区域不匹配**：应用商店按区域上架，搜不到时换个官方渠道（第二节表格里的后三种）。
- **和同类应用装混**：装之前再核对一次开发者名称，宇视旗下应用不止一款，卸错了会白折腾一遍账号。
