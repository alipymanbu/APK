## 一、看实况：从设备列表到多画面

设备列表里点一下设备就能开播实况。几个你会实际用到的控制：

- **分屏数量**：1 / 4 / 6 / 9 / 12 / 16 宫格切换。路数多的项目用大分屏总览，发现异常再点进单画面细看。
- **画质切换**：高清 / 标清 / 流畅三档（对应主码流 / 子码流 / 第三码流）。手机流量或信号差时切到流畅档，画面糊但不断流；回办公室看细节再切回高清。
- **手势操作**：双指缩放画面做数字放大（变倍）；鱼眼摄像头支持展开矫正。
- **截图与录像**：播放中一键截屏或录屏，文件存在手机相册/应用内文件区，随时点开回看。
- **收藏（自定义画面）**：把当前的画面布局、选中的摄像机和窗格位置存成一个收藏，下次一键还原这套布局——门店固定几个重点机位时特别省事。
- **走廊模式**：竖长画面的通道可以以竖幅显示，充分利用手机竖屏。

## 二、云台控制与双向语音

带云台的球机可以在实况画面里直接控制：

- 上下左右转动、聚焦、变倍、调预置位，都是手势操作（具体哪些手势可用，取决于你那台摄像头本身支持什么，App 只是入口）。

双向语音（拿手机跟摄像头那头喊话）：

- 对 **IPC**（含接在 NVR、VMS 下的摄像头）和 **NVR** 都可以开语音对讲。
- 对 NVR 开对讲的操作和 IPC 不一样：**长按对讲按钮，从列表里选中 NVR**；结束同样是长按再选一次。找不到入口多半是没按「长按」这个姿势。
- 声音能不能用，同样取决于设备端硬件，App 侧无法补足。

## 三、回放：找录像、翻录像

回放入口在实况界面切换。找一段录像的常规路径：

1. **选通道与日期**：按设备和时间检索；日历上能标出哪些天有录像（这一形式依赖新协议，见第五节）。
2. **拖时间轴**：按住时间轴拖动定位；双指捏合可以缩放时间轴刻度，先拉远看全天、再放大到具体几分钟。
3. **快速定位事件**：支持把一段录像切成 4 宫格或 9 宫格同屏播，一屏顶多份时间，翻事故前后几小时的内容时比拖时间轴快得多。
4. **智能回放**：对有智能事件的通道，可以只跳着播事件片段。

倍速与通道数有两条硬限制，用之前知道能省不少疑惑：

| 限制 | 规则 |
| --- | --- |
| 倍速 | 1/4x、1/2x、1x、2x、4x；但**直连添加的 IPC**（没走 NVR/VMS）只有 1x、2x、4x |
| 同步回放通道 | 最多 4 通道同时回放；画面可一键在实况和回放间切换 |

录像存在摄像头/录像机本地的 SD 卡或硬盘里，App 回放的就是这些录像；IPC 本身插了 SD 卡的，也能在 App 里直接回放卡里的录像（见第五节的协议前提）。

## 四、播放中的三个常见故障

- **看一会儿就自动停**：进 `Me > General`（我的 > 通用），把「自动暂停视频（Pause Video Automatically）」关掉。这个开关的本意是省流量，挂机盯画面的人要关它。
- **进度条卡在 0% / 19% / 95% 然后报错「unexpected error」**：这是官方排障文档专门列的故障，按这个顺序处理——① 在设备列表点开该设备 > Edit（编辑），把「流媒体协议（Streaming Media Protocol）」在 Protocol 2 / 3 之间对调后保存；② 完全退出 App 重开，设备页下拉刷新；③ 仍不行，把**设备端**的 MTU 值改成 576 再试。设备显示离线的，先按[云账号注册与设备添加.md](云账号注册与设备添加.md)第四节把设备弄上线。
- **导出录像时提示「视频压缩格式不支持导出」**：H.265 编码的录像在 iPhone 上（不分机型和系统版本）无法导出到相册，一部分安卓机同样如此。遇到这个提示，录像没丢，在 App 内的图片视频区仍然能看。
- **画面转圈连不上**：先确认设备 EZCloud 在线（见[云账号注册与设备添加.md](云账号注册与设备添加.md)第四节），再切一下画质档位——高清码流对上行带宽要求高，带宽不够时设备端出不去画面。

## 五、Protocol 2 / Protocol 3 是什么，影响哪些功能

设置里可能见到「流媒体协议 Protocol 2 / Protocol 3」的选项，它对应 App 与设备通信的两代协议（SDK2 / SDK3）。部分功能**只在 Protocol 3 下可用**：

- IPC 本地 SD 卡录像的回放
- 远程配置设备
- 本地录像带声音
- 回放里告警录像的红色标记
- 回放的日历检索（日期上的蓝点）
- 鱼眼画面

老设备连不上或功能缺项时，把协议切到 Protocol 3 试试（切换入口就在设备编辑页，见第四节的卡进度条故障）；反过来，个别老型号在新协议下异常，切回 Protocol 2 是常用的绕法。

实况和回放之外，让设备主动找你的能力是告警推送，转到[告警推送与远程配置.md](告警推送与远程配置.md)；还没装应用的，从[下载与安装教程.md](下载与安装教程.md)开始。
