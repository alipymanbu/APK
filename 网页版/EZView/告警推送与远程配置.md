## 一、把告警推送开起来：三处都要通

从设备到手机通知栏是一条链，断在任何一环都收不到推送：

1. **App 内按设备开启**：菜单 > 告警通知（Alarm Notifications）> 允许通知（Allow Notifications），勾选要接收告警的设备。新版可以同步配置到云端，换手机不用重新设。
2. **手机系统层面放行**：安卓/iOS 的系统设置里，EZView 的通知权限必须是开的。系统层被关了，App 内开一百次也没用。
3. **别让系统把后台杀了**：不少安卓系统的省电策略/电池优化会在后台杀掉 EZView 进程，进程不在推送就到不了——在系统设置里允许它后台运行或自启动；iPhone 则检查没开「专注模式 / 勿扰模式」。装了手机管家的，确认 EZView 没被拦截。

还有一条容易被忽略的**硬性范围**：只有**云端设备**和**免注册添加**的设备支持告警推送到手机；用 IP/域名等方式直连的**本地设备不推送**。本地设备不是收不到告警——在 App 的告警页面里照样有记录，只是不会主动弹到手机通知栏。要弹窗，就把设备绑到云账号上。

## 二、告警列表：一条告警能带出什么

告警页不只是消息列表：

- 点开一条告警，能直接跳到**关联的实况画面、告警录像和截图**（部分告警类型不支持联动，以实际设备为准）。
- 按**设备、告警类型、时间**三个维度筛选，设备多了以后靠它找。
- 支持**分享、删除、确认处理**，多人值守的场景可以用「确认」标记谁处理过了。
- 高级设置里能按**通道、时间段、告警类型**细分推送规则，比如只推夜里的移动侦测。

## 三、「收到的推送比告警少」的三种解释

对不上数时，先对以下三条，多数疑问就解了：

| 现象 | 原因 |
| --- | --- |
| App 内告警数 > 手机收到的推送数 | App 列表统计**所有设备**的事件；手机弹窗只推云端设备和免注册设备（见第一节） |
| 告警通知页的设备 < 设备列表的设备 | 从未联网上线的云设备不出现在告警页 |
| 提示「无法为更多低版本设备开启告警通知」 | 不支持告警云存储的低版本设备 + 本地设备，上限共 **64 台**；解法是升级设备固件，或关掉一些不重要设备的推送 |

## 四、人不在现场，手机上能改设备什么

按官方规格书口径，手机上可远程配置的设备参数分三类：

| 类别 | 可改的项 |
| --- | --- |
| 图像与叠加 | 时间、图像（OSD 字符叠加、补光/照明亮度） |
| 侦测与联动 | 移动侦测、人体检测、警报音、自动跟踪、PTZ 校正 |
| 录像与存储 | 录像计划、SD 卡管理 |

两点提醒：

- 实际能改到哪一档，还取决于设备自身能力——同一项设置在部分型号上会置灰或缺席，以你设备的实际菜单为准；PTZ 校正这类项也只有支持的机型才有入口。
- 这些都是设备端设置的远程入口，改动的效果和在设备本地菜单/Web 管理界面里改完全等同，所以改之前想清楚影响范围。

思路：**侦测类规则（移动侦测、人体检测、录像计划）决定了「什么时候产生告警」，第一节的推送链路决定了「告警怎么到你手机」**。告警不响时，两头都要查——先看设备端有没有配置侦测，再看推送链路。

## 五、Protocol 2 / Protocol 3 与远程配置的关系

远程配置属于依赖新协议（Protocol 3 / SDK3）的功能之一，老设备连不上或改不了参数时，先在 App 里把流媒体协议切到 Protocol 3 再试（协议说明与受影响功能清单见[实况预览与录像回放.md](实况预览与录像回放.md)第五节）。

## 六、不用了想注销账号

菜单 > 云账号（Cloud Account）> 注销账号（Cancel Account）。注销是不可逆操作，账号下的设备绑定关系一并失效；设备本体不受影响，可以用其他账号重新绑定。

设备端告警规则（移动侦测、录像计划）的细节在各设备的官方手册里，App 只是远程入口；日常画面操作回到[实况预览与录像回放.md](实况预览与录像回放.md)，账号与绑定问题见[云账号注册与设备添加.md](云账号注册与设备添加.md)。
