# 常见问题与故障排查

> 手机端连不上电脑、列表空的、推送不来、商店装不上——按现象逐条排查。

## 一、App 打开了但任务列表是空的

按命中率排序：

1. **账号不一致**：手机和电脑端登录的不是同一个账号，退出后用同一账号重登，见[手机登录与消息提醒设置.md](手机登录与消息提醒设置.md)。
2. **产品系列装混了**：电脑上是 Qoder 国际版，手机装的却是 Qoder CN Mobile（或反过来）。两套账号、任务、数据互不相通，看包名区分，见[下载与安装教程.md](下载与安装教程.md)。
3. **电脑端没开远程监听**：CLI 会话里要执行过 `/remote-control`、守护模式要跑着 `qodercn remote-control`，没开的话手机自然搜不到会话。
4. **电脑睡眠 / 关机 / 断网**：远程控制模式下电脑必须处于活跃状态，先确认电脑那头还活着。

## 二、扫码后一直连不上

- 手机和电脑都确认能上公网；公司网络环境下先切手机流量对比测试，能区分是网络还是服务的问题；
- 扫码得到的 URL 可以复制到浏览器打开，效果与相机扫码一致，扫码识别失败时用这条路；
- 电脑侧连接状态可用 `/remote-control status` 查看，状态异常就在会话里 `/remote-control stop` 后重新 `/remote-control` 开一次；
- 电脑端网络需要代理时，代理配置在电脑侧（配置文件改完要结束进程重启才生效），手机端只受自身网络影响。

## 三、任务卡住不动，也不推进

多数不是崩溃，是**它在等你**：

- 状态显示等待你确认 → 去会话里点批准 / 拒绝；
- 它抛了个问题给你 → 回一句它才能继续；
- 手机没收到提醒 → 按[手机登录与消息提醒设置.md](手机登录与消息提醒设置.md) 查通知权限与后台限制。

若确认不是在等你，且长时间毫无输出，电脑端 CLI 可直接在会话里继续下达指令；远程链路本身断了就重新扫码连接一次。

## 四、审批点了没反应 / 页面停在旧状态

先下拉刷新会话列表，再退出会话重进。仍然停在旧状态时，说明手机与电脑的同步断了（电脑侧网络波动、进程重启都会造成），到电脑上看 CLI 的实际状态，需要时重新执行 `/remote-control` 建立连接。改动内容以电脑上实际落地的文件为准，手机端只是查看入口。

## 五、应用商店搜不到 / 装不上

- **搜不到**：确认华为账号等应用商店账号的国家地区是中国大陆；设备系统版本过低、32 位机型也可能被商店直接隐藏；
- **提示不适配或安装失败**：换 64 位机型，或改走 APK 直链 / 网盘里的安装包手动安装（需开「允许安装未知应用」）；
- **商店迟迟没有你的机型**：用 H5 版 `https://qoder.cn/m` 顶上，功能覆盖日常跟进。

## 六、云端任务提交后没反应

1. 确认 New Task 页面的环境确实切到了 `Cloud`（停在本地环境时，任务在等你电脑上线）；
2. GitHub 账号是否已关联，目标仓库是否在授权列表里——不在就点 **Manage repository access** 去仓库里装 Qoder AI App；
3. 分支选对没有，选错分支改动会落到别处；
4. 会话列表里云端任务和本地任务并排显示，别只盯着原来的本地会话找，详见[云端任务与GitHub仓库绑定.md](云端任务与GitHub仓库绑定.md)。

## 七、升级与版本相关

应用内会提示更新，升级后偶发的登录态丢失，退出重登即可恢复。本地手装的旧版本（如 `0.1.18`）功能上可能缺少后续新增的入口，建议升到官方当前版本；涉及版本号的地方一律以官方页面当时显示为准。
