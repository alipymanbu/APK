# Whack 耗电快与后台收不到消息怎么办

> 本篇只解决两件事：Whack 后台被系统杀掉导致收不到消息，以及它在后台耗电偏快。

## 一、先判断是哪一种毛病

群聊类应用的这两件事是**同一套系统设置**的两面 —— 后台被限制，消息就不来；后台不限制，耗电就上去。先确认现象：

| 现象 | 大概率原因 |
| --- | --- |
| 锁屏后收不到新消息提醒，亮屏打开才有 | 后台被杀 / 通知权限没给 / 省电策略限制 |
| 一直在响但耗电明显变快 | 后台常驻 + 未做省电设置，或后台自启动被放开过度 |
| 时好时坏 | 系统省电策略在「清理」与「放行」之间来回，需固定白名单 |

设置路径按你的手机品牌对号入座（路径随系统版本变化，找不到就用设置里的搜索框搜关键词）。

## 二、先把基础项打开

1. 系统设置 → 应用 → Whack → 通知，全部允许，并打开需要的提醒类型；
2. 系统设置 → 应用 → Whack → 权限，确认通知、后台运行类权限没被禁；
3. App 内再确认消息提醒开关没关（群免打扰、频道免打扰会单独屏蔽）。

这三步没做完，后面的品牌设置做了也白做。

## 三、各品牌怎么放行后台

**华为 / 荣耀（HarmonyOS 4.X 及以下）** —— 华为官方支持页给的做法：

- 多任务界面下拉 Whack 卡片**加锁**，避免被一键清理清掉；
- 设置 → 搜索「应用启动管理」→ 关掉 Whack 的自动管理 → 勾选**允许后台活动**；
- 设置 → 搜索「电池优化」→ 对 Whack 设为**不允许**；
- 关闭省电模式；需要「休眠时始终保持网络连接」时在 设置 → 电池 → 更多电池设置 里打开。

HarmonyOS 5 及以上后台策略不同，按官方支持页对应机型的说明操作。

**小米 / Redmi（MIUI）**：设置 → 电池 → 应用智能省电 → Whack → 选**无限制**；多任务界面对卡片加锁防清理；消息收不到再检查 设置 → 通知 里是否放行。

**OPPO / realme（ColorOS）**：设置 → 电池 → 耗电保护（或「自定义耗电保护」）→ Whack → 关闭后台冻结与自动优化，改为允许后台运行。

**vivo / iQOO（Funtouch / OriginOS）**：设置 → 电池 → 后台高耗电 → 打开 Whack 开关；多任务界面对卡片加锁。

**通用原生安卓**：设置 → 电池 → 电池优化 → Whack 设为「不允许」；再在设置里关掉会强制清后台的第三方管家类工具。

## 四、耗电偏快怎么压

放行后台的代价是耗电，两边这样平衡：

- 只给 Whack 放行，别给所有应用放行 —— 后台常驻的应用越多，待机耗电越明显；
- 关掉系统的「省电模式 / 智能省电」对它的激进限制后，改用**定向白名单**，比全局放开更可控；
- 不用的时候从多任务里清掉它（加锁的卡片记得先解锁），或直接退出登录长开的场景；
- 第三方「加速清理」类工具别装，这类工具靠频繁唤醒自己来「清别人」，反而更耗电；
- 系统的「自适应电池 / 智能省电」会按使用频率自动限制低频应用 —— 你天天用它就不会被降级，偶尔才打开的账号才会被限。

## 五、还是收不到消息时

按顺序再排一遍：基础三项（第二节）是否都做了 → 品牌白名单是否真生效（改完重启一次再试）→ 是否被群免打扰或频道免打扰单独屏蔽 → 网络本身通不通。都排除了，再到 [常见问题与故障排查.md](常见问题与故障排查.md) 查其他可能（版本、账号、安装包）。
