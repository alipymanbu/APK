## 一、Whack 的社群是什么结构

Whack 是给游戏玩家用的群聊空间，一个社群相当于一个「主群」，里面还能再分频道（群内群分组）。你可以按游戏类型开垂直圈子 —— MOBA、FPS、RPG 各一圈；也可以只建一个三五好友的私密开黑群。粒度自己定：百人公会要指挥频道、后勤频道分开，小群一个频道就够。

官方给的典型用法是这几类：

- **游戏公会**：分指挥、后勤等频道，靠机器人发公告、管成员；
- **开黑小队**：私密社群，自定义语音房间权限，方便快速组队；
- **兴趣圈子**：用标签聚合同好，比如独立游戏、怀旧经典；
- **攻略社群**：由机器人整理问答，沉淀攻略。

## 二、创建一个社群

1. 登录后在首页找创建入口，按流程填社群名称、简介等信息。
2. 按官方隐私政策，**创建社群需要实名认证**：填姓名、身份证号，再用摄像头做一次人脸核对。这步只在创建时触发，浏览和发言不需要。
3. 建好后可继续加频道（分组）、设房间权限、选入群门槛与管理规则。

版本不同创建流程略有差异 —— 官方在 1.4.20 版优化过创建新社区的交互，你手上若是最新的包，看到的步骤可能更少，照屏幕提示走即可。

## 三、频道分组与权限怎么设

建好主群后按需要拆频道：公会类通常拆「指挥」「后勤」「招募」「灌水」；小群可以不分。每个频道可单独设权限，比如：

- 谁能发言、谁只能看；
- 语音房间的进入与说话权限；
- 入群门槛（申请即入 / 需审批 / 需邀请码）与管理规则。

这些设置的目的就是让不同频道承担不同职责，避免所有消息挤在一个屏里。具体每个开关在哪个菜单，各版本界面有差别，以你装的这版为准。

## 四、把人拉进来

三种常见方式：

1. **群二维码分享**：在社群里生成二维码或分享卡片发给对方，对方扫码即申请入群（官方 1.5.20 版优化过群二维码分享）。
2. **邀请码**：把邀请码发给对方，对方打开 App 时会自动识别并进群 —— 机制见 [注册登录与账号安全.md](注册登录与账号安全.md) 第五节。
3. **搜索加入**：对方在搜索页输入社群名称或社群 ID 找到你这个群，提交加入。

## 五、日常管理有哪些抓手

作为群主或管理员，你手上主要有这些手段：

| 手段 | 用途 |
| --- | --- |
| 置顶标签 | 把重要频道或会话钉在社群列表顶部（1.4.21 起） |
| 撤回他人消息 | 群主/管理员可撤回成员消息（1.5.20 起） |
| 移除成员 | 群内超管可把人移出社群（1.5.20 起） |
| 禁言、欢迎语、公告 | 交给机器人自动做，见 [群内AI机器人使用指南.md](群内AI机器人使用指南.md) |
| 潜水统计 | 看谁长期不发言（1.5.20 起优化） |

只有部分身份能执行这些操作，权限不够时对应按钮不会出现 —— 先确认自己是群主还是管理员。

## 六、社群内容怎么玩

社群之外还有内容侧：探索页里能看到群动态，个人主页可展示头像、签名、玩过的游戏与作品，支持发动态、文章、视频，以及点赞、评论、收藏、关注。想先感受社区氛围再决定建不建群，可以从搜索页找感兴趣的内容开始。
