## 一、装不上或装完打不开

| 现象 | 先查这几步 |
| --- | --- |
| 点安装包没反应 / 提示禁止安装 | 到「安装未知应用」里给对应来源开允许，见 [下载与安装教程.md](下载与安装教程.md) 第三节 |
| 安装时解析错误 | 安装包没下全，重新下载；下完可核对 MD5 是否为 `373AC70F9AE1BED212B03A32C7C68114` |
| 提示与已有应用冲突 | 手机上可能装着同包名的另一个版本，先卸载再装；包名应为 `app.group.whack` |
| 打开即闪退 | 确认系统在安卓 5.2 以上；老机型可先清一次应用缓存再打开 |
| 覆盖升级后异常 | 先备份需要的聊天内容，再卸载重装（重装后需重新登录） |

## 二、收不到验证码 / 登录不上

按顺序查，查到哪步解决就停：

1. 手机号有没有输错、区号对不对；
2. 手机本身能不能收到别的短信 —— 收不到就是卡或停机问题，与 App 无关；
3. 短信是不是被拦截软件收走了，去信息 App 的「拦截/垃圾箱」里翻；
4. 是否短时间内反复点「获取验证码」触发限流 —— 等一段时间再试，别连点；
5. 换网络环境试试（Wi-Fi 切流量），有时是当前网络发不出请求；
6. 改用第三方账号登录兜底，见 [注册登录与账号安全.md](注册登录与账号安全.md) 第三节。

## 三、通知收不到

新消息没提醒，九成是权限没给：

1. 系统设置 → 应用 → Whack → 通知，允许通知并打开需要的提醒类型；
2. 电池优化里别把它设成「严格限制后台」，否则消息推送会被系统掐掉；
3. App 内再确认一次消息提醒开关没被关。

## 四、剪贴板 / 邀请码不生效

复制了邀请码打开 App 却没进群：先看系统有没有禁止 Whack 读取剪贴板；关掉了就手动在 App 内填邀请码。机制说明见 [注册登录与账号安全.md](注册登录与账号安全.md) 第五节。

## 五、机器人点了没反应

多半不是故障，按这三层排：自己是不是群主/管理员（权限不够指令不生效）；指令格式是否按当前菜单写的；该功能是否在你这个版本里存在 —— 各功能对应的版本见 [群内AI机器人使用指南.md](群内AI机器人使用指南.md) 第六节，1.2.8 上没有的能力要换新包。

## 六、版本对不上怎么办

同一个名字在不同商店是不同版本：官方在应用宝、小米等商店持续发新版，App Store 上也有 iOS 版，各处显示的版本号与体积都不一样（以各页面当时显示为准）。判断手上的包是不是你要的，只看两处 —— 系统「应用信息」里的版本号，以及包名 `app.group.whack`。想要比 1.2.8 更新的功能，就从官方渠道取对应版本，别只看文件名。
