## 一、这个包是什么版本

你手上这份安装包是 Whack 1.2.8，属于安卓端。版本、包名、体积这几项以本篇给的为准 —— 各应用商店页面上显示的是官方后来发的版本，跟这份不是同一个：

| 项目 | 值 |
| --- | --- |
| 应用名 | Whack |
| 版本 | 1.2.8 |
| 包名 | `app.group.whack` |
| 安装包大小 | 70.88M |
| MD5 | `373AC70F9AE1BED212B03A32C7C68114` |
| 系统要求 | 安卓 5.2 以上 |
| 信息记录日期 | 2026-09-23 |

包名固定不变，是判断「装的是不是同一个应用」最可靠的依据 —— 装完在系统「应用信息」里能看到，应为 `app.group.whack`。

官方后续版本在各应用商店持续更新（版本号会一直变，具体以商店页面当时显示为准）。想要最新版就去官方渠道拿；只是想先用起来，这份 1.2.8 完全可用。

## 二、从网盘拿安装包

1. 打开 [Whack 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0e0c649f0e9e)，把分享转存到自己的网盘。
2. 在网盘里找到 `Whack_v1.2.8.apk`，下载到手机本地。
3. 想核对文件没损坏，可在电脑上算一次 MD5，与上表比对，一致即为同一份文件。

转存后再下载，分享链接失效也不影响你网盘里已有的那份，这是长期可用的做法。

## 三、安装步骤

安卓对非应用商店来源的包有拦截，第一次装要先放开：

1. 用手机浏览器或网盘客户端下载 `.apk` 文件。
2. 点击文件，系统弹出「禁止安装来自此来源的应用」之类的提示时，按引导进入「安装未知应用」设置，给该来源（浏览器或网盘）打开允许。
3. 回来重新点击安装包，确认安装。
4. 装完打开，首次启动会弹用户协议与隐私政策，点同意后才能继续 —— 这两项不同意就进不去主界面。

已装过旧版本的，直接覆盖安装即可，数据一般会保留；若覆盖后提示异常，按 [常见问题与故障排查.md](常见问题与故障排查.md) 里的办法处理。

## 四、首次启动会要哪些权限

Whack 属于社区类应用，基本功能要手机号才能用。安装后首次用到对应功能时会逐个弹权限请求，拒绝不影响其他功能：

| 权限 | 用在哪 |
| --- | --- |
| 电话（读取本机号码） | 手机号一键登录，拒绝则只能手动输号码 |
| 短信 / 验证码 | 注册登录收验证码 |
| 剪贴板 | 读取邀请码，帮你直接进对应社群 |
| 相机 | 扫码、拍摄发布，创建社群的实名核对也会用到 |
| 麦克风 | 语音相关功能 |
| 存储 / 相册 | 上传图片视频、保存文件 |
| 悬浮窗 | 小窗、悬浮显示类功能 |
| 通知 | 新消息提醒 |
| 位置 | 需要位置的相关功能 |

只开你用得到的那些就行。比如不打算用手机号一键登录，可以不给电话权限；通知收不到再回头开通知权限，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、iOS 端的情况

Whack 在苹果 App Store 也有上架，iPhone 用户直接在商店搜 Whack 安装即可，不需要本篇这份安卓包。iOS 与安卓账号数据是否互通、界面是否一致，以实际登录后看到的为准，本篇不作断言。
