## 一、装之前先确认这几点

- **这是个什么应用**：Epic游戏商城是 Epic Games 自己出的游戏商城 App，手机上可以逛商城、领每周免费游戏、下载安装游戏。它的安卓版全球可用（美国制裁计划限制的地区除外）；iPhone 版只在欧盟、日本、巴西等地上架。
- **不在 Google Play 上**：这个 App 是 Epic 通过自己的官网直接分发安装包的，所以在应用商店里搜不到，需要你手动装 APK——这也是为什么安装时系统会要求你「允许安装未知应用」，属于正常流程。
- **系统版本**：官方 FAQ 标注的最低要求是 SDK 24 起（部分语言版本的页面写 Android 8 / SDK 26），推荐 SDK 34（Android 14）以上以获得更好的表现；具体以官方页面当前标注为准。
- **存储空间**：本文对应的安装包只有 18.48M，装 App 本身不占地方；真正吃空间的是你从商城里下载的游戏本体，建议再预留几 GB。
- **联网**：逛商城、领游戏、下载游戏都需要网络。
- **安装包版本**：网盘里这份是 1.0.6 版；官方页面的当前版本号会不断更新，界面与入口可能和你装到的版本有差异，以应用内实际显示为准。

## 二、从网盘获取安装包

1. 打开头部的 **epic 安装文件资源**网盘链接，把文件**转存到自己的网盘**，再从自己的网盘下载到手机。
2. 下载完成后建议核对一下文件完整性，安装包的 MD5 为：

```text
eb40e7a1c4b487b986def1bc9d6e3b44
```

在电脑上可以用系统自带命令核对（PowerShell / 命令提示符）：

```powershell
certutil -hashfile "epic_v1.0.6.apk" MD5
```

对比输出的哈希值与上面一行是否一致（大小写不敏感）。不一致说明文件下载不完整，重新下载即可。

## 三、安装步骤

1. 在手机上点开下载好的 APK 文件，系统会提示「不允许安装未知应用」，按提示进入允许页面，**允许这次安装**（不同品牌手机入口名称略有差异，一般在弹窗里直接点允许即可）。
2. 等待安装完成，点「打开」。也可以先点「完成」，稍后从桌面图标进入。
3. 你首次打开 App 时需要登录 Epic 账号，注册与登录的注意事项见 [账号登录与跨平台同步.md](账号登录与跨平台同步.md)。

**三星手机额外注意**：One UI 6.1.1 的 Galaxy 机型默认开启 Auto Blocker（自动拦截），会直接拦掉这类侧载安装。需要先关闭它：设置 → 安全和隐私 → Auto Blocker → 关闭开关（关闭前系统会要求验证身份）。装完之后你可以再把它打开。

## 四、确认装的是哪一版

epic 的包名为 `com.epicgames.portal`，可在「设置 → 应用管理 → epic → 应用信息」里核对。版本号 1.0.6 对应的安装包大小为 18.48M。

如果你想用官方页面的最新版本，直接从官方安卓安装页获取即可：[store.epicgames.com/mobile/android](https://store.epicgames.com/mobile/android)（以官方页面当时显示为准）。

## 五、装不上或打不开

按现象对号入座：提示解析失败多是下载不完整（回到第二步核对 MD5）；被系统拦截的，检查第三节里的未知来源授权和三星 Auto Blocker；装好后登录不上、白屏等问题，直接看 [常见问题与解决方法.md](常见问题与解决方法.md)。
