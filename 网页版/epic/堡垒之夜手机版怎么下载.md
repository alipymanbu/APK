## 一、先装 Epic游戏商城，游戏从商城里下

《堡垒之夜》此前多年不在 Google Play 上，官方给出的正规安装渠道就是 Epic 自家的商城：先把商城 App 装上，游戏本体再从商城内下载。官方安装指引（带 `p=fortnite` 参数的官方安装页）列出的完整流程是：

1. 安装 Epic游戏商城：下载安装包、允许安装未知应用、安装并打开（安装文件资源见文首网盘链接，逐步操作见 [下载与安装教程.md](下载与安装教程.md)）。
2. 打开商城，找到《堡垒之夜》，点下载。
3. 跟随屏幕提示完成安装。
4. 打开游戏开玩。

三星手机装商城那一步如果被拦，先关 Auto Blocker（设置 → 安全和隐私 → Auto Blocker），装完可以再开回去。

## 二、你的手机带得动吗

商城 App 本身要求不高，但《堡垒之夜》是高保真游戏，官方支持页面列出的安卓设备要求明显更高（截至检索时，以官方页面为准）：

| 项目 | 要求 |
| --- | --- |
| 系统 | 64 位 Android，Android 10.0 或更高 |
| 处理器 | ARM64 |
| 内存 | 最低 4GB RAM |
| GPU | Adreno 530 或更高；Mali-G71 MP20、Mali-G72 MP12 或更高 |

对照方法：设置 → 关于手机，看处理器型号与运行内存。GPU 型号查不到的话，直接用手机型号搜索「SoC + GPU」即可判断。达不到要求的设备，商城可能直接提示不支持。

## 三、更新与账号

- 从商城装上的游戏会像手机上其他应用一样自动更新；也可以进商城里该游戏的详情页手动更新（原来的安装按钮位置会变成更新按钮）。
- 游戏进度跟着 Epic 账号跨平台走，手机上的进度和电脑、主机是同一条，前提是登录同一个账号，见 [账号登录与跨平台同步.md](账号登录与跨平台同步.md)。
- 游戏内的 V-Bucks 等内购怎么付、有没有返利，见 [内购支付与奖励返利.md](内购支付与奖励返利.md)。
- 装不上、登录不上的通用排查，见 [常见问题与解决方法.md](常见问题与解决方法.md)。
