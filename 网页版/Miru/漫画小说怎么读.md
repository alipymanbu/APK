Miru 里漫画和小说各走一套阅读界面，与视频播放分开。这两类内容能不能看，前提是装了对应类型的扩展（manga / fikushon），装法见 [扩展怎么安装与管理.md](扩展怎么安装与管理.md)。

## 一、漫画阅读

从搜索结果点开一部漫画 → 进详情页 → 选章节 → 进阅读界面。阅读界面上常见的可调项（不同扩展给出的选项不完全一样，以你点开时看到的为准）：

| 可调项 | 说明 |
| --- | --- |
| 阅读方向 | 日式页漫是右往左翻，条漫是上下滚动，按作品形态选 |
| 翻页方式 | 单页 / 双页 / 连续滚动，看屏幕尺寸和阅读习惯 |
| 亮度 | 长时间看建议调低，不必跟着系统亮度走 |

手机竖屏看条漫，用连续滚动最省事；横屏或平板看页漫，单页 / 双页配上对应方向，更接近纸漫的读法。

## 二、小说阅读

小说的阅读界面比漫画简单。当前版本对小说的支持相对基础，像字体颜色、背景色、翻页动画这类排版自定义项并不完整 —— 这是版本现状，不是你少点了某个开关。

实际影响是：想在夜间换成深色底、或想换字体，可能做不到。官方已把这类改进放进后续计划，具体什么时候有，以版本更新说明为准。

## 三、阅读进度会记住

和视频一样，漫画看到第几话、小说读到第几章都会被记下来，下次进来接着读。进度按「作品 + 扩展」记录，换源看同一部作品时不会带过去。

## 四、能不能离线看，取决于扩展

Miru 本体不提供内容下载。某个源支不支持把章节或整本缓存在本地，是**那个扩展自己的功能**：

- 界面上有缓存 / 下载入口 → 这个源做了离线功能；
- 界面上没有 → 是该扩展没做，换一个源试试，比在设置里翻开关有效。

## 五、读不出来时的排查顺序

1. **换章节**：单章图片加载失败，多半是源站那一章的问题；
2. **换源**：同一部作品换个源打开，能出图就说明是原源的问题；
3. **换网络**：图片是逐张从源站取的，某些网络环境下图片域会被拦，切一下网络就能验证。

仍然打不开、或一直空白，见 [常见问题与排查.md](常见问题与排查.md)。
