# Miru 扩展怎么安装与管理

> 本篇讲清 Miru 为什么装完是空的、扩展从哪儿装、怎么导入别人给的链接、以及装了不生效时先看哪里。

Miru 是「壳 + 扩展」的结构：本体不带任何内容，同一个应用能看影视、漫画、小说，靠的是你装了哪几类扩展。本篇只讲扩展这一层 —— 从哪来、怎么装、怎么卸、失效了怎么办。

## 一、先理解扩展分三类

每个扩展带一个类型标记，决定了它出现在哪个板块：

| 扩展类型 | 提供什么 |
| --- | --- |
| bangumi | 影视、动画等视频内容 |
| manga | 漫画 |
| fikushon | 小说 |

装的时候不用自己判断类型，扩展自己声明了。但知道这个分类，能解释一个常见困惑：为什么装了一个源之后，只有对应的那个板块有内容，另外两个还是空的。

## 二、从官方扩展仓库装（最常用）

1. 打开 Miru，切到底部的**扩展**页；
2. 点右上角的**下载 / 仓库**图标，进入扩展仓库列表；
3. 在列表里找到要用的源，点它右侧的**安装**；
4. 装好的源进入扩展页的**已安装**列表，点它能看到该源提供的条目。

按官方说明，官方扩展仓库提供视频源，**不需要自己写任何扩展**就能直接用。仓库里有哪些源会随时增减，以界面上当时显示的清单为准。

想在装之前先看看仓库里大致有哪些源，可以直接打开官方开发文档里指向的官方仓库站点 [miru-repo.0n0.dev](https://miru-repo.0n0.dev/) 浏览。

## 三、用链接导入扩展

别人给了你一个扩展地址，或你在别处看到了一个源：

1. 进扩展页，点右上角的 **+**；
2. 选**通过链接导入 / 导入扩展**；
3. 把扩展地址粘进输入框，确认。

导入进来的扩展与从仓库装的没有区别，同样进「已安装」列表。

导入失败时，按现象对一下原因：

| 现象 | 可能原因 |
| --- | --- |
| 粘贴后提示无效 / 没反应 | 地址指向的是网页，不是扩展文件本身（扩展文件一般是 `.js`） |
| 转圈一会儿后失败 | 当前网络拿不到那个地址，先在浏览器里打开这个地址确认一下 |
| 提示装好了，但列表是空的 | 扩展声明的内容类型与你想看的板块不是一类（见第一节） |

## 四、卸载与停用

- **卸载**：在已安装列表里对某个源点卸载，之后它提供的内容就不再出现在搜索结果里；
- **停用**：只是临时不想让某个源出现在搜索里时，能在源列表里把它关掉，不必卸载（开关的具体位置以界面为准）。

不确定某个源要不要长期留着时，先停用比卸载省事 —— 卸载之后想再用还得重装一遍。

## 五、自定义扩展仓库

除官方仓库外，Miru 支持添加自定义扩展仓库：把仓库地址填进设置里，就能像官方仓库那样列出并安装其中的扩展。官方源不更新时，改用这些仓库即可。

自定义仓库的地址由提供方给出，**用之前先确认来源可靠**：扩展是能在你的设备上发网络请求的代码，装来源不明的扩展，等于把这份权限交出去。

## 六、装了扩展却用不了

按这个顺序看：

1. **是不是装错了板块**：想搜影视，却只装了漫画或小说扩展，自然搜不出来；
2. **是不是这个源本身挂了**：换一个同类源搜同一个词 —— 别的源能搜到，就说明是这个源的问题，等它更新或换源即可；
3. **看扩展的调试日志**：Miru 给扩展配了调试日志，能在扩展相关页面看到该扩展报的错，这比「点了没反应」有用得多。

装了扩展之后怎么搜、怎么切线路，见 [搜索与播放怎么用.md](搜索与播放怎么用.md)；错误提示怎么读、源反复失效怎么办，见 [常见问题与排查.md](常见问题与排查.md)。
