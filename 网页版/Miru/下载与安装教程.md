Miru 是开源的多平台媒体应用，本体不带任何内容，装完得自己加扩展源才有东西可看。本篇只解决一件事：把网盘里这份包装进设备，并确认自己装的是哪一版。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本号通常是当时的最新发布版，而网盘里这份是整理文档时核对过的版本，两者未必是同一个。本文出现的版本号、包名、体积都以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Miru |
| 版本号 | 1.8.1 |
| 包名 | `miru.miaomint` |
| 安装包体积 | 17.54 MB |
| MD5 | `F81A3F5A733BA30DD9BE789EFB54A068` |
| 开发方 | Miru Project，开源项目，许可证 AGPL-3.0 |

安装包本体在头部那条「Miru 安装文件资源（夸克网盘）」里，转存到自己网盘后下载即可。

拿到文件后想确认是不是同一个包，看两处就够 —— **体积**和 **MD5**：

- **Windows**：右键文件看属性里的「大小」；MD5 在该目录打开 PowerShell 跑 `certutil -hashfile "文件路径" MD5`，输出里那一长串就是；
- **安卓**：用文件管理器长按文件看详情里的字节数；MD5 要用带「文件校验」功能的文件管理器，或专门的校验小工具来算。

两件事先说明白：

- **版本号怎么读**。官方按 `v1.8.x` 这样的版本号逐个发布，发布页在代码仓库的 Releases 页（[github.com/miru-project/miru-app](https://github.com/miru-project/miru-app)）。当前最新是哪个数字，以该页当时显示为准。
- **同名软件不止一个**。搜索引擎里叫「Miru」的产品有好几款，认包名 `miru.miaomint` 最稳，区分方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 二、装之前要核对的两件事

**第一，设备类型。** 这是安卓应用，官方发布页同时提供 Windows 版安装包，**没有 iOS 版** —— iPhone 与 iPad 装不了。苹果设备上只能用网页版，而网页版能做的事情是受限的（官方自己也建议优先用客户端）。

**第二，CPU 架构。** 官方发布页把安卓包按 CPU 架构分开发布，共三个：

| 官方发布页的包 | 体积（字节） | 对应设备 |
| --- | --- | --- |
| `app-arm64-v8a-release.apk` | 18,393,470 | 近几年出的手机，绝大多数属于这一档 |
| `app-armeabi-v7a-release.apk` | 17,870,725 | 较老的 32 位机型 |
| `app-x86_64-release.apk` | 19,444,031 | 安卓模拟器 |

**网盘里这份对应的是 arm64-v8a** —— 它的字节数与官方 arm64 那个包完全一致，主流手机直接装即可。只有两种情况需要按架构另找包：

- 安装时提示「应用与设备不兼容 / 无法解析」→ 你的机型可能是 armeabi-v7a，到官方发布页取对应那个；
- 想装在安卓模拟器里 → 模拟器多为 x86_64，取 `app-x86_64-release.apk`。

网盘里只放了 arm64 这一个包，需要另外两种架构时，以官方发布页为准。

## 三、安卓安装步骤

1. **转存并下载**：从 [Miru 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4a0e1afd83af) 把 APK 转存到自己网盘，再下载到手机；
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关；
3. **签名冲突就先卸载**：手机里若已有同包名但签名不同的版本，安装会直接失败，先把旧的那个卸掉再装；
4. **装完先别急着搜索**：搜索为空是正常的，接下来要做的事见第五节。

## 四、Windows 安装

官方发布页给 Windows 两个包：`miru-setup-<版本>.exe`（安装版）与 `Miru-<版本>-windows.zip`（免安装压缩包）。安装版会装进系统、带开始菜单入口；免安装版解压后直接运行，整个文件夹可以拷着走。两个都能用，装不上或启动异常时可以互相换着试。

功能上不用在两个平台之间做取舍：官方给的功能清单（扩展、搜索、进度保存、TMDB 元数据）是按整个应用说的，没有分平台开两套，两端能用到的东西基本一致，差别主要在系统集成层面。中文怎么切见 [中文界面与语言设置.md](中文界面与语言设置.md)。

## 五、第一次打开先做两步

打开后界面是**英文的**，首页也是空的 —— 这两点都不是装坏了：

1. **改中文**：进设置把 Language 选成中文，位置与步骤见 [中文界面与语言设置.md](中文界面与语言设置.md)；
2. **装扩展**：Miru 本体不带内容，要先到扩展页从官方仓库装几个源，装法见 [扩展怎么安装与管理.md](扩展怎么安装与管理.md)。

这两步做完才算能正常用。

## 六、装完做一次最小验证

装好扩展后，回首页搜一个常见的片名或漫画名：能搜出结果、点开能正常播放或翻页，就说明安装、语言、扩展三件事都通了。

搜不到结果、点开报错、或者一直转圈，按 [常见问题与排查.md](常见问题与排查.md) 往下排。
