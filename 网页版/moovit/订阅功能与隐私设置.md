## 一、免费版与 Moovit+ 的边界

查路线、看实时到站、下车提醒、收藏线路、离线保存行程——这些核心功能**免费版全部可用**，订阅不订阅不影响你坐车。Moovit+ 是订阅制增强包，官方帮助中心列出的独占功能：

| 功能 | 是什么 | 不订阅的替代做法 |
| --- | --- | --- |
| 去广告 | 界面无任何广告 | 忍着，功能不受影响 |
| Live Location | 在地图上实时看所乘线路的车辆移动 | 免费版看站点到站时间与地图上的线路径 |
| Compare Routes | 多条方案同屏在地图上对比 | 逐条点开方案对比 |
| Arrival Updates | 提前推送「你的线离站还有多远」 | 免费版到站提醒在接近终点时触发 |
| Safe Ride | 每次开实时导航时自动把位置分享给紧急联系人 | 手动把行程分享给朋友 |
| Live View | 用实景全景找站点出口与方向 | 看地图步行指引 |

是否需要，按你自己的痛点决定——只是查时刻表的话用不上。

## 二、价格与购买

- 官方提供**月付**与**年付**两档，年付相对更便宜（官方口径最多省 50%）；具体金额按地区与商店而异，**以你设备上订阅页当时显示的价格为准**。
- 购买入口：应用主界面左上角菜单 → Moovit+ → 选方案 → 按商店流程确认付款。
- 所有订阅都通过应用商店（Google Play / App Store）结算，应用内不单独收钱。

## 三、查看账单、取消、恢复

**查下次扣款**：

- Google Play：Play 商店 → 头像 → 付款和订阅 → 订阅 → Moovit → 续订日期；
- iOS：设置 → 点你的名字 → 订阅 → Moovit。

**取消**（在同一个入口点「取消订阅」）：

- 取消后**当前周期内继续有效**，到期不再扣款；
- 注意：删 Moovit 账号**不会**取消订阅——商店那头必须单独取消，这是官方帮助中心明确写过的坑；
- 换了手机：进任意 Moovit+ 功能页（或菜单里的「去广告版」），在订阅页点**恢复购买**，原周期接续；
- Android ↔ iOS **不能互转**：订阅绑在你最初购买的那个商店账号上，跨平台只能原平台退订、新平台重订。

## 四、它收集什么数据

按官方隐私政策（最后更新 2024-07-01）：

- **定位**：使用期间的 GPS 定位、设备传感器数据（陀螺仪等），用于算路线与实时导航；
- **行程信息**：你规划过的起终点与出行时间；
- **账号与设备**：安装即生成的 User ID、所在都市区、设备标识等；
- 收藏、表单填写、与客服的往来邮件也属于收集范围。

这些是它提供路线与实时提醒的原料，**定位权限一关，实时导航和下车提醒同时失效**——权衡点在这里，不是可以随便关的开关。想细读原文，隐私政策在 [www.moovit.com](http://www.moovit.com) 底部 Legal 里；要求删除账号与个人信息，走帮助中心的删除请求或发信 `privacy@moovit.com`。

## 五、在系统里收紧权限

不打算长期用、又不想它一直有定位时：

1. 设置 → 应用 → Moovit → 权限 → 位置，改成「使用时允许」或「仅在使用中」，关掉后台定位；
2. 不用实时提醒时，把通知权限关掉；
3. 用完清后台。副作用明确：后台定位关了，切到后台的导航提醒可能延迟；通知关了，下车提醒收不到（排查见 [常见问题与解决方法.md](常见问题与解决方法.md) 第三节）。
