# 换手机后收藏与账号怎么恢复

> 换了手机，收藏的线路、设好的家和公司还在不在，取决于你有没有建过账号。本篇讲清楚账号建不建、换机怎么恢复。

## 一、不建账号也能用，但换机就全没了

官方条款写得很直白：**不建账号不影响使用**——查路线、看实时到站、收藏、导航全都照常，数据存在手机本地。代价是换手机、卸载重装后，本地那套收藏与设置不会自己跟过来。

建了账号，官方列出的可找回项包括你填过的**家庭地址、公司地址**等账号内信息；收藏项的找回以「同一账号重新登录」为准。判断自己属哪种：应用主界面菜单里显示你的登录状态（邮箱/社交账号或「登录」入口），显示已登录就是建过号。

## 二、建账号的方式与时机

- **方式**：在应用菜单的账号入口里，用邮箱注册，或直接授权 Facebook / Google 账号登录（三选一即可）；
- **时机**：不用等——建议装完当天就把家、公司设好并登录，别等换机前才想起来（换机前临时登录只能救回账号里已有的，本地未同步的项救不回）；
- **成本**：不收钱，也不影响功能，只是多一个登录态。

## 三、换机恢复的实操顺序

1. 旧手机上先确认登录状态：菜单里能看到账号才算数；
2. 新手机装好应用（从哪拿安装包见 [下载与安装教程.md](下载与安装教程.md)）；
3. 打开应用，用**与旧机相同的那个账号**登录——方式选错（旧机用 Google、新机用邮箱）是两套账号，什么都不会回来；
4. 登录后核对：家/公司地址、收藏的线路与站点是否出现；
5. 缺的项对照旧手机截图手动补——收藏一个线路只要几十秒，别为几条收藏折腾客服。

换了平台（安卓 → iOS 或反向）时，社交账号登录照常可用；但订阅是商店账号维度的，跨平台恢复走 [订阅功能与隐私设置.md](订阅功能与隐私设置.md) 第三节的「恢复购买」，两件事分开处理。

## 四、账号在应用里还能改什么

菜单的账号详情页里可以查看与修改已填的个人资料（姓名、邮箱等）；邮箱改了之后，收据类邮件会发到新邮箱。要求删除账号与个人数据的入口在官方帮助中心（删除流程与订阅无关，删号**不**自动取消订阅，这一点在 [订阅功能与隐私设置.md](订阅功能与隐私设置.md) 第三节）。

## 五、旧手机没了、也没建过账号

没有账号就没有可恢复的东西——官方没有任何凭设备找回收藏的通道。这种情况下只能在新手机上重建：

- 收藏的线路：搜线路号 → 进详情 → 点星标，每条半分钟；
- 家和公司：搜地址 → 结果页点星标 → 标成 Home / Work；
- 装好后按 [实时到站与线路查询怎么用.md](实时到站与线路查询怎么用.md) 第五节把常用站也收进去，一次配齐，下次换机记得先登录。
