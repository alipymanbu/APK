# 路线规划与到站提醒指南

> 去一个不熟的地方，最怕坐过站。本篇讲怎么规划出行路线、怎么开实时导航、怎么让应用到站前叫你下车。

## 一、规划一次行程

在底部「路线」标签里，填起点和终点，出结果前有四件事可以调：

1. **起点/终点**：留空一个字段 = 用你的当前位置补上；双箭头图标一键对调两端。
2. **时间**：默认「现在出发」，也可以改成指定时刻，或切到「按到达时间反推该几点走」。
3. **交通方式**：在搜索设置里勾选要算进去的交通类型（公交、地铁、火车、步行等），还能设**最大步行距离**与距离单位（公里/英里）。
4. **地址要写具体**：官方用户指南的建议是按「门牌号, 街道, 城市」的格式输入（例如 `10 Noel Road`），只写地名或商圈这种宽泛词会给出不准的结果；输入时从下拉联想里选一条，命中率最高。

起点填你常去的地方时，直接点搜索页下方的历史记录或收藏（家/公司），省一次输入。

## 二、读懂结果页

- 每条方案显示总时长、出发/到达时间、换乘次数，按你的偏好排序。
- 点开任一方案看**分段指引**：走多久到站、坐哪条线、在哪换乘、还剩几站下车。
- **更早 / 更晚**：翻同一方向的前后班次，赶时间时常用。
- 实时数据可用时，时间段以实时样式标出（与 [实时到站与线路查询怎么用.md](实时到站与线路查询怎么用.md) 里说的判断口径一致）。
- 结果页的图标依次可：在地图上看整条路线、看线路评分、把路线分享给别人、收藏这条搜索、**把指引保存下来离线看**——最后这个在没网时也能翻出完整换乘步骤。

## 三、实时导航（Live Directions）

选好方案点「出发 / Start Navigation」，进入导航模式后：

- 全程分段引导：走到哪一站、车几点来、在哪换乘、还剩几站，逐步显示在底部指引卡上；
- **左右滑动指引卡**（不是滑地图）可以看上一步或下一步；
- 应用会根据车辆位置自动推进步骤，你也可以手动点「完成」跳过当前步；
- 过程中有动态 ETA，快到站时提醒你该下车；
- 需要**定位服务全程开着**；可以切到后台继续跑，通知栏照样给提示；
- 不想被提示音打扰：点右上角的铃铛即可关掉本次导航的通知。

注意：实时导航依赖 GPS，隧道、高架下信号弱时应用会退化成按排班推进，提醒可能滞后一两站，重要下车点自己也留意站名。

## 四、下车提醒（Get Off Alert）

这是坐陌生线路时最值钱的功能：应用跟着你的位置算剩余站数，快到站推一条通知叫你准备下车，不用一路盯着屏幕。

能不能准时响，取决于三件事同时成立，缺一去 [常见问题与解决方法.md](常见问题与解决方法.md) 对症处理：

1. 定位权限已授予、系统定位开关开着；
2. 通知权限已授予；
3. 导航或行程跟踪处于进行中（设了终点并点了出发）。

## 五、行程模式（Trip Mode）

上车后不想手动盯进度，可以启用行程模式：它按你选定的目的地持续更新预计到达时间、剩余站数，并在该下车时提醒。与实时导航的区别在于轻量——不开全程分段引导，只管「何时到、何时下」。等车时也可以先开起来，让应用替你数着车还有几站到。

## 六、没网的时候

- 行程方案页的「保存」按钮可把本次指引存到本地，没信号也能翻出换乘步骤；
- 线路与地铁图支持下载 PDF 离线查看；
- 实时到站、实时导航必须有网，离线时只剩排班表数据。

## 七、与订阅功能的边界

上面所有功能**免费版都可用**。另有几个属于 Moovit+ 订阅的增强项——实时线路在地图上的追踪、多路线同屏对比、提前的到站距离推送、把行程位置共享给紧急联系人——是否需要，见 [订阅功能与隐私设置.md](订阅功能与隐私设置.md) 里的对照表。
