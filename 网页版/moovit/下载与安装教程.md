## 一、先确认是不是你要的那个应用

Moovit 的安卓包名是 `com.tranzmate`，开发商登记为 Moovit App Global Ltd（以色列公司，其最终用户许可协议里的主体名是 TranzMate Ltd.）。你在应用商店或安装包信息里看到这三项对得上，装的就是同一个应用：

| 项目 | 值 |
| --- | --- |
| 应用名 | Moovit |
| 包名 | `com.tranzmate` |
| 开发商 | Moovit App Global Ltd |

它做的事只有一类：查公交、地铁、有轨电车等公共交通的时刻与实时到站，帮你规划从 A 到 B 的乘车路线。你要是想查的是打车或自驾导航，这个应用不是干这个的。

## 三、安卓 APK 安装步骤

1. 把 APK 文件传到手机（数据线、聊天工具传输、或浏览器下载均可）。
2. 点击文件开始安装。系统若弹出「禁止安装来自此来源的应用」，是「未知来源」开关没开：按提示进入**设置 → 安全/应用安装 → 允许安装来自此来源的应用**，对你的文件管理器或浏览器单独放行，再退回继续安装。
3. 装完打开。首次启动会依次要**定位权限**和**通知权限**——这两个都建议给：
   - 不给定位，地图上的「你在哪里」与实时导航不准或不可用；
   - 不给通知，下车提醒发不出来（详见 [常见问题与解决方法.md](常见问题与解决方法.md)）。
4. 首次进入会让你选城市或直接按定位识别城市。定位不准时手动搜城市名即可。

装不上或装完打不开时，先核对 MD5 是否与上表一致（不一致说明文件在传输中损坏，重新下载），再对照 [常见问题与解决方法.md](常见问题与解决方法.md) 里的安装失败一节。

## 四、系统要求：以商店页面当时显示为准

各来源给出的最低安卓版本并不一致，别只信一家：

- Moovit 的最终用户许可协议文本写的是 Android 4.0 及以上（较早的表述）；
- 第三方商店页面随版本变化，2026-09 分别出现过「Android 7.0+」「Android 6.0+」「Android 11+ 最低」等标注。

实际能不能装，以你获取安装包的那个页面**当时显示**的系统要求为准；装失败的第一嫌疑就是系统版本过低。

## 五、版本号怎么读

Moovit 的版本号是四段式，例如本套文档对应的 `5.194.0.1785`：第一段是大版本（长期为 5），第二段随发布递增（5.194 → 5.200），后两段是内部构建号。你在各处看到的版本号格式都一样，比较新旧时从左往右逐段比即可。

## 六、更新与降级

- 从商店装的：商店里开自动更新，或在「我的应用」里手动更新。
- 从 APK 装的：再装一个更高版本的 APK 即可覆盖升级，数据通常保留；想回到旧版（比如新版在你的机型上出问题），先卸载新版再装旧版——卸载会清掉应用内的收藏与设置，重要的收藏建议先记下来。

更新后某个功能找不到入口时，应用的帮助中心 [support.moovitapp.com](https://support.moovitapp.com) 有各功能的分篇说明，界面改版后那里更新得最快。
