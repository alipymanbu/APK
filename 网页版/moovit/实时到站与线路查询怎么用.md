## 一、先认识底部三个标签

打开应用，底部有三个标签，所有查询都从这里进：

| 标签 | 你在这里能干什么 |
| --- | --- |
| 路线（Directions） | 规划从 A 到 B 的行程，看收藏与最近行程 |
| 站点（Stops） | 看你周围的站点地图，点站点看有哪些线、下一班几点到 |
| 线路（Lines） | 直接搜某路公交/地铁，看它的完整停靠站与时刻表 |

第一次用建议先点开「站点」标签：地图上橙色的点是你当前的位置（识别不准说明定位没给，见 [常见问题与解决方法.md](常见问题与解决方法.md)），站点图标点一下就能列出经过它的所有线路和下一班到站时间。

## 二、实时时间与时刻表时间是两码事

站点和线路详情里，到站时间会以不同样式显示，含义不同：

- **实时时间**：来自车辆 GPS 与用户上报，是「这辆车此刻在哪、几点真能到」。实时档按信号强弱再分红黄绿：绿=信号强而准、黄=较准、红=可能不准、红带感叹号=车辆已偏线（现行版本的官方口径）。
- **时刻表时间**：该线路没有实时数据源时，显示黑色——可能是排班表原值，也可能按这条线的历史晚点折算过。

界面颜色在不同版本里有过变化（早期版本实时用橙色、现行版另有黑档），所以以你应用里实际显示的样式为准，判断标准就一条：**有实时源才是实时，没有就只是推算**。各颜色具体怎么信、时间显示离谱怎么查，单独拆在 [到站时间颜色与准确度怎么看.md](到站时间颜色与准确度怎么看.md) 里。你的城市有实时数据、还是只有排班表，取决于当地运营方是否提供数据，同一个应用在不同城市表现不同。

时间不刷新时，在页面**从上往下拉**即可重新获取。

## 三、查一个站点

1. 在「站点」标签点地图上的站点图标，进入站点详情。
2. 详情页列出经过该站的全部线路和各自的下一班时间。你可以：
   - **排序**：按到站时间或按线路名排列，人多的站先看最快那班；
   - **搜索**：站内线路多时直接搜线路号；
   - **收藏**：点星标把「站点＋线路」的组合存进收藏，下次不用站边上也能查它的时刻表。
3. 从站点可以反向规划「以它为起点/终点」的行程。

## 四、查一条线路

1. 在「线路」标签输入线路号或名称（地铁/火车则选起点终点站），结果里最好顺手选上运营方——同名线路在不同公司名下很常见。
2. 线路详情里你能看到：
   - 全部停靠站，点任一站看该站的下一班时间；
   - 地图图标：把整条线画到地图上，看车辆当前开到哪（有实时数据时）；
   - **方向**：公交有来回两个方向，进详情先核对方向对不对，反了点双向箭头切换；
   - 时刻表图标：看这一天从首班到末班的完整排班；
   - 星标收藏该线路——收藏的线路有重大变更（改道、时刻调整）时应用会推送通知。
3. 到站时间旁常有用户评分，点星可以自己也打一个。

## 五、收藏与常见操作

- **收藏什么**：线路、站点、地点（家、公司）都能收藏，收在星标页里，分「路线 / 线路 / 地点」几类。
- **收藏站点的两个入口**：① 站点详情页左下角的「加入收藏」按钮；② 收藏某条线路时，应用会接着让你选这条线上的哪个站——选完它同时进收藏。收藏的站点集中显示在星标页的 FAVORITES 卡片上（紧挨「附近」卡片），打开就能看这些站的下一班。
- **设「家」和「公司」**：搜到地址后在结果页点星标，标成 Home 或 Work，以后规划行程直接一键选它们当起点终点。
- **订阅某条线的推送**：线路详情页的电话图标是该线的通知开关，订阅后这条线有时刻调整、改道等重大变化会推送给你。
- **桌面小组件**：先把线路收藏好，然后在桌面添加 Moovit 小组件（安卓：长按桌面空白处 → 小组件 → 找 Moovit；iOS：长按桌面进入编辑 → 加小组件 → 搜 Moovit），不打开应用也能在桌面看收藏线路的下一班。各机型入口措辞略有差异，找不到就用「小组件」关键词搜。
- **历史记录**：搜索历史显示在搜索页下方，长按某条可以删除。
- **下拉刷新**：所有到站时间页都支持下拉刷新，等车时刷一下比干等准。

## 六、数据不对时怎么纠

公交数据的来源是「运营方时刻表 + 车辆 GPS + 用户上报」三层，第三层靠乘客自己：站点搬了、时刻表改了、线路绕行了，你都可以在应用里上报。你上报一次，附近其他乘客看到的信息就准一次。常见的错法与处理：

| 你看到的现象 | 处理 |
| --- | --- |
| 站点在地图上位置不对 | 在站点详情里提交位置问题上报 |
| 到站时间与实际差很多 | 先确认显示的是实时还是时刻表；确实错则上报 |
| 线路走向或停靠站变了 | 在线路详情里上报变更 |
| 站点名称写错/重复 | 上报站点信息 |

上报入口在线路或站点详情页内（不同版本图标略有差异，一般在「更多」或分享按钮附近）。
