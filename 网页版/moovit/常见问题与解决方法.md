# 常见问题与解决方法

> 定位飘、时间不准、提醒不响、装不上——这些是实际使用中最常撞到的问题。本篇按现象给排查步骤。

## 一、地图上「你在哪里」的位置不准或不出现

按顺序查三处，九成问题在前两处：

1. **系统定位权限**：设置 → 应用 → Moovit → 权限 → 位置，确认是「使用时允许」（选「仅一次」的话下次进又要重新给）。
2. **系统定位开关**：下拉快捷面板看 GPS 是否打开；部分手机还有「省电模式下禁止后台定位」的限制，省电策略里给 Moovit 设成「无限制」。
3. **应用内**：回到地图页点「回到我的位置」按钮重新定位。室内、高架下定位偏差本来就大，走到窗边再试。

## 二、到站时间一直是黑色（没有实时数据）

不是故障，先分清口径：实时时间与排班时间在界面上用不同样式区分（见 [实时到站与线路查询怎么用.md](实时到站与线路查询怎么用.md) 第二节）。黑色 = 该线路当前没有实时数据源，显示的是排班表。处理：

- 下拉刷新一次，排除网络没刷出来；
- 换一条线路试试——同一城市里，地铁常有实时、部分公交没有；
- 长期没有实时是当地运营方未接入，应用侧无法开启；
- 时间动辄多出一小时、或显示 -60 这类负数，不是这条线的问题，是手机时区错位——处理步骤见 [到站时间颜色与准确度怎么看.md](到站时间颜色与准确度怎么看.md) 第四节。

## 三、下车提醒不响

按这条链逐项确认，哪断了修哪：

1. **通知权限**没给 → 设置里打开；
2. **定位没开** → 提醒靠剩余站数推算，定位断了就没法算（同本篇第一节）；
3. **行程没真正开始** → 必须设了终点并点了出发/导航，光收藏路线不会触发提醒；
4. **应用被系统杀后台** → 电池设置里允许后台运行，别让它被「一键清理」清掉；
5. **导航铃铛被关过** → 导航页右上角铃铛是通知开关，点开确认。

## 四、搜索找不到我的城市 / 线路

- 换关键词：先搜城市名，选中城市后再搜线路号；
- 线路搜不到但站台在地图上：直接点站点图标，从站点里翻线路；
- 确认应用内选中的城市对不对——城市选错，再怎么搜线路都没有；
- 该城市确实没数据：Moovit 覆盖 112 个以上国家和地区、3400 多个城市（官网口径，截至 2026-09），但具体到小城市或县镇可能没有收录。官网有中国部分城市的线路页面（如上海、北京），你可以先在 [www.moovitapp.com](http://www.moovitapp.com) 搜一下城市名，网页有数据则应用里也有。

## 五、路线规划的结果不合理

- 起终点写具体：按「门牌号, 街道, 城市」格式输入，宽泛地名会算偏；
- 检查交通方式与最大步行距离的设置——把地铁关掉、或把步行距离限得太极端，都会算出奇怪方案；
- 时间设置：确认是「现在出发」还是指定时刻，赶早班车时这一项最容易填错；
- 指望更优结果时，多翻两条方案对比，点「更早/更晚」看相邻班次。

## 六、安装失败 / 打不开

1. 核对安装包：版本、包名、MD5 与 [下载与安装教程.md](下载与安装教程.md) 第二节表格一致吗？不一致先重新下载。
2. 系统版本过低：各来源标注的最低安卓版本不一致（旧协议文本 4.0+，第三方页面出现过 6.0+/7.0/11+），以你下载页当时显示为准。
3. 「未知来源」没放行：按安装教程第三节开一次。
4. 装完闪退：多半是系统过旧或内存吃紧，先升级系统再试；仍闪退则记录机型与系统版本再排查。

## 七、想改语言 / 在中国大陆能不能用

- **改语言**：应用语言一般跟随系统语言，把系统语言切成简体中文后重进应用即可；官方称支持 45 种语言，实际显示以应用内选项为准。
- **中国大陆**：官网有中国城市的公交地铁数据页面（上海、北京等），但各城市线路收录完整度不一，实时数据更少见。先在官网搜你所在城市，有页面再装应用查——这样最省时间。

## 八、还有问题找官方

- 帮助中心：[support.moovitapp.com](https://support.moovitapp.com)（分功能的问答与提交工单入口）；
- 邮件：技术支持 `support@moovit.com`，隐私相关 `privacy@moovit.com`。

提交问题时带上：应用版本号（设置里可查）、机型与系统版本、出问题的线路号/站点名、时间——这几样齐了，客服复现最快。
