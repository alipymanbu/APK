## 一、这条路对所有机型都通用

富士官方学习中心把「配方 → 相机」的标准做法定为：**把配方存成相机的自定义设置档**（Custom Setting，多数机型是 C1–C7）。它不依赖机型代际、不需要线、不碰保修问题——USB 直传功能对老机型不开放（见 [配方传输到相机教程.md](配方传输到相机教程.md)），手动这条路则从最早的支持到最晚的都行。下面的菜单路径以富士官方学习中心与机型说明书为准（各机型菜单措辞略有出入）。

## 二、在相机里建档并输入参数

1. 按 **MENU/OK**，进 **IMAGE QUALITY SETTING**（图像质量设置）标签页。
2. 选 **EDIT/SAVE CUSTOM SETTING** → 挑一个档位（如 C1）→ 提示 `CREATE NEW OK?` 时按 OK → 进 **EDIT/CHECK**。
3. 逐项输入配方页上的参数：胶片模拟、动态范围、高光/阴影（或色调曲线）、色彩、锐化、降噪、颗粒、白平衡及其偏移、ISO 上限等——App 里配方页给什么就填什么。
4. 输入完逐级返回，在保存界面**给这个档起个名字**（直接用配方名，下次在相机里一眼能找到），确认保存。

存一次长期有效；换配方就是重复这五步覆盖同一档，或另开一个档。

## 三、存好之后怎么快速调出来

访问自定义档的方式随机身结构不同（富士官方学习中心按机身分了三类）：

| 机身类型 | 代表机型 | 调档方式 |
| --- | --- | --- |
| 顶部带 PASM 拨盘 | X-S20、X-M5、X-H2S 等 | 拨盘直接转到 C1、C2… |
| 顶部无 PASM 拨盘 | X100VI、X-E5、X-T30 III 等 | 按 Q → 选 Q 菜单第一项 SELECT CUSTOM SETTING → 后拨轮切换档位 |
| 带胶片模拟拨盘 | X-T30 III、X-M5、X-E5 等 | 拨盘拨到 C 档；另可在 IMAGE QUALITY SETTING → FILM SIMULATION DIAL SETTING → FS RECIPE 设 ON，把三条配方存进 FS1–FS3 槽位 |

不确定自己属于哪类：看相机顶部有没有模式拨盘、有没有单独的胶片模拟拨盘即可；仍不确定就翻说明书「自定义拍摄模式」一章。

## 四、拍出来没变化？先看是不是在拍 RAW

这是最常见的空忙一场：富士官方明确说明，**胶片模拟、颗粒这类画质设置只写进 JPEG/HEIF，RAW 文件不带配方效果**。检查方法：

1. MENU/OK → IMAGE QUALITY，确认输出是 FINE 或 NORMAL（含 FINE+RAW 这类带 JPEG 的组合也行）；**选纯 RAW 就等于关掉了配方**。
2. 回放时看 JPEG 那张，不是只看 RAW。
3. 确认自己切到了存配方的那个档位（第三节的调档方式），而不是仍在 P/A/S/M 档上现调。

三项都对了，直出的 JPEG 就该是配方的色调。拍完还是不对，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、菜单里找不到配方写的那一项

配方参数是按传感器代际写的，**不同代机型的菜单项本身就不一样**——找不到多半不是你操作错了：

- 以 X-T3 的官方手册为例，其图像质量设置里**没有 CLARITY（清晰度）**一项；X-E4、X100V、X-T5 这些较新机型才有。配方让你设 Clarity、而你的相机没有这一项时，跳过即可。
- 反过来，配方页的「兼容机型」一节会写明你这代机器怎么改：老一代机型常要求 Color Chrome Effect 设为 Off、把最高 ISO 压到 6400；更新一代则可能建议颗粒选 Small、Clarity 用 0 或 -2。
- 找不到某项时的处理顺序：**先看配方页兼容说明 → 有对应说明照办 → 没说明就跳过该项**，其余照填。菜单项名称与有无，以你机型的说明书为准（截至 2026-09，各机型手册可在 [fujifilm-dsc.com](https://fujifilm-dsc.com/) 查到）。

参数填完、档也存对了，剩下的问题（照片格式、档位切换）都在第四节；想省掉逐项手抄，换 USB 线直传见 [配方传输到相机教程.md](配方传输到相机教程.md)，怎么找配方见 [胶片模拟配方怎么用.md](胶片模拟配方怎么用.md)。
