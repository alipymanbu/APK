## 一、这个功能是什么

Fuji X Weekly 的「配方传输」（官方叫 App-to-Camera Recipe Transfer）让你用一根 USB-C 线，把手机里选好的一条配方**直接写进相机的自定义设置档**（多数机型是 C1–C7，有的是 C1–C6 或 C1–C4），省去逐项手抄参数。iOS 版 2026 年 8 月上线该功能，**安卓版 2026 年 9 月上线**——安卓机要用它，应用得是商店里的新版（打开应用顶部能看到「相机 + 箭头」图标即支持，看不到就去商店手动更新，见 [常见问题与故障排查.md](常见问题与故障排查.md)）。

## 二、动手前先确认四件事

| 条件 | 要求 |
| --- | --- |
| 机身 | 全部 X-Trans V 机型；X-Trans IV 里除 X-T3、X-T30 之外的机型；较新的 GFX 机型 |
| 线材 | 高质量 USB-C 数据线（USB 2.0 或 3.0）；充电线、劣质线可能导致识别不了 |
| 手机 | 安卓需支持 USB Host（USB OTG），且 OTG 处于开启状态 |
| 相机 | 传输全程保持开机供电 |

**OTG 在哪开**：一般在 设置 → 系统/连接的设备/更多设置 → USB OTG（各品牌叫法不同），多数新机会自动开启，连不上时手动打开再试。个别机型（有用户反馈如 Nothing Phone 1）还要进开发者选项把「默认 USB 配置」改成文件传输——机型之间差异很大，连不上时按自己机型搜对应路径。

**机型不在这份清单里（比如 X-T3、X-T30 或更早的 X 系列）就用不了传输**，不代表应用坏了：老老实实照参数清单手动设进相机即可，效果完全一样，见 [胶片模拟配方怎么用.md](胶片模拟配方怎么用.md) 第六节。

## 三、相机端设置（缺一步就连不上）

不同机型菜单名略有出入，按自己机身说明书对：

1. 找到 **Connection Setting**（连接设置，有的在扳手菜单里，有的是独立一组）。
2. 把 USB 连接模式设为 **PC Connection MODE**（有的机型叫「PC连接模式」）。
3. **必须**把 USB RAW CONV./BACKUP RESTORE 设为对应选项——官方实测图注明：不选它传输功能不工作。
4. 有 USB 供电相关选项的机型，设为 Supply Off/Comm On（或 Off，视机型而定）；连不上时这一步优先排查。

## 四、传输步骤

1. 手机与相机都开机，用 USB-C 线连好。
2. 打开 Fuji X Weekly，点顶部的**传输图标**（相机带箭头），或在任意配方页顶部点同一个图标。
3. 点 **Choose Recipe**，选要传的配方。
4. 选要写入的自定义档位（C1–C7 里挑一个——**会覆盖该档原有设置**，先确认这一档没存别的东西）。
5. 点顶部 **Transfer**，完成后档位里就是这条配方的参数了。
6. 相机上切到该档位即可直接拍摄；想微调曝光补偿这类现场参数，照常在相机上调。

一次传一条、传多少条都免费。**成组批量传输（Recipe Sets）是订阅功能**，赠送的套装与自建套装的用法见 [Patron订阅与高级功能.md](Patron订阅与高级功能.md)。

## 五、用之前想清楚：保修提醒

官方在使用条款与公告里写得很直白：这个传输协议是**实验性功能、属于非官方也未经厂商授权的连接方式，可能影响相机的保修**，各地区保修条款不同，风险自担。官方作者本人的建议是**保修期内的机器先别用**，等保修过期再上；在保修期内又想用，属于你知情后的选择。

不想碰这个风险的话，手动抄参数这条路永远在，功能上没有任何损失——完整步骤见 [配方存进相机自定义档.md](配方存进相机自定义档.md)。

## 六、传不动时去哪查

连不上、一直提示没有相机、点了没反应这类问题，先按 [常见问题与故障排查.md](常见问题与故障排查.md) 逐条过一遍（OTG、线材、相机 USB 模式、应用版本是四个最高发的原因）；都试过还不行，官方 App 内置了 FAQ/Troubleshooting 页面，也可以通过官网 [fujixweekly.com](https://fujixweekly.com/) 页尾的联系方式找作者本人反馈。
