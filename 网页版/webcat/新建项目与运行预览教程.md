## 一、新建第一个工程

装好之后（安装见 [下载与安装教程.md](下载与安装教程.md)），上手的主线就一条：新建工程、进编辑器、写代码、点运行看效果。下面按这条线走一遍；PHP 项目要多开一个开关，单独放在第五节。

1. 首页右下角点 **+ 号**；
2. 选「新建工程」——有的版本会先让你挑模板，想从零写就选空白，想先看个能跑的例子就挑模板；
3. 给工程起个名字，确认后它出现在首页的工程列表里；
4. 点进这个工程，就进了编辑器界面。

工程列表就是你的工作目录：所有项目平铺在这，点谁进谁。重命名、删除这类操作在工程条目上（长按或条目内的菜单，各版本入口略有差异，以你界面上实际的为准）。

## 二、编辑器里有什么

按官方功能说明与各版本更新日志，你用得上的主要是这些：

| 能力 | 说明 |
| --- | --- |
| 语法高亮与补全 | HTML、CSS、JavaScript、PHP 四类代码的高亮与自动补全 |
| 自动保存 | 编辑内容自动存盘，不用手动 Ctrl+S（界面上仍可手动保存） |
| 暗黑模式 | 设置里可切主题 |
| 多窗口切换 | 同时开着多个文件时切着改 |
| 代码格式化 | 一键把乱的缩进排整齐（5.2.1 更新专门优化过这项） |
| JSON 编辑 | 5.2.1 起支持直接编辑 `.json` 文件 |
| 捏合缩放 | 编辑区双指捏合调字号/视图 |

项目里的文件操作（新建文件、新建文件夹、改名、删除）都在工程的文件列表里做；要拿现成源码开工，支持直接**导入 ZIP 压缩包**，导入时会调起系统的文件管理器选文件（5.2.1 的改动）。

## 三、运行与实时预览

写完想看效果：编辑界面里有**运行**入口，点它就用内置浏览器内核把当前页面跑起来——这是「所见即所得」的那部分，改一行、再跑一次，看的就是最新效果。官方说明里还提到预览支持多设备视图模拟（同一页面切不同屏幕尺寸看），入口在预览界面内，以你版本里的实际按钮为准。

多个来源的功能清单里还列了**局域网访问**：同一 Wi-Fi 下，让电脑或另一台手机的浏览器打开你这个页面看效果（无需 root）。入口在运行/预览相关菜单里，你的版本里有没有、叫什么名，以界面实际为准。

纯前端页面（HTML/CSS/JS）**离线就能编辑和预览**，这点是官网明确写进 FAQ 的；只有共享空间、云同步这类联网功能才需要网络。

## 四、可视化模式：不写代码也能改页面

除了直接写代码，这类编辑器通常还带一个**可视化模式**——像排版工具一样直接点选页面元素改内容、调样式（多个来源把它列为特色功能）。用它注意两条：

- **改完回代码模式核对一遍**。历史版本的可视化模式有过三个实打实的毛病：界面加载失败、把 JS 代码吞掉、改一个元素却动到别的文件——5.21 的更新内容明确修了这三条，但如果你装的是更早的包就会撞上（怎么核对版本见 [下载与安装教程.md](下载与安装教程.md) 第二节）；
- 拿不准的改动先跑一次预览，页面行为不对就切回代码模式看源码有没有被意外改动。

## 五、PHP 项目怎么跑

WebCat 内置了 PHP 本地运行环境，但它**默认不启用**，要跑 PHP 得先开开关：

1. 进**设置**，找到 PHP 运行环境的开关并打开；
2. 回到工程，新建一个 `.php` 文件；
3. 写一句输出试试，例如 `<?php echo "hello"; ?>`；
4. 点运行，页面里能看到输出即环境通了。

这条路径来自多份第三方图文教程，步骤一致；若你的版本里选项叫法不同，在设置里找带「PHP」字样的条目即可。

## 六、卡在哪一步了

建工程后一闪就退、预览页面空白、导入的 ZIP 进不来——这些都不在本篇范围，按现象去 [常见问题与故障排查.md](常见问题与故障排查.md) 查。想用文件管理器直接看工程的源文件在哪个目录、或者用电脑上的工具改它，路径和覆盖风险在 [项目文件存在手机哪个文件夹.md](项目文件存在手机哪个文件夹.md)。项目写到一半想挪到电脑上继续，见 [代码导出与共享空间使用.md](代码导出与共享空间使用.md)；项目能正常跑之后想打包成安装包，见 [网页打包成安卓App教程.md](网页打包成安卓App教程.md)。
