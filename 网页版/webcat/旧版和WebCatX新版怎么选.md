## 一、两个版本分别是什么

官网 `https://webcat.top` 的下载区分两个包（版本号以官网当时显示为准）：

| | WebCat 旧版 | WebCatX 新版 |
| --- | --- | --- |
| 官网标注版本 | V5.2.1（安装包文件名 `5.21.apk`） | V6.0.19 |
| 版本线 | 老名字的最后一条 | 官网主推的新名字、新版本线 |
| 本文档对应 | **是——网盘那份就是 5.21** | 否 |

两家下载站标的产品信息也对得上这份旧版：包名 `top.webcat.editor`、10.54M。也就是说，网盘里的包 = 官网归档的旧版 5.21，本套文档里的界面与步骤都按它写。

## 二、差异对照

按官网功能页与 FAQ（新旧两版同页介绍）整理，你选版本时真正关心的差异是这几条：

| 关注点 | WebCat 旧版 5.21 | WebCatX 新版 |
| --- | --- | --- |
| AI 助手 | 无 | 内置：让 AI 理解项目、生成/定位/修改代码 |
| 安卓原生能力桥 | 打包插件走的是早年的交互框架（2021 年 3.07 版重构时集成 `wc.js`） | 换成官方新命名的 CatNative 框架，`window.webcat` 直接调文件、相册、拍照、分享、扫码、录音、权限等 |
| 打包 APK | 支持，自定义包名/图标/版本 | 支持，同一套自定义项 |
| PHP 本地运行环境 | 内置，设置里手动开（多份教程按这版写） | 官网 FAQ 未提及此项，以装上后实际界面为准 |
| 语法高亮语言 | HTML/CSS/JS/PHP | 官网列 HTML/CSS/JS，另称可装扩展支持 PHP、Python 的高亮 |
| 离线编辑预览 | 支持 | 支持（FAQ 对两版同页回答） |
| 系统要求 | 官网下载区标「Android 5.0+」，下载站标「安卓 5.2 以上」 | 同页标注 |

## 三、怎么选

- **想要 AI 帮写代码、打包的 App 要调用相册/拍照/分享这类原生能力** → 装 WebCatX 新版；
- **只想安稳写 HTML/CSS/JS、或明确要用内置 PHP 本地环境** → 装 5.21 旧版（就是 [下载与安装教程.md](下载与安装教程.md) 里网盘那份），本套文档的每一步都和它对得上；
- 两版包名不同（新版包名以官网安装包属性为准），**可以同时装在同一台手机上**，互不覆盖，先都试一遍再定也行。

## 四、别认错：还有个同名的在线平台

搜索「webcat」还会撞见一个叫 Webcat 的国外在线应用搭建平台（网页可视化拖拽做应用、可协同编辑、部署到自定义域名，曾在 AppSumo 上售卖终身套餐）。它**没有安卓安装包**，和本篇说的手机代码编辑器只是重名。判断方法就一条：包名不是 `top.webcat.editor` 的，都不是本套文档说的东西。

## 五、升级与回退的注意点

- 从 5.21 升到 WebCatX 是**换版本线**：项目文件还在本地，但两版界面差异不小，升级后按 [新建项目与运行预览教程.md](新建项目与运行预览教程.md) 的入口重新认一遍；升级前建议先备份，见 [代码导出与共享空间使用.md](代码导出与共享空间使用.md)。
- 装回旧版（降级）同样是覆盖安装，但若两版数据目录不通用，降级后项目列表可能要靠之前导出的备份恢复——所以「先备份再换版本」是通用动作。
- 5.21 本身的更新历史止于 5.2.1（改动包括：去掉页面跳转动画、导入文件改调系统文件管理器、新增编辑 JSON、优化格式化、修共享空间刷新），之后的更新都在 WebCatX 线上。遇上旧版才有的毛病，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
