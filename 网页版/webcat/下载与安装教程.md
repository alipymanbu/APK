## 一、先认准是这一个

WebCat（也常被叫作 webcat 编辑器）是一款装在安卓手机上的 Web 代码编辑器，包名 `top.webcat.editor`。同名的下载页很多、版本号写法也不统一，装错包后面每篇文档里的设置路径都会对不上。装之前先对这三项：

| 核对项 | 值 |
| --- | --- |
| 官方名称 | WebCat（官网 `https://webcat.top` 上即此写法） |
| 包名 | `top.webcat.editor` |
| 资源形态 | 安卓 APK，iPhone 装不了 |

另外注意：国外有一个叫 [webcat.app](https://webcat.app) 的在线应用搭建平台也叫 Webcat，跟本文说的手机编辑器不是同一个产品，别在那边找安装包。

**价格**：安装包本身免费下载、免费安装。两家下载站的资费标注都写着「提供应用内购买项目」——也就是说装上后应用里有付费项目，具体是什么、多少钱，以应用内当时显示为准（官网未公布价目表）；不付费也能用基础的编辑与预览功能。

这份 5.21 对应官网下载区标注的「旧版 V5.2.1」——官网把新版本线改叫 WebCatX 之后，5.21 就是旧线的最后一版。你装的到底是哪一版、和新版怎么选，见 [旧版和WebCatX新版怎么选.md](旧版和WebCatX新版怎么选.md)。

下载后核一下 MD5，确认传输途中没损坏（文件名换成你实际的文件名）：

```powershell
certutil -hashfile "webcat_v5.21.apk" MD5
```

输出 `8b7ce394a8bda140ceca1bd7fc2f6c50`（大小写无所谓）即可。

**转存与下载的顺序**（夸克网盘的常规用法）：

1. 先在网盘里**保存/转存**这个分享链接到你自己的账号——在网页或客户端里打开链接，点保存；
2. 转存完成后到你自己的网盘里找它（分享链接失效也不影响已转存的副本）；
3. 在手机上或先传到手机再下载，按下一节安装；
4. 文件夹里那份防失效说明文本留着——分享链接哪天打不开了，靠它找回原始入口。

## 三、手机上怎么装

APK 不是从应用商店点「安装」装的，所以要先给安装来源授权：

1. 点开 APK 文件，系统弹出「禁止安装来自此来源的应用」时，进到该来源（浏览器或文件管理器）的授权开关并打开，返回；
2. 再次点击安装，确认详情页显示的图标与名称是 WebCat、包名是 `top.webcat.editor`；
3. 装完先别急着打开，到「设置 → 应用 → 应用信息」里核对版本（第五节）；
4. 首次启动会弹隐私政策确认与权限请求，按系统提示操作即可——具体会要哪些权限以你手机上弹出的为准，编辑与预览本身不联网也能用。

**系统要求有两个口径**：官网下载区标注「支持 Android 5.0+」，多家下载站标注「需要安卓 5.2 以上」。两者并列放在这，以你设备实际能否装上为准——装的时候系统报「解析错误 / 安装包与系统不兼容」，就先看 [常见问题与故障排查.md](常见问题与故障排查.md)。

以后升级是**覆盖安装**：拿新版本 APK 直接再装一次，不用先卸载（注意 WebCat 的项目文件存在本地，覆盖安装前别顺手清数据）。

## 四、装完能立刻干什么

打开就是中文界面。首页右下角的加号就能新建工程，进编辑器写 HTML/CSS/JS，点运行出预览——完整走一遍见 [新建项目与运行预览教程.md](新建项目与运行预览教程.md)。想跑 PHP 得先在设置里把 PHP 运行环境开关打开，那篇里有步骤。
