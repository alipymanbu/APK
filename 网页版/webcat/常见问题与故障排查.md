## 一、打开就闪退 / 打不开

闪退先别急着清数据，按出现频率把这几项走一遍——每一项都能当场确认，做完一轮基本能定位到原因：

1. **版本与系统不匹配**：系统低于安装包要求（官网标 Android 5.0+，下载站标安卓 5.2 以上），先核对你的系统版本；装的是别的渠道的包，先按 [下载与安装教程.md](下载与安装教程.md) 核对包名与 MD5；
2. **存储空间不足**：手机剩余空间太小会导致启动失败，清出几百 MB 再试；
3. **权限缺失**：到「设置 → 应用 → WebCat → 权限」确认存储等必要权限已给；
4. **缓存/数据损坏**：「设置 → 应用 → WebCat → 存储」先**清除缓存**试一次；
5. **后台限制**：部分机型的省电策略会强杀后台应用，把 WebCat 加进白名单。

**「清除数据」会把本地项目一起删掉**——项目存在应用数据目录里，清完就没了。走这一步之前，先按 [代码导出与共享空间使用.md](代码导出与共享空间使用.md) 导一份出来，否则闪退没修好、项目先丢了。

## 二、可视化界面加载失败 / 内容不对

5.21 的版本更新内容里，这几条都修过：**可视化界面加载失败**、**可视化模式吞掉 JS 代码**、**可视化修改时改到其它文件**。这些修复对应 5.21 这一版——你如果装的是更早的构建，就会实打实撞上。

处理办法：核对装的确实是 5.21（包名 `top.webcat.editor`，MD5 `8B7CE394A8BDA140CECA1BD7FC2F6C50`，核对方法见 [下载与安装教程.md](下载与安装教程.md) 第二节），不是就换成这份；已是 5.21 仍复现，退出工程重进一次再操作。

## 三、文件导入失败

导入 ZIP 或单个文件没反应、报失败，两个处理顺序：

1. **先对版本**：5.21 修过「文件导入失败」，且导入改为直接调用系统文件管理器——还在更早版本的先升级；
2. **再对文件**：确认 ZIP 没损坏、后缀是 `.zip`；导入时在系统文件管理器里选中的路径要能真实打开该文件（下载目录被清理过就重新下一份）。

## 四、预览跑不起来 / 页面空白

这属于项目本身的问题，不在故障范围：

- 纯 HTML 项目：确认入口文件是 `index.html`、路径大小写没写错；
- PHP 项目：**设置里的 PHP 运行环境开关没开**是最常见原因，打开后重新运行——完整步骤见 [新建项目与运行预览教程.md](新建项目与运行预览教程.md) 第五节；
- 页面本身依赖网络：断网环境下联网资源（CDN 脚本、图片）加载不出来，先用本地资源替代，或联网再试——编辑与预览的框架本身是支持离线的。

## 五、打出来的 APK 装不上

打包成功但安装失败，按这三条查（打包步骤见 [网页打包成安卓App教程.md](网页打包成安卓App教程.md)）：

1. **未知来源权限**：安装时系统拦截，就到该来源的「安装未知应用」开关打开再装（同 [下载与安装教程.md](下载与安装教程.md) 第三节的授权）；
2. **包名冲突**：你填的包名如果和手机上已装的某个应用相同，系统会当成覆盖安装而拒绝——换一个没被占用的包名重新打包；
3. **存储空间**：安装包加解压空间不够，先清理。

旧版打包插件历史上还修过「只能安装一个」「打包后长按闪退」「无法播放音频」等问题，这些都在更早版本里——你装的是 5.21 就不会遇到那批老问题。

## 六、在外面改过文件，改完的改动不见了

有用户反馈过这个现象：用别的编辑器改了工程目录里的源码，回到 WebCat 再看，改动被盖回去了。原因是应用运行中会按内存里的旧内容自动保存。处理与预防见 [项目文件存在手机哪个文件夹.md](项目文件存在手机哪个文件夹.md) 第三节——核心就一条：**外部编辑前先把 WebCat 彻底关掉**。

## 七、共享空间 / 云同步连不上

先分清是不是网络问题：**编辑和预览不需要网**，只有共享空间、云同步要联网。断网时这两个功能打不开是正常表现；有网仍进不去，「共享空间返回主页不刷新」是 5.2.1 已修的问题，对一下版本。两版应用之间的选择（旧版还是 WebCatX）见 [旧版和WebCatX新版怎么选.md](旧版和WebCatX新版怎么选.md)。
