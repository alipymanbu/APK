## 一、打开前的三件事

1. **确认网络**：角色库、对话、图像生成全部在云端处理，断网就是白屏或转圈。
2. **准备账号**：有第三方资料提到它支持 Google、Facebook 等第三方账号登录，实际提供哪些方式以应用内登录页为准；对话记录跟账号走，换手机后登录同一账号才有得接（以实际同步情况为准）。
3. **年龄门槛**：App Store 标 18+、Aptoide 标 PEGI-16，这是一款面向成年人的应用；首次启动如有年龄确认弹窗，如实选择。

## 二、把界面换成中文

官方口径是支持 10 种以上语言。中文化有三个途径，按顺序试：

1. **跟随系统语言**：多数应用首次启动会按手机系统语言出界面，如果你的系统是简体中文，大概率直接就是中文（以实际为准）。
2. **应用内手动切换**：到设置（Settings 或个人资料页）里找 `Language` / `语言` 一项；不同版本菜单位置不一样，找不到就以你手头版本的实际界面为准。
3. **对话本身用中文**：界面是英文也不影响聊天——直接用中文发消息，角色的回复语言一般会跟随你的输入（官方强调多语言下流畅互动，以实际表现为准）。

需要中文界面的角色对话，也可以在挑选角色时优先选开场白是中文写的角色。

## 三、挑一个角色开始第一段对话

1. **进大厅**：首页是推荐位，有第三方资料列了 For You、Weekly Picks 这类栏目，具体栏目名以你手头版本为准。
2. **用筛选收窄范围**：可以按类别（OC、Fictional、RPG 等）、角色性别、主题（Magical、Scenario、Human、Non-human 等）组合筛（第三方资料口径，以实际可选项为准）。
3. **点开卡片先看简介与开场白**：开场白就是对话的第一幕，觉得对味再进。
4. **开始对话**：直接打字推进剧情——描述你的动作、说出你的台词都行；想换剧情走向，在消息里直说即可，AI 会顺着改。

## 四、对话能记住多少

角色对前情的记忆有档位上限：免费档 4k；订阅档至少 8k，更高档位到 16k / 32k / 200k（官方订阅 FAQ 口径）。长对话发现角色「忘事」时，把关键设定重申一遍，或者另开一场新对话。各档位的具体差异与升级代价见 [宝石与订阅计划说明.md](宝石与订阅计划说明.md)。

## 五、第一天常见卡点

| 症状 | 先做什么 |
| --- | --- |
| 打不开 / 一直转圈 | 确认网络；换网络（Wi-Fi 与流量互换）再试；仍不行看 [常见问题与故障排查.md](常见问题与故障排查.md) |
| 提示宝石不足 | 每日签到等任务可以攒宝石，机制见 [宝石与订阅计划说明.md](宝石与订阅计划说明.md) |
| 界面全是英文 | 用第二节的方法切语言；或直接用中文聊，不影响使用 |
| 找不到想玩的类型 | 用筛选组合翻；或者干脆自己捏一个，见 [角色创建与玩法指南.md](角色创建与玩法指南.md) |
| 生成图像排队久 | 图像生成有排队，优先出图是订阅权益（官方口径），免费档等一等即可 |
