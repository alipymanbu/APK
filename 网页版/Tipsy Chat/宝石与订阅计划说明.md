## 一、不订阅也能玩

官方订阅 FAQ 的原话口径：**订阅不是必需的**。不付费的用户靠每日签到等任务攒宝石就能继续聊；对话不设内容过滤、角色创建数量不限，这两点订阅与免费没有区别——订阅买到的是更多宝石与更高级的功能。

免费档一天能聊多少，取决于当天攒到的宝石：有多个第三方资料提到签到每天可得约 50 宝石（数值随运营活动变动，以应用内显示为准），选低成本模型能聊得更久。

## 二、宝石怎么算

| 项目 | 规则 |
| --- | --- |
| 蓝宝石 | 订阅按档位每月发放，**当月有效、不结转**，每月初按当前订阅档位刷新 |
| 红宝石 | 任务等方式攒到的宝石，**永久有效、不过期** |
| 消耗顺序 | 聊天先扣蓝宝石，蓝宝石用完才扣红宝石 |
| 不同模型消耗不同 | Claude 这类高端模型耗宝石更多（官方称它是目前角色扮演领域最先进的模型之一），也有低成本模型供轻度使用 |
| 宝石用完了 | 升级订阅，或用充值入口单独买宝石；官方口径是订阅比单买宝石划算，因为还附带功能 |

## 三、免费与订阅档位对照

| 项目 | 免费 | 订阅通用 | Standard | Premium | Deluxe |
| --- | --- | --- | --- | --- | --- |
| 记忆容量 | 4k | 至少 8k | 最高 16k | 最高 32k | 最高 200k |
| 优先图像生成 | 无 | 有 | 有 | 有 | 有 |
| 免费自动灵感 | 无 | — | 有 | 有 | 有 |
| 调整回复长度 | 不能 | — | — | 有 | 有 |

价格以官方页面为准：第三方整理的月费档位约 4.99 / 14.99 / 44.99 美元（会变动，以应用内标价为准）；官方称年付最多比月付省 50%。iOS 端另有宝石内购包（如 2200 宝石 11.99 美元、25000 宝石 99.99 美元的档位，同样以应用内当时显示为准）。

## 四、值不值得订

- **每天聊几句**：免费档加每日签到的宝石够用，先用免费档一两周再决定。
- **长剧情、要角色记住前情、想快点出图**：订阅的收益集中在记忆档位、优先图像生成和灵感工具上，对照上表看你缺哪项。
- **计费方式**：月付会自动续费；年付除苹果、谷歌渠道外是一次性买断，不自动续。

## 五、退订与自动续费

先记住一条：**删除应用不等于退订**。各渠道的取消路径：

| 支付渠道 | 退订路径 |
| --- | --- |
| App Store | iPhone 设置 → 点顶部 Apple ID → 订阅 → 找到对应项 → 取消 |
| Google Play | Play 商店 → 菜单 → 订阅 → 找到对应项 → 取消 |
| RuStore | RuStore 底部账号页 → Subscriptions → 取消 |
| 信用卡 | 应用内 Settings → Subscription → Unsubscribe |
| PayPal / Subscribestar / Patreon | 回原支付平台按其流程取消 |

注意两点：要在**当前周期结束前至少 24 小时**取消，否则会再扣一期；取消后权益保留到当前计费周期结束。退款口径：苹果、谷歌渠道走各自的官方支持页申请；信用卡、PayPal 及其他平台按官方政策**当前周期内不退**。

已经在付费、想换档位、想知道差价怎么退：分渠道的升级与退款规则单独成篇，见 [升级订阅与退款规则.md](升级订阅与退款规则.md)。

## 六、订阅了没收到宝石

1. 按官方建议先**换一个浏览器重新登录**试试，很多权益显示问题到这一步就解决了。
2. 还不行就去 Discord 找官方客服（官方称客服账号为 Tipsy Bartender），订阅问题在 `#subscription-help` 频道提；或发邮件到 `support@tipsy.chat`。

订阅档位与聊天的关系（哪个档位该配哪种用法）也可以回看 [首次使用与中文设置.md](首次使用与中文设置.md) 的记忆一节；出了扣款纠纷想逐条排，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
