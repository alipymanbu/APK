## 一、自动补帧是做什么的

前后两页之间如果差别较大，直接连播会一跳一跳。选中相邻的两页，点工具栏的「自动补帧」，软件会在两页之间插进过渡画面，让动作看起来连贯。它省下的是你手动摆中间页的工作量。

要补出顺的动作，前提是**两页差别别太大**：比如第一页手臂垂下、第二页手臂已经举到底，中间补出来的过渡就容易显得怪。正确做法是先把大动作拆成几个小步骤摆好，再在差别不大的相邻页之间补。

## 二、什么时候别用自动补帧

| 情况 | 建议 |
| --- | --- |
| 两页差别很小，动作本来就顺 | 不必补，补了反而多出多余的中间页 |
| 两页差别很大（姿势跨度过大） | 先手动加一页把跨度缩小，再决定要不要补 |
| 补完后画面更怪 | 删掉补出来的过渡页，改回手动摆中间帧 |
| 出的动作一卡一卡 | 优先加页，再看是否适合补帧 |

补帧解决的是「页与页之间不够密」，解决不了「姿势本身摆得不对」。

## 三、播放速度在哪调

预览时点「玩」或播放按钮，动作太快或太慢就到设置里调播放速度。改完回到预览再看一遍，直到快慢合适。

一点提醒：**导出前先在预览里把速度确认好**。速度是画面的整体节奏，调晚了会连导出结果一起受影响，返工重新导出更费时间。导出相关的内容见 [导出视频与作品导入.md](导出视频与作品导入.md)。

## 四、用页数和速度估算成片时长

一段动画的时长由**页数**和**播放速度**两个因素共同决定：页数越多、每页停留时间越长，成片就越长。做之前先想清楚大概要多长，再决定摆多少页，比摆完发现太短或太长再回头补省事。

| 想要的成片时长 | 大致思路 |
| --- | --- |
| 几秒钟的小片段 | 十页上下，动作拆细即可 |
| 十几秒的短打斗 | 几十页，配合补帧压缩摆页工作量 |
| 更长的连续动作 | 分段落做，一段一段预览确认 |

上面的量级只是估算，实际取决于你的播放速度设置，以预览看到的效果为准。第一次上手摆页的流程见 [第一次制作动画的完整流程.md](第一次制作动画的完整流程.md)；若补帧或调速后出现异常，按 [常见问题与排查.md](常见问题与排查.md) 逐条排。
