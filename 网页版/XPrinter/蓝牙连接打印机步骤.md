# 蓝牙连接打印机步骤

> 从打印机自检页查名称密码，到在 XPrinter App 里连上并打一张测试标签的完整过程，附连不上时的排查顺序。

## 一、先弄清两件事：蓝牙名和 PIN 码

蓝牙配对要两个信息，都能从打印机自己身上拿到 —— **打印一张自检页**：

- 不带屏幕的机器：按住走纸键不放再开机，等状态灯闪一下后松开，自检页就出来了；
- 带屏幕的机器：进设置菜单选「打印自检页」确认即可。

自检页上会印出蓝牙名称与 PIN 码。芯烨蓝牙机型的默认值通常是名称 `printer001`、密码 `0000`，但**以你自己那台自检页上印的为准** —— 机器改过名或改过密码的话，默认值连不上。

## 二、在 App 里连

1. 手机打开蓝牙；安卓机还要在系统设置里先搜到打印机并配对一次，同时确保定位已打开（不给定位，App 里搜不到设备）。iPhone 不用在设置里配对，开定位后直接在 App 内连。
2. 打开 XPrinter，首页右上角显示「未连接」，点它。
3. 选连接方式：USB、蓝牙、网络三种，这里点**蓝牙连接**。
4. 等 App 扫到你的机器名，点它。
5. 首次连接会要 PIN 码，输入自检页上那串（默认多为 `0000`），确定。
6. 右上角变成已连接的设备名后，随便编辑一段内容点**打印**出一张测试标签 —— 出纸了才算真连上。

## 三、连不上时按这个顺序查

| 现象 | 怎么处理 |
| --- | --- |
| App 里根本搜不到设备 | 安卓确认定位权限已给、手机蓝牙开关已开；重启打印机和 App 再搜一次 |
| 搜到了但配对失败 | 核对 PIN 码是不是自检页上那串；打印机是否已连了别的手机 |
| 一直提示连接失败 | 在连接页点一次机器型号连接，等提示失败后再点一次（重试通常能成）；仍不行就重启打印机 |
| 手机已连上别的蓝牙设备占着 | 断开当前占用的蓝牙连接再试 |

一个容易忽略的点：打印机的蓝牙一般只同时服务一台手机。别人手机还连着它，你这边就怎么也连不上。

## 四、锁屏后老是断开

蓝牙连着、手机一熄屏就掉线，多半是系统省电策略在掐连接。把手机设置里的**自动锁屏改为「永不」**（或把 XPrinter 加进电池优化白名单），就能保持长连。摆摊、柜台这类要挂机打印的场景，建议直接接充电器并关掉自动锁屏。

## 五、连上之后

连接状态显示在首页右上角，点进去能看到当前设备。之后换纸、改模板都不用重连；只有换手机或打印机恢复出厂设置后才需要重新配对一次。连接正常但不出纸的问题属于打印环节，见 [打印不出字与乱码等问题排查.md](打印不出字与乱码等问题排查.md)。
