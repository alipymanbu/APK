## 一、这是个什么软件

XPrinter 是珠海芯烨电子科技有限公司给自家打印机做的手机端编辑与打印 App：你在手机上排版标签、小票，再通过蓝牙、USB、Wi-Fi 或云打印发给机器出纸。它覆盖的机器包括便携标签机、2 寸/3 寸标签机、4 寸条码面单机、热转印打印机，以及 58/80 热敏小票机。

你要装的是安卓版（包名 `com.xinye.xlabel`）。同一套名字的软件还有 Windows 版、iOS 版和网页在线版，那些在官网下载页各自分发，装错平台是白忙一场。

## 二、拿安装包

[XPrinter 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b0673f38a27b) 里这份是安卓 APK，先转存到自己的网盘再下载。这份包的实测信息（下载后可自行核对 MD5）：

| 项目 | 值 |
| --- | --- |
| 版本 | 5.2.1 |
| 包名 | `com.xinye.xlabel` |
| 大小 | 59.31M |
| MD5 | `126CCE8504F49583F35F649C19A3BF9A` |
| 最低系统 | 安卓 5.2 及以上 |

两点提醒：

- **版本以这份包为准**。官方商店与官网下载页上的版本号会随更新往前走（你搜到的常是更新的那版），两者不是同一个包 —— 想确认手里这份是不是它，比对上面的 MD5 最直接。
- 网盘里的文件名形如 `XPrinter_v5.2.1.apk`，下载完如果是 `.part` 结尾或体积对不上，说明没下完整，重下一次再装。

## 三、安装步骤

1. 把 APK 传到手机（数据线、局域网传输或网盘 App 下载都行）。
2. 用手机自带的文件管理器点这个 APK。
3. 系统若弹出「禁止安装未知来源应用」，点提示进设置、允许本次安装来源，再返回继续。
4. 装完先别急着打开，到系统设置里把蓝牙打开；要连 Wi-Fi 机型的，顺手把定位也打开（原因见下一节）。
5. 首次启动会连着弹几个权限请求，按下一节给。

安装失败最常见的两条：手机系统低于安卓 5.2（安装器会直接报解析错误），或安装包没下完整（安装中途报错）。前者换机器，后者核对体积与 MD5 重下。

## 四、首次运行的权限该不该给

App 的权限请求不是随便要的，逐条对应它的功能：

| 权限 | 不给会怎样 |
| --- | --- |
| 大致位置 | 安卓搜蓝牙打印机要依赖定位，不给就搜不到设备 |
| 相机 | 识图新建（拍模板 OCR 取字）用不了 |
| 存储 | 存不了模板里的图片、读不了 Excel 批量数据 |
| 麦克风 | 语音说关键词搜模板用不了 |
| 网络 | 云模板、在线更新拉不下来 |

只想打几张标签的话，**位置必须给**（蓝牙搜索靠它），其余可以等到用到那个功能时再给。iOS 侧在系统设置里开蓝牙与定位即可，App 内会引导。

## 五、其他平台的版本在哪

同一厂商的其他版本都在官网下载页 `https://www.x-printer.cn/xprinter-app/` 上分发（Windows 64/32 位、iOS、网页在线编辑），驱动与说明书在 `https://www.x-printer.cn/` 的下载区。手机与电脑的模板是分开存的，别指望装完安卓版电脑上就能直接用 —— 要跨端，得用它官网标称的模板云同步功能登录同一账号。
