## 一、先对症状，再动手

| 症状 | 大概率原因 | 直达 |
| --- | --- | --- |
| 应用里搜不到打印机 | 权限没给 / 机器休眠 | 见第二节 |
| 系统蓝牙配对失败 | 旧配对残留 / 配对码不对 | 见第三节 |
| 已连接但不走纸不打印 | 连接方式选错 / 被别的应用占用 | 见第四节 |
| 走纸但打出来是空白 | 热敏纸装反 | 见第五节 |
| 内容偏移、越打越歪 | 纸张类型选错 / 没校准 | 见第六节 |
| 字迹浅、发糊 | 浓度参数 / 纸受潮 | 见第七节 |
| 怀疑机器本身坏了 | 先打自检页验证 | 见[标签纸装法与校准](标签纸装法与校准.md)第四节 |

## 二、搜不到打印机

按顺序核对：

1. 打印机**开机**了吗？便携机型放久了会自动关机，按住电源键 3 秒重新开机。
2. 手机的**定位（或「附近的设备」）权限**给应用了吗？不给这个权限，安卓不允许应用扫描蓝牙设备，列表一定是空的。检查路径：系统「设置 → 应用 → XPrinter → 权限」。
3. 机器是不是在**待机/休眠**？按一下电源键唤醒再搜。
4. 距离拉到几米以内，中间别隔着金属柜、微波炉。
5. 手机蓝牙开关关了再开；还不行就把手机重启——这条听着笨，但能解决相当一部分「列表为空」。

云打印机型不走这条路：它们开机自动联网，用绑定设备号/扫码的方式添加，不需要蓝牙搜索。

## 三、系统蓝牙配对失败

- **先取消旧配对**：系统蓝牙设置里找到这台打印机，点「取消配对/忽略此设备」，然后重新连。残留的旧配对信息经常导致怎么都连不上。
- **配对码**：部分老型号在配对时要求输入 PIN，常见的默认值是 `0000`，具体以你的机型说明书为准。
- **别的手机抢连了**：打印机一般同一时间只接受一条蓝牙连接，先把周围其他已连过它的手机蓝牙关掉。

## 四、显示已连接，但点打印没反应

1. **确认应用里选的连接方式和你实际插的/连的一致**：用数据线就在应用里选 USB，用蓝牙就选蓝牙，别混着来。
2. **换一台占用着打印的应用**：蓝牙通道一次只能被一个应用使用，如果你还开着别的打印或收银应用，先关掉它们。
3. **重新连接一次**：在应用里断开设备再连，很多「假连接」（显示在线但通道已断）就恢复了。
4. 云打印机型检查**设备在线状态**：机器断网时任务会发过去但不打印，看机器屏幕或指示灯确认联网状态。

## 五、走纸正常，打出来是空白

热敏纸只有一面能打。拉开纸仓检查：纸卷装反了就翻个面重装（纸头从打印头那一侧拉出来），再打一张测试。判断纸的小技巧：用指甲快速划纸面，能划出灰黑色痕迹的那一面才是热敏面。

如果两面都划不出痕迹，这卷纸可能不是热敏纸（比如买成了普通收银纸），换了纸再试。

## 六、内容偏移、每张越打越偏

这是标签打印最高频的问题，两步解决：

1. **核对纸张类型**：应用里这个标签模板选的纸张类型（间隙纸/连续纸/黑标）必须和你实际装的纸一致，见[标签模板编辑与打印设置](标签模板编辑与打印设置.md)第一节的对照表。
2. **重新校准**：间隙纸机型按两下电源键，机器会自动走出一张标签完成定位。换过纸卷、换过不同尺寸的纸之后，都要重新校准一次。
3. **按官方流程重走一遍顺序**：装纸 → 校准 → **回到 APP 首页** → 重新点模板 → 弹出「尺寸变更」提示时点确认 → 再编辑打印。先进了编辑页才换纸/装纸，APP 里记的还是旧尺寸，怎么调内容都会错位，详见[标签纸装法与校准](标签纸装法与校准.md)第五节。

## 七、字迹浅、一部分深一部分浅

- 在应用的打印设置里**调高打印浓度**，一次加一档试。
- 浓度拉高还是浅，考虑**纸张问题**：热敏纸受潮、过期都会发浅，换一卷新纸对比。
- 一张纸上深浅不均、有固定位置的浅带，多半是**打印头脏了**，按说明书的指引用棉签蘸酒精清洁打印头，断电操作。

## 八、恢复出厂设置（桌面机型）

软件侧怎么调都不对、又排除了纸张问题，可以把桌面机型恢复出厂再重新配置：**关机状态下同时按住走纸键（FEED）和暂停键（PAUSE）开机**，看到指示灯按「蓝红同亮 → 只剩红 → 蓝灯亮并蜂鸣」的顺序变化后松手。这一组合适用于带按键面板的桌面机型，便携款和不同批次可能不同，动手前以你的机型说明书为准。

恢复出厂会清掉机器里的自定义设置，重新配置后先打一张测试页确认正常。

## 九、以上都试过还不行

剩下的多半和具体机型有关，别继续盲试：

- 到官方站点 `https://www.xprinter.net` 查你的机型页面，说明书和固件说明都在机型下。
- 找购买渠道的售后，把机型、手机系统版本、现象说清楚，售后判断起来会快很多。
- 如果怀疑安装包本身有问题（装不上、闪退），重新下载一份并核对 MD5，见[下载与安装教程](下载与安装教程.md)的版本信息表。
