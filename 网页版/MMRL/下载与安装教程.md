## 一、MMRL 是什么

MMRL 全称 Magisk Module Repo Loader，是一个开源的安卓模块管理工具，作者是 Der_Googler。它本身不是 root 方案，而是装在已有 root 的手机上，让你从各种模块仓库里浏览、安装、更新、卸载 Magisk 模块。它兼容 Magisk、KernelSU（含 KernelSU Next）、APatch、SukiSU Ultra 这几类 root 管理器，界面上没有广告。

适合你的情况：已经在用 Magisk 或 KernelSU，但客户端里找不到模块下载入口、或者想一次管理多个仓库的模块来源。本篇讲怎么把它装上并完成首次设置。

## 二、装之前先确认两件事

1. **手机已经装好一种 root 管理器**（Magisk / KernelSU / APatch / SukiSU Ultra 任一），并且 root 授权正常 —— MMRL 只负责模块仓库与安装流程，不做 root 本身。
2. **系统版本**：网盘里这一版的本地记录标注为需要安卓 5.2 以上（以官方渠道当时显示的要求为准）。另有公开教程称其在 Android 12 至 15+ 上实际可用 —— 一个说的是最低要求、一个说的是实测范围，两者并不矛盾，装之前以官方页面当时显示为准。

## 三、从哪拿安装包

- **官方渠道**：官网 [mmrl.dev](https://mmrl.dev) 的下载页、GitHub 的 [MMRLApp/MMRL](https://github.com/MMRLApp/MMRL) 发布页、Google Play 商店（包名 `com.dergoogler.mmrl`）。版本会一直更新，具体以官方页面当时显示为准。
- **网盘里这一版**：版本 5.31.42，包名 `com.dergoogler.mmrl`，安装包大小 3.18M。这是一份固定的历史版本，与官方最新版未必相同 —— 只想稳定用、不在意追新的话，直接用它即可。

## 四、安装步骤

1. 从上面任一渠道拿到 APK 文件。
2. 手机上点击 APK 开始安装；系统若提示「禁止安装未知来源应用」，按提示为该来源开启允许后重试。
3. 装完打开 MMRL，首次启动会让你选择本机使用的 root 管理器（Magisk、KernelSU、APatch 等），按手机实际情况选。
4. 选完进入主界面，此时仓库列表可能还是空的，下一步就是把模块仓库地址加进来。

从网盘获取的话：打开 [MMRL 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e06fce36d68f)，转存后下载 `MMRL_v5.31.42.apk`，按上面第 2 步安装即可。

装完只是有了工具，模块还得从仓库来 —— 怎么填仓库地址、怎么装第一个模块，见[添加模块仓库与安装模块教程.md](添加模块仓库与安装模块教程.md)。打开模块详情页时，卡片上的按钮与标记各是什么意思，见[模块卡片上的按钮和标记怎么看.md](模块卡片上的按钮和标记怎么看.md)；打不开、检测不到 root 管理器这类问题，见[常见问题与故障排查.md](常见问题与故障排查.md)。
