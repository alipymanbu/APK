## 一、WebUI X 是什么

有些模块的配置项很多（规则开关、路径、参数），写在说明文件里让你手改既麻烦又容易改错。这类模块会自带一个图形配置界面，你点几下就能改完，设置保存在模块自己的配置里。WebUI X 就是 MMRL 提供的这套界面框架，模块开发者用它写出来的配置页，直接跑在 MMRL 里，观感与安卓原生界面接近。

不是每个模块都有配置界面 —— 有没有，看模块卡片上有没有 WebUI 标识（各按钮含义见[模块卡片上的按钮和标记怎么看.md](模块卡片上的按钮和标记怎么看.md)）。

## 二、怎么进配置界面

1. 在仓库或已安装列表里找到该模块的卡片。
2. 卡片上带 WebUI 标识的，**直接点卡片**就会进入它的配置界面。
3. 在界面里改选项，按页面提示保存；涉及模块重新加载的改动，按提示重启手机。

长按卡片可以把它加为快捷方式（配置界面直接出现在桌面上），但**只有模块开发者支持时才会有这个选项** —— 长按没有反应就说明该模块没做适配，不是你操作错了。官方说明见 [mmrl.dev/guide/webuix/shortcuts](https://mmrl.dev/guide/webuix/shortcuts)。

## 三、JavaScript API 开关在哪

配置界面里的一些功能要模块拿到 JavaScript API 权限才能用。这个开关的位置**随版本不同**（官方 FAQ 口径，以官方文档当时显示为准）：

| 版本 | 路径 |
| --- | --- |
| 5.32.43 以上 | 设置 → 模块与权限 → 该模块 → 勾选两个选项 |
| 5.32.43 以下 | 设置 → 安全 → 允许 JavaScript API → 该模块 → 勾选两个选项 |

网盘里这一版是 5.31.42，属于 5.32.43 以下，走第二条路径。官方 FAQ 还标注该选项在部分新版本中已被移除，如果你按上面找不到，以官方 FAQ 页面 [mmrl.dev/guide/faq](https://mmrl.dev/guide/faq) 当时的内容为准。

## 四、界面打不开、点了没反应

先确认模块卡片上确实有 WebUI 标识（没有就是模块本身不带配置页）；有标识却打不开，多半与上面的 JavaScript API 权限或模块自身兼容性有关，排查步骤见[常见问题与故障排查.md](常见问题与故障排查.md)。
