## 一、先看懂卡片上的按钮

MMRL 里每个模块都以一张卡片展示，不同模块的卡片长得不一样 —— 有 WebUI 或动作脚本的模块，按钮更多。按官方文档的图示，各按钮含义如下：

| 按钮 | 作用 | 什么时候出现 |
| --- | --- | --- |
| 动作（Action）按钮 | 运行该模块自带的动作脚本 | 模块提供了动作脚本才有 |
| 更新按钮 | 把模块升到仓库里的新版本 | 检测到新版本才有 |
| 移除按钮 | 卸载该模块（重启后生效） | 已安装的模块 |
| 禁用按钮 | 停用模块但不删除（重启后不再加载） | 已安装的模块 |
| WebUI 图标 | 标识这个模块带配置界面；点卡片进入该界面 | 模块支持 WebUI 才有 |

没带 WebUI 的模块，卡片上就没有最后两项。判断一个模块「装没装、启没启、能不能更新」，看这排按钮就够了。

## 二、反功能标记：详情页里那些「提醒你注意」的标签

部分模块的详情页会带反功能（Anti-Features）标记 —— 类似 F-Droid 的做法，把用户可能介意的特征标出来，供你自己判断要不要装。常见几类：

| 标记 | 含义 |
| --- | --- |
| `Ads` | 含广告 |
| `Tracking` | 会跟踪或上报你的使用活动，哪怕可以关掉 |
| `KnownVuln` | 存在已知安全漏洞 |
| `Obfuscation` | 代码经过混淆 |
| `UnaskedRemoval` | 未经你同意移除应用、权限或其他模块 |
| `NonFreeNet` | 依赖不可更换的闭源网络服务 |
| `NonFreeDep` | 需要闭源组件配合才能工作 |
| `NSFW` | 含不适合公开场合显示的内容 |
| `LLM` | 全部或部分由大语言模型编写 |

完整清单以官方文档 [mmrl.dev/guide/antifeatures](https://mmrl.dev/guide/antifeatures) 为准。看到 `KnownVuln`、`UnaskedRemoval` 这类标记时，装不装由你决定 —— 标记只是把仓库维护者声明的信息摆出来。

## 三、黑名单：哪些模块被限制了

MMRL 官方维护一份模块黑名单（[mmrl.dev/blacklist](https://mmrl.dev/blacklist)），列出被限制的模块与限制动作，页面公开可查。你在 MMRL 里遇到「某个模块搜不到、或装不了」，先去这份名单里对一下，能省下不少排查时间。相关排查见[常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、卡片点进去还有哪些信息

点卡片进入详情页，除了上面这些按钮和标记，你还能看到模块包含的文件明细（APK、服务脚本等）、作者、版本、更新时间；模块页的截图、封面、分类这些展示内容则由仓库维护者自定义。带配置界面的模块，点卡片会直接进它的 WebUI，用法见[WebUI X 配置界面怎么用.md](WebUI%20X%20配置界面怎么用.md)。
