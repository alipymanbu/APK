## 一、MMRL-CLI 是什么

MMRL-CLI 是 MMRL 的命令行版本，作者同为 Der_Googler，以模块形式装进手机，装好后在终端里敲命令就能完成加仓库、装模块、启停模块这些事，效果与在 MMRL 界面里点按钮相同。适合两类人：习惯终端操作、或想写脚本批量管理模块的。它用 Rust 编写、按 MIT 许可发布（作者在 XDA 发布帖中的说法）；帖子显示当时最新版为 v0.3.3（2024 年 6 月），**版本以官方发布页当时显示为准**。

只想日常装几个模块的话，用界面版就够了（见[添加模块仓库与安装模块教程.md](添加模块仓库与安装模块教程.md)）；下面是命令行的用法。

## 二、常用命令

**加仓库**（地址与界面版里填的是同一个）：

```bash
mmrl repo add "https://magisk-modules-alt-repo.github.io/json-v2/json/modules.json"
```

**按名字或 ID 装模块**：

```bash
mmrl install mkshrc
```

**查看模块信息**（装之前先确认它是干什么的）：

```bash
mmrl info mkshrc
```

**搜索模块**：

```bash
mmrl search id node
```

**启用 / 停用 / 卸载**（与卡片上的按钮一一对应，含义见[模块卡片上的按钮和标记怎么看.md](模块卡片上的按钮和标记怎么看.md)）：

```bash
mmrl enable mkshrc
mmrl disable mkshrc
mmrl remove mkshrc
```

**升级 MMRL-CLI 自身**：

```bash
mmrl upself 0.3.3
```

## 三、和界面版怎么配合

仓库地址、模块数据两边是同一套：界面版里加过的仓库，命令行用 `mmrl repo add` 再加一次即可；命令行装的模块，回到 MMRL 界面的已安装列表里同样能看到。习惯「界面里挑、命令行批量执行」的用法也通 —— 先在界面浏览仓库（见[添加模块仓库与安装模块教程.md](添加模块仓库与安装模块教程.md)），把要装的模块名抄下来，再用一条 `mmrl install` 连着装。

命令报错时先确认 CLI 模块本身装好了、手机上有可用的终端环境；模块层面的通病（装完要重启、模块不生效怎么查）与界面版完全一样，见[常见问题与故障排查.md](常见问题与故障排查.md)。
