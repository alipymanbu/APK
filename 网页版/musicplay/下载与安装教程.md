musicplay 是一款安卓手机上的音乐播放器，对应开源项目 RecordEchoes，本文收录的是它的 0.3 版。安装本身不复杂：拿到 APK 后按提示允许安装即可，装好后的第一件事是登录账号，在线功能才能用起来。名字对不上、想搞清来龙去脉的，先看[和RecordEchoes是什么关系](和RecordEchoes是什么关系.md)。

## 一、网盘里这份是哪个文件

官方 0.3 一共发布了 6 个安装包：`arm64-v8a`、`armeabi-v7a`、`universal` 三种架构各有 release 与 debug 两版。网盘里这份的固定信息如下，大小与官方 2025 年 6 月 14 日发布的 arm64-v8a 正式包（release）完全一致，可以直接对照核验：

| 项目 | 值 |
| --- | --- |
| 版本 | 0.3 |
| 大小 | 48.97M（51,345,585 字节） |
| 包名 | `com.ghhccghk.musicplay` |
| MD5 | `AC08F4E898A9421C9FF9C5C922C84E54` |
| 对应官方文件 | `Music_Player-0.3-3-arm64-v8a-release-*.apk` |

几点提醒：

- 近几年的主流安卓手机基本都是 arm64 架构，直接用这份即可；只有很老或特殊的设备才需要 armeabi-v7a 版。
- 文件名带 `debug` 的是开发调试版，体积明显更大（0.3 的 arm64 debug 包约 75M），不建议日常使用。
- 想换用更新的版本（官方已发布到 0.6），去项目 GitHub 仓库的 Releases 页面下载，仓库地址见[和RecordEchoes是什么关系](和RecordEchoes是什么关系.md)。注意 0.6 的安装包比 0.3 多一种 x86_64 架构（给电脑上的安卓模拟器用），手机用户仍然选 arm64-v8a。

## 二、下载与安装步骤

最直接的方式就是上面提示块里的 **musicplay 安装文件资源（夸克网盘）**：转存到自己网盘后把 APK 下载到手机；在电脑上下载的话，用数据线或局域网传输把 APK 移进手机存储再装。

1. 在手机文件管理器里找到下载好的 APK，点开。
2. 系统提示「不允许安装未知来源应用」时，按提示允许当前文件管理器或浏览器安装应用（路径通常是 设置 → 应用 → 特殊应用权限 → 安装未知应用）。
3. 回到安装界面点「安装」，等进度走完。
4. 完成后点「打开」，或从桌面点图标进入。

手机上已装过同包名旧版本时，直接安装会走覆盖升级；如果提示「签名不一致」无法覆盖，把旧版本卸载后再装（官方 GitHub 渠道与其他渠道的包签名可能不同，覆盖不上是正常现象）。

## 三、第一次打开

打开后按提示授予音频/媒体访问权限，本地歌曲列表才有内容；当时点了拒绝也没关系，去手机 设置 → 应用 → musicplay → 权限 里补开即可。

在线搜歌、歌单这类功能需要登录酷狗账号，登录入口与步骤见[怎么登录酷狗账号](怎么登录酷狗账号.md)。装完打不开、闪退的，先对照[闪退与常见问题排查](闪退与常见问题排查.md)过一遍，不用急着重装。
