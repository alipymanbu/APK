# musicplay 歌词与播放设置

> 本篇讲 musicplay 里歌词怎么显示、桌面歌词怎么开，以及倍速、音调、睡眠定时器这些播放设置在哪个版本能用。

歌词相关的能力覆盖同步显示、逐字歌词与桌面歌词三层：播放页带同步歌词，0.6 重构了逐字歌词并重点改进桌面卡拉OK歌词。本文按「0.3 能用什么、0.6 多了什么」来写，网盘里的版本是 0.3，想用后面这些功能要先升级，版本对照见[和RecordEchoes是什么关系](和RecordEchoes是什么关系.md)。

## 一、播放页歌词

0.3 起播放界面就有歌词展示，歌词随播放进度滚动。歌词能不能显示取决于歌源有没有提供歌词；在线功能本身要先登录（见[怎么登录酷狗账号](怎么登录酷狗账号.md)）。匹配不到歌词的歌，播放页就不显示歌词，这属于歌源问题，不是故障。

## 二、逐字歌词与桌面歌词

- **逐字歌词**：0.6 对逐字歌词（KRC 格式，即卡拉OK式的字随歌唱）的解析与显示做了重构。
- **桌面歌词**：桌面歌词功能在早期版本就有；0.6 重点重做了桌面卡拉OK歌词的同步与显示逻辑，如果旧版桌面歌词出现不同步、显示异常，升级通常能解决。

桌面歌词在系统设置里可能还需要「显示在其他应用上层/悬浮窗」权限，弹出提示时允许即可；当时拒绝了就去 设置 → 应用 → musicplay 里补开。

## 三、倍速与音调（0.6 新增）

0.6 在播放器界面加了播放速度入口，点开是速度（Tempo）与音调（Pitch）调节对话框，并且可以锁定两者同步变化——比如 1.25 倍速时音调跟着升，避免变速不变调或变调不变速的别扭感。0.3 没有这个入口，播放速度是固定的。

## 四、睡眠定时器（0.6 新增）

0.6 加了睡眠定时器，到点自动停止播放，睡前听歌用得上；它支持远程播放控制，从耳机、通知栏等处操作定时也生效。0.3 没有内置定时，只能手动暂停。

## 五、其他值得知道的设置项

| 功能 | 版本 | 说明 |
| --- | --- | --- |
| 歌词分享 | 0.6 新增 | 把当前歌词（可带歌曲信息）分享出去 |
| 音量均衡（ReplayGain） | 0.6 新增 | 不同歌曲之间音量忽大忽小时可以打开 |
| ALAC 解码 | 0.6 新增 | 播放苹果无损格式（.m4a 封装的 ALAC）的本地文件 |
| 小米「音乐岛」分享 | 0.6 新增 | 小米机型上把正在播放的歌曲分享到系统音乐岛 |
| 系统媒体控件 | 0.6 改进 | 通知栏/锁屏播放控件的行为优化 |
| 设置界面 | 0.3 起持续扩充 | 0.3 已有基础设置，后续版本越加越多 |

本地音乐播放两个版本都支持：把音频文件放进手机存储，按提示授予媒体权限后即可在应用内播放。本地文件播不出来、在线功能异常的排查步骤，统一见[闪退与常见问题排查](闪退与常见问题排查.md)。
