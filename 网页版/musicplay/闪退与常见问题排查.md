# musicplay 闪退与常见问题排查

> 本篇汇总 musicplay 装不上、打不开、登录异常、歌词不显示这几类问题的排查顺序，多数问题按步骤走一遍就能定位。

本文按问题类型分节，每节给的是排查顺序而不是结论：先看现象在哪一节，再从上往下试。涉及版本差异的地方会注明是 0.3 还是 0.6 的行为，两个版本的关系见[和RecordEchoes是什么关系](和RecordEchoes是什么关系.md)。

## 一、安装包装不上

1. **提示「签名不一致」**：手机里已有一个同包名的旧版本，且两个包签名不同。卸载旧版后再装即可；覆盖安装只适用于签名一致的同包名包。
2. **提示解析失败/包损坏**：下载过程可能出错。先校验文件完整性——网盘这份 0.3 的 MD5 是 `AC08F4E898A9421C9FF9C5C922C84E54`，用手机文件管理器的校验功能或电脑上的 `certutil -hashfile 文件名 MD5` 命令比对；对不上就重新下载，对得上还装不上再往下查。
3. **存储空间不足**：安装包 48.97M，加上安装过程的临时占用，手机剩余空间最好留出 1GB 以上。

## 二、打开就闪退

1. **先确认系统版本**：0.6 版要求安卓 10 及以上（官方源码最低要求 minSdk 29）；0.3 没有官方标注的最低系统版本，如果你在很老的系统上装 0.3 闪退，先升级系统或改用 0.6 试试。
2. **清除数据重装**：官方在 0.6 的发布说明里明确建议「如遇问题建议清理数据或重新安装」，0.3 遇到诡异问题也可以照做——设置 → 应用 → musicplay → 存储 → 清除数据，不行就卸载重装。
3. **还是闪退**：记下复现步骤（打开就闪，还是点某个功能才闪），到项目仓库的 Issues 区看有没有相同反馈。

## 三、登录与在线功能异常

1. **反复登录不上**：先确认账号密码本身能正常登录酷狗官方渠道；官方渠道也登不上就是账号问题，改密码后再试。
2. **登录界面一直转圈**：查手机的联网管控——设置 → 应用 → musicplay 里确认「允许联网」「允许后台联网」都开着，手机管家类应用也可能拦它的联网请求，加入信任名单再试。扫码登录的具体方式见[怎么登录酷狗账号](怎么登录酷狗账号.md)。
3. **登录成功但点用户信息/个人页就闪退**：早期版本的已知现象（官方在 2025 年 7 月初修复，见 [Issue #1](https://github.com/ghhccghk/RecordEchoes/issues/1)）。临时办法：把应用完全退出、关掉后台再进；仍闪退就升级到 0.5 及以后的版本。
4. **登录成功但搜不到歌/放不出歌**：第三方客户端依赖上游接口，接口变动时个别功能会暂时失效，这不是你操作的问题。先换个网络（Wi-Fi/流量互换）排除本地网络因素，再确认应用是否已升到最新版。
5. **登录时闪退（仅限 0.2 及更早）**：官方在 0.3 修复了「userid 超过 Int 上限导致崩溃」的问题，遇到就升级到 0.3 或更高版本；网盘里这份 0.3 已包含该修复。

账号登录的具体步骤与换号方法，见[怎么登录酷狗账号](怎么登录酷狗账号.md)。

## 四、歌词不显示或不同步

1. **在线歌没歌词**：先确认已登录；再确认这首歌在官方渠道本身有歌词——歌源没有歌词，客户端就显示不出来。
2. **桌面歌词不出现**：检查悬浮窗权限（显示在其他应用上层）是否已授予，路径：设置 → 应用 → musicplay → 显示在其他应用上层。
3. **逐字歌词不同步**：0.6 重构过逐字歌词解析，旧版不同步优先升级；升级后仍不同步的多是特定歌源的数据问题。

歌词相关的功能对照（哪些版本有什么）见[歌词与播放设置](歌词与播放设置.md)。

## 五、本地歌曲播不出来

1. **列表是空的**：首次启动时拒绝了媒体权限。去 设置 → 应用 → musicplay → 权限，把音频/媒体相关权限补开，再刷新列表。
2. **某个文件播放失败**：确认文件本身能被其他播放器播放；个别格式（如 0.6 才加入解码的 ALAC）在 0.3 上不支持，属于版本能力差异。
3. **播放中途停止**：检查系统是否对该应用做了电池限制，把 musicplay 加入电池优化白名单或允许后台运行。

以上都试过仍未解决的，带着「版本号 + 复现步骤 + 现象」到项目仓库反馈，比笼统的「用不了」更容易得到回复。
