## 一、CatShare 是什么

CatShare 是一款开源的安卓文件互传工具，包名 `moe.reimu.catshare`，走的是国内手机厂商「互传联盟」的协议：用蓝牙发现对方，再用 WiFi 直连把文件传过去，全程不经过服务器、不消耗流量。它主要解决一件事——你的手机不是小米 / OPPO / vivo（比如类原生系统、海外版机型），但想和这些品牌的手机互传文件。

你适合它，如果：

- 手机是类原生 / 海外机型，自带互传功能和国内品牌对不上；
- 你想要一个没有广告、代码开源（MIT 许可）的互传工具；
- 你只需要「收发文件」这一件事，不需要账号、云盘那套。

## 四、安装步骤

1. 把 APK 传到手机上（网盘下载、数据线、聊天工具发过去都行）。
2. 点击 APK 开始安装。若是文件管理器或浏览器下载的包，系统会要求你先允许「安装未知应用」，按提示给那个来源开一下权限，装完可以关掉。
3. 装完打开，首次启动会依次请求权限，见下一节。

安装失败、点了没反应的处理见 [连接失败排查方法.md](连接失败排查方法.md)。

## 五、首次运行要给的权限

CatShare 的核心能力靠蓝牙 + WiFi + 定位三件套，缺一个都会直接影响使用：

| 权限 | 不给会怎样 |
| --- | --- |
| 蓝牙（含附近设备） | 对方搜不到你，你也发现不了对方 |
| 位置（定位服务） | 安卓系统规定：不给定位就扫不到周边蓝牙 / WiFi 设备，必须在系统设置里把定位总开关也打开 |
| 通知 | 传输在后台进行时看不到进度提醒 |
| WiFi 连接 | 建立直连传输通道需要它 |

如果要走「发送文件」这条路，还需要额外配置 MAC 地址（Shizuku 或手动输入），步骤见 [开启Shizuku发送教程.md](开启Shizuku发送教程.md)；只想先收文件的话，给完上面几项就能用，见 [接收文件操作步骤.md](接收文件操作步骤.md)。

## 六、系统要求

- F-Droid 页面标注：当前上架版本要求 **Android 10 及以上**，支持 `arm64-v8a`、`armeabi-v7a`、`x86`、`x86_64` 四种架构（截至检索时，以 F-Droid 页面当时显示为准）。
- 网盘里这份 1.4 版的最低系统要求，以你手机安装时的提示为准；装不上时先确认系统版本，再考虑换渠道拿别的版本。

## 七、以后怎么升级

GitHub Release 与 F-Droid 版本签名一致，所以从哪个渠道升都行、互相之间可覆盖安装：

- **走 F-Droid**：装个 F-Droid 客户端，它会提示该应用的更新，点一下就升；
- **走 GitHub**： Releases 页拿新包，确认包名仍是 `moe.reimu.catshare`、版本号不低于当前安装的，直接点安装覆盖。

升级后如果发送突然失灵，多半是 Shizuku 授权要重新给一次（见 [开启Shizuku发送教程.md](开启Shizuku发送教程.md)），不是包有问题。
