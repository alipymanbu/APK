## 一、首页能做什么

打开 palipali 后不需要登录就能直接用。首页默认是推荐流，按热门程度排当前的动漫作品，直接点封面就能进详情页；往下翻会按题材分类（热血、恋爱、搞笑这类）分组陈列，想漫无目的地找番就往这里翻。

除了推荐流，首页还有两个常用入口：

- **搜索框**：在页面顶部，明确知道要看什么时用它最快，下一节细说。
- **榜单入口**：在顶部搜索框附近，通常是一个火苗样式的图标，点进去是热播榜（动漫、电视剧、电影、综艺等分类排行）。不同版本的入口位置可能略有差异，找不到就在首页顶部区域找一找。

## 二、搜一部想看的番

搜索的正确打开方式：

1. 点首页顶部的搜索框，输入番剧名称。支持中文原名，部分版本也认别名或拼音缩写；记不清全名就输入最有辨识度的两三个字。
2. 在结果列表里按封面和年份认准你要的那部（同名翻拍不少，注意别点错）。
3. 进入详情页后，先看简介和剧集列表确认是你要的版本，再点第一集开看。

搜不到结果时先换个关键词再试（全名 → 简称 → 别名）；换了几个说法还是搜不到，那部作品可能就是不收录，属于内容覆盖的问题而不是你操作错了，具体见 [打不开与加载失败怎么办.md](打不开与加载失败怎么办.md) 的「搜不到想看的番」一节。

## 三、播放页的操作

进入播放页后，点一下屏幕中央会呼出控制栏，常用的操作都在这里：

| 你想做的事 | 怎么做 |
| --- | --- |
| 快进 / 快退 | 拖动底部进度条；看长番时直接拖比按倍速跳更准 |
| 换一集 | 在控制栏里点「选集」（或剧集列表），点对应集数即切换 |
| 调清晰度 | 控制栏里的画质选项，卡顿时切到「流畅」，网络好再用「高清」 |
| 看别人的评论 | 播放画面上会滚动显示其他观众的评论，部分版本支持发送弹幕参与讨论 |
| 全屏 / 退出全屏 | 点全屏按钮，或旋转手机自动切换 |

画质切换的取舍和缓存的关系，在 [离线缓存与画质设置.md](离线缓存与画质设置.md) 里有更细的对照。

## 四、收藏与追更

追番主要靠这三个机制：

- **收藏**：在播放页或详情页点收藏按钮，之后从「我的收藏」（或书架/追番列表）进入，不用再搜索。
- **进度记忆**：你看过的每一集会自动记进度，下次打开从上次的位置继续，不需要手动标记。
- **更新跟进**：正在连载的番更新后，重新进入详情页或收藏列表就能看到新的一集；热门新番一般按更新节奏陆续上线，上线时间以应用内实际显示为准。

刚装好还没用过、想先把几部常看的缓存到离线，可以先看 [离线缓存与画质设置.md](离线缓存与画质设置.md)；应用打不开、加载转圈的故障排查在 [打不开与加载失败怎么办.md](打不开与加载失败怎么办.md)。
