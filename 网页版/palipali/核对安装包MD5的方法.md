# 核对安装包MD5的方法

> 本篇讲怎么核对手里这份 palipali 安装包的 MD5 和包名，用来确认「下载完整」和「是不是同一份包」，手机和电脑的操作都有。

## 一、什么情况下需要核对

palipali 同名安装包多、下载链路又经过网盘转存，出现下面任一情况都值得核一次：

- 安装时报「解析包错误」「安装包损坏」——先确认文件没下坏。
- 想确认手机里已装的、网盘里的、别处看到的是不是**同一份包**（palipali 变体多，光看名字靠不住）。
- 从别的地方拿到一个 apk，想知道和网盘里这份是不是一个东西。

本文这份安装包的基准值是：

| 项目 | 基准值 |
| --- | --- |
| MD5 | `AF930E7C9C01AD5075E41D47026AFB95` |
| 包名 | `com.mhqaa.comic` |
| 体积 | 23.85M |

核对结果和 MD5 **逐字符完全一致**才算同一份包；大小写不敏感（`af93…` 与 `AF93…` 等价），但中间任何一位不同都不行。

## 二、手机上核对 MD5

安卓上系统自带功能一般不直接显示 MD5，常用两条路：

- **带哈希校验的文件管理器**：不少第三方文件管理器支持长按文件 →「属性」或「详情」→ 查看 MD5。你手机自带文件管理器若有这一项，直接用。
- **专用的校验类小工具**：应用商店里搜「MD5 校验」能找到一批小工具，选中 apk 文件即可算出校验值。挑不带广告弹窗、权限要求少的。

算出来的值与第一节基准值比对即可。手机上不方便操作时，也可以把 apk 传到电脑上核（下一节），核完再传回手机装。

## 三、电脑上核对 MD5

Windows 自带命令行工具就能算，不用装任何软件：

```powershell
certutil -hashfile "C:\Users\你\Downloads\palipali_v8.7.5.apk" MD5
```

把路径换成你的实际文件位置，回车后输出里第二行就是 MD5 值（空格会被去掉）。macOS / Linux 用：

```bash
md5 palipali_v8.7.5.apk
```

在电脑上核对还有一个好处：安装包是先在电脑上拿到的，**核对通过再传手机**，避免把坏包传来传去。

## 四、核对不通过怎么办

- **和基准值不一致**：文件下载不完整，或者根本是另一份包。删掉后重新从 palipali 安装文件资源（夸克网盘）获取：[https://pan.quark.cn/s/13c2672ecdca](https://pan.quark.cn/s/13c2672ecdca)，下完再核一遍。
- **MD5 一致但包名不同**：不成立——MD5 一致则文件逐字节相同，包名必然相同。如果你看到「MD5 一样但名字不一样」，那是显示名不同，以包名为准。
- **MD5 一致、体积对不上**：同理不会发生，两者一致说明就是同一份文件，放心安装。

## 五、顺手把包名也核了

MD5 证明「文件没坏、是同一份」，包名则回答「它是哪个应用」——判别 palipali 各变体时包名比名字可靠。查看方式：

- **手机**：部分文件管理器点开 apk 详情页会显示包名；安装前的系统弹窗有时也会列出应用名与包名。
- **电脑**：装一个查看 apk 信息的工具（如 APK 信息查看器），把 apk 拖进去就能读出包名 `com.mhqaa.comic`。

包名和版本号在「这份包到底是谁」上的意义，见 [版本更新与轻量版区别.md](版本更新与轻量版区别.md)；核对通过后的安装步骤见 [下载与安装教程.md](下载与安装教程.md)。
