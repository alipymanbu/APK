## 一、先弄清楚这份安装包是什么

Microsoft Teams 是微软的团队协作应用，聊天、音视频会议、文件共享都在一个应用里。手机端安卓版由微软（中国）有限公司在中国区署名发布，商店里的包名是 `com.microsoft.teams`。网盘里这份安装包的实测信息如下，网上能搜到的永远是官方最新版，两者不一定是同一个版本：

| 项目 | 数值 |
| --- | --- |
| 版本号 | 14161.0.0.2025022204 |
| 包名 | com.microsoft.teams |
| 安装包大小 | 358.87 MB |
| MD5 | `90F65BA258253AA73F0095964B7682C0` |

三点补充：

- 358.87 MB 在办公协作类应用里算大的，属正常现象——它把会议、通话、聊天几个模块都打进了一个包；下载完先看一眼文件大小，明显对不上就重新下载一次；
- 版本号里的 `2025022204` 表示这份包是 2025 年 2 月构建的，比官方最新版旧。用着正常就不必急着换，碰到的问题在官方新版里修了再考虑升级；
- 官方对安卓系统的要求是「支持最近 4 个大版本」（以官方系统要求页面为准）；本地采集记录里这份包标注的是安卓 5.2 以上。2018 年之后的机器基本都在范围内，太老的机型装最新包可能打不开。

## 二、从夸克网盘获取安装文件

1. 打开 [Teams 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b7cd2c459bf3)；
2. 登录夸克账号后，把文件转存到自己的网盘（先转存再下载，比直接下载稳定）；
3. 在自己的网盘里找到该文件，下载到手机存储；
4. 下载完核对文件大小，358.87 MB 左右为正常。

## 三、安装步骤

1. 在手机上点开下载好的 `Teams_v14161.0.0.2025022204.apk`；
2. 系统提示「不允许安装未知来源应用」——这是安卓对非商店安装的正常拦截，不是文件有问题。按你的品牌放行一次：
   - 小米 / 红米：设置 → 隐私保护 → 特殊权限 → 安装未知应用，允许你用来打开安装包的那个文件管理器；
   - 华为 / 荣耀：设置 → 安全 → 更多安全设置 → 安装外部来源应用；
   - 其它品牌：安装弹窗里点「设置」，在跳转的页面允许该来源；
   - 各品牌系统版本不同，入口名称可能有出入，认准「安装未知应用 / 外部来源」这个关键词即可；
3. 回到安装界面点「安装」，等进度走完；
4. 点「打开」，首次启动会让你选账号登录，具体见 [登录与账号管理.md](登录与账号管理.md)。

## 四、首次启动后先确认这几项权限

登录过程中应用会逐个请求权限，建议当场给到位，省得开会时才发现缺：

| 权限 | 用途 | 不给的后果 |
| --- | --- | --- |
| 麦克风 | 会议与通话里说话 | 别人听不见你 |
| 相机 | 视频会议、拍照共享 | 只能语音 |
| 通知 | 收新消息与会议提醒 | 错过消息和会议提醒 |

权限给错了也可以事后补：系统设置 → 应用 → Teams → 权限，逐项改。装完发现消息不提醒的，多数是通知权限和厂商省电策略的事，见 [收不到通知怎么排查.md](收不到通知怎么排查.md)。

## 五、覆盖安装与升级

- 包名相同（都是 `com.microsoft.teams`）的安装包可以直接覆盖安装，聊天记录、已登录的账号都在，不用重新设置；
- 想检查更新：应用内点头像 → 设置 → 关于，能看到当前版本；
- 用一段时间后存储会涨，是聊天图片和缓存在积累：系统设置 → 应用 → Teams → 存储 → 清除缓存能压回去，账号和聊天记录不受影响；
- 重装不丢服务端的数据，但会丢本地未同步的部分；退出登录前先想清楚工作账号能不能自己重新登进去（单位账号通常要连单位网络或验证）。
