# Teams 加入会议的几种方式

> 这篇讲手机上进 Teams 会议的几条路：点邀请链接、以访客身份加入、用会议 ID，以及卡在大厅时的处理。

## 一、点邀请链接加入（最常用）

别人给你发了会议邀请（邮件、聊天消息、日历日程里的链接），这是最顺的一条路：

1. 点邀请里「加入」旁边的链接（旧邀请显示为「立即加入会议」，新邀请直接显示完整网址，作用一样）；
2. 手机已装 Teams 的话，会自动跳进应用；没装会先被带去应用商店——装好后回到邀请里再点一次链接即可；
3. 在预加入屏幕里关掉/打开麦克风和摄像头，点「立即加入」。

两个可用的细节：

- 会议开始前最多 15 分钟就能先进预加入屏幕，用来试麦克风和摄像头，这个阶段进去不会打扰别人；
- 不装应用也能进：链接在浏览器里打开时选「在此浏览器上继续」，用 Microsoft Edge 或 Google Chrome 就能入会——这是 Teams 网页版的入会方式，适合借别人手机临时开个会、不想装应用的场景。

## 二、没有账号：以访客身份加入

不登录也能进别人的会议，手机端操作：

1. 点邀请链接打开 Teams 应用；
2. 允许 Teams 访问麦克风（不给的话别人听不见你）；
3. 点「以访客身份加入」；
4. 输入你的名字，点「加入会议」。

进会后你名字旁边会带个标签，别人一看就知道你怎么来的：

| 你的进入方式 | 名字旁的标签 |
| --- | --- |
| 只输了个名字 | 未验证 |
| 输了邮箱并通过一次性验证码 | 电子邮件已验证 |
| 登录了 Microsoft 账号 | 外部 |

## 三、用会议 ID 和密码加入

链接丢了或点不开，但手里有会议 ID 和密码（都在邀请邮件顶部或日历的会议详情里）：

1. 打开 Teams，进「会议」标签页；
2. 选「使用 ID 加入」；
3. 输入会议 ID 和密码，加入。

## 四、卡在大厅怎么办

有些会议开了大厅（等待室）：你点加入后进不去，要在里面等组织者放行。

- 等就行，组织者会收到「有人在大厅等候」的提醒，点「允许」你才进得去；
- 30 分钟内没人放行，你会被移出大厅——重新点一次邀请链接再试；
- 一直进不去还有一种可能：组织者的管理员策略要求参会者先验证，这时应用会让你输邮箱收一次性密码，或直接要求用授权账号登录，照提示走即可。

登录了账号再进会，能用的会议功能比访客多（比如会后聊天记录），所以常开会的建议先登录——登录相关见 [登录与账号管理.md](登录与账号管理.md)。进了会之后怎么共享屏幕、发文件，见 [聊天通话与文件共享.md](聊天通话与文件共享.md)。
