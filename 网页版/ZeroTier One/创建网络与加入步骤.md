## 一、整体流程是三步

ZeroTier 的组网分「网页端管理」和「设备端加入」两块，缺一不可：

1. 在官网控制台**注册账号并创建网络**，拿到一串 16 位的 Network ID；
2. 手机 App 里**输入这串 ID 加入**；
3. 回到控制台**勾选授权**这台新设备 —— 不授权，手机就一直连不上。

只做前两步就以为通了，是新手最常见的翻车点：加入 ≠ 通，授权才是开关。

## 二、网页端：注册并创建网络

1. 打开 [my.zerotier.com](https://my.zerotier.com/) 注册账号（免费个人用途可以直接用，无需绑卡；账号方案的设备数、网络数限制以 [官网定价页](https://www.zerotier.com/pricing/) 当时显示为准）。
2. 在 Networks 列表页点 **Create A Network**。系统会生成一个随机 ID 与随机名字的虚拟网络。
3. 点进这个网络的详情页，复制那串 **Network ID** —— 16 位十六进制，形如 `d5e04297a16fa690`。这是手机加入时唯一要填的东西，先留着。

顺手能把网络名改成你认识的名字（比如「家里内网」），其余设置保持默认就能用，先别动。

> 官网目前有新旧两套控制台：新版在 [central.zerotier.com](https://central.zerotier.com/)，旧版（Legacy Central）就是上面的 my.zerotier.com。两套里创建网络和授权设备的入口名称略有差别（新版叫 Member Devices，旧版叫 Members），操作逻辑完全一样，本文按旧版写。你用哪套都行，别一半操作在新版、一半在旧版来回切。

## 三、手机端：加入这个网络

1. 打开手机上的 ZeroTier One（还没装先看 [下载与安装教程.md](下载与安装教程.md)）。
2. 点主界面右上角的 **+**，把 Network ID 粘进去。
3. 需要调 DNS 的话，切到 **Network DNS** 或 **Custom DNS** 标签填；不确定就留空不动。
4. 点 **Add Network**，回到主界面确认这个网络旁边的**开关是打开的**。
5. 系统弹 VPN 请求时点允许。

做完这一步，手机已经「申请」进网络了，但状态还不会正常 —— 网页端控制台的成员列表里会冒出一条待处理的新设备，状态是未授权。

## 四、网页端：授权这台手机

回到刚才没关的控制台页面，刷新后在成员列表里找到刚加入的那台设备，认设备的办法：

- 列表里的 **Address** 是个 10 位地址，与手机 App 底部状态栏显示的那个地址一模一样，对上号就是它；
- 也可以先给它起个备注名（比如 `phone`），以后好认。

然后勾上它的 **Auth?** 复选框（新版控制台是在设备右侧的三点菜单里点 **Authorize**）。授权完成后，手机那端立刻从「拒绝访问」变成正常连接，App 底部状态显示 Online。

## 五、几条要记住的规则

- **只有被授权的设备能通信。** 即使别人知道了你的 Network ID，加入后不经你授权也进不来 —— 这是 ZeroTier 的基本安全模型。
- **每台设备有两套身份**：16 位的 Network ID 属于「网络」，10 位的地址属于「设备」。别把设备地址当成 Network ID 填进加入框。
- **免费个人版的设备数与网络数有限制**（当前为 10 台设备、1 个网络，以官网定价页为准），成员列表里只算已授权的设备。
- 手机换了网络环境（Wi-Fi 切流量）一般会自动重连，不需要重新加入；真连不上时对照 [常见问题与解决办法.md](常见问题与解决办法.md) 排查。
