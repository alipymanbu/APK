## 一、主界面：一屏看懂

打开 App，你能看到的东西就三样：

| 位置 | 内容 | 你要关注的 |
| --- | --- | --- |
| 网络列表 | 你加入过的网络，每个带一个开关 | 开关开着才连；点网络名进详情 |
| 底部状态栏 | 本机的 10 位节点地址 + 连接状态 | 状态是 `Online` 才算在线 |
| 右上角 `+` | 加入新网络的入口 | 填 16 位 Network ID |

底部那个 10 位地址（Node ID）是这台手机在全球的设备身份 —— 网页端控制台要你「认人」时，对的就是它。它和 16 位的 Network ID 是两回事，别填混。

网络旁的开关关掉 = 断开这个网络（但不退出）；手机系统里也会相应撤掉那条 VPN 连接，通知栏的 VPN 图标会消失，这是正常现象。

## 二、网络详情里能改什么

点列表里的某个网络进详情，你会碰到两类设置：

**DNS。** 分 **Network DNS** 和 **Custom DNS** 两个标签。前者让网络管理员在控制台下发的 DNS 生效，后者是你手填一个自己指定的 DNS 地址。只有管理员允许你配置 DNS 时这些才起作用；自己组的网，不折腾就都留空。

**连接信息。** 里面能看到这台设备在该网络里分到的虚拟 IP（形如 `10.x.x.x`）。这个 IP 就是别的设备访问你时要用的地址，忘了可以回网页端控制台的成员列表里查（那里显示每个成员的 Managed IP / ZT IP）。

一个已知别扭之处：**加入网络之后，部分设置改不了** —— 想改（比如换 DNS）得先删掉这个网络再重新加入一次（见下一节）。

## 三、删除网络

主界面上**长按**那个网络 → 点 **Delete**，它就从列表里消失，手机退出该网络。这只影响本机：网页端控制台里你的成员记录还在，下次用同一个 Network ID 重新加入、重新授权（或沿用之前的授权）即可恢复。

想彻底不再接入某个网络，除了在手机上删掉，也建议顺手去控制台把它取消授权，两边都清干净。

## 四、连接测试：确认真的通了

App 显示 Online 只代表「本机在网里」，两台设备互通还得测：

1. 在网页端控制台的成员列表里，记下**另一台设备**的虚拟 IP（Managed IP）。
2. 用能 ping 的设备去 ping 这个地址。电脑上：

```bash
ping -n 3 10.147.17.101
```

（把 `10.147.17.101` 换成对方真实的虚拟 IP；Linux / macOS 把 `-n 3` 换成 `-c 3`。）

3. 三个包都回、丢包 0%，就通了。此后你访问那台设备上的服务（远程桌面、SMB 共享、监控后台等），直接用这个 IP 即可。

ping 不通的话按 [常见问题与解决办法.md](常见问题与解决办法.md) 逐条排，多半是授权没勾、开关没开、或两边不在同一个网络里。通了但延迟持续几十上百毫秒、还来回飘，那是连接走了中继，判断与提速见 [连接慢或延迟高怎么排查.md](连接慢或延迟高怎么排查.md)。

## 五、日常使用的两个习惯

- **让系统别杀它。** 手机的省电策略会清理后台进程，被清掉后 VPN 断开、虚拟 IP 也暂时失效。把 ZeroTier One 加入电池优化白名单（各品牌手机叫法不同，常见在「应用启动管理 / 省电策略」里设为允许后台运行），需要长期在线时尤其重要。
- **连不上先看状态栏。** `Online` 才是连着；显示别的状态，回 [创建网络与加入步骤.md](创建网络与加入步骤.md) 检查加入与授权这两步。
