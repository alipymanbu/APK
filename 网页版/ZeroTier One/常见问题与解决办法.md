## 一、加入了网络，但显示拒绝访问 / 通不了

**症状**：App 里网络开关开着，网页端成员列表状态却是未授权，或者能连上但 ping 不通别的设备。

**原因与处理**：设备加入只是「举手报名」，你还没在控制台**勾选授权**。去网页端成员列表找到这台设备（Address 与手机底部状态栏的 10 位地址一致），勾上 **Auth?**（新版控制台是三点菜单 → Authorize）。授权一完成，手机端立刻恢复正常。

如果列表里根本看不到这台设备 —— 你多半填错了 Network ID 加进了别的网，或加入时网络选错了，回 [创建网络与加入步骤.md](创建网络与加入步骤.md) 核对那 16 位 ID。

## 二、状态一直不是 Online，或用着用着断了

按顺序查三处：

1. **开关**：主界面网络旁的开关是否开着（手动关过、或 App 被系统重启后有时会停在关的状态）。
2. **VPN 权限**：系统设置里 ZeroTier 的 VPN 权限是否还在；被清理数据后要重新允许一次。
3. **后台被杀**：国产手机的省电策略激进，App 一被清后台，连接就断。把 ZeroTier One 加入电池优化 / 自启动白名单（详见 [手机端界面与连接测试.md](手机端界面与连接测试.md) 第五节）。

另外，Wi-Fi 和流量之间切换的瞬间会断几秒，等它自己重连即可，一般不用管。长时间不通时先关再开一次那个网络开关，等于强制重连。

## 三、点了加入，却弹「无法建立 VPN 连接」

**原因**：安卓同一时刻只允许**一条** VPN 连接。你手机上如果开着别的 VPN 或者「私人 DNS + 加速器」类工具，ZeroTier 抢不到这条通道。

**处理**：先把其他 VPN 断开，再打开 ZeroTier 的网络开关。需要两者并存的场景基本无解 —— 这是系统限制，不是这个 App 的 bug。

## 四、设备数超了 / 加不进新设备

免费个人版有设备数和网络数上限（当前为 10 台设备、1 个网络，以 [官网定价页](https://www.zerotier.com/pricing/) 当时显示为准）。注意**只有已授权的成员占名额**，所以腾位置的正确做法是把不用的设备取消授权（Deauthorize），而不是删掉整个网络。设备很多时再考虑升级账号方案。

## 五、忘了 Network ID 或节点地址去哪找

- **Network ID**：网页端控制台的网络详情页顶部，随时可复制。
- **本机节点地址（10 位）**：手机 App 底部状态栏；电脑端在托盘 / 菜单栏控制面板左侧。
- **各设备的虚拟 IP**：控制台成员列表里的 Managed IP / ZT IP。

这三样最好加网络时就记下来，排错时全靠它们对号。

## 六、换了 DNS 或网络后行为怪异

加入网络后想改 DNS 却改不动 —— 是已知限制：**得删除网络再重新加入**，加入时在 DNS 标签里填新的（长按 → Delete，见 [手机端界面与连接测试.md](手机端界面与连接测试.md) 第三节）。重新加入后如果设备被当成新成员，回控制台确认它的授权状态。

公司 / 校园网环境里还可能遇到：网络能 Online 但业务不通，那是对方出口防火墙拦了虚拟 IP 的端口 —— 这种要改的是目标机器上的防火墙规则，不是手机端设置。

## 七、安装阶段的疑难

装不上、装完打不开的问题（系统拦「未知来源」、包与表里的 MD5 对不上、系统版本低于 5.2 等），在 [下载与安装教程.md](下载与安装教程.md) 里都有对应处理。
