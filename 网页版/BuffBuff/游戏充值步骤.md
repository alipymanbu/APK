## 一、充值前的准备

- **游戏内玩家 ID / UID**：直充按 UID 打点数，全程不需要你的账号密码。UID 在游戏内的个人资料页或设置页能查到，不同游戏位置不同；
- **一个能收信的邮箱**：官方下单口径要求填 User ID 和邮箱，充值完成后会有邮件通知；
- **可用的支付方式**：支持信用卡 / 借记卡 / 预付卡、Google Pay、PayPal、支付宝等主流渠道，具体可选项以结算页实际显示为准。

要不要注册账号？官方口径是**游客也能充值**，UID 和邮箱填对就能下单；登录账号（Google 或 VK）的价值在于同步订单、积分与优惠券记录。

先把 UID 抄下来再走充值流程，能避免中途切出去出错。

## 二、充值六步

1. 打开 app，进入充值商品目录（首页顶部的 Top-up 或分类入口）；
2. 选游戏：PUBG Mobile UC、Free Fire 钻石、Mobile Legends、原神创世结晶、崩坏：星穹铁道、绝区零、Valorant、暗区突围：无限、三角洲行动、荒野乱斗、Robux、Steam 钱包等都有专区，FC 26 等主机、PC 游戏也在列（覆盖范围以 app 内为准）；
3. 选档位：每档对应固定数量的点券或钻石，商品页会标注面值、适用区域与注意事项；
4. 填玩家 UID / 玩家 ID，**填完核对一遍**——UID 填错，点数会充进别人的账号，这是充值出错最常见的原因；同一页还要填接收通知的邮箱；
5. 确认订单：核对价格、折扣、积分抵扣与优惠券，能叠加的优惠按页面提示勾选；
6. 支付，等 app 内出现到账通知，再去游戏内的邮箱或背包核对。

## 三、积分与优惠券怎么用

- **Buff Points**：官方口径为 100 积分约抵 1 美元，消费后自动累积，结算时可勾选抵扣，也能在 app 内兑换免费游戏内物品；
- **新用户首单折扣**：官方口径最高 55% off（以 app 内活动页实时显示为准）；
- **app 端更便宜**：官方帮助页说明，手机 app 端下单的价格比网页端更低；
- **优惠券与活动**：优惠券在订单确认页领取或输入，注意有效期与适用范围；官方还常有月度抽奖、专属礼包等活动。

## 四、到账与未到账

- 充值成功的标志：app 内订单状态变为已到账，游戏内收到对应点数；
- 订单显示「处理中」属正常，等通知即可；
- 长时间未到账：先核对订单里填的 UID 是否与游戏内资料页一致，再确认游戏服务器是否在维护，最后走 app 内客服并提供订单号。分情况的完整排查与退款口径见[充值未到账怎么办](充值未到账怎么办.md)。
