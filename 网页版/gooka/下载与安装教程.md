Gooka（介绍页里也写作 gooka、Gookaai）是一款安卓端的 AI 角色聊天应用，打开首页点角色就能开始对话；多数介绍页称登录是可选项，个别版本可能有不同要求。本篇以 2026-09-23 采集的 1.1.3 版安装包为基准，装好之后怎么用，见[使用入门与聊天技巧](使用入门与聊天技巧.md)。

## 一、安装前先确认三件事

| 检查项 | 要求 | 说明 |
| --- | --- | --- |
| 系统版本 | 安卓 5.2 及以上（安装包标注口径） | 系统过旧时安装容易报解析错误 |
| 存储空间 | 预留 100MB 以上 | 安装包 27.27M，装完还要留出数据与缓存空间 |
| 安装权限 | 允许安装未知来源应用 | 从浏览器或文件管理器装包时系统会拦一次，按提示放行即可 |

## 二、取安装包

1. 打开 [Gooka 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d30f0dfd97c0)，先转存到自己的网盘，再从网盘下载到手机；也可以先下到电脑，再传到手机；
2. 下载完会得到一个 `.apk` 文件，文件名形如 `gooka_v1.1.3.apk`，以网盘内实际显示为准。

## 三、安装步骤

1. 在手机上打开「文件管理」，找到刚下载的 `.apk`；
2. 点它，系统弹「是否允许安装未知应用」时，给当前文件管理器放行；
3. 等安装走完点「打开」，首次使用的权限（如存储）按需给。

进首页不用登录，直接就能挑角色开聊，怎么玩在[使用入门与聊天技巧](使用入门与聊天技巧.md)里展开。

## 四、装不上时对号入座

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | 包没下完整，或系统版本低于要求 | 回网盘重新下载一遍；确认安卓版本满足要求 |
| 点了没反应 / 被系统拦截 | 没放行「未知来源」 | 设置 → 应用 → 特殊权限 → 安装未知应用，给文件管理器放行 |
| 提示空间不足 | 存储不够 | 清出几百 MB 再装 |
| 装上就闪退 | 系统兼容问题 | 走应用内「帮助中心」反馈，或换更高版本的系统试 |
| 覆盖安装被拒 | 同包名但签名不同 | 卸载旧版再装；旧版未登录的记录会丢，先复制保存重要对话 |

## 五、顺手校验一下安装包（可选）

担心传输过程中包被改坏的话，可以在电脑上对下载到的文件算一次 MD5，与下面这个值比对（采集这份包时记录的原始 MD5）：

```text
MD5 = 4FA7264B509DF71FA39641C2C45145A9
```

Windows 上用 PowerShell 一行搞定（文件名以网盘内实际为准）：

```powershell
certutil -hashfile "gooka_v1.1.3.apk" MD5
```

对不上就别装，回网盘重新下载。

## 六、版本说明

- 本篇对应版本：1.1.3（包名 `com.tings.ana`，2026-09-23 采集）；
- 官方后续会出新版本，界面与功能可能变化，以你装到的那一版实际显示为准；
- 网上能搜到 1.0.x、1.1.6、3.0.0、3.2.1 等各种「Gooka 版本」，包名各不相同，未必是同一个应用 —— 分辨方法见[版本与同名应用辨析](版本与同名应用辨析.md)；
- 有介绍页提到 Gooka 另有网页版或 iOS 版，本篇资源只有安卓安装包，其他端是否开放以官方渠道为准。
