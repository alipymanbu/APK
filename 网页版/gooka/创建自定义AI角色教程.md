现成角色不够贴合，或者想要一个完全按自己设定来的对话对象，就走自定义角色这条路。本篇步骤以 2026-09-23 采集的 1.1.3 版为准，字段名称以应用内实际显示为准。

## 一、入口与完整步骤

首页中间有一个「+」（加号）按钮，点它就开始创建智能体；不需要先注册登录。两个来源（一个与本篇同版本）给出的步骤一致：

1. 首页点「+」，进入角色创建页；
2. 填基本信息（名称、性别等），点「下一步」；
3. 补充背景信息，还可以输入角色可能说出的对话内容；
4. 点「创建」，生成专属角色卡；
5. 点开角色卡就能开始对话。

## 二、要填的东西

| 项目 | 填什么 | 建议 |
| --- | --- | --- |
| 名字 | 角色的称呼 | 起一个好喊的名字，以后搜索也靠它 |
| 形象 | 上传一张图片当角色形象 | 竖版人物图效果更自然 |
| 性格 | 角色的性格特点 | 写具体的行为倾向，比堆形容词好用（见下一节） |
| 背景故事 | 角色的来历与设定 | 决定它聊什么话题有底子 |
| 对话内容 | 角色可能会说的话（可选） | 给几句符合人设的例句，角色开口更贴设定 |

全部填完提交，专属智能体就生成了。字段是否必填、名称怎么显示，以应用内实际为准。

## 三、把人设写到位的四个做法

1. **性格写「行为」别写「标签」**：与其写「温柔」，不如写「说话不急，先接住你的情绪再给建议」，角色照着做的可能性高得多；
2. **背景故事给「关系」和「边界」**：有介绍页提到还可以设定你和角色的关系，把「你们怎么认识的」「它不会做什么」写进去，角色不容易跑偏；
3. **例句给「语气样本」**：对话内容那栏别写成自我介绍，挑两三句角色日常会说的话放进去，AI 学的是它怎么开口；
4. **先小改再大改**：创建完先聊几句看反应，哪里不对就回去改对应字段，比一次写一大篇再推翻省事。

## 四、自创角色还是现成角色

| 场景 | 建议 |
| --- | --- |
| 就想随便找人聊聊 | 首页挑个现成角色，零成本 |
| 有明确的人设或题材需求 | 自创，把设定一次写清 |
| 想要多个不同性格的角色切换 | 自创几个，分别设不同性格 |
