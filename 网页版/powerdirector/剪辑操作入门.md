## 一、新建项目与导入素材

1. 打开应用，在主界面点「新建项目」（首次使用会有简单引导）。
2. 给项目起名——正经剪辑建议养成起名的习惯，之后在中断后能从项目列表里找回来继续剪。
3. 从手机相册或文件里点选视频、照片，加入项目。
4. 素材进入时间轴后，竖屏横屏都可以剪：横屏适合常规视频，竖屏适合发手机端社交平台；界面支持横向或竖向编辑，转动手机即可切换操作方向。

## 二、时间轴上的基本剪辑

时间轴是主工作区，选中一段素材后常用动作：

| 你想做的 | 操作方式 |
|---|---|
| 掐头去尾 | 点选素材，拖动两端的绿色圆点调整起点与终点，视频、音频、照片通用 |
| 从中间切开 | 把播放头移到切点，用分割工具一分为二，再删掉不要的那半 |
| 调整片段顺序 | 长按素材拖到新位置 |
| 加慢动作/快放 | 选中片段调速度参数，无需素材本身支持慢动作拍摄 |
| 旋转/翻转/裁剪画面 | 在片段编辑工具里选对应项 |
| 调画面亮度对比度饱和度 | 片段的色彩编辑项里逐项调 |

先粗剪（把不要的都切掉）再精修（逐段调细节）是最省时间的顺序；边看边想很容易在单段上耗掉半小时。

## 三、文字、转场与特效

这三类素材在时间轴上都以「轨道对象」存在，加进去后再点它做个性化调整：

- **文字标题**：内置十几种文字样式（不同版本数量略有差异），加到标题轨后可改字体、色彩、大小、对齐与出现时间。片头片尾与段落字幕都靠它。
- **转场**：点时间轴上两段素材之间的转场图标，从列表里挑一个效果，预览确认。交接生硬的两个镜头加转场最见效。
- **特效工房**：水波、电视墙、复古、放射模糊这类画面特效，选中片段后套用，套之前能实时预览效果。

一句话经验：文字和转场宁少勿多，一部短片里两三种效果来回用就够，全套特效轮番上会显得杂乱。

## 四、多轨、画中画与绿幕

- **多轨编辑**：视频、图片、文字、音频各占轨道，可以叠放。拖动上层轨道素材缩小放在主画面上，就是画中画（PiP）。
- **混合模式**：上层素材可设混合模式，做双重曝光一类的叠影效果。
- **色度键（绿幕）**：对绿幕/蓝幕素材启用色度键去背，把人物或物体合成到另一个背景上。自己拍绿幕素材时，布光均匀、避免身体阴影落在幕布上，抠像效果差别非常大。
- **遮罩工具**：控制上层画面只显示某个形状区域，配合动画可以做局部遮挡或创意合成。

## 五、音频：配乐、配音与音量

- **加背景音乐**：从手机音乐文件导入，拖到音频轨；可与原视频声音混合，各自调音量。
- **旁白配音**：在时间轴位置上直接录音，录完作为独立音频轨调整。
- **从视频抽音频**：只想留某段视频的声音时，抽出音频单独使用。
- **淡入淡出**：音频头尾做渐变，避免音乐戛然而止。

声音方面最常见的坑：背景音乐比人声还响。配乐音量压到人声之下（大致听清人声为准），成片观感会好很多。

## 六、剪完之后

成片要存出来或发社交平台，走导出流程——分辨率、帧率在导出时才设定，具体见 [导出设置与画质选择.md](导出设置与画质选择.md)。长项目拖到预览发卡、导出失败时，别硬扛，按官方的拆分法分段导出，见 [剪辑闪退与大项目拆分.md](剪辑闪退与大项目拆分.md)。剪到一半闪退或卡顿，先看 [常见问题与解决方法.md](常见问题与解决方法.md)。
