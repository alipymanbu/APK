## 一、命令执行失败，提示权限或 Shizuku 未运行

排查顺序：

1. 打开 Shizuku 状态页，确认服务是「正在运行」。手机重启后服务必然失效，重新点一次「启动」即可（无线调试方式不用重新配对）；
2. 服务在运行但命令仍失败：进「设置 → 应用 → ShizuShell」确认授权没有被收回，部分省电策略激进的品牌（华为、小米常见）要把 ShizuShell 设为「无限制」后台，否则服务连接会被系统掐断；
3. 都没问题再检查命令本身——见下一节的报错对照。

## 二、命令报错对照表

| 报错/现象 | 多半是 | 处理 |
| --- | --- | --- |
| `adb: not found` 或类似「命令不存在」 | 抄命令时带了 `adb shell` 前缀 | 删掉前缀只留命令本体（详见[常用命令与实用技巧.md](常用命令与实用技巧.md)第二节） |
| `Permission denied` | Shizuku 没激活或授权被拒 | 按第一节排查；授权弹窗可能在通知栏里 |
| 命令回显为空、没有输出 | 命令本身正常但没有返回值 | 正常现象，比如部分 `settings put` 执行完就是安静的 |
| `Bad pid` / 参数类报错 | 命令拼错或该版本不支持此参数 | 逐字核对，或换等效命令 |
| 执行卡住不动 | 系统正在等待某个确认弹窗 | 下拉通知栏看看有没有待确认的窗口 |

## 三、无线调试配对一直失败

- 确认开的是「**无线调试**」而不是「USB 调试」，两者在同一个页面但功能不同；
- 配对码页面停留时间有限，动作要连贯：ShizuShell 里先点配对、再回设置取码、马上输码；
- 关掉 VPN/代理，确认手机连着 Wi-Fi；
- 刚做完系统更新（OTA）就配不上了：系统更新可能重置调试授权，回开发者选项重新允许一次再试；
- 实在配不上就换路径二（电脑 adb），一次做完就不需要无线配对了。

## 四、电脑 adb 连接异常

`adb devices` 出现的几种状态：

- 列表为空：数据线不支持数据传输（换线）、驱动没装好、或手机没弹授权；也检查开发者选项里「USB 调试」是否真的开着；
- 显示 `unauthorized`：手机上那条「允许 USB 调试吗」的弹窗还没点允许，下拉通知栏补点；
- 显示 `offline`：执行 `adb kill-server` 后重新 `adb devices`；仍不行就重启手机和电脑。

## 五、误停用/移除了应用，怎么恢复

- 停用的应用：执行 `pm enable 包名` 恢复；
- `pm uninstall -k --user 0` 移除的应用：执行 `cmd package install-existing 包名` 找回；
- 想不起包名：`pm list packages` 全量搜一遍，或按厂商过滤（如 `pm list packages | grep 小米厂商关键字`）；
- 品牌自带的找回入口：OPPO 系在「设置 > 应用 > 应用管理 > 找回卸载应用」，华为 HarmonyOS 5 在「设置 > 应用和元服务 > 恢复应用」——部分误删的系统应用走这里恢复最省事，入口名称以你的系统版本为准；
- 系统层面异常（桌面消失、功能报错）：先重启手机观察，再用上面的命令逐个恢复最近动过的包。

## 六、ShizuShell 和 root 有什么区别

| | Shizuku 路线（ShizuShell） | root |
| --- | --- | --- |
| 权限级别 | ADB/shell 级 | 超级用户级 |
| 是否解锁 Bootloader | 否 | 通常需要 |
| 是否修改系统分区 | 否 | 视方案而定 |
| 重启后 | 服务失效，需重新启动 | 权限一直在 |
| 能做的事 | adb 能做的一切（包管理、settings、wm 等） | 几乎全部 |

简单说：ShizuShell 够用在包管理、系统设置项调整这类日常需求上；需要更深层操作（改系统文件、挂载分区）的场景它做不了，那是 root 的领域。它的好处是你不用承担解锁和刷机的风险面。

## 七、安装与版本类问题

- **解析包错误**：安装包下载不完整（重新下载），或系统版本低于要求；
- **签名冲突**：手机里装过其他来源的同包名应用，先卸载再装；
- **网上说有新版本，我装的这个还是 1.0.0**：本文档以 2026-09-23 核对的安装包为准（1.0.0，69.51M）；官方后续是否发新版以 [Google Play 页面](https://play.google.com/store/apps/details?id=com.noxinfinity.shell) 显示为准，跨版本安装同样留意签名问题。

## 八、收费与隐私

- 商店信息显示 ShizuShell 免费下载、含应用内购买项目，具体以官方商店页面为准；
- 开发者公示的隐私政策地址可在其 Google Play 页面底部找到，介意权限收集的话先读一遍再决定是否使用（该应用申请的权限里包含存储、悬浮窗、使用情况访问等敏感项，均与它要做的系统操作相关）。
