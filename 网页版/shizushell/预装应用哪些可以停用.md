# 预装应用哪些可以停用（动手前的判断清单）

> 用 ShizuShell 免 root 清理预装应用之前，先照这篇判断：哪些可以直接停、哪些碰都别碰、拿不准时怎么核实。

## 一、动手前先记住一条原则

停用（`pm disable-user`）是可逆的，随时能 `pm enable` 找回来；对当前用户移除（`pm uninstall -k --user 0`）虽然多数情况也能恢复，但个别深度组件救不回来。所以拿不准的应用，**一律先停用、观察几天、确认没影响再考虑下一步**。命令本身在[常用命令与实用技巧.md](常用命令与实用技巧.md)第四、五节，这篇只讲「该对谁动手」。

## 二、通常可以放心停用的类型

下面这几类是多个独立来源一致归为「低风险」的，特点是：与通话、系统安全无关，且你几乎都有替代品：

| 类型 | 例子 | 说明 |
| --- | --- | --- |
| 预装第三方游戏、试玩应用 | 出厂就带的手游、试玩版 | 你没主动装过的那种 |
| 品牌重复应用 | 第二个浏览器、第二家应用商店、品牌音乐/视频/阅读 | 你已经在用另一款同类时 |
| 运营商应用 | 营业厅、运营商商城、用量查询 | 不用对应运营商服务就停 |
| 促销推广类 | 购物特惠版、资讯弹窗类、「手机清理大师」 | 广告推送大户 |
| 品牌云备份类 | 厂商云、云相册 | 不用厂商云备份时；停用前先确认已有别的备份方式 |

一个简单的交叉验证：这类应用在系统设置里通常本来就有「停用」按钮（只是有些品牌藏起来了），说明厂商也认可它们不是必需的。

## 三、碰都别碰的类型

这些组件停用或移除后，轻则功能异常、重则系统起不来，没有任何恢复技巧能兜底：

- **通信基础**：电话、短信、联系人、SIM 工具类组件；
- **界面与框架**：系统桌面（Launcher）、系统界面（SystemUI）、设置本身、Android System；
- **服务框架**：Google Play 服务、各厂商的服务框架（小米服务框架、华为 HMS、ColorOS 服务组件等）——它们不是「一个应用」，是很多功能的底层依赖；
- **系统组件**：WebView 与系统运行库、输入法、蓝牙/Wi-Fi 服务、开机向导。

判断特征：包名里出现 `systemui`、`launcher`、`framework`、`gms`、各厂商服务字样的，直接跳过。

## 四、拿不准时的三个核实动作

1. **看它是不是系统应用**：
   ```bash
   pm list packages -s
   ```
   `-s` 只列系统应用，`-3` 只列第三方应用；目标包在不在 `-s` 列表里，先有个底。
2. **看它装在哪**：
   ```bash
   pm path 包名
   ```
   输出路径里带 `/system/priv-app/` 的是厂商特权组件，风险等级最高，别动；带 `/data/app/` 的就是普通应用，怎么卸都行。
3. **搜一下包名**：把完整包名放进搜索引擎，一般能直接查到这个包是干什么的、停用了有什么后果，比猜靠谱。

## 五、停用之后怎么管理

- **看现在停用了哪些**：
  ```bash
  pm list packages -d
  ```
- **反悔了**：`pm enable 包名` 逐个恢复；
- **停用引发异常**（桌面消失、功能报错）：先重启手机，再按[常见问题与解决方法.md](常见问题与解决方法.md)第五节恢复；
- **品牌自带的找回入口**：部分系统误删系统应用后还有官方兜底——OPPO 系在「设置 > 应用 > 应用管理 > 找回卸载应用」，华为 HarmonyOS 5 在「设置 > 应用和元服务 > 恢复应用」，入口名称以你的系统为准，这比命令恢复还省事。
