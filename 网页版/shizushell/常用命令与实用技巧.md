## 一、先把界面用顺手

在 ShizuShell 里执行命令的流程很直接：

1. 激活 Shizuku 并完成授权（没做的话先看[Shizuku激活与授权教程.md](Shizuku激活与授权教程.md)）；
2. 在输入框敲命令，或者从预设命令列表里直接选一条；
3. 点「执行」，输出结果会显示在下方窗口，成功还是失败都有明确提示；
4. 执行过的命令都留在历史记录里，设置里可以清空记录；
5. 一条命令以后还要反复用，就把它加进快捷指令面板，之后点一下就能重跑。

## 二、抄命令前必看：去掉 `adb shell` 前缀

网上教程里的命令大多长这样：

```bash
adb shell pm list packages
```

这类写法是给「电脑连手机」的场景用的。在 ShizuShell 里你已经在手机本机的 shell 环境里了，**要把 `adb shell ` 这一段删掉**，只输入后面的部分：

```bash
pm list packages
```

带着前缀执行会直接报错（找不到 `adb` 这个命令），这是新手最容易卡住的地方。同理，教程里如果出现 `adb devices`，那也是电脑侧的命令，在手机上用不到。

## 三、查应用的包名

很多操作都要先知道目标应用的包名（形如 `com.tencent.mm`）：

```bash
pm list packages
```

列表会很长，配合过滤参数与关键词能省很多翻找：

```bash
pm list packages          # 全部应用
pm list packages -3       # 只看第三方应用
pm list packages -s       # 只看系统应用
pm list packages | grep wechat
```

`grep` 后面换成你的关键词即可；也可以直接搜厂商，比如 `pm list packages | grep xiaomi`。

## 四、停用与恢复应用（免 root「冻结」）

停用比卸载安全：应用从桌面和后台消失、不再自启，但数据还在，随时能恢复。

停用某个应用（把包名换成你在第三节查到的）：

```bash
pm disable-user --user 0 com.example.app
```

恢复它：

```bash
pm enable com.example.app
```

注意事项：

- 系统核心组件（桌面、电话、短信、系统 UI 相关）不要停用，停错了可能导致系统异常，好在 `pm enable` 能救回来；
- 同一个应用在不同系统上可能拆成多个包，停用一个包后界面残留另一部分是正常现象，逐个处理即可；
- 不确定某个包是什么，先搜一下再动手；**哪些包能停、哪些千万别动**，见[预装应用哪些可以停用.md](预装应用哪些可以停用.md)的判断清单。

## 五、对当前用户移除应用与恢复

想做得更彻底一点（效果接近卸载，但不动系统分区）：

```bash
pm uninstall -k --user 0 com.example.app
```

它的含义是「只对当前用户卸载、保留数据」，被移除的应用之后还能用下面的命令找回来：

```bash
cmd package install-existing com.example.app
```

这类操作只该用在确认无用的预装应用上。如果移除的是系统组件导致功能异常，`cmd package install-existing` 装不回来的情况也存在（极少数深度组件），动手前想清楚。

## 六、查看与修改屏幕参数

```bash
wm size
```

输出当前分辨率，比如 `Physical size: 1080x2400`。修改：

```bash
wm size 1080x2400
```

恢复默认：

```bash
wm size reset
```

屏幕密度（DPI）同理：

```bash
wm density          # 查看当前值
wm density 440      # 改成 440
wm density reset    # 恢复默认
```

调密度前先记下当前值——改完界面元素变大变小，不顺眼随时 `reset`。

## 七、其他高频命令速查

| 命令 | 作用 |
| --- | --- |
| `pm list packages -d` | 列出当前已被停用的应用（清理前后各查一遍，心里有账） |
| `pm path 包名` | 查应用安装位置，判断是不是系统特权组件（见判断清单篇） |
| `dumpsys battery` | 看电池状态、电量、温度、充电方式 |
| `settings get system screen_brightness` | 查当前屏幕亮度值 |
| `settings put system screen_brightness 120` | 直接改亮度（0~255，部分机型区间不同） |
| `settings put global window_animation_scale 0.5` | 把窗口动画调快（另有 `transition_animation_scale`、`animator_duration_scale` 两个同类键，改前先 `get` 确认） |
| `screencap -p /sdcard/1.png` | 静默截图到指定路径 |
| `input keyevent 26` | 模拟电源键（息屏/亮屏） |
| `logcat -d` | 倒出系统日志（排查应用崩溃时用） |

`settings` 里能改的项非常多（动画缩放、待机时间等），但不同 Android 版本键名有差异，改之前先用同一条命令 `settings get` 确认键存在，避免白改。

## 八、命令执行失败时

先对照两件事：Shizuku 是不是在运行（重启后失效最常见）、命令是不是还带着 `adb shell` 前缀。其余报错逐条看[常见问题与解决方法.md](常见问题与解决方法.md)。
