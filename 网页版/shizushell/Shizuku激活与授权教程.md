## 一、先弄清楚要激活的是什么

ShizuShell 本身只是个终端界面，真正的权限由 Shizuku 服务持有。Shizuku 是一个独立的开源框架，它通过系统的调试通道（无线调试或 adb）在后台跑起一个高权限进程，ShizuShell 再借用这个进程执行命令。所以你要做的事按顺序是：

1. 激活 Shizuku 服务（本篇第一、二、三节，三选一）；
2. 在 ShizuShell 里完成授权（第四节）；
3. 之后每次重启手机，服务会失效，需要重新启动一次（第五节）。

三条路径怎么选：

| 你的情况 | 选哪条 |
| --- | --- |
| Android 11 及以上，不想碰电脑 | 路径一：无线调试（推荐，全程手机上完成） |
| Android 10 及以下，或无线调试怎么都配不上 | 路径二：电脑 adb |
| 手机已经 root | 路径三：Root 启动 |

## 二、路径一：无线调试（Android 11+，不需要电脑）

1. 打开「设置 → 关于手机」，连续点击「版本号」7 次，开启开发者选项；
2. 进入「设置 → 系统 → 开发者选项」，打开「**无线调试**」（注意不是「USB 调试」）；
3. 回到 ShizuShell，按界面引导进入 Shizuku 的启动页，选择「通过无线调试启动」，再点「**配对**」；
4. 手机弹出配对通知后，回到「无线调试」页面点「**使用配对码配对设备**」，屏幕会显示一组 6 位配对码和端口；
5. 把配对码填进弹出的输入框，等待配对成功；
6. 配对成功后点「**启动**」，看到 Shizuku 显示正在运行即可。

注意事项：

- 配对那几步动作要连贯，配对码页面的端口每次都会变，输码前别在设置里乱点导致页面刷新；
- 手机和 Wi-Fi 保持连接，开着 VPN 或代理时配对容易失败，可以先关掉；
- 部分品牌（如小米的 MIUI/HyperOS）还需要同时打开「USB 调试（安全设置）」这个额外开关，ColorOS/OriginOS 等系统可能要求关闭「权限监控」类的安全选项。

## 三、路径二：电脑 adb（老系统或无线调试不可用）

这条路只需要做一次，做完之后日常不用再连电脑（但重启手机后仍要重新启动服务，见第五节）。

1. 在电脑上下载 [Google 官方 platform-tools](https://developer.android.com/tools/releases/platform-tools)，解压到一个好找的目录；
2. 手机打开「开发者选项 → USB 调试」，用数据线连上电脑，弹出的授权窗口点「允许」；
3. 在电脑的命令行里进入 platform-tools 目录，先确认连接正常：
   ```powershell
   adb devices
   ```
   能看到设备序列号和 `device` 字样才算连上了；
4. 执行 Shizuku 的启动命令（前提是手机上装了独立的 Shizuku 应用，可在其官方发布页获取）：
   ```powershell
   adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
   ```
5. 命令行输出服务启动成功后，拔掉数据线也能用。

常见卡点：`adb devices` 显示 `unauthorized` 说明手机上的授权没点；显示空列表多半是驱动或数据线问题（换一根能传数据的线）；显示 `offline` 就重插一次或重启 adb 服务（`adb kill-server` 后再 `adb devices`）。

## 四、Root 设备的启动方式

已经 root 的手机不用配对也不用电脑：在 Shizuku 的启动页选「通过 Root 启动」授权即可；或者手动执行：

```powershell
su -c sh /data/adb/shizuku/start.sh
```

Root 方式启动的服务在部分场景可以开机自启，这是三种方式里唯一能「一次搞定长期有效」的。

## 五、重启手机后要做什么

非 Root 激活的 Shizuku 服务**关机重启后就会失效**，这是机制决定的，不是坏了。处理方式：

- 平时重启：重新打开 ShizuShell，按引导再点一次「启动」即可，不用重新配对；
- 无线调试入口消失了：去开发者选项把「无线调试」重新打开；
- 新版 Shizuku 在受信任的 Wi-Fi 环境下支持自动重启服务（Android 13+，以 Shizuku 官方文档为准），可以留意自己的版本是否支持。

服务重新启动后，执行第一条命令时如果又弹授权询问，允许一次即可。

## 六、授权相关的小问题

- **找不到授权弹窗**：先确认 Shizuku 状态是「正在运行」，再进 ShizuShell 执行一条命令触发；部分系统会把弹窗折叠进通知栏，下拉看一下。
- **误点了拒绝**：进系统「设置 → 应用 → ShizuShell → 权限」里重新允许；或者到独立的 Shizuku 应用里找到 ShizuShell 重新授权。
- 授权完成但命令还是失败：多数是命令本身的问题而不是授权问题，对照[常见问题与解决方法.md](常见问题与解决方法.md)里的报错对照表排查。
