## 一、装之前先对一对手机配置

Winlator 是开源的 Windows 兼容层，在安卓上通过 Wine 与 Box86/Box64 运行为 x86/x86_64 编译的 Windows 程序。它不需要 root，但对硬件有要求：

| 项目 | 建议 | 说明 |
| --- | --- | --- |
| 处理器 | ARM64，骁龙优先 | 骁龙 + Adreno GPU 的兼容性与性能最好；麒麟机型问题较多 |
| GPU | 支持 Vulkan | Turnip、DXVK 这条快路依赖 Vulkan |
| 内存 | 6 GB 起 | 跑 3D 游戏建议 8 GB 以上 |
| 存储 | 给 Winlator 本体留 2 GB 以上 | 游戏本体另算，通常远大于这个数 |

社区教程普遍建议 Android 9.0 以上起步；官方发布页没有给出统一的最低系统版本，以 [winlator.org](https://winlator.org/) 与 [GitHub Releases](https://github.com/brunodev85/winlator/releases) 页面的说明为准。

## 二、这份安装包是什么版本

- 版本：9.0.1.1（Winlator 9.0 的社区构建）
- 包名：`com.WineBox64`
- 大小：232.53 MB（MD5：`0562780823DBB633D0040A12FC8018CE`）

装好后桌面图标和主界面显示的名字是 **WineBox64** —— 这是这份社区构建的名称，不是下错了别的软件，它就是 Winlator 的一个分支版本，区别见 [更新内容与社区构建说明.md](更新内容与社区构建说明.md)。

## 三、安装步骤

1. 从 [Winlator 安装文件资源（夸克网盘）](https://pan.quark.cn/s/29739d7deb69) 把 APK 转存到自己的网盘再下载到手机。
2. 允许安装未知来源应用：设置 → 安全/隐私 → 安装未知应用，给你的文件管理器或浏览器开一次权限。
3. 在文件管理器里点开 APK，完成安装。
4. 首次启动会创建目录并解压运行环境，要等几分钟，期间别杀后台。
5. 解压完成后进入主界面，接下来去 [创建容器与图形驱动选择.md](创建容器与图形驱动选择.md) 建第一个容器。

## 四、装完打不开怎么办

- 解压阶段卡住或闪退：先确认剩余存储够用（建议 3 GB 以上空闲），重启手机再开一次。
- 提示「应用未安装」：检查安装包是否下载完整（可与上面的 MD5 比对），重新转存下载一次。
- 其他启动类问题移步 [常见问题排查.md](常见问题排查.md)。
