## 一、容器是什么

容器就是 Winlator 里一台独立的「迷你 Windows 电脑」：每个容器有自己的 C 盘、自己的分辨率、驱动和组件配置。不同软件可以各建一个容器互不干扰；一个容器调坏了重建即可，不会牵连别的容器。

## 二、创建第一个容器

1. 主界面右上角点「+」新建容器。
2. 填名字（如「游戏」或软件名）。
3. 选屏幕分辨率，参考下表。
4. 选图形驱动（下一节）。
5. 保存后点这个容器的「运行」，出现 Windows 桌面就算成功。

建容器时顺手核对最下方的 DRIVES 段：D: 默认指向手机的 Download 目录，后面往容器里装软件全靠这条映射；显示不对就改回来再保存。

| 分辨率 | 适合 | 备注 |
| --- | --- | --- |
| 800×600 | 兼容性、性能优先 | 起步首选，卡就先降到这里 |
| 960×544 | 16:9 屏幕 | 画质与速度的折中 |
| 1280×720 及以上 | 高端机型 | 掉帧先降回来再说 |

## 三、图形驱动怎么选

| 驱动 | 适合 | 说明 |
| --- | --- | --- |
| Turnip (+Zink) | 骁龙 / Adreno | 性能最好的一档，骁龙机型优先试它 |
| Vortek | 实验性 | 9.0 新增的实验性 Vulkan 驱动，个别游戏上表现好，稳定性一般 |
| VirGL | 联发科 / Exynos / Mali | 通用兜底，兼容广但速度偏慢 |
| LLVMpipe | 排障 | 纯 CPU 渲染，很慢，只在别的都跑不起来时用 |

判断口径：骁龙先 Turnip，Mali 先 VirGL，都不理想再试 Vortek 或 LLVMpipe。

## 四、DirectX 后端

| 后端 | 对应 | 用法 |
| --- | --- | --- |
| WineD3D | DX 11 及以下 | 兼容面最广，先用它起步 |
| DXVK | DX 9/10/11 转 Vulkan | 骁龙机型跑 3D 游戏优先试，稳定就留下 |
| VKD3D | DX12 | 仅当软件明确要求 DX12 时用 |

9.0 新增了组件安装选项（Box64 / Turnip / DXVK），在容器设置里可以单独安装或升级这些组件；Vortek 驱动同样是这一版加入的（见 [更新内容与社区构建说明.md](更新内容与社区构建说明.md)）。

## 五、Box64 预设与其他设置

- Box64 预设按「兼容 → 性能」分档，3D 软件可以调高一档试试，不稳再调回来。
- 显存分配按机器实际内存给，6 GB 内存的机型常见给法是 4096~6144 MB，不是越大越好。
- 「强制全屏」对低分辨率的老游戏有用，这一版改进了该选项的行为。
- 跑不动、闪退的排查思路见 [常见问题排查.md](常见问题排查.md)。
