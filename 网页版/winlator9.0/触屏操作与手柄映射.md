## 一、容器里的触屏手势

进容器后，触屏会被映射成鼠标操作：

| 想做的操作 | 触屏手势 |
| --- | --- |
| 左键单击 | 单指轻点 |
| 右键 | 单指长按，或双指轻点 |
| 滚轮滚动 | 双指滑动 |
| 移动光标 | 手指按住屏幕拖动 |

不同版本的细节略有差异，以你容器里实际生效的为准；要频繁右键或精确定位的场合，外接鼠标仍然是最稳的选择。

## 二、打开输入控制（Input Controls）

1. 容器运行中按手机的返回键，呼出浮层菜单；
2. 点「Controls（控制）」；
3. 点「Input Controls（输入控制）」，在方案列表里选一套。

内置方案三类：

| 方案 | 适合 |
| --- | --- |
| RTS | 策略类、以鼠标点选为主的游戏 |
| Virtual Gamepad（虚拟手柄） | 想在屏幕上直接按虚拟按键 |
| 自定义手柄配置（Controller Profile） | 接了外接手柄，或想自己摆按键布局 |

## 三、虚拟按键怎么摆

自定义配置里可以往屏幕上放按钮、摇杆、十字键和触控板：

- 每个元素都能改位置、大小（缩放滑条）与形状；
- 选中元素后在属性里绑定要发送的键盘按键、鼠标动作或手柄键值；
- 按钮可设为「按住生效」或「点一下切换」两种模式；
- 十字键默认映射 W/A/S/D，摇杆既能发 WASD 键值也能发手柄轴值；
- 配置可以导出成 .icp 文件（落在 Downloads/Winlator/profiles 下），换容器、换机都能复用；
- 安装包里自带一批常见游戏的预置配置，挑最接近的复制一份再改，比从零摆快得多。

## 四、外接手柄

- 蓝牙手柄：先在手机的蓝牙设置里完成配对，进了 Winlator 才认得到；
- 有线手柄：用 OTG 线接入，安卓一般会自动识别；
- 进容器 → Input Controls → 选自定义手柄配置 → 点旁边的设置图标 → External Controllers，已连接的手柄会出现在列表里，点进去逐键映射；
- 常用映射思路：左摇杆当移动（对应 WASD），右摇杆当视角（对应鼠标），肩键与扳机绑鼠标键或常用功能键；
- 部分构建可在 XInput 与 DirectInput 之间切换：Xbox 系手柄优先 XInput，老式或杂牌手柄换成 DirectInput 再试。

手柄在安卓层面就认不到时，先解决连接问题再进 Winlator 调映射 —— 安卓看不到的设备，Winlator 也看不到。

## 五、键盘与鼠标

- 键盘鼠标属标准 HID 设备，蓝牙配对或 OTG 有线接入后，进容器一般直接可用；
- 个别按键（Enter、Esc、功能键等）在部分配置下不响应：常见做法是在容器里装一个键位重映射工具，把失灵的键转译成别的键再用；
- 中文输入的绕行办法见 [常见问题排查.md](常见问题排查.md)。
