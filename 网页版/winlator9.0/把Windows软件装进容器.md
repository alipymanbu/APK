## 一、先弄清容器里的盘符

Winlator 的 Windows 环境里有几个固定盘符：

- C: 是容器自己的系统盘；
- **D: 一般对应手机的 Download（下载）文件夹**；
- Z: 对应容器的根目录。

所以最省事的路径是：把安装包放进手机的 Download 文件夹，进容器后在 D: 盘里直接就能看到。

## 二、把文件弄进手机

- USB 数据线拷贝（最稳）；
- 网盘客户端下载到本地；
- 局域网共享或本地传输工具。

Winlator 本身不附带任何 Windows 软件或游戏，装什么由你自己准备，请只用你合法获得的安装文件。

## 三、在容器里完成安装

1. 容器列表点「运行」，进入 Windows 桌面。
2. 打开资源管理器，进 D: 盘找到安装包。
3. 双击安装程序（setup.exe 之类），按平时装 Windows 软件的习惯走完向导。
4. 大体积软件的安装会明显比电脑上慢，属正常现象，耐心等它跑完。

用完想退出容器：把里面开着的窗口全部关掉，会弹出确认退出的对话框，选 Yes 结束并回到主界面。触屏怎么点、右键怎么按，见 [触屏操作与手柄映射.md](触屏操作与手柄映射.md)。

## 四、建快捷方式，下次直接开

- 装完后，在开始菜单或安装目录里找到主程序 .exe，长按或右键选创建快捷方式。
- 回到 Winlator 主界面的「快捷方式（Shortcuts）」页，新装的程序会出现在这里；以后从这一页直接启动，不用再进 D: 盘翻目录。

## 五、免安装的绿色程序

解压即用型的程序：把整个文件夹拷进 Download，进容器后从 D: 盘进入该文件夹，直接运行里面的 .exe，同样可以按上面的方法建快捷方式。

装好的程序如果打不开、闪退或没声音，按 [常见问题排查.md](常见问题排查.md) 的顺序逐项试。
