# Winlator 容器内字体安装与乱码处理

> 容器里程序文字显示成方块或问号，多数是缺字体；本篇讲怎么把字体装进容器、怎么换界面字体。
> **相关文档**：[常见问题排查.md](常见问题排查.md) · [把Windows软件装进容器.md](把Windows软件装进容器.md)

## 一、先判断是不是字体问题

- 症状是文字变成方块、问号或随机符号，但程序本身能跑 → 基本就是容器里没有对应语言的字体；
- 症状是程序直接打不开或闪退 → 与字体无关，去 [常见问题排查.md](常见问题排查.md) 走启动类排查。

## 二、把字体装进容器

容器里没有手机上那种「字体管理器」，装字体就是放文件：

1. 把 .ttf / .otf 字体文件放进手机的 Download 文件夹；
2. 进容器，从 D: 盘把字体文件复制到 C 盘的 windows/Fonts 目录；
3. 重启容器（退出重进）让字体生效。

需要中文显示就装一款中文字体；运行日文等外文软件时装对应语言的字体。盘符与 Download 目录的对应关系见 [把Windows软件装进容器.md](把Windows软件装进容器.md)。

## 三、换界面字体

1. 开始菜单 → System Tools → Wine Configuration，打开 Wine 配置窗口；
2. 切到「Desktop Integration」页；
3. 在 Appearance 区的 Item 列表里选中要改的项目（活动标题、菜单、消息框等）；
4. 在下方 Font 里挑选字体并确认。

改完界面文字会按新字体渲染。下拉列表里找不到新装的字体时，先按上一节把字体放进 Fonts 目录，再重新打开这个窗口。

## 四、装了字体还是乱码

- 确认字体文件本身完整，重新下载一份试试；
- 确认字体复制进了容器内的 Fonts 目录，而不是还躺在 D: 盘；
- 个别程序写死了特定字体名，换一款覆盖该字形的字体再试。
