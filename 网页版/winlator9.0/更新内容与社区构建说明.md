## 一、9.0 版更新了什么

Winlator 9.0 发布于 2025 年 1 月，以下来自官方 GitHub Releases（v9.0.0）的更新清单：

- 新增实验性图形驱动 Vortek；
- 新增组件安装选项（Box64 / Turnip / DXVK），这些组件可以单独安装、升级；
- 改进 ALSA 音频插件；
- 改进「强制全屏」选项，对低分辨率的游戏更有用；
- Box64 更新到 0.3.2 版本；
- 为游戏 Ghost Song 加入专用修正；
- XServer 性能改进及其他修复。

对日常使用的直接影响：图形驱动多了一个可选项（[怎么选](创建容器与图形驱动选择.md)）、声音与全屏体验更稳、个别此前跑不起来的游戏有了转机。

## 二、这份 WineBox64 构建和官方版是什么关系

- 你安装的这份包版本为 9.0.1.1，包名 `com.WineBox64`，安装后界面名称显示为 WineBox64；
- WineBox64 是围绕 Wine 与 Box64 做整合的社区构建之一，各类 Winlator 资料站把它与 Bionic、GlibC 等并列在常见社区构建清单里；
- 官方版的包名是 `com.winlator`。两者可以理解为同一条产品线的不同分支：核心用法一致（建容器、装软件、跑 exe），差别在界面语言、预装组件与打包方式；
- 因为包名不同，社区构建与官方版通常可以先后安装、各自独立运行，互不覆盖。

## 三、版本线现状

官方版本线迭代很快，9.0 之后还有 10.x、11.x 等后续版本；本套文档以 9.0.1.1 这份包的口径为准，新版本的变化以 [GitHub Releases](https://github.com/brunodev85/winlator/releases) 页面为准。

## 四、开源与许可

Winlator 的代码以 LGPL-2.1 许可在 [GitHub](https://github.com/brunodev85/winlator) 开源（许可以仓库当前标注为准），它整合了 Wine、Box86/Box64、Mesa、DXVK、VKD3D、CNC DDraw 等开源项目。这个应用不在 Google Play 上架，一贯通过 GitHub 发布页等渠道分发 APK，这也是它只能以安装包形式装进手机的原因（[安装步骤](下载与安装教程.md)）。
