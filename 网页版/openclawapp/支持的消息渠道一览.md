## 第一个渠道怎么选

看两点：接入步骤的长短、你手机上常开的是哪个软件。Telegram 拿一个免费 bot token 就能用，步骤最短，适合当第一个——从建 bot 到拉群的完整链路见 [Telegram渠道接入步骤.md](Telegram渠道接入步骤.md)；WhatsApp、Discord、Slack 也都有各自的官方接入指南。渠道接入属于 Gateway 的配置，前提是 Gateway 已经跑起来（部署见 [下载与安装教程.md](下载与安装教程.md)）。

## 官方支持的渠道

官方配对文档列出的渠道（括号内为渠道 id）：Discord（discord）、飞书（feishu）、Google Chat（googlechat）、iMessage（imessage，仅 macOS）、IRC（irc）、Line（line）、Matrix（matrix）、Mattermost（mattermost）、Microsoft Teams（msteams）、Nextcloud Talk（nextcloud-talk）、Nostr（nostr）、Signal（signal）、Slack（slack）、SMS（sms）、Synology Chat（synology-chat）、Telegram（telegram）、Twitch（twitch）、WhatsApp（whatsapp）、Zalo（zalo）、Zalo 用户号（zalouser）。

实现了配对接口的外部插件（如 openclaw-weixin）还能再添渠道，列表以官方渠道文档当时为准。

另外自带一个网页聊天口：`openclaw dashboard` 打开的 Control UI 本身就能直接聊，一条聊天渠道都不接也能先用起来。

### 常用渠道速览

| 渠道 | 接入材料 | 适合 |
|---|---|---|
| Telegram | BotFather 发的 bot token | 步骤最短，手机电脑都顺手，首选；默认私信策略就是配对 |
| Discord | Discord 开发者后台的 bot token | 本来就常驻 Discord 的人 |
| WhatsApp | 扫登录二维码，把你的 WhatsApp 账号接入 | 想在用得最多的聊天软件里直接派活 |
| Signal | Signal 侧的接入配置 | 注重私聊场景的用户 |
| Slack / Teams / 飞书 | 工作群的 app 凭据 | 团队协作流 |
| iMessage | 仅 macOS 可接（BlueBubbles 路线） | 苹果生态用户 |

## 私信和群组的权限是分开的

接好渠道后，「谁有资格跟助手说话」是另一层：陌生发信人会拿到一个配对码，你批准了才算进门；群组里的发言权又是单独一份白名单，批准私信不会自动放开群组。机制与配置命令见 [安全设置与权限管理.md](安全设置与权限管理.md)。

WhatsApp 有个容易混的点：扫码登录是把你的 WhatsApp 账号关联到助手，「谁可以给这个账号发消息」由私信配对另行批准——两件事各走各的流程。
