## 先弄清这套软件的组成

OpenClaw 是一个开源自托管的个人 AI 助手（MIT 协议，代码在 [openclaw/openclaw](https://github.com/openclaw/openclaw)，文档在 [docs.openclaw.ai](https://docs.openclaw.ai)）。它分两块跑：

| 部分 | 跑在哪 | 作用 |
|---|---|---|
| Gateway（网关） | 电脑：macOS / Linux / Windows（原生 Hub 或 WSL2） | 真正干活的部分：接 AI 模型、执行任务、管会话 |
| 安卓 app（Node 节点） | 手机 | 手机端的聊天与遥控入口，把相机、通知等手机能力按授权开放给助手 |

安卓 app 本身不运行助手——你得先有一台跑着 Gateway 的电脑，手机才有东西可连。电脑端与手机端都装好后，按 [手机端配对与连接.md](手机端配对与连接.md) 完成配对。

## 电脑端：装 Gateway

### 系统要求

- 操作系统：macOS、Linux，或 Windows（官方 Windows Hub 桌面程序，或 WSL2 跑 Gateway）
- Node.js：24.16+ 或 26.1+，官方推荐 26 系（以官方安装页当时标注为准）
- 一个 AI 模型服务商的 API Key（Anthropic、OpenAI、Google 等，初始化向导里会要）

### 一条命令安装（推荐）

macOS / Linux / WSL2：

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

Windows（PowerShell）：

```powershell
iwr -useb https://openclaw.ai/install.ps1 | iex
```

脚本会检测系统、缺 Node 时自动补装，然后进入初始化向导。已经自己管 Node 的也可以用 npm：

```bash
npm install -g openclaw@latest --allow-scripts=openclaw
```

npm 12 默认拦截包的安装脚本，所以要带 `--allow-scripts=openclaw`；pnpm 对应写法是 `pnpm add -g --allow-build=openclaw openclaw@latest`。

不想碰命令行的话，官方还提供桌面程序：macOS 菜单栏应用、Windows Hub（带设置 / 托盘状态 / 聊天 / 节点模式）、Linux 的 AppImage 或 .deb 包，从 GitHub 发布页下载，首次运行向导会把 Gateway 一起配好。

### 初始化与启动

```bash
openclaw onboard --install-daemon
```

向导里要做的三件事：选模型服务商并填 API Key、接第一个聊天渠道、把 Gateway 注册成后台服务（macOS 用 LaunchAgent，Linux 用 systemd 用户服务）。可选步骤想跳过以后再补，用 `openclaw configure`；以后想换模型、接中转或本地模型，做法整理在 [切换AI模型与APIKey配置.md](切换AI模型与APIKey配置.md)。

装完核对状态：

```bash
openclaw gateway status   # 应看到 Gateway 监听 18789 端口
openclaw dashboard        # 在浏览器打开控制台（Control UI），能聊天就说明装通了
```

### 日常维护

```bash
openclaw --version              # 确认版本
openclaw doctor                 # 体检配置问题
openclaw update --channel stable
```

电脑端版本号按 v2026.月份.修订 的形式滚动发布（如 v2026.9.6），具体以官方发布页为准。

## 手机端：装 app

用上文第二节网盘入口拿到 apk（文件 openclawapp_v10.0.apk，约 6.7 MB）装上。装完先别急着用——它要连上电脑端 Gateway 才有用，连接与批准步骤见 [手机端配对与连接.md](手机端配对与连接.md)；第一次连不上多半是网络隔离或端口问题，处理思路整理在 [常见问题与排查.md](常见问题与排查.md)。

Gateway 跑通、手机连上之后，下一步通常是接一个聊天渠道，让你在平时用的聊天软件里直接派活——渠道清单与怎么选见 [支持的消息渠道一览.md](支持的消息渠道一览.md)。
