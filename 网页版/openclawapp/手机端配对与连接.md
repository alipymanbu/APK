## 先确认前置条件

安卓 app 是「伴生节点（node）」，本身不跑助手；它要连的是电脑上的 Gateway。开始前确认：

- 电脑端 Gateway 已在跑：`openclaw gateway status` 显示监听 18789 端口（没装的先看 [下载与安装教程.md](下载与安装教程.md)）；
- 手机与电脑网络互通：同一局域网，或通过 Tailscale 这类组网工具互通；
- 手机上已装好 app（安装包入口见 [下载与安装教程.md](下载与安装教程.md) 第二节）。

## 三种连接方式

app 的 Connect 标签页里有 Setup Code 与 Manual 两种模式；同一局域网下还能自动发现 Gateway。

| 方式 | 适用场景 | 怎么做 |
|---|---|---|
| 自动发现 | 手机和电脑在同一局域网 | Settings 的 Discovered Gateways 里选中你的网关直接连 |
| Setup Code / 二维码 | 组网后跨网段也适用，最省事 | 电脑端 `openclaw qr` 生成，app 里扫码或粘贴 |
| 手动填写 | 发现被路由器 AP 隔离等挡住时 | Advanced controls 里填主机 + 端口（默认 18789） |

私有网段地址用 `ws://` 协议填；跨网络远程访问建议走 Tailscale Serve 这类能提供 `wss://` 加密的路线，不要把端口直接暴露到公网（完整安全清单见 [安全设置与权限管理.md](安全设置与权限管理.md)）。

## 在电脑上批准这台设备

首次连接会在 Gateway 侧生成一条设备配对请求，需要你批准才生效：

```bash
openclaw devices list
openclaw devices approve <requestId>
openclaw nodes status    # 确认手机节点已连上
```

批准之后，app 以后启动会自动重连上次的 Gateway（手动填过的优先用手动端点），不用每次重新配。

## 连接保持与离线行为

app 靠一条前台服务维持与 Gateway 的连接，通知栏会有一条常驻通知——这是它保活的方式。离开前台后部分安卓系统会暂停次要连接，回到 app 时自动恢复。

断网时发出的消息按 Gateway 分开排队，重连后按顺序送达，不会丢。

## 手机上能做什么

- **聊天**：选会话、看历史记录、发文字 / 图片 / 语音；
- **语音**：Mic（说完再发）与 Talk（连续对话）两种模式；回复可以用电脑端配置的语音服务，没有就兜底走安卓系统 TTS；
- **手机能力按授权开放**：相机、照片、联系人、日历、通话记录、短信搜索、运动、已装应用、指定通知事件——逐项授权、逐项可关，取舍原则见 [安全设置与权限管理.md](安全设置与权限管理.md)；
- **工作区文件**：只读浏览助手的工作区，能预览文本或图片、能通过系统分享导出；
- **命令审批**：Gateway 有命令审批请求时，手机上能看脱敏后的命令预览与到期时间，直接批或驳；
- **多 Gateway 切换**：可以配对不止一台（比如家里一台、公司一台），Settings → Gateway 里切换，凭据、TLS 信任、缓存与离线队列互相隔离；
- **Wear OS 手表**：手表不存网关凭据，走配对手机的连接，能选会话、语音回复、中止正在跑的任务、发起实时 Talk。

## 连不上时的排查顺序

自动发现失败 → 先确认同一网段 → 改手动填 IP + 18789 → 跨网络就两端都进 Tailscale 再连。更完整的「症状 → 处理」清单（含配对码过期、频繁掉线）见 [常见问题与排查.md](常见问题与排查.md)。
