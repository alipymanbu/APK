## 一、先核对这几个数字

Joplin 是一款开源笔记应用，笔记以 Markdown 格式保存，它同时有 Windows、macOS、Linux、安卓、iOS 版本。本篇针对的是安卓版（包名 `net.cozic.joplin`），你手里这份安装包的信息如下：

| 项目 | 值 |
| --- | --- |
| 版本 | 3.1.4 |
| 包名 | `net.cozic.joplin` |
| 安装包大小 | 97.57M |
| MD5 | `D8EFDA2CC5A39C0EDBCA2AA430D86180` |
| 信息核对时间 | 2026-09-27 |

网盘里是 3.1.4 这一版。官方一直在更新，写作时安卓版已经迭代到 3.7.x（更新日志见 [joplinapp.org](https://joplinapp.org/help/about/changelog/android/)，以官方页面为准），先用哪一版看你自己的需要。

系统要求：安装包信息里标注「安卓 5.2 以上」，而 F-Droid 页面对 3.x 系列的标注是「需要 Android 6.0 或更新」——按更严的那个理解即可：手机低于 Android 6.0 时装不上，多半就是系统版本问题。

## 二、从夸克网盘获取安装包

头部的 [Joplin 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9bdef50b4522)就是安装包的获取入口。打开后转存到自己的网盘，再从网盘下载到手机本地，得到一个 `.apk` 文件。

拿到文件后建议先核 MD5（很多文件管理器长按文件就有「校验」入口），对上 `D8EFDA2CC5A39C0EDBCA2AA430D86180` 再继续装。MD5 不区分大小写，文件多一个空格或少一个字节都过不了校验。

## 三、安装步骤

1. 在手机上点开下载好的 `.apk` 文件；
2. 系统提示「不允许安装未知来源应用」时，按提示允许当前文件管理器或浏览器安装应用（不同品牌路径不一样，一般跳到「设置 → 应用 → 特殊权限 → 安装未知应用」）；
3. 回到安装界面点「安装」，等进度走完；
4. 打开应用，首屏会让你选语言、过一遍说明页，跟着走完即可。

装不上时的排查顺序：安装包没下完整（重新下载并再核一次 MD5）、系统版本低于要求、手机剩余存储不足。这三个原因占了绝大多数，其余情况见[常见问题与解决方法.md](常见问题与解决方法.md)第五节。

## 四、装完先调的两处设置

- **电池与后台**：进系统设置的电池页，把 Joplin 设为「不限制后台」或关掉对它的电池优化。你要用云同步的话这一步别省，不做它，锁屏之后同步经常不动（症状与处理见[常见问题与解决方法.md](常见问题与解决方法.md)第二节）。
- **同步目标**：什么都不配它也能当单机笔记用；想多设备一起用，按[同步配置方法.md](同步配置方法.md)配置。

## 五、官方还有哪些获取渠道

| 渠道 | 地址 | 说明 |
| --- | --- | --- |
| 官网下载页 | [https://joplinapp.org/download/](https://joplinapp.org/download/) | 有安卓 APK 直链与各桌面版 |
| Google Play | 应用商店内搜 Joplin | 商店版，随商店自动更新 |
| F-Droid | [https://f-droid.org/packages/net.cozic.joplin/](https://f-droid.org/packages/net.cozic.joplin/) | 社区构建渠道，版本可能滞后于官方 |
| GitHub Releases | [https://github.com/laurent22/joplin/releases](https://github.com/laurent22/joplin/releases) | `android-v` 开头的标签是安卓版 |

不同渠道构建的应用签名不一定相同，互相覆盖升级可能失败；选定一个渠道后固定用它升级。

另有一个 F-Droid 特有的差异值得知道：F-Droid 的构建版没有相机与定位相关功能（打包方式不同）。你要用「拍照存进笔记」这类功能的话，选官网直链或 Google Play 版。
