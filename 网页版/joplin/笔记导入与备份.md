# Joplin 笔记导入与备份方法

> 想把 Evernote、OneNote 或一堆 Markdown 文件搬进 Joplin，或者给笔记做备份、换手机迁移，按场景看对应小节。

## 一、先说清一个前提：导入入口在桌面端

ENEX、Markdown 目录、OneNote 这些导入功能都在 Windows、macOS、Linux 桌面版里（终端版也支持一部分），手机端没有这些菜单。所以迁移笔记的标准姿势是：电脑装桌面版 → 导入 → 配好与手机相同的同步目标 → 同步，笔记就到了手机上。桌面版从[官网下载页](https://joplinapp.org/download/)拿。

## 二、从 Evernote 迁移（ENEX 文件）

1. 在 Evernote 里把笔记本逐个导出为 ENEX 文件（Evernote 官方帮助里有导出步骤）；
2. 桌面版 Joplin 里走「文件 → 导入 → ENEX」，可以选单个文件，也可以选一个装满 ENEX 的目录（每个文件对应一个新笔记本）；
3. 导入完成后再同步到手机。

有几处已知的损耗，官方文档写得很明白：

- 表格会转成 Markdown 表格；粗体、斜体、列表、链接这类基础格式基本无损；
- 字体、字号、颜色不保留——文字内容都在，丢的是样式。确实需要保样式时，可以选按 HTML 方式导入 ENEX；
- Evernote 存在图片里的识别文字（OCR 数据）不会带过来；
- 笔记之间的内链按标题尽量还原；多条笔记同名时可能对不上号，导入后抽查一下内链。

## 三、导入 Markdown 文件

桌面版「文件 → 导入」里分两项：导单个 `.md` 文件（进当前选中的笔记本），或导一整个目录（目录结构映射成笔记本与子笔记本层级）。从别的 Markdown 笔记应用迁出来时，先看它能不能按文件夹批量导出 md，能批量就别一篇篇来。

## 四、从 OneNote 导入

官方支持两条路，都需要比较新的桌面版（网页版 ZIP 方案要 3.5.1 以上；OneNote Windows 桌面版导出方案要 3.5.5 以上），步骤以[官方文档](https://joplinapp.org/help/apps/import_export/)为准：要么从 OneNote 网页版把笔记本打包下载成 ZIP 再导入，要么在 Windows 的 OneNote 桌面版里导出 `.one` / `.onepkg` 再导入。手机上的 3.1.4 不涉及这一步，导入动作仍然在桌面端完成。

## 五、导出与备份

桌面版导出菜单里的几个格式，用途不同：

| 格式 | 保留什么 | 适合 |
| --- | --- | --- |
| JEX | 笔记、标签、附件、时间等元数据，整包可再导入 | 整库备份 |
| RAW | 与 JEX 同内容，按目录散开存放 | 想按文件管理时 |
| HTML / PDF | 单篇或整本的成品文件 | 发给别人看，不适合当备份 |

手机端没有这些整库导出菜单，备份思路就一条：配好同步目标，目标那侧就是你的备份。想再加一层保险，在电脑上用桌面版定期导一份 JEX 出来。

除此之外应用还自带「笔记历史」，默认保留 90 天的旧版本，误改误删时能从桌面端找回（方法见[常见问题与解决方法.md](常见问题与解决方法.md)第六节），但它不是备份的替代——库出大问题时能整包恢复的只有 JEX。

## 六、换手机怎么搬

1. 新手机装好 Joplin（装法见[下载与安装教程.md](下载与安装教程.md)）；
2. 配置与旧手机完全相同的同步目标，参数照抄（见[同步配置方法.md](同步配置方法.md)）；
3. 点「同步」，等全部笔记拉下来；
4. 开了端到端加密的，这一步会要你输主密码——主密码要提前抄好。

确认新手机数据完整之后，再去处理旧手机（退出登录或卸载）。
