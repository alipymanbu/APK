# Joplin 界面与基础用法

## 一、三层结构：笔记本 → 笔记 → 标签

- **笔记本**：一级分类，下面还能再建子笔记本，层级不限制数量；
- **笔记**：每条笔记归属一个笔记本，分普通笔记和待办两种，待办可以打勾、设闹钟提醒；
- **标签**：跨笔记本的横向归类，同一条笔记可以贴多个标签。

新建入口在右下角的「+」按钮；移动、复制、置顶这些操作在笔记右上角菜单里（菜单项以你手上的版本为准）。

## 二、写笔记：Markdown 编辑器

新建笔记直接打字就是在写 Markdown。2.9 版之后移动端编辑器加了工具栏，粗体、列表、插入图片这些不用手敲符号，点按钮就行；编辑器内还支持查找与拼写检查。

「配置」里能找到编辑器相关选项：新版还提供富文本编辑器模式，你这份 3.1.4 是否已有该选项，以设置界面实际显示为准。编辑视图与阅读预览随时切换。

## 三、附件与拍照

编辑笔记时可以从相册插图、附加文件，常见类型都支持：图片、视频、PDF、音频；其中音频、视频、PDF 会在笔记的阅读视图里直接内联显示，不用跳出去打开。也可以直接调相机拍照，拍完存进当前笔记。

两个边界要提前知道：

- **手机端目前不支持大于 10MB 的附件**——官方文档明确说明这类附件在同步时会导致应用崩溃，建议暂时别在手机上挂大文件。桌面端的单条附件上限是 200MB 一级（官方 2.9 版公告提过这个数字），两个口径别混；
- 「配置 → 附件下载行为」默认「总是」，即把所有附件都下载到手机。流量或存储紧张时改成「自动」（打开笔记才下载）或「手动」（点附件才下载），省空间也省流量。

附件跟着笔记一起走同步，附件多的库，同步耗时与流量都会明显变大。

## 四、搜索

顶部搜索框是全文搜索，标题与正文都能搜到（全文搜索是全平台都有的功能）。笔记多了之后，先选定笔记本再搜，范围小、出结果快。

## 五、锁与外观

「配置」里有应用锁相关选项，设备支持时可以用指纹或面部识别锁住应用（取决于手机硬件，以你设备上实际显示的设置项为准）。「外观」设置里能调主题，包括暗色模式。

## 六、把网页和文字分享进笔记

安卓系统的「分享」菜单里选 Joplin，会把链接或选中的文本直接存成一条新笔记——刷到文章随手收一条，不用复制粘贴再建笔记。两个限制：它只能新建笔记，不能把内容追加进已有笔记；存完默认落在哪个笔记本取决于应用当前状态，需要的话再移动。

## 七、和桌面端配合的两件事

- **多端同步**：电脑装桌面版、配同一个同步目标，笔记双向同步，配置步骤见[同步配置方法.md](同步配置方法.md)；
- **网页剪藏**：官方的 Web Clipper 浏览器扩展（Chrome / Firefox）能把网页或截图直接存成笔记。它依赖桌面版在后台运行，是电脑侧的功能，手机上不用找。
