# 坚果云 WebDAV 同步配置

> 坚果云是国内常用的 WebDAV 网盘，而 Joplin 官方 FAQ 把它列在「不支持的 WebDAV 主机」清单里。本篇把两边口径都摆出来，并给出实际能跑通的配置步骤与免费版额度。
> **相关文档**：[同步配置方法.md](同步配置方法.md) · [常见问题与解决方法.md](常见问题与解决方法.md)

> [!IMPORTANT]
> **Joplin 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/9bdef50b4522](https://pan.quark.cn/s/9bdef50b4522)

## 一、先摆清两个口径

- **官方 FAQ 的口径**：Joplin 官方常见问题页把坚果云（Jianguoyun）与 pCloud 列在「不支持的 WebDAV 主机」清单里，并附了对应 issue；
- **社区实践的口径**：不少用户在坚果云上稳定多端同步，关键动作是把「最大并发连接数」压到 1，避免短时间大量请求撞上坚果云的频率限制。

两边并列放在这，不做替你选边的结论：要开箱即用，Dropbox / OneDrive / Joplin Cloud 这类授权型目标更省事；只想用国内网盘、愿意多做一步设置，坚果云是常见选择。

## 二、在坚果云侧：生成应用密码

坚果云的 WebDAV 不用登录密码，要专门生成「应用密码」：

- **网页端**：登录[坚果云官网](https://www.jianguoyun.com/) → 右上角「账户信息」→「安全选项」→「第三方应用管理」→「添加应用密码」，起个名字（比如 joplin）后生成；
- **安卓端**：坚果云 App →「设置」→「第三方应用管理」，添加方式类似。

顺手在坚果云网页端建一个名为 `Joplin` 的文件夹，同步数据会放在这里，建好后别改名。

## 三、在 Joplin 侧：填 WebDAV

按[同步配置方法.md](同步配置方法.md)第三节把同步目标选成 WebDAV，然后填：

| 项目 | 值 |
| --- | --- |
| WebDAV URL | `https://dav.jianguoyun.com/dav/Joplin` |
| 用户名 | 你的坚果云登录邮箱 |
| 密码 | 第二步生成的应用密码（不是登录密码） |
| 最大并发连接数 | `1` |

「最大并发连接数设为 1」不是官方要求，是社区实践出来的参数：坚果云对 WebDAV 有频率限制，并发高了容易触发「Too many requests」，有用户反馈被限制后要等约 6 小时才解封。

填完点「检查同步配置」，通过后回主界面点「同步」。第一台设备首同步完成后再配第二台，不要两台同时首同步。

## 四、免费版的额度与限制（坚果云官方帮助）

| 项目 | 免费版额度 |
| --- | --- |
| 上传流量 | 每月 1GB |
| 下载流量 | 每月 3GB |
| WebDAV 访问频率 | 每 30 分钟不超过 600 次请求（付费版 1500 次） |
| 单文件上传大小 | 500MB |
| 单次列目录文件数 | 750 个（支持分页加载） |

文字笔记为主的库，这套额度很宽裕；库里大附件多的话，流量会先扛不住。除了少放附件，还可以把应用的「附件下载行为」改成「自动」或「手动」来省下行流量（见[界面与基础用法.md](界面与基础用法.md)第三节）。额度以[坚果云官方帮助页](https://help.jianguoyun.com/?p=2064)为准，可能随时间调整。

## 五、首同步前与报错

- **同步前先做一次备份**：把现有笔记导出一份 JEX（方法见[笔记导入与备份.md](笔记导入与备份.md)第五节）。同步操作失误导致丢笔记是社区里最常见的翻车点，备份后再动配置；
- **在意隐私就开端到端加密**：开了之后坚果云侧存的是密文（设置见[同步配置方法.md](同步配置方法.md)第四节）；
- **报 Too many requests**：被频率限制拦了。把最大并发连接数改成 1，等限制解除再同步；
- **报 403 Forbidden**：URL 或密码不对。地址要精确到 `https://dav.jianguoyun.com/dav/Joplin`，密码必须是应用密码；其他 403 场景见[常见问题与解决方法.md](常见问题与解决方法.md)第一节。
