## 一、先弄懂「同步目标」

Joplin 是离线优先的：笔记本体始终存在你的手机本地，没网也能打开、能改。同步只做一件事——把你本地的改动推到你选的「同步目标」上，再把其他设备的改动拉下来。换手机、重装应用，笔记都在同步目标上，不在应用本地。

官方支持的同步目标有：Joplin Cloud、Dropbox、OneDrive、Nextcloud、WebDAV、S3、Joplin Server（自建）、本地文件系统。安卓端基本都能用；其中「文件系统」在安卓上通过系统文件选择器选一个本地文件夹，可以配合 Syncthing 这类按文件夹同步的工具实现跨设备。

## 二、配置入口

打开 Joplin → 侧边抽屉 →「配置」→「同步」，第一项就是「同步目标」。选好目标、填完参数后先点「检查同步配置」，提示通过再回主界面点「同步」按钮跑第一次同步。

不同版本的菜单文字略有差异，认「配置 / 同步」这两个词就行；填错参数时「检查同步配置」会给出具体报错，比直接同步好排错。

## 三、各目标怎么配

### 1. Joplin Cloud（官方托管）

在[官网](https://joplinapp.org/plans/)注册账号，应用里选 Joplin Cloud 登录即可。数据存放在法国，官方称其端到端加密连运营方也无法读取你的数据；方案与价格以官方页面为准。

### 2. Dropbox / OneDrive（授权型）

选 Dropbox 或 OneDrive → 点「授权」→ 应用会拉起登录页 → 登录你的账号并允许 → 回到应用完成连接。全程不用手动填地址。注意同步数据会放进你网盘里的一个应用目录，别在网盘侧手动整理或删除那个目录。

### 3. Nextcloud / WebDAV（地址型）

这两个填法相同：服务器地址 + 用户名 + 密码。Nextcloud 的 WebDAV 地址一般是下面两种之一（在 Nextcloud 文件页左下角「设置」里能直接看到）：

```text
https://你的域名/nextcloud/remote.php/webdav/Joplin
https://你的域名/remote.php/dav/files/你的用户名/Joplin
```

先在 Nextcloud 里把路径末尾那个 `Joplin` 目录建出来，再回 Joplin 填地址，能省掉一次报错。另外官方特别提醒：如果电脑上装着 Nextcloud 桌面客户端，把 Joplin 这个目录从它的同步范围里排除掉——让 Joplin 自己管同步，两边同时管会互相干扰。

用坚果云这类国内网盘的 WebDAV，步骤、参数与额度限制单独有一篇：[坚果云同步配置.md](坚果云同步配置.md)。

### 4. S3

需要你已有一套 S3 兼容对象存储（或自建 MinIO），填 endpoint、访问密钥、存储桶名。适合本来就在用对象存储的人；只是想同步笔记的话，上面几种更省事。

### 5. Joplin Server（自建）

官方提供可自建的服务端程序（见 [GitHub 仓库](https://github.com/laurent22/joplin/tree/dev/packages/server)）。应用里填服务器地址、邮箱、密码三项。适合有服务器、不想把笔记交给第三方网盘的用户。

### 6. 本地文件系统（安卓）

选「文件系统」目标后，安卓会弹系统文件选择器，指定一个文件夹作为同步位置。它本身不跨设备，常见用法是配合 Syncthing 让这个文件夹在手机与电脑之间保持一致，笔记就跟着过去了。这个目标在移动端坏过一段时间，官方在 2.9 版本修复，你这份 3.1.4 可用。

## 四、给同步加上端到端加密

不开加密时，笔记在同步目标上是明文——Dropbox、WebDAV 这类目标，谁有网盘权限谁就能看到内容。Joplin 支持端到端加密（E2EE），开启后同步目标上只剩加密数据。

开启步骤（官方推荐从桌面端开始，手机端也能开，只是首次加密整库明显更慢）：

1. 在第一台设备上：「配置 → 同步 → 加密」，点「启用加密」，设一个主密码；
2. 主密码没有任何找回手段，忘了等于加密数据全部解不开，设完先抄在纸上；
3. 点「同步」，等它把全部笔记重新加密推上去。笔记多时按小时计，中途看着不动也别取消；
4. 其他设备点「同步」，收到主密钥后输入主密码，加密自动在这台设备上启用。

不要在多台设备上各自同时开加密，容易出现多把主密钥。忘记密码的后果与处理见[常见问题与解决方法.md](常见问题与解决方法.md)第四节。

## 五、换同步目标

官方设计上允许随时换目标：在配置里把「同步目标」换成新的，填好参数、通过检查后同步一次即可。换之前先把本地改动手动同步干净；换目标后第一次同步会把本地笔记重新推到新目标上，旧目标里的数据不会被自动删除，确认不要了再自己去清理。

**换 WebDAV 地址是另一个场景，官方 FAQ 有明确警告**：如果新地址指向的位置是空的，应用会认定你删除了全部数据，进而把本地笔记也一并删掉。官方给的换址流程是：先导出一份 JEX 备份 → 做最后一次同步 → 在网盘侧把旧位置的 Joplin 数据（含 `.resource` 目录里的附件）整个复制到新位置 → 再到应用里改地址、同步验证。JEX 导出方法见[笔记导入与备份.md](笔记导入与备份.md)第五节。
