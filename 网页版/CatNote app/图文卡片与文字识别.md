# CatNote 图文卡片与文字识别

> 本篇讲往 CatNote 里记内容的四种方式：发图文卡片、拍照识别文字、从微信读书导入、API 接口录入，以及各自适合的场景。

CatNote 的记录逻辑是「一张卡片一条内容」，像聊天一样把文字、图片发进去就成了一条笔记。本篇把四种记录入口列出来并给出选择依据；记进去之后怎么整理成知识网，见[标签与双向链接用法](标签与双向链接用法.md)。

## 一、四种记录入口怎么选

| 方式 | 适合什么内容 | 前提 |
| --- | --- | --- |
| 直接发卡片 | 灵感、随笔、备忘、图文混排 | 无 |
| 文字识别（OCR） | 纸质材料、截图里的文字 | 免费用户每月 3 次 |
| 微信读书导入 | 读书时的划线笔记与想法 | 需要装微信读书 |
| API 输入 | 批量、程序化的内容录入 | 需要会员与一定开发能力 |

还有第五种入口是在微信里记：绑定公众号后直接发消息就能存笔记，绑定步骤单独写在[微信输入与定时回顾设置](微信输入与定时回顾设置.md)里。

## 二、发一张图文卡片

1. 在应用主界面底部的输入框直接打字，回车发送，内容就存成一张卡片；
2. 需要配图时在输入框附带图片，支持图文混排在同一张卡片里；
3. 卡片发出后仍可编辑，后续补标签、加关联都不受影响。

这个入口没有任何门槛，官方把它设计成「像聊天一样」，你按平时发消息的习惯用就行。

## 三、文字识别：拍照与相册

输入框下方有「文字识别」按钮，分两种用法：

- **拍照识别**：现场对纸质书、黑板、包装上的文字拍照，识别结果直接生成笔记；
- **相册识别**：从手机相册选一张已有图片，把里面的文字提出来。

识别出来的内容是可编辑文本，你可以继续修改、加标签、关联到其他笔记。注意额度：这项是会员权益功能，免费用户每月能用 3 次，次数用完当月就只能手动打字或等下月。

## 四、从微信读书导入划线笔记

如果你在微信读书里习惯划线写想法，可以把它们搬过来：

1. 在微信读书中点「我的」-「笔记」，打开想导出的那本书；
2. 点「导出笔记」，选「复制到剪切板」；
3. 打开 CatNote，进「我的」-「笔记设置」-「导入笔记」，点「粘贴」再点「提交」。

导入完成后划线内容会生成对应笔记，你可以给它们打上书名或主题标签，方便以后按标签回看。

## 五、API 输入：程序化录入

内容量很大、或想从其他软件自动推内容进来时，可以用接口录入。这是会员功能，需要一定开发能力：

```text
POST https://api.catnote.cn/sapi/yoursecret
Content-Type: application/json

{
  "content": "你好，CatNote!"
}
```

要点：

- 接口地址里的 `yoursecret` 是你的个人密钥，完整地址在「笔记设置」的 API 模块点「复制地址」取得，不要泄露给他人；
- 参数 `content` 是笔记文本内容，单条最大 5000 字；
- 请求方法为 POST，`Content-Type` 为 `application/json`；
- 批量导入有频次限制：官方常见问题页写明 API 导入限制为**每天 100 条**，大批量搬运要分天做。

录入完成后，同样可以按标签和双向链接把批量内容组织起来；如果你还想把整库备份出去，导出流程见[多端同步与笔记导出](多端同步与笔记导出.md)。
