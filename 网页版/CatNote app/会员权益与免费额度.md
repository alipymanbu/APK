CatNote 的免费版不是阉割版试用：卡片记录、多级标签、合并笔记、热力图、多端云同步这些主功能都不限时长免费。会员加购的是几项高消耗或进阶能力，差异全部列在下面这张表里，买不买可以对着算。

## 一、免费与会员权益对照

| 功能 | 免费用户 | 会员 |
| --- | --- | --- |
| 图文卡片、多级标签、合并笔记、热力图 | 可用 | 可用 |
| 双向链接（正向关联） | 可用 | 可用 |
| 双向链接（反向链接列表） | 以应用内显示为准 | 官方会员页列入权益清单 |
| 多端云同步 | 永久免费，不限设备登录数 | 同左 |
| 图片存储额度 | 每月 60 MB | 每月 1 GB |
| 原图上传（不压缩） | 不支持 | 可开启 |
| 文字识别（OCR） | 每月 3 次 | 权益内使用 |
| 微信语音输入（自动转文字） | 不支持 | 支持 |
| API 输入 | 不支持 | 支持 |
| 定时回顾 | 不支持 | 支持 |
| 全量导出所有笔记 | 每月 1 次 | 无限制 |
| 同步到阿里云盘 | 支持，同步频率较低 | 支持，同步频率更高 |

文字内容不占图片额度，纯文字记录在免费版就是无限量的。各功能的操作入口分别写在[图文卡片与文字识别](图文卡片与文字识别.md)（OCR、API）与[微信输入与定时回顾设置](微信输入与定时回顾设置.md)（语音输入、定时回顾）里。

## 二、订阅方式与续订规则

会员分月度、年度、永久三档，权益内容相同，区别只在时长与折算优惠。采用一次性订阅模式：到期不会自动扣费续订，官方明确说这是刻意设计——不满意就不续，觉得好用自己再开。

具体价格以应用内会员页当时显示为准，本文不列价格数字，避免与最新定价对不上。

## 三、邀请好友能换多少会员

这是免费用户攒会员时长的主要途径，规则如下：

- 每成功邀请 1 位新用户：你得 5 天会员，对方得 7 天；
- 邀请生效条件：好友下载 App 并登录成功后，在「邀请好友」页面填你的邀请码；只限好友注册后 3 天内激活，过期作废；
- 单靠邀请攒的天数上限为 30 天；
- 好友首次购买年度及以上会员，你再得 25 天；这项要求在邀请成功后 1 年内完成首购，且次数不设上限。

## 四、图片存储空间的计算细节

图片额度是免费与会员差距最大的一项，几条规则值得单独记：

1. **按月重计**：图片用量每月从零开始累计，月底清零，不是按累计总量算；
2. **超额不清**：会员到期后，此前超额部分的图片会被保留，仍然可以查看使用；
3. **删除不退额**：删除笔记后，相关图片占用不会从当月累计值中减去（因为笔记有恢复功能）；
4. **原图上传更费额度**：会员开了原图上传后图片不压缩，单张占用会明显变大。

如果你的用法是「文字为主、偶尔配图」，免费 60 MB 每月完全够；如果习惯拍大量照片入库，先看[多端同步与笔记导出](多端同步与笔记导出.md)里的备份方案，再决定要不要为 1 GB 额度开会员。
