Aegis 里每一条账号记录叫一个「条目」，一条条目对应一个网站给的密钥。本篇讲条目怎么建、字段怎么填、绑定顺序怎么排；已经有一整柜验证器要搬过来的，直接看 [从别的验证器导入.md](从别的验证器导入.md)。

## 一、新增条目有四个入口

点主界面右下角的加号，能选到这几条路：

| 入口 | 适合的场景 |
| --- | --- |
| 扫描二维码 | 网站上给了二维码，直接对着屏幕扫 |
| 从图片识别二维码 | 二维码在电脑上、或者在截图里，把图片丢给 Aegis 识别 |
| 手动输入 | 网站只给一串密钥，或者二维码模糊扫不出来 |
| 从文件导入 | 手上已经有导出文件，一次性搬一批 |

四个入口最后落到同一张填写表单，所以下面的字段说明对它们都适用。

**扫码扫不出来**时，按这个顺序试：

1. 先确认已经给 Aegis 相机权限（系统设置 → 应用 → Aegis → 权限）；
2. 把二维码截图，改用「从图片识别二维码」这一路读图，比对着屏幕扫更稳；
3. 对着屏幕扫的话，把屏幕亮度调高、避开反光，让二维码占满取景框；
4. 三条都不行就别耗着，走**手动输入** —— 二维码里装的就是一串密钥加几个参数，手工填进去效果一样。

## 二、绑定一个账号的正确顺序

顺序错了容易把自己锁在外面，按这五步走：

1. **先在网站上开启两步验证**，让网站生成二维码或密钥；
2. **在网站确认之前别关掉那个页面** —— 多数网站要你紧接着输入一次验证码，才算开启成功；
3. **在 Aegis 里把条目建好**（下面第三节）；
4. **立刻用 Aegis 显示的当前码回填网站**，看到「已开启」之类的确认才算绑定完成；
5. **确认成功之后**，再去网站上确认一遍备用码（多数网站会另外给 8~10 个一次性备份码），把它单独存到密码管理器或纸上。

第 4 步如果反复提示验证码错误，先别急着删条目重建，按 [验证码不对怎么办.md](验证码不对怎么办.md) 对一遍手机时间和条目参数。

## 三、手动输入时每一项填什么

| 字段 | 填什么 | 注意 |
| --- | --- | --- |
| 发行人 / Issuer | 服务方名字，如 `GitHub` | 只影响显示和排序；填成网站名，日后列表里好找 |
| 账户名 / Account | 你这台服务上的账号，如邮箱或用户名 | 同一个网站有多个账号时，靠这一栏区分 |
| 密钥 / Secret | 网站给的那串字符 | 只填密钥本身，不要带上空格、换行或前后缀 |
| 算法 | 一般保持默认的 SHA1 | 只有网站明确写了才改，改了必须和服务端一致 |
| 位数 | 一般 6 位 | 少数服务用 8 位，网站会写明 |
| 周期 | 一般 30 秒 | 少数服务用 60 秒，网站会写明 |
| 类型 | 一般选 TOTP（按时间） | 只有服务端写 HOTP 时才选它 |

手动输入最容易错的是密钥：大小写敏感，且不能多空格。粘进来看一眼首尾有没有带空白。

## 四、只给了一串链接怎么办

有些网站不画二维码，只给一条 `otpauth://` 开头的链接。里面的密钥在 `secret=` 后面那一段，取到 `&` 或结尾为止，把它填进「密钥」栏，再把 `issuer=` 和 `label` 里的名字填进发行人、账户名。

不要把整条链接粘进密钥栏 —— 那样算出来的码和网站对不上，且报错时看不出原因。3.4.1 这一版没有「从剪贴板识别链接」的入口，那是更晚版本才加的功能；升级前只能按上面的办法手工摘。

## 五、条目建好之后

- **改名、换组、指定图标**：长按条目进编辑，可以改发行人/账户名、换图标、分配到分组。分组和多选过滤的用法见 [图标分组与界面设置.md](图标分组与界面设置.md)。
- **重复条目会主动问你**：新增时若同名同发行人已经存在，Aegis 会弹出对话框让你选「覆盖」还是保留两条，覆盖不可撤销 —— 在两个账号用了同一个发行人名字时尤其要看清再点。
- **删条目不可撤销**：删除前确认这个网站的登录不依赖它，或者你手上还有备份码。

## 六、加完两三条就做一次导出

条目攒起来之后再补备份，风险是中间这几天出的问题没人兜。加完几个关键账号就按 [备份与换手机迁移.md](备份与换手机迁移.md) 导出一份加密文件放着，条目的增减无所谓，格式都一样。
