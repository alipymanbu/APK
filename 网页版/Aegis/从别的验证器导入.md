换验证器最怕的是搬过去发现少了几个码，而少的那几个恰好是登录别的账号时要用的。本篇把导入来源、各自需要的文件和先后顺序列清楚，重点在「导入之后怎么确认没丢」。

## 一、导入前先明确一件事

Aegis 的引导流程只有「导入 Aegis 保险库」这一个入口 —— 也就是新手机接管旧手机的 Aegis 备份。从**其他**验证器搬数据，必须先把引导走完，再到 **设置 → 导入与导出** 里操作。这是入口位置，不是权限问题，找不到别以为是版本不对。

导入与导出里有两条路：

- **从文件导入**：把别的应用导出的文件交给 Aegis 解析，不需要 root；
- **从应用导入**：直接读手机上已装的验证器的数据，这个入口需要手机已 root。

优先用第一条。只有对方根本不提供导出文件时，才考虑第二条。

## 二、官方支持的导入来源

下表按官方项目说明整理，`从应用导入` 一列标了是否通常需要 root：

| 来源 | 要准备什么 | 是否通常要 root |
| --- | --- | --- |
| Google Authenticator | 旧机导出的转移二维码 | 否 |
| Authy | 无官方导出文件，需读取 Authy 应用数据 | 是 |
| Microsoft Authenticator | 读取已安装应用的数据 | 是 |
| andOTP | 备份文件（分新旧两种格式） | 否 |
| FreeOTP / FreeOTP+ | 读取已安装应用的数据或备份文件 | 视情况 |
| 2FAS Authenticator | 备份文件（可能是加密的） | 否 |
| TOTP Authenticator | 备份文件（可能是加密的） | 否 |
| Authenticator Plus | 文本 + HTML 形式的导出文件 | 否 |
| Steam | Steam 的 `maFile` / 令牌导出 | 视情况 |
| WinAuth | WinAuth 导出的文件 | 否 |
| Proton Authenticator | 备份文件（可能是加密的） | 否 |
| 纯文本 | 每行一条的密钥清单 | 否 |

官方对导入来源的支持会随版本增加（3.4.1 新增的就是从 Proton Authenticator 导入），表里没有的应用不代表不能用，可以先按「纯文本」自己整理一份。

## 三、从 Google Authenticator 导入

这条路径最常用，也最容易做漏一步：

1. 在**旧手机**打开 Google Authenticator，点右上角菜单 → **转移账号 → 导出账号**；
2. 此时旧机会显示二维码，**可能不止一个**（码多的时候是分屏轮播的）；
3. 在新手机的 Aegis 里走 **设置 → 导入与导出 → 从文件导入**，或在新增条目时选扫描二维码，对着旧机屏幕逐个扫；
4. **把所有二维码都扫完再确认**。官方在只扫到一部分时会明确警告「有一部分二维码没被导入」，并列出缺失的站点名；
5. 导入完成后，先别删 Google Authenticator，按第五节逐条验证。

第 4 步那个警告不要点掉就算过：那意味着有账号的码没搬过来，等你删掉旧应用之后就再也补不回来了。

## 四、其他几家要注意的地方

- **Authy**：官方没有提供能直接导出的备份文件，Aegis 对应的做法是读 Authy 应用本身的数据，一般要求手机已 root。没有 root 又不想 root 的话，更稳的是逐个网站重新绑定，而不是指望导出 —— 这也是换验证器时最容易卡住的一家。
- **andOTP**：备份文件有新旧两种格式，导入时 Aegis 会让你先选是哪一种（0.6.3 及以后的算新格式，0.6.2 及以前是旧格式）。选错会读不出条目，换一下再试即可，不会损坏原文件。
- **2FAS / Proton / TOTP Authenticator**：备份文件本身可能是加密的，导入过程中会弹窗要密码。这个密码是**对方应用当初设的那个**，不是 Aegis 的保险库密码。
- **Authenticator Plus**：`Settings → Backup & Restore → Export as Text and HTML` 导出的文件才行，`.db` 格式官方不支持。若导出的是带密码的 ZIP，先解开再导入。
- **Microsoft Authenticator**：工作/学校账号的条目可能受组织策略约束，导不出来的那部分只能回原应用继续用。

## 五、导入之后必须做的三件事

1. **逐条验证**：挑风险最高的几个账号（邮箱、网银、主用社交）各登录一次，用 Aegis 的码走完登录。不要只看「条目在列表里」就算成功。
2. **对一遍条数**：导入时 Aegis 会提示本次导入了多少条、跳过多少条。把这个数字和自己印象里的账号数对一下，差得多就回去查缺失的那部分。
3. **立刻做一次备份**：导入完的保险库就是新的完整版本，按 [备份与换手机迁移.md](备份与换手机迁移.md) 导出一份加密文件放好，再考虑卸载旧验证器。

验证那一步发现有码对不上，多半是条目参数（算法、位数、周期）沿用了默认值，处理办法在 [验证码不对怎么办.md](验证码不对怎么办.md)。
