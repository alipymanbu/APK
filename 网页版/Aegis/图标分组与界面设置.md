# Aegis 图标分组与界面设置

> 条目攒到几十条之后，靠翻单子找码会很慢：这一篇讲排序、搜索、分组、图标包和外观显示怎么配。

条目少的时候什么都不用配，几十条之后就得靠排序、搜索和分组把这堆码管起来。这一篇只讲界面和查找相关的设置，不解锁流程（那是 [保险库密码与生物识别.md](保险库密码与生物识别.md) 的事）。

## 一、排序：五种方式按习惯挑

主界面顶部有排序入口，可选的方式有：

| 排序方式 | 什么时候合适 |
| --- | --- |
| 发行人（A→Z / Z→A） | 默认思路；找某个网站的码时最快 |
| 账户（A→Z / Z→A） | 同一个网站有多个账号时，按账号名排更顺 |
| 使用次数 | 常登的那几个会被顶到前面 |
| 最近使用 | 按最近用过的顺序排，适合集中处理几个账号 |
| 自定义 | 手动把常用的拖到固定位置，顺序由你定 |

固定用某一种都行，但**别把「自定义」当成临时手段**：一旦手动排过，之后新增条目不会自动插到合适的位置，得再拖一次。

## 二、搜索：搜哪些字段可以自己定

搜索框的匹配范围可以在设置里勾选，可选的是**名称、发行人、备注、分组**这几类：

- 只勾名称和发行人，适合「记得网站名、不记得账户名」的情况；
- 把**备注**也勾上，只有你先给条目写过备注才有意义 —— 备注是编辑条目时可以填的自由文本，适合记「这是哪个环境的账号」；
- 把**分组**也勾上，输入组名就能一次筛出那一组；
- 勾得越多，结果越多也越杂，条目上百条时反而不好用。

跟排序配合用效率最高：先按分组或排序把范围收窄，再输关键词。点一下码是复制还是显示，是另一套开关，见 [验证码的显示与复制怎么设置.md](验证码的显示与复制怎么设置.md)。

## 三、分组：把「工作」「个人」「家人的」分开

分组是长按/编辑条目时指定的，主界面上可以按分组过滤：

- **新建分组**：在条目的编辑界面直接输入分组名，或用设置里的「编辑分组」统一管理；
- **不分组也有一处**：没指定分组的条目会归在「无分组」下，不会消失；
- **同时看多个分组**：设置里有「分组多选」开关，打开后可以一次选中好几组一起看；
- **清理空组**：设置里有「删除未使用的分组」，会把没有任何条目在用、但名字还留在列表里的组删掉；
- **删分组不等于删条目**：移除某个分组后，原本在该组里的条目会回到「无分组」，码本身还在。

## 四、图标包：让每条码一眼能认出来

Aegis 支持导入图标包，给条目指定图标后列表扫一眼就能认出来。官方没有自己出图标包，社区维护的资源里比较常提到的是 [aegis-icons](https://github.com/aegis-icons/aegis-icons)。

用法：

1. 在 **设置 → 图标包** 里点加号，导入一个图标包文件；
2. 到条目的编辑界面，给这一条指定图标；不指定就继续用自动生成的字母图标；
3. 同一个图标包重复导入会问你「是否覆盖」；不需要了可以在同一页删掉；
4. 删除图标包**不会**影响已经用上该图标的条目 —— 它们会保留当前的图标，只是以后不能再从这一包里挑了。

## 五、外观这一页的几项分别管什么

| 设置项 | 作用 | 什么时候值得改 |
| --- | --- | --- |
| 主题 | 在浅色 / 深色等几套配色里挑一套 | 纯黑那套夜里看不刺眼，高对比屏上也更省电 |
| 动态取色 | 跟随 Android 系统主题的配色做一层覆盖 | 系统支持动态取色时，界面配色能跟系统一致 |
| 语言 | 单独指定 Aegis 的界面语言，或跟随系统 | 系统语言不是中文、但想单独用中文看它时用得上 |
| 视图模式 | 列表 / 卡片两种展示 | 条目少用卡片直观，条目多列表一屏看得更多 |
| 显示图标 | 关掉后列表只剩文字，更紧凑 | 条目名起得规范、不需要靠图标认人时 |
| 账户名显示位置 | 隐藏 / 跟在发行人后面 / 放在发行人下方 | 同一发行人多账号时，「放下方」更好读 |
| 仅必要时显示账户名 | 只当同一个发行人下有多条时才显示账户名 | 绝大多数条目只有一个账号时，列表会清爽很多 |
| 码位分组 | 把 6 位码按几位一组断开显示 | 手动敲码时不容易串位 |
| 重置使用次数 | 把「按使用次数排序」累计的计数清零 | 换了常用账号之后，让排序重新开始统计 |

这些项都在设置里的「外观」页，改完立刻生效，只影响显示、不动保险库内容，可以放心试。码的复制、高亮、提前显示下一个码这类跟出码动作有关的开关在「行为」页，见 [验证码的显示与复制怎么设置.md](验证码的显示与复制怎么设置.md)。

## 六、编辑条目和重复条目的处理

长按条目进编辑界面，能改发行人、账户名、图标、分组，也能看到算法/位数/周期这几个参数。

新增时如果和已有条目同名同发行人，Aegis 会先弹窗问怎么处理，其中「覆盖」是不可撤销的：它会把原有的同名条目替换掉。**两个不同账号恰好用了同一个发行人名字时最容易误点**，遇到这个弹窗先看清楚再选。

排序、分组都配好了还是找不到码，回头检查第二节的搜索范围勾选 —— 只勾了名称和发行人时，用组名或备注去搜是搜不出来的。找到了条目但码不对，那是另一类问题，见 [验证码不对怎么办.md](验证码不对怎么办.md)。
