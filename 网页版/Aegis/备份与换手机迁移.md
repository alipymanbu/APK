验证码这东西平时不用管，一旦丢就是「进不去所有开了两步验证的账号」。Aegis 的备份全在自己手上，没有云端帮你兜底，所以这一篇的关键不是操作多复杂，而是别把唯一那份备份和手机放在一起。

## 一、导出和自动备份不是一回事

| 对比项 | 导出 | 自动备份 |
| --- | --- | --- |
| 谁触发 | 你自己点 | 条目有变动时自动写 |
| 在哪设置 | 设置 → 导入与导出 → 导出 | 设置 → 备份 |
| 文件格式 | 与自动备份完全相同 | 与导出完全相同 |
| 前提 | 无 | 保险库必须是加密的 |

官方把两者区分得很清楚：**格式一样，触发方式不一样**。也就是说恢复时用的是同一套流程，不用管手上这份文件是导出出来的还是自动备份出来的。

## 二、导出时那几个格式怎么选

点导出后会让你选格式：

| 格式 | 用途 |
| --- | --- |
| Aegis (.JSON) | 换机恢复、以后还要导回 Aegis —— **日常就用这个** |
| 文本 (.TXT) | 交给其他支持 `otpauth` 链接的工具 |
| 网页 (.HTML) | 想在浏览器里看一眼内容时用 |
| 导出为 Google Authenticator | 生成 Google Authenticator 能扫的二维码，用于搬去那边 |

导出前还能选「导出全部分组」或只挑几个分组。迁去别的工具才需要 TXT/HTML，自己留底一律选 JSON。

**加密开关要留着**：导出的对话框里有「加密保险库」这一项，别为了省事导出成明文 —— 明文文件里是一串串能直接生成验证码的密钥，落在谁手里等于账号少了一道锁。官方在导出明文时会明确警告一句，那是该听的。

## 三、导出用哪个密码

默认情况下，**导出的加密密码就是你解锁 Aegis 的那个保险库密码**，恢复时也输同一个。

如果你想让备份文件用一个和日常解锁不同的密码，可以在 **设置 → 安全 → 备份与导出单独密码** 里打开它。开了之后有个副作用要记住：**解锁密码不再能解密备份和导出文件**，恢复时只能输那个单独的备份密码。这个密码忘了，备份文件同样等于打不开，所以要么别开，要么和保险库密码一起妥善记住。

## 四、把自动备份配起来

在 **设置 → 备份** 里，先把「自动备份保险库」打开。

1. **选备份位置**：会调起系统的文件选择器，选一个文件夹。选好后，条目一有变动就会往里写一份。
2. **选备份策略**：可以「保留若干个版本」，也可以「只留单个备份」；官方对单备份策略的提示是它不可靠 —— 一次写入失败就没有第二份了，建议保留多个版本。
3. **想同步到云上，注意前提**：Aegis 本身没有网络权限，它只能写到你指定的那个文件夹，剩下的靠系统能力完成。官方 FAQ 里提到的、能直接被 Aegis 写入的云盘是 **Nextcloud**；另一种通用做法是把备份目录设在手机本地，再让别的同步工具把那个目录同步走。
4. **打开「备份提醒」**：到期没备份时 Aegis 会提醒你。它和密码提醒是两个独立开关，都建议开着。

有两个限制要提前知道，否则会以为功能坏了：

- **保险库没加密，就没有自动备份**（系统的云备份同理）—— 这两项功能官方都只对加密保险库开放；
- **系统自带的换机迁移（设备到设备）不受上面这条限制**，明文保险库也能跟着系统迁移走。

再补两个实际会碰到的点：

- **备份策略影响的是「能不能回退」**：选「保留若干个版本」时，目录里会留下多份文件，某次误删条目还能翻上一版；选「单个备份」则每次都被覆盖，只剩最近一次。空间紧张才考虑后者。
- **备份目录是「整份覆盖」而不是增量**：同一路径上的备份文件会被整份重写，所以如果这个目录同时被网盘客户端或同步工具盯着，要确认它处理的是「同名文件更新」而不是「另存一份」，否则目录里会堆出各种副本。

## 五、换手机的完整顺序

**在旧手机上：**

1. 确认保险库密码在手（这时候还能验证：锁屏一次，看是否输得进去）；
2. **设置 → 导入与导出 → 导出**，格式选 Aegis (.JSON)，保持加密，可选全部分组；
3. 把导出的文件传出去 —— 数据线、自己的云盘、加密压缩包都行。**别只在旧手机里留一份**，你正要放弃那台手机。

**在新手机上：**

4. 装好 Aegis（见 [下载与安装教程.md](下载与安装教程.md)），走首次启动引导；
5. 引导里选「导入 Aegis 保险库」，选中刚传过来的那个文件；
6. 输入密码 —— 默认是旧手机的保险库密码；如果你在旧机上开过「备份与导出单独密码」，这里要输那个单独密码；
7. 导入完成后**先别格掉旧手机**，按下一节逐条验证。

## 六、恢复之后必须核对的三件事

1. **条数对不对**：导入时会提示导入多少条。和导出前的数量对一下，差得多说明文件不是最新那一份，回旧手机重导。
2. **抽几个账号真登录一次**：尤其是主邮箱、网银、常用社交。验证码能显示不等于能通过验证 —— 时间不同步、参数不对都会在登录这一步才暴露，处理办法见 [验证码不对怎么办.md](验证码不对怎么办.md)。
3. **把新手机的自动备份接上**：恢复过来的保险库在新机上还没有备份路径。按第四节重新选一次备份位置，并打开备份提醒。

三件都过了，再回旧手机卸载 Aegis 或直接恢复出厂。密码和备份密码这类信息，别只写在旧手机里。
