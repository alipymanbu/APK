Aegis（全称 Aegis Authenticator）是安卓上的两步验证码工具，把各网站的两步验证口令集中存在手机本地，全程不联网。本篇只解决第一步：把网盘里这份 3.4.1 装好，并让首次启动的设置做完、能正常出码。

## 一、先核对网盘里这份包是哪一版

网上能搜到的多是官方当前最新版，和网盘里这份往往不是同一个版本号。本篇出现的版本、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Aegis（Aegis Authenticator） |
| 版本号 | 3.4.1 |
| 包名 | `com.beemdevelopment.aegis` |
| 安装包体积 | 6.26 MB |
| MD5 | `94910108D90A6B408CC9E011200286BB` |
| 开发者 | Beem Development |
| 开源许可 | GPL-3.0 |
| 支持的平台 | Android 6.0 及以上 |
| 核对时间 | 2026-09-23 |

安装包本体在 [Aegis 安装文件资源（夸克网盘）](https://pan.quark.cn/s/49eadd1f2342) 里，转存到自己的网盘再下载到手机。

几点要分清：

- **官方渠道在哪**：官网是 [getaegis.app](https://getaegis.app/)，源码与发布包在 [github.com/beemdevelopment/Aegis](https://github.com/beemdevelopment/Aegis)，应用商店页分别是 [Google Play 上的 Aegis](https://play.google.com/store/apps/details?id=com.beemdevelopment.aegis) 与 [F-Droid 上的 Aegis](https://f-droid.org/packages/com.beemdevelopment.aegis)。想确认手上这份是不是同一款，认包名 `com.beemdevelopment.aegis` 最快。
- **版本会往前走**：官方在 3.4.1 之后还发布过 3.4.2 等更高版本，界面与新增功能（例如从剪贴板识别 `otpauth` 链接）只在更新版本里才有；具体哪天是哪一版以官方发布页当时显示的为准。本文按 3.4.1 写，个别菜单位置在新版里可能不同。
- **MD5 怎么用**：下载完用文件管理器看文件详情，或找任意校验工具算一次 MD5，与上表一致说明传输过程没损坏；体积明显小于 6.26 MB 就是没下完。
- **只有安卓版**：官方 FAQ 里明确说没有把 Aegis 移植到 iOS、Windows、macOS 或浏览器扩展的计划，网盘里这份就是安卓安装包；想在电脑上跑只能借模拟器一类的环境。

## 二、装之前先确认两件事

1. **系统版本**：这一版最低要求 Android 6.0（内部标识 23）。低于 6.0 的机器装不上，别硬试。官方发布页与 F-Droid 页面都会标注当版的最低系统要求，换版本时以那里写的为准。
2. **先别动手机上原来的验证器**：如果现在用的别的应用里还存着正在用的码，不要先卸载。正确顺序是「Aegis 装好 → 把码导进来 → 逐条验证码能对上 → 再处理旧的」，具体见 [从别的验证器导入.md](从别的验证器导入.md)。
3. **顺带看一眼它申请什么权限**：相机（扫码）、文件访问（导入导出、写备份）。**没有网络相关权限** —— 装完在系统的应用信息里能看到这一条是空的，这也是它开头说的「完全离线」的依据。

## 三、安装步骤

1. 把安装包下载到手机。在电脑上下载的话，用数据线或任意传输工具拷进手机存储都可以。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统常把这一项收在「安全」「隐私」「更多安全设置」下面。
3. **点开 APK 完成安装**：系统提示「应用未经过安全检测」时选继续安装，这是第三方渠道安装包的常规提示。
4. **装完先别急着找码**：下一节的首次启动不设完，Aegis 不会让你新增条目。

安装被拦下时，不同提示对应的情况不一样，按这张表对：

| 系统提示 | 原因 | 处理 |
| --- | --- | --- |
| 解析包错误 / 解析包时出现问题 | 下载不完整或文件损坏 | 重新下载，下完核对体积是不是 6.26 MB、MD5 是否与上表一致 |
| 应用未安装 | 手机上已装了同包名且签名不同的版本 | 先卸载旧版再装；旧版的保险库文件会一起被清掉，卸载前先导出 |
| 已阻止安装 / 安全提示 | 未知来源开关没打开 | 回到第 2 步，给打开安装包的那个应用开权限 |

## 四、首次启动：把保险库的解锁方式设完

首次启动是几屏引导，最后落到保险库的解锁方式上。这一步做完才算装好。

1. **设解锁凭据**：引导会让你给保险库设密码，或用指纹/面容这类生物识别来解锁。Aegis 的保险库按官方规范也可以明文保存，但一旦不加密，「自动备份」这类依赖加密的功能就用不了（见 [备份与换手机迁移.md](备份与换手机迁移.md)）。
2. **建议密码和生物识别都留着**：生物识别解锁依赖手机的安全芯片，换指纹、改锁屏密码、系统更新都可能让它失效，那时只能靠密码进保险库。相关处理见 [保险库密码与生物识别.md](保险库密码与生物识别.md)。
3. **打开密码提醒**：设置里有一项「密码提醒」，到期就会让你输一次密码。官方出于「忘密码等于丢数据」的考虑不建议关掉它。
4. **引导里只有「导入 Aegis 保险库」这一个入口**：想从别的验证器搬数据，得先把引导走完，再去设置里的「导入与导出」，路径见 [从别的验证器导入.md](从别的验证器导入.md)。

## 五、装完做一次最小验证

1. 挑一个已经在用的账号，在它的安全设置里开启两步验证，用 Aegis 扫码或手动录入；
2. 退出登录再登一次，用 Aegis 当前显示的 6 位码走一遍完整登录；
3. 登录通过后，立刻按 [备份与换手机迁移.md](备份与换手机迁移.md) 做一次导出或打开自动备份 —— 这一步别拖，手机丢了或刷机了就没有第二次机会。

三项都过了，说明这份包装得没问题。第 1 步扫码没反应的话，换成图片识别或手动输入，具体见 [添加验证码与绑定账号.md](添加验证码与绑定账号.md) 第一节；第 2 步码老是不对，先看 [验证码不对怎么办.md](验证码不对怎么办.md)。

## 六、以后怎么更新到新版本

网盘里这份是 3.4.1，官方之后又发布过更高版本。更新本身不复杂，但有一个前提不能省：

1. **更新前先导出一次**：按 [备份与换手机迁移.md](备份与换手机迁移.md) 导出一份 Aegis (.JSON)。原因是下面第 2 条里的第二种情况最后会走到卸载重装，而卸载会把本地保险库一起清掉。
2. **用新安装包覆盖安装**：包名相同、签名相同就能直接覆盖升级，**条目都在保险库里，不会因为覆盖安装而丢**。如果系统提示「应用未安装」，说明新旧两份包不是同一把密钥签的（换了安装渠道时常见），这时只能先卸载再装 —— 所以第 1 步的导出别跳过。
3. **装完核对一次**：在应用信息里看版本号是不是换成新包了，再随手打开一条条目，确认码还在正常出。
4. **版本从哪来**：官网与源码发布页给出的版本更新最快，应用商店那两份可能要等上架（F-Droid 常见延迟几天）。走哪条路都行，认包名 `com.beemdevelopment.aegis` 就不会装错。
