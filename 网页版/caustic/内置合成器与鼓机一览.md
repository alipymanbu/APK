## 一、12 种机器对照表

一台机架最多放 **14 台可更换机器**，机器类型官方共列出 12 种，想重复用同一种也可以（比如摆两台 PCMSynth 载不同音色）。机架里另有 4 台固定机器（效果架、调音台、母带、序列器），不占这 14 个槽位，本篇只讲可更换的音源机器：

| 机器 | 官方定位 | 适合做什么 |
| --- | --- | --- |
| Subsynth | 虚拟模拟减法合成器 | 经典合成器音色：贝斯、主奏、铺底都行 |
| PCMSynth | 多采样波形合成器 | 载自己的采样当音色，自由度最高 |
| BassLine | 303 风格单音合成器 | 贝斯线、单音旋律，电子味正 |
| BeatBox | 8 通道采样鼓机 | 鼓点主力，每个通道可以换自己的采样 |
| PadSynth | 谐波表铺底合成器 | 长 pad、氛围铺底 |
| 8BitSynth | 8bit 方程式合成器 | 芯片音乐、复古电子游戏味 |
| Modular | 全可配置可路由合成器 | 自己搭信号路径，进阶玩法 |
| Organ | 风琴（音轮 + 旋转扬声器） | Hammond 类风琴音色 |
| Vocoder | 8 段声码器 | 机器人声、人声处理，需要外部音频输入 |
| FMSynth | DX 风格 3 算子 FM 合成器 | 电钢琴、钟铃、金属质感音色 |
| KSSynth | Karplus-Strong 弦建模合成器 | 拨弦、弹拨类音色 |
| SawSynth | 超级锯齿波复音合成器 | 宽厚的锯齿波和弦 |

## 二、按需求选型

- **从零开始**：Subsynth + BeatBox 两台就够起步，见 [编曲流程入门.md](编曲流程入门.md)；
- **想用自己的音色**：PCMSynth（支持 WAV 与 SoundFont）、BeatBox、Vocoder 都能喂你自己的文件，导入细节见 [采样与音源导入方法.md](采样与音源导入方法.md)；
- **做 8bit / 芯片风**：8BitSynth；
- **要电钢、铃铛、金属音色**：FMSynth；
- **喜欢折腾**：Modular，所有模块自己接；
- **处理人声**：Vocoder，需要先有外部音频（录一段人声采样再进声码器）。

不确定选哪台时，先把机架空槽点开挨个试 preset，比看参数表直观。

## 三、每台机器的效果槽

每台机器带 **2 个效果槽**，效果类型官方页面标注为 16 种（部分页面写 20 种，以应用内实际列表为准）。用法上的分工：

- 机器自己的效果槽管「这台的音色修饰」，进机器的效果面板各挂一个；
- 调音台的全局 Delay/Reverb 管「整个混音的空间感」，在混音阶段统一送；
- 母带部分的参数 EQ 与限制器管最终响度与频段收尾。

三层各管一段，别把所有效果都塞进机器槽里——全局混响统一送出去，比每台机器各挂一个更省、也更好控制。

## 四、音色从哪来

每种机器都带预设（preset），应用内可以直接切换；官方在 [www.singlecellsoftware.com](http://www.singlecellsoftware.com) 提供更多 preset 下载。想用自己下载的音色包、SF2 音源或采样文件，看 [采样与音源导入方法.md](采样与音源导入方法.md)。

机器加了但不出声、或效果怎么调都不对劲，先去 [常见问题与排查.md](常见问题与排查.md) 对一遍清单。
