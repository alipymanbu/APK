# 编曲流程入门

> 这篇按「搭机架 → 写 pattern → 排歌曲 → 混音」的顺序，讲在 Caustic 里做出第一首曲子的完整流程。

## 一、先认机架

打开应用后你面对的就是一个机架。按官方手册的口径，机架由两部分组成：**最多 14 台可随时更换的机器**（都是出声的音源类），加上 **4 台固定机器**——效果架、调音台、母带和序列器。每种可更换机器的用途和选型在 [内置合成器与鼓机一览.md](内置合成器与鼓机一览.md) 里有完整对照表，这里只讲流程。

加机器走「机器管理」屏：点控制面板左侧的机器按钮进去，在空槽上挑一种。加错了可以移除再换，但**移除机器时，这台机器里做过的东西会一起消失**（官方手册明确提醒），动手删之前想清楚。

## 二、搭一个最小可用的机架

第一次编曲建议就三台：

| 槽位 | 机器 | 干什么 |
| --- | --- | --- |
| 1 | BassLine 或 Subsynth | 写主旋律 / 贝斯线 |
| 2 | BeatBox | 敲鼓点 |
| 3 | PCMSynth | 补一个铺底或和弦垫（要用自己找的音色就选它，见 [采样与音源导入方法.md](采样与音源导入方法.md)） |

这个配置够写完一整首 demo。等哪一台不够用了再加，比预先规划省事。

## 三、给每台机器写 pattern

每台机器自带自己的音序部分：合成器里按步写入音符，BeatBox 里按通道排鼓点。你在应用里看到的大多数旋钮、推子，都能在录制的状态下拧动，参数变化会被记成自动化曲线，事后还能用编辑器改曲线形状。

写 pattern 的建议顺序：

1. 先把 BeatBox 的一段鼓点写稳，速度定下来；
2. 再往 BassLine/Subsynth 里填音符，跟鼓点对齐；
3. 最后加 PCMSynth 的铺底，撑开频率空间。

## 四、从 pattern 到歌曲

单个 pattern 循环不是曲子。先把控制面板中间的播放模式开关从 Pattern 切到 Song（官方手册的标准流程顺序），再到歌曲序列器（song sequencer）里把各机器的 pattern 排成有前奏、主歌、副歌的完整结构：重复、交错、留白都在这一层完成。

排歌曲时常见的两个坑：

- 每台机器只排一条 pattern 从头到尾，曲子会显得呆板——多写几条变奏交替用；
- 一上来就排五分钟长度——先把 30 秒的结构排顺，再往外扩。

## 五、混音与母带

调音台管两件事：每台机器的音量与声像平衡；全局的 Delay/Reverb 效果量。母带（master）部分提供参数 EQ 和限制器，用在最后控制整体响度。

动手顺序建议：

1. 先把各机器的音量摆平，别急着加效果；
2. 需要空间感的机器（比如铺底）送一点全局 Reverb，鼓组少送；
3. 最后用母带 EQ 切掉多余的频段，再用限制器收尾。

每台机器还有自己的效果槽，用法见 [内置合成器与鼓机一览.md](内置合成器与鼓机一览.md) 的效果一节。

## 六、automation：让参数自己动

绝大多数控制都支持自动化：录制状态下拧旋钮，曲线就记下来了；录完可以进编辑器精修。自动化分两层（官方手册口径）：**pattern automation** 跟着段落走，该段落每次在歌曲里出现都会重放；**song automation** 贯穿整曲长度。适合上自动化的参数：滤波器开合、效果湿度、音量推子——这些一动，曲子的「呼吸感」就有了。

## 七、演示版下走到这一步之后

整套流程在演示版里全部能跑，但**保存和导出是禁用的**：退出应用时当前歌曲会被自动保留，下次打开接着改；想拿到 WAV/Ogg/MIDI 成品文件，需要官方解锁键，导出界面的具体用法见 [导出歌曲与格式选择.md](导出歌曲与格式选择.md)。做完一段觉得值得继续，再考虑购买也不迟。

曲子做完发现哪台机器不顺手，先去 [常见问题与排查.md](常见问题与排查.md) 对一对是不是配置问题，再决定换不换。
