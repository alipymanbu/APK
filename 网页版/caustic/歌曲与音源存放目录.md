# 歌曲与音源存放目录

> 这篇讲 Caustic 把歌曲、预设、采样放在设备哪些目录里、怎么用这些目录做备份与迁移，以及第三方音色包是怎么装进来的。

## 一、都收在 caustic 文件夹里

应用把文件存在**用户可访问的存储**的 `caustic` 目录下——官方手册与各家音色包的安装说明都指向这个根目录。目录内按内容分家：

| 目录 | 放什么 |
| --- | --- |
| `caustic/presets/<机器名>/` | 各机器的预设，例如 `presets/pcmsynth/`、`presets/beatbox/` |
| `caustic/samples/<机器名>/…` | 采样文件，例如 `samples/pcmsynth/` |
| 歌曲文件 | 同在这套用户可访问存储里，具体子目录以应用内保存对话框显示为准 |

因为都在公开存储，用电脑的文件管理器就能直接翻看、整理、拷贝这些文件，不依赖应用本身。

## 二、备份与换机

- **换机迁移**：把整个 `caustic` 目录拷到新设备的同位置；
- **阶段备份**：拷出一份改名副本即可；
- 演示版没有手动存档功能（只有自动保留的当前歌曲），成规模的多版本备份在解锁、能正常保存之后才用得上。

## 三、文件进出的三条路

1. **USB 数据线**：手机连电脑，直接读写 `caustic` 目录；
2. **应用内 FTP 服务器**：应用里可以启动一个可选 FTP 服务，同一局域网内用电脑的 FTP 客户端连手机互传，不用插线；
3. **第三方内容包（安装器 APK）**：市面上不少音色/采样包做成安装器 APK，装上后把预设与采样释放到 `caustic/presets/…`、`caustic/samples/…` 的对应子目录，释放完成后安装器本身可以卸载。
