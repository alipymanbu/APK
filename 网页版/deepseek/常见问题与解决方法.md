# DeepSeek 常见问题与解决方法

> 本篇汇总 DeepSeek 手机版用起来最常撞到的问题：服务器繁忙、收不到验证码、上传失败、历史记录不见，每条给可执行的排查步骤。安装问题另见 [下载与安装教程.md](下载与安装教程.md)。

## 一、提示「服务器繁忙，请稍后再试」

被问得最多的一条。这是服务端负载问题，不是你手机坏了。

- 隔几分钟再发同一条消息，多数时候就能过；
- 把一大段任务拆成几个小问题分次问，单次请求越重越容易撞上繁忙；
- 换个时段再试，晚间高峰更容易出现（不少用户的反馈集中在这个时段）；
- 官方网页版 [https://chat.deepseek.com](https://chat.deepseek.com) 与手机端同一账号，一边繁忙可换另一边。

这一条足够独立成篇，专门的等与绕的办法（含接入 DeepSeek 模型的替代平台）整理在 [服务器繁忙请稍后再试怎么办.md](服务器繁忙请稍后再试怎么办.md)。

## 二、收不到短信验证码

1. 等 60 秒倒计时结束再点重发；
2. 核对手机号与国家区号；
3. 翻骚扰拦截，验证码短信常被误拦；
4. 大陆手机号用户直接改用微信登录，绕开短信；
5. 换个时段再试。

更完整的登录排查见 [注册登录方法与账号同步.md](注册登录方法与账号同步.md)。

## 三、文件 / 图片上传失败

- 先确认网络可用，换 Wi-Fi 和流量各试一次；
- 文件过大或格式冷门时，转成 PDF、Word、TXT、图片这类常见格式再传；
- 旧版本应用可能出现上传异常，更新到官方最新版再试；
- 不需要整个文件时，把相关段落复制进输入框，比传文件更快。

## 四、历史会话不见了

- 大概率是登录方式变了：手机号、微信、邮箱各是不同账号，退出后用**原来那种方式**登录；
- 不确定用哪个号注册的，去网页版 [https://chat.deepseek.com](https://chat.deepseek.com) 逐个试登录方式，记录还在的那个就是原账号；
- 找到入口后历史会话按时间排，往下滑能翻到更早的对话。

会话删了找不回、想提前导出留底的问题，见 [聊天记录导出与删除方法.md](聊天记录导出与删除方法.md)。

## 五、界面一直转圈 / 无响应

1. 关掉应用重新打开；
2. 确认能上网（换 Wi-Fi / 流量对比一下）；
3. 清应用缓存或卸载重装——聊天记录存在账号里，重装不会丢；
4. 仍无响应可能是服务端临时故障，过段时间再试。

## 六、其他

- **回答内容过时**：默认回答不联网，开「联网搜索」再问（用法见 [深度思考与联网搜索怎么用.md](深度思考与联网搜索怎么用.md)）。
- **想在电脑上用**：浏览器打开官方网页版即可，同一账号记录互通，差别对照 [手机版与网页版功能对比.md](手机版与网页版功能对比.md)。
- **装不上、闪退、解析失败**：属于安装环节的问题，处理步骤在 [下载与安装教程.md](下载与安装教程.md)。
