## 一、登录方式一览

打开应用第一件事就是登录，登录后才能发消息。入口按账号类型分两类：

| 你的情况 | 可用方式 |
| --- | --- |
| 中国大陆手机号 | 手机号 + 短信验证码；微信授权登录；部分设备支持一键登录 |
| 海外用户 / 有对应账号 | 邮箱注册登录；Google 账号；Apple ID |

用哪种方式注册，以后就用哪种方式登录——手机号、微信、邮箱注册的是不同账号，换一种方式登录看到的是另一个账号的空白记录。

## 二、手机号验证码登录（中国大陆）

1. 打开应用，在登录页输入手机号。
2. 点「发送验证码」，等短信到达。
3. 填入验证码，勾选同意用户协议与隐私政策。
4. 点登录，进入对话页。

首次登录即自动完成注册，没有单独的注册流程；之后这台手机会保持登录状态，不必每次都输验证码。

## 三、微信登录

在登录页选微信方式，会拉起微信授权页，确认后返回应用即完成登录。同一微信号下次登录，回到的是同一份聊天记录。

## 四、邮箱 / Google / Apple ID

官方国际渠道的版本支持邮箱注册（填邮箱、设密码或收验证邮件）、Google 账号登录与 Apple ID 登录。这一套入口在国内应用商店上架的版本里可能不出现，看不到就说明你装的是大陆渠道包，用手机号或微信即可。

## 五、验证码收不到怎么办

1. 等 60 秒倒计时结束再点重发，连续快速点重发反而更容易被限流。
2. 核对手机号有没有输错；海外号码要选对国家区号。
3. 翻一下系统的「骚扰拦截 / 拦截信箱」，验证码短信常被误拦。
4. 有微信就用微信登录绕开短信，不必死磕验证码。
5. 仍收不到就换个时段再试，验证码通道偶发拥堵。

## 六、聊天记录怎么跨设备同步

聊天记录存在账号里，不在单台手机上。所以：

- 换手机、卸载重装后，用**原来那种方式**登录同一账号，历史会话原样回来；
- 网页版 [https://chat.deepseek.com](https://chat.deepseek.com) 与手机 App 是同一账号体系，电脑上登录后能看到同一份记录；
- 想在电脑上接着手机上问了一半的话题，直接在网页版里找到那段会话继续。

反过来，发现记录「没了」，第一反应是检查登录方式有没有换（手机号换微信、微信换邮箱都会变成另一个账号）。

删除会话、导出数据留底的操作在 [聊天记录导出与删除方法.md](聊天记录导出与删除方法.md)——删除不可恢复，重要对话建议先备份。

## 七、其他登录问题

| 现象 | 处理 |
| --- | --- |
| 提示登录失败 / 网络异常 | 确认手机能上网后退出应用重开 |
| 微信授权后一直转圈 | 到微信「设置-账号与安全」的授权管理里取消对 DeepSeek 的授权，重新走一遍 |
| 验证码提示频繁 | 停几分钟再操作，或改用微信登录 |

装不上、打开就报错属于安装问题，看 [下载与安装教程.md](下载与安装教程.md)；登录成功后想用深度思考模式，见 [深度思考与联网搜索怎么用.md](深度思考与联网搜索怎么用.md)。
