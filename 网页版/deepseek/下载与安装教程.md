## 四、安装步骤

1. 在手机「文件管理」的 Download（下载）目录里找到下载好的 APK 文件，点它。
2. 首次直接安装 APK 时，系统会提示「不允许安装未知来源应用」——点「设置」，允许你的文件管理器（或浏览器）「安装未知应用」，返回后继续安装。
3. 等安装完成，12.34M 的包通常十几秒到一分钟。
4. 完成后桌面出现 DeepSeek 图标，点开进入登录页。

## 五、安装失败怎么办

| 现象 | 处理 |
| --- | --- |
| 提示「解析包出错 / 无法解析」 | 安装包没下完整：删掉重新下载，下完先看文件大小是否约 12.34M |
| 提示「与设备不兼容」 | 确认系统是 Android 8.0 及以上；过老的系统装不了新版 |
| 卡在「正在安装」很久 | 重启手机再装一次；存储空间不足也会卡住，先清理 |
| 装完点开就闪退 | 重启后再试一次；仍闪退就卸载重装，问题依旧则换官方渠道的包对比 |
