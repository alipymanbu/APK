# DeepSeek 深度思考与联网搜索怎么用

> 本篇讲 DeepSeek 输入框附近的几个开关：深度思考（DeepThink）、联网搜索、文件上传，各自适合什么场景、怎么组合用。还没装的看 [下载与安装教程.md](下载与安装教程.md)。

## 一、两个开关在哪里

在输入框附近（部分版本在输入过程中弹出）有两个可勾选的开关：

| 开关 | 做什么 | 什么时候开 |
| --- | --- | --- |
| 深度思考（DeepThink） | 回答前先展示一段推理过程，再给结论 | 数学、代码、逻辑分析、多步骤规划 |
| 联网搜索 | 先搜最新网页信息，再结合搜索结果回答 | 新闻、价格、版本更新这类时效性问题 |

两个开关互不冲突，可以单独开，也可以一起开——又新又难的问题（比如「刚发布的某个框架，用它解决某道算法题」）两个都勾。

## 二、深度思考模式

- 开启后，正式回答前会先出现一段「思考过程」，能看到它怎么拆解问题、试错、验证。
- 官方对这套模式的定位是数学、代码及各类复杂逻辑推理；问这类题开着明显更稳。
- 闲聊、翻译、查个常识不必开——思考过程会拖长等待时间，对答案质量没帮助。
- 思考过程本身就是内容：哪一步推理出了问题，顺着它追问比重新问一遍高效。

## 三、联网搜索

- 默认不联网，回答基于模型自身；勾选后会把最新网页信息拉进回答。
- 问时效性问题（今天的消息、最新版本号、最近的价格）务必开，否则容易拿到过时内容。
- 回答里会带信息来源，需要核实就点开原始出处自己看。

## 四、文件上传与文本提取

输入框附近的「+」或回形针按钮可以上传文件，应用会把文档内容提取出来再回答。官方功能列表里这一项叫「文件上传与文本提取」，适合：

- 把一整份报告、论文丢进去，先让它梳理要点；
- 基于文件内容做翻译、改写、总结，而不是复制粘贴大段文字进输入框。

上传失败、文件不认的情况，先翻 [常见问题与解决方法.md](常见问题与解决方法.md) 的文件上传一节。

## 五、语音输入

打字不方便时可以语音：系统键盘自带的语音听写直接可用；应用内部分版本在输入框右侧也提供麦克风入口。识别不准时，放慢语速、换安静环境重试，或改用键盘输入。

## 六、场景组合速查

| 你要做什么 | 推荐组合 |
| --- | --- |
| 查个常识、翻译一段话 | 都不开，直接问 |
| 解数学题、改代码 | 开深度思考 |
| 查最新消息、价格、版本 | 开联网搜索 |
| 基于一份文档提问 | 上传文件，按需再开深度思考 |
| 又新又难的复合问题 | 深度思考 + 联网搜索一起开 |

各开关的具体形态与名称随版本迭代会有变化，以应用内当时显示为准。用着出问题先看 [常见问题与解决方法.md](常见问题与解决方法.md)；想在电脑上接着聊，对照 [手机版与网页版功能对比.md](手机版与网页版功能对比.md)。
