## 一、界面是韩语看不懂怎么办

KakaoPage 面向韩国本土用户运营，界面以韩语为主；2026 年 1 月起官方做了面向海外用户的更新，支持多语言内容阅读（界面语言能否切换、能切哪些，以应用内设置与官方页面为准）。先把高频入口对照表存一份，日常够用：

| 韩语 | 意思 |
| --- | --- |
| 웹툰 | 漫画连载 |
| 웹소설 | 网络小说 |
| 책 | 书籍 |
| 요일연재 | 按星期更新的连载表 |
| 기다리면 무료 | 等待免费 |
| 선물함 | 礼物盒（每日领券处） |
| 보관함 | 收藏/书架 |
| 책갈피 | 书签 |
| 책장 | 书架（自建书单） |
| 캐시 | 现金（付费用的余额） |
| 자동충전 | 自动充值 |
| 성인인증 | 成人实名认证 |
| 더보기 | 更多 |
| 회차 | 话/章节列表 |

近期的版本更新还带来几样实用功能（以官方更新说明与应用内实际为准）：阅读记录（7.29 起，在作品主页可查自己的浏览痕迹）、漫画排行与书内文字搜索（7.30 起，能在整本小说里搜关键词）、自建书架（7.33 起，把在追的作品按自己习惯分组）。入口名字都是韩语，拿上面的对照表对号入座即可。

## 二、作品打不开或加载失败

按顺序排查：

1. **网络**：切换 Wi-Fi 与移动数据再试，海外网络环境下个别内容加载慢是常见现象；
2. **是否在服务范围内**：部分作品因版权限制只在韩国境内提供，海外登录时作品目录与韩国本地并不完全一致——搜不到某部作品，多半是这个原因，不是你操作的问题；具体成因与逐条自查见[作品搜不到与内容限制说明.md](作品搜不到与内容限制说明.md)；
3. **App 版本**：版本过旧会有接口不兼容，建议更新到新版（本文安装包为 7.33.0.6528，重装步骤见[下载与安装教程.md](下载与安装教程.md)）；
4. **单部作品打不开、其他正常**：进作品页看有没有休载（휴재）公告，作者停更或内容下架都会这样显示。

## 三、登录相关

- 短信验证码收不到、账号找回：处理步骤见[注册登录与账号设置.md](注册登录与账号设置.md)第四节；
- 提示需要韩国手机号：注册登录不需要，只有网页端充值会卡这一步，绕开方式见[PC网页版使用指南.md](PC网页版使用指南.md)第三节。

## 四、券、现金与退款规则

| 项目 | 规则（以官方页面/客服答复为准） |
| --- | --- |
| 租借券（대여권） | 通常自阅读起 72 小时内可反复看，到期后需重新取得 |
| 永久券（소장권） | 服务运营期内长期有效，换设备登录同一账号仍可看 |
| 等待免费券 | 按作品发放，只能用于对应作品 |
| 充值现金退款 | 支付后 7 天内、完全未使用的纯充值现金可申请全额退款 |
| 赠送现金 | 活动赠送的奖励现金不在退款范围内 |
| 应用商店内购 | 通过 Google Play / App Store 支付的，退款可能需要走对应商店的客服渠道 |

发生消费纠纷时，优先在 App 内客服中心提交咨询（문의하기），把支付时间与订单号带上，处理最快。充值路径怎么走、付款成功现金没到账的完整排查流程，见[现金充值与到账排查.md](现金充值与到账排查.md)。

## 五、卸载重装会丢什么

- **不丢**：账号本身、已购话数、阅读进度、收藏、现金与券——这些都挂在 Kakao 账号上，重装后登录同一账号即可恢复；
- **会丢**：设备上的临时缓存与下载内容。

所以遇到更新后闪退、界面卡死这类问题，直接卸载重装是安全的，配合上面的 MD5 校验确认包完整即可。
