## 一、登录前先弄懂一件事

Turrit 是 Telegram 的第三方客户端，登录的不是「Turrit 账号」，而是你的 Telegram 账号：

- 你在官方 Telegram 或其他客户端里注册的账号，都能直接登录 Turrit；
- 换设备、换客户端，聊天记录都在云端，登录即同步；
- 一个手机号对应一个账号，不存在「Turrit 单独再注册一遍」。

## 二、还没有 Telegram 账号：注册流程

1. 打开 Turrit，进入登录页；
2. 选好手机号区号，填入你的手机号；
3. 收到验证码后填入——验证码可能走短信，也可能发到你之前登录过 Telegram 的其他设备的应用内；
4. 按提示设置姓名，完成注册。

注册用的手机号就是账号的找回凭证，建议用自己长期在用的号码。

## 三、已有 Telegram 账号：直接登录

1. 打开 Turrit，输入手机号（注意选对区号，中国大陆是 +86）；
2. 输入验证码完成登录；
3. 如果你的账号开过**两步验证**，还要再输一次你当年设置的二级密码——那是独立于验证码的密码，忘了只能走账号找回流程。

登录成功后界面可能还是英文，切中文的步骤见 [中文界面与翻译设置.md](中文界面与翻译设置.md)。要在同一部手机上再登几个账号，见 [多账号同时登录与切换.md](多账号同时登录与切换.md)。

## 四、登录卡住的常见原因

| 现象 | 常见原因与处理 |
| --- | --- |
| 验证码收不到 | 先看有没有已登录 Telegram 的老设备，验证码常发在那里而不是短信；确认区号选对；等几分钟再点重发，频繁重发会被限制 |
| 提示验证码错误 | 验证码有效期短，超时就重新获取；别把旧短信里的码反复填 |
| 要求输入密码但忘了 | 那是两步验证的二级密码，验证码替代不了；按页面提示走找回流程 |
| 一直转圈进不去 | 退出应用重开；仍不行多半是当前网络连不上 Telegram 服务器，换一个网络环境再试 |
| 短信一直不来 | 看验证页有没有「通过电话呼叫接收」之类的选项，语音念码可作备选；再不行换网络环境重试 |

还有别的异常可以翻 [常见问题排查.md](常见问题排查.md)。
