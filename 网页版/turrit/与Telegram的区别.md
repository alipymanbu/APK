## 一、先说清关系

Turrit 不是另一款聊天软件。它基于 Telegram 的开源代码与 API 构建，登录的就是你原来的 Telegram 账号：

- 你在官方 Telegram 注册的账号，可以直接登录 Turrit，反过来也一样；
- 两边同时在线不冲突，消息走 Telegram 云端，会话记录自动同步；
- 群、频道、机器人、联系人都是同一套——换客户端不等于换圈子。

所以「区别」不在账号和数据上，而在客户端本身提供的功能与操作方式。

## 二、功能对照

| 方面 | Telegram 官方客户端 | Turrit |
| --- | --- | --- |
| 账号 | Telegram 账号 | 同一个 Telegram 账号，两边通用 |
| 同时登录账号数 | 3 个 | 官方站点宣称最多 10 个 |
| 界面语言 | 支持多语言，需进设置切换 | 内置中文语言包，安装后直接选中文 |
| 消息翻译 | 内置翻译，部分语言组合要手动开 | 聊天、频道、外链全场景翻译，发送前也可先译 |
| 下载速度 | 免费账号有速度上限 | 提供下载速度调节选项（官方宣称最高 20 倍加速，实际看网络） |
| 频道浏览 | 按会话进入 | 另有时间线方式浏览频道内容 |
| 群聊显示 | 按原群名显示 | 可给群聊加备注名，长群名不用硬读 |
| 收藏文件 | 集中在「保存的消息」 | 独立的云收藏视图，图片、视频、文件分类存放 |
| 隐私设置 | 手动逐项调 | 内置隐私检测，一键评分并按提示修复 |
| 消息过滤 | 无关键词屏蔽 | 支持关键词屏蔽、频道广告过滤、屏蔽特定用户的消息 |
| 其他 | — | 音乐播放列表、短视频信息流式的视频页、扫码加好友、自定义应用图标等 |

各功能随版本更新会有增减，以你手上客户端的实际界面为准。隐私与消息过滤的具体设置见 [隐私检测与关键词屏蔽.md](隐私检测与关键词屏蔽.md)。

## 三、什么情况下你会用得上这些差异

不替你下结论，只列两类典型场景：

- **经常读外文群或频道**：全场景翻译省去逐条复制去翻的动作，这是 Turrit 与官方版差异最大的地方；
- **手里有几个 Telegram 账号**：同时登录数放宽到 10 个，切换不用反复退出登录。

反过来，如果你只用一两个账号、聊天对象都用中文，官方客户端可能已经够用。

## 四、换用前要知道的事

- **第三方构建**：Turrit 由第三方团队（SEASTAR FUTURE HOLDING PTE. LTD.）开发，不是 Telegram 官方出品；装不装由你自行权衡，安装包建议只从官网、应用商店这类渠道拿；
- **账号安全功能照常可用**：两步验证、登录设备管理这些都在，建议把两步验证开上；
- **更新节奏**：Turrit 更新比较频繁，版本号与官方客户端不一一对应；
- **收费口径**：官方站点宣称免费无限制，第三方应用市场信息则标注含广告与内购，装之前可到应用商店页面确认当前口径。
