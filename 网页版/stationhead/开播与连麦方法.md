## 一、先看清安卓端的现状

截至官方 FAQ 的说法（以官方页面为准）：**开播功能目前只在 iOS App 和网页版提供，安卓 App 暂时不能开播**，官方正在开发中。安卓用户能做的：

- 用手机**听**任何电台；
- 被主播邀请**上麦当嘉宾**（连麦位对安卓用户开放）；
- 想自己开播，用手机或电脑的**浏览器**打开 [stationhead.com](https://www.stationhead.com/)，登录同一个账号即可开播 —— 账号、粉丝、订阅全部互通，网页版开播照样是你的那个用户名。

## 二、用浏览器开播的完整步骤

1. 浏览器打开 [stationhead.com](https://www.stationhead.com/) 并登录（没账号先按[注册登录与流媒体账号绑定](注册登录与流媒体账号绑定.md)注册）；
2. 进个人页点 **Go on air**（开始播出）；
3. 给节目起名；
4. 测试麦克风；
5. 加歌：可以搜单曲起步，也可以直接选你流媒体账号里的整个歌单（从歌单加歌的上限是 **99 首**）；
6. 选择是否通知你的关注者；
7. 点开始，把电台链接分享出去，听众点链接就能进（浏览器听众用 Chrome 或 Safari）。

## 三、直播中能做什么

| 操作 | 做法 |
| --- | --- |
| 说话 / 只放歌 | 随时切：只说话、边说边放、只放歌 |
| 邀请连麦 | 把听众拉上来接通，像电台导播那样对话；**同时最多 3 个连麦位** |
| 管理聊天 | 左滑到评论区，点右上角三个点：可设为 All Access 专用（All Access only）或直接关闭（Disable） |
| 收打赏 | 听众送的 coins 100% 归你，平台不抽成（应用商店强制渠道费除外） |
| 结束保存 | 下线后节目记录会留在你的主页，iOS 上点开节目按右上角垃圾桶图标可删除 |

## 四、开播前的设备与网络准备

- **麦克风**：手机开播就用手机本身，像打电话一样对着它说话；插一副耳机会明显减少环境噪音；网页开播可以外接麦克风，接好再点开始；
- **网络**：WiFi 或流量都行，关键是要稳；不稳先跑个测速（[www.speedtest.net](https://www.speedtest.net/)）；
- **防打断**：把手机调成**勿扰模式**，并且确认勿扰设置里不允许任何来电穿透 —— 来电会打断你的直播；
- **断开蓝牙**：连着的蓝牙耳机/音箱会导致出声异常，开播和听歌时都要断开；
- **关后台**：直播时别在后台挂一堆别的应用，会拖垮连接。

## 五、开播失败的官方排查顺序

点 Go on air 开不起来或直播中途断，按官方 FAQ 给的顺序来：确认网络 → WiFi 不行换流量、流量不行换 WiFi → 杀掉 App 重开 → 重启手机 → 开一次飞行模式再关掉 → 关省电模式（低电量模式）→ 清掉后台应用。逐条试完还不行，在 App 里轻轻**摇晃手机**调出报告窗口提交问题。

直播开起来之后就是运营的事了：怎么让人进来听，去[听歌与加入直播电台](听歌与加入直播电台.md)看听众视角；各种连不上的坑在[常见问题与故障排查](常见问题与故障排查.md)。
