## 一、注册前必须知道的前提

Stationhead 自己**不存任何音乐**，歌曲全部从你绑定的流媒体账号里实时播放。所以：

- **必须有 Spotify Premium 或 Apple Music 订阅**，免费版 Spotify 不能用（两家都提供免费试用，能不能用看你所在地区）；
- **安卓 App 只能绑 Spotify**；用 iPhone 或浏览器网页版才可以绑 Apple Music；
- 注册免费，不绑流媒体也能浏览，但听不了歌。

## 二、注册流程（安卓 App 为例）

1. 打开 App，点 **Sign up**；
2. 选择注册方式：邮箱，或 Apple 账号登录；
3. 输入邮箱、设置密码，点 Next；
4. **认领用户名（username）**，点 Create account。

用户名这里值得停一下：

- 你以后开播、建歌单，别人都是**用这个用户名搜到你**的，起一个好搜、好念的；
- 注册完就定型，改起来要走申请流程，别随手乱起；
- 粉丝圈里应援主播时，大家传播的也是主播的用户名。

## 三、绑定流媒体账号（不绑就没声音）

注册流程的最后一步就是提示你 **Connect**（连接 Spotify），这一步**不能跳过**，跳过了进电台只有画面没有声音。

已经跳过或当时没连上的，手动补绑：

1. 进右下角自己的头像（个人页）；
2. 点齿轮图标进入 **Settings**；
3. 选 **Streaming services**（有的版本显示为 Streaming devices）；
4. 选 Spotify，登录你的 Spotify Premium 账号并确认授权。

**怎么确认绑成功**：随便进一个正在播的电台，能听到音乐就是通了；再核对一下你自己的 Spotify App 是否在播同一首歌 —— 两边同步才是真正连上了。如果 Stationhead 里没声音，去[常见问题与故障排查](常见问题与故障排查.md)。

## 四、切换与限制

| 规则 | 说明 |
| --- | --- |
| 一次只能连一个服务 | 同一账号同一时间只连 Spotify 或 Apple Music 其中一个 |
| 随时可以切换 | 在电台页右上角齿轮的设置里换绑另一个服务 |
| 安卓的限制 | 安卓 App 只认 Spotify；想用 Apple Music，用浏览器打开 [stationhead.com](https://www.stationhead.com/) 登录同一账号 |
| 换绑会断当前播放 | 切换服务的瞬间，正在听的电台会重新连接 |

## 五、Spotify 里看不到播放记录，正常吗

正常。Stationhead 是直连 Spotify 服务器发起播放的，**不会出现在你 Spotify App 的历史记录里**，但播放照样计入官方数据 —— 只要你能在 Stationhead 里听到歌，计数就在走。这一点对参加榜单应援的人很重要，别因为「Spotify 里没记录」反复重连。

## 六、Stationhead+ 要不要买

Stationhead+ 是每月 2.99 美元的订阅，目前（以官方页面为准）带来的功能只有一项：**在电台聊天和 Threads 里发 GIF 动图**。不买不影响听歌、开播、连麦。网页版也能购买，买了之后手机登录同一账号同样生效。

## 七、账号相关的几个操作

- **换头像**：点头像进自己的电台页，再点一次头像就能自定义；
- **拉黑 / 举报**：点对方的头像，选 report 或 block；
- **申请改电台名（station name）**：需要先验证账号（用注册邮箱/手机号 + 密码登录的那种）；用其他方式登录的，给 [support@stationhead.com](mailto:support@stationhead.com) 发邮件，附上你的 Stationhead 用户名和想用的登录邮箱；
- **多设备登录**：手机 App 和浏览器网页版用同一账号，进度互通。

账号弄好后，下一步是进电台听歌，见[听歌与加入直播电台](听歌与加入直播电台.md)；想自己开播的看[开播与连麦方法](开播与连麦方法.md)。
