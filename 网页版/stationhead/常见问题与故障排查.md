## 一、进电台没声音

按命中率从高到低排查：

1. **流媒体账号没绑上**：个人页 → 齿轮 Settings → Streaming services，确认 Spotify 已登录并授权；没绑的照[注册登录与流媒体账号绑定](注册登录与流媒体账号绑定.md)补绑；
2. **静音状态没解除**：手机侧边的静音开关、媒体音量、（网页版）浏览器标签页的静音都查一遍 —— 静音不只让你听不见，还可能让播放不计入，详见[挂机听歌与播放计数规则](挂机听歌与播放计数规则.md)；
3. **Spotify 不是 Premium**：免费版 Spotify 播不了，Apple Music 免费试用期内可以；账号到期也会突然没声；
4. **蓝牙设备连着**：蓝牙耳机/音箱必须断开，否则声音被路由走；
5. **网络问题**：WiFi 和流量互相切换试一次；
6. **退出重进**：离开这个电台、杀掉 App（或关掉浏览器标签）再重新进一次；
7. **通用招**：重启手机 → 飞行模式开关一次。

判断标准：进电台后打开你自己的 Spotify App，**同一首歌在同步播** = 连接正常，问题只在手机出声端（检查媒体音量、蓝牙）；**Spotify 没在播** = 绑定或登录有问题。

## 二、安卓上用不了 Apple Music

这不是故障，是现状：**安卓 App 目前只支持绑定 Spotify**，官方还没有在安卓端放开 Apple Music。想用 Apple Music 有两条路：

- 用手机或电脑浏览器打开 [stationhead.com](https://www.stationhead.com/) 登录同一账号，网页版可以绑 Apple Music；
- 换一台 iPhone 装 iOS 版。

## 三、登录不上 / 报错

- 先确认账号本身能登：Stationhead 用注册邮箱（或 Apple 账号）+ 密码登录，别和 Spotify 的密码搞混 —— 两边是两个账号；
- 用邮箱/手机号 + 密码以外方式登录的，部分需要验证账号的操作（如申请改电台名）会过不去，需要给 [support@stationhead.com](mailto:support@stationhead.com) 发邮件处理；
- 安卓 App 里遇到说不清的问题，**轻轻摇晃手机**，会弹出报告窗口，把问题提交给官方团队。

## 四、开播失败 / 直播中断

按官方 FAQ 的排查顺序逐条来：

1. 测速确认网络（[www.speedtest.net](https://www.speedtest.net/)）；
2. WiFi 与蜂窝数据互换再试；
3. 杀掉 Stationhead 重开；
4. 重启手机；
5. 开一次飞行模式再关；
6. 关掉省电（低电量）模式；
7. 清空后台应用再播 —— 后台挂太多应用会拖垮直播连接。

另外两条提醒：开播前把手机调成**勿扰模式**（来电会打断直播）；开播前**断开蓝牙**。安卓用户注意：安卓 App 本身开播功能还在开发中，开播请用浏览器走 [stationhead.com](https://www.stationhead.com/)，见[开播与连麦方法](开播与连麦方法.md)。

## 五、其他高频疑问

| 疑问 | 答案 |
| --- | --- |
| Spotify 里怎么看不到播放记录？ | 正常，Stationhead 直连 Spotify 服务器播放，不进你的 Spotify 历史；能听到歌就是在计数 |
| 挂机听了一晚上，播放好像没算？ | 查一下是不是静音了手机或标签页 —— 静音会导致播放不计入，正确挂法见[挂机听歌与播放计数规则](挂机听歌与播放计数规则.md) |
| 听着听着被莫名其妙跳回频道主页？ | DJ 换班时的已知小毛病，重新搜主播用户名再进即可 |
| 免费版 Spotify 能用吗？ | 不能，必须 Spotify Premium 或 Apple Music 订阅（两家都有免费试用，看地区） |
| 装完打开闪退？ | 先重启手机；系统版本过旧也会导致，安卓 5.2 以下装不上或跑不动 |
| 装不上 APK？ | 多半是装过 Google Play 版签名冲突，先卸载旧版，见[下载与安装教程](下载与安装教程.md) |
| 听着听着被跳到别的电台？ | 你跟的主播下线了，弹窗问你是否转入同歌手的 Channel 继续播，不想转就拒 |
| 聊天发不了言？ | 主播可能把聊天设成了 All Access 专用或直接关闭；All Access 靠每天进 Channel 攒 Active Day 换 |
| GIF 发不出去？ | 发 GIF 是 Stationhead+（每月 2.99 美元）的订阅功能 |
| 想举报/拉黑某人？ | 点对方头像选 report / block |

## 六、都没解决怎么办

在 App 里轻摇手机提交报告（安卓），或给 [support@stationhead.com](mailto:support@stationhead.com) 写邮件（附上你的 Stationhead 用户名）。报障前先把[注册登录与流媒体账号绑定](注册登录与流媒体账号绑定.md)里的绑定状态和[听歌与加入直播电台](听歌与加入直播电台.md)里的同步判断过一遍，多数「没声音」问题出在这两处。
