## 一、下载完成的文件在哪里

下载完成后，文件有两个入口可以找到：

1. **应用内「文件」页**：所有下载完成的视频、音频按列表排列，这是最直接的入口。
2. **系统文件管理器**：文件实际保存在手机存储的应用下载目录里（默认内部存储；插了 SD 卡并在设置里切换过保存位置的话就在 SD 卡上）。用文件管理器按时间排序，通常能直接看到新下载的视频；相册应用不一定把它们扫出来。

注意一点：文件保存在手机存储里，**不在应用数据里**。所以卸载重装应用不会丢已下载的视频；但清理类工具的「深度清理」可能会把它们当垃圾扫掉，用这类工具时留意白名单。在系统相册里刷不到这些视频时别慌，直接用文件管理器按上面说的目录去找；要把它们搬到电脑上，见 [下载的视频怎么传到电脑.md](下载的视频怎么传到电脑.md)。

## 二、应用内能做的整理操作

在「文件」页里，对单个文件可以做这些事：

| 操作 | 用途 |
| --- | --- |
| 播放 | 用内置播放器直接看，支持调节播放速度、循环播放 |
| 重命名 | 改成你自己认得出的名字，方便日后翻找 |
| 删除 | 不需要的文件直接删，释放空间 |
| 分享 | 通过系统分享发给别的应用（发消息、投屏工具等） |

批量整理大量文件时，按下载时间排序、配合重命名，比在系统文件管理器里翻目录效率高。

## 三、密码保护文件夹的用法

应用官方功能里有一项「密码保护的文件夹」（私密空间），用途是把指定视频从普通列表里挪进一个需要输入密码才能看的区域——适合手机会被别人拿去用、但有些视频不想被人一眼看到的场景。

设置和使用的顺序：

1. 在应用里找到「私密文件夹」入口，首次进入会让你设置密码（有的版本是图案锁，按当时界面提示来）。
2. 设好密码后，在文件列表里长按（或点菜单）选中要隐藏的视频。
3. 选「移动到私密文件夹」之类的选项，确认。
4. 之后这些视频只出现在私密空间里；要查看就得先输密码。

两个提醒：

- **密码忘了基本找不回文件**：这类本地密码通常没有「忘记密码」的找回渠道，设的时候用你自己记得住的。
- **移动而非复制**：移进私密文件夹后普通列表里就没有这条了，是「挪过去」不是「拷一份」。
- **移出同样在应用内操作**：想还原时，进私密空间选中文件，选「移出 / 还原」，文件会回到普通列表；在系统文件管理器里是看不到也拿不出私密空间里的文件的。

## 四、SD 卡与存储位置

设备空间紧张时，把下载位置切到 SD 卡是官方支持的做法。操作思路：进应用的设置，找「下载路径 / 保存位置」一类的选项，切换到 SD 卡。切换后新下载的文件会落到新位置，之前下好的文件不会自动搬过去，需要的话在系统文件管理器里手动挪。

拔插 SD 卡的时机也有讲究：下载过程中拔卡会导致当次任务失败，从卡槽状态恢复后再用续传接着下即可（续传用法见 [下载失败排查.md](下载失败排查.md)）。
