## 一、先确认文件在哪

视频默认保存在手机存储的应用下载目录里。用应用内「文件」页的分享功能可以直接把单个视频发给别的应用，这本身就是传电脑的第一步入口；要批量搬，先在系统文件管理器里定位到这些文件（找法见 [文件管理与隐私空间.md](文件管理与隐私空间.md)）。

一个前置提醒：放在**私密文件夹**里的视频在系统文件管理器里看不到，要先在应用内把它移出私密空间，再用下面的方法传。

## 二、四种传法对比

| 方法 | 适合 | 特点 |
| --- | --- | --- |
| USB 数据线 | 文件大、数量多、要原画质 | 速度最快最稳，不受 Wi-Fi 影响 |
| 微信/QQ 文件传输助手 | 文件不大、图省事 | 不用连线，但大文件可能被压缩或限制大小 |
| 云盘中转 | 跨设备、还要留一份备份 | 手机上传、电脑下载，两端都要登录同一账号 |
| 局域网互传工具 | 同一 Wi-Fi 下批量传 | 不耗流量，电脑浏览器就能收文件 |

## 三、方法一：USB 数据线（推荐大文件用）

1. 用数据线把手机连到电脑（充电线多数也能传数据，连上没反应就换一根线试试）。
2. 手机上弹出 USB 用途选择时，选「传输文件」（MTP）。**选「仅充电」电脑上就看不到手机**——这是最常见的卡点。
3. 电脑上打开「此电脑」，会多出一个以手机型号命名的盘。
4. 进内部存储，找到视频所在文件夹，复制到电脑硬盘即可。
5. 传完先在电脑右下角「安全弹出」再拔线，避免文件没写完整。

个别品牌（如华为的部分机型）会在连接说明里要求电脑端先装 Windows Media Player 11 以上版本，遇到盘符打不开就先补这个再连。

## 四、方法二：微信 / QQ 文件传输助手

1. 手机和电脑登录同一个微信（或 QQ）账号。
2. 手机上在视频列表长按选中要传的视频（或用应用内「文件」页的分享按钮，选微信）。
3. 发送到「文件传输助手」。
4. 电脑端打开文件传输助手，把文件另存到硬盘。

注意：几百 MB 以上的大视频走这条路可能提示文件过大或传输后画质被压缩，这种情况改用数据线。

## 五、方法三：云盘中转

1. 手机上把视频上传到你的网盘（夸克网盘、百度网盘等都行）。
2. 电脑上打开同一网盘的网页版或客户端，登录同一账号。
3. 找到刚上传的视频，下载到电脑。

这条路的好处是上传后手机本地那份可以删掉腾空间，电脑端随取随用；代价是要来回传两趟。

## 六、方法四：局域网互传

手机和电脑连同一个 Wi-Fi，在手机上装一个局域网文件共享类应用（FTP 服务类的就行），按应用提示在电脑浏览器里输入它给出的地址，就能在电脑上直接浏览并保存手机里的视频。适合一次搬几十个文件的场景，不耗手机流量。

## 七、传完之后

- 传电脑前别删手机里的原文件，先确认电脑上能正常播放（拖进电脑自带播放器试一下），再清理手机空间。
- 如果视频在电脑上打不开，先看文件后缀是不是完整的（传输中断会截断文件），重新传一次；格式问题的处理思路见 [下载失败排查.md](下载失败排查.md)。
