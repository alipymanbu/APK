## 一、装之前先确认这几项

| 项目 | 值 |
| --- | --- |
| 系统要求 | 安卓 5.2 及以上 |
| 包名 | `com.jwg.gesture_evo` |
| 网盘里这份的版本 | 1.4-062402 |
| 安装包大小 | 39.51M |
| MD5 | `DEE6C88122EDF66484C1A517178247EE` |
| 资费 | 下载站标注为免费、含应用内购买项目（以实际页面为准） |

包名是你辨认应用的最稳依据：装完后到「设置 → 应用 → 应用信息」里搜 `gesture`，能看到 `com.jwg.gesture_evo` 就说明装的是同一个应用。各下载站的版本号写法是「主版本号-日期」（比如 1.4-060901、1.4-090501），版本会随时间往前走，你手上那份以安装包实际显示为准。

## 二、拿到安装包

打开 [GestureEVO 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2c0129b97f2b)，先把文件夹转存到自己的网盘，再从网盘下载到手机。文件夹里除了 APK，还有一份说明 txt，别急着删。

下载到手机后可以顺手核一下 MD5，确认传输途中没损坏：

```powershell
certutil -hashfile GestureEVO_v1.4-062402.apk MD5
```

输出与上表的 `DEE6C88122EDF66484C1A517178247EE` 一致即可；不一致说明文件不完整，重新下一次。

## 三、安装

1. 点开 APK，系统会弹「禁止安装未知应用」之类的提示 —— 这是浏览器或文件管理器没有安装权限，按提示进入对应应用的「安装未知应用」开关，允许一次即可。
2. **建议用系统自带的文件管理器来装**：系统认可的安装来源，后面开无障碍不会被「受限制的设置」拦住（拦住了怎么解，见 [无障碍服务老是被关闭怎么办.md](无障碍服务老是被关闭怎么办.md) 第二节）。
3. 走完安装流程，桌面会出现 GestureEVO 的图标。
4. 首次打开时如果弹权限申请，先按下面第四节把无障碍开起来，其余权限等功能提示到了再给。

## 四、首次启动：把无障碍服务开起来

手势类工具几乎全靠系统的无障碍服务读取你的滑动动作，这一步没做，后面所有手势都是摆设。

1. 打开 GestureEVO，在首页点「无障碍」入口。
2. 点「开启手势服务」。
3. 系统确认页上点「允许」。
4. 开完返回首页，顶部状态应显示服务已开启。

开关点不动、提示「受限制的设置」，或者开完过阵子自己关了，都不是你操作错了 —— 按 [无障碍服务老是被关闭怎么办.md](无障碍服务老是被关闭怎么办.md) 处理。

开完无障碍后再点「手势」进入配置页，按 [轮盘手势怎么设置.md](轮盘手势怎么设置.md) 把触发区和轮盘配好。

## 五、让它在后台活得久一点

系统省电策略会在后台把 GestureEVO 杀掉，杀了之后手势会突然失灵。各家手机路径不同，建议你在「手机管家 / 电池 / 应用自启动」里找到 GestureEVO，允许自启动并加入后台白名单。做完这一步再遇到手势失灵，就可以先排除「被系统杀了」这个原因（排查步骤见 [常见问题与故障排查.md](常见问题与故障排查.md)）。
