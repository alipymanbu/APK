# 轮盘手势怎么设置

## 一、先把界面认全

GestureEVO 首页有五个入口，按从左到右（或从上到下）依次是：

| 入口 | 管什么 |
| --- | --- |
| 首页 / 基础设置 | 屏幕方向、触发方式、应用黑名单、触发区域 |
| 小横条手势 | 屏幕滑动、底部上滑一类的小横条手势 |
| 简易手势 | 精简版手势动作 |
| 底边三段式 | 把底边分成三段分别绑定动作 |
| 其他设置 | 游戏防误触、动画模式、Root 增强等开关 |

配置轮盘之前，无障碍服务必须是开着的（没开先走 [下载与安装教程.md](下载与安装教程.md) 第四节），否则进配置页也存不住。

## 二、基础设置：方向与触发方式

- **配置方向**：竖屏、横屏可以分开配。你横屏打游戏多，就重点调横屏那一套；日常竖屏用得多，竖屏这套调顺手就行。
- **触发方式**：滑动或点击，按你习惯选。左撇子尤其别跳过这一步 —— 触发方向和手型不匹配，后面怎么调都会觉得别扭。

## 三、触发区域：轮盘从哪儿弹出来

**轮盘的位置和形状由触发区决定**，所以配轮盘之前先画好触发区：

1. 在触发区域里勾选要启用的边：竖向分「左竖」「右竖」，横向分「左横」「右横」。
2. 进「竖向触发区设置」调尺寸和位置 —— 决定你在屏幕哪一段滑、滑多宽才会唤出轮盘。
3. 进「横向触发区设置」调横向那一段的尺寸。

调触发区时对着你拇指自然够到的位置摆。触发区太窄会唤不出来，太宽又容易在刷视频、翻页时误弹，具体取舍见 [手势误触与不灵敏怎么调.md](手势误触与不灵敏怎么调.md)。

## 四、一级轮盘：主盘内容

一级轮盘就是唤出后你直接看到的那一圈图标：

- **加内容**：在配置页里往主轮盘添加你常用的功能项（截图、返回、启动应用、调音量这类）。
- **排序**：直接拖动图标调整顺序，最常用的拖到拇指最好够的位置。
- **删除**：把图标拖到红色 X 位置。
- **修改**：把图标拖到编辑图标位置，就能改这一项绑定的动作。

## 五、二级轮盘：长按才出来的子菜单

**长按一级轮盘里的图标**，才会弹出它的二级菜单，然后照一级的方式给每个功能配下一级操作。注意顺序：先长按弹出，再配置 —— 直接点是执行动作，不会进编辑。

二级轮盘适合放「同一类的几个动作」，比如一个图标下挂竖屏锁定、横屏锁定、自动旋转开关，主盘只占一格。

## 六、轮盘外观

轮盘的颜色、大小、透明度都能改。小屏手机把轮盘调小一点、透明度调低一点，挡内容少；大屏可以放大。改完直接唤出一次看效果，不合适再回去微调。
