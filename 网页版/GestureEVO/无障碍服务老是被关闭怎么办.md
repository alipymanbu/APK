# 无障碍服务老是被关闭怎么办

> 无障碍开了一会儿自己关了、侧载安装后开关点不动、通知栏老是提醒 —— 这类系统层面的问题怎么解。

## 一、先判断你遇到的是哪一种

| 现象 | 属于哪种 | 对应章节 |
| --- | --- | --- |
| 开关点不动，提示「受限制的设置」 | 侧载安装被系统限制 | 第二节 |
| 开了，过段时间自己关了 | 省电策略/清理把它关了 | 第三节 |
| 能开，但手势时好时坏 | 后台被杀 | 第三节 |
| 通知栏常驻「可以查看和控制您的屏幕」 | 系统的无障碍提醒，正常 | 第四节 |

## 二、提示「受限制的设置」，开关点不动

安卓 13 起，**不在应用商店安装的应用，默认不允许开启无障碍**，开关会提示「受限制的设置（出于安全考虑，此设置目前不可用）」。GestureEVO 从网盘侧载安装，正好会碰到这一条。解除步骤：

1. 进「设置 → 应用 → GestureEVO → 应用信息」。
2. 找「允许受限制的设置」并打开：原生系统一般在右上角菜单里，小米在「高级设置」下。
3. 回到无障碍页再开一次；仍不行就重启手机再试。
4. 应用信息里找不到这个选项时，换用**系统自带的文件管理器**点开 APK 覆盖安装一次（不用卸载），再回来开无障碍 —— 系统认可的安装方式不会受限。

## 三、开了自己关、或手势时好时坏

根因基本都是省电策略。两条都做才稳：

1. **别让系统关它的无障碍**：在电池/省电设置里把 GestureEVO 设为「无限制 / 允许后台活动」，并在安全中心的优化名单里排除它。
2. **别让系统杀它的后台**（各家入口不同，以你手机实际菜单为准）：

| 品牌 | 大致入口 |
| --- | --- |
| 小米 | 设置 → 电量和性能 → 应用配置 → GestureEVO → 后台配置「不限制」 |
| 华为/荣耀 | 手机管家 → 应用启动管理 → 手动管理 → 勾「允许自启动」「允许后台运行」 |
| vivo | i管家 → 应用管理 → 自启动管理；再在设置 → 电池 → 后台高耗电里允许 |
| OPPO/一加/realme | 设置 → 电池 → 找到 GestureEVO → 关「后台冻结」与「异常时自动优化」 |
| 三星 | 智能管理器 → 应用程序管理 → 自动运行，开启 GestureEVO |
| 魅族 | 手机管家 → 权限管理 → 后台管理 → 允许后台运行 |

另外在最近任务列表里给 GestureEVO 的卡片**加锁**（长按卡片点锁图标），清理后台时就不会被顺手划掉。

## 四、通知栏老是提醒「查看权限设置」

系统会周期性提醒你某个应用「可以查看和控制你的屏幕」，这是安卓对无障碍应用的统一提示，不是出错。不想看到它，只能在系统通知设置里关掉该类提醒，服务本身照常运行。

## 五、压住它的耗电

觉得耗电变大，按这几条收（每条都可执行）：

- 没在用的手势套件（小横条 / 简易手势 / 底边三段式）关掉，只留你在用的那套；
- 监听白名单收窄到常用应用，别全量监听（设置路径见 [手势误触与不灵敏怎么调.md](手势误触与不灵敏怎么调.md) 第四节）；
- 游戏防误触开着的场景就别再开游戏外的边缘触发；
- 依旧偏高再看是不是常驻动画开太多，把动画调简单（[小横条与底边手势设置.md](小横条与底边手势设置.md) 第四节）。

## 六、还是不行的兜底顺序

关掉无障碍开关 → 彻底关闭 GestureEVO 后台 → 重启手机 → 重开无障碍。多数无障碍状态卡死靠这四步恢复；四步之后依旧反复被关，多半是某款清理/安全类应用在干预，把它从清理名单排除或暂时卸载验证（详见 [常见问题与故障排查.md](常见问题与故障排查.md)）。
