## 一、为什么它能干这件事

充电快慢你只能靠体感（「好像快了？」），Ampere 给的是一个直接数字：插上哪套头+线，进电池的 mA 更高。官方定位也是这个——读数不能当精确科学用，但用来在**同一台设备上**比较各套充电器/数据线，够用。读数本身的含义和波动原因见 [充电电流读数怎么看.md](充电电流读数怎么看.md)。

## 二、对比前把条件固定住

同一根线，你亮着屏测和灭着屏测，差出来的 mA 能比线本身的差异还大。每次对比都满足这些条件：

| 条件 | 要求 |
| --- | --- |
| 手机 | 始终用同一台（不同机型的读数没有可比性） |
| 电量 | 每次都从差不多的电量开始测（原因见第四节） |
| 屏幕 | 亮度固定，最好统一亮屏或统一灭屏后立刻测 |
| 无线开关 | Wi-Fi、GPS、蓝牙状态保持一致，能关就关 |
| 后台 | 别在下载/更新应用、同步相册时测 |
| 等待 | 每次换头/换线后，等开屏那 10 秒「测量中」过去再记数 |

## 三、对比的顺序

1. 基准：用你怀疑的那套「头 + 线」充 30 秒左右，记下稳定后的 mA 区间（比如 1180~1310）。
2. 换线：同一个头，只换线，再记一个区间。
3. 换头：同一根线，只换头，再记一个区间。
4. 结论看区间重叠情况：两个区间的差距明显且方向稳定，才说明差异是真的；只差几十 mA、每次测还互有高低，就当没有差别。

这样一轮下来你就能回答三个实际问题：线是不是拖了后腿、头是不是虚标、以及家里哪套组合给这台手机充最快。装好 Ampere 就能开测，入口见 [下载与安装教程.md](下载与安装教程.md)。

## 四、越充越慢不是线的问题

电量接近充满时充电电流本来就会一路下降——锂电池最后一段是小电流「收尾」。你对比时如果一次从 30% 开始测、一次从 85% 开始测，后者数值天然低很多，别误判成线不好。这也是第二节要求「从差不多电量开始测」的原因。想看大电流，就在电量不高（比如 20%~50%）的时候测。

## 五、快充挡位大概率测不到

多数手机只有**熄屏**才进入快充（为了避免发热），而 Ampere 恰恰需要**亮屏**才持续测量。两边条件撞上了：你在它界面上看到的多是普通挡位的电流，看不到快充峰值。所以「Ampere 里只有 1000 mA，可我的手机是 66W 快充」这类落差是测量机制造成的，不代表快充坏了。

## 六、三星机型的特殊读法

部分三星机型（官方举例 S5 这一代）的固件不报实测电流，只报当前「头 + 线」配置下的**最大可能充电电流**——你换线它可能一直显示同一个数。这种机型上 Ampere 的对比功能基本失效，是固件行为，应用修不了。你的机型是不是这类，以及各种读数异常的处置，见 [读数为零或测量不结束怎么办.md](读数为零或测量不结束怎么办.md)。

## 七、充电宝、无线充、车载充也能这么测吗

能，但别跨类型比数字。官方把充电方式（USB / 电源适配器 / 无线）列为影响读数的因素之一：

- **无线充电**：中间多一层能量转换，进电池的电流通常比同档位的有线低，拿无线读数去和有线读数比高低没有意义；
- **充电宝**：差异主要来自它自己的输出能力和所剩电量，对比时同样固定到「同一台充电宝」；
- **车载充 / 电脑 USB 口**：电脑 USB 口输出小，读数低是正常的，别据此判断线坏。

对比只在**同一类型内部**进行：有线和有线比、无线和无线比，结论才站得住。读数为什么忽高忽低，见 [充电电流读数怎么看.md](充电电流读数怎么看.md)。
