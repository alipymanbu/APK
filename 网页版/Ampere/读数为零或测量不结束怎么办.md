# Ampere 读数为零或一直测量不结束怎么办

> 这篇管 Ampere 的几类读数异常：恒为 0、只有十几 mA、卡在「测量中」、拔线后不显示放电、后台测量被停，以及你的机型是否本来就不支持。

## 一、一直显示 0 mA

按顺序试：

1. 设置 ⇒ 基本设置 ⇒ 打开 **Old measurement method（旧测量方法）**，这是官方对「恒为 0」的第一处置。
2. 还是 0，再看 基本设置 ⇒ **Measurement interface（测量接口）**，换另一个接口试试。注意：这个选项只有在你的设备上找到 2 个以上的旧式接口时才会显示，找不到就说明你没有可换的。
3. 上面都无效，大概率属于第六节说的「机型不支持」。

## 二、最大只能测到 10~40 mA

不同设备/ROM 的电流上报接口用的单位不一样（有的是 mA，有的不是），Ampere 靠一个倍率来换算，倍率对不上就只剩十几 mA 的假读数。处置和上一节一样：设置 ⇒ 基本设置 ⇒ **Measurement interface**，换一个接口，换到数值符合常理的那个为止（比如插着充电器至少该有几百 mA）。

## 三、卡在「测量中」不动

官方 FAQ 给的顺序，从轻到重逐级试：

1. 重启应用；
2. 拔掉充电线再插回；
3. 删掉应用重装；
4. 重启手机；
5. 以上都无效，切换「Old measurement method」和/或换 Measurement interface。

另一个常见诱因是**系统固件更新之后**开始卡住——官方说明的处理是把 Ampere 的数据清掉重来：Android 设置 ⇒ 应用 ⇒ Ampere ⇒ 存储 ⇒ 清除数据，然后重新打开应用。

## 四、拔了线显示「未在充电」而不是负数

这是固件把「放电」状态误报成「Not charging」。开关在 设置 ⇒ 基本设置 ⇒ **Enhanced Measurement（增强测量）**，打开后它会尝试在这种状态下继续测放电电流。没效果的话再翻一遍 Measurement interface，仍然不行就是机型限制，没有更多办法。

## 五、小工具数值不动了、后台测量被停

桌面小工具上的数值不再跳动，通常不是应用坏了，而是系统的省电策略把它的后台测量停了——Android 的电池优化，以及各品牌自带的「深度睡眠」「自启动管理」这类机制，都会在灭屏后一段时间冻结后台应用。处置：

1. 系统设置 ⇒ 应用 ⇒ Ampere ⇒ 电池：改成「允许后台活动」/「不受限制」（各机型叫法不同）；
2. 在品牌自己的省电管理里把 Ampere 移出待优化/睡眠名单，有「自启动」开关的也打开；
3. 把小工具删掉重新添加，重启一次手机。

各品牌的省电策略差异很大，社区常用的 [Don't Kill My App](https://dontkillmyapp.com/) 整理了各机型的对应设置入口。要不要在后台挂着测，应用本身的机制说明见 [充电电流读数怎么看.md](充电电流读数怎么看.md) 第一节。

## 六、你的机型可能本来就不支持

有些设备缺电流测量芯片（或接口），装什么版本都测不出来，这不是应用的错。官方在说明里列过两类：

**基本测不了的老机型**（官方名单）：

| 机型 |
| --- |
| Galaxy Grand Prime（fortuna3gdtv） |
| Galaxy Note 2（t03g 系列） |
| Galaxy S3（d2att / d2spr / d2vmu） |
| Galaxy Tab 4 7.0（degas3g） |
| HTC Desire 510 |
| HTC One S / One X / One XL |
| HTC Sensation 4G |

**要用「旧测量方法」并选对测量接口才能测的**：HTC One M7 / M8、LG G3。

另外两个「测得出但数据没意义」的情况别和应用故障混淆：

- 部分三星机型只报「该配置下的最大可能电流」而不是实测值（官方举例 S5 这一代），换线读数不变——固件问题，应用修不了，见 [选充电器与数据线怎么测.md](选充电器与数据线怎么测.md) 第六节；
- 数值忽大忽小属于系统上报不稳，是正常现象，见 [充电电流读数怎么看.md](充电电流读数怎么看.md) 第三节。

官方对 unsupported 机型的建议是去它的 [XDA 论坛帖](http://goo.gl/pZqJg8)里查贴、反馈；官方 [FAQ](http://goo.gl/R8XgXX) 里也收录了上面这些处置的原始说明。如果你的新机型完全测不出，先过一遍第一到四节，再对照这里的名单判断是不是硬件层面的不支持。
