## 一、PSPlay 是什么

PSPlay 是一款第三方串流客户端，装在安卓手机或平板上，用来远程操控你的 PS4 / PS5 主机：主机的画面和声音串流到手机上，你在手机上操作。它和索尼官方的 PS Remote Play 解决的是同一件事，两款应用在设备门槛、手柄支持、连接方式上的具体差异见[与官方 PS Remote Play 的区别.md](与官方 PS Remote Play 的区别.md)。

本篇只讲安装这一步。装好之后首次使用前，还需要在主机和应用之间完成一次注册，那一部分见[主机注册与连接设置.md](主机注册与连接设置.md)。

## 二、安装前确认设备条件

官方说明给安卓侧的要求与建议如下（以官方说明页当时显示为准）：

| 项目 | 要求 / 建议 |
| --- | --- |
| 系统版本 | Android 5.0 或更高 |
| 处理器 | 建议双核及以上 |
| 内存 | 建议 2 GB 或更多 |
| 屏幕分辨率 | 1024 × 768 或更高 |
| 手机联网方式 | 建议连 5GHz Wi-Fi，延迟更低 |
| 主机联网方式 | 强烈建议主机用网线接入路由器 |
| 网络带宽 | 上传、下载速度建议至少 15 Mbps |

低配手机也能跑，但你需要在串流设置里把分辨率和帧率调低，才能保住流畅度（具体设置见[画面设置与多配置档案.md](画面设置与多配置档案.md)）。

## 三、获取安装文件

网盘里这份安装包对应的是 PSPlay 安装文件资源，转存到自己网盘后即可下载到手机安装：[PSPlay 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1aec9965323d)。

1. 打开上面的链接，登录夸克网盘；
2. 把整个资源文件夹转存到自己的网盘；
3. 在网盘客户端里下载 `PSPlay_v9.0.0.apk` 到手机本地存储。

## 四、安装步骤

这个应用不在国内应用商店上架，需要手动安装 APK：

1. 在手机文件管理器里点开下载好的 APK 文件；
2. 系统会提示「禁止安装未知来源应用」，按提示允许你所用文件管理器（或浏览器）的安装权限，不同品牌手机的入口位置不同，一般路径为「设置 > 安全 > 安装未知应用」；
3. 回到文件管理器继续安装，完成后打开应用；
4. 装好后先别急着连主机——首次使用必须在主机和应用之间完成注册，直接看[主机注册与连接设置.md](主机注册与连接设置.md)。

**装到 Android TV 盒子上**：PSPlay 也支持 Android TV 设备。盒子上没有文件管理器的话，先把 APK 拷进 U 盘插到盒子上安装，或用手机端「远程安装」类的工具推过去。装完后用遥控器操作注册界面即可，外网连接的手动 IP 输入在电视上同样可用。
