# PSPlay 外网串流与端口转发

## 一、外网连接的几条路

| | 自动远程连接 | UPnP 自动配置 | 手动端口转发 |
| --- | --- | --- | --- |
| 原理 | 应用借助官方网络服务打通链路 | 应用自动在路由器上开端口 | 你在路由器上手动开放指定端口 |
| 前提 | 注册时登录过账号 + 主机满足一组条件 | 路由器支持并已开启 UPnP | 会进路由器后台配置 |
| 适合 | 普通家庭宽带、不想折腾路由器 | 自动方式连不上、但路由器支持 UPnP | 上面两条都走不通的情况 |

建议的顺序：先用自动远程连接，不行再试 UPnP 自动配置，最后才手动做端口转发——越往后越折腾，但成功的把握也越大。

## 二、自动远程连接（PSPlay 5.0.0 起支持）

### 前提条件，一条都不能少

1. 注册主机时在 PSPlay 里**完成过账号登录**（只做过手动注册的不行，注册流程见[主机注册与连接设置.md](主机注册与连接设置.md)）；
2. 主机连着 PlayStation Network；
3. 主机系统是最新固件；
4. 家里如果有多台主机，只能远程连接被设为常用主机的那台。

### 开启与使用

1. 打开 PSPlay 的串流设置（streaming settings），启用 **automatic remote connection**；
2. 回到主界面点 **Remote Connect**，选择 **Automatic** 方式连接。

### 连不上最常见的原因：NAT 类型

自动连接目前仍是实验性功能，不是所有网络环境都通。最常见的卡点是主机显示 NAT Type 3——这通常意味着你的运营商没有给路由器分配真正的公网 IP（运营商级 NAT）。如果是这种情况，可以联系运营商申请公网 IP；拿到公网 IP 后自动连接的成功率会明显不同。NAT 类型的查看位置在主机的网络设定里。

## 三、UPnP 自动配置路由器

自动远程连接用不了时，PSPlay 还能替你自动配置路由器，省去手动做端口转发的功夫：

- **前提**：路由器支持 UPnP，并且该功能已开启（多数路由器默认开启，后台设置里一般叫「UPnP」，关闭状态就把它打开）；
- **限制**：不是所有路由器都支持 UPnP，部分路由器出于安全考虑不允许应用自动配置；
- **失败怎么办**：应用提示找不到路由器或其他错误时，说明这条路在你的网络环境下不通，回到下一节手动配置——这不是应用坏了，是路由器侧不放行。

## 四、手动端口转发

### 需要转发的端口

官方说明要求**全部**按对应协议转发到主机的内网 IP（9295 一个端口要同时做 TCP 和 UDP 两条规则）：

| 端口 | 协议 | 适用主机 |
| --- | --- | --- |
| 9295 | UDP + TCP | PS5 / PS4 |
| 9296 | UDP | PS5 / PS4 |
| 9297 | UDP | PS5 / PS4 |
| 9302 | UDP | 仅 PS5 |
| 987 | UDP | 仅 PS4 |

### 配置步骤

1. 用浏览器打开路由器管理后台（地址栏输入路由器的内网 IP，手机连家里 Wi-Fi 也能操作，电脑更方便）。不知道路由器 IP 的话，安卓手机在 Wi-Fi 详情里能看到网关地址；
2. 找到「端口转发 / Port Forwarding」设置（不同品牌叫法不同，一般在「WAN 设置」「高级设置」「NAT/虚拟服务器」之类的菜单下）；
3. 按上面的表逐条添加规则，内部 IP 填主机的内网 IP。如果你的路由器区分外部端口和内部端口，两边填一样的数字；
4. 给主机设置静态内网 IP（在主机网络设定里手动指定 IP，或在路由器上给主机做 IP-MAC 绑定）。不这样做的话，主机每次重启可能拿到新 IP，转发规则就失效了；
5. 查出家里宽带的公网 IP：用家里的任一设备访问 [www.whatsmyip.org](https://www.whatsmyip.org/)，页面上显示的就是。

### 在外连接与验证

- 出门在外时，点 PSPlay 主界面的 **Remote Connect**，填的必须是**路由器的公网 IP**，不是主机的内网 IP；
- 想提前验证端口通不通，用家里的网络访问 [www.canyouseeme.org](https://www.canyouseeme.org/)，输入 9295 检查即可；
- 家庭宽带的公网 IP 会变（动态 IP），某天外网串流突然连不上了、之前一直正常，第一件事就是重新查一次公网 IP。

## 五、连不上时的判断顺序

1. **先在局域网内确认 Local Connect 是正常的**——它正常，说明主机侧和应用侧都没问题，问题被隔离在外网链路上；
2. 外网连接反复报 `IO_EXCEPTION_OCCURRED` 或「connection could not be established」这类错误，通常是端口转发没配全（五条端口、协议、全部到位）或者运营商封了相关端口；
3. 运营商不给公网 IP 的情况下，端口转发也做不通——这时唯一的出路是申请公网 IP，或者回到自动远程连接碰运气；
4. 主机固件刚升级过之后突然连不上，可能是兼容性问题还没适配，这个原因的应对写在[主机注册与连接设置.md](主机注册与连接设置.md)的升级提醒里；
5. 链路通了但画面卡顿、延迟大，那不是「连不上」而是带宽或画质设置问题，处理见[画面设置与多配置档案.md](画面设置与多配置档案.md)的画质调整表。

本篇只管外网链路。注册失败、登录页报错、固件升级后失效这类问题的集中排查见[无法连接与报错排查.md](无法连接与报错排查.md)。
