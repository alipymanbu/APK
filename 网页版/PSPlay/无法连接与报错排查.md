# PSPlay 无法连接与报错排查

> 注册失败、登录页报错、外网连不上——本篇按报错发生的阶段归类，给出对应的检查与处理办法。

## 一、先把报错归到哪一类

用 PSPlay 遇到的问题基本落在三类里，处理入口完全不同：

| 类型 | 典型表现 | 处理入口 |
| --- | --- | --- |
| 注册与登录类 | 注册时出错、官方登录页打不开或报错 | 本篇第二、三节 |
| 外网连接类 | `IO_EXCEPTION_OCCURRED`、连接建立失败 | 本篇第四节 + [外网串流与端口转发.md](外网串流与端口转发.md) |
| 画质流畅类 | 能连上但卡顿、延迟高、操作慢半拍 | 本篇第六节 + [手柄支持与虚拟手柄.md](手柄支持与虚拟手柄.md) |

## 二、注册阶段的失败

注册要求手机与主机在**同一局域网**内进行，以下检查都在这个前提下进行：

1. **8 位数字不对**：先回到主机上的添加设备 / 链接设备页面，核对当前显示的数字与你在 PSPlay 里输入的是否一致，页面刷新后数字可能变化，以当时显示的为准；
2. **主机类型选错**：PS5 和 PS4 在 PSPlay 注册界面里是分开的选项，选错必然失败；
3. **老固件下拉选错**：主机固件较旧时要在下拉列表里选对应固件版本，不确定就保持默认；
4. **主机侧没就绪**：主机已用账号登录、远程游玩开关已打开（检查步骤见[主机注册与连接设置.md](主机注册与连接设置.md)第二节）；
5. **不在同一网段**：路由器的访客网络、双频路由器的隔离设置都会把手机和主机隔开，把它们放到同一个频段、同一个网络里再试。

## 三、PSN 登录出错

注册过程中会跳到索尼官方登录页。这一步报错（例如「A connection to the server could not be established」）或验证码刷不出来时，开发者提供了绕开应用内登录页的官方应急流程：

1. 在注册页右上角点 **Problems?**，选择 **OPEN PSN LOGIN WEBSITE**——登录页会在你设备的系统浏览器里打开；
2. 在浏览器里完成 PSN 登录；浏览器里也报同样错误的话，换另一台设备的浏览器登录（官方手册明确给了这条路）；
3. 登录成功后浏览器会停在一个白色跳转页，把地址栏里的完整网址复制下来；
4. 回到 PSPlay，把复制的网址粘进 **PSN login redirect URL** 输入框，应用就能完成登录。

**完全不想走登录的路**：注册界面开启 **Advanced Settings**，勾选 **Register PS5 / PS4 manually**，直接填入你账号的 Account-ID（一串纯数字）即可注册。查自己的 Account-ID 有两个官方手册提供的途径：

- 开发者发布的开源小程序 PlayStationSharp（GitHub 上的 [streamingdv/PlayStationSharp](https://github.com/streamingdv/PlayStationSharp) 项目，Windows 下运行），运行时同样要登录一次 PSN，但代码开源可自行核查；
- 官方手册还链接了一个社区提供的网页脚本（直达链接见 [PSPlay 官方说明页的 PSN login 章节](https://streamingdv.github.io/psplay/psn_login.html)），按页面指示操作后，结果里 `user_id` 变量旁边的纯数字就是 Account-ID。

用这条路的代价要清楚：**不登录就注册，之后用不了自动远程连接**（原因见[外网串流与端口转发.md](外网串流与端口转发.md)）。至于账号安全：开发者说明应用接触不到你在官方登录页输入的邮箱密码，登录成功后拿到的只有 Online-ID 和 Account-ID 两项，加密存在你自己设备上。信不信由你判断，两个途径都在，以官方说明页当时的写法为准。

## 四、外网连接报错

`IO_EXCEPTION_OCCURRED` 或「connection could not be established」反复出现，基本都在链路上，不在应用里：

1. 先确认家里局域网内 Local Connect 一切正常，把问题隔离到外网；
2. 对照[外网串流与端口转发.md](外网串流与端口转发.md)检查端口转发是否五条全配、协议对不对（9295 要 TCP 和 UDP 各一条）；
3. 主机显示 NAT Type 3、或路由器 WAN 口拿到的是内网地址（`100.x` / `10.x` / `192.168.x` 开头）——说明运营商没给公网 IP，端口转发和自动远程连接都做不通，找运营商申请公网 IP；
4. 之前一直正常、突然连不上——公网 IP 变了，重新查一次填进 Remote Connect。

## 五、主机固件升级后突然不能用

开发者反复提醒：主机固件更新后，PSPlay 可能需要时间适配。所以主机弹出固件更新时先别急着装，确认当前版本下应用还正常、或官方说明已适配新固件再升。已经升完出问题的，除了等适配没有别的办法——这也是把「先确认再升级」写在[主机注册与连接设置.md](主机注册与连接设置.md)里的原因。

## 六、能连上但卡顿、延迟大

这属于流畅度问题而不是连接问题，按顺序查：手柄改 USB 有线、手机连 5GHz Wi-Fi、主机走网线（细节见[手柄支持与虚拟手柄.md](手柄支持与虚拟手柄.md)末节），仍不理想就降分辨率和帧率（见[画面设置与多配置档案.md](画面设置与多配置档案.md)）。

以上都排查过仍然不行，重装一遍是最后的常规手段：卸载后从[PSPlay 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1aec9965323d)重新转存安装，注册需要重做一遍。
