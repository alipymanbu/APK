## 一、什么手柄都能接吗

在安卓上，凡是兼容 Android 5.0 以上的手柄，通过蓝牙或 USB 接上就能用——不限于索尼原厂的 DualShock / DualSense，第三方手柄也在支持范围内，这是 PSPlay 相对官方客户端的一个实际差异（差异项的完整对照见[与官方 PS Remote Play 的区别.md](与官方 PS Remote Play 的区别.md)）。屏幕虚拟按键的布局调整不在这篇里，见[画面设置与多配置档案.md](画面设置与多配置档案.md)。

**强烈建议手柄走 USB 有线连接。** 官方说明明确指出：不少安卓设备受硬件限制，蓝牙手柄会产生明显的输入延迟和按键滞后，这个问题出在设备硬件上，应用侧无法修复。如果你串流时总觉得操作「慢半拍」，第一件事就是把手柄从蓝牙换成 USB 线。

## 二、按键映射：手柄按键不对劲时

不同厂商的手柄按键布局五花八门，接上后出现按键功能对不上号的情况并不少见。处理方式：

1. 在主界面左上角打开导航抽屉，点 **Button mapping**；
2. 为你的手柄建一个按键映射档案，把实际按键逐个对应到 DualShock 的标准按键上；
3. 建好的映射档案之后一直在用，换手柄就再建一个。

有一个系统级的限制要知道：**如果你的手柄上有某个按键被安卓系统识别为 Home 键，应用无法接管它**——任何应用都覆盖不了系统 Home 键的行为。解决办法是在映射时改用 **Use 2 buttons combination**（两键组合）功能，把两个其他键组合起来代替那个键。

## 三、把手机当虚拟手柄（Gamepad Mode）

PSPlay 有个独立于串流的玩法：手机不传画面、不传声音，只作为一只额外的手柄接在主机上，适合手柄不够、临时用手机顶一个的场景。

**开启方式**：主界面右上角点三个点，选 **Gamepad Mode**。

**用它之前要知道的三件事**：

1. 想让手机和真实手柄同时用，主机上至少要有第二个访客（guest）账号档案。真实手柄要登在那个**没有被 Gamepad Mode 占用的档案**上，否则远程连接会直接被终止；
2. Gamepad Mode 下应用不处理音频和视频，但主机那边的数据照样在发送——也就是说流量并不会因为你看不到画面就省下来，用移动数据外连时要留意；
3. 手机屏幕上的虚拟手柄按键布局同样可以自定义，入口是导航抽屉里的 **Gamepad layout**（与串流画面的布局分开建，见[画面设置与多配置档案.md](画面设置与多配置档案.md)）。

## 四、串流时操作延迟大怎么办

按这个顺序排查：

1. 手柄改用 USB 有线（第一节说过的硬件限制，蓝牙是重灾区）；
2. 手机连 5GHz Wi-Fi，别用 2.4GHz，也别隔着墙；
3. 主机用网线接路由器；
4. 以上都做了还卡，进串流设置把分辨率和帧率降一档（具体见[画面设置与多配置档案.md](画面设置与多配置档案.md)），外网串流的延迟问题则要回到[外网串流与端口转发.md](外网串流与端口转发.md)里查链路。
