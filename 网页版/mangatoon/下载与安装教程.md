## 一、先确认这份包适不适合你的手机

下面这几个数字是**这份安装包本身的事实**，装之前先对一眼，后面校验文件、排查报错都要用：

| 项目 | 值 |
|---|---|
| 版本号 | 3.31.05 |
| 包名 | `mobi.mangatoon.comics.aphone.kbinstaller` |
| 安装包大小 | 30.51M（约 34,655,692 字节） |
| MD5 | `500F9118668F8ECB4AC5BF7E1080419D` |
| 记录日期 | 2026-09-23 |
| 系统要求 | 安卓 5.2 以上 |

两点要注意：

- **包名和商店版不一样**。Google Play 上的官方包名是 `mobi.mangatoon.comics.aphone`，这份是 `mobi.mangatoon.comics.aphone.kbinstaller`。包名不同，系统会当成两个独立的应用：手机上已经装了商店版的话，这份能共存安装，但**不会覆盖它、也不会接管它的更新**，两个图标会同时存在。
- **版本不是最新的**。官方版本号是 `3.x.yy` 这种三段式，2026 年 9 月官方已经发到 3.38.x 一带（更新日志多为「修复了一些程序崩溃问题」）。网盘里这份 3.31.05 是 2026-09-23 的存档版本，能正常用，但拿不到最新的修复。

## 二、从网盘拿安装包

打开 [MangaToon 安装文件资源（夸克网盘）](https://pan.quark.cn/s/dc36ab4f6696)，转存后进对应文件夹，里面是 `mangatoon_v3.31.05.apk`，旁边还有一份 `先保存再下载避免失效.txt` 说明文件。

下载到手机时直接用浏览器或文件管理器下载，别走即时通讯工具的「发送文件」——那类工具会改文件名或改后缀，APK 一被改动就装不上。

## 三、装之前先校验文件完整

下载中断、复制出错都会得到一个「看起来是 APK、实际是半截」的文件，装的时候只会报「解析包时出现问题」。装之前花一分钟对一下 MD5：

Windows 上把 APK 放在某个目录，打开 PowerShell 执行：

```powershell
CertUtil -hashfile mangatoon_v3.31.05.apk MD5
```

输出的 32 位十六进制应当与表格里的 `500F9118668F8ECB4AC5BF7E1080419D` 完全一致（大小写不敏感）。对不上就重新下载，别硬装。

手机上可以用文件管理器的「详情 / 校验」功能看 MD5；没有这个功能的，直接看文件大小是否为 30.51M，明显偏小就是没下完。

## 四、安装步骤

1. 用文件管理器点开 `mangatoon_v3.31.05.apk`。
2. 系统会提示「禁止安装来自此来源的应用」，点提示里的**设置**，给这个文件管理器（或浏览器）打开「允许安装来自此来源的应用」，再返回继续安装。
3. 等安装完成，首次启动时留意权限与语言提示（语言默认跟随手机系统语言，改法见 [语言设置与离线下载.md](语言设置与离线下载.md)）。

不同品牌菜单名略有差异，对照着找：

| 品牌 | 大致路径 |
|---|---|
| 原生 / 一加等 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |
| 小米 / MIUI | 设置 → 隐私保护 → 特殊权限 → 安装未知应用；另需注意「纯净模式」会拦截 |
| 华为 / 鸿蒙 | 设置 → 安全 → 更多安全设置 → 允许安装未知来源应用；纯净模式开启时会拦 |
| 三星 | 设置 → 应用 → 特殊访问权限 → 安装未知应用 |

## 五、装不上时，先看报错是哪一种

| 报错表现 | 多半是这个原因 | 怎么处理 |
|---|---|---|
| 「解析包时出现问题」 | 文件不完整、损坏，或系统版本低于 5.2 | 按第三节重新校验 / 重新下载；确认系统版本 |
| 「应用未安装」 | 存储空间不足，或与已装应用签名冲突 | 腾出 1GB 以上空间；若之前装过同包名的其他构建，先卸载再装 |
| 「INSTALL_FAILED_VERSION_DOWNGRADE」 | 手机上已有更高版本 | 卸载高版本后重装（会清掉该应用本地数据） |
| 「INSTALL_FAILED_NO_MATCHING_ABIS」 | 安装包的 CPU 架构与手机不匹配 | 换与手机架构匹配的构建，或改用商店版 |
| 点开 APK 没反应、无提示 | 文件管理器没拿到安装权限 | 按第四节给它开「安装未知应用」权限 |

安装成功但打不开、打开就闪退的，属于运行阶段的问题，处理办法集中在 [闪退与登录失败怎么解决.md](闪退与登录失败怎么解决.md)。

## 六、首次启动注意三件事

1. **语言**：漫画内容的语言默认跟随手机系统语言，想要别的语言要在设置里手动切（可选语言清单见 [语言设置与离线下载.md](语言设置与离线下载.md)）。
2. **账号**：先注册 / 登录再开始看，阅读进度、书架、金币都挂在账号上；换手机或清了应用数据，只有登录着才能找回来。
3. **先看免费内容**：一部分章节要付费解锁，也有每周免费漫画与看广告解锁的路子，第一次用建议先看 [免费看漫画的方法.md](免费看漫画的方法.md)，别一上来就充金币。
