## 一、语言默认跟着手机走，不改就会是系统语言

官方在应用简介里写明：**漫画内容的语言默认为手机系统语言**，想读别的语言要去设置里切换。

这带来一个直接后果——**作品显示成哪种语言，跟着你的系统语言走**；装完发现「怎么全是英文」，通常不是装错了包，而是手机系统语言设成了英文。先把系统语言改成你要的，再进应用看一次。

## 二、能切哪些语言

官方列出的语言清单（截至 2026-09，应用内实际可选项以当时显示为准）：

| 类别 | 语言 |
|---|---|
| 中文 | 简体中文、繁体中文 |
| 欧美语言 | 英语、法语、西班牙语、葡萄牙语、意大利语、德语 |
| 亚洲语言 | 印度尼西亚语、越南语、泰语、日语、马来语 |
| 其他 | 阿拉伯语 |

不同版本、不同地区看到的列表可能有出入，以设置页当时列出的为准。切换入口在应用的**设置页**（不同版本可能叫 Settings / 语言 / Language），具体位置随版本略有变动，进设置后找带「语言」字样的那一项即可。

切完语言，**已经下载到本地的章节不会自己变**：它们还是切换前那种语言的版本，要读新语言的章节，得重新下载。

## 三、离线下载：Wi-Fi 下好，没网再看

官方支持把漫画下载到本地离线阅读，典型用法是：连着 Wi-Fi 把在追的几部下完，路上、地铁里、出游没信号时照常看。

操作路径（入口名称随版本略有差异）：

1. 打开要下载的作品，进详情页或阅读页；
2. 找**下载**入口（详情页的下载图标，或阅读页里的下载选项）；
3. 选择要下的章节范围，等待下载完成；
4. 断网后从「我的 / 下载」进入，确认能打开。

几点边界：

- **离线看的是已下载的章节**，没下的章节断网就是打不开，追更的要定期补下。
- 下载内容占用手机存储，章节多的作品很占地方，空间紧张时先清理旧下载（应用内下载管理里可删；系统层面可走 设置 → 存储 → 清理缓存）。
- 下载到本地的内容存在手机存储里，**卸载应用会一并删掉**，要换机就重新下一遍。
- 建议登录账号再追更：书架、进度、下载记录的跨设备找回能力随版本而定，以应用内实际表现为准。
- 若下载一直失败、只在某个网络下失败，按 [闪退与登录失败怎么解决.md](闪退与登录失败怎么解决.md) 的网络一节排查——多半是网络或后台数据权限的问题，不是作品的问题。

## 四、追更提醒与订阅

在作品页订阅（关注 / 收藏）之后，新章节更新会给你提醒，不用自己反复进去翻。提醒没收到时，先检查手机有没有把该应用的通知权限关掉，再看是不是被系统的省电策略限制了后台运行（各品牌路径不同，一般在 设置 → 应用 → 该应用 → 省电策略 / 后台运行）。

## 五、和阅读相关的几个默认行为

- **阅读方式是竖向长条滑动**，一指上下滑即可，适合单手看彩色条漫。
- **建议先登录再追更**：阅读进度、书架这类记录的保存与同步范围随版本而定，换手机、清应用数据之前，先确认自己能重新登录找回。
- 部分章节需要付费解锁，具体怎么少花钱见 [免费看漫画的方法.md](免费看漫画的方法.md) 与 [金币充值与VIP订阅价格.md](金币充值与VIP订阅价格.md)。
