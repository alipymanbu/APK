## 〇、排查总原则：一次只改一个变量

改一处 → 试一次 → 有用就停，没用再改下一处。一口气关 VPN、清缓存、重启手机全都做一遍，最后好了你也不知道是哪一步起的作用，下次还得重来一遍。

## 一、闪退 / 打开就卡住

按顺序试，到哪一步好了就停：

1. **彻底关掉再开**：从最近任务里把应用划掉（不是按 Home 键收起来），等 10 秒重新打开。半加载状态卡住是最常见的原因。
2. **清缓存**：设置 → 应用 → MangaToon → 存储 → **先清缓存**。清缓存不丢登录状态，优先做这一步。
3. **看存储空间**：安装和运行都需要额外空间，剩余不足 1GB 时容易出现装不上、启动崩。清掉不用的视频和应用腾地方。
4. **系统版本与机型**：这份 3.31.05 要求安卓 5.2 以上（系统版本在 设置 → 关于手机 里看）；系统太旧、版本过低会装不上或启动就退。
5. **换网络再试**：有些启动崩溃是启动时拉不到配置，开飞行模式 10 秒再关掉，或换 Wi-Fi / 流量试。
6. **清数据（会退出登录）**：上面都无效再做——设置 → 应用 → MangaToon → 存储 → **清除数据**。它会清掉本地记录，所以**先确认自己记得账号密码**，清完要重新登录。
7. **重装**：仍不行就卸载重装。装包从 [MangaToon 安装文件资源（夸克网盘）](https://pan.quark.cn/s/dc36ab4f6696) 重新取，装之前按 [下载与安装教程.md](下载与安装教程.md) 第三节校验 MD5，别拿一个残缺文件反复试。

## 二、白屏 / 内容一直加载不出来

先把它当网络问题处理，除非你证明不是：

| 检查项 | 怎么做 |
|---|---|
| 换网络 | Wi-Fi 和流量互换一次；公共 Wi-Fi 常有限制 |
| 关掉干扰项 | 暂时退出 VPN、私人 DNS、广告拦截工具，试完再逐个开回来 |
| 后台数据权限 | 设置 → 应用 → MangaToon → 移动数据 / 流量后台，确认没被禁用、没被省流量模式挡住 |
| 省电策略 | 系统的省电 / 限制后台运行把它关掉，否则切个后台就断连 |
| 手机时间 | 设成**自动确定日期和时间**，时间偏差会导致校验失败、一直转圈 |
| 只有这一个应用坏 | 重启手机一次再试；多个应用同时坏，问题在网不在应用 |

作品页打不开而别的页正常，多半是这一部的资源加载问题——退出作品页重进、或过一会儿再试。

## 三、登录不上 / 登录后又被弹回登录页

这类问题基本出在会话数据和网络干扰，不在账号本身：

1. **换一条登录路线**：平时用第三方登录（Google / Facebook 等）就改用邮箱密码试一次，反之亦然。第三方登录要经过浏览器中转，中转失败就表现成「登录循环」。
2. **暂时关掉 VPN 与广告拦截**：它们会挡掉登录回跳的那一步。
3. **清缓存，不行再清数据**：设置 → 应用 → MangaToon → 存储 → 清缓存；仍循环就清数据（会退出登录，重登即可）。
4. **手输账号密码**：别用自动填充，注意大小写、前后有没有空格。
5. **确认手机时间是自动的**：同上一节第 5 条。
6. **换台设备登录同一个账号**：另一台也失败 → 服务端或账号问题，走第五节找官方；另一台正常 → 问题在本机数据，回到第 3 步。

登录成功后**多等十几秒**再操作，有的版本会在界面看起来没反应时继续在后台完成会话建立。

## 四、券、金币、奖励没到账

1. 退出重进，刷新一次余额；
2. 确认登录的是收奖励的那个账号；
3. 看券有没有**有效期**——有用户反馈攒下的券到期清零，过期的补不回来；
4. 看作品是否支持用券（部分作品不接受用券，或限制每天用券张数，以章节页当时显示为准）；
5. 以上都排除，带上截图找官方，说明时间、账号、作品名。

## 五、还没解决：找官方

| 渠道 | 说明 |
|---|---|
| 应用内反馈 | 「我的」页面里的 Feedback / 反馈入口，官方开发人员的回复口径是走这里处理 |
| 邮箱 | [support@mangatoon.mobi](mailto:support@mangatoon.mobi) |
| Facebook | [facebook.com/MangaToonEN](https://www.facebook.com/MangaToonEN/) |

发反馈时把这几样一次给全，能少来回几轮：**应用版本号**（设置里看，如 3.31.05）、手机型号与安卓版本、问题出现的时间与频率、报错原文截图、账号注册邮箱。
