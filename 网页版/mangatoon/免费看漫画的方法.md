## 一、先把收费逻辑弄清楚

官方在应用简介里说得很直白：**相当一部分章节需要付费解锁**，原因是作者要靠收入生活；同时官方也给了几条免费读的途径。所以你在 MangaToon 里遇到的章节，基本分三类：

| 类型 | 你能不能直接读 | 判断方式 |
|---|---|---|
| 免费章节 | 能，点开就读 | 详情页标免费、或前若干章无解锁按钮 |
| 本周免费作品 | 能，限时免费 | 列在免费专区 / 本周免费里，活动结束后会转回付费 |
| 付费章节 | 不能，要券、积分、金币或看广告 | 章节上有解锁提示与所需数量 |

付费的额度随作品而异，官方口径是「部分作品按章收费」，具体单价以章节页面当时显示为准。**付费方式通常是三种：用券 / 积分兑换、用金币永久解锁、看一段短视频临时解锁。**

## 二、四条免费拿额度的路子

### 1. 每周免费漫画

官方每周都会放出一批当周免费的作品，进免费专区就能读，不用花任何额度。这是最省事的一条——盯住专区轮换，一部作品在免费期内一次读完。

### 2. 完成任务得积分与阅读券

按官方简介，**完成平台任务会按周发放积分与阅读券**，用来兑换本来要花钱的章节。任务入口一般在「任务 / 福利 / 签到」这类页面，具体项目与给多少随活动调整，以应用内当时显示为准。

### 3. 看短视频解锁

官方简介写明：**即使没有积分和阅读券，也可以通过观看短视频来解锁章节**。这是零门槛的兜底办法——额度用光时，看一段广告换一章。有读者反馈看广告的次数每天有限，刷完就只能等第二天或改用其他方式，具体次数以应用内当时显示为准。

### 4. 邀请好友得阅读券

官方中文简介提到**邀请好友可获得大量阅读券**。邀请入口在应用内活动页，规则与发放数量随活动变动，以活动页当时说明为准。

## 三、券、积分、金币的区别（这一步最容易踩坑）

三样东西都能换章节，但性质完全不同：

| | 阅读券 / 积分 | 金币 |
|---|---|---|
| 怎么来 | 任务、签到、邀请、活动发放 | 充值购买，或活动少量赠送 |
| 解锁后 | 多为**限期、限作品** | **永久解锁**该章节 |
| 会不会过期 | 会（有用户反馈攒下的券到期作废） | 一般不会 |
| 适合干什么 | 先用掉快过期的，读当周免费之外的零散章节 | 锁定真正要反复看、长期追的作品 |

几点实操建议：

- **先花会过期的**：券有有效期，攒着不用最亏。有用户反馈「攒了十几张券到期清零」，也有反馈「部分作品不接受用券、或一天限用一张」——所以**兑换前先看章节页面的说明**，别默认所有作品都能用券。
- **金币解锁是买断**：同一章用金币解锁后不再重复收费，长期追的作品用金币更划算；只想尝鲜的先用券或看广告。
- 具体哪种作品支持哪种方式，**以章节页面当时显示为准**，这是唯一可靠的判断处。

## 四、什么时候值得直接充值

把上面的免费额度都算上还不够用，说明你是重度读者，这时再看 [金币充值与VIP订阅价格.md](金币充值与VIP订阅价格.md) 里的档位与订阅价格更划算。判断标准很简单：

- 每周免费 + 任务 + 广告已经够你看 → 不用充；
- 经常为额度卡在半截、又在追三部以上 → 先算 VIP 月费与你每月花的金币谁多，再决定。

## 五、免费额度相关的常见疑问

- **券没到账 / 广告看完没解锁**：先退出重进、确认网络正常；仍然没有就按 [闪退与登录失败怎么解决.md](闪退与登录失败怎么解决.md) 「券、金币、奖励没到账」一节联系官方。
- **免费作品突然要收费了**：免费是**限时**的，活动结束转回付费属正常规则，不是乱扣费。
- **换了手机额度不见了**：额度和账号绑定，先登录原账号；换了账号自然看不到原来的券与金币。
