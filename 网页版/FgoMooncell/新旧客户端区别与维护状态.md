# FgoMooncell 新旧客户端区别与维护状态

## 一、快速辨认：你装的是哪一个

官方给过一个一眼可辨的办法：**点右上角三个点，菜单里有「悬浮窗」切换的就是新版客户端**，没有则是旧版。

| | 旧版客户端 | 新版客户端（即 FgoMooncell 1.4.6） |
| --- | --- | --- |
| 包名 | `wiki.mooncell.app` | `wiki.fgo.app` |
| 桌面应用名 | Mooncell | Mooncell |
| 最后版本 | 早于新版（官网未标注具体版本号） | 1.4.6（2022-05-18 更新） |
| 右上角三点菜单 | 无悬浮窗切换 | 有悬浮窗切换 |

包名不同意味着两者可以同时安装、并存使用；想从旧版换到新版，不必先卸载旧版，装好后按上面的办法确认拿到的是新版即可。

## 二、悬浮窗：边玩边查怎么开

悬浮窗是新版客户端相对网页版最大的差异，也是「要不要装客户端」这个问题的答案所在。开启与使用：

1. 打开客户端任意页面，点右上角三个点；
2. 菜单里除了「悬浮窗」切换，还有**多栏 / 单栏模式**的切换（单栏适合手机竖屏阅读）；
3. 切到悬浮窗后，资料页会缩成一个小窗浮在屏幕上，可以拖动位置、缩放大小，一边开游戏一边对照查；
4. 小窗点不开或一开就消失，多半是系统没给「显示在其他应用上层」权限，去系统设置里给 Mooncell 打开即可。

悬浮窗模式 1.4.6 自带；浏览器访问没有这个能力。具体悬浮窗在你机型上的表现（分屏冲突、游戏防误触等）以实际使用为准。

## 三、维护状态：两个都已停止维护

官方 Wiki 的客户端页面（[Mooncell:Appclient](https://fgo.wiki/w/Mooncell:Appclient)）顶部明确标注：

- 安卓客户端**已于 2022 年停止维护**，不再提供技术支持；
- 使用过程中出现的问题均无法解决；
- 建议停止使用客户端，改用现代浏览器访问网站。

也就是说，1.4.6 就是终点，之后新版安卓、新屏幕比例带来的适配问题不会再修。截至 2026 年这个安装包仍能安装、能打开，但别期待它跟得上系统行为的变化。

**iOS 从来没有客户端**：官方给 iOS 用户的方案一直是在 Safari 里把网站添加到主屏幕，步骤见 [手机浏览器访问与添加主屏幕.md](手机浏览器访问与添加主屏幕.md)。

客户端源码是公开的（[GitHub - MooncellWiki/Mooncell-Client-Kotlin](https://github.com/MooncellWiki/Mooncell-Client-Kotlin)），想确认它做了什么可以直接看仓库。

## 四、客户端停更不等于资料停更

客户端里看到的页面与浏览器访问 `fgo.wiki` 看到的是同一份内容。Wiki 的资料由玩家社区持续更新，活动一览、卡池一览这些都随国服、日服进度滚动刷新，所以你在停更的客户端里查到的资料，和现在玩家正在编辑的是同一份。过时的只是客户端本身，不是资料。新版客户端的侧边栏还会自动列出当前进行中的活动，国服开新活动时会取国服译名显示。

## 五、现在该怎么选

| 你的情况 | 建议 |
| --- | --- |
| 只想查攻略、查掉率 | 直接浏览器访问 [fgo.wiki](https://fgo.wiki)，不必装客户端 |
| 想边玩游戏边用小窗对照资料 | 装新版（包名 `wiki.fgo.app`，1.4.6），安装入口见 [下载与安装教程.md](下载与安装教程.md) |
| 手上是旧版 | 可以直接加装新版共存；官方页面对旧版的态度同样是「建议停止使用」 |
| 用的是 iPhone | 没有客户端可装，用 Safari 添加到主屏幕即可 |
