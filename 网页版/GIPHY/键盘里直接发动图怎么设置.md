# GIPHY 键盘里直接发动图怎么设置

> 本篇讲怎么把 GIPHY 变成一块可以在任何聊天窗口里直接搜图的键盘：开启步骤、怎么切换、权限提示怎么看，以及机型上装不出来时的替代做法。

## 一、先把这件事的定位说清楚

GIPHY 的安卓版除了本身是个应用，还可以装成**系统输入法**。装上之后，你在任何聊天软件的输入框里都能直接切到它，搜图、点一下就发出去，不用在两个应用之间来回跳。

它解决的是"来回切换"这件事，仅此而已。如果只是偶尔用一次动图，用应用里"分享到聊天软件"那条路完全够（见 [保存与分享到聊天软件.md](保存与分享到聊天软件.md)），不必为此改动输入法。

## 二、开启步骤

GIPHY 应用装好之后，它不会自动变成输入法，要手动在系统设置里启用一次：

1. 打开手机的**设置**。
2. 进**系统 → 语言和输入法**（不同品牌路径略有差异，有的叫"语言与输入法"，有的在"通用管理"下面）。
3. 找**屏幕键盘 / 虚拟键盘 → 管理键盘**。
4. 在列表里找到 **GIPHY**，把它的开关打开。
5. 系统会弹一个安全提示，说明第三方输入法可能看到你输入的内容，确认即可。

打开之后，GIPHY 只是**可选输入法之一**，并不自动变成你的默认输入法 —— 你原来那个（搜狗、百度、Gboard 之类）还是默认的。

## 三、怎么切换与切回

- **切换过去**：在任意输入框里，点键盘右下角的输入法切换图标；或者**长按空格键**，在弹出的输入法列表里选 GIPHY。
- **切回来**：用同样的方式选回你原来的输入法。
- **长按空格没反应**：说明切换手势被你的默认输入法改过，直接用右下角那个切换图标。

## 四、这个键盘的隐私提示怎么看

系统在启用第三方输入法时会给一句警告，意思是"这个输入法可能收集你输入的内容"。这句话对所有第三方输入法都出现，不是针对 GIPHY 的，但它值得你认真想一秒：

- 输入法在原理上确实"看得到"你在键盘上打的字，这是它的工作方式决定的。
- GIPHY 键盘要联网才能搜动图，所以它必然有网络访问权限 —— 这是它功能的一部分。
- 如果你的顾虑比较大，两条务实的做法：一是**只在需要发动图的时候切过去，用完切回系统输入法**；二是干脆**不用这块键盘**，改用应用内搜索 + 分享的方式（见 [保存与分享到聊天软件.md](保存与分享到聊天软件.md)），效果一样，只是多一步操作。
- GIPHY 的隐私政策在官方帮助中心可以查到（[support.giphy.com](https://support.giphy.com/hc/en-us)），想较真的话读原文。

## 五、列表里找不到 GIPHY 怎么办

有用户反馈过在部分机型（尤其是部分三星设备）的"管理键盘"列表里看不到 GIPHY 这一项，官方应用商店的评价区里也能翻到这类反馈。这类问题通常不是你的操作错，而是机型对输入法的收录规则或厂商定制造成的。

按这个顺序试：

1. 确认 GIPHY 应用**已经装好并且打开过一次** —— 有些系统要等应用至少运行一次才把它登记进输入法列表。
2. 重启手机，再回"管理键盘"看一次。
3. 到"设置 → 应用 → GIPHY"里确认它没有被限制后台或禁用。
4. 仍然不出现，就**别在这上面耗时间了**：直接用应用内搜索再分享，日常体验差别不大（做法见 [保存与分享到聊天软件.md](保存与分享到聊天软件.md)）。

## 六、用完想撤掉

- **临时不用**：把输入法切回原来的就行，GIPHY 键盘不会自己跳出来。
- **彻底关掉**：回"设置 → 系统 → 语言和输入法 → 管理键盘"，关掉 GIPHY 的开关。
- **关掉之后**：GIPHY 应用本身照常能用，只是不再出现在输入法列表里。想再用时按第二节的步骤开一遍就好。
