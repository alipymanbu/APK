## 一、先说清这一份是哪个版本

GIPHY 是一个动图（GIF）、动画贴纸和短片段的内容平台，官方应用由 Giphy, Inc. 发布。它的用法可以概括成三件事：搜到想要的动图、把它发出去、需要时自己做一个。装机本身不复杂，容易卡住的只有两处：安装包从哪来，以及权限怎么给对。

动手之前，先对着下表确认你手上这一份是不是对的：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | GIPHY |
| 开发者 | Giphy, Inc. |
| 包名 | com.giphy.messenger |
| 版本号 | 4.19.0 |
| 安装包大小 | 128.47 MB |
| 安装包 MD5 | a1b881b538f263767d1a2d9471ef71f8 |
| 适用设备 | 安卓手机、安卓平板 |
| 是否需要联网 | 搜索、浏览、分享、上传全都要联网；断网时应用内几乎没东西可看 |

**版本号要对得上，但别拿别处的版本号来对。** 你在搜索结果里看到的 GIPHY 版本号大多是官方当前最新版，和这一份未必是同一个；官方大约每隔几周发一次更新，编号形如 `4.x.x`。判断"我装的对不对"，只看两项：包名是不是 `com.giphy.messenger`，版本号是不是上面这一个。

**这里不写死最低系统版本。** 各家第三方页面标注的最低安卓版本互相矛盾，都不是官方口径。最省事的判断办法是：先在手机上打开 [Google Play 上的 GIPHY 页面](https://play.google.com/store/apps/details?id=com.giphy.messenger)，如果显示"此应用与你的设备不兼容"，那就是装不上；能点"安装"，说明你的系统版本够用。系统版本不够时系统会自己拦下来，不会装到一半坏掉。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享。相比在搜索结果里随手点一个"立即下载"，从网盘转存再下载的好处是：链接固定，文件不会被下载站中途替换成别的东西。

1. 在手机上打开 [GIPHY 安装文件资源（夸克网盘）](https://pan.quark.cn/s/fa7451de84c3)。手机浏览器或夸克 App 都能打开，**建议用夸克 App** —— 浏览器下大文件容易被切后台打断。
2. 点"保存到我的网盘"，把文件转存到自己账号下。转存之后，之后下载就不再依赖原分享链接还在不在。
3. 进自己的网盘找到这个文件，点下载，等它落到手机存储里。
4. 下完核对两件事：文件名结尾是不是 `.apk`（这一份的名字形如 `GIPHY_v4.19.0.apk`）；大小是不是 128.47 MB 左右。差得多的，多半是没下完整，删掉重来。

如果你更习惯在电脑上操作：在电脑端网盘把文件下载下来，再用数据线拷到手机的 `Download` 目录，效果一样；之后从手机的文件管理里点它安装即可。

手上有校验工具的话，可以顺手算一遍 MD5，和上表的 `a1b881b538f263767d1a2d9471ef71f8` 比一比。一致说明传输过程没出错，不一致就重新下一遍。不查也不影响安装，这只是多一层保险。

## 三、安装：系统会拦一次，放行即可

这一份是通过网盘分发、手动安装的，不是从手机自带的应用商店里点"安装"装的，所以点安装包时系统会拦一下，提示"不允许安装来自此来源的应用"之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开文件管理，进 `Download`（下载）目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的"设置"，打开**允许安装此来源的应用**开关。
   - 部分机型要去"设置 → 应用 → 特殊应用权限 → 安装未知应用"里，找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独给它放行。
3. 回到安装界面点"安装"，等进度条走完。
4. 出现"打开 / 完成"时，先点"完成"。首次启动前把权限一次性理顺，比进去之后反复弹窗省事。

## 四、首次打开要给的权限

第一次打开时，系统会依次弹权限申请。哪些该给、为什么，对照下表：

| 权限 | 用途 | 建议 |
| --- | --- | --- |
| 相机 | 用应用内的拍摄入口录动图、做贴纸的必要条件 | 想做原创内容就必须给；只想搜图可以先拒，之后要用时系统会再问一次 |
| 麦克风 | 录制 GIPHY Clips（带声音的动图）时要收音 | 只做无声 GIF 可以不给；给了之后想收回，去"设置 → 应用 → GIPHY → 权限"里改 |
| 照片 / 存储 | 从相册挑素材做成动图，以及把动图存回相册 | 建议给。不给的话"用自己拍的素材做动图"和"存到相册"两条路都走不通 |
| 通知 | 官方版本用它推内容与提醒 | 可给可不给。拒绝不影响搜图和分享 |

一个实际会遇到的情况：权限弹窗点快了、误点了"不允许"，之后点创建按钮没有任何反应。这时不用重装，去系统设置里把对应权限改回"允许"就行。

## 五、装完先做三步自检

不用急着找图，先花一分钟确认这三件事，后面出问题也好定位：

1. **能打开、不闪退**：点图标能进到首页，能看见一排一排的动图在循环播放。反复闪退的话，看 [常见问题与排查.md](常见问题与排查.md) 里"闪退与编辑中崩溃"那一节。
2. **能加载出内容**：首页有内容，说明网络能连上 GIPHY 的服务器。首页空白、缩略图全是灰框，多半是网络这一层的问题，先看 [常见问题与排查.md](常见问题与排查.md) 的第二节。
3. **能搜、能复制**：随便搜一个词（比如 `happy`），点开一张图，试一次复制或分享。这一步把搜索、内容加载和分享通道一起验了。

三步都过，就可以正常用了。接下来最常做的是"搜到图然后发出去"，操作细节见 [怎么搜到想要的动图.md](怎么搜到想要的动图.md) 与 [保存与分享到聊天软件.md](保存与分享到聊天软件.md)。

## 六、升级与卸载要注意的

- **升级**：新版本会换一个安装包文件名，直接装新包覆盖即可，一般不用先卸载。安卓通常不允许用更低版本号覆盖更高版本号，遇到"应用未安装"先确认版本号方向。
- **卸载**：卸载会清掉应用私有目录里的本地数据。已经同步到 GIPHY 账号下的收藏不会丢，前提是卸载前已经登录并且收藏是登录状态下加的（见 [收藏与账号同步.md](收藏与账号同步.md)）。
- **安装包删了**：任何时候都能回到文首那条 GIPHY 安装文件资源的链接重新取一份；已经转存过的不受原分享影响。
