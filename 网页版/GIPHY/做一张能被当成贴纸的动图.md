## 一、贴纸和普通动图的区别只有一个字：透明

贴纸是 GIPHY 里的另一种内容形态：格式上和普通动图是同一类东西，差别只在于**背景是透明的**。本篇讲它的硬性规格、几种常见的"看着像、其实不合格"的做法，以及在手机上怎么把一张静态图做成贴纸。

搜索时你可能已经注意到了：同样一个词，搜出来的结果里有一部分图贴到别的东西上面也不会带白底 —— 那类就是贴纸（Sticker）。

正因为背景透明，贴纸的用法和普通动图不一样：普通动图是"一张图发过去"，贴纸是"盖在别的东西上面"。用它做表情、给照片加动效、在聊天里叠加，都是这个特性带出来的。

这个区别也决定了一件事：**一张白底的动图，即使画面内容再合适，也不是贴纸**。

## 二、官方列的规格

下面这份是官方给创作者列出的贴纸规格（[GIPHY 官方帮助中心](https://support.giphy.com/hc/en-us) 的贴纸规格页）。这类数值有调整的可能，以官方当页为准：

| 要求 | 具体 |
| --- | --- |
| 背景必须透明 | 导出时不能带白色或彩色的背景层 |
| 必须会动 | 至少要有两帧。一张不动的图不算贴纸 |
| 首帧的透明比例 | 第一帧至少 20% 的像素是透明的，否则不会被识别成贴纸 |
| 源文件格式 | 必须是 GIF。官方目前不支持 APNG |
| 循环方式 | 导出前把循环设成"永久循环"，不要只播一次 |
| 画布要裁到贴合 | 画面里留太多空白，上传后显示出来会非常小 |
| 不要边框 | 背景本来就是透明的，再加一圈边是多余的 |
| 宽高取 4 的倍数 | 官方的建议，不是硬性要求 |
| 对比度 | 官方另有"可见像素里至少 80% 以黑或白为主"的对比度要求 |

**这几条里真正绕不开的是前两条**：不透明就不叫贴纸，不动也不叫贴纸。后面几条是给走官方贴纸渠道、希望被大量收录的创作者准备的；你只是自己做一张在聊天里用，不必逐条卡死。

## 三、三种常见的"看起来是贴纸、其实不合格"

1. **白底图直接改后缀。** 把一张带白底的照片直接导成 GIF，背景还是白的，贴上去就是一块白方块。要透明，得在导出时**关掉背景层**，而不是改文件后缀。
2. **视频裁成圆形或方形再导出。** 官方明确说过，这种做法得到的结果不算贴纸 —— 虽然看起来形状对了，但透明背景不等于"裁出来的形状"。正确做法是去掉背景，形状由画面本身决定。
3. **用静态图硬撑。** 只有一帧的图不满足"至少两帧"。想让静态图动起来，用下面的办法。

## 四、在手机上把静态图做成贴纸

GIPHY 应用里没有独立的"贴纸生成器"入口，但它的创作流程能达成同样的结果 —— 官方提供的贴纸制作工具（Sticker Maker）在网页端，用来给静态图加动画。

手机上更省事的做法，是走 [自己做动图和贴纸.md](自己做动图和贴纸.md) 里那条路：

1. 从相册选这张静态图进创作页。
2. 加一样**会动**的东西：叠一张动画贴纸，或者加上会动的文字效果。
3. **关键一步：让背景透明。** 这一步在手机端受版本影响，界面里不一定有直接开关。如果你的版本里做不到透明背景，就把这张图当普通动图用 —— 它在聊天里照样能动，只是贴到别的图上会带底。
4. 上传时把标签写具体，方便之后自己搜回来。

**如果你的目标只是"在聊天里当一个会动的表情"，其实不必纠结透明背景。** 那件事的做法见 [动图做成聊天表情包怎么弄.md](动图做成聊天表情包怎么弄.md)。

## 五、做完之后

贴上去了才发现边缘有白边、或者小尺寸下糊成一团，这是贴纸最常见的两个问题：

- **白边**：多半是原图本来就带一圈浅色描边，或者导出时背景没关干净。回创作页重做一次比事后修省事。
- **缩小后看不清**：官方给创作者的建议里有一条 —— 别放会随尺寸缩小而消失的细碎细节。做完之后把图缩到聊天窗口里那么大看一眼，能看清才算过关。
