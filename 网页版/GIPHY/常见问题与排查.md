## 一、先按症状分类，别乱试

GIPHY 出问题时的表现就那么几种，绝大多数是网络、权限、版本这三样之一，真正需要重装的情况很少。本篇按"你看到的症状"组织：先在下面这张表里找到你的症状，再跳到对应那一节按顺序试，不要跳着试 —— 顺序本身能帮你排除原因。

| 你看到的 | 大概率是哪一层 | 直接跳到 |
| --- | --- | --- |
| 首页空白、缩略图一片灰框、搜索一直转圈 | 网络 / 服务连通性 | 第二节 |
| 换了好几个词都搜不出内容 | 关键词写法，或者同上的网络问题 | 第三节 |
| 应用一打开就退回桌面、编辑到一半崩掉 | 应用与设备 | 第四节 |
| 做完了传不上去、进度条卡住 | 素材或网络 | 第五节 |
| 收藏夹是空的、爱心点不亮 | 账号 | 第六节 |
| 键盘列表里找不到 GIPHY | 机型与系统设置 | [键盘里直接发动图怎么设置.md](键盘里直接发动图怎么设置.md) |
| 发给别人之后图不动 | 接收方应用的处理方式 | [保存与分享到聊天软件.md](保存与分享到聊天软件.md) |

## 二、内容加载不出来

这一类占了绝大多数。GIPHY 的内容全部来自在线服务，**本地没有任何内容缓存可用**，所以只要连不上它的服务器，界面就是一片空白 —— 应用本身并没有坏，也没法靠改设置绕开。

**第一步，先分清是网络问题还是应用问题。** 用手机浏览器打开 [giphy.com](https://giphy.com/)：

- 网页也打不开 → 问题在网络这一层，继续往下做。
- 网页能正常打开，只有应用不行 → 跳到"应用侧"那几步。

**网络侧：**

1. **换一种接入方式**：Wi-Fi 换成移动数据，或者反过来。如果换完就好了，问题在你原来那个网络。
2. **关掉代理类工具再试**：VPN、网络加速器、公司或学校的网络策略，都可能在中间把媒体域名拦掉。关掉之后重开应用看看。
3. **确认不是全站故障**：GIPHY 也偶发服务端问题，表现为你在哪都连不上。第三方状态页 [Downdetector 的 GIPHY 状态页](https://downdetector.com/status/giphy/) 上如果同一时间有大量报告，那就是等着，不用折腾手机。
4. **换个环境验证**：连个手机热点试一次，能通就说明是你常用网络的问题。

**应用侧：**

1. **彻底退出再打开**：从后台任务列表里划掉 GIPHY，重新进。
2. **清一次缓存**：到"设置 → 应用 → GIPHY → 存储"，点**清除缓存**（注意不是"清除数据" —— 缓存清了不影响登录状态，数据清了要重新登录）。
3. **确认版本不是太旧**：旧版客户端可能和新版服务对不上，更新到较新的版本再看。
4. **重启手机**，然后再打开应用。

## 三、搜不出想要的内容

如果内容本身能加载（首页有图），只是某个词搜不出东西，那是搜索的问题，不是故障：

1. **换成英文再搜。** 这是收益最大的一步，原因见 [怎么搜到想要的动图.md](怎么搜到想要的动图.md) 第二节。
2. **换同义词**，或者把词写得更具体/更笼统。
3. **别写整句**，只留主体词。
4. **确认搜索词没超长**（有 50 字符的上限），也别堆太多词。
5. **想找贴纸**，把 `stickers` 写进搜索词里。
6. **换了好几个词都完全没结果** → 那其实是第二节的问题（网络不通时搜索也是空的），回去按第二节查一遍。

## 四、闪退与编辑中崩溃

- **先清缓存再开**（"设置 → 应用 → GIPHY → 存储 → 清除缓存"）；不行就重启手机，再不行重装。
- **编辑到一半崩掉、进度全没了**：有用户在官方应用商店的评价里反馈过这种情况 —— 编辑过程中崩溃会丢掉没上传的编辑进度。务实的对策是：**别一次性磨太久** —— 素材选短一点，文字和贴纸分几步加、每完成一步就往下走上传，比一直挂着慢慢调安全。
- **重装前先确认收藏已经跟着账号走了**（见 [收藏与账号同步.md](收藏与账号同步.md)）。没有登录账号的话，重装等于把本地的东西全清掉。

重装需要的安装包，还是从文首那条 GIPHY 安装文件资源里取，或者用你之前转存到网盘的那一份。

## 五、上传失败

自己做的内容传不上去，按这个顺序排：

1. **素材太大或太长**。动图越大越长，上传越容易中断。先用剪刀把长度和范围切小一点再传。
2. **网络不稳**。上传比浏览更怕断线，换到稳定的 Wi-Fi 再试一次。
3. **确认是登录状态**。登录失效时上传会被拒，退出重新登录一次。
4. **素材本身的格式**。用相册里的视频做素材通常没问题；来源不明的文件如果反复失败，换一个素材试试，以区分是"素材的问题"还是"通道的问题"。
5. **改完标签再传**。标签里有异常字符时也可能导致提交失败，先把标签简化成一两个普通词试一次。

## 六、账号与收藏

- **爱心点不亮、收藏夹是空的**：先确认已经登录。收藏是需要账号的功能，未登录时用不了。
- **换了手机，收藏没了**：确认新设备登录的是不是**当初收藏时用的那个账号**。收藏跟着账号走，不跟着设备走。
- **收藏过的内容点不开了**：这类情况通常是原作者删除了内容，或者内容被平台下架，收藏里只剩一条打不开的空记录。
- **登录不上**：先按第二节确认网络能连通；账号本身的问题（忘记密码、怀疑被盗）走官方渠道 —— 帮助中心在 [support.giphy.com](https://support.giphy.com/hc/en-us)，官方公开的支持邮箱是 `support@giphy.com`。

## 七、怎么向官方反馈

应用里的问题和建议，官方给的正规渠道是两个：帮助中心 [support.giphy.com](https://support.giphy.com/hc/en-us) 和上面那个支持邮箱。描述问题时把这几样带上，对方一次就能定位：

- 手机型号与安卓版本；
- GIPHY 的版本号（在应用里能看到，这一份是 `4.19.0`）；
- 具体哪一步出的问题，最好带上截图或录屏。
