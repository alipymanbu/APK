## 一、为什么"当图片发"和"当表情发"不是一回事

把 GIPHY 里搜到的动图变成聊天软件里"点一下就发"的表情，是这类内容最常见的用法；本篇讲这么做的两条入口、体积限制卡住了怎么办，以及它和 GIPHY 收藏的区别。

同一个动图，用聊天软件的"图片"入口发出去，有时对话里会直接播放动画，有时只显示第一帧、点开才动 —— 因为这时接收方是按"一张图片"来处理的，各家客户端对动图的处理并不统一。

**而把它加进"我的表情"再发，客户端会按表情的规则来渲染**，显示效果通常稳定得多，也省去每次翻相册的麻烦。所以"把自己常用的动图做成表情包"这件事，值得花两分钟做一次。

## 二、以微信为例：把 GIF 加进自定义表情

微信自定义单个表情的入口有两条，都能用：

**路径一：从手机相册添加**

1. 微信里进 **我 → 表情**。
2. 滑到最底部，点 **添加的单个表情**。
3. 点右上角的 **+**，系统问相册权限时选允许。
4. 在相册里选中刚存下来的那张 GIF。
5. 按提示把裁切框调成正方形，点**完成**。

**路径二：长按现成的表情添加**

在聊天窗口里长按对方发来的那个表情，选**添加到表情**，它会直接进你的表情库。

微信对自定义表情的几条限制（这类规则会随版本调整，以你手上那版微信的提示为准）：

| 限制 | 具体 |
| --- | --- |
| 格式 | 静态图用 JPG / PNG；动图**必须**是 GIF |
| 体积 | 动态表情通常要求不超过 1 MB |
| 形状 | 会被裁成正方形显示 |
| 数量上限 | 自定义表情最多 300 个，满了要先删几个 |

## 三、体积超了怎么办

**这是从 GIPHY 拿图做表情最常卡住的一步。** 网上下来的动图动辄几 MB，而聊天软件的表情入口卡得很死。

按这个顺序处理，不用装任何额外工具：

1. **换一张更小的。** 回 GIPHY 再搜一次同类内容，挑时长更短、画面更简单的 —— GIF 的体积主要由帧数和尺寸决定，短一点、小一点的那张往往就够用了。
2. **先裁再存。** 用手机相册自带的编辑功能把画面裁小一圈，体积跟着降。
3. **实在过不了就退一步：当图片发。** 接受它可能只显示第一帧；或者用聊天软件的"文件"方式发，对方点开能看到完整动画。
4. **别为了压到限制以内去用来路不明的转换工具。** 换来的是画面糊、帧数被砍、动画变卡，得不偿失。

## 四、表情包和 GIPHY 收藏，是两回事

这两个概念很容易混，混了就会白折腾：

| | 存在哪 | 换手机之后 |
| --- | --- | --- |
| 聊天软件里的自定义表情 | 存在聊天软件自己的数据里 | **不会自动跟着走**，通常要重新加一遍 |
| GIPHY 账号里的收藏 | 跟着 GIPHY 账号（见 [收藏与账号同步.md](收藏与账号同步.md)） | 登录同一账号就回来了 |

所以更稳的习惯是：**在 GIPHY 里收藏一份，需要的时候再把常用的那几张加进聊天软件的表情库**。GIPHY 里那一份是你的"素材库"，聊天软件里那一份是"手边常用的几个"。

## 五、两点提醒

- **表情包发出去就收不回来了。** 别人保存、转发都拦不住。自己拍进画面的人脸、门牌、聊天记录，加进表情之前先想一遍。
- **别的聊天软件规则各不相同，但套路一样**：都有体积上限，都有自己的"表情/贴纸"入口。找不到入口时，在设置里搜"表情"两个字，基本都能找出来。发出去之后动画丢了的话，[保存与分享到聊天软件.md](保存与分享到聊天软件.md) 里那套排查思路同样适用。
