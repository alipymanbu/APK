## 一、不登录能用多少

GIPHY 的账号是免费的。**不登录也能搜图、看图、分享和复制** —— 这些是这个应用最常用的部分，先跳过登录不影响你上手。

但要清楚哪些事必须有账号才做得了：

| 想做的事 | 需要账号吗 |
| --- | --- |
| 搜索、浏览、看分类和热门 | 不需要 |
| 分享到聊天软件、复制到剪贴板 | 不需要 |
| 把动图存到手机相册 | 不需要 |
| 收藏动图、贴纸（爱心） | **需要** |
| 自己拍一段做成动图并上传到 GIPHY | **需要** |
| 换设备后看到之前收藏的内容 | **需要**（收藏跟着账号走，不跟设备走） |

一句话：**把账号当成"收藏夹和作品库的钥匙"就对了**，不是在用它换使用权。

顺带把费用说清楚：**下载和使用不收费**，搜图、收藏、分享都在免费范围内。至于这个应用里有没有广告、有没有内购项目，各家应用商店页面上的标注才是准的，以你手机上当时显示的为准。

## 二、怎么注册和登录

在应用里注册的入口在右下角的用户图标：点进去，切到注册（Sign up）那一栏，选一种方式建号。

**两种方式，选一种：**

- **用邮箱注册**：填邮箱地址、用户名和密码，提交即可。用户名会公开显示在你上传的内容旁，起名时顺手想一下。
- **用 Facebook 账号登录**：会短暂跳到 Facebook 授权页再跳回来。如果你的 Facebook 账号本身就不常用，建议还是用邮箱，少一层依赖。

登录之后，账号状态在各个设备上是通的：在电脑上打开 [giphy.com](https://giphy.com/) 登录同一账号，收藏和上传的作品与手机上是同一份。这也是后面"换设备不丢东西"的原理。

## 三、收藏怎么用

收藏入口是动图上的**爱心图标**：在动图或贴纸上点一下爱心，它就进了你的收藏；再点一下取消。收藏列表在导航栏的爱心图标里，网页端则是 [giphy.com/favorites](https://giphy.com/favorites)。

几个实际会碰到的点：

- **收藏的是"那张图"，不是文件。** 它不会往你手机相册里存东西，只是记下这条内容，用的时候点开再分享。想存成文件要看 [保存与分享到聊天软件.md](保存与分享到聊天软件.md)。
- **内容下架就没了。** 收藏只是引用，如果原作者删掉或内容被平台移除，收藏列表里这一条就点不开了 —— 真正舍不得丢的，顺手存一份到相册更稳。
- **别把收藏当分类用。** 收藏列表就是一个长条，没有文件夹；要分类的话，网页端登录后可以把内容归进"合集"分组。移动端各版本的入口位置不一样，找不到就先不折腾，用搜索词重新找回来也一样快。
- **收藏没有回收站。** 取消爱心是直接移除。

## 四、换手机、重装、多设备

这是账号真正起作用的地方。

1. **换手机或重装之后**：装上 GIPHY（安装包从文首的 GIPHY 安装文件资源里取，或者你之前转存过的那份），用**同一个账号**登录，收藏和你上传的作品会自己回来。
2. **没有用同一个账号登录**：新设备上就是一份空的收藏列表。本地卸载清掉的东西，官方不会替你恢复。
3. **多设备同时登录同一个账号**：收藏是共享的，在平板上收藏一张，手机上刷新就能看到，不需要手动同步。
4. **在网页端和移动端之间来回用**：官方支持用同一账号跨端，所以你可以在电脑上慢慢挑、加进收藏，回到手机上直接发。

## 五、账号相关的事项

- **用户名**：可以在账号设置里改，改完不影响已有的收藏和作品。
- **删号**：官方提供了删除账号的入口，删号是不可逆的，动手前把要留的内容先存到本地或别处。
- **账号异常**：如果发现登录不上、或者内容里出现了不是你发的作品，官方帮助中心（[support.giphy.com](https://support.giphy.com/hc/en-us)）里有账号被盗的处理说明，优先按官方流程走。
- **登录不上、验证码收不到之类的问题**，先按 [常见问题与排查.md](常见问题与排查.md) 第二节的顺序排查一次网络，再考虑账号本身的问题 —— 这两类问题的表现很像。
