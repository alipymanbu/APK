## 一、三个渠道一张表

| 对比项 | GitHub 发布版 | Nightly 每日构建 | Play 商店版 |
| --- | --- | --- | --- |
| 定位 | 官方正式发布 | 跟随最新代码自动构建 | 商店分发 |
| 稳定性 | 总体稳定、可日常用（官方文档口径） | 可能不稳定、可能带新 bug | 与官方 Beta 同一水平 |
| 更新方式 | 官方定期发布 | 自带内置更新器 | 商店自动更新，通常比 Beta 晚 1~2 周 |
| 包名 | 与另两者都不同 | `app.lawnchair.nightly` | `app.lawnchair.play` |
| 适合谁 | 多数人 | 测试者、尝鲜者、等某个具体修复的人 | 只想商店自动更新的人 |

官方文档的总结就三句话：求稳从 GitHub 或 Play 起步；要最新修复选 Nightly，同时接受偶发的翻车。

## 二、Nightly 的版本号怎么读

以 15.Dev.2186 为例，拆成三段看：

- **15** —— 这一代基于 Android 15 的 Launcher3 代码分支。Lawnchair 每一代跟随一个 Android 版本命名，代码跟着 AOSP 走。
- **Dev** —— 开发构建，区别于 Beta 与正式发布。
- **2186** —— 构建编号，随开发推进持续增大，数字越大代码越新。

构建号每天都在往前走，你装到的具体编号过几天就不再是最新——这是 Nightly 的常态，不代表装错了东西。

## 三、包名不同意味着什么

三个渠道是三个互相独立的应用，可以同时装在一台手机上。常见的用法是：留一份稳定渠道的日常用，另装一份 Nightly 试验新功能，试完不合适直接卸掉 Nightly 那份。

代价是两份数据互不相通，布局与设置要各配各的；换渠道就等于从头再配一遍，动手前记得先各做一份备份留底（方法见 [备份与恢复桌面布局.md](备份与恢复桌面布局.md)）。

## 四、更新怎么跟

- **Nightly**：在应用内用内置更新器检查更新；也可以到官方 GitHub 的 releases 页手动拿最新构建。
- **GitHub 发布版**：到官方 GitHub releases 页下载新 APK 覆盖安装。
- **Play 版**：商店自动更新，不用管。

覆盖安装只在版本号往前走时顺利；想把 Nightly 退回更旧的构建，必须先卸载再装，否则会报"应用未安装"——排查方法见 [下载与安装教程.md](下载与安装教程.md) 的第四节。

## 五、配套这份资源是哪一版

本文配套的 [Lawnchair 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3ea9407ada2c) 里是一份 Nightly 构建：版本 15.Dev.2186、包名 `app.lawnchair.nightly`、大小 21.60 MB、MD5 `E06C7DD89683EE0554577835EBB42FBF`，整理于 2026 年 9 月。

按第二节的读法，这份构建的编号在 Nightly 序列里不算新。介意新旧的话，装好后用应用内更新器升到当前构建，或者直接从官方 GitHub 拿最新的；不介意就先用，功能框架与设置项是一致的。
