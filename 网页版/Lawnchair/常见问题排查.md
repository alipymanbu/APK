## 一、先学这个万能动作

长按桌面空白处 → **主屏幕设置**（Home settings）→ 右上角 **更多**（⋮）→ **重启 Lawnchair**。

小部件全部消失、改了字体不生效、图标显示异常、桌面卡住——官方文档几乎每类问题都先让你试它。它只重启桌面本身，不动你的布局与设置，成本几乎为零。

## 二、系统手势不跟手

先分清两件事：这里说的是**系统导航手势**（回主屏、最近任务的滑动动画），不是 Lawnchair 自己的手势设置（主屏幕设置 → 手势那一节）。

第三方桌面拿不到系统桌面才有的手势特权，所以换上 Lawnchair 之后可能出现这些情况：

- 小米等厂商在系统层面直接封掉第三方桌面的手势导航。
- 回到主屏后，图标或小部件短暂点不动。
- 滑回主屏后快速连点，桌面内容闪一下、消失一下。
- 回主屏动画卡顿，甚至干脆不播。
- 刚滑回主屏就点开应用时，打开动画失效。
- 回主屏后内容出现前有短暂延迟——OPPO、一加、realme 在 Android 14 上出现过这类问题，别的机型也可能有。

官方文档给的两条改善路径：

1. **不 root**：Android 11 起 Lawnchair 走 Google 的 GestureNavContract 接口改善动画，效果取决于你的机型——接近原生系统的（Pixel、Nothing、AOSP 类 ROM）通常较好，深度定制的（三星、小米、欧加系）问题多一些。遇到"关闭应用后应用图标卡在屏幕上"，到 主屏幕设置 → 更多（⋮）→ **实验性功能**（Experimental features）→ 关掉 **Use GestureNavContract API**。
2. **已 root**：官方指的路是 QuickSwitch Magisk 模块——让 Lawnchair 接管最近任务界面，动画一致性会好得多。

这些限制大多来自 Android 或厂商定制本身，换哪个第三方桌面都躲不开，区别只在程度。

## 三、小部件三类问题

| 现象 | 处理 |
| --- | --- |
| 小部件加不上、添加时闪退 | 临时把默认桌面切回系统桌面 → 打开 Lawnchair → 重新添加这个小部件 → 再把默认桌面切回 Lawnchair |
| 小部件数据不更新 | 把小部件拉大再缩回原尺寸；打开提供小部件的那个应用，检查它的权限、清它的缓存 |
| 桌面上小部件全部消失 | 多半是桌面闲置久了被系统清掉——用第一节的"重启 Lawnchair"拉回来 |

## 四、被电池优化坑

系统为省电强杀后台时，Lawnchair 会表现出三类怪病：

- 双击熄屏之类依赖无障碍服务的手势失灵（服务被系统停了）。
- 小部件不更新、点了没反应。
- 退出应用回到桌面时重载、白屏半拍。

处理思路只有一个：给 Lawnchair 关掉电池优化。各家厂商的设置路径五花八门，官方文档直接指路 [dontkillmyapp.com](https://dontkillmyapp.com/?app=Lawnchair)，按你的手机品牌进去查对应步骤。

## 五、崩溃

### 先恢复使用

依次试：重启 Lawnchair（第一节）→ 更多（⋮）→ 应用信息 → 存储和缓存 → 清除缓存 → 重启手机 → 还不行，先按 [备份与恢复桌面布局.md](备份与恢复桌面布局.md) 备份，再走"清除存储"重置。

### 再交日志

Lawnchair 自带崩溃报告：崩溃后通常会弹一条通知，点 **Upload file** 生成链接 → **Copy to clipboard** → 到官方 GitHub 仓库的 bug 报告表单里，把链接粘进"Additional Information"后提交。

一个容易忽略的前提：Android 14 及以上必须给 Lawnchair 开着**通知权限**，否则崩溃通知收不到，日志也走不出去。

如果用的是 Nightly 构建且崩溃频繁，多半撞上了构建本身的 bug——等下一个构建、或先切到 GitHub 稳定渠道，都是合理选择；渠道差异见 [Nightly与Play版怎么选.md](Nightly与Play版怎么选.md)。

## 六、应用在抽屉里找不到

先确认不是被藏了：主屏幕设置 → 应用抽屉 → 隐藏应用，逐项核对勾选状态，操作细节见 [应用抽屉设置与隐藏应用.md](应用抽屉设置与隐藏应用.md)。再确认不是桌面整体被系统杀了后台——那类问题的表现是小部件一起异常，按第四节处理。
