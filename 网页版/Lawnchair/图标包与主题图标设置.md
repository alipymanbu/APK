## 一、设置入口

长按桌面空白处 → **主屏幕设置**（Home settings）→ **常规**（General）→ **图标样式**（Icon style）。图标包、主题图标来源都在这一层。

## 二、换图标包

1. 主屏幕设置 → 常规 → 图标样式。
2. 在列表里选一个已经装好的图标包。

图标包要作为普通应用先装到手机上。找包的两个常用渠道：

- Play 商店搜索 "icon pack"
- F-Droid 的图标包分类：[https://f-droid.org/en/categories/icon-pack/](https://f-droid.org/en/categories/icon-pack/)

官方配套的图标包叫 **Lawnicons**，开源、单色风格，既能当普通图标包用，也能当"主题图标来源"用（见下一节），单独装一个 APK 即可。

### "用强调色染色"开关

图标样式里有一个 **Tint with accent color**（用强调色染色）开关：打开后所有图标被套上当前强调色，观感统一，但会盖掉图标包本身的配色。用了彩色图标包还觉得颜色不对，先把这里关掉。

## 三、开单色主题图标（Themed icons）

主题图标是 Android 的原生功能：应用图标变成单色版本，再由桌面按你的壁纸与主题重新着色。它叠加在你选的图标包之上，两者不冲突。

开启路径：

1. 主屏幕设置 → 常规 → 图标样式。
2. 点 **主题图标来源**（Themed icon source）。
3. 点 **主题图标**，选作用范围：
   - 仅主屏幕
   - 主屏幕和应用抽屉
4. 在来源列表里选一个（装了 Lawnicons 就选它）。

图标包与主题图标来源这两个用法容易混，官方文档专门解释过区别：

| 用法 | 效果 |
| --- | --- |
| 当图标包用 | 应用它的默认外观；支持的设备上外观会带壁纸色彩 |
| 当主题图标来源用 | 单色图标，由 Lawnchair 按当前主题重新着色 |

个别应用没有单色图标，是因为 Lawnicons 还没收录它；可以去 Lawnicons 的 GitHub 仓库提交图标请求，或者自己投稿图标。

## 四、强调色与整体配色

主屏幕设置 → 常规 → **强调色**（Accent color），三种取色方式：

| 方式 | 行为 |
| --- | --- |
| 跟随系统 | 用设备系统提供的颜色 |
| 取自壁纸 | 从当前壁纸取色；动态壁纸可能取不准 |
| 自定义 | 从预设色板挑，或自己指定任意颜色 |

强调色不选"跟随系统"时，还可以点 **色彩样式**（Color style）换一套应用方式。

## 五、只改某一个应用的图标

1. 长按要改的那个图标 → 点 **自定义**（Customize，铅笔图标）。
2. 点一下现有图标，打开图标编辑器。
3. 从已安装的图标包里挑一个换上。

两个官方注明的限制：只对应用图标生效，快捷方式不行；工作资料（工作账户）里的应用不支持。

## 六、改完不生效

换字体、换图标包之后偶尔不刷新：主屏幕设置 → 右上角 **更多**（⋮）→ **重启 Lawnchair**。这是官方文档给的通用复位动作，多数"改了没反应"到这里就解决了；还不行再去 [常见问题排查.md](常见问题排查.md) 按类排查。
