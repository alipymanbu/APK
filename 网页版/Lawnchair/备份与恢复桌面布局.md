# Lawnchair 备份与恢复桌面布局

> 本篇讲怎么把整套桌面（布局加设置）存成 `.lawnchairbackup` 文件、换机或重装后怎么恢复、从 Nova Launcher 迁移怎么导入，以及重置回默认的正确顺序。

## 一、什么时候该备份

- 用 Nightly 构建的：每次更新前备份一份，翻车了好回退。
- 换机、恢复出厂、大范围卸载应用之前。
- 准备做"清除存储"级别的重置之前（见第五节）。

## 二、创建备份

1. 主屏幕设置 → 右上角 **更多**（⋮）→ **创建备份**（Create backup）。
2. 勾选要包含的内容：
   - **布局与设置**（Layout and settings）：桌面布局、抽屉与搜索设置、绝大多数设置项（含手势与主题）。
   - **壁纸**：当前壁纸（用的是动态壁纸时这项不可用）。
3. 点 **创建**，选一个好找的位置保存，比如"下载"目录或网盘目录。

备份文件扩展名为 `.lawnchairbackup`，文件名里会带生成时间。

## 三、备份包含与不包含什么

官方文档列得很细，换机前先对照这张表，别以为备份了就全都在：

| | 内容 |
| --- | --- |
| 包含 | 桌面布局（图标位置、文件夹）、应用抽屉与搜索设置、大多数 Lawnchair 设置（手势、主题等） |
| 不包含 | 小部件的数据与内部设置——位置会保留，恢复后需要逐个重新配置小部件内容 |
| 不包含 | 图标包、Smartspacer 这类配套应用本身——它们是独立应用，要另装；缺了 Lawnchair 会回退到默认设置 |
| 不包含 | 工作资料（工作账户）应用——Android 对它的处理不一致，恢复不可靠 |
| 不包含 | 目标设备上没装的应用——图标不会出现 |

## 四、恢复备份

1. 主屏幕设置 → 更多（⋮）→ **恢复备份**（Restore backup）。
2. 在文件选择器里选中你的 `.lawnchairbackup` 文件。
3. 选择恢复"布局与设置"、"壁纸"还是两者 → 点 **恢复**。

提示找不到备份文件时，确认它存在文件选择器能访问的位置（本机存储或可访问的网盘目录）。

### 从 Nova 备份导入

从 Nova Launcher 迁移过来的，Lawnchair 15 Beta 3 及之后的版本能直接读 `.novabackup` 文件，入口：主屏幕设置 → 更多（⋮）→ **恢复 Nova 备份**。

- **能恢复**：网格布局、图标及其位置、小部件位置（不含小部件数据）、文件夹及其内容（应用已装的前提）、已安装的图标包。
- **不能恢复**：Nova 手势、通知徽章等 Nova 专属设置；抽屉的分类与设置；Lawnchair 自己的设置；子网格位置会被对齐到最近的标准网格。

确认页会给出摘要：原来用了子网格布局的会提示对齐方式；想保留 At a Glance 的可以勾选"额外加一行"。考虑从 Nova 换过来的人为什么多、两边具体差在哪，见 [与NovaLauncher的区别.md](与NovaLauncher的区别.md)。

## 五、重置回默认

设置改乱了想全部重来，走清空存储这条路：

1. 主屏幕设置 → 更多（⋮）→ **应用信息**。
2. **存储和缓存** → **清除存储**。
3. 警告弹窗里点 **删除**。

这一步不可逆，所有自定义设置与布局全部还原为默认。动手之前先把第二节做一遍；重置后如果连 Lawnchair 本体都要重装，安装步骤见 [下载与安装教程.md](下载与安装教程.md)。
