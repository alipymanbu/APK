## 一、先弄清楚装哪个渠道

Lawnchair 有三个发布渠道，包名与更新方式都不同：

| 渠道 | 适合谁 | 特点 |
| --- | --- | --- |
| GitHub 发布版 | 大多数人 | 官方定期发布，总体稳定，官方文档建议从这里起步 |
| Nightly 每日构建 | 想第一时间拿到修复、能接受偶发问题的人 | 跟随最新代码自动构建，自带更新器，与 Beta 版是两个独立应用、可以并存 |
| Play 商店版 | 只想在商店里自动更新的人 | 包名不同（`app.lawnchair.play`），发布通常比 Beta 晚 1~2 周；受商店政策限制，部分功能不可用 |

三个渠道的详细差异单独写了一篇，见 [Nightly与Play版怎么选.md](Nightly与Play版怎么选.md)。本篇讲的是侧载 APK 这条路——网盘里的安装文件、GitHub 上的发布包都走它。

## 二、装之前确认两件事

- **系统版本**：网上收录的 Nightly 包信息显示最低要求 Android 8.0（API 26），以官方发布页当时的说明为准。
- **存储空间**：安装包本身 21.60 MB（本文配套这份的体积），再留几十 MB 余量即可。
- **不需要 root**：只有一项集成（QuickSwitch，接管最近任务动画）才涉及 root，普通使用完全用不到。

## 三、侧载安装步骤

### 1. 允许"安装未知应用"

Android 默认禁止从商店以外装应用，但要授权的不是全局开关，而是"你用来打开 APK 的那个应用"：

1. 打开系统设置 → 应用 → 特殊访问权限 → 安装未知应用（不同机型的菜单位置略有差异，在设置里直接搜"安装未知"最快）。
2. 找到你接下来要用的文件管理器（或浏览器），允许"来自此来源的应用"。

### 2. 拿到安装包

从 [Lawnchair 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3ea9407ada2c) 转存后下载到手机，或从官方 GitHub 发布页下载。装之前核对文件信息是好习惯，本文配套这份为：

- 包名：`app.lawnchair.nightly`（Nightly 构建）
- 版本：15.Dev.2186
- 大小：21.60 MB
- MD5：`E06C7DD89683EE0554577835EBB42FBF`

### 3. 放行 Play Protect 拦截

侧载时 Play Protect 可能弹警告甚至直接拦截，官方文档给的处理方式：

1. 弹出提示时点 **仍然安装**（Install anyway）。
2. 如果连这个选项都没有：打开 Play 商店 → 右上角头像 → **Play Protect** → 设置齿轮 → 关闭"使用 Play Protect 扫描应用" → 装完立刻把它再打开。

### 4. 点开 APK 完成安装

在文件管理器里点开 APK，按提示确认安装。出现"应用未安装"时按下一节的顺序排查。

### 5. 设为默认桌面

装完只是一个普通应用，还要让系统把桌面交给它：

1. 长按桌面空白处 → 点 **主屏幕设置**（Home settings）。
2. 点提示卡片"To access shortcuts and additional features, set Lawnchair as your default launcher"。
3. 在弹出的列表里选 **Lawnchair**。

也可以走系统设置：设置 → 应用 → 默认应用 → 主屏幕应用（叫法因机型而异）。

### 6. Android 13 及以上：允许"受限设置"

侧载的应用默认拿不到通知访问、无障碍服务等敏感权限，要手动解锁一次：

1. 先试着开启一个会触发拦截的权限（比如无障碍服务），让系统弹出 **受限设置**（Restricted setting）提示——必须先看到这个提示，后面的步骤才有效。
2. 主屏幕设置 → 右上角 **更多**（⋮）→ **应用信息**。
3. 在 Lawnchair 的应用信息页再点右上角 **更多**（⋮）→ **允许受限设置**。
4. 按屏幕提示完成。

官方文档说明：这一步通常只有 GitHub 与 Nightly 版需要，Play 商店版一般用不着。

## 四、"应用未安装"怎么查

按常见程度从高到低：

| 可能原因 | 处理方式 |
| --- | --- |
| 安装包来源不正规，签名对不上 | 换官方渠道重新拿包；手机里装过来路不明的修改包就先卸掉 |
| 文件下载不完整或损坏 | 删掉重新下载，核对 MD5 |
| 低版本覆盖高版本失败 | 先卸载已装的新版本再装（Nightly 更新频繁，最容易撞上） |

## 五、装完先做一次备份

开始折腾主题、网格、手势之前，先按 [备份与恢复桌面布局.md](备份与恢复桌面布局.md) 存一份 `.lawnchairbackup`——Nightly 构建更新很勤，之后不管是更新翻车还是自己改乱了，都能一键回到现在的样子。
