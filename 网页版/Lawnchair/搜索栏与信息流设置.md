# Lawnchair 搜索栏与信息流设置

## 一、dock 搜索栏

主屏幕底部 dock 区那根搜索条。路径：主屏幕设置 → **搜索栏**（Search bar）→ **Dock** 标签页。

| 想做的事 | 对应设置 |
| --- | --- |
| 彻底去掉搜索条 | 搜索栏小组件（Search bar widget）→ 选 **Disabled** |
| 换点击后打开的搜索服务 | 搜索供应商（Search provider）→ 从列表选；部分供应商要求先装配套应用；选 **Website** 则用浏览器打开对应搜索站 |
| 改外观 | Style 区：**Apply accent color** 让搜索条跟随主题配色；**Outline width** 调边框宽度（不为 0 时可再选边框颜色） |

## 二、应用抽屉搜索栏

抽屉里的搜索能力比 dock 栏强，能同时覆盖本机与网络。路径：主屏幕设置 → 搜索栏 → **应用抽屉**（App drawer）标签页。抽屉本身的布局与隐藏应用设置不在这层，见 [应用抽屉设置与隐藏应用.md](应用抽屉设置与隐藏应用.md)。

### 搜索算法二选一

- **应用搜索**（App search）：只搜已装应用。
- **本机全局搜索**（Global search (on-device)）：搜应用、联系人、文件、系统设置等本机内容。

### 全局搜索的结果类型

选了本机全局搜索后，下方"在搜索结果中显示"（Show in search results）可以逐类开关：

| 类型 | 说明 |
| --- | --- |
| 应用与快捷方式 | 能容忍少量拼写错误 |
| 网页建议 | 用内置供应商或自定义（按设置页里的 URL 说明填） |
| 联系人 | 搜通讯录及相关信息 |
| 文件 | 可限定照片视频 / 音频 / 全部文件；**Play 商店版因商店政策没有"全部文件"这一档**，侧载版本才有 |
| 系统设置 | 直接搜到系统设置项 |
| 搜索历史 | 点搜索框时显示最近查询 |
| 计算器 | 在搜索框里直接算数 |

### 一个容易踩的联动开关

**Match dock search bar actions**（与 dock 搜索栏保持一致）打开后：抽屉搜索栏继承 dock 栏的主题与图标，并且点 dock 栏不再打开你选的搜索供应商，而是直接进入抽屉搜索界面。发现"点 dock 栏怎么跑进抽屉了"，就是这个开关干的，关掉即可。

## 三、主屏幕左侧的 Google 信息流

前置条件按渠道不同：

- **Nightly 版**：信息流支持一般已内置，不用额外装东西。
- **其他版本**：先装官方配套的 **Lawnfeed 4**，从官方下载页 [lawnchair.app/downloads](https://lawnchair.app/downloads) 获取；Lawnfeed 不工作时，可改用第三方的 AIDL Bridge 兜底。

开启步骤：

1. 主屏幕设置 → **主屏幕**（Home screen）→ 打开 **显示信息流**（Show feed）。
2. **Feed provider** 保持为 Google（装的是 AIDL Bridge 就选它）。
3. 在主屏幕上向左滑，信息流就出来了。

开不出来按这个顺序试：把 Show feed 关一次再开 → 强制停止 Google 应用后重启 Lawnchair → 重启手机；仍不行，到 [常见问题排查.md](常见问题排查.md) 查后台限制。

## 四、搜索结果不对劲

- **结果缺失或不出**：核对搜索算法与结果类型的开关是否与你要的匹配；确认 Lawnchair 拿到了所需权限（文件类结果需要对应存储权限）。
- **网页建议不出**：查网络；查"网页建议"开关；自定义供应商核对 URL 是否有效。
- **上面都正常还异常**：主屏幕设置 → 更多（⋮）→ 重启 Lawnchair。
