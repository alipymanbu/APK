## 一、这是个什么应用

幻语AI 是一款安卓端的虚拟角色聊天应用：你挑一个 AI 角色或自己建一个，用文字、图片、语音跟它对话，官方站点 [huanyu-ai.com](https://huanyu-ai.com/) 上也提供网页端入口。它的安卓端以 APK 形式分发，**安装包从哪拿、拿的是哪一版**是用它之前最先要搞清的两件事，本篇就讲这两件事。

## 二、安装包从哪拿

| 各类第三方应用信息页 | 多为旧版 | 版本号常滞后，核对 MD5 更稳妥 |

网盘里那份包的完整事实（凡涉及版本、包名、大小一律以这张表为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.4.4 |
| 包名 | `com.chatllm.user` |
| 大小 | 97.71M |
| MD5 | `ff8ff52ac5f6643f3920461b8e8ab11e` |

下载完想确认文件没坏、没被换过，在 APK 所在目录打开命令行校验一下：

```powershell
certutil -hashfile 幻语AI_v1.4.4.apk MD5
```

输出的 32 位十六进制与上表一致即可安装。官方后续发新版时包体大小和 MD5 都会变，网盘这份仍是表里这一版，不必追求一致。

## 三、安装步骤

1. 从上表任一来源把 `.apk` 下载到手机（或先下到电脑再传过去）。
2. 用文件管理器点这个 APK，系统会弹「禁止安装未知来源应用」—— 这是安卓对非商店来源应用的默认拦截，在弹窗里进入该来源的授权开关（不同机型叫「允许安装未知应用」，位置一般在设置 → 应用 → 特殊访问权限），对你的浏览器或文件管理器打开。
3. 返回继续安装，等进度走完点「打开」。
4. 首次启动会要网络、存储等权限；语音输入功能另外需要麦克风权限。只想打字聊天的话，麦克风可以拒绝，不影响文字对话。

## 四、系统要求

官方页面没有给出明确的最低安卓版本；第三方信息页标注过「安卓 4.4 以上」（以官方当时显示为准）。安装包本身 97.71M，安装后占用会更大，装之前在设置里确认一下剩余空间，空间不足是安装失败最常见的原因之一。装完遇到闪退、卡顿，见 [常见问题排查](常见问题排查.md)。

## 五、装完打不开的三个快查

1. **安装时提示解析错误**：APK 多半没传完整，重新下载并按第二节校验 MD5。
2. **提示应用已损坏或版本冲突**：手机里已有同包名旧版本时，先在设置 → 应用里卸掉旧版再装（卸载会清掉该应用的本地数据，账号绑定过的可在装回后重新登录）。
3. **打开就闪退**：先确认不是设备资源问题，排查步骤见 [常见问题排查](常见问题排查.md)；注册登录环节卡住则看 [注册与登录方法](注册与登录方法.md)。
