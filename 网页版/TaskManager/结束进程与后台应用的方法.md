## 一、动手前先分清两类操作

TaskManager 的「结束」动作分两个层级，权限门槛不一样，失败了先对照这里：

| 操作 | 需要什么 |
| --- | --- |
| 结束安卓应用（Kill android apps） | Shizuku 运行 + 已授权即可 |
| 结束 Linux 进程、调整进程优先级 | **Shizuku 必须由 root 方式启动** |

也就是说：Shizuku 用无线调试或 adb 启动时，你结束普通应用没问题，但去动底层 Linux 进程或改优先级会失败——这是官方说明里写死的限制，不是你操作错了。没有 root 的手机，后一类功能就当它不存在。

## 二、结束一个后台应用的步骤

1. 打开 TaskManager，确认 Shizuku 在运行（否则结束动作会无响应或直接失败）。
2. 在进程列表里找到目标：先用 [CPU与内存占用怎么查看.md](CPU与内存占用怎么查看.md) 的方法确认它确实占资源，避免误杀。
3. 点开它，选结束 / Force stop，确认弹窗。
4. 回到列表看它是否消失；几秒后又出现，说明系统把它重新拉起来了（常见于推送类、同步类应用）。

杀后台的目的是把内存和 CPU 让给前台应用——如果你只是想省电，杀掉推送应用反而会让它更频繁地重新启动来补消息，效果可能与预期相反，这一点动手前想清楚。

## 三、这些进程不要碰

- **进程列表里的系统服务与厂商常驻组件**：结束掉轻则某个系统功能失灵（NFC、指纹、通知），重则手机直接重启。
- **不认识来源、名字像 `com.android.*`、`com.qualcomm.*` 的进程**：认不出的一律只看不杀。
- **正在运行的输入法、桌面、电话相关进程**：杀掉当场就能感受到异常。

原则很简单：**只结束你能说出包名归属的应用**，其余当观察用。

## 四、改优先级说明（需要 root）

官方功能清单里有「调整进程优先级」，但和杀 Linux 进程一样要求 Shizuku 由 root 启动。优先级影响的是系统资源紧张时谁先被压制，普通用户改它的收益很小，改错了还会让前台应用变卡，不建议在没有明确目标的情况下动它。

## 五、杀不掉怎么办

点了没反应、闪一下又回来、或者提示失败，按这个顺序查：Shizuku 是否在运行 → TaskManager 是否已授权 → 这个操作是不是需要 root → 目标是不是系统进程（系统进程本来就杀不掉）。对应处理都在 [常见问题与故障排查.md](常见问题与故障排查.md)。
