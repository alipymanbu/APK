## 一、这是个什么软件

TaskManager 是一款安卓端的开源任务管理器，界面与思路参考了 Linux 桌面的 GNOME 系统监视器：你打开它就能看 CPU 占用、内存占用、正在跑的进程，还能把某个应用或进程结束掉。它由开发者 Rohit Kushwaha 维护，源码与安装包都在 GitHub 上公开（`RohitKushvaha01/TaskManager`），采用 Apache-2.0 许可，也上架了 Google Play（包名 `com.rk.taskmanager`）。

要注意它的一条硬前提：**TaskManager 必须搭配 Shizuku 或 root 才能工作**。没配 Shizuku 时你打开它，监控与结束进程这类功能是用不了的——这不是 bug，是它的权限模型决定的。所以本篇装完 App 后，接着要做的是 [Shizuku配置与授权教程.md](Shizuku配置与授权教程.md) 里的步骤。

## 三、安装步骤

1. 从上面任一渠道拿到 APK 文件，点开安装。若系统弹出「禁止安装未知来源应用」，按提示进入设置、允许本次安装来源（不同品牌路径略有差异，一般在「设置 → 应用 → 特殊权限」里）。
2. 装完打开，第一次进入会让你选工作方式，**选 Shizuku**（前提是 Shizuku 已经装好并启动）。
3. Shizuku 那边会弹一个授权请求，点「始终允许」，TaskManager 才能拿到读取进程、结束应用的权限。

如果第 2 步你还没装 Shizuku，先别急着用——按 [Shizuku配置与授权教程.md](Shizuku配置与授权教程.md) 把 Shizuku 装好、启动、授权，再回到 TaskManager。

## 四、系统要求与搭配软件

- **系统版本**：本地采集记录标注为「安卓 5.2 以上」；实际上 Shizuku 的无线调试启动方式要求 Android 11 及以上，低于这个版本要走电脑 adb 启动（见 Shizuku 那篇）。
- **必备搭配**：Shizuku（开源，Rikka 开发，Google Play 与 GitHub 均可下载）；已 root 的设备可以直接用 root 方式启动 Shizuku。
- **存储占用**：安装包 26.67M，装上后会再占一点数据空间，属正常。

装好之后打不开、闪退、或者功能是灰的，按 [常见问题与故障排查.md](常见问题与故障排查.md) 逐条排查即可。
