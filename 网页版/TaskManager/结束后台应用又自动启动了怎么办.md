# 结束后台应用又自动启动了怎么办

## 一、杀完又回来，是没杀干净吗

不是。你在 [结束进程与后台应用的方法.md](结束进程与后台应用的方法.md) 里做的 Force stop 只作用于**当下这一刻**：进程确实死了，但只要系统需要它干活——推送到了、定时任务到期了、别的应用绑定了它的服务——它就会被重新拉起来。安卓默认并不禁止应用在后台活动，所以「杀一遍就永久清静」本来就不是系统承诺的行为。

想让它**别再回来**，靠的不是反复杀，而是切到系统的后台限制开关。下面两层，一层是原生安卓的，一层是各品牌自己加的。

## 二、原生安卓的「受限应用」开关

路径（不同安卓版本措辞略有差异，以你手机上的为准）：

**设置 → 应用 → 查看全部应用 → 选中目标应用 → 电池用量 → 受限**

按 AOSP 官方文档的口径，被设为「受限」的应用：

- 仍然可以由你手动打开，打开后功能正常；
- 无法在后台运行作业/闹钟，也无法在后台使用网络；
- 无法运行前台服务；
- 随时可以由你改回「不受限制」。

也就是说，受限管的是「你不碰它时它别自己动」，而不是把它卸载或封死。这条对电量与后台占用都有效果，代价见下一节。

## 三、各品牌还额外有一层

国产 ROM 普遍在原生之外又加了自己的后台管理，两层要都设才稳（叫法各家不同，以实际系统为准）：

| 品牌 | 常见入口/叫法 |
| --- | --- |
| 小米 / 红米 / POCO | 「自启动管理」，控制重启后能否自动拉起 |
| 三星 | 电池设置里的「休眠应用」，对长期不用的应用限制更狠 |
| OPPO / 一加 / Realme | 电池优化里的逐应用后台控制 |
| vivo / iQOO | 「后台高耗电」名单，找出并关掉后台凶的应用 |
| 原生安卓及其他 | 只有上面第二节的「受限」档 |

有用户反馈部分品牌在系统更新后会**重置**这些规则，所以改完隔段时间回头核对一眼。

## 四、哪些应用不该设成受限

限制是拿通知换安静的，设错了比不设更难受。**不该受限**的：

- 即时通讯、需要实时收消息的聊天应用；
- 邮件这类需要及时提醒的；
- 闹钟、时钟类；
- 任何「通知晚到会耽误事」的应用。

**适合受限**的：不常玩的游戏、偶尔打开的购物与资讯类、装了就忘的工具。判断标准就一条——**你等不等它的推送**。

## 五、怎么验证真的生效了

设完正常使用，隔一天看：**设置 → 电池 → 电池用量**，找到那个应用看后台耗电。生效的表现是后台占用接近零、没有持续的系统唤醒；如果数值照旧，回第二节、第三节把两层开关都再核一遍（多半是品牌那层没设，或被更新重置了）。

这套开关管的是「别自己动」，而 TaskManager 管的是「已经在跑的立刻停掉」——两者配合用：先用 TaskManager 结束当下的进程，再用系统开关断掉它自己回来的路。
