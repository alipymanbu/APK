# TaskManager 常见问题与故障排查

> 打不开、没数据、配对卡住、重启后失效——按症状查，多数问题根子都在 Shizuku。
> **相关文档**：[Shizuku配置与授权教程.md](Shizuku配置与授权教程.md) · [下载与安装教程.md](下载与安装教程.md) · [结束进程与后台应用的方法.md](结束进程与后台应用的方法.md)

## 一、打开就提示需要 Shizuku / 功能是空的

TaskManager 没有 Shizuku 就不能工作，这不是故障。按顺序确认：

1. Shizuku 装了没；没装先走 [Shizuku配置与授权教程.md](Shizuku配置与授权教程.md)。
2. Shizuku 主界面是否显示「正在运行」——不运行就先启动它（无线调试方式每次重启后都要启动一次）。
3. TaskManager 是否在 Shizuku 的授权列表里、是否选了「始终允许」。授权列表数量显示不对时，把 Shizuku 杀掉重进一次再看。

三步都对了还不行，把 TaskManager 也杀掉重开一次，让它重新连 Shizuku。

## 二、无线调试配对一直卡在「正在搜索配对服务」

- 确认系统的「无线调试」开关是**打开**状态，且和 Shizuku 的配对流程同时进行——先在系统里点「使用配对码配对设备」，再回 Shizuku 填码。
- 部分机型要求通知样式为「原生样式」才能在通知栏输入配对码（小米/红米上较常见），到系统通知设置里改一下。
- 还不行就把无线调试关掉重开，重新走一遍配对。

## 三、点「输入配对码」后立刻提示失败

配对码是有时效的，超时或输错都会失败。重新点「使用配对码配对设备」拿一组新码，立刻填入；注意 6 位数字别带空格。

## 四、提示 adb 权限受限

无线调试 / 电脑启动方式下，Shizuku 只拥有 adb（shell）级别的权限，部分高敏感能力会被系统限制。表现通常是「大部分功能正常，个别操作失败」。要突破这条线只有两条路：换 root 设备用 root 方式启动，或者接受这些操作不可用（参考 [结束进程与后台应用的方法.md](结束进程与后台应用的方法.md) 的权限对照表）。

## 五、重启手机后 TaskManager 又不工作了

非 root 启动的 Shizuku 不跨重启，这是系统限制不是 bug。每次重启后的固定动作：开无线调试 → 打开 Shizuku 点启动 → 再开 TaskManager。配对记录会保留，不用重做。

## 六、Shizuku 随机停止 / 老是掉线

- 检查电池优化：把 Shizuku 加进「不优化 / 允许后台运行」名单，被系统杀后台就会随机停止。
- 无线调试方式本身不如 root 稳，掉线后重新启动一次即可。
- 用电脑 adb 方式的，确认 adb 服务没被电脑睡眠中断。

## 七、结束进程没反应或杀不掉

对照 [结束进程与后台应用的方法.md](结束进程与后台应用的方法.md) 的权限表：结束普通应用要 Shizuku 在线且已授权；结束 Linux 进程、改优先级则要求 Shizuku **由 root 启动**，非 root 环境下这两项失败是预期行为。系统进程本来就无法被第三方结束，属于正常限制。

## 八、装不上 / 安装包校验不通过

- 安装时提示解析错误：多半是下载的 APK 不完整，重新下一份（网盘那份的 MD5 见 [下载与安装教程.md](下载与安装教程.md)，算完一致再装）。
- 提示禁止安装未知来源：按系统弹窗进入设置、允许本次来源。
- 提示与已安装版本签名冲突：先卸载旧版再装（注意卸载会清除该应用在本机的数据，装完重新授权 Shizuku 即可）。
