## 一、先认准钱走的哪条路

退款找错对象是最常见的空转。翻你的支付记录，看收款方与订单在哪，对应下表：

| 你是在哪付的 | 收款/订单方 | 第一步找谁 |
| --- | --- | --- |
| iPhone 内购 | 苹果（订单在 Apple ID 下） | Apple 的「报告问题」入口：[reportaproblem.apple.com](https://reportaproblem.apple.com)，用付款的 Apple ID 登录选中订单提交 |
| 应用宝 / 小米 / OPPO / vivo / 360 等商店 | 对应商店 | 商店 App 里的**订单详情页**，一般有「退款 / 投诉 / 对该订单有疑问」入口；商店客服比应用内客服响应通常更快 |
| 微信支付 | 商家（微信支付订单） | 微信 → 我 → 服务 → 钱包 → 账单 → 找到该笔 → 「对账单有疑问」，或小程序「12315」投诉 |
| 支付宝 | 商家（支付宝订单） | 支付宝 → 我 → 账单 → 该笔交易 → 「投诉」 |

**先走订单所在渠道，再找应用内客服**——渠道手里有收款与交易记录，是能直接原路退回的一方；应用内客服只能替你「申请」，不掌握退款通道。

## 二、证据清单（争论开始前先截完）

以下六样在**你去找客服之前**一次性截好存到相册外的地方（网盘/电脑都行）：

1. **搜索结果页**——如果是搜「DeepSeek」之类点进来的，这张事后补不了（见 [和DeepSeek是同一个吗.md](和DeepSeek是同一个吗.md) 第五节）；
2. **购买页**——价格、周期、「自动续费」字样；
3. **支付记录**——金额、时间、收款商户全称（对不上「广州加预算网络科技有限公司」的要标出来）；
4. **扣费提醒有没有收到**——没收到显著提醒，是你主张退款的核心依据（法规要求自动续费前五日显著提醒，见 [会员价格与自动续费取消.md](会员价格与自动续费取消.md) 第五节）；
5. **与客服的全部聊天记录**——含发送时间；
6. **使用消耗记录**——会员权益用了多少（有投诉方主张「绝大部分未使用」，用量截图直接影响按比例退款的折算）。

## 三、应用内怎么提

iOS 版简介写明的客服路径：打开 App →【我的】→【在线客服】→【专属客服】，把诉求一次说全：**买了什么、什么时候、要求全额退款、依据是什么**（未获显著提醒 / 因商店搜索排序误购，两条挑符合的写）。

公开渠道的现实情况要心里有数：黑猫投诉平台上针对本应用开发者的多条投诉里，有「商家未匹配成功」的系统提示（即投诉未能推送到位），应用宝评论区也有「客服不回应」的反馈。**所以别只在应用内等**——提完申请，同时或限期后走下面的升级路径。

## 四、协商不成的升级路径

按成本从低到高：

1. **黑猫投诉**（[tousu.sina.cn](https://tousu.sina.cn)）：填清金额、时间、商户全称，附上第二节的截图。平台上该商户已有大量同类投诉记录，你不是第一个，措辞可参考同类工单；
2. **12345 热线 / 全国消协智慧 315 平台**：自动续费未显著提醒类的纠纷，这两处是通用受理口；
3. **12315 小程序**：填写经营者全称「广州加预算网络科技有限公司」，走市场监管条线；
4. **支付渠道申诉**：微信/支付宝的交易投诉入口与上述并行提，渠道侧的处理往往更快。

每条路径都用**同一套证据包**，不要每次重拍、说法不一——受理方看到的材料一致，推进效率才高。

## 五、谈阶段方案时注意什么

有投诉方公开称，协商后商家提出过**按比例退款**（如扣除已消耗部分退七成）或**转为续期/其他权益**的方案。这类方案不存在统一标准，接受与否取决于你，但签字（或点确认）前问清三件事：

- 折算规则是什么（按次数？按金币？剩余多少）；
- 退款几个工作日到账、退到哪个账户；
- 接受后是否视为争议终结（以后还能不能再主张）。

拿不准就先不点确认，把方案截图，走第四节的路径再问一遍。
