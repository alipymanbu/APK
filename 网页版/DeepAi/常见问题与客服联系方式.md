## 一、客服联系方式

按响应速度排序，逐条试：

1. **应用内在线客服**：App Store 版简介写明的路径是「打开 App →【我的】→【在线客服】→【专属客服】」描述问题。安卓版入口以界面实际显示为准，找不到就往下走。
2. **公司总机**：`020-89855383`——来自工商信息公示平台的联系方式（2026-07-08 变更后号码），**可能随公司变更失效，以公示平台当时信息为准**。
3. **官网**：[www.cyheng.cn](http://www.cyheng.cn)（广州加预算网络科技有限公司站点，站内有各产品入口）。

⚠️ 黑猫投诉平台上确有用户反馈「App 内找不到在线客服、电话打不通」——**与上面的官方路径并列存在**，两条说法都没被推翻。应用内找不到时别死磕，直接走第 2、3 条 + 支付渠道。

## 二、点了生成没反应 / 一直转圈

按命中率排查：

| 现象 | 先查什么 |
| --- | --- |
| 全部功能都失败 | 网络是否正常；换个 Wi-Fi / 流量试一次 |
| 只有视频、音乐失败 | 这类生成耗时长，退出重进会丢任务——先等满一次，再去作品区看是否其实已生成 |
| 提示次数用完 / 需要付费 | 不是故障，是计费触发，见 [会员价格与自动续费取消.md](会员价格与自动续费取消.md) 第一、二节 |
| 刚装完就各种失败 | 是否拒绝了存储 / 相机权限（见下节）；或安装包与系统不兼容，见 [下载与安装教程.md](下载与安装教程.md) 第四节核对版本 |

**反复失败时的止损动作**：截图（含报错文字与时间）→ 记下作品编号/任务名 → 直接找客服。生成类服务按次扣费，失败也要留证据才好主张返还。

## 三、权限用途对照

应用隐私政策（2024-07-15 版）列的敏感权限及它自己写明的用途：

| 权限 | 用途（照政策口径） | 不给会怎样 |
| --- | --- | --- |
| 录音 / 麦克风 | 语音输入、录制用于 AI 创作的视频 | 语音输入和视频配音不可用 |
| 相机 | 拍摄要创作的图片 | 拍照类创作不可用 |
| 存储写入 | 保存图片、下载文件到相册 | 生成结果存不下来 |
| 剪贴板 | 复制邮箱地址、复制内容、粘贴问题 | 粘贴功能受限 |
| 读取安装列表 | 支付时判断是否装有微信/支付宝；商店评分跳转 | 部分支付/跳转路径异常 |
| 电话（设备标识） | 取 IMEI/设备 ID，用于唯一性识别与风控 | 可能影响登录与反作弊校验 |
| 人脸数据（非权限，属信息收集） | 实现图片写真与视频写真 | 不上传照片则写真功能不可用 |

用不到的功能**可以拒绝**，用到时系统会再要。涉及人脸的写真用完记得去作品区删除——政策写明用户可随时查看、管理或删除包含面部数据的照片，**这一步要你自己动手**。

## 四、找不到历史作品

生成结果落在「个人 / 作品区」，不是系统相册：

1. 进个人区按时间翻；
2. 换过账号登录的，作品跟账号走，确认当前登录的是生成时那个账号；
3. 已经下载过的，去手机相册 / 文件管理器的下载目录找；
4. 都没有且任务是失败中断的，作品可能从未生成成功，按第二节流程处理。

## 六、要不要卸载重装

先别急着卸：覆盖安装不会丢账号数据（见 [下载与安装教程.md](下载与安装教程.md) 第三节），但**卸载会清掉本地记录**。真要卸载，先确认三件事——会员有效期还剩多久（截图）、作品是否都已下载、登录账号与手机号记牢，否则装回来还要从头申诉找回。
