## 一、先确认你要装的是哪一份

柠檬TV 是安卓端的影视加电视直播应用：手机能装，电视盒子、智能电视也能装 —— 这类设备大多是安卓系统，装法相同。它不是 iOS 应用，iPhone 上装不了。本篇讲的就是安卓 APK 这一份，从拿包到装完核对走完全程。

网盘里这份包的参数（记录日期 2026-09-23），装之前先对一遍：

| 项目 | 数值 |
| --- | --- |
| 版本号 | 2.9 |
| 包名 | `com.ningmeng.tv` |
| 安装包大小 | 8.51M |
| MD5 | `3cd287152c7b660a009235ae07236f2f` |
| 系统要求 | Android 4.0 及以上（公开渠道页标注，以实际能否装上为准） |

网上各渠道页对这个包的写法不统一：有的标版本 1.0、大小 7.7M，有的标 2.9、8.5M，名称也常见「柠檬TV」「柠檬网络电视」混用。你手里要对的始终是**网盘里这一份**。包名 `com.ningmeng.tv` 是安卓系统识别应用的唯一标识，比显示名可靠 —— 核对时认包名，别只看图标和名字。

## 二、从网盘拿到安装包

1. 打开 [柠檬TV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f8d88cf4efe5)，把分享内容转存到自己的网盘（转存后不怕分享失效；不转存也能直接下载）。
2. 网盘里的应用文件夹名是 `柠檬tv（先保存再下载）`，APK 文件名形如 `柠檬tv_v2.9.apk`，旁边还有一份说明 txt。
3. 装电视走 U 盘的话，在电脑上下载这个 APK 再拷进 U 盘最顺手；只装手机就用夸克 App 登录同一账号直接下。
4. 下载完看大小是否接近 8.51M，明显偏小说明没下完整，重下一次。要校验完整性，把 APK 传到电脑算一遍 MD5，结果应当是 `3cd287152c7b660a009235ae07236f2f`；对不上就别装。

转存完找不到文件、提示空间不足，或者下载速度让人着急的，一般是网盘端的问题：换个网络重试、或先在电脑端下载再传，都能绕过去。

## 三、用 U 盘装到电视或盒子

电视没有自带应用商店入口时，U 盘是最省事的一条路：

1. 把 `柠檬tv_v2.9.apk` 复制到 U 盘根目录（带读卡器的 SD 卡也一样），安全弹出。
2. 把 U 盘插到电视侧面或背面的 USB 接口。
3. 用电视自带的文件管理器打开 U 盘，点这个 APK。
4. 系统会弹「禁止安装来自此来源的应用」—— 这是标准安全拦截，不代表文件有问题。按提示进入设置，允许安装来自此来源（有的机型叫「未知来源」），返回继续装。
5. 装完在应用列表里找到图标打开；第一次打开建议在 Wi-Fi 下进，首页列表要联网加载。

部分品牌电视有纯净模式之类的额外拦截（华为机型在 设置 → 系统和更新 → 纯净模式），装不上先把它关掉，装完再按自己习惯决定要不要开回来。盒子端如果装了当贝市场这类工具，也可以用它的「本地安装 / U 盘安装」打开 APK，效果一样。这一步卡住的（报「禁止安装」「解析包」「安装失败」等）按文案分型处理，见 [电视安装失败怎么排查.md](电视安装失败怎么排查.md)。

## 四、手机上安装步骤

1. 用文件管理器点开 APK，按提示给文件管理器授「安装来自此来源」的权限，装完可以再关掉。
2. 返回继续安装，等进度走完点「打开」。
3. 首次启动同意用户协议与隐私政策后进首页。

装不上、报「解析包出问题」，多半是包没下完整，回到第二节重下；闪退、卡顿的处理按类型分好了，见 [卡顿闪退与安装失败怎么办.md](卡顿闪退与安装失败怎么办.md)。

## 五、装完核对：确认没装错

到 **设置 → 应用 → 找到 柠檬TV → 应用信息**，看三项：

- 版本号应显示 `2.9`；
- 包名应为 `com.ningmeng.tv` —— 部分机型在这一屏或「更多」里直接显示包名，不显示的机型就跳过这条，改用版本号 + MD5 判定；
- 来源是你自己网盘里下的文件，而不是来路不明的应用商店。

三项都对，装的就是网盘这一份。装好之后怎么找频道、怎么搜片，接 [频道与影视内容怎么找.md](频道与影视内容怎么找.md)；手机上想投到电视，看 [投屏到电视怎么用.md](投屏到电视怎么用.md)。

## 六、以后有新版怎么更新

柠檬TV 是侧载装的应用，**没有应用商店那套自动提示更新**，升级就三步：

1. 回到网盘分享拿最新一份 APK（链接不变，还是同一个；网盘里文件名带的版本号就是当前这份的版本）。
2. 直接点新 APK 覆盖安装 —— 同一个包名（`com.ningmeng.tv`）覆盖装不用先卸载，播放记录会保留；先卸载再装则会把本机记录清掉。
3. 装完到 设置 → 应用 → 柠檬TV → 应用信息 看版本号，变了就是升上去了。

判断「有没有新版」没有固定周期：网盘这份的记录日期是 2026-09-23、版本 2.9，之后是否有新版本以网盘里当时显示的文件为准。设备端如果提示存储不足装不上，处理见 [电视安装失败怎么排查.md](电视安装失败怎么排查.md) 第四节。
