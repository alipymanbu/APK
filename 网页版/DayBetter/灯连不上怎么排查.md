# DayBetter 灯连不上怎么排查

> 本篇把 DayBetter 加灯与用灯过程中会碰到的失败分成五类，给出官方手册里的对应动作，并说明每一次重试之前该先做什么。

连不上灯的原因就那几类，但每类的修法完全不同，乱试一通只会把状态越搞越乱。本篇按「搜不到设备 / 配不上网 / 语音里看不到 / 用几天就掉线 / 灯本身不亮」这五种现象分开，每种给官方手册里对应的动作，以及重试之前该先清掉哪些中间状态。

## 一、先判断卡在哪一步

| 现象 | 卡在哪一层 | 直接去 |
| --- | --- | --- |
| App 里搜不到任何设备 | 蓝牙发现 | 第二节 |
| 搜到了，但一直连不上 WiFi | WiFi 配网 | 第三节 |
| App 里能控制，Alexa / Google 里看不到 | 第三方平台联动 | 第四节 |
| 一开始能用，过几天变成离线 | 断连恢复 | 第五节 |
| 灯本身不亮、只亮一部分 | 供电或硬件 | 第六节 |

## 二、App 搜不到设备

官方手册在这一项下列了六条动作，按顺序试，前一条不解决问题再进下一条：

1. 确认手机蓝牙是**开着**的（不是只开了 WiFi）；
2. 给 App 放行权限——官方手册的原话是「App 需要这些权限才能连接设备」，安卓侧少了定位 / 附近设备权限，蓝牙扫描拿不到结果；
3. 确认灯是亮的：用遥控器按一下 `ON` 或调亮，能亮说明灯没问题，问题在手机上；
4. 杀掉 App，关蓝牙再打开蓝牙，然后重新进 App 加设备；
5. 把手机移到灯旁边——官方两本手册分别写作 1 米和 4 英尺以内，中间不要有遮挡；
6. 换一台手机试。手册把「手机与 App 不兼容」也列为一种可能，这一条对老机型确实成立。

第 2 条里权限和扫描的关系，见 [权限和隐私说明.md](权限和隐私说明.md)。

## 三、连不上 WiFi

官方手册在这一项下给了四条：

1. **确认 WiFi 支持 2.4GHz**，5GHz 不行；
2. **重置设备后重试**——重置手法见 [蓝牙和WiFi怎么把灯连上.md](蓝牙和WiFi怎么把灯连上.md) 第五节，重置完要重新让它进入闪烁的配对状态；
3. **把设备搬到路由器附近**再配一次，信号弱是配网失败的常见原因；
4. 重新执行一遍「添加设备 → 连 WiFi」。

配上一条手册之外的实操经验：如果家里的热点是 2.4GHz 与 5GHz 双频合一的，通常可以直接用；反复失败就把两路拆成不同的 SSID 分别设置，让设备连 2.4GHz 那一路。密码输错的表现是一直停在「正在连接」，换一个确认无误的密码再试比反复重试更快。

## 四、Alexa / Google Home 里看不到灯

官方给的两步修复：

1. **把设备从 DayBetter App 里移除，再重新添加**；
2. **解除 Alexa 绑定，再重新 Link**。

动手前先确认设备在 DayBetter App 里是在线状态；App 里就不在线，先按第三节把网络问题解决掉，否则重新绑定这一轮还会失败。绑定方式与前提条件见 [定时分组和语音控制怎么用.md](定时分组和语音控制怎么用.md) 第三节。

## 五、加上了但过几天变成离线

这是和「一开始就加不上」不一样的一类问题，官方手册单独写成一条「灯失去连接」，给的动作是：

1. 确认设备是通电的（墙插、适配器、控制器上的开关都要看一遍）；
2. 确认手机与设备的距离——官方给的上限是 **10 英尺以内**（配网阶段要求更近，是 1 米 / 4 英尺；连上之后放宽到 10 英尺，两个数字对应的是不同阶段）。平时站在另一个房间用手机控制的，先走近了再看设备是不是真的掉了；
3. **在「My Device」页面把这个灯删掉，再重新连一次**。

第 3 步是最管用的一条，也是容易被忽略的一条：灯还在列表里但状态是离线时，直接重新配网往往配不上，因为旧的那条记录还占着。先删再加，等于把这一盏灯的状态清干净重来。

## 六、灯本身不亮或只亮一部分

这一栏已经不是 App 的事，官方手册列的动作是：

1. 确认电源是通的（插座、适配器接口、电源开关）；
2. 用遥控器按 `ON`，并连续按几次「亮度加」——有些情况下灯只是被调到了最低亮度；
3. 用 App 开灯并把亮度调上去；
4. 把所有部件重新插接一遍（控制器与灯带、控制器与电源）。

**灯珠一部分不亮**属于硬件问题，官方手册的处理方式是联系销售方支持，App 侧的排查解决不了。

## 七、每次重试前先做这两件事

乱按会留下中间状态，重试之前固定做这两步能省很多次无用功：

1. **确认灯处于配对状态**——灯在闪才叫在等配对；不闪就先按重置手法重置一次；
2. **确认手机这一侧干净**——蓝牙开着、WiFi 在 2.4GHz、App 已经登录、App 进程是刚重启的。

两件都确认过了还是失败，把现象和已经试过的动作记下来联系官方支持（官方手册给的邮箱是 `service@daybetter.com`，产品包装上也有联系入口）。
