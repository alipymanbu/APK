DayBetter 是控制自家氛围照明产品的手机端应用：手机先用蓝牙把灯找出来，再把灯接进家里的 2.4GHz WiFi，之后开关灯、改颜色、调亮度、放音乐律动、设定时都在这一个 App 里完成。它只配 DayBetter 自家的灯泡、灯带、落地灯、灯条这类硬件，手上没有对应设备的话，装完打开是空的。本篇只解决「把包装进手机、第一次打开」这一段。

## 一、网盘里这份包是哪一版

网上搜到的一般是应用商店当前挂着的那一版，而网盘里这份是整理文档时核对过的一版，两者未必是同一个版本号。凡涉及版本号、包名、体积，本文一律以这张表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | DayBetter |
| 版本号 | 1.5.5 |
| 包名 | `com.th.daybetter` |
| 安装包体积 | 63.44 MB |
| MD5 | `CDBBD8D931ADA703215ED96A07DE006B` |
| 适用平台 | Android |

**两端版本号不同步**：安卓端走的是 1.5.x 这一套编号，iOS 端是另一套（App Store 页面上标的是 2.5.x）。数字谁大谁小说明不了新旧，不要拿 iPhone 上的版本号去比安卓的。

**关于系统要求**：这份包的页面标注是「需要安卓 5.2 以上」——安卓正式版本序列里没有 5.2 这一档，按 5.0 / 5.1 这两代理解即可；官方手册没有单独写安卓最低版本，所以「我这台手机能不能装」最终以安装时系统放不放行为准。苹果那侧，App Store 页面标注要求 iOS 15.6 及以上，体积两百多 MB（现为 245.2 MB），装了 M 系芯片的 Mac 上也能运行（要求 macOS 12.5 以上）。以上页面信息会随版本更新变化，以你打开时看到的为准。

## 二、Android 手机安装步骤

1. **转存并下载**：从 [DayBetter 安装文件资源（夸克网盘）](https://pan.quark.cn/s/40d331aec531) 把安装包转存到自己的网盘，再下载到手机；也可以在电脑上下好，用数据线或互传工具拷进手机存储。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，把用来打开安装包的那个 App（文件管理器或浏览器）的开关打开。国产定制系统常把这一项收在「安全」或「隐私」分类下面。
3. **点安装包完成安装**：过程中提示「未经安全检测」「建议前往应用市场下载」属于第三方渠道安装包的常规提示，选择继续安装即可。
4. **覆盖安装先看版本**：手机上已经装过 DayBetter 时，安卓不允许用更低的版本号覆盖更高的版本，会直接报「应用未安装」。这时先卸载旧版再装——卸载会一并清掉本机保存的登录态，重新登录即可；灯本身是绑在账号下的，登录回来后设备列表还在。
5. **装完先别急着开**：先把权限过一遍（见 [权限和隐私说明.md](权限和隐私说明.md)），否则第一次加设备时容易出现「搜不到灯」的情况。

## 三、iPhone / iPad 上怎么装

苹果端在 App Store 里就叫 **DayBetter**，开发者一栏写的是 SHENZHEN DAYBETTER OPTO-ELECTRONICS CO., LTD.，分类是「工具」，支持简体中文在内的 26 种语言，直接在商店里搜名字即可。

两点区别先记住：

- 网盘里这份是安卓的 APK，装不到 iPhone 上；苹果设备走 App Store，安装包不从网盘取。
- 两端版本号不同步（安卓 1.5.x / iOS 2.5.x），界面细节也略有差异；按钮叫法对不上时，以你手上那端的界面为准。

## 四、第一次打开会经过哪几步

官方手册里的顺序是固定的：装好 App → 注册账号 → 打开手机蓝牙和 WiFi → 搜设备 → 把设备接进 WiFi。

| 步骤 | 你会看到什么 | 注意点 |
| --- | --- | --- |
| 注册 / 登录 | 新用户先注册账号；之后可以用密码登录，也可以用邮箱验证码登录 | 没有账号只能看空界面，加设备前必须登录 |
| 开蓝牙与 WiFi | 手机蓝牙、WiFi 两个开关都要打开 | 配网阶段手机要连在 **2.4GHz** 的热点上，5GHz 不行 |
| 搜设备 | 点右上角 `+`，走「搜索附近设备」（Go to search）这一栏 | 搜到的是待配网的灯，不是路由器 |
| 把设备接上 WiFi | 点 `Add` 加进列表，随后在设备信息页填 WiFi 账号密码 | 填的是 **2.4GHz** 那一路的密码 |
| 完成 | 提示连接完成，点 `OK` | 之后手机可以换回别的网络，远程控制照常 |

加灯的具体动作、灯怎么进配对模式、配网失败怎么处理，都写在 [蓝牙和WiFi怎么把灯连上.md](蓝牙和WiFi怎么把灯连上.md)。

## 五、装完做一次最小验证

1. 打开 App 能进主界面，没有卡在权限弹窗上；
2. 用邮箱验证码或密码能登录成功，说明 App 到服务端这一路是通的；
3. 点 `+` 能看到「搜索附近设备」这类入口，说明蓝牙扫描相关的权限已经给到。

第 3 步点了没反应、或者设备列表始终是空的，先别急着卸载重装，直接看 [灯连不上怎么排查.md](灯连不上怎么排查.md)。如果连自己要装的灯属于哪一类都还没确定，先看 [支持的灯具型号与配对App.md](支持的灯具型号与配对App.md)。
