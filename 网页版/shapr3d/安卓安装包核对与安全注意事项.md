# 安卓安装包核对与安全注意事项

> 本篇讲装一个安卓 APK 之前该做的核对：版本与体积、包名、MD5 哈希怎么比，安装权限怎么收窄，装完先看什么。方法对任何侧载 APK 通用，示例取这套文档对应的安装文件。

## 一、为什么装之前要核对

从应用商店装应用，校验、签名核对这些事商店替你做了；从安装包直接装（侧载），这些事就得自己做。核对的目的很具体：**确认装进手机的就是发布者放出来的那个文件，中间没有被改动过**。方法是多来源的安卓安全常识，与具体应用无关；对这份 Shapr3D 安装文件尤其值得做一遍，因为它没有官方安卓渠道可以交叉验证版本。

## 二、装前三步核对

先把 **shapr3d 安装文件资源（夸克网盘）** 转存并下载到手：[https://pan.quark.cn/s/3fb4226d4614](https://pan.quark.cn/s/3fb4226d4614)，然后按顺序核对：

**第 1 步：对版本与体积。** 本文档记录的安装文件是版本 8.3.23、约 8.28 MB。文件体积与记录差出一个量级（比如只有几百 KB 或多出几十 MB）就不要装，文件大概率不完整或被改过。

**第 2 步：对包名。** 在电脑上用 APK 信息查看工具（或在手机安装器弹出的应用信息里）读包名，应与记录一致：`com.hgfghdfgdfg.ghfghfhgffg`。仿冒应用常在包名上做一两个字符的改动，包名对不上就不是同一份文件。

**第 3 步：对 MD5。** 这是唯一能逐字节确认文件没被改动的强校验：

| 环境 | 命令 / 做法 |
| --- | --- |
| Windows PowerShell | `Get-FileHash 文件名.apk -Algorithm MD5` |
| Windows 命令提示符 | `certutil -hashfile 文件名.apk MD5` |
| 手机端 | 部分文件管理器自带「文件校验 / 哈希」功能；没有就传到电脑上算 |

算出的值应等于 `6A69C24D67455958556FA5BEAD65260C`（字母大小写不影响比对）。**对不上就删掉重下**——一个字节之差都会让哈希完全不同，哈希不符不存在无辜的解释。

## 三、安装权限要给得窄、收得快

安卓 8.0 起没有全局的「未知来源」开关了，安装权限按应用授予：允许「哪来打开安装包的那个应用」（浏览器或文件管理器）安装，而不是放行整个系统。路径一般是「设置 → 应用 → 特殊应用权限 → 安装未知应用」，各品牌入口措辞不同，在设置里搜「未知」都能找到。

两个要点：

1. 只给你实际用来打开 APK 的那一个应用授权；有页面让你先装某个「下载器」「助手」再授权它安装——这种模式是给你手机留一个常驻安装器，直接放弃。
2. **装完就把授权关回去**，十几秒的事，避免日后浏览器或文件管理器被利用来静默装包。

## 四、装完先看两样东西

**权限列表**：安装弹窗上把权限扫一遍再点安装。出现下面这些、又说不出合理理由的，直接放弃：

| 权限 | 为什么可疑 |
| --- | --- |
| 无障碍服务 | 能读屏、能代替你点击，是安卓上被滥用最多的一项 |
| 设备管理权限 | 让应用难以卸载，正常应用几乎用不到 |
| 短信 / 通讯录 / 通话记录 | 建模类应用没有索取这些的理由 |

**Play Protect 扫描**：装完打开 Play 商店 → 头像 → Play Protect → 扫描。它不只查商店应用，也检查侧载装进来的应用；有告警就先别打开，回头重走第二节的核对。

另外一个稳妥习惯：担心账号安全的话，首次使用先不登录常用账号，摸清应用行为再说。

## 五、两个时效性的点

- **Google 开发者验证在推进**：自 2026 年 9 月底起在巴西、印尼、新加坡、泰国等先行，2027 年扩展到更多地区——届时来自未验证开发者的侧载安装会被要求多走一步「已知悉风险」的确认流程，不是被彻底禁止。以 Google 官方说明为准。
- **安装被系统拦下**的常见原因除了权限没给，还有 APK 架构与设备不匹配（arm64-v8a / armeabi-v7a）或下载损坏导致签名无效——后者重下一遍通常就能解决，重下后记得再对一次 MD5。

装的过程中卡住的其他现象，去 [常见问题与故障排除.md](常见问题与故障排除.md) 的安装类速查表对号；安装文件的获取与各平台官方渠道见 [下载与安装教程.md](下载与安装教程.md)。
