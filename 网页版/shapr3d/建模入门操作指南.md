## 一、开工前知道三件事就够了

1. **两种建模路线可以混用**。Shapr3D 同时支持「直接建模」（选中面直接拖）和「基于历史的参数化建模」（左侧历史步骤里改参数）。你既可以直接拖一个面改形状，也能回头双击历史里的某一步改数值，两种动作在同一份模型上随时切换。
2. **工具栏是「自适应」的**。你选中的对象决定它推荐什么工具：选中一条边就推荐圆角 / 倒角，选中一个草图轮廓就推荐拉伸。找不到工具时，先看自己当前选中了什么，比在菜单里翻快。
3. **离线可用**。建模、改图、导出都可以在断网状态下做；联网后项目自动同步到你账号下的其他设备（官方口径为每个账号最多 3 台设备）。注意一个前提：断网能打开的是**已经下载到本机**的项目——项目列表里对单个项目可以「Download Now / Remove Download」，只存在云端的项目断网是打不开的。

## 二、15 分钟第一个模型（通用流程）

下面这套动作在 iPad、Mac、Windows 上完全一致，只是操作介质不同（见第三节）。

1. 新建一个项目，进入建模界面。
2. 在默认平面上画草图：点「Sketch」，画一个矩形。画的时候注意屏幕上出现的尺寸标注，直接点数值就能键入精确尺寸。
3. 选中草图轮廓 → 工具栏会推荐「Extrude（拉伸）」→ 拖动箭头或键入高度，草图变成实体。
4. 选实体的任意一条边 → 推荐出现「Fillet（圆角）/ Chamfer（倒角）」→ 点一下、拖箭头，边角就圆了或斜了。
5. 画第二个草图、再拉伸，然后用「Union（合并）/ Subtract（减去）/ Intersect（相交）」做布尔运算，得到组合结构。
6. 改动不满意：点左侧历史步骤里的任意一步，改参数或删掉重做。
7. 完成后按 [文件格式导入导出对照表.md](文件格式导入导出对照表.md) 选一个格式导出——3D 打印用 STL / 3MF，给其他 CAD 软件用 STEP 或 X_T。

**常用工具速查**：

| 工具 | 干什么 | 典型场景 |
| --- | --- | --- |
| Extrude | 把草图拉成体 | 一切造型的起点 |
| Revolve | 草图绕轴旋转成体 | 轴类、杯身、旋钮 |
| Loft | 多个截面之间过渡成型 | 流线形把手、变径管 |
| Sweep | 截面沿路径扫掠 | 管线、线缆、扶手 |
| Shell | 抽壳成均匀壁厚 | 盒子、外壳件 |
| Pattern | 线性 / 圆形阵列 | 一排孔、一圈齿 |
| Split | 把一个实体切成多个 | 拆件、做装配 |

## 三、三种操作介质，各有各的顺法

| 介质 | 顺手的做法 | 要注意的 |
| --- | --- | --- |
| iPad + Apple Pencil | 一只手转视角、另一只手用笔画和拖；选面直接推拉 | Apple Pencil 是推荐配置但**不是必需**，触控 / 触控板 / 外接鼠标都能完成日常建模 |
| 鼠标 + 键盘（Mac / Windows） | 左键选择、右键呼出上下文菜单；快捷键可以自己改（Settings 里的 keybindings） | 值得先记住的几个：撤销重做、视图切换、Esc 退出当前工具 |
| 3D 鼠标（SpaceMouse） | 专管视角，左手导航右手建模 | 官方支持 3Dconnexion SpaceMouse，桌面端即插即用 |

Windows 平板（支持触控笔的 Surface 一类）介于两者之间：官方明确支持触控 + 笔输入，是安卓平板之外少数「平板形态跑官方版本」的选择。

## 四、新手最容易卡住的四个点

1. **草图没闭合就拉伸**。轮廓有缺口时 Extrude 不会成功，放大缺口处补线即可；画草图时留意端点的吸附提示。
2. **模型飘在原点之外**。新几何都建议从原点附近的平面上起画，后面导入导出、对齐会省很多事。
3. **找不到撤销**。桌面端按 `Ctrl+Z` 撤销（Mac 是 `⌘Z`），重做是 `Shift+Ctrl+Z`（Mac `⇧⌘Z`）；iPad 端直接**三指左滑撤销、三指右滑重做**，或点屏幕上的撤销 / 重做图标。图标位置随版本挪过（5.440 界面改版时移到顶栏、5.460 又移回屏幕底角），找不到图标时用手势最稳。
4. **网格文件当实体用**。导入的 STL 是三角网格，只能在上面建参考、不能直接倒角抽壳；正确做法是参照网格重新画草图建模，格式细节见 [文件格式导入导出对照表.md](文件格式导入导出对照表.md)。

建项目的额度被 2 个项目的免费档上限卡住时，先看 [免费版与付费版区别.md](免费版与付费版区别.md) 再决定要不要升级；系统操作没讲到的细节，官方手册在 [support.shapr3d.com](https://support.shapr3d.com/hc/en-us)。安装环节的问题（含安卓安装文件的获取）回 [下载与安装教程.md](下载与安装教程.md)。
