## 一、先弄清楚你要装的是哪一种

Shapr3D 官方目前公开支持的平台是 **Windows、macOS、iPadOS 与 visionOS**，官方帮助中心明确写着「Android is not supported at this time」（安卓端暂不支持）。也就是说：

| 你手里的设备 | 能走的路 |
| --- | --- |
| iPad（iPadOS 17 及以上） | 用官方 App Store 渠道安装，见本篇第三节 |
| Mac（macOS Sonoma 14.0 及以上） | 用官方 App Store 或官网直装包，见本篇第三节 |
| Windows 电脑或 Windows 平板（Windows 10 2004 及以上） | 用官网直装包或 Microsoft Store，见本篇第三节 |
| 安卓手机 / 安卓平板 | 官方没有安卓版；只能通过本文第二节的安装文件资源安装安卓 APK，装出来是什么版本、能不能满足你的需求，以你设备上的实际表现为准 |

把这一层先摆清楚，是因为不少人搜「Shapr3D 安卓」时以为存在官方安卓版，结果装了来路不明的包。本篇的做法是：先把官方渠道列明白，再讲网盘里这份安卓安装文件怎么装、怎么核对。

## 二、安装安卓 APK（网盘安装文件）

如果你要在安卓设备上尝试，从夸克网盘转存后获取安装文件即可。**shapr3d 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/3fb4226d4614](https://pan.quark.cn/s/3fb4226d4614)

安装步骤：

1. 把网盘里的 APK 文件转存到自己的网盘后下载到手机（或先下到电脑再传到手机）。
2. 在手机上点开 APK。首次安装会提示「未知来源应用」，在系统弹窗里允许该来源安装即可；不同品牌（小米 / 华为 / OPPO 等）的开关位置不同，一般在「设置 → 安全」或安装时直接授权。
3. 装完打开应用，首次使用通常需要注册或登录账号。
4. 想核对包完整性，可以在电脑上算 MD5（PowerShell：`Get-FileHash 文件名.apk -Algorithm MD5`），与上表比对；不一致就别装，重新下载。

这四步是最小核对。装前完整检查清单（包名逐字比对、安装权限收窄、装完的权限列表与 Play Protect 扫描）在 [安卓安装包核对与安全注意事项.md](安卓安装包核对与安全注意事项.md)，多花两分钟，能避开绝大多数侧载安装的坑。

两点提醒：

- 官方版本号目前采用 `年份.序号`（如 26.100）这类编号，上面这份 8.3.23 是安装文件记录里的版本，与官方渠道的版本编号方式不一定对应，安装后以应用内显示为准。
- 这份 APK 是 8 MB 出头的小体积包，装好后具体能用到哪些功能，以应用内的实际可用范围为准；若你需要的是官方完整建模能力，可以对照第三节的官方渠道，在 Windows / Mac / iPad 上使用官方版本。

## 三、官方渠道（Mac / iPad / Windows）

官方下载入口都从 [www.shapr3d.com](https://www.shapr3d.com) 出发，设备要求可以查官方的 [Compatible devices](https://www.shapr3d.com/compatible-devices) 页面。各平台入口：

| 平台 | 系统要求 | 安装入口 |
| --- | --- | --- |
| iPad | iPadOS 17 及以上，建议搭配 Apple Pencil | [App Store：Shapr3D CAD Modeling](https://apps.apple.com/app/shapr3d-cad-modeling/id1091675654) |
| Mac | macOS Sonoma（14.0）及以上 | [App Store](https://apps.apple.com/app/shapr3d/id1091675654) 或官方直装包 [download.shapr3d.com/mac/latest](https://download.shapr3d.com/mac/latest) |
| Windows | Windows 10（2004 版本号及以上） | [Microsoft Store](https://apps.microsoft.com/store/detail/shapr3d/9N4K9QFV4XFC) 或官网下载页的 Windows 安装入口 |

Windows 端补充：官网给的是 `.appinstaller` 安装文件，双击即可走 App Installer 安装；如果你的 Windows 关掉了 Microsoft Store，需要确认系统里装了 App Installer 组件。

装好后第一次打开都要注册账号（邮箱注册即可）。免费档有 2 个项目的限制、导出格式也有限制，先弄清边界再决定要不要付费，对照 [免费版与付费版区别.md](免费版与付费版区别.md)。

## 四、装完之后

第一次建模不知道从哪下手，按 [建模入门操作指南.md](建模入门操作指南.md) 的顺序走一遍「草图 → 拉伸 → 改尺寸」，15 分钟左右能出第一个模型；安装或使用中碰到问题，先翻 [常见问题与故障排除.md](常见问题与故障排除.md)。这几篇没覆盖的问题再去查官方帮助中心 [support.shapr3d.com](https://support.shapr3d.com/hc/en-us)，官方的操作手册与更新日志都在那里。
