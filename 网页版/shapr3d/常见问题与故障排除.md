## 一、安卓手机 / 平板能用吗

**官方口径**：官方帮助中心的下载页写明，Shapr3D 目前支持 Windows、macOS、iPadOS 与 visionOS，**安卓端暂不支持**；官方社区里官方成员的答复也是短期内没有安卓版计划（理由包括能带动此类软件的安卓平板占比低）。

**现实的两个选择**：

| 你的情况 | 路径 |
| --- | --- |
| 只想先上手体验建模 | 网盘里的安卓安装文件资源可以直接装（见 [下载与安装教程.md](下载与安装教程.md)），装出来的版本与官方渠道的版本编号不对应，功能边界以应用内实际表现为准 |
| 要的是官方完整能力 | 走官方渠道装 Windows / Mac / iPad 版；支持触控笔的 Windows 平板是官方认可且最接近平板手感的设备 |

两边口径并列放在这里，怎么选你自己定。决定装安卓安装包的话，装前的核对步骤（包名、MD5、权限）见 [安卓安装包核对与安全注意事项.md](安卓安装包核对与安全注意事项.md)。

## 二、账号、设备与同步

**Q：一个账号能登录几台设备？**
官方口径是每个账号跨平台最多 3 台设备。

**Q：断网能不能用？**
能。建模、编辑、导出都离线可用；联网后项目自动云同步。但注意项目的三种存储状态：**仅本地**（还没备份上云）、**已同步**（云端与本机都有）、**仅云端**（本机没有，断网打不开）。在项目列表里可以对单个项目「Download Now」落到本机、「Remove Download」腾出空间。

**Q：多设备用同一个账号，要注意什么？**
官方明确建议**同一个项目同一时间只在一台设备上打开编辑**——两台设备同时开一个项目，是同步冲突的主要来源。真出了冲突，应用会弹冲突处理对话框（较新版本会显示最后编辑的人），按提示选保留哪个版本。

另外三点，多设备用户最好提前知道：

1. 「存储优化」开关开启时，**30 天没动过的项目会被自动清出本机**（云端仍在），再要用需要重新下载；离线需求多的把这个开关关掉（设置里按设备分别控制）。
2. 出问题后能「回到过去」靠的是项目版本历史（Version History，选历史版本点 Restore as Latest），**这是付费档能力，免费档没有**——免费档下被覆盖的项目没有回退兜底。
3. 社区里有用户反馈过同步拿旧数据覆盖新数据、事先没有提示的情况（官方建议的做法就是别两台设备同时开同一项目）。具体行为以官方帮助中心的 Sync 说明为准。

**Q：没有订阅，iPad / Mac / Windows 都要装吗？**
免费档本身就覆盖全平台，装哪个平台都行，账号一致项目互通；不需要为了「多平台」付费。

## 三、操作与功能疑问

**Q：没有 Apple Pencil 能用 iPad 版吗？**
能。官方明确 Pencil 是优化项不是必需项，触控、触控板、外接鼠标都能完成日常建模。

**Q：导入的 STL 为什么不能倒角 / 抽壳？**
STL 是三角网格体，只承载「形状近似」，不承载精确几何，所以参数化工具对它无效。进来当参考体照着重画，或向对方要 STEP / X_T（格式取舍见 [文件格式导入导出对照表.md](文件格式导入导出对照表.md)）。

**Q：免费档为什么导出按钮是灰的 / 只有低精度？**
免费档的导出范围只有低精度 STL / 3MF，STEP、图纸、USDZ 这些都是付费档能力，逐项对照见 [免费版与付费版区别.md](免费版与付费版区别.md)。

**Q：模型改坏了怎么办？**
桌面端与 iPad 端都有撤销；参数化建模下还能打开历史步骤，直接删掉或改出错的那一步。用浏览器打开的审阅链接（Review Links）只能看和评论，不承担编辑功能。

**Q：别人没有装 Shapr3D，怎么看我的模型？**
用分享审阅链接：对方在浏览器里就能旋转、缩放、评论，不用装任何软件。

## 四、安装类故障速查

| 现象 | 处理 |
| --- | --- |
| 安卓装 APK 提示「未知来源」 | 系统弹窗里允许该来源；部分品牌要在「设置 → 安全」里手动放行 |
| 安卓安装后闪退 | 先确认安卓版本满足安装文件标注的要求，再确认 APK 的 MD5 与记录一致（步骤见 [安卓安装包核对与安全注意事项.md](安卓安装包核对与安全注意事项.md)）；仍不行则该设备不兼容，换设备或走官方平台 |
| 安装时被 Play Protect / 系统安全扫描拦下 | Play Protect 也会检查侧载装的应用；被拦时先完成包核对再决定要不要放行，核对方法见 [安卓安装包核对与安全注意事项.md](安卓安装包核对与安全注意事项.md) |
| Windows 直装包双击没反应 | 官网给的是 `.appinstaller`，需要系统有 App Installer 组件；或改走 Microsoft Store 入口 |
| Mac 提示无法验证开发者 | 官方渠道（App Store 或官网直装包）不会有此问题；非官方渠道的包在「系统设置 → 隐私与安全性」里也不会提供放行入口，不建议硬装 |
| 登录收不到验证邮件 | 检查垃圾箱；换浏览器重新走注册流程；仍失败找官方支持 |
