## 一、先说免费档够干什么

免费档（官方叫 Basic）没有时间限制，不是试用版。你能一直用它做这些事：

- 建模本身不设限：2D 草图、约束、直接建模、参数化历史都在；
- 最多 **2 个项目**；
- 导出**低精度 STL / 3MF**（也就是 3D 打印最基础的格式）；
- 导入 STEP、IGES、X_T、DWG、STL 与图片底图；
- 跨平台账号（iPad / Mac / Windows / Vision Pro，每账号 3 台设备）与云同步。

也就是说：**学软件、画概念、打一个低精度件，免费档走完全程**。卡住你的会是下面这两件事之一。

## 二、免费与付费逐项对照

| 项目 | 免费（Basic） | 付费（Pro / Solo 档） |
| --- | --- | --- |
| 项目数 | 2 个 | 无限 |
| 导出 STL / 3MF | 仅低精度 | 高精度 |
| 导出 STEP / IGES / X_T | 不行 | 可以 |
| 导出 2D 图纸（DXF / DWG / PDF） | 不行 | 可以 |
| 导出 USDZ / GLB / OBJ | 不行 | 可以 |
| 技术图纸（2D 工程图） | 没有 | 有 |
| 项目版本历史（覆盖 / 误删后回退） | 没有 | 有（版本保留期按档位，Solo 档 30 天） |
| 实时渲染 + 材质库 | 没有 | 有（100+ 材质） |
| iPad 上的 AR 查看 | 没有 | 有 |
| 分享审阅链接（浏览器看模型） | 有限 | 完整 |
| AI 渲染（Generative Render） | 少量额度 | 更多额度 |
| 支持优先级 | 基础 | 优先 |

**判定方法**：只要你的下游是「真实制造」——送 CNC、给机加工出图、打高精度件——免费档的导出限制就绕不开，直接看付费档；如果只是学建模、出概念、打玩具件，免费档可以一直用。

## 三、价格与档位（会变，以官方页面为准）

官方定价页：[www.shapr3d.com/pricing](https://www.shapr3d.com/pricing)。

- 中文定价页当前展示为 **Pro 档约 ¥74/月（按年付 ¥888/年，每个编辑席位）**；
- 英文定价页同一档位叫 **Solo，$249.99/年（折合约 $20.83/月）**；
- 再往上是面向团队的 Studio / Enterprise 档（多席位、JT 与 CATIA / NX / Creo 等高阶格式、数据自托管等），个人用户一般碰不到。

注意两点：① 官方在不同地区的页面档位名称与价格不同，上面数值只是写作时点的记录；② 官方会改档位结构与价格，**付款前以你看到的官方定价页为准**。

## 四、教育版与几个省钱事实

1. **学生与教师免费**：官方为教育用户提供免费的教育许可，入口在官方定价页的「free for Students and Educators」处，用教育邮箱申请。
2. **一份订阅覆盖全平台**：订阅不按平台收费，iPad / Mac / Windows / Vision Pro 一份许可通用，模型云同步。
3. **免费档不是 14 天试用**：官方另有 14 天付费版试用（注册流程里出现），试用结束后账号落回免费档继续用。
4. **被导出限制卡住的临时解法**：先用低精度 STL 验证形状，确认设计成立再决定要不要为 STEP 导出付费，别为没定稿的模型升级。
