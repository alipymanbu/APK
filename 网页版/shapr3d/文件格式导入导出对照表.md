## 一、选格式前先分清三类文件

| 类别 | 代表格式 | 特点 | 适用 |
| --- | --- | --- | --- |
| 精确几何（B-rep） | STEP、IGES、X_T / X_B | 用数学面描述，精度无限缩放 | 交给其他 CAD / CAM / CNC |
| 三角网格（mesh） | STL、3MF、OBJ | 三角面片拼出来的近似形状 | 3D 打印、AR / 展示 |
| 原生格式 | SHAPR（Shapr3D 自己的）、SLDPRT 等 | 带设计历史，别的软件打不开 | 自己存档、跨设备继续编辑 |

一句话记忆：**要制造选 B-rep，要打印选网格，要留底选原生**。

## 二、导入格式清单

| 格式 | 说明 | 免费（Basic）可用 |
| --- | --- | --- |
| STEP / IGES | 行业标准中性格式，跨 CAD 协作首选 | 是 |
| X_T / X_B（Parasolid） | 与 SolidWorks、NX 同引擎，互换保真度最高 | 是 |
| STL | 三角网格，**仅作参考体**，不能直接参数化编辑 | 是 |
| DWG / DXF | 2D 图纸 / 草图导入 | 是 |
| SLDPRT / SLDASM | SolidWorks 零件与装配体原生文件 | 付费档 |
| 图片（PNG / JPG / TIFF / PDF / BMP / RAW / 静态 GIF） | 作为草图底图描线用 | 是 |
| SHAPR | Shapr3D 自己的格式 | 是 |
| NX / CATIA V5 / Creo / Solid Edge / JT / Rhino | 高阶 CAD 原生格式 | 仅更高档位 |

导入时导入设置里有「简化 / 修复几何」等选项，收到打不开或破面的模型时先动这里的开关再下结论。

## 三、导出格式清单与免费档限制

| 你要做的事 | 该导出的格式 | 免费档能不能做 |
| --- | --- | --- |
| 3D 打印 | 3MF（优先，含水密性信息）或 STL | 免费档**只给低精度** STL / 3MF |
| 交给其他 CAD / CNC | STEP、IGES 或 X_T | 免费档不行，需付费档 |
| 2D 图纸 | DXF、DWG、PDF | PDF / DXF / DWG 需付费档（技术图纸功能同） |
| 渲染展示 | USDZ、GLB、OBJ | USDZ / GLB / OBJ 需付费档 |
| 平面图 / 矢量 | SVG、JPEG、PNG | SVG 等需付费档 |
| 自己存档 | SHAPR | 是 |
| 装配审阅（高阶） | JT、ACIS、FBX 等 | 仅更高档位 |

免费档的核心限制就一条：**导出精度与格式被限制在低精度 STL / 3MF**。学习建模、画着玩够用；要把模型送进加工或打印出像样的件，就绕不开付费档，账见 [免费版与付费版区别.md](免费版与付费版区别.md)。

## 四、三个高频场景的具体选法

**场景 1：把 Shapr3D 模型发给用 SolidWorks 的同事**
两个软件同用 Siemens Parasolid 内核，**首选 X_T**——保真度最高、文件还小；对方打不开再退回 STEP。IGES 是两者都失败时的兜底，缺点是容易出破面。

**场景 2：送 3D 打印**
导 3MF 优先（打印机切片软件普遍认，且能带颜色 / 材质信息）；老切片软件只认 STL 就导 STL，注意免费档给的是低精度网格，曲率大的模型会有明显棱面，打印精度要求高就得升级档位或换渠道。较新版本还支持从导出菜单直接把模型送进切片工具（2026 年起陆续接入 Prusa、Bambu Lab、OrcaSlicer 等导出集成），入口以你手上版本的导出菜单为准。

**场景 3：从别的软件拿文件进来**
问对方要 STEP 或 X_T；只有 STL 时明确它是「参考体」，进来只能照着重画，不能直接改——这条在 [建模入门操作指南.md](建模入门操作指南.md) 的避坑清单里也提过。

## 五、容易踩的三个坑

1. **导出前不确认单位**。导入导出都涉及单位制（毫米 / 英寸），跨软件交接时先在两端把单位对齐，差 25.4 倍的模型就是这么来的。
2. **网格当精确几何传**。STL 转 STEP 并不能把网格变精确，转出来的 STEP 里还是那一堆三角面；要精确几何就得在 Shapr3D 里重建。
3. **版本兼容**。旧版软件收到新版导出的文件偶尔读不出，让对方更新到当前版本再试；具体格式支持以官方 [cad-file-types](https://www.shapr3d.com/product/cad-file-types) 页面为准，会随版本更新。
