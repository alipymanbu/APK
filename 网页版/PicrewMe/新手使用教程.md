## 一、上手路径总览

PicrewMe 的核心动作只有一条线：**建一个形象 → 逐项调整 → 完成保存**。建形象有两条路——拍一张自拍让应用生成基础形象，或者直接进编辑面板从头摆弄；两条路进去之后面对的是同一套编辑界面，所以会用一条，另一条也就会了。还没装应用的，先看 [下载与安装教程.md](下载与安装教程.md)。

## 二、第一步：自拍建形象

1. 打开应用，点**「开始自拍」**（首次会请求相机权限，允许后才能继续）。
2. 把正脸放进取景框内，五官尽量完整、光线别太暗，拍出来的基础形象才好修。
3. 拍完选择**性别**——男女的编辑面板内容有差异（比如胡子只在男性面板出现），选错了回上一步重选即可。
4. 进入编辑面板，开始逐项调整。

## 三、编辑面板：每一项在调什么

面板按部位拆成一排选项，点哪一项、下面的素材列表就换成哪一项的可选项。常见项目如下（具体项目以你装的版本实际界面为准）：

| 面板项 | 调的是什么 |
| --- | --- |
| 前发 / 后发 | 发型的前后两层，刘海与后脑勺的头发分开选 |
| 发色 | 头发颜色 |
| 肤色 / 脸型 | 面部底色与脸部轮廓 |
| 眉毛 / 眼睛 / 嘴巴 / 鼻子 | 五官各自的形状与位置 |
| 特征 | 面部细节项 |
| 胡子 | 胡型（男女面板内容有差异） |
| 眼镜 | 眼镜等脸部配饰 |
| 服装 / 配饰 | 上衣、外套、头饰、首饰等搭配件 |

选素材的原则就是**逐项过一遍、看整体效果**：先定发型和脸型这类大框架，再抠五官，最后放服装配饰——反过来调，改一处就得重看一遍整体。

## 四、微调：换色、移动、缩放

粗选完素材后，界面里这几类控件决定细节能不能到位：

- **画笔图标**：点它可以给当前部件换颜色。没有画笔的部件表示它不提供配色。
- **方向箭头（移动控件）**：选中部件后用上下左右箭头挪位置，比如把眼睛往上提一点、把帽子戴正。
- **缩放控件**：部分部件支持放大缩小，配合移动把部件摆到合适的位置。
- **重置**：调乱了就用重置把当前部件的位置、大小恢复初始值——只影响这一个部件，不会动你选好的颜色和其他部件。

不是每个部件都提供全部控件：界面上没出现某个按钮，就是这个部件不支持该操作，不是你没找到。

## 五、完成与保存

全部调满意后，点右上角的**「√」**进入保存页，成品图会存进手机相册（首次需要允许存储权限）。之后你就可以拿它当社交头像、发给朋友——具体保存位置、找不到图怎么办、以及网页版（电脑浏览器）怎么保存，都在 [头像保存与分享方法.md](头像保存与分享方法.md) 里讲。

界面一直转圈、素材加载不出来，多半是网络问题，按 [常见问题与解决方法.md](常见问题与解决方法.md) 处理，不影响已经捏好的部分。
