## 一、登录用的还是你的 X 账号

Chuckle 是第三方客户端，本身不发账号：你在登录页输入的手机号或邮箱，对应的就是你的 X（Twitter）账号，刷到的时间线与关注关系跟着这个账号走。还没有 X 账号的话，先用手机号或邮箱注册一个。

按应用介绍，安装后无需额外配置网络即可直接登录使用；如果你所在的网络长时间连不上，排查思路见 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 二、首次登录步骤

1. 打开 Chuckle，按提示选择语言；
2. 进入登录页，输入手机号或邮箱，完成 X 账号登录；
3. 登录成功后进入时间线，可以直接搜索帖子、浏览与关注用户。

登录遇到验证码、密码错误这类提示，先用浏览器登录一次 X 官网确认账号本身没问题，再回到 Chuckle 重试。

## 三、多账号的添加与切换

Chuckle 支持同时登录多个 X 账号，切换时不需要反复退出登录：

1. 在应用内找到账号管理入口（通常在侧边栏或「我的」页面，具体位置以当前版本界面为准）；
2. 选择添加账号，输入另一个 X 账号的手机号或邮箱完成登录；
3. 之后在账号列表里点选头像即可切换，切换后看到的内容直接跟着换成对应账号的。

## 四、账号安全的三点提醒

- 只从可信来源获取安装包：网盘里这份的 MD5 是 `E889EEFEE964C19E5ADDDD15BC219B26`，核对方法见 [下载与安装教程.md](下载与安装教程.md)；
- 多人共用一份订阅属于合租，按介绍页的说法会导致订阅失效，相关规则见 [订阅与多设备使用.md](订阅与多设备使用.md)；
- 出现异地登录提醒或怀疑账号异常时，先到 X 官方渠道改密码，再回头检查客户端。

## 五、登录不上的快速排查

按出现频率排：

1. 确认账号密码正确——先用官方应用或网页登录一次验证；
2. Wi-Fi 与移动数据互相切换一次再试；
3. 核对手机系统时间是否准确，时间偏差会导致登录验证失败；
4. 都试过仍失败，看 [常见问题与解决办法.md](常见问题与解决办法.md) 的登录与连接一节。
