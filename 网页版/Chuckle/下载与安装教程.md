## 一、你将要装的是什么

Chuckle 是一款第三方 X（Twitter）安卓客户端，开发者署名为 JJYY Studio（不同渠道署名可能不完全一致，以应用内信息为准）。它不是 X 官方应用，登录用的就是你自己的 X 账号；按应用介绍，安装后无需再单独配置网络即可直接登录使用，不同网络环境下的实际可用性以你实测为准。

网盘里这份安装包的核对信息如下（版本与体积以这份为准，官方渠道可能已发布更新的版本）：

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.0.2 |
| 包名 | `app.jjyy.chuckle` |
| 安装包大小 | 54.30 MB |
| MD5 | `E889EEFEE964C19E5ADDDD15BC219B26` |
| 系统要求 | Android 5.2 及以上（以安装包实际要求为准） |

## 二、获取安装文件

1. 打开上面的 **Chuckle 安装文件资源（夸克网盘）** 链接；
2. 把文件夹转存到自己的夸克网盘；
3. 在夸克 App 里把 `Chuckle_v1.0.2.apk` 下载到手机存储。

在电脑上操作也可以：先转存并下载到电脑，再把 APK 传到手机（数据线、局域网传输均可），后续步骤完全一样。用 iPhone 的话装不了 APK：iOS 版走 App Store，两个端的区别见 [安卓版与iOS版有什么区别.md](安卓版与iOS版有什么区别.md)。

## 三、安装步骤

1. 在手机文件管理里点开下载好的 APK；
2. 系统弹出「是否允许安装来自此来源的应用」时，允许本次安装；
3. 等待安装完成后点「打开」，首次启动会先让你选择语言；
4. 语言选完进入登录页，之后的操作见 [登录与账号管理.md](登录与账号管理.md)。

## 四、安装被拦截的常见情况

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「存在风险 / 高危应用」 | 系统对非应用商店来源安装包的例行提醒 | 选「仍要安装」继续 |
| 安装按钮灰色、点不动 | 后台应用或浮窗占用了安装界面 | 清理后台后重试 |
| 提示「无法解析安装包」 | 下载不完整或传输中断 | 对照上表 MD5 核对文件，重新下载 |

国产手机系统的「纯净模式」也会拦商店外的安装包：装不上时先到系统设置里搜「纯净模式」并临时关闭，装完再开回来。更多装不上、闪退的情况按 [常见问题与解决办法.md](常见问题与解决办法.md) 的顺序排查。
