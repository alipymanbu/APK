# QuickStar 状态栏图标与时钟设置

> 状态栏常年挤着蓝牙、NFC、闹钟、VPN 这些你根本不看第二眼的图标。这一篇讲怎么用 QuickStar 把它们逐个隐藏、怎么挪时钟位置、怎么让状态栏带上日期。

## 一、入口在哪

打开 Good Lock，点 QuickStar 进模块，先把总开关打开——不启用的话，下面的所有设置都不会生效。状态栏相关的设置集中在指示器（Indicator）部分。

## 二、逐个隐藏状态栏图标

在图标可见性（Visibility of Indicator Icons）列表里，每个系统图标各有一排开关，关掉哪个，哪个就从状态栏消失：

- 常见可关的：NFC、蓝牙、耳机插入、闹钟、飞行模式、VPN、移动热点等；
- VPN 图标在 4.1.x 版本进入可隐藏列表，移动热点的隐藏与「模式」「设备维护」这类新图标分别在后续版本加入，具体能关哪些取决于你的 One UI 版本；
- 你也可以把电池图形整个隐藏——如果已在系统设置里开了电量百分比数字，只留数字是常见的清爽做法。

实际取舍建议：把「常年开着但你从不需要看」的关掉（比如一直连着的蓝牙耳机），留两三个真正传递信息的，状态栏立刻干净。

## 三、时钟：位置、日期与格式

| 想改什么 | 怎么改 | 版本条件 |
| --- | --- | --- |
| 时钟位置 | 从默认左侧挪到中间或右侧 | 折叠屏机型的中间位置在 4.2.x 版本加入 |
| 状态栏显示日期 | 在时钟相关设置里打开 | One UI 5 起（5.x 版本线） |
| 日期显示格式 | 换成你习惯的年月日排法 | One UI 6.1 起（7.2.x 版本线） |
| 面板时钟带秒针 | 在快捷面板的时钟设置里打开 | One UI 5 起 |

版本条件对不上的话，选项可能直接不出现或改了无效，属于正常现象，不是设置错了。

## 四、改完没反应

先确认模块总开关是开着的，再锁屏重新点亮一次看是否刷新；仍然不行，按 [设置不生效与常见问题排查.md](设置不生效与常见问题排查.md) 的症状表逐项排查。设置项在你系统上是否存在，也可以先去 [版本更新与 One UI 兼容说明.md](版本更新与 One UI 兼容说明.md) 对一遍版本线。
