## 一、网盘里这一份的版本事实

网盘里的 **QuickStar 安装文件资源**（[https://pan.quark.cn/s/48b88a334902](https://pan.quark.cn/s/48b88a334902)）是 9.0.00.1 版：

| 项目 | 值 |
| --- | --- |
| 版本 | 9.0.00.1 |
| 包名 | com.samsung.android.qstuner |
| 大小 | 16.72 MB |

按官方商店更新说明的口径，v9.x 版本线面向 One UI 7 及以上设备、同时支持 One UI 8 设备。也就是说，这份 9.0.00.1 适合系统已经升到 One UI 7/8 的机型；系统更老的机型要用对应的旧版本线，对照关系见下表。

## 二、版本线与 One UI 对应关系

下表整理自 Galaxy Store 商店页公开的更新说明（官方随时可能调整，以商店页面为准）：

| QuickStar 版本线 | 对应 One UI | 该阶段加入的代表性功能 |
| --- | --- | --- |
| 5.x | One UI 4（Android 12） | 5.0.00.00 起支持 One UI 4；折叠屏时钟中间位置 |
| 6.x | One UI 5.x | 面板秒针时钟、状态栏日期时钟（One UI 5） |
| 7.x | One UI 6.0 ~ 6.1 | 状态栏日期格式自定义（6.1）；Theme Park 联动方式调整 |
| 9.x | One UI 7 及以上 | 官方明确 v9.x 面向 One UI 7+，并支持 One UI 8 设备 |
| 10.x | One UI 8 / 8.5 | 撰写时商店在架版本（10.0.04.26，2026-07） |

看不懂自己机型的 One UI 版本时，在系统「设置 → 关于手机 → 软件信息」里能看到 One UI 版本号，对进上表再决定装哪条版本线。

## 三、更新日志里值得知道的变化

节选自官方商店页的更新说明，挑与日常使用直接相关的：

- **One UI 7 系统侧改动**：系统原生把通知与快捷面板分离（左右角下拉），模块的分栏与直达功能跟它重叠——适配细节见 [One UI 7 快捷面板改动与适配.md](One UI 7 快捷面板改动与适配.md)；
- **One UI 8.5 适配**：面板样式自定义、横屏布局设置、控制条层级显示、面板项大小调整（2026-07 前后版本）；
- **One UI 8.5 初期**：「快捷设置按钮网格」调整曾官方说明暂时不可用，后续适配版恢复；
- **One UI 6.0 起**：「按最近更新显示通知」「直达快捷面板」移入系统设置，模块内移除；
- **One UI 6.1**：状态栏日期格式可自定义；
- **One UI 5**：面板秒针时钟、状态栏日期时钟；
- **更早积累**：VPN、移动热点、「模式」与「设备维护」图标先后加入可隐藏列表；部分设置支持随 Smart Switch 迁移。

## 四、怎么升级

1. 走 Galaxy Store：已安装列表里更新，或在 Good Lock 内直接查看每个模块的更新历史并更新；
2. 从网盘装的安装包（9.0.00.1 这类）不会自动更新，想要新功能走商店路线重装即可；
3. 动 One UI 大版本之前，先看一眼模块的更新说明，能少踩「功能暂时不可用」的坑——更新后真出了状况，按 [设置不生效与常见问题排查.md](设置不生效与常见问题排查.md) 处理。
