## 一、症状速查表

| 症状 | 先检查什么 | 对应章节 |
| --- | --- | --- |
| 改了设置，状态栏或面板没变化 | 模块总开关是否打开 | 第二节 |
| One UI 更新后某个功能不见了 | 功能是否搬进了系统设置 | 第三节 |
| One UI 更新后设置全部回到默认 | 是否赶上大版本跨越 | 第四节 |
| 更新 Good Lock 之后设置失效 | 是否旧版本的已知问题 | 第四节 |
| Galaxy Store 搜不到 Good Lock / QuickStar | 设备与地区是否受支持 | 第五节 |
| 换机后部分设置没跟过来 | 迁移方式是否用了 Smart Switch | 第六节 |
| 升到 One UI 7 后下拉面板行为变了 | 是否原生分离手势 | [One UI 7 快捷面板改动与适配.md](One UI 7 快捷面板改动与适配.md) |
| 网盘安装包弹出「无法安装」 | One UI 6.1.1+ 默认开启的自动拦截程序 | 第七节 |

## 二、改了没反应

1. 回 Good Lock 确认 QuickStar 的开关是开着的——这是最常见的原因；
2. 锁屏再点亮一次，让状态栏重绘；
3. 还不行就把手机重启一次，让系统界面进程重新加载模块；
4. 检查你的 One UI 版本是否提供该选项：很多设置项有版本条件（见 [版本更新与 One UI 兼容说明.md](版本更新与 One UI 兼容说明.md)），版本不够时选项可能根本不出现。

## 三、One UI 大版本更新后功能不见了

两种情况，处理方式完全不同：

1. **功能搬进了系统**：One UI 6.0 起，「按最近更新显示通知」「直达快捷面板」改成系统自带功能，模块设置里移除。去系统设置里找，功能还在，只是换了个地方；
2. **功能暂时不可用**：大版本刚推送时，个别功能会先被官方暂时停用等适配，比如 One UI 8.5 初期的按钮网格调整。这种只能等模块更新，装回旧版模块通常解决不了。

## 四、设置被重置或失效

- 系统大版本更新、模块大版本跨越时，部分设置可能回到默认，逐项重设一遍即可；
- 4.2.x 之前的版本存在「Good Lock 更新后 QuickStar 设置不恢复」的已知问题，官方更新日志标记过修复——遇到同类症状先把模块升级到最新；
- Good Lock 提供把各模块设置汇总查看与统一重置的入口，全部重来的话走那里最快。

## 五、Galaxy Store 搜不到

按三星官方支持页的口径：Galaxy Store 里搜不到 Good Lock，即说明这台设备不受支持；QuickStar 等模块的可用性也随机型与系统版本变化。这种情况只能等官方扩大支持范围，跟手机设置无关。

从网盘拿安装包直接安装是另一条路，装法见 [下载与安装教程.md](下载与安装教程.md) 第三节；装完如果 Good Lock 列表认不到模块，多半是版本线与 One UI 不匹配，对照版本说明换版本。

## 六、换机时设置能不能带走

6.3.x 版本起，QuickStar 的部分设置（通知显示方式、按钮网格、直达面板）支持随 **Smart Switch** 迁移，条件是 One UI 4.0 及以上。换机前用 Smart Switch 做整机备份，恢复后这些设置会跟过来；没覆盖到的项仍要手动重设一次。各项设置的具体改法见 [快捷面板布局与主题设置.md](快捷面板布局与主题设置.md)。

## 七、安装包被拦「无法安装」

One UI 6.1.1 起的三星机型自带**自动拦截程序**，默认开启，会拦截从 Galaxy Store、Play Store 之外来源的 APK 安装——从网盘下载的安装包正好落在这个范围内。三星官方对此的答复口径是：确认应用来源可信后，暂时关闭该功能再装。

1. 设置 → 安全与隐私 → 自动拦截程序；
2. 临时把开关关掉，回头把网盘安装包装上；
3. 装完确认 QuickStar 能正常从 Good Lock 进入后，把自动拦截程序重新打开。

装好之后 Good Lock 还是认不到模块，那不是拦截的问题，回到版本线上查，见 [版本更新与 One UI 兼容说明.md](版本更新与 One UI 兼容说明.md)。
