# QuickStar 下载与安装教程

> QuickStar 是三星 Good Lock 套件里负责「状态栏 + 快捷面板」的定制模块，免费，出自三星 Good Lock Labs。本篇讲清安装前提、两条获取路线与装好后的入口位置。

## 一、装之前先确认三件事

| 检查项 | 要求 | 说明 |
| --- | --- | --- |
| 手机品牌 | 三星 Galaxy | QuickStar 改的是 One UI 的系统界面，其他品牌的手机装了也用不上 |
| 主程序 | 先装 Good Lock | QuickStar 是 Good Lock 的插件，装完也要从 Good Lock 里进入设置 |
| 系统版本 | One UI 版本决定能跑哪个版本线 | 不同模块版本线对应不同 One UI 版本，对照关系见 [版本更新与 One UI 兼容说明.md](版本更新与 One UI 兼容说明.md) |
| 支持机型 | Good Lock 覆盖的机型 | 官方口径：Galaxy S、Note、Z Flip/Fold 系列与部分 A 系列、部分平板可用；你的机型上 Galaxy Store 搜不到 Good Lock 就是不支持 |

Good Lock 本体在 **Galaxy Store**（三星自带应用商店）里搜索安装。商店页面对 QuickStar 标注的目标系统是 Android 8 以上设备，但实际可用的功能随机型与 One UI 版本变化，以官方说明为准。

## 二、路线一：从 Galaxy Store 安装（推荐）

1. 打开 Galaxy Store，搜索 **Good Lock**，安装后打开，点「同意并继续」；
2. 在 Good Lock 的模块列表里找到 **QuickStar**，点旁边的下载按钮装上；
3. 装完回到 Good Lock 列表，点 QuickStar 进入设置界面。

这条路的好处是版本与你的 One UI 自动匹配，后续更新也在商店里完成。QuickStar 支持韩语、英语、中文、日语四种界面语言。

## 三、路线二：从网盘获取安装包直接安装

设备上登录 Galaxy Store 不方便时，可以用备好的安装包：把 **QuickStar 安装文件资源（夸克网盘）**（[https://pan.quark.cn/s/48b88a334902](https://pan.quark.cn/s/48b88a334902)）里的内容转存到自己的网盘，再把安装包下载到手机。

1. 在手机上点开安装包，系统会提示「不允许安装未知应用」，按提示允许对应来源（浏览器或文件管理器）安装；
2. 装完后从 **Good Lock → 模块列表** 里进入 QuickStar，先把开关打开，设置才会生效；
3. 如果 Good Lock 列表里认不到这个模块，多数是模块版本与 One UI 版本不匹配，对照上面提到的版本说明换版本线。

还有一个 One UI 6.1.1 起机型特有的坎：系统自带的**自动拦截程序**默认开启，会拦截从 Galaxy Store、Play Store 之外来源的 APK 安装。装网盘包时如果弹出「无法安装」，按三星官方说明先到 设置 → 安全与隐私 → 自动拦截程序 暂时关闭，装完确认能正常用再打开。

网盘里这一份的事实信息（以安装包本身为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 9.0.00.1 |
| 包名 | com.samsung.android.qstuner |
| 大小 | 16.72 MB |
| MD5 | 6DDD26482572FD39533AF1F3871EA94F |

官方商店的 QuickStar 一直在更新，商店页面显示的版本号可能已经高于这一份；想跟最新版走路线一，版本以官方商店页面为准。

## 四、装完从哪里进

无论哪条路线装上的，日常入口都是 **Good Lock → QuickStar**。它管两块地方：屏幕最上方的状态栏，以及下拉打开的快捷面板；两块分别怎么改，见 [状态栏图标与时钟设置.md](状态栏图标与时钟设置.md) 与 [快捷面板布局与主题设置.md](快捷面板布局与主题设置.md)。
