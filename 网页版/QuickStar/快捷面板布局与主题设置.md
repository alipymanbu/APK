# QuickStar 快捷面板布局与主题设置

> 下拉快捷面板一天要拉几十次，默认一行 4 个按钮，开关稍微多用几个就得翻页。这一篇讲怎么用 QuickStar 调按钮密度、把面板拆成左右两套、省掉「拉两次」直达开关，以及给面板换颜色。

## 一、入口在哪

Good Lock → QuickStar → 快捷面板（Quick panel）部分。同样要先打开模块总开关。

## 二、按钮网格：一行多放几个

- 加大每行按钮数：从默认 4 个调到 5 个或 6 个，第一页能看到的开关多出近一半，翻页次数明显变少；
- 反过来也可以调小，让每个按钮更大、更好按；
- 档位与可用性随 One UI 版本不同——One UI 8.5 初期版本一度官方说明暂不可用这项调整，后续适配版恢复，遇到选项变灰多半是这种阶段性的情况。

## 三、左右分栏：两套面板两套开关

开启左右分离后，从状态栏左侧下拉与右侧下拉打开的是两个独立面板，各放各的开关。一个实用的分法：

| 左侧面板（连接类） | 右侧面板（媒体与显示类） |
| --- | --- |
| Wi-Fi、蓝牙、移动热点、NFC、飞行模式 | 亮度、勿扰、屏幕模式、媒体输出、音量相关 |

肌肉记忆养成之后，你不用看面板内容就知道该从哪边拉。

## 四、直达快捷面板

默认第一次下拉看到的是通知，再拉一次才是快捷开关；「直接打开快捷面板」这类选项能省掉第一下拉。两点要知道：

1. 早期版本里这个开关在模块设置里，5.2.x 还给状态栏加过分区引导提示，标出哪段下拉进快捷设置、哪段进通知；
2. One UI 6.0 起，「直达快捷面板」「按最近更新显示通知」这两项改成了系统自带功能，模块设置里不再提供——新系统上找不到它们不是坏了，去系统设置里开。

再往上，One UI 7 直接把通知与快捷面板原生分开（左右角下拉、面板设置里 Separate/Together 可选），与模块的分栏、直达设置是两套并行的东西，升级后怎么对齐见 [One UI 7 快捷面板改动与适配.md](One UI 7 快捷面板改动与适配.md)。

## 五、面板配色与透明度

- 模块内可以改面板背景色、按钮颜色与透明度等基础样式；
- 想做整套主题级的联动（跟随壁纸取色、按钮形状一起改），需要搭配同属 Good Lock 的 **Theme Park** 模块；7.2.x 版本起改了与 Theme Park 的联动方式，官方说明要求 Theme Park 为 1.1.00.8 以上版本。

Theme Park 在 Good Lock 列表里单独安装进入；两边设置叠加时，如果面板样式表现奇怪，先检查是不是两处都改了同一项。

改完布局但面板没变化的话，去 [设置不生效与常见问题排查.md](设置不生效与常见问题排查.md) 对症排查。
