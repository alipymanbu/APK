## 一、One UI 7 的原生面板先搞清楚

三星从 One UI 7.0 起（首发机型如 Galaxy S25 系列）把通知面板与快捷面板分开了，下拉手势跟旧版完全不同：

| 手势 | One UI 6.1.1 及以下 | One UI 7.0 及以上 |
| --- | --- | --- |
| 单指从屏幕顶部下拉 | 通知 + 第一行快捷开关 | 从右上角下拉 = 快捷面板；从其他位置下拉 = 通知面板 |
| 双指下拉 | 完整展开快捷面板 | 不再需要 |
| 面板顶部左右滑 | 无此手势 | 通知与快捷面板之间切换 |

哪一侧开快捷面板也可以对调：分离模式的面板设置界面里提供了切换开关，左右手习惯自选。

## 二、Together 与 Separate 在哪切换

1. 从右上角下拉打开快捷面板，点铅笔图标进入编辑；
2. 点「面板设置（Panel settings）」；
3. 在 **Separate（分离）** 与 **Together（合并）** 之间选：
   - **Together**：老行为，通知与快捷开关同屏，再拉一次展开完整面板——开关用得不频繁的人顺手；
   - **Separate**：新行为，通知区域更大——需要适应两套下拉手势。

有个官方说明没写、但能省力的操作（有用户分享）：Separate 模式下，在通知面板的空白处（顶部日期一带，或底部按钮之间的空隙）**向右滑**，可以直接切到快捷面板，比从最顶上重新下拉省力。

## 三、跟 QuickStar 的设置怎么对齐

- QuickStar 的「左右分栏」「直达快捷面板」在旧系统上是补系统短板；One UI 7 原生有了分离手势后，这两类功能与原生行为重叠——其中「直达快捷面板」从 One UI 6.0 起就已移入系统设置，模块里没有；
- QuickStar 仍然能管、原生给不了的：状态栏图标显隐、时钟位置与日期、按钮网格密度、面板配色与透明度；
- 版本要对上：跑 One UI 7/8 的机型用 9.x/10.x 版本线的 QuickStar，对照关系见 [版本更新与 One UI 兼容说明.md](版本更新与 One UI 兼容说明.md)。

## 四、改完还是旧样式

1. 先确认系统真的在 One UI 7 上：设置 → 关于手机 → 软件信息；
2. 面板分离是系统行为，QuickStar 的设置叠加在其上；两边改了同一项时表现会互相覆盖，逐项回退排查的路径见 [设置不生效与常见问题排查.md](设置不生效与常见问题排查.md)；
3. 布局与配色的具体改法见 [快捷面板布局与主题设置.md](快捷面板布局与主题设置.md)。
