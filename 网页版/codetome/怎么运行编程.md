## 一、先在首页把环境配好

打开 App 进首页，能看到"配置环境"入口——第一次写代码前先点它，把运行环境配好，后面的编程页和课程练习都依赖这一步。首页上还有"常用软件""购机指南"这类与编程相关的栏目，不影响写代码，按需浏览就行。

## 二、在编程页跑第一段代码

1. 切到编程页，在代码编辑器里输入代码。
2. 选择对应的语言，C、Java、Python 等环境在编辑器界面一键切换。
3. 点"运行"按钮，程序就执行了，结果直接显示在页面上。

以 Python 为例，教学环境里已经内置了 Python 安装，不用你再配置任何东西，第一个程序从一行 `print` 开始就可以。版本更新后入口的叫法可能略有差异，找不到时留意底部的页签切换。

## 三、用答题页刷题

进答题页后，先在题库里选科目（比如 C 语言），进入该科目的题目列表逐题作答。适合已经看过讲解、想巩固语法的情况：题目按科目分组，做完能直接看出自己哪块知识点没过关。

## 四、在课程里边学边练

课程类内容（比如 Python 基础课）每个关卡里都有互动讲解、随堂演练、上机作业三类环节，代码练习直接嵌在页面里——学完一段马上写一段，不用在"看课"和"写代码"两个软件之间来回切。学习进度会保留，下次打开接着上次的关卡继续。

课程整体怎么按天推进、毕业项目是什么，见 [零基础入门Python.md](零基础入门Python.md)。
