## 一、课程结构：按天闯关

以 2.3.0 版本里的 Python 基础课为例，课程总共排 30 天，课程页会显示"共 30 天，已学 X 天"。整个课程拆成一个个"目标"，每个目标占一到两天：

| 阶段 | 内容 |
| --- | --- |
| 目标一 | 程序的运行 |
| 目标二 | Python 入门语句 |
| 后续目标 | 按同样节奏推进，逐关解锁 |
| 毕业项目 | 综合前面所学做一个小项目（课程里的示例叫"时光电影院"） |

每个目标里面再分三类环节：**互动讲解**（看知识点）、**随堂演练**（跟着写）、**上机作业**（独立完成一段代码）。顶部还有"学习提醒"和"联系客服"入口。

具体章节名称以你 App 里显示的为准，版本更新后可能调整。

## 二、开始前先试学

课程开头标着"试学"的关卡可以直接试，不用急着做决定。试的时候重点看两件事：讲解节奏你跟不跟得上、在手机上敲代码顺不顺手。都觉得合适再往下学，不合适就趁早换别的方式，试学本来就是这个用途。

## 三、每天的节奏怎么安排

- 按课程排的进度走，一天一个目标左右。每个目标都带演练和作业，写完才算过，别只看讲解就往下滑。
- 讲解页里的示例代码先照着敲一遍、跑一次，再看下一页；跑代码的方法见 [怎么运行编程.md](怎么运行编程.md)。
- 进度自动保留，中途退出、换时间继续都行；跨设备学习时保持同一账号登录。

## 四、卡住了怎么办

课程配套了助教答疑（官方宣传为"8h 在线答疑"）和社群共学。提问时带上你写的那段代码，说清三件事：做到哪一步、期望出现什么、实际出现什么——这样处理最快。安装失败、运行报错这类和课程内容无关的问题，先看 [常见问题与联系客服.md](常见问题与联系客服.md)。

## 五、基础课学完之后

Python 基础课之外，题库里还有 C 语言、Java 等科目的题目可以继续练，编程页也支持切换语言直接写代码。各入口的用法见 [怎么运行编程.md](怎么运行编程.md)。部分内容属于会员范围，差别见 [会员价格与免费功能.md](会员价格与免费功能.md)。
