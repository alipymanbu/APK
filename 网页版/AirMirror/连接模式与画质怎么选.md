## 一、两种连接模式的差别

远程控制、屏幕镜像、远程相机都受「连接模式」影响，两种模式的取舍不同：

| 对比项 | 普通模式 | 动态模式 |
| --- | --- | --- |
| 连接速度 | 更快 | 稍慢 |
| 显示帧数 | 更低 | 按网络动态平衡画质与延迟 |
| 流量消耗 | 更低 | 相对更高 |
| 单向聆听（听被控端声音） | 不支持 | 支持 |

## 二、在哪里设置

1. 打开 AirMirror，点 **个人 > 设置**；
2. 点 **连接模式**，选「普通模式」或「动态模式」后确定；
3. 模式选定后再选默认画质：
   - 普通模式：低画质 / 中画质 / 高画质；
   - 动态模式：平衡模式 / 画质优先 / 流畅度优先。

选项名称以你手上版本的实际界面为准（随版本更新可能调整）。

## 三、按场景选

| 你的情况 | 建议 |
| --- | --- |
| 跨网远控，在意每月流量额度 | 普通模式 + 中低画质，流量消耗最低 |
| 要看清屏幕上的小字（帮长辈操作、核对验证码） | 高画质，或动态模式的画质优先 |
| 网络一般，画面卡成幻灯片 | 动态模式的流畅度优先，或普通模式低画质 |
| 想同时听到被控手机的声音 | 只能选动态模式；注意单向聆听本身是会员功能，免费账户在远程模式下用不了 |

## 四、画质与流量的关系

跨网（非局域网）使用时，画面数据计入账户的远程数据流量，免费账户每月额度有限（数字与规则见 [免费与会员功能区别.md](免费与会员功能区别.md)）。同样时长下，高画质加动态模式流量走得最快；把默认画质调低一档，是免费额度下延长使用时间最直接的办法。

局域网内不受流量限制，按观感随便选。远程相机和屏幕镜像走的是同一套模式与画质设置（用法见 [远程相机与屏幕镜像用法.md](远程相机与屏幕镜像用法.md)），调一次全局生效。
