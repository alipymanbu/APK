## 一、远程协助和远程访问是两条独立的路

AirMirror 里有两个模块，连接方式完全不同：

| 对比项 | 远程访问（控制自己的设备） | 远程协助（帮别人的设备） |
| --- | --- | --- |
| 连接依据 | 两端登录同一个 AirDroid 账号 | 9 位一次性连接码 |
| 被控端装什么 | AirDroid | AirDroid Remote Support |
| 对方要不要配合 | 不需要在场 | 对方出示连接码并接受请求 |
| 适用对象 | 自己名下的手机 | 亲戚朋友、客户的手机 |

控制自己设备的完整流程在 [手机远程控制手机设置步骤.md](手机远程控制手机设置步骤.md)；本篇只讲协助这一条。帮别人时不要走「共享账号」的路——把账号密码给出去，你的所有绑定设备都暴露了，连接码方式没有这个问题。

## 二、连接步骤

1. 你的手机装好 AirMirror（获取方式见 [下载与安装教程.md](下载与安装教程.md)），进入**远程协助**模块；
2. 对方的手机安装 **AirDroid Remote Support**（iOS、Android 都有版），打开后界面上会显示一个 **9 位连接码**；
3. 你在 AirMirror 里输入这个连接码，发起连接；
4. 对方在弹出的请求里点接受，会话建立，你这边就能看到对方手机的屏幕。

连接码是一次性的，每次协助让对方重新报一个即可，不需要提前加好友或绑定。

## 三、会话里能做什么

| 功能 | 用途 |
| --- | --- |
| 实时屏幕共享 | 看对方手机当前画面，定位问题出在哪一步 |
| 手势引导 | 在对方屏幕上画箭头、圈注，告诉对方该点哪里 |
| 文字 / 语音聊天 | 边看边说，不用另开电话 |
| 暂停屏幕共享 | 对方要输密码、看验证码时，随时暂停保护隐私 |

注意与「远程访问」的能力差异：协助会话默认是「看 + 指导」，对方接受控制请求后才能直接操作对方手机，能否直接控制取决于对方的接受与授权情况。

## 四、免费时长与限制

远程协助**每天有 2 分钟免费时长**，超过后连接会被断开；需要更长时间，要购买 AirDroid Remote Support 的套餐，价格与套餐内容以官方页面为准（这类权益会调整）。

顺带一提：远程协助的 iOS 版 AirMirror 是有的，但它的 iOS 版只有协助模块，远程控制、远程相机这些「远程访问」功能只有安卓版 AirMirror 才有。
