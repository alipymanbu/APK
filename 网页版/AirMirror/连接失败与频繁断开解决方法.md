## 一、先记住一个结论

这类问题绝大多数出在**被控手机那台设备**上，而不是 AirMirror 这台。最常见的原因是安卓系统把被控端的 AirDroid 后台进程杀了，设备因此离线。控制端这边能做的检查很少：确认自己有网、账号登录正常，然后就把注意力放到被控端去。

## 二、第一嫌疑：系统杀后台

被控端 AirDroid 进程被杀后，AirMirror 里的设备就显示离线。官方给的应急办法很直接：在**网络稳定的情况下，重新打开一次被控手机上的 AirDroid**，把后台进程激活，再回到 AirMirror 重连。

不想每次都手动激活，就要在被控手机上把 AirDroid 设为允许后台运行。各家系统路径不同，官方帮助中心按品牌有专门教程（小米、华为、三星、魅族、OPPO、vivo 等），路径会随系统版本变化，直接搜对应品牌的那篇照着设即可。设置时重点过一遍这三类：

1. 自启动与后台运行权限——允许 AirDroid 自启动、不限制后台活动；
2. 省电策略——把 AirDroid 移出省电限制（电池优化白名单），排查期间顺手关掉系统省电模式；
3. Wi-Fi 休眠——部分手机可以设置「休眠时保持 Wi-Fi 连接」，锁屏断网也会表现为设备离线。

注意即使全设了，也不能百分百保证进程不被杀——电量过低、后台应用堆得太多、系统太旧时照样会被杀。

## 三、无障碍（辅助权限）被系统自动关闭

走「辅助权限插件」方式免 root 的设备，这个权限会被系统自己关掉，控制就只剩画面不能操作。已知的三种情形：

| 设备 | 什么时候被关 |
| --- | --- |
| 魅族 | AirDroid 自动更新或重装之后 |
| 小米、华为 | 后台进程被系统杀掉之后 |
| 三星、部分 vivo | 设备锁屏之后 |

处理办法都一样：在被控手机上打开设置，搜索「无障碍」（或「辅助功能」），找到 AirDroid 的控制插件，重新开启它的服务。应用内弹出「相关权限已被收回」之类的提示时，按提示里的「去开启」跳过去开也行。

权限开了还是控制不了，再补两步：到「应用权限管理」里把 AirDroid 的权限尽量设为「始终允许」；插件反复掉权限时，把它卸载重装一次，安装过程中按提示一次性授完所有请求的权限。

## 四、免 root 设置失效

用电脑 USB 方式做的免 root，遇到下面任一操作都会失效，需要重新连线再做一次：

- 重启了被控手机；
- 关闭了「USB 调试」或开发者选项；
- 更改了 USB 配置或连接方式。

现象是原来能控制的设备突然只能看画面、不能操作。重新执行免 root 设置的步骤见 [手机远程控制手机设置步骤.md](手机远程控制手机设置步骤.md) 第二节。

## 五、卡顿、延迟、画面模糊

能连上但用起来难受，按这个顺序处理：

1. **查两端网络**——优先两端都连 Wi-Fi；用移动数据时切到 5G 或信号好的位置。测法很简单：在被控手机上开个网页或视频，卡就说明是网络的问题；
2. **给被控端减负**——关掉被控手机后台的视频播放、大型游戏这类吃资源的应用，降低系统负荷；
3. **降画质**——把 AirMirror 的连接模式与画质调低一档（见 [连接模式与画质怎么选.md](连接模式与画质怎么选.md)），流畅度立刻改善；
4. **重启两端应用**，仍无响应就重启两台设备再连；
5. **两端都更新到官方最新版**再试。

## 六、其他可以逐项排除的原因

按出现频率从高到低：

1. 被控设备关机或断网了（手机端也能看到设备离线，先确认设备本身在线）；
2. AirDroid 被卸载或登出了账号（两端账号不一致时设备不会出现在列表里）；
3. 被控设备电量过低，系统进入激进的省电策略；
4. 屏幕镜像类报错（弹窗被拒、小米「后台弹出界面」没开），单独见 [远程相机与屏幕镜像用法.md](远程相机与屏幕镜像用法.md)；
5. 两端网络质量差——跨网远程对两端网络都有要求，卡顿、掉线时先换网络再试。

全部排除后仍然失败，把两端应用都更新到官方最新版再试；仍旧不行时到官方帮助中心（[help.airdroid.com](https://help.airdroid.com/hc/zh-cn)）按报错关键词搜对应文章。
