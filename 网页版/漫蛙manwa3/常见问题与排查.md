## 一、打开后一直转圈 / 进不去首页

1. 启动时的**线路选择**换一条，多试一两条——单条线路抽风最常见。
2. 换网络环境对比：Wi-Fi 与移动数据各开一次，只有某一侧不行就是那边的网络问题（路由器重启、DNS 换默认）。
3. 系统层面确认没开「限制后台 / 流量省流」把应用断了网。
4. 都不行就先放几分钟再开——线路侧的故障你这边无解，等它恢复最实在。

## 二、闪退、停止运行

按代价从小到大依次做，做到哪步好了就停：

1. **清缓存**：长按桌面图标 → 应用信息 → 存储占用 → 清理缓存（不动数据）。
2. **看剩余存储**：系统可用空间太少会连累图片解码，至少留出几百 MB；有页面给出的经验值是**低于 300M 容易图片解码失败**，先腾空间。
3. **重启应用 / 重启手机**：清掉临时故障，顺手把后台清一遍。
4. **检查权限**：应用信息 → 权限，把存储 / 文件读取相关权限给上。
5. **重置应用内配置**：若设置里有「性能」一类入口，用其中的「重置引擎配置」，并关掉硬件加速渲染（这是第三方页面给出的针对本应用的建议，你这一版有没有该选项以界面为准）。
6. **清数据**：应用信息 → 存储 → 清除数据（会丢登录状态与本地缓存，书架在账号上就没事）。清完再开。
7. **覆盖装一个完整的新包**：清数据还闪退，就用 [下载与安装教程.md](下载与安装教程.md) 里那份重新下、重新装；确认包完整的办法见 [安装包版本与校验.md](安装包版本与校验.md)。

## 三、在线阅读很卡、翻页顿

| 现象 | 先动这三个开关 |
| --- | --- |
| 画面清晰但一顿一顿 | 画质预设降到「平衡」 |
| 到下一话要等半天 | 关掉「预加载下一章」 |
| 弱网下图片一半白 | 图片加载线程改成 1x |

另外：Wi-Fi 信号弱时换移动数据试；缓存管理里如果有几百 MB 的临时缩略图，清掉；后台同时挂着下载 / 视频应用也让出来。设置项名称以你这一版为准，详见 [阅读设置与离线缓存.md](阅读设置与离线缓存.md)。

## 四、图片不显示 / 白图 / 加载失败

1. 先按第一节确认网络本身通——白图几乎都是取图失败，不是文件坏了。
2. 换一条线路重进该章节。
3. 部分页面建议在设置里**切换图像渲染引擎或加速节点**（是否提供这两个选项因版本而异，没有就跳过这条）。
4. 清一次缓存后重进；仍不行，等新版本——单章图片缺失也可能是内容侧没传上来。

## 五、安装被拦、装不上、装完是别的应用

- **系统提示禁止安装**：按 [下载与安装教程.md](下载与安装教程.md) 第三节给这一个来源放行。
- **解析包出错 / 安装中断**：包没下完整，重新下载；想确认这份包完好，比对 MD5（见 [安装包版本与校验.md](安装包版本与校验.md)）。
- **提示与已装应用签名不同、装不上**：先卸载旧的再装——卸载会清掉本地数据，账号下的书架不受影响。
- **装完打开发现界面完全不对**：八成装了同名的其他东西，进 设置 → 应用 查包名，不是 `com.jcydmzj.mwanam` 就删掉，回到网盘那份重装。

## 六、缓存下不下来 / 已缓存的章节打不开

1. **看存储**：缓存失败最常见的原因是剩余空间不够，先腾出几百 MB 再试（腾空间的顺序见第二节第 2 条）。
2. **看网络**：下载中途断网会停在半截，回到缓存管理界面点继续或重下；Wi-Fi 不稳就换移动数据。
3. **先清缓存、别急着清数据**：缓存管理里删掉卡住的那一部再重新缓存一次。**「清除数据」会把已缓存章节一并删掉**——缓存存在应用私有目录里，跟着应用数据走；真要清数据，做好重下一遍的准备。
4. **已缓存的章节离线打不开**：确认走的是应用内的缓存入口（缓存管理 / 已下载），而不是书架里的在线条目；仍打不开就重下该章。
5. 存储、网络、重下都试过仍失败，属于版本或内容侧的问题，等新包覆盖安装（见 [下载与安装教程.md](下载与安装教程.md) 第五节）。

## 七、账号与同步相关

- **忘记密码 / 换手机登不上**：走找回流程，细节见 [账号注册与收费说明.md](账号注册与收费说明.md) 第五节。
- **书架空了**：先确认当前登录的是不是原来那个账号；没登录状态下看到的自然是空书架。
- **内容提示仅会员可见**：这属于账号权限问题，换线路和清缓存都不解决，需要登录有权限的账号；免费与会员的两种口径在 [账号注册与收费说明.md](账号注册与收费说明.md) 第三节并列说明。
- **同步要不要登录、同步哪些东西**：见 [账号注册与收费说明.md](账号注册与收费说明.md) 第四节的对照表。
