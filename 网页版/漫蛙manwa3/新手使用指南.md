## 一、先认识四个入口

启动选完线路进主界面后，你日常只会碰到四个地方：

| 入口 | 你在这里做什么 |
| --- | --- |
| 首页 | 看推荐、点「最近更新」找刚上的新章 |
| 搜索 / 搜寻 | 按名字或关键词直接找某一部 |
| 书架（收藏） | 存下在追的作品，回来接着看 |
| 会员 / 我的 | 登录、注册、看账号状态 |

不同版本的图标位置会有差异，认的是**文字与功能**，不是坐标。

## 二、找漫画的三条路

1. **最近更新**：首页点「最近更新」，列出最近一周内上线的新漫画，按时间倒排——追更的人从这里进最快。
2. **分类 / 排行**：按题材标签（热血、恋爱、悬疑、校园等）筛选，或看排行榜；切换标签后作品集合会整批换掉，某个标签下没内容就换一个或稍后再看。
3. **搜索**：顶部搜索框输入关键词（作品名、作者名都行），也可点热搜榜直接进。

## 三、从详情页到阅读界面

1. 点任意一部作品的封面进详情页——那里有简介、状态（连载中 / 已完结）与章节列表。
2. 点「开始阅读」进入阅读界面。
3. 阅读中**点屏幕中央**唤出工具栏，再点「目录」就能跳到任意一话；翻页方式与亮度在设置里调，见 [阅读设置与离线缓存.md](阅读设置与离线缓存.md)。

## 四、把作品收进书架

在详情页点收藏 / 加入书架，作品就进书架列表。之后：

- 新章节更新时，书架里该作品会标出更新提示，打开应用直接点进去即可；
- 书架会记着你上次读到第几话，点「继续阅读」直接回到原处；
- 换手机时，**用同一账号登录**，书架与阅读进度才会跟着走（见下一节）。

## 五、账号：注册与登录

入口是首页右下角的「会员」/「我的」→ 登录页 →「去注册」，填你常用、能收信的邮箱（或常用手机号），注册完回登录页登录即可。两种注册方式、免费与会员的口径分歧、找回密码的细节，都在 [账号注册与收费说明.md](账号注册与收费说明.md)。

不登录也能看一部分内容（以界面要求为准）；要跨设备同步书架与进度才需要登录。

## 六、几个高频动作的落点

- **接着上次看**：书架 → 点作品 → 继续阅读。
- **看最新一话**：首页 → 最近更新，或进作品详情页点章节列表最上面一话。
- **跳章**：阅读界面点屏幕中央 → 目录 → 选话。
- **存到手机里慢慢看**：详情页或章节列表的缓存按钮，见 [阅读设置与离线缓存.md](阅读设置与离线缓存.md)。
- **打不开 / 一直转圈**：换线路或按 [常见问题与排查.md](常见问题与排查.md) 排。
