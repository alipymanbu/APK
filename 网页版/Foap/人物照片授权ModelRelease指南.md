## 一、什么时候需要一份 Model Release

Model release 是被拍者签署的一份许可文件，同意你把这张照片用于商业销售。规则一句话：**照片里有可识别的人 + 你要标 Commercial（可商用）→ 就需要**。两个常见误区：

- **自拍也要签**。照片里可识别的人是你自己，也得走同样的流程，官方明确说过这一点。
- **脸不完整不等于安全**。判定标准是「可识别」，背影、侧影、标志性特征都可能构成可识别；拿不准就看下一节的判据，再拿不准就按 Editorial 传。

Editorial（仅编辑用途）许可不需要授权书，这是它保守但省事的原因，两种许可的差别见 [上传照片与出售流程.md](上传照片与出售流程.md) 第五节。

## 二、人群照：两条判据

街上、市场、活动现场拍到的照片最常纠结这个问题，官方社区给过明确口径：

| 画面情况 | 要不要逐人签授权 |
| --- | --- |
| 人群只占画面小部分、脸部不清晰、主体是别的东西 | 一般不需要（个别例外情况官方会另行提示） |
| 人群占画面比例大、脸清晰可辨认 | 每一张可识别的脸都要一份 |

## 三、官方模板怎么拿、怎么填

官方社区有一篇 [Model releases](https://community.foap.com/model-releases/) 专文，内附官方模板 PDF 的下载入口。填写方式任选其一：

1. 打印出来手填，签完拍照或扫描；
2. 手机或电脑上用在线签名工具填（官方例子里举的是在线 PDF 签名网站）；
3. 电脑上用 PDF 编辑工具直接填。

填的时候注意两个位置：

- **左侧**给被拍的人（模特）填个人信息并签字；
- **右侧**给你（摄影师）填并签字；
- 模特未满 18 岁的，由父母或法定监护人在文件上标注「ONLY if model is under 18」的位置代签。

## 四、提交去哪、怎么确认

授权书不在 App 里交，走网页上的 [Model Release 面板](https://www.foap.com/me/model-releases)：

1. 用与 App 相同的邮箱和密码登录；首次进入按页面说明点确认。
2. 主屏会列出**需要你补授权**的那些照片。
3. 点选照片（按住 Shift 可多选）→ 点「Upload next model release」→ 选择填好的授权文件 → 点「Submit for approval」提交审核。
4. 一张照片里有多张可识别的脸时，可以对同一张照片上传多份授权，逐一挂上。
5. 提交后点「Submitted for approval」页签核对，能看到刚才提交的照片就说明流程走对了。

授权审核通过前，这类照片的 Commercial 授权处于悬置状态；急着上架的话，先按 Editorial 传，授权办妥后再调整。

## 五、没有人像也别大意

两件相邻的坑顺手一起说：

- **可识别的私有建筑、品牌标识、艺术品**同样可能需要产权方许可（property release），逻辑与肖像授权一致：你无权替别人授权。
- **只传你自己拍的照片**。官方条款对非本人拍摄的内容零容忍——判定为搬运的照片会连同账号一起删除，还可能被追究。这一条没有申诉空间，是红线。

授权书、许可这些事办妥了，收入怎么算、什么时候能提现，见 [收入分成与提现规则.md](收入分成与提现规则.md)；操作层面的疑难汇总在 [常见问题与使用技巧.md](常见问题与使用技巧.md)。
