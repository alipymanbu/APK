AiU 是北京聆心智能科技有限公司推出的 AI 角色对话应用：里面有一批自带人设的角色可以直接开聊，也能自己捏角色，角色会记住你说过的事。它走手机端安装包路线，本篇只做一件事——把网盘里这份包装进手机并正常打开。

## 一、先确认网盘里这份包是哪一版

应用商店里显示的是官方当时的最新版，跟网盘里这份未必是同一个版本号。本篇出现的版本号、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | AiU |
| 版本号 | 1.3.8 |
| 包名 | `com.beings.aiu` |
| 安装包体积 | 87.09 MB |
| MD5 | `57B3E29EC8CFC5C2B1DF43730FAB0400` |
| 适用平台 | Android（手机端 APK） |
| 开发者 | 北京聆心智能科技有限公司 |

**系统要求以官方页面为准。** 官网没有单独公布最低安卓版本，各应用商店的 AiU 详情页会标注该版本对应的系统要求，装之前在那里核对一眼最稳；低于要求的表现通常是装不上或装上打不开。本文不转述任何未经官方确认的具体版本号。

装之前先弄清三件事：

- **认包名，别只认图标和名字。** 应用商店里搜「AiU」会出来若干个同名或近名条目，装错了账号和聊天记录都对不上。这份包的包名是 `com.beings.aiu`，装好后在「设置 → 应用 → 应用管理」里点进 AiU 就能看到。
- **官方渠道另有几处入口。** 官网是 [ai-beings.com](https://ai-beings.com/aiu/)，安卓端也可以在腾讯应用宝的 AiU 页面取；iOS 端在 App Store 上架，应用名写作「AiU-AI剧情聊天机器人-虚拟恋人陪伴」。网盘这份是安卓 APK，iOS 设备装不了。
- **没有电脑版。** 官方只发布手机端应用，想在电脑上用只能走安卓模拟器，做法见 [在电脑上用模拟器运行.md](在电脑上用模拟器运行.md)。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [AiU 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5d8aaa852f99)，在手机夸克 App 里打开最省事。
2. **先转存再下载**：选中安装包，转存到自己的网盘目录，再下载到本机。分享链接以后可能失效，转存过的那份不受影响。
3. **核对体积**：下载完成后看一眼文件体积，应当约 87.09 MB。中途断网重连后体积偏小，安装时会直接报「解析包错误」。
4. **想校验完整性**：在电脑上把包算一遍 MD5，结果应与上表一致（大小写不敏感）。

```cmd
certutil -hashfile AiU_v1.3.8.apk MD5
```

文件名随版本变化，以实际提供的那个为准。

## 三、安装步骤

1. **给文件管理器开「安装未知应用」权限**：进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把用来打开 APK 的那个应用（文件管理器或浏览器）的开关打开。国产定制系统这项常收在「安全」或「隐私」分类里。
2. **点击 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续，这是侧载安装包的常规提示。
3. **手机上已有更高版本时先卸载**：安卓不允许用低版本覆盖高版本，会直接报「应用未安装」。卸载会一并清掉本机数据，动手前先在应用内翻一遍有没有导出或备份对话的入口（是否提供以应用内为准），没有的话就确认这些记录是否还需要。
4. **报「签名不一致」说明包名撞了**：手机里已装过同包名的另一个来源版本，处理办法见本篇第五节的表。
5. **留出安装空间**：安装过程中系统还要展开一份文件，建议预留 500 MB 以上可用空间。

## 四、第一次打开要确认的三件事

1. **能联网**：角色列表和对话都在服务端完成，应用本身不能离线聊天。打开后一直停在加载状态，就先用浏览器确认手机能正常上网。
2. **能登录进去**：第一次进入会先弹用户服务协议，点「确定」后按提示用手机号加验证码登录。收不到验证码的处理见 [注册登录与账号设置.md](注册登录与账号设置.md)。
3. **能看到角色并发出一句**：首页刷得出角色卡片，说明数据侧通了；随便点进一个角色发一句「你好」，能正常收到回复就算装好了。想自己捏一个角色，方法见 [怎么创建自己的AI角色.md](怎么创建自己的AI角色.md)。

## 五、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整 | 核对体积与 MD5，按第二节的步骤重新取一份 |
| 提示「应用未安装：签名不一致」 | 手机里已有同包名、不同来源的版本 | 先在应用管理里卸载旧包，再装这份 |
| 安装被安全中心拦下 | 侧载包被系统安全策略拦了 | 在安全中心的拦截记录里选「继续安装」 |
| 点安装没反应 | 「安装未知应用」权限没给 | 回到第三节第 1 步补上权限 |
| 装完打开就闪退 | 系统版本过低、存储不足或包残缺 | 见 [常见问题与排查.md](常见问题与排查.md) |

以后换版本或者重装，按第二节的步骤重新取一份即可，安装动作与这次相同。
