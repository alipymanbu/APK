# 在电脑上用模拟器运行 AiU

> AiU 官方只有手机版。本篇讲电脑上想用它只能走的这条路——安卓模拟器：怎么装、怎么把包装进去、声音和麦克风怎么打通，以及跑不起来时的常见原因。

先说结论：AiU 官方发布的是安卓 APK 与 iOS 版手机应用，官网页面上只有这两个下载入口，没有桌面版，也没有能直接在浏览器里聊天的网页版。所以电脑上要用，常规做法只有一个——装一个安卓模拟器，把手机版装进模拟器里跑。本篇写清这条路怎么做、代价是什么。

## 一、先判断这条路值不值得走

| 你会得到 | 你会付出 |
| --- | --- |
| 大屏加键盘，长对话、改人设都更舒服 | 模拟器本身占几 GB 磁盘，还要常驻内存 |
| 一边在电脑上聊，一边手机也能用（同一手机号登录即同一账号） | 语音与麦克风要单独配置，效果不如手机 |
| 电脑上也能捏角色、整理人设 | 模拟器的兼容性与稳定性不由 AiU 负责 |

只想偶尔聊两句，直接用手机更省事；要长时间打字、或者人设写得比较长，模拟器才划算。

## 二、装模拟器并把 AiU 装进去

1. **选一个安卓模拟器装上**。挑的时候看三点：能不能选 Android 9 以上的系统版本、是否支持硬件虚拟化加速、附带软件是否干净。
2. **打开虚拟化**。多数模拟器要求电脑 BIOS 里开启虚拟化（Intel VT-x / AMD-V），Windows 上还需要装好「虚拟机平台」组件。没开的话模拟器会起不来或者极慢，一般它会给出明确提示。
3. **建实例时设成竖屏**。AiU 是手机竖屏应用，分辨率按手机比例设（如 1080×1920），别用平板横屏。
4. **把 APK 装进去**。两种办法：直接把 APK 文件拖进模拟器窗口；或用模拟器自带的「安装 APK / 本地安装」选中文件。装之前按 [下载与安装教程.md](下载与安装教程.md) 第一节核对一次版本与体积。
5. **登录**。打开后与手机端一样，用手机号加验证码登录，这样两边进的是同一个账号。

## 三、声音和麦克风怎么打通

电脑上最容易卡住的是音频，分两个方向：

- **听角色说话**：声音走电脑的输出设备，跟系统音量一致。戴耳机时检查模拟器的音频输出有没有一起切过去。
- **发语音消息**：模拟器用的是电脑的麦克风。先在系统「设置 → 隐私 → 麦克风」里允许模拟器访问麦克风，再在模拟器的音频设置里把输入指向你的麦克风设备，否则点录音会没有反应。

模拟器一般还有一个总开关式的「音频输入 / 输出」选项，默认可能是关的，装完先检查一遍。音色本身的设置与手机端完全一样，见 [语音音色怎么设置.md](语音音色怎么设置.md)。

## 四、跑不起来时的常见原因

| 现象 | 多半是什么原因 | 处理 |
| --- | --- | --- |
| 模拟器自己启动失败或极慢 | BIOS 虚拟化没开 | 进 BIOS 打开 VT-x / AMD-V，或补装「虚拟机平台」组件 |
| 安装 APK 报「解析包错误」 | 模拟器的安卓版本低于应用要求，或包没下完整 | 换安卓版本更高的实例重装，并核对体积与 MD5 |
| 装完打开就闪退 | 模拟器兼容性问题 | 换另一个模拟器，或换另一个系统版本的实例再试 |
| 界面错位、按钮点不到 | 实例分辨率不是手机竖屏比例 | 改成 1080×1920 一类竖屏比例后重启实例 |
| 语音没声音、录音没反应 | 音频开关或麦克风权限没给 | 回第三节逐项检查 |
| 登录或功能异常 | 先排除账号本身的问题 | 在手机上用同一账号确认正常，再判断是不是模拟器环境导致 |

模拟器是第三方软件，安装来源、附带软件与数据安全由你自己把关；它能不能稳定跑 AiU，取决于模拟器与这份安装包的兼容情况，以你实际测试的结果为准。反复折腾仍然不行的话，回手机上用是最省事的选择。
