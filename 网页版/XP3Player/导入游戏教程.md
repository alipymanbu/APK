# XP3Player 导入游戏教程

> 本篇讲把 Kirikiri 引擎游戏搬进手机并在 XP3Player 里启动的全过程：游戏放哪、点哪个文件、触屏手势怎么对应鼠标。

XP3Player 采用「你浏览到哪个文件夹、就选哪个文件启动」的读取方式，所以游戏放在哪个目录并不影响启动，关键只有两点：游戏文件夹要完整解压，点开的文件要对。下面按顺序走一遍。

## 一、先确认这游戏能跑

XP3Player 只能运行 Kirikiri（吉里吉里 / Krkr）引擎的游戏，判断方法按可靠程度排：

- **看目录内容**：游戏文件夹里有一个或多个 `.xp3` 文件（最常见的是 `data.xp3`），基本可以确定是 Kirikiri 游戏；
- **看资源标注**：你获取游戏的地方如果标了 KrKr、吉里吉里、Kirikiroid2 版，就是明确说明；
- **排除法**：Ren'Py（目录里有 `.rpa`）、Unity、RPG Maker 之类引擎的游戏，这个模拟器一律跑不了。

拿不准的话，先看[引擎与游戏兼容性](引擎与游戏兼容性.md)那一篇，里面有更细的判别方法和它明确不支持的部分。

## 二、把游戏放进手机

1. 手机上装一个能解压的文件管理器（如 ZArchiver 这类）。
2. 把游戏的压缩包解压成一个**完整的文件夹**。不要只把 `data.xp3` 单个文件抽出来——字体、补丁、视频、脚本都还在游戏目录里，缺了任何一个都可能启动失败。
3. 解压出来的文件夹放在**内置存储**上，路径随意，比如根目录下建个 `games` 文件夹归拢所有游戏，之后好找。
4. 尽量不要放在外置 SD 卡：不少机型上模拟器读不到 SD 卡路径，或运行时异常。

解压环节的几个坑，多来源反馈一致：

- **用专门的解压工具**（ZArchiver 这类），手机自带的解压功能偶尔会把资源解坏，表现为解压成功但游戏起不来；
- **套娃压缩包要解两层**：解出来还是压缩包就再解一次，直到看到游戏文件为止；
- **后缀异常的压缩包**（文件名里混了乱码或多余字符）：改回正常的压缩包后缀（`7z`、`rar` 等）再解压；
- 加密压缩包需要解压密码的，密码在你获取游戏的同一处提供；
- 尽量在本机解压，别用「云解压」类在线服务，这类服务容易漏文件。

安卓 14 / 15 上如果应用里浏览不到你放游戏的目录，改放应用专属目录 `Android/data/org.tvp.kirikiri2/files/` 下，再在应用内切到该路径（操作方法见[下载与安装教程](下载与安装教程.md)第四节）。

## 三、启动游戏

1. 打开 XP3Player，进入文件浏览界面。
2. 浏览到你解压好的游戏文件夹。
3. 点击里面的 `data.xp3`——这是绝大多数游戏的启动入口。
4. 目录里没有 `data.xp3` 时，点主程序 `.exe` 文件；部分汉化整合包点的是别的 `.xp3`（比如「启动游戏.xp3」这类名字）。
5. 第一次进入游戏前可能弹出一个简短的使用说明页，点右上角的关闭按钮（X）关掉即可。
6. 等待加载完成，进入游戏画面。

点 `data.xp3` 报错、或点了没反应，多半不是你操作错了，而是游戏封包加密或用了模拟器没实现的插件——排错方法见[闪退与常见问题处理](闪退与常见问题处理.md)。

## 四、触屏手势与鼠标的对应

Kirikiri 游戏原本靠鼠标操作，模拟器把手势映射成这样：

| 你在屏幕上的动作 | 对应的鼠标行为 |
| --- | --- |
| 单指点一下 | 鼠标左键单击 |
| 双指同时按屏幕 | 鼠标右键 |
| 单指长按后拖动 | 鼠标左键拖拽 |
| 虚拟鼠标模式下：单指按住不动 | 左键按住拖动 |
| 虚拟鼠标模式下：双指按住不动 | 右键拖动 |
| 手机返回键 | 键盘 ESC |

游戏进行中呼出模拟器自己的菜单（存读档、文字速度、虚拟鼠标、虚拟键盘、窗口大小调整都在里面）。最常见的呼法：游戏画面是方形而手机屏幕是长形，画面外会留出黑色区域，**在黑色区域向上滑**就出菜单；你的机型若不是这个布局，再试屏幕底部上滑或应用内的菜单按钮。需要输入名字、处理要右键的界面时，先从菜单里把虚拟键盘或虚拟鼠标调出来。

## 五、存档怎么处理

- 游戏内自带的「保存」按钮由游戏脚本控制，正常点就行；个别游戏点保存会闪退，这是已知情况，改用模拟器菜单里的系统存档功能保存。
- 存档位置：绝大多数 Kirikiri 游戏把存档写在游戏目录下的 `savedata` 文件夹里，备份、换机迁移、放现成存档都围绕它操作，完整方法见[存档位置与备份迁移](存档位置与备份迁移.md)。
- 全局设置对所有游戏生效，游戏内菜单只对当前游戏生效，模拟器没有「每个游戏各自记住设置」的机制，换游戏后设置要看一眼。
- 存档跟着游戏目录走：搬动或重命名游戏文件夹，存档就跟着去了新位置；只搬目录不搬存档，等于从头开始。

画面卡、文字显示不对这类体验问题，去[画面与操作设置](画面与操作设置.md)里调渲染和字体，基本都有解。
