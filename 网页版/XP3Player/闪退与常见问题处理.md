# XP3Player 闪退与常见问题处理

> 本篇把 XP3Player 最常见的几类故障集中处理：先给速查表，再逐条讲具体怎么排。

先按现象对号入座，查不出结果的再往下翻对应小节。多数故障的根源只有四个：权限没给够、渲染模式不合适、封包加密、字体缺失。

## 一、速查表

| 现象 | 常见原因 | 先试什么 |
| --- | --- | --- |
| 应用列表是空的 | 没有「所有文件访问」权限 | 系统设置里给 XP3Player 开所有文件访问 |
| 一打开游戏就闪退 | 渲染模式不兼容 | 全局设置切回软件渲染 |
| 点 data.xp3 报错 | 封包加密 / 插件没实现 | 看第三节，需要对应的 xp3filter.tjs |
| 文字被裁掉一半或显示方块 | 缺 CJK 字体 | 游戏目录放 default.ttf，或设置里换字体 |
| 转场卡、动画慢 | OpenGL 下纹理过大 | 把 Max Texture Size 降到 2048 或切回软件渲染 |
| 点游戏内「保存」闪退 | 个别游戏脚本与模拟器不合 | 改用模拟器菜单里的系统存档 |
| 弹出提示后退出 | 游戏文件损坏（占大头） | 重新获取游戏文件，无效再换模拟器版本 |
| 部分音乐或音效没声音 | CD 音轨 / MIDI 播放被忽略 | 属机制限制，见第八节 |

## 二、列表空白、浏览不到游戏

1. 手机 设置 → 应用 → XP3Player → 权限 → 文件与媒体，安卓 14 / 15 上打开「允许管理所有文件」。
2. 授权后仍看不到部分目录的，把游戏文件夹移到 `Android/data/org.tvp.kirikiri2/files/` 下，再在应用内切到该路径。
3. 确认游戏是**完整解压**出来的文件夹，而不是只拷了一个 `data.xp3` 进去。

## 三、点 data.xp3 报错

这一步报错最常见的原因是**封包加密**：不少商业游戏对 `.xp3` 包做了加密，直接点会提示错误。模拟器为此设计的解法是 `xp3filter.tjs`——把对应游戏的解密脚本文件放进游戏目录再启动（这个机制本身见[引擎与游戏兼容性](引擎与游戏兼容性.md)第四节的说明）。

几个要点：

- 解密脚本要与游戏一一对应，用错游戏的 filter 没有用；
- 你获取游戏时所用的资源方通常会同时提供这个文件，**没有它就没有正常途径让这个游戏跑起来**；
- 除报错信息里有明确插件提示外，别急着怀疑模拟器坏了——先确认文件名、位置都对。

另一类报错指向插件：游戏用了模拟器没有实现的自定义插件，这种情况换补丁、换版本都解决不了，只能放弃这一个游戏（详见[引擎与游戏兼容性](引擎与游戏兼容性.md)第五节的不支持清单）。

还有两组高频「脚本异常」的对应关系，多来源反馈基本一致：

- **弹出提示后退出**：大头是游戏文件损坏——下载、复制、移动任何一步都可能弄坏文件，先重新获取一遍完整游戏文件再试；重新获取后依旧弹的，换个模拟器版本试；
- **提示程序不兼容**：把该游戏对应的 `patch.tjs` 放进游戏目录（这个补丁文件的机制见[引擎与游戏兼容性](引擎与游戏兼容性.md)第四节）。

## 四、打开就闪退、游戏中闪退

1. **先动渲染模式**：全局设置里把渲染器切回软件渲染。OpenGL 渲染官方就注明兼容性不如软件渲染，闪退先怀疑它。
2. 启动后长时间停在加载界面的，重启一次手机再试；同时确认游戏在内置存储而不是 SD 卡。
3. 上面都无效时，换一个模拟器版本再试：1.2.6、1.3.4、1.4.0 这些版本对个别游戏的兼容性有差异，同一游戏「这个版本闪退、那个版本正常」的情况真实存在。

## 五、文字显示异常

- 文字被裁掉下半截、整行方块或问号，基本都是字体问题。在游戏目录里放一个 `.ttf` 字体文件并改名为 `default.ttf`，需要能覆盖中文的字库；
- 也可以在全局设置里选择字体或强制使用默认字体；
- 具体设置项的位置见[画面与操作设置](画面与操作设置.md)。

## 六、卡顿、转场慢

1. 已开 OpenGL 的，把 Max Texture Size 降到 2048 试；
2. 还不行就切回软件渲染对比，两个模式各有牺牲，选不卡的那个（取舍表在[画面与操作设置](画面与操作设置.md)第二节）；
3. 个别游戏用了标注 soft 的特效插件，这类插件只在软件渲染下工作——用 OpenGL 时相关画面失效甚至出错，切回软件渲染反而正常。

## 七、存档问题

- 点游戏内「保存」就闪退：改用模拟器呼出菜单里的系统存档，效果等同，只是入口不同；
- 存档在哪、怎么备份迁移：绝大多数 Kirikiri 游戏把存档写在游戏目录下的 `savedata` 文件夹里，备份、换机迁移、放现成存档都是围绕它操作，完整做法见[存档位置与备份迁移](存档位置与备份迁移.md)；
- 游戏目录搬动过之后读不出旧存档：把存档文件夹随游戏一起搬回原位、保持目录名一致即可。

## 八、没声音或部分音频无声

1. **只有某几段 BGM 或音效无声**：这类游戏用了 CD 音轨或 MIDI 播放，模拟器把相关请求直接忽略（官方写明的机制，归入[引擎与游戏兼容性](引擎与游戏兼容性.md)第五节的不支持清单），不是故障，也没有设置能救回来；
2. **完全没声音**：先把手机的媒体音量调高，再检查游戏自带的音量选项——它由游戏脚本提供，位置每个游戏不一样，通常在游戏设置或系统菜单里；
3. **过场动画放不出来或没声音**：模拟器用 libavcodec 解码音视频，格式覆盖面很大，但对设备性能有要求——关掉后台应用再试；个别老游戏用的封装格式实在放不出的，跳过动画不影响流程。

以上都试过还不行的，把现象、游戏来源标注、你当前的版本号对一遍[引擎与游戏兼容性](引擎与游戏兼容性.md)里的清单，确认它属于「本来就不支持」的那一类，就不用再耗时间了。
