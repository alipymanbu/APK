搞清楚「它到底模拟什么」能省掉大量无效折腾：XP3Player 只服务一个引擎家族，游戏对不对口一眼就能判，判不出来才需要往下读。本篇把判别方法、补丁机制和不支持清单一次讲完。

## 一、Kirikiri 是什么引擎

Kirikiri（吉里吉里，圈内常写 Krkr）是日本开发者 W.Dee 的开源游戏引擎，大量同人游戏和相当数量的商业作品用它开发。它的游戏资源打包成 `.xp3` 封包，游戏目录里最常见的入口文件就是 `data.xp3`。

XP3Player 对应的开源项目是 Kirikiroid2：把 Kirikiri2 / KirikiriZ 移植到安卓的运行器，代码与版本发布都在 [`https://github.com/zeas2/Kirikiroid2`](https://github.com/zeas2/Kirikiroid2)，官方应用页也在 [Google Play](https://play.google.com/store/apps/details?id=org.tvp.kirikiri2) 上。项目的更新节奏以仓库页面显示为准。

## 二、名字为什么这么多

XP3Player、Kirikiroid2、吉里吉里2模拟器、KRKR模拟器——这些名字指的是同一个应用，只是各分发渠道和整合包叫法不同。认 **包名 `org.tvp.kirikiri2`** 最保险，安卓设置里的应用信息能直接看到。

版本号方面，网盘里这一版是 1.4.0.avn；社区常见的分发版本还有 1.2.6、1.3.4 等，不同版本对个别游戏的兼容性有差异，遇到顽固问题换个版本试是常规手段（见[闪退与常见问题处理](闪退与常见问题处理.md)第四节）。

## 三、怎么判断一个游戏能不能跑

按证据强弱排：

1. **看目录**：文件夹里有 `.xp3` 文件（尤其 `data.xp3`）→ 基本能跑；
2. **看标注**：资源方标了 KrKr / 吉里吉里 / Kirikiroid2 版 → 明确能跑，其中「Kirikiroid2 版」整合包通常已带好补丁，拿来就能玩；
3. **反例排除**：目录里是 `.rpa`（Ren'Py）、Unity 的数据文件、RPG Maker 的资源结构 → 跑不了，别浪费时间。

只有 `.exe` 没有 `.xp3` 的情况也值得试一下：少数游戏的封包内嵌在主程序里，模拟器支持直接点 `.exe` 启动，跑不跑得起来点了就知道。

## 四、加密封包与三个补丁文件

模拟器为应对 Kirikiri 游戏常见的封包加密与定制留了三个脚本接口，全部放在**游戏目录**里生效（与 `data.xp3` 同级）：

| 文件 | 作用 |
| --- | --- |
| `xp3filter.tjs` | 解密加密过的 `.xp3` 封包——点 `data.xp3` 报错时首先怀疑缺它 |
| `patch.tjs` | 存在时会在游戏启动脚本之前执行，整合包常用它来挂补丁 |
| `RegisterData.tjs` | 模拟 Windows 注册表，个别游戏读注册表键值时需要 |

这三个是模拟器设计好的机制，不是外挂。`xp3filter.tjs` 与游戏一一对应，通常由你获取游戏的地方随包提供；没有对应文件时，这个游戏就没有正常途径可以启动——这属于游戏与模拟器能力边界的问题，不必再折腾模拟器设置（排查流程见[闪退与常见问题处理](闪退与常见问题处理.md)第三节）。

## 五、明确不支持的部分

以下几类是官方说明里写明的边界，遇到对应症状可以直接放弃排查：

- **外部插件模块**：模拟器只有硬编码的内置插件（addFont、json、krmovie、sqlite3、wuvorbis、layerEx 系列等），游戏若用了清单之外的自定义插件，跑不起来；
- **部分插件只在软件渲染下可用**：官方标注 soft 的插件在 OpenGL 模式下不工作，相关画面会失效或出错；
- **CD 音轨与 MIDI 播放**：相关请求会被直接忽略，游戏里表现为对应音频无声；
- **没有文本输入框、字体/文件选择对话框、控制台**：需要键盘输入的场景走模拟器自带的虚拟键盘。

商业游戏多用自定义扩展插件，其中大多数无法在模拟器上运行——这不是版本问题，是插件没有实现，换版本、打补丁都改变不了结论。

## 六、拿到游戏的推荐路径

资源标注「Kirikiroid2 版」或「已带补丁」的最省事，解压即玩；只标 KrKr 的，先按第三节判别，报错再按第四节补 filter。安装运行器本身见[下载与安装教程](下载与安装教程.md)，游戏怎么放、怎么点见[导入游戏教程](导入游戏教程.md)。
