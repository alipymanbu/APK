# Campus 常见问题与故障排查

## 一、按症状对号入座

| 症状 | 先看哪节 |
| --- | --- |
| 点安装没反应 / 提示禁止安装 | 二 |
| 打开就闪退、白屏 | 三 |
| 收不到验证码、登不上 | 四 |
| 认证一直不通过 | 五 |
| 发不出内容、功能入口消失 | 六 |
| 地图空白 / 页面一直转圈 | 七 |

## 二、安装失败

1. **提示「禁止安装来自此来源的应用」**：给当前来源（浏览器或文件管理器）授予「安装未知应用」权限后重试，步骤见 [下载与安装教程.md](下载与安装教程.md) 第四节。
2. **提示解析错误 / 安装包损坏**：多半是下载不完整。对照大小 136.28M 重新下载；需要重新拿安装包时，入口是 [Campus 安装文件资源（夸克网盘）](https://pan.quark.cn/s/119c93de0fd1)。
3. **提示空间不足**：先清理出 1GB 以上空间再装（安装包本身 136.28M，解压安装后占用更大）。
4. **系统版本过低**：安装记录标注需要安卓 5.2 以上；更低版本装不上属于硬件限制，换机或用网页版前的其他途径之前，先确认系统版本（设置 → 关于手机）。

## 三、闪退、白屏、卡顿

按成本从低到高试：

1. **清缓存**：设置 → 应用 → Campus → 清除缓存（**先别清数据**，清数据要重新登录）；
2. **确认空间**：可用空间不足会导致地图资源加载失败、启动即退；
3. **重启手机**后再开；
4. **升级到新版本**：如果你用的是网盘里那份较早的版本（1.2.0），而应用内已提示更新，先升级再判断是不是设备问题；
5. **重装**：以上都无效就卸载重装（卸载前确认聊天记录是否需要 —— 聊天数据存云端还是本地，以应用内实际行为为准）。

## 四、登录与验证码

- **收不到短信验证码**：等 60 秒后重新获取；检查手机是否停机、是否装了拦截短信的应用；换 Wi-Fi / 数据网络再试一次（运营商通道偶尔会卡）。
- **换号登不上**：Campus 账号绑定手机号，换号后一般需要走应用内的账号申诉或换绑流程，入口在登录页或设置里，按界面提示操作。
- **提示账号异常**：不要反复重试触发限制，等一段时间再试，或通过应用内反馈渠道联系处理。

## 五、校园认证不通过

1. 确认**学校、学院、专业、年级**填写与学籍一致（见 [注册登录与校园认证.md](注册登录与校园认证.md) 的四步流程）；
2. 确认选的是你实际就读的**校区**，选错学校会导致核验对不上；
3. 换一种认证方式再试（界面提供多种验证方式）；
4. 以上都对仍不通过，属于人工/系统核验问题，通过应用内反馈渠道提交，不要反复提交同一条信息。

## 六、发不出内容 / 功能入口找不到

- **评论、发动态没反应**：先看校园认证是否已通过 —— 未认证只能浏览（[注册登录与校园认证.md](注册登录与校园认证.md)）；
- **课表、校园卡等入口不存在**：多半是学校尚未接入或你的认证状态不满足，不是安装问题（[课表与校园服务功能.md](课表与校园服务功能.md) 第六节）；
- **被限制发帖**：短时间大量发帖/评论可能触发风控，停一会儿再发。

## 七、地图空白、一直加载

1. 检查网络（校园网 captive portal 未认证时会一直转圈）；
2. 检查定位权限是否授予：设置 → 应用 → Campus → 权限 → 位置信息；
3. 新校区或新学校点位本来就少，先确认不是「数据少」被误当成「加载失败」。

## 八、还是解决不了

把**具体提示原文**（弹窗文字、发生步骤、手机型号与系统版本）记下来，通过应用内的反馈/客服入口提交。定位问题时，安装包信息可以一并附上：版本 1.2.0、包名 `com.kairuotu.campus`（若你已经升级过版本，以应用内「关于」页显示的为准）。
