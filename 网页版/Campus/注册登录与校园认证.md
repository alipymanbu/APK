# Campus 注册登录与校园认证

> 第一次打开 Campus 要做的三件事：登录、选学校、通过校园认证。

## 一、这篇解决什么

Campus 的内容圈层只对本校学生开放，所以「你是谁、你在哪所学校」是绕不开的两步。这篇按实际点击顺序讲：怎么登录、怎么选学校、校园认证填什么、认证不通过怎么办。账号还没装好就卡住的话，先看 [下载与安装教程.md](下载与安装教程.md)。

## 二、登录

1. 同意隐私协议后进入登录页，点击「登录账号」。
2. 目前可见的登录方式是**手机号 + 短信验证码**（第三方商店的操作说明里也是这么演示的）。
3. 输入手机号 → 收验证码 → 填入即完成注册兼登录，首次登录自动创建账号。

手机号就是这个账号的本体：换号、注销、以及登录后应用会围绕账号收集哪些数据，都和它绑在一起 —— 数据范围与权限开关见 [隐私与权限设置.md](隐私与权限设置.md)。收不到验证码、换了手机号登不上这类问题，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 三、选择学校

登录后的第一件事是**选择你的学校**：

- 搜索框输入学校名，点选自己的校区（部分学校有多个校区，别选错 —— 内容圈层按学校划分，选错了看到的就是别的学校的动态）。
- 选定后进入校园圈，此时你可以**浏览**本校同学发布的动态。
- 想**发布**内容、评论、加好友，要先做下一步的校园认证。

## 四、校园认证（四步）

按应用内的实际入口走：

1. 点击界面**右上角头像**，进入个人中心；
2. 点击「**校园认证**」进入认证流程；
3. 填写**学校、学院、专业、年级**；
4. 选择一种认证方式完成验证，通过后即可在校园内发布动态。

关于这一步的常见卡点：

| 情况 | 说明 |
| --- | --- |
| 找不到认证入口 | 认证按钮在个人中心里，先进右上角头像页 |
| 信息填错 | 学院/专业/年级填错可能通不过核验，重新提交即可 |
| 认证方式二选一 | 界面会给出可选的验证方式，按提示选一种完成 |
| 一直不通过 | 见 [常见问题与故障排查.md](常见问题与故障排查.md) |

## 五、学校列表里搜不到自己的学校

认证的前提是先选到学校，搜不到就走不完认证，也就发不了内容。按这个顺序处理：

1. **换写法再搜一遍**：全称、简称、带不带「大学」都试一次 —— 名单里的校名写法未必和你口语里的一致；
2. **确认不是选错了地区/校区**：有的学校多校区分别收录；
3. **仍搜不到 = 应用还没收录**：这不是你的操作问题。App Store 上有用户评论要求增加港澳地区的高校（有用户反馈，截至 2026-09），说明名单本身在随版本增补 —— 以应用内搜索结果为准，同时可通过应用内反馈渠道提交你的学校名；
4. 认证要绑定学校，选不到就走不完认证 —— 在收录之前，发布相关功能都用不了。

换学校（转学、读双学位）没有查到公开的自助切换入口，别自己反复重装或换号硬试 —— 直接走应用内反馈渠道问一句最快。

## 六、认证之后你能做什么

- 在校园圈发帖、评论、给同学点动态；
- 用聊天功能加同校好友私聊；
- 在地图上标记地点、发布带位置的内容；
- 参加学校、社团或同学发起的活动报名。

其中地图与动态的具体玩法在 [校园地图与动态使用指南.md](校园地图与动态使用指南.md)，课表、校园服务类功能在 [课表与校园服务功能.md](课表与校园服务功能.md)。
