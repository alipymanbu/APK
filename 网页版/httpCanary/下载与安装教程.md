## 一、先弄清楚这是个什么东西

HttpCanary（中文圈常叫「小黄鸟」或「黄鸟抓包」）是一款安卓上的网络抓包工具：它在手机里开一条本地 VPN，把设备上各个应用发出的 HTTP、HTTPS、WebSocket、TCP/UDP 请求接住，再摊开给你看参数、响应体、耗时。典型场景是调试自己写的接口、看某个应用在后台请求了什么、复现一个只在手机上出现的网络问题。

装之前有两件事你得先知道：

- **官方已停止更新**。HttpCanary 官方站点 [www.httpcanary.com](https://www.httpcanary.com/zh-hans/) 的公告写明：该应用已停止更新和维护（最后的版本号 3.3.6），并已从各应用商店下架。作者后来转向了新项目 Reqable。所以你现在装到的版本、以及后面还会不会有新版，都以你手上这份文件为准。
- **它对系统版本敏感**。安装包本身对手机要求不高，但要抓到 HTTPS 明文，Android 7.0 及以上还要额外装一次证书 —— 那一步单独写在 [HTTPS证书安装与配置.md](HTTPS证书安装与配置.md)，**没做那一步，抓到的 HTTPS 请求全是密文**。

## 二、拿安装包

打开 [httpCanary 安装文件资源（夸克网盘）](https://pan.quark.cn/s/66f404eb3cf6)，转存到自己的网盘后下载 APK 到手机。网盘里这一份的实际参数如下，下载完照着核对：

| 项 | 值 |
| --- | --- |
| 版本 | 9.9.9.9 |
| 包名 | `com.guoshi.httpcanary` |
| 大小 | 12.45M |
| MD5 | `BFC85195A7D0C36AB8B4CE62E177D4AA` |
| 记录日期 | 2026-09-21 |

版本号会随文件更新而变化，以网盘里当时显示的为准；上面这张表记录的是本次存档那一份。要确认文件没下坏，看大小是否接近 12.45M，或者在电脑上算一次 MD5 与表里比对。

包名 `com.guoshi.httpcanary` 也用得上 —— 后面在设置里「目标应用」按名字找不到时，按包名搜就是它。

## 三、安装步骤

1. APK 下到手机后，从浏览器的下载列表点开它；或用文件管理器进「下载」目录点这个文件。
2. 系统会拦一道「禁止安装来自此来源的应用」—— 这是装任何商店外 APK 都会遇到的。在弹窗里点「设置」，允许当前这个来源（浏览器或文件管理器）安装未知应用，再返回。
3. 回到安装页点「安装」，等进度走完。
4. 点「打开」直接进，或者回桌面找图标。

装完可以把安装包删掉，不影响已装的应用。升级时如果提示签名不一致，说明你前后装的是不同来源签的包，先卸载旧的再装新的 —— 卸载会清掉 HttpCanary 内部保存的抓包记录，重要的记录先导出，见 [抓包过滤与数据查看.md](抓包过滤与数据查看.md)。

## 四、第一次打开要做的事

首次启动会依次过一遍许可协议和初始化，按顺序会碰到这几个东西：

1. **用户许可协议**：点同意才能往下走。
2. **配置 VPN**：HttpCanary 靠一条本地 VPN 接管流量，点「配置」授权即可。这条 VPN 只在本机生效，不经过外部服务器。系统每次启动它都会问一次「是否允许建立 VPN 连接」，允许才有抓包。
3. **安装 CA 证书**：初始化里会引导你装根证书。**这一步在 Android 7.0 以上常常装不进系统**，提示失败很正常，可以先跳过，回头按 [HTTPS证书安装与配置.md](HTTPS证书安装与配置.md) 里的路子装 —— 不过在证书就位前，HTTPS 请求你只能看到密文。
4. **通知权限**：系统若弹出，建议允许 —— 抓包进行中能从通知栏直接看到状态，比切回 App 确认快。

进去以后是列表页：左上角是抽屉菜单（设置从这进），右下角是那个标志性的小飞机按钮，点它开始/停止抓包。

## 五、系统要求与权限

| 项 | 情况 |
| --- | --- |
| 安卓版本 | 各分发页普遍标注 Android 5.0 及以上（推荐 7.0+）。以安装时系统的实际提示为准 |
| 设备 | 真机与主流模拟器都能跑；模拟器上要抓 HTTPS 一样要处理证书 |
| 网络 | Wi-Fi 与蜂窝数据都可以 |
| Root | 不是硬性要求，基础抓包免 Root；**但把根证书装进系统目录这类操作需要 Root** |
| 权限 | VPN、通知、存储（导出文件与证书） |

## 六、证书还没装好，先别急着抓

装完 App ≠ 能看到明文。判断顺序很短：

- 手机能上网、HttpCanary 列表里也有条目 → 说明 VPN 通了，往下查证书；
- 列表一条都没有 → 是抓包本身没起来，见 [抓不到包怎么排查.md](抓不到包怎么排查.md)；
- 列表有条目但 HTTPS 的响应体是乱码/密文 → 就是证书问题，照 [HTTPS证书安装与配置.md](HTTPS证书安装与配置.md) 装。

证书这一步是一次性的，装好之后每次开抓包都不用再动。
