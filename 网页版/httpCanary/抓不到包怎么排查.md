## 一、先花十秒分类，别瞎试

开着抓包、操作一遍目标应用，回来看列表，然后按现象走：

| 现象 | 属于哪类 | 去哪节 |
| --- | --- | --- |
| 列表**一条都没有** | 流量根本没进来 | 第二节 |
| 有条目，但 HTTPS 响应体是**密文 / 乱码** | 证书没被信任 | 第三节 |
| 有条目、有明文，但**某个应用就是抓不到** | 目标做了防护 | 第五节 |
| 提示**证书安装失败**、找不到文件 | 证书装不上 | 第四节 |
| 打不开、闪退、记录存不下来 | 环境与权限 | 第六节 |

分类错了，后面每一步都是白试。最常见的两类是「一条都没有」和「只有密文」，先解决这两类。

## 二、列表一条都没有

按顺序查，查到哪步停在哪步：

1. **VPN 授权给了吗**：启动抓包时系统会弹「允许 HttpCanary 建立 VPN 连接吗」，点了拒绝就是空的。去系统设置 → 网络和互联网 → VPN，确认状态。
2. **抓包真的开着吗**：看右下角按钮形态与通知栏常驻提示；有的手机会「省电策略」把后台的 VPN 杀掉 —— 在系统里把 HttpCanary 设为**不限制后台 / 允许自启动**，并从后台划掉重开一次。
3. **过滤条件收太死了**：设置 →「目标应用」如果只勾了 A，你却在操作 B，自然是空的。同理查「目标 Host」。**排查时先把两个都清空**，能出包了再逐个加回去。
4. **先清后台再复现**：目标应用如果在抓包启动前就建好了连接，那条连接可能不走你这条 VPN。把它从后台彻底划掉，重新打开再操作。
5. **换个验证对象**：用手机浏览器随便访问一个 https 网站。浏览器有包而目标应用没有 → 问题在目标应用（跳第五节）；浏览器也没有 → 回第 1～3 步。
6. **网络本身通不通**：飞行模式开一下关掉，或换 Wi-Fi / 流量试。手机上不了网时抓包列表当然是空的，这跟工具无关。

## 三、有流量但 HTTPS 全是密文

说明 VPN 通了，只是**解密那一环没成**。按这个顺序：

1. 设置 →「SSL 证书设置 / HttpCanary 根证书」看状态。显示未安装 → 照 [HTTPS证书安装与配置.md](HTTPS证书安装与配置.md) 从第二节开始装。
2. 显示已安装、但 Android 7.0+ 上仍解不开 → **用户证书不被系统信任**，这是 Android 7.0 起的规则，不是故障。走该篇第四节把根证书移进系统目录（需要 Root），或走第五节的替代路子。
3. 移进系统后**重启 HttpCanary**，有些机型还要重启手机才认。
4. 明文出来了但**个别请求仍密文** → 那些请求可能走了别的通道（例如应用内嵌的自定义协议），或目标应用做了校验，跳第五节。
5. 顺带确认一下：不是你把「目标 Host」配成了只匹配某个域名，把正在测的接口排除在外了。

**浏览器提示「连接不是私密连接 / 证书不受信任」是正常的** —— 它不认你自签的根证书。这只影响浏览器自己，不影响 HttpCanary 抓包，可以直接继续；介意的话把根证书装成用户证书通常能消除提示。

个别浏览器还自带一套证书库，不吃系统的设置：Firefox 类要用自己的开关去信任第三方证书（一般在设置的隐藏/调试项里）；个别新版 Chrome 会忽略某些自签根证书，遇到就系统证书、用户证书各装一次试。

## 四、证书根本装不上

- **安装时提示「安全性提醒 / 数据不再是私密的」**：点「仍然安装」，这是系统对导入根证书的例行提示。
- **在文件选择器里找不到导出的证书**：系统选择器进不去应用私有目录。把 `HttpCanary.pem` 复制到「下载」目录，再从那里选，见 [HTTPS证书安装与配置.md](HTTPS证书安装与配置.md) 第二节。
- **菜单里没有「从存储安装 CA 证书」**：不同品牌叫法不同，在系统设置里搜「证书」或「凭据」关键词；也有的机型藏在「安全 → 更多安全设置 → 加密与凭据」下面。
- **装了立刻又消失 / 提示失败**：部分机型的 ROM 会拦截用户 CA，或要求同时装 `.pem` 与 `.p12`。都试一遍仍失败，就走 Root 移系统目录那条路 —— 那条不经过系统的选择器。
- **Root 下点「移动」报错**：system 分区不可写。改用 Magisk 模块方案（该篇第四节第 2 组步骤）。

## 五、只有某个应用抓不到：固定证书

现象很典型：其他应用都正常，**唯独这一个**要么不出包、要么出包但解不开，日志里能看到类似「目标 App 使用了固定证书」的提示。

原因：这个应用在校验服务端证书是不是它认可的那张，你签的证书过不了它这一关。这属于应用自己的防护，装系统证书解决不了。

可行的方向：

- **你开发的应用**：在它的网络安全配置里信任用户证书，或调试期关掉校验 —— 这是最干净的做法。
- **第三方应用**：要继续抓，得在**已 Root、带 Xposed 类框架**的环境里加装对应模块才能让它的校验放行。这套操作只对你有权测试的应用做，且会改动系统环境，心里有数再动；不想折腾 Root 的话，接受「这个应用抓不了」也是合理选择。
- **换了路子仍不行**：改用电脑侧的代理方案（如 Reqable 这类桌面工具 + 手机 Wi-Fi 代理），有时能覆盖手机上抓不到的场景。

## 六、装不上、闪退、记录存不下来

| 现象 | 处理 |
| --- | --- |
| 安装时提示「禁止安装未知应用」 | 允许当前来源（浏览器/文件管理器）安装未知应用后重装 |
| 升级提示签名不一致 | 前后两个包来源不同签名。先卸载再装；**卸载会清空已抓的记录**，重要的先导出，见 [抓包过滤与数据查看.md](抓包过滤与数据查看.md) 第五节 |
| 打开就闪退 / 白屏 | 先清一次应用缓存；仍崩则卸载重装（同上，先看有没有要留的记录）。安卓版本过低或 ROM 过新都可能，装的时候系统给的兼容提示要当真 |
| 抓得到但保存 / 导出失败 | 系统设置 → 应用 → HttpCanary → 权限，把存储（文件与媒体）设为允许 |
| 记录刷新不全、时间对不上 | 看设置里的 DNS 项，解析异常会让部分请求显示异常；换个内置 DNS 再复现一次 |
| 列表越用越卡 | 记录太多，一次排查完就清空，重要的导出走人，见 [抓包过滤与数据查看.md](抓包过滤与数据查看.md) 第六节 |

## 七、什么时候该换路子

- **所有应用同时失效、昨天还好好的** → 多半是系统更新或 ROM 收紧了证书策略，先按第三节重走一遍证书流程，再考虑 Root 方案。
- **只有新装的那个应用不行** → 是它做了防护，第五节。
- **证书这条路反复走不通**（无 Root、ROM 又不让装）→ 别硬耗，改用桌面代理方案，或者在模拟器里开 Root 做一次到位的配置 —— 模拟器那套流程在 [HTTPS证书安装与配置.md](HTTPS证书安装与配置.md) 第四节末尾。
