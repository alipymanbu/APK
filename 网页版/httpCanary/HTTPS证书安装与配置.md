# HttpCanary HTTPS 证书安装与配置

> 本篇讲怎么把 HttpCanary 的根证书装进手机，让你能看懂 HTTPS 请求的明文 —— 免 Root 和 Root 两条路都写。

## 一、为什么必须做这一步

HttpCanary 解 HTTPS 的办法是中间人：它在你手机本地生成一张自己的根证书，用它给每个 https 站点现场签一张证书。手机信了这张根证书，才肯把解出来的明文交给你看。

问题出在系统那侧：**Android 7.0 起，系统默认不再信任「用户自己安装」的 CA 证书**，只认出厂就带的系统证书。于是就会出现你装了证书、App 里也显示已安装，抓到的 https 请求响应体却还是密文 —— 不是没抓到，是解不开。

所以这一整篇要解决的就一件事：**让你的根证书被信任**。两条路：

| 你的设备 | 走哪条 |
| --- | --- |
| Android 6.x 及以下 | 装成用户证书就够，第三节做完即可 |
| Android 7.0+，没有 Root | 第三节先装用户证书，再看第五节的替代办法 |
| Android 7.0+，有 Root | 第三节 + 第四节，把根证书移到系统目录，一步到位 |
| 只是想抓自己开发的应用 | 第六节那条更省事，不用动证书 |

## 二、先导出根证书

1. 打开 HttpCanary，点左上角三条杠打开抽屉，进「设置」。
2. 找「SSL 证书设置」（有的版本叫「HttpCanary 根证书」）→「导出 HttpCanary 根证书」。
3. 选类型：

| 类型 | 装到哪 | 用在什么场景 |
| --- | --- | --- |
| `Privacy Enhanced Mail (.pem)` | 用户证书 | 免 Root 装，Android 6.x 直接可用 |
| `System Trusted (.0)` | 系统证书 | 给 Root 设备 / Magisk 模块用，文件名形如 `<哈希>.0` |

4. 导出的文件落在内部存储的 `/HttpCanary/cert/` 目录下。用文件管理器进去能看到 `HttpCanary.pem`、`HttpCanary.p12`（以及选了 `.0` 时的对应文件）。

顺手把这几个文件复制一份到「下载」目录：证书安装界面按目录翻找时，`Android/data` 与应用私有目录常常进不去，放在「下载」里最省事。

## 三、把证书装成用户证书（免 Root 的基础步骤）

不同品牌菜单名略有差别，按这几个关键词在设置里搜就行：**安全 → 更多安全设置 → 凭据存储 → 从手机储存安装 → CA 证书**。

1. 系统设置里进「CA 证书」项。
2. 弹出「您的数据将不再是私密的」这类提醒，点「仍然安装」（这只是系统对导入根证书的例行警告）。
3. 浏览到你放证书的位置，选 `HttpCanary.pem`。
4. 提示「已安装 CA 证书」即完成。

两个补充：

- **WLAN / VPN 那类证书**用的是 `HttpCanary.p12`，导入时要输密码；常见口径是 `HttpCanary`，以你导出界面当时的提示为准。
- 装完可以在「设置 → 加密与凭据 → 用户凭据」里看到它 —— 有，就说明装进去了。**但「用户凭据里有」不等于「https 能解密」**，Android 7.0+ 还差第四节那一步。

## 四、Root 设备：把根证书移进系统目录

这是 Android 7.0+ 上唯一能让系统真正信任它的常规做法。

**先走 App 内置的路（最快）：**

1. 设置 →「HttpCanary 根证书」→「添加根证书至系统（Root）」→ 点「移动」。
2. 弹出 Root 授权请求时点允许。
3. 回到设置页看状态，显示已加入系统即可，重启 HttpCanary。

**内置按钮报错（提示 system 分区不可写之类）时走 Magisk 模块：**

1. 确认设备有 Magisk，并且已经装好上一节的用户证书 —— 装完后 `/data/misc/user/0/cacerts-added/` 下会多出一个 `.0` 结尾的文件。
2. 把这个 `.0` 文件放进一个 Magisk 模块包的 `system/etc/security/cacerts/` 目录里（模块包就是个 zip，用文件管理器改后缀打开即可）。
3. Magisk → 模块 → 从本地安装 → 选这个包 → 装完重启。
4. 重启后用文件管理器看 `/system/etc/security/cacerts/`，里面有那个 `.0` 文件就算成了。

模拟器（MuMu、雷电等）上也是同一套：先在模拟器设置里打开「可写系统盘」与 Root，再按上面第 1 步点「移动」，授权后重启 HttpCanary。

## 五、没有 Root 怎么办

按省事程度排：

1. **只抓自己的应用**：在 `AndroidManifest.xml` 里配 `networkSecurityConfig`，同时信任 `system` 与 `user` 两类证书，这个应用的 https 就能被解开。这条只对你自己开发、且只在调试期用，发布前要去掉。
2. **用虚拟环境跑目标应用**：HttpCanary 的设置里能装 VirtualApp，把目标应用装进 VirtualApp 再从里面启动 —— 虚拟环境自己信任用户证书，等于绕开了系统那条限制。代价是多一层、性能有损耗，且不是每个应用都能在里面正常跑。
3. **换设备或用模拟器**：找一台能刷 Root 的备用机、或直接用带 Root 开关的安卓模拟器，按第四节做一次，一次到位。

顺便一提，还有个不改系统的笨办法：在一台能装系统证书的设备上装好证书、备份 HttpCanary 的应用数据，再把备份恢复到目标手机 —— 证书随数据一起过去。各家备份工具路径不同，只适合手头正好有现成备份功能的情况。

## 六、装完怎么验证

1. 打开 HttpCanary → 设置 →「HttpCanary 根证书」，状态显示已安装/已加入系统。
2. 开抓包，用手机浏览器访问任意 https 站点。
3. 回列表看那条请求：**能看到 URL、请求头、响应体明文 = 成功**；只有 `CONNECT` 或响应体是密文 = 没成，回到 [抓不到包怎么排查.md](抓不到包怎么排查.md)。
4. 浏览器提示「连接不是私密连接」也属正常 —— 它不认你这张自签证书；这只影响浏览器自己，不影响 HttpCanary 解包。

## 七、想撤销的时候

系统设置 → 加密与凭据 →「删除凭据」，可以移除已装的用户证书。Root 设备把 `/system/etc/security/cacerts/` 里对应的那个 `.0` 删掉（或卸掉那个 Magisk 模块）再重启即可。

抓包证书是你自己签的、只在本机起作用，装着不会影响别的应用联网；但**只在需要抓包的设备上装**，抓完移除，是个好习惯。
