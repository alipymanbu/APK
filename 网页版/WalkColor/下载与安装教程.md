## 一、先确认你要装的是哪一份

WalkColor 是一款安卓端的波点拼贴图片创作工具：你导入一张照片，叠上色块、撒一层镂空形状、打几个字，就能导出壁纸、社交配图、短视频甚至 Live 图。它在苹果 App Store 也有同名应用，但本篇讲的是**安卓 APK 这一份**。

网盘里这份安装包的参数如下，装之前建议先对一遍：

| 项目 | 数值 |
| --- | --- |
| 版本号 | 1.4.0 |
| 包名 | `com.jumang.walkcolorgj` |
| 安装包大小 | 36.05M |
| MD5 | `37708b743e39ba3130fe6e231c30fe87` |
| 开发者 | 苏州聚芒网络科技有限公司 |

包名是安卓系统识别应用的唯一标识，比应用显示名更可靠 —— 网上同名或近名的安装包不止一个，核对时**认包名，别只看图标和名字**。

## 二、从网盘拿到安装包

1. 打开 [WalkColor 安装文件资源（夸克网盘）](https://pan.quark.cn/s/19bf6f4272b0)，把分享内容转存到自己的网盘（不转存也能直接下载，但转存后文件长期有效，不怕分享被取消）。
2. 在网盘里找到应用文件夹，里面是 `WalkColor_v1.4.0.apk` 这样的 APK 文件，外加一个说明 txt。
3. 在手机上打开夸克 App 登录同一账号，找到该文件选择下载；也可以先在电脑上下载，再通过数据线、局域网传输或聊天工具把 APK 发到手机。
4. 下载完成后核对文件大小是否接近 36.05M，明显偏小说明没下完整，重新下一次。

如果你在电脑上校验完整性，可用校验工具对 APK 算 MD5，结果应当是 `37708b743e39ba3130fe6e231c30fe87`；对不上就别装了，重新下载。

## 三、手机上安装步骤

安卓从应用商店之外安装 APK，需要你手动允许一次：

1. 用文件管理器点开 APK，系统会弹「禁止安装来自此来源的应用」—— 这是正常的拦截，不是文件有问题。
2. 按提示进入**设置 → 允许安装来自此来源的应用**（不同品牌手机入口名称略有差异，有的叫「安装未知应用」），给文件管理器或浏览器授一次权，装完可以再关掉。
3. 返回继续安装，等进度走完点「打开」。
4. 首次启动时应用会申请**相册 / 存储权限**，用于读你选的照片和把导出的成品写进相册 —— 拒绝的话你既选不了图也存不了结果，建议允许。

安装卡住或报「解析包出错」，一般是 APK 没下完整或下载被中断，回到第二步重新下载即可；具体更多报错的处理见 [导出格式与常见问题.md](导出格式与常见问题.md)。

## 四、装完核对：确认没装错包

装好后到 **设置 → 应用 → WalkColor → 应用信息**，看一眼详情：

- 包名应显示 `com.jumang.walkcolorgj`；
- 版本号应显示 1.4.0；
- 安装来源是你自己的网盘，而不是来路不明的应用商店。

三项都对，说明装的就是网盘里这一份。若包名对不上（比如显示成别的字符串），说明装到了另一个同名应用，先卸载再重新安装 —— 网上叫 WalkColor 的安装包至少还有两三种不同包名、体积从十几 M 到两百 M 不等，逐一列在 [同名版本区分与选择.md](同名版本区分与选择.md)。装好之后怎么从零做出第一张作品，接 [波点拼贴新手使用教程.md](波点拼贴新手使用教程.md)。
