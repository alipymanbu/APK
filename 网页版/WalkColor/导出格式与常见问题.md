## 一、导出入口与三种格式

作品做完后点右上角黄色的**导出**按钮，导出菜单提供三种格式（实际选项以应用内为准）：

| 格式 | 是什么 | 用在哪 |
| --- | --- | --- |
| PNG | 静态图片，无水印高清 | 手机壁纸、朋友圈 / 小红书配图、头像、贺卡 —— **绝大多数场景选它** |
| MP4 视频 | 动起来的短片 | 短视频平台、想让装饰元素有出场动画时 |
| Live Photo | 动态照片 | 支持实况图的场景；在安卓上导出后的播放效果取决于你用什么应用打开它 |

菜单里通常还有**一键全部导出**：三种格式一次全出，省得来回点。导出前先点顶栏「预览」确认成品，预览看到的就是导出后的画面。

## 二、导出后文件在哪找

导出的作品默认写进手机相册 / 图库，一般在相册里能看到 WalkColor 相关的目录或当天新增的图片。找不到时按这个顺序排查：

1. 打开系统**相册 → 最近**，看有没有刚导出的图；
2. 用文件管理器查 `Pictures`、`DCIM` 目录下 WalkColor 相关文件夹；
3. 都没有 —— 多半是**存储权限没给**。到 设置 → 应用 → WalkColor → 权限 里把「文件和媒体 / 照片和视频」权限设为允许，再导出一次。

MP4 与 Live Photo 同理：视频找不到就看相册的「视频」分类，Live Photo 找不到就换支持实况图的查看方式打开。

## 三、安装与首次使用常见问题

**Q：安装时提示「禁止安装来自此来源的应用」？**
安卓对外部 APK 的常规拦截，不是文件有问题。按提示允许一次该来源的安装权限即可，装完可以关掉，步骤见 [下载与安装教程.md](下载与安装教程.md)。

**Q：报「解析包出错」或装到一半失败？**
一般是 APK 没下载完整。回到网盘重新下载一遍（文件应接近 36.05M），再装。核对包名是否为 `com.jumang.walkcolorgj` 也能帮你确认拿到的是正确的包。

**Q：打开就闪退、或用一会卡死？**
先确认安装包完整、手机存储空间充足；再把应用完全关闭后重开。若是在堆了很多图层的大图上卡，减少装饰数量或关掉分区拼贴再试。问题持续的话，卸载后按 [下载与安装教程.md](下载与安装教程.md) 重装一次。

**Q：选不了照片或导出存不进去？**
相册与存储权限没允许。到系统设置里给 WalkColor 授予照片 / 存储权限，重新进应用操作。

**Q：导出的图有水印吗？收费吗？**
按官方介绍，应用免费、导出不带水印，功能不做分层收费（以你实际安装的版本表现为准）。

**Q：应用里有「说明」和「草稿」两个按钮，是干什么的？**
「说明」是应用内置的操作指引，「草稿」用于保存未完成的作品进度 —— 具体行为以应用内提示为准。日常多用的是顶栏撤销 / 重做与「预览」，操作位置见 [波点拼贴新手使用教程.md](波点拼贴新手使用教程.md)。

**Q：怎么确认自己装的是不是同一份？**
到 设置 → 应用 → WalkColor，核对包名 `com.jumang.walkcolorgj`、版本 1.4.0。网上同名安装包不止一个，认包名最稳妥。

想让导出的成品更好看，配色与构图的技巧在 [手机壁纸与配图制作技巧.md](手机壁纸与配图制作技巧.md)。
