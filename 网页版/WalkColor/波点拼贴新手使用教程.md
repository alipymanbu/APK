## 一、先认识界面：一排按钮 + 四个页签

WalkColor 的编辑界面很简单，你只需要记住两块地方：

- **顶栏**：左边是撤销、重做两个箭头，改坏了随时退回去；右边一排按钮是「说明」「草稿」「预览」「导出」，其中**导出**是黄色高亮的，做完图从这里出去。导出前可以先点「预览」看去掉界面元素后的成品效果。
- **下方四个页签**：**底图、色块、装饰、文字**。一张作品就是按这四层叠出来的 —— 最底下是照片，往上盖色块，色块上挖形状、撒装饰，最上面写文字。

标准流程四步：点「新创作」导入照片 → 在「色块」层铺底色 → 在「装饰」层撒形状 → 到「文字」层写一句话，最后右上角导出。下面逐层拆开讲。

## 二、底图页：换照片与拼贴布局

切到「底图」页签，你会看到这几个控件：

| 控件 | 作用 |
| --- | --- |
| 新创作 | 从相册选一张照片，开始一幅新作品 |
| 换照片 | 保留当前的色块与装饰，只把底图换掉 |
| 加副图 | 再加一张照片进来组合创作，配合分区拼贴做多图排版 |
| 随机配方 / 清除配方 | 没灵感时点「随机配方」，自动生成一套色块与装饰搭配；不满意就「清除配方」重来 |
| 分区拼贴（开关） | 打开后把画布分成多块，可以放多张照片 |
| 复制模式：单图 / 上下 / 左右 | 决定底图是一整张，还是上下两栏、左右两栏排布 |
| 一键清除色块和装饰 | 底图保留，上面叠的东西全部清空，从头再来 |

（部分版本布局略有差异，「配方」相关按钮也可能叫别的名字，以界面实际显示为准。）

新手最常见的用法就是「单图 + 一张照片」。想做双图对比或多图排版时再打开分区拼贴。选图这一步不用追求完美构图 —— 后面的色块和镂空会盖掉大部分背景，主体清楚就够。

## 三、色块页：铺一层底色

「色块」层决定了整张图的色调基调，页面上从上到下是：

1. **锁定底图**开关：打开后底图固定，拖动时只动色块，避免误把照片挪位。
2. **构图**比例：一排预设画幅（如 5:7、3:5、3:4、9:16、4:5），点一下就切换整体画幅。做手机锁屏选 9:16 一类的竖长比例，做社交配图选接近正方的比例。
3. **色块样式**：**纯色** / **条纹**两档切换。条纹会有额外的粗细、倾斜等参数可调。
4. **色块颜色**：色盘直接点选；配色建议优先用自动提取的照片主色调或内置的莫兰迪预设，具体怎么挑见 [手机壁纸与配图制作技巧.md](手机壁纸与配图制作技巧.md)。

色块的位置和大小可以直接在画布上拖，不必拘泥于铺满 —— 只盖住画面某一半、留出照片主体，是很常用的构图。

## 四、装饰页：撒形状，这是 WalkColor 的核心玩法

「装饰」页签负责那层「撒在照片上的形状」，也是这个应用最有辨识度的地方：

- **装饰颜色**：一排色点选当前形状的颜色，旁边还有取色器（从照片上直接吸取颜色）和**「打乱现有颜色」**按钮 —— 不知道配什么时点它一次，整批形状换一套配色，多点几次往往能碰出满意的组合。
- **形状镂空**开关：打开时形状像模版一样在色块上「挖空」，露出底下的照片；关掉时形状是实心色块盖在照片上。**镂空打开才有「照片从洞里透出来」的效果**，这是本应用的招牌玩法。
- **形状**列表：圆点、星形、心形、漩涡、太阳、字母等多种样式可选，列表里还有一个 **Mix** 选项，混用多种形状。
- **自动 / 手动装饰**：自动模式按排列算法整批撒；切到**手动**就变成逐个放置 —— 想让某个星正好压在人物手上，只能手动摆。
- **贴纸素材**：装饰类素材里还有按「全部 / 萌系 / 装饰」分类的贴纸可挑，用来点缀画面的边角。
- **锁定底图**：同色块页，防止拖形状时误动照片。

数量与大小靠滑块或画布上的手柄调。玩法细节与构图建议见 [手机壁纸与配图制作技巧.md](手机壁纸与配图制作技巧.md)。

## 五、文字页：写一句话收尾

「文字」页签控制最上层的文字：

- **字体**：中英文字体一排切换，中文常见的黑体、明朝、楷体和 Georgia、Helvetica、Futura 等英文字体都在列表里，点选即时生效。
- **文字阴影 / 文字加粗 / 文字镂空**三个开关：阴影让字从背景里跳出来；加粗适合短句大字；镂空则把字变成透出照片的窗口，和装饰层的形状镂空是同一套逻辑。
- 除横排外还支持**竖排文字**，做古风或海报式排版时用得上（以界面实际提供的选项为准）。

写文案的原则是短 —— 一句 4~8 个字足够，字多了在小屏上反而看不清。想直接看成品感，点顶栏「预览」。

## 六、存草稿与导出

- 画到一半退出前点顶栏**「草稿」**保存进度；导出菜单里也有**「存储到草稿箱」**选项，下次可以从草稿箱接着改（具体保留行为以应用内提示为准）。
- 完成后点右上角**导出**，可选 PNG 静态图、MP4 视频、Live Photo 动态图，也能一键全部导出 —— 各格式怎么选、导出后去哪找文件，见 [导出格式与常见问题.md](导出格式与常见问题.md)。
- 还没装应用的话，先按 [下载与安装教程.md](下载与安装教程.md) 把安装包装好。
