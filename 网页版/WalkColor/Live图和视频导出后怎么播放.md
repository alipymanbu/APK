## 一、MP4：最省心的动态格式

WalkColor 导出的 MP4 是标准视频，任何手机的相册、任何聊天工具都能直接播，没有兼容问题。两个常用去处：

- **发社交平台 / 聊天**：当普通视频发即可。
- **当动态壁纸**：安卓自 Android 10 起，系统壁纸选择器普遍支持用视频做壁纸，入口通常是**长按桌面 → 壁纸 → 我的照片 / 视频壁纸**，选中 MP4 设为锁屏或桌面；三星、小米、OPPO、一加等品牌也可以在图库里打开该 MP4，用菜单里的「设为壁纸」（各品牌入口名称与是否支持循环播放略有差异，以你的机型为准）。

导出前先点顶栏「预览」确认画面，导出后到相册的「视频」分类里找它，找不到的排查步骤见 [导出格式与常见问题.md](导出格式与常见问题.md)。

## 二、Live 图：为什么在安卓上「按了不动」

Live Photo 不是单一文件，而是**一张静态图配一小段视频**的组合；这套东西最早由苹果定义，安卓侧则**没有统一标准** —— 各品牌自己实现，叫法也不一样（动态照片、实况照片）。由此产生三个你多半会遇到的现象：

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 相册里长按才有反应，点开是静止图 | 多数品牌就是这么设计的，长按播放 | 在系统相册中**长按图片**播放 |
| 发给朋友，对方只看到静态图 | 各品牌动态照片格式互不兼容，跨品牌分享常降级为静态 | 让对方也用长按试；不行就改发 MP4 |
| 某些相册 / 机型根本识别不了 | 老旧机型或第三方相册不认该封装 | 换系统相册打开；仍不行就导出时改选 MP4 |

**通用结论：要稳，就用 MP4；Live 图当加分项。** 需要对方一定能看动态时，导出菜单里直接选 MP4 最保险。

## 三、导出的视频 / 动态图打不开时的排查

按顺序过一遍，大多数问题停在前三步：

1. **换入口**：视频用系统相册或文件管理器打开，别只在聊天工具的预览里看。
2. **查权限**：设置 → 应用 → WalkColor → 权限，确认照片 / 存储权限已给（没权限时导出本身就可能失败）。
3. **看文件大小**：在文件管理器里查这个文件，接近 0 或明显偏小 = 导出没完成，重新导出一次。
4. **换播放器**：极少数机型的自带播放器缺解码组件，装一个通用播放器（如 VLC 类）试播。
5. **绕开格式**：问题只出在 Live 图时，回头用 WalkColor 再导一份 MP4 —— 格式差异与选择建议见 [导出格式与常见问题.md](导出格式与常见问题.md)。

另有一条来自第三方页面的提醒（单一来源，仅供参考）：MP4 文件较占空间，长期堆积记得清理；部分老旧机型对 Live 格式素材的读取支持不全。想让动态成品的构图更讲究，见 [手机壁纸与配图制作技巧.md](手机壁纸与配图制作技巧.md)。
