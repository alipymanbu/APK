## 一、先分清是哪一种"连不上"

三种症状对应的原因完全不同，先对号入座：

| 症状 | 大概率原因 |
| --- | --- |
| wenet 里登录就报错 | 账号格式、密码、地区、欠费（见下文二~四） |
| 登录显示成功，但网页打不开 | 手机切了流量、认证没真正完成（见第五节） |
| 用一会儿就断、要反复登录 | 掉线重连、被顶号、信号问题（见第八节） |

## 二、登录报错：账号与密码

1. **账号格式**：是否漏了前缀（如 `edu`）、是否混入空格；有的学校账号区分大小写；
2. **密码**：初始密码多为身份证后六位（X 大写）；改过密码后所有设备都会掉线，要重新输；
3. **密码过期**：部分运营商体系的密码会定期过期，按学校通知的短信方式重取（见[套餐缴费与绑定解除.md](套餐缴费与绑定解除.md)）；
4. **地区没选对**：wenet 右下角设置里的"地区"选错会导致登录失败，改完**重启 APP** 再试——这条最容易被忽略。

## 三、登录报错：账号状态

- **欠费/到期**：查余额，缴清后退出重登（缴费流程见[套餐缴费与绑定解除.md](套餐缴费与绑定解除.md)）；
- **已被别处登录**：账号在另一台设备在线，先在原设备退出；原设备不在手上就去学校服务号里把那台设备下线；
- **未开通**：新生账号有时需要先在服务号或营业厅激活宽带，没激活的账号怎么登都会失败。

## 四、安装包本身的问题

如果你刚装好就闪退、或登录页根本不出现：

1. 核对安装包信息（版本 1.3.6、包名 `com.xinli.netkeeper`、约 6.22 MB，详见[下载与安装教程.md](下载与安装教程.md)）——装错同名仿冒包会出各种怪问题；
2. 安装后没给网络权限，去系统设置里检查；
3. 卸载重装（会清登录状态，不影响账号），重装后重新选地区。

## 五、登录"成功"却打不开网页

1. **确认走的是 WiFi 不是流量**：关闭移动数据再试，防止手机判定"WiFi 不可用"偷偷切换；
2. **关掉 WLAN 助理类开关**：设置 → WLAN → 关闭"WLAN 助理 / WLAN+ / 无线网自动切换"（各家叫法不同），否则系统会在认证完成前把 WiFi 断掉；
3. **随机 MAC 干扰**：部分学校的认证绑定设备 MAC。在系统 WLAN 设置里点开当前 WiFi → 隐私/高级 → 改用"设备 MAC"（而不是随机 MAC），再重新登录；
4. **代理/VPN 没关**：不少学校的认证系统检测到代理或 VPN 会只放行一部分流量——表现是微信能聊、网页打不开。把系统代理、VPN、加速器类应用关掉再重新登录一次；
5. **等一下再验证**：认证通过到真正通网有几秒延迟，稍等后重开网页；
6. **换网页试**：个别门户域名被墙内策略影响，用常见站点验证。

## 六、认证页面不弹出来

连上了校园 WiFi 但什么都不弹，浏览器也打不开时，手动触发认证页：

- 用浏览器访问一个**任意网址**（很多学校用 `1.1.1.1`、`3.3.3.3` 这类短地址做触发页，先试最顺手的）；
- 不行就访问学校公布的认证页地址（问学校信息化中心或看新生手册）；
- 还不行先"忘记"这个 WiFi 重连一次，或重启路由器/手机的 WiFi 开关。

弹出后输入账号密码完成认证即可；如果你用的是 wenet，直接在 App 里登录通常能绕过"等弹页"这一步。

## 七、报错提示速查

把常见提示和对应动作列一张表，遇到先查表再动手：

| 你看到的提示 | 先做什么 |
| --- | --- |
| 账号或密码错误 | 核对账号前缀与大小写；密码改过就用新密码；按学校方式重取密码 |
| 账号已在线 / 达到同时在线用户数 | 有设备没退出：旧设备退出，或去自助平台删设备（见[多设备同时上网与掉线排查.md](多设备同时上网与掉线排查.md)） |
| 欠费 / 账号已停用 / 费用超支 | 缴费或换套餐，退出重登（见[套餐缴费与绑定解除.md](套餐缴费与绑定解除.md)） |
| 地区不能使用本服务 / 网络异常 | 检查 wenet 里的地区设置，改完重启 APP |
| 认证失败 / 服务器超时 | 确认连的是学校信号、没开代理 VPN；等半分钟重试；持续出现就是维护期，看学校公告 |
| 反复弹登录页（登录成功又弹） | 校园网到期未缴费的常见表现；缴费后仍弹再查随机 MAC 与在线设备数 |

各校提示文案不统一，表里的措辞仅供参考——**判断依据是你校实际显示的原文**。

## 八、频繁掉线与顶号

- 一个账号同时在线的设备数有上限，手机、电脑、平板共用时容易互相顶——在线数规则、超限挤下线、15 分钟无数据自动下线这类机制详见[多设备同时上网与掉线排查.md](多设备同时上网与掉线排查.md)；
- 换设备一定先在旧设备点"退出登录"，直接装到新设备上登会冲突（正确顺序见[连接校园网上网步骤.md](连接校园网上网步骤.md)）；
- 信号弱的角落（卫生间、上铺墙后）会反复掉线，先换个位置验证是不是信号问题；
- 宿舍断电重启后，路由器和认证会话都要时间恢复，等一两分钟再连。

## 九、自查无效再找人

上面都排过还不行，按这个顺序找人：先看学校信息化中心/服务号有没有公告（维护时段会集中出现登录问题）→ 服务号里的在线客服或报修 → 找校内网络服务点。反馈时说清三件事：账号形式（别发密码）、报错原文、已排除哪些原因，能少跑一趟。
