# wenet 连接校园网上网步骤

> 讲装好 wenet 之后，怎么用学校发的账号连上校园网、怎么扫码让电脑一起上网、怎么退出换设备。

## 一、先确认你的账号格式

wenet 本身不发账号，账号密码来自你的学校（或学校合作的运营商）。各校格式不一样，常见的有这几种：

| 账号形式 | 常见于 |
| --- | --- |
| `edu` + 学号 | 部分院校明确要求前面加 `edu` 前缀 |
| 纯学号 | 多数按学号认证的学校 |
| 新开的手机号 | 办了校园融合套餐的学校 |
| 电信校园卡号码 + 后缀 | 电信闪讯体系的学校 |

密码通常是身份证后六位（末位是 X 注意大小写）或身份证后八位，也可能是学校统一分配的初始密码。**拿不准就以你校录取手册、信息化中心通知为准**——账号写错格式是最常见的登录失败原因。

## 二、手机连接校园 WiFi

1. 打开手机的 WLAN 设置，找到学校公布的无线信号（常见的如 `CT-Young`、`xxx-ChinaNet`、`xxx-STUDENT`，以你校通知为准）并连接；
2. 连上后先不要急着打开别的 App。如果你的手机开了"WLAN 助理 / WLAN+ / 无线网自动切换"，建议先在系统 WLAN 设置里关掉——它会在认证完成前判定"这个网没互联网"而自动切回流量，导致登录总差一步；
3. 确认 WiFi 连着、移动数据可以先关掉，避免手机偷偷走流量。

## 三、打开 wenet 登录上网

1. 打开 wenet（首次使用先按[下载与安装教程.md](下载与安装教程.md)把地区选好）；
2. 在登录页输入账号与密码，注意账号前缀别漏（如要求 `edu` 就必须带上）；
3. 点击**登录 / 连接**，成功后应用会显示已在线状态；
4. 回到系统 WLAN 确认已连上的信号，随便开个网页验证能上网。

登录成功后一般会保持在线；宿舍断电、换楼层、隔夜后重新打开 App 连一次即可。

## 四、电脑怎么上网：扫码登录

很多学校宿舍是"一号多端"：一个账号能同时带手机和电脑。电脑端常见两种方式：

- **电脑装 NetKeeper 类客户端**：电脑连上网线或校园 WiFi 后，打开电脑端客户端，它会弹出二维码，你用手机上的 wenet **扫码**即可让电脑上网；
- **网页认证**：电脑连上网后浏览器自动弹出认证页，输入同一套账号密码登录。

具体走哪种看你校安排；不确定就先试网页认证，不行再看学校有没有要求装电脑端客户端。

## 五、退出登录与切换设备

换手机、刷机、或者想把账号换到另一台设备用时，**必须先在原设备的 App 里点"退出"，而不是直接关掉 App 或关 WiFi**——账号往往绑定了当前在线设备，不退出直接登新设备，容易提示"账号已在线"或顶号冲突。

1. 在 wenet 里找到**退出登录**，确认退出；
2. 新设备安装 wenet、选好地区，再用同一套账号登录；
3. 若仍提示账号在线，去[套餐缴费与绑定解除.md](套餐缴费与绑定解除.md)看解除绑定的办法，或等几分钟让旧会话超时。

平时在公用电脑上用完也建议点退出，别把登录状态留在别人机器上。

## 六、登录失败先看这里

密码过期、账号欠费、地区没选对、账号格式不对，都会表现为"登录失败"但提示各不相同。按提示对照[连不上网排查办法.md](连不上网排查办法.md)逐条排一遍，多数问题能自己解决。
