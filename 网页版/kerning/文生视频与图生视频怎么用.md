# 可灵AI 文生视频与图生视频怎么用

> 本篇讲可灵AI 最常用的两个功能：文生视频（一句话生成视频）与图生视频（让静图动起来），包括提示词怎么组织、参数怎么选、参考图有什么要求。生成会消耗灵感值，规则见 [灵感值与会员订阅说明.md](灵感值与会员订阅说明.md)。

## 一、开工前的准备

1. 装好 App 或打开网页端并登录（两端入口差异见 [网页版和App有什么区别.md](网页版和App有什么区别.md)）；
2. 在个人中心确认今天的免费灵感值余额；
3. 想清楚要生成竖屏还是横屏——后面选画幅要用。

## 二、文生视频：五步出第一条片子

1. 在首页选「视频生成」→「文生视频」；
2. 在提示词框写下画面描述；
3. 选模型版本、时长与画幅；
4. 点生成，任务进入排队；
5. 等待几分钟，完成后预览并保存。

单次生成的时长有多种档位（常见 5 秒或 10 秒，新版本可到 15 秒），时长越长消耗的灵感值越多；点生成前页面会显示本次消耗，先看清再确认。想拍更长的内容，可以用「视频续写」把生成的片段接着往下延长，具体操作与规则见 [视频续写与首尾帧进阶技巧.md](视频续写与首尾帧进阶技巧.md)。

### 提示词公式

官方使用指南给的结构是：**主体 + 运动 + 场景 + 镜头语言 + 光影 + 氛围**。照这个顺序写，命中率明显比一句话高：

```text
差：一只狗在跑
好：一只金毛犬在开满野花的草地上奔跑，镜头从侧面跟随拍摄，
    午后阳光斜照，草叶随风摆动，画面明亮，慢动作
```

几条实战经验：

- 一次只描述一个主要动作，堆五六个动作会让画面混乱；
- 明确写镜头（推近、拉远、跟随、环绕），结果比「随便拍」稳定得多；
- 想要特定画风就在结尾点明，如「水墨画风格」「赛博朋克霓虹」「胶片质感」；
- 界面上有「负向提示词」栏的话，把明确不想要的东西写进去（文字、水印、变形的手指），能减少返工；
- 第一条不满意很正常，微调其中一两个要素重新生成，比整句推翻重写更快。

## 三、图生视频：让静图动起来

1. 选「视频生成」→「图生视频」；
2. 上传一张图片，或上传首帧与尾帧两张图；
3. 用文字描述你想要的运动方式；
4. 选时长与模式，生成。

参考图的常见要求（以页面上传时的实际提示为准）：

| 项目 | 要求 |
| --- | --- |
| 格式 | jpg / jpeg / png |
| 文件大小 | 不超过 10 MB |
| 尺寸 | 宽和高都不小于 300 px |
| 宽高比 | 大约在 1:2.5 到 2.5:1 之间 |

图片内容越有主体、层次越清晰，动起来越自然。运动描述写「镜头缓慢推近，人物微笑转头」这类具体动作，比「动起来」有效。用首帧+尾帧两张图可以控制画面怎么过渡，适合做转场。

## 四、参数怎么选

| 参数 | 常见选项 | 怎么选 |
| --- | --- | --- |
| 画幅 | 16:9 / 9:16 / 1:1 | 发抖音、朋友圈选 9:16；发 B 站、YouTube 选 16:9 |
| 时长 | 5 / 10 / 15 秒 | 第一次先选短的，试对提示词再加长 |
| 模式 | 标准 / 高表现 | 高表现画质与运动更好，灵感值消耗也更高 |
| 模型版本 | 随官方更新迭代 | 不确定就用默认的最新版 |

另外两类常用入口：AI 图片（文生图、图生图，静态图还能一键转成动态视频）和音效生成（给视频配上环境音或对白）。它们操作逻辑与上面相同，都是提示词 + 参数 + 生成。想让画面里的人物开口说话，单独有一套对口型与配音的做法，见 [对口型与声音怎么加.md](对口型与声音怎么加.md)。

## 五、生成之后

- 满意就下载保存；免费账号导出的视频可能带平台水印，去水印属于会员权益，见 [灵感值与会员订阅说明.md](灵感值与会员订阅说明.md)；
- 一直排队、生成失败或提示内容违规，按现象对照 [常见问题与故障排查.md](常见问题与故障排查.md) 处理；
- 同一个题材想批量出片，把已验证的提示词存下来，每次只改场景或风格词，比每次从头写省得多。
