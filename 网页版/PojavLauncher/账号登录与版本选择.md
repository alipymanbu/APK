## 一、两种账号，决定你能玩什么

PojavLauncher 启动后第一件事是添加账号。它本身只是启动器，不含游戏，账号类型直接决定你能不能进服务器：

| 账号类型 | 怎么登录 | 能做什么 | 限制 |
| --- | --- | --- | --- |
| Microsoft 账号 | 添加账号 → 选 Microsoft Account → 弹出微软官方授权页面，输入已购买 Java 版的账号 | 单人游戏、进开启正版校验的多人服务器，皮肤与披风正常 | 账号必须已购买（或迁移过）Minecraft: Java Edition |
| 本地（离线）账号 | 添加账号 → 选 Local Account，随便输一个用户名 | 单人游戏、局域网联机 | 进不了开启正版校验的服务器；名字可能与他人重名 |

几点登录时实际会碰到的情况：

- 微软授权走的是系统浏览器，登录的是**微软官方页面**，授权完成会自动跳回启动器；如果跳回失败，重试一次通常就好。
- 授权页提示成功却一直跳不回启动器：这类「跳转失败」是微软授权流程的常见问题，不是启动器独有。处理顺序：清一次浏览器的缓存和 Cookie → 换一个浏览器重试 → 先在别的设备上确认该账号能正常登录微软，排除账号本身的问题。
- 登录时报 `The server has not found anything matching the request URI` 这类 404 错误，官方说明里给的原因就是**该账号没有购买或迁移 Minecraft: Java Edition**，不是启动器坏了。
- 想进 Hypixel 这类大型服务器，只能用微软账号；本地账号会被正版校验挡在门外（联机步骤见 [服务器联机教程.md](服务器联机教程.md)）。
- 如果你的安装包来自 Google Play（Dahlia 版起），未购买游戏的账号连游戏资源下载都会被启动器拒绝；APK 直装版没这道限制，但进正版服务器仍需要正版账号。

## 二、版本列表怎么选

启动器支持的版本跨度非常大：从 2009 年的远古预览版 rd-132211，到 1.21 系列快照（含 Combat Test 版本）都在支持范围内。选版本时按这个思路走：

1. **看设备**：老手机（3 GB 内存以下）从 1.8.9、1.12.2 这类老版本起步，体验差距很大；新一点的设备可以直上 1.20.x。
2. **看 Java 要求**：1.17+ 需要 Java 17、1.20.5+ 需要 Java 21，启动器一般会自动选对运行时，但如果你手动改过设置，记得核对（对应关系见 [Java运行时与渲染器选择.md](Java运行时与渲染器选择.md)）。
3. **看服务器**：打算进某个服务器，先看它要求的游戏版本，版本对不上是连不上服务器的第一原因（加服务器的完整步骤见 [服务器联机教程.md](服务器联机教程.md)）。
4. **看模组**：要玩模组的话，先确定模组/整合包支持的版本，再回来选同样的游戏版本（见 [Forge与Fabric模组安装.md](Forge与Fabric模组安装.md)）。

选好版本点开始后，第一次会联网下载该版本的游戏文件，之后再次启动就不再重复下载。

## 三、Profiles：给不同玩法各存一套配置

启动器支持多 Profile（配置档案）：每个 Profile 可以单独绑定不同的游戏版本、Java 运行时、渲染器和游戏目录。实际用途比如：

- 一个 Profile 玩原版 1.20.4，另一个 Profile 挂 Forge 1.16.5 的模组包，互不干扰。
- 同一个版本分别建「省电档」（低内存、低分辨率）和「画质档」，按电量切换。

切换 Profile 就等于切换整套游戏环境，不用每次手动改设置。

## 四、游戏文件装在哪、怎么备份

游戏目录在手机存储的 `games/PojavLauncher/.minecraft`（从 v3.3.1 起是这个路径，与你 PC 上 `.minecraft` 的结构一致）。知道这个位置的直接用处：

- 存档（`saves`）、资源包、截图都在里面，换机或清手机前把这个目录拷走就能保留进度。
- 手动装模组时，mods 文件夹也在这里（见 [Forge与Fabric模组安装.md](Forge与Fabric模组安装.md)）。
- 游戏版本反复出错、想彻底重来时，删掉对应 Profile 的游戏目录让它重新下载即可。

登录或版本启动卡住不走，直接翻 [闪退黑屏与登录报错处理.md](闪退黑屏与登录报错处理.md) 对着症状查。
