# PojavLauncher Forge与Fabric模组安装

> 在手机上给 Minecraft 装模组：优先用启动器内置的自动安装器，其次手动放 mods 文件；整合包可以直接在启动器里搜。

## 一、先确认你的安装包支持到什么程度

内置自动安装是 Edelweiss 版本及之后才有的能力：一键安装 Forge / Fabric / Quilt / OptiFine，并在启动器内直接搜索、安装 CurseForge 和 Modrinth 上的整合包。如果你手上是更早的构建（比如网盘资源里那份 20240926 版本），自动安装器可能不完整，这时走第二节的手动方式，效果一样。

另外，1.17+ 的模组环境对 Java 与渲染器有要求：Java 对应关系见 [Java运行时与渲染器选择.md](Java运行时与渲染器选择.md)，Sodium/Iris 这类模组建议用 Zink 或 LTW 渲染器跑。

## 二、手动装模组（任何版本通用）

1. 在启动器里先选定目标游戏版本并完整启动一次，让游戏目录生成。
2. 用手机文件管理器打开游戏目录（默认在 `games/PojavLauncher/.minecraft`；如果你给 Profile 单独设过游戏目录，以 Profile 的为准，见 [账号登录与版本选择.md](账号登录与版本选择.md)）。
3. 没有 `mods` 文件夹就新建一个，把模组 jar 文件直接拷进去。
4. 回到启动器，重新启动该版本。加载时间会明显变长，属正常。
5. 进游戏后看主界面左下角的版本标注或 Mods 列表，确认模组已加载。

Forge 手动方式还需要先装 Forge 本体（把官方的 Forge installer 交给启动器安装），Fabric 则装一个 fabric loader 版本即可。安装器跑完出现 `exited with code 0` 才算成功，版本列表里会多出一个带 Forge/Fabric 后缀的版本。

## 三、装模组的三个常见坑

- **版本要对齐**：模组版本、加载器版本、游戏版本三者必须一致，1.16.5 的模组放进 1.20.4 的 mods 文件夹，结果就是加载时闪退。
- **一次少加几个**：排障时逐个添加比一把全塞进去高效得多，闪退时你才知道是哪一个的问题（对照 [闪退黑屏与登录报错处理.md](闪退黑屏与登录报错处理.md)）。
- **OptiFine 与 Sodium 二选一**：两者都是优化模组，同时放会冲突；要光影就 Sodium + Iris 组合（配合 LTW/Zink 渲染器），不要混装。

## 四、整合包与特殊模组

- **整合包**：Edelweiss 之后的版本可以直接在启动器内搜索 CurseForge / Modrinth 的整合包安装；手动导入时把包里的 mods、resourcepacks、config 对应放进游戏目录同名文件夹，CurseForge 包的实际文件多在 overrides 子目录里，解压后按同样方式摆放。整合包体积大，先确认手机剩余空间。
- **模组服务器**：进装了 Forge/Fabric 的服务器，客户端要装同一加载器与同版本模组，漏装的表现是被踢出或进不去（联机步骤见 [服务器联机教程.md](服务器联机教程.md)）。
- **ReplayMod（录像回放）**：需要给启动器额外装 FFmpeg 插件才能正常工作，Gladiolus 版本对此做了专门支持。
- **光影/资源包**：资源包放进 `resourcepacks`，光影包配合 Iris 使用；光影对帧数影响极大，中端机从低配光影开始试。

装好模组后如果操作不便，可以按 [触屏按键与外接键鼠设置.md](触屏按键与外接键鼠设置.md) 给模组常用的物品栏快捷键单独加虚拟按钮。
