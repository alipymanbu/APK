## 一、先弄清楚你要装的是哪一份

PojavLauncher 是一个安卓应用（APK 安装包），不是游戏本体。装好之后，它会在你登录账号、选定游戏版本后，再从官方服务器把游戏文件下到手机上。所以「装启动器」和「装游戏」是两步，这篇只讲第一步。

官方发布的 APK 有两种常见形态，区别在安装包里**有没有内置 Java 运行时**：

| 形态 | 体积 | 特点 |
| --- | --- | --- |
| `app-debug`（包名 `net.kdt.pojavlaunch.debug`） | 大（本资源约 159.45 MB） | 内置 Java 运行时，装好即可用，不联网也能完成安装和后续更新 |
| `app-debug-noruntime` | 小 | 不含运行时，只适合已经装过完整版、用来更新启动器本体的情况 |

网盘里的那份 PojavLauncher 安装文件资源（夸克网盘）就是前一种 `app-debug` 构建，包名为 `net.kdt.pojavlaunch.debug`，版本号 **20240926**，MD5 为 `4AE52518AAF74D914F44C58E7E8FE7CD`，可用于核对文件是否下载完整。在电脑上核对 MD5 用 Windows 自带的命令即可：`certutil -hashfile 文件路径 MD5`。它和官方最新发布版不一定相同——官方大版本按花名发布（如 Edelweiss、Foxglove、Gladiolus），晚于这个日期才加入的功能（如 LTW 渲染器）在这份包里可能没有。

另外注意：`net.kdt.pojavlaunch.debug` 与 Google Play 商店版（`net.kdt.pojavlaunch`）包名不同，两者会作为**两个独立应用**共存，不会互相覆盖。

## 二、官方渠道有哪些

以官方 GitHub 仓库（[PojavLauncherTeam/PojavLauncher](https://github.com/PojavLauncherTeam/PojavLauncher)）为准，获取方式有三种：

1. **GitHub Releases**：[github.com/PojavLauncherTeam/PojavLauncher/releases](https://github.com/PojavLauncherTeam/PojavLauncher/releases)，下载按花名发布的稳定版 APK。
2. **Google Play**：搜索 PojavLauncher，包名 `net.kdt.pojavlaunch`；注意从 Dahlia 版起，商店版要求账号已购买 Minecraft，否则启动器会拒绝下载游戏资源。
3. **自行构建**：仓库 README 提供了 Gradle 构建步骤，普通用户不需要走这条路。

**该项目已于 2025 年 9 月前后归档停更**，官方 README 已明确标注不再维护，继任项目是 [Amethyst-Android](https://github.com/AngelAuraMC/Amethyst-Android)。停更不代表不能用：已有版本仍然可以正常安装、登录、下游戏，但更新的游戏版本出现兼容问题时不会再有官方修复。第三方下载站上的「最新版」请谨慎对待，改动过的安装包有盗取微软账号凭据的风险。

## 三、安装步骤（以网盘那份为例）

1. 把 [PojavLauncher 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f0996b2ddfa3)里的 APK 转存并下载到手机存储（若你是转发到电脑再传到手机，放到「下载」目录即可，路径随意，能找到就行）。
2. 打开手机的**设置 → 应用管理（或安全与隐私）→ 安装未知应用**，给你用来下载或传文件的浏览器/文件管理器授予「允许安装未知应用」权限。不同品牌路径名称略有差异，搜「安装未知应用」一般都能找到。
3. 用文件管理器找到刚下载的 APK，点它 → 选**安装**。安装包约 159 MB，解析需要几秒到十几秒。
4. 装完点**打开**，进入启动器。此时还不能直接玩——先去完成账号登录（见 [账号登录与版本选择.md](账号登录与版本选择.md)），选好版本后启动器才会去下载游戏文件。

如果第 3 步报「解析包时出现问题」，常见原因是安卓系统版本过低或安装包下载不完整——先用上面的 MD5 核对文件，再确认系统版本（第三方资料普遍把可安装线写在 Android 5.0 左右，版本越新的游戏对系统与硬件要求越高，以实际安装为准）。

## 四、第一次启动会发生什么

- 启动器界面出现后，先添加账号（微软账号或本地账号）。
- 在版本列表里选一个游戏版本，点开始后，启动器会联网从 Mojang 官方服务器下载该版本的游戏文件与资源，第一次会等几分钟，时间长短取决于版本与网速。
- 下载完成进入游戏画面后，屏幕上会出现虚拟按键和虚拟鼠标。操作不习惯的话，先看 [触屏按键与外接键鼠设置.md](触屏按键与外接键鼠设置.md)；新版本游戏起不来或闪退，多半与 Java 运行时、渲染器、内存分配有关，见 [Java运行时与渲染器选择.md](Java运行时与渲染器选择.md) 与 [闪退黑屏与登录报错处理.md](闪退黑屏与登录报错处理.md)。
