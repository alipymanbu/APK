## 一、先分清是哪一层出了问题

排查前先定位层级，三层的处理方向完全不同：

1. **安装层**：APK 装不上、装完点开就退 —— 查安装包与系统版本；
2. **启动器层**：能打开启动器，但下载游戏或启动版本时失败 —— 查运行时、渲染器、内存与网络；
3. **游戏层**：能进游戏，玩着玩着退 —— 查内存、模组与发热。

## 二、症状对照表

| 症状 | 常见原因 | 处理顺序 |
| --- | --- | --- |
| APK 解析失败、装不上 | 安装包下载不完整；系统版本过低 | 用 MD5 核对文件（`4AE52518AAF74D914F44C58E7E8FE7CD`）；确认系统满足最低要求后重装 |
| 点开启动器图标就闪退 | 存储空间不足；安装了互相冲突的两个启动器版本 | 清出至少 2~3 GB 空间；若同时装了 Google Play 版与 APK 版，先卸载其中之一再试 |
| 登录报 404（`The server has not found anything matching the request URI`） | 账号没有购买或迁移 Java 版 | 换已购买的正版微软账号；本地账号只能玩单人与局域网（见 [账号登录与版本选择.md](账号登录与版本选择.md)） |
| 授权页登录成功却跳不回启动器 | 浏览器缓存或默认浏览器拦截 | 清浏览器缓存或换浏览器重试；先在别处确认账号能正常登录微软 |
| 进服务器报 Invalid session / 验证失败 | 登录会话过期 | 删除账号重新登录再连（联机排查见 [服务器联机教程.md](服务器联机教程.md)） |
| 版本列表能选、进度条走完就退回启动器 | Java 运行时与游戏版本不匹配 | 按版本对应表核对运行时（见 [Java运行时与渲染器选择.md](Java运行时与渲染器选择.md)） |
| 新版本（1.21.1+）进去黑屏 | 旧构建的 GL4ES 渲染器缺陷 | 换 Zink/LTW 渲染器；或换用 Gladiolus 及之后的构建，该问题在此版本已修复 |
| 加载世界或生成地形时闪退 | 内存分配不足或过大 | 交给自动分配，或手动留出系统余量（同一篇的第三节） |
| 玩半小时后越来越卡、最终闪退 | 发热降频 + 内存吃紧 | 打开 sustained performance mode；调低游戏内分辨率；给手机散热 |
| 装模组后必闪退 | 模组与游戏版本不匹配、模组互相冲突 | 逐个移除模组定位问题；OptiFine 与 Sodium 不可共存（见 [Forge与Fabric模组安装.md](Forge与Fabric模组安装.md)） |
| 服务器连不上 | 版本不符；账号是本地（离线）账号；地址或端口抄错 | 先核对服务器要求的版本与地址；正版服务器必须微软账号登录（完整排查见 [服务器联机教程.md](服务器联机教程.md)） |
| 游戏资源下载失败 | 网络不稳；Google Play 版未购买游戏 | 换网络重试；商店版需要账号已购 Minecraft（见 [下载与安装教程.md](下载与安装教程.md)） |

## 三、几个值得记住的判断依据

- **闪退退回启动器 ≠ 启动器崩了**：游戏进程退出后会回到启动器界面，这是正常行为，要看的是日志里最后一行的报错关键词（内存溢出、模组加载失败、运行时错误，处理方向各不相同）。
- **黑屏有声**：基本是渲染器问题，换渲染器比反复重启有效。
- **改动生效的前提是重启该版本**：渲染器、内存、运行时改完，都要重新启动对应版本，原地重试不生效。
- **彻底重置**：版本反复坏掉时，删掉该 Profile 的游戏目录（`games/PojavLauncher/.minecraft`）让它重新下载，比重装启动器快。

## 四、项目已停更，遇到新问题怎么办

官方仓库已归档（2025 年 9 月前后），现有问题不会再有官方修复，已知问题的状态可以翻官方 issue 列表；更新的 Minecraft 版本出现兼容问题时，官方指出的去向是继任项目 [Amethyst-Android](https://github.com/AngelAuraMC/Amethyst-Android)。你不需要立刻迁移：现有构建对已支持的版本（到 1.21 系列）依然可用；只有当你要玩更新版本、且确认是启动器层面的兼容问题时，换继任项目才是正解。

排查掉环境问题之后还慢的，回头把三个「帧数旋钮」都过一遍：分辨率、渲染器、持续性能模式（见 [Java运行时与渲染器选择.md](Java运行时与渲染器选择.md)）。
