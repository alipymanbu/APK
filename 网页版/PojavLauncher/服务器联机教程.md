## 一、加服务器只要三步

1. 启动器里先启动对应版本进入游戏，主界面选**多人游戏（Multiplayer）**，点**添加服务器（Add Server）**。
2. 服务器名称随意，地址填服务器公告给的域名或 IP；带了端口就写成 `IP:端口` 的形式，没给端口就什么都不加（游戏默认走 25565）。
3. 保存后回到列表，等它刷新出在线人数再双击进入。列表里显示红叉说明当前连不上，原因从第四节往下对。

手机上加服务器的操作和电脑版完全一样，电脑上怎么加、手机上就怎么加，区别只在下面两道门槛。

## 二、版本与账号两道门槛

- **版本**：客户端版本要跟服务器要求的一致；有些服务器装了跨版本兼容插件，允许相邻几个版本进入，以服务器自己的公告为准。回启动器换版本的方法见 [账号登录与版本选择.md](账号登录与版本选择.md) 第二节。
- **账号**：开启正版校验的服务器只能用微软账号进入；本地（离线）账号只能进关闭了校验的服务器或局域网联机。两种账号的差别与登录方法见 [账号登录与版本选择.md](账号登录与版本选择.md) 第一节。

「明明地址没错却总被拒绝」多半就卡在这两道门槛上，而不是网络问题。

## 三、模组服务器要多装一步

服务器带 Forge/Fabric 模组时，客户端也必须装同一加载器、同一套模组，漏装的典型表现是被服务器直接踢出或方块行为异常。安装方法见 [Forge与Fabric模组安装.md](Forge与Fabric模组安装.md)。整合包服务器一般会直接给出「客户端整合包」，按包导入、版本选对即可，不要自己零散拼模组。

## 四、连不上排查表

| 提示 | 多半是 | 处理 |
| --- | --- | --- |
| 无法解析地址 / 无法连接服务器 | 地址输错、服务器没开 | 核对地址与端口抄写是否一致；确认服务器在线（别人能否进） |
| 连接超时 | 到服务器线路不稳（外服高峰期常见） | 换个网络环境重试，或过段时间再连 |
| 版本不匹配被拒 | 客户端与服务器版本不一致 | 回启动器把版本换成服务器要求的那个 |
| Invalid session / 身份验证失败 | 登录会话过期 | 启动器里删除账号重新登录，再进服务器 |
| 被踢出并提示白名单 | 服务器需要先申请白名单 | 按服务器要求提交申请，等通过再进 |

反复报验证失败还可能是系统时间不准导致的，核对一下手机时间是否为自动同步。

## 五、局域网联机

同一个 Wi-Fi 下最快：

1. 一方进入单人世界，在设置里选**对局域网开放**，屏幕会显示一个端口号。
2. 另一方在多人游戏里直接添加服务器，地址填对方的内网 IP 加上那个端口（手机在 Wi-Fi 详情里能看到本机 IP）。
3. 开放方退出世界，联机即断；这种方式不需要任何账号校验。

进得去但卡顿、频繁掉线的，先看设备性能与渲染设置（[Java运行时与渲染器选择.md](Java运行时与渲染器选择.md)），再按 [闪退黑屏与登录报错处理.md](闪退黑屏与登录报错处理.md) 的对照表排查。
