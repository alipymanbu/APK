## 一、先习惯虚拟鼠标

Java 版 Minecraft 是按电脑键鼠设计的，进入游戏画面后你看到的第一个工具就是**虚拟鼠标**：屏幕上出现一个指针，用左侧区域滑动来移动它，点按等于鼠标左键。

- 如果你希望每次进游戏指针就绪、不用再点开，可在启动器设置里打开「Start with virtual mouse on」（默认以虚拟鼠标启动）。
- 背包、合成台这类界面用虚拟鼠标操作最自然；走路和转向则靠左下摇杆区与右侧滑动。
- 手感别扭先别急着改按键布局，先试试调指针大小与滑动灵敏度，多数不适感来自这两项。

## 二、屏幕按键可以完全自定义

PojavLauncher 的自定义控件系统支持整块重排，你可以把屏幕做成任何布局：

- 按钮可自由增删、拖动定位、改大小改颜色，位置还能按屏幕比例自动适配不同尺寸的手机。
- 可以加一个**屏幕虚拟摇杆**（移动端常见的操作方式），习惯手游手感的人建议第一时间加上。
- 按钮可以设置「进游戏才显示 / 菜单里才显示」，把不常用的键从游戏画面里藏掉。
- 改好的布局能导出保存，换机或重装后导入即可，不同 Profile 可以用不同布局。

改布局时留出右侧转视角的空白区域，全屏铺满按钮反而没法玩。

## 三、外接键鼠与手柄

插上外设后，键位与操作方式就和电脑版一致了。

| 外设 | 连接方式 | 说明 |
| --- | --- | --- |
| 键盘 | 蓝牙或 OTG/USB | WASD 移动、快捷栏数字键、F3 调试屏等键位与电脑版一致；输入框支持中文输入法（个别老版本组合键有兼容问题） |
| 鼠标 | 蓝牙或 OTG/USB | 硬件鼠标全键位支持（含中键与侧键），挖方块、放方块的精度立刻正常 |
| 手柄 | 蓝牙或 USB | 官方对游戏手柄做了低延迟适配，Xbox 布局手柄最省事；较新版本还支持 Switch 手柄 |

用键鼠玩时记得把虚拟按键缩到边上或藏起来，视野干净很多。手柄党如果觉得默认键位不顺，也可以在控件设置里重映射。

## 四、游戏内快捷设置

进入游戏后，从屏幕侧边唤出 Quick Settings（快捷设置）面板，不用退回启动器就能调：

- **分辨率缩放**：卡顿第一优先调这里，把渲染分辨率降一档，帧数往往明显回升（性能原理见 [Java运行时与渲染器选择.md](Java运行时与渲染器选择.md)）。
- **手势设置**：双指缩放等触屏手势的开关。
- **陀螺仪**：用手机姿态辅助转视角，玩建造类时有人喜欢开。

另外两个值得知道的启动器级开关：「sustained performance mode」会主动限制性能换稳定，长时间玩发热严重、帧数越玩越掉时可以打开试试；「alternate surface rendering」在个别机型上能提升渲染表现，画面异常时切换它是个排查手段。

操作相关的问题（按键没反应、触屏失灵）如果重启解决不了，大概率不是这里的问题，去 [闪退黑屏与登录报错处理.md](闪退黑屏与登录报错处理.md) 对照排查；想连服务器找回账号，见 [账号登录与版本选择.md](账号登录与版本选择.md)。
