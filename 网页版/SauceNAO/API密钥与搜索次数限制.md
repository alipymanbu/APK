## 一、要不要填：先看你的用法

这一项是可选的：**不填也能正常搜图，填上只提高每天的搜索次数上限**。要不要填，取决于你一天大概搜几张、有没有反复撞上"服务器请求过多"。菜单里那一项的界面说明也是这个口径：

- **偶尔用（一天搜几张图）**：不填，够用，别折腾。
- **一天要搜很多张**，或者已经不止一次遇到"服务器请求过多"：填上，这是唯一能提高额度的办法。

## 二、密钥从哪儿来

密钥由 SauceNAO 的服务方签发，跟你在客户端里做什么无关。获取步骤：

1. 用浏览器打开 [saucenao.com](https://saucenao.com)；
2. 注册一个账号（免费账号就能申请，不需要付费）；
3. 登录后进入 [SauceNAO 的 API 页面](https://saucenao.com/user.php?page=search-api)，生成或查看属于你的密钥，它是一串字母数字；
4. 把这串字符整段复制下来。

**客户端里没有"登录账号"这个入口**，它只保存这一串密钥，不保存你的账号密码。所以流程是"在浏览器里拿密钥，回应用里粘贴"。

## 三、限制分两档，报错只对应其中一档

服务方的次数限制分短时和总量两层，都跟"是不是填了密钥"有关：

| 限制 | 触发后的表现 | 怎么恢复 |
| --- | --- | --- |
| 每 30 秒一档 | 提示"服务器请求过多" | 停十几秒到半分钟左右再搜 |
| 每 24 小时一档 | 同样是"服务器请求过多"，但等几十秒也不会好 | 只能等次日额度刷新，或填密钥提高上限 |

参考量级：不填密钥时大约每 30 秒 4 次、每天一百次上下；**这组数字是多次被人引用的经验值，官方会调整，以 API 页面当时显示为准**。关键是理解结构——短时限制靠"慢一点"能解决，每日限制只能靠"提额度"解决。区分办法很简单：停半分钟再搜就好了的是前者，一直不好的是后者。

## 四、填进去之后的几件事

1. **怎么填**：打开右上角菜单，点 API 密钥，把复制的那串字符粘进去并确认。粘贴时注意别带上首尾的空格。
2. **怎么确认生效**：连着搜几张图，不再撞"服务器请求过多"，基本就说明额度上去了。填入的密钥若无效，表现是额度**没有变化**（照旧受匿名额度限制），这时把它清空、重新复制一次即可，不要反复重装应用。
3. **别公开分享**。密钥与你的账号绑定，别人拿去用就是跟你共用同一份额度；额度被别人耗光，受影响的是你自己。
4. **换手机或重装要重填**。客户端不会把它备份到云端，卸载后这一项就没了。

## 五、不打算注册的话，怎么把额度用久一点

不填密钥也能正常搜，只是要接受更低的额度，几条实用做法：

- 搜完一张再搜下一张，中间留十几秒，让短时限制自然恢复；
- 不用为了试效果把同一张图反复提交，重试一次不中就换图或换库，重复提交最耗额度；
- 撞上"服务器请求过多"就停手，等 30 秒左右再继续；硬点只会把恢复时间推得更远。

## 六、次数还是不够：官方还有付费账号这一层

密钥解决的是"免费额度太低"，但它不能把额度无限拉高。服务方本身还卖账号档位，用来换更高的搜索次数与更高的搜索优先级——也就是说额度大致分三层：

| 层级 | 怎么得到 | 大致处在什么位置 |
| --- | --- | --- |
| 匿名使用 | 什么都不填 | 最低，日常搜几张够用 |
| 免费账号 + 密钥 | 注册后在 API 页面拿密钥，填进应用 | 比匿名高一档，多数个人用途到这就够了 |
| 付费账号 | 在服务方页面升级账号档位 | 最高，同时影响次数与结果优先级 |

三条硬信息这里不写死：**具体有哪几档、每档多少钱、各档对应多少次，都以官方账号升级页面当时显示为准**。第三方资料里流传过"每月几美元到二十几美元"这种量级说法，只能当参考，不能当价目表用。要不要为它花钱，判断标准还是你的实际用量：偶发使用填个免费密钥足够；如果每天都撞每日上限，再去官方页面看现价。

## 七、别和另一条提示混起来

"请求被 Cloudflare 阻止"**不是额度问题**，它跟你的搜索次数无关，换一个网络通常就能过。两条提示的区分与处理，见 [搜不到图或结果不对怎么排查.md](搜不到图或结果不对怎么排查.md) 第六节。
