## 一、它替你做的事是"倒着搜图"

平时的搜索是你给关键词、它给一堆图；SauceNAO 反过来：你给一张图，它告诉你这张图在哪些地方出现过、最可能出自谁手。落到二次元图上，命中的通常是 Pixiv 的插画页与画师主页、某个图库站的投稿条目、或者某部动画的具体一集。

有两件事要提前说清，免得期待落空：

- **它给的是"出处"，不是"内容描述"**。它不会告诉你图里画的是谁、穿的什么，只会告诉你去哪儿能找到这张图的原始发布页。
- **不需要注册、不需要登录**，装完就能搜。右上角菜单里那个 API 密钥是可选项，只影响每日能搜多少次，见 [API密钥与搜索次数限制.md](API密钥与搜索次数限制.md)。

## 二、把图送进去的三条路

| 方式 | 怎么做 | 什么时候用 |
| --- | --- | --- |
| 应用内选图 | 点主界面的"选择图片"，从系统相册或文件里挑一张，选完立刻开始搜 | 图已经存在手机里 |
| 按图片链接搜 | 把图片的直链（`http` 或 `https` 开头的图片地址）粘进"按图片链接搜索"的输入框提交 | 图在网页上，手上有它的地址 |
| 从别的应用分享 | 在相册、浏览器、聊天软件里对着图片点"分享"，选 SauceNAO | 最省事的一条路：不用先存图再进来找 |

第三条其实不是独立的一条：你分享图片过去，它走的是第一条路；你分享的是一段链接文本，它走的是第二条路。区别只在于你不用自己打开应用。

搜索完成后界面会自动跳到结果页面，不需要再手动点一次。

**关于"使用照片选择器"这个开关**（在右上角菜单里，是个勾选项）：

- 勾上时，挑图走的是系统自带的照片选择器，界面更清爽，而且只把你选中的那张图交给应用；
- 不勾时，走的是传统的"打开文件"方式。
- 实用建议：点了"选择图片"却翻不到想要的图、或者选完没任何反应，把这个开关换个状态再试一次，多数情况下就正常了。

这个开关之所以有两种做法，是因为应用本身没有读取相册的权限，挑图这件事始终由系统代办，具体见 [上传的图会被保存吗.md](上传的图会被保存吗.md) 第三节。

**格式与体积**：常见的位图（JPG、PNG）都没问题；体积特别大的图可能被服务端直接拒掉，表现就是提示"无法加载结果"——遇到这种情况，先把图压小或者裁到你要找的那一块再传。

## 三、搜之前要不要改数据库

主界面下方那一行默认写着"所有数据库"，意思是三十多个索引一起搜。这个默认值适合大多数情况——找插画作者、找图库投稿都能覆盖。

只有两种情况需要动它：想缩小范围让结果更干净，或者想避开某类内容。怎么选见 [搜索数据库怎么选.md](搜索数据库怎么选.md)。

## 四、结果卡片上的每一处

结果页是一列卡片，每张卡片对应一条命中记录，结构固定：

| 位置 | 内容 |
| --- | --- |
| 左侧 | 命中图在库里的缩略图，用来肉眼比对是不是同一张 |
| 右上角 | 相似度，形如 `95.3%` |
| 标题行左侧 | 命中条目的名称（作品名、投稿标题之类） |
| 标题下面几行小字 | 该条目的元信息，例如图库里的 ID、作者名、出处站点、集数与时间点 |

元信息的具体项目随来源不同而不同：来自插画站的条目一般给作者名和作品 ID，来自动画索引的条目会给作品名、集数甚至时间点。**这几行小字往往比百分比更有用**——它才是你拿去核对"是不是我要找的那张图"的依据。

### 相似度怎么读

相似度是"你上传的图"与"库里那条记录"的匹配程度，不是"这张图有多大概率是它"。用法上记三点：

- 正确来源通常排在最前面，**先看前几条**，别从头翻到尾；
- 百分比越高越值得先点开，但**低不等于错**：同一张图的正确来源，在图片被二次保存、裁剪、调色、加过文字或水印之后，相似度往下掉是常事；
- 所以判据是"缩略图看着像不像 + 元信息对不对得上"，百分比只用来决定先看哪一条。

### 一个容易踩的预期差

同一张图，你搜出来的第一条未必是你最早看到它的那个地方。图库站、搬运号和壁纸站都会收录同一张图，**这些地方是"出现过的位置"，不是"原始出处"**。要判断原始出处，看元信息里的作者与出处站点是不是创作平台，而不是收录站。

## 五、点一下和长按，各能做什么

- **点卡片**：弹出这条记录带有的全部外部链接，选中一条就会用浏览器打开——通常是原作页或图库条目页。
- **长按卡片**：弹出两个动作。"复制到剪贴板"复制的**是这条记录的标题**（方便你拿标题去别的地方搜）；"分享"则是把标题当文本发给别的应用。
- **它不提供保存原图**这一动作。想拿原图，得顺着结果里的链接去原作页面自己取，或者退一步截屏——但重新保存过的图，下次再拿来搜，相似度会比原图低。

## 六、结果没出来，或者看着不对

结果页可能出现这几种状态，先认一下名字：正常出结果；提示"无结果"，说明这张图在索引里没匹配上；以及"无法加载结果""请求被 Cloudflare 阻止""服务器请求过多"这三种失败提示，原因和办法各不一样。

这几种情况按 [搜不到图或结果不对怎么排查.md](搜不到图或结果不对怎么排查.md) 里的顺序走一遍，比反复重试有效。
