## 一、先确认这一份是哪个版本

SauceNAO 是一个反向搜图服务：你给它一张图，它在自己的索引里比对，告诉你这张图最可能出自哪里。落到二次元图上，常见的结果是 Pixiv 上的插画与画师、某个图库站的投稿、以及某部动画的具体一集。服务本身以网页 [saucenao.com](https://saucenao.com) 为主入口，下面这份是手机上用的安卓客户端。

动手之前，先对着下表核对手上这一份：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | SauceNAO |
| 开发方 | luk1337（开源项目，Apache License 2.0） |
| 包名 | `com.luk.saucenao` |
| 版本号 | 1.25 |
| 安装包大小 | 2.91 MB |
| 安装包 MD5 | `619A8D5A7F76F7FA35FEDCB190D03883` |
| 系统要求 | Android 5.0 及以上（1.25 版的官方分发渠道标注） |
| 联网要求 | 每次搜索都要联网，比对在服务端完成，断网出不了结果 |
| 是否需要账号 | 不需要注册就能直接用 |

**版本号不要拿搜索结果里的去对。** 网上能搜到的多半是官方当前最新版，和这一份未必是同一个；判断"手上这份对不对"，只看两项：包名是不是 `com.luk.saucenao`，版本号是不是 1.25。

**系统要求也不要照抄下载站。** 这一版在官方分发渠道上标注为 Android 5.0 及以上，也就是说比 5.0 高的系统（6.x、7.x 一直到更新的版本）都满足它的要求；而更新的应用版本会把门槛抬高（例如后续版本要求 Android 6.0 及以上），所以换新版包之前回官方页面确认一次即可。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享，分享里是一个以应用名命名的文件夹（形如 `saucenao（先保存再下载）`），安装包就在文件夹里。

1. 在手机上打开 [SauceNAO 安装文件资源（夸克网盘）](https://pan.quark.cn/s/eadf625201a3)。手机浏览器和夸克 App 都能打开，**建议用夸克 App**：浏览器下载大文件容易在切后台时被中断。
2. 点"保存到我的网盘"，把文件夹转存到自己账号下。转存之后，之后重新下载就不再依赖原分享是否还在。
3. 进自己的网盘找到那个文件夹，进文件夹，把里面的安装包下载到手机。
4. 下完核对两件事：文件名以 `.apk` 结尾（这一份形如 `saucenao_v1.25.apk`）；大小在 2.91 MB 左右。差得多的，多半是没下完，删掉重来。

如果你更习惯在电脑上操作：在电脑端网盘下载，再用数据线把 apk 拷到手机的 `Download` 目录，效果一样；之后从手机的"文件管理"里点它安装即可。

手上有校验工具的话，可以顺手算一遍 MD5，和第一节表里的 `619A8D5A7F76F7FA35FEDCB190D03883` 比一比。一致说明传输过程没出错；不一致就重新下一遍。不查也不影响安装，这只是多一层保险。

## 三、安装：系统会拦一次，放行即可

这一份是从网盘手动装的，不是从手机自带应用商店里点"安装"装的，所以点安装包时系统会拦一下，提示"不允许安装来自此来源的应用"之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开"文件管理"，进入 `Download` 目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的"设置"，打开**允许安装此来源的应用**开关。
   - 部分机型要去"设置 → 应用 → 特殊应用权限 → 安装未知应用"里，找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独给它放行。
3. 回到安装界面点"安装"，等进度条走完。
4. 出现"打开 / 完成"时点"完成"，先把安装流程走完再启动。

安装过程中如果提示"应用未安装"或"解析包出错"，通常是包没下完整或下载时被浏览器改名（例如多出一个 `.bin` 后缀）。重新从第二节走一遍即可。

## 四、首次打开怎么用起来

这个客户端没有引导页，进来就是一个很简单的主界面：上方是标题栏，中间是"选择图片"的按钮和用来粘贴图片链接的输入框，下方是当前选中的数据库。三条能走通的路径：

1. **在应用里选图**：点"选择图片"，从系统相册或文件里挑一张，选完立刻开始搜索，出结果后自动跳到结果页面。
2. **从别的应用分享过来**：在相册、浏览器或聊天软件里对着图片点"分享"，选 SauceNAO。这是手机上最省事的一条路，不用先把图存到本地再进来找。
3. **按图片链接搜**：手上有图片的直链（以 `http` 或 `https` 开头的图片地址）时，把它粘进"按图片链接搜索"的输入框提交。从别的应用分享一段链接文本过来，走的也是这条路。

数据库那一行默认显示"所有数据库"，意思是三十多个索引全搜一遍。要不要改、改成什么，见 [搜索数据库怎么选.md](搜索数据库怎么选.md)。三条路径的具体差别和结果页面怎么看，见 [怎么搜图和看懂结果.md](怎么搜图和看懂结果.md)。

另外提醒一句：装完之后它**不会向你申请相册或存储权限**——不是漏了，是这个客户端根本没有申请这类权限，选图走的是系统提供的挑图入口。它拿到了什么、上传的图去了哪，见 [上传的图会被保存吗.md](上传的图会被保存吗.md)。

## 五、怎么确认装的是该装的那一个

同名或近名的搜图应用在安卓上不少，判断标准只有一条：**包名是 `com.luk.saucenao`**。核对办法：设置 → 应用 → 找到 SauceNAO → 应用信息里看包名（部分机型显示为"应用详情 → 高级"）。

这个客户端是开发者 luk1337 以开源方式发布的，源码在 [GitHub 上的 SauceNAO 仓库](https://github.com/LuK1337/SauceNAO)，同时也上架了 [F-Droid](https://f-droid.org/packages/com.luk.saucenao/) 和 Google Play。所以你在这几个渠道看到的是同一个应用的不同分发方式，不是山寨——真正要提防的是包名不一样、却也叫这个名字的仿冒品。

需要说明的是，**它不是 SauceNAO 官方出的应用**：检索服务由 [saucenao.com](https://saucenao.com) 提供，客户端是第三方写的。所以客服、账号、检索范围这些问题，客户端这边管不了，能改的只有界面与搜索参数。

## 六、升级与卸载要注意的

- **升级**：新版本会换一个安装包文件名，直接装新包覆盖即可，不用先卸载。覆盖安装不影响已装好的东西。
- **卸载**：这个客户端不保存搜索历史，卸载重装的代价只是要把该选的选项重选一遍——你在右上角菜单里填过的 API 密钥会一起清掉，重装后要再填一次（见 [API密钥与搜索次数限制.md](API密钥与搜索次数限制.md)）。
- **安装包删了**：任何时候都能回到第二节那条 SauceNAO 安装文件资源的链接重新取一份；已经转存过的不受原分享是否还在的影响。
