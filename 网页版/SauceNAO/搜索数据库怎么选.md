## 一、这一行到底在选什么

SauceNAO 背后不是一个大库，而是几十个来源各异的索引拼起来的：每个索引对应一个平台或一类内容（某个插画站、某个图库站、动画索引之类）。搜索时你可以全搜，也可以只挑其中几个。

主界面那一行的显示规则要留意，它和一般"多选"的直觉相反：

| 显示 | 含义 |
| --- | --- |
| 所有数据库 | 一个都没勾，等于全搜 |
| 某个库的名字 | 只勾了一个 |
| N 个数据库 | 勾了两个及以上 |

所以想全库搜，做法是**把勾选清空**，而不是把所有条目都勾上——都勾上也能搜到同样多，但那一行会显示成"N 个数据库"，看着像被限制过。

## 二、三十八个索引，按用途分五类

按"你想找的东西在哪儿"来记，比背字母表有用：

| 类别 | 包含的索引 | 适合找什么 |
| --- | --- | --- |
| 插画与画师社区 | pixiv Images、Nico Nico Seiga、Nijie Images、drawr Images、Pawoo.net、Skeb、Twitter、bcy.net Illust、ArtStation、deviantArt、MediBang、PortalGraphics.net、2D-Market、Kemono | 插画的原作页、作者主页与作品 ID |
| 图库与贴图站 | Danbooru、Gelbooru、Konachan、Yande.re、Sankaku Channel、Idol Complex、Anime-Pictures.net、e621.net、FurAffinity、Furry Network、bcy.net Cosplay、Shutterstock | 角色图、壁纸、同人图的图库条目 |
| 漫画 | DoujinshiDB、Madokami (Manga)、MangaDex | 一页漫画出自哪部作品 |
| 动画与影视 | Anime、Movies、Shows | 动画、影视截图出自哪部、哪一集 |
| 成人向 | H-Magazines、H-Game CG、H-Misc (eH)、H-Misc (nH)、H-Anime、FAKKU | 内容分级为成人，名单前缀带 H |

两点补充：

- **图库那一类里也有不干净的**。`e621.net`、`FurAffinity`、`Furry Network` 这三个以兽类、拟人题材为主，内容分级参差不齐，但分类上不属于 H 开头的索引，所以它们不会被"避开 H 类"这个做法自动排除。
- **`Shutterstock` 是商业图库**，收录的是售卖的素材图，跟同人图不是一回事；你搜二次元插画时它基本只贡献噪声。

## 三、按你的目标来勾

| 你的目标 | 怎么勾 |
| --- | --- |
| 找一张插画的作者与原作页 | 只勾"插画与画师社区"那一组，其中最常用的是 pixiv Images |
| 找某张角色图的来源条目 | 勾"图库与贴图站"那一组 |
| 一页漫画找作品 | 勾"漫画"那一组 |
| 动画或影视截图找作品、集数 | 勾"动画与影视"那一组 |
| 不确定要找的是什么 | 保持"所有数据库" |

"动画与影视"这三个索引值得单说：命中这类索引的条目，元信息里除了作品名，还可能带上**集数与画面时间点**——这正是拿动画截图找番时最想要的信息。不过它同样受索引覆盖范围限制，不是每部作品都在里面。

## 四、收窄范围能解决什么、不能解决什么

- **不能提高命中率**。索引里没有这张图，你勾一个库或勾全部，都是"无结果"。收窄范围从来不是"搜不到就换库试试"的理由。
- **能减少噪声占位**。全库搜索时，某些索引会吐出一批相似度中等、但跟你要找的完全无关的条目，把你真正需要的那条挤到列表后面。只勾相关的那一组，列表会干净得多，通常也出得更快。
- **代价是可能漏掉跨类别的来源**。一张图画师发在插画站、同时被人搬到图库站，你只勾了图库那一组，就只看到搬运版的条目——元信息里的作者信息通常没有原作页全。

## 五、不想看到成人向结果怎么办

这个客户端里没有独立的内容分级开关，能做的只有一件事：**在选库时把那几类去掉**。

1. 打开"选择数据库"的勾选列表，把名字以 H 开头的六个索引取消勾选。
2. 顺手把 `e621.net`、`FurAffinity`、`Furry Network` 一起摘掉，见第二节的补充说明。
3. 这个做法只影响你接下来的搜索。哪天要找的图确实出自被摘掉的那几类库，把它们加回来再搜即可；需要全库搜索时，按第一节的做法把勾选清空。

要接受两个后果：一是**"无结果"的概率会变高**，因为不少图的原始出处本来就在被摘掉的那几个库里；二是少数条目的缩略图本身就属于不该在公开场合翻看的内容，摘掉相关索引后这种情况会明显减少。如果你需要更细的分级控制，网页版上提供了跟内容分级相关的过滤选项，客户端这边没有对应入口（两边的差别见 [和网页版及其他识图工具的区别.md](和网页版及其他识图工具的区别.md)）。
