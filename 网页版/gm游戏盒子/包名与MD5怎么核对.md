## 一、本份包的身份三件套

以下数据来自安装包本身（记录日期 2026-09-21），**本套文档所有涉及版本、包名、体积的说法都以这张表为准**：

| 项目 | 值 |
| --- | --- |
| 版本 | 3.13.1722 |
| 包名 | `com.fxwff.yxh08` |
| 大小 | 17.98M |
| MD5 | `fe5ac9ee132f7d0567975e598a13cc12` |

网盘里的 APK 文件名带版本号（形如 `gm游戏盒子_v3.13.1722.apk`），换新版时文件名会跟着变、分享链接不变，所以判断手头是哪一版，认文件名 + 下面的核对方法即可。

## 二、为什么网上搜到的对不上

同名页面各说各话是常态，你搜到的这些别拿来直接和上表比：

- **同名不同包**：同样叫「gm游戏盒子」的页面标的是 `com.btyx.gm`（版本 v1.1.3、体积 6.33M），叫「GM游戏盒」的另一处标的是 `com.gmgamebox.gmgb`（版本 1.1.0.5）—— 都和本份的 `com.fxwff.yxh08` 不同。**包名不同就是不同的应用**，界面像也不算同一个。
- **同版本号、MD5 却不同**：都标着 `3.13.1722` 的渠道页，MD5 却各写各的（如 `99ac4982b6b2474d6232116dd8e6cd11`、`39253BC95CBB45DE9B456810D63952E4`）。同一版本号在不同渠道可能是不同的打包，原因从外部无法确认 —— 结论只有一条：**对不上表里的 MD5 就别装**。
- **名称写法混乱**：渠道页有写 `gm游戏盒子`、`GM游戏盒`、`gm手游盒子` 的，页面标题不作数，认包名。
- **厂商一栏也分歧**：有的写「四川乐疯玩网络科技有限公司」，有的写「互联网」，两边并列放着，以应用内「关于」页显示的为准。

## 三、在电脑上算 MD5

把 APK 传到电脑，PowerShell 里执行：

```powershell
Get-FileHash -Algorithm MD5 ".\gm游戏盒子_v3.13.1722.apk"
```

或者用系统自带的 certutil（命令行窗口）：

```bat
certutil -hashfile gm游戏盒子_v3.13.1722.apk MD5
```

输出的 32 位十六进制与表里的 `fe5ac9ee132f7d0567975e598a13cc12` 完全一致（不区分大小写），就说明这份包没下坏，也不是别的东西冒名顶替。

## 四、在手机上看版本

**设置 → 应用 → gm游戏盒子 → 应用信息**，能看到版本号，与表里的 `3.13.1722` 比对。部分机型在这一屏或「更多」里会显示包名，不显示的机型就以版本号 + 电脑端 MD5 这两条判定，够用。

## 五、什么情况下需要核对

- 安装包**不是从本文档给的网盘拿的**，而是别人转发、或从别的页面下的；
- 装完发现**图标像、功能却对不上**（八成是装到了同名的另一个应用）；
- 文件大小和 17.98M 明显不符。

只要沾上一条就走一遍第三节；对不上就别装，回到 [下载与安装教程.md](下载与安装教程.md) 重新拿一份。装不上、装上闪退的处理，见 [打不开闪退怎么办.md](打不开闪退怎么办.md)。
