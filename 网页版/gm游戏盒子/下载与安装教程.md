## 一、先确认你要装的是哪一份

gm游戏盒子 是安卓端的游戏盒子：你在里面搜索游戏、下载游戏，顺带领礼包和代金券。客户端安装本身不收费，盒子里的游戏带充值入口（公开渠道页的资费说明写的是「游戏内充值购买」）。本篇讲的是**安卓 APK 这一份**，别拿安卓包去 iOS 上装。

网盘里这份包的参数（记录日期 2026-09-21），装之前先对一遍：

| 项目 | 数值 |
| --- | --- |
| 版本号 | 3.13.1722 |
| 包名 | `com.fxwff.yxh08` |
| 安装包大小 | 17.98M |
| MD5 | `fe5ac9ee132f7d0567975e598a13cc12` |
| 系统要求 | 安卓 5.2 以上（公开渠道页标注，以实际能不能装上为准） |
| 资费 | 客户端免费安装，游戏内充值；渠道页标注适龄 16 周岁以上 |

包名是安卓系统识别应用的唯一标识，比应用显示名可靠 —— 网上叫「gm游戏盒子」「GM游戏盒」的安装包不止一个，包名各不相同。核对时**认包名，别只看图标和名字**，同名应用怎么区分见 [包名与MD5怎么核对.md](包名与MD5怎么核对.md)。

各渠道页对厂商的写法不一致（有的写「四川乐疯玩网络科技有限公司」，有的直接写「互联网」），两边并列放着，以应用内「关于」页显示的为准。

## 二、从网盘拿到安装包

1. 打开 [gm游戏盒子 安装文件资源（夸克网盘）](https://pan.quark.cn/s/32c53c8dd58d)，把分享内容转存到自己的网盘（转存后长期有效，不怕分享失效；不转存也能直接下载）。
2. 网盘里的应用文件夹名是 `gm游戏盒子（先保存再下载）`，APK 文件名形如 `gm游戏盒子_v3.13.1722.apk`，旁边还有一个说明 txt。
3. 手机上用夸克 App 登录同一账号，找到该文件下载；也可以先在电脑上下载，再通过数据线、局域网传输或聊天工具把 APK 发到手机。
4. 下载完成看文件大小是否接近 17.98M，明显偏小说明没下完整，重下一次。

要校验完整性，把 APK 传到电脑算一遍 MD5（命令见 [包名与MD5怎么核对.md](包名与MD5怎么核对.md)），结果应当是 `fe5ac9ee132f7d0567975e598a13cc12`；对不上就别装，重新下载。

转存完在网盘里找不到文件、提示空间不足、或者下载速度让人着急的，实操路径都在 [网盘转存与下载太慢怎么办.md](网盘转存与下载太慢怎么办.md)。

## 三、手机上安装步骤

安卓从应用商店之外装 APK，需要你手动放行一次：

1. 用文件管理器点开 APK，系统大概率弹「禁止安装来自此来源的应用」—— 这是标准安全拦截，不代表文件有问题。
2. 按提示进入**设置 → 允许安装来自此来源的应用**（有的机型叫「安装未知应用」），给文件管理器或浏览器授一次权，装完可以再关掉。
3. 返回继续安装，等进度走完点「打开」。
4. 华为等机型如果开着**纯净模式**，会在安装前后额外拦一道：设置 → 系统和更新 → 纯净模式，关掉再装，装完按自己习惯决定要不要开回来。
5. 首次启动会要求同意用户协议与隐私政策，同意后进首页。盒子的游戏列表要联网加载，第一次打开建议在 Wi-Fi 下进。

装不上或报「解析包出问题」，多半是包没下完整，回到第二节重下；其他报错的处理按类型分好了，见 [打不开闪退怎么办.md](打不开闪退怎么办.md)。

## 四、装完核对：确认没装错

到 **设置 → 应用 → 找到 gm游戏盒子 → 应用信息**，看三项：

- 版本号应显示 `3.13.1722`；
- 包名应为 `com.fxwff.yxh08` —— 部分机型在这一屏或「更多」里直接显示包名，不显示的机型就跳过这条，改用版本号 + MD5 判定；
- 来源是你自己网盘里下的文件，而不是来路不明的应用商店。

三项都对，装的就是网盘这一份。装好之后怎么在里面找游戏、签到领福利，接 [签到代金券礼包怎么领.md](签到代金券礼包怎么领.md)；打开就闪退的，直接翻 [打不开闪退怎么办.md](打不开闪退怎么办.md)。
