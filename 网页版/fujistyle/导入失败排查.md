## 一、USB 方式：三类常见症状

### 1. 设置写进去了，拍出来却没变化

先看相机是不是在 **M 档（手动曝光）**。官方教程明确提到：部分设置在自动 / 半自动档位下会被相机的自动逻辑覆盖，看起来就像没导入成功。切到 M 档再验证；另外确认你导入的目标槽（C1–C7）和你拨盘上选的槽是同一个。

相机侧还有两个开关会造成「没生效」的错觉：

- **拍摄格式设成了 RAW**：RAW 不经过机内的胶片模拟处理链，颗粒、Color Chrome 效果都不会出现在文件上，要直出胶片感请拍 JPEG；
- **开了自然实时取景（Natural Live View）**：屏幕预览与最终 JPEG 不一致，实际拍一张回看才知道真实效果。

如果参数确实写进去了、只是颜色跟社区样张不一样，那不是导入失败，是复刻偏差的问题：见 [为什么配方颜色对不上.md](为什么配方颜色对不上.md)。

### 2. 相机连不上

按官方给的顺序逐项检查：

1. 相机的 USB 连接模式设置对了没有——配方同步用 `USB RAW CONVERSION / BACKUP RESTORE`（X-M5 可能要用 `USB TETHER SHOOTING (FIXED)`），设置路径见 [配方导入相机教程.md](配方导入相机教程.md) 第三节。
2. 手机的 **OTG** 开了没有（下一节专门讲）。
3. 线能不能传数据——换一根确定能传数据的 USB 线试，很多「充电线」插上只有电流没有数据。
4. 还不行就换一个 OTG 转接头（Type-C OTG）再试。

### 3. 提示「相机被占用 / in use」

说明相机的 USB 通道被别的应用先占了。官方的处理办法：检查有没有相册、文件管理器、USB 工具类的应用正在通过 USB 访问相机，把这些后台应用清掉再重连。

## 二、OTG：安卓连相机的第一道坎

OTG（On-The-Go）让手机充当「主机」去驱动外接设备。OTG 关着（或手机不支持）时，手机可能只给相机充电、根本认不出设备。

- **最快的开法**：系统设置顶部搜索栏搜 `OTG`，把 `OTG` / `OTG 连接` / `USB OTG` 打开。
- **有的手机没有这个开关**：插入设备时自动生效，搜不到开关不算异常。
- **有的品牌会自动关闭**：一段时间不用后 OTG 自动关掉，重开即可。
- 官方另有一份 OTG 报错与 USB 使用设置的修复文档：[docs.fujistyleapp.com/OTG_iSSUE_FIX](https://docs.fujistyleapp.com/OTG_iSSUE_FIX)。

## 三、无线方式：失败多半是干扰

官方 FAQ 的口径是：无线连接走 Wi-Fi 与蓝牙，受电磁干扰影响，**偶发失败属于正常现象**，不是坏了。按下面顺序处理：

1. 重启手机与相机的蓝牙；
2. 把相机里保存的旧无线配对记录删掉，再重新配对；
3. 所处环境信号干扰大（室外强光、距离远、电磁环境复杂）时，直接改用 USB 有线导入——官方自己也说有线的稳定性好得多；
4. 反复配对失败时，在相机 `CONNECTION SETTING` 里选 `RESET WIRELESS SETTING` 重置后从头配（步骤见 [配方导入相机教程.md](配方导入相机教程.md)）。

另有一层原因要先排除：无线导入是 **Beta 且限定机型**的功能，你的机型不在已开放名单里的话，怎么试都连不上。USB 能用、无线搜不到的机型差异见 [支持相机型号与预设槽位.md](支持相机型号与预设槽位.md) 第三节。

## 四、都试过了还不行

- 带着「机型 + 现象 + 已试过的步骤」发邮件给官方：`fujistyleinfo@163.com`；
- X-T30 II 的用户优先看官方博客里的 X-T30 II 专项排查指南（[www.fujistyleapp.com/blog](https://www.fujistyleapp.com/blog)），其他机型遇到类似问题也能参考；
- 确认一下机型确实在支持列表里：[支持相机型号与预设槽位.md](支持相机型号与预设槽位.md)。
