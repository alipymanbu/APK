## 一、先搞懂：几种登录方式就是几个独立账号

你可以用 Google、KakaoTalk、Facebook、MBC Plus 官网账号等不同方式登录，官方 FAQ 明确说明：**每种登录方式各自独立管理等级和昵称**，互不相通。

这解释了一个最常见的惊悚场景——打开应用发现等级、昵称、点数全变了：系统不存在「自动重置」，大概率是你这次用了另一种登录方式，进了一个新账号。处理办法就是退出登录，改回原来的方式重新登录。

新用户注册时就要把这事当回事：选定一种登录方式后固定用它，别今天用谷歌明天用 Kakao，攒的点数分散在几个账号里最亏。

## 二、ID / 密码找不回来时怎么办

出于隐私保护，连官方运营者也看不到你的 ID 和密码。找回路径：

1. **记得登录方式** → 去对应平台（Google / Facebook / Kakao / MBC Plus 官网等）走它们自己的「找回 ID / 密码」流程；
2. **想不起当初用的哪种方式** → 发邮件到 `mbcplus@mbcplus.com`，写清两件事：
   - 要找的账号昵称；
   - 使用该账号的大致月份（写「大约 3 月到 5 月」这种模糊范围也行）。

官方会帮你查出这个昵称当时是用哪种方式登录的，之后再按第一种情形找回。

## 三、退会前必须知道的事

官方退会页把后果列得很直白，确认前逐条看完：

| 退会后发生什么 | 说明 |
| --- | --- |
| 等级与点数全部消失 | Time / Ruby / Star 三种点数连同使用记录一起删除，无法恢复 |
| 账号立即删除 | 同一个 ID 不能恢复、也不能重新注册 |
| 想回来只能换账号 | 重新注册要用另一个账号，等级和点数不迁移 |

一句话：退会 = 这个账号的一切清零。只是暂时不想用了的话，卸载应用就够了，账号和点数都留着。

## 四、退会的操作路径

1. 打开应用，进首页右上角的菜单按钮；
2. 点昵称旁边的人形图标，进入「我的信息」（MY）；
3. 拉到页面最底部，点「会员退会」（회원 탈퇴）；
4. 核对注意事项与将被删除的信息，最终确认后完成退会。

如果账号已经登不进去、又需要删号，改走邮件：发到 `idolchamp@mbcplus.com` 说明退会或删除账号信息的诉求，**邮件里务必附上你的昵称**。

## 五、两个官方邮箱各管什么

- `mbcplus@mbcplus.com` —— 查「当初用哪种方式登录的」这类账号找回问题；
- `idolchamp@mbcplus.com` —— 退会、账号信息删除等请求与咨询。

发信都带上昵称，能省一轮往来。日常使用问题（打不开、投票、点数）先过一遍 [常见问题与故障排查.md](常见问题与故障排查.md)；点数规则本身见 [投票点数CHAMSIM详解.md](投票点数CHAMSIM详解.md)，注册流程的完整说明在 [注册与登录指南.md](注册与登录指南.md)。
