## 一、安装环节的问题

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 点安装没反应 / 「应用未安装」 | 系统版本低于要求 | 13.3.2 版需要 Android 8.0 以上，先在设置 → 关于手机里确认系统版本 |
| 「解析包出错」 | 安装包没下完整或被损坏 | 核对 MD5（`40F6915B5D30291A396C760037F96ADB`）后重新获取 [Funimate 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4846ac449999) |
| 提示「禁止安装未知来源应用」 | 没给文件管理器授权 | 按安装教程第三节的品牌路径放行 |
| 安装到一半失败 | 存储空间不足 | 264 MB 的包加上运行空间，建议预留 2 GB 以上再装 |
| 与旧版本冲突 / 覆盖安装失败 | 设备上已有别的来源装的同包名版本（包名 `com.avcrbt.funimate`） | 先卸载旧版再装；卸载会清掉本地草稿，先导出再动 |
| 装上后闪退或打不开 | 设备处理器不兼容（此包为 arm64-v8a） | 在 arm64 真机上安装；模拟器环境不在常规支持范围 |

覆盖安装失败那一条多见于「商店版 + 网盘版」混装的设备，卸载重装二选一即可，别来回切换。

## 二、使用中的常见问题

| 问题 | 说明与处理 |
| --- | --- |
| 导出的视频有水印 | 免费版导出带 Funimate 水印，去除水印是 PRO 订阅功能；价格与档位以应用内当时显示为准 |
| 广告太多 | 广告是免费版的常态；去除广告包含在 PRO 订阅权益里，档位与价格以应用内当时显示为准 |
| 找不到某个特效 | 特效库随版本更新，部分特效按地区或活动轮换；换到特效入口重新浏览，或确认应用是否为可更新的版本 |
| 音乐库里找不到某首歌 | 曲库按地区与版权情况变化，用本地音频替代最稳 |
| 误触发了订阅扣款 | 订阅走应用商店支付。Android 扣款 48 小时内可在 Play 商店订单记录里申请退款，iOS 走 `reportaproblem.apple.com`；完整步骤见 [订阅取消与退款流程.md](订阅取消与退款流程.md) |
| 想注销账号 | 设置里「Others」区的「停用账户（Deactivate Account）」入口；注意停用账号**不会**取消订阅，订阅要在商店里单独取消（见 [订阅取消与退款流程.md](订阅取消与退款流程.md)） |
| 收到骚扰评论或看到不当内容 | 长按评论可举报；账户设为私密可限制陌生人评论，方法见 [账号注册与隐私设置.md](账号注册与隐私设置.md) |

## 三、重装的标准流程

上面修不好的，按这个顺序重装一遍：

1. 备份：把相册里已导出的成片确认保存好（应用内未导出的草稿会随卸载丢失）。
2. 卸载当前版本。
3. 重新获取安装包（入口在 [下载与安装教程.md](下载与安装教程.md) 第二节），核对 MD5 后安装。
4. 首次启动重新授权存储权限；要继续用社区功能就登录原账号。

## 四、报错时先收集什么

到应用商店评论区或官方支持邮箱（`support@funimate.com`，官方联系页还列有 `support@pixerylabs.com`；官方站 [www.funimate.app](https://www.funimate.app) 也有支持入口）反馈问题时，把这几项写上，处理效率高很多：设备型号与系统版本、应用版本号（设置或商店页可查）、触发问题的具体操作步骤、报错截图。剪辑与导出环节的操作问题先看 [视频剪辑功能与特效怎么用.md](视频剪辑功能与特效怎么用.md)，多数是入口没找对。
