## 一、先核对安装包信息

Funimate 是 AVCR Inc. 出品的手机端视频剪辑应用，Android 与 iOS 双平台都有。下面是安卓安装包的实际信息，装之前先对一遍，确认拿到的是同一份：

| 项目 | 内容 |
| --- | --- |
| 版本 | 13.3.2 |
| 包名 | `com.avcrbt.funimate` |
| 安装包大小 | 约 264.28 MB |
| MD5 | `40F6915B5D30291A396C760037F96ADB` |
| 适用系统 | Android 8.0 及以上（第三方应用库对该版本的标注，以官方商店页面当时显示为准） |
| 处理器架构 | arm64-v8a |

几点说明：

- 版本、大小、MD5 以网盘里这份安装包为准；官方商店的最新版号会不断更新，两者经常不是同一个版本，不影响安装使用。
- Android 8.0 以下的设备装这个版本会直接报解析错误，先确认系统版本（设置 → 关于手机 → Android 版本）。
- 官方渠道也发布过 13.3.2 版的 XAPK 安装包，同样标注 Android 8.0 以上，与这份包的口径一致。

## 二、获取安装包

从 [Funimate 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4846ac449999) 转存到自己的网盘后，用夸克网盘客户端把文件下载到手机本地存储（建议放在 `Download` 目录，方便后面找）。

下载完成后先核对文件大小是否在 264 MB 左右。体积差得多的，多半是没下完，别急着装。

## 三、允许安装外部来源的应用

不是从应用商店装的包，安卓默认会拦。需要给「负责打开这个包的应用」（一般是文件管理器或浏览器）放行：

| 手机品牌 | 大致路径 |
| --- | --- |
| 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / vivo | 设置 → 安全 → 安装未知应用 |
| 三星 | 设置 → 应用程序 → 右上角菜单 → 特殊权限 → 安装未知应用 |

找不到入口时，直接在系统设置顶部搜索「未知」两个字，大多数系统都能搜到这一项。装完之后建议把授权关回去。

## 四、安装步骤

1. 打开文件管理器，进入刚才的下载目录，点 `Funimate_v13.3.2.apk`。
2. 系统弹出「是否安装此应用」时点「安装」，等进度条走完（这个包不小，可能要十几秒）。
3. 点「打开」或回到桌面，从图标进入应用。

安装到一半失败或报错的，按 [安装失败与常见问题排查.md](安装失败与常见问题排查.md) 的表格对号入座。

## 五、用 MD5 核对安装包完整性

如果下载过程中断过、或装的时候总报「解析包出错」，先核对 MD5，确认文件本身没坏：

```powershell
# Windows（PowerShell）
certutil -hashfile "D:\Download\Funimate_v13.3.2.apk" MD5
```

```bash
# macOS / Linux
md5sum Funimate_v13.3.2.apk
```

算出来的值与第一节表格里的 MD5 一致（大小写不敏感）就说明文件完整；不一致就是没下完整或被改动过，重新下载一遍即可。

## 六、首次启动注意什么

- 第一次打开会依次申请存储/媒体权限（读照片和视频做剪辑素材），允许后才能在素材选择页看到自己相册的内容。
- 应用内带社区功能，打开后会有登录引导；注册方式与隐私设置见 [账号注册与隐私设置.md](账号注册与隐私设置.md)。
- 免费使用时会看到广告，部分特效与素材包标注了 PRO 标记；这些不影响基础剪辑功能的试用，具体收费口径见 [视频剪辑功能与特效怎么用.md](视频剪辑功能与特效怎么用.md) 的导出一节。
- iOS 用户没法用 APK，需要从 App Store 搜「Funimate」安装，本篇不覆盖 iOS 流程。
