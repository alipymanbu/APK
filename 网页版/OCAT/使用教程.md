## 一、一条学习循环：问句 → 收藏 → 磨耳朵

OCAT 的玩法围绕「句子」而不是「单词」展开，你实际会反复走这条循环：

1. **用母语输入想表达的话**。比如直接输入「这个多少钱」，不需要自己组织成「请告诉我这句日语怎么说」，应用会理解你的意图并返回地道的说法。
2. **查看返回的句子**。日语句子自带平假名注音，你不用再单独查读音；点一下句子就能播放发音。
3. **觉得以后用得上就收藏**。收藏时可以放进你自建的收藏夹，比如「点餐」「问路」「工作寒暄」，分类方式完全由你定。
4. **回到收藏夹循环播放**。后台循环播放时可自定义播放间隔、语速，以及是否附带翻译——通勤、做家务时把耳朵泡在句子里。
5. **忘上下文时用「场景回顾」**。每条收藏的句子都能一键跳回当初的对话现场，看它是在什么语境下出现的，记忆更牢。

这套循环围绕的是「背单词不如背句子」：你收藏的每一句都来自你自己的真实表达需求。还没装上的话，先看 [下载与安装教程.md](下载与安装教程.md)。

## 二、放大展示：把手机当临时翻译器

句子支持放大显示。面对面和外语使用者沟通、一时说不出口时，你可以把刚才查到或收藏的句子放大到整屏递过去看。这个场景下 OCAT 相当于一块「写字板」——你不需要对方装任何应用，也不需要来回递手机输字。

实际使用建议：

- 出发前把高频场景（机场、酒店、餐厅）的句子提前查好、收进一个收藏夹，现场直接调出来放大，比临场打字快；
- 放大显示配大字号，非常适合给不熟悉手机操作的老人看。

## 三、收藏夹管理：养你自己的句库

收藏夹是 OCAT 的重心，几个实用操作：

| 操作 | 说明 |
| --- | --- |
| 自定义收藏夹 | 按场景或主题建夹子，句子可以归类整理 |
| 竖排排版 | 收藏列表支持竖排显示，符合日语阅读习惯 |
| 句库合集 | 可以把收藏组织成句库合集，成套复习 |
| 场景回顾 | 从收藏的句子跳回原始对话，重现学习现场 |

句子的价值在于「真正属于你」：别人分享的词表你未必用得上，而你自己问出来的句子几乎都来自你生活里真的想说的话。收藏夹积累一段时间后，它就是你个人表达需求的清单。

## 四、主题对话与测试模式

除了「你问我答」式的句子查询，还有几个进阶玩法：

- **主题对话模式**：围绕某个话题与 AI 持续对话，适合想成段练习表达的时候；对话中冒出来的好句子照常点播、收藏。
- **测试模式**：检验你对收藏句子的掌握情况，适合阶段性自查——收藏了一堆句子之后，隔几天测一轮，看哪些已经能脱口而出、哪些还得回炉。
- **影子跟读**：收藏夹里的句子从「听得熟」练到「说得出」的系统方法，含录音回听与复习安排，单独成篇，见 [影子跟读怎么练.md](影子跟读怎么练.md)。

## 五、播放与语音设置

收藏夹循环播放相关的可调项：

| 设置项 | 你能调什么 |
| --- | --- |
| 播放间隔 | 句与句之间留白多久，方便跟念或回想 |
| 语速 | 由慢到快，初学从慢速开始 |
| 是否附带翻译 | 磨耳朵后期建议关掉翻译，强迫耳朵直接对应外语 |
| 睡眠倒计时 | 设定时长后自动停止播放，适合睡前磨耳朵 |
| 朗读音色 | 应用内置了较为自然的朗读音色，可按喜好选择 |

配合节奏：前几个星期多「问 + 收」，把循环播放当背景音；句库有一定规模后加测试模式自查，想练开口就进入跟读（[影子跟读怎么练.md](影子跟读怎么练.md)）；坚持每天磨一段耳朵，比周末突击两小时有效。

订阅与免费额度决定了你能问多少句、合成多少条语音，具体规则见 [订阅价格与免费额度.md](订阅价格与免费额度.md)；使用中碰到额度、语音、账号类问题，先翻 [常见问题解答.md](常见问题解答.md)。
