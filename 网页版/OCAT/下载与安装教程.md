## 三、安卓安装步骤

1. 从上面任一渠道拿到 APK 安装包（网盘渠道为 `OCAT_v3.1.1.apk` 这类命名，以实际文件为准）。
2. 在文件管理器里点开该 APK。系统第一次安装来自浏览器或网盘的应用时会提示「未知来源」，允许后继续。
3. 等待安装完成，首次打开应用会请求联网权限——它的核心功能（获取地道句子、语音合成）都需要联网才能用。
4. 注册或登录账号后即可开始使用；学习循环的具体玩法见 [使用教程.md](使用教程.md)。

如果安装按钮点了没反应，或者提示「解析包错误」，先核对两件事：安装包是否完整下载（文件大小应接近 51.64M），以及你的系统版本是否满足要求。这两点排查思路在 [常见问题解答.md](常见问题解答.md) 里有展开。

## 四、核对文件完整性（MD5 校验）

如果你对安装包的来源渠道不放心，或者下载中断过、怀疑文件损坏，可以用 MD5 值做一次完整性比对：

| 工具 | 操作 |
| --- | --- |
| Windows 命令行 | `certutil -hashfile "OCAT_v3.1.1.apk" MD5` |
| macOS / Linux | `md5sum OCAT_v3.1.1.apk`（macOS 用 `md5` 命令） |
| 安卓文件管理器 | 多数主流文件管理器的「文件属性」里能直接看到 MD5 |

比对基准是第一节的 `98A81B369C6D1A1385811A3A2670F4CF`（MD5 值大小写不敏感，字母 A–F 等价）。两边一致说明文件完整；不一致就重新下载一份，不要强行安装。
