# Bitdefender 卸载与设备管理员怎么撤

> 开了防盜之后直接卸载会被系统拒绝，忘了 PIN 更会卡在这一步。本篇给出两条卸载路径、PIN 的找回位置，以及撤权之后哪些能力会消失。

卸载失败这件事几乎只发生在一个前提下：防盜功能已经开启，应用拿到了**设备管理员**权限。Android 的设计是这种应用不能被动卸载，必须先把权限撤掉。本篇两条路径覆盖有 PIN 和没 PIN 两种情况，按你手上有什么选一条走。

## 一、路径一：应用内卸载（记得 PIN 就走这条）

1. 打开 Bitdefender，进 **More（更多）**。
2. 点导航里**你自己的邮箱账号那一行**。
3. 往下滚动，找到 **Uninstall Bitdefender Mobile Security** 并点它。
4. 按提示输入你设过的 **应用 PIN 码**。
5. 确认删除。

判断该走哪条路径的标志：**More → 账号页面里有没有「Uninstall」这一项**。

- 有 → 说明已授予设备管理员权限，走上面的流程，它会顺手把权限一起撤掉。
- 没有 → 说明当时没给设备管理员权限，直接用系统的常规卸载即可（设置 → 应用 → Bitdefender → 卸载）。

## 二、路径二：撤设备管理员再常规卸载

忘了 PIN、或者应用内卸载走不通时用这条：

1. 打开系统「设置 → 安全（或 隐私 → 更多安全设置）」。
2. 找到 **设备管理应用 / 设备管理员（Device administrators / Device admin apps）**。
3. 在列表里点 **Bitdefender**，把它的开关关掉，或取消勾选。
4. 系统会弹出确认，点**停用 / Deactivate**，再确认一次。
5. 回到「设置 → 应用 → Bitdefender」，点**卸载**并确认。

撤权时系统会提示防盜相关能力将失效，这是正常提示，按确认继续即可。

## 三、忘了 PIN：先去账号里把它取回来

PIN 存在你的账号里，能取：

1. 登录 [central.bitdefender.com](https://central.bitdefender.com)。
2. 进「我的设备（My Devices）」，点这台 Android 设备的卡片。
3. 点右上角 **Rename（重命名）**，面板里的 **Application PIN** 字段就是这个码。

拿到 PIN 后走路径一最省事；取不回来就直接走路径二，两条路都能卸载成功。

## 四、撤权之后会失去什么

设备管理员权限只服务于防盜这一块，撤掉之后这些能力会一起失效：

| 能力 | 撤权后的状态 |
| --- | --- |
| 远程锁定设备 | 不可用 |
| 远程清除设备数据 | 不可用 |
| 抓拍照片并同步到账号 | 不可用 |
| 输错 PIN 后的持续拦截 | 不再生效 |
| 恶意软件扫描、网页保护、来电拦截 | 不受影响，照常工作 |

也就是说，如果你只是嫌卸载麻烦，而不需要防盜，可以先撤权把应用继续用着，不用整个卸掉。

## 五、卸载之后要收的尾

- **辅助功能权限会留一条空记录**。系统「设置 → 无障碍 / 辅助功能 → 已下载的服务」里可能还留着 Bitdefender 这一条，点进去确认已关闭即可；重装新版本后需要重新打开。
- **通知栏的常驻通知消失**是正常的，那条通知来自它的前台服务，程序没了通知也没了。
- **账号里的设备记录还在**。不打算再用这台设备的话，可以在 Central 的设备列表里留意一下这条记录；留着也不影响使用，只是列表里会多一台。
- **订阅不会因为卸载而变化**。卸载只是移除手机上的程序，账号里的订阅状态与到期时间另算，是否退订、怎么退，以官方订阅条款为准。

## 六、想重装的话

卸载后再装回来，有两点提前知道会省事：

1. **被清掉的设置需要重做**：应用锁勾选的应用、Smart Unlock 的受信任网络、防盜开关都不会跟着回来，得重新设一遍。要在意的，卸载前先把这几项记下来（对应的设置在 [应用锁防盜与VPN怎么用.md](应用锁防盜与VPN怎么用.md) 里）。
2. **安装包还是那一份**：如果手机里的包已经删了，重新取一份就行 —— [Bitdefender 安装文件资源（夸克网盘）](https://pan.quark.cn/s/03d1856aee1e) 里放的是同一款，装法与核对要点见 [下载与安装教程.md](下载与安装教程.md)。

装回后登录同一个账号，设备会重新出现在 Central 的列表里，订阅自动跟着账号生效，不需要重新激活。
