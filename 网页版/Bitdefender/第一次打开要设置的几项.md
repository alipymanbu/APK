装好只是把程序放进了手机，真正的防护开关分散在几个地方：账号没登录进不去主界面，辅助功能不开网页与诈骗防护就是灰的，设备管理员不放手防盜和卸载都会出问题。本篇按「先做什么、后做什么」排一遍，对应网盘里那份 3.3.238.2429（包名 `com.bitdefender.security`）。

## 一、先认一遍界面

底部导航栏是后续所有操作的入口：

| 位置 | 名称 | 干什么 |
| --- | --- | --- |
| 左起第一 | Dashboard（仪表盘） | 顶部是设备安全状态卡片，下面是各功能的状态与快捷动作 |
| 左起第二 | Protection（防护） | 恶意软件扫描、网页保护、诈骗防护、来电拦截 |
| 左起第三 | Privacy（隐私） | VPN、应用锁、身份保护 |
| 左起第四 | Performance（性能） | 电池与资源相关的设置 |
| 最右 | More（更多） | 设置、报告、活动日志、账号与卸载入口 |

菜单名称与栏目划分随版本有过调整，装的语言不同叫法也不同；如果你看到的是英文界面，对照表在 [中文界面与语言设置.md](中文界面与语言设置.md)。

## 二、登录：这一关过不去就什么都做不了

1. 首次打开会要求把设备绑定到一个 **Bitdefender 账号**。填邮箱密码，或点 Google / Facebook / Microsoft 账号登录。
2. 没有账号就在同一页注册，注册完成会回到应用。
3. 登录位置很关键：**在应用内登录，这台设备才会出现在网页端 [central.bitdefender.com](https://central.bitdefender.com) 的「我的设备」里**。后续要远程定位、锁机、找回应用 PIN，都靠这条设备记录。
4. 没登录成功的表现是：主界面进不去，或进去后功能卡片全是灰的。这种状态下先检查网络与账号密码，再排查是不是系统的省电策略把它的前台服务杀了。

## 三、订阅状态：14 天试用与到期后的变化

配置向导里的第一项就是订阅状态（Subscription Status），这一项决定了功能能用多久。

- **新账号默认有 14 天免费试用**，试用期内所有功能都是开的。
- **手上如果有激活码**，在这一步选「I have a code / 我有激活码」，填进去激活，激活后这份订阅的有效期会在同一页显示。
- **到期后会怎样**：官方说明产品的防护功能需要有效订阅支持，订阅结束后相关功能会停止工作。也就是说网盘里这份包不是「装完永久可用」，订阅状态请在应用内或网页端账号页确认。
- **状态在哪看**：应用内走 More → 账号邮箱那一行，能看到当前订阅；网页端登录 Central 后同样能看到。

续费、升级到多设备版本这类事都在官方渠道办，别在别处找所谓的激活方式。不想继续用了要提前关掉自动续费（默认是开启的），关续费、退款的路径与时间窗口见 [订阅续费与退款怎么处理.md](订阅续费与退款怎么处理.md)。

## 四、辅助功能权限：网页保护与诈骗防护的前提

- 网页保护（Web Protection）和诈骗防护（Scam Alert）要读你浏览器、聊天应用里的链接，靠的是 Android 的**辅助功能服务**。
- 配置向导里会出现一个「ACTIVATE / 开启」按钮，点它会被跳到系统的辅助功能页面；在那个列表里找到 Bitdefender，把开关打开。
- 如果跳转后你自己退出来了，或者后来被系统清理提醒关掉了，功能会静默失效 —— 应用内对应卡片会提示未启用。手动路径：系统「设置 → 无障碍 / 辅助功能 → 已下载的服务」。这一步的失败方式很典型：息屏后应用被省电机制停掉，这项授权被系统一并收回，于是网页保护、诈骗防护、来电拦截一起失效，应用会提示**网页保护被另一个服务关闭了**。遇到这种情况，光把开关重新点开没用，必须先在系统侧放开它的后台 —— 逐品牌的路径在 [网页保护总被关掉怎么办.md](网页保护总被关掉怎么办.md) 里。

## 五、设备管理员：防盜和正常卸载都绕不开

- 开启防盜（Anti-Theft）时，应用会请求**设备管理员（Device administrator）**权限。Android 上远程锁机、远程清除这类能力必须以这个权限为前提。
- 同一套权限也是卸载的前置条件：不撤权，卸载会被系统拒绝。相关的处理集中写在 [卸载与设备管理员怎么撤.md](卸载与设备管理员怎么撤.md)。
- 加上这道权限后，系统「设置 → 安全 → 设备管理应用」里会多出一条 Bitdefender。别在不知情的情况下把它关掉 —— 关掉等于防盜失效。

## 六、通知权限与后台保活

这两项决定了「出事了你会不会知道」和「过几天它还在不在干活」。

1. **放行通知**：在系统「设置 → 应用 → Bitdefender → 通知」里允许通知，并把它设为重要，别归到会折叠的静默分类里。扫描结果、拦截记录、状态异常都通过它提醒你。
2. **解除电池优化**：在「设置 → 应用 → Bitdefender → 电池」里设为**不优化 / 无限制**。
3. **允许自启动**：有的系统叫「后台自动启动」「自启动管理」，把它打开。
4. **在最近任务里锁定它**：上滑清理后台时不会顺手把它清掉。

各家定制系统的路径差别很大，找不到上述开关时用系统设置里的搜索框直接搜应用名；小米、华为、三星、OPPO、vivo、一加等 13 个品牌的具体路径列在 [网页保护总被关掉怎么办.md](网页保护总被关掉怎么办.md) 的对照表里，照着找比自己翻菜单快。

## 七、最后跑一次完整扫描

配置向导的末尾会让你立刻扫描一次，建议就地在这一步把首次扫描做完：

- 首次扫描会检查已安装的应用与存储内容，耗时与应用数量、存储容量有关，插着 SD 卡会更久。
- 扫描结果的处理方式、以及实时防护各项开关的说明，见 [扫描与实时防护怎么用.md](扫描与实时防护怎么用.md)。
- 扫描完成后回到仪表盘，状态卡片应当是「安全 / 无问题」类的正常提示，说明这一套配置走通了。
