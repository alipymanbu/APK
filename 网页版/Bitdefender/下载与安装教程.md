安卓上的 Bitdefender 属于「装完必须要有一个账号才能用」的那类安全软件，所以安装这件事不只是把 APK 点开：先要确认网盘里这份包是哪一个产品（Bitdefender 名下有好几个同名软件），再走完未知来源、条款同意、账号登录这几步。本篇按顺序把这条链走完。

## 一、先核对网盘里这份包

网上搜到的通常是官方当前最新版，与网盘里这份往往不是同一个版本号。本篇出现的版本、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Bitdefender |
| 产品名 | Bitdefender Mobile Security & Antivirus（安卓版） |
| 版本号 | 3.3.238.2429 |
| 包名 | `com.bitdefender.security` |
| 安装包体积 | 72.21 MB |
| MD5 | `1946D4CC5FDB442CF2DE988F90F424C2` |
| 开发方 | Bitdefender（罗马尼亚） |
| 核对时间 | 2026-09-23 |

安装包本体在 [Bitdefender 安装文件资源（夸克网盘）](https://pan.quark.cn/s/03d1856aee1e) 里，转存到自己的网盘再下载到手机。

几点要分清：

- **官方渠道在哪**：产品页是 [bitdefender.com 手机安全页](https://www.bitdefender.com/consumer/mobile-security-android)，账号与设备管理在 [central.bitdefender.com](https://central.bitdefender.com)，应用商店页是 [Play 商店的 Bitdefender Mobile Security](https://play.google.com/store/apps/details?id=com.bitdefender.security)。想确认手上这份是不是同一款，认包名 `com.bitdefender.security` 最快。
- **这份是付费产品线，不是免费版**：Bitdefender 在安卓上还有一款叫法相近的免费产品，包名不同、功能范围也小一圈。装之前先看 [同名产品与官方渠道怎么认.md](同名产品与官方渠道怎么认.md)，避免装完发现少了你要的那个功能。
- **版本会往前走**：官方会持续更新，新版里菜单名称与功能位置可能有调整。本文按 3.3.238.2429 写，具体以你手上这版界面显示为准。
- **MD5 怎么用**：下载完用文件管理器看文件详情，或任意校验工具算一次 MD5，与上表一致说明传输没损坏；体积明显小于 72.21 MB 就是没下完，别装。

## 二、装之前先确认两件事

**1）系统版本够不够。** 官方英文站现在标注的要求是 **Android 7.0 及以上**，繁体中文站标注的是 **Android 6.0 及以上**，并注明 Scam Protection 与 App Anomaly Detection 需要 Android 6 及以上（以官方页面当时显示为准）。两处口径不一致，说明这条底线随版本调整过；为避免装完功能缺一块，建议以 Android 7.0 为实际底线。查看自己的版本：系统「设置 → 关于手机 → Android 版本」。

**2）先准备好一个账号和网络。**

- 这份包必须**联网**才能用：它能判断一个应用是否安全，靠的是把信息送到云端比对，断网状态下扫描也会走不动。
- 必须登录一个 **Bitdefender 账号**才能进入主界面。可以用邮箱注册，也可以直接用 Google / Facebook / Microsoft 账号登录。没有账号的话，注册流程在应用内就能走完。
- 新账号进入后有 **14 天免费试用**，试用期内功能是全的（官方在下载页写明试用完全免费、不需要额外解锁）。这块的状态怎么看、到期后有什么变化，见 [第一次打开要设置的几项.md](第一次打开要设置的几项.md)；不想继续用要提前关掉自动续费，路径见 [订阅续费与退款怎么处理.md](订阅续费与退款怎么处理.md)。

## 三、安装步骤

1. **把 APK 下到手机。** 在电脑上下载的话，用数据线或任意传输工具拷进手机存储都可以。
2. **允许安装未知来源应用。** 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统常把这一项收在「安全」「隐私」「更多安全设置」下面。
3. **点开 APK 完成安装。** 系统提示「应用未经安全检测」时选继续安装，这是第三方渠道安装包的常规提示。
4. **同意条款。** 安装向导里会先让你读并同意订阅协议（Subscription Agreement），点继续。
5. **登录账号。** 首次打开会要求把设备绑定到一个 Bitdefender 账号，输入邮箱密码或选择第三方账号登录。
6. **跟着配置向导走完。** 向导会依次问订阅状态、网页保护所需的辅助功能、以及是否立刻扫描一次，详见 [第一次打开要设置的几项.md](第一次打开要设置的几项.md)。

## 四、安装失败时怎么对号处理

| 系统提示 | 原因 | 处理 |
| --- | --- | --- |
| 解析包错误 / 解析包时出现问题 | 下载不完整或文件损坏 | 重新下载，下完核对体积是不是 72.21 MB、MD5 是否与上表一致 |
| 应用未安装 | 手机上已有同包名但签名不同的版本 | 先卸载旧版再装。若旧版已开启防盜，**必须先撤掉设备管理员权限**，步骤见 [卸载与设备管理员怎么撤.md](卸载与设备管理员怎么撤.md) |
| 已阻止安装 / 安全提示拦截 | 未知来源开关没打开 | 回到第 2 步，给打开安装包的那个应用开权限 |
| 提示系统版本过低、不兼容 | Android 版本低于官方要求 | 换一台设备，或先升级系统版本 |
| 装上了但一打开就退回桌面 | 系统省电策略杀掉了它的前台服务 | 在系统里给 Bitdefender 解除电池优化，见 [第一次打开要设置的几项.md](第一次打开要设置的几项.md) |

## 五、装完确认三件事

1. **版本对上了**：系统「设置 → 应用 → Bitdefender」里可以看到版本号，应当是 `3.3.238.2429`。部分系统把它放在「应用信息 → 高级」里。
2. **包名对上了**：同一页面能看到包名 `com.bitdefender.security`，这也是判断自己装的是付费版还是别的同名产品的依据。
3. **能进主界面**：登录账号后应看到仪表盘（Dashboard），顶部是一张设备安全状态卡片。若一直停在登录或加载界面，先看 [常见问题与排查.md](常见问题与排查.md) 里的联网与账号两条。
