# Bitdefender 中文界面与语言设置

> 官方的安卓版目前没有中文界面，界面语言跟着手机系统走。本篇列出官方支持的语言清单、切换方法，以及界面只有英文时那些菜单的中英对照。

很多人装完第一眼发现界面全是英文，以为装错了包或版本太老。原因不在这份包上：官方在安卓端提供的是十几门语言，**其中不包含简体中文与繁体中文**，所以手机系统设为中文时，界面会回落到英文。本篇把语言这件事一次说清楚。

## 一、官方支持哪些界面语言

按官方常见问题页当时列出的清单，安卓版提供这些语言：

| 分组 | 语言 |
| --- | --- |
| 西欧与北欧 | 英语、荷兰语、法语、德语、意大利语、葡萄牙语、西班牙语、瑞典语 |
| 中欧与东欧 | 捷克语、匈牙利语、波兰语、罗马尼亚语、希腊语、俄语 |
| 近东与亚太 | 土耳其语、日语、韩语、泰语、越南语 |
| 拉美 | 巴西葡萄牙语 |

**清单里没有中文**，官方在同一页标明「其他语言会在后续版本中加入」（以官方支持页当时显示为准）。所以中文系统下看到英文界面是正常结果，不是包损坏、也不是版本太旧。

## 二、界面语言怎么改：只有一条路径

**应用内没有单独的语言开关**，在官方中文页面上能看到的那种「进入设置改语言」的说法，是给桌面版和统一入口 App 写的，安卓的这款安全应用不走这套。真正的规则是：

1. 打开系统「设置 → 系统 → 语言和输入法 / 语言与键盘」。
2. 把**系统语言**换成上表里的某一门（例如英语、日语、韩语）。
3. 回到 Bitdefender。若界面没跟着变，从最近任务里划掉它再打开一次。

几个由此产生的实际影响：

- **改系统语言会波及整台手机**，不只是这一个应用。想单独让它显示外文而其他应用保持中文，安卓本身不提供这种能力。
- **中文系统 + 英文界面是常态**。想要中文界面，唯一可行的做法是等官方更新的语言清单里出现中文。
- **换语言不影响账号**，订阅状态、扫描记录、应用锁设置都跟着账号走，不需要重新登录或重新配置。

## 四、报告和日志里那些词怎么读

扫描总结与活动日志是给排查用的，里面的分类词固定就那几个，认一次以后都能对上：

| 界面英文 | 指的是什么 |
| --- | --- |
| Threats found / Threats blocked | 本次扫描或拦截发现、拦下的风险项数量 |
| Items scanned | 本次实际检查过的对象数量（应用与文件） |
| Quarantine / Uninstall | 处理动作，安卓端以卸载风险应用为主 |
| Weekly Reports | 每周自动汇总一份的安全报告 |
| Activity Log | 按时间排列的动作与状态变更记录 |

周报每周出一份，不需要手动开启；活动日志里能看到扫描、拦截、设置变更这些事件的先后顺序，排查「某天之后就不管用了」这类问题时，它就是时间线。具体读法与常见判定见 [常见问题与排查.md](常见问题与排查.md)。
