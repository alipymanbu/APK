# Bitdefender 应用锁防盜与VPN怎么用

> 这三项都集中在 Privacy 与 More 里，也最容易出「开了之后自己反而被挡住」的情况。本篇讲清解锁方式、受信任网络、远程定位与锁机的操作位置，以及 VPN 每天的流量额度。

这三项不是扫描器，是「管住别人动你手机」和「换个网络出口」的能力，失败方式也和扫描不一样：扫描出问题给提示，这三项出问题往往是你自己被挡在门外。下面按 App Lock、防盜、VPN 的顺序讲，顺带带上手表联动。

## 一、应用锁：先设 PIN，再挑应用

1. 在 Privacy → App Lock 里第一次进入会让你设置一个 **安全 PIN 码（Security PIN Code）**。
2. 设完 PIN 后是**勾选要锁住的应用**。勾上的应用每次打开都要验一次 PIN 或指纹。
3. 解锁方式支持密码与生物识别；设了指纹可以直接用指纹过，省去输码。
4. **防盜功能共用同一个 PIN**，所以这个码别设成自己记不住的。

**Smart Unlock（智能解锁）** 是 App Lock 的配套：让你把家里的、公司的 Wi-Fi 设成**受信任网络**，连着这些网络时不解锁也能打开被锁的应用。

- 设置路径：More → Settings → App Lock 区域 → Smart Unlock，进入后列表里会出现你当前连着的 Wi-Fi 名称，点 ADD 加进受信任列表。
- 重点是**先把手机连上那个 Wi-Fi，再进这个页面**，没连上的网络不会出现在列表里。
- 把这台网络的开关撤掉，它就不再受信任，锁立刻恢复。

两个容易踩的点：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 连续输错好几次后要等一会儿才能再试 | 设计如此：PIN 或指纹连续错 5 次，会强制等待 30 秒 | 等满 30 秒再试；别在等待期反复点 |
| 找不到「关闭应用锁」的开关 | 官方没有提供总开关 | 逐个把已勾选应用前面的勾去掉，勾完就等于关了 |

## 二、忘了那个 PIN 码怎么办

PIN 是找得回来的，**在网页端账号里取**，不在手机应用里：

1. 用电脑或浏览器登录 [central.bitdefender.com](https://central.bitdefender.com)。
2. 进入「我的设备（My Devices）」，点这台 Android 设备的卡片。
3. 点右上角的 **Rename（重命名）**，在弹出的面板里找 **Application PIN** 字段，那里存着你设过的码。

想主动换一个码：应用内 More → Settings → 防盜区域 → **Security PIN Code**，输入当前码，再输入新码。

## 三、防盜：开起来之前先知道它要什么权限

防盜（Anti-Theft）是这套里权限最重的功能，开启时会请求**设备管理员（Device administrator）**权限，这是 Android 侧的硬性前提：没有它，远程锁机与远程清除都做不到。

能做的事与操作位置：

| 能力 | 在哪操作 |
| --- | --- |
| 远程定位设备 | 网页端 Central → 我的设备 → 该设备 |
| 远程锁定设备、发送提示消息到屏幕 | 同上 |
| 远程清除设备数据 | 同上，属于权限最重的一项，误触后果不可逆，操作前先确认目标设备 |
| 抓拍照片（Snap Photo） | 应用内设置里开启；需要相机权限，官方注明在 Android 6 上还需要额外的拍照与录像授权 |
| 状态异常提醒 | 应用内的通知 |

两点提醒：

- **开了防盜之后卸载会变麻烦**：系统会拒绝直接卸载，需要先撤设备管理员权限，步骤在 [卸载与设备管理员怎么撤.md](卸载与设备管理员怎么撤.md) 里，建议在开启之前先看一眼。
- **抓拍照片会同步到账号里**。照片可以在 Central 的设置里调整是否展示，位置是网页端账号设置里的相关开关。

## 四、VPN：每天 200 MB，且手机同一时间只能有一个

VPN 的额度是官方明确写出来的：**每天 200 MB 加密流量**（以官方产品页当时显示为准）。这个量适合临时场景，不适合当日常流量通道。

- **首次连接要过一次系统授权**。点连接时 Android 会弹出「允许 Bitdefender 设置 VPN 连接」，必须点允许；点了不允许就不会再有第二次主动提示，得去系统「设置 → 网络与互联网 → VPN」里重新处理。
- **同一时间只能有一个 VPN 生效**。手机上另有别的 VPN 或加速类应用时，两者会互相顶掉，表现为「连不上」或「连上又断」。要用哪个就先关掉另一个。
- **额度用完当天的表现**是流量不再走加密通道，具体提示以你装的那版界面为准。
- **什么场景值得用**：机场、酒店、咖啡馆这类公共 Wi-Fi 下，你准备登录账号或付款之前连一下；家里的移动网络没必要。
- **法规提醒**：官方在用户指南里提到，部分国家对 VPN 的使用有法律限制，首次使用可能弹出相应提示；在有这类规定的地区请自行按当地法规判断。

**关于「有的说法是无限流量」。** 官方对不同套餐给的 VPN 档位不一样：这款产品自带的属于**标准 VPN**，额度就是每天 200 MB；同品牌更高档的套餐里配的是不限流量的 VPN。所以看到别人讲「Bitdefender VPN 不限量」并不矛盾 —— 那是另一档套餐的版本，具体包含什么以官方产品页与你的订阅状态为准。

## 五、手表联动与账号隐私

- **WearON** 把上面这些能力延伸到 Wear OS 手表上：手机一时找不到时，可以从手表触发响铃帮你定位；离开手机一定距离也会收到提醒。用之前需要手表与手机配对完成。
- **Account Privacy（账号隐私）** 做的是另一件事：检查你绑定的邮箱是否出现在已知的数据泄露事件里，结果给的是「有没有、出现过几次」这类信息，不会替你改密码。收到提醒后要处理的是那**个网站**的密码，而不是这里的设置。
