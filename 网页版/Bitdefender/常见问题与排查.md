# Bitdefender 常见问题与排查

> 收集用下来最常卡住的几类问题：登录进不去、扫描半天不完、该有的提醒收不到、被系统悄悄关掉权限。每条给出判断依据和处理顺序。

这份应用的大多数「不工作」都不是程序坏了，而是三类原因：账号/订阅状态不对、系统把权限或后台收走了、网络不通。下面按现象分条，每条都给出**先查哪里**，避免在一个方向上反复试。

## 一、登录与账号

**一直停在登录页或加载页。** 按这个顺序查：

1. 手机当前网络能不能正常打开别的网页。这款应用的判定在云端完成，它比普通应用更依赖网络。
2. 账号密码是否正确 —— 直接用同一套凭据在网页端 [central.bitdefender.com](https://central.bitdefender.com) 登一次，能进说明凭据没问题，问题在手机侧。
3. 用 Google / Facebook / Microsoft 第三方登录的，确认对应账号本身在这台手机上能正常登录。
4. 上面都正常还是进不去，检查系统的电池优化与自启动限制（见本节第五条）。

**换了手机怎么继续用。** 新手机装上同一份包，登录**同一个账号**，订阅与设备记录会跟着账号走，不需要重新激活；旧设备不打算用了，可以按 [卸载与设备管理员怎么撤.md](卸载与设备管理员怎么撤.md) 收尾。

## 二、订阅状态与试用

**功能卡片是灰的、或者提示需要订阅。** 大概率是 14 天试用到期了。

- 查状态：应用内 More → 账号邮箱那一行，能看到当前订阅与到期时间；网页端 Central 里同样能看到。
- 官方口径是产品的防护功能需要有效订阅支持，订阅结束后相关功能会停止工作。到期后的处理（续费或多设备套餐）都在官方渠道办。
- 自己有没有激活码，可以在配置向导第一步选「I have a code / 我有激活码」填进去；填过的码会显示在订阅状态里。

**不想续、要关掉自动续费，或者想退款**，入口在网页端账号里而不是手机应用里；官方给的关续费路径、退款时间窗口与联系方式见 [订阅续费与退款怎么处理.md](订阅续费与退款怎么处理.md)。这里先记一条最容易搞错的：**卸载应用不等于退订**，账号里的订阅照旧。

## 三、扫描卡住或扫描时间过长

**先看是不是存储扫描在拖时间。** 按需扫描默认会连内部存储与已挂载的存储卡一起过，存储卡内容多、碎片多时耗时很长。只在意外来应用风险的话，可以在 More → Settings 的扫描器区域关掉 **Scan Storage**，此后扫描只过已安装应用，时间会明显缩短。

**判断它是真卡住还是在慢慢跑：** 扫描界面会持续显示进度与已检查项数。数字在动就是在跑；停在同一个数字几分钟不动，再按下面处理。

**处理顺序：**

1. 直接中断扫描，回到仪表盘重进一次扫描。
2. 关掉其他后台应用后重扫，排除内存紧张导致的进程被挂起。
3. 检查最近任务里是不是有清理类工具在反复杀它的进程 —— 这类冲突是最常见的原因，处理方式见本节第五条。
4. 仍然不行就重启手机再扫一次。重启后仍复现，属于应用层面的问题，可卸载重装（步骤见 [卸载与设备管理员怎么撤.md](卸载与设备管理员怎么撤.md)）。

## 四、手机耗电与发热变明显

- 首次安装后的第一次完整扫描是这套里最耗电的一段，属正常范围；之后按需扫描只在你自己点的时候跑。
- 安装时扫描会在你每装一个应用后触发一次，属于短时动作。
- **如果它在后台持续占用**，通常是两个原因：一是有清理类应用反复把它杀掉、它反复重启；二是定时任务被系统挤到了不合适的时间。先处理这两点，再看耗电是否回落。

## 五、后台被杀、权限被悄悄关掉（国产定制系统高发）

这一类问题的特点是不报错，只是「过一阵子就不管用了」。三个地方都要确认：

| 要确认的项 | 位置 | 被关掉后的表现 |
| --- | --- | --- |
| 电池优化 | 设置 → 应用 → Bitdefender → 电池 | 后台进程被清，实时防护停摆 |
| 自启动 | 设置 → 应用 → 自启动管理 | 重启手机后它不自己起来 |
| 辅助功能服务 | 设置 → 无障碍 / 辅助功能 → 已下载的服务 | 网页保护、诈骗防护、来电拦截一起失效 |
| 通知权限 | 设置 → 应用 → Bitdefender → 通知 | 拦截与扫描结果不再提醒你 |

一个很实用的自查动作：**回应用里看那几张功能卡片是不是仍是启用状态**。前面三项里任何一项被关，对应卡片就会提示未启用 —— 它自己会告诉你，比你在系统设置里翻要快。

其中「辅助功能服务」被关是最高发、也最容易搞错的一种：它是被息屏后的省电机制连带收回的，所以**先在系统侧放开后台、再重新授权，顺序反了会当场再掉一次**；逐品牌的路径在 [网页保护总被关掉怎么办.md](网页保护总被关掉怎么办.md)。

## 六、该有的提醒收不到

- 系统通知权限、通知分类（别被折叠进静默分类）先确认一遍。
- 防盜类提醒走的是网络来路，手机必须能连到云端；断网期间的操作不会补推。
- 抓拍照片之类的记录是同步到账号里的，在应用里看不到时要到网页端 Central 的对应设备下查。

## 七、想减少信息上报

官方给出的开关是同一个：More → Settings 的扫描器区域，关掉 **In-the-cloud detection（云端检测）**。关掉后不再向云端上报可疑应用的信息，代价是判定范围收窄、对新出现威胁的反应变慢。这是官方提供的唯一一个此类开关，没有更细的粒度。

## 八、两条容易误判的现象

**扫出你自己装的工具类应用。** 侧载的、改过签名的、来源不明确的工具类应用被列出来是常见结果。处理前先确认三件事：来源是不是你信任的地方、是什么时候装的、它要了哪些权限。确认是自己主动装且来源可信的，可以先不动它；但官方在安卓端给出的处理动作是**卸载**，是否提供「忽略并加入信任」这类入口，以你装的这版界面为准。

**它和手机自带的安全中心同时存在。** Android 允许安装多个安全类应用，两者不会互相卸载；但系统自带的安全中心可能把 Bitdefender 归到「待优化」「不常用」名单里限制后台，表现为一段时间后防护失效。两边都留着的话，至少把上表里那几项给 Bitdefender 放行。
