这份应用有两类工作方式：一类是**你主动发起**的扫描，一类是**它自己在后台盯着**的实时防护。多数人只用了前者，然后觉得「装了没什么感觉」——本篇把两类都走一遍，并标明哪些开关不能关。

## 一、三种扫描，扫的东西不一样

| 扫描类型 | 什么时候跑 | 扫什么 | 入口 |
| --- | --- | --- | --- |
| 按需扫描（On-Demand） | 你自己点 | 已安装的应用与设备存储 | Protection → Malware Scanner |
| 安装时扫描（On-Install） | 每装/更新一个应用后自动 | 刚装上的那个应用 | 无需操作，自动触发 |
| 存储扫描（Scan Storage） | 按需扫描时一并执行 | 内部存储与已挂载的存储卡 | 跟随按需扫描，默认开启 |

**安装时扫描不需要你记得做什么**：它靠前台服务立刻捕捉到安装或更新事件，装完即查，也不用你手动发起。这也是它常驻一条通知的原因 —— 别把这条通知禁掉，否则这一步的即时性会受影响。

**存储扫描会明显拉长扫描时间**，尤其是插着大容量存储卡的机器。如果你只在意外来应用的风险、不在乎存储卡里的文件，可以在 More → Settings 的扫描器区域把 Scan Storage 关掉，此后按需扫描只过应用。

**Android 6 上还会多问两项授权**：第一次点开始扫描后，系统会依次弹「允许 Bitdefender 拨打电话和管理通话」和「允许访问照片、媒体和文件」——前者用于识别通话相关威胁，后者是让扫描器能读到存储内容。两项都点允许，扫描才跑得起来；当时点了拒绝的话，扫描会停在起始状态，回系统「设置 → 应用 → Bitdefender → 权限」里补上即可。

## 二、扫出结果之后怎么处理

1. 扫描结束后，检测到的风险项会单独列出来，逐条给出名称与判定类型。
2. 处理动作以**卸载**为主：确认它确实是你不认识、也不需要的东西，点卸载入口把它移除。
3. 扫描过程中可以随时中断。中断不会留下半套结果，下次重扫即可。

一个容易踩的坑：**别在扫描刚出结果时急着下手**。先把列表看完 —— 某些你自己侧载的工具类应用、修改过签名的应用，被标出来是常见现象；判断依据是「这个应用是不是你主动装的、来源你知不知道」，而不是「名字里有没有可疑字样」。

## 三、实时防护的四道关卡

这几项不是扫描器，是拦截器，各自守一段：

| 功能 | 拦什么 | 开启的前提 |
| --- | --- | --- |
| App Anomaly Detection（应用异常检测） | 已经在手机上、行为开始变得异常的应用 | 默认随防护开启；官方注明该功能需要 Android 6 及以上 |
| Web Protection（网页保护） | 钓鱼页与恶意站点 | 需要打开辅助功能服务；会读写浏览器书签，用于把恶意站点从浏览历史里清掉 |
| Scam Alert（诈骗防护） | 短信、聊天应用、通知里的可疑链接 | 需要打开辅助功能服务；官方注明该功能需要 Android 6 及以上 |
| Call Blocking（来电拦截） | 已知的垃圾与诈骗来电 | 需要辅助功能服务里的来电筛选能力 |

前两项与后两项的差别在触发点：网页保护在你打开链接时判，诈骗防护在消息到达、你还没点开时判，来电拦截在铃响之前判。四项都要用到辅助功能权限，所以**这一项一旦被系统关掉，四项会一起失效，而且不会有明显的报错**。定期回应用里看一眼对应卡片是不是仍是启用状态，是个成本很低的习惯。

已经被关掉过、或者反复被关掉的话，恢复办法不是重复点开关，而是要在系统侧放开后台 —— 官方把这件事写成了一篇带各家品牌路径的说明，整理在 [网页保护总被关掉怎么办.md](网页保护总被关掉怎么办.md)。

## 四、云端检测开关：关掉会发生什么

More → Settings 的扫描器区域有一个 **In-the-cloud detection（云端检测）** 开关，默认是开的。

- 开着的时候，遇到可疑应用会把相关信息送到云端比对，判断更准、也能覆盖刚出现的新威胁。
- 关掉之后，**不再向云端上报可疑应用的信息**，代价是判定范围收窄、对新威胁的反应变慢。
- 这个开关只影响上报与云端比对这一类行为，不影响扫描本身能不能跑。

如果你在意「不想让设备信息往外发」，官方在常见问题里给出的就是这个开关；更细的粒度在应用里没有提供，以你装的这版界面为准。

## 五、它要的那些权限各对应什么

官方对安卓版的权限用途有逐条说明，对着看就不会觉得「要这么多权限干什么」：

| 权限 | 用途 |
| --- | --- |
| 网络访问 | 与云端通信，判断文件与网页的安全性 |
| 读取手机状态与身份 | 判断当前是否联网；生成与云端通信所需的设备唯一标识 |
| 读写浏览器书签 | 网页保护模块把恶意站点从浏览历史中删除 |
| 读取日志数据 | 从 Android 系统日志里识别威胁活动的痕迹 |
| 位置 | 防盜功能的远程定位 |
| 相机 | 防盜的抓拍照片功能 |
| 存储 | 让扫描器能检查存储卡中的内容 |
| 辅助功能服务 | 扫描浏览器与聊天应用中的链接、监控应用行为、筛选来电 |

## 六、想确认它还在干活，看这两处

- **Reports（报告）**：里面有一份每周汇总一次的安全报告，能看到这段时间检查了多少对象、拦下多少风险。
- **Activity Log（活动日志）**：按时间排列的动作记录，扫描、拦截、设置变更都在里面。排查「从哪天开始不对劲」时，按日期往下翻比猜快得多。

两处的入口都在 More 里，具体读法见 [中文界面与语言设置.md](中文界面与语言设置.md) 的对照表。
