# SecondScreen 黑屏或显示异常怎么恢复

> 本篇讲启用 SecondScreen 配置后出现黑屏、界面错位、字体过大过小等问题时的还原方法，按从易到难的顺序排列。

## 一、先判断改的是哪一层

显示参数被改乱后，症状不同，要回退的层级也不同：

- **只有字变大了或变小了**：多半只是密度（DPI）被改，界面结构没变；
- **图标、按钮、整个布局都变了**：分辨率和密度都被改过；
- **画面被裁掉一圈或有黑边**：Overscan 被设置过；
- **完全黑屏或界面错乱**：填了设备不支持的分辨率组合。

判断错了也不用怕，下面的流程从头到尾走一遍就能全部还原。

## 二、恢复顺序：从容易到彻底

### 第 1 步：应用内停用配置

屏幕还能操作时，打开 SecondScreen 把当前启用的配置文件停用——这是最干净的还原方式，应用会把参数改回去。黑屏看不到界面时跳过这步。

有个已知的小坑：旧版本停用配置后，屏幕方向可能仍然锁定在横屏改不回来。这是 2.9.4 版本更新日志里明确修复的问题——遇到这种情况，先升级到 2.9.4 再停用配置即可。

### 第 2 步：重启手机

部分设备的显示覆盖在重启后会被清掉。如果重启后界面恢复正常，先别急着继续用同一套参数——说明设备吃不消那个值，回 [分辨率与DPI配置教程.md](分辨率与DPI配置教程.md) 换保守一点的设置。注意：重启**不一定**能还原，覆盖值能否在重启后保留取决于设备与改动方式，重启没用的直接进下一步。

### 第 3 步：adb 重置命令（兜底）

界面完全没法操作、重启也没救时，用电脑执行系统级的重置命令——这三条是 Android 系统自带的显示参数还原命令：

```bash
adb shell wm size reset
adb shell wm density reset
adb shell wm overscan reset
```

三条分别对应分辨率、密度、Overscan，全部执行一遍即可，不存在「只重置一条」的必要。执行前手机要能连上 adb：

- 之前用数据线授权过 SecondScreen 的，插线直连即可；
- Android 11 以上也可以走无线方式，步骤见 [无线调试授权步骤.md](无线调试授权步骤.md)；
- 电脑还没装 adb 环境的，先看 [adb授权命令与常见报错.md](adb授权命令与常见报错.md) 第二节。

想确认重置是否生效，可以在重置前后各执行一次查询：

```bash
adb shell wm size
adb shell wm density
```

输出里的 `Physical size` / `Physical density` 是设备出厂值；如果还多出一行 `Override size` / `Override density`，说明覆盖仍在生效——重置成功后 Override 行会消失。万一重置后显示仍不正常，重启一次手机再确认。

## 三、恢复之后做一次检查

界面回来了不等于全部复原，建议快速过一遍：

- 锁屏、设置、输入法键盘都完整可见；
- 截一张图看尺寸是否回到设备原始分辨率；
- 打开一两个平时常用的应用确认布局正常。

## 四、下次怎么避免

- **改参数前先记录原始值**：用上面的 `wm size` / `wm density` 查询命令把出厂值抄下来，恢复时有对照；
- **一次只改一个值**，确认没问题再改下一个（见 [分辨率与DPI配置教程.md](分辨率与DPI配置教程.md) 的实操建议）；
- **启用配置前保存手头工作**：分辨率变更会刷新系统界面，未保存的内容会丢；
- 新设备第一次尝试时选保守值（比如密度只调低一档），确认设备能承受再加大幅度。
