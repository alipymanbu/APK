## 一、为什么外接屏上网页还是手机排版

浏览器在手机上默认按移动设备请求网页——它把自己的设备类型、屏幕宽度等信号发给网站，网站据此返回手机版布局。接上外接屏后屏幕变大了，但浏览器的请求信号没变，网页自然还是手机排版。SecondScreen 的配置文件里提供了「Chrome 默认显示桌面版网站」开关（见 [分辨率与DPI配置教程.md](分辨率与DPI配置教程.md)），启用后浏览器会以桌面设备的身份请求网页，多数网站就会返回完整版布局。

要注意的是：桌面模式是浏览器向网站发出的**请求**，不是强制命令。网站最终返回哪一版由它自己的实现决定——个别站点会无视请求继续推送手机版，或按账号、跳转规则另行处理。

## 二、只对当前页面开（手动，每次都要）

偶尔看一个页面时，不用改任何设置：

1. 打开 Chrome，进入目标网页；
2. 点右上角三点菜单；
3. 勾选「桌面版网站」（部分版本叫「桌面网站」），页面会自动刷新成桌面版。

这个勾选只对当前站点生效，换一个网站要重新勾一次。适合临时查一个只在桌面版里才完整的页面（比如某些后台管理页、文档站）。

## 三、所有网站默认桌面版（Chrome 内部开关）

想让 Chrome 一律按桌面版请求，用浏览器自带的实验开关：

1. 地址栏输入 `chrome://flags` 并打开；
2. 搜索 `desktop`；
3. 找到「Global setting to request desktop site on Android」，把它设为 Enabled；
4. 按提示重启浏览器。

重启后 Chrome 会默认以桌面版请求所有网站。flags 属于实验性功能区，选项名称与位置随 Chrome 版本变动，找不到时以你设备上浏览器的实际菜单为准。

## 四、个别网站仍要手机版：加例外

默认桌面版之后，个别在桌面排版下反而难用的站点（比如某些为触屏优化的服务页）可以单独排除：设置 → 网站设置 → 桌面版网站 → 添加例外网站，把这些站点的网址加进去，它们会继续按手机版加载。

## 五、和外接屏搭配的实际效果

外接屏 + 桌面版网站 + SecondScreen 调好的分辨率密度，是最接近「手机当电脑用」的组合：网页铺满外接屏、多栏布局正常显示、配合蓝牙键鼠操作顺畅。连接外接屏本身的方案（有线适配器、无线投屏）见 [外接显示器连接方案.md](外接显示器连接方案.md)；还没装应用的，安装与授权从 [下载与安装教程.md](下载与安装教程.md) 开始。
