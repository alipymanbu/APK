# SecondScreen 无线调试授权步骤

## 一、适用前提

官方 adb 从 Android 11 起支持无线调试：手机和电脑连同一个 Wi-Fi，配对一次即可发命令，全程不需要数据线。满足以下条件再走这条路：

- 手机是 Android 11 或更高（低版本没有「无线调试」开关，只能走数据线，见 [adb授权命令与常见报错.md](adb授权命令与常见报错.md)）；
- 电脑上已经装好 platform-tools（`https://developer.android.com/tools/releases/platform-tools`）；
- 手机和电脑在同一局域网内。

## 二、配对与连接

1. 手机：设置 → 开发者选项 → 打开「无线调试」，点进去选择「使用配对码配对设备」，屏幕会显示一个 **IP 地址：端口** 和一个 **6 位配对码**。注意配对弹窗里的端口和主界面上显示的端口不是同一个，别混用。
2. 电脑：在 platform-tools 目录打开命令行，先执行配对（IP、端口、配对码都照手机弹窗上显示的填）：

```bash
adb pair 192.168.1.5:37845
```

提示输入配对码时输入那 6 位数字，回车后显示配对成功。

3. 再执行连接。这一步的端口要换成手机「无线调试」**主界面**上显示的端口：

```bash
adb connect 192.168.1.5:40123
```

4. 连上之后执行授权命令，与有线方式完全相同：

```bash
adb shell pm grant com.farmerbb.secondscreen.free android.permission.WRITE_SECURE_SETTINGS
```

没有报错就是授权成功，回手机上打开 SecondScreen 确认提示已消失。

## 三、几个实际会碰到的点

- **端口每次打开都会变**：无线调试的端口不是固定的，每次重开「无线调试」开关端口都可能换，连不上时先回主界面看一眼当前端口。
- **配对码是一次性的**：弹窗关掉就要重新点「使用配对码配对设备」生成新的。
- **网络要通**：路由器开了 AP 隔离（访客网络常见）时，两台设备互相 ping 不通，配对会一直超时，换回常规网络或直接用数据线。
- **授权只需一次**：配对关系会保留，之后手机再开「无线调试」，电脑 `adb connect` 一次就能直接发命令，不必重新 pair。

授权完成后就能进 [分辨率与DPI配置教程.md](分辨率与DPI配置教程.md) 建配置文件了；万一之后显示参数改乱，恢复见 [黑屏或显示异常怎么恢复.md](黑屏或显示异常怎么恢复.md)。
