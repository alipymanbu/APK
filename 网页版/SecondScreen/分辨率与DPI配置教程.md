## 一、一切从配置文件开始

SecondScreen 的功能围绕「配置文件」（Profile）组织：把一组显示参数（分辨率、密度、各项开关）存成一个方案，接不同的外接屏用不同的方案，启用停用都是一键的事。授权完成后打开应用，第一步就是新建一个配置文件，而不是直接在主界面找开关。

配置文件之间相互独立，你可以为客厅电视、便携屏、投影仪各建一套。官方还支持「连接显示设备时自动加载配置」：插上外接屏自动切换到对应方案，拔掉自动还原，省去每次手动启用。

新建配置文件的完整动作（社区中文教程的通用记录）：点主界面下方的「+」→ 输入配置文件名称、选择屏幕类型 → 按需调整分辨率等显示设置 → 右上角保存 → 回到列表点「加载」启用。

## 二、改分辨率与密度

配置文件里最常用的两项：

- **分辨率（Resolution）**：按外接屏的实际规格填，例如外接 1080P 电视就填对应的宽高；
- **密度（Density / DPI）**：决定界面元素的大小。密度调低，同屏能容纳的内容变多、按钮变小；调高则相反。

密度数值为什么这样起效：Android 官方把 160dpi 定为基准密度，界面元素按「密度无关像素」计量，实际像素数约等于 元素尺寸 × 密度 ÷ 160——把密度从 480 调到 320，同一个按钮占的像素就少了约三分之一，看起来自然「变小」。官方说明见 [Android 开发者文档：支持不同的像素密度](https://developer.android.google.cn/training/multiscreen/screendensities)。

官方对这款应用的一个典型用法是：手机连接外接屏后，通过改密度让系统直接呈现平板式界面（更多分栏、更接近桌面布局）。想在手机屏幕上验证效果，不接外接屏也可以直接启用配置文件看变化。

两个实操建议：

1. **一次只改一个参数**，改完看效果再动下一个，两个一起改出了问题不好定位是哪个引起的；
2. 改之前先记下设备原始的分辨率和密度（恢复时要用的原始值查法与完整恢复流程见 [黑屏或显示异常怎么恢复.md](黑屏或显示异常怎么恢复.md)）。

### 常用参考值

社区实践里常被拿来起步的「密度 + 分辨率」组合，不求一次到位，按自己的外接屏微调：

| 密度 | 分辨率 | 适用倾向 |
| --- | --- | --- |
| 320 | 720x1280 | 接近平板界面的起步值，元素大、好点按 |
| 480 | 1080x1920 | 1080P 外接屏的常用搭配 |
| 460 | 1080x1920 | 同上，界面元素稍大 |
| 560 | 1440x2392 | 高分屏上追求容纳更多内容 |

这组值来自社区的通用记录，不同设备与系统的实际表现有差异——只当起点，不当标准，最终以你屏幕上的实际效果为准。社区里另一个常见的起步组合是密度 440 搭 1080x1920（面向 16:9 外接显示），同样只作参考。

还有一条不用 SecondScreen 也能感受密度变化的路：部分系统的开发者选项里有「最小宽度」（Minimal width）设置，改的就是密度，常见可填范围约在 120~640 之间。想零成本试一试可以用它，但它没有配置文件管理、也不带本应用的其他联动，长期使用还是回到配置文件方案。该入口的名称与位置因系统而异，以设备实际菜单为准。

## 三、配置文件里还有什么可调

官方提供的主要选项，按用途归堆：

| 选项 | 作用 | 备注 |
| --- | --- | --- |
| 自动启用蓝牙 / Wi-Fi | 接外接屏时自动连键鼠或网络 | 方便游戏手柄、键盘即插即用 |
| Chrome 默认显示桌面版网站 | 外接屏上浏览网页不再是手机排版 | 手动开法与默认设置见 [Chrome桌面版网站怎么设为默认.md](Chrome桌面版网站怎么设为默认.md) |
| 锁定屏幕方向为横屏 | 避免外接屏上界面竖着显示 | 常与分辨率调整搭配 |
| Overscan | 老电视画面被裁掉边缘时补偿 | 官方标注需 Android 4.3 以上 |
| 系统级沉浸模式 | 全局隐藏状态栏和导航栏 | 官方标注需 Android 5.0 以上 |
| 关闭背光 / 关闭振动 | 外接屏工作时让手机本体的屏幕歇掉省电 | 官方注明并非所有设备兼容 |
| 桌面快捷方式 | 从主屏幕一键启用某个配置文件 | 不用进应用翻菜单 |

另有 **Quick Actions**（快捷操作）：不建完整配置文件，直接单次执行某个动作，适合偶尔用一下的功能。以及 **Tasker 集成**：把 SecondScreen 的动作挂进 Tasker 自动化流程，实现「连接某 Wi-Fi 就启用某配置」这类联动。

## 四、启动配置前的一个固定动作

官方权限说明里有一条值得单独拎出来：应用持有「关闭其他应用」权限，用途是**在分辨率 / 密度变更后刷新界面**。这意味着启用配置文件的瞬间，系统界面会被刷新一遍——正在编辑的内容、没保存的表单都可能被带走。所以养成一个习惯：**先保存手头的东西，再启用配置**。

## 五、改坏了怎么办

密度或分辨率填了不合适的值，最轻的表现是字变小按钮难点按，严重的会黑屏或界面错位。恢复路径按顺序走：先在应用内停用配置，不行再重启，最后用 adb 重置命令兜底——每一步的具体操作都整理在 [黑屏或显示异常怎么恢复.md](黑屏或显示异常怎么恢复.md)。还没完成授权的话，先回 [adb授权命令与常见报错.md](adb授权命令与常见报错.md) 把权限解决掉。
