## 一、免费账号给多少

官方口径：

- 基础空间 **10GB**；
- 通过官方给出的奖励任务最多可扩到 **50GB**（具体奖励内容以 App 内提示为准，历史上有邀请好友、多设备登录等玩法）；
- 单个文件上限 **5GB**（官方套餐页口径；官网首页旧文案写的是 4GB，两处不一致时以官方套餐页为准，传大文件前先确认）；
- 下载端不限总流量：官方称广告支持的下载不限带宽、不限下载次数。

## 二、免费与付费差在哪

| 项目 | Basic（免费） | Ultra | Pro |
| --- | --- | --- | --- |
| 存储空间 | 10GB（奖励最多 50GB） | 100GB | 1TB |
| 单文件上限 | 5GB | 50GB | 50GB |
| 下载页广告 | 有 | 无 | 无 |
| 人机验证 | 可能有（「无验证码」是付费权益） | 无 | 无 |
| 整个文件夹打包下载（ZIP） | 不支持，只能逐个下载 | 支持 | 支持 |
| 直链下载（跳过 MediaFire 页面） | 不支持 | 支持 | 支持 |
| 文件密码保护 | 不支持 | 支持 | 支持 |
| 一次性链接（One-Time Link） | 可用 | 可用 | 可用（标注每日 100 个） |

价格会变动，且 Ultra 按带宽档位计价，以下仅作量级参考、以官方页面当时显示为准：Pro 按月约 $9.99，按年付折合约 $5.83/月；Ultra 起价约 $3.99/月；另有面向团队的 Business 档（2TB、100 个子账号）。价格以美元计价，付款方式是否支持国内卡以结账页为准。

## 三、免费账号的实际限制

- **下载页有广告**：广告位紧挨着下载按钮，点错就跳到别家页面，见 [分享链接与下载教程.md](分享链接与下载教程.md) 的辨认方法；
- **文件夹不能打包下载**：免费接收方只能一个一个点，批量分发场景见同一篇里的应对办法；
- **续传口径有分歧**：官方宣传页称免费下载支持断点续传、无等待；第三方工具站的说法相反（免费下载不能续传、速度受限）。两边并列供参考，你的实际体验以当时网络为准；
- **文件保留与账号活跃挂钩**：免费空间按 active-account storage 描述，账号长期闲置时的文件保留政策以官方说明为准。

## 四、怎么判断免费够不够用

- 存照片、视频、文档，总量在 10GB 以内 → 免费够用，上传操作见 [上传与照片自动备份.md](上传与照片自动备份.md)；
- 单个文件超过 5GB → 免费传不了，先压缩拆分或升级；
- 要把整个文件夹发给一批人 → 打包下载是付费功能，免费账号先在本地压成 ZIP 再上传更省事；
- 讨厌下载页广告、经常要下载 → 升级省心。

## 五、升级与退订

- **升级**：官网 Upgrade 页面或 App 内升级入口，套餐对比以上文表格加官方页面为准；
- **退订**：官方有订阅政策页（subscription policies），取消订阅走那个页面；
- **升级出问题**（报错、扣款没到账）：按官方指引提交工单，附上出错的时间点、具体报错与支付方式，客服才好查。
