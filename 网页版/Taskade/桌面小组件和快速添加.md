## 一、小组件解决的是「记一下」这一步

想起一件事时，解锁、找应用、进项目、再新建——四步走完念头就没了。**Quick Add（快速添加）小组件**把这一步压到一次点击：桌面上直接写，写完自动进指定项目，和云端实时同步。

适合的场景：随手记待办、开会时记行动项、睡前把明天要做的事先记上。

## 二、把小组件放到安卓桌面

1. 在手机**桌面空白处长按**，直到出现桌面编辑状态。
2. 点**小部件（Widgets）**。
3. 在小部件列表里找到 **Taskade**，选 **Quick Add** 那个。
4. 按住它拖到桌面上想放的位置，松手。

放好之后桌面上就多了一个加号入口，不用先打开应用。

## 三、用小组件快速记一条任务

1. 点桌面上的**加号**，打开快速添加。
2. 输入要做的事。
3. 选目标**工作区 / 文件夹 / 项目**。
4. 需要的话再选放进项目的哪个位置（区块）。
5. 点 **Add to Project** 完成，任务立刻同步进去。

## 四、日期直接用自然语言写

Taskade 能认自然语言写的日期，不必去翻日历选。在任务里写上时间说法即可，常见写法：

| 写法 | 识别为 |
| --- | --- |
| `today` / `tomorrow` / `yesterday` | 今天 / 明天 / 昨天 |
| `next week` | 下周 |
| `last Monday` / `next Monday` | 上周一 / 下周一 |
| `May 1st` / `1st May` | 5 月 1 日 |
| `May 1st 5 pm` / `1st May 2023 at 5 pm` | 指定到具体时间 |

这招在项目里直接加任务时同样管用——比如打「整理发票 tomorrow」回车，任务就会带上明天的到期日。

## 五、给任务设到期提醒

有了到期日还不够，要让它提醒你：

1. 点开要提醒的**任务或子任务**。
2. 点 **加号** 打开 Add-ons（附加项）。
3. 填**开始 / 结束时间**。
4. 在 **Notification（通知）** 里选提前多久提醒。
5. 需要的话再加**第二条通知**（比如提前一天和当天各提醒一次）。

## 六、通知不响，先开权限

提醒设了却不弹，基本都是系统权限没给。按手机系统处理：

- **Android**：设置 → 通知（或 设置 → 应用 → Taskade → 通知）→ 找到 Taskade，打开通知开关；再确认「勿扰模式」没有把它一起静音。
- **iOS**：设置 → 通知 → Taskade → 打开「允许通知」。

另外**通知设置是按设备生效的**：手机和电脑要各开一次，不是一处开了到处都响。

## 七、小组件不刷新或显示异常

小组件长时间不更新，一般是后台被系统限制或应用数据异常。处理顺序：先把应用完全关掉重开；仍不正常就做一次强制停止与清缓存（只清缓存，别先清数据）。步骤见 [常见问题与排查.md](常见问题与排查.md) 的「一直转圈，加载不出内容」一节。
