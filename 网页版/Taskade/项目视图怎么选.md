## 一、视图不是「另存一份」

同一个项目可以换好几种样子来看：列表、看板、表格、思维导图、日历……但这些**不是导出成不同文件**，而是同一份数据的不同呈现。你在列表里加的任务，切到看板会原样出现，切回来也不会少东西。

所以看到别人项目长得不一样，不用重新建一个——**先建内容，再挑视图**。

## 二、八种视图各管什么

| 视图 | 适合做什么 | 免费版可用 |
| --- | --- | --- |
| 列表 List | 写待办、记笔记、日常执行 | 是 |
| 看板 Board | 按阶段拖动卡片，跟进流程 | 是 |
| 表格 Table | 多列字段并排比较、批量核对 | 是 |
| 思维导图 Mind Map | 头脑风暴、把想法铺开看关系 | 是 |
| 日历 Calendar | 看哪天到期、按时间铺排 | 是 |
| 文档 Docs | 在任务之上写长文、成稿 | 是（Beta） |
| 甘特图 Gantt | 排时间线、看任务依赖与先后 | 否，需付费 |
| 组织结构图 Org Chart | 展示层级与汇报关系 | 否，需付费 |

另有一个 Actionsheet 视图也属于付费范围。免费版能覆盖日常绝大多数场景，只有「排项目时间线」和「画组织结构」这两类才非升级不可。

想把某个视图里的数据拿到表格里继续算，可以**按视图导出 CSV**，导出的列会跟着视图走（表格视图一个字段一列，看板视图会带上卡片所在的列），具体见 [项目导出与备份.md](项目导出与备份.md)。

## 三、怎么切换

项目顶部会列出可用的视图标签（列表、看板、表格、思维导图等），**点一下标签就切过去**，其余视图收在「更多视图」里。手机上在项目内滑动 / 点顶部的视图入口同样能切。

切换只是换视角，不会复制、转换或丢失数据。

## 四、按你的实际场景对号入座

不要为了用而用，按「你现在要解决什么」来选：

- **每天照着清单干活** → 列表。最直白，子任务缩进一目了然。
- **一群人推同一件事** → 看板。把列设成「待处理 / 进行中 / 已完成」，谁把卡片拖到哪一列，进度一眼可见。
- **手上有一批条目要核字段**（名字、状态、负责人、日期）→ 表格。一排一行，适合横向比对和批量整理。
- **只有个模糊想法要展开** → 思维导图。从一个中心往外长，理清关系比硬列清单快。
- **重点是「什么时候」** → 日历看全局分布；要排先后和依赖，就到甘特图（付费）。
- **成果本身是一篇文章** → 文档视图，任务和正文放在同一份里。

同一个项目也可以按阶段换视图：起步用思维导图理清，执行期用看板推进，收尾用表格复盘——都指同一份数据。

## 五、视图和字段的关系

表格、看板这类结构化视图好不好用，取决于你给任务挂了哪些属性（到期日、指派人、状态、优先级等）。**属性挂得越清楚，视图能自动帮你分得越细**；一个只有文字的任务，在哪都是干巴巴一行。

所以顺序是：先在项目里把任务和属性填齐，再切到合适的视图看结果，而不是指望换个视图内容就变规整。属性怎么挂见 [任务和项目怎么建.md](任务和项目怎么建.md) 的「给任务挂属性与附件」。
