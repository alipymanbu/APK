## 一、先把四个层级摆清楚

Taskade 的内容是按层级收纳的，从上到下是：

```text
工作区 Workspace
└── 文件夹 Folder（可选）
    └── 项目 Project
        └── 任务 Task
```

理解方式很简单：**工作区是「哪一支团队 / 哪一类事」**，文件夹是一层可选的归类，**项目是「一件具体的事」**，任务是这件事里的每一条。个人用可以只建一个工作区，所有项目平铺在里面；团队或同时管几个客户时，再拿文件夹隔开。

层级不用一开始就想全，先建项目、用起来，需要归类时再把项目拖进文件夹即可。

## 二、新建一个项目走哪条路

进入某个工作区或文件夹后，**右下角的加号**就是新建入口，点开一般有三种路线：

| 路线 | 适合什么情况 | 你会得到 |
| --- | --- | --- |
| 空白项目 | 结构心里有数，想自己敲 | 一张干净的任务列表 |
| 用模板 | 想要现成的骨架 | 一份已经分好段、填好示例的任务结构 |
| AI 生成器 | 只有一句话想法 | 描述一句，自动生成项目骨架与任务 |

用 AI 生成器的操作是：加号 → 选 AI 生成器 → 用一句话描述你要做的事（比如「三周的搬家清单，按房间分类」）→ 生成后点创建。生成结果不满意可以重来或直接改。

**新建出来的项目默认是列表视图**，之后随时能切成别的样子，切换不会弄丢内容——各种视图看的是同一份数据，只是呈现方式不同（详见 [项目视图怎么选.md](项目视图怎么选.md)）。

## 三、往项目里加任务

- **一行就是一条任务。** 在项目里点任意空白处直接打字，敲回车换行就是下一条。
- **Tab 缩进成子任务**，`Shift + Tab` 往回退一级。这是把大任务拆小的主要手段，也是后面视图能自动分组的依据。
- **打勾完成。** 点任务前的方框即可；完成后可以隐藏起来，让列表只剩待办。
- **拖动排序 / 折叠。** 任务左侧有拖动把手，按住可以挪位置；有子任务的行可以折叠，只看主线。

手机上同样是「选中任务 → 底部工具栏操作」，左右滑动工具栏能看到更多按钮：缩进、反缩进、上移下移、加粗斜体下划线、高亮。

## 四、给任务挂属性与附件

选中一个任务后，右侧或底部会有一个加号（Add-ons 菜单），这里挂的都是让任务能真正用起来的东西：

| 挂件 | 作用 |
| --- | --- |
| 到期日 | 给任务定截止时间，之后会出现在日历视图里 |
| 指派 | 把任务分给项目里的某个人 |
| 评论 | 在任务下讨论、留话 |
| 上传文件 | 附上文档、图片等 |
| 计时器 | 记录这件事花了多久 |
| 表情回应 | 表示赞成或反馈 |

不想点菜单的话，**直接在任务行里打斜杠 `/`** 也能唤出这些命令，输入关键词回车即可。手机上则是打字键盘上的工具条，机器人图标进去是 AI 相关命令。

## 五、把任务和项目串起来

- **@ 提及**：在任务里打 `@` 加上目标项目（或人）的名字，就能建立一条跳转链接，点一下从当前项目跳到那边。
- **# 标签**：打 `#` 加标签名，用同一套标签横跨多个项目给任务归类，之后按标签就能把散在不同项目里的同类任务捞出来。

这两个符号在手机端也能用：选中任务后在工具栏里找 `@Mention`，效果一样。

## 六、多人协作：分享与权限

要把项目给别人看或一起改：

1. 打开项目，点右上角的**三个点**。
2. 选**分享**。
3. 填对方邮箱并设定权限，或直接**复制链接**发出去。

权限从高到低大致是「拥有者 → 可编辑 → 可评论 → 只看」，按对方该不该动手来选。项目一旦分享出去，对方的改动会实时出现在你这边；这也意味着**给外部人开权限前先想清楚给到哪一档**。
