## 一、安装包装不上，提示解析错误或应用未安装

按可能性从高到低排：

1. **文件没下完就点了安装。** 删掉重下，下完确认大小与 138.52 MB 相符。
2. **文件损坏。** 用 MD5 校验工具核对是不是 `5713342BD8D6D49D00E2728213DDF7E5`，对不上就重下。
3. **系统版本过低。** 装上闪退或直接拒绝，多半是系统太老；本版支持范围见 [下载与安装教程.md](下载与安装教程.md) 的「系统版本」。
4. **旧版残留冲突。** 曾经装过同名应用的话，先在「设置 → 应用」里彻底卸载，再装这一版。

## 二、登录不上

先把最容易错的一步排除：**确认你用的是注册时的同一种登录方式**（邮箱密码，还是 Google / Apple / Microsoft）。换错方式会登进一个空账号，看起来就像「账号丢了」。

其余依次排查：

- 邮箱没验证 → 翻收件箱与垃圾邮件，点验证链接；
- 忘记密码 → 登录页走「忘记密码」，邮件重置；
- 开了两步验证 → 验证码不对先检查手机时间是否自动同步，换机后用备用码；
- 网页端登录被拦 → 放行弹窗与第三方 Cookie。

仍不行时，注意区分「完全登不上」和「登上了但内容不对」——后者是账号串了，处理办法见 [注册登录与多端同步.md](注册登录与多端同步.md)。

## 三、一直转圈，加载不出内容

先在别的设备或浏览器上试一下同一个项目，用来区分是**你的网络**问题还是**服务本身**的问题。若只有你的手机不行，按平台处理：

1. **强制停止。** 设置 → 应用 → Taskade → 强制停止，再重新打开。
2. **清缓存。** 设置 → 应用 → Taskade → 存储 → 清除缓存，先只清缓存，不动数据。
3. **清数据。** 还不行再清除数据（会需重新登录），然后重启手机。
4. **重装。** 以上都无效时卸载后重装（重装前确认改过的东西已经同步上去）。

一般到第 2、3 步就能恢复。

## 四、改了的没同步 / 离线改动没上云

Taskade 联网时是实时同步，断网时的改动会先存本机、联网后再传。所以：

- **先确认网络真恢复了**，只是信号格有变化不代表应用已连上，切换一下 Wi-Fi / 流量试试。
- **等几分钟再刷新**，同步偶尔会延迟，不是每次都要立刻处理。
- **别在两台设备上同时离线改同一件事**，否则重新联网时可能撞车，需要你手动选保留哪边。
- **去别的设备或网页端确认**，看改动是否已经到云端。

如果是「项目整个不见了」而不是「改动没上去」，见下面第八条。

## 五、收不到任务到期或协作通知

先分清是**提醒没设**还是**权限没开**——设提醒的步骤见 [桌面小组件和快速添加.md](桌面小组件和快速添加.md)。两处都对了还是没动静，按下面查：

系统权限：

- **Android**：设置 → 通知（部分机型是 设置 → 应用 → Taskade → 通知）→ 找到 Taskade，打开通知开关；再确认「勿扰模式」没有把它一起静音。
- **iOS**：设置 → 通知 → Taskade → 打开「允许通知」。

应用内设置：进入应用的通知设置，确认任务指派、评论、提及、到期这几类事件没有被单独关掉。

两个容易忽略的点：

- **通知是按设备生效的**，手机和电脑要各开一次，不是一处开了到处都响。
- 偏好邮件提醒的话，把 `notifications@taskade.com` 加进联系人，免得提醒邮件被扔进垃圾箱。

## 六、手机上编辑任务时底部的工具栏不见了（Android）

这是 Android 的**全屏手势**挡住了工具栏，不是应用坏了。处理办法：

1. 打开系统**设置** → **显示**；
2. 往下找**导航栏**相关选项；
3. 从「手势」切到**导航按钮**，回应用里工具栏就回来了。

工具栏若回来后仍时有时无，可再换一种输入法试一次。

## 七、AI 提示额度用完

大概率不是故障，而是 AI 额度用尽。先去账户的用量处看剩余额度：

- 免费版的额度是**一次性**的，用完不重置；
- 付费版按月补充，看看是不是本期已用完。

额度怎么消耗、免费版给多少，见 [免费版和付费版有什么区别.md](免费版和付费版有什么区别.md)。如果额度明明充足却仍被拒，先把应用重开一次再试。

## 八、删掉的项目或任务找不回来了

先别急着重做，按顺序找：

1. **归档 / 回收站。** Taskade 删除的项目通常先进入归档区，在账户的归档入口里可以恢复，不是一删就没。
2. **全局搜索。** 用搜索按名字找，可能只是被移到了别的工作区或文件夹。
3. **换错账号。** 确认当前登录的是常用账号，不是用另一种方式登录出来的空账号。

恢复回来之后，建议把重要的归档策略定一下——定期清归档是自己的事，官方不会替你保留。
