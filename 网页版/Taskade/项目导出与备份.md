## 一、导出解决的是哪两个问题

- **备份**：数据在云端，账号一旦删除就永久消失，导出是唯一能留在自己手里的副本。
- **搬运**：把内容拿到别的工具里用（写进文档、导进表格、喂给其他系统）。

Taskade 的导出按粒度分两档：**单项目导出**拿到的是可读文档，**按视图导出**拿到的是表格数据。要哪个，先想清楚下一步用在哪。

## 二、导出单个项目（可读文档）

1. 打开要导出的项目。
2. 点右上角的 **⋯（三个点）** 菜单。
3. 选 **Export（导出）**。
4. 选择格式：**Markdown / PDF / 纯文本**。

这套导出会保留项目的层级——任务、子任务、备注都在，不只是把文字拍平。手机上操作同理，先打开项目再找右上角菜单。

## 三、按视图导出表格（CSV）

如果下一步是进 Excel、Google 表格或别的系统，**不要用文档格式，直接导 CSV**。方法是打开项目、切到某个视图，再执行导出。不同视图导出的列不一样：

| 你所在的视图 | 导出的表格长什么样 |
| --- | --- |
| 表格 Table | 每个字段一列，一条任务一行 |
| 列表 List | 任务与子任务，附带各自字段 |
| 看板 Board | 卡片，外加它所在的列 |
| 日历 Calendar | 任务，附带开始与到期时间 |
| 思维导图 Mind Map | 每个节点，附带它的父节点 |
| 组织结构图 Org Chart | 每个角色，附带它归属谁 |

一句话记法：**想留成能读的文档用 Markdown / 纯文本 / PDF，想进表格用 CSV。** 各视图的区别见 [项目视图怎么选.md](项目视图怎么选.md)。

## 四、让自动化帮你定期备份

不想每次手动导，可以把它挂成一条自动化，让它按点自己跑：

1. **触发条件**：日程，比如「每天」某个固定时间；
2. **动作一**：Project Export（把指定项目导成 Markdown / 纯文本）；
3. **动作二**：把导出的文件上传到云端硬盘（如 Google Drive 的一个备份目录）。

这样每天/每周都有一份落在云端硬盘里，项目被误删也不至于全丢。自动化在免费版也能建（官方计划页显示免费版有数量上限，付费版不限条数），对备份频率要求高时再考虑升级，名额与限制见 [免费版和付费版有什么区别.md](免费版和付费版有什么区别.md)。

## 五、换账号或删账号之前，先做这四件事

删除账号是**永久且不可撤销**的，动手前按顺序做：

1. **导出所有想留的项目**（第二节的办法，逐个来；官方不会替你备份）。
2. **转移共享工作区的所有权**：你是某个共享工作区的拥有者，先把所有权转给另一位成员，否则对方会一起失去访问。
3. **取消有效订阅**：还有付费计划的话先取消，避免继续扣费。
4. **在账号设置里执行删除**：进入设置页面拉到底，点删除/关闭账号，按提示**重新输入邮箱**确认。

删除请求提交后，官方的口径是数据会在一定时间内（最多约 30 天）从各系统与备份中清完。24 小时内联系客服或许还能挽回，之后不保证。

只想退出某个共享工作区、不删整个账号的话，让该工作区的拥有者把你移出即可，不必走删号流程。
