# Taskade 界面语言怎么改成中文

> 本篇讲 Taskade 的界面支持哪些语言、怎么在手机和电脑上把界面换成中文，以及更换语言时哪些东西会跟着变、哪些不会。

## 一、支持哪些语言，含不含中文

官方帮助中心说明 Taskade 目前支持 31 种界面语言，**清单里包含中文**。常见还有英语（美式 / 英式）、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语等。语言数量与清单会随版本调整，具体以官方帮助页当时显示为准。

需要先分清两个概念：

| 你说的「语言」 | 指的是什么 | 能不能靠设置改 |
| --- | --- | --- |
| 界面语言 | 按钮、菜单、提示文字用什么语言 | 能，下面就是操作 |
| 内容语言 | 你写的任务、你自己起的名 | 不能，界面换成中文不会翻译你的内容 |
| AI 回复语言 | 智能体、AI 助手回答用什么语言说话 | 部分能，靠提问语言和指令控制，见第五节 |

## 二、在手机上换成中文

1. 打开 Taskade，进到**账号 / 设置**入口（通常在左上角或侧边栏的头像附近）。
2. 找到**语言（Language）**一项，多在「通用 / General」分组下。
3. 从列表里选**中文 / Chinese**。
4. 返回后界面文字即刷新为中文。

如果换了没生效，把应用完全关掉再重开一次；手机端各项设置的叫法会随版本微调，找不到时以应用内实际显示为准。

## 三、在电脑网页端换成中文

有两条路，任选其一：

- **快路**：点右上角**头像** → 选 **Change Language（切换语言）** → 在下拉列表里选 Chinese。
- **常路**：头像 → **设置（Settings）** → **通用（General）** → 在 **Language** 里选。

桌面客户端与网页端入口一致。语言设置跟着**账号**走，所以在一台设备上改好，另一台设备登录后一般已经是中文。

## 四、在手机键盘工具条里找不到中文命令

界面语言影响的是菜单文字，**AI 命令（/ask、/outline 这类）的命令词本身是英文的**，换成中文界面也不会变成中文命令。打这些命令时照英文敲即可，或者用中文把需求说清楚，让 AI 直接理解。

## 五、换语言时要注意的三件事

1. **已写的内容不会被翻译。** 换界面语言只动界面，不动你项目里的文字。
2. **AI 用哪种语言回答，多半取决于你怎么问。** 想稳定拿到中文回答，提问就用中文写；给智能体加了人设的，可以在它的指令里直接写明「一律用中文回复」。
3. **语言是账号级设置。** 如果某个设备上还是英文，多半是没登录同一个账号，或这台设备上的会话还没刷新，重登一次再看。

## 六、界面还是英文 / 找不到语言入口

先确认版本不太旧（旧版可能没有中文项），再按 [常见问题与排查.md](常见问题与排查.md) 里「一直转圈，加载不出内容」一节重置一下应用数据后重试。仍然找不到入口时，注意有些设置项要登录后才出现，未登录状态看到的菜单是精简的（登录步骤见 [注册登录与多端同步.md](注册登录与多端同步.md)）。
