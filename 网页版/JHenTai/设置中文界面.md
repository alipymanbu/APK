## 一、把界面切成简体中文

JHenTai 官方内置了简体中文语言包，但首次启动默认跟随英文，要手动切一次（多个中文教程的步骤一致）：

1. 打开应用，点右下角（或侧边）的**设置**图标进入设置页。
2. 找到 **Preference**（偏好设置）一项，点进去。
3. 点第一项 **Language**（语言）。
4. 在列表里选 **简体中文**，界面文字立即切换。

切完返回上一级，菜单、按钮应该都已是中文。如果部分界面还是英文，把应用完全退掉再开一次即可生效。

## 二、三种界面布局

JHenTai 按设备尺寸给三套布局（官方功能列表），不用你手动配：

- **手机布局**：底部标签栏 + 列表，单手够得到全部入口；
- **平板布局**：左右分栏，左侧导航、右侧内容；
- **桌面布局**：窗口化，鼠标操作为主。

应用通常会按屏幕大小自动选对布局；识别不准时（比如平板上仍显示手机版），有用户分享可在 `设置 → 外观` 里强制启用电脑版模式——以键盘操作取代触控，并启用多分页浏览，大屏上更顺手（单一博客经验，入口名称以你的版本实际显示为准）。

阅读页面另有 4 种排版可切（垂直滚动、水平翻页、双列等），在阅读页里随时换，细节见 [下载漫画与离线阅读.md](下载漫画与离线阅读.md)。

## 三、几项常用偏好设置

| 你想做的事 | 位置 |
| --- | --- |
| 调 Windows 鼠标滚轮翻页速度 | `设置 → MouseWheel` |
| 导出/导入应用数据（换机、备份） | `设置 → Advanced Setting → Export Data` |
| 恢复没跑完的下载任务 | `设置 → Download → Restore Download tasks` |
| 用指纹解锁应用 | 官方功能列表里的 `Fingerprint unlock`，在设置的安全相关项里开 |
| 改列表样式、EH 站点选项 | `设置 → EH Setting`（各项含义见 [常见问题与报错排查.md](常见问题与报错排查.md)） |

## 四、语言设置找不到时

设置页的菜单名随版本略有差异，认准这三个英文关键词定位：**Preference**（或 Preferences）、**Language**、**简体中文**（有的版本写作 `Chinese (Simplified)` 或 `zh_CN`）。若你的版本里确实没有中文选项，先按 [下载与安装教程.md](下载与安装教程.md) 换成官方最新版再试。
