## 一、列表一直 Connect Timeout / Receiving Data Timeout

画廊列表反复加载失败、报连接或接收数据超时，官方 Q&A 给了四步：

1. 换代理节点、换网络条件试一次；
2. 网络确实慢就到 `设置 → 网络设置` 把超时时间调大；
3. 到网络设置里**关闭 domain fronting（域前置）**开关再试；
4. 还不行，把错误信息里的英文原文对着看——那是 E-Hentai 直接给出的访问限制原因，按其官方 Wiki 的说法处理。

用代理的桌面版用户注意：代理地址在应用的 `网络设置` 页填写，不在系统里设（官方 README 说明）。

## 二、封面/缩略图报 Bad state: Failed to load

日志里出现 `Bad state: Failed to load xxx`，含义是那张图的节点你的网络访问不到（官方 Q&A）：

- 换代理与网络条件后重试；
- 把日志里的图片链接直接丢进浏览器打开——浏览器也打不开，说明问题在链路不在应用；
- 在 `设置 → 高级` 打开「记录所有日志」（需重启应用生效），下载失败的链接都能在下载日志里看到；
- 单张图始终解析不到可用节点时，去 E-Hentai **官网设置里换「节点区域偏好」**（官方 Q&A 指向官网设置页）。

补一个背景数字：图片直链本来就有有效期——H@H 节点的直链最多 15 分钟、服务器直链最多 24 小时（EHWiki 口径）。所以卡住的图**重新解析通常就能好**，这也是应用会自动重解析、阅读页支持长按触发重解析的原因。

## 三、搜索结果比网页少，甚至为空

按官方 Q&A 的顺序查四处过滤器：

1. 搜索页右上角**漏斗图标**——先看你自己的筛选条件；
2. `设置 → 偏好 → Local Tag Filtering`——本地屏蔽了哪些标签；
3. `设置 → EH Setting → My Tags`——网站侧的标签过滤；
4. `设置 → EH Setting → Site Settings`——站点自身的过滤设置。

四处各自管什么、My Tags 的权重和 Hidden 怎么算，单独写在 [标签屏蔽与搜索过滤设置.md](标签屏蔽与搜索过滤设置.md)。四处都干净还有差异，再看 [账号登录方式与403错误.md](账号登录方式与403错误.md) 确认登录状态。

## 四、列表里不显示标签

不是应用坏了，是列表样式不带标签（官方 Q&A）：

- 去 E-Hentai **官网**把列表样式（list style）换成会显示标签的那种，应用会跟着生效；
- 想网页和应用用两种不同样式——官网的 Profile 各用一个，在 `EH Setting → Profile Setting` 里选；
- 设了本地标签过滤但画廊没被过滤掉：同样是样式问题——Compact 这类样式在官网上每条只显示有限几个标签，过滤标签超出显示范围就不生效，换一个能显示全标签的样式。

## 五、按日期搜索时间对不上

E-Hentai 只支持按 **UTC 时间**搜画廊，而应用按系统时区显示——差几个小时是时区换算造成的，不是数据错了（官方 Q&A）。v8.0.0 起官方更新说明里加了「画廊时间按 UTC 显示」的开关，在偏好设置里切过去，应用显示就和搜索口径对齐了。

## 六、数据备份与迁移

换手机或重装前，先到 `设置 → Advanced Setting → Export Data` 导出数据；装回后导入即可。下载任务单独用 `设置 → Download → Restore Download tasks` 恢复（见 [下载漫画与离线阅读.md](下载漫画与离线阅读.md)）。应用本体的安装包见 [下载与安装教程.md](下载与安装教程.md)。
