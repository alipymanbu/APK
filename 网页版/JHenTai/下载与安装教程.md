## 一、JHenTai 是什么

JHenTai 是一个开源的 E-Hentai 图库阅读器，用 Flutter 写成，官方同时提供 Android、iOS、Windows、macOS、Linux 五个平台的安装包，源码与全部安装包都在 [github.com/jiangtian616/JHenTai](https://github.com/jiangtian616/JHenTai) 的 Release 页面。它没有上架应用商店，安装包要自己下载，安卓版就是一个普通 APK。

本篇以安卓手机为主（多数人从这里开始），桌面与其他平台的方式在第三节列了一张表。

## 二、安装安卓版（APK）

1. 从上方或这里拿到安装包：[JHenTai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/da609d024f5d)。
2. 核对文件：网盘里那份是 `JHenTai_v8.0.12.apk`，约 13.55M，包名 `top.jtmonster.jhentai`。版本会随更新变化，以官方 Release 页面当时显示为准。
3. 在手机上点开 APK 安装。系统会先问「是否允许安装未知来源应用」——普通浏览器或文件管理器下载的 APK 都要过这一关，在弹出的提示里允许即可（不同品牌入口略有差异，一般在 设置 → 安全 → 安装未知应用）。
4. 装完打开，首次启动是英文界面，先去 [设置中文界面.md](设置中文界面.md) 切成简体中文。

如果你是从 GitHub Release 自己下 APK，注意按 CPU 架构选（官方说明）：

| 架构 | 适合谁 |
| --- | --- |
| `arm64-v8a` | 近几年的主流安卓手机（第 8 代 ARM 架构），绝大多数人选这个 |
| `armeabi-v7a` | 老一点的手机（第 7 代 ARM 架构） |
| `x86_64` | 极少见的 Intel/AMD 处理器设备 |

## 三、其他平台怎么装

| 平台 | 官方安装方式 | 官方注明的注意点 |
| --- | --- | --- |
| Windows | 下载 `Windows_xxx.zip` 解压，双击 `jhentai.exe` 运行 | Win11 若启动不了，用兼容模式运行；被 Windows Defender 拦截时选择信任；要用代理就在应用的网络设置页填代理地址 |
| iOS | 下载 `.ipa`，用 AltStore 或 SideLoadly 签名后安装 | 官方提供 AltStore 源，装好后更新更省事 |
| macOS | 下载 `.dmg` 安装 | 需要在系统设置里信任它；官方标注该平台不再维护 |
| Linux | 下载 `.deb` 或 `.AppImage` | 可能需要先装 `webkit2gtk-4.1`；官方标注该平台不再维护 |

## 四、怎么更新

- **安卓**：直接安装新版 APK 覆盖旧版，数据会保留；新包可从官方 Release 页面获取（见下）。
- **Windows**：删掉旧的解压目录，再解压新 zip 即可（官方说明，没有覆盖安装一说）。
- **其他平台**：iOS 重签新 `.ipa`；macOS/Linux 换装新的安装包。

官方 Release 页面地址是 [github.com/jiangtian616/JHenTai/releases](https://github.com/jiangtian616/JHenTai/releases)，当前最新版本号以该页面当时显示为准。

## 五、装完接着做什么

第一次上手按这个顺序来：先把界面切成中文（[设置中文界面.md](设置中文界面.md)），再登录你的账号（[账号登录方式与403错误.md](账号登录方式与403错误.md)）。之后遇到加载超时、图片打不开之类的问题，直接查 [常见问题与报错排查.md](常见问题与报错排查.md)。
