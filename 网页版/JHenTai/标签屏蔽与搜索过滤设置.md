## 一、先分清四层过滤器

同一个「搜不到东西」的问题，可能卡在不同层。按官方 Q&A 的排查顺序，从快到慢过一遍：

| 层 | 在哪改 | 影响范围 |
| --- | --- | --- |
| 搜索漏斗 | 搜索页右上角漏斗图标 | 只影响这一次搜索 |
| Local Tag Filtering | `设置 → 偏好` | 只在本机生效，不碰账号 |
| My Tags | `设置 → EH Setting → My Tags` | 账号级规则，网页端与应用共用 |
| Site Settings | `设置 → EH Setting → Site Settings` | 站点自身的过滤选项 |

顺序建议：先看漏斗（最常被自己忘掉），再看本地，最后才去动账号侧的 My Tags——My Tags 改了会连网页端一起变。

## 二、My Tags 的权重与硬/软过滤

网站侧的 My Tags 用「权重」决定过滤强度（EHWiki 社区词条口径，数值以页面当时显示为准）：

| 概念 | 规则 |
| --- | --- |
| 权重范围 | 99 ~ -99，默认 10 |
| **硬过滤** | 勾选标签旁的 **Hidden**：画廊只要带这个标签就被过滤，其他标签再高也没用 |
| **软过滤** | 给标签设**负权重**：画廊全部标签的权重**求和低于阈值**才被过滤 |
| 过滤阈值 | 在 My Settings 里设，默认 0，可设 -9999 ~ 0 |
| Watched（关注） | 勾选 Watched 的标签进关注页；关注阈值默认 0，可设 0 ~ 9999 |
| 失效场景 | **Toplists 与收藏夹列表永远不过滤**——榜单里冒出不想看的内容是正常的 |
| 标签集 | 普通用户 1 组，Gold Star 用户最多 10 组，每组最多 100 个标签 |

另有一个容易迷惑的现象（EHWiki 的 Quirks 条目）：**当一次搜索按过滤条件算下来会是 0 条结果时，站点可能直接忽略过滤器**——所以「我明明屏蔽了却还能搜到」有时恰恰说明结果快被你清空了。

## 三、应用内对应的几个开关

以下几项是官方更新说明（v8.0.0 起）列出的应用侧能力，本篇对应的 8.0.12 版都已包含：

- **快速本地屏蔽画廊上传者**：看到不想看的上传者，详情页里直接本地拉黑，不经过账号；
- **本地评论屏蔽规则支持按内容过滤**：不只想按人屏蔽、还想按评论文字过滤时用它；
- **标签屏蔽规则里的中文生效**：早期版本「规则里写中文无效」的问题已在 v8.0.0 修复，用简体中文写屏蔽规则没问题；
- **搜索语言过滤条件拼在最前面**：指定语言搜索时过滤条件前置，短词组搜索不再被截断；搜索选项现在继承到所有搜索场景，不再只对点标签搜索生效；
- **画廊时间可按 UTC 显示**：在偏好设置里切换（见 [常见问题与报错排查.md](常见问题与报错排查.md) 日期一节）。

## 四、过滤之后结果还是不对

按这个顺序收尾：

1. 漏斗里有没有残留的高级筛选（语言、时间范围、页数）；
2. 换一个**能显示全部标签的列表样式**——Compact 这类样式在官网上每条只带有限几个标签，过滤标签超出显示范围就不生效（详见 [常见问题与报错排查.md](常见问题与报错排查.md)）；
3. My Tags 权重是不是设得太温和：软过滤要**总和低于阈值**才动手，单个 -5 的负权重很容易被别的标签补回来，想硬性屏蔽直接用 Hidden；
4. 以上都干净仍比网页少，先确认登录状态（[账号登录方式与403错误.md](账号登录方式与403错误.md)），站点本身对部分关键词有屏蔽，这时任何客户端都搜不到。
