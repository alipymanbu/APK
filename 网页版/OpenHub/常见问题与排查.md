## 一、Trending（趋势）页面打不开或报解析错误

Trending 是 OpenHub 从 GitHub 网页抓取解析出来的，GitHub 页面结构一改版，这个页面就会出现解析错误。历史上已经发生过几次，官方也修过几次：

- v3.1.0 修复了 Trending 页面、语言选择页的解析错误；
- v3.2.1（也就是 3.2.1 这个最终版本）又修复了一次 Trending 页解析错误，并顺带移除了 Bugly 统计组件。

**你现在能做的**：

1. 确认自己装的是 3.2.1 —— 旧版本在 GitHub 页面改版后 Trending 大概率打不开；
2. 已经是 3.2.1 还打不开，说明是 GitHub 又改版了，这个客户端官方已停止维护，短期内不会有新修复。临时替代：直接在浏览器里看 [github.com/trending](https://github.com/trending)；
3. 其他页面（仓库、搜索、Issue）走的是 GitHub API，不受网页改版影响，可以正常用。

## 二、登录授权失败或卡在授权页

OpenHub 从 v3.2.0 起只支持 OAuth 网页授权登录，登录问题集中在这条链路上：

| 现象 | 先检查什么 |
| --- | --- |
| 授权页打不开、一直转圈 | 手机能否正常访问 GitHub 网页；国内网络直连 GitHub 不稳定，可尝试更换网络环境后重试 |
| 授权页要求输入验证码 | 账号开启了两步验证（2FA），在授权页输入验证器动态码即可，属 GitHub 正常流程 |
| 输完账号密码没反应 | 确认账号密码本身能在网页上登录成功 |
| 授权完成后回到应用仍是未登录态 | 退出应用重新打开再试一次；仍不行就到 GitHub 网页撤销授权后重新来一遍 |
| 登录后数据加载失败 | 网络问题，GitHub API 请求没到达；同样是换网络环境 |

登录正常但数据偶尔整体加载失败、稍等又恢复，可能是触到了 GitHub 的接口调用限额，过一会儿再试。

撤销重授的操作路径：登录 GitHub 网页版 → Settings → Applications → Authorized OAuth Apps → 找到 OpenHub → Revoke，然后回应用重新登录。详细步骤见 [登录与多账号切换.md](登录与多账号切换.md)。

## 三、收不到通知

OpenHub 的通知来自 GitHub 账号的消息，排查按这个顺序：

1. 应用内确认通知开关是打开的（侧边栏进设置查看）；
2. 系统设置里检查是否给 OpenHub 开了通知权限（国产系统普遍默认关闭第三方应用通知）；
3. 通知依赖应用能连上 GitHub，网络不通时自然收不到 —— 参考第二节；
4. GitHub 网页端的通知设置里，确认对应类型的通知本身是启用的 —— 网页端 Settings → Notifications 可按仓库与参与方式细分，相关通知全被关掉的话，客户端侧自然没有可推的内容。

## 四、安装失败

安装环节的问题对照处理：

| 报错/现象 | 原因与处理 |
| --- | --- |
| 提示解析包错误 | 安装包下载不完整或被改动过，重新下载并核对 MD5，见 [下载与安装教程.md](下载与安装教程.md) |
| 提示无法安装/不兼容 | 系统版本低于 Android 5.0，OpenHub 要求 5.0 及以上 |
| 安装到一半中断 | 存储空间不足，或安装器被系统杀掉；清理后重装 |
| 装完点开就闪退 | 先重启手机；仍闪退则卸载后重新安装并核对包完整性 |

## 五、这个项目还在更新吗

判断依据（截至本文撰写时）：

- OpenHub 在 GitHub 上以 GPL-3.0 协议开源，仓库为 [github.com/ThirtyDegreesRay/OpenHub](https://github.com/ThirtyDegreesRay/OpenHub)，累计四千多 star；
- 官方仓库已经较长时间没有新提交，**3.2.1 就是当前最新的发布版本**，本文档里的功能描述都以这个版本为准；
- 这意味着：GitHub 网页侧改版引发的功能失效（最典型的就是 Trending 解析）可能不会再有官方修复；仓库、Issue、代码阅读这类走 API 的核心功能不受影响，仍可正常长期使用；
- 遇到新问题可以到仓库的 Issues 区搜索或提交反馈；有开发能力的也可以自行从源码构建（需要自己配置构建环境）；
- 如果因此考虑换一个仍在维护的客户端，对比与选择建议见 [GitHub安卓客户端怎么选.md](GitHub安卓客户端怎么选.md)。
