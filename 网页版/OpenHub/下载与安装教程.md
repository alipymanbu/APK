## 一、安装前先确认这几件事

OpenHub 是一个开源的 GitHub 安卓客户端，只能在安卓手机上运行。动手之前先核对设备与安装包：

| 项目 | 要求 / 数值 |
| --- | --- |
| 系统版本 | Android 5.0 及以上 |
| 安装包大小 | 约 3.23 MB |
| 包名 | `com.thirtydegreesray.openhub` |
| 本篇对应版本 | 3.2.1 |
| 安装包 MD5 | `437828606E260874E99AFE76E09012D2` |

两点说明：

1. **需要有一个 GitHub 账号**。OpenHub 本身免费开源，但它的所有数据都来自你的 GitHub 账号，没有账号就只能看公共 Trending 页，无法登录使用完整功能。
2. 版本号与大小以安装包实际文件为准；官方后续如果发新版，以官方发布页显示为准。

## 二、从哪里获取安装包

官方提供的获取渠道有三个：

| 渠道 | 地址 | 说明 |
| --- | --- | --- |
| GitHub Releases | [github.com/ThirtyDegreesRay/OpenHub/releases](https://github.com/ThirtyDegreesRay/OpenHub/releases) | 开发者官方发布页，APK 直接下载 |
| Google Play | [play.google.com](https://play.google.com/store/apps/details?id=com.thirtydegreesray.openhub) | 适合能访问 Play 商店的设备 |
| 酷安 | [coolapk.com](https://www.coolapk.com/apk/com.thirtydegreesray.openhub) | 国内应用市场 |

如果上述渠道下载不便，也可以从 [OpenHub 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1865eb8d1c57) 转存后下载，文件与上表核对无误后再安装。

## 三、核对安装包再安装

从非商店渠道拿到 APK 后，建议先核对 MD5，确认文件没有被改动过：

1. 用手机或电脑上的哈希计算工具算出 APK 文件的 MD5 值；
2. 与第一节的 `437828606E260874E99AFE76E09012D2` 逐字比对；
3. 不一致就不要安装，换一个渠道重新获取。

## 四、安装步骤

1. 点开下载好的 APK 文件；
2. 系统弹出「未知来源应用」提示时，选择允许本次安装（不同品牌手机路径略有差异，一般在设置里的「应用管理」或「安全」中可找到对应开关）；
3. 等待安装完成，整个过程通常几秒钟即可结束——安装包只有 3.23 MB；
4. 装完可以在系统设置里把 OpenHub 移动到 SD 卡（应用信息 → 存储 → 更改存储位置）。

安装失败的情况（提示解析包错误、装到一半中断等）集中在 [常见问题与排查.md](常见问题与排查.md) 里说明。

## 五、装好之后的第一步

首次打开 OpenHub 会直接进入登录页，需要用 GitHub 账号完成 OAuth 授权才能进入主界面。具体流程和授权时弹出的权限说明，见 [登录与多账号切换.md](登录与多账号切换.md)。
