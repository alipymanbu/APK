## 一、主题与主色调

设置入口：打开侧边栏，进 Settings（设置），主题相关选项都在里面。

| 选项 | 可选值 | 说明 |
| --- | --- | --- |
| 主题 | Light / Dark / AMOLED Dark | AMOLED 纯黑主题是 v3.0.0 加入的，OLED 屏幕手机用它更省电 |
| 主色调（Accent color） | 多种颜色可选 | 决定按钮、链接、高亮处的颜色，与主题搭配使用 |

你换主题和主色调只影响 OpenHub 自己的界面，不会影响系统全局的深色模式设置。想让应用跟随系统昼夜切换的话，OpenHub 没有自动跟随选项，需要手动在 Light 和 Dark 之间切换。

## 二、界面语言

OpenHub 内置了十几种界面语言，中文用户相关的是这两个：

- **简体中文**（Simplified Chinese）
- **繁體中文**（Traditional Chinese，v3.2.0 加入）

完整语言列表：英语、简体中文、繁体中文、希伯来语、德语、印地语、葡萄牙语、韩语、西班牙语、俄语、波兰语、格鲁吉亚语、意大利语、荷兰语、捷克语、葡萄牙语（巴西）。

切换方法：Settings → 语言（Language）→ 选简体中文。应用默认跟随系统语言，系统是中文时首次打开通常已经是中文界面，手动设置用于固定语言或在多语言环境切换。

注意一点：语言设置只翻译界面文字，仓库的 README、Issue 内容是用户写的原文，不会被翻译。

## 三、省流量的两个设置

用手机流量刷 GitHub 时，这两个开关在设置里：

1. **移动网络下不加载图片**（v2.6.0 起提供）：开启后流量环境下头像、仓库封面等网络图片不加载，文字内容正常浏览；回到 Wi-Fi 环境图片恢复加载。
2. **离线模式（Offline mode）**：离线时仍能看之前浏览过的内容。适合通勤路上无网或信号差的场景，缓存以外的新数据要等联网后刷新。

另外，安装包本身只有 3 MB 出头，装在手机上几乎不占空间，还可以在系统应用信息里把它移动到 SD 卡（v3.0.0 起支持），机身空间紧张的老设备用得上。

## 四、桌面快捷方式

长按桌面上的 OpenHub 图标会弹出快捷方式，可以直接跳到常用页面，不用先进主界面再找入口。常用哪几个页面，就把哪几个固定到桌面（具体项目以你设备上长按显示的为准）。

外观之外，日常用得最多的是仓库浏览与代码阅读，操作入口见 [仓库浏览与代码阅读.md](仓库浏览与代码阅读.md)；页面行为异常时先看 [常见问题与排查.md](常见问题与排查.md)。
