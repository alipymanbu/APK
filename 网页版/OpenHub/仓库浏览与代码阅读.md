## 一、发现仓库的几个入口

登录后从侧边栏能进这几个页面：

| 入口 | 能做什么 |
| --- | --- |
| Trending（趋势） | 按日 / 周 / 月看热门仓库，支持按任意语言筛选（含全部语言），还能看到当日 / 本周 / 本月的总 star 数 |
| 搜索 | 同时搜仓库和用户 |
| Collections（合集） | 浏览 GitHub 官方整理的仓库合集 |
| Featured topics（精选话题） | 浏览 GitHub 精选的话题页 |
| 书签（Bookmark） | 把用户或仓库收藏起来，方便下次直达 |
| 浏览记录（Trace） | 自动记录你看过的仓库和用户，找前几天看过但没收藏的仓库就靠它 |

注意：Trending 页面偶尔会因 GitHub 网页改版而打不开，属于已知情况，处理办法见 [常见问题与排查.md](常见问题与排查.md)；其余入口走 GitHub API，不受影响。Collections 和 Featured topics 与 Trending 同属页面解析类入口，网页改版时同样可能出问题（v3.1.0 就集中修过 Trending、Collections、Featured topics 这几个页面的解析错误）。

## 二、仓库页里能做什么

进入任意一个仓库后，你可以：

- 看 README、仓库描述、分支列表、提交历史（commits）和活动（activity）；
- Star、Watch、Fork，操作后状态与 GitHub 网页同步；
- 浏览文件树，逐层进入目录；
- 从 Releases 页下载源码包、发布版文件或单个文件；
- 查看仓库最近的 Wiki 更新；
- 自己账号下的私有、公开、Fork 和加星仓库都能在此查看。

## 三、在手机上读代码

读代码相关的功能主要有三块：

- **语法高亮**：主流语言的源码文件打开后有配色高亮，比裸文本好读得多；
- **Markdown 渲染**：README 和 .md 文件按渲染后的效果显示，表格、代码块、链接都能正常呈现；
- **提交差异（diff）**：在提交详情里看每次改动新增/删除了哪些行，评审别人代码或回看自己的改动都够用。

想离线读代码的话，配合离线模式可以看缓存过的文件；联网环境下所有公开仓库都能直接打开。

## 四、Issue 与用户、组织页

**Issue**：可以查看任意仓库的 Issue 详情、评论和事件，也能创建、打开、关闭 Issue，发表、编辑、删除评论，写评论时支持先预览再提交；给你自己的 Issue 管理标签（编辑、新增、删除）；「创建的 / 分配给你的 / 提到你的」三类 Issue 有独立入口。

**用户页**：看资料、关注者与关注列表、所属组织、公开仓库、加星仓库和动态；可以关注 / 取消关注。

**组织页**：看组织信息、公开仓库、活动与成员列表。

多账号用户的提醒：以上所有操作都作用于**当前登录的账号**，切换账号后 Star、Follow 等操作会记到新账号头上，切换方法见 [登录与多账号切换.md](登录与多账号切换.md)。

## 五、几个顺手的习惯

1. 看到可能以后要用的仓库，先 Bookmark 而不是只靠浏览记录 —— 记录会被新浏览不断往前顶；
2. 常看的几个页面用桌面快捷方式直达（长按应用图标），少进两层菜单；
3. 流量环境下记得开「移动网络不加载图片」，README 里的大图是流量大户，设置方法见 [主题与语言设置.md](主题与语言设置.md)。
