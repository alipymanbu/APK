# Locus Map 定位漂移与轨迹断线排查

> 轨迹画成直线、定位乱跳、海拔不对，多数不是应用坏了，而是系统权限与省电设置在拦它。本篇按现象给排查路径，以官方知识库的口径为准。

## 一、先看 GPS 指示灯的颜色

主屏上的 GPS 指示灯用颜色区分状态，排查从它开始：

| 颜色 | 含义 | 处理 |
| --- | --- | --- |
| 白色 | 应用内没开启定位 | 点指示灯，再点开启定位 |
| 橙色 | 手机系统层面的 GPS 没开 | 下拉快捷开关，打开位置信息 |
| 绿色 | 正常定位中 | 不用管 |

白色且点居中按钮就弹权限警告，属于第三种情况：位置权限没给，见下一节。

## 二、位置权限必须「始终允许」

记录轨迹、语音导航这类功能要靠后台定位，只给「仅在使用时允许」是不够的：

- **Android 10** 把位置权限分成三档：不给、仅使用时、始终。只有「始终」能让应用在屏幕熄灭后继续拿位置——选它并不意味着 GPS 一直开着耗电，应用只在需要时才读取；
- **Android 11 及以上**，「始终允许」不在常规权限页里，一般是你在应用里启动记录或导航时，应用弹窗引导你跳到系统设置去授权；
- **授权会被收回**：系统对长期不用的应用会自动撤销「始终允许」（官方口径约三个月不用），之后记录又会出问题，重新授权一次即可。

## 三、轨迹变直线：电池优化在杀后台

屏幕一灭 GPS 就断、轨迹被直线连起来，最常见的元凶是厂商的省电机制——它会把「闲置」的应用冻结，位置读取随之中断。应用自己的设置管不了这层，要在系统里处理：

1. 把 Locus Map 移出电池优化（设置 > 应用 > Locus Map > 电池，选「不受限制」或类似选项）；
2. 各品牌还有自己的后台管理：华为/荣耀叫「启动管理」，小米叫「省电策略」，三星在「电池 > 后台使用限制」里，逐一把它设为例外；
3. 拿不准自己机型的设置路径，去 [dontkillmyapp.com](https://dontkillmyapp.com/) 按品牌查，那里汇总了各厂商杀后台的具体开关位置。

开启记录时应用如果弹出电池优化警告，不要跳过，当场按提示处理掉。

## 四、定位与海拔不准的调参

权限和省电都处理完仍有轻微漂移，进 设置 > GPS 与传感器 调这几项：

- **位置过滤**：选 medium 或更强的档位，压掉抖动；
- **谷歌服务辅助定位**：开或关都试一遍，效果因机型而异；
- **高程管理**：SRTM 数据选「优化 GPS 值」；手机有气压计就把气压计打开；高程过滤同样选 medium 或更强。

漂移严重、海拔明显不对时的进一步手段：

- SRTM 数据改选「替换 GPS 值」——爬升改由离线高程数据计算，不再依赖 GPS（该数据怎么下见 [离线地图与地图资源.md](离线地图与地图资源.md)）；
- 还不满意可开 Expert settings 里的自定义海拔阈值，在轨迹详情 > 编辑里用滑块调整。默认阈值不是固定值：用气压计取 2、用高程数据取 3、Android 12 以上取 5、其余取 10；
- 注意轨迹详情里的「更新高程」工具会覆盖按阈值算出的结果，用过之后阈值就不再起作用。

## 五、排查清单

| 现象 | 按顺序查 |
| --- | --- |
| 完全没有定位 | 指示灯颜色 → 应用内定位开关 → 系统 GPS 开关 → 位置权限 |
| 屏幕一灭就断 | 位置权限是否「始终」→ 电池优化是否排除 → 品牌后台管理 |
| 轨迹直线连接 | 同上两项（都是后台被杀的表现） |
| 定位抖动 | 位置过滤调强 → 辅助定位开关切换 |
| 海拔/爬升不对 | 高程管理各项 → SRTM 改替换模式 → 自定义阈值 |

排查完定位，重新记一条短轨迹验证效果最直接；还没装应用的话从 [下载与安装教程.md](下载与安装教程.md) 开始，订阅档位对功能的影响见 [免费版与付费功能区别.md](免费版与付费功能区别.md)。
