# 提示词怎么写才出好图

> 同一个 App，别人出图好看、你出图随机，差别九成在提示词。本篇给出可抄的结构与例子。还没跑通第一张图的话，先看 [第一次生成图片的完整流程.md](第一次生成图片的完整流程.md)；图压根出不来那是流程问题，看 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 一、先记住一条：越靠前越重要

Stable Diffusion 系列模型读提示词时，对**排在前面**的词权重更高。所以写的时候按「最重要的放最前」排：

```text
主体 → 主体细节 → 风格 → 构图 → 光线 → 质量词
```

「一只白鹿，站在雾气弥漫的森林里，唯美梦幻，柔光」好过「一张超级美丽的图片，有一只动物」。前者每一段都在给模型信息，后者只有形容词在空转。

## 二、六层结构对照表

不用每次全写满，但每次出图不满意时，对照这张表看漏了哪层：

| 层 | 作用 | 例词 |
| --- | --- | --- |
| 主体 | 画面里是什么 | 一只白色小鹿 / 穿汉服的女孩 / 赛博朋克城市 |
| 主体细节 | 长相、动作、穿着 | 回头、长发、红白汉服、鹿角带花 |
| 风格 | 画成什么画风 | 水墨、动漫、油画、梦境感、未来感 |
| 构图 | 镜头怎么摆 | 半身特写、全身、俯视、仰视 |
| 光线 | 什么光 | 逆光、黄昏柔光、月光、霓虹灯光 |
| 质量词 | 拉高完成度 | 高清细节、精致画面、杰作质感 |

## 三、照着 App 的风格分区选词

首页的风格分区（古风、二次元、唯美梦境等）本质是帮你预选了画风方向，你的提示词往同一个方向写，出图才不拧巴：

| 你选的分区 | 提示词往这个方向写 |
| --- | --- |
| 古风 | 汉服、庭院、灯笼、月下、水墨晕染、青绿山水 |
| 二次元 | 动漫风格、赛璐璐上色、少女、高饱和、清透 |
| 唯美梦境 | 梦幻、光斑、薄雾、柔焦、仙境、唯美光影 |

一个偷懒但有效的起点：作品墙卡片上那些短词（「暮光森林、神话、仙境」「极光、浪潮、梦幻场景」）就是能出这套图的真实提示词，点「制作同款」后只替换主体词即可。

## 四、三个立刻能用的技巧

1. **一次只改一个词**。图不满意时，整句重写会让你不知道是哪个改动起了作用；只改主体、或只改风格词，两相对比最快摸到规律。
2. **把「不满意」翻译成具体描述**。觉得画面脏，就加「干净背景、简洁构图」；觉得脸崩，就加「精致五官」；而不是写「再好看一点」这种模型读不懂的话。
3. **反向描述**。如果你用的版本在生成页提供「不希望出现」之类的输入框，把最怕出现的东西填进去，常见的可填：模糊、低质量、多余的手指、变形、文字水印。没有这个输入框就跳过，不影响出图。

## 五、质量词清单（可整段抄）

中文直接写没问题；习惯英文的话这些通用质量词也吃：

```text
杰作质感，超高清细节，锐利对焦，精致画面
masterpiece, best quality, ultra-detailed, sharp focus
```

注意质量词是锦上添花——主体和风格没写对，堆再多质量词也救不回来。

## 六、还是出不好图的四个去向

- **图能出来但手或脸崩了**：这是 AI 出图的老毛病，有专门的修法，看 [生成的图手指和脸画崩了怎么办.md](生成的图手指和脸画崩了怎么办.md)；
- **图能出来但不满意**：回到第二节对照表补层，或用「制作同款」借用别人验证过的提示词；
- **排队、失败、保存不上**：这些是流程问题不是写法问题，看 [常见问题与解决方法.md](常见问题与解决方法.md)；
- **想要完全自己控制模型、参数、分辨率**：手机 App 点选式的界面做不到的，电脑端可以，差异看 [和电脑版Stable Diffusion有什么区别.md](和电脑版Stable Diffusion有什么区别.md)；想换着花样练提示词，可以从 [第一次生成图片的完整流程.md](第一次生成图片的完整流程.md) 里的路径 A 反复改词开始。
