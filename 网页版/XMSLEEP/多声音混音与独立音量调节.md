## 一、播放与停止就一个动作

打开应用，首页是声音卡片列表：**点一下卡片开始播，再点一下停止**，没有多余的播放页。官方主页把声音总数标为 100+（网页版列出 113 种），实际以你界面上能看到的为准，常见的是雨声、篝火、雷声、猫咪呼噜、鸟鸣、夜虫、海浪、溪流这一类自然声。

## 二、叠加：把几个声音同时点亮

第二次点另一张卡片**不会打断第一个**，两张会一起响——这就是它的混音玩法。典型的叠法：

| 你想达到的效果 | 可以这样叠 |
| --- | --- |
| 屏蔽窗外突发噪音 | 雨声 + 雷声 |
| 睡前温度感 | 篝火 + 猫咪呼噜 |
| 白天安静但不死寂 | 溪流 + 鸟鸣 |

组合本身没有标准答案，你按当下环境叠就行。

## 三、每个声音单独调音量

1. 播放中点该卡片**右下角的音量图标**，弹出这个声音自己的音量条。
2. 想整体调轻调重，用「一键调整所有声音」的入口一次改完。
3. 官方说明音量设置会在应用重启后自动保留——你睡前调好的比例，第二天打开还在，不用每晚重调。

这一步是整个应用最值得花两分钟的地方：叠了三个声音却全在同一个音量上，多半会吵；把主声音（比如雨声）留在中位、辅助声音（猫呼噜）压到很低，才不容易把人吵醒。

## 四、声音从哪来：内置、网络、本地

- **内置声音**：随安装包带在手机里，**离线也能放**，弱网环境不受影响。
- **网络声音**：应用会从 GitHub 动态加载更多音频资源（来自开源项目 moodist，MIT 许可），这部分**需要联网**，加载不出来时处理办法见 [常见问题与故障排查.md](常见问题与故障排查.md)。
- **本地音频**：可以导入你自己手机里的音频文件来播（官方说明支持顺序、随机、单曲循环三种模式，以你版本的界面为准）。本地音频与白噪音**互斥**——你放本地歌时白噪音自动暂停，反之亦然，不会两套声音叠着响。

## 五、播放中常用的三个入口

- **收藏**：点声音卡片的标题，选「收藏」，之后在收藏列表里直接调。
- **最近播放**：官方说明重启应用时会弹出最近播放，可一键恢复上次那套声音；不想看到可以在设置里关（开关位置以你版本的界面为准）。
- **全局浮动按钮**：有声音在播时会出现一个小浮动按钮，点开能看当前在播哪几个、快速暂停；滚动页面时它会自动收起，不挡内容。

## 六、蓝牙耳机的自动行为

连着蓝牙耳机播放时，**耳机断开（比如没电、超出距离）应用会自动暂停**——这是防止你睡着后声音突然外放的设计。想继续播，重新点一次播放即可；相关疑问见 [常见问题与故障排查.md](常见问题与故障排查.md)。

调好一组顺手的组合后，把它存成预设一键切回，做法在 [倒计时定时与预设保存设置.md](倒计时定时与预设保存设置.md)。
