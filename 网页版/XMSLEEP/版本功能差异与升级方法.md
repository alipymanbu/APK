## 一、先说结论

你手里这份是 **2.1.3**（25.44 MB，记录时间 2026-09-23），官方仓库检索时最新版是 **2.3.3**（28.5 MB，以 [Releases 页面](https://github.com/Tosencen/XMSLEEP/releases) 当时显示为准）。**混音、独立音量、导入本地音频、在线加载更多声音、无缝循环这些核心能力 2.1.3 都有**（这份包的介绍里写明了）；差的是 2.1.3 之后新版本陆续加进来的东西。

## 二、2.1.3 没有的功能（官方更新日志显示在更高版本才加入）

| 功能 | 加入版本 | 2.1.3 里有吗 |
| --- | --- | --- |
| 呼吸练习引导（4-4-4） | v2.2.1 | 无 |
| 桌面小组件（时间 + 每日名言） | v2.2.3 | 无 |
| 自定义图片/视频背景、本地音频三种播放模式 | v2.2.8 | 无 |
| 简化版界面（3 列瀑布流） | v2.2.9 | 无 |
| 番茄时钟（结束铃声/震动） | v2.3.0 | 无 |
| 网页版播放器入口、黑白主题、通知栏冥想控制 | v2.3.1 | 无 |
| 和风天气源（自填 Key） | v2.3.2 | 无 |
| 每日一言随机每日图、敏感词过滤 | v2.3.3 | 无 |

对照办法很简单：**你界面上找不到某个功能，先查这张表**——多半不是你没找到，而是版本没到。表里没列的（混音、独立音量、倒计时这类基础项）通常是 2.1.3 已有的，具体有没有、入口在哪，以你装上后的实际界面为准。

## 三、要不要升级

- **想省事**：2.1.3 直接能用，混音 + 倒计时 + 预设覆盖了绝大多数日常场景；急着用某个新功能再升。
- **想先体验新功能但不想动手机**：网页版播放器（v2.3.1 加入的能力）浏览器就能开，见 [网页版在线播放器怎么用.md](网页版在线播放器怎么用.md)——不受手机版本限制。
- **系统较老的手机**：官方最新版标注最低 Android 8.0（API 26），低于这个系统的手机装不上新版，继续用网盘这份更稳妥（它的记录要求是安卓 5.2 以上，见 [下载与安装教程.md](下载与安装教程.md)）。

## 四、升级步骤

1. 打开 [github.com/Tosencen/XMSLEEP/releases](https://github.com/Tosencen/XMSLEEP/releases)，下载最新版 APK（页面上标的体积、最低系统要求以当时显示为准）。
2. 直接安装即可覆盖——包名同为 `org.xmsleep.app`，同签名的覆盖安装不需要先卸载。
3. 应用内置了通过 GitHub Releases 检查更新的机制，之后有新版会提示；**国内网络访问 GitHub 可能慢或失败**，自动检查失败时手动走第 1 步就好，提示失败的处理见 [常见问题与故障排查.md](常见问题与故障排查.md)。
4. 升级前把关键的预设组合记一下更保险（官方没有导出功能，数据留在本地，覆盖安装一般不受影响，但记一笔不亏）。

装不上、提示解析错误或签名冲突时，按 [常见问题与故障排查.md](常见问题与故障排查.md) 的安装排查走。
