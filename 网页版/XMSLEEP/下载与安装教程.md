## 一、先认清你要装的那一份

XMSLEEP 是一个开源免费的 Android 白噪音应用（MIT 许可，代码仓库在 [github.com/Tosencen/XMSLEEP](https://github.com/Tosencen/XMSLEEP)），装之前先对清楚版本——网上搜到的最新版和网盘里那份经常不是同一个。

网盘里这份安装包的记录信息：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.1.3 |
| 包名 | `org.xmsleep.app` |
| 大小 | 25.44 MB |
| MD5 | `986D8CD92A5B7189F823F3E723E48F09` |
| 记录时间 | 2026-09-23 |

官方渠道的最新版发布在 [github.com/Tosencen/XMSLEEP/releases](https://github.com/Tosencen/XMSLEEP/releases)，本次检索时显示为 v2.3.3、28.5 MB，**以官方页面当时显示为准**。两个版本在功能上有明确差异，装之前可以先看 [版本功能差异与升级方法.md](版本功能差异与升级方法.md)。

## 二、从夸克网盘拿安装包

1. 点开 [XMSLEEP 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5534180f6164)，先「保存到我的网盘」——先转存再下载，分享链接失效后你网盘里仍然有。
2. 手机装夸克 App 并登录同一个账号，在网盘里找到 `XMSLEEP（先保存再下载）` 文件夹。
3. 文件夹里的 `XMSLEEP_v2.1.3.apk` 就是安装包，下载到手机本地。
4. 文件夹里还有一份 `先保存再下载避免失效.txt` 说明文件，是给你的转存提示，不用运行它。

## 三、安装步骤

1. 在文件管理器里点这个 `.apk`。系统会弹「禁止安装未知应用」——点提示里的设置入口，允许你下载用的那个应用（夸克或文件管理器）安装未知应用，再返回继续。
2. 装完点「打开」即可开始用。
3. 想确认包没下坏，可以核对 MD5 是否等于 `986D8CD92A5B7189F823F3E723E48F09`，对不上就是下载不完整，重新下一次。

安装报错（解析包错误、签名冲突）的处理见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、系统要求

- 网盘这份 2.1.3 的记录标注：**需要支持安卓系统 5.2 以上**。
- 官方仓库最新版标注的最低要求是 Android 8.0（API 26）、目标版本 Android 15，**以官方页面为准**。
- 手机系统版本低于要求时，安装阶段就会报错；两份要求不一样是因为版本不同，按你要装的那一份对照即可。

## 五、装完第一次打开怎么开始

1. 首页是一排声音卡片，点任意一张（雨声、篝火、雷声、猫咪呼噜这类）就开始播，再点一次停止。
2. 想几个声音叠着放，就把几张卡片同时点亮，每张都能单独调音量——具体玩法在 [多声音混音与独立音量调节.md](多声音混音与独立音量调节.md)。
3. 睡前用的话记得设一个倒计时，到点自动停，见 [倒计时定时与预设保存设置.md](倒计时定时与预设保存设置.md)；打算整夜播的话，先读 [整夜播放白噪音伤耳朵吗.md](整夜播放白噪音伤耳朵吗.md) 把音量和摆法定了。
4. 第一次加载网络声音需要联网；如果卡片一直转圈，按 [常见问题与故障排查.md](常见问题与故障排查.md) 里的办法处理。
5. 不想装应用时，浏览器里也有能直接用的版本，见 [网页版在线播放器怎么用.md](网页版在线播放器怎么用.md)。
