## 一、有些声音一直转圈、加载不出来

**先判断是哪一类**：内置声音点开即响、离线也能放；加载不出来的那些是**网络声音**，资源在 GitHub 上，国内网络访问时快时慢。

- 换个网络（Wi-Fi / 流量）重试一次，多数情况是这次没连上；
- 只是想赶紧入睡的话，直接用内置声音，功能上没有缺口；
- 网页版同样依赖在线加载，连不上时它也一样，见 [网页版在线播放器怎么用.md](网页版在线播放器怎么用.md)。

## 二、蓝牙耳机一摘下声音就停了

**这是设计行为，不是故障**：官方说明蓝牙耳机断开时会自动暂停，防止你睡着后声音突然外放吵到别人。想让它继续播，重新点一次播放即可；不连耳机用外放时不会触发。

## 三、安装报错：解析包错误 / 装不上

按顺序排查：

1. **包是否完整**：文件应为 25.44 MB、MD5 为 `986D8CD92A5B7189F823F3E723E48F09`（网盘这份 2.1.3 的记录值）。对不上就是下载不完整，回 [下载与安装教程.md](下载与安装教程.md) 重新拿一次。
2. **系统版本**：官方最新版要求 Android 8.0 以上，网盘这份记录要求安卓 5.2 以上；系统低于要求会在安装阶段直接报错。
3. **签名冲突**：如果手机上已装过另一个渠道的同包名应用、签名不同，系统会拒绝覆盖。只能先卸载再装——**卸载会带走预设和收藏**，先按 [倒计时定时与预设保存设置.md](倒计时定时与预设保存设置.md) 里说的把组合记下来。

## 四、某个功能找不到（网页版入口、番茄钟、简化版…）

先对照 [版本功能差异与升级方法.md](版本功能差异与升级方法.md) 的表：那些功能是在 2.1.3 **之后**的版本才加入的，你版本里本来就没有。要升级按那篇的步骤走。

## 五、更新检查失败 / Releases 打不开

应用的自动更新走 GitHub Releases，**国内网络访问 GitHub 可能超时**。失败时不用等它：浏览器手动打开 [github.com/Tosencen/XMSLEEP/releases](https://github.com/Tosencen/XMSLEEP/releases) 下载最新 APK 覆盖安装即可；或者干脆继续用当前版本，日常功能不依赖这次更新。

## 六、播放一会儿就被手机杀掉了

白噪音要长时间后台播，部分手机的省电策略会把它暂停。遇到这种情况，在系统设置里做两处调整（不同品牌菜单名称略有差异）：

1. **电池 / 省电策略**：把 XMSLEEP 设为「不优化 / 无限制」；
2. **后台运行**：允许后台活动，锁屏后不清理。

另外官方说明支持系统媒体面板与锁屏控制，锁屏界面也能暂停和恢复，不必每次解锁进应用。

## 七、倒计时数字显示不对

官方在 v2.3.1 修复过「自定义倒计时显示问题」——**旧版本会有这个已知问题**，倒数本身照常走，只是数字显示异常。介意的话按 [版本功能差异与升级方法.md](版本功能差异与升级方法.md) 升到新版即可。

## 八、它会不会收集我的数据

按官方仓库的隐私说明：应用收集的是**匿名**使用统计（活跃数、崩溃报告），**不收集个人身份信息**，权限也只申请必要项。介意统计上报的话，可在系统层面关闭该应用的网络权限——代价是网络声音也加载不了，内置声音不受影响。
