## 一、先确认你的手机能不能装

KineStop 是安卓应用，商店页面标注的最低系统要求是 Android 7.1 及以上（不同渠道页标注略有出入，以官方商店页面为准）。安装包很小，本地这份是：

| 项目 | 值 |
| --- | --- |
| 版本 | 5.0 |
| 包名 | `com.urbandroid.kinestop` |
| 大小 | 7.66M |
| MD5 | `9C9CFF45D53879D7EAA7C242A40ABE5C` |

如果你手里的包和上面几行对不上（尤其包名），先别装 —— 包名不一致说明不是同一个应用。

## 二、安装步骤

1. 从 [KineStop 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ccaccf320b20) 下载 `KineStop_v5.0.apk` 到手机。
2. 点击文件开始安装。若系统弹出「禁止安装未知来源应用」，按提示进入对应来源的授权开关，允许一次后再返回安装。
3. 装完打开应用。第一次启动会依次请求权限，三项都建议给全（见下一节）。

整个安装过程没有账号注册，也不需要登录 Google 服务。

## 三、首次启动要给的三项权限

KineStop 的全部能力都建立在这三项权限上，缺一项都会让功能打折：

1. **显示在其他应用上层（悬浮窗）** —— 这是核心权限。它的作用是把会动的点阵画在你正在用的视频播放器、电子书阅读器之上。不给这项，点下播放键后屏幕上什么也不会出现。
   弹窗出现时点「允许」或「去开启」，在系统设置里打开「允许显示在其他应用上层」的开关，再返回应用。
2. **无障碍服务（可选但官方建议开）** —— 应用说明里写明：为了在整个屏幕（包括状态栏、通知栏和锁屏界面）上绘制运动提示，它可能要求启用 KineStop 无障碍服务。官方声明只用这项服务提升显示效果，不收集、不存储、不共享任何个人信息。路径一般在 系统设置 → 无障碍 → 已安装的服务 → KineStop。
3. **身体活动 / 物理活动权限（配合「在车内自动启动」时才需要）** —— 只有当你在设置里勾选了「在车内自动启动」，应用才会要这项权限，用加速度计判断你是否在行驶的车里。不用自动启动可以先不给。

## 四、点下播放键，确认它在工作

1. 回到 KineStop 主界面，点**右下角的播放按钮**。
2. 屏幕上应立即出现一层随手机姿态移动的点阵（默认是蓝色气泡样式）。
3. 按 Home 键回桌面、再随便打开一个视频应用 —— 点阵仍然浮在最上层，这才说明悬浮权限生效了。
4. 要停下，回到 KineStop 再点一次同一个按钮即可。
