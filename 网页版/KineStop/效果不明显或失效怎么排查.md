## 一、点播放键后屏幕上什么都没有

按出现频率排查：

1. **悬浮窗权限没给** —— 这是最常见原因。去 系统设置 → 应用 → KineStop → 权限，确认「显示在其他应用上层」已开启，回到应用重按播放键。
2. **装的包不对** —— 包名应为 `com.urbandroid.kinestop`。可以在应用信息页核对；对不上说明装了别的东西，换 [下载与安装教程.md](下载与安装教程.md) 里的包重装。
3. **系统版本过低** —— 官方商店标注需 Android 7.1 及以上，过旧的系统装上也无法正常绘制悬浮层。

## 二、点阵开着，切到别的应用就消失了

悬浮层被系统「省电策略」杀掉了。安卓厂商的后台清理很容易干掉常驻悬浮应用，官方给的对策是：

1. 关闭对该应用的电池优化：系统设置 → 应用 → 特殊访问权限 → 电池优化，切到「全部应用」，把 KineStop 设为不优化（这条路径在各品牌上基本通用）。
2. 个别品牌还有自己的第二层开关，需要额外处理：

| 品牌 / 系统 | 后台限制强度 | 额外要做的事 |
| --- | --- | --- |
| Google Pixel / 原生安卓 | 低 | 一般做完上一步就够 |
| 三星 One UI | 高 | 电池 → 后台使用限制，检查「睡眠中应用 / 深度睡眠应用」列表，把 KineStop 移出去 |
| 小米 / HyperOS | 很高 | 授权管理里开启自启动，省电策略选「无限制」；部分设置重启后会复位，留意复查 |
| 华为 / 荣耀 EMUI | 很高 | 设置里搜「应用启动管理」，关掉 KineStop 的「自动管理」，手动允许后台运行与自启动 |
| OPPO / vivo 系 | 很高 | 各自的「后台冻结 / 自启动管理」里逐项放行 |

3. 允许它后台运行、不要用「一键清理」划掉它；也别养成随手清空最近任务的习惯 —— 那会把悬浮层连根停掉。
4. 各机型完整步骤，官方推荐直接对照 [dontkillmyapp.com](https://dontkillmyapp.com) 的机型指南操作（这份指南正是 KineStop 同厂开发者维护的）。

做完这组后重开一次点阵，切出去再看是否还在。仍会消失的，进阶做法是关掉系统里针对该应用的「自动优化/智能省电」类开关。

## 三、点阵一直在，但人还是晕

这属于「有效果但不够」或「用法不对」：

1. **提前开，别等晕了再开** —— 它的定位是几分钟起效的预防手段，症状已经上来再开，帮助会打折扣。
2. **看屏幕时才有效** —— 你低头看手机它才有意义；望向窗外、闭眼休息时它帮不上，此时更有效的是看远处地平线。
3. **点阵太淡/太小** —— 换一个对比度更高的主题（见 [设置自动启动与切换主题.md](设置自动启动与切换主题.md)），并把手机举到接近平视的高度，让屏幕与窗外视线冲突变小。
4. **个体差异** —— 晕动症本来就是高度个人化的问题，媒体实测也普遍是「对我有效、不保证人人有效」；医生的口径是这类提示对重度晕车者作用有限。已经晕起来的应对办法单列在 [已经晕车了怎么缓解.md](已经晕车了怎么缓解.md)，多种手段并用（少刷屏、坐前排、开窗通风、必要时遵医嘱用药）比单押一个 App 更现实。
5. **确认点阵方向真的在跟车动** —— 车转弯时观察点阵是否朝转弯反方向漂移；静止状态下点阵不动是正常的，说明传感器数据没异常。

## 四、耗电与发热明显

悬浮层持续绘制会额外耗电，属正常现象，量级不大但长途中可感知：

- 不在车上时手动关掉（再点一次播放键），别让「在车内自动启动」全天候待命；
- 开了自动启动的，参考上一条把没必要的提示音关掉；
- 若异常耗电到不合常理，先按第二节排除后台反复重启导致的循环启动。

## 五、还没装或要换一台设备

从 [KineStop 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ccaccf320b20) 重新获取安装包，装好后按 [下载与安装教程.md](下载与安装教程.md) 把三项权限一次给全，多数「失效」其实是权限没到位。
