## 一、它申请了哪些权限，各干什么用

应用商店里登记的权限用途说明如下（新版本可能有增减，以 App 实际申请为准）：

| 权限 | 官方登记的用途 |
| --- | --- |
| 位置 | 发帖时标记地理位置 |
| 通讯录 | 屏蔽通讯录联系人，避免碰到认识的人 |
| 存储 | 存储想要的照片和视频 |
| 电话 | 账号安全与风控检测 |
| 摄像头 | 拍照发帖 |
| 日历 | 设置日历提醒 |
| 系统设置 | 设置悬浮窗权限 |
| 麦克风 | 发送语音消息 |
| 通知 | 接收与自己相关的消息通知 |
| 读取视觉媒体 | 发布图片视频 |

逐条给判断依据：

- 想收消息提醒 → 允许「通知」；不想让 App 提醒 → 关掉也不影响聊天本身，只是要自己主动进去看；
- 想发图文帖、发语音 → 对应的「存储 / 读取视觉媒体 / 麦克风 / 摄像头」按需给；
- 介意发帖带位置 → 拒绝「位置」，发帖就不带地理标记；
- 「通讯录」这条是反向的隐私功能：它是用来把通讯录里的熟人在平台上屏蔽掉的，不是用来加好友的；
- 其余权限不常用，拒绝后遇到具体功能再补开即可。

## 二、匿名模式下，什么会暴露什么不会

Soul 的互动基于 Avatar 虚拟形象，官方口径是不依赖现实身份或外貌。落到日常使用：

- 别人看到的你的形象、昵称、引力签、瞬间，都是你捏出来、写出来的那套；
- 手机号用于注册与验证，不作为资料展示（以 App 内实际展示为准）；
- 反过来说，「匿名」不是法外之地，平台有实名要求兜底，发布违规内容照样会被处理。

## 三、账号安全的几条习惯

- 验证码不给任何人，包括自称客服的人——官方不会向你索要验证码或密码；
- 异常登录提醒出现时，先改密码再排查；
- 遇到账号问题走官方渠道：App 内的反馈入口，或官方登记的联系邮箱 `soul@soulapp.cn`；
- 搜到的「代解封」「代申诉」服务都不要信，账号问题只有官方渠道能处理。

## 四、青少年模式与未成年人保护

- **开启路径**：在「自己（或「我的」）」页进设置，点「进入青少年模式」（各版本入口叫法略有差异，以 App 内实际显示为准）；
- **平台机制**（官方生态安全报告披露过的口径）：18 周岁以下用户无法注册；被识别出的未成年账号会被强制切入青少年模式；该模式下有每日累计时长与使用时段限制（曾披露过的口径是当日累计不超过 40 分钟，当前数值以 App 内为准）；
- **家长可做的**：发现孩子冒用成年人身份注册，可通过平台举报通道反馈；青少年模式的内容池偏知识与兴趣向。

## 五、注销与长期不用

- 想注销：在 App 的设置里找账号相关选项，具体路径以 App 内实际显示为准；
- 注销不可逆，账号下的虚拟资产、会员状态、社交关系会一并处理，动手前先想清楚；
- 只是暂时不用的话，退出登录就够了，不必注销。
