## 一、这只猫从哪来：2018 年的一张动图

Bongo Cat 的画面元素各有出处，目前公认的脉络是：

- **形象**：Twitter 用户 **StrayRogue**（@StrayRogue）画的那只圆滚滚的小白猫；
- **动起来**：2018 年 5 月，Twitter 用户 **DitzyFlama**（@DitzyFlama）把这张图做成小猫跟着游戏配乐敲邦戈鼓的动图——最早的版本其实只有两帧：落爪、抬爪，配上音乐却意外走红，Bongo Cat 梗就此成立；
- **出圈**：之后被网友二创出各种乐器版本——敲架子鼓、弹钢琴、弹马林巴、吹萨克斯，配什么歌的都有，「一只猫演奏一切」成了固定套路。

你现在在手机上点的这只猫，就是这套梗形象的安卓端落地：点击屏幕，小猫挥爪敲乐器。

## 二、网页版 bongo.cat 的按键对照

这个梗有个公认的网页版 [bongo.cat](https://bongo.cat/)，由 Eric Huber 制作，在电脑浏览器里打开就能玩：按下键盘上不同的键，小猫就敲对应的乐器。网页版的默认按键如下（截至 2026-09 的官网布局，后续可能调整）：

| 键位 | 乐器 |
| --- | --- |
| `A` / `D` | 邦戈鼓（左 / 右） |
| `C` | 镲片 |
| `F` | 牛铃 |
| `B` | 铃鼓 |
| `空格` | 猫叫（Meow） |
| `1` ~ `0` | 钢琴 |
| `Q` ~ `P` | 马林巴 |

如果你在电脑前想试试「原版」，直接开这个网页就行；它不需要安装，也不需要账号。

## 三、网页版、PC 版、安卓版，别搞混

围绕这只猫一共有三类常见的东西，对应「在哪玩」的三种答案：

| 形态 | 用法 | 特点 |
| --- | --- | --- |
| 网页版（bongo.cat） | 电脑浏览器打开即玩 | 按键表见上，零安装 |
| PC 桌面版（Steam 等渠道，2025 年上线） | 装在电脑上，猫蹲在任务栏跟着你的键盘鼠标动作 | 偏直播、挂机场景 |
| 安卓版（bmf.bongo.cat，开发者 BudaCat） | 装在手机上，点屏幕演奏 | 随身携带、触屏直接敲 |

想在手机上随时敲两下的，用的就是第三种——转存这份 **bongocatmver 安装文件资源（夸克网盘）** 即可：[https://pan.quark.cn/s/6db0f53d99f1](https://pan.quark.cn/s/6db0f53d99f1)，安装步骤见 [下载与安装教程.md](下载与安装教程.md)。

PC 桌面版值得多说两句，因为它是这三者里热度最高的：2025 年以免费形式登陆 Steam 后，长期排在 Steam 同时在线人数榜前列（公开统计口径，峰值一度接近 20 万人同时在线）。它会在屏幕角落蹲一只猫，跟着你的按键和点击刨手手，攒够一定操作量还会弹出小宝箱，开出帽子之类的猫猫配饰；也可以把多只猫拉进同一个房间联机，谁在偷懒一目了然。直播圈后来把它玩出了新花样——用别的形象替换猫本体，做成跟着操作动起来的「皮套」。你在视频网站看到的「猫替主播敲键盘」，多半就是这么来的。

三者的玩法是相通的：都是「你出节拍，猫出动作」。玩过网页版再来用安卓版，上手几乎为零，区别只是从敲键盘变成点屏幕，见 [玩法与乐器切换.md](玩法与乐器切换.md)。
