## 一、先弄清同步的是什么

书架上的每本书分两层走：

- **书目条目**（小）：书名、作者、封面、进度、书签、高亮、笔记——登录了的设备都会同步；
- **书文件**（大）：真正的 EPUB / PDF，留在云端，哪台设备打开了才下载到哪台。

所以第二台设备不会在后台把整个书库拉下来；封面上带下载角标的是「云端有、本机还没有文件」的书，点开才会取文件。文件一旦下载就不会被自动清理——手机越来越占空间多半是这个原因，清理办法见第五节。

## 二、官方云同步（默认）

1. 主菜单 → Account 登录账号；
2. 登录后菜单里出现 Sync 开关，Readest Cloud 默认开启；
3. 各平台客户端的安装方式见 [下载与安装教程](下载与安装教程.md)，网页版直接登录即用。

同步内容可以按类别开关（主菜单 → Advanced Settings → Data Sync）：书与书文件、阅读进度、标注、应用设置、字体、背景、词典、OPDS 目录、凭据、阅读统计。**凭据（Credentials）默认是关的**：第一次打开时要你设一个「同步口令」，其他设备输入同一个口令才能读这些加密字段；口令丢了没有找回，只能重新录入。

认书逻辑值得一读：Readest 按文件内嵌元数据认书，不认文件名——重命名、挪位置、换更干净的版本，进度与标注都跟着书走。

## 三、用自己的网盘同步

WebDAV、Google Drive、OneDrive、iCloud Drive、S3 兼容桶都能接，入口在 设置 → Integrations → Cloud Sync。动手前先知道两点：

- **这是付费计划功能**：截至写这篇时需要 Plus / Pro / Lifetime 订阅（以官方页面为准），免费版点这些选项会跳到账户页；
- **网页版连 WebDAV 要求服务器开 CORS**，桌面与手机客户端是直连，不受限。

多个提供商可以同时开（互为镜像）；也可以关掉 Readest Cloud、只用自建存储。各项同步类别的行为差异见上一节。

## 四、和 KOReader 墨水屏设备同步

两条路线，按需求选：

| 路线 | 同步内容 | 做法 |
| --- | --- | --- |
| KOSync（官方服务器） | 只有阅读进度 | 书内 Book Menu → KOReader Sync；服务器默认 `https://sync.koreader.rocks/`，Readest 侧校验方式选 File Content，KOReader 侧 Document matching 选 Binary |
| Readest 插件 | 书、进度、书签、标注全量 | 两端登录同一 Readest 账号；KOReader 装官方仓库发布页的 Readest 插件，Tools → Readest 里推送 / 拉取 |

两个坑提前避开：

- 用 Google / Apple 等社交登录注册的账号，KOReader 插件登录不了（它只认邮箱加密码）——先到 Main Menu → Account 给账号设一个密码；
- KOSync 路线只同步进度，书签与高亮不会跟过去；要全量就走插件路线。

## 五、清理空间

- **只删本机文件**：长按封面（桌面右键）进入 Book Details → 垃圾桶 → Remove from Device Only。云端与标注不动，封面变回下载角标，想再读点一下就拉回来；
- **看云端占了多少**：Account → Manage Storage，按体积排序，挑大文件删；
- **清缓存**（移动端）：Advanced Settings → Manage Cache，清的是临时文件与孤儿文件，不动你已下载的书；
- **两处要小心**：选择模式里的批量删除会连云端一起删（没有「只删本机」的批量版）；Account → Delete All Books 是全端清空，不可撤销，且只作用于 Readest Cloud——WebDAV 等第三方存储里的副本不受影响。

清理完还觉得占用不对劲（比如指望过 Manage Cache 清书），把现象对照 [常见故障排查](常见故障排查.md) 第四节再核一遍。
