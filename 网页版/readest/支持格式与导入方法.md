## 一、能打开哪些格式

| 格式 | 说明 |
| --- | --- |
| EPUB | 官方推荐。标注、目录、排版重排在这类文件上支持最完整 |
| MOBI / AZW / AZW3 | Amazon Kindle 系格式 |
| FB2 | 俄语与东欧地区常用的电子书格式 |
| CBZ / ZIP | 图片打包的漫画格式 |
| PDF | 按页排版的固定版式；文字版 PDF 可以选中、高亮、查词 |
| TXT | 纯文本，套用你设置的排版参数渲染 |
| Markdown | `.md` 文件按可重排文本渲染，保留标题、列表与链接 |

几点提醒：

- 排版、标注这类功能在 EPUB 上体验最完整；PDF 属于固定版式，能做的操作比可重排格式少。
- AZW4、KFX 这类不在表里的格式，或带版权保护的文件，Readest 打不开；怎么处理你手里的文件，以官方文档和你的授权情况为准。
- 同一本书换个更干净的 EPUB 版本重新导入不会丢进度，原因见第三节。

## 二、把书弄进书架的方式

| 方式 | 入口 | 适用场景 |
| --- | --- | --- |
| 文件选择器 | 书架 `+` 按钮，或 `Ctrl+O` / `Cmd+O` | 最常规的单个/多个文件 |
| 拖放 | 把文件拖进 Readest 窗口 | 桌面端批量导入 |
| 系统分享 | 文件管理器或浏览器里「分享给 Readest」 | 手机、平板 |
| 文件关联 | 双击书文件（Readest 设为默认打开方式） | 桌面端 |
| URL 导入 | `+` 菜单 → From Web URL，粘贴 EPUB 的 HTTP(S) 直链 | 有直链的书；粘贴普通文章页地址时会自动把正文剪存成一本 EPUB |
| 内置浏览器 | `+` 菜单 → From Web Browser，存 Calibre-Web、Kavita 等书库服务器地址 | 自建书库服务器，下载的书自动入库 |
| 网页小说转 EPUB | `+` 菜单 → From Web Novel，粘贴章节列表页地址 | 连载小说，勾选章节后合成一本 EPUB |
| Nearby BookDrop | 设置 → Integrations → 打开 Nearby BookDrop | 同一局域网内设备直传，走 LocalSend 协议 |
| OPDS 目录 | `+` 菜单 → Online Library，填目录地址与账号 | 订阅 Standard Ebooks、自建 calibre 服务器等 |

补充几点：

- **整文件夹导入**：`+` 菜单 → From Directory，可按格式与最小体积过滤，还能让子文件夹自动变成书架分组。
- **原位阅读**（Read books in place）：在同一导入对话框里勾上它，Readest 只登记这个文件夹、从原位置读书，不复制副本，省磁盘；代价是从 Readest 里删掉这类书时，原文件会一起被删。
- **网页小说先核对再抓**：Readest 会先解析出章节列表让你确认，确认后才逐章抓取。
- **重复导入会被拦**：Readest 按文件内容与元数据识别同一本书，重复导入直接拒绝，书架上不会出现两本一样的书。
- **邮件投书**：Plus / Pro / Lifetime 订阅用户有一个专属收书邮箱，把书当附件发过去就进书库；收件地址与允许的发件人名单在 设置 → Integrations → Send to Readest 里管理。免费渠道是上面的网页剪存与系统分享。
- **OPDS 目录还能自动追新**：每个目录可开「自动下载新条目」，服务器一上新书就进你的书库；支持 OPDS-PSE 流式阅读的大书边翻页边从服务器取内容，不用先下完整文件。
- **文件关联怎么设**：Windows 右键书文件 → 打开方式 → 选择 Readest 并勾「始终」；macOS 右键 → 显示简介 → 打开方式 → 选 Readest 后点「全部更改」；手机端不设关联，靠系统分享面板里的「用 Readest 打开」。

## 三、换文件不丢进度

Readest 认书认的是文件内嵌的元数据（书名、作者等标识），不是文件名。由此有两个实用结论：

- 重命名文件、在磁盘上挪位置，不影响进度与标注；
- 用更干净的同书 EPUB 替换旧副本，进度、书签、笔记会自动接上。

另外，你改的书名、作者、标签、封面都存在 Readest 自己的书库配置里，原文件永远不会被改动。

## 四、导出与外送

- 选中一本书可以走系统分享（手机端），或用 Nearby BookDrop 直传给同一网络下的另一台设备；
- 高亮与笔记可以导出到 Obsidian，或同步到 Readwise、Hardcover 这类标注库服务，操作见 [阅读功能与标注笔记](阅读功能与标注笔记.md)。
