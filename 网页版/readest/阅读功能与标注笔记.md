## 一、界面与快捷入口

- 点页面正中（手机点按，桌面单击）唤出上下工具栏；
- 底部工具栏的目录图标（或按 `S`）打开侧边栏：目录、书签、笔记、全书搜索都在这里；
- 顶栏的笔记图标（或按 `N`）打开笔记本，列出本书全部摘录与笔记；
- `Ctrl+Shift+P` / `Cmd+Shift+P` 打开命令面板，想不起某个功能在哪时直接搜名字。

翻页与选择的手势（触屏与鼠标通用）：

| 操作 | 效果 |
| --- | --- |
| 点 / 单击页面左、右边缘 | 上一页 / 下一页 |
| 左右滑动（手机） | 翻页 |
| 长按 / 双击文字 | 开始选择并弹出操作条 |
| 双指捏合 | 缩放（PDF 与图片书） |

常用的键盘快捷键（macOS 把 `Ctrl` 换成 `Cmd`）：

| 按键 | 作用 |
| --- | --- |
| `T` | 开关朗读；播放中 `Space` 暂停、`Ctrl+]` / `Ctrl+[` 逐句跳 |
| `Ctrl+F` / `Ctrl+B` | 全书搜索 / 加书签 |
| `Shift+J` / `Shift+A` / `Shift+V` | 滚动模式 / 自动滚动 / 速读模式 |
| `←` `→` / `Alt+←` `Alt+→` | 翻页 / 跳章节 |

完整表在官方文档的 Advanced 页；按键都可在 设置 → Behavior → Keyboard Shortcuts 里改绑，冲突时会明确提示。

## 二、高亮、书签与笔记

- 选中文字后可以高亮、加笔记、复制，也能直接查词或翻译；
- 书签阅读中一键添加，集中收在侧边栏；
- 摘录与笔记可以导出到 Obsidian，或同步到 Readwise、Hardcover 这类标注库服务；
- 标注要跨设备同步时，设置项在同步分类里，见 [多设备同步与备份](多设备同步与备份.md)。

## 三、分屏对照阅读

并行阅读（Parallel Read）把两本书并排打开，支持同步滚动与联动跳转。读外版书对照译文、论文对照参考资料时会常用；两屏各自的进度互不影响。

## 四、朗读（TTS）

- 朗读引擎分三类：设备本机语音、浏览器语音、云端语音；手机客户端走系统 TTS，网页版走浏览器 / 云端语音；
- 安卓、iOS 的桌面小组件可以直接控制播放：长按桌面 → 小组件里加 Readest，朗读时它就是迷你播放器，还能显示最近在读的书；
- 想边听有声书边看文字，可以接 Audiobookshelf 这类有声书服务器做对照播放。

## 五、翻译与查词

- 选中段落调用 DeepL 翻译，不用离开当前页面；
- 词组查询接 Wikipedia / Wiktionary；
- 支持导入自定义词典包，查词时多个词典的先后顺序可以在设置里调。

## 六、排版与主题

- 字体、字号、行距、页边距、段间距都在阅读界面顶栏的视图菜单里调；
- 主题色有浅色 / 深色 / 棕褐护眼几种预设，配色也能自己改；
- 视图菜单里还有全书翻译成你的母语的功能，读外文书可以先整体翻一遍再细读；
- 需要更深度控制样式时，可以写自定义 CSS。

## 七、硬件翻页键与校对规则

**蓝牙翻页器与音量键**：设置 → Behavior → Page Turner 里可以把音量键映射成翻页（手机），也能给「上一页 / 下一页 / 上一节 / 下一节」逐个绑定自定义按键——翻页遥控器和墨水屏实体键都走这里。安卓墨水屏设备还多一个可绑定的「整屏刷新」动作，用来清除电子墨水残影；配合同一设置页里把翻页滑动（Swipe to Paginate）关掉，就是纯按键操作。

**校对规则（Proofread）**：Book Menu → Proofread 里可以建自定义「查找替换」规则，每条规则指定模式（纯文本或正则）、替换内容、范围（选段 / 全书 / 整个书库），以及作用于显示还是只作用于朗读——比如只让 TTS 把缩写读成全称、屏幕上照旧显示缩写。修 OCR 旧书错字、统一引号这类场景都用它；建议先在选段范围试跑，再放大到全书。

**应用锁**：主菜单 → Advanced Settings 里可设 4 位 PIN，每次启动都要解锁；手机上还能开指纹 / 面容解锁（生物解锁失败时回落到 PIN）。PIN 没有找回机制，忘了只能清除应用数据。

哪本书读了一半想换设备接着看，同步方式见 [多设备同步与备份](多设备同步与备份.md)；书还没导入的先看 [支持格式与导入方法](支持格式与导入方法.md)。
