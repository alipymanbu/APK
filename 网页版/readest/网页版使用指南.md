## 一、打开与登录

浏览器访问 [web.readest.com](https://web.readest.com/)，用邮箱或 Google / Apple / GitHub / Discord 账号登录即可，没有安装步骤。网页版要求登录后才能使用——书架、进度、标注都挂在账号上。

官方说明网页版在首次访问后会缓存下来，之后离线也能打开；各浏览器对离线应用的限制不同，以实际表现为准。另外网页版永远跑最新代码，不存在「更新版本」这件事。

## 二、网页版能做什么

阅读引擎与客户端是同一套，读书、标注、笔记、搜索、分屏对照这些主功能都在：

- 书架：网格 / 列表视图、搜索、按作者与系列分组；
- 阅读：高亮、书签、笔记，目录与全书搜索在侧边栏，操作细节见 [阅读功能与标注笔记](阅读功能与标注笔记.md)；
- 朗读：走浏览器或云端语音，音色与手机上用系统语音不同；
- 翻译与查词：选中段落翻译、Wikipedia 词条查询。

**网页版没有的**：Nearby BookDrop（局域网直传）只在桌面与移动端应用里有；安卓 / iOS 的桌面小组件也与网页版无关。

## 三、书从哪来

- 在客户端里导入过的书，登录同一账号后网页书架上直接能看到：先到的是书目条目，文件在你点开时才按需下载——封面上带下载角标的就是还没取文件的书；
- 网页版也能导入本机文件、粘贴 EPUB 直链，或从 OPDS 目录取书。

## 四、和手机、桌面版配合

同一个账号下，进度、书签、标注在网页版与各客户端之间自动同步：网页上读到哪，手机上打开就是哪一页，反向也一样。

手机上想要随手读，装安卓客户端更合适（安装方式见 [下载与安装教程](下载与安装教程.md)，APK 可从上面的 Readest 安装文件资源转存获取）；电脑上则按习惯二选一：偶尔读几页，网页版零维护；重度书库建议装客户端，功能更全（比如局域网直传与更多导入方式）。

## 五、两个网页版特有的注意点

- **WebDAV 同步**：网页版连 WebDAV 服务器时，浏览器会先检查服务器的跨域（CORS）响应头，服务器没开放跨域就连不上；桌面与手机客户端是直连，不受此限。
- **第三方云存储**：把书库镜像到自己的 WebDAV / Google Drive / OneDrive / iCloud / S3 属于付费计划功能，截至写这篇时需要 Plus / Pro / Lifetime（以官方页面为准）；默认的 Readest Cloud 不收费，同步机制见 [多设备同步与备份](多设备同步与备份.md)。
