## 一、各平台的获取渠道

Readest 是免费的开源电子书阅读器，官方渠道覆盖 Windows、macOS、Linux、Android、iOS 与浏览器。按手头设备挑一条：

| 平台 | 渠道 | 说明 |
| --- | --- | --- |
| Android | Google Play，或官方下载页的 APK | Play 商店版可自动更新；APK 版升级要自己装新包 |
| Windows | 官网下载页的 `.exe` 安装包 | 分 x64 与 ARM64 两种 |
| macOS | 官网 `.dmg`，或 Mac App Store | universal 包，Intel 与 Apple Silicon 都能装 |
| Linux | Flathub、AppImage、`.deb` | Flathub 上的应用 ID：`com.bilingify.readest` |
| iOS | App Store | 搜索 Readest 即可 |
| 浏览器 | [web.readest.com](https://web.readest.com/) | 免安装，用法见 [网页版使用指南](网页版使用指南.md) |
| 墨水屏设备 | KOReader 插件 | 借 KOReader 的插件机制接入，见 [多设备同步与备份](多设备同步与备份.md) |

官方入口：官网下载页 [www.readest.com/zh/download](https://www.readest.com/zh/download)；发布包同样挂在 GitHub 仓库 [github.com/readest/readest](https://github.com/readest/readest) 的 Releases 页。

如果你拿到的链接是网盘分享（比如上面的 Readest 安装文件资源），转存后把 APK 拷进手机即可，步骤见下一节。

## 二、安卓手机装 APK

1. 把 APK 保存到手机存储（转存 Readest 安装文件资源后下载，或从官方下载页直取）；
2. 用文件管理器点开 APK；系统第一次会提示「允许从这个来源安装应用」，确认放行；
3. 安装完成后从桌面打开 Readest，第一屏是空书架，导入书就能读。

**核对拿到的是不是官方包**，可以用这两条信息：

- 包名：`com.bilingify.readest`
- 网盘这份 APK 的 MD5：`5916EED4ACB5F51533B0E7160C00CAD6`

在 Windows 上核对 MD5：

```powershell
certutil -hashfile .\readest_v0.9.96.apk MD5
```

桌面安装包还有一层 minisign 签名（Releases 页每个安装包配有同名 `.sig` 文件），从非官方渠道拿到安装包时的校验步骤见 [常见故障排查](常见故障排查.md) 第五节。

**版本差异**：网盘里这份是 **0.9.96**，大小约 32.37M；截至写这篇时官方发布页的版本已到 0.12.10（以官方页面为准）。两个版本的基础阅读功能一致，要不要追新版，取决于你是否需要最近的改动；升级 APK 版直接装新包覆盖即可，书库与阅读进度不受影响。

> 安卓系统的最低版本要求以官方下载页说明为准；装不上时先核对 APK 的 MD5 是否完整。

## 三、桌面版怎么装

- **Windows**：双击 `.exe` 安装包，按向导走完。
- **macOS**：打开 `.dmg`，把 Readest 拖进 Applications；第一次打开若被系统拦截，到「系统设置 → 隐私与安全性」里放行。
- **Linux**：AppImage 加执行权限直接运行；Debian 系可用 `.deb`；或从 Flathub 装 Flatpak 版。Flatpak 下中日韩文字显示成方块是已知问题，修复办法见 [常见故障排查](常见故障排查.md) 第三节。

**想尝鲜新功能**：设置 → Behavior → Update 里可以打开 Nightly Builds 通道，每次检查更新都会给到当天构建的开发版。桌面三平台与安卓有此选项；Linux 只有 AppImage 支持应用内自更新（`.deb` 与 Flatpak 跟随包管理器）；iOS 跟随 App Store，网页版则永远自动是最新版。

## 四、不想安装就用网页版

浏览器打开 [web.readest.com](https://web.readest.com/)，登录账号就能读书，官方说明首次访问后可离线使用。网页版与装出来的客户端共用同一套书库与同步，具体差别写在 [网页版使用指南](网页版使用指南.md)。

## 五、装完第一步

打开应用后书架是空的：点书架上的 `+`（或按 `Ctrl+O` / `Cmd+O`）选文件导入，也可以直接把文件拖进窗口。支持哪些格式、手机上怎么传书，见 [支持格式与导入方法](支持格式与导入方法.md)。
