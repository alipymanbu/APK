## 一、批注：标重点、写意见

审阅别人的文档、看资料划重点，用的是批注工具。在打开的文件里点右上角 **Edit（编辑）**，选 **Annotate（批注）**：

| 工具 | 用途 |
| --- | --- |
| 高亮 | 给重点句子上底色，颜色可选（官方称支持一百多种颜色） |
| 下划线 / 删除线 | 划重点或标记要删的内容 |
| 便签 / 评论 | 在页面边上挂一条意见，不打断正文 |
| 文本框 | 在任意位置加一段说明文字 |
| 画笔 | 直接在页面上圈画、手写 |

批注不会改动原文内容，只叠加在页面上，所以拿不准的时候放心标。

## 二、填写与签名

**填表**分两种，做法不同：

- 交互式表单：点空格直接出光标，正常输入；
- 非交互式表单（一张「纸」）：用文本框工具，把框拖到空格里再输入，详细步骤见[怎么编辑PDF文字.md](怎么编辑PDF文字.md)第三节。

**签名**的常规做法：

1. 翻到需要签字的位置；
2. 用文本框或画笔工具在落款处手写名字；
3. 写完调整大小和位置，保存。

同一份文件经常要签的话，签名保存下来下次直接用，比每次手写省事。

## 三、页面整理：排序、提取、拆分、删除

页面级操作在一个**缩略图视图**里完成（一般从页面浏览模式进入，一屏显示多页小图）：

- **调顺序**：长按某页的缩略图，拖到新位置松手；
- **提取 / 多选**：依次点选需要的页，一次导出成新文件；
- **拆分**：选中一部分页导出，等于把大文件拆成几份小的；
- **删除**：选中不要的页一次删掉；
- **插入空白页**：在指定位置加一页空白，用来补签字页或草稿。

几个实用组合：

- 转 Word 前先把无关页删掉，转换更快、结果更干净（转换见[PDF转换与OCR识别.md](PDF转换与OCR识别.md)）；
- 只发合同里自己负责的那几页：提取需要的页成新文件再分享；
- 老师发的整套卷子，删掉已做的部分，剩下当今天任务清单。

## 四、整理完发出去

处理好的文件通过安卓的**分享**功能发给微信、QQ、邮件等应用，也可以先保存回手机存储再自己传；要纸质版的话，直接走手机打印功能输出。分享出去之前建议自己先翻一遍：批注是否都还在、页序对不对、有没有多页漏页。
