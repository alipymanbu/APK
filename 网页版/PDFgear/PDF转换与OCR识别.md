## 一、手机上能转哪些格式

安卓版 PDFgear 支持把 PDF 转成常见的文档和图片格式：

| 目标格式 | 典型用途 |
| --- | --- |
| Word（.docx） | 接着改内容、交作业、改简历 |
| Excel | 表格类 PDF 的数据再加工 |
| PowerPoint | 幻灯片类 PDF 恢复成可编辑 |
| JPG / PNG | 把页面当图片发出去、插进别的地方 |
| RTF / TXT | 只要纯文字内容 |

具体某个版本里提供了哪些转换方向，以你装的应用内实际列表为准。

## 二、转换步骤（以 PDF 转 Word 为例）

官方文档给出的安卓版路径是这样的：

1. 打开应用，主界面点「+」把要转的 PDF 添加进来，点开这个文件；
2. 点**右上角的三个点**，选 **Convert（转换）**；
3. 选目标格式（比如 Microsoft Word），点 **Convert** 开始；
4. 完成后，转换出来的文件会自动存进主屏幕的 **Files（文件）区**，随时点开查看。

其他格式（Excel、PPT、JPG、PNG、RTF）走同一个入口，区别只在第 3 步选的目标格式。转换是本地处理的，文件不用上传到哪台服务器；但个别功能或 AI 相关能力会要求联网，遇到「无网络」提示时检查一下手机网络再试。

找不到转换出来的文件，先回主界面看 **Files 区**，不用去手机文件管理器里翻。

## 三、扫描件与 OCR：把图片型 PDF 变成能改的文档

扫描件、拍照件直接转换出来往往还是一张张图片。OCR（文字识别）做的事是把图里的字认出来，变成真正可编辑的文字：

1. 把扫描版 PDF 放进应用；
2. 选带 **OCR** 的转换方向（比如转成 Word 或 TXT）；
3. 等识别完成，输出文件里的字就可以正常选中、修改了。

OCR 适合的场景：

- 别人只给你发了**扫描版合同 / 盖章文件**，你要在里面改字或抄数据；
- 老教材、试卷的照片版 PDF，想复制题目文字；
- 长按选不中文字的任何 PDF（判断方法见[怎么编辑PDF文字.md](怎么编辑PDF文字.md)第一节）。

识别准确度取决于原文件的清晰度：拍得歪、光线差、字太小的页面，识别错误会明显变多，转换后**务必通读一遍**再拿去用。

## 四、转换前后的注意点

- **排版会走样**：转 Word 后行距、字体、分页和原 PDF 不会一模一样，交正式文件前先核对格式；
- **图片格式是逐页的**：转 JPG/PNG 通常一页出一张图，页数多时注意批量保存的位置；
- **改完还能转回去**：改好的 Word 可以用应用内的「转 PDF」方向再生成 PDF，方便发送最终版（Word 转 PDF 的具体步骤见[怎么新建PDF文件.md](怎么新建PDF文件.md)第二节）；
- **大文件慢**：几百页的文档在手机上转换要等一阵，赶时间就先只转需要的页（页面的拆分方法见[批注签名与页面整理.md](批注签名与页面整理.md)）。
