## 一、安装前先核对这些信息

Felo AI 是一个带引用来源的 AI 搜索应用，同一个产品还有网页版，浏览器打开 `https://felo.ai` 就能用。本篇针对的是安卓安装包这份文件，动手装之前先核对：

| 项目 | 信息 |
| --- | --- |
| 应用名称 | Felo AI（安卓应用名 Felo Search） |
| 安装包版本 | V2.1.4 |
| 安装包大小 | 45.01 MB |
| 包名 | ai.felo.search |
| MD5 | 4C61BDE2AA6D852607155E55DF5E94C0 |
| 系统要求 | 安卓 5.2 以上 |

版本号以这份安装包为准。Felo 的 App 更新比较频繁，官方渠道的最新版本号以官网显示为准；如果你在意某个新功能是否可用，先去官网确认再决定。

## 二、从夸克网盘拿到安装包

1. 打开 [Felo AI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1e046aac322a)；
2. 选择「转存」把文件存到自己的网盘，之后随时能取；
3. 在夸克网盘 App 或网页版里找到这个 APK 文件，点下载；
4. 下载完成后，在文件管理器里能看到一个以 `felo ai` 开头、`.apk` 结尾的文件。

下载后想校验文件是否完整，可以用文件管理器或电脑上的工具算一下 MD5，应与第一节表格里的值一致；不一致说明下载不完整，重新下载即可。

## 三、安装步骤

1. 在文件管理器里点这个 APK 文件；
2. 系统提示「不允许安装未知来源应用」时，按提示允许你的文件管理器（或浏览器）安装应用。不同品牌手机的入口在「设置 → 应用 → 特殊应用权限 → 安装未知应用」附近，叫法略有差异；
3. 回到文件管理器再点一次 APK，点「安装」；
4. 装完点「打开」，或从桌面图标进入。

## 四、第一次打开

- 首次启动会询问语言与通知权限，按自己的习惯选即可，语言之后能在设置里改；
- 不登录也能直接搜索；要保存搜索记录、在手机和网页版之间同步，才需要登录账号。登录方式的注意事项见 [常见问题与故障排查.md](常见问题与故障排查.md) 第二节；
- 免费范围与积分规则，见 [免费使用与积分说明.md](免费使用与积分说明.md)。

## 五、装不上时的常见原因

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包出错」 | 下载不完整，MD5 对不上 | 重新从网盘下载一遍 |
| 点安装后闪回桌面 | 安装器被系统拦截 | 检查第三节第 2 步的未知来源权限 |
| 提示存储空间不足 | 剩余空间小于安装包体积 | 清出至少 200 MB 再装 |
| 提示系统版本过低 | 安卓版本低于要求 | 换系统符合要求的设备 |

装好之后遇到搜索、登录方面的问题，直接看 [常见问题与故障排查.md](常见问题与故障排查.md)。
