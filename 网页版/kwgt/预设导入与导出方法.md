# KWGT 预设导入与导出方法

> KWGT 的每个小组件内容都存成一个预设文件（.kwgt）——换机、备份、从别人那里拿成品、装预设包，全都围绕这个文件。本篇讲它存在哪、怎么进手机、怎么导出，以及最容易踩的「文件变 0 字节」坑。

## 一、预设文件放在哪

KWGT 在手机内部存储里建一个 `Kustom` 文件夹，小组件预设都放在其中的 `widgets` 子目录里。同一家族的应用各管各的目录，别放混：

| 应用 | 预设目录 |
| --- | --- |
| KWGT | `Kustom/widgets` |
| KLWP（动态壁纸） | `Kustom/wallpapers` |
| KLCK（锁屏） | `Kustom/lockscreens` |

把 `.kwgt` 文件放进 `Kustom/widgets`，它就会出现在编辑器的预设列表里；删掉文件，列表里就没了。

## 二、把预设装进手机的两种方式（二选一）

**方式一：文件管理器直接拷**

1. 用文件管理器把 `.kwgt` 文件复制到 `Kustom/widgets`；
2. 打开 KWGT 编辑器，在预设列表里找到它，选中、保存。

**方式二：编辑器内导入**

1. 打开 KWGT 编辑器，点「导入」；
2. 从**Kustom 文件夹之外**的任意位置（比如 Download 目录）选中文件；
3. 导入完成后，预设同样出现在列表里。

两种方式做的是同一件事，选一种即可。

## 三、0 字节损坏是怎么来的

最经典的翻车：文件已经拷进了 `Kustom/widgets`，你又对它执行了一次「导入」——等于让程序把文件复制到它自己身上，结果原文件被一个 0 字节的空文件覆盖，列表里显示损坏（Corrupted）、打开是空容器。这是官方论坛版主解释过的固定行为，不是你操作姿势不对，是重复导入这个动作本身就不成立。

预防只有一条：**文件已经在 `Kustom/widgets` 里，就别再点导入**。从网盘或聊天工具下载时，先把文件落到 Download 之类的普通目录，再走方式一或方式二。

## 四、后缀不对的几种情况

| 你拿到的文件 | 怎么处理 |
| --- | --- |
| `xxx.kwgt` | 直接用 |
| `xxx.kwgt.zip` 或 `xxx.zip` | 先去掉 `.zip` 后缀改名试试；仍被当成损坏文件的话，它可能真的是压缩包，解压取出里面的 `.kwgt` |
| 其他后缀 | 大概率不是预设文件，别硬导 |

## 五、导出与换机

编辑器里可以对当前预设执行导出，生成 `.kwgt` 文件。换机迁移的完整动作：

1. 导出你的预设，或者直接把整个 `Kustom/widgets` 文件夹打包备份（更稳妥）；
2. 传到新手机；
3. 按第二节的方式装回 `Kustom/widgets`；
4. 在新手机桌面上放一个 KWGT 空块，选中对应预设、保存。

预设里用到的图片、字体如果放在 Kustom 文件夹之外的自定义路径，换机后要一并搬过去，否则预设会缺素材。

顺带一提：应用里的「恢复预设」（Recover preset）功能是 Pro 解锁项之一，免费版的兜底手段就是文件备份——所以把整个 `Kustom/widgets` 文件夹打包的习惯更值得养成。

## 六、预设从哪找

- 商店里搜「KWGT」：大量预设包应用，装好后它们的预设直接出现在编辑器列表里；
- Reddit 的 r/kustom 版块：社区成品分享，常直接给 `.kwgt` 文件；
- 中文社区（如酷安）：预设与教程都有，下载后按第二节导入。

预设装好了套不上（点了没反应、显示损坏），先按第三、四节核对文件本身；文件没问题但小组件不刷新，去[小组件不显示或不更新怎么排查.md](小组件不显示或不更新怎么排查.md)。还没装 KWGT 的，从[下载与安装教程.md](下载与安装教程.md)开始。
