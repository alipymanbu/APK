# KWGT 桌面小组件怎么添加

> KWGT 装好后桌面上不会自动出现任何东西——它的全部产出都要走「先在桌面放一个空小组件、再往这块区域里装内容」这条流程。本篇讲这条流程的每一步，以及第一次创建内容的两种走法：套现成预设、从零做一个最简单的。

## 一、先弄清它的显示方式

KWGT 不是打开来看的主题应用，它显示出来的东西全部以「小组件」的形式长在你的桌面上，而小组件是由桌面（启动器）负责摆放和渲染的：

1. 在桌面空白处长按，唤出桌面的「小组件 / 添加插件」列表；
2. 找到 KWGT，你会看到一排不同尺寸的空小组件（1x1、2x2、4x2、4x4 等）；
3. 挑一个拖到桌面——第一次建议选大一点的（如 4x4），空间多好操作，之后可以缩小；
4. 放好后是一块空白区域，**点这块空白区域**才会打开 KWGT 编辑器。

桌面上可以放多个 KWGT 小组件，各自装不同的内容，互不影响。

## 二、第一次：套现成预设（最快见效）

1. 点桌面的空白块进入编辑器；
2. 在预设列表（Library）里选一个已装好的预设；
3. 预览没问题就点右上角的保存（软盘图标）；
4. 回到桌面，空白块已经变成预设的样子。

预设从哪来：装预设包应用，或拿到单个 .kwgt 文件导入，两条路都写在[预设导入与导出方法.md](预设导入与导出方法.md)。很多预设是按某个尺寸设计的，放进尺寸不同的空块会被压缩或裁切——长按小组件用桌面提供的「调整大小」改一改即可。

## 三、从零做一个最简单的：点击打开应用

想自己动手的话，用这个 5 分钟的小例子摸清编辑器的路数：

1. 点空白块进入编辑器，点「创建」新建一个预设；
2. 点右上角「+」，选「图像」，从相册挑一张图放进去；
3. 切到「触摸」选项卡，点「+」添加一个触摸动作，选「启动应用」，再选一个具体应用；
4. 点保存，回到桌面。

现在点这块小组件就会打开你选的那个应用。照这个路数把常用应用都排一遍，就做出了一套自己的快捷启动区。图像能放，文本、形状、进度条这些元素也一样加；让内容随电量、时间、天气变化的进阶写法要靠公式与全局变量，入门见[编辑器公式与全局变量入门.md](编辑器公式与全局变量入门.md)。

## 四、你的桌面要支持什么

- **添加与调整大小**：系统自带桌面基本都支持；小组件尺寸细调（半格步进）这类能力常见于 Nova 这类第三方桌面；
- **别让桌面杀小组件**：个别桌面更新后出现过小组件不再刷新的情况，官方论坛的验证办法就是换一个桌面再装一遍，详见[小组件不显示或不更新怎么排查.md](小组件不显示或不更新怎么排查.md)。

## 五、保存了但桌面没变化

按顺序核对：

1. 编辑器里点的是**保存**，不是直接退出；
2. 桌面上点的确实是 KWGT 的空块，而不是别的应用的小组件；
3. 空块尺寸和预设的设计尺寸差太远会显得不对劲，长按小组件调整大小；
4. 还是不行，走[小组件不显示或不更新怎么排查.md](小组件不显示或不更新怎么排查.md)的排查清单。

还没安装 KWGT 的话，先看[下载与安装教程.md](下载与安装教程.md)；想弄明白它都能做什么，见[是什么软件.md](是什么软件.md)。
