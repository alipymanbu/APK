# KWGT 是什么软件

> KWGT（全称 KWGT Kustom Widget Maker）是安卓上的小组件制作工具：你可以把时钟、天气、电池、音乐控制、日历这类信息做成自己想要的桌面小组件，也可以直接套用别人做好的成品。本篇讲它的定位、免费版与 Pro 的差别、以及同一家族的其他应用。

## 一、它解决什么问题

安卓桌面上的小组件（widget）平时由各个应用自己提供，长什么样、显示什么、占多大，都是应用写死的，你只能选择放或不放。KWGT 走的是另一条路：你在桌面上放一个空的 KWGT 小组件，这块区域里放什么内容、什么布局、点了做什么，全部由你自己拼出来；不想动手的话，也可以直接载入别人做好的成品（预设）。

它不替代你的桌面（启动器），也不改系统主题——装完之后桌面不会有任何变化，你放了多少个 KWGT 小组件，桌面上就有多少块自定义区域。

## 二、你能用它做什么

| 常见用途 | 桌面上会得到什么 |
| --- | --- |
| 时钟与日期 | 自己排版的时钟，字号、字体、时区、格式随你定 |
| 天气卡片 | 温度、天气状况、未来几小时预报，样式自己拼 |
| 音乐控制 | 显示正在播放的歌曲、封面，带上一首/暂停/下一首按钮 |
| 电池与系统信息 | 电量百分比、内存、存储等系统数据 |
| 日历与待办 | 下一个日程、当月日期 |
| 快捷启动 | 一张图片或一个按钮，点击打开指定应用或快捷方式 |

编辑器本身是一套图层式设计工具：文本（自定义字体、渐变、阴影）、形状、图片、图标、进度条、可复用的组件模块都能往上摆，支持 SVG 矢量图，每个对象都可以绑触摸动作；条件判断和全局变量让同一块卡片按状态变样式，进阶写法见[编辑器公式与全局变量入门.md](编辑器公式与全局变量入门.md)。

其中天气这类数据依赖对应的系统权限（比如位置），第一次用到时按提示授予即可；音乐控制依赖系统播放信息，个别系统还要求授予通知使用权。

## 三、免费版和 Pro 的差别

| 版本 | 情况 |
| --- | --- |
| 免费版 | 商店免费安装，带广告，部分功能受限 |
| Pro | 单独一个 Pro Key 应用，一次性买断，解锁全部功能并去掉广告 |

两个应用是分开的：免费版装的是主程序，Pro 是一把「钥匙」。官方对 Pro 解锁内容的说明是这几条：

- 去掉广告；
- 解锁从存储卡导入外部预设包与皮肤——社区预设包大多吃这一条，很多第三方预设需要 Pro 才能载入；
- 恢复预设（Recover preset，配置出问题时把上一次的状态找回来）；
- Buzz Launcher 导入。

不少社区预设用到了 Pro 才有的功能，套用别人的成品前先看一眼预设说明里有没有注明需要 Pro。

## 四、同一家族的其他应用

同一开发商（Kustom Industries）还有几个姊妹应用，编辑器操作逻辑接近，学会一个就能触类旁通：

| 应用 | 做什么 |
| --- | --- |
| KLWP | 动态壁纸制作 |
| KLCK | 锁屏制作 |
| KWCH | 手表表盘制作 |

另有未读数插件、天气插件等配套插件，用来补充小组件里的数据源。

## 五、预设与求助去哪找

- 官方文档站：`https://docs.kustom.rocks`，含下载页与常见用法示例；
- 官方论坛：`https://forum.kustom.rocks`，排查问题先翻这里，开发者会直接回复；
- Reddit 的 r/kustom 版块：大量成品展示与分享；
- 商店里搜「KWGT」能找到大量预设包应用，免费与收费都有；
- 中文社区（如酷安）也有不少预设分享与中文教程。
