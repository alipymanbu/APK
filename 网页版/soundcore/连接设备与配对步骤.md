# soundcore 连接设备与配对步骤

> soundcore 应用连设备的固定顺序是：设备先和手机蓝牙配对，再进应用里「添加设备」。本篇按官方支持文档把这个顺序、失败时的手动添加路径和常见的双设备冲突讲清楚。

## 一、配对前先确认三件事

1. **设备已经和手机蓝牙配对**。官方流程是「先蓝牙、后应用」：先把耳机/音箱与手机在系统蓝牙里连上，再打开 soundcore 应用。官方 FAQ 的原话口径是「建议先把设备与手机配对，再连接应用」。
2. **手机没在跟别的蓝牙设备忙**。官方排查步骤里有一条：检查手机是否还连着其他蓝牙设备，有就先断开，再让应用连。
3. **应用是装在手机上的**。soundcore 应用不支持电脑（官方多篇指引明确写过），只提供 iOS 与 Android 版本。

首次进入应用时必须同意**位置权限**，否则扫不到设备；这个权限为什么要给、怎么在系统设置里改，见 [位置权限与账号说明.md](位置权限与账号说明.md)。

## 二、标准添加流程

官方各机型的指引都走同一条路，差别只在菜单层级：

1. 打开 soundcore 应用；
2. 点左侧页面的 **Add Device（添加设备）**，应用会自动扫描附近处于连接状态的设备；
3. 按屏幕提示确认连接，设备出现在「我的设备」里就算完成；
4. 自动识别失败时，点 **Set Up Manually（手动设置）**，按 系列名 → 具体型号 逐级选择，手动把它加进来。

手动添加时如果**列表里找不到你的型号**，官方的处理方式是：把这个页面截图，连同手机型号、应用版本一起发给客服（见 [固件更新与常见问题排查.md](固件更新与常见问题排查.md) 的联系入口）。

## 三、自动连不上的官方排查顺序

官方支持文档里针对「应用找不到设备 / 连不上」给了一套固定动作，按顺序做：

| 顺序 | 动作 | 说明 |
| --- | --- | --- |
| 1 | 升级应用到最新版 | 已装过的官方建议**卸载后重装**，而不是覆盖安装 |
| 2 | 先在系统蓝牙里配对 | 应用不负责第一次的蓝牙配对，这一步在系统设置里完成 |
| 3 | 同意位置权限 | 首次进入应用必同意 |
| 4 | 断开手机上其他蓝牙连接 | 减少扫描干扰 |
| 5 | 手动添加 | Set Up Manually → 系列名 → 型号 |
| 6 | 切换系统区域/语言 | 英文官方文档建议切到 English (United States)；国行用户按官方客服口径保持系统与网络为大陆地区 |
| 7 | 卸载重装并重新登录 | 仍不行再走这一步 |

其中第 6 条是官方明确写出来的技巧：系统区域设置会影响设备列表能否显示出来。

另有两个官方点名的场景：**iPhone 正在通话时**应用可能连不上设备，先结束通话再打开应用重试；蓝牙里显示已连接、应用里却不出现设备时，走首页 **添加设备 → 选设备类型图标 → 从列表里选型号** 的路径手动认领一次（官方 Space 2 指南口径）。

## 四、第一次连上了、后来连不上

这种「隔天就失联」的情况，官方给的第一个检查点不是重置设备，而是**双连接（Dual Connections）状态**：

- 如果设备的 App 连接被手机 A 占着，手机 B 上的应用就连不上；
- 处理：把手机 A 上后台运行的 soundcore 应用彻底关掉，再用手机 B 连。

如果手机只有一台，官方的后续动作是重启设备，或换一台设备试，用来区分是设备问题还是手机问题。

设备端的重置（长按充电盒按钮、组合键之类）各机型不一样，官方有单独的重置指引，必要时按你的具体型号去官方支持页查；应用侧能做的排查就是上面这些。
