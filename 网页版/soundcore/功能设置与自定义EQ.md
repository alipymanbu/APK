## 一、先看你的机型有哪些功能

同一份应用里，不同设备显示的功能页不一样，判据是机型（见 [支持设备与机型清单.md](支持设备与机型清单.md)）。官方用户指南里给出的功能入口按设备类型分成两组：音箱侧集中在「产品信息 / 固件更新 / 电量 / 音量 / EQ / 灯效 / 自动关机」，耳机侧多出降噪、触控自定义、佩戴测试、查找耳机这些页。下面各节只讲「官方指南里写明有这个入口的机型」，你的设备上找不到某个入口，多半就是该机型不带这个功能。

## 二、EQ 与音效

音箱类机型的预设 EQ（不同机型预设数量略有差异，官方音箱指南里出现过这些）：

| 预设 | 效果 |
| --- | --- |
| soundcore Signature | 标准均衡调音 |
| Voice | 人声更突出 |
| Balance | 高频低频均不做增强 |
| Treble Boost | 增强高频 |
| BassUp | 实时增强低频 |

自定义 EQ 的路径（官方 Motion X600 页的 FAQ 口径）：应用内 **Equalizer → Custom → Full-Band**，点任意频点展开对应频段，长按拖动调整。改完的曲线就是该设备在该应用里记录的调音，不登录账号时这份配置不会随账号保存（官方对账号的口径见 [下载与安装教程.md](下载与安装教程.md)）。

官方 Space 2 的 FAQ 里有一条容易被忽略的口径：**应用里的 EQ 与音效设置只作用于媒体播放**（音乐、视频、播客），不会改变通话音质——通话音质差去调 EQ 是没用的，官方给的排查方向是通话降噪与网络，不是 EQ。

耳机类机型的进阶项按官方指南还有：HearID 听感测试（按你的听感生成专属曲线，P31i/R60i NC 等机型）、BassUp 开关（Life P3 等机型）、游戏模式（Life P3 等机型，降低玩手游时的音画延迟）。

## 三、降噪与环境音（耳机类）

官方 P31i/R60i NC 指南给出的三档：**降噪 / 普通 / 透明**，透明模式用于听音乐的同时听到周围人声。部分机型把降噪做成分场景调优，Life P3 的口径是交通 / 户外 / 室内三档，各自针对不同环境噪声。这些都是应用内切换，耳机按键只能做档位循环时才需要在应用里改映射。

## 四、实用小功能

| 功能 | 入口/用法 | 哪些设备有 |
| --- | --- | --- |
| 查找耳机（Find My Headset） | 应用内开启后，丢失的耳机会发出较大声音 | Life P3 等部分耳机 |
| 佩戴测试 | 应用内运行，检查耳塞佩戴密封程度 | Life P3 等入耳式 |
| 双设备连接 | 设置 → 双连接（Dual Connection）开启，再连第二台手机 | AeroFit Pro、P31i 等部分机型 |
| 触控/按键自定义 | 在设备页里改「上一曲/音量/语音助手」等映射 | 默认按键不够用的机型（如 V30i 音量调节只能在应用里设置） |
| 自动关机时间 | 设备页里设定时长，到时设备自动关机 | 音箱类（Glow 等与耳机类部分机型） |
| 灯光效果 | 带灯音箱在应用里选音乐同步模式之外的静态灯效 | Glow、Flare、Rave 系列 |
| 音量与电量 | 应用内直接调音量、看电量，不用按设备按键 | 音箱类（Glow 等指南明确） |
| 语音提示开关 | 关掉/恢复开关机提示音 | 音箱类（Glow 等指南明确） |
| 助眠/冥想内容 | 应用内的助眠与冥想板块 | Sleep A10 等对应机型 |

## 五、LDAC 与音质优先（仅限安卓）

支持 LDAC 的机型（Motion X500/X600、AeroFit Pro 等官方指南明确）在应用内切换高音质模式：

1. 打开应用，进首页右上角**设置**；
2. 选**声音模式（Sound mode）**；
3. 选**音质优先（Audio quality priority）**，即切到 LDAC 编码。

官方指南同时写明三条限制：需要 **Android 8.0 以上**、iOS 设备不支持；切换要花约 10 秒，旧固件可能提示先更新；LDAC 更耗电，连接稳定性在干扰少的环境下更好。
