## 一、固件更新怎么触发

官方机制是**连上应用后自动检测**：设备连接到应用时，一旦检测到新固件版本就会收到通知，不需要你去别处下载。入口在设备页右上角的「…」菜单里（官方 Motion Boom Plus 指南口径）。基本步骤：

1. 把设备连上 soundcore 应用；
2. 按提示进入固件更新，确认开始；
3. 更新期间不动手机，等设备自己完成；
4. 更新成功后设备会自动重启。

有些功能（比如 LDAC 切换）遇到旧固件时，应用会反过来提示你先更新固件再继续。

## 二、更新期间的注意事项

官方各机型指南对「更新中」的要求是一致的，列出来都是几条别去碰的规矩：

- 耳机类：耳机**放回充电盒**，充电盒**保持打开**直到更新完成，全程保持充电状态；
- 音箱类：保持设备通电，别在更新中按设备按键；
- 更新期间**不要操作手机**（官方 Motion X600 指南口径，除非你把应用设成后台运行）；
- 更新中断可能导致设备异常，宁可等几分钟也不要中途杀应用。

## 三、常见问题排查表

| 现象 | 按顺序做 |
| --- | --- |
| 应用扫不到设备 | 升级或卸载重装应用 → 系统蓝牙先配对 → 同意位置权限 → 断开其他蓝牙设备 → 手动添加（完整清单见 [连接设备与配对步骤.md](连接设备与配对步骤.md)） |
| 手动添加里没有我的型号 | 截图「手动设置」页面，连同手机型号、应用版本联系客服；若是较新的机型，先确认应用是商店最新版 |
| 第一次连上，之后连不上 | 检查双连接：另一台手机的 soundcore 应用在后台占着设备，关掉它再连；再不行重启设备或换设备试 |
| 注册账号的激活码过期 | 官方口径：卸载应用后重装再试 |
| 固件更新卡住/失败 | 确认设备电量充足、在充电状态 → 保持连接不杀应用重试一次 → 仍失败就联系客服并说明机型与现象 |
| 想确认设置有没有保存 | 未登录账号时设备配置不随账号保存（官方口径），需要换机保留配置就先在应用内登录 |

## 四、联系官方客服的入口

上面这些都试过仍不行，官方给的联系路径有两条：应用内**帮助页**发起，或发邮件到 `service@soundcore.com`（官方支持文档口径，承诺 24 小时内回复）。发之前把三样东西备好，官方 FAQ 里明确要求提供：手机型号、应用版本、以及问题页面的截图（比如手动添加列表）。机型能不能连、清单对不对，先对照 [支持设备与机型清单.md](支持设备与机型清单.md) 再问，能省一轮往返。
