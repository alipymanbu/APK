## 一、本篇讲什么

同样一个创意，有人一次出片、有人连烧五次灵感值 —— 差别几乎都在提示词上。本篇列的是实际最高频的几类错误，每条按「错例 → 为什么会废 → 怎么改」写，你可以对照自己最近的废片逐条排查。基本写法见 [文生视频与图生视频教程.md](文生视频与图生视频教程.md) 第五节，本篇不重复那套骨架。

## 二、一条片里塞了两个镜头运动

**错例**：「镜头缓慢推进，然后向右摇」

一条 5 秒片段里，模型对多个运镜指令的处理是二选一或硬糅合，出来的效果常常是推到一半突然歪掉。**一条片只写一个运镜**，要两个动作就生成两条再剪到一起，或者用多镜头模式给每个镜头各配一个（见 [首尾帧与运镜控制怎么用.md](首尾帧与运镜控制怎么用.md)）。

## 三、动作动词太虚，模型只能瞎猜

**错例**：「一个女生在厨房做早餐」

「做早餐」是十分钟的过程，5 秒里模型只能随机截一段。把动作改成**具体、可数的步骤**：

```
她把鸡蛋磕进碗里，搅拌，倒进平底锅，抬头看向镜头
```

更进一步可以按秒给节拍（0-2 秒做什么、2-5 秒做什么），时长与台词量的对应关系大致是：5 秒片段 8~12 个词、10 秒 15~20 个词，塞多了结尾会被截断或发音含糊。

## 四、人物细节堆太多，互相打架

**错例**：「27 岁女性、栗色头发、浅棕眼睛、雀斑、藏青亚麻衬衫卷袖、细金项链、低马尾、耳钉……」

八个细节同时要求渲染，模型会顾此失彼，反而每张脸都有点怪。**留两个标志性细节**（比如「藏青亚麻衬衫、低马尾」），其余让模型补。需要人物**精确一致**时，别靠文字堆细节 —— 用图生视频传参考图，或者用元素参考把人物「锁」住（最多可传多张多角度图或一小段角色视频）。

## 五、想让画面里出现文字、Logo、包装字

**这是模型能力的硬限制**：生成画面里的文字、品牌标识、包装上的字，出来大概率是扭曲的乱码，重生成多少次都一样，纯烧灵感值。

对策：

- 提示词里**主动排除**：负向提示写「不要文字、不要标识」；
- 需要品牌 Logo、字幕、包装字 → **后期加上**，别指望生成时一步到位；
- 只是片尾字幕的话，用剪辑工具叠字比生成靠谱得多。

## 六、运镜有「稳」和「险」之分

实测反馈一致的规律：**慢而小的动作稳，快而大的动作容易出 artifacts**。

| 更稳（优先用） | 更容易翻车 |
| --- | --- |
| 固定机位 | 快速变焦 |
| 缓慢推进 5%~10% | 甩镜 |
| 缓慢拉远 5%~10% | 大角度旋转 |
| 小幅平摇 10°~15° | 剧烈手持晃动 |
| 轻微视差平移 | 主体贴脸快速移动 |

画面已经「很假、边缘发虚」时，先把运镜降到表左列，再考虑换模型或升档质量模式。

## 七、人物越生成越不像：漂移

连着生成同一个人，第二条开始换了一张脸、发色变了、背景家具变形 —— 这是漂移。成因是模型对上一帧的细微误差会逐帧累积，片段越长越明显。修法按成本从低到高：

1. **负向词兜底**：写上「不要变形、不要多余手指、不要闪烁」这类护栏词；
2. **用参考图代替文字描述**：同一张参考图喂给每一次生成，人物自然一致；
3. **续写时保持同模型同模式**：换模型续写会导致光线、质感突变（见 [首尾帧与运镜控制怎么用.md](首尾帧与运镜控制怎么用.md) 第四节）；
4. **缩短单段时长**：5 秒内的片段漂移概率远低于 10 秒以上。

## 八、图生视频里写了与原图矛盾的话

**错例**：图是大头近景，提示词却写「远景、全身」；图是正午亮光，提示词却写「黄昏暖光」。

图生视频的分工是**图管「长什么样」、文字只管「怎么动」**。文字跟图打架时，模型要么不听、要么把画面改得四不像。先如实描述图里已有的构图与光线，再在后面接动作。

## 九、排查顺序

废片先按这个顺序过一遍，多数能定位：

1. 是不是一条片写了两个运镜（第二节）？
2. 动作是不是太虚（第三节）？
3. 是不是想在画面里出字（第五节）？
4. 是不是运镜太猛（第六节）？
5. 是不是人物一致性问题（第七节）？

按顺序改一处、生成一次，别一次全改 —— 全改了好了你也不知道是哪条起的作用，下次还是乱试。改完仍不理想、且怀疑是网络或余额问题，转 [常见问题与解决办法.md](常见问题与解决办法.md)。
