## 一、本篇讲什么

按「你看到的现象」组织，从上往下对号入座即可。多数问题先做三件事就能解决大半：**换稳定网络、清出 1GB 以上可用存储、把 App 升到最新版后重启**。下面每条都在这个基础上展开。

## 二、点了生成，一直转圈或失败

1. **看网络**：生成是云端渲染，手机网络抖一下任务就断。切到稳定的 Wi-Fi 或 5G 再试；
2. **看存储**：手机本地可用空间不足 1GB 时容易渲染中断，先清理相册与缓存；
3. **看版本**：旧版本可能与服务端不兼容，升级后重启再生成；
4. **看余额**：灵感值不足也会表现为生成失败，去「我的」→「灵感值明细」核对，规则见 [灵感值与会员价格说明.md](灵感值与会员价格说明.md)；
5. **看内容**：提示词或参考图触发内容审核时任务会被拦下，改写描述、换张图即可。

确认不是网络和余额问题后，**隔一段时间再生成**——高峰时段排队严重属正常现象，同一时段反复重试只会白扣额度（未成功的任务通常不扣，但以官方实际规则为准）。

## 三、生成结果不对：画面乱、镜头跳、不像描述的

这属于效果问题而非故障，按顺序试：

- **提示词太杂**：一个画面只保留一个核心动作，删掉多余的特效描述；
- **两张图差异大导致跳镜头**：用了首尾帧就要保证首尾两图同主体同场景，详见 [首尾帧与运镜控制怎么用.md](首尾帧与运镜控制怎么用.md)；
- **先图后代**：先用图片（扣得少）把创意验证对，再生成视频；
- **换模型**：新旧模型对同一条提示词的表现差很多，同一提示词换个模型试试。

## 四、灵感值莫名变少 / 突然不能生成

九成是**过期清零**。打开灵感值明细，重点看两类短命额度：邀请好友与精选任务奖励（约 31 天有效）、每月赠送额度（约 30 天有效）。系统按「剩余有效期短的先扣」自动消耗，明细里灰色条目即已过期。完整规则与规避办法见 [灵感值与会员价格说明.md](灵感值与会员价格说明.md)。

**会员停订后余额骤减**也是同理：会员附赠的灵感值与会员状态绑定，续费一断立刻失效。

## 五、会员开成功了但权益没到

1. 支付后等 1~3 分钟，下拉刷新会员中心；
2. 退出账号重新登录，触发一次权益同步；
3. iOS 内购确认扣款成功后才发货，先在苹果订阅页确认订阅状态；
4. 仍未到账 → 带订单号 / 交易单号联系官方客服核实。

## 六、视频保存下来有水印

普通账号生成的作品可能带官方水印，无水印导出通常是会员权益之一。先确认自己是否在会员期内（见 [灵感值与会员价格说明.md](灵感值与会员价格说明.md)）；确实在期内仍带水印，按第五节联系客服。

## 七、App 装不上 / 打不开 / 闪退

| 现象 | 处理 |
| --- | --- |
| 点安装提示「未知来源」 | 按 [下载与安装教程.md](下载与安装教程.md) 第三节给当前来源开一次允许，装完关掉 |
| 安装包解析失败 | 文件可能没下完，重新下载一份；想要一份干净的安装文件可从 [可灵AI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/207edd5cb27f) 重新取 |
| 打开即闪退 | 清理手机可用空间到 1GB 以上，重启手机再开 |
| 提示包名冲突 / 装了两个 | 先卸载来源不明的同名应用再装，正版包名为 `com.kwai.kling` |
| 更新后打不开 | 卸载重装（作品在云端账号里，不会丢） |

## 八、安卓端和网页版功能对不上

个别进阶选项在移动端与网页端的上线时间不一致 —— 手机上找不到某个功能时，先去 [可灵AI 网页版](https://klingai.com/app) 看一眼有没有；网页版功能面板通常更全，也是参数调试更顺手的地方。两端用同一账号登录，作品与灵感值互通。
