## 一、本篇讲什么

默认生成时，画面长什么样全靠模型自由发挥，出来的东西常常「内容对、镜头不对」。首尾帧和运镜是两个把控制权拿回来的手段：**前者定住开始与结束那两帧，后者规定镜头怎么移动**。两个都属于图生视频的选项，用之前建议先过一遍 [文生视频与图生视频教程.md](文生视频与图生视频教程.md) 的基本流程。

## 二、首尾帧：定住开头和结尾

**它解决的问题**：你已经知道视频第一眼要是什么、最后一眼要是什么，只要中间的过渡。

用法：

1. 进入图生视频，找到「添加尾帧」（入口在图生视频功能区右上角一带，不同版本措辞可能略有差别）；
2. 上传首帧图与尾帧图两张；
3. 写一句过渡描述，点生成 —— 模型会用这两张图作起止，产出中间的运动过程。

**关键注意点：两张图要足够像。** 同一主体、同一场景、同一构图，只差一点（比如人物从闭眼到睁眼、镜头从远景到近景）。两张图差异过大时，模型不会硬拗过渡，而是直接切成两个镜头 —— 你看到的就是「跳了一下」。首尾帧不支持与运镜、蒙版类参数同时使用，页面上会互斥置灰，别硬开。

**省灵感值的组合技**：先用文生图批量出若干张风格一致的图，挑两张构图接近的当首尾帧，再生成过渡视频。这比直接文生视频碰运气的成功率高，图片本身扣的灵感值也少。

## 三、运镜控制：规定镜头怎么动

不想靠提示词玄学，就直接在参数区选运镜。常见选项：

| 运镜 | 画面效果 | 典型用法 |
| --- | --- | --- |
| 推进 | 镜头向主体靠近，主体变大 | 强调人物表情、突出产品 |
| 拉远 | 镜头远离主体，环境露出 | 结尾收束、展现大场景 |
| 水平摇 / 垂直摇 | 镜头原地转向 | 扫过一排物体、从脚摇到脸 |
| 旋转 | 画面绕轴转动 | 制造眩晕、梦幻感 |

提示词里写运镜（如「镜头缓慢推进」）也能起到类似作用，但参数选项更稳；两者冲突时以参数为准。

## 四、视频续写：突破单次时长上限

单次生成的时长有上限（以页面当时显示为准），想出更长的片子就用**续写 / 延长**：在已生成的片段基础上追加下一段，模型会接着上一帧的末尾状态继续演。多次续写可以拼出几分钟的成片。

注意两点：

- 每次续写都会**重新扣一次灵感值**，且段数越多，前后风格漂移的概率越大；
- 续写前先确认这一段内容方向对了再往下接，方向错了续出来的全是废片，见 [灵感值与会员价格说明.md](灵感值与会员价格说明.md) 的消耗规则。

## 五、多镜头与故事板

更新一代的模型支持一次生成多个镜头（分镜式生成，镜头数上限以官方页面为准），你可以在故事板里给每个镜头分别写景别、视角与运动。这适合广告、短剧这类需要分镜的题材；日常单镜头片段用不上，没必要为它升档。

## 六、什么时候用哪个

| 你的需求 | 用什么 |
| --- | --- |
| 只要画面动起来，长什么样随缘 | 普通文生视频 / 图生视频 |
| 开头结尾必须是指定的两张图 | 首尾帧 |
| 内容对但镜头乱 | 运镜参数 |
| 片子要更长 | 视频续写 |
| 一条片子里要换好几个场景 | 多镜头 / 故事板 |

效果始终不理想时，多半不是参数问题而是提示词问题，排查步骤见 [常见问题与解决办法.md](常见问题与解决办法.md)。
