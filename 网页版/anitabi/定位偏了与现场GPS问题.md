## 一、先分清「真错」还是「不确定」

地图上的蓝点周围通常有一圈淡色的**精度圈**——那是手机在告诉你「我大概在这个圈里」。判读方法：

- 圈很小（±5 米内）但点明显偏到街对面 → 真误差，往下查；
- 圈很大（±50 米级） → 手机自己就不确定，先不怪 anitabi，按下面第 2、3 条改善接收条件即可。

蓝点是手机系统给的定位，anitabi 只负责显示——所以点偏了，先修定位，不是卸载 App。anitabi 侧需要你确认的只有一件事：**定位权限给了没有**（首次安装时要允许，见 [下载与安装教程.md](下载与安装教程.md)）。

## 二、按原因对号入座

| 原因 | 典型表现 | 你能做的 |
| --- | --- | --- |
| 在室内 / 楼里 | 点贴到最近的路上或院子中央 | 走到室外或窗边，屋顶会挡住大部分卫星信号 |
| 高楼夹缝（城市峡谷） | 点跳到街对面、隔一个街区 | 走到路口、广场一侧等几秒，信号直接看到天空才会准 |
| 定位是缓存的旧值 | 显示你几分钟前的位置 | 把定位开关关掉再打开，或杀掉 App 重开，强制刷新 |
| 省电模式在限速 | 点更新慢、走一段才动一下 | 用地图期间关掉省电/低电量模式，必要时允许后台运行 |
| 刚落地 / 冷启动 | 第一次定位偏得离谱，慢慢回正 | 原地站 30~60 秒等它收敛 |
| 开着 VPN 或虚拟定位 | 点整块漂到别的城市、别的国家 | 关掉这类工具再打开地图 |
| 手机壳太厚 / 手挡住 | 信号一直偏弱、缓慢漂移 | 摘壳试试，手机平放别一直握着 |

前六条是通用 GPS 排查里最常见的成因（多来源一致的常识性结论），不需要懂原理，从上往下试一遍基本能定位到原因。

## 三、现场巡礼的实用动作

1. **对照截图而不是迷信蓝点**：anitabi 的地标坐标本身也可能有偏差——官方行为建议写明平台「不对内容的精确性做严格判断」。走到地标附近后，举手机对截图（操作见 [地图上怎么搜作品圣地.md](地图上怎么搜作品圣地.md)），场景对上了才算到，蓝点只负责把你带到街区。
2. **投影地图时先在开阔地取一次定位**：进地铁、进商场再出来，蓝点常带着旧位置，先在门口站几秒等圈缩下去再开始找点。
3. **签到点不上**：那是灰度功能，与定位精度无关，处理见 [白屏打不开与网络问题排查.md](白屏打不开与网络问题排查.md)。

## 四、什么时候该怀疑是 anitabi 的问题

定位在其他 App（比如地图导航类）里准、只有 anitabi 的蓝点不动或地图不刷新——那才轮到查网络与版本：地图数据是联网拉的，网络卡住时蓝点会正常动、地图却不更新，这种「点动图不动」走网络排查：[白屏打不开与网络问题排查.md](白屏打不开与网络问题排查.md)。
