# 白屏打不开与网络问题排查

> 本文按「先确认装对、再确认网络、最后确认是不是临时故障」的顺序，排查 anitabi 打不开、白屏、地图一直加载不出来的问题。

## 一、先判断你卡在哪一种

anitabi 本体只有 3.37M，地图瓦片、地标、截图全是联网后拉取的。所以「打不开」几乎都能归成三类，对号入座再往下查：

| 症状 | 更可能是哪类问题 |
| --- | --- |
| 打开就白屏，进不去主界面 | 安装包问题 或 网络不通 |
| 界面出来了，地图空白 / 地标转圈加载不出 | 网络质量 或 服务器端波动 |
| 偶发：上午还能用、下午就加载不动 | 服务端或线路的临时故障 |

## 二、先排除安装包问题

装错包、包不完整，最典型的表现就是启动即白屏。核对三样：

1. 包名必须是 `com.anitabi.map`；
2. 版本与体积对得上（本套文档对应 2.0.3 / 3.37M，见 [下载与安装教程.md](下载与安装教程.md) 的核对表）；
3. MD5 用校验工具算一遍，和表里一致再装。

对不上就重新从 [anitabi 安装文件资源（夸克网盘）](https://pan.quark.cn/s/88a16e73b323) 转存一份。仍白屏就卸载重装一次（升级覆盖安装残留旧数据也会白屏）。

## 三、再排除网络问题

这是最常见的一类，按顺序试：

1. **换一个网络**：Wi-Fi 和移动数据互切一次。地图数据要实时拉，代理/加速器开着反而可能干扰；官方 App Store 下有用户反馈过「以前要加速器才不白屏、后来不用了」，也有用户反馈过在海外（日本）突然白屏——网络环境对它的影响因时因地而异，切换网络是最先该做的动作。
2. **确认不是全设备断网**：随便开个网页验证一下。网络本身通、只有 anitabi 白屏，往下走第 3、4 条。
3. **换个地区节点再试**：官方更新记录里提到过「福建、广东、贵州等地不可访问」的情况（当时的处理是给备用方案）。你所在地区历史上出现过访问困难，换网络出口再试有实际意义。
4. **等几分钟重开**：服务端波动时，反复狂点没用——杀掉 App，隔几分钟再开。

## 四、这些情况不是你的错

- **地图滑不动、一直显示加载**：App Store 有用户反馈过这种状态（伴随白屏），属于官方需要修的范畴，个人侧能做的就是换网络 + 重装 + 等更新。反馈渠道见 App Store 页面的开发者联系入口。
- **签到失败 / 定位点不了**：签到功能本来就是灰度上线的，官方当时的说明是「无法签到时请和现场工作人员说明」——签到拿不到盖印不影响你正常看地标。
- **部分地标搜不到**：R 限内容默认被屏蔽、冷门作品数据待补完，这两条是规则不是故障，见 [地图上怎么搜作品圣地.md](地图上怎么搜作品圣地.md)。

## 五、App 实在打不开时的替代路线

手机端一时打不开，不代表整个服务都挂了——网页版和它是同一套数据。用手机浏览器或电脑开网页版地图，照样能查地标、看截图；如果你只是需要行前整理，电脑上反而更顺手。分工细节见 [网页版和手机App怎么配合用.md](网页版和手机App怎么配合用.md)。
