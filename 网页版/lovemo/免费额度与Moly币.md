## 一、Moly 币是什么

Moly 币是 lovemo 应用内的虚拟币，聊天对话要消耗它：你发消息、AI 回复，都会按应用内的规则扣 Moly。额度用完想继续聊，要么继续领（下面三条途径），要么充值（价格与档位以应用内充值页为准），要么改用自备的 API Key（见 [API设置与模型接入.md](API设置与模型接入.md)）。

## 二、免费领取的三条途径

第三方教程给出的免费获取方式有三种，具体数值以你应用内活动页为准：

| 途径 | 操作 | 额度 |
| --- | --- | --- |
| 每日签到 | 「我」→ 账单 / Moly 钱包 → 每日签到 | 每天 10 币，连续签到有额外奖励 |
| 邀请新用户 | 把邀请码给新用户，对方注册时填写 | 每成功一位 100 币 |
| 话题活动 | 发抖音、小红书参与 #lovemo 话题并完成有效互动 | 100~1200 币 |

两个领取细节：历史邀请成功获得的 Moly 可以在账单里查询；邀请新用户的奖励，新用户要在**注册完成后 24 小时内**领取才有效，过期作废。

## 三、官网口径的每日免费额度

官网对使用方式的介绍里提到「应用提供每日 60 条免费对话额度，付费订阅后可解锁无限对话、专属图片内容及角色记忆升级服务」。这个口径和上面第三方教程的签到领币口径是并列关系，不同版本、不同时间的活动规则可能不一样，两边都没有错 —— 你实际能用多少，以登录后应用内显示的为准。

## 四、Moly 与自有 API token 的关系

如果你在 API 设置里接入了自己的模型服务，就同时存在两种「燃料」：应用内的 Moly 币和你自己的 API token。第三方教程的说明是：

- 二者没有本质区别，可以在设置里选择**优先消耗哪一个**。
- 应用自带的**沉浸式角色互动功能只能消耗 Moly**，不走你的 API token。

省钱思路：日常闲聊把优先消耗设成自有 token（走 Key 的用量），沉浸式互动这类专属玩法留给 Moly；Moly 靠每天签到慢慢攒，不够时再考虑充值或话题活动。

## 五、额度不够用了怎么办

按顺序试：先签到、查账单确认有没有没领的邀请奖励；再评估要不要参与话题活动；仍不够就二选一 —— 充值 Moly（档位以应用内为准），或改走自备 API Key 的路线（有一条接免费模型的零成本路线，步骤见 [怎么免费聊天.md](怎么免费聊天.md)）。想减少额度消耗，可以从记忆条数、回复节奏这些设置入手，见 [角色创建与聊天设置.md](角色创建与聊天设置.md)。
