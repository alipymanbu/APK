## 一、lovemo 是什么

lovemo 是一款以 AI 虚拟陪伴为核心的社交应用（安卓版），你在里面可以自定义聊天对象的外貌、性格、背景，在闺蜜、伴侣、损友这类关系类型之间切换，用文字、图片或语音互动。开发商是宁波群鸟科技有限公司，官网为 [https://www.lovemoai.com/](https://www.lovemoai.com/)，腾讯应用宝的详情页在 [sj.qq.com/appdetail/io.iftech.lovemo](https://sj.qq.com/appdetail/io.iftech.lovemo)，可以用来核对开发商与产品信息。

这篇只解决「拿到包、装上、能打开」这一段；装好后先去做 API 设置或领聊天额度，见 [API设置与模型接入.md](API设置与模型接入.md) 和 [免费额度与Moly币.md](免费额度与Moly币.md)。

## 二、安装包从哪拿

最直接的入口是上面头部那份 **lovemo 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/c8f8e825e507](https://pan.quark.cn/s/c8f8e825e507)。打开链接 → 转存到自己的网盘 → 把 APK 下载到手机（在电脑上操作的话，先下到电脑再传到手机也行），文件名形如 `lovemo_v1.6.3.apk`，以网盘内实际显示为准。

这份包的固定信息：

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.6.3 |
| 包名 | `io.iftech.lovemo` |
| 安装包大小 | 70.55M |

下载完可以核对一下 MD5 是否一致（一致说明文件完整、没下残）：Windows 上把 APK 放到某个目录，运行 `certutil -hashfile lovemo_v1.6.3.apk MD5`，输出应与上表一致。

版本号说明：应用商店页与应用宝显示的版本（如 1.6.2）可能和网盘里这份 1.6.3 对不上，这是正常现象 —— 官方商店随更新往前走，网盘里存放的是上面表格里这一版，版本号 / 包名 / 大小一律以表格为准。

## 三、系统要求

- **安卓版本**：第三方下载页普遍标注 Android 5.0 及以上（个别页面写法略有出入），官方没有给出统一口径，以你实际安装时的系统提示为准。
- **存储空间**：安装包 70.55M，安装后占用更大，至少预留几百 MB 可用空间。
- **网络**：首次登录与后续对话都需要联网，离线状态聊不了。
- **登录方式**：多个教程与官网说明一致 —— 用微信登录，登录后才能使用聊天等功能。

## 四、安装步骤

1. 在手机浏览器或夸克里打开网盘链接，把 APK 转存并下载到手机。
2. 点击 APK 开始安装。系统弹出「禁止安装来自此来源的应用」是安卓对非商店安装的默认拦截 —— 去设置里给浏览器或文件管理器授予「安装未知应用」权限（一般在「设置 → 安全/隐私 → 安装未知应用」），返回继续装。
3. 安装完成打开应用，首次启动会要求同意用户协议与隐私政策，按提示同意。
4. 用微信完成登录，进入主界面。

安装阶段报「应用未安装」「解析包出错」这类错，多数是包下载不完整或系统版本过旧，先核对第二节表格里的 MD5，再对照 [常见问题解答.md](常见问题解答.md) 排查。

## 五、装完第一件事

lovemo 打开后**通常不能直接开聊**：要么先在「我的 → API 设置」里配置模型与密钥，要么使用应用自带的 Moly 币额度。这两条路怎么走，分别见 [API设置与模型接入.md](API设置与模型接入.md) 与 [免费额度与Moly币.md](免费额度与Moly币.md)。

另外，官方渠道目前可见的主要是安卓端；iOS、网页版之类的说法散见于第三方页面，以官方渠道当时显示的为准。桌面端与多端情况有任何疑问，也可以先看 [常见问题解答.md](常见问题解答.md)。
