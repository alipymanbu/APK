## 一、为什么打开还不能直接聊

lovemo 的对话由大模型驱动，官网对使用方式的说明是：微信登录后进入设置页做 API 配置（填写 AI 模型、API URL 和密钥），完成后才能创建聊天窗口开始互动。也就是说，如果你既没配 API，也没有可消耗的 Moly 币额度，第一句话就发不出去。两条路任选其一：

- **用应用内额度**：领 Moly 币（签到、邀请等方式），不需要自己注册任何模型服务，见 [免费额度与Moly币.md](免费额度与Moly币.md)。
- **自备 API Key**：在 API 设置里接入第三方大模型服务，走你自己 Key 的用量。

## 二、API 设置步骤

多个第三方教程的步骤一致，按下面顺序走：

1. 微信登录后进入「我的」页面。
2. 打开「API 设置」。
3. 在角色配置界面选择 AI 模型（模型提供方），填写 API URL 与 API Key（密钥）。
4. 返回首页，设置角色状态。
5. 需要的话顺手调一下聊天偏好（回复行为类开关），回首页就能开聊。

可选哪些模型服务：第三方页面提到支持接入 OpenAI、DeepSeek、Kimi 等主流大模型服务，具体列表以你应用内「API 设置」页当时显示的为准；模型选哪个不影响本篇步骤，填的名字、URL、Key 三者要配套（都来自同一家服务），填错任何一项都会连不上。

两个来自第三方教程的操作细节：模型列表支持按名称搜索，找不到想要的模型时先在模型选择页搜一下；配置自有 Key 的选项名在教程里写作「使用自有 API」，以界面实际显示为准。

想把零成本路线走全，还有一条接免费模型的路线可走，步骤见 [怎么免费聊天.md](怎么免费聊天.md)。

## 三、自备 Key 与 Moly 额度怎么选

两种方式的差异：

| 对比 | 自备 API Key | Moly 币额度 |
| --- | --- | --- |
| 前置成本 | 需要去模型服务商注册并拿 Key | 无，应用内签到/邀请即可领 |
| 费用走向 | 按你 Key 在服务商侧的用量计费 | 消耗应用内 Moly 币 |
| 聊天体验 | 取决于你接的模型 | 取决于应用默认模型 |

第三方教程还提到两个设置细节：

- 在设置里可以选**优先消耗 Moly 还是自有 token**，两者没有本质区别，可以随时切换。
- 应用**自带的沉浸式角色互动功能只能消耗 Moly**，这部分不走你的 API Key。

不想花钱又想聊，优先把 Moly 额度领满再考虑自备 Key；对回复质量有明确要求（比如指定某家模型）再走 API 路线。

## 四、常见配置问题

- **填完 Key 还是发不出消息**：先确认选择了优先消耗的额度类型（Moly 或 token）；再确认 Key 未过期、账户里还有用量。
- **换了模型服务**：模型、API URL、Key 三项要一起换成同一家，只改其中一项会连不上；改完发一句话测试。
- **不想碰 API**：完全可以，不配 API 也能用 Moly 额度聊天，见 [免费额度与Moly币.md](免费额度与Moly币.md)。
- **配置好之后聊什么**：先创建一个角色再开聊，步骤见 [角色创建与聊天设置.md](角色创建与聊天设置.md)；安装与登录问题则回到 [下载与安装教程.md](下载与安装教程.md)。
