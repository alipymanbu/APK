## 一、三条免费路线总览

| 路线 | 要做什么 | 特点 |
| --- | --- | --- |
| 应用内 Moly 额度 | 每日签到、邀请好友、话题活动 | 零花费，靠每天攒，见 [免费额度与Moly币.md](免费额度与Moly币.md) |
| 官网口径的每日额度 | 登录即用 | 官网介绍为每日 60 条免费对话额度，以应用内实际显示为准 |
| 自备 Key + 免费模型 | 注册一家模型服务，把它的免费模型接进 lovemo | 零花费，要动手配一次，见下一节 |

前两条靠应用内活动，规则随版本和时间变动；第三条配好之后，聊天消耗的是模型服务侧的额度，和应用内 Moly 是两条账。

## 二、自备 Key 接免费模型的步骤

一份针对 1.6.3 版本的第三方教程给出了完整路线：去硅基流动（可搜索「硅基流动」进官网）注册并新建 API 密钥，再从它的模型广场复制一个免费模型名，填回 lovemo 的 API 设置。步骤如下：

1. 打开硅基流动官网，用「统一登录入口」注册并登录。
2. 登录后点右上角的三横线菜单，进入「API 密钥」。
3. 点「新建密钥」，生成一串密钥，先复制保存好。
4. 回到模型广场，用右上角筛选器选 DeepSeek 厂商，找到标注免费的模型点进去。
5. 复制模型名称（名称右侧的复制图标）。
6. 打开 lovemo，进「我」页面，打开「API 设置」。
7. 选择「使用自有 API」，把密钥和模型名分别粘贴进去，保存。

之后聊天就走你自己的 Key。两点提醒：免费模型的范围和额度政策由硅基流动决定，随时可能调整，以它当时的页面为准；配置项的选项名以你应用内实际显示为准，教程里的叫法可能略有出入。

## 三、配好了还是聊不动

按顺序查三件事：

1. 密钥与模型名是否来自同一家服务（混用必连不上）。
2. 粘贴时是否带进了空格或换行。
3. API 设置里优先消耗的是 Moly 还是自有 token，切换一下再试。

仍不行就换一个免费模型重试，更多排查见 [API设置与模型接入.md](API设置与模型接入.md)。不想折腾 API 的，回到签到攒 Moly 那条路线，每天领一点也够日常聊一阵；聊天内容的边界与隐私注意事项见 [常见问题解答.md](常见问题解答.md)。
