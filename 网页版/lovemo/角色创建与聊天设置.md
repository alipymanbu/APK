# lovemo 角色创建与聊天设置

> 这篇讲 lovemo 里怎么创建自己的角色：能自定义哪些参数、关系类型怎么切换、记忆和聊天偏好在哪调。

## 一、创建你的第一个角色

前提：已经完成微信登录，并且 API 或 Moly 额度至少有一项就绪（没就绪先看 [API设置与模型接入.md](API设置与模型接入.md)）。创建入口在消息界面：

1. 进入消息页面，点**上方的加号**。
2. 输入角色名称，开始创建你的 OC（原创角色）。
3. 按引导填人设参数（见下一节），保存后就能开聊。

不想从零捏一个，也可以在官方角色的基础上改人设 —— 挑一个现成角色，把性格、背景改成你想要的样子，改动后它就按新设定跟你聊。

创建之后想回头改人设：第三方教程给出的入口是聊天界面右上角的扩展按钮（或「…」菜单），在里面找「人设设定」「编辑角色」一类的选项，能改出生背景、性格、长相等设定，改完保存；同一处通常也能改「你」自己的用户设定 —— 你希望它怎么称呼你、怎么理解你，也值得一并写清楚。

## 二、能自定义哪些东西

把官网与第三方教程提到的可自定义项汇总成一张表：

| 项目 | 能改什么 | 说明 |
| --- | --- | --- |
| 基础信息 | 昵称、性别、年龄、头像形象 | 头像可用图片或应用内的文生图工具生成 |
| 性格 | 幽默、傲娇、理性、温柔等特质 | 写得越具体，回复风格越稳定 |
| 背景故事 | 人物经历、你们的关系设定 | 决定它「记得自己是谁」 |
| 说话风格 | 语气、口癖、表达习惯 | 想要某种腔调就写清楚 |
| 关系类型 | 闺蜜、伴侣、损友等 | 见下一节 |

官网在创作能力的介绍里还提到：可以用文字为角色设定专属性格与剧情内容，用文生图工具设计人物形象和故事场景，平台开放创作者社区供用户分享原创故事模板。创作时注意官方的内容边界（哪些不能写），见 [常见问题解答.md](常见问题解答.md)。

人设怎么写才有效，第三方教程给过一个对比：想捏一个「美食爱好者」，只写「喜欢美食」效果一般，写成「喜欢吃火锅、擅长推荐餐厅、会跟你聊做菜技巧」这类具体描述，回复才贴得住你想要的风格 —— 表格里每一格都照这个思路写具体。

## 三、关系类型与多角色切换

lovemo 支持同时管理多个角色，并在不同关系之间切换：闺蜜、伴侣、损友等类型各有不同的聊天氛围。你不需要删掉旧角色再建新的 —— 消息列表里每个角色是一条独立会话，想换氛围就切到另一个会话接着聊。

## 四、记忆设置

第三方教程提到的记忆相关设置有三处，都在角色/人设相关页面里：

- **永久记忆**：在人设或记忆中手动添加你想让它长期记住的内容（比如你的称呼、偏好、约定），这类内容不随对话轮次流失。
- **对话记忆条数**：设置 AI 每次参考最近多少条对话，条数越多对前文的把握越足。
- **自动总结**：开启后应用会自动总结对话上下文，长时间聊天也能保持连贯。

一个实用组合：重要信息手动写进永久记忆，日常上下文交给「记忆条数 + 自动总结」；发现它忘了前文，先查这两处而不是重开角色。

## 五、聊天偏好开关

官方与第三方教程提到过这些行为类开关，名字以你应用内实际显示为准：

| 开关 | 作用 |
| --- | --- |
| 等我说完再回复 | 避免你还没打完它就插话 |
| 暂停 / 继续 | 临时停下对话，回来接着聊 |
| 角色主动问候 | 没聊的时候它也会发来早安晚安之类的消息 |
| 向上滚动触发回复 | 翻历史记录时决定是否触发新回复 |

这些开关不影响额度消耗规则（额度见 [免费额度与Moly币.md](免费额度与Moly币.md)），只影响对话节奏。另有第三方教程提到：应用内有一个「官方小助手」会话，点它右上角的三点菜单可以编辑聊天信息并保存，想手动修正某条记录时可以找找这个入口。角色建好后发图、听声音、玩动态的做法见 [动态与语音功能.md](动态与语音功能.md)。
