## 一、先弄清楚：装 APK 不等于拿到 root

SukiSU Ultra 是内核级的安卓 root 方案，可以理解为 KernelSU 的一个开源分支：root 的实现放在系统内核里，手机上那个 App 是「管理器」，负责批准授权、管理模块和改设置。你只装 APK、不处理内核，打开管理器会看到「未安装 / 不支持」之类的提示 —— 这不是安装包坏了，是内核里还没有它的成分。本篇按「装管理器 → 让内核支持 → 验证」三步走。

## 二、动手前先确认这几件事

| 条件 | 说明 |
| --- | --- |
| 解锁 Bootloader | 刷入任何非原厂内核的前提。解锁通常会清空手机数据，先备份照片、聊天记录与验证器 |
| 内核侧支持 | 三选一：ROM 已集成 SukiSU/KernelSU 驱动；你刷入了兼容的内核包；你用管理器修补 boot 镜像再刷回去 |
| 自定义 Recovery | 走「刷 zip」路线需要 TWRP 这类第三方 recovery；只走「修补镜像」路线可以不用 |
| 刷机基本功 | 会进 fastboot / recovery、会执行 `fastboot flash`，知道刷错了怎么回退 |

不满足「内核侧支持」这一条，后面装得再顺利也用不了。厂商深度改内核的机型（魅族、一加、realme、OPPO 等）不能用通用 GKI 包，需要走各自的构建路线。

## 三、第一步：安装管理器 APK

安装包信息以本地保存的那一份为准（网上常能搜到别的渠道的版本，未必是同一个包）：

| 项目 | 值 |
| --- | --- |
| 版本 | v4.1.3 |
| 包名 | `com.sukisu.ultra` |
| 大小 | 11.59M |
| MD5 | `540890b027496ab7fa5fe2006c467cec` |
| 记录时间 | 2026-09-21 |

步骤：

1. 从 [SukiSU Ultra 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e537a31c4e5b) 把 APK 下到手机；
2. 想核对文件没被改动，可以在电脑上算一下 MD5，与上表一致再装；
3. 点开 APK，系统若提示「禁止安装未知来源应用」，在设置里允许本次安装；
4. 装完先打开看一眼首页：内核版本、Android 版本、设备代号、SELinux 状态、管理器版本这几行能正常显示，说明管理器本身没问题（此时多半还没 root，属正常）。

## 四、第二步：让内核支持它（三条路线选一条）

### 路线 1：GKI 设备直接刷内核包（最常见的做法）

适用于 GKI 2.0 设备（小米、红米、三星等），不适用于上面说的深度改内核厂商。

1. 查清自己手机的内核版本（设置 → 关于手机，记下 `5.10`、`5.15`、`6.1`、`6.6` 这类前两段数字）；
2. 到 SukiSU Ultra 官方资源页找对应内核版本的 GKI 构建，下载文件名带 `AnyKernel3` 字样的 zip（无后缀的 zip 是未压缩包，`.gz` 是特定型号的压缩格式）；
3. 手机进入 TWRP，选 Install，定位到该 zip，滑动确认刷入；
4. 刷完重启回系统，进行第五节的验证。

### 路线 2：用管理器修补 boot 镜像再刷回（不想换内核包时）

1. 从你的当前 ROM 包里取出 `boot.img`（部分新机型是 `init_boot.img`）；
2. 管理器里选择「修补文件」，选中该镜像，得到一个修补后的文件；
3. 手机进 fastboot，执行类似下面的命令刷回（分区名以你的机型为准）：

```bash
fastboot flash boot patched_boot.img
fastboot reboot
```

### 路线 3：从源码把 SukiSU 集成进自己的内核（高级用户）

面向自己编译内核的人，官方仓库提供集成脚本，主分支（LKM 模式）与内置构建分支各一条：

```bash
curl -LSs "https://raw.githubusercontent.com/SukiSU-Ultra/SukiSU-Ultra/main/kernel/setup.sh" | bash -s main
```

需要 KPM 支持时内核要开 `CONFIG_KPM=y`；非 GKI 内核还要开 `CONFIG_KALLSYMS=y` 与 `CONFIG_KALLSYMS_ALL=y`。这一步出错的概率最高，没编译经验直接用路线 1。

## 五、第三步：验证是否成功

依次核对：

1. 打开管理器，首页状态显示已安装，内核版本、SELinux 等字段读得出来；
2. 装一个 root 检查类应用，或在终端里执行 `su -c id`，返回里出现 `uid=0(root)`；
3. 设置 → 关于手机里的内核版本与你刷的一致。

三步都过了，root 环境就算搭好，接下来去 [超级用户授权与权限管理.md](超级用户授权与权限管理.md) 给需要的应用放权限。哪一步卡住了，按 [常见问题与故障排查.md](常见问题与故障排查.md) 对号入座。

## 六、几个容易踩的坑

- 刷与当前内核 KMI 不匹配的包，轻则开不了机，重则要线刷救砖 —— 刷之前确认包名里的内核版本；
- 解锁 BL、刷非原厂内核都可能影响保修与系统更新，动手前把官方的兼容性说明看完；
- 管理器版本过旧可能与内核侧对不上，装完 APK 后在设置里开启检查更新，保持两侧版本接近。
