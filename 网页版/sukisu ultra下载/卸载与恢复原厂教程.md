# SukiSU Ultra 卸载与恢复原厂教程

## 一、先想清楚要撤到哪一层

卸载不是一个动作，是三个深度，选错层级会白折腾：

| 层级 | 做法 | 撤掉什么 | 适合什么情况 |
| --- | --- | --- | --- |
| 1 | 管理器内卸载 | root 与模块管理能力 | 只是不想用了，手机继续自用 |
| 2 | 刷回原厂 boot 镜像 | 内核里的 root 成分 | 某个应用不认 root 环境、系统更新前想清干净 |
| 3 | 恢复完整原厂固件 + 锁回 Bootloader | 所有软件层面的修改痕迹 | 卖手机、送修、要求彻底还原 |

层级 3 里「锁 Bootloader」是唯一可能把手机锁死的操作：**必须在固件完整刷回原厂之后才能锁**，锁的过程还会再次清空数据。没把握就停在层级 2。

## 二、层级 1：管理器内卸载

1. 先把模块撤干净：管理器 → 模块页，逐个删除（别直接跳到卸载，残留模块留着没意义）；
2. 管理器 → 设置 → 找到卸载入口（不同版本叫法略有差异，有的写作 Uninstall / 卸载），确认卸载；
3. 重启手机。

做完这一步，管理器通常会被移除、root 授权消失。但如果你当初刷过 `AnyKernel3` 内核包或修补过 boot 镜像，**内核里的成分还在** —— 这也是很多人卸完发现「怎么还能用」的原因，接着走层级 2。

## 三、层级 2：刷回原厂 boot 镜像

这是最常用的彻底做法，前提是你手里有刷机前备份的原厂镜像：

1. 确认你的机型用的是哪个分区：新机型（多为 Android 13 及以后）通常是 `init_boot.img`，老机型是 `boot.img`，取错分区刷了也白刷；
2. 进 fastboot，把原厂镜像刷回去：

```bash
fastboot flash init_boot stock_init_boot.img
fastboot reboot
```

3. 重启后打开一个需要 root 的工具验证：不再弹授权窗、提示无 root，即已撤干净；
4. 手动卸载管理器 APK（长按图标卸载即可）。

有用户反馈（社区论坛帖）：如果刷过 `AnyKernel3` 内核包，必须刷回**原厂 boot.img** 才算干净；只刷过 boot 修补的，刷回原厂 `init_boot` 即可。两种情况都以「刷回你当初替换掉的那个分区的原厂镜像」为准。

## 四、层级 3：锁回 Bootloader（高阶，慎做）

顺序不能颠倒：**先完整恢复原厂固件，再锁 BL**。在还跑着改过固件的状态下锁 BL，手机会拒绝启动未签名的软件，而又没有已启动的系统让你再解锁 —— 这是最容易造成不可逆损坏的操作之一。锁完通常还要再清一次数据。

锁回后：开机的解锁警告消失、系统更新恢复正常推送。但要注意有不可逆项：部分品牌会永久记录解锁历史，三星的 Knox 熔丝一旦触发无法复位（以上为通行经验，各品牌政策以官方说明为准）。

## 五、卸载之后仍然存在的东西

- **解锁 Bootloader 本身不因卸载而改变**：只要没锁回去，开机时的解锁警告就一直在；
- **数据与账号**：层级 1、2 不动你的照片与应用数据；层级 3 会全部清空；
- **已经授出的授权记录**：随管理器卸载一并消失，不用单独清。

卖机或送修走层级 3，日常停在层级 1 或 2 就够。卸载后想重新装回，步骤与第一次安装完全相同，见 [下载与安装教程.md](下载与安装教程.md)；只是遇到「装了没反应」的状况，先别急着重装，按 [常见问题与故障排查.md](常见问题与故障排查.md) 查一遍。
