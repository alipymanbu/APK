## 一、首页显示「未安装 / 不支持」

管理器装好了却报未安装，按这个顺序排查：

1. **内核侧还没做**：只装了 APK 当然没有 —— 去 [下载与安装教程.md](下载与安装教程.md) 补刷内核包或修补 boot 镜像；
2. **刷了但没生效**：刷完没重启、或刷错了分区，重启一次再看；用 fastboot 刷的确认命令里的分区名没写错；
3. **包与内核不匹配**：ROM 集成的是别的 root 方案（如 KernelSU 其他分支、APatch）时，管理器可能认不出来 —— 看内核包发布说明里标注适配哪个管理器版本；
4. **管理器太旧**：内核侧是新版、管理器是老版，对协议可能失败，升级管理器再试。

## 二、授了权，应用还是拿不到 root

- 先在超级用户列表里确认该应用的授权状态是「允许」，不是被 App Profile 挡住了（见 [超级用户授权与权限管理.md](超级用户授权与权限管理.md)）；
- 让它重新请求一次：撤销授权 → 重启该应用 → 再触发，看弹窗是否出现；
- 只有这一个应用不行、别的应用正常 → 问题多半在这个应用自己的 root 检测或 SELinux 环境上，与 root 本身无关；
- 全部应用都不行 → 卸掉最近装的那个模块再重启，按 [模块安装与使用教程.md](模块安装与使用教程.md) 的排除法逐个试。

## 三、OTA 系统更新后 root 没了

系统更新会重写启动分区，内核里的 root 成分被覆盖。关键点：**OTA 装完、重启之前**就要处理。

1. OTA 下载安装后**不要立刻重启**；
2. 打开管理器 → 刷入 / 修补内核界面，选 GKI/non_GKI install，选中你的 `AnyKernel3` 内核 zip，选择与当前运行插槽**相反**的那个插槽刷入；
3. 刷完再重启。也可以改用 LKM 模式装到未使用插槽；
4. 非 GKI 设备最稳的办法是进 TWRP 把内核包重新刷一遍。

刷第三方包保 root 需要你的 ROM 是 A/B 双插槽结构；单插槽机型直接走第 4 条。

## 四、银行 / 支付类应用提示环境异常

这类应用会检测 root 与解锁状态，能不能过取决于具体应用的检测强度，**没有通用的必过方案**，别信任何打包票的说法。你能做的是：给这类应用保持零 root 授权、检查有没有模块在改它们的运行环境。要彻底干净，只能恢复原厂 boot 镜像、锁回 Bootloader —— 那等于卸载 root，自己权衡。

## 五、刷完卡在开机画面 / 循环重启

按这个顺序救：

1. 强制进 fastboot（通常是音量减 + 电源，机型有差异）；
2. 刷回你刷之前的原厂 `boot.img` / `init_boot.img`（**刷机前就要备好这个文件**，没有就去同版本 ROM 包里解出来）：
   `fastboot flash boot stock_boot.img` 后重启；
3. 还不行就进 recovery 双清（会丢数据），或用官方线刷工具恢复。

预防远比救援容易：刷任何包之前，先确认 KMI 版本对得上、原厂镜像在手边。

## 六、日志与求助

自查一轮仍解决不了，用管理器的工具 → 发送日志打包环境信息，连同首页截图（内核版本、Android 版本、SELinux 那页）一起发到官方渠道：

- 项目仓库（提 Issue）：[github.com/SukiSU-Ultra/SukiSU-Ultra](https://github.com/SukiSU-Ultra/SukiSU-Ultra)
- 官方文档站（安装与兼容性说明）：[sukisu.org](https://sukisu.org/)
- 社区群组入口在官方文档的链接页里，提问题前先搜一遍有没有人问过同样的症状

描述问题时写清三件事：手机型号与系统版本、内核包还是修补镜像装的、从哪一步开始出的问题。
