## 一、不想自己捏：先从角色广场挑

不想动手的话，直接在角色 Feed 里挑：官方分类有精选（Featured）、官方（Official）、奇幻（Fantasy）、冒险（Adventure）等，每个角色自带人设、声音和说话方式，选中即可开聊。角色社区也在持续更新：可以给角色、图片、视频点赞，推荐喜欢的角色、关注创作者，评论区也能互动（创作者可以关掉自己角色的评论）。

## 二、从零创建一个角色

官方给的三条路（App Store 介绍）：

1. **全自定义**：头像、声音、性格、说话方式逐项自己定；
2. **AI 辅助创建**：用一句话描述你想要的「氛围」，几秒得到一个初始角色，再手动微调；
3. **Remix 别人的角色**：遇到喜欢的角色，一键改得更甜、更暗、更怪——前提是创作者开了「允许 Remix」开关（创作者可在自己的角色上控制这个开关）。

视觉上角色用 Live2D 模型呈现（眨眼、脸红、裙摆摆动这类细节都有），配音来自官方制作的高保真 AI 语音库。

## 三、亲密度：6 个等级

你和角色的聊天越多，亲密度越高：

- 亲密度分 **6 个渐进等级**，从「点头之交（Acquaintance）」一路升到「伙伴（Partner）」；
- 每升一级解锁新的称呼与情感维度；
- 各角色还有自己的故事、任务和话题，随亲密度逐步解锁。

## 四、记忆系统：它记得你说过什么

| 机制 | 作用 |
| --- | --- |
| 检索记忆（Retrieval Memory） | 分层的 Persona / Memory / Context 系统，召回过去聊过的重要细节，而不是只看最近几十条 |
| 钉住记忆（Pinned Memory） | 把重要的台词钉住，之后对话里它一直记得 |
| 角色事件（Character Events） | 共同经历变成一条可见的时间线，AI 之后会主动引用 |
| 记忆日记（Memory Diary） | 官方 PC 版介绍里提到的成长记录，存下你们之间的交流片段 |

## 五、聊天之外的玩法

- **视觉化情节**：聊天里可以生成与上下文相关的图像/视频，一键「Animate」让某个瞬间动起来，还能把 AI 生成的场景设成聊天背景；
- **漫画生成**：版本更新日志里加入了漫画生成功能；
- **Roleplay 模式**：扮演任意角色/世界（官方 PC 版介绍给的例子：庄园领主、卧底任务、恋爱剧情等），普通对话与角色扮演模式可自由切换；
- 聊天模式还有「浪漫模式」与「精简模式」可选。其中高级记忆、更高保真的模型、浪漫模式、上下文图像/视频生成、创作者工具属于订阅解锁范围，见 [会员订阅与免费额度.md](会员订阅与免费额度.md)。
