> 带 GPS 模块的记录仪能把行车轨迹叠在视频上一起回放。本篇讲怎么在手机上看轨迹、定位标志不正常怎么办、GPS 自动校时，以及在电脑上看轨迹的办法。

## 一、先确认你的机器带 GPS

带 GPS 的机型在拍摄或播放界面会有定位标志 —— 有品牌手册把它描述为屏幕角落的一个小图标：**绿色 = 定位正常，白色 = 还没定位上**。你的界面上没有这类标志，说明这台机器不带 GPS，后面几节就不用看了。

## 二、在手机上看轨迹的完整流程

多份品牌手册写明的步骤大同小异（不同版本入口叫法略有差别）：

1. 按 [连接行车记录仪的步骤.md](连接行车记录仪的步骤.md) 连上记录仪。
2. 在设备视频里把**带 GPS 数据的那段视频下载到手机**。
3. **断开记录仪热点，让手机恢复外网** —— 轨迹地图要联网加载，这一步最容易漏，漏了就只有画面没有轨迹。
4. 重新打开 App 进相册，点开刚下载的视频，轨迹随播放同步展示。

## 三、定位不上的常见情形

| 情形 | 说明 |
| --- | --- |
| 刚开机定位不上 | GPS 冷启动要等几分钟，开出一段路再看 |
| 地下停车场、高楼密集处 | 信号被遮挡，属正常 |
| 阴雨天、云层厚 | 有品牌手册明确写了这种情况可能定不上 |

以上都属正常现象，不需要修机器；长时间停在「白色」状态再考虑排查硬件。

## 四、GPS 自动校时

带 GPS 的机器收到定位信号后会自动同步时间，时区默认按东八区（UTC+8）。你所在的时区不同，先在设置里把时区差值调对，时间才会准 —— 手动校时间的入口见 [录像与系统设置.md](录像与系统设置.md)。

## 五、想在电脑上看轨迹

开发者的英文站提供电脑端播放器下载页（[sunningsoft.com/en/pcgps.html](http://www.sunningsoft.com/en/pcgps.html)，以页面当时可访问为准），用它打开带 GPS 的视频文件即可显示轨迹。电脑上没有这个播放器时，普通播放器只能放画面、看不到轨迹层。
