## 一、连接前你要准备什么

这套 App 的工作方式是：记录仪自己发出一个 WiFi 热点，手机连上这个热点后，App 通过它取画面、取文件。开始前逐项确认：

| 检查项 | 说明 |
| --- | --- |
| 记录仪已上电 | 点火通电或接 USB 供电，等它启动完成 |
| 记录仪的 WiFi 已打开 | 多数机型开机自动开，有的要在记录仪菜单里手动点 WiFi 图标 |
| 知道热点的名称和密码 | 名称多与品牌 / 型号相关（有的就叫 `ROAD-CAM-XXXX` 这类形式），密码印在说明书、机器底部的标签上，或能在记录仪的设置页看到 |
| 手机已装好 App | 还没装的先看 [下载与安装教程.md](下载与安装教程.md) |
| App 权限已给全 | 至少 WLAN 与存储；部分机型搜设备还要定位权限（手机设置 → 应用权限里开） |

按应用商店页面的标注，这套 App 适配联咏、海思、全志、杰理、安霸、凌通、凌阳等多家记录仪主控方案 —— 也就是说不同品牌记录仪连上后的界面与选项可能略有差别，但连接方式是同一套。

## 二、连接步骤

1. 给记录仪上电，等启动完成（通常几十秒）。
2. 打开手机「设置 → WLAN」，在列表里找到记录仪的热点名称，输入密码连接。
3. 手机可能弹出「此网络无法访问互联网，是否保持连接」，选**保持连接**——这是正常现象，这个热点本来就不通外网。部分安卓机会把不联网的热点自动切回移动数据导致掉线，记得勾「不切换网络」或「始终使用此网络」。
4. 打开 RoadCam。首次使用会要求注册登录（手机号或第三方账号，多份品牌手册都提到这一步），按提示完成。
5. 点屏幕中间的橙色按钮（或带记录仪名称的相机入口）。部分机型这里还有一步「添加设备 / 绑定」：App 会自动搜到已连上热点的机器，个别情况要输设备验证码，或在记录仪屏幕上确认。
6. 连上后自动进入实时预览。首次连上时画面出现前有短暂等待，属正常 —— 有品牌手册把 1 秒内的预览延迟直接列为正常标准。

## 三、实时预览能做的事

- **调安装角度**：记录仪贴在前挡上后，驾驶位往往看不到它的屏幕。用实时预览对准水平线再固定支架，这是预览最实用的场景。
- **开始 / 停止录像**：在手机上控制记录仪录或停。
- **抓拍**：预览过程中直接拍一张照片存档。

画面正常后，把需要的视频存进手机相册：[怎么看回放与下载视频.md](怎么看回放与下载视频.md)。

## 四、连上之后手机没网了

记录仪的热点只在手机与机器之间传数据，不提供外网。连接期间：

- 想继续导航或听在线音乐，断开记录仪热点即可 —— 循环录像不依赖 App，断开后记录仪照常录。
- 预览或导完文件后及时断开，免得手机一直挂着这个不联网的 WiFi。

循环录像时长、停车监控这些参数在 [录像与系统设置.md](录像与系统设置.md) 里调；连不上就按 [连不上与常见问题.md](连不上与常见问题.md) 逐条排查。
