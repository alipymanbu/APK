# Wake On Lan 唤醒失败的原因排查

> 手机发了唤醒指令、电脑没反应 —— 问题九成出在电脑端或网络配置，而不是应用本身。本篇是一张从上到下的排查清单，逐项过。

## 一、先缩小范围

按这个顺序切一刀：

1. 手机连家里 Wi-Fi（与电脑同一路由器），在应用里发一次唤醒；
2. 电脑有反应 → 局域网唤醒没问题，问题在外网配置，跳到《外网唤醒与路由器端口转发》；
3. 电脑没反应 → 继续下面的对照表。

## 二、局域网也唤不醒：对照表

| 环节 | 常见原因 | 处理 |
| --- | --- | --- |
| BIOS | Wake on LAN / Power On by PCI-E 没开；ErP 深度节能开着 | 进 BIOS 开唤醒选项；ErP 必须 Disabled |
| Windows 网卡 | 「允许此设备唤醒计算机」没勾；魔术包唤醒没开 | 设备管理器 → 网卡属性里逐项核对 |
| Windows 快速启动 | 关机后网卡停留在收不到包的状态 | 电源选项里关闭「启用快速启动」 |
| 连接方式 | 电脑用 Wi-Fi 连网 | 绝大多数 Wi-Fi 网卡不支持关机唤醒，改插网线 |
| 电源 | 电脑插头被拔、插线板开关关了 | 网卡靠待机供电，必须一直接市电 |
| MAC 地址 | 手抄错了，或填成无线网卡的 MAC | 用应用内网络搜索重新扫描，或用电脑上的 `ipconfig /all` 核对 |
| 广播地址 | 填成电脑自己的 IP 而不是广播地址 | 电脑 IP 是 192.168.1.100 就填 192.168.1.255 |
| 路由器 | 开了 AP 隔离，或手机连了访客网络 | 手机和电脑连同一个主路由网络，关掉隔离 |
| 关机方式 | 长按电源键强制关机、或拔电源线断电 | 强制断电后网卡进不了待机监听状态，用系统正常关机再测 |
| 笔记本电源 | 只用电池供电 | 插上市电再试，电池供电下唤醒常被禁用 |
| 关机状态 | 完全关机（S5）收不到、睡眠可以 | 部分笔记本/主板的行为，先试睡眠唤醒，再查主板手册 |
| 笔记本 | 厂商压根没实现关机唤醒 | 查该型号规格是否支持，这种没有变通办法 |

## 三、几个容易忽略的点

- **睡眠唤醒 OK、关机唤醒不行**：优先怀疑 Windows 快速启动与 BIOS 里的 ErP，这两个是出现频率最高的坑；
- **之前能唤醒、突然不行了**：想想最近是否更新过网卡驱动、刷过 BIOS、动过路由器设置，挨个还原试；
- **设备在应用里显示离线**：在线状态靠端口探测与 ping，电脑刚关机那几秒状态可能还没刷新，不用等它变灰，直接发也行；
- **换了路由器后全面失灵**：网段变了（比如 192.168.1.x 变成 192.168.31.x），应用里所有设备的广播地址都要跟着改；
- **手机和电脑之间隔了层路由器**（光猫加路由器、主路由加子路由）：广播地址的填法与普通组网不同，见《多层路由组网下广播地址怎么填》；
- **Windows 大版本更新后突然不行**：更新可能重置网卡驱动设置，回设备管理器把「允许此设备唤醒计算机」与「唤醒魔术包」重新勾一遍。

## 四、电脑端没设置好的回去补课

对照表里任何一条指向 BIOS 或网卡设置的，具体操作步骤都在《电脑端开启网络唤醒的设置步骤》，那里写得比本表细；手机端参数怎么填回头核对《添加设备与局域网唤醒操作》。

全部排查过还是不行，最后剩下一种可能：这台电脑的网卡或主板就是不完全支持网络唤醒 —— 用另一台确定支持的机器交叉验证一次，就能下结论了。
