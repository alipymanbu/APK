# Wake On Lan 电脑端开启网络唤醒的设置步骤

> Wake On Lan 只负责发唤醒指令，电脑端不开网络唤醒就永远收不到。本篇讲 BIOS、操作系统、网卡三处要开的地方，以及 MAC 地址怎么查。

## 一、开始前确认两件事

1. **电脑用网线连路由器**。有线网卡对网络唤醒的支持最完整；绝大多数 Wi-Fi 网卡不支持在关机后收唤醒包，官方说明里也明确提到 Wi-Fi 设备很可能唤醒不了；
2. **电脑保持接通电源**。关机后网卡要靠待机供电才能监听唤醒信号，插头一拔就什么都没了。

笔记本要单独说：不少笔记本在完全关机（S5）状态下收不到唤醒包，只在睡眠（Sleep）状态下可以，这取决于厂商实现。装好之后两种状态各试一次就知道了。另外，只用电池供电时唤醒多半不生效，测试时插着电源。

## 二、BIOS/UEFI 里开启 Wake on LAN

重启电脑，在开机自检时按 Del / F2（部分品牌是 F1、F10 或 Esc，开机画面有提示）进 BIOS：

1. 找 **Power Management**（电源管理）或 **Advanced**（高级）分类；
2. 找到名字类似下面之一的选项并设为 Enabled：
   - Wake on LAN
   - Power On by PCI-E / PCI-E Devices
   - Resume by LAN / LAN Wake Up
3. 如果有 **ErP**（或 ErP Ready、深度节能）选项，**设为 Disabled** —— 这个选项开着会在关机后彻底切断网卡供电，网络唤醒直接失效，这是最常见的翻车点之一；
4. 按 F10 保存退出。

不同主板的菜单叫法不同，找不到就在 BIOS 里逐个分类翻。常见品牌的菜单位置大致如下（不同型号有出入，以实际 BIOS 为准）：

| 品牌 | 常见路径 |
| --- | --- |
| 华硕 ASUS | Advanced → APM Configuration → Power On By PCI-E |
| 技嘉 Gigabyte | Settings → Platform Power → Wake on LAN |
| 微星 MSI | Settings → Advanced → Wake Up Event Setup → Resume By PCI-E Device |
| 华擎 ASRock | Advanced → ACPI Configuration → PCIE Devices Power On |
| 戴尔 Dell | Power Management → Wake on LAN |
| 惠普 HP | Advanced → Power-On Options → Remote Wakeup |
| 联想 Lenovo | Power → Wake on LAN |

## 三、Windows 系统侧的网卡设置

BIOS 开了还不够，Windows 的网卡驱动默认可能不允许唤醒：

1. 右键开始按钮 → **设备管理器** → 展开 **网络适配器**；
2. 找到有线网卡（名字一般含 Realtek / Intel / Ethernet），右键 → **属性**；
3. **电源管理**选项卡：勾选「允许此设备唤醒计算机」；
4. **高级**选项卡：找到「唤醒魔术包 / Wake on Magic Packet」设为 Enabled（有的驱动叫 Magic Packet Wakeup）；
5. **关闭快速启动**：控制面板 → 电源选项 → 选择电源按钮的功能 → 更改当前不可用的设置 → 取消勾选「启用快速启动」。快速启动会让关机后网卡停留在收不到唤醒包的状态，同样是高发坑。

改完建议重启一次并正常关机，再用手机试唤醒。

## 四、Linux 系统侧（可选）

电脑跑 Linux 的话，用 `ethtool` 检查与开启：

```bash
ethtool eth0            # 看 Wake-on 一行：g 表示已支持魔术包唤醒，d 表示关闭
ethtool -s eth0 wol g   # 开启魔术包唤醒
```

这条设置重启后会失效，需要写进 systemd service 或发行版的网络配置里持久化。

## 五、查到电脑的 MAC 地址

唤醒指令是发给网卡 MAC 地址的，手机上添加设备时必须填它：

- **Windows**：`Win + R` 输入 `cmd` 回车，再输入 `ipconfig /all`，找到有线网卡的「物理地址」，形如 `AA-BB-CC-DD-EE-FF` 的 6 组十六进制；
- **Linux**：`ip link`，看网卡条目里的 `link/ether`；
- **不用手抄**：Wake On Lan 自带网络搜索（Network Search），能直接扫出局域网里在线设备的 MAC 与 IP，见《添加设备与局域网唤醒操作》。

## 六、三处都设好了再试

BIOS、系统、网线供电三处都确认后，回到手机应用里添加设备试一次。还是唤不醒的话，按《唤醒失败的原因排查》的清单从上往下过一遍，绝大多数问题都能对号入座。
