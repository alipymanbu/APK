## 一、添加设备前的状态

确保两件事已完成：电脑端开启了网络唤醒（见《电脑端开启网络唤醒的设置步骤》），手机连在电脑同一个路由器的 Wi-Fi 下。

## 二、方式一：网络搜索自动添加

界面里的 **Network Search（网络搜索）** 会扫描当前局域网里在线的设备，列出 IP、主机名与 MAC：

1. 手机连家里 Wi-Fi，电脑保持开机在线；
2. 打开网络搜索，等扫描结果出来；
3. 在列表里找到你的电脑（按主机名或 IP 认），点添加进设备列表。

这是省事的添加方式：MAC 地址自动带出，避免手抄出错。

## 三、方式二：手动添加

点界面右下角的添加按钮，逐项填写：

| 参数 | 填什么 | 举例 |
| --- | --- | --- |
| Name | 随意的备注名，方便认 | 书房电脑 |
| Mac Address | 电脑有线网卡的 MAC 地址 | AA-BB-CC-DD-EE-FF |
| Broadcast IP / Hostname | 局域网广播地址，一般是电脑 IP 把最后一段改成 255 | 电脑是 192.168.1.100，就填 192.168.1.255 |
| Port | 保持默认 9 即可 | 9 |

广播地址填错是手动添加时最常见的失败原因：不确定网段时，先在电脑上用 `ipconfig` 看自己拿到的 IP（如 192.168.31.23），广播地址就是 192.168.31.255。主路由下还挂着子路由、或光猫自带 Wi-Fi 也在用的多层组网，广播地址的填法另有一套讲究，见《多层路由组网下广播地址怎么填》。

## 四、发唤醒指令

设备列表里点一下设备就是发送唤醒，成功与否几秒内见分晓（电脑风扇会转起来）。日常配合这几个功能用：

- **分组（Groups）**：把多台设备编进一组，一键整组唤醒，适合书房加客厅多台设备的场景；
- **桌面小组件（Widget）**：把某台设备或某个分组钉在桌面，一键唤醒不用进应用；
- **在线状态**：设备列表通过端口探测与 ping 自动刷新每台设备的在线/离线状态，发指令前可以看一眼，在线就没必要发了；
- **SecureOn**：部分网卡支持带密码的唤醒（在设备设置里填 SecureOn 密码），普通家用场景一般用不到。

## 五、测试顺序建议

1. 电脑睡眠状态 → 手机发一次，应能唤醒；
2. 电脑完全关机 → 再发一次，看这台机器支不支持关机唤醒；
3. 两种都失败，回到《唤醒失败的原因排查》。

局域网里稳定之后，再按《外网唤醒与路由器端口转发》去弄出门在外唤醒的事，别一上来就配外网。设备多了以后想定时或条件触发，看《Tasker自动化与设备清单备份》。
