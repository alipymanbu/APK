## 一、远程功能清单

绑定车辆后，App 里能远程做的事主要有这些（具体到你的车有哪些，以 App 内实际显示为准）：

| 功能 | 你能用它做什么 |
| --- | --- |
| 远程车辆信息 | 查看点火状态、门锁状态、车窗、胎压、续航、油耗/电耗等车况 |
| 远程车门锁止/解锁 | 忘带钥匙时用手机锁车、解锁 |
| 远程发动机启动 | 提前着车，配合空调预启动，冬夏上车前先把温度调好 |
| 远程控制车窗和天窗 | 在楼下发现车窗没关，用手机关上 |
| 气候预控制 | 设定出发时间，让车辆按时提前调节车内温度 |
| 远程闪光鸣笛 | 在大停车场找车，让车闪灯鸣笛报告位置 |
| 车辆定位 | 在地图上查看车辆当前位置、停车位置提示 |
| 地理围栏 | 车辆进出你划定的区域时收到通知 |
| 被盗通知和车辆损坏提示 | 车辆报警、疑似碰撞时手机收到推送 |
| 遥控泊车助手 | 部分车型支持在车外用手机控制泊入/泊出，这个功能以独立应用形式提供 |

两个使用上的判断依据：

- **状态类功能基本随到随看**，车况数据由车辆定期上报，你打开 App 就能读。注意上报不是实时的——远程车辆信息的数据大约每两分钟上报一次，刚关上车门马上看 App，门锁状态可能还是旧的，等两三分钟刷新再看，别当成故障；
- **指令类功能（解锁、启动、关窗）走云端下发**，从按下按钮到车辆执行有几秒到几十秒延迟，且车辆必须停在有移动网络信号覆盖的地方——地下二层车库发指令没反应，多半不是坏了，是车收不到信号。

## 二、这些功能不是默认全开

用之前过一遍这张检查表，缺一项对应功能就不可用：

1. **车辆已绑定**，账号里能看到你的车（步骤见 [账号注册与车辆绑定.md](账号注册与车辆绑定.md)）；
2. **互联服务已激活且在有效期内**，中国大陆的互联服务免费期一般为自激活起三年，到期后对应服务会停，续期政策以官方条款为准；
3. **敏感功能完成过身份验证**，远程解锁、部分定位服务首次使用会要求验证；
4. **车辆本身支持该功能**，同一辆车不是所有功能都有，例如遥控泊车只有配备相应硬件的车型可用。

## 三、远程发动机启动的注意点

远程启动是使用频率最高、也最容易出问题的功能：

- 发动机远程运转期间，车内必须没有人，这是安全设计的前提，不要试图在有人锁车内时远程启动；
- 部分车型对远程启动的时长有限制，到时自动熄火，具体时长以车辆手册为准；
- 冬天用它预热车辆时，确保停车地点通风，不要在密闭车库内长时间远程运转发动机；
- 指令发出后如果车没有响应，先确认车辆网络信号，再查 App 里的服务状态，不要连续重发。

## 四、找车与防盗

「车辆定位 + 闪光鸣笛」组合解决大停车场找车问题；「地理围栏 + 被盗通知」则适合把车借给别人或停放在公共场所时盯状态。被盗通知触发时，先通过 App 确认车辆状态，真发生盗抢应直接报警，由警方处理，App 的通知记录可以作为参考信息。

要用手机直接当钥匙、或人站在车外控制泊车的，属于近场功能，条件与授权流程单独整理在 [数字钥匙与遥控泊车使用条件.md](数字钥匙与遥控泊车使用条件.md)。电动车特有的充电类远程功能（远程启停充电、找桩）单独整理在 [充电与电动车功能.md](充电与电动车功能.md)；功能突然不可用时先确认 [服务到期续费与互联商店购买.md](服务到期续费与互联商店购买.md) 里的服务期限，再按 [常见问题与故障排查.md](常见问题与故障排查.md) 排查。
