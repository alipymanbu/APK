## 一、数字钥匙：手机当车钥匙用

数字钥匙把手机变成实体钥匙的替代品：靠近车辆自动解锁、上车直接启动，还能把钥匙分享给家人并随时撤销。这是独立于远程控车的一项功能，条件也单独列：

| 条件 | 说明 |
| --- | --- |
| 车辆配备 | 融合 UWB 超宽带、蓝牙、NFC 三种技术，只有配备相应硬件的车型支持（中国新款长轴距 C 级等在售车型已官方宣传搭载）；支持车型以官方兼容性查询页或经销商确认为准 |
| 手机兼容 | 不是所有手机都行。国际版兼容性页列的是 Apple、Samsung、Google 的特定机型，中国大陆支持的设备清单可能不同，设置前先查 |
| 钥匙载体 | 存在手机自带的卡包/钱包里（如 Apple Wallet），不装额外 App；Apple Watch 也可用 |
| 账号 | 需要已注册 Mercedes me ID 并完成车辆绑定 |

激活流程的通用要点（以车机与手机当时的提示为准）：

1. 车辆点火开启，手机放在车内无线充电托盘上；
2. 在车机或应用里选择数字钥匙，按提示配对；
3. 配对成功后钥匙写入手机钱包，之后带着手机靠近车辆约 4 米内即可被识别、解锁；
4. 分享给他人：在应用内发起分享，对方需为兼容手机；授权可随时单独撤销。

由于钥匙依赖手机电量与系统，出门远行时仍建议把实体钥匙带在身上作为兜底。

## 二、遥控泊车助手：人在车外控制泊车

遥控泊车解决的是「停进去了人出不来」的场景：车位太窄，先下车，再用手机控制车辆自动泊入或泊出。注意它是一个**独立应用**（遥控泊车助手 App），不是主应用里的按钮。

使用前提与流程：

1. 车辆配备主动泊车辅助及相应硬件，支持车型有限；
2. 需要 Mercedes me 账号、与车型匹配的遥控泊车助手应用、一台兼容手机（具体机型清单以官方兼容性页面为准）；
3. **首次使用要在车内授权手机**：在车机的辅助/泊车设置里选择授权新设备，用应用扫描车机屏幕上的二维码完成授权；一部车可授权多台手机，不用了可以随时解除授权；
4. 泊车时先在车内选好泊入方式并挂 P 熄火下车，之后在车外打开应用连接车辆，按提示控制泊入/泊出。

安全边界（泊车过程中系统会自己执行，你要做的是守住这几条）：

- **钥匙随身带**：泊车过程中按一下实体钥匙的按钮就能中止并刹停车辆，这是最可靠的急停手段；
- 泊车过程中车辆保持锁定，车内不能有人和宠物；
- 注意车位上方障碍（低垂管道、限高杆）——系统测距以地面障碍为主，上方东西测不全；
- 系统检测到故障或超出能力范围会自动刹停、挂 P、拉手刹，手机上会收到中止提示，此时接管车辆即可；
- 公开道路上使用要遵守当地交规，操作者须具备驾驶资格。

## 三、这两项功能用不了，先查什么

按命中率排序：

1. **车型没配硬件**——数字钥匙与遥控泊车都是高配硬件门槛的功能，老车型与低配车型直接没有，查配置表或问经销商；
2. **手机不兼容**——尤其数字钥匙对手机 NFC/UWB 有要求，换一台兼容手机试试即可分辨；
3. **手机没授权**——遥控泊车换新手机后要重新在车内授权；
4. **互联服务到期**——服务停用会影响相关功能，续费情况见 [服务到期续费与互联商店购买.md](服务到期续费与互联商店购买.md)；
5. 应用版本过旧——更新到最新版再试。

远程功能（人不在车边也能用）与这两项近场功能的区别，见 [远程控车功能详解.md](远程控车功能详解.md)；账号与绑定问题见 [账号注册与车辆绑定.md](账号注册与车辆绑定.md)。
