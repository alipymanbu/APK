## 一、免费期怎么算

按奔驰中国的互联服务条款，中国大陆的 Mercedes me 互联服务**免费期为自服务激活起三年**。注意三点：

- 起算点是**激活时间**，不完全等于提车时间——车放了一段时间才激活的，免费期从激活那天往后数；
- 免费期到期前，官方通常会发短信提醒续费（多位车主反馈过这类「关怀」短信），收到短信可以先去商店核对自己车的到期时间；
- 免费期覆盖哪些服务因车型与配置而异，你的车具体在免费期里包含什么，以绑定车辆后 App 与商店里显示的清单为准。

## 二、到期后哪些功能会停

到期受影响的主要是**远程控车与在线增值类功能**：远程解锁/锁止、远程启动发动机、远程关窗、车辆定位查看等。车上的基础机械功能不受任何影响，应急类服务（如紧急呼叫）按官方说明独立提供，具体边界以官方条款与客服答复为准。

判断自己是不是到期了，最直接的证据链：

1. 以前能用的远程功能突然整体不可用（不是某个功能，是一批）；
2. App 或短信里收到服务到期提示；
3. 在互联商店（见下节）登录后能看到服务的剩余期限。

三项都吻合就是到期了，而不是 App 出故障——别急着重装。

## 三、互联商店里有什么

续费和加购都在**梅赛德斯-奔驰互联商店**（官网 `https://www.mercedes-benz.com.cn/mmc/index.html`，也可从应用内进入）完成。截至 2026-09 商店页面的主要商品标价如下，**价格与商品随时可能调整，下单前以商店页面为准**：

| 商品 | 标价（截至 2026-09） |
| --- | --- |
| 远程控制 | 458 元/1 年起 |
| 远程温控（发动机启动） | 458 元/1 年起 |
| 远程控制（含远程温控） | 798 元/1 年起 |
| 高德导航续订单品（NTG6/NTG7） | 698 元/1 年起 |
| 高德+远程组合包（NTG6） | 1158 元/1 年起 |
| 互联组合包（NTG7 / Gen20x i2） | 1298 元/1 年起 |
| 奔驰充电星随行 | 498 元/1 年起 |
| 声音世界 / 光影世界 | 198 元/1 年起 |
| 后轮主动转向（数字化选配，限指定车型） | 4998 元/1 年 |

几点选购判断：

- 「元/1 年起」的「起」表示按车型、车机代次不同价格上浮，先在商店绑定车辆看自己车的实价；
- **远程控制与远程温控是两个独立商品**，只想冬天远程热车就买远程温控，要解锁、定位、关窗全套再买远程控制或组合包；
- 导航类商品与车机代次（NTG6/NTG7/Gen20x 等）挂钩，买错代次用不了；
- 2022 年媒体报道过的旧价格（如远程启动一年 398~498 元）与现行标价不同，说明这套定价一直在调整——旧文章、旧攻略里的价格不要直接当真。

## 四、购买与自动续费要注意的事

- **计费周期自选**：月度、季度、年度等，下单时选择；
- **自动续费是默认逻辑**：协议约定到期前后会通过你绑定的第三方支付账户代扣下一周期费用，前提是你签过免密支付协议。不想自动续的，要么不开免密，要么到期前手动关闭，避免被动扣款；
- 购买后服务自动附加到车辆，一般无需再去经销商开通；
- 商店相关的订单、退款、扣费问题打互联商店客服 **400-660-4066**；互联服务本身的开通与故障打互联服务中心（号码见 [常见问题与故障排查.md](常见问题与故障排查.md)）。

## 五、断了再续，数据还在吗

服务到期停用后再续费，车辆绑定关系、账号资料都保留，重新开通后远程功能恢复，一般不需要重新绑车。若到期时间过久导致车机端也需要更新，按商店或客服指引操作即可。

功能不可用拿不准是不是到期，先过一遍 [常见问题与故障排查.md](常见问题与故障排查.md) 的排查表；远程功能的具体用法见 [远程控车功能详解.md](远程控车功能详解.md)。
