## 一、拨弦了屏幕没反应、不出音名

按顺序过这五步，多数情况能定位到原因：

1. **麦克风权限**——设置 → 应用 → DaTuner → 权限，确认麦克风是「允许」。权限被拒时应用听不到任何声音，这是最常见的原因。
2. **手机麦克风别被遮挡**——手机壳、手指堵住底部麦克风孔会明显衰减拾音。
3. **靠近声源**——把手机放到琴身一米内，拨一下看底部频率数字有没有跳动；有数字跳但不出音名，说明收到的是噪音而不是乐音。
4. **换个安静处再试**——旁边有人说话、外放音乐时，信号可能被噪音盖住。
5. **插着耳机就先拔掉**——有的耳机自带麦克风，系统会把收音切到耳机上，手机本机麦克风离琴更远就更难拾音；拔掉再试能排除这一层。

它不需要联网，断网也能用；「没反应」不是网络问题。

## 二、噪音环境下识别乱跳

- **一次只拨一根弦**：两根弦同时响是乱跳最常见的来源，多个调音器资料的口径一致——单拨一根、让音自然延续，再拨下一根。
- 用**滤波锁定**锁到目标音，其余频段直接忽略（两个锁定的用法见 [乐器调音怎么用.md](乐器调音怎么用.md) 第四节）。
- 手动把左侧灵敏度条调低，让它对轻微噪音不敏感；代价是要更用力拨弦。
- 手机尽量贴近乐器，而不是贴近噪音源。

## 三、按它调准了，跟别人合还是对不上

| 先查什么 | 怎么查 / 怎么改 |
| --- | --- |
| 参考频率被改过 | 进配置看 A4 是不是 440Hz；被改成 442 等值时改回 440（改法见 [乐器调音怎么用.md](乐器调音怎么用.md) 第五节） |
| 容差太宽 | 设置里把「准了」的范围调窄，避免偏十几音分也变绿 |
| 靠耳朵不靠屏幕 | 以底部的音分数为准：0 才是正中，变绿只说明在容差内 |
| 对方乐器本身不准 | 钢琴、管乐器等固定音高乐器不能现场拧弦，需要它们先校音 |

## 四、安装时被拦、报错、装不上

| 现象 | 处理 |
| --- | --- |
| 「禁止安装来自此来源的应用」 | 按提示允许该来源（安装步骤见 [下载与安装教程.md](下载与安装教程.md) 第四节），这不是包有问题 |
| 「解析包时出现问题」 | 包没下完整，核对大小 18.91M 与 MD5 `91D6228712CB02DE6EFE0F5E51150F19`，对不上就重下 |
| 与已装版本冲突 / 签名不一致 | 手机上若装过别的渠道的 `com.bork.dsp.datuna`，签名不同会拒装：先卸掉旧的，再装这份 |
| 存储空间不足 | 安装包 18.91M，安装时需要更多可用空间，先清一下存储 |

## 五、版本对不上、要不要更新

网盘这份是 **v3.504**（存档于 2026-09-23），商店里的版本可能更新（公开版本记录里 2026 年年中已见到 `3.7.9` 这样的编号，以官方页面当时显示为准）。这个应用的版本编号有 `3.5xx`、`3.7x` 等几条不连贯的序列，**别只看数字大小判断新旧**。要追新版就用官方商店覆盖安装，包名相同可直接升级；手上这份固定版本则不会自动更新。

## 七、搜到一个同名网页版，跟这个是一回事吗

不是一回事。[datuner.com](https://www.datuner.com/) 是一个浏览器里直接用的在线调音器，它的关于页明确写着「与任何同名手机应用无关联、无背书关系」。本目录这几篇讲的都是安卓 APK（包名 `com.bork.dsp.datuna`），下载入口见 [下载与安装教程.md](下载与安装教程.md)。两者功能有重叠，但账号、设置、版本互不相通，别拿网页版的结论套到手机应用上。
