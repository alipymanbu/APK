## 一、秤面符号对照表

| 显示 | 含义 | 处理 |
| --- | --- | --- |
| `LO` | 电量不足 | 换新电池 |
| `Err` / `Er1` | 超载（量程上限 180kg / 400lb） | 立即下秤，避免损坏秤 |
| `C` | 测量过程出错 | 下秤后重新上秤再测一次 |

## 二、主页显示 Disconnected（连不上秤）

按官方 FAQ 逐项检查：

1. 手机网络可用，Fitdays 有联网权限；
2. 秤处于开机状态、手机蓝牙已开；
3. 系统版本达标：iOS 8.0 / Android 5.0 及以上；
4. 以上都对还连不上，走手动配对：`Account` → `Device` → `+` 重新找秤。

安卓手机注意：**安卓 6.0 起扫描蓝牙设备必须开着定位服务**（安卓 10.0 起还需要授权定位权限），定位一关蓝牙扫描就停，这是「明明开了蓝牙却搜不到秤」最常见的系统性原因。

有用户反馈（三星 S22）：在系统「设置 → 应用 → Fitdays → 权限」里把「附近设备（Nearby devices）」权限设为允许后解决了搜不到秤的问题，新机型可以顺手检查这一项。

## 三、测了但出不来体脂数

官方列出的检查顺序：

1. App 停在主页，别切走；
2. 光脚、脚底和秤面都干燥，站到金属电极上；
3. 数字闪烁期间保持站立 5~10 秒，直到显示 `Finished` 或数字停止闪烁；
4. 蓝牙确认已开；
5. 确认手机蓝牙连的是**这台秤**——附近有别人的秤时容易串连。

穿袜子只能测出体重和 BMI，这是原理限制，不是故障。

## 四、称重不稳定 / 两次称重不一样

1. 确认秤放在**硬、平**的地面（地毯、软垫上必不准）；
2. 翻过来看四个秤脚底部有没有粘着异物；
3. 拔掉电池重装，重启一次秤。

挪动位置或换电池后，上秤让它自动落回 `0.0` 完成校准再用。

## 五、开不了机 / 充不进电（充电款）

**电池款**：取出电池按正确方向重装；电量耗尽就直接换新电池。

**USB 充电款**：

1. 关机再重新开机；
2. 充不进电时，换一根**能正常给手机充电**的数据线试；
3. 还不行换一个充电头，或直接插电脑 USB 口试；
4. 都不行，联系购买渠道的客服走售后。

## 六、其他常见问题

| 问题 | 解法 |
| --- | --- |
| 脂肪肌肉比等数据明显不对 | 去核对用户资料的性别、身高、年龄，算出来的指标全靠这三项 |
| 8 电极型号体重多 0.2kg | 手柄要先放秤面、上秤归零后再拿起来，见[连接体脂秤与首次测量](连接体脂秤与首次测量.md) |
| 用 Instagram 登录不了 | 2020 年 6 月底起已停用，改用邮箱注册登录 |
| 找回密码 | 注册页点 `I forgot my password`，或联系客服改密 |
| 更新 App | 商店开了自动更新会自动装；没开就去 Google Play / App Store 手动查 |
| 一台秤连多台手机 | 可以，但要用不同账号、别同时测 |
| 换手机后历史记录还在吗 | 记录存在服务器，新手机登录原账号即可找回，见[换手机后数据还在吗](换手机后数据还在吗.md) |

## 七、需要网络的操作清单

这些操作离开网络做不了，遇到「点了没反应」先确认手机能上网：注册登录、新增或修改用户信息、配对/删除秤设备、修改设置项。测量数据的历史记录也是经由服务器保存的。

## 八、还解决不了：找官方反馈

- App 内渠道：`Account` → `Settings` → `Help` 提交反馈，官方称约 3 天内回复，回复后留意主页的铃铛通知和反馈历史页；
- 厂商客服：沃莱全国热线 400-138-9908（08:30-24:00），售后热线 0760-28160371（08:30-18:00）；
- 硬件本身的问题（秤体损坏、量程异常）优先走购买渠道的售后。
