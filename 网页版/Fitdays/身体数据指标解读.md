## 一、能测出哪些指标

官方 FAQ 列出的基础指标共 13 项（不同秤型号、不同语言版本会有增减，以你的秤的说明书为准）：

| 指标 | 说明 |
| --- | --- |
| 体重（Weight） | 最基础的测量值 |
| BMI | 体重与身高的比值，用来快速判断胖瘦区间 |
| 体脂率（Body fat rate） | 脂肪占体重的比例 |
| 去脂体重（Fat-free body weight） | 去掉脂肪后的体重 |
| 皮下脂肪（Subcutaneous fat） | 皮下储存的脂肪 |
| 内脏脂肪（Visceral fat） | 围绕内脏的脂肪 |
| 体水分（Body water） | 体内水分占比 |
| 骨骼肌率（Skeletal muscle rate） | 骨骼肌占体重的比例 |
| 肌肉量（Muscle Mass） | 肌肉的总重量 |
| 骨量（Bone mass） | 骨骼的估算重量 |
| 蛋白质率（Protein rate） | 蛋白质占比 |
| 基础代谢（BMR） | 静息状态下一天消耗的热量估算 |
| 体年龄（Body age） | 按身体数据折算出的「相当于多少岁」 |

部分型号还能测到更多项目（如心率、身体平衡），官方 FAQ 明确：**只有秤本身支持的功能，App 里才会出现对应数据**，有没有以你的秤为准。

带手柄的 8 电极型号更进一步：除了全身数据，还能给出**身体节段的脂肪与肌肉量**（开发者介绍里标注为「8 电极测脂，精准测量身体节段脂肪与肌肉量」），具体分哪些节段以秤型号为准；测量时多一步手柄操作要点，见[连接体脂秤与首次测量](连接体脂秤与首次测量.md)。

## 二、年龄限制：什么年纪能测什么

体脂类数据并非全年龄段都开放，官方给出的适用范围与限制：

| 年龄段 | 能测什么 |
| --- | --- |
| 6 岁以下 | 只有体重，没有 BMI 和体脂率等数据 |
| 6~10 岁 | 体重 + BMI，没有体脂率等数据 |
| 11~70 岁 | 完整指标（官方标注的适用区间） |
| 70 岁以上 | 超出官方标注的适用区间，数据仅供参考 |

孕妇不建议使用体脂测量；体内有心脏起搏器等医疗植入物的人群也不适用（体脂测量会有微弱电流经足底通过），这两条是官方说明书的警告项。

## 三、数据不准？先排查这几个原因

官方 FAQ 点名的几个常见原因，按出现频率排：

1. **个人资料填错** —— 性别、身高、年龄任一项不对，脂肪肌肉比等计算类指标就会整体偏移，去 `Account` 里核对目标用户的资料；
2. **穿袜子上秤** —— 只能出体重和 BMI，想看体脂必须光脚；
3. **脚底或秤面有水** —— 干燥的足底接触是测量的前提；
4. **数字还在闪就下秤** —— 等显示 `Finished` 再动，否则手机收到的数据不全；
5. **蓝牙连到了别的秤** —— 附近有别人的秤时会串，见[常见问题与报错排查](常见问题与报错排查.md)。

## 四、测量之外的辅助功能

开发者提交的应用商店介绍里还列了几个配套功能（口径来自官方开发者页面，具体入口与可用性随版本有增减，以你手机上的实际界面为准）：

| 功能 | 介绍口径 | 适合谁 |
| --- | --- | --- |
| 饮食建议 | 三餐食谱、营养摄入推荐 | 减脂期不知道怎么吃的人 |
| 运动建议 | 自定义减脂计划、看运动燃脂效率 | 有明确减脂目标的人 |
| 饮水助手 | 定点提醒、饮水记录 | 想养成喝水习惯的人 |
| 界面主题 | 15 种应用颜色可选 | 个性化偏好 |

这些功能不依赖新硬件，属于 App 内的记录与提醒工具；核心数据仍来自秤，测量本身的要点见[连接体脂秤与首次测量](连接体脂秤与首次测量.md)。

## 五、怎么用这些数据

单次数据只反映那一刻的状态，真正有意义的是趋势：同一时间段的对比、减脂期的曲线变化，操作见[历史记录与数据对比](历史记录与数据对比.md)；数据也能同步到 Apple Health 等平台统一管理，见[数据同步到健康平台](数据同步到健康平台.md)。

最后是官方的统一口径：所有数据仅供体重管理、长期运动与健身监测参考，**不能作为医疗诊断或治疗的依据**，有医疗需求请咨询医生。
