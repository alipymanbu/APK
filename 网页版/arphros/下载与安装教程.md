## 一、先确认你要装哪个平台

Arphros 官方提供三个平台的版本，获取渠道不一样：

| 平台 | 官方渠道 | 说明 |
| --- | --- | --- |
| Android | Google Play、官网下载页 | 商店版可自动更新，APK 版需手动更新 |
| Windows | 官网下载页、itch.io 页面 | 提供 EXE 安装包与 ZIP 免安装包 |
| Linux | 官网下载页 | 提供 TAR.GZ 压缩包 |

官网下载入口：[arphros.kjn.in.th/download](https://arphros.kjn.in.th/download)；Google Play 商店页：[play.google.com/store/apps/details?id=com.kidjanate.arphros](https://play.google.com/store/apps/details?id=com.kidjanate.arphros)。Windows 版只能从官网或 itch.io 拿，不上商店。

从网盘资源安装的用户走下面第二、三节的安卓 APK 流程即可，装完与商店版是同一个应用（包名 `com.kidjanate.arphros`）。

## 二、网盘资源这一版是什么

网盘里的 Arphros 安装文件资源对应 **v2.4f3**，关键信息如下，装完可以用这些数据核对一下包对不对：

| 项目 | 值 |
| --- | --- |
| 版本号 | 2.4f3 |
| 包名 | `com.kidjanate.arphros` |
| 安装包大小 | 96.74 MB |
| MD5 | `95CA780AD379BC4EC5EE55B5AF54F22F` |

两点注意：

- **版本可能落后于官方最新**。官方渠道在持续更新，写作时 itch.io 已提供 2.4f7，官方在更新日志里称其为「Arphros v2 的最终稳定版」（以官方页面为准），各版本更新明细见官方开发日志 [rhitomaic.itch.io/arphros/devlog](https://rhitomaic.itch.io/arphros/devlog)。2.4f3 与最新版的核心玩法、编辑器功能一致，但社区里用新版做的关卡个别效果可能依赖新触发器，装旧版玩不到完整效果。
- **系统要求**：2.4f3 的资源资料标注为 Android 5.2 以上；第三方应用商店对 2.4f7 版标注 Android 7.0+。以你实际安装时能否运行为准，老机型装最新版遇到闪退时可退回旧版试试。

## 三、安卓安装步骤（APK）

1. 从 [Arphros 安装文件资源（夸克网盘）](https://pan.quark.cn/s/da4e55644fd8)把 APK 文件转存到自己网盘后下载到手机，或直接下载到本地。
2. 点开下载好的 APK。首次安装系统会提示「不允许安装未知来源应用」，按提示允许浏览器或文件管理器安装应用（不同品牌手机的入口名称略有差异，一般在设置的安全或应用权限里）。
3. 回到安装界面点「安装」，等待完成。安装包约 97 MB，加上游戏运行数据，建议预留 1 GB 以上存储空间。
4. 装完打开应用。首次进入需要加载资源，等待主界面出现即可。

MD5 校验方法（可选）：把下载好的 APK 用文件管理器的属性查看，或用校验工具算一次 MD5，与第二节的值比对，一致说明包完整。

## 四、首次启动：账号怎么选

进入主界面前会有登录选择，共三种：

- **注册新账号**：邮箱注册即可，推荐。发布关卡、评论、积分排行榜这些社区功能都需要账号。
- **已有账号直接登录**。
- **游客模式（Guest）**：不注册也能进游戏、玩关卡、用编辑器，但需要登录身份的功能用不了（比如评论、积分排行），想参与社区时再补注册即可。

登录后主界面能看到：街机（Arcade，玩社区关卡）、编辑器（Editor，自己做关卡）、排行榜（Leaderboard）、收件箱（Inbox）、设置（Settings）、新闻（News）等入口。各个入口的用法见[社区关卡玩法与积分.md](社区关卡玩法与积分.md)和[关卡编辑器入门.md](关卡编辑器入门.md)。

## 五、安装后建议先做的三件事

1. **进设置检查音画偏移**：节奏游戏对音画同步敏感，如果试玩时音乐和判定对不上，去设置的 Audio 里调 Global Offset，具体见[设置调优与常见问题.md](设置调优与常见问题.md)。
2. **切界面语言**：Arphros 支持英语与简体中文界面，中文用户可在设置里切换。
3. **开编辑器自动备份**：打算做关卡的话，先在设置的 Editor 区把 Auto-Backup Project 打开并设一个合适的间隔，防止编辑进度丢失。

最后一句提醒：Arphros 官方声明与《跳舞的线》（Dancing Line）及 Cheetah Games 无隶属关系，它是独立的同人系节奏游戏；游戏内的社区规则（尤其音乐版权）在发布关卡前务必读一遍，见[自制关卡发布与社区规则.md](自制关卡发布与社区规则.md)。
