## 一、新建一个关卡

在主界面点 Editor 进入关卡创建页，先填一组基础信息。这些信息以后随时能改（编辑器里 Edit > Level Info），但发布时会直接展示给玩家，建议一开始就填规范：

| 选项 | 可选值 | 填写建议 |
| --- | --- | --- |
| Level Name | 自由文本 | 关卡标题，玩家第一眼看到的名字 |
| Description | 自由文本 | 介绍关卡内容；给音乐作者署名、写更新记录也可以放这里 |
| Difficulty | Auto / EZ / Normal / Hard / Expert | Auto 会根据关卡内容自动生成，但不太准，官方建议自己选 |
| Genre | EDM / Pop / Anime / Classic / Other | 拿不准就选 Other |
| Theme | Instrumental / English / Japanese / Korean / Other | 拿不准就选 Other |
| Change Banner | 图片 | 推荐尺寸 1280×384 px，其他尺寸可能被缩放变形或裁切 |
| Music Artist / Title | 文本 | 用了别人要求署名的音乐，必须在这里或简介里写明 |

填完保存就进入编辑器主界面。编辑过程中系统可能要求你先保存项目才能继续某些操作（比如导入音乐），属正常流程。

## 二、编辑器界面总览

进入编辑器后，界面分四块：

- **顶部标签（Level Tabs）**：Manage / Edit / Assets / Objects / Triggers / Extra 六个标签，是编辑器的核心，详见下文。
- **Level Information Tab（项目信息）**：Edit > Level Info 打开，管雾效、天空盒、环境光、相机类型这些全局观感。相机类型有三档：Stable Camera（v2 起，控制项最多）、Weird Camera、Old Camera（前身 CTTS 的老系统，兼容旧关卡用）。
- **Manage Level Tab**：对象列表（Hierarchy）、底部工具条、试玩控制、Inspector 属性面板都在这里。
- **Mobile Buttons（仅安卓）**：屏幕下方的相机升降按钮、Move/Gizmos 模式切换、撤销重做按钮。

## 三、六个标签各管什么

### Manage 标签（文件操作）

Open（打开项目）、Save（保存）、Backups（备份列表）、**Import Song（导入音乐）**、How to Use?（跳转官方文档）、Export as Playable / Export Project（导出）、Exit Editor（退出，退出前会提示保存）。导入音乐就用这里的 Import Song。

### Edit 标签（编辑操作）

撤销/重做；复制、粘贴、复制副本（Duplicate）、删除；Focus on Object（镜头怼到选中对象跟前看细节）；Reset Camera（镜头归位）；还有 Level Info 和 Settings 两个入口。

### Assets 标签（素材）

Sprites（贴图）、Models（模型）、Materials（材质，可自建）、Scripts（脚本，可创建可导入）。脚本这一项官方单独维护了一套说明：Arphros 脚本语言基于 Lua，配合脚本触发器用来移动、缩放、旋转对象；开发者 API 文档还提到移动游戏窗口的能力仅 Windows 版支持（[arphros.readthedocs.io](https://arphros.readthedocs.io/en/latest/Code/)）。

### Objects 标签（放置物体）

- **基础形体**：Empty（空对象）、Cube、Plane、Sphere、Cylinder、Half Pyramid、Capsule。
- **特殊对象**：Obstacle（碰到即判失败的障碍物）、Point Light（点光源）、Text（3D 文字）。

### Triggers 标签（触发器）

触发器是让关卡「动起来」的关键，按作用对象分四类：

| 类别 | 触发器 | 用途 |
| --- | --- | --- |
| 对象 | Move / Scale / Rotate / Visibility / Color / Material / Stop | 移动、缩放、旋转、显隐、变色、换材质；Stop 用来停掉另一个触发器 |
| 玩家 | Jump / Speed / Teleport / Direction / Freeze / Tail / Sequence / Tap | 跳跃、变速、传送、转向、定身、清尾迹、按序调用、点按响应 |
| 相机 | Camera / Shake / FOV / Glitch | 转镜头（仅 Stable Camera）、震屏、变焦、故障特效 |
| 世界 | Fog / Environment / Gravity | 雾、环境色、重力 |

### Extra 标签（起点与终点）

Start Position（设置出生点，配合试玩用）、Finish Trigger（终点，触发即过关）、Level Analyzer（统计场景里各类对象数量）。

## 四、Inspector：改一个对象的属性

在 Hierarchy 里选中对象后，Inspector 面板可以改：

- **Transform**：位置、缩放、旋转；Space Type 决定相对世界还是相对屏幕移动。
- **Visibility**：显示、隐藏或移除。
- **Obstacle Type**（重点）：None（不是障碍）、**Wall**（撞上判失败，有撞击音）、**Pass-Through**（穿过判失败，适合做虚空）、**Water**（穿过判失败，有落水音）。你放的每个方块算不算致命障碍，就靠这一项区分。
- **Rendering**：材质与外观微调。

## 五、试玩与保存

- 底部工具条或 Manage 里的 **Play** 随时试玩当前关卡（不用发布），Stop 退出试玩。
- 试玩前可以用 Extra > Start Position 在当前位置设出生点，调试中后段就不用从头跑。
- Trigger Viewing 可以控制触发器图标的显示方式（隐藏 / 全显 / 碰到才显 / 碰过之后显），排查触发器问题时很有用。
- **Ctrl + S 随手保存**，再把设置里的 Auto-Backup 打开，双保险；备份策略与导出给别人，见[关卡备份与导出.md](关卡备份与导出.md)。

## 六、手机端按钮与电脑端快捷键

安卓端屏幕下方有一排专用按钮：相机升高/降低；Move Mode（方便转镜头）与 Gizmos Mode（方便选改对象）切换；移动/旋转/缩放等工具按钮；撤销/重做。工具按钮只在 Gizmos 模式且选中对象时生效。

电脑端快捷键（同样要求 Gizmos 模式下选中对象的部分已标注）：

| 快捷键 | 作用 |
| --- | --- |
| 右键拖动 | 旋转镜头 |
| 左键 | 选择对象 |
| Ctrl + S | 保存 |
| I / O / P | 开始 / 暂停 / 停止试玩 |
| Alt + C / V / D | 复制 / 粘贴 / 复制副本（需选中对象） |
| Shift + Z / Shift + Y | 撤销 / 重做 |
| 1 / 2 / 3 | 移动 / 旋转 / 缩放（需选中对象） |

## 七、2.4f7 版编辑器有什么新东西

网盘资源这版是 2.4f3，而官方最新版 2.4f7（v2 最终稳定版）在编辑器层面有几处实打实的变化，升级前知道差异能少走弯路（明细见官方开发日志）：

- **复制关卡会生成新 ID**：想做同款不同版时直接复制，不用从零搭。
- **编辑器可显示音频时间**：新增的文字信息能显示当前音频时间（ATime）、计偏移后的音频时间（OTime）、玩家状态与接地检测状态——对拍对轨时比纯靠耳朵准。
- **撤销/重做快捷键**（Shift + Z / Shift + Y）修掉了在输入框里打字时误触的问题。
- **导出工程修复**：此前版本导出工程不含对象、脚本等元数据，2.4f7 起才完整包含，详细影响见[关卡备份与导出.md](关卡备份与导出.md)。

如果你在 2.4f3 上找不到上面某个功能，不是你操作错了，是版本没到。

## 八、新手推荐路线

1. 先建一个只有一条直路 + 几个 Wall 障碍的关卡，走通「导入音乐 → 放对象 → 设终点 → 试玩」的完整流程。
2. 再加 Move 触发器让某个物体随节奏动，加 Camera 触发器转镜头。
3. 想研究别人怎么做，去街机里找 Featured 关卡，用关卡信息页的克隆（Clone）按钮把别人的关卡复制一份拆开看，见[社区关卡玩法与积分.md](社区关卡玩法与积分.md)。
4. 做完想发布，先读[自制关卡发布与社区规则.md](自制关卡发布与社区规则.md)，尤其音乐版权那部分。
