## 一、设置页分区速查

主界面 Settings 进设置，按分区列在这里（只列调过会明显影响使用的项）：

| 分区 | 关键项 | 说明 |
| --- | --- | --- |
| Graphics | Quality | 画质档位，**卡顿先调它，选 low** |
| Graphics | Resolution / Screen Scale / Target FPS | 分辨率、画面缩放、目标帧率 |
| Graphics | Fullscreen Mode | 全屏开关（主要影响桌面版） |
| Graphics | Post-Processing | 后处理总开关：Bloom、Motion Blur、Ambient Occlusion、Depth of Field、Chromatic Aberration、Color Grading、Vignette 七项可单独关 |
| Audio | Music (Menu) / Music (In Game) / SoundFX | 菜单音乐、关卡音乐、音效三个音量 |
| Audio | **Global Offset** | 全局音画偏移，不同步就调它（见下） |
| Editor | Disable Fog in Level Editor | 编辑器里关雾，低配机开这个能明显提速 |
| Editor | Auto-Backup Project / Interval | **自动备份开关与间隔**，做关卡必开 |
| Editor | Open Project Info by Default | 新建关卡时自动打开项目信息页 |
| Interface | Tablet Mode | 小屏设备的界面模式，开编辑器会启用摇杆控制 |
| Interface | Editor UI Scale | 编辑器按钮、下拉框的大小 |
| Interface | Button Mode | Hold（按住）与 Quick（点按）两种按键判定方式 |
| Data | Migrate Old Data / Clear Saved Levels / Reset | 旧数据迁移、清空本地已存关卡、恢复默认设置 |
| About / Feedback | — | 制作组名单与链接；游戏内反馈入口 |
| Experimental | — | 实验性功能，官方标注不稳定，自行斟酌 |

## 二、音画不同步：两层偏移分开调

不同步分两层，先判断是哪层：

- **所有关卡都不同步** → 调 Audio 里的 **Global Offset**。判断方法：音乐慢半拍就调小，音效快半拍就调大，边打边试。
- **只有某一个关卡不同步** → 在那个关卡的信息页右侧调该关卡单独的 **music offset**（玩法见[社区关卡玩法与积分.md](社区关卡玩法与积分.md)）。

另外把 SoundFX 音量开大一些对踩点有帮助——判定音效越清楚，偏差越好判断。

## 三、卡顿处理顺序（从省事到彻底）

1. Graphics > Quality 调到 low。
2. Post-Processing 整个关掉（这七项特效单独关也行，Bloom 和 Motion Blur 最吃性能）。
3. Resolution 和 Screen Scale 降一档。
4. Target FPS 设低一点（锁定 30/60），帧率稳比高重要。
5. 只在编辑器里卡的话，开 Disable Fog in Level Editor，再把 Inspector 里不用的子类目折叠（设置里有 Hierarchy / Inspector Closed by Default 两项）。

## 四、游客模式能干什么、不能干什么

- **能**：玩关卡（包括下载）、进编辑器做关卡、本地试玩、改设置。
- **不能**：评论、积分与排行榜入账等需要账号身份的功能；部分界面元素（如关卡评论区）对游客直接不显示。

游客模式做的关卡如果之后注册了账号，建议重新登录后再发布，确保关卡挂在你的账号名下。

## 五、数据与存储相关

- **Clear Saved Levels**：你玩过的关卡会缓存在本地（第一次玩才需要下载），这个设置一键清空。换机、腾空间、缓存出问题时用。本地关卡工程怎么备份、怎么导出，见[关卡备份与导出.md](关卡备份与导出.md)。
- **Migrate Old Data**：Arphros 更换街机系统后旧数据不自动继承，老玩家用这项把旧街机数据迁过来。
- **Reset to Default Settings**：设置调乱了恢复出厂。
- 隐藏游戏水印（Hide Arphros Watermark）是**支持者（supporters）专属**设置项，普通账号看不到效果。

## 六、找官方反馈的三条路

1. **游戏内反馈**：设置 > Feedback，可以直接提交，能勾选附带设备信息——报卡顿、闪退类问题建议带上。
2. **Discord 社区**：官方 Discord 是最活跃的求助渠道，关卡被误下架、账号问题都适合在这里问，入口见官网 [arphros.kjn.in.th](https://arphros.kjn.in.th/)。
3. **邮件**：官方在下载页给出的联系邮箱是 `arphros@gmail.com`。

另外账号层面有一点值得知道：2.4f7 起可以直接在游戏内更换邮箱并触发激活邮件（官方更新日志），改完记得去新邮箱收信完成激活。

官方关卡编辑器文档在 [four-devs.gitbook.io/arphros-docs](https://four-devs.gitbook.io/arphros-docs)，游戏内 Manage 标签的 How to Use? 按钮跳转的就是它。

装机环节的问题（安装失败、来源权限、版本选择）回[下载与安装教程.md](下载与安装教程.md)对照排查；编辑器操作细节见[关卡编辑器入门.md](关卡编辑器入门.md)。
