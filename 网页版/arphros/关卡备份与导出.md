# Arphros 关卡备份与导出

> 做了几十个小时的关卡丢不起：本篇讲 Arphros 关卡数据存在哪、自动备份怎么开、导出可玩文件与完整工程的区别，以及换设备前该做什么。

## 一、关卡数据分两类，先分清

你手里的 Arphros 数据其实是两摊，丢的方式不一样：

| 数据 | 是什么 | 存在哪 |
| --- | --- | --- |
| 玩过的关卡缓存 | 街机里下载过的社区关卡 | 本地，设置里 Clear Saved Levels 一键清空 |
| 自己的关卡工程 | 你在编辑器里做的项目 | 本机——官方提供的保存、备份、导出全是本地文件操作 |

两摊都只在你设备上。发布到社区的关卡（见[自制关卡发布与社区规则.md](自制关卡发布与社区规则.md)）才有服务端留存，所以**没发布的工程只有你设备上那一份**。

## 二、三道备份防线

编辑器 Manage 标签（界面说明见[关卡编辑器入门.md](关卡编辑器入门.md)）加上设置页，一共给你三道防线：

1. **随手 Save**：编辑器里 Ctrl + S（电脑端）。做触发器、改材质这类大改动前后各存一次。
2. **Auto-Backup 自动备份**：设置 > Editor 里的 Auto-Backup Project 开关和 Auto-Backup Interval 间隔。它解决的是「崩溃 / 闪退前忘了存」，间隔别设太长。
3. **Backups 备份列表**：Manage > Backups，罗列可用的历史备份，改崩了从这里回滚。

## 三、Export as Playable 和 Export Project 不是一回事

Manage 标签下两个导出按钮，用途不同：

- **Export as Playable**：导出可直接游玩的关卡文件——把成品发给朋友本地玩、或留一个「定稿快照」用这个。
- **Export Project**：导出完整工程，拿到的人能继续编辑。

一个与版本直接相关的坑：官方 2.4f7 更新日志明确提到，**此前版本导出工程时对象、脚本等元数据不会包含在内，2.4f7 起才包含**。也就是说在网盘资源这版 2.4f3 上用 Export Project 之前，先想清楚用途——要做跨版本交接，升级到官方最新版再导出更稳（版本说明见[下载与安装教程.md](下载与安装教程.md)）。

## 四、旧格式与新数据迁移

- 官方文档提到旧关卡使用 `.popy` 格式，编辑器触发器里的 Legacy 相机就是为兼容这批旧关卡保留的。拿到老关卡文件打不开或表现不对，先怀疑版本与格式差异。
- 设置 > Data 里的 **Migrate Old Data** 用于把旧街机系统的数据迁到新街机系统，老玩家更新后第一次进游戏建议跑一次。

## 五、换设备前的三步

1. 新设备先装好 Arphros（官方未说明工程文件的跨版本兼容细节，建议两台设备用相近版本，装哪版见[下载与安装教程.md](下载与安装教程.md)）。
2. 旧设备上把要带走的关卡用 Export Project 导出并转移到新设备。
3. 新设备导入工程后先从头试玩一遍，确认触发器与音乐对位没有漂移，再用设置里的 Global Offset 微调（调法见[设置调优与常见问题.md](设置调优与常见问题.md)）。
