## 一、装之前先核对这份包

Hanime 是安卓端的动漫播放应用，多数商店页面把它列为「Hanime动漫」，开发者登记为长沙小玖玖信息技术有限公司。内容走在线播放，安装包本身只有二十几 MB。

网上搜「Hanime」会带出大量版本号、体积各不相同的下载页，那是各渠道在不同时间收录的版本，跟网盘里这份不一定是同一个。整套文档里出现的版本信息一律以网盘这份安装包的登记信息为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Hanime（商店页面多列为「Hanime动漫」） |
| 版本号 | 2.2.6 |
| 包名 | `aidqwn.jinskd.dfb1jwsd.woxqlc` |
| 安装包体积 | 23.84 MB |
| MD5 | `33D92193764950E85578877714149E38` |
| 适用平台 | 安卓（手机端 APK） |
| 系统要求 | 登记信息标注「安卓系统 5.2 以上」 |
| 开发主体 | 长沙小玖玖信息技术有限公司 |
| 信息日期 | 2026-09-23 |

装之前核对三件事：

- **认包名，别只认名字。** 搜「Hanime」会同时带出包名各不相同的近名应用，包名对不上就不是同一份包。
- **这是安卓 APK，iPhone 装不了。** 本篇只覆盖安卓手机。
- **系统要求按登记口径判断。** 上表标注的是「安卓系统 5.2 以上」，近几年的安卓手机基本都满足；装不上或一打开就退，按 [打不开与播放卡顿解决办法.md](打不开与播放卡顿解决办法.md) 排查。

另外提醒：不同渠道对这款应用的分级标注并不一致，个别渠道标为仅限成年人使用，请结合自身情况与当地法规判断是否使用。

系统要求的标注也各渠道一套说法：有的下载页写「安卓 3.6 以上」，有的写「4.0 以上」，网盘这份登记的是「5.2 以上」。这类标注本就粗糙，判断能不能装以实际安装结果为准，装不上时按 [打不开与播放卡顿解决办法.md](打不开与播放卡顿解决办法.md) 排查。

## 二、从网盘获取安装包

1. **打开分享页**：点开 [Hanime 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d149e0011f5d)，手机上装了夸克 App 会直接唤起，没有就在浏览器里打开。
2. **先转存再下载**：把安装包转存到自己的网盘目录，再从网盘下载到手机。分享页里直接下载也可以，但转存过的那份不依赖原分享链接，以后回头再找更稳。
3. **核对体积**：下载完看一眼文件大小，应当约 23.84 MB；体积明显偏小说明没下完整，装到一半会报「解析包错误」，重新下载一次即可。
4. **想确认文件没坏**：在电脑上算一遍 MD5，应与上表一致（大小写不敏感）：

```powershell
certutil -hashfile Hanime_v2.2.6.apk MD5
```

文件名以你实际拿到的为准，不必与示例逐字相同。

## 三、安装步骤

1. **允许安装未知来源应用**：进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，给用来打开这个 APK 的应用（文件管理器或浏览器）开权限；国产定制系统常把这一项收在「安全」或「隐私」分类里。
2. **点 APK 开始安装**：系统弹「来自未知来源」之类的提示时选继续，这是安装商店之外安装包的常规提示。
3. **留出安装空间**：安装包虽小，安装过程还要展开数据，预留几百 MB 空间比较稳妥。
4. **提示「应用未安装」时**：先确认存储够用；以前装过包名相同、来源不同的「Hanime」时，会因签名不一致装不上，卸载旧的那份再装。
5. **装好先别删安装包**：重装、换机时还能再用一次。

## 四、第一次打开

1. **同意隐私政策**：首次启动会弹隐私政策与权限说明，同意后才能进首页。
2. **不登录也能用**：浏览和播放不登录就行，大部分内容免费观看，遇到需要账号或额外条件的内容时以应用内提示为准；登录入口与登录前后的差别见 [登录与更新提醒设置.md](登录与更新提醒设置.md)。
3. **确认能联网**：内容在线加载，第一次打开一直转圈，先用浏览器确认手机能上网，还不行就按 [打不开与播放卡顿解决办法.md](打不开与播放卡顿解决办法.md) 处理。

进首页后，找番从顶部搜索框或底部「分类」开始，具体见 [搜索与分类找番方法.md](搜索与分类找番方法.md)；看中的番想留着慢慢看，见 [收藏与离线缓存方法.md](收藏与离线缓存方法.md)。
