## 一、平台层面的安全机制

按官方说明，上传到 Aptoide 的内容——无论来自开发者还是用户商店——都会经过病毒扫描，并与生态内其他商店的记录比对，判断是否存在威胁。

要补一句实话：扫描降低的是「明显恶意软件」的概率，替代不了你自己的判断。装之前看一眼评论与评分、留意应用申请的权限是否与功能匹配，这几步花不了一分钟。

## 二、为什么装的时候手机会弹警告

从非系统预装商店安装 APK 时，Android 的 Play Protect 可能提示「未经过审核」或存在风险。官方 FAQ 对此的解释是：Aptoide 兼容大量设备与较旧的系统版本，这类提示在第三方渠道安装时并不少见；从官方来源拿到安装包后，按屏幕提示继续安装即可。

处理顺序：先确认安装包来源（官方渠道，或你信任的渠道）→ 点「更多信息」→ 选「仍然安装」。对来源没把握就先不装，核对完来源再说。逐步操作见 [下载与安装教程.md](下载与安装教程.md)。

## 三、常见问题速答

| 问题 | 回答 |
| --- | --- |
| Aptoide 是什么来头 | 2011 年创立于葡萄牙里斯本的独立安卓应用商店，官方定位为开源项目 |
| 需要注册吗 | 下载与安装应用不需要账号；评分评论、开商店等社区功能需要 |
| 免费吗 | 商店本身免费，应用以免费内容为主；应用内购买走官方虚拟货币体系（AppCoins / Aptoide 余额，版本不同叫法不同，以应用内说明为准） |
| 能和 Google Play 共存吗 | 能。两者互不冲突，已经从 Play 装的应用不会被覆盖 |
| 能装在平板 / 电视上吗 | 手机、平板可用；官方另有面向安卓电视的形态 |
| 有 iPhone 版吗 | 官方称在欧盟等受支持地区提供 iOS 形态（替代应用市场）；安卓安装包装不进 iPhone，以官方页面为准 |
| 怎么更新 Aptoide 自己 | 在应用内更新，方式与更新其他应用一样，不用重新下载安装包 |
| Aptoide 自己能装旧版吗 | 能，官方明确提供旧版本下载，适合兼容性需要（给自己手上的应用降级见 [应用降级与版本回退.md](应用降级与版本回退.md)） |
| 怎么删除账号 | 用应用内的账号管理选项操作 |
| 为什么搜不到某个应用 | 商店收录有范围：先换关键词，再考虑换一家商店搜（商店网络的结构见 [自建商店与关注店铺.md](自建商店与关注店铺.md)） |
| 应用更新不及时怎么办 | 到详情页的版本列表手动检查；新版本刚发布时，各商店收录有先后 |

## 四、几个容易误判的点

- **「未知来源应用」不是病毒标记**。它只是 Android 对所有非预装渠道安装行为的统称，开了授权不代表设备安全等级变化；
- **评分低不等于应用有问题**。也可能是这家商店收录的版本老旧导致差评，翻翻评论的日期再下结论；
- **商店里的版本号和你已装的不一致**，未必是谁旧谁新——不同渠道的发布节奏不同，以版本号大小为准。
