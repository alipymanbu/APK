## 二、安卓手机：从网盘拿到安装包再安装

1. 打开上面的 Melinked 安装文件资源（夸克网盘）链接，把文件转存到自己的网盘；
2. 在夸克网盘客户端里把 APK 文件下载到手机本地存储；
3. 在手机的文件管理器里找到下载完成的 APK，点它开始安装；
4. 如果手机弹出「禁止安装未知来源应用」的提示，按提示允许来自当前文件管理器（或浏览器）的安装，再回到第 3 步；
5. 装完在桌面点开 Melinked，第一次启动会依次请求若干权限，逐个决定允许或拒绝即可。

「允许未知来源」这个开关在 Android 8.0 以后是按应用逐个授权的：你允许的是「文件管理器可以安装应用」，不是全局放开，装完也不必去改回来。

## 三、iPhone：走 App Store

iOS 版不在网盘资源里，直接在 App Store 搜「Melinked」安装即可，开发者显示为 Chengdu Xingzhendi Technology Co., Ltd.。注意两点：

- 官方 App Store 页面标注面向 iPhone（iPad 与 macOS 不在其列），免费下载、含应用内购买；
- iOS 版安装包体积与安卓不同，且随版本变化，以商店页面当时显示为准。

## 四、系统要求与权限

官方应用商店页面对当前版本标注的系统要求是 Android 8.0 以上（以官方页面当时显示为准）。安装后你会被请求这些权限，它们各自对应的功能如下：

| 权限 | 用在哪 |
| --- | --- |
| 存储 / 读取媒体文件 | 发送本地文件、图片、视频消息 |
| 摄像头 | 拍摄、音视频通话 |
| 麦克风 | 语音留言、语音通话 |
| 电话 | 通话中直接拨打电话 |
| 日历 | 会议安排 |
| 蓝牙 | 使用蓝牙耳机等设备 |
| 通知 | 接收消息提醒 |

某个权限你用不上就拒绝，不影响其余功能；之后真用到对应功能时再补授权也可以。

## 五、装不上或打不开怎么排查

- **安装时提示解析失败 / 包损坏**：先确认 APK 是完整下载的（网盘转存后要等进度走完），再核对文件大小是否与上表一致；讲究一点可以用工具核对 MD5 是否等于 `67fc5252c32020cea8f1ab33eaa91789`，对不上就是下载过程出了问题，重新下载即可。
- **提示与已装应用冲突**：手机里若装过同包名（com.melink.android）的其他来源版本，先卸载旧的再装。
- **装上了但闪退**：确认系统版本不低于应用要求；老旧机型可以改试商店里的旧版本说明或升级系统。
- **iOS 搜不到**：确认设备是 iPhone，且 App Store 登录的地区收录了该应用；换个地区账号才能搜到的情况确实存在。
