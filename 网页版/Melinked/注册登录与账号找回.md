# Melinked 注册登录与账号找回

装好应用后第一件事是注册。Melinked 支持的进入方式不止一种，本文按官方隐私政策与更新说明里能确认的信息整理，帮你在注册前就把该准备的想清楚。

## 一、能怎么登录

根据官方隐私政策的说明，Melinked 账号可以这样进入：

| 方式 | 说明 |
| --- | --- |
| 手机号注册 | 收集手机号是为满足网络实名制要求，注册时要填账号名称与头像 |
| 邮箱账号 | 应用内置邮箱模块，注册 Melinked 帐号或邮箱账号时都会收集账号名称、头像 |
| 第三方账号关联登录 | 官方列出的平台包括微信、QQ、新浪微博、LinkedIn、Facebook、Twitter |

第三方登录的本质是把对方平台的唯一标识、昵称、头像授权给 Melinked 使用；你在这几个平台里用哪个最顺手，就选哪个，不必全绑。

## 二、注册时会发生什么

- 你要提供**账号名称和头像**，这是完成注册的基本项；
- **手机号**属于实名制要求的信息，不提供可能无法正常使用服务；
- **密保邮箱、密保问题**：官方说明这两项用于找回账户，注册当下顺手填好，比事后补救省事得多；
- 性别、地区等按你的意愿选填。

注册完成后你会拥有一个 Melinked ID，它是你在平台内的身份标识，之后登录、管理账户设置都用它。

## 三、账号找回的三条路

1. **邮箱登录验证窗口的忘记密码入口**：6.0.0 版本起，邮箱登录验证窗口增加了忘记密码入口，走验证流程重置密码即可；
2. **密保邮箱 / 密保问题**：注册时填过的，找回时按当时设置的答案验证；
3. **第三方关联登录**：当初用微信等第三方账号登录的，继续用同一方式登录即可回到原账号——这条最容易被忽略，很多人「丢号」其实只是换了登录方式。

三条路都走不通时，只能通过应用内的客服或联系渠道处理；官方应用商店页面给出的联系方式里包含官方网站 `https://www.melinked.com` 与官方微信号「成都星阵地科技」（以官方页面当时显示为准）。

## 四、注销账号与更换手机号

**注销**：官方隐私政策写明了入口路径——【我的 → 设置 → 账户与安全 → 注销】，注销后官方会对个人信息做删除或匿名化处理。动手前想清楚两件事：实名绑定的手机号注销后能不能再用于注册新号，官方没有说明；有纠纷未了结的交易先处理完再注销。

**更换绑定手机号**：有用户在 App Store 中国区评论里反馈（2025 年 2 月），换绑流程走到输入新号码验证码之后没有提交按钮、走不下去。这条反馈不代表当前版本仍然如此，但它指向一个稳妥的做法：**趁旧手机号还能收验证码时尽早办换绑**，真卡住了直接走客服渠道，别在流程里反复重试。

## 五、几个容易踩的点

- **同一个手机号/邮箱别在两个账号间来回换绑**：实名信息与账号是一对一的，换绑操作前先确认要保住的是哪个账号。
- **第三方平台的账号改名不影响登录**：授权依据的是平台唯一标识，不是昵称，所以你在微信里改名不会导致 Melinked 登录异常。
- **邮箱模块与应用账号是两回事**：邮箱是应用内的一个功能模块（详见[MeMeet会议与MeMail邮箱](MeMeet会议与MeMail邮箱.md)），有自己的登录验证流程；应用账号丢了不代表邮箱一并丢失，反之亦然，处理时分开看。

登录成功后，聊天模块的用法在[MeChat聊天与翻译功能](MeChat聊天与翻译功能.md)；如果是冲着找服务、谈合作来的，先看[跨境服务发布与担保交易](跨境服务发布与担保交易.md)。
