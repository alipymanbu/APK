Melinked 的能力不止聊天：谈成合作后要开会，正式往来要发邮件，这两件事分别落在 MeMeet 和 MeMail 两个模块里。它们是随版本迭代逐步加进来的，本篇先讲清各自的位置，再讲怎么用。

## 一、MeMeet：把讨论搬进会议室

MeMeet 会议功能在 5.9.0 版本加入应用（官方更新说明原文是「增加 MeMeet 会议」），后续版本持续增强：

- **音视频通话先行**：6.1.0 版本新增网络音视频电话，6.2.0 优化了呼叫体验——先有一对一通话，再有多人会议，这个顺序和大多数办公软件的演进一致；
- **AI 会议纪要**：6.2.0 版本新增，开完会不用手工整理记录；
- **日历配合**：应用请求「日历」权限的用途就是会议安排（见安装教程的权限对照表），预约进日历、到点提醒。

适用场景：跨境合作里双方时区不同、文字说不清的内容（方案讲解、看样、答疑），一次会议比几十条异步消息省时间。跨语言会议更要用好译员与文字辅助，参考[MeChat聊天与翻译功能](MeChat聊天与翻译功能.md)里的三条路。

## 二、MeMail：应用内的邮箱

MeMail 邮箱模块 5.6.0 加入，5.7.0 加入团队邮箱能力。从更新说明能看出它按「正经邮箱客户端」的方向做：

| 能力 | 出处（版本） |
| --- | --- |
| 邮箱模块与基础收发 | 5.6.0 |
| 团队邮箱 | 5.7.0 |
| 邮件分类收藏、标记垃圾邮件、收件通知 | 5.8.0 / 5.8.1 |
| 解析日程邮件 | 5.8.0 |
| 邮件批量处理 | 5.9.0 |
| 邮箱一键操作、登录验证窗口加忘记密码入口 | 6.0.0 |
| AI 编辑邮件 | 6.2.0 |

实用判断：

- **什么时候用它而不是外部邮箱**：对方也在 Melinked 平台上时，站内邮件和聊天、会议在一个应用里流转，不需要在几个工具间切换；
- **对外通信照旧用你的常用邮箱**：MeMail 的价值在协同，不是让你迁移邮箱服务；
- **登录验证独立**：邮箱有自己的登录验证流程，忘记密码走验证窗口的入口（6.0.0 起）；这类账号问题和应用账号的找回是两条线，见[注册登录与账号找回](注册登录与账号找回.md)。

## 三、三个模块怎么串起来

一个典型的跨境服务流程是这样走的：你在平台上发布或找到服务 → 用 MeChat 洽谈细节（涉及钱与交付的约定落文字）→ 约定好了开 MeMeet 会议对齐 → 正式方案与合同用 MeMail 往来 → 交易环节走平台的担保支付（见[跨境服务发布与担保交易](跨境服务发布与担保交易.md)）。

你手上的版本是否包含上述全部能力，取决于版本号——网盘里的 6.0.3 与商店最新版之间隔着若干次更新，缺的功能升级即可获得，升级方式见[下载与安装教程](下载与安装教程.md)的相关说明。
