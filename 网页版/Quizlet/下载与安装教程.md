## 一、先认准是这一个

Quizlet 这个名字在各商店可能有仿冒或同名应用，安装前对一下这三项：

| 核对项 | 值 |
| --- | --- |
| 应用显示名 | Quizlet |
| 包名 | `com.quizlet.quizletandroid` |
| 开发者 | Quizlet Inc |

包名是应用的唯一身份，图标和显示名都可能被仿冒，包名不会。

## 三、手机上安装（侧载步骤）

APK 不是从应用商店点「安装」装的，所以要先给安装来源授权：

1. 点开 APK 文件，系统弹出「禁止安装来自此来源的应用」时，进入该来源（浏览器或文件管理器）的授权开关并打开，返回；
2. 再次点击安装，确认详情页显示的应用名是 **Quizlet**、图标与你预期一致；
3. 装完先别急着打开——到「设置 → 应用 → 应用信息」里确认版本与包名（见下一节）。

以后升级是**覆盖安装**：拿到新版本 APK 直接再装一次即可，无需卸载，账号里的学习集与进度不受影响（前提是登录了同一个账号——数据存在账号里，不在本地）。

## 四、装完核对

「设置 → 应用 → 应用信息 → Quizlet」里看两项：

- **版本号**：装网盘这份应显示 10.37；
- **包名**（部分机型在「高级/应用信息」里）：`com.quizlet.quizletandroid`。

版本号对不上，说明你装的不是这份包；包名对不上，说明装的是另一个同名应用，先删掉再按本篇重装。

## 五、不想装 APK 的话

Quizlet 本身是个网页服务，安卓 App 只是它的其中一个入口：

- **网页版**：浏览器打开 [quizlet.com](https://quizlet.com) 直接用，无需安装。官方帮助页列出的浏览器兼容范围以 Chrome 64 及以上等主流版本为基准，具体清单以 [Quizlet 帮助中心](https://help.quizlet.com/hc/zh-cn) 当时显示为准；
- **iPhone / iPad**：这份是 APK，**iPhone 装不了**。iOS 版在 App Store 单独上架（应用页见 [apps.apple.com](https://apps.apple.com/cn/app/quizlet-%E4%BD%BF%E7%94%A8%E5%8D%95%E8%AF%8D%E5%8D%A1%E5%AD%A6%E4%B9%A0/id546473125)），走苹果内购付费，与安卓端的购买渠道互不相通。

网页版、iOS 版、安卓版登录的是**同一个账号**，学习集与进度跟着账号走，换端不用重新导入。
