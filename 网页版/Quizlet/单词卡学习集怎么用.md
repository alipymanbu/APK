## 一、学习集是什么

学习集就是一组「词语 + 定义」或「问题 + 答案」的卡片列表，可以带图片和音频。你在 Quizlet 里做的所有学习活动——背卡片、做测试、玩匹配游戏——都是围绕某一个学习集展开的。

平台上有教师和学生创建的数百万个现成学习集，你既可以搜来直接用，也可以自己建。

## 二、自己创建学习集

在网页或安卓 App 里都能建，入口是创建学习集。基础结构是一行一张卡：正面写词语/问题，背面写定义/答案。可用的输入手段：

| 手段 | 什么时候用 |
| --- | --- |
| 手动逐行输入 | 卡片少、要精确控制措辞 |
| 上传自己的图片 | 记实物、记图表部位 |
| 从免费图库选图 | 不想自己找图 |
| 录制自定义音频 | 记发音（外语、医学术语等） |
| 扫描文档创建 | 手头是纸质/ PDF 材料 |
| 智能辅助工具生成 | 给一段材料，让它替你出卡片初稿，再人工改 |

创建时可以给整个学习集选一门语言——这决定后面练习时用哪种语言出题与发音。做完保存，学习集默认可以在搜索里被别人找到（也可以去设置里改成不公开）。

## 三、找现成的学习集

不想自己录入就直接搜：

1. 打开 [quizlet.com](https://quizlet.com) 或 App，点搜索；
2. 输入主题（比如「日语 N3 单词」「人体骨骼」），回车；
3. 结果里按学习集标签浏览，挑卡数合适、最近有人用的那个打开。

搜到的现成学习集可以直接开始学，也可以复制到自己账号下再改——别人的原集不受影响，你改的只是副本。

## 四、8 种学习方式怎么选

同一个学习集可以从多个角度练，官方列出的主要方式与免费/付费边界如下（**付费口径截至 2026 年 9 月，以官方购买页为准**）：

| 方式 | 你实际在做什么 | 免费账户能用到什么程度 |
| --- | --- | --- |
| 单词卡 | 正面翻背面，逐张过卡 | 可用 |
| 学习 | 按你答对答错动态排序出题，难度递增 | 每个学习集限次数；订阅者不限 |
| 书写 / 拼写 | 打字作答、听音拼写（已并入学习模式，选项里切换） | 随学习模式一起 |
| 测试 | 一组题自测出分 | 每个学习集可做一份模拟测试 |
| 模拟测试 | 更接近真实考试的成套卷 | 同上 |
| 匹配 / 爆破 / 方块 | 计时小游戏，把词和定义连起来 | 可用 |
| Quizlet Live | 分组对战的课堂游戏 | 可用（需从班级/学习集发起） |
| 学习指南 / 专家解答 | 汇总重难点、分步解题 | 订阅功能 |

选型建议：临考前用**学习**过一轮再用**测试**查漏；纯背词用**单词卡 + 匹配**；课堂互动用 **Quizlet Live**。

用测试前注意两条官方提示：**测试不像其他活动会保存进度**——中途离开页面，这一轮就没了，要打完整卷再走；想要纸质版，测试页的更多菜单里有打印入口，操作在 [打印与导出学习集.md](打印与导出学习集.md)。另外「Gravity」这个老活动官方已下线，页面上看到的介绍别再去找它，限时练习用匹配替代。

**学习模式的自定义**：打开学习集 → 学习 → 设定目标，再进「选项」菜单可以指定只练星标卡、换词语顺序、改音频开关、选题型、选评分方式。想练手写就在这里把模式切成「书写」。

## 五、班级与小组

- **教师**：注册时勾了「我是教师」后可以创建班级、把学习集加进班级、邀请学生。学生一旦加入，你后续往班级里加的新内容会推送给他们；
- **学生**：接受班级邀请后，**学班级内的学习集时可以免费用学习与测试模式**——这两个模式对普通免费用户有次数限制，但班级内容是例外。官方把「无限次、无广告」写明了三个前提：**你已登录**、**你被教师添加进了班级**、**你学的是从班级页面加进来的学习集**；三个条件缺一个就可能撞到付费墙；
- **撞到付费墙先查两件事**（官方给的排查顺序）：① 教师的班级成员页里有没有你的用户名——没有就是没被加进去，让教师重新邀请；② 你是不是从**主页**直接点开的学习集——换成从班级页面进入再试；
- **学习小组**：同学之间也能组小组一起练，进度共享的范围以小组设置为准。

不确定某个功能要不要钱，对照 [免费版与Plus订阅区别.md](免费版与Plus订阅区别.md) 里的对照表，别等到用到一半弹付费才反应过来。
