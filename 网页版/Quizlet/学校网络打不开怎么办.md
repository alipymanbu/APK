# Quizlet 学校网络打不开怎么办

> 在校园网/公司网里打不开网站或 App、收不到确认邮件、图片加载不出来——多半不是 Quizlet 挂了，是网络侧把它拦了。本篇讲怎么定位与解。

## 一、先确认是不是网络侧拦的

一个很省事的判据：**同一网络下，手机流量能开、校园 Wi-Fi 打不开**（或换一个网络就能开），问题就在网络侧，不在账号也不在 App。换网络对照一次即可定性，别急着清缓存重装（那套在 [闪退打不开与故障排查.md](闪退打不开与故障排查.md) 里，对网络拦截没用）。

官方帮助中心有专门一篇「Quizlet 被阻止或无法加载」，说的就是这个场景：学校网络屏蔽 Quizlet 时，网站和移动 App 都会打不开。

## 二、让 IT 加白名单（官方给的解法）

校园网有管理员的话，正解是请管理员放行，官方要求加白的项：

**域名**

```
https://quizlet.com
https://*quizlet.com
https://quizlet.live
```

**IP 段**：官方列了一长串 IPv4/IPv6 段（都是其 CDN 的网段，核心是 `104.16.0.0/13`、`104.24.0.0/14`、`141.101.64.0/18` 等几段，完整清单见 [Quizlet 帮助中心](https://help.quizlet.com/hc/zh-cn) 的「Quizlet 被阻止或无法加载」一文，直接抄给管理员即可）。

**邮件发件人**（不加这个，确认邮件与密码重设邮件会被拦，账号根本注册不上）：

```
no-reply@quizlet.com
account@account.quizlet.com
newsletter@newsletter.quizlet.com
```

Quizlet Live 课堂游戏走的是独立域名 `quizlet.live`——只放行了 quizlet.com 的话，网页能开但课堂游戏连不上，就是漏了这一条。

## 三、图片不加载是另一件事

学习集里的图库图片显示为空白，官方说明：**免费图库的许多图片托管在 Flickr 上**。网站本身能开、只有图片缺——让管理员确认校园网没有屏蔽 Flickr，而不是去折腾 Quizlet。

## 四、Google 登录报错不属于网络屏蔽

在学校网络里用 Google 账户登录弹 `admin_policy_enforced` 之类的错误，那是 **Google Workspace 侧的应用访问限制**，不是网络拦了域名——处理办法（网页端加密码那条路）在 [注册登录与账号找回.md](注册登录与账号找回.md) 第四节，本篇不再重复。

## 五、没有管理员可找时

校园网没有可联系的 IT、或者你自己就是网络的主人（家里宽带连不上）：

1. 换移动流量试一次，确认是宽带侧的问题；
2. 检查是不是自己开着代理/VPN 配置错了——官方的排查口径是「开着 VPN 的先关掉试」，关掉后能开就说明问题在代理本身；
3. 关掉代理也打不开时，先到别的设备/网络交叉验证，再判断是 Quizlet 服务端故障还是你这条线路的问题——定性方法在 [闪退打不开与故障排查.md](闪退打不开与故障排查.md) 第二节。
