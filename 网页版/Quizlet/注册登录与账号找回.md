## 一、注册一个账号

在 [quizlet.com](https://quizlet.com) 或安卓 App 里都能注册，支持四条路：

| 方式 | 说明 |
| --- | --- |
| Google 账户 | 一键授权，最常见 |
| Apple 账户 | iOS 设备上常用 |
| Facebook 账户 | 授权登录 |
| 邮箱 + 密码 | 不依赖第三方时的兜底方式 |

两个注册时的注意点：

- **教师注册时要勾选「我是教师」**——班级、形成性评估这些教师功能跟着这个身份走，事后改身份不如一开始选对；
- **部分地区/年龄的用户，创建和编辑学习集之前要先通过确认邮件获得家长同意**（13 岁以下等情形）。确认邮件官方标注最多 24 小时送达，没收到先翻垃圾邮件文件夹。

## 二、用户名与密码的规则

- **用户名只能改一次**：个人资料 → 设置 → 个人信息 → 用户名旁的编辑，输入密码后点「永久更改」。改之前想好，没有第二次机会；
- **用户名删号后也不能再用**：即使你注销了账号，那个用户名也不会释放给别人（包括你自己重建）；
- **改密码**：设置 → 账户和隐私 → 更改密码，输入当前密码、新密码并确认。忘记密码就走登录页的重设流程。

## 三、忘记用户名或密码

- 忘记用户名：到 [quizlet.com/forgotten/username](https://quizlet.com/forgotten/username) 用注册邮箱申请用户名列表；
- 忘记密码：登录页的「忘记密码」会发重设邮件到注册邮箱；
- **注册邮箱已经进不去了**：官方有单独的账户找回流程（帮助中心「无法访问账户」相关文章），要走身份验证，不是在登录页能解决的；
- 疑心自己有多个账号：同样用上面的用户名查询页，把邮箱关联的用户名全列出来，登录后再删掉不需要的。

## 四、登不进去的几种情形

按你看到的现象对号入座（完整条目以 [Quizlet 协助中心](https://help.quizlet.com/hc/zh-cn) 的「无法登入」为准）：

| 现象 | 原因与处理 |
| --- | --- |
| Google 登入报 `Error 400: admin_policy_enforced` 或「存取已封禁」 | 你所在学校/机构的 Google Workspace 限制了 Quizlet。**网页端**可走 `https://quizlet.com/oauth-help` 这个页面：输入邮箱 → 收登录链接邮件 → 按提示给账户**新增密码**，此后用邮箱+密码登录。注意官方标注该选项**目前仅限网页，手机 App 暂不支持** |
| 总是登进另一个 Google 账户 | 设备上登了多个 Google 账户导致串号。先去 [google.com](https://google.com) 登出，回 Quizlet 点「用 Google 账户登入」再选对账户 |
| 提示「尝试登入太多次」 | 输错触发了频率限制，等一段时间再试，别连续重试把窗口越拖越长 |
| 用 Apple / Facebook 登入失败 | 确认登的是当初授权的那个 ID；用 Apple 且开过「隐藏我的电子邮件」时，账户绑的可能是随机转寄邮箱——这种情形改用邮箱+密码登录更省事 |
| 收不到确认/登录邮件 | 官方口径是确认信息最多 24 小时送达，先查垃圾邮件文件夹 |

## 五、别人用我的邮箱注册了

帮助中心有专门条目处理这种情形：确认那个账号不是你的之后，按官方指引申诉。处理期间不要用「用邮箱登录」的方式去将就——你登进去的是别人的资料。
