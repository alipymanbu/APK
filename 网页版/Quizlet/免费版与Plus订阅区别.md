## 一、免费和付费差在哪

免费账户不是残废版：单词卡、匹配/爆破/方块这类小游戏、班级内的学习与测试都能正常用。付费解锁的主要是「不限次数」和「更高级的学习工具」：

| 能力 | 免费账户 | Plus 订阅 |
| --- | --- | --- |
| 创建与搜索学习集 | 可用 | 可用（多图表学习集、富文本编辑） |
| 单词卡、匹配等小游戏 | 可用 | 可用且无广告打断 |
| 学习模式 | 每个学习集限次数 | 不限次数，含自定义学习路径与智能评分 |
| 测试 / 模拟测试 | 每个学习集一份 | 不限 |
| 学习指南、专家解答 | 不可用 | 可用 |
| 离线学习 | 不可用 | 可用 |

（口径截至 2026 年 9 月，来自官方帮助中心；功能与限制随时可能调整，**以 [quizlet.com](https://quizlet.com) 购买页当时显示为准**。）

## 二、有哪几种订阅

官方现行的订阅类型（同样以购买页为准）：

| 计费方式 | 说明 |
| --- | --- |
| Quizlet Plus 月付 / 年付 | 个人用，自动续订 |
| Quizlet Plus 无限制版 | 个人用的完整功能档，自动续订 |
| Quizlet Plus 教师版 | 年付，含班级进度跟踪的形成性评估 |
| 家庭版计划 | 按年计费、多人共享一份高级权限；**不含免费试用**，不取消就自动续费，且只有还没注册的人有资格购买或加入 |
| 团体订阅 | 学校/部门整批买，**买一年不自动续订**，从购买日起算 |

价格不是固定数：App Store 中国区应用页当时列出的内购价位包括 Quizlet Plus ¥68.00 与 ¥298.00、教师版 ¥233.00 等档位，但月付/年付分别对应哪个数、以及网页端价格，**一律以你下单那一刻的购买页为准**，本篇不替你记死价格。

## 三、取消自动续订

订阅默认自动续订，取消入口跟着你的**付款渠道**走，三选一：

| 付款渠道 | 取消入口 |
| --- | --- |
| 网站上直接支付 | 登录 [quizlet.com](https://quizlet.com) → 设置 → 订阅管理 |
| Google Play（安卓 App 内购） | Play 商店 → 订阅管理 → Quizlet → 取消 |
| Apple（iOS 内购） | 系统设置 → 顶部你的名字 → 订阅 → Quizlet |

两条经验：**在当前订阅期结束前至少 24 小时取消**才来得及（苹果渠道官方明确写了这条）；另外要知道在 App 内买的订阅只能在对应商店取消，回网页端是找不到开关的。

## 四、订阅到期后内容还在吗

到期且未续订，账户自动降回免费版：

- **保留**：你的全部学习集、文件夹、班级、上传的图片、录过的音频都还在账户里；
- **失去**：所有升级功能（学习/测试不限次数、学习指南、专家解答、离线、无广告等）立即不可用；
- 降级期间再编辑订阅期创建的学习集，原来加的付费特性（如富文本格式）会从被改动的词条上移除；
- 班级进度数据不丢，重新升级后恢复。

判断自己当前是哪种状态：登录后进设置页，页面顶部显示「到期日期」= 不会自动续订，显示「续订日期」= 还在自动续订中。

## 五、要不要开，一个判断标准

只在考前突击、一个学习集反复练的——免费版的次数限制够你用，先别开。**每天高强度刷多个学习集、或者要给全班用**的，次数限制会天天撞墙，订阅才花得值。开之前按第三节确认好取消路径，别让自动续订替你做决定。
