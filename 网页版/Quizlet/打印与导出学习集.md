## 一、打印：只能在电脑网页端做

官方帮助中心写死了这条限制：**移动 App 不支持打印**，要打就得用笔记本或台式机登录网页版。步骤：

1. 登录 [quizlet.com](https://quizlet.com)，打开要打印的学习集；
2. 点**更多菜单**（学习集页面上的「…」）→ **打印**；
3. 调整页面尺寸和打印选项。**看不到具体格式选项，说明这个学习集的语言不支持自定义排版**——仍然可以用浏览器自带的打印对话框打出来；
4. 点打印。想存成 PDF 不打印的话，在浏览器打印对话框里把目标打印机改成「另存为 PDF」即可。

三个实操细节：

- **长学习集先展开**：词语列表底部有「查看更多」，要一直点到全部词语显示出来再打，否则只打出了前一屏；
- **高亮与富文本要勾「打印背景」**：用 Firefox 打印时尤其注意（官方提示），不勾的话你设置的高亮效果打不出来；
- **测试也能打**：测试页的更多菜单里有「列印测试」入口，打的是卷子不是卡片。

打印版式（表格速查表 / 可剪卡片 / 索引卡尺寸）随语言与浏览器而异，以你当时看到的选项为准；版式不满意就走下一节的导出，自己在排版软件里排。

## 二、导出：只有创建者能导，且只在网页端

导出把学习集变成纯文本，粘到 Excel、Word 里自己加工。限制官方写得很清楚：

| 限制 | 说明 |
| --- | --- |
| 仅创建者 | **你自己建的学习集才能导**；从别人那里复制来的，导出选项不出现（版权限制） |
| 仅网页端 | 手机 App 里没有导出入口 |
| 图片不能带 | 版权限制，导出的文本里只有词语和定义，没有图 |

步骤：登录 → 进「我的文件库」→ 单词卡学习集 → 打开目标学习集 → 更多菜单 → **导出** → 选好词语与定义的排列方式（制表符 / 逗号 / 自定义字符分隔）→ **复制文本** → 粘到你要去的地方。

制表符分隔的文本粘进 Excel 或 Google 表格会自动一列一列对齐；要双面打印正反面的，用两栏表格（左词右义）在 Word 里排比在网页上折腾版式省事。

## 三、卡在中间的场景怎么办

- **想导出的不是自己建的**：官方没有绕开的办法——要么用第一节的打印功能直接打网页排版，要么把它复制过来后逐条自己录一份（复制件同样不能导出）；
- **只想要一份 PDF**：打印对话框另存为 PDF 就是官方路径，不需要第三方工具；
- **要打印的是测试卷**：用测试页的打印入口，别用学习集打印再手抄题。

官方帮助中心的「打印设置」与「导出你的学习集」两篇都没有标注订阅门槛——这两件事的已知限制是「创建者身份 + 电脑浏览器」，具体以页面当时是否给出入口为准。
