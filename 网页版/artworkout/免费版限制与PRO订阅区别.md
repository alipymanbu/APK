## 一、免费账号能干什么

ArtWorkout 免费下载、免费进应用，但免费账号受两套机制限制：

- **能量 / 次数限制**：免费状态下的可画内容按天给，多数用户反馈实际每天基本只够画一两幅，用完就要等恢复；
- **看广告续命**：能量用完时可以看一段广告换继续画的机会，有用户反馈单段广告约半分钟，且画完一幅后也会比较频繁地弹出订阅引导。

免费账号拿到的分数反馈是基础版的笔画准确度评分，够你判断「这一笔歪没歪」；更细的笔画质量分析要订阅后才完整。

## 二、免费与 PRO 逐项对照

| 对比项 | 免费版 | PRO 订阅 |
| --- | --- | --- |
| 课程库 | 每天少量免费内容 | 全部 3500+ 课程与成套课程 |
| 新课程 | 受限 | 每周更新都能练 |
| 多人模式 | 次数受限 | 不限次数 |
| 广告 | 有，能量用完靠看广告续 | 无广告 |
| 评分反馈 | 基础评分反馈 | 有第三方评测称笔画质量分析更完整 |

## 三、PRO 的档位与价格

PRO 按订阅周期收费，官方提供周付、月付、季付、年付几档，**价格按你所在地区和账号商店显示为准**，购买前应用内会展示本地货币价格。参考量级（随汇率与官方调价变动，勿当报价）：

| 档位 | 参考价格（美区 / 欧区商店页） |
| --- | --- |
| 周付 | 7.99 美元 / 7.99 欧元 |
| 月付 | — / 8.99 欧元 |
| 季付 | — / 34.99 欧元 |
| 年付 | 49.99~79.99 美元 / 49.99 欧元 |

几点购买前要知道的：

- 订阅**默认自动续费**，到期前一天内会自动扣下一期；只想试一个月的话，买完就去商店的订阅管理里关掉自动续费，不影响本期权益；
- 周付折算下来最贵，年付单月成本最低；不确定能否坚持的话，先周付试一两周再决定；
- 已购 PRO 但没生效，先确认商店账号是不是扣费的那个，重启应用再试，还不行走商店的退款流程（见 [取消订阅与常见问题.md](取消订阅与常见问题.md)）。

## 四、按使用场景决定要不要订阅

- **每天就想画一张解压**：免费版基本够用，省下的钱不值当；
- **想系统学（线条 → 素描 → 上色 → 透视/人体）**：免费次数撑不起连续练习，订阅才有意义，直接看 [课程体系与练习路径.md](课程体系与练习路径.md) 规划路径；
- **主要冲着多人模式来**：免费次数限制很影响体验，常玩就订；
- **给孩子当电子画板**：先免费试一周，孩子每天一幅的量刚好卡在免费额度附近，再决定。

判断标准就一条：把免费额度用完的那天，你是「算了」还是「还想画」——前者留在免费，后者再掏钱。
