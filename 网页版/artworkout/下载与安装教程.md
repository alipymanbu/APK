## 一、装之前先确认这是你要的应用

ArtWorkout 是一款「边画边打分」的绘画教学应用：每一课把一幅画拆成 10~30 个小步骤，你照着画，应用实时分析你每一笔的准确度和线条质量，画完给出得分。它适合零基础入门，也适合有基础的人当每日热身练习。安卓版、iOS 版都有，本篇对应的是**安卓安装包**。

搜「artworkout」时容易撞见另一款国产应用「ArtworkOut绘画助手」，两者不是同一款产品。认准下面这组信息就不会装错：

| 项目 | 值 |
| --- | --- |
| 应用名称 | ArtWorkout |
| 版本 | 0.1.89 |
| 包名 | app.artworkout.learn.how.to.draw |
| 安装包大小 | 135.98M |
| MD5 | D1F73C71745455355D60CB265F5EED1B |
| 系统要求 | 安卓 5.2 及以上 |

这组数字对应网盘里这一份安装包；官方后续会持续更新版本，最新版号以官方发布渠道为准，两者不一定是同一个版本。

## 二、下载与安装步骤

1. 打开 [ArtWorkout 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1ebbb747aa1b)，把 APK 转存到自己的网盘，再下载到手机本地；
2. 在手机文件管理里点开下载好的 APK。系统第一次会提示「不允许安装未知来源应用」，按弹窗指引允许本次安装（入口一般在 设置 > 安全，或直接在安装弹窗里授权）；
3. 等安装完成，135 MB 左右的包在正常网络下十几秒就能装完；
4. 打开应用，首次进入会有几步初始化引导（语言选择、内容偏好这类），跟着点完就能进第一课。

## 三、装不上怎么排查

按命中概率从高到低排查：

1. **包不完整**：网盘转存或下载中断会得到损坏的 APK，重新转存再下载一遍是最先该做的事；
2. **核对文件**：下载完可以对照上面表格里的 MD5 与大小确认没下错、没下残；
3. **存储空间不足**：装 135 MB 的包，手机至少要留出几百 MB 余量；
4. **来源授权入口找不到**：各品牌安卓的「允许安装未知来源」位置不同，有的在 设置 > 安全，有的在安装弹窗里当场授权，认准提示走即可。

反复失败就换一台设备或换网络重下，别反复安装同一个坏包。

## 四、首次启动的两件事

- **联网**：进入课程列表、多人模式都需要网络。有用户反馈网络不稳定时内容加载会变慢，建议在正常 Wi-Fi 或流量下使用；
- **存储与手感**：画完的作品和进度都在应用里，别用「清理大师」类工具去清它的数据；画画时手指直接怼屏幕上即可，介意误触可以接电容笔。
