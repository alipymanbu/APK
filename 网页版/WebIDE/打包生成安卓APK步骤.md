## 一、打包前把参数定好

这些参数决定 APK 装到手机后是什么样子，生成之前先定下来：

| 参数 | 影响的是什么 |
| --- | --- |
| 应用名称 | 桌面图标下面显示的名字 |
| 图标 | 桌面上看到的那个图标 |
| 启动页 | 打开 App 时先出现的那一屏 |
| 包名 | 系统区分应用的标识；换了包名，系统就当作另一个应用，可以与旧版本并存 |

参数都在打包设置里改。改完再生成，省得装上才发现名字或图标不对、又得重打一遍。

## 二、代码加密开不开

生成的 APK 默认加密，别人拿到包也不容易把源码还原出来。

开关的位置：主界面右上角三个点 → 「工具设置」→ 「代码加密」，点亮即开。

- 自己留着用、不介意被看源码 → 开不开随意；
- 打算把 APK 发给别人 → 保持加密开启。

## 三、生成并安装

1. 项目代码先过一遍预览，确认没有报错（预览都跑不起来的页面，打包出来一样跑不起来）；
2. 点运行，等安装包生成；
3. 生成后调起系统的安装程序，像装普通应用一样装到手机上；
4. 装完桌面上出现图标，点开就是你的应用。

生成的 APK 也可以直接分享给别人——发到社交平台或传文件都行，对方安装时同样要走一遍「允许未知来源安装」。发出去之前的检查、对方手机上的各类拦截、更新版本的发法，单独整理在 [把生成的APK发给别人.md](把生成的APK发给别人.md)。

## 四、装上之后测什么

- 名称、图标、启动页是不是按你设置的显示；
- 页面跳转、按钮点击在真机上是否正常；
- 横竖屏切换、返回键的表现。

哪一步卡住了，先看 [常见问题排查.md](常见问题排查.md)。如果只是想要个顺手的手机编辑器、并不需要出安装包，可以对比一下 [与Acode和AIDE的区别.md](与Acode和AIDE的区别.md) 再做决定。
