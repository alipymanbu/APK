# WebIDE 与Acode和AIDE的区别

> 搜「手机 WebIDE」时经常同时冒出 Acode 和 AIDE。三款工具都能在手机上写代码，但「要不要直接把网页变成 APK」这个分叉点决定了该选哪个。

## 一、三款工具各是什么

- **WebIDE（本文这套文档的主角）**：bzyapp 出的手机端工具，路线是「写网页代码 → 直接在手机里生成加密 APK」，全程不碰电脑；
- **Acode**：开源的安卓代码编辑器，编辑体验和文件管理是强项，本身不负责生成安装包；想跑 Python、PHP 这类程序，得自己再配 Termux；
- **AIDE**：面向 Android 原生开发的集成环境，走 Java / C++ 工程路线，也能写 HTML5 应用，学习曲线明显更陡。

## 二、对照表

| | WebIDE | Acode | AIDE |
| --- | --- | --- | --- |
| 核心定位 | 网页代码打包成 APK | 代码编辑 + 预览 | Android 原生开发 |
| 生成 APK | 内置，填参数就能出包 | 不内置 | 内置（原生工程编译） |
| 主要语言 | HTML / CSS / JavaScript / TypeScript | 100 多种语言的语法高亮 | Java / C++ / HTML5 |
| 上手门槛 | 低 | 中 | 高 |

Acode 与 AIDE 的信息取自它们的官方页面与开源仓库，会随版本变化，以官方说明为准；WebIDE 一栏的口径与本文档其余各篇一致。

## 三、按你的目的选

- **手里有个 H5 页面或小工具，想变成手机上能点的 App**：WebIDE，路径最短——建项目、写（或粘）代码、点运行；
- **只想用手机改代码、连服务器、管 Git**：Acode。它的 FTP/SFTP、SSH 终端、Git 支持都在编辑这条线上，不需要它帮你出包；
- **想正经学 Android 开发、做原生应用**：AIDE 才是对口的工具。

选定了 WebIDE 的话，从 [项目创建与代码编辑入门.md](项目创建与代码编辑入门.md) 开始动手；要出安装包的完整流程在 [打包生成安卓APK步骤.md](打包生成安卓APK步骤.md)。
