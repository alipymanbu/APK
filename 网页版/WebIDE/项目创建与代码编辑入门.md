## 一、第一步：创建项目

打开 WebIDE 后不写代码，先建项目：

1. 点「创建项目」；
2. 输入项目名；
3. 选择语言类型——做网页类项目就是 HTML / CSS / JavaScript 这一套，也支持 TypeScript；
4. 确认后进入项目。

项目建好，你会看到它的目录结构，和电脑上的网页工程长法差不多。从目录树里选中某个文件，就能进入编辑。

给项目文件起名时尽量避开空格、中文和特殊字符——网页里互相引用路径，这类名字最容易出岔子：路径对不上、资源加载不出来，多半栽在这里。

## 二、编辑器里有哪些能用的

在手机上打字编码，决定顺手程度的是这几样，都是现成的、不用额外配置：

- **语法高亮**：HTML、CSS、JavaScript、TypeScript 都会着色，标签和括号一眼能对上；
- **自动缩进与补全**：输入时自动缩进，常用语句有补全提示，减少手机键盘的敲击量；
- **深色模式**：夜间写代码把界面切成深色主题，长时间盯屏幕眼睛舒服不少。

## 三、点预览看效果

代码写到哪一步都可以点预览按钮：修改之后预览界面即时刷新，在手机上直接看页面效果，不用等打包出来再验证。

建议的节奏是：小步修改 → 预览确认 → 再改下一处。整页都确认过了，再去走生成安装包那一步，见 [打包生成安卓APK步骤.md](打包生成安卓APK步骤.md)。

## 四、没网能不能写

能。离线状态下照样可以写代码、调试项目；联网之后项目走云端存储同步，换手机、平板接着写也能把进度接上。编程进度本身是实时保存的，误退出应用重新进去即可继续。

所以「通勤路上把代码写完，回到有网的环境再打包」是一条走得通的路线。写的过程中碰到报错，先翻 [常见问题排查.md](常见问题排查.md)；还没装上应用的，从 [下载与安装教程.md](下载与安装教程.md) 开始。
