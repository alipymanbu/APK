## 一、先选控制模式，再选连接方式

FT8CN 的设置里，PTT（发射控制）与链路是两个独立选项：**控制模式**决定「谁来按下发射键」，**连接方式**决定「手机和电台靠什么连通」。控制模式有 VOX、CAT、RTS、DTR 四种，连接方式有 USB 线、蓝牙、网络三种（后三种只对 CAT/RTS/DTR 有效）。

按你的硬件条件对号入座：

| 方式 | 需要什么 | 能控制什么 | 适合谁 |
| --- | --- | --- | --- |
| VOX | 一条音频线（手机接电台话筒/音频口），电台开 VOX | 只管收发音频，电台自己判断何时发射 | 不想折腾线缆与指令，先跑起来再说 |
| CAT + USB | 手机支持 OTG + USB 数据线 | PTT、同步频率、切工作模式，部分机型还回报 SWR / ALC | 主流玩法，控制最完整 |
| CAT + 蓝牙 | 电台自带或加装蓝牙 | 同上（无线） | 官方手册列出的支持机型：GUOHE Q900（截至 v0.89 手册，以官方为准） |
| CAT + 网络 | 手机与电台同一局域网 | 同上（无线） | 官方手册列出：部分 ICOM 机型、FlexRadio 6000 系列 |

控制模式里的 RTS / DTR 是用串口的这两根线直接当 PTT 用，接了相应转接板的用户才用得到，选法与 CAT 相同。

## 二、USB 线连接的完整步骤

这是最常见也最完整的一条路，按顺序做：

1. **先配置、后插线**：在 FT8CN 设置页里**先选好你的电台型号与波特率**。不同型号的控制指令不一样，型号或速率选错，插上线也控制不住电台。
2. 手机端确认支持 OTG（不支持就配一个 OTG 转接头）。
3. 电台调到可以做 FT8 的状态（模式、频率设好），用 USB 线接上手机。
4. 系统弹出「选择应用处理 USB 设备」时选 **FT8CN**；接着弹串口授权提示，同样授权给 FT8CN。
5. 弹出串口选择窗口时**选中用于控制的那一个** —— 有的电台（如 IC-705）会列出两个串口，选错就毫无反应，换另一个再试。
6. 回到解码页确认：频谱有起伏、频率能被软件带动，就说明 CAT 通了。

一条经验：**先把设置做完再插线**。反过来做，插线时的授权弹窗与设置项容易互相打断，你会分不清是哪一步没生效。

## 三、音频电平：决定你发出去的信号干不干净

FT8 走的是电台的 SSB 通道，**手机送出的音频大小直接决定发射质量**，这一步所有连接方式都躲不掉：

- 打开 FT8CN 的音量（音频输出）设置，**一边看电台的 ALC 表一边调**：让 ALC 只在起表附近轻微摆动，不要顶到红区。
- 参考值（因机型而异，别照抄）：有使用者在 IC-705 上把电台侧音量设 50%、手机侧约 25%，ALC 刚好起表。
- **调过头的两头都不对**：音频过大 → 失真，对方收到的是脏信号；音频过小（ALC 几乎不动）→ 有些电台的输出功率会低到接近 0。
- 手机侧调不细的场景（比如网络控制模式下音量联动不了），改用电台侧的音频输入电平来调。

0.93 起设置里有 **SWR 与 ALC 告警开关**，打开后异常会提醒你，第一次架台建议开着，确认链路正常后再按需关。

## 四、纯接收：不接发射的接法

只想收报文、不发射（SWL），一条音频线把电台耳机口送进手机就行，社区里验证过的接法是：

`电台耳机口 → 3.5mm 音频线 →（音频隔离器）→ USB 声卡 → OTG → 手机`

- **音频隔离器值得加**：不少人反馈直连会让电台底噪明显抬高，隔离器就是解决这个的。
- 接线前**先把电台音量调到最低**，接好后再往上推，避免过大音频直接灌进声卡。
- 电台模式切到 USB（上边带），看 FT8CN 频谱上出现成排的竖直线状轨迹，再微调音量到合适幅度。
