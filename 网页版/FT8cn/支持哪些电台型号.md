## 一、最权威的清单在软件里

不用到处翻帖子：**FT8CN 设置页里「选电台型号」的那个列表，就是你手上这个版本的完整支持清单**。在列表里选中型号后，软件会自动带出该机型对应的控制参数（CI-V 地址、波特率、指令集），这正是它能控住电台的原因。

两个口径要留意：

- 官方发行说明里多次出现「新增支持的电台型号」，**列表随版本增长** —— 你装的版本决定你能选到哪些型号（本文按 0.93 与公开资料整理，以你实际打开看到的为准）。
- 「出现在列表里」代表软件发得出指令；能不能稳定工作还取决于电台固件与连接方式，见下两节。

## 二、公开资料里能看到的支持范围

下表按系列汇总官方发行说明、官方快速手册与公开技术文档的口径（**截至 0.93 相关资料，以官方页面当时显示为准**）：

| 系列 / 型号 | 支持情况 | 出处口径 |
| --- | --- | --- |
| ICOM 系列 | USB 串口 CAT 常见用法；**部分型号支持网络（Wi-Fi）控制**；驻波比与 ALC 过高告警支持 | 官方发行说明、官方快速手册 |
| YAESU 系列 | CAT 控制；驻波比与 ALC 过高告警支持 | 官方发行说明、第三方对源码的分析 |
| 建伍（Kenwood）TS 系列 | CAT 控制；驻波比与 ALC 过高告警支持 | 官方发行说明、第三方对源码的分析 |
| Elecraft 系列 | 驻波比与 ALC 过高告警支持 | 官方发行说明 |
| 协谷（Xiegu）X6100 | USB 连接可用；**Wi-Fi 模式需固件 1.1.7 及以上**，且截至该条发行说明发射音频仍有未解决的问题 | 官方发行说明 |
| 协谷（Xiegu）X6200 | 蓝牙可用，**实测前提是固件升到 1.06**（在 `GEN → SYSTEM → System Info` 里查） | 器材商技术博客实测（2025-01，针对 1.06 固件） |
| FlexRadio 6000 系列 | 网络模式控制 | 官方快速手册 |
| GUOHE Q900 | 蓝牙控制 | 官方快速手册（v0.89 版本） |
| truSDX、Wolf SDR 等 | 出现在源码的机型清单里 | 第三方对开源代码的分析，非官方声明，以软件内列表为准 |

**SWR / ALC 告警**（0.93 设置里有开关）只对上表标注支持的系列有效；不支持的机型上这两项读数本来就取不到，开关开着也只是不告警。

## 三、按连接方式反查：你的电台走哪条路

| 你的条件 | 可走的方式 | 代表机型 |
| --- | --- | --- |
| 想完全无线 | 蓝牙 | GUOHE Q900、X6200（固件 1.06+） |
| 想无线且电台带网口/Wi-Fi | 网络 | 部分 ICOM、FlexRadio 6000 系列、X6100（固件 1.1.7+，见上表限制） |
| 手机 + 线最省事 | USB（OTG） | 只要电台有 USB 声卡 + 串口，主流机型基本都走这条 |

网络方式还有个组网细节：**热点直连（AP 模式）优先于经路由器中转（Station 模式）** —— 官方发行说明点名过后者在部分家用路由器下会引入丢包与延迟，无线连接不稳时先把这一层排除掉再怀疑软件（接法见 [连接电台的设置方法.md](连接电台的设置方法.md)）。

## 四、型号选错、固件不够的典型症状

- **型号选错**：软件发出的指令集与电台对不上，症状就是「什么都控制不了」—— 频率不同步、PTT 不触发，但收音可能正常。回去改型号即可，波特率同理（见 [连接电台的设置方法.md](连接电台的设置方法.md) 第二节）。
- **双串口没选对**：插上后弹出的串口列表里选错一个，表现与「没连上」一样；换另一个再试。
- **固件低于门槛**：X6200 低于 1.06 蓝牙配对就可能出问题，X6100 低于 1.1.7 没有 Wi-Fi 模式 —— 先升固件再排查软件。
- **症状分层**：到底是「没连上」还是「连上了收不到」，判法在 [收不到信号与无法解码的排查.md](收不到信号与无法解码的排查.md)。

还拿不准你的型号支不支持，最直接的办法是打开设置翻一遍型号列表；列表里没有、又必须用的机型，走官方反馈入口提问（入口见 [下载与安装教程.md](下载与安装教程.md) 第六节）。
