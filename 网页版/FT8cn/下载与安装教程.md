## 一、这是什么，适合谁

FT8CN 是一款安卓手机上的 FT8 通信软件，开发者是业余无线电爱好者 BG7YOZ，免费开源。它把通常要跑在电脑上的 FT8 收发流程搬进手机：你把手机接到电台上，手机负责收音频、解码、按 15 秒周期送出信号，笔记本可以不带出门。

两类人用得上：

- **有电台、想轻装出门通联的人**：一部手机 + 一台电台就能完成 FT8 收发，适合户外、应急或桌面积有限的场景；
- **只有短波收音机的纯接收用户（SWL）**：不接发射，只用手机解码空中的 FT8 报文，看别人通联也能玩。

先把边界说清：**手机本身不发射无线电，发射由电台完成**；发射须遵守当地无线电管理规定并持有相应执照，纯接收解码则没有这个要求。

## 三、系统要求

| 要求 | 说明 |
| --- | --- |
| 系统 | Android 6.0 及以上，官方快速手册注明兼容鸿蒙系统（以官方手册为准） |
| 麦克风 | 必须能录音 —— 靠它收电台的声音，没录音权限什么都解不出来 |
| OTG | 只在你要用 USB 线连电台时才需要，手机要支持 OTG 或配一个 OTG 转接头 |
| 网络 | FT8 对时钟精度要求在 1 秒以内，手机要能联网校时；完全离线时钟会越走越偏 |
| 蓝牙 | 可选，仅蓝牙控制的电台需要 |

## 四、获取与安装步骤

1. 打开 [FT8CN 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6afdbc62ce99)，把安装包转存到自己的网盘再下载到手机；电脑端下载后用数据线拷进手机也一样。
2. 下载完顺手校验一遍 MD5，结果应当是 `4408236014135E0C697DA357DE23D604`，对不上说明传输中文件损坏了，重新下载。
3. 点击 APK 安装。系统若弹「禁止安装来自此来源的应用」，到 `设置 → 安全（或隐私）→ 安装未知应用`，允许你使用的下载工具（浏览器、文件管理器等）安装一次即可，装完可以关掉。
4. 装好后先别急着连电台，把首次打开的权限与必填项过一遍（下一节）。

想直接看官方最新版，发行页在 [gitee.com/nijialoop/ft8cn/releases](https://gitee.com/nijialoop/ft8cn/releases/)（分流地址见第六节）。

## 五、首次打开：三个权限、两项必填

**权限**（官方快速手册的口径）：

| 权限 | 要不要给 | 用途 |
| --- | --- | --- |
| 录音 | **必须给** | 采集电台发出的声音，是解码的唯一输入 |
| 定位 | 可选 | 自动算出你的 Maidenhead 网格，不给就手动填 |
| 蓝牙 | 可选 | 只有走蓝牙控制的电台才用得上 |

两个注意点：**有些机型第一次运行就授予了录音权限、却仍然录不进去，重启一次 FT8CN 就恢复**；判断录音到底通没通，看频谱页 —— 频谱有起伏说明声音进来了，一片死平就是没录上（排查步骤见 [收不到信号与无法解码的排查.md](收不到信号与无法解码的排查.md)）。

**必填项**：首次启动会让你填**呼号**与**网格**（Maidenhead 定位，如 `PM95` 这样的四字母数字组合）。呼号是你在通联中报出的身份，网格是你所在的位置，这两项会进到你发出的每一条报文里；只收不发也建议先填对，否则消息列表里的信息对不上号。
