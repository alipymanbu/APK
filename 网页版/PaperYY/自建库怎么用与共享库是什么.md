## 一、自建库是什么，什么时候才需要它

按官方定义：**自建库是你自己上传参考文献资源建立的比对库**。你把写作时参考过的文献传进去，提交检测时勾选它，系统就会把你的论文同时和「自建库 + 本地库 + 网络库」对比。

它要解决的是一个公共库解决不了的问题：**你参考的那份资料本身不在公共库里**。

| 你参考的东西 | 公共库能查到吗 | 要不要用自建库 |
| --- | --- | --- |
| 已发表的期刊、学位论文 | 一般能 | 不必，直接查就行 |
| 导师给的未发表初稿、课题组内部报告 | 查不到 | 要 |
| 学长学姐没公开的毕业论文 | 查不到 | 要 |
| 自己上一版写过、这次要接着用的段落 | 查不到 | 要，否则自引不会被发现 |
| 网上的公开文章、百科条目 | 多数能 | 不必 |

**判断标准就一句**：如果你参考的资料在公共库里搜不到，而你又想知道「我和它重了多少」，才需要自建库。想查整篇是不是抄了网上的东西，那是公共库的职责，建库帮不上忙。

## 二、怎么传进去

入口在自建库的上传页。上传页对文件的限制写得比较明确，**截至 2026-09 官方上传页标注为**：

| 项目 | 要求 |
| --- | --- |
| 支持格式 | doc、docx、pdf、txt |
| 单个文件大小 | 不超过 15M |
| 上传方式 | 点击选择文件，或直接把文件拖进上传区 |

超过 15M 的常见原因是文档里塞了大量高清图片；参考资料一般用不到图，压缩或另存后再传。

传完之后**别只看「上传中」，去自建库的文档管理页面确认文件已经在列表里**。传上去了但没进列表，后面勾选时是找不到它的。

## 三、最容易踩的坑：提交时没勾

**建了自建库不等于会用它查。** 官方给的使用步骤只有两句，第二句才是关键：

1. 先把参考过的资料上传到自建库；
2. **提交论文时，在比对源选择页面上勾选该自建库。**

没勾 = 自建库不参与比对 = 你前面白传。这一步在提交页上通常和选择查重版本在同一屏，很容易被当成付费选项顺手取消掉。

**一个自检办法**：提交完成后看报告里的比对来源说明，如果里面没有你自建库的内容，说明这次没勾上。

提交前的准备步骤与各版本计费口径，见[怎么提交论文查重与次数怎么算.md](怎么提交论文查重与次数怎么算.md)；传上去发现没生效、或者提交时找不到自建库选项，见[常见问题与排查.md](常见问题与排查.md)。

## 四、花不花钱

自建库查重本身是**按 0 元/千字**计费的，官方同时标注它的**免费次数不限**（截至 2026-09 的提交页口径，会调整，以官方页面为准）。

也就是说：**你花的是「把你的资料传上去」这件事的工夫，不是钱。** 传进去的资料长期有效，之后每次查重都能勾选复用，不用重复上传。

## 五、共享库与机构库

自建库页面上还有两个分层，别和「一人自建资料库」混起来：

- **一键共享资料库**：加入共享后，可以把全网共享库的全部文献纳入你自己的自建库。自建库页面上给出的量级是「全网共享库现有文献 1316395 篇」「累计机构共享库文献 43598 篇」——**这些数字每天在变**，看个量级就行。
- **多人共建机构库**：以学校院系、课题组为单位共建一个专属库，适合「同一批人反复查同一批内部资料」的场景。

关于共享，官方有两条说明要一起看：

1. 加入共享即可把全部共享文献纳入你的自建库；
2. **「即使您共享了自建库，其他用户也无法查看到您的论文。」**

两条并不冲突：共享交换的是**可比对的资料**，不是文档原文的浏览权限。但仍有一个问题需要你自己判断——**把你自己的原创论文放进共享池当比对源，是否合适**。如果你的论文还没定稿、还没发表，更稳妥的做法是不共享、只留作个人自建库。

## 六、传错了怎么办

官方 FAQ 专门有一条问「把自己的原创论文不小心上传到自建库怎么办」，答案是：**在自建库的文档管理页面删除即可**，删除是即时的。

所以用完记得回去清一遍：**你上传的那份文件本身是存在平台上的**，不用了就删掉，别把内部资料长期留在那里（相关的可见性规则见[报告和论文会不会泄露.md](报告和论文会不会泄露.md)）。
