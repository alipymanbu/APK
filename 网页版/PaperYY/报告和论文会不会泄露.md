## 一、官方给出的安全口径

先声明一句：下面这些都是**官方说明**，第三方没有能力独立验证，所以照原样列出，供你判断。

| 问题 | 官方说明 |
| --- | --- |
| 传输与存储 | 全站使用 HTTPS 加密协议；文档上传至华为云 OBS |
| 服务器 | 采用阿里云认证的高防服务器 |
| 报告保留 | 默认只保留 **7 天**，支持自行删除、支持报告加密 |
| 会不会被收录 | 不会将你提交的文件收录或添加到比对数据库 |
| 唯一的例外 | 你自己把论文发布到能被收录的期刊或平台；学校的优秀毕业论文一般由导师提交给图书馆后统一送检 |
| 代写 | 官方明确表示不提供任何代写服务 |

「不收录」这一条值得单独说清：它意味着**你今天在这里查过的论文，不会因为查过就变成日后被别人查出的比对源**。这和你自己把论文发到公开渠道是两码事。

## 二、自建库的可见性

自建库是你自己上传的参考资料库，它的可见性规则是：

- **只有你本人能看到**，官方称其为「无痕检测」；
- **即使你共享了自建库，其他用户也看不到你上传的论文内容**；
- 想删掉已上传的资料，在**自建库的文档管理页面**里直接删除即可，删除是即时的。

如果你论文里参考的是导师给的未发表资料、内部报告这类不便外传的文件，用自建库比把原文直接粘进正文更稳妥，但要清楚：**你上传进去的那份文件本身仍然在平台上**，用完记得去管理页面删掉。

关于「共享」，官方有两条说法要分清：一条是「加入共享即可将全部文献纳入到你的自建库」，另一条是「**即使您共享了自建库，其他用户也无法查看到您的论文**」。前者说的是共享交换的是**可比对的资料**，后者说的是**文档原文的浏览权限仍然只属于你**。但「把我自己的原创论文放进共享池当比对源是否合适」是另一个问题，需要你自己判断——论文还没定稿、还没发表时，建议不做共享。上传格式、勾选步骤与三个共享分层见[自建库怎么用与共享库是什么.md](自建库怎么用与共享库是什么.md)。

## 三、报告才是更容易被忽略的一环

多数人担心的是「上传会不会泄露」，实际更容易出事的是**报告**——它包含你论文的全文标注，而你往往把它随手放在好几个地方。

按这几点处理：

1. **出了结果当天就下载**，因为平台上只保留 7 天（见[查重报告怎么看.md](查重报告怎么看.md)）；
2. **在平台上用完就删**。官方支持自行删除报告，也支持给报告加密——如果某份报告还要留着复查，加个密；
3. **下载下来的文件别乱放**：不要留在公共电脑、网吧机器、共享打印店的机器上；
4. **别通过群聊、大群文件长期留存报告**，转发过等于多了一份不受你控制的副本；
5. **旧手机转手前处理干净**：退出账号、卸载 App，并且删掉本地下载目录里的报告文件——这些文件不随账号注销而消失。

## 四、注销账号前必须做的两件事

注销是不可逆的，且各端会一并退出（见[注册登录与多端同步.md](注册登录与多端同步.md)）。动手之前：

1. **把还需要用的报告下载到本地**，账号一注销就再也取不回；
2. **清空自建库**，确认里面没有还需要保留的参考资料。

## 五、你还能额外做的

官方口径之外，把风险再往下压一点的做法：

- **提交前删掉论文里的个人信息**：封面上的姓名、学号、导师姓名、致谢里的人名，学校查重时通常也不查封面，去掉不影响结果；
- **分章节提交**：只想确认某一节的重复情况时，不必把整篇传上去；
- **不要在非官方渠道提交**。第三方代理查重站点拿走的是同一份论文，而你并不知道它怎么存、存多久。要查就自己在官方页面查（入口见[怎么提交论文查重与次数怎么算.md](怎么提交论文查重与次数怎么算.md)）。

最后一条实话：**任何在线检测都要求你先把论文传上去**，能做的只是控制「传给谁、留多久、有多少份副本」。把上面这几件小事做完，风险就压到了平台自身安全水平这一层。
