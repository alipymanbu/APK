## 一、三种扫描来源

主屏幕的「**扫描**」磁贴里可以选三种取材方式：

1. **打印机扫描**：把原稿放在打印机玻璃板或自动进纸器（ADF，仅部分机型带）上，扫到手机——这是多数人用的一路，多页文件用进纸器一次送完；
2. **导入照片**：从手机相册选已有图片当作扫描件处理；
3. **手机摄像头拍摄**：直接用摄像头拍纸面文档，效果上更接近「拍照后修边」，光线不好时不如真扫描。

手机必须与打印机在**同一个 Wi-Fi 网络**里，打印机这一路才走得通；不在一个网里时应用里根本找不到那台打印机。

## 二、扫描设置逐项调

开始扫描前后能改的设置（移动端在屏幕底部的任务类型和顶部的设置菜单里）：

| 设置项 | 选项与建议 |
| --- | --- |
| 任务类型 | 文档、照片、批次处理——批量扫多份材料用批次处理，一份扫完接着放下一份 |
| 纸张大小 | Letter、A4、4x6 英寸等，与实际原稿一致 |
| 输入源 | 自动、扫描器玻璃板、送稿器（ADF）——厚照片别走进纸器，容易刮伤 |
| 解析度 | 300 dpi 够日常文档；要高画质再选 1200 dpi（更慢、文件更大） |
| 颜色 | 彩色或灰度，黑白文稿选灰度省体积 |

扫描后若出现「检测边界」画面：**自动**让应用找边缘，**完整**保留整幅，**手动**拖动边点自己框。

## 三、预览、保存与文件类型

扫描完成后进入预览：可以加页（继续扫或导入）、旋转、对单页编辑、替换或删除，然后保存：

- **基本 PDF**：多页合成一个文件——发别人的合同、证书选这个；
- **影像（JPEG）**：每页存成单独图片——照片、素材选这个；
- 保存时还能改文件名和压缩设置，落点选手机本地或云账号。

注意一个容易期待落空的地方：**多项识别、书本扫描、自动去手影、存成可搜索 PDF 或 Word** 这几个进阶选项属于 HP+ 机型（HP Smart Advance）的能力，普通机型上看不到这些选项是正常的。

## 四、扫描完直接分享

预览页的分享按钮可以把结果直接交出去：

- **邮件**：系统会打开手机上的邮件应用并把扫描件作为附件，前提是邮件账号已经在手机系统里配置好；
- **云存储**：传到应用内绑定的云账号；
- **短信 / 聊天应用**：走系统的分享面板发给任意应用；
- **传真**：要走「移动传真」磁贴单独发，完整步骤见[手机发传真.md](手机发传真.md)。

经常重复「扫描后发邮件 / 存云盘」这套动作的话，把它配成一键快捷方式更省事，见[快捷方式一键任务.md](快捷方式一键任务.md)。

## 五、扫描失败常见原因

- 应用里找不到打印机：先按[常见问题排查.md](常见问题排查.md)把连接恢复，扫描自然就好；
- 从进纸器扫描卡纸：取出整叠纸抖齐、撕掉粘住的便签再放；
- 扫出来一片黑：玻璃板上的原稿没盖好盖子，或玻璃面脏了，擦干净重扫；
- 扫出来有黑边、歪斜：回到预览页裁剪，或重新扫一次选「自动」边界。

扫描件要打印出来的话，流程在[打印照片与文档.md](打印照片与文档.md)。
