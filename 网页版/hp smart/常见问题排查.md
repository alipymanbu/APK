# HP Smart 常见问题排查

> 本篇按故障现象分了五类：找不到打印机、显示离线、任务卡住、扫描失败、远程打印不可用，每类先给最快的自查顺序，最后附一节兜底重置。

## 一、先分清是哪一类

卡住的现象不同，处理路径完全不同，动手前先对号入座：

- **添加打印机时列表里没有它**——连接还没建立，看第二节；
- **之前能用，现在显示离线**——连接断了，看第三节；
- **能连上，打印任务发出去没动静**——打印机侧的问题，看第四节；
- **扫描不动或扫出来不对**——看第五节；
- **人不在家，远程打印发不出去**——账号与网络条件问题，看第六节。

## 二、添加时找不到打印机

按出现频率从高到低排：

1. **手机和打印机不在同一个网络**：手机连了邻居家的 Wi-Fi、连了访客网络、或用了流量，列表里都不会有打印机；
2. **双频路由器只给打印机连 2.4 GHz**：不少 HP 家用机型只认 2.4 GHz 频段，路由器把两个频段分开命名时，让打印机接 2.4 GHz 那个；
3. **定位权限没给**：安卓上 HP Smart 靠定位权限辅助发现打印机，系统设置里把它打开；
4. **打印机不在设置模式**：新机或换过网络后，把打印机还原到 Wi-Fi 设置模式（触屏机型在「网络设置」里还原；无屏机型用面板按键），然后 **2 小时内**重开应用重新设置；
5. **AP 隔离**：路由器开了 AP 隔离（访客网络常见），设备互相看不见，关掉或换主网络。

具体还原步骤与按键组合见[添加打印机与无线连接.md](添加打印机与无线连接.md)第四节。

## 三、打印机显示离线

1. 看打印机面板有没有报错（卡纸、缺墨、缺纸），先排除硬件提示；
2. 打印机**待机时间长了会进睡眠**，面板点一下唤醒，等半分钟到一分钟再刷新应用；
3. 重启打印机（关电源再开），仍不行就**重启路由器**——多数「莫名离线」是路由器侧的分配问题；
4. 打印机面板上确认它还连着原来的 Wi-Fi（换过路由器或改过 Wi-Fi 密码，打印机里存的旧网络就失效了，要重新走一遍添加流程）。

## 四、打印任务卡住

1. 打印机面板或应用里看任务队列，把卡住的任务**取消**后重发一次；
2. 确认纸盒里有纸、墨盒/连供有余墨；
3. 照片任务打了半天不出来，多半是高精度设置+大文件在慢慢传，别急着取消；
4. 反复卡住就重启打印机和手机两端再试。

## 五、扫描失败或结果不对

- **应用里找不到扫描仪**：手机与打印机不在同一网络、或打印机刚重启还没就绪，等它面板显示就绪再扫；
- **进纸器扫描卡纸**：把整叠纸抖齐、抽出粘住的照片或便签，重新放好；
- **扫出来有黑边、歪斜**：预览页里旋转、裁剪后再保存；
- **扫出来一片黑**：盖板没盖严或玻璃板脏了；
- **摄像头拍文档太暗**：换个光线均匀的环境重拍，拍时让纸占满取景框。

## 六、远程打印（Print Anywhere）不可用

远程打印不是默认就有的，它要求：

1. 打印机已在 HP Smart 里用 **HP 账号**完成设置；
2. 打印机**连着能上网的网络**（只连 Wi-Fi 但路由器断网时，远程任务发不到）；
3. 应用里「从任意位置打印」开关是打开的（账号页 → Solutions → Print Anywhere）；
4. 机型支持——HP+ 机型（型号带 e）和部分指定机型支持，老机型可能压根没有这一项。

在意隐私的话，可以开「Private Pickup（私密取件）」，任务先挂在云端，人走到打印机旁边用手机确认后才出纸。开关位置、取件步骤、机型清单见[远程打印与私密取件.md](远程打印与私密取件.md)。

## 七、都不行：按这个顺序重置

反复排查无效时，按从轻到重的顺序来，每做一步试一次：

1. 重启打印机 → 重启路由器 → 重启手机；
2. 手机上清除 HP Smart 的数据或卸载重装（安装包从[下载与安装教程.md](下载与安装教程.md)取）；
3. 打印机恢复出厂设置，重新走一遍添加流程。

走到第三步前，建议先把打印机的耗材状态拍张照留底，恢复出厂不会丢耗材信息，但自定义设置会清掉。
