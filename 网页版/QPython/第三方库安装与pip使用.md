## 一、两条路分别适合什么

官方介绍写明 QPython 内置解释器与 PIP 包管理，装库这件事有两种走法：

| 路线 | 入口 | 适合装什么 | 特点 |
| --- | --- | --- | --- |
| QPYPI | 主界面的「扩展 / QPYPI」 | 已经预编译好的常用包（纯 Python 的包居多） | 点选即可，不用敲命令 |
| pip 命令 | 终端里敲 `pip3 install ...` | QPYPI 上没有的包、要锁版本的包 | 与电脑上的用法一致，来源是公共 PyPI |

先试 QPYPI——它上面的包是按安卓环境准备好的；QPYPI 没有再走 pip。

## 二、用 pip 装包（终端里）

```bash
pip3 install requests
pip3 install requests==2.25.1
```

带 `==版本号` 的写法能锁死版本，跟教程保持一致时建议照抄版本号，避免新版接口变了报错。

**国内网络下指定镜像源**能显著提高成功率（PyPI 官方源在境外，超时是装不上的头号原因）：

```bash
pip3 install requests -i https://pypi.tuna.tsinghua.edu.cn/simple
```

升级已装的包：

```bash
pip3 install --upgrade requests
```

装完验证，在同一个终端里：

```python
import requests
print(requests.__version__)
```

能打印出版本号，这个库就算装好了，脚本里直接 `import` 即可。

## 三、装不上时按这个顺序排查

1. **先看报错类型**（输出在终端里，往上翻）：`ReadTimeout` / `Connection` 类是网络问题，加镜像源重试。
2. **包需要编译 C 扩展**：报 `setup.py` / `gcc` / `Failed building wheel` 之类，说明这个包在手机上没法就地编译——**换 QPYPI 上的预编译版本**，或找这个包的纯 Python 替代品。带原生代码的重型库（部分科学计算、数据库驱动）在手机上本来就受限。
3. **依赖冲突**：提示某个依赖的版本要求互相打架时，先只装你直接要用的那个包，让 pip 自己解依赖；仍冲突就锁一个较旧、彼此兼容的版本。
4. **空间与权限**：手机存储快满、或系统限制了应用目录写入时，安装会中途失败——先清理空间，再确认 QPython 的文件读写权限是开的（见 [常见报错与问题排查.md](常见报错与问题排查.md)）。
5. **SSL 握手报错**（如 `SSL: NO_CIPHERS_AVAILABLE`）：有用户在用 requests 访问 HTTPS 时遇到过，属于环境层的加密套件兼容问题，处理办法见 [常见报错与问题排查.md](常见报错与问题排查.md) 对应条目。

**同一份包只装一处**：QPYPI 装过又用 pip 装一遍同名库，可能让解释器加载到其中一份旧的，出现「明明装了却 import 不到新版本」。需要换路线时，先卸掉再装。

## 四、装完的包放在哪、怎么管

pip 装的库落在 QPython 自己的应用目录下的 site-packages 里，你在终端或编辑器里 `import` 都能拿到，**不需要**像电脑那样配 `PYTHONPATH`。查看已装的包：

```bash
pip3 list
```

要删掉某个包：

```bash
pip3 uninstall 包名
```

脚本本身则存在你保存时选的那个目录里（见 [第一个脚本怎么写并运行.md](第一个脚本怎么写并运行.md)）——**库和脚本是两回事**，一个在应用目录、一个在你选的文件夹。

## 五、这几个库最常被问到

- `requests`：网络请求。手机上访问 HTTPS 若报 SSL 相关错误，见 [常见报错与问题排查.md](常见报错与问题排查.md)。
- `numpy` / `pandas`：科学计算。属原生扩展较重的库，能否顺利装上取决于包是否提供对应安卓架构的预编译版本——优先从 QPYPI 里找。
- `androidhelper` 相关的系统调用：不需要装，QPython 自带，见 [脚本调用安卓功能教程.md](脚本调用安卓功能教程.md)。
