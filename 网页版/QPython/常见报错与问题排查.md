## 一、先把报错读明白

QPython 的报错分两层，别混着看：

- **Python 层**：`SyntaxError`、`IndentationError`、`ModuleNotFoundError`、`ImportError` —— 你的代码或环境问题，报错里带文件名和行号，照着行号回编辑器改。
- **系统层**：`EACCES (Permission denied)`、`SecurityException`、SSL/连接类异常 —— 安卓或网络那侧拒绝了你，代码本身没写错，要动的是权限与网络。

下面每条都按「现象 → 原因 → 处理」写，对号入座即可。

## 二、装库相关

### 1. pip install 卡住或超时

- **现象**：终端里 `pip3 install xxx` 长时间没动静，最后 `ReadTimeout` / `Connection timed out`。
- **原因**：默认源在境外，链路不稳。
- **处理**：带镜像源重装——`pip3 install xxx -i https://pypi.tuna.tsinghua.edu.cn/simple`（详见 [第三方库安装与pip使用.md](第三方库安装与pip使用.md)）。

### 2. 提示 `Failed building wheel` / 找不到 `gcc`

- **现象**：安装过程里出现编译类字样，最后失败。
- **原因**：这个包带 C 扩展，需要在手机上现场编译，而手机上没有完整工具链。
- **处理**：换 QPYPI 里预编译好的版本，或找纯 Python 的替代包。**这不是你命令敲错了**，别反复重试同一个包。

### 3. 明明装了却 `ModuleNotFoundError`

- **现象**：pip 显示 Successfully installed，脚本里 `import` 仍然找不到。
- **原因**：装到了别的解释器路径、或之前用另一条路线装过同名包，两份互相遮挡。
- **处理**：`pip3 list` 确认包在不在；先 `pip3 uninstall 包名` 清干净，再用单一路径重装一次。脚本与库的关系见 [第三方库安装与pip使用.md](第三方库安装与pip使用.md) 第四节。

## 三、网络与 SSL

### 4. `SSL: NO_CIPHERS_AVAILABLE` 一类的握手报错

- **现象**：用 `requests` 访问 HTTPS 网站时抛 SSL 相关异常，普通网页能打开。
- **原因**：手机端 Python 环境与目标站点的加密套件协商不上，属环境兼容问题，有用户实测遇到过。
- **处理**：先确认同一个地址在系统浏览器里打得开（排除站点本身的问题）；再把请求里的 SSL 校验按你的场景调整，或换一个目标站点验证是不是个别站点的问题。改动只针对你自己的脚本，不要全局关闭校验后忘了改回来。

### 5. 脚本里联网请求没反应

- **现象**：请求一直挂着不返回。
- **原因**：手机网络切换（Wi-Fi 与流量来回切）、或脚本在前台被系统节流。
- **处理**：给请求加超时参数让它明确失败，而不是无限等；切回稳定网络再跑。

## 四、文件与权限

### 6. `open failed: EACCES (Permission denied)`

- **现象**：读写文件时报权限拒绝，路径多半指向公共目录（Download、SD 卡）。
- **原因**：安卓高版本对应用访问共享存储有限制，或你没给 QPython 文件权限；应用商店评论里也有个别机型反馈「文件读写权限开不了」。
- **处理**：到 设置 → 应用管理 → QPython → 权限 里允许「文件和媒体 / 所有文件访问」；仍不行就把文件存到 QPython 自己的目录下（编辑器保存时选应用内的目录最省事）。

### 7. 调用相机、传感器、剪贴板被拒

- **现象**：[脚本调用安卓功能教程.md](脚本调用安卓功能教程.md) 里的调用抛权限类异常。
- **原因**：对应的运行时权限没开。
- **处理**：同上到应用权限页逐项允许；用完不需要的权限可以随时撤销（4.x 的设置页里就有对应开关）。

### 8. 找不到刚保存的脚本

- **现象**：编辑器保存成功，「文件」里翻不到。
- **原因**：保存目录与「文件」当前浏览的目录不一致。
- **处理**：看编辑器标题栏显示的路径，按那个路径往上找；养成固定存一个目录的习惯，见 [第一个脚本怎么写并运行.md](第一个脚本怎么写并运行.md) 第二节。

## 五、运行与界面

### 9. 点了运行没看到输出

- **现象**：界面没变化，或一闪而过。
- **原因**：输出在终端窗口里，而你停在编辑器页。
- **处理**：切到终端，向上滚动找结果与 traceback；报错行号与编辑器里的行号是对应的。

### 10. 桌面小组件添加后不显示

- **现象**：添加了 QPython 小组件，桌面上不出现（应用商店评论里有安卓 15 用户反馈过）。
- **原因**：系统对后台与小组件的限制，属个别系统版本上的表现。
- **处理**：先给 QPython 允许自启动与后台运行，再删掉小组件重新添加一次；仍不显示就不用小组件——从应用图标进主界面跑脚本，功能不受影响。

### 11. 启动闪退 / 打不开

- **现象**：点图标立刻退出。
- **原因**：安装包不完整、与旧版本数据冲突、或系统版本过低。
- **处理**：按 [下载与安装教程.md](下载与安装教程.md) 第二节核对包大小与包名（`org.qpython.qpy`），不对就重新下载；再试卸载后重装（会丢掉已装的库与脚本，先备份你存的 `.py` 文件）。

## 六、还查不到答案时去哪问

- 官网 [www.qpython.com](https://www.qpython.com/) 上有配套课程与社区入口；应用商店页的开发者支持信息里给了微信学习社区、视频号「QPython编程」与公众号「QPY+」这些渠道。
- 英文社区可到 Stack Overflow 打 `qpython` 标签提问（[stackoverflow.com/questions/tagged/qpython](https://stackoverflow.com/questions/tagged/qpython)）。
- 提问时把**完整报错文本、安卓版本、QPython 版本（4.0.1 那份看设置页）**一起贴上，比只说「跑不起来」更容易被回答。
