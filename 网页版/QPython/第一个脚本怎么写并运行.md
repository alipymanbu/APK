## 一、先认清主界面那几个入口

装好打开（安装见 [下载与安装教程.md](下载与安装教程.md)），首屏常见这几项，各管一段：

| 入口 | 你用它做什么 |
| --- | --- |
| 终端 | 像电脑上的命令行：一行一行敲 Python 语句，回车立刻出结果，用来试语法、查属性最顺手 |
| 编辑器 | 写多行代码，保存成 `.py` 文件；带语法高亮与行号 |
| 文件 | 浏览已经保存的脚本，点一个就能选「运行」 |
| 二维码 | 把电脑上写好的代码转成二维码，用手机扫一下读进来，省去打字 |
| 扩展 / QPYPI | 安装第三方库（详见 [第三方库安装与pip使用.md](第三方库安装与pip使用.md)） |

不同版本的入口名称与排布会有出入，找不到某一项时按图标含义认（终端是命令行图标、编辑器是铅笔/文档图标）。

## 二、写第一个脚本（编辑器路线）

1. 点「编辑器」进入，用新建（一般在右上角是加号或文件图标）建一个文件，命名为 `hello.py`。
2. 敲入：

```python
print("Hello, QPython!")
```

3. 点保存（文件图标），选一个自己记得住的目录——**别放太深的路径**，一会儿要在「文件」里找到它。
4. 点运行按钮（保存按钮旁边通常是运行），界面会跳到终端，底部输出：

```
Hello, QPython!
```

编辑器的缩进靠键盘工具条上的进/退格箭头控制——Python 对缩进敏感，手滑多一个空格就会报 `IndentationError`。

## 三、不想存文件就直接试（终端路线）

点「终端」进去，就是一个交互式解释器：

```python
>>> [1, 2, 3]
>>> sum([1, 2, 3])
6
```

输完立刻回显，退出按返回键即可（返回键关掉当前终端页，不会删你已存的脚本）。**试想法用终端，成体系的程序用编辑器**，两条路写的都是同一套解释器，语法一致。

终端还有几个容易被忽略的开关：有公开教程提到，在终端页的菜单里可以**启用 Wake lock（保持唤醒）与 Wi-Fi lock（保持联网）**——跑一个要跑十几分钟的脚本前把保持唤醒打开，屏幕熄灭后脚本不容易被系统打断；同一菜单里也能新开一个终端页、在多个终端之间切换（以你这版界面实际显示为准，找不到就跳过，不影响写代码）。

## 四、跑一个已经存在的脚本（文件路线）

回到主界面点「文件」，找到刚才保存的 `hello.py`，点它会弹菜单，选「Run / 运行」，结果照样出现在终端窗口里。从这里跑出来的脚本，相对路径以运行时的工作目录为起点——所以「明明文件在脚本旁边却读不到」的情况照样会发生，判据与修法见 [脚本找不到文件怎么定位路径.md](脚本找不到文件怎么定位路径.md)。

## 五、把电脑上的代码搬进手机（二维码路线）

在电脑上把代码做成二维码，回到 QPython 点「二维码」扫码，内容会被读进来，你可以直接存成 `.py`。适合临时贴一小段代码；整份工程文件还是走网盘或数据线拷贝更稳。

## 六、第一次跑，这几点最容易卡住

- **保存了却在「文件」里找不到**：多半是存到了另一个目录。回编辑器看标题栏显示的路径，或在「文件」里往上翻一层。
- **运行后窗口一闪而过看不到输出**：输出在终端里，往上翻滚看；报错信息也在这里，照它提示的行号回编辑器改。
- **改完没生效**：确认点的是「保存」而不是直接返回——没存盘的改动运行时读不到。
- **代码要用第三方库**（`requests`、`numpy` 之类）：先去装，见 [第三方库安装与pip使用.md](第三方库安装与pip使用.md)。
- **运行报错看不懂**：常见报错的成因与处理，整理在 [常见报错与问题排查.md](常见报错与问题排查.md)。
- **脚本报 `FileNotFoundError` / 找不到数据文件**：多半是工作目录与你想的不同，按 [脚本找不到文件怎么定位路径.md](脚本找不到文件怎么定位路径.md) 三段代码定位。

## 七、想让脚本调用手机硬件

写个提示框、读个电量、拍张照片这类需求，靠的是 QPython 内置的 QSL4A 能力——用 Python 直接调安卓系统接口，写法与常见例子见 [脚本调用安卓功能教程.md](脚本调用安卓功能教程.md)。

## 八、这个环境还能跑什么（官方简介列的方向）

应用商店里这份应用的官方简介（检索于 2026-09-26）把能力范围列成这几项，你挑方向时可对照：

| 方向 | 简介里提到的组成 | 你实际要做的第一步 |
| --- | --- | --- |
| 交互式编程 | QNotebook 浏览器跑 Jupyter Notebook 文件 | 先按本篇第二节写通一个 `.py`，再考虑 Notebook |
| 科学计算 | NumPy、Scikit-learn 等库的安装与管理 | 走 [第三方库安装与pip使用.md](第三方库安装与pip使用.md)，装不上按那里的顺序排查 |
| Web 开发 | 简介把 Web 开发列为支持方向 | 先在终端里用标准库起个本地服务试通，再决定上框架 |
| 本地 AI | 简介写明集成 Ollama 框架，可在移动端运行 Llama3.3、DeepSeek-R1、Phi-4、Mistral、Gemma2 等大语言模型 | 以应用内实际入口为准——模型清单与入口会随版本调整，官方页面当时显示的说法优先 |

这张表只是**方向索引**，不是「都能直接跑通」的承诺：能否装上某个库、能否加载某个模型，取决于你这台手机的配置与当时的版本，逐步验证即可。
