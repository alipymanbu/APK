## 一、这是干什么用的

你在 [第一个脚本怎么写并运行.md](第一个脚本怎么写并运行.md) 里写的都是纯 Python 逻辑；这一篇往前一步——**让脚本碰到手机本身**：弹个提示框、读电量、拿剪贴板内容、调相机拍一张。QPython 把这些安卓系统能力封装成 Python 可调的接口，官方介绍里管这套东西叫 QSL4A（老牌的 Script Layer for Android 一脉），项目说明里列出的覆盖范围包括联系人、定位、电话、短信、音频、媒体播放、剪贴板、网络状态，以及相机、传感器、音量、屏幕亮度、电池、蓝牙、振动、NFC、USB 等硬件管理。

**你不需要额外安装它**——QPython 装完就自带。

## 二、第一行写什么：找到那个桥接对象

写法上历来有两种入口名，不同版本内置的模块名不完全一样，**先试第一个，报模块不存在就换第二个**：

```python
import androidhelper
droid = androidhelper.Android()
droid.makeToast("你好，QPython")
```

```python
import android
droid = android.Android()
droid.makeToast("你好，QPython")
```

`droid` 就是你调用安卓功能的入口：后面接方法名，一个方法对应一类系统能力。`makeToast` 会在屏幕上弹一条短暂的文字提示——用它验证「桥接通了」最快，因为成功与否一眼能看见。

> 若两个入口都提示 `ModuleNotFoundError`，说明你手上这一版的内置模块名另有写法，去官网 [www.qpython.com](https://www.qpython.com/) 的课程与文档页确认当前版本的导入方式，别照老教程硬敲。

## 三、一条能直接跑通的完整例子

在编辑器里建 `toast_demo.py`，保存后运行：

```python
import androidhelper

droid = androidhelper.Android()
droid.makeToast("脚本跑通了", duration="short")
print("已发送提示")
```

终端先打印 `已发送提示`，同时屏幕上浮出文字提示——**两个输出都出现**，说明脚本既在解释器里跑了，也成功让安卓那侧执行了动作。只看到 print、没看到提示条，就是桥接没接上，往下看第五节。

## 四、这些能力分三类，按需取用

| 类别 | 典型动作 | 你可能的场景 |
| --- | --- | --- |
| 界面反馈 | 弹提示条、对话框、输入框 | 脚本跑完告诉用户结果；让脚本向你问一个参数 |
| 系统状态 | 电量、网络状态、剪贴板、传感器读数 | 写个脚本判断「低电量就停」；批量读剪贴板内容 |
| 硬件与应用 | 相机、振动、音量、屏幕亮度、启动其他应用 | 定时拍照、给脚本加振动提醒、自动化点开某个应用 |

调用前后的两条硬规则：

1. **系统权限要先开**：涉及相机、存储、定位、短信这类敏感能力，得在 设置 → 应用管理 → QPython → 权限 里允许对应项，否则调用会直接被系统拒（报错表现见 [常见报错与问题排查.md](常见报错与问题排查.md)）。QPython 4.x 的设置页里也能看到「所有文件访问权限」这类开关，按需打开、不用的可以随时撤销。
2. **拿不到就别硬猜**：某个方法名在你的版本里可能有增减（这类接口随版本迭代会加新函数）。先用最小例子验证方法存在，再往脚本里堆逻辑。

## 五、桥接不通时的检查顺序

1. `import` 那一行就报错 → 换第二节里的另一个入口名。
2. 导入成功但调用时抛异常 → 读异常类型：权限类（`SecurityException` 之类）去开权限；空指针/服务类异常，多半是该能力在当前机型上不可用，换台设备或换个能力先试。
3. 什么输出都没有 → 确认你点的是「运行」而不是只保存了；输出与报错都在终端窗口里，往上翻。
4. 脚本要联网或要装第三方库 → 先走 [第三方库安装与pip使用.md](第三方库安装与pip使用.md)。

## 六、和普通 Python 库的关系

QSL4A 调的是**这台手机的系统能力**，与 pip 装的第三方库互补：`requests` 负责和服务器说话，QSL4A 负责和手机说话，两者能在同一个脚本里一起用。所以先把 [第三方库安装与pip使用.md](第三方库安装与pip使用.md) 搞定，再回来把系统调用拼进去，是更省事的顺序。
