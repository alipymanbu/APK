## 一、这是什么

QPython 是安卓上的 Python 编程环境：你装上它，手机里就有解释器、控制台、编辑器和一套能调用安卓系统能力的库，写完代码当场就能跑。应用商店页显示的开发者与运营者是北京优趣天下信息技术有限公司，官网入口在 [www.qpython.com](https://www.qpython.com/)（站点标题写作 QPython+，配套课程与社区都挂在那上面）。

它的包名是 `org.qpython.qpy`——判断「装的是不是这个应用」就看这一项。这篇只讲**拿包与安装**；装好后怎么写第一个程序见 [第一个脚本怎么写并运行.md](第一个脚本怎么写并运行.md)。

## 三、从网盘获取安装包

1. 打开 [QPython 安装文件资源（夸克网盘）](https://pan.quark.cn/s/98105e5cb4df)，把分享内容**转存到自己的网盘**（不转存直接在线下载大文件容易中断）。
2. 在网盘里找到 `QPython_v4.0.1.apk`（所在文件夹为「QPython（先保存再下载）」），下载到手机本地。
3. 下载完核对大小是否接近 73.83M；有出入就重下一次。

## 四、官方渠道（想要最新版走这里）

- **官网**：[www.qpython.com](https://www.qpython.com/)，站点标题为 QPython+，上面有功能介绍、配套课程与社区入口。
- **开源分支**：`qpython-android` 在 GitHub 与 Gitee 都有组织页（[gitee.com/qpython-android](https://gitee.com/qpython-android)），其项目说明写明 QPython 分 Ox（面向初学者）与 3x（面向有经验的 Python 用户）两个分支，历史安装包可在对应 release 页找到。
- **国内应用商店**：应用宝等商店搜索「QPython」，注意核对包名是 `org.qpython.qpy`。

官方渠道拿到的通常是当时的最新版；网盘这份是 4.0.1，是收录时的那一版。两条路选一条即可，不必混着装。

## 五、安装步骤（安卓）

1. 点击已下载的 `.apk` 文件开始安装。
2. 系统若提示「禁止安装来自此来源的应用」，是浏览器或文件管理器没拿到安装权限：按弹窗进入「安装未知应用」设置，给当前这个来源打开允许，再返回重试（各品牌路径略有差异，一般在 设置 → 安全/隐私 → 安装未知应用）。
3. 安装过程中若弹出 Play Protect 之类的安全扫描提示，选择「仍然安装」即可。
4. 装完直接打开——**没有注册登录页**，进来就是主界面（终端、编辑器、文件等入口）。

## 六、系统与空间要求

- **系统版本**：官网课程页写明学习用的 QPython 版本不低于 3.3.0；具体到安卓系统版本，以官方页面当时说明为准。你手上这台手机若是很旧或很新的系统，装完先按 [常见报错与问题排查.md](常见报错与问题排查.md) 过一遍权限。
- **空间**：安装包 73.83M，再预留约等于包体的解压空间；之后装第三方库、写脚本还要另留几百兆（见 [第三方库安装与pip使用.md](第三方库安装与pip使用.md)）。
- **账号**：不需要登录就能用解释器、编辑器与文件功能。

## 七、装好后先确认三件事

1. 打开能直接进主界面，能看到终端、编辑器这类入口，且没有要求登录。
2. 在 设置 → 应用管理 → QPython 里，包名显示 `org.qpython.qpy`、版本显示 4.0.1，与第二节的表对得上。
3. 点开「终端」，输入 `print("hi")` 回车，屏幕输出 `hi` —— 说明解释器在跑。

三项都对，安装这一环就完成了。接着看 [第一个脚本怎么写并运行.md](第一个脚本怎么写并运行.md)；运行时遇到报错，翻 [常见报错与问题排查.md](常见报错与问题排查.md)。
