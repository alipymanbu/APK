## 一、你可能搜到的其实不止一个应用

同一个名字在不同渠道下是**不同的包**，装错一个，脚本与库就都对不上号。检索于 2026-09-26 的情况：

| 你看到的名字 | 包名 | 页面显示的开发者 | 页面显示的系统要求 | 说明 |
| --- | --- | --- | --- | --- |
| QPython（应用宝商店页） | `org.qpython.qpy` | 北京优趣天下信息技术有限公司 | 以页面当时显示为准 | **本文目录讲的就是它**，网盘那份 4.0.1 也是它 |
| QPython3（第三方商店 Aptoide 页面） | `org.qpython.qpy3` | QPythonLab | 页面标注 Android 8.1.0 起 | 与上面**不是同一个包**，可与它共存安装 |
| 各类历史安装包（GitHub / Gitee release 页） | 视分支而定 | qpython-android 开源组织 | 以对应 release 页为准 | 版本更旧，一般是想要特定老版本时才用 |

**判断依据永远是包名**：下载前看页面 URL 或包信息里的包名，别只看应用图标和标题——它们长得几乎一样。你网盘那份的包名核对方法见 [下载与安装教程.md](下载与安装教程.md) 第二节。

## 二、Ox 与 3x：官方自己就分了两条线

开源项目页（[gitee.com/qpython-android](https://gitee.com/qpython-android)）的项目说明写得很直白，QPython 按使用场景分两个分支：

| 分支 | 面向谁 | 你如果…就选它 |
| --- | --- | --- |
| QPython Ox | 编程学习者，界面与功能对新手更友好 | 第一次在手机上写 Python，只想快点跑起来看结果 |
| QPython 3x | 有经验的 Python 用户，提供更进阶的技术特性 | 已经熟 Python，要调更底层的能力、跑更复杂的项目 |

同一份说明还列了两条线的特性文档链接（`qpython_ox_featues` 与 `qpython_3x_featues` 页面），拿不准时先看这两页再决定，别在商店里盲装。

## 三、按这三步选，五分钟定下来

1. **先定包**：要的就是本文目录这一版（`org.qpython.qpy`、4.0.1），直接走 [下载与安装教程.md](下载与安装教程.md)；要另一个包，去对应商店页下载，核对包名再装。
2. **再定系统门槛**：第三方商店页标注的最低系统版本（如 `org.qpython.qpy3` 页面写的 Android 8.1.0+）只是**那一版**的门槛，会随版本变化——**以你下载时页面显示为准**。手机系统低于门槛时，往往「装得上但商店不让更新」，见 [常见报错与问题排查.md](常见报错与问题排查.md)。
3. **最后定要不要共存**：两个包可以同时装在一台手机上（包名不同，系统当成两个应用），但**脚本与已装的第三方库互不共享**——在 A 里装的 `requests`，B 里 import 不到。装两个只会加倍维护成本，除非你确实要对比两条线，否则装一个就够。

## 四、同类选择也一并说清楚

手机上跑 Python 并非只有这一家，公开的入门教程里常拿来对比的还有 Termux（类 Linux 终端环境，用 `pkg` 装 Python，适合要完整 Linux 工具链的人）与 Pydroid（IDE 形态的 Python 编辑器）。三者的差别大致是：

| 你要做的事 | 更合适的选择 |
| --- | --- |
| 边学边练、写短脚本、调用手机硬件 | QPython（现成界面 + 系统调用能力，见 [脚本调用安卓功能教程.md](脚本调用安卓功能教程.md)） |
| 要 git、要后台常驻服务、要完整命令行 | Termux 一类终端环境 |
| 只想要个带补全的编辑器 | Pydroid 一类 IDE |

这张表是**按用途给的方向**，不是排名；具体到某一版的可用性，仍以你安装时的实测为准。

## 五、已经装错了怎么办

- **装成了另一个包**（比如本想装 `org.qpython.qpy` 结果装了 `org.qpython.qpy3`）：先按包名确认，再决定留哪个。两个都在也没坏处，但建议只留一个，避免以后每次都要核对包名。
- **版本太旧装不上/跑不动**：旧 release 页的包对应老系统，新手机上可能有兼容问题，优先装当前商店里的版本。
- **卸载前先备份**：你写的 `.py` 脚本和已装的库都随应用走，卸载会一起没——把脚本目录里的文件拷出来再卸（脚本在哪见 [第一个脚本怎么写并运行.md](第一个脚本怎么写并运行.md) 第二节）。
