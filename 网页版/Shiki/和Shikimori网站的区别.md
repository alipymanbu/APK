## 一、一句话说清两者关系

Shikimori 是一个俄罗斯的动漫资料库与追番社区网站（域名有过 `shikimori.one`、`shikimori.io`、`shiki.one` 等多个，以官网当时显示为准）；**ShikiApp 不是它的官方应用，而是一个独立开发者（pewaru-333）写的第三方手机客户端**，把网站的数据用手机界面呈现出来，代码在 GitHub 上按 GPL-3.0 公开。

所以两者的分工是：**数据、账号、追番列表都在 Shikimori 网站那边，ShikiApp 只是你在手机上操作它们的入口**。

## 二、逐项对比

| 维度 | Shikimori 网站 | ShikiApp |
|---|---|---|
| 形态 | 浏览器访问的网页 | 安卓安装包（APK） |
| 出品方 | Shikimori 站方 | 个人开发者 pewaru-333（非官方） |
| 代码 | 闭源 | 开源，GPL-3.0 许可，GitHub 公开 |
| 界面语言 | 俄文为主（浏览器可机翻） | 只有俄文，无中文切换 |
| 账号 | 你注册的 Shikimori 账号 | 登录同一个账号 |
| 追番列表 | 网页端可编辑 | 手机端可编辑，与网页同步 |
| 网络要求 | 直接访问站点 | 依赖站点接口，站点挂了它也挂 |

## 三、账号是同一套，这是关键

你在网页上注册的 Shikimori 账号，直接在 ShikiApp 里登录即可（登录名是**昵称**，不是邮箱，且大小写敏感）。登录后你在哪边把某部动画标成「在看」，另一边也会跟着变 —— 列表、收藏、评分都存在网站账号下，不随安装包走。

这也是换手机、重装应用前**先登录**的理由：账号里的数据不会因为卸载而丢。

需要注意的两点：

- 不登录也能浏览大部分资料，但**把作品加入自己的列表、收藏角色、收发消息这些都要登录后才能用**。
- 站上部分内容标着 18+，网页端要登录并确认年龄才能看；应用里遇到同样的验证属正常现象。
- 账号怎么注册、密码忘了怎么找回，单独一篇讲透：[账号注册与密码找回.md](账号注册与密码找回.md)。另外站方用户协议写明**登录名与密码不得转交他人**，而第三方客户端的登录凭据要经过谁的手取决于你装的包 —— 只从 [GitHub 发布页](https://github.com/pewaru-333/ShikiApp/releases) 或本文头部的 [ShikiApp 安装文件资源（夸克网盘）](https://pan.quark.cn/s/aee5b60bfd51) 获取安装包。

## 四、什么时候用哪个

- **查资料、快速搜一部作品**：手机上用 ShikiApp 更顺手，打开就是搜索。
- **管理列表、看放送时间表、泡论坛**：两边都行，数据是同一份。
- **遇到应用打不开、界面看不懂**：直接用浏览器开官网最稳妥，网页还能借助浏览器自带翻译转成中文（见 [界面俄文看不懂怎么办.md](界面俄文看不懂怎么办.md)）。
- **想确认应用出了新版本**：看它的 [GitHub 发布页](https://github.com/pewaru-333/ShikiApp/releases)，网站本身不会通知你客户端更新。
