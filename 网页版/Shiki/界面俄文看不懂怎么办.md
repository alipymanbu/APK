# ShikiApp 界面俄文看不懂怎么办

## 一、先把现状说清楚

打开 ShikiApp 发现满屏俄文，**不是安装出错，也不是版本下错了**：

- 应用内置语言就是俄文，**没有提供中文切换选项**；
- 把手机系统语言调成中文，界面通常也不会跟着变（以你装的版本实际表现为准）。

它的数据源 Shikimori 是俄语站点，开发者优先做俄文界面是自然选择。你有两个思路：**认几个关键词直接用**，或者**去网页端配合浏览器翻译**。

## 二、最低限度的中俄对照表

先背下面这些，界面主干就能点通：

### 登录页

| 俄文 | 意思 |
|---|---|
| Логин (никнейм) | 登录名（昵称） |
| Пароль | 密码 |
| Авторизация | 登录/授权（登录页标题） |

### 追番列表的六个状态

| 俄文 | 意思 |
|---|---|
| Запланировано | 计划看 |
| Смотрю | 在看 |
| Просмотрено | 已看完 |
| Пересматриваю | 重看中 |
| Отложено | 搁置 |
| Брошено | 弃了 |

### 高频动作词

| 俄文 | 意思 |
|---|---|
| Поиск | 搜索 |
| Новости | 新闻 |
| Клубы | 俱乐部 |
| Сообщения | 消息/私信 |
| Профиль | 个人资料 |
| Настройки | 设置 |
| Избранное | 收藏 |

记法：**先认名词点进对应板块，再靠返回键和图标退出** —— 俄文界面多数操作靠位置和图标就能完成，真正要读的文字不多。具体每步在哪点，对照 [搜索追番与收藏教程.md](搜索追番与收藏教程.md) 的步骤说明一起用。

## 三、替代办法：用浏览器开网页端

遇到应用里实在读不懂的页面，最省事的解法是**换到网页端**：

1. 用手机或电脑浏览器打开 Shikimori 官网（域名以官网当时显示为准，`shikimori.one`、`shikimori.io`、`shiki.one` 都是它用过的）。
2. 用浏览器自带的「翻译此页」转成中文。
3. 登录你的同一个账号 —— 列表、收藏、评分和应用里是同一份数据（见 [和Shikimori网站的区别.md](和Shikimori网站的区别.md)）。

这样查资料、改列表都能用中文看，应用只留给「手机上快速搜一下」的场景。

## 四、翻译应用内文字的笨办法

只想搞懂应用里某一屏的文字时，还有两个不依赖官方选项的做法：

- **截屏后用系统相册/微信的图片翻译**：长按或选「翻译」，多数中文安卓机都自带这功能。
- **用另一部手机或电脑上的截图识字工具**翻。

效率不高，但对付设置页、报错弹窗这类偶尔才碰一次的文字足够了。

遇到登录不上的问题不是语言的锅，看 [常见问题与排查.md](常见问题与排查.md)；还没装应用先看 [下载与安装教程.md](下载与安装教程.md)。
