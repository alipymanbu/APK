## 一、打开一直转圈 / 内容加载不出来

应用本身不带数据，所有内容实时取自 Shikimori 网站，所以**先分清是「你没网」还是「它站那边不通」**：

1. 手机先开个网页确认网络正常。
2. 网页正常但应用卡住 → 用浏览器打开 Shikimori 官网试一下；**官网也打不开，就是站点侧的问题**（该站历史上换过 `shikimori.one`、`shikimori.io`、`shiki.one` 等域名，迁移期间或防护验证异常时会整段时间不好用），等一会儿再开应用即可。
3. 官网通、只有应用不行 → 切换 Wi-Fi 与移动数据各试一次（不同网络出口的连通性不一样），再不行到系统设置里清一次应用缓存后重开。
4. 打开官网时反复弹验证页（填完又弹、跳转后重来）→ 有用户反馈过这种情况，通常换个网络出口或过段时间再试就能过；这类验证是站点侧的防护，不是应用故障。
5. 都不行 → 卸载重装，或换一个版本（见下方「更新与换版本」）。

## 二、登录不成功

登录页两个字段：`Логин (никнейм)` 是**昵称**、`Пароль` 是密码。按顺序自查：

1. **是不是把邮箱当昵称填了** —— 登录用的是注册时起的昵称，不是邮箱地址。
2. **大小写** —— 昵称和密码都区分大小写，确认没开错大写锁定。
3. **输入法语言** —— 昵称里有俄文字符时，检查是不是敲在了英文布局上（反之亦然）；两边布局差一个字母就登不上。
4. **浏览器自动补全** —— 网页登录时浏览器可能擅自把首字母改大写，手动改回来再提交。
5. 还是不行就走**密码重置**：完整流程、收不到邮件的排查清单，以及「分辨是昵称错还是密码错」的官方判别法，都在 [账号注册与密码找回.md](账号注册与密码找回.md)。

## 三、提示需要登录 / 年龄验证

浏览标着 **18+** 的内容时，站点要求先登录并确认成年 —— 应用里遇到同样的提示属正常设计，登录你的账号即可，不是应用坏了。

同理，**把自己的列表加入作品、收藏角色、发消息**这些动作没登录时会被拦下，先按 [搜索追番与收藏教程.md](搜索追番与收藏教程.md) 登录再操作。

## 四、安装时报错

| 症状 | 处理 |
|---|---|
| 「解析包时出现问题」/ 打开即闪退 | 安装包没下完整或已损坏：重新下载，并按 [下载与安装教程.md](下载与安装教程.md) 里的命令核对 MD5 |
| 提示系统版本过低 | 手机安卓版本低于该包的最低要求（这份 alpha-0.3.1 要求安卓 5.2 以上）；新版本要求更高，装前对一眼官方页面 |
| 「禁止安装未知来源」 | 到设置里允许当前来源（文件管理器/浏览器/夸克），再点一次安装 |
| 装上了但图标是旧的、功能对不上 | 手机上残留了旧版本：先卸载再装新的，不要覆盖安装不同来源的包 |

## 五、更新与换版本

- 版本号一直是 `alpha-0.x.y` 形式，**更新节奏不固定**，最新版以 [GitHub 发布页](https://github.com/pewaru-333/ShikiApp/releases) 为准（安装包固定叫 `ShikiApp.apk`）。
- **升级、降级、换装之前先确认已登录**：列表、收藏、评分存在 Shikimori 账号下，不随安装包走，重装不会丢（原理见 [和Shikimori网站的区别.md](和Shikimori网站的区别.md)）。
- 新版偶尔有界面或功能变动，升级后个别入口位置变了属正常；用不惯可以回发布页装回旧版。
- 找不到设置项、菜单词认不出，是语言问题不是 bug，看 [界面俄文看不懂怎么办.md](界面俄文看不懂怎么办.md)。
