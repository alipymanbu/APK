## 一、一张表看明白

在 bt磁力猫 里搜出来的结果是磁力链接，网上也有人分享 .torrent 种子文件。两者指向资源的方式不同，但对下载工具来说是同一件事的两种入口：

| | 磁力链接（magnet） | 种子文件（.torrent） |
| --- | --- | --- |
| 形态 | 一段纯文本，`magnet:?xt=urn:btih:...` | 一个几十 KB 的文件 |
| 怎么拿到 | 复制粘贴即可 | 先下载文件，再导入 |
| 传播方式 | 发一串字符 | 发一个文件 |
| 会不会过期 | 链接本身永不过期 | 文件也一直在 |
| 下不动的原因 | 没人做种（见排查篇） | 同左，与格式无关 |

两者的「身份证」是同一串哈希——同一个文件的磁力链接和种子文件，最终解析出的是同一份资源。所以链接不会 404，但会**没速度**：格式永远有效，持有文件的人却可能已经走光了，这是 [磁力链接下载没速度怎么排查.md](磁力链接下载没速度怎么排查.md) 那篇要解决的问题。

## 二、磁力链接各段是什么意思

一条完整的磁力链接长这样：

```
magnet:?xt=urn:btih:e075b3148f5c0e6d1a0b2c3d4e5f6a7b8c9d0e1f&dn=示例文件.mp4&tr=udp://tracker.example:80
```

| 片段 | 含义 |
| --- | --- |
| `xt=urn:btih:` 后的 40 位字符 | 文件哈希，资源的唯一身份，缺了它链接无效 |
| `dn=` | 显示用的文件名，仅是标签，改了也不影响下载的是什么 |
| `tr=` | tracker 服务器地址（可有多个），帮你更快找到持有者；没有它也能靠 DHT 网络慢慢找到人 |

你不需要手动改任何一段：整段复制、整段粘贴进下载工具即可。截断（少了哈希）或贴重复了才是常见出错方式。

## 三、把磁力链接交给下载工具

1. 在 bt磁力猫 的结果里点「复制磁力链接」，确认复制的是 `magnet:` 开头的完整一整段；
2. 打开下载工具 → 新建任务 → 粘贴。多数工具会自动识别剪贴板里的 magnet 开头文本，弹出确认框；
3. 手机浏览器里直接点一个 magnet 链接时，系统会弹「用哪个应用打开」，选你的下载工具（这依赖应用注册了磁力协议，装好后一般默认可用）。

接下来就是等它跑起来——有无速度的判断与处理，见 [磁力链接下载没速度怎么排查.md](磁力链接下载没速度怎么排查.md)。

## 四、它和「普通文件的校验」不是一回事

磁力哈希校验的是 BT 网络里的资源；你从网盘拿到的安装包是普通文件，走的是另一套校验：比对 MD5。bt磁力猫 安装包的 MD5 与校验命令写在 [下载与安装教程.md](下载与安装教程.md) 的校验一节，怀疑包下错了就去那里核对。
