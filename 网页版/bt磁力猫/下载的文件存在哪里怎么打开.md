## 一、先从下载工具里看，别去文件系统里翻

每个下载工具都保存了任务的实际存储路径，这是最准的来源：

1. 打开下载工具的任务列表，点开已完成的任务 →「详情」；
2. 详情页里的「保存位置 / 文件路径」就是文件的真实落点；
3. 一般旁边还有「打开文件夹」「打开文件」按钮，直达目标。

以这里显示的路径为准——不同工具、不同版本的默认值不同，直接翻文件系统经常白翻。

## 二、翻文件系统时的两个默认落点

如果工具里找不到入口，用手机自带的「文件管理」按顺序找这两处（路径按内部存储根目录算）：

| 位置 | 什么时候在这 |
| --- | --- |
| `Download/`（下载） | 多数工具的默认目录，浏览器下载也在这 |
| 工具名同名文件夹（如 `/Android/data/<包名>/files/`） | 部分工具按自己建目录；这类目录在新版安卓里文件管理器可能显示受限，优先用第一节的方法 |

仍找不到就用文件管理器的**搜索**功能，输入任务里的文件名关键词（下载工具的任务名通常就是文件名）。

## 三、常见格式用什么打开

| 格式 | 打开方式 |
| --- | --- |
| `.mp4` / `.mkv` / `.avi` / `.rmvb` 等视频 | 系统相册/播放器大多能放 mp4；mkv、rmvb 等编码杂的装第三方播放器（如 VLC、MX Player）更省事 |
| `.flac` / `.mp3` / `.m4a` 音频 | 系统音乐 App 或任一播放器 |
| `.zip` / `.rar` / `.7z` 压缩包 | 文件管理器自带解压，或装解压工具 |
| `.apk` | 点击安装，来源放行步骤见 [下载与安装教程.md](下载与安装教程.md) |
| 不认识的扩展名 | 先别点，按 [下载的文件怎么查毒.md](下载的文件怎么查毒.md) 的扩展名判断过一遍 |

## 四、文件在、但播放器说打不开

三种常见原因，按顺序排除：

1. **下载没完成**：任务进度没到 100%，文件是半截的——回到下载工具确认状态（卡住不动的见 [磁力链接下载没速度怎么排查.md](磁力链接下载没速度怎么排查.md)）；
2. **编码不被当前播放器支持**：同一个 `.mkv`，系统播放器可能放不了、第三方播放器可以——先换播放器试；
3. **文件本身损坏**：大小明显小于任务标称值，重新下这一份。

排除完这三条仍不行，再考虑文件名后缀写错（如把视频命名为 `.txt`），用文件管理器改回正确后缀即可。
