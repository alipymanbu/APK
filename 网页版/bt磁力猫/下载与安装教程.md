## 一、先确认你要装的是哪一个

叫「磁力猫」的安卓应用至少有三种：一款小说阅读器、一款休闲益智游戏，还有一款磁力资源搜索工具（也就是本篇要装的 bt磁力猫）。它们图标风格接近，装错的典型症状是打开后完全不是自己想要的功能。

区分只看一个东西：**包名**（安装包的身份证号）。本篇所指版本的事实如下：

| 项目 | 值 |
| --- | --- |
| 应用名 | bt磁力猫 |
| 包名 | `com.racing.citymoto.drj3d41h65sd` |
| 版本 | 7.3.8 |
| 安装包大小 | 13.57 MB |
| MD5 | `a6957df34ea54d2bf3c924cd93861f45` |
| 开发者 | 苏州聚芒网络科技有限公司 |

版本号会随更新变化，上表是当前这份安装包的事实，装好后可在「设置 → 应用 → 应用信息」里核对包名是否一致。

## 二、从网盘拿到安装包

1. 打开 [bt磁力猫 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6bf3c917e619)，把里面的文件夹**转存**到自己的夸克网盘；
2. 手机装上夸克 App，登录同一账号，找到转存进来的 `bt磁力猫_v7.3.8.apk`；
3. 点文件 → 下载 → 下载完成后在提示里直接点「安装」，或用手机的「文件管理」找到它再点安装。

网盘里发出去的就是上表那一版（7.3.8 / 13.57 MB）。以后应用更新时，网盘里的文件夹名不变，文件会换成新版本号的包，转存链接照旧可用。

## 三、放行「安装未知应用」

安卓默认禁止从应用商店以外的来源安装 APK，首次安装会弹「不允许安装未知应用」之类的拦截。处理步骤（菜单叫法因手机厂商而异，MIUI / ColorOS / OriginOS 等都在「安全」或「隐私」相关页里）：

1. 打开 设置 → 安全（或 隐私）→ 更多安全设置 → 安装未知应用；
2. 找到你用来下载的那个应用（夸克、浏览器或文件管理），把开关打开；
3. 回到安装界面重新点「安装」；
4. 装完可以顺手把这个开关关回去，不影响已安装的应用。

## 四、校验安装包没有下错

文件在传输中损坏会导致「解析包时出错」。在电脑上可算一次 MD5 与第一节表格比对：

```powershell
Get-FileHash .\bt磁力猫_v7.3.8.apk -Algorithm MD5
```

输出的哈希与 `a6957df34ea54d2bf3c924cd93861f45` 一致，说明包完整；不一致就重新下载。手机上没有现成的校验工具时，直接重新下一次通常更快。

## 五、装不上、打不开的常见情况

| 现象 | 多半是这个原因 | 怎么处理 |
| --- | --- | --- |
| 解析包时出错 / 安装包已损坏 | 下载不完整 | 重新下载，或按第四节比对 MD5 |
| 点「安装」没反应、反复弹拦截 | 该来源没拿到安装权限 | 按第三节打开开关后重装 |
| 提示「已存在同名应用」 | 手机里装过同包名的旧版 | 先卸载旧版再装；卸载会清掉应用内的本地数据 |
| 装好了但桌面找不到图标 | 部分桌面不自动创建图标 | 在应用抽屉里长按图标拖到桌面 |
| 打开立刻闪退 | 包损坏，或系统版本过旧 | 先按第四节校验并重装；仍闪退则换一台设备试装，以定位是包还是系统的问题 |

安装这一步的问题九成出在「来源权限」和「包不完整」两件事上，先排查这两条，再考虑其他。装好之后若想让系统再把应用扫一遍，用自带的 Play Protect 即可，步骤见 [下载的文件怎么查毒.md](下载的文件怎么查毒.md)。
