## 一、贵族币是什么，和 VIP 不是一回事

按官方《贵族币充值协议》，贵族币是平台内的虚拟币，用来兑换**贵族爵位服务**及平台内的相关消费（协议更新于 2024 年 8 月，以协议页当时显示为准）。三条要点：

- 它**不是**代币票券、预付款凭证，不具备货币价值，**不能反向兑换成法定货币**；
- 它和会员订阅是两笔账：会员走自动续费（见[会员开通与自动续费取消.md](会员开通与自动续费取消.md)），贵族币是单次充值的余额，互不通用；
- 各充值渠道可能收取手续费，由渠道商定，充值页会显示——选渠道前先看一眼。

## 二、充值成功后能不能退：不能

这是协议里加粗写明的部分，充之前务必看清：

| 情形 | 协议口径 |
| --- | --- |
| 充值成功后反悔 | **不提供退还、不提供逆向兑换**；充值类商品不适用「七日无理由退货」 |
| 自己输错账号 / 金额 / 选错种类 | 损失由你自己承担，平台不退款、不补偿 |
| 贵族币无法使用（平台侧异常） | 可联系官方客服查询处理 |
| 平台系统算错数量 | 少发的会补足；**多发的有权直接从账户扣回** |
| 未成年人充值 | 平台禁止未成年人使用充值服务 |

结论：充值是「点下去就生效」的动作，输完金额再核对一遍账号与数字，别指望事后反悔。

## 三、充错了、没到账，正确的处理顺序

协议只给了「联系官方客服」这一条通道，所以证据自己先留好：

1. **截图三样**：支付成功页、账户余额页、订单号/交易单号；
2. **先查支付渠道**：微信/支付宝/银行卡的交易记录能确认钱到底扣没扣、扣给谁了——渠道侧流水是后续一切沟通的底牌；
3. **找官方客服**：App 内「帮助与反馈」优先，邮箱 `cs@lespark.us`（同[常见问题与故障排查.md](常见问题与故障排查.md) 的联系方式），说明时间、金额、订单号、账号手机号；
4. **别走「私下退款」**：任何自称客服、让你点链接填卡号或先转账「激活退款」的私信都是二次诈骗（见[交友防骗与举报指南.md](交友防骗与举报指南.md)）。

## 四、只用官方渠道充值

协议明确：使用非官方指定方式充值，平台不保证到账，还可能伴随诈骗风险，情节严重会被冻结余额甚至封禁账号。各类「代充打折」「低价贵族币」的第三方渠道正是这一条针对的对象——省下的折扣，换不来任何售后。装机与官方入口见[下载与安装教程.md](下载与安装教程.md)。
