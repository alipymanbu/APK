## 一、先核对你要装的这份包

网盘里那份安卓包的事实如下，装之前对照一眼，避免装错文件或装到旧包：

| 项目 | 值 |
| --- | --- |
| 版本号 | 9.7.20 |
| 包名 | `com.redwolfama.peonylespark` |
| 安装包大小 | 274.49M |
| MD5 | `4bde57eaf4babd7d69e63d75f8c29535` |
| 文件记录时间 | 2026-09-21 |

三点说明：

- **版本会一直变**。这份是 9.7.20，官方与各应用商店的最新版一直在迭代（2026 年 9 月的渠道页已显示到 9.7.50），你看到的版本号与上表不一致是正常的，以上表为准的是**网盘里这份文件**。
- **包名一致就对**。安卓系统按包名识别应用，`com.redwolfama.peonylespark` 与各渠道页标注的签名一致；同名不同包的仿冒品装上去会变成另一个应用。
- **MD5 可以自己验**。下载完成后在 Windows 上跑一条命令即可核对文件是否完整：

```powershell
certutil -hashfile "LesPark_v9.7.20.apk" MD5
```

输出的 32 位十六进制与上表一致，说明文件没下残。

## 二、从哪里拿安装包

按省事程度排，你有三个入口：

1. **夸克网盘（本篇头部那条链接）**：打开 [LesPark 安装文件资源（夸克网盘）](https://pan.quark.cn/s/12bccaeb4073)，把 `LesPark_v9.7.20.apk` 转存到自己的网盘后下载到手机。这是上表那份可核对的包。
2. **官方网站**：[www.lestory.cn](https://www.lestory.cn) 首页有扫码下载入口，适合想要「官方最新版」的场景——拿到的版本比网盘里新，但没有可对照的 MD5。
3. **App Store**：iPhone 用户在苹果应用商店搜 LesPark 安装，页面显示 18+ 分级、支持内购。

Android 用户走第 1 或第 2 条；第 3 条只对 iOS 有效。

## 三、系统要求

- **安卓**：第三方渠道页标注的最低要求是 Android 8.0 及以上，以官方下载页当时显示为准。安装包 274M 左右，解压与首次启动还要占更多空间，建议预留 1G 以上可用存储。
- **iOS**：App Store 页面显示支持 iPhone / iPad，年龄分级 18+，安装包约 400M 量级（以商店当时显示为准）。
- **联网**：注册、直播、聊天全是在线功能，装完没网什么都打不开。

## 四、安卓安装步骤

1. 把 APK 传到手机（网盘 App 内直接下载、数据线拷贝、或浏览器下载均可）。
2. 点击 APK 文件，系统若弹出「禁止安装来自此来源的应用」，这是「未知来源」开关没开——按提示进入**设置 → 安全/隐私 → 允许安装未知应用**，给当前安装来源（浏览器或网盘 App）授权后返回重装。
3. 安装完成后首次启动，会依次要求同意用户协议与隐私政策，点同意才能进入。
4. 接着是手机号 + 短信验证码登录，详见[注册登录与隐私设置.md](注册登录与隐私设置.md)。
5. 运行中弹出的权限申请（存储、位置、摄像头、麦克风、通知等）可以先拒绝非必需项，用到对应功能时再开——每一项权限管什么，见[注册登录与隐私设置.md](注册登录与隐私设置.md)。

## 五、装不上或装完打不开

按出现的现象对号入座，排查步骤在[常见问题与故障排查.md](常见问题与故障排查.md)，最常见的三类：

- **解析包时出错 / 安装包损坏**：多为下载不完整，重新下载后先验 MD5 再装；
- **安装包与系统不兼容**：确认系统版本达到上一节的最低要求；
- **装完一闪就退**：先按排查篇清缓存、看内存，再决定是否重装。
