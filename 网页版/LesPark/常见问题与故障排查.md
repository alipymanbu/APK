## 一、安装阶段

**提示「解析包时出错」/「安装包损坏」**
九成是文件没下完整。重新下载，下完先验 MD5（命令见[下载与安装教程.md](下载与安装教程.md) 第一节）再装。

**提示「应用未安装」/ 与系统不兼容**
先看系统版本是否达到最低要求（渠道页标注 Android 8.0 及以上，以官方页当时显示为准）。另外检查存储空间——安装失败很多时候只是**磁盘满了**，清出 1G 再试。

**装完一闪就退 / 打不开**
按顺序试：① 强制停止后重开；② 清缓存（设置 → 应用 → LesPark → 存储 → 清除缓存）；③ 看手机内存是否被占满，杀掉后台再开；④ 卸载重装（会丢本地数据，聊天记录在账号云端的不受影响）。三步都无效，多半是该版本与你系统不兼容，换官方最新版试。

## 二、登录阶段

**收不到短信验证码**
- 手机信号差时先等一等，验证码有到达延迟；
- 检查短信是否被拦截软件收走（翻拦截箱）；
- 换 WiFi / 蜂窝数据网络重发——网络链路问题会让请求根本没发出去；
- 连续多次收不到再试手机重启，DNS 缓存异常也会卡在这一环。

**提示登录失败 / 错误码**
先切网络（WiFi 换流量）重试；再确认给 LesPark 的联网权限没被系统关掉（设置 → 应用 → LesPark → 联网控制）。同一手机号多设备挤号会互相踢下线，确认没有别处登着。

**忘记账号 / 换号了**
账号跟手机号走：旧号还能收验证码就用它登录后换绑；旧号已停机，用 App 内的申诉/客服通道处理，别反复试错把号锁了。

## 三、使用阶段

**消息通知收不到**
查两层：① 手机系统层——设置里 LesPark 的「通知」权限是否允许、是否被「省电策略」限制后台；② App 层——消息免打扰是不是开着（含群聊单独免打扰）。两层都开才会响。

**同城 / 附近的人不准**
位置权限没给就是全局推荐；给了还不准，看系统定位服务是否开着、是否只给了「仅使用期间」。App 内还有「临时穿越 / 永久穿越」的定位设置项（以实际版本显示为准），若之前改过虚拟位置，同城内容就会按穿越后的地点算，改回真实位置即恢复。

**直播间卡、语音断**
语音直播对上行网络敏感：先切网络试；多人连麦卡优先怪网络而不是应用——换 5G 或信号更好的 WiFi 再判断。

**版本太旧、功能找不到**
火花、闪聊、投票问答这类新功能要新版本才有。先确认你装的不是旧包：设置里看版本号，去官网 [www.lestory.cn](https://www.lestory.cn) 或网盘（见[下载与安装教程.md](下载与安装教程.md)）拿新包覆盖安装。

**误扣费 / 自动续费忘关**
按[会员开通与自动续费取消.md](会员开通与自动续费取消.md) 的表格先去对应渠道解约，再联系客服说明扣费时间与金额。
