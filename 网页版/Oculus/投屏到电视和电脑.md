投屏是把头显里看到的画面放给旁边的人看。它有三个去向 —— 手机、电脑浏览器、Chromecast 类设备 —— 每个去向的账号要求不一样，这也是「明明同一个网络却投不上去」的主要原因。

## 一、投屏前必须先成立的前提

| 前提 | 说明 |
| --- | --- |
| 同一 Wi-Fi | 头显与接收设备要连同一个网络；双频路由要让两者落在同一频段 |
| 账号一致 | 头显和接收设备要登录同一个 Meta 账号 |
| 账号身份 | 投到**手机**的只有头显上的**主账号**能行，且该账号要登录在你想投过去的那台手机上 |

关于账号身份这条，官方的口径是：

- **主账号**：可以投到手机、Chromecast 设备、电脑浏览器；
- **次级账号**：只能投到 Chromecast 设备与电脑浏览器，**不能投到手机**。要用次级账号投，就在 VR 里发起会话并选 Chromecast 或电脑，电脑那侧浏览器要用次级账号登录。

所以「投到手机一直失败」时，先想一下：手机应用里登的是不是头显的主账号。

## 二、从 VR 里发起

1. 戴上头显，按手柄上的 Meta 键打开通用菜单。
2. 选 **相机**，再选 **投放**。
3. 在目标里选 **电脑** 或 **手机应用**。

## 三、从手机应用里发起

1. 打开手机应用，点 **投放**。
2. 先选要投出的头显，再选要投到的设备。
3. 列表里一开始看不到目标设备，点 **其他设备** 让它重新扫一遍网络。
4. 点 **开始** 就开投了；要停的时候在应用里点 **停止投放**，或者在头显里选 相机 → 投放 → 停止投放。

有一条要记住：**在手机上关掉这个应用、或者切到别的应用，投屏会直接停**。想让投屏一直开着，手机就停在应用这一页别动。

## 四、Chromecast 到底行不行

这一点官方自己的两版说明不完全一致，两边都列出来，你自己按当时的页面判断：

- **较早的官方说明**：要求电视或设备支持 Chromecast，不支持时退而投到手机应用。
- **较新的官方说明**：Chromecast 与 Meta Quest 的配合**支持并不完整、可能无法正常工作**，建议优先投到手机或电脑。

两版都同意的一点是：内置 Chromecast 的电视可能能用，但**不保证所有型号都兼容**。电视扫不出来时，一个折中办法是先把画面投到手机，再从手机镜像到电视 —— 代价是多一层转接，延迟和画质都会打折。

## 五、投不上去按这个顺序查

1. **同一个 Wi-Fi**，双频要同频段，别一个连主路由一个连访客网络。
2. **账号**：投手机看是不是主账号；投电脑看浏览器里登录的账号对不对。
3. **重启**：头显、手机、接收设备依次重启一遍。
4. **检查更新**：头显、手机、接收设备的软件都看一遍有没有新版本。
5. **重启路由器**。
6. **换一张网络**。有些网络会从安全层面拦住设备互相发现，官方点名的场景包括：家用访客网络、公司或商用网络、酒店与机场网络、部分手机热点共享。在这类网络里折腾设置通常没有用，换一张网络往往才是解法。

## 六、几个已知的限制

- **投屏与录制同时进行**可能出问题，需要同时录和投时，先试一次看是否稳。
- **投屏费电**，也会占用头显性能，长时间投屏建议接着电源。
- **地区**：Quest 并非在所有国家和地区都开放，在未开放地区，投屏这类需要联网的能力会表现为失败。具体支持范围以官方支持地区列表当时显示的为准。
- 投出去的画面对旁观者是「全部可见」的：菜单、通知、应用名都会一起显示，人多的时候留意一下。

投屏通了之后，如果遇到的是应用本身卡顿、闪退这类问题，去 [常见问题与排查.md](常见问题与排查.md)；如果连配对都还没做完，先回到 [配对头显与重新登录.md](配对头显与重新登录.md)。
