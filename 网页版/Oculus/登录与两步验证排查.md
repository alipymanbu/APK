# 登录与两步验证排查

> 讲清登录时最容易点错的那个按钮、两步验证要在哪开、账号被暂时锁住多久能恢复，以及怎么核对账号有没有用错。

这个应用本身不存账号，它只是把你的 Meta 账号登进去。所以登录类问题基本都能归到两类：登录入口选错了，以及账号这一层被卡住了（密码、两步验证、账号锁定）。按下面两类一类一类排，多数情况不用找客服。

## 一、先排「入口选错」这一条

社区里反复出现的场景是这样的：账号密码在网页上和手机上都正常，偏偏在应用里报「邮箱或密码不正确」，改了三遍密码、卸了又装还是错。最后发现是**点错了登录按钮** —— 用了那个「用旧账号登录」式的按钮，而不是页面上主推的那个登录入口。

遇到这种情况先这样做，再考虑密码问题：

1. 回到登录页，认准主登录入口再点，别点成分支按钮。
2. 还不行就把**默认浏览器**换一个再试。社区里有用户反馈，换过默认浏览器之后登录就通过了。
3. 前面两条都试过仍不行，才走「忘记密码」流程重设。

## 二、两步验证在哪开关

一个关键事实：**两步验证不能在头显上开启或关闭**。要改这项设置，只能去账户中心，三条路都行：

- 电脑浏览器；
- 手机浏览器；
- 这个手机应用内的账户中心入口。

路径是：登录账户中心 → **密码和安全** → **双重验证** → 选你的 Meta 账号 → 按屏幕提示走完，最后输入收到的验证码。

## 三、验证码出问题时的处理

| 现象 | 原因与处理 |
| --- | --- |
| 一直收不到短信验证码 | 逐条排：运营商是否受支持 → 手机网络是否正常 → 运营商有没有发故障通知 → 关掉飞行模式 → 重启手机 → 检查短信是否被拦截号码挡住 → 更新手机系统。都试过仍不行，联系运营商 |
| 提示尝试次数过多 | 短时间内请求验证码太多，账号会被暂时锁定，**需要等 24 小时**再试 |
| 换了手机号，收不到码 | 属于彻底失去访问权限，只能联系官方支持；流程里可能需要你用带照片的证件证明身份 |
| 验证器应用丢了（换机、重置手机） | 同上，走官方支持流程找回，别在第三方页面填账号 |

等待 24 小时这一条很容易被忽略：明明只是多按了几次「重新发送」，结果整晚登不进去，第二天自己就好了。看到「尝试次数过多」就停下来等，别继续点。

## 四、不确定账号对不对，用设备列表核

登录不上去时，最容易犯的错是「账号其实用错了」。判据是这个页面：[账户中心 · 我的设备](https://auth.meta.com/settings/my/devices/)。

- 页面里**列出**了你的头显 → 账号是对的，问题在密码或验证码，按上面几节处理；
- 页面里**没有**你的头显 → 换另一个 Meta 账号登录再试。

这个页面同时也是「远程退出账号」的入口，头显丢了或转让时可以在这里处理。

## 五、登录之后的小设置

- **通知权限**：系统弹窗问通知权限时给上。拒绝也能用，但下载完成、好友消息这类提醒不会进通知栏，需要自己进应用里看。
- **后台别被清掉**：国产系统默认会清后台，把这个应用加进电池优化白名单（设置 → 电池 → 该应用 → 不优化），否则配对、投屏过程中容易被系统掐断。

账号这一层通了之后如果头显还是登不进去，那是配对与设备侧的问题，转到 [配对头显与重新登录.md](配对头显与重新登录.md)；应用能登进去但一开就崩，看 [常见问题与排查.md](常见问题与排查.md)。
