Oculus 是 Meta 出的手机端伴侣应用，用来给 Quest 系列头显做初始设置、配对、投屏，以及在手机上逛商店、把游戏远程装进头显。这个应用现在已经改名叫 Meta Horizon，包名仍是 `com.oculus.twilight`。本篇只管把网盘里这份安卓包装进手机，并让第一次启动顺利走通。

搜索引擎给的通常是官方最新版，网盘里这份是整理文档时核对过的那一版，两者不一定同名同版本。下面这些字段都以这份包为准：

| 版本号 | 378.0.0.29.229 |
| 包名 | `com.oculus.twilight` |
| 安装包体积 | 79.00 MB |
| MD5 | `08CEA75FD6D6EB5EAF54FEAFC6DBA566` |
| 版本核对时间 | 2026-09-22 |
| 适用平台 | Android 手机 |

包名那一列最值得留意：网上叫 Oculus 的应用不止一个，用 `com.oculus.twilight` 核一下，就能确认手上这份是不是要给头显做设置的那个。安装包本体的获取与转存步骤在第三节。

版本号方面：这个应用的版本号是由多段数字拼起来的（如 `378.0.0.29.229`），官方更新很频繁，后续版本以官方商店当时显示的为准，这里不预判。

## 二、装之前先看门槛

### 手机侧

官方不同页面给出的最低系统要求并不完全一致，装机前对一下手机系统版本：

| 来源 | 安卓最低版本 |
| --- | --- |
| 官方手机应用安装说明页 | Android 5.0 或以上 |
| 官方产品支持页 | Android 5.0 或以上（同页另标 iOS 15.1 或以上） |
| 部分更早的官方页面 | iOS 10 或以上 |

以商店页面当时标注的为准。系统版本低于要求时的常见表现是应用能装上但打开异常、或者设置头显的过程中断。

有一件事官方专门写了提示：这个应用**在平板或其他设备上可能无法正常工作**。给头显做初始设置时，优先用手机，别用平板省事。

### 头显侧

用手机完成初始设置的主要是 Quest 系列：

| 头显 | 手机应用能帮上什么 |
| --- | --- |
| Meta Quest 3 / 3S | 完成初始激活设置、配对、投屏、远程装应用 |
| Meta Quest 2 | 同上 |
| Meta Quest Pro | 同上 |
| Oculus Rift / Rift S | 设置走电脑上的 Meta Horizon Link，手机应用只能用来浏览商店内容 |
| Oculus Go | 官方设置页仍列了它，可走手机应用连接 |

## 三、安装步骤

1. **转存并下载。** 从 [Oculus 安装文件资源（夸克网盘）](https://pan.quark.cn/s/547a759b1297) 把 APK 转存到自己的网盘，再下载到手机；在电脑上下载的话，用数据线或传输工具拷进手机存储也一样。
2. **允许安装未知来源应用。** 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统常把这项收在「安全」或「隐私」分类下。
3. **点开 APK 安装。** 系统提示「应用未经过安全检测」时选择继续安装。这是第三方来源安装包的常规提示，与包本身是否可靠无关 —— 可靠性靠上一节的包名与 MD5 核对。
4. **覆盖安装的心理准备。** 手机里已经有同包名的版本时，这次安装会直接覆盖它，登录状态通常保留；想干净重来的话先卸载再装。
5. **遇到「应用未安装」。** 多半是手机里那个同包名版本比这份新 —— 安卓不允许用低版本覆盖高版本，先卸载旧版再装。若提示的是存储不足，腾出空间后重试。

## 四、第一次打开要过哪几关

启动顺序本身不复杂，但卡在哪一步的应对方式完全不同，按这个顺序看：

1. **通知权限。** 系统弹窗问通知权限时给上。拒绝也能用，只是下载完成、好友消息这类提醒进不了通知栏。
2. **登录 Meta 账号。** 用头显上那个 Meta 账号登录，内容才对得上。没有账号先在官方渠道创建。这一步点错登录入口的表现和处理写在 [登录与两步验证排查.md](登录与两步验证排查.md)。
3. **蓝牙、附近设备与 Wi-Fi。** 官方明确要求：手机要连上 Wi-Fi 并开启蓝牙，才谈得上用这个应用设置头显。安卓上还要把「与附近设备共享」这类权限给到应用 —— 少了它，表现同样是一直搜不到头显。
4. **配对头显。** 首次连接要输入头显上显示的那串配对码，完整流程与失败排查在 [配对头显与重新登录.md](配对头显与重新登录.md)。

## 五、装完做一次最小验证

不用碰头显，先把能验的验掉：

| 看到的现象 | 说明什么 |
| --- | --- |
| 登录后能看到个人主页、头像与好友入口 | 账号与网络通了 |
| 商店能正常翻出游戏列表 | 账号区域与网络没被挡住 |
| 应用里有「投放」入口 | 当前版本没有被判定为过旧 |

要让配对、投屏、远程安装这些功能真正可用，还得把手机关联到头显上，这一步在 [配对头显与重新登录.md](配对头显与重新登录.md) 里讲；如果装包或首次启动本身出问题，先看 [常见问题与排查.md](常见问题与排查.md)。
