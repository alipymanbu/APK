# 配对头显与重新登录

> 讲清手机与头显怎么配对上、配对卡住时按什么顺序查，以及头显掉登录之后用手机把它救回来。

配对要解决的是两件事：让手机认得这台头显，以及让头显在掉登录之后重新回到你的账号上。这两件事的前提条件几乎一样，失败原因也高度重合，所以放在一篇里讲。

## 一、几个前提先摆平

配对类操作失败，多数不是步骤点错，而是下面某一条不成立：

| 前提 | 具体要求 |
| --- | --- |
| 同一 Wi-Fi | 手机与头显要连同一个网络；路由器是双频时，两者还要落在**同一个频段**上 |
| 蓝牙都开 | 不只是手机的蓝牙，头显侧的蓝牙也要打开 —— 这是最常被漏掉的一条 |
| 附近设备权限 | 安卓上还要求应用拿到「与附近设备共享」这类权限，没给就扫不到头显 |
| 账号一致 | 手机应用里登录的，必须是头显上正在用的那个 Meta 账号 |
| 应用够新 | 商店里的版本明显落后时，配对流程会中途失败；更新用的安装包见 [Oculus 安装文件资源（夸克网盘）](https://pan.quark.cn/s/547a759b1297) |

官方对蓝牙这条的表述是：手机必须连接 Wi-Fi 并开启蓝牙，才能用这个应用设置 Quest 头显。只连 Wi-Fi 不开蓝牙时，最常见的表现就是一直「搜不到头显」。还有一条配套提示：应用里看不到「添加设备」入口时，先更新应用，然后**完全关掉再重新打开**，入口才会出现。

## 二、首次配对怎么走

1. 打开手机应用，用头显上那个 Meta 账号登录。
2. 按应用里的引导开始设置头显，它会先扫附近的设备。
3. 头显里会显示一串**配对码**（8 位数字）。
4. 把这串码输进手机应用，两边建立连接。

头显软件更新完成后，正常情况下会自动和手机应用配上；没自动配上的，就走上面第 3、4 步手动输码。

## 三、配不上时按这个顺序查

| 顺序 | 要查的事 | 具体动作 |
| --- | --- | --- |
| 1 | 网络是否同一张、同一频段 | 手机别连访客网络或热点；双频路由把两台设备放到同一个频段 |
| 2 | 头显侧蓝牙 | 进头显设置确认蓝牙是开着的，这是社区里反馈最多的一个原因 |
| 3 | 应用版本 | 去官方商店看有没有更新；明显落后就更新。重装一次也值得试 |
| 4 | 谁在用这台头显 | 头显被多人用过时，把手机应用退出登录再重新登一次 |
| 5 | 手机蓝牙缓存 | 安卓：设置 → 应用 → 蓝牙 → 存储 → 清除缓存；iOS：设置 → 蓝牙 → 忽略已配对设备。注意清了缓存后，其它蓝牙设备要重新配 |
| 6 | 换一张网络 | 有些路由或网络会拦住设备互发现，换个网络再试；官方另有一个查 Wi-Fi 问题的诊断应用可用 |

如果应用提示**「此头显已与某个 Meta Horizon 个人主页配对」**，说明这台头显上已经有别人的个人主页了。两种处理：在头显里把你自己加为额外个人主页，或者把头显恢复出厂设置（第一个重新登录的人会成为设备所有者，之后再加其他人）。

## 四、头显掉登录了怎么找回

头显退出登录后重新登不上去，按顺序试：

1. **先确保头显连上 Wi-Fi。** 头显没网会直接提示你连 Wi-Fi，这一步不成立，后面都白做。
2. **用手机应用把它拉回来。** 在手机应用里用头显上那个账号登录，应用会自动帮你把头显重新登进去。
3. **确认蓝牙与权限。** 手机蓝牙开着，且应用拿到了蓝牙权限；应用里能看到头显已通过蓝牙连接，成功率更高。
4. **核对是不是登错了账号。** 打开官方账户中心的设备页 [auth.meta.com/settings/my/devices](https://auth.meta.com/settings/my/devices/)：设备列表里能看到你的头显，说明账号用对了；看不到，就是账号弄混了。
5. **更新头显软件。** 头显软件过旧也会拦登录，用官方的软件更新工具更新一次。
6. **恢复出厂设置。** 上面都试过仍不行，才走这一步；重置前的准备与具体路径见 [恢复出厂设置与转让头显.md](恢复出厂设置与转让头显.md)。

注意一条：如果头显上用的是别人的个人主页，第 2 步的「手机应用自动重新登录」是不起作用的 —— 这种情况下得回到账号本身去解决。

## 五、提示「你不拥有这台头显」

有一类提示语很唬人：明明是你自己设置的头显，应用却说你不拥有它，于是设备设置一项都改不了。这**多数不是所有权问题，而是账号或连接没对上**。官方给的处理顺序是：

1. **先确认账号没登错。** 到 [账户中心 · 我的设备](https://auth.meta.com/settings/my/devices/) 看你登录的账号下列没列出这台头显；没列出就换另一个 Meta 账号重试。
2. **重启两端。** 头显和手机各重启一次；头显可以用按住电源键 30 秒的强制重启。
3. **补齐连接条件。** 手机蓝牙开启、应用拿到蓝牙权限、两台设备在同一个 Wi-Fi 上，再把应用更新到最新版。
4. **手动重新配一次。** 在应用的 **设备** 里点「添加新设备」，选对头显型号，按提示走。配对码在头显里的 **设置 → 通用 → 关于** 能看到，输进应用即可完成配对。
5. **仍不行才重置。** 到这一步才考虑恢复出厂设置，路径见 [恢复出厂设置与转让头显.md](恢复出厂设置与转让头显.md)。

顺带说明：这台头显**确实**是二手买来的、里面还挂着前主人账号时，第 1 步就会露出马脚 —— 你的账号下列不出这台设备。这种情况的解法是重置，而不是反复试配对，流程见 [恢复出厂设置与转让头显.md](恢复出厂设置与转让头显.md) 第五节。

配对成功之后，接下来最常用的是把画面投出去，见 [投屏到电视和电脑.md](投屏到电视和电脑.md)；如果卡在登录环节而不是配对环节，先看 [登录与两步验证排查.md](登录与两步验证排查.md)。
