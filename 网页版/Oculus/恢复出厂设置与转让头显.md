# 恢复出厂设置与转让头显

> 讲清什么情况下该把 Quest 恢复出厂设置、用手机应用怎么操作、设备不在手上怎么远程擦除，以及二手头显转手前后各自要处理什么。

恢复出厂设置是把头显清回刚拆箱的状态。它出现在两种场合：头显怎么调都调不好时当最后手段，以及头显要转给别人时必须清干净。手机应用里就能直接发起这个操作，不用非蹲在头显上按组合键。

## 一、动手之前先办三件事

| 准备 | 原因 |
| --- | --- |
| 打开云备份 | 打开后应用数据（游戏进度、应用设置）会先备份到云端，重置后还能接着用 |
| 电量充到 50% 以上 | 官方明确要求；中途断电有风险 |
| 确认账号能登进去 | 重置后要用 Meta 账号重新登录，密码、验证码这一层先确认可用，排查见 [登录与两步验证排查.md](登录与两步验证排查.md) |

另外两条先记住，省得重置完才发现：

- **不可撤销**：头显里的账号信息、已下载的游戏和内容都会被清掉，没有后悔药。
- **买过的不丢**：重置只删头显本地内容，账号下已购买或已下载的内容仍在账号里，重新登录后可以再装。

## 二、用手机应用恢复出厂设置

1. 打开手机应用，点底部你的头像。
2. 进 **设备**，选中要处理的那台头显。
3. 进 **头显设置 → 高级设置**。
4. 选 **恢复出厂设置**，再点 **重置** 确认。

重置过程中头显会自动重启，重启后走一遍首次设置流程 —— 连网、配对、登录，步骤见 [配对头显与重新登录.md](配对头显与重新登录.md)。

## 三、从头显本体恢复（应用连不上时）

应用连不上头显、或者头显卡在某个界面进不去系统时，改用硬件按键组合：

1. 先把头显关机。
2. 同时按住 **电源键** 和 **音量减（-）键**，直到出现启动菜单。
3. 用音量键把光标移到 **恢复出厂设置**，按电源键确认。
4. 用音量键选 **是**，再按一次电源键。

如果只是卡住、还没到要清空的程度，先用轻一点的办法替代：**按住电源键 30 秒**做一次强制重启。能重启解决的就别重置。

## 四、设备不在手上：远程擦除

头显丢了或被盗时，用电脑或手机访问 [账户中心 · 我的设备](https://auth.meta.com/settings/my/devices/)：

1. 在设备列表里选中你的头显。
2. 点 **删除设备数据**（或恢复出厂设置）。
3. 走一遍身份验证流程。
4. 完成后这台头显会从列表里消失；它**下一次联网时**才真正执行重置。

列表里看不到这个选项，说明该头显的软件版本还不支持远程擦除，只能等设备回到手上再处理。

## 五、二手头显：转手前后各做什么

这是实际交易里最容易卡住的一环。

**卖家侧**，交出去之前：

1. 在头显上退出账号，或直接按第二节的方式恢复出厂设置；
2. 到 [账户中心 · 我的设备](https://auth.meta.com/settings/my/devices/) 确认这台设备已从你的账号里移除；
3. 还想留进度的话，重置前把云备份开着，数据留在自己账号里。

**买家侧**，拿到之后：

1. 头显里还挂着前主人账号时，**恢复出厂设置**就能清掉，这也是官方给的解法；
2. 重置后**第一个登录的账号会成为设备所有者**，所以先想清楚用哪个账号登，再动手；
3. 之后按 [配对头显与重新登录.md](配对头显与重新登录.md) 配对；要不要给家人开共享，看 [远程安装与家庭共享.md](远程安装与家庭共享.md)。

一条必须提前知道的风险：**报失或被盗的头显会被官方停用**。卖家不肯当面让你验机、价格明显偏低的，别买 —— 这类设备到手后可能连账号都登不上，且没有自助恢复的办法。

## 六、重置完还是不行怎么办

恢复出厂设置治的是「本机状态坏了」这一类问题。重置完仍然不对，多半已经不是本机的事，分两种走：

- 登不进账号、验证码收不到 → [登录与两步验证排查.md](登录与两步验证排查.md)；
- 能登录但应用本身打不开、闪退 → [常见问题与排查.md](常见问题与排查.md)。
