## 一、图源打不开或章节加载失败

按顺序排查：

1. **确认应用版本**：图源修复是跟着应用更新发的，站点改版后旧版本会集体失灵。先升级到最新版（渠道差异见第五节），大量「图源挂了」的反馈其实止步于这一步；
2. **看是不是个别源**：只挂一个图源 → 到同一部作品的详情页换源，操作见[图源管理与切换方法.md](图源管理与切换方法.md)；多个图源同时挂 → 多半回到版本问题或网络问题；
3. **人机验证页**：个别站点开启 Cloudflare 一类验证，应用内会弹出验证页，按提示完成一次即可；反复卡验证就换源，等下个版本的图源修复；
4. **网络环境**：部分图源站点在部分网络环境下加载缓慢或超时，换时段或换网络再试，能区分是站点问题还是链路问题。

应用本身不托管漫画内容，内容都来自各图源站点，站点侧的临时故障只能等站点或应用侧恢复。作品能正常打开、只是更新提醒不响，属于另一类问题，排查步骤见[新章节通知收不到的排查.md](新章节通知收不到的排查.md)。

## 二、全局搜索很慢、结果太杂

全局搜索会逐个询问启用的图源，图源越多越慢。到「设置 → 图源 → 图源管理」把不看的语言与内容类型全部停用，只留常用的几个，速度与结果质量都会明显改善；常用图源顺手置顶，浏览页也干净。

## 三、界面是英文，想改成中文

右上角三点 → 设置 → 外观（Appearance）→ 语言，选「中文（中国）」即可。若菜单层级不好找，直接把系统语言切到中文也能达到同样效果（应用默认跟随系统语言）。

## 四、提示「应用未安装」或升级失败

- 最常见原因是旧版本残留或签名不一致：先卸载旧版再装新包。**卸载前先做备份或确认同步账号已登录**，否则收藏与历史会丢，备份方法见[收藏、同步与追踪服务.md](收藏、同步与追踪服务.md)；
- 安装包下载不完整也会报错，重新下载后核对文件大小（本地这份 9.4.1 为 13.45M）与 MD5（`A0F27448F261F16ED5FF680EF9CF6722`）；
- 手机存储不足时同样装不上，清出空间再试。需要重新获取安装包时，用[Kotatsu 安装文件资源（夸克网盘）](https://pan.quark.cn/s/032605e70cff)。

## 五、GitHub、F-Droid 与 nightly 的区别

| 渠道 | 更新节奏 | 说明 |
| --- | --- | --- |
| GitHub Releases | 最快 | 官方发布页，应用内置自更新提示 |
| F-Droid | 稍慢 | 商店构建流程多一步，个别修复会晚一些到 |
| nightly | 每日 | 开发测试版，不稳定，日常使用不建议 |

普通读者在 GitHub 与 F-Droid 之间二选一就行；nightly 只推荐愿意帮忙测试新功能的人（自担风险）。想换渠道安装时，先卸载旧版再装（卸载前记得先备份）。

## 六、数据搬到新手机

两条路线，按情况选：

1. **账号同步**：旧设备登录同步账号 → 新设备首次启动选「登录同步账号」→ 收藏与历史自动下来，最省事；
2. **备份文件**：旧设备导出备份 → 文件传到新设备 → 首次启动选「从备份恢复」。不想用账号时走这条。

已缓存的离线章节两条路都不覆盖，它们是本机文件，换机后需要重新下载（详见[离线下载与本地漫画导入.md](离线下载与本地漫画导入.md)）。
