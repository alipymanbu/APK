## 一、装之前先分清渠道

Kotatsu 是一款安卓上的开源漫画阅读器，图源直接内置在应用里，装好就能搜书、看书，不需要再逐个安装图源插件。它没有上架 Google Play，需要以安装包方式安装（以官方发布页为准），搜索引擎里能搜到大量第三方下载站，版本真伪与新旧都不好说，认准下面几个渠道即可。

本篇以本地这份安装包为口径：版本 9.4.1、包名 `org.koitharu.kotatsu`、大小 13.45M。网上会看到更高的版本号，那是官方后来的更新，功能入口可能有细微差异。

## 三、安装步骤

1. 从上面任一渠道把 APK 文件保存到手机；
2. 允许安装未知应用：进入「设置 → 应用」，找到你用来下载或打开文件的那个应用（浏览器或文件管理器），打开「安装未知应用」开关。这是针对单个应用的开关，装完可以再关掉（旧版安卓路径是「设置 → 安全 → 未知来源」，以你手机的界面为准）；
3. 在通知栏或文件管理器里点开刚下载的 APK，点「安装」；
4. 出现「应用未安装」提示时，多半是手机里残留了旧版本或签名不一致：先卸载旧版再装。卸载前建议先做备份，方法见[收藏、同步与追踪服务.md](收藏、同步与追踪服务.md)。

## 四、首次启动的三屏引导

1. **欢迎页三选一**：「本地存储」是单机使用，不注册任何账号；「登录同步账号」用于从另一台设备把书架搬过来；「从备份恢复」用来导入老设备导出的备份文件。第一次用、不想折腾就选本地存储；
2. **勾选语言与内容类型**：默认勾选 Manga（日漫），看韩漫再勾 Manhwa，看欧美漫画勾 Comics。这一步决定浏览页里默认出现哪些图源，多勾不影响使用，后面还能在图源管理里调整；
3. **个性化推荐询问**：开启后应用会根据你的阅读历史推荐相关作品，不想开就选拒绝，不影响其他任何功能。

进主界面后，从底部「浏览（Explore）」标签开始找书；想先调阅读手感，看[阅读模式与界面设置.md](阅读模式与界面设置.md)。

## 五、升级与换机

- 从 GitHub 渠道装的版本带应用内自更新，出新版会提示；F-Droid 渠道通过 F-Droid 客户端更新，节奏慢一些；
- 换机或重装前，先把书架与进度保住：登录同步账号，或在旧设备上导出备份文件，两种方式的取舍见[收藏、同步与追踪服务.md](收藏、同步与追踪服务.md)；
- 装好后如果某个图源打不开或章节加载失败，处理思路在[常见问题与解决办法.md](常见问题与解决办法.md)。
