# imo 常见问题与排查

> 装好、登录之后，实际会碰到的多半是「消息不响」「通话卡」「后台被清」这几类。这篇按现象给出排查顺序，每条都先给可执行的一步，再给找不到原因时的下一步。

## 一、消息不响、通知不来

这是 imo 在国产系统上最常被吐槽的一类，原因几乎都出在系统的省电与后台管理，而不是 imo 本身。按顺序查：

1. **通知权限**：设置 → 应用 → imo → 通知，确认允许，并且没有把这个渠道静音；
2. **后台自启动**：在系统的「应用启动管理/自启动」里，把 imo 设成允许自启动、允许后台活动；
3. **电池优化**：把 imo 移出「深度省电/智能省电」名单，改成「不限制」；
4. **锁屏清理**：部分系统锁屏后清理后台，需要在「最近任务」里给 imo 加锁；
5. 都放行后，重启一次手机，再让朋友发条消息验证。

其余可能：手机开了勿扰模式、imo 内被设成了静音、对方被你自己拉黑。

## 二、收不到验证码 / 注册登录卡住

验证码到不了手机，官方列了七类原因（网络延迟、短信权限、被手机拦截、当天次数超限、网络受限、号码不活跃、一台设备关联多号）。逐条排查表在 [注册登录与换手机号.md](注册登录与换手机号.md) 第三节。

如果验证码收到了、填进去却报错：多半是**填错数字**或**页面已过期**，回上一步重新获取一次即可，别反复提交。

## 三、通话卡、听不到声音

| 现象 | 先做这一步 |
| --- | --- |
| 通话断断续续 | 换网络（Wi-Fi ↔ 流量），靠近路由器或改用 5GHz |
| 完全听不到对方 | 检查是否插着没插好的耳机、是否误触静音 |
| 对方听不到你 | 系统里放行 imo 的麦克风权限，重启应用 |
| 视频糊 | 设置里调高视频清晰度，同时确认上行带宽 |
| 一响铃就断 | 大概率是网络受限或被对方拉黑，先换网络再判断 |

通话质量取决于**你这一侧的上行网络**，家里 Wi-Fi 通话卡时，先怀疑带宽和信号，而不是对方。

## 四、闪退、打不开

1. 重启手机，再打开一次；
2. 设置 → 应用 → imo → 存储，清一次缓存（**不要**顺手清「数据」，那会退出登录并丢本地记录）；
3. 确认系统版本满足要求（见 [下载与安装教程.md](下载与安装教程.md) 第二节）；
4. 若刚更新过就崩，卸载重装本仓库这一份包再试。

## 五、耗电和流量偏高

- **耗电**：常驻后台收消息本身就吃电。把「自动下载收到的媒体」关掉、减少长时间视频通话后台运行，能明显省电；
- **流量**：视频通话最费流量，尽量放 Wi-Fi 下；出门前看一眼有没有开「移动数据下自动播放视频」。

## 六、隐私和账号安全上的两个提醒

- **锁屏泄露**：不想让消息内容出现在锁屏，去 imo 隐私设置里关掉通知内容预览；
- **陌生登录提醒**：收到不是你本人操作的「新设备登录」提示，立即改 PIN、检查登录设备、必要时改绑手机号，细节见 [注册登录与换手机号.md](注册登录与换手机号.md) 第五节。

## 七、广告和推广通知太多

imo 免费版在使用中会带广告，这是它维持免费的方式；官方另有付费订阅（Premium），订阅后应用内广告不再出现，并附带宽裕的云端存储等权益，具体权益与价格**以应用内订阅页当时显示为准**。

不想订阅、只想少被打扰，从系统通知入手最直接：

1. Android 13 及以上：设置 → 通知 → 应用通知 → imo，按「通知渠道」逐个关掉营销/推广那几条，但**保留「消息」这条**，否则会连正常消息一起静音；
2. 收到某条推广通知时，长按它，选关闭此类通知，或进对应渠道单独关掉；
3. 休息时段可以开系统的「勿扰模式」，只放行电话与重要联系人。

## 八、记录占空间太大怎么清

聊天记录、收到的图片视频是 imo 占空间的大头。清理按这个顺序来，别一上来就清数据：

1. 先在设置里确认云端同步已完成（见 [聊天记录导出与备份恢复.md](聊天记录导出与备份恢复.md)），免得清完本地才发现云端没有；
2. 设置 → 应用 → imo → 存储，先「清缓存」，这一项不会退出登录、也不动聊天记录；
3. 还想省更多空间，再进 imo 的存储/聊天设置里按会话清理媒体，或删掉不再需要的会话；
4. **不要**直接清「应用数据」，那等于把 imo 恢复成刚装好的状态，会退出登录。

## 九、确定不了是哪个环节的问题

用一句话缩小范围：**是装不上、登录不上，还是登录后功能异常？**

- 装不上 → 看 [下载与安装教程.md](下载与安装教程.md) 第六节；
- 登录不上 → 看 [注册登录与换手机号.md](注册登录与换手机号.md)；
- 功能异常（消息、通话、通知） → 看本篇一到五节。

按这三条分流，基本能定位到具体那一篇，不用在一堆现象里挨个试。
