## 一、先对准这一份包

imo 的版本号是按「年份.月份.构建号」排的，比如 `2025.09.1021` 表示 2025 年 9 月的一条构建。下面这些字段只对**这一份安装包**成立：

| 项目 | 这一份的值 |
| --- | --- |
| 应用名 | imo |
| 版本 | 2025.09.1021 |
| 包名 | com.imo.android.imoim |
| 安装包大小 | 133.75 MB |
| MD5 | `25f00649af22237c5a5dd2034444af81` |
| 记录日期 | 2026-09-23 |

官方渠道上现在能下到的通常已经是更新的版本号，和你手里这份不一定是同一版。**对版本号、包名、体积，一律以这张表为准**；想知道官方最新到哪一版，去官网 [imo.im](https://imo.im/) 的下载页看当时显示。包名 `com.imo.android.imoim` 是 imo 的安卓完整版，它和「Lite 精简版」不是同一个包，两者可以并存。

## 二、装之前确认两件事

**系统版本。** 本地记录里这一份对应的要求是「安卓 5.2 以上」，第三方应用收录页多写「安卓 5.0 以上」，两者略有出入。安卓版本太低会出现「装到一半失败」；系统版本在手机「设置 → 关于手机」里看，具体最低要求以设备实际安装结果为准。

**剩余空间。** 安装包 133.75 MB，装完占用会更大，因为还要算上应用本体、聊天记录、收到的图片视频缓存。手机上留出安装包体积两倍以上的空余，用起来才不会因为空间不足中断。

## 三、从网盘取包并安装（安卓）

1. 打开 **imo 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/3c7dde32f354](https://pan.quark.cn/s/3c7dde32f354)，转存或下载其中的 `.apk` 文件；
2. 如果是在电脑上取的包，把 `.apk` 传到手机的「下载」目录（数据线、聊天工具传文件都行）；
3. 在手机的文件管理器里进入「下载」，点这个 `.apk` 开始安装；
4. 首次安装系统会拦一下，提示「不允许从此来源安装应用」。到「设置 → 应用 → 特殊权限 → 安装未知应用」里，给你点安装的那个应用（通常是文件管理或浏览器）放行，再回来重新点安装；
5. 装完桌面或应用列表里会出现 imo 图标。

两条经验：**不要**用「在线解压」「改后缀」等办法处理安装包，那会让包直接损坏；安装时提示「解析包失败」，多半是包没下完整，删掉重下一次即可。

## 四、核对安装包是否完整

从网盘下到电脑后，建议先对一次 MD5，确认传输过程没损坏。Windows 上用 PowerShell：

```powershell
Get-FileHash -Algorithm MD5 ".\imo_v2025.09.1021.apk"
```

输出的哈希值与第一节表格里的 MD5 一致，说明这一份包完整；不一致就重新从网盘取一次。这一步能省掉「装到一半报错、却分不清是包的问题还是手机的问题」的折腾。

## 五、第一次打开要做的几项

- **允许权限**。要让 imo 读通讯录才能看到哪些朋友在用，要麦克风、摄像头权限才能通话。用不到的可以先不给，功能触发时系统会再问。
- **允许后台与通知**。imo 靠推送收消息，装完第一次打开会要「通知」权限；不给的话对方发消息你这边不会响。国产系统还要在「电池/后台管理」里允许 imo 自启动、别被清后台（详见 [常见问题与排查.md](常见问题与排查.md)）。
- **准备一个手机号**。imo 用手机号注册，注册时会按区号选国家/地区（详见 [注册登录与换手机号.md](注册登录与换手机号.md)）。

## 六、装不上、装完打不开

| 现象 | 常见原因 | 先做这一步 |
| --- | --- | --- |
| 提示「解析包失败」 | 安装包下载不完整 | 删掉重下，或按第四节核对 MD5 |
| 提示「应用未安装」 | 空间不足，或已装同包名的其他版本 | 清出空间；若已装有同包名的 imo，先卸载再装 |
| 系统不让点安装 | 未放行「安装未知应用」 | 见第三节第 4 步 |
| 装完点开就退回桌面 | 系统版本过低或缓存异常 | 重启手机后再试，仍不行见 [常见问题与排查.md](常见问题与排查.md) |

安装环节的排查顺序统一是：**包完整 → 空间够 → 系统版本够 → 权限放行**。四步都过还装不上，再按排查那篇往下走。
