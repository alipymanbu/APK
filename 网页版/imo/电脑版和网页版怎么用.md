## 一、官网提供哪些版本

在官网 [imo.im](https://imo.im/) 的下载入口里能看到这几个版本，别下错：

| 版本 | 说明 |
| --- | --- |
| imo Android | 功能完整的安卓稳定版，就是本仓库这一份对应的版本 |
| imo Android Lite | 精简的轻量版，占用更小 |
| imo iOS | 苹果手机/平板版 |
| imo Windows | 电脑版 |
| imo macOS | 苹果电脑版，Intel 与 Apple 芯片各有一份安装包 |

桌面端是否提供原生安装包**会随地区变化**。官网下载页没给你所在地的桌面安装包时，可以用浏览器登录网页版，或按第四节走安卓模拟器这条路。**以官网下载页当时提供的版本为准。**

## 二、电脑版怎么装

1. 打开官网 [imo.im](https://imo.im/)，进下载页；
2. 选和电脑系统对应的安装包（Windows 选 Windows 版），下载；
3. 双击安装，按提示下一步；装完桌面上出现 imo 图标；
4. 首次打开按第三节登录。

Mac 用户的安装包在同一页面，文件名一般形如 `.dmg`，双击挂载后拖进「应用程序」即可。**不要**从来路不明的第三方站点下桌面版，认官网。

## 三、登录：手机号 + 验证码

电脑端和手机端登录方式一致，都用手机号：

1. 打开桌面版/网页版，先选国家/地区区号，再填手机号；
2. 请求验证码，等短信；
3. 填码登录。

用同一个手机号登录，电脑端会看到你在手机上的联系人。验证码收不到的处理与手机端完全相同，见 [注册登录与换手机号.md](注册登录与换手机号.md) 第三节。

⚠️ 桌面端第一次登录，系统可能会给手机端推一条「新设备登录」的提示。看到不是你自己操作的登录提醒，立即去改 PIN 并检查登录设备。

## 四、手机上取不到包、想在电脑上用怎么办

如果你只有电脑、手上暂时没有那份安卓安装包，有两种常见走法：

- **网页版优先**：能直接登录、发消息、语音/视频通话，不用装任何东西；
- **安卓模拟器**：在电脑上装一个安卓模拟器（如 BlueStacks），在模拟器里登录应用商店搜 imo 安装。这条路的代价是吃电脑内存较多，模拟器本身也要单独装。

已有安装包的，直接在手机或模拟器里装本仓库这一份即可，步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 五、给没装 imo 的人发通话链接

imo 有一个网页通话能力：你发出一个链接，**对方不需要装 imo**、用浏览器打开就能和你通话。适合临时拉一个不在 imo 上的朋友进来，比如家里长辈只用微信、你不想让他们额外装应用时。

用法是在应用里找到这个「创建通话链接/分享链接」入口，生成后把链接发给对方。对方点开授权麦克风、摄像头即可加入，走的是浏览器通话，所以对网络有一定要求。

## 六、多端同时在线会不会冲突

同一手机号可以在多个端登录，消息会同步到各端。要注意的是：手机端和电脑端都能响铃，视频通话接在哪一头由你先接的那个设备决定。想省手机流量，就在电脑上接。

## 七、桌面端常见的两个坑

- **听不到声音/看不到画面**：桌面系统首次会请求麦克风、摄像头权限，被拒绝后要到系统「隐私」设置里手动放行，再重启客户端。
- **登录后一直转圈、联系人不同步**：先确认电脑网络能正常访问外网，再退出重登一次；仍不行就换个网络环境再试，并按 [常见问题与排查.md](常见问题与排查.md) 逐项排查。

想确认自己下的是不是官方版、以及「完整版 / Lite 版」该怎么选，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
