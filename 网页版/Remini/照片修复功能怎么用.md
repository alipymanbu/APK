## 一、主流程就四步

1. 打开 Remini，在首页点「Enhance」（增强/修复）入口。
2. 从相册里选一张要处理的照片，必要时先用自带的裁剪工具把画面裁到位。
3. 点「Enhance」开始处理，等待几秒到十几秒（时间取决于网络与照片大小）。
4. 处理完成后会进入前后对比界面，左右滑动查看效果；满意就点保存，照片存回相册。

界面文案和按钮位置会随版本变化（本文对应的 3.7.835 版与官方商店的最新版可能有出入），认准「选照片 → 处理 → 对比 → 保存」这条主线就行。

## 二、处理模式怎么选

Remini 把不同问题拆成了不同模式，你手上的照片是哪种毛病，就选对应的入口：

| 模式 | 适合的照片 |
| --- | --- |
| Unblur & Sharpener（去模糊锐化） | 拍糊了、手抖、对焦没对上的近期照片 |
| Old Photos Restorer（老照片修复） | 泛黄、褪色、有划痕折痕的老照片 |
| Denoiser（降噪） | 夜景、暗光下拍出的噪点多的照片 |
| Image Enlarger（放大） | 分辨率太低、想放大后还能看清的照片 |
| Color Fixer（色彩修正） | 偏色、发灰的照片 |
| Face Enhancer（人脸增强） | 人像、自拍、合影，重点是五官细节 |
| Background Enhancer（背景增强） | 人清楚但背景糊了的照片 |
| AI Photos（AI 写真） | 用自己的照片生成 AI 写真风格图 |

不同版本里这些入口的叫法和排布不完全一样，找不到某个模式时以应用内实际列表为准。

想在电脑大屏上处理（比如整理扫描的老照片），不用装应用，官方浏览器版直接上传处理，见 [电脑上怎么用网页版.md](电脑上怎么用网页版.md)。

## 三、实体老照片怎么处理

实体照片（纸质的那种）不能直接处理，先翻拍成数字图再走上面同样的流程。翻拍质量直接决定修复上限：

- 光线均匀，避免闪光灯，避免照片表面反光；
- 手机与照片平行、对焦清楚后再拍；
- 让照片占满画面，减少多余背景。

翻拍完如果只是想清晰化，选 Old Photos Restorer 或 Unblur & Sharpener 都可以，各试一次看效果。

## 四、处理前的两个习惯

- **用原图，别用截图或聊天软件压缩过的图**。截图和转发图已经被压掉一批细节，修复的余地小很多。
- **一次只修一张，先试后批量**。同一批照片的毛病通常相同，先用最有代表性的那张试出合适的模式，再处理剩下的，避免把免费额度浪费在不合适的模式上。
