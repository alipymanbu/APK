# bing AI 对话样式怎么选

> 「更有创造力 / 更平衡 / 更精确」三个按钮分别适合什么场景，以及把问题问清楚的几个写法。

主页那三个样式按钮不是摆设：同一个问题用不同样式问，回答的长度、口吻、发挥程度都不一样。这套「三档对话风格」的设计来自它连接的 New Bing 服务（2023 年 2 月该服务上线时就提供这三种模式）。选档的原则只有一条：**要答案选精确，要灵感选创造，拿不准选平衡**。

## 一、三种样式对照表

| 样式 | 适合的事 | 典型问法 |
| --- | --- | --- |
| 更精确 | 查事实、查数据、要简短可靠的答案 | 「某某的 API 限速是多少？」 |
| 更平衡 | 日常问答、总结、解释、翻译 | 「把这段话总结成三点」 |
| 更有创造力 | 写作、起名、脑暴、玩梗 | 「给咖啡店起十个带季节感的名字」 |

切换不需要退出会话：直接在主页点另一档，再发下一条消息就行。

服务方在 2023 年 3 月的发布说明里给过三档的官方定义，可以当作选档的准绳：**精确**=答案更短、更贴搜索结果；**创意**=答案更长、描述更充分；**平衡**=介于两者之间。同一道题用三档各问一遍，答案从篇幅到口吻都会不同，拿不准时这个对比法最直观。

## 二、配合提问写法效果更好

样式定了之后，问题本身怎么写影响更大。几个立竿见影的写法：

1. **限定范围**：「2024 年之后」比「最近」清楚，「不超过 100 字」比「简单说说」可控；
2. **要求给出来源**：「答案后面附上来源链接」，事实类问题建议养成这个习惯，方便你自己核对；
3. **分步走**：复杂的活别一口气说完，先让它出提纲，你确认后再逐段展开；
4. **给它素材**：总结、改写类的任务，把原文完整贴进输入框（8000 字以内），比让它凭印象写靠谱；
5. **在句子里点名风格**：不改档位、直接在问题里写「简短精确地回答」或「放开写，越生动越好」，效果近似切档，适合一个问题一个风格的场合。

## 三、GPT4 模式开关

样式按钮下方还有一个「启用 GPT4 模式」开关。这个开关控制对话所用模型的档位，不影响三种样式的划分。开与不开在回答质量与速度上的差别，建议你用同一个问题各跑一遍自己对比，以实际效果为准。

## 四、回答不满意怎么办

- 回答太干、太短：切「更有创造力」或把约束条件放松，要求它展开某一点；
- 回答太飘、不贴题：切「更精确」，并把问题里的关键条件重复一遍；
- 回答到一半断了：先点开新会话再试，轮数与长度的限制见 [打不开或对话报错怎么办.md](打不开或对话报错怎么办.md)。
