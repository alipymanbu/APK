这个 App 没有注册、签到那一套流程，打开就是对话页，你要做的只有三件事：选样式、打字、看回答。本篇按从上到下的顺序把界面讲一遍。安装包怎么来的见 [下载与安装教程.md](下载与安装教程.md)。

## 一、主页就是对话页

新会话的主页从上到下是这几块：

| 区块 | 你能做什么 |
| --- | --- |
| 示例提示词卡片 | 上面摆着现成的问法（比如「以海盗的口吻写一首关于外太空鳟鱼的俳句」），点一下就填进输入框，不想想问什么就直接点它 |
| 选择对话样式 | 「更有创造力 / 更平衡 / 更精确」三个按钮，选中的会高亮，怎么选见 [对话样式怎么选.md](对话样式怎么选.md) |
| 启用 GPT4 模式 | 一个开关，控制对话所用模型的档位；开与不开的回答差别以你实际对话效果为准 |
| 底部输入框 | 打字的地方，右边有字数计数 |

对话过程中会出「停止响应」按钮，回答跑偏或太长想打断时点它即可。

## 二、输入框的几个细节

1. **字数上限 8000**：输入框右下角的 `0/8000` 就是计数，超长的材料建议拆开分几轮发；
2. **换行**：提示文字写着「Shift + Enter 换行」——这是给外接键盘准备的习惯，手机软键盘直接按回车键即可；
3. **提示词**：输入 `/` 可以选提示词；App 设置里还有「提示词管理」，你可以把自己常用的问法存进去，下次不用重复打。

## 三、设置里有什么

点右上角「设置」，能看到这些入口：

| 入口 | 用途 |
| --- | --- |
| 用户信息 | 查看当前用户状态 |
| 高级设置 | 修改对话行为的选项都在这里，不熟悉保持默认即可 |
| 语音设置 | 语音相关的开关 |
| 提示词管理 | 新增、编辑你自己的常用提示词 |
| 开源地址 | 跳转到这个客户端的程序页面 |
| 复制站点 | 把它连接的站点地址复制出去 |
| 版本信息 | 显示站点程序的版本号（注意这不是安装包的版本号） |
| 站点域名 | 显示它当前连接的站点地址 |

其中「站点域名」这一项在排查时最有用：对话报错时，先看这里显示的地址能不能在浏览器里打开，能打开说明站点活着，问题多半出在你这头的网络；打不开就是站点或线路的问题。具体排查步骤见 [打不开或对话报错怎么办.md](打不开或对话报错怎么办.md)。

## 四、先试这三句

想快速摸清它的脾气，建议第一轮就按这三句来：

1. 事实型：「用三句话说明某某是干什么的」（切到「更精确」）；
2. 总结型：「把这段话总结成三点：……」（切到「更平衡」）；
3. 创意型：「以海盗的口吻写一首关于外太空鳟鱼的俳句」（切到「更有创造力」）。

三种样式跑完一轮，你就知道之后遇到不同的事该切哪一档了。
