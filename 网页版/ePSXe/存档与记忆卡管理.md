# ePSXe 的存档与记忆卡管理

> 记忆卡和即时存档不是一回事，坏掉的后果也不一样。本篇讲清两者的区别、各在哪管理、Autosave on Exit 该不该开，以及换代设备时怎么把存档完整搬走。

存档是玩到一半才想起来关心、但一旦丢了最难受的东西。在这份模拟器上，你需要区分两套机制，因为它们的存放方式、丢失风险和恢复手段完全不同。

## 一、两种存档，别混为一谈

| | 记忆卡（Memcard） | 即时存档（Savestate） |
| --- | --- | --- |
| 相当于 | 原机的记忆卡 | 把此刻的运行状态整个拍下来 |
| 存在哪 | 记忆卡文件里，**所有游戏共用** | 每个游戏自己的存档槽 |
| 管理方式 | 用「Run bios」进原机记忆卡编辑器 | 游戏内菜单操作 |
| 丢失风险 | 一坏影响面大 | 单个槽损坏只影响那一个进度 |
| 和 PC 版互通 | 支持 | 支持 |

**记忆卡是所有游戏共用的一个文件**，这一点是本篇最需要记住的 —— 它出问题不是丢一个游戏，是丢全部。官方也专门提醒过要做备份。

## 二、记忆卡怎么用

- **Memcard1 File / Memcard2 File**：分别选择两个记忆卡端口使用的文件。端口对应原机的两张卡。
- **Enable / Disable memcards**：可以整体关掉记忆卡。少数游戏（例如 Lifeforce）**必须关掉才能正常跑**，遇到这类游戏就在这里关一次。
- **用 Run bios 管理记忆卡内容**：主界面的 **Run bios** 会进入原机的记忆卡管理界面，在那里可以**移动、删除**具体的存档块 —— 相当于在真机上整理记忆卡。想清掉某个游戏的旧存档、或者腾出空位，就在这里做。
- **记忆卡文件长什么样**：标准 PS1 记忆卡的转储是 **128 KB 的裸数据**，里面是 15 个存档块加 1 个目录块。常见扩展名有 `.mcr`（最通用）、`.mcd`、`.bin`，三者内容一致，只是叫法不同 —— 在别处看到这三个扩展名，都可以直接拿来当记忆卡文件用。
- **和真机记忆卡互换**：真机经专用读卡设备导出的格式（如 `.gme`）、掌机上的虚拟记忆卡格式（如 `.vmp`）都不是裸数据，要先转换成 `.mcr` 才能被模拟器直接读到；反过来，这里的 `.mcr` 也能转成对应格式给别的设备用。
- 文件名与路径在 **Preferences → Memcards** 相关项里可以改，改之前先确认新的文件是你要用的那一份。

## 三、即时存档怎么用

游戏进行中呼出菜单，两个选项：

- **Menu → Savestate**：把当前状态存到所选的槽位；
- **Menu → Loadstate**：从所选的槽位恢复。

**一共 5 个槽位**（官方标为 MAX = 5）。用法上建议固定一个习惯，例如「1 号槽存日常进度、5 号槽存 Boss 战前」，免得覆盖掉想留的那个。

两条容易被忽略的性质：

- **即时存档搬不进别的模拟器**。它是这套模拟器自己的格式，既不能给别的模拟器读，也不能给真机用。要跨设备或跨模拟器搬进度，先在游戏里正常存档到记忆卡，再搬记忆卡文件 —— 记忆卡是通用的，即时存档不是。
- **切换 BIOS 模式会让旧即时存档失效**。官方说明过，真实 BIOS 下的即时存档与内置 HLE 模式下的即时存档**互不兼容**，两者的命名空间不同。打算切换模式之前，先把进度落到记忆卡上；切换之后旧的即时存档就读不回来了，这不是操作失误，是设计上就不互通。

关于格式兼容，官方给过一条时间线，可以当参考：ePSXe 1.2.0 / 1.4.0 支持版本 0 的即时存档，1.5.0 起支持 0 和 1，1.6.0 起支持到 2，1.7.0 起支持到 3，**1.8.0 及以上支持 0、1、2、3 全部四种**。实际含义是：**低版本读不了高版本写出来的新格式存档**。用 2.0.17 存档、再拿很早的老版本去读，可能读不出来，反过来一般没问题。

## 四、Autosave on Exit 值不值得开

设置里有一项 **Autosave on Exit**：退出模拟器时自动存一次状态，下次进游戏会弹出恢复提示。

官方对它的态度是**不推荐** —— 它用多线程实现，个别情况下状态文件可能损坏。所以建议是：

- 想要这个便利，可以开；
- **但不要把它当成唯一的存档手段**，重要的进度用第二节的记忆卡和第三节的即时存档双保险；
- 遇到「退出后再进游戏，进度不对或提示存档损坏」，第一件事就是关掉它，改用手动存。

## 五、存档放在哪，卸载会不会丢

这取决于你首次启动时给 ePSXe 选的存储方式（见 [下载与安装教程.md](下载与安装教程.md) 第四节）：

| 存储方式 | 存档位置 | 卸载应用后 |
| --- | --- | --- |
| 共享存储（基准文件夹） | 你挑的那个文件夹里 | **通常保留** |
| 私有存储 | `/storage/emulated/0/Android/data/com.epsxe.ePSXe/files/epsxe/` | **随应用一起被删**，且普通文件管理器访问不到 |

**用私有存储的人注意**：卸载等于清档，重装也拿不回来。要长期玩，就把基准文件夹换到共享存储的位置 —— 路径在 **Preferences → Storage preferences → ePSXe base folder** 里改，改完记得把旧文件先搬过去。

## 六、备份怎么做最稳

1. **整个基准文件夹复制一份**。这是最省事也最完整的做法：记忆卡、即时存档、配置都在里面，不用去区分哪个文件管什么。
2. **记忆卡单独存一份**，因为它是所有游戏共用的，坏一次代价最大。
3. **利用官方自带的上传下载功能**：ePSXe 支持把记忆卡与即时存档上传到 Dropbox，在多台设备之间共享。换了设备想接着玩，这条路不用碰数据线。
4. **换手机、刷机、恢复出厂设置之前先备份一次**，这些操作的风险比卸载应用高得多。
5. **别用第三方清理工具「深度清理」基准文件夹**。这类工具把存档目录当缓存清掉，是很常见的丢档原因。

补一条和多碟游戏有关的：设置里有专门的记忆卡处理模式，官方更新记录把它描述为「按游戏切换记忆卡，让同一款游戏的不同碟共用同一张卡」。玩多碟游戏时用这个模式，换碟环节就不必手动换卡。

## 七、和 PC / Linux 版互通

ePSXe 的记忆卡与即时存档**和 Windows / Linux 版格式兼容**，这是它和不少安卓模拟器不一样的地方。实际用处：

- 手机上没时间打完的部分，把存档拷到电脑，在 PC 版接着玩；
- 反过来也一样。两边的文件放进各自的记忆卡槽位即可。

一个前提还是版本问题：**PC 版的版本号与安卓版不是同一套编号**，跨版本读写时如果读不出来，先把两边都升到各自较新的版本再试，别在旧版本上反复折腾。

另外，PC 版的记忆卡文件放在它自己的 `memcards` 目录里 —— Windows 在程序目录下，Linux 与 macOS 在用户目录的 `.epsxe` 里。安卓这边的文件拷进那个目录、或把 PC 那份拷进基准文件夹，互换就完成了，不需要转换格式。

## 八、换设备时的迁移步骤

1. 在旧设备上确认基准文件夹用的是共享存储（是私有存储的话先改过来，并把文件搬出 `Android/data`）；
2. 把整个基准文件夹拷到电脑或移动存储；
3. 新设备装好 ePSXe，首次启动时**新建并选中一个新的文件夹作为基准文件夹**；
4. 把旧文件夹里的内容复制进新基准文件夹，覆盖同名文件；
5. 打开 ePSXe，运行一次曾存档的游戏，进游戏呼出菜单读一次档，确认能读到；
6. 确认成功后，**再考虑**卸载或清理旧设备的数据。

卡在第五步读不到档，先别急着删旧数据 —— 问题多半在基准文件夹位置或权限上，按 [常见问题与排查.md](常见问题与排查.md) 第十节查一遍。另外提醒一句：如果迁移时只搬了记忆卡与即时存档文件，画面与按键设置不会跟着走，需要在新设备上重新调一遍，参考 [画面设置与卡顿优化.md](画面设置与卡顿优化.md)。
