# ePSXe 的手柄与触屏按键怎么设

> 触屏能玩，但 PS1 上的动作、格斗、赛车类游戏手感差别很大。本篇讲清先选对 PSX 手柄类型、触屏皮肤怎么编辑、六个额外按键能绑什么，以及外接手柄从自动识别到手动映射的完整步骤。

按键配置这块的顺序很重要：**先确定模拟成哪种 PSX 手柄，再决定用触屏还是外接手柄**。顺序反了会出现「按下没反应」或者「按键位置全不对」，因为不同手柄类型下可用的键位本身就不一样。

## 一、先选对 PSX 手柄类型

位置：**Preferences → Player1 → Pad Type PSX**，四个选项：

| 类型 | 什么时候用 |
| --- | --- |
| Digital（仅数字） | 原版 PS1 手柄，没有摇杆。**部分游戏原本就不支持 DualShock**，这类必须选它 |
| Dual Shock | 带双摇杆与震动，多数现代游戏用这个 |
| Namco Gun / Justifier Gun | 光枪类游戏，用触屏来打 |

ePSXe 内置了一份「哪些游戏支持哪种手柄」的数据库，**你选了游戏不支持的类型，它会自动把该模式禁用掉**。所以遇到「摇杆没反应」，先回头看这里是不是被自动切回了 Digital —— 那不是故障，是游戏本身不接受。

顺带把多人玩法的两种形态分清：**同一台设备上的双人分屏**不需要额外设置，插上手柄就能开始；**两台设备联机对战**则要求两边用同一个游戏、同一份 BIOS，步骤与已知限制见 [两台设备联机对战怎么用.md](两台设备联机对战怎么用.md)。

## 二、用触屏玩

### 皮肤与显示

| 选项 | 位置 | 作用 |
| --- | --- | --- |
| Pad Skin Landscape | 触屏设置 | 横屏皮肤，共 6 种，另有 `None`（不显示按键） |
| Pad Skin Portrait | 触屏设置 | 竖屏皮肤，共 7 种 |
| Hide/Show Touch Buttons | 触屏设置 | 等效于开关整个虚拟手柄 |
| Transparency on skins | 触屏设置 | 皮肤透明度，避免挡住画面 |
| Vibrate on touchscreen buttons | 触屏设置 | 按虚拟键时震动反馈 |

**用外接手柄玩，就把皮肤设成 `None` 或直接隐藏**，否则屏幕上会一直挂着一层按键挡住画面。

### 编辑自己的按键布局

位置：**Preferences → TouchScreen → Edit Gamepad**，横屏与竖屏各一套编辑器。在编辑器里可以：

- **移动、缩放、隐藏**任意一个按钮 —— 按钮太小或太大都在这里改；
- 用 **SWAP MODE** 切换到模拟摇杆那一套皮肤进行编辑；
- **添加右摇杆**：默认只启用左摇杆，选 Analog 模式时如果发现右边是空的，就是这里没开。

### 动态方向键与动态动作键

打开 Dynamic Dpad/Lstick 与 Dynamic Action Buttons 后，**在屏幕左半边滑动控制方向、右半边滑动触发动作键**，不再需要按在固定按钮上。习惯手势操作的人会觉得更接近原生手感。

### 自定义皮肤文件

**Pad Skin file** 可以指定一张 PNG 作为皮肤，用来替换内置样式。

### 几套配置档，以及按游戏自动恢复

触屏设置不止一套：可以保存多套触屏配置（包含按键布局、PSX 手柄类型、模式与连发设置），并且**能按游戏自动恢复** —— 下次进同一个游戏，触屏配置回到上次用的那一套。

实际用处是给不同类型的游戏各配一套：格斗游戏想要紧凑的六键布局、RPG 想要宽松的方向键区、赛车想要大尺寸的油门刹车。分好之后不用每次进去重调，换句话说这一节的内容配一次就够本了。

## 三、六个额外按键能绑什么

触屏除了固定键位，还能加**最多 6 个额外按钮**（Map virtual buttons），每个可以绑成：

- **存 / 读即时存档** —— 不用每次呼出菜单；
- **帧率限制开关** —— 临时加速用；
- **连招（combo）** —— 两个键合成一个键，格斗游戏常用；
- **粘滞键（sticky）** —— 按一下松开仍然保持按下状态。

对应地，**Map hw buttons** 可以把上面这些功能绑到手柄的实体键上，用外接手柄时就不必再碰屏幕。

## 四、连外接手柄：先试自动识别

1. 先把手柄连上设备：蓝牙配对，或用 OTG 转接线连接；
2. 确认手柄在系统里能用 —— **先在别的应用里试一下**，这一步能排除掉一半问题；
3. 打开 ePSXe，进游戏，**在游戏中按一下手柄上的按键**；
4. 如果这个型号被自动识别，会弹出一个提示框问你是否用手柄玩，确认即可。

ePSXe 内置了常见型号的配置档，选中型号后**多数手柄不需要手动映射**：Moga、Moga PRO、PS3（Sixaxis）、PS4、Xbox 360、Xperia Play、Nyko Gamepad PRO、iPega、Archos、Nvidia Shield、Ouya 等都在列。

顺带一提，除了手柄，ePSXe 也支持 OTG 鼠标（更新记录里加过这项支持）。需要精确点选设置项时它能派上用场，玩游戏本身还是手柄与触屏更合适。

## 五、没被自动识别时的五步手动映射

位置都在 **Preferences → Player1** 下面：

1. **Gamepad Test Axis** —— 拨动摇杆，屏幕上应出现数值变化。没变化说明手柄没连通，别往下走（需要 Android 3.1 及以上）；
2. **Select Gamepad** —— 在扫描结果里选中你的手柄。**触屏用户选 `virtual`**；用 Xperia Play 选 `xperiaplay`（这样才能支持触控板）；Moga 设备选 `moganative`；
3. **Player 1 map buttons** —— 逐个把虚拟按键指到实体键上；
4. **Player 1 map axis** —— 把摇杆轴指过来。这一步要配合第 1 步看到的数值。个别手柄的 **L2 / R2 是模拟量**，也必须在这里映射；
5. **Pad Type PSX** 选 **Dual shock**。提醒一句：**原版 PS1 上有些游戏不支持 DualShock**，这类游戏要退回 Digital 才能玩。

映射完进游戏实测一遍：方向、菜单、以及需要同时按的键都要试，别等到玩了半小时才发现某个键是空的。

## 六、手柄连上了但没反应，按这个顺序查

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 所有键都没反应 | 蓝牙配对记录有残留 | 在系统里删掉这个手柄的配对记录，重新配一次 |
| 只有个别键不灵 | 映射表里那几项是空的 | 回 **Player 1 map buttons** 重新指定 |
| 有线能用、无线不行 | 问题在蓝牙链路，不在模拟器 | 检查电量、距离、以及是否被其他应用占用 |
| 动了但方向不对 | 轴映射反了或指错了轴 | 用 Gamepad Test Axis 看数值，重新映射 |
| 蓝牙手柄延迟明显 | 老设备上的兼容选项在起作用 | 在 ePSXe 设置里**关掉 `bluez` 这个选项**（它只对很老的机型有意义）；PS4 手柄另有一些系统侧的延迟处理办法 |

完整的现象—对策表在 [常见问题与排查.md](常见问题与排查.md) 第六节，那一节按「完全不响应 / 部分不响应 / 延迟」分了三条。

## 七、震动与体感

- **Vibration Mode** 三档：`disabled` / `enabled` / `enabled on device`。选 `enabled on device` 时用手机自身的振动马达。
- **震动效果本身是有限的**：它依赖手柄的驱动，Android 也不支持分不同马达、不同效果的震动，所以别指望和原机一致 —— 有震感就是正常水平。
- **摇杆死区（dead zone）**：手柄与重力感应都可以设。摇杆松手后画面还在缓慢漂移，就是死区偏小 —— 调大一档这个现象就没了；反过来觉得转向不够灵敏，就调小一点。
- **Accelerometer**：可以用重力感应来控制左摇杆，可选 X 轴、Y 轴或两者。赛车、飞行类的游戏可以试试。
- **Autofire**：可以指定一个键开启连发，按住即自动连按，省手。

## 八、和画面设置的关系

按键顺不顺手是一回事，画面跟不跟得上又是一回事。触屏连招、赛车过弯这类操作，对帧率稳定性比对手柄更敏感；如果按键本身没问题但操作总是差半拍，先去 [画面设置与卡顿优化.md](画面设置与卡顿优化.md) 第四节把帧率问题排掉，再回来调键位。
