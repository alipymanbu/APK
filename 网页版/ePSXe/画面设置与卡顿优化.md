# ePSXe 的画面设置与卡顿优化

> 画面糊、比例不对、跑着跑着卡顿，这三个问题的调法完全不同。本篇先讲渲染器怎么选，再讲分辨率与过滤，最后给一份「先关什么、后关什么」的掉帧排查顺序。

画面选项集中在 **Preferences** 的显示相关几项里。本篇不按界面顺序罗列，而是按「先调哪一项收益最大」来排 —— 多数人卡顿其实只需要动第一项。

## 一、渲染器：先动这一项

**Preferences → Video Renderer**，六个选项，取舍如下：

| 渲染器 | 特点 | 建议 |
| --- | --- | --- |
| Hardware | 快且稳，兼容性最好 | **不确定就先用它** |
| Hardware + Shaders | 在此之上加 FXAA 一类后处理，画面更平滑 | CPU / GPU 较新、追求观感时用 |
| Pete OGL2 / Fast OGL2 | OpenGL HD 渲染，画面最平滑 | 兼容性受限，需要单独配插件 |
| OpenGLPlugin | 同上，走外部插件 | 同上 |
| Software | 纯软件渲染，最兼容但最慢 | **只在很老的机器或 OpenGL 驱动有问题时用**（例如 Adreno 200 那一代） |

一个直观的判据：**画面出现花屏、贴图错位、整块变黑**，第一反应就是换渲染器，而不是去调分辨率。反过来，**画面正常但掉帧**，也别先怀疑渲染器，先看第二节。

## 二、分辨率与过滤：清晰度和流畅度的直接交换

| 选项 | 取值 | 说明 |
| --- | --- | --- |
| Internal Resolution | x1 / x2 | x1 是 PS1 原始分辨率、最准；x2 更平滑，但需要更强的 CPU |
| Video Filtering | 开 / 关 | 硬件渲染下的画面过滤；默认开。想要接近原机的颗粒感就关掉 |
| Video Filtering 2D | 开 / 关 | 专治 2D 游戏画面，会叠加 2xsai 一类滤镜 |
| PSX Dithering | 开 / 关 | 抖动效果，仅在特定模式下有效 |
| Scanline Transparency / Thickness | 开 + 厚度、透明度 | 模拟老电视的扫描线 |
| Plugin Subpixel Precision | 开 / 关 | 提升 3D 精度，但更吃内存和 CPU |

**内部分辨率是单项收益最大的开关**：从 x2 降到 x1，帧数往往直接上一个台阶，代价只是画面没那么锐利。卡顿时第一个该试它。

### 其余几个开关，用到再动

| 开关 | 作用 | 什么时候动 |
| --- | --- | --- |
| 亮度配置（brightness profile） | 提供几档亮度方案 | 游戏本身偏暗、暗部看不清时 |
| Overscan（上下溢出裁剪） | 裁掉画面上下边缘的杂色条 | 个别游戏边缘有杂色时 |
| Blit skip | 恢复旧版本默认的绘制跳过行为 | 特定游戏在默认模式下异常时 |
| 按游戏保存配置（game profile） | 把当前的画面 / 按键 / 音频设置绑定到某一款游戏 | 几个游戏的设置互不通用时 |

最后一项值得单独说：**ePSXe 支持按游戏保存配置档案**，下次进这款游戏会自动套用当时那套设置。你如果玩着好几款游戏、每款都要微调，靠它就不用每次重调 —— 这是这套设置体系里最省事的一环。

## 三、画面比例与黑边

- **Screen ratio** 三选一：`4:3`（PS1 真实比例）、全屏拉伸、宽屏模式。
- **Screen orientation**：横屏、竖屏、反向横屏。
- **Top/bottoms black bands**：PAL 制式游戏的上下黑边可以去掉，画面更大，但**它是靠拉伸实现的，可能弄坏个别游戏**（例如 Alundra 2 的过场动画与读取画面）。画面出问题又找不到原因时，把这一项关回去试试。
- **Screen color depth**：16 / 32 位色。32 位在播放游戏内动画时颜色更好。

## 四、掉帧排查：按这个顺序关

**先确认是不是真的在掉帧。** 打开 **Preferences → Show FPS**，看运行时的数字：部分游戏本身就是 30 帧设计，显示 30 并不等于出问题；PS1 的满速基准是 50 / 60 帧。

确认掉帧了，按下面的顺序动，**一次只改一项**，改完用同一个场景复测：

1. **内部分辨率降到 x1** —— 单项收益最大；
2. **换渲染器** —— Hardware 与 Software 之间来回试一次；
3. **开 CPU frameskip** —— 选项有 `disabled` / `enabled` / `enabled only in high resolution games` 三档，代价是画面帧数变低；
4. **关掉部分音频效果** —— 音频和画面共用算力，减负对两者都有用，取舍见第五节；
5. **MME** 设为 `enabled`（能更快）；**注意不要在支持 NEON 的机型上选 `Force`，会崩**；
6. **HW/SW Threading Mode** —— 1.5 GHz 及以下的 CPU 打开它更快；关掉能提升准确性，是「准确」与「流畅」的交换；
7. **开「持续性能模式」（sustained performance mode）** —— 设置里有这一项，作用是抑制短时过热带来的反复降频，适合一玩就是半小时以上的场景；
8. **调自定义帧率** —— 部分机型（含 Android TV）有这个设置项，可以按屏幕刷新率把帧率上限挪一挪，具体档位以设备上的界面为准；
9. **PSX CPU 超频** —— 能提高一部分游戏的内部帧率，但**需要很强的设备**。中低端机上开了只会更卡，所以它是这里最后才考虑的一项，不是提帧数的主力手段。

**还有一种卡顿不是设置问题**：玩二三十分钟后越来越卡、退出重进又好了，那是机身过热降频。这一条怎么调设置都没用，注意别边充边玩、别戴厚壳。

## 五、声音的取舍：延迟还是流畅

音频缓冲的默认设置是**大缓冲**：帧率更稳、平均速度更好，代价是**声音相对画面有延迟**。设置里另有两档低延迟模式 `low` 与 `very low`，把缓冲压小，延迟降低但更吃 CPU。

怎么选：

- 玩动作、音游、需要听声辨位的游戏 → 试 `low` 或 `very low`，但要有掉帧的心理准备；
- 玩 RPG、策略类，声音延迟不敏感 → 保持默认大缓冲，帧率优先；
- 出现声音重复、断续 → 先看帧率，官方口径是**需要跑到 50 / 60 帧（满速）声音才正常**，这类问题多半是卡顿的附属现象，按第四节处理，详见 [常见问题与排查.md](常见问题与排查.md) 第三节。

## 六、OpenGL HD 渲染插件（想进一步提画质再看）

OpenGL HD 渲染依赖一个**外部的 OpenGL 插件**，它不在安装包里，需要自己另外放到设备上，路径与文件名在官方 `epsxe.com/android/video.html` 上有说明。使用的两个前提：

1. 把插件文件放进设备存储；
2. **Preferences → GPU Plugin** 里选中它，同时把 **Video Renderer 设为 OpenGLPlugin**，两边要配套，只设一边不生效。

关于它值不值得用：**画面通常比软件渲染好，尤其是在 3D 游戏里，但兼容性更差** —— 会出现缺画面、图层错位这类问题，而且往往需要**每个游戏单独调**。它自带一个游戏内工具栏（Toggle GLConfig），里面有帧率限制、离屏绘制、过滤、Alpha 等一批开关可以边玩边调，效果不理想时也能一键存成配置文件。

这一节的选择权留给你：追求画质就用它然后逐个游戏调，追求省心就用 Hardware 渲染。两个都能跑，没有哪个是「正确」答案。

### 插件从哪来，以及几条社群经验

获取插件现在比手动拷文件省事：更新记录里提到可选插件已经以独立 APK 的形式上架应用商店；偏好设置的插件条目里也有一个下载最新插件的按钮。不管用哪种方式，装完都要回到 **GPU Plugin** 里选中它，并把 **Video Renderer** 设成 OpenGLPlugin —— 两边配套才生效。

下面几条来自用户社群的常见做法，**不是官方口径**，效果因机型与游戏而异：

- 把插件的渲染分辨率降到 480p 或 600p，比单纯关帧率限制更直接；
- 关掉 FI（过滤）与 AB（高级混合）；
- 关掉「子像素精度（Subpixel Precision）」；
- 音频延迟用普通档，别为了压低延迟把缓冲压得太小。

**有一处两边口径冲突**，这里摆在明面上：插件的多线程模式，官方文档推荐 `2-threads + effects`，而社群里有相反的说法，认为开了反而更慢。没有统一答案，建议在同一个场景下把两个档位各试一次，以你那台设备的实测为准。

## 七、按设备档次给一套起步设置

| 设备情况 | 建议起步 |
| --- | --- |
| 新机（Android 12 以上、ARMv8） | Hardware 渲染 + x2 分辨率 + 过滤开 |
| 中端机（能跑满但有波动） | Hardware 渲染 + x1 分辨率 + 掉帧时开 frameskip |
| 老机（OpenGL 驱动有问题） | Software 渲染 + x1 + Threading 开 |
| 画面异常（花屏 / 错位） | 先换渲染器，别调分辨率 |
| 安卓电视 / 电视盒子 | Hardware 渲染 + x1；别用 OpenGL HD 那一套，电视上逐游戏调设置更麻烦，单独一篇见 [在安卓电视和电视盒子上怎么玩.md](在安卓电视和电视盒子上怎么玩.md) |

调完手感还是差半拍、按键明明没问题，去 [手柄与触屏按键怎么设.md](手柄与触屏按键怎么设.md) 第八节看两者的关系；游戏本身进不去而不是卡，那是另一类问题，走 [常见问题与排查.md](常见问题与排查.md) 第一、二节。
