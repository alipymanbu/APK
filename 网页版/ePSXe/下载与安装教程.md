ePSXe for Android 是安卓上的索尼 PlayStation（PSX / PSOne）模拟器，由 PC 版 ePSXe 移植而来，手机、平板与安卓电视都能跑。它本身不带游戏，装完还要准备 BIOS 与游戏镜像才能玩起来。这篇只解决两件事：把包装进设备，以及把首次启动必须配的东西配齐。

## 一、网盘里这份包的版本信息

网上能搜到的是官方后来发布的新版，网盘里这份是整理文档时核对过的那一版，两者未必是同一个版本号。凡涉及版本号、包名、体积，以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | ePSXe |
| 版本号 | 2.0.17 |
| 包名 | `com.epsxe.ePSXe` |
| 安装包体积 | 10.55 MB |
| MD5 | `67B711552E6FD4BF2F6E1D54E0736649` |
| 本表核对时间 | 2026-09-23 |

**关于渠道**：这个应用的官方上架渠道是 Google Play，在商店里是付费购买的。网盘里这份是同一个应用的手动安装包，不经过商店 —— 这也是安装时要单独开一次「未知来源」权限的原因。

**关于版本号**：安卓版按 `2.0.x` 递增，官方更新日志里能对上的是 2.0.15 → 2.0.16 → 2.0.17 → 2.0.18 → 2.0.19 这样一条线。其中 2.0.17 官方记为 2024 年 2 月发布（页面上的日期没标全）。**PC 版的那套 2.0.5 / 2.0.18 编号与安卓版不是同一套**，两边版本号数字接近但不通用，别拿 PC 版的更新记录来判断手机上这份是新是旧。想看官方后来加了什么，可以对照 `epsxe.com/android/changelog.html`，但记得那上面写的是更晚的版本，与网盘里这份不是同一版。

## 二、安卓设备要满足什么条件

官方 `epsxe.com/android/features.html` 给的要求分两档：

| 档位 | 要求 |
| --- | --- |
| 最低 | Android 5.0（Lollipop）、ARMv7 或 x86、1.0 GHz、256 MB 内存、支持多点触控或实体键或外接手柄 |
| 推荐 | Android 12–15、ARMv8、1.2 GHz 双核以上、OpenGL 支持良好的 GPU、512 MB 内存、容量充足的存储 |

关于系统要求的**口径不一**要提醒一句：官方页面写的是 Android 5.0，而一些第三方资料里出现过「Android 5.2」甚至「Android 2.3」的说法，这些与官方页面对不上。这里不替你裁决，安装时以系统自己给出的兼容提示为准。

真正决定跑得动跑不动的不是系统版本号，而是芯片的 GPU 与驱动。同一个版本装在不同机型上的表现差别很大，这部分放在 [画面设置与卡顿优化.md](画面设置与卡顿优化.md) 里讲。

如果你打算装在安卓电视或电视盒子上，安装方式与手机不一样（要靠 U 盘拷包，而且必须有外接手柄），单独写在 [在安卓电视和电视盒子上怎么玩.md](在安卓电视和电视盒子上怎么玩.md) 里。

## 三、安装步骤

1. **转存并下载安装包**：从 [ePSXe 安装文件资源（夸克网盘）](https://pan.quark.cn/s/16c23ffc4fd0) 把安装包转存到自己的网盘，再下载到手机或电脑。
2. **把包送到设备上**：手机端直接下载最省事；在电脑上下载的话，用数据线或任意传输方式拷进设备存储即可。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。部分定制系统把这项开关收在「安全」或「隐私」分类下面。
4. **点击安装包完成安装**：系统提示「应用未经过安全检测」属于手动安装的常规提示，继续即可。
5. **想回装低版本要先卸载**：安卓不允许用更低的版本号覆盖更高版本，会直接报「应用未安装」。卸载会不会连存档一起清掉，取决于你首次启动时选的是哪种存储方式，见第四节与 [存档与记忆卡管理.md](存档与记忆卡管理.md)。
6. **装完先别急着进游戏**：先按第四、第五节把文件夹与权限过一遍，否则首屏可能卡在选文件夹上。

## 四、首次启动：先选一个「基准文件夹」

从 2.0.16 起，ePSXe 在 Android 11 及以上改用分区存储（官方叫 scoped storage），**不再全盘扫描存储去找文件**，而是要求你先指定一个「ePSXe base folder」（基准文件夹），它把记忆卡、即时存档、金手指、补丁这些数据都放在这里。首次启动时你会被要求挑一个文件夹，两种选法区别很大：

| 选法 | 数据实际落在哪 | 卸载后 | 手动备份 |
| --- | --- | --- | --- |
| 共享存储 | 你挑的那个文件夹，通常在内部存储根目录（例如自建的 `epsxe`） | 一般会保留 | 用文件管理器就能拷走 |
| 私有存储 | `/storage/emulated/0/Android/data/com.epsxe.ePSXe/files/epsxe/` | 随应用一起被系统删掉 | 普通文件管理器访问不到 |

怎么选：

- **第一次装就用共享存储**：在文件选择器里新建一个文件夹再选中它（官方也是这么建议的）。
- **从旧版本升级上来的**：旧版会在内部存储根目录留一个叫 `epsxe` 的文件夹，直接选它，这样旧的记忆卡、即时存档、BIOS 与游戏目录才能被继续读到。
- **选了私有存储**：能用，但存档拿不出来、卸载即丢，只适合不打算长期留档的人。

路径也可以事后改：**Preferences → Storage preferences → ePSXe base folder**。

## 五、放开「全部文件访问」权限

Android 11 及以上，如果发现 BIOS、存档或游戏明明在设备里却读不到，多数是外部存储权限没给全。按官方给的步骤走一遍：

1. 打开系统「设置」；
2. 搜索 `All files access`（中文系统里通常叫「所有文件访问权限」或「文件和媒体」）；
3. 点右上角三点菜单，选「显示系统应用」；
4. 在列表里找到「外部存储 / External Storage」，点进去；
5. 打开「允许管理所有文件」这一项；
6. 重启 ePSXe。

## 六、装完做一次最小验证

别急着拷游戏，先确认环境是通的：

1. 打开应用，能进主界面，没有停在选文件夹或权限报错上；
2. 进设置随便改一项（例如打开「Show FPS」），退出再进入，设置还在 —— 说明基准文件夹可写；
3. 此时游戏列表里是空的，这是正常的，因为还没有放游戏；
4. 记忆卡与存档文件此时也还没生成，等第一次跑游戏才会出现。

这三步都过，就可以接着准备两样东西了：先看 [PS1的BIOS文件怎么放.md](PS1的BIOS文件怎么放.md)，再看 [游戏镜像格式与存放位置.md](游戏镜像格式与存放位置.md)。顺序别反 —— 没有 BIOS，游戏放进去也进不去。
