这套模拟器的故障集中在这几处：游戏文件本身、BIOS、分区存储权限、图形渲染方式、以及手柄链路。每节开头给出「先做哪一件」，遇到问题直接跳到对应那一节，不要一上来就重装。

## 一、游戏进不去：黑屏、闪退、点了没反应

先分清是**模拟器的问题**还是**这个游戏的问题**：

1. **先点一次 Run bios**。能出索尼开机画面，说明模拟器与 BIOS 都正常，问题在游戏文件上，往下走第二条；
2. **等半分钟再判断**。部分游戏首次加载会黑屏较长时间，急着杀进程反而打断初始化；
3. **换渲染器再进一次**（Hardware 与 Software 之间来回试），换完重启应用，个别机型不重启不生效；
4. **把内部分辨率降到 x1** 再进，个别游戏在特定档位下必然黑屏；
5. **换另一个游戏验证**。别的游戏能跑、只有这一个不行，那就是这个镜像的问题，去拿一份完整的重新放。

官方 FAQ 对黑屏给的口径是：如果用的是硬件渲染器，不兼容的游戏比例非常低（约 1%），**更可能是镜像格式不对、或者文件本身不完整/损坏** —— PS1 游戏通常在 600–700 MB 区间，明显偏小就别再试了。

装了但打开就退到桌面：先卸载再重装一次，直接覆盖安装遗留的旧数据是常见诱因。

## 二、提示找不到 system.cnf，或说镜像不完整

出现 `system.cnf` 找不到的提示，含义很单一：**模拟器在这个镜像里没找到光盘该有的文件系统**。原因就三种 —— 文件不完整、格式不对、或者已损坏。处理顺序：

1. **确认是解压后的镜像**，不是 `.7z` / `.zip` / `.rar` 本身（见第八节）；
2. **确认体积正常**，单碟游戏偏小到几十 MB 的，基本可以判定没下全；
3. **确认格式在支持列表里**，`cue` 与 `bin`、`img` 与 `ccd` 这类要成对出现，少一半就加载不了，格式清单见 [游戏镜像格式与存放位置.md](游戏镜像格式与存放位置.md) 第一节；
4. **换一份完整的镜像**。前面三条都对还是不行，就是对这份镜像本身的判断，换来源重下一份比继续折腾设置更快。

如果连 `Run bios` 都不出画面，那是 BIOS 层面的问题，走第五节。

## 三、声音重复、断续、没声音

- **先看帧率**。官方的说法很明确：ePSXe 用的是同步音频机制，**需要跑到 50 / 60 帧（满速）声音才会正常**。所以「声音重复、卡顿」绝大多数是掉帧的附属现象，按 [画面设置与卡顿优化.md](画面设置与卡顿优化.md) 第四节把帧率提上去，声音通常跟着好转；
- **完全没声音**：先调手机音量与静音开关，再确认应用内音频选项没有被关成静音；
- **只有某个游戏有声音问题**：记录下来单独处理，这类多是该游戏的兼容性问题，不代表模拟器整体坏了；
- **声音比画面慢半拍**：这是音频缓冲的设置取舍，不是故障。降低缓冲能减少延迟但更吃 CPU，取舍方式见 [画面设置与卡顿优化.md](画面设置与卡顿优化.md) 第五节。

## 四、游戏列表是空的，或者扫不到游戏

**Android 11 及以上不会自动扫描**，这是一个高频误解。按顺序检查：

1. **有没有用 `+` 按钮添加文件夹**：点 **Run game**，右上角的 **+** 就是入口，没加过文件夹列表当然是空的，做法见 [游戏镜像格式与存放位置.md](游戏镜像格式与存放位置.md) 第四节；
2. **文件夹选对没有**：选到游戏目录的上一级、或者直接选了存储根目录，都会扫不出东西；
3. **文件是不是真的在本地**：网盘客户端的「在线占位」文件读不到，确认文件属性里显示的是实际占用空间；
4. **是不是放在 `Android/data` 下面**：Android 11 之后部分系统把这块区域对新装应用完全隔离，把游戏挪到自建目录里再试；
5. **存储权限给全没有**：按 [下载与安装教程.md](下载与安装教程.md) 第五节开一次「全部文件访问」，再重启应用；
6. **目录层级别太深**：分区存储下扫深层目录会很慢，看起来像卡住；把游戏集中到层级更浅的文件夹里。

**列表里有名字、点进去打不开**：条目还在但文件已经被删或改名了。重新扫一次；改用 [游戏镜像格式与存放位置.md](游戏镜像格式与存放位置.md) 第五节的做法，长按条目创建桌面快捷方式，之后直接从桌面进。

## 五、BIOS 放了却读不到

1. **确认体积是 512 KB**，明显不是这个数基本可判定文件不完整；
2. **确认路径指定了**：**Preferences → Bios preferences → Bios file** 手动挑一次，尤其当它不在基准文件夹里的时候；
3. **确认文件是解压出来的 `.bin`**，不是压缩包本身；
4. **检查存储权限**：Android 11 及以上，权限没给全时文件在那里也读不到，按 [下载与安装教程.md](下载与安装教程.md) 第五节处理；
5. **看版本**：2.0.17 的更新内容里包含「修复 Android 11+ 分区存储下的若干问题」，手上是更早版本的话先升级再排查。

判断到底通没通，只看一件事：**Run bios 能不能出索尼开机画面**。能出就没问题，剩下的都归游戏文件管。

## 六、手柄连上了但按键没反应

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 所有键都没反应 | 蓝牙配对记录有残留 | 删掉配对记录重新配一次 |
| 只有个别键不灵 | 映射表里那几项是空的 | 回映射页重新指定一次 |
| 有线能用、无线不行 | 问题在蓝牙链路，不在模拟器 | 查电量、距离、是否被别的应用占用 |
| 摇杆用不了 | Pad Type 被自动切成了 Digital | 该游戏可能原本不支持 DualShock，属于正常现象 |
| 蓝牙手柄延迟明显 | 老设备的兼容选项在起作用 | 在设置里关掉 `bluez` 选项 |

完整的手动映射五步、以及各个型号的识别方式，在 [手柄与触屏按键怎么设.md](手柄与触屏按键怎么设.md) 第五、六节。

## 七、画面花屏、贴图错位、只剩一部分画面

**花屏、贴图错位、背景异常**这类问题的归因通常很单一：**渲染方式与你设备的图形驱动不匹配**。

1. 换一个渲染器，用同一款游戏对比效果；
2. 换完**重启一次应用**；
3. 只有个别游戏出问题的，多半是该游戏自身的兼容性问题，换渲染器能缓解就保持现状；
4. 用了 OpenGL HD 渲染插件的，**它的兼容性本身就更差**，缺画面、错位是已知代价；它自带的游戏内工具栏可以逐项开关调整，还不行就退回 Hardware 渲染，取舍见 [画面设置与卡顿优化.md](画面设置与卡顿优化.md) 第六节。

**进游戏黑屏、只出声音**：按第一节的顺序处理。

**画面比例不对、上下有黑边**：这不是故障。PAL 制式游戏的上下黑边可以去，但去掉黑边是靠拉伸实现的，可能弄坏个别游戏，具体见 [画面设置与卡顿优化.md](画面设置与卡顿优化.md) 第三节。

## 八、为什么压缩包不能直接跑

zip、7z、rar 里的游戏**不能直接加进列表运行**。原因是这类格式无法对大文件做随机读取，而 PS1 镜像动辄六七百 MB。处理办法：

- 先在设备上**解压出 cue/bin 或 img/ccd**，再把解压后的文件夹加进模拟器；
- 真需要压缩存放，就转成 **PBP** —— 它是唯一支持随机访问、能被直接运行的压缩形态；
- 不压缩也行，容量足够放下一百多个游戏。

## 九、怎么确认自己装的是哪一版

进应用的设置或关于页面看版本号，与 [下载与安装教程.md](下载与安装教程.md) 第一节表格里的 `2.0.17` 对一下：

- 对不上，说明手上是另一份包，本篇涉及的设置项名称与位置可能与你看到的不完全一致；
- 想核对包名，应是 `com.epsxe.ePSXe`；核对安装包体积，应是 10.55 MB；
- 怀疑安装包不完整、想换一份干净的：从 [ePSXe 安装文件资源（夸克网盘）](https://pan.quark.cn/s/16c23ffc4fd0) 重新转存下载，**装之前先按下一节做一次存档备份**。

## 十、存档读不出来，或者存档丢了

按可能性从高到低查：

1. **基准文件夹位置变了**。换过存储方式、或者改过 **Preferences → Storage preferences → ePSXe base folder**，模拟器就会去新位置找存档，旧的还在旧位置。改回去或把文件搬过来；
2. **卸载重装导致丢失**。如果基准文件夹在私有存储（`Android/data/com.epsxe.ePSXe/files/epsxe/`），卸载会连存档一起被系统删掉，这类丢失无法找回；
3. **被清理工具清掉了**。第三方「深度清理」把基准文件夹当缓存清理，是常见的丢档原因；
4. **Autosave on Exit 写坏了状态文件**。现象是退出后再进游戏提示存档异常，关掉这个选项改用手动存；
5. **跨版本读不了**。低版本读不了高版本写出的新格式即时存档，把两边都升到较新版本再试。

详细的备份方式、记忆卡与即时存档的区别、以及换设备的迁移步骤，都在 [存档与记忆卡管理.md](存档与记忆卡管理.md) —— 那一篇值得在开始玩游戏之前先读一遍，因为记忆卡是所有游戏共用的一个文件，坏一次影响全部。

## 十一、没装 BIOS 也能进游戏？

**没放 BIOS 却能把游戏跑起来**，说明当前用的是内置的 HLE（高层仿真）BIOS 模式，不需要你自己准备固件。它的代价是**兼容性更低、记忆卡支持有限**。相关的三件事：

- **兼容性问题**：某些游戏进不去、画面异常或存档异常。判断方法 —— 补一个真实 BIOS 再跑同一款游戏，问题消失就说明是 HLE 模式的兼容性所致；
- **即时存档不互通**：真实 BIOS 与 HLE BIOS 下的即时存档互相读不了，而且**切换之后旧的读不回来**。要切换模式，先把进度存进游戏内的记忆卡；
- **自动识别的条件**：BIOS 文件要是 `.bin`、且体积恰好 512 KB，才会被自动扫到；不符合就走手动指定。

完整说明见 [PS1的BIOS文件怎么放.md](PS1的BIOS文件怎么放.md) 第七节。

## 十二、联机连不上、玩一会儿两边不同步

这一类的排查顺序是固定的，因为**它的门槛是硬的，不符合就是直接连不上**：

1. **两台设备上是不是同一个游戏** —— 不只是名字一样，区域版本与镜像来源也要一致；
2. **两块设备是不是同一份 BIOS** —— 一边 SCPH1001、另一边 SCPH7502 是常见的失败原因；
3. **是不是同一个路由器** —— 一台连 Wi-Fi、一台连热点就不同网段了；路由器的「AP 隔离」也会挡住互访；
4. **版本差太远** —— 升级到相近版本再试；
5. **进入游戏后不同步** —— 多半是镜像版本不一致，或者过程中用了读档（官方明确说读档支持但不稳定、不推荐）。

开房与加入的完整步骤、以及联机与分屏的区别，见 [两台设备联机对战怎么用.md](两台设备联机对战怎么用.md)。
