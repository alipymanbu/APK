# ePSXe 的游戏镜像：支持哪些格式、该放在哪

> PS1 游戏以光盘镜像的形式交给模拟器，格式不对或放错位置都会「扫不到」。本篇列出 ePSXe 认的格式、为什么压缩包不能直接跑、目录怎么组织，以及怎么让它在 Android 11 及以上把游戏列出来。

游戏文件不随模拟器提供，需要你自己准备。准备到位之后，还要让 ePSXe 找得到它 —— 这一步比格式本身更容易卡住人，尤其是 Android 11 及以上的机器。本篇按「格式 → 组织 → 扫描」三件事讲。

## 一、ePSXe 认哪些格式

官方列出的支持格式如下：

| 格式 | 说明 | 推荐度 |
| --- | --- | --- |
| `cue` / `bin` | 最常见的单轨光盘镜像，一个 cue 配一个 bin | 推荐 |
| `cue` / 多 bin | 音轨分开存放的多文件镜像 | 推荐 |
| `img` / `ccd` | CloneCD 那套，同样是成对文件 | 推荐 |
| `mds` / `mdf` | Alcohol 那套（v1 版本） | 可用 |
| `pbp` | 索尼掌机格式，官方 FAQ 里推荐的压缩方案 | 推荐 |
| `cdi` | 另一种镜像封装 | 可用 |
| `nrg` | Nero 的镜像格式 | 可用 |
| `ecm` | 需要额外处理的一种压缩镜像 | 可用 |
| `chd` | 把整张盘压成单个文件的格式，从 2.0.16 起支持 | 可用，体积更小 |
| `iso` | 裸镜像，没有音轨信息 | 可用，但缺音轨 |

官方在 FAQ 里给的建议是优先用 **bin/cue、img/ccd 或 pbp** 这三种。

## 二、压缩包为什么不能直接跑

这一条是新手最常问的：**zip、7z、rar 里的游戏不能直接添加到列表里跑**。

原因官方说得很直白：这类压缩格式没法给大文件做随机读取，而 PS1 镜像动辄六七百 MB，边解压边读取不现实。所以：

- 拿到 `.7z` / `.zip` / `.rar` 的游戏包，**先在设备上解压出 cue/bin 或 img/ccd**，再把解压后的文件夹加进模拟器；
- 手机上没有解压工具的话，装一个能处理 7z 的即可，ePSXe 自身也带 zip / 7z 的解压工具可用；
- **确实需要压缩存放**，就转成 **PBP** 格式 —— 它是支持随机访问的压缩形态，ePSXe 能直接跑；PBP 还支持把多张碟合进一个文件的大包（更新记录里修过大于 2 GB 的 PBP 支持），多碟游戏用它能把文件数压到最少；
- 不压缩也没关系：现在一张存储卡放下一百多个游戏不成问题。

## 三、文件怎么组织

目录结构直接影响能不能扫到、扫得快不快：

- **一个游戏一个文件夹**，文件夹名用游戏名，方便在列表里认。
- **成对文件要同名**：`cue` 与 `bin`、`img` 与 `ccd`、`mds` 与 `mdf` 是配套的，改名必须一起改；只改其中一个，模拟器就找不到另一半。
- **多碟游戏分开放**：每张碟各占自己的文件，游戏过程中在菜单里换碟，不用退出重开。
- **体积可以作为判据**：PS1 游戏通常在 600–700 MB 区间（单碟）。明显偏小（比如几十 MB）的多半是没下全、或者解压不完整，这种文件往往一启动就报错，见 [常见问题与排查.md](常见问题与排查.md) 第二节。
- **别放在 `Android/data` 下面**：Android 11 之后部分系统把这一块对新装应用完全隔离，放这里的游戏经常扫不到。

## 四、让 ePSXe 扫到游戏

**Android 11 及以上**（分区存储生效后，模拟器不再全盘扫描）：

1. 打开 ePSXe，点 **Run game**；
2. 界面右上角会出现一个 **+** 按钮，点它，然后选你存放游戏的文件夹；
3. 选中的文件夹**连同它往下最多 5 层子文件夹**都会被扫描；一共最多可以添加 16 个文件夹；
4. 扫完，游戏会以列表形式出现，点条目即可启动。

两条经验：**目录越平越好**，分区存储下扫一个层级很深的目录会明显变慢；**别把整个存储卡根目录加进去**，那是扫描最慢的一种加法。

**Android 10 及以下**：没有这层限制，ePSXe 会自动扫描存储并列出找到的游戏；扫不到时可以在偏好设置里指定游戏目录。

## 五、游戏列表与封面

扫到游戏之后，ePSXe 会维护一份游戏列表（Gamelist）：

- **封面与信息是从网络下载的**，需要联网；不联网时列表照样能用，只是没有封面。
- **长按列表里的某个条目**，可以把它创建成桌面快捷方式，之后直接从桌面图标启动这个游戏，不用每次先进模拟器。
- 列表里的条目来自扫描结果，所以**删掉或移动了游戏文件，记得重新扫一次**，否则会留下打不开的条目。

## 六、多碟游戏怎么换碟

支持多碟的游戏在游戏过程中提供了换碟选项，位置在游戏内呼出的菜单里，不需要退出重开，也不需要重启模拟器。存档的时机建议放在换碟提示出现、系统让你保存的那一刻，具体管理方式见 [存档与记忆卡管理.md](存档与记忆卡管理.md)。

三件事值得提前知道：

1. **换碟前先存一次档**。换碟是少数几个会打断运行状态的操作，先落到记忆卡上比只靠即时存档稳。
2. **多碟游戏的记忆卡有专门的处理模式**，可以让同一款游戏的不同碟共用同一张卡，不必手动换卡，说明见 [存档与记忆卡管理.md](存档与记忆卡管理.md) 第六节。
3. **个别游戏的换碟历史上出过问题，并且已经在更新里修掉**。官方更新记录里能对上的例子：Metal Gear Solid 的 VR 任务换碟在 2.0.17 修复，另有若干游戏在 2.0.18 修复。网盘里这份是 2.0.17，**已经包含前面那一处修复**。所以你在某个游戏的换碟环节卡住时，先确认自己装的是哪一版，不要一上来就怀疑镜像坏了。

## 七、看到这些附加项不用奇怪

ePSXe 还带几项和游戏文件相关的支持，用到时知道它们在就行：

- **子通道文件（sub / sbi）**：个别游戏依赖它才能正常过场，放在游戏同目录即可。
- **PPF 补丁**：用于给镜像打翻译补丁，支持在游戏运行时按需应用。
- **Libcrypt 支持**：处理一部分带防盗版校验的原版镜像。
- **内置 zip / 7z 解压**：不用另外装工具也能解开一部分压缩包。

## 八、扫不到游戏时的最短排查路径

按顺序试，别一上来就重装：

1. 确认文件是**解压后**的镜像，而不是 `.7z` / `.zip` 本身；
2. 确认文件夹已经通过 **+** 按钮加进了扫描列表（Android 11 及以上不会自动扫）；
3. 确认存储权限已给全，方法见 [下载与安装教程.md](下载与安装教程.md) 第五节；
4. 确认文件不是网盘客户端的「在线占位」文件 —— 属性里要显示实际占用空间才算真在本地；
5. 以上都对还是空的，换一个目录层级更浅的文件夹再试一次。

仍然扫不到，去 [常见问题与排查.md](常见问题与排查.md) 第四节，那一节按「列表为空」「列表有名字但打不开」分了两种走法。
