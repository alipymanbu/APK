# Animeko 电脑版怎么装和要注意什么

> 桌面端拿到的不是手机那份 APK，三个系统各是另一种包、各自的依赖也不同；这一篇把电脑上装机与启动时会碰到的坑一次讲完。

电脑上装 Animeko，和手机上完全是两条路：官网给桌面端准备的是三种不同的文件，其中 Linux 还要先补依赖。这一篇按系统把步骤和已知问题列清楚，避免在「装完打不开」上耗时间。

## 一、先去官网取对包

官网下载页（`https://animeko.org/downloads`）按系统给出不同的文件：

| 系统 | 拿到的是什么 | 备注 |
| --- | --- | --- |
| Windows | 一个 zip 压缩包 | 解压后运行其中的可执行文件 |
| macOS | 一个安装镜像 | 按系统提示拖入应用目录 |
| Linux | 一个 AppImage 文件 | 需要先补依赖，见下节 |

**Windows 有一条硬性提醒**：解压目录**不要带中文、尽量不要有空格**。带中文的路径是官方点名会导致启动异常的原因之一，换成纯英文目录再试一次往往就好了。

## 二、Windows：字体与背景颜色渲染异常

这是官方 wiki 专门记录的一条：表现为**界面字体和背景色明显不对**。原因是 Windows 双显卡 —— 常见于同时有集成显卡和独立显卡的笔记本，程序跑在了不该跑的那块显卡上。

处理办法：

1. 打开 Windows 设置，依次进入 **系统 → 显示 → 显卡设置**；
2. 在「桌面应用」里点 **浏览**，找到 `Animeko.exe` 加进来；
3. 选中 `Animeko.exe`，把选项改成 **集成显卡（省电）**，保存；
4. 重新打开 Animeko。

## 三、macOS：提示打不开怎么放行

macOS 会拦下没有经过商店分发的应用，提示类似「未打开」。官方给的两条路任选一条：

**方案一（命令行）**：

```bash
sudo xattr -d com.apple.quarantine /Applications/Ani.app
```

执行后输入锁屏密码，再重新打开。

**方案二（图形界面）**：打开 **系统设置 → 隐私与安全**，在安全性一栏点 **仍要打开**，再输入锁屏密码。

## 四、Linux：先装依赖再启动

Linux 上播放依赖系统里的 VLC，登录跳转依赖 gvfs，缺了会出现「能开界面但播不了」或「登录打不开浏览器」。按发行版执行：

**Arch Linux**

```bash
sudo pacman -S --needed vlc
```

另外按 Arch Wiki 的说明补上 GVFS。

**Ubuntu**

```bash
sudo apt-get install mesa-utils vlc gvfs-libs
```

注意：**VLC 用 Snappy 装可能不起作用，建议走 apt**。

**Fedora**

```bash
sudo dnf install vlc gvfs
```

Fedora 上如果启动后闪退，官方给出的绕过办法是启动时指定 sqlite 库：

```bash
LD_PRELOAD=/usr/lib64/libsqlite3.so.0 ./ani
```

（路径按你机器上实际的 sqlite 位置替换。）

启动前先加可执行权限：

```bash
chmod a+x ./ani
./ani
```

## 五、桌面端独有的几点

- **可以最小化到系统托盘**，关窗口不等于退出程序；
- **Linux 上播放时会阻止屏幕保护与自动锁屏**（通过 D-Bus），看长片不会被锁屏打断；
- **第一次播在线源同样要等一会儿**，桌面端不存在「秒开」，原因与手机端一样，见 [播放源怎么选与卡顿排查.md](播放源怎么选与卡顿排查.md)；
- **账号进度与收藏靠登录同步**，桌面端和手机端是两个各自安装的客户端，数据不会自动互通，见 [注册登录与Bangumi账号同步.md](注册登录与Bangumi账号同步.md)。

## 六、装完的验证方式

和手机端一致：搜一部常见番，进详情页点播放，能出画面就说明依赖齐全。若卡在某一步：

- 界面能开但播不了 → 多半是缺 VLC 依赖（Linux）；
- 字体背景异常 → 回到本文第二节；
- 打开就被系统拦下 → 回到本文第三节；
- 其余情况 → 见 [常见问题与排查.md](常见问题与排查.md)。
