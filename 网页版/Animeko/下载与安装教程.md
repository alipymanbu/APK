Animeko 是手机、平板和电脑上的弹幕追番应用，它自己不存放视频，只把番剧资料、放送日程和多个可播的数据源聚合到一个客户端里。本篇解决两件事：网盘里这份包到底是哪一版，以及怎么把它顺利装进你的安卓设备。

## 一、先核对网盘里这份包是哪一版

各下载站标的版本号是他们自己的登记，和网盘里这份常常对不上。本文出现的版本、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Animeko |
| 版本号 | 6.0.0 |
| 包名 | `me.him188.ani` |
| 安装包体积 | 61.60 MB |
| MD5 | `d3aef38a9264a0f0482f07e86f0ccd56` |
| 形态 | 安卓 APK |
| 本文核对时间 | 2026-09-22 |

判断是不是同一个包，看**包名 + MD5**，不要看名字旁边的版本数字。另外几点容易混：

- **Animeko 曾用名 Ani，官方现在也简称 Ani**，所以在别的页面它可能以 Ani 出现，包名 `me.him188.ani` 对得上就是同一个应用。
- 网上搜到的多是官方最新版，与网盘里这份并非同一版；两者版本号不同是正常的，本文只认上表。
- **收费情况**：应用本身是开源项目（AGPL-3.0 许可），官方页面与更新日志里都没有订阅、内购或会员这类付费项；若官方后续调整，以官网页面为准。

## 二、安卓：装网盘里这份 APK

1. **先转存再下载**。打开 [Animeko 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f581b37ef550)，把 APK 转存到你自己的网盘再下载到手机。转存别省：分享链接失效后，只有转过存的那份还在。
2. **允许安装未知来源应用**。在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，允许你要用来打开安装包的那个应用（文件管理器、浏览器或网盘客户端），再点 APK 安装。
3. **提示「应用未安装」就先卸载旧版**。手机里若已有同包名但签名不同的版本，覆盖安装会直接失败，先卸掉再装。
4. **包名相同，两个版本无法共存**。装着旧版再装这份，旧版会被覆盖，收藏与缓存是否保留取决于应用自身处理，想留旧版就别装。

如果这份包在你的机型上装不上，也可以到官网下载页（`https://animeko.org/downloads`）对照架构重新取一份：官网把安卓包按 `universal`、`arm64-v8a`、`armeabi-v7a`、`x86_64` 分开提供，不确定自己是什么架构就选 `universal`。

## 三、电脑和 iPhone 的装法不一样

**网盘里这份是安卓 APK，电脑与 iPhone 都用不了。** 这两条路的步骤都不少，各自单独成篇：

- 电脑（Windows / macOS / Linux）要用官网按系统提供的包，Linux 还得先补依赖 —— 见 [电脑版怎么装和要注意什么.md](电脑版怎么装和要注意什么.md)；
- iPhone / iPad 要下载官方 IPA 再用侧载工具安装，且有 7 天签名这类限制 —— 见 [iPhone和iPad怎么装.md](iPhone和iPad怎么装.md)。

## 四、第一次打开先做三件事

1. **确认数据源可用**。应用内置了默认的 BT 源与在线源，首次打开若提示选择数据源，把两类都打开，搜索时覆盖面更全。想加自己的源，见 [播放源怎么选与卡顿排查.md](播放源怎么选与卡顿排查.md)。
2. **决定要不要现在登录**。不登录也能看大部分内容，区别是收藏与进度只留在本机。打算长期用、或不止一台设备，就趁现在绑定 Bangumi，见 [注册登录与Bangumi账号同步.md](注册登录与Bangumi账号同步.md)。
3. **挑一部常见番走一遍流程**。搜索 → 进详情页 → 播放，能出画面就说明装好了。

## 五、装完做一次最小验证

用一部常见番走一遍「搜索 → 详情页 → 播放」，卡在哪一步就按现象分头处理：

- 搜不出任何内容 → 见 [搜索找番与放送日程怎么看.md](搜索找番与放送日程怎么看.md)；
- 能搜到但一直转圈、或播几秒就停 → 见 [播放源怎么选与卡顿排查.md](播放源怎么选与卡顿排查.md)；
- 装不上、提示解析包错误、装上就闪退 → 见 [常见问题与排查.md](常见问题与排查.md)。
