Animeko 是开源项目，装不上、被误报、某个源突然失效这几类问题，多数不是「软件坏了」，而是环境或源的问题。下面按现象归类，每条给出判断依据和动作。

## 一、装不上

| 现象 | 大概率原因 | 动作 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完或下坏了 | 重新从 [Animeko 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f581b37ef550) 取包，转存后再下载 |
| 提示「应用未安装」 | 同包名但签名不同 | 先卸载旧的再装 |
| 点了没反应 | 没开「安装未知应用」权限 | 在系统设置里给文件管理器 / 浏览器开权限 |
| 装了但打不开 | 系统版本过老或架构不匹配 | 换官网对应架构的包；系统太老可能确实不支持 |

判断手里的包是不是网盘里那一份，看包名 `me.him188.ani` 与 MD5，细节见 [下载与安装教程.md](下载与安装教程.md)。

## 二、打开就闪退或白屏

- **桌面端白屏 / 启动异常**：Windows 上解压目录带中文或空格可能导致启动异常，换一个纯英文、无空格的目录再解压，细节见 [电脑版怎么装和要注意什么.md](电脑版怎么装和要注意什么.md)；
- **Windows 字体与背景颜色明显不对**：这是双显卡笔记本上跑错显卡导致的已知显示问题，要在显卡设置里把它指到集成显卡，步骤见 [电脑版怎么装和要注意什么.md](电脑版怎么装和要注意什么.md)；
- **macOS 提示打不开**：不是包坏了，按官方给的放行方式处理即可（命令行去隔离属性，或在隐私与安全里点「仍要打开」），见 [电脑版怎么装和要注意什么.md](电脑版怎么装和要注意什么.md)；
- **iPhone 上首次打开提示「不受信任的开发者」**：侧载应用的正常提示，去 `设置 → 通用 → VPN 与设备管理` 里信任你的 Apple ID，见 [iPhone和iPad怎么装.md](iPhone和iPad怎么装.md)；
- **手机上打开就退**：先确认系统版本不太老；仍不行就换官网对应架构的包重新装。

## 三、杀毒软件报毒或拦截

**开源软件通常没有商业数字签名证书，被拦是常见现象，不等于包有问题。** 判断依据是包名与 MD5 和官方发布的一致。处理办法是在杀毒软件里把 Animeko 加入信任列表；如果拦得厉害，也可以改用官网提供的包。

## 四、在线源用不了 / 出现白框

官方 FAQ 对这类现象给的方向是：**更新到较新的版本**（旧版在处理在线源时有过白框、加载失败的问题）。其余播放类问题的排查见 [播放源怎么选与卡顿排查.md](播放源怎么选与卡顿排查.md)。

## 五、登录和注册问题

- 跳转注册 / 登录显示「已停止访问该网页」→ 是内置浏览器的问题，换第三方浏览器并设为默认；
- 注册提示「账户激活服务不可用」→ 激活码输完后删掉最后几个字符，再重新手动输入。

完整说明见 [注册登录与Bangumi账号同步.md](注册登录与Bangumi账号同步.md)。

## 六、反馈问题前先做两件事

官方明确要求：**反馈前先把 Animeko 更新到最新版**，否则不予解答；**报 Bug 时附上日志** —— 日志在「设置 → 关于 → 分享日志」里导出。

把「现象 + 复现步骤 + 日志」一起提交，比只说「播不了」有用得多。反馈渠道是项目的 GitHub Issues。

## 七、升级与数据安全

升级一般只影响应用本身，但**缓存可能因引擎变化失效**（v5.3.1 明确提示过），升级前先看 [离线缓存与没网时怎么看.md](离线缓存与没网时怎么看.md)。设置支持导入 / 导出，换设备或重装前先导出一份，能省很多重配的时间。
