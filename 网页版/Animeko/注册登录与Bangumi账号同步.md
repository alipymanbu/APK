Animeko 用的就是 Bangumi 账号，它没有自己独立的一套注册体系。这一篇讲清两者各管什么、不登录会少什么，以及从注册到登录常见的那几个卡点。

## 一、先弄清 Animeko 与 Bangumi 各管什么

Bangumi 是一个 ACG 资料与收藏交流站点，由 Sai 在桂林发起，负责条目资料、评分和追番进度。Animeko 靠它来完成进度管理与收藏同步，但**播放这件事和 Bangumi 无关** —— Bangumi 不提供任何播放功能。

两者的分工可以这样看：

| 你要做的事 | 由谁提供 |
| --- | --- |
| 番剧条目、简介、评分、标签 | Bangumi（在 Animeko 内直接浏览） |
| 想看 / 在看 / 看过 的收藏状态 | Bangumi 账号 |
| 观看进度、跨设备续播 | Bangumi 账号 |
| 找可播放的源、播放、弹幕、缓存 | Animeko 自身 |

## 二、不登录能用多少

不登录（游客状态）也能搜索、浏览条目、播放和缓存，大部分功能不受影响。少掉的只有一样：**收藏与观看进度不跟着账号走。**

| | 游客 | 已登录 |
| --- | --- | --- |
| 搜索、播放、缓存 | 可用 | 可用 |
| 收藏（想看/在看/看过） | 只存本机 | 同步到 Bangumi |
| 换设备 / 重装后恢复进度 | 不能 | 能 |
| 发送弹幕 | 需要账号绑定 | 用 Bangumi 用户名绑定 |

打算长期追番、或用不止一台设备，建议先登录；只是临时看看，游客状态也够。

## 三、注册 Bangumi 与激活卡点

注册入口在 Bangumi 官网（`https://bangumi.tv`）。要点只有一个：**用一个能正常接收邮件的邮箱**，否则收不到激活邮件。

官方 FAQ 记录了一个已知问题：**注册时提示「账户激活服务不可用」**。处理办法是在输入完激活码后，手动删掉最后几个字符，再重新手动输入一遍。

## 四、登录时跳转显示「已停止访问该网页」

这是官方 FAQ 里点名的情况：登录 / 注册要跳到 Bangumi 网页，而这个跳转发生在**应用内置浏览器**里，内置浏览器容易被目标站拦下。

处理办法：

1. 手机里装一个第三方浏览器（如 Chrome、Via、Firefox）；
2. 在系统设置里把它设为**默认浏览器**；
3. 回到 Animeko 重新发起登录。

登录态是有有效期的。**登录过期时 Animeko 会提示重新登录**，按提示再走一次授权即可，不用重装或清数据。

**桌面端**还有一个便利点：登录页的验证码加载不出来时，可以在该页面直接刷新重试，不必退出整个流程。

## 五、进度是怎么同步的

- **自动更新进度**：一集看完，观看进度会写回账号，不需要手动标记集数。
- **跨设备续播**：换设备或重装后登录同一个账号，收藏列表和「上次看到哪」会回来。
- **手动改状态**：想看 / 在看 / 看过 这类状态随时可以自己改，改完同样同步。

同步的前提是网络能连上 Bangumi。完全断网看缓存时，进度会先留在本机，等有网再对上，见 [离线缓存与没网时怎么看.md](离线缓存与没网时怎么看.md)。

## 六、换设备或重装怎么恢复

1. 新设备上装好 Animeko，进登录入口，用**同一个 Bangumi 账号**登录；
2. 等收藏列表刷出来，确认「在看」里有你原来的番；
3. 打开其中一部，看进度是不是接着上次的地方。

有两点不会跟着账号走：**缓存**是本机文件，换设备要重新缓存；**数据源设置**也是本机配置，换设备后可能要重新配。后者见 [播放源怎么选与卡顿排查.md](播放源怎么选与卡顿排查.md)。
