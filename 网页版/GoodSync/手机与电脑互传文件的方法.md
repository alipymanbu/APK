# GoodSync 手机与电脑互传文件的方法

> 本篇讲怎么让手机和电脑互相看到对方并传文件：两端登录同一个 GoodSync Connect 账号、手机端把服务开起来、电脑端找到手机。

## 一、前提：两端登录同一个账号

手机和电脑之间的连接靠 GoodSync Connect 账号（就是[安装时](下载与安装教程.md)登录的那个）：

- **手机端**：打开 GoodSync，用账号登录。
- **电脑端**：装好 GoodSync（Windows 或 macOS，免费版即可），安装过程中或从菜单 **Tools → GoodSync Connect Setup** 登录同一个账号。

两端的账号邮箱、密码必须完全一致，否则互相找不到。

## 二、手机端：把服务开起来

1. 切到底部的 **Server** 标签页。
2. 顶部能看到你的 UserID 和设备名（Server Name），名字右边的铅笔图标可以改设备名。
3. 点底部蓝色 **Start** 按钮。
4. 屏幕中间出现 **Now you can connect to this device from your desktop computer using GoodSync** 就说明服务已经跑起来了。

## 三、电脑端：找到这台手机

1. 在电脑端 GoodSync 里点 **Browse**（浏览）。
2. 进入 **GoodSync Connect**，点 **Servers** 按钮。
3. 列表里会出现你账号下的所有设备，找到刚才设了名字的那台手机。

## 四、互传文件

连上之后两条路都能走：

| 方向 | 在哪操作 | 能做什么 |
| --- | --- | --- |
| 电脑 → 手机 | 电脑端 Browse 里浏览手机文件夹 | 下载、上传、重命名、删除、复制文件和文件夹 |
| 手机 → 电脑 | 手机端 **Explorer** 标签页 | 浏览电脑上的文件，上传/下载 |

手机端 Explorer 里常用的几个操作：右下角 **[+]** 按钮添加要访问的账号或设备；右上角三点菜单里有搜索、显示隐藏文件等选项；点某个文件右侧的三点是 Download（下载）、Open with（打开方式）、Rename、Delete、Copy、Cut、Info；长按文件可多选后批量删除、剪切、复制。

## 五、流量走的是哪条路

这一点直接决定会不会烧手机流量：

| 情况 | 实际走向 |
| --- | --- |
| 电脑和手机连同一个 WiFi/路由器 | 文件全走本地局域网，不经过任何外部服务器 |
| 不在同一局域网 | 服务先帮你把两端「找到」，传输仍走点对点；手机若在蜂窝网络下，流量按你的套餐计费 |

所以日常备份手机照片时，让手机连家里 WiFi 再开 Server，蜂窝流量一分都不会花。

再补一句直连失败的兜底：路由器隔离、防火墙或 VPN 把两端挡住时，GoodSync 会自动改走官方中转服务转发加密流量——文件不经过中转落盘，但速度通常比直连慢一截；看到传输变慢而两端确实不在同一网段，多半就是走了中转。

## 六、连不上时按这个顺序查

1. 两端是不是登录了**同一个**账号（最常见的原因）。
2. 手机端 Server 是不是还在跑——锁屏久了被系统杀掉的话，回 Server 标签页再点一次 Start。
3. 两端是不是在同一个网络里（或至少手机不是蜂窝数据）。
4. 电池优化有没有放开，见[下载与安装教程](下载与安装教程.md)第五节。
5. 还不行就看日志：手机端右上角三点菜单里有 **Show an activity log**，能直接看到服务有没有在响应连接。

更细的排查条目在[常见问题解答](常见问题解答.md)；连上之后想自动备份照片，直接看[备份手机照片到电脑的步骤](备份手机照片到电脑的步骤.md)。实在懒得折腾网络，还有一条 USB 数据线直连的路，见[用USB数据线直连备份的方法](用USB数据线直连备份的方法.md)。
