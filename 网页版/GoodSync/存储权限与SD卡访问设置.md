## 一、Local 标签页是授权入口

打开 GoodSync 底部的 **Local** 标签页，这里列出手机上所有可用的存储分区（内部存储、SD 卡、USB 外接设备）。点其中任何一个，要么直接进入浏览，要么弹出授权请求。没授权的分区，电脑端连过来是看不到里面文件的。

## 二、Android 11 及以上：所有文件访问权限

从 Android 11 开始，内部存储、SD 卡、USB 设备的访问统一走 **All files access**（管理所有文件）这一项权限。安装或首次启动时如果跳过了，可以手动补：

1. 系统设置里搜「所有文件访问权限」（各品牌叫法略有差异）。
2. 在应用列表里找到 GoodSync。
3. 打开「允许管理所有文件」。

## 三、Android 10 及以下：指定可写文件夹

旧版 Android 没有上面那项总开关，改用「挑文件夹授权」：

1. 打开 GoodSync，进 **Local** 标签页。
2. 点菜单图标，选 **Pick writable folder**（选择可写文件夹）。
3. 选中你想开放的文件夹。

之后这个文件夹会以类似 `SDCard_A5` 的名字出现在可访问列表里，电脑端看到的就是它。需要开放多个目录就重复操作几次。

## 四、SD 卡相关的两个实际问题

- **多张 SD 卡**：可以同时授权访问，多张卡的分区都会出现在 Local 列表里。
- **卡找不到**：个别手机的 SD 卡挂载方式特殊，分区列表里看不到时，试试第五节的 Root 文件系统模式，从根目录把卡找出来。

## 五、想看完整文件系统（Root FS）

出于防误删的考虑，GoodSync 默认把系统根目录藏起来。想看到手机从根开始的整个文件系统：

1. 长按或点右上角菜单进入 **Preferences**（偏好设置）。
2. 打开 **Browsing Root FS** 这一项。
3. 回到 Local 标签页，列表里会多出一个 Root FS 分区。

要知道的几点：部分系统目录仍然进不去，部分文件操作不受支持；这个模式并不比刷机获取的权限更多，只是把能看的都摆出来给你看。日常备份照片用不到它，主要是排查「文件明明在卡上却看不到」这类问题时才开。

## 六、后台常驻通知是怎么回事

安卓端平时没有任何后台活动；只有你在 Server 标签页把服务开起来、正在给电脑提供文件时，才有后台进程。系统会因此挂一条**不可划掉**的常驻通知——这是「服务正在运行」的标志，不是异常。不想让它跑，就到 Server 标签页把服务停掉，通知随之消失。

锁屏后被系统杀服务、电脑连不上这类问题，多数是电池优化没放开，见[下载与安装教程](下载与安装教程.md)第五节；更完整的排查清单在[常见问题解答](常见问题解答.md)。
