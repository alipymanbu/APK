# GoodSync 用 USB 数据线直连电脑备份的方法

> 不想注册账号、或手机和电脑始终连不上时，可以用 USB 数据线把手机连到电脑，以 MTP 方式直接备份。本篇讲这条路怎么走、有哪些实测会碰到的限制。

## 一、两条路怎么选

| | GoodSync Connect（WiFi） | USB 直连（MTP） |
| --- | --- | --- |
| 需要账号 | 两端登录同一个账号 | 不需要 |
| 靠什么连 | 同一局域网（或互联网） | 一根数据线 |
| 手机端要做什么 | Server 标签页开着服务 | 什么都不用开 |
| 适合 | 定期自动备份照片 | 临时导一批文件、设备登录不了账号 |

两条路里，Connect 方式的设置见[手机与电脑互传文件的方法](手机与电脑互传文件的方法.md)；本篇讲 USB 这条。

## 二、连接与备份步骤

以下都在电脑端 GoodSync 里操作：

1. 用数据线把手机连到电脑，手机上把「USB 用途」选成**传输文件（MTP）**（部分手机默认只充电，要手动改）。
2. 新建或打开任务，点左侧或右侧的浏览按钮。
3. 在文件系统列表里选 **Media Devices (MTP)**。
4. 点 **Local Media**，下拉列表里会出现你的手机，点选它。
5. 进到要备份的文件夹（相册一般在 `DCIM/Camera`），另一侧选电脑上的存放目录。

之后 **Analyze → Sync** 的流程、以及勾 **No _gsdata_ folder here** 的注意事项，和 WiFi 方式完全一样，见[备份手机照片到电脑的步骤](备份手机照片到电脑的步骤.md)。

## 三、实测会碰到的两个限制

- **识别要等**：插上线后，电脑端可能要 1~5 分钟才认出手机，机型和电脑各不相同，不是卡住了。
- **锁屏会暂停**：手机锁屏期间电脑端连不上；同步中途锁屏超时，同步会停住，解锁后继续。跑大批量照片前，先把手机的亮屏时长调长一点，或同步期间保持亮屏。

## 四、什么情况下别用它

给十几 GB 的相册做首次全量备份，插着线等识别、还要保持亮屏，整个过程比较熬人；有条件连同一个 WiFi 的话，优先用 Connect 方式跑首备，USB 直连留着做偶尔的应急导出。
