# GoodSync 的 `_gsdata_` 状态文件夹是什么

> 本篇讲备份/同步目录里那个隐藏的 `_gsdata_` 文件夹：里面装了什么、为什么越长越大、怎么不让它写进手机、整删了会怎样。

## 一、它从哪来、干什么用

你在电脑端跑过一次备份或同步任务后，任务两侧的文件夹里会各多出一个隐藏的 `_gsdata_` 文件夹。里面记着两侧文件上次对比的结果——下次跑任务时，GoodSync 靠它判断哪些文件变了，只处理变化的部分。删掉它，下一次就得把所有文件从头重新对比一遍。

## 二、里面装的是什么

| 内容 | 作用 |
| --- | --- |
| `_file_state._gs` | 状态文件：记录哪些文件已经同步过、两侧差异如何 |
| `*.log` | 涉及这个文件夹的任务运行日志 |
| `_saved_` | 被删除或被覆盖文件的**上一版**（默认开启，默认保留 30 天） |
| `_history_` | 被删除或被覆盖文件的**多个历史版本**（默认关闭；与 `_saved_` 那个选项互斥，不能同时开） |
| `_insync.gsl` 等 | 小型技术文件 |

## 三、为什么它会越长越大

只要「保存被删除/替换文件」的选项开着（默认开），每次任务删掉、覆盖掉的文件都会被塞进 `_saved_` 或 `_history_`。备份相册这类目录时，被覆盖的照片攒多了，文件夹自然就大。

收缩的办法：在电脑端打开任务，进 **Job Options → Recycle/History**，关掉不需要的「保存被删除/替换文件」选项；之后可以安全地清空 `_saved_` 和 `_history_` 的**内容**。状态文件别动。

## 四、不想让它出现在手机目录里

把状态挪到电脑上存：在任务里选中指向手机的那一侧，**Folder Options** 里勾上 **No _gsdata_ folder here**。之后状态会改写到电脑上你的用户目录里（Windows 上通常在 `C:\Users\你的用户名\AppData\Local\GoodSync\_mirror_`），手机目录保持干净。勾选的具体步骤见[备份手机照片到电脑的步骤](备份手机照片到电脑的步骤.md)第四节。

## 五、整个删掉行不行

行，但要想清楚后果：删掉 `_gsdata_` 等于把该文件夹的同步历史清零，下次任务会把所有文件当成新文件重新对比一遍。官方给的稳妥重置流程：

1. 停掉所有用到这个文件夹的任务；
2. 把任务**两侧**的 `_gsdata_` 都删掉；
3. 先跑 **Analyze**，再恢复同步。

GoodSync 下次运行时会自动重建这个文件夹。日常想腾空间，只需要按第三节清 `_saved_`/`_history_`，不必整删。

还有一个容易忽略的点：`_gsdata_` 是隐藏文件夹，在电脑文件管理器里看不到它是正常的，要打开「显示隐藏文件」才可见。
