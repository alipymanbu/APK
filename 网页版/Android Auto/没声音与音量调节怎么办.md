# Android Auto 没声音与音量调节怎么办

> 车上喇叭不响、导航不播报、音乐断断续续：按「车机 — 手机 — 应用 — 连接」四层逐层定位，每一层给可执行的检查项。

## 一、先分清是哪种「没声音」

声音链路上任何一环断了，表现都是「没声」，但修法完全不同，先对号入座：

| 现象 | 大概率出在哪一层 |
| --- | --- |
| 只有导航播报没声，音乐正常 | 车机的「导航 / 语音」音量频道被调低或静音 |
| 音乐、导航全没声，但收音机有声 | 音源没切到 Android Auto，或应用内设置静音 |
| 所有声（含收音机）都没声 | 车机音响本身的问题，与 Android Auto 无关 |
| 有声但断断续续、几秒一卡 | 连接层：线缆、无线信号干扰 |
| 显示在播放就是不出声（重插线、颠簸后出现） | 典型的应用 / 连接状态卡住，重启两端解决 |

动手前停车操作，别边开边调菜单。

## 二、车机侧：音量是分频道的

这是最容易被忽略、也最高发的一层。**很多车把音量拆成「多媒体 / 导航 / 语音」三条独立通道**，你用方向盘音量键调的往往只是多媒体那条——导航播报单独静音时，你怎么调总音量它都不响。

1. 进车机的音频设置菜单，找 `声音 / Voice / 音量 / 音频` 这类条目。
2. 看有没有「导航」「语音」「Android Auto」独立音量，逐条确认不为 0、没开静音。
3. 确认**音源**没停在收音机或 AUX：投射工作时音源若不对，Android Auto 会出奇地安静。切到正确音源（部分车叫 Media / USB / 手机）。
4. 快速排除法：放一段收音机或本地音乐。收音机也没声 = 车辆音响故障，去查车；只有投射没声 = 继续往下。

## 三、手机侧：三个开关

1. **媒体音量**：用音量键把「媒体」通道推上去（注意不是铃声音量），`设置 → 声音与振动` 里能看到各通道滑块。
2. **勿扰 / 飞行模式 / 驾驶模式**：三者任一开启都可能压掉通知与播报音，用前关掉。
3. **手机锁屏前看一眼**：部分机型深度省电或清理后台会把投射音频挂起，锁屏后没声时先解锁再试一次。

## 四、应用侧：逐个查声音设置

只在某个应用里没声时，直接进那个应用的设置：

- **Google Maps**：`设置 → 导航设置 → 声音`——这里有个「语音指导音量」，还有「仅警报」「静音」两个档位，误选后导航就永远不说话。改回正常音量并确认不是静音档。
- **Spotify / YouTube Music 等音乐应用**：看应用内的音质与播放设置；音质设为「自动」时，信号差会自动降码率，弱网下车载播放容易出现卡顿暂停，可手动固定较高音质。
- **系统音效**：手机上的杜比全景声、系统均衡器等音效处理偶尔会和投射输出打架，出现怪声、爆音时先把它们关掉再试。

## 五、连接层：声音断续先查线和信号

有线：音频卡顿、几秒断一次，和「连不上」是同一个根源——换一根**能传数据的短线**（1 米内、无延长线），清干净充电口，逐个 USB 口试。线缆接触不良造成的时断时续是最高发原因，详细步骤在 [连不上与黑屏问题排查.md](连不上与黑屏问题排查.md) 的第二节。

无线：Wi-Fi 信号弱、干扰大时，画面还能凑合、声音先开始卡。让手机离车机天线近一些、关掉手机热点，必要时删掉旧配对重新握手；仍不行就先用有线跑通一次，见 [连接汽车教程.md](连接汽车教程.md) 第三节。

## 六、最后两招

1. 从车机界面退出 Android Auto 再进一次，然后重启手机——多数「昨天还好好的、今天突然没声」到这一步就恢复了。
2. 还不行：`设置 → 应用 → Android Auto → 存储 → 清除缓存`，清完重连；Google Play 服务与导航、音乐应用也顺手更新到最新——音频类 bug 大多靠版本更新修掉。

两招之后仍无声，且收音机正常、别的手机插同一台车也没声，问题在手机侧，可考虑卸载重装（安装包见 [下载与安装教程.md](下载与安装教程.md)）；反过来别人手机在你车上也没声，把车开去经销商处查车机。
