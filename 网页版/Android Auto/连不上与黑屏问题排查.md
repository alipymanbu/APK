## 一、先按症状对号入座

Android Auto 是手机和车机两头的系统在通信，一头不对怎么折腾另一头都没用。先看你遇到的是哪种：

| 现象 | 优先查哪里 |
| --- | --- |
| 手机能充电，但车机不出 Android Auto | USB 线是不是数据线、插没插对 USB 口、车机里 Android Auto 是否被禁用 |
| 车机完全认不到手机 | 兼容性、线缆、USB 口，以及车机里旧的连接记录 |
| 无线怎么都连不上 | 蓝牙 + Wi-Fi 开关、旧配对记录、无线兼容性、车机固件 |
| 连上了用一会儿就断 | 有线查线和口，无线查信号与配对 |
| 车机黑屏 / 花屏 | 重启车机、重新插拔、更新车机系统 |
| 能连蓝牙打电话，就是没投射 | 普通蓝牙连接 ≠ Android Auto，查车机投射开关 |
| 一台手机行、另一台不行 | 问题在不行的那台手机上 |
| 换谁的手机都不行 | 问题在车上：USB 口、车机或固件 |

排查全程在停车状态下进行，别边开车边拔线点菜单。连上了但声音不对（没声、断续、导航不播报）不属于本篇，单独看 [没声音与音量调节怎么办.md](没声音与音量调节怎么办.md)。

## 二、六步常规排查（按顺序做，别跳）

1. **确认两边都支持**。手机 Android 9+，车在 [Android Auto 兼容车型查询](https://www.android.com/auto/compatibility/) 里能查到——有的车看着有 USB 口却根本不支持投射，有的只支持有线不支持无线，年款和配置不同结果不同，以官方列表为准。
2. **车机侧把开关打开**。在车机的 `设置` 里翻 Android Auto / Smartphone Projection / Phone Projection / Device Connections 这类菜单，确认没被禁用，也确认你的手机这条记录没被单独关掉。这是「能打电话但没投射」最常见的原因。
3. **重启两端**。手机重启一次；车机按车辆手册的方式重启（只关电门往往不够，车机不会真正重启）。很多偶发故障到这一步就结束了。
4. **换线、换口**。用一根**能传数据**的短线（1 米内、无延长线），优先手机原装线；车上每个 USB 口都试一遍。线能充电不等于能传数据，纯充电线是有线连接失败的第一大原因。同时把手机充电口里的灰絮清一清，接触不良会造成「插上没反应」和「用着断开」两种症状。
5. **检查手机侧的 USB 模式与权限**。插着线时下拉通知栏，把 USB 用途从「仅充电」改成**传输文件 / MTP**；再进 `设置 → 应用 → Android Auto → 权限`，把电话、短信、通讯录、附近设备这些权限给全，缺权限会导致连上但功能残缺。
6. **更新再清缓存**。应用商店里把 Android Auto、Google Play 服务升到最新，手机系统更新也装上；车机固件有更新同样要装（很多连接兼容性问题是车厂固件修的）。还不行就 `设置 → 应用 → Android Auto → 存储 → 清除缓存`（**先只清缓存**，「清除数据」会重置所有配对与设置，是下一步才用的手段），清完重启手机重连。

## 三、无线连不上的专项处理

按第二节走完还不行，再针对无线下手：

1. 确认手机**蓝牙和 Wi-Fi 同时开着**，且车机明确支持无线 Android Auto。
2. 把配对记录删干净重来：车机蓝牙列表删掉手机，手机 `设置 → 已连接的设备 → 已保存的设备` 删掉车，车品牌名开头的 Wi-Fi 网络「忘记」，从车机侧重新发起配对。
3. **先插线跑通一次**——无线配对卡住时，用有线完成首次初始化，之后再切无线，是用户里反馈最有效的一招。
4. 关掉手机热点和 VPN 再试（有用户反馈 Google 系 VPN 会挡住无线投射的连接），配对成功后再开。
5. 5GHz Wi-Fi 被占用或干扰严重时（车库里的扩展器、邻近强信号）会握手失败，先把车挪远一点试。
6. 电池优化把 Android Auto 后台杀掉会导致无线「连上就断」：`设置 → 应用 → Android Auto → 电池`，改成不优化或不限制后台。

## 四、还没解决时

- 用 `设置 → 应用 → Android Auto → 存储 → 清除数据` 做一次重置，然后当作全新设备重新配对——这是手机侧最彻底的一招，做完必须重走一遍 [连接汽车教程.md](连接汽车教程.md) 的步骤。
- 拿另一台 Android 手机交叉验证：**别人的手机在你车上也不行**，问题基本锁定在车机或固件，找经销商处理；**你的手机在别的车上也不行**，问题在手机，考虑系统更新、卸载重装（安装包见 [下载与安装教程.md](下载与安装教程.md)），或检查是否装了投屏类、抢夺 USB 连接的冲突应用。
- 车厂固件、系统更新是最后的变量，两边都更到最新仍不行，且官方兼容列表里确实有你这个年款，就该把问题交给车辆经销商了——继续在手机上重装应用不会解决车机侧的问题。
