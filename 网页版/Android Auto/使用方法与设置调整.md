## 一、车机上你实际会用到的东西

投射成功后，车机屏幕是手机的「驾驶专用镜像」：能点的东西都是大按钮，键盘输入、复杂操作在行驶中一律被禁用，这是刻意为之的限制——**要搜索目的地、要打字，先把车停下**。

主界面上常见这几类入口：

| 入口 | 你拿它做什么 |
| --- | --- |
| 地图 / 导航 | Google Maps、Waze 等导航应用上屏，实时路况、事故与测速提醒、车道指引；电动车还能在地图上看到剩余电量、到达目的地的预计电量和沿途充电站 |
| 电话 | 拨打、接听、听语音信箱，通讯录直接读手机的 |
| 消息 | 语音播报短信与即时通讯消息，用语音口述回复，也能点预设的快捷回复；长的群聊摘要会以要点形式念给你 |
| 音乐与播客 | Spotify、YouTube Music、Amazon Music、播客等音频应用，播放界面上可切歌、可换应用 |
| 应用启动器 | 所有支持投射的应用图标；不用的可以隐藏（见第三节） |

主界面一般会把地图、正在播放的媒体、通讯这三个卡片拼在一屏（dashboard 布局），点卡片进全屏，点左上角或方向盘上的主页键回来。

## 二、语音是主要操作方式

方向盘上的**语音键长按**、或屏幕右上角的麦克风图标、或说「Hey Google」，都能唤起 Google 助理。开车时优先动嘴：

- 导航类：「导航到最近的充电站」「今天路况怎么样」「带我回家」。
- 通讯类：「打给某某」「读我的新消息」「回复：我马上到」。
- 媒体类：「播放我的收藏歌单」「大声一点」「下一首」。

助理本身可用的语言与国家有关——官方单独公布了一份「Google 助理 for Android Auto」支持国家列表，比 Android Auto 本身的国家列表更短，不在列表里的地区语音能力会缺一块，遇到「语音唤不醒」先对照官方 FAQ 的两份名单。

**停车时才能玩的**：车辆停放时，车机上才能跑休闲应用，典型的就是 GameSnacks 平台上的小游戏（如 Bubble Woods、Angry Birds Friends、Candy Crush Soda Saga）；一旦你起步，这类应用会被系统自动退出。会议等生产力应用同样只在停车状态下可用。

## 三、手机端值得改的设置

设置入口：`设置 → 已连接的设备 → 连接偏好设置 → Android Auto`（部分机型在设置搜索框里直接搜「Android Auto」最快），或打开应用本体。常用的几个：

- **自定义启动器（Customize launcher）**：系统默认会把手机里所有支持投射的应用全塞上车机首页，包括你开车时永远不会点的。在这里把无关应用隐藏、把常用的排前面，能明显减少开车时翻页找图标的时间。
- **为我的车辆自动启动**：上车自动投射，免手动。
- **锁屏时允许 Android Auto**：不打开的话无线连接可能每次都要先解锁手机。
- **连接后自动播放音乐 / 自动恢复上次播放**：按喜好开或关。想早上上车不要音乐自动响，就把它关掉；播放音量是跟着手机媒体音量走的，上车前先调好。
- **白天 / 夜间主题**：默认按时间自动切换，也可以强制固定一种；夜间固定深色可以减少屏幕反光。

### 开发者选项（进阶，普通用户可跳过）

设置页拉到最底部，**连续点「版本号」10 次**左右会出现已开启的提示，之后右上角三点菜单里会多出「开发者设置」。里面能改的东西包括：强制无线投射常开（**耗电明显、且有延迟，除非排查问题否则别开**）、强制视频分辨率、固定地图主题等。改出问题记得回来把开关还原。

## 四、行驶中的行为边界

- 行驶中无法键盘输入，目的地搜索、回复消息的打字输入都会被禁用，停车才能操作。
- 手机侧的来电、通知在投射期间由车机接管显示；普通蓝牙音乐通道可能被占用（视车型而定）。
- Android Auto 与 Apple CarPlay 在大多数车上不能同时运行，插两台手机时通常只有一个能投射。
- 安装在手机上的应用**不会**全部出现在车机上——只有做了适配的应用才有图标，没适配的怎么点都点不出来，这不是故障。
