## 一、连接前先核对四件事

四个条件是与的关系，缺一个都连不上，按顺序过一遍能省掉大量无用排查：

1. **手机**：Android 9.0 或更高，且有移动数据套餐。无线投射的要求更高，见下表。
2. **车**：中控系统或后装音响支持 Android Auto，官方查询入口是 [Android Auto 兼容车型查询](https://www.android.com/auto/compatibility/)。车上有 USB 口不等于支持——具体到你的年款、配置是否支持，以官方列表和车辆手册为准。
3. **线**（有线连接才需要）：高质量数据线，官方建议 1 米（3 英尺）以内、不经过 USB 集线器、不加延长线；手机原装线通常最稳。
4. **地区**：官方公布的可用国家/地区列表（美国、日本、韩国、德国、英国、印度、泰国等 40 多个，含台湾地区，**不含中国大陆**）之外，官方明确「大多数功能无法正常工作」。

无线投射对手机的额外要求（官方口径）：

| 条件 | 要求 |
| --- | --- |
| 系统版本 | Android 11 任意机型；Android 10 的 Google / Samsung 机型；Android 9 的 Samsung Galaxy S8、S8+、Note 8 |
| Wi-Fi | 支持 5GHz Wi-Fi（欧盟地区还有额外的 5GHz 法规要求，Google 自家 Pixel 3 及更新机型合规） |
| 车机 | 车辆或音响本身支持无线 Android Auto——很多车只支持有线，这要查车辆手册 |

手机不满足无线条件不代表不能用，**退回去用有线连接**即可。

## 二、有线连接步骤

全程在停车熄火或挂 P 档的状态下操作，官方与各车厂都强调首次设置必须停车完成：

1. 启动车辆，等车机系统完全开机（有的车只关电不关机，车机其实还在运行，最好按整套熄火流程来）。
2. 用数据线把手机连到车上的 USB 口。车上通常有多个 USB 口，**只有一个真正接了投射系统**，逐个试。
3. 手机弹出 USB 用途通知时，别停在「仅充电」，选**传输文件 / MTP**（部分机型直接显示 Android Auto 选项）。
4. 车机屏幕弹出「是否连接 Android Auto」的确认框，选**是**。这个同意选项一般能在车机的 `设置 → 智能手机连接 / Smartphone Connection` 里重新打开。
5. 手机保持解锁，按提示完成首次授权；首次引导没走完时不要熄火走人。
6. 车机上点 Android Auto 图标，几秒内界面应该就出来了。

连上之后，手机的媒体音频会交给 Android Auto 通道，**部分车型的普通蓝牙音乐（A2DP）在投射期间不可用**；倒车影像、原车导航与 Android Auto 互斥的情况也很常见，具体行为以你的车型手册为准。

## 三、无线连接步骤

无线连接的机制是：**先用蓝牙完成握手，再靠 5GHz Wi-Fi 传输画面**，两个都得开：

1. 手机打开蓝牙与 Wi-Fi，车辆静止停放。
2. 在车机上进入蓝牙配对菜单（有的车在 `设置 → 智能手机连接 → 连接新设备`），把手机配对上。
3. 手机弹出「连接 Android Auto」的确认框时选允许；车机弹 Wi-Fi 连接请求时确认。
4. 配对成功后，以后上车只要手机蓝牙连着车，界面会自动出来，不用再掏手机。

两个实测常见的经验：

- **第一次先用有线走完初始化，再切无线**，不少用户反馈无线配对怎么都不成时，插线跑通一次之后无线就正常了。
- 配对出问题时把旧记录删干净再重来：车机蓝牙列表里删掉手机，手机的 `设置 → 已连接的设备 → 已保存的设备` 里删掉车，车品牌开头的 Wi-Fi 网络也「忘记」，然后从车机侧重新发起配对。

## 四、连上之后的两个确认点

- 手机设置里的 Android Auto 选项（`设置 → 已连接的设备 → Android Auto`，或直接打开应用）有「**为我的车辆自动启动 Android Auto**」「**手机锁屏时允许 Android Auto**」两个开关，日常用建议都打开，否则每次上车还要手动点。
- 车机侧同样有总开关：菜单可能叫 Android Auto、Smartphone Projection、Phone Projection、Device Connections 等，确认没被关掉。手机能连蓝牙通话、却死活不出 Android Auto 界面，多半就是这里被禁用了。

连接成功后的功能用法见 [使用方法与设置调整.md](使用方法与设置调整.md)；插上没反应、或者用着用着断开，按 [连不上与黑屏问题排查.md](连不上与黑屏问题排查.md) 逐条排。
