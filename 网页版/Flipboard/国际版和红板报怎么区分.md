# Flipboard 国际版和红板报怎么区分

> 名字一样、图标同色系，但这是两个不能混用的应用：网盘里给的是国际版，国内商店里常见的是「红板报」。本篇讲怎么一眼认出自己手上是哪一个。

## 一、先记住结论：认包名，不认图标

同一个品牌下挂着两个安卓包，看名字容易混，看包名不会错：

| | 国际版（本文与网盘里这一份） | 红板报（中国版） |
| --- | --- | --- |
| 应用名显示 | Flipboard | 红板报 |
| 安卓包名 | `flipboard.app` | `flipboard.cn` |
| 官网 | [flipboard.com](https://flipboard.com) | [flipboard.cn](https://www.flipboard.cn) |
| 界面文字 | 以英文为主 | 中文 |
| 内容编排 | 全球来源 + 区域版本 | 面向中文读者的本地化内容 |
| 账号体系 | 国际版账号 | 独立账号，两边不通用 |

网盘里这一份是**国际版**，版本 4.3.62，包名 `flipboard.app`。

## 二、在手机上怎么确认自己装的是哪个

三条路，任选一条就够：

1. **看桌面图标下方的名字**。写 Flipboard 的是国际版，写「红板报」的是中国版。
2. **看界面语言**。打开就是一段英文引导的是国际版。注意：国际版里也能把区域版本切成 China，但那是内容来源变了，界面文字不会因此变成中文，别被这一点带偏。
3. **看包名（最可靠）**：
   - 安卓设置 → 应用 → 应用管理 → 找到该应用 → 应用信息，页面底部或「应用详情」里能看到包名；
   - 或者在应用商店该应用的详情页找「应用 ID / 包名」一栏。

如果这三条指向的不一致（比如名字写着 Flipboard、包名却是 `flipboard.cn`），以包名为准 —— 有第三方站点会把两个包的名字混着写，包名是唯一没法含糊的那一项。

## 三、为什么会有两个版本

Flipboard 2010 年在美国上线，2013 年底进入中国，最初是同一套产品的汉化版本。2017 年中国团队独立运营，另起了中文名「红板报」，服务器与内容运营都转由国内团队负责。从此两边各走各的版本线，也各自积累账号数据。

这段历史留下的直接后果有两个：

- **账号互不相通**。2017 年改版之后，原来的国际版账号在红板报那边不能登录，收藏与自制杂志也不会迁过去。反过来说，你在国际版里做的东西也不会出现在红板报里。
- **版本号没有对应关系**。两边各自发版，版本号完全对不上是正常的，不能拿来判断谁更新、谁更旧。

## 四、国际版里怎么切到中文内容

如果你主要想读中文资讯，不必换成红板报 —— 国际版内置了区域版本（Regional Editions），官方帮助中心列出的清单里包含 China：

1. 底部进 Profile（我的）。
2. 点右上角齿轮进 Settings（设置）。
3. 选 Regional Editions（区域版本），在列表里挑一个。

三条要留意的：

- **一次只能设一个**区域版本，切换会换掉 Explore（发现）里的推荐内容与部分推送。
- 切换区域版本**不会**改变界面语言，也不会把内容全部变成中文，只是把该地区的媒体来源与话题优先展示。
- 你已经关注的杂志与作者是跟着账号走的，换区域不会掉关注。

官方帮助中心列的区域版本有三十来个，应用商店的介绍文字里写的则是 25 个本地化版本 —— 两个数字都出现过，具体以官方页面当时显示的清单为准。

## 五、从别处拿包时容易踩的坑

- **文件名不等于包名**。网盘、群里、第三方站点的文件名都可以随便起，`Flipboard` 这三个字不代表里面一定是国际版。
- **同名不同源**。官方发布渠道只有两个：Google Play（国际版）与国内各应用商店（红板报）。官网 `flipboard.com` 与 `flipboard.cn` 上也各有官方下载入口。别的地方来的包，装之前至少核对一次包名。
- **版本号别与网上对号入座**。网上搜到的 4.3.63 是国际版当前的最新版，网盘里这份是 4.3.62，差一个小版本属正常；文档里的版本号一律以本地这份为准。
