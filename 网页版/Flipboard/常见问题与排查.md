## 一、装不上

| 提示 | 原因 | 怎么处理 |
| --- | --- | --- |
| 解析包错误 / 应用未安装 | 安装包没下完整，或多传了一次损坏 | 重新下载；下完按 [下载与安装教程.md](下载与安装教程.md) 第三节校验 MD5 |
| 已被阻止安装 | 系统拦了非商店来源 | 给「负责下载这个包的应用」开安装未知应用权限，详见安装教程第四节 |
| 空间不足 | 安装时需要额外余量 | 清出不小于安装包大小的空间再装 |
| 装完图标名是「红板报」 | 装的不是这份包 | 见 [国际版和红板报怎么区分.md](国际版和红板报怎么区分.md) |

## 二、打开就闪退，或者卡在启动页

老机型上的表现最典型。官方对旧版安卓设备的说明是：**系统越新体验越好，最低要求 Android 5.0**，但仅满足最低要求不等于跑得顺。

按顺序试：

1. 确认系统版本 — 设置 → 关于手机 → 系统版本，低于 5.0 就不必再折腾了。
2. 清掉应用缓存再开（路径见第四节）。
3. 卸载重装。重装时从 [Flipboard 安装文件资源（夸克网盘）](https://pan.quark.cn/s/14c675c0394c) 重新取包，别用手机上那个可能已经损坏的旧文件。
4. 重装后用同一个账号登录，关注与自制杂志都在服务端，不会丢。

## 三、一直转圈、加载不出内容

先分清楚是**全网**不行还是**只有 Flipboard** 不行：

1. 拿浏览器随便开一个网页。打不开 → 是网络问题，与这个应用无关。
2. 浏览器正常、只有 Flipboard 空 → 很可能是系统把它的联网权限关了。去 设置 → 应用 → Flipboard → 流量使用/联网权限，确认 Wi-Fi 与移动数据两项都没被禁。
3. 官方给的排查顺序里还有一条：**Wi-Fi 与移动数据互换试一次**。同一台手机在两个网络下表现不同，能快速定位是网络侧还是应用侧。
4. 「换网络」在国产系统上还有个隐藏原因：应用被限制了后台联网，锁屏一段时间后再打开就会加载失败，把它的后台运行权限放开。

## 四、内容不更新，老是那几条

官方给安卓用户的第一步就是这两下，先做完再看别的：

**清内容缓存**

1. 手机 设置 → 应用 → 找到 Flipboard。
2. 选 **存储** → 点 **清除缓存**（注意是缓存，不是「清除数据」，后者会把登录态一起清掉）。

安卓端**应用内没有清缓存入口**，只能从系统设置走，别在应用里翻菜单找。

**强制停止**

1. 同一页面里点 **强制停止**。
2. 重新打开应用。

做完还不刷新，再依次看：应用是不是最新版本、系统有没有可更新的补丁、网络是否稳定。这套顺序对「加载慢」「内容陈旧」都适用。

## 五、首页推的东西越来越不相关

这是关注清单跑偏了，去 [怎么调整首页信息流和兴趣标签.md](怎么调整首页信息流和兴趣标签.md) 按第三节那张表处理：只想降权重的用 Show less，彻底不要的来源用 Mute，整个话题不要了才去取消关注。

## 六、登不上

| 现象 | 处理 |
| --- | --- |
| 忘了用户名 | 应用内 Get started → Log In → Email → Forgot username or password? → Forgot Username?，用户名会发到邮箱 |
| 忘了密码 | 同一入口选密码重置，去邮箱点链接 |
| 邮箱也想不起来 | 用密码重置入口把可能的邮箱逐个试，哪封收到邮件就是哪个 |
| 用 Twitter 登录失败 | 官方已于 2023 年 4 月 3 日停止支持 Twitter 登录，改用邮箱或换一个第三方账号 |
| 换手机后关注全没了 | 多半是登录了另一个账号（比如误登成第三方账号建的新号），核对一下登录方式 |

更细的注册与找回步骤见 [注册登录与账号同步.md](注册登录与账号同步.md)。

## 七、图片或视频显示不出来

- **文章里的图裂了** → 多数是发布方那边的图挂了，或者被你手机上的广告拦截类 App 拦了。同一个站点在浏览器里打开对照一下就知道。
- **视频要手动点才有声音** → 这是设计如此，信息流里的视频不自动播放，只有发布方在文章里设了自动播放才会自己动。
- **播放器黑屏但有声** → 切一下阅读视图与网页视图，两种壳对嵌入式播放器的兼容不一样。
- **文章只给一段，要登录或订阅才能看全文** → 这不是应用的问题：文章本身是在发布方的网页里打开的，可见多少由那个站点定。把阅读模式设成 Android custom tabs 能保留你在原网站的登录态，少反复登录，见 [深色模式与阅读视图怎么设置.md](深色模式与阅读视图怎么设置.md) 第二节。

## 八、广告太多

先分清来源，再对症下药：文章内的广告切阅读视图能压掉大半，信息流里的广告卡片官方目前没有隐藏办法。完整判断见 [通知与广告怎么控制.md](通知与广告怎么控制.md) 第三节。

## 九、桌面小部件不刷新

按官方给的三条查：

1. **有没有登录** — 未登录状态下小部件的内容看不了也不更新。
2. **应用是不是被移到了 SD 卡** — 移过去之后小部件直接不可用，要移回内部存储。
3. **更新频率设了多少** — Profile → 齿轮 Settings → Widget Updates 里调，设得太低自然会显得「不动」。

## 十、怎么确认自己装的是哪个版本

想核对版本号与包名：

1. 手机 设置 → 应用 → Flipboard → 应用信息，能看到版本号与包名；
2. 对照 [下载与安装教程.md](下载与安装教程.md) 第一节那张表：版本 **4.3.62**、包名 **`flipboard.app`**、大小 15.93M。

网上搜到的版本号比这个高是正常的 —— 网盘里给的是发布当时那一版，不是当前最新版。

以上都试过仍有问题，可以走应用内 设置 里的帮助与反馈入口提交。提交时把「版本号 + 包名 + 机型 + 系统版本」一起写上，能省掉来回问的时间。
