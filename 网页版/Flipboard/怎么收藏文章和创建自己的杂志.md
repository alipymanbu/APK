## 一、Magazine 是什么，flip 是什么

- **Magazine（杂志）**：你的一个收藏夹，也是别人能关注、能一起往里放东西的公开页面。
- **flip**：把一篇内容放进杂志的这个动作 — 官方帮助中心里「我 flip 过的」指的就是「我存进去过的」。

能存进去的不只是文章：**文章、视频、图片、播客、以及你自己写的 Note（短笔记）** 都可以。理论上任何能在线打开的东西都能存。

两条前置条件：**必须先登录**，且存的杂志必须是你自己建的或已被邀请协作的（见 [注册登录与账号同步.md](注册登录与账号同步.md)）。

## 二、建一个自己的杂志

两种入口，随便哪一种：

- **Profile 页**：进 Profile → **Create a New Magazine**。
- **边读边建**：在文章里点 **+** → 选 **Create a new magazine**。

然后填三样：

1. **标题**（必填）—— 别人搜到你这本杂志靠的就是它，写具体点，比如「安卓阅读器实测」比「我的收藏」有用。
2. **描述**（可选）—— 说明这本收的是什么，方便别人判断要不要关注。
3. **公开还是私有** —— 公开的会出现在你的资料页上、别人能关注；私有的只有你自己看得见。

**能建多少本**：官方帮助中心的两处说明不一致 —— 「创建杂志」一篇写的是最多 249 本，「杂志数量上限」一篇写的是 275 本。以你在应用里实际撞到上限时的提示为准。

## 三、往杂志里存东西

1. 打开你要存的那篇文章。
2. 点 **+**（Flip 按钮）。
3. 在弹出列表里选一本已有杂志；没有合适的就当场 **Create a new magazine**。
4. 存好后，这本杂志里就多了一条，你的 Profile → Magazines 里也能看到。

想在存的时候附一句话，用 **Add a Note**（写备注）—— 会作为一条独立内容加进杂志，适合当「主题说明」或者给这本杂志开个头。

## 四、拉人一起维护：群组杂志

一本杂志可以从头就建成协作的，也可以事后邀请人：

- **新建时**：在弹出选项里选 **For sharing with a group**（与群组分享），再选邀请方式。
- **已有杂志**：Profile → 找到那本杂志 → ⋮ → 编辑 → **修改贡献者**，然后选邀请方式。

四条规则：

| 事项 | 说明 |
| --- | --- |
| 邀请有效期 | 邀请链接/邀请函数**7 天**后过期，过期重新发一次 |
| 管理权限 | 只有**创建者**能加人、移人；被邀请的人只能往里放内容 |
| 私有资料页的影响 | 创建者把 Profile 设为私有后，**群组杂志的内容对其他人会一并隐藏**，想公开就要把资料页改回公开 |
| 退出 | 贡献者可以随时退出某本群组杂志；退出后**不再能往里放东西**，但公开的群组杂志仍可浏览 |

## 五、整理、置顶与删除

- **置顶**：杂志的所有者可以把某一条 **Pin**（钉）到杂志顶部，访客进来第一眼看到的就是它。
- **删单条**：Profile → 打开杂志 → ⋮ → 编辑内容，选中要删的那条删掉。**官方明确写了没有撤销**，删之前想清楚。
- **改杂志**：⋮（手机端）打开编辑菜单，可以改标题、描述、公开状态、贡献者。
- **删杂志**：同一个编辑菜单里选择删除，杂志连同里面的内容一起移除，同样不可恢复。
- **管评论**：你是杂志所有者时，任何一条评论你都能删 —— 打开那条 flip 的评论区，点评论旁边的删除即可。

## 六、别把 Storyboard 当成杂志

信息流里偶尔会刷到 **Storyboard**，长得像杂志但性质完全不同：

| | Magazine（杂志） | Storyboard |
| --- | --- | --- |
| 谁建的 | 你或别的用户 | 发布方，通常 5~12 篇凑一个主题 |
| 能不能往里存 | 能 | 不能，它是一张**静态页面** |
| 怎么用 | 收藏、持续加内容、可协作 | 当目录看，点开里面的单篇读 |
| 会更新吗 | 会，你加它就长 | 不会 |

判断方法很简单：在 Storyboard 上点 + 是存不进「这本」的，只会让你另选一本杂志。
