# Flipboard 深色模式与阅读视图怎么设置

> 同一篇文章，在 Flipboard 里可能长得完全不一样 —— 取决于它来自哪种内容源，也取决于你把「阅读模式」设成了哪一档。本篇讲主题怎么切、两种阅读模式各有什么代价、以及为什么有的文章只给几行字。

## 一、切深色模式

安卓版默认是浅色主题，而且**默认不跟随手机**——手机开了深色，Flipboard 可能还是白的。改法：

1. 底部进 **Profile**。
2. 点右上角**齿轮图标**进 Settings。
3. 在 **Options** 区里找到 **Theme**，选你想要的：浅色、深色，或者跟随手机自动切。

三条说明：

- 这一项在两个方向都能改回来，切错了不会有什么副作用。
- 主题只影响 Flipboard 自己的界面。点进文章后你看到的是**发布方的网页**，它是不是深色由那个网站决定，与这里的设置无关。
- 想深色网页也省心，配合下一节的阅读视图一起用。

## 二、两种阅读模式，先选一个

文章打开后用什么「壳」来显示，由 **Reading Mode（阅读模式）** 决定：

1. **Profile → 齿轮 Settings → Display Options（显示选项） → Reading Mode**。
2. 在下面两档里选一个。

| | Android custom tabs（较新） | Legacy web view（旧式内置） |
| --- | --- | --- |
| 谁来渲染网页 | 系统的默认浏览器 | 应用自带的老式 WebView |
| 阅读视图按钮 | **没有**这个按钮 | 文章右上角有纸张图标，可切阅读视图 |
| 替代方案 | 用浏览器自带的「简化视图」（Chrome 的 Simplified View）达到同样效果 | 无 |
| 浏览器登录态 | 保留得更好，原网站不用反复登 | 常常要重新登 |
| 支持范围 | Chrome、Edge、Firefox、Brave、Tor 等主流浏览器 | 所有机型都能用 |

怎么选：

- **嫌网页里广告多、排版乱** → 用 **Legacy web view**，这样你才有那个可以一键剥掉网页杂物的阅读视图按钮。
- **在意速度和登录态**（比如要读付费站点的文章）→ 用 **Android custom tabs**，广告问题交给浏览器的简化视图解决。

切换是双向的：从 custom tabs 切回 Legacy web view，阅读视图按钮就会重新出现。

一个容易被当成故障的边界：**阅读视图只在手机应用里有，网页版没有这个功能**。另外安卓端**应用内没有「清除缓存」入口**（iOS 版有），要清缓存只能走系统设置，步骤见 [常见问题与排查.md](常见问题与排查.md) 第四节。

## 三、四种排版，看到的不一样是正常的

同样是「一篇文章」，背后可能是四种完全不同的东西，认出来就不会以为是故障：

| 类型 | 长什么样 | 你能做什么 |
| --- | --- | --- |
| Webview | 排版跟该网站的网页一致，**连它自己的广告一起带过来** | 切阅读视图/简化视图以减少广告 |
| RSS feed | 可能只有几行字、没有图 | 没办法展开，**显示多少由发布方在源里规定** |
| Storyboard | 一个专题页，里面列着 5~12 篇文章 | 当目录用，逐篇点开读 |
| Reader view | 统一、干净的纯文字版 | 读长文最舒服 |

RSS 那一条最容易误会：你看到半截就断了，又找不到「阅读全文」，这不是应用出问题，是发布方在 RSS 里只给了摘要。

阅读视图也不是白拿的：官方说明它**可能把某些嵌入式内容简化甚至省略**，视频、互动图表这类东西会掉，所以遇到内容和正文对不上的，换回网页视图看一眼。

## 四、视频什么时候会自动播

- **信息流里的视频不会自动播**，要点一下才开始；视频广告同样不会出声。
- **点进文章之后就不一定了**：文章里嵌的视频如果发布方设了自动播放，你可能会看到并且听到，这一项 Flipboard 管不了，只能在那个网页里自己关。
- 在公共场合刷文章，建议先看字，遇到视频手动点 —— 这是最省事的规避方式。

## 五、一个要知道的功能边界：没有完整离线阅读

官方帮助中心里有一条明确写着：**完整的离线阅读目前不支持**，属于「以后可能会做」的功能。

所以这几件事别指望：

- 出门前把一批文章下载下来，飞机上断网看；
- 没网时打开已读过的文章还能重新加载正文；
- 靠缓存代替流量。

有网时正常读、读完的内容留在历史里，这是现阶段的实际能力。
