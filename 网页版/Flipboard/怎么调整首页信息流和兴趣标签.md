# Flipboard 怎么调整首页信息流和兴趣标签

> Flipboard 首页推什么，全看你关注了什么。本篇讲四个底部标签页各自管什么、怎么把「不想看的东西」按不同力度处理掉、以及怎么把信息流放到桌面小部件上。

## 一、先认清四个标签页

底部一排图标就是全部入口，各管一段：

| 标签 | 干什么 |
| --- | --- |
| Home（首页） | 默认落地页。顶部那条可以左右滑的横条叫 home bar，第一条固定是 **For You** |
| Following（关注） | 分三个子页：All（关注的一切）、Profiles（关注的人）、Accounts（连进来的社交账号） |
| Explore（发现） | 按话题、杂志、作者搜索和闲逛的地方，也是加关注最顺手的入口 |
| Profile（我的） | 你的资料、杂志、点赞、通知，以及 Settings 设置入口 |

首页横条上能挂多个信息流，**点右上角的 ⋮ 可以编辑 home bar**：不是自己挑的话题可以从这里挪走，想天天看的可以往前排。

## 二、For You 到底是怎么拼出来的

For You 不是「一条时间线」，它是把你关注的**所有**来源（话题 + 杂志 + 作者 + 媒体）合成一个流；你关注得还少的时候，系统会补一批推荐内容进来填充。

所以调教的着力点只有一个：**改你关注了什么**。改得越细，这个流越准。

## 三、三个力度，选对了才不白费

在 For You 里看到不想看的东西，别急着直接取消关注 —— 先分清你要的是「少一点」还是「彻底不要」：

| 你的想法 | 操作位置 | 效果 |
| --- | --- | --- |
| 这一类以后少推点 | 文章上的 ⋮ → **Show less**（不感兴趣） | 只是降低权重，**不会**静音这个来源或话题 |
| 这个来源以后一条都别出现 | 文章上的 ⋮ → **Mute** | 全站范围内不再出现该来源的文章 |
| 这篇违规了 | 文章上的 ⋮ → **Report** | 从你的流里移除并提交官方审核 |
| 整个话题都别要了 | For You 右上角滑杆图标 → 取消关注该话题 | **全局**取消关注，包括你钉在 home bar 上的那一份 |

Mute 过的来源想恢复：进 **Profile → Settings → Muted Sources**，把对应来源的勾去掉即可。

## 四、把兴趣标签调细一点

两种加关注的方式，效果一样：

- **For You 右上角的滑杆图标（Personalize / Tune）**：直接增删话题，官方还会根据你现有的关注推荐相近话题。这里的诀窍是**往细里选** —— 选「意大利菜」比只选「美食」有用得多。
- **Explore 里搜**：搜人物、话题、标签、博客、你常看的站点都行，找到后点关注。

有一点要提前知道：**在 For You 里取消关注是全局动作**。如果你只是不想在首页看到它、但希望它留在别处，正确做法是保留关注，改用上面那张表里的 Show less。

## 五、区域版本：换一批内容来源

想让首页多出某个地区的媒体和热搜话题：

1. **Profile → 齿轮 Settings → Regional Editions**。
2. 在清单里挑一个，比如 China、Hong Kong、Taiwan、Japan 这些都在列。

官方会**自动读你手机的语言与地区设置**，直接给你一个它认为最相关的区域版本；如果你的系统设置没落在它的清单里，它给你的那个就可能不是你想要的。所以想固定看某一地的内容，别等它猜，自己设一次。

三条约束：

- **一次只能设一个**区域版本，换掉就会换掉 Explore 里的定制栏目和部分推送。
- 它只改内容来源，**不改界面语言**，也不会把你已关注的杂志挤掉。
- 这个设置在网页版上没有，只能在手机应用里改。

## 六、把信息流放到桌面小部件

安卓桌面小部件是 Flipboard 提供的第二个入口，装好之后不用点开应用就能扫一眼标题：

1. 长按桌面空白处 → 选 **Widgets（小工具）**。
2. 在列表里找到 **Flipboard**，把小组件拖到桌面上。
3. 点小组件里的任一条即可打开应用。

四条使用限制，提前知道省得白折腾：

- **必须登录**。官方说明：未登录状态下，小组件里的内容看不了也点不动。
- **内容不能自定义**。小组件展示的就是你的首页信息流，没有单独的选题设置。
- **刷新频率可以调**：**Profile → 齿轮 Settings → Widget Updates**，在里面选择更新频率。
- **应用不能装在 SD 卡上**。部分机型支持把应用移到 SD 卡，一旦移过去，小组件直接不可用，需要先移回内部存储。

不想要了就把小组件拖到底部的删除区域，选移除。

如果首页越来越跑偏，或者小组件长期不刷新，按 [常见问题与排查.md](常见问题与排查.md) 里的对应条目排查。
