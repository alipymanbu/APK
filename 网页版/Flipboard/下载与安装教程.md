## 一、装之前先对一遍这份包的信息

Flipboard 是一款把新闻、杂志和社交内容聚在一起读的应用，开发商是 Flipboard，官方免费提供，界面以英文为主。下面这张表是网盘里那份安装包的实际信息——网上搜到的「最新版」常常已经是另一个版本号，装之前以这张表为准，装完在应用信息里核对也对得上。

| 项目 | 值 |
| --- | --- |
| 应用名 | Flipboard |
| 包名 | `flipboard.app` |
| 版本 | 4.3.62 |
| 安装包大小 | 15.93M |
| 安装包 MD5 | `6f208056af3a222139e4408aa379b9d4` |
| 系统要求 | 官方帮助中心列的是 Android 5.0 及以上；第三方分发渠道对近期版本标注的是 Android 11 及以上。以你手机上安装时的实际提示为准 |
| 适用形态 | 安卓手机 / 平板（国际版） |

先看这几点：

- 系统在 Android 11 以上的机型基本不会有兼容问题；还停在 Android 5.x 的老机器要试过才知道，安装时被系统直接拦下就是装不了。
- 一般留出 60M 以上空闲空间就够了：包本身 15.93M，装完还会额外占一部分。
- 这份包是**国际版**（包名 `flipboard.app`）。国内常见的「红板报」是另一个包（`flipboard.cn`），账号和内容不互通，拿不准自己该用哪个，先看 [国际版和红板报怎么区分.md](国际版和红板报怎么区分.md)。
- Flipboard 还有网页版与 iPhone 版，登录同一个账号就能用；本套文档只针对网盘里这份安卓安装包。

## 二、把安装包从网盘取到手机

1. 打开 [Flipboard 安装文件资源（夸克网盘）](https://pan.quark.cn/s/14c675c0394c)。
2. 先点「保存到我的网盘」，再下载。直接下载也能用，但转存到自己的网盘之后，原分享链接以后失效了也不影响你。
3. 等下载完，记一下文件在手机里的位置，多数浏览器会放进「下载」或 `Download` 目录。
4. 文件名通常形如 `flipboard_v4.3.62.apk`，以网盘里实际显示的名字为准。

打开链接提示失效或要提取码，说明这条分享已经不是当前状态，换最新的一条再试。

## 三、动手装之前校验一下包

安装包从网络传到手机，中途出过错的话，装的时候会报「解析包错误」。花半分钟校验一次，能省掉后面一堆莫名其妙的排查。

用电脑校验最省事：把 APK 拷到电脑上，在它所在目录打开 PowerShell 执行：

```powershell
certutil -hashfile "flipboard_v4.3.62.apk" MD5
```

输出的十六进制串去掉空格后，应该和第一节表里的 `6f208056af3a222139e4408aa379b9d4` 完全一致（大小写不敏感）。手机上也可以用带 MD5 校验功能的文件管理器做同样的事。

对不上就重新下载一次，别将就着装。

## 四、先去系统里放行「未知来源」

网盘里的包不是从应用商店装的，安卓默认会拦一次。要先给负责下载它的那个应用（浏览器或夸克）开安装权限，各品牌路径不一样：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 权限管理 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装外部来源应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 生物识别和安全 → 安装未知应用 |
| 原生安卓 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

路径记不住也没关系，在设置顶部的搜索框里搜「未知应用」或「外部来源」，基本都能跳到同一页。找到负责下载的那个应用，把开关打开。

## 五、安装与第一次打开

1. 从通知栏点刚下载完的文件，或者打开文件管理器找到那个 `.apk` 点它。
2. 弹出安装界面点「安装」，等进度走完，桌面出现图标，名称显示为 Flipboard。
3. 首次启动会依次弹权限申请。真正影响功能的是这几项：

| 权限 | 不给会怎样 |
| --- | --- |
| 网络 | 整份内容都拉不到，只能看到一个空壳 |
| 存储 / 照片和视频 | 图片缓存、文章里保存图片这类操作会受限 |
| 通知 | 只影响推送提醒，不影响阅读 |
| 后台运行 / 自启动 | 通知可能延迟，桌面小部件也不会自动刷新 |

具体弹哪几项、叫什么名字，以你手机上实际弹出的为准，上表只是它们各自的用途。

4. 启动后会先看到一段引导：选几个你感兴趣的话题，选完首页就有了内容。这一步不选也能进，首页会退化成一段通用推荐。
5. 引导走完会提示你注册或登录。**不登录也能翻内容**，但收藏、关注、评论以及桌面小部件里的互动都要登录才可用，注册方式见 [注册登录与账号同步.md](注册登录与账号同步.md)。

## 六、装不上或者装完打不开

按这个顺序自查，比反复重装有效：

- 提示「解析包错误」「应用未安装」→ 回到第三节重新校验 MD5，文件多半没下完整。
- 提示「已被阻止安装」→ 第四节的未知来源权限没开，或者开了但给错了应用（要给它下面载这个包的那个应用）。
- 装好后点图标没反应、闪一下退回桌面 → 先看系统版本是否低于本包支持的范围；仍然不行，到 [常见问题与排查.md](常见问题与排查.md) 里按「打开就闪退」一条往下排。
- 提示空间不足 → 清出不小于安装包大小的空闲空间再试，安卓在安装时要额外留出余量。
- 装完发现是中文界面、图标写着「红板报」→ 你装的不是这份包，见 [国际版和红板报怎么区分.md](国际版和红板报怎么区分.md)。
