## 一、Ozon ID 是什么

Ozon 的账号体系叫 Ozon ID：用一个手机号码做身份验证，登录时不需要记密码，输手机号收验证码就行。购物、订单、优惠、Ozon 银行相关服务都挂在同一个 Ozon ID 下，App 和网页版通用。

不登录也能逛：浏览目录、把商品加进购物车都不拦。但要真正下单，系统会要求你输入手机号和收货地址 —— 实际上等于走一遍注册。登录后才有订单追踪、个人折扣这些。

## 二、手机号注册（最通用的方式）

1. 打开 Ozon App，点底部或顶部的「登录」（Войти）→「登录或注册」。
2. 输入手机号。号码前的国家区号要在下拉列表里选对（中国是 `+86`，俄罗斯是 `+7`）。
3. 点「获取验证码」，把收到的短信验证码填进去。
4. 验证通过后系统直接把你带进个人中心，注册就算完成。
5. （可选）在个人中心补填邮箱、设一个密码 —— 邮箱用于以后找回账号，建议填。

验证码有时不走短信而走「闪呼」（flash-call，一通立刻挂断的来电）：把来电号码的后几位填进验证码框同样有效。App 页面上如果写着「稍后再试」，说明上一条验证码还没到冷却时间，等几十秒再点。

部分场景还提供「通过 Госуслуги（国家服务门户）确认的账号」「VK ID」「Apple ID」等注册入口 —— 这些依赖对应平台的已验证账号，能否看到入口以你设备上实际显示为准。

## 三、日常怎么登录

- **App / 网页**：点「登录」→ 输手机号 → 填验证码，全程无密码。
- **设置了密码之后**：也可以用「手机号 + 密码」登录，适合收短信不方便的时候。
- **收不到验证码**：先检查手机信号与拦截短信的垃圾箱；仍收不到的排查思路见 [常见问题与故障排查.md](常见问题与故障排查.md)。

登录状态会保持一段时间，日常换网络、重启 App 不用反复登录；换手机只要手机号还在，重新收一次验证码就能登进去，购物车和订单都在云端。

## 四、换绑手机号

号换了是件必须处理的事，否则旧号一旦停机，验证码收不到就登不进去了。路径：个人中心 → 设置 → 电话号码字段 →「更改」→「无需确认更改」（按页面实际文案为准）→ 输入新号码 → 收新号验证码 → 填入。

两个前置条件：

- 如果旧邮箱还绑着，流程会先要求你填绑定的邮箱并输入邮件里的验证码；
- 邮箱也丢了、旧号也收不到，就走「通过邮箱恢复账号」的入口，用邮箱验证码重设；两条路都断了，只能联系官方客服人工核验。

改完手机号后，旧号如果还绑着别的服务（比如银行类功能），记得同步更新。

## 五、注册与登录的常见卡点

| 卡点 | 判断 | 处理 |
| --- | --- | --- |
| 输入手机号后一直「稍后再试」 | 验证码频率限制 | 等冷却结束再点，别连点（连点会排队，反而更慢） |
| 区号选错 | 收不到短信 | 回到第一步核对国家区号，`+86` 与 `+7` 最容易搞混 |
| 提示账号已存在 | 这个号注册过 | 直接走「登录」流程，不用重新注册 |
| 验证码填对了还是进不去 | 网络层被拦 | 关掉 VPN 再试，见 [常见问题与故障排查.md](常见问题与故障排查.md) |

注册完成后就可以正式下单了，流程见 [下单购买与配送方式.md](下单购买与配送方式.md)。
