**涉及订单的问题，先在应用内找在线客服并留下订单号**——电话与邮箱没有你的订单上下文，来回会慢很多。

## 二、装不上 / 装完打不开

按这个顺序排查：

1. **核对 MD5**：与 [下载与安装教程.md](下载与安装教程.md) 表里的 `2029331fe3eb8420d43c051058605798` 不一致，说明文件在传输中损坏，重新拿一份。
2. **系统版本**：资料页要求 Android 5.1 及以上，系统更低会装不上或闪退。
3. **「未知来源」没放行**：提示禁止安装来自此来源时，进设置对你的文件管理器/浏览器单独放行。
4. **包冲突**：手机上若已有同包名但签名不同的包（比如来路不明的渠道包），会安装失败。先卸载旧的再装。
5. **装的是旧版**：应用宝那一侧的版本长期滞后，装上后发现少板块、少活动资格，多半是版本问题而不是故障，换一个渠道的包即可（见 [各渠道版本不一样怎么选.md](各渠道版本不一样怎么选.md)）。
6. 以上都排除还闪退 → 用网盘里那版（7.2.0）试试；新版在个别机型上出问题并不罕见。

## 三、打开后没餐厅 / 定位不准 / 地址下单不了

- 定位权限没给，或手机定位服务本身关着 → 去系统设置打开，重进应用。
- **收货地址必须在澳门配送范围内**。你在内地、或地址选到了范围外，就是一家店都不显示——这不是故障（见 [注册与点餐支付流程.md](注册与点餐支付流程.md)）。
- 想送到的酒店属于「送不进、只能门口取」的情况，地址里写清门口位置，别指望骑手上楼。

## 四、支付失败

| 现象 | 先查什么 |
| --- | --- |
| 一直转圈/报错 | 网络；换个支付渠道再试 |
| 银行卡被拒 | 该卡的线上/境外支付限额与开关 |
| 看不到活动立减 | 当日名额抢完（页面会直接不显示）；或版本低于活动要求（如 V5.8.5） |
| 券没抵扣 | 灰字提示写的条件，见 [优惠券消费金与月卡怎么用.md](优惠券消费金与月卡怎么用.md) 第六节 |

**付款失败不要连续重复付**：先去订单页看这笔到底成没成，重复支付会产生多笔待支付/已支付订单，处理起来更麻烦。

## 五、配送与商品问题

- **没送到 / 超时很离谱**：订单页联系在线客服，报订单号，让平台查配送记录。
- **漏送、错送、洒漏**：拍照留证再联系商家或客服，这是最有效的一条。
- **餐到了找不到骑手**：酒店场景居多——地址没写清门口位置时最常发生，写清「XX 门 / 大堂」能避免。
- **退款怎么算**：走银联立减的订单，整单退款只退你实际支付的金额，部分退款按实付比例退（活动细则口径）；未使用且已购买的劲爆券不支持退款退单。其他情况以客服给的处理方案为准。

## 六、商家想入驻

官方常见问题给的路径很短：

1. 打开 mFood，点底部「我的」；
2. 往下拉找到「商家入驻」；
3. 在弹出页面填写相关信息并提交，等平台回复。

官网也有面向商户的方案页（同 [www.mfoodapp.com](https://www.mfoodapp.com)），适合要谈合作方案的场景。
