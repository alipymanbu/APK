## 一、注册登录：手机号加验证码就行

1. 打开应用，进入注册/登录页。
2. 输入手机号收验证码。内地手机号与港澳手机号都能用于注册登录，不必专门换澳门号码。
3. 登录后官方描述里提到新人礼包（注册即赠价值 50 元礼包），是否仍发放、含什么，以应用内「我的」页面当时显示为准。

登录态跟手机号走，换手机重装后用同一个号登录即可拿回账户里的券与地址。

## 二、先给权限，否则列表是空的

- **定位**：不给定位，首页按不准你的位置，附近餐厅列表会失真；首页左上角有定位按钮，点它可手动重定位到附近，看到最新活动与周边商家。
- **通知**：不给通知，接单、配送进度、优惠到期都提醒不到你。

这两项都能在系统设置里随时改，不必在首次弹窗时纠结。

## 三、收货地址是能不能下单的关键

地址填不对，后面全白搭：

1. 收货地址必须落在**澳门**的配送范围内，选到范围外的点会直接提示无法下单。
2. **填酒店要写清是哪个门**。澳门的外卖普遍只能送到酒店门口、送不上楼（有娱乐场的酒店更是进不去），骑手到门口会联系你出来取。写清「XX 酒店大堂 / 正门 / 侧门」能省掉一轮电话。
3. 联系电话填你当下能接的号，骑手到了找不到人是超时的主要原因。
4. 送住宅则精确到大厦名、座数与楼层，澳门很多旧楼没有电梯、门牌也不规则，写细一点更稳。

## 四、下单与配送类型

选餐厅 → 加购物车 → 结算页核对。结算页上你要留意三件事：**配送类型、预计送达时间、优惠抵扣**。

配送类型常见几种（以结算页当时显示为准）：

| 类型 | 含义 |
| --- | --- |
| mFood 专送 | 平台配送团队送，是默认形态 |
| 超远送 | 距离超出常规范围的订单，通常更慢、可能有额外费用 |
| 商家自送 | 商家自己的人送，时效由商家定 |
| 自取 | 你自己到店取，没有配送费 |

时效方面，官方站点的中文页写「取餐后约 15 分钟送达」，英文页写「30 分钟内送达」，两个口径并存——实际多久取决于商户忙不忙、距离多远，**以结算页当时给出的预计时间为准**，别拿宣传数字当承诺。有用户在 App Store 留言称晚上点的米粉约 30 分钟送到，这只是单条反馈，不代表普遍时效。

下单后可在订单页实时看状态与配送进度，送餐途中能同步看到骑手位置。需要指定时间送达的，用预约下单功能（入口在结算页，不同版本叫法略有差别）——赶在回酒店的路上先下一单、指定送达时间，是很多人在澳门的实际用法。

## 五、支付方式

mFood 官方列出的线上支付渠道：

| 渠道 | 备注 |
| --- | --- |
| MPay | 澳门本地电子钱包，本地居民常用 |
| 支付宝（Alipay） | 内地用户顺手 |
| 微信支付（WeChat Pay） | 内地用户顺手 |
| 银联 / 云闪付 | 经常有立减活动，见 [优惠券消费金与月卡怎么用.md](优惠券消费金与月卡怎么用.md) |
| VISA / Mastercard | 国际卡 |
| ICBC ePay、BOC PAY、TAI FUNG PAY | 澳门本地银行系钱包 |

几点注意：

- 支付方式能不能用、有没有活动立减，**以支付页面当时显示为准**；有的渠道对卡的发卡行有要求（比如银联活动就排除了部分澳门/香港地区的借记卡）。
- 内地游客最省事的组合是支付宝或微信，不用先去办本地钱包。
- 支付失败先看是不是银行卡本身的境外/线上支付限额，再看是不是活动名额已抢完导致页面报错（重进一次结算页即可）。

## 六、小费与额外费用

澳门没有强制小费文化，外卖平台上给不给全凭自愿，不给也正常。你实际要付的是：菜品价 + 配送费（自取则无）− 各类优惠抵扣，结算页会列清楚，付完在订单页能看到明细。

## 七、收货之后

餐到手先看一眼有没有漏单、洒漏。有问题别急着差评，先走 [常见问题与客服联系方式.md](常见问题与客服联系方式.md) 里的售后顺序：先联系商家/在线客服，谈不拢再升级。
