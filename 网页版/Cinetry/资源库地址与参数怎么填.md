## 一、每种类型都有的三栏

不管选哪个类型，表单都是同一套骨架：

| 栏位 | 填什么 | 常见错误 |
| --- | --- | --- |
| 名称 | 自己认得出的名字 | 不影响连接，随意 |
| 地址 | 服务的访问地址（见下表） | 漏端口、`http`/`https` 写反 |
| 账号 / 密码 | 该服务的登录凭据 | 大小写；服务端账号被禁用 |
| UserAgent | 留空即可 | 不会填就用默认，别乱写 |

## 二、各类型地址怎么写

| 类型 | 地址写法 | 补充说明 |
| --- | --- | --- |
| Jellyfin | `http://{你的Jellyfin地址}:{端口}` | 填对后自动读资源库、播放记录、视频详情，默认本地硬解、播放记录自动同步 |
| Emby | `http://{你的Emby地址}:{端口}` | 同上；Jellyfin 与 Emby 默认端口都是 `8096`，两台同机时注意别撞端口 |
| 苹果 CMS | 采集接口地址：域名，或域名 + `/api.php/provide/vod/` | 返回必须是 json；带 `/api.php/provide/vod` 的完整地址也能直接填 |
| IPTV | m3u 文件地址，或 TVBox 的 txt 直播源地址 | 两种格式都认 |
| WebDAV | `http://{WebDAV地址}:{端口}` | 以目录形式展示，自动读同目录刮削好的 `.nfo`、封面、海报、字幕，支持 `.strm` 文件播放 |
| Alist / OpenList | `http://{地址}:{端口}`，**路径要带 `/dav`** | 与 WebDAV 同样读刮削数据；漏掉 `/dav` 是最常见的连不上原因 |

音乐类服务（Subsonic、Navidrome、GD 音乐台、audiobookshelf、道理鱼）同样是「地址 + 账号密码」，按服务自己的文档取地址。

## 三、填之前先在浏览器里验一次

添加前用手机或电脑浏览器把地址打开，一分钟排除一半问题：

1. **服务器类**（Jellyfin / Emby）：打开后应出现登录页——能出页，地址和端口就是对的；`ERR_CONNECTION_REFUSED` 多半是服务没启动或端口错了。
2. **CMS 接口**：打开后浏览器里应直接返回一串 json 数据；不出 json 就换正确的接口地址再试。
3. **WebDAV / Alist**：能在浏览器里列出目录最好；Alist 记得带上 `/dav` 路径。

浏览器里都打不开的地址，填进 Cinetry 也连不上——先回去修地址，排查顺序见 [常见问题与故障排查.md](常见问题与故障排查.md) 第一节。

## 四、连上之后你应该看到什么

- Jellyfin / Emby：电影、电视剧等分类直接同步进来，播放记录与服务器端一致。
- CMS / IPTV：分类列表和点播/直播条目按接口返回展示。
- WebDAV / Alist：以文件夹层级展示，刮削过的目录会出海报墙。

一片空白时不是地址错就是权限错，回到 [添加资源库与服务器连接教程.md](添加资源库与服务器连接教程.md) 第二节对照重填。

## 五、配置的保存与再编辑

- 填过的服务器会保存在本地，下次打开不用重输；添加入口里可以对已有资源库再编辑。
- 较新版本还支持把整份资源库配置导出/导入成文件（换机时比手抄方便），以及直接添加夸克网盘、115 网盘作为资源库——**这些是后续版本加入的能力**，你手上版本有没有，以 [官方更新日志](https://blog.gstory.cn/docs/cinetry/version) 当时显示为准。
