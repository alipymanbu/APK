## 一、先认清你要装的那一份

Cinetry 是一款开源免费的跨平台音视频播放器客户端（代码仓库在 [github.com/gstory0404/Cinetry](https://github.com/gstory0404/Cinetry)，官网 [cinetry.gstory.cn](https://cinetry.gstory.cn/)），本身不带任何影视内容，靠你添加的媒体服务器出内容。装之前先对清楚版本——你在网上搜到的最新版，和网盘里那份经常不是同一个。

网盘里这份安装包的记录信息：

| 项目 | 值 |
| --- | --- |
| 版本 | 0.5.2 |
| 包名 | `com.gstory.cinetry` |
| 大小 | 63.26 MB |
| MD5 | `CE3189EAD2392918EFBB39C794F0EA5D` |
| 记录时间 | 2026-09-23 |

官方的发布页在 [github.com/gstory0404/Cinetry/releases](https://github.com/gstory0404/Cinetry/releases)，本次检索时第三方下载页显示的最新版为 v0.8.4（2026-09-20 前后），**以官方页面当时显示为准**。版本号按 `0.主版本.小版本` 递增，0.5.2 与 0.8.x 之间隔了多个版本，功能会有差异——先按你要装的那一份对照即可。

## 二、从夸克网盘拿安装包

1. 点开 [Cinetry 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c8f2b974f116)，先「保存到我的网盘」——先转存再下载，分享链接失效后你网盘里仍然有。
2. 手机装夸克 App 并登录同一个账号，在网盘里找到 `Cinetry（先保存再下载）` 文件夹。
3. 文件夹里的 `Cinetry_v0.5.2.apk` 就是安装包，下载到手机本地。
4. 文件夹里还有一份 `先保存再下载避免失效.txt` 说明文件，是给你的转存提示，不用运行它。

## 三、安装步骤

1. 在文件管理器里点这个 `.apk`。系统会弹「禁止安装未知应用」——点提示里的设置入口，允许你下载用的那个应用（夸克或文件管理器）安装未知应用，再返回继续。
2. 装完点「打开」即可开始用；第一次打开是空库状态，接着要做的是 [添加资源库与服务器连接教程.md](添加资源库与服务器连接教程.md) 里那一步。
3. 想确认包没下坏，可以核对 MD5 是否等于 `CE3189EAD2392918EFBB39C794F0EA5D`，对不上就是下载不完整，重新下一次。

安装报错（解析包错误、签名冲突、装完打不开）的处理见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、系统要求

- 网盘这份 0.5.2 的记录标注：**需要支持安卓系统 5.2 以上**。
- 第三方应用库对 v0.8.1 标注的最低要求是 Android 7.0，**以官方页面为准**。
- 两份要求不一样是因为版本不同；手机系统版本低于要求时，安装阶段就会直接报错。

## 五、想装其他平台去哪拿

Cinetry 覆盖 Android、iOS、Windows、macOS、Linux 和电视（TV）这几类平台，官方安装说明（[blog.gstory.cn/docs/cinetry/Install](https://blog.gstory.cn/docs/cinetry/Install)）给的入口是：

- **Windows / macOS / Linux / Android**：官方 [releases 页面](https://github.com/gstory0404/Cinetry/releases)，另有 123 云盘、小飞机网盘的正式版与预览版分流（以官网当时显示为准）。
- **iOS**：官方说明是借助爱思助手自签名或巨魔安装；TestFlight 邀请链接的获取方式写在官方仓库 README 里。
- **TV（电视盒子）**：官方安装说明的做法是直接安装手机版安装包。

各平台界面与操作逻辑基本一致，你在手机上学会的那一套可以直接搬到电视和电脑上。

## 六、版本更新与共存

- 同一台设备上升级：直接安装新版本的 apk 即可覆盖，配置与播放记录留在本地，不会丢（它们加密存在设备上）。
- 手机上已装过别的渠道的 Cinetry：包名同为 `com.gstory.cinetry`，若提示签名冲突，先卸载旧的再装——卸载会清掉本地配置，服务器地址需要重填，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
- 拿不准该不该升：版本号会随时间变化，一律以 [官方发布页](https://github.com/gstory0404/Cinetry/releases) 当时显示为准。
