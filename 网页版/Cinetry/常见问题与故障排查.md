## 一、服务器连不上

按命中率排查：

1. **同一网络吗**：手机连的是不是和服务器同一个局域网；出门在外时，服务器有没有公网入口或内网穿透——不在一个网络里，IP 地址再对也连不上。
2. **地址抄对了吗**：`http` / `https` 有没有写反、端口号有没有漏（Jellyfin 常见是 `8096`，Emby 常见是 `8096` 或反代后的 443，以你自己的部署为准）。
3. **服务还活着吗**：用手机浏览器直接打开那个地址，能出登录页说明服务正常，问题在 App 这边的填写；打不开先去电脑上看服务是否在跑。
4. **账号密码**：大小写、是否被服务器禁用。
5. **地址栏填错类型**：Alist/OpenList 漏了 `/dav`、CMS 填了非 json 的页面——逐项对照 [资源库地址与参数怎么填.md](资源库地址与参数怎么填.md)。
6. **HTTPS 证书问题**：自建证书或证书过期时，先改用 `http` 地址连一次确认是证书的事；较新版本的设置里有「Https 证书验证开关」，可临时关掉再连（0.8.0 加入，以官方更新日志为准）。
7. 仍连不上：删掉这条资源库重新添加一次，排除保存时的残留配置。

## 二、连上了但库里是空的

- 服务器刚建好或刚扫完媒体，等它索引完成再刷新。
- 这个账号在服务器那边**有没有该库的访问权限**——权限没给，客户端这边就是空的。
- 你添加的类型对不对：把 WebDAV 当成 Jellyfin 填，接口对不上就永远拉不到数据。类型与要填的字段对照见 [添加资源库与服务器连接教程.md](添加资源库与服务器连接教程.md) 第一节。

## 三、聚合搜索搜不到

1. 先确认目标那台服务器的连接状态是正常的（左上角切换入口里能看到）。
2. 换个更短的关键词再搜——模糊匹配对全名、半截名都认，但打错字照样没有。
3. 结果被类型过滤挡了：把过滤条件清掉再看一次。
4. 只在某一台里有内容，就切到那台里按分类浏览，聚合搜索查的是已连接的库。

## 四、播放卡顿、花屏或没声音

| 症状 | 先试这一步 |
| --- | --- |
| 卡顿、缓冲转圈 | 网络带宽不够或服务器在远端：换近一点的网络，或降低码率片源 |
| 花屏、绿屏、画面撕裂 | 设置里切换「硬件解码」开关（关、开各试一次） |
| 连接类报错、走 Http/2 失败 | 设置里关掉 Http/2 开关 |
| 没声音 | 看音轨是否切到了空轨；手机是否处于静音/勿扰 |
| 提示无法播放 / 死链 | 这条源本身失效了——Cinetry 的死链检测会把失效条目标出来，换另一台服务器的同名资源 |
| 只有 Emby 里部分片子播不出 | 较新版本对 302 直链与 Emby 兼容做过多轮优化，先升级到官方最新版复测 |

高规格片源（HDR / Dolby Vision）播不出对应效果，多半是屏幕或解码链路不支持，不是故障，说明见 [播放手势与画质字幕设置.md](播放手势与画质字幕设置.md) 第三节。

## 五、安装与升级问题

- **解析包错误**：下载不完整。核对 MD5 是否为 `CE3189EAD2392918EFBB39C794F0EA5D`，不对就重新下载（步骤在 [下载与安装教程.md](下载与安装教程.md)）。
- **签名冲突 / 安装失败**：设备上已有其他渠道的同包名版本，先卸载再装；注意卸载会清掉本地配置，服务器地址要重填。
- **版本比官网旧**：版本号只认 [官方发布页](https://github.com/gstory0404/Cinetry/releases) 当时显示的为准，网盘里这份是固定版本，需要新功能时去官方发布页拿最新安装包；较新版本还带**软件内更新**功能（Android / macOS / Windows，0.7.7 加入），设置里有更新入口就不用每次开网页。
- **系统版本不够**：网盘这份 0.5.2 记录的要求是安卓 5.2 以上；安装阶段就报错通常是系统过旧。

## 六、隐私与数据问题

- 播放记录、服务器配置、账号信息加密存在**设备本地**，不上传——所以换手机不会自动恢复，把资源库重新添加一遍即可。
- 应用不扫库：你没手动添加的数据源，它读不到；权限申请也集中在网络与存储上。
- 卸载即清空：卸载前想留住服务器地址，自己先抄下来。
