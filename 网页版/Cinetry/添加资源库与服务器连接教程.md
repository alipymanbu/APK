## 一、先明白：你得先有自己的内容来源

Cinetry 是纯本地客户端，不内置任何影视资源，也不扫你手机里的文件——它只加载你手动添加的数据源。所以第一次打开看到空列表是正常的，下一步就是把你自己已有的服务（家里的 NAS、自己搭的 Jellyfin/Emby、在用的直播源等）接进来。

你能添加的类型，按官方说明包括：

| 类型 | 你手上需要有什么 |
| --- | --- |
| Jellyfin / Emby / 飞牛影视 | 服务器地址 + 账号密码 |
| 苹果 CMS | 接口地址 |
| WebDAV / Alist / OpenList | 网盘或文件服务的地址 + 账号密码 |
| IPTV | 直播源地址（m3u 之类） |
| Subsonic / Navidrome / GD 音乐台 / audiobookshelf / 道理鱼 | 音乐服务地址 + 账号密码 |

## 二、添加资源库的入口

1. 首次打开，点界面正中的「添加资源库」；以后再加，从同一入口进。
2. 选数据源类型（上表里的一种）。
3. 填名称（自己认得出就行，比如「家里 NAS」）和服务地址，需要登录的再填账号密码。
4. 确认后，Cinetry 会做一次实时连接状态检查：连上，媒体库（电影、电视剧、音乐、图片）就会同步进列表；连不上，先记下报错，按 [常见问题与故障排查.md](常见问题与故障排查.md) 排。

地址示例长这样（按你自己的服务改）：

```text
http://192.168.1.10:8096     # Jellyfin 默认端口
https://media.example.com    # 有域名和证书的服务
```

每种类型的地址格式、Alist 要带 `/dav` 这类易错点，逐栏对照在 [资源库地址与参数怎么填.md](资源库地址与参数怎么填.md)——填之前先按那篇在浏览器里验一遍地址，能少走很多弯路。

## 三、导入现成的资源库列表

除了手动逐条添加，添加资源库页面右上角的菜单里还有一个「导入」：把别人分享给你的资源库列表地址（一个链接）和访问密码填进去，点确认，整份列表会批量进到你的资源库里。

- 导入只是替你省去逐条手填的功夫，数据源依然是**你自己填进去的地址**，Cinetry 本身仍然不提供任何内容。
- 换手机或重装后，重新走一遍导入/添加就能恢复，配置不会自动云同步（它不上传任何数据）；较新版本支持把资源库配置导出/导入成文件，以及添加夸克网盘、115 网盘作为资源库，详见 [资源库地址与参数怎么填.md](资源库地址与参数怎么填.md) 第五节。

## 四、连不上时先查这三样

添加后列表一直空着或转圈，九成是这三样之一：

1. **地址和端口**：手机和服务器是否在同一个局域网；用 IP 的时候有没有打错端口。
2. **账号密码**：区分大小写；服务器那边账号是否被禁用。
3. **协议**：`http` 和 `https` 别写反；自建证书的服务，浏览器里先能打开再说。

逐条对应的排查步骤在 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、多台服务器的保存与切换

- 每台服务器的地址和账号都会保存在本地（加密存储，不上传），下次打开不用重输。
- 界面左上角可以随时切到另一台服务器，切换时会实时显示连接状态。
- 找片时不必挨个切：[聚合搜索与切换服务器怎么用.md](聚合搜索与切换服务器怎么用.md) 里的聚合搜索会一次查完所有已连接的服务器。
- 想按用途拆库（比如「电影」「儿童动画」分开），多建几个资源库即可，首页会分类展示。
