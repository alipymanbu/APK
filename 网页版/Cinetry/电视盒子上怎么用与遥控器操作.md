## 一、先装上：TV 装的是手机版安装包

官方安装说明的做法：**电视盒子直接安装手机版的 Android 安装包**，不是另有一个 TV 专用包。步骤和手机一致（见 [下载与安装教程.md](下载与安装教程.md)），只是装的入口换成了盒子的文件管理器或 U 盘。

装完第一次打开，先按 [添加资源库与服务器连接教程.md](添加资源库与服务器连接教程.md) 把服务器加进来——在电视上输入地址比较费劲，建议先在同网络的手机上配好，再用「数据互传」或手输的方式迁移（该能力属较新版本，以官方更新日志为准）。

## 二、TV 模式开关

较新版本的设置里有「TV 模式」切换，**切换后需要重启应用才生效**（以官方更新日志当时显示为准）。进入 TV 模式后界面会按大屏与遥控器操作重排：首页、列表、焦点移动都围绕方向键设计。你装的版本设置里没有这一项，就维持默认界面，按键功能同样可用。

## 三、遥控器按键对照

按官方更新日志与使用说明整理的实际映射（不同版本略有出入，以你手上版本的操作手感为准）：

| 遥控器按键 | 作用 |
| --- | --- |
| OK（确认） | 播放 / 暂停；在列表里是进入选中项 |
| ← / → | 后退 / 快进 |
| ↑ / ↓ | 切换上一集 / 下一集 |
| 菜单键 | 显示 / 隐藏控制页 |
| 返回键 | 退回上一页 |

要点：

- 播放中按 **菜单键** 唤出控制条，再用方向键移动焦点，就能切音轨、字幕、选集。
- 剧集连播时 ↑/↓ 直接换集，不用退回列表。
- 焦点找不到时按返回退一级再进，界面焦点会回到默认位置。

## 四、电视上的找片流程

1. 首页用方向键在分类与海报间移动，确认进入详情。
2. 找特定片子用搜索：TV 端是屏幕键盘 + 方向键确认；较新版本支持联想输入（边输边出候选），以官方更新日志为准。
3. 多台服务器时，从服务器切换入口换库，或直接搜——聚合搜索一次查所有已连接的库，见 [聚合搜索与切换服务器怎么用.md](聚合搜索与切换服务器怎么用.md)。

## 五、客厅网络的两个常见坑

电视盒子大多只连 Wi-Fi，比手机更容易踩网络坑：

1. **路由器开了 AP 隔离 / 访客网络**：盒子和 NAS 被隔开，服务器地址再对也连不上——关掉隔离或让两者进同一网络。
2. **信号弱**：4K 播放对带宽敏感，卡顿时先用有线或靠近路由器复测。

逐项排查见 [常见问题与故障排查.md](常见问题与故障排查.md) 第一节；播放设置（硬解、Http/2 开关）在 [播放手势与画质字幕设置.md](播放手势与画质字幕设置.md) 第三节。
