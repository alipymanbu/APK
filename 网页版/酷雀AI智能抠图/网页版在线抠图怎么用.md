## 一、什么时候用网页版

电脑上临时抠一张图、不想在手机和文件传输上折腾，或者手头这台机器不方便装软件 —— 直接开浏览器用官方的在线工具箱 [tools.kuque.com](https://tools.kuque.com/)，功能与 App 同一套（抠图、证件照、修复、放大都在）。它是酷雀官网 [www.kuque.com](http://www.kuque.com/) 体系里的在线端，不是第三方套壳站。手机上装了 App 的场景还是走 App 更顺，见 [抠图换背景怎么用.md](抠图换背景怎么用.md)。

## 二、入口与访问限制

- **地址**：[tools.kuque.com](https://tools.kuque.com/)
- **要 PC**：官方页面明确提示「当前在线网站暂不支持移动端抠图，请访问PC端操作」—— 用手机浏览器打开会看到这条提示和「下载 APP」的引导。所以网页版只在电脑浏览器里用。
- **免安装**：打开即用，不用下载 APK；需要 App 安装包的场景（备用机、重装）见 [下载与安装教程.md](下载与安装教程.md)。

## 三、网页版上的工具清单

按官网首页的分类，各入口对应的实际用途：

| 分类 | 入口 | 你拿它做什么 |
| --- | --- | --- |
| 智能抠图 | AI智能抠图 / 人像 / 物品 / 签名 / Logo / 头部抠图 | 与 App 相同的主体分离，签名与印章走镂空处理 |
| 智能抠图 | 印章抠图 / 白底图 | 公章校徽单独抠；商品直接出白底图 |
| 证件照 | 证件照抠图 / 换背景 / 改尺寸 | 在线照相馆流程，1寸2寸换底色 |
| 智能消除 | AI消除笔 / AI去字迹 / 图片去水印 | 去遮挡物、擦手写字迹、去水印 |
| 图像美化 | AI变清晰 / AI无损放大 / AI人像美颜 | 修复模糊图、放大、人脸美化 |
| 图像处理 | AI人像修复 / 老照片修复 / 黑白照片上色 | 旧照片翻新类需求 |
| 图像处理 | 图片矫正 / 图片加水印 / 图片打光 | 拍歪的文档转正、加文字水印、调光 |

与手机端的分工可以这么记：**大批量、要传原图的活在电脑网页版做；随手拍随手修的在 App 做**。两边的会员权益是否互通，见 [会员价格与权益说明.md](会员价格与权益说明.md) 中「各端不互通」的规则 —— 网页版能否用你买的 App 会员，以下单页面与网页版登录后的实际显示为准。

## 四、网页版操作流程（以抠图为例）

1. 在电脑浏览器打开 [tools.kuque.com](https://tools.kuque.com/)；
2. 选入口（人像、物品、签名…选得准，第一次分离就干净）；
3. 上传图片 → 等自动处理 → 检查边缘；
4. 需要的话换背景、调尺寸；
5. 导出保存。**要透明底素材就导出选 PNG** —— JPG 不带透明通道，导出时会把透明区域填成白色，等于白抠。

边缘不干净的补救手段与 App 端一致，见 [抠图换背景怎么用.md](抠图换背景怎么用.md) 第四节。

## 五、官方支持的其他独立工具

酷雀体系下还有几个各自独立域名的在线工具，属于同一厂商的不同产品线，按需取用：

- 图片格式转换：[zhuanhuan.kuque.com](https://zhuanhuan.kuque.com/)（Webp/PNG/JPEG/HEIC 互转、批量处理、压缩）
- 水印工具：[shuiyin.kuque.com](https://shuiyin.kuque.com/)（去水印、加水印类需求）
- 图片无损放大：[fangda.hgs.cn](https://fangda.hgs.cn/)

这三个站与工具箱、App 的权益是否通用没有公开说明 —— 用到付费功能时以各自页面显示为准。
