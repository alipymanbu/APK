## 一、这篇解决什么问题

装好应用后，最常用的就是「把主体抠出来、换张背景」。整个流程大致是：选一张图 → AI 自动识别主体 → 几秒后出预览 → 你调整背景和构图 → 保存。下面按你实际点界面的顺序讲，每一步该选什么、抠坏了怎么补救。还没装的先看 [下载与安装教程.md](下载与安装教程.md)。

## 二、先选对入口

首页会按主体类型给你分好入口，选得准，AI 第一次就抠得干净：

| 入口 | 适合抠什么 | 备注 |
| --- | --- | --- |
| AI智能抠图 | 通用，不确定选哪个时用它 | 自动判断主体类型 |
| 人像抠图 | 单人、多人照片 | 发丝级分割是它的强项 |
| 物品抠图 | 商品、静物 | 电商白底图常用 |
| 签名抠图 | 手写签名 | 镂空笔画也能分开 |
| Logo抠图 | 品牌标志 | 纯色、渐变背景效果好 |
| 印章抠图 | 公章、图章 | 红章与底色分离 |
| 校徽抠图 | 校徽、徽章类 | 弧形边缘专用 |

选择困难就直接用 AI智能抠图 —— 它会自动识别人像、物品、商品、文字、动物、Logo 图形这几类主体，识别错了再手动换入口重来。

## 三、完整操作流程

1. **进功能页，选图**：点对应入口 → 从相册选图或现拍。支持多张的入口会允许你一次选几张做批量处理（批量是会员权益，见 [会员价格与权益说明.md](会员价格与权益说明.md)）。
2. **等自动抠图**：上传后它自动检测需要保留的主体并移除背景，官方标称 3 秒左右出图，实际耗时看图片大小与网络。
3. **检查边缘**：重点看头发丝、镂空处（如椅背、眼镜腿）、主体与背景颜色接近的区域。边缘不干净先别保存，往下看第四节的补救办法。
4. **编辑背景与构图**：出图后你可以做这些调整 ——
   - **换背景**：纯色底（白、红、蓝等）、模板背景，或上传自己的图当背景；
   - **尺寸**：按目标平台的规格裁到合适大小；
   - **裁剪 / 缩放 / 旋转**：把主体摆正、放到位。
5. **保存**：确认后导出到相册。导出的图是带透明或新背景的成品，需要特定格式时在保存前留意格式选项。

## 四、抠不干净时怎么办

- **换入口重抠**：人像用物品入口抠，边缘必然差。回上一步选对类型再来。
- **换精细模型**：更新记录里提过「增加精细抠图处理模型」，抠图页里如果有模型 / 精细度切换项，遇到复杂边缘（毛发、网格、镂空）切到更精细的那个再跑一次。
- **手动修补**：主体被抠掉一块（如深色衣服融进背景），用编辑页的涂抹 / 恢复类工具把那块涂回来；多抠出来的杂物用擦除工具去掉。
- **背景太复杂**：毛玻璃、碎花背景本身难分割 —— 先把原图放进 [图片变清晰与无损放大.md](图片变清晰与无损放大.md) 说的修复流程提高清晰度，主体轮廓更分明，再回来抠。

## 五、抠完之后能接着做什么

- **改尺寸 / DPI**：如果这张图是要交差用的（报名、店铺上架），抠完直接在尺寸与 DPI 选项里调，省得再开别的工具，详见 [图片变清晰与无损放大.md](图片变清晰与无损放大.md)。
- **做成证件照**：人像抠完想换底色当证件照，走证件照入口更省事，尺寸和底色都是预设好的，见 [证件照制作教程.md](证件照制作教程.md)。
- **加字、贴纸**：更新记录里有「增加贴纸功能、添加文字功能」，编辑页里能找到，适合做海报类的图。

一句话总结：入口选对、边缘细看、背景按用途选 —— 这三点做到了，出图基本不用返工。
