## 一、使用券：按人数买，按人选频道

YH bubble 本身免费下载，收艺人留言靠订阅。官方在商店页写的机制是：

- 你购买的是**使用券**，券的数量决定了你同时能订阅几位艺人；
- 买好券后，在应用里**用券选择要接收留言的艺人**；
- 选定后即可收到该艺人发给你的留言（功能见 [艺人留言与互动功能怎么用.md](艺人留言与互动功能怎么用.md)）。

简单说：券 = 订阅位，一位艺人占一个位。想多订一位，就得多买一张券。

## 二、价格与续费规则

官方页面给出的规则（截至 2026-09 以官方页面为准）：

| 项目 | 规则 |
| --- | --- |
| 价格 | **随购买的使用券人数变化**，具体金额在应用内 bubble 订阅页面查看 |
| 订阅期 | 1 个月 |
| 续费 | 到期后**每月自动更新（自动续费）** |
| iOS 扣款 | 通过 iTunes 订阅，费用从 iTunes 账户扣 |

也就是说这是个**按月自动续费**的订阅：不主动取消，每月到期都会再扣一次。想停就在到期日之前取消，方法见第四节。

**价格参考**：bubble 各版本同属一家公司，官方网页商店上其他版本的标价为**每位艺人每月 3.99 美元**（截至 2026-09 查 JYP / STARSHIP / STARS 版页面）；日本版是网页每月 600 日元、应用内每月 640 日元。**YH 版的具体金额以 YH 版结算页当时显示为准**，本篇不写死数字。

官方购买须知里还有几条容易踩的：

- 同一档权益的券**不能重复购买**；
- 订阅期内**不能改成另一种订阅类型**；
- **删除应用不会自动取消订阅**；
- 未成年人的购买，未经法定代理人同意的，用户或法定代理人可取消。

## 三、在哪儿买：应用内与网页商店

两条官方渠道：

1. **应用内购买**：在 YH bubble 或对应平台商店里直接订阅；
2. **官方网页商店**：[store.dearu.com](https://store.dearu.com/) → 选择 `YH bubble` 进入该版本的网页商店。

买之前有三点要留意：

- **在哪个商店买，要在同一处核对与使用**。有用户经验贴提醒：当前使用的应用与购买券的商店不是同一个时，购买的券可能与已有聊天室对不上 —— 买前确认自己用的是哪个版本、在同一个入口完成购买（单一来源说法，以官方页面为准）。
- **认准官方域名 `store.dearu.com`**。有经验贴特别指出 `weverse.io/bubble` 不是 bubble 的官方商店地址，来路不明的「低价代购」页面不要用。
- 价格与优惠以结算页显示为准，别按别人帖子里的旧价准备预算。

## 四、怎么取消续费与退款

两个概念要分开：

- **取消订阅（停续费）**：官方给出的路径是应用内 **「MY 菜单 → bubble 订阅管理」**；网页商店买的券则回网页商店的订阅管理操作。取消后**到期日当天之前仍可正常使用、不退款、当期结束后不再自动续费**。
- **退款**：取消订阅本身不给退款，退款走单独的申请流程（见下表）。

**网页商店的官方退款政策**（同系统各版本页面一致，YH 版以 YH 商店页面为准）：

| 情形 | 规则 |
| --- | --- |
| 购买 / 自动续费日起 7 天内 | 可申请全额退款 |
| 超过 7 天后中途取消 | 退款 = 扣除已使用天数金额、再扣剩余金额的 10% |
| 特殊情形一 | 买券或注册后 30 天内，除欢迎语外没收到任何艺人消息 → 可在券终止后 7 天内申请退款，申请后订阅天数重置 |
| 特殊情形二 | 艺人入伍、与经纪公司解约导致频道服务终止，且当前券已无可订阅的艺人 → 可申请退款（限使用日起 2 周内订阅的情形） |

申请方式：应用内 **「咨询 → 付款/取消」**，或发邮件到客服邮箱（YH 版为 `help_YH@dear-u.co`），需附注册邮箱、券名称、退款理由、购买时收到的付款凭证。另有官方提醒：**滥用退款政策、反复无理由申请会被限制退款或使用服务**；折扣购买的按折后价退。

应用商店（App Store / Google Play）内购买的退款按各商店自己的规则申请，与网页商店政策可能不同 —— 官方也写明「网页商店与应用商店的购买/退款政策可能不一样，付款前请确认细则」。

## 五、常见疑问

- **券买了没到账 / 艺人没出现在列表里**：先确认购买用的账号与登录应用的账号是同一个、且在同一个商店入口购买，排查步骤见 [收不到消息提醒怎么办.md](收不到消息提醒怎么办.md)。
- **换手机后订阅还在不在**：订阅跟随你登录的账号与付款渠道走 —— 新设备上用同一个邮箱账号登录即可，订阅与记录的详细口径见 [换手机后聊天记录还在吗.md](换手机后聊天记录还在吗.md)。
- **每位艺人分别收多少钱**：官方只说明「价格随人数变化」，各档位金额以订阅页当时显示为准，本篇不写死数字。
