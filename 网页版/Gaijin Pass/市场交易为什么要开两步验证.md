## 一、想在市场卖东西，账号要先过两道关

Gaijin Market 是 War Thunder、CRSED 等项目里玩家互相买卖物品的地方（战利品箱、用户涂装等），入口在游戏机库菜单 **Shop → Marketplace**，或网页版 [trade.gaijin.net](https://trade.gaijin.net/)。官方支持页写明了两条下单硬性条件：

| 条件 | 去哪补 |
| --- | --- |
| 账号邮箱已验证 | [store.gaijin.net/user.php](https://store.gaijin.net/user.php) 个人资料页 |
| 账号已开启两步验证 | 见[账号绑定与两步验证设置.md](账号绑定与两步验证设置.md)，Gaijin Pass 或 Google Authenticator 都算数 |

另外注意：市场对 **PS4、Xbox、DMM** 渠道账号不可用（截至本文检索时，以官方页面为准）；交易用专门的 Gaijin Coins 货币结算。

也就是说，装 Gaijin Pass 的动机不止「防盗号」——很多玩家是先被市场挡住了，才回头来补两步验证。

## 二、用 Gaijin Pass 补上两步验证的最短路径

1. 手机装好应用（版本与校验信息见[下载与安装教程.md](下载与安装教程.md)）；
2. 确认账号邮箱已验证、手机号已绑定；
3. 按绑定教程任选一条官方路径扫码或输激活码；
4. 绑定完成后，市场页对「两步验证」这一条的校验即满足。

绑完之后市场仍提示未开启的，先退出市场登录再重新登录一次，让状态刷新（多帖反馈这一步有效，见下节排查）。

## 三、开了两步验证，市场还是不让交易

按官方文档与官方论坛技术版里反复出现的案例，最常见的卡点按顺序排查：

1. **邮箱其实没验证**：绑定页能进不等于邮箱已验证，先去个人资料页确认邮箱状态；
2. **Steam 创建的账号没绑独立邮箱**：必须先给游戏账号绑邮箱并完成确认，两步验证才开得起来（官方对 War Thunder、Crossout、Star Conflict、CRSED 都有单独说明）；
3. **绑邮箱时提示「email in use」**：这个邮箱已经被你名下另一个 Gaijin 账号注册了——换一个没用过的邮箱，或走官方流程注销多余账号释放邮箱；
4. **确认邮件迟迟不来**：回到 **Profile → Settings → Account Protection** 重新填写邮箱再触发一次；
5. 以上都做完仍不生效：退出市场 / 商店登录后重新登录，再等一段时间重试；仍不行就走官方客服。

Steam 绑邮箱的逐步操作官方有专门文章：[War Thunder 版](https://support.gaijin.net/hc/en-us/articles/209617049)、[Crossout 版](https://support.gaijin.net/hc/en-us/articles/211959385)。

## 四、市场之外，两步验证还挡着什么

- **网页商店与论坛的部分操作**：购买、登录管理等动作在开启两步验证后会要求你输码或在 Gaijin Pass 里点确认；
- **账号会话管理**：出过异常登录的账号，除了输码还可以在网页端直接踢掉其他设备的会话，方法见[动态验证码与登录确认用法.md](动态验证码与登录确认用法.md)；
- **找不回验证码就没法交易**：市场下单依赖两步验证一直可用，所以备用码要存好——恢复路径整理在[验证码报错与换手机恢复.md](验证码报错与换手机恢复.md)。
