## 一、绑定前先检查三件事

| 检查项 | 不满足会发生什么 | 补办方式 |
| --- | --- | --- |
| 账号邮箱已确认 | 绑定页直接要求先完成邮箱验证 | 到游戏官网或 [store.gaijin.net](https://store.gaijin.net/) 个人资料页确认邮箱 |
| 已绑定手机号 | 绑定页要求先绑手机号 | 同上，在个人资料页绑定手机号 |
| 应用已安装 | 扫码后无应用可跳转 | 先完成安装，见[下载与安装教程.md](下载与安装教程.md) |

Steam 创建的账号还有一条：游戏账号本身要先绑定邮箱（在对应游戏里操作），否则开不了两步验证。

**手机号还没绑的，具体步骤是这样**（官方流程，两道验证码）：登录 [store.gaijin.net/user.php](https://store.gaijin.net/user.php) → **Settings → Account protection** → 找到手机号一项点 **Enable** 并输入号码 → 先到注册邮箱收一封确认码邮件、输入 → 再等一条短信安全码、输入 → 手机号绑定完成。

## 二、方式一：从游戏 / 商店的个人资料页绑定

这是最常见的路径，入口在网页端的个人资料页，不在手机应用里：

1. 打开 [store.gaijin.net](https://store.gaijin.net/)（或你玩的那款游戏的官网）并登录账号；
2. 进入 **Settings → Account protection（账号保护）**；
3. 选择启用 Gaijin Pass 后，页面会生成一个**二维码**；
4. 手机上打开 Gaijin Pass 扫这个码，绑定即完成，两步验证同时开启。

扫不了码也没关系：绑定页可以改走**手动激活**，页面会生成一段个人激活码，把它输入手机应用的激活界面，效果与扫码一致。

## 三、方式二：从 Gaijin Pass 官网页面绑定

不想进游戏官网操作的话，官方给 Gaijin Pass 单独做了一个绑定页：

1. 浏览器打开 [login.gaijin.net/code/](https://login.gaijin.net/code/)；
2. 用 Gaijin 账号的登录名和密码登录；
3. 页面按需向你**确认邮箱**、并要求输入**短信验证码**验证手机号；
4. 通过后页面生成二维码，用手机应用扫码完成绑定；同样支持改用手动激活码输入。

两条路径生成的绑定结果没有区别，选顺手的那条即可。

## 四、扫码失败的两个高频原因

**1. 你扫的是「第三方动态码应用」那一类的码。** Gaijin 的两步验证有两条并行方案：绑定 Gaijin Pass，或绑定 Google Authenticator 这类通用验证器。在网页绑定页选了「第三方应用」这条路之后出来的二维码，是给 Google Authenticator 那类应用扫的，拿 Gaijin Pass 去扫会提示验证码不正确。处理办法：回到绑定页改选 Gaijin Pass 方案再生成码。两种方案的区别见下节。

**2. 手机时间不准。** 动态码按时间计算，设备时间偏差会导致码对不上。Gaijin Pass 应用内自带时间同步选项，先同步再试；更系统的排查见[验证码报错与换手机恢复.md](验证码报错与换手机恢复.md)。

## 五、Gaijin Pass 与 Google Authenticator 怎么选

官方对两种方案都支持，差别在应用能做的事：

| 对比项 | Gaijin Pass | Google Authenticator 类应用 |
| --- | --- | --- |
| 动态验证码 | 有 | 有 |
| 应用内一键放行登录 | 有（点一下确认，不用抄码） | 没有，只能抄码 |
| 登录历史 / 异常登录提醒 | 应用内可见 | 没有 |
| 拦截可疑登录 | 可以直接拒 | 没有 |
| 依赖 | 需要网络时提醒才及时 | 纯离线也能出码 |

只用过通用验证器、不想换的读者，沿用 Google Authenticator 也完全可以；想要登录确认和登录记录，就用 Gaijin Pass。Google Authenticator 一路的设置流程可参考官方两步验证说明：[support.gaijin.net](https://support.gaijin.net/hc/en-us/articles/203623622)。

另外还有第三种形态——**邮箱两步验证**：对已确认邮箱、有购买记录、但一直没开两步验证的账号，官方会在新设备登录时自动启用邮箱验证码，这封通知邮件意味着什么、怎么处理，见[动态验证码与登录确认用法.md](动态验证码与登录确认用法.md)第四节。

如果你的目标是去 Gaijin Market 卖东西：两步验证本身就是市场下单的硬性门槛之一，门槛细节与「开了还是不让交易」的排查见[市场交易为什么要开两步验证.md](市场交易为什么要开两步验证.md)。

## 六、解绑与关闭

关闭入口同样在网页端个人资料页：**Settings → Account protection**，点击关闭 Gaijin Pass 的选项即可。

两点提醒：

- 关闭 Gaijin Pass 后，账号的**两步验证会一并关闭**，不会自动切到别的验证器；
- 如果应用已经删了、手机号也没了，导致网页端关闭不了，就只能走人工客服通道，具体材料清单见[验证码报错与换手机恢复.md](验证码报错与换手机恢复.md)。
