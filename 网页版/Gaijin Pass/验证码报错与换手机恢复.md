# Gaijin Pass 验证码报错与换手机恢复方法

> 本篇讲两步验证出问题时的四条官方恢复路径：码不对、有备用码、手机号还在、手机号没了，按你手头还剩什么对号入座。

## 一、码还能看到，但输入后提示不对

先做**时间同步**，这是官方文档给的第一处理法。动态验证码按设备时间计算，手机时间快了或慢了几十秒，算出来的码就是错的。

- Gaijin Pass 应用内自带**自动时间同步**选项（在安全/设置相关界面里），点一次再取码；
- 手动路径：把手机系统时间改成「自动获取网络时间」，确认时区正确，然后重新打开应用看码。

同步后仍不行的，确认你输的是**当前显示**的码（页面停留久了码会刷新），且没有把空格、顺序输错。

## 二、手头有备用码：最快的一条路

开启两步验证时，官方会给你一组**备用恢复码（reserve codes）**。如果当时存了，找回顺序是：

1. 在登录确认页点击 **「Unable to confirm log in?（无法确认登录）」** 链接；
2. 按提示输入一枚备用码；
3. 页面生成新的二维码，用手机上的验证应用重新扫——应用需要重新安装的话，先完成安装（见[下载与安装教程.md](下载与安装教程.md)）；
4. 扫不了码的设备同样支持手动激活码输入。

备用码每枚只有效一次，用掉一枚少一枚；还没用过的继续留着。

## 三、手机号还在：短信验证码重开

没存备用码、但账号绑定的手机号能收短信，走这条：

1. 登录页点击 **「Unable to confirm log in?」**；
2. 选择短信恢复，官方会把一段验证码发到绑定手机号；
3. 输入短信验证码后，页面生成新的二维码；
4. 扫码后 Gaijin Pass（或你选用的验证应用）会带着两步验证重新绑上；
5. 不能扫码时，同样会给出一段 **8 位手动激活码**，在应用里输入即可。

## 四、手机号也没了：只剩人工客服

换了号码、丢了手机、短信也收不到——到这一步就只能联系官方客服处理，入口：[support.gaijin.net](https://support.gaijin.net/hc/en-us/requests/new)。

动手提交前先确认一件事：两步验证是不是被官方自动切到了**邮箱验证码**（有确认邮箱、有购买记录的账号在新设备登录时会遇到，见[动态验证码与登录确认用法.md](动态验证码与登录确认用法.md)第四节）。是的话，验证码在邮箱里，先找邮箱服务商把邮箱找回来，往往就不用走到客服这一步。

提交工单时官方明确要求的材料按账号情况分两种：

| 账号情况 | 需要提交 |
| --- | --- |
| 账号上有购买记录 | 最近**三笔购买**的发票或支付凭证 + 常用电脑的系统信息（官方支持页有格式说明） |
| 账号没有任何购买 | 常用电脑的系统信息（主要硬件配置列出来即可） |

系统信息可以在游戏安装目录或官方支持页说明的工具里导出；材料越完整，核验越快。

## 五、还没出事的人，现在该做的三件事

1. **把备用码存到两个地方**（密码管理器 + 一份离线），它是所有恢复路径里最快的；
2. **保持绑定手机号有效**——短信恢复靠它，换号前先去个人资料页换绑；
3. **别只在一台设备上装验证应用**——手机送修、换机期间，账号还有第二条出码途径就断不了登录。换机场景的完整流程见[账号绑定与两步验证设置.md](账号绑定与两步验证设置.md)与本文第三节。
