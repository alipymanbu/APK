## 一、Security 页：三样东西都在这里

绑定完成后，应用主界面的 **Security（安全）** 页集中了最常用的三块：

| 内容 | 你能拿它做什么 |
| --- | --- |
| 动态验证码 | 在游戏登录页、官网要求输入两步验证码时，把这里当前显示的码抄过去 |
| 最近登录记录 | 查看账号最近在哪些平台、什么时间登录过，发现陌生记录立即处理 |
| 登录请求确认 | 有新登录请求时，在应用里选择放行或拒绝，不用手动抄码 |

验证码会随时间自动刷新，输入时以屏幕当前显示为准；如果输入后提示码不正确，先做时间同步（方法见[验证码报错与换手机恢复.md](验证码报错与换手机恢复.md)）。

## 二、新设备登录时，实际会发生什么

当一台没有被记住的设备登录你的 Gaijin 账号（游戏客户端、官网、商店页都算），流程是这样的：

1. 那台设备上照常输入账号密码；
2. 登录页要求补充两步验证，同时你的手机会收到请求（开了推送的话是弹窗）；
3. 请求里带着登录账号、位置、IP 等信息，你在应用里二选一：
   - **放行（ALLOW）**：点一下，那台设备即可进入；
   - **拒绝**：直接拦下这次登录，并且能在应用里看到是哪来的请求；
4. 收不到推送时，把 Security 页当前显示的动态码输入登录页，效果等同放行。

也就是说：**在你自己的常用设备上，多数时候只需要在手机上点一下**；只有推送没到位时才需要抄码。

## 三、登录记录值得定期看一眼

Security 页的登录历史是这套体系里容易被忽略的部分。建议的节奏：

- 每次收到**你自己没发起**的登录请求并拒绝后，顺手翻一下历史，确认没有已经混进去的会话；
- 隔一两周扫一眼最近登录的平台与地点，陌生 IP 出现就改密码并检查绑定状态。

发现账号有异常登录迹象时的处理顺序：先在应用里拒绝该请求，再改密码，再核对两步验证是否仍然开启（状态在网页端个人资料页可见）。

## 四、News 页：把项目新闻收进一个应用

News 页是 Gaijin Pass 的另一半功能：订阅 War Thunder、Crossout、Enlisted 等项目的新闻后，更新公告、商店活动、开发进展会推送到这一个应用里，不用再去各项目官网翻。

- 订阅入口在 News 页内，按项目勾选即可；
- 通知粒度在 Settings 的通知项里调，可以只留安全请求、关掉资讯推送，或反过来；
- 注意**新闻与邮件通知只有 9 种语言**（英、德、法、西、俄、波、捷、葡、土），没有中文——这也是很多读者觉得「新闻看不懂」的原因，界面语言与新闻语言是两个独立设置，详见[中文设置与界面语言调整.md](中文设置与界面语言调整.md)。

## 五、Settings 页：三件可以马上做的事

| 设置项 | 建议 |
| --- | --- |
| 推送通知（PUSH） | 保持开启——登录确认依赖它，关了之后只能靠抄码 |
| 应用语言 | 界面可切简体中文，见[中文设置与界面语言调整.md](中文设置与界面语言调整.md) |
| Feedback（反馈） | 应用卡顿、异常时的官方反馈入口 |

遇到应用打不开、主界面一直加载的情况，先检查手机网络（登录提醒依赖网络连接），重启应用多数能恢复；有用户反馈过个别版本会出现主界面加载卡住的情况，若重启无效可等下一版更新或通过 Feedback 反馈。
