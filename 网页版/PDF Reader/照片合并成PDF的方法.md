# KDAN PDF（PDF Reader）照片合并成PDF的方法

> 本篇讲怎么用手机把拍下来的多张照片合成一个多页 PDF——这条路径在免费版就能走通。

## 一、适用场景

拍照留档的纸质文件——合同每页一张照片、报销发票一把、白板与手写笔记——零散图片既不好转发也不好打印。合成一个 PDF 后可以整体发送、继续批注与签名、统一归档。

## 二、把照片合成一个 PDF（官方博客给出的安卓步骤）

1. 打开应用，在首页点 **Create PDF**（创建 PDF）；
2. 选 **Import Images**（导入图片），从相册一次选多张——每张照片会成为新的一页；
3. 拖动缩略图调整页序；
4. 确认生成，得到一个多页 PDF。

两个补充：

- 想要一个空白 PDF 来拼模板、做封面或目录，同一入口里选 **Create Blank PDF**；
- 官方博客在与其他编辑器对比时说明，免费版导出**不强制加水印**——同类应用里不少免费版转出来的文件都盖着水印，这一点容易当成缺陷误会它。

## 三、往已有的 PDF 里补页

拍完发现漏了一页、或想把新照片接进旧文件，走页面编辑模式（订阅功能）：

1. 打开目标 PDF，从工具栏进入「页面编辑（Page Edit）」视图；
2. 在要插入的位置**勾选那一页**——新内容会插在它后面；
3. 点底部的 **Append**（附加）；
4. 选来源：**From PDF**（从另一份 PDF，可选全部页或指定页码范围）或 **From Images**（从相册选图片）；
5. 确认后，新页出现在勾选页之后。

还没订阅、只想把新一批照片归档的话，用第二节的方法对整批图片重新生成一个新文件即可——「从图片生成」免费，「改已有文件的页面」才是订阅档（差异见 [免费版与订阅版功能对比.md](免费版与订阅版功能对比.md)）。

## 四、拍照质量决定后面每一步

- 光线均匀、纸面平整、四角拍全，后面无论是打印还是 OCR 都省事；
- 每页一张照片、对齐边框拍，比斜着拍一整份再裁剪省力得多；
- 生成后想让「字能搜索、能复制」，需要对文件跑 OCR（订阅功能，做法见 [格式转换与页面管理方法.md](格式转换与页面管理方法.md)）；
- 想在生成的文件上签字、盖章，做法见 [注释与签名操作指南.md](注释与签名操作指南.md)。
