## 一、四种读法怎么选

| 模式 | 适合 |
| --- | --- |
| 垂直滚动 | 默认方式，通读报告、长文 |
| 水平滚动 | 横版幻灯片、漫画式排版 |
| Text Reflow | 小屏手机看纯文字长文：提取正文重排成单栏，字号随你调 |
| 幻灯片模式 | 逐页翻着讲（订阅功能） |

小屏手机上字号偏小的论文类 PDF，优先试 Text Reflow；但重排会丢原排版，表格、公式会乱，看这类文件切回原版式。跳到指定页与全文搜索在阅读菜单里；书签、大纲、缩略图三种导航各有入口，长文档先看大纲定位最快。

## 二、语音朗读

- 订阅版有整篇朗读（文本转语音），通勤时「听」文档用；
- 免费版在 Text Reflow 模式下也有文字转语音的入口（应用商店的功能描述写明限于该模式），与你手上版本的实际表现可能不同，以点开后的提示为准；
- 朗读效果取决于系统 TTS 引擎，中文朗读前先到系统设置确认装了中文语音包。

## 三、常见问题

### 3.1 打不开某个 PDF

按顺序排查：

1. 文件没传完整——重新下载/复制一次，对比文件大小与来源处是否一致；
2. 文件本身损坏——换台设备或用电脑打开同一份验证；
3. 加密 PDF——带打开密码的会先弹密码框；只有权限密码（禁止复制打印）的文件能打开，但部分操作受限；
4. 格式不识别——除 PDF 外，应用也支持 TXT、ePub 与常见图片格式；docx/xlsx 这类要先转成 PDF，或用对应的应用打开。

### 3.2 文件从哪里导入

应用内的导入入口支持本机文件夹、云盘账号、邮件附件「用其他应用打开」等方式。最省事的路径：手机连电脑把 PDF 直接拷进 Download 目录，再在应用里从本地文件夹访问——应用能读到本机的文件夹。

### 3.3 卸载或换机会不会丢东西

文档与已保存的批注都在 PDF 文件本身里，把文件拷走，批注就跟着走；阅读进度这类应用内状态不跟随，卸载重装后会回到初始。换机迁移整库文件，直接把文档文件夹整体拷到新机即可；跨设备云同步是订阅权益，登录同一 KDAN ID 生效。

### 3.4 账号长期没登录，要求重置密码

官方在 2026 年 8 月的版本更新中加入了一条安全策略：账号闲置 180 天后再次登录会要求重置密码。按流程走即可，不是被盗号；遇到收不到重置邮件，检查垃圾箱或换网络再试。

### 3.5 编辑、转换之后找不到结果文件

转换、压缩这类操作默认不覆盖原文件，而是生成新文件（同名或带后缀），在文件列表按修改时间排序找最新的那个；操作时留意弹出框里的保存路径提示。
