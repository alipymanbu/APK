## 一、先确认你的版本能不能转

转换、页面管理、OCR 全部属于 Document 365 订阅范围，免费版点这些功能会直接弹出订阅提示。免费方案能做的只有反向那一步：把图片、网页、剪贴板内容**生成** PDF。档位差异见 [免费版与订阅版功能对比.md](免费版与订阅版功能对比.md)。

## 二、PDF 转 Word / Excel / PowerPoint

典型场景：拿到一份只有 PDF 版的合同或报表，要改数字、复制表格。

1. 在文件列表里选中目标 PDF，或在阅读界面从工具/更多菜单进入转换功能；
2. 选择「转换为 Word / Excel / PowerPoint」；
3. 等转换完成，结果一般生成为同名的新文件，再决定是编辑后另存，还是直接回传 PDF。

两点预期管理：

- 转换质量取决于原 PDF 的结构。文字版 PDF 转出来接近原样；扫描件转出来是整页图片贴进 Word，改不了字——那是 OCR 的活（下一节）；
- 复杂排版（多栏、艺术字、嵌套表格）转完多数要手动调格式，预算这一点时间。

## 三、扫描件 OCR：把图片变成可搜索的文字

OCR 解决的是「扫描件/照片里的字没法选中和搜索」的问题。官方标注支持 50 多种语言的识别。

1. 打开扫描版 PDF，进入 OCR 功能；
2. **选对源语言**是识别率的关键：中文文件选中文，混排文件选对应组合；
3. 转换后得到可搜索、可编辑的新文档。

识别率上限由扫描质量决定：倾斜、模糊、分辨率过低的页面，先想办法重扫或拍清楚再转。

## 四、页面增删与合并拆分

这一组操作在页面管理入口里做，缩略图模式下最直观：

| 想做的事 | 怎么做 |
| --- | --- |
| 删掉某几页 | 缩略图选中 → 删除 |
| 抽出某几页单独存 | 选中 → 提取 |
| 把另一份 PDF 的页面接到后面 | 页面编辑视图勾选目标页 → 底部 **Append** → **From PDF**，可选全部页或指定页码范围 |
| 把相册图片插为新页 | 同上，**Append** → **From Images**，从相册多选 |
| 多份合成一份 | 新建合并，依次加入文件 |
| 一份按区间拆成多份 | 选中区间 → 拆分 |
| 页面顺序乱了 | 缩略图拖动重排 |
| 横竖颠倒 | 选中 → 旋转 |

官方安卓支持文档对 Append 的口径是：新内容插在**你勾选的那一页之后**，From PDF 支持「全部页」或「指定页码范围」两种选法。

顺带说明两个方向的区别：上面这些改已有文件的页面操作是订阅档；手里只有一堆照片、想从零合成一个多页 PDF 的，走 [照片合并成PDF的方法.md](照片合并成PDF的方法.md) 那条路径，免费版就能完成。

合同类文件处理完建议做一次平面化（Flatten），把表单域与批注层固定进页面，避免后续软件对层的兼容问题。

## 五、加密、水印与压缩

- **密码加密**：设置打开密码；禁止复制/打印是另一道权限密码，可以单独设；
- **水印**：加文字或图片水印，也可以移除自己加的；
- **压缩**：邮件附件超限时先压缩一份再发；扫描件压缩率高，纯文字文件压不出多少空间；
- **平面化**：把表单域、批注层固定进页面，之后不可再单独编辑这些层。

## 六、手机上做这些操作的边界

屏幕小、文件大时，页面拖动排序这类操作在平板或电脑上做效率高得多——订阅权益用同一个 KDAN ID 登录就能在 Windows/Mac 端使用。几十 MB 以上的大文件转换，放着让它转完，别中途杀后台；转换中断了重跑一次即可，原文件不会被覆盖。
