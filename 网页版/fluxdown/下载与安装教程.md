FluxDown 是一款免费开源的多协议下载器，由 zerx-lab 开发，代码以 AGPL-3.0 协议开源。搜索时常见小写 `fluxdown` 的写法，指同一个应用。它同时有 Windows、macOS、Linux、NAS 版本，本套文档对应的是安卓手机版。

## 二、安装步骤

1. 打开上面的网盘链接，把 APK 转存到自己的夸克网盘，再用夸克 App 或网页版下载到手机；
2. 在手机文件管理里点开下载好的 APK，系统提示「禁止安装未知来源应用」时选择仍要安装，并在跳出的设置页里允许夸克（或你的文件管理器）安装应用；
3. 回到安装页继续，等待安装完成；
4. 首次打开 FluxDown，按提示授予存储权限——没有这个权限，下载的文件存不进本地目录。

官方发布渠道里，安卓包同时提供 arm64-v8a、armeabi-v7a、x86_64 分架构版本与通用版；不确定自己机型该用哪个时，选通用版即可。

## 三、认准官方渠道，避开仿冒站

FluxDown 的官方渠道只有两个：

- 官网：[https://fluxdown.zerx.dev](https://fluxdown.zerx.dev)（中文内容在 `/zh/` 路径下）
- GitHub 仓库：[https://github.com/zerx-lab/FluxDown](https://github.com/zerx-lab/FluxDown)

2026 年 7 月开发者在 V2EX 社区提醒：当时出现了仿冒官网 `fluxdown.com.cn`，分发的是带木马的假安装包（银狐木马的仿冒手法），官方站点会针对它弹出警告条。从搜索引擎找下载源时看清域名，别进这类高仿站。

想核对拿到的包有没有被掉包，可以在电脑上对 APK 算一次 MD5，与第一节表格里的值比对：

```powershell
certutil -hashfile "fluxdown_v0.2.3.apk" MD5
```

一致就说明是这一版的原包。

## 四、安装失败时先查这几处

| 现象 | 常见原因与处理 |
|---|---|
| 提示「安装包解析失败」 | 文件没下完整，重新下载一次；或核对 MD5 是否一致 |
| 提示「与已安装应用冲突」 | 手机里有同包名的旧版本且签名不同，先卸载旧版再装 |
| 点了没反应 | 存储空间不足，清理后重试 |
| 装好打不开或闪退 | 重新授予权限、重启手机再试；仍不行说明该版本与机型不兼容，换官方新版 |

已下载完成的文件保存在公共目录（如 Download）里，卸载 FluxDown 本体不会删掉它们；但任务列表、下载记录这类应用内数据会随卸载清空。

装好后第一步是往里添加任务，见[添加下载任务的几种方式.md](添加下载任务的几种方式.md)；下载速度不理想的话，直接翻[下载速度慢的原因与提速方法.md](下载速度慢的原因与提速方法.md)。
