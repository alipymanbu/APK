## 一、两种添加方式

**磁力链接**：在资源页复制 `magnet:?xt=urn:btih:…` 开头的整条链接，按[添加下载任务的几种方式.md](添加下载任务的几种方式.md)里的步骤粘贴新建即可，FluxDown 会自动按 BT 任务处理。

**种子文件**：把 `.torrent` 文件存到手机里，在新建任务入口选择本地文件添加。种子里记录了资源的节点与文件结构信息，效果和磁力一样，只是来源形式不同。

**挑着下**：种子包含多个文件时，可以只勾选要的那几个，不必把整包附属文件都拉下来（入口以你手上的版本界面为准）。

## 二、磁力没速度，多半是这几种情况

BT 下载的原理是「从其他正在下载或已下载完的人那里拿数据」，所以速度不取决于你的网有多快，而取决于这条资源有没有人在做种：

| 现象 | 原因 | 能做的事 |
|---|---|---|
| 长时间 0%，连元数据都拿不到 | 在线做种的人太少或为 0 | 换热门资源验证流程；这条资源无解 |
| 开始很慢，几分钟后起来 | DHT 网络找节点需要暖机时间 | 等一等，别急着删任务重加 |
| 速度忽高忽低 | 各个源的上线时间不一致 | 挂着，BT 任务靠时间熬 |
| 完全连不上 | 运营商或网络环境限制了 BT 流量 | 换 WiFi 与移动数据对比测试 |
| 能看到 peer 数但速度一直是 0 | 路由器没做端口映射，别人连不进你的 NAT | 见下文第三节的端口打通 |

## 三、几个能提高连速的抓手

1. **补充公共 Tracker**：Tracker 是帮 BT 客户端互相认识的介绍人。FluxDown 内置了一批公共 Tracker，也支持在设置里手动添加，多加几条常用公共 Tracker 能明显提高找到节点的几率。常用的公共 Tracker 例如 `udp://tracker.opentrackr.org:1337/announce`、`udp://open.tracker.cl:1337/announce`——这类地址时效性强，会失效，以网上维护中的公共 Tracker 列表为准；
2. **打通端口**：BT 建连的规律是双方至少有一方端口可达。路由器开着 UPnP 时，客户端能自动映射端口；无公网 IP 的网络环境对 BT 的限制所有客户端都一样（开发者本人在社区里答复过这一点），社区常见的反馈是 IPv6 网络下能连的资源更多、速度更好；
3. **保持应用在线**：安卓的后台清理会掐断 BT 连接，把 FluxDown 加进电池白名单或后台保护名单，下载期间别用一键清理；
4. **先拿热门资源试**：想验证流程是否走通，用一条做种数多的热门资源比冷门资源靠谱得多。

另有一类私有 Tracker（PT 站）只允许指定客户端接入，用其他客户端下载可能没速度、甚至违反站点规则导致封号——下 PT 资源前先看站点的客户端白名单规定。

## 四、eD2K 电驴链接

官方列出的支持协议里包含 eD2K（电驴）链接，桌面端可以直接添加；手机端这个协议的入口以你手上的版本界面为准。如果粘贴 `ed2k://` 链接没有被识别，说明该版本移动端还没放开这个协议，等更新或改用桌面版。

磁力任务速度上不去时，先排除资源本身没源的问题，再看[下载速度慢的原因与提速方法.md](下载速度慢的原因与提速方法.md)里其他层面的排查。
