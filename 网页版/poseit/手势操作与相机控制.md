## 一、先弄清「选没选中」

Poseit 的所有手势都先看你**当前有没有选中人偶部位**，这是它整套操作的总开关：

- **什么都没选中时**：手势全部作用于相机（转视角、平移、缩放），人偶纹丝不动。
- **选中某个部位时**：手势改为扭转这个部位；此时点空白处可取消选择、关掉弹出的菜单。

所以第一件事是「点人偶身上选中它，点空白处取消」。掌握这个节奏，后面的手势才不会串台。

## 二、相机三手势（未选中状态）

| 手势 | 作用 |
| --- | --- |
| 单指拖动 | 转动相机方向（绕场景环视） |
| 双指拖动 | 平移相机（画面平行移动） |
| 捏合 / 张开 | 缩放视图（拉近、推远） |

想从背面、俯视等刁钻角度观察姿势，全靠这三个手势反复切换。相机本身也有「自由 / 受限」模式的区别：把相机旋转设为自由模式后，双指扭转可以对整个场景做同样操作，见下一节。

## 三、调整姿势的核心手势

1. **点选身体部位**：点人偶的头、肩、手臂、腿等处，点到哪选哪。腰部（胯部）是整个人偶的重心，选中它拖动 = 整个模型转身。
2. **单指拖动 = 屏幕空间旋转**：选中部位后，单指在屏幕上任意位置拖动即可扭转该部位——所有调整都基于你当前的视角方向，**不必从原起点开始拖**，在屏幕空白处下手也行。这是 Poseit 最核心的「屏幕空间旋转」玩法，转相机到顺手的角度再拖，比死磕一个视角快得多。
3. **两指扭转（twist）**：选中部位后两指像拧毛巾一样拖动，让部位沿视图方向扭曲；把相机旋转设为自由模式，还能对整个场景做同样操作。
4. **双指拖动平移（gizmo）**：当选中的部位上出现带小箭头的操纵杆（gizmo），用两指拖动即可把该部位平移到别处，而不是原地转角度。
5. **父部位联动**：比如选手这样的末端部位，单指拖只动手本身；改成两指捻动，手、前臂、上臂会连着一起动——要摆自然的姿势，优先用这个手法。

## 四、锁定：让不想动的部位别跟着跑

画面左侧有一个钥匙形状的按钮，作用是**锁定选中部位的朝向**：

- 选中某个部位（比如头），点钥匙按钮 → 该部位被锁住。
- 之后再去拖上半身、转躯干，别的部位跟着走，被锁住的头部朝向保持不变。

实际摆姿势时经常是「先锁头，再扭身体」，这样眼睛视线不会被躯干的调整带跑。反过来，手脚这类要精确到位的部位，也常靠锁定把已经摆好的一端固定住，再慢慢调另一端。

## 五、常用操作速查

| 想做什么 | 怎么做 |
| --- | --- |
| 环视 / 平移 / 缩放场景 | 未选中时：单指拖 / 双指拖 / 捏合 |
| 选中一个部位 | 直接点它 |
| 取消选择、关菜单 | 点空白处 |
| 扭转选中部位 | 单指拖（任意位置起手） |
| 沿视线方向扭曲 | 两指拧 |
| 平移选中部位 | 出现 gizmo 后两指拖 |
| 转整个模型 | 选中腰部后单指拖 |
| 移动整个模型 | 选中腰部后双指拖 |
| 固定某部位朝向 | 选中后点左侧钥匙按钮 |
