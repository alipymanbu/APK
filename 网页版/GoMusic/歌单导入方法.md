## 一、入口在「收藏夹」

底部导航进「收藏夹」，里面有输入歌单 ID 的入口。GoMusic 不要求你登录音乐平台的账号，只要一个歌单 ID 就能把整份歌单拉进来。

## 二、歌单 ID 怎么取

以网易云音乐为例：

1. 手机上打开网易云 App，进到目标歌单页；
2. 点右上角「分享」→ 复制链接；
3. 把链接粘贴出来看一眼，`id=` 后面那串数字就是歌单 ID，比如 `https://music.163.com/playlist?id=12345678` 里的 `12345678`。

网页版网易云同样适用：浏览器打开歌单页，地址栏里 `id=` 后面的数字就是。

## 三、导入步骤

1. 复制好歌单 ID；
2. 回到 GoMusic，进「收藏夹」，点导入入口；
3. 粘贴 ID，确认导入；
4. 等列表加载完，歌单内容就存在软件内了，可以整份播放，也可以把里面的歌再收进自己的收藏。

导入之后的播放、收藏操作见 [新手上手与播放操作.md](新手上手与播放操作.md)。

## 四、导入失败常见原因

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 提示 ID 无效 | 复制到的是歌单名或整段文字 | 只填纯数字的 ID，前后别带空格 |
| 列表加载不出来 | 歌单被设为「仅自己可见」 | 把歌单改成公开，或换一份公开歌单试 |
| 部分歌曲灰掉或缺失 | 平台侧下架、版权变动 | 软件内补不回来，可以单独搜歌名替代 |
| 一直转圈 | 网络波动 | 换个网络重试；反复失败先随便搜首歌验证网络通不通 |

以上是常见情形的归纳，具体提示以你手上的版本实际显示为准。

## 五、想去 Apple Music / Spotify：那是另一款同名工具

把网易云歌单搬到国际平台这件事，GoMusic 播放器本身不做——它管的是把歌单导进来自己听。跨平台搬家用的是同名的开源网页工具（GitHub 上的 `https://github.com/Bistutu/GoMusic`），它把歌单解析成通用清单，再交给迁移网站完成搬家，用法见 [同名软件区分与歌单迁移工具.md](同名软件区分与歌单迁移工具.md)。
