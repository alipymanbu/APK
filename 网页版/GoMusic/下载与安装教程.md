## 一、先确认：你要装的是哪款 GoMusic

叫「GoMusic」的软件不止一个，装错了名字就对不上本文说的功能。先按特征分清楚：

| 名称 | 形态 | 识别特征 | 与本篇的关系 |
| --- | --- | --- | --- |
| GoMusic（本文主角） | 安卓 App，中文界面 | 版本 1.0，包名 `com.gomusic.zixtty`，安装包约 20.65M | 就是它 |
| GO Music（GOMO Live） | 安卓 App | 走 Google Play 分发的国际版播放器，版本号 4.x，界面偏英文 | 不是同一款 |
| gomusic（GitHub 开源） | 电脑终端工具 | 跑在 Linux/macOS 命令行里，用来连 YouTube Music | 与手机无关 |
| GoMusic（开源歌单迁移工具） | 网页工具 | 把网易云/QQ 音乐歌单解析成文本清单，配合迁移网站搬到 Apple/YouTube/Spotify | 在浏览器里用、不装 App，用法见 [同名软件区分与歌单迁移工具.md](同名软件区分与歌单迁移工具.md) |

最省事的判断办法：对安装包大小（约 20.65M）和包名 `com.gomusic.zixtty`，对得上就是本文说的这款。

## 二、安装包基本信息

下面这些取自这份安装包本身的记录。网上搜到的「最新版」版本号可能不一样，以你手上的安装包为准：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0 |
| 包名 | `com.gomusic.zixtty` |
| 安装包大小 | 20.65 MB |
| MD5 | `BAFC747FFA1FD7A178120B0986FADB08` |
| 系统要求 | Android 5.2 及以上（按安装包信息标注） |
| 界面语言 | 中文 |

MD5 可以用来核对文件是否完整：把下载好的 APK 算一次 MD5，与上表一致说明文件没在传输中损坏。Windows 自带校验命令，在 PowerShell 或 cmd 里执行（把文件名换成你下载到的 APK 实际文件名）：

```powershell
certutil -hashfile GoMusic_v1.0.apk MD5
```

手机上不少文件管理器也带「文件校验」功能，作用相同。

## 三、拿到安装包

安装包放在夸克网盘里：[GoMusic 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cda589d1a0ef)。

1. 手机或电脑打开上面的链接；
2. 登录夸克账号后选「转存」，把资源存进自己的网盘；
3. 在网盘里找到 APK 文件，下载到手机存储。

## 四、允许安装未知来源应用

这个 APK 不从应用商店来，安卓默认会拦一次。你需要给「负责下载/打开 APK 的那个应用」授一次权：

- Android 8 及以上：设置 → 应用管理 → 特殊应用权限 → 安装未知应用，找到你用来下载或打开 APK 的应用（浏览器、夸克、文件管理器），打开「允许安装未知应用」；
- 不同品牌的路径有差异：小米在「应用设置」、华为在「安全 → 更多安全设置」附近，设置里直接搜「未知」两个字最快；
- 装完之后可以把开关关回去，不影响已经装好的 GoMusic。

## 五、安装与首次启动

1. 在文件管理器里点开下载好的 APK，选「安装」；
2. 弹出安全提示时选「仍然安装」；
3. 装完点「打开」，进到首页就是一个搜索框，直接输歌名就能开始用。

装好之后从哪下手：日常搜歌、播放、看歌词的步骤在 [新手上手与播放操作.md](新手上手与播放操作.md)；想把网易云的歌单整批搬进来，看 [歌单导入方法.md](歌单导入方法.md)。

安装被拦截、装完打不开这类情况，去 [常见问题排查.md](常见问题排查.md) 对着现象处理。
