# Yeelight 灯光效果与场景怎么用

> 本篇讲进到某盏灯的控制页之后能做的几件事：调光、彩光、流光、把喜欢的效果收藏起来、自己编一套动态灯光，以及把多盏灯编成情境和房间。

灯配好网之后，日常用得最多的就是控制页：亮度、色温、颜色、动态效果。本篇按「单灯能调什么 → 怎么把自己调好的效果留下来 → 怎么让多盏灯一起变」三层讲，都是官方说明里给过的操作，不涉及别的花样。

## 一、智能调光页：进来先看这几项

在「设备」页点一下某盏灯，就进到它的控制页，官方把这个页面叫「智能调光」，里面预置了六种灯光效果模式，不想自己调的时候点其中一个直接用。

不同灯的调节档次不一样，先分清两类：

| 灯的类型 | 能调什么 |
| --- | --- |
| 只有亮度的灯（白色灯泡、部分灯带） | 开关、亮度 |
| 可调光调色的灯（彩光灯泡、氛围灯一类） | 开关、亮度、色温、颜色、动态效果 |

灯具体支持到哪一档，以它控制页上实际出现的选项为准——页面上没有的选项，就是这盏灯不支持，不用去别处找。

## 二、彩光与流光

- **彩光**：进「彩光」设置页，拖动调色盘上的圆圈，灯的色相跟着变；
- **流光**：让颜色循环流动起来。官方说明里支持设置四种流光色彩，另外能单独调流光的速度，以及这盏灯当时的亮度。

各调一次就能直观判断你手上这盏灯是单色灯还是彩光灯。

## 三、把调好的效果收藏起来

点页面中间那个「收藏」图标，可以把当前这组「彩光」或「流光」设置存进「我的最爱」。下次不用重新拖一遍调色盘，从收藏里点出来即可。

常用的两三组存下来之后，日常基本就不用再进调色盘了。

## 四、自己编一套动态灯光

官方管这个叫「个性化灯光」，做法是把一串「帧」按顺序排出来播放：

1. 进「设置 → 个性化灯光」，先给这套效果起个名字；
2. 设置**执行次数**，以及循环结束之后停在什么状态（停在某个亮度、或者回到白光）；
3. 用「增加帧数」往序列里加帧，可用的有四类：
   - **亮度值**：只改亮度；
   - **色彩帧**：指定这一帧的颜色与亮度；
   - **色温帧**：指定这一帧的冷暖；
   - **暂停帧**：停顿一段时间；
4. 每一帧都能单独设执行时长，加完可以先预览，满意了再保存。

需要连续变化的场合（呼吸、渐变、闪烁提示）用它省事：它能把「变到哪、变多快、变几次、最后停在哪」一次说清，不用手动掐着时间点。

## 五、情境：一次控制多盏灯

「情境」是把自己选的若干盏灯和它们各自的状态打包成一个按钮。做法是在情境管理页点「建立情境」，选一个情境图标、起好名字，然后挑灯、逐盏设定亮度颜色，点完成。

之后切情境就是一个动作，比一盏一盏调快得多。一个房间里灯光角色比较固定的话（看书、看电影、起夜），值不值得建这几个情境，用一两次就知道了。

## 六、房间：按空间成组管理

灯一多，设备列表会变成一长串。把灯归到房间里之后：

- 点房间那一条，可以**对这个房间里的灯一起开关、一起调亮度**；
- 点房间里的「增加设备+」，能把灯补进这个房间；
- 在房间那一条上向左滑，能直接设延时关灯，也能删掉这个房间的设置。

房间和情境解决的是两件事：房间是「位置分组」，情境是「状态打包」。想让某一组灯在固定时间自动切换，见 [定时任务与音乐律动怎么设置.md](定时任务与音乐律动怎么设置.md)；想用语音或别的智能家居平台来控制这些灯，见 [语音助手与HomeKit怎么接入.md](语音助手与HomeKit怎么接入.md)。
