智能灯和普通灯最大的差别，在于它自己就是一台联网设备。所以墙上的开关、家里的宽带、灯的安装位置，都会直接影响你在 App 里看到什么。本篇把这几件事集中讲一遍——都是官方说明里零散提过、但很少有人串起来的地方。

## 一、从墙上开关关灯之后会发生什么

你按墙上开关把灯关掉，等于**把这台联网设备断电了**：

- 这段时间里 App 里这盏灯会显示离线，手机上控制不了，语音助手也叫不动它，定时任务同样不会执行；
- 再把墙开关打开，灯重新上电后会自己连回 Wi-Fi。官方在社区回复里的说法是：这样开关不会弄坏灯，**只是别连着开关 5 次**——那个动作是重置设备的信号，见 [添加设备与配网.md](添加设备与配网.md)。

所以想让灯一直可控，做法是：**墙上的开关保持常开，日常开关都走 App、语音，或者灯具自带的遥控**。习惯按墙开关的人，最常见的抱怨就是「手机上老是显示离线」，原因往往就在这里。

如果你确实想保留墙上手动开关的手感、又不想让灯掉线，官方另有一条路径：Yeelight 的无线智能调光开关，用蓝牙遥控，**不直接切断灯的供电**，让灯保持在线。官方标注它兼容 Yeelight 智能吸顶灯系列、水晶吊灯和智能窗帘电机，**不兼容灯泡与台灯**，买之前先对一下自己灯的类型。

## 二、家里断网了会怎样

| 断的是哪一段 | 灯这边还能做什么 |
| --- | --- |
| 宽带断了，路由器本身还在通电 | 墙上开关照常用；手机 App 和语音助手都控不了 |
| 路由器也断电了 | 墙上开关照常用；无线遥控类配件通常也还能用，因为它走的是本地蓝牙 |
| 只是手机没连上家里这个 Wi-Fi | 换回家里 Wi-Fi 就能控；在外网想控，前提是家里网络正常 |

一句话：**断网不等于灯坏，只是「聪明」的那部分暂时停工**。拿手机试半天没反应的时候，先看一眼家里网络是不是断了。

## 三、一个高频误操作：连着开关灯

连续开关灯 5 次（每次开约 2 秒、关约 2 秒）是官方定义的重置动作。它的本意是给「刚接手的旧灯」恢复出厂，但也很容易被误触发：

- 跳闸、闪断、来回拉几次开关之后，灯有可能自己进了重置状态，表现为 App 里认不到、需要重新添加；
- 一旦真的被重置，配网信息、房间、名字这类设置都会清掉，只能重加一遍。

排查「灯怎么突然在 App 里不见了」的时候，先回想一下最近有没有反复开关过它的电源。

## 四、装灯位置与灯具选择上的坑

官方在产品说明里列过几条与安装相关的注意，值得在动手前看一眼：

| 注意项 | 原因 |
| --- | --- |
| 不要装在**带调光旋钮**的灯具或灯座上 | 官方明确写了可能损坏产品 |
| 不建议装在**狭小密封的桶状灯罩**里 | 信号和散热都会受影响，装了也容易掉线 |
| 不要用在**潮湿环境** | 产品自身的适用条件限制 |
| 安装、拆卸、检查灯具时**先断电** | 安全要求 |

另外两条与「够不够用」相关的官方口径，也一并放在这里：

- **灯到路由器的距离**：官方给吸顶灯的口径是 **30 米以内、无遮挡**；隔了承重墙、遇上金属吊顶就会明显缩水；
- **一台手机能带几盏灯**：官方说法是**没有数量限制**，一盏灯也支持被多部手机控制；实际能带多少取决于你家路由器的 Wi-Fi 并发能力，灯一多先看路由器。

## 五、这套用法里的取舍

把上面的内容合起来其实是一句话：**智能灯越是保持通电、离路由器近、离干扰源远，它就越稳**。反过来，如果你习惯用墙开关管灯、灯装在不透信号的金属罩里、路由器又塞在弱电箱最里层，那它在 App 里时不时离线就是正常结果，不是产品坏了。

判定方法也简单：把灯挪近路由器、墙开关保持常开，观察一两天。状态明显变好 → 是环境问题；照旧 → 按 [配网失败与设备离线排查.md](配网失败与设备离线排查.md) 逐条查。
