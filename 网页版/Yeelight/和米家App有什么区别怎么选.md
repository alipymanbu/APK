# Yeelight 和米家 App 有什么区别怎么选

> 本篇讲清 Yeelight App、米家 App、Yeelight Pro、Yeelight Station 这几套控制端分别管什么，登录用的是哪个账号，以及你手上这批灯该用哪一个。

同一批灯，用 Yeelight App 还是米家 App 控制，是买回来最先要定的一件事。这一篇把几套容易搞混的控制端分开讲，说明各自的定位、账号关系，以及为什么建议定下一个就别来回切。网盘里那份就是 Yeelight 官方 App 的安卓安装包，装法见 [下载与安装教程.md](下载与安装教程.md)。

## 一、先分清四个名字

| 名字 | 是什么 | 管什么设备 |
| --- | --- | --- |
| **Yeelight App** | 易来官方的手机控制端，安卓包名 `com.yeelight.cherry` | 易来消费级智能灯——灯泡、灯带、吸顶灯、台灯、氛围灯这一批 |
| **米家 App** | 小米的智能家居总入口 | 米家生态下的各类设备，Yeelight 的灯是其中一类 |
| **Yeelight Pro** | 面向易来 Pro 全屋灯光系统的另一套 App | Pro 系列的网关、灯具、开关、传感器这套体系 |
| **Yeelight Station** | 电脑端程序，官方标注 Windows 8 及以上、暂不支持 macOS | 官方列出的少数型号，以官方页面为准 |

四者不是同一个东西的不同版本，装错了打不开自己的设备很正常。

## 二、账号：都是小米账号

Yeelight App 官方隐私政策里明确写了这一点：**这个应用只能通过小米账号登录**，没有小米账号的话，登录流程里会先引导你注册一个；账号注册和关联的个人信息都在小米服务器上完成。

这也解释了为什么接入第三方平台时，提示的都是「关联小米账号」——**Google Home、Amazon Alexa、IFTTT 这些平台在绑定 Yeelight 设备时，走的正是登录小米账号这一步**，具体步骤见 [语音助手与HomeKit怎么接入.md](语音助手与HomeKit怎么接入.md)。

数据存在哪里，官方隐私政策的口径是分开的：设备信息按场景不同，存在小米服务器或易来自己的服务器上；**情景、房间管理、用户反馈这类数据存在易来服务器**，且不与个人信息或小米账号关联，只按指令执行。在意数据流向的，可以照这个口径理解。

顺带说一个和账号强相关的常见需求：**想让家里人也来控灯**。官方 FAQ 里提到设备支持分享、可以被多部手机控制，具体入口以 App 内设备设置页实际显示的选项为准；找不到分享入口时，让家人用**同一个小米账号**登录，是最省事的做法。

## 三、两套添加流程都官方支持

官方帮助中心里，指向 Yeelight App 的添加流程和指向米家 App 的添加流程是**分开的两套**，步骤几乎一样：重置设备、选 2.4GHz 网络、连 `yeelink-light-` 开头的热点。

官方没有承诺「同一盏灯在两边都能随时认到」。有用户在较早的实测中反馈过：在米家 App 里把灯加好之后，Yeelight App 认不到这盏灯、需要重新重置；也有经销渠道的说法是两边共用一个云端、装了哪个都能看到。**两方说法并不一致，遇到时以你设备在 App 里的实际表现为准。**

实践上稳妥的做法是：**定一个 App，从配网到日常控制都用它**，不要两边来回添加。真要在两个 App 之间换，就按换 App 的流程重新配一次网。

## 四、怎么选

| 你的情况 | 建议 |
| --- | --- |
| 手上主要是易来的灯，想调光调色、玩灯光效果、用音乐律动 | 用 Yeelight App |
| 家里还有一堆别的米家设备，想让灯和它们联动 | 用米家 App，把灯加进去 |
| 装的是易来 Pro 系列网关与灯具 | 用 Yeelight Pro |
| 想在电脑上控制灯 | 先看 Yeelight Station 的官方支持型号清单，不在清单里的别指望 |

要提前说明的一点：音乐律动、彩光流光这类玩法，两边 App 的覆盖并不完全相同，具体以你用的这个 App 里实际能点到的功能为准。

## 五、局域网控制为什么值得开

不管最后用哪个 App，都建议把设备的「局域网控制」打开。开启之后手机和设备在同一网络下走本地直连，响应更快；要用 Google Home 的本地执行，也必须开它。开启路径见 [添加设备与配网.md](添加设备与配网.md) 的第四节。

换 App 之后认不到设备，按本节的办法重新配一次网即可；换过网络之后的频繁离线，再按 [配网失败与设备离线排查.md](配网失败与设备离线排查.md) 逐条查——两种情况都别先怀疑灯坏了。
