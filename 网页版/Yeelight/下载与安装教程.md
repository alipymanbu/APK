Yeelight 是易来智能灯光的官方手机控制端，装了它才能给灯泡、灯带、吸顶灯这类设备配网、调亮度色温、改灯光效果、设定时。它只有安卓与 iOS 两个手机版本。本篇只讲安卓这一侧：核对网盘里这份包是哪一版、装好、首次打开登录，以及怎么确认它已经能认出设备。

## 一、先确认你要装的是哪一个 Yeelight

名字叫 Yeelight 或近似名字的应用不止一个，装错的话打开会是一套完全不同的界面。认下面三项最稳妥：

| 认什么 | 值 |
| --- | --- |
| 运营主体 | 青岛易来智能科技股份有限公司（官方隐私政策里署名的运营方） |
| 包名 | `com.yeelight.cherry` |
| 官网 | [www.yeelight.com](https://www.yeelight.com/) |

包名是手机系统里唯一的标识，两个包名不同、名字相同的应用可以同时装在一台手机上，各自的设备列表互不相通。应用商店页面的标题常带副标题或本地化后缀，名字对不上很正常，**认包名**最准；装完也可以在「设置 → 应用 → 应用管理」里点开它的详情页核对。

同一个品牌下还有别的控制端：面向 Yeelight Pro 全屋系统的 Yeelight Pro，以及电脑端的 Yeelight Station。它们管的是不同的设备体系，和本篇这份手机应用不能互相替代，区别见 [和米家App有什么区别怎么选.md](和米家App有什么区别怎么选.md)。

## 二、核对网盘里这份安装包

网上搜到的版本信息通常是官方当时的最新发布版，而网盘里这份是配文档时核对过的那一版，两者未必是同一个版本号。本文出现的版本、包名、体积都以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Yeelight |
| 版本 | v3.5.4 |
| 包名 | `com.yeelight.cherry` |
| 安装包体积 | 36.32 MB |
| MD5 | `501BAF1B62FABA38C9C5ADF40DFE9FF2` |

这个应用的版本号形如 `3.5.4`，官方渠道隔一段时间会发新版；你手上这份就是上表这一版。想装商店里的更高版本是另一回事，届时界面与入口位置可能与本文描述有差异，具体以应用商店页面当时显示的为准。

## 三、装到安卓手机上

1. **转存再下载**。打开网盘分享页，先转存到自己的网盘，再从自己的网盘下载到手机；直接点在分享页上下载有时会失败，转存这一步省不掉。
2. **找到文件**。在手机「文件管理」里找到刚下好的 `.apk` 文件，点击安装。
3. **允许安装未知来源的应用**。系统弹出提示时，给用来打开安装包的那个应用（文件管理器或浏览器）授权。Android 8 及以上是逐应用授权的，装完可以关回去；国产定制系统常把这项收在「安全」或「隐私」分类里。
4. **看到「未经过安全检测」属常规提示**，继续安装即可。
5. **提示「应用未安装」时先看版本**。安卓不允许用低版本覆盖高版本；手机上已经装了比 v3.5.4 更高的 Yeelight，想换成本文这份得先卸载旧版，卸载会把应用内数据一并清掉。

安装包本身不涉及付费环节。装完不要急着连灯，先把下一节的登录做完。

## 四、首次打开：登录与前置准备

- **账号只能用小米账号**。官方隐私政策写明，这个应用只能通过小米账号登录；没有小米账号时，登录流程里会先引导你注册一个，账号注册与关联的个人信息都在小米那侧完成。
- **先把手机连到 2.4GHz 的 Wi-Fi**。设备配网只走 2.4GHz，手机连在 5GHz 上，后面添加设备那一步会卡住。路由器把两个频段合并成一个名字（双频合一）时怎么处理，见 [添加设备与配网.md](添加设备与配网.md) 第一节。
- **权限按提示给**。较新的安卓系统要求应用拿到位置权限才能读取 Wi-Fi 列表，配网那一步如果系统弹了，照给就行；不给的话，连「附近有哪些 Wi-Fi」都读不到。
- **通知建议允许**。设备状态、固件更新这类提醒走系统通知，关掉不影响控灯，但真出问题时你会少一条线索。

## 五、装完做一次最小验证

别等真要用的时候才发现装了个不对劲的版本，装完按这三步过一遍：

1. 打开应用，确认能正常登录进到主界面；
2. 切到「设备」页，点右上角的「+」，确认能看到「添加设备」的入口和一张设备型号列表；
3. 如果手上已经有一盏配好网的 Yeelight 灯，看它有没有出现在设备列表里。

第 2 步的入口能正常打开，就说明应用本身没问题，接下来是 [添加设备与配网.md](添加设备与配网.md) 的事；添加过程中卡住、或者加完马上显示离线，直接看 [配网失败与设备离线排查.md](配网失败与设备离线排查.md)。

用起来之后最常被问到的两件事，也提前指一下路：从墙上开关关灯之后 App 里到底还算不算在线、家里断网时灯还能做什么，见 [关墙开关断网后灯还能用吗.md](关墙开关断网后灯还能用吗.md)；什么时候需要升级灯本身的固件、升到一半失败了怎么救，见 [固件升级与升级失败恢复.md](固件升级与升级失败恢复.md)。
