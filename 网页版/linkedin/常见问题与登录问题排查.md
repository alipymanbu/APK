## 一、登录时验证码图不出来 / 验证加载一半卡住

这是近年反馈比较集中的问题：应用商店评论区里 2026 年有多条同类反馈，做跨境求职的从业者也把它列为注册与登录阶段最常见的报错——登录到人机验证那一步，验证图片加载不出来或加载到一半就停。按这个顺序试：

1. **换网络环境重试**：切换 Wi-Fi 与移动数据再试一次，验证组件加载不出来常见于当前网络的访问异常。
2. **等一会儿再试**：短时间内反复触发验证，平台可能临时收紧校验，隔一段时间再登录。
3. **先在网页版登录一次**：用浏览器打开 [https://www.linkedin.com](https://www.linkedin.com) 登录，网页版过了验证之后，App 里再登往往就顺了。
4. **更新或重装 App**：旧版本与验证组件的兼容问题，装新版能解决一部分；安装方式见 [下载与安装教程.md](下载与安装教程.md)。

如果以上都无效，去官方帮助中心（[https://www.linkedin.com/help/](https://www.linkedin.com/help/)）提交反馈，这类纯客户端外的验证故障自己刷是刷不好的。

## 二、账号被要求验证 / 提示受限

登录时被要求做身份核验（人脸、证件或手机验证），是平台的风控机制在起作用：换了常用设备、换了登录地区、或账号行为触发了规则，都可能触发——刚注册的新账号也可能一注册就被要求验证。有用户反馈过验证过程中 App 闪退、验证后仍被反复要求验证的情况。能做的：

- 按提示**在网页版完成验证**（流程更完整，不容易中途崩）。
- 核验材料与账号信息保持一致，验证通过后不要短期内频繁换设备、换网络登录。
- 确实被误限的，通过帮助中心的申诉入口提交说明。

## 三、收不到验证邮件或短信验证码

| 检查点 | 操作 |
| --- | --- |
| 垃圾邮件箱 | 验证邮件常被误判，先翻一遍 |
| 邮箱地址对不对 | 注册页填错的邮箱永远收不到，退回上一步核对 |
| 重发冷却 | 点「重新发送」后等 1~2 分钟再查，连续快点的重发容易被拦 |
| 换邮箱 | 上面都试过就换一个常用邮箱重新注册 |
| 短信验证码收不到 | 部分地区号码（含 +86）触发短信验证后送达可能偏慢，等几分钟再点重发；反复收不到就改用邮箱注册 |

## 四、App 闪退、卡顿

1. 清理 App 缓存（系统设置 → 应用管理 → LinkedIn → 存储 → 清除缓存，不要点「清除数据」，那会退出登录）。
2. 手机剩余存储留出余量，存储快满的设备 App 容易闪退。
3. 卸载重装，重装后登录同一账号，资料与人脉都在云端不会丢。
4. 还不行就检查是不是系统版本过旧——App 对安卓版本有要求，见 [下载与安装教程.md](下载与安装教程.md) 的版本说明。

## 五、改密码与找回账号

- **记得密码想改**：设置 → 登录与安全 → 更改密码。
- **忘了密码**：登录页点「忘记密码」，验证邮件发到注册邮箱，按邮件里的链接重设。
- **注册邮箱也不用了**：帮助中心里有账号找回的专门流程，需要提供能证明账号归属的信息。

## 六、想删除账号

设置 → 「账号偏好」里有关闭账号（删除）的入口，删除前平台会确认一遍并说明数据保留期；数据安全层面的口径是你可以要求平台删除你的数据。删除是最终操作，账号下的人脉与资料一并没了，想清楚再点——只是暂时不用的话，退出登录就够了。

以上几类问题里，「验证码不出来」和「反复要求验证」占了大头，都属于平台侧的验证机制，你这边能做的主要是换网络、走网页版、等冷却；解决不了就走帮助中心，比在 App 里反复重试更快。
