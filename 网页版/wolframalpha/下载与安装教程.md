## 一、先认准是这一个

Wolfram|Alpha 这个名字在安卓上不止一个安装包，装错包后面每篇文档的版本号、设置路径都会对不上。装之前先对这三项：

| 核对项 | 值 |
| --- | --- |
| 官方名称 | Wolfram\|Alpha（官方规定单色显示时两个词用竖条隔开） |
| 包名 | `com.wolfram.android.alpha` |
| 开发者 | Wolfram Group LLC |

## 三、手机上怎么装

APK 不是从应用商店点「安装」装的，所以要先给安装来源授权：

1. 点开 APK 文件，系统弹出「禁止安装来自此来源的应用」时，进到该来源（浏览器或文件管理器）的授权开关并打开，返回；
2. 再次点击安装，确认详情页显示的图标与名称是你预期的那个，包名是 `com.wolfram.android.alpha`；
3. 装完先别急着打开，到「设置 → 应用 → 应用信息」里核对版本（第四节）；
4. 首次启动会要相机、存储之类的权限：相机是给照片输入用的（属 Pro 功能），暂时不用的先拒掉，用到时再给。

**这个应用的查询要联网才能出结果**——你输入的问题是交给 Wolfram 的计算引擎算完再返回的，不是手机本地算的。装好了断网按查询没反应是正常现象，见 [常见问题与解决办法.md](常见问题与解决办法.md)。

以后升级是**覆盖安装**：拿新版本 APK 直接再装一次，不用先卸载，登录状态与记录保留（前提是同一个账号）。

## 四、装完核对

「设置 → 应用 → 应用信息」里看两项：

- **版本号**：装网盘这份应显示 `1.4.27.20260311581`；
- **包名**（部分机型在「高级 / 应用信息」里）：`com.wolfram.android.alpha`。

版本号对不上，说明你装的不是这份包；包名对不上，说明装的是另一个同名应用，先删掉再按本篇重装。版本号那一长串各段是什么意思、以后怎么升级，见 [版本号怎么看与更新.md](版本号怎么看与更新.md)。

## 五、商店里那个免费条目是怎么回事

官方 2022 年起把原来的移动应用改称 **Wolfram|Alpha Classic（经典版）**，同时推出新的免费应用，并在官方博客里说明经典版不再引入新功能、建议用户迁到新应用。安卓上对应成两个包名：

| 包名 | 对应条目 | 你手里这份 |
| --- | --- | --- |
| `com.wolfram.android.alpha` | 经典版（Classic），早期为一次性买断 | 是 |
| `com.wolfram.android.alphapro` | 现行免费条目，Play 页面标题即 Wolfram\|Alpha | 否 |

- 经典版在商店里的**付费方式变过**，各第三方页面标价不一，以商店页面当时显示为准；
- 分步解答、照片输入这类功能属于 **Wolfram|Alpha Pro**，要有 Wolfram ID 加有效订阅才开，入口以应用内当时显示为准；
- 两条包名装在同一台手机上会共存（包名不同），不会互相覆盖——别因此以为装错了。

## 六、iPhone 用户走另一条路

网盘这份是 **APK，iPhone 装不了**。iOS 版在 App Store 单独上架（[apps.apple.com 的应用页](https://apps.apple.com/us/app/wolfram-alpha/id548861535)），账号与安卓版、网页版共用同一个 Wolfram ID，登录后订阅状态是通的。
