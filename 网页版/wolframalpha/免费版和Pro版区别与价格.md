## 一、免费版给什么

官方 FAQ 的口径：**个人非商业用途免费**，靠广告支撑；Pro 才是无广告环境。具体到你手上的应用：

| 项 | 免费（Basic） |
| --- | --- |
| 查询与结果窗格 | 完整可用，含图、含数据 |
| 数学输入键盘 / 模板 | 可用（第三方实测：免登录即可用分数、幂、根号、导数、积分、求和、极限、矩阵这些模板） |
| 广告 | 有 |
| 分步解答 | 不含 |
| 照片输入（拍题） | 不含 |
| 每次查询的计算时间 | 标准档；官方 FAQ 说 Pro Premium 才给更长的计算时间 |
| 保存收藏与历史 | 官方给的是「免费注册账号后可保存收藏夹与历史记录」（指网页端） |

**判断标准很简单**：只想要答案与图表，免费部分就够了；想要**过程**（分步解答）与**拍照输入**，才需要 Pro。

## 二、Pro 版买到的是这几样

以官方安卓页与 FAQ 为准：

1. **分步解答**：微积分、代数、三角、方程求解、基础数学、化学等科目的逐步提示；
2. **照片输入**：拍照或从相册选图，把题目识别成输入再查询（数学 OCR）；
3. **输入助手**：原先是独立的课程助手应用，现在并进主应用，按 Pro 开放；
4. **无广告** + 更长的计算时间；
5. **一次订阅到处用**：同一个 Wolfram ID，网页版与安卓/iOS 应用通用，不用重复买。

## 三、价格：以官方页面当时显示为准

各渠道与各时期显示的价格差得比较远，二手页面的数字互相矛盾，所以下面**只列官方页面的口径**（2026 年 9 月查到的页面显示，随时会变）：

| 档位 | 官方页面显示 |
| --- | --- |
| Basic | 登录后免费 |
| Pro（学生价，中国区） | 月付 ¥66，年付 ¥408 |
| Pro Premium（学生价，中国区） | 月付 ¥81，年付 ¥684 |
| Pro（Google Play 应用内购买，美元区） | 描述页写 $9.99/月、年付最高 $59.99 |

- 页面入口：[zh.wolframalpha.com 的 Pro 页](https://zh.wolframalpha.com/pro)；
- **学生价要选 Student 身份并按页面流程验证**，不是默认档；
- 应用内购买的价格由 Google Play 结算，与网页端订阅不一定同价——买之前两边都看一眼；
- 第三方评测给出的 Pro 价格（有写 $7.99/月、也有写更低的年付折算价）与上表对不上，**以你下单那刻官方页面显示的为准**。

## 四、开通与取消

1. **网页端开通**：注册/登录 Wolfram ID → 进 Pro 页选档位付款，回来在应用里登录同一账号（生效可能要等几分钟，见 [常见问题与解决办法.md](常见问题与解决办法.md) 第三节）；
2. **应用内开通**：应用里走 Pro 入口调起 Google Play 内购，扣款由 Play 处理；
3. **取消自动续费**：在 Google Play 里取消——打开 Play 商店 → 点头像 →「付款和订阅」→「订阅」→ 选 Wolfram|Alpha →「取消订阅」。取消后**当前已付费的周期仍可用**，到期才降级；
4. 网页端买的订阅也在这里管理（它会以订阅条目的形式出现在 Play 里，若没出现，就是走的网页端，去 [account.wolfram.com](https://account.wolfram.com/) 管理）。

## 五、先别急着买

- Pro 加的是**过程展示、输入方式与无广告**，不是把答案藏起来——免费部分照样给完整结果与图（见第一节的表）；
- 数学核对类用途，先用 [怎么算定积分.md](怎么算定积分.md) 里的自由写法 + 免费结果跑一遍，够用就不用订阅；
- 订阅前确认你确实高频用到拍题或分步解答——低频使用时，免费部分加网页版的数学输入模板已经能覆盖大部分场景。
