## 一、按了查询一直转圈、没有结果

查询要发给 Wolfram 的计算引擎、拿回结果再渲染，所以先分清是**没发出去**还是**发出去了没理解**：

1. 确认网络能用（先开个别的网页试一下）；
2. 换个更短的查询再按一次——太长太杂的输入处理起来更慢；
3. 隔一会儿重试，别把偶发的服务端变慢当成自己这边的网络问题；
4. 还是没反应就杀掉应用重开，再用最简单的 `2^20` 试——这条能出结果说明链路通了，问题在你原来那个查询上，转 [怎么搜索答案.md](怎么搜索答案.md)。

## 二、「看不懂你的查询」提示

这不是故障，是它没理解输入。按顺序走：换说法 → 用完整词 → 不混记法 → 查拼写 → 改英文，五条的详细解释与改写对照在 [怎么搜索答案.md](怎么搜索答案.md) 第二节、第三节。

## 三、登录了 Pro，功能还是锁着的

官方 FAQ 对这种情况给过两条说明：

1. **可能要等几分钟**才生效，不是点完登录立刻就解锁；
2. **在网页端买的 Pro，要在应用里用同一个 Wolfram ID 登录**才会带过来；另外 Windows 商店版是单独购买，不共用网页订阅。

等了几分钟、账号也对，还是没解锁，走官方反馈入口（第六节）把账号邮箱与购买时间带上。免费与 Pro 到底差在哪、值不值这个钱，见 [免费版和Pro版区别与价格.md](免费版和Pro版区别与价格.md)。

## 四、老是被登出、加载慢

- **掉登录**与**加载慢**在应用商店的评价区有用户反馈（属个案，不代表所有机型）；先确认手机系统时间是自动设置的，再清一次应用缓存重试；
- 商店评价区出现过官方回复「已通过新版本更新修复」的登录问题——所以**先把自己应用升到最新版**再排查，步骤见 [版本号怎么看与更新.md](版本号怎么看与更新.md)；
- 反复掉就退出重登一次，把账号密码存进系统的账号管理，别只靠记住的自动登录。

## 五、安装与版本类问题

| 现象 | 原因 | 下一步 |
| --- | --- | --- |
| 装完版本号对不上 | 装的不是这份包 | 回 [下载与安装教程.md](下载与安装教程.md) 第四节核对 MD5 与包名 |
| 旧手机装不上 | 系统版本不够 | 各渠道页面给的最低安卓版本不一致（有写 6.0+、有写 8.1+），**以你安装时那家商店页面显示的为准**；本文档的登记信息里也没有这一项 |
| 打开就是另一个同名应用 | 装错了包 | 卸载后按包名 `com.wolfram.android.alpha` 重装 |
| 想换到商店的免费条目 | 两条包名是两个应用 | 见 [下载与安装教程.md](下载与安装教程.md) 第五节，包名不同、可共存 |

## 六、要反馈问题、问官方

- 每个结果页底部有**反馈表单**，报「结果算错了」用它最直接（官方 FAQ 明确推荐）；
- 应用商店里开发者留的联系邮箱是 `info@wolframalpha.com`；
- 想查功能、看别人怎么用，走官方 FAQ 页：[wolframalpha.com 的常见问题](https://www.wolframalpha.com/faqs/)。

## 七、隐私上你该知道的两件事

- 官方 FAQ 的口径是**你的输入是保密的**，细节见 [wolfram.com 的隐私政策](https://www.wolfram.com/legal/privacy/wolfram)；
- 商店页面的数据安全声明提到应用可能收集**个人信息、照片与视频、设备标识**，传输加密、可要求删除数据——照片输入（Pro 功能）会用到拍照内容，不打算用这个功能就别给相机权限（[下载与安装教程.md](下载与安装教程.md) 第三节的权限步骤里可以先拒绝）。

## 八、查询有没有次数限制

你正常手动查问题，**不用担心次数**：

- 官方没有公布过查询次数配额，第三方在一个会话里连查二十多次也没碰到限额；
- 真正被条款挡掉的是**程序化批量访问**——用脚本、机器人反复查询属明确禁止，被监测到会限制或中止访问（详见 [能查哪些类型的问题.md](能查哪些类型的问题.md) 第四节的表格）；
- 免费与付费的差别不在次数，而在过程展示、输入方式与广告，见 [免费版和Pro版区别与价格.md](免费版和Pro版区别与价格.md)。
