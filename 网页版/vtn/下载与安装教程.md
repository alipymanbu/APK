## 一、先确认你要装的是什么

VTN 是一家会员制的健康美丽购物平台出的购物 App（运营方是杭州唯堂电子商务有限公司，隶属 ACCESS 集团），早期它在市场上的常见叫法是「单创」，现在 App 与官方渠道统一叫 VTN。安卓版包名固定是 `com.abm.app`，装之前先记住这一串，后面核对要用。

网上能搜到的「官方最新版」和网盘里那份常常不是同一个版本，涉及版本号、包名、体积，一律以网盘里那份为准：

| 项目 | 值 |
| --- | --- |
| 版本 | 6.9.7 |
| 包名 | `com.abm.app` |
| 安装包大小 | 63.19M |
| MD5 | `2a32e6768a500d3d529cc5e16eb8c1fb` |
| 整包字节数 | 66263107（下载工具显示的字节数对得上才完整） |

官方商店的版本一直在往前走（腾讯应用宝 2026-06-19 显示 6.9.7，之后收录站已见到更高的 7.3.5），所以「商店里的最新版」和网盘里这份对不上号很正常 —— 以官方商店当时显示为准。只想装上能用的最新版，走第四节的商店渠道更省事；想装和网盘完全一致的那份，就按下面来。

## 二、从网盘拿安装包

打开 [VTN 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9766a66beb05)，找到 VTN 的文件夹，把 `vtn_v6.9.7.apk` 下载到手机本地再安装。转存到自己的网盘再下载也可以，文件夹里附了一份「先保存再下载避免失效」的说明，照做能避免分享链接过期后拿不到文件。

下载完先别急着点，核对两件事：文件大小接近 63.19M（明显偏小说明传输不完整，删掉重下）；文件名是 `vtn_v6.9.7.apk` 而不是一串来路不明的字符。

## 三、安装步骤

1. 用手机浏览器或夸克打开上面的地址，把 APK 下载到本地。
2. 点击下载好的 `.apk` 文件。系统如果弹出「禁止安装来自此来源的应用」，说明还没授权 —— 按提示进入 `设置 → 安全 → 安装未知应用`（不同品牌路径略有差异，也可能叫「未知来源」「安装外部来源应用」），给当前这个安装来源（浏览器或夸克）打开允许。
3. 回到安装界面点「安装」，等进度走完。
4. 首次启动会申请一批权限，常见的有：读写外部存储（保存图片与缓存）、请求安装应用、位置、网络与 WLAN 状态。联网与存储建议给足，位置不给也能逛、能下单，只是涉及定位的功能会少。

装完打开，注册与优惠码的事见 [注册登录与优惠码填写.md](注册登录与优惠码填写.md)。

## 四、其他获取渠道

iPhone 直接在 App Store 搜 `VTN`（开发者 Hangzhou WeiTang E-commerce Co., Ltd，应用页 `apps.apple.com/cn/app/vtn/id1241833105`）；安卓可以在腾讯应用宝搜 `VTN`，或从官网 [vtnclub.com](https://vtnclub.com) 找下载入口。商店渠道的好处是后续更新会自动推。

网盘这份 APK 的用处在于：商店打不开、设备没有谷歌服务、或者你想要和网盘里版本完全一致的包时，能直接装上。

## 五、装不上时按这个顺序排查

| 现象 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| 点安装就提示「已阻止安装」 | 未知来源授权 | 按第三节第 2 步给当前来源授权后重试 |
| 提示「解析包时出错」「安装包损坏」 | 文件完整性 | 删掉重新下载，确认大小接近 63.19M |
| 提示「安装失败」「已存在同名应用」 | 旧版本残留 | 先卸载旧版再装（卸载只丢本机登录态，账号数据在云端，重新登录即可） |
| 提示「空间不足」 | 存储余量 | 清出几百 MB 再装 |
| 装上了但一点就闪退 | 网络、缓存、系统版本 | 转到 [售后退换与常见问题.md](售后退换与常见问题.md) 逐条过 |

多数组装机按「重新下载 → 授权 → 卸载重装」三步就能解决；三步都试过还不行，再去看排查那篇。
