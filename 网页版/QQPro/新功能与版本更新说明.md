## 一、它从哪来

手表上的 QQ 客户端有一条民间演进线：早期的 WearQQ，之后是基于 NT 框架的 NWearQQ（只留聊天的精简版），QQPro 则是**基于 nwear-QQ 最终版 2 打造的手表 QQ**，在它之上继续加功能、修小屏上的毛病。QQPro 自身的版本号从 1.0 起步一路递增，公开页面上已能看到 1.5.1 —— 版本号会持续变化，看到的最新版以发布页当时显示为准。

**你手头网盘里这份是 1.4 版**（38.15M，包名 `com.tencent.qqlite`），比它新的版本网上还有，两者不是同一份文件；版本号、大小、MD5 一律以你实际下载到的包为准。

## 二、这条线上改了些什么

综合公开的更新说明，QQPro 相对基础版的改进集中在「小屏上把消息看全、把操作做顺」：

| 改进 | 解决的问题 |
| --- | --- |
| 可以查看转发的聊天记录 | 以前转发消息点进去看不到上下文，现在不用切手机 |
| 引用消息显示发送者昵称 | 收到引用回复时能认出原消息是谁发的 |
| 表冠滚动适配 | 转动表冠就能翻聊天列表，不用在小屏幕上搓来搓去 |
| 修复回复带图看不见 | 以前对方回复里带图片会空白 |
| 限制表情包最大大小 | 防止超大表情把小设备卡住 |
| 页面缩放至 90% | 屏幕小时让一屏多显示一点，字图比例自己调 |

更新说明里还提到过：聊天列表加载提速、降低内存占用、修复群聊 @ 成员失效、消息免打扰自定义时段等。这些条目随版本滚动，具体某一条落在哪个版本号上，以对应版本的更新说明为准（部分条目未逐条标注版本）。

## 三、QQPro 和原版 QQ 手表版的差别在哪

一句话：原版解决「手表上能不能用 QQ」，QQPro 在此基础上解决「用起来顺不顺」—— 转发内容、引用溯源、表冠滚动这些都属于把小屏上的高频操作补齐。功能取舍层面的对照（它保留什么、不做什么）见 [与手机QQ的区别.md](与手机QQ的区别.md)。

## 四、怎么升级

1. 从 [QQPro 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7e5c120365a0) 或你信任的发布渠道拿到新版本 APK。
2. 核对新包的版本号与大小，别把旧包当新包装回去了。
3. 走覆盖安装：包名相同、签名一致的包直接 `adb install` 覆盖，聊天数据不丢（完整步骤见 [下载与安装教程.md](下载与安装教程.md)）。
4. 装完打开确认版本号已更新，不用重新扫码（覆盖升级不掉登录态；只有卸载重装才需要重新授权，见 [常见问题与解决.md](常见问题与解决.md)）。

升级后发现新版本有问题、想退回 1.4：网盘里那份 1.4 一直可用，先卸载新版再装旧版即可 —— 但降级会清掉本地数据，装回后重新扫码登录。
