## 一、键盘打字

进入聊天界面点输入框，手表会调出输入法。屏幕小，能打的字有限，所以先确认两件事：

- 手表自带的输入法一般支持**全键盘 / 九宫格**切换，在输入界面点键盘图标就能改布局；
- QQPro 这条线（NWearQQ 一脉）的公开说明里提到**支持第三方输入法** —— 你的手表如果装过别的输入法，可以在输入框里切换试试；入口找不到就以你手上版本的界面为准。

打长句不现实，回一句短话、一个表情是它更常见的用法。

## 二、语音转文字

比打字更快的路子是说：

1. 在输入界面找**麦克风 / 语音图标**，点它开始说话；
2. 对着手表麦克风正常语速说，识别结果会填进输入框；
3. 看一眼有没有识别错的字，改完再发送。

注意两点：语音转文字**需要手表联网**（走手表自己的 WiFi 或 eSIM）；部分手表的这项功能依赖自带输入法，不同品牌支持的语言也不一样，以实际界面为准。此外你也可以直接**发语音消息**（按住说话那种），对方在手机上点开就能听 —— 这比转文字更少出错。

## 三、表情与图片

- 表情是手表上回复频率最高的内容，但**表情包有大小上限**（公开更新说明里明确做过限制），超大的发不出去，换个小的即可。
- 看图片时觉得显示区域太小，可以把页面缩放调到 90%（见 [新功能与版本更新说明.md](新功能与版本更新说明.md)）。
- 收图、看大图这类操作在小屏幕上体验有限，重要的图片回手机上看（对照见 [与手机QQ的区别.md](与手机QQ的区别.md)）。

## 四、长按一条消息能做什么

短消息列表里，**长按**是高频入口。这条线的公开说明里提到过这些能力：

| 操作 | 用途 |
| --- | --- |
| 长按消息 → 回复 | 引用某条消息回复；QQPro 会显示被引用消息的发送者昵称 |
| 长按消息 → 复制 | 把文字内容拷出来（配合粘贴发送） |
| 长按消息 → 查看转发内容 | 直接看转发的原始聊天记录，不用切手机 |
| 长按群成员 → @ | 在群里点名某人 |

长按菜单的具体选项随版本变化，以你手上版本弹出的菜单为准；没有某一项不代表说错了版本，只是这个版本没做。

## 五、翻列表与找消息

聊天列表长了之后，**转动表冠滚动**（QQPro 做过表冠适配）比在小屏幕上滑来滑去顺手；没有表冠的手表就上下滑动。要找很久以前的消息时，别在手表上翻 —— 手机端搜索是更快的路径。

消息在手表上收发异常（发出去没反应、收不到回复）时，先按 [常见问题与解决.md](常见问题与解决.md) 排查网络与登录态，再回来试输入。
