## 一、这是装在手表上的应用

QQPro 是给安卓智能手表用的 QQ 客户端，界面按小屏做了适配。它不走手表自带的应用商店，安装包需要你手动装进手表 —— 这也是本篇要讲的事。

它也能装在普通安卓手机上并正常运行，但那样就失去了小屏适配的意义；如果你只是想在手机上聊 QQ，直接用官方手机版更合适（两者的取舍见 [与手机QQ的区别.md](与手机QQ的区别.md)）。

## 二、拿到安装包

从 [QQPro 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7e5c120365a0) 下载到电脑或手机上，网盘里那份的事实如下：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.4 |
| 包名 | `com.tencent.qqlite` |
| 大小 | 38.15M |
| MD5 | `E2B82CF7C829FEA208B93CA3CA58E0D7` |
| 系统要求 | 安卓 5.2 以上（安装时以实际提示为准） |

下载完可以校验一下 MD5，确认文件完整没损坏。Windows 上在安装包所在目录打开命令行：

```powershell
certutil -hashfile QQPro_v1.4.apk MD5
```

输出的哈希与表格里的 `E2B82CF7C829FEA208B93CA3CA58E0D7` 一致即可。

> 网上还能搜到更新的版本号（如 1.5.1），但那不是网盘里这份；两者的版本号、大小、MD5 都可能不同，以你实际下载到的文件为准。

## 三、装进手表：ADB 方式（通用）

绝大多数手表没有「点击安装 APK」的入口，ADB 是最通用的办法。你需要：一台电脑、手表的充电线（或无线调试能力）、下载好的 APK。

1. **打开手表的开发者模式**：手表上进 `设置` → `关于手表` → 找到「版本号」，连续点 7 次左右，直到提示已进入开发者模式。
2. **打开 USB 调试**：返回 `设置` → `开发者选项`，打开「USB 调试」（有的手表还要求同时打开「ADB 调试」）。
3. **电脑装 ADB**：从安卓开发者站点下载 platform-tools，解压后在该文件夹地址栏输入 `cmd` 回车，打开命令行。
4. **连接手表**：用手表充电线连电脑，手表上弹出「是否允许 USB 调试」时勾选「一律允许」并确认。
5. **确认连接**：

```bash
adb devices
```

列表里出现一串设备号即连接成功；如果是 `unauthorized`，回到手表上点允许。

6. **安装**：把 APK 拖进命令行窗口补全路径，执行：

```bash
adb install C:\path\to\QQPro_v1.4.apk
```

看到 `Success` 就装好了，手表应用列表里会出现 QQPro。

### 无线调试怎么连

Wear OS 与多数新款手表支持无线调试，不用充电线也能装：

1. 手表 `设置` → `开发者选项` → 打开「无线调试」，手机和手表连**同一个 WiFi**；
2. 在手表上点进「无线调试」详情，选「使用配对码配对设备」，记下屏幕上的 **IP:端口** 和 **配对码**；
3. 电脑上用较新版本的 platform-tools 执行（把 IP、端口、码换成手表显示的）：

```bash
adb pair 192.168.1.50:37123 482913
adb connect 192.168.1.50:5555
```

4. `adb devices` 里状态是 `device` 就可以走上面第 6 步的 `adb install` 了。

老款手表没有「无线调试」选项时，就用充电线走有线 ADB。装完出于安全考虑，把 USB 调试 / 无线调试关掉即可，不影响已安装的应用。

## 四、装进手表：文件管理器方式（部分手表支持）

少数安卓手表自带「文件管理」或支持蓝牙/云盘传文件：把 APK 传到手表存储里，用文件管理器点它，按提示允许「安装未知应用」即可。手表提示不支持时，回到上面的 ADB 方式。

## 五、装完之后

第一次打开 QQPro 会先让你同意使用协议，同意后进入登录界面，出现一个二维码 —— 它**只支持扫码登录**，需要用手机 QQ 扫这个码。完整步骤见 [扫码登录方法.md](扫码登录方法.md)。

装不上、装上了闪退、或者界面显示不全，都属于常见现象，排查办法在 [常见问题与解决.md](常见问题与解决.md)。
