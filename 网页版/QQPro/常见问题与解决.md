# 常见问题与解决

> 登录失败、收不到消息、装不上、界面显示不全 —— 手表上用 QQPro 最容易碰到的几类问题和排查顺序。

## 一、扫码后登录失败 / 提示登录环境异常

按这个顺序排查：

1. 手表和手机**连同一个 WiFi**（QQ 的安全策略要求登录的两台设备处于同一网络环境时才放行），再扫一次。
2. 确认手机 QQ 本身在线、能正常收发消息。
3. 手表时间是否准确 —— 系统时间偏差过大会让登录校验失败，`设置` 里核对一下日期时间。
4. 都试过仍失败，用手机 QQ 的反馈入口提交：`手机QQ > 头像 > 设置 > 关于QQ与帮助 > 反馈`，附上手表型号和提示原文。

## 二、手表收不到消息通知

手表 QQ 的消息推送本来就比手机弱，收不到时先看这几项：

- 手表**没戴在手上**时，系统为省电可能不推送通知；点开 QQPro 本身通常仍能收到并回复。
- 手表开了**勿扰模式**时，收到消息也不会振动、不亮屏 —— 关掉勿扰再试。
- 手机处于静音模式时，链路上的通知也可能不响。
- 手表和手机靠蓝牙中转消息时会有延迟，稍等片刻或打开手表的 WiFi 再看。
- **手表的省电策略把 QQPro 清掉了**：手表本身是安卓系统，电池/后台管理可能在息屏后杀掉应用。到手表的 `设置` → `电池`（或 `应用` → `QQPro`）里，把它设为「不受限 / 允许后台运行」，或在最近任务里锁定它；具体路径随品牌不同，以实际界面为准。
- 确认手表端 QQPro 还处于登录状态（掉线后要重新扫码，见 [扫码登录方法.md](扫码登录方法.md)）。

## 三、安装失败或装上就闪退

- **提示安装失败**：先核对包名应为 `com.tencent.qqlite`、系统要求安卓 5.2 以上；再看手表剩余存储 —— 空间不足时安装阶段就直接报错，清出几百 MB 重试。用 ADB 安装时把完整报错贴出来看 —— `INSTALL_FAILED_UPDATE_INCOMPATIBLE` 意味着手表上已有同包名但签名不同的旧版，先卸载旧版再装（`adb uninstall com.tencent.qqlite`）。
- **装上闪退**：手表存储空间不足是最常见原因，清出几百 MB 再试；仍闪退就重新下载安装包并核对 MD5（方法见 [下载与安装教程.md](下载与安装教程.md)），文件损坏会导致启动即崩。

## 四、界面显示不全、字太小或被裁掉

不同手表的屏幕密度差异很大，安装后出现显示不全时，用 ADB 调一下显示密度：

```bash
adb shell wm density
```

记下当前值，再调到一个更合适的值（比如先减 20~40 试效果）：

```bash
adb shell wm density 320
```

不满意就用 `adb shell wm density reset` 恢复默认。另外 QQPro 自身提供了页面缩放选项（公开更新说明里提到可缩放至 90%），在应用内的设置里找找缩放/字号相关开关，往往比改系统密度更省事。

## 五、图片、表情发不出去或看不到

- 收到的**回复里带图片却看不见**：公开更新说明里已把这个问题列为修复项，先升级到新版本试试（见 [新功能与版本更新说明.md](新功能与版本更新说明.md)）。
- **大表情包发不出**：这是对表情包大小做了限制，属于小屏设备上的取舍，换个小一点的表情即可（输入相关的完整说明见 [消息输入与回复.md](消息输入与回复.md)）。
- 手表端对图片、视频这类消息的支持本来就有限，重要的图片内容回到手机上看更稳妥。

## 六、重新安装与升级

新版本直接覆盖安装即可（包名相同，聊天数据不丢）：重新下载 APK，走 [下载与安装教程.md](下载与安装教程.md) 里的 ADB 流程，`adb install` 对已安装的同签名应用就是升级。签名不一致导致装不上时，才需要先卸载 —— 卸载会清掉本地数据，重装后重新扫码登录即可。
