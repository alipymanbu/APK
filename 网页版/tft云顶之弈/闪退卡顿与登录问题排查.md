## 一、先分清是哪种坏法

对不上号的症状，修法完全不同，先归类：

| 症状 | 多半是哪类问题 |
|---|---|
| 打开就闪退 / 打一半崩 | 内存不足、版本过旧、缓存损坏 |
| 画面冻住不动 | 进程假死，先强制停止 |
| 卡在登录 / 转圈进不去 | 网络、账号方式、服务器维护 |
| 更新下载失败 | 存储权限被拒、存储空间不足 |
| 没声音 | 音量 / 静音 / 被其他播放器抢占 |
| 装的时候被拦 | "未知来源"权限没开（见安装篇） |

以下步骤来自官方 Android 排查流程（[官方支持页](https://support.riotgames.com/zh-cn/riot/performance/troubleshooting-mobile-android)），
**从第 1 步开始顺着做，每做一步试一次**，别一上来就重装。

## 二、万能第一步：重启

按电源键选"重新启动"；无效就长按电源键约 30 秒强制重启。
手机和电脑一样需要"休息"，相当一部分假死重启就能好。

## 三、确认系统和游戏都是新的

- **系统**：`设置 → 系统 → 系统更新`，升到最新；
- **游戏**：商店装的去 Google Play"我的应用和游戏"里更新；
  侧载装的按游戏内提示覆盖安装新包（拿新包看[下载与安装教程.md](下载与安装教程.md)）；
- **权限**：`设置 → 应用 → Riot Games 应用 → 权限`，确认**存储**已勾上。
  首装 / 更新时弹的授权框点过"拒绝"，就会出现"提示有更新但下不动"。

## 四、卡死时：强制停止再进

1. `设置 → 应用和通知 → 找到该游戏`（看不到就点"查看全部应用"）；
2. 点**强制停止**；
3. 回桌面重新打开。

顺手把后台应用清一清 —— 所有后台应用都占内存，游戏起不来经常就是内存被占满了
（点最近任务键，把不用的划掉）。

## 五、还不好：清缓存 → 清数据

按代价从小到大：

1. **清缓存**：`设置 → 应用和通知 → 游戏 → 存储和缓存 → 清除缓存`。
   只删临时文件，不丢账号，先试这个；
2. **清数据**：同一位置改点**清除存储空间 / 清除数据**。这一步会把本地存档全清掉 ——
   **动手前必须确认账号已绑定 Riot 账号**：官方明确说非 Riot 账号的数据无法恢复，
   没绑定就清 = 进度直接蒸发。绑定方法见[账号注册与登录.md](账号注册与登录.md)；
3. **重装**：最后手段。卸载 → 重启手机 → 重新安装，同样受上面那条警告约束；
   重装用的安装包按[下载与安装教程.md](下载与安装教程.md) 第三节重新获取。

## 六、登录转圈 / 进不去对局

- 先确认不是维护期：官方渠道公告的停服时间只能等；
- 切换网络试试（Wi-Fi ↔ 数据），路由器重启一次；
- 只用官方客户端与官方入口登录，第三方"登录器 / 加速页面"出了问题官方不负责，
  账号风险也自负；
- 设备账号登不上去、又找不到入口升级的，回[账号注册与登录.md](账号注册与登录.md) 对着做；
- 都试过还进不去，走 Riot 官方支持页（[support.riotgames.com](https://support.riotgames.com)）提工单。

## 七、没声音 / 没通知

- 媒体音量拉起来、确认手机没开静音；
- 游戏内设置里音频开关是否打开；
- 是否被别的音乐播放器抢占了音频焦点（部分播放器播歌时会静音其他应用）；
- 通知不弹：`设置 → 通知 → 找到该游戏 → 允许通知`，各分类开关都打开。

## 八、配置达标还是卡

满足最低配置仍掉帧，按这个顺序找原因：后台占用 → 画质设置调低 →
确认机型没有踩到换引擎后的新门槛（官方要求在
[下载与安装教程.md](下载与安装教程.md) 第二节列了两张对照表，18.1 补丁后安卓 8 / 4 GB 起步）。
