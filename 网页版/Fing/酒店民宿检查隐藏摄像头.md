# 酒店民宿检查隐藏摄像头

> 这篇讲入住后怎么用 Fing 扫一遍房间 Wi-Fi 找可疑摄像头，以及这套方法的边界在哪。

## 一、结论先说

联网直播型的偷拍设备（IP 摄像头）必须挂在一个 Wi-Fi 上才能把画面传出去——**你连上房间的 Wi-Fi 再扫一遍，它就会以一台网络设备的形式出现在列表里**，厂商名、设备类型往往直接写着摄像头。这是 Fing 能帮上的部分。但**有线直录、只插内存卡的摄像头不联网，任何扫描类应用都查不到**，还得靠物理检查。把两层都做了才算查过。

## 二、扫描步骤

1. 入住后先连上房间/民宿提供的 Wi-Fi（务必连对——扫的是你连的这个网络）；
2. 打开 Fing，执行一次扫描，等设备列表出来；
3. 重点看这几类条目：设备类型标着 `Camera` / `IPC` / `Surveillance` 的；厂商是海康威视、大华、TP-Link、萤石这类安防品牌的；以及任何你叫不出名字的条目；
4. 点进可疑条目看详情：能拿到型号的，直接拿型号字符串去搜索，是明摆着的商用摄像头还是别的设备，一搜便知。

注意两类干扰项，别自己吓自己：

- **机顶盒、智能电视、音箱带摄像头**是明装的，不算隐藏设备；
- **路由器、网络打印机**这类基础设施本来就在网上，逐个看厂商名，确认不是偷拍设备即可。

## 三、这套方法查不到什么

按「能不能联网」划线，一张表说清：

| 摄像头形态 | Fing 扫得出吗 | 原因 |
| --- | --- | --- |
| 联网 IP 摄像头（Wi-Fi 直连） | 扫得出来 | 它就在你连的网络里 |
| 走另一个 Wi-Fi / 手机热点回传的 | 扫不出来 | 不在你扫的这个网络 |
| 只录内存卡、不联网的 | 扫不出来 | 任何网络扫描都看不见它 |
| 有线、连到录像机的 | 扫不出来 | 同上 |

（表里的「扫不出来」是官方与第三方测评反复确认的边界，不是 Fing 独有的缺陷——**联网扫描这条路天生只覆盖联网设备**。）

补物理检查的两个低成本办法：

1. **关灯看反光**：全屋拉黑，用手机手电筒扫一遍可疑物件（烟感器、闹钟、插座、电视机），镜头会反出一个亮点；
2. **重点查正对床和浴室的位置**，以及「位置不合常理的东西」——没有电线却插着的充电头、朝向床的烟感器。

## 四、发现可疑设备后的处理

1. **别拆、别动手**：保留现场，先拍照录视频留存；
2. **断开该 Wi-Fi**，用移动数据继续取证；
3. **报警**：把扫描结果（设备名、IP、厂商、型号）作为线索提供，这类设备出现在短租空间通常直接违反当地法律与平台规则；
4. **联系平台**：向预订平台举报房源，平台有义务处理。

涉及他人的正当隐私检查只应在你**本人入住/居住的空间**内进行；扫描也只扫你已获准使用的那个网络。

## 五、一次没扫出来就下结论？

不要。原因见第三节的表格——网络侧没查到，物理侧还没做；反过来，物理侧看着干净，也建议补一次网络扫描，两边互为兜底。出门前把 [怎么查看谁在蹭网.md](怎么查看谁在蹭网.md) 里「认陌生设备」那套顺一遍，判断逻辑是一样的：**认不出的东西，先当嫌疑对象查清楚**。
