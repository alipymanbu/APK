# 怎么查看谁在蹭网

> 这篇讲用 Fing 扫出家里 Wi-Fi 的全部设备、认出陌生设备，以及确认被蹭网后怎么处理。

## 一、结论先说

手机连上家里 Wi-Fi，打开 Fing 扫一次，几秒后你会拿到一份设备清单：每台设备的 IP 地址、厂商、型号、设备类型。把清单里叫不出名字的挑出来，就是你要找的「蹭网嫌疑对象」。确认之后改 Wi-Fi 密码，是最直接的处理方式。全程不需要登录路由器后台。

## 二、扫描步骤

1. 手机连上要检查的 Wi-Fi（位置权限得先给，见 [下载与安装教程.md](下载与安装教程.md) 第四节）；
2. 打开 Fing，进入设备列表页，点扫描按钮（首次使用显示为「扫描当前网络」）；
3. 等几秒，列表会按设备一条条列出；
4. 点右上角的视图切换，可以在「简化 / 标准 / 技术」三种显示密度间切换——技术视图会露出 IP、MAC 这些细节。

免费账户每天最多手动扫 3 次（官方帮助文档口径，以应用内实际显示为准），日常看看足够。

## 三、看懂设备列表

| 字段 | 你能读出什么 |
| --- | --- |
| 设备名 / 厂商 | `Samsung`、`TP-Link`、`Xiaomi` 这类厂商名，是认设备的第一线索 |
| 设备类型 | 手机、电视、摄像头、打印机等分类 |
| IP 地址 | 同网段说明在你内网里；变化频繁的多半是 DHCP 轮换 |
| 在线状态 | 此刻是否正连着 |

**给认得出的设备改名**：点进设备详情，改成「客厅电视」「老妈手机」，以后每次扫完一眼就能看出多没多东西。官方术语叫设备清单（inventory），你只需要记住：改过名的设备，下次扫描还会保留（前提是有位置权限且登录着账户）。

**识别不准很正常**。设备识别是尽力而为的：有的设备对外透露的信息就那么点，Android 从 2023 年起还限制了应用读取 MAC 地址，纯手机扫描只能按 IP 识别，结果会比桌面版粗（官方公告口径）。详情页如果有「识别得对吗」一类的提示，点「不对」可以手动选对品牌型号。

## 四、判断谁在蹭网

三条经验：

1. **先对自家设备**。把手机、电脑、电视、平板、智能音箱、摄像头挨个对上号，剩下的才是嫌疑对象；
2. **看厂商**。列表里冒出一个你没买过任何该品牌产品的条目，基本就是外来设备；
3. **看新旧**。第二次扫描时冒出来的新条目，比一直躺着的旧条目更值得关注——登录账户后可收到「有新设备接入」的提醒，订阅版含手机与邮件推送（官方 FAQ 口径）。

**常见误判**：打印机、路由器自身、访客手机连过一次留下的记录、IoT 设备的随机 MAC，都可能让列表比你数出来的「实际设备」多。拿不准的，去路由器后台的设备列表交叉核对一遍——两边数字对不上，再回来查 [扫描不出设备怎么排查.md](扫描不出设备怎么排查.md)。

## 五、确认被蹭网之后怎么办

按成本从低到高：

1. **改 Wi-Fi 密码**。进路由器后台（浏览器输 `192.168.1.1` 或 `192.168.0.1`，账号密码看路由器背面标签），改掉无线密码，长度 12 位以上、大小写数字符号混着来。改完所有自家设备要用新密码重连；
2. **加密方式选 WPA2 或 WPA3**，别用已经淘汰的 WEP；
3. **开访客网络给外人用**。朋友来家里要网，发访客网络的密码，别发主网的。访客网络开启「AP 隔离」后，客人设备看不到你家的摄像头、NAS、打印机（路由器后台的常见设置项，各品牌叫法不一）；
4. **改了密码还扫出陌生设备**，说明密码没管住：检查是不是有设备把密码存进了万能钥匙一类的共享工具，或者干脆路由器被蹭了管理后台——重置路由器重新配置最省心。

Fing 本身只负责「让你看见」，拉黑、限速这类动作在手机免费版里做不了：拦截设备、给设备断网限时是桌面版配合付费订阅的功能（详见 [网速测试与断网排查.md](网速测试与断网排查.md) 关于免费与订阅的对照）。改密码这一招不依赖任何订阅，效果也最彻底。
