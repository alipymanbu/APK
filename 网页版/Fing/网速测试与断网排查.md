# 网速测试与断网排查

> 这篇讲用 Fing 测速、判断断网到底是你家的问题还是运营商的问题，以及自带的几个网络诊断工具怎么用。

## 一、先说结论

网卡、断线、刷不动视频，先分清三件事：**外网断了（运营商故障）、外网没断但你家内网堵了（有人狂下东西 / 路由器抽风）、还是单台设备的问题**。手机版里对应这三层的有三组工具：测速 + 断网检测、设备清单、ping / traceroute / 端口扫描。按下面顺序查，一般十分钟内能定位到层。

## 二、测速：下载、上传、延迟

入口在应用里的 Internet（互联网）页，点开始测速，几秒出结果：

| 指标 | 看什么 | 怎么解读 |
| --- | --- | --- |
| 下载速度 | 刷视频、下文件快不快 | 对照你办的宽带套餐标称值，长期只有标称的零头就该找运营商 |
| 上传速度 | 发视频、开视频会议、网盘备份 | 家宽上传通常远低于下载，属正常；但低于 1Mbps 会影响视频通话 |
| 延迟（ping） | 打游戏、点按钮的跟手程度 | 家宽到国内节点个位数到几十毫秒算正常；上百毫秒且波动大，先重启路由器再测 |

**测速前把好三点**，否则数字没有参考价值：

1. 手机尽量贴近路由器，或干脆插网线的设备测——Wi-Fi 信号弱本身就是变量；
2. 关掉正在后台下载、云备份、投屏的应用，它们会吃掉带宽；
3. 连续测两三次取稳态值，单次结果波动很常见。

订阅版支持定时自动测速并保留更长的历史曲线，用来跟运营商对账；免费版手动测，够日常用。测出来一直不达标，拿最近几次截图去找运营商报障——有连续记录比口头说「慢」有用得多。

## 三、断网检测：是全网断还是只有我断

Fing 的断网检测是**众包**式的：同一地区其他用户也在报故障，才能判定「这一片都断了」。你这边打不开网页时开一下这个功能，会直接告诉你两种结论之一：

- **区域性故障**：等运营商修，别折腾家里设备；
- **只有你家断**：往下走第四节。

具体入口名称随版本变化，以应用内实际显示为准。

## 四、只有你家断 / 时断时续，按这个顺序查

1. **看 Fing 的设备列表还刷不刷得出来**。刷得出来 → 内网是通的，问题在外网出口或 DNS；完全刷不出来 → 问题在路由器或内网；
2. **ping 一下外网地址**。用应用内的 Ping 工具，对一台公网设备测响应：丢包严重或全超时，出口有问题；
3. **traceroute 看断在哪一跳**。路由追踪会列出数据包经过的节点，卡在第一跳（你家网关）= 路由器问题；卡在运营商的某一跳 = 报障时把这张图给客服，比「我网不好」清楚十倍；
4. **DNS 查询工具**。域名解析不动也会表现成「网是通的但网页打不开」，换公共 DNS（如运营商给出的备用 DNS）试一下；
5. **端口扫描**。对内网某台主机扫开放端口，看看有没有意外暴露的服务（比如从没开过的远程桌面端口开着）——这条偏排查安全问题，不是修断网的必经步骤。

以上工具都在应用的工具区里，免费版可用。注意：**只对你有权管理的网络用**，扫别人的网络属于越界行为。

## 五、免费版能到哪一步

截至 2026 年 9 月检索到的官方口径（价格与权益随时可能调整，以[官网](https://www.fing.com/)当时显示为准）：

| 能力 | 免费版 | 订阅版（Premium） |
| --- | --- | --- |
| 手动扫描 | 每天最多 3 次 | 不限 |
| 测速 / ping / traceroute / 端口扫描 | 可用 | 可用 |
| 持续监控、定时测速 | 不可用 | 可用 |
| 事件时间线 | 最近 7 天 | 完整 |
| 新设备提醒推送 | 基础 | 手机 + 邮件 |
| 拦截 / 限制某台设备上网 | 不可用 | 可用（需配合桌面版） |

一句话：**只是偶尔看看谁在连、测个速，免费版够用**；要「7×24 盯着 + 出事推送 + 断别人网」才需要掏钱。付费功能的入口在手机上会露出，但拦截类动作实际依赖 Fing Desktop 在你网络里常驻。

## 六、查不出所以然的时候

九成的「测出来不对劲」其实是内网侧的问题：设备连错网、AP 隔离开着、手机权限没授。这类症状与处置见 [扫描不出设备怎么排查.md](扫描不出设备怎么排查.md)；如果你连设备清单都没扫出来，先回 [下载与安装教程.md](下载与安装教程.md) 把权限配好。
