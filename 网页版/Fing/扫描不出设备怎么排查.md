# 扫描不出设备怎么排查

> 这篇解决三类高频症状：扫出来是空的、扫出来的比实际少、设备认出来是错的。

## 一、先分清是哪种「不对」

| 症状 | 最可能的原因 | 对应章节 |
| --- | --- | --- |
| 列表空的，或只扫出自己一台 | 权限没给、连错网络 | 二 |
| 设备数明显少于路由器后台 | AP 隔离、访客网络/VLAN、手机端识别限制 | 三 |
| 设备认成了别的牌子 / 一直显示 Generic | 识别信息不足、MAC 随机化 | 四 |
| 想手动扫却提示由桌面版接管 | 手机与桌面版处于联动状态 | 五 |

## 二、扫出来基本是空的

按这个顺序过一遍，每条都是硬条件：

1. **连对 Wi-Fi**：手机数据流量关掉也无妨，关键是手机确实连在要扫的那个 Wi-Fi 上，而不是邻居的、不是蜂窝网；
2. **位置权限**：安卓把 Wi-Fi 名称算作位置信息，不授权则 SSID 读不出来、网络认不出、每次扫描都从零开始（官方帮助文档明确的后果）。去「设置 → 应用 → Fing → 位置」允许，并确认应用内「设备识别」开关打开；
3. **本地网络权限（iOS）**：iPhone 首次扫描会弹「允许访问本地网络」，拒绝了就一台都扫不到，去「设置 → Fing → 本地网络」补开；
4. **同一网段**：手机连的是访客 Wi-Fi，主网设备天然不可见——这不是 bug，是路由器隔离设计。确认自己连的是主网络，或去路由器后台看访客网络是否开了隔离。

授权之后**重新扫一次**才生效，别拿旧结果下结论。

## 三、扫出来的比实际少

手机扫出 12 台、路由器后台显示 16 台，差的那几台去这几处找：

- **AP / 客户端隔离**：路由器后台里叫 `AP Isolation`、`Client Isolation` 或「网络隔离」的开关打开后，无线设备之间互相看不见，扫描器同理受限；
- **访客网络 / VLAN**：挂在访客 SSID 或 IPTV 等独立 VLAN 下的设备，主网扫描不到，属正常；
- **设备躲探测**：部分设备对 ARP 探测不回应、防火墙拦 ICMP，会漏。第三方实测这类环境的识别率在八成多，**交叉核验**（路由器后台 vs Fing）比单信一边可靠；
- **Android 的 MAC 限制**：2023 年起谷歌要求应用不能再读取设备 MAC 地址，手机版扫描改为按 IP 识别，识别细度下降；此前扫到过的 MAC 在不刷新网络的前提下仍保留，一旦刷新则丢失（官方公告口径）。想要最全的数据，用同一账户配一个 Fing Desktop，桌面版不受此限制，数据会同步回手机。

经验做法：后台说 5 台、Fing 扫出 7 台，多半是路由器把断线设备也列着；反过来 Fing 少，就按上面四条查。

## 四、设备认成 Generic / 认错型号

识别是尽力而为，信息就那么多时认不准很正常：

1. **手动改**：进设备详情，用「识别得对吗」的否定入口，从候选里选对品牌、型号，保存；
2. **iOS 设备开了私有地址**：iPhone 的「私有 Wi-Fi 地址」（即 MAC 随机化）会让同一台 iPhone 每次看起来都不一样，识别会反复归零。稳定识别可在该 Wi-Fi 下关闭私有地址开关（系统设置里针对该网络）；
3. **DHCP 没刷新**：设备租约信息没更新，识别依据就旧。重启该设备或等一轮租约刷新再扫。

改过的信息在登录账户、位置权限齐全的前提下会保留；每次扫描都回退成默认值，就是权限没给全的信号（回到第二节）。

## 五、提示由桌面版扫描 / 手机上点不动扫描

手机与桌面版用同一账户联动时，**数据以桌面版扫描为准**，手机端不单独发起扫描。要恢复手机手动扫，官方给的路径是：

1. 用桌面版同款账户登录手机 Fing；
2. 设备列表页右上角圆形三点图标进入网络列表；
3. 对桌面版那条网络左滑，点红色「删除」，选择删除当前网络或分离全部网络。

分离后该网络回到「已扫描网络」列表，手机可以重新手动扫。注意：这只是解除联动，不会删除你网络里的任何东西，重新扫描随时能建回来。

## 六、还是不行的兜底

1. 杀掉应用重开、退出登录再登一次（部分状态只有重登才刷新）；
2. 换一台设备连同一 Wi-Fi 扫一遍：能扫出来说明是原手机的权限/系统限制，扫不出来说明是路由器侧的隔离设置；
3. 直接登录路由器后台看设备列表——那是权威数据源，Fing 的价值在识别与提醒，不在取代后台。
