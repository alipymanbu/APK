## 一、先看懂状态标签

官方把每条转换路线标了状态，本篇照搬这个口径：

| 标签 | 含义 |
| --- | --- |
| 稳定（Stable） | 已在真机用真实文件验证过 |
| Beta | 可用，但有明确写出的边界情况 |
| 实验性 | 能跑，但受设备差异影响大 |
| 计划中 / 不支持 | 还没做，或有意不做 |

它不是「万能转换器」：官方明确不承诺任意格式互转，没验证过的路线不会吹成支持。支持状态可能随版本更新变化，以官方仓库的支持矩阵为准。本清单按官方最新版整理；**网盘里那份 0.2.0 版不含下文标注了起始版本的功能**，逐条对照见 [版本更新与功能差异.md](版本更新与功能差异.md)。

## 二、视频

输入格式：MP4、MKV、MOV、WEBM、AVI、3GP、3GPP、TS、MTS。

| 转换方向 | 状态 | 关键限制 |
| --- | --- | --- |
| 视频转 MP4 / MKV / MOV | 稳定 | 重新编码为 H.264 或 H.265，音频 AAC；字幕、附件、多余音轨不保留 |
| 视频转 WEBM | 稳定 | 视频默认 VP9（可选 VP8），音频 Opus |
| 多个视频合并（0.2.1 起） | 稳定 | 按所选顺序拼接；分辨率不一致时自动加黑边适配；无声片段自动补静音轨 |
| 视频转 GIF | 稳定 | 只取选定范围的前 30 秒、最多 30 fps、900 帧；短边默认压到 480 px（可选 720 px 或原始尺寸） |
| 视频转概览拼图（0.2.3 起） | 稳定 | 按时间均匀采样生成 3×3 / 3×4 / 4×4 / 5×5 网格打样图，可导出 JPG 或 PNG |

## 三、音频

| 转换方向 | 状态 | 关键限制 |
| --- | --- | --- |
| 从视频提取音频 → MP3 / M4A / WAV / FLAC / WMA / OPUS | 稳定 | 只取第一条音轨；M4A 是 AAC 重编码而非直接复制 |
| 音频互转（MP3 / M4A / AAC / FLAC / WAV / WMA / OGG / OPUS 之间） | 稳定 | MP3 可选 CBR 码率或 VBR 档位（V0/V2/V4/V6）；OPUS 固定 48 kHz 采样，其他采样率会自动重采样到 48 kHz；WAV / FLAC 不涉及码率选项 |

## 四、图片

| 转换方向 | 状态 | 关键限制 |
| --- | --- | --- |
| JPG / JPEG / JFIF / JPE / PNG / WEBP 互转，或转 ICO | 稳定 | 转换不复制元数据；PNG/WEBP/ICO 保留透明通道，转 JPG/JFIF 时透明压平成白底 |
| GIF → 静态图 | 稳定 | 可选只转第一帧，或拆帧输出到文件夹；动画时序与循环信息不保留 |
| HEIC / HEIF → 常见图片格式 | Beta | 走系统解码器，能否转成功取决于你的手机芯片支持 |
| ICO → 其他格式 | 稳定 | 只读取最大一层，且要求图标内是 PNG 载荷；老的 BMP 图标载荷读不了 |
| 任意常见图片 → PDF | 稳定 | 每张图一页，页面可选 A4 适配或按原图比例 |
| 图片超分辨率 | 稳定 | 双线性 2×/3×/4×，或 Real-ESRGAN 4× AI 模型（模型按需下载，见 [图片与PDF转换操作指南.md](图片与PDF转换操作指南.md)） |

## 五、PDF 与 Office 文档

| 转换方向 | 状态 | 关键限制 |
| --- | --- | --- |
| PDF → JPG / PNG / WEBP | 稳定 | 逐页栅格化成图片，不提取嵌入原图，也不做 OCR |
| 多个 PDF 合并 | 稳定 | 按页对象合并，普通文字与矢量内容尽力保留；复杂表单、书签、附件不保证 |
| PDF → TXT / Markdown | 稳定 | 只导出可选中文字；扫描版 PDF 没有文字层，会明确失败 |
| PDF 压缩（0.2.1 起） | 稳定 | 三档（高画质 / 均衡 / 小体积），通过降采样内嵌图片实现，正文文字与版式保留 |
| PDF 加密 / 解密 | 稳定 | 加密=给输出加打开密码；解密要求你能正常打开源文件或提供密码——它不做密码破解 |
| DOCX / PPTX / XLSX → PDF / TXT / MD | Beta | 源文件上限 64 MiB；本地渲染，默认用系统字体出中文，复杂中日韩字体可在设置里按需下载高保真 Noto 字体；复杂版式（文字重叠、形状错位）是预期内的，不承诺与 Office 完全一致 |

## 六、字体与字幕歌词

| 转换方向 | 状态 | 关键限制 |
| --- | --- | --- |
| TTF / OTF / WOFF / WOFF2 互转 | 稳定 / Beta | 整包容器转换，不做字体子集化、不改轮廓；WOFF2 方向要求 64 位设备 |
| SRT / VTT / LRC / ASS 互转 | Beta | 只支持这四种，不支持 TXT；转成 SRT/LRC 时样式全部丢弃（ASS 特效、WebVTT 设置不保留）；LRC 没有结束时间概念 |

字幕文件输入上限 8 MiB；文本按 UTF-8 读取，读不动时自动回退 GB18030/GBK，常见中文字幕不受影响。

## 七、它明确不做什么

- 不做 OCR：扫描版 PDF 无法变出文字层。
- 不解密受保护的文件：PDF 解密工具只处理你有权打开的文件。
- 不承诺任意格式：官方支持矩阵里「Any → Any」标的是 Planned（未实现），遇到矩阵外的格式就转不了。
- 不上传文件：所有转换在手机本地完成，这也是它和在线转换网站最大的差别。
