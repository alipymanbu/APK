## 一、把文件加进任务队列

三种进文件的方式，按场景挑：

- **分享 / 打开方式**：在文件管理器或相册里选中文件，点「分享」或「打开方式」，选 ZenConverter，输出格式会自动预选。
- **相册 / 文件夹批量导入**：在应用内直接选一批同类文件，一次性进队列。
- **逐文件设置**：队列里每个任务可以单独设目标格式与参数；混合类型的文件会被自动分开路由到各自的转换路线。

任务进入队列后由前台服务执行，通知栏能看到逐任务进度；不需要盯着屏幕等，但**转大视频时别把应用从后台划掉**，也别在电量告急时开跑。

一个已知的不便：应用内导入走系统自带的文件选择器，选不了第三方文件管理器（有用户提过希望接入 MT 管理器这类工具，尚未实现）。习惯用第三方管理器的，从管理器里选中文件后「分享」给 ZenConverter 即可绕过。

## 二、视频转格式（MP4 / MKV / MOV / WEBM）

选好目标容器后，有两种参数模式：

**1. 压缩预设（省事路线）**

一键模板，替你定好编码、CRF 质量档、分辨率与帧率策略和 AAC 音频码率，适合「不想研究参数、就想要个能发出去的小文件」。选了预设之后，裁剪范围仍然可以自己调。

**2. 手动模式（可控路线）**

| 参数 | 你能调什么 | 怎么选 |
| --- | --- | --- |
| 视频编码 | H.264 / H.265 | H.265 体积更小但老设备可能放不了；发给别人的文件优先 H.264 |
| 码率 | 手动指定 | 值越大越清晰、体积越大 |
| 分辨率上限 | 限制短边 | 压小体积先从这里下手，比拉低码率更不容易糊 |
| 帧率上限 | 设定最大帧率 | 源视频低于上限时不会强行补帧 |
| 音频 | 编码、码率、采样率 | 默认 AAC 即可满足大多数场景 |
| 裁剪范围 | 可视化拖拽选起止点 | 想截取片段时用；多段分割要 0.2.1 及以上（网盘 0.2.0 版只有基础裁剪） |
| 高级处理 | 倒放、淡入淡出、镜像、旋转、画幅适配/裁剪 | 见第五节 |

字幕轨、附件、多余音轨在任何方向上都不会被复制——转出来的文件只有第一条视频轨和重编码后的音频。

## 三、多个视频合并（0.2.1 起）

这一项是 0.2.1 才加入的功能，网盘里的 0.2.0 版没有；版本对照见 [版本更新与功能差异.md](版本更新与功能差异.md)。

1. 一次选中多个视频文件（按你选择的顺序拼接，所以先排好顺序）。
2. 目标格式选 MP4 / MKV / MOV / WEBM 之一。
3. 分辨率不一致时不用预处理：应用会按参考视频（或你指定的分辨率上限）自动加黑边适配比例，音频统一成目标容器的标准参数；没有声音的片段会自动补静音轨。

## 四、视频转 GIF 与概览拼图

**转 GIF** 的默认参数偏保守：输出只取你选定范围的前 30 秒、最多 30 fps、900 帧，短边默认压到 480 px（可选 720 px 或原始尺寸）。想转更长的动图，先在源视频上把起止点挪到想要的那一段——超过 30 秒的部分会被截掉。

**概览拼图**（Contact Sheet，0.2.3 起）把视频按时间均匀采样拼成一张网格图，常用来快速预览一部片子拍了什么：

- 网格可选 3×3（9 帧）、3×4（12 帧，默认）、4×4（16 帧）、5×5（25 帧）——行数列数目前是固定档位，不支持自定义（有用户提过这个需求）；
- 可开关参数信息头（编码、分辨率、帧率、码率等）和每帧时间戳角标；
- 导出 JPG 或无损 PNG。

## 五、高级处理

| 处理 | 用在 | 说明 |
| --- | --- | --- |
| 倒放 | 视频、音频 | 视频倒放限制在 60 秒以内、源文件要能读出时长与体积信息 |
| 淡入淡出 | 视频、音频 | 常给片段开头结尾加 |
| 镜像 / 旋转 / 画幅适配与裁剪 | 视频 | 竖拍转横、微调构图用 |
| 降噪 | 音频 | 无需下载模型的 afftdn 降噪 |
| 音量 / 静音、回音 | 音频 | 静音适合「只要画面」的场景 |

## 六、提取音频与音频互转

**从视频抽音轨**：选视频文件，目标格式选 MP3 / M4A / WAV / FLAC / WMA / OPUS，只导出第一条音轨。配合裁剪范围可以只抽某一段。注意两点：

- M4A 走 AAC 重编码而不是直接复制音轨，所以「提取」同样要花转码时间，源文件越长越久——这是官方路线的设计，不是卡住了；
- 输出文件不带内嵌封面图（封面属于附件流，转换不复制），转出的 MP3 在播放器里可能显示无封面。

**音频之间互转**（MP3、M4A、AAC、FLAC、WAV、OGG、OPUS 输入）：

- MP3：要压缩率就选 CBR 码率；要「最好质量」直接挑 VBR 档位 V0（体积大）→ V2（常用）→ V4 → V6（体积小）。
- WAV / FLAC：无码率选项，转无损归档用。
- OPUS：固定工作在 48 kHz，源文件是 44.1 kHz 会自动重采样；可选项只有 {48k, 24k, 16k, 12k, 8k}。
- 同样支持倒放、淡入淡出、音量调整、回音与降噪。

## 七、AI 补帧（实验性，0.2.2 起）

RIFE 2× 补帧能把 30 fps 视频插到 60 fps，基于手机 GPU（Vulkan）跑。这是 0.2.2 才加入的实验功能，网盘里的 0.2.0 版没有：

- 模型不内置，首次使用会按需下载并校验 SHA-256，这一步需要网络；
- 1080p 以上自动按显存调整策略；
- 不同芯片的 GPU 驱动差异大，这个功能目前标实验性——失败就当试错，重要素材先转一份普通版本保底。

## 八、转换中与转换后

- 转换在前台服务里跑，通知栏有逐任务进度，可随时取消。
- 完成后可以直接把输出分享出去，或尽力打开输出文件所在位置。
- 超大视频要预留存储空间、内存与电量；转之前看一眼剩余空间，比转到一半失败省事。

格式支持边界（你的源文件在不在清单里）看 [功能与格式支持清单.md](功能与格式支持清单.md)；任务卡住或失败，去 [常见问题与转换失败排查.md](常见问题与转换失败排查.md)。
