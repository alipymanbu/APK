## 一、安装前先确认两件事

ZenConverter 是安卓应用，装之前先核对你的设备：

| 检查项 | 要求 | 说明 |
| --- | --- | --- |
| 设备架构 | 64 位（arm64-v8a） | 官方发布的 APK 只含 arm64-v8a，32 位手机装不了这个包 |
| 系统版本 | 较新的安卓系统 | 第三方商店的版本页显示需要 Android 8.0 及以上，以官方发布页为准 |
| 存储空间 | 安装包约 49 MB，另留转换余量 | 转大视频时，源文件与输出文件都需要临时空间 |

安装包体积以你实际拿到的那份为准——网盘里这份 0.2.0 版约 49.21 MB，官方后续版本的体积可能变化。

## 二、从哪里拿安装包

三个渠道任选其一：

| 渠道 | 适合谁 | 说明 |
| --- | --- | --- |
| 本文开头的 ZenConverter 安装文件资源（夸克网盘） | 想直接转存、不想去海外商店的人 | 转存到自己网盘后下载即可，对应 0.2.0 版 |
| [GitHub Releases](https://github.com/Jasonzhu1207/ZenConverter/releases) | 想要最新版、想核对来源的人 | 官方发布页，能看到每个版本的更新说明 |
| [Google Play](https://play.google.com/store/apps/details?id=org.zenconverter.app) | 能访问 Play 商店的人 | 应用包名 `org.zenconverter.app`，可在商店里核对 |

想校验下载到的包是否完整，可以比对 MD5：

```text
MD5: 377DE1BB03D7D1A91E7154B67A065F59
版本: 0.2.0
```

这是上文网盘资源里那份 0.2.0 包的校验值；从别的渠道拿到的更新版本，MD5 自然不同。这份 0.2.0 包还与 GitHub 官方 v0.2.0 发布的 APK 逐字节一致（SHA-256 相同），来源可放心。

## 三、安装步骤

1. 把 APK 下载到手机本地存储。
2. 在文件管理器里点开这个 APK。系统第一次会提示「禁止安装未知应用」，按提示允许**你用来打开 APK 的那个应用**（文件管理器或浏览器）安装应用即可，不用全局放开。
3. 点「安装」，等进度走完。
4. 装完点「打开」，或在桌面图标启动。

如果安装到一半提示「解析包出现问题」，多半是下载不完整——重新下载并比对上面那份 MD5；如果提示与应用冲突，看 [常见问题与转换失败排查.md](常见问题与转换失败排查.md) 里签名冲突的处理。

## 四、装好后的第一次启动

- **权限**：首次添加文件时会请求存储相关权限，允许后才能读到手机里的视频、图片；转换期间会出现常驻通知（前台服务进度），通知权限也建议打开。
- **界面语言**：应用内直接切换简体中文、繁体中文、英文、法文是 0.2.3 起的功能；0.2.0（网盘这份）为中文界面。
- **外观**：深色模式是 0.2.2 起加入，Material You 动态取色是 0.2.3 起加入；0.2.0 只有浅色主题。各版本功能差异见 [版本更新与功能差异.md](版本更新与功能差异.md)。
- **联网行为**：日常转换不需要网络。应用只在两种情况下联网——手动检查更新、按需下载 AI 模型或高保真字体（见 [图片与PDF转换操作指南.md](图片与PDF转换操作指南.md)）。

## 五、升级与卸载

- 覆盖安装新版本时，包名与签名要一致。如果你先装过 GitHub Releases 的包、再想装网盘这份（或反过来），遇到签名不一致的提示，需要先卸载旧版再装——**卸载前把还没拿到的转换结果先分享导出**。
- 应用自身不自动后台更新，想升级就隔段时间去 GitHub Releases 或商店看一眼。0.2.0 与 0.2.3 之间的功能差距（视频合并、多段分割、PDF 压缩、AI 补帧等）逐条列在 [版本更新与功能差异.md](版本更新与功能差异.md)，先看完再决定要不要升。
