## 一、图片格式互转

**输入**：JPG / JPEG / JFIF / JPE、PNG、WEBP、GIF、HEIC / HEIF、ICO。
**输出**：JPG / JFIF / PNG / WEBP / ICO / PDF。

选输出格式前先弄清楚这几件事：

| 事项 | 说明 |
| --- | --- |
| 质量档位 | JPG / JFIF / WEBP 有四档：原始 100、高 95、均衡 85、小体积 60；PNG 永远无损输出 |
| WEBP 无损 | 需要 Android 11 及以上才可选无损输出 |
| 透明通道 | 转 PNG / WEBP / ICO 时保留；转 JPG / JFIF 时透明区域压平成白色 |
| 元数据 | 转换不复制 EXIF 等元数据（拍摄信息会丢）；JPEG 的方向信息会尽力保留 |
| 动图 | WEBP 动图只取画面不保留动画；GIF 另有专门处理，见下一节 |
| ICO 输出 | 生成的是内嵌多尺寸 PNG 的标准图标文件 |

ICO 作为输入时有个坑：只有图标内层是 PNG 载荷才能读，遇到很老的制作工具导出的 BMP 载荷图标会转不了。

## 二、GIF 的三种处理方式

同一个 GIF 源文件，你可以：

1. **只转第一帧**——要一张静态封面图时用；
2. **拆帧输出**——把每一帧导出成图片存到一个子文件夹里，适合逐帧取素材；
3. **当静态图转格式**——按上一节的规则转成 PNG / WEBP 等。

拆帧走 FFmpeg 解码路线，动画时序、循环次数、帧延迟都不保留——你要的是那一叠图，不是能动的 GIF。

## 三、图片超分辨率（放大不糊）

输出 JPG / JFIF / PNG / WEBP 时可以叠加放大倍率，两条路线：

| 路线 | 倍率 | 特点 |
| --- | --- | --- |
| 双线性插值 | 2× / 3× / 4× | 秒出，但只是普通拉伸算法，放大越多越模糊 |
| Real-ESRGAN AI 模型 | 4× | 基于深度学习模型重建细节，不是单纯拉伸；速度慢很多 |

AI 模型的实际使用要点：

- **模型按需下载**：应用不内置模型，首次使用要联网下载并做 SHA-256 校验；有 4.65 MB 的通用紧凑模型和 63.9 MB 的高画质模型两档。
- **分块推理**：大图按瓦片分块处理，按手机内存动态分配像素预算，一般不会直接内存溢出，但大图耗时会成倍增长。
- **不保透明**：AI 放大后的输出没有透明通道，带透明的 PNG 先想清楚。
- 开启放大时画质固定用原始质量档，GIF 拆帧选项也会隐藏。

## 四、图片拼 PDF

选一批图片，输出选 PDF：

- **每张图一页**，页面两种模式：A4 适配（带白底）或按原图比例；
- **多张合成一个多页 PDF**，或每张图各自生成一个 PDF；
- 页面保持图片原有比例，不裁切。

## 五、PDF 转图片

选 PDF，输出 JPG / PNG / WEBP，逐页导出成图片：

- 这是**栅格化**——把每一页渲染成图片，适合发预览图、做快照；
- 它不是「提取 PDF 里的原图」：页面上的文字会变成图片的一部分，不再可选；
- 多页 PDF 一次性输出为一组同尺寸图片。

## 六、PDF 工具箱

| 操作 | 怎么用 | 值得知道的 |
| --- | --- | --- |
| 合并多个 PDF | 一次选多个文件，按顺序合并 | 按页对象合并而非截图拼接，普通文字层和矢量内容尽力保留；复杂表单、书签、附件不保证跟着走 |
| 导出文字（TXT / MD） | 选 PDF，输出 TXT 或 Markdown | 只导出可选中文字；Markdown 版会带文档标题和分页标题；**扫描版没有文字层，会明确失败**，这不是故障 |
| 压缩（0.2.1 起） | 三档：高画质 / 均衡 / 小体积 | 原理是把内嵌图片降采样重编码，正文文字、矢量与版式不动；源文件图片占比越高，压得越狠 |
| 加密 | 给输出 PDF 设一个打开密码 | 密码只存在于内存中，不落盘 |
| 解密 | 打开源文件（或提供密码）后移除安全限制 | 它不做密码破解——不知道密码的 PDF 解不开 |

Office 文档（DOCX / PPTX / XLSX）也能本地转出 PDF / TXT / MD，这条 Beta 路线的限制（64 MiB 上限、版式偏差）写在 [功能与格式支持清单.md](功能与格式支持清单.md)。中文显示问题先查字体：0.2.0 起默认用系统字体渲染，出方块或字形缺失时，到设置里按需下载高保真 Noto CJK 字体再转。

转出来的文件去哪了、转换中途取消会怎样，见 [常见问题与转换失败排查.md](常见问题与转换失败排查.md)；「压缩」等功能的版本归属见 [版本更新与功能差异.md](版本更新与功能差异.md)。
