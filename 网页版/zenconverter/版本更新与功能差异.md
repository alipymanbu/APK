## 一、先确认你手上是哪个版本

- 网盘资源里那份是 **0.2.0**，安装包约 49.21 MB。
- 这份包与 GitHub 官方 v0.2.0 发布的 APK 逐字节一致（SHA-256 相同：`040d5dcd00977fb120f3e942d69d381acb998dfcf1441f3574425ae4ab8335ff`），校验通过的可以放心用。
- 官方迭代很快，2026 年 9 月已发布到 0.2.3（另有跟随主干持续构建的预发布版）；最新版本号以 [GitHub Releases](https://github.com/Jasonzhu1207/ZenConverter/releases) 页面为准。

在应用内看版本：设置或「关于」页一般会标出；对不上时以安装包属性为准。

## 二、功能是在哪个版本加入的

按官方各版本发布说明整理（截至 0.2.3，之后的新版本以发布页为准）：

| 版本 | 加入的主要功能 |
| --- | --- |
| 0.1.5 | 图片 / 视频元数据查看、清理、备份与恢复；模板化一键压缩；通过分享或「打开方式」导入任意文件 |
| 0.1.8 | TTF / OTF / WOFF / WOFF2 字体互转 |
| 0.1.9 | 图片超分辨率（双线性 + Real-ESRGAN 4×）；SRT / VTT / LRC / ASS 字幕歌词互转 |
| **0.2.0（网盘这份）** | Opus 音频输出；Office 转换默认用系统字体渲染、支持按需下载高保真 CJK 字体 |
| 0.2.1 | 多个视频合并；视频 / 音频统一裁剪与多段分割；PDF 压缩（三档）；自定义输出目录失效时自动回退默认目录 |
| 0.2.2 | 深色模式与主题适配；RIFE 2× AI 视频补帧（实验性）；AI 推理迁移到 NCNN + Vulkan |
| 0.2.3 | 视频概览拼图；Material You 动态取色；应用内切换界面语言（简中 / 繁中 / 英 / 法）；查看 HEIC / HEIF 元数据；输出文件命名清理 |

也就是说：**0.2.0 已经有**全部基础转换（音视频转码、图片、PDF、Office、字体、字幕、超分、元数据清理）；**0.2.0 没有的**主要是视频合并、多段分割、PDF 压缩、AI 补帧、概览拼图、界面多语言切换和深色模式。

## 三、要不要升级

按你的用法判断：

| 你的需求 | 建议 |
| --- | --- |
| 单个文件转格式、抽音频、图片 PDF 互转 | 0.2.0 够用，不必折腾 |
| 要合并多个视频、把长视频切多段 | 至少升到 0.2.1 |
| 要 AI 补帧、深色模式 | 至少升到 0.2.2 |
| 要概览拼图、界面切英文 / 法文、看 HEIC 照片元数据 | 至少升到 0.2.3 |

升级方式与签名注意事项见 [下载与安装教程.md](下载与安装教程.md) 第五节；合并、补帧等新功能的具体玩法见 [视频与音频转换操作指南.md](视频与音频转换操作指南.md)。
