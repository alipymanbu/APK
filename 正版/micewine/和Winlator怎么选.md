# MiceWine 和 Winlator 怎么选：安卓跑 Windows 程序的两个主流方案

> MiceWine 与 Winlator 干的是同一件事：在安卓手机上跑 Windows 程序与 PC 游戏。本篇把两个方案在安装、首次配置、硬件适配上的实际差异摆出来，按你的机型对号入座。

## 一、先说共同点

- 都是免费的开源项目，都不在应用商店上架，安装时都要自己放行「未知来源」；
- 思路同类：把 Windows 程序的调用翻译给安卓（Linux）执行，再配上 x86 指令翻译 —— 所以跑的都是真正的 exe，不是移植版；
- 都不用 Root，都在快速迭代，兼容情况随时可能因一次更新而改变。

## 二、实际差异在哪

把两边截至 2026 年 9 月的情况并列在这里（都以各自官方发布页的最新说明为准）：

| 对比项 | MiceWine | Winlator |
| --- | --- | --- |
| 装机体积 | 安装包 32.55M | 社区下载页给的安装包量级在 200MB 上下（版本差异大），还要再放一个 OBB 数据文件 |
| 首次配置 | 应用内下载一个 rootfs（约 500MB），一路走完 | 建「容器」、放 OBB，再进容器里选图形驱动 |
| 系统门槛 | 官方口径 Android 10+ | 社区说法在 Android 8~9 之间不等，比 MiceWine 松 |
| GPU 适配 | 官方主打 Adreno 6xx / 7xx，其他 GPU 实验性 | 生态更宽：Mali 芯片有专门分支，新版还在加针对 Mali 的封装 |
| 可调项 | 分辨率、帧率上限、MangoHUD、任务管理器分核 | 容器制图形驱动选择、DX 封装（DXVK 等）、大量细调项 |
| 社区体量 | 项目较小，可查的教程少 | 用户多、讨论多、分支多（Frost、GlibC 等） |

## 三、按机型对号入座

- **骁龙（Adreno 6xx/7xx）**：两个都值得试。想少折腾、步骤一条道走完，MiceWine 的流程更短；想对每个游戏单独细调驱动与封装，Winlator 的选项更多。
- **天玑 / 麒麟（Mali）**：MiceWine 这边有用户反馈暂时跑不起来、官方也只给到实验性支持；Winlator 生态里有面向 Mali 的分支可以试，但兼容性同样打折扣。芯片适配的细节见 [常见问题与报错排查.md](常见问题与报错排查.md)。
- **老机型（Android 8~9）**：MiceWine 的官方门槛是 Android 10+，达不到就只剩 Winlator 一条路（能不能跑、跑多顺，以你设备的实际表现为准）。

## 四、两手都装也没冲突

两个应用包名不同（MiceWine 是 `com.micewine.emu`，Winlator 是 `com.winlator`），数据目录也互不相干，可以同时装在一台手机上 —— 同一个游戏在两边各试一次，哪个跑得好用哪个。装好 MiceWine 之后的流程见 [下载与安装教程.md](下载与安装教程.md)。
