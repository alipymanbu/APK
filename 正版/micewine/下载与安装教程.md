## 一、装之前，先对一遍设备条件

MiceWine 是一个在安卓手机上运行 Windows 应用与 PC 游戏的开源项目（开发者 KreitinnSoftware，MIT 许可，代码在 [GitHub 仓库](https://github.com/KreitinnSoftware/MiceWine-Application)），中文社区里常被叫作「老鼠酒」。它不是把 Windows 整个装进手机，而是给 Windows 程序提供一个能跑起来的运行环境。

动手之前，按下面这张表对一遍你的手机：

| 条目 | 参考门槛 | 说明 |
| --- | --- | --- |
| 系统版本 | Android 10 及以上 | 官方仓库给出的口径，低于此版本装上也起不来 |
| 处理器 | 高通骁龙为主 | 官方主要适配 Adreno 6xx / 7xx 系列 GPU；其他 GPU 属于部分支持、实验性 |
| 内存 | 建议 4GB 起 | 社区资料普遍提到的门槛，加载桌面环境本身就要吃掉一块内存 |
| 图形 | Vulkan 1.1+ | 社区资料提到的门槛，具体以官方发布页为准 |
| 存储空间 | 2GB 以上富余 | 安装包 32.55M、rootfs 数据包约 500MB，之后装游戏还要更多 |
| Root | 不需要 | 全程在应用层完成 |

本文以 **v0.5.0** 为准来写流程；你的版本若更新，界面入口名称可能有出入，思路不变。还在犹豫该用 MiceWine 还是同类工具的，可以先看 [和Winlator怎么选.md](和Winlator怎么选.md) 再决定装谁。

## 二、拿安装包

v0.5.0 的安装包大小为 32.55M，文件 MD5 是 `3C43037CBCE4B66E6A9AD75FF3AFF7DE`。

MiceWine 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/4a953041409f](https://pan.quark.cn/s/4a953041409f)，转存后把 APK 下载到手机即可。

装完之后，可以到 系统设置 → 应用管理 里查一下这个应用的包名，应该是 `com.micewine.emu` —— 用它确认你装的是这个项目本身，而不是名字相近的别的东西。

## 三、安装 APK

1. 先在 系统设置 → 安全/隐私 → 安装未知应用 里，给你用来传文件的应用（浏览器或文件管理器）放行；
2. 点开 APK，确认安装；
3. 装完先不用急着研究界面 —— 首次启动还有一步 rootfs 要处理，见下一节。

## 四、首次启动：准备 rootfs

rootfs 可以理解为 MiceWine 进入 Windows 桌面环境所依赖的一套基础文件，aarch64 架构的数据包约 500MB。**v0.5.0 起，应用内就能直接下载它**，不用再到处找包：

1. 打开 MiceWine，按提示授予存储等权限；
2. 应用检测到还没有 rootfs，会弹出下载提示，在网络稳定的环境里等它下完（约 500MB，注意流量）；
3. 下载完成后自动解压，应用重启，你会进入一个类似 Windows 10 的桌面环境（内置环境默认对应 Windows 10）。

用更早版本、或应用内下载反复失败时，社区里的常见做法是去官方仓库的 Releases（发布）区手动下载 aarch64 的 rootfs 数据包，放进手机存储后按应用提示选择该文件。具体入口以你手上版本的界面为准。

下载卡住、失败或加载不出来时，排查思路见 [常见问题与报错排查.md](常见问题与报错排查.md)。

## 五、进了桌面之后

- 想把你自己的游戏或软件跑起来：从拷文件到点开 exe，见 [运行EXE与基础操作.md](运行EXE与基础操作.md)；
- 画面卡、帧数低：分辨率与帧率都在设置里调，见 [性能优化与画面设置.md](性能优化与画面设置.md)；
- 打算外接手柄或键鼠：见 [手柄与键鼠操作设置.md](手柄与键鼠操作设置.md)。
