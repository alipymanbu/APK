## 一、两条路线：挑现成的，还是自己捏

登录之后你有两条路：

- **直接选现成角色**：应用内置大量原创角色，第三方介绍提到题材覆盖浪漫、奇幻、科幻等类型，具体角色有各自的外貌、声线、性格与背景设定，搜索角色名称或创作者就能定位；
- **自己创建角色**：登录后点底部的**创建**按钮，从名字开始一项项设定，捏出只属于你的那一个。

两条路不冲突，很多人是先玩几个预设角色找到喜欢的互动感觉，再动手捏自己的。

## 二、自定义角色能设哪些属性

综合第三方商店页的描述，创建角色时可以设定的属性包括：

| 属性 | 说明 |
| --- | --- |
| 名称 | 角色的名字 |
| 年龄 | 可自定义 |
| 性别/类型 | 创建时选择 |
| 外观 | 外貌细节可自定义 |
| 职业 | 可自定义 |
| 性格 | 决定 AI 回应的语气与互动风格 |
| 背景故事 | 可以自己写一段世界观，让角色「生活在」某个设定里 |

第三方页面还提到，创建时有**人设模板**、**场景关键词提示**等辅助工具，提供创建教程、文件导入、模板下载功能——不擅长从零写设定的话，先套一个模板再改，比空着起步快得多。

## 三、从关键词到剧情：创建时的小技巧

- 第三方介绍提到应用提供「古风宅院」「职场危机」这类**分类关键词**，输入场景关键词还能生成多结局故事——给角色配背景故事时，用这些现成关键词打底，再往里加你的私设；
- 性格一栏别只写一个词，写清「遇到冲突时的反应」「说话的习惯」这类可被对话直接体现的细节，互动时差异会明显得多；
- 角色库支持按**标签筛选**（第三方页面提到的标签包括「原创」「自设」等），逛别人公开的自设角色也是找灵感的路子；
- 第三方页面还提到一个**共创池**：用户在那里交流聊天体验，创作方也会参考其中高质量内容做角色设计——你在里面看到的人气设定，可以作为自己捏角色的参考；捏好的角色和原创剧情还能发布到社区供他人浏览评论，这套以女性创作为核心的社区生态是它与传统单机聊天工具明显不同的地方。
