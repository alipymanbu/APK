## 一、游戏怎么运转

The Password Game 是 Neal Agarwal 2023 年 6 月上线的解谜项目：你只需要「设一个密码」，但规则会一条条加上来，总共 35 条。两个基本盘要先知道：

- **老规则永久生效**：新规则出现后，之前所有规则仍然必须同时满足——改一处可能连环破坏前面几条，所以每加一个字符都要回头看一眼；
- **第 34 条是官方玩梗**：它只会显示「这条规则跳过」；最后一条（第 35 条）要求把**当前时间（HH:MM）**写进密码。规则的先后以游戏内实际顺序为准。

集齐全部 35 条、点了确认之后还没完：你要在**两分钟倒计时内把整条密码重新手打一遍**，复制粘贴无效，打错就得重来。

## 二、35 条规则分阶段速览

### 第 1—10 条：假装是正常注册页

| 条目 | 要求 |
| --- | --- |
| 1 | 密码至少 5 个字符 |
| 2 | 包含数字 |
| 3 | 包含大写字母 |
| 4 | 包含特殊符号 |
| 5 | 所有数字之和等于 25 |
| 6 | 包含一个月份的英文名 |
| 7 | 包含罗马数字 |
| 8 | 包含一个「赞助商」名字（百事 / 星巴克 / 壳牌 三选一） |
| 9 | 密码里的罗马数字相乘要等于 35 |
| 10 | 把图里的验证码（CAPTCHA）原样写进去 |

### 第 11—25 条：脑洞铺开

| 条目 | 要求 |
| --- | --- |
| 11 | 包含今天的 Wordle 谜底（每天变） |
| 12 | 包含一个元素周期表的双字母元素符号 |
| 13 | 包含当前月相的 emoji |
| 14 | 看街景图猜出国家名并写进去 |
| 15 | 包含一个闰年 |
| 16 | 写出棋局的最优解（代数记谱法） |
| 17 | 一颗蛋「Paul」，放进密码并保护好，别删它 |
| 18 | 密码中元素的原子序数加起来等于 200 |
| 19 | 所有元音字母加粗 |
| 20 | 密码着火了，在火烧掉密码前把火苗删干净 |
| 21 | 放入 4 个举重 emoji |
| 22 | 包含「i am loved」/「i am worthy」/「i am enough」之一 |
| 23 | 蛋孵出来了，每约 20 秒喂一条虫（或每 50 秒喂 3 条），饿死就完 |
| 24 | 找一个指定时长的 YouTube 视频，把链接写进密码 |
| 25 | 挑两个字母，之后不许再用它们 |

### 第 26—35 条：排版地狱

| 条目 | 要求 |
| --- | --- |
| 26 | 斜体数量要是加粗数量的两倍 |
| 27 | 至少 30% 的内容用 Wingdings 字体 |
| 28 | 写出指定颜色的十六进制色值 |
| 29 | 罗马数字必须用 Times New Roman 字体 |
| 30 | 每个数字的字号等于它的平方 |
| 31 | 相同字母各自要有不同的字号 |
| 32 | 密码要包含自己的长度（数字） |
| 33 | 密码长度必须是质数 |
| 34 | （官方玩梗，直接跳过） |
| 35 | 包含当前时间 HH:MM |

## 三、最容易卡住的几条

- **第 9 条（罗马数字乘 35）**：35 = 5 × 7，写 V 和 VII 最省事；后面还有排版规则要给每个罗马数字调字体，罗马数字越少越轻松；
- **第 5 条（数字和为 25）**：早期就用 889 这类短组合凑，数字会在后面的规则里越加越多，留余量；
- **第 17 / 23 条（Paul）**：还在蛋里的阶段最怕手滑删掉；孵出来后是个定时喂食的活物，合成中途记得回头看，饿了就喂虫——很多人不是败给规则，是败给忘了喂；
- **第 11 / 35 条（Wordle 答案与当前时间）**：都跟「当前时刻」挂钩，一次玩太久跨天的话，Wordle 谜底变了就要回头改，所以这两条尽量留到最后统一处理；
- **最后的重打环节**：确认密码前先把它抄到别的地方看好结构，两分钟里照着手打，符号多的段落放慢点。

## 四、玩之前的两个提醒

- 别把成品当真密码用：这串东西满足的是游戏规则，不是任何网站的安全要求，也不要在真实账号里复用其中的写法；
- 卡关是设计的一部分：规则互相冲突时先保罗马数字、Paul 和月相这几条「活物」，排版类的最后统一调。

规则条目在应用里就是普通网页，加载慢或白屏时按[常见问题解答.md](常见问题解答.md)的排查步骤处理；想在应用里找到这个项目，主界面列表里认准「The Password Game」。
