## 一、这些项目从哪来

nealfun 聚合的是 [neal.fun](https://neal.fun) 网站上的内容。那是美国独立开发者 Neal Agarwal 从 2017 年起陆续发布的个人项目合集，主打「小游戏 + 数据可视化 + 互动实验」，公开介绍口径下项目数量在 35 个以上（截至 2026 年初，以打开应用时实际列表为准）。应用的界面是中文，但项目内部基本保持英文原样。

## 二、最常被提起的项目

| 项目 | 一句话说明 | 上手要点 |
| --- | --- | --- |
| Infinite Craft | 从水、火、风、土四个元素开始两两组合，无限合成新东西 | 拖拽即可玩，没有失败一说；据多家第三方资料，它在 2024 年进入过谷歌年度游戏类搜索榜前列，开局配方与进阶思路见[Infinite Craft 合成攻略.md](Infinite Craft 合成攻略.md) |
| The Password Game | 给你一串越来越离谱的密码规则，看你能撑到第几条 | 规则一条条叠加，前几条简单，后面会互相冲突，35 条全表见[密码游戏规则一览.md](密码游戏规则一览.md) |
| The Deep Sea | 往下滚动页面，一路下潜到深海，各深度出现真实存在的生物 | 没有操作门槛，当「滚动纪录片」看 |
| Design the Next iPhone | 在一台手机模具上自由加装摄像头、风扇、天线、耳机孔等配件，装完自动估价 | 应用截图展示的主打项目，点点点就能玩 |
| Spend Bill Gates' Money | 给你一笔巨款额度，把清单里的东西买买买，直到花光为止 | 同系列还有换其他富豪的版本 |
| Absurd Trolley Problems | 从经典电车难题开始，选项越来越荒诞 | 每题二选一，做完会给你全网的选项统计对比 |
| Draw a Perfect Circle | 画一个尽可能圆的圆，按百分比打分 | 一局几秒，容易上头 |
| The Size of Space | 滚动对比从人到可观测宇宙的尺寸 | 同样是滚动式，适合当科普 |
| Life Stats | 实时统计你出生以来地球发生的各种数据 | 输入出生日期即可 |
| Asteroid Launcher | 自定义一颗小行星砸向地球，看损害评估 | 参数随便调，结果用数据呈现 |
| Internet Artifacts | 按年代浏览互联网早期文物的图鉴 | 适合慢慢翻 |
| Stimulation Clicker | 一个把各种「刺激」不断堆到你屏幕上的点击器 | 讽刺向，玩到后面有反转 |
| Space Elevator | 乘坐太空电梯一路上升，看沿途高度都有什么 | 滚动式 |
| Ambient Chaos | 把雨声、咖啡馆、丧尸入侵等环境音随意叠加 | 当白噪音或整活工具都行 |
| Baby Map | 在地图上看全球各地的出生地点亮情况 | 打开即看，无操作门槛 |

项目列表会随网站更新变化，上表只覆盖讨论度最高的一批，不保证在应用里按原样、原名全部出现。

## 三、按你能花的时间挑

- **3 分钟以内**：Draw a Perfect Circle、Absurd Trolley Problems、Baby Map——点开就完，一局即止；
- **半小时左右**：The Password Game、Design the Next iPhone、Asteroid Launcher——有一条完整的流程线，能玩出结果；
- **反复回坑**：Infinite Craft——组合无上限，试错成本为零，最容易一玩一晚上；
- **无脑滚动型**：The Deep Sea、The Size of Space、Space Elevator——不需要动脑，适合躺床上划。

## 四、在应用里怎么进项目

打开应用后，主界面就是项目列表，往下拉就能翻到更多卡片；点中一个项目会新开内容页，第一次进入需要等它加载（内容来自网页，所以联网是前提，加载慢多半是网络问题）。项目里的操作以点、拖、滚动为主，没有需要教学的部分；英文界面下的应对办法见[怎么设置中文.md](怎么设置中文.md)。

还没装应用的话，先去[下载与安装教程.md](下载与安装教程.md)拿安装文件资源。
