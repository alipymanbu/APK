## 一、先懂机制再动手

Infinite Craft 是 Neal Agarwal 2024 年初上线的合成游戏，也是 nealfun 里讨论度最高的项目。你要做的事只有一件：把元素两两叠到一起，看冒出来什么。

- 开局侧栏只有四个元素：水、火、风、土（英文显示为 Water / Fire / Wind / Earth）；
- 电脑上是拖拽：把一个元素拖到另一个上；手机上点一下第一个、再点一下第二个即可合成；
- 合成结果会出现在画面上，同时加入右侧侧栏，成为以后可以继续用的新元素；
- 结果由生成模型当场判定：**一个组合第一次被试出来时结果就定死了，此后所有玩家试这对都会得到同一个结果**；全球第一个合成出某个新结果的玩家会拿到首次发现标记（社区叫 First Discovery）；
- 没有终点、没有失败：这个游戏不存在「通关」，合成出越离谱的东西越说明你玩进去了。

因为结果判定是全球统一的，所以下面这些开局组合在绝大多数情况下会稳定复现；往深处走的组合则可能因你的合成路径不同而变化，以你实际合成出来的为准。

## 二、开局值得先试的组合

第一层组合几乎人人相同，先把这几对叠出来，你的元素库就有十几个可用的积木了：

| 组合 | 结果 |
| --- | --- |
| 水 + 火 | 蒸汽（Steam） |
| 水 + 土 | 植物（Plant） |
| 水 + 风 | 波浪（Wave） |
| 火 + 土 | 熔岩（Lava） |
| 火 + 风 | 烟（Smoke） |
| 土 + 风 | 尘埃（Dust） |
| 火 + 火 | 火山（Volcano） |
| 水 + 水 | 湖（Lake） |
| 土 + 土 | 山（Mountain） |
| 风 + 风 | 龙卷风（Tornado） |

「自己叠自己」不是浪费次数——四个基础元素自组合都会出新东西，而且树（植物+植物）、森林（树+树）、家庭（人+人）这类「同类叠同类」的推进线全靠自组合打开。

## 三、往深里走的三个思路

1. **自组合**：石+石、树+树、人+人，都会开出一条新线（例如 人+人=家庭，家庭+家庭=村庄，村庄+村庄=城市）；
2. **复用百搭元素**：火、水、人类、生命这几个元素几乎跟什么都能反应，每合成出一个新东西，先拿它们挨个试一遍；
3. **顺着主题连打**：合成出恐龙之后，接着试恐龙+火、恐龙+冰、恐龙+机器人、恐龙+太空——主题链是产出首次发现最稳定的方式。

经典的「造人」路线可以当参考模板：水+土出植物，植物+水出沼泽，蒸汽+风出云，云+火出闪电，沼泽+闪电出生命，生命+土出人类。个别环节的结果可能随版本或你的路径有差异，思路比配方本身更通用。

## 四、侧栏管理与防翻车

- 元素多了用**搜索框**找，别在几百个方块里肉眼翻；侧栏还能按时间排序，方便看最新的发现；
- 工作区乱了对着**垃圾桶**拖，只清画面不清存档；
- **Reset（全盘重置）不可逆、没有撤销**——它会清空你所有已发现的元素，手别滑。想重新开始之前，确认你是真的不要这一库存了；
- 合成出的英文名不认识不影响玩：emoji 图标就代表这个元素的类别，照着图标继续叠即可；英文应对的其他办法见[怎么设置中文.md](怎么设置中文.md)。

这个项目在整个合集里的位置和同类项目对比，见[游戏与项目大全.md](游戏与项目大全.md)；装好了应用却还没找到它，主界面往下多翻几屏。
