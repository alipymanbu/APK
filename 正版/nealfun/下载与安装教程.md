## 一、装机前先核对基本信息

nealfun 是一个把 neal.fun 网站上的互动小游戏和实验项目聚合到手机上用的安卓应用。装之前，建议你先核对手里这份安装包的基本信息：

| 项目 | 信息 | 说明 |
| --- | --- | --- |
| 应用版本 | 1.0 | 以安装包自身信息为准 |
| 包名 | `com.neal.fun` | 装完在系统应用详情里能看到 |
| 安装包体积 | 1.15M | 非常小，流量下载也无压力 |
| MD5 | `A9BB882F82DBB9A544B3CFB5061BB70C` | 可用校验工具核对是否同一份包 |
| 系统要求 | 安卓 5.2 及以上 | 以安装包要求为准；老机型先看系统版本 |

这几项里最实用的是包名和 MD5：网上的安卓应用同名者多，包名对得上才说明你装的是同一个东西。

## 二、获取安装文件资源

安装包通过夸克网盘分享获取，步骤如下：

1. 打开上面的 **nealfun 安装文件资源（夸克网盘）** 链接；
2. 把文件**转存到自己的夸克网盘**（分享文件直接下载可能受限，先转存再下最稳）；
3. 在自己网盘里找到这份 APK，下载到手机；
4. 下载完成后就能在通知栏或「文件管理」的下载目录里找到它。

这一步不需要在电脑上操作，手机浏览器直接打开网盘链接、装一个夸克 App 就能完成全流程。

## 三、安装步骤

安装包不是从应用商店来的，安卓会把它当「未知来源应用」处理，流程如下：

1. 点开下载好的 APK 文件，系统会提示「不允许安装未知应用」；
2. 按提示进入设置，**允许你的文件管理器或浏览器安装应用**（不同品牌的入口名称略有差别：小米在「隐私保护/特殊权限」、华为在「更多安全设置」、OPPO 与 vivo 在「安全与隐私」里，以手机实际弹出的提示为准）；
3. 返回安装界面，点「安装」，几秒即可完成——安装包只有 1.15M；
4. 装完点「打开」，图标会出现在桌面上。

装完如果系统应用详情里显示的包名是 `com.neal.fun`，说明安装的就是本文说的这份应用。

## 四、第一次打开会看到什么

- 主界面是一个项目列表，界面为中文；
- 列表里的每个项目（小游戏、模拟器、可视化实验）点进去才会真正加载内容；
- 这些内容来自网页，**打开项目时需要联网**，网络不通会一直转圈或白屏；
- 大部分项目内部是英文，怎么面对语言问题单独写在[怎么设置中文.md](怎么设置中文.md)里。

第一次不用挨个点，可以先看[游戏与项目大全.md](游戏与项目大全.md)挑几个讨论度最高的项目上手。

## 五、装不上或打不开时的排查

| 现象 | 先检查什么 |
| --- | --- |
| 提示「安装包损坏」 | 重新下载一次，核对 MD5 是否为 `A9BB882F82DBB9A544B3CFB5061BB70C` |
| 提示解析失败 | 确认下载完成的是 `.apk` 而不是半截文件；安卓版本是否 5.2 及以上 |
| 打开后一直加载 | 检查网络；项目内容在网页端，断网就出不来 |
| 转存/下载网盘失败 | 检查夸克账号是否登录、网盘空间是否充足 |

更多疑问（它和官网什么关系、要不要账号、是否收费）集中在[常见问题解答.md](常见问题解答.md)里。
