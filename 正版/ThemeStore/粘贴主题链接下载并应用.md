# 粘贴主题链接下载并应用

> 本篇讲手上只有一条主题页面链接时的做法：复制链接、交给 ThemeStore 下载成文件、再安装应用。

ThemeStore 除了装本地文件，还有一条「下载 + 安装」合成一步的路径：你把一条主题页面链接粘进去，它去把主题包取回本地并完成安装。适用于你想把某个主题留成文件、或想在另一台设备上重复使用同一套主题的场景。

## 一、这条路径和「本地安装」的区别

| 对比项 | 本地安装 | 粘贴链接下载 |
| --- | --- | --- |
| 前提 | 手机里已有 `.mtz` | 有一个主题页面的链接 |
| 中间产物 | 无 | 会先落一份主题包到本地 |
| 适合 | 自己攒的主题文件 | 在浏览主题时随手拿到链接 |
| 依赖 | Shizuku / Root 授权 | 同上，另外还需要网络通畅 |

两条路的最后一步是一样的：主题被写进系统，之后在系统主题列表里应用。

## 二、准备一条链接

主题链接指的是主题详情页的地址，不是分享口令，也不是应用商店里的搜索页。拿到之后：

- 用系统的复制功能复制整条链接，别手动敲，字符容易漏；
- 尽量不要用屏幕识别、扫一扫一类的工具去「读」链接，识别出错会让地址失效；
- 如果链接是在电脑上看到的，用聊天工具发到手机上再复制，比手输可靠。

## 三、操作步骤

1. 打开 ThemeStore，找到「主题下载」这一类入口（与首页的「主题安装」不是同一个功能）。
2. 选择导入链接，把刚才复制的地址粘贴进去。
3. 确认后开始下载，等待进度走完。
4. 下载完成后执行安装，将主题写入系统。
5. 到系统主题的本地列表里应用这套主题。

如果第 3 步一直失败，先按下一节排查；确认链接和网络都没问题后，也可以改走「本地安装」那条路：把主题包单独下下来，再按 [本地主题包怎么导入安装.md](本地主题包怎么导入安装.md) 导入。

## 四、下载失败怎么排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示链接无效 | 复制不完整，或不是主题详情页链接 | 重新复制一次完整链接 |
| 一直停在 0% | 网络受限，或需要登录才能访问该页面 | 换网络重试，确认链接在浏览器里能正常打开 |
| 下载完成但安装报错 | 主题包与当前系统版本不匹配 | 换适配当前 MIUI / HyperOS 的主题 |
| 下载完成却找不到文件 | 落盘位置由应用决定 | 直接用应用内的安装入口继续，不必自己找文件 |

「链接在浏览器里打不开」是最值得先确认的一条：链接本身失效的话，应用里怎么重试都不会成功。

## 五、下载下来的东西会一直在吗

安装完成后主题已经进了系统，本地那份包是否保留由应用自己管理。想长期留档、方便以后换机重装的话，更稳妥的做法是**自己把 `.mtz` 存一份到网盘或电脑**，使用时按本地安装导入。

## 六、多台设备用同一套主题

同一套主题要在第二台手机上用，重复粘贴链接并不是好办法（链接可能失效）。推荐流程是：第一台设备上把主题包取回并存出来，之后在第二台设备上直接走本地安装。这也能省掉每台设备各下载一遍的时间。

## 七、装完之后

安装与应用是两步，别漏掉第二步。想让这套主题只取一部分模块、其余保持现在的样子，见 [主题模块怎么单独混搭.md](主题模块怎么单独混搭.md)。
