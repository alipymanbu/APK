# 同名应用与官方渠道怎么认

> 搜「themestore」会撞上一堆叫这个名字的东西：小米官方主题商店、ColorOS 的 Theme Store、商店里的壁纸应用。本篇讲怎么把本篇文档讲的那个 ThemeStore 认出来。

「ThemeStore」「主题商店」这两个词被好几个完全不相干的产品用着，搜索结果混在一起。装错东西轻则白折腾，重则给手机请进一个广告应用。本篇把容易混的几个列清楚，并给出可靠的辨认方法。

## 一、几个容易混的对象

| 名字 | 包名 | 是什么 | 和本应用的关系 |
| --- | --- | --- | --- |
| ThemeStore | `com.merak` | 小米 / Redmi 上装 `.mtz` 主题的工具，需要 Shizuku 或 Root 才能写入 | **本篇文档讲的就是它** |
| 主题商店 / 小米主题 | `com.android.thememanager` 等 | 小米官方的主题、壁纸、字体商店 | 官方商店，导入第三方 `.mtz` 受系统版本限制 |
| HyperOS 主题管理 | `com.miui.themestore` | 系统里负责主题管理的组件 | 系统组件，不是可下载的应用 |
| Theme Store | `com.nearme.themespace` 一类的包名 | 面向 OPPO / 一加 / realme 的主题商店 | 别的品牌的官方商店，装到小米上没用 |
| 壁纸主题商店、手机主题商店 | `com.bizhidaquan.kmi`、`com.zhutisd.hk` 等 | 应用商店里的壁纸 / 头像类应用 | 只是名字像，功能完全不同 |

最后一行是搜索结果里最常见的干扰项：应用商店里有一批叫「壁纸主题商店」「手机主题商店」的应用，做的是壁纸与头像，和 `.mtz` 主题没有任何关系。

## 二、三步认准

**第一步看包名。** 这是唯一可靠的判据：本篇讲的 ThemeStore 包名是 `com.merak`。

在手机上查任意应用包名的通用办法（小米在主题开发文档里给过这个方法）：回到桌面长按应用图标 → 应用信息 → 点右上角的信息按钮（图标是一个感叹号），包名就写在里面。还没安装时，也可以在文件管理器里查看安装包的详细信息，部分管理器会直接列出包名。

装好之后对照一下：包名不是 `com.merak` 的，就不是本文讲的这个应用。

**第二步看能力。** 打开之后如果它要求你先启动 Shizuku 或授予 Root 权限才能装主题，那就是这一类工具；一个只会让你「一键换壁纸」的应用不是。

**第三步看版本与体积。** 本地这一份是 1.0.6、32.99 MB。版本号会随时间变化，体积只能当辅证。

## 三、为什么这个应用要以 APK 方式装

它不在应用商店上架，安装包只能自行获取。这类由个人开发者维护的应用通常没有独立官网，发布渠道是作者自己维护的资源页或网盘。

这也意味着一个后果：**没有商店的更新通道**。应用更新后不会有自动提示，想知道有没有新版本得回到作者的发布渠道看；装新版时覆盖安装即可，主题数据不受影响。

## 四、拿到安装包时的几点提醒

- 优先用文档里给出的那份安装文件资源，来源明确；
- 拿到包后先核对包名与 MD5，核对方法见 [下载与安装教程.md](下载与安装教程.md)；
- 名字里带「修改版」「增强版」之类的包不要用——这类二次打包的文件无法核对来源，打包者也可能塞了别的东西进去；
- 遇到要求额外注册账号、填写手机号的安装包，直接放弃，正品不需要。

## 五、官方渠道那一边的边界

小米官方的主题商店本身也支持从本地导入 `.mtz`，但新版 MIUI 与 HyperOS 对导入做了限制，第三方与社区主题常常导不进去，这类主题就需要借助 ThemeStore 写入。官方商店里能正常获取的主题，走官方自己的流程安装即可。

如果装上之后界面、功能与本文描述对不上，多半是拿到的不是同一个应用，回到第一节的表里比对包名。
