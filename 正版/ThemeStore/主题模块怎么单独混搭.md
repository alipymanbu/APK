# 主题模块怎么单独混搭

> 本篇讲一套主题不是一个整体：图标、壁纸、锁屏、状态栏这些模块可以分开取用，以及怎么换、怎么还原。

绝大多数小米主题包不是一个不可拆的整体，而是由若干模块拼起来的。装进去之后，你完全可以只用它的图标、保留现在的壁纸，或者反过来。本篇讲清模块有哪些、怎么单独应用、以及混搭常见的几类冲突。

## 一、一套主题里通常包含哪些模块

主题包内部的资源是按模块组织的，可单独设置的部分大致如下（具体项随 MIUI 与 HyperOS 版本略有差别）：

| 模块 | 影响的位置 |
| --- | --- |
| 桌面图标 | 桌面上的应用图标样式 |
| 桌面壁纸 | 主屏背景 |
| 锁屏 | 锁屏样式、时钟，部分主题带交互 |
| 锁屏壁纸 | 锁屏背景 |
| 状态栏 | 顶部电池、信号、时间等图标 |
| 控制中心 / 通知栏 | 下拉面板的样式与开关外观 |
| 字体 | 系统全局字体 |
| 息屏显示 | 息屏界面 |
| 铃声 / 通知音 | 来电与提示音 |
| 开机动画 | 开机过程中的过渡画面 |

判断一套主题「包含什么」，最省事的办法是导入时看 ThemeStore 解析出来的模块清单——它列出来的就是这套包里实际有的东西；没做的模块，主题作者根本没提供资源。

## 二、只应用其中一部分

在系统主题里做混搭：

1. 打开系统主题应用，进入「我的」→ 主题（不同版本入口文字略有差别）。
2. 找到已经装进来的这套主题，点「混搭」而不是「应用」。
3. 在混搭界面里逐项选择：每一项都可以选「来自本主题」或保持原来的。
4. 只勾你想换的模块，确认应用。

按模块勾选的好处是改动可预期：只换图标就没必要连铃声一起换掉——很多主题会顺带把铃声替换成作者选的音乐，装完才发现来电铃声变了，通常就是这里没留意。

## 三、混搭常见的三类冲突

| 冲突 | 表现 | 处理 |
| --- | --- | --- |
| 状态栏与控制中心来自不同主题 | 下拉面板颜色与顶部图标风格不搭 | 这两项尽量取自同一套主题 |
| 字体与图标同时换 | 部分界面文字错位或被裁切 | 先只换字体，确认正常再加图标 |
| 主题与系统版本不匹配 | 部分模块生效、部分完全没变化 | 换适配当前版本的主题包 |

第三类是版本问题而非混搭问题，换包即可，不必在混搭界面反复试。

还有一类容易误判成混搭失败的：混搭好之后，整套主题被系统切回了经典主题。那不是混搭造成的，成因与处理见 [主题自动变回默认怎么办.md](主题自动变回默认怎么办.md)。

## 四、混搭后怎么还原

有两种粒度：

- **只还原某一项**：回到混搭界面，把该项改回默认或另一套主题的对应项，确认即可。
- **整体还原**：在系统主题里应用一套官方主题（或系统默认主题），会把当前所有模块一次性覆盖掉。

还原不需要动 ThemeStore 本身。主题数据装在系统里，ThemeStore 只是把文件写进去的工具，卸载它不会自动还原，也不会把已应用的主题带走。

## 五、装了多家主题之后的管理建议

- 同一模块被后装的覆盖：后应用的同一模块会顶掉前一套，不会并存两份。
- 想随时切回来，就得把用过的 `.mtz` 都留着——系统里不保存历史副本，见 [本地主题包怎么导入安装.md](本地主题包怎么导入安装.md) 里关于重复安装的说明。
- 主题包多起来之后，按「主题名 + 适配版本」给文件命名，比只留一串数字文件名好找得多。
