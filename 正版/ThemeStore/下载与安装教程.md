ThemeStore 是一个给小米、Redmi 手机用的主题安装工具，解决的是「拿到了 .mtz 主题包却装不进系统主题」这件事。它本身不是主题商店，不提供主题内容，只负责把你手上的主题包装进系统。本篇覆盖安装前的检查项、安装步骤与首次启动设置。

## 一、装之前先确认三件事

| 要确认的 | 要求 | 怎么查 |
| --- | --- | --- |
| 手机品牌 | 小米 / Redmi（MIUI 或 HyperOS） | 设置 → 我的设备 |
| 系统版本 | Android 11 及以上 | 设置 → 我的设备 → 全部参数 |
| 权限方式 | 准备好 Shizuku 或已 Root | 见 [Shizuku免root授权怎么设置.md](Shizuku免root授权怎么设置.md) |

关于系统版本，公开资料里的标注并不一致：多数下载页写的是支持 Android 11 ~ 15，也有页面写「Android 4.3 以上」。**以安装时系统给出的提示为准**（截至 2026 年 9 月的公开资料）。

第三项最容易被忽略：ThemeStore 要往系统主题目录里写东西，普通应用权限做不到，所以它必须借助 Shizuku 或 Root 才能完成安装。**只装 APK 是不够的**，这一点在下一节和专门的文档里都有说明。

## 二、安装文件从哪拿

安装包是单个 APK。本地保存的这一份信息如下，装完可以用它核对是不是同一个包：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.6 |
| 包名 | `com.merak` |
| 安装包大小 | 32.99 MB |
| MD5 | `66D8E4A45ECD757BC9179EA3A844E1FD` |

网盘里给的就是这一版；网上的介绍页往往写的是当时的最新版，两者版本号不一定相同，**装之前对上表核对一下更稳妥**。

下载与安装文件入口：[ThemeStore 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bc49d5af0d6a)

## 三、安装步骤

1. 把 APK 传到手机。可以直接在手机浏览器里打开网盘链接下载，也可以先下到电脑再传过去，放哪个目录都行，`Download` 文件夹最好找。
2. 在文件管理里点开这个 APK。
3. 如果系统提示「禁止安装未知来源应用」，按提示给当前这个文件管理器（或浏览器）打开「安装未知应用」的开关，再返回重试。
4. 等待安装完成，桌面会出现 ThemeStore 的图标。

### 被「纯净模式」拦住怎么办

小米系统默认开着纯净模式，对未经过小米安全审核的应用会拦截安装。真遇到时有两种走法：

- 在安装界面的提示里选择单次授权安装，装完这次即可；
- 或者进入安装页面右上角的「设置」→「纯净模式」，临时关闭后再装（有锁屏密码会要求先输入）。

装完建议把纯净模式恢复回去，或者改用单次授权的方式，避免以后装别的应用时一路被拦。

## 四、第一次打开：语言与权限

首次启动会先让你选界面语言，提供**简体中文、繁体中文、英文**三种。选完跟随引导授予所需权限，之后才进得去主界面。

几个提醒：

- 权限没给全，界面能进去但到安装那一步会失败，回头在「设置 → 应用管理 → ThemeStore → 权限」里补齐即可。
- 主界面上最常用的入口是「主题安装」，用于选择本地主题文件。
- 此时 Shizuku 还没启动的话，安装动作会停在权限这一步，先去把 Shizuku 跑起来再回来。

## 五、核对装的是不是这一版

想确认手机里装的和网盘里给的是同一份文件，可以算一次 MD5 比对。

Windows 上把 APK 放好，在 PowerShell 里执行（路径按实际改）：

```powershell
Get-FileHash -Algorithm MD5 "D:\下载\themestore.apk"
```

输出里 `Hash` 一行的值与上表的 MD5 一致即可。手机上可以用带校验功能的文件管理器查看。

版本号可以在「设置 → 应用管理 → ThemeStore」的详情页看到，应为 `1.0.6`。

## 六、装完打不开或装不上

先确认系统版本、权限、纯净模式这三项，绝大多数安装类问题都出在这里。仍然不行时，按 [常见问题与排查.md](常见问题与排查.md) 里的条目逐条对照。
