# Shizuku 免 root 授权怎么设置

> 本篇讲 ThemeStore 不 root 时的授权链路：Shizuku 怎么启动、怎么把权限交给 ThemeStore、重启手机后为什么又失效。

小米系统的主题数据目录普通应用写不进去，所以 ThemeStore 在没有 Root 的情况下要借 Shizuku 拿到的 ADB 权限来完成写入。这一步是整套流程里最容易卡住的地方，本篇把它拆成「装 Shizuku → 启动服务 → 授权给 ThemeStore」三段讲清楚。

## 一、先理解这条链路

```
ThemeStore  →  请求权限  →  Shizuku（以 shell 身份运行）  →  写入系统主题数据
```

关键点有三个：

- Shizuku 需要**自己先处于运行状态**，它没启动时，ThemeStore 的授权请求会失败或根本弹不出来；
- Shizuku 的服务是**临时性的**，手机重启后通常要重新启动一次；
- 授权是「应用级」的，要在 Shizuku 里**单独把 ThemeStore 勾上**，光装好 Shizuku 不算完。

Root 用户走的是另一条路：授予 root 权限后跳过 Shizuku 这一段，其余流程一致。本文只讲免 root 的这条。

## 二、准备

- 已安装 ThemeStore（见 [下载与安装教程.md](下载与安装教程.md)）；
- 已安装 Shizuku（自行从可信渠道获取）；
- 打开「设置 → 关于手机」，连续点击版本号 7 次，直到提示已进入开发者模式；
- 进入「设置 → 更多设置 → 开发者选项」，打开**USB 调试**与**无线调试**。

用无线调试的方式启动 Shizuku 时，手机需要连着 Wi-Fi；Android 11 及以上才支持无线调试，这也是这套方案常见的系统门槛。

## 三、启动 Shizuku 并授权给 ThemeStore

1. 打开 Shizuku，选择「通过无线调试启动」。
2. 点「配对」，按提示进入开发者选项里的「无线调试」。
3. 在无线调试页面点「使用配对码配对设备」，屏幕上会出现一个配对码。
4. 下拉通知栏，在 Shizuku 的通知里填入这个配对码完成配对。
5. 回到 Shizuku，点「启动」，等状态变成「已启动」。
6. 进入 Shizuku 的「已授权应用」列表，找到 ThemeStore，把开关打开。
7. 回到 ThemeStore，重新执行一次安装主题的动作。

第 6 步的授权弹窗有时会在你首次使用 ThemeStore 时才出现，看到写着 ThemeStore 名字的系统风格授权框时，点允许即可。

## 四、常见卡点

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| Shizuku 显示未启动 | 服务没启动成功，或重启过手机 | 重走第三节第 1~5 步 |
| 配对码填了没反应 | 配对码已过期，或没在通知栏里填 | 重新点一次「使用配对码配对设备」拿新码 |
| Shizuku 里找不到 ThemeStore | ThemeStore 还没发起过请求 | 先在 ThemeStore 里点一次安装，再回来看列表 |
| 授权过，下次开机又不行 | Shizuku 服务随重启失效 | 每次重启后重新启动 Shizuku，通常不用再手动勾授权 |
| ThemeStore 报权限不足 | 授权开关没打开，或系统权限没给全 | 检查 Shizuku 授权列表 + 应用权限两处 |

如果 Shizuku 装好却一直起不来，多半是开发者选项里的开关没配对（USB 调试、无线调试需要同时打开），或者后台省电策略把 Shizuku 清掉了——在「设置 → 应用管理 → Shizuku → 省电策略」里设为「无限制」会稳一些。

### 让它别被系统清掉

主题写入是个持续几秒到几十秒的过程，中间被系统掐掉就会失败。把下面几项一次设好，能省掉很多「明明授权了却装不上」的情况：

| 设置项 | 位置 | 设成什么 |
| --- | --- | --- |
| 省电策略 | 应用管理 → Shizuku → 省电策略 | 无限制 |
| 自启动 | 应用管理 → Shizuku → 自启动 | 打开 |
| 电池优化 | 设置 → 电池 → 电池优化 → 所有应用 → Shizuku | 不优化 |
| 无障碍 | 设置 → 无障碍 → 已下载的应用 → Shizuku | 打开 |

ThemeStore 自己也建议按同样的口径设一遍（把上表里的 Shizuku 换成 ThemeStore）。

**关于「每次重启都要重来」**：没有 Root 的情况下，Shizuku 的服务本身无法在开机时自动拉起，手机重启后需要按第三节重新启动一次。这一步躲不掉，但授权关系会被记住，通常不用再把 ThemeStore 勾一遍。已经 Root 的设备可以在 Shizuku 里打开开机自启，免掉这一步。

## 五、什么时候必须用 Root

Android 版本较低、或机型不支持无线调试时，Shizuku 这条路走不通，这时需要已 Root 的设备。已经 Root 的话，直接在授权提示里选 Root 方式即可，不需要 Shizuku。两条路只选一条，同时挂两套授权没有必要。

## 六、授权没问题但主题还是装不上

授权链路只是其中一环，主题包本身不兼容、导入方式不对也会失败。如果 Shizuku 状态是「已启动」、ThemeStore 的授权也开着，问题多半在主题包那一侧，可以转到 [常见问题与排查.md](常见问题与排查.md) 继续看。
