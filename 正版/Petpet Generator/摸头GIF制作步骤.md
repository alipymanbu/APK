## 一、先认一遍界面（中英对照）

整个界面一屏就能看完，常用的是这几处：

| 界面原文 | 意思 | 你要做什么 |
| --- | --- | --- |
| upload / choose file / or drop here | 上传 / 选择文件 / 或拖到这里 | 点 `choose file` 从相册选图（手机上"拖拽"用不上） |
| enter a url to upload | 输入图片网址上传 | 可以直接贴一个图片链接，见下文注意事项 |
| preview | 预览 | 效果实时显示在这里，手掌会自动拍 |
| adjust mode | 调整模式 | 打开后可以用手指在预览框里拖动图片位置 |
| flip / size / squish / speed | 镜像 / 缩放 / 挤压 / 速度 | 参数滑杆，怎么调见[参数调整技巧.md](参数调整技巧.md) |
| reset | 重置 | 一键恢复全部默认值 |
| export | 导出 | 生成并保存 GIF 文件 |

标题下面还有一行玩笑话 "if this crashes your browser it is NOT my fault"（浏览器崩了可不赖我），不用管它。

## 二、第一步：选一张图

点 `choose file`，从相册或文件里挑一张图。选图的经验：

- 正脸、脸部占画面比例大的图效果最好，头像类图片正合适；
- 图片会被放进一个方形画框里，非方形的图建议先在相册里裁成正方形，位置最好控制；
- 宠物照、卡通形象、朋友的表情照都能用，拍出来各有各的喜感。

也可以在 `enter a url to upload` 里贴图片网址直接抓取，但原版就注明了：有的网站不喜欢被直接外链图片，网址上传不一定能成。所以更稳的路子还是把图存到手机里再选。

## 三、第二步：把头挪到手掌下面

上传后预览框里马上就有动画了，但图的位置未必正好卡在手掌下。两个动作：

1. 打开 `adjust mode` 开关（原文说明：开启后可以用鼠标/触摸/键盘在预览里移动图片，手机上也能用），然后用手指把图片拖到合适位置，让"头"正对手掌；
2. 配合 `size` 把图放大或缩小、`flip` 把图水平镜像（让脸的朝向顺着拍打方向），细节对不齐就反复拖两下。

关闭 `adjust mode` 后预览恢复播放，确认整个动画节奏顺眼。

## 四、第三步：导出 GIF

点 `export`，工具开始逐帧生成并输出 GIF 文件。两点提醒：

- 导出的就是最终成品文件，直接按[导出GIF保存与分享方法.md](导出GIF保存与分享方法.md)发到微信、QQ 即可；
- 网页原版特意提示过：预览链接只在你自己的浏览器里有效，没法把"链接"发给别人——所以一定是保存文件再分享，App 里导出即得到文件，不存在这个问题。

导出后觉得节奏太慢、压得太扁，回[参数调整技巧.md](参数调整技巧.md)调 `speed` 和 `squish` 再来一张；从哪拿安装包，见[下载与安装教程.md](下载与安装教程.md)。
