## 一、为什么必须自己备份

Squid 不需要账号，笔记**默认只存在本机**，官方对此的口径是「笔记存在你的设备上，完全私密」。代价是：卸载应用、恢复出厂、系统清理、换手机，任何一条都会让笔记消失，没有任何云端账号能帮你找回。所以备份这件事只能你自己做，而且要在**出事之前**做——尤其是收到「请卸载重装」提示时，先备份再动手，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

备份入口统一在：**Squid 设置 → 备份与恢复**。

## 二、本地备份（免费，够用）

1. 打开 Squid 设置 → 点 **备份与恢复** → **本地备份**。
2. 点 **创建备份**，挑一个保存位置（本机存储、SD 卡，或交给别的应用存到网盘——比如存进 Google Drive）。
3. 得到一个 `.bak` 文件，把它挪到你自己的存档习惯里（电脑、移动硬盘、网盘均可）。

恢复：同一位置点 **恢复备份**，从设备或应用里选中那个 `.bak` 文件 → 恢复。

**红线**：恢复会**覆盖（删除）设备上现有的全部笔记**，换成备份时的状态。想保留现在的内容，先导出一遍再恢复。

## 三、云备份（Premium 功能）

勾上 Premium 后可以把全部笔记自动备份到网盘，也顺带导出一份 PDF：

1. 设置 → 备份与恢复 → **云备份** → **云存储提供者**，选 Google Drive、Dropbox 或 Box 并登录。
2. 回到上一页，可以设置备份间隔、立即触发一次备份/导出，或直接点 **恢复备份**。
3. 备份落在网盘里的固定目录（「云文件夹」按设备命名，默认形如设备型号）：

| 网盘 | 目录 |
| --- | --- |
| Google Drive / Box | `Squid/<云文件夹>/` |
| Dropbox | `Apps/Squid App/<云文件夹>/` |

目录下有两层：`Backup` 存可恢复的原始笔记（**不要手动改动里面的内容**，改了备份可能失效），`PDFs` 存每篇笔记导出的 PDF，任何平台都能直接看。老版本早期建的目录名是 `Apps/Papyrus App`，2021 年 11 月后的版本统一成上面的名字。

云备份购买了却仍是灰的、或登录状态失效，处理办法见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、换机 / 重装后怎么找回笔记

按你备份的方式对号入座：

**本地备份**：
1. 新设备装好 Squid（安装见 [下载与安装教程.md](下载与安装教程.md)）。
2. 设置 → 备份与恢复 → 本地备份 → 恢复备份。
3. 把之前存的 `.bak` 文件选中（若存在网盘里，先把文件下载到设备上，或在文件选择器里切到对应应用）。

**卸载重装的特殊场景**：安卓 10 及以上，卸载时可以保留应用数据（4.2 版加入的能力）；部分设备上应用更新失败会提示你先备份再重装。若重装后没有自动弹恢复提示，手动路径是：恢复备份 → 选设备内部存储 → 进 `.data/com.steadfastinnovation.android.projectpapyrus/backup/` → 选 `papyrus.bak` → 恢复。

**云备份**：新设备登录同一网盘 → 设置 → 云备份 → 存储提供者登录 → 点恢复备份 → 在列表里选对应那次备份。每个备份对应创建时的「云文件夹」名，换了设备名要注意选对。

## 五、导出 vs 备份：别混用

两者都能生成文件，但用途不同：

| | 格式 | 能否回填进 Squid | 用途 |
| --- | --- | --- | --- |
| 备份 | `.bak` | 能，整库恢复 | 换机、重装、防丢 |
| 导出 | `.squidnote` | 能，单篇导入 | 把一篇笔记发给同样装 Squid 的人 |
| 导出 | PDF / PNG / JPEG | 不能 | 给任何人看、打印、归档 |

批量把多篇笔记或整个笔记本导出成 PDF / `.squidnote` 属于 Premium 能力（4.1 版起在 Squid10 界面里支持批量导出）。日常习惯建议是：**每周一次本地备份，重要笔记随手导出 PDF**，两份都放网盘。

## 六、备份文件相关的常见疑问

- **恢复为什么把我现在的笔记清了？** 恢复的语义是「把应用恢复到备份那一刻」，不是合并，所以现有内容会被替换。想两份都留，先用导出把现有笔记存成 PDF。
- **`.bak` 能手动打开看吗？** 不能当文档看，它只给 Squid 恢复用；要看内容用导出的 PDF。
- **云盘里的 `Backup` 文件夹能整理吗？** 不要动，整理会破坏备份完整性（官方原话即如此要求）；要归档就复制一份出去，原件留在原位。
