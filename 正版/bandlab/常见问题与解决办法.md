## 一、本篇讲什么

按症状查：先找到你遇到的现象，照对应小节的顺序试。这些排查基于应用本身的机制（权限、联网、云端工程、安卓音频系统），通用的安卓应用故障（清缓存、重装）也一并列了。装不上、版本对不上的问题在[下载与安装教程.md](下载与安装教程.md)。

## 二、打不开、闪退、卡住不动

按代价从小到大试：

1. **强制停止再重开**：长按应用图标 → 应用信息 → 强行停止，再打开。
2. **查权限**：应用信息 → 权限，确认**麦克风**、存储/媒体权限给了 —— 缺麦克风权限进到录音界面会异常，严重时直接闪退。
3. **清缓存**：应用信息 → 存储占用 → 清理缓存。**清缓存不动工程数据**，你的歌在云端；「清除数据」才会退出登录，慎用（清前先确认记得账号密码）。
4. **看系统版本与剩余空间**：系统版本过低或过新都可能不兼容；机身存储与运行内存吃紧也会让重应用崩。留出可用空间再试。
5. **卸载重装**：重装后**用原账号登录**，云端的工程会回来。安装包还是从 [BandLab 安装文件资源（夸克网盘）](https://pan.quark.cn/s/dc6b1c7ba416) 下载，别去别处找版本不明的包（重装步骤见[下载与安装教程.md](下载与安装教程.md)）。

## 三、录音没声音 / 录进去是空的

1. 麦克风权限没给 —— 系统设置里打开（见上一节第 2 条）。
2. 电平表不动 = 信号没进来：先在 Voice/Mic 轨道界面说话看表；不动就检查是不是被别的应用占了麦克风（录屏、语音通话挂后台都可能占着）。
3. **输入设备**：安卓端 Studio 跟随**设备的主声音设置**，不能在应用里单独挑输入设备 —— 插了外接麦没声音，去系统声音设置里确认默认输入是不是它。
4. 蓝牙耳机麦克风在部分机型上不走 SCO 通道会录不上，换成有线耳机试一次。

## 四、录音延迟、跟节拍对不上

- **先换有线耳机**：蓝牙耳机的缓冲延迟通常明显更大，监听和回放都会吃亏。
- 编辑器里有延迟测量/修正入口（不同版本位置不同，找带 Latency 字样的地方）校一次。
- 录的时候开节拍器，回放才好判断是延迟问题还是自己唱歪了（唱歪用 AutoPitch 修，见[AutoPitch修音与音效预设.md](AutoPitch修音与音效预设.md)）。

## 五、输入监听开不了

这是设计行为：**必须插着耳机才允许开监听**，不戴耳机开监听会形成啸叫（麦克风收到音箱里的自己）。插上有线耳机后，点轨道视图的耳机图标即可打开；打开后听不到自己，再检查耳机是不是被系统识别成了输出设备。

## 六、工程找不到了 / 换设备怎么接

- 工程存在**云端**，不在手机本地：用原来那个账号登录，进 Library 就能看到；手机 App 与网页版 [bandlab.com](https://www.bandlab.com/) 是同一份。
- 关掉应用前**先点云图标 Save** —— 没保存的改动可能不进云端。详情见[录歌与多轨编曲教程.md](录歌与多轨编曲教程.md) 第七节。
- 换了邮箱/第三方账号登录，等于换了身份，原来那个账号的工程不会跟过来 —— 先想清楚当初用哪种方式注册的。

## 七、导出点了没反应 / 文件在哪

按[歌曲导出与发布教程.md](歌曲导出与发布教程.md) 第三节的路径重走一遍。常见两类：

1. **保存位置没落定**：官方帮助文档注明，安卓上直接存到本地可能需要文件保存类应用接管（类似 Dropbox、Google Drive）。点了下载却找不到文件，就接一个这类应用或用系统文件选择器指定目录。
2. **网络中断**：导出要走云端渲染/下载，网断了就停在原地。换稳定网络重试。

导出的文件是当时的快照，改了工程要重新导。

## 八、注册、登录与界面是英文

- 注册登录都要联网；网络不稳会卡在登录转圈，换 Wi-Fi 或数据再试。
- 界面切成中文：头像 → `Settings` → `Preferences` → `Language` → 简体中文（入口名以当时界面为准）。详见[下载与安装教程.md](下载与安装教程.md) 第六节。

## 九、听到别人的歌也想改（Fork 不了）

作者可以选择是否开放 Fork：带**绿色 Fork 标志**的曲目才允许你拿去继续编，没这个标志就是作者关了权限，应用里不会给你这个入口。你自己发布的歌要不要开放，发布时自己勾（见[歌曲导出与发布教程.md](歌曲导出与发布教程.md) 第六节）。
