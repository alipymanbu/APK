## 一、本篇讲什么

歌在云端存着，但你真正想要的是手机里的一个文件，或者别人能在你主页听到它。本篇讲三条出口：**存成文件**（导出整首/单轨）、**做母带**（把响度和质感统一到发布水准）、**发布与分享**（个人主页、社交平台、允许别人 Fork）。三者互相独立，可以只做其中一两件。

## 二、保存 ≠ 发布

点右上角**云图标**时会出现两个选项：

- **Save**：存进你的 Library，只有你自己看得见，随时接着改；
- **Publish**：公开发到你的个人主页，别人能听、能评论，还取决于你是否允许它被 Fork。

选错了不用慌：先 Save 的作品之后仍可再发布，反之发布的版本你也能继续编辑出新版本。

## 三、把整首导出成文件

1. 底部进 **Library**（库）图标，在 Projects 列表里点开你的项目。
2. 点项目右上角的**三点 / 曲线箭头**菜单，选 **Download**。
3. 选 **Download as Audio**（要视频画面就选 Download as Video，导出的是带画面的视频文件，适合往短视频平台发）。
4. 选择保存位置。

一个安卓端的实际坑：官方帮助文档注明，**直接存到手机本地可能需要一个文件保存类应用来接管保存**（类似 Dropbox、Google Drive 这类）。如果你点了下载却在相册/文件管理里找不到文件，多半是卡在这一步 —— 接一个云盘类应用或用系统文件选择器指定目录即可。

导出的文件会进你指定的目录；不确定落在哪，就在文件管理器里按文件名或修改时间找。

## 四、导出单轨（分轨）

只想拿某一条（比如单独的人声干声）出来时：

1. 打开项目进入工作室，点左下角**推子图标**进 Mix View。
2. 找到目标轨道，点它的三点菜单。
3. 选 **Export as Audio/MIDI** —— 音频轨导出为音频文件（移动端常见为 m4a），MIDI 轨可以按 MIDI 导出，拿去别的软件接着编。

要一次拿全部分轨（stems），网页端路径是项目菜单 → Project → Download → Tracks，可在 M4A 与 WAV 之间选；手机端找不到该入口时，逐轨导出或改用网页版。

## 五、母带处理（Mastering）

混音满意后做一遍母带，让整首的响度和清晰度统一。官方给了三档预设，逐个点能直接试听对比：

| 档位 | 官方说明的方向 |
| --- | --- |
| CD QUALITY | 通用档，整体提亮、加一点响度 |
| BASS BOOST | 低频重的曲子（电子、说唱一类） |
| ENHANCE CLARITY | 让各层更清晰、更有穿透力 |

三个入口，用哪个都行：

1. **做完整首就顺手做**：工作室里点云图标保存/发布时，在附加设置里选 **Mastering**，听完选档 → Done → 再 Save 或 Publish。
2. **给手机里的现成文件做母带**：新建轨道 → 底部 Tools 里选 **Mastering** → Import Your Track，支持 mp3、mp4、wav、aac、ogg 等常见格式导入。
3. **给已经存在云端的旧版本做**：Projects 里点开该项目的某个版本 → View Details → 右上角三点 → **Edit Mastering**。

做完母带的成品同样从第三节的 Download 路径下载到手机。

## 六、发布与分享

- **发到个人主页**：第二节的 Publish。发布时可以填名字、描述，并决定**是否允许 Fork**。
- **什么是 Fork**：别人 Fork 你的歌，等于拿你的工程当底继续加东西、再发布他那一版。允许 Fork 是开放 Remix 的开关；不允许则只有你自己能改。带绿色 Fork 标志的曲目才表示作者开放了这个权限。
- **发到短视频平台**：官方给了三条路 —— ① 按第三节导出成视频后自行上传；② 发布一条 Video Mix 后直接点分享到对应平台；③ 打开工作室播放，用手机自带的录屏功能录下来再发。

## 七、回查与再编辑

导出的文件是**某一刻的快照**：之后你再改工程，已导出的文件不会跟着变，要重新导一次。工程本体永远以云端为准，改完记得点云图标（见[录歌与多轨编曲教程.md](录歌与多轨编曲教程.md) 第七节）。找不到导出的文件、或下载点了没反应，翻[常见问题与解决办法.md](常见问题与解决办法.md)。
