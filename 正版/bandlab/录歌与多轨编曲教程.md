## 一、本篇讲什么

你已经装好并登录，现在想录出第一首歌。本篇按你实际操作的顺序走：新建项目 → 选第一轨的类型 → 按红键录音 → 加第二轨、第三轨 → 让各轨对上节拍 → 调音量 → 保存到云端。录完想修音就去[AutoPitch修音与音效预设.md](AutoPitch修音与音效预设.md)，想把成品存成文件就去[歌曲导出与发布教程.md](歌曲导出与发布教程.md)。

## 二、新建项目

打开应用，底部点红色的 **+** 号（或 Create 入口），进入工作室界面。第一次进会弹「新建轨道」让你先选一种轨道开张，可选的类型有：

| 轨道类型 | 你拿它干什么 |
| --- | --- |
| Voice/Mic（人声/麦克风） | 用手机内置麦克风录人声、说话、哼唱 |
| MIDI Instruments（虚拟乐器） | 用键盘或屏上演奏钢琴、鼓、合成器等 370 多种虚拟乐器 |
| Looper | 点按现成的循环素材包快速拼出鼓点与伴奏 |
| Guitar / Bass | 接上吉他或贝斯，把 App 当效果器/音箱用（需要转接线或音频接口） |
| Import Track（导入轨道） | 把手机里的 MP3、M4A、WAV 当伴奏导进来 |
| BandLab Sounds | 从十万多条免版税素材里挑循环、单音，双击就加进工程 |

拿不定主意就先选 **Voice/Mic** —— 手机直接开录，别的以后再补。

### 完全没头绪时：让 AI 先起个底子

除了上面这些轨道类型，创建流程里还有两个「生成类」入口，官方口径为免费，适合空白开工：

- **SongStarter**：选一个风格（11 种可选，如 pop、lofi、hip hop）或输入一句歌词，点骰子按钮，它一次给你 3 个音乐点子；换氛围（日间/夜间/黄昏图标）或再摇一次换一批，看中的可以直接送进 Studio 继续编。
- **Palette**：按风格、调性、BPM 自动叠 5 条对得上的循环，几秒钟铺出一个起手式，每条素材的音量可单独调，满意后送进 Studio。

生成的只是起点，后面照样走本篇的录音与编排流程。

## 三、录第一段

1. 在 Voice/Mic 轨道界面，先对着手机说话或哼两句，看电平表有没有跳动 —— 有跳动说明麦克风收到了信号。
2. 点底部红色**录音键**开始，再点一次停止。这一段就成了你的第一轨。
3. 点右上角的向下箭头回到编排视图（Arrangement View），能看见整条时间轴上刚录下的这块。
4. 想边听边录自己的声音（输入监听），点轨道视图里的耳机图标打开 —— **必须插着耳机才允许监听**，不戴耳机直接开监听会啸叫；用有线耳机还能降低你听到的延迟。
5. 录之前把**节拍器**打开（录音界面右下角的图标），不然多轨叠在一起容易越录越歪。不想让节拍器的声音被录进去，就戴着耳机录。

### 录歪了怎么办

时间轴上双击可以开启**循环（cycle）**，拖两端的把手设定循环长度，同一个段落就能反复录。录完一条不满意，用底部的撤销/重做箭头切换，挑出最好的那一条（口语叫 take）。

## 四、加轨与编排

- 在第一条轨道下方点 **+** 加新轨，选类型，接着录或接着编。
- 想改编排视图里的某一块，点它的轨道头进入**轨道视图**（Track View）做细改；下滑或点右上角 X 返回编排视图。
- 速度与调性在 **Studio Settings** 里设：速度连点三下输入数字，或用加减微调、上下拖动快速改；调性在 Project Key 里滑动选大调或小调。
- 想边录边看词，点顶部的钢笔图标打开歌词/笔记页，写下的歌词会跟着工程走，换设备也在。
- 轨道数与项目时长有上限：官方帮助中心的口径是**最多 16 条音频与 MIDI 轨、单个项目最长 15 分钟**。另有第三方页面称会员档可到 32 轨 —— 官方文档没见到这个数字，**两边并列**供你参考，实际上限以你界面里能加到第几轨为准。

## 五、让各轨对上

- **循环素材**：在新建轨道里选 BandLab Sounds，挑一条鼓或钢琴循环，双击加进项目；拖动它对齐小节线，编曲框架很快就能拼出来。
- **鼓机/Looper**：Looper 界面把鼓、贝斯、效果一层层点上去，适合先起一个 beat 再往上录人声。
- **节拍吸附**：编辑 MIDI 时 Snap（吸附）按钮会把音符吸到网格上，关掉才能自由摆放。
- **调音器**：人声、吉他、贝斯轨的轨道视图右下角有调音器图标，接真乐器先校音再录。

## 六、混音：把音量调平

点左下角的**调音台图标**进入 Mix View，这里能对每一条轨道：

- 调音量推子与声像（左右位置）；
- **M** 静音、**S** 独奏（独奏时只听这一轨，检查细节常用）；
- 重命名、复制、删除轨道，以及从三点菜单导出单轨。

把人声推到盖过伴奏一点点、伴奏左右别打架，一首歌基本就能听了。录完的干声建议加一层效果，做法在[AutoPitch修音与音效预设.md](AutoPitch修音与音效预设.md)。

## 七、保存到云端

点右上角的**云图标**，选择 Save（存为私有项目）或 Publish（发布到个人主页）。**这一步不做，工程就不算存下来** —— 关掉应用前先看一眼云图标状态。之后在网页版或另一台设备登录同一账号，这个项目会出现在你的 Library 里接着编。

存成文件、发到别的平台，走的是另一条路：见[歌曲导出与发布教程.md](歌曲导出与发布教程.md)。
