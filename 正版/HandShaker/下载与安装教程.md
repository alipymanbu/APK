## 一、先分清要装几个东西

HandShaker 不是手机上一个 app 就能用的软件：手机端应用负责在你手机上提供文件访问，电脑端客户端负责发现手机、展示文件并完成传输。两端都要装。

| 端 | 装在哪 | 从哪获取 | 版本（截至本文写作） |
| --- | --- | --- | --- |
| 手机端 | 安卓手机 | 本文的网盘资源，或官方手机端下载地址 | 1.2.0 |
| 电脑端 | Windows 电脑 | [锤子科技官网下载页](https://www.smartisan.com/apps/handshaker) | v2.6.0（2018-05-15） |
| 电脑端 | Mac | 同上，或在 Mac App Store 搜索 HandShaker | v2.5.6（2018-03-30） |

两端版本号是各自独立编号的（手机端是 1.x，电脑端是 2.x），不需要刻意对齐，建议都用官网当前提供的版本。电脑端系统要求：Windows 版适用 Windows 7 及更高版本，Mac 版适用 OS X 10.10 及更高版本（以官网页面为准）。

## 二、手机端安装

本文开头给出的 HandShaker 安装文件资源（夸克网盘）里放的就是手机端 APK。转存到自己的网盘后下载到手机即可安装；也可以先下到电脑，再用任意方式传到手机上装。安装包信息如下，装之前可以先核对：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.2.0 |
| 包名 | com.smartisanos.smartfolder.aoa |
| 大小 | 5.50 MB |
| MD5 | A41C71156C5C6A46BFA343E964EC2E16 |
| 开发者 | 锤子科技（北京）有限公司 |
| 系统要求 | 页面标注「安卓 5.2 以上」（原文如此），实际以安装时系统提示为准 |

安装步骤：

1. 把 APK 放到手机存储里，点开安装；
2. 第一次安装会弹「未知来源应用」提示，允许即可。这个开关通常在「设置 - 安全」或「设置 - 安全与隐私」里，找不到时直接在系统设置里搜「未知来源」；
3. 如果安装被系统拒绝，先检查两件事：手机剩余存储空间（官方故障排除里提到，剩余空间太小装不上，一般要留出 1 GB 以上）和系统版本是否满足要求；
4. 装完先放一边，等电脑端装好后再连接（见下一篇[手机电脑连接方法](手机电脑连接方法.md)）。

官方也提供一个手机端应用的直接下载地址：[sf.smartisan.com/sf/release/apk](http://sf.smartisan.com/sf/release/apk)，以官网当时提供的版本为准。

## 三、电脑端安装

**Windows：**

1. 打开[官网下载页](https://www.smartisan.com/apps/handshaker)，下载「完整安装包」（官方教程建议首次安装用完整安装包），直链是 [sf.smartisan.com/download/win/full/10](https://sf.smartisan.com/download/win/full/10)，以官网当时显示为准；
2. 运行安装程序，按提示完成；
3. 官网页面当前显示的最终版本是 v2.6.0（2018-05-15）。

**Mac：**

1. 打开 Mac App Store，搜索「HandShaker」，点击安装；或者到[官网下载页](https://www.smartisan.com/apps/handshaker)直接下载安装文件，直链是 [sf.smartisan.com/sf/release/download](https://sf.smartisan.com/sf/release/download)；
2. 官网页面当前显示的最终版本是 v2.5.6（2018-03-30）。

Mac 这边如果你想先看看别的传文件工具再决定，[Mac端传文件与替代工具.md](Mac端传文件与替代工具.md)把现状和常见选项列了一遍。

## 四、装完之后

两端都装好后，第一次连接时手机上会弹「信任此电脑」的授权提示，点信任才能连上。连接的具体步骤和两种连接方式（无线 / USB）的区别，见[手机电脑连接方法.md](手机电脑连接方法.md)；如果搜不到设备或连不上，按[连接失败排查.md](连接失败排查.md)逐项检查。
