## 一、背景：Google 官方工具已经停了

Mac 本身不能像 Windows 那样直接打开安卓手机的文件窗口，很多人以前靠的是 Google 出的 Android File Transfer。截至本文写作，这个工具已被 Google 停止提供与维护（多个来源都引述了 Google 支持页面的说法），在新版 macOS 上能不能用全看运气。也就是说，现在Mac 用户找传文件工具，本来就得在第三方里选。

## 二、HandShaker 在其中的位置

HandShaker 是这些第三方选择里的一个：免费、官网仍提供下载（Mac 版最终版本 v2.5.6，2018-03-30）、手机端 + 电脑端配对使用，装法和用法见[下载与安装教程.md](下载与安装教程.md)。它的特点是文件按照片、视频、音乐分好类、支持无线和 USB 两种连接，用起来接近文件管理器的习惯。

要留意的一面：它 2018 年之后就没有版本更新了，有用户反馈在某些新系统组合上会遇到不稳定的情况。如果你 Mac 和手机的系统都比较新，装好先试一次连接和一次大文件传输，再决定要不要把它留下。连接类问题先按[连接失败排查.md](连接失败排查.md)过一遍，别急着归因于「软件废了」。

## 三、常被提到的替代工具

下面的名单来自各类「安卓传文件到 Mac」主题文章里反复出现的工具，这里只列形态，不替你下结论：

| 工具 | 形态 | 适合谁看一眼 |
| --- | --- | --- |
| OpenMTP | 免费开源，拖拽式窗口 | 只想免费、能接受界面朴素 |
| MacDroid | 免费版单向传输，完整功能按年订阅 | 想把手机当磁盘挂载进 Finder |
| AirDroid | 免费加付费，走账号的无线方案 | 想顺便同步短信、通知、镜像屏幕 |
| Smart Switch | 三星官方免费工具 | 手机是三星 |
| 各品牌手机助手 | 各品牌官方免费 | 手机品牌明确、只想用官方渠道 |

这些工具的版本、收费与功能随时间变化很快，用之前到对应官网确认当前政策。

## 四、按什么条件选

几个能落地的判断点：

1. 手机是什么牌子：三星选 Smart Switch 是最顺的路；锤子 / 坚果手机用 HandShaker 能多得到闪念胶囊、剪贴板这些系统级联动（见[文件传输与相册同步.md](文件传输与相册同步.md)）；
2. 传的频率和体积：偶尔传几张照片，哪个免费用哪个；经常整批导照片视频，优先试无线连接的方案，避免反复插线；
3. 愿不愿意付费：OpenMTP 和 HandShaker 都能零成本起步；订阅制工具的功能上限更高，但值不值只有你自己的使用频率能回答。

本文开头的 HandShaker 安装文件资源（夸克网盘）提供的是手机端安装包，想先零成本试一遍再比较其他工具，成本最低的顺序就是先装它。
