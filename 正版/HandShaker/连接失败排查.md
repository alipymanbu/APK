# HandShaker 连接失败排查

> 搜不到设备、USB 没反应、连上就断、传输服务装不上 —— 本篇按故障现象给出排查顺序，内容整理自官方故障排除文档。

先确认一个总前提：连接时手机要**解锁**且手机端 HandShaker 是**打开**的。这是官方 FAQ 里第一条，也是最容易忽略的一条。

## 一、无线搜索不到手机

按顺序检查：

1. 手机和电脑是否连的是**同一个路由器**（两个 WiFi 名字看着像，实际是两个网络的很常见）；
2. 有些网络要做二次认证（登录页点一下同意）之后才能真正联网，先把电脑浏览器打开随便刷个网页确认网络可用；
3. 完全退出两端应用再重新打开，重新等搜索；
4. 部分路由器默认关闭了「组播模式」（官方点名思科设备有此情况），这种网络下设备发现就是不通的 —— 换个网络，或直接改用 USB；
5. 实在搜不到，用扫码连接绕过设备发现（电脑端 v2.5.6 起支持，见[手机电脑连接方法.md](手机电脑连接方法.md)）。

## 二、USB 连接没反应 / 连接失败

1. 确认手机端 HandShaker 已打开、手机已解锁；
2. 检查手机上 USB 连接方式的选项：官方故障排除里两种建议都出现过 —— 一处要求确认是「媒体设备 / 传输文件（MTP）」，另一处建议选「仅充电」或「PTP（查看图片）」再试。两种都试一遍，哪个能连上用哪个；
3. 确认已打开「USB 调试」（设置 - 开发者选项；开发者选项入口通常要先连点 7 次「版本号」才会出现）。关于这一步有两种说法：官方文档把它列为**连不上时的排查项**，而不少第三方教程把它写成**必做的第一步**。省事的顺序是先不开直接连，连不上再回来打开它；
4. 用锤子（Smartisan OS）手机的话，先退出省电模式，省电模式下连不上是官方列明的；
5. 个别联想、LG 手机需要打开「USB 绑定 / USB 网络共享」（设置 - 绑定 & 网络 / 网络共享与便携式热点）才能正常连接；
6. 换一根数据线（优先用手机原装线）、换电脑上另一个 USB 口，重新插拔。

## 三、无线连上后频繁断开

- 复杂无线环境（公司网络、公共网络）会干扰连接，官方给的办法就是换网络或改用 USB；
- 更常见的原因是手机系统把手机端服务杀掉了。把 HandShaker 加入自启动 / 后台运行白名单，各品牌设置位置不同，见下一节。

## 四、各品牌手机的后台权限设置

官方故障排除里按品牌列了设置位置，对照自己手机改：

| 品牌 | 设置位置 |
| --- | --- |
| 华为 | 设置 - 权限管理 - 找到 HandShaker - 设置单项权限 - 打开「信任此应用」 |
| 小米 | 设置 - 授权管理 - 自启动管理打开 HandShaker；设置 - 电量和性能 - 神隐模式 - 应用配置 - HandShaker 选「无限制」 |
| 魅族 | 手机管家 - 自启动管理 - 勾选允许 HandShaker 后台启动 |
| 三星 | 智能管理器 - 内存 - 自动运行应用程序 - 打开 HandShaker 开关（7 天未使用会被自动关掉，注意再开） |
| 乐视 | 设置 - 隐私授权 - 把 HandShaker 加入自动启动列表 |

另外，装了「绿色守护」「净化大师」这类后台管理软件的话，要么卸载，要么把 HandShaker 的开机与后台自启设为允许。

## 五、手机端提示安装失败

电脑端第一次通过 USB 连接时，可能会往手机上安装传输服务；装不上时按官方文档查两点：

1. 是否允许安装「未知来源」应用（设置 - 安全中心 / 安全与隐私 - 未知来源）；
2. 手机剩余存储空间 —— 剩余空间太小装不上，一般要有 1 GB 以上可用空间。

如果是你自己手动装 APK（比如网盘里那份手机端安装包）被拒绝，同样先查这两条，详见[下载与安装教程.md](下载与安装教程.md)。

## 六、以上都不行

官方论坛设有 HandShaker 版块（`bbs.smartisan.com`），不过这个软件最后一次版本更新停在 2018 年，发帖未必有人回；更快的方式是换个思路验证：换一根线、换一个网络、换一台电脑分别试，把问题定位到「线 / 网络 / 电脑」哪一环，再对症处理。用 Mac 且反复连不稳的话，也可以先看看[Mac端传文件与替代工具.md](Mac端传文件与替代工具.md)再决定要不要换工具。常见疑问也可以先看[常见问题解答.md](常见问题解答.md)。
