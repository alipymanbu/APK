# HandShaker 文件传输与相册同步

## 一、拖拽互传：和用文件管理器一样

连接成功后，你可以在电脑端 HandShaker 窗口和电脑的文件管理器之间直接拖拽：

- 从文件管理器把文件拖进 HandShaker 窗口 → 文件传入手机；
- 从 HandShaker 窗口把文件拖到电脑的某个文件夹 → 文件导出到电脑；
- 窗口内可以新建、删除、移动、重命名文件夹和文件，支持多选批量操作。

照片、视频、音乐会被按类型整理好，找某类文件时不用一层层翻文件夹。官方说明里还提到可以在电脑端管理手机外置 SD 卡的内容。

## 二、把手机照片导出到电脑

想一次性把照片备份出来，官方教程给的做法是：在电脑端打开【全部文件】-【相册】，把整个相册文件夹导出到电脑上你选的位置。比单选照片拖拽省事得多。

如果你希望「拍完自动进电脑」，用的是相册同步功能，见下一节。

## 三、相册自动同步

电脑端 HandShaker 里可以开启相册同步：开启后，手机相册会和电脑本地的某个相册目录自动保持同步，你不用每次手动导。这个功能在电脑端的设置里开启；电脑端 Windows 版 v2.6.0（2018-05-15）起，本地相册的存放目录可以自选，第一次用时要选好电脑端的存放位置。

## 四、闪念胶囊与剪贴板：锤子手机专属

有两类功能只对 Smartisan OS 的手机有意义，普通安卓手机连上后用不到，不用纠结：

- **闪念胶囊**：电脑端可以记录、查看闪念胶囊，它走的是欢喜云服务，不需要连接手机。前提是你有欢喜云账户、且手机端（锤子手机）在「设置 - 欢喜云服务」里开启了闪念胶囊同步，然后在电脑端登录同一账户并勾选开启；
- **剪贴板**：官方说明里写明，从电脑往手机剪贴板推送文字是针对 Smartisan 设备的能力。

普通安卓手机用户的核心用法就是第一、二节的内容：连接、拖拽、导出相册。

## 五、传输方式怎么选

| 场景 | 建议 |
| --- | --- |
| 传几个小文件，随手操作 | 无线连接，不插线方便 |
| 传大文件（视频、大体积压缩包） | USB 数据线，官方明确建议：速率更高也更稳 |
| 公司 / 公共 WiFi 下连不稳 | 改用 USB，或换网络（见[连接失败排查.md](连接失败排查.md)） |
