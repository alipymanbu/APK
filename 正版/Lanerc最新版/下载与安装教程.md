## 一、这是个什么应用

Lanerc 是一款安卓端的动漫追番应用，你可以在手机上搜番、按题材筛选、收藏追番清单、看弹幕、投屏到电视，也能把剧集缓存到本地离线看。本篇只讲安装这件事：从哪拿包、怎么核对包没拿错、怎么装进手机，装完后的注册与使用请看相关文档。

## 二、先核对安装包信息

网上叫 Lanerc 的下载页非常多，包名、大小、版本号五花八门，装错包是这类应用最常见的翻车点。你从上面网盘拿到的那份，信息是固定的：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.1.6 |
| 包名 | `com.qsreod` |
| 大小 | 36.75M |
| MD5 | `2579d1f15bbd956e73280501ccfd10a9` |

拿到包后先看文件名与大小对不对得上（约 36.75M，差得太远说明不是这份）。下载站页面上写的版本号常与这份不一致 —— 各渠道的版本写法本来就不统一，**以实际安装包的这四项为准**，不要拿网页上的数字来判断拿没拿对。

## 三、安装步骤（安卓通用）

1. 从 [Lanerc 安装文件资源（夸克网盘）](https://pan.quark.cn/s/723862244d4a) 把 APK 下载到手机（或先下到电脑再传过去）。
2. 点开 APK 开始安装。系统若提示「禁止安装未知来源应用」，按提示进入设置，允许本次或该来源安装（各品牌入口略有差异，一般在 设置 → 安全/隐私 → 安装未知应用）。
3. 安装过程中若杀毒组件弹「风险提示」，这类第三方渠道包没有应用商店上架记录，提示属于误报居多 —— 但你应先确认文件名、大小、MD5 与上表一致，确认无误再继续。
4. 装完打开应用，首次启动会请求网络、存储等权限；存储权限关系到后面的离线缓存，建议允许。

部分机型在安装时卡住或提示解析错误，可以先断开网络（开飞行模式）再装一次，装完再恢复网络；仍失败的排查思路见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、升级与重装注意

- Lanerc 这类应用不在应用商店分发，**升级 = 拿到新包再装一遍**，安装前不用卸载旧版，直接覆盖即可。
- 覆盖安装不会丢账号（账号在服务端），但本地缓存的剧集可能需要重新下载。
- 装完想确认版本：进「我的」页面查看版本号，与安装包标称的 1.1.6 对照。
- 以后换手机或重装，直接回网盘那份拿包即可，链接不变。
