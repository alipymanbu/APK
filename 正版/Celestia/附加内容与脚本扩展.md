# Celestia 附加内容与脚本扩展

> 本篇讲往 Celestia 里加新天体与高清纹理（add-ons）的方法、extras 目录的位置，以及 .cel/.celx 脚本与 cel:// 链接的用法。
> **相关文档**：[基础操作与手势入门.md](基础操作与手势入门.md) · [下载与安装教程.md](下载与安装教程.md)

> **Celestia 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/b5989c6638c6](https://pan.quark.cn/s/b5989c6638c6)

Celestia 的天体数据库被官方设计成可扩展的：新天体条目、高分辨率纹理、航天器模型都能以后挂内容（add-ons）的形式加进来，脚本则能驱动视角与时间做一整套演示。本篇讲这些东西放在哪、怎么生效。

## 一、附加内容能加什么

按官方描述，常见类型有：

| 类型 | 举例 |
| --- | --- |
| 新天体条目 | 彗星、恒星、扩展星表 |
| 高分辨率纹理 | 行星表面的更高清贴图 |
| 三维模型 | 按精确轨道运行的小行星与航天器 |
| 虚构物体 | 知名科幻作品里的星舰等 |

数据库容量也随之扩展：按官方介绍，默认星表超过 60 万颗恒星，装入附加星表后可到 177 万以上；深空天体同样有对应的扩展目录（数字以官方页面为准）。

## 二、extras 目录放在哪

安卓版从 **extras** 目录读取附加内容，路径为：

```text
Android/data/space.celestia.mobilecelestia/files/CelestiaResources/extras
```

使用要点：

1. 把下载到的附加内容**保持其自带的目录结构**放进 extras；
2. 重启 Celestia 后生效；
3. Android 11 之后的系统对 `Android/data` 目录有访问限制：可以用数据线连电脑，从电脑上把文件夹复制进去；部分机型的系统文件管理器也能进入该目录；
4. extras 里的脚本会出现在收藏（Favorites）里，可直接加载。

## 三、脚本与 cel:// 链接

脚本有两种格式，分工不同：

| 格式 | 特点 | 适合 |
| --- | --- | --- |
| `.cel` | 官方自有脚本语法，一条条命令顺序执行 | 固定路线的演示，比如绕太阳系一圈 |
| `.celx` | 基于 Lua，可以写逻辑与交互 | 带菜单、能中途改变行程的复杂脚本 |

一段最简单的 `.cel`，作用是选中地球并在 3 秒内飞过去（写法出自官方脚本指南）：

```cel
select { object "Sol/Earth" }
goto   { time 3 }
wait   { duration 3 }
```

使用要点：

- 脚本放进 extras 后从收藏（Favorites）里加载运行；
- 官方脚本指南（含全部命令参考）在 [celestiaproject.space 的 CEL Scripting Guide](https://celestiaproject.space/docs/CELScriptingGuide/Cel_Script_Guide_v1_0g.htm)；
- 支持 `cel://` 形式的链接：点开这类链接，应用会直接把视角带到链接记录的位置与时刻，适合分享自己摆好的观察机位。

## 四、从哪找附加内容

- 官方的附加内容校验工具与提交入口在 GitHub：[github.com/celestiamobile/celestia-addon-validator](https://github.com/celestiamobile/celestia-addon-validator)；
- 原版 Celestia 的官方论坛设有 add-on 板块，内容按天体与主题分类：[celestiaproject.space/forum](https://celestiaproject.space/forum/)。

装好附加内容后，天体与普通天体一样可以用搜索或星体浏览器找到；操作方式见[基础操作与手势入门.md](基础操作与手势入门.md)。第一次安装应用本身的过程见[下载与安装教程.md](下载与安装教程.md)。
