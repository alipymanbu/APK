Celestia 是一款实时三维宇宙模拟软件，手机上可以查看行星、卫星、恒星、星系等天体的实时位置与外观。本篇按「先核对条件 → 选渠道 → 安装 → 第一次打开」的顺序走一遍，装好后的手势操作见[基础操作与手势入门.md](基础操作与手势入门.md)。

## 一、安装前先确认三件事

| 项目 | 要求 / 说明 |
| --- | --- |
| 系统版本 | Android 5.0 以上（官方口径）；本文对应的安装包要求 Android 5.2 以上 |
| 存储空间 | 安装包约 399.36M，建议预留比安装包体积更大的剩余空间 |
| 渠道差异 | 官方明确说明：不同市场分发的版本，功能可能存在差异 |

## 二、从哪获取安装包

官方分发渠道见第五节的表格，包名统一为 `space.celestia.mobilecelestia`。如果不方便访问这些渠道，可以直接使用上面网盘里的 **Celestia 安装文件资源（夸克网盘）**：转存到自己的网盘后即可下载。这份安装包的版本为 1.9.5，大小约 399.36M，MD5 为 `F76A89DC509DFA7978DC64F2EA1D086E`，可用于核对下载到的文件是否完整。

## 三、APK 安装步骤

1. 从网盘把 APK 文件下载到手机存储；
2. 在文件管理器里点开这个 APK；
3. 系统提示「未知来源应用」时，按提示允许安装；
4. 等待安装完成，点「打开」。

> 部分机型的「允许安装未知来源应用」开关藏在 设置 → 安全（或 应用管理）里，按机型提示操作即可。

## 四、首次启动会经历什么

- **初始加载**：安装包内含大量天体数据，第一次启动要完成初始加载，耗时比平常应用长，属正常现象，等它跑完即可；如果迟迟无响应，见[常见问题与排查.md](常见问题与排查.md)。
- **教程提示**：首次进入会出现操作说明与运行演示，跟着走一遍就能掌握基本手势，之后在菜单的 Help（帮助）里随时能再查。
- **语言**：官方内置简体中文等语言，界面默认显示英文时，检查应用内或系统语言设置。
