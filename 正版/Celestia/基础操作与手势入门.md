手机屏幕没有鼠标滚轮和右键，Celestia 把桌面版的操作全部换成了手势。装好后先记住下面四个手势，再熟悉菜单结构，之后无论去看哪颗天体都是同一套动作。

## 一、四个核心手势

| 手势 | 作用 |
| --- | --- |
| 单指拖动 | 绕当前天体旋转视角（对应桌面版右键拖动） |
| 双指拖动 | 在空间中平移移动（对应桌面版左键拖动） |
| 双指捏合 | 拉近 / 拉远（对应桌面版滚轮） |
| 单指点按 | 选中天体 |

这套手势与官方说明一致；忘了的时候，点开操作菜单里的 Help（帮助）可以再查一遍。

## 二、菜单与工具栏

- 屏幕侧边的**三横图标**打开操作菜单，星体浏览器、帮助、收藏等入口都在这里；
- 菜单最上方是「**设置**」，其中「图形」小节的「渲染参数」管星等显示与画面效果，逐项说明见[星等显示与画面调节.md](星等显示与画面调节.md)；
- 工具栏可以通过信息按钮隐藏或显示，看全景时把工具栏收起来视野更干净；
- 工具栏上有**对象模式 / 相机模式**（object mode / camera mode）切换：对象模式下视角绕着选中天体转，相机模式下移动的是相机本身。

## 三、搜索天体

1. 点搜索框，输入天体名称；
2. 名称用**官方英文拼写**，例如 `Mars`、`Io`、`Hubble`，输中文一般搜不到；
3. 在结果里点选目标，前往（Go to）后应用会把视角带过去。

搜索结果较多时，先看清条目所属的天体系统再进，避免同名条目选错。人造航天器（国际空间站、哈勃望远镜等）也走同样的搜索，搜不到多半是时间没对上，见[航天器与空间站怎么看.md](航天器与空间站怎么看.md)。

## 四、星体浏览器与天体信息

- 操作菜单里打开**星体浏览器**（Star Browser），按类别浏览天体条目；
- 点条目名称会弹出选项，选「前往」即可看到外观与各项信息；
- 天体信息页可以按**子系统**（subsystem）查看构成，比如一颗行星的各个卫星。

## 五、收藏与常用位置

常去的位置可以存进收藏（Favorites / Bookmarks），下次直接跳转，不用重新搜索。收藏里还能看到附加内容目录中的脚本，具体见[附加内容与脚本扩展.md](附加内容与脚本扩展.md)。

看天体时想让时间快进或倒回来对比位置变化，用时间控制，见[时间加速与日食观测.md](时间加速与日食观测.md)；启动或运行遇到异常，见[常见问题与排查.md](常见问题与排查.md)。
