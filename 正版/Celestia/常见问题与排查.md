# Celestia 常见问题与排查

> 本篇汇总 Celestia 安卓版常被问到的几件事：启动慢、卡顿闪退、语言设置、搜不到天体、附加内容不生效。

下面按现象归类，每条给出先做什么、再做什么。安装环节的渠道与版本问题见[下载与安装教程.md](下载与安装教程.md)。

## 一、第一次打开很久没反应 / 黑屏

- 安装包约 399.36M，内含大量天体数据，第一次启动要完成初始加载，在低端设备上等待时间更长，先让它跑完这一次；
- 长时间无响应时，检查剩余存储空间是否充足，空间不足会拖慢甚至中断加载；
- 仍然不行就重启应用再试一次，首次加载成功后，之后的启动会快很多。

## 二、运行卡顿

- 菜单里提供若干渲染调节项（如环境光 ambient light、星系亮度 galaxy brightness、可见星等下限等），整体调低一档，帧率通常能明显回升；
- 把标签、标记这类叠加显示关掉一部分；
- 时间大幅加速时天体位置刷新更频繁，卡顿明显时先降一档流速再观察。

各渲染项的位置与逐项调法见[星等显示与画面调节.md](星等显示与画面调节.md)。

## 三、闪退或崩溃

1. 先确认用的是较新版本，旧版已知崩溃会在后续更新中修复；
2. 官方请用户把崩溃报告提交到 GitHub issues（仓库 [github.com/celestiamobile/AndroidCelestia](https://github.com/celestiamobile/AndroidCelestia)），反馈时附上机型、系统版本与复现步骤；
3. 更新版本后仍然闪退，可先清一次应用缓存再试。

## 四、界面是英文，怎么切中文

官方内置简体中文等语言。界面显示英文时，先看应用内的设置项里有没有语言选项；没有的话，把系统语言切换为简体中文后再进应用。菜单里的 Help（帮助）里也能看到手势说明。

## 五、搜不到某个天体

- 用**官方英文拼写**搜索，例如搜 `Io` 而不是「木卫一」；
- 看到的恒星、标签比预期少，多半是星等显示下限的问题，调法见[星等显示与画面调节.md](星等显示与画面调节.md)；
- 航天器（空间站、望远镜等）搜不到，常见原因是时间没对上它在轨的时期，见[航天器与空间站怎么看.md](航天器与空间站怎么看.md)；
- 目标如果是后装的附加内容提供的，先确认附加内容已正确放进 extras 并重启过应用。

## 六、附加内容放了没生效

最常见原因是路径与目录结构不对：内容必须放在 extras 目录下并保持其自带的目录结构，放完要重启应用。Android 11 以后手机上直接访问该目录受限，用电脑经数据线复制最稳妥。完整步骤见[附加内容与脚本扩展.md](附加内容与脚本扩展.md)。

## 七、网上教程里的快捷键，手机上按了没反应

网上不少 Celestia 教程按**桌面版**写：`K`/`L` 调时间流速、`G` 前往、`[` `]` 调星等、`J` 倒转时间……这些是键盘快捷键，手机版用不上。对应功能都在三横菜单里，例如渲染参数在 设置 → 图形 → 渲染参数，时间控制在菜单的时间项，手势对照见[基础操作与手势入门.md](基础操作与手势入门.md)。

看天象时不知道怎么调时间流速，见[时间加速与日食观测.md](时间加速与日食观测.md)。
