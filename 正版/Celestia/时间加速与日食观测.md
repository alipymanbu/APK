Celestia 里的天体按真实规律持续运动，把时间流速调快或倒转，才能肉眼看到行星公转、卫星绕转这类过程。本篇讲时间控制的用法，以及用它看几类典型天象的具体路子。

## 一、时间流速怎么调

- 默认按真实时间走，此时行星的运动几乎察觉不到；
- **调快**：天体运动会明显加快，地球自转、木卫绕转几分钟内就能看出变化；
- **调慢**：贴近逐帧观察某个瞬间；
- **倒转**：支持时间反向（time reversing），把已经过去的天象「倒回去」看。

时间控制在界面菜单的时间项里，加减速与倒转都从那里切。选档的原则是**先快后慢**：先用大档位定位到大趋势，再落到小档位看细节。

要精确对到某个日期（比如找航天器在轨的窗口）时，注意一类特殊口径：航天器轨道数据的起止日期按 UTC 编码而非当地时间，处理办法见[航天器与空间站怎么看.md](航天器与空间站怎么看.md)。

## 二、用 Eclipse Finder 找日食

安卓版内置日食查找器（Eclipse Finder），不用自己算日期：

1. 打开操作菜单，进入 Eclipse Finder（日食查找器）；
2. 选择关注的天体系统（如地球—月球）与时间范围；
3. 在列出的日食/月食条目里选中一次；
4. 应用会把视角带到对应的位置与时刻，再配合加减速微调，看食入食出的全程。

## 三、适合用时间功能看的几类天象

| 天象 | 看法 |
| --- | --- |
| 日食 / 月食 | 直接用 Eclipse Finder 跳到时刻，再微调流速 |
| 木卫食、卫星凌木星 | 视角对准木星，中等速度加速 |
| 行星公转与两星会合 | 大幅加速，视角拉远 |
| 地球自转与昼夜交替 | 小幅加速，视角固定在地表附近 |

看的过程中如果画面明显卡顿，把渲染相关选项调低一点再继续，处理办法见[常见问题与排查.md](常见问题与排查.md)；手势不熟导致视角跑飞，回[基础操作与手势入门.md](基础操作与手势入门.md)过一遍四个手势。
