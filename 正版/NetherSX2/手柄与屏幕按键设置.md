## 一、先在系统层把手柄连好

1. 蓝牙手柄：进安卓「设置 → 已连接设备 → 蓝牙」，让手柄进入配对模式并配对；有线或转接手柄：用 OTG 线接到手机。
2. **先在别的应用里确认手柄能用**（随便一个按键测试 app 即可）。系统层都没反应，问题在手柄或手机蓝牙，模拟器里怎么调都没用 —— 先重启手柄、重开蓝牙，换根线或换个转接头再试。
3. 系统层正常后，进游戏 → 暂停 → 右上角控制器图标进 Controller Settings，开始映射。

## 二、按键映射：自动打底，手动补漏

官方 FAQ 的原话口径：在 Controller Settings 里映射手柄，**先用自动映射**；自动映射之后，**扳机键（L2/R2）和摇杆常常仍要手动补一遍**。

- 自动映射：Controller Settings 里选自动配置，多数标准手柄一遍就位；
- 手动补：点对应按键 → 按下手柄上的那个键，把没反应的逐个补齐；
- L3/R3 与右摇杆：同样在 Controller Settings（游戏内暂停 → 右上角控制器图标）里选「Add/Remove」按钮加出来，或把布局切成双摇杆（dual sticks）。

NetherSX2 相对 AetherSX2 的改进之一就是手柄自动配置更全：项目持续把手柄配置库更新到 SDL_GameControllerDB 的最新版，官方更新说明里点名加过 8BitDo Pro 3 / Ultimate 2C、PS VR2 Sense 控制器、罗技无线震动垫、多款街机摇杆等型号。你的手柄不在库里也能用，只是要走上面的手动映射。

## 三、屏幕按键怎么改

1. 游戏中按暂停（或返回键）→ 点右上角的 controls 标签；
2. 拖动按键改位置、调整缩放改大小；
3. 同一处还能**加额外按钮**：快进、快速存档 / 读档这类热键都可以上屏。

屏幕控件的样式随版本不同：2.0 起换了一套新的屏幕控件，网盘这份 v1.9a-dev 还是此前那套 —— 用法一致，长相不同。

## 四、存成配置档案，按游戏自动加载

输入档案（input profile）= 屏幕按键布局 + 手柄绑定（含宏按钮）打包保存（官方 FAQ 有完整步骤）：

**建一个档案**：

1. 先把屏幕按键调成你想要的样子（可选）；
2. 绑好蓝牙手柄、需要的话设好宏按钮（可选）；
3. Controller Settings 第一个标签里有「Save Profile」，存档并命名；
4. 想恢复默认布局，也在同一菜单里重置。

**让某个游戏自动用它**：

1. 打开该游戏的 Game Properties（列表里长按，或游戏内暂停菜单右上角 info 按钮）；
2. 滑到 General 标签 → Input Profile → 选中你的档案；
3. 进这个游戏时自动加载；换别的游戏则回到全局布局。

## 五、宏（组合）按钮

每个虚拟手柄有 4 个宏按钮（M1~M4）：Controller Settings → 滑到对应手柄端口（一般是 Port 1）→ Macro 分类 → 选一个宏按钮 → 设触发方式（手机音量键、手柄按键、组合键，或留空用触屏点）→ 选要同时按下的键位组合。

频率（frequency）保持 0 就是纯组合键；调成非 0 会按设定频率反复触发。宏按钮在触屏上默认隐藏，要进 Controller Settings → Add/Remove Buttons 才能显示出来，且要正在游戏内才能加。

## 六、手柄还是不识别

按顺序排：系统层先测（第一节）→ 模拟器里清掉自动结果、手动逐键映射（第二节）→ 换一个输入档案排除档案本身的问题 → 还不行，连同「闪退、黑屏」一起看 [常见问题与故障排查.md](常见问题与故障排查.md)。
