## 一、两种存档，用途不一样

| 类型 | 是什么 | 特点 |
| --- | --- | --- |
| 记忆卡存档 | 游戏自己存的进度，像真 PS2 的记忆卡 | 跨版本、跨设备可靠；长期进度靠它 |
| 即时存档（save state） | 随时给整个模拟状态拍快照 | 方便，但受版本线限制（见下） |

- 即时存档在暂停菜单 → Load/Save state：10 个槽 + 1 个快速存档（快速存档是给屏幕上的快捷键用的）；
- **官方已知限制**：3668（Classic）与 4248（主线）两条线的即时存档互不通用 —— 在两条线之间来回换，只能靠游戏内存档；
- 两边口径并列：官方升级指南说 Transfer Data 导出的内容包含即时存档；独立教程提醒跨版本 / 跨设备之后即时存档未必读得出来 —— 所以**重要进度养成在游戏里存一次的习惯**，迁移前后都以游戏内存档为准。

## 二、存档文件在哪

- 记忆卡与即时存档都在 `Android/data/xyz.aethersx2.android` 目录下（官方 FAQ 口径）；
- **Android 11+**：系统对 `Android/data` 有限制，文件管理器要额外授权才能进去看（官方 FAQ 口径）；
- 同一个数据目录下的子位置（社区教程口径）：`files/bios` 放 BIOS、`files/textures` 放贴图包、`files/cheats` 放金手指文件（见 [金手指代码怎么用.md](金手指代码怎么用.md)）。

## 三、先做两件预防工作

1. **把记忆卡换成「文件夹卡」**（独立教程的做法）：App Settings → Memory Cards → Create New Card → 类型选 Folder（命名成如 `memcard1.ps2`）→ 回到 Card Name 切到这张新卡。默认那张固定容量的卡存几个游戏就满；文件夹卡是每个游戏各占一张「卡」，互相不挤。
2. **第一次存档的格式化提示照单全收**：第一个游戏存档时会问你要不要格式化记忆卡 —— 正常，同意即可，之后不会再问。

## 四、导出备份（Transfer Data → Export）

旧版本里操作：

1. Settings → Transfer Data → Export；
2. 选一个存放文件夹（独立教程建议在 Download 里新建一个，好认）；
3. 弹出的清单勾上要导的内容 —— 官方 README 给的清单是：BIOS、记忆卡、即时存档、游戏设置、封面、贴图包；
4. 点 Export 等它跑完。

什么时候必须做：从 AetherSX2 或低于 1.9a 的版本升上来**必做**（流程见 [下载与安装教程.md](下载与安装教程.md) 第五节）；1.9a 及以上覆盖升级**建议做**（官方口径：可选但稳妥）。

## 五、导入恢复（Transfer Data → Import）

1. 新版本里进到游戏列表：Settings → Transfer Data → Import；
2. 选中当时导出的那个文件夹；
3. 清单保持勾选 → 确认，等它导完；
4. **全局设置重新过一遍** —— 这部分不随导入走（官方 README 口径）。

## 六、换手机 / 重装系统

1. 旧机先走第四节导出；
2. 把导出文件夹拷到新机（数据线、云盘都行）；
3. 新机装应用、走完向导（[下载与安装教程.md](下载与安装教程.md) 与 [首次启动与BIOS导入.md](首次启动与BIOS导入.md)）；
4. 到游戏列表后走第五节导入；
5. 游戏镜像不用「迁移」—— 新机重新放文件、重新指目录即可（[游戏镜像与游戏列表.md](游戏镜像与游戏列表.md)）。

**注意**：安卓的机制是**卸载即清数据**：没导出就直接卸载，记忆卡与即时存档跟着应用一起没（社区反馈里「重装后进度丢了」全是这么来的）。先导出，再动手。

## 七、更新 / 换版之后存档不见了，按这个顺序查

1. 是不是**换错了版本线** —— 3668 与 4248 的即时存档不通用（本篇第一节）；
2. 是不是**选中的卡变了** —— App Settings → Memory Cards 里确认 Card Name 还指向你一直在用的那张；
3. 是不是**装错了包、或卸载时清了数据**（本篇第六节）；
4. 找回导出的备份，走第五节导入；
5. 排查完之前**别急着开新档** —— 新档会写进当前选中的卡，先确认旧卡在哪。

排查入口统一收在 [常见问题与故障排查.md](常见问题与故障排查.md)。
