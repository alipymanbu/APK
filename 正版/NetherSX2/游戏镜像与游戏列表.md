## 一、游戏文件自己做

官方 FAQ 的口径：模拟器只应运行你**自己拥有、自己从光盘导出**的游戏。做法是把你的 PS2 光盘用 ImgBurn 这类工具做成 `.iso` 镜像，再通过 USB 拷到手机；体积太大可以用 gzip 或 chdman 压缩（这两个都是官方点名的工具）。本套文档不提供任何游戏下载。

BIOS 还没导的，先回 [首次启动与BIOS导入.md](首次启动与BIOS导入.md) —— 没有 BIOS，镜像再全也起不来。

## 二、认哪些格式

支持的镜像格式（与 AetherSX2 同源的官方清单）：

| 格式 | 说明 |
| --- | --- |
| `.iso` | 标准光盘镜像，未压缩，体积最大 |
| `.chd` | 无损压缩格式，省空间；制作方式有坑，见第五节 |
| `.cso` | 压缩镜像格式 |
| `.bin` | 光盘镜像的常见形态 |
| `.gzip` | gzip 压缩的镜像 |
| `.elf` | 可执行文件，日常很少用到 |

## 三、把游戏加进列表

1. 首次启动向导的最后一步就是「添加游戏目录」；错过了也没关系，在主界面的游戏列表页再加：选「添加游戏目录 / 扫描目录」，定位到你放镜像的文件夹；
2. 授权该文件夹后，列表会扫描出里面的镜像，游戏出现在列表 / 网格视图里；
3. 镜像放普通文件夹即可（比如内部存储里建个 `PS2Games`），路径自己记得住就行。

## 四、封面与桌面快捷方式

- **封面**：长按列表里的游戏 →「Choose Cover Image」挑一张图；也可以把封面图（jpg/png，文件名用游戏标题或游戏序列号）放进数据目录下的 `covers` 文件夹 —— 数据目录的位置见 [常见问题与故障排查.md](常见问题与故障排查.md) 存档那一节。
- **桌面快捷方式**：长按游戏 →「Create Launcher Shortcut」，下次从桌面直接进这款游戏。
- 封面与网格视图的显示细节会随版本调整，以你装的那版界面为准。

## 五、CHD 的两个坑（官方已知问题）

1. 用 `createdvd` 制作的 CHD 导入后不能用，除非制作时加 `-c zlib` 参数；`createcd` 制作的 CHD 通常更小，空间紧张优先用它。
2. 压缩只是省空间的手段 —— 转换完先开一局确认能正常进游戏，再考虑删掉原文件，别让唯一一份拷贝卡在半成品上。

## 六、游戏出现在列表但跑不动

先分清是格式问题还是性能问题：CHD 导不进按第五节；能进游戏但卡顿、花屏、黑屏，按 [画质与性能设置.md](画质与性能设置.md) 和 [常见问题与故障排查.md](常见问题与故障排查.md) 逐项排。
