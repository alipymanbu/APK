## 一、装的时候被拦

| 现象 | 怎么办 |
| --- | --- |
| 系统不让装（未知应用） | 给文件管理器或浏览器开「安装未知应用」权限，见 [下载与安装教程.md](下载与安装教程.md) 第四节 |
| Play Protect 弹警告 | 官方已知情况：APK 用测试密钥签名导致；官方发布页每版附 VirusTotal 报告，要不要继续由你判断 |
| 装完图标打不开、秒退 | 先核对包名 `xyz.aethersx2.android` 与文件大小（21.57 MB），见 [下载与安装教程.md](下载与安装教程.md) 第三节 |

## 二、游戏进不去、黑屏

按顺序查三样：

1. **BIOS** —— 向导走完了吗、BIOS 导入并被识别了吗？没有 BIOS 游戏起不来（官方口径：必需项），见 [首次启动与BIOS导入.md](首次启动与BIOS导入.md)；
2. **镜像本身** —— CHD 导不进的坑在 [游戏镜像与游戏列表.md](游戏镜像与游戏列表.md) 第五节；换一个游戏试，能排除是不是个别文件的问题；
3. **渲染器** —— 能进游戏但画面黑 / 花，切 OpenGL 或软件渲染器试（官方 FAQ：硬件渲染的花屏可以拿软件渲染器绕开）。

## 三、卡顿、掉帧

- 相机一转就掉帧 → 大概率是 GS 读回慢，把 Hardware Download Mode 调成 Disabled（或 Unsynchronized），代价是特效可能出瑕疵（官方口径）；
- 整体慢 → 按 [画质与性能设置.md](画质与性能设置.md) 第三节的清单从上往下试，每次只改一项；
- 手机本来就弱 → 门槛口径在 [下载与安装教程.md](下载与安装教程.md) 第六节；两个大核的机器别开多线程 VU；
- 升级之后才变卡 → 先把设置重置一遍再试（官方 FAQ：新版本可能改了更好的默认值）。

## 四、官方点名的已知问题（不是你配错了）

这些都在 NetherSX2 官方发布说明的 Known Issues 里，对上号就别再折腾设置：

| 问题 | 官方口径 |
| --- | --- |
| NASCAR、Colin McRae 系列画面异常 | 4248 主线的已知问题 —— 玩这几款换 Classic（3668）线 |
| 老款 Mali 在 Vulkan 下渲染异常或崩溃 | 先用 OpenGL 过关卡，或改用 Classic；新款 Mali 无此问题 |
| 即时存档在两条线之间读不出来 | 3668 与 4248 的 save state 互不兼容 —— 跨线换用请走游戏内存档 / 记忆卡 |
| createdvd 做的 CHD 用不了 | 制作时加 `-c zlib`，或改用 createcd |
| 2024 年及以后做的贴图包不兼容 | PCSX2 改了贴图命名方式，只有旧命名的包能用 |
| 较新的 RetroAchievements 成就不工作 | 用了新功能（Remember / Recall）的成就集暂不支持，官方在跟进 |
| Play Protect 警告 | 测试密钥签名所致，见第一节 |

## 五、存档相关

- **存档在哪**：`Android/data/xyz.aethersx2.android` 目录下，即时存档与记忆卡都在这里；Android 11+ 上文件管理器要额外授权才能进这个目录（官方 FAQ 口径）。
- **即时存档槽**：暂停菜单 → Load/Save state，10 个槽 + 1 个快速存档（给触屏按钮用）。
- **从别的设备搬存档**：只能整张记忆卡导入、不能单个存档搬 —— 在游戏列表**从左边缘往右滑**唤出「Import Memory Card」，选一份 `*.ps2` 镜像导入。
- **换机 / 重装前**：先用应用内 Transfer Data → Export 导出一份（官方升级指南也是这么建议的，见 [下载与安装教程.md](下载与安装教程.md) 第五节）。

## 六、手柄不识别、按键错位

先看系统层能不能用，再看自动映射有没有漏掉扳机键 —— 步骤在 [手柄与屏幕按键设置.md](手柄与屏幕按键设置.md)。按键「按了没反应」多半是没映射上，不是手柄坏了。
