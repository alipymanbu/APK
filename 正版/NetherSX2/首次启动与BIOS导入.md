## 一、向导一共几步

首次启动是一个分步向导，走完才进主界面（界面沿用 AetherSX2 的设计，NetherSX2 没有另改这套流程）：

1. **欢迎与常见问题页** —— 直接下一步。
2. **选性能预设** —— Optimal/Safe 与 Fast/Unsafe 两个选项。官方口径是默认的 Optimal/Safe 对多数游戏兼容性和表现都最合适，除非你的机器明显带不动，否则选它。
3. **Import BIOS（导入 BIOS）** —— 在文件选择器里选中你的 BIOS 镜像文件；回到列表后要把那一份**点选中**（单选钮打上勾）再下一步（独立教程口径）。
4. **确认 BIOS 生效** —— 看到 BIOS 被识别后再下一步。
5. **添加游戏目录** —— 选中存放游戏镜像的文件夹，进游戏列表。选完应用会扫描并导入该目录下的全部游戏，镜像多时要等一会（独立教程口径）。

向导之后随时能改：设置里有 BIOS 选项可以重新导入，游戏目录也能在主界面补加（见 [游戏镜像与游戏列表.md](游戏镜像与游戏列表.md)）。横竖屏默认跟随系统自动旋转，也可以在 App Settings 第一页强制横屏。

## 二、BIOS 为什么必须有

官方 FAQ 的口径很直接：BIOS 镜像是运行游戏的必需项，不是可选项；它应当用自制软件（homebrew）从**你自己的** PS2 主机里导出。

- 应用本身不带 BIOS —— 安装包里没有，也不会替你准备；
- 正确的来路只有你自己那台主机：用自制工具把主机 BIOS 导出来，网上这类教程很多（搜「PS2 BIOS dump」即可找到）；
- 不要从来历不明的下载站随手抓一份 BIOS 文件 —— 既不可靠，也可能踩版权问题。本套文档不提供 BIOS 下载。

存放位置随你：放普通文件夹最省心（社区教程建议直接放进你的游戏文件夹）。应用自己的数据目录是 `Android/data/xyz.aethersx2.android`，其中 `files/bios` 是 BIOS 位、`files/textures` 是贴图包位（社区教程口径）—— Android 11+ 直接往这个目录拷文件常常不生效（系统对 `Android/data` 的限制），所以导入这一步走应用内的文件选择器就好，不必手动拷。

## 三、导入操作与生效确认

1. 向导走到 Import BIOS 时点它，在文件选择器里找到你导出的 BIOS 文件（常见形态是一份 `.bin` 镜像）并选中；
2. 回到向导，确认这一步显示已识别、能点下一步 —— 这就代表导入成功；
3. 之后想换一份：去设置里的 BIOS 选项重新选（部分版本里叫 Choose BIOS File）。

导入不生效、向导卡在这一步的排查见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、进主界面后的第一件事

- **别急着点游戏** —— 此时列表是空的，你还缺游戏镜像，去 [游戏镜像与游戏列表.md](游戏镜像与游戏列表.md) 把文件备好、目录加上；
- **过一遍全局设置**：性能预设从 Optimal/Safe 起步；图形选项该动哪几项见 [画质与性能设置.md](画质与性能设置.md)；
- **按键先能用就行**：触屏按键开箱就能点，要接实体手柄的映射见 [手柄与屏幕按键设置.md](手柄与屏幕按键设置.md)。

## 五、向导走不动的三种情况

| 现象 | 先查什么 |
| --- | --- |
| 装都装不上 | 不是向导的问题，见 [下载与安装教程.md](下载与安装教程.md) 第四节 |
| 导入 BIOS 那步选不到文件 | 确认 BIOS 文件还在手机里、路径记得住；文件没下载完整就重新拷一份 |
| 打开就闪退、黑屏 | 先核对包名与安装步骤（[下载与安装教程.md](下载与安装教程.md) 第三、四节），再按 [常见问题与故障排查.md](常见问题与故障排查.md) 对号入座 |
