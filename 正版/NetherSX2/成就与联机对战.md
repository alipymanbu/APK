## 一、成就走的是第三方服务

成就不是应用自带的奖杯，而是接的 [RetroAchievements](https://retroachievements.org)（下称 RA）—— 一个给老游戏做成就的社区服务，账号要在它官网注册。独立教程的口径：NetherSX2 是 RA 官方支持的安卓 PS2 模拟器；官方项目也把「修复 RetroAchievements 通知」列为自己的改动项，2.1 发布说明里还专门修过硬核模式的成就问题 —— 版本越新，这块越稳。

## 二、开通步骤

1. 先去 [retroachievements.org](https://retroachievements.org) 注册账号，并按邮件验证；
2. 应用内：左上角三横线 → App Settings → **Achievements** 标签；
3. 打开 Enable RetroAchievements，填上官网的账号密码登录（两份独立教程的步骤一致）；
4. 成就需要**联网**才会弹 —— 断网状态下不判成就。

## 三、你的游戏能不能出成就

- **镜像要匹配**：成就集按镜像的哈希与区域匹配 —— 同一游戏美版 / 欧版 / 日版常常只有一个版本有成就。先在 RA 官网搜游戏名，确认有没有成就集、支持哪个版本（独立教程口径）；
- **硬核模式（Hardcore）**：RA 服务的规则是硬核模式禁用即时存档、快进与金手指，积分双倍（RA 官方文档口径）。要不要开自己权衡 —— 开着的时候这三样都别碰，与 [金手指代码怎么用.md](金手指代码怎么用.md) 第六节互为反面；
- **官方已知问题**：较新的、用了 Remember / Recall 功能的成就集在 NetherSX2 上不能用（发布说明口径，官方标注在跟进）—— 遇到「有成就集却弹不出来」，先对上这一条。

## 四、联机对战：版本先对上

- 官方在 **2.2n 开发版**的发布说明里加入了实验性联机，并在设置里新增 Networking 区（发布说明口径，2026 年初）；
- 网盘这份 **v1.9a-dev 未必有这个入口** —— 以你实际看到的界面为准；稳定线是否已合入，以 [官方发布页](https://github.com/Trixarian/NetherSX2-patch/releases) 为准；
- 能联什么游戏：官方发布说明附了一份「PS2 联机游戏清单（2024）」表格，列了哪些游戏能联、各用哪个私服 —— 游戏和私服都要先按表确认。

## 五、官方给的开启步骤（2.2n 口径）

1. App Settings → System Settings → 打开 **Enable DEV9 Ethernet**；
2. **API** 选 Sockets；**Device** 按你的网络选 —— 默认 WiFi，走 VPN 或手机流量的选对应项；
3. 需要手动指 DNS 时：**DNS1 Mode** 选 Manual，DNS1 填社区私服地址 —— 官方发布说明点名的两家是 [ps2online.com](https://ps2online.com) 与 [psrewired.com](https://psrewired.com)；这项也可以按游戏单独给；
4. 用完想关：DNS1 Mode 改回 Auto、DNS1 填 `0.0.0.0`，再把 DEV9 开关关掉。

官方在发布说明里还附了配套视频教程，具体以发布页当时的内容为准。

## 六、不顺的时候

- **成就不弹**：查登录状态与网络 → 查镜像区域是否匹配成就集（第三节）→ 对「新成就集不支持」的已知问题（[常见问题与故障排查.md](常见问题与故障排查.md) 第四节）；
- **联机进不去**：先确认版本里有没有 Networking 区（第四节），再核对 DEV9 与 DNS 的填法（第五节）；私服本身挂没挂，看对方公告。
