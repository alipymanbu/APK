## 一、先别动默认值

首次启动选的 Optimal/Safe 预设，官方口径是「对多数游戏兼容性和表现都最好」。先按默认玩，遇到某个游戏出问题再往下调 —— 每次只改一项，改完玩一局验证，才知道是哪一项起了作用。

另外一条官方提醒：**升级后突然变卡，先把设置重置一遍** —— 新版本可能换了更好的默认值，你的旧自定义反而在拖后腿。

## 二、渲染器：Vulkan 还是 OpenGL

| 你的情况 | 怎么选 | 依据 |
| --- | --- | --- |
| Adreno GPU（多数骁龙机） | 用 Vulkan | 官方 FAQ 的提速建议 |
| 某个游戏在 Vulkan 下画面错、或反而更慢 | 这个游戏单独切 OpenGL | 官方 FAQ：部分游戏在 OpenGL 下表现更好 |
| 老款 Mali GPU | 优先 OpenGL；Vulkan 可能渲染出错甚至崩溃（官方点名 Dark Cloud 2 这类情况） | NetherSX2 官方已知问题；新款 Mali 无此问题 |
| 用 Classic（3668）线 + Vulkan | 顺手把 Threaded Presentation 打开 | 官方 README 的性能建议 |

顺带一提：AetherSX2 时代的 FAQ 存档对「Mali 该不该上 Vulkan」前后两版说法不一致，NetherSX2 自己的发布说明给的是上表这条（老 Mali 走 OpenGL），以它为准。

## 三、官方给的优化手段清单

按代价从小到大排，逐项试：

| 手段 | 在哪开 | 代价 / 注意 |
| --- | --- | --- |
| 硬件读回关闭 | Graphics → Hardware Download Mode 选 Disabled（或 Unsynchronized） | 相机一转就掉帧时有效；特效可能出现瑕疵 |
| fastmem | System 设置 | 官方 FAQ 列的提速项，建议保持开启 |
| 多线程 VU（MTVU） | System 设置 | 至少 3 个大核才划算；两个大核的机器别开 |
| 降低分辨率 | Graphics → 分辨率缩放 | 机型弱时最直接的减负手段 |
| 预载纹理 + GPU 调色板转换 | Graphics 设置 | 部分游戏有效（官方 FAQ 口径） |
| 降低混合精度 | Graphics → 混合精度 | 换性能，代价是画面可能出错 |
| 音频同步改 Async Mix | Audio → SPU2 混音模式 | 不是所有游戏都兼容 |
| 降频模拟 CPU | System：cycle rate 调负数、cycle skip 调正数 | 官方明说：游戏内部会卡，最坏可能崩溃 —— 最后手段 |
| 切软件渲染器 | Graphics → Software | 绕开硬件渲染的花屏；画面全靠 CPU 算，明显更吃处理器（配方见下） |
| 宽屏补丁 | Graphics → Enable Widescreen Patches | 16:9 屏才用得上；补丁集由 NetherSX2 持续更新（官方更新说明） |
| Threaded Presentation | Graphics 设置 | 老 Mali 提振明显（独立教程口径）；3668 线 + Vulkan 官方也要求开 |
| 显示帧率 | App Settings → Show FPS（OSD Scale 调字号） | 只用来观测，不提速 |
| 快进倍率 | System → Speed Control | 默认 200%，机器强可再调高（独立教程口径） |
| 预载贴图包 | Graphics → Load Texture Replacements | 用 HD 贴图包才开，详见第六节 |

软件渲染器要跑得动，官方给的配方是：4 个大核的机器关掉多线程 VU、把软件渲染线程设为 2、再开 affinity control；只有 2 个大核的机器别指望软件渲染器（小核算栅格太慢）。

**affinity control（CPU 亲和）**：三星、Pixel 这类机型上能改善帧率稳定性。帧率在 20fps 以上来回跳时可以拿它试：先在 Graphics 里开「Show CPU Usage」看哪个线程最重，再选对应的模式。这项设置可以按游戏单独给。

## 四、单个游戏单独调

全局保持默认，只给问题游戏开小灶：

- 游戏列表里**长按**该游戏 → Game Properties → Game Settings 标签，在这里改的只影响这一款；
- 游戏中也能进：暂停菜单 → 右上角 info 按钮 → Game Properties；
- 用法上把「渲染器、分辨率这类只有这一款特殊」的项放进单游戏设置，全局那份保持默认，其余游戏不受影响。

## 五、宽屏的两条路

1. **宽屏补丁**：Graphics → Enable Widescreen Patches —— 给本身没有宽屏模式的游戏补出 16:9；这批补丁由 NetherSX2 持续更新（官方更新说明点名维护者）；
2. **让虚拟 PS2 以为你的屏是 16:9**：Settings → Start BIOS 进主机的 System Configuration → Screen Size 改成 16:9，再 Exit Game 退出 —— 带内置宽屏模式的游戏会直接用上，不必打补丁（独立教程做法）。

两条不冲突：内置宽屏靠第 2 条，没有内置宽屏的游戏靠第 1 条。

## 六、贴图包（HD Texture Packs）

- **总开关**：Graphics 拉到底，打开 Load Texture Replacements；
- **放哪**：贴图放 `Android/data/xyz.aethersx2.android/files/textures/<游戏序列号>/`（社区教程口径）。Android 11+ 手动往这个目录拷文件可能不显示 —— 用带授权能力的文件管理器操作（系统对 `Android/data` 的限制，与 [首次启动与BIOS导入.md](首次启动与BIOS导入.md) 第二节同一原因）；
- **官方已知限制**：2024 年及以后制作的贴图包不兼容（PCSX2 改了贴图命名方式），只有旧命名的包能用 —— 这是版本限制，不是你放错位置。
