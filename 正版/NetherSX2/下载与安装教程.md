## 一、NetherSX2 是什么

NetherSX2 是安卓平台上的 PlayStation 2（PS2）模拟器，由社区在 AetherSX2 停更之后接手延续：AetherSX2 的开发者 Tahlreth 于 2023 年 1 月宣布停止开发，此后社区项目 NetherSX2 接续维护 —— 最早由 Anon 与 EZOnTheEyes 做出，现在由 Trixarian 在 GitHub 上维护（[官方项目页](https://github.com/Trixarian/NetherSX2-patch)）。

你装它要干的事很明确：在手机上运行你自己的 PS2 游戏镜像。它不带 BIOS、也不带游戏 —— BIOS 要从你自己的 PS2 主机导出，游戏镜像要从你自己的光盘做出来，分别见 [首次启动与BIOS导入.md](首次启动与BIOS导入.md) 和 [游戏镜像与游戏列表.md](游戏镜像与游戏列表.md)。

它与原版的关系，几条要点：

- 包名与 AetherSX2 完全相同（`xyz.aethersx2.android`），装上后读的是同一份应用数据；
- 维护者给它的定位是 AetherSX2 的补丁延续版：更新游戏兼容配置（GameDB，条目取自 PCSX2）、更新宽屏与去隔行补丁、更新手柄配置库、修复 RetroAchievements 通知、暴露更多全局设置，并清理原版 APK 里残留的广告与统计服务组件；
- 没有上架应用商店，安装包只从 GitHub 发布页或网盘这类渠道取得；
- 后继项目 EtherealSX2 已在开发（[GitHub 仓库](https://github.com/Trixarian/EtherealSX2)），发到哪一步以官方页面为准。

## 二、两条版本线怎么选

NetherSX2 有两条并行的版本线，按你玩的游戏和手机芯片选：

| 版本线 | 基底 | 适合谁 | 官方点名的注意点 |
| --- | --- | --- | --- |
| 主线（Patched） | AetherSX2 v1.5-4248 | Adreno GPU（骁龙）与性能较强的机器 | NASCAR、Colin McRae 系列在它上面有画面问题 |
| Classic | AetherSX2 v1.5-3668 | 老 Mali、性能较弱的机器 | 少了 4248 那批画面修复；部分游戏反而只有它跑得好 |

官方 README 的口径是「看你玩什么」：Classic 一般更省性能，主线的兼容性修复更多。两条线的即时存档（save state）互不通用，来回换请用游戏内存档 —— 细节见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 三、安装包从哪拿

两条路：

1. **网盘**：打开 [NetherSX2 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4bd835138339)，把 APK 下到手机。网盘里是固定的一版，不会自动更新。
2. **官方发布页**：主线在 [github.com/Trixarian/NetherSX2-patch](https://github.com/Trixarian/NetherSX2-patch/releases)，Classic 线在 [github.com/Trixarian/NetherSX2-classic](https://github.com/Trixarian/NetherSX2-classic/releases)。每条发布里分「稳定版 / 开发版」两个下载位，当前各是哪个版本以页面为准（截至 2026-09，主线稳定版为 2.1）。官方每个版本都附 VirusTotal 扫描报告链接，不放心就先扫。

网盘里那份安装包的记录如下，下载后可逐项核对：

| 项目 | 值 |
| --- | --- |
| 版本 | v1.9a-dev |
| 大小 | 21.57 MB |
| 包名 | `xyz.aethersx2.android` |
| MD5 | `416D096A9271EE807D4DEEEA3D13A52E` |
| 信息记录日期 | 2026-09-23 |

- **核对大小**：下载完成的文件应约 21.6 MB，明显偏小说明没下完整，删掉重下。
- **核对包名**：装之前用任意「查看 APK 信息」的工具打开文件，确认包名是 `xyz.aethersx2.android`。安卓上的 PS2 模拟器不止这一个，包名对不上就别装。
- 网盘这版（v1.9a-dev）比官方发布页上的现行版本旧，两边版本号不要混着对。

## 四、安装步骤

1. 按第三节把 APK 下载到手机，核对大小与包名。
2. 用文件管理器点这个 APK 安装。手机若弹出「禁止安装未知应用」，去「设置 → 应用 → 特殊应用权限 → 安装未知应用」里给文件管理器或浏览器开权限，再装一次（各品牌路径略有差异，认准「安装未知应用」这个词）。
3. 装完桌面出现图标，点开进入首次启动向导 —— 后面几步见 [首次启动与BIOS导入.md](首次启动与BIOS导入.md)。

### 安装时 Play Protect 弹警告

官方发布说明把它列为已知情况：项目用测试密钥（test keys）给 APK 签名，Google Play Protect 可能因此弹警告。判断依据两条：官方发布页为每个版本附了 VirusTotal 扫描报告；这条警告针对的是签名方式，不是扫描出的具体恶意行为。要不要继续安装，由你自己判断。

## 五、从旧版本升级

官方 README 按「你现在的版本」给了两条路径，照你的起点对号入座：

**你在用 NetherSX2 1.9a 或更新**（网盘这份 v1.9a-dev 就在这条线上）：

1. 建议先导出一份备份（可选但稳妥）：应用内 Transfer Data → Export 会把 BIOS、记忆卡、即时存档、游戏设置、封面、贴图包一起导出到一个文件夹；
2. 直接点新 APK 覆盖安装，当前设置会保留。

**你在用 AetherSX2，或低于 1.9a 的 NetherSX2**：

1. 先在旧应用里用 Transfer Data → Export 导出全部数据；
2. 正常卸载旧应用，卸载时不要保留文件；
3. 安装 NetherSX2；
4. 进到游戏列表界面后，用 Transfer Data → Import 把刚才导出的文件夹导回 —— BIOS、记忆卡、即时存档、游戏设置、封面、贴图包都会回来；
5. 全局设置重新过一遍（这部分不随导入走）。

两条路径共同的前提：**旧应用要卸干净** —— NetherSX2 与 AetherSX2 同包名、不同签名，残留的旧版本会让新包装不上；同一时间也只能装一个版本（社区汇总帖口径，截至 2026-01）。导出备份的具体做法见 [存档备份与换机迁移.md](存档备份与换机迁移.md)。

## 六、手机能不能带得动

官方 FAQ 对硬件的口径只有一套：

- **处理器**：至少骁龙 845 级别 —— 具体说就是 4 个大核（Cortex-A75 级）；
- **只有两个大核的机器**（如骁龙 700 系）能装，但别开多线程 VU，开了反而更差，重型游戏基本指望不上；
- **GPU**：Adreno 表现最好；Mali、PowerVR 能跑但明显更慢（老 Mali 还有额外的渲染坑，见 [画质与性能设置.md](画质与性能设置.md)）；
- 网盘那份包内标注的最低系统是安卓 5.2 —— 系统版本够不等于跑得动，芯片才是门槛；
- 社区汇总帖（4PDA，2026-01 更新）给的系统口径是「安卓 8.0+ 64 位、骁龙 845+ 级」—— 与官方 FAQ 的芯片口径互相印证，但两条都只是入门线，重游戏照样吃硬件。

装不上、进不去的排查见 [常见问题与故障排查.md](常见问题与故障排查.md)。
