## 一、先弄清楚你要装的是什么

Magisk 是一套开源的 Android 系统自定义工具（GPL v3 协议，作者 topjohnwu），官方要求设备系统高于 Android 6.0。它由几个部分组成：

| 组成 | 你能用它做什么 |
| --- | --- |
| MagiskSU | 给需要 root 权限的应用授予权限 |
| Magisk Modules | 通过安装模块修改只读的系统分区 |
| MagiskBoot | 解包与重打包 boot 镜像 |
| Zygisk | 部分模块依赖的运行环境，需在应用设置里开启 |

中文社区常把 Magisk 叫「面具」；老教程里说的「Magisk Manager」，指的就是现在的 Magisk 应用本体。

本篇对应网盘里那份安装包的版本为 30.7（约 11.08 MB，包名 com.topjohnwu.magisk）。官方最新版本号随时间变化，以 GitHub Releases 页面显示为准：[`https://github.com/topjohnwu/Magisk/releases`](https://github.com/topjohnwu/Magisk/releases)。

## 二、安装前你要准备什么

对照下面这份清单逐项确认，缺一项都走不下去：

1. **Bootloader 已解锁**。Magisk 的安装方式是把修补过的镜像刷进 boot 分区，锁着写不进去。没解锁的先看[解锁Bootloader与准备工作.md](解锁Bootloader与准备工作.md)。
2. **会用 adb 和 fastboot**。整个流程需要在电脑上敲几条命令，工具用 Google 官方的 platform-tools：[`https://developer.android.com/tools/releases/platform-tools`](https://developer.android.com/tools/releases/platform-tools)。
3. **一份与当前系统版本完全一致的镜像**。有 ramdisk 的机型取 `boot.img`（有 `init_boot` 分区的机型取 `init_boot.img`），没有 ramdisk 的机型取 `recovery.img`。镜像从你机型对应的官方固件包或自定义 ROM 压缩包里提取。
4. **Magisk 应用装在手机上**。安装包可从上面 GitHub Releases 页面下载，也可以直接使用这份 Magisk 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/94a0e9615942](https://pan.quark.cn/s/94a0e9615942)。
5. **电量和数据**。电量保持 50% 以上；开刷前把手机里的照片、聊天记录备份一遍，后面任何一步出岔子都可能要清数据。

另外两个顺序问题：如果你还要刷自定义内核，先装 Magisk 再刷内核；如果之前装过 Magisk，这次升级直接在应用里用「直接安装」，不要重复本篇的首次安装流程，具体见[更新通道与升级方法.md](更新通道与升级方法.md)。

## 三、确认你的机型走哪条路线

打开 Magisk 应用，首页 Magisk 卡片里有一行 **Ramdisk** 的显示结果，它决定你走哪条路：

- **显示「是」**：常规路线，修补 `boot.img`（或 `init_boot.img`），按第四节的流程走。
- **显示「否」**：你的机型 boot 分区里没有 ramdisk，Magisk 只能借助 recovery 分区工作，刷入方式有特殊变化，先读官方安装文档里「Magisk in Recovery」一节再动手：[`https://topjohnwu.github.io/Magisk/install.html`](https://topjohnwu.github.io/Magisk/install.html)。
- **三星机型**：跳过本篇通用流程，直接看[三星机型安装步骤.md](三星机型安装步骤.md)。

有个例外要知道：部分小米机型明明不该有 ramdisk，bootloader 却照样接受 ramdisk，界面上却显示「否」。官方的说法是没法事前检测，只能实际试一次。如果你是这类机型、刷完没生效，按「有 ramdisk」的路线上再做一次即可。

## 四、修补镜像并刷入（主流流程）

确认手里有 Magisk 应用、对应的镜像文件后，按顺序做：

1. 把 `boot.img` / `init_boot.img` / `recovery.img` 拷进手机存储。
2. 打开 Magisk 应用，在 Magisk 卡片上点**安装**。
3. 如果你要修补的是 recovery 镜像，勾选**Recovery Mode**选项。
4. 方式选择**选择并修补一个文件**，选中刚才拷进来的镜像，开始安装。
5. 修补完成后，把生成的镜像拉回电脑（文件名里的随机串每次不同，以你手机上实际生成为准）：

   ```bash
   adb pull /sdcard/Download/magisk_patched_xxxxx.img
   ```

6. 手机重启进 fastboot 模式，把修补过的镜像刷回对应分区（分区名与你修补的镜像类型对应）：

   ```bash
   fastboot flash boot magisk_patched_xxxxx.img
   # 或 init_boot / recovery，与第 3 步的镜像类型保持一致
   ```

7. 可选步骤：如果你的机型有独立的 `vbmeta` 分区，可以在 fastboot 下刷一次禁校验的 vbmeta：

   ```bash
   fastboot flash vbmeta --disable-verity --disable-verification vbmeta.img
   ```

   注意这一步可能清空你的数据。

8. 重启开机，打开 Magisk 应用，会弹一个「需要修复运行环境」的提示，点确认并等待自动重启。

**两条官方警告，务必照做：**

- 绝不刷别人分享给你的修补镜像，也绝不在另一台设备（哪怕同型号）上修补镜像再拿回来刷 —— 出问题可能要清空全部数据才能救回来。
- 修补镜像这一步，永远在你要装 Magisk 的那台设备本机上完成。

## 五、首次启动

刷入并重启后，打开应用确认这几件事：

- 首页 Magisk 卡片处的「已安装」显示出版本号（例如 30.7），说明刷入成功。
- 第一次启动如果提示修复运行环境，按提示操作等待重启即可。
- 之后你大概率会想装模块，方法和注意事项在[模块安装与管理.md](模块安装与管理.md)。

装完先别急着装一堆东西。建议当天先正常用一用、重启一两次确认系统稳定，再开始加模块 —— 万一之后开机卡住，自救方法在[开机循环怎么办.md](开机循环怎么办.md)。

## 六、三星机型的差异

三星机型的安装路线和上面不同，关键差异先说清楚，让你判断要不要继续：

- 装 Magisk 会**永久熔断 Knox**，这个动作在任何情况下都不可逆，影响三星自家的安全相关功能与官方售后政策。
- 首次安装**必须清空全部数据**（不含解锁 bootloader 时那一次），动手前必须备份。
- 刷入不走 fastboot，而是用 Odin 把修补过的 `AP` tar 文件连同 `BL` / `CP` / `CSC` 一起刷入。
- 完整的分步操作（OEM Lock / KnoxGuard 解锁检查、Odin 刷入、升级系统）在[三星机型安装步骤.md](三星机型安装步骤.md)，内容以官方文档三星专区为依据：[`https://topjohnwu.github.io/Magisk/install.html`](https://topjohnwu.github.io/Magisk/install.html)。

如果你能接受这些代价，按三星篇的步骤一步步走；哪一步拿不准，先回到第二节把准备工作再核对一遍。
