# 解锁Bootloader与准备工作

> 装 Magisk 的前提是 bootloader 已解锁。本篇讲清解锁要付出什么代价、在手机和电脑上各要准备什么、镜像去哪找，把首次安装前的坑一次排掉。

## 一、为什么必须解锁，解锁要付出什么

Magisk 的安装方式是把修补过的镜像写进 boot（或 init_boot / recovery）分区。bootloader 锁着的时候，任何分区都写不进去，所以这一步绕不开。

解锁前先对照这张表，确认你能接受代价：

| 代价 | 说明 |
| --- | --- |
| 数据全清 | 解锁动作本身就会清空手机全部数据，先备份 |
| 保修状态变化 | 多数品牌对已解锁设备的保修政策不同，以你品牌官方售后的口径为准 |
| 三星 Knox 熔断 | 不可逆。Knox 触发后三星自家的安全相关功能（如部分金融类应用的正常运行）和官方售后政策都会受影响 |
| 安全基线下降 | 解锁后任何人拿到你的手机都可以刷入镜像，建议解锁后不要在手机里存敏感凭据 |

三星机型在解锁前还要额外确认两个状态：下载模式（Download mode）里的 **OEM Lock** 值和 **KnoxGuard** 值。KnoxGuard 处于 `Active` / `Locked` 状态的设备（多见于运营商渠道机）无论怎么操作都装不了 Magisk；`Prenormal` 状态需要设备累计开机达到 168 小时后才会转为解锁状态。具体查看位置：设置 → 电池和设备维护 → 维护模式开启后，进下载模式查看。

## 二、手机端的准备

### 1. 打开 OEM 解锁开关

设置 → 关于手机 → 连续点 7 次「版本号」打开开发者选项，然后在开发者选项里打开 **OEM 解锁（OEM unlocking）**。开关打不开时要分情况：三星机型的解锁可行性以下载模式里的 OEM Lock 值为准（见第一节末尾），不要只看这个开关下结论；其他品牌多见于运营商渠道机（美版、加版常见），开关灰色通常意味着设备被锁死解锁，那这台设备就走不通了。

### 2. 打开 USB 调试

同样在开发者选项里打开 **USB 调试**。后面电脑上的 adb、fastboot 命令全靠它。

### 3. 备份

再强调一次：解锁会清空全部数据。照片、通讯录、聊天记录、验证器应用，全都要先导出。

## 三、电脑端的准备

1. 下载 Google 官方 platform-tools（内含 adb 与 fastboot）：[`https://developer.android.com/tools/releases/platform-tools`](https://developer.android.com/tools/releases/platform-tools)，解压到一个路径里没有中文的目录。
2. 手机用数据线连电脑，首次连接手机上会弹「是否允许 USB 调试」，勾选允许。
3. 验证连接：

   ```bash
   adb devices
   ```

   能列出一行设备号即连接正常。验证 fastboot 则先重启到 fastboot 模式再执行：

   ```bash
   fastboot devices
   ```

   常见坑：Windows 下设备管理器里出现带黄色叹号的未知设备，多半是驱动问题，装对应品牌的手机驱动或 Google USB Driver 即可。

## 四、找到你需要的镜像

你要的那份镜像（`boot.img` / `init_boot.img` / `recovery.img`，取决于机型有没有 ramdisk，判断方法见[下载与安装教程.md](下载与安装教程.md)第三节）通常从这两个地方来：

1. **官方固件包**：你机型对应品牌的官方固件下载渠道，下载与手机当前系统版本**完全一致**的固件包，解压后提取镜像。版本号差一位都可能刷不开机。
2. **自定义 ROM 压缩包**：如果你刷的是第三方 ROM，镜像在 ROM 的 zip 里。

两个提醒：

- 镜像版本必须与你手机当前的系统版本一致。先在设置里查清当前系统版本号再去下固件。
- 把提取出来的镜像在电脑和云盘里各存一份。这份原版镜像是你日后还原系统、救砖的底牌，一旦丢了会很麻烦。具体怎么用它还原，见[卸载教程与还原原系统.md](卸载教程与还原原系统.md)。

## 五、准备工作的验收标准

全部就绪的标志，对照下面几条：

- 开发者选项里 OEM 解锁已打开（或已确认你的设备可解锁）；
- USB 调试已打开，`adb devices`、`fastboot devices` 都能认到设备；
- 手机里已装好 Magisk 应用；
- 手里有一份与当前系统版本一致的镜像文件；
- 数据已备份，镜像已另存。

五条全满足，就可以进入正式安装流程了，步骤在[下载与安装教程.md](下载与安装教程.md)第四节。
