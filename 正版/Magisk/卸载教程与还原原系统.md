# 卸载教程与还原原系统

> 想把 Magisk 从设备上彻底移除、还原到官方系统状态，本篇按不同安装方式给出对应的卸载路径，以及三星机型绝对不能踩的一个坑。

## 一、首选：应用内卸载

绝大多数人只需要这一条路：

1. 打开 Magisk 应用 → **设置** → **卸载 Magisk**。
2. 选**完全卸载**：应用会自动还原你当初修补的镜像并重启设备，重启后设备回到未安装状态。
3. 如果只是想临时关闭 root、之后再用，选「仅还原镜像」即可，不用动应用本体。

卸载完成后，手机桌面上的 Magisk 应用图标会随卸载消失。个别情况下重启后应用还在，手动卸载这个应用即可，此时它已经只是个普通应用，不再有系统级作用。

## 二、自定义 Recovery 用户的卸载方式

如果你的设备装过第三方 Recovery（TWRP 之类），也可以在 Recovery 里完成卸载：

1. 把 Magisk 的 APK 文件改名为 `uninstall.zip`（在手机上用文件管理器改，Windows 上如果看不到扩展名，先在文件夹选项里打开「显示文件扩展名」）。
2. 把改好名的 zip 放进手机存储。
3. 进 Recovery，像刷普通卡刷包一样刷入这个 zip。
4. 重启。

注意：官方已把自定义 Recovery 的安装方式标记为**弃用**，仅作最低限度维护。能用第一节的应用内卸载，就不要走 Recovery。另外装有模块的设备，Recovery 方式不要顺手清掉 cache 分区 —— 部分模块的规则文件存在那里，清了会导致残留问题。

## 三、三星机型：绝对不要手动刷回原版分区

这是三星用户最容易翻车的地方，官方原文的警告级别是「绝不要（Never, ever）」：

**不要用任何工具把 `boot`、`init_boot`、`recovery`、`vbmeta` 这些分区单独刷回原版镜像。** 这样做的结果是设备变砖，而且只有全量 Odin 救回（连带清空全部数据）这一条恢复路。

三星机型的正确做法：

- **想卸载**：走第一节的完全卸载，让应用自己处理。
- **想升级系统**：不要等 OTA，也绝不能直接刷原版 `AP` 文件。去下载新版本固件，把新的 `AP` tar 先在 Magisk 应用里修补，再按安装时的 Odin 流程刷入；与首次安装唯一的差别是这次用 `HOME_CSC` 而不是 `CSC`（升级不清数据，首次安装才清）。
- 完整的三星安装流程回顾在[下载与安装教程.md](下载与安装教程.md)第六节。

## 四、卸载后还要处理什么

- **解锁状态不会变**：卸载 Magisk 不会重新锁定 bootloader。确需回锁的，先查清你品牌官方的回锁条件与流程；条件不满足时强行回锁，设备可能直接变砖。
- **模块残留**：完全卸载会一并处理模块文件；如果你之前手动备份过模块 zip，确认不再需要后再删。
- **镜像备份**：[解锁Bootloader与准备工作.md](解锁Bootloader与准备工作.md)第四节里让你另存的那份原版镜像，在设备确认一切正常后可以继续留着 —— 留着它，以后随时能干净地重来一遍解锁之后的完整流程。
- **应用白名单**：当初给过 root 权限的应用，卸载后它们请求 root 会直接失败，属正常现象，不用处理。
