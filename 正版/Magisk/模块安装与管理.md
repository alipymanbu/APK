# 模块安装与管理

> 模块是 Magisk 最常用的玩法：不改系统分区就替换或新增系统功能。本篇讲模块怎么装、怎么更新卸载、Zygisk 开关在哪、装坏了怎么用安全模式兜底。

## 一、模块是什么，你能拿它做什么

模块是打包成 zip 的小型补丁。装上之后，它替换的部分只在系统运行时生效，只读的系统分区本身一个字节都没动 —— 想还原，把模块禁用或删掉、重启就行。这是模块和刷机包最本质的区别：**试错成本极低，前提是你一次只试一个**。

官方应用本身不提供模块商店，模块 zip 都从社区渠道拿。社区里流通的模块覆盖的大方向有：界面与字体调整、状态栏与导航行为调整、机型参数修改等。具体某个模块是什么效果，以它自己的发布页说明为准。

## 二、安装一个模块的完整步骤

1. 把模块 zip 下载到手机存储（来源见第四节）。
2. 打开 Magisk 应用，底部切到**模块**页。
3. 点**从存储安装**，选中那个 zip。
4. 安装完成后按提示**重启**，模块在重启后才生效。
5. 重启后回到模块页，确认模块开关是启用状态。

更新与卸载都在模块列表里完成：模块条目上可以直接检查更新、禁用、卸载，改完重启生效。

## 三、Zygisk 开关

一部分模块依赖 Zygisk 运行环境。它默认不开，位置在：

**设置 → Zygisk**，打开后重启生效。

两个提示：

- Zygisk 开关状态变化都要重启才生效，刚打开发现模块还是不工作，先重启再说。
- 模块的说明页一般会写明「需要 Zygisk」或「不需要」。装之前看一眼，能省一次重启。

## 四、模块从哪里来，怎么挑

模块没有统一的官方应用商店，主要流通渠道是开发者的 GitHub 仓库和各大安卓开发社区。挑的时候按这几条过滤：

| 检查点 | 为什么 |
| --- | --- |
| 最近更新时间 | 停更大半年的模块在新系统上大概率有兼容问题 |
| 适配的系统版本 | 说明页会写适配的 Android 版本区间，对照你自己的 |
| 是否要求 Zygisk | 决定你要不要先开第三节那个开关 |
| 发布渠道是否可靠 | 只从开发者本人的发布页或可信的社区转载处拿 zip，来路不明的模块包里可以是任何代码 |

一次只装一个模块，重启确认正常后再装下一个。一次装五六个再重启，出了问题你都不知道是谁干的。

## 五、装坏了的兜底

模块导致开机卡住（卡在开机动画反复循环）是新手最常见的事故，处理方法有两种：电脑上敲一条 `magisk --remove-modules` 命令，或者用按键组合进 Magisk 安全模式 —— 具体操作和按键时机，见[开机循环怎么办.md](开机循环怎么办.md)。

应用内卸载 Magisk 本体的方法在[卸载教程与还原原系统.md](卸载教程与还原原系统.md)里，那篇同时讲了怎么还原系统分区。

## 六、应用提示「检测到 root」时

先给官方口径：官方 FAQ 明确写过，Magisk 本体已不再负责「隐藏 root」这件事。

应用设置里有两个与此相关的选项：

- **强制执行排除列表（Enforce DenyList）**：总开关；
- **配置排除列表（Configure DenyList）**：把应用加进列表。

把某个应用加入排除列表后，这个应用运行时所处的环境里看不到 Magisk 的修改。另外，自 28.0 版起，排除列表在不开 Zygisk 的情况下也能强制执行（官方更新日志）。

现实预期也要说清楚：部分应用（银行、支付类居多）的环境检测比排除列表覆盖得更深，加了列表也未必能运行；各应用的策略不同，以你设备上的实际表现为准。是否在这个方向上继续深入，由你自己权衡，本篇只写到官方功能为止。
