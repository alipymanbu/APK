# 开机循环怎么办

> 装完模块重启后卡在开机动画，是 Magisk 用户最常见的事故。本篇给出两条自救路径（adb 命令、安全模式按键组合），以及各自的适用条件。
> **相关文档**：[模块安装与管理.md](模块安装与管理.md) · [下载与安装教程.md](下载与安装教程.md)

## 一、先确认症状

开机循环的典型表现：开机动画走到一半或走完后又黑屏重来，反复不止。大多数情况是某个模块与你的系统版本不兼容，少数情况是两个模块互相冲突。系统本身没坏，处理方式就是**把模块全部禁用，让系统先用原样启动**，再回头清理。

两条路按顺序试，走通一条即可。

## 二、路径一：adb 命令删模块（推荐，需 USB 调试已开）

前提：你之前在开发者选项里打开过 USB 调试，电脑上有 platform-tools。

1. 手机连电脑，确认能识别：

   ```bash
   adb devices
   ```

2. 执行这条命令，删除全部模块并自动重启：

   ```bash
   adb shell magisk --remove-modules
   ```

3. 等设备自动重启，正常进系统后，到 Magisk 应用的模块页确认模块已清空。

## 三、路径二：Magisk 安全模式（无电脑也能救）

大多数现代安卓设备都支持开机时的按键组合进系统安全模式，Magisk 会抢在系统之前检测这个组合：检测到时，本次启动不加载任何模块，模块保留但被停用。

按键时机是这条路径的关键，官方 FAQ 特别指出**网上多数教程的时机说得太晚**：

1. 按电源键开机。
2. **在开机动画出现之前**就按住音量下键 —— 比你平时看到的教程里「动画出现时按住」要早几秒。
3. 按时机不同，结果分两种：
   - **动画一出现就松开**：只进 Magisk 安全模式（模块被禁用），系统正常模式启动，你手机里的其他设置不受影响；
   - **一直按到进系统**：Magisk 安全模式和系统安全模式同时激活，模块被禁用的同时系统也进安全模式，事后重启一次即可回到正常模式。

如果试了几次时机都踩不准，两种结果其实都能救活设备，只是进了系统安全模式后需要多重启一次。

## 四、恢复之后

进系统后按这个顺序清理：

1. 打开 Magisk 应用 → 模块页，确认所有模块已禁用或删除。
2. 回忆最近装过 / 更新过哪个模块，嫌疑最大。先单独装回其他正常模块，重启确认能开机，最后再处理问题模块。
3. 问题模块去它的发布页看有没有兼容你系统版本的更新；没有就弃用，别硬装。
4. 如果清完模块你还是想彻底重来，可以走应用内卸载再重装，见[卸载教程与还原原系统.md](卸载教程与还原原系统.md)。

## 五、下次怎么避免

- 一次只装一个模块，重启确认正常后再装下一个（这句话值得再说一遍）。
- 每次装模块前看它的适配说明：适配的 Android 版本、是否要求 Zygisk。
- 系统大版本更新（比如 Android 15 到 16）后，之前正常工作的模块也可能不兼容，更新系统后先别急着启用全部模块。
- 保持 USB 调试开启 —— 平时它只是个调试开关，出事时它是救援通道，路径一永远比路径二省事。
