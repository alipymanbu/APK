# 三星机型安装步骤

> 三星机型装 Magisk 与通用流程差异很大：要过 Knox 与 OEM Lock 两道检查、用 Odin 而不是 fastboot 刷入、首次安装必清数据。本篇把官方文档的三星专区按操作顺序整理成完整步骤。

## 一、动手前必须接受的两个事实

1. **Knox 熔断不可逆**。在这台设备上首次安装 Magisk 的那一刻，Knox 保修位被永久触发，任何手段都恢复不了。三星自家的安全相关功能与官方售后政策都会受影响。
2. **首次安装必须清空全部数据**（这次清数据不算在解锁 bootloader 那一次之内 —— 加上解锁那次，前后一共要清两次）。动手前把照片、通讯录、聊天记录、验证器全部备份。

接受不了这两条，就此打住；能接受，再往下走。

## 二、确认这台机器能不能解锁

三星机型比其他品牌多一道前置检查：下载模式（Download mode）里的两个状态值。查看方法：设置 → 电池和设备维护 → 维护模式，先开启维护模式，再用你机型的按键组合进下载模式（各机型组合不同，搜「你的型号 + download mode」即可）。

**OEM Lock** 的可能取值：

| 显示 | 含义 |
| --- | --- |
| ON (L) | 完全锁定，解不了 |
| ON (U) | bootloader 锁着，但已允许 OEM 解锁，可以继续 |
| OFF (U) | 已完全解锁 |

下载模式里**没有** OEM Lock 一栏的，多半是美版、加版等渠道限制机型，解不了。

**KnoxGuard（RMM）** 的可能取值：

| 显示 | 含义 |
| --- | --- |
| Active / Locked | 设备被运营商或保险公司远程锁定，装不了 Magisk |
| Prenormal | 临时锁定，设备累计开机满 168 小时后一般会自动解除 |
| Checking / Completed / Broken | 已解锁，可以继续 |

KnoxGuard 处于锁定状态时，无论 bootloader 什么状态都装不了 Magisk。

## 三、解锁 bootloader

1. 开发者选项里打开 **OEM 解锁（OEM unlocking）**。
2. 关机，按你机型的组合键进下载模式。
3. 按提示长按音量上键解锁 bootloader —— 数据当场清空并自动重启。
4. 走一遍开机初始化设置：所有步骤都跳过即可，但**全程保持联网**。
5. 重新打开开发者选项，确认 **OEM unlocking 选项存在且是灰色的** —— 灰色说明 KnoxGuard 没锁你的设备，这是好消息。
6. 到这一步，下载模式已经接受非官方镜像了。

## 四、准备固件与刷入工具

1. **下载完整官方固件包**（包含 AP / BL / CP / CSC 四个 tar 文件），固件版本要与手机当前系统一致。可以从三星官方服务器直取，常用工具：Frija、SamFirm.NET、samfirm.js（任选其一，均为社区维护的官方服务器下载工具，以各工具发布页为准）。
2. **解压固件**，把 `AP_[机型_版本].tar.md5` 这一个文件拷进手机存储（其他三个 tar 留在电脑上，刷入时要用）。
3. **电脑上装好刷入工具**：Windows 用 Odin3（需先装三星官方 USB 驱动），Linux 可用 Odin4 或 Heimdall。
4. 手机上装好 Magisk 应用（Magisk 安装文件资源见文首提示块）。

## 五、修补 AP 文件并刷入

1. 打开 Magisk 应用 → Magisk 卡片 → **安装**。
2. 机型没有 boot ramdisk 的，勾选 **Recovery Mode**。
3. 方式选**选择并修补一个文件**，选中刚才拷进来的 AP tar 文件，开始安装。
4. 修补完成后，用 adb 把产物拉回电脑：

   ```bash
   adb pull /sdcard/Download/magisk_patched_xxxxx.tar
   ```

   **不要用 MTP（文件传输模式）把这个文件拖回电脑** —— MTP 传大文件有损坏的历史案例，官方文档特别点名。

5. 手机重启进下载模式，电脑打开 Odin：
   - `AP` 槽选修补过的 `magisk_patched_xxxxx.tar`；
   - `BL`、`CP`、`CSC` 三个槽选原固件解压出来的对应文件 —— **注意是 `CSC`，不是 `HOME_CSC`**，因为首次安装要靠它触发清数据。
6. 点开始，刷完设备自动重启。开机过程中如提示恢复出厂，**同意执行**。
7. 没有 boot ramdisk 的机型，重启后先进一次 recovery 模式启用 Magisk，再进系统（原因见官方安装文档「Magisk in Recovery」一节，入口在[下载与安装教程.md](下载与安装教程.md)第三节）。
8. 安装并打开 Magisk 应用，按提示完成附加设置，等待自动重启。

完成后打开应用，Magisk 卡片显示出版本号即为成功。之后的模块安装、升级日常，与通用流程一致，分别见[模块安装与管理.md](模块安装与管理.md)和[更新通道与升级方法.md](更新通道与升级方法.md)。

## 六、之后怎么升级系统

root 后的三星机型**收不到可用的 OTA**。升级方式是手动来一遍：

1. 下载新版本完整固件；
2. 把新的 `AP` tar 在 Magisk 应用里重新修补；
3. Odin 刷入时流程同第五节，**唯一差别：这次用 `HOME_CSC`，不用 `CSC`** —— 升级不清数据，首次安装才清。

## 七、两条铁律

- **绝不要**把 `boot`、`init_boot`、`recovery`、`vbmeta` 任一分区单独刷回原版镜像 —— 大概率直接变砖，唯一的恢复路是全量 Odin 救回（连带清空全部数据）。
- **绝不要**直接刷原版 `AP` 文件升级 —— 想升级就按第六节重新修补。
