## 一、安装前先知道的几件事

MusicKiller 是一款安卓端听歌应用，打开就能搜歌播放，不需要注册账号，也不绑定手机号，界面上没有开屏广告和弹窗。曲库覆盖流行、摇滚、民谣、古典、爵士等风格，播放时可以在四档音质之间切换。部分应用市场把它收录为「音乐终结者」，指的就是同一个应用（包名 `xyz.jdynb.music`），看到两个名字不必疑惑。

本篇以网盘里的 1.0 版安装包为准：包名 `xyz.jdynb.music`，安装包约 13.5 MB。系统版本方面，收录信息标注为安卓 5.2 以上，安装时以手机实际提示为准；近年发售的机型一般都能装。

## 二、获取安装包

安装包不在应用商店里，统一从网盘获取：

1. 点开 [MusicKiller 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1fa7ce1eecea)，进入分享页；
2. 勾选里面的 APK 文件，点「转存」保存到自己的夸克网盘；
3. 打开手机上的夸克 App，在「我的网盘」里找到刚转存的 APK，点「下载」；
4. 下载完成后在通知栏或夸克 App 的下载列表里点开 APK，进入安装。

建议先转存再下载：直接点分享页里的文件有时只能预览，转存到自己网盘后才能拿到完整文件。

## 三、安装步骤

1. **允许安装未知来源应用**：点开 APK 时系统会提示「禁止安装未知来源」，按提示跳转到设置页，允许夸克 App（或你的文件管理器）「安装未知应用」；
2. **确认安装**：返回安装界面，点「安装」，等进度条走完；
3. **授予存储权限**：首次打开 MusicKiller 会请求存储（音乐/文件）权限，选「允许」——扫描本地音乐、保存下载歌曲都依赖它；
4. **进入首页**：不需要登录，直接就能用。

## 四、首次启动后从哪开始

首页分推荐、歌单、排行榜、歌手几个板块，可以直接浏览，也可以点顶部的搜索框输入歌名。第一次用建议按这个顺序走一遍：

1. 搜索框里输入一首你想听的歌，点结果直接播放；
2. 在播放页点音质选项，感受各档音质的差别；
3. 点「收藏」把这首歌加进喜欢，之后在歌单里能找到。

具体每一步的界面操作，见 [搜歌与播放操作.md](搜歌与播放操作.md)；想把歌缓存到本地离线听，见 [歌单与离线缓存.md](歌单与离线缓存.md)。

## 五、安装环节的常见问题

| 现象 | 处理办法 |
| --- | --- |
| 提示「解析包错误」「安装包损坏」 | 多半是下载不完整，回网盘重新下载一遍；核对文件 MD5 是否为 `3207383AA54195F95A77514426A42B15` |
| 找不到「允许未知来源」入口 | 不同品牌路径不同：小米在「设置 - 隐私保护 - 特殊权限」，华为在「设置 - 安全 - 更多安全设置」，OPPO/vivo 在「设置 - 安全 - 安装外部来源应用」，都在安装弹窗里点跳转也能直达 |
| 安装后点开闪退 | 确认系统版本满足要求；重启手机再试一次，仍闪退见 [常见问题排查.md](常见问题排查.md) |
| 装完桌面上没有图标 | 部分桌面会把新应用收进「推荐文件夹」，从应用列表里长按图标拖出来即可 |

安装与启动都正常之后，日常使用基本不会再遇到门槛；用到一半碰到的问题，多数在 [常见问题排查.md](常见问题排查.md) 里有对应的处理办法。
