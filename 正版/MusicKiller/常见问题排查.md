# MusicKiller 常见问题排查

> 搜不到歌、下载中断、歌单丢失、播放卡顿——MusicKiller 用起来最常碰到的几类问题，本篇按现象给出排查顺序。

## 一、搜索结果显示「无资源」

按顺序试：

1. **检查关键词**：有没有错别字、有没有用简称。曲库按歌名匹配，搜「周董的歌」当然什么都没有；
2. **换搜索维度**：歌名搜不到就换歌手名或专辑名，从专辑页里翻目标曲目；
3. **换个写法再搜**：部分歌曲因版权原因只对特定关键词有结果，全名、带专辑或歌手前缀的写法各试一次。

三招都试过仍无结果，大概率是曲库确实没有这首歌。这种歌不值得反复重试，过段时间曲库更新后再搜一次即可。

## 二、批量下载频繁中断，或下载完放不出来

**中断**，先查网络：

- 切到 WiFi 或信号好的移动网络再下；
- 关掉后台占带宽的其他应用（视频、下载工具），减少波动；
- 一次少勾几首，分批下比一次下几十首稳。

**下载完无法播放**，多半是音质兼容问题：

- 进「设置 - 下载设置」，把下载音质从无损换成标准档，重新下载这首歌；
- 部分设备对高音质文件兼容性差，标准音质基本都能放；
- 如果标准档也放不出来，删掉这个文件重新下载一次——文件在下载中断时被当成完整文件留存，就会出现这种「下载完成却损坏」的情况。

## 三、收藏的歌单找不到了，或歌显示「已失效」

1. 进「我的 - 收藏」板块，按「歌单」分类筛选，先确认是不是误操作移除了收藏——这是最常见的原因；
2. 歌单还在但里面个别歌显示「已失效」：是那首歌在曲库侧发生了变动，不是你删错了；
3. 已失效的歌重新搜一次歌名，多数能找到替代条目，重新收藏进歌单即可。

歌单数据保存在设备上，卸载重装前先想清楚；重要歌单建议记一份歌名清单在备忘录里，出问题能快速恢复。

## 四、播放卡顿、有杂音

分在线和离线两种情况：

| 场景 | 排查顺序 |
| --- | --- |
| 在线播放卡顿 | ① 切更稳的网络（WiFi 优先）；② 关掉后台占带宽的应用；③ 把播放音质临时降一档，卡顿会明显缓解 |
| 离线播放有杂音 / 卡顿 | ① 删掉这首歌的本地文件重新下载；② 仍不行就换低一档音质下载 |
| 全部歌都卡 | ① 清一下后台再试；② 重启 App；③ 重启手机；④ 检查手机剩余存储是否过低 |

卡顿只出现在某一首歌上，基本是该文件的音质或下载问题；所有歌都卡，才需要往设备和网络方向查。
