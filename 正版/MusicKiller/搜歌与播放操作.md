## 一、四个浏览板块，先逛再搜

首页底部导航分几个板块，不确定听什么的时候从这里入手比搜索更省事：

| 板块 | 适合的场景 |
| --- | --- |
| 推荐 | 没有明确目标，随便听听，按听歌习惯给的歌单 |
| 歌单 | 按主题、心情、场景、年代、曲风细分的一批歌，比如学习、跑步、睡前、怀旧 |
| 排行榜 | 看当下热度最高的歌；内置热歌榜、新歌榜、飙升榜等几个榜单，追新歌看这里 |
| 歌手 | 直奔某位歌手，把他/她的歌一次翻完 |

这些板块的内容会随曲库更新，你听过的歌会影响推荐结果。

## 二、搜索：换着关键词试

点顶部搜索框，输入歌名即可查找，支持按歌名、歌手、专辑、歌词片段检索。四个实用习惯：

1. **歌名记不全时，改搜歌手名或专辑名**，从结果里翻目标曲目，比猜关键词快；
2. **只记得一句歌词时，把那句歌词当关键词搜**——按歌词检索对想不起歌名的场合特别管用；
3. **别用简称和错别字**——搜索显示「无资源」很多时候是关键词不准，不是曲库没有；
4. 个别歌曲因版权原因只对特定关键词有结果，换一个写法（全名、带专辑前缀）往往就能搜到。

搜到之后点一下就直接播放，不用先加歌单。搜不到、或结果里点不开的情况，处理思路见 [常见问题排查.md](常见问题排查.md) 第一节。

## 三、四档音质怎么选

播放页里可以切换音质，共有四档，都免费可选，不需要会员。各收录页列出的档位为 128k / 192k / 320k 的 MP3 与 FLAC 无损（2000k），具体档位名称与数值以你手机上软件内显示为准：

| 你的情况 | 建议档位 |
| --- | --- |
| 用流量听，只想省流量 | 128k，听感差别对大多数人可接受 |
| 平时 WiFi / 5G 随便听 | 192k 或 320k，流量与音质的平衡点 |
| 用耳机认真听、想听细节 | FLAC 无损，代价是单首文件更大、缓存更占空间 |
| 蓝牙音箱 / 车机播放 | 320k 即可，蓝牙传输本身就会压缩，无损优势发挥不出来 |

两个注意点：

- 档位越高，**在线播放消耗的流量和缓存占的空间都按倍数涨**——无损单曲体积是 128k 的十几倍，手机存储紧张的话别全开无损；
- 个别设备对无损文件的兼容性差，如果下载后的歌放不出来，先把下载音质换回标准档再试（详见 [常见问题排查.md](常见问题排查.md) 第二节）。

## 四、播放时的实用操作

- **滚动歌词**：播放页可以在歌曲界面与歌词页之间切换，歌词跟着进度滚动；
- **后台播放**：切到别的 App 或熄屏，歌不会停，锁屏后照常续播；
- **锁屏控制**：锁屏界面上可以直接切歌、暂停、调进度，不用解锁进 App；
- **定时关闭**：设定时长后自动停止播放，睡前听歌不怕播一整夜；
- **播放队列**：一次播放的队列可以自己调整，长按播放按钮能进队列管理；
- **播放历史**：听过的歌自动留记录，也支持启动后接着播上次的历史歌曲，昨天随手点开的那首能翻回来。

另外两个批量技巧：在歌曲列表里**长按进入多选**，批量加减歌、批量下载；听歌途中想换歌不必退出播放页，在播放界面直接翻找即可。

听上瘾之后一般会想做两件事：把常听的攒成自己的歌单，以及把歌缓存下来离线听——这两件事的完整做法在 [歌单与离线缓存.md](歌单与离线缓存.md)。
