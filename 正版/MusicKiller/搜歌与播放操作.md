## 一、四个浏览板块，先逛再搜

首页底部导航分几个板块，不确定听什么的时候从这里入手比搜索更省事：

| 板块 | 适合的场景 |
| --- | --- |
| 推荐 | 没有明确目标，随便听听，按听歌习惯给的歌单 |
| 歌单 | 按曲风、心情、场景找一批歌，比如学习、跑步、睡前 |
| 排行榜 | 看当下热度最高的歌，新歌上得快 |
| 歌手 | 直奔某位歌手，把他/她的歌一次翻完 |

这些板块的内容会随曲库更新，你听过的歌会影响推荐结果。

## 二、搜索：换着关键词试

点顶部搜索框，输入歌名即可查找。三个实用习惯：

1. **歌名记不全时，改搜歌手名或专辑名**，从结果里翻目标曲目，比猜关键词快；
2. **别用简称和错别字**——搜索显示「无资源」很多时候是关键词不准，不是曲库没有；
3. 个别歌曲因版权原因只对特定关键词有结果，换一个写法（全名、带专辑前缀）往往就能搜到。

搜到之后点一下就直接播放，不用先加歌单。搜不到、或结果里点不开的情况，处理思路见 [常见问题排查.md](常见问题排查.md) 第一节。

## 三、四档音质怎么选

播放页里可以切换音质，共有四档，从普通音质到无损（FLAC）都免费可选，不需要会员。没有官方标称的码率数字，选择时按这个原则就够：

| 你的情况 | 建议档位 |
| --- | --- |
| 用流量听，只想省流量 | 最低档，听感差别对大多数人可接受 |
| 平时 WiFi / 5G 随便听 | 中间档，流量与音质的平衡点 |
| 用耳机认真听、想听细节 | 无损（FLAC），代价是单首文件更大、缓存更占空间 |
| 蓝牙音箱 / 车机播放 | 中间档即可，蓝牙传输本身就会压缩，无损优势发挥不出来 |

两个注意点：

- 档位越高，**在线播放消耗的流量和缓存占的空间都按倍数涨**，手机存储紧张的话别全开无损；
- 个别设备对无损文件的兼容性差，如果下载后的歌放不出来，先把下载音质换回标准档再试（详见 [常见问题排查.md](常见问题排查.md) 第二节）。

## 四、播放时的实用操作

- **滚动歌词**：播放页同步显示歌词，跟着进度滚动；
- **后台播放**：切到别的 App 或熄屏，歌不会停；
- **锁屏控制**：锁屏界面上可以直接切歌、暂停、调进度，不用解锁进 App；
- **播放历史**：听过的歌自动留记录，昨天随手点开的那首能翻回来。

听上瘾之后一般会想做两件事：把常听的攒成自己的歌单，以及把歌缓存下来离线听——这两件事的完整做法在 [歌单与离线缓存.md](歌单与离线缓存.md)。
