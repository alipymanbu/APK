## 一、先对号入座

ShizuWall 用不起来，多数卡在 Shizuku 这一环。Shizuku 官方手册明确说：许多厂商对安卓系统做了修改，会造成 Shizuku 无法正常工作。先按现象对号：

| 现象 | 直接看 |
| --- | --- |
| 一直显示「正在搜索配对服务」 | 第二节 |
| 点「输入配对码」后立刻提示失败 | 第三节 |
| 能启动但提示 adb 权限受限 | 第四节 |
| 用着用着 Shizuku 自己停了 | 第五节 |
| 重启手机后 Shizuku 又要重新启动 | 第六节 |

以下内容整理自 Shizuku 官方用户手册（[shizuku.rikka.app](https://shizuku.rikka.app/zh-hans/guide/setup/)），机型开关以手册当时内容为准；激活流程本身见 [Shizuku激活与授权步骤.md](Shizuku激活与授权步骤.md)。

## 二、一直显示「正在搜索配对服务」

官方手册给的解法：允许 Shizuku 在后台运行 —— 搜索配对服务需要访问本地网络，而许多厂商会在应用退到后台（不可见）后立刻禁止它访问网络。

具体做法：到系统设置里找到 Shizuku 的电池/后台策略，改为「无限制/允许后台运行」；不同品牌入口不同，可按机型搜「允许应用后台运行」。配对过程中不要切走 Shizuku，让它停在前台，等通知栏出现配对服务的通知，从通知里填码。

## 三、点「输入配对码」后立刻提示失败

官方手册单列了一个机型：MIUI（小米、POCO）—— 到系统设置的「通知管理 → 通知显示设置」，把通知样式切换为「原生样式」，再重新配对。

其他机型遇到同样报错，先确认已把通知权限授予 Shizuku（配对码要从 Shizuku 的通知里填），再重试。

## 四、提示 adb 权限受限

能启动、但 Shizuku 提示 adb 权限受限，是厂商在开发者选项里额外设了限制。官方手册给出的开关：

| 系统 | 开关位置 |
| --- | --- |
| MIUI（小米、POCO） | 开发者选项里开启「USB 调试（安全设置）」—— 注意它和「USB 调试」是两个分开的选项 |
| ColorOS（OPPO、OnePlus） | 开发者选项里关闭「权限监控」 |
| Flyme（魅族） | 开发者选项里关闭「Flyme 支付保护」 |

## 五、Shizuku 随机停止

无 root 设备上系统会为省电清理后台，Shizuku 被杀后就「未运行」了。官方手册对所有设备给四条：

- 保证 Shizuku 可以在后台运行；
- 不要关闭「USB 调试」及「开发者选项」；
- 在开发者选项里把 USB 使用模式改为「仅充电」（Android 8 是「选择 USB 配置 → 仅充电」；Android 9 及以上是「默认 USB 配置 → 不进行数据传输」）；
- Android 11 及以上，启用「停用 adb 授权超时功能」。

官方手册还单列了三个机型的注意点：

| 系统 | 注意点 |
| --- | --- |
| EMUI（华为） | 开发者选项里开启「"仅充电"模式下允许 ADB 调试」 |
| MIUI（小米、POCO） | 不要用「手机管家」的扫描功能 —— 它会禁用开发者选项 |
| Sony | 不要点连接 USB 后弹出的对话框，那会改变 USB 使用模式 |

被杀掉了就重新点一次「启动」即可恢复；重启之后想少动手，见 [重启后规则失效怎么办.md](重启后规则失效怎么办.md)。

## 六、重启后要重来吗

只重做「启动」这一下：官方手册写明，无线调试与连接电脑两种方式由于系统限制，每次重新启动后都需要再次执行启动步骤；配对只需一次，不用重来。

重启后的完整处理（自启、手动、自动化三条路）见 [重启后规则失效怎么办.md](重启后规则失效怎么办.md)；更多使用疑问见 [常见问题解答.md](常见问题解答.md)。
