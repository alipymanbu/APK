# FL Studio Mobile 常见问题与解决方法

> 本篇汇总 FL Studio Mobile 在安卓上最常见的几类问题：装不上、打不开、声音延迟、MIDI 键盘连不上、工程文件找不到。装好之后的使用问题也可以直接翻对应篇章：[界面与工作流程入门.md](界面与工作流程入门.md) · [乐器与效果器清单.md](乐器与效果器清单.md) · [导出与项目互通.md](导出与项目互通.md)。

## 一、安装时提示"未知来源"或被拦截

这是系统安全机制在拦，不是包有问题。到「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给你用来打开 APK 的那个文件管理器授权，再回去重新安装。装完建议把授权关回去。

## 二、装完打不开或闪退

按顺序排查：

1. **系统版本过低**：这份包要求安卓 5.0 及以上（以官方页面为准），低于这个版本装上也可能打不开；
2. **存储不够**：安装解压需要额外空间，清出几个 GB 再试；
3. **下载不完整**：重新下载一遍，文件大小应与安装包标注一致（244.35 MB），对不上就是没下完整；
4. **老旧机型性能不足**：多轨加效果的项目对处理器有要求，可以先开新工程试一条空轨能不能正常出声。

## 三、按下去声音慢半拍（延迟）

官方明确说明：触屏到出声的延迟取决于设备本身。延迟明显时可以：

- 关掉后台占资源的其他应用；
- 减少同时发声的轨道数和效果器数量，尤其少叠几个混响；
- 录音时接受监听延迟、录完再对齐，是移动设备的常规做法；
- 换更新的设备是最直接的解法，处理器越快能同时干的事越多。

## 四、MIDI 键盘连不上 / 多了一个"位置"权限申请

外接 MIDI 键盘（蓝牙 LE 类）在安卓上必须拿到**位置权限**才能扫描蓝牙设备——这是安卓系统层的强制要求，官方说明只把蓝牙用于连接 MIDI 键盘、不会用它定位。所以看到申请"位置信息"时放行即可，键盘才能被搜到。有线或 USB 类连接则不涉及这个权限。

## 五、工程文件在哪、换机怎么搬

- **位置**：安卓 11 及以上，工程、录音、导出音频都在 `Android/data/com.imageline.FLM/files`，系统文件管理器默认看不到这个目录；
- **日常管理**：直接用应用内的 SONGS 页，导入文件也从这里进，不用去文件管理器翻；
- **换机 / 重装**：先用[导出与项目互通.md](导出与项目互通.md)里的同网络直传或云分享把工程挪走；
- **记住一条**：卸载应用 = 私有目录里的工程一起被删，删之前先把要留的东西搬出去。

## 六、导出的音频找不到了

导出完成的文件同样落在应用的私有目录里。最省事的确认方式是回到 SONGS 页看文件列表，或直接用系统"分享"把成品发到微信、邮箱等地方，绕开文件目录的问题。

以上手段都试过仍解决不了的，可以到官方支持页面（`https://support.image-line.com/`）检索对应关键词，或去官方论坛发帖，附上设备型号和系统版本会更容易得到答复。
