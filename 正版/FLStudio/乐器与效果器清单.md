## 一、随机附带的 8 个乐器

以下乐器全部随应用附带，不需要额外购买：

| 乐器 | 类型 | 你用它做什么 |
| --- | --- | --- |
| 3x Osc | 减法合成器 | 三个振荡器的经典合成器，做主音、贝斯都行，桌面版 FL Studio 同名插件的预置音色可直接用 |
| DirectWave | 采样播放器 | 钢琴、弦乐、吉他这类"实录感"音色靠它加载，也支持装自己的采样 |
| GMS | 混合合成器 | 来自 FL Studio 桌面版 Groove Machine 的多音色合成器，电子味浓 |
| MiniSynth | 合成器 | 资源占用低、自带大量预置音色，用户社区里还有成千上万的补充音色 |
| Slicer | 循环切片器 | 把鼓循环或旋律循环切片，在钢琴卷帘里逐片触发重新编排 |
| SoundFont Player | 音色库播放器 | 加载 `.sf2` 格式的 SoundFont 音色库，网上免费资源很多 |
| SuperSaw | 合成器 | 快速做出电子舞曲风格的宽铺底和主音 |
| Transistor Bass | 单音贝斯合成器 | 做 acid 风格的贝斯线和共鸣主音 |

## 二、随机附带的效果器

官方口径是 30 个以上，同样全部随应用附带。按用途分组列给你：

- **动态与塑形**：压缩器（Compressor）、限制器（Limiter）、失真（Distortion）、波形成形（Waveshaper）
- **空间与调制**：混响（Reverb）、延迟（Delay）、合唱（Chorus）、镶边（Flanger）、移相（Phaser）、立体声扩展（Stereo Spreader）、磁带停止（Tape Stop）、抖动与晃动（Wow and Flutter）
- **频率处理**：参数均衡器、图形均衡器、高通 / 低通 / 带通滤波器、共振峰滤波器（Vox）
- **修音与分析**：自动音高修正（Auto Pitch）、自动闪避（Autoduck）、调音器（Tuner，吉他 / 人声 / 乐器）、分析器（Analyzer，看频谱 / 波形 / 响度 / 立体声像）

录人声时常用的组合是：Auto Pitch 修音高 + 压缩器稳动态 + 混响铺空间，三件套挂一条人声轨就够起步。

## 三、随附的音色内容

装完就能用的素材包括：

- **鼓组采样**：底鼓（Kicks）、军鼓（Snares）、踩镲与吊镲（Hats / 铙钹）、嗵鼓（Toms）、打击乐（Percussion）、上升音效（Risers）、音效（SFX）
- **DirectWave 乐器库**：吉他、键盘、管弦乐、贝斯、合成器键盘 / 主音 / 铺底、切片、鼓与鼓组、效果器音色
- **预置音色包**：MiniSynth 按贝斯 / 琴键 / 主音 / 铺底 / 音效 / 合成器分类；SuperSaw 按琶音 / 贝斯 / 钟声 / 音效 / 主音 / 铺底 / 序列分类

## 四、应用内商店：买什么、不买行不行

应用内商店主要卖 DirectWave 的扩展采样音色包。**不买不影响任何核心功能**——乐器、效果器、鼓组采样都是随机附带的，而且你可以把自己找的音频文件或 SoundFont 装进 DirectWave 和 SoundFont Player 里用，不一定非要花钱补音色。

另外有一条官方给的免费路子：用 Image-Line 账号注册应用（应用内 Help → Users & support forums），官方论坛的用户版块里会放免费的 DirectWave 内容。

音色挂到轨道上之后怎么导出成品，见[导出与项目互通.md](导出与项目互通.md)；安装或加载音色遇到问题，翻[常见问题与解决方法.md](常见问题与解决方法.md)。
