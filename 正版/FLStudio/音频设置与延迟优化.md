## 一、延迟从哪来、有多大

你在键盘上按下一个音，到喇叭里听到它，中间隔的那段时间就是延迟。官方手册给的口径是：移动设备上的这段延迟通常在 **40~200 毫秒**之间，具体取决于设备本身。延迟大的时候你会觉得"手指按下去，声音慢半拍"，这是硬件特性，不是设置错了——但设置可以在一定程度上改善它。

## 二、把响应调快：两个开关

入口：首页按钮 → Settings → Audio。

**1. Sound mode（声音模式，安卓专属）**——音频引擎的三档选择：

| 档位 | 效果 |
| --- | --- |
| Fast（快） | 延迟最低，但只有性能跟得上的设备才扛得住 |
| Safe（安全） | 减少爆音和杂音，延迟增加一些 |
| Ultra safe（超安全） | 延迟最长，但设备兼容性最好 |

排查爆音、卡顿时就从 Fast 往下调；追求手感就从 Safe 往上调，出现杂音再退回来。

**2. Enable low latency mode（启用低延迟模式）**——尽量压到最低延迟、改善触屏响应；代价是部分设备上会出现 CPU 过载或爆音。开了之后弹几下试试，有杂音就关掉。

## 三、录音前做延迟校准（Calibrate）

**为什么要校准**：你跟着喇叭里的声音唱歌或弹琴时，实际比工程里的事件慢了 40~200 毫秒，直接录下来的轨会整体拖后一截。延迟补偿的作用就是把录到的音频往前对齐。

操作路径：Settings → Audio → 打开 **Enable audio recording latency compensation** → 点 **Calibrate**。校准的原理是让应用录下自己发出的一声"哔"，量出从发声到被麦克风收到的往返延迟。

**用内置麦克风校准**（官方步骤）：

1. 找个安静的地方；
2. 拔掉耳机；
3. 音量开到 80~100%；
4. 点 Calibrate。

**用外接麦克风校准**（官方步骤）：

1. 找个安静的地方；
2. 音量开到 50% 左右；
3. 把麦克风凑近扬声器，或贴住耳机单元；
4. 点 Calibrate。

**校准失败**多半是那声"哔"没被收到，按这个清单排查：音量调大、校准过程中别碰别挪设备、确认麦克风没被手机壳挡住、环境尽量安静（官方原话：在公交车上不行）、用了多输入声卡的话确认输入选择和麦克风对得上。

iOS 设备不需要这一步（官方注明）。

## 四、录音输入与质量

也在 Settings → Audio 里：

- **Recording Source（录音来源）**：多麦克风设备可以选立体声或单独的左 / 右声道——有的手机有一颗麦克风是专门做降噪的、拾音反而差，两个都试试。外接声卡（安卓经 OTG 转接）后这里会多出输入选项，没有明确标注时就逐个试；
- **Use 32 Bit format for recording audio（用 32 位格式录音）**：系统支持时可选，把录音从 16 位 WAV 换成 32 位浮点 WAV，文件更大。
