## 一、导出成品音频：五种格式怎么选

从工程菜单里选渲染 / 导出（不同版本入口名称略有差异，以你手上的实际菜单为准），可以整曲导出，也可以只导出选中的片段：

| 格式 | 适合场景 |
| --- | --- |
| WAV | 无损存档、继续进电脑端处理的首选，文件大 |
| MP3 | 发给朋友听、传到手机里当成品，体积小 |
| AAC | 兼容性好的有损格式（是否可用取决于系统） |
| FLAC | 想要无损又要省空间的折中选择 |
| MIDI | 导出的是音符数据不是声音，单轨或多轨都支持，拿去别的软件里重新配音色 |

拿不准就选 WAV 存档 + MP3 分享，两份都出。

## 二、工程文件与多设备互通

工程以 `.flm` 格式保存，安卓与 iOS 设备上的工程互通。换设备有两条路：

1. **同网络直传**：两台设备连同一个 Wi-Fi，在应用的文件页里互相分享工程，不经过云端，速度取决于局域网；
2. **云分享**：把工程传到云上再从另一台设备取回，适合两台设备不在一个网络里的情况。

换机或重装前务必走一遍上面的流程——应用卸载后私有目录里的工程会被一并删除，这一点在[下载与安装教程.md](下载与安装教程.md)里也强调过。

## 三、接到电脑上的 FL Studio 桌面版

这是这套应用最常用的一条进阶路线：

- 手机上做的工程可以导出为 `.flp` 工程文件，在电脑上的 FL Studio 桌面版里打开继续做——补轨道、上更重的效果、精修混音都行；
- 桌面版（单独出售）本身内置了 FL Studio Mobile 插件版，界面和手机版一致，你在电脑上也能用同一套操作习惯；
- 反过来，桌面版同名乐器（如 3x Osc）的预置音色可以直接在移动版里用。

版本越新互通越顺，导出 `.flp` 前把两端都更新到较新版本，遇到打不开的情况以官方说明为准。

## 四、给别的软件用：MIDI 导入导出

如果你用的是电脑上其他的编曲软件，可以把移动版的音符导出成 MIDI 文件（单轨或多轨）带过去；同样也能导入现成的 MIDI 文件当作素材。MIDI 只包含"弹了什么音"，不包含音色，导过去之后音色要在目标软件里重新配。
