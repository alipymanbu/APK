## 一、导出成品音频：五种格式怎么选

从工程菜单里选渲染 / 导出（不同版本入口名称略有差异，以你手上的实际菜单为准），可以整曲导出，也可以只导出选中的片段：

| 格式 | 适合场景 |
| --- | --- |
| WAV | 无损存档、继续进电脑端处理的首选，文件大 |
| MP3 | 发给朋友听、传到手机里当成品，体积小 |
| AAC | 兼容性好的有损格式（是否可用取决于系统） |
| FLAC | 想要无损又要省空间的折中选择 |
| MIDI | 导出的是音符数据不是声音，单轨或多轨都支持，拿去别的软件里重新配音色 |

拿不准就选 WAV 存档 + MP3 分享，两份都出。

保存 / 渲染对话框里还有几个勾选项，都会直接影响成品：

- **Normalize level（归一化电平）**：把最大峰值顶到 100%，成品响度拉满；
- **High quality（高质量）**：WAV 用 32 位、FLAC 用 24 位、MP3 和 AAC 用 320 kbps（不开则是 16 位 / 192 kbps）；
- **Trim initial silence（修剪开头静音）**：把渲染开头的一段无声剪掉；
- **Render to last bar（渲染到最后一个小节）**：在最后一小节末尾停住，避免混响之类的长尾把文件拖得很长。

## 二、分轨导出（Stems）：给别的软件继续做

保存时勾选 **Split mixer tracks（拆分混音器轨道）**，每条 Playlist 轨会各自出一份独立音频文件，也就是常说的分轨（Stems）。用途：

- 拿到别的 DAW（包括 FL Studio 桌面版）里继续混；
- 发给没装同款音色的合作者，对方不用纠结工程缺什么插件；
- 把分轨再导回原工程、把原始轨静音，给设备省 CPU。

勾 **Enable master effects（启用主效果）** 会让分轨带上总线上挂的效果；去别的软件混音时通常不勾，灵活性更高。分轨文件存放在 My Files → My Tracks 下，按「工程名 - 格式」命名。

## 三、工程文件与多设备互通

工程以 `.flm` 格式保存，安卓与 iOS 设备上的工程互通。换设备有三条路：

1. **同网络直传**：两台设备连同一个 Wi-Fi，在应用的 SHARE 页里互相分享工程，不经过云端，速度取决于局域网；
2. **云分享**：同样在 SHARE 页，把工程传到云上再从另一台设备取回，适合两台设备不在一个网络里的情况；
3. **SEND（发送）**：保存对话框里的 SEND 按钮，把当前工程或成品经邮件、微信等任何支持文件分享的应用发出去——注意它和 SHARE 页是两回事，SEND 走的是系统分享，SHARE 是两套 FL Studio Mobile 之间的直传。

换机或重装前务必走一遍上面的流程——应用卸载后私有目录里的工程会被一并删除，这一点在[下载与安装教程.md](下载与安装教程.md)里也强调过。

## 四、接到电脑上的 FL Studio 桌面版

这是这套应用最常用的一条进阶路线：

- 手机上做的工程可以导出为 `.flp` 工程文件，在电脑上的 FL Studio 桌面版里打开继续做——补轨道、上更重的效果、精修混音都行；
- 桌面版（单独出售）本身内置了 FL Studio Mobile 插件版，界面和手机版一致，你在电脑上也能用同一套操作习惯；
- 反过来，桌面版同名乐器（如 3x Osc）的预置音色可以直接在移动版里用。

版本越新互通越顺，导出 `.flp` 前把两端都更新到较新版本，遇到打不开的情况以官方说明为准。

## 五、给别的软件用：MIDI 导入导出

如果你用的是电脑上其他的编曲软件，可以把移动版的音符导出成 MIDI 文件（单轨或多轨）带过去；同样也能导入现成的 MIDI 文件当作素材——长按轨道图标就能把当前轨另存为 MIDI。MIDI 只包含"弹了什么音"，不包含音色，导过去之后音色要在目标软件里重新配。
