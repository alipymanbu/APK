## 一、安装包基本信息

DuckDuckGo 是 DuckDuckGo 公司官方出品的安卓浏览器，浏览器、搜索与隐私防护功能都在同一个 App 里。下面是本文对应安装包的核对信息，与你从应用商店看到的最新版本号可能不同：

| 项目 | 值 |
| --- | --- |
| 应用名称 | DuckDuckGo Private Browser |
| 版本 | 5.274.1 |
| 包名 | com.duckduckgo.mobile.android |
| 安装包大小 | 约 116 MB |
| MD5 | CEBAED3D617AB2639C4AE01A1BD7AAAB |

核对 MD5 的方法：安装前用文件校验工具算一遍安装包的 MD5，与表里一致说明文件完整未损坏；不一致就重新下载一份。

## 二、安装前的准备

1. 确认手机系统版本满足要求（以官方商店页面当时显示为准）。
2. 允许安装来自应用商店之外的应用：安卓会按「你从哪个应用发起安装」分别授权。路径一般是 **设置 → 应用 → 特殊应用权限 → 安装未知应用**，找到你用来打开安装包的那个应用（文件管理器或浏览器），打开它的「允许安装未知应用」开关。
3. 部分机型的企业管控（如公司账号管理的设备）会直接禁止侧载安装，这种情况只能改用应用商店渠道。

## 三、安装步骤

1. 从 [DuckDuckGo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1e39a3e5f087)获取安装包，转存到自己的网盘后下载 APK 文件到手机存储。
2. 用文件管理器打开下载好的 APK，点「安装」。
3. 若系统提示「来自未知来源」，回到上一步把对应应用的安装权限打开再继续。
4. 安装完成后点「打开」，首次启动会有一页隐私功能介绍，直接按提示进入主界面即可。

装好后建议顺手把浏览器设为系统默认，这样点开其他应用里的链接会直接用它打开。

## 四、首次启动建议做的三件事

1. **设为默认浏览器**：进 **系统设置 → 应用 → 默认应用 → 浏览器应用**，选 DuckDuckGo；也可以在它自己的 **设置 → 默认浏览器** 里一键跳转。
2. **导入旧浏览器的书签和密码**：在 **设置 → 导入** 里按提示操作，从 Chrome 等浏览器把书签、密码迁过来，不用手动一条条抄。多设备之间的持续同步见 [书签密码同步与备份.md](书签密码同步与备份.md)。
3. **确认各项保护已开启**：默认状态下追踪拦截、强制加密等都是开着的，可以在 **设置 → 隐私保护** 里逐项核对，各项的作用见 [隐私保护功能一览.md](隐私保护功能一览.md)。

## 五、安装环节的常见问题

- **点安装没反应或按钮是灰的**：多是「安装未知应用」权限没给对应用——注意授权对象是「你用来打开 APK 的那个应用」，不是 DuckDuckGo 本身。
- **提示「应用未安装」**：先确认安装包完整（核对上面表格里的 MD5），再检查手机剩余存储是否够用；如果手机里已经装过同包名的版本且系统拒绝覆盖，可以先卸载旧版再装（卸载会清掉旧版本地书签和登录状态，重要数据先按同步那篇做一次备份）。
- **安装后图标不见了**：部分桌面启动器会延迟刷新，重启一次手机即可。
