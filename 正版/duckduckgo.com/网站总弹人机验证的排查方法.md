# 网站总弹人机验证的排查方法

> 用 DuckDuckGo 浏览器时部分网站反复要求过验证码？本篇按「先看是谁的原因」的顺序给出排查步骤，多数情况能在浏览器设置里解决。

## 一、先明白验证码为什么会找上你

网站的人机验证不是随机的：风控系统会按你的 IP 信誉、浏览器行为一致性、Cookie 历史给每次访问打分，分数不高不低的那批人就会被要求点验证。多个独立排查来源的结论一致：隐私类浏览器更容易被要求验证，因为它拦掉 Cookie 和指纹信息后，网站对「你是谁」缺少历史依据，只能多问一句。

这不是故障，也不是被针对——同一网络环境下换别的浏览器可能一样会遇到。明白了这一点，排查思路就清晰：**把「可疑信号」一项项排除**。

## 二、排查步骤（按顺序做）

1. **看盾牌图标**：点地址栏旁的盾牌，查看这个页面拦了什么。把该站点的对应保护放宽后刷新，多数验证码循环到此解决。
2. **允许该站点保留 Cookie**：部分网站的验证流程需要 Cookie 才能记住「你刚过过验证」。被拦时验证会无限循环。单独给这个网站放宽即可，不影响其他网站。
3. **检查是否同时在用 VPN**：VPN 的共享出口 IP 是验证码循环的头号来源——同一条 IP 上只要有少数人行为异常，整条 IP 都会被标记。暂时断开 VPN（包括付费订阅里的那类）再试；确认是 VPN 的锅后，换服务器节点往往就能改善。
4. **切换网络对比**：Wi-Fi 与移动流量之间切换再访问。如果只有其中一种网络触发，问题在网络侧而不是浏览器。
5. **重启家用路由器**：家宽的动态 IP 有可能恰好曾被列入风控名单，重启拿到新 IP 后直接恢复。这一点与用什么浏览器无关。

## 三、手机网络自带的因素

手机流量的验证码通常比家里 Wi-Fi 多，原因是运营商把大量用户放在同一个出口 IP（运营商级 NAT）后面：同一条 IP 里任何一个用户行为异常，整条 IP 的评分都会被拖累。这不是你的手机有问题，也无法从浏览器侧彻底避免——换个时间或换个网络再试是更实际的做法。

## 四、App 追踪保护会让验证变多吗

不会混淆：App 追踪保护拦的是**其他 App**发往追踪公司的请求，不改变你访问网站时的 IP 与浏览器特征，与网站验证码无关。它借用的本地 VPN 通道与「你另开一个 VPN 应用」互斥，这才是它间接牵连网络体验的地方，详见 [App追踪保护怎么开启.md](App追踪保护怎么开启.md)。

## 五、都试过还是不行

- 用另一个浏览器打开同一页面对比：如果别的浏览器也循环，问题在网络侧；如果只有 DuckDuckGo 循环，回到第二步把该站点的 Cookie 放宽做彻底。
- 个别强制严格风控的网站（银行、票务类常见）怎么调都过不去时，这类站点用系统浏览器单独处理是更省时间的办法，不必为了它放弃日常浏览器的整体保护。
