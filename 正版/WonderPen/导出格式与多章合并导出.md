## 一、能导出的六种格式

按官方帮助文档与定价页，导出格式覆盖以下六种，且**免费版与两档会员的导出格式一致**，导出不设会员门槛：

| 格式 | 典型用途 |
| --- | --- |
| Word（docx） | 交稿给编辑、后续在 Word 里改 |
| PDF | 打印、定稿存档 |
| Epub 电子书 | 发布到阅读平台 |
| 网页（HTML） | 自行发布、浏览器里看 |
| 纯文本（txt） | 迁移到其他写作工具、投稿系统 |
| 图片（PNG） | 分享单篇内容 |

导出时内置排版会尽量保留编辑器里的常用效果，表格、代码块与代码高亮都能带出去。

## 二、导出范围：单篇还是整部

导出面板里可以选：

- **只导出当前选中的节点**——单篇文档；
- **导出当前节点及其所有子节点**——把整卷、整部书一次带出，长篇著作用这个。

选文本或网页格式且包含子节点时，还能进一步选**导出为单个文件还是文件夹**：导出为文件夹会保持目录树里的层级结构，一章一个文件，方便后续分别处理。

## 三、多章合并导出为一部书

长篇最常见的需求是把几十个章节合成一个文件：

1. 在左侧目录树里勾选要导出的多个文档或章节；
2. 导出为单个文件；
3. 选择章节之间的连接方式：
   - **分页**——每个章节另起一页，适合 Word、PDF 成书；
   - **空行**——章节之间用指定数量的空行衔接，适合纯文本类。

桌面版 3.1.2 起，Word 导出还支持把列表项、表格带进 docx（官方 2026-05 更新日志口径），此前版本导出 Word 时这些格式可能丢失。

## 四、两个容易踩的点

- **超长文档不要导出为图片**：官方文档明确警告，文档太长时导出图片可能失败，这类内容改走 PDF 或 Word。
- **PDF 想保留背景效果要开「打印背景」**：文档里设了背景色、背景图之类的显示效果时，导出设置里不开打印背景，成品里是不会出现的。

## 五、手机端的导出

移动端的导出能力比桌面端精简，且**跟版本挂钩**：

- 移动版 0.9.39 起，在文档编辑器右上角的更多按钮（三个点）里可以**导出为文本文件**（`.txt`）或**导出为图片**；图片支持长图、卡片两种样式，可调字体、是否显示标题，成品保存到手机相册。
- 早于 0.9.39 的版本没有这两个入口。本文写作时网盘里采集的安装包是 0.9.24，如果你装的是这一版而需要这些功能，要么升级到应用商店的最新版，要么先用云同步把稿子转到桌面端导出。

## 六、数据归属：随时可以整体带走

官方导出文档里有一句值得留意的话：数据在文档库内部以 JSON 方式存储，但你随时可以把内容导出为文本格式、并保持目录层级关系——「你的数据总是属于你」。实际含义是：即使哪天你不再用 WonderPen，全部稿子也能按原有章节结构导出来，迁去其他文字处理软件。整库层面的打包与搬家用 Zip 导出/导入，操作见[自动备份与文档快照.md](自动备份与文档快照.md)；导入能力的边界（官方仅支持 txt 导入）见[从新建文档库到导出成文.md](从新建文档库到导出成文.md)。
