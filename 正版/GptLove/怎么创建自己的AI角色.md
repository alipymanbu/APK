# GptLove 怎么创建自己的AI角色

> 现成角色的人设是固定的，改不了。本篇讲清怎么从零建一个属于你的角色：要填哪几项、每项怎么写才管用，以及角色卡和世界书怎么用上。

如果你想长期跟同一个「人」聊，现成角色是不够用的——它们的人设是别人写死的。这个应用给了自建角色的入口，人设、开场白、头像都能自己定。本篇按「入口 → 逐项怎么写 → 导入角色卡 → 建完怎么管」讲。

## 一、入口与前置条件

1. **先登录。** 没登录时建角色的入口点不动，登录方式见 [注册登录与账号设置.md](注册登录与账号设置.md)。
2. **在首页找到「+」。** 建角色的入口是首页的加号按钮，点进去就是新建角色的表单。
3. 表单里通常包含：角色名、头像、人设描述（性格与背景）、开场白，以及更细的提示词与可见性选项——具体字段以你手机上当时显示的为准。

## 二、每一项怎么写才管用

自建角色能不能聊得下去，几乎全看这几栏填得够不够具体。

| 栏目 | 别这么写 | 建议这么写 |
| --- | --- | --- |
| 角色名 | 随便一个昵称 | 一个确定的称呼，后面所有对话都会用它自称 |
| 人设描述 | 「温柔、善良」 | 身份 + 性格 + 说话习惯 + 与你的关系，四样都落到具体 |
| 开场白 | 留空 | 一句能直接把场景带起来的话，相当于给对话定调 |
| 头像 | 不设 | 设一张，会话列表里才好认 |

人设描述可以直接套这个骨架：

```text
身份：____（职业、年龄、所处的世界）
性格：____（两三句，写具体行为，不写形容词堆砌）
说话习惯：____（口头禅、称呼你什么、句子长短）
与我的关系：____（陌生人 / 旧识 / 同事……）
```

一句话总结：**凡是「你希望它记住的」，都写进人设描述；凡是「只影响这一场的」，放进开场白。**

## 三、世界书：把背景设定单独放

角色卡之外，应用还支持**世界书（世界观书）**这类设定集。它和角色人设的分工是：

- **人设** = 这个角色是谁；
- **世界书** = 这个世界里有什么（地名、组织、规则、和角色相关的其他人）。

什么时候该用世界书：剧本涉及多个场景或多个配角、设定写进人设里会太长把角色描述撑爆的时候。设定本身不长，就并进人设描述，不必单开一个世界书。

## 四、导入现成的角色卡

除了手打，应用支持**导入外部角色卡**来快速生成角色。可用的做法与注意事项：

1. **准备文件**：角色卡通常是一张图片或一个 JSON 文件，从你有权使用的来源获取。
2. **不要用截图。** 通过截图、聊天软件转发这类方式二次保存，会压缩掉卡内携带的信息，导入后角色设定可能残缺或直接报错——用原始文件。
3. **走应用内的导入入口**，选中文件后按提示确认，导入成功的角色会出现在你的角色库里，点头像即可开聊。
4. **导入后先试聊一句**，确认人设读进去了；发现人设没生效，多半是文件在传递过程中被压缩了，换原始文件重来。

## 五、建完之后怎么管

- **在「我的角色」一类板块里找**：自建与导入的角色会集中在这里，和首页的官方角色墙分开。
- **可改的与不可改的**：自建角色的人设、头像一般可以再编辑；从外部导入的卡，改之前先想清楚要不要留一份原始文件。
- **可见性选项**：建角色表单里有把角色设为公开或仅自己可见的选项。想自己用，设成仅自己可见即可；公开意味着它可能出现在别人的列表里。
- **同一角色可以随时重开一段**：想换剧情走向，不一定要改设定，新开一个会话从头演即可。

## 六、几个常见卡点

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 加号点了没反应 | 没登录 | 先登录，见 [注册登录与账号设置.md](注册登录与账号设置.md) |
| 导入角色卡失败 | 文件被压缩过，或格式不被支持 | 换原始文件重试，别用截图件 |
| 角色不按人设说话 | 人设描述太笼统，或换过模型 | 把描述写具体；再到聊天页顶部换个模型试 |
| 角色聊几句就跑偏 | 对话累积太长，或设定之间有冲突 | 关键设定重述一次；检查人设里有没有自相矛盾的地方 |
