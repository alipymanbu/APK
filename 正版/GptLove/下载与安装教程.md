GptLove 是安卓端的 AI 角色聊天应用：首页有一批自带人设的角色可以直接开聊，也能自己建角色、换模型，聊过的事角色会记着。本篇只做一件事——把网盘里这份包装进手机，并确认它能正常打开、正常收到回复。

## 一、先确认网盘里这份包是哪一版

应用市场和下载站上显示的是官方当时的最新版，跟网盘里这份未必是同一个版本号。本篇出现的版本号、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | GptLove |
| 版本号 | 1.0.17 |
| 包名 | `com.zhangwei.gptlove` |
| 安装包体积 | 7.09 MB |
| MD5 | `54F728ABF596EAECCE1335E01373DDFE` |
| 适用平台 | Android（手机端 APK） |
| 界面语言 | 简体中文 |
| 登记的系统要求 | 需要支持安卓系统 5.2 以上 |

装之前先弄清三件事：

- **认包名，别只认名字。** 搜「GptLove」会出来一堆同名或近名条目，其中好些并不是这个应用。这份的包名是 `com.zhangwei.gptlove`，装好后在「设置 → 应用 → 应用管理 → GptLove」里点进去能看到；对不上的先按 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 核一遍再装。
- **这是安卓包，iPhone 和 iPad 装不了。** 网盘里这份是 APK；这个应用目前没有 iOS 版本，苹果设备上没有对应的安装文件。
- **系统要求以本机实际表现为准。** 上表那行「安卓 5.2 以上」是这个包登记的要求，自己在「设置 → 关于手机」里对一眼版本号最稳；低于要求的表现通常是装不上，或者装上打开即退。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [GptLove 安装文件资源（夸克网盘）](https://pan.quark.cn/s/42f2a8e32206)，用手机上的夸克 App 打开最省事。
2. **先转存再下载**：选中安装包，转存到自己的网盘目录，再从自己的目录里下载到本机。分享链接以后可能失效，转存过的那份不受影响。
3. **核对体积**：下载完成后看一眼文件体积，应当约 7.09 MB。中途断网重连后体积明显偏小，装的时候会直接报「解析包错误」。
4. **想校验完整性**：在电脑上把包算一遍 MD5，结果应与上表一致（大小写不敏感）。

```cmd
certutil -hashfile GptLove.apk MD5
```

文件名随版本变化，以网盘里实际提供的那个为准。

## 三、安装步骤

1. **给文件管理器开「安装未知应用」权限**：进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把用来打开 APK 的那个应用（文件管理器或浏览器）的开关打开。国产定制系统这项常收在「安全」或「隐私」分类里。
2. **点击 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续，这是侧载安装包的常规提示。
3. **手机上已装过更高版本时先卸载**：安卓不允许用低版本覆盖高版本，会直接报「应用未安装」。卸载会一并清掉本机数据，动手前先在应用内翻一遍有没有导出或备份的入口（是否提供以应用内为准）。
4. **报「签名不一致」说明包名撞了**：手机里已装过同包名、不同来源的版本，按第五节表格处理。
5. **留出安装空间**：安装过程中系统还要展开一份文件，建议预留 500 MB 以上可用空间。

## 四、第一次打开要确认的三件事

1. **能联网**：角色列表和对话回复都要联网才能拿到，应用本身不能离线聊天。打开后一直停在加载状态，先用浏览器确认手机能正常上网，再从应用内重试一次。
2. **能登录进去**：第一次进入会先弹用户协议，点确认后按提示登录。登录方式与收不到验证码的处理见 [注册登录与账号设置.md](注册登录与账号设置.md)。
3. **能看到角色并发出一句**：首页刷得出角色卡片，说明数据侧通了；随便点进一个角色发一句「你好」，能正常收到回复就算装好了。想自己捏一个角色的，做法见 [怎么创建自己的AI角色.md](怎么创建自己的AI角色.md)。

## 五、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整 | 核对体积与 MD5，按第二节重新取一份 |
| 提示「应用未安装：签名不一致」 | 手机里已有同包名、不同来源的版本 | 先在应用管理里卸载旧包，再装这份 |
| 安装被安全中心拦下 | 侧载包被系统安全策略拦了 | 在安全中心的拦截记录里选「继续安装」 |
| 点安装没反应 | 「安装未知应用」权限没给 | 回到第三节第 1 步补上权限 |
| 装完打开就闪退 | 系统版本过低、存储不足或包残缺 | 见 [常见问题与排查.md](常见问题与排查.md) 第二节 |

以后换版本或重装，按第二节的步骤重新取一份即可，安装动作与这次相同。

## 六、装完之后顺手做两件事

- **在应用管理里记一眼包名**：点进 GptLove 的应用信息页，确认包名是 `com.zhangwei.gptlove`。以后再拿到一个也叫 GptLove 的包，拿这条一对就知道是不是同一个应用。
- **把网盘里的包留着**：这类应用的版本号走得快，某个新版用着不对劲时，能退回来的前提是手上还留着旧包；转存过的那份是干净的原始文件。
