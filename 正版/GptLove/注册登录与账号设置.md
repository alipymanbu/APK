# GptLove 注册登录与账号设置

GptLove 的角色列表可以随便看，但**发消息之前必须登录**——这是它和少数「打开就能聊」的同类应用不一样的地方。本篇只讲登录这一件事：怎么进得去、怎么不出岔子。

## 一、登录方式：QQ 邮箱收验证码

目前的版本里，登录入口在首页（部分版本在页面右上角），走的是**邮箱验证码**这一条路，不是密码登录：

1. 打开应用，第一次进入会先弹用户协议，点确认后继续。
2. 点首页的「登录」入口。
3. 填入**QQ 邮箱地址**（形如 `数字@qq.com`），点获取验证码。
4. 去 QQ 邮箱收信，把收到的数字验证码填回应用。
5. 验证通过即完成登录，随后按提示填一个昵称。

几点提醒：

- **邮箱写法要完整。** 填 `123456` 这种纯数字是不行的，要填完整的 `123456@qq.com` 形式。
- **用哪个邮箱，以后就用哪个登录。** 换一个邮箱登录，等于换了一个账号，之前那个账号里的内容不会跟过来。
- **没有第三方登录入口是正常的。** 这个应用目前没有微信、Apple 等一键登录，只有邮箱验证码这一条。

## 二、第一次登录后要做的设置

| 设置项 | 在哪 | 说明 |
| --- | --- | --- |
| 昵称 | 登录后按提示填，之后可在个人页修改 | 会显示在你和角色的对话里 |
| 头像 | 个人页 / 聊天设置 | 可换成自己的图片 |
| 聊天背景 | 聊天界面的设置里 | 同上，属于界面自定义，不影响聊天内容 |

昵称和头像建议一次就设成自己认得出的，后面建了多个角色、开了多个会话时，能靠它确认「这是我在跟谁聊」。

## 三、账号里到底存了什么

这是最容易被误解的一点：**这个应用不是「会话存在本机、卸载即清空」那一类**。

- 你建过的角色、和角色聊过的内容，在应用里是跟着账号走的；官方口径是角色对对话有记忆，能延续之前的设定。
- 因此**换手机时，用同一个邮箱账号登录，原来的角色和会话通常还在**；换邮箱登录就看不到。
- 反过来也要留意：聊天记录不完全是「只在你手机上」的东西，具体怎么存、存多久，以应用内展示与它自己的隐私政策为准。

如果你在意聊天内容的留存，先看 [常见问题与排查.md](常见问题与排查.md) 里「聊天记录与换设备」那一节，确认当前版本给不给你导出或删除的入口。

## 四、退出登录与切换账号

- **退出登录**：在个人页 / 设置里找「退出登录」，退出后回到未登录状态，角色列表还能看，但发不了消息。
- **切换账号**：先退出，再用另一个 QQ 邮箱按第一节的流程登录。
- 换账号收验证码时，**注意确认收到的邮件是发给你现在要用的那个邮箱**，别拿旧账号的验证码去填。
- 如果只是想换个昵称、换个头像，不用退出登录，直接改即可。

## 五、登录不进去时的自查顺序

1. **收不到验证码** → 先看 QQ 邮箱的垃圾箱、订阅邮件分类；再确认邮箱地址没写错（尤其是数字部分）；仍不行就等一两分钟重发，或换一个 QQ 邮箱试。**别连续狂点「重新发送」**——短时间反复请求会被服务端限流，反而更久收不到。
2. **提示验证码错误 / 已过期** → 验证码有时效，重新获取一条，拿到后立刻填。填的时候注意别把空格带进去。
3. **点了登录没反应** → 先确认手机网络正常（切到流量或换 Wi-Fi 各试一次），再重启应用重来。网络层的完整排查顺序见 [常见问题与排查.md](常见问题与排查.md) 第二节。
4. **之前能进、现在进不去** → 先排除网络，再确认用的是不是同一个邮箱账号；账号本身没问题的前提下，这类现象多数是接口临时不可用，隔一会儿再试。

上面四条都排过还是进不去，就不是你这边能修的了：要么是接口临时不可用，隔一段时间再试；要么是当前版本太旧，等更新后再试。**别为了登录去装来路不明的同名包**——分辨方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 六、关于「用手机号 / 微信能不能登」

公开资料里目前**只见到邮箱验证码这一种方式**，没有手机号登录的说明。如果以后版本里出现了别的登录方式，以应用内实际显示为准；在它出现之前，准备好一个能收信的 QQ 邮箱就够了。
