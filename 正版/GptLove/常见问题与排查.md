这一篇是排错用的：先定位是「包的问题」「网络的问题」还是「账号的问题」，再按对应小节处理。绝大多数情况都落在前两类。

## 一、安装阶段：先分清是包的问题还是环境的问题

装不上的错误提示就那么几种，先按提示归到对应的那一类里，能省掉反复试：

1. **包本身有问题** —— 提示「解析包错误」，或安装进度到一半失败。先排除下载环节：这份包体积约 7.09 MB，明显偏小就是没下完，回网盘重新转存下载一份干净包最直接，见 [下载与安装教程.md](下载与安装教程.md) 第二节。
2. **环境不允许安装** —— 点安装没反应、被安全中心拦下。这是系统权限与安全策略的事，不是包坏了：去「设置 → 应用 → 特殊应用权限 → 安装未知应用」放行；被拦下的，在安全中心的拦截记录里选「继续安装」。这两类都在点安装的那一刻就表现出来，与下载无关。
3. **设备不满足要求** —— 提示系统版本过低。这份包登记的是安卓 5.2 以上，低于这个版本装不了；满足版本仍打不开的，按下一节排查。
4. **包名撞车** —— 提示「应用未安装：签名不一致」，说明手机里已有同包名、但来源不同的包。先在应用管理里卸载旧包，再装这份；**卸载会清掉本机数据**，动手前先确认有没有要留的东西。

归类方法：错误提示里出现「解析」字样的归第 1 类，出现「安全」「未知来源」字样的归第 2 类，出现「版本」字样的归第 3 类，出现「签名」字样的归第 4 类。**归错类会在错的方向上白折腾**——比如反复重下安装包，而真正缺的是安装权限。

安装包本身有问题，就直接从 [GptLove 安装文件资源（夸克网盘）](https://pan.quark.cn/s/42f2a8e32206) 重新转存下载一份干净包，比在原文件上反复折腾快。

## 二、打开就退 / 一直转圈

**打开几分钟内闪退**，按下面顺序排除：

1. **存储不足**：应用运行要占空间，留出几百 MB 再试。
2. **清一次缓存**：进「设置 → 应用 → 应用管理 → GptLove → 存储」，先点**清除缓存**。只清缓存不会动你的账号数据，别顺手点成「清除数据」。
3. **重启手机**：清掉后台残留的连接再进一次。
4. **系统版本过低**：见第一节最后一行。
5. **包不完整**：重装一份新的。
6. **机型兼容**：换一台设备试同一个包，能开说明是原设备的问题。

**一直停在加载页**，几乎都是网络问题，按这个顺序走一遍：

1. **用浏览器打开任意网页**，确认手机确实能上网——浏览器都打不开，就不是应用的问题。
2. **切网络各试一次**：Wi-Fi 与流量互换。有些网络会拦掉这类应用的后端请求，换一条就通。
3. **关掉 VPN / 代理 / 私人 DNS**：这类工具会把请求绕到被限流的线路上，是这个应用最常见的连不上原因。
4. **看手机的日期与时间是不是「自动」**：时间偏差过大会让加密连接直接失败，在「设置 → 系统 → 日期与时间」里打开自动同步。
5. **开关一次飞行模式，或重启手机**：刷新一下网络注册与 DNS 缓存。
6. **等一段时间再试**：接口服务偶发不可用不在你这边能修的范围，隔一会儿自己会恢复。

上面第 2 到第 5 步，是针对「应用能开、但拿不到数据」这类现象的通用处理，对登录、聊天回复同样适用。

## 三、登录进不去

| 现象 | 多半是什么原因 | 处理 |
| --- | --- | --- |
| 收不到验证码 | 邮箱写错、或进了垃圾箱 | 核对完整邮箱地址；翻 QQ 邮箱的垃圾箱与订阅分类；等一分钟重发 |
| 验证码提示错误 / 过期 | 验证码有时效 | 重新获取一条，收到立刻填 |
| 点了登录没反应 | 网络不通 | 换网络重试，或重启应用再进 |
| 之前能进现在进不去 | 用的不是同一个邮箱 | 确认登录用的是当初那个邮箱账号 |

登录方式的完整说明与前置步骤见 [注册登录与账号设置.md](注册登录与账号设置.md)。

## 四、聊天发不出 / 收不到回复

- **消息发不出去**：先看是否还在登录状态（退出后会回到只能看不能聊的状态），再确认网络。
- **回复很慢或长时间不出**：这与角色、与模型都有关，通常先等；连续两次都这样，回聊天页顶部换一个模型再试。
- **回复明显变短、答非所问**：优先怀疑模型，换一个模型验证；换了还一样，再回角色编辑页看人设描述是不是写得太笼统。
- **角色像忘了前面说过的话**：同一个会话里通常能接上；跨会话不一定继承，把关键设定在开头重述一遍最省事。挑角色与开场的完整建议见 [怎么挑角色和开始聊天.md](怎么挑角色和开始聊天.md)。

## 五、聊天记录与换设备

- **换手机会不会丢**：这个应用的角色与对话是跟着账号走的，用**同一个邮箱账号**登录，原来的内容通常还在；换邮箱登录等于换账号，看不到旧内容。
- **卸载重装**：卸载会清掉本机那份数据，但账号里的内容不受影响，重装后重新登录即可。
- **想留个底**：目前公开资料里没有见到官方的导出功能说明；如果应用内有导出或备份入口，用它，别指望从手机文件系统里翻出来。
- **在意隐私的话**：聊天内容不完全是「只存在你手机上」的东西，具体怎么存、存多久以应用内的隐私说明为准；不想留的内容可以考虑在应用内删除对应会话。

## 六、其它

- **苹果设备能用吗**：不能。这个应用目前只有安卓版，没有 iOS 版本，iPhone / iPad 上没有对应安装文件。
- **能离线用吗**：不能。角色列表和回复都要联网。
- **怎么更新**：公开渠道的新版本会陆续放出来；网盘里那份对应当前这一版（1.0.17）。装新版前记得先卸载旧版，并确认包名仍是 `com.zhangwei.gptlove`，别装到同名应用上——分辨方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
- **版本号与体积对不上**：以 [下载与安装教程.md](下载与安装教程.md) 第一节的表格为准，那是网盘里这份包的事实；网上显示的是官方最新版，两者常常不是同一版。
