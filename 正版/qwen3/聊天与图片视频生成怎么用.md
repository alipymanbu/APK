# Qwen 聊天与图片视频生成怎么用

> 本篇按任务讲 Qwen 的日常操作：怎么开对话、怎么让它先思考、怎么联网查资料、怎么发图发文件、怎么生成图片和视频、怎么用语音对话。界面按钮的位置可能随版本略有变化，以你手上的版本为准。

## 一、普通对话：先说清需求

底部输入框打字发送即可，支持连续追问。几个让回答质量立刻不一样的输入习惯：

- 把背景一并给出来：不说「帮我写个通知」，说「帮物业写一份周日 9 点停水检修的业主通知，语气客气，200 字内」。
- 追问时直接引用上一轮：「第二条太长，压到 50 字以内」。
- 要格式就说格式：「用表格对比」「分三点」「给我 JSON」。

## 二、思考模式：数学逻辑题才开

处理数学、逻辑推理、多步骤规划这类问题时，可以在输入区附近找到「思考 / Thinking」开关打开。打开后它会先输出一段推理过程再给结论，生成时间变长，但复杂题的答对率明显更稳。

日常问答、翻译、闲聊不必开——费时间，收益小。判断标准：这道题「想错一步就全错」就开，否则不开。

## 三、联网搜索：查时效信息

问今天、最近、最新版这类问题前，把「搜索 / Search」开关打开。回答会附带来源网页链接，点开可以核对。

要不要开搜索的简单判断：答案会随时间变的（版本号、价格、新闻、赛事），开；固定知识（定义、公式、历史），不开，直接问更快。

## 四、发图片和文件给它

输入框旁的「+」（或回形针）入口，可以选相册图片、拍照，或发送文件。实用的几类：

| 你发什么 | 能让它做什么 |
| --- | --- |
| 截图 | 读报错弹窗、设置页面，告诉你下一步点哪 |
| PDF / Word / 文档 | 总结要点、按你的问题在文内找答案 |
| Excel / CSV 表格 | 解读数据、算汇总、帮你写分析结论 |
| 照片 | 认地标、读说明书画重点、看菜谱步骤 |
| 录音 / 视频 | 转文字、总结内容 |

文件太大或格式生僻时可能失败，先把 PDF 拆小或转成常见格式再发。

## 五、生成图片

在功能入口（或直接在对话里描述）选择图片生成：把画面描述得越具体，出图越接近预期。一个能直接用的描述模板：

```text
主体 + 动作/场景 + 风格 + 画面细节 + 比例
例：一只橘猫趴在窗台上看雨，宫崎骏动画风格，柔和黄昏光线，竖屏 9:16
```

它也支持改图：上传一张图，说「把背景换成雪天」「改成赛博朋克配色」。生成结果不满意就点重新生成，或在追问里局部修改描述。

想让图里出现文字（海报标语、招牌、双语封面），把要显示的文字原样写进描述并用引号标出，例如「写一张海报，大字 'SUMMER SALE'，下方小字 '50% Off'」。图内文字排版是它相对拿手的场景，中文文字也能直接排进图里。

## 六、生成视频

视频生成的入口跟图片生成相邻（部分版本可能只在特定功能页提供）。写提示词的要点：一句话说清「谁 + 在哪 + 做什么 + 镜头怎么动」，例如：

```text
航拍视角，清晨的海边小镇，镜头从海面缓缓推向码头，写实风格
```

生成视频比图片慢得多（分钟级），适合先想好描述再一次出片；当前主要是短片片段，不适合当完整剪辑工具用。

## 七、语音对话与拍照提问

- **语音**：输入框旁的麦克风入口，说话提问，它语音回答；开车、做饭时解放双手。部分版本有实时语音通话模式，可以像打电话一样连续对话。
- **拍照问答**：看到不认识的东西（植物、仪器面板、外文菜单）直接拍照发问，配合联网搜索连翻译带解释一步到位。

## 八、长文档与深度研究

- **长文档**：整本 PDF、几十页报告可以直接发，让它按章节总结、或带着具体问题去文内找答案，比一页页翻快得多。
- **深度研究**：给一个需要多方查证的题目（选型对比、行业现状），启动深度研究后它会多轮检索并产出一份带引用来源的报告，耗时几分钟，适合替代你自己开十几个网页来回比对的过程。

用量相关的限制与报错处理，见 [常见问题与解决方法.md](常见问题与解决方法.md)。
