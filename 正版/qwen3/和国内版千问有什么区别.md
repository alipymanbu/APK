## 一、先说结论：这是两个 App

| | 国际版 Qwen（本套文档写的） | 国内版「千问」 |
| --- | --- | --- |
| 开发者 | 阿里云（Tongyi Lab / Qwen 团队） | 阿里（同一模型家族的国内消费端） |
| App 名称 | Qwen（曾用名 Qwen Chat，网页端标题 Qwen Studio） | 千问（原「通义千问」，2025 年 11 月改名） |
| 安卓包名 | `ai.qwenlm.chat.android` | 独立包名（以商店页面为准） |
| 入口 | 网页版 [chat.qwen.ai](https://chat.qwen.ai/)、官网 [qwen.ai](https://qwen.ai/) | 网页版 [qianwen.com](https://www.qianwen.com/) |
| 注册方式 | 邮箱验证码、Google、GitHub、Apple（不需要中国大陆手机号） | 以中国大陆手机号为主 |
| 游客使用 | 支持，不登录可先试 | 未登录仅能对话一轮（第三方实测口径） |

两家背后是同一个 Qwen 模型家族，核心的对话、推理、多模态能力同源；差别在于账号体系、界面语言、生态功能这些「外壳」。

## 二、版本号不能直接比

国际版 App 的版本号（本套文档涉及的这份是 1.9.0）与国内版千问（安卓已到 7.x，2026 年 8 月第三方实测）走的是两套版本序列，数字大小不代表新旧或强弱。判断功能差异要看功能本身，不要看版本号。

## 三、账号不互通

两边是各自独立的注册体系：国际版用邮箱 / Google / GitHub / Apple，国内版用大陆手机号。没有官方说明支持两边账号互通，聊天记录也不共享——在国际版聊的内容，登录国内版千问看不到，反过来一样。想两边都用，就各注册一个。

## 四、功能侧重差异

- **界面与语言**：国际版面向全球用户，多语言支持是其主打项（Qwen3 系列模型支持 119 种以上语言），界面默认英文、跟随系统；国内版界面全中文，也更早用上中文语音、中文场景的本地化功能。
- **生态集成**：国内版与阿里系应用（办公、电商场景）的联动更深，具体以官方功能页为准；国际版没有这类国内生态集成，走的是纯助手路线。
- **多模态**：两边都具备图片 / 文件理解与生成能力，具体到某个功能（比如视频生成）的开放程度，以各自 App 内实际显示为准。
- **免费口径**：两边消费端都免费，但额度策略各自独立调整；国内版未登录只能一轮对话，国际版游客模式可多聊一些（也有频次约束）。

## 五、怎么选

- 手机号是大陆的、主要用中文、想要本地化生态联动 → 装国内版千问。
- 没有大陆手机号、常驻海外、要界面多语言、或已经在用 Google / GitHub 账号 → 装国际版 Qwen（获取方式见 [下载与安装教程.md](下载与安装教程.md)，登录细节见 [登录方式与账号同步.md](登录方式与账号同步.md)）。
- 拿不准就先各试一次：两边都能免费用，实际聊几轮的体验差异比参数表更直观。
