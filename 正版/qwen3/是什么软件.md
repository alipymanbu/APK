## 一、一句话定位

Qwen 是阿里云 Qwen 系列大模型的官方对话客户端：你在输入框里提问、传图、传文件，回答由云端模型生成，手机本身不跑模型。开发主体标注为 Alibaba Cloud（Qwen 团队），安卓包名是 `ai.qwenlm.chat.android`。

## 二、「Qwen」和「Qwen3」是什么关系

Qwen3 是 Qwen 模型家族的一个系列名称（同一系列还有 Qwen-VL 视觉、Qwen-Omni 音视频等分支）。你手机上装的 App 名称就叫 **Qwen**，App 内部调用的是 Qwen 系列模型，模型版本会随官方更新而变化，不需要你手动升级「模型版本」。有些渠道把这个包叫 qwen3，指的就是它主打 Qwen3 系列模型的那段时期。

注意：应用商店里还有一个阿里系的「千问」App（原通义千问），那是同一模型家族的国内版，与这款国际版 Qwen 是两个应用、两套账号，见 [和国内版千问有什么区别.md](和国内版千问有什么区别.md)。

## 三、能做什么

| 功能 | 你能拿它做什么 |
| --- | --- |
| 普通对话 | 问答、翻译、写文案、写邮件、改代码，支持多轮追问 |
| 思考模式 | 处理数学、逻辑、推理类问题时先「想」再答，过程可见 |
| 联网搜索 | 回答里带上网页来源，适合查时效性信息 |
| 看图看文件 | 发图片、PDF、表格、文档给它，让它总结、解读、提取信息 |
| 生成图片 | 用文字描述生成图片，也支持改图、换风格 |
| 生成视频 | 用文字描述生成短视频片段 |
| 语音对话 | 用说话的方式提问，它用语音回答；也能对着摄像头提问 |
| 深度研究 | 给一个复杂题目，它多轮检索后产出一份带引用的报告 |

具体每个功能的入口和操作，见 [聊天与图片视频生成怎么用.md](聊天与图片视频生成怎么用.md)。

## 四、免费还是收费

截至本文整理时，Qwen 消费端（手机 App、网页版、桌面端）免费使用，没有面向个人的订阅套餐。阿里云另有一条面向开发者的按量计费 API 通道，与 App 用户无关。免费额度与功能边界以官方页面为准。

用量上的现实约束是频次与高峰期限流：免费用户聊得多、赶上高峰时段，会遇到变慢或「稍后再试」，具体数值官方没有公布。另外，未登录的访客模式能做的事比登录后少一截（历史同步、文件上传等），第三方资料里提到的「额度更高付费档」说法不一，以你 App 内实际显示为准。

## 五、换设备、换平台

同一个 Qwen 账号可以登录多个端，聊天记录自动同步：

- 手机：安卓（Google Play 或 APK 安装）、iOS（App Store）
- 电脑：Windows、macOS 桌面客户端
- 浏览器：网页版，见 `https://chat.qwen.ai/`（[chat.qwen.ai](https://chat.qwen.ai/)）

不装 App 也可以直接用网页版；手机端的优势主要是语音对话和拍照提问。登录与同步细节见 [登录方式与账号同步.md](登录方式与账号同步.md)。

## 六、适合什么场景

需要中文、多语言都拿得出手的免费 AI 助手，且希望手机、电脑、网页共用一份记录——比如日常问答、查资料带引用、读文档做摘要、写文案、随手生成一张配图或一段短视频。它不适合当离线工具用：所有回答都依赖联网。
