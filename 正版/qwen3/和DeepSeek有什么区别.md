## 一、基本情况对照

| | Qwen（本套文档写的） | DeepSeek |
| --- | --- | --- |
| 开发方 | 阿里云（Tongyi Lab） | 深度求索（2023 年成立） |
| 形态 | 手机 App + 网页版 + 桌面客户端 | 手机 App + 网页版（[chat.deepseek.com](https://chat.deepseek.com/)） |
| 登录方式 | 邮箱验证码、Google、GitHub、Apple | 邮箱、Google、Apple ID |
| 不登录能用 | 访客模式可用 | 支持游客使用 |
| 免费 | 消费端免费 | 免费，官方明确无广告、无应用内购买 |
| 跨设备同步 | 同一账号多端同步 | 同一账号多端同步 |

两者的登录与同步体验接近，真正拉开差异的是下面这些功能侧重。

## 二、功能侧重：多模态一站式 vs 对话为主

**Qwen 把多种生成能力装进了同一个对话窗**：文字聊天之外，你可以直接让它生成图片、生成短视频、开语音对话、对着摄像头提问、上传文档表格做分析，还有多轮检索出报告的深度研究功能——这些都在免费范围内。

**DeepSeek 的官方功能列表以对话类为主**：联网搜索、深度思考（Deep-Think）模式、文件上传与文字提取。图片生成、视频生成不在其官方公布的功能列表里（截至本文整理时，以官方页面为准）。它的强项在文本推理：数学、逻辑、代码这类「想清楚才能答对」的任务，深度思考模式表现出色。

一句话对照：

- 要「一个 App 什么都能干」——生图、生视频、语音、读文件 → Qwen 的功能覆盖面更大。
- 主要就是打字问答、写代码、做推理 → 两家都能胜任，DeepSeek 的思考模式在纯文本难题上值得单独一试。

## 三、思考模式两边都有，开关思路一样

两边都提供「先思考再回答」的模式（Qwen 叫思考 / Thinking，DeepSeek 叫 Deep-Think），共同点是：

- 复杂题（数学、逻辑、多步规划）开了更稳，简单问答开了纯属浪费时间；
- 思考过程可见，答错了能看出它哪一步想偏了；
- 生成时间明显变长，高峰期尤其明显。

## 四、免费与限流

两边消费端都不收费，也没有公开的按月订阅档。共同的现实约束是高峰期限流：用量大或服务器拥堵时会遇到「稍后再试」、回答变慢这类情况，具体数值两家都没公布。差异在于功能面：同样的免费额度，Qwen 覆盖生图生视频这类高成本功能，DeepSeek 把成本集中在文本推理上——这本身就是两种产品思路。

## 五、实操建议

1. 两个 App 都免费，**都装上实测**是最快的办法，不冲突。
2. 日常混合需求（问问题 + 偶尔生图 + 读 PDF）→ 留 Qwen 当主力，操作见 [聊天与图片视频生成怎么用.md](聊天与图片视频生成怎么用.md)。
3. 大段代码、数学证明、长文推理 → 两边各试同一道题，谁的思考过程更合你意用谁。
4. 关注账号差异：两家账号体系独立，聊天记录不互通；换主力时没有一键迁移，重要对话先另存文本。
