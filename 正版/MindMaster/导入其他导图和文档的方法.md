## 一、导入入口在哪

手机端的导入路径（官方移动端指南的步骤）：

1. 回到**文件**页（底部导航的文件标签）；
2. 点右下角的 **+** 图标 → 选**「导入文件」**（Import File(s)）；
3. 也可以点文件页右上角的**更多图标** →「导入文件」；
4. 在手机存储里浏览、点选要导入的文件，等几秒让应用分析转换，一张导图就生成了。

生成的是一份**新文件**，不会改动你的原文件。导完先看一遍层级对不对，再决定存云里还是存本地（见 [云文件与本地文件怎么转换.md](云文件与本地文件怎么转换.md)）。

## 二、支持哪些格式

官方指南列出的手机端可导入格式：

| 来源 | 格式 |
|---|---|
| MindManager | `.mmap` |
| XMind | `.xmind` |
| FreeMind | `.mm` |
| EdrawMax | `.eddx` |
| Word | `.docx`（结构良好效果最好） |
| HTML | `.html` |
| Markdown | `.md` |

另外官方更新日志里加过**导入幕布**文件的支持。电脑端还支持把结构清晰的 Word、HTML、Markdown 直接生成导图，手机端以导入菜单实际列出的为准。

两条官方注意项：

- **导入的文件可能与原始版本不是 100% 相同** —— 主题样式、连接线细节可能要手动调；
- **大文件导入会比较慢**，别连点多次，等它转完。

## 三、别人发给我的导图，打不开怎么办

微信、QQ、钉钉里收到的导图源文件，处理顺序是：

1. 接收并保存文件到手机；
2. 打开 MindMaster，在**「本地文件」**里找到它查看、保存、编辑；
3. 如果文件管理器里直接点了没反应，回到应用内用第二节的导入入口选它 —— 系统里没有注册对应后缀时，**从应用内导入**比从外部打开更可靠。

至于导出成什么格式发给别人最合适：要发**能继续编辑**的原文件，导出 `.emmx`（编辑页右上角 → 导出 → `.emmx`，再走应用内分享发出去）；要发给**不装软件的人**，导出图片或 PDF（见 [导出为图片和PDF的方法.md](导出为图片和PDF的方法.md)）。

## 四、PDF 和图片能不能直接变导图

不能直接还原成一模一样的导图。官方客服的答复是：软件无法把 PDF / 图片导入后生成完全一致的导图；可以用 AI 功能导入相关文件、自动生成**概括性**的思维导图，但 AI 生成的内容不会还原原文每一个细节，且**执行会消耗 AI 点数**（免费版和会员都只有 500 点，用完需等充值，见 [常见问题与解决办法.md](常见问题与解决办法.md)）。

也就是说：手里是**结构化文件**（xmind、docx、md）就走第二节直接导；手里是**扫描件/图片**就当参考素材手动誊，别指望 AI 输出能原样照搬。
