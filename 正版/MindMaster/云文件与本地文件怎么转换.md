# 云文件与本地文件怎么转换

> 手机里的导图到底存在哪、云文件怎么落到手机本地、同步不上和内容丢了怎么找回。

## 一、先分清两种文件

| | 个人云文件 | 手机本地文件 |
|---|---|---|
| 存在哪 | 你的账号云空间 | 这台手机的存储里 |
| 换设备 | 登同一账号就能接着编辑 | 不会跟过去，换手机要自己转移 |
| 占什么 | 占云空间额度（免费版 150M） | 占手机存储，不占云空间 |
| 卸载应用后 | 还在 | 没了 |
| 多端同步 | 支持 | 不同步 |

新建时弹窗让你选的就是这两类。判断现有文件属于哪类：回文件列表，云文件在「个人云」分组下，本地文件在「本地文件」分组下。

## 二、云文件转成手机本地文件

想把云里的文件落到手机上（离线看、或者卸载前留个底）：

1. 打开这个文件进入编辑页；
2. 点右上角的**工具按钮**（「…」菜单）；
3. 选**「转为本地」**。

转完后文件出现在「本地文件」分组里，它就是一份独立的手机本地文件 —— 不再跟着云端更新。之后云端那份如果继续在电脑上改，两边内容会各走各的，别当成同一份。

## 三、本地文件怎么变成云文件

「转为本地」是单向的，反过来没有对等的一键按钮。要让一份只存在手机里的文件上云、能在别的设备打开，实际可用的路子是：在新设备或电脑端重新建一份内容后存到个人云，或用系统文件分享把文件传到目标设备再导入。**本地文件没有自动备份** —— 换手机、卸载应用前，先把重要文件转存出来（导出图片/PDF 也行，见 [导出为图片和PDF的方法.md](导出为图片和PDF的方法.md)）。

微信、QQ、钉钉里别人发给你的导图源文件，接收后打开本应用，在「本地文件」里就能查看、保存、编辑。

## 四、同步不上怎么办

官方帮助中心给的处理顺序，照着走：

1. 在文件列表**下拉刷新**，重新拉一次目录；
2. 看手机是不是处在弱网或断网状态；
3. APP 提示同步失败时，**退出账号再重新登录**；
4. 仍不行，联系官方客服反馈。

另一端充值或改动后这边没显示，多半也是同一条链路的问题 —— 先重新登录再看。

## 五、内容丢了、误删了：用历史版本

两条入口都能进（官方帮助中心的路径）：

1. **编辑页**：右上角「…」→「历史版本」→ 目标文件右侧「…」→「还原 / 预览」；
2. **文件页**：长按文件 →「历史版本」→ 同样操作。

免费版和会员在这的差别很大（截至检索时，以官方页面为准）：

| | 免费版 | 收费版 |
|---|---|---|
| 保存的历史版本 | 2 版 | 20 版 |
| 最长保留 | 30 天 | 30 天 |
| 能做什么 | **只能查看** | 查看 + 还原 |

也就是说免费版误删了内容，历史版本只能当参考、恢复不了 —— 重要的图定期导出一份图片或 PDF 到手机相册/文件里，是最省事的兜底。

## 六、云空间不够用了

免费版云空间 150M，会员扩容到 1G（终身类型可到 10G）（官方会员对比页，截至检索时，以官方页面为准）。空间不足时优先清理不用的旧云文件，或者把大文件「转为本地」从云里腾出来 —— 本地文件不占云空间。
