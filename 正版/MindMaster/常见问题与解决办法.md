## 一、一点就闪退

官方给的两步：

1. 把应用从后台彻底关掉，再重新打开；
2. 一直闪退的话，联系官方客服核查 —— 微信公众号「亿图软件」，或官网的在线客服。

重启无效时可以再补两步通用处理：去系统设置清一次应用缓存（**别点「清除数据」**，本地文件会被清空）；装不上、反复闪退的完整排查在 [下载与安装教程.md](下载与安装教程.md)。

## 二、文件不同步、内容不见了

这两件事的处理都集中在 [云文件与本地文件怎么转换.md](云文件与本地文件怎么转换.md)：同步不上走第四节的四步（下拉刷新 → 查网络 → 退出重登 → 找客服），内容丢了走第五节的「历史版本」。这里只强调一个前提 —— **历史版本免费版只能查看、不能还原**（2 版、30 天），恢复不了的场景就只能接受丢失，重要图平时导出一份图片或 PDF 兜底。

## 三、买了会员，登录后还是显示免费版

按官方帮助中心的排查顺序：

1. **确认登的是不是购买时那个账号**。微信、QQ、手机号、邮箱分别注册出来的是**各自独立的账号** —— 用手机号买的会员，用微信登录自然看不到。PC 端可在右上角头像 → 用户中心 → 我的订单里核对有没有订单记录。
2. **确认装的是不是最新版**。旧版本可能不识别新的会员权益，先升级再登录看。
3. **看设备有没有超限**。个人版一个账号最多同时登录 **3 台设备**，超限后仍能登录，但**按非会员状态使用**。处理：头像 → 用户中心 → 设备管理，把不用的设备下线。

另外一个容易混淆的点：在**另一端**（比如电脑上）充值后手机端没显示，先退出账号重新登录一次；仍不生效就带着订单号找官方客服。

## 四、账号要解绑、换绑、注销，或有两个账号

这些操作都在**账号安全中心**完成：[https://account.edrawsoft.cn/security](https://account.edrawsoft.cn/security)。

- **换绑 / 解绑**：登录上述网址 →「安全中心 → 更改绑定」。
- **注销**：应用内「个人资料」页最下方，或上述网址的「安全中心 → 注销账户」。
- **两个账号想合并**（比如一个有会员、一个存了文件）：只能在**电脑端**操作 —— 先用非会员那个账号登录安全中心注销，再用会员账号登录并在安全中心把前者绑回来。

注销前三条硬提醒（官方口径）：

1. **不可恢复**，亿图账号是统一账号体系，注销会删掉该账号的一切信息；
2. **云文件会永久删除**，包括 MindMaster 在内的该账号全部云文档 —— 注销前先把文件备份/转移；
3. **会员账号不能注销**，合并账号时注销的必须是非会员那个。

手机号丢了收不到验证码时，换绑要走人工客服，需要提供账号信息和订单记录。

## 五、免费版到底能用到什么程度

免费版日常画图够用，卡脖子的额度在这里（官方会员对比页，截至检索时，以官方页面为准）：

| 权益 | 免费版 | 会员 |
|---|---|---|
| 云空间 | 150M | 1G（终身类型 10G） |
| 主题风格切换 | 2 种 | 33 种 |
| 插入图片 | 每个文件 2 张 | 不限 |
| 剪贴画 | 每类目前 8 个 | 全部 |
| 标签组 | 1 组、每组最多 5 个 | 不限 |
| OCR 识别 / PDF 扫描 | 各 3 次 | 无限次 |
| 待办 / 日历提醒（仅 Android） | 各 3 次 | 无限次 |
| 历史版本 | 2 版、仅查看 | 20 版、可还原 |
| AI 点数 | 500 点 | 500 点 |

布局（22 种）免费版就能用满，画图本身不受限制。要不要升级，按你卡在哪一行决定 —— 卡在图片张数、OCR 次数就值得考虑，只是嫌主题不好看就先把精力放在配色上。

## 六、个人版和企业版不是一回事

| | 个人版 | 企业版 |
|---|---|---|
| 激活方式 | 账号登录，权益跟账号走 | 密钥激活，绑定电脑 |
| 联网要求 | 需联网使用 | 激活后可离线 |
| 商用 | 仅个人用途，不支持商用 | 可用于商业用途 |
| 换电脑 | 登录即用（最多 3 台同时在线） | 需重新激活 |

价格与购买口径（是否可按月、有无活动）以官方订单页当时显示为准：[https://www.edrawsoft.cn/order/mindmaster_buy.html](https://www.edrawsoft.cn/order/mindmaster_buy.html)。
