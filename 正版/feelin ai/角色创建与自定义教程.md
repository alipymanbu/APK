## 一、预设角色和自创角色

首页角色列表里是现成的角色：平台预设的、其他用户创建后被收进来的都有，每个带头像、简介和样例句，点开聊几句就知道合不合拍。

如果这些都不合适，可以从零造一个自己的角色——名字、性格、音色、背景故事都由你定，造完它就出现在你的角色列表里，随开随聊。

## 二、创建入口

登录后在首页找到「**+**」版块，进去就是角色创建页。创建页有两条路：自己逐项填，或者用 **AI 辅助生成**设定再手动改（以应用内实际提供的按钮为准）。

创建不需要一口气写完：外貌、性格、声音、背景设定可以先填个大概，之后再回来一点点补充。比较省时间的做法是先按直觉填一版，聊几轮感受一下，再回来微调——设定改了之后，角色的回应方式会跟着变。

## 三、能定制哪些东西

| 设置项 | 你可以定什么 |
| --- | --- |
| 基本信息 | 名字、性别 |
| 外貌 | 外貌与服装风格等视觉设定 |
| 性格 | 性格标签与说话倾向，比如温柔还是直接、话多还是简短 |
| 擅长领域 | 心理学、科技、文学、编程等，决定角色能陪你聊哪类话题 |
| 音色 | 从多种声音风格里选一种，语音聊天时用的就是它 |
| 背景故事 | 角色的经历与你们之间的关系设定，对话会围绕它展开 |

两个人设只差一个字段，聊起来可能完全是两种感觉：性格标签决定说话的语气，背景故事决定角色怎么接你的话。所以调角色时优先动这两项，比反复换名字、换头像有效得多。

创建好的角色可以选择**公开分享**，让其他用户也能搜到并使用；有介绍提到其他用户付费体验你的角色时，创作者能按比例获得积分分成，具体比例与规则以应用内为准。

## 四、创建完顺手调两处

- **对话模型**：不同模型回应风格与速度不一样，切换路径见[模型切换与聊天设置.md](模型切换与聊天设置.md)；
- **聊天方式**：文字与语音随时可切，打字嫌麻烦就直接按语音按钮说；想直接打电话，角色要挂「轻语模型」，见[AI电话与语音通话.md](AI电话与语音通话.md)。

后面聊的过程里碰到验证码、签到、模型消耗之类的问题，集中放在[常见问题与解决方法.md](常见问题与解决方法.md)里。
