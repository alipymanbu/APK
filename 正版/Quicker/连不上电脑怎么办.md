# Quicker 连不上电脑怎么排查

> 手机 APP 提示连接超时或一直连不上时，按本篇顺序逐项排查：局域网互通 → 路由器隔离 → Windows 防火墙 → IP 选错 → 端口验证码对不上。

## 一、排查顺序总览

| 顺序 | 检查项 | 典型表现 |
| --- | --- | --- |
| 1 | 是否真的在同一个局域网 | 手机在用流量，或连的是访客/邻居 Wi-Fi |
| 2 | 路由器是否隔离了设备间通信 | 同一 Wi-Fi 也连不上，提示 `Connection timed out` |
| 3 | Windows 防火墙是否放行端口 | 电脑能 ping 通手机方向的网络，但 APP 连不上 |
| 4 | 电脑端选错了 IP | 电脑插网线又连 Wi-Fi、开着 VPN、装了虚拟机 |
| 5 | 端口、验证码对不上 | 电脑端改过默认值 666 |
| 6 | 电脑端服务根本没开 | 设置里没启用 APP 连接 |

## 二、第一步：确认两台设备互相能通

1. 分别记下两台设备的 IP：
   - 电脑：`Win + R` → 输入 `cmd` → 回车 → 输入 `ipconfig`，看「IPv4 地址」；
   - 手机：设置 → WLAN → 点当前网络，查看 IP 地址。
2. 同一网段的 IP 前三段数字相同：电脑 `192.168.1.55`、手机 `192.168.1.199`，算同网段；一个是 `192.168.1.x`、另一个是 `192.168.31.x`，就不通。
3. 在电脑上验证到手机的连通性（IP 换成你手机的实际值）：

```powershell
ping 192.168.1.199
```

有字节回复说明网络层是通的，跳到第四节查防火墙；一直「请求超时」就先解决下一节的网络互通问题。

## 三、网络层不通：Wi-Fi 隔离了设备间通信

很多 Wi-Fi 默认限制接入设备之间互相访问，常见于三种环境：

- **路由器开了 AP 隔离（AP Isolation / Client Isolation）**：浏览器打开路由器管理页（常见 `192.168.1.1` 或 `192.168.0.1`，具体在路由器底部标签上），在「无线设置」或「安全设置」里找到隔离选项关掉，不同品牌菜单位置不同（华硕等品牌藏在无线的高级设置里）。
- **访客 Wi-Fi**：访客网络几乎都强制隔离，把手机和电脑都换到主网络。
- **公司 / 校园网**：管理员通常禁用设备互连，这种环境基本无解；可以让手机开热点给电脑（或电脑开热点给手机），组成一个自己的小局域网再连。

## 四、能 ping 通但连不上：Windows 防火墙

防火墙拦掉监听端口，是「网络明明通、就是连不上」的最常见原因。给端口 666（或你改过的端口）建一条入站放行规则：

1. 打开「Windows Defender 防火墙」→「高级设置」。
2. 左侧选「入站规则」，右侧点「新建规则」。
3. 规则类型选「端口」→ 下一步。
4. 选 TCP，填入你使用的端口号（默认 666）→ 下一步。
5. 选「允许连接」→ 下一步，配置文件全勾 → 下一步。
6. 随便起个名字（例如 `Quicker`）保存。

省事的替代做法：在「允许应用通过防火墙」列表里找到 Quicker，把「专用」和「公用」都勾上。再不行可以临时关闭防火墙做对照测试——关掉就能连、开回来就不通，即可确认是规则问题，回头把规则补对。

## 五、电脑有多个网络时：可能选错了 IP

电脑插着网线又连着 Wi-Fi、开着 VPN、装过虚拟机（VMware、VirtualBox 会添加虚拟网卡）时，电脑同时有多个 IP。扫码窗口里选了不对的那个，手机自然连不上：

- 回到电脑端扫码窗口，点「更改...」换一个与手机同网段的 IP 再试；
- 或者把暂时不用的网卡禁掉：`Win + R` → 输入 `ncpa.cpl` → 右键禁用多余的适配器（虚拟机网卡、VPN 虚拟网卡等），只留正在用的那个。

## 六、端口与验证码不一致

- 电脑端改过端口后，手机端必须填新端口；还按默认的 666 填，只会一直超时。
- 验证码要与电脑端设置页显示的一致。它的用途是防连错机器——同一个网络里有多台电脑装着 Quicker 时，验证码能保证手机连的是你面前这台。

## 七、以上都过了还是不行

先分清问题类型：「从来没连上过」属于本篇范围；「能连上、用一会儿就失灵」是另一类问题，另见[总是自动断开怎么办.md](总是自动断开怎么办.md)。
