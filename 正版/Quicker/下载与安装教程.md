## 一、先确认你要装的是哪个东西

Quicker 的主体是 Windows 电脑上的效率工具：用鼠标中键呼出一个快捷面板，点按钮执行各种动作。安卓端不是把这套工具照搬到手机上，而是**电脑面板的遥控器**——装在手机上、连上电脑后，手机屏幕会变成一块常驻的快捷面板，点上面的按钮，动作在电脑上执行。

几个先说清楚的事实：

- **必须配合电脑端使用**。手机 APP 自身没有独立功能，电脑上没装（或没运行）Quicker 时，它没有可连的对象。
- **没有 iOS 版本**。官方常见问题里的口径是长期内都不会有。
- 安卓客户端由官方开源，源代码在 [github.com/cuiliang/QuickerAndroid](https://github.com/cuiliang/QuickerAndroid)，官方下载页提供的 APK 渠道就是这个仓库的 Releases 页面。

两个入口：

## 三、手机要满足什么条件

| 条件 | 说明 |
| --- | --- |
| 系统版本 | 官方文档要求安卓 7.0 及以上，更老的系统不保证能正常使用 |
| 网络 | 与电脑连同一个 Wi-Fi；连接过程在局域网内完成，不依赖外网服务器 |
| 电脑端 | 电脑上已安装并正在运行 Quicker，且开启了 APP 连接（做法见[怎么连接电脑.md](怎么连接电脑.md)） |

## 四、安装步骤

1. 从上面任一入口拿到 APK 文件。
2. 点开 APK 开始安装。系统提示「不允许安装未知来源应用」时，按弹窗引导允许来自当前来源的安装（不同品牌手机的入口措辞略有差异）。
3. 安装完成，打开 APP。
4. 如果之后面板显示不出来，先到系统设置里检查这个 APP 的「显示悬浮窗 / 显示在其他应用上层」权限有没有放行——面板要以悬浮形式常驻在手机屏幕上，这个权限被拦是最常见的原因。

## 五、装好之后做什么

装完只是第一步：这个 APP 打开后没有现成内容可看，要先连上电脑才有面板。电脑端还没设置的话，从[怎么连接电脑.md](怎么连接电脑.md)开始，把电脑端的 APP 连接开起来，再用扫码或手动输 IP 的方式连上；连接环节卡住时，翻[连不上电脑怎么办.md](连不上电脑怎么办.md)，绝大多数失败出在局域网互通和 Windows 防火墙这两处。
