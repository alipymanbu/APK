## 一、连接前先备齐四个条件

| 条件 | 检查方法 |
| --- | --- |
| 手机和电脑在同一个局域网 | 两台设备连同一个路由器；电脑走网线时，网线也要接在同一台路由器下 |
| 电脑已运行 Quicker | 电脑任务栏里有 Quicker 图标 |
| 电脑端已开启 APP 连接 | 默认是关闭的，做法见第二节 |
| 防火墙放行监听端口 | 连不上时的头号嫌疑，排查步骤见[连不上电脑怎么办.md](连不上电脑怎么办.md) |

电脑端的监听端口默认是 666；你改过的话，手机端要填同一个值。

## 二、电脑端：先开启 APP 连接

1. 打开电脑端 Quicker 的设置窗口，进入「手机APP / WebSocket 设置」页面。
2. 启用对应服务（不同版本的开关名称略有差异，以你电脑端设置页实际显示为准）。
3. 记下端口和验证码。验证码的用途是：同一个网络里有多台电脑都装了 Quicker 时，防止手机连错机器。
4. 端口和验证码都可以改，改完记住新值，手机端要与这里保持一致。

## 三、方式一：扫码连接

这是官方文档给出的标准路径：

1. 电脑端点面板窗口的头像按钮，在菜单里选「连接手机APP」，弹出扫码连接窗口。
2. 电脑有多个 IP 时，在窗口里选择与手机同一网络的那个（一般是 192.168 开头、前三段与手机 IP 相同的地址）；只有一个 IP 时这一步会自动跳过。选错了点「更改...」重选。
3. 打开手机上的 Quicker APP，扫码对准电脑上显示的二维码。
4. 提示连接成功后，手机屏幕上会出现常驻面板。

不同版本电脑端的入口位置可能略有出入：有的版本面板上直接有二维码图标，点开就是同一个扫码窗口。

## 四、方式二：手动输入 IP 和验证码

二维码不好对焦或扫码失败时，可以在手机 APP 里手动填三项信息：

- **电脑的局域网 IP**：电脑上按 `Win + R`，输入 `cmd` 回车，再输入 `ipconfig`，找「IPv4 地址」那一行；
- **端口**：默认 666，以电脑端设置页里的值为准；
- **验证码**：与电脑端设置页里显示的一致。

填完点连接。如果提示 `Connection timed out` 之类的超时信息，问题多半出在网络不通或防火墙拦截，按[连不上电脑怎么办.md](连不上电脑怎么办.md)逐项过一遍。

## 五、连上之后

手机屏幕上会常驻显示快捷面板，面板按钮来自你电脑端配置的内容，点一下即在电脑上执行对应动作。连接断开后（比如 APP 被系统杀掉后台、电脑端重启过），重新打开 APP 再连一次即可；反复连不上的情况按排查篇处理。如果是「界面还在但按钮点不动」这类运行中失灵，处理办法与背后的维护现状见[总是自动断开怎么办.md](总是自动断开怎么办.md)。
