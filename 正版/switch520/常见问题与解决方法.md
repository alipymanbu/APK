## 一、应用打不开 / 一直转圈

按命中率从高到低试，通常前两条就能解决：

1. **网络问题**：当前网络不稳定或对访问有限制——换一个 Wi-Fi，或蜂窝数据与 Wi-Fi 互换一次再打开；
2. **服务端临时维护**：升级、维护期间谁都连不上，隔半小时到几小时再试，这不是你手机的问题；
3. **版本过旧**：客户端长期没更新、接口变了会打不开或白屏，用新安装包覆盖安装（见[下载与安装教程.md](下载与安装教程.md)第三节）；
4. **入口变更**：这类应用的访问入口偶有更换，确认你打开的是当前在用的版本，而不是从旧帖子里复制的旧入口。

判断技巧：如果连首页都加载不出来，问题基本在网络或服务端；如果**首页能开、只有点某个条目失败**，多半是单个资源的问题，换个条目试试就能区分。

## 二、闪退 / 黑屏

1. **系统版本**：安卓 5.2 以下不支持（版本要求见[下载与安装教程.md](下载与安装教程.md)第一节），到 设置 → 关于手机 里确认；系统本身有更新也一并装上——系统与应用版本不匹配是闪退的常见来源；
2. **彻底重启**：先在 设置 → 应用 里对该应用点**强制停止**再打开（只从后台划掉不一定真关掉）；不行就重启手机——多数偶发闪退是内存或进程状态脏了；
3. **安装包完整性**：包下残了会表现为「一打开就退」，按下载与安装教程第四节做 MD5 比对，不对就重下；
4. **存储与内存余量**：清出 200 MB 以上存储空间，同时关掉一批后台应用再试；
5. **权限是否给全**：设置 → 应用 → switch520 → 权限，把网络、存储这类它要用的权限打开——权限缺失时部分页面会直接崩；
6. **只在某一页闪退**：那是该页面数据异常，绕开它用搜索直达其他条目；稳定复现的话等版本更新修复；
7. **更新后才开始闪退**：多半是新版本自身的问题，等下一个版本修复；急用的话先卸载、装回上一个稳定版本（卸载前先确认账号能重新登录，见第五节）。

## 三、页面加载慢 / 内容出不来

- **换网络试一次**：先排除是你这条网络本身慢；
- **避开高峰时段**：晚间是使用高峰，同样的操作换到上午往往明显更快；
- **大文件走电脑**：游戏文件这类大体量内容，优先在电脑端网盘客户端下载，再传手机；
- **清缓存**：设置 → 应用 → switch520 → 清除缓存（**注意别点「清除数据」**，那会把本地登录态一起清掉）。

## 四、登录不上 / 频繁要求重新登录

1. 先确认账号密码拼写正确（区分大小写）；忘记密码走登录页的找回入口；
2. 注册没成功就登录必然失败——回[新手使用教程.md](新手使用教程.md)第二节重新走一遍注册流程；
3. 网络请求没走通时，登录接口会超时，表现就是「点了没反应」或报错——这种情况按第一节第 1 条换网络；
4. 换了手机登录不上：账号是同一个，与设备无关，重点核对自己记的账号名是否就是当初注册的那个。

## 五、更新后数据丢了（收藏、记录不见）

有用户反馈升级系统或重装应用后本地记录消失。预防和补救各一条：

- **预防**：确认这些数据跟着**账号**走（登录状态下收藏的条目，换设备登录后应能看到）；重要信息别只存在应用本地；
- **补救**：先退出账号再重新登录一次——数据若在服务端会拉回来；仍然没有的话，本地数据已随卸载/清除丢失，无法恢复，只能重新收藏。

## 六、安装失败排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | 文件不完整或损坏 | 重下并做 MD5 比对（[下载与安装教程.md](下载与安装教程.md)第四节） |
| 「禁止安装未知来源应用」 | 系统安全限制未开 | 按下载与安装教程第三节开一次开关 |
| 「安装包与已安装应用签名冲突」 | 装过来源不同的同名包 | 先卸载旧的再装（注意第五节的数据提醒） |
| 空间不足提示 | 存储余量太小 | 清出 200 MB 以上再装 |
| 装完打不开 | 系统版本过低 | 确认安卓 5.2 以上，不达标就换设备 |

## 七、下载链接 / 提取码 / 解压密码相关

链接打不开、提取码无效、解压报密码错、分卷解压失败，这些都归下载流程管：

- 链接与两个密码的处理在[游戏搜索与下载方法.md](游戏搜索与下载方法.md)第三节的表里，链接过期时回详情页重新点一次【立即下载】拿新链接即可；
- 分卷包解不开（缺卷、密码大小写、格式不支持）对照[分卷压缩包解压教程.md](分卷压缩包解压教程.md)第五节的报错表逐条排查。
