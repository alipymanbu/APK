## 一、分卷是什么、为什么只解压第一个

大文件一次传不完，就被切成一串编号连续的小包：

```text
xxx.part1.rar
xxx.part2.rar
xxx.part3.rar
xxx.part4.rar
```

也可能长这样：`xxx.7z.001` / `xxx.7z.002`，或者 `xxx.zip` + `xxx.z01` + `xxx.z02`。**它们是一个文件的碎片，不是四个独立的包。**

解压规则就一条：**所有分卷放进同一个文件夹，右键第一个（part1 / 001 / 主文件），选「解压到当前文件夹」**——解压软件会自动按编号把后续分卷接上去。不要逐个解压，也不要只解压其中一个就以为完了。

## 二、解压前的三个检查

按顺序过一遍，能挡掉九成报错：

1. **下齐了没有**：对照详情页/网盘里标注的文件数与总体积数一遍，缺一卷必然解压失败；文件名后缀还是临时下载状态（说明没下完）的，先下完；
2. **文件名改没改**：分卷**一个字都不能改名**，序号乱了软件就接不上；要整理就整个文件夹一起移动；
3. **是不是都在一起**：所有分卷必须在同一个文件夹里，散落在下载目录各处的先归拢。

## 三、解压步骤（电脑端）

1. 装一个解压软件：`.zip` Windows 自带就能解；`.rar` / `.7z` 需要第三方软件（WinRAR、7-Zip 这类都行）；
2. 右键**第一个分卷** → 解压软件菜单里选「解压到当前文件夹」或「解压到 xxx\」；
3. 弹出密码框时输入解压密码——**区分大小写，照抄别手打**；带密码的分卷只需输入一次，软件会自动用于后续所有卷；
4. 等进度条走完，得到的就是完整的原始文件/文件夹。

**网盘的「在线解压」不要依赖**：它对格式、体积常有限制，还可能因网络中断半途失败。统一做法是**先完整下载到本地，再用本地解压软件解压**——加密包、分卷包都不受在线解压那套限制。

## 四、手机端解压

1. 确认所有分卷已下载到手机同一目录（夸克/文件管理器的下载目录）；
2. 主流国产安卓的文件管理器自带解压：点第一个分卷 → 解压 → 输入密码；
3. 提示「无法打开该格式」时，装一个支持 RAR/7Z 的解压应用再试；
4. 大体量游戏建议在电脑上解压完再传回手机，手机端处理几十 GB 容易因内存不足中断。

## 五、报错对照表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 「分卷损坏」「Unexpected end of archive」 | 缺卷 / 某卷没下完 / 文件名被改 | 核对文件数与体积，补齐后重解（第二节） |
| 「密码错误」 | 提解压密码时大小写输错，或误把提取码当解压密码 | 回详情页重新复制密码，逐字符核对 |
| 「未知的数据格式」/ 打不开 | 系统/软件不支持该格式 | 换 WinRAR、7-Zip 等支持 RAR/7Z 的软件 |
| 解压到一半报错停住 | 网盘在线解压中断，或本地网络中断 | 改成本地完整下载后解压（第三节） |
| 解压出来是另一个压缩包 | 资源是「套娃」压缩 | 对内层包再解一次，直到出现安装文件或普通文件 |

彻底排除后仍失败，多半是文件本身下残了——回[游戏搜索与下载方法.md](游戏搜索与下载方法.md)的流程重新获取一遍链接再下载；应用自身的问题（打不开、闪退）见[常见问题与解决方法.md](常见问题与解决方法.md)。

## 六、解压成功长什么样

解压完成后你会看到实际内容：可能是游戏本体数据、说明文件，也可能套着下一层压缩包（继续解到出现能直接用的文件为止）。确认内容能正常打开后，分卷压缩包可以整组删除腾空间——**要留就整组留，别只留一半**。如果你解出来的是一个 `.apk` 安装包，那就是应用本身的安装文件，装机步骤见[下载与安装教程.md](下载与安装教程.md)第三节。
