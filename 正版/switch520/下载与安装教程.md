几个点提醒你：

- **包名是应用的身份证**。以后升级、覆盖安装、排查冲突，看的都是包名而不是图标和名字——`com.x520switch.app` 这一串才是 switch520。

- 网上第三方下载站标注的版本与系统要求五花八门（有的写需要安卓 8.0），以你手里这份安装包与官方页面为准。

大文件下载建议在 Wi-Fi 下进行，中途断流会导致包不完整（装不上、装上闪退都可能由它引起）。

## 三、安装步骤（安卓）

安卓默认不允许安装「未知来源」的应用，第一次装需要手动开一次：

1. 把 APK 文件传到手机，用文件管理器点它；
2. 系统弹出「禁止安装未知来源应用」时，按提示进入**设置 → 安全/隐私 → 允许安装未知应用**，给当前这个来源（文件管理器或夸克）打开开关；
3. 返回后再次点击 APK，确认安装；
4. 安装完成后先别急着打开，可以先核对一下 MD5（下一节）；
5. 首次启动会申请网络等常规权限，按需允许即可。

之后版本更新时，用新的安装包**覆盖安装**即可——包名相同（`com.x520switch.app`）会直接升级，不用先卸载。**先别卸载再装**：卸载会清掉应用内的本地数据，账号类数据（收藏、记录）能不能跟着账号走，见[常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、用 MD5 核对安装包

MD5 是文件的「指纹」，32 位十六进制，文件有一个字节不同结果就全变。核对方法任选一种：

- **手机**：装一个 MD5 校验类工具（应用商店搜「md5」），选中 APK 文件计算，与 `3704A420C8349C0FE677A6691E58AC72` 逐字符比对；
- **电脑（PowerShell）**：

```powershell
Get-FileHash .\switch520_v1.1.2.apk -Algorithm MD5
```

输出的 `Hash` 值转大写后与上表一致即为完整文件。

比对不上，只说明**你下载的这份不完整或被改动过**，解决办法就是重新下载（见第二节），不要继续安装来源不明的同名包。

## 五、装不上、装上就闪退怎么办

按出现顺序排查，前三条覆盖了绝大多数情况：

1. **下载是否完整**——先做第四节的 MD5 比对，不对就重下；
2. **系统版本是否达标**——安卓 5.2 以下装不了（设置 → 关于手机里查看）；
3. **存储空间是否够**——15.93 MB 的包本身不大，但安装解压与首次启动缓存需要额外余量，建议预留 200 MB 以上；
4. **是否与旧版本冲突**——装过旧版且反复覆盖失败时，先卸载再装（注意第三节的数据提醒）；
5. 还是不行，把报错原文对照[常见问题与解决方法.md](常见问题与解决方法.md)里的条目逐条排查。
