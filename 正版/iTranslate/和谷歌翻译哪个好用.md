## 一、两款应用的底子

| | iTranslate | 谷歌翻译 |
| --- | --- | --- |
| 支持语言 | 100+ | 明显更多（第三方口径 130 到 249 不等，2024 年起谷歌大幅扩充） |
| 免费范围 | 文字翻译、词典、短语本 | 基本全功能免费 |
| 订阅 | Pro（第三方评测多写为每月 5 美元上下，以 app 内订阅页为准） | 无订阅（API 收费与个人使用无关） |
| 与系统集成 | 独立 app，另提供键盘扩展 | 与安卓系统、谷歌生态深度集成 |

上表是截至 2026-09 的公开资料口径，两边都在持续更新，以各自官方页面为准。

## 二、五个维度怎么分

**语言覆盖**：查小语种、冷门语言，谷歌翻译覆盖面更宽；iTranslate 的 100 多种覆盖主流语言，日常与旅行场景基本够用。

**离线**：两家都有离线包，门槛不同——iTranslate 的离线锁在 Pro 里（语言包设置见[离线翻译设置方法.md](离线翻译设置方法.md)），谷歌翻译的离线包免费下载。常年出境的用户把这点算进成本里。

**语音对话**：多个第三方评测把 iTranslate 的语音模式列为强项——男女声可换、语速可调、支持音译；谷歌翻译的对话翻译同样可用，在 Pixel 等机型上还有系统级的实时翻译加成。

**相机**：两家都能拍菜单拍路牌。谷歌的实时取景叠加更成熟；iTranslate 的相机翻译（官方称 Lens）支持调整取景框限定识别范围，另有扫物体的 Object 模式。

**数据与账号**：iTranslate 已不再提供账号注册与登录（官方支持页 2025-09 的口径），收藏与历史只保存在本机；谷歌翻译跟谷歌账号走，跨设备更省事。

## 三、按场景给判据

| 你的情况 | 更顺手的选择 | 原因 |
| --- | --- | --- |
| 只查词、翻句子 | 哪个都行 | 两边免费功能都够 |
| 常年出境、弱网多 | 算一笔账再定 | 谷歌离线免费；iTranslate 离线要 Pro 但语音更细 |
| 主要靠开口对话 | iTranslate | 语音模式是它打磨最多的部分 |
| 小语种、冷门语言多 | 谷歌翻译 | 覆盖面差距明显 |
| 换手机频繁、多设备 | 谷歌翻译 | 账号同步 vs 本机数据 |
