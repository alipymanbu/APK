## 一、你的数据存在哪

按官方说明，归档数据库、媒体缓存和导出文件都保存在当前设备上——数据库与缓存在应用数据目录，导出文件在你选择的位置。它们不会自动上传到任何服务器，应用也没有账号系统和云端副本。

这带来两个直接后果：

- **卸载或清理应用数据，等于删掉归档**。动手前先确认 HTML 导出件已经另存（导出方法见 [HTML导出与离线浏览方法.md](HTML导出与离线浏览方法.md)）；
- 换手机时归档不会自动跟过去，需要你手动把导出文件复制到新设备；
- 归档数据库本身的跨设备迁移，官方没有提供说明；跨设备可靠的载体是导出的 HTML 文件，不要指望直接搬数据库。

## 二、登录凭证怎么被使用

登录时应用通过 Cookie 与 QQ 空间建立会话，凭证仅用于当前会话。官方给出的几条规则你要记住：

1. 不在不受信任的设备上登录；
2. 不把 Cookie、数据库文件或导出文件发给陌生人；
3. 只备份本人账号或已获明确授权的账号资料。

## 三、项目已停止维护，这对你意味着什么

官方仓库在 2026 年 9 月 4 日发布公告：停止开发、修复与技术支持，历史版本不再保证能正常运行（背景与版本核对见 [下载与安装教程.md](下载与安装教程.md)）。落到使用上是三件事：

- **不会再有官方新版本**。任何渠道出现"新版""修复版"，一律不要下载——官方公告专门提醒过，已有因使用非官方来源软件导致账号信息泄露的情况；
- 出了问题没有官方渠道可求助，重要资料务必额外备份：定期导出 HTML，存到受信任的存储介质；
- 项目历史代码按 GPLv3 授权，这只是授权方式的说明，不代表有人在继续维护它。

## 四、一份按时机执行的安全清单

| 时机 | 做什么 |
| --- | --- |
| 安装前 | 核对安装包版本与 MD5（见 [下载与安装教程.md](下载与安装教程.md)），只用官方历史发布版本 |
| 登录时 | 只在自己的设备上登录；归档期间保持当前 QQ 会话稳定 |
| 归档后 | 先核验归档范围（见 [归档范围与内容限制.md](归档范围与内容限制.md)），再尽快导出 HTML 并另存一份到其他设备 |
| 卸载 / 清数据前 | 确认导出文件已备份且能正常打开 |
| 长期 | 定期检查备份文件是否还能打开；导出文件含他人昵称与评论，公开前先脱敏 |
