## 一、装之前先知道的三件事

QzoneArchive 是一个开源的 QQ 空间本地归档工具，你用它登录自己的 QQ 账号后，可以把空间里的动态、照片、视频、评论和留言备份到设备本地，再导出成浏览器能直接打开的 HTML 文件。它有 Windows、macOS、Linux 桌面版和安卓版，本篇只讲安卓版。

1. **项目已停止维护**：官方 GitHub 仓库（[github.com/Gaoshu705/QzoneArchive](https://github.com/Gaoshu705/QzoneArchive)）在 2026 年 9 月 4 日发布公告，宣布停止一切开发与维护。已发布的版本仍可使用，但之后不会再有官方修复或更新。
2. **别找"新版"**：官方公告里明确提醒，不要从第三方渠道下载所谓的新版、修复版或衍生版本——曾有因使用非官方来源软件导致账号信息泄露的情况。要用，就用官方历史发布过的版本。
3. **官方文档站仍可访问**：安装与使用说明见 [fox2043.github.io/QzoneArchive](https://fox2043.github.io/QzoneArchive/)，本篇与它口径一致。

还没决定用哪个工具做备份的，先看 [QQ空间备份工具怎么选.md](QQ空间备份工具怎么选.md)。

## 二、核对你要装的是哪个版本

从 [QzoneArchive 安装文件资源（夸克网盘）](https://pan.quark.cn/s/da7ac7d0f816) 转存后下载得到的安装包，信息如下：

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.0.3 |
| 包名 | top.ehre.qzonearchive |
| 安装包大小 | 约 31.08 MB |
| MD5 | 7eee1605b41e3c0c20774cb11bb7e58e |

系统要求方面，官方发布页标注安卓版适用于 Android 8 及以上（arm64 架构），以官方页面当时的说明为准。

想在安装前核对文件没被改动过，可以把安装包传到电脑上算 MD5：Windows 在命令提示符里执行 `certutil -hashfile 文件路径 MD5`，macOS 与 Linux 用 `md5sum 文件路径`，结果与上表一致即可。

如果你在别的渠道看到更高的版本号，先回官方仓库确认——项目已停更，任何"更高版本"都值得怀疑。

## 三、安装步骤

1. 把安装包下载到手机存储；
2. 在文件管理器里点开 `.apk` 文件，系统提示"是否允许安装未知来源应用"时按提示允许；
3. 等待安装完成，打开应用。

部分手机系统的授权入口不完全一样：

| 系统 | 常见路径（以手机实际设置为准） |
| --- | --- |
| 小米 / MIUI | 安装弹窗内直接授权 |
| 华为 / 鸿蒙 | 设置 → 安全 → 更多安全设置 → 外部来源应用下载 |
| 原生类系统 | 安装弹窗 → 设置 → 允许来自此来源的应用 |

## 四、装完之后

首次打开会先看到免责声明，确认后进入登录页。接下来的扫码登录与归档操作见 [扫码登录与首次归档步骤.md](扫码登录与首次归档步骤.md)；动手归档前建议先看一眼 [归档范围与内容限制.md](归档范围与内容限制.md)，里面说明了一条最常见的疑问：没有被点赞或评论过的动态可能无法归档。
