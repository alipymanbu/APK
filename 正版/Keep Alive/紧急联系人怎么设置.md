## 一、警报触发时到底会发生什么

「Are you there?」通知没人确认之后，应用按你配置的紧急联系人逐项执行，全部由手机本机完成：

- 给**每个短信联系人**各发一条你写好的警报消息；
- 对开启了「包含位置」的联系人，**补发第二条**带位置信息的短信；
- 配置了电话号码的话，**拨出电话并自动开免提**；
- 配置了 Webhook 的话，向你填的 URL 发一个 HTTP 请求（1.3.2 已支持）。

可以只配短信、不配电话；短信联系人也可以加多个。

## 二、短信联系人的四个字段

| 字段（英文标签） | 填什么 | 注意 |
| --- | --- | --- |
| 电话号码 Phone Number | 紧急联系人的手机号 | 演练期先填自己的另一个号码；正式配置时优先挑**住得近、能真的上门**的人 |
| 名称或关系 Name or Relationship（可选） | 如「女儿」「邻居老王」 | 只在应用列表里帮你认人，不会发进短信 |
| 警报消息 Alert Message | 触发时发出的短信内容 | 写法见下一节 |
| 包含位置 Include Location | 开关 | 开启后补发位置短信；需要系统定位服务开着，没开时主界面会显示 Location Services Off 警告 |

「包含位置」依赖精确定位与后台定位权限，按应用内提示授全即可（权限清单见[权限与后台设置注意事项.md](权限与后台设置注意事项.md)）。

## 三、警报消息怎么写

收短信的人第一反应多半是「这是啥、真的假的」。消息要替他省掉这三步疑问：

```text
我是张三。这条短信是我的手机自动发出的：手机已超过设定时间没有任何操作，
我可能失去了意识或行动能力。请先打我电话，打不通请尽快安排人来家看看。
```

要点：

- **写明是手机自动发出**——避免被当成垃圾短信或恶作剧忽略掉；
- **写明「超时未操作」意味着什么**——人可能出事，也可能只是误报，让对方先电话确认；
- **给出明确的下一步**——先打电话、再上门，顺序写清楚；
- 不用写家庭住址——开了「包含位置」，位置会通过第二条短信单独发过去；
- 收件人是长辈时，用他们习惯的说法，别写「触发警报」这类术语。

## 四、免提电话与 Webhook

- **电话号码（Phone Call Number）**：填了就在警报触发时拨出、并自动开免提。免提是让在场的人能听见、也方便对方喊话确认——接通后，对方听到的是你手机所在环境的声音。这一项需要「拨打电话」权限。
- **Webhook（Alert Webhook）**：警报触发时向自定义 URL 发送 HTTP 请求，适合接进你自己搭的通道，比如家庭通知群、自动化平台。1.3.2 已支持；请求格式以你手上版本的界面提示与官方文档为准。

## 五、配完之后

紧急联系人不是配完就完事：跟[监测参数怎么设置.md](监测参数怎么设置.md)里的演练流程连起来，完整触发一遍（短信先发给自己），确认消息内容、位置短信、电话都按预期工作，再把收件人换成真实联系人。发送失败与费用的情形，在[常见问题解答.md](常见问题解答.md)里有展开。
