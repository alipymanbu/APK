## 一、这套文档写给谁

TouchRetouch 是一款安卓端的照片修图工具，专门做一件事：把照片里多余的东西去掉——路人、电线、垃圾桶、脸上的瑕疵都算。它不是带滤镜调色的综合编辑器，界面也只有底部那几个工具按钮。本篇只讲怎么把安装文件装到手机上并确认装对了版本；装好之后怎么用，看同目录的另外几篇。

## 二、先拿到安装文件

打开 [TouchRetouch 安装文件资源（夸克网盘）](https://pan.quark.cn/s/23a7f14f479d)，转存后进入 **TouchRetouch（先保存再下载）** 文件夹，里面是一个 APK 文件，命名格式是 `TouchRetouch_v5.0.apk`。这是**安装文件**本身，不是快捷方式，把它下载到手机本地即可安装。

如果你要在手机上直接下载，先在手机浏览器或夸克 App 里打开分享链接并转存到自己的网盘，再从网盘里下载该 APK 到本机——不要只留在在线文件列表里，安装器读的是本机文件。

## 三、安装步骤

1. 把 APK 文件下载到手机存储（下载目录即可）。
2. 用手机自带的文件管理器点这个 APK。
3. 系统如果弹出「禁止安装来自此来源的应用」，这是正常的拦截——安卓默认只允许应用商店装包。点提示里的**设置**，为该来源（文件管理器或浏览器）打开「允许安装」开关，再返回继续安装。
4. 安装完成后点「打开」，或回到桌面找 TouchRetouch 图标。
5. 首次启动会请求相册访问权限——它需要读你手机里的照片才能编辑，允许即可；拒绝的话你只能用它自带的示例图。

装完后那条渠道开关建议关回去（设置 → 安全/隐私 → 安装未知应用），不影响已装应用的使用。

## 四、核对装的是不是这个版本

安装前后都可以核对。网盘里这份包的固定信息如下，以它为准：

| 项目 | 值 |
| --- | --- |
| 版本 | 5.0 |
| 包名 | `com.advasoft.touchretouch` |
| 安装包大小 | 63.57M |
| MD5 | `98F80D41E81B7C088F96E3CAFB4ECAF5` |
| 采集于 | 2026-09-23 |
| 系统要求 | 安卓 5.2 及以上 |

核对方式：

- **看包名**：手机「设置 → 应用 → 已安装应用 → TouchRetouch → 应用信息」里，较新的系统会直接显示版本号与包名；也可以用任意「应用信息查看」类工具读包名，必须是 `com.advasoft.touchretouch`。
- **看版本号**：应用内的「关于」或设置页会显示版本，应为 5.0。官方后续会发新版本，界面上显示比 5.0 新属正常，**以官方页面当时显示为准**。
- **看 MD5**（可选）：把手机上的 APK 传回电脑，用 `certutil -hashfile TouchRetouch_v5.0.apk MD5`（Windows）算一遍，与表里一致即同一份文件。

包名对不上说明下错了文件；版本对不上则可能是官方更新了，两个情况都别混着用。

## 五、装不上或打不开

安装被拦、装完闪退、打开后相册是空的，这几类问题各有原因，逐条排查见 [常见问题与支持格式.md](常见问题与支持格式.md)。

另外，官方在应用内置了视频教程（首页的 Tutorials 入口），第一次用建议先看一遍再动手；工具具体怎么点，见 [怎么去除照片里的多余物体.md](怎么去除照片里的多余物体.md)。
