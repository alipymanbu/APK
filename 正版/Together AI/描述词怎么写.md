# 描述词怎么写：让生成结果更贴你的想法

> 文生视频、图生图片都要写描述词。这篇只讲一件事：怎么把一句话写成一份「主体 + 动作 + 场景 + 风格」俱全的描述词，以及结果不满意时先改哪一段。

## 一、四个要素，缺一样就丢一样

AI 生成只认你写出来的字。描述词里四样东西各占一句短语，拼起来就是一份够用的描述：

| 要素 | 回答的问题 | 示例 |
| --- | --- | --- |
| 主体 | 谁或什么在画面里 | 一只橘猫、穿红裙的女生、一辆复古自行车 |
| 动作 | 主体在干什么 | 在雪地里打滚、回头微笑、沿街道骑行 |
| 场景 | 在哪、什么时间 | 夜晚的城市街头、阳光下的麦田 |
| 风格 | 什么质感 | 暖色调胶片感、动漫风、特写镜头 |

四个要素不用写成完整句子，逗号隔开的短语串更好用。

## 二、模糊与具体的对照

同一件事，两种写法拿到的东西差别很大：

| 模糊写法 | 具体写法 |
| --- | --- |
| 可爱的猫 | 一只橘猫在窗台上伸懒腰，午后阳光，特写镜头 |
| 城市夜景 | 雨后的城市街头，霓虹灯反光，缓慢推进的镜头 |
| 帅气的动作 | 穿黑色皮衣的人回头，慢动作，电影感打光 |
| 风景视频 | 横向构图的山谷清晨，云雾缓慢流动，航拍视角 |

规律就一条：**你脑子里有画面，就把它拆成四个要素写出来；写不出来，生成的也只能赌。**

## 三、结果不满意时，先改对应的那段

生成的结果和预期不符时，别整句推倒重来，对着问题改对应要素：

- **主体不像**（猫变成狗、人物面目不清）→ 改**主体**：写清数量、颜色、外观特征；
- **动作怪或太快太慢** → 改**动作**：把动词换成更日常的描述（「缓慢摇头」「轻轻跳动」），少用夸张修饰；
- **背景乱飞** → 改**场景**：场景只留一个，别一句话塞两个地点；
- **质感不对**（像截图不像视频、色调难看）→ 改**风格**：点名镜头感（特写/远景/推进）和色调（暖/冷/胶片）。

改一段生成一次，比全句重写快得多，也更容易知道是哪部分起效。

## 四、不想写词，就走模板

描述词这套是给「自己有想法」的人用的。没想法时直接用模板：主题分类里挑（节日、写真、情侣、变身等），点开上传自己的素材就能出结果，具体见[怎么用三种生成模式.md](怎么用三种生成模式.md)第六节。生成总失败或效果一直不对时，排查方向见[常见问题与解决思路.md](常见问题与解决思路.md)。
