## 一、这个功能解决什么问题

你在电脑上让 Agent 跑一个长任务（深度研究、搭应用、改代码），人要离开座位 —— 远程控制让你用手机接着盯：看进度、补指令、批权限，不用守在电脑前。项目文件、终端和运行环境**始终留在电脑上**，手机只是一个轻量的控制入口，不把任务搬到手机上跑。

## 二、使用前要备齐的三样东西

| 条件 | 说明 |
| --- | --- |
| 手机 App 是 4.20 或更新版本 | 这是远程控制上线合作的版本，旧版没有这个入口 |
| 电脑上装有桌面端 Agent（MiniMax Code） | 支持 macOS 12 及以上、Windows 10 及以上；下载入口 `https://agent.minimaxi.com/download` |
| 两端登录同一账号，桌面端保持运行 | 远程控制是桌面端发起的能力，电脑端退出或关机，手机就连不上 |

手机还没装 App 的话，先用这份 [MiniMax 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a1cba70f2953) 把 App 装好。

## 三、怎么绑定

按官方文档的说明，绑定动作在**电脑端**发起：

1. 电脑上打开 MiniMax Code，确认已登录、正在运行；
2. 打开 Remote Control（远程控制）入口；
3. 按页面提示完成手机端的绑定（通常是扫码或确认配对，以页面当时显示为准）；
4. 绑定完成后，手机端会保持与桌面端会话的连接。

## 四、绑完之后手机能干什么

把官方文档和应用商店更新说明列的能力汇总成一张表：

| 你在手机上能做 | 对应场景 |
| --- | --- |
| 查看桌面端任务进度 | 长任务跑到哪一步了，一眼看到 |
| 查看 Agent 回复、终端输出、代码改动、测试结果 | 不开电脑也能了解任务细节 |
| 查看任务产物和部分文件内容 | 生成的文档、网页等产品直接翻 |
| 发送补充指令 | 中途想起新要求，随手补进去 |
| 回应提问、处理权限审批 | Agent 卡在「等你确认」的环节时，手机上放行 |

## 五、几个使用要点

- **电脑端不能关**：运行环境在电脑上，合盖休眠、断网、退出登录，手机端连接就断了。离开前把电脑电源设置改成「接通电源时不休眠」更稳；
- **审批别攒着**：Agent 停下来等权限确认时整段任务是停摆的，手机上看到待审批尽快处理；
- **绑定关系可解**：不用了在桌面端解除绑定即可，不影响两端各自单独使用。

绑定不上、连上又掉线这类问题，先看[常见问题与解决办法](常见问题与解决办法.md)；日常任务怎么下达到 Agent，见[日常使用场景与技巧](日常使用场景与技巧.md)。
