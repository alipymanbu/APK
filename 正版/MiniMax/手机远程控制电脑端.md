## 一、这个功能解决什么问题

深度研究、网页应用构建这类任务一跑就是几分钟到几十分钟，人不可能一直守在电脑前。2026 年 9 月的 4.20 版本起，App 增加了远程控制：电脑上的桌面端 Agent 继续干活，手机作为轻量控制入口——任务进度、终端输出、代码改动都能在手机上看，需要你拍板时在手机上点一下就行。

两端的分工是：项目文件、终端和运行环境都留在电脑上不动，手机只负责「看进度、发指令、批权限」。

## 二、用之前要备齐两样东西

| 端 | 要求 | 去哪拿 |
| --- | --- | --- |
| 手机 | MiniMax App 4.20.0 或更高版本 | 本页顶部的 MiniMax 安装文件资源（夸克网盘）里就是 4.20.0；更新版见[官方下载页](https://chat.minimaxi.com/download) |
| 电脑 | 桌面端 MiniMax Code 已安装、已登录同一账号、保持运行 | [code.minimaxi.com/download](https://code.minimaxi.com/download) |

注意账号要一致：手机和电脑登录的是同一个账号，绑定才找得到彼此。

## 三、连接步骤

1. 电脑上打开 MiniMax Code，确认已登录并停在主界面；
2. 在桌面端找到 Remote Control 入口（远程控制）；
3. 按页面提示完成手机端绑定（一般是扫码或输码确认，以页面显示为准）；
4. 绑定完成后，手机与桌面端会话保持连接，任务动态会推到手机上。

之后你在电脑上下发一个长任务（比如做一份行业调研），锁屏出门，路上用手机看它跑到哪一步、中途补一句要求、弹出权限确认时在手机上批掉，回到电脑前产物已经在了。

## 四、手机端能做的四件事

- **查看任务进度**：Agent 回复、终端输出、代码改动、测试结果随时刷新可见；
- **发送补充指令**：任务跑一半想到新要求，直接在手机上发；
- **回应提问**：Agent 中途向你提问时，在手机上回答，任务不用等；
- **处理权限确认**：涉及敏感操作（如安装依赖、改动文件）的审批弹窗，手机上放行或拒绝。

手机端看不了的部分也明确：完整的编辑、调试还是要回电脑上做，手机不是替代桌面端，是让你离开电脑时任务不停摆。

## 五、连不上时的排查顺序

| 现象 | 按顺序检查 |
| --- | --- |
| 绑定页扫不上 | 两端是否登录同一账号；电脑端 MiniMax Code 是否在线 |
| 绑定成功但收不到进度 | 电脑是否休眠（休眠会断连，把电源设置里的休眠关掉）；手机网络是否正常 |
| 手机端发送指令没反应 | 电脑端是否被手动退出；重新绑定一次 |
| 突然全部断开 | 电脑端更新重启了，等它起来后重连 |

还有一条路径可以不用守在电脑前：桌面端支持定时任务与 IM 连接（把结果推送到聊天软件），适合「每天固定跑一次」的重复任务，入口在桌面端同一片功能区，配置以官方文档为准（[远程控制文档](https://agent.minimaxi.com/docs/code/automation/remote-control)）。
