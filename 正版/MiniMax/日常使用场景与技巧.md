## 一、先分清两类活：对话类和 Agent 任务类

你打开 App 之后面对的是一个对话框，但两类活的用法不一样：

| 类型 | 适合的事 | 交互方式 |
| --- | --- | --- |
| 对话类（高效模式） | 问答、翻译、写作、文档总结、识图 | 你一句它一句，当场出结果 |
| Agent 任务类 | 深度研究、做演示文稿、搭全栈应用、写代码、多模态内容生成 | 下达任务后它自主规划执行，交付最终成果 |

官方介绍把能力分成高效模式与深度任务两档；有第三方资料称界面提供「高效 / 专业」双模式切换，入口叫什么以 App 内实际显示为准，日常轻活用默认的对话模式即可。下面按场景分别说。

## 二、日常问答、写作与翻译

输入框直接打字就能用。几个省时间的做法：

- 输入框下方的快捷入口（如帮我识图、帮我写作、帮我翻译、文件总结）比空口描述需求更快，点对应功能后按提示给素材；
- 对结果不满意时，用回答旁的「重写」让它换一版，而不是重新描述一遍需求；
- 一段对话聊偏了就新开一个会话，不同主题分开管，回头找记录方便。

## 三、文件、图片处理

- **文档总结**：把 PDF、Word 等文件传进对话，让它摘要点、列结论。上传文件需要授予存储 / 相册权限，权限处理见[注册登录与账号管理](注册登录与账号管理.md)第四节；
- **识图**：拍照或从相册选图发给它，可以问图中内容、转录文字、看懂图表。拍出来的图手抖、字太小，识别质量会明显下降，尽量拍清楚。

## 四、语音交互

点输入框旁的语音入口说话即可。首次使用会请求麦克风权限。适合走路、开车手不方便的场景；环境嘈杂时识别会出错，重要内容用键盘输入更稳。

## 五、Agent 任务：让它们自己跑

官方应用商店页列出的 Agent 能力包括这几类，都是「你给目标、它交付结果」的用法：

| 能力 | 你给什么 | 它交付什么 |
| --- | --- | --- |
| 深度研究与分析 | 一个研究主题 | 整合全网信息的深度研究报告 |
| 专业演示文稿 | 主题与素材要求 | 成型的 PPT |
| 全栈应用构建 | 应用需求描述 | 覆盖前端到后端的应用 |
| 代码编写与调试 | 代码需求或报错代码 | 可用的代码与测试 |
| 多模态内容生成 | 画面 / 声音要求 | 视频、音频、图片素材 |

用 Agent 任务的两点经验：

- 需求写得越具体（受众、篇幅、风格、交付格式），返工越少；
- 任务跑得越久越要盯进度提示，需要你确认的环节它会停下来问你。

## 六、手机远程控制桌面端 Agent（4.20 版新增）

从 4.20 版开始，手机 App 可以直接连接电脑上运行的桌面端 Agent：项目文件、终端和运行环境仍留在电脑上，手机作为轻量控制入口 —— 随时看 Agent 回复、终端输出、代码改动和测试结果，需要介入时在手机上发指令、回应提问、处理权限审批。

典型用法：人离开电脑（吃饭、通勤）时，用手机盯着电脑上正在跑的长任务，该批权限批权限，不用回座位。绑定步骤、两端各自的条件和注意事项单独整理在[手机远程控制电脑端](手机远程控制电脑端.md)。

## 七、对话记录管理

- 回答可以复制、分享出去，格式会保留；
- 不同主题分会话存放，历史列表里按会话找；
- 涉及个人敏感信息的对话，结束后自己删掉会话更稳妥。

遇到回答中断、闪退之类的问题，直接翻[常见问题与解决办法](常见问题与解决办法.md)。
