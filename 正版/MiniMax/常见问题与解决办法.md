## 一、安装报错：解析包失败 / 安装中断

按这个顺序排查：

1. **校验文件完整性**：对照[下载与安装教程](下载与安装教程.md)第二节的 MD5 重新算一遍，不一致说明下载不完整，删掉重新下载（校验方法也在那一篇里）；
2. **存储空间**：手机剩余空间比安装包大小还小时装不上，清出空间再装；
3. **未知来源**：确认已允许你的文件管理器 / 网盘 App「安装未知应用」，而不是只允许浏览器；
4. **旧包覆盖失败**：如果手机里已有一版且签名信息对不上，先卸载旧的再装。

需要重新拿安装包时，用这份 [MiniMax 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a1cba70f2953)。

## 二、收不到短信验证码

1. 先等 60 秒再点重发，运营商短信通道有延迟，连点反而更容易被风控拦下；
2. 检查手机是否开了短信拦截 / 骚扰过滤，翻一下拦截记录；
3. 换网络环境试试（关 Wi-Fi 用流量，或反过来），部分风控策略按网络出口判定；
4. 长期收不到这个运营商的短信，考虑改用「一键登录」（手机卡在本机时）或第三方账号方式，见[注册登录与账号管理](注册登录与账号管理.md)第一节。

## 三、权限之前拒绝了，现在想打开

去系统「设置 → 应用 → MiniMax → 权限」逐项打开对应权限即可，不用重装。各权限分别影响什么功能，看[注册登录与账号管理](注册登录与账号管理.md)第四节的对照表。

## 四、回答到一半断了 / 一直转圈

1. 先看手机网络是否可用，切换 Wi-Fi 与流量各试一次；
2. 长对话内容很长时，出现中断可以新开一个会话继续，把关键结论复制过去；
3. Agent 类长任务中断后，重新下达时把已完成的进度说明白，避免从头再来。

## 五、MiniMax 是谁家的产品

开发者是**上海稀宇科技有限公司**（即 MiniMax 公司自己），不是套壳的第三方。有第三方资料提到国内安卓端此前以「海螺AI」名义发布、后整合更名为 MiniMax App，这一说法以官方页面为准；你在应用商店认准开发者名称就不会认错。

名字上还有一个容易混淆的点：现在应用商店里同时存在「MiniMax」和「海螺AI」两个 App，同属一家公司但主打方向不同，搜错了会装到视频创作那个去。两者的对应关系和区分办法单独写了一篇：[与海螺AI是什么关系](与海螺AI是什么关系.md)。

## 六、收费吗

- App 免费下载，**带 App 内购项目**（App Store 页面标注「免费 · App 内购买」）；
- 日常对话、问答等基础用法不付费就能用；
- 有第三方资料提到存在会员方案（如更高清晰度渲染、商用授权等），具体项目与价格以 App 内订阅页当时显示为准，此处不写死数字。

## 七、想升级到新版本

官方更新很频繁（应用商店里小版本几乎每周都发）。升级走官方渠道最直接：iOS 在 App Store 更新；安卓在官网下载页 `https://chat.minimaxi.com/download` 拿最新安装包，覆盖安装即可，对话记录在登录同一账号后保留。
