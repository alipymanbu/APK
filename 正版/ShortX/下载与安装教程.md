## 一、ShortX 是什么

ShortX 是一个安卓自动化工具，官方把它定义为 Xposed 模块：你用它建「一键指令」（按一下连做一串动作）和「自动指令」（满足条件自动执行），思路接近 iOS 的快捷指令或 Tasker，但它走的是系统级触发器，能抓界面、通知、前后台这类系统事件。开发者是 Tornaco（同一位作者也开发了 Thanox）。它不适合所有手机 —— 前提是你的设备已经 Root 并装好 Xposed 框架，本篇就讲怎么把这套环境装起来并激活。

## 二、安装前先确认三件事

| 条件 | 怎么确认 | 缺了会怎样 |
|---|---|---|
| 已 Root | 装有 Magisk、KernelSU 或 APatch 任意一种 | Xposed 框架装不上，ShortX 无法激活 |
| Xposed 框架 | 推荐 [LSPosed](https://lsposed.org/)，在它的管理器里能看到模块列表 | 模块没有可勾选的地方 |
| 系统版本 | 官方商店页面标注 Android 8.0 及以上（以官方页面当时显示为准） | 过旧的系统可能装不上或运行不正常 |

三个条件缺一不可。网上有「不用 Root、挂个 Shizuku 就能用」的说法，与官方文档对不上 —— 官方文档写明 ShortX 目前仅支持基于 Xposed 激活，别按那条路折腾。

## 四、安装与激活步骤

官方文档给出的激活流程是四步，顺序不能乱：

1. 安装下载好的 APK（正常点击安装即可）。
2. 打开你的 Xposed 管理器（如 LSPosed），在模块列表里找到 ShortX，**勾选「Android 系统」和「System UI」这两个作用域**。
3. 重启设备。
4. 重启后打开 ShortX，能看到指令界面即说明激活成功。

最容易漏的是第 2 步的作用域勾选 —— 只装了 App、没勾作用域，重启后 ShortX 打得开但什么自动化都执行不了。装完遇到不生效的情况，直接看 [常见问题与激活失败排查.md](常见问题与激活失败排查.md)。

## 五、免费版和完整版是怎么分的

官方有两条发布线，装之前先弄清楚手里是哪个：

- **免费版**：从 GitHub 发布页获取，功能有范围限制；
- **完整版**：在 Google Play 商店付费购买，功能完整。

官方没有公开一份「免费版少了哪些功能」的对照清单，具体差异以应用内提示为准。另外有用户反馈 GitHub 上归档的版本更新节奏比商店慢，也就是说两边的版本号可能对不齐 —— 你要以哪边为准，取决于你用的是哪条渠道的包。
