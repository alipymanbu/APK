# Simpler 常见问题与排查

> 本篇按"现象 → 原因 → 处理"整理 Simpler 使用中最常遇到的几类问题：装不上、没声音、会员不生效、进度丢失、界面语言不对、输入题判错、提醒关不掉。

## 一、先做一个能解决大半问题的动作

遇到任何异常，先确认两件事，再往下查：

1. **版本是不是太旧**。本套文档对应的是 6.5.25。Simpler 的更新记录里，能看到多次针对具体故障的修复，例如订阅激活异常（6.5.23 修复）、部分地区证书下载失败（6.5.21 修复）、完成级别后证书领取异常（6.5.24、6.5.25 修复），以及多轮"修复若干错误、提升稳定性"。**升级到较新的版本，往往就绕过了你正遇到的问题**。
2. **网络是否可达**。语法题库、音频、订阅状态都要联网获取，先确认网络通不通，再怀疑应用本身。

## 二、安装相关问题

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示"解析包时出现问题" | 安装包没下完整 | 删掉本地文件重新下载；重新下载后比对 MD5 是否为 `01EBEC8092D4B7F1C832723E191A65AE` |
| 提示"应用未安装" | 手机里已装了签名不同的同名应用 | 先卸载旧的那个 Simpler，再装这一份；卸载前确认进度已登录账号同步 |
| 点了 apk 没反应 / 被系统拦下 | 没允许该来源安装应用 | 在系统设置里给正在打开文件的 App 打开「允许安装未知应用」开关，见[下载与安装教程.md](下载与安装教程.md) |
| 提示需要更新系统 | 系统版本过低 | 以应用商店页面上标注的系统要求为准；低于要求时只能换设备或用较新的系统 |
| 装完发现是别的软件 | 从第三方下载站点错了包 | 核对包名是否为 `ru.zengalt.simpler`，不对就卸载，改从本文开头的「Simpler 安装文件资源」里取 |

## 三、没声音 / 音频放不出来

按这个顺序查，绝大多数在第 1、2 步就解决：

1. **媒体音量**。手机的媒体音量是独立一路，可能被单独调到了零。播放时按一下音量键，看调的是不是"媒体"。
2. **蓝牙断连未释放**。之前连过耳机或车机，音频还在往那边走。关一次蓝牙，或者断开已连设备。
3. **其它应用占着音频通道**。后台正在播放的音乐/视频或通话会抢焦点，退掉再试。
4. **下载没完成**。音频是联网获取或缓存的，切到稳定 Wi-Fi 重开这一节。
5. **只有个别句子没声音**。先跳过去继续做，回来重开这一节；仍然没有就是这一条的音频有问题，不必反复试。

## 四、会员付了钱但没生效

这是订阅类应用的高频问题，原因几乎都在"账号对不上"，按顺序处理：

1. **确认用的是同一套账号**。付款的是应用商店账号（Apple ID / Google 账号），学习进度和会员状态绑定的是应用内登录的账号。**换过登录方式**（比如原来用邮箱、后来改成第三方登录）就可能出现"钱付了、会员没了"。
2. **点一次「恢复购买」**。换设备或重装后，会员状态不会自动回填，需要在应用内触发一次恢复。
3. **杀掉应用重开**。商店的付款回执到应用之间会有一点延迟，重启一次通常就同步上了。
4. **确认没有重复订阅**。同一档位在 App Store 和 Google Play 各买一次的话，是两笔独立扣款。取消其中一笔的自动续费。
5. **仍然不行再看退款**。退款路径与条件见[免费版和会员有什么区别.md](免费版和会员有什么区别.md)。

## 五、界面语言不是我要的

Simpler 的界面语言跟随系统。想单独给它换语言：

- **Android 13 及以上**：系统「设置 → 系统 → 语言和输入 → 应用语言」里找到 Simpler，单独指定。需要先在系统语言列表里添加过目标语言，列表里没有的语言这里也选不到。
- **iPhone / iPad**：系统「设置」里往下找到 Simpler，点进去选「语言」。
- **系统版本较老、没有这个入口**：只能改整个系统的语言。

另外，Simpler 支持的界面语言是官方标注的 12 种（含简体中文）。不在这个范围内的语言，改系统语言也不会生效。

## 六、进度、星星不见了

- **换手机或重装后进度空了**：进度是跟应用内账号走的，不是在本地跟着手机走。先用原来那个账号登录，再等一次同步。**如果你从没登录过账号，那进度本来就只存在这台手机上**，卸载或换机都找不回来。
- **刚做的练习没算进去**：断网状态下完成的内容可能没上传，联网后重开一次应用。
- **刚重装过，本地进度本来就没了**：本地缓存会随卸载清除，只有账号里的进度能找回。所以**重装前先确认能正常登录账号**，这也是升级版本时应该"覆盖安装而不是先卸载"的原因。

## 七、应用闪退或卡在加载

1. 先在系统的应用信息里**清一下缓存**（不是清数据——清数据会丢掉本地进度）。
2. 确认剩余存储空间足够，Simpler 会缓存音频和配图。
3. 升级到较新版本，官方更新记录里稳定性修复占了很大比重。
4. 仍然崩溃，按第十节联系官方，反馈时把手机型号、系统版本、Simpler 版本号（本套文档对应 6.5.25）一起写清楚。

## 八、句子输入题总是判错

这类题要你把整句敲出来，判错的原因通常不在你的语法上：

- **手机软键盘替你改了答案**。中文输入法的自动纠错、首字母大写、联想词候选，可能在你没察觉的时候替换掉你敲的词。先关掉输入法的「自动纠错」和「自动大写」再试。
- **空格与标点**。句子里多一个空格、少一个句点都可能判错，逐字对一下题目里的原句。
- **版本问题**。官方更新记录里对句子输入练习做过修正（6.5.27 明确写的是"应用户要求更新了句子输入练习，错误会更少"），**先升级到较新版本**再判断是不是你的问题。
- **想彻底避开软键盘的干扰**，用电脑模拟器配物理键盘做这类题，做法见[在电脑上用模拟器练.md](在电脑上用模拟器练.md)。

## 九、学习提醒太频繁或关不掉

提醒来自系统通知，不在应用里单独开关：

- **Android**：系统「设置 → 应用 → Simpler → 通知」，可以整个关掉，也可以只保留某一类。
- **iPhone / iPad**：系统「设置 → 通知 → Simpler」，同上。
- **只想安静几天**，用系统的「专注模式/勿扰模式」比改应用权限更省事，恢复后提醒照旧。

反过来，如果**该提醒的时候没有提醒**，先看通知权限是不是被系统收回了——长时间不打开的应用，部分系统会自动收回权限。

## 十、官方反馈渠道

应用内和官方说明里给出的联系邮箱是 `help@simpler.link`，官方明确表示接受使用建议与问题反馈。写信时把「设备型号 + 系统版本 + Simpler 版本号 + 复现步骤」写全，比只描述现象有效得多。涉及订阅扣款的争议，同时联系对应商店的客服处理更快。
