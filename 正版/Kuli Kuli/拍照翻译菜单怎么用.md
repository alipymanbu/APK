拍照翻译是 Kuli Kuli 的核心功能：把外文菜单、商品标签拍下来，译文直接叠在图上看。结果里除译文外还会附带语境信息——菜品长什么样、有没有常见过敏原、标签上的成分和用法是什么，点餐和购物时主要就看这几样。

## 一、哪些场景适合拍

官方描述里明确列出的适用对象包括：

| 场景 | 你能从结果里得到什么 |
| --- | --- |
| 餐厅菜单（含手写菜单、每日推荐） | 菜名译文、菜品参考图、潜在过敏原与配料提示 |
| 零食包装 | 口味、配料、产品说明的译文；官网还提到会按包装信息估营养评分 |
| 护肤品与美妆标签 | 成分、功效、使用方法 |
| 药店商品标签 | 用途与用法说明 |
| 收据、账单 | 你每一项付了什么钱 |
| 御神签、艺术作品、建筑说明、路牌、门票 | 内容译文加上文化背景解释 |

出餐厅之外的三个高频场景是：超市看零食配料、药妆店看护肤品成分、结账后核对收据。拍法与看菜单一致，只是关注点从「菜名 + 过敏原」换成了「成分表 + 用法」。

## 二、拍照与相册导入的步骤

免费版每天只有 2 次拍照翻译（次数明细见 [会员价格与免费次数.md](会员价格与免费次数.md)），出手前先想好拍哪张。操作本身是这四步：

1. 打开应用，初始界面就两个入口：拍照，或从相册选一张已有的照片；
2. 对准菜单或标签拍一张（手写菜单也可以，支持手写内容识别）；
3. 等几秒出结果，译文叠加显示在原图上，部分内容会附菜品参考图或成分说明；
4. 如果出发前已经把菜单拍好存在相册里，直接导入相册图片翻译，结果一样。

相册导入在餐厅信号差时特别有用：进门先拍几张，出店后慢慢看也行。

## 三、结果里那些额外信息怎么用

- **菜品参考图**：点餐前先看图，知道这道菜大概长什么样、是什么形态，避免凭菜名瞎猜；
- **过敏原与配料提示**：有饮食禁忌（花生、麸质、海鲜等）的人，下单前先扫一眼这层信息，比现场比划省事；
- **文化解读**：拍御神签、景点说明牌这类内容时，结果里除译文外还会解释背景含义，不只是直译；
- **收据逐项整理**：官网介绍收据会被整理成可读的逐行条目，结账后核对每一项花了什么更直接。

## 四、译文看不清、看不全怎么办

翻译结果叠在原图上，遇到竖排菜单、花体字或者拍得远的照片，常见两个问题：字太小看不清、一段译文被截成省略号。可以试这几招：

1. 靠近重拍，让目标区域占满画面；
2. 光线不足时开灯或换角度，避开反光的塑封膜；
3. 内容太密的长菜单分段拍，一次拍半页比一次拍整页准；
4. 结果支持原文与译文并排对照（官网展示的双栏形态），拿不准某条译文对应哪行原文时切到对照视图逐行核；
5. 仍被截断的话，参考 [常见问题与解决方法.md](常见问题与解决方法.md) 里的截断问题一节。

菜单看懂了，接下来和服务员、店员的口头交流可以用双向语音对话，语言覆盖与各模式的差异见 [支持哪些语言与翻译方式.md](支持哪些语言与翻译方式.md)。如果打开应用就提示次数用尽或付费，直接翻 [会员价格与免费次数.md](会员价格与免费次数.md)。
