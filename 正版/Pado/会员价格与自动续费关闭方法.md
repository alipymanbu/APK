## 一、先说结论

Pado 免费下载，会员与虚拟道具走应用内购买。价格分档、续费规则随渠道不同而不同 —— **一切以你购买时页面显示为准**；下面的数字是截至 2026 年 9 月从官方商店页面抄下来的，仅供你判断「大概什么价位」。

## 二、公开价格表（App Store 页面，截至 2026-09）

| 内购项 | 价格 |
| --- | --- |
| 连续包月 | ¥9.90 / 月 |
| 年度会员 | ¥52.00 / 年 |
| 永久会员 | ¥79.90 |
| 永久会员（另一档） | ¥49.90 |
| 双人永久会员 | ¥99.00 |
| 萌豆 1200 / 2400 / 3000 / 5000 / 10000 | ¥12 / ¥24 / ¥30 / ¥50 / ¥100 |

官方简介给的口径是：双人连续包月 9.9 元/月、双人连续包年 52 元/年、永久会员 79 元，**最终以页面展示为准**。同一时段页面上同时挂着 ¥49.90 与 ¥79.90 两档「永久会员」，具体哪档对应什么权益，购买页会写清楚 —— 付钱前把权益列表读完再点。

「萌豆」是应用内的虚拟道具计价项，用途以应用内的说明页为准，这里不展开（公开资料没写清具体用途）。

## 三、自动续费怎么运作

按官方说明（连续包月/包年属于自动续订）：

1. 你确认购买后，费用计入你的商店账户（iPhone 是 iTunes 账户）；
2. 订阅周期到期前 **24 小时**，系统自动扣费并延长一个周期；
3. 想取消，必须在**当期到期前至少 24 小时**操作，否则会自动续下一期。

## 四、关闭续订的路径

**iPhone**：设置 → 进入「iTunes Store 与 App Store」→ 点 Apple ID → 账户设置页 → 订阅 → 选中 Pado → 取消订阅。这是官方简介里给出的路径，取消后当前周期仍可用到期。

**安卓**：续费由购买渠道托管，不是在 Pado 里点 —— 在应用宝等渠道买的，就去对应渠道的「我的 → 设置 → 自动续费 / 订阅管理」里关；微信、支付宝签约的扣费，去支付方的「扣费服务 / 自动续费」列表里解约。找不到入口就看扣费记录来自谁，在那一侧关。

- 会员服务协议 / 用户协议：[https://www.wanyijia.vip/userAgreement/index.html](https://www.wanyijia.vip/userAgreement/index.html)
- 隐私政策：[https://www.wanyijia.vip/privacyAgreement/index.html](https://www.wanyijia.vip/privacyAgreement/index.html)

应用内查看自己的会员状态：首页底部「我的 - Pado情侣VIP」；扣费或权益有疑问，用「我的 - 意见采集 / 联系客服」反馈（渠道与联系方式见[隐私设置与账号注销方法.md](隐私设置与账号注销方法.md)第五节）。价格、权益、续费规则都可能随官方调整而变化，掏钱前以当时的购买页与协议为准。若你只是想把应用装上先试用，安装包见[下载与安装教程.md](下载与安装教程.md)。
