## 一、Pado 会向你要哪些权限

以下清单出自官方隐私政策（最近更新 2025-04-20，全文见 [Pado 隐私政策](https://www.wanyijia.vip/privacyAgreement/index.html)），按功能对应：

| 你用的功能 | 应用会拿什么 |
| --- | --- |
| 记录 / 相册 / 日记 | 相册与存储权限（读图片、存图片） |
| 拍照发图 | 摄像头 + 相册 |
| 情侣定位 / 距离查看 | 地理位置（开启定位服务后通过 GPS 或 WiFi **持续**收集） |
| 距离查看 / 实时共享位置 | 还会拿**设备电量与充电状态** |
| 甜言蜜语（语音聊天） | 麦克风；安卓端为及时收到消息会自启动相关进程 |
| 纪念日提醒 | 通知、日历写入 |
| 聊天 / 绑定状态检测 | 后台获取你的用户信息与设备信息 |
| 统计分析 | 友盟第三方 SDK 在后台获取用户与设备信息 |

用不到的功能可以不给对应权限 —— 隐私政策写明拒绝提供部分信息或权限时对应功能不可用，**但不影响其他功能**。

## 二、对方能看到什么、怎么关

- **位置与足迹**：关闭手机定位服务即停止收集，足迹也不会再记录；应用内的定位设置里也能关 —— 关掉后对方看不到你的实时位置；
- **电量与充电状态**：用距离查看或实时共享位置时会带给对方，不想展示就在定位设置中关闭定位（隐私政策原文口径）；
- **单侧看不到对方**：双方数据都以「已绑定 + 各自授权」为前提，你关掉自己的共享，对方那边就是没有数据，见[实时定位与足迹查看教程.md](实时定位与足迹查看教程.md)。

## 三、解除关系、撤回授权、注销账号的路径

这些都是隐私政策里写明的入口，按路径点即可（界面措辞以你的版本为准）：

| 你要做的事 | 路径 |
| --- | --- |
| 查看 / 输入匹配码 | 首页底部「我的 - 我的匹配码」→ 输入对方匹配码绑定 |
| 解除情侣关系 | 首页右上角「设置 - 账号信息 - 解除关系」 |
| 查看会员状态 | 首页底部「我的 - Pado情侣VIP」 |
| 修改昵称、头像 | 首页底部「我的 - 右上角设置 - 个人信息」 |
| 撤回权限授权 | 手机的「设置 - 隐私 - 权限管理」里改 Pado（系统层操作） |
| **注销账号** | 「我的 - 右上角设置 - 账号信息 - 注销账号」 |
| 关掉消息通知 | 安装时拒绝，或去手机系统的「通知」中心关掉 Pado |

注销后按《网络安全法》等法规，平台会先留存相关信息，超过法定保存期限再删除或匿名化 —— 这是官方写明的处理方式，不是「立刻清零」。

## 四、登录方式不止手机号一种

隐私政策写明两种入口：**手机号 + 短信验证码**注册，或用**微信 / QQ 第三方账号**登录（第三方登录会带上昵称、头像、性别）。细节见[匹配码组队与登录方法.md](匹配码组队与登录方法.md)。
