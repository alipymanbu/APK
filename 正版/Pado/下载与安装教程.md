## 一、先确认你要装的是哪个 Pado

Pado 是重庆万艺嘉科技有限公司开发的情侣互动应用，安卓包名是 `com.lovengu.wyj`，功能围绕情侣定位、足迹、相册、恋爱日记与打卡。

装之前认这两点，任一不符就不是同一个东西：

- **包名**必须是 `com.lovengu.wyj`；
- **开发者**必须是「重庆万艺嘉科技有限公司」（应用商店详情页会写）。

另外注意：海外有一款同名的德国地理轨迹记录应用（[pado-app.de](http://www.pado-app.de/)），主打路线记录与计步，跟本文这套完全无关 —— 搜索时别看岔。

## 二、安装包从哪拿

安卓安装包有两个可靠来源：

1. **网盘留存的那份**：[Pado 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d7b5727c28ee)，包事实如下表（这是网盘里那份包的实测记录，网上商店显示的是官方最新版，两者常不是同一版）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.1.1 |
| 包名 | com.lovengu.wyj |
| 大小 | 64.79M |
| MD5 | `1E3C18E995B1EF8105F90CA5419FEE58` |
| 记录时间 | 2026-09-23 |

2. **官方应用商店**：安卓可去[应用宝的 Pado 详情页](https://sj.qq.com/appdetail/com.lovengu.wyj)（该页显示版本 1.2.4、2025 年 8 月 15 日更新，版本号会随更新变化，以页面当时显示为准）；iPhone 在 App Store 搜「Pado」，开发者显示为 Chongqing Wanyijia Technology Co., Ltd.，要求 iOS 13.0 或更高。

## 三、装之前核对一次 MD5

从网盘转存或经过中转下载的文件，偶发下载不完整。用任意支持 MD5 校验的工具（电脑端或手机端均可）算一遍文件哈希，跟上表的 `1E3C18E995B1EF8105F90CA5419FEE58` 比对：

- 完全一致 → 文件完整，可以装；
- 对不上 → 重新下载一次再校验，别硬装。

## 四、安卓安装步骤

1. 把 APK 从网盘转存并下载到手机（或先下到电脑再传过去）；
2. 首次安装非商店来源的 APK，系统会要求你给文件管理器或浏览器「安装未知应用」权限 —— 按提示允许这一次即可；
3. 点击 APK → 安装 → 位置等权限不用现在急着给，等两人匹配成功后再按需授权；
4. 打开应用，按[匹配码组队与登录方法.md](匹配码组队与登录方法.md)完成登录与组队。

## 五、装不上或装完打不开时先查这四条

| 现象 | 先查什么 |
| --- | --- |
| 解析包时出错 / 安装包损坏 | 回到第三节重新校验 MD5，多半是下载不完整 |
| 安装被拦截 | 系统的「纯净模式」、手机管家之类会拦非商店安装，按提示临时放行这一次 |
| 空间不足 | 包体 64.79M，解压安装还要额外空间，先清出几百 MB 余量 |
| 装完闪退 | 看系统要求：这个安装包标注「需要支持安卓系统 5.2 以上」，系统过旧可能跑不动；确认后再考虑换商店版 |

## 六、版本差异怎么理解

同名应用在不同渠道版本号并不一致，装错版本是常见困惑：

- 网盘留存版：**1.1.1**（2026-09-23 记录）；
- 应用宝详情页：**1.2.4**（2025-08-15 更新）；
- iPhone App Store：版本历史已迭代到 **2.0.0**，安装包体积 129.6 MB（iOS 端与安卓端不是同一个安装文件）。

功能以你实际打开后看到的为准；三方教程写的界面若与你手上的版本对不上，以应用内为准。
