# 定位不更新与消息收不到的排查

> Pado 的点停在原地、对方消息到不了你手上时，按这篇从上到下逐层查。

## 一、先分清是哪一层坏了

位置共享坏掉只有四种可能：**手机自己没定位 → 应用没权限 → 传不出去 → 后台被杀**。按顺序查，前一层没通别查后一层：

1. 打开手机自带的地图，看蓝点能不能落到你所在的街道 —— 落不下，先修手机本身的定位，与 Pado 无关；
2. 地图正常，再开 Pado 看地图里自己的点 —— 点不动或空白，是权限问题（第二节）；
3. 权限没问题，切一下 Wi-Fi 与流量 —— 只有一种网络能用，是网络路径的问题；
4. 以上都好、只有锁屏后不更新 —— 是后台被限制（第三节）。

## 二、权限层：最常见的原因

- **位置权限只给了「使用期间」**：锁屏后就不再上报。要持续共享，安卓选「始终允许」，iPhone 选「始终」；
- **精确位置被关**（iPhone）：只会传回模糊范围，看起来像卡住；
- **总开关没开**：系统设置里的定位服务本身是关的；
- **对方那一侧没授权**：定位是双向各自授权的，你查完自己，也要让对方照第二节检查一遍。

各品牌路径以系统实际界面为准；安卓各厂商支持文档给的通用排查顺序也是这一套：总开关 → 应用位置权限 → 网络 → 去掉干扰物。

## 三、后台层：锁屏后就不更新

安卓的省电策略是这类问题的高发点：

| 检查项 | 设成什么 |
| --- | --- |
| 电池优化 / 省电策略（Pado） | 不限制 / 允许后台运行 |
| 自启动 / 关联启动 | 允许（各品牌叫法不同） |
| 后台数据 | 允许（后台数据被禁，位置算出来也发不出去） |
| 系统全局省电模式 | 共享期间关掉，或保持充电 |

iPhone 侧对应两处：**后台 App 刷新**要开；**低电量模式**会拖慢后台更新，共享期间别一直开着。另外 Apple 标注该应用未打开时也可能使用位置信息、会影响电池续航 —— 后台更新与耗电本来就是绑定的。

## 四、网络层与环境层

- 弱网、地铁、电梯里位置发不出去是正常的，走到信号好的地方等十几秒；
- 开了 VPN 或私人 DNS 时，请求可能被规则拦掉 —— 排查期间先关掉再试；
- 金属磁吸壳、车载支架会挡卫星信号，取下壳到窗边试一次；
- 如果手机上装过「模拟定位 / 虚拟 GPS」类工具，先退出或卸载它 —— 系统定位被劫持时，所有定位类应用都会失真。

## 五、还没解决时

1. 强行停止 Pado → 重新打开，让它重新取一次定位并重新连推送；
2. 对照[下载与安装教程.md](下载与安装教程.md)确认安装包完整、版本没有装错；
3. 换台手机登录同一账号试：**只有你这台坏** = 手机设置问题；**两台都坏** = 账号或匹配关系问题，回[匹配码组队与登录方法.md](匹配码组队与登录方法.md)确认匹配状态，或走应用内客服反馈。

消息收不到时，额外查三处：系统的通知权限是否给了 Pado、手机是否开了勿扰模式，以及 Pado 的后台有没有被限制 —— 官方隐私政策写明聊天消息依靠应用在后台接收用户与设备信息，后台被禁时消息与定位往往一起失效（见第三节的表）。
