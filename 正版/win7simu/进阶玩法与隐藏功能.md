## 一、这些玩法从哪来的

不是网友瞎传：官方维护着一个「Did you know」教程视频合集，专门演示这类藏得深的功能，地址在 [visnalize.com/win7simu/dyk](https://visnalize.com/win7simu/dyk)。下文每一条都能在合集中找到对应演示视频，操作细节以视频与应用内实际显示为准。

所列功能在更早的版本里就已存在，网盘这份 3.19.1 基本都能用；个别注明了加入版本。

## 二、BIOS Setup：开机画面和登录画面都能换

[首次启动与桌面操作.md](首次启动与桌面操作.md) 里提到开机时的 BIOS 自检画面。BIOS Setup Utility（2.16.0 起）不只是个摆设——在里面可以**改开机画面和登录画面**（官方教程「Changing Boot & Logon screen with Bios」演示的就是这件事）。想把手机模拟成另一台「电脑」，从这里下手最彻底。

## 三、Program Installer：往模拟器里装更多应用

Program Installer（3.6.0 起）可以**从在线目录添加更多的模拟应用**（官方教程「Adding online apps with Program Installer」）。也就是说 [模拟应用一览.md](模拟应用一览.md) 列的并不是全部——联网后打开 Program Installer 看看在线列表，可能还有能装的。注意这装的不是真正的 Windows 软件，仍是模拟器里的模拟程序。

## 四、小彩蛋清单

| 彩蛋 | 在哪 | 是什么 |
| --- | --- | --- |
| Chrome 恐龙小游戏 | 模拟的 Chrome 浏览器 | 和真 Chrome 一样，断网时会出现恐龙小游戏（官方教程演示过怎么主动去玩） |
| 给 CMD 上色 | 命令提示符 | 用命令改命令行的配色（官方教程「Coloring CMD」） |
| 用 CMD / Run 启动程序 | 命令提示符 / 运行 | 键入程序名打开对应的模拟程序，Alt + R 随手调出「运行」 |
| Media Center 欢迎屏 | Windows Media Center | 首次进入有一段欢迎 / 首次运行画面（3.16.0 加入，官方归为 easter egg） |
| 用记事本做网页 | 记事本 | 3.14.0 起文本可另存为 HTML，放到模拟浏览器里就能打开看（官方教程「Building a website in Notepad」） |
| 「摆样子」的 Windows Installer | Windows Installer | 官方教程直接称它 dummy——模拟安装向导的娱乐程序 |
| 计算器随主题变脸 | 计算器 | 换主题后计算器外观跟着变（官方教程专门对比过） |
| 蓝屏样式随主题变 | BSOD Customizer | 不同主题下蓝屏画面长得不一样（官方教程「BSOD for different Themes」） |

## 五、主题带来的「系统级」变化

换主题不只是换皮肤，有些主题会连系统行为一起变：

- **Windows 11 主题**：任务栏图标可以**居中**（官方教程注明 Windows 11 主题限定）。
- **Windows XP 主题**：有完整的「装机流程」可走（官方教程「Setting up a complete Windows XP」）。
- **Windows 95 / 2000 主题**：登录界面会变成对应年代的样子（官方教程「User login in Windows 95/2000」）。

切换主题的入口见 [主题与个性化.md](主题与个性化.md)。

## 六、外设与边角设置

- **蓝牙鼠标**：安卓版可以连接蓝牙鼠标来用（官方教程演示过连接过程），配合 Mouse 程序里的指针设置更顺手。
- **显示缩放**：模拟器带显示缩放设置（官方教程「Zooming the display」），界面太大 / 字太小可以调。
- **账号头像**：登录账号后可以更换头像（官方教程「Changing your account's picture」）。
- **屏幕保护与动态壁纸**：在 Personalize 里设置，见 [主题与个性化.md](主题与个性化.md) 第一节。
