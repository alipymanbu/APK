## 一、两版是什么关系

Win7 Simu 由同一个开发者（Visnalize）维护，一套模拟环境出了两种形态：

- **安卓版**：独立的 APK 安装包，装在手机 / 平板上（安装方法见 [下载与安装教程.md](下载与安装教程.md)）。
- **网页版**：2021-08-28 上线，浏览器直接打开 [win7simu.visnalize.com](https://win7simu.visnalize.com/)，不装任何东西。图形、界面和大部分功能与安卓版一致。

iOS 上**没有客户端**：官方明确因 App Store 政策不会上架，iPhone / iPad 用户官方给的方案就是网页版，可以「添加到主屏幕」让它像应用一样打开。

## 二、功能对照表

下表是官方给出的关键功能对照（截至 2026-09 官网口径）：

| 功能 | 安卓版 | 网页版 |
| --- | --- | --- |
| 跨平台使用 | 不支持 | 支持 |
| 离线使用 | 支持 | 支持 |
| 文件管理器直接访问本地文件 | 不支持 | 不支持 |
| 文件下载与上传 | 部分支持 | 支持 |
| 访问本地 / 原生应用 | 部分支持 | 不支持 |
| 在线账号同步设置 | 支持 | 支持 |
| 多主题支持 | 支持 | 支持 |
| 多语言支持 | 支持 | 支持 |
| 系统通知 | 支持 | 不支持 |
| 显示控制 | 支持 | 不支持 |
| 鼠标 / 触控板控制 | 支持 | 不支持 |

读表时的几个补充：

- 「文件管理器直接访问本地文件」两边都标红是平台政策所致（Android 11+ 存储限制、浏览器沙箱），两边都靠「上传到模拟环境」的方式传文件。
- 「访问本地 / 原生应用」安卓版也只是部分支持：Android 12 起系统限制应用包可见性，开始菜单里未必能看到手机上装的全部应用。
- 账号两版通用（同步设置用），但**密码无法找回**，相关注意点见 [常见问题解答.md](常见问题解答.md) 第二节。

## 三、按场景怎么选

| 你的情况 | 建议 |
| --- | --- |
| 手上有安卓机，想离线玩、要系统通知和显示控制 | 安卓版 |
| 设备系统较老（Android 5.x / 6.x） | 选对应的旧版安装包（官方 4.x 新版要求 Android 7.0+） |
| iPhone / iPad | 只能网页版 |
| 电脑上想随手怀旧一下 | 网页版最省事 |
| 不确定要不要装 | 先玩网页版，觉得合适再装安装包 |

## 四、网页版使用提示

- **横屏优先**：手机浏览器打开时竖屏会提示旋转设备，横屏体验才完整；不支持的竖屏布局在新版里会直接报错而非蓝屏。
- **依赖现代浏览器能力**：开机 BIOS 自检画面会逐项检查 canvas、webGL、indexedDB 等特性，用的是主流浏览器一般全部就绪；老浏览器或缺组件会出现部分「not supported」。
- **网页版同样免费**，功能差异以官方 about 页的对照表为准。
