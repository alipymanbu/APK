## 一、先划清边界：它不是真系统

用之前先把预期对齐，这几条都是官方 FAQ 明确说过的：

- **不能安装 `.exe` 或 Windows 程序**。它只是界面和功能的模拟，没有运行真 Windows 程序的基础设施。
- **Internet Explorer 和 Chrome 都是模拟出来的浏览器**，功能很有限：可能连不上网、速度慢、不能下载文件，官方明确表示这已是实现的上限。
- **没有 Microsoft Office**，官方列为低优先级计划，不要为了「在手机上用 Office」来装它。
- **不能当手机桌面启动器（launcher）用**，官方专门写过说明文章劝退这类需求。

## 三、文件能力边界

- **ZIP**：3.8.0 起可查看、解压 `.zip` 内容。
- **PDF**：3.11.0 起支持打开。
- **手机里的文件默认看不到**：从 Android 11 开始系统限制应用读取彼此的存储，File Explorer 里不会直接出现你手机上的文件；官方给的出路是在模拟环境内的文件夹上用右键菜单「Upload files here」把文件传进去。
- **备份**：控制面板里的 Backup & Restore（整体备份/还原模拟环境文件）是 4.5.0 才加入的功能，这份 3.19.1 里没有，重要文件建议另行留档。

## 四、开始菜单里找不到某些东西

- 想在开始菜单里看到**手机上装的游戏和应用**：Android 12 起系统限制了应用包可见性，这类条目可能不再显示，官方表示无法绕过。
- 开始菜单的具体用法（长按发送到桌面等）见 [首次启动与桌面操作.md](首次启动与桌面操作.md)；其他常见故障集中在 [常见问题解答.md](常见问题解答.md)。
