## 一、在哪里换主题

两条入口任选其一：

- 桌面空白处**长按一秒**（触屏的右键）→「Personalize」；
- 开始菜单里直接打开 Personalize（个性化）。

Personalize 里能单独改的有：桌面背景（含动态 / 会动的壁纸）、窗口颜色、屏幕保护程序、系统声音，也可以整套换主题。换 Aero 系主题时可以顺便看一眼玻璃效果和窗口动画——这是官方还原的重点部分。

## 二、内置主题清单

官方把主题分成四组（截至 2026-09 官网口径，实际以你应用内 Personalize 显示为准）：

| 分组 | 主题 |
| --- | --- |
| Aero 主题（Win7 默认系） | Windows 7 Aero、Architecture、Landscape、Nature |
| 基本和高对比度 | Windows 7 Basic、Windows Classic、高对比度黑、高对比度白 |
| 其他 Windows | Windows 3.1、Windows 95、Windows 98、Windows 2000、Windows XP、Windows Vista、Windows 8、Windows 8.1、Windows 10、Windows 11（亮色）、Windows 11（深色） |
| 杂项 | Windows XP 变体（Embedded、Olive Green、Royale Noir、Royale、Silver、Zune）、macOS、ChromeOS、Ubuntu、Kubuntu（Breeze）、Windows Longhorn（Slate / Plex）、Aero Noir、Oxygen、Windows Whistler |

注意两点：

- 其中部分标注为 **premium（进阶主题）**，如 Ubuntu、Aero Noir 和 Windows XP 变体系列，获取方式以应用内显示为准（官方现行的订阅方案见 [常见问题解答.md](常见问题解答.md) 第四节）。
- 主题清单随版本增长：Windows 11 深色、Kubuntu 是 3.6.0 加的，Aero Noir 是 3.10.0 加的。网盘这份 3.19.1 之后的官方新版还在继续加主题（如 4.1.0 的 Onebit），想要最新主题只能换用官方新版安装包。

主题还会连带改一些「系统行为」：Windows 11 主题的任务栏图标可以居中、Windows XP 主题有完整的装机流程、Windows 95 / 2000 主题的登录界面是当年的样式，蓝屏和计算器的外观也会跟着主题变——这些属于进阶玩法，具体见 [进阶玩法与隐藏功能.md](进阶玩法与隐藏功能.md)。

## 三、桌面小工具与光标

- **桌面小工具（Windows Gadgets）**：2.6.0 起可用，还原的是 Windows Vista / 7 独有的桌面小工具，比如时钟、日历这类常驻挂件。
- **光标样式**：3.7.0 起有 macOS 和 Ubuntu 两套光标集，在 Mouse 程序的指针选项里切换；对触屏用户影响不大，接鼠标或外接触控板时才看得出差别。

## 四、用 Theme Studio 自己做主题

官方有一个独立的配套应用 **Theme Studio**，网页版直接可用：[visnalize.com/win7simu/themestudio](https://www.visnalize.com/win7simu/themestudio)

- 可以从零或基于现有主题改出**自己的配色与外观**，深度自定义整套界面。
- 有个 **Autofill（自动填充）** 特性，官方教程演示过——给整套界面换配色时能省掉大量逐项填色的重复操作。
- 做好的主题可以发布到 Public Gallery 给别人用，也可以浏览、套用别人分享的主题；已发布的主题也能再编辑（官方教程演示过整个流程）。
- 自己调的主题建议**导出留档**：官方更新日志记录过一次导致 Theme Studio 主题损坏无法使用的事故（3.19.2 修复，但已损坏的主题无法恢复），留个导出文件更稳妥。

## 五、一个彩蛋：蓝屏也能改

BSOD Customizer（3.6.0 起）可以自定义蓝屏死机画面——纯属娱乐，喜欢整活可以配一个截图玩。改完的蓝屏在触发对应场景时生效。
