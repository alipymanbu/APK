## 一、开机三步：BIOS 自检 → 开机动画 → 登录界面

点开应用后不是直接进桌面，而是一套还原 Windows 7 时代的开机流程：

1. **BIOS 自检画面**：黑底白字的 `Win7 Simu BIOS` 界面，逐项列出功能检查（canvas、webGL、indexedDB 等），模拟的是真机开机前的硬件自检。这里还能进入 BIOS Setup Utility（2.16.0 起是独立模拟程序），在里面连开机画面、登录画面都能换，见 [进阶玩法与隐藏功能.md](进阶玩法与隐藏功能.md)。
2. **Starting Windows 开机动画**：经典的四色旗帜聚合动画。
3. **登录界面**：和 Windows 7 的登录屏一致。

在登录界面你有三个选择：

| 操作 | 效果 |
| --- | --- |
| 点击**行李箱图标** | 以 Guest（访客）身份直接进入，不需要注册 |
| 用户名 + 密码登录 | 使用你自己注册的账号 |
| 社交账号登录 | 用 Google、GitHub、Apple 账号直接登录或绑定 |

账号相关注意事项：

- 账号用于在云端同步你的设置；离线也能用模拟器的大部分功能，但**账号、部分游戏和浏览器需要联网**（官方 FAQ 口径）。
- **密码无法找回**：官方明确暂不支持找回密码，忘了只能重新注册一个账号。

## 二、桌面与开始菜单

进入桌面后，触屏上的操作对应关系是：**点按 = 鼠标左键，长按一秒 = 鼠标右键**。

- **打开右键菜单**：在桌面空白处长按一秒，会弹出和 Windows 7 一致的桌面右键菜单（个性化、刷新等）。
- **把程序发到桌面**：打开开始菜单，在想要的程序上长按，弹出菜单后选「Send to Desktop」，桌面上就会出现它的快捷方式。
- **多选与拖动**：可以选中多个桌面图标一起拖动排列（3.9.0 起支持）。
- **关机**：点开始菜单右下角的电源按钮，和真 Windows 7 一样有关机、注销等选项（Alt + L 快速注销当前用户）。

## 三、窗口操作

窗口标题栏右上角是最小化、最大化、关闭三个按钮，和桌面 Windows 一致。外接键盘时可以用快捷键贴边分屏：

| 快捷键 | 作用 |
| --- | --- |
| Alt + Up | 最大化窗口 |
| Alt + Down | 还原 / 最小化窗口 |
| Alt + Left | 窗口贴到左半屏 |
| Alt + Right | 窗口贴到右半屏 |
| Alt + 4 | 关闭窗口 |

## 四、通用键盘快捷键

这些快捷键主要面向网页版，安卓版连接外接键盘后同样可用（Alt 是统一修饰键，避免和系统快捷键冲突；Mac 上用 ⌥ Option 代替）：

| 快捷键 | 作用 |
| --- | --- |
| Alt + W | 打开开始菜单 |
| Alt + D | 最小化所有窗口、显示桌面 |
| Alt + E | 打开文件资源管理器 |
| Alt + R | 打开「运行」对话框 |
| Alt + L | 注销当前用户 |
| Alt + N | 新建空白文档 |
| Alt + O | 打开文件 |
| Alt + S | 保存文件 |
| Alt + Shift + S | 另存为 |

## 五、外设与显示设置

- **蓝牙鼠标**：安卓版可以连接蓝牙鼠标来用（官方教程演示过连接过程），配合 Mouse 程序里的指针设置更顺手。
- **显示缩放**：模拟器自带显示缩放设置（官方教程「Zooming the display」），界面太大 / 字太小可以调。
- **账号头像**：登录账号后可以更换头像。

更多隐藏功能与彩蛋集中在 [进阶玩法与隐藏功能.md](进阶玩法与隐藏功能.md)。

## 六、卡在开机画面怎么办

- 启动后长时间黑屏是最常见的问题，一般与系统的 Android WebView 组件有关，把它更新到最新版通常就能解决，详见 [常见问题解答.md](常见问题解答.md)。
- 想先确认流程长什么样，可以先用网页版走一遍同样的开机过程（见 [下载与安装教程.md](下载与安装教程.md) 第四节）。
