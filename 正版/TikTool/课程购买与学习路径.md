## 一、课程都讲什么

课程围绕 TK、Temu 等海外电商平台的运营展开，主线大致是：

| 环节 | 内容方向 |
| --- | --- |
| 市场分析 | 看市场与类目，判断从哪里切入 |
| 选品策略 | 挑品的方法与实战案例 |
| 内容创作 | 短视频制作、直播技巧、粉丝互动 |
| 广告投放 | 付费流量的投放方法 |
| 带货实操 | 兴趣电商带货的分步讲解 |

除系统课程外，还有导师教学视频 —— 多是已经跑通流程的从业者讲自己的经验与踩过的坑，适合当「别人怎么做成」的参照来看。课程目录与开课情况随时间会变，以应用内实际展示为准。

## 二、买课的入口与步骤

1. 打开 TikTool 进首页，找到电商教学（或课程）入口；
2. 浏览课程列表，点开感兴趣的一门进详情页；
3. 在详情页查看课程目录与价格，确认后点购买；
4. 付款后在「我的课程」（或同类入口）里开始学习。

下单前值得确认的几件事：

- 课程目录是否正好覆盖你当前最想解决的问题，别只看标题下单；
- 价格、优惠与已购记录以应用内展示为准；
- 付费内容按需购买，遇到「限时」「内部资料」这类催促话术，先冷静核对课程目录再决定。

课程大致什么价位、大额支出怎么规避风险、退款走哪条路，单独整理在 [课程价格与付费注意.md](课程价格与付费注意.md)，下单前建议过一遍。

## 三、一条新手可以照着走的学习顺序

刚接触跨境电商的话，按下面的顺序学能少绕路：

1. **先看市场分析与选品** —— 先知道卖什么、卖给谁，后面的动作才有意义；
2. **再学内容创作** —— 短视频与直播是把品推出去的主要手段，这一步花的时间最值得；
3. **最后碰广告投放** —— 有了选品判断和内容手感，再谈付费放量，否则容易把钱花在跑不动的内容上；
4. **学的时候配合工具练** —— 热词挖掘帮选题、数据分析帮复盘，两件事穿插做（用法见 [功能模块使用指南.md](功能模块使用指南.md)）。
