## 一、安装前先核对三件事

TikTool 是一款面向跨境电商从业者的安卓应用，内容围绕 TK、Temu 等海外电商平台的运营学习与辅助展开。动手装之前，先确认设备条件：

| 项目 | 要求 |
| --- | --- |
| 系统版本 | 安卓 5.2 及以上（以安装时设备上的实际提示为准） |
| 剩余空间 | 安装包约 61.78M，建议再留出一部分空间给安装过程与缓存 |
| 网络环境 | 注册与课程内容都要联网加载，建议在稳定的 Wi-Fi 下操作 |

你手上这份安装包的关键信息，可用来核对拿到的文件是否完整、有没有被改过名：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.0.5 |
| 包名 | com.zp.tktool |
| 安装包大小 | 61.78M |
| MD5 | FDE8A0B3A0CC9F357A9466DDCFA147DA |

文件名一般形如 `TikTool_v2.0.5.apk`。包名 `com.zp.tktool` 与开发者「纸条（厦门）科技有限公司」可以作为你辨认正身的依据。

## 二、从安装文件资源把包拿到手

[TikTool 安装文件资源（夸克网盘）](https://pan.quark.cn/s/37c050832bcf)已在本文开头给出，整条流程是「转存 → 下载 → 安装」：

1. 点开头部链接，登录你的夸克账号；
2. 把文件转存到自己的网盘空间；
3. 在网盘里找到这个 apk，下载到手机；
4. 下载完成后，在通知栏或「文件管理」的下载目录里点开它，按提示完成安装。

在电脑上操作更顺手的话，也可以先在电脑端完成转存与下载，再用数据线、局域网传输等方式把文件送到手机上装。

## 三、安装时可能碰到的拦截

- **「禁止安装未知来源应用」**：安卓默认只放行应用商店的安装包。按弹窗指引，给你正在用的浏览器或文件管理器开「安装未知应用」权限，装完可以再关掉。
- **手机管家的风险提示**：部分机型会扫描非商店来源的安装包。先对照上面的版本、包名与 MD5 表，确认是自己主动获取的那份文件，再选择继续安装。
- **装到一半失败**：常见原因是空间不足、系统版本低于要求，或者下载中途断流导致安装包不完整 —— 重新完整下载一遍，多数就能过。

## 四、也可以直接从应用商店装

TikTool 已在腾讯应用宝上架，开发者与运营者均为「纸条（厦门）科技有限公司」。在应用宝或部分手机自带商店里搜「TikTool」也能安装。

两处版本可能不一样：商店页面会随官方更新（2026 年 1 月时应用宝显示为 2.1.4），而上面这份安装文件资源固定是 2.0.5。功能大体一致，界面细节会有出入 —— 本套文档的描述都以你实际安装后的界面为准。

除安卓外，同一开发者（纸条（厦门）科技有限公司）在 App Store 上也上架了 iOS / iPad 版的 TikTool，iPhone 与 iPad 用户可以直接在 App Store 里搜「TikTool」安装；两个平台的功能节奏不完全同步，iOS 商店页同样标注免费、含应用内购买。

## 五、想在电脑上用怎么办

TikTool 没有官方的电脑客户端，它是手机应用。如果你习惯在电脑前学课程，可以借助应用宝电脑版这类安卓运行环境来装手机版：在浏览器访问 `https://sj.qq.com`，下载并安装应用宝电脑版，然后在里面搜索 TikTool 安装。设备配置要求以应用宝官网的说明为准。

装好并能正常打开后，下一步是注册登录，见 [注册登录与基础设置.md](注册登录与基础设置.md)；装不上或启动异常，先翻 [常见问题与使用注意.md](常见问题与使用注意.md)。
