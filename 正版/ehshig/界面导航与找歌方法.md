## 一、这篇适合谁

装好 ehshig 之后，你面对的是一个全蒙语歌的曲库，第一次打开常不知道从哪下手。这篇按「首页 → 搜索 → 播放页 → 我的」的顺序把常用入口走一遍，让你能自己找到歌手、榜单和收藏。界面细节可能随版本微调，以你手机上看到的为准。

## 二、首页的几个入口

打开应用进首页，常用的找歌入口有这几类（具体排布各版本略有差异）：

- **歌手**：按歌手翻，适合你已经有想听的人——蒙语长调、呼麦、马头琴演奏、蒙古流行歌手都能按人找。
- **排行/榜单**：新歌、热歌之类的榜单入口，想随便听听或跟热点时从这里进。
- **推荐**：首页会按你的听歌习惯推「猜你喜欢」这类卡片，点一下就能直接播。
- **搜索框**：目标明确时最快，见下一节。

你也可以先进「电台」「专辑」这类栏目（若你的版本有），思路一样：先缩小范围，再点歌进播放页。

## 三、搜索：中文、蒙古文都能输

搜索支持中文与蒙古文双语输入：

1. 点顶部搜索框；
2. 输入歌手名或歌名——会蒙文就直接输蒙文，不会就用中文音译或汉字名搜；
3. 结果里点任意一首即播放，也可以先听在线试听再决定要不要下载。

搜不到时换个关键词（只输名字的一部分、或换一种音译写法），蒙古语歌名的中文译写往往不止一种，见[常见问题与解决办法.md](常见问题与解决办法.md)。

## 四、播放页能做什么

点歌进播放页，常用操作都在这一页：

| 操作 | 说明 |
| --- | --- |
| 收藏/喜欢 | 加入你的收藏，之后在「我的」里能找到 |
| 下载 | 存到手机离线听，需要给应用存储权限，规则见[会员与离线下载说明.md](会员与离线下载说明.md) |
| 关注歌手 | 关注后歌手有新作更容易被你看到 |
| 歌词 | 播放时同步滚动显示蒙古语歌词，显示与跳转设置见[同步歌词与播放设置.md](同步歌词与播放设置.md) |
| 音质 | 页面上有音质标识，点一下可在不同音质档位间切换 |

播放页一般还支持横屏（部分版本），横过来看歌词更宽。切歌用页面上的上一首/下一首按钮，播放模式（单曲循环、列表循环、顺序播放）的切换在[同步歌词与播放设置.md](同步歌词与播放设置.md)里讲。

## 五、「我的」里管理自己的东西

底部「我的」栏目是你自己的地盘：

- **下载的歌**：已下载与下载历史都在这里，离线听歌从这里进；
- **收藏/喜欢**：听过的、收藏的歌按记录翻；
- **关注的歌手**：已关注的歌手列表；
- **设置**：齿轮图标，语言切换、定时关闭、听歌识曲、账号登录/退出、个性化广告开关都在里面，具体项见[同步歌词与播放设置.md](同步歌词与播放设置.md)与[常见问题与解决办法.md](常见问题与解决办法.md)。

## 六、登录与多设备

用手机号或微信等渠道登录后，收藏、关注、播放进度这类数据跟着账号走；电脑端/车机端扫码登录用的也是同一套账号体系。换手机前先确认已登录同一账号，避免收藏丢失（详见[常见问题与解决办法.md](常见问题与解决办法.md)）。
