## 一、安装与启动

**提示「解析包时出现问题」或安装包损坏**
先核对下载的文件 MD5 是否为 `62D51F100FCAF4B044E9D107DAEAA5C0`（对照见[下载与安装教程.md](下载与安装教程.md)），不一致就重新下载；传输中途断过也会损坏，建议重新拉一次文件。

**提示「禁止安装未知来源应用」**
这不是病毒警告，是系统的默认拦截：按弹窗跳到设置，允许当前来源（浏览器或文件管理器）安装应用，再回来点安装。

**安装包解析失败 / 装不上**
- 系统低于安卓 5.2：这份包要求 5.2 及以上，低版本装不了；
- 手机存储空间不足：先清理出比 APK 体积更大的空余空间（包体 127.21M，解压安装还要额外空间）；
- 厂商安全中心拦截：在手机自带的管家/安全设置里放行该安装来源。

**打开就闪退或黑屏**
先升级到新版本再试（官方更新日志里多次修复过播放服务被回收、异形屏显示等问题）；若只有这一个应用闪退，去系统设置清一次它的缓存；重装仍闪退，确认机型系统版本不低于 5.2。

## 二、界面与语言

**想把界面切成中文（或蒙古文）**
启动引导或设置菜单里有语言选项，选中文即可；部分版本首页就能切换显示语言。设置菜单从主界面齿轮图标进入。

**找不到「定时关闭」**
路径是：主界面齿轮图标 → 「定时关闭」→ 选时长。选项措辞各版本略有差异，若设置里是四个一组的选项列表，定时关闭就在其中。详细步骤见[同步歌词与播放设置.md](同步歌词与播放设置.md)。

**歌词不滚动、不显示**
点播放页的歌词区域切回歌词视图；再看是否被误触切了封面模式。仍无歌词属个别歌曲没有歌词文件，换一首验证。

## 三、搜索与播放

**搜不到想听的歌**
蒙古语歌名的汉字译写常有多种，换一种音译或只输名字的一部分再搜；会写蒙文的话直接用蒙文输入命中率更高。搜歌方法见[界面导航与找歌方法.md](界面导航与找歌方法.md)。

**播放卡顿、自动暂停**
弱网环境下先切低音质档位（播放页音质标识处点一下）；检查是否误开了定时关闭（到点会自动停，见[同步歌词与播放设置.md](同步歌词与播放设置.md)）；后台被系统清理也会中断播放，把 ehshig 加入系统的后台运行/省电白名单，别让它被一键清理掉。

**听歌识曲没反应**
识曲要麦克风权限：系统设置 → 应用 → ehshig → 权限 → 允许麦克风，再重新试。

**下载点了没反应**
下载要存储权限，同样去权限设置里允许「文件和存储」类权限；会员权益相关规则见[会员与离线下载说明.md](会员与离线下载说明.md)。

## 四、账号、会员与扣费

**会员扣了钱没生效**
先完全退出重进、或退出重新登录；确认扣款账号与登录账号一致；超过 24 小时仍未生效，带订单号找应用内客服。详见[会员与离线下载说明.md](会员与离线下载说明.md)。

**已下载的歌播不了**
会员过期后，离线缓存的内容可能无法继续播放——这是官方用户协议写明的规则，续费后恢复。想长期保留的歌不要只依赖离线缓存。

**怎么取消自动续费**
到支付渠道侧关：微信「扣费服务」、支付宝「免密支付/自动扣款」、iOS「设置 → 订阅」，且要在到期前 24 小时以上操作，完整路径见[会员与离线下载说明.md](会员与离线下载说明.md)。

**换手机了，收藏和会员还在吗**
登录原来那个账号即可；账号数据跟着账号走，与设备无关。第三方登录（如微信）要先在新手机上登回同一微信。

**不想用这个账号了**
应用内提供注销入口（协议中称「删除账号」）：注销后服务停止、数据清除，不可恢复，操作前先把需要的收藏导出或记下。

## 五、权限与隐私

应用会按功能申请权限，按需给即可，关掉某项只影响对应功能：

| 权限 | 影响的功能 |
| --- | --- |
| 存储/文件 | 下载歌曲、保存铃声 |
| 麦克风 | 听歌识曲 |
| 相机 | 扫码登录、扫码 |
| 位置 | 个性化内容与广告（可拒绝） |
| 通知 | 新歌与活动提醒 |

不想收个性化广告，可在应用「设置 → 个性化推荐广告设置」里关掉开关（关闭后广告仍在，只是不再按你的听歌记录定制）。隐私条款的原文入口在应用内协议链接与官网 [www.ehshig.com](http://www.ehshig.com) 上，涉及个人信息处理的疑问按其中「如何联系我们」一节的渠道反馈。
