## 一、先确认手上是哪个版本

你从不同渠道拿到的 AccuBattery 版本未必一样，装之前先核对包信息，免得装错包：

| 项目 | 数值 |
| --- | --- |
| 版本号 | 2.1.6 |
| 包名 | `com.digibites.accubattery` |
| 安装包大小 | 16.07M（约 16,972,877 字节） |
| MD5 | `41FF31A009EBAA03ED0D7965DBC70FE9` |
| 开发者 | Digibites |
| 系统要求 | 官方标注支持大多数 Android 5.0+ 设备；手上这份包另有「需 Android 5.2 以上」的标注 |

核对 MD5 用任意带校验功能的文件管理器即可；包名在安装前也能从文件名或安装器的「应用信息」里看到。网上搜到的最新版可能是另一个版本号，**版本 / 包名 / 体积以上表为准**。

## 二、从网盘拿安装包并安装

1. 打开 [AccuBattery 安装文件资源（夸克网盘）](https://pan.quark.cn/s/22cb8d1fe685)，把 `AccuBattery_v2.1.6.apk` 转存到自己的网盘或直接下载到手机。
2. 手机上点击该 APK → 系统弹出「是否安装」→ 按提示装完即可。若提示「禁止安装未知来源应用」，按提示到设置里给对应来源（浏览器、文件管理器等）打开一次允许，装完可以再关掉。
3. 装好后桌面会出现 AccuBattery 图标，点开进入首次教程。

整个安装过程不需要 root，也不需要登录账号。

## 三、首次打开：教程与校准

首次启动会自动跑一遍教程，按官方帮助中心的说法，有三件事值得照做：

1. **设置充电警报** —— 教程会问你充到百分之几提醒拔线，官方建议设在 **80% 左右**。之后随时能在充电页拖动那个蓝色滑块改（详见 [充电页面与充电警报设置.md](充电页面与充电警报设置.md)）。
2. **校准（calibration）** —— 教程结尾会跑一个校准流程，用来识别你的机型、查出电池的设计容量。设备信息不准时可以之后手动改。
3. **允许通知** —— 充电警报是靠通知发出来的，装完先去系统设置里确认 AccuBattery 的通知是开着的。Android 8 以上它的通知分成「充电警报」「电池状态」等多个类别，个别设置要进系统通知设置里调，见 [常见问题与解决办法.md](常见问题与解决办法.md)。

教程想重跑一遍：点右上角菜单（三个竖点）→ Tutorial。校准不必反复做。

## 四、装完先认识四个标签页

底部一共四个标签，后面几篇文档都是按这四个页组织的：

| 标签 | 干什么用 | 对应文档 |
| --- | --- | --- |
| 充电（Charging） | 插电时看实时充电数据、拖充电警报滑块 | [充电页面与充电警报设置.md](充电页面与充电警报设置.md) |
| 放电（Discharging） | 拔掉充电器后看耗电速度、各应用耗电 | [耗电统计与续航估算.md](耗电统计与续航估算.md) |
| 寿命（Health） | 看电池健康度、估计容量随时间的变化 | [电池健康怎么看.md](电池健康怎么看.md) |
| 历史（History） | 逐条回看过去的充电 / 放电会话 | [充电页面与充电警报设置.md](充电页面与充电警报设置.md) |

一个直观的规律：**插着电时充电页是实时的，拔掉电时放电页是实时的**；没插电时充电页下方那一大块显示的是上一次充电的历史数据（有橙色横幅标出起止时间），别当成实时值误读。

## 五、几个开箱就该知道的口径

- **数据是攒出来的**：健康度、应用耗电、续航估算都要攒够几次充电 / 放电样本才有数，前几天看到空白或缺失是正常的。
- **屏幕亮着时数据会跳**：想测充电器或线材，灭屏充电再看，见 [充电页面与充电警报设置.md](充电页面与充电警报设置.md)。
- **免费版够日常用**：核心的健康度、充电警报、耗电统计都在免费版里，高级版主要多出悬浮统计窗、深色主题和更长历史记录，差异见 [常见问题与解决办法.md](常见问题与解决办法.md)。

遇到警报不响、数值缺失这类问题，直接看 [常见问题与解决办法.md](常见问题与解决办法.md)；想让健康度尽快出结果，看 [电池健康怎么看.md](电池健康怎么看.md)。
