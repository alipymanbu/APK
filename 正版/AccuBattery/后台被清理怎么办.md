## 一、先判断是不是被清理了

它要一直留在后台才能连续读电流、记充电会话。被系统或清理工具杀掉后，症状很典型：

- **历史页被切得七零八落**——一次充电变成好几条短记录，中间还缺一段；
- 某段时间的充电/放电数据整体缺失，放电页那格「最耗电的应用」突然没内容；
- 充着电打开应用，它像是刚启动（回到教程或重新加载）。

偶尔一次重启导致的断档不用管；**连续几天都断**，就是下面这套设置没做。

## 二、三道闸门，逐个放行

不管什么品牌，卡它的都是这三处，按顺序查：

1. **最近任务里加锁**（官方给的首选解法）：进多任务界面，找到 AccuBattery 的卡片**下拉或点锁形图标**加锁。这是持久设置，做一次即可——代价是这张卡片再也不能被划掉清走了。
2. **省电/电池优化白名单**：系统设置里搜「电池优化 / 电量优化」，把 AccuBattery 设为**不允许优化**。各品牌的任务 killer、省电模式里的例外名单也一并加上。
3. **允许自启动与后台活动**：别让它被「自动管理」判成可回收（下节有华为的官方路径）。

手机品牌自己的省电策略各不相同，官方给的兜底办法是按机型查 [dontkillmyapp.com](https://dontkillmyapp.com/) —— 这个站按品牌列出了每家要关哪个开关。

## 三、华为 / 荣耀的官方路径

华为官方支持页给出的「应用无法后台运行」排查步骤，对它同样适用：

| 设置项 | 操作 |
| --- | --- |
| 锁定后台 | 多任务界面对该应用卡片下拉加锁 |
| 启动管理 | 设置里搜「应用启动管理」→ 关掉自动管理 → 勾选允许自启动、允许关联启动、允许后台活动 |
| 电池优化 | 设置里搜「电池优化」→ 选所有应用 → 找到它 → 设为**不允许** |
| 省电模式 | 设置 → 电池 → 关掉省电模式（需要长期统计时） |
| 高耗电提醒 | 系统弹「高耗电提醒」时选「不再提示」，别顺手点了「关闭应用」 |

来源：华为官方支持内容 [consumer.huawei.com](https://consumer.huawei.com/cn/support/content/zh-cn00428704/)。其他品牌以各自官方说明为准，路径大同小异。

## 四、做没做对，怎么验

1. 灭屏放一晚上，第二天开历史页：**一晚上的充电应该是完整的一条**，不是三五段。
2. 插上充电器，看充电页顶部电流是否在正常跳动（这同时也是数据链路正常的标志，见 [常见问题与解决办法.md](常见问题与解决办法.md)）。
3. 还是断的话，回头检查第二节的三道闸门有没有漏掉——最常漏的是「电池优化白名单」，加了锁却没关优化的机器照样会被回收。

设置生效需要重启一次应用才稳定；改完后头一两天的记录可能仍有断档，属于旧数据，不用回滚。
