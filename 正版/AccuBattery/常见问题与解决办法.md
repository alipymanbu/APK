## 一、充电警报不响

警报是靠通知发的，所以「没响」基本都出在通知链路上，从上往下查：

1. **总开关**：系统设置 → 应用 → AccuBattery → 通知，确认「允许通知」开着。也可以长按它那条常驻通知直接跳进去。
2. **类别开关**：Android 8 以上它的通知分成多个类别——**充电警报**、**充电警报（勿扰时段）**、其他、**电池状态**（常驻那条）。进到类别列表里确认「充电警报」没被单独关掉。个别机型默认不显示类别列表。
3. **勿扰模式**：手机整机处于勿扰时默认不报。要让它在勿扰下也响，需打开该类别的「勿扰例外」；只调成静音的话，开了振动仍会震。
4. **应用内的勿扰时段**：设置页里有一段自己指定的起止时间（比如睡觉时不报），检查是不是被它挡了。
5. **声音选错**：警报音选「默认通知音」会用系统默认，想恢复应用自带的那声，要在声音列表里选「AccuBattery charge alarm」。

顺带两个常见疑问：

- **想隐藏通知栏那条常驻通知，又不想失去警报** —— 可以做到，把「电池状态」这个类别隐藏/静音即可，警报是另一个类别，不受影响。
- **只想去掉状态栏左上角的小图标** —— 把「电池状态」类别的优先级调到「低」或选「最小化通知」。较新的系统如果只让选「是否响声」，把它设为静音就行。

## 二、页面没数据 / 数值缺失

按位置对号入座：

| 位置 | 现象 | 处理 |
| --- | --- | --- |
| 充电页顶部 | 电流恒为 0 | 说明读不到这台机器的电池电流信息，属于机型兼容问题，把机型与系统版本发给官方支持邮箱最直接 |
| 充电页容量估计 | 一直不给数 | 充入不足 5% 不显示估值，继续充到 5% 以上 |
| 放电页应用耗电 | 空白 | 授予**使用情况访问权限**，授权后等 15 分钟以上 |
| 寿命页 | 空白/大量灰点 | 只采信充入 60% 以上的会话，先用几天；灰点是被拒样本 |
| 任何位置 | 找不到之前的提示卡 | 右上角菜单 → 设置 → 显示所有提示卡 |

权限授予过程本身报错的，参见官方帮助中心 [accubattery.zendesk.com/hc](https://accubattery.zendesk.com/hc) 里的「Unable to grant usage stats permission」。那里含完整用户手册与 FAQ；技术支持邮箱 `support@accubatteryapp.com`，提问前先把机型、系统版本、应用版本（本包为 2.1.6）备齐。

## 三、装完被提示有病毒 / 恶意软件

官方对此的说明是**误报**：应用用了加密手段防护自身代码，部分杀毒引擎读不到源码，就把「无法解析」当成了恶意特征。判断依据还是你自己：包的 MD5 与来源是否可信（核对方法见 [下载与安装教程.md](下载与安装教程.md)）。若你从不明来源拿到的包与这里给的信息对不上，那就别装。

## 四、健康度超过 100% 或看着离谱

分母（设计容量）的问题最常见——厂商填错、没填、或者你换过电池。按 [电池健康怎么看.md](电池健康怎么看.md) 第二节核对并手动改正设计容量，再看结果。出厂留有余量、以及单次样本噪音，也会让读数短暂越过 100%。

## 五、亮屏时间、耗电数字和系统对不上

三处口径差异，都不是故障：

- **亮屏时间**：应用读不到「亮着锁屏」的时段，所以这里统计的会比系统显示的少。
- **应用耗电**：AccuBattery 按前台归属记账，系统按模型分摊，详见 [耗电统计与续航估算.md](耗电统计与续航估算.md)。
- **电流/电压与 USB 线上测的不一致**：一边测的是电池侧、一边是接口侧，转换损耗与实时波动都会造成差异。

## 六、系统显示 AccuBattery 自己很耗电

它要在充电和放电全程持续读取电池数据，本身就有常驻开销，系统统计把它排到前面是正常现象。不想看到常驻通知，按第一节的做法隐藏「电池状态」类别即可，不影响警报。

## 七、免费版和高级版差在哪

| 能力 | 免费版 | 高级版 |
| --- | --- | --- |
| 健康度、容量估计、充电警报、耗电统计 | 有 | 有 |
| 广告与升级提示 | 有 | 移除 |
| 悬浮统计窗（电流 / CPU 占用叠在其他应用上） | 无 | 有 |
| 深色与 AMOLED 黑主题 | 无 | 有 |
| 历史卡片可回看范围 | 最近 24 小时 | 最多 150 条会话 |

悬浮窗的用途是边用别的应用边看实时电流——比如验证某应用的「省电模式」是否真的省电。注意进程级 CPU 叠加窗在 Android 7 以后因系统安全策略已不可用。升级走应用内购买，与安装包本身无关。
