## 一、资源嗅探在哪，能找到什么

X浏览器的**资源嗅探**能列出当前页面加载的视频、音频资源地址。入口在页面工具菜单里的「嗅探媒体资源」：播放视频的页面上点开它，嗅探成功后页面会弹出一个**视频工具条**，提供下载、播放等操作。

嗅探到的资源可以：

- 用第三方播放器在线播放；
- 交给下载器下载保存；
- 通过 DLNA 投屏到智能电视、电视盒子（同一套嗅探结果，详见官方教程 [如何投屏视频到其他设备](https://www.xbext.com/tutorials/how-to-cast-video-to-other-devices/)）。

## 二、为什么要绑第三方下载器

X浏览器内置的下载器按「保持简单」的思路只做了 HTTP 直链下载和断点续传。碰上大文件、BT 种子、M3U8 流媒体，就需要专业下载器接管。

| 下载器 | 特点 |
| --- | --- |
| FluxDown | 开源免费，支持 BT 磁力、ED2K、M3U8 |
| 1DM / 1DM Plus | 多线程下载，Plus 版功能更多 |
| ADM | 多线程 + BT，安卓上流行 |
| FDM | 免费开源的跨平台下载器 |
| Aria2App | 基于 Aria2，支持多种协议 |
| 迅雷 | 国内用户熟悉，BT 速度快 |
| Gopeed | 开源的新一代下载器 |
| Android 系统下载器 | 系统自带，无需安装 |

以上列表截至 2026-09 整理自官方教程页，以[官方页面](https://www.xbext.com/tutorials/how-to-bind-a-third-party-downloader/)当时显示为准。

## 三、绑定下载器的两种方式

1. **每次临时选**：下载文件时 X浏览器会弹出下载对话框，手机里装了受支持的下载器时，列表里能直接切换，点谁谁来接手；
2. **设默认下载器**：浏览器设置 → 基本设置 → **当前下载器**，选定后所有下载请求自动交给它。

几个常问的点（官方教程 FAQ 口径）：

- 绑定第三方下载器**不影响**内置下载器已有的下载记录，两边的记录各自独立；
- 可以同时装多个下载器，按场景临时切换；
- 装了下载器但列表里不显示：确认下载器能正常打开、在支持列表里，重启 X浏览器再试，必要时核对包名（如 ADM 是 `com.dv.adm`）。

## 四、M3U8 视频下载并转 MP4（四步）

M3U8 是流媒体格式，一个索引带一堆小片段，普通下载拿不到完整视频。配合 1DM、ADM、迅雷、FluxDown 之一，可以下载后**自动合并转成 MP4**：

1. 在 X浏览器打开目标网页，页面工具菜单 →「嗅探媒体资源」，拿到 M3U8 地址；
2. 点视频工具条上的「下载」；
3. 下载器解析后列出可选分辨率（如 1080p、720p、480p），选一个；
4. 下载完成后自动合并转换为 MP4，无需手动操作。

想先练手，官方教程里给了一个测试流地址：`https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8`（直接在 X浏览器里打开再嗅探）。

下载速度取决于视频源服务器、你的网络、片段数量；卡慢时优先换稳定 Wi-Fi。只下载你有权使用的内容，版权责任在使用者。

## 五、嗅探不到资源时

| 现象 | 原因与处理 |
| --- | --- |
| 嗅探列表是空的 | 资源可能要开始播放后才加载，先播一段再嗅探 |
| 视频能看但嗅探不到 M3U8 | 部分站点做了处理，嗅探本来就不是对所有网站有效，属正常限制 |
| 下载到一半失败 | 换下载器试试（不同下载器对流的兼容不一样），或换网络环境 |

页面播放卡顿等播放问题与浏览器整体的故障排查，见[常见问题与故障排查](常见问题与故障排查.md)；给嗅探装增强脚本（如自动嗅探）属于油猴脚本的用法，见[油猴脚本使用指南](油猴脚本使用指南.md)。
