# X浏览器常见问题与故障排查

> 页面异常、打不开、登录不了、卡顿、后台被杀、忘记手势密码——用 X浏览器最常碰到的这些问题，各给一条排查路径。

## 一、页面异常：空白、排版错乱、按钮点不动

按官方 FAQ 给的顺序逐项排除，每做一步就刷新页面看一次：

1. **关闭广告拦截**：拦截规则可能误杀页面元素（详见[广告拦截设置](广告拦截设置.md)的误杀处理）；
2. **禁用用户脚本**：脚本会改写页面，装多了容易把页面改坏；
3. **检查 JS 是否被禁用**：大部分页面需要 JS 才能正常渲染；
4. **清除浏览器缓存**：主菜单第二屏（菜单左滑）选「清理」；
5. 以上都无效 → 浏览器设置里「重置为默认设置」。

## 二、某些网页打不开

排查顺序：

1. 退出浏览器重新进入再试；
2. 切换网络环境（Wi-Fi 和移动数据各试一次）；
3. 用其他浏览器访问同一个网址，确认不是网站本身挂了；
4. 关闭广告拦截再试，排除误杀。

两点背景知识，遇到时不用怀疑浏览器坏了：

- 没有正常备案的网站、恶意网站可能被网络防火墙阻断，这不是浏览器的问题；
- 有些网址 UC/QQ 浏览器能打开而 X浏览器打不开，是因为那两家提供了服务器中转模式。官方对此的建议是尝试 [X浏览器 x5 内核分支版本](https://www.xbext.com/branch/xbrowser-x5-branch/)。

## 三、网页能看，但登录不了

登录依赖 Cookies。检查这两个开关：

| 设置项 | 位置 |
| --- | --- |
| 禁用 Cookies | 浏览器设置 → 高级设置 |
| 隐私模式不禁用 Cookies | 浏览器设置 → 安全及隐私 |

如果开了隐私模式，注意隐私模式下会话结束后登录状态不保留，属正常设计。

## 四、越用越卡

官方 FAQ 给的四个方向：

- **标签开太多**：内存不足会导致系统频繁换页造成卡顿。作者实测 200 个标签以内对性能没有明显影响，具体取决于手机本身；
- **网页本身重**：部分网页渲染时占用资源过多，关掉对照即可确认；
- **用户脚本装太多**：脚本会吃内存和 CPU，逐个禁用定位；
- **缓存堆积**：定期清理。主菜单第二屏「清理」，或在高级设置里开「自动清理页面缓存」。

浏览器占用空间随使用变大同理——安装包很小，占空间的是缓存，清理方式同上。

视频播放卡顿官方单独有一篇说明：[如何解决播放视频的卡顿问题](https://www.xbext.com/faq/how-to-solve-the-problem-of-playing-video-lag/)；下载视频相关的设置见[视频嗅探与视频下载](视频嗅探与视频下载.md)。

## 五、切后台就被杀

X浏览器**没有申请高优先级后台进程**，这是它省电省内存的设计取舍，代价是切到后台后容易被系统杀掉。减少被杀概率的办法：

1. 别开太多标签、少开重页面，降低内存占用；
2. 修改系统的省电策略，放行这个应用。以小米为例：手机设置 → 省电与电池 → 设置 → 应用智能省电（其他品牌入口类似，以各自系统为准）。

想在熄屏时继续播网页音频/视频，走另一条路：页面工具箱 → 网站设置 → 开「允许后台播放」（见[基础功能与上手设置](基础功能与上手设置.md)的速查表）。

## 六、忘记手势密码

给历史记录、收藏夹、密码管理设了手势解锁又忘了的话：

1. 在浏览器地址栏输入 `x:info` 打开信息页；
2. 拉到页面底部，点 **Reset gesture unlock password** 重置手势密码。

## 七、返回键被网页劫持

恶意网页常劫持返回键，表现为怎么按都退不出当前页。这时**长按后退键**，会弹出页面的返回路径列表，直接选你要回的那一层。

## 八、换手机或重装后数据还在吗

可以。三条路任选（可叠加）：

1. 定期手动备份：浏览器设置 → 用户中心 → 备份用户数据，备份到公共下载目录；
2. 默认每周自动备份到下载目录（可在设置里调周期）；
3. 登录云端账号后开启自动同步。

备份/同步的内容包括：快速访问、收藏夹、全部设置、自定义拦截规则、密码与自动填充、当前打开的标签、脚本管理器里的脚本；手动备份额外含历史记录与离线文件。账号只支持邮箱注册（官方明确不收手机号、QQ、微信），邮箱只用于找回密码和通知。

具体的导入、备份与和电脑浏览器互同步的操作步骤，见[书签导入与数据备份同步](书签导入与数据备份同步.md)。
