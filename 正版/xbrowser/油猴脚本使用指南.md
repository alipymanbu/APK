## 一、和桌面浏览器装脚本有什么不同

在 Chrome 上用油猴脚本，你得先装 Tampermonkey 这类管理器扩展；X浏览器把这个管理器**做在了浏览器里**，拿到脚本就能直接装。脚本能做的事和桌面端一样：页面翻译、自动翻页、去广告辅助、界面改造等。

管理入口统一在：**浏览器设置 → 用户脚本**。装过的脚本都在这里开关和删除。

## 二、安装脚本的两种方式

### 方式一：地址栏直接打开脚本地址（最简单）

1. 复制脚本的 URL（通常以 `.user.js` 结尾）；
2. 粘贴到 X浏览器地址栏打开；
3. 浏览器识别出油猴脚本，弹出安装提示，点安装即可。

想验证流程，可以打开官方的测试脚本 [gm-hello.js](https://www.xbext.com/download/code/gm-hello.js)，装完后访问 `www.example.com` 会弹出一个 Hello World 对话框。

### 方式二：从 Greasy Fork 安装

[Greasy Fork](https://greasyfork.org/) 是主要的脚本分享站，脚本量大、更新勤。以装一个脚本为例：

1. 打开脚本详情页，点「安装此脚本」；
2. 第一次装脚本时站点会弹对话框，选 **「我已经安装了用户脚本管理器，让我安装」**（X浏览器内置管理器，所以直接这么选）；
3. 再次点安装，X浏览器弹出安装提示，确认即可。

其他脚本站合集官方也整理了一份：[受欢迎的脚本站点列表](https://www.xbext.com/favorites/popular-user-script-sites/)。官网自己还维护了几个常用脚本，如 Cookie 管理器、网页翻译器、快捷搜索工具条，都在官网用户脚本栏目里。

## 三、装完没生效，按这个顺序查

| 现象 | 排查 |
| --- | --- |
| 装完脚本页面没变化 | 先到 设置 → 用户脚本 确认脚本处于**启用**状态 |
| 启用了还是没反应 | 检查脚本元数据里的匹配规则（`@match` / `@include` / `@exclude`）是否覆盖当前网页 |
| Greasy Fork 点安装没反应 | 站点先弹了「我已经安装了用户脚本管理器」提示，按完流程再点一次安装 |
| 脚本功能在手机上不对劲 | 很多脚本是为 PC 页面写的，装之前先看脚本作者说明里是否注明兼容手机浏览器 |

脚本与广告拦截互相影响的场景（脚本改坏页面、拦截误杀脚本资源），排查思路见[常见问题与故障排查](常见问题与故障排查.md)的第一节。
