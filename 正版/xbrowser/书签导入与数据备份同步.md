## 一、从其他浏览器导入书签（HTML 方式）

几乎所有浏览器都支持把书签导出成 HTML 文件，X浏览器也从这个格式导入：

1. 在旧浏览器里把书签**导出为 HTML**；
2. 把这个 HTML 文件放进手机公共下载目录（通常是 `/sdcard/Download`）；
3. 打开 X浏览器：浏览器设置 → 用户中心 → **从 html 文件导入书签**；
4. 选中文件完成导入。

还有两条更省事的路：直接用 X浏览器打开那个 HTML 书签文件，或把文件「分享/发送」给 X浏览器，它会自动识别并导入。

## 二、账号与云端同步

X浏览器的账号**只用邮箱注册**——官方明确不收集手机号，也不接受 QQ、微信登录，邮箱只用于找回密码和通知。登录云端账号后可以开启自动同步，数据一有变动就推到云端。

同步的数据包括：主页快速访问、收藏夹、全部设置、自定义拦截规则、密码与自动填充、当前打开的标签、脚本管理器里的脚本。

## 三、本地备份（不登录账号也行）

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 手动备份 | 浏览器设置 → 用户中心 → 备份用户数据 | 存到公共下载目录，重装前先做一次 |
| 自动备份 | 默认开启 | 每周自动备份到公共下载目录，周期可调 |

手动备份的内容比云端同步**多两样**：历史记录和离线文件。

三个手段可以叠加用：定期手动备份一份 + 保留每周自动备份 + 登录账号开自动同步。这样即使卸载重装，也能从备份文件或云端恢复到原来的状态。

## 四、和电脑浏览器互相同步书签

手机和桌面浏览器之间搬书签，官方提供一个开源扩展：**书签同步助手**，装在电脑浏览器上、登录同一个 X浏览器账号后双向同步。

- 支持的桌面浏览器：Chrome 88+、Edge 88+、Firefox 109+，以及其他 Chromium 内核浏览器（截至 2026-09，以[官方介绍页](https://www.xbext.com/tools/xbrowser-bookmark-sync/)为准）；
- 优先从各自扩展商店安装，官方页面上有 Chrome / Edge / Firefox 三个商店的直达链接；
- 商店装不了时，也可以下载 CRX 文件，在 `chrome://extensions/` 开启开发者模式后拖拽安装。

已知的使用注意（来自官方页面与作者答复）：

| 情况 | 处理 |
| --- | --- |
| 装完找不到扩展图标 | 被浏览器折叠进「拼图/扩展」菜单了，在里面固定到工具栏 |
| 登录后不同步 | 确认网络可用；必要时退出账号重新登录 |
| 多设备同步有延迟 | 云端同步需要时间，等片刻或手动触发一次 |
| 360 极速浏览器上只能上传不能下载 | 作者答复未测试过该浏览器，建议用 Chrome 或 Edge |

## 五、换机 / 重装的完整顺序

1. 旧手机：先做一次手动备份（确认备份文件在公共下载目录，换机时一并拷走），账号开着自动同步的等它推完；
2. 新手机：装好 X浏览器（安装见[下载与安装教程](下载与安装教程.md)）；
3. 恢复：登录账号拉取云端数据，或从备份文件导入；
4. 核对：收藏夹、设置、脚本都在，再开始用。

恢复后个别页面异常或登录态丢失，属于缓存与会话不随备份走的正常现象，排查见[常见问题与故障排查](常见问题与故障排查.md)。
