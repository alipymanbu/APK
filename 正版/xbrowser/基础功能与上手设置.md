## 一、界面逻辑：和 Chrome 一样「一切皆页面」

X浏览器的主界面只有两块：顶部搜索框（含快速访问入口）和底部工具条。收藏、历史、下载、设置这些功能都是独立页面，交互方式与普通网页一致——如果你用过 Chrome，这套逻辑不需要学习。

主页默认不放新闻流，也没有任何推送，这是它与国产手机浏览器上手后最大的体感差别。

## 二、切换与自定义搜索引擎

切换搜索引擎有四种方式，任选顺手的：

1. 在主页**长按搜索框**；
2. 输入关键词后，**长按搜索框右侧的搜索按钮**；
3. 把工具条某个按钮的长按手势设为「切换搜索引擎」（浏览器设置 → 手势设置）；
4. 安装官网提供的「快捷搜索工具条」增强脚本。

想用内置列表之外的引擎，走 **浏览器设置 → 高级设置 → 添加自定义搜索引擎**：找到目标引擎的查询参数，把参数值替换成 `%keywords%` 占位符。比如把 Bing 做成自定义引擎，就填：

```text
https://www.bing.com/search?q=%keywords%
```

保存后它就会出现在搜索引擎切换列表里。

## 三、标签页的几个实用操作

| 你想做的事 | 操作 |
| --- | --- |
| 调整标签顺序 | 打开标签列表，拖动标签右侧的图标 |
| 恢复刚关掉的标签 | 在手势设置里把某个长按按钮设为「恢复刚刚关闭的标签」；或开启「快捷触碰手势」后在屏幕上画一个反向开口的 `ɔ` 形，可连续执行直到全部恢复 |
| 启动时不自动打开上次的标签 | 浏览器设置 → 基本设置 → 启动恢复上次未关闭标签，选「询问」或「禁用」 |

## 四、手势与个性化

X浏览器的可定制范围主要在三处：

- **手势**：浏览器设置 → 手势设置。长按手势、快捷触碰手势都能映射到具体动作（恢复标签、切换搜索引擎等）；
- **外观与布局**：菜单可以自定义项目，搜索栏可以放到屏幕底部；
- **每站记忆**：地址栏进入某网站后，通过页面工具箱 → 网站设置，可以对单个网站单独开「允许后台播放」等选项（熄屏继续听网页音频就靠这个）。

## 五、阅读模式与离线保存

看长文和小说时，阅读模式会自动抽取正文、过滤页面广告，并支持预读与自动拼页（下一章自动接上）。存内容做离线也有三种形态：整页截图、保存为 PDF、保存为 MHT 单文件。

## 六、常用设置路径速查

| 需求 | 设置路径 |
| --- | --- |
| 移动页面强制缩放 | 浏览器设置 → 高级设置 → 强制页面缩放 |
| 前进/后退不重新加载页面 | 浏览器设置 → 高级设置 → 打开超级缓存 |
| 自动清理页面缓存 | 浏览器设置 → 高级设置 → 自动清理页面缓存 |
| 后台播放网页音视频 | 页面工具箱 → 网站设置 → 允许后台播放 |
| 添加自定义搜索引擎 | 浏览器设置 → 高级设置 → 添加自定义搜索引擎 |
| 启动恢复上次标签 | 浏览器设置 → 基本设置 → 启动恢复上次未关闭标签 |

设置完这些，浏览器基本就顺手了。下一步建议先把[广告拦截设置](广告拦截设置.md)里的规则订阅配好；想在浏览器里直接存网页视频，看[视频嗅探与视频下载](视频嗅探与视频下载.md)；要折腾油猴脚本，见[油猴脚本使用指南](油猴脚本使用指南.md)；遇到具体故障再翻[常见问题与故障排查](常见问题与故障排查.md)。
