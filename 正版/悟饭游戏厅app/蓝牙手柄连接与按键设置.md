# 悟饭游戏厅蓝牙手柄连接与按键设置

悟饭游戏厅把外设入口放在「我的 → 手柄」里，连接分蓝牙和 OTG 两条路；连上之后还要做一次键位映射，手柄才能真正控制游戏。本篇按「配对 → 校验 → 调键位」的顺序走。

## 一、连接蓝牙手柄

1. 打开悟饭游戏厅，点底部导航栏的**「我的」**；
2. 在功能栏里找到**「手柄」**，点进去；
3. 点**「开启蓝牙」**，页面会跳到手机的系统蓝牙设置，把蓝牙开关打开；
4. 按手柄说明书进入配对态（常见做法是长按 `A + Mode` 键，指示灯快闪后松开）；
5. 在手机的蓝牙设备列表里选手柄完成配对，显示已连接后返回悟饭游戏厅；
6. 回到手柄页面，如果列表里出现了你的手柄型号，就说明连接成功；随便按几个键，界面对应位置有反应亮灯，按键就是通的。

## 二、支持哪些手柄

应用内手柄页面列出的支持类型包括：悟饭定制手柄、北通蓝牙手柄、小米蓝牙手柄、IPEGA 蓝牙手柄、雷剑蓝牙手柄、其他蓝牙手柄，以及主流 OTG 手柄。列表以你应用内「我的 → 手柄」页面显示的为准。

## 三、有线（OTG）手柄怎么接

1. 用 OTG 转接头把有线手柄接到手机上（手机本身要支持 OTG）；
2. OPPO、VIVO 品牌的手机需要先到**设置 → 其他设置**里把 OTG 功能打开，否则插上没反应；
3. 插好后回到悟饭游戏厅的「手柄」页面，能识别到手柄即可进入下一步。

## 四、连接后：做一次按键映射

蓝牙或 OTG 连上只是让手机认识手柄，还要把按键映射到游戏里：

1. 在「我的 → 手柄」页面确认手柄型号下方显示**已连接**；
2. 点下方的**「映射按键」**进入键位设置，按你的习惯调整各键的对应关系；
3. 进入游戏后，按界面上的提示（通常有箭头指引）打开**「摇杆和按键」**设置；
4. 在这里可以调方向键**位置**、**透明度**，以及设置**连发键**；调完保存，返回就能用手柄开打。

## 五、连不上、没反应时

- **蓝牙列表里搜不到手柄**：确认手柄已进入配对态（指示灯按说明书在闪）；没闪就重新长按组合键进入配对；
- **OTG 插上没反应**：OPPO / VIVO 先检查系统设置里的 OTG 开关是否打开（第三节第 2 步），再换一个 OTG 头试；
- **手柄连上了但游戏里不动**：多半是没做映射（第四节），进游戏按提示打开「摇杆和按键」确认键位已经设置并保存；
- **按键位置和手指习惯对不上**：回游戏内「摇杆和按键」重新摆位置，不必重连手柄。
