## 一、这份安装包的基本信息

beanfun!（官方写法为小写加感叹号，即 beanfun!）是台湾游戏橘子集团（Gamania）面向玩家的会员平台应用：一个账号登入旗下多款游戏、扫码登录电脑端游戏、管理 GASH 乐点点数、接收游戏资讯与社群动态。对想玩橘子系台服、港服游戏的玩家来说，注册与日常登录基本都绕不开它。

下面是这份安装包的实际信息，与网盘里那份文件一一对应：

| 项目 | 内容 |
| --- | --- |
| 版本 | 3.6.10 |
| 安装包大小 | 约 95.28 MB |
| 包名 | `com.gamania.beanfun` |
| MD5 | `A0EB92DEA0DBC1E473392F7D98396228` |
| 适用系统 | Android 手机 |

两点提醒：

- 官方 Google Play 上的版本可能已经更新到更高，功能界面会有些差异；以官方商店页面显示为准。
- 手机上的应用商店如果直接能搜到 beanfun!，也可以从商店安装；走安装包安装通常是为了拿到特定版本，或在商店不可用的环境下使用。

## 二、获取安装包

安卓安装包（APK）从 **[Beanfun 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a41702d74f74)** 获取：打开链接 → 转存到自己的网盘 → 下载到手机本地存储。

iOS 用户没有对应的安装包：beanfun! 的 iOS 版只通过 App Store 分发，直接在 App Store 搜索「beanfun」安装即可；台/港/澳以外地区的 App Store 可能搜不到，需要切换对应地区的 Apple ID。

下载完成后建议先核对一下文件大小（约 95 MB 量级），明显偏小说明没下完整，装不上的概率很大。

## 三、安装步骤

APK 属于「绕过应用商店」的安装方式，安卓默认会拦一道，流程如下：

1. 把 APK 文件放到手机存储里（网盘 App 直接下载，或从电脑拷过去）。
2. 用系统自带的「文件管理」找到这个 APK，点它。
3. 系统会提示「禁止安装未知来源应用」——这是安卓的安全默认值。点提示里的「设置」，允许你正在用的那个文件管理器（或浏览器）「安装未知应用」，返回后继续。
4. 等安装进度走完，点「打开」。

各品牌手机的「允许安装未知应用」入口略有差异，都在「设置 → 应用管理 → 特殊应用权限（或类似名称）→ 安装未知应用」这一层级下，按提示跳转即可。

## 四、安装后第一次打开

1. 首次启动会请求网络、通知等常规权限，按需允许。
2. 界面默认是繁体中文，这是正常现象——这个应用主要面向台湾、香港、澳门的玩家，官方没有简体中文界面。
3. 新用户走「注册」流程创建账号，老用户直接登入。注册环节要准备一个常用邮箱，具体注意事项写在 [账号注册与认证方法.md](账号注册与认证方法.md) 里，建议先看那篇再动手注册。
4. 如果你的主要目的是在电脑上玩橘子系端游（比如新楓之谷），装好 App 后第一时间把账号安全设置做掉，之后就能用手机扫码登录电脑，见 [扫码登录电脑游戏.md](扫码登录电脑游戏.md)。

## 五、安装阶段常见报错

| 现象 | 常见原因与处理 |
| --- | --- |
| 提示「解析包时出现问题」 | 安装包没下载完整，或下载过程被中断。重新下载一次，下完核对文件大小。 |
| 提示「与应用冲突」或安装按钮灰色 | 手机里已经装过低版本或同名应用。先卸载旧的再装；注意卸载不会删除你的游戏账号本身。 |
| 存储空间不足 | 这个安装包接近 100 MB，安装时还要翻倍的临时空间，清出至少 1 GB 再装。 |
| 安装完成后图标点不开、闪退 | 确认安卓系统版本达到应用要求（过老的系统装上新版应用会闪退）；重启手机再试一次。 |
| 安装后被手机管家标记风险 | 官方包名是 `com.gamania.beanfun`，可以用 MD5 核对文件是否原封未动；被标记多为商店外安装的通用提示，自行判断后加入信任或卸载。 |

装好并注册完账号之后，日常用得最多的两个场景是扫码登录电脑游戏和管理 GASH 点数，分别在 [扫码登录电脑游戏.md](扫码登录电脑游戏.md) 与 [GASH乐点储值与消费.md](GASH乐点储值与消费.md) 里展开。
