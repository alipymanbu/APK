## 一、验证信/验证码收不到

按顺序排查：

1. **翻垃圾邮件**：官方信件被误判进垃圾箱是最常见原因，确认后把发件人加入白名单。
2. **等 5~10 分钟再重发**：国际邮件有延迟，连续狂点重发只会让后来的信被限流。
3. **换邮箱重试**：个别邮箱服务商与官方信件的投递不稳定，有用户反馈换国际邮箱后恢复正常（邮箱选择的详细建议见 [账号注册与认证方法.md](账号注册与认证方法.md) 第三节）。
4. **短信验证码收不到**：先确认号码是否属于支持地区（手机验证有地区限制，见注册篇第四节），再检查手机拦截软件有没有把国际短信拦掉。

## 二、忘记密码

1. 在登录页点「忘记密码」。
2. 输入注册邮箱，系统寄重设信件。
3. 从邮箱里的链接进入，设定新密码。
4. 回到登录页用新密码登入，顺手在 App 里检查一次已登录设备列表。

走不通的情况一般是：注册邮箱自己也登不进了、或注册资料对不上。这时只能走官方客服申诉，需要提交身份类证明——这就是注册时强调生日要填真实的原因，资料对得上申诉才快。

## 三、换手机：动态密码器怎么迁移

验证器（Google Authenticator / Microsoft Authenticator）的动态密码存在**旧手机本地**，换机不会自动跟过去。两种情况分开处理：

**旧手机还在手上：**

1. Google Authenticator：旧手机里导出该账号的二维码/转移码，新手机扫码导入。
2. Microsoft Authenticator：开启云备份并在新手机用同一账号恢复，或同样用账号转移流程。
3. 迁移完成后在新手机上看一眼动态码是否正常刷新，旧手机上的条目再删除。

**旧手机已经没了/送人了：**

验证器条目无法凭空恢复，需要走官方渠道解除双重认证绑定，通常要提交身份验证资料。所以：**换机前先迁移，是这一节唯一想让你记住的话**。如果嫌麻烦，注册验证器时直接登录账号使用（而不是跳过登录），动态密码会跟着账号走，换机只需重新登录。

## 四、账号被锁/登录异常

| 情形 | 处理思路 |
| --- | --- |
| 提示账号锁定 | 先分清是「登录失败过多」还是「游戏账号被停权」：前者改密等待即恢复；后者要走客服申诉，完整流程见 [账号被锁与解锁申诉.md](账号被锁与解锁申诉.md)——涉及身份认证的上传**本人**证件，资料与注册信息一致才能通过 |
| 提示异地登录/新设备验证 | 属于安全机制，手机扫码或动态密码确认即可放行 |
| 怀疑被盗（收到非本人操作的登录通知） | 立即改密码 → 检查并下线不认识的已登录设备 → 确认双重认证处于开启状态 |
| 点数异常消耗 | 先查 App 钱包交易明细定位扣费来源，再联系官方客服申诉；流水记录是申诉的依据 |

预防的成本远低于解锁的成本：密码独立不复用、双重认证开起来、注册资料留真实，三件事做完，绝大多数锁号风险已经挡在门外。行为侧同样有红线——外挂、代练、账号交易是官方查禁的重点，命中即停权；这类「为什么被锁、怎么申诉」的完整讨论在 [账号被锁与解锁申诉.md](账号被锁与解锁申诉.md)。

## 五、App 打不开/页面加载失败

1. **先分清是不是网络环境问题**：beanfun! 的官网与服务面向台湾、香港地区，其他地区的网络直连可能加载缓慢或超时；先用浏览器开一下官网 `https://tw.beanfun.com`，官网都打不开时大概率是网络路径问题，不是 App 坏了。
2. **官方维护**：例行维护时段相关服务一起停（各游戏维护时间不同，以官网维护公告为准），等维护结束再试。
3. **App 版本过老**：老版本遇到服务端升级会连不上，更新到官方商店当前版本即可。
4. **系统时间不准**：影响登录态与动态密码校验，开启自动获取网络时间。

## 六、日常安全清单

- 密码独立设置，不与其他网站共用。
- 双重认证保持开启；验证器换机前先迁移。
- 定期看一次「已登录设备」，不认识的直接下线。
- 点数卡卡密只输入在官方储值页，任何私聊索要卡密的都是风险信号。
- 客服只认官方站内/官方页面提供的渠道，搜索引擎排前头的「客服电话」广告位不要信。
