## 一、为什么端游登录要靠这个 App

橘子系的电脑端游戏（比如台服新楓之谷）走的是网页登录流程：游戏启动器把你带到官网登录页，输账号密码后才回到游戏。问题在于这套流程对账号安全的要求越来越细——异地登录、非常用设备，都容易触发额外验证。

beanfun! App 提供的另一条路是**扫码登录**：电脑登录页显示一个二维码，你在手机 App 里确认一下，登录就完成了。好处有两个：

- 电脑上全程不用输密码，键盘记录、输错锁定这类风险都绕开了；
- 手机在手边才能确认，别人拿到你的电脑也登不进你的账号。

## 二、扫码登录步骤

1. 手机上确认 beanfun! 已经登录你的账号（首次使用先完成 [账号注册与认证方法.md](账号注册与认证方法.md) 里的流程）。
2. 电脑上启动游戏，走到登录页，选择扫码/QR Code 登录方式，屏幕上出现二维码。
3. 打开手机 beanfun! App，用 App 内的扫一扫功能对准电脑屏幕上的二维码。
4. 手机上弹出确认框，核对设备信息后点确认。
5. 电脑上的登录页自动跳转，登录完成，回到游戏即可。

整个过程手机必须能上网，并且登录的是同一个账号——手机上登着 A 账号、电脑想登 B 账号是扫不了的。

## 三、另一条路：动态密码登录

如果当时手机扫不了码（比如电脑屏幕反光、摄像头不方便），登录页也支持「账号 + 密码 + 动态密码」的传统方式：

1. 前提是你在 [账号注册与认证方法.md](账号注册与认证方法.md) 第五节把验证器绑定好了。
2. 登录页输账号密码后，打开手机上的验证器应用，把当前显示的 6 位动态码填进登录页。
3. 动态码每 30 秒换一次，填的时候注意倒计时，快跳秒就等下一组再填。

两条路的效果一样：都用「你手机上才有的东西」证明是你本人。

## 四、常见游戏与官方入口

| 入口 | 地址 |
| --- | --- |
| 台湾站（游戏与会员服务主站） | `https://tw.beanfun.com` |
| 香港站 | `https://hk.beanfun.com` |
| 台服新楓之谷专站 | `https://maplestory.beanfun.com` |

同一账号在不同站点分区登录——台湾账号走 `tw.beanfun.com`，香港账号走 `hk.beanfun.com`，点数也是分区管理的（详见 [GASH乐点储值与消费.md](GASH乐点储值与消费.md)）。进游戏前先弄清自己的账号是哪个区，站选错了登录页会找不到你的账号。

两个登录页的细节，进游戏前值得知道：

- **游戏子账号**：端游登录用的不是 beanfun! 主账号本身，而是挂在它下面的「游戏账号」。一个 beanfun! 账号下可以建多个游戏子账号（社区旧教程写上限 5 个，现行为以官方页面为准），登录时先选要用的那一个。
- **入口位置**：登录入口在官网页面上的登录条/按钮里，登录成功后从游戏列表点「启动」进入游戏；官网偶尔改版，找不到入口时以官网当时的页面结构为准。

## 五、扫码失败排查

按出现频率从高到低：

| 现象 | 处理 |
| --- | --- |
| 扫码后电脑页面没反应 | 网页会话过期了，刷新登录页重新生成二维码再扫；二维码通常一两分钟就失效，是设计如此不是故障 |
| 手机提示网络错误 | 手机网络不稳定，换 Wi-Fi/流量再试 |
| 扫码成功但登录页报错 | 确认手机 App 与电脑登录的是同一个账号、同一个站点分区；不对就先在 App 里切换/登出重登 |
| 二维码扫不出来 | 把电脑屏幕亮度调高、关闭护眼模式/滤镜，App 扫码窗对准整个二维码 |
| 每次都要额外验证 | 正常现象：新设备、异地 IP 都会触发更严格的检查，按页面提示走完即可；频繁出现在常用设备上时，检查是否清了浏览器 Cookie |
