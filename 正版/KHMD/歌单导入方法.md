# KHMD 歌单导入方法

> 本篇讲怎么把你在其他音乐平台攒的歌单导入 KHMD，以及歌单解析失败时的排查。
> **相关文档**：[搜歌与下载步骤.md](搜歌与下载步骤.md) · [音质与下载路径设置.md](音质与下载路径设置.md) · [常见问题排查.md](常见问题排查.md)

## 一、导入的入口在哪

KHMD 支持把其他平台歌单里的歌搬过来，不用一首一首重新搜。入口在**左上角菜单 → 歌单导入**。

进入后先选歌单来自哪个平台（支持哪些平台以应用内列出的为准，分发页介绍里提到 QQ 音乐、网易云音乐、酷我等），然后把那个平台分享出来的歌单链接完整粘进输入框，点「解析」。解析成功后歌单里的歌会列出来，接着逐首试听或勾选批量下载，下载步骤见 [搜歌与下载步骤.md](搜歌与下载步骤.md)。

## 二、歌单链接从哪拿

在原平台自己的应用里打开要搬的歌单 → 点「分享」→ 复制链接。要的是**歌单本身的分享链接**，不是某首歌的链接，也不是你的个人主页链接。

## 三、解析失败怎么排查

提示解析失败时，应用里有一句「解析失败看这里」的提示，点开按它给的步骤重来。常见失败原因与对应处理：

| 原因 | 处理 |
| --- | --- |
| 链接复制不完整 | 重新分享一次，整条复制，别手抄 |
| 粘贴的是歌曲链接或主页链接 | 回原平台重新分享整个歌单 |
| 歌单设成了私密 | 在原平台把歌单设为公开再试 |
| 平台改版导致解析失效 | 隔几天再试，或先换另一个平台的歌单试 |

## 四、导入之后

导入的只是歌单里的歌曲清单，不是音频文件，想离线听还是要逐首下载。音质怎么选见 [音质与下载路径设置.md](音质与下载路径设置.md)；哪首搜不到、下载失败，处理思路见 [常见问题排查.md](常见问题排查.md)。
