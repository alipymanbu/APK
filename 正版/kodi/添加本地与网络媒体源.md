## 一、总流程：加目录 → 定内容类型 → 扫库

不管片源在本地还是网络，套路一样：

1. 主页进「**电影**」（或「剧集」「音乐」）→ 提示目录为空时选「**进入文件区**」/「添加视频」；
2. 点「**添加视频…**」→「浏览」→ 选中或新建源；
3. 弹出「**设置内容**」对话框 → 勾选「**此目录包含**」→ 选「电影」或「剧集」→ 选择信息提供方（刮削器，内置有 The Movie Database 等）→ 语言选中文；
4. 确定后 Kodi 开始扫描，扫完主页电影面板就是带海报与简介的墙。

只选了目录、没设内容类型，目录里的文件只能「文件模式」手动点播，不会进媒体库、不会有海报。

## 二、加本地文件夹（手机存储 / 盒子外接 U 盘移动硬盘）

「浏览」窗口里选「主目录」或「外部存储器」，一路进到影片所在目录确认即可。前提是第一节里说的存储权限已经给了（Android TV 11+ 手动授权见[首次启动与中文设置.md](首次启动与中文设置.md)）。

**剧集目录的形状会影响刮削效果**：每部剧一个文件夹、集名里带 S01E01 这类编号，识别率最高；几百集全部平铺在一个目录里，刮削器猜不准哪集是哪集。扫错了可以「设置内容」里改类型后重新扫，或清空媒体库重来。

## 三、连 Windows 共享 / NAS（SMB）

这是把 Kodi 当客厅播放器用的主流接法——片子都在电脑或 NAS 上，盒子只负责播。

**方式 A：浏览网络位置**。「浏览」窗口选「**Windows 网络（SMB）**」，理论上能直接看到同网段的工作组与设备（这个能力依赖 WS-Discovery 发现机制，Kodi 19.1 起恢复支持，Windows 10 默认开启）。能浏览到就直接点进去选目录。

**方式 B：手动添加网络位置**（浏览不到时用，更稳）。在「浏览」窗口选「**添加网络位置…**」：

| 字段 | 填什么 |
| --- | --- |
| 协议 | Windows 网络（SMB） |
| 服务器名称 | 电脑或 NAS 的 IP（如 `192.168.1.10`，推荐 IP，比机器名稳） |
| 共享文件夹 | 共享名，如 `Media` 或 `movies` |
| 用户名 / 密码 | 共享设置的账号；**即便共享没设密码也要随便填两个非空字符**，留空在部分系统组合下会连不上 |

连 Windows 电脑做服务器时，记得电脑端「网络发现」和「文件共享」是打开的；路由器若开了「AP 隔离」，盒子与电脑互相看不见，先去路由器里关掉。SMB 版本方面，Kodi 不支持早已淘汰的 SMB1，NAS 端至少开 SMB2。连不上时按[常见问题排查.md](常见问题排查.md)的 SMB 一节逐项过。

## 四、NFS 与 UPnP

- **NFS**：NAS 用户（群晖、威联通等）常用，性能通常好于 SMB。接法同样是「添加网络位置」选 NFS 协议，填服务器 IP 与导出路径；NAS 端要先在共享文件夹设置里开 NFS 权限。
- **UPnP**：不想配置账号密码时的省事路线。电脑端 Windows 的「媒体流」或 NAS 的 DLNA/UPnP 服务打开后，Kodi 的「浏览」窗口里会出现「UPnP 设备」，点开就能选目录播放。缺点是元数据整理能力弱，适合临时看，不适合养媒体库。

## 五、扫库之后的两个常用动作

- **重扫**：目录右键（长按）→ 有「扫描媒体库到新内容」；海报下载失败或信息错了，进「设置内容」改刮削器与语言后再扫。
- **改内容类型**：扫出来的分类不对（剧集被当成电影），进「设置内容」改「此目录包含」的类型即可，不用删源。

片库扫好之后，配一个字幕下载服务是下一步最值得做的事，见[字幕下载与音轨切换.md](字幕下载与音轨切换.md)。想接的还有直播频道（M3U 列表 + 节目单），那是另一条 PVR 路线，见[直播电视IPTV接入.md](直播电视IPTV接入.md)。
