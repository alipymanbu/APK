## 一、首次启动会经过什么

装好后点开 Kodi，第一次启动通常停在两件事上：

1. **存储权限请求**：手机端首次进入会弹「允许 Kodi 访问照片、媒体和文件」，选允许——不让它读存储，本地视频一个都看不到。Android TV 11 及以上的设备经常**不弹这个窗**，导致 Kodi 里看不到任何本地文件，需要手动去系统设置开：`设置 → 应用 → Kodi → 权限 → 文件和媒体 → 始终允许`。这一步是电视盒子上最常见的「装好了却没片可放」的原因。
2. **首次进入主页**：你会看到一个深色界面，左侧一排「电影 / 剧集 / 音乐 / 电视节目」等入口。这些只是分类壳子，点进去都是空的——因为还没告诉它媒体放在哪，这一步在[添加本地与网络媒体源.md](添加本地与网络媒体源.md)里做。

## 二、换中文：先把字体改成 Arial based

直接把语言切成中文，界面上的字会全部变成方块——这不是乱码故障，而是默认皮肤字体不含中文字形。正确顺序是两步，**第一步不能跳**：

1. **改字体**：主界面点左上角齿轮（设置）→ **界面（Interface）** → **皮肤（Skin）** → **字体（Fonts）** → 从默认值改为 **Arial based**。
2. **改语言**：回到 **界面（Interface）** → **区域（Regional）** → **语言（Language）** → 在列表里选 **Chinese（Simple）**。

列表是按字母序的长列表，Chinese 排在 C 开头那段。选完界面立即切换为中文，无需重启。

两步的先后顺序不能反：先切语言再改字体，满屏方块会让你连菜单都找不到。万一已经变成了方块，按同样的菜单路径（位置没变，只是字看不懂）把字体改回即可。

## 三、顺手确认版本号

换完中文，打开「设置」页，左下角就能看到版本号。本套文档对应的是 **21.3**（Omega 系列的一个修正版）。如果你手里的数字不同，菜单位置大体一致，个别设置项名称以你屏幕上显示的为准。

## 四、几个值得马上改的小设置

都在设置里，改不改随你：

- **设置级别**：设置页左下角有个级别滑块（基本 / 标准 / 高级 / 专家），很多教程里提到的选项默认藏在「高级」或「专家」级别里，先把它拉到「高级」，省得照着教程找不到选项。
- **关闭开机动画音效**：在 `界面 → 声音` 里，电视客厅党常用。
- **区域格式**：`界面 → 区域` 里除了语言，还能改时区与日期格式，影响剧集列表里「首播日期」的显示。

## 五、界面顺了，接着喂片源

界面顺眼了，就该把内容告诉它：本地硬盘、NAS、Windows 共享、UPnP 服务器，接法都在[添加本地与网络媒体源.md](添加本地与网络媒体源.md)。片源接入后，如果发现播放的外语片没字幕，去[字幕下载与音轨切换.md](字幕下载与音轨切换.md)配一个字幕下载服务。
