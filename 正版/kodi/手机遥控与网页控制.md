## 一、先在 Kodi 里打开遥控权限

Kodi 默认关着遥控通道，手机上装什么 app 都连不上。先在盒子端的 Kodi 里开两处，路径都在 `设置 → 服务 → 控制`：

| 开关 | 作用 |
| --- | --- |
| **允许通过 HTTP 远程控制** | 打开遥控的基础通道，Kore 连接、网页控制都靠它 |
| **允许本机上的程序远程控制** | 遥控应用基础指令走这里 |
| **允许其他系统上的程序远程控制** | 手机与盒子是两台设备，必须开 |

同一页的「端口」「用户名」「密码」三项记一下：默认端口 `8080`、用户名 `kodi`、密码为空。部分版本不设密码时网页控制会被自动禁用，排查连不上时先给这一页设个密码再试。

## 二、用 Kore 遥控（官方应用）

**Kore** 是 Team Kodi 官方的安卓遥控应用（Play 商店与 F-Droid 都能装到，应用包名 org.xbmc.kore）。它不只是方向键：切字幕、切音轨、管理播放列表、清理媒体库、往盒子里发 YouTube 视频都能在手机上完成，字幕与音轨功能的具体用法见[字幕下载与音轨切换.md](字幕下载与音轨切换.md)。

连接步骤：

1. 手机与盒子连**同一个 Wi-Fi**（不同网段连不上，这是最常见的失败原因）；
2. 打开 Kore，首次运行会自动扫描网络，扫到了直接点盒子加入；
3. 扫不到就走手动添加，四个字段照着填：

| 字段 | 填什么 |
| --- | --- |
| 地址 | 盒子的 IP，在 Kodi 的 `设置 → 系统信息 → 网络` 里看 |
| 端口 | `8080`（没改过的话） |
| 用户名 | `kodi`（没改过的话） |
| 密码 | 上一节里设置的密码，没设就留空 |

## 三、浏览器直接当遥控

不想装应用时，开了 HTTP 远程控制之后，同一局域网内任意设备（手机、平板、电脑）的浏览器访问 `http://盒子IP:8080` 就会得到一个网页遥控界面：能看媒体库、点播、控制播放。临时找不到遥控器时最快，地址栏里那串就是「盒子的 IP 加冒号 8080」。

## 四、连不上时按顺序查

1. **不在同一网络**：手机连了蜂窝网络或访客 Wi-Fi 都不行，确认两端 IP 前三段一致（如都是 `192.168.1.x`）；
2. **Kodi 端开关没开全**：回到第一节那三个开关逐个核对，尤其是「允许其他系统上的程序远程控制」；
3. **密码问题**：部分版本空密码会禁用网页接口，设一个密码再连；
4. **路由器 AP 隔离**：与共享文件连不上是同一个病根，关掉隔离（见[常见问题排查.md](常见问题排查.md)的 SMB 一节）；
5. **Windows 电脑当主机时**：系统防火墙要放行 `8080/tcp`（HTTP）与 `9777/udp`（事件端口），盒子端系统一般没有防火墙，可跳过这条。
