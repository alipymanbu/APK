## 一、要备份的东西都在「数据文件夹」

Kodi 在设备上分两处：程序本体（重装就有，不用备份）与**数据文件夹**（你的全部家当）。换皮肤、装插件、扫好的媒体库、播放列表、看过的进度，全在数据文件夹里。安卓端的路径是：

```
Android/data/org.xbmc.kodi/files/.kodi/
```

其中 `userdata/` 子目录放着设置与库数据库，`userdata/Database/` 里的 `MyVideos*.db` 就是海报墙背后的媒体库本体。媒体文件本身不在这套目录里——它们在硬盘、NAS 或 U 盘上，备份 Kodi 不等于备份片源。

## 二、Android 10+ 拷不出来怎么办

从 Android 10 起，多数设备限制了文件管理器直接访问 `Android/data` 目录，很多人在这一步卡住。两条官方路线：

1. **用 Kodi 自带的文件管理器**：`设置 → 文件管理器`，在里面添加源时输入 `special://home/` 就能进到数据文件夹内部，把整个目录**复制到外部存储或共享位置**（Kodi 内部有权限读自己，不受系统限制）；
2. **用官方 Backup 插件**：在 `设置 → 附加组件 → 从库安装` 里装 Backup 插件，按向导选择备份目标（外部存储、网络位置均可），它会打包数据文件夹。恢复时同样走这个插件反向还原。

两条路线都能在拔不出数据目录的设备上完成备份；有电脑与数据线、能直接看到 `Android/data` 目录的设备，手动整夹复制也一样。

## 三、换新设备：备份 + 重装 + 恢复

1. 旧设备按第二节做出备份，存到 U 盘或网络位置；
2. 新设备装好 Kodi（安装方法见[下载与安装教程.md](下载与安装教程.md)），先启动一次让它生成目录；
3. 用 Backup 插件恢复，或手动把备份内容覆盖回新设备的数据文件夹；
4. 重启 Kodi，检查三项：媒体库还在、插件列表完整、播放一段确认。

## 四、换机后必查的一件事：源路径

媒体库数据库里记的是**媒体源的路径**。新旧设备上片源的路径变了（比如旧盒子是 `smb://192.168.1.10/media`，新设备换了个入口），恢复完会显示库在、但点开条目播不了。处理办法：

- 在 `文件 → 添加视频` 的源列表里，编辑旧源为新路径，保持内容类型设置不变；
- 之后对源执行「扫描媒体库到新内容」，Kodi 会把现有条目重新挂到新路径上。

换机前把 NAS、电脑共享的地址保持不变（IP 固定下来），恢复后就几乎不用动。

## 五、备份的时机

- **跨大版本升级前**（例如 20 → 21）：大版本动底层结构，升级前备份一次，出问题可整体回退；
- **动手改高级设置前**：手动编辑数据文件夹内的配置文件属于进阶操作，改前先备份；
- **插件大改后**：按第二节的任意一条路线再打一份即可，备份可以随做随覆盖。
