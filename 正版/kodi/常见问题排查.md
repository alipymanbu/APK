## 一、安装类

**下载下来的文件是 `.txt` 或 `.zip`，装不了**
个别手机浏览器把 APK 转存成了别的扩展名。先把扩展名改回 `.apk` 再装；反复出现就换浏览器，或用电脑下载后传过去。安装包本身的正确形态见[下载与安装教程.md](下载与安装教程.md)。

**「解析包时出现问题」/ 安装中断**
常见原因按顺序排查：安装包没下完整（重下并核对 MD5）；安装包架构与设备 CPU 不符（32 位设备装了 64 位包或反过来，换对应架构的包）；存储空间不足（64.70M 的包加上解压余量，留 1G 以上稳妥）。

**打开就闪退**
先确认系统版本达到 Android 5.0（老设备低于门槛是硬伤）；再试「设置 → 应用 → Kodi → 清除数据」后重开；仍闪退就卸载重装最新版。频繁闪退多为设备 ROM 兼容性问题，官方论坛按机型搜索通常能找到同款设备的讨论。

## 二、文件与权限类

**Kodi 里看不到本地视频 / U 盘**
十有八九是存储权限没给。手机：系统设置 → 应用 → Kodi → 权限 → 文件与媒体 → 允许。Android TV 11 及以上经常**不弹授权窗**，必须走这条手动路径并选「始终允许」，只给「仅本次」的话下次又看不到。

**换中文后满屏方块**
不是故障，是先切了语言没改字体。进 `设置 → 界面 → 皮肤 → 字体` 改成 Arial based 即恢复，完整步骤见[首次启动与中文设置.md](首次启动与中文设置.md)。

**字幕显示错字/方块**
字幕的方块是字体问题、错字是字符集问题，两种修法不同，对照表见[字幕下载与音轨切换.md](字幕下载与音轨切换.md)第五节。

## 三、网络共享类（SMB / NAS）

**「Windows 网络（SMB）」里浏览不到任何设备**
按顺序检查：盒子与电脑/NAS 是否在同一网段；路由器是否开了 AP 隔离（开了就互相不可见，关掉）；Windows 电脑的「网络发现」与「文件和打印机共享」是否开启。浏览不通不代表连不上——直接用「添加网络位置」手动填 IP 大多能连，字段填法见[添加本地与网络媒体源.md](添加本地与网络媒体源.md)。

**手动添加也连不上 / 提示认证失败**
核对三点：共享文件夹名拼写（不是磁盘盘符路径，是共享名）；账号密码是否为共享端真实设置；**共享无密码时 Kodi 端也不能留空**，用户名密码随便填非空内容再试。另外 Kodi 不支持早已停用的 SMB1，老 NAS 需要在 NAS 管理界面把 SMB 最低版本调到 2 以上。

**能连上但播放大文件卡顿**
先看传输链路：盒子走有线或 5GHz Wi-Fi 比连 2.4GHz 稳得多；NAS 与路由之间最好是千兆有线。4K 高码率片对带宽要求高，链路不行再好的设备也救不了。

## 四、播放类

**声画不同步**
播放中按出底部控制条 → 喇叭图标 → 「声音延迟」，现场微调并可存为默认，操作细节见[字幕下载与音轨切换.md](字幕下载与音轨切换.md)。

**音量明显偏低 / 无声音**
先分开两个音量：安卓系统音量与 Kodi 内部音量是两套，都拉上去。仍偏低时检查 `设置 → 系统 → 音频` 里的输出设备与「直通输出（passthrough）」——接功放/回音壁才需要开直通，直连电视时开了反而可能没声。无声音还可能是该音轨编码设备不支持（如 DTS/TrueHD 直通），换音轨或关直通试试。

**播放 4K / 高码率卡顿**
在 `设置 → 播放器 → 视频` 确认硬件加速处于启用状态（个别机型关掉软件解码反而流畅，两头都试）；确认电视与链路都支持该分辨率；老盒子播不动 4K 是性能上限，不是设置能解决的。

**升级后媒体库还在吗**
同包名覆盖升级（org.xbmc.kodi 不变）时设置与媒体库保留；跨大版本升级动底层，升级前用官方库里的 Backup 插件导出一次设置更稳妥。降级必须卸载重装，数据会丢。备份与换新设备的完整流程见[备份与换机迁移.md](备份与换机迁移.md)。

**手机遥控连不上**
Kodi 默认关着遥控通道，先到 `设置 → 服务 → 控制` 开「允许通过 HTTP 远程控制」等三个开关，再核对端口与同一局域网，按顺序排查见[手机遥控与网页控制.md](手机遥控与网页控制.md)第四节。
