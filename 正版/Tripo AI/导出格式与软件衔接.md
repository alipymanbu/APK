## 一、六种导出格式怎么选

官方帮助中心列出的导出格式共六种，按用途对号入座：

| 格式 | 适用场景 |
| --- | --- |
| GLB | Web、AR/VR、游戏引擎；纹理内嵌，单文件即可 |
| FBX | 游戏与 3D 动画软件的行业标准，Maya、3ds Max、Unity 常用 |
| OBJ | 通用 3D 编辑与基础 3D 打印兼容 |
| STL | 3D 打印标准格式，只含几何体、不含贴图 |
| 3MF | 较新的 3D 打印格式，带切片信息 |
| USD | 影视特效、动画与协作工作流 |

拿不准就先选 GLB（带贴图、单文件），要打印则选 STL 或 3MF。

## 二、导进 Blender

- GLB 直接拖进视口就能用，贴图随文件一起进来，不用重新指定路径；
- 导入后先看面数：AI 生成的原始模型面数极高（有实测一次生成出来约 190 万面），Blender 里开着都会卡，先减面再编辑。

## 三、导进 Unity / Unreal

- Unity 用 FBX 或 GLB 都行；Unreal 走 FBX 更省事；
- 原始生成结果不要直接丢进场景——先在生成平台里用重拓扑（Retopo）把面数降下来（官方的滑块范围是 500~50000 面，可选三角面或四边面），降到一万面上下的量级再导出；
- 有用户实测的可行流程是：图生 3D → 重拓扑到 10000 面 → 导出 GLB/FBX → 进引擎，这条路是走得通的。

## 四、拿去 3D 打印

1. 导出 STL 或 3MF；
2. 进切片软件（Cura、PrusaSlicer 等主流切片器都认这两种格式）；
3. AI 生成的网格不保证封闭（水密），切片报错时先用修复工具处理；
4. STL 不含颜色，想彩色打印就改导 3MF 或带贴图的格式，具体看你的打印机支持什么。

## 五、手机上导还是电脑上导

手机版的核心是随时生成、随手看；重导出、重编辑的活儿更适合在电脑端做。官方网页端 Tripo Studio 与手机应用同属一个产品体系，较新版本已支持两边账号互通（细节见 [账号与多端同步](账号与多端同步.md)），网页端的导出与编辑能力更全。相关入口与常见问题见 [常见问题与排查](常见问题与排查.md)。
