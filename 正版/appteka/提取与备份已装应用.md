# Appteka 提取与备份已装应用

> 本篇讲怎么用 Appteka 把手机上已装的应用提取成 APK 文件：备份到本机、分享给别人，或者上传到商店，全程不需要 Root。

「把手机里的应用变成 APK 带走」是 Appteka 最早的本职——它的前身叫 AppSend，包名 com.tomclaw.appsend 就是由此而来，商店反而是后来长出来的功能。换机前把应用安装包攒一份、把某个应用传给别的设备，用的都是这一套。

## 一、三种去向

| 你想做的事 | 怎么实现 | 前提 |
| --- | --- | --- |
| 备份自己手机的应用 | 提取成 APK，存在本机存储或转存到 SD 卡、电脑 | 不需要登录 |
| 把应用传给别人 | 提取成 APK 后走系统分享（聊天工具、云盘等） | 不需要登录 |
| 把应用（或你自己做的应用）发布给所有人 | 走客户端的上传流程，过审核后上架 | 需要登录 |

## 二、提取成 APK

- 提取入口在客户端内：已装应用列表与应用详情里有提取/分享类的操作项，不同版本入口位置有差异，以你手上那版的实际界面为准。
- 绝大多数应用都能提取，包括大部分系统应用；个别受系统保护的会失败，属正常现象。
- 提取不需要 Root，产物是标准的 APK 文件，落在你的存储里，可以再用文件管理器复制到 SD 卡或电脑。
- 一个容易误会的边界：**APK 只含应用本体，不含应用数据**。聊天记录、游戏进度这类东西不会跟着 APK 走，备份这类内容要用应用自带的备份功能。

## 三、分享给别人

提取出来的 APK 就是普通文件，长按或用应用详情里的分享入口，走系统分享面板发出去即可：QQ/微信发文件、传到云盘、电脑连接复制，都是常规操作。对方拿到后按[下载与安装教程.md](下载与安装教程.md)的步骤安装即可。

## 四、上传到商店

官方发布说明页（[appteka.store/pubinstr](https://appteka.store/pubinstr)）给的流程是五步：

1. 在客户端里打开上传入口（官方说明是底栏的云朵图标）。
2. 点 Select Application，选中要发布的 APK 或已装应用。
3. 补齐应用资料：截图、分类、简介。
4. 点 Upload to Exchange 提交。
5. 过审核后，应用会同时出现在 [appteka.store](https://appteka.store/) 和客户端里。

发布免费、不限制数量；具体按钮文案与细节以官方发布说明页为准。

## 五、备份的完整口径

如果你做备份是为了换机或防丢，建议这样组织：

1. 提取 APK 后，复制一份到电脑或你自己的网盘——手机存储出问题就都白提了。
2. 装回时按「下载与安装教程」的步骤走，签名一致的应用可以直接覆盖安装升级，跨版本降级则要先卸载（见[常见问题与解决办法.md](常见问题与解决办法.md)第七节）。
3. 别忘了第二步里说的数据边界：APK 恢复的只是应用，数据要另做备份。
