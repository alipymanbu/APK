# Appteka 网页版浏览与电脑端下载

> 本篇讲不装客户端怎么用 Appteka：用浏览器直接浏览与下载 APK、在电脑上下载后怎么传到手机，以及网页版与客户端的功能差异。

Appteka 的商店本身就是一个网站，浏览器打开就能搜应用、下 APK，不用注册也不用先装客户端。适合两种场景：手机空间紧张不想多装一个商店，或者你习惯在电脑上找应用、下好了再传手机。

## 一、手机浏览器直接用

1. 打开 [appteka.store](https://appteka.store/)，首页就有分类入口；也可以直接进应用列表页 [appteka.store/apps](https://appteka.store/apps)。
2. 搜索或按分类找到目标应用，进应用页看简介、评分、评论。
3. 点 Download APK 直接下载。浏览器拦你时点「仍然下载」，装的时候一样要开「安装未知应用」权限——授权对象换成你的浏览器，完整步骤见[下载与安装教程.md](下载与安装教程.md)第三节。

## 二、电脑上下载，再传到手机

在电脑浏览器里打开应用页点 Download APK，文件会下到电脑，之后任选一种方式传手机：

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| 数据线（USB） | 手机选「文件传输」模式，把 APK 复制进手机的 `Download` 目录 | 文件大、求稳 |
| 聊天工具 | 电脑发给手机端（如 QQ 文件助手） | 手边没有数据线 |
| 云盘中转 | 传到网盘，手机端下载 | 两边都不方便连线时 |

传到手机后，用文件管理器进对应目录点开 APK，安装步骤与拦截处理和手机端完全一样，见[下载与安装教程.md](下载与安装教程.md)。

## 三、网页版与客户端差在哪

| 能力 | 网页版 | 客户端 |
| --- | --- | --- |
| 浏览、搜索、直接下载 APK | 有 | 有 |
| 看应用的评分与评论 | 有 | 有 |
| 写评论、发帖讨论 | 看得到评论；写这类带身份的操作走客户端 | 登录后有 |
| 更新提醒 | 无 | 有 |
| 发布自己的应用 | 官网只提供发布说明页 | 登录后有 |

结论很简单：只是找包、下包，网页版够用；想长期用、要更新提醒和社区功能，再装客户端。
