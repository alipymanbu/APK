## 一、先把歌找出来

搜索框支持三类输入，命中率从高到低：

| 输入内容 | 适合场景 |
| --- | --- |
| BV 号 / AV 号 / EP 号 | 精准直达某个视频或合集里的音频，最准 |
| 歌名或歌手关键词 | 模糊找歌，结果按音乐列表组织 |
| UP 主相关关键词 | 找同一位创作者的多首作品 |

搜不到想要的那首时，先换 BV 号直达试试；再不行就换关键词——B 站视频标题往往带一堆修饰词，用歌名原词比用视频标题里的花哨写法更容易命中。

登录过 B 站账号的话，收藏夹会自动变成现成的歌单，不用手动搬歌，见 [账号登录与收藏夹同步.md](账号登录与收藏夹同步.md)。

## 二、歌单管理怎么做

- **新建歌单**：在歌单页新建，起个名字即可；
- **加歌**：搜索结果或正在播放的曲目里，把歌收藏进指定歌单；
- **排序**：歌单内的曲目支持拖拽调整顺序，按自己的听歌习惯排；
- **删改**：歌单支持编辑与删除，删歌单不影响 B 站收藏夹。

## 三、播放模式与控制

播放页里可用的控制项：播放 / 暂停、上一首 / 下一首、进度拖动、音量，以及三种循环模式——顺序播放、单曲循环、随机播放。睡前挂歌选随机加定时关闭（见第六节）是常见组合。

## 四、音质档位怎么选

应用内提供多档音质（流畅、高清、无损等，具体档位名称以你装的版本实际显示为准），切换的大致思路：

| 档位 | 适合场景 |
| --- | --- |
| 流畅 | 流量紧张、通勤路上、信号一般 |
| 高清 | 日常 WiFi 下听 |
| 无损 | 戴耳机、对音质有要求、不在乎流量 |

同一首歌在高档位下更耗流量，用移动数据时先想好再切。

## 五、后台播放与锁屏控制

切到桌面或锁屏后播放会继续，通知栏和锁屏界面都有控制条，可以直接暂停、切歌。要注意的是系统层面的限制：如果把 BiliMusic 从最近任务里划掉，部分机型的播放会跟着停——想让它一直在，就别划掉它，同时按 [下载与安装教程.md](下载与安装教程.md) 第四节关掉电池优化；息屏后还是会停的话，按机型对照 [息屏后停止播放的设置方法.md](息屏后停止播放的设置方法.md) 处理。

## 六、定时关闭与歌词显示

- **定时**：设置定时后，到点自动停止播放，睡前挂歌不怕整夜放；
- **歌词**：播放时自动匹配歌词并逐行滚动高亮，歌词匹配不上就显示不出，属于正常现象——视频标题不规范时匹配容易落空。

遇到搜不到歌、后台被杀、下载失败这些问题，翻 [常见问题与解决方法.md](常见问题与解决方法.md)；想把歌存到本地离线听，见 [音频下载与格式选择.md](音频下载与格式选择.md)。
