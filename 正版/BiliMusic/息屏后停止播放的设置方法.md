# 息屏后停止播放的设置方法

> 本篇针对「BiliMusic 锁屏或息屏几分钟后播放自动停」这一问题：原因出在系统的电池策略，按机型给出具体设置路径。
> **相关文档**：[常见问题与解决方法.md](常见问题与解决方法.md) · [歌单管理与播放设置.md](歌单管理与播放设置.md)

---

> **BiliMusic 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/d7d8fa1a2592](https://pan.quark.cn/s/d7d8fa1a2592)

## 一、先明确原因

息屏停播基本不是应用本身的毛病：国产安卓系统默认按「省电优先」管理后台应用，锁屏一段时间后会把后台应用冻结甚至直接结束。第三方应用没有厂商白名单加持，被清理得更早。解决思路因此只有一个——把 BiliMusic 加进系统的「不被清理」名单。

## 二、通用排查顺序（各机型通用）

1. 电池优化设为「不允许 / 无限制」；
2. 最近任务界面给应用加锁，别把它划掉；
3. 关闭省电模式再试一次；
4. 还停，按下面的机型专设走。

## 三、各机型的具体设置路径

| 机型 | 设置路径 |
| --- | --- |
| 华为 / 荣耀 | 设置 → 应用启动管理 → 关闭「自动管理」→ 勾选「允许后台活动」；多任务界面下拉卡片加锁；设置里搜「电池优化」→ 找到 BiliMusic 设为「不允许」 |
| 小米 / 红米 | 设置 → 应用管理 → BiliMusic → 省电策略 → 「无限制」；多任务界面长按卡片加锁 |
| OPPO / 一加 | 设置 → 电池 → 耗电保护（或自定义耗电保护）→ 关闭「后台冻结」与「检测到异常时自动优化」；多任务下拉加锁 |
| vivo / iQOO | 多任务界面点卡片右上角锁图标；设置 → 电池 → 后台高耗电 → 打开 BiliMusic 开关 |

同一品牌不同系统版本的菜单位置会有出入，路径以你手机的实际系统为准；找不到就到设置搜索框里直接搜「电池优化」或「自启动」。

## 四、华为机型的两个额外开关

华为机型按上面设完还停，再检查两处（厂商支持页给出的口径）：

1. **休眠保持联网**：设置 → 电池 → 更多电池设置 → 打开「休眠时始终保持网络连接」——息屏后系统可能断网，在线播放自然就停了；
2. **启动管理三项全开**：手机管家 → 启动管理 → 关闭自动管理 → 打开「允许自启动 / 允许关联启动 / 允许后台活动」。

## 五、设完还是停的几种情况

- **省电模式 / 超级省电开着**：临时关掉验证一次，很多「设置都对但还停」是它造成的；
- **装了第三方清理类 App**（管家、加速球）：这类软件会强制清后台，先卸载或把 BiliMusic 加进白名单；
- **应用数据被「深度清理」清掉**：把它加进系统清理白名单；
- **以上全试过仍频繁停**：清一次应用缓存、退出重进再试，其他现象对照 [常见问题与解决方法.md](常见问题与解决方法.md)；日常怎么挂后台听，见 [歌单管理与播放设置.md](歌单管理与播放设置.md)。
