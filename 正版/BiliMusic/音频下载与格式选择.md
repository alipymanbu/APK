# BiliMusic 音频下载与格式选择

## 一、下载的是音频，不是视频

BiliMusic 下载的是从 B 站视频里提出来的音频文件，不带画面。这决定了它的用途：导进车载播放器、塞进本地音乐库、耳机里离线听。想要画面还是得回 B 站客户端看原视频。

## 二、下载步骤

1. 在搜索结果或歌单里找到想存的那首歌；
2. 进入播放页（或列表内的歌曲条目），打开更多菜单，选下载；
3. 挑格式与音质，确认后开始下载；
4. 下载完成后在本地音乐（或应用内已下载列表）里就能找到。

下载前确认存储权限已经给到应用，权限没给是「点了没反应」的最常见原因。

## 三、四种格式怎么选

下载时可选输出格式，各有明确的适用场景：

| 格式 | 特点 | 适合 |
| --- | --- | --- |
| MP3 | 兼容性最好，任何设备都认 | 车机、老音箱、随便导来导去 |
| FLAC | 无损压缩，音质最好，体积大 | 认真收藏、配好耳机 |
| WAV | 无压缩无损，体积最大 | 后续要剪辑处理 |
| AAC | 有损里效率高，同音质体积更小 | 手机存储紧张、大批量下载 |

拿不准就选 MP3——兼容性最稳；认真收藏再上 FLAC。

## 四、封面与歌曲信息

下载支持封面嵌入与元数据写入：文件自带封面图与歌名信息，导进其他播放器后不是一堆「未知歌手」和灰块。B 站视频标题不规范时，写进去的曲名可能也跟着不规范，介意的话下载前先确认歌曲条目显示的名字对不对。

## 五、下载不了的情况

- **版权受限或付费内容**：这类音频可能无法解析下载，换其他 UP 主的翻唱或纯音频版本通常可行；实在没有就回 B 站官方客户端收听；
- **下载中断或卡住**：换一个网络环境重试，或检查手机剩余存储空间；
- **点了没反应**：先查存储权限，再看 [常见问题与解决方法.md](常见问题与解决方法.md) 的对应条目。

下载好的歌怎么编排进歌单、怎么切播放模式，见 [歌单管理与播放设置.md](歌单管理与播放设置.md)。
