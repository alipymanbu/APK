## 一、安装前先核对这些信息

BiliMusic 是第三方开发的 B 站音乐客户端，不是哔哩哔哩官方出品，也没有上架主流应用商店，所以要从安装文件装起。动手前先核对这份包的基本信息：

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.11.0 |
| 包名 | org.u2x1.bmsc |
| 安装包大小 | 27.62 MB |
| MD5 | 409980BDF3995756C85DA15875085F81 |
| 系统要求 | 安卓 5.2 及以上（以安装包标注为准） |

两点提醒：

1. 第三方应用更新频繁，网上搜到的最新版本号通常比这份更新，两者的功能可能有出入；要用文档里这一份，就认准上表的版本号与 MD5。
2. 包名是区分「同名应用」最可靠的依据——搜 BiliMusic 会出来好几位开发者的作品，包名不同就是不同的应用，登录态与数据互不相通。

## 二、从网盘拿到安装包

1. 打开 [BiliMusic 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d7d8fa1a2592)；
2. 把里面的 APK 文件转存到自己的网盘（分享资源需要先转存才能下载）；
3. 在夸克网盘客户端里把 APK 下载到手机存储。

下载完用文件管理器确认 APK 完整，大小应接近 27.62 MB。文件明显偏小或解不开，多半是下载中断，重新下载一次即可。

## 三、安装步骤

1. 在文件管理器里点开下载好的 APK；
2. 系统首次会提示「禁止安装未知来源应用」，按提示允许你的文件管理器（或浏览器）安装应用；
3. 返回继续安装，完成后点「打开」。

个别国产系统点安装没反应，等几秒再试。装完建议把「未知来源安装」授权收回去，只保留给常用的文件管理器。

## 四、装好后的第一次启动

首次启动建议按顺序做三件事：

1. **给权限**：应用会申请存储权限（缓存与下载音频要用）和通知权限（后台播放的控制条要用），都允许；
2. **关电池优化**：系统设置 → 应用管理 → BiliMusic → 电池，把电池优化设为「不允许」或「无限制」，否则锁屏或切后台后播放容易被系统掐掉（各机型的完整路径见 [息屏后停止播放的设置方法.md](息屏后停止播放的设置方法.md)）；
3. **登录或直接搜歌**：不登录也能搜索与播放；要把自己 B 站收藏夹变成歌单，先去登录，步骤见 [账号登录与收藏夹同步.md](账号登录与收藏夹同步.md)。

装完打不开、闪退这类问题，直接翻 [常见问题与解决方法.md](常见问题与解决方法.md)。
