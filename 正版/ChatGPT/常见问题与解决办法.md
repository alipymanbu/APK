## 一、登录相关

| 现象 | 先做什么 |
| --- | --- |
| 登录页一直转圈 | 确认当前网络能打开 [chatgpt.com](https://chatgpt.com)；换网络环境再试 |
| 输入密码后弹回登录页 | 清 App 缓存（系统设置 → 应用 → ChatGPT → 清除缓存），重新登录 |
| 提示 Access denied | 所在地区不在服务范围内，或当前网络被识别为异常出口；按 OpenAI 服务条款确认可用地区 |
| 登录后没有历史记录 | 大概率登录成了另一个账号（邮箱注册与第三方按钮是两个账号）；对照 [注册与登录账号.md](注册与登录账号.md) 第三节确认登录路径 |

若不只是登录问题，而是收到「账号已停用」的通知或提示，属于另一类情形，原因与申诉路径见 [账号被停用与申诉.md](账号被停用与申诉.md)。

## 二、对话中的报错

- **Something went wrong**：服务端临时故障，点重试或换个话题再发，通常几分钟内恢复，不用动手机设置。
- **You've hit the usage limit / 已达用量上限**：高级模型或工具的额度用完了。免费档等一段时间自动重置；付费档的额度窗口为滚动计算，具体规则以提示文案与官方帮助页为准。
- **回答中途断掉**：点「继续生成」；反复断说明当前负载高，错峰再用。
- **上传文件失败**：确认格式受支持、文件没超出当前档位的大小上限；把文件拆小是最快的绕行办法。
- **扣了款但档位没变 / 想申请退款**：订阅类的钱的问题不在这篇展开，排查顺序与申请路径见 [订阅扣款与退款.md](订阅扣款与退款.md)。

## 三、验证码与邮箱问题

注册或找回密码时验证码收不到，处理顺序：垃圾邮件夹 → 等 1~2 分钟点重发 → 核对邮箱拼写 → 换 Gmail/Outlook 重试。更完整的对照表见 [注册与登录账号.md](注册与登录账号.md) 第四节。

## 四、应用本身的问题

| 现象 | 处理 |
| --- | --- |
| 安装时提示解析包错误 | 安装包下载不完整，重新下载并核对 MD5（方法见 [下载与安装教程.md](下载与安装教程.md) 第二节） |
| 打开就闪退 | 先清缓存；无效则确认存储剩余空间，卸载后重装 |
| 收不到更新 | APK 来源不会自动更新，到网盘或官方商店页面取新版覆盖安装 |
| 界面卡在加载 | 检查网络；退出账号重新登录；仍不行则卸载重装（对话在云端，重装不丢） |
| 语音模式说不出声 / 对方听不到 | 到 系统设置 → 应用 → ChatGPT → 权限 里确认麦克风已允许；蓝牙耳机占用时先断开再试 |

判断「要不要重装」的顺序：清缓存 → 退出重登 → 卸载重装。三步走完还不好，多半是服务端或账号问题，等一等或找官方支持，别反复刷机。

## 五、数据与隐私

- **对话被用于训练模型**：消费级档位默认可能开启，到 设置 → 数据控制 里关闭「改进模型」开关（详见 [手机端功能一览.md](手机端功能一览.md) 第五节）。
- **删除记录**：单条删除在对话长按菜单里；清空全部在数据控制页；导出备份也在同一页。
- **注销账号**：账号设置最底部有删除账号入口，删除后不可恢复，订阅需先取消。

## 六、服务端问题的自查办法

怀疑不是自己手机的问题时，先看 [OpenAI 状态页](https://status.openai.com)：如果显示有故障事件，你这边怎么操作都没用，等修复即可。状态页正常而你持续报错，再走上面各节的排查路径。
