## 一、安装前先确认三件事

1. **设备与系统**：ChatGPT 官方安卓客户端于 2023 年 7 月上架谷歌 Play 商店。历史商店页面标注的系统要求为 Android 8.0 及以上，具体以官方商店页当时显示为准。安装包本体约 91.43 MB，加上运行缓存，建议预留 500 MB 以上可用空间。
2. **网络环境**：OpenAI 的服务未对中国大陆地区开放，应用打开后需要能访问其服务器才能登录使用。你所在地区能否使用、是否合规，请自行确认当地法律法规与 [OpenAI 服务条款](https://openai.com/policies)。
3. **账号**：可以先装好应用再注册账号，互不阻塞。注册流程见 [注册与登录账号.md](注册与登录账号.md)。

## 二、安装包版本与文件核对

网盘中的这份安装包信息如下，涉及版本号、包名、体积一律以它为准（网上商店里的是官方最新版，常常不是同一版）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.2026.111 |
| 包名 | com.openai.chatgpt |
| 安装包大小 | 91.43 MB |
| MD5 | `45C49653754B23809C8FB9093AFC3A81` |

下载完成后如需核对文件是否完整，最直接的办法是比对 MD5：

```powershell
certutil -hashfile "C:\下载目录\ChatGPT_v1.2026.111.apk" MD5
```

在电脑上执行上面这条命令（把路径换成你的实际文件位置），输出的哈希值与表格中的 MD5 一致，说明文件传输完整。手机端部分文件管理器也提供「文件校验」功能，入口名称各家不同。

OpenAI 的版本号采用 `1.年份.序号` 的形式，更新相当频繁。本篇写的是网盘里保存的这一版；官方最新版号以 [谷歌 Play 商店页面](https://play.google.com/store/apps/details?id=com.openai.chatgpt) 为准，两者功能上差异通常不大，但登录兼容性建议尽量用较新的包。

## 三、安装步骤

1. 从 [ChatGPT 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e53587484dbd) 下载 APK 文件到手机存储。
2. 点开 APK，系统会提示「禁止安装未知来源应用」，选择「仍要安装」或「设置」：
   - 原生系统：设置 → 应用 → 特殊应用权限 → 安装未知应用，给浏览器或文件管理器授权；
   - 国产系统（小米 / OPPO / vivo / 荣耀等）：路径名称略有差异，一般藏在「隐私保护」或「更多设置」里，搜「安装未知」能直接定位；
   - 华为部分机型还会额外要求输入锁屏密码确认。
3. 回到安装页，点「安装」，等待完成。
4. 完成后点「打开」。若当时没点，稍后在桌面图标进入即可。

如果安装按钮点了没反应，或提示「解析包出现问题」，多半是下载不完整，回到上一节核对 MD5 后重下。

## 四、首次启动

第一次打开会看到欢迎页与语言选项，界面语言支持中文。接下来是登录环节：

- 已有账号：用邮箱+密码登录，或点 Google / Microsoft / Apple 的第三方按钮一键登录（设备上没有谷歌服务时，Google 按钮多半用不了，替代做法见 [没有谷歌服务能正常用吗.md](没有谷歌服务能正常用吗.md)）；
- 没有账号：在登录页选注册，几分钟就能完成，具体见 [注册与登录账号.md](注册与登录账号.md)；
- 不想注册：跳过登录也能直接对话，但对话不保存、刷新即丢，模型与功能也受限，只适合临时试一下。

登录成功后，历史对话、自定义设置会自动同步到这台手机。

## 五、更新与卸载

- **更新**：通过 APK 安装的版本不会走商店自动更新。官方推送新版时，应用内通常会出现更新提示；也可以定期回网盘或官方商店页面取新包，直接覆盖安装，聊天记录与设置都会保留。
- **卸载**：长按图标卸载即可，只删除本机数据。你的对话保存在云端账号里，换手机或重装后登录同一账号，记录会同步回来。
- **装不上新版本**：确认新包版本号高于当前已装版本（同版本号的包无法覆盖安装），必要时先卸载再装。

安装或启动过程中遇到报错，可对照 [常见问题与解决办法.md](常见问题与解决办法.md) 逐条排查。
