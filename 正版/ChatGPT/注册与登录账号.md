## 一、注册前准备两样东西

1. **一个能打开 [chatgpt.com](https://chatgpt.com) 的网络环境**。注册与使用都在这个域名下进行，能否访问取决于你所在地区，请自行确认当地法律法规与 OpenAI 服务条款。
2. **一个邮箱**。社区里普遍的反馈是：
   - Gmail、Outlook 这类国际邮箱基本都能通过验证；
   - QQ、163、126 等国内邮箱有用户反馈无法完成注册，建议避开（各家政策会变，以注册页实际提示为准）。
   - 手机号：现在的注册流程已不强制要求手机号验证，邮箱即可走完全程。

已经注册过 OpenAI 账号的（比如之前用过网页版、DALL·E 或 API），直接用原账号登录即可，不需要重新注册。

## 二、注册步骤（手机 App 与网页通用）

1. 打开 App（或浏览器访问 [chatgpt.com](https://chatgpt.com)），点右上角 **Sign up**（注册）。
2. 选择注册方式：输入邮箱，或直接用 Google / Microsoft / Apple 账号一键创建。
3. 设置密码，至少 12 位。
4. 去邮箱查收 **6 位数字验证码**，填入页面点继续。
5. 填写姓名和生日，完成。

全程大约两三分钟。注册完成后这个账号在手机 App、网页版、桌面版通用，登录同一账号即同步。

## 三、登录方式对照

| 登录方式 | 适合谁 | 注意点 |
| --- | --- | --- |
| 邮箱 + 密码 | 所有注册用户 | 密码忘了走「忘记密码」重置邮件 |
| Google 账号 | 注册时选了「Continue with Google」 | 必须用注册时同一个 Google 账号 |
| Microsoft 账号 | 同上 | 同上 |
| Apple 账号 | iOS 用户为主 | 用了「隐藏邮箱」的，登录入口仍是 Apple 按钮 |

容易踩的坑：注册时用邮箱、登录时却点第三方按钮（或反过来），会被当成两个不同账号，表现为「找不到对话记录」。确认始终走同一条登录路径即可。

## 四、验证码或注册失败的处理

| 现象 | 处理 |
| --- | --- |
| 验证码邮件收不到 | 先看垃圾邮件夹；等 1~2 分钟再点重发；确认邮箱地址没拼错 |
| 提示邮箱无效或不受支持 | 换 Gmail 或 Outlook 重新注册 |
| 提示 Signup is currently unavailable | 多为服务端临时波动，换时段重试 |
| 一直卡在验证页 | 清浏览器缓存或换浏览器再试 |

## 五、账号安全建议

- 注册后在账号设置里开启**两步验证**（入口与名称以账号设置页为准），邮箱密码泄露时多一道防线。
- 不要把账号借给他人共用。同一账号多处登录本身允许，但异常登录行为可能触发风控。
- OpenAI 的服务对中国大陆地区未开放。账号注册地区与实际使用环境不一致时，存在被限制使用的可能，这一点在注册前就应有预期。
- 万一账号被停用（收到停用通知或登录直接提示账号不可用），原因分类与官方申诉路径见 [账号被停用与申诉.md](账号被停用与申诉.md)。

注册完成后，免费账号能直接开始对话。免费与付费在功能、额度上的差别，见 [免费版与付费版区别.md](免费版与付费版区别.md)；登录环节出问题，见 [常见问题与解决办法.md](常见问题与解决办法.md)。
