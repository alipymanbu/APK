# 连不上手表的常见问题排查

> 连接失败绝大多数出在两件事上：调试开关没开稳、网络不通。本篇先给一张基础清单，再按现象逐个对。

## 一、先过一遍基础清单

| 检查项 | 怎么确认 |
| --- | --- |
| 手表的 ADB / 无线调试开关还开着 | 进开发者选项看一眼；部分系统息屏久了会自动关 |
| 手机和手表在同一个 Wi-Fi | 不是"手机连流量、手表连 Wi-Fi"，也不是只靠蓝牙 |
| 手表上的 IP 输对了 | 手表重启或换网后 IP 会变，重新看一遍再填 |
| IP 和端口没有多余空格 | 有用户反馈 IP 带空格连不上，官方更新日志也提过修复此项 |
| 手表没息屏休眠 | 息屏一段时间后 Wi-Fi 可能休眠，调试时保持亮屏或放在充电器上 |
| 手机端权限给了 | 存储读写、查看 WLAN 状态等权限要在首次启动时允许 |

## 二、按现象对号入座

**一直转圈、最后超时** —— 网络层不通。最常见原因是公共 Wi-Fi 的"设备隔离"（公司、校园、酒店网络很常见），设备之间互相不可见。用手机开个热点让手表连上，通常立刻就好。

**提示连接被拒绝** —— 调试开关被系统关了，或端口不对。无线调试有"配对"和"连接"两组端口，连接用的端口通常和配对页显示的不同；而且每次重新开启调试，端口都可能变化，一律按手表当前屏幕上显示的填（谷歌官方的 Wear OS 调试文档也专门提示过这一点）。

**扫描不到设备（支持自动扫描的版本）** —— 同样多是设备隔离的网络，先排除网络再怀疑软件；也可以直接切回手动填 IP 的方式。

**手表上一直没弹授权确认框** —— 调试开关没开成功，或上一次的授权已过期。重开开关再连一次。

**全都试过还不行** —— 谷歌官方对 Wear OS 无线调试给出的排查顺序：确认两台设备在允许互访的同一网络、重启调试服务（对应到工具箱场景就是完全退出工具箱再重开）、把手表的无线调试关掉再重新打开。按这个顺序过一遍，多数软性故障都能清掉。

## 三、特殊设备和网络环境

- **华为手表**：多数型号运行 HarmonyOS，不走标准 Wear OS 的连接流程，官方帮助中心有华为专页，按专页来。
- **三星、OPPO**：开发者选项入口层级不同，对照 [连接手表的完整步骤.md](连接手表的完整步骤.md) 里的品牌表。
- **手表用独立 eSIM 流量**：手表没连 Wi-Fi 自然连不上，先在手表设置里把它接到家里的 Wi-Fi。
- **访客网络**：路由器的访客网络一般也开设备隔离，用主网络或热点。

## 四、连上了但功能用不了

- 部分**高级功能**（命令行、声音管理、Split APK 安装、多重 APK 等）需要捐赠解锁，界面里灰着或提示解锁属于正常设计，不是故障。
- 改分辨率/DPI 后显示异常：把参数改回默认值即可，见 [屏幕与电池调试功能详解.md](屏幕与电池调试功能详解.md)。
- 以上都对过还是不行：去 [官方帮助中心的疑难解答](https://help.wearosbox.com/) 按品牌找专页，或通过帮助中心的联系方式反馈。
