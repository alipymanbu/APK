# WearOS 工具箱连接手表的完整步骤

> 工具箱是通过 ADB 调试通道控制手表的，所以连接的核心就是两件事：手表打开调试开关、手机和手表在同一个网络里。本篇按顺序把每一步拆开讲。

## 一、连接的前提

| 前提 | 在哪一侧操作 |
| --- | --- |
| 手表已打开开发者选项 | 手表 |
| 手表已打开 ADB 调试（或无线调试） | 手表 |
| 手机与手表连在**同一个 Wi-Fi** 下 | 两侧都要 |
| 手机上已装好 WearOS 工具箱 | 手机 |

华为手表等系统不同的设备，以及 OPPO、三星这类入口路径有差异的品牌，官方帮助中心都单独准备了连接页面，遇到时直接去 [help.wearosbox.com](https://help.wearosbox.com/) 查对应品牌。

## 二、在手表上打开开发者选项

通用 Wear OS 手表的做法：

1. 手表上进入 **设置 → 系统 → 关于**（部分机型是"关于手表"）。
2. 找到 **版本号**，连续点击 7 次，直到提示"您已处于开发者模式"（有锁屏密码的手表会先要求输入密码）。

常见品牌的差异：

| 品牌/系统 | 入口 |
| --- | --- |
| Wear OS 2.0 及更早 | 设置 → 关于 → 连点版本号 |
| Wear OS 3+ | 设置 → 系统 → 关于 → 连点版本号 |
| 三星 Galaxy Watch | 入口层级与其他表略有不同，见官方帮助中心的三星专页 |
| OPPO 手表 | 设置 → 其他设置 → 关于手表 → 连点版本号 |
| AOSP 类手表 | 设置 → 关于手表 → 连点版本号 |

## 三、打开调试开关

回到手表 **设置 → 开发者选项**（有的机型藏在"系统"里），打开以下开关：

- **ADB 调试**：基础开关，必须开。
- **通过 Wi-Fi 调试 / 无线调试**（名称随系统版本不同）：走无线连接必须开。打开后手表会显示自己的 IP 地址和端口，**把这个 IP 记下来**，后面要在工具箱里填。

注意：部分系统在你摘下手表或息屏一段时间后会自动关掉 Wi-Fi，调试连接会跟着断。调试期间尽量保持手表亮屏或放在充电器上。

## 四、手机与手表接入同一网络

把手机和手表连到**同一个路由器的 Wi-Fi**。有两个常见坑提前避开：

- 手表必须自己连上 Wi-Fi，只靠蓝牙和手机配对是不够的。工具箱在帮助中心里也列了蓝牙调试等连接方式，但同一 Wi-Fi 下走 WLAN/无线调试是最常规的做法。
- 公司、校园、酒店的公共 Wi-Fi 常开"设备隔离"，设备之间互相不可见，这种情况用手机开热点给手表连（或反过来）通常能解决。

## 五、在工具箱里连接

1. 手机上打开 WearOS 工具箱。
2. 在首页的设备地址栏输入上一步记下的手表 IP（端口号按手表上显示的填；IP 或端口里有空格会导致连接失败，输完检查一遍）。
3. 手表上弹出"允许 USB 调试吗"之类的确认框时，勾选"一律允许使用这台计算机进行调试"再点允许，以后就不用重复确认。
4. 看到设备信息出现即连接成功，之后可以直接进 [手表应用与文件管理实操.md](手表应用与文件管理实操.md) 或 [屏幕与电池调试功能详解.md](屏幕与电池调试功能详解.md)。

提示：官网展示的新版界面支持自动扫描配对——不用手填 IP，从发现的设备列表里选一下、手表上确认一次即可。你手里的版本界面以实际显示为准；需要手动填 IP 的版本，按本节第 1~3 步操作。

## 六、连上之后

- 连接状态下修改任何设置（分辨率、电量显示等）立即生效，不用重启工具箱。
- 手表重启或换网络后 IP 可能变化，连不上时先重新看一眼手表上显示的 IP。
- 调试开关被系统自动关闭也是常见断连原因，按 [连不上手表的常见问题排查.md](连不上手表的常见问题排查.md) 的清单逐项核对即可。
