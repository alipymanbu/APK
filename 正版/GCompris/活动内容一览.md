# GCompris 活动内容一览

> 本篇按官方分类过一遍 GCompris 里的活动内容，并讲清主界面的星星、控制栏图标，帮你在打开之前知道每类活动练什么、适合多大孩子。

GCompris 官方定位是给 2 至 10 岁儿童的教学软件，所有内容拆成一个一个的小活动（新分支 26.0 已有 197 个，旧分支 4.3 也在一百个以上），主界面按类别分组。下面按官网中文页的分类说明各练什么。

## 一、常见分类各练什么

| 分类 | 练什么 | 例子 |
| --- | --- | --- |
| 探索电脑 | 认识输入设备 | 键盘、鼠标、触摸板操作 |
| 阅读 | 字母与文字 | 字母、单词、阅读练习、输入文本 |
| 算术 | 数与运算 | 数字、运算、枚举、乘法表 |
| 科学 | 直观理解自然现象 | 运河闸门、水循环、可再生能源 |
| 地理 | 认识世界 | 国家、地区、文化 |
| 游戏 | 经典桌面游戏与益智 | 国际象棋、记忆配对、四子棋、井字棋 |
| 其他 | 基础认知 | 颜色、形状、盲文、认识时间 |

类别入口在主界面顶部，屏幕竖着放时会移到左侧。有的分类下还有子分类做二次过滤，比如算术类分「数数、算术、测量」三小类。同一个活动内部还分难度级，低龄从最简单的级别开始即可，不必按年龄死对号。

## 二、看星星选活动：图标上的年龄段标记

主界面每个活动图标上都有星星，数量与颜色合起来就是官方标注的适用年龄段：

| 星星 | 年龄段 |
| --- | --- |
| 1~3 颗黄星 | 2~6 岁 |
| 1~3 颗红星 | 6 岁以上 |

星星越多难度相对越高。按孩子年龄筛选时直接看颜色，再按下面的年龄段挑具体类别：

- **2~4 岁**：黄星活动里的「其他」类（颜色、形状、认识时间）以及键盘鼠标类的随意点按活动，这类活动没有失败惩罚，纯探索。
- **5~7 岁**：算术类的枚举、简单运算，阅读类的字母与单词，加上记忆配对类游戏。
- **8~10 岁**：红星活动里的科学类（运河闸门、水循环），地理类的国家拼图，以及国际象棋、四子棋这类有策略深度的游戏。

## 三、进活动后：底部控制栏的图标

进入活动后，屏幕底部会出现一排控制图标（只在当前活动用得上时才显示），认识它们能省掉大部分「这怎么退出去」「怎么给提示」的困惑：

| 图标 | 作用 |
| --- | --- |
| 房子 | 退出当前活动，回到上一层菜单 |
| OK | 提交答案 —— 有的活动不会自动判定完成，要点它或按回车确认 |
| 灯泡 | 显示提示，部分活动用灯泡引导孩子找答案 |
| 左右箭头 | 切换难度级；没过完当前级也能直接跳级 |
| 嘴唇 | 要求把问题再读一遍 |
| 问号 | 打开帮助说明，讲不清的规则会写在这里 |
| 扳手 / 列表 | 全局设置与该活动自己的设置（难度、题目集），见[家长设置与难度调整](家长设置与难度调整.md) |

## 四、触屏设备上的两个注意点

1. **键鼠类活动可能受限**：「探索电脑」分类是按电脑的键盘、鼠标设计的，在纯触屏的手机上部分活动会打折扣或被隐藏，以应用内实际显示为准；给平板配个鼠标能完整玩到这一类。
2. **文字量大的活动受翻译影响**：阅读、单词类活动依赖界面翻译，简体中文覆盖不满时这类活动会出现英文混排，具体见[怎么设置中文](怎么设置中文.md)。

还没装的话先看[下载与安装教程](下载与安装教程.md)；装好后打开活动没有语音提示的，看[没有声音怎么解决](没有声音怎么解决.md)。
