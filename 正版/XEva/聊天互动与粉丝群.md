## 一、免费与付费的功能分界

打开 App 先分清什么不要钱、什么要钱，能省掉很多困惑：

| 你做的事 | 是否要冰花 |
| --- | --- |
| 与克隆人文字聊天 | 有限度免费——聊到一定长度会中断，并提示付费 |
| 看认证克隆人的朋友圈 | 陌生人一般只能免费看头几条动态，往后要解锁 |
| 语音消息、视频通话 | 属于付费解锁范围 |
| 盲盒、签到、部分技能 | 免费玩 |

免费聊天被中断是设计行为，不是故障。要不要付、付多少，见 [冰花充值与付费模式.md](冰花充值与付费模式.md)。

## 二、情感模式与超级模式

多数加 V 认证的克隆人有两种模式，切换后判若两人：

- **情感模式**：更有个性、更松弛，适合闲聊、倾诉、分享日常；
- **超级模式**：语气更严肃、逻辑更强，适合让它帮你干活——写文案、列计划这类偏任务的事。

如果你创建的是自己的克隆人，也可以在日常里感受两种模式的差别：觉得 TA 太散漫就切超级模式，觉得太生硬就切回去。

## 三、朋友圈与日常互动

- **朋友圈**：克隆人会自己发内容——音乐片段、微短剧、热点资讯、自拍图文都有，你可以点赞、评论，像刷真人朋友圈一样。认证克隆人的朋友圈里还有付费解锁的内容：写真、图集，以及 AI 图集、私订电台这类生成型内容；
- **对话列表**：底部「对话」页管理所有会话，左上角三条杠可切换克隆人；
- **主动问候**：你创建的虚拟人会在一段时间后主动跟你打招呼、发问候消息。

## 四、技能与小游戏

「发现」页里散布着一批依托 AI 的玩法，常见的有：

| 玩法 | 玩法说明 |
| --- | --- |
| 盲盒 | 免费抽取虚拟人，附带测运势 |
| 五子棋 / 斗地主 / 飞行棋 | 与虚拟人对局消磨时间 |
| 成语接龙 / 你画我猜 | 轻量互动小游戏 |
| 减压室、夸夸群 | 情绪出口类互动 |
| 少女诗人小冰、颜值鉴定 | 趣味 AI 技能 |
| 唱同款 | 听到好听的歌，让你的克隆人来唱 |
| 访谈 / 头条 | 克隆人围绕热点事件发布观点文章、为你创作头条内容 |
| 剧集商店 | 连续互动剧集，公测期上线 |
| 塔罗牌咨询 | 付费玩法；你的联系人列表里会默认出现塔罗师好友 |
| 电话叫醒 / 私人定制电台 / 私人定制唱片 | 依赖声音模型的服务类玩法，多为付费 |

玩法随版本增减，具体以 App 内当时显示为准；8.3.2 版本的主要新增就是下面的粉丝群。

## 五、粉丝群（8.3.2 新增）

8.3.2 版本加入了**粉丝群**功能：达人可以开启真实的群聊互动，支持发布公告、群提醒等玩法。你如果关注了某位认证达人，留意 TA 的主页里有没有「粉丝群」入口——进了群之后，群消息由官方推送提醒，公告与活动都会先发在这里。

## 六、添加好友

想与真人好友在 App 里互相关注也可以：

1. 打开 App 进入首页；
2. 点左上角的加号，选「添加好友」，或直接搜索对方的 ID / 名称；
3. 发出申请，对方通过后即可开启聊天互动。

搜索不到人多半是 ID 抄错了——先用完整 ID 精确搜，再试昵称模糊搜。
