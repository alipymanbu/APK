## 一、先分清是哪种「坏了」

同样是「用不了」，三种症状的排查起点不同：

| 症状 | 先怀疑 |
| --- | --- |
| 点开就退、进不去 | 安装包、系统版本、数据异常 |
| 聊到一半闪退 | 后台资源、缓存、网络切换 |
| 能用但发消息慢、界面顿 | 网络、线路、缓存（也可能是模型响应慢） |

下面按顺序做，**每做完一步就试一次**，好了就停，不用把全套做完。

## 二、逐步排查（从代价最小的开始）

1. **强制停止后重开**：手机设置 → 应用 → 找到 dickcat → 强制停止，再重新打开。多数临时故障到这一步就好。
2. **换个网络试试**：Wi-Fi 和移动数据互切一次。联网应用「发不出去、一直转圈」经常只是当前网络不通。
3. **清缓存（不会丢数据）**：设置 → 应用 → dickcat → 存储 → **清除缓存**。缓存清掉不影响登录状态和聊天记录。
4. **检查后台与存储**：关掉后台占资源的其他应用，确认手机可用存储还剩两成左右——存储见底时应用最容易闪退。
5. **检查权限**：设置 → 应用 → dickcat → 权限，确认网络、存储等必要权限没有被禁用。
6. **清数据（有代价，先想清楚）**：上一步都无效才走这里——「清除数据」会把应用恢复到刚装好的状态，**未同步的本地记录会一起没**。所以先确认已登录账号、记录已同步，再执行；清完重新登录即可。
7. **核对版本再重装**：系统确认在安卓 5.2 以上；卸载后重新安装，安装包信息对照[下载与安装教程.md](下载与安装教程.md)里的信息表（版本 1.0.28、约 80.79M、MD5 `DBFEDD16166B69EFC845EDBC43C3A1B1`），别装到损坏或来历不明的包。
8. **系统也更新一下**：部分应用对新系统有适配要求，旧系统对新应用同理——设置里检查系统更新，装完再试。

**卸载重装前必做**：登录账号确认聊天记录已同步，否则卸载即清除（详见[常见问题与解决办法.md](常见问题与解决办法.md)的记录丢失一节）。重装需要安装包时，从 [dickcat 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d5398be07227) 再取一份。

## 三、「卡」的两种情况

- **界面卡、列表顿**：按上面第 1~4 步处理即可，通常是后台或缓存问题。
- **回复慢、发出去半天才回**：先分清是网络还是模型——切网络排查；网络正常就先换 AI 线路、再换聊天模型（步骤见[聊天模型与AI线路切换.md](聊天模型与AI线路切换.md)）。有渠道资料提到部分版本在设置里提供「流畅模式」与清除缓存入口，你的版本里有没有、叫什么名字，以界面实际显示为准。

## 四、都试过了还不行

到这一步多半不是你这边能修的。反馈时把三样东西说清楚：**版本号**（设置里可查，本页资料对应 1.0.28）、**哪一步出的问题**（打开就退 / 聊着退 / 只是慢）、**手机系统版本与机型**。比一句「打不开」好排查得多；同一时间多台设备登录同一账号也会造成异常，反馈前先排除（见[常见问题与解决办法.md](常见问题与解决办法.md)）。
