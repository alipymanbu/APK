## 一、先弄清离线翻译能做什么

离线翻译是把翻译引擎和语言数据下载到手机本地，没有网络也能翻。代价是能力缩水：

| 功能 | 离线下可用 |
| --- | --- |
| 文本翻译 | 可用（支持的语言有限） |
| 语音翻译 | 可用（安卓需另下语音语言包，且部分机型不支持） |
| 对话翻译 | 不可用 |
| 拍照翻译 | 不可用 |
| 网站翻译 / 文档翻译 | 不可用 |
| 词典、发音 | 不可用 |

所以离线包解决的是「打字查词、翻简单句子」这个最基本的场景；菜单、路牌在没网时翻不了 —— 需要拍照翻译的场合，可以先把画面拍下来存着，等有网了再翻。

## 二、下载语言包的步骤

1. 打开 Papago，进入侧边菜单，找到「设置」→「离线翻译」（不同版本入口名称略有差异，有的版本在菜单里直接叫「离线翻译」）；
2. 在语言包列表里找到需要的语言对（如 中文（简体）↔ 韩语）；
3. 点下载图标，等进度走完、条目出现已下载标记即可；
4. 安卓上要离线用语音翻译的话，同一界面里还有单独的语音语言包，需要再下一份。

建议在出发前、Wi-Fi 环境下完成下载；单个语言包体积在一百多 MB 的量级，以应用内显示为准。

## 三、支持离线的语言范围

按官方帮助中心的口径，离线翻译覆盖的语言对是：韩语、英语、日语、中文（简体）之间互相翻译。想离线翻西班牙语、泰语这类语言是做不到的（以你手机上应用内实际显示为准，官方后续可能调整）。

设备方面的门槛（官方口径）：

- 文本离线翻译：手机运行内存 4GB 以上；
- 语音离线翻译（安卓）：运行内存 4GB 以上，且系统版本要求更高，具体以应用内提示为准。

运行内存不够的旧手机，语言包可能不出现在列表里，或下载后不可用。

## 四、语言包管理

- 查看占用：离线翻译设置页里能看到每个语言包的大小，不用的及时删掉腾空间；
- 删除：点语言包条目旁的删除图标，删了随时可以重新下载；
- 更新：官方更新语言包后按提示重新下载或更新，更新后离线翻译质量会有变化。

## 五、离线使用时的建议

- 出发前把高频句（问路、点菜、退房、过敏提示）先在线翻好并收藏，离线时直接从翻译记录里调出来，具体操作见 [文本翻译与语音对话怎么用.md](文本翻译与语音对话怎么用.md) 的记录一节；
- 离线结果通常比在线略生硬，重要沟通（签合同、看病）务必联网确认；
- 酒店和机场一般有免费 Wi-Fi，重要的拍照翻译、对话翻译可以到这些场合再做。
