# Sefirah 电脑上收发短信

> 本篇讲怎么让手机上的短信出现在电脑上、怎么用电脑发短信、双卡怎么选卡，以及目前还没做的部分。

短信是 Sefirah 里权限要得最多的一项——读联系人、读电话状态、收发短信都要授权，权限给全之前电脑端的消息页是空的。本篇按「给权限 → 重连 → 收发」的顺序讲。

## 一、先把权限给全

在手机端应用的权限页面里，把短信相关的权限都给上：

| 权限类别 | 用来做什么 |
| --- | --- |
| 短信收发 | 读取、接收、发送短信，接收彩信 |
| 联系人 | 显示发件人是谁，而不是一串号码 |
| 电话状态 | 判断当前用的是哪张卡的号码，发送时才知道走哪张卡 |

给完权限要**重新连接一次**，消息才会出现在电脑端的消息页。给权限前就连接着的话，界面不会自己刷新。

## 二、在电脑上看和发

1. 连接后，电脑端的**消息**页按会话列出短信。
2. 点开会话可以看完整来往，也能直接回复或新发一条。
3. 双卡手机可以**切换用哪张卡**发送。

发件人存过联系人就显示联系人名，没存就显示号码。

## 三、目前还没有的

官方仓库的说明文档明确说明：**附件尚未实现**。收到带附件的彩信时，正文能看，图片等附件拿不到——需要附件就回手机上看。

## 四、不显示、发不出去怎么查

| 现象 | 先查 |
| --- | --- |
| 消息页是空的 | 短信相关权限是否全给了；给完有没有重新连接 |
| 只显示号码不显示名字 | 联系人权限没给 |
| 发送时选不了卡 | 电话状态权限没给，或者手机本来就是单卡 |
| 会话排序不对 / 点开就崩 | 官方在 1.1.1 这一版修过「会话排序」与「双卡下拉框崩溃」两个缺陷，先确认两端装的是不是这一版或更新 |

## 五、别和通知同步搞混

短信来的时候，电脑上也可能同时弹一条通知，但那是**通知通道**，和消息页的短信是两套东西：通知可能因为 Android 15 的敏感通知限制而看不到内容，消息页则取决于上面这几个权限有没有给全。通知那一侧的处理见 [通知同步和媒体控制.md](通知同步和媒体控制.md)。
