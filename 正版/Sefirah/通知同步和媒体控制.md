配好之后，两个方向的信息流是反的：一边是电脑上弹手机的通知，另一边是手机遥控电脑的播放与音量。这两件事都在主界面上，但依赖的权限不同，通知这一块还受系统版本影响很大。

## 一、让手机通知出现在电脑上

1. 手机端在引导页或设置里给**通知使用权**（通知监听）权限。
2. 两端连接状态下，手机来通知时电脑上会以气泡形式弹出来。
3. 首次连接后，电脑端的通知列表要等一会儿才加载出来。

同时要给**通知权限**：官方说明里它有三个用途——显示连接状态、别的功能需要时发提醒、以及维持连接不被系统杀掉。只给通知监听、不给通知权限，连接更容易掉。

Sefirah 一共有哪几项权限、每项管什么功能，汇总在 [各个权限对应哪些功能.md](各个权限对应哪些功能.md) 里。

## 二、Android 15 起通知变少，怎么补回来

这是平台层面的限制，不是应用改坏了：**从 Android 15 开始，敏感通知不再同步到电脑**。官方给的绕过办法是用 ADB 单独授权：

```bash
adb shell appops set com.castle.sefirah RECEIVE_SENSITIVE_NOTIFICATIONS allow
```

做这件事需要电脑上有 ADB 环境。电脑上还没有的话，去 Android 官方开发者站点的 platform-tools 下载页（`developer.android.com/tools/releases/platform-tools`）取一份压缩包，解压后**在那个目录里**打开命令行执行上面的命令——手机要先打开 USB 调试，并在弹窗里授权这台电脑。

少数机型直接执行会失败，官方点名的是一加：先在开发者选项里关掉该应用的**系统优化**，或关掉**权限监控**，再执行一次命令。

两端同时连着 ADB 的时候，电脑端会在设备上线时自己尝试补上这条授权，所以你本来就用数据线连着做别的事，往往不用手动敲。

## 三、用手机控制电脑的播放和音量

- 在手机端的媒体控制区域，可以控制电脑当前正在播放的内容：播放 / 暂停、上一首 / 下一首，以及电脑的输出音量。
- 前提是两端处于已连接状态，而且电脑上有正在播放的媒体，才会出现在列表里。

## 四、通知相关的常见毛病

| 现象 | 先查 |
| --- | --- |
| 电脑上完全不弹通知 | 通知使用权是否给到 Sefirah；Android 13+ 的受限设置是否放行 |
| 部分应用的通知收不到 | Android 15 及以上的敏感通知限制，按第二节的 ADB 命令补权限 |
| 有通知但看不到内容 | 手机上那个应用自身设置了隐藏通知内容 |
| 连接过一会儿就断 | 通知权限没给，系统把后台进程清掉了；同时把应用加入不省电名单 |
| 一加机型上 ADB 命令执行失败 | 先在开发者选项里关掉系统优化或权限监控，再执行命令 |

短信有自己的权限套餐和独立界面，单独写在 [电脑上收发短信.md](电脑上收发短信.md) 里。
