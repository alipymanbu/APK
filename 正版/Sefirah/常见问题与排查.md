装好了、也配对上了，但某个功能不动——这是用这类工具最常见的状态。原因大多集中在三类：权限没给全、系统把后台清了、两端版本差得多。本篇把常见现象按类别摊开，先给结论。

## 一、连不上、看不到设备

| 现象 | 先查什么 |
| --- | --- |
| 两端互相看不到 | 是否真的在同一个局域网；访客网络与 AP 隔离会挡住 |
| 能互相看到，但连不上 | 电脑防火墙是否放行 5149 到 5169；当前网络是不是「专用网络」 |
| 手机端发起连接后电脑没弹提示 | 电脑端是否停在主界面；Windows 是否把弹窗拦掉了 |
| 密钥对不上 | 断开重来，别硬连 |
| 公司 / 酒店网络下怎么都不通 | 用手机热点把两端接在一起，绕过网络侧隔离 |

完整顺序见 [手机和电脑怎么配对连接.md](手机和电脑怎么配对连接.md)。

## 二、连上了但总掉线

| 先查 | 说明 |
| --- | --- |
| 手机端通知权限 | 官方说明里它有一项用途是维持连接存活，没给容易被系统回收 |
| 省电策略 | 把 Sefirah 加入不省电 / 允许后台运行的名单 |
| 位置权限 | 它用来自动判断是否在熟悉的网络并触发重连，缺了自动重连不生效 |

省电相关的入口各家叫法不一样，找不到就从设置的搜索框里直接搜 Sefirah：

- 原生 Android：设置 → 应用 → Sefirah → 电池，选「无限制」。
- 国产系统常见两步：先在「应用管理 → 自启动 / 后台运行」里允许自启，再到「电池 → 应用耗电管理」里允许后台活动。
- 只关「电池优化」不够，自启那一步漏掉的话，手机重启后连接不会自动恢复。

## 三、某个功能不生效，按功能定位

| 功能 | 不生效时先查 |
| --- | --- |
| 剪贴板 | 两个方向是分开的开关，手机转电脑还要无障碍权限，见 [剪贴板同步怎么用.md](剪贴板同步怎么用.md) |
| 文件与手机存储 | 存储权限、Android 版本门槛，见 [传文件和访问手机存储.md](传文件和访问手机存储.md) |
| 通知 | 通知使用权与 Android 15 的敏感通知限制，见 [通知同步和媒体控制.md](通知同步和媒体控制.md) |
| 短信 | 短信、联系人、电话状态三类权限要一次给全再重连，见 [电脑上收发短信.md](电脑上收发短信.md) |
| 屏幕镜像 | 先确认电脑上装了 scrcpy 并在设置里指了路径，见 [屏幕镜像怎么开.md](屏幕镜像怎么开.md) |

## 四、Android 13 及以上特有的卡点

侧载安装的 Sefirah，**无障碍权限和通知使用权会被系统限制**。表现是授权开关点了没反应、或者引导页一直要求你去授权。

处理办法：进「设置 → 应用 → Sefirah → 右上角菜单」，打开**允许受限设置**，再回到应用里重新授权。这一步没做的话，剪贴板同步和通知同步都起不来。每项权限分别管哪个功能，对照表在 [各个权限对应哪些功能.md](各个权限对应哪些功能.md)。

## 五、Android 15 及以上的通知限制

从 Android 15 开始，**敏感通知不再同步到电脑**，这是平台限制。官方给的办法是用 ADB 单独授权：

```bash
adb shell appops set com.castle.sefirah RECEIVE_SENSITIVE_NOTIFICATIONS allow
```

命令的细节与机型例外见 [通知同步和媒体控制.md](通知同步和媒体控制.md) 第二节。

## 六、两端版本对不上

- 两端版本跨度大时，配对与同步容易出问题，尽量把两端对齐到同一个版本号。
- 官方更新日志里给过一个通用兜底：遇到两端都正常却配不上的情况，**两端都重置应用**（清除应用数据）后重新配对。会清掉已有配对与设置，动手前先确认自己不需要留记录。
- 本页网盘里那份是安卓端 1.1.1，电脑端尽量选接近的版本。

## 七、安装包本身的问题

| 现象 | 处理 |
| --- | --- |
| 提示「解析软件包时出现问题」 | 重新从 [Sefirah 安装文件资源（夸克网盘）](https://pan.quark.cn/s/52b461a3ae72) 转存下载，并核对 MD5 |
| 提示「禁止安装未知应用」 | 给打开 APK 的那个应用授权，细节见 [下载与安装教程.md](下载与安装教程.md) |

## 八、真要反馈时准备什么

官方收集问题的入口是安卓端与电脑端各自的官方仓库 Issues 页面，以及官方 Discord。一次把信息给全能省一轮往返：

- 两端各自的版本号，手机机型与 Android 版本，Windows 版本
- 卡在哪一步、能不能复现，复现步骤写清楚
- 报错原文或提示框截图里的文字
