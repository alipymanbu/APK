# Sefirah 传文件和访问手机存储

> 本篇讲「文件怎么过去」的两条路子：用分享菜单把文件发给对方，以及把手机存储挂进 Windows 资源管理器，附带挂载那一步的官方警告。

传文件这件事 Sefirah 有两条路：急着发一两个文件，用分享菜单；想让电脑像翻本地盘一样翻手机里的照片和文档，就把手机存储挂进资源管理器。两条路的前提不一样，第二条对系统版本有硬要求。

## 一、发单个文件：走分享菜单

两端都支持从系统分享菜单发文件：

1. 在**手机**上：在相册或文件管理器里选中文件 → 分享 → 在分享目标里选 Sefirah。
2. 在**电脑**上：同样通过应用把文件发到手机。

接收端会先落到应用自己的接收位置，再按需要移动或另存。

## 二、文件落在哪，发送前要不要确认

- **接收位置可以在应用设置里改**。默认不会散落在系统下载目录里让你去猜，找不到就去设置里看一眼当前的接收目录。
- **收发完成会有通知提醒**，不会出现「点了发送、什么都没发生」这种无法判断的状态。
- **互传文件不会再弹确认框**。第一次配对时你要在电脑上点一次「接受」，之后已配对的设备默认是受信任的；所以发出去就发出去了，别指望有个二次确认拦一下。

## 三、把手机存储挂进资源管理器

这一步要满足两个条件，缺一不可：

- 手机是 **Android 11 或更高**（官方明确要求）
- 电脑端是 Windows

操作顺序：

1. 手机端应用设置里打开**存储访问权限**，按提示给「所有文件访问」这类权限。
2. 电脑端的资源管理器里会出现一个指向手机存储的入口，点进去就是手机的文件。

两个官方提示必须留意：

- 这个功能官方标注为**偏实验性**，在部分系统上可能不工作——尤其较老的 Windows 10，以及一些非官方精简过的 Windows 11。
- 官方仓库的说明文档里有一条警告：**不要把远程存储的位置设成电脑上已经存在的文件夹**，那会把该文件夹里原有的内容删掉。挂载点要指向一个新建的空文件夹。

## 四、权限与系统门槛对照

| 想做的事 | 手机端要给的权限 | 系统门槛 |
| --- | --- | --- |
| 收发单个文件 | 文件和媒体（存储）相关权限 | 无特殊要求 |
| 电脑浏览手机整体存储 | 所有文件访问权限 | Android 11 及以上 |

## 五、传不动、看不到怎么查

| 现象 | 先查 |
| --- | --- |
| 分享菜单里找不到 Sefirah | 两端是否已连接；手机端应用是否还在后台运行 |
| 资源管理器里没有手机存储入口 | 手机是否 Android 11 及以上；存储访问权限是否已给；电脑端是否重连过 |
| 挂上了但打不开文件夹 | 属于该功能的实验性限制，官方说明在部分 Windows 版本上不工作；换一台系统版本正常的电脑对比一下 |
| 传大文件传一半断了 | 手机端被系统挂起或息屏省电，保持应用在前台并把它加入不省电名单 |
| 挂载后发现电脑上某个文件夹被清空 | 挂载点指到了已有内容的文件夹，属于官方警告的那种误操作 |

剪贴板这类小内容走的是另一条通道，见 [剪贴板同步怎么用.md](剪贴板同步怎么用.md)。
