# Sefirah 手机和电脑怎么配对连接

> 本篇是首次配对的操作顺序：两端怎么互相发现、密钥怎么核对、自动连接与手动连接怎么选，以及「看得见却连不上」时先查哪里。

配对这一步需要你手动确认一次，过了这一步，剪贴板、文件、通知这些才通。多数「连不上」不是应用出毛病，而是两端不在同一网段，或者手机端的基础权限没给全。

## 一、配对前先确认三件事

| 检查项 | 怎么确认 |
| --- | --- |
| 两端在同一个局域网 | 手机和电脑接的是同一个路由器；访客网络、开了 AP 隔离的网络、手机走流量而电脑走宽带，都不行 |
| 两端应用都在运行 | 电脑端启动后停在主界面；手机端打开应用 |
| 手机端基础权限已给 | 引导页要求的权限先给完。位置权限别跳过，官方说明里它用来自动判断「当前是否在熟悉的网络」，缺了自动重连不生效 |

从网盘装的 APK，引导页授权可能被系统挡住，先按 [下载与安装教程.md](下载与安装教程.md) 第二节处理「允许受限设置」。

## 二、完整配对顺序

1. 电脑端启动 Sefirah，等一会儿，两端列表里应该能互相看到对方设备。
2. 在**手机端**发起连接，二选一：手动连接、自动连接，两者区别见第四节。
3. 电脑端弹出接受 / 拒绝连接的提示，选**接受**。
4. **核对两端显示的密钥是否一致**，一致再继续。
5. 认证走完，两端各自进主界面。电脑端的通知列表首次加载要等一会儿才有内容，属正常。

顺序别颠倒：连接是从手机端发起的，电脑端只负责接受。在电脑端找「发起连接」找不到，就是被这个流程决定的。

## 三、密钥核对这一步别跳过

流程里要求两端显示的密钥对得上，对不上就断开重来，不要「先连上再说」。重来之前把两端都退回主界面，再重新发起一次。

## 四、自动连接和手动连接怎么选

| 方式 | 你需要做什么 | 什么时候用 |
| --- | --- | --- |
| 手动连接 | 自己填电脑的 IP 地址 | 知道电脑 IP、想快一点；电脑有多张网卡时更可靠 |
| 自动连接 | 什么都不用填 | 不知道电脑 IP；代价是应用要逐个地址试，慢一些 |

换过路由器、或者电脑换了网段之后，之前「自动连接」试出来的地址可能已经不对，这时改用手动连接填当前的电脑 IP，往往一次就通。

## 五、看得见、连不上：先查防火墙和端口

官方仓库的说明文档专门写过这种情况——两台设备能互相发现，但连接建不起来，先检查电脑的防火墙，放行 **5149 到 5169** 这段端口。

Windows 上还有两层要过，按下面顺序做：

1. **把当前网络改成「专用网络」**。系统把网络识别成「公用网络」时默认拦得更严，改完要重新连一次。
2. **按应用放行**。进「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」，在列表里找到 Sefirah，把「专用」和「公用」两列的勾都打上；列表里没有它，就点「更改设置 → 允许其他应用」手动把电脑端程序加进去。
3. **按端口兜底**。上面两步都不行时，在「高级安全 Windows Defender 防火墙 → 入站规则 → 新建规则」里，规则类型选「端口」，TCP 和 UDP 各建一条，端口范围填 `5149-5169`，动作选「允许连接」。

公司、学校、酒店这类网络还有自己的隔离策略，不是本地设置能解决的，这种情况用手机热点把两端接在一起最省事。

## 六、换手机、换网络、重新配对

- **换手机**：新手机装好安卓端，按上面流程重新配一次；电脑端把旧设备的配对记录删掉，免得它一直尝试重连一台已经不用的设备。
- **换路由器或搬家**：配对记录还在，只是地址变了，重新连一次即可。
- **两端都正常就是配不上**：官方更新日志里出现过「本机账户登录时取不到设备名」这类问题，当时给出的处理办法是**两端都重置应用**（清除应用数据）后重新配对。这是最后一招，会清掉已有的配对与设置。

## 七、配对之后，先拿剪贴板验一下

配对成功不等于每个功能都通——各功能还要单独开权限与开关。验证成本最低的是剪贴板：在电脑上复制一段文字，看手机上能不能粘出来，具体开关见 [剪贴板同步怎么用.md](剪贴板同步怎么用.md)。配对反复失败的话，按 [常见问题与排查.md](常见问题与排查.md) 里的连接类条目逐条排。
