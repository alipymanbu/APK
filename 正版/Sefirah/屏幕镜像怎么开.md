# Sefirah 屏幕镜像怎么开

> 本篇讲把手机屏幕投到电脑需要额外准备什么、怎么在应用里指向 scrcpy、怎么启动，以及没画面时先查哪几件事。

屏幕镜像和前面几个功能不一样：它不内置在 Sefirah 里，而是调用另一个开源工具 scrcpy 来实现——所以除了 Sefirah 两端，你还要在电脑上单独准备 scrcpy。缺了它，点启动只会弹一个提示。

## 一、先准备 scrcpy

1. 去 scrcpy 的官方仓库 `github.com/Genymobile/scrcpy` 的 Releases 页面下载 Windows 版压缩包。
2. 解压到一个固定位置，别放在临时目录里，路径里也尽量别有会变动的东西。
3. 回到 Sefirah 电脑端的**设置**里，把 scrcpy 的位置指到解压出来的可执行文件。

## 二、启动镜像

最省事的一条路是先接数据线：

1. 手机开启开发者选项与 **USB 调试**。
2. 用数据线把手机连到电脑，按手机上弹出的提示允许调试。
3. 在 Sefirah 电脑端界面上**点那个手机边框**，就会启动镜像。

第一次用 USB 走通之后，Sefirah 会尝试通过默认的 tcpip 端口连接，之后的连接就不一定要线了。

## 三、可以在设置里预设启动参数

屏幕镜像那一节里可以配置启动参数与 ADB 连接相关的偏好，比如画面尺寸、码率这类 scrcpy 自己支持的选项。参数含义以 scrcpy 官方文档为准；填错了会起不来，所以改之前先把默认值记下来。

## 四、没画面时按顺序查

| 现象 | 先查 |
| --- | --- |
| 提示找不到 scrcpy | 电脑端设置里的 scrcpy 路径是否指向解压出来的可执行文件 |
| 提示 ADB 设备没连上 | 数据线是否支持传数据、USB 调试是否打开、手机上是否点了允许调试 |
| 点了没反应 / 弹一个提示框 | 官方在这一版里加过明确提示：设备没连上或找不到 scrcpy 时会给对话框，照着提示补 |
| 有画面但很卡 | 无线连接的常见表现，优先改回数据线；或降低分辨率与码率参数 |
| 之前能连，现在连不上 | 手机重启后会丢掉 tcpip 监听，重新插一次线启动即可 |

scrcpy 自身的疑难，官方仓库的说明文档指明去查 scrcpy 自己的连接文档与 FAQ，那部分不归 Sefirah 管。
