# Sefirah 剪贴板同步怎么用

> 本篇讲剪贴板两个方向分别要开什么、手机端为什么要给无障碍权限、图片为什么传过来了却粘不出来，以及不生效时怎么查。

剪贴板是 Sefirah 最常用的一项，也是「装好了却觉得没用」的高发区——因为两个方向是分开管的，各有一套开关和权限。本篇按方向拆开讲，最后给一张不生效的排查表。

## 一、两个方向，各开各的

| 方向 | 要开什么 |
| --- | --- |
| 电脑 → 手机 | 手机端的**设备设置**里启用剪贴板同步；要同步图片还得另外打开图片同步开关 |
| 手机 → 电脑 | 手机端启用剪贴板同步偏好设置，再给**无障碍权限**——官方说明里无障碍权限的用途就是「把安卓剪贴板同步到电脑」 |

第一次配对完只开了其中一边，是很常见的情况：你会发现「电脑复制到手机好使，反过来不行」。这不是坏了，是另一边没开。

在手机端点开已连接设备的名字，就进得去它的设置页，里面那个开关叫「与电脑同步剪贴板」（英文界面写作 Sync clipboard with desktop），图片同步通常在同一页。界面文案会随版本变化，位置以你装的那一版为准。

## 二、手机往电脑发，走无障碍权限

1. 进「设置 → 无障碍 → 已安装的服务（有的系统叫已下载的应用）→ Sefirah」，打开开关并确认。
2. Android 13 及以上如果这一步授不上权限，先去「设置 → 应用 → Sefirah → 右上角菜单」，打开**允许受限设置**，再回来授权。
3. 授完之后回应用里重新连接一次，让服务挂上。

无障碍服务被系统自动关掉是常事（省电策略、系统更新、安全软件清理）。手机复制了东西电脑没反应，第一件事就是回这里看开关还在不在。

## 三、不想全程自动，也可以手动发

除了自动同步，手机端还留了几个手动入口：

- 常驻的设备状态通知上的操作
- 快捷设置里的磁贴（下拉通知栏里那个）
- 系统分享菜单——选中文字或链接，分享到 Sefirah

手动入口不依赖无障碍服务，对授权有顾虑、或者只是偶尔用一次时，走这条路更省心。

## 四、图片和链接这两类内容

- **图片**：电脑上复制一张图，默认不一定发得出去，要在设备设置里打开图片同步；收到之后如果手机上粘不出来，还要打开**把收到的图片加入剪贴板**这一项——否则图片只是传过来了，没进系统剪贴板。这个开关是「收得到、粘不出」最常见的原因。
- **链接**：电脑上复制的网址同步到手机后会按链接处理，可以直接点开。如果同步过去是一串点不动的纯文本，用手机上的文本编辑器确认一下是不是被自动加了空格或换行。

## 五、不生效时按这样查

| 现象 | 先查 |
| --- | --- |
| 电脑复制，手机没反应 | 手机端设备设置里剪贴板同步是否开着；Sefirah 是否被系统清掉了后台 |
| 手机复制，电脑没反应 | 无障碍服务是否还开着；Android 13+ 的受限设置是否放行 |
| 图片收不到 | 设备设置里的图片同步开关是否打开 |
| 图片收到了但粘不出来 | 「把收到的图片加入剪贴板」是否打开 |
| 时好时坏 | 手机省电策略把应用挂起了，把它加入不省电名单 |

剪贴板内容在两端设备之间直连传输，不经过账号或云端。要传大文件、或者想让电脑直接翻手机里的文件，那是另一套功能，见 [传文件和访问手机存储.md](传文件和访问手机存储.md)。
