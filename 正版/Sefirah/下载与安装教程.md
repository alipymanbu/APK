Sefirah 是一个把 Android 手机和 Windows 电脑连起来的开源工具，剪贴板、文件、通知、短信、屏幕都能在两端之间走，两端在同一个局域网里直连，不需要注册账号。它不是单端软件：手机和电脑各装一个，只装一边用不起来。本篇只管「装」，连接那一环见 [手机和电脑怎么配对连接.md](手机和电脑怎么配对连接.md)。

## 一、哪份包装哪台设备

网盘里这份是**安卓端**安装包。电脑端要另外装，官方给的来源是这几个：

| 装在哪台设备 | 系统要求 | 从哪拿 |
| --- | --- | --- |
| Android 手机 | 以官方发布页标注为准；其中「把手机存储挂到资源管理器」这一项要求 Android 11 及以上 | 本页网盘资源 |
| Windows 电脑 | Windows 10 及以上，具体以商店页标注为准 | 微软商店搜 Sefirah（官方应用 ID `9PJV6D1JPG0H`）；或官方仓库 `github.com/shrimqy/Sefirah` 的 Releases 页面 |
| Linux 电脑 | 官方说明支持有限，部分功能没有 | 官方仓库 `github.com/shrimqy/Sefirah` 的 Releases 页面 |

两端版本不用刻意追新，但**别差太多**：版本跨度大时配对与同步容易出问题。本页网盘里这份是安卓端 1.1.1，电脑端尽量选与它接近的版本；官方发布页按版本号归档，能翻到历史版本。

这一类的手机连电脑工具还有 KDE Connect 和微软 Phone Link，三者在平台覆盖、账号要求上的差别见 [和KDE Connect这类工具的区别.md](和KDE Connect这类工具的区别.md)。

## 二、安卓端安装

1. 从上面的 **[Sefirah 安装文件资源（夸克网盘）](https://pan.quark.cn/s/52b461a3ae72)** 把 APK 转存并下载到手机本地存储。
2. 点开这个 APK。系统提示「不允许从此来源安装」时，去弹窗给的那个入口，给**当前打开 APK 的应用**（文件管理器或浏览器）打开「允许安装未知应用」，再返回重装。
3. 装完第一次打开，引导页会连着要几项权限。这里有一个必经的坎：**Android 13 及以上，系统默认不允许侧载应用申请无障碍与通知使用权**。授权被挡住时，去「设置 → 应用 → Sefirah → 右上角菜单」，打开**允许受限设置**，再回到引导页重新授权。
4. 授权顺序上，通知权限和存储相关权限先给完；无障碍权限可以等真正要同步剪贴板时再给，用途见 [剪贴板同步怎么用.md](剪贴板同步怎么用.md)。

## 三、电脑端安装

两条路，功能一致，选一条即可：

- **微软商店**：在商店里搜 Sefirah，或按应用 ID `9PJV6D1JPG0H` 定位，点「获取 / 安装」。这种方式能跟着商店自动更新。
- **官方 Releases 页的压缩包**：官方仓库 `github.com/shrimqy/Sefirah` 的 Releases 页面提供按架构分开的 Windows 包（x64 与 arm64 两种），下载后解压运行。**要按电脑架构选**，选错会起不来；不确定就看系统信息里的「系统类型」。

电脑端第一次启动后，停在主界面等两端互相发现即可——发起连接的动作在手机端做，顺序见 [手机和电脑怎么配对连接.md](手机和电脑怎么配对连接.md)。

## 四、这份包的身份信息

文档里凡涉及版本号、包名、体积，都以这份包为准（网上能搜到的是官方最新版，和这份不是同一版）：

| 项目 | 值 |
| --- | --- |
| 应用版本 | 1.1.1 |
| 包名 | `com.castle.sefirah` |
| 安装包大小 | 9.34M |
| MD5 | `C57D91D95083E484C399E4753C5B8B46` |

包名就是应用在系统里的身份。想确认手机上装的到底是哪一份，去「设置 → 应用 → Sefirah → 应用信息」看包名是否与上表一致。想核对 MD5，在电脑上用任意 MD5 校验工具对 APK 算一次，与上表逐位比对即可。

## 五、装不上的几种情况

| 现象 | 原因方向 | 处理 |
| --- | --- | --- |
| 提示「解析软件包时出现问题」 | 文件没传完 / 下载中断 | 重新从网盘转存下载，并核对 MD5 |
| 一直提示「禁止安装未知应用」 | 打开 APK 的那个应用没有安装权限 | 给**打开 APK 的应用**授权，不是给 Sefirah 授权 |
| 装完打开，授权页怎么点都授不上 | Android 13 及以上的受限设置拦截 | 按第二节第 3 步打开「允许受限设置」再试 |
| 电脑端解压后运行不起来 | 下载的包与电脑架构不符 | 按系统类型改下 x64 或 arm64 那一份 |
| 两端都装好，却互相看不到设备 | 不在同一个局域网 | 按 [手机和电脑怎么配对连接.md](手机和电脑怎么配对连接.md) 第一节核对 |

装完之后的下一步是配对，配对失败的排查集中在 [常见问题与排查.md](常见问题与排查.md)。
