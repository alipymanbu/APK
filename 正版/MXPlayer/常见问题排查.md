# MX Player 常见问题排查：没声音、看不到文件、字幕乱码

> 本篇把 MX Player 最高频的几类故障放在一起：播放没声音、视频列表是空的、字幕乱码、播放崩溃、图标或状态不对，按现象对号入座。

## 一、有画面没声音（或直接崩溃）

九成是音轨格式问题：AC3 / EAC3 / DTS 这几种音轨**不随应用内置**，MX Player 会尝试借用手机系统的音频解码，系统也没有时就没声，个别机型还会崩。

按顺序试：

1. 播放中点 SW 按钮切到 SW 解码（它对这几种音轨处理最完整）；
2. 切 SW 后反而崩溃：设置 → 解码器 → 关掉「HW+ audio on SW video」；
3. 长期有这类片源：装自定义解码包，版本对应、安装步骤与来源说明见[不支持此音频格式怎么办.md](不支持此音频格式怎么办.md)。

排查时先用一个 MP4（AAC 音轨）确认手机喇叭本身是好的，别把静音开关和蓝牙耳机占用当成播放器故障。

## 二、视频列表是空的、找不到文件

按命中率排：

1. **存储权限没给够**（尤其 Android 11+）：系统设置 → 应用 → MX Player → 权限 → 给「文件与媒体」或「所有文件」一档，回应用重新扫描；
2. **列表只显示有视频的文件夹**：MX Player 默认只列「含视频文件」的目录，纯图片文件夹不会出现，不是丢了；
3. **文件夹被 .nomedia 隐藏**：很多下载工具会在目录里放 `.nomedia` 文件让系统媒体库忽略它，MX Player 跟着不显示。删掉那个 `.nomedia` 文件再刷新；
4. **视频在存储卡上**：换过 SD 卡或卡没挂载时列表会少一截，确认存储卡能正常读。

刷新入口：列表页菜单 → 刷新，或设置里重扫存储。

## 三、字幕乱码或对不上时间轴

- **乱码（问号 / 方块）**：编码和字体两个原因，处理步骤在[字幕加载与设置.md](字幕加载与设置.md)第五、六节——先切编码（UTF-8 / GBK），不行换中文字体；
- **字幕比人声快 / 慢半秒**：字幕上用同步功能加偏移量，MX Player 会记住；
- **手动挂的字幕下次播放没自动出现**：同名同目录才会自动挂，字幕文件改名成和视频同名（后缀不变）放一起。

## 四、播放崩溃、花屏、卡第一帧

- 先切 SW 模式播同一个文件，SW 能播就是 HW/HW+ 与机型的兼容问题；
- 开了 HW+ 的设备：设置 → 解码器 → 关掉 HW+ 再试，官方明确 HW+ 不保证所有机型可用；
- 一打开列表就闪退（还没播放）：清一次应用数据重开，多数是扫描缓存放大了个别异常文件；
- 系统层面兜底：应用信息里清除缓存（别急着清数据，清数据会丢播放记录和解码偏好）。

## 五、图标、通知与列表状态不对

- **看过的视频颜色变了**：这是正常功能，看完和看到一半的用不同颜色标记，见[手势操作与播放控制.md](手势操作与播放控制.md)第五节；
- **后台播放没有通知条**：通知权限被关了，给上即可；
- **桌面小部件 / 文件关联异常**：装了两个播放器互相抢关联时，去系统设置 → 应用 → 默认应用里改「打开方式」。

## 六、安装、更新与版本

- 装不上、提示签名冲突、MD5 校验：属于安装环节的问题，步骤与处理在[下载与安装教程.md](下载与安装教程.md)；
- 网盘里这份是 3.1.1 版（包名 com.mxtech.videoplayer.ad，免费版），官方商店的版本号可能更新，更新后设置项名称偶尔会变，找不到某个开关时以设置页搜索为准。

以上都排完还不行的，去官方支持站 [support.mxplayer.in](https://support.mxplayer.in/) 搜对应现象，官方知识库按「Video Playback / Subtitle」分类维护，比论坛帖子可靠。
