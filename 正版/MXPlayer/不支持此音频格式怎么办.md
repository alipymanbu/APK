# MX Player 提示「不支持此音频格式」怎么办：EAC3 / AC3 / DTS 与自定义解码包

> 播放时弹出「不支持此音频格式（EAC3）」或全程无声，是音轨编码不在内置支持里。本篇讲怎么确认要装哪个解码包、怎么装、装完还不认怎么办。

## 一、为什么会有这个提示

AC3（杜比数字）、EAC3（杜比数字+）、DTS、MLP/TrueHD 这几种音频编码因为授权问题**不随应用内置**（官方支持页说明自 1.7 版起改用可替换的 FFmpeg 解码器机制）。播放带这些音轨的文件时，你会遇到三种表现之一：

- 弹窗「不支持此音频格式（EAC3）」；
- 画面正常但全程无声；
- 个别机型直接崩溃（处理见[解码模式选择.md](解码模式选择.md)第五节）。

先确认音轨是不是这类编码：用任何「媒体信息」工具看一眼视频的音轨名，出现 AC-3 / E-AC3 / DTS 字样就是本文的情况。

## 二、先看应用要哪个包

解码包**版本号必须和应用版本号一致**、架构必须和手机 CPU 一致，装错任何一个都加载不上。两个查看入口：

- 错误弹窗本身：有的会直接写「Can't find custom codec. Please use version 1.xx.0 ARMv8 NEON」，照提示的版本和架构下载即可；
- 应用内：设置 → 解码器 → 拉到底部「自定义编解码器（Custom codec）」一行，能看到当前状态与需要的架构（常见四种：ARMv8 NEON、neon64、x86、x86_64；前两种对应 ARM 手机，x86 系多为模拟器）。

拿不准架构时的省事办法：社区打包里有一种 AIO（全架构合包），把各架构都装进一个 zip，应用自己挑对的那个。以你实际下载页的说明为准。

## 三、安装步骤

1. 按第二步确认的版本 + 架构下载解码包 zip；
2. zip **不需要解压**，放进手机存储任意目录（放下载目录的话，部分版本能自动识别文件名带版本号的包）；
3. 设置 → 解码器 → 自定义编解码器 → 选中这个 zip；
4. 加载成功应用会自动重启，再播刚才那个文件就有声了。

## 四、装了没生效的排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「无法加载自定义解码包，使用默认解码器」 | 包版本和应用版本不一致 | 升级应用或换对应版本的包 |
| 选了 zip 没反应 | 下载不完整、zip 被手机安全软件改名 | 重新下载，确认扩展名还是 .zip |
| 加载成功但仍无声 | 当前在 HW/HW+ 模式下走系统音频通道 | 切 SW 解码再播 |
| 全都试过还是无声 | 音轨文件本身损坏 | 换一个已知正常的 AC3/DTS 文件验证 |

## 五、解码包从哪来

两条渠道，性质不同，自己掂量：

- **官方渠道**：官方只提供「自己编译」的说明（编译方法在 `https://mx.j2inter.com/ffmpeg`，需要 Android NDK 环境）与官方论坛链接，不直接发布成品包；
- **社区现成包**：XDA 论坛、GitHub 上的第三方项目（如 MX_FFmpeg）提供按版本编译好的成品，从哪下、信不信，属于你自己的来源判断——装的是别人编译的库文件，来源不明的包不要装。

装好解码包后无声、崩溃问题仍未解决的，回到[常见问题排查.md](常见问题排查.md)按现象继续排；不装包也可以把文件转成 AAC 音轨再播（用你手头任何格式转换工具处理自己的文件即可），效果等价。
