## 一、播放界面手势速查

手势是 MX Player 最常用的控制方式，全部作用在画面上：

| 手势 | 效果 |
| --- | --- |
| 画面上左右拖动 | 快进 / 快退 |
| 右半屏上下拖动 | 调音量 |
| 左半屏上下拖动 | 调亮度 |
| 双指上下滑动 | 调播放速度 |
| 双指捏合 / 张开 | 缩放画面（去掉黑边、放大局部） |
| 双击 | 播放 / 暂停（可在设置里开关或改成快进） |

两个注意事项：

- **亮度手势没反应**时，先关掉系统的自动亮度，一部分机型上两者会打架；
- 左右拖动的快进步长和双击行为都在 设置 → 播放器 里可调，嫌一次跳太多或太少就去改。

## 二、倍速播放

两条路径：

1. 播放中**双指上下滑**直接切档；
2. 精确控制：菜单 → 播放 → 速度，选 0.25x 到 4x 之间的档位。

注意：倍速和解码模式有牵扯，**HW 模式下只有 Android 6.0 及以上才能变速**，老系统想倍速就把视频切到 HW+ 或 SW 模式再调，详见[解码模式选择.md](解码模式选择.md)。

## 三、后台播放与画中画

- **后台播放**：长按播放键，画面停掉、声音继续，你可以切出去干别的；回到应用再点一下恢复画面。此功能配合 HW+ 模式使用（官方说明后台播放属 HW+ 的能力）。
- **画中画（PiP）**：Android 8.0 及以上，播放中按 Home 键或从菜单开画中画，视频缩成悬浮小窗继续播。悬浮窗挡到别的内容时拖走即可。

## 四、锁屏防误触与儿童锁

- **播放锁**：播放界面的锁形按钮，点一下进入锁定，触摸全部失效（来电、误碰都不影响播放），解锁长按锁钮或按提示操作。给小孩看动画片前先锁上，不然退出键迟早被按到；
- **儿童锁（Kids Lock）**：比播放锁更严，锁定后需要特定的解锁动作才能退出应用，防止孩子顺手退出去点别的。入口在设置里，老版本需要另装配套插件，以你版本里设置页的实际提示为准。

## 五、进度记忆与 A-B 循环

- **每部视频的播放位置都会被记住**，中途退出下次打开自动续播，从上次的位置接着放；
- 列表里**看过一半的**和**看完的**用不同颜色标记，挑没看完的接着看很直观；
- **A-B 循环**：菜单 → 播放 → A-B 重复，设起止两点后在这段之间反复播，学外语、抠舞蹈动作常用。

## 六、外接键盘的快捷键

插了实体键盘（平板配键盘、电视盒子遥控器也走这套）时可用：空格键播放 / 暂停，方向键左右快退快进，菜单快捷键在 设置 → 播放器 里可自定义。用遥控器导航列表和播放界面同样是方向键逻辑。

调音量亮度嫌手势够不着，或者双击总误触想改键位，这些都属于播放体验的微调；播放本身出问题（卡顿、没声音）则要看[解码模式选择.md](解码模式选择.md)和[常见问题排查.md](常见问题排查.md)。
