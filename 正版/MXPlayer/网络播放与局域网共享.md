## 一、三条路各自适合什么

| 入口 | 适合场景 | 前提 |
| --- | --- | --- |
| 网络流（贴链接） | 手头正好有一个视频的直链地址 | 链接能直接打开视频文件 |
| SMB | 播电脑或 NAS 硬盘里的片库，反复看 | 两台设备在同一 Wi-Fi，电脑开了共享 |
| DLNA / 局域网扫描 | 局域网里有媒体服务器（NAS、路由器 USB 共享等） | 服务端开了 DLNA / UPnP |

三个入口都在应用左侧抽屉（列表页左上角菜单）的「网络」区里。

## 二、SMB 连电脑或 NAS

1. 手机和电脑（或 NAS）连同一个 Wi-Fi；
2. 电脑端把装电影的文件夹设为共享（Windows：右键文件夹 → 属性 → 共享；NAS 在管理页开 SMB 服务）；
3. MX Player → 网络 → SMB → 右上角 + 新建：
   - **主机**：填电脑的局域网 IP（Windows 下 `ipconfig` 查看，如 `192.168.1.100`），也可以直接填 `计算机名.local`；
   - **账号**：直接填电脑的 Windows 登录账号和密码（没设密码的账号先设一个，匿名连接多数会被新版系统拒绝，见下）；
4. 保存后点开这条连接，按目录进到共享文件夹，点文件直接播。

连不上的常见原因按命中率排（后两条是 Windows 侧的硬变化，多数人栽在这里）：

- 两台设备不在同一网段（路由器开了访客网络隔离），或电脑睡眠了；
- 电脑防火墙拦了 SMB（文件和打印机共享未放行）；
- **匿名连接被新版 Windows 默认拒绝**：Windows 10 1709 起、Windows 11 24H2 起更严格，不带账号密码的 guest 连接一律被挡。给共享文件夹对应的 Windows 账号设个密码，MX Player 连接里填真实账号密码，别勾匿名；
- **老 NAS / 老设备只支持 SMB1**：SMB1 已被新版系统停用，这类设备只能从服务端开启 SMB2/SMB3（NAS 管理页或 Windows 管理员 PowerShell `Set-SmbServerConfiguration -EnableSMB2Protocol $true`）。

逐项排除，先保证电脑自己在文件管理器里能打开 `\\电脑IP\共享名`，再回头看手机端。

## 三、DLNA 与局域网发现

NAS 或带 USB 共享的路由器一般都带 DLNA 服务。开了之后，MX Player 的「网络」页会自动扫描出设备，点进去浏览媒体列表播放，不需要输账号密码。DLNA 列表由服务端生成，手机端只负责点播，所以看到哪些文件、什么排序都取决于服务端的设置。

## 四、贴链接直接播

网络页里选「网络流」，把视频直链（`http(s)://…` 结尾指向具体视频文件的那种）贴进去播。注意几点：

- 网页播放页的地址（比如某个视频网站的视频详情页 URL）不等于视频文件直链，贴进去播不了；
- 直链通常有时效，过期重新取；
- MX Player 默认会接管浏览器里点开的视频链接，如果你不想点链接总被它抢走，去 设置 → 播放器 / 常规 里把「处理 http/https 视频链接」的选项关掉（官方特性页列了这个开关，位置以你的版本设置页为准）。

## 五、网络播放卡顿怎么办

网络源卡顿先查链路再查解码：

1. Wi-Fi 信号弱是最大头，离路由器近点试试，或干脆让电脑和手机都连 5 GHz 频段；
2. 高码率 4K 文件对无线带宽要求高，卡成 PPT 时用 SMB 的设备改插网线；
3. 链路没问题还卡，试试切解码模式：设置 → 解码器里有「SW 解码器(网络)」等开关，在线播放遇到奇怪卡顿时手动把当前视频切 SW 或 HW+ 对比（模式差异见[解码模式选择.md](解码模式选择.md)）。

播局域网视频时手势照常可用（倍速、音量亮度见[手势操作与播放控制.md](手势操作与播放控制.md)），字幕一样能挂本地 srt。连不上、能连上但列表为空这类问题，去[常见问题排查.md](常见问题排查.md)。
