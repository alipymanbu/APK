## 一、把字幕挂到视频上的三种方式

1. **同名同目录自动加载**：把 `xxx.srt` 和 `xxx.mp4` 放同一个文件夹、主文件名一致，播放时自动挂上。这是最省事的方式，绝大多数字幕站下载的压缩包解压后本身就是这个结构。
2. **播放中手动选择**：播放界面点字幕按钮（一个 T 字图标）→ 打开 → 浏览到字幕文件所在位置选中。字幕文件不必和视频放在一起，选一次之后 MX Player 会记住关联。
3. **在线搜索字幕**：字幕按钮里带在线搜索入口，按文件名搜公开字幕库。能否搜到、搜到的是不是你要的语言都不保证，搜不到时还是手动下载字幕文件再走方式 1 或 2。

MKV 这类容器内嵌的字幕轨不需要额外挂载，字幕按钮里直接切换轨道即可。

## 二、支持的字幕格式

按官方特性页列出的支持清单：

| 格式 | 扩展名 | 备注 |
| --- | --- | --- |
| SubRip | .srt | 最常见，纯文本 + 时间轴 |
| SubStation Alpha / Advanced SSA | .ssa / .ass | 支持完整样式（字体、颜色、特效） |
| SAMI | .smi | 支持 ruby 注音标签 |
| MicroDVD | .sub / .txt | |
| VobSub | .sub + .idx | DVD 提取的图片字幕，两个文件要放一起 |
| SubViewer 2.0 | .sub | |
| MPL2 | .mpl / .txt | |
| TMPlayer | .txt | |
| PJS | .pjs | |
| WebVTT | .vtt | 网页字幕格式 |
| Teletext / DVD / DVB 字幕轨 | — | 随容器内嵌 |
| 蓝光 PGS | — | 图形字幕，官方支持页注明的处理方式为配合 SW 解码器使用 |

中文字幕文件最常用的是 .srt 和 .ass 两种，碰到 .idx+.sub 组合时记得两个文件都要在。

## 三、用字幕手势调时间轴和位置

字幕显示出来后，直接在**字幕文字上**做手势（不是在画面上）：

| 手势 | 效果 |
| --- | --- |
| 字幕上左右滑动 | 快速前后移动字幕与视频位置 |
| 字幕上上下滑动 | 字幕整体上移 / 下移 |
| 双指捏合 | 改变字幕大小（对 SSA 和图片字幕是缩放整体比例） |
| 菜单 → 字幕 → 同步 | 精确调节时间轴偏移量，字幕比人声快就加正值 |

时间轴差半秒到一秒是最常见的情况，用同步功能一次调好，MX Player 会记住这个文件的偏移量。

## 四、样式设置与自定义字体

播放中 → 菜单 → 显示 → 字幕，能调的东西：

- 字体、字号、文字颜色、描边与背景透明度；
- 用户字体：把 `.ttf` / `.otf` 字体文件放进手机，在字幕设置里选择加载，中文用户常配自己习惯的中文字体；
- 以 `/` 开头的字幕行按斜体显示（可在设置里开关）、字幕淡出效果。

官方特性页还提到字幕描边与阴影（ticker border / shadow）默认增强可读性，不用担心浅色画面上看不清白字。

## 五、多字幕同时挂

MX Player 支持同时加载多个字幕文件（比如中英双语各一份），在字幕按钮的轨道列表里勾选。播放时切换轨道即时生效，不用重新选文件。

## 六、乱码：字全是问号或方块

中文 srt 常见两类乱码，处理入口不同：

- **问号 / 乱码字符**：字幕文件编码和设置的解码编码对不上。字幕按钮 → 字幕列表 → 长按该字幕 → 编码，把编码切到 UTF-8 或 GBK（GB18030）试一遍，中文 srt 一般就是这两种；
- **方块（豆腐块）**：编码其实对了，是当前字体不含中文字形，换一个中文字体（见第四节的自定义字体）。
