## 一、这是什么应用

LastChat 是一款安卓端的 AI 聊天客户端，本身不提供模型，而是把你自己的各家大模型接口（OpenAI、Claude、Gemini，以及任何兼容 OpenAI 格式的中转/自建服务）接到一个界面里对话。它是开源项目 [RikkaHub](https://github.com/re-ovo/RikkaHub) 的分支，官方仓库在 [github.com/Cocolalilal/LastChat](https://github.com/Cocolalilal/LastChat)，许可协议 AGPL-3.0，界面按 Material You 风格做了一轮重构，另外扩展了 Python 运行环境、角色卡、记忆检索这些能力。

适合的人：手里已经有（或愿意去申请）一个 API key，想在手机上用同一个界面切换多家模型、又不想让对话内容经过某个厂商 App 的用户。只想开箱即聊、不想配 key 的人，这款会卡在配置那一步，见 [配置API接口与模型教程.md](配置API接口与模型教程.md)。

> [!NOTE]
> 名字撞车提醒：另有一个叫 LastChat 的网页产品（[lastchat.app](https://lastchat.app)，开发商 Reforged LLC，按订阅收费）——那不是本篇讲的这一款。本篇这一款的包名是 `lastchat.rikkafork.cocolal`，只在安卓上跑，开源免费。

## 三、安装步骤

1. 把 APK 传到手机上（下载到手机、局域网互传、数据线拷过去都行）。
2. 用手机自带的文件管理器点开这个 `.apk` 文件。
3. 系统会弹「是否允许安装未知应用」——给文件管理器或浏览器授予这个权限，再回到安装界面点安装。
4. 装完点「打开」，或者回桌面找图标。

> [!NOTE]
> 如果手机开启了纯净模式 / 应用管控（各品牌叫法不同），会额外拦一道，按提示选「仍要安装」即可。安装来源是你自己下载的这份包，拿不准时先核对上面表格里的 MD5。

## 四、第一次打开

1. 1.4.3 起带一段首次设置流程，按提示走完即可；急着进主界面也可以先跳过，后面随时能回设置里补。
2. 进去后先配提供商和模型 —— 没有这一步，输入框发不出有效回复。步骤见 [配置API接口与模型教程.md](配置API接口与模型教程.md)。
3. 主界面左侧是会话抽屉（新建对话、切助手都在这），底部是输入框，输入框上方那排按钮用来选模型、切当前助手。
4. 想直接看某个功能怎么玩：多角色与记忆看 [助手设定与角色卡怎么用.md](助手设定与角色卡怎么用.md)，让 AI 跑代码和联网查资料看 [代码运行与联网搜索怎么用.md](代码运行与联网搜索怎么用.md)。

## 五、版本与兼容性说明

- 版本号是三段式 `x.y.z`（如 1.4.5），发布页偶有带后缀的预发布版（如 `1.4.2_rev`），正式使用装正式版即可。
- 官方发布页没有标注最低 Android 版本，装的时候以系统本身的提示为准；如果安装时提示版本过低，说明这台设备的系统低于该包的最低要求。
- 从 1.4.2 起提供 32 位（Armv7a）包，1.4.5 又给 ARMv7 补上了工作区（Workspaces）支持 —— 老的 32 位机器也能用这些功能。
- 升级前要不要先备份、怎么备份，见 [备份恢复与常见问题.md](备份恢复与常见问题.md) —— 有几个版本是明确要求「更新前先备份」的。
