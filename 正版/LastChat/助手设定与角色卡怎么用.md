## 一、助手是什么

一个助手 = 一套独立的系统提示词 + 默认模型 + 参数设定。你可以建任意多个（翻译助手、写作助手、编程助手、某个角色的扮演助手……），在侧边栏随时切换；**助手之间的对话互相隔离**，换助手不会串台。

配套的组织手段：

- **标签**：给助手打标签分类，数量多了以后按标签筛。
- **导入/导出**：助手配置可以整份导出再导入，用于换机或分享给别人；1.4.3 起还支持从 Chatbox 导入配置。
- **主题色**：1.4.1 起可以按助手指定 Material You 配色，也能从头像/背景图里取色。

## 二、怎么建一个自己的助手

1. 侧边栏 → 设置 → 助手 → 右上角加号新建，起名保存。
2. 点开助手卡片填配置。**系统提示词**是核心 —— 它决定这个助手的人设与做事方式；要它别中途停下来问问题，就把「有不确定的自己选一个继续往下做」这类要求直接写进去。
3. **模型覆盖**：给这个助手固定一个聊天模型（留空则用全局默认模型）。换模型只影响新消息，历史消息不会重跑。
4. 可调的生成参数（留空即用模型默认值）：

| 参数 | 作用 |
| --- | --- |
| `temperature` | 回复随机性，0 最稳、越高越发散；与 `topP` 通常二选一 |
| `topP` | 核采样阈值，压低可让回复更集中 |
| `maxTokens` | 单次回复的长度上限 |
| `reasoningLevel` | 推理模型思考多少，`AUTO` 交给模型自己定 |
| `streamOutput` | 关掉则等完整回复一次给出，不逐字流式 |

5. 还有几样按需开：**预设消息**（每次对话开头固定注入的内容）、**本地工具**（默认带一个查当前时间的工具）、**该助手可见的 MCP 服务器**（不在列表里的服务器，它的工具对这个助手就是不可见的）。
6. 保存后在侧边栏或聊天工具栏切换；助手之间对话隔离，切换对新消息立即生效。

> [!NOTE]
> 模型问「你是什么模型」答不上来是正常现象：客户端默认不注入身份提示词，模型本身对自己的版本没有准确认知。想要固定答案，在助手里自己写一条身份提示词即可。

## 三、RAG 记忆怎么开

LastChat 的记忆是本地向量库（RAG）：模型主动把值得记的事写进记忆库，之后**在别的对话里**也能检索引用。要点：

1. 进入某个助手的**记忆**页签，打开记忆开关。
2. 需要一个 **embedding（嵌入）模型** —— 没配它，记忆写不进去；换嵌入模型后旧向量需要重建，设置里有对应的处理入口。
3. 模型要能主动调用工具才会写记忆，因此选的聊天模型需支持工具调用；不想全自动也可以在记忆页手动增删条目。
4. 想让它「翻旧账」，1.4.3 起提供了记忆检索工具，助手可以主动搜索记忆与历史对话；1.4.3 还加了对聊天摘要的回退/编辑/保存选项。

记忆与聊天记录都存在设备本地，不上传（见 [备份恢复与常见问题.md](备份恢复与常见问题.md) 的备份方式）。

## 四、角色卡与语音

面向「和某个角色聊天」这类用法，LastChat 在助手之上补了角色向的能力：

- **角色卡导入**：支持 SillyTavern 规范的角色卡（v2 与 v3），有 PNG 与 JSON 两种入口 —— PNG 卡的元数据嵌在图片里，导入选图即可；JSON 卡选文件导入。导入后名称、系统提示词、描述、性格、场景、首条消息会自动填好，卡片图片通常还会自动设成聊天背景。1.4.6 对角色卡的解析与容错做了明显加强，卡面格式不规范时更少失败。
- **世界书（Lorebook）**：给角色挂背景资料，1.4.4 起可以**按单个对话**开关世界书，不必全局生效。
- **每个角色单独选声音**：1.4.3 起支持按角色挑 TTS 音色，另有自动朗读开关与音色管理页；1.4.6 起长回复的朗读排队续播，不打断不丢句。
- **角色向的生图工具**：1.4.3 起角色可调用图像生成（支持 ComfyUI 作为生图提供商），需要你另行配好生图模型。
- **分支与分享**：消息可分支（fork）继续聊，对话可导出到剪贴板。

**上下文省 token**：助手里有一项 `contextMessageSize`（每次请求携带的最近消息数上限），默认 `0` 即带全部历史；调成具体数值后，每条请求只带最近 N 条消息 —— 长对话烧钱快、或频繁撞上下文上限时，第一个该动的就是它（状态码层面的表现见 [API报错与连接失败怎么排查.md](API报错与连接失败怎么排查.md)）。

用法顺序建议：先在 [配置API接口与模型教程.md](配置API接口与模型教程.md) 把聊天模型与嵌入模型配好 → 建助手 → 导角色卡 → 开记忆。

## 五、这些数据放哪、怎么挪到新手机

助手配置、角色卡、记忆、聊天记录都归在应用的本地数据里。换机/重装前先做一次备份，方式见 [备份恢复与常见问题.md](备份恢复与常见问题.md) —— 尤其是跨大版本升级，官方有明确的「更新前先备份」提示。
