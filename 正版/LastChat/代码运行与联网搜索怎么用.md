## 一、Python 运行环境（Workspaces）

LastChat 内置 Python 执行能力：AI 生成的代码可以直接在手机上跑，不用另装 Python。按版本分两种形态，看你在用哪一版能少踩坑：

- **1.4.4 及之后**：Python 沙盒被换成了基于 PRoot 的 **Workspaces（Linux 工作区）** 环境，安装包因此比之前小了一半以上（旧版把 Python 环境整个打进 APK）。
- **1.4.4 之前**：用的是 Chaquopy 沙盒；从这版升级会动工作区架构、做数据库迁移，官方在该版发布时明确写了**更新前先备份**（见 [备份恢复与常见问题.md](备份恢复与常见问题.md)）。

工作区相关的位置：

- 平板模式的设置里有 Workspaces 项（1.4.5 起加入）；同一版本还给 ARMv7（32 位）设备补上了工作区支持。
- 1.4.6 起，二进制文件和超大文件不再塞进提示词，而是**引导你把文件放到工作区里**处理 —— 碰到「让 AI 读个大文件」的需求，走工作区比直接贴内容靠谱。

**注意**：工作区首启会下载/准备运行环境，需要网络；环境没准备好之前跑代码会失败，等它完成再试。

## 二、JavaScript 运行环境（QuickJS）

内置 QuickJS 引擎，AI 写的 JS 片段可直接执行，无需 Node。用法和 Python 一样：在对话里让它跑，结果回填到对话中。适合一次性的数据处理、格式转换、小工具脚本。

## 三、内置联网搜索

应用自带联网搜索，让模型能回答时效性问题，不需要你单独配搜索 key：

- 搜索提供商在设置里选；**Bing 提供商自 1.4.5 起带一个 RSS 兜底模式** —— 主通道被拦时会退回 RSS 抓取，不至于直接没结果。
- 有免 key（keyless）的搜索通道，1.4.7 修过它的问题；如果你的版本搜索一直返回空，先升级到 1.4.7 或更高，再不行就换一个搜索提供商。
- 助手侧有「内置搜索 / 由模型决定」之类的开关，只有助手确实偏好内置搜索时才会激活 —— 搜索没生效时，先看当前助手的搜索设置，而不是怀疑网络。

## 四、MCP 外接工具

MCP（Model Context Protocol）让你把外部工具接给模型用：文件系统、数据库、自建服务等，接上后模型就能真正去操作，而不只是聊天。

1. 设置里找 **MCP** 入口，添加服务器，填命令/地址与参数。
2. 1.4.6 起支持 **OAuth 方式的 MCP 服务器**，需要授权的远程服务可以走这个流程登录。
3. 工具名冲突问题（多个服务器暴露同名工具）在 1.4.3 已修复 —— 之前遇到「调错工具」升级即可。
4. 加完在对话里让模型调用验证一次；模型是否可用取决于当前聊天模型是否支持工具调用（见 [配置API接口与模型教程.md](配置API接口与模型教程.md)）。

## 五、什么时候用哪个

| 场景 | 用什么 |
| --- | --- |
| 算个数、转个格式、写个小脚本 | JS/Python 直接跑，别让它只给代码 |
| 处理大文件 / 二进制文件 | 放进 Workspaces 工作区（1.4.6 起会自动引导） |
| 需要最新信息、实时事件 | 开内置联网搜索 |
| 让 AI 操作你自己的服务/数据 | 接 MCP |

这些能力都挂在助手上，按助手单独配更省心，见 [助手设定与角色卡怎么用.md](助手设定与角色卡怎么用.md)。
