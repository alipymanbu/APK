## 一、数据存在哪

聊天记录、助手配置、角色卡、记忆向量全部存在**设备本地**，按官方口径是本地优先、不经过第三方存储服务器。这意味着两件事：隐私归你自己管；**卸载应用 = 数据一起没**，所以备份要自己动手。

## 二、两种备份方式

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| 本地导出 | 设置里的**备份页**导出数据库/数据文件到手机存储 | 换机前临时备一份，最省事 |
| WebDAV 同步 | 设置里填一个 WebDAV 服务地址（坚果云等兼容服务都行），自动同步备份 | 长期兜底，换机/重装后直接拉回 |

恢复方向同理：新设备装好应用 → 在备份页或 WebDAV 设置里选恢复。助手配置另有单独的导入/导出（含 Chatbox 导入），只想搬配置不搬聊天记录时用它，见 [助手设定与角色卡怎么用.md](助手设定与角色卡怎么用.md)。

> [!WARNING]
> **升级前先备份，尤其是跨大版本。** 官方在 1.4.4（改工作区架构 + 数据库迁移）和 1.4.6（大量改动、部分功能未打磨完）两个版本的发布说明里都明确写了「Make sure to backup before updating」。备份页在 1.4.3 做过布局整理，找不到入口就去设置里翻「备份」。

## 三、怎么升级

- 1.4.5 起应用内的**更新弹窗/更新横幅**重做得更顺，平板模式下也能用 —— 有弹窗时先备份再点更新。
- 想手动装：从 [LastChat 官方发布页](https://github.com/Cocolalilal/LastChat/releases) 下载对应架构的 APK 覆盖安装（同一包名直接覆盖即可，别先卸载）。
- 也可以从 [LastChat 安装文件资源（夸克网盘）](https://pan.quark.cn/s/23f77e84f6f7) 重新取安装包：换手机、清完手机存储想重装时，转存那一份再下载即可。
- 版本号是 `x.y.z`，发布页偶有带后缀的预发布版（如 `1.4.2_rev`），日常使用装正式版。官方发版节奏不定，以发布页当时显示为准。

## 四、常见问题

**1. 打字发出去没有回复，或一直转圈**
九成是提供商没配好或 key 失效。按 [配置API接口与模型教程.md](配置API接口与模型教程.md) 第四节那四条依次查：key 有效性 → Base URL 路径 → 模型 ID → 接口格式。

**2. 问它「你是什么模型」，答案乱七八糟**
正常。客户端默认不注入身份提示词，模型对自身版本没有可靠认知。要固定答案，在助手里自己写一条身份提示词（见 [助手设定与角色卡怎么用.md](助手设定与角色卡怎么用.md)）。

**3. 提供商列表里莫名其妙多了卡片**
预置提供商会自动出现在列表里，1.4.5 修过「provider presets 自主添加到用户提供商列表」的问题 —— 遇到先升级，还没升就手动删掉多余的卡片。

**4. 启动即闪退 / 用一会儿崩溃**
按版本对号入座：1.4.2 集中修过三类崩溃（安全存储初始化导致的启动崩、大对话数据库回填时的内存耗尽、部分设备发消息时的数据库兼容崩溃），1.4.1 修过开启图片压缩后大图导致的崩溃。**当前版本低于对应修复版本的，先升级**；已是最新版仍崩，先备份数据再清缓存，仍不行就带「设备型号 + Android 版本 + 复现步骤」去 [Issues](https://github.com/Cocolalilal/LastChat/issues) 搜一下有没有人报过。

**5. 联网搜索没结果**
先看当前助手的搜索开关是否启用；再看搜索提供商，Bing 通道在 1.4.5 加了 RSS 兜底、免 key 搜索在 1.4.7 修过问题 —— 版本旧就先升级，版本已是最新就换一个搜索提供商（见 [代码运行与联网搜索怎么用.md](代码运行与联网搜索怎么用.md)）。

**6. 长对话越来越卡**
1.4.4 对数据库取数加了边界、把过滤下推到数据库层，专门针对长对话的卡顿与内存耗尽；1.4.5 又降低了聊天滚动时的掉帧。**先升级**，仍旧卡就分拆对话、清理不再需要的历史会话。

**7. 想从别的客户端搬过来**
支持 Chatbox 导入（1.4.3 起）；提供商配置可用二维码/文本串分享导入 —— 注意那串内容里含明文 API key，别随手发到公开群。
