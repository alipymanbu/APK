## 一、先确认你要装的是哪个 JsHook

JsHook 是一款安卓上的工具应用：你用 JavaScript 写脚本，它负责把脚本注入到指定的目标应用里，Java 层和 native 层都能挂上钩子。它是开发者与调试人员向的工具，不是装上就能自动变出功能的普通应用 —— 没有脚本、没有激活，它基本什么都不做。

包名是 `me.jsonet.jshook`，开发者为 JsonET。装之前核对包名，可以避免装到同名或仿冒的安装包。

## 三、从哪获取

两个来源，按需选：

1. **夸克网盘**：就是头部那条 [JsHook 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e7c3a4d58ac5)，保存到自己网盘后下载 APK 安装，适合不方便访问海外渠道的设备。
2. **官方渠道**：官网 [https://www.jshook.org/](https://www.jshook.org/)、官方文档站 [https://doc.jshook.org/](https://doc.jshook.org/)、GitHub 下载仓库 [https://github.com/JsHookApp/Download](https://github.com/JsHookApp/Download)，另有 Google Play 页面 `https://play.google.com/store/apps/details?id=me.jsonet.jshook`。官方 FAQ 明确说安装文件可以在 GitHub 下载仓库找到。

无论哪个来源，装完都可以比对一下 MD5（上面表格里的那串值），确认文件在传输过程中没有损坏。

## 四、安装步骤

1. 把网盘里的资源转存到自己的网盘账号，再下载到手机存储（或模拟器的共享目录）。
2. 在文件管理器里点开 APK；系统第一次会问「是否允许安装未知来源应用」，允许当前文件管理器即可。
3. 等待安装完成，点打开。

几条安装阶段的常见注意点：

- **不要在旧版本上直接覆盖跨大版本升级**（比如 1.0.x 跳到 1.1.x 之后再跳更大版本）。官方 FAQ 提到跨大版本升级可能崩到打不开，恢复办法见[常见问题解答.md](常见问题解答.md)。
- **装在真机、虚拟机还是模拟器**：APK 本体都能装，但 JsHook 装完只是第一步，后面还有「激活」。真机走 root 激活最省事；虚拟机（VMOS、光速虚拟机这类）与模拟器也能用，差别在[激活教程.md](激活教程.md)里展开；没有 root 的设备另有经 LSPatch 的用法，见[免root与LSPatch路线.md](免root与LSPatch路线.md)。
- 装完先别急着配脚本：没有激活的情况下，应用列表和 hook 服务都是不可用的状态。

## 五、装完之后

安装只是把 JsHook 这个「管理器」放进了手机，真正的开关在激活环节：它需要设备具备 root 环境并部署一套后台组件，激活成功的标志是首页出现已激活状态。具体的激活前提与逐步操作，见[激活教程.md](激活教程.md)。

激活完成后才轮到脚本：从内置仓库订阅、手动导入或自己写，然后指定目标应用启用 hook 服务，流程见[脚本管理.md](脚本管理.md)。
