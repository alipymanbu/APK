## 一、什么时候需要连电脑

手机上改脚本，输错一个括号就要来回切应用。官方提供的电脑端方案有两种，对应不同场景：

- **VS Code 插件**：在电脑上用 Visual Studio Code 编辑 `.js` 脚本，快捷键一键推到手机或从手机拉回来，适合日常写脚本。
- **frida 命令直连**：电脑上装了 frida 的话，可以直接连手机上的 frida-server 端口，用电脑端的 `frida` 命令 spawn / attach 目标应用，适合配合既有 frida 工作流的人。

## 二、VS Code 插件：推送与拉取脚本

插件地址：[https://marketplace.visualstudio.com/items?itemName=JsonET.jshook-vscode-extension](https://marketplace.visualstudio.com/items?itemName=JsonET.jshook-vscode-extension)（Visual Studio Code 的扩展市场搜索 `jshook` 也能找到）。

装好后，在 VS Code 里对 `.js` 文件右键，或直接用快捷键：

| 快捷键 | 作用 |
| --- | --- |
| `Shift+Alt+D` | 把当前脚本推送到手机 |
| `Shift+Alt+C` | 从手机拉取脚本 |
| `Shift+Alt+F` | 清空日志 |
| `Shift+Alt+G` | 查看日志（自动刷新） |

三个使用条件，缺一个都连不上：

1. **脚本名与相对路径要和手机上一致**：插件靠「脚本名 + 相对路径」对号入座，本地随便改名再推会变成两个脚本。
2. **在 JsHook 设置里开启 server**：手机端不开，电脑端推什么都石沉大海。官方说明开启 server 不要求 JsHook 一直留在后台。
3. **电脑与手机在同一 Wi-Fi 网络**：按下快捷键后会弹出 IP 输入框，填手机在局域网里的地址。

推送成功后，别忘了改脚本内容要重启目标应用才生效（见[脚本管理.md](脚本管理.md)第二节）。

## 三、frida 命令直连

JsHook 的 frida-server 默认监听 `28042/28043` 两个端口，电脑端 frida 通过端口转发连上去：

```shell
# 端口转发
adb forward tcp:28042 tcp:28042
```

以目标应用包名 `com.android.xxx`、脚本 `test.js` 为例：

```shell
# spawn 方式：拉起目标应用并注入
frida -H 127.0.0.1:28042 -f com.android.xxx -l test.js

# attach 方式：注入已在运行的应用
frida -H 127.0.0.1:28042 -n com.android.xxx -l test.js
```

如果目标应用走的是 `fridagadget` 框架（见[脚本管理.md](脚本管理.md)第三节），连接方式与上面相同，只是连的是 gadget，把 `-n` / `-f` 换成 `Gadget`：

```shell
frida -H 127.0.0.1:28042 Gadget -l test.js
```

直连方式的前提仍然是设备完成激活（见[激活教程.md](激活教程.md)），否则手机上根本没有可连的服务。
