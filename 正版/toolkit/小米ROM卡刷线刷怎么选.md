# 小米ROM卡刷线刷怎么选

> 在 toolkit 里下载到小米 ROM 只是第一步，怎么把它刷进手机取决于你下的是卡刷包还是线刷包。这篇讲两种包怎么分、各自要走什么前置、清不清数据。

## 一、两种包一眼分清

小米官方固件按刷入方式分两类，认文件就能分清：

| | 卡刷包 | 线刷包（Fastboot 包） |
|---|---|---|
| 文件特征 | `.zip` 压缩包（文件名含机型与安卓版本） | `.tgz` 压缩包，解压后文件名含 fastboot |
| 需要什么 | 只需手机本体，电脑可省 | 电脑 + MiFlash 线刷工具 + 数据线 |
| BL 解锁 | 系统更新内手动选包不需要 | 需要，先解 BL 锁 |
| 数据 | 相对温和，仍有风险 | 通常清空全部数据 |
| 适用 | 同底包内的升级/重装 | 系统崩溃救砖、跨安卓底层的重刷 |

判定口径以小米官方「如何刷机」帮助页为准：[www.mi.com/service/support/rom](https://www.mi.com/service/support/rom/)。以下要点整理自该页与小米社区帖，入口名称随系统版本有差异，以你手机上实际显示为准。

## 二、卡刷的路径与边界

1. 从 toolkit 下载的卡刷包拷进手机存储（部分版本要求放进 `download_rom` 文件夹）。
2. 打开「系统更新」，点右上角的「…」→「手动选择安装包」，选中这个 zip，重启后完成。
3. 找不到「手动选择安装包」这个入口时，社区给出的办法是在系统更新页面连点版本图标若干次把它触发出来（隐藏选项，各版本触发方式不一）。

边界要记住一条：**卡刷跨不了安卓底层**。比如稳定版基于安卓 11、你想刷的开发版基于安卓 12，直接卡刷会失败或变砖 —— 这类跨度要么找一个与当前底包同安卓版本的卡刷包先过渡，要么改走线刷。

## 三、线刷的前置与代价

线刷是「强刷」，能把崩溃开不了机的机器救回来，代价也最大：

1. **先解 BL 锁**：手机插 SIM 卡登录小米账号、绑定设备，在社区申请解锁并通过审核（有等待期），期间手机会清数据。
2. 下载线刷包并解压，电脑装好 MiFlash 与驱动，手机「音量下 + 电源键」进 Fastboot 模式连接。
3. 在 MiFlash 里选刷机脚本：保留数据 / 全部清除 / 全部清除并上锁，三个选项清数据的程度不同，选前想清楚。
4. 点刷机后保持连接稳定，等手机自动重启。

BL 解锁会失去官方保修资格，Root 相关的代价在 [打不开与权限问题排查.md](打不开与权限问题排查.md) 第四节有展开。

## 四、刷前自查清单

- **机型对不对**：同机型还有 4G/5G、不同区域版本之分，包不可混用；先在「设置 → 我的设备」核对完整型号。
- **电量够不够**：刷机中断电是变砖的常见原因，动手前把电充足。
- **备份做没做**：卡刷相对温和，线刷基本必清数据 —— 联系人、照片、聊天记录先备份。
- **包型认没认对**：`.zip` 与 `.tgz` 别下混，线刷包必须解压后给 MiFlash 用，不能直接刷压缩包本身。
