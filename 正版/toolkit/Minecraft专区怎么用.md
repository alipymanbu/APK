## 一、板块能做什么

MC 专区提供两类东西：一是我的世界的游戏资源（模组、资源包、地图），可以浏览并下载；二是服务器信息，帮你找到能进的服务器。下载下来的内容落在手机本地存储里，再由你导进游戏。

## 二、找资源与服务器

1. 进首页，打开 MC 专区。
2. 在资源列表里按分类浏览，找到要的模组、资源包或地图，点下载。
3. 找服务器时记下服务器地址，进游戏走「多人游戏 → 添加服务器」把它填进去就能连。

下载不碰游戏本体，没 root 也能做。

## 三、把模组与资源包装进游戏

导入方式取决于你手机上跑的是哪一版 Minecraft，常见两种情况：

- **基岩版**：`.mcpack` / `.mcaddon` 这类文件，在文件管理器里选中它，用「打开方式」选 Minecraft，游戏会自动导入并给出完成提示；也可以把 zip 格式的资源包手动放进游戏的 `resource_packs` 目录（在 `Android/data` 下的游戏数据目录里，新版安卓对这一层访问有限制，进不去就优先用「打开方式」导入）。
- **借助启动器跑 Java 版**：把模组 jar 文件放进对应目录（通常是 mods 目录），并且要求模组版本与加载器版本匹配。

导入动作本身有几个容易忽略的点：

- **先关掉游戏再导**：Mojang 官方 bug 库里记录过「游戏开着时导入不生效」的问题（在 Windows 版上确认），安卓上遇到点了没反应、没有导入提示，把游戏从后台完全清掉再导一次。
- **一次导一个**：批量导入容易漏提示，导入完成的标志是屏幕上方的通知，没看到就等它跑完。
- **装完要激活**：导入成功不等于生效 —— 全局资源去「设置 → 全局资源」启用；单个世界的资源在编辑世界的「资源包」页签里激活。装了却「没变化」，先查是不是没激活。

最常踩的坑仍然是**版本不匹配**：模组或资源包对应的游戏版本和你装的游戏不一致，是「下载了、导入了、进游戏没生效」的头号原因，版本差得远时甚至会让游戏崩溃。导入前先对一眼版本号，具体导入路径以你的游戏版本的官方说明为准。

## 四、装不上或没生效时

按顺序分四段排查：

1. **下载段**：文件没下完整就重新下一次；核对是不是把 Magisk/LSPosed 模块下载和 MC 资源下载搞混了板块（模块那路见 [刷机资源怎么下载.md](刷机资源怎么下载.md)）。
2. **导入段**：游戏完全关闭后再用「打开方式」导一次；确认出现导入完成的通知。
3. **激活段**：去「设置 → 全局资源」或世界编辑页的资源包页签看它在不在、有没有启用。
4. **冲突段**：同时启用多个插件后游戏崩溃或显示异常，是插件互相冲突 —— Minecraft 官方帮助给的办法是先备份世界，然后逐个停用插件定位到冲突的那个；另外多个资源包改同一处素材时，排在最上面的那个生效。版本不匹配在上一节。

四段都排过还不行，把现象对照 [打不开与权限问题排查.md](打不开与权限问题排查.md) 过一遍。
