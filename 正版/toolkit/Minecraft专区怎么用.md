## 一、板块能做什么

MC 专区提供两类东西：一是我的世界的游戏资源（模组、资源包、地图），可以浏览并下载；二是服务器信息，帮你找到能进的服务器。下载下来的内容落在手机本地存储里，再由你导进游戏。

## 二、找资源与服务器

1. 进首页，打开 MC 专区。
2. 在资源列表里按分类浏览，找到要的模组、资源包或地图，点下载。
3. 找服务器时记下服务器地址，进游戏走「多人游戏 → 添加服务器」把它填进去就能连。

下载不碰游戏本体，没 root 也能做。

## 三、把模组与资源包装进游戏

导入方式取决于你手机上跑的是哪一版 Minecraft，常见两种情况：

- **基岩版**：`.mcpack` / `.mcaddon` 这类文件，下载后直接用 Minecraft 打开会自动导入；资源包再到「设置 → 全局资源」里启用才生效。
- **借助启动器跑 Java 版**：把模组 jar 文件放进对应目录（通常是 mods 目录），并且要求模组版本与加载器版本匹配。

最常踩的坑是**版本不匹配**：模组或资源包对应的游戏版本和你装的游戏不一致，是「下载了、导入了、进游戏没生效」的头号原因。导入前先对一眼版本号，具体导入路径以你的游戏版本的官方说明为准。

## 四、装不上或没生效时

先分清是哪一段出了问题：下载没完成（重新下一次）、文件没导进游戏（用文件管理器找到下载的文件，重新用游戏打开一次）、版本不匹配（换对应版本的资源）。三段都排过还不行，把现象对照 [打不开与权限问题排查.md](打不开与权限问题排查.md) 过一遍，或者去 [刷机资源怎么下载.md](刷机资源怎么下载.md) 确认是不是把模块下载和资源下载搞混了板块。
