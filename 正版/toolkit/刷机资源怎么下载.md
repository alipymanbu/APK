## 一、板块里有什么

刷机资源板块提供三路在线资源，都在应用内直接浏览、直接下载：

| 资源 | 你能拿到什么 |
|---|---|
| 小米 ROM | 小米官方固件包，在线查找与下载 |
| Magisk 仓库 | Magisk 模块（zip 包） |
| LSPosed 仓库 | LSPosed 模块 |

注意 LSPosed 相关入口默认不出现在主页 —— 从刷机资源板块里进去找。

## 二、下载一条龙怎么走

按分发页给出的流程，从进板块到拿到文件是一条线：

1. 进首页，打开刷机资源板块。
2. 选要进的仓库：小米 ROM / Magisk 仓库 / LSPosed 仓库。
3. 在仓库列表里找到目标模块或固件，点界面上的下载。
4. 下载完成的文件落在手机本地存储里，后续刷入就是用这些文件。

下载这一步本身不碰系统，装好应用、给了文件管理权限就能做。

## 三、下载下来之后怎么用

这是和「下载」最容易脱节的一步，三路资源各自要过的关不一样：

- **Magisk 模块**：打开手机上的 Magisk 应用 → 模块 → 从本地安装 → 选中下载的 zip → 重启生效。前提是你手机已经刷入 Magisk。具体操作以你装的那版 Magisk 的官方文档为准。
- **LSPosed 模块**：模块装好后去 LSPosed 管理器里启用；在 LSPosed 管理器内长按模块就是卸载。LSPosed 本身要求手机已 root 并启用 Zygisk，环境没搭好时装了也用不上。
- **小米 ROM 包**：分卡刷包与线刷包两类，包型怎么认、各要走什么前置、清不清数据，单独开了一篇讲，见 [小米ROM卡刷线刷怎么选.md](小米ROM卡刷线刷怎么选.md)。

## 四、root 与风险边界

- 口径说明：有的分发页写「无需 root 即可使用」，有的写「高级功能需要 root」。两条并列供你参考 —— 浏览与下载资源不依赖 root；真正把模块刷进系统、刷系统本身，依赖 root 环境。
- 刷机存在变砖与丢数据风险：动手前备份好数据，确认机型、包型、版本号三者匹配。
- 版本更替很快：仓库里能下到什么模块、ROM 有没有上新，以你打开板块时看到的列表为准。
