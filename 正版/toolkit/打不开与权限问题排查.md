## 一、安装被拦

| 现象 | 处理 |
|---|---|
| 提示「不允许安装未知来源应用」 | 跟随弹窗跳设置，允许这次安装来源，返回重装 |
| 提示已存在同名应用/安装失败 | 先确认包名 `com.rootes.toolkit` 是否装过旧版，卸了旧的再装 |
| 下载到一半失败 | 夸克网盘里重新下载一次，装前可用 MD5 核对文件（方法见 [下载与安装教程.md](下载与安装教程.md)） |

## 二、打开就闪退或卡在首页

- **文件管理权限没给**：首次启动要求授予文件管理权限，这一步被拒会导致进不了首页。去系统设置 → 应用 → toolkit → 权限，把存储/文件类权限补上再重开。
- **Beta 版稳定性有限**：1.0.9Beta 是测试版，遇到崩溃先完全退出再重开；反复崩就等下一版，以实际发布为准。
- **清后台重开 / 重启手机**：安卓杀后台策略各家不同，偶发一次闪退多半是资源被回收，不一定是应用坏了。

## 三、功能点了没反应

按功能类型分三路排查：

1. **在线功能**（翻译、AI 对话、ROM 与仓库浏览）：断网或网络差时没有结果，先换网络试。
2. **刷机类功能**：点了没反应，十有八九是没拿到 root。在 root 管理器（如 Magisk 的超级用户列表）里确认 toolkit 已被授权；手机本来就没 root 的话，这类功能用不了是正常的，见下一节的口径说明。已 root 的小米用户要走刷机这条线，先看 [小米ROM卡刷线刷怎么选.md](小米ROM卡刷线刷怎么选.md) 认清包型与前置。
3. **LSPosed 相关入口找不到**：默认不显示在主页，去刷机资源板块里找；还找不到就确认 LSPosed 环境本身（root + Zygisk）装好没有，环境没搭好时装了也用不上，详见 [刷机资源怎么下载.md](刷机资源怎么下载.md)。

## 四、root 的两种口径

各分发页对 root 的说法不一致，两条并列写给你，不替你选边：

- 一种说法：无需 root 即可使用（浏览、下载、日常小工具这一层）。
- 另一种说法：高级功能需要 root（刷机、刷模块这类动系统的操作）。

把两句话合起来就是实际体验：**下载与日常工具不用 root，动系统的操作要 root**。另外提醒一句，手机 root 本身有失去保修、部分应用拒绝运行等代价，是否 root 是你对自己设备的取舍。
