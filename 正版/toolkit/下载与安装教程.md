## 一、先认这份包

toolkit 是一款安卓玩机工具箱，把刷机资源（小米 ROM、Magisk 仓库、LSPosed 仓库）、我的世界专区，以及翻译、ping 检测、二维码生成等一批小工具收进同一个应用。据分发页信息，它由个人开发者制作（有分发页称作者是 B 站 UP 主），没有上架主流应用商店，所以拿到安装包主要靠网盘这类渠道。

你手上这份安装包的信息如下，涉及版本与体积时以此为准 —— 网上搜到的可能是更新的版本：

| 项目 | 数值 |
|---|---|
| 版本号 | 1.0.9Beta |
| 包名 | `com.rootes.toolkit` |
| 安装包大小 | 7.76M |
| MD5 | `2A63A7E7DBF267B7BD0AF2B40D1EEBE3` |
| 记录时间 | 2026-09-23 |

两点提醒：

- 版本号带 Beta，说明这是测试版，稳定性没有正式版的保证，遇到崩溃先看 [打不开与权限问题排查.md](打不开与权限问题排查.md)。
- 分发页标注的系统要求为安卓 5.2 以上；实际能否安装以你手机的系统为准。

## 二、从网盘拿到安装包并装上

1. 打开 [toolkit 安装文件资源（夸克网盘）](https://pan.quark.cn/s/382df1f991a7)，把整个文件夹转存到你自己的夸克网盘（需要夸克账号），再在手机端夸克网盘里把 apk 下载下来。
2. 点开下载好的 `toolkit_v1.0.9Beta.apk`。Android 会弹「不允许安装未知来源应用」，跟随提示跳到设置允许这一次安装来源，返回再点安装。
3. 装完直接打开，没有注册登录环节。

若是在电脑上下载后传到手机，装前可以核对一下文件完整性，Windows 下执行：

```powershell
certutil -hashfile "toolkit_v1.0.9Beta.apk" MD5
```

输出应与上表的 `2A63A7E7DBF267B7BD0AF2B40D1EEBE3` 一致（大小写不敏感）。

## 三、首次启动要过的三道关

1. **同意软件政策**：首次打开会先弹软件政策/隐私条款，同意后才能进首页。
2. **文件管理权限**：进首页前会要求授予文件管理权限，不给的话大部分功能用不了，直接允许。
3. **root 授权（可选）**：手机已经 root 的话，进入首页时可以选择给它授 root 权限，刷机类功能要用；没有 root 也能进应用，只是刷机相关那部分用不了。各分发页对「哪些功能免 root」口径不一，见 [打不开与权限问题排查.md](打不开与权限问题排查.md) 的说明。

## 四、装完先看什么

- 首页按板块分组：刷机资源、MC 专区、实用功能。想先试刀，从实用功能里的 ping 检测或二维码生成开始，这两个不碰系统、没门槛，用法见 [实用工具怎么用.md](实用工具怎么用.md)。
- LSPosed 相关的模块入口默认不显示在主页，这不是丢功能，去刷机资源板块里找，见 [刷机资源怎么下载.md](刷机资源怎么下载.md)。
- ROM 下载、仓库浏览、翻译、AI 对话这些功能都在线取数据，断网时拿不到结果；文本转换这类本地工具不受影响。
- 整个应用免费、无广告，使用中如果某天开始要求付费，先确认你装的是不是这一版。
