## 一、GeoGebra 家族好几款，该装哪个

GeoGebra 按用途分多个免费应用，容易装混。官方下载页的能力对照归纳如下：

| 应用 | 强项 | 适合 |
| --- | --- | --- |
| Geometry（本篇这套） | 几何构造：点线圆、多边形、变换、轨迹、圆锥曲线 | 平面几何学习与演示 |
| Graphing | 函数图像与方程 | 代数、函数学习 |
| Calculator Suite | 前两者加 3D、CAS、概率、电子表格的全家桶 | 想一个 App 全搞定 |
| 3D Calculator | 空间图形 | 立体几何 |
| Scientific / CAS | 数值计算 / 符号运算 | 对应计算需求 |

只画平面几何就用 Geometry；要 3D 或符号运算另装对应款，包名不同互不冲突。教材或老师指定了哪款，就按指定的装。

## 二、考试模式是什么

GeoGebra 各应用内置**考试模式**（Exam Mode）：启动后锁定设备，学生不能切出去用其他应用或上网，同时保留计算器本身的作图能力。它面向有考试监管要求的场景，由监考方决定是否启用，平时自己练习不需要碰它。是否允许在考试中使用 GeoGebra、用哪一款，以你们当地的考试规定与老师要求为准。

## 三、画板上标签太多太乱

默认设置下每画一个对象都自动挂一个字母标签。处理办法：菜单「设置 → General」把标注（Labeling）改成 **New Points Only**，只有点自动标注，线条与圆不再挂标签（这是官方教程给手机用户的建议）。已经画出来的多余标签，点对象在设置面板里改。

## 四、工具找不到、点了没反应

| 情况 | 处理 |
| --- | --- |
| 工具栏图标上带小箭头 | 长按或点击展开，同类工具藏在这一组里 |
| 「过点作平行线」之类工具点了不动 | 点击顺序不对：先选参照对象（直线），再选通过的点，顺序反过来工具不响应 |
| 刚画错几步 | 撤销按钮一步步退回去，不用删重来 |
| 输入分数后内容跑进分母、指数错位 | 光标被困在结构里：按右方向键移出再继续输入，完整规则见 [代数输入技巧.md](代数输入技巧.md) |
| 想要的功能 Geometry 里没有 | 换对应款应用（3D 去 3D Calculator、符号运算去 CAS），见第一节对照表 |

## 五、账号与作品相关

- **作图要不要注册**：不要，打开就能画；云端保存与分享链接才需要免费账号，见 [保存分享与账号说明.md](保存分享与账号说明.md)。
- **换手机作品还在吗**：登录同一账号就在云端；只在本地保存过的作品，换机前先分享或导出。
- **作品能发给别人吗**：能，保存后生成分享链接，对方在浏览器里就能打开并操作你的图形。
