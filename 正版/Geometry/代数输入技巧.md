# GeoGebra Geometry 代数输入技巧

> 本篇讲 GeoGebra Geometry 的代数输入：键盘上没有的符号怎么打、分数与指数输入后光标为什么会「困住」、结果怎么转小数。输入错位是新手最常见的坑，一篇讲透。

## 一、两种输入路线

画一个对象有两种方式：用工具在画板上点（见 [界面与基础操作入门.md](界面与基础操作入门.md)），或在代数输入里键入。需要精确坐标、精确方程时键入更快：输入 `(3, 2)` 生成点，输入 `x^2 + y^2 = 25` 生成圆，回车后图形与代数式同时出现。

手机上键入用的是 App 自带的虚拟键盘，不是系统输入法——这点先明确，下面的按键都在它上面。

## 二、键盘上没有的符号：用 ^ 和函数名

找不到根号、平方这类符号时不用翻找，直接按写法键入（官方示例口径）：

| 想输入 | 键入 | 说明 |
| --- | --- | --- |
| x 的平方 | `x^2` | ^ 后面就是指数 |
| e 的 x 次方 | `e^x` | |
| 立方根 | `(3x-1)^(1/3)` | 指数写成分数即可 |
| 平方根 | `sqrt(2)` | 也可以用键盘上的根号键 |
| 圆周率 | `pi` | GeoGebra 自动识别为 π |
| 绝对值 | `abs(-2)` | 或用键盘的绝对值键 |

## 三、光标陷阱：输入分数后内容全跑进分母

这是多份独立教程都专门提醒的坑。App 的分数、指数、根号都是「结构化」显示的——你按 ÷ 键后，光标进入分母位置，**并且会一直留在里面**，直到你用方向键把它移出来，或直接回车。没移出来就接着输入的内容，全部进了分母：

| 你想要的 | 实际发生的 | 原因 |
| --- | --- | --- |
| (1/2)×3 = 3/2 | 得到 1/6 | 按 ÷ 输完 2 后光标还在分母里，×3 也进了分母 |
| 8^(2/3) 后继续写 ÷3 之外的内容 | 内容进了指数 | 指数位同理 |
| 根号 9 + 16 = 25 | 根号下变成 9+16 | 根号内同理 |

正确的手指动作只有一个：**输完结构内的内容后，按一下右方向键把光标移出结构，再继续写后面的算式**。回车确认前先看一眼输入框，检查下标位置对不对。

## 四、结果想看小数怎么办

分数或根式输入后，GeoGebra 默认保留精确形式（分数、根号）。输出历史里有一个带 ≈ 符号的小图标，点它就把结果转成小数近似值，再点回来恢复精确形式。

## 五、更多按键藏在 f(x) 键盘里

虚拟键盘上有个 f(x) 按键，点开能看到 n 次方根等更多数学按键；键盘右上角的三点菜单里还能搜全部命令。n 次根的操作顺序是：f(x) 键盘选 n 次根键 → 输入根指数 → 右方向键移出 → 输入被开方数——还是第三节那套光标规则。

输入错位不是故障，是结构化编辑的正常行为，习惯右方向键这个动作之后就不会再踩。画图与度量流程见 [平行四边形构造实例.md](平行四边形构造实例.md)；其他问题翻 [常见问题与解决办法.md](常见问题与解决办法.md)。
