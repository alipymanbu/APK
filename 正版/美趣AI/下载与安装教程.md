## 一、这份包是什么

## 二、下载安装包

打开 [美趣AI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/74e6914dc3a1)，转存或直接下载 `美趣AI_v3.6.0.apk` 即可。网盘里是整理好的单个 APK 文件，不需要解压、不需要挑版本。

## 三、安装步骤

1. 把 APK 传到手机（网盘 App 内直接下载，或电脑下载后用数据线 / 互传工具拷过去）。
2. 在手机文件管理器里点这个 APK。
3. 系统若弹出「禁止安装未知来源应用」，按提示进入该来源（一般是文件管理器或浏览器）的「允许安装」开关，返回继续装。
4. 装完打开，首次启动会依次请求权限，见下一节。

**系统要求**：官方商店页标注「Android 7.0 以上」。系统低于 7.0 大概率装不上或装完闪退，处理办法见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、首次启动要给的权限

按商店页面公开的敏感权限说明，装完首次打开时你会碰到这几类授权，用途都是明确的：

| 权限 | 用在哪 |
| --- | --- |
| 存储 / 视觉媒体读写 | 上传图片视频做素材、把生成的作品保存到本地 |
| 相机 | 做 AI 头像等场景时拍摄照片（也可以改为从相册选） |
| 麦克风 | 录制视频、给口播 / 数字人配音 |
| 听觉媒体读取 | 上传音频文件 |
| 通知 | 作品生成完成后提醒你 |
| 系统设置 | 你没开通知时，应用会指引你跳到开关页 |

只给存储 + 相机也能走完「选素材 → 生成 → 存相册」的主流程；麦克风不给就只能用现成素材，不能现场录音。

## 五、装完核对一下 MD5（可选）

想确认包没下坏，在 APK 所在目录开命令行执行：

```powershell
certutil -hashfile 美趣AI_v3.6.0.apk MD5
```

输出应为 `d61c7ae9de71621741fb7d9b8e548036`。对不上说明文件不完整，重新下载一次即可。

装好之后怎么生成第一条视频，见 [文生视频与图生视频怎么用.md](文生视频与图生视频怎么用.md)；第一次打开就被要求登录、充值或闪退，见 [常见问题与解决方法.md](常见问题与解决方法.md)。
