## 一、装不上或装完闪退

| 现象 | 处理 |
| --- | --- |
| 点安装提示「禁止安装未知来源」 | 按系统提示给当前来源开「允许安装」开关，返回重装 |
| 提示解析失败 / 包损坏 | 校验 MD5（命令见 [下载与安装教程.md](下载与安装教程.md) 第五节），对不上就重新下载 |
| 系统版本过低 | 官方标注要求 Android 7.0 以上，低于它大概率装不上或闪退 |
| 装完一打开就闪退 | 先确认不是系统太旧；再看存储权限有没有给——首屏要加载本地与网络资源，权限缺失容易异常 |
| 手机拦截 | 部分品牌机型有自家的安装审核与安全扫描，按提示放行即可 |

## 二、生成一直转圈 / 失败

1. **先看网络**：生成是云端执行的，断网或代理不稳都会卡住，切个网络试试。
2. **别中途退应用**：生成是排队的，退出页面不等于取消任务，重新进去在作品记录里找。
3. **权限是否给全**：上传素材要存储读取权限，录音频要麦克风——缺权限的表现就是点生成没反应或立刻报错。
4. **隔一会儿再试**：高峰期排队会变长；连续多次失败再考虑升级版本或反馈（见第六节）。

## 三、生成效果不满意

- **文生 / 图生视频**：问题多半出在描述太泛或源图太乱，改法见 [文生视频与图生视频怎么用.md](文生视频与图生视频怎么用.md) 第五节。
- **照片跳舞**：换照片、换模板、升版本三步走，见 [照片跳舞与AI特效制作教程.md](照片跳舞与AI特效制作教程.md) 第五节。
- **推文视频**：个别镜头崩就重绘那个镜头，字幕问题回检查步改，见 [小说推文视频制作教程.md](小说推文视频制作教程.md) 第五节。
- 生成类功能本身有随机性，同一描述多跑一次结果可能就不同——但连续几轮都明显不对，就是描述或素材的问题，不是「再点一次」能解决的。

## 四、网盘里的版本和商店不一样

网盘这份是 3.6.0（2026-09-21 保存），官方商店页面同期已显示 3.6.3（2026-08-15 更新）。这是正常的——商店一直在迭代，网盘保存的是当时那份完整包。两者包名相同（`com.xinglihe.aiimage`），可以直接覆盖安装升级。下载与校验步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 五、找不到某个功能

这个应用的功能列表变动很频繁，你看到的教程对不上界面是常事：

- 3.6.2 加了**电商带货**视频与口播数字人优化；
- 3.6.3 加了 **AI 漫剧**一键生成；
- 1.8.6 起**照片说话**才支持文字 / 语音 / 视频三种驱动。

所以「别人有我没有」通常只是版本差异——先确认手头版本，再看是不是入口换了位置（旧入口的新名字认功能形态，别认旧截图）。各功能的入口形态见 [文生视频与图生视频怎么用.md](文生视频与图生视频怎么用.md) 第二节。
