## 一、先把收费结构说清

美趣AI 免费下载，但**多数生成功能要消耗会员时长或金币**——这是各应用商店评论里抱怨最集中的点（「一进来就要求充值」是高频评价）。它有两种消耗方式：

- **VIP 会员**：按时间订阅，订阅期内解锁会员功能；
- **金币**：按次消耗，生成一次扣一次，具体换算以应用内显示为准。

免费额度是否存在、送多少，**以应用内实际显示为准**——各时期政策不同，网上的说法都不作数。

还有一层要提前看清：**会员与金币可能是叠加的**。黑猫投诉平台上有大量用户反馈，开了会员之后生成仍要消耗金币、部分操作要二次付费；而官方 iOS 购买说明里只列了 VIP 档位、没有提叠加规则——两边口径不一致，付款前以应用内实际标价为准。纠纷与退款的处理路径单独收在 [充值退款与投诉处理.md](充值退款与投诉处理.md)。

## 二、会员档位（iOS 内购页口径）

App Store 的应用内购买说明里列的档位如下（2026-09 查到的口径）：

| 档位 | 价格 |
| --- | --- |
| 1 周 | 38 元 |
| 1 个月 | 98 元 |
| 3 个月 | 148 元 |
| 12 个月 | 198 元 |

注意三点：

1. 这是 **iOS 内购页**写的价格，安卓渠道（应用商店内购、支付宝 / 微信支付）的档位与定价可能不同，**以你实际付款页面显示为准**；
2. 该说明同时写明「订购生效后无法退款」——付款前想清楚；
3. 价格会调整，本文不作为长期有效的报价。

## 三、订阅前该看清什么

- **扣费周期**：周订阅是自动按周扣的，一周 38 元换算下来是所有档位里最贵的，只想试用时更要看清自动续费开关的状态。
- **续费方式**：iOS 走系统订阅（Apple ID 扣款），安卓走对应支付渠道，两者取消路径不同（下一节）。
- **先小后大**：先用最低档跑通一次完整生成（比如一条推文视频），确认效果符合预期再考虑长周期——商店评论里「没试用就直接收费」的抱怨很多，你自己验证比看评论靠谱。
- **评分参考**：同款应用在不同商店评分差距较大（应用宝约 2.2、App Store 约 3.6，以商店当时显示为准），差异主要就出在收费与效果的预期落差上。

## 四、自动续费在哪取消

**iOS**：

1. 打开「设置」→ 点顶部你的 Apple ID → 「订阅」；
2. 找到美趣AI，点进去；
3. 点「取消订阅」，确认。

取消后当期权益用到期为止，不再扣下一期。

**安卓**：

1. 先看应用内：「我的」→ 设置 / 会员中心里一般有「管理订阅 / 自动续费」入口，从这里关最直接；
2. 应用内找不到时，回到你付款的那个渠道（应用商店的订阅管理、支付宝的自动扣款列表、微信的扣费服务）里关闭对应签约。

关完之后可以隔天再回应用内确认一次状态显示，双保险。

## 五、扣了钱但权益没到账

1. 确认付款是否真的成功（看支付渠道的扣款记录，不是应用内的转圈）；
2. 退出登录再登回来，或重启应用——权益同步延迟偶尔会发生；
3. 仍没到账，带着订单号找应用内客服 / 反馈入口（反馈邮箱见 [常见问题与解决方法.md](常见问题与解决方法.md) 第六节）；
4. iOS 的扣款问题也可以走 Apple 的报告问题渠道申请处理，但如前所述，官方说明标注生效后不退，结果以渠道判定为准。

还没装的话，安装包与装机步骤在 [下载与安装教程.md](下载与安装教程.md)。
