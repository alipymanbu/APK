## 一、先过一遍三分钟自查

1. zip 有没有解压？解开就没法认了，保持 zip 原样。
2. 文件名改过没有？MAME 认的是精确文件名。
3. 放的目录是不是当前版本正在读的目录？改过自定义 ROM 目录的话，确认设置里选的就是它。
4. romset 版本和模拟器版本对不对？（见第三节）
5. 父 ROM / BIOS 在不在？子 ROM 与 neogeo.zip 的坑见 [ROM放置与载入方法.md](ROM放置与载入方法.md) 第一节。

## 二、症状对照表

| 症状 | 最可能的原因 | 处理 |
| --- | --- | --- |
| 列表里根本没有这个游戏 | romset 版本不匹配；目录不对；文件名被改 | 先核对版本，再查目录与文件名 |
| 列表里有，点开黑屏或退出 | 缺父 ROM 或缺 BIOS（如 neogeo.zip） | 把同游戏的父 ROM、对应 BIOS 放进同一目录 |
| 提示缺文件（missing files） | 同上，应用会点名缺哪个 | 按提示补对应文件 |
| 极慢、声音断续 | 设备性能不足，或游戏基板太重 | 见 [画面与性能调优.md](画面与性能调优.md) 的处理顺序 |
| 退出后进度、高分丢了 | 多数街机原设计就是断电即失 | 用存档快照保进度（见下一节） |

## 三、版本与 ROM 集怎么对应

网盘资源里这份是 1.34。同产品线的官方更新日志：1.32 基于 MAME 0.285、1.33 基于 0.286、1.34.1 基于 0.287——1.34 落在 0.28x 段。MAME 的 ROM 集逐版本有差异，找 ROM 时认准 0.28x 一带的包；手里已经有 0.139 老集的，那是给旧版 MAME4droid 用的，两套互不通用。

官方这条线更新很快，截至 2026-09 已到 1.41.x（基于 MAME 0.289），最新对应关系以 [官方 Releases 页](https://github.com/seleuco/MAME4droid-Current/releases) 为准。

## 四、两件先说明白的事

- **联机（NetPlay）不是 1.34 的功能**。网上有些教程演示联机对战，那是 1.37 及以后版本加入的。你要是在 1.34 里找不到联机入口，不是找错了地方，是这版还没有。
- **个别游戏跑不了是正常的**。四万多个游戏与系统，官方也说明不可能全部完美，还专门请用户别就某个游戏能否支持发邮件。某个游戏怎么都跑不起来时，换一个 romset 版本试一次，还不行就放弃它。

## 五、进度与高分怎么留

街机原机就是"投币开局、断电清零"的设计，直接退出游戏丢进度是正常现象，不是故障。想把进度留下来，用模拟器菜单里的存档快照（Save / Load State）：保存时给一个槽位，读档时选同一个槽位。两点要心里有数：

- 部分游戏对快照支持不完整，保存时会弹警告；能保存不等于读回来一定正常，重要进度多存一个槽位。
- 快照格式在 MAME 各版本之间不通用。升级应用之后，旧快照不一定还能读回来——升级前别把进度押在快照上。

另外，"高分榜记不记"因游戏而异，同样是原机特性，不能靠设置保证。
