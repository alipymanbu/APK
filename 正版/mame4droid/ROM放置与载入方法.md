## 一、MAME 的 ROM 与家用机模拟器不一样

你在 SNES 模拟器上放一个 zip 就能玩的习惯，到 MAME 这里要先纠正三件事：

- **一个游戏可能不止一个文件**。街机 ROM 有"父 ROM / 子 ROM"结构：子 ROM 是同款游戏的地区版或改版，它依赖父 ROM 里的通用数据。举例：想玩 `ddsomu.zip`（Shadow over Mystara 的北美版），同目录必须还有父 ROM `ddsom.zip`，否则读不出来。
- **有些游戏还需要 BIOS**。比如 Neo Geo 的游戏全部要目录里有一个 `neogeo.zip`，少了它这一整类游戏都黑屏。
- **ROM 集版本要和模拟器核心匹配**。MAME 每个版本的 ROM 命名与内容校验都会变，拿 0.139 时代的旧 ROM 喂给基于 0.28x 的新版，大概率识别不到。名字也别改：`mslug.zip` 改成 `合金弹头.zip` 就没人认得了。

另外：zip 不要解压。MAME 直接读 zip 包，解开反而要你再压回去。

## 二、ROM 目录：默认位置与首次选择

首次打开应用，它会先问你"ROM 文件放在哪"：用应用专属的默认目录，还是自选一个目录。装好后，默认是把游戏 zip 放进应用专属目录：

```text
/storage/emulated/0/Android/data/com.seleuco.mame4d2024/files/roms/
```

放好后重新打开应用，游戏会出现在列表里；点游戏名载入，投币、开始这些街机按键在屏幕虚拟按键区，布局怎么调见 [手柄与触屏操作设置.md](手柄与触屏操作设置.md)。

当时选错了或以后想换目录，入口在设置里：**Settings → General → Change ROMs path**（菜单叫法以你装的版本为准）。

## 三、Android 11 之后，这个目录不好进

`Android/data` 从 Android 11 起被系统收紧，Android 13 更是堵住了第三方文件管理器的绕行通道——你在管理器里点到这一层，"使用此文件夹"按钮常常是灰的。这不是 MAME4droid 的问题，所有应用专属目录都一样。可行的几条路，按省事程度排：

1. **改用自定义 ROM 目录（推荐）**。让模拟器直接读一个普通目录（比如 `Download/MAME4droid`），完全避开 `Android/data`：设置里改 ROM 路径（见第二节），或首次启动的提问里直接选自选目录——系统文件选择器会打开，选到你建的文件夹，点"使用此文件夹"再允许即可。应用自带的帮助也列了读取 ROM 的几种方式，以你装的版本里看到的为准。
2. **系统自带的"文件"应用**。Google 的 Files 或厂商内置文件管理器对 `Android/data` 有特殊权限，部分机型可以用它把 zip 拷进去；有的系统版本连拷贝都限制，能不能成以你手机实测为准。
3. **USB 连电脑**。手机连电脑后，从电脑端可以访问手机的 `Android/data`，把 zip 直接拖进上面那个 roms 目录。这是最稳的办法之一。
4. **Shizuku 授权的文件管理器**（如 FV File Explorer）。借助 Shizuku 的权限读写 `Android/data`，但要先装 Shizuku 并激活，折腾程度高一档。

不管走哪条路，zip 保持原样放进 roms 目录即可，不用建子文件夹。

## 四、放好之后

- 重新打开应用再看列表；列表按游戏英文名（即 ROM 文件名）排列，找名字别用中文名去找。
- 列表里有、点开却黑屏或退出 → 十有八九是缺父 ROM 或缺 BIOS，回到第一节的三个坑挨个对。
- 列表里根本没有 → 检查目录、文件名、romset 版本，[游戏识别不到与运行异常排查.md](游戏识别不到与运行异常排查.md) 有完整的对照表。
