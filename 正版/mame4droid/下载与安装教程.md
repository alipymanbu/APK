## 一、先确认你要装的是哪一版

同一个开发者（Seleuco / David Valdeita）发布的 MAME4droid 不止一条产品线，包名不同、定位差别很大。装错版本后游戏怎么都识别不到，是新人最常见的第一坑：

| | 新版线（2024/2025/2026） | 旧版（0.139u1 线） |
| --- | --- | --- |
| 包名 | com.seleuco.mame4d2024 | com.seleuco.mame4droid |
| 基于 | 较新的 MAME 核心（0.28x 段） | MAME 0.139u1（2011 年的核心） |
| 规模 | 40000 多个游戏与系统 | 约八千个街机游戏 |
| 设备要求 | 官方按高端机型设计 | 老机型也能跑 |
| 范围 | 除街机外还能跑 ZX Spectrum、Amstrad CPC、MSX 等家用机/电脑系统 | 基本只有街机 |

本套文档与下文网盘资源里的安装包都属于**新版线**。手机比较旧、或只想玩八九十年代初的经典街机，可以考虑旧版；想玩得全、设备也够新，选新版。

## 三、安装步骤

1. 把 APK 弄到手机上：手机网盘 App 直接下载，或电脑下载后数据线传输。
2. 在手机上点开 APK。系统会拦一次"未知来源应用"，到 设置 → 应用 → 特殊应用权限 → 安装未知应用（不同机型路径叫法略有差异），给你的文件管理器或网盘 App 授权。
3. 回来继续装完，打开应用。
4. 首次打开会让你回答"ROM 文件放在哪"（用默认目录还是自选目录）。不确定就先选默认，以后随时能在设置里改，具体见 [ROM放置与载入方法.md](ROM放置与载入方法.md)。此时游戏列表是空的——这是正常的，MAME4droid 本身不带任何游戏，ROM 要自己准备。

## 四、装完第一件事：给 ROM 找个落脚处

安装只是第一步。街机模拟器要你自己放游戏文件（ROM），放对了地方游戏才会出现在列表里。默认路径、Android 11/13 之后的目录限制、父 ROM 与 BIOS 这些坑，都在 [ROM放置与载入方法.md](ROM放置与载入方法.md)。

## 五、关于版本号

网盘里这份是 1.34。这条产品线更新很勤：官方更新日志里 1.33 基于 MAME 0.286、1.34.1 基于 MAME 0.287，截至 2026-09 已更新到 1.41.x（以 [官方 Releases 页](https://github.com/seleuco/MAME4droid-Current/releases) 为准）。要不要升级随你，但同一套文档里的功能描述以你实际装的版本为准——联机（NetPlay）等新功能是 1.37 之后才加入的，1.34 里没有。
