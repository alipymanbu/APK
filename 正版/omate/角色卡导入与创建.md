## 一、角色从哪来：三条入口

在「角色」页点右上角「+」，你会看到三个选择：

| 入口 | 适合谁 |
| --- | --- |
| 新建角色 | 想完全按自己的想法捏一个人设 |
| 导入角色 | 已经有本地角色卡文件（PNG / JSON） |
| 导入 URL | 手上有含角色数据的链接 |

网络不好时，走 URL 或从发现页导入会明显偏慢，多等一会儿，不是卡死。

## 二、新建角色：各字段都管什么

新建时填的东西直接决定角色「演得像不像」，每个字段的作用：

| 字段 | 作用 |
| --- | --- |
| 名称 / 头像 / 简介 | 基础信息；头像可选，用于列表展示 |
| 开场白（第一条消息） | 对话开始时角色说的第一句话 |
| 备选问候语 | 多个开场白，每行一条，随机取用；支持多行文本 |
| 性格特点 | 性格、习惯、行为模式 |
| 场景设定 | 角色所处的环境与情境 |
| 对话示例 | 示范对话，让模型学会这个角色的说话风格 |
| 系统提示词 | 引导 AI 扮演该角色的系统级指令 |
| 历史后指令 | 追加在对话历史之后的补充指令 |

填得越具体，角色的言行越稳定。有两个省力的功能可以利用：

- **从图片生成设定草稿**：创建角色时给一张图，可以自动生成一份设定草稿，你再改。
- **智能修改**：编辑角色时用自然语言描述改动（比如「让她说话更毒舌一点」），不用自己逐字段去改。

## 三、导入角色卡：格式与兼容性

- 支持本地导入 **PNG / JSON** 格式的角色卡文件，兼容酒馆（SillyTavern）常用的 V1 / V2 规范。
- 角色卡数据可以**再导出**，分享回酒馆社区。
- 一个隐藏入口：**图片浏览器会自动识别**你下载到本地的角色卡文件，点开就能导入。

版本提示：charx 格式、世界书、预设、jsonl 聊天记录的整批迁移是 1.9.7 起新增的生态导入能力，本篇对应的 1.9.4 版本里没有 —— 手上有这类文件的话，要么升级到新版，要么只取其中的角色卡部分。以[官方更新日志](https://help.omate.org/changelog/)为准。

从酒馆过来的读者可以按这份对照在 1.9.4 里找对应物（社区里流传的口径，官方在 1.9.7 起才做了原生的世界书与预设引擎）：

| 你在酒馆里的东西 | 在 1.9.4 的 OMate 里 |
| --- | --- |
| 角色卡 PNG / JSON | 直接导入（V1 / V2 规范） |
| 世界书 / World Info | 用「知识库」承担，注意要先配好嵌入模型，见 [模型分工与服务商选择.md](模型分工与服务商选择.md) |
| 预设 / Preset | 用「注入提示词」与自定义提示词承担 |

## 四、从发现页取卡

1. 进「发现」页，浏览或搜索角色。
2. 点开喜欢的角色卡，点「导入」。
3. 设好头像、核对信息后保存，它就会出现在你的角色列表里。

发现页刷不出内容时，去检查设置里的「发现页 API 地址」配置，见 [API设置与密钥配置.md](API设置与密钥配置.md) 第五节。

## 五、编辑与删除

- **编辑**：在角色列表左滑角色卡，点「编辑」，改完保存。
- **删除**：右滑角色卡，点「删除」，确认框里要**手动输入 delete** 才会执行 —— 这是防误删的保护机制。
- 删除角色**不可撤销**。角色删掉后，它名下的聊天记录仍然保留，但你无法再与它开新对话。

删错了还有一层兜底：应用有回收站机制（1.7.1 起），对话与角色删除后先进回收站，见 [备份恢复与数据迁移.md](备份恢复与数据迁移.md)。

## 六、导入之后去哪用

角色导入后，在「对话」页新建对话、选中它就能开聊；聊天里的消息操作、重答重写、长期记忆怎么配合，见 [聊天功能与长期记忆.md](聊天功能与长期记忆.md)。
