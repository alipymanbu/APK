## 一、为什么 OMate 需要你自己的 API 密钥

OMate 不提供模型服务，所有 AI 回复都走你自己填的 API 密钥。这意味着：

- **聊天质量取决于你选的模型**，与 OMate 本身无关；
- **费用由你的服务商直接收取**，OMate 不收额外的服务费；
- 用兼容 OpenAI 规范的中转站、甚至本地部署的模型，理论上都能接。

官方手册的原话是：理论上 OpenAI 规范与 Claude 规范的接口都可以，但各家服务商对 API 的支持程度不同，个别服务商下可能无法正常工作。选主流服务商出问题的概率最低。

## 二、添加一个 API 配置

1. 进入「设置」页，找到「API 设置」，点「+」新增。（部分版本入口是左滑 API 设置卡片，照着界面提示走即可。）
2. 在弹出的表单里填三项必填信息：

| 字段 | 填什么 |
| --- | --- |
| 名称 | 随意，方便你自己区分，比如「主力」「备用」 |
| API 规范 | OpenAI 接口规范；Claude 接口规范在 1.0.13 及以上版本支持（仅聊天和总结模型） |
| API 密钥 | 在服务商官网申请的 key |

3. 保存即可。保存后新配置会被自动设为「活跃」，之后的所有功能默认用它。

两个实用细节：

- 表单右下角有个浮动按钮，能**快捷填入预设服务商的配置**，不用手抄地址。
- 密钥只存在你手机本地，OMate 不上传到任何服务器。但反过来说，**手机别借人，也别把配置截图发出去**。

## 三、活跃配置与每个对话单独选 API

- 新添加的配置自动成为活跃配置，全局生效。
- 在**每个对话的设置里可以单独换用另一个 API 配置** —— 比如日常聊天用便宜的模型，写长篇故事时切到能力更强的模型。

## 四、编辑、删除与导入导出

| 操作 | 怎么做 | 注意 |
| --- | --- | --- |
| 编辑 | 在 API 配置列表**左滑**卡片，进入编辑，改完保存 | 改完立刻生效 |
| 删除 | 在列表**右滑**卡片，按提示输入确认 | 至少保留一个配置，最后一个删不掉 |
| 导入 / 导出 | 设置里支持把 API 配置导出成文件，也能扫码导入 | 换机迁移时很省事，见[备份恢复与数据迁移.md](备份恢复与数据迁移.md) |

## 五、发现页 API 设置（容易漏配的一处）

除了聊天用的主 API，还有一个「发现页设置」：

- 位置：设置 → 发现页设置 → API 地址。
- 作用：发现页的角色卡等资源从这些远程地址拉取。系统按你排的顺序逐个尝试，再合并取到的数据。
- 你可以添加多个地址、调整优先顺序。发现页刷不出内容时，先来检查这里。

## 六、给聊天用的模型传附加参数

API 配置的「模型参数」栏支持以查询串格式传附加参数，例如 `max_tokens=2048&top_p=0.9`：

- `max_tokens`：限制单次回复的输出长度上限（注意它限制的是模型输出，不是你发送的内容量）；
- `top_p`、`frequency_penalty` 等采样参数按服务商支持情况透传。

回复总是被截断、或想控制输出风格时可以调这里。参数是否生效取决于服务商，OMate 只负责透传。

## 七、接本地模型（Ollama 这类）

OMate 支持把 API 指向你自己的本地模型服务，官方的口径是「包括私密又无限的本地模型」。以 Ollama 为例：

1. 电脑上装好 Ollama 并拉取一个模型；
2. Ollama 默认提供 OpenAI 兼容接口，地址形如 `http://<电脑的局域网IP>:11434/v1`（11434 是默认端口，改过以实际为准）；
3. 手机和电脑连**同一个局域网**，在 OMate 新建一个 API 配置：规范选 OpenAI，地址填上面这个，密钥本地服务一般不校验、随手填一个即可（以所用服务的说明为准）。

两个边界要知道：

- 本地方案省的是调用费，换来的是速度与能力取决于你电脑的硬件；
- 嵌入、语音、生图这类专用模型本地服务未必提供，缺哪类哪类功能就不可用，分工详见 [模型分工与服务商选择.md](模型分工与服务商选择.md)。

## 八、配好之后

API 通不通，最快的验证方法是发一条消息：有流式回复就是通了。报错时先别急着换 key，对照 [常见问题与故障排除.md](常见问题与故障排除.md) 的排查清单过一遍。确认 API 没问题后，就可以去 [角色卡导入与创建.md](角色卡导入与创建.md) 准备你的第一个角色了。
