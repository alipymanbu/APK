## 一、为什么要备份

你的角色、对话、记忆、知识库全部存在手机本地，卸载重装、换机、丢机都会带走它们。OMate 给了三层保护，按常用程度排：

| 手段 | 作用 |
| --- | --- |
| 手动备份 / 恢复 | 导出完整数据文件，自己存好 |
| 云同步 | 按同步协议在设备间拉取数据（1.9.0 起） |
| 回收站 | 删除的对话与角色先进回收站，误删可捞（1.7.1 起） |

## 二、备份包含什么

备份覆盖的内容：

- 角色、对话、长期记忆、角色记事本、知识库；
- 记事本数据（1.4.7 起）；
- 发现页数据（1.4.9 起）；
- MCP 服务器的配置（1.9.3 起，你装的 1.9.4 已包含）。

**备份支持加密**（1.7.4 起），含隐私内容时建议开启。

一个已知边界：**对话中发送的图片不参与备份与恢复**。有图片记忆的对话，换机后图片部分会缺，重要图先另存。

## 三、备份与恢复的操作

1. 进设置里的「备份与恢复」。
2. 备份：点导出，生成备份文件；可以直接保存到系统下载目录（1.4.7 起），方便你随后传到网盘或电脑。
3. 恢复：在新环境里选备份文件导入，按提示确认。

推荐节奏：**每次大动作前手动备一份** —— 升级应用前、恢复出厂前、准备折腾知识库或提示词模板前。备份文件自己再转存一份到网盘或电脑，只留手机本地等于没备份。

恢复完成后别急着关页面，**扫一眼知识库的分组与勾选状态**：官方更新日志显示旧版本恢复备份曾有过知识库分组被清空的问题（1.9.8 才修复），你用的版本越早越要核一眼；发现丢了，重新挂载一次即可。

## 四、云同步

1.9.0 起支持云同步协议：多台设备间按协议同步聊天与角色数据。适合两台手机来回用的人。同步是增量的，注意先在一台设备上完成本地备份再做同步类操作，两头数据打架时以备份为准。

## 五、回收站：删除操作的最后一道网

1.7.1 起，删除对话与角色不是立即消失，而是先进回收站。所以：

- 误删了对话或角色，先去回收站找，别急着重做；
- 想彻底清理，进回收站手动清空；
- 删除时的「输入 delete」确认与回收站是两道独立的保护，前者防手滑，后者留后悔药。

## 六、换机 / 重装的推荐流程

1. 旧设备：先做一次手动备份（建议加密），把备份文件传到手机外（网盘 / 电脑）；
2. 新设备：装好 OMate（安装渠道见 [下载与安装教程.md](下载与安装教程.md)）；
3. API 配置重新填一遍，或者用配置的导入 / 二维码扫码功能（见 [API设置与密钥配置.md](API设置与密钥配置.md)）；
4. 新设备上执行恢复，选你传过来的备份文件；
5. 抽查一两个对话与长期记忆是否完整，确认无误后再卸载旧设备上的应用。

卡在哪一步，先看 [常见问题与故障排除.md](常见问题与故障排除.md)；备份文件恢复失败的，重点核对是否跨了大版本、是否加了密但没输对密码。
