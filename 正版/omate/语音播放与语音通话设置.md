## 一、语音功能的两个层级

| 层级 | 能做什么 | 需要配置 |
| --- | --- | --- |
| 语音播放 | 把角色的文字回复读出来 | 语音模型 + 角色卡里的语音参数 |
| 语音通话 | 像打电话一样与角色对话 | 在语音播放基础上再加语音识别模型 |

常见困惑先解答：**聊天界面看不到语音图标，不是坏了** —— 官方的设计是「角色设置里没配语音参数，图标就不显示」。先去把第二节的两步配完。

## 二、语音播放：两步配出来

**第一步，在 API 设置里填语音模型。** 以硅基流动为例，语音模型填 `FunAudioLLM/CosyVoice2-0.5B`（模型名以[服务商文档](https://docs.siliconflow.cn/cn/userguide/capabilities/text-to-speech)当前显示为准）。

**第二步，在角色卡里填语音参数。**

1. 进角色列表，找到要说话的角色，左滑 → 编辑；
2. 在编辑页的「语音参数」里填入参数并保存；
3. 回到与该角色的对话界面，文字左上角会出现语音图标，点击即播。

硅基流动的参数形如：

```text
voice=FunAudioLLM/CosyVoice2-0.5B:alex
```

其中 `alex` 是服务商的预置音色，具体可选音色与写法以服务商的语音合成文档为准。**参数填错格式，图标可能照旧不出现** —— 对照服务商文档逐字核。

## 三、自定义音色：用你自己的录音

硅基流动支持上传录音生成自定义音色，OMate 里做了音色管理面板配合使用，官方也录了[音色教程视频](https://www.bilibili.com/video/BV1Q25WzuEZn)。想给角色换上特定嗓音时走这条路：先在服务商侧完成音色制作，再把音色写进角色卡的语音参数。

## 四、语音通话：再多配一个识别模型

语音通话时你说的话要先被转成文字，所以要在语音播放配好的基础上，**再在设置里填语音识别模型**：

- 与聊天模型同服务商时，直接填模型名即可，例如硅基流动填 `FunAudioLLM/SenseVoiceSmall`，OpenAI 填 `whisper-1`；
- 也可以给识别单独指定服务商：点击设置项的「+」，单独填 API 地址、key 和参数 —— 比如 chat 走海外服务商、识别走国内服务商这种混搭。

## 五、配置完的检查顺序

1. 语音模型填了吗？（设置页）
2. 角色卡的语音参数填了吗？（角色编辑页，左滑进入）
3. 图标出现了吗？（对话界面文字左上角）
4. 想通话，识别模型填了吗？

按顺序查，卡在哪一步就补哪一步。图标不出现九成是第 2 步参数格式不对；通话里对方听不见你说的话，则查第 4 步。再不行回 [常见问题与故障排除.md](常见问题与故障排除.md) 和 [模型分工与服务商选择.md](模型分工与服务商选择.md)（确认你的服务商到底有没有语音类模型）。
