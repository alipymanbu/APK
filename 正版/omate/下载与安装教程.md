## 一、OMate 有哪些官方获取渠道

OMate 是一款基于 AI 的角色扮演聊天应用，主打用你自己的 API 密钥与自定义角色对话。它主要面向安卓手机，iOS 也有上架。官方发布渠道有三个：

| 渠道 | 说明 |
| --- | --- |
| 官方 APK | 从官网或用户手册页直接下载 APK 文件安装，版本更新最快 |
| Google Play | 商店分发，包名 `org.omate.console`，更新略有延迟 |
| App Store | iOS 版（名为 omate chat），更新有延迟 |

官方地址：

- 官网：[omate.org](https://omate.org)
- 用户手册（首页有最新版下载入口）：[help.omate.org](https://help.omate.org)

iOS 一侧，官方给出的 App Store 链接是美区页面；另有用户反馈国区 App Store 直接搜 omate chat 也能找到（以你商店里实际搜到的为准）。

## 二、版本说明：网盘这份是 1.9.4

OMate 更新比较频繁。本篇配套网盘资源里的安装包是 **1.9.4**（2026-09 采集），而官方手册当时显示的最新版已是 1.9.9。两者核心玩法一致 —— 角色创建与导入、聊天、面具、故事模式、朋友圈、长期记忆、知识库这些在 1.9.4 里都已经具备。

世界书、统一预设系统、内置助手「小M同学」、charx 与 jsonl 批量导入等是 1.9.7 及以后才加入的功能，1.9.4 里没有。如果你很在意这些，建议从官方渠道取最新版；具体版本差异以[官方更新日志](https://help.omate.org/changelog/)为准。

## 三、从夸克网盘取安装包

1. 打开 **OMate 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/61e801a658c1](https://pan.quark.cn/s/61e801a658c1)
2. 登录夸克账号后，把文件**转存到自己的网盘**（分享内容不支持直接下载，转存后才有）。
3. 在自己的网盘里把 APK 文件下载到手机，文件名形如 `omate_v1.9.4.apk`。

## 四、安装包信息核对

下载完成后，建议先核对一遍安装包信息再安装。网盘里这份 APK 的采集信息如下：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.9.4 |
| 包名 | `org.omate.console` |
| 大小 | 123.26M |
| MD5 | `F219F1E2B7DE53B0790984AC79C50C44` |

核对方法：用文件管理器自带的属性页，或任一 MD5 校验工具算一遍文件的 MD5 值，与上表一致说明文件完整、没在下途中损坏。大小对不上（明显偏小）多半是下载中断，重新下载即可。

## 五、安卓安装步骤

1. 先允许安装：进入系统「设置 → 应用管理（或安全设置）」，允许你的文件管理器或浏览器「安装未知应用」。不同品牌手机入口名称略有差异，一般搜「未知来源」能找到。
2. 点开下载好的 APK，按提示点「安装」。
3. 首次启动时按需授予权限（存储等），授权被拒的功能会不可用，之后可在系统设置里补授。
4. 安装完成后建议关闭「安装未知应用」的授权，保持系统习惯。

安装过程中如果提示「解析包错误」，多半是安装包没下完整，回到上一节核对大小与 MD5。

## 六、装好后的第一件事：配置 API

OMate 首次启动后**不能直接聊天** —— 它不内置模型服务，回复全部走你自己填的 API 密钥。所以第一步是进设置页把 API 配好，具体步骤、支持哪些规范、密钥怎么保管，见 [API设置与密钥配置.md](API设置与密钥配置.md)。

配好 API 之后，再从发现页导入或自己新建一个角色就能开聊了，见 [角色卡导入与创建.md](角色卡导入与创建.md)。遇到装不上、启动闪退之类的问题，先看 [常见问题与故障排除.md](常见问题与故障排除.md)。
