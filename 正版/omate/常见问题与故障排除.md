## 一、发消息报错或没有回复

这是最高频的问题，九成出在 API 配置上。按顺序过：

1. **规范选对没有**：OpenAI 规范的服务商就选 OpenAI 规范；Claude 规范要求应用 1.0.13 以上，且只覆盖聊天和总结模型。
2. **密钥本身**：去服务商后台确认 key 有效、额度没用完、没填多余空格。
3. **服务商兼容性**：官方手册明确说各家支持程度不同，个别服务商下应用可能无法正常工作。换一家主流服务商往往比调参数管用。
4. **看错误详情**：报错提示点击后不会立刻消失，还能复制内容（1.9.2 起），把错误信息拿去对照服务商文档，比盲试快得多。
5. **中转站用户**：部分中转站对特定模型的响应格式有偏差，表现为解析报错；先换官方源验证是应用问题还是中转问题。
6. **功能类报错查模型分工**：知识库、语音、生图走的是专门的模型，拿对话模型名填进对应位置是不工作的，对照 [模型分工与服务商选择.md](模型分工与服务商选择.md) 第一节补齐。

## 二、长回复写到一半断了

回复越长越容易超时。1.9.6 起，设置里新增了全局的「请求超时时间」（默认 10 分钟），用思考型模型或慢速中转站可以调大。你用更早的版本（比如 1.9.4）没有这个设置项，遇到中断可以：换响应更快的模型、调小 `max_tokens`（见 [API设置与密钥配置.md](API设置与密钥配置.md) 第六节）、或升级应用。

## 三、感觉角色「失忆」了

- 检查**载入记忆上下文条数**：默认是 3，聊天很长时把更早的内容挤出上下文是正常行为，调大会缓解；
- 长期记忆可存入知识库并同步角色记事本（1.9.1 起），确认这两个开关状态符合预期；
- 撤销最后一条消息会连记忆一起回滚 —— 如果你撤销过，那几轮的「记忆消失」不是 bug；
- 早期版本有过个别机型上记忆检索失效的问题（1.9.2 前后修复过一批），表现明显不对就先升级到最新版再观察。

## 四、发现页刷不出来、导入很慢

- 发现页内容走的是「发现页 API 地址」，去设置 → 发现页设置里确认地址配了、顺序没全失效，见 [API设置与密钥配置.md](API设置与密钥配置.md) 第五节；
- 通过 URL 导入角色、从发现页下载卡，在弱网下就是慢，官方手册也提示要耐心等，不是卡死；
- 本地角色卡也可以直接导入（PNG / JSON），不等网络，见 [角色卡导入与创建.md](角色卡导入与创建.md)。

## 五、语音图标不显示、通话听不见你的话

- **聊天界面根本没有语音图标**：这是设计行为 —— 角色卡里没配语音参数，图标就不出现。先配语音模型，再在角色编辑页填语音参数，两步链路见 [语音播放与语音通话设置.md](语音播放与语音通话设置.md)；
- **图标在、点了没声音**：查语音模型那一栏是不是空的，或填了不支持语音的服务商模型；
- **语音通话里你说的话没被识别**：语音通话额外需要语音识别模型，单独检查这一栏。

## 六、删除相关的保护机制

| 现象 | 原因 |
| --- | --- |
| 删除对话 / 角色时要求输入 `delete` | 防误删的确认机制，照着输入即可 |
| 最后一个 API 配置删不掉 | 应用要求至少保留一个配置 |
| 角色删了但聊天记录还在 | 属正常设计：记录保留，只是不能再与该角色对话 |
| 删的东西又找回来了 | 去回收站手动清掉，删除操作先进回收站（见[备份恢复与数据迁移.md](备份恢复与数据迁移.md)） |

## 七、想要某个功能，但设置里找不到

OMate 版本迭代快，很多功能是后加的。对照这张表再找：

| 功能 | 加入版本 |
| --- | --- |
| 云同步 | 1.9.0 |
| 终止请求、撤销回滚记忆 | 1.9.2 |
| 备份含 MCP 配置 | 1.9.3 |
| 请求超时设置、浅色模式 | 1.9.6 |
| 世界书、预设系统、小M助手、charx / jsonl 批量导入 | 1.9.7 |

你手头的版本低于对应版本号就看不到，升级即可。完整列表以[官方更新日志](https://help.omate.org/changelog/)为准。

## 八、还解决不了：官方渠道

- **工单**：[官方客服工单系统](https://txc.qq.com/products/711445/)，每日定时处理；
- **视频教程**：官方在 B 站有[快速开始 + 功能详解](https://www.bilibili.com/video/BV1ekoLYUEYC)的完整演示，图文看不懂的环节跟着视频走一遍；
