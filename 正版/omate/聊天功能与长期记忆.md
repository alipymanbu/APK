## 一、新建一个对话

在「对话」页点右上角「+」：

1. 对话标题可以不填，系统会按角色和面具自动生成；
2. 选一个角色（必选）与面具（可选）；
3. 选 API 配置 —— 这里可以和全局活跃配置不同，给这个对话单独指定；
4. 点「创建」进入聊天。

回复是流式输出的，文字逐段出现。想中途打断，用聊天页的「终止请求」菜单（1.9.2 起提供），不用干等。

## 二、消息层面的操作

| 你想做的 | 怎么做 |
| --- | --- |
| 改一条消息 | 在消息气泡上左右滑动调出编辑 / 删除 |
| 让 AI 重新回答 | 重答功能；1.9.4 起重写意见会插到你的消息之前，而不是追加在末尾 |
| 带着记忆重写 | 重写时可勾选把长期记忆作为参考（1.9.2 起） |
| 撤销最后一条 | 对最后一条消息有撤销菜单，且会**回滚这笔操作对长期记忆、角色记事本写入的内容**（1.9.2 起） |
| 快速回底部 | 长对话里点浮动按钮直接跳到最新消息 |

重答 / 重写的实测体验与模型能力有关：没有给修改意见、也没启用记忆参考时，部分模型可能只是原样复读，给一句明确要求会好很多。

## 三、话题、历史与回溯

- **新话题**：非角色扮演模式下，输入框左侧有「新话题」按钮。点开后旧话题自动存为聊天历史，随时在右上角菜单 →「查看聊天历史」翻回来。
- **回溯**：支持回到之前的某个节点重来，标题可手动指定（1.9.2 起）。
- 删除整个对话：在对话列表滑动卡片删除，同样需要输入确认；删了先进回收站，误删可捞，见 [备份恢复与数据迁移.md](备份恢复与数据迁移.md)。

## 四、面具、故事与朋友圈

这三个是围绕角色聊天的衍生玩法，日常用得最多的是前两个：

- **面具**：预设的角色模板，让同一个对话快速切换身份；
- **故事模式**：沉浸式地体验角色背后的剧情线；
- **朋友圈**：角色会像真人一样发动态，你可以指定由哪个对话来生成内容，也能设定在指定时间**自动生成**新动态（1.7.4 起）。

## 五、长期记忆：怎么让它记住你

OMate 的角色不会聊几轮就「失忆」，靠的是长期记忆机制，你可以按需调整：

- **载入上下文条数**：默认值是 3（1.9.2 起的默认），记忆太淡可以调大，太大则更耗 token；
- **记忆存入知识库**：长期记忆可以写入知识库长期保存（1.9.1 起）；
- **同步角色记事本**：记忆同时更新到角色记事本，两个入口共享；
- **配套回滚**：撤销最后一条消息时，记忆与记事本的相关写入一并回滚，不会留下脏数据；
- **背后的模型分工**：记忆提取与新话题标题走的是「总结模型」，没填总结模型就由对话模型兼任 —— 给它单独配个便宜的模型能省调用费，分工详见 [模型分工与服务商选择.md](模型分工与服务商选择.md)。

记忆相关的模板（如提取提示词）支持变量定制，属于进阶用法，设置页里能找到。

## 六、进阶能力（知道有就行）

- **语音**：支持语音播放、语音通话与朗读模式；语音图标要配了语音模型和角色语音参数才出现，完整链路见 [语音播放与语音通话设置.md](语音播放与语音通话设置.md)；
- **发图片**：对话支持发送图片，但要求 API 配置里指定视觉模型，且备份恢复不覆盖对话中的图片；
- **LivePage**：1.8.0 起，角色回复里可以出现可交互的卡片页面，属于创作者玩法；
- **创作者模式**：1.8.0 起，用悬浮球以悬浮窗打开设置页，方便边聊边调，还有常用文字快捷复制。

这些能力都依赖你配的模型与 API，遇到不生效先回到 [API设置与密钥配置.md](API设置与密钥配置.md) 检查配置，再看 [常见问题与故障排除.md](常见问题与故障排除.md)。
