## 一、先认全几个入口

打开 App 后你会用到的主要入口有这几类，各管一件事：

| 入口 | 用途 |
| --- | --- |
| 首页 | 新番动态与推荐，日常打开最先看到的页面 |
| 搜索 | 按关键词直接找某部番 |
| 分类 | 按类型浏览，适合没想好看什么的时候逛 |
| 时间表 | 每日更新表，看一周七天各更新哪些番 |
| 我的 | 追番列表、观看历史、设置、反馈入口都在这 |

App 不需要注册登录，上面这些功能装完即用。

## 二、找番的三条路

1. **知道名字**：直接用搜索框输关键词。搜索结果为空时会有专门的无结果提示页，检查一下关键词（试试中文名或常用的简称）。
2. **只记得类型**：进分类页按类型浏览，逐级筛到想看的为止。
3. **追新番**：用时间表。时间表按更新日组织，今天是星期几就能看到今天更新的番；新番一般在你搜到它之前就会先出现在这里。

NekoAnime 的内容来自互联网公开渠道，作者官方说明应用本身不存储视频。先把一个现实交代清楚：**目前只接了一个数据源（樱花动漫）**，能搜到什么、更新多快完全取决于它的更新节奏——某部番突然搜不到时，先怀疑数据源侧的变化，而不是你的操作有问题。「增加数据源」在官方 Issues 里有多人请求，但截至本文撰写仍是开放状态、没有实现，所以换源自救这条路目前是不存在的。

## 三、追番：把要长期看的番收进来

- 在番剧详情页点追番，这部番就进了「我的」里的追番列表。
- 追番列表支持排序（v0.5.1 专门优化过排序体验），番多了之后按自己习惯排一遍，之后每季新番更新时按列表挨个看即可。
- 取消追番同样在详情页操作，列表会同步移除。

## 四、观看历史与进度记忆

- 你看过的每一集会自动记进观看历史，不需要手动收藏。
- 中途退出后再次打开，播放进度会被记住，点开同一集从上次的位置继续。
- 想清空历史：在「我的」里有「清空观看历史」的选项，一次性清掉全部记录。

## 五、「我的」页面里值得动的几个开关

| 设置 | 作用 | 什么时候动它 |
| --- | --- | --- |
| 禁用横屏模式 | 关掉自动横屏 | 在床上侧躺看、不想屏幕乱转时 |
| 允许在竖屏状态下全屏播放 | 竖屏也能全屏 | 折叠屏/平板进播放页显示异常时，官方给的首选解法 |
| 清除番剧数据缓存 | 清掉 App 的数据缓存 | 页面数据错乱、番剧信息不刷新时 |
| 问题反馈 | 直达 GitHub Issues | 遇到崩溃、加载失败想反馈时 |
| 检查更新 | 查有没有新版 | 疑似遇到老版本已知问题时 |

表里没有的常用诉求有两个，都还没做：夜间模式（请求已排入 0.6.0 里程碑，该版本截至撰写未发布）和繁简界面切换（Issues 里有请求记录）。想要的功能在这里找不到时，先去[播放器手势与倍速说明](播放器手势与倍速说明.md)的「还在排队」清单对一遍，别在设置页里白找。

追番看番之外，通勤没网想先下几集的话，用离线缓存，具体见[离线缓存使用指南](离线缓存使用指南.md)；播放过程中卡住、闪退一类的问题汇总在[播放失败与常见问题排查](播放失败与常见问题排查.md)。
