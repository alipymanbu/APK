# NekoAnime 播放器手势与倍速说明

> 本篇讲 NekoAnime 播放界面的手势操作：怎么倍速、怎么调进度/亮度/音量、全屏里怎么选集，以及哪些播放功能目前没有。

## 一、播放中的四个手势

看番时最常用的操作都能用手势直接完成，不用去找按钮：

| 手势 | 效果 | 什么时候有的 |
| --- | --- | --- |
| 长按屏幕 | 按住期间 2 倍速播放，松手恢复原速 | v0.3.0 起 |
| 水平滑动 | 快进 / 快退，改变播放进度 | v0.3.0 起 |
| 播放区左侧上下滑动 | 调节亮度 | v0.5.0 起 |
| 播放区右侧上下滑动 | 调节音量 | v0.5.0 起 |

左右分区这个设计来自用户在 Issues 里的建议（希望横屏时左手管亮度、右手管音量），作者在 v0.5.0 落地了。所以滑动时先认准区域：靠屏幕左半边上滑是变亮，靠右半边上滑是变响。

## 二、倍速：目前只有「长按 2x」一种

NekoAnime 没有倍速选择菜单。想加速只有一条路：按住屏幕不放，播放就以 2 倍速进行，松手回到正常速度。

1.5x、0.5x 这类多档倍速，作者在 Issues 里回复过「多倍速的实现还得等一等」，这个请求到本文撰写时仍未实现。习惯用 1.25x 精细调速的话，现阶段只能接受 2x 一档。

## 三、全屏状态下直接选集

从 v0.2.0 起，全屏播放时可以直接选集，不用退出全屏再点集数列表。连着刷几集的时候，在全屏里换集比返回详情页快得多。

## 四、手势失灵或画面方向不对

- 手势没反应：先确认版本，左右分区调亮度音量是 v0.5.0 才加的，旧版本没有。
- 横屏后布局错乱、按钮位置不对：横屏适配仍有公开的待修问题（Issues #45，截至撰写开放中），临时绕开的办法是「我的 → 禁用横屏模式」，或者改用「允许在竖屏状态下全屏播放」，两个开关的说明见[界面与追番功能上手](界面与追番功能上手.md)。
- 播放本身卡住、转圈，与手势无关，去[播放失败与常见问题排查](播放失败与常见问题排查.md)。

## 五、你想要的播放功能可能还在排队

在提需求前先看这份「已知没有」清单，省得白找：

| 功能 | 现状（截至撰写） |
| --- | --- |
| 多档倍速菜单 | 只有长按 2x，多倍速请求开放中 |
| 夜间模式 | 请求已排入 0.6.0 里程碑，该版本尚未发布 |
| 手动检查更新按钮 | 目前只有自动检查更新，手动按钮请求开放中 |

确认是版本已有、只是你没找到的功能，翻翻上面的手势表；确认没有的，到官方 Issues 搜一下关键词再决定要不要新提一个。
