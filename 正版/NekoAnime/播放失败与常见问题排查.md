# NekoAnime 播放失败与常见问题排查

> 本篇汇总 NekoAnime 播放环节的常见故障：进播放页闪退、视频加载慢或失败、整站打不开、集数显示不符、横竖屏异常，每条都给出对应做法。

## 一、一进播放页就闪退

这是 v0.5.2 之前版本最典型的问题。按作者在发布说明里的解释：视频源地址被加密后，旧版本解不了，进播放页直接崩溃；v0.5.2（2025-01-23）加入了应对处理，此问题才算修掉，且作者自己也说明这只是临时手段。

**做法**：先到「我的」确认你的版本号。低于 0.5.2 就升级，升级渠道与步骤见[下载与安装教程](下载与安装教程.md)。升级后依然崩溃的，用「我的 → 问题反馈」到 GitHub Issues 里看是否有人报告同类情况。

## 二、视频一直转圈 / 加载失败

这类问题的根源在于内容来自互联网公开渠道，源站的可用性会直接传导到播放端。按顺序试：

1. **直接重试一次**。播放线路会自动切换（v0.4.0 起支持），失败后 App 有机会换到别的线路。
2. **换一集试试**。单集失败、整部番都失败，含义不同：整部都失败更可能是当时的网络或源侧问题，等一会儿再看。
3. **避开高峰**。晚间新番集中更新时段源站压力大，加载慢属于常见现象；急看的番可以先用离线缓存，见[离线缓存使用指南](离线缓存使用指南.md)。
4. **换网络**。Wi-Fi 与移动数据互换一次，排除本地网络因素。
5. **判一下是不是整站故障**。所有番都放不出来、换什么番都一样，那就不是你的问题，看下一节。

加载速度本身在 v0.3.0 做过一轮专门优化，如果你用的是远早于 0.5.x 的版本，升级本身就是最有效的处理。

## 三、整站都放不出来：数据源出问题了

NekoAnime 目前只接了一个数据源（樱花动漫），源侧域名一失效，全 App 的番都会放不出来。这不是假设：2024 年 9 月就发生过一次，当时的源站域名失效，作者先在 Issues 里同步情况、观望了一段时间，最后发布 v0.4.0 直接换用新的数据源才解决（Issues #21 里有完整的处理过程）。

遇到「什么都放不出来」时，你的正确动作：

1. **别反复卸载重装**。源侧故障重装解决不了，反而可能丢数据。
2. **去 Issues 看一眼**：[https://github.com/xioneko/neko-anime/issues](https://github.com/xioneko/neko-anime/issues)，整站级故障必然有人先你一步报告，搜「数据源」就能找到同类帖子。
3. **等新版**。数据源失效只能靠作者修复或换源，App 端没有任何设置能自救；修复节奏取决于作者的业余时间，见第六节的说明。

另外要提前知道：**换数据源的版本会清掉旧数据**。v0.4.0 发布时作者明确预告过，追番列表、观看记录、番剧缓存都会失效，要求先卸载再安装。以后再遇到版本说明里写「更换数据源」，升级前先看完备注、想清楚数据再动手。

## 四、播放的集数和选的集数对不上

「实际播放的第 X 集」与界面显示的集号偶尔会不一致——这是作者在 v0.4.0 发布说明里明确提过的已知情况，官方说法是出现概率可以接受、暂以现状处理。

**做法**：遇到时先退出该集重进一次；确认是普遍现象后，以实际播放内容为准选集，并把这一集的偏差记在心里，跳集时手动核对一下进度条。

## 五、画面方向与全屏的怪问题

| 现象 | 处理 |
| --- | --- |
| 折叠屏/平板进播放页显示异常 | 打开「我的 → 允许在竖屏状态下全屏播放」，这是官方给的解法 |
| 屏幕自动转来转去 | 打开「我的 → 禁用横屏模式」 |
| 进度条被拖拽时自己消失 | 这是 v0.3.0 之前的老毛病，v0.3.1 已修，升级即可 |

相关背景：v0.2.1 起官方才适配 Android 10 与平板/宽屏 UI，设备越特殊（折叠屏、平板、宽屏），越建议用最新版。

## 六、以上都不是 → 怎么反馈

1. 在「我的」里点「问题反馈」，会引导你到官方仓库的 Issues 页：[https://github.com/xioneko/neko-anime/issues](https://github.com/xioneko/neko-anime/issues)。先搜一下关键词，同类问题大概率有人提过。
2. 新开 Issue 时写清：App 版本号、手机型号、安卓版本、做了什么操作、现象是什么。
3. 涉及内容版权的诉求，官方仓库的说明里给的联系方式是邮箱 `xioneko@outlook.com`。

一个合理的预期：这是个业余维护的开源项目，更新节奏偏慢——作者在 2025 年的 Issues 里回复过「最近几个月感觉很难抽出时间」。所以源侧故障、疑难崩溃的修复可能要等一阵子，等修复期间先用已缓存的内容顶一顶（见[离线缓存使用指南](离线缓存使用指南.md)），比反复折腾安装包有用。

追番、历史这些使用层面的入口问题，见[界面与追番功能上手](界面与追番功能上手.md)；播放中的手势、倍速怎么操作，见[播放器手势与倍速说明](播放器手势与倍速说明.md)。
