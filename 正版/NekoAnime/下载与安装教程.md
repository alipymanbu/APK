## 一、安装前先确认三件事

1. **系统版本**：NekoAnime 官方仓库标注需要 Android 10 及以上（v0.2.1 起适配 Android 10）。系统低于这个版本会装不上或装上也跑不起来，先到「设置 → 关于手机」确认你的安卓版本。
2. **安装包体积**：本文对应的是 0.5.2 版，安装包约 10.57M，手机留出几十 MB 空间就够。
3. **版本口径**：截至本文撰写，作者在 GitHub 发布页上的最新版本就是 v0.5.2（2025-01-23 发布，修复了进入播放页崩溃的问题）。之后如果官方发了新版，请以官方发布页为准，见下文的获取渠道。

## 二、从哪获取安装文件

两个正规渠道：

- **本页提供的 NekoAnime 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/ec52d3eeb7d2](https://pan.quark.cn/s/ec52d3eeb7d2)，转存后即可下载 0.5.2 版安装包，对应本文的全部版本信息。
- **官方 GitHub 发布页**：[https://github.com/xioneko/neko-anime/releases](https://github.com/xioneko/neko-anime/releases)，能下到作者发布的各历史版本与未来新版。

两个渠道拿到的 0.5.2 版应当是同一个包，可用第四节的包信息互相核对。

## 三、安装步骤

1. 从上面的渠道把 APK 文件下载到手机存储。
2. 在文件管理器里点开这个 APK。第一次装时会弹「不允许安装未知来源应用」之类的提示，按提示进入系统设置，允许你的文件管理器（或浏览器）安装应用。
3. 回到安装界面点「安装」，十几秒即可完成。
4. 装完直接打开，不需要注册账号，也不需要任何授权登录。

## 五、升级与换版本的注意点

- **从旧版升到 0.5.2**：直接覆盖安装即可，追番、历史等数据保留。目前没有官方说明需要卸载重装。
- **历史上有过一次必须卸载重装的先例**：v0.4.0 更换了整套数据源，官方当时明确要求先卸载再安装，因为旧数据源的追番、缓存、观看记录全部失效。今后如果再遇到「更换数据源」这类大版本说明，照官方备注处理，别硬覆盖。
- **装了旧版（0.4.x 及更早）一直崩溃的**：进入播放页就闪退的问题在 v0.5.2 才修掉，直接升级，具体见[播放失败与常见问题排查](播放失败与常见问题排查.md)。
- App 内置了检查更新的入口（在「我的」页面），从 v0.2.0 起会自动检查更新、提示你跳转新版下载地址。想要「手动点一下检查更新」的按钮目前还没有，这是个开放中的功能请求；想确认最新版本号，直接看官方发布页最准。
- **对更新节奏的预期**：这是作者的业余开源项目，版本迭代偏慢（0.5.x 之后很长一段时间没有新版）。以发布页实际显示为准，不要因为「迟迟不更新」怀疑自己装了假包。

## 六、装不上时的通用排查

按出现概率从高到低：

1. **提示「未知来源」被拦截**：回系统设置把「安装未知应用」权限授给刚才用来打开 APK 的那个应用（文件管理器/浏览器），再重试。
2. **存储空间不足**：清理出至少 100MB 再装。
3. **之前装过半路损坏的包**：先卸载旧的 NekoAnime，重新下载 APK 再装；重新下载后建议核对一次第四节的 MD5，确认包没有下坏。
4. **以上都不行**：换一个渠道重新拿包（第二节两个渠道二选一即可），仍失败则到官方仓库的 Issues 页看是否有人报告同类问题。
