用过一次抽卡分析后，你的抽卡记录默认保存在小助手的云端，下次分析时新旧自动合并。本篇讲的全是围绕这份记录的实际操作：备份、搬家、纠错、删除。管理入口是官方提供的网页：[www.lelaer.com/uigf.php](https://www.lelaer.com/uigf.php)，功能较多，建议在电脑浏览器里操作。

## 一、云端记录是怎么滚存的

游戏接口只给最近 180 天的抽卡记录，但小助手会把你每次分析拿到的记录存在云端，并按抽卡 id 去重后合并 —— 所以只要隔一段时间（比如每个版本卡池结中介时）做一次抽卡分析，云端账本就能一直往下滚，不用担心记录被游戏「翻篇」。

有两个使用前提值得注意：

- 导入功能生效前，你需要先在小助手内**至少做过一次抽卡分析**，云端账户才算激活；
- 抽卡 id 是去重的关键，手工补录或导入的文件必须带正确的抽卡 id，否则会插进重复数据。

## 二、用 UIGF 格式与其他工具互导

UIGF 是原神抽卡记录的通用交换格式，社区里主流工具都认它（标准见 [uigf.org](https://uigf.org)）。在小助手的官方管理页上，围绕这个格式能做这些事：

| 操作 | 说明 |
| --- | --- |
| 导入 UIGF 记录 | 上传 `.json` 文件，把别的工具导出的记录并进云端账本 |
| 导入非小酋记录 | 仅支持非小酋导出的 `.xlsx` 文件 |
| 导入 Paimon.moe 记录 | 仅支持 Paimon.moe 导出的 `.xlsx` 文件 |
| 导出 UIGF 记录 | 把云端账本导出成 `.json`，留档或搬去别的工具 |
| 删除云端全部记录 | 清空云端账本，删了不可恢复 |
| 重置手动添加的记录 | 只清手工补录的那部分，正常分析的记录不受影响 |

截至本文整理时，官方页面列出的可互导来源包括：Genshin-Wish-Export、胡桃工具箱（hut.ao）、应急食品（gtool.mukapp.top）、Genshin-Gacha-Export、嘟嘟可故事集（DodocoTales）以及提瓦特小助手微信小程序。这份清单会随时间变化，以官方页面当时显示为准。

**搬家典型场景**：从 PC 桌面工具换到手机 App 用 —— 在旧工具里导出 UIGF json → 到管理页上传导入 → 手机上重新做一次抽卡分析，云端合并后数据就齐了。反向搬家就是导出再导入，一样走这条格式。

## 三、手动补录与纠错

官方管理页支持手动补充抽卡记录，但有边界，别指望它万能：

- 只支持修改最后 1 个金的抽数，或添加缺失的记录，已有的记录不能改；
- 补错了可以点页面上的重置按钮清空全部手动数据，之后在小助手内删除对应 UID 的本地记录，再做一次分析即可重新补录；
- 删除云端记录时注意：管理页删的是云端，App 内还留着一份本地记录，两边都删干净再重建才不会残留旧数据。

## 四、彻底删除云端记录

想把账本从云端清掉有两个途径：

1. 管理页的「删除云端全部记录」，一键清空、不可恢复；
2. 按官方 FAQ 的说法，也可以发邮件到 `zzpro@lelaer.com` 申请删除。

删除属于不可逆操作，动手前如果想先把记录留个底，先走一遍第二节里的「导出 UIGF 记录」，拿到 json 文件再删。

删完记录如果连这工具本身也不想用了，相关安全疑问（登录信息会不会残留、要不要注销什么账号）可以对照 [账号安全与常见问题.md](账号安全与常见问题.md) 确认一遍；这套记录体系的前提是先完成一次抽卡分析，流程回看 [抽卡分析使用教程.md](抽卡分析使用教程.md)。
