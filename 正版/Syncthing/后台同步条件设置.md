## 一、为什么需要专门设置

安卓系统会积极省电，把「看起来不活跃」的后台应用杀掉。Syncthing 的同步恰恰发生在后台，所以要做两件事：在应用内告诉它**什么条件下允许运行**，在系统里告诉安卓**别杀它**。两边都到位，锁屏之后才会继续同步。

## 二、应用内的运行条件（Run Conditions）

打开 App → 左上角菜单 →「设置」→「运行条件」。常见选项如下（不同版本叫法略有差异，以你手机上实际显示的为准）：

| 选项 | 建议 | 说明 |
| --- | --- | --- |
| 在 Wi-Fi 下运行 | 开 | 最常用的档位 |
| 按流量计费的 Wi-Fi 下运行 | 按需 | 连热点、随身 Wi-Fi 时是否同步 |
| 在移动数据下运行 | 默认关 | 开了会消耗流量，大文件夹慎开 |
| 漫游时运行 | 默认关 | 同上 |
| 飞行模式下运行 | 默认关 | 特殊场景才用 |
| 使用哪种电源时运行 | 选「交流电源」或「均可」 | 只想充电时同步就选交流电源 |

条件设得越保守，「看起来不动」的时候越多。如果状态一直显示「Syncthing 已停用」，先回到这里逐项核对：是不是没连 Wi-Fi、没在充电，或者勾了「尊重系统的省电设置」而系统正处于省电模式。

## 三、关掉系统对它的电池优化

以接近原生安卓的路径为例（国产系统的入口略有不同，一般都在「应用管理」→ 该应用 →「电池」里）：

1. 系统设置 → 应用 → Syncthing；
2. 电池 / 电池优化；
3. 改为「无限制 / 不优化 / 允许后台运行」。

不给这一项的话，很多机型在锁屏几分钟后就冻结它的后台进程，表现是「连着 Wi-Fi 也不同步，点亮屏幕它又动起来了」。

## 四、自启动与常驻通知

- 应用内设置里的「开机自启动」打开后，重启手机不用再手动开 App；
- 通知栏那条常驻通知是安卓对前台服务的保护机制，**建议保留**——部分系统在通知被禁用后会连前台服务一起限制；
- 国产系统的「省电策略 / 后台管控」里，把它设为允许自启、允许后台、允许关联启动。

## 五、排查顺序清单

不同步时按这个顺序查：

1. 主界面或通知里是否显示「已停用」→ 回到第二节核对运行条件；
2. 设备列表里对方是否在线 → 不在线是对方没开或网络不通，不是本机问题；
3. 文件夹状态是「正在同步」但速度为零 → 确认两边同时在线；电脑端看连接类型是否走了中继（见[常见问题解答](常见问题解答.md)）；
4. 锁屏就不动、亮屏就动 → 第三节的电池优化没关；
5. 重启 App 后恢复、过一阵又停 → 系统后台管控，检查第四节。

配对和文件夹还没弄好的，先看[设备配对与共享文件夹教程](设备配对与共享文件夹教程.md)，再回来调这里。
