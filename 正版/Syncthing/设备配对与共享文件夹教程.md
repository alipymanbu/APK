## 一、配对的逻辑：两边都要加对方

Syncthing 不用注册账号。每台装了它的设备首次启动时会生成一个唯一的设备 ID（七段大写字母数字，形如 `ABCDE12-FGHIJK3-…`），配对就是**两台设备各自把对方的 ID 加进自己的设备列表**，只加一边是连不上的。

安全性也建立在这个机制上：光知道你的设备 ID 并不能连上你的设备，对方设备上也必须手动添加你的 ID，连接才会建立。

## 二、在哪找到自己的设备 ID

- 手机端：打开 App → 左上角菜单 →「显示设备 ID」，会显示完整 ID 和二维码；
- 电脑端：打开管理页面（默认 `http://127.0.0.1:8384`）→ 右上角「操作」→「显示 ID」，同样带二维码。

另外手机端也有完整的 Web GUI（左上角菜单 →「Web GUI」，浏览器地址 `http://127.0.0.1:8384`），界面与电脑端一致。基础的配对用 App 界面就够了；更细的设置（设备连接地址、中继开关等）要从这里调，见[中继连接慢的解决方法](中继连接慢的解决方法.md)。

## 三、添加远程设备

1. 手机端在「设备」页点「+」，选「扫描二维码」对准电脑端屏幕扫，或把电脑端 ID 复制过来手动粘贴；
2. 设备名随意（只是本地显示用的名字），保存；
3. 到电脑端的 Web GUI，会弹出「新设备」提示，确认添加——这一步就是「另一边也要加你」；
4. 两边设备状态都变成在线（设备名旁出现绿色圆点）即配对成功。

顺序反过来（先在电脑端加手机）也一样，哪边先做都行，但两边必须都完成。

## 四、建立第一个同步文件夹

以「把手机相册同步到电脑」为例：

手机端（发送方）：

1. 「文件夹」页点「+」；
2. 标签随意（如「相机照片」），路径选到相机目录；
3. 在「共享给设备」里勾选刚配对的电脑；
4. 保存。

电脑端（接收方）：

1. Web GUI 会弹出「文件夹共享请求」，点「添加」；
2. 把路径改成本地想存放的位置（如 `D:\照片备份`）；接受时也可以把类型改选为「仅接收」，做成单向备份——典型搭配见[手机照片自动备份到电脑](手机照片自动备份到电脑.md)；
3. 保存后等初始同步完成：左下角进度走完、文件夹状态显示「最新」即成。

之后手机上新拍的照片就会在联网时自动出现在电脑的文件夹里。

**安卓 11 及以上的路径限制**：新版安卓收紧了应用对公共目录的写入能力，部分系统目录（如整个 DCIM 根目录）可能无法被选为同步文件夹。可以把要同步的内容放进 `Documents/`、`Download/` 这类允许的位置，或使用 App 提示的应用私有目录（能同步，但其他 App 不一定能直接访问里面的文件）。

## 五、三种文件夹类型怎么选

文件夹设置里可以指定类型，同一文件夹在不同设备上的类型可以不同：

| 类型 | 行为 | 典型用途 |
| --- | --- | --- |
| 发送和接收 | 双向同步，任何一方的改动都互传 | 两边都要增删改的资料夹 |
| 仅发送 | 本机只往外推，接收端的改动不回传 | 手机相册 → 电脑备份 |
| 仅接收 | 只收不发，本机的改动不外传 | 电脑往手机推电子书、安装包 |

「仅发送 / 仅接收」比双向更能防误操作：接收端误删了文件，下次同步它又会被推回来，不会真的丢。

## 六、文件夹里的三个隐藏项

每个同步文件夹里会出现几个以点开头的目录和文件，各有用途，**都不要手动删**：

| 名称 | 作用 |
| --- | --- |
| `.stfolder` | 标记「这个文件夹由 Syncthing 管理」；丢了会报 folder marker missing |
| `.stignore` | 排除清单（写法见[忽略文件与版本控制](忽略文件与版本控制.md)） |
| `.stversions` | 开了版本控制后，被替换/删除文件的归档处（同上） |

误删 `.stfolder` 怎么救，也写在[忽略文件与版本控制](忽略文件与版本控制.md)里。

## 七、同步什么时候发生

两台设备**同时在线**时才互传：都连同一个家庭 Wi-Fi 最稳；隔着互联网也能同步（设备间先互相找到对方，再建立加密连接），速度取决于两边的上行带宽。速度明显不理想时，先看是不是走了中继：[中继连接慢的解决方法](中继连接慢的解决方法.md)。App 在满足运行条件时才在后台工作，条件怎么设见[后台同步条件设置](后台同步条件设置.md)。
