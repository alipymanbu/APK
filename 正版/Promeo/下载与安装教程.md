## 一、安装前先核对这几项

Promeo 是 CyberLink（讯连科技）出品的营销内容制作应用，安卓包沿用了前身 AdDirector 的包名。你手里的这份安装包来自网盘分享，先确认它与下面这份采集记录一致，避免装到别的东西：

| 项目 | 值 |
| --- | --- |
| 应用名称 | Promeo |
| 版本 | 8.3.3 |
| 包名 | `com.cyberlink.addirector` |
| 安装包大小 | 182.17 MB |
| MD5 | `3488068F410D3FB379400774D83382A8` |
| 采集时间 | 2026-09-27 |

两点提醒：

- 系统要求：采集记录标注为安卓 5.2 及以上；不同商店页面标注口径可能不同，以你手机实际能否安装为准。
- 手机上如果已经装了 Google Play 渠道的 Promeo 或旧版 AdDirector，包名相同，属于覆盖升级；但若签名不一致，系统会直接拒绝安装，需要先卸载再装（详见[常见问题与解决方法.md](常见问题与解决方法.md)）。

## 二、把安装包下载到手机

安装包通过夸克网盘分享获取，完整入口是 **[Promeo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/03fed5d431d2)**。流程分两步：

1. **转存**：在手机或电脑上打开上面的链接，登录夸克账号，把分享内容转存到自己的网盘（不转存的话链接内容随时可能失效）。
2. **下载**：在夸克网盘 App 里找到转存后的文件夹，下载其中的 APK 文件到手机本地存储。安装包约 182 MB，建议确认手机剩余空间充足再开始。

下载完成后，可以顺手核对一下文件名里带的版本号（`Promeo_v8.3.3` 这个形态）与大小，和第一节表格对得上再往下装。

## 三、安装步骤

安卓系统默认不允许安装应用商店之外的安装包，所以中间会弹出一次授权：

1. 打开手机自带的「文件管理」，找到刚下载的 APK 文件，点它。
2. 第一次安装时系统会提示「不允许安装未知来源应用」，按提示允许你的文件管理器（或浏览器）安装应用。不同品牌的入口不同：小米在「设置 - 隐私保护 - 特殊权限」，华为在「设置 - 安全 - 更多安全设置」，原生安卓在弹窗里直接给授权。
3. 回到文件管理器再点一次 APK，等待安装完成。
4. 点「打开」启动 Promeo。首次启动一般会请求存储等权限，按需允许，否则导入照片视频素材时会受限。

## 四、装不上时按这个顺序排查

按命中率从高到低：

1. **提示「应用未安装」且手机上已有 Promeo/AdDirector**：多半是签名冲突，把已装的旧版卸载后再装。
2. **提示空间不足**：182 MB 只是安装包体积，安装过程还要解压出更多内容，清理出至少 1~2 GB 再试。
3. **下载中断导致包损坏**：重新下载一遍，再对照第一节的 MD5 与大小确认文件完整。
4. **点了 APK 没反应**：换个文件管理器打开，或把 APK 移到手机内部存储再试（部分机型对 SD 卡路径有限制）。
