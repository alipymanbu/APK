## 一、两个场景，别搞混

- **缓存下载**：把剧集存进手机，没网也能看——适合通勤、坐飞机。
- **投屏**：手机在线播，画面送到电视上显示——需要手机和电视连同一个 Wi-Fi，不省流量。

一个存本地，一个换屏幕，操作入口都在播放页附近。

## 二、缓存剧集到本地

1. 打开要看的剧，进到播放页（或详情页）。
2. 找到「下载」入口，点开选集列表。
3. 勾选要缓存的集数——连载剧建议只勾已更新的，完结剧可以全选。
4. 确认后开始下载，进度在下载/缓存列表里看。
5. 下载完成的剧集在有缓存入口的列表里会显示已下载标记，点开即离线播放。

注意：

- 缓存前先看一眼剩余存储空间，4K 片源单集体积不小，几十集存下来占几个 G 很正常。
- 只在 Wi-Fi 下操作，别用流量批量下——设置里如果有「仅 Wi-Fi 下载」开关，打开它。
- 缓存的文件属于应用私有数据，清应用缓存（不是清安装包）会把它们一起清掉，想保留就别乱清。

## 三、投屏到电视（同一 WiFi）

1. 手机和电视连**同一个 Wi-Fi**——这是投屏能搜到设备的前提，不同网段（比如一个 2.4G 一个 5G 隔了访客网络）会搜不到。
2. 在播放页点「TV」投屏按钮。
3. 等它搜出附近的投屏设备，点选你的电视。
4. 连上后手机画面就送到电视上了，手机可以锁屏或干别的，电视继续播（投屏模式下手机是遥控器，进度、音量还能在手机上调）。

搜不到设备的排查顺序：确认同一 Wi-Fi → 电视的投屏/DLNA 功能有没有打开 → 路由器有没有开「访客网络」或 AP 隔离（有就关）→ 都不行就用电视自带的投屏功能反向拉，或直接看 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 四、投屏时顺手把画质拉满

投屏就是为了大屏看高画质，进电视后记得把线路换成带「4K」「蓝光」标注的那条——具体怎么换见 [播放线路切换与画质设置.md](播放线路切换与画质设置.md)。同一条线路在手机上可能流畅、投到电视上却卡，因为电视解码压力和带宽占用都更大，降档或换线即可。

## 五、离线与在线的选择建议

| 场景 | 用哪个 |
| --- | --- |
| 通勤地铁 / 飞机上 | 提前缓存到本地 |
| 家里客厅大屏 | 在线播 + 投屏 |
| 流量充足但网一般的酒店 | 缓存更稳，比在线播少一层卡顿 |
| 追连载、每天只看一集 | 在线播即可，别囤缓存占空间 |

缓存管理（删除旧剧、看占用空间）在应用的下载/缓存列表里操作，定期清一清过期的，给新剧腾地方。
