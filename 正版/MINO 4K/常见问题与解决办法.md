## 一、播放卡顿、总在缓冲

按这个顺序试，通常第二步就能解决：

1. **换线路**：播放页中间的「播放源」切一条别的线路，等几秒看效果——这是最有效的一步（详见 [播放线路切换与画质设置.md](播放线路切换与画质设置.md)）。
2. **降清晰度**：4K 线路对带宽要求高，网络一般时切到高清档更流畅。
3. **验网络**：用别的视频 App 播一下，别的也卡就是你网络的问题，重启路由器；只有这个卡，回到第 1 步继续换线。
4. **低峰期**：晚高峰线路拥挤，同一条线换个时间段可能就不卡了。

## 二、点了播放黑屏 / 一直转圈不出画面

- 先确认是不是**只有这一部片**坏：换一部热播的试。单片坏 → 换线路通常能救。
- 所有片都黑屏 → 检查网络，然后清一次应用缓存（设置 → 应用 → MINO 4K → 清理缓存，**别点「清除数据」**，那会把观看记录一起清掉）。
- 清完还黑屏 → 卸载重装，安装包从 [MINO 4K 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d001b0c168ad) 重新拿（重装前确认缓存的离线剧可有可无，会被清掉）。

## 三、安装失败的几种提示

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 禁止安装未知来源应用 | 系统拦截第三方 APK | 按 [下载与安装教程.md](下载与安装教程.md) 第三节授权后重装 |
| 解析包时出错 / 安装包损坏 | 下载不完整或传输损坏 | 重新下载，对一下文件名里的版本号与 85.49M 的大小 |
| 签名冲突，无法安装 | 新旧两份包签名不一致 | 只能先卸载旧版再装新版（观看记录会丢） |
| 存储空间不足 | 手机没空间 | 先清理出至少 500M 再装 |

## 四、闪退、打不开、用着用着崩溃

1. **重启应用**：从后台彻底划掉再进。
2. **看版本**：确认装的是 `com.tool.electric.basic` 的 6.0.2（或更高）版本，来路不明的包可能被改坏。
3. **清缓存**：设置 → 应用 → MINO 4K → 清理缓存（同上，不清数据）。
4. **系统版本太旧**：应用对安卓 4.0 以上都兼容（第三方下载页标注），但特别老的系统跑高码率 4K 可能吃力，可试着降清晰度播放。
5. 以上都无效 → 卸载重装最新份。

## 五、搜索找不到想看的片

- 换关键词：用片名主体搜，去掉「第X季」等后缀；也可试演员、导演名。
- 看分类页与排行榜有没有：见 [找片与搜索技巧.md](找片与搜索技巧.md)。
- 确实没有 → 走首页「粉丝4K求片专区」提需求，等资源更新。

## 六、投屏搜不到电视

确认手机与电视在**同一个 Wi-Fi** → 电视端投屏/DLNA 开关打开 → 关掉路由器的「访客网络」「AP 隔离」→ 再点播放页的「TV」重搜。详细步骤见 [下载缓存与投屏电视.md](下载缓存与投屏电视.md)。

## 七、缓存的剧突然播不了 / 不见了

多半是被清理掉了：清应用缓存、手机管家的「深度清理」、或系统存储不足时自动回收，都会删私有目录里的离线文件。对策：重要剧集重新缓存一份，别依赖它长期保存；同时在手机管家里把该应用加入白名单。缓存策略与选集操作见 [下载缓存与投屏电视.md](下载缓存与投屏电视.md)。

## 八、每次打开都要重新搜 / 记录丢失

观看记录保存在本地，清「清除数据」会一并清空——注意只用「清理缓存」。另外覆盖安装（同包名升级）不丢记录，卸载重装才丢。想让记录跟着账号走（换手机也能接上进度），注册并登录即可，步骤与同步范围见 [账号注册与登录.md](账号注册与登录.md)。
