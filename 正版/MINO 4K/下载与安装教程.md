## 一、这是什么应用

MINO 4K（也写作 MINO4K、米诺4K、米诺影视）是一款安卓手机上的影视点播应用：首页按电影、连续剧、综艺、动漫、短剧等分类推荐片单，点开就能在线播放，也能把剧集缓存到本地离线看。界面是深色底、红色高亮的布局，底部四个标签：首页、短剧、排期表、我的。

它没有上架主流应用商店的正式渠道，安装包以网盘分享为主。本篇给的版本信息以手头这份安装包为准：

| 项目 | 值 |
| --- | --- |
| 版本 | 6.0.2 |
| 包名 | `com.tool.electric.basic` |
| 大小 | 85.49M |
| MD5 | `1D9F4B5D227A55D6440C1DD2C816CD65` |
| 系统要求 | 安卓 4.0 及以上（第三方下载页标注，以页面当时显示为准） |

网上能搜到的「官方最新版」常常是另一个版本号，装之前以包名和版本号对一下，别装混了。

## 二、从网盘获取安装包

1. 打开 [MINO 4K 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d001b0c168ad)，把分享转存到你自己的夸克网盘（需要装夸克 App 或用网页版登录）。
2. 转存后在网盘里找到该应用的文件夹，里面的 APK 文件名形如 `MINO 4K_v6.0.2.apk`。
3. 在手机上打开夸克网盘，找到这个 APK，点下载。文件约 85M，建议在 Wi-Fi 下载。
4. 如果你已经在电脑上转存好了，也可以把 APK 用数据线 / 微信文件传输助手 / 局域网共享拷到手机，再在手机上点开安装。

核对：文件名带的版本号应该是 `6.0.2`。对不上就以网盘里实际那份为准，或在「我的」里看应用内版本号。

## 三、安装步骤（安卓）

安卓默认不允许安装「未知来源」的应用，第一次装需要手动放行：

1. 在文件管理器或浏览器里点开这个 APK，系统会弹「禁止安装未知来源应用」之类的提示。
2. 按提示进入「安装未知应用」授权页，给发出安装请求的那个应用（文件管理器 / 浏览器 / 夸克）打开允许。
3. 返回后再次点 APK，确认安装界面显示的应用名是 MINO 4K，点「安装」。
4. 装完先别急着打开，回到授权页把刚才的开关关掉——只在装这个包的瞬间需要它。
5. 打开应用，首页加载出片单即算安装成功。

不同品牌手机的菜单名略有差异（MIUI 叫「安装未知应用」，ColorOS 叫「允许来自此来源的应用」），入口一般都在：设置 → 应用设置 → 授权管理 → 安装未知应用。

## 四、覆盖安装与升级

以后拿到新版本 APK 时，**直接在已装旧版的手机上点开新 APK 覆盖安装**即可，不用先卸载——只要包名一致（`com.tool.electric.basic`），观看记录和缓存都会保留。

如果覆盖安装时提示「签名不一致，安装失败」，说明两份包不是同一个签名体系（常见于不同渠道分发的包），只能先卸载旧版再装新的，此时观看记录会丢，缓存的离线视频也会被清掉，介意的话先想清楚再操作。详见 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 五、首次打开注意什么

- 第一次启动会申请存储等权限，用于缓存视频到本地；拒绝后离线下载功能会不可用，建议允许。
- 首页顶部是搜索框（可搜影片、演员、导演），下面一排是精选、电影、连续剧、综艺、动漫、短剧等内容标签。
- 想快速判断安装是否正常：随便点一部影片进播放页，能看到画面与进度条就说明一切正常；出不来画面先按 [播放线路切换与画质设置.md](播放线路切换与画质设置.md) 换线路，再不行看 [常见问题与解决办法.md](常见问题与解决办法.md)。
- 观看记录默认存在手机本地；想换手机也能接着看，装完顺手注册个账号，见 [账号注册与登录.md](账号注册与登录.md)。
