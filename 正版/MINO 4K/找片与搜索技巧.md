## 一、找片的四条路

MINO 4K 给了四种找片方式，按你的目标选：

| 你想要什么 | 走哪里 |
| --- | --- |
| 明确知道片名 / 演员 / 导演 | 顶部搜索框 |
| 按类型慢慢挑 | 首页「全部分类」进影视分类页 |
| 看现在大家在追什么 | 首页「排行」 |
| 追正在更新的剧、看哪天更新 | 首页「排期表」或底部「排期表」标签 |

## 二、搜索：片名、演员、导演都能搜

点首页顶部的搜索框，输入关键词即可，支持影片名、演员名、导演名。输入时会出联想结果，右侧还有「今日热搜」榜——按热度排的前十名（片名右侧带热度值，如「23.6万」），不知道看什么时可以直接点热搜进去。

小技巧：

- 搜剧名时去掉副标题，只搜主体（如「剑来」而不是「剑来 第二季」），结果更全。
- 演员名搜出来的往往是该演员的作品合集，比一部部找快。
- 有第三方页面提到搜索支持拼音首字母/全拼（如输入片名首字母也能命中），实际以搜索框联想结果为准。
- 搜不到的片先换个关键词；确实没有就用下面第五节的求片专区。

## 三、分类页：三层筛选缩小范围

首页点「全部分类」进入影视分类页，顶部先选大类（电影 / 连续剧 / 综艺 / 动漫 / 短剧），然后有三行筛选器：

1. **排序**：最新、最热、好评——追新选「最新」，怕踩雷选「最热」。
2. **地区**：中国大陆、美国、香港、韩国、英国等。
3. **类型 + 年份**：喜剧、动作、爱情、惊悚、犯罪、冒险……年份从 2026 往下排。

三行可以叠加，比如「连续剧 + 最热 + 中国大陆 + 2025」就是去年最火的国产剧。选完在结果里点封面直接进播放页。

## 四、排行榜与排期表

**排行榜**（首页「排行」）：按电影 / 连续剧 / 综艺 / 动漫 / 短剧分组，日榜、周榜、月榜三个维度，条目右侧是热度数值，说明写着「根据近期播放热度排名，实时更新」。选剧荒时从日榜前三开始挑一般不会错。

**排期表**（首页或底部「排期表」标签）：顶部横向切日期（昨天 / 今天 / 明天……），下面列出当天更新的剧集，每部右侧有个心形按钮——点一下收藏，更新时方便回头找。追连载剧最实用的入口就是它：今天看今天更新了什么，明天再来看明天的。

## 五、粉丝 4K 求片专区

首页中部有「粉丝4K求片专区」板块，专门放用户求片与高画质片单。你缺什么资源可以从这里提需求，也可以看看别人求到了什么——片单走这个渠道找起来比到处翻方便。

## 六、从找片到顺畅播放

找到片子只是第一步，点开后如果画面卡、不清晰，先别换应用——大概率是当前线路的问题，见 [播放线路切换与画质设置.md](播放线路切换与画质设置.md)；想离线存下来路上看，见 [下载缓存与投屏电视.md](下载缓存与投屏电视.md)。
