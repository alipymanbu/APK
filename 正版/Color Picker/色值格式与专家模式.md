## 一、主界面上的两个常用值

- **HEX**（形如 `#1A2B3C`）：网页与 UI 场景最通用，CSS 里可以直接粘贴，发给别人也不容易错；
- **RGB**：三个 0~255 的数值，在 PS、Figma 这类设计软件里新建颜色时用。

取色后可以手动复制色值；部分较新版本在设置里提供「取色后自动复制 HEX」的开关，打开后每取一次色自动进剪贴板，你的版本有没有这个开关以设置页实际显示为准。

## 二、专家模式里多出来什么

主界面点烧瓶图标进入专家模式，在常用值之外多出这些实时数据：

- 更多色值模型：CMY、CMYK、HSL、HSV、RYB、CIE LAB、CIE XYZ；
- **色温**（开尔文 K）：这个颜色偏冷偏暖的程度；
- **主波长**（纳米 nm）：颜色在可见光谱上的位置；
- **亮度**（luminance）；
- 与当前所选色卡里最接近颜色的**匹配度**（百分比）。

每一行数据都能点开看更细的内容；不需要的行可以在设置里关掉，画面上只留你用得到的。

## 三、每列色值各是干嘛用的

| 数值 | 适合的场景 |
| --- | --- |
| HEX / RGB | 网页、UI、发给设计师 |
| HSL / HSV | 调色直观：想「同色更亮一点、更灰一点」时按这两个调 |
| CMY / CMYK | 印刷参考。屏幕换算出的 CMYK 与实际印刷有偏差，只能当参考值 |
| CIE LAB / XYZ | 与设备无关的色值，用来描述和比较色差（见 [取色不准怎么办.md](取色不准怎么办.md)） |
| RYB | 美术里的红黄蓝三原色体系，画画配色时用得上 |
| 色温 / 主波长 | 光源偏色、光谱位置这类参考信息 |

同一颜色在 HSL 和 HSV 下的数值会差得很远——两个模型的算法不同，HSL 的「亮度 50%」与 HSV 的「明度 100%」都对应纯色。在两个工具之间对数值时先确认对方用的是哪个模型，别把两组数值当成两个颜色。

## 四、匹配度怎么理解

专家模式会把当前颜色与你选中的色卡做比对，给出库里最接近色的匹配度：百分比越高，说明这个颜色越「像」卡里的某个标准色。选哪张卡、拿它对 RAL 色号的流程，见 [色卡库与RAL对照.md](色卡库与RAL对照.md)。
