# Color Picker 图片颜色转 HEX 色值方法

## 一、什么时候走这条路

- 设计稿、海报截图里的某个颜色想要数值；
- 素材图、照片里挑一个主色出来用；
- 别人发来的配色参考图，想落成可复制的色值。

拿相机对着屏幕测是常见错误做法——屏摄会引入摩尔纹与白平衡偏差，直接打开图片文件取色才是稳的。

## 二、四步流程

1. 把图片存到手机相册（截图本来就存在相册里；聊天工具里收到的图先保存原图）；
2. 在 Color Picker 里打开这张图，或在相册里选中图片点「分享」发给它；
3. 双指放大，把要的位置对准后点一下，读出 HEX 值；
4. 复制色值去用；需要 RGB、CMYK 等其他格式，切专家模式（见 [色值格式与专家模式.md](色值格式与专家模式.md)）。

应用内的入口与手势细节见 [相机取色与图片取色方法.md](相机取色与图片取色方法.md)。

## 三、HEX 拿到手怎么用

- **网页 / CSS**：直接粘进样式里，大小写都行：

```css
color: #1A2B3C;
background-color: #1a2b3c;
```

- **Figma / PS / 即时设计**：新建颜色时把 HEX 粘进色值输入框，会自动换算成对应数值；
- **文档与协作**：直接写 `#RRGGBB` 给同事，比发截图可靠。

## 四、色值可能已经变了的两种情况

- 图片被压缩或转发过：聊天工具传图常会重新压缩，颜色有小幅偏移，对色要求高就找原图或原文件；
- 屏幕渲染差异：同一张图在不同手机上读出的值可能不同（原因与排查见 [取色不准怎么办.md](取色不准怎么办.md)）。你要交付的是色值数字本身，下游按数字走，不受你的屏幕影响；受影响的只是「在你屏幕上看起来对不对」。
