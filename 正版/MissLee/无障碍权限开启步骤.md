## 一、为什么必须开无障碍

你打开一个带开屏广告的应用时，广告页右下角或右上角会出现「跳过」按钮；无障碍服务让 MissLee 看到屏幕上出现了什么按钮，并代替你把那一下点掉。它只做这一件事：识别按钮、模拟点击，全程不需要联网。权限关掉，这一切就停了。

也正因为这个权限能读屏、能代点，它属于 Android 里等级最高的授权之一，给谁开、什么时候关有讲究——专门的风险判断与处理路径写在[无障碍权限的安全须知.md](无障碍权限的安全须知.md)，先把本篇的操作做完再看它也不迟。

## 二、通用开启步骤

1. 打开 MissLee，主界面有一个总开关，点它会提示前往系统无障碍设置（也可以手动走：系统「设置」里搜索「无障碍」）。
2. 在无障碍设置的「已下载的应用 / 已安装的服务」里找到 MissLee。
3. 点进去打开开关，系统会列出该服务能做什么，确认后返回。
4. 回到 MissLee 主界面，确认总开关处于开启状态。

部分系统会在通知栏挂一个常驻图标（类似「MissLee 正在运行」），这是无障碍服务的正常表现，不用去关它。

## 三、让它在后台常驻（各品牌差异）

只开无障碍还不够——国产系统的省电策略常在几小时或一次重启后把服务杀掉。按品牌对号入座：

| 品牌 / 系统 | 操作路径 |
| --- | --- |
| 华为 / EMUI / 鸿蒙 | 设置 → 应用和服务 → 应用启动管理 → 找到 MissLee → 关闭「自动管理」，把自动启动、关联启动、后台运行三个开关全部打开 |
| 小米 / MIUI | 设置 → 省电与电池（或应用设置 → 应用管理 → MissLee）→ 省电策略改为「无限制」；再把手机管家里对 MissLee 的自动优化关掉 |
| OPPO / vivo / ColorOS 等 | 在电池（或应用耗电管理）里允许 MissLee「后台高耗电 / 后台运行」，并把自启动开关打开 |
| 通用做法 | 在最近任务卡片上把 MissLee 下拉（或长按）加锁，防止一键清理时被误杀 |

做完这些后重启一次手机，再确认无障碍开关仍是开的，就说明保活生效了。

开关自动关闭不是 MissLee 坏了。华为官方知识库对这一行为的解释是：清理后台或重启设备后应用被清理，服务无法启动，系统就把开关显示为关闭——重新打开开关即可恢复。所以华为机型除了启动管理三开关，还可以在设置里搜索「电池优化」，把列表切到「所有应用」，找到 MissLee 设为「不允许」优化；再加锁的做法（多任务卡片下拉）同样来自官方建议。

## 四、开完怎么验证

随便打开一个带开屏广告的应用（视频、资讯类基本都有）：广告出现后不用你动手，一两秒内被自动点掉并进入主界面，即生效。

验证不通过时按顺序排查：先回系统无障碍设置看开关是否还在开的状态；再按第三节检查保活；若开关正常、个别应用就是跳不掉，多半是该应用不在内置规则里，去[规则导入与自定义.md](规则导入与自定义.md)补规则；仍然异常的看[常见问题与失效处理.md](常见问题与失效处理.md)。
