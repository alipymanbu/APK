# NoActive 白名单与冻结规则设置

> NoActive 的冻结是默认行为，「谁不被冻结、什么时候不冻结」由两层规则决定：模块自动识别的豁免状态，加上每个应用的手动开关。本篇把两层都讲清，并给出按应用类型的搭配建议。

## 一、应用列表怎么读

- 应用列表显示已安装应用与各自的配置状态：白名单应用带绿色盾牌标识；只配了一项的直接显示配置名，多项配置会标注「更多配置」。
- 列表里看不到的应用按系统应用处理——系统应用有全局白名单，默认不冻结。
- 所以「我在列表里找不到 XX 应用」通常不是 bug，它多半被当成系统应用跳过了。

## 二、模块自动豁免的情况（不用你设置）

下面这些状态下应用不会被冻结，都是模块自动识别的：

| 状态 | 行为 |
| --- | --- |
| 有可见窗口 | 免冻结 |
| 通话中 / 播放铃声 | 免冻结 |
| 正在定位 / 正在录音 / 正在使用相机 | 免冻结 |
| 已连接 VPN / 正在备份 / 开启了无障碍 | 免冻结 |
| 带系统签名的应用、Magisk、输入法、Xposed 模块 | 默认白名单 |

官方功能说明里还有两条识别细节：

- 应用同时挂着媒体播放和音频播放时，按「正在播放音乐」处理，免冻结。
- 对照这张表能解释大部分「这个应用怎么一直不被冻结」——先看它是不是处在上述状态，再考虑改设置。

## 三、每个应用的手动开关

### 1. 白名单

开启后该应用完全不受冻结限制，推荐给消息必须实时送达的应用（微信这类）。官方仓库有一条要注意的说明：白名单推送进程时，需要把主进程一起加白，否则仍可能被后台限制。

### 2. 后台播放

播放期间不冻结，暂停后约 10 秒冻结。判定口径是「有声即为播放」，不只是音乐播放——有的应用切到后台并不会主动停止发声，这种应用开了这个开关就永远不会被冻结。适合音乐、播客类；给会后台发声但不该发声的应用开它，等于变相白名单。

### 3. 常驻通知

通知常驻期间不冻结，通知被移除后约 3 秒冻结。百度网盘这类会一直挂着常驻通知的应用，开了这个开关效果等同于白名单，要自己权衡。

### 4. 禁用意图

管的是挂起意图一类：状态栏操作、桌面小组件，官方说明里还包括发送广播、启动前台服务、启动 Activity。V3.2 起对 Android 13+ 已内置意图限制，这个开关主要留给 Android 12 的设备。

### 5. 网速识别

后台传输不冻结的判据：上传达到 100KB/s 或下载达到 300KB/s；回落到上传 10KB/s、下载 30KB/s 以下后约 3 秒冻结。下载大文件、同步相册这类场景开着它，防止传输被打断。

## 四、后台优化（原「重要程度」）

给后台应用定优先级，内存不足时系统按 oom_adj 从大到小的顺序杀。三档区间如下：

| 档位 | 主进程 oom_adj | 子进程 oom_adj |
| --- | --- | --- |
| 高 | 600–649 | 650–699 |
| 中 | 700–749 | 750–799 |
| 低 | 800–899 | 900–999 |

按官方说明的同类场景举例：先后台了 C（低）、B（低）、A（高）三个应用，A 的后台顺序最靠前、拿到的 oom_adj 最小，内存吃紧时最后才轮到它被杀。想保哪些应用，就把它们设高一档。

## 五、按应用类型怎么搭

| 应用类型 | 建议 |
| --- | --- |
| 微信 / QQ 等 IM | 白名单（推送进程要连主进程一起加白） |
| 音乐 / 播客 | 后台播放 |
| 下载 / 同步类 | 网速识别 |
| 挂常驻通知的网盘类 | 别开常驻通知开关；要么接受它被冻结，要么加白名单，二选一 |
| 闹钟等小工具 | 先用默认；真出现响铃不准再加白名单 |

## 六、极致模式与游戏场景

- 极致模式是 3.0 起加入的开关（社区教程口径），作用是防止你打游戏时被后台应用解冻打扰；它和设置页齿轮里的开关是同一个，可以添加成状态栏磁贴随手切换。
- 打游戏前的搭配：开极致模式防解冻；开黑语音、直播的场景不用额外操作——正在录音、通话中的应用本来就免冻结。
- 社区有人分享过用命令行小工具把极致模式做成自动化、配合 Scene 之类的工具实现「打开游戏自动处理后台」（单一用户分享，工具未经广泛验证，想折腾再试）。

## 七、进阶配置文件（社区文档口径，以官方文档为准）

社区维护的进阶文档（自我标注可能过时）提到这些进阶玩法，改动前先备份：

- 模块的配置目录是 `/data/system/NoActive_8位随机字符/`，其中 `config/MemConfig.json` 可以调内存保留值：`freeRAM`（物理内存保留）、`freeSWAP`（交换分区保留，ZRAM 和 Swapfile 都算 SWAP）；`0` 为自动，负整数关闭，正整数按 MB 指定。
- JSON 写错语法时，模块会自动清掉错误配置并还原默认，所以改坏了也不用慌，改回合法 JSON 即可。
