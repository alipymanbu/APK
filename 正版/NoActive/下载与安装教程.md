## 一、装之前先确认：它是什么、需要什么环境

NoActive 是一个 Xposed 模块，做的事情是把你切到后台的应用「冻结」起来：应用留在内存里，但不再占用 CPU，也就是常说的「墓碑机制」。按官方站点的说法，应用切到后台约 3 秒后被冻结，回到前台时快速解冻。它不是装完就能用的普通应用，动手之前先确认这三样都在：

| 条件 | 说明 |
| --- | --- |
| 已 root 的安卓机 | 社区教程口径：Magisk / KernelSU / APatch 任一均可 |
| LSPosed | 模块靠 LSPosed 激活，Zygisk 版是常见搭配 |
| 安卓 12 及以上 | 官方站点标注支持 Android 12–17，以官方页面为准 |

没 root、没装 LSPosed 的手机，装上安装包也不会有任何效果——这是排查「为什么没用」时最先要排除的情况。

还有一点提前说清：NoActive 的工作不依赖开发者选项里的任何设置，不需要为它去改那些开关（社区文档口径）。

想核对官方最新说明，可以看开发者主页 [www.myflv.cn](https://www.myflv.cn/)、官方站点 [app.myflv.cn](https://app.myflv.cn/) 与 [LSPosed 模块仓库页](https://modules.lsposed.org/module/cn.myflv.noactive/)。

## 三、下载安装包

1. 转存 [NoActive 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5eb1e3f6b70f)到自己网盘，再把 `NoActive_v3.3-Pro.apk` 下载到电脑或手机。
2. 建议先校验 MD5，确认文件完整（以 Windows 为例，在 apk 所在目录打开终端执行）：

```text
certutil -hashfile NoActive_v3.3-Pro.apk MD5
```

输出的哈希与上表 MD5 一致再继续安装；不一致说明下载不完整，重新下载一次。

## 四、安装并启用模块

1. 安装 apk。装完先别急着打开——现在它还没有生效。
2. 打开 LSPosed，进入「模块」页，找到 NoActive 并启用。
3. 勾选作用域：
   - **系统框架**：核心功能，必须勾；
   - **系统界面**：部分版本提供，勾上后多一个从磁贴解冻的入口，建议一起勾。
4. 社区经验：如果之后遇到模块工作异常，可以回到 LSPosed 把「文件作用域」也勾上再重启一次。
5. 重启手机。作用域不重启不生效。

## 五、验证是否生效

1. 打开 NoActive，进入「用户应用」，切到「运行列表」。
2. 随便开一个应用再退回桌面，回来看运行列表：显示「已冻结」就是生效了。
3. 列表里没有任何「已冻结」→ 到右上角设置里换冻结方式，怎么选见 [冻结方式怎么选.md](冻结方式怎么选.md)。
4. 换了方式还是不行 → 按 [常见问题与故障排查.md](常见问题与故障排查.md) 的顺序排查。

## 六、从旧版本升级过来要注意

- 从 2.9 及更早版本升到 3.x：社区教程提醒先删掉旧配置目录 `/data/system/Noactive` 再装新版，否则重启后可能出现异常。
- NoActive 3.x 有正式版 / Pro / Alpha 几条分支的说法来自社区教程（Pro 为内测稳定版），以官方发布页为准；网盘里这份是 3.3-Pro。
