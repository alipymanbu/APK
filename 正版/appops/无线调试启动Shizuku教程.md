# 无线调试启动 Shizuku 教程（免电脑）

> App Ops 免 root 使用的第一步是启动 Shizuku。安卓 11 及以上可以用"无线调试"在手机上直接完成，不用连电脑；本篇给完整步骤与常见报错处理。

## 一、什么情况下走这条路

- 手机没有 root、手边没有电脑、系统是安卓 11 及以上 —— 这是启动 Shizuku 最省事的方式。
- 安卓 10 及以下的免 root 设备用不了无线调试，只能连电脑走 adb（步骤见第三节）。
- 配对只需要做一次；之后每次重启手机都要重新"启动"一次 Shizuku（系统限制），但不用重新配对。

## 二、无线调试启动（安卓 11 及以上）

以下步骤来自 Shizuku 官方手册（[https://shizuku.rikka.app/](https://shizuku.rikka.app/)）：

1. 打开开发者选项：设置 - 关于手机，连续点击"版本号"数次，直到提示已进入开发者模式（不同机型入口可能不同，可按机型搜一下）。
2. 在开发者选项里打开"USB 调试"，再进入"无线调试"并启用。
3. 打开 Shizuku，点"配对"开始配对。
4. 在系统的"无线调试"页面点"使用配对码配对设备"，屏幕上会显示一组配对码。
5. 把配对码填进 Shizuku 的通知里（弹不出通知就先允许 Shizuku 的全部通知）。
6. 配对成功后回到 Shizuku 首页点"启动"，看到"Shizuku 正在运行"即完成。
7. 回 App Ops 选 Shizuku 模式并授权，完整流程见 [工作模式选择与初始化.md](工作模式选择与初始化.md)。

## 三、连电脑启动（安卓 10 及以下，或有电脑时）

官方手册的流程：

1. 电脑下载 Google 提供的"SDK 平台工具"并解压（官方手册里有 Windows / Linux / Mac 三个平台的下载地址）。
2. 手机开启"USB 调试"后连电脑，在解压目录打开终端执行 `adb devices`，手机上弹出的"是否允许调试"勾选"总是允许"。
3. 执行启动命令（适用于 Shizuku v11.2.0 及以上）：

```powershell
adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
```

在 PowerShell 或 Mac / Linux 终端里，要把 `adb` 换成 `./adb`。

## 四、报错对照表

| 现象 | 处理（依据 Shizuku 官方手册） |
| --- | --- |
| 一直显示"正在搜索配对服务" | 允许 Shizuku 在后台运行 —— 搜索配对服务需要访问本地网络，不少厂商会在应用切到后台后立刻掐断它的网络 |
| 点"输入配对码"后立刻失败 | MIUI / POCO：系统设置的"通知管理 - 通知显示设置"里，把通知样式切换为"原生样式" |
| 提示 adb 权限受限 | MIUI / POCO：开发者选项里开启"USB 调试（安全设置）"，注意它和"USB 调试"是两个独立开关；ColorOS（OPPO、一加）：开发者选项里关闭"权限监控"；Flyme（魅族）：关闭"Flyme 支付保护" |
| Shizuku 随机停止 | 允许 Shizuku 后台运行；不要关"USB 调试"与开发者选项；开发者选项里把 USB 使用模式改为"仅充电"（安卓 8 是"选择 USB 配置"，安卓 9 及以上是"默认 USB 配置 - 不进行数据传输"）；安卓 11 及以上开启"停用 adb 授权超时功能" |
| 华为 EMUI 随机停止 | 开发者选项里开启"'仅充电'模式下允许 ADB 调试选项" |
| 小米用"手机管家"扫描后失效 | 不要用手机管家的扫描功能，它会禁用开发者选项 |
| Sony 插 USB 后失效 | 不要点插线后弹出的对话框，它会把 USB 使用模式改掉 |

无线调试怎么都启动不了时，还有一个通用招：把"无线调试"开关关掉再打开，回 Shizuku 重试一次。

## 五、启动之后

- 每次**重启手机**后 Shizuku 服务都会消失，重新点一次"启动"即可（配对不用重来）。App Ops 里已经改好的设置照常生效，只是那段时间不能继续管理。
- 想让 Shizuku 少被系统杀掉：按上表"随机停止"那一行，把后台与 USB 相关选项设置好。
- 启动成功但 App Ops 还是连不上、列表加载失败时，去 [常见问题与解决方法.md](常见问题与解决方法.md) 查应用侧的排查；装 App Ops 本身的问题回 [下载与安装教程.md](下载与安装教程.md)。
