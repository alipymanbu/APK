## 一、先认准你要装的是哪个

App Ops 是安卓手机上的权限管理工具，开发者署名 Xingchen & Rikka，官方站点为 [appops.rikka.app](https://appops.rikka.app/)。它管理的是系统里一套叫 "appops" 的隐藏设置，能干什么见 [权限控制功能详解.md](权限控制功能详解.md)。对老设备的兼容不错（安卓 5.x 时代即可运行），确切的最低系统版本以官方页面为准。

安装前可以核对这几项信息，避免装到同名仿冒应用：

| 项目 | 本套文档对应的安装文件 |
| --- | --- |
| 包名 | `rikka.appops` |
| 版本 | 9.0.7 |
| 大小 | 约 9.86 MB |
| MD5 | `DCC84651E5DC1D4E0C566F75CBBF6AC3` |
| 记录时间 | 2026-09-23 |

官方会持续发新版本，你后续拿到的版本号可能高于上表。版本不同不影响基本用法，个别界面入口可能略有变化，以应用内实际显示为准。

## 二、获取渠道

官方渠道有三个：Google Play、酷安、GitHub Releases，官方下载页 [https://appops.rikka.app/zh-hans/download.html](https://appops.rikka.app/zh-hans/download.html) 汇总了这三个入口。

| 渠道 | 说明 |
| --- | --- |
| 夸克网盘（本套文档配套） | 就是上表那份 9.0.7 安装文件，转存后直接下载安装 |
| Google Play | 商店里显示为 App Ops - Permission Manager，需要能访问 Play 商店 |
| 酷安 | 搜包名 `rikka.appops` 认准 |
| GitHub Releases | 仓库 `RikkaApps/App-Ops-issue-tracker` 的 Releases 页，能看历次发布 |

只想拿一份现成能装的安装包，从 App Ops 安装文件资源（夸克网盘）取即可：[https://pan.quark.cn/s/dbfa136854e4](https://pan.quark.cn/s/dbfa136854e4)，先转存到自己网盘，再下载到手机。

不同渠道的获取方式与价格可能不同，以官方下载页当时显示的为准。

## 三、安装步骤

1. 从上一节任选一个渠道拿到 APK（走网盘的话，先转存再下载到手机存储）。
2. 点开 APK 安装。系统首次会提示"未知来源应用"，允许当前来源安装即可。
3. 装完打开。首次启动通常直接引导你选工作模式 —— 这一步跳不过去：不接上权限，应用列表里的开关改不了任何东西。
4. 不知道选哪个模式，看 [工作模式选择与初始化.md](工作模式选择与初始化.md)。

## 四、升级旧版本

- 手机上已装旧版时，用同包名（`rikka.appops`）的 APK 覆盖安装即可。你已经改好的那些设置保存在系统里、不在应用数据里，覆盖安装不会动它们。
- 从 5.x 之前的旧版升级后，行为会与旧版不同（新版跟随系统行为），典型现象是"点允许没反应"，原因与处理见 [常见问题与解决方法.md](常见问题与解决方法.md)。
- 升级后打不开或异常时，先看新版本的发布说明确认系统要求有没有变化，再考虑重装。
- 想知道每个版本改了什么、修了哪些机型的问题，官方变更日志在这里：[https://appops.rikka.app/zh-hans/changelog/](https://appops.rikka.app/zh-hans/changelog/)。
