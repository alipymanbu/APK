# DKChat 收不到消息提醒怎么办

> 分清「消息没到」还是「没弹提醒」，按系统通知、后台、联网三块逐项排查。

## 一、先分清两种情况

打开 DKChat 后：

- **能看到新消息，只是手机没响、没弹窗** → 是「提醒」问题，往下走第二到第五节；
- **打开也没有新消息** → 是「没收到」问题，优先查第六节的网络与后台。

两种情况的病根不同，别混在一起排查。

## 二、系统通知权限（最常见原因）

手机设置里给 DKChat 开通知，主流品牌的路径（以你手机实际菜单名为准）：

| 品牌 | 路径 |
| --- | --- |
| 华为/荣耀 | 设置 → 应用和服务 → 应用管理 → DKChat → 通知管理 → 允许通知 |
| vivo | 设置 → 通知与状态栏 → 应用通知管理 → DKChat → 允许通知 |
| 小米/OPPO 等 | 设置 → 通知与控制中心（或「应用管理」）→ 找到 DKChat → 允许通知 |

进去后把 **允许通知** 总开关打开，并确认横幅、锁屏、铃声这几项没被单独关掉；如果列表里有「静默通知」一类的分组，把它关掉或改成有声音的提醒。Android 13 以后首次启动还会弹一次「是否允许发送通知」，当初点了「不允许」就会是现在这个症状 —— 只能在系统设置里改回来。

## 三、别让系统把后台杀掉

消息要靠常驻后台才能推过来。按品牌把这几项打开（华为/荣耀的路径最全，其他品牌同名开关照找）：

1. **自启动**：设置 → 应用 → 启动管理 → DKChat → 关掉「自动管理」，手动打开「允许自启动、允许关联启动、允许后台活动」；
2. **省电不限制**：设置 → 电池 → 电池优化（或「更多电池设置」）→ 找到 DKChat → 选「不允许」/「不优化」；
3. **多任务加锁**：在最近任务列表里长按 DKChat 卡片点锁定（小锁图标），避免一键清理把它清掉。

做完后重启一次手机再观察 —— 华为官方支持页明确说，重启后应用未启动时收不到消息属正常现象，**重启后先手动打开一次 DKChat**。

## 四、联网权限与省流量模式

- 设置 → 流量管理 → 应用联网（或「联网控制」）→ DKChat → **移动数据和 WLAN 都勾上**，只勾一个就会出现「Wi-Fi 下正常、出门就没消息」；
- 关掉「智能省流量 / 省流量模式」—— 华为支持页指出该模式会导致收不到消息；
- 勿扰模式、游戏模式开启期间通知会静音，检查系统勿扰是否误开。

## 五、应用内开关也过一遍

进 DKChat 的「我的 → 设置」找消息提醒相关开关，确认没被关掉；有第三方页面提到官方后续版本修复过「iOS 后台收不到推送」的偶发问题、并持续优化弱网推送 —— **版本过旧时先升级再测**，你网盘那份是 1.2.9（见 [常见问题与解决方法.md](常见问题与解决方法.md) 第五节的版本对照），商店有新版就优先更新。

## 六、打开应用也没有消息：查网络

1. 换一个网络（Wi-Fi 切流量）重发一条测试；
2. 看其他应用能不能联网 —— 全都不通就是手机网络本身的问题；
3. 前台挂着时消息秒到、锁屏一段时间后才补发，通常是第三节的后台被杀，回去补设置；
4. 以上都正常还是收不到，等几分钟再试（服务器偶发延迟），并在应用内反馈入口报告。

按二 → 三 → 四 → 五的顺序走完，绝大多数「收不到提醒」到第二、三节就解决了。其他高频问题见 [常见问题与解决方法.md](常见问题与解决方法.md)。
