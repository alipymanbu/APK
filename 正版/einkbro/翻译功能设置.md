# EinkBro 翻译功能设置

> EinkBro 的翻译有四种做法：整页翻、逐段翻、原地翻、图片翻，各有适用的页面类型。本篇讲每种怎么触发、AI 渠道要配什么，以及版本差异。

## 一、四种翻译方式总览

| 方式 | 效果 | 触发位置 |
|---|---|---|
| 整页翻译 | 整页内容经 Google 翻译替换显示 | 菜单 → Translate，或工具栏 Translation 按钮 |
| 逐段翻译 | 每段原文旁边出现译文 | 工具栏 Translate by Paragraph |
| 原地翻译 | 译文直接替换原文 | 长按 Translate 按钮后选原地模式 |
| 图片翻译 | 翻译图片里的文字，结果覆盖在图上 | 长按 Translate 图标，选图片翻译 |

整页翻译不依赖任何密钥，开箱能用；逐段和原地翻译想用 AI 渠道才需要配置，见[AI功能与密钥配置.md](AI功能与密钥配置.md)。

## 二、逐段翻译（外文长文主力）

逐段翻译是读外文文章最顺的方式：译文与原文并排，随时对照。

1. 打开文章，点工具栏 **Translate by Paragraph**（或长按 Translate 按钮选逐段模式）；
2. 屏幕里的段落会逐个出现译文，还没滚到的地方不翻译，省流量；
3. 再点一次按钮或关闭开关即可恢复原文。

- 用 AI（OpenAI / Gemini）做逐段翻译从 14.4.0 版起支持，网盘的 14.6.0 已包含；
- 翻译结果缓存的增强（重访页面秒出译文）是后续版本的改进；
- 某些页面逐段翻译排版会乱：优先试试先开阅读模式再翻，正文干净了翻译也稳。

## 三、原地翻译

长按 Translate 按钮选原地模式，译文直接顶替原文显示。14.6.0 里原地翻译走 Google 渠道；用 OpenAI/Gemini 做原地翻译是 15.11 之后版本加入的能力（以官方更新日志为准）。

## 四、图片翻译

适合翻图表、漫画、截图里的文字：

1. 先在 **设置 → Misc → Translate Image API Key** 填入图片翻译服务的密钥，没密钥这个功能不可用；
2. 长按 Translate 图标选图片翻译，单张图即可翻；
3. 页面里图片多时，**长按翻译图标可批量翻译剩余图片**。

## 五、YouTube 双字幕

在 **设置 → Misc → Dual Captions for YouTube** 里选第二字幕的语言，之后在浏览器里播 YouTube 视频时可以同时显示两行字幕（比如英文原文 + 中文对照）。

## 六、语言偏好

- **设置 → Misc → Translation Languages**：自定义 Google 翻译的目标语言列表，按需填（如 `zh-TW, zh-CN`）；
- 逐段翻译用什么引擎、什么语言，在翻译配置对话框里选（长按 Translate 按钮可看到各模式）。

## 七、版本差异提示

网盘这份是 14.6.0。对照官方更新日志，翻译方面后续版本的主要变化：原地翻译支持 AI 渠道（15.11+）、逐段翻译缓存与排版修复（15.x）、按网站记忆翻译模式（15.12+）、移除已停服的 Papago/Naver 渠道（16.7）。14.6.0 的四种翻译方式与本文描述一致，细节行为以你手上的版本为准。
