# EinkBro 翻页触控与手势设置

> EinkBro 是围绕墨水屏翻页体验设计的：点屏幕边缘、按音量键都能翻页，动作还能逐个改。本篇把这些开关和入口一次讲清。

## 一、三种翻页方式总览

| 方式 | 怎么开 | 适合场景 |
|---|---|---|
| 触屏翻页（点屏幕边缘） | 工具栏「Touch Turn Page」按钮 | 单手捧着看长文，点一下翻一页 |
| 音量键翻页 | 菜单里的 Quick toggle 打开 Volume keys | 设备带实体按键，墨水屏阅读器的常见姿势 |
| 工具栏翻页按钮 | 把 Page Up / Page Down 加进工具栏 | 想要明确的按钮位置，或外接鼠标 |

三者在普通网页和阅读模式下都生效；阅读模式下的翻页详见[阅读模式与排版调整.md](阅读模式与排版调整.md)。

## 二、触屏翻页：开启与区域布局

1. 点工具栏上的 **Touch Turn Page** 按钮，开启后屏幕左右（或上下）边缘变成翻页热区。
2. **长按**这个按钮弹出触控配置对话框，可选「左右分区」或「上下分区」两种布局——横屏阅读用左右，竖屏看网页用上下，按你的握持方向选。
3. 开着触屏翻页时，**长按音量键会临时停用翻页 5 秒**，用来应付「只想调音量」的时刻；
4. 不想用了再点一下 Touch Turn Page 即可关闭。

注意：音量键在部分墨水屏设备（如文石 Boox）上由设备侧的「应用优化」分配权限，浏览器里开了还不生效时要到设备侧检查，详见[墨水屏设备适配与调优.md](墨水屏设备适配与调优.md)。

热区的默认动作：点上半（左半）回到上一页，点下半（右半）翻到下一页，长按则分别跳到页首、页尾，全部可以改，见下一节。

## 三、翻页重叠：Page Reserved Height

翻到下一页时，页面顶部会保留一小段上一页的末尾，避免接不上上文。这个重叠量在 **设置 → UI → Page Reserved Height** 里调：

- 默认值 `80`（像素）；
- 也支持按百分比填；
- 觉得「每页开头看不懂」就调大，觉得「翻页太慢」就调小或填 0。

## 四、触摸区动作自定义

每个热区的单击和长按都能换成别的动作，入口在 **设置 → Gestures（手势）→ Touch Area Click Actions**：

| 位置 | 默认单击 | 默认长按 |
|---|---|---|
| 上区 | Page Up（上一页） | Scroll to Top（回到顶部） |
| 下区 | Page Down（下一页） | Scroll to Bottom（到底部） |

可选项不止翻页——阅读模式、翻译、分享等整个工具栏动作目录都能绑上来。也就是说你可以把「点左上角」定义成「打开阅读模式」这类组合。

## 五、双指滑动与浮动按钮

- **双指滑动**：设置 → Gestures → Two Finger Swipe Gestures，默认关闭。开启后上下左右四个方向各能绑一个动作，适合把高频操作（如关闭标签）放在键盘够不着的地方。
- **浮动按钮**：设置 → UI → Floating Button Position，可选右侧 / 左侧 / 居中 / 不显示 / 自定义位置。它默认是导航键，**长按默认打开标签总览**；在 Gestures 里还能给它的四个滑动方向各绑一个动作。
- 墨水屏设备上如果浮动按钮碍事，选「Don't show」，需要标签切换时用工具栏的 Tab Count 即可。

## 六、外接键盘与实体按键

- **Vi 键**：设置 → Behavior → Vi Key Binding，默认关。开启后可用 `j`/`k` 这类按键滚动，适合给墨水屏配蓝牙键盘的用户。
- **方向键翻页**：同一页的 Use Up/Down Key，默认关；开启后蓝牙键盘的上下方向键就是翻页键。

设置项太多找不到时，在设置页顶部的搜索框里直接输名字（如「Gestures」），其他入口与排查见[常见问题排查.md](常见问题排查.md)。
