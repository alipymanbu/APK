## 一、进入阅读模式的几种方式

阅读模式会剥掉网页的导航栏、侧栏、广告，只留正文，是长文阅读的主力。进入方式有三种：

1. 点工具栏的 **Reader Mode** 按钮（默认工具栏就有）；
2. 从菜单 → Content Adjustment → Reader mode；
3. **长按工具栏的 Font Size（字号）按钮**——顺手，值得记住。

再点一次按钮就退回原网页。阅读模式有自己的工具栏配置（旋转、全屏、加粗、字号、触摸翻页、目录等），和普通网页的工具栏互不影响。

## 二、阅读模式的排版设置

**长按 Reader Mode 图标**打开排版对话框，这几项可以调：

- 页边距与行距：调整后立即生效；
- 横屏双栏：横着拿设备时正文分两栏，减少每行字数；
- Keep extra content：默认阅读模式只保留正文，勾上它会保留数学公式（MathJax/KaTeX）等附加内容——看带公式的文章时再开；
- 阅读字体：可以给阅读模式单独指定字体。

同样的对话框也能从 **设置 → UI → Reader Mode Settings** 进入。

## 三、字号、加粗与自定义字体

| 想做的事 | 操作 |
|---|---|
| 临时放大/缩小 | 工具栏 Increase Font / Decrease Font，每按一次 ±10% |
| 打开字号对话框 | 工具栏 Font Size 按钮，可精确设置并选字体样式 |
| 全文加粗 | 工具栏 Bold Font |
| 强制白底 / 黑字 | 菜单 → Content Adjustment → White background / Black font |

几点经验：

- 墨水屏灰阶有限，**Bold Font 全文加粗**是对抗字体发虚最直接的一招，开了之后不少网站的可读性明显改善；
- 白底黑字（White background）对付深色模式网站很有效——有些网站强制黑底，墨水屏上看就是一片糊；
- 颜色反转（Invert Color）可以从工具栏配置里加进来，适合临时看白底页面想换黑底的场景；
- 字体大小、加粗这些显示偏好还能**按网站记忆**，设置方法见[常见问题排查.md](常见问题排查.md)的逐站点规则一节。

## 四、竖排阅读（中日韩文）

工具栏的 Vertical Layout（或菜单 → Vertical mode）切换竖排，正文从上到下、从右往左排，适合古籍、日文小说这类内容：

- 翻页时**按行对齐**，不会把一行字从中间切断；
- 数字与英文缩写会做纵中横排（横着占一格）；
- 页边距、行距沿用阅读模式那套设置。

竖排和阅读模式可以叠加使用。

## 五、暗色模式与主题

- **Dark Mode** 在 设置 → UI → Dark Mode，三档：跟随系统 / 强制开 / 禁用。墨水屏用户一般选「禁用」，避免界面自己变黑。
- 网站本身的深色样式用上一节的 White background 对付。
- 新版本（16.x 起，以官方更新日志为准）增加了界面主题：强调色、边框样式、底纹都能换；网盘这份 14.6.0 里没有这组设置，只有经典黑白界面。

## 六、图片显示

- 想省流量或让页面更清爽：菜单 → Site Settings 里可以全局关 Images，也能只对某个网站关；
- **墨水屏图片优化**（把网页图片加亮、加抖动，让照片在墨水屏上看得清）是 15.10 之后的版本加入的功能，14.6.0 里没有；需要的话从官方渠道装新版，渠道对比见[下载与安装教程.md](下载与安装教程.md)。

残影、全刷这类屏幕现象属于设备固件层面的设置，浏览器调不了，处理办法见[墨水屏设备适配与调优.md](墨水屏设备适配与调优.md)。

阅读时碰到外文内容不用切出去复制粘贴，逐段翻译的用法见[翻译功能设置.md](翻译功能设置.md)；读完想把正文存成电子书，见[网页另存为电子书.md](网页另存为电子书.md)。
