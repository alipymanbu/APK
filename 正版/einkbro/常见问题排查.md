## 一、页面空白、按钮点不动：先查 JavaScript 和 Cookie

很多网站没有 JS 就渲染不出来，EinkBro 默认两者都是开的。如果你关过：

- 菜单 → Quick toggle：这一屏集中了 Incognito、AdBlock、JavaScript、Cookies 等开关，先确认没被关掉；
- 长期方案是「全局关 + 白名单」：设置 → Site Settings 里 JavaScript / Cookies 各有 Whitelist，只给信任的站点开，其余全关，兼顾安全与可用；
- 白名单条目点一下就能编辑。

改完记得刷新页面。

## 二、广告还是出现：AdBlock 排查

- AdBlock 默认开启；确认 Quick toggle 里没被误关；
- 设置 → Site Settings → AdBlock → Update AdBlock Content 手动更新一次过滤列表；
- 检查是不是把该网站加进了 AdBlock Whitelist（自己加的白名单自己忘了，是「拦不住」的头号原因）。

## 三、只想对某一个网站改设置：逐站点规则

不想全局动设置时，用逐站点覆盖：在工具栏打开 Site Settings 对话框（当前页面的设置），可以只对当前站记住这些偏好——桌面版/移动版、字号、加粗、白底黑字、阅读模式、翻译方式，以及单独开关 AdBlock、Cookie、JS、图片。

- 规则范围可以是整个站，也可以精确到路径（如 `example.com/docs`）；
- 已保存的规则集中管理在 设置 → Site Settings → Configured Sites，可以逐条改或删；
- 用深色网站、流氓弹窗站、图片站时最省心。

## 四、换手机怎么搬数据

设置 → Backup 里有四种方式：

| 方式 | 做法 | 说明 |
|---|---|---|
| Google Drive 同步 | 登录后备份/恢复 | 登录在浏览器内完成，不依赖 Play 服务 |
| 导出/导入 App Data | 导出 zip → 新设备导入 | 含历史、书签、设置、WebView 登录数据 |
| 局域网互传 | Share / Receive App Data | 两台设备同一 Wi-Fi 下直传 |
| 书签单独迁移 | Export / Import Bookmarks | 只搬书签，轻量 |

注意恢复语义：新版本（16.x 起，以官方更新日志为准）恢复是**合并**进本地数据，本机已有内容不会被删；更早版本（含网盘的 14.6.0）恢复行为可能整包替换本地数据。不管哪个版本，动手前先导出一份 zip 备底。

## 五、安装失败或装完变成「两个 EinkBro」

- **解析包失败**：重新下载一遍（文件不完整），或确认系统是 Android 7.0 以上；
- **覆盖安装提示失败**：签名不一致，先卸载再装，重要数据先按第四节导出；
- **桌面上出现两个 EinkBro 图标**：你先后装了 Play 版（包名带 `.g`）和 APK 版（包名不带），这是两个独立应用，数据不互通，留一个、删另一个即可，详见[下载与安装教程.md](下载与安装教程.md)第五节。

## 六、墨水屏上残影重、越用越卡

残影与全刷闪烁是墨水屏的正常现象，刷新模式、全刷频率、后台冻结这些开关在设备固件里，不在浏览器里；设备侧与浏览器侧的调法分两步走，见[墨水屏设备适配与调优.md](墨水屏设备适配与调优.md)。

## 七、登录 Google 或其他账号被拦

EinkBro 基于系统 WebView，登录 Google 这类账号时遇到「此浏览器可能不安全」或反复跳回登录页，是 WebView 浏览器的通病。按顺序试：

1. 确认 Cookie 开着且没对相关域名做限制（见本篇第一节）；
2. 升级到最新版——官方更新日志里就有一条「移除 User-Agent 中的 wv 标记，让 Google 登录可用」的修复，旧版更易被拦；
3. 还不行时，在 设置 → Misc → Custom User Agent 里启用自定义 UA，伪装成主流浏览器的标识再试；官方也提到这一招可用于通过 Cloudflare 的人机校验。

若怀疑是账号本身被风控（异地登录提醒、要求补充验证），处理入口以 Google 账号页面的提示为准，与浏览器无关。

## 八、设置项太多找不到

设置页**顶部有搜索栏**，输入设置名直接跳转，中英文都能搜（「字体」「Gestures」都行）。翻页相关的开关清单见[翻页触控与手势设置.md](翻页触控与手势设置.md)。

## 九、清理与隐私

设置 → Data Control：勾选要清的类型（缓存、历史、IndexedDB 与本地存储、Cookie），一次性清理；勾上 Clear On App Exit 则每次退出自动清。共享设备或处理敏感内容后建议清一遍。

## 十、还有问题：去哪反馈与看新版本

- 报 bug、搜已知问题：项目的 GitHub Issues（从 [github.com/plateaukao/einkbro](https://github.com/plateaukao/einkbro) 进）；
- 看每个版本改了什么：GitHub Releases 的更新日志；
- 想升级到新版：渠道对比与升级注意见[下载与安装教程.md](下载与安装教程.md)。

AI 相关报错（密钥、额度、自建服务）先按[AI功能与密钥配置.md](AI功能与密钥配置.md)第六节自查一遍再来。
