# EinkBro 网页另存为电子书

> 网页文章想存下来慢慢看、或者导进电纸书阅读器？EinkBro 能把网页导出成 EPUB、PDF、MHT 三种格式，本篇讲各自怎么用、适合什么场景。

## 一、保存方式总览

| 格式 | 得到什么 | 适合 |
|---|---|---|
| EPUB | 带目录和图片的电子书 | 导进 Kindle / 文石 / Supernote 等阅读器慢慢看 |
| PDF | 带目录项的定稿文档 | 存档、打印、格式不能乱掉的资料 |
| MHT | 单文件网页存档 | 原样保存整个网页（含样式），日后用浏览器打开 |
| 截图 | 整页长图 | 快速留档或分享版式 |
| 稍后读 / Instapaper | 存进阅读列表 | 「先存着回头读」，不导出文件 |

入口大多在菜单 → Share & Save 区块里。

## 二、导出 EPUB（多页合并成一本书）

1. 打开文章，先开阅读模式（排版干净，导出效果好）；
2. 菜单 → Share & Save → EPUB，或工具栏的 Save EPUB 按钮；
3. 对话框里有两个标签页：保存新的、打开已有的；
4. **多篇文章可以存进同一个 EPUB**——每篇自动成为一个章节，下次在另一篇文章里再点 EPUB，选择追加到已有的那本即可；
5. 目录编辑器里可以拖拽调整章节顺序。

导出的 EPUB 带 EinkBro 标识，方便在阅读器里认出来。在 Supernote 设备上，EPUB、PDF 等下载会自动路由到设备的 Document 目录，直接在自带阅读器里打开；该设备更多适配细节见[墨水屏设备适配与调优.md](墨水屏设备适配与调优.md)。

## 三、存为 PDF

菜单 → Share & Save → Save as PDF。两点可调：

- **纸张大小**：设置 → Misc → Printed PDF Paper Size，导出前先选好（A4、Letter 等）；
- PDF 会带目录项，长文档在阅读器里可以跳章节。

## 四、存为 MHT 单文件存档

菜单 → Share & Save → Save as MHT，整个页面（文字、样式、图片）打进一个 `.mht` 文件。和 PDF 的区别：MHT 保留网页原来的结构与排版，适合「原样留证」，但要在浏览器里打开，不适合阅读器。

## 五、整页截图

从菜单发起，会把整页从头到尾拼成一张长图，不是只截当前屏幕。存的也是图片文件，走系统下载目录。

## 六、稍后读与 Instapaper

- **Save for later**：本地阅读列表，先把链接存着，在列表里点开读；
- **Instapaper**：存到 Instapaper 账号，跨设备接着读，需要你有该服务账号。

## 七、导出的文件在哪

- 所有导出与下载都落在系统的下载目录，菜单 → Downloads 可以直接打开；
- 导出的 EPUB/PDF 想传到电纸书，用数据线或网盘中转即可。

存正文前如果发现排版太乱、广告太多，先去[阅读模式与排版调整.md](阅读模式与排版调整.md)把阅读模式调好再导出；安装或升级版本的渠道选择见[下载与安装教程.md](下载与安装教程.md)。
