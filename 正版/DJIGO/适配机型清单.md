## 一、DJI GO 支持的设备

以下为[官方下载页](https://www.dji.com/cn/downloads/djiapp/dji-go-3)列出的支持产品（截至成文，以官方页面为准）：

| 产品线 | 具体型号 |
| --- | --- |
| 精灵 Phantom 3 | Standard、SE、Advanced、Pro、4K |
| 悟 Inspire 1 | Inspire 1、Inspire 1 Pro、Inspire 1 RAW |
| 经纬 Matrice | Matrice 100、Matrice 600、Matrice 600 Pro |
| 灵眸 Osmo | Osmo、Osmo+、Osmo Pro/RAW、Osmo Mobile、Osmo 手机云台 2 |
| 图传 | DJI Lightbridge 2 |
| 农业 | MG-1 植保机 |

一个简单的记法：**精灵 3 与更早的经纬/悟一代用 DJI GO；精灵 4 与御、晓、悟 2 之后全都不用这个 app**。确认自己的设备在列后，从 [下载与安装教程.md](下载与安装教程.md) 拿安装包开始。

## 二、手机端要求

- **系统**：Android 4.1.2 及以上。
- **推荐机型**（官方下载页名单）：LG V20、VIVO X9、OPPO R11、Google Pixel、Nexus 6P、Huawei P9、Huawei Mate 9、Samsung Galaxy Tab S2、Galaxy S5 / S6 / S6 Edge / S7 / S7 Edge / S8 / S8+、Galaxy Note 5 / Note 8、小米 5 / 小米 6。
- 名单外的机型：官方口径是「未在列表内的手机型号缺乏稳定性验证，如果你的手机系统符合需求，理论上是能够使用的，但无法保障使用时的稳定性」。也就是说老机器先装上试，图传卡顿属预期内现象。
- **iOS 版**：App Store 单独提供，版本要求以 App Store 页面为准；功能与 Android 版基本一致。

关于这个 app 的现状（应用商店下架、版本停在 3.1.83、新手机上的预期），另见 [还能用吗.md](还能用吗.md)。

## 三、别装错：DJI GO、DJI GO 4、DJI Fly 对照

这三个 app 名字相近，覆盖的设备完全不同。装错了 app 会一直搜不到设备，这是识别不到飞行器的第一大原因；搜不到设备时的完整排查见 [常见问题与解决办法.md](常见问题与解决办法.md)。

| app | 适用设备 |
| --- | --- |
| **DJI GO**（本篇） | 精灵 3 系列、悟 Inspire 1 系列、经纬 M100 / M600 系列、Osmo 初代系列、Lightbridge 2、MG-1 |
| **DJI GO 4** | 精灵 Phantom 4 全系列、御 Mavic Pro / Air / Mavic 2 系列、晓 Spark、悟 Inspire 2、经纬 M200 / M210 |
| **DJI Fly** | Mavic 3 / Mini / Air 系列、Avata、FPV、Neo 等新款消费级 |
| DJI Pilot / Pilot 2 | 行业级机型（如 M300 RTK、M30 系列等），Pilot 2 仅在带屏遥控器上使用 |

补充两点历史原因，避免网上查资料时被绕晕：

- 官方在 2017 年初发布 DJI GO 4 时明确说明：DJI GO **不能识别** Phantom 4 Pro 与 Inspire 2，这两类设备必须换 DJI GO 4。
- 初代 Phantom 4 与初代御 Mavic Pro 是过渡期机型，两个 app 都能连，但新功能只在 DJI GO 4 上更新，用 DJI GO 连它们得不到后续功能。

机型确认无误后，按设备类型建立连接的步骤见 [连接飞行器步骤.md](连接飞行器步骤.md)。
