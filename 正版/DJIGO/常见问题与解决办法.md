## 一、打开 app 搜不到设备 / 一直显示未连接

典型症状先对一下号：**app 首页的「相机」图标是灰色的** —— 官方排查文档对精灵 3 系列就用这个图标状态表示「遥控器与手机未连接」。

按出现频率从高到低查：

1. **app 装错了**：精灵 4 / 御 Mavic / 晓 Spark / 悟 Inspire 2 要用 DJI GO 4，DJI GO 永远搜不到它们 —— 对照 [适配机型清单.md](适配机型清单.md) 的三 app 对照表。
2. **连接方式用错**：精灵 3 Standard / SE 走 Wi-Fi（不要插线），Advanced / Pro / 4K 走 USB 线（不要连热点）。详表见 [连接飞行器步骤.md](连接飞行器步骤.md)。
3. **线不是数据线**：很多 USB 线只能充电。换原装线或确认带数据传输的线，再换个手机接口；**手机壳太厚导致插头接触不良**也属官方列明的原因，先摘壳。
4. **手机连了别的网络**：Wi-Fi 类设备要求手机停在设备发出的热点上；手机若自动切回 4G/家里 Wi-Fi，连接即断。热点名对、密码不对的，默认密码是 `12341234`，忘了可以整体重置 —— 见 [精灵3标准版WiFi连接与重置.md](精灵3标准版WiFi连接与重置.md)。
5. **遥控器与飞行器没对频**：换过设备或新购二手设备时，遥控器可能没绑定这台飞行器，按机型的对频流程重新对一次。
6. **固件太旧**：长期没用的设备固件可能落后于 app，用官方工具升级固件后再连。

## 二、图传画面卡顿、花屏、黑屏

- **手机性能不够**：图传解码很吃性能，官方推荐机型名单（见适配机型清单）之外的旧手机容易出现卡顿；关掉后台应用、降低屏幕录制与画质选项能缓解。
- **干扰与距离**：城市楼宇、高压线、人群密集处图传会明显变差；天线方向也要对着飞机。
- **缓存堆积**：app 用久了缓存变大，进设置清一次缓存再试。
- **Wi-Fi 类设备的信道拥挤**：精灵 3 Standard 这类走 Wi-Fi 图传的设备，在 Wi-Fi 环境复杂的地方容易掉帧，换空旷场地验证。

## 三、登录不上 / 激活失败

激活与登录都需要手机**联网**（激活走的是手机网络，不是飞行器）。首次激活弹「激活失败」时，官方排查文档给的处理顺序是：

1. **给 app 开权限**：到手机系统设置里找到 DJI GO（iOS 在设置列表里找，Android 在应用管理里找），把它的各项访问权限打开，再重试激活；
2. **重启飞行器**再激活一次；
3. **换网络环境**：Wi-Fi 与蜂窝数据互相切换着试 —— 激活请求对网络环境敏感；
4. **换一台设备**：可能的话换另一部手机（安卓/iOS 互换）来激活，优先用官方兼容名单内的机型。

收不到注册验证码：检查短信拦截记录，或换一条网络通道重试。以上都试过仍失败，联系大疆官方客服，让他们在后台看设备激活状态。

## 四、飞行记录不同步

1. 确认 app 里已登录 DJI 账号（没登录只存本机）；
2. 同步发生在手机联网时，飞行完当天记得开一次网络；
3. 换手机后记录「丢了」：多半是登录了另一个账号，用当时飞行用的那个账号登录即可。

## 五、安装失败与闪退

| 现象 | 处理 |
| --- | --- |
| 提示「未知来源」被拒 | 允许该来源安装后再试（步骤见 [下载与安装教程.md](下载与安装教程.md)） |
| 华为/鸿蒙装不上 | 关闭系统「纯净模式」再装（官方支持页给出的方式） |
| 解析包错误 | 安装包下载不完整，核对 MD5：`ce95611144d8eaf8cdcb1a2882b49a23`，不一致重新下载 |
| 一打开就闪退 | 确认系统 ≥ Android 4.1.2；清一次 app 缓存；存储不足先清理 |
| 商店里搜不到 DJI app | 官方已从华为/小米/Google Play 等平台下架，属正常 —— 从官网或本文开头的网盘资源拿 APK，现状见 [还能用吗.md](还能用吗.md) |
| 下载很慢或断 | 安装包近 180 MB，从本文开头的 DJI GO 安装文件资源（夸克网盘）获取，转存后下载更稳 |

## 六、以上都不奏效时

带着机型、手机型号、app 版本号（3.1.83 或你实际安装的版本）去大疆官方支持渠道问，官方响应比社区猜测可靠。查资料时注意：网上大量教程混着 DJI GO 与 DJI GO 4 的内容，操作界面相似但设备不同，别照搬 —— 先确认自己该用哪个 app，这能省掉大部分无效排查。
