## 一、标准连接流程

官方支持页给出的 Wi-Fi 图传连接步骤，按顺序做：

1. 打开遥控器电源；
2. 给飞行器上电，等自检完成；
3. 手机的 Wi-Fi 列表里选 `PHANTOM3_XXXXXX`（尾号每台机器不同）；
4. 输入密码 —— 出厂默认是 `12341234`；
5. 打开 DJI GO 进入相机画面，能看到相机实时画面就说明图传已建立。

连不上先回头核对你连的热点名字和密码，这是这一步最常见的失败点。

## 二、默认热点名与密码在哪里看

- **热点名（SSID）与密码印在遥控器背面标签上**，官方排查文档明确指向这里；
- 出厂默认密码统一为 `12341234`；
- 如果你（或设备的上一位主人）在 app 里改过密码，标签上的默认密码就失效了 —— 这是二手机器最常踩的坑，处理办法见下一节。

## 三、在 DJI GO 里修改 Wi-Fi 名称与密码

默认密码谁都能猜到，拿到机器后建议改掉：

1. 手机连上设备的 Wi-Fi、打开 DJI GO 并连接成功；
2. 进 app 的 Wi-Fi 图传设置（说明书「DJI GO App」章节对应的设置页）；
3. 在里面修改 SSID 与密码；
4. 保存后设备的热点会按新名字/新密码广播，**手机要用新密码重连一次**。

改完把新密码记在可靠的地方 —— 忘了也没有「找回」一说，只能按下一节整体重置。

## 四、忘了密码：重置回出厂默认

精灵 3 Standard / SE 的遥控器支持不连手机直接重置（官方手册与官方客服口径一致）：

1. 打开遥控器（不需要开飞行器，也不需要连手机）；
2. 把云台拨轮拨到最右；
3. S2 拨杆来回拨动至少 3 次；
4. 遥控器发出一声长鸣 = SSID 与密码已重置回默认。

重置后再到手机 Wi-Fi 里连 `PHANTOM3_XXXXXX`、输入 `12341234` 即可。

精灵 3 4K 同样是 Wi-Fi 图传机型，重置操作与 Standard 基本相同，但未逐台验证，以你手里机型的官方说明书为准。

## 五、图传距离与频段参考

精灵 3 Standard 官方规格：Wi-Fi 图传工作在 5.725–5.825 GHz 频段；空旷环境不遮挡时，FCC 地区图传距离约 1000 m、CE 地区约 500 m。实际能飞多远受遮挡、干扰与当地法规限制，官方数值只是无遮挡理想环境的上限，别拿它当日常飞行半径。

## 六、连上了但没画面

Wi-Fi 连接成功但 DJI GO 里看不到相机画面，多与信号占用和距离有关，完整排查清单见 [常见问题与解决办法.md](常见问题与解决办法.md)；USB 线类机型（Advanced / Pro / 4K 之外的接法）见 [连接飞行器步骤.md](连接飞行器步骤.md)。
