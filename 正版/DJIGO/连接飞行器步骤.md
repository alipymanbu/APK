## 一、先搞清楚你的设备走哪种连接

DJI GO 连接设备只有两条路：**USB 数据线** 或 **Wi-Fi**。对应关系如下（细则以各产品的官方说明书为准）：

| 设备 | 连接方式 | 手机这一端做什么 |
| --- | --- | --- |
| 精灵 Phantom 3 Advanced / Pro / 4K | USB 数据线 | 数据线把手机接进遥控器侧面的接口 |
| 精灵 Phantom 3 Standard / SE | Wi-Fi | 手机连上遥控器发出的 Wi-Fi 热点 |
| 悟 Inspire 1 系列 | USB 数据线 | 数据线接遥控器 |
| 经纬 Matrice 100 / 600 / 600 Pro | USB 数据线 | 经配套遥控器（如 Lightbridge 2）接手机 |
| 灵眸 Osmo / Osmo+ / Osmo Pro / RAW | Wi-Fi | 手机连 Osmo 发出的 Wi-Fi |
| Osmo Mobile / Osmo 手机云台 2 | 蓝牙 | 手机蓝牙直接配对 |
| MG-1 植保机 | USB 数据线 | 经配套遥控器接手机 |

注意：精灵 3 系列内部接法不一样：Standard / SE 的图传走遥控器 Wi-Fi，所以手机**不要**插线；Advanced / Pro 反过来走 USB 线，手机**不要**去连什么热点。这是精灵 3 用户连不上的高频原因。

Standard / SE 的 Wi-Fi 连接细节（默认热点名与密码、在 app 里改密、忘了密码怎么重置）单独成篇：[精灵3标准版WiFi连接与重置.md](精灵3标准版WiFi连接与重置.md)。

## 二、通用连接流程

不管哪种设备，顺序都是这五步：

1. **先开设备（或遥控器），再连手机**。飞行器要先通电自检完成（指示灯正常）再开遥控器，具体开机顺序按你机型的说明书执行。
2. **建立物理连接**：USB 设备插线；Wi-Fi 设备到手机的设置里连对应热点（热点名通常含设备型号，密码在说明书或机身标签上）。
3. **打开 DJI GO**：app 检测到设备会弹出设备界面；同一部手机装了大疆多个 app 时，注意确认弹的是 DJI GO 而不是别的。
4. **登录 DJI 账号**（首次需要注册）。
5. **激活**：首次连接时 app 会引导激活，需要手机联网。激活一次即可，之后离线也能用。

Osmo 手持设备没有激活飞行器的部分，连上就能拍；飞行器激活完成后建议先在 app 里进入相机画面确认图传正常，再谈起飞。

## 三、飞行器起飞前的检查项

- 遥控器与飞行器都已开机、电量充足；
- app 相机界面里能看到实时画面、GPS 信号良好；
- 在 app 里确认返航点已刷新（GPS 定位准了返航点才准）；
- 桨叶安装到位、周围无遮挡。

新手第一次飞，建议先在 app 的模拟器里练：DJI GO 内置了飞行模拟器（在「学院」里），不消耗电池也不炸机。模拟器和实际飞行操作入口见 [智能飞行功能怎么用.md](智能飞行功能怎么用.md)。

## 四、连不上时先查这六处

先认识官方给出的症状：**app 首页的「相机」图标是灰色的** —— 官方排查文档对精灵 3 系列就是这么描述「遥控器没连上手机」这个状态的，见到灰色图标按下面顺序查：

1. **app 装对了没有**：精灵 4 / 御 / 晓 / 悟 2 要用 DJI GO 4，不是 DJI GO —— 对照 [适配机型清单.md](适配机型清单.md)。
2. **连接方式用对了没有**：见本文第一节那张表，插线与连 Wi-Fi 两种方式别混。
3. **线材与接口**：USB 线尽量用原装或带数据功能的线（部分充电线不传数据），换一个手机接口再试；**手机壳太厚会让插头插不到底、接触不良**，官方排查清单里专门提了这条，先摘壳再试。
4. **Android 手机的 USB 模式**：部分安卓手机连上遥控器后要在弹窗里选「仅充电」或「传输文件」，没弹窗的话试试在开发者选项里开 USB 调试 —— 这条也在官方排查清单内。
5. **Wi-Fi 连接的设备**：确认手机连的热点是设备本身发出的那个，而不是家里路由器或遥控器上的其他网络；官方也提示注意 Wi-Fi 信号是否已被占用。
6. **遥控器没开机或固件过旧**：先确认遥控器指示灯正常；长期闲置的设备固件可能落后于 app。

按这六条查完仍然不行，去看 [常见问题与解决办法.md](常见问题与解决办法.md) 的完整排查清单。
