## 一、先说结论

Echo Music 的歌词是**跟着唱到哪滚到哪**的同步歌词，还支持逐词高亮；播放页上滑或点歌词区即可进入全屏歌词视图。本篇讲三件事：歌词怎么调样式、歌词数据从哪来、外语歌词怎么翻成中文。

## 二、进入歌词与调样式

1. 播放任意一首歌，点播放页的歌词区域（或上滑），进入全屏歌词。
2. 歌词页面上通常有几个可切换的显示形态 —— 逐行滚动、逐词高亮、以及不同的动画风格。官方说明里列出的能力包括：
   - **多种歌词动画**：可挑不同的滚动/渐变样式；
   - **逐词同步**：一行里按唱到的词逐个点亮；
   - **Lyrics+**：新增的歌词源，覆盖面与准确率比早先的来源更好。
3. 具体菜单名字在不同版本里会有出入，以你手上这一版界面为准 —— 找不到某个选项，多半是这版还没带，或在别的层级里（设置页顶部有搜索框，直接输关键词能定位到设置项）。

歌词没显示或对不上时，先看[常见问题与解决方法.md](常见问题与解决方法.md) 的歌词那一节，通常换歌词源就能解决。

## 三、AI 翻译：把外语歌词翻成中文

如果你听的歌是非中文的，Echo Music 带了歌词翻译能力，需要你配一个翻译用的接口才会生效。

配置路径：**设置 → AI Settings（AI 设置）**。

关于翻译用的是哪一套，两处官方资料的说法不同，你按自己这版界面对：README 把它描述为「内置 Google 翻译集成」，开发文档则写可选 Provider —— 界面上看到现成的翻译开关就直接开，看到 Provider/API Key 栏才需要按下表配。

| 配置项 | 怎么填 |
| --- | --- |
| Provider（提供方） | 默认是 OpenRouter，也可换成 ChatGPT、Gemini 或 Custom（自定义） |
| API Key | 到 [openrouter.ai](https://openrouter.ai/) 注册后生成，粘进来 |
| Base URL | 只在 Provider 选 Custom 时才需要填，填你所用服务的地址 |

几点注意：

- 翻译是要联网调用接口的，Key 一般有免费额度，用完需要你自己充值或换服务 —— 这一步是可选的，不开翻译不影响其它功能。
- 你不配 Key，歌词照常显示原文，只是没有翻译那一栏。
- Key 属于你自己的账号凭据，别截图发到公开场合。

## 四、和其它功能的关系

- 歌词是你听歌时的「画面」，和[一起听与Spotify歌单导入.md](一起听与Spotify歌单导入.md) 里的实时同步收听是两码事：一起听同步的是**播放进度**，歌词仍然各自按自己的屏幕滚。
- 想让歌单里多点能看歌词的完整曲目，把 Spotify 歌单导进来是最快的路子，做法在[一起听与Spotify歌单导入.md](一起听与Spotify歌单导入.md)。
- 首次使用、权限相关的问题见[下载与安装教程.md](下载与安装教程.md)。
