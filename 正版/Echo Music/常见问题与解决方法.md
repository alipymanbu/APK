# Echo Music 常见问题与解决方法

## 一、先按这个顺序排查

大多数问题能归到四类：**网络、系统权限、曲库本身、版本**。按下表对号入座，能省掉大量乱试：

| 现象 | 先查什么 | 详见 |
| --- | --- | --- |
| 歌曲加载不出、一直转圈 | 网络与省流量开关 | 第二节 |
| 切后台就断、锁屏停播 | 电池白名单与后台数据 | 第三节 |
| 有歌没歌词、歌词对不上 | 歌词源与翻译配置 | 第四节 |
| 闪退、装不上、更新失败 | 安装包与版本 | 第五节 |

## 二、搜得到歌却播不出来

1. **先确认网络**：换一个 Wi-Fi 或用流量试一次。能打开网页但播不了，问题多半在下一步。
2. **查省流量**：系统级的「省流量 / 数据节省」会限制后台与媒体加载，对它放行或暂时关闭（路径见[离线下载与后台播放设置.md](离线下载与后台播放设置.md)）。
3. **查应用内的 Data Saver**：若开着，先关掉再试；它会压低码率，在弱网下反而可能更不稳。
4. **多试几首**：只有一首播不了、别的都正常，通常是那一首在曲库里缺失或受限 —— 搜索换个关键词、或换同曲目的其它版本，不是你的设置问题。

## 三、切后台就断 / 锁屏停播

这是国产 ROM 省电策略的典型行为，不是应用坏了。按这个顺序给权限：

1. 设置 → 应用 → Echo Music → 电池 → 允许后台活动（或选「不限制」）。
2. 同一页里确认后台数据没有被限制。
3. 若手机有「一键清理 / 内存加速」习惯，把 Echo Music 加进白名单，别让它被顺手清掉。

设完播一首锁屏验证：通知栏应保留播放控制条。详细路径与其它开关在[离线下载与后台播放设置.md](离线下载与后台播放设置.md)。

## 四、歌词空白、对不上或没有翻译

- **整屏没歌词**：换歌词来源。官方列的来源里 Lyrics+ 覆盖面更好，优先试它（入口在歌词页或歌词相关设置，具体名随版本变）。
- **歌词滚动但不逐词高亮**：不是所有歌都有逐词时间轴，没有的会退回逐行显示 —— 属正常，不是故障。
- **翻译那栏是空的**：翻译要配了接口才生效，去 设置 → AI Settings 填 Provider 与 API Key，步骤见[同步歌词与AI翻译设置.md](同步歌词与AI翻译设置.md)。
- **歌词比唱的快/慢**：先确认不是自己拖过进度条；持续偏移就换歌词源。

## 五、闪退、装不上、更新失败

**装不上**：提示「解析包错误」＝ 安装包没下完整，重新下一遍（[下载与安装教程.md](下载与安装教程.md) 有校验 MD5 的办法）；提示来源不受控，按[下载与安装教程.md](下载与安装教程.md) 安装步骤里未知来源那一项放行。

**闪退**：先在 系统设置 → 应用 → Echo Music → 存储 里**清缓存**（别先清数据 —— 清数据会把已下载的离线歌曲和设置一起删掉）。清完重启应用，多数轻度闪退到此为止；仍闪退再考虑重装（离线内容会丢，注意提前知道这一点）。

**更新**：应用内的 OTA 更新已被官方**永久移除**，只能手动更新 —— 去官网或 GitHub Releases 下新包装上。手动覆盖安装通常能保留已有数据；版本号体系与网盘那份对不上是正常的，见[下载与安装教程.md](下载与安装教程.md) 的版本说明。

## 六、项目状态与「还能不能用」

Echo Music 是开源项目，官方对内容来源的说明是：应用本身不托管任何歌曲，曲库来自公开可访问的网络资源。项目是否会继续更新、有没有停更，**以 [github.com/EchoMusicApp/Echo-Music](https://github.com/EchoMusicApp/Echo-Music) 仓库当时的状态为准** —— 第三方页面关于「已停止维护」的说法有时效性，别据此提前卸载。

停更了也能继续用：已装的版本照常能听、能播本地文件（[离线下载与后台播放设置.md](离线下载与后台播放设置.md)），只是不再有新功能；真出问题，按本篇前四节的顺序排查即可。有具体疑问也可去官方的 Discord 社区问（入口在官网 [echomusic.fun](https://echomusic.fun/) 页面上）。
