## 一、按顺序自检（官方给的「报告前先试」清单）

官方明确：下面这几步能解决大部分常见问题，报障之前先走一遍。**按顺序做，别跳**：

1. **重启并更新**：WeMod 和游戏都重启一次，两者都更到最新，再重启一次电脑。
2. **校验游戏文件**：
   - Steam：游戏右键 → 属性 → 已安装文件 → **验证完整性**；
   - Epic：游戏「…」→ 管理 → **验证**。
3. **干净启动**：WeMod 与游戏都**以管理员身份运行**；暂时关掉杀软；关掉其他后台程序；**先启动游戏、再回 WeMod 连接**。
4. **一次只开一个修改项**：逐个开，看是哪一个导致失效或崩溃（这是定位冲突的标准手法）。
5. **游戏崩溃 → 关掉悬浮窗（overlay）** 再试。
6. **切换全屏 / 窗口模式** 试一遍，两种模式的表现往往不一样。
7. **检查网络**：修改项要联网拉取；用手机遥控的还要确认两台设备在同一网络（见 [常见问题与连接故障排查.md](常见问题与连接故障排查.md)）。
8. 还不行 → 干净重装（见第四节）。

卡在「载入修改」不动的，多半是第 3 步该查的东西没查 —— 杀软与流量过滤工具的加白步骤在 [杀毒软件报毒与白名单设置.md](杀毒软件报毒与白名单设置.md)。

## 二、游戏刚更新完就失效

游戏一发补丁，WeMod 就要跟着更新才能识别新版本 —— 所以「刚更新完就失效」属于**等更新**，不是你装错了：

- 游戏页会显示 **Needs update（需要更新）** 状态，位置在应用的 **Upcoming（即将支持）** 区域；
- 点 **Notify me（通知我）**，更新完会有提醒；
- **Pro 用户可以用 Boost 影响排队优先级**；
- 想看整个更新队列，社区官方人员给的入口是应用内的 **Creators → Queue**。

判断依据：**同一时期别的游戏能用、只有这一款不行 → 大概率是它在排队等更新**，与「全都不能用」是两回事。

## 三、几个症状对照

| 症状 | 优先查哪里 |
|---|---|
| 所有游戏的修改项都卡在载入 | 杀软 / 流量过滤拦截，见 [杀毒软件报毒与白名单设置.md](杀毒软件报毒与白名单设置.md) |
| 只有某一款游戏不行 | 该游戏在等更新（第二节），或修改项组合冲突（逐个开） |
| 游戏一起来就闪退 | 关悬浮窗、管理员启动、先校验游戏文件 |
| 按热键没反应 | 热键被改或被清成 Not set，见 [修改功能开关与热键设置.md](修改功能开关与热键设置.md) |
| 游戏压根不在列表 | 见 [游戏检测不到怎么手动添加.md](游戏检测不到怎么手动添加.md) |
| 手机端开关无效 | 电脑端 WeMod 是否开着、配对是否还在，见 [常见问题与连接故障排查.md](常见问题与连接故障排查.md) |

## 四、干净重装（自检最后一步）

1. 卸载 WeMod；
2. 删掉这两个目录（可能有残留配置）：

```text
C:\Users\<你的用户名>\AppData\Local\WeMod
C:\Users\<你的用户名>\AppData\Roaming\WeMod
```

3. 重启电脑；
4. 从官网 [www.wemod.com](https://www.wemod.com/) 重新安装。

装完大概率要重新做一次杀软排除项，不然新文件又会被拦 —— 回到 [杀毒软件报毒与白名单设置.md](杀毒软件报毒与白名单设置.md) 把那两个目录补上。

## 五、该报障时报什么

自检走完仍不正常，用应用内入口：游戏页标题旁的 **`?`** → **Report an Issue（报告问题）**，生成的摘要可复制去官方 Discord 或发邮件（`support@wemod.com`，主题写清游戏名）。

要提供的信息（官方清单）：WeMod 用户名与订阅类型、系统版本、WeMod 版本（在设置里）、游戏名与平台、出问题的具体时间与报错原文、已经试过哪些步骤。

官方**不受理**的几类：联机场景下的使用、来路不明的游戏文件、带反作弊保护的游戏、尚未发售的作品 —— 报了也不会有结果，先对照 [游戏检测不到怎么手动添加.md](游戏检测不到怎么手动添加.md) 第一节确认是不是支持范围内的游戏。
