## 一、先弄清楚：手机上装的这个 WeMod 是「遥控端」

WeMod 本体是一个只有 Windows 版的桌面应用，用来给 3000 多款单机 PC 游戏挂修改器、模组和互动地图（官网：[www.wemod.com](https://www.wemod.com/)）。你在手机上装的这个包**不是 WeMod 本体**，官方叫它 Remote（遥控端），包名 `com.wemod.remote` —— 它的作用是把电脑上的 WeMod「搬」到手机屏幕上：人躺在沙发上，用手机开关游戏里已经挂好的修改项、调数值，不用再 Alt+Tab 回桌面。

所以它有几个绕不开的前提，缺一个都白装：

| 前提 | 说明 |
|---|---|
| 一台装了 WeMod 桌面端的 Windows 电脑 | 手机端只是遥控器，运算全在电脑上 |
| 电脑上的 WeMod 保持打开 | 官方支持文档明确：桌面端必须开着，遥控才有效 |
| 手机和电脑在同一个 WiFi | 配对走局域网，不同网段（比如一个用流量）连不上 |
| WeMod Pro 订阅 | Remote 属于 Pro 功能，免费账号用不了，详见 [免费版与Pro版区别.md](免费版与Pro版区别.md) |

另外一条官方写在支持文档里的系统门槛：**Android 7.0 及以上**（iOS 端是 12.0 及以上，本篇不涉及）。

## 二、安装包从哪拿

**WeMod 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/0aeb494c59a0](https://pan.quark.cn/s/0aeb494c59a0)

网盘里这份包的事实信息（下载后可自行核对）：

| 项目 | 值 |
|---|---|
| 版本 | 5.0.0 |
| 包名 | `com.wemod.remote` |
| 大小 | 4.56M |
| MD5 | `34F5C0C2527AAC8DC73B0B9778D6EDB8` |

官方渠道另有一个，可以对照着看：**Google Play 商店页**搜「WeMod Remote」（页面上这个名字后来随品牌改名写作 Wand Pro Remote，以商店当时显示为准）。网盘这份是 5.0.0 版，官方之后可能已经出了新版，两边版本号对不上是正常的 —— 要最新版就去商店，要和本篇步骤一致就用网盘这份。

**电脑端从哪拿**：官网 [www.wemod.com](https://www.wemod.com/) 首页的下载按钮就是 Windows 版安装包（页面会标注只支持 Windows，包体大小以官网当时显示为准）。手机端装完没电脑端，等于遥控器没有电视机。

MD5 想核对的话：把 APK 和 MD5 值放进同一个校验工具（手机端文件管理器或电脑端哈希工具都行）算一遍，对不上说明文件在传输中损坏，重新下载一次。

## 三、安装步骤

1. 在手机上打开网盘链接，把 APK 下载到本地并点开安装。若系统提示「禁止安装来自此来源的应用」，那是浏览器或文件管理器的安装权限没给，去系统设置里允许一次即可（不同品牌路径略有差异，一般在「设置 → 安全 → 安装未知应用」）。
2. 装完先**不要**急着打开。先把电脑端的事办了：装好 WeMod 桌面端、登录你的 WeMod 账号（要用手机遥控得是 Pro，见 [免费版与Pro版区别.md](免费版与Pro版区别.md)）、确认右上角有「Connect（连接）」入口。
3. 确认手机和电脑连的是同一个 WiFi。
4. 打开手机端应用，此时它会停在输入 PIN 的界面 —— 正常，PIN 要从电脑上取，下一步去 [手机连接电脑配对教程.md](手机连接电脑配对教程.md)。

装完发现连不上、卡在 PIN 界面，属于高频问题，处理步骤集中在 [常见问题与连接故障排查.md](常见问题与连接故障排查.md)。

## 四、这个应用在手机上能干什么、不能干什么

能做的（官方支持文档列出的范围）：

- 开关游戏里的各个修改项，不用退出游戏；
- 调整修改项的数值（官方叫 precision mods，需要 Pro）；
- 实时看修改项的状态与说明；
- 不缩小游戏画面就启动修改器；
- 保存、载入一组修改配置。

不能做的：它**没法脱离电脑单独工作** —— 电脑端 WeMod 一关，手机上就只剩一个连不上的空界面（它在手机上发起的启动动作，也是让电脑那边去执行）；官方也明确它不兼容免费账号，且不支持 Amazon Fire、Windows Mobile 这类平台。

装好并配对成功之后怎么用，见 [手机连接电脑配对教程.md](手机连接电脑配对教程.md)；不想用手机、只在电脑上开关，四种方式的对照在 [修改功能开关与热键设置.md](修改功能开关与热键设置.md)；电脑上游戏列表里找不到游戏，走 [游戏检测不到怎么手动添加.md](游戏检测不到怎么手动添加.md)。
