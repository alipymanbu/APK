## 一、先按顺序做这三件最有效的

官方支持文档和社区里被反复验证过的处理顺序就是这三条，别跳着试：

1. **两端都彻底关掉再重开**。手机端要真正退出（不是划到后台），电脑端从系统托盘退出 WeMod，或直接开任务管理器把所有 WeMod 进程结束掉 —— 只关窗口经常不够，残留进程会让新一次连接继续用旧状态。
2. **确认两台设备在同一个 WiFi**，且没有开「访客网络」这类会隔离设备的选项。手机流量下必失败。
3. **确认 Windows 防火墙没拦 WeMod**，且桌面端的远程控制开关是打开的。

绝大多数卡在「Enter PIN（输入 PIN）」这一步的问题，做完这三条就好了。

## 二、按症状对照

| 你看到的现象 | 最可能的原因 | 处理 |
|---|---|---|
| 输完 PIN 一直转，提示「在电脑上打开 WeMod」 | 桌面端进程假死，或两端状态没同步 | 按上一节第 1 条彻底重启两端再连 |
| 输 PIN 直接失败 / 一直连不上 | 不同网络，或防火墙拦截 | 查 WiFi 是否同一网络；补防火墙放行 |
| 手机能打开，但功能缺失、配对过不去 | 账号是免费版或订阅已过期 | Remote 属 Pro，见 [免费版与Pro版区别.md](免费版与Pro版区别.md) |
| 之前好使，突然连不上 | 桌面端被关了，或网络变了 | 确认 WeMod 桌面端开着、remote control 开关打开 |
| 手机浏览器兜底页也打不开 | 本机网络问题（代理/VPN/公司网络限制） | 关掉代理与 VPN 换普通 WiFi 重试 |

## 三、防火墙怎么放行

1. 打开控制面板 → Windows Defender 防火墙 → **允许应用通过防火墙**；
2. 点「更改设置」→「允许其他应用」，选中 WeMod 的可执行文件加入；
3. 确认 **专用** 与 **公用** 两个勾都打上，确定保存；
4. 第一次连接时若弹出「是否允许 WeMod 访问」的系统提示，两项都勾再点允许。

第三方杀毒软件同理：在它的「拦截记录 / 信任区 / 排除项」里把 WeMod 加白，该加的目录与完整步骤集中写在 [杀毒软件报毒与白名单设置.md](杀毒软件报毒与白名单设置.md)。修改器类工具被安全软件误判是常见情况，加白之后再试连接。

## 四、连不上时的兜底办法

官方支持文档给的替代路径：**用手机浏览器打开遥控页**，地址是 `remote.wand.com`（早期资料里写的是旧域名 `remote.wemod.com`，以官方文档当时显示为准）。页面功能与手机端一致，连上了就说明问题出在 App 本身（版本旧、缓存坏），把 App 强制停止后重开、或重装一次 —— 安装包可重新从 [WeMod 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0aeb494c59a0) 取，步骤见 [下载与安装教程.md](下载与安装教程.md)。

浏览器页能开、App 不能开 → 重装 App；两个都开不了 → 回到第二节，问题在网络或账号那一层。

## 五、几个容易误判成「连不上」的情况

- **开关点了没反应**：不是连接问题，可能是修改项组合冲突。关掉其中一个再看另一个是否恢复，对照 [修改功能开关与热键设置.md](修改功能开关与热键设置.md) 第二节。
- **游戏里按热键没反应**：热键可能被改成别的键或被移除了（显示 Not set），改法见 [修改功能开关与热键设置.md](修改功能开关与热键设置.md) 第三节。
- **电脑断网后手机不能用**：官方说明里，账号登录与订阅校验需要联网；配对已完成的情况下核心开关功能在本地仍可用 —— 所以断网场景下「刚要配对」会失败，「已经配着」一般没事。
- **换了手机或重装了 App**：配对不会保留，要重新输一次 PIN，流程照 [手机连接电脑配对教程.md](手机连接电脑配对教程.md)。
