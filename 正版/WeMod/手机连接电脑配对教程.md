## 一、配对前 30 秒自查

配对失败九成出在这三项上，先逐条过一遍再动手：

1. **手机和电脑在同一个 WiFi**。手机用流量、或连了访客网络（很多路由器的访客网络和主网络互相隔离），都配不上。
2. **电脑上的 WeMod 桌面端开着、并且已登录 Pro 账号**。桌面端一关，遥控立刻断。
3. **Windows 防火墙没有拦 WeMod**。第一次连接时 Windows 通常会弹「允许 WeMod 通过防火墙吗」，勾了私有/公用两项再点允许；当初点了取消的，去控制面板的「允许应用通过 Windows 防火墙」里补勾（细节见 [常见问题与连接故障排查.md](常见问题与连接故障排查.md)）。

## 二、取 PIN 与配对步骤

官方流程是「电脑取号、手机填号」，两步：

1. 电脑上打开 WeMod 桌面端，点**右上角的「Connect（连接）」图标**，界面会显示一串 PIN。
2. 手机上打开已装好的 WeMod 遥控端（装法见 [下载与安装教程.md](下载与安装教程.md)），把这串 PIN 输进去。
3. 配对成功后，你正在玩的游戏和它的修改项会直接显示在手机屏幕上，之后就能在手机上开关了。

PIN 是每次连接时现给的，不是固定密码 —— 换一次会话就换一串，取号处没有「记住上次的号」这回事。

## 三、连上之后怎么用

- **开关修改项**：手机列表里每个修改项都有开关，点一下开、再点一下关，效果和在电脑上点完全一样。
- **调数值**：需要精确数值的修改项（官方叫 precision mods，Pro 功能）可以在手机上直接改数字。
- **看状态**：修改项的开启状态、说明文字实时刷新，不用切回电脑确认。
- **省屏幕**：游戏全屏时不想切出来启动修改器，可以在手机上发起。

操作细节和「电脑上还有哪几种开关方式」是同一套概念，对照着看 [修改功能开关与热键设置.md](修改功能开关与热键设置.md)。

## 四、官方写明的几条生效边界

这几条来自官方支持文档，配对前知道能省不少排查时间：

| 情况 | 结果 |
|---|---|
| 电脑端 WeMod 关闭 | 遥控失效，手机端连不上 |
| 联网中断 | 账号登录与订阅校验需要联网；配对完成后，核心开关功能在本地仍可用 |
| 免费账号 | Remote 不可用（属 Pro 功能） |
| Amazon Fire、Windows Mobile 等平台 | 官方标注不支持 |
| 手机端连不上时的兜底 | 用手机浏览器打开官方兜底页，地址见下一段 |

兜底地址：官方支持文档当前给的是 `remote.wand.com`；早期社区帖里给的是旧域名 `remote.wemod.com`（品牌改名前后的两种叫法）。以官方文档当时显示的为准，页面打不开就先按 [常见问题与连接故障排查.md](常见问题与连接故障排查.md) 排查网络与防火墙。
