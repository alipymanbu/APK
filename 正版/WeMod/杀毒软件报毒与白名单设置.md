## 一、为什么会被报

WeMod 这类工具要读写游戏进程，这在杀软眼里和恶意软件的行为特征高度相似，所以被标成「可疑」「特洛伊」「潜在不受欢迎程序」都很常见。这不代表你的文件一定有问题，也不能反证它一定干净 —— **判断只能靠下面这几步**。

## 二、先判断：是不是误报

1. **看来源**：包是不是从官网 [www.wemod.com](https://www.wemod.com/) 或本页头部的 [WeMod 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0aeb494c59a0) 拿的。来源不明的先别急着加白。
2. **多引擎复查**：把可执行文件传到 [VirusTotal](https://www.virustotal.com/) 让几十家引擎同时扫一遍 —— 卡巴斯基官方论坛里，遇到 Wand.exe 被报 `PDM.Trojan.Win32.Generic` 的用户走的就是这条路径，版主的建议也是先做这个复查再反馈。
3. **只有一个引擎报、且报的是「行为启发」类名称**：通常是误报特征。多个主流引擎都报具体家族名，那就按安全事件处理，别加白。

判断标准一句话：**来源可信 + 多引擎只有零星启发式报 → 按误报处理走加白；否则不要加白。**

## 三、加白名单：要加哪几个位置

Windows Defender（其他杀软路径类似，找「排除项 / 信任区 / 隔离区」）：

1. `设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护 → 管理设置`；
2. 拉到 **排除项** → `添加或删除排除项` → 添加文件夹；
3. 依次加入官方社区人员给的这两个目录：

```text
C:\Users\<你的用户名>\AppData\Local\WeMod
C:\Users\<你的用户名>\AppData\Roaming\WeMod
```

品牌改名后目录名可能跟着变（Wand），以你本机 `AppData` 下实际存在的那个为准；找不到就两个都看一眼。**加白的范围只到这两个应用数据目录**，不用把整个磁盘或游戏目录都豁免出去。

被误删的文件先去杀软的**隔离区**恢复，再加排除项 —— 只加排除不恢复，程序还是缺文件。第三方杀软（卡巴、火绒等）在它自己的「信任区 / 排除项」里做同样的事；卡巴用户的个案里，升到新版主程序后仍被拦的，走厂商的样本反馈通道申诉。

## 四、还有一类拦截不在杀软里

社区里官方人员确认过的一个具体场景：**AdGuard for Windows** 对游戏的 `.exe` 开了流量过滤（或开了 `Filter localhost`），WeMod 就注入不进去，现象是「修改一直卡在载入」。处理步骤：

1. 打开 AdGuard → 设置（齿轮）→ 常规设置；
2. 拉到底 → **高级设置**；
3. 找到 **Filter localhost（过滤 localhost）**，关掉；
4. 同时保证 WeMod/Wand 在 AdGuard 的白名单里。

所以排查这类「卡在载入」时，除了杀软，把流量过滤 / 广告拦截类工具也算进嫌疑名单（浏览器插件一般不影响，装在系统层的才会）。完整排查顺序见 [修改不生效与闪退崩溃怎么办.md](修改不生效与闪退崩溃怎么办.md)。

## 五、临时关闭的边界

官方在「报告问题前先试这几步」里允许**暂时**关掉杀软做对照测试 —— 目的只是确认拦截是不是元凶，测完就该把实时防护开回来、靠排除项长期解决。别把「关掉安全软件」当成常规配置。

顺带一提，杀软拦截也会导致另一个症状：游戏根本没被扫出来，列表里找不到它 —— 那种情况看 [游戏检测不到怎么手动添加.md](游戏检测不到怎么手动添加.md)。
