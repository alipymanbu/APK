## 一、先确认这个游戏该不该出现

WeMod 只覆盖一部分游戏，列表里没有它可能是正常结果。官方给出的支持范围：

| 支持 | 不支持 |
|---|---|
| 单机 PC 游戏 | 主机游戏（PlayStation / Xbox / Switch） |
| Steam、Epic、GOG、Ubisoft Connect 购买的版本 | 手机游戏、浏览器游戏、VR 游戏 |
| | 带反作弊保护的游戏 |
| | 以多人联机为主的游戏 |

在游戏页搜索框里搜一下名字：**搜得到** = 已支持或在排队做；**搜不到** = 官方列的四种原因之一 —— 暂不支持、刚发售还在做、数据库里用的是另一个名字、带反作弊。这几种都不是你的操作问题。

还有一种看着奇怪但**不是故障**的情况：库里出现你没买、没装的游戏。官方解释是检测走的是系统注册表、平台元数据和历史安装记录，同一作品的不同版本也会并排显示（比如原版与「决定版」各占一条）。忽略它们即可。

## 二、检测不到时手动指定游戏

官方的「Adding a game manually」流程，检测不到就走这条：

1. 打开 WeMod，进入那个游戏的页面；
2. 点 **Add Game（添加游戏）**；
3. 选 **Add Game Manually（手动添加）**；
4. 把游戏的 `.exe` 拖进提示框，或点浏览手动定位。

**桌面图标不是 exe** —— 那是启动器。在图标上右键 →「打开文件所在位置」，跳过去再选真正的 `.exe` 就快很多。

官方给的默认安装路径：

```text
Steam:      C:\Program Files (x86)\Steam\steamapps\common\[游戏名]
Epic:       C:\Program Files\Epic Games\[游戏名]
Ubisoft:    C:\Program Files (x86)\Ubisoft\Ubisoft Game Launcher\games\[游戏名]
```

右上角出现「Game not found」时也有同一个入口：点旁边的 **Fix** 按钮，再选「Add Custom Installation」手动找 exe，或直接把 exe 拖进 Fix 面板（社区里官方人员给的步骤）。

## 三、Game Pass / 微软商店的游戏扫不到

这一类比 Steam 麻烦，原因是商店把游戏装在 `WindowsApps` 目录下，那是隐藏且受权限保护的文件夹。社区里验证过的两条路：

1. **用管理员身份启动 WeMod**（右键 → 以管理员身份运行），先在任务管理器里结束所有 WeMod 进程再启动；
2. **把 WeMod 升到最新版** —— 官方开发人员在社区确认过旧版本存在「商店游戏检测不到」的问题，后续版本（当时是 7.0.11）修过。现在遇到同样现象，第一件事仍是先更新。

另外有用户反馈：先把 WeMod 加进杀毒软件的排除项，商店游戏才会被扫到，详见 [杀毒软件报毒与白名单设置.md](杀毒软件报毒与白名单设置.md)。

## 四、游戏页那条「Setup Information」提示别直接关掉

进入游戏页时偶尔会弹一个说明框，写的是**这个游戏特有的启动要求**，比如「必须先启动游戏再连 WeMod」「某个修改项在本作里有限制」。用之前扫一眼，很多「按了没反应」就是启动顺序不对。

误关了还能再看：断开与游戏的连接再重连，或点游戏页标题旁的 **`?`** 图标 → **Setup Information**。
