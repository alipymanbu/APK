## 一、设置入口在哪

长按主屏幕任意空白处，就会弹出设置 —— 这是 Olauncher 官方在 F-Droid 页面里专门标注的「Important」操作，也是整个应用唯一不好找的地方：桌面上除了几个应用名什么都没有，设置藏在长按里。

记住官方那句提示就够用：「基本靠滑动和长按就能搞定」。

## 二、主屏幕应用管理

Olauncher 的主屏不是图标网格，而是一列文字形式的应用名，最多放 8 个。每个位置都由你自己指定：

| 想做什么 | 怎么做 |
| --- | --- |
| 换掉某个位置的应用 | 长按那个应用名，在弹出的选项里更换 |
| 重命名应用 | 同样长按后选重命名，改的是桌面显示名，不影响应用本身 |
| 隐藏不想看到的 | 长按应用名选隐藏；隐藏后去设置里还能找回来（见下） |
| 看全部应用 | 主屏往上滑，调出应用列表，顶部带快速搜索框 |
| 打开应用 | 直接点应用名 |

双开应用（应用分身）与工作资料（work profile）里的应用也会出现在列表里，不需要额外设置。

列表与搜索的两个细节：应用列表按名称排序，顺序看着不对多半是新装应用还没刷新，重启一次手机即可（官方在 6.4.x 里修过抽屉排序问题，旧版遇到顺序异常不奇怪）；顶部搜索按应用名匹配，搜不到时换应用原名或英文名再试 —— 拼音搜索是在 6.x 里持续改进的功能（v6.7.1 更新说明），v5.3.2 支持到什么程度以实际为准。

隐藏掉的应用去哪了：长按空白处进设置，点顶部的「Olauncher」字样，里面是已隐藏应用的列表，可以取消隐藏。这一点官方 FAQ 单独列过条目，因为入口确实太隐蔽，详见[常见问题与排错](常见问题与排错.md)第四节。

## 三、手势总表

v5.3.2 里的手势就这几条，官方介绍里逐条列过：

| 手势 | 作用 |
| --- | --- |
| 长按空白处 | 打开设置 |
| 上滑 | 打开全部应用列表 + 快速搜索 |
| 下滑 | 拉下系统通知栏 |
| 左滑 / 右滑 | 打开你在设置里指定的应用 |
| 双击屏幕 | 锁屏（需要先开启辅助功能权限，默认关着） |

两点提醒：

- 双击锁屏用不到就不必开权限，不影响其他功能，权限说明见[常见问题与排错](常见问题与排错.md)第三节；
- 这里说的是 Olauncher 自己的桌面手势，和系统级的全面屏导航手势（侧滑返回、上滑回桌面）是两回事。装了第三方桌面后系统手势失灵是另一类问题，在[常见问题与排错](常见问题与排错.md)第二节单独讲。

## 四、显示与外观设置

进设置后能看到的项目大致是这些，都是即时生效：

- **文字大小**：主屏应用名、日期时间的大小；
- **应用对齐**：左对齐 / 居中 / 右对齐；
- **状态栏**：显示或隐藏顶部状态栏；
- **深色 / 浅色主题**：两套配色切换；
- **日期时间与屏幕时间**：决定主屏上显示哪些信息，屏幕时间是当日使用时长统计。

改完不满意就再进设置改回来，没有一键还原，项目少，逐项恢复也就几步。注意这条定制边界：到这里为止 —— 图标包、通知红点、小组件这类常见桌面功能不在其中，原因与替代方案见[没有图标包和通知红点怎么办](没有图标包和通知红点怎么办.md)。

## 五、每日壁纸

Olauncher 每天自动换一张壁纸。两个使用要点：

- 每日壁纸需要联网获取，在意流量的可以不用它；
- 想固定某张图，按官方 FAQ 的说法，直接从手机系统设置或相册里设壁纸即可，不依赖 Olauncher 自己的设置项；
- 至于图源，有第三方文章称是 Bing 每日壁纸，官方介绍里没有写明，以应用实际表现为准。

## 六、藏起来的小功能

为了保持主屏干净，Olauncher 把一些小众功能收起来了，设置界面上看不到。官方给的位置是：进设置后打开 **About 页面**，那里有完整的功能清单和官方 FAQ。

你现在用的 v5.3.2 属于 5.3 系列，和 6.x 相比功能面少一些（没有私密空间、横屏模式这些），但设置结构是一样的。如果这篇里的某个选项在你的设置里找不到，多半是版本差异，以你手机上实际显示的为准。
