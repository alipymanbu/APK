## 一、想换回原来的桌面 / 想卸载

Olauncher 只是一个桌面应用，卸载它不影响手机里的任何数据。顺序做对就省事：

1. 先把默认桌面改回去：系统「设置」→「应用」→「默认应用」→「主屏幕应用」，选回系统桌面或你原来用的桌面；
2. 再到应用列表里正常卸载 Olauncher。

不先改默认直接卸载，部分手机会拒绝，或者卸载完桌面短暂错乱。如果你只是暂时不想看到它，也可以不卸载，把默认桌面切回去即可，它就退到后台不出现了。

## 二、全面屏手势失效（小米等设备高发）

装了 Olauncher 之后，系统级的全面屏手势（侧滑返回、上滑回桌面）可能失灵。对这个问题，官方 FAQ 的说法很明确：

- 部分设备在装了第三方桌面后**不支持系统导航手势**；
- 这个问题**只能由设备厂商通过系统更新解决**，桌面应用侧没有修复办法。

用户反馈集中在小米 / MIUI 上（有用户明确反馈「小米全面屏手势用不了」）。能做的替代：

| 做法 | 说明 |
| --- | --- |
| 把导航方式改成三键导航 | 系统设置里的导航方式切换，先用返回键顶着 |
| 用桌面的下滑手势替代下拉 | Olauncher 自己的上滑（应用列表）/ 下滑（通知栏）不受影响，它们是桌面内部动作 |
| 留着官方支持页等系统更新 | 见 GitHub 仓库的 Issues 区 |

判断是哪类问题：如果失灵的是「侧滑返回」这类系统手势，按本节处理；如果失灵的是 Olauncher 自己的上滑抽屉，先重启一次手机再试。

## 三、双击锁屏没反应

双击锁屏走的是系统「辅助功能（无障碍）」权限，默认是关闭的。按这个顺序检查：

1. 系统设置 → 无障碍（辅助功能）→ 找到 Olauncher → 允许；
2. 回到主屏再双击试试；
3. 还不行，检查省电策略：部分系统会悄悄关掉无障碍服务，把 Olauncher 加进电池白名单 / 自启动名单后再试。

关于这个权限的隐私问题，官方说明是：它**只**用于双击熄屏这一个动作，是可选项，默认关闭，不收集也不共享任何数据。不开这个权限，其余功能照常可用。

## 四、隐藏的应用去哪了

隐藏不是卸载，应用本体还在手机上。找回入口相当隐蔽：

1. 长按主屏空白处打开设置；
2. 点设置顶部的「Olauncher」字样；
3. 里面就是已隐藏应用的列表，取消勾选即可放回主屏。

这是官方 FAQ 列出的第一条，因为几乎所有人都找不到这个入口。日常隐藏 / 取消隐藏的操作在[设置与手势详解](设置与手势详解.md)第二节。

## 五、屏幕时间显示不对

v5.3.2 的屏幕时间（当日使用时长）有一个已知问题：官方在 v5.3.4 的更新说明里，第一条修复就是「fix: screen time」。所以数字明显不对时不用反复检查设置，属于这个版本的已知缺陷，后续版本已修。

两个相关事实：

- v6.3.14 起屏幕时间还能长按指定「点了它就打开哪个应用」，v5.3.2 没有这个玩法；
- 如果不需要这个统计，直接在设置里把屏幕时间显示关掉即可。

## 六、每日壁纸与流量

- 每日壁纸每天联网换一张，在意流量的关闭它，改用系统壁纸；
- 想固定某张图，从手机系统设置或相册设置即可，不必依赖 Olauncher；
- 壁纸不显示或不变：先确认网络可用，再看设置里每日壁纸的开关状态，操作见[设置与手势详解](设置与手势详解.md)第五节。

## 七、想要小组件、天气、文件夹怎么办

Olauncher 本体刻意不做这些，图标包、通知红点的情况也一样 —— 这篇单独讲：[没有图标包和通知红点怎么办](没有图标包和通知红点怎么办.md)。简版结论：作者另有一个付费的 **Pro Launcher**（包名 `app.prolauncher`），在 Olauncher 的基础上加了小组件、天气、文件夹等功能，需要这类功能可以考虑它；装之前先翻一遍 Olauncher 设置的 About 页，确认隐藏功能里没有你想要的那样。

## 八、其他零碎问题

- **桌面只剩几个应用名，找不到设置**：长按空白处，见[设置与手势详解](设置与手势详解.md)第一节；
- **应用列表里搜不到某个应用**：确认它没被隐藏（第四节），再看它是否装在工作资料里；搜索匹配不上时换应用原名或英文名再试，见[设置与手势详解](设置与手势详解.md)第二节；
- **工作资料（work profile）里的应用卸载、应用信息打不开**：官方在 v6.7.1 修过这类问题，v5.3.2 碰到时只能换新版，或在系统「设置 → 应用」里手动操作；
- **版本问题**：网盘那份是 v5.3.2，官方最新是 6.x，想升级就去 GitHub Releases 或应用市场，渠道对照与跨渠道升级的注意点见[下载与安装教程](下载与安装教程.md)第四节。
