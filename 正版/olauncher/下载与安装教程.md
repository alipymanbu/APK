## 一、你拿到的是哪个版本

本篇引用的 Olauncher 安装文件资源对应下面这一版，版本号、包名、体积都以它为准：

| 项目 | 值 |
| --- | --- |
| 版本 | v5.3.2 |
| 包名 | `app.olauncher` |
| 体积 | 2.13 MB |
| MD5 | `9EEBF1F7F1473799110E3B31091C9106` |

官方当前最新版已到 6.x，比 5.3 系列多了私密空间（Android 15+）、横屏模式 APK、屏幕时间长按跳转等新内容；v5.3.2 是 5.3 系列的基础功能形态，这些新东西都没有。装哪个版本都行，但同一台手机不要新旧两版混装。

Olauncher 是开源软件（GNU GPLv3 许可），官方发布页在 [GitHub 仓库](https://github.com/tanujnotes/Olauncher)，想核对版本说明可以去看它的 Releases 页面。

## 二、安装步骤

1. 从 [Olauncher 安装文件资源（夸克网盘）](https://pan.quark.cn/s/fd8438afe8b7)把安装包转存到自己的网盘，再下载到手机；
2. 在手机上点开这个 APK。如果系统提示「未知来源应用」，按提示允许当前文件管理器或浏览器安装应用；
3. 装完点「打开」，系统一般会直接弹出「选择主屏幕应用」，选 Olauncher 并选「始终」；
4. 如果没有弹出，按一下手机的 Home 键，同样会弹出让选桌面；
5. 回到主屏，你会看到只剩几个文字形式的应用名，没有图标 —— 这就装好了。

装完后先去[设置与手势详解](设置与手势详解.md)把设置入口找到（长按空白处），不然容易在空荡荡的桌面上找不到门。

## 三、把它设为默认桌面

错过首次弹窗也没关系，手动设一次：

1. 打开系统「设置」→「应用」→「默认应用」（部分品牌叫「默认应用管理」）；
2. 找到「主屏幕应用」或「桌面 / Launcher」这一项；
3. 选 Olauncher。

不同品牌的路径略有差别：MIUI 在「桌面」设置里有「默认桌面」，华为在「应用和服务」→「默认应用」里，Vivo/OPPO 大多在「应用管理」的默认应用分类下。找不到就用系统设置顶部的搜索框搜「默认」。

之后按 Home 键回到的就是 Olauncher 的桌面。哪天想换回原来的桌面再卸载，步骤在[常见问题与排错](常见问题与排错.md)第一节。

## 四、官方渠道有哪些

除了网盘这份安装包，Olauncher 官方还在这几个渠道发布，各渠道给的都是当时的最新版（目前是 6.x，不是 v5.3.2）：

| 渠道 | 地址 | 说明 |
| --- | --- | --- |
| Google Play | [play.google.com](https://play.google.com/store/apps/details?id=app.olauncher) | 官方主渠道，自动更新 |
| F-Droid | [f-droid.org](https://f-droid.org/packages/app.olauncher) | 开源应用市场，F-Droid 侧构建签名 |
| IzzyOnDroid | [apt.izzysoft.de](https://apt.izzysoft.de/packages/app.olauncher) | 第三方开源源 |
| GitHub Releases | [github.com/tanujnotes/Olauncher/releases](https://github.com/tanujnotes/Olauncher/releases) | 直接下 APK，能选旧版本 |

近期官方版本要求 Android 7.0 及以上（以 F-Droid 页面当时显示为准）。这几条渠道与网盘那份包同属官方或开源发布体系，只是版本进度不同。

两点实用提醒：

- 网盘这份安装包不会自己更新。想跟随官方版本，就用上表渠道安装（F-Droid 要先装它的 F-Droid 客户端，再在客户端里搜 Olauncher）；
- 跨渠道升级时签名可能对不上（比如 F-Droid 的包由 F-Droid 签名，GitHub 的包由作者签名），系统会要求先卸载再装 —— 卸载重装后主屏的那几个应用名要重新指定一次，动手前先把自己主屏放了哪几个应用记下来。

## 五、安装环节容易碰到的提示

- 提示「应用未安装」：先确认下载的包完整（2.13 MB 左右），再确认手机系统版本满足要求；旧系统装不上时只能换官方渠道的最新版试试；
- 装完桌面没变化：绝大多数是没把默认桌面切过来，按第三节操作一遍；
- 装完想先认认手势和设置：直接看[设置与手势详解](设置与手势详解.md)；
- 遇到桌面手势异常、卸不掉：去[常见问题与排错](常见问题与排错.md)对照处理。
