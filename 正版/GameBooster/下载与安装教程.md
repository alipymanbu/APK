## 一、下载前先确认两件事

1. **系统版本**：官方商店目前标注 Android 7.0 及以上可装；也有第三方下载站标成 5.0+，两个口径不一致时以官方商店为准。
2. **装的是哪个包**：G19 Mobile 有两个独立应用——免费版 Game Booster 4x Faster（包名 `com.g19mobile.gamebooster`）和付费的 Pro 版（包名 `com.g19mobile.gameboosterplus`）。本文档对应的是免费版，装完后广告与功能边界见[常见问题与排查.md](常见问题与排查.md)。

本套文档对应的安装包信息如下，网上搜到的官方最新版可能与此不同：

## 二、把安装文件拿到手机上

网盘里的文件不能直接装，要先转存到自己的网盘再下载到手机：

1. 打开 [GameBooster 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0e49a9a2c7cf)的分享页。
2. 勾选文件，点「保存到网盘」，转存到自己账号下的任意文件夹。
3. 打开手机上的夸克网盘 App，找到刚转存的 APK 文件，点下载。
4. 下载完成后在通知栏或「传输记录」里点开文件，进入安装。

## 三、安装步骤

1. 点开 APK 后系统会问「是否允许安装」，首次会跳到「安装未知应用」设置页。
2. 找到你用来下载的这个应用（比如夸克网盘、浏览器、文件管理器），打开它的「允许安装未知应用」开关。
3. 返回重新点开 APK，点「安装」，等进度走完。
4. 安装完成点「打开」，应用进入首次启动流程。

如果提示「解析包失败」或「安装包损坏」，多数是下载中断导致文件不完整，重新下载一次；确认无误后可以核对 MD5（见下一节）。

## 四、核对安装包（可选）

想确认手里的文件和本文档对应的是同一份，可以核对 MD5：

- 用支持「文件校验」功能的文件管理器（多数第三方文件管理器都有这个入口），对 APK 计算 MD5。
- 结果应为 `e90d4b8435f121bc5c0e57ff75a676a4`。
- 对不上说明文件不完整或不是这一版，重新下载即可。

## 五、首次启动要给的权限

Game Booster 4x Faster 属于「管后台、画悬浮窗」的工具，首次打开会陆续向你要几项权限，每一项给不给、不给会怎样，在[悬浮窗与权限设置.md](悬浮窗与权限设置.md)里有一张总表。建议至少先给「显示在其他应用上层」（悬浮窗），否则加速过程中的浮层信息看不到。权限给完后就可以从[一键加速与游戏启动.md](一键加速与游戏启动.md)开始上手；想改画质预设（分辨率 / HDR / FPS）则看[GFX画质设置指南.md](GFX画质设置指南.md)。
