## 一、权限总表：给谁、管什么

| 权限 | 应用拿它做什么 | 不给会怎样 |
| --- | --- | --- |
| 显示在其他应用上层（悬浮窗） | 游戏中显示 HUD 浮层信息 | HUD 看不到，其他功能基本正常 |
| 使用情况访问（Usage access） | 识别你是否切离了游戏 | HUD 无法感知切换，部分监控功能受影响 |
| 勿扰（Do Not Disturb） | 专注模式在游戏期间开启勿扰 | 专注模式不可用 |
| 修改系统设置 | Ultra 启动模式关亮度自适应、屏幕常亮、关自动旋转 | 该启动模式的部分动作不生效 |
| 网络 | 按官方说明从服务器加载游戏配置 | 无法加载在线配置 |
| 后台清理 | 请求系统结束后台应用进程以释放内存 | 一键加速基本失效 |

前三行是「特殊权限」，要在系统设置里手动开；后三行在首次使用对应功能时按弹窗给即可。

## 二、悬浮窗权限怎么开

应用内弹窗会直接带你跳到系统设置页；如果跳过了，手动路径是：

1. 打开系统「设置」→「应用管理」（或「应用程序」）。
2. 找到 Game Booster 4x Faster，进入「权限」或「特殊权限」。
3. 找到「显示在其他应用上层」（不同品牌叫法不同：也有写「允许显示悬浮窗」「出现在顶层 / Appear on top」的），打开开关。

个别品牌（如小米/MIUI 系）还会额外要求「后台弹出界面」权限，不开的话游戏里点悬浮窗可能没反应，同样在应用详情的权限页里能找到。

## 三、电池优化也要关

游戏期间应用要在后台维持悬浮窗与通知运行，省电策略激进的系统会直接把它杀掉，表现为「HUD 出现几秒就消失」。按官方说明，HUD 运行时会挂一条**带停止按钮的常驻通知**——这条通知还在，说明应用活着；通知没了，多半就是被系统清了。处理办法：

1. 系统设置 → 应用管理 → Game Booster 4x Faster → 「电池」。
2. 选择「不受限制 / 无限制」，或关闭「电池优化」。

国产品牌还有各自的「自启动 / 后台运行」白名单（通常叫省电策略、应用速冻、智能限制之类），各品牌的具体入口在[后台被杀与电池白名单.md](后台被杀与电池白名单.md)里有一张品牌对照表。

## 四、HUD 开了但不显示，按这个顺序查

1. 确认悬浮窗权限已开（见第二节）。
2. 看通知栏：HUD 的常驻通知还在吗？不在，说明应用已被系统杀掉，先按[后台被杀与电池白名单.md](后台被杀与电池白名单.md)放行电池限制。
3. 确认应用是在「从它的列表启动游戏」之后才挂 HUD——直接在桌面上打开应用不会显示浮层。
4. 确认电池优化与后台白名单已放行（见第三节）。
5. 重启一次应用再进游戏试。
6. 仍不显示的，看[常见问题与排查.md](常见问题与排查.md)里的其他线索。

另外注意：HUD 上显示的数值随设备与系统版本而定，设备提供不了的读数（比如某些机型的电池温度）不会显示，这不代表功能坏了。
