## 一、GFX 工具能改什么

按官方介绍，GFX 工具提供四类画质预设：

| 预设项 | 官方说法 | 适合什么情况 |
| --- | --- | --- |
| 分辨率 1080 | 更改游戏渲染分辨率 | 想要更细腻画面、且机器带得动 |
| HDR 画质 | 开启 HDR 画质与特效 | 低端设备上官方称可开启，实际观感因机型而异 |
| Extreme FPS | 解锁更高的帧率档位 | 高刷新率屏幕机型优先尝试 |
| 风格（Style） | 更改画面色彩风格 | 喜欢偏冷/偏艳等不同色调 |

这四项是应用侧给出的预设选项，最终画面表现由游戏与设备共同决定；能设到哪一档，以你游戏内实际可用的选项为准。两点背景：

- 官方更新日志显示，GFX 工具最初就是为 Free Fire、吃鸡类（Battlegrounds）、使命召唤手游这类游戏做的——所以部分游戏在工具里没有对应入口，属正常现象。
- 部分版本里还会多出阴影、抗锯齿（MSAA）这类扩展项，有没有取决于机型、系统版本与游戏，以你机器上的实际显示为准。

## 二、通用操作步骤

1. 打开应用，进入 GFX 工具（或「游戏设置」里的画质入口，名称以应用内显示为准）。
2. 选要调整的游戏。
3. 按上面四类逐项选择想要的档位。
4. 应用保存预设，然后从应用里启动游戏，让预设生效。

## 三、改了游戏内画质之后，必须重新应用一次

这是官方页面上唯一反复强调的使用提示：**如果你在游戏自己的设置里改过任何画质选项，先完全关闭游戏，再从本应用重新应用一遍预设，然后才进游戏。**

顺序错了的典型现象就是「明明设了 Extreme FPS，进游戏还是老样子」——游戏内设置把预设覆盖了。处理办法固定：

1. 从后台彻底关闭游戏（不是回到桌面）。
2. 打开 Game Booster 4x Faster，重新应用 GFX 预设。
3. 再进游戏。

更多「设置了不生效」的情况收在[常见问题与排查.md](常见问题与排查.md)里。

## 四、低端机怎么选

- 优先调「风格」和「分辨率」这两项，风险最小；HDR 和 Extreme FPS 对设备要求更高，带不动时画面反而更卡。
- 新版应用里官方对 GFX 的口径是「根据内存、CPU 核数、屏幕刷新率给出保守的建议起点，最终由你自己在游戏里应用」；旧版本则是直接给出预设选项。无论哪种，建议一次只改一项，进游戏确认有改善再继续改下一项。改完记得看看悬浮窗 HUD 与各项权限是否配好，见[悬浮窗与权限设置.md](悬浮窗与权限设置.md)。

## 五、账号安全与封号风险怎么说

官方口径是「账号安全、不影响账号」，新版描述还明确了应用不修改游戏文件。第三方社区（专做这类画质工具的站点，基于 2023–2026 年的玩家报告总结）给出的规律更细，两边并列供你参考：

| 行为 | 社区观察的风险 |
| --- | --- |
| 基础画质改动（分辨率 / FPS / 风格），设置一次不再动 | 极低 |
| 一局内反复快速切换画质配置五次以上 | 低到中（异常的配置改动容易被反作弊标记） |
| 画质工具与任何外挂 / 改机工具同时使用 | 高（出事的其实是外挂，但会连累账号） |
| 游戏大版本更新后继续沿用旧版工具改出的配置 | 中（旧配置文件可能正好被新版反作弊盯着） |

两边口径冲突时怎么取舍：官方宣传不等于游戏厂商的背书，社区规律也只是观察不是保证。稳妥做法是画质设置一次到位、不反复横跳，竞技排位前先查该游戏自己的用户协议，以游戏厂商的规则为准。
