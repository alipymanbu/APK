# Game Booster 4x Faster 后台被杀与电池白名单

> 本篇解决一类最常见的问题：Game Booster 4x Faster 开着开着就被系统杀掉，Auto-Boost 失灵、HUD 消失。根因是省电策略，跟应用本身坏了没关系。悬浮窗权限相关的内容见[悬浮窗与权限设置.md](悬浮窗与权限设置.md)。

## 一、为什么这类应用特别容易被杀

Game Booster 4x Faster 干活的方式决定了它必须常驻后台：按官方说明，HUD 要以一条带停止按钮的常驻通知运行，自动加速要在你启动游戏时立刻介入。而省电系统的逻辑恰恰相反——凡是不在前台、又要长期活跃的应用，都是清理候选。所以它被杀的表现集中在三处：

- HUD 出现几秒就消失，通知栏里的常驻通知不见了；
- Auto-Boost 开了但过一会儿自己变灰；
- 加速按钮点了没反应。

## 二、通用做法：解除电池优化

所有 Android 都有这一层，先把基础项做掉：

1. 系统设置 → 应用管理 → Game Booster 4x Faster → 「电池」。
2. 选「不受限制」（部分系统叫「无限制」「不优化」），或直接关掉「电池优化」开关。

做完这一步，原生 Android（Pixel 类）基本就够了；国产品牌的系统还要看下一节。

## 三、国产品牌的额外白名单

菜单名随系统版本差异很大，以下按品牌列入口，找不到时用设置里的搜索功能搜「自启动」或「电池」：

| 品牌 | 要做的几件事 |
| --- | --- |
| 小米 / 红米（MIUI / HyperOS） | 应用详情里开「自启动」；省电策略设为「无限制」；最近任务里把应用卡片下拉锁定 |
| 华为 / 荣耀（EMUI / MagicOS） | 「启动管理」改为手动管理，允许自启动、关联启动、后台活动三项全开 |
| OPPO / 一加 / realme（ColorOS 系） | 「耗电管理」里允许完全后台运行；多任务界面锁定应用卡片 |
| vivo / iQOO（OriginOS 系） | 「后台高耗电」里允许该应用；开启自启动 |
| 三星（One UI） | 「电池」→「后台使用限制」里，把它从「深度休眠」和「休眠应用」列表中移出 |

锁最近任务卡片是个通用小技巧：在多任务界面长按或下拉应用卡片，出现锁形图标即锁定，系统清理时就会跳过它。

## 四、Auto-Boost 失效的修复顺序

有第三方教程专门给过这个问题的处理顺序，实测思路对国产系统同样适用：

1. 按第二、三节解除电池与后台限制，MIUI / EMUI 记得把「自启动」也打开。
2. 完全退出应用（从最近任务划掉），重新打开。
3. 进应用把 Auto-Boost 开关重新开一次。

如果做完这些 Auto-Boost 还是反复失效，多半是系统更新后白名单被重置了，重新过一遍第三节即可；HUD 能出现但马上消失的，回[悬浮窗与权限设置.md](悬浮窗与权限设置.md)按第四节顺序查，加速本身没反应的看[常见问题与排查.md](常见问题与排查.md)第一、三节。
