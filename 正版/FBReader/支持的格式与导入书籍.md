## 一、先查表：你要读的格式在不在里面

下表是官方给出的安卓版支持情况（Android 一列，截至 2026 年 9 月，以官方页面当时显示为准）：

| 格式 | 安卓版支持 | 备注 |
| --- | --- | --- |
| ePub | 支持 | 主力格式之一；带 Readium LCP 保护的 ePub 从 3.7 起也能开 |
| ePub3 | 部分支持 | 官方标注为「部分」 |
| fb2 / fb2.zip | 支持 | 主力格式之一；部分设备的 3.8 版有「看不到 fb2」的坑，见第五节 |
| mobi | 支持 | 只开无 DRM 的 mobi，Kindle 商店那种带 DRM 的开不了 |
| 纯文本 txt | 支持 | |
| MS Word `.doc` | 支持 | 只有老的 `.doc`，**`.docx` 不支持** |
| RTF | 支持 | |
| PDF | 支持 | Free 版需装 PDF 插件；Premium 内置 |
| DjVu | 支持 | 两个版本都要装 DjVu 插件 |
| 漫画 `.cbz` | 支持 | Free 版需装漫画插件；Premium 内置 |
| 漫画 `.cbr` | 不支持 | 无论哪个版本 |

几个容易踩的点：

- **DRM**：只认 Readium LCP 这一种保护方案，其他 DRM 的 ePub 一律开不了。
- **docx、cbr** 是明确不支持的，转成 doc / cbz 再读，或者换专门的工具转格式。
- 插件怎么配、Free 和 Premium 在格式上差在哪，见 [下载与安装教程.md](下载与安装教程.md) 第四节。

## 二、书怎么进书架：三条路

**路 1：文件管理器直接点开。** 手机里装好 FBReader 后，在文件管理器里点一个 ePub/fb2 文件，选择用 FBReader 打开，书会被登记进书架。

**路 2：应用内导入。** 打开 FBReader，从书架界面进入文件选择，浏览到书所在目录勾选导入。安卓 10 及以上的 3.8 版走的是系统文件选择框架，**第一次会弹授权**，按提示选中你放书的文件夹即可。

**路 3：网络书库 / 云端。** 从 OPDS 书库直接下载进书架，或走官方 Book Network 云端同步，细节见 [书签与跨设备同步.md](书签与跨设备同步.md)。

## 三、书放哪个文件夹最省事

安卓 10+ 上 3.8 及之后的版本用系统存储访问框架（SAF）读文件，它对不同目录的授权能力不一样：

- **`Download` 目录**：系统出于安全考虑**不允许授予整个文件夹的权限**，书堆在这里最容易出现「书架上有、打不开」。
- **自建子目录**（如 `Download/Books`）：官方给出的规避办法就是把书挪进自建子文件夹，然后在书架菜单跑一次 **Rescan（重新扫描）**，FBReader 会自动把挪过的文件和书架条目重新对上。
- **设置里把书的目录加进库路径**：`设置 → 书库` 里添加的文件夹，其中所有文件（包括以后新加的）都会获得访问权；但受系统限制，**不是所有文件夹都能加**。

一句话：**书别平铺在 `Download` 根目录，自己建个 `Books` 子文件夹专门放**，能避开大半授权问题。

## 四、书架上那个三角警告标志是什么

3.8 及之后的版本里，书架上某本书旁边出现警告标志，含义是：**文件看起来在设备上，但应用当前没有权限读它**。三种解法（按省事程度排）：

1. **点那本书，手动选中它的文件** —— 选文件这个动作本身就是一次授权，选完就能读；
2. **把书所在文件夹加进库路径**（`设置 → 书库`）；
3. **把文件挪进可授权的文件夹**再 Rescan（见上一节）。

## 五、fb2 文件在书架上不显示（部分设备）

官方已确认：部分设备上 3.8.\* 版看不到 fb2 文件，别的格式正常。原因是系统文件框架不认识 fb2 这个扩展名。官方给的两个临时办法：

- **把 fb2 打包进 zip**：一个书一个 zip、或多本书合一个 zip 都行，只要文件名以 `.zip` 结尾，框架就能识别，FBReader 能读出里面是同一本书，**书签和进度都保留**；
- **退回 3.7.7 版**：该版本不用系统框架所以不受影响，官方下载页有包；但必须**先卸载 3.8 再装 3.7.7**（安卓不允许直接降级安装），还要关掉自动更新防止又被升上去。

完整的问题排查（包括文件访问权限怎么开）见 [常见问题与解决办法.md](常见问题与解决办法.md)。
