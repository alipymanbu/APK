## 一、网络书库是什么

FBReader 内置「网络书库（Network Library）」功能，走的是 **OPDS 协议** —— 一个专门给阅读器用的在线图书目录格式。连上一个 OPDS 书库后，你可以在书库里直接浏览分类、搜书、下载进书架，全程不用先开浏览器下文件再导入。

它和 [书签与跨设备同步.md](书签与跨设备同步.md) 里讲的 Book Network（官方云书库）是两回事：

| | 网络书库（OPDS） | Book Network |
| --- | --- | --- |
| 是什么 | 别人的在线书目录，公版书库、个人书库都算 | 官方云端，存你自己的书 |
| 要不要账号 | 多数公开书库不用登录 | 要 Google 账号 |
| 能干什么 | 浏览、搜索、下载进书架 | 同步书目、进度、书签 |

## 二、添加步骤

安卓端的入口路径（不同版本菜单叫法略有差异）：

1. 在阅读界面按**返回键**（或点菜单按钮）调出主菜单，选 **「打开网络书库 / Network Library」**；
2. 进入书库列表页，点**右上角菜单**（三个点或图标）→ **「添加目录 / Add catalog」**；
3. 在 **URL** 栏里填入书库提供的 **OPDS 地址**（`https://` 开头的完整地址，以书库方公布为准），有名称栏的顺手起个名字；
4. 确认后书库出现在列表里，点进去就能浏览、搜索、下载。

**内置书库不用加就有**：官方预置了 **Project Gutenberg** 与 **Smashwords** 两个公开书库，装好就能直接逛。

## 三、地址与账号的几个坑

- **地址要完整**：`https://` 开头、一路填到底，漏了协议头或多个 `/` 都会连不上；
- **有的书库要登录**：弹出用户名 / 密码框说明该书库开了认证，按书库方的说明填（有的用邮箱当用户名，密码另发）；
- **书库方给你的不是网址而是 OPDS 地址**：普通网页首页填进去通常打不开，要找书库公布的 feed / OPDS 专用地址；
- **官方 Book Network 的 OPDS 地址是 `https://books.fbreader.org/opds`**，但它强制 Google 认证，填进去能连上也只在登录了 Google 账号的 FBReader 里有意义，拿去喂第三方阅读器没用。

连不上时先自查这三点（地址拼写 → 是否要认证 → 是不是拿网页地址当了 OPDS 地址），九成问题在这。书库能打开但下载的书进不了书架，那是文件访问权限的问题，见 [常见问题与解决办法.md](常见问题与解决办法.md) 第一、二节。

## 四、下载的书和本地导入的书有区别吗

没有 —— 从网络书库下载的书落到你的存储里之后，和从文件管理器导入的书（见 [支持的格式与导入书籍.md](支持的格式与导入书籍.md) 第二节）走同一套书架、同样的格式支持、同样的书签与进度机制。唯一的差别是省掉了「先自己去找文件」那一步。
