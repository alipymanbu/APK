# 书签与跨设备同步

## 一、FBReader 的「书签」就是划线

在 FBReader 里**书签和高亮是同一个操作**：没有单独的书签动作 —— 你要做的是**选中一段文字，然后在弹出的菜单里点「书签」**。选中的这段文字会被标记，同时进入书签列表。

不同平台弹出菜单的形态略有差异：有的平台显示的是**样式名**（用来选书签样式），有的显示一个图标，认准「书签 / Bookmark」那个即可。

桌面版还有一个快捷入口：点工具栏上的书签图标，直接在当前页开头加一个书签。安卓端没有这个工具栏按钮，走选中文字的路子。

## 二、书签样式：内置三种，桌面版可自建

书签带样式（颜色 / 标记方式），内置**三种样式**，添加时可选。需要更多样式的话，**自定义样式在桌面版的设置对话框里新建**；安卓端用内置三种即可。

书签列表的入口在阅读界面的菜单里（书签 / Bookmarks），列表里可以跳转、删除。

## 三、跨设备同步：官方 Book Network

想让手机、平板、电脑上的**书、阅读位置、书签**保持一致，用官方的 Book Network（`books.fbreader.org`）：

| 项 | 说明 |
| --- | --- |
| 同步什么 | 书目列表、阅读位置、书签、自定义书架（按你的开关逐项同步） |
| 书存在哪 | 书文件存在你自己的 Google Drive 空间里，你可直接在 Drive 里看到；元信息、封面、阅读位置存在官方服务器上 |
| 权限范围 | 官方声明只申请「上传新文件」和「读取 FBReader 自己创建的文件」的权限，不碰你 Drive 里的其他内容 |
| 怎么访问 | 手机端在 FBReader 设置里登录同步；浏览器打开 `books.fbreader.org` 可以直接管理书库、从电脑往里加书 |

使用前提有两处要有数：

1. **依赖 Google 账号**（书在 Google Drive），设备得能连上 Google 服务；
2. Android 端的集成比桌面端「稍复杂」（官方原话），登录入口在应用的同步 / 网络设置里，遇到登录不上的情况多与设备的 Google 服务状态有关。

不想用云端的话，同一个文件夹里的书用文件管理器拷走、拷回来，位置和书签数据存在本地也会跟着书走 —— 但这条路**换设备要手动搬**，只适合自己两台设备间倒腾。

## 四、网络书库：不放文件也能读

FBReader 内置网络书库功能（Network Library），支持 OPDS 协议的在线书库可以直接浏览、下载进书架：

- 内置书库有 **Project Gutenberg** 与 **Smashwords** 两个；
- 别的 OPDS 书库可以自己加：打开菜单里的 **Network Library（网络书库）** → 右上角菜单 → **Add catalog（添加目录）** → 填入书库的 OPDS 地址即可；
- 官方 Book Network 自己也有 OPDS 地址 `https://books.fbreader.org/opds`，但它**要求 Google 认证**，填进第三方阅读器用不了，只在登录了 Google 账号的 FBReader 里有意义。

## 五、换机 / 重装前先想清楚进度存在哪

书文件本身放在你的存储里，删应用不会动它，重装后重新授权、书架跑一次 **Rescan** 就能把书找回来（步骤见 [支持的格式与导入书籍.md](支持的格式与导入书籍.md) 第三、四节）。

但**阅读位置与书签存在应用自己的数据里，跟书文件是两回事**：没开同步就重装或换新设备，书能扫回来，进度和书签不保证还在。所以：

- 打算换机、重装、退回旧版本前，先把 **Book Network 同步开起来**（本页第三节），让位置和书签上云；
- 不想用云端的，至少在动手前确认一下当前书签大致读到哪一章，便于手动找回。
