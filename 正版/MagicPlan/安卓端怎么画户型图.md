## 一、先说清楚：安卓端没有扫描功能

网上不少教程会讲「用摄像头扫一遍房间自动生成户型图」——那是 iOS 侧的功能。官方帮助中心的设备支持页写明：**安卓设备不支持扫描（Scan / Auto-Scan）**，原因是这类自动扫描依赖 iOS 设备上的 LiDAR 传感器。

所以你在安卓端找不到扫描入口不是安装出了问题。安卓端添加房间走的是手动路线：方房间、定义拐角、导入描图、填充房间（下文逐一讲）。手动方式画出来的户型图在精度上不吃亏——尺寸都是你输入或用激光测距仪量出来的实际数值。

## 二、新建项目

magicplan 的数据结构是「项目 → 楼层 → 房间」，动手画之前先建项目：

1. 打开应用进入主界面，点 **+ New Project**。
2. 进入项目面板（Project Dashboard），填项目名称、描述、地址。地址不是必填项，但它会用在后续导出的报告里。
3. 在项目里添加楼层（一层户型就一个楼层；画整栋楼时再分多层）。

每个项目下方有一个 **Files 区**，之后导出的所有文件都列在这里（详见[导出格式与分享方法.md](导出格式与分享方法.md)）。

## 三、添加房间的四种方法

### 3.1 方房间（Square Room）

最快的方法，适合户型里占大头的规整房间——卧室、客厅、卫生间基本都是矩形。操作路径：

1. 进入楼层后点 **+ Insert** → **Room**；
2. 选 **Add a square room**，再选房间类型；
3. 矩形房间出现后，接着做四件事里你需要的那几件：改尺寸、连激光测距仪现量、加拐角改形状、拖到平面上的合适位置。

### 3.2 手绘房间（Draw Room，即「定义拐角」）

画不规则房间用这个：逐个拐角点下去，围出一个任意形状的房间。L 形客厅、带拐角阳台的房间都靠它。操作路径：

1. 点 **+ Insert** → **Room** → **Draw Room**，选房间类型；
2. 按顺序点击各拐角位置，背景网格帮你估长度和角度；
3. 画完闭合后，逐段把尺寸改成实际值——网格只是辅助，精度靠你后面输入的数字。

网格的单位换算：公制下一格代表 1 平方米，英制下一格代表 9 平方英尺；单位本身可以在项目设置里切换。

### 3.3 导入描图（Import & Draw）

手里已经有纸质户型图、房产证附图或照片时，把图导入当底稿，在上面描出墙体。这是把旧图纸数字化最省事的一条路。操作路径：

1. 点 **+ Insert** → **Room** → **Import and draw**，现场拍一张或从相册选图（需要相机与相册权限，首次使用会弹窗索要）；
2. **给底图定比例**：把虚线对准图上一段已知长度（比如图上标了的某面墙），输入它的实际尺寸，或连激光测距仪现场量一段；
3. 之后按 3.1 / 3.2 的方式逐间加房间、拼起来；
4. 画完后底图可以在隐藏/显示之间切换，导出时是否带底图也跟随这个选择。

**注意：比例一旦定下就不能改**——官方在文档里专门标了这条警告。定比例时务必用一段可靠的已知尺寸；底图比例设错，整层都得重来。

### 3.4 填充房间（Filler Room / Filler Wall）

壁橱、走廊、飘窗下的小空间这类不好按常规方式画的区域，用填充补上，保证整层面积与周长统计完整。操作路径：点 **+ Insert** → **Room** → **Insert a filler**，选填充房间或填充墙（房间要选类型），然后用蓝色箭头把它拖到空档处，松手自动填满。

### 添加之后的顺序

四种方法可以混用：先用方房间铺大房间，再用手绘补异形区域，最后用填充堵缝隙。

## 四、改尺寸与拼户型

- **改尺寸**：房间创建后随时可以改，点选墙体或房间直接输入数值。先粗后精是常规做法——先把整层的房间都摆出来，再逐间把尺寸改准。
- **拼房间**：把单个房间拖到一起、拼接成整层平面。拼的时候注意保持墙体对齐，后续导出和 3D 视图里才不会出现错缝。

## 五、放对象与测量

- **对象库**：内置家具、结构、标注三类对象（门窗、楼梯、家具、电器等），从库里拖进房间即可。对象尺寸可以按实物修改。
- **量间距**：可以测量对象与墙、对象与对象之间的距离，家具摆位、水电点位确认都用得上。
- **自定义对象**：PRO 订阅可以通过 Object Manager 做自己的对象并在工作区共享，偶尔画图的用户用不上，跳过即可。

## 六、用激光测距仪量得更准

手动输入尺寸的精度取决于你量得准不准。magicplan 的 PrecisionLink 支持连接蓝牙激光测距仪与数字卷尺，把量出来的数值直接进图。哪些型号能用、在应用里怎么连、连不上怎么排查，集中写在[激光测距仪与外设连接.md](激光测距仪与外设连接.md)里。

## 七、2D 与 3D 查看

画完的户型在应用内就能切换 2D 与 3D 视图，检查层高、门窗位置是否合理。3D 模型也能在 magicplan Cloud（网页端）里查看，需要给家人或同事展示时，直接在电脑上打开比凑在手机前方便。

画完之后要做的事就顺理成章了：导出 PDF 或 CAD 格式见[导出格式与分享方法.md](导出格式与分享方法.md)。
