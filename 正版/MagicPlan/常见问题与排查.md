## 一、安装与启动

| 现象 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| 提示不兼容 | 系统版本、ARCore 支持 | 核对机型是否在 [ARCore 支持设备](https://developers.google.com/ar/devices)名单里，老系统先升级 |
| 安装到一半失败 | 安装包完整性 | 按 MD5（见[下载与安装教程.md](下载与安装教程.md)第一节）核对文件后重新下载 |
| 提示应用冲突 | 手机里是否有旧版 | 卸载旧版本再装 |
| 打开就闪退 | 存储空间 | 清理空间后重启手机再试 |

## 二、找不到「扫描房间」功能

安卓端没有扫描功能——官方帮助中心写明安卓设备不支持扫描与自动扫描，这两个入口只在 iOS 侧出现（自动扫描还进一步要求带 LiDAR 的 iPhone Pro / iPad Pro，且系统为 iOS 17 以上）。在安卓手机上反复找扫描按钮是白费劲，直接用[安卓端怎么画户型图.md](安卓端怎么画户型图.md)里的四种手动方法。

## 三、登录后看不到自己的项目

项目数据跟着**账号**走。多半是登了另一个账号——可能是注册时用了不同邮箱，或者手机上之前登过别人的账号。先核对当前登录的邮箱再判断。项目不会因为卸载应用而消失，换手机后登同一账号即可取回；反之，换了个账号登录，看不到旧项目是正常的。

## 四、导出相关

- **导出的文件在哪**：项目面板的 **Files 区**里，应用内导出与云端导出都归档在这里；从 Cloud 下载到电脑更方便，见[导出格式与分享方法.md](导出格式与分享方法.md)。
- **上次的导出不见了**：同类型再次导出默认**覆盖**旧文件。要保留每次的版本，在 Cloud 的 Settings → Export → Export File Versioning 里改为创建新版本。
- **发出去的 PDF 是旧图**：应用不会自动更新已导出的 PDF。每次改完图纸要重新生成导出，这是最容易漏的一步。
- **导出等很久**：内容多时生成需要时间，期间不要退出应用；反复中断就分楼层、分类型多次导出。

## 五、存储与运行

官方 FAQ 里专门提过：设备存储紧张会导致运行异常（扫描场景最明显，官方建议至少保留 10% 或 10GB 可用空间）。安卓端用不到扫描，但照片、360 全景、导出文件都在往本地塞，空间见底时应用各种怪毛病都会冒出来——先清空间，再重启应用。

## 六、能在电脑上用吗

能，但不是装个电脑版客户端，而是用浏览器打开 **magicplan Cloud**（[cloud.magicplan.app](https://cloud.magicplan.app)）：管理项目、看 3D、导出与下载文件、生成分享链接都在网页端完成；桌面编辑功能目前是 Cloud 里的 **Beta 选项**（登录后点右上角开关启用），大屏改图可以开它。手机负责现场画图，电脑负责整理与交付，两边数据实时同步。

## 七、离线能用吗

官方在产品页把「现场离线作业（Offline mode for fieldwork）」列为产品能力之一。离线画图、拍照记录没有问题；账号登录、项目同步到云端、在电脑上取文件这些动作自然需要网络。现场网络不稳时，先在应用里把项目建好，回公司再联网同步。

## 八、其他

- **换手机怎么办**：新手机装应用、登同一账号，项目都在云端。
- **应用内要你更新版本**：网盘这份是 2025.2.0，官方商店的版本号更新。要不要升上去取决于你的使用场景，功能差异以官方更新说明为准。
- **两个免费项目用完了**：看[免费额度与订阅方案.md](免费额度与订阅方案.md)，里面有各档位的取舍。
- **蓝牙测距仪搜不到 / 连不上**：先开系统定位（安卓蓝牙扫描依赖定位权限），再按[激光测距仪与外设连接.md](激光测距仪与外设连接.md)第四节逐条排查。
- **导入的底图比例设错了**：比例只能在创建楼层时定一次，之后改不了，只能删掉这层重新导入；下次定比例时用一段可靠的已知尺寸，最好用测距仪现量。见[安卓端怎么画户型图.md](安卓端怎么画户型图.md)的导入描图一节。
