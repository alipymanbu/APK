## 一、导出入口在哪

- **应用内**：主界面选中项目进入项目面板 → 点进任意楼层 → 点右上角 **Export** 图标 → 点导出名称选择格式 → 右侧 Settings 可先配置参数。导出完成后会自动弹出预览。
- **云端（magicplan Cloud）**：登录 [cloud.magicplan.app](https://cloud.magicplan.app) → 打开项目 → 进入楼层 → 点右上角 **Send** → **Export Floor Plans** → 点 Export 生成新文件或 Update 更新已有导出。

无论在哪导出，文件都归档到项目的 **Files 区**（项目面板往下滚动能看到），从那里可以保存到手机本地。

注意：导出内容多时生成要等一会儿，官方明确提示**生成过程中不要退出应用**。

## 二、格式一览：你要的东西分别导成什么

| 导出类型 | 文件格式 | 里面有什么 | 适合交给谁 / 用在哪 |
| --- | --- | --- | --- |
| Report PDF | PDF | 图纸 + 照片 + 备注 + 明细 + 自定义表单 | 业主汇报、存档、走流程的正式交付物 |
| Sketch PDF | PDF | 带尺寸标注的图纸 | 只想给对方看户型图的场合 |
| Sketch 图像 | SVG / JPG / PNG / DXF | 平面图文件 | 进其他软件继续加工（DXF 兼容 AutoCAD；JPG/PNG 兼容 SketchUp） |
| 3D 导出 | IFC / OBJ / USDZ | 三维模型 | 进 3D 建模软件（IFC 兼容 SketchUp、AutoCAD；OBJ 兼容 AutoCAD；USDZ 兼容 SketchUp、Blender，且是唯一包含对象的 3D 格式） |
| 统计导出 | PDF / CSV | 面积、周长、使用面积等数据 | 做预算、报数据的表格场景 |
| 估价导出 | PDF / XLS | 估价明细：数量与材料规格 | 报价、施工预算 |

三个细节先记住，能省不少事：

- **DXF 里不含尺寸标注**——要把标注带进 AutoCAD 的场合，用 SVG 或改出 Sketch PDF。
- **USDZ 是唯一带对象的 3D 格式**，家具摆设要一起带走就选它。
- 某些 PDF 报告的导出权限与订阅档位挂钩，你的档位能导哪些以应用内实际显示为准。

## 三、两个最容易踩的坑

1. **同类型文件默认被覆盖**。再次导出同一种格式时，新文件默认覆盖上一次的（不叫 Sketch 2）。想每次都留档，去 Cloud 的 **Settings → Export → Export File Versioning** 勾选按新版本创建，之后就会生成 Sketch、Sketch 2、Sketch 3 这样递增的文件。
2. **改了图，PDF 不会自己更新**。应用不会自动重导 PDF——每次修改完图纸，记得重新生成一遍需要的导出文件，否则发给对方的还是旧版。

## 四、导出前可以调的参数

点导出类型右侧的 **Settings** 齿轮进入配置菜单，PDF 类导出的可调项相当多：

| 参数组 | 能调什么 |
| --- | --- |
| 页面布局 | 所有楼层拼一页 / 一层一页 / 一层一页＋每页两间 / 一层一页＋每页一间 |
| 纸张与方向 | US Letter、US Legal、US Tabloid、A4、A3、A2；横版或竖版 |
| 房间名标签 | 全部显示 / 只显示主要房间 / 不显示 |
| 比例 | 整层与单间各自可选「最大化」「自动选最接近」或手动指定 1:1 到 1:1000；可让所有楼层用同一比例、自动旋转版面以放大图纸 |
| 尺寸标注 | 整层图：外墙与门窗详细尺寸、每间主尺寸、面积、仅显示手动输入过的尺寸；单间图：全部 / 两向主尺寸 / 仅手动 / 不显示 |
| Report PDF 附加内容 | 尺寸、自定义字段、照片/360 全景/视频、备注、表单，各自单独开关 |
| 照片 | 可单独排照片页，大小分小/中/大三档 |
| 页脚声明 | 每页底部默认带一段免责声明，可改成自己的文字 |
| 标题栏 | 报告开头的 Title Block：公司 logo、联系方式、房产名称与位置，还可带房间数与面积统计 |

交正式报告前值得花两分钟过一遍这页——「每间一张图＋只显示主要房间名＋照片单独成页」和「全部拼一张大图」是两种完全不同的交付观感。

## 五、给导出文件加公司抬头

在 Cloud 的 Company Profile 里配置公司名称与联系方式，可以加到导出文件上，仅支持 PDF、SVG、PNG、JPEG 四类格式；配合 Report PDF 的 Title Block，报告头部会带上公司 logo 与联系信息。对外交付时这一步能把「个人文件」变成「公司文件」。

## 六、把文件拿到电脑上 / 发给别人

- **取文件**：所有导出都能在 magicplan Cloud 里取——云端相当于你所有项目文件的仓库，在电脑浏览器登录后直接下载，比数据线传文件省事。
- **发分享链接**：项目可以生成分享链接发给客户、查勘员或项目经理，对方打开链接就能看进度与成果，不用你挨个发文件。桌面编辑功能目前是 Cloud 里的 Beta 选项（登录后点右上角开关启用），需要大屏改图时可以试试。

导出发现文件不对、找不到、被覆盖了，先去[常见问题与排查.md](常见问题与排查.md)对一遍。
