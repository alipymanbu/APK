## 一、不开账号能用什么

不登录也能打开应用里的**示例项目**，可以浏览和编辑它。拿来熟悉界面、试一试改尺寸和导出是够用的——先玩示例再决定注册，是最稳的路径。

## 二、注册之后免费有什么

登录或注册 magicplan 账号后，你可以使用**两个免费项目**。

一个「项目」按官方的口径指**一处物业或一个工地**：这个项目里的全部户型图、照片、导出与报告都算在内。所以免费额度怎么花，取决于你怎么划项目——自己家一户就是一个项目，两个免费名额够把整套流程走熟；想管理多处房产或多个工地，就要考虑付费了。

## 三、付费方案分两条线（截至 2026-09，以官方页面为准）

### 3.1 应用内单席位订阅：Sketch 与 Report

新用户仍然可以直接在应用内购买单席位的 **Sketch** 或 **Report** 订阅。从官方帮助中心的分档看：Sketch 主打画图与基础导出，Report 在此之上加了报告能力，具体差异以购买页当时显示的为准。偶尔接活、一个人用的，从这条线入手最直接。

### 3.2 云端 PRO 订阅：按项目数计费

团队用户走 magicplan Cloud 的 PRO 系列（订阅在 [cloud.magicplan.app](https://cloud.magicplan.app) 里购买），按「每月新项目数」计费，所有功能全开、不另收席位费：

| 方案 | 承诺期 | 单价（每个项目） | 月费（按 10 项目计） |
| --- | --- | --- | --- |
| PRO Flex | 按月 | $40 | $400/月 |
| PRO 12 | 12 个月 | $30 | $300/月 |
| PRO 24 | 24 个月 | $25 | $250/月 |

PRO 方案的几条规则，签约前过一遍：

- **每月最少 10 个项目**起订，这是下限不是上限，可以调高；
- **当月没用完的项目滚存到下个月**；
- 超出额度的项目按 **$40/个** 自动计入下一期账单；
- **用户数不限**，团队成员随便加，不按人头收费；
- 自带估价工具（PRO Estimator）与自定义价格表；
- 有 API 访问，能把 magicplan 接进自己现有的业务系统；
- 北美用户额外有 Xactimate（ESX）与 CoreLogic（FML）文件导出。

另外，早期在云端购买过 Sketch、Report 或 Estimate 订阅的老用户保留原方案，价格与服务不变。

## 四、选哪条线的判断依据

| 你的情况 | 建议 |
| --- | --- |
| 只想试试 / 自己家画一次 | 示例项目 + 两个免费项目，大概率够 |
| 偶尔帮人画、一个人干活 | 应用内 Sketch / Report 单席位订阅 |
| 团队多人用、工地多、要协同与报告 | Cloud 的 PRO 系列（按项目计费） |

## 五、订阅前想清楚的三件事

1. **PRO 到期后的处理**：订阅结束后不能再创建或编辑项目，当期没用完的项目额度也随之冻结；重新订阅后会恢复。合同期内降档有限制，Flex 随时降、12/24 个月方案要到临近到期才能调，签约时按最稳定的月用量报数，别按峰值报。
2. **超额计费是自动的**：额度用超的项目会自动按 $40/个 计入下期账单。团队里多人同时建项目时，留意每月的项目数消耗。
3. **两条线的账号是同一个**：应用与 Cloud 用同一账号登录，项目数据跟着账号走。换手机、换电脑都不影响项目本身。

免费额度内的项目要不要付费导出、哪些格式受档位限制，实际界面里都有提示；动手前先看一眼，免得画完才发现导不了。装好应用的第一步见[下载与安装教程.md](下载与安装教程.md)。
