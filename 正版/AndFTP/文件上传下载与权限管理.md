## 一、先分清两个浏览器

AndFTP 里有两套并排的文件浏览器：**设备（本地）浏览器**管手机存储，**FTP（远程）浏览器**管服务器目录，界面上通过手机/云朵图标切换。上传与下载其实是同一个动作的两个方向：

- 当前停在**本地**浏览器 → 选中文件 → 切到远程目标目录 → 点上传；
- 当前停在**远程**浏览器 → 选中文件 → 切到本地目标目录 → 点下载。

方向搞反是最常见的乌龙：文件没传错地方，只是你以为在传、实际点的是反方向的按钮。

## 二、选中文件与文件夹

- **长按**是选择的开关，点一下则是进入目录或打开文件；
- 长按一个文件夹即选中**整个文件夹**——之后的上传、下载或删除会应用到它下面所有子文件夹和文件（官方 FAQ 的原话逻辑），不用进文件夹逐个勾；
- 支持多选，批量下载一个目录的照片时直接长按拖选即可。

## 三、上传、下载与断点续传

- 上传和下载都带**断点续传**：传输中途断网、切后台被杀，重新连上后再次传输同一文件会从断点接着传，不必从头来；
- 传大文件前建议在设置里开启 **Wake lock**（防止传输时设备休眠导致传输中断）；
- 同时可以有多个文件在队列里传输，不用等第一个完成再选第二个。

## 四、日常文件管理操作

| 操作 | 怎么做 |
| --- | --- |
| 重命名 / 删除 | 选中文件后走菜单 |
| 新建文件夹 | 远程、本地浏览器都支持 |
| 复制粘贴 | 本地浏览器内可用 |
| 移动文件 | 选中文件 → 菜单里的「移动」→ 在目标文件名框里填 `子文件夹/新文件名`（官方 FAQ 的做法，等于移动加改名一步完成） |
| 打开文件 | HTML、MP3、文本、视频等可直接打开，本地或远程文件都行 |
| 排序 | 按名称、大小、日期 |
| 分享 | 从相册等应用直接分享给 AndFTP 上传；本地文件也能作为邮件附件、蓝牙等发出 |

## 五、改服务器上的文件权限（chmod）

SSH/FTP 服务器上的文件有读、写、执行三组权限，改网站文件权限（比如目录 755、文件 644）是网页维护的高频动作：

1. 在远程浏览器里选中文件或文件夹；
2. 走菜单里的权限设置（update permissions）；
3. 按需勾选所有者 / 组 / 其他用户的读、写、执行位，确认后提交到服务器。

改权限走的是服务器的 chmod 语义，服务器账号本身没权限时操作会被拒绝，不是客户端问题。

## 六、自定义命令

连接后可以向服务器发送自定义 FTP/SCP 命令。用得上的场景举例：

- 服务器要求 `SITE` 类指令（如改站点属性）时手动补发；
- 排查问题时发一条 `PWD` 或 `STATUS` 看服务器实际状态。

这一功能面向熟悉 FTP 指令集的人，日常传文件完全用不到它。

## 七、文件夹同步：要弄清版本边界的功能

文件夹同步（mirror remote/local，把一个目录按镜像规则对齐到另一端）能省掉「挑出改动文件再传」这一步，适合把手机相册、工作目录定期备份到服务器。关于免费版能否使用，官方描述与第三方资料说法不一，两种口径的对比、完整配置流程和定时用法单独写在[文件夹同步与定时备份.md](文件夹同步与定时备份.md)。

在确认边界之前，免费版稳妥的替代做法是：手动长按选中文件夹 → 上传，配合第三节的断点续传，效果上只是少了「自动对齐差异」这一步。

## 八、从其他应用调起传输（面向开发者）

AndFTP 对第三方应用开放 Intent 接口，别的应用可以带着参数调起它完成上传或下载（官方页面附有 Intent 文档与示例代码）。普通使用者感知不到这一层，但如果你在自研一个需要 FTP 能力的 App，这是现成的方案，接口细节以官方页面（[www.lysesoft.com/products/andftp](http://www.lysesoft.com/products/andftp/)）为准。

传输过程卡住、报错，见[连接失败常见问题排查.md](连接失败常见问题排查.md)；服务器改用密钥登录后连不上，见[SFTP密钥登录设置.md](SFTP密钥登录设置.md)。
