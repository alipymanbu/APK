## 一、动手前先备齐四样东西

| 需要的信息 | 说明 | 常见来源 |
| --- | --- | --- |
| 主机地址 | 域名或 IP，如 `ftp.example.com` | 服务商开通邮件 / 控制面板 |
| 端口 | 与协议配套，见下文对照表 | 服务商说明页 |
| 用户名和密码 | 或 SSH 私钥 | 你开通服务时设置的账号 |
| 协议类型 | FTP / FTPS / SFTP / SCP 四选一 | 服务商明确写着哪种就用哪种 |

**协议类型是最容易搞错的一项**：主机商说「SSH 连接」那就是 SFTP/SCP，说「FTP over TLS」才是 FTPS。类型选错时服务器根本不会按你预期的方式应答，报错也不直观——连不上时第一个回头检查的就是它。

## 二、新建服务器配置

1. 打开 AndFTP，首屏是服务器列表，点 **+** 号进入新站点设置；
2. 站点设置页顶部有几个标签页（常规、高级、同步等，不同版本措辞略有差异），第一步只动「常规」；「同步」标签是给目录镜像备份用的，单独写在[文件夹同步与定时备份.md](文件夹同步与定时备份.md)；
3. 依次填主机地址、端口、用户名、密码；
4. 在「类型」下拉框里选协议（见下一节的对照表）；
5. 如需连接后直接落在某个目录，填「远程目录（Remote dir）」——**必须以 `/` 开头**，比如要进 `myremotefolder` 就填 `/myremotefolder`，不带开头的斜杠会导致无法切换目录（官方 FAQ 明确提过这一点）；
6. 点保存，回到列表后点这条站点即可连接。

## 三、四种协议怎么选

| 类型 | 全称 | 是否加密 | 常用端口 | 典型场景 |
| --- | --- | --- | --- | --- |
| FTP | File Transfer Protocol | 明文，不加密 | 21 | 局域网 NAS、内网设备、临时测试 |
| FTPS | Explicit FTP over TLS/SSL | 加密（TLS） | 21（常用） | 虚拟主机、要求 FTPS 的托管商 |
| SFTP | SSH File Transfer Protocol | 加密（SSH） | 22 | VPS、Linux 服务器 |
| SCP | Secure Copy Protocol | 加密（SSH） | 22 | 基于同一 SSH 账号的快速单文件拷贝 |

补充两点：

- 官方对 FTPS 同时支持显式（Explicit）与隐式（Implicit）两种握手方式，端口以服务商给的为准，别按「常见端口」硬猜；
- 局域网里传大文件图快用明文 FTP 无可厚非，但只要流量走公网（手机流量、公共 Wi-Fi），就应该用 FTPS 或 SFTP——明文 FTP 连密码都是裸奔。

## 四、密码登录还是密钥登录

- **密码登录**：常规路径，用户名密码直接填进设置即可；
- **不想把密码存在手机里**：站点设置里有认证提示选项，开启后每次连接时才输入账号密码，设备上不落盘；
- **SSH 密钥登录**（服务器禁用密码登录时只能走这条）：用户名照填、密码留空，然后到「高级」标签里选私钥文件，完整步骤单独写在[SFTP密钥登录设置.md](SFTP密钥登录设置.md)。

## 五、主动模式与被动模式

FTP/FTPS 有主动（Active）与被动（Passive）两种数据连接方式，站点设置里可以切换：

- 默认用被动模式即可，它对客户端所在网络的防火墙最友好；
- 如果服务器端防火墙配置严格（只放行了 21 端口、没开被动端口段），被动模式会「能登录但传不了文件」，这时反过来试主动模式；
- 这一项只影响 FTP/FTPS，SFTP/SCP 没有「模式」的概念，不用管。

## 六、已有 FileZilla 配置可以直接导入

AndFTP 支持设置文件的导出与导入，其中包括读取 FileZilla 的站点配置。如果你在电脑上用 FileZilla 管理过同一批服务器，把站点管理器导出的配置文件放进手机导入，能省去逐条重填——具体入口在站点管理界面，以你手头版本的菜单显示为准。

## 七、保存之后

连接成功你会直接看到远程目录的文件列表。传文件、建目录、改权限的操作见[文件上传下载与权限管理.md](文件上传下载与权限管理.md)；如果卡在连接这一步，直接翻[连接失败常见问题排查.md](连接失败常见问题排查.md)——那里按报错现象列了检查顺序。
