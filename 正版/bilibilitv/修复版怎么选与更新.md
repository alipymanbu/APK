## 一、先弄清两个版本号

bilibilitv 的包身上叠着两套编号，社区帖子里混着用，先分清：

- **底版号 1.6.6**：2018 年最后一版以「哔哩哔哩TV版」名义发布的官方电视端客户端。后来官方电视端改名云视听小电视，这条线就停在了 1.6.6。
- **修复版号 v1.0、v2.0……**：社区开源项目接手后给自己的修复迭代编的号。你看到的「2.0 修复版」「3.0 内测」「v11 测试版」说的都是修复版号，底版并没变。

所以「1.6.6」和「v9.0」并不矛盾：底版永远是 1.6.6，修复版号说明接口和功能修到了哪一步。

## 二、各修复版都改了什么

下表按项目页的更新记录整理（截至撰稿，之后的更新以项目发布页为准）：

| 修复版 | 对你实际有影响的变化 |
| --- | --- |
| v2.0 | 首页推荐回来了（改用 1.6.4 时期的推荐接口） |
| v3.0 | 改用网页端视频源，登录后能拿到 1080P；番剧一度看不了 |
| v4.0 | 视频源优先电视端、其次网页端；修复动态加载失败 |
| v5.0 | 能看直播了（含直播弹幕） |
| v6.0 | 换用 dash 格式网页源；不支持 hevc 编码——8K 档这个版本看不到 |
| v7.0 | 播放速度调节；直播分区与「我的关注」 |
| v8.0 | 长按点赞一键三连、长按投币同时点赞；播放进度优先云端（手机看到一半，电视能接上） |
| v9.0 | hevc 软解放开（8K 有戏）；修复音画不同步；长按记住倍速状态 |
| v10.0 | 「稍后再看」、CC 字幕、弹幕过滤、自定义 CDN、画面调节等一批实验功能 |
| v11.0（测试） | 账号切换（长按）、用户黑名单、「影视」模块、解码器选择；最低支持版本反而降了，有人在 Android 4.0 上跑起来 |

两个结论可以直接从表里读出来：

1. **功能上别拿老修复版硬扛**——直播、稍后再看、三连这些都是后来才加的，找不到入口多半只是版本老。
2. **「清晰度全员 720P」先怪版本再看账号**——项目记录里明确提过网页端视频源一度只能拿到 720P，等新源或换版本，比自己反复调设置有用。

## 三、网盘里这份 1.6.6 在哪个位置

[bilibilitv 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d99ceec19dec)里的是底版 1.6.6 体系下的一份构建（约 7.63M，MD5 `CB3819F916893F089A9CA3FA34695581`），拿来即用没问题。它对应哪一版修复迭代，安装包本身看不出来；想用上最新的接口修复，去项目发布页拿新构建覆盖安装。

## 四、去哪更新、怎么更新

- **项目发布页**：[https://github.com/qidian55/bilibilitv1.6.6-repair](https://github.com/qidian55/bilibilitv1.6.6-repair)，新构建从这里出。
- **常见故障排查帖**：[https://github.com/qidian55/bilibilitv1.6.6-repair/discussions/83](https://github.com/qidian55/bilibilitv1.6.6-repair/discussions/83)，首页空白、登录失败这类问题先去对号。
- **使用指南（wiki）**：[https://github.com/qidian55/bilibilitv1.6.6-repair/wiki](https://github.com/qidian55/bilibilitv1.6.6-repair/wiki)。

更新方式就是用新 apk 覆盖安装（同包名直接覆盖，见[下载与安装教程.md](下载与安装教程.md)）。两个例外要注意：

1. **改包名的构建**：社区流传个别改包名版本（改成官方电视版的包名，用来通过部分厂商白名单）。这类包与云视听小电视同包名冲突、装哪个就得二选一，项目页也提醒改包名构建可能出现部分运行错误。
2. **别买、别替它宣传**：项目页明确禁止利用这个项目盈利，也点名过一批倒卖它的公众号和闲鱼卖家——项目页免费下载的东西，遇到收费的直接绕开。项目同时要求不得在B站站内宣传它，这正是第三方客户端的身份决定的。
