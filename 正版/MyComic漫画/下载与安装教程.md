## 一、这是什么软件

MyComic（常被叫作 MyComic漫画、我的漫画）是一款安卓上的漫画、小说、影视三合一阅读软件。你在一个应用里就能追漫画、看小说、刷番剧，不用装三个 App。它走的是「多数据源聚合」的路子——同一部作品可能有多条线路可切，某条线路挂了换一条就能继续看。

适合的人：想把追漫、追书、追番放在一个应用里解决，又不想被一堆订阅流程缠住的安卓用户。

**目前只有安卓版**：官方明确答复过，没有苹果版、鸿蒙版、网页版。用 iPhone 或鸿蒙 Next 的话装不了，别去找所谓「iOS 版」的安装包。

## 二、拿到安装包

两个入口，任选其一：

1. **[MyComic漫画 安装文件资源（夸克网盘）](https://pan.quark.cn/s/44d3cf9b9111)**——转存后下载，得到的是固定一版，不会被官方更新覆盖，适合想固定在某个版本的场景；
2. **官方发布页**——历史版本列表在 Gitee 的发行页，路径是 `https://gitee.com/luqichuang/MyComic/releases`，每个版本都有 `.apk` 与 `.zip` 两种包；官方站点 `https://www.mycomic.xin/` 上也有直达下载按钮，显示的版本以页面当时为准。

两种入口拿到的包版本未必相同。**你要装哪一版，以包的版本号为准，不要假设名字一样就内容一样。**

## 三、网盘里这一份是什么版本

本地核对过的事实（这是网盘里那份包的信息，网上搜到的「最新版」未必是它）：

| 项目 | 值 |
| --- | --- |
| 版本 | v1.11.4 |
| 包名 | `com.wuyou.wyk88.zmrj` |
| 大小 | 31.23M |
| MD5 | `acf0a6e6f9263ef5d0ac2a01c7142a75` |
| 整包大小 | 32,750,337 字节 |

包名是安装身份：你手机上已装的若是同一个包名，装这份就是升级；若是别的包名，装完会是两个并存的应用。想确认手上的包没下错，可用校验工具比对 MD5 是否为上表那串。

官方 Gitee 发行页上 v1.11.4 之后还有 v1.11.5、v1.11.6、v1.11.7 等更新版本；网盘这份停在 v1.11.4 属正常，功能层面的差异见下面的更新记录。

## 四、安装步骤

1. 手机上打开网盘链接（或从发布页直接下载），把 APK 下到本机；
2. 若系统弹「不允许安装来自此来源的应用」，这是安装未知来源应用的常规拦截——到设置里为你的文件管理器或浏览器临时放行，装完可以关掉；
3. 点击 APK 走系统安装流程，装完打开；
4. 首次启动按引导授予联网等基础权限，不给的话漫画加载不出来（排查见[常见问题与故障排查.md](常见问题与故障排查.md)）；
5. 进首页后建议先做一件事：把数据源换成你想要的那条（见[数据源切换与导入教程.md](数据源切换与导入教程.md)），再开始搜书。

安装失败多半是三种原因：安装包没下完整（重新下载，或用 MD5 校验）、手机存储空间不足、系统版本过旧。逐条排除的方法在[常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、v1.11.4 版本改了什么

官方发布记录里，v1.11.4 与它前一版 v1.11.3 的变化：

**v1.11.4**

- 小说章节可缓存
- 小说阅读新增深色模式
- 修复导入分享书单的 bug
- 修复其他部分 bug

**v1.11.3**

- 新增书单分享功能（收藏页右上角菜单）
- 优化广告显示（禁止开屏广告重复触发切屏）
- 精简 apk 体积
- 修复 bug

后续版本的要点（供你判断要不要升级）：v1.11.5 加了收藏页排序筛选与作品标记；v1.11.6 让漫画/小说/影视内容可按需加载、数据源可关闭，并新增数据库管理；v1.11.7 修复了 VIP 自动备份、章节切换顺序按钮、小说缓存不存阅读记录等问题。完整列表以 Gitee 发行页为准。

## 六、收费与广告是怎么回事

官方口径：软件**免费使用、内嵌广告**；VIP 是可选项，权益是屏蔽软件内所有广告、专属主题皮肤、每日自动备份阅读数据。你不开 VIP 也能看全部功能，只是会看到广告。第三方下载页常见「无广告版」「纯净版」的说法，与官方口径对不上，别按那个预期装完去数广告。

更细的使用问题见[阅读设置与使用技巧.md](阅读设置与使用技巧.md) 与[离线缓存与书架管理.md](离线缓存与书架管理.md)。
