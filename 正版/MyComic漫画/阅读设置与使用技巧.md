## 一、找到想看的书

三个入口，按你的已知信息选：

- **顶部搜索栏**：输漫画名或作者名，关键词模糊匹配，输一半也能出结果。v1.11.6 起，搜索页会按不同数据源把结果分组展示——同名作品在各源的收录不一样，多看一组常有收获；
- **题材分区**：热血、恋爱、悬疑、治愈等分区逐层点进去，适合没明确目标时翻；
- **排行榜**：按热度看当前什么在追，用来发现新坑。

搜到某部书却加载不出来，是源的问题不是搜索的问题，处理顺序见[常见问题与故障排查.md](常见问题与故障排查.md)。

## 二、阅读界面能调什么

点开正文后，点屏幕中央唤出设置面板：

| 设置 | 什么时候调 |
| --- | --- |
| 翻页模式 | 竖向滚动 / 左右翻页，按你单手拿手机的习惯选 |
| 屏幕亮度 | 夜里看，比系统亮度单独压低更护眼 |
| 显示比例 | 页面偏小或被裁边时调整 |
| 横竖屏 | 横屏看跨页大图更完整 |

小说阅读在 v1.11.4 新增了**深色模式**：进小说正文的设置里开，晚上追书不用把屏幕打成一片白。漫画与小说的设置是各自独立的，漫画调好了不会自动套到小说上。

## 三、两个高频手势

- **阅读页长按加载失败的图片**：单独重载这一张——网络抖动导致的花图、空白页，不用退出重进；
- **阅读页长按已显示的图片**：单独缩放这张图，看小字对白或彩蛋细节时用；
- **书架长按作品**：切换源 / 详情 / 删除（详见[离线缓存与书架管理.md](离线缓存与书架管理.md)）。

记住一个规律：**这个应用里「长按」几乎都是快捷菜单**，找不到功能时先在相关页面长按试试。

## 四、内容与数据源的个性化

装完想让界面只留漫画？去个人中心：

- **默认数据**：勾选要加载的内容类型（漫画 / 小说 / 影视），没勾的不进首页也不进搜索；
- **数据源配置**：单独关闭某条源，把总出问题的那条拉黑；
- **数据库管理**：v1.11.6 加的入口，用于查看和清理本地数据缓存，空间紧张或数据异常时用。

这三项的详细操作在[数据源切换与导入教程.md](数据源切换与导入教程.md)，此处只说入口位置。

## 五、广告与会员

软件免费、内嵌广告（开屏与页面内都有）。若广告影响阅读，官方提供的路径是开通 VIP——权益为屏蔽软件内全部广告、专属主题皮肤、每日自动备份阅读数据，说明与购买入口在应用内个人中心，具体价格以页面当时显示为准。第三方渠道流传的所谓「特殊版本」与官方口径不符，不建议拿来源不明的包（认包名与 MD5 的方法见[下载与安装教程.md](下载与安装教程.md)）。
