# 手机画质只有480p怎么办

> 会员档没问题、网速也够，画面却糊成标清？多半不是设置能解决的，而是设备的 DRM 等级被降了。本篇讲怎么查、为什么掉、怎么补救。

## 一、先排除三个简单原因

按顺序核对，别一上来就怀疑手机：

1. **套餐档位**：含广告标准和标准档本身最高就是 1080p，4K/HDR 只有高级档有（见[离线下载与画质设置.md](离线下载与画质设置.md)）。
2. **应用内设置**：应用设置 → 视频画质，确认没有选「标准/省流量」，也没开「数据节省程序」。
3. **网速**：官方推荐带宽是 720p 约 3 Mbps、1080p 约 5 Mbps、4K 约 16 Mbps；可用 [fast.com](https://fast.com)（Netflix 自家的测速站）或应用内自带的网络检测直接测。

三项都正常但还是糊，继续往下。

## 二、真正的元凶：DRM 安全等级

安卓上流媒体画质受 Widevine DRM 等级约束，它决定你的手机有没有资格播高清：

| 等级 | 解密在哪做 | 实际效果 |
| --- | --- | --- |
| L1 | 硬件安全环境（TEE） | 有资格播 720p/1080p，条件齐时可达 4K/HDR |
| L3 | 软件解密 | 各平台普遍压到约 480p 标清，设置改不了 |

Netflix 在此之上还有自己的一层认证：硬件支持 L1 只是一个条件，厂商还要通过 Netflix 的设备认证、固件里的 DRM 实现也要被认可，三者都满足应用才放开高清。所以会出现「硬件明明支持、应用里就是只有标清」的情况。

## 三、怎么查你的设备

- **应用内查**：Netflix 应用 → 我的 Netflix → 右上角头像 → 应用设置 → 播放规格（部分版本叫「播放规范」），这里直接列出 Widevine 等级（L1/L3）和当前设备可用的最高分辨率。
- **第三方工具查**：装 DRM Info，翻到 Widevine Modular DRM 一节看 Security Level。怀疑买了二手 Low 清手机的人，买前先用这招验一遍。

## 四、为什么会从 L1 掉到 L3

设备出厂是 L1，后来变 L3，常见于这几件事之后：

- 解锁 bootloader 或对系统做 root；
- 刷了非官方系统、或把国行机刷成海外 ROM（反过来也一样）；
- 系统更新本身出了问题，把 DRM 组件或证书弄坏；
- 厂商安全补丁长期没跟上。

## 五、怎么补救

按代价从小到大试：

1. 清除 Netflix 应用数据（设置 → 应用 → Netflix → 存储 → 清除数据）后重登，部分临时性失效这样就好。
2. 检查并安装系统更新，等厂商把 DRM 相关补丁补齐。
3. 部分小米/POCO 机型的系统设置里提供 Widevine 证书重新下载的入口（在指纹支付相关设置里找 Widevine L1 一项），有用户实测能救回来，具体路径随系统版本不同，找不到就别硬找。
4. 刷过机的，恢复官方系统并重新锁定 bootloader 才可能回去——注意重锁会清空数据。
5. 都不行就是设备的信任链被动过了，软件层面无解；好在投屏到电视看不受手机 DRM 等级影响。
