## 一、安装前先核对三件事

1. **系统版本**。Netflix 应用商店页面的要求是 Android 7.0 及以上（2026 年起收紧，部分新版构建要求更高，以官方页面为准）。系统过旧的设备即使能装上，也大概率卡在登录或播放环节。
2. **剩余存储**。安装包本身约 216 MB，装完加上缓存和离线下载，实际占用会明显超过这个数，建议预留 1 GB 以上。
3. **允许安装未知来源应用**。不在应用商店里装，就需要给「文件管理器」或浏览器开「安装未知应用」权限：设置 → 应用 → 特殊权限 → 安装未知应用，找到你用来打开安装包的那个应用，允许即可。

## 三、安装步骤

1. 在网盘客户端里把 `Netflix_v9.72.0build364377.apk` 下载到手机存储。
2. 用文件管理器找到这个 apk，点开。
3. 系统提示「是否允许安装未知应用」时，选择允许（只对当前这一次或该应用生效，看你自己选）。
4. 点「安装」，等进度走完。
5. 装完点「打开」，或回到桌面从图标进入。

## 四、装不上时的常见原因

| 现象 | 大概率原因 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 安装包没下载完整，或传输中损坏 | 重新下载一遍，核对文件体积是否约 215.7 MB |
| 提示「存在签名冲突 / 已有更高版本」 | 手机上装过别的渠道的同包名版本 | 先卸载旧版再装 |
| 提示存储空间不足 | 剩余空间小于安装所需 | 清理后重试 |
| 安装按钮点不动 / 秒退 | 系统版本过低 | 见第一节，确认 Android 版本 |
| 装好但打不开、闪退 | 系统过旧或内存紧张 | 重启手机再试；仍然闪退看排查篇 |
