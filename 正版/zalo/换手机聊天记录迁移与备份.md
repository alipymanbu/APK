## 一、先搞懂机制：聊天记录存在手机里

Zalo 官方帮助中心写得很直白：聊天数据保存在你正在用的这台设备上，而不是云端。这个设计对隐私有利（别人的账号登上去也看不到你的记录），但代价是：

- **换新手机登录同一个账号，旧手机的聊天记录不会自动出现**；
- **卸载重装 Zalo 之前没有备份，记录全部丢失**，官方明确说这种情况无法恢复。

所以换机或重装前，第一件事不是删应用，而是按下面步骤备份。

## 二、旧手机上做备份（官方步骤）

1. 打开 Zalo，进底部的**个人**（Cá nhân）页；
2. 右上角进**设置**（Cài đặt）；
3. 找到**备份与恢复**（Sao lưu và khôi phục），点**立即备份**（Sao lưu ngay）；
4. 给这份备份**设置密码**（备份密码，和登录密码是两回事）；
5. 等进度走完，期间可以正常用 Zalo。

备份做完后，页面会显示备份的日期和时间，供你确认。

## 三、新手机上恢复

1. 新手机登录你的 Zalo 账号；
2. 登录后通常会自动弹出恢复提示，点**恢复**（Khôi phục）；
3. 输入备份时设的密码；
4. 等恢复完成，文字消息就会回到新手机。

如果登录后没有弹窗：同样进设置 → 备份与恢复 → 手动点**恢复**。

## 四、备份覆盖不到的内容（重点）

标准备份有明显边界，官方说明如下：

| 内容 | 标准备份是否覆盖 |
| --- | --- |
| 文字消息 | 覆盖 |
| 图片、视频、文件 | 不覆盖 |
| 已删除的消息 | 不覆盖 |
| 已撤回的消息 | 不覆盖 |

想让图片视频也跟着走，官方给的路子是升级 **zCloud** 云存储服务（付费）；不少第三方教程还提到安卓端可关联 Google Drive 备份照片，入口随版本变化，以你手机里的实际界面为准。

所以务实做法是：**换机前把聊天里的重要文件、图片先手动另存到手机相册或网盘**，别指望备份把多媒体一并带走。另外，三星和谷歌 Pixel 有「卸载 Zalo 时保留消息」的特殊选项，其他品牌没有这个待遇。

## 五、备份密码忘了的后果

备份密码是独立的，忘了没有找回功能，官方的处理方式只有一条：**在旧手机上删掉备份密码和最近一次备份，重新备份一次**，再用新密码恢复。

两种情况无法挽回：

- 旧手机已经不在手边、密码又忘了 → 这份备份作废，记录救不回来；
- 先删了应用才想起没备份 → 数据随卸载一起没了。

所以备份密码当场记在可靠的地方，别凭脑子记。

## 六、电脑端可以再上一道保险

Zalo PC 支持把消息、图片、文件**导出成本地备份文件**（设置 → 数据 → 其他 → 导出数据，两个独立教程口径一致，菜单名以当前版本为准），适合把工作里的重要往来存一份到电脑。导出与电脑版的其他用法见 [电脑版网页版与多设备同步.md](电脑版网页版与多设备同步.md)。

换号、换绑手机号这些账号层面的操作和换机是两回事，见 [注册流程与账号设置.md](注册流程与账号设置.md)；新手机装好 Zalo 后登录不上，属于登录故障，看 [收不到验证码与注册报错处理.md](收不到验证码与注册报错处理.md)。
