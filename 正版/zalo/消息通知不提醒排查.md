# Zalo 消息通知不提醒排查

> 本篇处理「消息来了却没提醒」：先分清是全局不提醒还是单个会话被静音，再按应用内设置、系统权限、省电策略三层逐项排查。

## 一、先分清两种情况

排查前先做个区分，能少走一半弯路：

- **所有消息都不提醒** → 是应用内通知设置、系统权限或省电策略的问题，按下面二到五节排查；
- **只有某个人或某个群不提醒，其他都正常** → 多半是这个会话被单独静音了，打开那个会话 → 右上角菜单 → 检查通知开关是否被关掉，打开即可。

另外注意一个容易误判的场景：**电脑端在线时，手机端可能不再推送部分提醒**，两台设备都开着时以最后操作的设备为准。以为手机坏了，其实消息在电脑上已经读过了。

## 二、应用内通知开关

Zalo 自己有一层通知控制：设置 → 通知（Thông báo），确认消息通知、声音、振动都开着。这一层关了，系统权限再全也不会响。

## 三、系统层：通知权限与锁屏显示

- 安卓：系统设置 → 应用 → Zalo → 通知，允许通知，并确认「锁屏上显示」「横幅」这些子开关没被单独关掉；
- iPhone：系统设置 → 通知 → Zalo，允许通知并选好提醒样式；
- 省流量模式会拦通知，官方帮助中心专门提到：关掉系统的**数据节省模式**，否则可能漏提醒。

## 四、省电策略与后台限制（安卓重灾区）

国产安卓系统的后台管控是这类问题最常见的根因。Zalo 在后台被清理后就收不到推送，进应用才能看到积压消息。逐项处理：

1. **电池优化白名单**：系统设置里搜「电池优化」（或应用详情里的电池选项），把 Zalo 设为「不允许优化 / 无限制」；
2. **允许后台运行**：华为等品牌在「应用启动管理」里关掉自动管理，手动允许自启动、关联启动、后台活动；小米、OPPO、vivo 在各自的安全中心 / 电池设置里找类似的「后台高耗电 / 允许后台」开关；
3. **关闭省电模式**：低电量模式会延迟消息到达；
4. **从最近任务里锁定 Zalo**（下拉应用卡片加锁），防止一键清理时被杀。

iOS 上后台管理宽松得多，一般只要第三节的通知权限没问题就行。

## 五、还不行就这三步收尾

1. **检查网络**：Wi-Fi 和流量之间切换一下试；
2. **更新或重装 Zalo**：老版本的通知故障更新后常直接消失（重装前先按 [换手机聊天记录迁移与备份.md](换手机聊天记录迁移与备份.md) 备份，重装会丢本地记录）；
3. **重启手机**：解决偶发的推送通道卡死。

## 六、和它容易混起来的另一个问题

「收不到**验证码**短信」和「收不到**消息通知**」是两码事：前者是注册登录阶段的短信通道问题，处理方法在 [收不到验证码与注册报错处理.md](收不到验证码与注册报错处理.md)；本篇只管装好之后的消息提醒。两台设备之间的登录关系与同步规则，见 [电脑版网页版与多设备同步.md](电脑版网页版与多设备同步.md)。
