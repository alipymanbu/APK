ACMarket 里拿应用的动作和别人家的商店差不多：搜到、点开看信息、下载、装。真正的门槛不在操作，而在**搜不到想要的词**和**看清这个包是不是你要的**这两件事上。本篇按顺序讲一遍，另外把下载中断和更新检测处理掉。

## 一、商店里的四个区域

打开应用后，界面大致分四块，先知道各自干什么能省不少点按：

| 区域 | 用途 |
| --- | --- |
| 首页 / 榜单 | 按热度、更新时间等维度铺出来的推荐列表，适合没有明确目标时翻 |
| 分类 | 按品类分组浏览，适合「想找个某类工具」这类需求 |
| 搜索 | 有明确应用名时最直接，输入关键词即可 |
| 个人区（左上角） | 语言等设置、下载记录、更新入口都在这里 |

首页刷不出来时先怀疑网络，不要反复下拉刷新，处理方法见 [安装失败与常见报错排查.md](安装失败与常见报错排查.md)。

## 二、搜索：关键词怎么写命中率更高

1. **优先用英文原名**。商店里的条目绝大多数按英文原名收录，用中文名搜不一定能匹配到；不确定原名时，先在浏览器里查清它的官方英文名再回来搜。
2. **关键词越短越好**。应用名加太多后缀（版本、平台字样）反而搜不到，留核心词即可。
3. **同名条目要筛**。搜出来的列表里可能出现名字相近的多个条目，靠图标和简介区分不可靠，进详情页按下一节核对。
4. **搜不到就换入口**。分类页里按品类翻一遍，有时比搜索更快——部分条目没有被索引到搜索里。

## 三、点开详情页先核对三件事

不要只看标题就点下载，详情页上至少确认这三项：

| 核对项 | 为什么看 | 怎么看 |
| --- | --- | --- |
| 包名 | 判断是不是你要的那个应用本体 | 与官方发布页上的包名对照；本文档所对应的 ACMarket 本体包名是 `net.appcake` |
| 版本号与更新时间 | 判断这份包的新旧 | 与官方渠道的发布记录对照，日期明显偏旧的谨慎对待 |
| 体积 | 与官方安装包体积是否大致相符 | 差距过大通常意味着里面塞了别的东西 |

这三项对不上就别装。商店里的安装包由第三方提供、不经过 Google Play 那套上架审核，判断责任在你这边，具体口径见 [第三方商店的权限与风险.md](第三方商店的权限与风险.md)。

## 四、下载与安装

1. 在详情页点下载按钮，进度条通常在页面底部或应用内单独列表里显示；
2. 下载期间**不要杀掉商店的后台**，也不要在多任务里直接划掉它——大体积应用的下载会被一起中断；
3. 下载完成后一般会直接弹出安装界面；没有自动弹出时，到系统「文件管理 → 下载」里找 APK 手动点开；
4. 首次让商店替你把包装上，系统会要求给它「安装未知应用」权限，允许后才继续；
5. 装完在桌面或应用列表里就能看到图标，商店的个人区里也会留下这条记录。

安装包与商店本体一样，都放在 [ACMarket 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a98b939ba40a) 里，需要时转存后下载。

## 五、下载中断与重复下载

表现为进度条卡住不动、或提示下载失败：

- **换一下网络**：移动数据与 Wi-Fi 之间切一次，比反复点重试有效；
- **先看剩余空间**：空间不足时进度条会走到某个百分比就不动，清出空间后重来；
- **锁屏别太久**：部分机型在深度休眠时会掐断后台连接，下载大包时把屏幕留着或把商店加进电池白名单；
- **不要重复点下载**：商店会按任务排队，重复点容易生成多个任务互相抢带宽，先把已有任务取消掉再重来。

装到一半失败、报「解析包出错」或「应用未安装」的，转到 [安装失败与常见报错排查.md](安装失败与常见报错排查.md) 按报错原文对照处理。

## 六、已装应用的更新与卸载

- **更新**：个人区里通常有已装应用列表，会标出有新版可更新的条目，逐个或批量更新都行。更新走的是同一套下载安装流程，同样要留意权限变化。
- **卸载**：商店里的卸载入口只是跳系统的卸载流程，真正的删除动作由系统完成；商店卸载后不会连带删掉你从它那里装的其他应用。
- **清理**：不再需要时，把商店本体在系统设置里卸载即可，已下载的 APK 残留在「文件管理 → 下载」里，需要手动删。

重装或换版本，仍然从 [ACMarket 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a98b939ba40a) 取用；想在电脑上操作，见 [在电脑上的模拟器里运行.md](在电脑上的模拟器里运行.md)。
