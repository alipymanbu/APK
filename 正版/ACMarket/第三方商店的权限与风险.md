# ACMarket 第三方商店的权限与风险

> 本篇讲 ACMarket 作为非官方商店意味着什么、装它之前该核对什么、哪些权限该给哪些别给，以及从它里面装应用时责任在哪。

ACMarket 没有上架 Google Play，属于侧载安装的第三方应用商店：它自己不经过商店方的上架审核，里面的安装包也由第三方提供。这不等于它一定有问题，但意味着**没有人为你装进去的东西背书**，几个动作必须自己做。本篇不替你决定用或不用，只把该核对该收紧的地方列清楚。

## 一、侧载渠道的实际含义

| 维度 | 官方商店的应用 | 像 ACMarket 这样的侧载商店 |
| --- | --- | --- |
| 上架审核 | 有平台侧审核与签名校验 | 无平台背书，靠开发者自律 |
| 更新方式 | 商店统一推送 | 由商店自己或你手动检查 |
| 责任归属 | 出问题可追溯 | 需要你自己核对来源与包内容 |
| 安装前提 | 直接安装 | 需开启「安装未知应用」权限 |

理解这张表就够用：**把它当成一个下载入口，而不是一个可信度背书**。

## 二、装之前该核对的四项

1. **来源**：只从官方站点或你自己留存的安装包安装。本文档对应的包在 [ACMarket 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a98b939ba40a) 里，版本 4.9.8。
2. **包名**：应当是 `net.appcake`。包名对不上，说明你拿到的不是这份包。
3. **体积**：约 46.32 MB。体积明显偏大通常意味着被塞了额外内容。
4. **校验值**：MD5 应为 `C61D37203246142A86450B93BB8509D3`。在电脑上算一遍再传进手机，比装完再怀疑划算：

```cmd
certutil -hashfile ACMarket_v4.9.8.apk MD5
```

（文件名随版本变化，以官网当时提供的为准。）

## 三、它自己要的权限怎么给

装完第一次打开，商店会向系统申请几项权限。按用途分两类：

| 权限 / 授权 | 是否该给 | 说明 |
| --- | --- | --- |
| 网络 / 数据访问 | 该给 | 不联网它拉不到任何列表 |
| 存储（文件读写） | 该给 | 用来存下载的安装包 |
| 安装未知应用 | 该给 | 不给就装不了任何东西 |
| 通知 | 可给 | 主要用于下载进度提醒，不给也能用 |
| 设备管理器 / 无障碍 | **不给** | 与下载安装无关，给了等于把控制权交出去 |
| 短信、通话记录、通讯录、定位 | **不给** | 一个下载客户端没有理由要这些 |
| 悬浮窗、后台自启 | 视需要 | 只影响下载在后台是否会断，介意就拒绝 |

判断标准只有一条：**这项权限和你正在做的事有没有直接关系**。安装过程中的系统弹窗若看不懂，选拒绝再看功能是否受影响，多数情况下不受影响。

## 四、从它里面装的应用，责任在自己

第三方商店里的安装包无法保证与官方发布版逐字节一致，同一个应用在不同渠道也可能被改过签名或塞入额外组件。装之前至少做三件事：

1. 在详情页核对**包名**与**版本号**，与官方发布信息对照，对不上不装；
2. 安装界面展开看一眼**权限清单**，一个输入法要读通讯录、一个壁纸应用要发短信，直接放弃；
3. 涉及支付、网银、社交账号的应用，尽量走官方渠道；确需从别处装的，先装上在非主力设备或系统分身里跑一段，确认行为正常再考虑主设备。

已经装上的应用出现异常发热、耗电暴涨、通知栏出现不明广告，先卸载它而不是去关通知。

## 五、账号与隐私上的自查项

- 这个商店**不需要登录**也能使用，遇到要求填手机号、邮箱、支付信息才能下载的版本，不要填；
- 商店内浏览记录、下载清单留在本机，卸载时清掉；系统设置里清除数据同样会清空；
- 商店里某个应用内部要求登录 Google 账号或其他账号，那是那个应用自身的行为，登录前先判断它是否值得给凭据。

## 六、不想用了怎么退干净

1. 先卸载从这个商店装的应用里你不需要的那些（在系统「应用管理」里逐个卸载，商店的卸载入口只是跳系统流程）；
2. 卸载 ACMarket 本体；
3. 到「文件管理 → 下载」里删掉残留的 APK，这类文件占空间又不常用；
4. 回系统「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把之前授权过的开关关掉。

需要重新装回时，安装包从 [ACMarket 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a98b939ba40a) 取，安装步骤与装前核对见 [下载与安装教程.md](下载与安装教程.md)。如果只是想在电脑上试，用模拟器比装到主力手机更稳妥，做法见 [在电脑上的模拟器里运行.md](在电脑上的模拟器里运行.md)。
