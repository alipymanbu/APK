## 一、本篇解决什么

书库扫进来的书，名字是文件名自带的，有的带一堆杂乱后缀、有的是一串编号，看着乱；攒多了还想删掉一部分。本篇讲在 ReadEra 里改名、移动、删除各是什么效果，以及**它不复制书**这个前提对这些操作意味着什么。书从哪来、怎么归类，在[支持的格式与导入书籍.md](支持的格式与导入书籍.md)。

## 二、先记住这个前提

ReadEra **不把书复制进自己的存储**，书库里的每一条都指向你手机里那个真实文件。所以：

- 你在它里面「删除」，删的是**原始文件本身**，不是应用的一条记录。删完之后，文件管理器里也找不到这个文件了。
- 你在它里面「移动 / 重命名」，动的同样是原始文件。其它应用看到的结果跟着变。
- 手机上没有「卸载应用就能找回书」这回事 —— 书不在应用里，应用没了，书还在你文件夹里（除非你删过）。

**动手前的两条**：要删的书先确认别处还有备份；要批量改名的，先在一两个文件上试，确认效果再全量做。

## 三、入口在哪

按 Play 商店页描述的口径，文件层面的操作集中在两处（不同版本的措辞可能略有出入，找不到就往「关于文档」「文件夹」这类条目下翻）：

| 你想做什么 | 去哪 |
| --- | --- |
| 看这本书存在哪、跳到它所在文件夹 | 打开这本书的「关于文档」类入口 |
| 改名、移动、复制、删除、分享单个文件 | 同上，那一组文件操作菜单里 |
| 改书库里显示的标题 / 作者 / 系列 | 同上，编辑文档信息 |
| 查重复文件 | 同上，会提示该文件在设备上的重复情况 |
| 整个文件夹的增删改 | 侧边栏「文件夹」入口：可浏览外部文件夹、看到每个文件夹里有多少本受支持的书，并新建 / 复制 / 移动 / 删除文件夹 |

「文件夹」视图还有一个实用价值：它按目录列出各处的书量，哪个目录堆了多少一目了然，适合用来判断扫描范围该不该收窄（收窄办法见[支持的格式与导入书籍.md](支持的格式与导入书籍.md)）。

## 四、改名：改的是文件名还是显示名

- **重命名文件**：改的就是文件名本身，改完书库里这条的标题跟着变（书库标题默认取自文件名）。
- **编辑标题 / 作者 / 系列**：这是改书库里显示的信息，用来把 `某站_某某书_12345.epub` 这类乱名整理成看得懂的样子；实际文件名是否同步变化，以你操作后的结果为准 —— 用之前先在**一个不重要的文件**上试一次。
- **改了名，进度还在不在**：书库按文件对应关系记进度，同一个文件改名后一般能认出来；但跨目录大挪移就未必了。稳妥做法是：**先读完一本再整理**，或者整理后发现进度丢了，手动跳回上次那页（也就几秒）。相关口径的另一面见[划线书签与读书笔记.md](划线书签与读书笔记.md)。

## 五、删除：删之前停三秒

1. 确认这条指向的是不是你想要的那个文件 —— 从「关于文档」里看文件位置，别删错了同名的另一份。
2. 想清楚这份文件在别处还有没有副本。没有，就先拷一份出来。
3. 删。侧边栏里有回收站一类的入口时，删掉的内容在那里还能找回一段时间（以你实际界面为准）；**不要把它当保险箱**，真需要的文件先落到别处。

删完书库里那条会消失，进度与书签按官方口径仍会保留一阵，同名文件放回来还能接上原页 —— 但这只对「误删后放回同一个文件」有效，见[常见问题与解决方法.md](常见问题与解决方法.md)。

## 六、不动文件也能让书库变干净

不想真删文件时，这几条更安全：

- **收窄扫描范围**：把杂乱目录移出扫描列表，书库立刻清爽，文件原封不动。
- **用合集收口**：把常读的书放进一个合集，日常从合集进，全量书库当仓库。
- **按阅读状态过滤**：已读、待读、收藏这几个列表只看该看的那部分。
- **挪目录而不是删**：把不常读的书挪到未纳入扫描的归档目录，等需要时再加回扫描范围。
