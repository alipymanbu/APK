## 一、本篇解决什么

同一个阅读器，有人要大字号给长辈看，有人要夜间黑底给睡前看，有人要看扫描版 PDF 得先裁边。本篇把显示相关的开关集中讲一遍 —— 书怎么进书库在[支持的格式与导入书籍.md](支持的格式与导入书籍.md)。

## 二、先认识阅读界面

- **点屏幕中央**：呼出上下工具条与侧边面板（目录、搜索、书签、设置都在这里），再点一次收起。
- **左右滑动，或点屏幕左侧 / 右侧区域**：翻页。
- **顶部右上角**：快速加书签，入口详见[划线书签与读书笔记.md](划线书签与读书笔记.md)。
- **底部进度条 / 页码**：拖动跳页；进度条上会显示当前页与全书页数。

不同格式的可调项不一样 —— 文本类（EPUB、FB2、MOBI、DOCX、ODT、TXT）调的是字体排版，图类（PDF、DjVu）调的是页面缩放与边距。设置里两套参数是分开存的，别在一个格式下调好了就以为所有书都变了。

## 三、文本类：字体与排版

可调项包括字号、字重（粗细）、行距、对齐、缩进、断字开关、段首缩进，取值范围在设置 → 阅读里逐项列出。

- **中文字体**：官方说明里提到支持系统字体，用于中文、阿拉伯文等文字的显示；把字体切成「跟随系统」即可让中文书用机型自带的那套中文字体，这是最省事的默认选择。
- **自定义字体**：把字体文件传上去给所有书用 —— 这一项属 Premium 功能（见[常见问题与解决方法.md](常见问题与解决方法.md)）。免费版下，用系统里已装的字体即可。
- **调完不满意就还原**：设置项逐条可改回默认，不用担心调乱。

## 四、主题配色与亮度

- **五种配色**：日间、夜间、护眼（sepia，偏黄）、微光（twilight，介于日夜间那档）、控制台（黑底绿字那类高对比风格）。在阅读面板或设置里切换，切换对当前书立即生效。挑法很简单：白天日间，夜里夜间，睡前嫌黑底刺眼就护眼或微光。
- **亮度可低于系统下限**：ReadEra 自带一层亮度调节，能压到比系统最低亮度还暗 —— 熄灯后看手机这个最有用。
- **手势调亮度**：在屏幕**左边缘**上下滑动即可改亮度，不用拉通知栏。
- **自动 / 手动**：亮度项里可以交给系统自动，也可以固定成手动值。

## 五、翻页方式

| 想要的效果 | 在哪改 |
| --- | --- |
| 横向翻页 / 纵向滚动 | 设置 → 阅读 → 翻页（水平 / 垂直） |
| 用音量键翻页 | 设置 → 阅读 → 「翻页和页面标识符」→ 打开「音量按钮」 |
| 屏幕方向锁定或跟随 | 阅读面板里的屏幕旋转开关，或系统下拉里的自动旋转 |
| 看完停在哪页 | 「自动保存当前页」默认开启，重开接上次位置 |

音量键翻页这条路径是按公开教程的口径写的（侧边菜单 → 设置 → 阅读 → 翻页和页面标识符 → 音量按钮），不同版本条目名略有出入，找不到就往「阅读」分类下翻一遍。

## 六、PDF 与 DjVu 怎么调

这两个格式不能改字体，但页面本身可调：

- **缩放**：双指捏合，或用设置里的缩放选项固定一档。
- **页边距与裁边**：扫描版 PDF 常带一圈白边，裁边能把正文放大到铺满屏。
- **单列模式**：把「一屏两页」的跨页扫描图拆成两张连续单页，看双页排版的书不再来回放大。
- **页面旋转**：扫描方向不对（横倒的页面）时按 90° 转正。
- **翻页方向**与文本类共用同一处设置。

## 七、多窗口与给孩子用

- **分屏开两本**：在支持分屏的机型上，可以左边 EPUB 右边 PDF 同时开两个窗口，也可以用系统「最近任务」在多本书之间切。
- **儿童模式**：官方给的入口是**三点菜单** —— 对当前书库的某个部分开启，或对正在读的那本书单独开启。开启后是简化界面 + 大号封面 + 家长控制，你把要给孩子看的书筛出来、加进儿童合集，孩子那边就只看得到这些。想退出同样走三点菜单。

调完这些基本就定型了；之后做标记、记笔记的那套操作，在[划线书签与读书笔记.md](划线书签与读书笔记.md)。
