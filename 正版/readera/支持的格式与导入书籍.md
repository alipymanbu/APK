## 一、本篇解决什么

你手机里可能同时躺着从不同地方来的文件：浏览器下好的 PDF、聊天工具收的 EPUB、扫描件、办公文档。本篇讲 ReadEra 认哪些扩展名、这些文件怎么自动进书库、以及书库里怎么把它们找到 —— 装机那一步在[下载与安装教程.md](下载与安装教程.md)。

## 二、能打开的格式

按官方页面的分类口径，可读格式大致分四类：

| 类别 | 格式 |
| --- | --- |
| 电子书 | EPUB、MOBI、AZW3、FB2 |
| 文档 | PDF、DjVu |
| 办公 | Word 的 DOC / DOCX / RTF、ODT |
| 文本与漫画 | TXT、CHM、CBR、CBZ |

另外三点实际会用到的：

- **压缩包不用解压**：FB2 装在 ZIP、RAR 里可以直接打开；Word 文档与 PDF 文件从压缩包里读也支持。也就是说你从网盘转存下来一整包书，不必先逐个解开。
- **PDF 能处理扫描版**：支持裁剪页边距、缩放；「单列模式」可以把跨页的双页扫描图拆成两张单独的页看，适合扫描版书和论文。
- **Word 文档会自己长目录**：DOC/DOCX 即使原文件里没有做目录，它也能按标题层级生成一个可跳转的目录。

扩展名对但文件仍打不开的情况（下载中断、文件损坏、带 DRM 的商业书）不在上表范围内，排查方法见[常见问题与解决方法.md](常见问题与解决方法.md)。

## 三、书怎么进来：自动扫描 + 指定文件夹

**默认行为是自动扫描**：你从浏览器、聊天工具、邮件里存下一本 EPUB 或 PDF，不需要手动「导入」，下次打开应用它已经出现在书库里了。它靠的是扫描你允许的那些文件夹。

**想改扫描范围**（比如书都放在某个新目录里）：

1. 打开应用，进设置（侧边菜单底部的「设置」）。
2. 找到扫描文件夹相关的条目，点右下角加号选择要新增的目录；同一个入口里也能删掉不想要的目录。
3. 加完回到书库，新目录下的文件会被识别出来。

**权限没给就什么都扫不到** —— 这是最常见的翻车点，手机系统那一层的授权怎么开，见[下载与安装教程.md](下载与安装教程.md)；怎么确认是权限问题而不是文件问题，见[常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、它怎么处理文件本身

这几条决定了你删文件、挪文件之后会发生什么：

- **不复制书**：ReadEra 不把书复制进自己的存储里，它直接引用原文件，所以装 2000 本书的应用本体占用不会跟着涨。
- **认重复**：同一个文件出现在两个文件夹里，书库里会按重复处理，不会给你摆出两份一模一样的封面。
- **进度和书签跟着书名走**：官方口径是即使文件被移动或删除，书签与当前阅读页也能保留 —— 你把文件删了、之后又重新下载回来，打开还能接上原来那一页。这条对「清理手机空间又想留进度」很实用，但别当成备份手段：书本身没了，能留下的只是位置信息。
- **数据可以放 SD 卡**：设置里有把应用数据存到 SD 卡的选项，设备带卡槽时可用来省机身空间。

## 五、书库里怎么组织

侧边菜单把同一批文件按不同视角分好了，同一本书不会因为出现在多个分类里而变出多份：

- **阅读状态**：正在阅读、收藏（Favorites）、待读（To Read）、已读（Have Read）—— 后三个是你手动打标的结果，「正在阅读」则按最近打开自动排。
- **自动归类**：作者、系列、格式、文件夹、下载目录、回收站。
- **合集（书架）**：自己建的主题书架，一本书可以同时进多个合集；建合集的入口在书籍卡片的菜单里，给新合集起个名字即可，之后在侧边栏「合集」下能找到。
- **排序与视图**：按名称、格式、最近阅读排序；列表密度可调（完整 / 简洁 / 缩略图 / 网格，其中网格视图属 Premium，见[常见问题与解决方法.md](常见问题与解决方法.md#免费版和-premium-差在哪)）。
- **搜书**：顶部搜索栏输关键词即可，对几万册规模的书库也够用（官方称在 50 万册规模上做过测试）。

书找齐之后，怎么读得舒服见[字体主题与翻页设置.md](字体主题与翻页设置.md)；怎么划线记笔记见[划线书签与读书笔记.md](划线书签与读书笔记.md)。
