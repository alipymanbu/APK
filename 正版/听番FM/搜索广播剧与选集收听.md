## 一、先说结论

找剧在听番FM里有三条路：首页直接刷推荐、用顶部搜索框输关键词、进「作品索引」按条件筛。找到剧后点开就是播放页，选集、收藏、定时、倍速都在这一屏。本篇按你实际操作的顺序讲这三条路和播放页的基本操作。

## 二、首页与榜单：不知道听什么时的入口

打开应用进首页，「每周热播」列出当前主推的广播剧，每条带连载状态与主演信息，点任意一条直接进详情/播放。首页还能进这几类榜单：

| 榜单 | 看什么 |
| --- | --- |
| 热门榜 | 当前收听量高的作品 |
| 追剧榜 | 被最多人收藏追更的作品 |
| 新剧榜 | 最近上架的新作品 |

榜单只是发现入口，看到名字合口味就点进去听，不合适就退出换一部，没有额外成本。

## 三、搜索框：心里已有剧名时走这条

1. 点首页顶部的搜索框。
2. 输入关键词 —— 剧名、作者名、声优名都能作为关键词，输入时会有搜索建议联想，直接点联想项比打全名快。
3. 结果页可看热门搜索、热门榜、追剧榜、新剧榜的聚合入口；命中的剧点开即播。

搜不到目标剧时，先确认有没有打错字、换更短的词再试一次；仍然没有，说明应用暂未收录，见[登录方法与故障排查.md](登录方法与故障排查.md)里「搜不到 / 剧集不全」那一节的处理办法。

## 四、作品索引：按条件筛出一批可选的

「作品索引」（部分版本叫「全站索引」）是结构化的筛选页，字段包括：

- **更新状态**：连载中 / 已完结 —— 想一次听完整本就筛已完结。
- **风格**：古风、都市、悬疑等题材维度。
- **性质**：**免费 / 付费** —— 只想听不花钱的，把「性质」筛成「免费」，出来的结果都能直接播。
- **状态**：作品本身的上架状态。

筛完的列表点任意一部进入播放页，和搜索结果是同一个播放界面。日常想找一批能免费听完的剧，走「性质 → 免费」这一步最省事。

## 五、播放页：选集、收藏与追更

进入一部剧的播放页后，你会用到这些控件：

1. **选集**：点「选集」展开剧集列表（如「第1集」「篇上」「篇下」这类分集条目），点哪集播哪集，连载中的剧新集会往下排。
2. **收藏 / 追更**：点收藏按钮把剧收进「我的收藏」；追更后有新章节更新会推送提醒（通知权限要在安装时允许，见[下载与安装教程.md](下载与安装教程.md)第三步）。
3. **评论与弹幕**：播放页有评论区和实时弹幕，想看剧情讨论就开着，嫌干扰可以关掉。
4. **继续收听**：播放进度自动记录，下次从首页「历史记录」或直接进该剧，接在上次停下的位置。

剧听上了之后，倍速和定时关闭在播放页同一屏，见[倍速与定时关闭设置.md](倍速与定时关闭设置.md)。
