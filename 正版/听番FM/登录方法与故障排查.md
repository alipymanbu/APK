## 一、先说结论

登录只要手机号加短信验证码，不用密码；不登录也能浏览和播放大部分内容，登录主要为的是收藏、追更与多设备同步进度。用起来碰到问题时，先按本文的故障对照表走一遍：换网络、查后台权限、对版本，逐层排查。

## 二、登录步骤

1. 打开应用，点底部导航栏的「我的」。
2. 点页面顶部的登录入口。
3. 输入手机号，收短信验证码后填进去，点「登录」完成。

登录状态会记住；换手机后用同一个手机号收验证码登回来，收藏和进度跟着账号走（多端同步是官方介绍页列出的功能，手机与平板之间进度自动接续）。**收不到验证码**别在这个页面干等，按[登录收不到验证码怎么办.md](登录收不到验证码怎么办.md)的顺序查信号、拦截、SIM 卡与欠费。

## 三、会员与积分是怎么回事

- 应用内基础资源可直接收听；部分独家、付费剧集需要 VIP 或单独付费解锁。
- 「我的」页面有充值入口，会员档位常见的是 3 天卡、月卡、季卡等 —— **具体价格与档位以应用内实时显示为准**，页面会随活动调整。
- 不想付费时，可走每日签到、分享任务攒积分，用积分兑换部分内容的收听权限；另外在「作品索引」把「性质」筛成「免费」，出来的整批剧都不需要付费，入口见[搜索广播剧与选集收听.md](搜索广播剧与选集收听.md)第四节。

## 四、常见故障对照表

| 现象 | 先做什么 | 还不行再做 |
| --- | --- | --- |
| 播放卡顿、一直缓冲 | 切换 Wi-Fi 与移动数据各试一次，排除当前网络 | 把该集缓存到本地离线听（见[倍速与定时关闭设置.md](倍速与定时关闭设置.md)第五节）；更新到新版本 |
| 搜不到某部剧 / 剧集不全 | 换更短的关键词重搜 | 确认应用暂未收录；反馈时带上剧名与集数，便于对方定位补全 |
| 定时关闭不生效 | 确认应用没被从后台划掉 | 到系统里把听番FM设为允许后台运行，再设一次定时（各品牌路径见第五节） |
| 倍速超过 2× 声音变调 | 这是快放的物理现象，换回 1.5× 以内 | 无，属正常表现 |
| 更新提醒收不到 | 检查安装时是否允许了通知权限 | 到系统通知设置里允许该应用通知；应用内设置里也有一项通知偏好开关 |
| 闪退或界面异常 | 重启手机，再打开应用 | 升级应用与系统版本；仍不行按第六节清缓存/清数据 |
| 登录收不到验证码 | 按[登录收不到验证码怎么办.md](登录收不到验证码怎么办.md)逐步排查 | 换机测卡，定位手机侧还是应用侧 |

排查顺序上有个通用原则：**网络 → 后台权限 → 版本**，逐层排除，别一次全改，否则不知道是哪一步起的作用。

## 五、后台保护：让定时与后台播放真正生效

定时不生效、放着放着自己停，根因都是系统在后台把应用杀了。各品牌打开保护的路径（截至 2026-09 的各厂商公开支持文档，路径可能随系统版本调整，以你的系统实际菜单为准）：

| 品牌 / 系统 | 怎么设 |
| --- | --- |
| 通用做法 | 多任务界面（上滑停顿）里下拉听番FM的卡片加锁，加锁后不会被一键清理清掉 |
| 华为 / 鸿蒙 | 设置里搜索「应用启动管理」→ 关闭听番FM的自动管理 → 勾选「允许后台活动」；再搜「电池优化」→ 设为不允许；同时在「设置 → 电池」里关掉省电模式 |
| vivo / iQOO | 长按桌面图标 → 应用信息 → 权限与后台，允许后台运行并在电池策略里选不受限 |
| 其它品牌 | 在「设置 → 应用 → 听番FM」里找「省电策略 / 后台耗电 / 自启动」三个开关，全部放开 |

设置完回播放页重新设一次定时验证。另外别用第三方「一键清理」类工具随手清后台 —— 它们不受上面开关约束，会把加了锁的应用一起杀掉。

## 六、闪退与清缓存 / 清数据

按代价从小到大试，每做完一步先复现问题再决定要不要做下一步：

1. **重启手机**：清掉临时故障，成本最低。
2. **检查更新**：应用升级到最新版、系统也升到最新版 —— 旧版本与新系统的兼容问题多数靠这一步解决。
3. **清缓存**：长按桌面图标 → 应用信息 → 存储 → 清除缓存。只删临时文件，登录状态和记录都还在，先做这一步。
4. **清数据**：同一入口选「清除数据」。会退出登录、清掉本地记录与缓存，**收藏与追更跟着账号走，重新登录即恢复**；清完重新用[下载与安装教程.md](下载与安装教程.md)里的包重装也无妨（版本信息以该篇表格为准）。
5. **卸载重装**：桌面长按图标卸载，再从网盘重新下包装一次，处理错误配置残留。
6. **仍闪退**：多是该版本与此机型的适配问题，截图反馈给应用客服，等新版本；同时留意是否只在某部剧的某一集上闪退（换一集试），是单集数据问题就带剧名与集数反馈。
