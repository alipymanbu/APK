## 一、三端支持情况

| 平台 | 安装形式 | 备注 |
| --- | --- | --- |
| Windows | zip 解压 | 0.7.6 及以上要求 Windows 10 21H1（build 19043）或更高；0.2～0.7.5 还支持 Windows 7 SP1+ |
| Android | APK 安装 | 本文提供的安装文件资源即此形态 |
| iOS | IPA 安装 | 无越狱环境且不支持 TrollStore 的话，官方推荐用 Sideloadly 安装，勾选「Enable File Sharing」 |

支持情况截至官方文档当前口径，以后以官方页面为准。

## 二、官方的定位：电脑优先，手机是附属

官方文档写得很直白：这款软件没有为小屏设备优化，无法保证在手机等小屏设备上呈现合理的 UI 尺寸与布局；手机端被定位为附属产品，官方推荐用电脑端获得完整体验。

对你实际有用的四点差异：

- **操作方式两端一致**——官方 FAQ 明确「移动端操作与电脑端一样」，教程在两端通用。
- **卡顿程度不同**——手机端卡顿常见，程度因设备与系统调度而异；电脑端卡了重启软件通常就能缓解。
- **下载体验不同**——移动端自动下载资源包不支持后台下载，下载期间不能切出应用；Windows 端的 10G 存储空间要求特指 AppData 所在分区。
- **作品可以跨端带走**——项目文件（.aap）与存档（.aas）连同同名文件夹拷到另一端的数据目录就能继续用，见[工程文件备份与转移.md](工程文件备份与转移.md)。

## 三、怎么选

- **有电脑、打算认真做剧情**：装 Windows 端，界面布局与性能都有保障，资源包加载也更省心。
- **只想在外面用鉴赏模式看看别人作品，或改改台词**：手机端够用，卡了先关「自动编译」「自动保存」，见[卡顿与常见问题排查.md](卡顿与常见问题排查.md)。
- **手机上做完整项目**：能用，但要有准备——UI 没适配小屏、资源包下载不能切后台、卡顿概率更高。

定了装哪端，就从[下载与安装教程.md](下载与安装教程.md)开始；装完的第一步操作见[剧情制作入门教程.md](剧情制作入门教程.md)。
