## 一、数据目录在哪

| 平台 | 数据目录位置 |
| --- | --- |
| Windows | `C:\Users\<用户名>\AppData\LocalLow\foxxlight\AzureArchive\data` |
| Android | `/storage/emulated/0/Android/data/com.foxxlight.AzureArchive/files/data` |
| iOS | 文件 App 内的 `我的iPhone(iPad)/AzureArchive/data` |

安卓端推荐用 NP 管理器一类的文件管理器定位和编辑这个目录。

## 二、目录里各是什么

| 成员 | 存什么 |
| --- | --- |
| `assets/` | 资源文件，除离线安装外一般不用动 |
| `overrides/` | 全局自定义资源，配置方法见[全局自定义角色与manifest配置.md](全局自定义角色与manifest配置.md) |
| `projects/` | 项目文件（.aap），每个项目文件还有与之同名的自定义资源文件夹 |
| `saves/` | 存档文件（.aas），同样可能带同名自定义资源文件夹 |
| `settings/` | 设置文件 |
| `manualInstall/` | 手动安装资源包时用到 |

## 三、怎么备份

把整个 data 文件夹整份拷走，就是最完整的备份——项目、存档、自定义资源、设置全在里面。

## 四、怎么转移到另一台设备

官方明确支持任意端到任意端的转移：把 `.aap` 与 `.aas` 文件连同它们的同名文件夹，放进目标设备数据目录的对应位置即可。

两个要点：

- 必须连同名文件夹一起拷——自定义资源跟在项目、存档的同名文件夹里，只拷 `.aap`/`.aas` 文件，剧情里的自定义角色和素材会丢。
- 手机上找不到 `Android/data` 目录时，用 NP 管理器这类能访问该层级的文件管理器。

转移过去之后打不开或素材缺失，先检查同名文件夹有没有到位，再对照[卡顿与常见问题排查.md](卡顿与常见问题排查.md)处理。
