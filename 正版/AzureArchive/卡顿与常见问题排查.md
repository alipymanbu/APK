## 一、先学会看报错

遇到异常，键盘按 **F8** 可以查看并复制报错信息；没有 F8 键的环境，在设置里开启调试控件，然后点屏幕右侧的框。把报错原文拿去官方反馈渠道提问，比一句「我卡住了」有用得多。

## 二、安装与资源包类问题

| 现象 | 处理办法 |
| --- | --- |
| 一直卡在「检查更新」 | 按数据目录找到 settings 文件夹删掉，具体见[官方 B 站专栏](https://www.bilibili.com/read/cv36296375/) |
| 一直卡在「等待中」 | 多半是资源包与本体版本不匹配，核对版本对应表后重装，表在[下载与安装教程.md](下载与安装教程.md) |
| 提示「无法加载资源包」 | 同样先核对版本匹配；安卓端安装资源包时中途切出应用也会导致失败 |
| 图片或角色在工程、鉴赏模式里缺失 | 没装资源包就先装；已装过的重新安装资源包 |
| 音乐、角色、图片无法使用，左下角有弹窗 | 重新安装资源包，或参考[官方 B 站专栏](https://www.bilibili.com/opus/1029243098115342336)的说明 |
| 手动安装时选中 zip 后白屏卡住 | 正常现象，等处理完成，提示重启后重启即可 |

数据目录在哪（settings 文件夹就在它下面）：Windows 端是 `C:\Users\<用户名>\AppData\LocalLow\foxxlight\AzureArchive\data`，安卓端是 `/storage/emulated/0/Android/data/com.foxxlight.AzureArchive/files/data`，iOS 端在文件 App 的 `我的iPhone(iPad)/AzureArchive/data`（AppData 是隐藏文件夹，找不到先开「显示隐藏项目」）。settings 文件夹删除后软件会自动重建，改炸了不用怕。

## 三、卡顿类问题

按顺序试：

1. 重启软件；手机端不行就重启手机。
2. 在设置里关闭「自动编译」和「自动保存」——官方文档点名这两个选项，关掉能明显缓解。
3. 检查后台程序是不是开太多了。
4. 手机端卡顿在很大程度上来自设备与系统调度，官方明确说手机端是附属产品、推荐用电脑端。两端差异详见[手机端与电脑端怎么选.md](手机端与电脑端怎么选.md)。

## 四、编辑器里的「不生效」

- **动作代码不生效**（比如角色倒地自起）：先检查代码里有没有混入中文字符（包括全角标点），这是最常见的原因；倒地动作的做法可以看官方 B 站账号的视频教程。
- **角色倒地或消失后回到原位**：官方给的做法是在倒地动作的脚本后加一个等待指令——额外指令填 `wait`、时间填 1500；或者在动作脚本后面加一个删除选中角色的脚本。
- **spine 文件提示「当前版本不可用」**：不支持 3.8.75 版本，改用 3.8.96，见[自定义角色导入方法.md](自定义角色导入方法.md)。

## 五、角色库里找不到某个角色

AzureArchive 的角色库跟随《蔚蓝档案》国际服，日服最新角色未必收录。官方给的替代方案是用自定义角色功能自己导入，见[自定义角色导入方法.md](自定义角色导入方法.md)。
