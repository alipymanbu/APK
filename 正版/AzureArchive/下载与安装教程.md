## 一、安装前先确认这几件事

AzureArchive 是 Foxxlight（狐光体）开发维护的《蔚蓝档案》非官方剧情编辑器，软件本体免费，目前仍处于测试阶段。官方文档也说明这是一个爱好项目，Bug 修复按业余节奏来——装之前先把预期摆正：它不是一个装完就保证稳定运行的工具。

| 项目 | 说明 |
| --- | --- |
| 本篇安装包版本 | 0.7.9.2 |
| 安装包大小 | 约 318.25M |
| 包名 | `com.foxxlight.AzureArchive` |
| MD5 | `31C471BB04150C7DE307336378047EC7` |
| 存储空间 | 需预留 10G 以上；Windows 端特指 AppData 文件夹所在分区 |
| Windows 系统 | 0.7.6 起要求 Windows 10 21H1（build 19043）及以上 |

两点提醒：

- 本体 318M 只是开始，资源包是另一笔开销（0.6.0 以上版本预加载文件约 600M，离线本地资源包约 4G），10G 的预留里已经包含了这些余量。
- 装完先别急着删安装包。资源包加载出问题时，可能要用「手动安装」重来一遍。

## 二、从哪里下载

官方文档站是 [aadoc.foxxlight.top](https://aadoc.foxxlight.top/)，官方在文档里写明软件完全免费、仅在官方网站提供下载，在其他平台看到付费的可以直接要求退款。

本文提供的 [AzureArchive 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ff41b2ade19d) 即上面表格里 0.7.9.2 这一版的安卓安装包，转存后取用即可。

## 三、安装与首次启动（安卓）

1. 安装 APK 后打开，程序会先问你要一个昵称（游戏里「老师」的名字），填好确认进入。
2. 首次启动会加载数据，这一步明显偏慢，属于正常现象，等它跑完。
3. 加载完进入首页，只有「鉴赏模式」和「项目模式」两个入口——前者看别人做好的剧情，后者才是自己动手做。

安卓端在资源包自动下载阶段不支持后台下载，下载期间别切出应用，切出可能导致下载中断或资源包损坏。

## 四、资源包怎么装

剧情素材不随 APK 走，要另外装资源包，分两条路。

**自动安装（默认路径）**：首次启动问完昵称后程序自动下载所需资源，下载支持断点续传。0.6.0 及以上版本先下约 600M 的预加载文件，之后在线获取资源。网络环境差时会下得慢、频繁中断、报各种神秘的错——官方文档给的出路是改善网络，或者转手动安装。

**手动安装（自动下载失败时）**：

1. 下载与你本体版本对应的资源包 zip（对照表见下一节）。
2. 在 AzureArchive 的加载界面点「手动安装」按钮，选中这个 zip。
3. 选中后画面卡住白屏是正常现象，等它处理完，提示重启后重启软件即可。

如果连 zip 方式也不行，还可以把 zip 里的内容直接解压到手动安装文件夹，版本匹配的话程序启动时会自动装。安卓端路径是：

```
/storage/emulated/0/Android/data/com.foxxlight.AzureArchive/files/data/manual_install
```

这个文件夹要自己创建，文件放进去之后它会自动消失（等于安装完成）。

## 五、资源包和本体版本的对应关系

资源包装错版本，是「一直卡在等待」「提示无法加载资源包」的最常见原因。按官方文档当前的对照表（以后以官方页面为准）：

| 本体版本 | 所需资源包 |
| --- | --- |
| 0.7.8 | 202406030217（从这个系列起，旧版本不再支持在线服务器） |
| 0.7.9 | 202408180000（与之前版本不适配，没有移动端版本） |
| 0.7.9.1 及以上 | 202408202213（另有仅限 Windows 的 202412150051，部分特效无法使用） |

本文安装包是 0.7.9.2，对应资源包 202408202213。

装完之后的第一步操作见[剧情制作入门教程.md](剧情制作入门教程.md)；装的过程中卡住或报错，先翻[卡顿与常见问题排查.md](卡顿与常见问题排查.md)。
