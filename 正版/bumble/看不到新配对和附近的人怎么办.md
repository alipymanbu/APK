# Bumble 看不到新配对和附近的人怎么办

## 一、先分清三种「看不到」

| 你的现象 | 更可能的原因 | 去哪修 |
|---|---|---|
| 「用户」里刷不出新档案 | 筛选太窄、位置错、档案被隐藏 | 第二节、第三节 |
| 有人喜欢你但列表里是空的/模糊 | 免费版「为你心动」就是模糊的 | [订阅与价格.md](订阅与价格.md) |
| 配对出现了但收不到提醒 | 通知权限或系统设置 | 第四节 |

**最常见的真凶是第一节里你自己的筛选**——半径拉太小、年龄区间太窄，队列其实是「按设计为空」，看起来却像坏了。

## 二、筛选与隐藏开关自查

按顺序排查，每条都给得出可执行动作：

1. **距离半径**：「用户」右上角漏斗 → 距离，人少的地区先拉到最大试一轮；
2. **年龄范围**：上下限都放宽 2~3 岁再看有没有变化；
3. **想认识哪类人群**：确认性别取向设置没把你想要的人排除掉；
4. **验证状态**：这个筛选只给你看过了照片认证的人，池子会明显变小（判断要不要开见 [账号与隐私安全设置.md](账号与隐私安全设置.md)）；
5. **瞌睡模式**：开着的话档案对所有人隐藏，先关掉；
6. **隐身模式**：Premium 的这个功能只让**你喜欢过的人**看到你，没右滑过的人根本刷不到你——如果你开了它又很少右滑，档案等于半隐身；
7. **每日喜欢额度**：额度用完后你自己的滑动会停（24 小时重置），但**不影响别人刷到你**——这条只解释「滑不动」，不解释「没人」。

改完一两条就等几分钟再开应用，别一次全改（改完没变化就分不清是哪条起的作用）。

## 三、位置跑偏怎么修

位置错了，推给你的就是另一个城市的人。修复步骤按系统给：

**iOS**：

1. 设置 → 隐私 → 定位服务，把开关关掉；
2. 重启手机（关机再开机）；
3. 回到定位服务把开关打开；
4. 重开 Bumble。还不行就进 定位服务 → Bumble → 选「下次询问」，重开应用时选「使用期间允许」。

**Android**：

1. 确认系统定位总开关打开，且 Bumble 拿到了定位权限（设置 → 应用 → Bumble → 权限 → 位置）；
2. 重启手机后重开应用；
3. 仍不对就卸载重装（安装包入口见 [下载与安装教程.md](下载与安装教程.md)，重装后记得重新给权限）。

系统层还有两个会让定位异常的干扰项：**省电模式**（限制后台定位）与 **VPN**（改变你表现出的位置，还会拦短信验证码）。两个都先关掉再测。

## 四、配对来了却没提醒

排查顺序固定不动：

1. **系统通知权限**：设置 → 应用 → Bumble → 通知，总开关打开，配对/消息/点赞几类各自允许；
2. **应用内开关**：Bumble 设置里的通知选项也要开——两层都开才有提醒；
3. **勿扰与专注模式**：手机的免打扰、专注模式若把社交类静音了，Bumble 会正常收到但不响；
4. **后台限制**：省电策略把 Bumble 的后台活动砍掉后，推送到不了——把它加入电池优化白名单。

**官方「已知问题」里当前列着一条**：通知开关全开却仍收不到邮件/推送（帮助中心的故障排除文章会更新状态，以当时页面为准）。你按上面四步都查过还收不到，属于这条，等修复或联系客服，不是你的设置问题。

另外两条官方在册的已知问题一并留意：旅行模式下应用变慢或加载不出来；聊天界面里某些消息打不开（后者先按 [常见问题与故障排除.md](常见问题与故障排除.md) 的网络与清缓存步骤排一遍）。

## 五、什么时候怀疑是账号被限

设置全对、位置正常，但**连续很多天**既没人喜欢你也没人回你，可能是账号被降权或在审核中（原因常见于被举报、频繁举报别人、短时间大量滑动、资料里留了外部联系方式）。处理办法只有三条：

1. 正常使用几天，别删号重建——重建档案往往比原档案权重更低；
2. 把档案补齐（照片、简介、认证），认证是明确的加分项（见 [照片认证总是失败怎么办.md](照片认证总是失败怎么办.md)）；
3. 有明确证据被误判的，走客服提交请求，材料按 [常见问题与故障排除.md](常见问题与故障排除.md) 第四节准备。

「限流」没有官方公开的判据，上面第 3 条里的说法多来自用户反馈——**无法确认时以客服答复为准**，别按论坛说法反复删号重装。
