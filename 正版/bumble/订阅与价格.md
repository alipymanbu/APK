## 一、先说结论：免费能用，卡在哪

Bumble 免费版不是试用期，聊天、配对、照片认证、基础筛选全都完整开放。它卡你的是**数量**，不是功能：

- 每日喜欢额度有限（用完 24 小时重置）；
- 延长配对每天只有 1 次；
- 已失效的配对捞不回来；
- 「为你心动」里喜欢你的人是模糊的；
- 左滑不能撤销。

所以判断要不要掏钱，只看一件事：**上面哪一条真的卡住了你**。都不卡，免费版够用。

## 二、三档订阅对照

| 能力 | 免费 | Boost | Premium | Premium+ |
|---|---|---|---|---|
| 每日喜欢额度 | 有限 | 有限 | 无限 | 无限 |
| 撤销左滑（改变心意） | - | 有 | 有 | 有 |
| 捞回已失效配对 | - | 有 | 有 | 有 |
| 延长配对 | 每天 1 次 | 无限 | 无限 | 无限 |
| 查看喜欢你的人 | 模糊 | 模糊 | 清晰 | 清晰 |
| 隐身模式（只对喜欢的人可见） | - | - | 有 | 有 |
| 旅行模式（换位置） | - | - | 有 | 有 |
| 高级筛选（含交友意图） | - | - | 有 | 有 |
| 每周免费 SuperSwipe | - | 5 | 5 | 10 |
| 每周免费 Spotlight | - | 1 | 1 | 2 |
| 优先点赞、档案每日推荐 | - | - | - | 有 |

两个容易被忽略的规则：

- **Spotlight 单次只持续 30 分钟**，作用是这段时间内让更多人看到你的档案（对方不会知道你用了它）；
- **每周额度不累计**——订阅周期开始时自动刷新，没用完就没了。

## 三、价格是多少

价格**因渠道、地区、订阅时长而异，以你设备商店里当时显示的为准**。可核对的两组公开数字：

- **iOS 中国区 App Store**（官方页面列出的内购项，2026 年 9 月查询）：7 天 Bumble Premium ¥63、1 个月 Bumble Premium ¥138、7 天 Bumble Boost ¥38，另有按次购买的 SuperSwipe 包。
- **美元区参考价**（第三方价格追踪站汇总，2026 年口径）：Boost 约 $14.99/周 或 $39.99/月，Premium 约 $24.99/周 或 $89.99/月。

同一档订阅，周付折算下来比月付贵不少，**先看月价再决定**。另外 Bumble 不时有首期优惠价，续费时会跳回原价——这是订阅制的常态，别被首期价误导。

## 四、安卓怎么付钱

安卓端的内购**必须走 Google Play**：你需要把信用卡或 PayPal 绑到 Google 账号上，Bumble 应用内的购买统一通过 Google Play 结算。不想绑定支付方式的话，官方给的替代路径是在网页端购买——但注意 Bumble 已转为纯应用服务，网页端仅限存量操作，以官方帮助中心当时说明为准。

通过其他渠道（短信代扣等）买的订阅，取消方式各不相同，官方帮助中心的「付费功能」分类下按渠道列了对应办法。

## 五、怎么取消自动续订

订阅默认自动续订，取消入口在**你付款的那个渠道**，不在 Bumble 应用里：

1. **Google Play**：点头像 → 付款和订阅 → 订阅 → Bumble → 取消；
2. **App Store**：设置 → 你的 Apple ID → 订阅 → Bumble → 取消订阅；
3. **PayPal / 信用卡直绑**：去对应平台的自动付款/预授权设置里撤掉。

取消后**当前周期内已付的功能仍可用到到期**，到期不再扣款。两个常见误区：

- **解绑银行卡 ≠ 取消订阅**——解绑只是换了支付凭证，订阅关系还在，可能照样扣款失败后反复重试；
- **删应用 / 删账号的处理不同**：删掉手机上的应用不会取消订阅；删账号前官方建议先把订阅取消掉，否则扣款渠道仍在。

试用期内想退，在扣款前取消才不产生费用；已扣款的退款要走官方的退款申请流程（在帮助中心提交，需说明情况）。

一个冷门但会真实发生的例外：**照片认证一直失败、导致你登不进账号且重试次数用完时，订阅不会继续自动续费**，此时同样可以申请退款（Apple 渠道买的须直接找 Apple）；找回账号后，已覆盖周期内的权益仍可用到到期（认证的重试规则见 [照片认证总是失败怎么办.md](照片认证总是失败怎么办.md)）。

付费只是为了少受数量限制，规则本身还是那套——倒计时、开场消息怎么发，见 [配对与聊天规则.md](配对与聊天规则.md)。
