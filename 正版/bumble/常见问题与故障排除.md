## 一、收不到验证码

按命中率从高到低试，多数到第三步就好了：

1. **关掉 VPN**——官方明确列出的原因：VPN 会拦掉 Bumble 发出的短信，确保你从注册所在国发请求；
2. **核对号码**：确认输对了、带对了国家代码；
3. **改用来电验证**：界面上点「没收到短信」，换电话方式——**不用接起来**，输入来电号码后六位即可；
4. **等几分钟再点重发**：频繁重发会被限制，官方建议同一号码**满 24 小时后再试**；
5. **切换网络**：Wi-Fi 和移动数据互换一次，或开关一次飞行模式；
6. **重启手机**再重新请求一次。

还不行，用备用登录方式（Facebook / Apple ID / Passkey，设置路径见 [账号与隐私安全设置.md](账号与隐私安全设置.md)）登进去，进应用后再改绑手机号。

## 二、应用闪退、卡住、白屏

官方排查顺序照抄即可，别跳步——很多「疑难杂症」在第二步就解决：

1. **查网络**：开关一次飞行模式；换个 Wi-Fi 或用移动数据试试，排除是网的问题；
2. **更新版本**：去商店看有没有新版。版本过旧是崩溃的常见原因；侧载装的包商店不会提醒你，得自己对照官方页面的当时版本号；
3. **强停重开**：设置 → 应用 → Bumble → 强制停止，再打开；
4. **登出重登**：个人档案 → 设置 → 底部「登出」，重启应用再登；
5. **清缓存**：设置 → 应用 → Bumble → 存储 → **清除缓存**；还不好再点**清除数据**（这不会删你的账号，只是把应用恢复到初次安装状态，本机的登录态和草稿会没）；
6. **查权限和空间**：定位、相机、照片、通知四项权限是否给齐；手机存储快满的先腾空间——**空间不足会直接导致卡顿与崩溃**；
7. **关省电模式、VPN、广告拦截器**：这三样都可能干扰 Bumble 联网或后台运行；
8. **重启手机**：关机 30 秒再开，清掉卡住的后台进程。

八步走完还坏，就是应用侧的已知问题或账号侧的问题了，接着看第四节。

## 三、消息发不出去、配对不见先别慌

三种「看起来像坏了」的情况其实是规则：

| 现象 | 真实原因 | 该做什么 |
|---|---|---|
| 配对还在，但聊天框发不了消息 | 异性配对里你在等待女方开场，24 小时倒计时中 | 等，或用每天 1 次的延长（规则见 [配对与聊天规则.md](配对与聊天规则.md)） |
| 某个配对突然消失了 | 倒计时到期，配对失效 | 去配对队列的已失效列表找回（需 Boost 及以上） |
| 对方发来的图片显示为模糊打码 | 预期行为，不是加载失败 | 自行点开查看 |
| 右滑过的人再也刷不到 | 右滑无法撤回，对方已从你的推荐流移除 | 无法找回，只能通过已配对入口联系 |

排除这些之后仍然发不出去，回到本节第二节重跑一遍网络与清缓存——消息类问题九成出在这两处。

## 四、什么时候该找客服

走完排查仍不正常（登录被拒、支付扣款异常、内容被误判下架），在官方帮助中心提交请求，准备好四样材料：

1. 准确描述问题（从哪一步开始、报什么错）；
2. 屏幕截图；
3. 机型与系统版本；
4. 出问题时你具体做了什么。

带错误代码的先去帮助中心的错误代码文章查一遍含义——那篇文章按代码列了处置办法，多数能自助解决。登录本身的疑难（收不到码）在第一节已经排过，别重复提交。

提交前先确认自己撞的不是**官方在册的已知问题**（帮助中心的故障排除文章会滚动更新，以当时页面为准）：通知全开仍收不到推送、旅行模式下应用卡慢、聊天里部分消息打不开——这三条官方明说在修，你的设置没问题，等修复即可。收不到推送的自查四步（系统权限 → 应用内开关 → 勿扰/专注模式 → 后台限制）见 [看不到新配对和附近的人怎么办.md](看不到新配对和附近的人怎么办.md)。

认证环节的失败不算故障：姿势没照抄、光线太暗、重试次数用完各有各的解法，别混进普通故障里提工单，先走 [照片认证总是失败怎么办.md](照片认证总是失败怎么办.md)。

新装或重装的入口在 [下载与安装教程.md](下载与安装教程.md)；重装后第一件事是把备用登录方式补上，见 [账号与隐私安全设置.md](账号与隐私安全设置.md)。
