## 一、先对一下版本：你要装的是哪一份

Medisafe 在 Google Play 等商店持续更新，商店里的版本号通常比你手上这份新。网盘里这份安装包的信息如下，装之前可以先核对一遍：

| --- | --- |
| 版本 | 9.44.4 |
| 包名 | `com.medisafe.android.client` |
| 安装包大小 | 187.37M |
| MD5 | `00CABF22F5D80A0FCF7EE6563A12C6A2` |
| 系统要求 | 安卓 5.2 以上（安装包信息标注） |
| 信息核对时间 | 2026-09-27 |

两点说明：

- 包名是 `com.medisafe.android.client`，这是官方安卓包的固定标识；如果你从别处拿到的 APK 包名对不上，就要当心了。
- 商店在售的新版本对系统版本的要求会更高（2026-09 时点商店页面已要求安卓 11 以上），且功能与免费/付费口径可能调整，以[官方帮助中心](https://help-center.medisafe.com/en/)当时显示为准。

## 二、把安装包拿进手机

这份 Medisafe 安装文件资源放在夸克网盘里：[Medisafe 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5f0245cab7af)，流程是「转存到自己网盘 → 下载到手机」：

1. 在电脑或手机浏览器打开上面的网盘链接，登录夸克账号后选择「保存到网盘」；
2. 打开手机上的夸克 App（或先在电脑下载、再用数据线传到手机），找到刚转存的文件，下载到手机存储；
3. 记住下载位置，通常在 `Download` 目录。

如果你更习惯用商店安装，也可以直接在 Google Play 搜 Medisafe——但商店版本与你转存的这份不一定是同一个版本，版本事实以本页第一节表格为准。

## 三、安装步骤与「未知来源」授权

安卓不允许直接安装来自商店之外的 APK，首次安装需要给一次授权：

1. 在文件管理器里点开下载好的 APK 文件；
2. 系统弹出「出于安全考虑，手机已设置为禁止安装未知来源应用」之类提示时，点「设置」进入对应页面，打开「允许安装未知应用」（不同品牌的入口略有差异，见下表）；
3. 返回后继续安装，等待完成。

| 手机品牌 | 授权入口大致位置 |
| --- | --- |
| 小米 / 红米 | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / vivo | 设置 → 安全 → 安装未知应用 |
| 三星 | 设置 → 生物识别和安全性 → 安装未知应用 |
| 原生 / 其他 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

（各品牌系统版本不同，入口名称可能有出入，认准「安装未知应用 / 未知来源」这个关键词即可。）

部分国产系统还会额外询问「是否允许此应用安装其他应用」，针对的是你的文件管理器或浏览器，允许一次即可。

## 四、装完之后

安装完成点「打开」，应用会先走一遍欢迎流程。接下来要做的是注册账号、添加第一个药物和设置提醒时间，具体操作见[首次设置与添加药物](首次设置与添加药物.md)。

装完先别急着删安装包——如果你之后要给家里老人另装一部手机，还得再用一次。

## 五、装完没提醒？先看这一篇

提醒能准时响，靠的是系统允许应用在后台弹通知。很多国产手机默认收紧后台、清理类应用会误杀提醒，这是「装好了却不响」的头号原因，逐项排查见[提醒不响怎么排查](提醒不响怎么排查.md)。
