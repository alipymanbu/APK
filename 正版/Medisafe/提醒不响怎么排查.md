## 一、最常见的三个原因

按官方帮助中心的说法，提醒失灵大多不是应用坏了，而是被系统或别的应用拦掉了：

1. **省电设置**：系统把 Medisafe 判成「不重要后台」，到点不让它弹通知；
2. **清理类应用**：Clean Master、360 Security、CM Security、Fast Booster 这类「清理加速」应用在清理后台时会顺手杀掉 Medisafe 的提醒进程——官方 FAQ 点名了这几款；
3. **通知权限没给**：应用根本没拿到弹通知的许可。

## 二、逐项排查清单

按顺序做，每做完一项用第四节的方法测一次：

| 步骤 | 操作 | 位置 |
| --- | --- | --- |
| 1 | 打开 Medisafe 的通知权限 | 设置 → 应用 → Medisafe → 通知 |
| 2 | 关掉对 Medisafe 的电池优化 | 设置 → 应用 → Medisafe → 电池 → 选「不限制 / 允许后台活动」 |
| 3 | 允许自启动与后台运行 | 设置 → 应用 → Medisafe → 自启动（国产 ROM 常见） |
| 4 | 关闭省电模式 | 设置 → 电池 → 省电/超级省电模式（省电时通知会被推迟） |
| 5 | 允许后台数据 | 设置 → 应用 → Medisafe → 流量使用 → 后台数据设为允许 |
| 6 | 卸载或加白清理类应用 | 把 Medisafe 加进 Clean Master、360 Security 等应用的白名单，或干脆卸载它们 |
| 7 | 关掉静音与勿扰模式 | 手机关机键长按菜单 / 设置 → 声音（静音状态下提醒不发声，官方安全须知里专门列了这一条） |

国产系统（小米、华为、OPPO、vivo 等）还有各自的「省电策略」，把 Medisafe 设为「无限制」并锁定后台任务，能挡掉绝大多数误杀。

## 三、两个容易漏的角落

**时区**：跨时区用（比如换了手机卡或出国）可能让提醒时间对不上。应用会自动检测时区，但如果你手动改过系统时间，记得核对应用内显示的下次提醒时间对不对。

**多设备登录同一账号**：官方明确建议不要在两台时区不同的设备上登录同一账号跑提醒——提醒时间会互相打架。想给家人另一台设备也盯着吃药，正确做法是用 Medfriend 协作，见[Medfriend家人协作](Medfriend家人协作.md)。

## 四、怎么验证提醒真的会响

别等到第二天吃药时间才发现又没响，加一个两分钟后的测试剂量：

1. 在主页点「+」→「添加剂量」，选任意一个已有药物；
2. 时间设成两分钟后，保存；
3. 锁屏放桌上等它响。

能准时弹、声音正常，说明排查生效；不弹就回到第二节从第 1 步再过一遍。

## 五、还不行的话

把应用升级到商店最新版试一次（老版本的提醒逻辑可能没适配你的新系统）；仍不行就写信给官方支持 `support@medisafe.com`，附上手机型号和系统版本。重装前先确认账号已在登录状态，数据有云端备份再动手，步骤见[数据备份与换机迁移](数据备份与换机迁移.md)。
