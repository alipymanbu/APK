# Medisafe 首次设置与添加药物

> 本篇讲装好 Medisafe 后的第一轮设置：注册账号、添加药物、把服药时间排进计划、给不同药物换提醒声音。

## 一、先注册账号，再开始记药

注册不是强制的，但没有账号就没有云端备份，换手机时数据带不走。建议第一件事就把账号建好：

1. 点左上角头像，进入「My Profile（我的资料）」；
2. 选一个头像并填好基本信息；
3. 点「Sign Up（注册）」，输入邮箱和密码；
4. 去邮箱点确认链接，或把邮件里的验证码输回应用，账号即生效。

忘记密码时，在欢迎界面或应用内「More」菜单点「Log in」→「Forgot password?」，输入注册邮箱重置；如果系统认不出这个邮箱，多半是你注册时用了另一个邮箱地址。

## 二、添加第一个药物

注册完回到主页（一个药盒样式的界面），添加药物：

1. 点主页右下角的「+」；
2. 搜索药名（支持常见处方药、非处方药、维生素与保健品）；
3. 选择剂量（一片、两片、半片或自定义剂量）；
4. 设定服药时间与重复规则（每天、每周或指定几天）；
5. 保存后，主页药盒里就会出现这颗药。

给家人吃药的场景一样适用：把对象换成家人的药即可，也可以在「My Profile」里为家人单开档案，各记各的，互不混淆。

## 三、把服药计划排对

服药计划不只有「每天一次」一种排法，常见几类：

| 场景 | 怎么设 |
| --- | --- |
| 每天固定时间 | 添加药物时直接选时间与重复规则 |
| 一天多次（早中晚） | 同一个药物加多个剂量时间点 |
| 复杂方案（隔天、每周几） | 在剂量计划里选自定义频率 |
| 按需服用的药（疼了才吃） | 把药物设为「as needed（按需）」，吃的时候手动记录，不弹固定提醒 |
| 周末想睡懒觉 | 用周末模式（weekend mode）单独推迟周末的提醒时间 |

需要改时间或剂量时：点底部菜单「Medications」，点进要改的药物，点右上角铅笔图标修改，改完点「Update」保存。

## 四、把提醒声音调得能分清

家里药多的时候，不同药物用不同提示音很有用——听到声音就知道该吃哪颗。Medisafe 支持给每个药物单独选提醒铃声，付费版可选的声音更多（免费/付费的具体划分见[订阅与免费区别](订阅与免费区别.md)）。设好后建议按[提醒不响怎么排查](提醒不响怎么排查.md)做一次两分钟的实测，确认手机真能准时弹出来。

## 五、顺手把健康指标也记上

除了记吃药，你还能顺手把二十多项健康测量项记在一起：血压、血糖、体重、血氧等，适合慢病管理时把「吃药 + 测量」放在一起看。测量数据同样能生成报告发给医生。这一块不用急着一轮设完，先把药和提醒跑顺，测量项之后随时可以补。
