## 一、四种连接方式，对号入座

| 连接方式 | 适合谁 | 前提条件 |
| --- | --- | --- |
| WiFi | 家里、办公室最常用的接法 | 手机与打印机连**同一个路由器** |
| 蓝牙 | 便携式热敏打印机、小票机 | 打印机带蓝牙功能 |
| USB-OTG 直连 | 没有网络的环境、无 WiFi 模块的老打印机 | 一根 OTG 转接线 + 打印机的 USB 线 |
| 网络共享 | 打印机插在电脑上、本身不能联网 | 电脑开启打印机共享，手机与电脑同一局域网 |

前三种在应用里选打印机时会直接出现；第四种对应官方说的 Windows 共享（SMB/CIFS）与 Mac/Linux 共享（Bonjour/IPP/LPD）—— 打印机挂在电脑上，手机通过局域网找到它。

## 三、三类打印技术都覆盖

喷墨、激光、热敏三类打印机都能连，另外还包括：支持 AirPrint 协议的机型、Mopria 认证机型、移动热敏打印机（随身小票机、标签机这类）。官方口径是「几乎任何喷墨、激光或热敏打印机」—— 清单外的小众品牌未必打不通，值得先试。

## 四、判断顺序：你的打印机属不属于「能用」

1. **先查型号系列**：打印机机身或说明书上有型号（比如 HP Deskjet 2700），对照上面表格里的系列名。
2. **查协议标识**：机身或包装上找 AirPrint / Mopria 标识，有其中之一就能连。
3. **都没有 → 试 USB 直连**：用 OTG 线把打印机 USB 口接到手机，不少没有 WiFi 模块的老打印机靠这条路过关（设置步骤见[用OTG线直连打印机怎么设置](用OTG线直连打印机怎么设置.md)）。
4. **打印机插在电脑上**：在电脑系统里把打印机设为共享，手机与电脑连同一网络后搜。

## 五、搜不到打印机的高频原因

最常见的三条，按顺序排查：

1. **手机在用移动数据，或打印机连的是访客网络** —— 必须同一局域网才能搜到；
2. **权限没给** —— 位置 / 附近设备权限被拒后，WiFi 搜索会失败或列表一直为空，权限说明见[下载与安装教程](下载与安装教程.md)第四节；
3. **打印机在休眠** —— 部分机型休眠时不响应搜索，按一下打印机上的任意键唤醒再搜。

这几条都排除后还不行 —— 手动按 IP 添加、蓝牙先配对、换连接方式兜底等更完整的排查，见[打印机搜不到怎么办](打印机搜不到怎么办.md)；USB 直连的设置与排查单独有一篇：[用OTG线直连打印机怎么设置](用OTG线直连打印机怎么设置.md)。

确认打印机连得上之后，怎么在应用里选中它、发出第一张打印任务，见[怎么打印文件和照片](怎么打印文件和照片.md)。
