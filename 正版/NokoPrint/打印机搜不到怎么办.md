## 一、先按这六条快查

绝大多数「搜不到」出在这六处，按顺序过一遍：

| 序号 | 检查什么 | 怎么处理 |
| --- | --- | --- |
| 1 | 手机是不是在用移动数据 | 切到打印机连的那个 WiFi；USB 直连的不受此条影响 |
| 2 | 打印机是不是连在访客网络 / 另一个路由器上 | 手机与打印机必须**同一路由器**下的同一网络，访客网络通常隔离设备 |
| 3 | 位置 / 附近设备权限给了没有 | 系统「应用详情 → 权限」里打开后，把应用完全关掉重开（权限说明见[下载与安装教程](下载与安装教程.md)） |
| 4 | 打印机是不是在休眠 | 按一下机身任意键唤醒，部分机型休眠时不响应搜索 |
| 5 | 打印机自己连上网没有 | 在打印机面板上看 WiFi 标志或网络状态；显示离线就先重连打印机的 WiFi |
| 6 | 是不是偶发的扫描失败 | 打印机、路由器各重启一次，再重新打开应用搜 |

## 二、自动搜索一直失败：手动按 IP 添加

打印机其实在网上、只是扫不出来时，可以绕过自动搜索，直接按 IP 添加（多个第三方指南提到这个做法，应用内入口名称以你装的版本为准）：

1. **拿到打印机的局域网 IP**，两个来源任选：
   - 打印机面板：进「设置 → 网络 / 无线」这类菜单，屏幕上会显示 IP（形如 `192.168.1.x`）；
   - 路由器管理页：浏览器打开路由器管理地址，在「已连接设备」列表里找打印机名字。
2. 在应用里选**手动添加 / 按 IP 添加**打印机，把 IP 填进去。
3. 添加成功后这台打印机会留在列表里，之后直接选用即可。

填了 IP 还是连不上 → 打印机的 IP 多半变了（路由器重新分配过），重查一次再填；也可以在路由器里给打印机绑一个固定 IP，一劳永逸。

## 三、蓝牙 / USB 打印机搜不到时

- **蓝牙打印机**：先到手机的系统蓝牙设置里完成**配对**，再回应用里找 —— 应用内搜不到时多数是系统层还没配对；
- **USB 直连的**：搜不到是另一套原因（转接线、数据线、USB 权限），单独有一篇排查，见[用OTG线直连打印机怎么设置](用OTG线直连打印机怎么设置.md)。

## 四、还搜不到：换一条连接路子兜底

WiFi 这条路实在不通，不必死磕：

- 打印机有 USB 口 → 买一根几块钱的 OTG 转接头走直连（[用OTG线直连打印机怎么设置](用OTG线直连打印机怎么设置.md)）；
- 打印机插在电脑上 → 电脑开打印机共享，手机从局域网连（接入方式对照见[支持的打印机与连接方式](支持的打印机与连接方式.md)）。

连上之后的选文件、设参数流程见[怎么打印文件和照片](怎么打印文件和照片.md)。
