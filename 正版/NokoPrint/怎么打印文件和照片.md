## 一、整体流程：四步

1. 打开应用，等它列出打印机；
2. 选中你的打印机；
3. 选要打的文件（照片 / 文档 / 网页 / 云端）；
4. 改参数、看预览、按打印。

## 二、第一次用：把打印机找出来

打开应用后它会自动扫描三种连接的打印机：同一 WiFi 下的网络打印机、蓝牙打印机、用 OTG 线插在手机上的 USB 打印机。扫描有结果取决于三件事：

- **手机与打印机在同一 WiFi**（USB 直连的除外）；
- **位置 / 附近设备权限已允许** —— 不给就搜不到，权限说明见[下载与安装教程](下载与安装教程.md)；
- **打印机没在休眠** —— 休眠中先按一下机身按键唤醒。

打印机插在电脑上共享出来的接法，看[支持的打印机与连接方式](支持的打印机与连接方式.md)里的判断顺序。

## 三、能打哪些文件、从哪里打

应用内可选的文件来源与格式（官方口径）：

| 来源 | 格式 |
| --- | --- |
| 手机相册 | JPG、PNG、GIF、WEBP |
| 手机存储 | PDF、Word / Excel / PowerPoint（DOC、XLS、PPT、TXT 等常见文档后缀） |
| 邮件附件 | PDF、DOC、XLS、PPT、TXT |
| 云服务 | Google Drive 等云端文件 |
| 网页 | 用内置浏览器打开后直接打印 |

两个实用点：

- **多张照片合成一页**：选多图打印时可以设每页张数，打证件照排版用得上；
- **不用先把文件传到电脑**：微信里收到的 PDF、邮箱里的登机牌，长按 → 分享 → 选 NokoPrint 直接进打印流程 —— 它同时接入了系统的「分享」与「打印」菜单，别的应用里凡是出现这两个菜单的地方都能调它。

## 四、打印参数每一项什么时候动

按打印前会进入参数与预览页，常用项如下：

| 参数 | 干什么用 | 什么时候动 |
| --- | --- | --- |
| 份数 | 一次打几份 | 要发材料给一组人 |
| 逐份打印 | 多份按「1-2-3」成套出，还是按「111/222/333」出 | 多页多份，省去手动理页 |
| 页面范围 | 只打第 3~5 页这类 | 长文档只要其中几页 |
| 纸张大小 | A4、Letter、照片纸尺寸等 | 换纸时必改 |
| 纸张类型 / 纸盒 | 普通纸、照片纸；多个纸盒选进纸口 | 打照片、打印机有双纸盒 |
| 彩色 / 黑白 | 单色打印 | 草稿、纯文字页，省彩色墨 |
| 双面 | 单面或双面 | 页数多的材料 |
| 输出质量 | 草稿 / 标准 / 高 | 内部草稿用低质量更快更省墨 |
| 无边距 | 照片打满整张纸不留白边 | 光面或哑光照片纸 |

预览窗口能看到最终版面 —— 页边距、裁切对不对先在这里看出来，别直接浪费纸。

## 五、第一次打就能用对的两条经验

1. **先打 1 页测试再批量**：参数（尤其纸张尺寸与质量）确认无误后再加量；
2. **黑白文档把彩色关掉**：默认彩色模式下纯文字页也可能吃到彩色墨，黑白模式既省墨又快。

打印没反应、打印机一直搜不到这类问题，按[打印机搜不到怎么办](打印机搜不到怎么办.md)的清单排查；免费版与高级版在功能上有没有差别，见[免费版与高级版的区别](免费版与高级版的区别.md)。

## 六、打照片常碰到的两个问题

1. **照片打出来被裁掉一块，或缩得只剩中间一小块** —— 多是缩放方式与纸张尺寸没对上：把缩放调成「适应页面 / 按纸张缩放」，并核对参数里的纸张尺寸与实际放的纸是否一致；
2. **照片四周有白边，想要满版效果** —— 打开参数里的「无边距」，它配光面或哑光照片纸用才正常；普通 A4 纸上开了也容易在边缘溢墨。

照片效果始终不对时，先用一张普通文档页试打，排除打印机本身的问题再回头调照片参数。
