# NokoPrint 用OTG线直连打印机怎么设置

## 一、需要准备的三样东西

1. **支持 OTG 的手机** —— 判断方法很简单：随便插个 U 盘能被识别，就支持；
2. **OTG 转接头** —— USB-C 转 USB-A 或 micro-USB 转 USB-A，按手机接口买，几块钱；
3. **打印机的 USB 线** —— 就是打印机平时连电脑用的那根方口线。

有一个坑提前说：**部分充电线不带数据芯**，外观完全一样但传不了数据 —— 插上完全没反应时优先换线。

## 二、连接与打印步骤

1. **先开打印机电源**再插线（部分机型开机状态下才枚举设备）；
2. OTG 转接头接手机，USB 线两头接手机与打印机；
3. 手机弹出「**允许应用访问 USB 设备**」→ 选允许（这步不给，后面全白搭）；
4. 打开 NokoPrint，打印机列表里会以 USB 方式出现这台打印机，选中它；
5. 挑个一页的 PDF 试打，流程与 WiFi 打印一致（见[怎么打印文件和照片](怎么打印文件和照片.md)）。

## 三、没弹权限窗口时，去哪手动开

插上后一直没弹「允许访问 USB 设备」的窗口：

1. 重插一次 USB 线 —— 权限窗口通常只在插入瞬间弹；
2. 还不弹 → 手机「设置 → 应用 → 特殊访问权限」（部分品牌叫「更多设置」）里找 **USB 设备** 入口，给 NokoPrint 授权；
3. 各品牌手机的菜单路径名称略有差异，找不到就搜系统设置里的「USB」。

## 四、插上了但打不出来的排查表

| 症状 | 多半是 | 怎么处理 |
| --- | --- | --- |
| 插上完全没反应 | 充电线冒充了数据线 / 转接头只能充电 | 换一根确认能传数据的线；换转接头再试 |
| 手机提示 USB 设备不受支持 | 接口接触或线材问题 | 重插、换口、换线 |
| 能识别但任务发出去没动静 | 驱动语言对不上（多见于激光打印机） | 有第三方指南提到：应用里若能选 PCL / PostScript 这类驱动语言，切换一档再试 |
| 便宜的入门喷墨怎么都不出纸 | 部分入门机型是主机端渲染（GDI）结构，USB 移动直打支持差 | 改走 WiFi 连接，或用电脑中转 |

## 五、什么时候值得用 OTG 直连

三种场景下它比 WiFi 靠谱：家里/酒店**没有可用网络**；打印机是**没有 WiFi 模块的老机型**；公司或学校网络开了设备隔离，WiFi 搜不到（这类网络问题见[打印机搜不到怎么办](打印机搜不到怎么办.md)）。缺点也直接：离打印机两米内、占着手机充电口。连接方式的全面对照见[支持的打印机与连接方式](支持的打印机与连接方式.md)。
