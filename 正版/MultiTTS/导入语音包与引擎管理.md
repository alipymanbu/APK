MultiTTS 装好之后界面是空的 —— 发音人不在安装包里，要靠导入语音包补上。这一步是它最容易卡住的地方：选错文件、压缩包多层套壳、用了不支持的文件管理器，都会出现「导入了但什么都没有」。本篇把两条导入路径和判断标准写清楚。

## 一、先弄清三个词

| 词 | 指什么 |
| --- | --- |
| 语音包 | 一个压缩包，里面装着某个或某几个引擎的数据与音色文件。体积跨度很大，小的两三百 MB，大的能到几个 GB |
| 引擎 | 语音包内按来源分的组，比如微软系、Edge 系、百度系、搜狗系、小米系、讯飞系、字节系等。具体有哪几组，取决于你导入的那一份 |
| 发音人 | 引擎下的具体音色，也是你最终选中、让系统用它念的那一个 |

一个语音包里可以有多个引擎、几十上百个发音人；反过来，也不是一个语音包对应一个声音。

## 二、语音包从哪来

- **不在安装包里**，需要另外准备。装包解决的是「软件能不能跑」，语音包解决的是「有没有声音」。
- **语音包没有统一的官方渠道**，网上流传的都是使用者或整理者自己打包分享的，所以文档里给不了下载地址 —— 拿到哪一份，就按下面的判据挑。
- 流通中的语音包多由使用者或整理者打包分发，里面装哪些引擎、哪些音色，由打包的人决定，所以同一款软件配不同语音包，能听到的声音差别很大。
- 挑包时留意三件事：
  1. **体积就是占用**：包越大音色越多，导入后占用手机存储也越多；
  2. **里面可能混有在线音源**：这类音色需要联网才出声，断网就没声音，图稳定就多留离线音源；两类音源怎么分辨见 [在线音源和离线音源怎么选.md](在线音源和离线音源怎么选.md)；
  3. **来源要可信**：导入等于把压缩包里的数据解压进应用目录，从不明来源拿的包先确认清楚再导。

## 三、导入方式一：软件内「导入数据」（优先用这条）

1. 把语音包下载到手机，**不要手动解压**。
2. 打开 MultiTTS，点右上角菜单 → 「导入数据」。
3. 文件选择器里定位到那个压缩包。找不到路径就点「显示根目录」，再从内部存储逐层进去；软件一般会记住你上次选过的目录，下次直接跳过去。
4. 选中压缩包后会开始导入，等它提示导入完成。
5. 回到主界面如果还是空的，点右上角菜单 → 「重载数据」。

有两个硬性条件，不满足会静默失败：

- **压缩包第一层必须有一个合法的 `config.yaml`**。这是软件识别语音包内容的入口文件，没有它就当成普通压缩包，导进去什么也没有。
- **别用第三方文件管理器选包**。实测用系统自带的文件管理器选包成功率最高，第三方文件管理器经常出现「选了但导入失败」。

## 四、导入方式二：解压后放进目录（大包更稳）

包特别大的时候，走软件内导入可能中途报错或卡住，这时改成手工放置：

- **语音数据**解压到：

  ```text
  /storage/emulated/0/Android/data/org.nobody.multitts/files/voice/
  ```

  注意是把这个压缩包「解压到」目标目录，让 `config.yaml` 等文件直接出现在 `voice` 下面，**不要再多套一层文件夹**。放好后回软件点「重载数据」。

- **hanlp 数据包**（与中文分词相关的那份数据）解压到：

  ```text
  /storage/emulated/0/Android/data/org.nobody.multitts/files/data/
  ```

  并确认 `hanlp.properties` 落在：

  ```text
  /storage/emulated/0/Android/data/org.nobody.multitts/files/data/hanlp/hanlp.properties
  ```

  放完重启一次软件。

一个现实限制：Android 11 起，手机自带的文件管理器大多进不去 `Android/data` 目录（部分机型和第三方文件管理器可以）。如果你的手机进不去这个目录，就走第三节的方式一，别在这条路上耗。

## 五、导入完成后必做三件事

1. **重载数据**。让软件重新读一遍配置文件，不点这一步可能看不到新包。
2. **试听**。点发音人旁边的耳机图标听一下，能出声再往下。
3. **选中一个发音人**。只有被选中的那个才会真正发声，试听能响不等于已经选中。

## 六、引擎管理：增删排序与导出

右上角菜单里的「引擎管理」（有的版本直接叫「引擎」）管的是语音包导进来的这堆数据：

| 操作 | 用途 |
| --- | --- |
| 编辑 / 添加 | 手工补或改一个引擎的配置项 |
| 删除 | 整组引擎连它的发音人一起去掉，适合某组音色用不上、想省点空间 |
| 排序 | 调整引擎在主界面上的先后顺序，常用的往上挪 |
| 导出数据 | 把当前引擎的数据导出成压缩包，方便备份或换机重导 |

删单个发音人的入口不同版本不一样：有的是长按发音人头像、有的是按住条目左右拖动、有的是长按下方按钮。按你手上这版的界面提示操作，弹出的确认框里确认即可。

如果只是想彻底清空重来，**卸载重装比一个个删快**，注意卸载会一并清掉应用目录里的语音数据，重装后要重新导入。

## 七、导入前先估算一下空间

导入失败里有一类就是空间不够，而报错往往很笼统，事先算一下能省一遍折腾：

- **占用 ≈ 解压后的体积**，不是压缩包的体积。语音包是压缩过的，解压到应用目录后会明显膨胀，别按压缩包的大小去估。
- **手工放置（第四节那条路）会同时留着压缩包和数据两份**。导入成功后把压缩包删掉，能省回一份。
- **稳妥的预留量是语音包体积的两倍以上**：一倍给解压后的数据，一倍应对导入过程中的临时文件。
- **只想留喜欢的音色**：导入后按引擎整组删掉不用的，比重新找一个「精简版」语音包省事，操作见第六节的引擎管理。
- 判断手机还剩多少空间这种例行检查，别等导入报错了才做 —— 大包导入到一半失败，往往得从头再来。

## 八、导入失败：按现象对照

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 选了压缩包，界面还是空的 | 压缩包第一层没有 `config.yaml`（常见于「外层多套了一个文件夹」的打包） | 重新打包：**从内层那个装着 `config.yaml` 的文件夹开始压**，而不是在外面长按压缩 |
| 导入中途报错 / 长时间不动 | 包太大，手机存储或内存不够，或运行中被系统打断 | 清出足够空间；改用第四节解压到 `voice` 目录的方式 |
| 提示没有权限、打不开文件 | 用的是第三方文件管理器 | 换系统自带的文件管理器重试 |
| 「重载数据」后列表没变化 | 数据没落到正确目录，或路径多了一层 | 核对 `voice` 与 `hanlp` 两处路径 |
| 导入成功，但点了没声音 | 导入的全是在线音源，或还没选中发音人 | 换离线音源；先试听再选中 |
| 重启软件后发音人又没了 | 数据被清理类软件或「清除数据」操作删掉了 | 重新导入，并把 MultiTTS 加进清理白名单，见 [常见问题与排查.md](常见问题与排查.md) |

导完并能出声之后，接着调参数与音色：[音色试听与朗读参数设置.md](音色试听与朗读参数设置.md)。
