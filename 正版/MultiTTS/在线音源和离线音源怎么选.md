# MultiTTS 在线音源和离线音源怎么选

> 本篇讲语音包里的在线音源与离线音源有什么实际差别：怎么认、断网会怎样、延迟与隐私各付什么代价，以及主用哪一类。

同一份语音包里常常同时装着离线和在线两类音源，名字看起来差不多，用起来的差别却不小：离线的不依赖网络，在线的要看网速、断网就哑。选错了会把「听书听一半没声音」算到软件头上。这一篇讲怎么分辨、怎么按场景选。

## 一、先分清手上这个是哪一类

| 判断办法 | 离线音源 | 在线音源 |
| --- | --- | --- |
| 看条目图标 | 带下载含义的图标，表示数据已经在手机里 | 带网络含义的图标，表示要联网才有声 |
| 看占用 | 随语音包一起装进手机，占空间 | 往往只是一条入口配置，本身不占多少空间 |
| 开飞行模式试听 | 照样出声 | 一声不响 |

最可靠的是第三种：**开飞行模式逐个试听**，能出声的就是离线音源。图标在不同版本、不同语音包里未必画得一样，别只靠看图标下判断。

## 二、代价对照

| 维度 | 离线音源 | 在线音源 |
| --- | --- | --- |
| 网络依赖 | 无 | 必须有网，弱网下会断断续续 |
| 断网表现 | 正常朗读 | 直接没声音 |
| 响应快慢 | 本机生成，首句通常更快也更稳 | 要走一次网络来回，受网速与对方服务状态影响 |
| 音质与自然度 | 取决于本地模型，总体上不如云端大模型 | 通常更自然、更接近真人 |
| 隐私 | 文本不出手机 | 文本要交给对应厂商的服务器合成 |
| 流量 | 不耗流量 | 按朗读量消耗，长时间听书累积起来可观 |
| 存储占用 | 占手机空间，语音包越大占得越多 | 基本不占 |
| 长期可用性 | 装好就能一直用 | 依赖厂商的接口，接口变了就可能失效 |

「延迟低、音质自然」这两项是离线与在线方案的普遍规律，具体到什么程度以你实际试听为准。

## 三、按场景怎么选

- **通勤、地铁、飞机上听书** → 离线。地下和飞行模式是在线音源最难受的场景。
- **拿它当系统默认语音库，读屏也走它** → 离线。在线音源一断网，读屏会跟着一起哑。
- **对音色自然度要求高、且网络稳定** → 可以用在线，但**留一个离线音源兜底**，网络不好时手动切过去。
- **只在固定 Wi-Fi 环境下用、也不在意流量** → 在线没什么问题。

## 四、两个常见的误用

1. **拿在线音源当主语音库**。网络一抖就没声音，而这个现象很容易被误判成「软件出问题了」。多数长期使用者的做法是：**主用离线，在线只作补充**。
2. **以为「导入成功」就等于「能离线用」**。导入成功只说明配置被读到了，不代表音频数据在本地 —— 在线音源的音频是每次朗读时现取的。

## 五、想只留离线音源

在线音源通常混在引擎列表里，清掉的办法是整组删除引擎，步骤见 [导入语音包与引擎管理.md](导入语音包与引擎管理.md) 的引擎管理一节。删之前先用飞行模式试听确认一遍要留的那些确实是离线音源，别把还能用的也一起删了。

## 六、出问题时怎么判断

- **有网时正常、断网后没声音** → 当前选中的就是在线的那个，换一个离线音源即可。
- **一直没声音，连试听也没声** → 不是音源类型的问题，去 [常见问题与排查.md](常见问题与排查.md) 走完整排查。
- **在 MultiTTS 里调了语速没效果** → 与音源类型无关，是「本地配置」开关的方向问题，见 [音色试听与朗读参数设置.md](音色试听与朗读参数设置.md)。
