# MultiTTS 下载与安装教程

> 本篇讲怎么在安卓手机上把 MultiTTS 装好：先核对网盘里这份包，再开放安装权限、处理首次打开要给的授权。

MultiTTS 是安卓系统上的文字转语音引擎前端。它本身没有「书架式」的朗读界面，装好之后由别的 App（阅读类、读屏类、以及任何允许自定义发声的软件）调用它的发音人来念。它的安装包和语音包是分开的两件事：APK 装完，界面里一个发音人都还没有。本篇只把「装」这一步走完。

## 一、先核对网盘里这份包

网上搜到的通常是作者更新的版本，和网盘里这份往往不是同一个版本号。本篇出现的版本、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | MultiTTS |
| 版本号 | 1.8.3 |
| 包名 | `org.nobody.multitts` |
| 安装包体积 | 144.71 MB |
| MD5 | `B898A4041EFDE5F5CFB59851A0A7DE1D` |
| 核对时间 | 2026-09-23 |

安装包本体在 [MultiTTS 安装文件资源（夸克网盘）](https://pan.quark.cn/s/777b9e57704a) 里，转存到你自己的网盘后下载到手机。

几点要分清：

- **为什么是 144.71 MB**：1.8.3 这一版按 CPU 架构分成了两个包 —— arm64-v8a 的约 144.71 MB，armeabi-v7a 的约 110.34 MB。网盘里这份是 arm64 版，对应近几年出厂的手机。如果你从别处拿到一份 110 MB 出头的包，那多半是 32 位那一份；体积明显小于 110 MB 就是没下完。
- **版本会往前走**：作者后续还发布过更新版本，新版本里菜单位置和开关叫法可能不同，哪天是哪一版以发布页当时显示的为准。本文按 1.8.3 写。
- **MD5 怎么用**：下载完在文件管理器里看文件详情，或用任意校验工具算一次 MD5，与上表一致说明传输没损坏；体积明显小于 144.71 MB 就是没下完。
- **认包名最可靠**：网上流通的版本很多，判断是不是同一款，认包名 `org.nobody.multitts` 最快。
- **别把安装包和语音包搞混**：网盘里给的是软件本体。软件装好后发音人是空的，要另外导入语音包，见 [导入语音包与引擎管理.md](导入语音包与引擎管理.md)。

## 二、装之前先确认三件事

1. **系统里能不能出现这个引擎**。各渠道对最低系统版本的说法并不统一（有写 Android 4.0 的，也有写 5.x 的），没有可靠口径，所以别纠结版本号，直接看结果：装完之后进系统的「文字转语音」设置，首选引擎列表里能看到 MultiTTS 就说明这台机器能用。看不到就不用往下折腾了。
2. **要不要马上把它设成系统默认引擎**。设成默认之后，读屏、以及所有调用系统 TTS 的地方都会走它；而语音包还没导入时，会出现「能选中、但一点播放就没声音」。如果你手机上正在用读屏，先看 [设为系统默认朗读引擎.md](设为系统默认朗读引擎.md)，别把自己读屏的声音弄没了。
3. **手机是不是安卓**。它是安卓系统上的语音引擎，要靠安卓自己的文字转语音机制才能被别的 App 调用，iPhone 上没有对应的版本。

## 三、安装步骤

1. **把安装包传到手机**。在电脑上下载的话，用数据线或任意传输工具拷进手机存储都行。
2. **允许安装未知来源应用**。在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统常把这一项收在「安全」「隐私」「更多安全设置」下面。
3. **点开 APK 完成安装**。系统提示「应用未经过安全检测」时选继续安装，这是第三方渠道安装包的常规提示。
4. **首次打开时按提示授权**。常见的是存储权限与通知权限：存储权限关系到后面导入语音包时能不能读到压缩包，通知权限关系到常驻通知能不能挂住（它被清掉时后台更容易被杀，见 [常见问题与排查.md](常见问题与排查.md)）。

安装被拦下时，不同提示对应的情况不一样，按这张表对：

| 系统提示 | 原因 | 处理 |
| --- | --- | --- |
| 解析包错误 / 解析包时出现问题 | 下载不完整，或包与手机 CPU 架构不匹配 | 重新下载，核对体积是不是 144.71 MB、MD5 是否与上表一致 |
| 应用未安装 | 手机上已装了同包名、但签名不同的版本 | 先卸载旧版再装；卸载会清掉应用内的语音数据 |
| 已阻止安装 / 安全提示 | 未知来源开关没打开 | 回到第 2 步，给打开安装包的那个应用开权限 |
| 装完在「文字转语音」里找不到它 | 引擎没被系统识别，或安装未真正完成 | 卸载后重装一次；若仍不行，多半是包本身不对，换一份确认过包名的包 |

## 四、装完先别急着设默认

打开 MultiTTS 会看到一个空界面，没有发音人、没有可选的音色 —— 这是正常状态，不是装坏了。正确的顺序是：**先导入语音包 → 试听并选中一个发音人 → 再把它设成系统默认引擎**。跳过中间两步就设默认，结果是别的 App 调它时一声不响。

装完可以先用这张清单自检，三项都过了再往下走：

| 检查项 | 通过标准 | 不通过时看哪 |
| --- | --- | --- |
| 系统认没认它 | 系统「文字转语音」的首选引擎列表里能看到 MultiTTS | [设为系统默认朗读引擎.md](设为系统默认朗读引擎.md) |
| 界面是不是空的 | 打开后没有发音人属正常，导入语音包后才会出现 | [导入语音包与引擎管理.md](导入语音包与引擎管理.md) |
| 能不能出声 | 导入并选中发音人后，试听听得到声音 | [音色试听与朗读参数设置.md](音色试听与朗读参数设置.md) |
