## 一、这份安装包是什么

柠檬音乐是一款安卓音乐播放器，在线听和下载到本地都行，安装包不到 10 MB，装起来很快。下面这张表是**这份安装包**的事实信息，你核对文件、判断手机能不能装，都以它为准（网上的“最新版”页面写的常常是另一个版本，别混着对）：

| 包名 | `com.zhekou.qm` |
| 安装包大小 | 9.82M（10292087 字节） |
| MD5 | `397C0A1CFB40E482168781165D9730C5` |
| 系统要求 | 安卓 5.2 及以上 |

## 二、从网盘拿到安装包

1. 打开 [柠檬音乐 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c7fb009c1a50)。
2. 登录你自己的夸克账号 → 选择**转存**，把整个文件夹存进你的网盘（文件夹里通常还带一个“先保存再下载”的说明 txt，一起转存即可）。
3. 在你的网盘里打开该文件夹，找到 `柠檬音乐_v1.1.4.apk`，点**下载**到手机。
4. 手机上等下载进度走完再点开文件 —— 下载中途点开是装不上的（安装包不完整）。

> 文件夹名带“（先保存再下载）”是提醒你先转存：直接用别人的分享页下载，链接可能随时失效，转存进自己网盘后就一直在。

## 三、安装步骤

1. 点开刚下载的 `.apk` 文件，系统会弹“禁止安装未知应用”之类的提示。
2. 按提示进入**设置 → 允许此来源安装应用**，打开开关（不同品牌手机的叫法略有差别，有的叫“未知来源”，有的叫“安装未知应用”）。
3. 返回后再次点安装，等进度走完点**完成**（先别急着点“打开”，回桌面从图标进更稳）。
4. 首次启动会要存储等权限，用于把下载的歌曲存到手机里 —— 拒绝了会导致下载功能用不了，建议允许。

## 四、装不上、提示解析失败

按出现的提示对号入座：

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| “禁止安装未知应用” | 没给安装权限 | 按第三节第 2 步打开该来源开关 |
| “解析包时出现问题” | 文件没下完整 | 重新下载；下完按本节下方的命令核对 MD5 |
| “安装失败 / 应用未安装” | 手机里已有同包名旧版且签名不同 | 先卸载旧版再装（会丢掉旧版里的下载记录，先确认要不要保留） |
| “该设备不支持” | 系统低于安卓 5.2 | 换系统版本更高的手机，或用电脑装完再传过去 |

核对文件是否完整，可以在电脑上打开命令行执行（把路径换成你的实际路径）：

```powershell
certutil -hashfile "柠檬音乐_v1.1.4.apk" MD5
```

输出的 32 位十六进制与表格里的 MD5 完全一致，说明文件没下坏。
