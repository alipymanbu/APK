## 一、打开后先认清这几个位置

柠檬音乐的首页是一层顶栏 + 一个搜索框 + 一大块内容区 + 底部常驻播放条。你需要认的只有这几个：

| 位置 | 长什么样 | 作用 |
| --- | --- | --- |
| 顶栏入口 | 我的 · 歌单 · 歌手 · 排行 · 更多 | 切换五块主要内容 |
| 左上角 | 三条横线图标 | 侧边菜单（设置等） |
| 右上角 `+` | 加号 | 扩展操作入口，点开后按出现的菜单选 |
| 搜索框 | 占位文字“点我/搜索/歌手/歌名” | 直接搜歌、搜歌手 |
| 底部播放条 | 封面 + 歌名 + 进度条 + 上一首/播放/下一首 | 随时控制当前在放的歌 |

顶栏里你最常用的是**歌单、歌手、排行**三个 —— 没有明确想听什么的时候，从这三处挑；已经有目标了，直接用搜索框。

打开应用也不要求先注册账号，直接就能进首页找歌（以你打开后实际看到的为准）。另外，本篇描述的是包名 `com.zhekou.qm` 那一份的界面；如果你手机上的柠檬音乐长得完全对不上，先看 [界面和网上截图不一样怎么办.md](界面和网上截图不一样怎么办.md)。

## 二、按歌单找歌

1. 顶栏点**歌单**。
2. 内容区上方有“歌单一 / 歌单二 / 歌单三…”几组标签，可横向切换。
3. 再往下是风格标签：抖音、经典、情歌、BGM、游戏、怀旧、合唱、网络、儿童等，点一个就只看这个方向的歌单。
4. 歌单以卡片展示，卡片上标着**播放量**（如“9358播放”），点进去看歌单里的曲目，点任意一首就开始放。

## 三、按榜单找歌

1. 顶栏点**排行**。
2. 同样有“排行一 / 排行二…”几组标签。
3. 榜单卡片常见的是飙升榜、新歌榜、热歌榜、抖音榜、怀旧榜、会员飙升榜这类，点开就是该榜的歌曲列表，从上往下点着听即可。

榜单会随时间换血，具体有哪些榜、叫什么名字，以软件内当时显示为准。

## 四、按歌手找歌

1. 顶栏点**歌手**。
2. 顶部先选语言分组：华语男、华语女、华语组合、日韩男、日韩女等；再用**热门**或 **A~Z** 字母索引缩小范围。
3. 列表里每个歌手右侧有粉丝数和**关注**按钮，点**关注**后，你回头找这位歌手会更快。

## 五、搜索框直接搜

搜索框的占位文字已经写清了三种输入：**关键词 / 歌手名 / 歌曲名**。输入后回车即出结果，点结果里的任意一首就进入播放（接下来的操作见 [播放与下载歌曲教程.md](播放与下载歌曲教程.md)）。

搜不到时先确认没打错字、再换歌手名或专辑名试一次 —— 排查方法见 [常见问题与故障排查.md](常见问题与故障排查.md)。
