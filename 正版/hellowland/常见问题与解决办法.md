## 一、安装类问题

**提示「解析包时出现问题」**
文件没下完整或损坏。回到 [下载与安装教程.md](下载与安装教程.md) 重新下载，别在原来那份上重试。

**提示「应用未安装」**
手机里残留了同包名的旧版本。先去 **设置 → 应用管理** 找到 `com.hellowland_1116` 卸载干净，再装一次。

**系统版本不符**
装 hellowland 需要安卓 5.2 及以上。在 **设置 → 关于手机** 里查版本号，低于 5.2 就装不了。

**装完图标不见了 / 被拦下**
部分手机的「纯净模式」「风险应用管控」会隐藏非商店来源的应用。在系统安全设置里临时放行本次安装即可，装完记得按需恢复。

## 二、启动与闪退

按顺序试，多数能停在前三步：

1. **重启应用**：从最近任务里划掉，重新打开；
2. **清缓存**：**设置 → 应用管理 → hellowland → 存储**，先只清缓存（不清数据，登录状态还在）；
3. **检查权限**：确认网络等相关权限已允许；
4. **清数据重进**：上一步没用再清数据——代价是本地记录重置，账号本身不受影响（用用户名密码重新登录即可）；
5. **卸载重装**：从 [hellowland 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9c0aa5688107) 重新下一份安装包，注意核对 MD5 与版本；
6. **查存储空间**：手机可用空间长期低于 10% 时，各种应用都会随机闪退，先清理出空间。

清数据、卸载重装这类操作前，记住你的**用户名和密码**——账号在服务器上，重装后登录回来收藏和记录都还在。

## 三、登录与注册

**注册页点不开 / 协议弹窗没反应**
多半是网络没连上或请求超时，换 Wi-Fi 与移动数据各试一次；仍不行见下一节的网络排查。

**收不到验证邮件**
先翻垃圾邮件箱；再核对邮箱地址有没有拼错。邮箱已停用且密码忘记的话，只能换用户名重新注册（见 [注册登录账号方法.md](注册登录账号方法.md)）。

**登录提示账号或密码错误**
用户名密码区分大小写，重新输入一遍；确认没开输入法的意外大写锁定。多次失败就走找回密码流程。

**换设备后收藏不见了**
多半是没登录或登录了另一个账号——先确认右上角显示的用户名是不是你自己的。

## 四、内容与搜索

| 现象 | 原因与处理 |
| --- | --- |
| 二创内容看不到 | 未登录，登录后可见 |
| 输入文号搜不到 | 编号只能是纯数字，去掉字母、空格、符号 |
| 标签筛选没结果 | 部分内容需登录；或该标签下暂无公开作品 |
| 网页版打开慢/打不开 | 官网入口是 [hellowland.com](https://hellowland.com/)，换网络或稍后再试 |
| 缓存的文读不了 | 缓存可能已过期，联网状态下重新缓存一次 |

## 五、还没解决

把**提示原文、手机品牌与安卓版本、操作到哪一步**这三样记全，再回头对着相关文档重走一遍流程——多数问题出在权限、网络与版本这三件事上。安装文件的重新获取方式见 [下载与安装教程.md](下载与安装教程.md)。
