## 一、旋律写完之后缺什么

一段旋律单独听往往单薄：速度不对、调不合适、没有伴奏、各声部糊在一起。这篇按「先定速度调性、再加伴奏、最后混音」的顺序，把 musicLine 里对应的开关逐个说清楚。工具本身怎么用见[新手入门与音符输入方法.md](新手入门与音符输入方法.md)。

## 二、速度与调：两个最常动的值

**BPM（テンポ）** 决定整曲快慢。同一个旋律，60 BPM 是慢歌，140 BPM 就变快歌——先定 BPM 再修细节，可以少返工一遍。

**キー（曲调）** 决定整曲的音高基准。改调不需要挪任何一个音符，整曲一起平移；想试「这首歌升高两个调会不会更好听」，改一下キー立刻能听出来。

还有一个官方明确列出的能力：**保持音程不变、只改节奏**。这在你先写好旋律、后来才想换拍子时特别有用——旋律关系不动，只是排布的疏密变了。

## 三、伴奏侧：乐器、鼓、和声

| 项目 | 说明 |
| --- | --- |
| 乐器音色 | 一百种以上可选，钢琴/吉他/小号/小提琴这类常规乐器，到八音盒、颤音琴、陶笛、风笛这类都有；每个音轨单独指定 |
| 自动鼓 | 按风格自动生成鼓点，官方点名的风格包括摇滚、金属、朋克——不用手敲鼓也能有靠谱的节奏底 |
| 分轨编写 | 旋律、和弦、鼓各占轨道，分开写分开改，这是「立体」而不是「单线」曲子的分水岭 |
| 和声/和弦创建 | 进阶功能，随作曲等级提升解锁；没看到入口说明等级还没到 |
| 钢琴卷轴输入 | 想要精确到十六分、三十二分音符这类细节奏时，回到卷轴逐个摆（32 分音符在 8.6.9 版本加入） |

## 四、混音：让各声部不打架

官方列出的混音相关能力有这么几项：

- **分轨音量**：哪个声部抢了主旋律，把它的音量拉下来，比改音符快；
- **ソロ（solo）单独试听**：只听某一条轨，用来定位「到底哪里难听」；
- **パン（声像，LR）**：把吉他偏左、钢琴偏右，立体声下层次立刻分开；
- **リバーブ（混响）**：给干声加空间感，加多了会糊，宁少勿多；
- **リリースカット** 之类的音色塑造选项，属于进阶用户常动的几项。

顺序建议：先分轨音量把比例调平 → 再 solo 查个别轨的问题 → 最后才加混响这类效果。反过来先加效果，容易把问题掩盖掉。

## 五、版本演进：你这版有哪些、没有哪些

版本号越大功能越新，官方更新记录里与编曲直接相关的节点大致如下（老版本没有对应按钮属正常）：

| 版本 | 加了什么 |
| --- | --- |
| 9.5.0 | 声音的调整功能 |
| 9.3.0 | Edge-to-edge 显示适配、调整轨道 |
| 9.1.0 | 调整轨道（Adjustment Track） |
| 9.0.0 | 音源库更新 |
| 8.21.0 | 上线十周年纪念主题 |
| 8.17.0 | 鼓的改进 |
| 8.15.1 | 专辑功能 |
| 8.14.4 | 歌曲可视化 |
| 8.13.2 | 播放列表 |
| 8.11.4 | 查看模式 |
| 8.10.10 | 图章工具 |
| 8.8.3 | 按乐器显示推荐音阶区域 |
| 8.6.9 | 32 分音符 |
| 8.5.7 | 竖屏作曲 |
| 8.1.7 | 高级会员（Premium）用户支持 |

本文档对应安装包是 9.1.1：**9.1.0 及更早的条目它都有，9.3.0 之后的（含 Edge-to-edge 适配）它没有**——更新的 9.5.x / 9.7.x 才有的东西别在界面上找。想升级就走商店或重新取包，见[下载与安装教程.md](下载与安装教程.md)。

改完设置如果出现没声音、卡顿、闪退，先别卸载，[常见问题与故障排查.md](常见问题与故障排查.md) 里按顺序排查过一遍。
