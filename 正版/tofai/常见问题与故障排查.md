## 一、注册时收不到邮箱验证码

按命中率从高到低排：

1. **先翻垃圾箱**。验证码邮件是陌生发件人，最容易被丢进垃圾邮件 / promotions / 订阅分类里。
2. **核对邮箱拼写**。打错一个字母，验证码永远到不了。
3. **等一会儿再点重发**。邮件通道有延迟，倒计时结束再发一次；短时间连点会被限流，这种情况一般要等一段时间才能再取。
4. **邮箱容量满了**也收不进新邮件，清一下收件箱。
5. **换个邮箱试**。个别邮箱服务商与发件方不兼容，换一个域名（QQ / 163 / Gmail 之类）基本能绕开。
6. 以上都试过还不行，检查邮箱的过滤规则和黑名单设置，把发件地址加入白名单。

## 二、图形验证码显示不出来

页面上验证码区域空白、点刷新也没图案，基本是网络问题：**刷新页面或切换网络（Wi-Fi 与流量互换）再试**。持续空白就清理一下 app 缓存后重开，见下一节。

## 三、打开闪退、一直转圈加载

1. `设置 → 应用 → Tofai → 存储` 里点**清除缓存**，再强制停止，重新打开。
2. 清缓存没用就**重启手机**再试 —— 很多偶发闪退重启就好。
3. 确认系统版本没落后太多，有系统更新先更。
4. 一直转圈基本是网络：换网络、关掉代理或加速器再试。
5. 还不行就卸载重装（对话记录跟账号走，重装后用同一邮箱登录即可拿回）：安装包重新从 [Tofai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/fa4df886d8b4) 取，装完核对包名是 `com.jawn.honey`，详见 [下载与安装教程.md](下载与安装教程.md)。
6. 提示「解析包时出现问题」＝文件没下完整，删掉重下。

## 四、版本号和包名怎么老对不上

你会在不同页面看到 v1.3.8、v1.3.13 之类，而网盘里这份是 **v1.2.6**，包名 `com.jawn.honey`、15.93 MB。这些页面各自标注的包名也五花八门（`com.agtechltd.tofai`、`com.larus.nova`、`com.huanyu.datacenter`），别拿它们当依据。

判断依据只有一条：**装到手机上后，`设置 → 应用 → 应用信息` 里显示的包名是 `com.jawn.honey`**。版本新旧不影响本文档讲的操作路径；如果某个功能在你这版找不到，先确认是不是版本差异，再看 [多模型切换与免费额度说明.md](多模型切换与免费额度说明.md) 里的对应说明。

## 五、聊着聊着额度用完了

每日免费额度按天重置，当天用完等第二天即可；限免模型不受影响，切到限免档继续聊。想多拿一点可以签到、填邀请码、邀请好友，入口在 [多模型切换与免费额度说明.md](多模型切换与免费额度说明.md) 第三节。

## 六、账号注销

注销是**不可撤销**的，角色、对话记录、额度都会一起没。真要注销：

1. 右下角人像图标进个人中心，点右上角设置。
2. 在设置里找**「账号管理」或「账号安全」**（不同版本叫法不同）。
3. 点「账号注销」，读完风险提示，确认注销。

只想换个邮箱重新登录，不必走到这一步 —— 用另一个邮箱登录通常就是一个独立的新账号，两边的角色与记录不互通。
