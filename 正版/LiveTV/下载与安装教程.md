## 一、先确认安装包信息

装之前先核对包的信息，别把别的同名软件装进电视。网盘里那份包的事实如下（网上各下载站标的版本常常与它不一致，以这份为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 20260519 |
| 包名 | com.live.tv |
| 大小 | 16.00M |
| 系统要求 | 安卓 5.2 及以上 |
| 文件名 | LiveTV_v20260519.apk |

版本号 `20260519` 是一串年月日形式的数字，界面里看到的版本以你装的这个包为准。文件大小约 16 MB，下载很快，但正因为它小，下载不完整时更容易出问题（见 [常见问题与解决方法.md](常见问题与解决方法.md)）。

## 二、拿到安装包

打开 [LiveTV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bfc4c315b511)，里面有应用文件夹与 `LiveTV_v20260519.apk`。三种取法按你的设备挑一种：

1. **电视 / 盒子能直接装网盘客户端**：在设备上装夸克网盘客户端，登录后转存再下载，直接得到 apk 文件。
2. **电脑中转（最稳）**：电脑浏览器打开分享链接，转存后下载 apk 到本地，再拷进 U 盘 —— 后面第三节就是这条路。
3. **手机中转**：手机上转存并下载 apk，留在手机存储里，直接按第四节安装。

如果你想校验文件是否下载完整，在电脑上打开命令提示符或 PowerShell，运行：

```powershell
certutil -hashfile LiveTV_v20260519.apk MD5
```

输出的 32 位十六进制应与 `081010BC078C8786CA0617666A974252` 完全一致（大小写不敏感）；对不上就是文件没下完整或下错了，重新下载再验一次。

## 三、装到电视 / 电视盒子（U 盘法）

电视和盒子的系统五花八门，但流程都一样：**允许安装未知来源 → 插 U 盘 → 找到 apk → 确认安装**。

1. 把 `LiveTV_v20260519.apk` 拷进 U 盘根目录，拔出前在电脑上安全弹出。
2. U 盘插到电视 / 盒子的 USB 口。
3. 打开电视的 **设置 → 安全 / 账户与安全**，找到 **「未知来源」或「允许安装未知应用」**，对后面要用的文件管理器（或浏览器）开启。不同品牌叫法不同，有的在「安全」里，有的在「应用」里。
4. 打开电视自带的 **文件管理器**，找到 U 盘里的 apk（通常在「外接存储 / U盘」分类下），按遥控器确认键。
5. 弹出安装确认页时选 **「安装」**；若提示「禁止安装」，回到第 3 步把来源权限开对地方。
6. 装完先 **「打开」** 跑一次；也有人习惯回桌面再从应用列表启动，两种都行。

**盒子用户**：当贝、天猫魔盒、小米盒子等自带文件管理，插 U 盘后桌面会弹出 U 盘入口，点进去直接点 apk 即可，不需要额外装软件。

## 四、装到手机 / 平板

1. 手机浏览器打开分享链接，下载 apk；或从电脑拷贝过去。
2. 点开文件时系统会提示「不允许安装来自此来源的应用」—— 点 **「设置」**，给浏览器 / 文件管理开启允许，再返回继续。
3. 安装完成后打开。手机 / 平板上的操作与电视一致，只是遥控器按键换成了触屏点按（见 [频道分类与换台操作.md](频道分类与换台操作.md)）。

## 五、首次启动会看到什么

第一次打开会出现一页 **遥控器教学**：告诉你按 **确认键** 打开频道列表、按 **上下键** 切换频道，右上角是当前频道信息；看完按确认键继续即可进直播。这一页之后还会出现在设置里，忘了操作可以再看。

装好后如果遇到黑屏、卡顿、某个频道没画面，按 [常见问题与解决方法.md](常见问题与解决方法.md) 逐条排查即可。
