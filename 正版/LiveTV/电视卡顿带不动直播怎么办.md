# 电视卡顿带不动直播怎么办

> 先分清是网络卡还是整机卡，再对症下药：网络侧调连接，整机侧清缓存、外接盒子。

## 一、先做三十秒分诊：到底是哪种卡

直播类应用的「卡」有两种，处理方向完全相反，先花三十秒判断：

| 现象 | 更可能是 | 跳到 |
| --- | --- | --- |
| 画面转圈缓冲、换台时加载，但**按遥控器有反应** | 网络问题 | 第二节 |
| 按遥控器**半天才响应**、打开列表也顿、别的应用同样慢 | 整机性能问题 | 第三节 |
| 只有这一个应用卡，其他直播、点播都流畅 | 应用本身 | 见 [常见问题与解决方法.md](常见问题与解决方法.md) |

最省事的验证：**在电视旁边用手机连同一个 Wi-Fi 测速**。手机快、电视慢 → 问题在电视侧；手机也慢 → 是家里整体网络，先修网络。

## 二、网络侧：按顺序试这五步

1. **断电重启路由器和电视**：两个都拔电等一分钟再插回。多数临时性卡顿到这一步就好了，别跳过它直接折腾设置。
2. **改走有线**：电视网口插网线直连路由器。有线是所有方案里最稳的 —— 官方电视厂商的支持文档在处理「播放停止、反复加载」时，第一条建议也是改接有线看是否改善。
3. **调整 Wi-Fi**：没网线就让电视与路由器 **5 米内、少隔墙**；双频路由器让电视连 **5GHz**（穿墙弱但干扰少，隔两堵墙就别用它，改回网线）；路由器与电视之间留出至少 1 米距离，太贴反而互相干扰。
4. **腾出带宽**：家里有人在下载、云备份、开会议时，直播缓冲是正常现象 —— 暂停它们再看，或等晚高峰过后。同一时间太多人看同一频道也会卡（多来源印证），换个时段即知。
5. **换解析地址（进阶）**：电视网络设置里把 DNS 改为手动，填 `223.5.5.5` 或 `8.8.8.8`，有时能改善加载。改坏了改回「自动」即可。

五步之后仍卡，而手机同位置测速正常 —— 基本可以确定不是网络，往下走。

## 三、整机侧：老电视的通病

智能电视用久了普遍变慢，卡顿主要卡在两处：**运存小** 与 **系统垃圾堆积**（多个测评来源口径一致：1GB / 2GB 运存是卡顿重灾区，4GB 才算流畅分水岭 —— 数据出自第三方实测，以你的实际手感为准）。

按代价从小到大试：

1. **清应用缓存**：设置 → 应用管理，逐个清理视频类应用的缓存，清完重启电视。这一步对「用一会儿就顿」最有效。
2. **关自启动**：设置里关掉自动更新、后台预加载，开机少拉一堆后台。
3. **只留常用应用**：低配电视装三五个应用就到头了，删掉不看的。
4. **恢复出厂设置**：以上都无效再用 —— 会清空所有已装应用与登录信息，等于电视重装系统，先想清楚再按。
5. **外接电视盒子**：2018 年以前的老款、或运存 2GB 以下的机型，系统已经救不回来 —— 买个几百元档的盒子（以当时售价为准）负责运算，老电视只当显示器用，是最省事的一招。

## 四、怎么判断不是应用的锅

- 所有应用、包括电视自带系统都卡 → 整机问题，照第三节办；
- 只有直播卡、网页视频都流畅 → 网络对直播流不稳，回到第二节；
- 只有某几个频道卡 → 频道源的问题，换台即可（见 [常见问题与解决方法.md](常见问题与解决方法.md)）；
- 卡顿从安装新版本后开始 → 退回重装网盘里那份完整安装包（[下载与安装教程.md](下载与安装教程.md) 第二节有校验方法）。

装好、调顺之后想把常用台固定下来，见 [频道分类与换台操作.md](频道分类与换台操作.md) 的收藏一节。
