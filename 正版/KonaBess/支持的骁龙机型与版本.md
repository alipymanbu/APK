## 一、支持哪些芯片

KonaBess 只对高通骁龙生效，项目仓库的 README 与发布记录给出的支持范围如下（更新的芯片随新版本陆续加入）：

| 系列 | 型号 |
| --- | --- |
| 骁龙 8 系 | 855 / 865 / 888 / 8 Gen 1 / 8+ Gen 1 / 8 Gen 2 / 8 Gen 3 / 8s Gen 3 / 8 Elite |
| 骁龙 7 系 | 750 / 765 / 778G / 780G / 7 Gen 1 / 7+ Gen 2 / 7+ Gen 3 |
| 骁龙 6 系 | 690 |

几点说明：

- 「8 Elite」（骁龙 8 至尊版）是 **0.25 版本**才加进来的，你手上这份 0.25beta 正好包含；
- 骁龙 865 是这个工具最早的目标机型（名字里的「Kona」就是 865 的代号，见第五节）；
- 不在表里的芯片——包括联发科、Exynos、Tensor——打开也识别不了，别硬试；
- 同一颗芯片在不同手机上还受厂商固件结构影响，表里有、但你打开就报错的情况也存在，排查思路见 [常见问题与恢复方法.md](常见问题与恢复方法.md)。

## 二、版本号怎么读

KonaBess 的版本号形如 `0.25beta`，一直以 beta 节奏发布、版本号停在 0.x；**判断新旧直接比数字**，`0.26` 比 `0.25` 新，`0.9` 比 `0.25` 旧。

各版本的代表性变化（摘自项目仓库的发布记录）：

| 版本 | 加了什么 |
| --- | --- |
| 0.17 | 骁龙 8+ Gen 1 支持 |
| 0.18 | 骁龙 8 Gen 2 支持 |
| 0.20 | 骁龙 7 Gen 1 支持；修复 Galaxy S23 系列打不开频率表 |
| 0.21 | 骁龙 7+ Gen 2 支持 |
| 0.22 | 骁龙 8 Gen 3 初步支持；修复新芯片的频率数量限制 |
| 0.23 | 骁龙 7+ Gen 3、8s Gen 3 支持；修复新机自动检测 dtb 索引 |
| 0.24 | 骁龙 G3x Gen 2、8 Gen 3 无基带平台支持 |
| 0.25 | 骁龙 8 Elite 支持 |
| 0.26 | 骁龙 8 Elite Gen 5 支持 |

要看完整发布记录和下载最新包，去项目仓库的 Releases 页面：[github.com/libxzr/KonaBess](https://github.com/libxzr/KonaBess/releases)。

## 三、这套文档对应的版本

本文档系列写的是这份安装包：

| 项目 | 数值 |
| --- | --- |
| 版本 | 0.25beta |
| 包名 | `xzr.konabess` |
| 大小 | 0.94M |

也就是说它包含到「骁龙 8 Elite 支持」为止的更新；如果你的芯片是更晚加入的（如 8 Elite Gen 5），这份包识别不了，需要去上面的 Releases 页面拿新版本。版本号会持续变化，以页面当时显示为准。

## 四、KonaBess 和 KonaBess Next 是什么关系

网上搜 KonaBess 会同时出现一个叫 **KonaBess Next** 的东西：那是另一位开发者维护的分支，主打更新的芯片、更现代的界面，包名也和原版不同。你从本文档安装包拿到的是**原版**（`xzr.konabess`），功能与操作以本文档系列为准；两者只是同源，配置并不通用。

## 五、为什么叫这个名字

「Kona」是骁龙 865 平台的代号。这个工具最早就是为了压榨 865、抗衡 888 的 GPU 表现而做的，后来支持范围才一路扩到 8 系全系与 7 系、6 系——名字一直没改。你如果只是想给 865 提性能或降功耗，它正是为此而生；如果是更新的芯片，先对照第一节确认支持再说。
