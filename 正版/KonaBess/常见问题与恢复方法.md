## 一、一打开就提示「获取镜像失败」

这是最高频的问题，原因基本落在两类里，按顺序排查：

**第 1 类：手机还没具备条件**

- Bootloader 没解锁，或 root 没装好（Magisk / KernelSU / APatch 任一没正常工作）；
- KonaBess 没拿到 root 授权——去 root 管理器里看授权记录，被拒绝了就改成允许再重开应用。

搞定 root 与解锁后仍报错，才看第 2 类。前置条件的自查清单在 [下载与安装教程.md](下载与安装教程.md)。

**第 2 类：它找不到需要的镜像文件**

- 文件不存在或路径不对：它需要的是与你当前系统版本完全匹配的 `boot.img` 或 `vendor_boot.img`；
- 文件损坏：下载的固件包不完整；
- 版本不匹配：固件版本和手机在跑的系统对不上；
- 自制 ROM：第三方系统的镜像结构与工具预设不兼容。

对策：去你手机品牌的官方渠道下载**与当前系统版本完全一致**的固件包，解压后从里面取出 `boot.img` / `vendor_boot.img` 提供给 KonaBess，再重试。

## 二、刷完花屏、闪点，甚至开不了机

按严重程度分两步处理：

**还进得去系统（轻度）**：跑测试或游戏时出现闪点、彩条、花屏、抖动，说明刚刷的频率/电压不稳。进 KonaBess 把出问题档位的频率调低或电压调高，重新「保存 → 打包并刷入 → 重启」即可，判断方法见 [超频降压操作步骤.md](超频降压操作步骤.md) 第四节。

**开不了机（重度）**：现象多是**卡在开机第一屏或反复重启**（社区里叫「卡米」），说明这次的频率/电压这台机器撑不住。恢复的思路固定：把改动前的原镜像刷回去，三条路按你手上的东西选。

**路 1：电脑 fastboot 刷回备份（最通用）**

1. 手机关机，长按**电源键 + 音量减**进 fastboot 模式（少数机型是音量加，以你机型为准）；
2. 连电脑，先执行 `fastboot devices` 确认识别到了；
3. 刷回备份——**备份文件是什么分区就刷回什么分区**：

```bash
fastboot flash boot boot备份文件.img
# 备份是 vendor_boot 就用这条：
fastboot flash vendor_boot vendor_boot备份文件.img
```

KonaBess 备份的是你这台机器承载参数的那个镜像：有的机型是 `boot.img`，不少新机型是 `vendor_boot.img`（社区里就有人吃过「备份明明有、刷 boot 却没用」的亏）。A/B 分区的机型还要带 `_a` / `_b` 后缀，刷错分区不生效；刷完 `fastboot reboot` 重启，频率表会回到默认。

**路 2：Recovery 刷回**：能进 TWRP 一类第三方 Recovery 的，直接刷「备份旧镜像」存在手机里的那份文件。备份还在手机里但你没拷过电脑，先在 Recovery 里挂载存储、把它拷出来再刷——刷完记得再拷一份到电脑。

**路 3：没备份就只能回原厂**：从你手机品牌的官方线刷包里提取**同版本**的 `boot.img` / `vendor_boot.img` 刷回去——恢复的是出厂频率，这一轮改动作废，之后重新按保守参数再来。

三条路里前两条都依赖备份，第三条是兜底（要重新下线刷包）——这也是 [超频降压操作步骤.md](超频降压操作步骤.md) 第一节把「备份」列在第一位的原因。

## 三、按步骤做了，但重启后没变化

依次核对四个环节，断在哪一环就在哪一环重来：

1. **频率表**和**电压表**（若你的芯片有两张表）都分别点过自己的「保存……修改」？只保存了一张，另一张的改动不会生效；
2. 点的是**「打包并刷入新镜像」**并且走完了，中途取消等于没刷；
3. **重启了**：参数是重启后才加载的，不重启永远看不到变化；
4. 想改的频率**没超过这颗芯片的上限**：超过上限的频率无法正常工作，表现出来就是「改了没反应」或直接异常，各芯片上限见 [超频降压操作步骤.md](超频降压操作步骤.md) 第五节。

## 四、用了一段时间，自己变回默认了

多半是**系统 OTA 更新过**：系统更新一般会把启动分区刷回官方版本，你在 KonaBess 里刷进去的改动随之消失，root 也可能同时受影响。更新后先确认 root 还在，再按 [超频降压操作步骤.md](超频降压操作步骤.md) 重新走一轮「改表 → 刷入 → 重启」；如果你导出过默认参数，这会儿也能对照着恢复。

## 五、界面全是英文看不懂

应用本身没做完整中文适配：把手机**系统语言切成简体中文**后再打开 KonaBess，界面会跟着显示中文；改回来即可。不想动系统语言的话，对照 [超频降压操作步骤.md](超频降压操作步骤.md) 里的按钮中文名（「备份旧镜像」「编辑 GPU 频率表」「保存……修改」「打包并刷入新镜像」等）照着点也一样用。

## 六、芯片在支持列表里，但打开就识别不出来

支持列表见 [支持的骁龙机型与版本.md](支持的骁龙机型与版本.md)。先确认你装的版本够新（比如 8 Elite 要 0.25 起），再走第一节的两类原因排查；两者都排除了，很可能是厂商固件结构特殊，社区里按机型讨论的资料比通用教程更对症。
