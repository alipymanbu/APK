## 一、动手之前：先把后悔药备好

改表这个动作要刷写启动镜像，参数不稳会让手机开不了机，所以顺序不能反：

1. 点 **「备份旧镜像」**：软件会把当前的 boot / vendor_boot 镜像备份到手机存储里；
2. 备份成功后**再复制一份到电脑**（数据线连电脑拷走）——手机自己开不了机时，只有电脑上那份能救你；
3. 进 **「导入导出」→ 导出**，把出厂的频率表、电压表数值存一份，方便以后一键回到默认；
4. 想清楚恢复手段：手边有 TWRP 一类第三方 Recovery，或者电脑上装好了 fastboot 工具。两样都没有，先别往下走。

## 二、正式操作的完整顺序

1. **备份旧镜像**（见上一节，跳过这步等于裸奔）；
2. **编辑 GPU 频率表**：
   - 点进某个频率档位，修改数值后点 **「保存 GPU 频率表修改」**；
   - 单位是 Hz，数值很长——**只动前三位**，后面那一串 `0` 不要碰；
   - 想超频就往上调，想省电就往下调，一次只动一个档位。
3. **编辑 GPU 电压表**：
   - 点进某个频率对应的电压，换一档后点 **「保存 GPU 电压表修改」**；
   - 档位列表**越靠上电压越低、越靠下电压越高**；
   - 想降压省电，就往列表上方一档一档换，找出这一频率下还能稳定工作的最低档；想更稳就往下方换；
   - **骁龙 888 及之后的芯片通常只有频率表、没有电压表**，改频率就行，不用找电压入口。
4. **「打包并刷入新镜像」**：两张表都保存过后再点它，等待打包完成；
5. **重启手机**：改出来的参数重启后才生效，不重启等于白改。

> 注意：每一轮「改表 → 保存 → 打包刷入 → 重启」都是完整的一圈，改一个档位就要重跑一次，安排好整块时间再动手。

## 三、要不要抄别人的「作业」

社区里（酷安、论坛等）有人把调好的参数以 `konabess://` 开头的一整段文本分享出来，KonaBess 里走 **「导入导出」→「从剪贴板导入」** 就能整套导进来，之后仍要走「保存 → 打包刷入 → 重启」。

抄之前想清楚两点：

- 每台手机的芯片体质不同，别人的极限值在你机器上可能直接花屏；
- 优先挑**保守的**作业——同样电压下频率偏低的那一份；导入后自己再逐档微调，比整套照搬稳。

## 四、刷完怎么验证稳不稳定

判断标准不是跑分高低，而是**有没有显示异常**：

1. 用 3DMark 之类跑分工具跑一轮（Wildlife / Wildlife Extreme 都行），或者直接玩一会儿对 GPU 压力大的游戏；
2. 出现**闪点、彩色条纹、黑点、花屏、画面抖动**，都说明当前频率或电压撑不住；
3. 处理办法固定：把出问题那个档位的**频率往低调**一截，或者**把电压换成更高一档**（也就是列表里更靠下的那档），重新保存、重新打包刷入、重启，再测；
4. 反复几轮直到跑测试和日常使用都不再出现异常，这一档就算调稳了。

想更快定位问题档位，可以先用系统工具类 App 把 GPU 频率锁在你刚改的档位上再跑测试，能省不少猜的时间。

## 五、频率不是越高越好：先查上限

骁龙 865 之后的型号大多带 GPU 频率上限，**超过上限的频率根本无法正常工作**，甚至直接导致异常。各芯片上限不同，动手前先查清楚你这颗的天花板（社区资料按型号整理得比较全），别把表加到天花板以上。

改完一轮之后如果出现「刷入了但没变化」或者过几天自己变回默认了，按 [常见问题与恢复方法.md](常见问题与恢复方法.md) 对应章节排查。
