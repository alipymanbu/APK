## 一、装之前先确认三件事

KonaBess 不是装上就能用的普通 App，它要改的是手机的启动镜像，所以三样东西缺一不可：

1. **Bootloader 已解锁**：各品牌解锁方式不同，先确认你的机器解了锁；
2. **已有 root**：Magisk、KernelSU、APatch 任一都行，打开 KonaBess 后它会向 root 管理器请求授权；
3. **芯片在支持列表里**：只有部分骁龙型号可用，联发科、Exynos 等一律不行，具体清单见 [支持的骁龙机型与版本.md](支持的骁龙机型与版本.md)。

差了解锁或 root，打开就会卡在「获取镜像失败」；芯片不对则根本识别不出来。处理办法在 [常见问题与恢复方法.md](常见问题与恢复方法.md)。

## 二、下载与安装

安装包就是一份单文件 APK，从 [KonaBess 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c1a2fac13ba7) 转存后装到手机上：

| 项目 | 数值 |
| --- | --- |
| 版本 | 0.25beta |
| 包名 | `xzr.konabess` |
| 安装包大小 | 0.94M |
| MD5 | `5F0C3F572BAC43632A8FF569B7FD47CC` |

安装步骤：

1. 转存后在网盘里点 APK 安装，手机若弹出「禁止安装未知来源应用」，按提示给网盘临时授权即可；
2. 装完先别急着改参数，确认 root 管理器（Magisk / KernelSU / APatch）已经装好并且能正常弹授权窗；
3. 打开 KonaBess，第一个弹窗基本就是 root 授权请求，选择**允许**。

装好之后的完整操作顺序（先备份、再改表、再刷入）在 [超频降压操作步骤.md](超频降压操作步骤.md)。

## 三、第一次打开会看到什么

- **root 授权弹窗**：点允许。如果一直不弹，去 root 管理器里检查 KonaBess 是否被拒绝过。
- **芯片识别结果**：授权成功后，正常会显示你手机的骁龙型号；如果直接提示「获取镜像失败」，按 [常见问题与恢复方法.md](常见问题与恢复方法.md) 里的两条原因逐个排查。
- **界面语言**：应用本身没有做完整的中文适配，把手机系统语言切成简体中文后再打开，界面就会显示中文；不想改系统语言的话照英文菜单操作也行，各按钮的中文名在 [常见问题与恢复方法.md](常见问题与恢复方法.md) 第五节列了出来。
- **「帮助」入口**：应用内自带一页说明，遇到和本套文档不一致的地方，以应用内实际界面为准。

## 四、装它意味着什么风险

KonaBess 最终要把改好的镜像**刷回手机的启动分区**——这就是它必须 root、必须解锁 Bootloader 的原因，也意味着参数改坏了手机可能无法正常开机。所以第一次动手前务必按 [超频降压操作步骤.md](超频降压操作步骤.md) 的开头把旧镜像备份出来，并留一份在电脑上；真出了问题的恢复流程在 [常见问题与恢复方法.md](常见问题与恢复方法.md)。

系统的最低版本标注是安卓 5.2 以上；不过实际卡不卡得住你，取决于第 1 节那三个条件，而不是系统版本号。
