## 一、关键词能搜哪三个地方

在搜索框输入关键词后，可以选择匹配范围：

| 搜索范围 | 效果 |
| --- | --- |
| 标签（部分一致） | 作品标签里**包含**这个词的都算命中，结果最多 |
| 标签（完全一致） | 只匹配**完整等于**这个词的标签，结果更准 |
| 标题、说明文字 | 在作品标题和作者写的说明里找 |

pixiv 的作品主要靠标签组织，想找某个题材时优先试「标签（完全一致）」，搜不到再放宽到部分一致。

## 二、多关键词与排除

- **同时包含多个词（AND）**：用空格把关键词隔开，例如搜 `风景 水` 会同时命中带「风景」和「水」的作品；
- **排除某个词**：在不想出现的词前面加半角连字符 `-`，可以把它从结果里去掉（具体写法以官方帮助说明为准）。

另外勾选「整合显示同作者作品」，可以把同一作者的多个结果合并成一条，刷结果时不容易被一个人刷屏。

## 三、按条件筛选

搜索结果页可以叠加这些筛选条件，缩小范围：

| 条件 | 适用 |
| --- | --- |
| 投稿期间 | 只要最近（或某段时间）的作品 |
| 收藏数 | 只要热度达到某个档位的作品 |
| 分辨率 / 纵横比 | 找手机壁纸、横图封面时好用 |
| 字数 / 语言 | 小说作品专用 |

「收藏数」是最常用的热度筛子：收藏越多说明越多人喜欢，想快速找精品就把这个档位调高。

## 四、结果比预期少？检查这几个开关

搜索结果突然变少，多半不是没图，而是被设置挡掉了：

1. **浏览限制**：R-18、R-18G 这类年龄限制作品默认不显示，而且这项设置不能在 APP 里改，要用网页版调整，具体见 [年龄限制作品显示设置.md](年龄限制作品显示设置.md)；
2. **AI 生成作品过滤**：可以设置搜索结果是否显示 AI 生成的作品，开着过滤时相关结果不会出现；
3. **屏蔽设置**：被你屏蔽的标签或作者不会出现在结果里。普通用户可以屏蔽 1 项，高级会员最多 500 项；
4. **地区限制**：因所在地区原因，部分作品无法浏览，这属于平台规则，不是 APP 故障。

## 五、排行榜：不知道搜什么的时候

不想搜关键词时，排行榜是现成的逛法。APP 里有「排行榜」页，每天正午过后（日本时间）公布按前一天数据算出的榜单，种类有这些：

| 榜单 | 收录范围 |
| --- | --- |
| 每日 / 每周 / 每月 | 按日、周、月汇总的热门作品 |
| 新人 | 只收录从没进过每日榜的用户的作品（一旦上过日榜就不再进新人榜） |
| 原创 | 只收不含二次创作的原创作品 |
| AI 生成 | 只收 AI 生成作品（其他榜单都不含 AI 生成作品） |

排行榜同样受屏蔽与浏览限制影响：被你屏蔽的标签/用户、未开启显示的年龄限制作品，都不会出现在榜单里。

## 六、标签是入口

看中一张图时，点作品上的标签可以直接跳到同标签的作品列表——这是比搜索框更顺手的找图路径，看到合适的标签就点进去多看几张。
