# AIRI 常见问题与解决方法

> 发消息没反应、回复慢、不说话、手机上找不到某些功能——这篇把 AIRI 新手最常撞到的问题集中列一遍。

## 一、发消息没有任何回复

装好后第一句话发出去石沉大海，几乎都是「大脑」没接好，按顺序排查：

1. **还没配服务商**：AIRI 本身不带模型，必须先在初始化引导或「服务来源」设置里配好一个聊天服务商。没有配置的情况下发消息就是没回应，这是最常见的误会的来源；
2. **API Key 填错**：多一个空格、少一段、复制成了别的服务的 Key 都会导致请求失败，重新粘贴一遍；
3. **Base URL 不对**：用 OpenAI 兼容接口时，端点地址要从服务商文档里原样复制，不要凭印象手打；
4. **没选模型**：配完服务商还要在模型列表里选定一个并保存，只配来源不选模型等于没配完。

具体每一步的填法见[大模型与API密钥配置.md](大模型与API密钥配置.md)。

## 二、回复要等很久

- 你选的是**带思考功能的模型**。官方文档明确提示这类模型生成回复很慢，换成普通对话模型（非思考模型）流畅度立刻不一样；
- 服务商本身在高峰期响应慢，可以在服务商的官网或状态页确认；
- 本地模型（Ollama）的回复速度取决于你设备的算力，模型选太大就会等很久，换个小参数量的模型试试。

## 三、她不开口说话 / 听不到我说话

- **无声**：去「机体模块 → 发声」确认没有选「无」，且语音合成提供商已切换到你自己新加的那个——自带的 Kokoro TTS 不支持中文，中文内容会读不出来或表现异常；
- **听不到**：先查「听觉」是不是还停在「无」；再查麦克风权限——系统弹权限时点过拒绝的，去系统设置里给应用补上麦克风授权；最后在听觉页点「start monitoring」测麦克风有没有电平；
- **她说话时我插不上话**：这是正常设计，AIRI 朗读时会暂停收音，避免把自己的声音识别进去，等她读完再说。

语音两半的完整配置步骤在[语音输入与输出设置.md](语音输入与输出设置.md)。

## 四、有些功能在手机上找不到

移动端版本仍在持续开发中，功能上和桌面端有差距。目前这些能力主要在桌面端，或需要从源码运行：

- 游戏联动（我的世界、异星工厂）；
- Discord / Telegram 机器人；
- 屏幕视觉捕捉（Vision Capture）；
- 更完整的长期记忆。

手机上想体验更多功能，可以直接用浏览器打开官方网页版 `https://airi.moeru.ai/`，官方文档目前也建议手机用户优先用网页端；桌面端安装包从 GitHub 的 [releases 页面](https://github.com/moeru-ai/airi/releases/latest)下载，文件名形如 `AIRI-<版本号>-windows-x64-setup.exe`，以页面当时显示为准。

## 五、想换形象、换性格

形象和性格都归角色卡管：内置的「ReLU」可以直接换掉，自己建卡或导入社区分享的 Character Card V3 卡包都行，卡包还能附带 Live2D/Spine/VRM 形象模型。做法见[角色卡创建与切换.md](角色卡创建与切换.md)。

## 六、想重装或换个版本

重装前不用做特别备份——配置和服务商凭据存在本地应用数据里，卸载会一起清掉，介意的话先把 API Key 记到别处。重新安装还是从[AIRI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/214eb5e3b959)转存下载即可。

想用更新的版本就去官方 [releases 页面](https://github.com/moeru-ai/airi/releases/latest)看，注意区分稳定版和预发布版——预发布版功能新但可能出问题，追求稳定选稳定版。另外网上搜到的「AIRI」相关介绍五花八门，版本号、功能描述经常对不上，判断信息新旧时以官方文档 `https://airi.moeru.ai/docs/` 和你自己设备上的实际表现为准。

## 七、哪里能问到活人

自查无果时，社区里有真人可以问：

- **Discord**：项目官方 Discord 服务器，官方手册里留了管理员账号可以留言提问，入口见官方文档页面；
- **QQ 群 / 微信群**：中文用户聚集地。两个群的加入方式都以 GitHub 仓库（`https://github.com/moeru-ai/airi`）README 与说明文件里的最新指引为准——邀请链接会过期，别信第三方转贴的旧链接。

提问前把这几样准备好：你的应用版本号、用的服务商和模型、问题的具体表现（截图更清楚，但注意别把 API Key 截进去）。版本对不上号是社区答疑里最常见的来回，先说清楚能省一轮。
