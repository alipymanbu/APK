# AIRI 语音输入与输出设置

## 一、语音功能的两半：发声和听觉

AIRI 的语音分两个独立模块：**发声**（TTS，把回复读出来）和**听觉**（STT，把你的话转成文字）。两者互不依赖，可以只开一半——比如让她读字但你只打字，或者你说话她只回文字。不想用的话，在对应页面选「无」即可，官方手册也是这么建议的。

两个模块的入口都在设置的「机体模块」页面里。

## 二、让 AIRI 开口说话（TTS）

配置路径：设置 → 机体模块 → 发声。

关键的一条：**自带的 Kokoro TTS 不支持中文**。中文用户不要在自带音源上浪费时间，直接加一个新的语音服务商：

1. 在发声页面点「＋」新增一个来源；
2. 填入该服务商要求的内容（通常是 API Key，按服务商文档来）；
3. 回到「发声」页面，把语音合成提供商切换成刚加的这个；
4. 先选服务商和模型，再选该模型提供的音色——顺序反了看不到可用音色。

补充两点：不同服务商显示的设置字段不一样，以实际界面为准；Pitch（音调）只对支持该参数的服务商生效，调了没反应不是坏了。

启用后，AIRI 朗读回复时输入区会出现「停止朗读」按钮，点它只停当前这段语音，不会撤销已经生成的文字回复。

## 三、让 AIRI 听见你（STT）

配置路径：设置 → 机体模块 → 听觉。

1. 选择一个语音转文字的服务商。官方手册提到浏览器自带的 STT 对中文支持不完整（网页端的经验），想省事同样建议新建一个支持中文的服务商来源；
2. 配好后还要**选一个可用的麦克风**，并允许应用使用麦克风——第一次使用时系统会弹权限请求，拒绝过的话之后就去系统设置里手动补授权；
3. 回到首页的对话框，点麦克风图标选择麦克风、开关语音输入。

听觉模块还有一组自动发送设置：

| 设置项 | 作用 |
|---|---|
| Auto-send transcribed text（自动发送转录文本） | 开启后识别结果按设定延迟自动发出 |
| 关闭自动发送 | 识别结果先停在输入框，你检查修改后再手动发 |
| Auto-send delay（自动发送延迟） | 调整识别完成到自动发出之间的等待时间 |

建议先关着自动发送用几天，确认识别质量后再开。

一个容易让人疑惑的行为：**AIRI 正在说话时会暂停收音**，避免把自己的语音识别进去。所以「她读回复时我插不上话」是设计如此，等她读完再说话即可。

## 四、测试与排查

配置页里自带两组测试：

- **测麦克风**：在听觉页中间点「start monitoring」开启监听，对着说话看电平反应，没反应就调 Sensitivity（灵敏度）或检查系统里麦克风是否被别的应用占用；
- **测 STT**：在页面最下方点「start speech-to-text」，说话后在 Transcription Result 区看识别结果，有字说明链路通，没字先查麦克风权限。

常见故障速查：完全无声 → 发声选了「无」或没切到新加的服务商；说话没反应 → 麦克风权限没给、或听觉还停在「无」；中文识别成一堆乱码/空结果 → 用了不支持中文的默认 STT，换服务商。更多问题场景见[常见问题与解决方法.md](常见问题与解决方法.md)。

## 五、语音功能的成本提示

TTS 和 STT 都是按用量向服务商付费的（多数有小额免费额度），语音开得越频繁开销越大。想压成本的话：中文内容先确认服务商支持中文再充钱；纯文字聊天不产生语音费用；更多省钱路线（含免费方案）单独整理在[运行费用与免费方案.md](运行费用与免费方案.md)里。

语音通了你就有了一个能看、能说、能听的完整角色。想进一步调她的性格和绑定的模型，回到[角色卡创建与切换.md](角色卡创建与切换.md)。
