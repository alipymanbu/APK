## 一、为什么装好之后还不能聊

AIRI 的角色表现（形象、动作）是本地的，但理解和生成回复依赖外部的大语言模型服务。你没有配置服务商时，发消息不会有回应——这不是卡住了，是还差一步配置。官方文档的说法是：先保证「聊天服务商和模型」配置成功，之后再加语音、视觉这些能力。

## 二、服务商怎么选

以下是官方支持的主要接入方式，按你的情况对号入座：

| 接入方式 | 适合谁 | 需要准备 |
|---|---|---|
| OpenAI 兼容接口 | 手里有任意兼容 OpenAI 格式的中转或官方 Key | API Key + Base URL |
| DeepSeek | 想用国产模型，价格敏感 | DeepSeek 的 API Key |
| OpenRouter | 想一个 Key 切换多家模型 | OpenRouter 的 API Key |
| Ollama（本地） | 电脑上已经跑过本地模型，想断网可用 | 本机已启动 Ollama 服务 |
| Gemini / Claude / Qwen | 有对应官方账号与 Key | 对应服务商的 API Key |

几点补充判断：

- **不确定选哪个时**，官方文档建议从官方提供商、OpenRouter、OpenAI 兼容接口或本地 Ollama 里挑一个开始。前三种都需要联网和 Key，Ollama 适合不想把对话发给云端的场景，但推理速度取决于你的设备。
- **OpenAI 兼容接口是万能兜底**。市面上的聚合站、中转站几乎都提供 OpenAI 格式，只要拿到 Key 和 Base URL 两个值就能填；国内厂商（DeepSeek、通义千问、智谱、Kimi 等）大多也提供 OpenAI 兼容端点。
- **先想成本再选型**。不同接入方式的持续开销差得很多，免费的路线也有好几条，选之前看一眼[运行费用与免费方案.md](运行费用与免费方案.md)。
- 本篇不展开各家 Key 的申请步骤，那属于各服务商自己的注册流程。

## 三、配置步骤

**第一次打开 App**：初始化引导会直接带你走一遍——选择语言后，点「配置你自己的 AI 服务来源」，然后按下面填。如果你想用官方提供的模型服务，也可以在引导里点「登录」，用官方账号方案省去自己找 Key 的过程。

**已经过了引导、想改配置**：进入设置界面，找到「服务来源」（服务商）相关页面操作。

以 OpenAI 兼容接口为例（官方手册以硅基流动举例，流程一致）：

1. 在服务商列表选中你要用的来源，点「下一步」；
2. 填入 API Key；如果选的是「OpenAI 兼容」类型，还要填 Base URL，也就是服务商的 API 端点地址，通常在服务商的接口文档里能直接复制；
3. 再点「下一步」进入模型选择；
4. 从模型列表里选一个模型，点「保存并继续」。

保存后回到主界面发一句话试试，有回复就说明通了。

## 四、模型怎么挑

模型列表里的名字都来自你配置的服务商，AIRI 只是把它们列出来给你选。挑选时两个实用建议：

- **优先选非思考模型**。官方文档明确提示：带思考（reasoning）功能的模型生成回复要等更久，对话流畅度差。日常聊天选普通对话模型体验更好。
- **想用绘画功能要留意工具调用**。如果你之后打算让 AIRI 生成图片，聊天模型必须支持工具调用（Tool Calling / Function Calling），否则模型只会回文字、不会向图像服务提交任务。选模型时在服务商那边确认一下这个能力。

## 五、API Key 的安全习惯

- API Key 只保存在你自己的设备里，这是 AIRI 的设计方式——凭据不经过第三方服务器。
- 不要把 Key 截图、贴到群里、发到 Issue 或任何公开场合。Key 泄露等于把你的模型账户送给别人刷。
- 如果怀疑泄露，立刻去服务商后台吊销重开一个，然后在 AIRI 设置里替换。
- Discord Bot Token、语音服务的凭据同理，都只存本地配置。

配置好「大脑」之后，下一步通常是给她定人设和形象，见[角色卡创建与切换.md](角色卡创建与切换.md)；想让她开口说话、听见你说话，见[语音输入与输出设置.md](语音输入与输出设置.md)。配完还是没反应的话，[常见问题与解决方法.md](常见问题与解决方法.md)第一节就是针对这种情况的。
