## 一、钱花在哪：一张总账

AIRI 是开源软件，安装它本身不花钱。持续的成本来自你接入的外部服务，按使用习惯可能涉及三项：

| 项目 | 什么时候产生 | 大致量级 |
|---|---|---|
| 聊天模型 API | 每发一条消息 | 按输入/输出字数计费，轻度闲聊通常每月几元起，量大的话随消息量上涨 |
| 语音合成（TTS） | 每次让她开口 | 各家按字符数计费，部分服务商有免费额度 |
| 语音识别（STT） | 每次语音输入 | 多数按时长计费，部分服务商有免费额度 |

具体价格由你选的服务商决定，AIRI 不抽成、不加价——它只是把请求转发给你自己填 Key 的那家。以下价格类信息截至 2026-09，均以各服务商页面为准。

## 二、聊天模型的省钱路径

按成本从低到高有三条路：

**1. 本地模型（零 API 费）**。用 Ollama 在自己的电脑上跑开源模型，AIRI 接本地服务，之后聊天不再产生 API 费用。代价是要一台配置够的电脑、并且手机上的 AIRI 得和它处于同一网络环境才能连上。适合愿意折腾、对隐私敏感的人。

**2. 免费额度的云端模型**。OpenRouter 聚合了多家模型，其中带免费标注的模型可以直接零成本试用（以 [OpenRouter 官网页面](https://openrouter.ai/)当时显示为准）；国内厂商（DeepSeek、通义千问、智谱、Kimi 等）普遍提供新用户赠送额度，多数还提供 OpenAI 兼容端点，AIRI 里选「OpenAI 兼容」类型填上就能用。

**3. 低价套餐**。各家厂商时不时推出低价调用包，有用户实测过国内厂商每月几元的小套餐对日常闲聊就够用（这类促销时有时无，下单前看当时的价格页）。

一个来自社区的提醒：有用户反馈过个别国内服务商的接口与 OpenAI 兼容格式存在细节差异，直连可能报错——遇到这种情况换一家、或查该服务商的兼容性说明，不是 AIRI 的问题。

## 三、语音功能的成本参考

- **TTS**：应用自带 Kokoro 语音不支持中文，中文用户实际都要外接服务商。各家云端 TTS 按字符计费，多数有小额免费额度；想零成本的话，有用户在电脑上自建了开源的 TTS 兼容服务，再把服务地址填进 AIRI 的语音设置里用（属于进阶玩法，需要一台常开的电脑，具体以该开源项目文档为准）。
- **STT**：部分服务商按分钟计费，闲聊场景每月用量不大。手机上也可以只用文字输入，STT 完全不配置不产生任何费用。

## 四、控制开销的几个习惯

- 给角色卡绑定模型时（见[角色卡创建与切换.md](角色卡创建与切换.md)），日常闲聊绑便宜的模型，只在需要时切贵模型，切换卡片即切换计费档位；
- 选非思考模型——思考模型回复前会先在后台生成一段思考内容，这段同样计费，换普通模型既快又省；
- 定期去服务商后台看用量明细，AIRI 侧不显示消费金额；
- API Key 不要外泄——Key 被别人拿去刷，账单算你的。

算完账再决定怎么配也不迟，服务商的具体填法见[大模型与API密钥配置.md](大模型与API密钥配置.md)。还没装应用的话，先从[AIRI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/214eb5e3b959)拿到安装包，装好再谈配置。
