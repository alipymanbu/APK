# spacedesk 手机变电脑副屏设置步骤

> 电脑端和手机端都装好后，本篇带你从零连出第一块「手机副屏」，并讲清扩展与镜像两种模式怎么切。

## 一、连接前确认三件事

1. 电脑端 spacedesk Driver Console 状态是 **ON**；
2. 手机和电脑处于**同一个局域网**（连同一个路由器）；
3. 没开 VPN —— VPN 会让手机和电脑「看起来不在一个网络里」，是搜不到电脑的常见原因。

三件事都没问题，就可以按下面的三种方式任选一种连接。

## 二、方式一：同一个 Wi-Fi（最省事）

1. 手机打开 spacedesk，主界面会自动搜索同一网络里的电脑；
2. 等你的电脑名字出现在列表里，点它后面的连接按钮；
3. 手机屏幕上出现电脑画面，连接完成。

首次连接电脑端如果弹出防火墙提示，选**允许**。这一步之后手机就相当于一块真正的副屏：你可以在上面放文档、聊天窗口、视频，鼠标也能直接移过去操作。

## 三、方式二：热点直连（没有路由器 / Wi-Fi 太挤时用）

让两台设备直接点对点连，绕开路由器：

- **电脑开热点**：Windows 设置 → 网络和 Internet → 移动热点，打开后让手机连这个热点；
- 或**手机开热点**：手机开热点，让电脑连上去。

连好后打开 spacedesk，步骤与方式一相同。热点直连的延迟通常比「经过路由器的 Wi-Fi」好，在外面没有路由器的场合（笔记本 + 手机）也靠它。

## 四、方式三：USB 数据线（追求稳定时用）

安卓端支持走 USB 线传输画面，利用的是系统的「USB 网络共享」：

1. 用数据线把手机连到电脑；
2. 手机设置里打开 **USB 网络共享（USB tethering）**（一般在 设置 → 网络 → 热点与网络共享 里）；
3. 电脑上会多出一个新的网络适配器，spacedesk 会通过它找到电脑；
4. 打开 spacedesk 点连接。

USB 方式不受 Wi-Fi 干扰影响，长会话、看文档码字这类用途下最稳。三种方式的快慢对比与选法，单独写在[画面卡顿优化技巧](画面卡顿优化技巧.md)里。

## 五、连上之后：扩展还是镜像

连接成功后，手机默认成为一块**扩展屏**（把窗口拖过去就是另一块桌面）。想改模式：

1. 电脑上按 `Win + P`，或者右键桌面 → 显示设置；
2. **扩展**：手机显示电脑桌面的延伸部分，两边内容不同，办公首选；
3. **复制**：手机与主显示器显示同样内容，适合把手机架起来当演示屏；
4. 在显示设置里还能拖动两块屏幕的相对位置，让鼠标移动方向和实物摆放一致；副屏的分辨率、缩放也在这个页面里调。

## 六、横竖屏、触控与断开

- **横竖屏**：转动手机，画面会跟着旋转；不想要自动旋转就在手机系统里锁住方向，或在 spacedesk 设置里关掉自动旋转。
- **触控**：手机屏幕可以直接点按操作电脑，设置里有「触摸屏（绝对位置）」与「触摸板（相对移动）」两种模式可切换；带压感笔的设备可以直接在上面写画。部分多指手势在旧版本上不可用，以你装到的版本实测为准。
- **断开**：手机端点断开按钮即可；下次打开 App，这台电脑还会在列表里，再点一次就重连。

连不上、列表里没有电脑、或者连上就掉线，去[连接失败排查方法](连接失败排查方法.md)按顺序查一遍，多数问题两分钟内能定位。
