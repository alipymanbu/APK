> spacedesk 由电脑端与手机端两部分组成，缺一不可。本篇按「先电脑、后手机」的顺序讲清两边各自从哪拿、怎么装、装完怎么确认就绪。

## 一、先弄清要装哪两个东西

spacedesk 是「一对」软件，很多人装完发现连不上，第一原因就是只装了一头：

| 设备 | 装什么 | 从哪拿 | 作用 |
| --- | --- | --- | --- |
| Windows 电脑 | spacedesk DRIVER（驱动程序） | 官网 [www.spacedesk.net](https://www.spacedesk.net) | 把电脑变成「被显示的一端」 |
| 安卓手机 / 平板 | spacedesk Viewer（本篇的主角） | 见下方第三节 | 把手机屏幕变成「显示的一端」 |

两台设备之后要通过**同一个局域网**（或 USB 线）连起来，全程不需要连接互联网。

## 二、电脑端：下载并安装 DRIVER

1. 打开官网下载页 [www.spacedesk.net](https://www.spacedesk.net)，按你的系统版本下载对应的 DRIVER 安装包（Windows 11 / Windows 10 / Windows 8.1 各有对应版本；Windows 7 已不在官方支持列表里）。
2. 双击运行下载到的安装包，一路 Next，接受许可协议。
3. 安装过程中有一项 **「Add an exception to the Windows Firewall for spacedesk」**（把 spacedesk 加入 Windows 防火墙例外），保持勾选，不要取消 —— 取消了之后手机很可能搜不到电脑。
4. 装完如果提示重启，就重启一次。
5. 装完后电脑右下角托盘区会出现 spacedesk 图标，点开 **spacedesk Driver Console**，确认状态是 **ON**（默认就是开着的）。

对显卡的要求以官方页面为准：一般的 NVIDIA / AMD / Intel 核显独显都可以；显卡驱动太旧的电脑建议先更新显卡驱动再装。虚拟机、SLI / CrossFire 多卡环境不在官方支持范围内，遇到问题别浪费时间排查。

## 三、安卓端：拿到安装包并安装

安卓端就是本页提供的 spacedesk 安装文件资源，转存后把 APK 装进手机即可：

- [spacedesk 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6477de5a7823)

本资源对应的版本信息如下，可以作为核对依据：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.1.38 |
| 包名 | `ph.spacedesk.beta` |
| 安装包大小 | 3.08 MB |
| MD5 | `F64A169ACE6426A8F08A021925307BB5` |
| 采集时间 | 2026-09-21 |

安装时注意两点：

- 安卓端要求 **Android 5.0 及以上**。
- 如果手机提示「未知来源应用」，在系统设置里允许该来源安装即可；装完可以关掉。

装好后打开 App，名字就叫 spacedesk（有些渠道显示为 spacedesk - USB Display for PC），开发者署名应为 datronicsoft —— 包名 `ph.spacedesk.beta` 是确认你没装到仿冒应用的最可靠依据。

## 四、装完后的检查清单

两边都装完后，逐条确认，全部满足就可以去看[手机变电脑副屏设置步骤](手机变电脑副屏设置步骤.md)了：

1. 电脑端 Driver Console 状态为 **ON**；
2. 手机和电脑连的是**同一个路由器**（或准备用 USB / 热点方式，见连接教程）；
3. 电脑的防火墙放行了 spacedesk（安装时勾了例外一般就没事；装了第三方安全软件的，手动放行一次）；
4. 手机打开 spacedesk，界面上能刷出你的电脑名字。

搜不到电脑、或者点了连不上，直接翻[连接失败排查方法](连接失败排查方法.md)，那篇按出现概率排了排查顺序。

## 五、版本有效期：这件事提前知道能省一次排障

spacedesk 目前以 beta 形式发布，**每个版本自带有效期**，这是它与其他软件不太一样的地方：

- 到期日期会显示在电脑端 **spacedesk Driver Console** 里，以那里显示的为准；
- 版本到期后连接会失效，**电脑端和手机端要一起更新到新版本**才能恢复 —— 只更新一头没用；
- 更新方式：电脑端去官网重下 DRIVER 覆盖安装，手机端用新的 APK 重装。

如果你某天打开突然连不上、提示过期（expired），多半就是这个原因，处理步骤写在[连接失败排查方法](连接失败排查方法.md)的过期一节。

## 六、免费还是收费

官方的授权口径（以官网授权页为准）：**个人非商业使用免费**，功能与商业版相同；公司设备、经营性用途属于商业使用范畴，需要对应的商业授权。手机端在 Google Play 等渠道标注有应用内购买项目，日常当副屏用不到它，不影响免费使用。
