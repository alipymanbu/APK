## 一、先确认你手里的是「数据线」

USB 方式走的是系统的「USB 网络共享」，它要求线材能传数据。市面上大量线材是**只充电线**：插上能充电、手机识别不到电脑，共享开关直接是灰的。快速判断：

- 换一根确定能传文件的线（平时连电脑拷照片用的那根）；
- 插上后手机通知栏出现 USB 连接提示、电脑有「叮咚」声，才说明这根线有数据能力；
- Type-C / Micro-USB 都可以，与手机接口匹配即可。

## 二、手机端：先插线，再开 USB 网络共享

顺序很重要：**先插线，再找开关**。多数手机在没检测到 USB 连接时，「USB 网络共享」开关是灰的、点不动（三星等品牌的官方说明里明确写了这一点）。

| 手机 | 路径 |
| --- | --- |
| 原生系统 / Pixel | 设置 → 网络和互联网 → 热点与网络共享 → USB 网络共享 |
| 三星 | 设置 → 连接 → 移动热点和网络共享 → USB 网络共享 |
| 其他品牌 | 从屏幕顶部下拉，长按「热点」进入，找 USB 网络共享 |

两个实际会碰到的细节：

- 每次重新插线，这个开关可能要**重新打开一次**（部分系统不会自动记住）；
- 开关打开后手机如果弹「USB 连接请求」之类的确认，点允许。

## 三、电脑端：两处确认

1. 打开 **spacedesk Driver Console**，确认状态 ON，并在设置里启用 **USB Cable（Android）** 相关选项（不同版本的菜单位置略有差异，找到 USB 字样的开关打开即可）；
2. 插线并打开手机共享后，Windows 的网络适配器列表里会多出一个新网络 —— 它显示「未识别的网络 / 无 Internet」是**正常现象**，这条链路是给 spacedesk 传画面用的，本来就不需要能上网，别去「修复」它。

## 四、连上后手机上出现 192.168 开头的地址

USB 方式连好后，手机端 spacedesk 列表里出现的通常是一个 `192.168.x.x` 的本地地址（而不是电脑名字），点它连接即可 —— 这是 USB 网络共享的虚拟网段，属正常现象。

## 五、用着用着断：两个节电设置

USB 共享的网络适配器会被 Windows 的节电策略停掉，长会话掉线先查这两处：

1. 设备管理器 → 网络适配器 → 找到你手机对应的适配器 → 右键属性 → 电源管理 → 取消勾选「允许计算机关闭此设备以节约电源」；
2. 控制面板 → 电源选项 → 更改高级电源设置 → USB 设置 → USB 选择性暂停设置 → 改为「已禁用」。

另外手机侧开启省电模式也会掐断后台传输，插着电源、关掉省电模式再当副屏。

## 六、什么时候选 USB，什么时候选无线

- **选 USB**：Wi-Fi 信号差或拥挤、公共 Wi-Fi 环境（同一网络里的陌生人可能搜到你的电脑）、需要长时间稳定挂着的会话；
- **选无线**：手机要边充电边到处走、电脑没空余 USB 口、临时展示。

无线方式的完整对比（哪些快哪些慢）在[画面卡顿优化技巧](画面卡顿优化技巧.md)里；USB 走不通时，先回[手机变电脑副屏设置步骤](手机变电脑副屏设置步骤.md)确认无线方式可用，再用本篇第五节排 USB 专属问题。
