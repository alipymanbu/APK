## 一、先走这条五步快查

大多数连接问题出在最基础的地方，先花一分钟过一遍：

1. 电脑端 spacedesk Driver Console 状态是不是 **ON**；
2. 手机和电脑是不是连的**同一个路由器**（注意别一边连了访客 Wi-Fi、一边连了主 Wi-Fi）；
3. 两边是不是都没开 **VPN**；
4. 电脑上有没有装**第三方安全软件**（它们自带防火墙，Windows 防火墙的例外对它们无效）；
5. 两边都重启一次再试（驱动 OFF 再 ON，手机 App 杀掉重开）。

快查没解决，再按下面几节对号入座。

## 二、手机列表里根本不出现电脑

按命中率从高到低：

| 原因 | 怎么确认 | 怎么处理 |
| --- | --- | --- |
| 不在同一网段 | 电脑和手机连的是不是同一个路由器 | 改成连同一个 Wi-Fi；有多个路由器/中继的，确认它们没有做网络隔离 |
| 路由器开了 AP 隔离（访客网络常见） | 手机连的是不是「访客 Wi-Fi」 | 关掉访客网络或 AP 隔离，换主网络 |
| VPN 拦在中间 | 两端任一处开着 VPN | 都关掉再搜 |
| 电脑端驱动没开 | 托盘图标 → Driver Console 显示 OFF | 点成 ON |
| Windows 防火墙拦了 | 安装时没勾「加入防火墙例外」 | 防火墙设置里手动放行 spacedesk，或重装驱动并保持勾选 |
| 第三方安全软件拦了 | 装了电脑管家类软件 | 在该软件的联网防火墙里放行 spacedesk |

还搜不到的话，用[热点直连](手机变电脑副屏设置步骤.md)绕开路由器试一次：热点下能连上，问题就锁定在路由器网络侧。走 USB 数据线的遇到「搜不到 / 共享开关是灰的」，换 [USB数据线连接副屏步骤](USB数据线连接副屏步骤.md)排查线材与两端设置，那篇不占这里的条目。

## 三、能搜到，但点了连接失败或闪退

- **两边版本不匹配**：电脑端 DRIVER 与手机端 Viewer 版本差距过大时会连不上，把两端都更新到当前版本再试（安装包获取见[下载与安装教程](下载与安装教程.md)）。
- **连接中途闪退**：把手机后台清干净重开 App；系统剩余内存太小的旧设备更容易出现。
- **显卡驱动太旧**：电脑显卡驱动多年没更新过的，先更新显卡驱动再试，历史上旧驱动与 spacedesk 同用出过蓝屏案例。
- **反复失败**：在电脑端 Console 里把状态 OFF → ON 切一次，等 10 秒再连。

## 四、提示版本过期（expired）

spacedesk 的版本自带有效期（机制说明见[下载与安装教程](下载与安装教程.md)第五节），到期后会出现连不上、提示 expired 之类的情况。处理只有一条路：

1. 电脑端去官网 [www.spacedesk.net](https://www.spacedesk.net) 下载**当前**的 DRIVER，覆盖重装；
2. 手机端用**当前**的 APK 重装：[spacedesk 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6477de5a7823)；
3. **两端都要更新**，只更新一头还是会失败；
4. 重装后新的到期日期在 Driver Console 里可以看到。

平时在 Console 里瞄一眼到期日期，快到期就顺手更新，可以彻底避开这个坑。

## 五、特殊环境：这些情况官方不保证

- **虚拟机**：在虚拟机里跑 Windows 当主机不属于官方支持范围，可能出现鼠标指针乱跳、副屏黑屏等现象，别在这上面耗时间；
- **多显卡互联**：SLI / CrossFire 开启时 spacedesk 无法正常工作，先关掉；
- **公司 / 学校网络**：这类网络常有设备隔离策略，手机和电脑互相看不见。换手机热点直连最省事；
- **Windows 7**：已不在官方支持列表，能装上也不代表能用，不建议折腾。

## 六、都不是，还是连不上

把两端的现象描述整理好，去官方支持论坛 [forum.spacedesk.ph](https://forum.spacedesk.ph) 发帖求助。发帖前先确认你两端都是当前版本 —— 旧版本的连接问题往往更新一次就没了。如果连上了但画面卡，去[画面卡顿优化技巧](画面卡顿优化技巧.md)调连接方式。
