## 一、这是什么应用

Magnet Robot 是一款安卓端的磁力链接检索工具，应用界面的中文名是「磁力检索机器人」，副标题写着「为你方便快捷抓取数据」。你打开它，在输入框里敲关键字，它会去多个磁力数据源里检索，把命中的条目列出来。

它只负责检索与展示，拿到条目之后怎么用由你自己决定。

装之前先对一下手机：

| 项目 | 数值 |
| --- | --- |
| 版本 | 1.0.9 |
| 包名 | `com.magnet.robot` |
| 安装包大小 | 18.31M |
| 系统要求 | 安卓 5.2 及以上 |
| 应用分类 | 系统工具 |

以上是本地保存的那一份安装包（2026-09-23 保存）的实测信息；网上能搜到的介绍若与之冲突，以这份为准。

## 二、从网盘拿安装包

1. 打开 [Magnet Robot 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2d807ef5d221)。
2. 把里面的文件夹转存到你自己的网盘（登录夸克后按提示操作即可）。
3. 在网盘里找到 `Magnet Robot_v1.0.9.apk`，下载到手机。
4. 也可以先在电脑上下载，再通过数据线或局域网传到手机。

文件夹里会附一个「先保存再下载避免失效」的说明文件，照做就行——分享链接有时效，转存到自己网盘最稳妥。

## 三、安装步骤

1. 在手机文件管理器里点刚下载的 `.apk`。
2. 系统弹出「是否允许安装未知应用」时，需要给当前文件管理器（或浏览器）授予安装权限：到 `设置 → 安全/应用安装` 里打开对应开关，再回来点安装。
3. 等安装完成，打开应用。

几个常见的安装卡点：

- **提示「解析包时出错」**：多半是下载不完整，删掉重下（参见 [设置与常见问题.md](设置与常见问题.md) 里的排查）。
- **提示「与现有版本冲突」**：手机里装过同包名但签名不同的包，先卸载旧的再装。
- **系统要求确认**：应用需要安卓 5.2 以上；系统过低会装不上或闪退。

## 四、首次打开会看到什么

装好打开，你会看到一个以对话式检索为主界面的页面：

- 顶部是应用名「磁力检索机器人」与副标题，右上角有两个图标：消息/会话图标和设置图标；
- 中间是空状态插画，写着「智能磁力链检索机器人」；
- 底部一排是输入区：左边麦克风按钮、中间「请输入您要检索的关键字」输入框、右边发送按钮。

第一次用直接在输入框里打字、点发送，就能发起一次检索。检索结果长什么样、每个字段什么意思，见 [磁力搜索结果怎么看.md](磁力搜索结果怎么看.md)；如果打开时弹出推广页面，处理办法在 [设置与常见问题.md](设置与常见问题.md)。
