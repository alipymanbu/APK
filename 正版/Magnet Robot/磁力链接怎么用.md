## 一、它长什么样

一条磁力链接是纯文本，最简形式只有一行：

```
magnet:?xt=urn:btih:51df6808c739174c8f264701ba94460c5238d6ce
```

各段含义：

| 片段 | 含义 |
| --- | --- |
| `magnet:` | 协议名，表明这是磁力链接 |
| `xt=urn:btih:` | 参数名 `xt`（exact topic）+ 标识类型：BitTorrent info hash |
| 后面 40 位字符 | 文件内容的 SHA-1 哈希，是这份资源的唯一指纹；内容差一个字节，哈希就完全不同 |
| `&dn=文件名` | 可选，显示用的文件名（下载工具拿到元数据前先显示它） |
| `&tr=tracker地址` | 可选，Tracker 服务器地址，帮下载工具找到同时在下这份文件的人 |

要点就一条：**这串字符不指向某台服务器上的文件，它只描述「文件的内容指纹」**。下载工具拿这个指纹去 P2P 网络里找持有相同文件的人，所以链接本身不会过期——只要还有人在分享，它就一直有效；反过来，一个都没人分享的资源，链接再正确也下不动。

## 二、怎么交给下载工具

磁力链接不是网页地址，点开不会直接下载，要交给支持它的下载工具：

1. **复制整条链接**——从检索结果或网页里长按/全选，确保 `magnet:?` 开头到结尾没有被截断（手机上复制最容易丢尾部）。
2. **打开你的下载工具**——手机或电脑上任意支持磁力/BT 的下载工具；多数工具会自动识别剪贴板里的 `magnet:?`，弹出「新建任务」确认框，没有弹就手动粘贴到新建任务输入框里。
3. **确认任务信息**——工具会先花点时间取元数据（文件名、大小、分片列表），取到之后才显示完整文件列表，这时再点开始。

电脑上在浏览器里直接点 `magnet:` 链接时，浏览器要先把交给哪个工具处理的权限配好（默认应用设置里的 `magnet` 项），否则点了没反应。

## 三、下载卡住时按这个顺序查

任务加进去了但不动，按出现频率从上往下排查：

1. **看状态文字**——`正在获取元数据` 是正常的等待（磁力链接本身不含文件列表，要先问网络要）；等了几分钟还在这一步，说明网络里找到的人太少，先放着或换下一个资源。
2. **看做种数**——下载工具会显示「做种中/连接的用户」数量。**0 个做种 = 现在没人分享这份文件**，这不是你的设备问题，等不来就换别的资源。
3. **看速度是不是 0 KB/s 但有连接**——多半是防火墙/安全软件拦了下载工具的出站连接，放行后重试；公司、校园网络常对 P2P 流量有限制，换个网络能验证。
4. **确认下载工具有开 DHT/节点发现**——DHT（分布式哈希表）是磁力链接不靠 Tracker 也能找到人的机制，工具的设置里相关开关要打开。
5. **换个下载工具再试**——同一条链接在不同工具里表现差异不小，一个工具卡死不代表链接坏了。
6. **核对链接本身**——`urn:btih:` 后面应是 40 位字符（新协议有 64 位的）；短了就是复制时被截断了，回源头重新复制。

（不同下载工具的界面与开关位置差别较大，具体选项名以你用的那个工具为准。）
