## 一、发起一次检索

打开应用，光标落在底部的「请输入您要检索的关键字」输入框上，输入关键词，点右侧的发送按钮即可。输入框左边的麦克风按钮是语音输入，不方便打字时可以用它。

检索是围绕关键字去多个数据源查的，所以：

- 关键字越具体，命中越准——太宽泛的词会返回一堆不相干条目；
- 换一种说法再搜一次是常态，第一个词没结果不代表没有。

## 二、结果页的结构

检索提交后会进入结果页，顶部标题是「磁力吧」，左边是返回箭头。

**标签栏是数据源。** 标题下方一排可切换的标签（默认看到的有「磁力天堂」「磁力多」「1024BT」等），每个标签代表一个独立的检索源。当前选中的那个下面有下划线。某个源没有命中，它的列表就是空的——**切标签看别的源**，是结果为空时第一件该做的事。

**底部那行提示要说清楚**：「搜索结果只展示搜索成功且有数据源的」。也就是说，你看到的条目只是「检索成功的那部分」，它不等于全网该关键词的全部结果；没显示不代表资源不存在，可能只是这个源当时没返回数据。

## 三、一条结果里有什么

每个条目大致是这样几行：

```
[标题]
收录时间：2023-04-03   文档大小：1.5 GB
由 www.cltt667.buzz 提供
```

| 字段 | 你该怎么读它 |
| --- | --- |
| 标题 | 资源的自述名称，也是你判断相关性的主要依据；标题本身常带来源站点信息 |
| 收录时间 | 该条目被收录进数据源的时间，**不是资源本身的发布时间**；久远不等于失效，但可作新旧参考 |
| 文档大小 | 资源的体积，用来预估下载量与手机剩余空间是否够 |
| 提供方 | 这条数据来自哪个站点（这里是数据来源标注，不是下载地址） |

列表最前面的图标是应用的机器人头像，没有可点的操作按钮——**结果页只负责展示**，复制链接等动作要靠长按标题或自己另想办法，具体以你装的这个版本的实际表现为准。

## 四、拿到条目之后

检索只是第一步，后续取决于你要做什么：

- 想把资源取回来，需要一个支持磁力链接的下载工具，把它交给那个工具处理——复制链接、新建任务、以及之后卡住怎么查，见 [磁力链接怎么用.md](磁力链接怎么用.md)；
- 大文件先看「文档大小」，确认手机存储空间够（18.31M 的是应用本体，资源体积是另一回事）；
- 换源再搜、换个关键词再搜，是拿到更多结果最直接的办法。

如果结果一直为空、或应用本身装不上、闪退，按 [设置与常见问题.md](设置与常见问题.md) 里的排查逐条试；还没装上应用的话，先看 [下载与安装教程.md](下载与安装教程.md)。
