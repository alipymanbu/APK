## 一、装之前先认识它

baseapk 是一款装在安卓手机上的 APK 管理工具：把手机里已装的应用提取成安装包、整理下载下来的一堆 .apk 文件、压缩解压文档、提取音频，都归它管。在腾讯应用宝等商店里它以「base.apk工具」的名字上架，开发者标注为合肥煌博信息技术有限公司，简体中文界面，商店页面上标注为免费、无广告。

你从上面网盘链接拿到的是 1.3 版。各下载渠道的版本并不一致（商店里能见到 1.1 到 1.8 的不同版本），凡涉及版本号、体积，都以你实际下载到的那份为准：

| 项目 | 数值 |
| --- | --- |
| 版本 | 1.3 |
| 包名 | dfg.com.fty |
| 安装包大小 | 57.38M |
| MD5 | 652C99ED8073092228FE79E918D224E1 |

应用商店对这个版本的介绍里还提到内置指南针、手电筒、分贝仪这类小工具，以及查看耗电排行的电池管理，用到时在工具列表里找。

## 二、从夸克网盘把安装文件转存下来

网盘分享链接里的文件要先转存进自己的网盘，才能下载：

1. 手机或电脑打开 [baseapk 安装文件资源（夸克网盘）](https://pan.quark.cn/s/524b02c3e88e)；
2. 勾选里面的安装包，点「转存」，选一个自己找得到的位置；
3. 打开夸克网盘 App（或网页版），在转存的位置把它下载到手机存储里。

下载完成后别急着点开——先在文件管理器里看一眼文件大小是不是在 57.38M 上下。差得远的文件多半下坏了，重新下一遍比排查省事。

## 三、打开「允许安装未知应用」

这份安装文件不经过应用商店，系统默认拦着。安卓 8.0 之后这个开关按应用逐个给：

1. 进 设置 → 应用 → 特殊应用权限（不同品牌叫法略有差别，直接在设置里搜「未知」最快）；
2. 找到「安装未知应用」；
3. 给你用来打开安装包的那个应用（一般是系统文件管理器，或夸克网盘）打开「允许安装未知应用」。

只给实际用来安装的那一个应用开就行，不用全局放开。

## 四、安装

1. 打开文件管理器，进刚才的下载目录，点安装包文件（文件名以你下载到的为准）；
2. 系统会列出这个应用需要的权限，点「安装」；
3. 等进度走完，点「打开」或回桌面点图标。

想核对拿到的文件和上面表格里那份是不是同一个，可以在电脑上算一下 MD5：

```powershell
Get-FileHash "D:\下载\baseapk_v1.3.apk" -Algorithm MD5
```

算出来的值与 `652C99ED8073092228FE79E918D224E1` 一致（大小写不敏感），就是同一份文件。

## 五、第一次启动

首屏会要求存储权限——这个必须给，不给它扫描不到手机里的应用和安装包，整个工具等于白装。安卓 11 之后还要多一步：全盘扫描类工具要的是「所有文件访问权限」，去 设置 → 应用 → 特殊应用权限 → 所有文件访问权限，在列表里找到 baseapk 打开开关。装完扫不到任何东西，先回头查这个开关。给完权限回到首页，能看到「文件收藏」和「导出记录」两个入口：前者是你收藏过的应用，后者留着每一次提取 APK 的历史。

装完先去 [应用提取与分享步骤.md](应用提取与分享步骤.md) 看它最核心的功能怎么操作；装不上、打开就闪退这类问题直接翻 [常见问题与解决办法.md](常见问题与解决办法.md)。
