# Libratone 常见问题与故障排查

> 本篇汇总 Libratone 耳机、音箱最常见的几类故障：连接断续、配对失败、配网不通、升级卡住，以及指示灯怎么读。

## 一、播放断续或有噪音

蓝牙耳机在无遮挡环境下距手机 10 米内可以正常使用。出现断续、噪音，按这个顺序排查：

1. 手机和耳机之间是不是隔了墙、身体或者另一台大功率设备；
2. 距离是不是超了——耳机连在身上、手机放在另一间屋是最常见的场景；
3. 附近有没有 Wi-Fi 路由器、微波炉等 2.4GHz 干扰源密集的环境。

距离和遮挡都正常还断续，先更新固件再试（见[固件升级与恢复出厂教程.md](固件升级与恢复出厂教程.md)）。

## 二、耳机连不上已配对过的手机

正常情况下配过对就会自动回连。回连失败时：

1. 在手机蓝牙列表里把这台耳机**删除（取消配对）**；
2. 让耳机进入设置模式（关机状态长按多功能键 3 秒以上，指示灯快闪）；
3. 重新在手机蓝牙列表里配对连接。

双击无效、回连慢这类问题，重配一遍多数能解决。

## 三、两部手机想共用一副耳机

耳机与两部手机都配对过之后，在两部手机的蓝牙列表里分别选择这副耳机连接即可。注意同一时刻耳机只跟一台手机保持活跃连接，切换时要先在当前手机上断开。

## 四、音箱 Wi-Fi 配网一直失败

1. 确认音箱在设置模式：顶部指示灯**左右交替闪烁**才是；不在就长按「小鸟」键约 2 秒强制进入；
2. 走安卓备用路：手机直连音箱热点，浏览器打开 `192.168.1.1` 手动配网（步骤见[耳机音箱连接配对教程.md](耳机音箱连接配对教程.md)第四节）；
3. 还不行就恢复出厂（ZIPP 2 / MINI 2：开机状态按住「小鸟」键和电源键 10 秒），等灯旋转、自动进设置模式后重新配网；
4. App 里设备旁出现感叹号标记，也可能只是 Wi-Fi 信号弱——把音箱挪近路由器再试。

## 五、App 搜不到设备

逐项核对：

- 设备是否已开机且有电（低电的设备可能无法进入配对状态）；
- 设备是否处于设置模式（灯快闪 / 左右交替闪），没进就按对应产品的按键操作进入；
- 手机蓝牙是否打开、是否离设备足够近；
- 音箱要配网的话，确认手机和音箱最终要连的是同一个 Wi-Fi。

## 六、指示灯含义对照

以 TRACK+ 耳机为例：

| 指示灯状态 | 含义 |
| --- | --- |
| 白灯快速闪烁 | 设置模式（可配对） |
| 红灯持续闪烁 | 固件升级进行中，别断电 |
| 红灯快闪 3 次 | 出现错误 |
| 白灯常亮 | 充电中（低电时为红灯常亮） |
| 灯熄灭 | 电量已充满 / 已关机 |

音箱（ZIPP 系列）：红灯闪烁 3 次表示错误；红灯长亮表示电量不足，尽快接电源；10 个灯转圈是在处理中，耐心等。

指示灯之外反复复现、怀疑硬件故障的，先看[保修售后与客服渠道.md](保修售后与客服渠道.md)里官方售后的联系方式，别自己拆机。

## 七、网上的老帖说「电台功能用不了」

ZIPP 系列的互联网电台依赖第三方平台，历史上出过服务中断；截至 2026-04 的官方公告，该服务已恢复，但官方同时说明它仍依赖第三方平台、不保证不间断。遇到在线电台播不出来，先怀疑服务端而不是设备——换蓝牙或本地播放验证设备本身是否正常即可。
