## 一、权限类问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 打开应用，菜单全是灰的、点不动 | Shizuku 没运行，或没给 ShizuTools 授权 | 按 [Shizuku配对与启动教程.md](Shizuku配对与启动教程.md) 把服务启动；重开 ShizuTools 让授权弹窗再弹一次，选允许 |
| 昨天还好用，今天全灰了 | 手机重启过，无线调试方式的服务不会自己回来 | 重新点一次 Shizuku 的「启动」即可，配对不用重做 |
| Shizuku 显示正在运行，但时好时坏 | 后台被电池优化杀掉 | 「设置 → 应用 → Shizuku → 电池」改为不限制 / 不优化 |
| 无线调试配对一直卡在「正在搜索配对服务」 | Shizuku 切后台后失去本地网络权限 | 允许 Shizuku 后台运行与后台联网，再重试配对 |

## 二、音量相关

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| SoundMaster 停止后，某些应用彻底没声音 | 中途被关机 / 更新打断，静音状态残留 | 打开 **MixedAudio 菜单**，把对应应用的静音关掉（官方指定的恢复方式） |
| 某个应用在 SoundMaster 里调音量没反应 | 版权保护强的应用不走普通音频通道（官方举例 Spotify 这一类） | 该应用只能用系统音量，属于已知限制 |
| 小窗里看视频觉得声音慢半拍 | SoundMaster 运行时有 20~50 毫秒固有延迟 | 官方口径是正常现象；对延迟敏感的场景先停止 SoundMaster |
| 关机 / 更新前忘了停止 SoundMaster | 同上，受控应用可能被静音 | 预防：更新、关机前先点停止；出事按第一行处理 |

## 三、画中画相关

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点了 UniversalPip 通知没反应 | 当时开着录屏 / 投屏，或 Shizuku 已停 | 停掉录屏；确认服务运行（[Shizuku配对与启动教程.md](Shizuku配对与启动教程.md)） |
| 小窗关不掉、找不到全屏按钮 | 控制菜单够不到 | 开发者选项 →「模拟辅助显示设备」先改别的值再改回**无**；或执行 `adb shell settings put global overlay_display_devices null` |
| 小窗里触摸操作不灵 | 小窗与主屏是两块显示区域 | 用通知在主屏底部弹出的控制菜单操作，别直接戳小窗 |

## 四、功能本身用不了

| 现象 | 结论 |
| --- | --- |
| LookBack 降级总是失败 | 官方 README 明确写着 **does not work on all devices**（并非所有设备可用），换台机器可能就行，这不是你操作错了 |
| IntentShell 的命令执行不了 | 命令里的 `key` 必须是应用内那串 32 位十六进制密钥（每台设备唯一）；**连续用错会把所有命令锁定 5 分钟**，这是防穷举的设计，等 5 分钟再试 |
| 某个菜单点了报错 | 先确认 Shizuku 运行、再看报错文本里的关键词；本地手敲命令可以走 **LocalShell** 菜单复现同一条命令，验证是权限问题还是命令本身的问题 |

## 五、版本核对

装的版本和文档对不上时，以你手里的包为准：网盘里那份安装包的档案是 **1.4.6 / `com.legendsayantan.adbtools` / 5.33M / MD5 `F507EC9E8A78E56709498AB235482981`**（截至 2026-09-23），核对办法见 [下载与安装教程.md](下载与安装教程.md) 第五节。官方发布页的版本号以 [github.com/legendsayantan/ShizuTools/releases](https://github.com/legendsayantan/ShizuTools/releases/latest) 当时显示为准，它会随开发进度往前走；两边对不上时，以你手里包的实际档案为准。

动手前的安装与授权问题集中在 [下载与安装教程.md](下载与安装教程.md)；删系统应用的取舍看 [卸载系统预装软件教程.md](卸载系统预装软件教程.md)；音量与画中画的完整用法分别在 [多应用同时发声与独立音量控制.md](多应用同时发声与独立音量控制.md) 和 [强制开启画中画模式.md](强制开启画中画模式.md)。
