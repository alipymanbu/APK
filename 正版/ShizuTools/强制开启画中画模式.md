# 给任意应用强制开启画中画模式教程

> 有些应用不允许小窗悬浮，UniversalPip 菜单不依赖应用自己那套开关，照样把它塞进一个悬浮窗里。

## 一、它解决什么问题

部分应用（比如一些视频、地图类应用）开发者侧就没开画中画权限，你在系统设置里找不到开关。UniversalPip 不改应用本身，而是给它套一个可悬浮的窗口，从而实现「一边刷别的、一边看小窗」。

前提照旧：Shizuku 正在运行（见 [Shizuku配对与启动教程.md](Shizuku配对与启动教程.md)）。

## 二、使用步骤

1. 点 ShizuTools 里的 UniversalPip 菜单，状态栏会常驻一条新通知 —— 这条通知就是开关。
2. 打开你想小窗的应用，开始播放或停在你要的画面上。
3. 下拉通知栏点这条通知，**注意先把通知栏收干净再点**，几秒内应用会被挪进一个悬浮小窗。

## 三、运行中怎么控制

应用跑在小窗里之后，直接触摸它并不总是灵（它和主屏是两块显示区域）。官方的通知菜单会在**主屏幕底部**弹出一排控件，常用的有：

- 常用媒体控制键（播放/暂停等）；
- **全屏按钮** —— 退出小窗、把应用还原回正常显示，就靠它。

## 四、打不开、关不掉时的兜底

| 现象 | 处理 |
| --- | --- |
| 点了通知没反应 | 先确认 Shizuku 在运行；确认当时没有正在录屏（见第五节） |
| 控制菜单里的全屏按钮点不到 | 开发者选项 →「模拟辅助显示设备」→ 先改成别的值，再改回**无（None）**，小窗随之关闭 |
| 上面那条也不方便操作 | 连电脑执行一条命令关闭：`adb shell settings put global overlay_display_devices null` |

第二条路依赖系统自带的「开发者选项」，你前面配 Shizuku 时已经把它打开了（见 [Shizuku配对与启动教程.md](Shizuku配对与启动教程.md) 第三节）。

## 五、两个已知注意事项

- **开着录屏、投屏这类功能时，小窗表现会不正常**（官方 wiki 明确提示）。要小窗就先把录屏停掉。
- 官方在 README 里给这个功能留了一句替代方案：作者自己的另一个项目 Extendroid（[github.com/legendsayantan/Extendroid](https://github.com/legendsayantan/Extendroid)）对画中画场景做得更好，可以对比后取舍。

小窗相关的异常（窗口不消失、画面黑屏）汇总在 [常见问题与报错排查.md](常见问题与报错排查.md)；顺手把独立音量也配上，小窗视频和后台音乐各响各的，见 [多应用同时发声与独立音量控制.md](多应用同时发声与独立音量控制.md)。
