## 一、这是什么，装之前先知道

ShizuTools 是一个把 ADB 级别的系统操作做成菜单的安卓工具集，作者在 GitHub 上以 GPL-3.0 协议开源（仓库 [legendsayantan/ShizuTools](https://github.com/legendsayantan/ShizuTools)）。它自己没有特权，**必须搭配 Shizuku 才能工作** —— 手机上没装 Shizuku、或者 Shizuku 服务没启动，打开它基本什么都做不了。

装之前确认三件事：

| 前提 | 说明 |
| --- | --- |
| 安卓系统 | 官方仓库的 `minSdk` 为 27，即 **Android 8.1 及以上**（版本号同样标注 1.4.6，与网盘那份一致）；部分功能还有更高门槛，见下表 |
| Shizuku 已安装且在运行 | 免电脑启动 Shizuku 需要 **Android 11+** 的无线调试；Android 10 及以下要连电脑 |
| 不需要 root | 全程走 Shizuku 的 ADB 通道，不解锁 bootloader、不刷机 |

各功能的系统门槛（来自官方 README 与 wiki，截至 2026-09）：

| 功能 | 系统要求 |
| --- | --- |
| 卸载预装应用（Debloater）、画中画（UniversalPip） | 随 Shizuku 通道可用即可 |
| 独立音量控制（SoundMaster） | Android 10 及以上 |
| 无线调试启动 Shizuku | Android 11 及以上 |

## 二、拿到安装包

两条路，任选一条：

1. **网盘**：[ShizuTools 安装文件资源（夸克网盘）](https://pan.quark.cn/s/436b57ffbc12) —— 里面是整理好的 APK，转存后下载即可。
2. **官方发布页**：[github.com/legendsayantan/ShizuTools/releases/latest](https://github.com/legendsayantan/ShizuTools/releases/latest) —— 有 Release 构建与仓库内的 Dev 构建两种。

两者的版本号可能对不上：**网盘里这份是 1.4.6**，官方发布页会随开发进度更新。只想稳定用，装哪份都行，装完用第五节的清单核对一下你手里到底是哪个版本。

## 三、安装步骤

1. 在手机上打开下载好的 `.apk`。
2. 系统会问「是否允许安装来自此来源的应用」—— 安卓对非应用商店渠道统一有这个开关，按提示给浏览器或文件管理器授一次即可。
3. 装完先别急着打开，先把 Shizuku 弄到运行状态（见 [Shizuku配对与启动教程.md](Shizuku配对与启动教程.md)），否则打开也只是一屏灰色菜单。

## 四、首次启动：把权限授给它

1. 打开 Shizuku，确认状态是「正在运行」。
2. 再打开 ShizuTools，系统会弹出 Shizuku 的授权请求，**选允许**。
3. 回到 ShizuTools 主界面，菜单从灰色变成可点，就说明通了。

之后每次重启手机，如果 Shizuku 服务停了，ShizuTools 这边会跟着失效 —— 这不是应用坏了，重新把 Shizuku 启起来即可，步骤见 [Shizuku配对与启动教程.md](Shizuku配对与启动教程.md)。

校验 MD5 的办法：在电脑上用 `certutil -hashfile 文件名.apk MD5`（Windows）算一遍，和上表对得上，说明下载过程中没有损坏。包名也可以在手机的「设置 → 应用信息」里核对，认准 `com.legendsayantan.adbtools`。

## 六、装完能干什么

主界面是一排功能菜单，常用的几个：

- **Debloater**：卸载系统预装与臃肿应用，用法见 [卸载系统预装软件教程.md](卸载系统预装软件教程.md)；
- **MixedAudio / SoundMaster**：多个应用同时出声、按应用独立调音量，见 [多应用同时发声与独立音量控制.md](多应用同时发声与独立音量控制.md)；
- **UniversalPip**：给不允许画中画的应用强制开画中画，见 [强制开启画中画模式.md](强制开启画中画模式.md)；
- **LookBack**：免卸载给应用降级，官方注明并非所有设备可用；
- **LocalShell**：手动敲一条 ADB 命令的输入框。

遇到点了没反应、报错、功能灰掉，直接翻 [常见问题与报错排查.md](常见问题与报错排查.md)。
