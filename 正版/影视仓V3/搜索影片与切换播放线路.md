## 一、配置成功后你面对的界面

首页展示的是**当前接口给你的分类**（电影、剧集、综艺、动漫之类，具体栏目由接口决定，不同接口长得不一样），顶部或侧边有搜索入口。你看到的片源清单不是软件内置的，而是你填的那条接口带过来的 —— 换一条接口，首页就换一批内容。

还没配接口的先看 [配置接口地址教程.md](配置接口地址教程.md)。

## 二、搜索与打开一部片

1. 在搜索框输入片名（用遥控器的拼音/笔画输入，或按提示用手机扫码在手机端输入）。
2. 结果列表里点进你想要的那一部，详情页会显示影片信息与剧集列表。
3. 选集数直接按确认键即开始播放。

同一部片在你当前接口里可能有多个来源：进入播放时会弹出可用的视频源列表，**点一个就开始播 —— 这就是「切换线路」**。哪个源画质好、哪个源稳，接口之间差别很大，选片时多看几个源是正常操作。

## 三、播放中你能调什么

播放界面按下确认键（OK 键）一般会呼出控制条，常见可调项：

| 操作 | 说明 |
| --- | --- |
| 切换解析线路 | 当前源卡了、黑屏了就切到另一条，这是最常用的一招 |
| 倍速播放 | 加速或减速，各版本支持档位不同，以界面显示为准 |
| 跳过片头片尾 | 追剧时省掉每集重复的开头结尾 |
| 加载本地字幕 | 接口没带字幕时，可指定设备里的字幕文件（`.srt` / `.ass`，与视频同名放一起最容易被识别）；没出来怎么排，见 [常见问题与解决方法.md](常见问题与解决方法.md) |
| 全屏 / 画面比例 | 画面被拉伸时在这里调 |
| 看分辨率、缓冲速度 | 画面信息里能看到当前清晰度与缓冲速度，用来判断是片源慢还是你家网络慢 |

各版本菜单名称与摆放位置略有差异，以你屏幕上的实际选项为准；本表列的是这类壳软件通用的能力。

## 四、电视直播

**接口里如果带了直播源**，界面上会有直播入口，进去就是电视台列表，用法跟点播一样直接选台。直播源和点播源是两种不同的地址：直播不工作而点播正常，说明问题出在直播接口上，去 [配置接口地址教程.md](配置接口地址教程.md) 第三节换一条直播接口即可。

## 五、播不出来时的判断顺序

按这个顺序走一遍，能覆盖大多数情况：

1. **这一部播不了** → 换一条线路（片源列表里再点一个源）。
2. **有声音没画面 / 黑屏** → 还是换线路，通常某条源的编码你的设备解不了，换一条就正常。
3. **这一部所有源都不行** → 换一部试；能播说明只是那部片的源坏了。
4. **所有片都播不了** → 问题不在播放，回 [配置接口地址教程.md](配置接口地址教程.md) 检查地址是不是失效了。

更细的现象对照在 [常见问题与解决方法.md](常见问题与解决方法.md)。
