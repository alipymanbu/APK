## 一、接口相关

**配置地址后提示读取失败、首页一片空白**
九成是地址本身的问题：要么已失效，要么粘贴时带了空格、少复制了字符。先用手机或电脑浏览器打开这条地址 —— 能返回一段文本说明地址活着，是软件侧没读对，重新干净地复制一遍再填；打不开就直接换一条地址，接口失效是常态，不用怀疑软件坏了。整套重填流程见 [配置接口地址教程.md](配置接口地址教程.md)。

**前几天还好用，今天突然没内容了**
接口由第三方个人维护，地址换域名、停更都很常见。重新获取最新地址覆盖旧的即可，你手里存的备用地址这时候用。

**地址读进去了，但首页只有仓库列表、没有片源**
接口类型填错了（多仓地址贴到了只认单仓的位置，或反过来）。对照 [配置接口地址教程.md](配置接口地址教程.md) 第三节的表格，换到正确入口重填。

**扫码推送连不上**
手机和电视/盒子必须在同一个 WiFi 下；确认连的是同一个路由器（一个 2.4G 一个 5G 也常被路由器隔开）、关掉路由器的「访客网络」隔离设置后重试。

## 二、安装相关

| 现象 | 处理 |
| --- | --- |
| 提示解析错误 / 无法解析安装包 | 先校验包是否下完整（28.23M、MD5 见 [下载与安装教程.md](下载与安装教程.md) 第二节）；完整仍报错说明这个包与该设备系统不兼容，换台设备试 |
| 提示签名不一致，装不上 | 设备上有同名或同类的旧应用，先卸载再装 |
| 安装按钮是灰的 | 去「设置 → 安全 / 账号与安全」打开未知来源安装权限，各品牌路径略有差异 |
| 安装时安全软件报毒提示 | 第三方分发的 apk 常触发这类提示；先确认下载来源可信（比对教程里那张表的 MD5），再自行决定是否继续安装 |

## 三、播放相关

**点开一部片黑屏 / 长时间无响应**
换一条线路再播 —— 同一部片往往有多个源，某个源挂了或编码太新都会这样。

**有声音、没画面**
设备解不了那条源的视频编码。优先换线路；换了几条都一样的话，选清晰度更低的源通常能绕开（老盒子解高码率更吃力）。

**卡顿、缓冲慢**
播放信息里能看到缓冲速度：速度一直很低多半是源站慢，换线路；速度正常但画面仍顿，查你家网络（有线连接通常比 WiFi 稳）。

**直播入口打不开 / 频道全是灰的**
直播接口失效了，和点播是两回事 —— 按 [配置接口地址教程.md](配置接口地址教程.md) 第三节换一条直播接口。

**整部片搜不到、或所有源都放不了**
先换一部验证软件本身还能不能播；能播就只是那部片的源坏了，不能播则回 [配置接口地址教程.md](配置接口地址教程.md) 检查地址。

## 四、运行相关

**打开就闪退 / 白屏**
依次试：重启设备 → 系统设置里清一次应用缓存 → 不行就清数据（接口地址会一并清掉，之后要重填）→ 还不行就卸载重装（安装包在 [影视仓V3 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a46a92d12124)）。

**第一次用本地接口文件时不让读**
应用要先拿到存储权限才能读你上传的接口文件：在设置里点「存储权限」授予后再操作，步骤见 [配置接口地址教程.md](配置接口地址教程.md) 第四节。

**想恢复到刚装好的干净状态**
系统「设置 → 应用 → 影视仓V3」里选「清除数据」，接口、观看记录、收藏会全部归零，重新配置即可。

**换了新接口后界面还是旧内容**
软件有本地缓存：清一次应用缓存再重新打开；仍不对就清数据后重填地址。
