## 一、这是什么应用

影视仓是安卓平台上的一类播放器「壳」，由 TVBox 开源项目（GitHub 上的开源代码）改出来的各个分支之一。你要先明白它的工作方式：**装好后它本身不带片源**，界面是空的，你得再填一个「接口地址」才会出内容 —— 所以装完的第一件事不是找片，是配置接口，那部分在 [配置接口地址教程.md](配置接口地址教程.md) 里讲。

它能装的设备很广：智能电视、机顶盒、投影仪、平板、手机，只要是安卓系统都可以试。本篇只讲把安装包装上去，装好之后怎么找片、怎么换线路，见 [搜索影片与切换播放线路.md](搜索影片与切换播放线路.md)。

## 二、本篇用到的这份安装包

网盘里存的是**当时整理的那一版**，第三方下载站上挂的常常是别的版本。你在网盘里拿到的这一份事实如下：

| 项目 | 值 |
| --- | --- |
| 版本号 | 3.0.36 |
| 包名 | com.mygithub0.tvbox0.osd_kitkat |
| 安装包大小 | 28.23M |
| MD5 | `5ca7d7d4247466df58e3d6654a7566e7` |
| 信息核对日期 | 2026-09-21 |

第三方下载站页面上能看到 3.0.35、6.1.6 等其它版本号，那是各家渠道自己的更新进度，与网盘这份无关；**你装的是哪一版，以本表为准**。想核对文件有没有下完整，比对 MD5 即可（Windows 上用 `certutil -hashfile 文件名.apk MD5` 算一遍，和上表逐位对照）。

包名尾段的 `kitkat` 一般理解为这是一份面向安卓 4.4（KitKat）这类老系统的兼容构建 —— 这是从命名推测的常见理解，未见官方说明，你的设备表现以实际安装结果为准。

## 三、获取与安装步骤

1. 打开 [影视仓V3 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a46a92d12124)，把应用文件夹转存到自己的网盘；文件夹里除了安装包，还有一份防止分享失效的说明文本，一并留着即可。
2. 把 `影视仓V3_v3.0.36.apk` 下载到 U 盘（或先下到手机、电脑再传过去）。28.23M 的包，网络正常时很快；下完如果校验 MD5，应与上表一致。
3. U 盘插进电视或盒子的 USB 口，打开设备自带的「文件管理」，找到这个 apk 按确认键开始安装。
4. 若系统弹出「不允许安装来自此来源的应用」或安装按钮是灰的，这是未知来源安装的常规拦截：按提示进入授权开关（不同品牌位置略有差异，常见在「设置 → 安全 / 账号与安全」里）打开后再装一次。
5. 装完在「全部应用」或「应用中心」里找它的图标打开。首次打开界面是空的属正常 —— 它是空壳，下一步去填接口，见 [配置接口地址教程.md](配置接口地址教程.md)。

## 四、装不进去时先看这三条

下面三种提示最常见，先在这里对号入座，完整的排查在 [常见问题与解决方法.md](常见问题与解决方法.md)：

| 你看到的提示 | 多半是什么原因 |
| --- | --- |
| 解析错误 / 无法解析安装包 | 包没下完整（先校验 MD5），或系统版本与这个包不兼容 |
| 由于签名不一致无法安装 | 设备上已有同名或同类应用，先卸载旧的再装 |
| 安装按钮灰色点不动 | 未知来源权限没开，按上面第 4 步的路径打开 |

## 五、系统要求与兼容注意

- 只有安卓安装包，iOS 设备装不了。
- 有第三方测试者记录过：一台安卓 4.4.2 的老盒子上，影视仓 3.0.35 可正常安装并运行，同设备装 5.0 版本却提示无法解析安装包 —— V3 这条线对老系统相对友好。**这是别人的实测记录，你的设备以实际为准。**
- 安装包 28.23M，装进去之后加上接口缓存还会再占一些空间；接口数据出问题时清一次应用数据即可，见 [常见问题与解决方法.md](常见问题与解决方法.md) 的运行相关那一节。

装好之后，从 [配置接口地址教程.md](配置接口地址教程.md) 开始用；配置成功后怎么找片、怎么换线路，见 [搜索影片与切换播放线路.md](搜索影片与切换播放线路.md)。
