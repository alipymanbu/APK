# 安装包解析失败怎么办

## 一、你看到的是哪一种提示

同一个根因，各品牌电视措辞不一样，先对号入座：

| 提示原文 | 多半指向 |
| --- | --- |
| 解析程序包时出现问题 / 解析包出错 | 文件不完整，或这个包与系统版本不兼容 |
| 应用未安装 / 软件包似乎已损坏 | 文件在下载或拷贝过程中损坏 |
| 此应用与您的设备不兼容 | 系统版本低于这个包的要求 |
| 安装失败、错误代码（如 INSTALL_FAILED 字样） | 签名冲突、空间不足或 CPU 架构不匹配 |

排查从最常见的原因开始，一步步来，多数情况走到第三步就好了。

## 二、逐条排查

1. **重新拷一遍**。用 U 盘中转时最常见的就是拷贝中断、U 盘本身有坏块。把 apk 删掉重新复制一次；手头的 U 盘老出问题，就先格式化成 **FAT32** 再拷（老电视基本都认这个格式；格式化会清空 U 盘数据，先把别的文件备份走）。
2. **校验文件完整**。核对大小是否为 28.23M、MD5 是否与 [下载与安装教程.md](下载与安装教程.md) 第二节那张表一致；对不上说明文件本身坏了，回网盘重新下载一次。
3. **检查设备存储空间**。电视自带存储常被系统与预装应用占满，先在系统设置里清理出几百 MB 空余再装。
4. **看系统版本**。这个包要求的最低安卓版本高于你设备的系统时，怎么装都报错。老盒子尤其如此 —— [下载与安装教程.md](下载与安装教程.md) 第五节记录过一条实测：安卓 4.4.2 的设备装 V3 这条线没问题，装更高版本线的包就解析失败。
5. **换一条安装途径**。U 盘这条路走不通就换：先把 apk 装进手机验证包是好的（能装说明文件没问题，问题在电视那头）；再用电视端应用市场的「远程推送」功能，手机连同一个 WiFi 上传安装包，绕开 U 盘这个变量。
6. **设备本身限制**。部分品牌出于政策要求限制了第三方应用安装入口（表现为按钮灰色、点了没反应、只允许从自家商店装），去「设置 → 安全 / 账号与安全」确认未知来源开关是否打开、有无品牌自己的安装限制开关。

## 三、装上了但打不开

- 提示**签名不一致**：设备上有同名或同类旧应用，先卸载再装新的，见 [常见问题与解决方法.md](常见问题与解决方法.md)。
- 打开就闪退、白屏：按 [常见问题与解决方法.md](常见问题与解决方法.md) 运行相关那一节处理（重启 → 清缓存 → 清数据 → 重装）。

装好之后别忘了它是空壳，第一步是填接口：[配置接口地址教程.md](配置接口地址教程.md)。
