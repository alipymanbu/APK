## 一、这套环境一共几层

JsXposedPro 首页那张「LSPosed」状态卡，背后其实是一整条链。任何一层缺了，这张卡都亮不起来：

| 层 | 作用 | 缺了会怎样 |
| --- | --- | --- |
| Root（Magisk / KernelSU / APatch 等） | 一切的前提 | 首页「Root」卡不亮 |
| Zygisk | 框架的注入环境 | 框架刷了也不生效 |
| LSPosed（现已更名 Vector） | 模块的加载框架 | 没有管理器可用，模块卡不亮 |
| JsXposedPro（作为模块启用） | 你要用的工具本身 | 启用前功能无处生效 |
| 目标应用（勾进作用域） | 生效对象 | 勾谁才对谁起作用 |

先装 JsXposedPro 本体再搭环境也行，顺序不影响结果；两条线都齐了，回 [激活与环境准备.md](激活与环境准备.md) 对一遍状态卡即可。

## 二、搭环境四步

1. **Root**：手机已 Root 的直接跳过。没有的话先解决 Root（Magisk、KernelSU、APatch 都是常见方案，选哪个取决于机型与系统），本篇不展开。
2. **打开 Zygisk**：用 Magisk 的，在 Magisk 设置里打开 Zygisk 开关然后重启；用 KernelSU 或 APatch 的，本身不带 Zygisk，需要另装一个 Zygisk 实现模块（如 Zygisk Next），以你所用 Root 方案的说明为准。
3. **刷入框架**：从框架的官方发布页下载 zip 包，在 Magisk / KernelSU 的「模块」页刷入，按提示重启。
4. **启用模块**：框架起来后打开它的管理器，在「模块」列表里启用 JsXposedPro，并把要调试的目标应用勾进作用域。

一个容易踩的点：Zygisk 是在开机早期注入的，刚刷完框架的那次重启里它往往还没真正生效——**再重启一次**是常规操作，不是折腾你。

## 三、关于「LSPosed 改名 Vector」

截至 2026-09 整理本文时，LSPosed 项目已更名为 **Vector**（由 JingMatrix 维护，发布页 [github.com/JingMatrix/Vector](https://github.com/JingMatrix/Vector)），支持 Android 8.1 起的新系统，旧 Xposed 模块（包括 JsXposedPro 这类）照常兼容。网上教程两种叫法都有，指的都是同一条脉络；下载时认准官方发布页，具体版本与支持范围以发布页为准。

## 四、框架层排查

状态卡不亮、模块没动静时，先分清是「框架层」还是「应用层」的问题。应用层的排查（作用域、强停重开、看日志）见 [常见问题解答.md](常见问题解答.md)，这里只管框架本身：

- **管理器打开了，模块列表却是空的**——多半是框架没真正起来。回 Magisk 确认 Zygisk 一栏显示已启用，再重启一次手机。
- **刷入后通知栏没有出现框架的持久通知**——同上，基本是 Zygisk 没生效或刷入的包不对，核对包的版本与你的 Root 方案匹配后重刷。
- **改了作用域但不重启**——作用域变更要在目标应用重启后才生效；整机重启是最稳妥的确认方式。
- **开机卡住（反复重启 / 卡 logo）**——用你 Root 方案提供的模块管理途径临时停用框架或出问题的模块再开机，动手排查前先备份数据。

环境搭完、JsXposedPro 也启用后，回 [激活与环境准备.md](激活与环境准备.md) 确认状态卡，然后就能进 [新增应用与快捷菜单.md](新增应用与快捷菜单.md) 把目标应用挂进来了。
