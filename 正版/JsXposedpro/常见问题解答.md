## 一、安装相关

**安装时提示「解析包错误」或安装失败**

1. 先核对安装包完整性：MD5 是否与 [下载与安装教程.md](下载与安装教程.md) 表格里的值一致，不一致就重新下载；
2. 再看系统与架构：打开 JsXposedPro（或系统设置）确认你的系统版本与 CPU 架构，个别老系统或非常见架构的设备会出现装不上的情况；
3. 存储空间不足也会安装失败，清理后再试。

**从哪里重新获取安装包**

从 [JsXposedPro 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d2a89a724435) 转存后下载即可，版本与 MD5 信息见下载教程里的表格。

## 二、首页状态卡不亮

**「Root」显示未获取**

手机没有 Root，或 Root 管理器没有给 JsXposedPro 授权。先完成 Root；之后打开 JsXposedPro 时留意是否弹出了 Root 授权请求，别手滑点了拒绝。

**「LSPosed」显示未激活**

框架本身还没装好或没起来的，先去 [LSPosed环境搭建与模块排查.md](LSPosed环境搭建与模块排查.md) 把环境搭完，再按顺序查：

1. LSPosed 框架本体装好了吗（管理器能正常打开）；
2. LSPosed「模块」列表里，JsXposedPro 的开关打开了吗；
3. 作用域里勾选目标应用了吗；
4. 按 LSPosed 的提示重启了吗。

四步都做完回首页再看，仍不亮就把手机重启一次确认。

**「Frida」显示未激活**

先把 Root 与 LSPosed 两项点亮，这一项依赖它们；仍不亮就翻应用内「求助」标签的内置教程，以首页实际显示为准。

**「AI」显示未激活**

进「设置」的 AI 配置完成 Key 配置（支持自动配置），配好回首页确认。

## 三、加了应用却没效果

按命中率从高到低排查：

1. **目标应用加进 JsXposedPro 了吗**——LSPosed 勾了作用域还不够，JsXposedPro 的「项目」里也要新增这个应用，见 [新增应用与快捷菜单.md](新增应用与快捷菜单.md)；
2. **两边勾的是同一个应用吗**——LSPosed 作用域与 JsXposedPro 项目里选的应用包名要一致；
3. **目标应用重启了吗**——拦截通常在应用启动时生效，把目标应用从最近任务里划掉（或用系统设置强停）再重开；
4. **日志里有记录吗**——到日志板块用关键词搜，一条记录都没有多半是前两步没做对。

前三步都确认无误、怀疑框架根本没把模块加载进去的，转到框架层排查：[LSPosed环境搭建与模块排查.md](LSPosed环境搭建与模块排查.md)。

另外，同一开关在不同应用上的效果本来就有差别：各应用的实现方式不同，个别功能对个别应用无效属正常现象，不是你操作错了。

## 四、别下错：名字相近的工具不是同一个软件

网上能搜到名字很像的几款工具（例如包名为 `com.jsxposed.x` 的一款），与本篇文档对应的 JsXposedPro **不是同一个软件**，功能与界面都有差别。认准包名：`com.wanfengyyds.jsxposedpro`，装之前在安装信息里看一眼包名最稳妥。

## 五、使用边界

只在你自己的设备上、对你有权调试的应用使用：自己开发中需要排查问题的 App、已获授权做测试的对象。对他人应用做未授权的修改可能违反法律与平台条款，这类用法不在本文档讨论范围内。
