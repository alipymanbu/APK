# JsXposedPro 激活与环境准备

> 本篇讲怎么把 JsXposedPro 首页的四张状态卡（AI、LSPosed、Frida、Root）逐一点亮，每张卡背后对应什么前置条件。

## 一、先看懂首页的四张状态卡

JsXposedPro 把环境是否就绪做成了首页最直观的四张状态卡，从上到下大致是：

| 状态项 | 点亮的含义 | 没点亮时先做什么 |
| --- | --- | --- |
| AI | 设置里的 AI 配置（Key）已完成 | 见本篇第三节 |
| LSPosed | 手机上装好 LSPosed，并在其中启用了本模块 | 见本篇第二节 |
| Frida | Frida 运行环境就绪 | 先保证 Root 与 LSPosed 两项已亮，再看内置「求助」教程 |
| Root | 手机已取得 Root 权限 | 先解决 Root，这是一切的前提 |

卡片上的文字与版本号会随软件版本变化，以你手机上实际显示为准。四张卡下面的设备信息面板（系统版本、SDK 版本、设备型号、CPU 架构、框架包名）是排查环境时的重要依据——确认系统适配、发帖求助都靠它，点右上角「复制」就能把整段信息带走。

## 二、Root 与 LSPosed：主体环境

**Root 是前提。** 没有取得 Root 时，首页会一直显示「未获取Root」，后面两项也不会亮。Root 的实现方式（Magisk、KernelSU 等）取决于你的机型与系统，本篇不展开 Root 教程；假设你的手机已经 Root 完成，再继续往下。

**LSPosed 负责让 JsXposedPro 挂进目标应用。**（该项目现已更名 Vector，手机上还没装框架的，搭建步骤见 [LSPosed环境搭建与模块排查.md](LSPosed环境搭建与模块排查.md)。）装好 LSPosed 后按这个顺序操作：

1. 打开 LSPosed 管理器，进入「模块」页。
2. 找到 JsXposedPro，打开它的开关（启用模块）。
3. 进入它的作用域设置，勾选你准备调试的目标应用。
4. 按 LSPosed 的提示重启系统或目标应用。

完成后回到 JsXposedPro 首页，看「LSPosed」这一项是否已经变成已激活。注意第 3 步勾选的目标应用，就是之后你在 JsXposedPro 里「新增应用」时能选到的范围，两边要一致，具体见 [新增应用与快捷菜单.md](新增应用与快捷菜单.md)。

**Frida 这张卡**对应其内置的 Frida 运行环境，是否点亮以首页实际显示为准。如果 Root 与 LSPosed 都已就绪、这一项仍未激活，先翻应用内「求助」标签里的内置教程，再考虑重启手机后重开应用确认。

## 三、AI 配置：最后一张卡

打开底部「设置」标签，进入 AI 配置，按界面提示完成配置即可（该版本支持自动配置 Key，不需要你手动填一长串参数）。配好之后回到首页，「AI」这张卡应显示已激活。

AI 激活与否不影响环境搭建，但会影响后续在项目里使用 AI 辅助分析相关的能力，建议一开工就先把它配好。

## 四、都点亮之后的核对单

动身去添加目标应用之前，对着首页过一遍：

- Root、LSPosed 两项已亮（Frida 以实际显示为准，AI 建议一并配好）；
- LSPosed 里 JsXposedPro 的作用域已勾选你要调试的应用；
- 设备信息面板里的系统版本与目标应用没有明显的版本冲突（比如目标应用对系统版本有要求）。

都齐了，就可以进 [新增应用与快捷菜单.md](新增应用与快捷菜单.md) 把目标应用正式挂进来了。
