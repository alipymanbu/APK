## 一、装之前先知道自己要装的是什么

JsXposedPro 是一款运行在安卓手机上的动态 Hook 调试工具，你可以把它理解为「给应用做调试的配套工具」：在不改动目标应用安装包的前提下，对目标应用的方法逻辑做拦截与调整，配合自带的 AI 辅助与日志功能来排查问题。

它的完整功能建立在 Root 与 LSPosed 框架环境之上。你可以先不 Root 直接安装、看看界面，但首页的状态卡不会点亮，调试类功能也用不了。环境的准备与激活步骤见 [激活与环境准备.md](激活与环境准备.md)。

## 二、获取安装文件资源

安装文件从网盘拿：转存 [JsXposedPro 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d2a89a724435) 到自己的网盘后，把 APK 下载到手机（或先下到电脑再传过去）。

这份安装包的实测信息如下（整理于 2026-09，若之后有新版，以你拿到的包为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 4.0.1 |
| 安装包大小 | 99.27 MB |
| 包名 | `com.wanfengyyds.jsxposedpro` |
| MD5 | `7e7bc902f51366a5f25017c28939c8c3` |

下载完建议核一下 MD5，确认包没有下坏。在电脑上用 PowerShell 执行（文件名换成你实际下载到的名字）：

```powershell
certutil -hashfile "JsXposedpro_v4.0.1.apk" MD5
```

输出的值与上表一致就没问题；不一致就重新下载一次，别硬装。

## 三、安装步骤

1. 在手机上点开下载好的 APK，系统弹出「是否安装」时点继续。
2. 首次安装第三方来源的应用时，系统会提示「不允许安装未知来源应用」，按提示允许「来自此来源的应用」安装（不同品牌的叫法略有差别，都在系统弹窗里能直接点）。
3. 等安装完成，桌面出现 JsXposedPro 图标。
4. 打开后是简体中文界面。

如果在这一步报「解析包错误」之类的问题，先回到上一节核对 MD5，再对照 [常见问题解答.md](常见问题解答.md) 里安装相关的条目排查。

## 四、第一次打开会看到什么

打开 JsXposedPro，底部固定五个标签：**项目、仓库、首页、求助、设置**。

- **首页**：最上面是应用名与四张状态卡（AI、LSPosed、Frida、Root），已点亮显示对勾、未点亮显示叉号，部分卡片下方还会带版本号；往下翻是设备信息面板，把系统版本、SDK 版本、设备型号、系统存储、CPU 架构、框架包名逐行列出，右上角有「复制」按钮，求助或核对环境时直接复制走。
- **项目**：管理你要调试的目标应用，右下角的「+」（选择APP）就是新增入口。
- **仓库**：脚本资源区，内容以你手上这个版本的实际显示为准。
- **求助**：内置教程入口，遇到不会的操作可以先翻这里。
- **设置**：AI 配置在这里完成。

刚装好时状态卡大概率全是「未激活 / 未获取」，这是正常现象——先把环境准备好，步骤在 [激活与环境准备.md](激活与环境准备.md)。
