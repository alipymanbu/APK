## 一、开始之前

FairEmail 只是个邮件客户端，不提供邮箱地址，你需要先有一个现成的邮箱账号。它用标准协议（IMAP/POP3 收信、SMTP 发信）连接几乎所有服务商，但**不支持微软的私有协议 Exchange Web Services 和 ActiveSync** —— 纯 Exchange 服务器的账号连不了；不过 Outlook.com、Office 365 这类提供 IMAP 的微软邮箱可以正常配。

先确认你的账号属于哪一类：

| 你用的邮箱 | 怎么配 |
| --- | --- |
| Gmail / Google Workspace | 选 Gmail (OAuth) 向导 |
| Outlook / Live / Hotmail / Office 365 | 选 Outlook (OAuth) 向导 |
| Yahoo / AOL / Sky | 选对应的 OAuth 向导 |
| QQ 邮箱、163、企业自建服务器等 | 选「其他提供商 (IMAP)」手动填 |
| 纯 Exchange（只开 EWS 的公司账号） | 配不了，换支持 Exchange 的客户端 |

POP3 也支持，但收信方式决定了它在多设备场景下的体验（邮件被拉走后其他设备就看不到了），能用 IMAP 就别用 POP3。

## 二、OAuth 授权登录（Gmail、Outlook、Yahoo）

1. 首次启动同意许可协议后进入快速设置向导；
2. 选带 (OAuth) 字样的入口，例如 Gmail (OAuth)、Outlook (OAuth)；
3. 输入邮箱地址后会跳到服务商的授权页面，登录并允许 FairEmail 访问；
4. 回到应用，服务器地址、端口、加密方式全部自动填好，点「保存」完成。

三个容易出错的点：

- 向导里若同时出现 Gmail (Android) 和 Gmail (OAuth) 两项，前者只能用手机上已登录的 Google 账号，想给 FairEmail 单独配一个账号选后者；
- Google 的「高级保护计划」（Advanced Protection）禁止第三方邮件应用接入，开着这个功能的账号配不了；
- OAuth 入口只存在于 Play 商店版和 GitHub 版，F-Droid 版没有（见 [下载与安装教程.md](下载与安装教程.md) 的渠道差异）。

## 三、其他服务商：手动 IMAP 配置

向导里没有你的服务商时，选「其他提供商 (IMAP)」：

1. 填显示名、邮箱地址和密码，点「检查」，FairEmail 会查询服务商的自动配置库，查到就直接保存；
2. 查不到会进手动设置，你需要准备四样东西：
   - IMAP 收信服务器地址与端口（常见 993，SSL/TLS）；
   - SMTP 发信服务器地址与端口（常见 465 配 SSL/TLS，或 587 配 STARTTLS）；
   - 用户名（多数服务商就是完整邮箱地址，个别只取 @ 前面的部分）；
   - 密码或应用专用密码；
3. 收信（账户）与发信（身份）是两个独立的配置项，都要填 —— 漏掉发信那半边，就只会收不会发。

具体参数去服务商帮助页搜「IMAP」基本都能找到，找不到就直接搜「服务商名 + IMAP 设置」。

手动配置时报「No connection / 无法连接」的，官方 FAQ 给了两条最常见的原因：一是主机名填错 —— 回「手动设置 → 账户选项」里逐字核对收发服务器主机名，错误提示里有时会直接写出正确主机名；二是证书透明度校验失败 —— 个别服务商的证书过不了这项校验，可在账户选项里关掉它再试（关掉会降低一层连接校验，确认服务商本身可信再做）。配好账号后收信时断时续，多半不是这里的问题，看 [后台同步与电池优化设置.md](后台同步与电池优化设置.md)。

## 四、两步验证与应用专用密码

不少服务商对第三方客户端不认登录密码，只认单独生成的「应用专用密码」或「授权码」，常见于：

- 开了两步验证的账号（Gmail 走 OAuth 不受此限，直接授权即可）；
- QQ 邮箱、163 等国内服务商，对任何第三方客户端都要求授权码；
- GMX、Web.de、Posteo 等国外服务商，以及部分服务商在你用 VPN、换网络时的临时要求；
- Apple iCloud：苹果要求第三方客户端一律用 App 专用密码（Apple 账号需先开两步验证），在 account.apple.com 的「登录与安全 → App 专用密码」里生成；注意改一次 Apple 账号主密码，所有专用密码会自动吊销，要重新生成再填。

生成入口一般在服务商网页版的「账户安全 / 授权管理 / POP3-IMAP 服务」里。生成后把这一串专用密码（而不是登录密码）填进 FairEmail。两个细节：复制粘贴时别把首尾空格带上；密码管理器自动填充偶尔会填成旧密码，报「认证失败」时先人工核对一遍输入框里的内容。

## 五、配好之后

- 一个 FairEmail 可以配多个账号、多个发信身份，数量没有限制；
- 配好的账号默认双向同步并保留离线副本，断网也能读已缓存的邮件、写好后自动补发；
- 收信频率、文件夹同步范围、通知方式都在账号设置里逐项调，改完不生效的问题翻 [常见问题与解决方法.md](常见问题与解决方法.md)。

日常怎么用（统一收件箱、会话整理、写信）见 [收发邮件使用指南.md](收发邮件使用指南.md)。
