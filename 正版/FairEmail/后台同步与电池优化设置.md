# 后台同步与电池优化设置

> 本篇专讲 FairEmail 收不到新邮件的头号原因：安卓系统或手机品牌把它的后台同步杀了。按品牌给出具体放行路径，以及设置完仍会失效的几个坑。

## 一、为什么偏偏是邮件应用被杀

FairEmail 靠一个常驻前台服务与服务器保持长连接来推送新邮件，这意味着它要 7×24 小时活在后台 —— 正好撞在厂商电池管理的枪口上。原生 Android 的限制相对温和（深度休眠、自适应电池），但三星、小米、华为等厂商在系统里另加了一层更激进的休眠策略：应用几天不打开就可能被休眠甚至冻结。邮件、聊天这类「要随时收消息」的应用是最大受害者。

FairEmail 安装后会主动请求「忽略电池优化」权限（官方声明的用途就是保障后台收信），弹窗出现时允许即可；但仅这一步在国产 ROM 上往往不够，还要按下面各品牌的路径再放行一次。

## 二、各品牌的放行路径

设置项的名称随系统版本变化，以下按常见叫法给，以你手机的实际界面为准：

| 品牌 / 系统 | 放行步骤 |
| --- | --- |
| 原生 Android（Pixel 等） | 设置 → 应用 → FairEmail → 电池 → 选「不受限制」 |
| 小米 / Redmi / POCO（MIUI、HyperOS） | 设置 → 应用管理 → FairEmail → 省电策略 → 无限制；再到手机管家 → 自启动管理里打开；最近任务界面下拉卡片加锁 |
| 华为 / 荣耀（EMUI、HarmonyOS） | 手机管家 → 应用启动管理 → FairEmail → 手动管理，打开「允许自启动 / 关联启动 / 后台活动」三开关；再到电池优化设置里把 FairEmail 设为不优化 |
| 三星（One UI） | 设置 → 电池 → 后台使用限制 → 把 FairEmail 移出「深度休眠应用」；应用详情 → 电池 → 选「未优化」 |
| OPPO / realme / 一加（ColorOS 系） | 设置 → 电池 → 找到 FairEmail 的耗电管理 → 允许后台运行；自启动管理里放行 |
| vivo / iQOO（Funtouch OS 系） | 设置 → 电池 → 后台功耗管理 → 允许后台高耗电；自启动管理里放行 |

两个通杀动作：关掉省电模式再观察；在最近任务界面把 FairEmail 卡片加锁，防止一键清理。

## 三、设置完还是被杀的坑

- **设置会被重置**：部分系统（尤其 MIUI 系）在重启或系统更新后重置应用的电池策略，收不到邮件时先回来复查一遍；
- **省电模式是总开关**：超级省电 / 低电模式下厂商会无视一切白名单，充上电或退出省电模式；
- **数据节省器**：安卓的数据节省器会限制后台流量，把 FairEmail 加进「不限制数据流量的应用」名单；
- **工作资料单独一套**：工作资料（双开/分身）里的应用受独立管理，别只改了主空间的设置。

## 四、确认同步是否真的在跑

1. 打开 FairEmail，下拉刷新收件箱，确认账号能正常收信（排除服务器一侧的问题，见 [账号配置与登录.md](账号配置与登录.md)）；
2. 回到桌面等 5~10 分钟，让朋友发一封测试邮件，看通知是否到达；
3. 打开应用后邮件才进来、关掉就断 —— 就是后台被杀，回到第二节按品牌重新放行；
4. 常驻通知还在但邮件不进来 —— 检查账号的同步条件（仅 Wi-Fi / 仅充电时同步），其余排查见 [常见问题与解决方法.md](常见问题与解决方法.md)。

照做一遍仍收不到，再把常见问题整篇过一遍，最后才考虑去官方支持页提问。
