## 一、默认就开着的防护

FairEmail 对邮件内容的默认处理比多数客户端保守，这些默认值建议保留：

| 默认行为 | 防的是什么 |
| --- | --- |
| 远程图片先确认再加载 | 借图片像素记录你何时何地读信 |
| 打开链接先确认 | 误点钓鱼链接 |
| 识别并禁用追踪图片 | 邮件营销常用的追踪像素 |
| 重排可疑邮件的排版 | 藏在排版里的伪装链接 |
| 显示发件人认证失败的警告 | 冒充熟人或机构的伪造邮件 |
| 安全视图（去掉脚本与不安全 HTML） | 恶意代码借邮件执行 |

## 二、权限与数据边界

- 权限要求少：收发邮件只靠网络权限；不给通讯录权限只是没法自动补全收件人；不给通知权限（Android 13 及以上安装时会问）就看不到新邮件提醒；
- 无广告、无内嵌分析统计，也不经任何第三方服务器中转 —— 邮件数据只存在于你的设备和你的邮箱服务商两端；
- 支持系统级的 Android 备份，是否启用、备份到哪由你在系统设置里决定；
- 隐私政策在官网 [email.faircode.eu](https://email.faircode.eu/) 有专门页面。

## 三、加密邮件（OpenPGP 与 S/MIME）

- 解密与验证签名：装 OpenKeychain 这类密钥管理应用后，FairEmail 可以解密 OpenPGP 加密邮件、验证数字签名；S/MIME 的解密与签名验证开箱即用，不需要额外应用；
- 用 S/MIME 给发出的邮件签名/加密属于 Pro 功能；
- 用 OpenPGP 发签名/加密邮件，需要配合 OpenKeychain 完成密钥选择，第一次使用会引导你安装。

## 四、应用锁与通知内容

- 生物识别 / PIN 锁（Pro）：开启后进入应用要过指纹或 PIN，手机借给别人看时邮件不会被顺手翻到；
- 锁屏上的通知内容可以在通知设置里收窄，少露正文预览；
- 想对信任的发件人放开「图片确认」：读信时在确认弹窗里选「始终显示此发件人的图片」，比全局关掉防护稳妥。

## 五、账号与授权的管理

- OAuth 授权的账号（Gmail、Outlook、Yahoo 等）：在服务商的账号安全页可以随时撤销 FairEmail 的访问权，撤销后应用里的该账号立即失效；
- IMAP 密码方式的账号：在服务商处改密码后，回 FairEmail 的账户设置里更新密码即可，不用删账号重配；
- 卸载应用会清掉本地的离线邮件缓存，服务器端数据不受影响。

默认设置已经偏严格，日常觉得「每次都要确认图片很烦」时，优先按发件人逐个放开，而不是全局关掉确认机制；安全类的选项改前先想清楚它当初防的是什么。
