## 一、收不到新邮件 / 同步停了

这是 FairEmail 被问得最多的问题，根源几乎都是安卓系统把它的后台「杀」了。按顺序查：

1. 看通知栏有没有那个低优先级常驻通知 —— 它是前台服务的标志，被划掉或被系统隐藏都可能导致同步异常；
2. 关掉对 FairEmail 的电池优化：系统设置 → 应用 → FairEmail → 电池 → 改为「不受限制 / 允许后台运行」（各品牌路径叫法不同，国产 ROM 还要在「自启动管理」里放行）；
3. 检查账号设置里的同步选项有没有被改过（比如限定只在 Wi-Fi 或充电时同步）；
4. 部分机型的省电模式会整体冻结后台同步，关掉省电模式或充电后再观察。

改完仍不行就重启一次手机，让前台服务重新拉起来。

小米、华为、三星、OPPO、vivo 各自的详细放行路径单独整理在 [后台同步与电池优化设置.md](后台同步与电池优化设置.md)，以及「设置完会被重置」「省电模式无视白名单」这些坑也在那篇里。

## 二、没有新邮件通知

- Android 13 及以上，安装时没授予通知权限的，去 系统设置 → 应用 → FairEmail → 通知 里打开；
- 每个账号用不同提示音、不同震动节奏属于 Pro 功能，免费版只有全局通知设置；
- 通知栏那个常驻通知去不掉，这是设计如此 —— 它没了，推送新邮件的机制就没了。

## 三、账号登录失败 / 认证错误

| 报错特征 | 先查什么 |
| --- | --- |
| 提示认证失败 | 用的是不是「应用专用密码/授权码」？两步验证或服务商强制要求时，登录密码进不去 |
| 复制粘贴后仍失败 | 密码首尾有没有带上空格；密码管理器是否自动填了旧密码 |
| OAuth 授权页报错 | Google「高级保护计划」开着时不允许第三方邮件客户端 |
| 服务器连不上 | 服务器地址、端口、加密方式（SSL/TLS 与 STARTTLS 别选反） |
| 能收不能发 | SMTP（身份）那半边配置漏填或填错 |

QQ 邮箱、163 这类国内服务商要的是「授权码」，不是网页版登录密码；生成入口见 [账号配置与登录.md](账号配置与登录.md)。

「服务器连不上 / No connection」再补两条官方 FAQ 的口径：先逐字核对服务器主机名（手动设置 → 账户选项），错误信息里有时会直接给出正确主机名；主机名没错的话，试试关掉账户选项里的证书透明度校验 —— 个别服务商的证书过不了这道校验。iCloud 用户先确认用的是 App 专用密码，改过 Apple 主密码的要重新生成一个。

## 四、邮件显示与附件

- 图片不显示：默认就是先确认再加载，属于防护行为；点确认，或选「始终显示此发件人的图片」；
- 排版乱了：可疑邮件会被重排防钓鱼，确信可信时从菜单选择按原始排版查看；
- 附件选不了 / 打不开：改用系统文件选择器，个别第三方文件管理器会静默取消选择，应用端只能收到「文件未选择」；
- 附件预览没有的格式：FairEmail 不内置 Office 等文档渲染，选「保存」后用相应应用打开。

## 五、存储、搜索与其他

- **应用占的存储慢慢变大**：离线邮件缓存存在本地，在账号/文件夹设置里限制本地保留的邮件时间范围（比如只留最近三个月）就能控制；
- **搜索结果不全**：默认搜索范围是已同步到本地的邮件，本地搜索索引属于 Pro 功能；把同步范围调大或翻服务器网页版找老邮件更直接；
- **换手机**：新机重装并重配账号即可，服务器上的邮件会重新同步下来，见 [下载与安装教程.md](下载与安装教程.md) 的换机段落；
- **官方支持**：FAQ 与提问入口在 [m66b.github.io/FairEmail](https://m66b.github.io/FairEmail/)，作者本人用多语言回复用户问题。

以上行为特征基于 1.2226 版本；应用更新频繁，个别设置项的名称与位置以你手上的版本界面为准。
