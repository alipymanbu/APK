## 一、先认识界面与那个常驻通知

FairEmail 刻意做得克制：左侧抽屉是账号与文件夹列表，主区域是邮件列表，点进一封是会话视图。它通过 IMAP IDLE 与服务器保持长连接，新邮件是推送到达的，不是隔几分钟轮询一次。为此它会在通知栏挂一个低优先级的常驻通知 —— 这是它在安卓上保住后台同步的方式。别嫌它碍眼：把它划掉或被系统隐藏，新邮件提醒就没了保障。

## 二、统一收件箱与多账号

- 配了多个账号后，默认所有账号的收件箱合并成一个统一收件箱；也可以在显示设置里改成按账号或按文件夹分开显示；
- 发件时在写信界面点发件人一栏，即可切换用哪个身份（发信地址）发出；
- 每个账号的草稿、已发送、垃圾箱都对应服务器上的真实文件夹，本地不会另造一套，在手机上删掉的邮件服务器上同步进垃圾箱；
- 想让点邮件链接直接进 FairEmail：系统设置 → 应用 → 默认应用 → 邮件应用 里选它（各品牌叫法略有差异），网页和聊天里的 mailto 链接就会跳过来。

新邮件收不到、时断时续，九成与账号无关而是后台被系统杀了，按品牌的处理见 [后台同步与电池优化设置.md](后台同步与电池优化设置.md)。

## 三、收到的邮件怎么整理

| 想做什么 | 怎么操作 |
| --- | --- |
| 归档 / 移动 | 长按或左滑调出操作，移进服务器上的目标文件夹 |
| 删除 | 右滑或菜单删除，默认进服务器垃圾箱 |
| 标记 / 加星 | 列表里点星标图标 |
| 展开会话 | 会话视图按线程折叠同一主题的往来邮件 |
| 搜索 | 顶部放大镜，默认在已同步到本地的邮件里找 |
| 批量处理 | 长按进入多选，批量已读、移动、删除 |

整理完发现列表还是乱，多数是同步范围太宽：在账号或文件夹设置里限制本地保留的邮件时间范围（比如只留最近三个月），列表和新邮件速度都会更跟手。

## 四、写邮件

1. 右下角按钮新写信件；收件人可以从通讯录选（首次要授权联系人权限，不给也能手输）；
2. 正文支持常用样式：字号、颜色、加粗、列表等；
3. 附件走系统文件选择器，选好后显示在正文下方；
4. 写一半退出去，草稿留在草稿箱，回来接着写。

断网也能写和发：操作先存本地，联网后自动送出。出差路上没信号时把要回的都写完，恢复网络一起发出去。

## 五、读邮件时那些「多一步」的设计

你大概率会碰到下面几个确认弹窗，它们是故意的防护，不是故障：

- 邮件里的远程图片默认不加载，点确认才显示 —— 防止发件人借图片像素记录你什么时候读了信；
- 点邮件里的链接先弹确认 —— 防钓鱼；
- 排版诡异的邮件被重新排版显示，藏起来的伪装链接会现形；
- 无法通过发件人认证的邮件带警告标识 —— 警惕冒充发件人的伪造邮件。

按自己的习惯调整这些行为（包括对信任的发件人放开图片），见 [隐私与安全设置.md](隐私与安全设置.md)。

## 六、和 Pro 版有关的日常功能

基础收发全部免费，下面这些属于付费 Pro 项，日常用到再考虑：每账号/文件夹的独立通知声音、消息贪睡（稍后提醒）、回复模板、定时发送、按规则自动归类、桌面邮件列表小部件、生物识别/PIN 锁。建议先用免费版把邮件收发跑顺，确认自己真的缺哪样再补哪样。
