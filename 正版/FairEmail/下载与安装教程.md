## 一、这份安装包的基本信息

FairEmail 是一款开源的安卓邮件客户端，由荷兰开发者 Marcel Bokhorst（FairCode）维护，源码以 GPL-3.0 协议公开在 GitHub 上。本文对应的安装包信息如下：

| 项目 | 内容 |
| --- | --- |
| 应用名称 | FairEmail |
| 版本 | 1.2226 |
| 包名 | eu.faircode.email |
| 安装包大小 | 27.32 MB |
| MD5 | 1AB93ACC29FD04A97E7755138E3F266A |

版本号、包名与大小以这份安装包为准。官方仍在持续更新（最新版本号可在官方发布页 [github.com/M66B/FairEmail/releases](https://github.com/M66B/FairEmail/releases) 查看），日常使用不必纠结新旧。

## 二、下载安装包

1. 打开 [FairEmail 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9296392663a5)，转存到自己网盘后下载，或直接下载 `FairEmail_v1.2226.apk`；
2. 下载完成后，用手机自带或第三方的文件管理器找到这个 apk 文件；
3. 想核对安装包是否完整，可以用带 MD5 校验功能的工具比对文件指纹，正确值见上表。

## 三、安装步骤

1. 在文件管理器里点开 apk，系统会提示「是否允许从此来源安装应用」，允许即可继续；
2. 安装完成后打开 FairEmail，首次启动会先弹出 GNU GPLv3 许可协议，点「同意」才能往下走（不同意就无法使用）；
3. 接着进入账号设置向导，怎么填见 [账号配置与登录.md](账号配置与登录.md)。

对系统版本有要求：近年官方版本的最低要求是 Android 6.0（旧版本或有不同，以官方发布页为准）。另外 FairEmail 是纯邮件客户端，不带邮箱地址，你需要先在某个邮箱服务商那里有账号。

## 四、官方还有哪些获取渠道

除了本文给的安装包，官方认可的途径还有：

- Google Play：访问 [play.google.com/store/apps/details?id=eu.faircode.email](https://play.google.com/store/apps/details?id=eu.faircode.email)；
- GitHub Releases：访问 [github.com/M66B/FairEmail/releases](https://github.com/M66B/FairEmail/releases)，在资产列表里展开下载 apk；
- F-Droid：访问 [f-droid.org/en/packages/eu.faircode.email](https://f-droid.org/en/packages/eu.faircode.email/)，注意 F-Droid 构建未获 Google 的 OAuth 审批，没有 Gmail/Outlook 的授权登录入口。

不同渠道的构建签名不一定相同：从 F-Droid 版换到 GitHub 版（或反过来）必须先卸载旧版再装新版，本地离线邮件会因此清空，动手前想清楚。

## 五、升级与换机

- GitHub 版更新最勤，且自带版本检查（可在杂项设置里关掉）；Play 商店版、F-Droid 版的更新节奏由各自商店决定；
- 同渠道升级直接覆盖安装，不用卸载；跨渠道升级先卸载（签名不同装不上）；
- 换新手机：重装后需要重新走一遍账号设置，服务器上的邮件会重新同步下来，本地的离线缓存不会跟着账号迁移。

装好后卡在某一步、或者收不到新邮件，直接翻 [常见问题与解决方法.md](常见问题与解决方法.md)。
