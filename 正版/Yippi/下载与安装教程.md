## 一、这份安装包是哪一版

Yippi 是一款把普通消息和秘密消息合在同一个应用里的社交聊天工具，包名 `com.toga.chat`。下面这几项是手头这份安装包的实测数据，装之前先跟手机上已有的版本对一下：

| 项目 | 值 |
| --- | --- |
| 版本号 | 7.0.27 |
| 包名 | `com.toga.chat` |
| 安装包大小 | 251.03M |
| MD5 | `88c033701d45341ea0d68db1aef46cdd` |
| 记录日期 | 2026-09-21 |

网上各应用商店能看到 7.0.30、7.0.33 等更新的版本号，那是官方后来推的版；**这一份就是 7.0.27**，两个版本号不是一回事，别拿网上的更新日志来对照这份包。

## 二、系统要求

- 这份安装包只适用于**安卓**（APK 格式）；iOS 端要在苹果应用商店另行下载，与这份包无关。
- 第三方商店页面把最低系统标为 **Android 8.1.0 及以上**（截至 2026-09 的页面显示，以实际安装提示为准）。系统低于这个版本时，安装器会直接报「解析包时出现问题」或「安装失败」。
- 安装后首次启动会陆续要相机、麦克风、相册、通讯录、位置这几项权限。按官方隐私政策的说法，这些权限**默认不启用**，只在你用到对应功能时才申请——你可以只放行当下要用的那几项。

### 权限与隐私：两处开关在哪

官方隐私政策（[yiartkeji.com](https://yiartkeji.com/zh-hans/privacy-policy-app/?lang=zh-hans)）里给了两条可直接操作的口径：

| 你想做的事 | 路径 |
| --- | --- |
| 关掉推送通知 | 应用内「设置」→「通知」，关闭对应推送开关；不登录账号时，推送走的是设备标识符 |
| 撤回已给的授权 | 系统设置 → 应用 → Yippi → 权限，逐项关闭；相机、麦克风、通讯录、相册、位置都在这里 |

政策同时写明：**即使你已授权，在不需要对应功能时也不会收集**；要彻底停用某项功能，撤权限比卸载更快，也随时能开回来。

## 三、下载与安装步骤

1. 从本篇头部的 **Yippi 安装文件资源（夸克网盘）**（[https://pan.quark.cn/s/189b2e8484f3](https://pan.quark.cn/s/189b2e8484f3)）转存并下载 APK 到手机，或先下到电脑再传到手机。
2. （可选）怕文件在传输中损坏，先在电脑上算一次 MD5：

```powershell
certutil -hashfile .\Yippi_v7.0.27.apk MD5
```

输出应为 `88c033701d45341ea0d68db1aef46cdd`；对不上就重新下载一次，别拿损坏的包去装。

3. 在手机文件管理器里找到这个 APK，点一下开始安装。
4. 系统如果弹出「禁止安装来自此来源的应用」，是拦截了未知来源安装——按提示进入设置，允许本次安装来源，再回到安装界面继续。
5. 装完先别急着登录，先看一眼 [停止服务后还能不能用.md](停止服务后还能不能用.md)：官方发过停服公告，登录能不能成是另一回事。

## 四、装不上怎么排查

按顺序试，每一步都可能直接解决，不必全做：

| 现象 | 先试这一条 |
| --- | --- |
| 「解析包时出现问题」 | 系统版本低于 Android 8.1.0，或 APK 没下完整；先校 MD5，再换台系统新一点的机器试 |
| 「存储空间不足」 | 安装包 251.03M，解压后占用更大；清理出 1GB 以上可用空间再装 |
| 「与已有应用签名不一致」 | 手机上装着别处下载的同包名应用；先卸载旧的再装（卸载前先确认聊天记录要不要留） |
| 点开 APK 没反应 | 部分文件管理器不接管安装；改用系统自带的「安装器」或在「下载」目录里再点一次 |
| 装完打不开、秒退 | 先重启手机，再清一次应用缓存；仍不行则卸载重装 |
| 权限弹窗被拒后功能不亮 | 进系统设置 → 应用 → Yippi → 权限，把相机、麦克风、存储按需打开 |

装好之后从 [加好友的几种方法.md](加好友的几种方法.md) 开始用。
