## 一、Yipps 是什么

按运营方壹艺科技官网（[yiartkeji.com](https://yiartkeji.com/)）的说法，**Yipps 是 Yippi 应用生态里的虚拟奖励积分**——不是现金，也不能提现成银行卡余额，只能在 Yippi 及其合作体系内抵扣消费。你在应用里看到的「Yipps」「积分」字样指的是同一个东西。

跟它相关还有两个容易混的词：

| 词 | 指什么 |
| --- | --- |
| Yipps | 上面说的奖励积分，用于抵扣与打赏 |
| Yipps Wanted（全城找 Yipps） | 线下商家的返积分活动平台，扫码消费拿积分 |
| 内容打赏 | 观众把 Yipps 打赏给动态作者、直播主、贴图设计师 |

## 二、攒到的 Yipps 能花在哪

运营方列出的用途覆盖日常开销，整理成表：

| 用途 | 说明 |
| --- | --- |
| 手机话费 | 用积分充值话费 |
| 水电费 | 缴纳每月水电账单 |
| TopzMall 线上购物 | 在该商城用积分抵扣 |
| TogaGo 订购 | 买火车票、订酒店住宿 |
| Rest N Go 按摩椅 | 线下服务消费抵扣 |
| Red Box 娱乐设施 | 娱乐场所消费抵扣 |
| 打赏 | 支持 Yippi 动态、直播主、贴图设计师 |

**这些抵扣项目能不能真的用，取决于合作方与活动是否还在跑**：上表来自运营方与活动页的公开说明（内容最早可追到 2021—2023 年的活动页面），具体规则以官方页面当时显示为准。

## 三、从哪攒得到 Yipps

公开材料里给出的获取途径有这么几条：

1. **内容收益**：你发的动态、开的直播收到观众打赏，拿到的就是 Yipps。
2. **线下消费返积分**：在「全城找 Yipps」合作商家付款时，向商家出示你的二维码让对方扫；线上下单则截图二维码发给商家。**你的二维码每 15 分钟刷新一次**，别拿很久之前的截图去扫。
3. **参与活动**：官方办过的玩法包括每日奖金池、消费赢奖等，参与方式与名额每次活动单独公布。
4. **推荐奖励**：推荐家人朋友注册，页面写明最高可得 150 Yipps，并在其后的消费返积分里拿 7% 的终身推荐奖励（活动页原文口径，具体以活动页为准）。
5. **成为内容创作者**：运营方把「加入成为内容创作者」列为获取更多 Yipps 的一条路径。

## 四、停服之后，积分怎么办

这条最重要：**Yipps 存在服务器侧，不是你手机里的文件**。按 [停止服务后还能不能用.md](停止服务后还能不能用.md) 里那份停服公告，服务器停止服务后，依赖网络的积分查询、抵扣、打赏一律连不上。

- 官方公告建议你抢救的是「个人媒体、回忆与重要信息」，**没有提到积分如何折算或退还**；查不到公开说法的事情，这里不替你猜。
- 若你还有未花掉的 Yipps，可按官方渠道（运营方官网 [yiartkeji.com](https://yiartkeji.com/)）的客服口径问一次；答复以对方给的为准。
- 积分记录如果只存在于应用内，清应用数据前先把能看到的页面截图留底——见 [停止服务后还能不能用.md](停止服务后还能不能用.md) 第三节。

想把应用装回手机核对积分页面，走 [下载与安装教程.md](下载与安装教程.md)；积分打赏的入口在会话与直播间里，对应 [秘密消息与白板怎么用.md](秘密消息与白板怎么用.md)。
