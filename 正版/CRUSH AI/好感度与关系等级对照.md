## 一、关系等级门槛表

你在每轮对话后的好感度变化由 AI 根据**对话内容 + 角色设定**自动调整，没有手动加点的入口。全部等级与所需魅力值（官方角色设定页数据）：

| 关系 | 魅力值要求 |
| --- | --- |
| 恋人 | 5000 |
| 倾心 | 2500 |
| 挚友 | 1200 |
| 熟识 | 50 |
| 陌生 | -50 |
| 厌恶 | -1200 |
| 反感 | -2500 |
| 敌人 | -5000 |
| 敌人 | -∞ |

（最后两行在官方原表里同名「敌人」，门槛一为 -5000、一为 -∞，此处照抄未改。）

几点读表须知：

- 门槛可正可负：好感度掉到负数不是「关系清零」，而是往厌恶、反感、敌人方向走，角色对你的态度会跟着变差；
- 顶格是「恋人」，升到顶后关系页面会显示已达最高关系等级；
- 关系提升后角色可能展露更多关心与不同的互动方式，但具体表现**按角色设定走** —— 同样的好感度，不同角色演出来不一样。

## 二、情绪与好感度是两套东西

好感度是长期的、可量化的等级；**角色情绪**是即时的，每轮对话后 AI 也可能调整（开心、难过、生气、兴奋等），影响下一条回复的语气与反应。所以你看到状态里情绪忽然变了、但关系等级没动，是正常现象，两者本来就不同步。

## 三、关系页面：这段对话的九个分页

在对话中点进角色的**关系区域**就打开这个页面（每角色、每段对话各自独立）。九个分页一览：

| 分页 | 你能做什么 |
| --- | --- |
| 封面 | 看在一起天数、角色当前心理状态（情绪/想法/意图/好感度变化）、对话相簿 |
| 人设 | 设定「我扮演…」，角色按这个人设称呼你、对待你；可随时切换人设换身份 |
| 对话统计 | 累计消息数、每日平均、连续天数 |
| 我们的距离 | 好感度与关系等级进度条，点「下一级」看完整等级表 |
| 魔法咒语 | 写持续生效的对话指令（口吻、篇幅、称呼、剧情方向） |
| 场景 | 切换/更换当前对话场景；你是创作者时还能管理场景 |
| 记忆事件 | 回忆时间轴：单独开关、长按拖动排序、手动新增 |
| 时光写真 | 随关系加深解锁的纪念写真；角色未开放 AI 生图时该页提示未开放 |
| 设定 | 对话名称、对话语言、记忆选项、回应格式新增 |

三个高频操作的细节：

- **魔法咒语**：写一次持续作用于这段对话，但 AI 有随机性，官方明说咒语无法保证每次效果一致 —— 想稳定就写得明确、分步、多试几次；
- **记忆事件**：「自动记忆事件」总开关与「重置对话」在设定分页；每则记忆还有独立开关，关掉后 AI 不再参考它；
- **重置对话是破坏性操作**：清除这段对话的记忆事件、关系与好感度，**无法恢复**。想留底就先把关键记忆事件手动记一份，或者干脆开新对话。

## 四、时光写真与对话相簿的边界

两处都会存 AI 生成的图片，但用途不同：**对话相簿**收的是这段对话里生成过的全部图片（封面页可进完整相簿）；**时光写真**是按关系等级解锁的模板化纪念写真，未解锁的显示上锁。角色若未开放 AI 生成或内容受限，时光写真页会直接提示尚未开放，这不是你的设置出了问题。

## 五、想让关系往哪边走，你能控制的是「说什么」

好感度由 AI 判定，你控制不了数值本身，但输入就是它的依据：对话内容与角色设定共同决定每轮加减。想升得快，聊的内容贴合角色的人设与动机（这些字段由创作者填写，见 [自定义角色创建字段教程.md](自定义角色创建字段教程.md)）；另外注意当前回应模式的记忆上限 —— 轻量模式只记 10 句、没有记忆总结，角色接不上你前面的铺垫时，别急着怪好感度系统，先看模式，对照见 [点数消耗与回应模式选择.md](点数消耗与回应模式选择.md)。
