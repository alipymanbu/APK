# Grayjay 添加视频源与订阅导入方法

> Grayjay 本身不带内容，视频全靠「源」（各平台的插件）。本篇讲怎么加源、怎么把你在各平台的订阅和播放列表搬进来、底栏标签怎么调。

## 一、装完第一步：去「Sources」页加源

刚装好的 Grayjay 首页基本是空的——它是聚合器，不托管任何视频，你得先把要看的平台插件打开。官方插件目录在 [plugins.grayjay.app](https://plugins.grayjay.app/)，收录的有（节选，截至 2026-09）：

| 源 | 说明 |
| --- | --- |
| YouTube | 主流视频平台 |
| BiliBili (CN) | 登录后可用更高画质、字幕与会员内容 |
| Twitch / Kick（Beta） | 直播平台，直播与聊天都支持 |
| Rumble / Odysee / PeerTube / Dailymotion（Beta）/ BitChute（Beta） | 其他视频站 |
| SoundCloud / Mixcloud（Alpha） | 音频为主 |
| Patreon / Nebula | 会员制平台，登录后免费与付费内容并排可见 |
| Apple Podcasts / Radio Browser（Alpha） | 播客与电台目录 |
| NASA+ / TED Talks / Curiosity Stream / FOSDEM / Internet Archive（Alpha） | 纪录片、讲座与资料库 |

添加方式有两种：

1. 在应用的「Sources」页用内置扫码器，扫插件页上的二维码；
2. 用手机浏览器打开插件页，点「Open in Grayjay」，会跳回应用装上该源。

某个特定的 PeerTube 实例要单独装：打开 [PeerTube Plugin Host](https://pluginhost.grayjay.app/peertube?url=https://peertube.futo.org)，填入实例地址后点「Open in Grayjay」，那个实例会作为一个插件装进来。

插件页上带 Alpha / Beta 标注的是成熟度标记：没标注的最稳，Beta 次之，Alpha 最早期，缺功能或失效的概率也最高。选源时看到这两个标记，预期放低一点；个别源质量参差、稳定性不一，是插件制应用的常态，坏了换源或更新插件即可（排查见 [常见问题与故障排查.md](常见问题与故障排查.md)）。

## 二、导入你在各平台的订阅

两种路子，按你有没有该平台账号选：

**路子 A：登录平台直接导入**

1. 到「Sources」页点开那个平台；
2. 登录你的账号；
3. 登录后出现「Import Subscriptions」按钮（该插件支持才有），点它把订阅名单搬进来。

**路子 B：从 NewPipe 搬**

1. 在 NewPipe 里把订阅导出成 JSON 文件；
2. 用手机上的文件浏览器（系统自带或第三方都行）打开这个 JSON，选 Grayjay 处理。

正在用 NewPipe、还在犹豫要不要换的，两边差异与适合人群的对比见 [与NewPipe的区别与选择.md](与NewPipe的区别与选择.md)。

播放列表同理：登录后在同一入口点「Import Playlists」（插件支持才有）。

导入完成后，所有平台的订阅会汇进一条**通用信息流**：按时间倒序排列，直播和已预约的直播置顶。订阅创作者时，存的是频道的元数据，位置在手机本地。

## 三、订阅标签去哪了

- 「Subscriptions（订阅）」标签在你至少订阅一个创作者之前**不显示**；
- 进「Settings → Manage Tabs」可以增删、排序底栏标签；
- 调过顺序后订阅标签可能被收进「More」，找不到先去「More」翻。

## 四、要不要登录各平台账号

Grayjay 默认不跟踪你，所以不登录时各平台不知道该给你推什么，首页推荐不带个性化。登录之后的变化：

- 拿到该平台给你的个性化推荐；
- 会员制平台（Patreon、Nebula 等）登录后才能看到你已付费的内容；
- BiliBili 登录后才有更高画质与字幕。

观看历史也存在手机本地。登录与不登录的取舍，配合首页现象的理解见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、源装好之后怎么搜

- 搜视频：首页或订阅页点搜索图标，结果跨所有已启用源；
- 搜创作者 / 播放列表：分别到 Creators、Playlists 页搜；
- 结果出来后点筛选按钮：可以单独关掉某个源的结果，也能用过滤条件继续收窄（关掉的源越多，可用的公共筛选条件越多）。

播放与后台设置见 [播放设置与投屏方法.md](播放设置与投屏方法.md)。
