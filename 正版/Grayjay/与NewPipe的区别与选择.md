# Grayjay 与 NewPipe 的区别与选择

> 两个都是「不装官方客户端也能看视频」的安卓应用，经常被拿来比较。本篇只摆差异和各自适合的情况，选哪个由你的使用方式定。

## 一、核心差异一张表

| 维度 | Grayjay | NewPipe |
| --- | --- | --- |
| 平台范围 | 插件制：YouTube、Twitch、PeerTube、Rumble、Odysee、BiliBili (CN)、Patreon、Nebula 等十多个源 | 内置支持 YouTube、PeerTube、SoundCloud、Bandcamp、media.ccc.de 等 |
| 平台账号登录 | 支持，登录后拿个性化推荐、看已付费的会员内容 | 不支持登录，一切数据本地化 |
| 订阅管理 | 存手机本地，跨源汇成一条通用信息流 | 存手机本地 |
| 设备间同步 | 局域网设备同步（端口 `12315`），另有备份文件整包迁移 | 无设备同步 |
| 源码许可 | 源码公开但不是 OSI 认证开源（FUTO 自有许可） | 开源 |
| 桌面版 | 有 Windows / macOS / Linux 版 | 只有安卓版 |

安装包体积差别也大：Grayjay 这份 164.58M，NewPipe 的安装包小得多，在意体积和后台占用的话这是个实际差异。

## 二、按使用方式对号入座

- **只看 YouTube、SoundCloud 这几个站**，想装个轻量的 → NewPipe 就够；
- **订阅分散在多个平台**（比如 YouTube 加 Twitch 加 BiliBili），想一条信息流全看完 → Grayjay 的多源聚合就是为这个场景；
- **要登录平台账号**——看 Patreon / Nebula 已付费内容、拿各平台个性化推荐、BiliBili 高画质 → 只有 Grayjay 支持；
- **在意开源许可**，只接受 OSI 认证开源 → NewPipe；
- **手机和电脑都想用同一个应用** → Grayjay 有桌面版。

两边不互斥：常见做法是先装着过渡，把订阅搬过去用一阵再决定去留。

## 三、从 NewPipe 搬到 Grayjay

订阅不用手抄：NewPipe 里把订阅导出成 JSON 文件 → 用文件浏览器打开这个 JSON → 选 Grayjay 处理，订阅名单就进来了。完整步骤（含从平台账号直接导入的另一种方式）见 [添加视频源与订阅导入方法.md](添加视频源与订阅导入方法.md)。

过渡期两个应用可以并存，确认订阅和列表都搬全了再卸旧的；Grayjay 侧的整列表离线下载与换机备份见 [离线下载与播放列表管理.md](离线下载与播放列表管理.md)。装完遇到问题，排查思路见 [常见问题与故障排查.md](常见问题与故障排查.md)。
