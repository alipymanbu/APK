# Grayjay 常见问题与故障排查

> 装好之后最容易卡住的几个点：订阅标签不见了、首页全是随机视频、某个源加载失败、设备同步连不上、装不上或闪退。逐条对答。

## 一、底栏找不到「订阅」标签

按顺序查两种可能：

1. 你还没有订阅任何创作者——订阅标签在有订阅之前不显示，先去加源并关注几个频道（见 [添加视频源与订阅导入方法.md](添加视频源与订阅导入方法.md)）；
2. 调过标签顺序——它可能被挪进了「More」里，进「Settings → Manage Tabs」把订阅标签拖回底栏。

## 二、首页全是随机视频

这不是故障。Grayjay 默认不跟踪你，各平台不知道该给你推什么，首页自然是没有个性化的内容。想要熟悉的「猜你喜欢」：

- 到「Sources」页点开对应平台并登录账号；
- 登录后推荐恢复个性化；观看历史和订阅仍存在手机本地。

不在乎个性化的，也可以只把首页当「全平台内容池」，靠搜索和订阅流找东西。

## 三、某个源打不开或加载失败

按顺序试：

1. 先判断是不是单源问题——换别的源的视频试试，都能播就只是那个源出问题；
2. 平台改版常导致个别插件临时失效，去 [plugins.grayjay.app](https://plugins.grayjay.app/) 重新安装或更新该插件；
3. 带着 Beta / Alpha 标注的源本身就不够稳，长期小毛病不断的话，直接换其他源看同类内容，别耗在上面；
4. 仍然不行，用应用内「Settings」里的反馈按钮报给官方，或发邮件到 [grayjay@futo.org](mailto:grayjay@futo.org)。

另外注意搜索范围：搜索只覆盖**已启用**的源。某个视频搜不到，先确认它所在平台的插件装了没有；装了还搜不到，到搜索结果的筛选里检查那个源是不是被关掉了。

搜索时也可以临时把出问题的源在筛选里关掉，不影响其他源使用。

## 四、设备同步失败

设备间的同步走局域网端口 `12315`：

| 现象 | 检查 |
| --- | --- |
| 完全搜不到对方 | 两台设备是否在同一局域网 |
| 能看到但连不上 | 防火墙或安全软件有没有拦 `12315` 端口 |
| 跨外网同步 | 目前同步不能经互联网中转，跨网同步不了 |

不想折腾同步的，直接用备份文件整包迁移，做法见 [离线下载与播放列表管理.md](离线下载与播放列表管理.md)。

## 五、装不上或装完闪退

- **装不上**：先确认「安装未知应用」权限给到了打开安装包的那个应用（步骤见 [下载与安装教程.md](下载与安装教程.md)）；再核对系统版本，各渠道对最低版本的标注不一，最新版多标注 Android 9.0 以上；
- **装完闪退**：重启手机再开一次；仍闪退就换个来源对照——从 [Grayjay 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0d2c403b4472) 重新下载覆盖安装，或从官网 [grayjay.app](https://grayjay.app/) 拿最新版试；
- **桌面出现两个 Grayjay**：官网 APK 与 Play 商店版包名不同，会并存，属于正常现象，固定用其中一个并只从同一渠道更新。

## 六、收费与源码

- 收费：应用免费用，官方提供一次性付费授权，付不付功能完全一样（官方 FAQ 明确说明），付费只是支持开发的方式；
- 源码：公开在 [gitlab.futo.org/videostreaming/grayjay](https://gitlab.futo.org/videostreaming/grayjay)，插件开发文档也在同一仓库；
- iOS 版：官方明确近期没有，重心在安卓与桌面端。
