## 一、适用范围

这一套「蓝牙安装 / 小程序管理」功能面向 Zepp OS 设备 —— 小米手环 7、Amazfit GTR 4 这类能装小程序的手环和手表。社区反馈 1.8.3-Beta 是较完善支持 ZeppOS 2.0 设备（如 GTR 4）的版本，开发者更新记录里 1.8.3-Beta 也标注了对 GTR 4 的支持；更早的版本装不了，装不上先核对版本（版本口径见 [下载与安装教程.md](下载与安装教程.md)）。

## 二、安装步骤

1. 打开 Suiteki，点上方按钮完成授权；
2. 登录 Zepp 账号，在获取密钥界面选「添加到列表」（这一步与 [密钥获取步骤.md](密钥获取步骤.md) 是同一套授权，密钥取不出来的话安装也走不下去）；
3. 在设备管理里设置设备型号与名字（名字非必需）；
4. 回首页点「蓝牙安装」，选择要装的小程序文件，等它传完；
5. 手环端出现新装的小程序即成功。

安装报错看第四节的代码对照。

## 三、卸载

- 已在列表里的小程序：进「小程序管理」，点它选卸载；
- 列表里没有但手环上确实装了：在「小程序管理」界面点「添加应用信息」，把小程序的信息手动补进来之后再卸载；
- 补充一个社区里常见的说法：第三方小程序在手环端大多卸不掉，只能恢复出厂，所以手机端用 Suiteki 卸载是最常用的路子。

## 四、安装报错代码对照

以下是米坛社区反馈帖里整理的对照（单一来源整理，供排查参考，以实际版本行为为准）：

| 报错 | 处理方向 |
| --- | --- |
| `10D30A` | 版本太旧，用 1.8.2 以上版本再装 |
| `10D301` / `10D4xx` | 先进官方应用刷新（同步一次手环数据），再回 Suiteki 装 |
| `10D508` | 表盘或小程序文件本身的问题；把文件解压后重新压成 ZIP 再装 |
| `10D501` | 大概率已经装完，到手环上看 |
| `10D656` | 文件不被支持，换适配该设备的版本 |
| `onConnectFail` | MAC 地址填错，或手环连不上（常见是没电） |
| `10D203` | 检查 MAC 地址、手机蓝牙开关、官方应用是否在后台（有反馈需要先开官方应用同步数据） |

设备信息（MAC 地址、型号）在哪看，见 [手环型号与应用入口对照.md](手环型号与应用入口对照.md)；装完密钥要配第三方应用用的，回到 [密钥获取步骤.md](密钥获取步骤.md) 与 [常见问题排查.md](常见问题排查.md)。
