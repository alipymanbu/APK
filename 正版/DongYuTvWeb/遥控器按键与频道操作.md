## 一、照着老电视的习惯设计

DongYuTVWeb 没有首页、没有影视推荐位，打开就是频道画面，操作逻辑照搬了老式闭路电视：你只会在「切台」和「调音量」这两件事上按遥控器。这套键位对老人几乎零学习成本，给家里长辈装好后，一般只需要教一句话：「按上下换台」。

## 二、键位总表

以下键位来自官方 README，逐条对应：

| 遥控器按键 | 作用 |
| --- | --- |
| 方向上 | 上一个频道 |
| 方向下 | 下一个频道 |
| 左键 | 音量减 |
| 右键 | 音量加 |
| 确定键 | 换台（调出频道选择） |
| 数字键 | 直接跳到对应频道号 |
| 菜单键 | 打开设置 |
| 菜单键连按两下 | 换源（切换当前频道的备用信号） |
| 返回键 | 返回 / 退出 |
| #号键 | 强制刷新当前频道（画面出问题时用） |

注意两点：

- **数字键换台**依赖频道号，各频道的号码以频道列表页显示为准；
- 不同遥控器的「#号键」位置不一：有的在键盘区右下角，有的要按「*+号」切换出来。找不到时优先看遥控器上有没有标 `#` 的键。

## 三、一个频道看不了，先换源再强刷

这是日常使用里最常碰到的情况：某个台画面卡住、黑屏或转圈。处理顺序固定为：

1. **双击菜单键换源**——同一个频道往往有多个信号源，切到另一个通常就恢复；
2. **按 #号键强制刷新**当前频道；
3. 还不行就按方向键跳到别的台再跳回来；
4. 依然黑屏才进入排查流程，见[黑屏或无法播放怎么办](黑屏或无法播放怎么办.md)。

滑动操作是后续版本加进来的：1.0.10 起支持滑动切台与频道换源，1.0.12 又加了滑动屏幕换源与快速换源——遥控器键位从初版到现在没有变过，触屏上多出的这些手势只属于较新版本，老版本以按键操作为准。

## 四、换台时界面长什么样

按下方向键或数字键后，屏幕上会短暂显示频道信息再回到全屏画面；加载期间画面中央会显示「加载中」字样。如果换台后长时间停在加载提示，多半是该频道源的问题——按第三节的顺序换源或强刷即可，不需要重启 App。

## 五、装好之后先花一分钟试这些键

新装好的第一件事是把上表按一遍，尤其是：

- 数字键直达（比如直接按频道号跳台）；
- 双击菜单键换源——这个组合键最隐蔽，但日后用得最多；
- #号键强刷。

键位确认没问题后，建议顺手把开机自启设置好，见[开机自启动设置](开机自启动设置.md)；想了解频道列表的构成与换源机制，看[频道列表与自定义源说明](频道列表与自定义源说明.md)。
