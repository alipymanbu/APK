## 一、频道从哪来：网页官流，不是 m3u 播放列表

DongYuTVWeb 与常见 IPTV 软件的根本区别在于：它**不内置 m3u 播放列表**，而是用 WebView 直接加载电视台官方网站的网页直播流。央视、各省卫视等主流频道都在列，频道与分类由开发者维护在项目的频道配置文件里，随版本更新。这个机制带来两个特点：

- **不用你找源、换源、订阅源**——传统 IPTV「昨天能看今天全挂」的维护成本被消掉了；
- **频道可用性跟着电视台官网走**——官网直播间偶尔维护或改版，个别台会临时看不了，按[黑屏或无法播放怎么办](黑屏或无法播放怎么办.md)里的换源/强刷处理，多数能恢复。

## 二、换源机制怎么用

频道配置里的 `children` 字段允许同一个频道挂多个信号源，日常操作对应遥控器上的：

- **菜单键连按两下** → 在当前频道的多个源之间切换；
- 触屏设备也可以在频道列表界面滑动切台（1.0.11 起）。

也就是说，看到「某个台看不了」时，第一反应不是找新直播源文件，而是双击菜单键换源。

## 三、想加自己的源：普通用户 vs 会折腾的

### 普通用户：暂不支持 App 内自定义

官方 README 写明：**目前不支持在 App 里自定义源**。想添加自己的频道，途径是在官方公众号私信开发者提交需求。所以「导出一个 m3u 导进去」这类 IPTV 软件的常规操作在 DongYuTVWeb 上行不通，选它就是选官方维护的那套频道。

### 会编译的：改配置文件自己构建

项目开源（Apache-2.0），频道清单在源码 `app/src/main/assets/lives/` 下的 jsonc 文件里（当前为 `live-2026-03-19.jsonc`），支持注释。三种播放器类型决定了加源的难度：

| 播放器 | 适用场景 | 关键配置 |
| --- | --- | --- |
| `common` | 普通无验证的 m3u8 直链 | 频道里给 `args.liveUrl` 即可 |
| `simple`（自定义脚本） | 直播地址带时间戳/签名等验证参数 | 写 `init.js` / `play.js` 脚本生成真实地址，内置 CryptoJS 与 HttpUtil |
| `base` | 加密或只能靠网页环境播的地址 | 直接加载目标网页并全屏化，如官方示例的广西卫视官网 |

脚本机制里几个官方点名的要点：`{{channelName}}` 占位符会被替换成所选频道名；请求若被目标站检测 Referer，用 `X-Referer` 请求头由内部转写；`playLive(url)` 是内置的播放调用。完整示例与说明都在官方 README 的「自定义频道」一节（GitHub 仓库 `Yu2002s/DongYuTVWeb`）。

注意官方仓库页标注了「已停止开源更新，请勿克隆代码」——源码与配置结构以仓库当时的 README 为准，动手前先读一遍最新说明。

## 四、频道号与数字换台

频道配置早期用 `number` 字段定义频道号（数字键直达用），后续更新已把该字段从配置中去除，号码按频道在列表中的顺序生成。所以：数字键换台照常可用，但**不要参考旧文章里写死的频道号对照表**，以你当前版本的频道列表显示为准。

## 五、更新会带来什么变化

频道调整随版本发布，近期公开可见的调整包括：新增省台（如广西卫视、支持换源的频道结构）、播放脚本超时自动换台等。想知道当前版本的完整频道清单，最直接的办法是装好后按确定键翻一遍分类；版本层面的变化可关注官方发布中心（`http://app.jdynb.xyz/`）的版本动态。安装或更新包的方式见[下载与安装教程](下载与安装教程.md)。
