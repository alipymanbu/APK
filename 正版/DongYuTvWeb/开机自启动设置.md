# DongYuTVWeb 开机自启动设置

> 电视一开机直接进 DongYuTVWeb 看直播：远程设置、手动设置两条路，再附 ADB 兜底命令。

## 一、为什么值得设

DongYuTVWeb 打开即看、无首页无广告，把它设成开机自启 + 默认桌面后，电视的使用方式就回到了老电视：按电源，出直播。对老人来说省掉了「开机后在智能桌面里找应用」这一整步。

注意一个版本细节：1.0.13 的更新说明里明确写着「修改默认开机不自启」——也就是说装上网盘这份 1.0.13 后，**默认是不自启的**，想开机进直播必须按本文设置一次。官方提醒：不保证所有电视都支持，方案仅在原生系统虚拟机 Android 12 上测试通过，定制系统可能无效——所以给两条主路径之外还留了一条 ADB 兜底。

## 二、远程设置（推荐先试）

前提：手机和电视在同一局域网，且电视已按[下载与安装教程](下载与安装教程.md)的方式开启过 ADB。

1. 手机端打开 DongYuTVWeb 的 `设置 -> 远程连接 -> 连接电视`；
2. 连上后点操作按钮，依次执行：
   - **开启自启动**；
   - **设置默认桌面**。

两步都做完后重启电视验证：开机应直接进入 DongYuTVWeb 的频道画面。

## 三、手动设置

手机远程连不上时，在电视上手动做同样两件事：

1. **开自启动**：翻电视的 `设置` 和系统自带的应用管理类 App，找「应用自启动 / 开机启动」相关开关，对 DongYuTVWeb 打开；找不到开关的品牌可搜索「电视品牌 + 应用自启动设置」。
2. **允许悬浮窗权限**：确保 DongYuTVWeb 至少打开过一次，并在权限管理里允许**悬浮窗**——这是自启机制依赖的权限，缺了它自启大概率不生效。
3. **设为默认桌面**：在电视桌面按遥控器的 **Home 键（主页键）**，系统通常会弹出「选择默认桌面」的提示，选 DongYuTVWeb 并勾选「始终」；部分电视要把这项设置藏在 `设置 -> 桌面 / 启动器` 里。

## 四、ADB 兜底：命令行设默认桌面

上面两条路都走不通（尤其是一些深度定制的系统）时，用 ADB 直接把 DongYuTVWeb 注册为默认启动项：

1. 电视进入工厂模式并开启 USB 调试（进入方法因品牌而异，可参考公开的工厂模式教程）；
2. 用无线调试或数据线连接电视与电脑（用手机替代电脑时，需装 MT 管理器等自带终端的工具）；
3. 在终端依次执行：

```bash
adb connect 电视IP:5555      # 无线连接
adb devices                  # 确认设备已连接
adb shell                    # 进入设备终端
cmd package set-home-activity "xyz.jdynb.tv/.MainActivity"   # 设为默认启动项
reboot                       # 重启设备验证
```

其中 `xyz.jdynb.tv` 就是 DongYuTVWeb 的包名。执行完重启后开机应直接进直播。若提示设置失败或重启后无效，说明该定制系统限制了默认桌面替换，只能退回「桌面快捷方式 + 系统自启动开关」的组合。

## 五、设完后的验证清单

- 按电视电源键重启，等待进入系统；
- 正常结果：直接出现 DongYuTVWeb 频道画面，按[遥控器按键与频道操作](遥控器按键与频道操作.md)里的键位即可换台；
- 如果开机仍进原桌面：逐项复查「自启动开关」「悬浮窗权限」「默认桌面」三处；
- 如果开机进直播但想退回原来的智能桌面：在电视设置里把默认桌面改回系统桌面即可，DongYuTVWeb 本身不受影响。
