# DongYuTVWeb 黑屏或无法播放怎么办

> DongYuTVWeb 打开后黑屏、转圈、播不出来：按换源 → 强刷 → 换内核包 → 补 WebView 的顺序逐层排查。

## 一、先分清是「个别台」还是「全部台」

排查前先按一下方向键多切几个台：

- **只有个别台黑屏**：是该频道的信号源问题，不是你设备的问题，走第二节的两步通常能解决；
- **所有台都黑屏/转圈**：大概率是设备 WebView 内核过旧，走第三、四节。

另外先确认基本前提：电视网络已连通（同一台电视能打开系统自带的浏览器或应用商店即算通），并且没有被路由器做年龄限制之类的拦截。

## 二、个别台黑屏：换源 + 强刷

DongYuTVWeb 的多数频道不止一个信号源，官方也内置了换源机制（频道配置里的 `children` 字段就是干这个的，见[频道列表与自定义源说明](频道列表与自定义源说明.md)）：

1. **连按两下菜单键** → 切换到当前频道的备用源；
2. 仍不行按 **#号键** 强制刷新当前频道；
3. 还不行就先跳走再跳回，让频道重新初始化。

官方播放脚本里有「超时自动换台」的逻辑（提交记录 `feat: 优化播放脚本，添加超时自动换台`），所以部分源失效时它会自己跳，偶尔等待比手动排查更快。

## 三、所有台都黑屏：补 X5 内核

DongYuTVWeb 的播放依赖系统 WebView 内核。老电视、老盒子的内置 WebView 版本过低时，网页直播流解不出来，表现为所有台都起不来。官方的处理方式：

1. **先试在线装内核，不用重装**：官方发行说明里反复写着一个更轻量的办法——小体积包用户播不了时，打开 App 的 `设置 -> 更新webview -> 在线下载X5内核`，装完再试，省去重装换包这一整步；
2. **在线装了仍不生效**：官方 1.0.14 / 1.0.15 两个版本专门修过「X5 内核不起作用」的问题，如果你的包比它们还老，先按[版本更新与升级方法](版本更新与升级方法.md)升级再试；
3. **换大包对照**：官方发布页也提供内置 X5 内核的大体积版本，老设备可以直接用它。装机时选包的方法见[下载与安装教程](下载与安装教程.md)——手机和新设备用小包、电视和老设备用大包，就是这条排查路线的由来；
4. X5 内核在安装阶段报错的话，官方建议直接反馈给开发者（发布中心的交流入口）。

网盘资源里的这份 1.0.13 是 15.26M 的小体积包；如果你的设备全台黑屏且系统较老，按上面第 1、3 条把内核补上。

## 四、还播不了：手动安装 Android System WebView

部分设备即使换了包也不行，官方指的最后一招是手动更新系统的 **Android System WebView** 组件。官方给出这几个渠道：

| 渠道 | 地址 | 说明 |
| --- | --- | --- |
| 官方维护的 WebView 列表 | `http://app.jdynb.xyz/webview/` | 首选，按设备位数选 |
| 项目作者的 Gitee 仓库 | `https://gitee.com/jdy2002/android-webview/releases` | 国内直接可达 |
| 123 网盘 | 官方 README 内给出 | 32 位设备用 |
| ApkMirror | `https://www.apkmirror.com/apk/google-inc/android-system-webview/` | 需要相应网络条件 |

装 WebView 的位数要和设备一致（老设备 32 位、主流设备 64 位），装完重启电视再打开 DongYuTVWeb。

## 五、兜底之后仍无解的情况

- **安装阶段就失败**：多半是电视拦截第三方应用，按[下载与安装教程](下载与安装教程.md)第五节临时禁用「软件包安装程序」再装；
- **能进频道列表但永远加载中**：换过源、换过包、补过 WebView 三步都做过仍不行，可以去官方发布中心的 FAQ 页（`https://app.jdynb.xyz/faq`）与交流群反馈，附上电视品牌型号与系统版本；
- **只有声音没画面或画面卡顿**：属于解码性能问题，多见于低配盒子，切换到信号码率较低的源（双击菜单键换源）通常可缓解。
