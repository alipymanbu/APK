## 一、要不要注册账号

官方更新说明中提到，全部阅读与听书功能可以不注册、不登录直接使用。只有一种场景必须登录：手机和电脑之间要同步进度（见[电脑网页端与浏览器扩展.md](电脑网页端与浏览器扩展.md)第三节）。只用手机单机听书的，可以一直不登录。

## 二、收费与订阅

- 官方商店信息的口径是「高级功能限时免费、无订阅、无隐藏收费」，截至本篇整理时如此，**是否长期免费以官方商店页面当时的标注为准**；
- 如果某天应用内出现订阅提示，以应用内实际展示为准，本篇不做猜测性结论。

## 三、导入失败或转换失败

按顺序排查：

1. **核对格式**：确认文件在支持列表内（EPUB / PDF / TXT / MOBI / AZW / AZW3 / DOCX 等，完整清单见[支持的格式与导入方法.md](支持的格式与导入方法.md)第一节）；
2. **检查文件本身**：文件在电脑上能否正常打开？文件大小是否为 0？先排除传输损坏 —— 网盘下载的文件重新下一遍；
3. **带版权保护的书**：从商店购买且绑定了 DRM 的电子书无法被第三方阅读器处理，换无 DRM 版本；
4. **扫描版 PDF**：本质是图片的 PDF 依赖识别能力，效果不好时优先找文字版；
5. **换格式绕过**：MOBI / AZW3 转换失败时，若有条件先用电脑转成 EPUB 再导入；
6. **重启再试**：大文件转换占用资源多，清理后台后重试一次，仍失败则可能是版本问题，去商店页面看有没有更新。

## 四、听书相关

| 现象 | 判断与处理 |
| --- | --- |
| 锁屏后朗读停了 | 系统省电策略杀掉了后台播放，把 Readify 加入电池优化白名单/允许后台运行 |
| 读到一半顺序乱 | 多半是 PDF 重排后的段落顺序问题，见格式篇第三节；换文字版源文件 |
| 语速忽快忽慢 | 先确认是否手动调过倍率；仍异常时换音色对比，判断是音色问题还是文件问题 |
| 生僻词、人名读错 | 语音合成的常见局限，换音色对比，无逐词校正功能 |
| 目录里找不到章节 | TXT 网文章节格式不规整时识别会缺失，只能按段落快进快退 |

锁屏就停的处理，各品牌设置后台运行的大致入口（系统更新后名称可能略有变化）：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / Redmi | 设置 → 应用设置 → 应用管理 → Readify → 省电策略 → 无限制 |
| 华为 / 荣耀 | 设置 → 应用 → 应用启动管理 → Readify → 关闭「自动管理」，允许后台活动 |
| OPPO / 一加 | 设置 → 电池 → 应用耗电管理 → Readify → 允许完全后台行为 |
| vivo / iQOO | 设置 → 电池 → 后台功耗管理 → Readify → 允许后台高耗电 |
| 三星 | 设置 → 电池 → 后台使用限制，把 Readify 移出休眠/深度休眠应用 |

## 五、进度不同步

1. 确认两端登录的是同一账号；
2. 在网页端手动刷新一次，等十几秒再看进度；
3. 检查手机端网络是否正常（同步需要联网）；
4. 仍不同步时，记下手动翻到的大致位置，跨端先手动对齐，隔天再试（偶发的同步延迟没有更好的本地办法）。

## 六、安装包校验对不上

按[下载与安装教程.md](下载与安装教程.md)第三节的 MD5 值核对时对不上，直接重新下载，不要强行安装；连续两次都不一致，换一台设备或网络环境再试。安装后闪退、白屏这类问题，先确认系统版本达到 Android 7.0（商店信息口径），再考虑卸载重装。

## 七、安装后要求谷歌服务、闪退或找不到功能

- 有第三方渠道提示这款应用会校验谷歌账户或安装来源：安装后反复要求跳转商店、或一打开就闪退时，先检查手机上有没有谷歌服务框架（国内系统的手机默认不带）；
- 没有谷歌服务框架的设备，换有谷歌服务的环境再试；实在没有条件，只能改用 Google Play 商店渠道使用；
- 找不到某个功能（比如睡眠定时、离线语音包）时，先对照[更新日志与新功能.md](更新日志与新功能.md)确认是不是版本差异 —— 网盘里的 1.9.4 不包含后续版本加的能力，不是应用坏了；
- 仍然闪退时按第六节先排除安装包损坏，再按第四节排除电池策略限制。
