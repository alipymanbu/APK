## 一、五种加好友途径的条件对照

| 途径 | 适用场景 | 前提条件 |
| --- | --- | --- |
| 行动条码（二维码） | 两人面对面 | 双方任一人在「聊天」页顶部打开扫码或「显示行动条码」，扫完点「加入好友」 |
| 以 ID 搜索 | 知道对方的 LINE ID | 对方必须开着「允许以 ID 加入好友」的开关 |
| 以电话号码搜索 | 知道对方注册用的手机号 | 对方须允许以电话号码加入；官方页面说明部分设备/地区下此入口可能不开放 |
| 通讯录自动添加 | 注册时授权过通讯录 | 双方手机里都录有彼此的号码，且都开了自动加入设置 |
| 可能认识的人 | 陌生人扫码后互加 | 你扫了别人，对方会出现在你的「您可能认识的人」名单里 |

当面加人最稳的是二维码：不用记 ID、不受对方搜索开关影响。扫完顺手发一条贴图或消息，对方就能从聊天室里把你加回来，双向完成。

## 二、ID 搜索不生效的常见原因

- **对方关了开关**：设置 → 好友 → 允许以 ID 加入好友。关着就搜不到，只能换二维码或让对方改设置。
- **ID 输错**：LINE ID 区分大小写与下划线，没有「@」前缀（带 @ 的是邀请链接格式）。
- **入口不对**：加好友入口在「聊天」列表上方（或主页的好友添加按钮），选「搜索」后切换到「ID」分类再输。

顺带一提，如果你不想被陌生人搜到，把同一处开关关掉即可，对方再用你的 ID 搜索就搜不出来。

## 三、群聊、开放聊天室、多人通话

- **群聊（群组）**：从聊天列表右上角新建，把已有好友拉进来，上限 500 人（以官方当前说明为准）。群里可以多人语音/视频通话，还能把群设成「多个管理员」。
- **开放聊天室（OpenChat）**：按兴趣关键词搜出来的公开房间，可以匿名（用系统生成的角色身份）加入，不用暴露自己的真实账号信息。适合跟不认识的同好聊天；房间里有管理员规则，进房前会显示房间说明。
- **群视频/语音**：在群聊天室点电话图标选择类型；开放聊天室不支持私密的多人视频通话，这一点别弄混。

把同事同学拉群用前者，想找兴趣圈子又不想让群里人看到自己好友关系就用后者。

## 四、聊天窗口里用得上的几个功能

- **贴图**：LINE 的招牌是贴图，聊天输入框旁的贴图商店里有免费与付费两类；朋友发来的贴图点了就能看出处。注意免费领的活动贴图大多只有 90 或 180 天有效期，领取条件与到期规则见 [免费贴图领取与有效期.md](免费贴图领取与有效期.md)。
- **Keep Memo**：一个只有你自己的聊天室，长按消息选「保存在 Keep Memo」可当临时收藏夹用，文字、图片、链接都能存。
- **翻译**：聊天室菜单里可以启用自动翻译，也可以把官方翻译账号（在好友搜索里搜 translator 相关 ID）加进聊天室，发中文它会回英文（或其他语言）。跨语言聊天时比切出去复制粘贴省事。
- **回收与撤回**：发错的消息长按可撤回，24 小时内有效；撤不掉的（如已被截屏）只能道歉了。

加完好友、聊上天之后，下一步建议把账号的换机准备做掉——聊天记录不备份，换手机就没了，方法见 [账号迁移与聊天记录备份.md](账号迁移与聊天记录备份.md)。
