## 一、免费贴图从哪领

入口有两处：应用内「主页 → 贴图」的贴图商店，或网页版贴图小铺 [store.line.me](https://store.line.me)。商店里的贴图分两类：付费贴图（用代币购买）与免费贴图。免费贴图绝大多数是**品牌或官方账号的推广活动**，领取条件常见三种：

| 领取条件 | 说明 |
| --- | --- |
| 把指定官方账号加为好友 | 最常见的一种，加完好友回活动页即可领取 |
| 完成指定任务 | 例如观看指定视频若干分钟、打开关联应用完成操作 |
| 限量赠送 | 「前 N 名加好友者可得」，晚一步就领不到 |

活动随时上新、随时下架，具体哪几张能领、条件是什么，以你打开贴图商店当时的活动页为准。

## 二、有效期规则：90 天与 180 天

- 活动免费贴图普遍带使用期限，常见的是**自下载日起 90 天或 180 天**，个别活动标示不同，一律以活动页写明为准。
- 下载本身也有截止日：**过了下载期限就无法领取**，错过通常不会再出（促销型贴图基本绝版）。
- 付费购买的贴图一般没有使用期限，个别商品页有特殊标示的除外。
- 到期后的表现：贴图从你的选择列表中消失、无法再发送；活动仍在期内时可以重新领取（期限按新的下载日重新起算，具体以活动页规则为准），活动结束后则无法再领。

## 三、为什么有些免费贴图「找不到」

不少免费贴图不会出现在商店的常规列表里（俗称隐藏贴图），而是通过**活动页的直达链接**分发，链接形如 `line.me/S/sticker/数字`。这也是品牌活动贴图的主要入口——看到攻略文章里的链接，点开直接领取即可；自己盲逛商店反而容易错过。

领取条件里最常见的动作是「加官方账号为好友」，加好友的各种途径与开关设置见 [加好友与聊天基础.md](加好友与聊天基础.md)。需要留意的是：加好友后若领取页未刷新出贴图，退出商店重新进入，或确认该账号是否属于你所在地区的活动范围——部分活动只面向特定地区的用户。

## 四、几个省事的做法

- 想持续白拿贴图，与其等别人盘点，不如直接把常搞活动的官方账号（购物、礼物、旅游类官方账号最活跃）加好友，活动上线时会推送给你。
- 下载前先看一眼活动页标的使用期限：90 天的贴图下了一堆，三个月后批量过期，聊天室里会突然「没图可用」。
- 付费贴图与免费贴图在列表里混排，购买前确认价格标示，别把代币花在限时免费的同款上。
