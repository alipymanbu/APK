## 一、先弄清楚你要装的是什么

fiil+ 是 FIIL（斐耳）蓝牙耳机的官方配套 App，安卓版包名 `com.fengeek.f002`，上架主体为江西斐耳科技有限公司。它不是音乐播放器，装它只为一件事：让手机能对 FIIL 耳机做蓝牙之外的深度设置——电量与模式查看、EQ 音效、双设备连接、固件更新、产品注册，这些都走它。

这份安装包版本为 3.4.28，约 120.89M，MD5 校验值 `41FE7C5B766502819FD175E609C607F5`（担心文件损坏时可用它比对）。应用商店里的版本号会更高（截至 2026 年 9 月，第三方商店已收录 3.5.x），日常使用差异不大；装完这版后也可以直接在应用商店里升到当前最新版再用。

## 二、安装前确认三件事

| 检查项 | 说明 |
| --- | --- |
| 手机系统版本 | 第三方商店对 fiil+ 标注的系统要求为 Android 8.0 以上，以官方商店页面为准；安卓版本过低会装不上 |
| 存储空间 | 安装包约 120M，加上安装后的占用，预留 400M 以上比较稳 |
| 「未知来源」安装权限 | 从网盘拿到的安装包不经过应用商店，需要在系统里允许本次安装 |

「允许安装未知来源应用」的入口各厂商叫法不同，常见位置：

- 原生 Android：设置 → 应用 → 特殊应用权限 → 安装未知应用
- 小米 / Redmi：设置 → 隐私保护 → 特殊权限 → 安装未知应用（多数机型在安装弹窗里直接授权即可）
- 华为 / 荣耀：设置 → 安全 → 更多安全设置 → 安装外部来源应用；部分新机型要先关闭「纯净模式」
- OPPO / vivo / 一加：安装弹窗内授权即可，个别机型在「设置 → 安全」里

## 三、安装步骤

1. 打开头部给出的 fiil+ 安装文件资源（夸克网盘）链接，转存到自己网盘后把安装包下载到手机（夸克分享页右上角有转存入口）。
2. 在手机通知栏或「文件管理 → 下载」里找到 `.apk` 文件，点开。
3. 系统弹出「是否安装此应用」时点安装；中途出现安全拦截，按第二节的方法放行。
4. 装完点打开，第一次启动会有隐私政策与权限申请，逐项看完再同意。

安装中途常见的三种报错，对号入座：

| 报错表现 | 多半是 | 处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | 安装包下载不完整 | 回网盘重新下载一遍再装，装完可用第一节的 MD5 比对 |
| 提示「禁止安装」后没有继续选项 | 纯净模式 / 未知来源没放行 | 按第二节对应厂商的路径放行，华为新机型先关纯净模式 |
| 卡在「正在安装」很久没动静 | 存储不足或后台占用 | 清出 1G 以上空间、重启手机后再装 |

装不上、装一半失败的处理见[常见问题排查.md](常见问题排查.md)。

## 四、首次打开会要哪些权限

fiil+ 申请的权限不少，每一项都对应一个具体功能。不想全给的话，先只给「附近设备 / 位置」，其余等用到再说：

| 权限 | 对应的功能 | 不给会怎样 |
| --- | --- | --- |
| 附近设备 / 蓝牙 | 搜索、连接耳机 | App 没法用 |
| 位置（部分系统表现为「附近设备」） | 安卓扫描蓝牙设备需要；另用于查询附近门店、运动耳机轨迹 | 多数手机上搜不到耳机 |
| 相机 | 扫序列号二维码快速注册产品 | 只能手动输入序列号 |
| 短信 | 注册产品时接收验证码 | 验证码要自己切出去看 |
| 电话 | App 内一键拨打官方客服电话 | 打电话要自己记号码 |
| 录音 | 语音搜歌 | 语音功能不可用 |

权限随时能在系统里改：设置 → 应用 → fiil+ → 权限，漏了哪项补哪项。

## 五、用的是 iPhone

iOS 版叫 fiil+，App Store 搜「fiil+」就能装，地址是 [https://apps.apple.com/cn/app/fiil/id1021206429](https://apps.apple.com/cn/app/fiil/id1021206429)。iOS 版同样覆盖耳机设置、煲机、产品注册与正品验证，与安卓版功能基本一致；iOS 从商店装完直接打开，不需要本篇的未知来源操作。
