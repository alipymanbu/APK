## 一、为什么必须开无障碍服务

安卓不允许普通应用替用户点屏幕，模拟点击、模拟滑动这类操作只对无障碍服务开放，所以 Auto Clicker 必须拿到这项权限才能工作。开发者在商店页面说明：该权限用于实现模拟点击与滑动的核心功能，不通过它收集你的个人数据。

顺带说明另一项常被搞混的权限：悬浮窗权限只负责把控制面板显示在别的应用上面，它开没开不影响点击本身。两项权限的分工见[常见问题与使用注意](常见问题与使用注意.md)。

## 二、开启步骤

1. 打开 Auto Clicker，点开始（或按应用内引导）跳转到系统设置；
2. 找到「无障碍」（有的系统叫「辅助功能」），进入「已下载的应用」或「已安装的服务」；
3. 选中 Auto Clicker，打开开关；系统会弹一次风险确认，确认即可。

不同品牌的入口位置不一样：原生系统在「设置 → 无障碍」；多数国产系统收在「设置 → 更多设置」或「辅助功能」里。实在找不到，就在设置页顶部的搜索框里搜「无障碍」。

## 三、服务为什么会被自动关掉

常见的四种原因，对应的典型表现也各不相同：

| 原因 | 典型表现 |
| --- | --- |
| 省电策略杀掉了服务 | 跑一会儿就停，面板可能一并消失 |
| 一键清理或加速球清了后台 | 切到别的应用再回来就不点了 |
| 应用更新后服务被系统重置 | 更新完一打开就是没开权限的状态 |
| 部分系统对无障碍应用有使用确认 | 状态栏出现提示，服务被暂停 |

其中省电策略是最高发的：三星、小米、一加等省电激进的品牌上，这类「跑一会儿就被关」的反馈最集中，这几家的机器重点检查第四节的白名单设置。另外刚装完或刚更新完应用时，无障碍服务列表有时要等一会儿才刷出它的条目，找不到就退出去重进一次设置。

## 四、让它稳定驻留的做法

下面这些是安卓通用的保活做法，入口名称各品牌略有差异：

1. 电池策略里把 Auto Clicker 设为「不受限制」或「无限制」；
2. 允许它自启动（有的系统叫「后台弹出界面」也要一并允许）；
3. 在最近任务界面把它的卡片锁定，避免一键清理误伤；
4. 挂机时让屏幕保持常亮，或插着电并在开发者选项里开「充电时屏幕不休眠」——屏幕一灭，自动点击就没有作用对象了。

## 五、开了还是点不动的几种情况

按顺序试：

1. 把无障碍服务关掉再重新打开——服务掉线后最常见的解法；
2. 完全退出应用重开一次；
3. 换一个目标应用试试（比如点系统自带的计算器）——如果别处能点、只有某个应用没反应，多半是那个应用自己屏蔽了模拟点击。不少金融、支付类应用和带反作弊的游戏会主动拒绝自动化操作，这属于对方应用的防护，不是 Auto Clicker 出了故障；
4. 以上都无效，卸载后重装一次作为最后的手段——重装后无障碍与悬浮窗两项权限都要重新开（重装步骤见[下载与安装教程](下载与安装教程.md)）。

排查完仍不正常的其他现象，对照[常见问题与使用注意](常见问题与使用注意.md)的速查表再走一遍。
