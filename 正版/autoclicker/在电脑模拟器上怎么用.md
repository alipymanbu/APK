# 在电脑模拟器上怎么用

> Auto Clicker 是安卓应用，但可以装进电脑上的安卓模拟器里跑——键鼠定点更准、大屏看得清、长挂机也不占用手机。本篇讲这条路怎么走、要注意什么。

## 一、什么人适合走模拟器这条路

模拟器本身就是一台跑在电脑里的安卓设备，Auto Clicker 在里面的用法和手机上完全一样。适合的场景：

- 要反复点某个网页按钮、桌面小游戏的按钮，鼠标直接点也行，但连点几百下交给模拟器里的 Auto Clicker 更省手；
- 挂机时间长，不想让手机整夜亮屏发热；
- 想边挂机边用电脑干别的。

## 二、装模拟器与装应用

以 BlueStacks 为例（它官方页面就收录了 Auto Clicker - Automatic tap 这款应用，其他安卓模拟器同理）：

1. 到 BlueStacks 官网下载安装包，装进电脑；
2. 启动后登录 Google 账号，打开内置的 Play 商店；
3. 搜「Auto Clicker - Automatic tap」安装；装不了 Play 商店的环境，把网盘里的 apk 拖进模拟器窗口，模拟器会自动安装；
4. 打开应用，走一遍和手机上相同的权限开启流程。

## 三、模拟器里照样要开两项权限

模拟器里的安卓系统自带完整的设置界面，无障碍服务和悬浮窗权限都在里面开，步骤与手机一致，细节见[无障碍权限开启与掉线排查](无障碍权限开启与掉线排查.md)。模拟器的省电策略一般比真机宽松，服务被杀的概率也更低——这也是模拟器挂机更稳的原因之一。

## 四、电脑性能参考

以 BlueStacks 5 官方给出的最低配置为准（以官网页面为准）：

| 项目 | 最低要求 |
| --- | --- |
| 系统 | Windows 7 及以上，macOS 11（Big Sur）及以上 |
| 处理器 | Intel、AMD 或 Apple Silicon |
| 内存 | 4GB 起 |
| 磁盘 | 10GB 可用空间 |
| 权限 | 需要电脑管理员身份 |

## 五、两个要注意的差异

1. **落点不通用**：模拟器的分辨率和长宽比通常与手机不同，手机上导出的配置脚本导进模拟器后，目标点位置多半对不上，需要重新摆一轮再保存（迁移流程见[配置脚本导入与导出](配置脚本导入与导出.md)）；
2. **风控叠加**：带反作弊的联网游戏对模拟器环境本身就比较敏感，再叠加自动化操作，被判定违规的可能性比真机更高，用之前掂量账号的分量。单机类、放置类没有这层顾虑。

模拟器里点不动、面板出不来这类问题，先按[常见问题与使用注意](常见问题与使用注意.md)的速查表走一遍，思路与真机一致。
