## 一、先选对阅读方向

漫画的阅读方向装反了是新手最常见的别扭来源，先按内容类型选：

| 你看的内容 | 建议模式 |
| --- | --- |
| 日漫（单页扫描） | 单页模式，从右往左翻（R→L） |
| 条漫/韩漫（长条图） | 垂直滚动（上下滑） |
| 欧美漫画 | 单页模式，从左往右翻（L→R） |
| iPad 上看跨页 | 双页模式 |

方向调错的最直观信号：翻页顺序「对不上剧情」，或者条漫被切成一页一页的。在阅读界面里调出设置菜单即可切换。

## 二、翻页与阅读操作

- **音量键翻页**：单手握持时最实用，设置里打开后按音量+/-就能翻页；
- **自动翻页**：设置里可调翻页速度，适合边做别的事边看；看条漫时也能用；
- **点按区域翻页**：屏幕左右区域对应前进/后退，配合阅读方向自动适配。

## 三、界面与外观

- **背景颜色**：阅读页背景支持自定义颜色。看白底扫描件选黑或深灰能明显降低刺眼感；
- **深色模式**：跟随系统或应用内单独设置，夜间阅读建议直接开；
- **自定义封面**：书架里的漫画可以换封面——导入的本地文件若封面识别不对，手动指定一张图即可。

## 四、按场景组合的推荐配置

| 场景 | 推荐组合 |
| --- | --- |
| 被窝里看日漫 | 深色模式 + 黑色背景 + 音量键翻页 |
| 通勤看条漫 | 垂直滚动 + 自动翻页关（手动滑更跟手） |
| iPad 躺着看 | 双页模式 + 自动翻页 |
| 看自己导入的扫描件 | 单页 R→L + 深色背景 |

设置项的具体位置随版本略有差异（1.8.x 与 2.x 的菜单组织不同），找不到时在阅读界面内点屏幕中间呼出菜单最稳妥。

外观调顺之后，如果接下来要解决的是「源挂了」「搜不到书」「闪退」这类问题，直接去 [常见问题排查.md](常见问题排查.md)；还没装好的先看 [下载与安装教程.md](下载与安装教程.md)。
