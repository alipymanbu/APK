## 一、版本线速览

以官方商店与发布渠道的更新记录为据（日期以对应商店页为准，个别版本在不同渠道的收录日期略有出入）：

| 版本 | 时间 | 关键变化 |
| --- | --- | --- |
| 1.8.0 | 2025-02 | 常规修复 |
| **1.8.4** | 2025 年春（本文网盘包所在版本） | 介于 1.8.0 与 2.0.0 之间的版本 |
| 2.0.0 | 2025-03 | 大版本更迭起点 |
| 2.0.1 | 2025-03 | 紧急修复：上一版在旧系统上的崩溃 |
| 2.0.8 | 2025 下半年 | 修复 MP 源的图片显示问题 |
| 2.1.0 | 2025-12 | 新增失效源切换器；修 WC 源简介缺失 |
| 2.1.1 / 2.1.2 | 2026-01 | 两连发：稳定性与崩溃处理 |
| 2.1.3 | 2026-03 | 修复刷新时 Too many requests 报错 |
| 2.2.2 / 2.2.3 | 2026-05 / 06 | 热修复；大章节列表的性能优化 |
| 2.2.4 | 2026-08（截至 2026-09 的最新版） | 修复 WC 源 |

从记录能读出两件事：一是 2.0.x 是一次伤筋动骨的大改（刚发布就紧急热修），二是 2.x 的更新几乎全在「修源」和「修崩溃」上打转。

## 二、1.8.4 与 2.x 的实际差异

对你日常使用有影响的主要是这四点：

- **失效源的处理**：2.1.0 起应用内置「源切换器」，源挂了可以切到备用；1.8.4 只能手动移除再重加（处理思路见 [漫画源添加与管理.md](漫画源添加与管理.md)）；
- **刷新限流**：2.1.3 专门修了 Too many requests；1.8.4 遇到这个报错只能靠少刷、等一等；
- **系统要求**：2.2.4 在第三方商店页标注需 Android 11 及以上（体积约 67MB，以商店页当时显示为准）；1.8.4 对系统的要求没有官方数字，老设备装不进新版时，旧版反而是唯一选项；
- **性能**：2.2.3 针对章节特别多的作品做了优化，收藏了大量长篇的话新版翻列表会顺一些。

## 三、升还是不升

两种情况各有道理：

| 你的情况 | 建议 |
| --- | --- |
| 设备较新、追的源正好在 2.x 修过（MP/WC 等） | 升级收益明显，去官方渠道装新版 |
| 老设备（Android 11 以下）、手上 1.8.4 用着没毛病 | 留在旧版；新版可能装不上 |
| 已经在 1.8.4 上配好了源和本地库 | 升级前先想清楚：换版本后源要重新核对，配置未必原样保留 |

想继续用或重装 1.8.4，从 [MangaBoya 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b3e3ac6b95e0) 取包即可，安装步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 四、查新版去哪看

- 官网（含安卓发布页入口）：[mangaboya.github.io](https://mangaboya.github.io/)；
- iOS 在 App Store 的应用页直接看「版本历史」；
- 官方说明里明确写过「应用界面目前仅提供英文」——个别第三方市场把语言标成中文，以官方说法为准，别因此误装了来路不明的「汉化包」。

升级后第一次打开如果发现源都空了，属于正常现象，按 [漫画源添加与管理.md](漫画源添加与管理.md) 重新添加即可；升级过程中遇到报错，先去 [常见问题排查.md](常见问题排查.md) 对一遍现象。
