## 一、安装前先对一遍信息

GammaAI 是一款安卓端的 AI 助手应用，功能覆盖 AI 对话、AI 绘画、PPT 大纲与常用写作模板。安装之前，先核对你手头这份安装包的基本信息：

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.0.1 |
| 安装包大小 | 约 28.19 MB |
| 包名 | com.aigamma.qyyd |
| 系统要求 | 安卓 5.2 及以上 |
| 开发者 | 深圳市青云跃动科技有限公司 |

你的手机安卓版本在「设置 → 关于手机」里能查到，低于 5.2 的设备装不上。这份安装包来自网盘而不是应用商店，第一次安装时系统会要求允许「安装未知来源应用」，处理方式见第三节。

## 二、从夸克网盘拿安装包

1. 在手机上打开 [GammaAI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/dbf16979cba3)；
2. 建议先转存再下载：在分享页勾选文件，选「保存到网盘」转存到自己账号（按钮名称以夸克 App 实际版本为准）——转存之后，下载就不受这条分享链接后续变化的影响；
3. 打开夸克 App，在「我的文件」（网盘文件列表）里找到转存的文件夹，点其中的 APK 文件开始下载；
4. 下载完成后，在通知栏或夸克 App 的传输列表里点开安装包（文件名形如 `gammaai_v1.0.1.apk`）。

担心文件下坏了，可以按 [常见问题与注意事项.md](常见问题与注意事项.md) 里的方法核对 MD5。

## 三、安装步骤

1. 点开下载好的 APK 文件，系统弹出「是否安装」的提示；
2. 如果被系统拦下，需要先允许「安装未知来源应用」：不同品牌手机的入口名称略有差异，最快的办法是在系统设置的搜索框里搜「未知来源」或「安装未知应用」，找到开关后，允许给「浏览器」或「文件管理」（取决于你从哪里点开的安装包）；
3. 回到安装弹窗继续，装完点「打开」，或从桌面点 GammaAI 图标进入。

装不上的其他原因（存储空间不足、版本不匹配等）也整理在 [常见问题与注意事项.md](常见问题与注意事项.md) 里。

## 四、第一次打开：注册登录

1. 打开应用，点右上角的头像图标；
2. 按页面提示完成登录，没有账号就先注册一个（具体验证方式以应用内实际显示为准）；
3. 登录后回到首页，顶部导航的四个板块（灵感、绘画、对话、应用）就都能进了。

## 五、它要哪些权限

以下是官方应用商店公示的权限，以及常见的用途方向，供参考（以应用实际申请为准）：

| 权限 | 常见用途 |
| --- | --- |
| 网络访问、查看网络与 WLAN 状态 | AI 生成与登录都依赖联网，属于基础权限 |
| 读取与写入存储空间 | 保存生成的图片等文件 |
| 在其他应用上层显示 | 部分界面以悬浮形式展示 |
| 请求安装文件包 | 处理安装包相关操作 |
| 防止手机休眠、控制振动 | 生成等待时保持运行、提供操作反馈 |

介意的话，可以在「系统设置 → 应用 → GammaAI → 权限」里逐项查看和调整；权限与隐私政策的完整公示可在 [应用宝的 GammaAI 页面](https://sj.qq.com/appdetail/com.aigamma.qyyd) 查看。

## 六、网盘版本和应用商店版本不一样？

- 网盘这份是 1.0.1 版；截至本篇写作时，[应用宝页面](https://sj.qq.com/appdetail/com.aigamma.qyyd)显示的版本是 1.0.3（2025-03 更新，以商店页面实时显示为准）；
- 想用商店新版，直接去应用商店搜 GammaAI 更新即可；
- 本篇的界面描述基于 1.0.1，新版本界面可能略有差异，但安装与登录流程大体一致。
