## 一、安装前先对一遍信息

fakku 是一款安卓端的漫画阅读应用，内置漫画与小说两个板块。安装前建议先核对手里这份安装包的基本信息，避免装到别的同名应用：

| 项目 | 信息 |
| --- | --- |
| 版本 | 5.2.44 |
| 包名 | `com.itcode.reader` |
| 安装包大小 | 9.73 MB |
| MD5 | `F4CEBFD31BAABDB2E39718B00B37BF00` |
| 系统要求 | 安卓系统 5.2 以上（渠道标注不一，见下） |
| 界面语言 | 简体中文 |

几点说明：

- 以上是这份安装包的实测信息，不等于官方最新版。fakku 的版本迭代较快，网上能搜到更新的版本号，属正常现象，以你实际拿到的安装包为准。
- 系统要求各渠道标注不一致：有标「安卓系统 5.2 以上」的，也有标「安卓系统 4.3 以上」的。稳妥起见按 5.2 以上准备；如果你的系统在 4.3~5.2 之间且装得上，以实际能装能用为准。
- 这是一份 APK 安装包，不是从应用商店直接装的，安装时系统会提示「来自未知来源」，属于第三方安装包的正常提示。
- 渠道信息里把这款应用标注为「年满十六周岁以上」使用，给未成年人安装前请留意这一点。

## 二、从哪里获取安装包

安装包放在夸克网盘里，获取方式：

1. 打开 [fakku 安装文件资源（夸克网盘）](https://pan.quark.cn/s/86a796df3321)；
2. 把文件转存到自己的网盘（夸克网盘的分享需要转存后才能下载）；
3. 在网盘客户端里把 APK 下载到手机存储。

如果是在电脑上下载的，把 APK 通过数据线、微信文件传输助手等方式传到手机后再装，别直接在电脑上双击。

## 三、安装步骤

1. 在手机文件管理里找到刚下载的 APK，点它；
2. 系统弹出「是否允许安装」时选允许。不同品牌的入口略有差别：
   - 小米 / 红米：提示「出于安全考虑，已禁止安装」时，点「允许本次安装」，或到「安装未知应用」里给对应来源授权；
   - 华为 / 荣耀：会跳到「允许安装未知应用」页面，给文件管理或浏览器打开开关；
   - OPPO / vivo：类似，在弹出的页面里允许对应来源安装应用；
3. 授权后回到安装界面，点「安装」，等进度走完；
4. 装完可以点「打开」直接进入，或以后从桌面图标进。

存储权限要到首次使用离线缓存时才会用到，第一次弹窗建议允许，否则后面缓存漫画会失败，详见 [离线缓存与下载管理.md](离线缓存与下载管理.md)。

## 四、装不上时的排查顺序

- **提示「解析包出现问题」或「安装包损坏」**：先核对 MD5 是否为 `F4CEBFD31BAABDB2E39718B00B37BF00`，不一致说明下载过程出了问题，删掉重新下载一份再试；
- **提示「已有更高版本」或安装失败**：手机里可能装过别的版本，先卸载旧版再装；
- **存储空间不足**：9.73 MB 的安装包本身不大，但安装过程需要额外空间，至少留出几百 MB；
- **系统版本太低**：系统远低于渠道标注的「安卓系统 5.2 以上」时可能装不上，这是硬性要求；
- 装上了但打不开、闪退之类的问题，转到 [常见问题排查.md](常见问题排查.md)。
