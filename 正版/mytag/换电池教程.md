# myTag 换电池教程

> 本篇讲 myTag 防丢器用什么电池、怎么开壳更换、装好后怎么确认通电，以及低电量时设备的行为变化。

防丢器用久了两件事最常见：响铃没声音了、地图长时间不更新。这两件事大概率是同一件事——电池电量低了。自己换一颗电池就能解决，不用换整机。

## 一、用什么电池：CR2032 纽扣电池

myTag 防丢器用的是 **CR2032 型纽扣电池**（3V 锂锰扣式电池），超市、便利店都能买到，几块钱一颗。买的时候认准型号 `CR2032` 就行，不要买成 CR2025、CR2016 这类外形相近但厚度/容量不同的型号——装进去接触不良或者用不了多久。

## 二、换电池步骤

1. 沿设备**侧面的缝隙**撬开外壳——壳体侧面留了专门的开口，用指甲或薄片卡进去就能掰开；
2. 取出旧电池。取的时候**小心避开电池旁边的微动开关**，别硬抠把它怼坏；
3. 装入新电池，**正极（+）朝上**，平放进电池仓；
4. 扣回外壳，按到严丝合缝。

全程不需要螺丝刀，也不用任何工具。

## 三、装好后怎么确认通电

新电池装到位后，设备应该马上给你两个信号：

- **响两声蜂鸣**；
- **红色指示灯闪两下**。

两个信号都有 = 通电正常。没声音先检查电池是不是装反了、正极是不是朝上；还没反应就把电池取出来重装一次，确认触点干净、电池放平。通电正常但应用里搜不到设备的话，按 [配对激活教程.md](配对激活教程.md) 重新走一遍搜索配对，或者翻 [常见问题与解决方法.md](常见问题与解决方法.md) 的「添加设备失败」一节。

## 四、低电量时设备会有什么表现

电池快耗尽时，设备会**优先保住定位上报，主动关掉发声**。对应到使用中的感受就是：

| 现象 | 说明 |
| --- | --- |
| 地图上还查得到位置 | 低电量下定位上报仍在工作，正常 |
| 附近查找点了响铃没声音 | 设备已主动关闭发声，不是坏了 |
| 喇叭图标变灰 | 超出蓝牙范围或电量过低，先走近再试 |

所以「还查得到位置、但怎么点都不响」就是该换电池的信号。详见 [附近查找与响铃.md](附近查找与响铃.md) 第五节。

## 五、换完电池要重新配对吗

一般**不用**。换电池只是给设备断电再通电，你的账号和设备的绑定关系存在云端，装好后应用里这台设备照常能用。

两种情况例外：设备此前被**解绑**过（解绑会重置设备并清空位置信息），或者换电池后设备始终搜不到——这两种都按 [配对激活教程.md](配对激活教程.md) 重新走一遍配对激活即可，授权码还是包装卡片上那串。

## 六、安全提醒

纽扣电池要**放在儿童和宠物够不到的地方**：一旦被吞下，电池会在体内持续放电造成严重烧伤，官方手册对此有明确警告。万一发生误吞，立即就医。旧电池不要随手丢在桌上，用胶带贴住两面包好再丢弃。
