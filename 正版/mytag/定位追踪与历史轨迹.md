用 myTag 找东西之前，先弄清楚它的定位逻辑很重要——它和车载 GPS 定位器不是一回事，预期对不上就容易觉得「定位不准」。

## 一、定位是怎么来的：靠周围手机接力，不是 GPS

myTag 防丢器内部**没有 SIM 卡、没有 GPS 模块**，它靠的是「众人拾柴」式的蓝牙网络：

1. 防丢器持续向外发蓝牙信号；
2. 附近装了配套应用的其他用户的手机收到这个信号后，把位置匿名上报；
3. 你在应用地图上看到的，就是这些上报拼出来的设备位置。

由此有几个直接推论，写成了下面这张表：

| 场景 | 表现 |
| --- | --- |
| 设备在人流多的市区 | 上报的手机多，位置更新及时、相对准 |
| 设备在郊外、高速路上 | 周围没几台装了应用的手机，可能长时间不更新 |
| 设备在室内深处 | 信号被建筑削弱，定位点会有偏差 |
| 设备随车高速移动 | 上报有时间差，位置点会落后于实际 |

官方手册也明确写了：定位使用的是人群协作网络而非 GPS，室内或高速移动场景会出现偏差，建议结合历史轨迹核对。

## 二、在哪看位置和历史轨迹

应用主页有专门的位置历史入口，提供四个时间档：

| 档位 | 对应时段 |
| --- | --- |
| 6H | 最近 6 小时 |
| 1D | 今天 |
| 2D | 昨天 |
| 3D | 最近两天 |

切到对应档位就能看设备在这段时间里的位置记录；页面上有**刷新按钮**，点一下拉取最新位置。找东西时建议先用 3D 档看设备最后一次出现在哪，再用 6H 档缩小范围，最后切换到 [附近查找与响铃.md](附近查找与响铃.md) 里的近距离查找把它精确定出来。

## 三、位置多久更新一次：没有固定周期

这类防丢器的位置**没有固定的更新间隔**——它不是设备定时上报，而是「周围有装了配套应用、连着网的手机路过」才产生一个新的位置点。所以：

- 商场、车站、市区这类人多的地方，刷新可能几分钟一次；
- 郊外、高速路上可能几十分钟甚至更久都不动；
- 想看最新位置就点刷新按钮，然后耐心等几分钟，不要连续狂点。

换句话说，位置更新得勤不勤，取决于设备周围的人流量，不是设备本身出了问题。

## 四、位置偏差大，怎么判断和改善

看到定位点和实际位置差了几十米甚至更远，先对照这几个原因：

- **上报机制本身有时间差**：位置是「最后有人路过时上报的点」，不是实时坐标；
- **室内遮挡**：墙、金属柜、电梯井都会让上报点飘；
- **高速移动**：设备在移动的车上时，轨迹点会滞后。

改善的做法只有一个方向：**让设备周围有更多装了应用、连着网的手机**。比如丢在商场里，位置通常比丢在空旷停车场更新得更勤。

## 五、地图上完全没有位置数据

设备激活后一直看不到任何位置点，按这个顺序排查：

1. 确认防丢器是**通电状态**（开机时该响两声、红灯闪两下）——断电的设备不会发信号，自然没有任何上报；
2. 确认设备所在的区域不是人烟稀少的地方，官方建议**把设备带到人多一些的区域**，等周围手机来上报；
3. 回主页点刷新，稍等几分钟再看。

如果设备有电、也到了人多区域还是没数据，先检查手机网络和应用权限（见 [常见问题与解决方法.md](常见问题与解决方法.md)），必要时把设备解绑后按 [配对激活教程.md](配对激活教程.md) 重新激活一次。
