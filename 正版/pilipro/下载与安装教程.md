## 一、装机前先弄清三件事

- **这是安卓安装包（APK）**：pilipro 以 APK 形式分发，装在安卓手机上。它不是应用商店里的上架应用，安装方式与普通 APK 相同。
- **它是第三方开发的客户端**：pilipro 是爱好者开发的哔哩哔哩第三方客户端（PiliPlus 系的升级分支），并非 B 站官方出品。它不需要替代官方客户端——包名不同，两者可以共存。
- **版本以你拿到的那份为准**：网盘资源里是 1.7.5 版（约 24.68 MB）。网上能搜到的可能已是别的版本号，第三方客户端没有应用商店的自动更新，版本事项见「更新与版本管理」。

## 二、从夸克网盘转存安装包

安装包通过网盘分享获取：[pilipro 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f664ac78d89a)。

1. 复制链接在浏览器打开，或直接在夸克 App 里打开；
2. 点「保存到网盘」，把分享内容转存到自己网盘（转存后再下载，比直接下载更稳，不怕原分享失效）；
3. 在「我的网盘」里找到转存的文件夹，勾选 APK 文件下载到手机。

手机上不方便时用电脑也行：先把 APK 下载到电脑，再通过数据线、局域网传输或聊天工具传到手机。

转存后找不到安装包时：在夸克 App 的搜索里输 `apk` 或按文件夹名搜一遍；再不行回「我的网盘 → 最近转存」里看。

## 三、安装步骤

1. 在手机文件管理器里找到下载好的 APK（文件名形如 `pilipro_v1.7.5.apk`）；
2. 点开安装。系统第一次会拦一下，提示「不允许安装未知来源应用」——按提示跳到设置，给对应来源（浏览器或文件管理器）开「允许安装未知应用」权限；
3. 回到安装界面继续，等安装完成；
4. 打开应用，首页直接出现推荐内容，没有额外的初始化向导。

## 四、常见品牌的「未知来源」开关位置

各品牌叫法和路径不完全一样，大致在以下位置（以手机系统实际为准）：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装未知应用（或「其他设置」） |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 允许安装未知应用 |
| 三星 | 设置 → 应用程序 → 特殊权限 → 安装未知应用 |
| 原生类（Pixel 等） | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

授权对象是「你用来打开 APK 的那个 App」（浏览器、文件管理器、网盘客户端），不是给整个系统开门；装完后可以把这个授权关掉。

## 五、核对安装包（可选）

在意包是否被改动过的话，安装前可以核对 MD5：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.7.5 |
| 包名 | com.example.pilipro |
| 大小 | 约 24.68 MB |
| MD5 | 191637B3D314C42A93C156474DDE0701 |

核对方法：部分文件管理器在文件「详情 / 属性」里直接显示 MD5；电脑上可以用 `certutil -hashfile 文件名 MD5`（Windows）比对。数值完全一致，说明文件没有损坏、也没有被改过。

## 六、装不上时的排查

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包出错」 | 下载不完整或传输中断 | 重新下载一次，核对 MD5 |
| 安装按钮一直灰色 | 存储空间不足 | 清出至少 1 GB 空间再试 |
| 提示与已装应用冲突 | 之前装过旧版本 | 直接覆盖安装；装不上再卸载旧版（注意先看本地存档要不要保，见[弹幕与评论保存](弹幕与评论保存.md)） |
| 安装完成后打开就闪退 | 系统版本或机型兼容问题 | 重启手机再开一次；仍闪退见[与官方客户端的区别及常见问题](与官方客户端的区别及常见问题.md)的排查表 |

装好之后第一件事通常是登录自己的 B 站账号，具体见[登录与账号同步](登录与账号同步.md)。
