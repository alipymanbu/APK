## 一、播放器的基本手势

进入播放页后，点一下画面呼出控制栏，再点一下收起。这一系客户端的手势约定大同小异：

| 手势 | 作用 |
| --- | --- |
| 双击画面左 / 右 | 快退 / 快进（幅度可在设置里调） |
| 左半边上下滑动 | 调亮度 |
| 右半边上下滑动 | 调音量 |
| 水平方向滑动 | 拖动进度 |
| 长按画面 | 临时倍速，松开恢复 |

以你版本的实际表现为准；具体行为在设置的「播放」分区里都有对应开关。

## 二、画质、音质与解码

- **画质**：播放页右下角设置里切换。可选档位取决于两件事——视频本身上传了哪些档位、你的账号权益解锁了哪些档位。第三方客户端同样按账号权益显示档位，1080P 及以上的档位通常要求登录（登录见[登录与账号同步](登录与账号同步.md)）。
- **音质**：与画质在同一处设置，部分视频提供更高码率的音质选项。
- **解码方式**：设置里可选硬解 / 软解。画面卡顿、绿屏、花屏时先切软解——软解更吃性能，但兼容面更广；反过来，软解卡就切回硬解。
- **倍速**：控制栏的倍速按钮里选常用档位；看长视频时长按画面临时加速更顺手。
- **追番相关**：同系客户端普遍带「跳过番剧片头 / 片尾」（默认跳一次，可在设置关）与高能进度条（进度条上标出热门片段的位置），追连载时好用；你的版本有没有，以设置里实际出现的项为准。

## 三、离线缓存与后台播放

- **缓存视频**：视频页里找「缓存」入口，选画质后开始下载；同系客户端普遍支持批量缓存、断点续传与自定义保存位置（设置 → 下载相关分区）。缓存同样受账号权益限制——高画质档位要求登录。
- **缓存内容也是本地的**：卸载即没，不跟账号走；换机不能直接迁移，重新缓存即可。
- **后台播放**：设置里开「后台播放」后，切出画面只留声音，适合当播客听；配合系统媒体通知栏控制播放。
- **定时关闭**：睡前挂视频的话，看看设置里有没有定时停止项（同系普遍有），免得醒来说了一夜。

## 四、应用内小窗：视频和直播都行

小窗是 pilipro 相对同系前作的主要差异之一：视频和直播都能缩成悬浮小窗，边刷列表边挂着看。

- **怎么用**：在播放页触发小窗（小窗按钮或返回手势，以你版本为准），画面缩成可拖动的悬浮块；
- **悬浮块操作**：拖到屏幕任意位置、调整大小，具体手势以实际版本为准；
- **和系统画中画的区别**：应用内小窗只在 pilipro 自己的界面里悬浮，切到别的 App 会中断；系统级画中画则是悬浮在其它应用之上。两者不是一回事，想要「切出去还挂着看」的话，小窗满足不了；
- **直播也能挂**：进入直播间同样可以缩成小窗，一边刷首页一边挂着看直播，是它最常见的用法之一。直播的入口与直播弹幕存档见[直播观看与直播弹幕](直播观看与直播弹幕.md)。

## 五、第一次用，建议先过一遍这几项设置

1. 默认画质与移动网络下的画质策略，按自己的账号权益与流量额度定；
2. 自动全屏与横竖屏跟随方式，横屏党关掉「跟随重力」能少很多误触发；
3. 弹幕的显示区域、透明度与字号（详见[弹幕与评论保存](弹幕与评论保存.md)）；
4. 后台播放开关——只听声音的场景靠它；
5. 双击快进 / 快退的幅度，默认值未必合手。

播放设置都存本地，改错了随时改回来，放心试。
