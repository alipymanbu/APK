## 一、先对版本号

- 网盘资源里这份是 **1.0.6**（2026-09 采集）；
- 官方在 GitHub 的发布序列里，1.0.4 之后直接是 1.1.0，1.0.5 / 1.0.6 没有单独的发布说明（第三方下载站收录过 1.0.5）；
- 截至本文整理时，官方已发布到 **1.3.0**；最新版本信息以 [GitHub Releases](https://github.com/shiyi-0x7f/olib-mobile/releases) 页面为准。

## 二、1.0.x 这一代有什么

1.0.6 属于 1.0.x 这一代，以下能力在这个代际已经具备（来自 1.0.1~1.0.4 的官方更新记录）：

- 应用内阅读器（1.0.2 起内置）；
- 首页个性化书籍推荐（1.0.2 起）；
- 下载历史记录、下载前重复文件检测（1.0.2 起）；
- 下载页「分享」按钮，把书文件发给其他应用（1.0.3 起）；
- 下载页「打开文件夹」按钮，跳到系统下载目录（1.0.4 起修复可用）；
- 邮箱密码登录、多线路切换、多主题。

## 三、1.0.6 没有的新版本功能

以下功能都是升级到新版本才有的，逐条对照官方更新记录：

| 功能 | 加入版本 | 说明 |
| --- | --- | --- |
| 寻书（AI 推荐） | 1.1.0 | 输入想看的书由 AI 推荐候选，有配额限制 |
| 一键更新版本 | 1.1.0 | 应用内直接升级；1.0.6 只能手动下载新 APK 覆盖安装 |
| 收藏夹导出分享 | 1.1.0 | 把收藏夹导出给他人 |
| 主题换装 | 1.1.0 | 更多主题外观可选 |
| 跳过登录 | 1.2.0 | 启动时不登录直接进主界面；1.0.6 没有这个入口 |
| 微信读书集成 + 统一书架 | 1.2.0 | 把微信读书的书接入同一个书架 |
| 无线传书 | 1.3.0 | 手机与电脑互传书籍，扫码连接、需同一 Wi-Fi 与新版桌面端配合 |
| 扫码登录（统一账号体系） | 1.3.0 | 登录改为扫码授权，老账号首次要重新扫码；1.0.6 仍是邮箱密码登录 |

一句话判断要不要升级：只用本地导入加基础阅读，1.0.6 够用；想用寻书、无线传书、跳过登录，必须升到对应版本以上。

## 四、升级怎么走

1. 新版 APK 从官方渠道拿：[GitHub Releases](https://github.com/shiyi-0x7f/olib-mobile/releases) 或[官方页面](https://www.bookbook.space/)；
2. 下载后直接覆盖安装；书架与设置是否保留以实际表现为准，覆盖前把重要的本地书文件在电脑上留一份（安装权限的开启方法见 [下载与安装教程.md](下载与安装教程.md)）；
3. 升到 1.3.0 及以上后，登录方式换成扫码，老账号首次使用要重新扫码授权一次，流程见 [登录与线路选择.md](登录与线路选择.md)；
4. 1.0.6 没有应用内「一键更新」（1.1.0 起才有），只能按上面手动覆盖。
