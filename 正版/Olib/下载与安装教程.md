## 一、装之前先了解这几点

Olib 是一个开源的安卓电子书阅读客户端，源码与项目说明托管在 [GitHub](https://github.com/shiyi-0x7f/olib-mobile)，采用 MIT 许可证。按项目自己的定位，它是一个**第三方客户端**：应用本身只负责界面与阅读功能，在线搜书、下载书的数据来自外部书源，这部分需要登录对应的书源账号才能用。

本文对应的安装包信息如下（这是网盘资源里那一版的事实；官方项目仍在更新，页面上的最新版本可能已经往前走了）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.6 |
| 包名 | `com.olib.read` |
| 安装包大小 | 约 47.22 MB |
| MD5 | `ACD31A3F3375681592B519696B0EE145` |
| 适用平台 | 安卓手机 |

最低安卓系统版本这类要求以[官方页面](https://www.bookbook.space/)为准。APK 属于侧载安装（不走应用商店），所以第一次装要先开一次安装权限，下面分开讲。

## 二、获取安装文件

打开本文开头的 **Olib 安装文件资源（夸克网盘）** 链接，把里面的 APK 先转存到自己的网盘，再从网盘下载到手机——夸克网盘的分享链接需要先转存才能下载。也可以在电脑上下载后，用数据线把 APK 拷进手机的「下载（Download）」目录。

下载完成后核对一下：APK 文件大小在 47 MB 上下，文件名以网盘内实际文件为准。

## 三、开启安装权限

点开 APK 时安卓会拦一次，提示「出于安全考虑，您的手机目前不允许安装此来源的应用」。放行方法（不同品牌叫法略有差异）：

1. 弹窗里直接点「设置」→ 打开「允许来自此来源的应用」→ 返回重试；
2. 或者手动进：**设置 → 应用 → 特殊应用权限 → 安装未知应用**，找到你用来打开 APK 的那个应用（文件管理器或浏览器），打开它的「允许安装未知应用」开关；
3. 部分国产机型还会要求登录品牌账号，或先关闭「纯净模式 / 增强防护」才允许装第三方 APK，按提示临时关掉即可，装完可以再开回去。

## 四、安装与首次打开

1. 在文件管理器里点刚下载的 APK，点「安装」，等进度走完；
2. 装完点「打开」；首次启动可能询问存储权限（读取你放进手机的本地书要用），建议允许，否则本地导入功能用不了；
3. 打开后会先见到登录界面——1.0.6 这一版没有「跳过登录」入口（那是 1.2.0 版才加入的功能），需要先登录书源账号，步骤见 [登录与线路选择.md](登录与线路选择.md)；
4. 本地导入阅读的功能本身不依赖账号，登录完成后就能用，做法见 [本地书导入与书架管理.md](本地书导入与书架管理.md)；这版有哪些功能、新版本多出了什么，见 [更新日志与版本差异.md](更新日志与版本差异.md)。

## 五、装不上或打开就闪退

- 提示「解析包出现问题」：多半是下载不完整，重新下载一次；有条件的话用 MD5 值（见第一节表格）核对文件完整性；
- 点了没反应：确认打开的是 `.apk` 文件本身，不是网盘的分享页面；
- 装上了但一打开就退出：先确认手机剩余存储空间够用（安装包约 47 MB，还要给书籍缓存留余量）；仍不行就到 [常见问题与解决方法.md](常见问题与解决方法.md) 里对症排查。
