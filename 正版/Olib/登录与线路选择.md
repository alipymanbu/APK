## 一、为什么打开就要求登录

Olib 是一个第三方阅读客户端：项目方只做了前端界面，在线搜书、下载书的数据全部来自外部书源。这意味着：

- **Olib 自己不发账号**——你在它里面登录的不是「Olib 账号」，而是外部书源的账号；
- 想用在线搜索与下载，先得在所选书源那边有账号；书源怎么选、怎么注册，以[项目官方页面](https://www.bookbook.space/)与应用内的说明为准；
- 本地导入阅读的功能本身不依赖账号，但 1.0.6 这版启动后要先过登录这一关（「跳过登录」入口是 1.2.0 起才有的），导入做法见 [本地书导入与书架管理.md](本地书导入与书架管理.md)。

## 二、登录的一般流程

打开 App 后的大致步骤（不同版本界面措辞可能略有差异，以实际界面为准）：

1. 进入登录界面；
2. 先选一条线路（见下一节）；
3. 输入你在书源侧注册用的邮箱和密码；
4. 点登录，成功后即可搜索与下载。

1.0.6 用的是**邮箱密码登录**；扫码登录（配合统一账号体系）是 1.3.0 起才有的新方式，两者的差别见 [更新日志与版本差异.md](更新日志与版本差异.md)。

账号注册这一步请在所选书源的官方网站自行完成，Olib 内部不提供注册入口。第三方书源的注册渠道与可用性随时间和地区变化较大，本文不列具体地址，以官方页面和应用内提示为准。

## 三、线路是什么、怎么选

「线路」指的是客户端连接外部书源用的不同服务器入口，同一个账号在不同线路上都能登录。项目把「多线路」作为内置特性，就是为了某条线路连不上时可以换另一条。

选择上没有玄学，按这个顺序试：

1. 默认线路先试一次；
2. 登录超时或搜索一直转圈 → 换一条线路再登录；
3. 换线路后要重新搜一次，原来的搜索结果不会自动刷新。

## 四、多账号切换

Olib 支持保存多个账号并在它们之间切换，适合这些场景：

- 你在书源侧有不止一个账号（一个日常用、一个备用）；
- 家里多人共用一台设备，各自用自己的账号。

切换入口在账号/设置相关的界面里。切换后书架与下载记录是否跟着账号走，以当前版本的实际表现为准——切换前先把重要的下载文件确认清楚。

## 五、登录不上的常见原因

按出现概率从高到低：

| 现象 | 先检查什么 |
| --- | --- |
| 一直转圈不出结果 | 换一条线路；确认手机能正常上网 |
| 提示密码错误 | 确认登录的是书源账号，不是把 Olib 当成有独立账号的应用 |
| 账号密码正确但仍登录失败 | 书源侧可能限制登录频率，或该线路暂时不可用；隔一段时间再试或换线路 |
| 报错笼统、看不出原因 | 1.0.x 这一代的报错信息比较笼统；1.3.0 起登录失败会明确指出是不是线路被拦，老版本只能逐条换线路试 |
| 之前能用现在不行 | 书源侧入口会变化，关注项目官方页面的说明 |

更多排查思路见 [常见问题与解决方法.md](常见问题与解决方法.md)；登录搞定后，阅读界面的排版与主题怎么调见 [阅读排版与主题设置.md](阅读排版与主题设置.md)。
