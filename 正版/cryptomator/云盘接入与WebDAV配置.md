保险库可以放在云盘里，也可以只放在手机本地。放哪个云盘、能不能连上，取决于两件事：你装的是哪个渠道的变体，以及你的网盘有没有被列入直连名单。本篇把这两个变量拆开讲，最后给出 WebDAV 这条通用路。

## 一、完整功能渠道支持哪些存储位置

在 Google Play 或官网 APK 这类「完整功能」渠道上，你建库时可选的存储位置有：

| 存储位置 | 说明 |
| --- | --- |
| Dropbox | 应用内直接授权登录 |
| Google Drive | 应用内直接授权登录 |
| OneDrive | 个人版与企业版（OneDrive for Business）都可用 |
| pCloud | 应用内直接授权登录 |
| WebDAV | 任何提供 WebDAV 访问的服务都行 |
| S3 | 兼容 S3 协议的对象存储 |
| 本地存储 | 手机自身存储及外接存储设备 |

前四个需要你先有对应服务的账号；WebDAV 和 S3 是两条「万能口」，第五节展开。

## 二、你装的渠道决定了云盘被砍多少

同一个应用在不同渠道发行时，因为依赖组件的授权原因，云盘支持不一样（详见 [下载与安装教程.md](下载与安装教程.md) 的渠道对照表）：

| 渠道 | 被砍掉的云盘 | 剩下的 |
| --- | --- | --- |
| Google Play 两个变体 | 无 | 全部 |
| 官网 APK | 无 | 全部 |
| Accrescent | Google Drive | Dropbox、OneDrive、pCloud、WebDAV、S3、本地 |
| F-Droid 自建仓库 | Google Drive | Dropbox、OneDrive、pCloud、WebDAV、S3、本地 |
| F-Droid 主仓库 | Google Drive、Dropbox、OneDrive、pCloud（凡要 API 密钥的都不要） | WebDAV、S3、本地 |

已经在用某个渠道、又发现缺想要的云盘？换渠道重装（库文件在云盘里是通用的，换渠道不影响数据）或者在第五节里看 WebDAV 路线能不能绕过去。

## 三、云盘账号在哪连、在哪登出

首页右上角菜单进「Settings」（设置），第一组就是「Cloud Services」（云服务）：列出应用支持的全部服务，点某个服务就启动它的授权登录；已经登录过的，再点就是登出。

你在建库或添加已有库的流程里没连过账号也不用专门跑这一步——流程会自动把你带到登录页。专门进设置连账号的场景是：换账号、登出某个不再用的服务、或者云端授权过期后重新登录。

## 四、连接失效了怎么处理

打开库时如果一直转圈或报授权错误，多数是云盘的登录态过期了：

1. 进设置 → Cloud Services，点对应服务重新登录一遍。
2. 回到库列表重新解锁。

个别网盘会定时收回长期授权，隔一阵要重连属于正常现象；如果重连后还是报错，把该云盘官方应用也更新到最新再试。

## 五、用 WebDAV 接入其他网盘和 NAS

列表之外的服务，只要提供 WebDAV 访问就能用：建库或添加已有库时，存储位置选「WebDAV」，填服务器地址、账号、密码即可。常见可用对象包括自建 NAS、Nextcloud、以及各家提供 WebDAV 接口的网盘。

- 服务器地址以你的服务商给的为准，通常是一串 `https://` 开头的完整 URL，填的时候连同路径一起写全。
- 官方文档维护了一份非穷尽的服务列表和各自的接法，在 [https://docs.cryptomator.org/misc/supported-cloud-services/](https://docs.cryptomator.org/misc/supported-cloud-services/)，接不上的服务先去那页对一遍参数。
- S3 同理，填端点、桶名、密钥三件套。

## 六、不上云：纯本地存储

存储位置选「本地存储」（Local storage）时，保险库就建在手机存储或外接存储上，全程不经过任何云服务。想备份这个库，你自己用别的手段把那个加密文件夹整夹拷走即可——它本身就是一组密文，放在哪里都不怕被看到，怕的只有密码和恢复密钥丢失（见 [忘记密码与常见问题排查.md](忘记密码与常见问题排查.md)）；完整备份该拷哪些东西，见 [保险库文件夹结构与备份.md](保险库文件夹结构与备份.md) 第四节。

库建好、账号连好之后，日常解锁与文件操作见 [保险库日常使用与文件操作.md](保险库日常使用与文件操作.md)。
