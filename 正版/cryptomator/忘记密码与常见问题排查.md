这一篇收集的是你真用起来才会碰到的那些事：官方文档把它们散在各个角落，这里按「症状 → 原因 → 怎么办」集中列一遍。先说最重要的一条：这个应用里没有任何「找回」按钮，密码和恢复密钥是你唯一的钥匙，所有预防动作都围绕这一条。

## 一、忘记密码：后果与唯一出路

密码忘了，数据就解不开了——没有客服能帮你，开发者同样不能，这不是客服态度问题，而是密码从未离开过你手里。唯一的补救物是你自己备份过的**恢复密钥**（一串几十个词的文本）：

- 手上有恢复密钥 → 用它重设密码，数据完好；
- 密码和恢复密钥都丢了 → 这份数据永久无法解密，任何人都一样。

所以动作只有两个：还在用的库，确认恢复密钥已经抄出来了；还没备份的，现在就去保险库设置里把恢复密钥显示出来存好。日常流程见 [创建加密保险库步骤.md](创建加密保险库步骤.md) 的第二节。

## 二、界面点不动、按钮按下没反应

典型症状：应用开着，但屏幕上点什么都没反应，甚至出现一个提示说应用被遮挡。

原因多半不是应用坏了，而是**护眼滤镜类应用**（蓝光过滤、屏幕调色之类的工具，比如 Twilight 一类）在整个屏幕上盖了一层滤镜窗口。出于防误触安全设计，Cryptomator 检测到自己的界面被别的应用盖住时会主动禁用输入，防止假界面骗你操作。

处理按顺序试：

1. 暂时关掉（或卸载）护眼滤镜应用，再试 Cryptomator，能用就确认是滤镜引起的。
2. 确实要和滤镜共存的话：在滤镜关闭的状态下进 Cryptomator 设置，找到「被遮挡时禁用应用」（Block App When Obscured）开关关掉，再把滤镜开回来。官方的建议是宁可不开这个豁免——少一层滤镜更安全。
3. 想查出还有谁会盖在别的应用上面：系统设置 → 应用 → 右上角菜单 →「显示在其他应用上层」（不同机型入口名略有差异），列表里就是全部嫌疑对象。

## 三、截不了图、录不了屏

你尝试给 Cryptomator 界面截图，系统直接提示禁止——这不是故障，是应用的防截屏安全开关在起作用，防止别的应用在后台偷录你的解密内容。

临时需要截图（比如设备带外接显示器）：设置里有对应的「屏幕安全」（Screen Security）开关，关掉后即可截屏，截完建议再开回去。

## 四、库老是被自动锁定

后台切换出去一会儿回来就要重新输密码，这是自动锁定在按设置工作。调整位置：设置 → Automatic Locking，可选 1 / 2 / 5 / 10 分钟或永不；下面还有单独的「熄屏时锁定」开关，嫌熄屏就锁太频繁的话把它关掉，只按时间超时来锁。

具体每档的取舍见 [保险库日常使用与文件操作.md](保险库日常使用与文件操作.md) 第五节。

## 五、指纹开关不见了或用不了

按顺序核对：

1. 设备有没有指纹硬件、系统里有没有录入指纹——两者缺一，Cryptomator 里的指纹开关就不会出现；
2. 设置里的指纹总开关是否打开、该保险库的单独开关是否打开；
3. 首次启用要求先用密码解锁一次该库，这一步没做指纹不会生效；
4. 指纹解锁依赖设备帮你保存密码，锁屏方式太弱（比如无锁屏）时部分系统会拒绝提供凭据存储，先把锁屏设成带生物识别或强密码。

## 六、云盘打不开、一直转圈或报授权错误

多见于隔了一段时间没用：

1. 设置 → Cloud Services，点对应云盘重新登录；
2. 回到库列表重新解锁；
3. 还是报错就把该云盘的官方应用更新后重试。

WebDAV / S3 类型连不上时，核对服务器地址、端口、路径是否与服务商给的一致，更多见 [云盘接入与WebDAV配置.md](云盘接入与WebDAV配置.md) 第五节。

## 七、版本对不上时怎么办

网盘里那份安装包是 1.12.0（核对信息见 [下载与安装教程.md](下载与安装教程.md)），官网最新版已是 2.x。你发现某个设置项位置或功能和本篇描述不一致时，先看版本号，再以你手机上的实际界面为准；确实需要新版本行为的话，从官方渠道装最新版，不要把两个来源的包混装在一起猜。

版本差的另一种典型表现是解锁时直接报「格式不支持 / 版本不支持」——那是库的格式被别的设备上的新版应用升级过了，处理思路和版本对齐建议单独写在了 [保险库格式升级与版本兼容.md](保险库格式升级与版本兼容.md)。
