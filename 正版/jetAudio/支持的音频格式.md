## 一、格式清单

jetAudio 对音频格式的覆盖比系统自带播放器宽得多，官方说明里列出的格式按用途整理如下：

| 用途 | 格式 |
| --- | --- |
| 常见有损 | MP3、OGG、OPUS、M4A、SPX（Speex） |
| 无损 | FLAC、APE（Monkey's Audio）、WV（WavPack）、TTA（True Audio） |
| PCM / 苹果系 | WAV、AIFF |
| 模块音乐 | MOD 及 S3M、IT 等模块子格式 |
| 其他 | MPC（Musepack）、WMA（见下）、MIDI（见下） |

两个结论可以直接记：

- **无损不用转码**：FLAC、APE、WV、TTA 都能直接播，不需要先压成 MP3；
- **模块音乐能放**：MOD/S3M/IT 这类老格式很多播放器早就砍掉了，jetAudio 还保留着。

## 二、两个例外：WMA 与 MIDI

这两个格式不是装上就能放，官方说明里明确带了条件：

- **WMA**：能不能放取决于设备。部分手机的系统解码器不支持 WMA，官方原话是「部分设备可能不支持，请核对你设备的规格」。遇到放不出来的 WMA，最省事的路径是转成 MP3 或 FLAC，而不是反复折腾播放器设置；
- **MIDI**：靠内置的 jetAudio WaveTable MIDI 合成器引擎播放，这是 Plus 版功能（差别见 [免费版与Plus版区别.md](免费版与Plus版区别.md)）。

## 三、放不出来时按这个顺序排查

1. **先看扩展名在不在上表里** —— 尤其是从压缩包解出来、后缀被顺手改过的文件；
2. **WMA 先换一台设备试**，另一台能放就说明是你这台设备不支持，转码解决；
3. **排除文件本身损坏** —— 下载到一半断网的文件在别的播放器里同样放不出来，重新下载即可；
4. **歌在 NAS 或共享文件夹里** —— 先确认是连接问题还是格式问题，连接排查见 [局域网和云盘听歌.md](局域网和云盘听歌.md)；
5. **曲库里压根没有这首歌** —— 多半不是格式不支持，而是扫描范围被限制或目录被 .nomedia 屏蔽了，见 [音乐库整理与文件夹筛选.md](音乐库整理与文件夹筛选.md)。

## 四、手机外部的歌也能播

本地存储不够放无损时，不用删歌搬歌：家里 NAS、电脑共享文件夹、WebDAV、以及 Google Drive / Dropbox / Box / OneDrive 这些云端的音乐，jetAudio 都能直接串流播放，设置方法见 [局域网和云盘听歌.md](局域网和云盘听歌.md)。格式支持的范围和本地播放是一致的。

安装还没做的话从 [下载与安装教程.md](下载与安装教程.md) 开始。
