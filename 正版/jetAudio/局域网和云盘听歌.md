## 一、它能从哪拿歌

除手机本地存储外，jetAudio 可以直接播放这些来源的音乐（官方说明里明确列出）：

| 来源 | 例子 |
| --- | --- |
| 局域网共享文件夹 | Windows 电脑的共享目录 |
| 挂在路由器上的存储 | USB 硬盘接路由器 |
| NAS | 群晖、威联通等设备的 SMB 共享 |
| WebDAV 服务器 | 自建或第三方 WebDAV 网盘 |
| 云存储 | Google Drive、Dropbox、Box、OneDrive |

前提只有一个：**手机此刻能访问到那个网络位置** —— 家里同一个 Wi-Fi、NAS 的共享服务开着、云账号能登录。云服务在当前网络环境能不能直连取决于你自己的网络条件，应用本身不处理这件事。

## 二、连接共享文件夹（SMB）的步骤

1. 手机和共享源连同一个局域网；
2. 电脑端确认共享目录已开启、账号密码可用（Windows 的网络设置里确认「网络发现」和「文件共享」处于打开状态）；
3. 在 jetAudio 的浏览器里**添加网络位置**，按界面提示填地址、账号、密码 —— 具体入口名称随版本略有差异，在浏览器的菜单或「添加」里找 SMB / 共享文件夹 / 网络相关字样；
4. 连上后按目录挑歌播放，操作和本地文件一致。

连不上时先查三个高发原因：

- 手机用的是移动数据而不是家里 Wi-Fi；
- Windows 侧防火墙拦了文件共享；
- 账号密码没写对 —— Windows 账号有时需要写成 `电脑名\用户名` 的形式。

## 三、连云盘

浏览器里添加对应云服务、登录授权即可。两点提醒：

- 云端文件的播放流畅度由网络决定，无损大文件先试听一首，别一上来把整个云端目录塞进播放列表；
- 各家云服务的账号可用性由服务商决定，哪一个连不上就先换另一个来源，不用死磕。连不上的更多原因汇总在 [常见问题与排查.md](常见问题与排查.md)。

## 四、WebDAV 与 NAS 怎么选

WebDAV 需要填的信息和 SMB 类似：服务器地址、端口、账号、密码。家里有 NAS 的话**局域网内优先走 SMB**（通常更快更稳），人在外面、不方便连回家里网络时才走 WebDAV 或云盘。

## 五、网络播放和格式的关系

从共享文件夹或云端拿到的文件，受格式支持的约束和本地播放**完全一致**：WMA 这类设备相关的格式在网络播放里一样可能无声，对照 [支持的音频格式.md](支持的音频格式.md) 处理。还没装应用的话从 [下载与安装教程.md](下载与安装教程.md) 开始；连上之后想调音质，看 [均衡器与音效设置.md](均衡器与音效设置.md)。
