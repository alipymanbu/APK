## 一、闹钟没响 / 半夜应用被杀

这是安卓端投诉最多的一类，绝大多数不是应用本身的问题，而是系统把后台杀了。按顺序排查：

1. **电池优化白名单**：系统设置 → 应用 → Sleep Cycle → 电池，改成「不受限制 / 不优化」。国产 ROM 一般还有独立的「自启动」「后台运行」开关（MIUI 叫省电策略、ColorOS 叫应用速冻），一并放开。
2. **麦克风权限**：权限被收回（部分系统会在长期不用后自动收回）会导致追踪和闹钟逻辑都异常，去应用权限页确认麦克风仍是「允许」。
3. **音量**：闹钟走媒体音量的机型不少，睡前把媒体音量拉高；开了勿扰的话检查勿扰规则是否放行闹钟。
4. **插电**：不插电过夜、电量耗尽关机，闹钟自然不会响。
5. **多任务清理习惯**：如果你睡前习惯一键清后台，把 Sleep Cycle 加锁或关闭「清理时忽略锁定应用之外」的策略。

改完之后跑一晚验证：正常情况下早上会有完整的睡眠图。

## 二、数据明显不对劲

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 整夜显示几乎没睡 / 曲线平直 | 麦克风被挡住、手机离得太远 | 麦克风侧朝向自己、缩短距离，参考摆放四条（见[使用教程与智能闹钟设置.md](使用教程与智能闹钟设置.md)） |
| 曲线毛刺多、碎片化醒来一大片 | 环境噪音大（风扇、空调、临街车流） | 换个噪音小的位置，或关掉风扇 |
| 半夜数据从某点中断 | 后台被杀 / 手机没电 | 按上面第一节处理 |
| 显示时长明显短于实际 | 你躺下很久才点「开始睡眠」，或起身没停止 | 睡前躺好再开始；半夜起来记得结束后再继续 |

另外要建立一个预期：**声学方案给出的是行为估计，不是医学测量**。它的价值在看趋势和对照习惯，别拿某晚的深睡时长当诊断依据；真怀疑睡眠呼吸暂停这类问题，去做正规的多导睡眠监测。

## 三、打鼾与梦话录音相关

- 录音功能在付费侧，免费版没有（边界见[免费版和付费版有什么区别.md](免费版和付费版有什么区别.md)）；
- 开了录音但录不到：确认音量与摆放，鼾声检测同样依赖麦克风清晰拾音；
- 录音攒多了占空间：应用内 Profile → More → Sound Detection 里可以调低保留时长或一键清空录音（删除后不可恢复）；助眠音频缓存在 Profile → Sleep Aid 里清；
- 介意隐私的话，可以在应用设置里关闭录音类功能，历史录音也能在应用内删除；录音数据的存储与上传口径以官方隐私政策为准，删除账号与订阅的完整说明见[取消订阅与删除数据的方法.md](取消订阅与删除数据的方法.md)。

## 四、两人同床能准吗

能，但有两个已知影响：

- 应用分辨不了「你的动静」和「伴侣的动静」，对方翻身、起床会被记到你的睡眠图里；
- 如果对方也打鼾，鼾声统计会互相污染。

想减小干扰，把手机放**你这一侧**的床头柜、尽量靠近你。另外有个官方的针对性方案：如果两人都用 Sleep Cycle、且设备连着同一个 WiFi 并授予了 WiFi 权限，应用隐私设置里的「伙伴链接（Partner Link）」功能会自动配对，把两人的动静分开统计；不需要时也可以在隐私设置里把它关掉。两人的数据要彻底分开，最终还是各用各的手机各开各的会话最稳妥。

## 五、换手机 / 数据还在吗

- **关联了账号**：登录同一账号即可同步回来（云同步本身属于付费功能，见对照表）；
- **没关联账号、只本地记录**：卸载重装可能丢失本地历史，换机前先在应用内确认是否有备份途径；
- **订阅要跟着 Google Play 账号走**：换机后用同一 Play 账号在应用内恢复购买，不用重复付钱。

如果上面的排查都走完还是解决不了，剩下的多半是版本相关的个案——先更新到最新版再观察一晚；安装途径与版本说明见[下载与安装教程.md](下载与安装教程.md)。
