## 一、配对前的准备清单

动手前把这四样备齐，能省掉大半中途失败：

- Hub 已通电，放在路由器附近（官方建议信号路径上少隔墙、少放电器）；
- 手机已装好 Eight Sleep 应用并登录了账号；
- 手机能连上家里的 WiFi，且你知道 WiFi 密码；
- 手机蓝牙已打开（新机型配对必需）。

## 二、新机型（Pod 4 / Pod 3）：蓝牙配对流程

1. 应用里选择添加设备，按提示授予蓝牙权限；
2. Hub 进入配对模式后，机身指示灯会闪蓝色——这是「可以配了」的信号；
3. 在应用里选择你家 WiFi、输入密码，剩下的交给它自己连。

如果你的 Hub 没有闪蓝灯，说明它还没进配对模式：按住 Hub 背面的大按钮约 15–30 秒，直到灯开始闪蓝为止。

## 三、老机型（初代 Pod / Pod Pro / Pod 2）：热点配对流程

这批机型不走蓝牙，而是让手机临时连 Hub 自己发出的热点：

1. 应用提示后，**暂时退出应用**，打开手机的 设置 → WLAN；
2. 在 WLAN 列表里找一个名字形如 `Eight-XXXX` 的网络（XXXX 是四位的字母数字组合，每台机器不同），连上它；
3. 回到应用继续，选择你家 WiFi 并输入密码。

注意：这批机型**不支持 5GHz 频段**。如果你的 WiFi 是双频合一（2.4G 与 5G 共用一个名字），连不上时先去路由器后台把 2.4G 频段单独拆出来再试。

## 四、各代机型对 WiFi 的要求

| 机型 | 蓝牙配对 | WiFi 频段 |
| --- | --- | --- |
| 初代 Pod / Pod Pro / Pod 2 / Pod 2 Pro | 否（热点配对） | 仅 2.4GHz |
| Pod 3 | 是 | 2.4GHz 与 5GHz 都可以 |
| Pod 4 及更新的机型 | 是 | 以配对时应用内的提示为准 |

拿不准自己手里的 Hub 是哪一代的话，看随机的说明书或机身型号标识最稳；也可以先按蓝牙流程试，应用认不出设备时再改走热点流程。

## 五、配对卡住的三个常规处理

1. **确认灯的状态**：Hub 灯色变化对应不同状态，含义速查见 [Hub指示灯含义与故障排查](Hub指示灯含义与故障排查.md)。闪蓝灯 = 等待配对；常亮白灯 = 已经连上。
2. **重启 Hub**：拔掉电源，等 30 秒再插回去，然后重新走一遍配对。
3. **重置后重配**：先做基础重启——取下水箱、断电 15–30 秒、插回并装回水箱，等灯闪蓝；无效再升级到恢复出厂（按住背面小按钮通电、等绿灯闪烁松手），完整按键顺序与数据清除提醒见 [恢复出厂与二手购买注意](恢复出厂与二手购买注意.md)。

配对成功后，应用首页会出现你这一侧的当前温度与目标温度，就可以开始调温了，操作细节见 [温度调节与智能闹钟设置](温度调节与智能闹钟设置.md)。
