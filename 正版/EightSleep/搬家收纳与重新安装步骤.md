## 一、动身之前：准备两样东西

官方拆装指南要求备齐：

- **排水工具（drain tool）**：装设备时那个 tech bundle 盒子里有，专门用来放水，日常安装用不上，很多人已经找不到——找不到就联系官方客服，别用别的接头硬怼；
- **接水的容器**：大盆或桶，中途满了随时停，比换盆方便。

## 二、拆解四步

### 第 1 步：断开

握住 Cover 水管两端轻轻拔开即可。水管里带水也可以直接断开，最多滴几滴；Blanket 和 Pillow Cover 同理。

### 第 2 步：排水

- **Cover**：把水管末端架在盆上（不用把 Cover 抱下来，只要水管大部分低于 Cover 表面），排水工具咔哒扣进水管接口，水就会自己流；水流变细后用手压一压 Cover 再挤一点出来，滴不动了拆下排水工具；
- **Hub**：断开电源，取出水箱倒空，排水工具扣到 Hub 背面的接口上，架在盆上放到滴不出水；
- **Blanket / Pillow Cover**：平铺在床上、保持水管低于表面，逐侧扣上排水工具放水，轻压把残水挤出来。

### 第 3 步：收纳

- Cover：内面朝上翻过来，水管塞进 Cover 里侧防折，纵向对折两次后从下往上卷成卷；
- Hub：水箱擦干装回去，随盒或加缓冲材料打包；
- Blanket / Pillow Cover：水管收在中间，折三折或轻卷。

### 第 4 步：拆 Base（有的话）

建议两个人配合：先撤床垫，取下固定条与连接板，断开 Base 电源，把 Base 两侧对折，再从床架里抬出来。

## 三、到新家装回：多一步 priming

物理装回很简单：Cover 套上床垫、水管与 USB 线接牢 Hub、水箱加水、通电连 WiFi（流程与 [首次配对与WiFi连接步骤](首次配对与WiFi连接步骤.md) 相同）。容易跳过的是下一步：

**强制做一次 priming（排气）**：应用内 Settings → 点你的 Pod → Maintenance 里触发。水管重新接过的系统里有空气，不排气的话调温会发飘，这一步官方拆装指南里明确列了，别省。

应用里如果直接提供了 reconnect（重新连接）选项，优先用它走完上述流程，配对信息可以保留。

## 四、顺带检查一遍

装回后第一晚，顺手核对：Hub 灯是白色常亮（在线）、调温有反应、晨间报告正常刷新。哪一项不对，按 [Hub指示灯含义与故障排查](Hub指示灯含义与故障排查.md) 处理；如果这台机器是买来的二手设备，装回前应该先恢复出厂并重新绑定，见 [恢复出厂与二手购买注意](恢复出厂与二手购买注意.md)。
