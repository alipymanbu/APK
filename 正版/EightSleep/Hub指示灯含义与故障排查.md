## 一、先看灯：灯色速查表

Hub 上的灯就是它的状态屏，官方帮助中心给出的含义如下：

| 灯的状态 | 含义 | 你该做什么 |
| --- | --- | --- |
| 蓝灯闪烁 | 配对模式，等待连接 | 在应用里继续配对流程 |
| 橙色常亮（Pod 3） | 初始化中，正在连 WiFi | 等待；长时间不变查密码与频段 |
| 白色常亮 | 已配对并连上 WiFi | 正常状态，无需处理 |
| 浅蓝色常亮 | 制冷运行中 | 正常状态 |
| 粉色常亮 | 制热运行中 | 正常状态 |
| 红色发亮 | 传感器或线缆没插好 | 检查 USB、电源线、水管的接头 |
| 绿灯闪烁 | 恢复出厂进行中 | 不要断电，等它自己转成闪蓝 |
| 橙/黄灯闪烁（老机型） | 与 WiFi 断开 | 多为密码错、连了 5GHz、或信号太弱 |

老机型闪黄灯时，官方列的三种典型原因正好对应三个检查动作：重输密码；确认没连 5GHz（老机型只认 2.4GHz）；把 Hub 挪近路由器——官方提到信号弱多发生在距离超过 20 英尺（约 6 米）时。

## 二、连不上 WiFi 的六个常见原因

官方帮助中心归纳的掉线原因，按出现频率从高到低排：

1. **距离太远**：理想是 Hub 与路由器之间视线无遮挡、尽量近；用了中继器的话，中继器与路由器、中继器与 Hub 之间都要视线通畅；
2. **中间障碍物多**：墙、电器、老旧管线都会干扰 2.4GHz 信号；
3. **网络里设备太多**：先断开几台别的设备试试；路由器支持 QoS 的话，把 Hub 的 MAC 地址设成优先；
4. **路由器自动跳信道**：把信道固定下来（官方建议先试 1 或 11），自动选信道会在跳变时把 Hub 甩下线；
5. **网络里有极老的设备**：条件允许就在路由器上关掉 802.11a/b/g 协议兼容，老协议会拖慢整个网络；
6. **双频争抢**：路由器开了 band steering 或 airtime fairness 时，老机型容易被挤掉线，试着关掉其中之一。

## 三、应用崩溃或卡在加载页

官方帮助中心给的处理顺序，照着从上往下做：

1. 确认应用是最新版本（重装时可以从 [下载与安装教程](下载与安装教程.md) 重新获取安装文件）；
2. 确认手机与 Hub 处于可连接状态（蓝牙开、同一 WiFi）；
3. 核对 WiFi 名称与密码没有输错；
4. Hub 断电重启：取下水箱、拔电 15–30 秒再插回，水箱装回，等灯转成闪蓝；
5. 换一台手机或平板登录同一账号试；
6. 都不行就恢复出厂设置以刷新固件，然后重新配对。

## 四、温度不变化与漏水这类硬件问题

- **调了温度没反应**：先看灯——红色发亮说明有线缆没插牢；灯正常却不动，把 Hub 断电重启一次再试；
- **水箱与水质**：官方有两套口径并存——维护页建议自来水约 2 升、严禁任何清洁剂（用了会失保），随机手册则写每两个月用双氧水加蒸馏水换水；两种说法的出处与取舍见 [水箱换水与日常保养步骤](水箱换水与日常保养步骤.md)，动手前以应用内保养页提示为准；
- **发现漏水**：床垫下或 Hub 周围出现水渍时，立即断电停用、擦干现场，联系官方客服判断，不要带水继续运行。

## 五、联系官方支持

以上都试过仍解决不了，直接找官方：邮箱 `support@eightsleep.com`；美国境内也有电话支持 `888-699-4015`。联系前把灯色、报错截图、WiFi 环境先整理好，客服处理会快很多。

配对失败反复卡在第一步的话，回到 [首次配对与WiFi连接步骤](首次配对与WiFi连接步骤.md) 核对机型对应的配对方式；灯全正常、只是功能不会用，直接翻 [温度调节与智能闹钟设置](温度调节与智能闹钟设置.md)。
