## 二、从哪里获取安装包

本项目作者的原始发布渠道只有 GitHub（`https://github.com/lyswhut/lx-music-mobile/releases`），官方文档也明确写了「其他渠道均为第三方转载发布」。你可以两个来源二选一：

- 从上面的 **LXMusic 安装文件资源（夸克网盘）** 转存后下载，拿到的是本文表格里那份固定版本的包，装完可以按 MD5 核对；
- 或者去官方 GitHub Releases 页面下载最新版，功能与修复更新。

官方在下载页还提醒过一点：网络上流传的所谓「魔改版、开箱即用版」不是官方发布，存在安全风险；官方版本永远不会向你索要账号或手机号。如果你对包的来源有顾虑，按第六节的方法核对 MD5 就能确认手上这份包是不是表格里那份。

除了正式版，官方还提供**测试版**：经 GitHub Actions 分发，下载需要登录 GitHub 账号；不方便登录的话可用 nightly.link（它只指向最新的测试版构建）。官方对测试版的定位是体验新功能与协助测试，可能包含未知问题 —— 日常使用优先正式版。

## 三、选择哪个 APK 架构

官方每次发布都会提供多个 APK，命名里带不同的架构标识。选错架构通常表现为「装不上」或「解析包时出现问题」，按下面的优先级选：

| 安装包标识 | 适合谁 | 说明 |
| --- | --- | --- |
| `arm64-v8a` | 绝大多数近几年的手机 | 官方建议优先下载这个 |
| `universal` | 装不上 arm64 包时的兜底 | 包含全部架构，体积更大 |
| `armeabi-v7a` | 老款 32 位手机 | arm64 装不上再试它 |
| `x86_64` | 模拟器、少数平板 | 按设备架构选 |
| 版本号带 `sl` | 想要状态栏歌词的用户 | 「墨·状态栏」特别版，见[歌词与状态栏歌词.md](歌词与状态栏歌词.md) |

简单记法：先试 `arm64-v8a`，装不上换 `universal`。

## 四、安装步骤

安卓上装的是 APK 安装包，不走应用商店，流程如下：

1. 从网盘转存并把 APK 文件下载到手机存储；
2. 在文件管理器里点开这个 APK；系统第一次会提示「禁止安装未知来源应用」，选择允许来自该文件管理器（或浏览器）的安装；
3. 确认权限弹窗（网络、存储等），点安装，等进度条走完；
4. 打开应用，首次进入建议先到「设置」里把各项过一遍 —— 官方文档原话是默认设置与 UI 操作「不以新手友好为目标」，先按自己习惯调一遍再开始用，会顺很多；
5. 想直接开始听歌的，跳到[歌单与播放列表机制.md](歌单与播放列表机制.md)看它的列表播放逻辑，能少走很多弯路。

## 五、升级时的「版本号太低」提示

这是移动版一个容易踩的坑：官方文档说明，`universal` 安装包的内部版本号**总是低于**单架构安装包（甚至跨版本也是如此）。如果你之前装的是 `universal` 包，升级时改用了单架构包（或反过来），系统可能提示「版本号太低」无法覆盖安装。

处理办法：升级时保持与首次安装相同的架构类型；确实要换架构类型时，先卸载旧版再装新版（卸载前先备份数据，见[数据同步与备份.md](数据同步与备份.md)）。

## 六、核对 MD5 与安装失败排查

下载完成后，可以用任意 MD5 校验工具（文件管理器自带、或 PC 上的 `certutil -hashfile 文件名 MD5`）核对包的完整性，正确值是 `0B236C6F95231B10B75DA120690DCFBB`。对不上说明下载不完整或包被改过，重新下载即可。

安装失败的常见原因，按出现频率排：

- **解析包时出错**：下载不完整（先核 MD5），或架构选错（回到第三节换包）；
- **点了没反应 / 提示禁止安装**：未知来源权限没给到对应的文件管理器，回第四节第 2 步；
- **提示版本号太低**：见第五节的架构问题；
- **安装后闪退**：确认安卓版本是否在 5.0 以上；仍有问题看[常见问题与播放异常排查.md](常见问题与播放异常排查.md)。

杀毒软件报毒的情况比较特殊，官方有专门的说明，也放在[常见问题与播放异常排查.md](常见问题与播放异常排查.md)里一起讲。
