> 这篇讲怎么用 `lxmusic://` 开头的链接从浏览器、快捷指令等外部场景直接控制洛雪：搜歌、切歌、收藏，一次说清哪些链接可用、参数怎么填。

## 一、这个功能是干什么的

从 v1.6.0 起，移动版支持 Scheme URL：在浏览器地址栏、二维码、快捷指令、自动化工具里放一个 `lxmusic://` 开头的链接，点击就能唤起洛雪执行对应动作。传参格式与电脑版一致，官方文档目前声明支持的调用分为两类：**带参数的播放类**（`data` 方式）和**免参数的播放控制类**（直接 URL）。

## 二、免参数的控制链接：最简单先试这组

这一组不需要任何参数，`lxmusic://` 后面拼上动作名即可，点开就执行：

| 动作 | 链接 |
| --- | --- |
| 播放 | `lxmusic://player/play` |
| 暂停 | `lxmusic://player/pause` |
| 切换播放或暂停 | `lxmusic://player/togglePlay` |
| 下一曲 | `lxmusic://player/skipNext` |
| 上一曲 | `lxmusic://player/skipPrev` |
| 收藏当前歌曲 | `lxmusic://player/collect` |
| 取消收藏当前歌曲 | `lxmusic://player/uncollect` |
| 不喜欢当前歌曲 | `lxmusic://player/dislike` |

典型用法：把「下一曲」「暂停」做成手机快捷指令面板，或者放进自动化工具里当遥控按钮。

## 三、搜索并播放：URL 方式传参

搜索并播放一首歌，用 `music/searchPlay` 路径，歌名直接拼在后面：

```text
lxmusic://music/searchPlay/突然的自我
```

实际放进浏览器时要把中文做 URL 编码（浏览器一般会自动处理）：

```text
lxmusic://music/searchPlay/%E7%AA%81%E7%84%B6%E7%9A%84%E8%87%AA%E6%88%91
```

可以只传歌名，也可以传「歌名-艺术家」的形式（`歌曲名-艺术家`），带歌手名能更准确地命中。官方还提醒：参数里若含 `/` 之类特殊字符，要**单独**对参数做 URL 编码，否则调用会异常。

## 四、data 方式传参：播放歌单

歌单级别的调用走 `songlist/play`，参数以 URL 编码后的 JSON 放进 `data`：

```text
lxmusic://songlist/play?data=%7B%22source%22:%22kw%22,%22id%22:%223373919903%22%7D
```

上面这条等价于传入了 `{"source":"kw","id":"3373919903"}`（官方文档示例）。参数规则：

| 参数 | 是否必传 | 说明 |
| --- | --- | --- |
| `source` | 必传 | 歌单来源 |
| `id` / `url` | 二选一必传 | 歌单 ID 或歌单 URL |
| `index` | 选传 | 播放第几首，从 0 开始 |

歌单 ID 怎么拿：分享歌单链接、或在网页端打开歌单时地址栏里的那串数字。链接打不开外部歌单的问题与「歌单源」的对应关系，见[歌单与播放列表机制.md](歌单与播放列表机制.md)。

## 五、data 方式传参：播放指定歌曲

精确播放某首歌走 `music/play` 或 `music/searchPlay`（JSON 方式）。`music/play` 要求传齐歌曲名、歌手、来源、歌曲 ID、音质数组等参数，属于给第三方程序对接用的完整格式；只想「搜到就放」的话，`music/searchPlay` 只需要歌名（可选歌手、专辑、时长、是否稍后播放），日常够用：

| 参数 | 必传 | 说明 |
| --- | --- | --- |
| `name` | 是 | 歌曲名 |
| `singer` | 否 | 歌手名，带上更准 |
| `playLater` | 否 | `true` 时加入稍后播放而非立即播放 |

「稍后播放」队列的行为规则（优先插播、会被普通切歌清空）在[歌单与播放列表机制.md](歌单与播放列表机制.md)里有完整说明。

## 六、链接点了没反应

按顺序核对：

1. **版本不够**：Scheme URL 从 v1.6.0 起才支持，老版本装了也没反应，升级方法见[下载与安装教程.md](下载与安装教程.md)；
2. **参数没编码**：中文与特殊字符必须 URL 编码，`data` 里的 JSON 要整段编码；
3. **路径拼错**：路径要照抄表里的写法，注意大小写（如 `skipNext`、`searchPlay`）；
4. **系统拦截**：部分浏览器首次打开自定义 Scheme 会询问「是否允许打开应用」，点了拒绝就不再弹 —— 去系统设置里重置该浏览器的「默认打开」权限再试。

仍无响应、且能确认版本与参数都对时，官方文档指向的相关讨论在 GitHub issue（`https://github.com/lyswhut/lx-music-desktop/issues/1056`），可以带着你的链接去比对。其他常见故障分流见[常见问题与播放异常排查.md](常见问题与播放异常排查.md)。
