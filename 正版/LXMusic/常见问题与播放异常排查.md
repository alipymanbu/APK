## 一、所有歌都提示「请求异常」

提示原文大概是「请求异常，可以多试几次，若还是不行就换一首吧」。官方 FAQ 对这种**成批出现**的异常有明确结论：绝大多数是你的**网络到不了接口服务器**，不是软件坏了，也不是某首歌的问题。

先理解一点背景，排查就不慌：按官方许可协议的口径，软件本身不直接获取音频数据，播放用的链接由「设置 - 音乐来源」里所选的来源返回 —— 所以来源与网络两侧任何一边不通，都是同一副「请求异常」的样子，也意味着**换网络**和**换音乐来源**是两条平行的修复路径。按这个顺序处理：

1. **换网络**：切到移动数据试试；移动数据也不行，开关一次飞行模式再试；
2. **重启网络设备**：家用宽带可以试着把光猫断电 5 分钟左右再通电联网；
3. **确认是不是网络问题**：用浏览器打开 `http://ts.tempmusics.tk` —— **显示 404 是正常的**，说明网络通；如果打不开或显示别的，就是你的网络访问不了接口服务器；
4. **换 DNS**：把 DNS 改回自动获取；手动 DNS 时不要用 360 的 DNS，可以换成 `223.6.6.6` 或 `8.8.8.8`；
5. **升级与换源**：确认用的是较新版本；再到「设置 - 音乐来源」里切换到其他来源再试；
6. 都不行时，官方的说明是接口偶有波动，**等一两天**再试往往自己就好了。

判断口诀：**换一首歌无效、换一个网络有效** → 网络问题，回到第 1、3 步。

刚装好就一首都放不了的，大概率也在这个范围里：先按上面第 1、3 步排网络，再试第 5 步换音乐来源，不要急着卸载重装。

## 二、移动版能不能下载歌曲

不能。官方 FAQ 明确写着：**移动端暂不支持歌曲下载功能**。你在网上看到「洛雪音乐支持无损下载」之类的说法，描述的不是官方移动版的行为。

所以想离线听歌，现实的做法是：配合电脑端使用，或依赖列表同步把收藏带到各设备（见[数据同步与备份.md](数据同步与备份.md)）。如果某个安装包宣传「支持下载」，它就不是官方发布的包，是否使用需要你自己掂量（官方对第三方渠道下载的安全性不做任何保证）。

## 三、杀毒软件提示有病毒或恶意行为

官方对此有正面回应，要点是：

- 软件代码**开源**，可以自行查阅；官方安装包由 CI 从源码构建，构建过程在 GitHub Actions 上有日志可查；
- 作者只能保证自己写的代码没有恶意代码、不收集用户信息；软件依赖的第三方库若出问题（供应链攻击），软件会被牵连，这一点无法百分百排除；
- 上述保证的前提是安装包**来自官方页面给出的渠道**。

落到操作上：先确认你的包的来源（官方 GitHub Releases，或你手上这份已核对 MD5 的资源），再决定是否把杀软的警告放行。来源不明的包，不建议继续使用。安装与 MD5 核对方法见[下载与安装教程.md](下载与安装教程.md)。

## 四、第一次用建议先调设置

官方文档直言不讳：为了提高使用门槛，本软件的**默认设置与 UI 操作不以新手友好为目标**，建议使用前先按自己的喜好把设置过一遍。结合实际使用，最值得先动的是这几处：

- 「设置 - 音乐来源」：播放异常时切换的第一入口；
- 播放行为相关开关：比如「双击列表歌曲时切换到当前列表播放」（默认关，开了顺手很多，作用见[歌单与播放列表机制.md](歌单与播放列表机制.md)）；
- 桌面歌词与歌词样式：开关与权限问题见[歌词与状态栏歌词.md](歌词与状态栏歌词.md)。
