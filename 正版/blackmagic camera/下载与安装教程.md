## 一、动手前先对机型

Blackmagic Camera 是 Blackmagic Design 出品的免费摄像应用，2024 年 6 月起登陆安卓。它走的是专业机路线：帧率、快门角度、ISO、白平衡全部开放手动控制，所以对手机摄像头硬件有硬性要求，不是所有安卓手机都能正常用。

按官方技术规格页（截至 2026-09，以官方页面为准）：

| 项目 | 要求 |
| --- | --- |
| 系统版本 | Android 13 或更高 |
| 机型 | 见下表 |

| 品牌 | 官方列出的支持机型 |
| --- | --- |
| Samsung Galaxy | S21 / S22 / S23 / S24 / S25 系列；Tab S9 平板 |
| Google Pixel | 6 / 7 / 8 / 9 系列（Fold 折叠机型除外） |
| OnePlus | 11 / 12 |
| Xiaomi | 13 / 14 各型号；Xiaomi Pad 6 平板 |
| Sony Xperia | 1 / 5 / Pro 系列 |
| Oppo / Vivo | 部分兼容机型 |

两个容易踩的点：

- 机型在列表里不等于功能全开。120fps、8K、Open Gate、部分编解码器只在特定机型上可用，官方也写明"部分功能取决于设备"。
- 机型不在列表里，装了也大概率白装。常见表现是取景黑屏、参数灰着调不动，或者启动即闪退。

## 三、安装步骤（apk 方式）

1. 从网盘把 apk 转存下载，传到手机存储里。
2. 在电脑上先校验一下文件完整性，确认与上表 MD5 一致：

   ```powershell
   certutil -hashfile "blackmagic camera_v3.2.3.0010.apk" MD5
   ```

3. 在手机上点开 apk。系统会提示"禁止安装未知应用"，按提示允许你的文件管理器（或浏览器）安装应用。
4. 等安装完成，点打开。

首次启动会依次请求相机、麦克风，部分机型上还有照片与视频权限。这是一款摄像应用的基本权限，拒绝任何一项都没法正常开拍，建议全部允许。

## 四、首次开拍前的三件事

1. 认识界面：底部有拍摄（Camera）、媒体（Media）、消息（Chat）、设置（Settings）四个标签；拍摄画面上上下滑动，可以收起或展开 HUD 参数层。
2. 确认能拍：按下录制键试拍几秒，再到媒体标签里回放。片段能正常播放，说明相机权限与编码都正常。
3. 把参数调顺手：帧率、快门、ISO、白平衡都在 HUD 上点按即改，每一项的范围与用法见 [拍摄参数设置指南.md](拍摄参数设置指南.md)。调色与 LUT 部分，等你拍到要出片的阶段再看 [LUT导入与色彩设置.md](LUT导入与色彩设置.md)。
