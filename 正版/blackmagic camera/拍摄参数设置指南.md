## 一、先认识 HUD：所有参数都点得到

拍摄界面是一层 HUD（平视显示）叠在画面上：镜头选择、帧率、快门、时间码、ISO、白平衡、色调、直方图、音频电平都在上面。操作逻辑只有一条——点哪个，改哪个：点 ISO 就弹 ISO 调整盘，点音频表就弹增益调整。屏幕顶部的状态条同样可以点，点任意一项会弹出对应面板。

不想看到 HUD，上下滑动屏幕即可收起，画面变成全屏；再滑回来就恢复。对焦不用找菜单，直接点画面里想合焦的位置。

## 二、曝光与色彩

各参数范围以机型为准，下表是官方规格给出的范围（不同手机差异很大）：

| 参数 | 范围 / 档位 | 说明 |
| --- | --- | --- |
| ISO | 由机型与镜头决定 | 点 HUD 上的 ISO 指示直接调 |
| 快门速度 | 1/24 到 1/8000 | 滚轮选取，可锁定 |
| 快门角度 | 1.1° 到 360° | 与快门速度二选一使用 |
| 白平衡 | 自动，或手动 2500K 到 10000K | 预设：阴天、阴影、荧光灯、白炽灯、日光 |
| 色调 Tint | -50 到 +50 | 微调画面偏绿或偏品红 |
| 曝光补偿 | ±3 档 | 不想全手动时的折中 |

快门"速度"与"角度"两种模式在相机设置里切换，都有锁定开关。追电影感就用快门角度 180°；夜景想压住抖动模糊，就手动改快门速度。

## 三、帧率与画幅

- 帧率预设：23.98 / 24 / 25 / 29.97 / 30 / 48 / 59.94 / 60 / 100 / 120 fps，上限由机型与所选编解码器决定。选帧率的依据通常是后期交付格式：网络视频常用 25 或 30，想做升格慢动作选 60 或 120。
- 画幅比例：帧导栏支持 9:16、4:5、1:1、4:3、14:9、1.85:1、2:1、2.35:1、2.39:1、2.4:1、2.76:1。
- 竖持拍横片：支持手持竖屏时录 16:9——想把手机举得低调一点、不引人注意时用这个。
- Open Gate：3.1 版起在兼容机型上可用，按整块传感器全画幅录制，后期再裁任意画幅。你的机型是否支持，以 app 内是否出现该选项为准。

录制编码（H.264 / H.265，部分新机型还有 APV）与分辨率（最高 8K，视机型）在设置的录制页里改，还有 Low / Medium / High / Max 四档码率可选。怎么搭配着选见 [录制格式与画质怎么选.md](录制格式与画质怎么选.md)。改高分辨率前留意剩余存储空间，8K 素材掉存储很快。

另外两项在设置里、拍特定题材才会碰到的：

- 延时摄影：独立开关，间隔从每 2 秒采集 1 帧到每 10 分钟采集 1 帧，云景、车流、施工记录都用得上。
- 变形镜头（Anamorphic）：有变形宽银幕镜头的话，在这里设置压缩画面的还原比例与镜头校正，画面才会被拉回正常比例。

## 四、辅助工具：让你敢直接出片

| 工具 | 开法 / 范围 | 什么时候用 |
| --- | --- | --- |
| 斑马纹 Zebra | 开/关，75% 到 100% | 过曝预警：高光超过阈值时画面出现斑马条 |
| 伪色 False Color | 开/关 | 按曝光区间给画面上色，比斑马纹看得更细 |
| 峰值对焦 Focus Assist | 开/关，1% 到 100% | 合焦边缘发亮，手动对焦必备 |
| 直方图 | RGB 三通道叠加 | 看整体曝光分布与通道溢出 |
| 安全区 | 开/关，5% 到 100% | 给平台裁切留余量 |
| 网格 / 中央点 | 三分线、十字线、中心点 | 构图与水平 |
| 防抖 | 关 / 标准 / 电影 / 极端 | 走动拍摄用高一级，固定机位直接关 |

3.2 这一版修过斑马纹与伪色的标定偏差。如果你在旧版本上发现斑马纹出现的时机和实际过曝对不上，先升级再拍。

## 五、对焦与变焦

- 自动对焦：点画面任意位置，即在该点合焦。
- 手动对焦：0.00（最近）到 1.00（最远）的滑杆。
- 焦点预设：三组 rack focus 预设，可设不同的变化时长，拍"焦点转移"镜头时不用手忙脚乱。
- 变焦：预设档位最高 8 倍；在刻度上滑动可以到 15 倍。点变焦图标可隐藏缩放显示，回到全屏画面。

## 六、音频与场记信息

- 音频表：VU 或 PPM 两种表头，在设置里切换；点表头可调增益。插上兼容的外接麦克风后，增益也在同一处调。
- 时间码：每条片段可录"运行时间"或"当日时间（TOD）"两种时间码；多机位同步可以配 Tentacle Sync E 这类蓝牙时码器（需配件支持）。
- 片段元数据：每条素材可以写场记板名、镜头数据、卷号、场次、条次、好条标记、内/外景、日/夜、制作名、摄影机编号、导演、摄像等字段。多人协作后期翻素材时，这些字段就是检索依据。

这些参数调顺之后，色彩与 LUT 部分见 [LUT导入与色彩设置.md](LUT导入与色彩设置.md)；开直播时这些参数照样实时可调，见 [直播推流设置方法.md](直播推流设置方法.md)。
