## 一、先弄清自己装的是什么

Gloom 是一个安卓上的 GitHub 客户端。你在手机上直接看某个仓库的代码、文件列表、提交记录、Issues、Pull Requests 和 Releases，不用为了看一眼代码去开浏览器。它由 MateriiApps 维护、代码开源，界面走的是谷歌 Material You（Material 3）那一套，官方仓库里给的定位就是「用 Material You 重新做一遍 GitHub」。

三件事先记住：

| 项目 | 情况 |
| --- | --- |
| 形态 | 安卓手机应用。没有电脑版，也没有网页版 |
| 数据来源 | GitHub 官方的接口，登录走 GitHub 的 OAuth 授权 |
| 官方仓库 | [github.com/MateriiApps/Gloom](https://github.com/MateriiApps/Gloom)，GPL-3.0 许可 |
| 收费 | 开源项目，应用本身不收费，界面里也没有内购或订阅 |

它跟 GitHub 官方那个 App 不是同一个东西，也不是官方出的。两个装在同一台手机上也互不影响，具体差别见 [常见问题与排查.md](常见问题与排查.md)。

## 二、装之前对一遍这张表

下面这些是网盘里那份包的实际信息。网上搜到的多半是官方构建产物里更新的编号，跟网盘里这份往往对不上，装之前以这张表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Gloom |
| 版本 | 1.0.0 |
| 包名 | `com.materiiapps.gloom.debug` |
| 安装包大小 | 25.64M |
| 安装包 MD5 | `204A8BD8928AF8FD08D49FE53343E52F` |
| 系统要求 | 安卓 5.0 及以上 |

三条判断：

- **包名末尾的 `.debug` 是这份包的身份**。Gloom 的调试构建和正式构建用的是两个不同包名，所以这份能和你手机上已有的正式版 Gloom 同时存在、互不覆盖。装之前先看已有那个的包名，包名不一样就是两个独立应用，各自的登录状态和设置也是分开的。
- **系统低于安卓 5.0 装不了**。官方仓库里这一支的最低要求是 API 21，也就是安卓 5.0；另外动态取色这类外观特性还要更高的系统版本，详见 [动态取色和图标怎么换.md](动态取色和图标怎么换.md)。
- **手机存储留 30M 以上的空闲空间**，安装包本身 25.64M，装完还要占一点。

还有一条不是系统要求、但一定绕不过去的前提：**这台手机得能连通 `github.com`**。Gloom 自己没有账号体系，登录和首页内容都来自 GitHub，网络到不了 GitHub 的话，装上了也走不到第二步。

## 三、把安装包取到手机

1. 打开 [Gloom 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1b5cf0fe0273)。
2. 先点「保存到我的网盘」，再从自己的网盘里下载。直接下载也能装，但转存一次之后，原分享链接以后有变化也不影响你手上的文件。
3. 等下载完成，记下文件位置，多数浏览器会放在「下载」或「Download」目录。
4. 网盘里的文件名形如 `Gloom_v1.0.0.apk`，以实际显示为准。

打开链接提示失效时，说明这条分享已经不是当前状态，换最新的一条再取。

## 四、装之前顺手校验一下

安装包从网络到手机，中间传坏了不会主动报错，而是在安装时给你一句「解析包错误」。花半分钟能省下后面一堆排查。

把 APK 拷到电脑上，在文件所在目录执行：

```powershell
certutil -hashfile "Gloom_v1.0.0.apk" MD5
```

输出的十六进制串去掉空格后，应该与第二节表里的 `204A8BD8928AF8FD08D49FE53343E52F` 完全一致（大小写不敏感）。对不上就重新下一次，别将就着装。手机上带 MD5 校验功能的文件管理器也能做同样的事。

## 五、先去系统里放行「未知来源」

网盘里的包不是从应用商店装的，安卓会拦一次。要先给打开这个包的应用（浏览器或夸克）开安装权限，各家路径不完全一样：

| 品牌 | 大致路径 |
| --- | --- |
| 原生 / 类原生 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |
| 小米 / Redmi | 设置 → 应用设置 → 应用管理 → 权限管理 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 | 设置 → 安全 → 安装外部来源应用 |
| vivo | 设置 → 更多设置 → 权限管理 → 安装未知应用 |

各品牌改版频繁，找不到时直接在设置里搜「未知来源」或「安装未知应用」。

装完建议把刚开的这一项关回去：给浏览器或文件管理器长期留着安装权限，等于把「谁来都能装」的口子一直开着。下次要装别的侧载包时再打开一次即可。

## 六、安装

1. 在文件管理器里点这个 APK，按提示确认安装；如果系统提示「该应用未经安全检测」之类，选择继续安装。
2. 装完后启动器里会出现 Gloom 图标，点开。
3. 第一次打开会停在登录入口。Gloom 不提供自己的账号，需要你用 GitHub 账号授权一次，完整流程在 [登录与授权怎么弄.md](登录与授权怎么弄.md)。
4. 如果打开后一直转圈、或登录页打不开，先确认这台手机能不能访问 GitHub，再回头看排查那篇。

## 七、装完确认三件事

| 要确认的 | 在哪看 | 不对说明什么 |
| --- | --- | --- |
| 能登录上 | 登录完成后能看到自己的头像和用户名 | 网络到不了 GitHub，或者授权没走完 |
| 首页有内容 | 首页动态流能刷出条目 | 账号刚注册、没关注任何人、也没 star 过仓库时，首页本来就稀 |
| 界面外观正常 | 图标、取色、深浅色跟着系统走 | 系统低于安卓 12 时没有动态取色，属正常 |

## 八、以后怎么更新

Gloom 官方**没有正式的发行版（Releases）页面**，正式的获取途径是官方仓库里 GitHub Actions 构建出来的产物（README 的安装一节给的就是这个入口），或者你自己把源码拉下来编译。所以手机上不会像商店应用那样自动提示更新。

几点实际影响：

- **网盘这条分享是长期有效的**：换版本时替换的是里面的文件，分享链接本身不变，不用重新找地址。
- **这份 `.debug` 包和官方正式包不能互相覆盖升级**：包名不同，系统会当成两个应用。想换成正式包，是「装新的、卸旧的」，而不是升级。
- **判断新旧别看版本号数字**：官方在不同阶段用过不同的版本号口径，网盘里这份是 1.0.0，官方后来的构建产物用的是另一套编号，直接比大小会看错。要确认是不是新的，看官方构建产物的时间。
