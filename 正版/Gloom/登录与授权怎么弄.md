## 一、为什么一定要登录

Gloom 自己没有账号，它是拿「你授权给它的 GitHub 身份」去读 GitHub 上的内容。所以第一次打开它只会停在登录入口，不登录基本没法用：首页那条动态流是按你关注的人和 star 过的仓库生成的，没登录就是空的。

登录之后你能看到的东西大致分两类：公开内容和与你账号相关的内容。

| 需要登录吗 | 内容 |
| --- | --- |
| 登录后才有 | 首页动态流、你 star 过的仓库、你的关注与粉丝关系 |
| 登录后更顺手 | 仓库页的 star 操作、关注/取关、给 issue 和 PR 加表情回应 |

## 二、登录的完整流程

Gloom 走的是 GitHub 的 OAuth 授权，不是在应用里直接填账号密码 —— 这一点对你有好处：密码始终只输给 GitHub 自己的页面。

1. 在 Gloom 的登录入口点「用 GitHub 登录」（不同版本措辞略有差别，认按钮位置即可）。
2. 手机会跳到浏览器（系统浏览器或应用内置的浏览器页签）。
3. 在 GitHub 页面上登录你的账号，然后会看到一个授权确认页，列出这个客户端能读取和能操作的范围。
4. 在授权页点同意，浏览器会跳回 Gloom，这时应用里就会显示你的头像和用户名。
5. 回到首页，动态流开始加载，说明这条链路通了。

如果第 2 步跳出去之后停在第 3 步的登录页，别急着退出 —— 有些手机上首次授权需要先在浏览器里完成一次 GitHub 登录，这一步和 Gloom 本身无关。

## 三、授权确认页上那些项目是什么意思

授权页列的是这个客户端未来能替你做哪些事。对普通用户来说，看两点就够：

- **能否读取你的公开信息**：这是首页动态、关注列表能显示的前提，必须给。
- **能否替你写入**：Gloom 在应用内能替你做的主要是 star / 取消 star、关注 / 取关、给 issue 或 PR 加表情回应。发 issue、写评论、合并 Pull Request 这类操作它不做，需要时回 `github.com` 网页端。

授权页的具体条目会随 GitHub 侧的调整变化，以你当时看到的页面为准。看到不认识的权限项，可以选择先不授权、把页面记下来再决定。

## 四、登录上不去的三种常见情况

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 跳转后页面一直加载不出来 | 手机网络到不了 `github.com` | 换一个能正常打开 `github.com` 的网络再试；Gloom 这边没有任何可调的设置能绕过这一步 |
| 授权完没跳回应用，停在浏览器的成功页 | 系统没把回调交回 Gloom，或默认浏览器被改过 | 回到 Gloom 看是否已登录；没登上就再走一次，跳转完成前不要手动关浏览器 |
| 登录时被要求做两步验证或安全验证 | 这是 GitHub 账号侧的登录流程 | 按浏览器里的提示在 GitHub 页面上完成，完成后会继续跳回应用 |

有一点要提醒：**账号开了两步验证不影响 Gloom**，那个验证发生在浏览器的 GitHub 页面里，不在应用内。

## 五、换账号、退出、撤销授权

三种情况分开处理：

- **只是想在应用里换一个账号登录**：先在应用内退出当前账号，再重新走一次第二节的流程。如果你手机上装了多个包名的 Gloom（比如网盘这份 `.debug` 和官方正式包），它们的登录状态是**各自独立**的，退了一个不影响另一个。
- **想把本地痕迹清干净**：卸载应用或清除应用数据，本地的登录状态就没了。这一步不会对你的 GitHub 账号做任何改动。
- **想让授权彻底失效**：要去 GitHub 侧撤销。打开 `github.com` 的 Settings → Applications → Authorized OAuth Apps，找到对应条目移除。**卸载 Gloom 不等于撤销授权** —— 授权记录留在你的 GitHub 账号里，卸载只是把本地的钥匙丢了。

撤销之后想再用，重新走一次登录授权就行，过程同上。

## 六、第二个账号、以及多设备

Gloom 的定位是「一个客户端配一个 GitHub 身份」，日常用一个账号就够。真要看另一个账号的内容，最省事的做法是撤销授权后重新登录，而不是指望应用里随时切换 —— 应用内是否有账号切换入口以你装的这版实际显示为准。多个包名的 Gloom 各自登录一个不同账号，也是可行的做法。

同一个账号在手机和平板上各授权一次互不影响：授权是发给「客户端」的，不是发给设备的。

## 七、登录之后先做这一步

登录成功不等于首页立刻有内容。如果你是新账号，建议先做两件事，否则首页会一直是空的：

1. 在网页端或应用里 star 几个常看的仓库；
2. 关注几个你关心的作者或组织。

这两样是首页动态的来源，具体会在 [首页动态和探索怎么用.md](首页动态和探索怎么用.md) 里展开。登录过程中还有别的异常，先看 [常见问题与排查.md](常见问题与排查.md)。
