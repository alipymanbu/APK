## 一、这套界面长什么样

Gloom 用的是谷歌 Material You（Material 3）这套设计语言。它跟普通安卓应用最大的区别是：**主色调不是写死的品牌色，而是可以从你手机的壁纸里取**。取出来之后，按钮、卡片、选中态、图标底色都会跟着变成同一色系的不同深浅，整屏看起来是一个整体。

这不是它的独有技术，是安卓系统的能力，只要应用愿意接、手机系统够新就能用。

## 二、动态取色的前提是系统版本

| 你的系统 | 实际效果 |
| --- | --- |
| 安卓 12 及以上 | 可以从壁纸取色，界面跟着你的壁纸变 |
| 安卓 11 及以下 | 没有动态取色，只能用它自带的固定配色 |

所以：**在旧系统上觉得「这界面怎么没有网上截图那种感觉」，不是装错了**，是系统本身不提供这个能力。Gloom 支持的最低系统版本远低于安卓 12，低版本能用，只是外观是固定配色。

如果你在安卓 12 以上的机器上看不到取色效果，先确认系统设置里开着壁纸取色（部分品牌把它放在「壁纸与个性化」里，各家叫法不同），再回来重开一次应用。

## 三、深浅色模式

Gloom 的深浅色是**跟着系统的深浅色开关走**的：你把手机切到深色，它会一起变深；切回浅色也一样。也就是说，想让它夜间不刺眼，改的是手机的显示设置，不是应用里的设置。

深浅色和动态取色是两件独立的事：前者决定背景是黑还是白，后者决定主色是什么颜色。两者可以同时生效——深色模式加壁纸取色，是最常见的一套组合。

## 四、启动图标可以换一套

Gloom 除了默认图标，还准备了几套不同风格的启动图标，大致包括：

| 风格 | 说明 |
| --- | --- |
| 经典 | 默认那套，标准配色 |
| 风格化 | 线条更简的变体 |
| Catppuccin 配色 | 社区流行的配色主题（Latte、Frappé、Macchiato、Mocha 几种色调） |
| Pride 系列 | 主题色系图标 |
| 节日款 | 阶段性出现的应景图标 |

**怎么换**：在桌面（启动器）上长按 Gloom 图标，找到「编辑」「应用信息」或图标样式的入口，会看到一列可选图标，选一个确认即可。不同品牌、不同启动器的入口名字差别很大，有的把「换图标」放在主题商店里，有的干脆不提供 —— **能不能换成，取决于你的桌面，不取决于 Gloom**。换不成不代表应用有问题。

具体可选的套数以你装的这版实际显示为准：不同版本的 Gloom 带的图标套数不一样，官方仓库里目前能看到上面这几类。

## 五、界面语言

Gloom 的界面文案跟随手机的系统语言。它的翻译由社区在官方的 Crowdin 翻译项目里做，也就是说中文的完整度取决于翻译进度，**有些条目可能还是英文**，这属于正常现象，不是没装好中文包。

两点实际建议：

- 想确认当前版本的中文覆盖到什么程度，直接把界面语言切成中文用一圈最直观。
- 遇到中英混排的界面不用去应用市场找「汉化版」——那类改动过的包来路不明，而且这份客户端本身就是开源项目，翻译是走官方渠道的。

## 六、改了没生效怎么查

| 现象 | 先做什么 |
| --- | --- |
| 切了壁纸但应用配色没变 | 完全退出应用再打开；部分系统要等下一次壁纸重新应用 |
| 换图标后桌面还是老的 | 桌面缓存没刷，把图标从桌面移除再重新拖出来 |
| 长按图标没有换图标的入口 | 你的启动器不支持，属于系统限制，应用侧无法解决 |
| 深色模式和系统不一致 | 先在系统里切一次深浅色，再回到应用确认 |
| 界面还是英文为主 | 系统语言不是中文，或这个版本的翻译还没覆盖到 |

外观之外的问题——登录跳转、首页空白、安装报错——都不在这一篇里，按 [常见问题与排查.md](常见问题与排查.md) 逐条对。第一次装还没装上的，先回 [下载与安装教程.md](下载与安装教程.md)。
