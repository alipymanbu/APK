# Hpoi 查手办资料与价格的方法

## 一、先想清楚你要查的是哪一层

Hpoi 的资料库按「作品 → 角色 → 条目」组织，条目覆盖手办、模型、GK/DIY 与周边。你带着不同问题进来，看的字段不一样：

| 你的问题 | 重点看 |
| --- | --- |
| 这个手办官方卖多少 | 定价（含币种） |
| 什么时候发货/发售 | 出货日 |
| 多大、什么材质 | 比例、尺寸、材质（PVC、ABS 等） |
| 谁做的、谁发行的 | 制作、发行、原型、涂装一栏的厂商与人名 |
| 实物长什么样 | 官图与「用户图片」 |
| 值不值得买 | 评分 + 评论区品控反馈 |

## 二、怎么搜到条目

1. 打开应用，在首页最上方的搜索框输入作品名、角色名或商品名。用日文原名或中文译名都能命中，搜不到时换一边的语言再试。
2. 首页资料库区有「最新入库 / 热门预定 / 热门出荷」三个口径：想追新品看「最新入库」，想看大家都在订什么看「热门预定」，想知道哪些已经出货看「热门出荷」。
3. 条目列表支持按厂商、系列、出货年月等条件筛 —— 找「某厂商 2026 年出的所有 1/7」这类需求就靠筛选组合，比翻列表快。
4. 想换电脑细看或分享给别人：网页版每个条目与相册都有独立网址（形如 `hpoi.net/hobby/编号` 与 `hpoi.net/album/编号`），把链接发给自己或同好，对方打开就是同一个条目。

## 三、条目页的字段怎么读

条目页把一款商品的参数列得很全：名称（中日对照）、属性（性别、类别、比例人形等）、定价、出货日、比例、制作/发行/原型/涂装、角色与作品关联、尺寸、材质、特典说明。几个容易误读的地方：

- **价格显示 0 日元（0 元）** 多半表示价格未公布，不是真的免费。未开订的条目常见这种显示，等厂商公布后才会填上真实价格。
- **定价不等于到手价**：定价是厂商建议零售价（日元标价换算成人民币显示），你实际从店铺或二手渠道拿到的价格随行情浮动。
- **特典**一栏列的是特定渠道附赠的赠品，不同渠道的特典不同，下单前核对清楚你走的渠道给不给。
- **出货日**写「未知」说明厂商还没排期；延期很常见，条目简介区通常会贴厂商的延期说明。

## 四、评分与评论区是行情情报源

条目页的评分来自用户打分，评论数多的条目评论区基本是两类信息：**品控反馈**（掉漆、溢胶、断件这类实物瑕疵的集中反馈）和**行情讨论**（有人报自己多少收的、有人问现在什么价）。下单前把评论翻一两页，比只看官图靠谱得多 —— 官图是厂商给的，评论区才是实物反馈。

## 五、看到喜欢的条目先收藏

条目页有收藏入口，收藏后从个人页能快速回访，盯补款与出货动态也方便。收藏同时会涨 ATK 积分（积分规则见[相册上传与积分获取规则.md](相册上传与积分获取规则.md)）。

条目看好了要去哪买，三条路径怎么选见[买手办与卖二手的流程.md](买手办与卖二手的流程.md)；如果资料库还缺这个条目的实拍图，你自己拍了就能传，步骤见[相册上传与积分获取规则.md](相册上传与积分获取规则.md)。
