# Nrfr 的 Shizuku 配对与授权教程

对多数人来说，「装 Nrfr」和「能用好 Nrfr」之间的差距全在这一篇：Shizuku 是一个独立的权限管理工具，它通过安卓的调试机制把一部分系统级权限临时交给普通应用用。Shizuku 没跑起来，Nrfr 打开就是提示无权限或者直接闪退；Shizuku 跑起来了但没授权，同样用不了。顺序是：先启动 Shizuku → 再授权 Nrfr → 然后才轮到 Nrfr 里做修改。

## 一、启动 Shizuku 的三种方式

| 方式 | 适用情况 | 特点 |
| --- | --- | --- |
| 无线调试 | Android 11 及以上 | 不用电脑，手机上独立完成；推荐 |
| 电脑 adb | 未 Root 的 Android 10 及以下（官方手册口径） | 需要数据线与电脑；低版本系统的主要选择 |
| Root | 已解锁 Root 的设备 | 一步启动，但多数用 Nrfr 的人本来就是为了免 Root |

无线调试的配对入口在 Android 11 才加入系统，所以低版本设备只能走电脑 adb 或 Root。你设备的实际支持情况以 Shizuku 官方说明为准（`https://shizuku.rikka.app/`）。官方手册还提醒了两条硬性规则：**配对只需做一次，但每次重启手机后都要重新点一次启动**；如果点启动没反应，先把无线调试关掉再打开再试。

## 二、方式一：无线调试配对（Android 11+）

1. 打开手机的开发者选项（设置 → 关于手机 → 连续点击「版本号」多次）。
2. 进入开发者选项，打开「无线调试」，保持这一页不要退出。
3. 打开 Shizuku 应用，首页点「配对」→「使用配对码配对设备」，系统会跳到无线调试页面，点「使用配对码配对设备」会出现一个 6 位配对码。
4. 此时通知栏会出现「输入配对码」的通知，把 6 位码填进去；没看到通知就把 Shizuku 切回前台再看。
5. 配对成功后回到 Shizuku 首页，点「启动」，状态变成「Shizuku 正在运行」即可。

## 三、方式二：电脑 adb 启动

1. 电脑上装好 adb：下载 Google 提供的 SDK Platform Tools（`https://developer.android.com/tools/adb`），解压到任意文件夹。
2. 手机开 USB 调试，数据线连接，手机上弹出「允许调试」时勾选「一律允许」再确认。
3. 在解压目录打开终端（Windows 下按住 Shift 右键选「在此处打开 PowerShell 窗口」），执行 Shizuku 应用内「通过连接电脑启动」页面提示的那条启动命令（各版本路径不同，以应用内显示为准；PowerShell 下命令里的 `adb` 要写成 `./adb`）。
4. 命令执行完，Shizuku 应用里显示正在运行即可；adb 连不上设备时按 [Shizuku启动失败排查手册](Shizuku启动失败排查手册.md) 第五节核对。

## 四、把权限授给 Nrfr

1. Shizuku 正在运行时，打开 Nrfr，通常会直接弹出 Shizuku 的授权请求，点「允许」。
2. 如果没有弹窗，打开 Shizuku 首页的应用列表，找到 Nrfr，打开它的授权开关。
3. 有用户反馈过一种情况：勾选授权后，Shizuku 首页仍显示「已授权 0 个应用」——把 Shizuku 从后台划掉重新打开，就会正常显示。授权状态本身没丢，只是界面没刷新。

## 五、启动失败先看这几条

最高频的三条：

- **重启手机后 Shizuku 停了**：正常现象，不是故障——官方明确每次重启后都需要重新启动一次（配对不用重做）。
- **配对码输不进去或一直搜索配对服务**：多与通知样式、后台运行限制有关，处理方法见 [Shizuku启动失败排查手册](Shizuku启动失败排查手册.md)。
- **授权请求一闪而过或无响应**：确认 Shizuku 首页确实是「正在运行」，运行中才有权限发放授权弹窗。

更多症状（MIUI 通知样式、随机停止、adb 权限受限等）统一收录在 [Shizuku启动失败排查手册](Shizuku启动失败排查手册.md)。

## 六、Shizuku 就绪之后

回到 Nrfr：现在打开它不会再提示权限问题了，具体怎么选卡、选国家码、保存生效，见 [修改国家码与运营商名教程](修改国家码与运营商名教程.md)；如果启动过程里遇到别的问题，翻 [常见问题解答](常见问题解答.md)；需要重新找安装包则回 [下载与安装教程](下载与安装教程.md)。
