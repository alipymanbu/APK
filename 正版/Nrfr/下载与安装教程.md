# Nrfr 下载与安装教程

> 本篇讲 Nrfr 安装包的构成与两条安装路径：手机上直接装 APK，或用电脑端的快速启动工具一键安装。装完之后还要启用 Shizuku 才能用，见 [Shizuku配对与授权教程](Shizuku配对与授权教程.md)。

Nrfr 是一个开源的安卓工具，作用是把系统读取 SIM 卡国家码、运营商信息的结果改成你指定的值，免 Root 使用。它本身是一个普通的 APK，安装没有门槛；真正容易卡住的是它的前置条件——手机上要有一个能正常运行的 Shizuku。本篇先把包装上，Shizuku 的启动与授权单独写在 [Shizuku配对与授权教程](Shizuku配对与授权教程.md) 里。

## 一、安装前先弄清楚：要装哪几个东西

| 文件 | 装在哪 | 是否必须 | 作用 |
| --- | --- | --- | --- |
| Nrfr 主程序（APK） | 手机 | 必须 | 执行修改操作的应用 |
| Shizuku（APK） | 手机 | 必须 | 给 Nrfr 提供系统权限支持 |
| 快速启动工具（电脑端程序） | 电脑 | 可选 | 通过数据线自动往手机上装上面两个 APK |

快速启动工具只是省事用的，不装它也完全可以——手机上手动装 Nrfr 和 Shizuku 两个 APK 是最直接的方式。新手建议走手动安装这条路，少一层 adb 连接的变量。

## 二、从哪获取安装包

上面表格里的 Nrfr 主程序 APK 可以从 **[Nrfr 安装文件资源（夸克网盘）](https://pan.quark.cn/s/25058918ccd1)** 获取，转存到自己的网盘后下载到手机安装即可。Shizuku 的安装包不在其中，需要另从 Shizuku 官方渠道获取（官网 `https://shizuku.rikka.app/`，或 GitHub 项目页 RikkaApps/Shizuku 的 Releases）。

本文口径的版本信息如下（以实际安装包为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.3 |
| 包名 | com.github.nrfr |
| 大小 | 7.46M |
| 开源协议 | Apache-2.0（项目地址 `https://github.com/Ackites/Nrfr`） |

## 三、方式一：手机上直接安装（推荐）

1. 把 Nrfr 的 APK 传到手机存储（网盘客户端直接下载，或数据线拷贝）。
2. 在手机文件管理器里点开 APK，系统提示「未知来源应用」时，允许从该来源安装。
3. 同样方式把 Shizuku 的 APK 也装上。
4. 装完先别急着打开 Nrfr——它此刻还没有权限，继续看 [Shizuku配对与授权教程](Shizuku配对与授权教程.md)，把 Shizuku 跑起来并给 Nrfr 授权，再回来做修改操作。

## 四、方式二：电脑端快速启动工具

官方 Release 里另有一个电脑端的快速启动工具（压缩包形式），它通过 adb 帮你把 Nrfr 和 Shizuku 自动装进手机并拉起应用。适合熟悉数据线调试、想省去手动传输的人。

1. 手机开启开发者选项：进入设置 → 关于手机，连续点击「版本号」（部分机型是「内部版本号」）多次，直到提示已进入开发者模式。
2. 在开发者选项里打开「USB 调试」；如有「USB 调试（安全设置）」「USB 安装」开关，一并打开。
3. 数据线连接手机与电脑，手机上弹出的 USB 调试授权选允许。
4. 在电脑上解压并运行快速启动工具，等它检测到设备。
5. 按工具的提示操作：它会自动把 Shizuku 装进手机，然后需要你按提示把 Shizuku 启动起来，之后工具再安装 Nrfr。
6. 安装完成后在手机上打开 Nrfr 继续。

方式二在 v1.0.2 修过一次 ADB 服务端的问题，如果用旧版工具连不上设备，换最新版再试。

## 五、装完之后

- 下一步是把 Shizuku 启动并授权给 Nrfr：见 [Shizuku配对与授权教程](Shizuku配对与授权教程.md)。
- 权限就绪后，应用内的具体操作（选卡、选国家码、改运营商名、还原）见 [修改国家码与运营商名教程](修改国家码与运营商名教程.md)。
- 装好后打不开、授权不上之类的情况，先查 [常见问题解答](常见问题解答.md)；Shizuku 层面的启动故障见 [Shizuku启动失败排查手册](Shizuku启动失败排查手册.md)。
