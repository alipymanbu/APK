## 一、它到底改了什么？会不会伤卡或伤系统？

按官方说明，Nrfr 调用系统提供的运营商配置接口，改的是「系统按什么地区来读取这张卡的运营商信息」，SIM 卡本身完全不被写入、不损坏，系统文件也不被修改。修改随时可以通过应用内的还原功能撤销。它不依赖 Xposed、Magisk 这类框架，也不需要 Root。

## 二、安全吗？是开源的吗

Nrfr 是开源项目（Apache-2.0 协议，代码在 GitHub 项目 Ackites/Nrfr 公开），Shizuku 同样开源。两者都可以自行核对源码与构建产物。需要留意的是官方免责声明：工具仅供学习研究，修改系统设置带来的使用影响自行承担。

## 三、重启手机后还有效吗？

有效。官方说明一次修改会持续保持，重启后不丢。想撤销时用应用内还原功能。

## 四、双卡手机两张卡都能改吗？

能，且两张卡互相独立：可以只改卡 1、只改卡 2，或分别设成不同的国家码。还原也可以按卡分别操作。

## 五、保存后没生效怎么办？

按顺序核对（详细步骤见 [修改国家码与运营商名教程](修改国家码与运营商名教程.md) 的排查一节）：

1. Shizuku 是否正在运行——这是最高频原因，手机重启后 Shizuku 服务会停，需要重新启动，启动环节的故障按 [Shizuku启动失败排查手册](Shizuku启动失败排查手册.md) 处理；
2. Nrfr 的授权是否还有效；
3. 读取卡信息的目标应用是否需要彻底重开一次；
4. 设备是否属于官方提示的「部分设备可能不支持修改国家码」。

排查仍无解时，看下面第六、七两条。

## 六、改了国家码，有的应用还是识别成原来的地区

先分清 Nrfr 的作用边界：它改变的是**系统读取 SIM 卡运营商配置那一侧的结果**（卡属于哪个国家、运营商是谁）。而应用判断「你在哪个地区」时，可能同时参考网络出口 IP、系统语言、账号资料等其他因素——那些都不在 Nrfr 的作用范围内。所以改完后仍有应用认出原地区，不代表修改失败，先把「这个应用到底在读什么」和「Nrfr 改了什么」分开判断，再看 [修改国家码与运营商名教程](修改国家码与运营商名教程.md) 第四节确认修改本身是否已生效。

## 七、打开 Nrfr 提示无权限 / 闪退

几乎都是 Shizuku 环节没走通：服务没启动、或者启动了但没授权给 Nrfr。处理路径见 [Shizuku配对与授权教程](Shizuku配对与授权教程.md)，启动环节的故障见 [Shizuku启动失败排查手册](Shizuku启动失败排查手册.md)，按「启动 → 授权」两步走完再打开 Nrfr。

## 八、我的手机能用吗？对系统版本有要求吗

Nrfr 本身的安装没有特殊限制；实际可用性取决于 Shizuku 能不能在你的设备上启动：

| 你的情况 | 可用路径 |
| --- | --- |
| Android 11 及以上 | 无线调试配对，手机上独立完成 |
| Android 10 及以下、未 Root | 电脑 adb 方式启动 Shizuku |
| 已 Root | Shizuku 直接以 Root 启动 |

官方项目页未标注 Nrfr 的最低安卓版本，具体支持范围以官方页面为准（`https://github.com/Ackites/Nrfr`）。

## 九、改国家码会影响正常打电话、上网吗

官方注意事项里明确写了「修改国家码可能会影响运营商服务，请谨慎操作」。实际影响因机型与运营商而异，稳妥做法是：改之前记下原始值，只在需要的时段保持修改，用完还原；还原后一切回到原样。
