先说两条最基础的判断，能省掉大半排查：

- **配对只需做一次，启动每次开机后都要重做**——官方手册明确写了「由于系统限制，每次重新启动后都需要再次进行启动步骤」。重启手机后 Shizuku 显示未运行，不是故障，回 Shizuku 点一次启动即可。
- **启动不了时先试「关掉再打开无线调试」**——官方给的第一处理办法就这一条，很多「点启动没反应」到这一步就解决了。

下面按症状展开。

## 一、一直显示「正在搜索配对服务」

| 可能原因 | 处理 |
| --- | --- |
| Shizuku 被系统禁止了后台与本地网络访问 | 允许 Shizuku 在后台运行；部分厂商系统会在应用退到后台后立刻切断它的网络权限，搜索配对服务恰恰需要访问本地网络 |

这一条是官方手册原文给出的两个方向：**允许后台运行**、**允许访问本地网络**。不同品牌允许后台运行的位置不同，按你的机型搜「允许应用后台运行」即可。

## 二、点「输入配对码」后立刻提示失败

| 可能原因 | 处理 |
| --- | --- |
| MIUI（小米、POCO）的通知样式不兼容 | 把 Shizuku 的通知样式在系统通知管理里改成「原生样式」（Android 样式），再重新配对 |
| 通知权限没给 | 系统设置里允许 Shizuku 发送通知——配对码要通过 Shizuku 的通知输入，通知被禁这一步就走不下去 |

改完通知样式后从「配对」重新走一遍流程。

## 三、点「启动」没反应或启动失败

1. 先关掉无线调试开关，再重新打开，回 Shizuku 再点一次启动（官方手册的建议）。
2. 确认 WLAN 处于连接状态，无线调试的配对与服务发现依赖本地网络。
3. 仍失败就重新配对一次：重新打开「无线调试」后端口会变，旧的配对关系可能失效。

## 四、Shizuku 用着用着自己停了

官方手册对「随机停止」给的处理是三件事一起做：

- 在系统设置里允许 Shizuku **后台运行**（省电策略改为无限制，路径按机型搜）；
- **不要关闭「USB 调试」和「开发者选项」**——无线调试建立在这两者之上，关了服务就断；
- 开发者选项里把 USB 使用模式改为「**仅充电**」（Android 8 叫「选择 USB 配置」，Android 9 及以上叫「默认 USB 配置」）。

国产系统后台清理激进，把 Shizuku 加进后台白名单是最有效的稳定手段。

## 五、电脑 adb 方式：设备检测不到 / 启动不了

| 现象 | 核对点 |
| --- | --- |
| `adb devices` 列表为空 | 手机「USB 调试」是否打开；数据线是否支持数据传输（部分充电线不传数据）；换一个 USB 口再试 |
| 设备在线但手机上没弹授权 | 拔插数据线，手机上勾选「一律允许」再确认 |
| 能连上但 Shizuku 起不来 | 确认执行的是 Shizuku 应用内提示的那条 `start.sh` 命令，路径以应用内显示为准；PowerShell 下 adb 命令写作 `./adb` |

官方口径：连接电脑启动适用于**未 Root 且运行 Android 10 及以下**的设备；adb 工具用 Google 提供的 SDK Platform Tools（`https://developer.android.com/tools/adb`）。

## 六、提示 adb 权限受限

部分定制系统会限制 adb 的权限范围，Shizuku 能启动、但拿到的权限比正常设备少。这是系统侧的限制，应用内无解——表现为某些依赖高权限的操作（包括修改运营商配置）执行失败。遇到这种情况只能换启动方式（如设备已 Root 就用 Root 启动）或换设备验证，不要反复重试。

## 七、排查完了还是不行

- 按 [Shizuku配对与授权教程](Shizuku配对与授权教程.md) 从头完整走一遍流程，重点核对每一步的开关状态；
- 确认 Shizuku 本身是官方渠道的较新版本，旧版与新版系统的兼容问题在更新里修；
- Shizuku 正常运行后 Nrfr 仍有问题，转 [修改国家码与运营商名教程](修改国家码与运营商名教程.md) 第四节的排查顺序，或查 [常见问题解答](常见问题解答.md)。
