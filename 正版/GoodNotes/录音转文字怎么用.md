## 一、这套语音功能适合谁

如果你常开会、上课，说话比打字快，这篇讲的语音转写能帮你把讲出来的话直接变成文字记录。本篇按 2.7.9 版的界面说明入口和操作，高版本若有调整，以应用内实际显示为准。

## 二、入口在哪

打开应用，首页会有「**欢迎来到会议语音转文字**」的卡片，右侧的「**查看记录**」可以翻以前转好的内容；点卡片里的「**点击使用**」（推荐位标题为「玩转语音」，配文「说话秒变文字」）就进入语音功能页。

语音功能页集中了五个入口，按用途选：

| 功能 | 干什么用 |
| --- | --- |
| 实时语音转写 | 主力功能：边说话边出文字 |
| 语音听写 | 用麦克风口述、转成文本输入 |
| 语音转写 | 对已有录音做转写 |
| 在线语音合成 | 把文字转成语音播出来 |
| 语音评测 | 对朗读发音打分（练习场景用） |

## 三、实时语音转写操作步骤

1. 进入「实时语音转写」页，页面标题就在顶部；
2. 点底部圆形**麦克风按钮**开始，首次使用系统会请求麦克风权限，允许后才能录音；
3. 正常说话，波形在跳动表示正在收音，**内容区会实时出现转出来的文字**；
4. 想给转写内容补字，点输入框左侧的「+」切换键盘手动输入；
5. 说完了点右上角**完成**，记录会保存，回首页「查看记录」能再次打开。

转写质量受环境噪声和收音距离影响：离麦克风近一点、安静一点的场合出来更准，这是所有语音转文字工具的共性。

## 四、文字识别（拍照转文字）

除了语音，纸上的内容也能变成可编辑文字：在笔记里插入或拍照扫描后，用**文字识别（OCR）**把图片里的字提取出来。典型用法是拍板书、拍纸质讲义 → 识别成文字 → 直接整理进笔记，省去手抄。识别入口与效果以应用内实际提供的为准。

## 五、语音速记与普通笔记怎么配合

快速记录一条想法时，语音速记比新建完整笔记更快——说完即得文字；等内容多起来、需要配图和排版时，再回到 [新建笔记与模板排版.md](新建笔记与模板排版.md) 把它整理成一篇结构完整的笔记。录音、文字、图片混排也是在同一套编辑工具里完成的。
