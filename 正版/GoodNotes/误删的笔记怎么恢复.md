## 一、删除笔记的正确姿势

删之前先走正规入口，这样内容会进废纸篓、留有反悔余地：

1. 打开 GoodNotes 首页，点**右上方的小勾**进入编辑（多选）状态；
2. 勾选要删除的笔记；
3. 点**右上方的废纸篓**图标，选中的笔记被移入废纸篓。

不要顺手清掉废纸篓——清空之后就找不回来了，删错了还指望它兜底。

## 二、误删了怎么恢复

只要还在废纸篓里，就能捞回来：

1. 点首页**右侧的设置**（齿轮）入口；
2. 进入**废纸篓**；
3. 找到被删的笔记，勾选后点**恢复**，笔记回到原来的位置。

恢复是按笔记逐个操作的；如果一次删了很多，耐心勾选即可。真正清空废纸篓之前值得问自己一句：这篇还要不要。与之相对，正想批量搬页、合并笔记，见 [分屏与复制粘贴怎么做.md](分屏与复制粘贴怎么做.md)。

## 三、界面不是中文怎么办

应用本身面向中文用户，但界面语言可能跟随系统或单独设置：

1. 打开手机**设置**，找到**应用管理里的 GoodNotes**；
2. 点**语言**（有的版本这一项显示为 `Language`），选择**简体中文**；
3. 回到应用，界面即变为中文。

这是安卓「按应用设置语言」的功能，需要系统版本支持（Android 13 及以上提供该入口）。如果你的手机在应用信息页里找不到「语言」项，直接把**系统整体语言**改成简体中文，再重启应用。

## 四、其他常见问题

| 现象 | 处理 |
| --- | --- |
| 装不上 / 提示解析错误 | 安装包没下载完整，回到 [下载与安装教程.md](下载与安装教程.md) 重新下载并核对大小与 MD5 |
| 找不到某篇笔记 | 用全局搜索按关键词找，或去收藏夹、对应文件夹里翻 |
| 合并笔记时粘贴报错 | 批量粘贴的页面太多，分几批粘贴 |
| 录音功能用不了 | 检查是否授予了麦克风权限：设置 → 应用 → GoodNotes → 权限 |
| 系统版本太旧装不了 | 这份安装包要求 Android 6.0 及以上，低于该版本无法安装 |

版本、包名等安装包信息以 [下载与安装教程.md](下载与安装教程.md) 里的表格为准；操作入口若与描述不一致，以应用内 2.7.9 版实际界面为准。
