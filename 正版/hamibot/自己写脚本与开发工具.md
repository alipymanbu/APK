## 一、写脚本前先知道这些

- **语言**：JavaScript 加 JSON，官方开发教程默认你已经会用基本语法；
- **出身**：Hamibot 客户端基于开源项目 Auto.js 二次开发，脚本语法一脉相承，网上 Auto.js 的教程资料大多能直接参考；两个项目的关系与差异单独写在 [与Auto.js的区别.md](与Auto.js的区别.md)；
- **免 root 边界**：基于无障碍的控件操作（找按钮、点文字）全程免 root；基于屏幕坐标的触摸操作（`click(x, y)` 这类）要安卓 7.0 以上或 root 才生效；
- **运行前提**：设备已配对、无障碍等权限已开（见 [注册配对与权限设置.md](注册配对与权限设置.md)）。

网盘里这份 1.6.1 客户端对应的脚本环境已支持模板字符串、`Array.includes()`、`String.padStart()` / `String.padEnd()` 这些语法（以官方更新日志为准），写新脚本可以放心用。

一段能跑的最小示例：

```javascript
app.launchApp('计算器');   // 按应用名启动
sleep(1000);               // 等待 1 秒
toast('已打开');           // 弹个提示
```

常用模块一览：

| 模块 | 干什么 | 例子 |
| --- | --- | --- |
| `app` | 启动、卸载应用 | `app.launch('com.hamibot.hamibot')` 按包名启动 |
| 选择器 | 找控件并操作 | `id('submit').findOne()` 按控件 id 找按钮 |
| `http` | 网络请求 | `http.get(url)`、`http.postJson(url, data)` |
| `threads` | 多线程 | `threads.start(function(){ ... })` 把耗时操作放进子线程 |
| `device` | 设备信息 | `device.isPortrait()` 判断竖屏（1.6.1 起） |
| `click` | 坐标触摸 | `click(x, y)`，需安卓 7.0+ 或 root |

## 二、在线编辑与远程调试

- **在线编辑器**：打开[脚本控制台](https://hamibot.com/dashboard/scripts/console)，选中脚本点「源码」进入编辑器，改完按 Ctrl+S 保存，适合改几行的小调整；
- **远程调试**：设备不在身边也能连上去调试，步骤见官方文档「开发」一节（[docs.hamibot.com](https://docs.hamibot.com/)）。

## 三、本地开发：VSCode 插件

写正式脚本建议在电脑上配 VSCode，再装插件「Hamibot 开发助手」（作者 BATU1579）：在 VSCode 插件市场搜这个名字安装即可，提供代码提示与文档查询，比网页编辑器顺手得多。插件的源码与问题反馈在 [github.com/batu1579/hamibot-assistant](https://github.com/batu1579/hamibot-assistant)。

## 四、REST API：让脚本对接外部系统

Hamibot 提供 REST API，可以从外部系统管理设备与脚本（比如由服务器触发某台设备跑某个脚本）：

- 地址：`https://api.hamibot.com/`，备用地址 `https://api.hamibot.cn/`（适用于小程序等场景）；
- 认证：HTTP 头里带个人访问令牌，在控制台的账号页生成，令牌以 `hmp_` 开头；有脚本作者提到令牌有效期一年、到期要重新生成，以控制台设置页当时显示为准；
- 配额：API 请求的免费额度是 100 次，超出在控制台订阅；当前用量在控制台「配额」页查。

```shell
curl -H "Authorization: hmp_你的令牌" https://api.hamibot.com/
```

接口清单见官方文档的 REST API 一节：[docs.hamibot.com/rest/overview](https://docs.hamibot.com/rest/overview)。

## 五、开源仓库与上架

- **开源**：安卓客户端源码在 [github.com/hamibot/hamibot](https://github.com/hamibot/hamibot)，2020 年创建，撰写本篇时 star 数 3000+，许可证以仓库内说明为准；
- **上架脚本**：写好的脚本可以提交到脚本市场供所有用户安装，官方允许作者从中获得收益，分成与上架规则以官方说明为准。
