# APKFx 版本更新与包名变化说明

> APKFx 有一个少见的特点：包名跟着版本号走，新版本装上不会覆盖旧版本。这篇讲清楚机制、已知版本对照和升级的正确姿势。

## 一、先给结论

从多个公开渠道汇总的安装包信息看，APKFx 不同版本的包名并不相同，而是把版本号编进了包名里（如 7.1 版是 `com.apkfx.app7_1`）。对安卓来说，包名不同就是两个不同的应用——所以**直接装新版不会覆盖旧版**，装完手机上会出现两个 APKFx 图标，两份数据也各自独立。这不是安装出错，是机制如此。

## 二、已知版本与包名对照

下表汇总自公开下载渠道标示的包名信息，**以你实际拿到的安装包为准**：

| 版本 | 包名 | 备注 |
| --- | --- | --- |
| 2.0 | `com.apkfx.app2` | 较早版本 |
| 4.0 | `com.apkfx.app4` | |
| 7.1 | `com.apkfx.app7_1` | 多个下载站在售的常见版本 |
| 7.3 | `com.apkfx.app7_3` | 本篇配套网盘包的版本，约 21.05 MB，MD5 `31F99D1CC9FD3B06EED7A52C6B1505A6` |

规律很直白：包名末尾跟着版本号。以后见到 `app7_4` 之类的写法，不用奇怪。

## 三、想升级到新版怎么操作

1. 获取新版安装包（方式见[下载与安装教程](下载与安装教程.md)的第二步）；
2. 直接安装——系统会把它当成一个新应用装进去；
3. 装完桌面出现新旧两个图标，**用新的那个**，确认一切正常后把旧的卸载；
4. 旧应用里的本地数据（如收藏记录）不会自动跟到新版，需要在新的版本里重新弄一遍。

## 四、怎么核对自己装的是哪一版

打开手机「设置 → 应用管理」，找到 APKFx，看两行信息：

- **版本号**：确认是不是你想要的那个版本；
- **包名**：`com.apkfx.app7_3` 这样的写法，末尾对上版本号，说明包没拿错。

手机上出现两个 APKFx、不确定哪个是新装的时候，也是用这个办法区分——包名末尾数字大的就是新版。想进一步确认包本身没被调包，用 MD5 比对，方法见[报毒与风险提示怎么处理](报毒与风险提示怎么处理.md)。装不上、提示签名不一致之类的问题，见[常见问题与解决办法](常见问题与解决办法.md)。
