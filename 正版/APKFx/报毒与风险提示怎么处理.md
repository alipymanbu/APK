## 一、为什么装 APKFx 容易被拦

APKFx 没有上架主流应用商店，分发靠 apk 安装包。安卓对「不走商店的安装」默认多一道盘问，安全软件对这类包也普遍更敏感。综合多个渠道的说明，拦截理由通常落在三种情况：

1. **非商店来源**：最常见的提示，本质是系统在提醒你「这个包不来自应用商店」。对软件库类应用属于正常现象；
2. **签名不在商店体系内**：上架应用走商店认可的签名链，第三方包的签名各不相同，容易被当成「陌生应用」；
3. **包名曾被标记**：某个包名若被人恶意举报过，之后装同包名的应用也会被连带提示。

## 二、两类提示，两种对待

| 提示内容 | 性质 | 建议做法 |
| --- | --- | --- |
| 「非应用商店来源」「未知来源应用」 | 常规提醒 | 确认来源可信后，按提示允许安装 |
| 「含恶意扣费代码」「索取大量隐私权限」等具体指控 | 值得当真 | 先别装这个包，换渠道重新获取或直接放弃 |

一条底线：**不要按「关掉安全软件再装」的教程做**。拦截提示是判断包有没有问题的重要信息源，关掉它等于把唯一的检查环节跳过了。

## 三、装之前核对 MD5

MD5 相当于安装包的指纹——同一份文件算出来的值一定相同，被人动过手脚就对不上。你从夸克网盘拿到的 7.3 版安装包，整理时的 MD5 是 `31F99D1CC9FD3B06EED7A52C6B1505A6`，核对方法（文件名按你实际下载到的为准）：

```powershell
# Windows（CMD 或 PowerShell 都行），在 apk 文件所在目录执行
certutil -hashfile APKFx_v7.3.apk MD5
```

```bash
# macOS / Linux
md5 APKFx_v7.3.apk      # macOS
md5sum APKFx_v7.3.apk   # Linux
```

算出来的值与上面一致，说明这份文件就是整理时的原始包；对不上就别装，重新下载一遍再核。其他版本对应的包名与信息，见[版本更新与包名变化说明](版本更新与包名变化说明.md)。

## 四、装完之后的两件事

1. **权限复查**：系统设置 → 应用 → APKFx → 权限。这类工具正常用不到通讯录、短信、无障碍这类高敏感权限；列表里出现超出功能需要的授权，卸载并换渠道重新获取；
2. **留意头几天的行为**：无故弹窗、静默自动下载、流量异常都算异常信号。正常情况下它只是一个浏览与下载资源的工具，安安静静待在桌面上。

## 五、拿不准的时候

- **多引擎在线扫描**：把 apk 文件传到 VirusTotal（[virustotal.com](https://www.virustotal.com/)）这类在线服务，几十个杀毒引擎同时扫一遍，比手机上单个安全软件的结论可靠。个别引擎报「通用/启发式」而主流引擎都干净时，多为误报；大厂引擎集中报毒就别装了；
- **宁可放弃**：安装包随时可以重新获取，设备安全比省事重要。装与不装拿不准时，默认不装。
