## 一、装之前先确认三件事

1. **机型**：官方下载页写明支持 MX4 及后续上市的魅族机型。更早的老机型官方没有承诺兼容。
2. **系统版本**：官方要求把系统升级到当时的最新出厂系统再检测，Flyme 4 及更早的系统版本不支持。如果你的魅族手机还在很老的系统上，先升级系统，否则装上也可能打不开或检测异常。
3. **版本与体积**：本资源为 2.1.2 版，安装包 6.15 MB。这是魅族官方 mCheck 下载页当前标注的同一版本号（截至 2026-09 检索时）。安装包 MD5 为 `D4B0DCD0D28E9F288E0817B62B08FE3A`，在意文件完整性的话可以先核对再安装。

## 二、安装包从哪拿

魅族mCheck 是魅族售后服务体验中心使用的硬件检测辅助工具，官方通过魅族服务页面的 mCheck 下载页分发，常见应用商店里不一定搜得到。你可以直接从魅族mCheck 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/a9c57bcffee9](https://pan.quark.cn/s/a9c57bcffee9) 获取，转存到自己网盘后下载 APK 即可，也可以先下到电脑再传到手机。

拿到文件后核对两点：

| 核对项 | 应为 |
| --- | --- |
| 文件名 | `mcheck_v2.1.2.apk` 一类的 APK 文件 |
| MD5 | `D4B0DCD0D28E9F288E0817B62B08FE3A` |

MD5 建议在电脑上用校验工具核对；手机端部分文件管理器也带「文件校验」功能，但入口名称各家不同，以你手机文件管理器的实际功能为准。

## 三、安装步骤

1. 把 APK 文件传到手机存储（网盘 App 直接下载，或数据线 / 局域网传输都行）。
2. 在文件管理器里点开这个 APK。首次安装侧载应用时，系统会提示「禁止安装未知来源应用」，按提示允许当前文件管理器（或浏览器）安装应用。Flyme 的授权入口在「设置 → 安全」里，不同系统版本路径略有差异。
3. 点「安装」，等几秒完成。桌面会出现「魅族手机检测工具」图标，标题栏显示「魅族手机检测工具 V2.1.2」。
4. 打开应用，第一屏会显示「检测到手机信息」和你的机型型号。到这里安装就完成了，接下来怎么跑检测见 [检测项目与一键检测步骤.md](检测项目与一键检测步骤.md)。

## 四、装不上时的排查

| 现象 | 常见原因与处理 |
| --- | --- |
| 提示「解析包出现问题」 | 多半是下载不完整，重新下载一遍再装；核对 MD5 不一致就换一份 |
| 提示「应用未安装」 | 系统版本过低是常见原因（Flyme 4 及更早不支持），先升级系统 |
| 与已有应用冲突 | 如果手机以前装过其他来源的 mCheck，先卸载旧的再装 |
| 存储不足 | 6.15 MB 的包不大，但安装仍需要少量临时空间，清一点存储再试 |

装上之后打不开、闪退，或者非魅族手机想装着试试，单独列在 [常见问题与无法使用排查.md](常见问题与无法使用排查.md) 里。
