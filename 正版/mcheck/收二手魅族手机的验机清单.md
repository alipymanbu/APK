> 本篇给你一份收二手魅族手机时能照着做的验机清单：先查 Flyme 账号有没有退出、再对三码、再看外观，最后用魅族mCheck 把硬件整体过一遍。

## 一、先确认 Flyme 账号已退出（最要紧的一步）

魅族手机带「查找手机」功能：登录了 Flyme 账号的设备，机主可以远程挂失、锁定、清空数据。所以收二手魅族机，**第一件事不是看外观，而是确认卖家的 Flyme 账号已经退出**——账号没退的机器，你拿回家随时可能被远程锁死，这样的机器再便宜也不能要。

操作：

1. 打开「设置」，看顶部有没有已登录的 Flyme 账号。要求卖家**当场退出**（设置 → Flyme 账号 → 退出登录）。
2. 卖家说忘了密码：到官方找回入口 `https://i.flyme.cn/forgetpwd` 按提示重置；重置不了就走账号申诉 `https://i.flyme.cn/appeal`（可申请重置安全手机、清除密保问题，官方口径 3 个工作日内以短信反馈结果）。
3. 机器处于挂失锁定状态：在网络正常时用官网或「查找手机」App 登录该机上的账号点「解除挂失」；没有这个按钮就直接打魅族客服 400-788-3333（号码以官网当前公示为准）。
4. 卖家既退不了账号又不愿配合申诉的，直接放弃交易。

## 二、三码合一：核对设备的「身份证」

三个地方的 IMEI 必须逐位一致：

| 出处 | 怎么看 |
| --- | --- |
| 拨号盘 | 输入 `*#06#`，弹出 IMEI |
| 设置 | 「关于手机」里的 IMEI / 序列号 |
| 包装盒 | 盒身贴纸（没盒子就与卡托上的码对照） |

再用魅族mCheck 交叉一遍：启动页点「更多信息」，手机信息页里列着 SN、IMEI1、IMEI2、系统版本号，字段含义与核对口径见 [手机信息字段与验机.md](手机信息字段与验机.md)。任何一处对不上，机器可能是改码机或拼装机，终止交易。

## 三、外观与进水痕迹

行业质检（如回收宝公开的质检流程）和大量验机经验总结下来的通用做法：

- **螺丝**：底部的螺丝看有没有拧花、划痕，有拆动痕迹的机器大概率开过盖；
- **缝隙**：后盖、屏幕与中框的缝隙应均匀，一边大一边小、能塞进纸片的，可能换过屏或后壳；
- **卡托防水标**：取出 SIM 卡托对着光看，防水标遇水会变红，变红说明进过水或受过潮；
- **充电口**：看有没有积灰、毛刺、烧蚀痕迹；
- **屏幕**：亮白图看压伤灰斑、亮黑图看亮点漏光，卖家不肯发黑白屏图的要多留心。

## 四、用魅族mCheck 把硬件整体过一遍

标识核对完，装上魅族mCheck 跑一遍一键检测（工具从魅族mCheck 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/a9c57bcffee9](https://pan.quark.cn/s/a9c57bcffee9) 获取；检测项的配合动作见 [检测项目与一键检测步骤.md](检测项目与一键检测步骤.md)）。二手机重点盯这几项：

| 检测项 | 二手机高发问题 |
| --- | --- |
| 屏幕 | 坏点、亮点、亮斑（换过屏或摔过） |
| 按键 | 电源键、音量键松垮、回弹差（拆修过的机器常见） |
| 声音 | 听筒杂音、喇叭破音（进水机典型后遗症） |
| USB | 充电口接触不良、时断时续 |
| 相机 | 对焦迟钝、进灰（镜头内黑点） |

再补两个检测项之外的动作：插卡打一通电话验证听筒与麦克风、连一次 WiFi 和蓝牙；电池方面观察充电时是否异常发热、电量跳变。

## 五、验出问题之后

- 还在交易流程内：拿着检测结果与卖家协商退货，黑白屏图、检测截图都是凭据；
- 已经收下但想修：检测完把结果上传给售后再报修，能省去复现环节，官方送修入口与流程见 [检测结果上传与售后送修.md](检测结果上传与售后送修.md)。
