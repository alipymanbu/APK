## 一、什么手机能用

| 问题 | 答案 |
| --- | --- |
| 哪些机型支持 | 官方口径：MX4 及后续上市的魅族机型 |
| 需要什么系统 | 升级到当时的最新出厂系统；Flyme 4 及更早不支持 |
| 非魅族手机能用吗 | 官方没有承诺。安装可能成功，但它测的是魅族硬件体系，在别的品牌手机上各项检测不保证可用，上传结果也没有意义 |
| 模拟器上能用吗 | 不行，模拟器没有真实硬件可测 |

工具在启动页只显示「检测到手机信息」而不进检测列表时，先确认机型与系统版本是否满足上面两行。

## 二、装不上

按现象对症：

- **「解析包出现问题」**：安装包下载不完整是第一嫌疑，重新下载并核对 MD5（`D4B0DCD0D28E9F288E0817B62B08FE3A`，完整核对方法见 [下载与安装教程.md](下载与安装教程.md)）。
- **「应用未安装」**：系统版本过低（Flyme 4 及更早不支持），先升级系统再装。
- **点了没反应**：确认 APK 是完整下载的 `.apk` 文件，而不是改了名的压缩包。

## 三、打不开或闪退

1. **系统不满足要求**：老系统上是主因，升级 Flyme 后再试。
2. **以前装过别的版本**：卸载旧的，重启后再装当前包。
3. **开机时间太长、内存紧张**：重启一次手机再打开，很多「闪退」在这一步就解决了。

## 四、检测项卡住或没反应

| 情况 | 处理 |
| --- | --- |
| USB（充电）项不动 | 插上充电线再继续，这一项不插线测不了 |
| 按键项不动 | 它在等你实际去按实体键，看屏幕提示逐个按 |
| 声音项没声音 | 确认没连蓝牙耳机（声音走到别处了）、媒体音量没被静音，再重试该项 |
| 相机项黑屏 | 检查有没有其他应用占着摄像头，关掉后台再进 |
| 整个列表点不动 | 退出应用重新打开，重跑一键检测 |

某一项反复失败时，先换个角度验证（比如充电口不行就换一根线、换一个充电头），确认是硬件本身的问题再送修；送修入口见 [检测结果上传与售后送修.md](检测结果上传与售后送修.md)。

## 五、它和拨号盘工程模式是一回事吗

不是。两个入口经常被混为一谈：

| | 魅族mCheck | 拨号盘工程模式 |
| --- | --- | --- |
| 打开方式 | 安装的独立 App | 部分魅族机型拨号盘输入 `*#*#3646633#*#*`（多见于 MTK 平台机型，因机型而异，输入后自动弹出） |
| 覆盖范围 | 七大项硬件检测，逐项给出结果 | 工程测试菜单，项目与机型强相关 |
| 结果去向 | 可上传到魅族售后服务系统 | 无上传，纯本地 |
| 适用人群 | 普通用户也能按提示操作 | 菜单项多且偏专业，不认识的选项不要乱点 |

两个都试过之后还是分不清问题出在哪，就带着 mCheck 的检测结果联系售后，让专业的人接手。
