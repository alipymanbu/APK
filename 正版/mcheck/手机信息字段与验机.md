## 一、这个页面在哪

打开魅族mCheck，启动页显示「检测到手机信息」和机型型号，点型号下方的「更多信息」，进入「手机信息」页。这一页是只读的设备标识清单，不做任何写入操作，所以拿来看二手机没有任何风险。

## 二、字段对照表

| 字段 | 含义 | 验机时看什么 |
| --- | --- | --- |
| 手机 SN | 出厂序列号（Serial Number），一台一码 | 与包装盒上贴纸的 SN 是否一致 |
| 手机 MEID | CDMA 制式设备标识，电信网络相关设备才有 | 留空不一定异常，取决于机型与制式 |
| 手机 IMEI1 | 主卡槽的移动设备国际身份码 | 与拨号盘 `*#06#` 查到的第一串一致 |
| 手机 IMEI2 | 第二卡槽的 IMEI，双卡机型才有 | 与 `*#06#` 查到的第二串一致 |
| 手机系统版本号 | 系统构建标识，形如 `VxxxIR release-keys` | 判断是不是国行原厂系统（release-keys 为正式签名） |
| 手机型号 | 机型代码，如 `PJJ110` | 与该型号官网参数页对得上 |
| NFC 卡绑定 | NFC 卡的绑定情况 | 读不到时会显示「未知」，不代表 NFC 坏了 |

其中 IMEI 是验机时最有用的一项：IMEI 相当于手机的身份证号，正规渠道机器的 IMEI 会同时印在包装盒上，并且可以与系统内查询结果互相印证。

## 三、二手机验机的用法

1. **先看这一页，再拨 `*#06#`**：拨号盘输入 `*#06#`（Android 通用代码）会弹出 IMEI，逐位与 mCheck 手机信息页里的 IMEI1 / IMEI2 比对；两者对不上，说明主板或系统被动过，谨慎入手。
2. **对包装盒**：盒子上的 SN 与 IMEI 贴纸与页面显示一致，才说明「盒机一体」。
3. **看系统版本号**：`release-keys` 结尾一般是正式出厂签名系统；显示开发者版本或奇怪的构建号，可能是刷过机的机器。
4. **标识看完再跑硬件**：标识核对完，回到检测列表跑一键检测，屏幕坏点、按键、充电这些二手机高发问题都能当场暴露。流程见 [检测项目与一键检测步骤.md](检测项目与一键检测步骤.md)。

从卖家手里收机时，账号锁、外观痕迹、电池这些字段之外的检查同样要做，完整的动手顺序单独整理在 [收二手魅族手机的验机清单.md](收二手魅族手机的验机清单.md)。

## 四、字段显示 unknown 或空白怎么办

在实机上这些字段**可能显示 `unknown` 或留空**——实测截图里就有 SN 显示 `unknown`、MEID / IMEI 空着的情况。这不一定代表机器有问题，常见原因：

- 双卡机型没插 SIM 卡时，IMEI 相关字段可能读不全；
- 部分机型系统对这类标识的读取权限收得很紧，工具拿不到值；
- MEID 只有电信制式相关的设备才填。

所以**不要只凭这一页下结论**：用 `*#06#` 和包装盒交叉核对，再结合硬件检测项的结果综合判断。如果 IMEI 连 `*#06#` 都查不到或与盒子明显不符，那才是要警惕的信号。
