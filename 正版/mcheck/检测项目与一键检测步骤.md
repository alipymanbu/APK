## 一、打开后的三个页面

装好后从桌面打开「魅族手机检测工具」，流程是固定的三步：

1. **启动页**：显示「检测到手机信息」，中间是你的机型型号（如 `PJJ110` 这类型号代码），下面有「更多信息」链接和一颗蓝色的「进入」按钮。
2. **手机信息页**：点「更多信息」可以看 SN、IMEI 等设备标识字段，这一页的用途在 [手机信息字段与验机.md](手机信息字段与验机.md) 里单独讲，验机场景用得最多。
3. **手机检测页**：点「进入」进入检测列表，每项右侧标着「未检测」，底部一颗「一键检测」按钮。

## 二、七个检测项

检测列表共七项，其中四项标了「必检」（官方认为送修检测时这几项必测）：

| 检测项 | 覆盖内容 | 官方标注 |
| --- | --- | --- |
| 屏幕 | LCD、触屏 | — |
| 按键 | 物理按键、mBack | 必检 |
| 传感器 | 光感、重力、距离、地磁、陀螺仪 | — |
| 声音 | 喇叭、听筒、MIC、震动、耳机 | 必检 |
| 相机 | 前置相机、后置相机、闪光灯 | 必检 |
| 网络信号 | WiFi、蓝牙、SIM 卡 | — |
| USB | 充电 | 必检 |

几个要注意的点：

- **mBack** 是魅族老机型上那颗可按可轻触的实体 Home 键，全面屏机型上对应的则是侧键与屏下指纹相关交互，具体测什么以实机提示为准。
- 「网络信号」项测的是 WiFi、蓝牙、SIM 卡的连接状态，不是网速跑分。
- 「USB」项只标了「充电」，也就是验证充电口和充电链路是否正常，不是数据传输测试。

## 三、一键检测怎么跑

点底部的「一键检测」，工具会按列表顺序逐项过。这类硬件检测大多需要你本人配合，不是全靠自动跑：

- **按键项**：屏幕会提示你按对应的实体键，按它提示逐个按一遍。
- **声音项**：会依次出声（喇叭、听筒），你自己判断有没有破音、杂音；测听筒时把手机贴到耳边，测震动时手摸机身感受；插上耳机可以顺带测耳机通路。
- **屏幕项**：会出现纯色或测试画面，你观察有没有坏点、亮点、亮斑；触屏部分按提示沿轨迹滑动，看有没有断触。
- **相机项**：分别打开前置和后置取景，画面正常、对焦能动就算过；闪光灯会真的闪，别对着眼睛。
- **传感器项**：按屏幕提示转动、遮挡手机（距离传感器用手挡一下即可）。
- **USB / 充电项**：提前把充电线插上，否则这一项没法继续。

每一项做完，列表里对应条目的状态会从「未检测」变成检测结果。全部跑完后，结果怎么交给售后，见 [检测结果上传与售后送修.md](检测结果上传与售后送修.md)。

## 四、跑检测前的准备清单

| 准备 | 为了哪一项 |
| --- | --- |
| 电量充到够用，或直接插着充电器 | USB（充电）项；同时避免检测中途断电 |
| 找个安静环境 | 声音项要靠耳朵听杂音 |
| 一张亮度均匀、白纸或纯色画面可参考的环境 | 屏幕坏点观察更准 |
| 充电线、（可选）耳机 | USB 项、耳机通路 |
| 摘掉手机壳、贴膜视情况 | 按键手感与触屏灵敏度判断更真实 |

检测项点不动或卡在某一项时，多半是配套条件没满足（比如 USB 项没插线），先补条件再重试；更多情况见 [常见问题与无法使用排查.md](常见问题与无法使用排查.md)。
