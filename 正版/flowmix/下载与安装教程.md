## 一、Flowmix 是什么

Flowmix 是一款 Android 全局音频均衡器应用：它作用在系统音频输出层，而不是某个播放器内部，所以你用什么音乐 App、视频 App 甚至游戏，它都能统一处理声音。本篇只讲安装这件事——拿包、装上、授权；装好之后怎么调，见[新手怎么调音.md](新手怎么调音.md)。

## 二、安装前先对一眼版本信息

装不上、打不开多半是版本对不上，先把这几项核对清楚：

| 项目 | 值 |
|---|---|
| 包名 | `cn.ykload.flowmix` |
| 版本 | Beta5-10 |
| 安装包大小 | 6.37M |
| MD5 | `de123d66d3ec0f25e6631c601b5375e4` |
| 系统要求 | Android 9.0（API 28）及以上 |
| 架构 | ARM64-v8a |
| 所需存储空间 | 10 MB 以内 |

网盘里那份就是上表的 Beta5-10。官方下载页还会发布更新的版本，版本号以 [Flowmix 官方下载页](https://docs.flowmix.ykload.com/download.html) 当时显示为准；换版本前建议先看官方的[升级注意事项](https://docs.flowmix.ykload.com/upgrade-notice.html)。

## 三、从哪里拿安装包

两个入口，任选其一：

1. **官方下载页**：[docs.flowmix.ykload.com/download.html](https://docs.flowmix.ykload.com/download.html)，页面上标注「官方下载 [推荐]」的直链就是当前最新版；
2. **本篇头部的 [Flowmix 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f2b90a749954)**：转存到自己的网盘后再下载，好处是这份包不会失效，想回滚到 Beta5-10 时也有地方拿。

下载前可以顺手核对 MD5 与上表是否一致，不一致说明不是同一份包。

## 四、安装步骤

1. 在手机上点击 APK 文件开始安装；
2. 若系统弹出「禁止安装来自此来源的应用」，这是安装第三方 APK 时的常规提示，在系统设置里允许本次安装即可；
3. 装完首次启动会进入引导页，按提示把权限逐个授掉；
4. 权限授完即可进入主界面，接下来按[新手怎么调音.md](新手怎么调音.md) 准备一条 EQ 配置。

## 五、首次启动要给哪些权限

| 权限 | 用途 | 必须？ |
|---|---|---|
| 音频设置权限 | 应用全局 EQ 效果 | 是 |
| 蓝牙权限 | 检测蓝牙音频设备 | 是 |
| 文件读取权限 | 读取本地 EQ（txt）文件 | 是 |
| 通知权限 | 显示状态通知、保持后台运行 | 推荐 |

四项都授掉最省事。通知权限虽标「推荐」，但它关系到后台保活，想让 Flowmix 一直在线就别拒绝，详见[后台保活与重启失效排查.md](后台保活与重启失效排查.md)。想在手表上开关 Flowmix、切换配置，还可以另装穿戴端的 FlowChan，安装方式见[FlowChan手表伴侣怎么装.md](FlowChan手表伴侣怎么装.md)。

## 六、装不上、打不开

**安装后无法打开**：通常是安装包下载不完整，或设备不是 ARM64 架构。重新下载一次（拿包入口见本篇头部），再确认手机确实是 ARM64-v8a。

**提示「应用未安装」**：两个常见原因——手机上装过不同签名的旧版本，或存储空间不足。先卸载旧版 Flowmix，检查剩余空间，再重新安装。

**首次启动比较慢**：首次启动要初始化音频引擎、加载数据，多等一两秒属正常现象，不是卡死。

## 七、想卸载时

在系统设置里正常卸载即可。若想连数据一起清掉，卸载前先进入 App 设置清除数据；账号里的云端配置会保留，下次登录同一账号还能恢复。
