## 一、为什么它会被后台杀掉

Flowmix 要一直挂着才能持续处理音频，而 Android 的省电机制会杀掉后台进程。被杀之后 EQ 就断了，所以保活是长期使用 Flowmix 必做的一件事。

**基础三件套**（多数人做到这层就够了）：

1. **授予通知权限**，让 Flowmix 显示持久通知；
2. **在最近任务里锁定** Flowmix 的卡片（后台卡片上锁），防止一划就清掉；
3. **禁用电池优化**：设置 → 应用 → Flowmix → 电池 → 不优化；部分机型还要关掉省电策略。

**还不够时的进阶措施**：

1. 开启保活通知；
2. 允许自启动——注意这一项在个别机型上反而是关掉效果更好，自行试一遍；
3. 禁用电池优化、关闭省电策略（同上，部分机型路径不同）；
4. 允许后台活动（Magic OS 设备）；
5. 到「Sync」页面的设备记忆里，把要用的音频设备设为「自启动」，并开启该设备的 EQ 选择弹窗；
6. 授予无障碍权限——这一项权限过高，建议把上面的都试过还不行再考虑。

此外，设置里还有「无感后台」（设置 → 实验性）可以打开，保活场景下也建议打开「自动进入无感后台」。

## 二、重启手机后 EQ 失效

这是正常现象，不是坏了：重启后系统效果链是干净的，你手动打开一次 Flowmix 就能重新激活。不想每次开机都点一下，有两条路：

- 给 Flowmix 授予无障碍权限，让它能自动激活；
- 至少要做到：允许自启动 + 在设备记忆里把所需音频设备设为「自启动」。

注意「能自启动」和「自动激活某设备的音效」是两件事，后者要在设备记忆里单独配置。

## 三、换了耳机/设备，EQ 没自动应用

按这三项检查：

1. 该设备是否已保存过配置；
2. 设备记忆模式是否设为「自启动」；
3. Flowmix 是否还在后台正常运行。

想让某个设备每次插上就自动用某条 EQ，就得在「Sync」页面的设备记忆里把它配好；不希望某台设备被管理，也可以在设备记忆的已隐藏列表里把它藏起来。

## 四、配置在多台设备间没同步

Flowmix 的云同步（FlowSync）把 EQ 配置存在云端，换机或平板共用时靠它。同步不生效按这几步查：

1. 两台设备登录的是**同一个 YKload 账号**；
2. 「Sync」页面的同步状态是否显示「已连接」；
3. 手动触发一次同步，等几秒刷新；
4. 网络本身通不通（WiFi / 移动数据切一下）。

登录不上先查网络、稍后重试或换网络环境。云端数据在卸载后仍保留，重新登录即可恢复，所以换机前不必手动导出。想进一步了解这块，见[新手怎么调音.md](新手怎么调音.md) 与官方 [FAQ](https://docs.flowmix.ykload.com/faq.html)；如果问题其实是「开了没声音」而不是「后台掉线」，走[开启后没效果怎么办.md](开启后没效果怎么办.md) 的排查链。
