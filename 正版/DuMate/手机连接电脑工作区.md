## 一、这个功能解决什么

手机适合下指令，不适合跑重活——几百页 PDF 解析、上千行表格清洗、批量格式转换，手机上又慢又容易中断。连上「电脑工作区」之后，这些任务在电脑上执行，你在外面用手机发指令、看进度、收结果，等于远程遥控自己的电脑。

手机端与电脑端之间靠**云端中转**互通，所以两端都必须联网，且登录**同一个账号**。

## 二、配对前的准备

| 准备项 | 要求 |
| --- | --- |
| 账号 | 手机端与电脑端登录**同一个**百度账号（或同一百度智能云账号），账号不同查不到设备 |
| 电脑端 | 已安装桌面版 DuMate 并登录，Windows 10 及以上或 macOS（M 系列芯片） |
| 网络 | 两端都要能联网，任务经云端中转 |
| 客户端版本 | 两端尽量都更到最新，旧版本可能没有该入口 |

电脑桌面版从官网 [www.dumate.cn](https://www.dumate.cn/) 下载；手机端安装包见 [下载与安装教程.md](下载与安装教程.md)。

## 三、连接步骤

**手机侧（发起方）**：

1. 进入首页对话界面，点消息输入框**左侧的加号「+」**，展开功能菜单；
2. 选【连接电脑工作区】；
3. 点页面底部的【连接新设备】，按提示授予设备搜索权限（一般需要定位/附近设备权限，这是系统对局域网发现的硬性要求）。

**电脑侧（被发现方）**：

4. 打开电脑端 DuMate，确认登录的是与手机**完全相同**的账号；
5. 进入设备管理页面，点【查找设备】；
6. 手机出现在列表里就点连接，配对完成。

之后你在手机上发的指令会经云端中转路由到电脑执行，处理过程与结果实时同步回手机端。

## 四、连上之后怎么用

- **照常发指令**：在手机首页输入框描述任务即可，不用手动选「发给电脑」，重活会按工作区规则路由；
- **切走也不怕**：任务在电脑上跑，你可以退出 App，完成后收通知；
- **成果同步**：生成的文档、数据、报告回传到手机，能直接查看、继续改；
- **会话接续**：换设备后不用重新交代任务背景，会话、资料、进度和产物在两端同步。

## 五、连不上 / 断了怎么排查

按出现频率从高到低：

1. **两端账号不一致**——最常见。检查手机与电脑登录的是不是同一个账号；
2. **电脑端没开着**——任务要路由到电脑，电脑客户端得处于运行状态；
3. **设备搜索权限没给**——手机侧点【连接新设备】时弹的权限框选了拒绝，去系统设置里补授权再重试；
4. **网络隔离**——两端不在可互通的网络环境（如电脑挂了代理、公司网络限制出站），先确认电脑能正常访问网页；
5. **版本过旧**——两端客户端都升到最新再试。

仍连不上时，把配对步骤原样重走一遍（先断开再【连接新设备】）通常能恢复。其他跑不动的情况见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 六、用它之前值得知道的边界

- **指令经云端中转**：不是局域网直连，涉及敏感文件时先想清楚是否适合走这条链路；
- **电脑得有电、有网、没休眠**：电脑睡眠后任务不会自己醒，出差前把电脑设置成不自动休眠更稳；
- **手机自己也能干活**：轻量任务（问答、网页调研、小文件处理）不必转发，直接手机端跑更省事。
