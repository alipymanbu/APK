## 一、DuMate 是什么

DuMate（中文名「百度搭子」）是百度出的一款 AI 办公智能体，有手机版和电脑桌面版两套。你用一句大白话描述要干的活——「把这份合同的条款提出来」「按类型整理下载文件夹」「搜集某行业最新动态做一份 PPT」——它自己拆步骤、调技能、跑到出结果，而不是只回你一段文字。

电脑版跑在 Windows / macOS 上，负责重度任务（大文件、批量处理）；手机版装在安卓或 iPhone 上，除了自己干活，还能把指令转发给电脑去跑。本篇讲的是**安卓手机版**怎么拿、怎么装。

厂商信息来自官方版权页：百度在线网络技术（北京）有限公司、北京百度网讯科技有限公司。官网入口是 [www.dumate.cn](https://www.dumate.cn/)，产品页在 [cloud.baidu.com/product/dumate.html](https://cloud.baidu.com/product/dumate.html)。

## 二、先确认你的手机能不能装

装之前对一下这几项（第三方应用商店在 2026-09 标注的口径，以官方页面当时显示为准）：

| 项目 | 要求 |
| --- | --- |
| 系统 | Android 8.0 及以上 |
| 网络 | 必须联网，任务在云端跑，离线用不了 |
| 磁盘 | 安装包约 50~63 MB（不同版本有差异），安装后还要留出运行缓存空间 |
| 账号 | 一个能收短信的手机号，或已有的百度账号 / 百度智能云账号 |

包名是 `com.baidu.dumate`，认准这个就不会装到同名的仿品上。

## 四、安装与首次启动

1. 点开 APK，系统若提示「禁止安装未知来源应用」，到设置里给浏览器或文件管理器临时开一次「允许安装未知应用」，装完可以关掉；
2. 装完打开，第一屏是服务协议与隐私政策，**必须同意才能继续**；
3. 进入登录页。

## 五、登录方式

三种都行，任选其一：

- **手机号**：收短信验证码，新用户用这个最快，没注册过会自动注册；
- **百度账号**：已有百度 App / 网盘账号的直接登；
- **百度智能云账号**：适合已经在用百度智能云的人。

登录入口的位置：点首页左上角的三横线图标，或任意功能入口，都会带出操作页。

## 六、装完先做三件事

1. **给权限**：首次发起带文件、图片、语音的任务时，系统会弹权限申请——相册/文件读取、麦克风、相机按需给。给不给都能聊天，但不给文件权限就用不了上传和整理文件（详见 [常见问题与解决方法.md](常见问题与解决方法.md)）。
2. **看一眼积分**：右上角或个人中心能看到当前积分数，新账号有免费额度，用完次日刷新，收费口径见 [积分与会员价格.md](积分与会员价格.md)。
3. **发第一条测试指令**：比如「帮我整理一下相册里最近的截图」，跑通一遍就知道它怎么回你了，具体玩法见 [新手使用教程.md](新手使用教程.md)。
