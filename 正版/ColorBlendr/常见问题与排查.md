# ColorBlendr 常见问题与排查

> 服务开关打不开、授权提示被拒、无线 ADB 配对卡住、改完颜色不动——按现象分类列出原因与处理，照着对即可。

下面这些都是「现象 → 原因 → 处理」的对应关系，先从最像你遇到的那一条看起，改完再看一眼服务状态行是不是 `Theming is active`，很多问题到这就结束了。

## 一、装不上、装完打不开

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 解析包错误 | 安装包没下完或已损坏 | 重新下载，核对体积 4.51 MB、MD5 与 [下载与安装教程.md](下载与安装教程.md) 表格一致 |
| 应用未安装 | 手机上已有同包名的更高版本 | 先卸载旧版；卸载前记得先关服务，步骤见 [备份恢复与彻底卸载.md](备份恢复与彻底卸载.md) |
| 已阻止安装 | 未知来源安装没开 | 在「特殊应用权限 → 安装未知应用」里给文件管理器或浏览器开权限 |
| 装上了但没有可改的项 | 系统低于 Android 12，或系统不带 Material You | 官方要求 Android 12 及以上，低于该版本无解 |

## 二、服务与授权

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 服务开关打开后自己关掉 | 电池优化在后台清理它 | 在系统设置里把 ColorBlendr 的电池策略设为不受限制 |
| 状态行一直不是 `Theming is active` | 服务没开或没跑起来 | 先开关一次，再按下一行的授权项逐条对 |
| 提示 `Root permission not granted` | 超级用户请求被拒 | 到 root 管理器里把该应用的授权改为允许，回应用重试 |
| 提示 `Shizuku permission not granted` | Shizuku 授权没给，或 Shizuku 已经停了 | 确认 Shizuku 在运行，授予权限后重试；手机重启后要重新启动 Shizuku |
| 生成不了壁纸配色、只提示要文件访问权限 | 缺少读取壁纸的媒体/文件访问权限 | 在系统设置里补上该权限；暂时不想给就改用「Custom primary color」手动指定颜色 |

## 三、无线 ADB 配对卡住

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 走到输入配对码就没了下文 | ColorBlendr 的通知权限没给 | 允许它发通知，配对通知是流程的一环 |
| 通知里没有输入配对码的地方 | 系统把通知样式改成了自家风格 | 到「通知 → 通知样式」切回 Android 原生样式再试 |
| 提示配对不成功 | 配对码过期、或手机切回了蜂窝网络 | 重新点「使用配对码配对设备」拿新码；Wi-Fi 无外网时先关移动数据 |
| 每次重连都要重新配对 | 无线调试随 Wi-Fi 断开而关闭 | 属于该模式的正常行为，想省事就改用 Shizuku 或 Root |

## 四、改完颜色不动

按这个顺序查，前三步能解决绝大多数情况：

1. **服务在不在跑**——状态行是否为 `Theming is active`；
2. **模式配没配对**——Root / Shizuku / 无线 ADB 三者任一路径没走通都写不进去，见 [Root与Shizuku和无线ADB模式怎么选.md](Root与Shizuku和无线ADB模式怎么选.md)；
3. **应用有没有重启**——已经打开的应用要退出重进才会刷新配色；单独指定过的应用更要「强行停止」后重开；
4. **是不是这台设备的系统不读 Material You**——见下表。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| Google 系应用变了、系统自带应用没变 | 系统（如 OneUI 类）自带应用用自己的调色板 | 官方说明这类系统只影响 Google 应用与支持 Material You 的应用，无法在此范围内解决 |
| 只有某几个应用不变 | 这类应用改用自带的调色板 | 用「Per app theme」把它们挑出来单独指定，见 [单独给某个应用改色怎么做.md](单独给某个应用改色怎么做.md) |
| 重启手机后配色恢复原样 | 无线 ADB/Shizuku 的授权随重启失效，或系统自身重置了配色 | 重新配一次模式，再应用一次配色；常用则考虑改用 Root |
| 个别开关是灰的、点不动 | 需要更高的 Android 版本或 root 权限 | 属于官方说明的限制，换模式或升级系统；不必反复重装 |
| 三星手机升级 One UI 8.5 后深色模式黑灰混杂 | One UI 8.5 改了默认调色板，与 Material You 取色方式对不上 | 把风格指定成 Neutral 或 Tonal Spot，做法见 [三星OneUI深色模式发灰怎么修.md](三星OneUI深色模式发灰怎么修.md) |

## 五、通知栏与后台

| 现象 | 处理 |
| --- | --- |
| 通知栏长期挂着一条「Background service」通知 | 点它即可关闭；或在系统通知设置里把该渠道静音，不影响改色 |
| 觉得耗电变多 | 先关掉「Update colors on screen off」，它会让熄屏后仍定期刷新配色；不需要就关 |
| 想临时停用但保留配置 | 关掉服务开关即可，配置不会被清掉，见 [备份恢复与彻底卸载.md](备份恢复与彻底卸载.md) |

## 六、其他偶发情况

| 现象 | 处理 |
| --- | --- |
| 改色后锁屏壁纸变成纯黑 | 有用户反馈过这一现象。先重启手机看是否自行恢复；仍不正常就关掉服务开关再重启；要彻底回到原状按 [备份恢复与彻底卸载.md](备份恢复与彻底卸载.md) 的顺序卸载 |
| 之前调好的深色模式观感又变回去了 | 多半是又动过系统的「壁纸与样式 → 调色板」，或系统更新换了取色规则；重新应用一次 Neutral / Tonal Spot，见 [三星OneUI深色模式发灰怎么修.md](三星OneUI深色模式发灰怎么修.md) |
| 手动改过的色阶长按复位没反应 | 官方在版本更新里修过「长按不能复位手动改色」这一项；长按无效时，改成把整块调色板重新应用一次，或恢复一份备份 |
| 小米、OPPO、华为这类定制系统上会怎样 | 官方口径是「Android 12+ 且支持 Material You」；定制系统自带应用跟不跟随，取决于那套系统自己的取色实现（官方只点过 OneUI 一例）。先按上面「只有某几个应用不变」那条单独指定试试，系统自带应用不变属于预期范围 |

## 七、颜色改乱了想回默认

1. 手动改过的色阶：在调色板上**长按**该色块，恢复到默认值；
2. 整体参数（风格、三个滑块、纯黑开关）：逐项点回默认，或直接 Restore 一份之前存好的备份；
3. 连应用都不想留：按 [备份恢复与彻底卸载.md](备份恢复与彻底卸载.md) 的顺序关服务、卸载、重启。

各个配色项分别管什么，见 [怎么调出想要的配色.md](怎么调出想要的配色.md)。
