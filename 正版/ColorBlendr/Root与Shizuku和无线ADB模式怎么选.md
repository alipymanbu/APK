# ColorBlendr 的 Root、Shizuku、无线 ADB 三种模式怎么选

> 三种模式决定你到底能改到什么程度、以及每次重启手机后要不要重新配一遍。本篇把三者的前提、能力和配对步骤分开讲，最后给一份按使用场景的选择清单。

ColorBlendr 改的是系统级配色，绕不开「谁来替你写入系统设置」这个问题，所以它必须先拿到一份特权：root、Shizuku、或者临时借来的 ADB 权限。本篇说清这三条路的差别，让你一次选对。

## 一、三种模式的能力差别

| 模式 | 你需要先准备什么 | 能用到的范围 |
| --- | --- | --- |
| Root | 手机已 root（Magisk、KernelSU 等） | 全部选项可用，包含系统级外观、纯黑设置界面等更深的部分 |
| Shizuku | 另外装一个 Shizuku，并用无线调试把它启动起来 | 常用配色项可用；官方明确说明「自定义选项有限」，个别开关会灰掉 |
| Wireless ADB | 手机连着 Wi-Fi，开发者选项里的「无线调试」可用 | 与 Shizuku 接近，不用装额外应用，但配对是临时的，断开后要重新配 |

官方对后两者的口径是一致的：能用，但改不动全部。判断某个开关为什么灰掉，看 [常见问题与排查.md](常见问题与排查.md) 里「个别开关是灰的、点不动」一条。

## 二、Root 模式

前提是手机已经有可用的 root 权限，并且 root 管理器能正常弹出授权窗口。

1. 应用内选 **Root**；
2. 系统弹出超级用户请求时选择允许（建议勾选记住，否则每次都要点一遍）；
3. 若提示 `Root permission not granted`，说明请求被拒了，去 root 管理器里把 ColorBlendr 的授权改回允许；
4. 回到主界面打开服务开关，状态行显示 `Theming is active` 即为生效。

Root 模式下才有的一项：v2.0.0 起支持给同一台手机上的其他用户配置主题，主用户改配色时会把同机其他用户的配置一并照顾到。

## 三、Shizuku 模式

Shizuku 本身不 root，它的作用是把 ADB 权限借给普通应用用。用好它需要两步：先把 Shizuku 跑起来，再让 ColorBlendr 拿到它的权限。

1. 安装 Shizuku（官方发布页在 [github.com/RikkaApps/Shizuku](https://github.com/RikkaApps/Shizuku)），按它首页的引导用无线调试启动；
2. 启动成功后，回到 ColorBlendr，工作模式选 **Shizuku**；
3. 弹出 Shizuku 授权请求时选择允许；
4. 提示 `Shizuku permission not granted` 就是这一步没批，去 Shizuku 应用里把 ColorBlendr 的授权打开再回到应用重试。

需要知道的限制：**手机重启后 Shizuku 会停**，ColorBlendr 里的 Shizuku 授权随之失效，得重新启动一次 Shizuku 才能继续改色。这是 Shizuku 本身的工作方式，不是应用出错。

## 四、Wireless ADB 模式

不想装 Shizuku，就用应用自带的无线 ADB 配对，整个过程在手机上和 ColorBlendr 的通知里完成。

1. 把手机连到一个稳定的 Wi-Fi。**如果这个 Wi-Fi 没有外网，先关掉移动数据**，否则系统会切回蜂窝网络，配对容易失败；
2. 打开「设置 → 开发者选项 → 无线调试」；
3. 点「使用配对码配对设备」，屏幕上会出现一个 6 位配对码，先别关掉这个页面；
4. 在 ColorBlendr 里选 **Wireless ADB**，点「Start」，应用会发出一条通知；
5. **在通知里输入那 6 位配对码**；
6. 回到应用再点一次「Start」，出现 `ADB pairing successful` 就配对好了。

三个容易卡住的点：

- **必须允许 ColorBlendr 发通知**，那条输入配对码的通知是流程的一环，通知被禁就无从输入；
- 有的系统把通知样式改成了自家风格，导致通知里输入不了配对码，需要到「设置 → 通知 → 通知样式」切回 Android 原生样式；
- 无线调试在部分机型上会随 Wi-Fi 断开而关闭，重连后要重新配对一次。

## 五、按场景选

- 手机本来就 root 了：直接 Root，省事且功能最全；
- 不想 root、能接受多装一个应用：Shizuku，代价是重启后要重新启动 Shizuku；
- 只是偶尔改一次配色、不想留常驻工具：无线 ADB，用完断开；
- 只让 Google 系应用和本来就跟随 Material You 的应用变配色：Shizuku 或无线 ADB 够用；要动到系统设置界面背景这类更深的位置，就得 Root。

有一条共同的代价要先知道：Shizuku 与无线 ADB 都要经过「开发者选项 → 无线调试」，等于把设备的调试授权放宽；root 更直接，等于把最高权限交出去。这属于你自己的设备与自己的选择，值不值得为一次配色放开由你判断——不想长期留着，用完把无线调试关掉、把 Shizuku 卸载即可。

## 六、模式配不上时的自查顺序

| 现象 | 先查这里 |
| --- | --- |
| 选了模式后服务开关还是灰的 | 授权窗口有没有被误拒；Shizuku 是否还在运行 |
| 每次重启后都要重新配 | 用的是 Shizuku 或无线 ADB 模式，属于正常现象 |
| 无线 ADB 走到输入配对码就断了 | 通知权限、通知样式、Wi-Fi 是否具备外网 |
| 配对成功但改色无效 | 服务开关是否打开；配色是否真的应用过，见 [怎么调出想要的配色.md](怎么调出想要的配色.md) |

以上都对过还是不行，按 [常见问题与排查.md](常见问题与排查.md) 逐条排查。安装环节的问题见 [下载与安装教程.md](下载与安装教程.md)。
