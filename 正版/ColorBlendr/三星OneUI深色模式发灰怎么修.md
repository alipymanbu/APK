# ColorBlendr 用来修三星 OneUI 深色模式发灰怎么操作

> 三星部分机型升级 One UI 8.5 后，深色模式出现黑灰混杂、尤其集中在 Google 系应用与拨号盘。本篇讲清这个现象的来由，以及用 ColorBlendr 把配色换回旧观感的具体做法、能维持多久、还有你这版 v2.0.3 的两个前提。

这是 ColorBlendr 的一类「非改色、而是修观感」的用法：你不想要新配色，只想让深色模式回到升级前的样子。做法本身很简单，难点在于知道它为什么有效、以及什么时候会失效。

## 一、先说清这个现象是什么

2026 年 5 月 One UI 8.5 推送后，Galaxy S25、S24、S23 等机型陆续有用户反馈：深色模式下的黑不再是纯黑，而是深浅不一的灰，菜单项像黑块压在浅灰底上，读起来很累。

几个已被多家教程与媒体提到的特征：

- **集中在 Google 系应用与系统自带的通话界面**，例如 Gmail、Google 信息、Google Keep、拨号盘；同一个界面里旁边的通话记录却仍是纯黑；
- **浅色模式同样受影响**，只是深色模式下对比强烈、更容易被发现；
- **原因是取色规则变化**：One UI 8.5 调整了默认调色板，与 Google 的 Material You 取色方式对不上，两边算出来的深浅不一样；
- **三星当时没有正式修复**，公开报道里提到官方已知悉但未给出修复时间，之后是否已修以你的系统更新说明为准。

## 二、用 ColorBlendr 修的做法

核心只有一步：**把配色风格指定成 One UI 8 及更早版本的默认风格**，也就是 Neutral 或 Tonal Spot。系统按旧风格重新算一遍颜色，那些灰色块就回到了原来的深度。

1. 按 [Root与Shizuku和无线ADB模式怎么选.md](Root与Shizuku和无线ADB模式怎么选.md) 把工作模式配好，Shizuku 或 root 都可以，公开教程里普遍用 Shizuku；
2. 打开 ColorBlendr，进入风格选择页（v2.0.3 里和配色滑块在同一片区域），选中 **Neutral** 或 **Tonal Spot** 其中一个；
3. 回到主界面确认服务开关是打开的、状态行显示 `Theming is active`；
4. 到 Google 信息或拨号盘这类受影响的应用里看一眼，深浅应已恢复；
5. 两个风格都试试，选观感更接近你升级前的那一个。

风格各自的观感差别见 [怎么调出想要的配色.md](怎么调出想要的配色.md)，Neutral 与 Tonal Spot 都在同一张表里。

## 三、生效能维持多久

公开教程给出的经验是：**这套风格一旦应用，即使之后把 Shizuku 甚至 ColorBlendr 本身卸载、或者重启手机，观感也会保持住**，因为配色已经写进系统。

但有两个会把它打回去的动作：

- **再去动系统的「壁纸与样式 → 调色板」**：重新选一次系统调色板，会按 One UI 8.5 的新规则重算颜色，灰块回来；有用户明确反馈过这一点；
- **系统再推一次大版本更新**：更新后一切以新系统的取色规则为准，需要重新应用一次。

也就是说，这是一次性对齐，不是一劳永逸的补丁。

## 四、你这版 v2.0.3 的两个前提

1. **风格名字对得上**：v2.0.3 的风格列表里就有 Neutral 与 Tonal Spot，这篇的做法可以直接照做；
2. **但 One UI 8 上可能改不动**：官方在 **v2.1** 的更新说明里明确写了「修复了 OneUI 8 上无 root 模式下颜色更新不生效的问题」。你手上这份是 v2.0.3，如果你用 Shizuku 或无线 ADB 模式、系统又是 One UI 8 及以上，就正好落在那个已经修过的坑里——**应用了没反应，不是你操作错**。这种情况换用 root 模式，或换官方更高版本（版本情况以官方发布页当时显示的为准），在 [下载与安装教程.md](下载与安装教程.md) 第一节有核对版本的方法。

## 五、不想装 ColorBlendr 时的替代做法

公开教程里还给了两条更轻的路径，成功率不如上面这条，可以按代价从低到高试：

| 做法 | 代价 | 说明 |
| --- | --- | --- |
| 系统「壁纸与样式 → 调色板」里换一个配色 | 最低 | 部分用户反馈能缓解灰块问题；但这条路径本身也在新版取色规则下，效果因机型和版本而异 |
| 换一套系统主题或图标包 | 中等 | 图标包只换图标；主题能覆盖到哪些界面取决于该主题自己声明的范围，Google 应用内部的底色一般不在其中 |

## 六、不想用了怎么退回去

修好之后如果哪天想恢复默认，按 [备份恢复与彻底卸载.md](备份恢复与彻底卸载.md) 的顺序来：**先关服务 → 卸载 → 重启手机**，跳过「关服务」会留下改不掉的颜色。

要是对照本篇做完仍没有变化，先确认服务状态与工作模式，再按 [常见问题与排查.md](常见问题与排查.md) 逐条对。
