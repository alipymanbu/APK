## 一、先对一下你手里这份是什么

QooApp 是给安卓手机用的二次元手游平台，装好之后你能在里面找到国内应用商店上架不了、或上架晚很久的日韩与海外手游，直接在应用内下载安装，同时还有游戏情报和玩家社区。本篇对应这份安装文件的几个事实如下，装之前可以拿来核对，后面几篇也都以这几个数字为准。

| 项目 | 值 |
| --- | --- |
| 应用名 | QooApp |
| 版本 | 9.3.0 |
| 安装包体积 | 72.26 MB |
| 包名 | `com.yuanqi.qoo` |
| 厂商 | 安吉元气网络科技有限公司 |
| MD5 | `DEB1E67C52ED028BFC94234E9C4CBFB0` |

要注意的是：这个版本号是**这份包自己的**，不是网上此刻能搜到的最新版。你按应用名去搜，结果里给的版本往往已经是 9.4 开头的另一个包，包名、体积都可能对不上 —— 名同包不同的情况可以看 [同名应用与版本怎么认.md](同名应用与版本怎么认.md)。

## 二、安装文件在哪

QooApp 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/46c2d13e8955](https://pan.quark.cn/s/46c2d13e8955)

拿到之后的处理顺序是：先在网盘里把它保存到自己账号下，再从网盘客户端下载到手机。这一步别省 —— 网盘分享地址有可能失效，保存到自己账号里的是你自己的一份。

下载下来只有一个 `.apk` 文件，不需要解压。体积对上表里的 72.26 MB 就说明下完整了。

## 三、装到手机上

1. 用手机自带的「文件管理」进下载目录，找到这个 `.apk`，点它。
2. 系统会先拦一道，提示「未知来源」「外部来源应用」或「出于安全考虑，已阻止安装」。
3. 顺着提示进 `设置`，给**你刚才实际用来点开它的那个应用**开启「允许安装未知应用」—— 用文件管理点开的就开文件管理的，用浏览器点开的就开浏览器的，这一步开错对象是装不上最常见的原因。
4. 回到安装界面，确认安装，进度走完出现「打开」。
5. 桌面上会生成 QooApp 图标，点图标即可启动。

如果你是从微信、QQ 里接收的这个包，部分手机会把后缀改掉或不允许直接安装，表现是「文件格式不支持」。改从网盘客户端或文件管理器下载更稳。

## 四、第一次打开会依次遇到这些

| 顺序 | 出现的界面 | 你要做什么 |
| --- | --- | --- |
| 1 | 用户协议 / 隐私政策 | 读完同意，否则进不去 |
| 2 | 年龄确认（部分版本才有） | 按实际勾选确认 |
| 3 | 登录方式选择 | 用通行证登录、第三方账号授权，或先点游客模式进去看看 |
| 4 | 首页推荐位 | 不用急着设置，直接搜游戏即可 |

第 3 步是唯一需要提前想一下的：游客模式能进去，但账号相关的进度、关注、福利不会跟着你走。注册与登录的完整流程见 [注册登录与通行证怎么申请.md](注册登录与通行证怎么申请.md)。

## 五、APK 装不上时先查这几条

| 现象 | 先查什么 |
| --- | --- |
| 提示「解析包错误」/「解析软件包时出现问题」 | 包没下完整或传输中被改动。用文件管理器看文件属性，核对 MD5 是否等于 `DEB1E67C52ED028BFC94234E9C4CBFB0`，不一致就重下 |
| 提示「应用未安装」 | 依次排查：手机剩余空间是否明显大于 72.26 MB（安装过程还要额外占一份空间）；是否已经装过同一个包名的版本（签名不同会冲突，需先卸载旧的再装）；系统版本是否过低 |
| 点了安装但系统没反应 | 「允许安装未知应用」的权限给错了对象，见上方第 3 条 |
| 装到一半被手机管家 / 安全中心拦下 | 按提示放行后重试，或在安全软件的拦截记录里恢复 |
| 装好了图标点不开、一进就退 | 属于运行阶段的问题，见 [下载游戏与安装失败排查.md](下载游戏与安装失败排查.md) |

另外提醒一句：这份包的体积是 72.26 MB，如果你手里那个文件只有几 MB 或几十 KB，那不是它 —— 大概率是网盘没下完或者是别的东西。
