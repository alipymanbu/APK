## 一、一次正常的下载安装长什么样

QooApp 里下载游戏走的是「应用内下安装包，再交给系统安装」，全程不需要跳转到别的应用商店。下面是从点下载到能玩之间的完整过程，中间那几道提示看着吓人，其实都不需要你处理。

1. 在游戏页点下载，**可能弹出一个提示说这款游戏需要 Google Play 服务**。
2. 直接点下载 / 确认即可，不用管这个提示。没有 Google Play 服务不影响在这里拿到安装包 —— 这正是很多人用 QooApp 的原因。
3. 看着进度条从 0 走起来，就可以点返回去做别的了，下载会在后台继续。
4. 下完切到「我的游戏」，在这里能看到已下载和已安装的游戏。
5. 首次进游戏时，游戏自己可能还要再下一批资源，那是游戏的事，和 QooApp 无关。

## 二、下载阶段出问题

| 现象 | 处理顺序 |
| --- | --- |
| 提示下载失败（Download failed） | ① 先把 QooApp 更新到你手上渠道的最新版；② 还不行就进 `设置 → 应用 → 找到 QooApp → 存储 → 清除数据`，然后重新下载。清数据只影响本地记录，不影响通行证 |
| 进度条一直 0、不动 | 先换网络试（流量与 Wi-Fi 互换）；再确认手机剩余空间够不够放这个包 |
| 下载到一半中断、续不上 | 回到游戏页重新点下载，多数情况会重下；反复失败的按上一条清数据再试 |
| 下载很快成功但装不上 | 见下一节 |

## 三、安装阶段出问题

### 提示「未安装应用程式」

这是最常见的一条，按下面顺序试，命中率从高到低：

1. **空间不够**。安装需要的不只是安装包那么大，手机剩余的可用空间要明显多于安装包体积；低于一成时很容易直接报这个错。清掉不用的应用或照片再装。
2. **默认安装位置在存储卡**。进 `设置 → 应用 → 默认安装位置`，改回「手机存储 / 内部存储」再装。
3. **清一次应用商店的缓存数据**。进 `设置 → 应用 → 全部 → 找到应用商店（Google Play 商店）→ 清除数据`，然后重装这个游戏。
4. **root 过的手机**：用文件管理器找到 `.android_secure` 目录下的 `smdl2tmpl.asec` 删掉，再重新安装。

### 提示 Download failed because you may have not purchased this application

这条说的是游戏需要的数据包没装或装得不完整，跟上文第一条的 Google Play 提示是两回事。带数据包的游戏要按下一节的方式手动放 obb。

### 装完打不开、闪退、卡在登录画面

- 先确认这款游戏是否检测 root。相当多日韩游戏会拒绝在 root 机上运行，隐藏 root 也未必有效，这类限制由游戏本身决定，不是 QooApp 能改的。
- 再确认这款游戏是否要求先装 LINE、KakaoTalk、Google 等第三方应用并登录，部分平台的游戏会强制走那道流程。
- 剩下这种「已经进了游戏、界面里出的错」（引继失败、充值不到账、闪退在某张画面）都超出了 QooApp 的职责范围，需要找该游戏的官方客服。

## 四、带数据包（OBB）的游戏怎么装

一部分大型游戏除了 `.apk` 还带 obb 数据包，装完主程序仍然进不去，就是缺了这一步：

1. 先把 `.apk` 装上，再把下载到的所有 obb 文件留在手机上别删。
2. 看 obb 的文件名推断游戏包名：形如 `main.1200.com.example.game.obb` 的，包名就是 `com.example.game`（去掉前面的 `main.数字.` 和后面的 `.obb`）。
3. 进手机存储根目录的 `Android/obb`，新建一个和包名完全同名的文件夹。
4. 把 obb 文件全部移进这个新建的文件夹里，然后启动游戏。

包名对错是关键：文件夹名少一个字符、多一个大写，游戏都读不到。

## 五、游戏要更新时该怎么办

回到 QooApp 里找到这款游戏，重新点下载，**覆盖安装**上去。

这里有一条硬提醒：**不要为了更新先卸载旧版**。很多游戏的存档放在应用内部，卸载会连进度一起清掉；覆盖安装才是保住进度的做法。覆盖安装时系统只会提示更新，不会要求重新登录游戏。

另外，如果你想更新的游戏版本号一直没变，可能是这份包本身还没跟上 —— 收录来源不同，个别游戏会比官方晚一两天，发现超过一天没更新，可以在应用内反馈。
