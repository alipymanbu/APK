## 一、装机前先确认这几件事

| 项目 | 说明 |
| --- | --- |
| 安装包类型 | 安卓 APK 安装包 |
| 版本 | 1.0.2（安卓版） |
| 体积 | 约 1.53 MB |
| 系统要求 | Android 5.2 以上（以安装时系统提示为准） |
| 是否需要注册 | 打开后直接设置紧急联系人即可，无需注册账号 |

上面这些以安装包本身的属性为准——网上搜到的官方页面可能已经是更新的版本，你拿到手的安装文件是哪一个版本，装上后进「设置/关于」看一眼最直观。

## 二、从哪里获取安装文件

Demumu 的安卓安装包可以从上面的 **Demumu 安装文件资源（夸克网盘）** 获取：

1. 点开网盘链接，把安装包转存到自己的网盘；
2. 在网盘客户端里把它下载到手机存储；
3. 下载完成后，从通知栏或网盘 App 的「传输列表」里点开这个 APK，就会跳转到系统安装界面。

如果你用的是 iOS 设备，则不走这条路：iOS 版 Demumu 上架在 Apple 的 App Store，直接在商店里搜索安装即可（付费应用，价格以商店页面当时显示为准）。

## 三、安装步骤（安卓）

1. **点开 APK**：在文件管理器或网盘客户端里点刚下载的安装包；
2. **允许安装未知来源应用**：如果不是从应用商店装的，系统会提示「不允许安装未知来源应用」，按提示允许你的文件管理器（或网盘客户端）安装应用即可；不同品牌手机的入口略有差异，一般在 设置 → 安全/隐私 → 更多设置 里；
3. **确认安装**：回到安装界面点「安装」，1.53 MB 的包体几秒就能装完；
4. **打开应用**：安装完成后直接点「打开」，进入首次设置流程。

## 四、核对安装包（可选）

如果你想在安装前确认文件没损坏，可以核对一下这份安装包的指纹信息：

- 文件名：`Demumu_v1.0.2.apk`
- 大小：1.53 MB
- MD5：`22088D2643A5E0F8D3AD15BD179B2667`

用手机或电脑上的 MD5 校验工具算一下结果，一致就说明文件完整。这一步不做也不影响安装。

## 五、装完之后做什么

装完第一件事不是研究界面——应用本身只有一个大大的签到按钮（媒体实测的描述是：整个应用就一个页面，填姓名和邮箱、点签到，没有别的操作），重点是先把**紧急联系人**设置好，否则预警机制等于没开。具体怎么填、填几个、选谁合适，看这篇：[紧急联系人设置指南.md](紧急联系人设置指南.md)。

设置完成后，剩下的事就是每天记得打开点一次签到。签到和预警是怎么联动的、忘了签会发生什么，看这篇：[每日签到与预警机制.md](每日签到与预警机制.md)。

如果是**给父母长辈装**，设置和交付的清单不太一样（要替他们填联系人、用系统闹钟固定签到时间），照 [给父母长辈设置教程.md](给父母长辈设置教程.md) 走一遍。

安装或使用中遇到别的状况（比如装不上、点签到没反应），可以先翻 [常见问题与注意事项.md](常见问题与注意事项.md)。
