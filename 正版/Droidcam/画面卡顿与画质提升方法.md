## 一、先提画质：两处设置

1. **手机端**：App 首页右上角菜单（⋮）进 Settings，Camera 区里把 **Video Quality** 调到 High。
2. **电脑端**：客户端启用 HD 模式选 720p 或 1080p（官方帮助页 `https://www.dev47apps.com/droidcam/hd-mode/` 有具体开关位置）。720p/1080p 属于付费版 DroidCamX 的能力，免费版停在标准清晰度，差异见 [免费版与专业版区别.md](免费版与专业版区别.md)。

注意 1080p 的代价比 720p 大一倍——像素翻倍，传输开销也翻倍，先开 720p 看效果，稳了再上 1080p。

## 二、治卡顿：按命中率排序的清单

| 动作 | 在哪操作 | 适用情况 |
| --- | --- | --- |
| 不带音频 | 客户端连接时不勾音频 | 电脑有麦克风或戴耳机时，直接省一大块开销 |
| 降到 720p | 客户端 HD 模式 | 1080p 卡时先降档 |
| 重启路由器 / 换 5GHz WiFi | 路由器与手机 WiFi 设置 | WiFi 拥挤、信号弱导致冻结 |
| 最小化客户端预览 | 客户端点 Mute Preview，或按 `Ctrl+H` 缩到任务栏 | 电脑负载高时给别的程序让资源 |
| 开 Limit FPS + 画质 Normal/Low | 手机 App 设置 → Camera 区 | 手机端是瓶颈时 |
| 客户端里把画面旋转 180°，手机倒着放 | 客户端视频控制 | 省一笔 CPU 开销，官方实测有效 |
| 传输格式切 Classic | 客户端顶部 DroidCam 菜单 → Settings → Video Transfer Format | 上面的都不管用时试 |
| 画质 Normal + Target FPS 30 + 关 Advanced Options | 手机 App 设置（新版客户端配套 App） | 治反复卡顿、频繁掉线，改完在客户端里删掉手机重新添加 |
| Video Format 从 AVC 改成 MJPEG | 新版客户端双击 DroidCam 源 → Properties | 旧手机专用对策 |
| 自定义码率 | 手机 App 设置 → Advanced Options（仅 Android） | WiFi 快或走 USB 时想精确控制带宽，官方定位为进阶玩法 |
| 检查 NVIDIA 限速 | NVIDIA 控制面板 → 3D 设置 → Background Application Max Rate | 装了 NVIDIA 控制面板的电脑 |
| 清理手机后台 | 关掉任务管理类、省电类 App | 手机被限速时 |

验证卡顿到底出在哪：客户端顶部 DroidCam 菜单选 **With Stats** 再连接，看每帧总耗时——低于 30ms 就能流畅，超了说明瓶颈真实存在。

**WiFi 还是 USB？** 常规情况 USB 更稳；但如果你电脑离路由器近（尤其电脑走网线）且手机支持 5GHz WiFi，WiFi 反而可能比 USB 快。两条路都试一下再定。

## 三、控发热与耗电

视频串流本身就是高负载，发热正常，能做的是别让它更糟：

- 手机插着电源用（USB 连接天然满足；WiFi 连接也插根充电线），电量满格时发热和掉电都最小；
- 连接后把手机屏幕调暗——反正你不看它；
- 手机散热别堵：别放在被子、沙发缝上；
- 发热严重时：手机端开 Limit FPS，客户端把 Video Transfer Format 切成 Classic；
- 注意手机息屏跑一段时间后，省电模式可能把 App 或 WiFi 冻结（三星用户优先看 [连接失败与常见报错排查.md](连接失败与常见报错排查.md) 第四节）。

## 四、多台手机同时用

Windows 客户端最多同时连 **3 台**设备：顶部 DroidCam 菜单里关掉 Compact View，界面就会出现多个预览小窗，点小窗（快捷键 `Ctrl+1`、`Ctrl+2`）把对应设备切到主预览。想在 OBS 里同时开多个机位的话，开发者单独的 DroidCam OBS 应用更合适（支持 4K，且经典客户端没有 4K 计划）。

画面顺了之后，想搞清自己用的是免费版还是付费版、哪些功能要解锁，见 [免费版与专业版区别.md](免费版与专业版区别.md)。
