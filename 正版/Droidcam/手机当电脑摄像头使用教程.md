## 一、连之前先确认三件事

1. 手机上 DroidCam App 已经打开、停在首页（首页显示 WiFi IP 和端口）。
2. 电脑上 DroidCam 客户端已经启动（桌面图标、开始菜单，或 `C:\Program Files (x86)\DroidCam` 里的程序）。
3. 想清楚用哪种连接：**WiFi** 免线、最省事；**USB** 稳定抗干扰，但要先开 USB 调试。两种方式的特点对比见 [画面卡顿与画质提升方法.md](画面卡顿与画质提升方法.md)。

## 二、WiFi 连接（推荐先用这个）

1. 手机连上家里的 WiFi，注意和电脑处于**同一个网络**（电脑走有线网线也算同一网络）。
2. 看手机 App 首页显示的 WiFi IP 与端口。如果 IP 显示为 `0.0.0.0`，说明手机根本没连上 WiFi，先解决网络。
3. 电脑客户端里选择 **WiFi/LAN** 方式，把 IP 和端口照着填进去，点 **Start**。
4. 手机 App 开始出画面、客户端预览窗出现同样的画面，即连接成功。

默认端口连不上时，可以在手机 App 和客户端两边把端口号改成同一个别的值（如 4748）再试。

## 三、USB 连接（先开 USB 调试）

USB 连接比 WiFi 多两步准备：**开 USB 调试** 和 **装手机驱动**。

1. 解锁开发者选项：打开手机「设置 → 关于手机」，找到「版本号」，连续点击 7 次，系统提示已进入开发者模式。
2. 回到「设置」，搜「USB 调试」（在开发者选项里），打开开关。
3. 用数据线把手机插到电脑上，Windows 通常会自动装好驱动。客户端切到 **USB** 页，点刷新按钮；手机上若弹出「允许 USB 调试」，点允许。
4. 客户端里选中设备、点 Start。

**驱动没自动装好**（客户端刷新不到设备）时，按品牌装官方驱动：Google 系（Pixel/Nexus/一加）用 Google 官方 USB 驱动 `https://developer.android.com/studio/run/win-usb`；三星在 `https://developer.samsung.com/mobile/android-usb-driver.html`；其他品牌搜「ADB Drivers + 品牌名」。装完重插数据线再刷新。

**连接报 connection reset / connect lost / error receiving video headers**：手机下拉通知栏，把 USB 的用途切成「PTP（传输照片）」「相机」或「仅充电」再试；更多排查见 [连接失败与常见报错排查.md](连接失败与常见报错排查.md)。

另外两种免路由器的连法也支持：手机开**热点**让电脑连，或用手机的 **USB 网络共享**（USB Tethering）；部分支持 USB-C 网线的机型还能走有线以太网。

## 四、在会议/直播软件里把摄像头切过来

连接成功后，DroidCam 在电脑上就是一个普通摄像头设备，名字显示为 **DroidCam Webcam**（新版客户端环境下叫 **DroidCam Video**）：

| 软件 | 在哪里选 |
| --- | --- |
| Zoom | 设置 → 视频 → 摄像头，选 DroidCam Webcam |
| Microsoft Teams | 设置 → 设备 → 摄像头 |
| Discord | 用户设置 → 语音和视频 → 摄像头 |
| OBS Studio | 来源 → 添加「视频采集设备」→ 设备选 DroidCam Webcam |

用 **OBS** 还有两条更顺的路：一是把手机画面当浏览器源添加，地址填 `http://手机IP:端口/video/force/1280x720`；二是用开发者单独出的 DroidCam OBS 插件——不用装客户端、支持 macOS、能开 4K，整套步骤见 [OBS直播与录屏连接方法.md](OBS直播与录屏连接方法.md)。

## 五、常用操作

- **切前后摄像头**：连接前在手机 App 里点「Camera Swap」按钮。双摄以上的机型，部分额外镜头不一定能选，因手机型号而异。
- **带声音**：客户端连接时勾选音频选项即可把手机麦克风一起采集过来，系统里会出现一个叫 **Droidcam Audio** 的麦克风设备，会议软件里把它选成麦克风输入即可；但官方自己的建议是——电脑有麦克风就用电脑的，音频延迟与音质通常不如视频稳定，不需要就别带音频（卡顿对策见 [画面卡顿与画质提升方法.md](画面卡顿与画质提升方法.md)）。
- **竖屏画面**：客户端里右键预览 → Transform 菜单做 90° 旋转，再把手机物理横过来架好，最后裁掉多余部分；注意 DroidCam 的视频输出始终是横屏尺寸，竖屏要靠变换加裁剪凑出来。
- **手机息屏继续用**：连接后按 Home 键把 App 退到后台、甚至熄灭屏幕都行，还能省电；个别品牌（三星 Android 11 起）对后台应用管得严，画面会停，处理办法在 [连接失败与常见报错排查.md](连接失败与常见报错排查.md)。
- **用浏览器当监视器**：在任意设备浏览器打开 `http://手机IP:端口/video`，就能看到摄像头画面（MJPEG 方式），也可以拿第二台手机/平板这样看。

## 六、一屏速查

```text
WiFi：手机开 App → 记下 IP:端口 → 客户端选 WiFi/LAN → 填入 → Start
USB ：设置→连点版本号7次→开发者选项→USB调试 → 插线 → 客户端选 USB → 刷新 → 允许调试 → Start
会议软件：设置里的摄像头 → 选 DroidCam Webcam
```
