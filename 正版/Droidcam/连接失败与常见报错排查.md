## 一、Connect failed. Check IP and Port

这是 WiFi 连接最常见的报错，按顺序过一遍：

1. **确认同一网络**：手机和电脑必须同一网络（电脑插网线也算）。手机用流量时必然连不上。
2. **IP 显示 0.0.0.0**：手机没连上 WiFi，先修手机的网络。
3. **重启路由器**：拔电等几秒再插回去，等它启动完再连。
4. **VPN**：先连 DroidCam、再开 VPN；或者干脆改用 USB 连接绕开 VPN。
5. **防火墙**：电脑、手机、路由器上的防火墙都可能拦掉连接，公司或学校网络尤其常见——这种网络环境官方给的对策就是换 USB 连接。
6. **双频路由器**：家里同时开着 2.4GHz 和 5GHz 两个 WiFi 名时，手机和电脑（含插网线的电脑）尽量落在同一个频段，跨频段会被部分路由器隔离。
7. **电脑有多块网卡**：客户端设置 Advanced 区有 **Bind IP** 选项，选中连接 WiFi 的那个网络接口再重启客户端。
8. **杀毒软件**：有用户反馈杀毒软件会拦 USB 连接；WiFi Calling 功能被反馈会导致连接一阵子后掉线。
9. **公司管控的电脑**：Windows Defender 的「网络保护」可能拦连接。管理员 PowerShell 里执行 `Set-MpPreference -EnableNetworkProtection Disabled` 可以关掉它（改的是你自己的电脑安全设置，后果自己评估；公司设备建议先问管理员）。
10. **新版客户端找不到设备**：把 **Refresh Device List** 连点 3 次，会出现手动添加设备的入口，照手机 App 显示的 IP 手填即可。

## 二、画面是纯绿色（绿屏）

- 在客户端里用 **File > Exit** 完全退出，重新打开再连。
- 还不行就**重启电脑**——虚拟摄像头输出需要和系统同步一次，重启能解决。

## 三、USB 连接认不到设备

按这个顺序查：

1. 手机 App 是否开着并停在首页；客户端 USB 页是否点了刷新。
2. 手机上有没有弹「允许 USB 调试」——弹了就要点允许。
3. 报 `ADB.exe not found` 或 `Error running adb.exe`：
   - 检查 `C:\Program Files (x86)\DroidCam` 下的 `adb` 文件夹还在不在，被删了就重装客户端；
   - 电脑或系统较老时，官方提供旧版 adb 的 zip 包（`https://files.dev47apps.net/usb_setup_windows_2018.zip`），下载后替换上面那个 adb 文件夹；
   - 注册表 `HKEY_LOCAL_MACHINE\Software\Microsoft\Command Processor` 下若存在 `AutoRun` 键，删掉它再试。
4. 报 connection reset / connect lost / error receiving video headers：手机通知栏里把 USB 用途切成 PTP（传输照片）、相机或仅充电。
5. 驱动问题：客户端刷新不到设备时按品牌装驱动（链接见 [手机当电脑摄像头使用教程.md](手机当电脑摄像头使用教程.md) 的 USB 一节）。Windows 自动装的驱动有时不对，手动装官方驱动反而能好。
6. 仍不行：官方还有一个备用 USB 设置工具（`https://files.dev47apps.net/usb_setup_windows.zip`），它会自动给所有连接的设备做端口转发，有效的话用它压缩包里的 adb 文件夹替换客户端下的同名文件夹。

## 四、三星手机：连一会儿画面就停

Android 11 起，三星限制了应用在后台保持唤醒，画面会冻结。绕开的办法：

- 连接时给手机**插着电源**；
- 按 [dontkillmyapp.com](https://dontkillmyapp.com/samsung) 上针对三星的方案关掉对应的电池优化。

其他品牌的省电模式同样可能冻结后台应用，遇到类似情况优先关省电模式。

## 五、其他几类报错

| 现象 | 处理 |
| --- | --- |
| 视频有了但声音断断续续 | 声音走低延迟传输、很怕网络干扰：确认同一网络同频段，或改 USB 连接；多数场景直接换电脑麦克风更省事 |
| 付费功能是灰的，买了 Pro 也不生效 | 这是 DroidCamX 没能向商店验证购买，卸载后从应用商店重新下载一次即可 |
| Windows 客户端设置改了不保存 | 删除 `C:\ProgramData` 下的 droidcam 配置文件后重开客户端 |
| 客户端卸载不干净 | 控制面板卸载，或运行安装目录里的 Uninstall.exe；异常时进安全模式再卸载 |

## 六、什么时候直接换连接方式

排查超过十分钟还没头绪时，直接换条路往往更快：WiFi 不行换 USB（防火墙、VPN、公司网络都绕开了）；USB 不行换 WiFi（驱动问题绕开了）。两种方式的切换步骤都在 [手机当电脑摄像头使用教程.md](手机当电脑摄像头使用教程.md)。连上了但画面卡，去 [画面卡顿与画质提升方法.md](画面卡顿与画质提升方法.md)。
