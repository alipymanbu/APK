## 一、先分清三个「不是一回事」

搜索时容易混淆的三组名字：

1. **DroidCam（免费）与 DroidCamX（付费）**：同一开发者的两个安卓应用，包名分别是 `com.dev47apps.droidcam` 和 DroidCamX 自己的包名。本文网盘里的是免费版 6.28。
2. **DroidCam（经典）与新版 DroidCam**：官网 [dev47apps.com](https://www.dev47apps.com/) 是经典版，[droidcam.app](https://www.droidcam.app/) 是新一代应用，手机端是不同应用、购买也互不相通。新版应用的免费档可以试用 HD 画质，但要去掉水印需购买其 Pro——这与经典免费版「无水印」的口径不同，别混着理解。
3. **手机端购买与电脑端功能**：Windows 客户端里的部分控制项（镜像、翻转、对比度等）需要手机端是 DroidCamX 才解锁。

## 二、功能差异对照

| 能力 | 免费版 DroidCam | DroidCamX（付费） |
| --- | --- | --- |
| 使用时长/水印 | 不限时长、无水印 | 同左 |
| 清晰度 | 标准清晰度 | 解锁 720p / 1080p HD 模式 |
| 广告 | 有 | 无 |
| USB-Only 模式 | 无 | 有（只允许 USB 连接，更利于隐私） |
| 来电时静音摄像头音频 | 无 | 有 |
| Smooth FPS（画面更稳） | 无 | 有 |
| Windows 客户端 Pro 控制（镜像/翻转/旋转/对比度/亮度等） | 灰置不可用 | 解锁 |

日常视频会议用免费版就够用；需要高清画质、画面调节控件的是 DroidCamX 的目标场景。付费版价格以 Google Play 当时显示为准。

## 三、购买与账号绑定规则

- **换手机不用重买**：Google Play 的购买绑定在你的 Google 账号上，新手机登录同一账号后直接安装 DroidCamX 即可；Play 商店同步购买记录有时要等一会儿，没立刻生效就过段时间再试。iOS 侧绑定 Apple 账号，换机后在 App 内用「Restore Purchase」恢复。
- **购买不跨应用变体**：Android 的 DroidCam/DroidCamX、Android 的 DroidCam OBS、iOS 版 DroidCam，三者各算各的，买了一个不会解锁另一个。
- **没有 Google 服务的设备**（如部分国产手机刷机后）：官方提供邮件购买渠道，写信到 `support@dev47apps.com` 说明来意。
- **买了却不生效**：DroidCamX 向商店验证购买失败时会表现为免费版（Pro 功能灰置），卸载后从商店重新下载一次即可恢复。

## 四、免费版能一直用吗

免费版没有使用时长限制、没有水印，连接方式（WiFi/USB）也都开放，长期用没问题；主要受限的是清晰度上限和客户端里的画面调节控件。先把免费版用顺，确有高清需求再考虑升级，安装与连接流程见 [手机当电脑摄像头使用教程.md](手机当电脑摄像头使用教程.md)。
