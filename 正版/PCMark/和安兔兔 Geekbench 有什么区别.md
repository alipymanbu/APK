# PCMark 和安兔兔 Geekbench 有什么区别

同一个手机在不同软件里跑出来的数字完全不能互相对照，这不是软件算错了，而是它们量的东西根本不是一回事。搞清口径差异，才不会拿着安兔兔的分数去和别人 PCMark 的分数较劲。

## 一、四种工具分别在量什么

| 工具 | 主要测什么 | 回答的是哪类问题 |
| --- | --- | --- |
| PCMark for Android | 整机在网页浏览、视频编辑、文档写作、图片编辑、数据解析这五类日常任务下的表现，另可测真实续航 | 「日常用起来顺不顺、电池能撑多久」 |
| 安兔兔 | CPU、GPU、内存、存储的综合峰值，附加屏幕与充电等单项测试 | 「这颗芯片的上限有多高」 |
| Geekbench | CPU 的单核与多核算力（另有 GPU 计算测试） | 「处理器算力排在第几档，跨平台也能比」 |
| 3DMark | 图形渲染与游戏场景的 GPU 表现 | 「玩游戏、跑重载图形任务行不行」 |

差别最集中的地方是**测试负载的性质**。PCMark 官方强调自己的测试建立在日常活动之上、而不是抽象算法，并且是把设备当成一个整体来量；安兔兔、Geekbench 走的是把各硬件模块分别压到高位的路子。两边的目标不同：

- 想看「峰值有多强」，看安兔兔、Geekbench；
- 想看「平时用着到底怎么样」，看 PCMark。

## 二、分数为什么不能互相换算

三条原因，缺一条都构不成可比的分数：

1. **计分规则不公开也不一致**。各家的加权方式、子项权重都是自己的算法，没有公开的换算公式。所以「PCMark 10000 分相当于安兔兔多少分」这类换算没有依据，看到就跳过。
2. **同一台机在不同榜单里排名可能不同**。峰值型测试容易受散热策略和厂商调校影响，日常负载型测试更看系统调度与存储速度，一台机在一个榜单靠前、在另一个榜单中等，是常见结果。
3. **续航是另一回事**。PCMark 把性能和续航放在同一套日常负载下量，续航结果因此可以和性能分数互相对照（续航测试每一轮循环都会留下一个性能分）。用别的工具测出来的续航小时数，和这套负载下的小时数不是同一个环境，放一起比意义不大。

## 三、按你的问题选工具

| 你想知道的事 | 该看哪个 | 怎么用 |
| --- | --- | --- |
| 系统更新后是否变卡了 | PCMark | 更新前后各跑一次，**保证测试版本相同**，对比子项分数 |
| 日常续航有没有变化 | PCMark | 按统一亮度、统一联网条件跑续航测试，见 [跑分和续航测试怎么测.md](跑分和续航测试怎么测.md) |
| 这台设备玩游戏够不够 | 3DMark | 图形项分数结合真实游戏帧率一起看 |
| 处理器算力排第几 | Geekbench | 看单核与多核，两个都要看，别只看多核 |
| 二手手机硬件是否有问题 | PCMark 加安兔兔 | PCMark 看日常负载是否稳定，安兔兔看各项硬件是否在正常档位 |

**用来排查故障时，重复性比绝对值更重要。** PCMark 官方给出自家测试在受控条件下的精度通常在 3% 以内，这意味着同一台设备在同一条件下反复跑，分数应当落在一个很窄的区间里。如果两次结果差得离谱，那多半是环境或温控出了问题，而不是设备性能突然变了 —— 排查方向见 [分数怎么看懂.md](分数怎么看懂.md)。

## 四、两边都有一条共通的铁律

**跨测试版本不能比。** PCMark 的 Work 3.0 与 Work 2.0、Work 1.0 结果不具备可比性，因为 3.0 是针对 64 位架构重做的。这一点在各家工具上是通例：测试版本换代、计分规则调整，旧分数就与新分数断代。

所以别人给你一个分数时，要连着问三件事：用的是哪个工具、测试版本是几、设备在什么条件下跑的。缺了任何一项，这个数字都只能当参考，不能当结论。PCMark 自己的版本号体系怎么读，见 [同名应用与版本怎么认.md](同名应用与版本怎么认.md)。

## 五、一句话结论

**峰值看安兔兔和 Geekbench，图形看 3DMark，日常体验和续航看 PCMark。** 想要一个完整的印象，就各取所需地组合使用，而不是指望某一个软件的数字能替代全部。各家的测试版本与计分规则都可能随时间调整，具体口径以各自官方页面当时显示的说明为准。
