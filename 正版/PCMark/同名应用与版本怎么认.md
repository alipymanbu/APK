# PCMark 同名应用与版本怎么认

> 本篇解决两个高频困惑：名字里带 PCMark 的东西有好几个，怎么区分手机版和电脑版；以及应用版本号、测试版本号这两套号各是什么意思。

搜「PCMark」的时候，搜索结果里混着电脑版、手机版和图形基准工具，下载来的东西很可能不是你要的那个。本篇把名称、包名、版本号三条线索分开讲，用来确认手上这一份到底是什么。

## 一、三套产品的分工

| 名称 | 跑在哪 | 测什么 | 怎么一眼认出来 |
| --- | --- | --- | --- |
| PCMark for Android | 安卓手机、平板 | 整机日常性能与电池续航 | 应用商店里的显示名带 Benchmark 字样，包名以 `com.futuremark.pcmark.android` 开头 |
| PCMark 10 | Windows 电脑 | 电脑整机性能、办公续航 | 装在 Windows 上，安装包是 exe，不是 apk |
| 3DMark | 手机、电脑、iOS | 图形与游戏性能 | 名称里是 3D 不是 PC，测试场景是游戏渲染 |

三者都出自同一家：UL Solutions（早期叫 Futuremark）。同一家出的产品经常互相引荐，所以在 PCMark 的页面上看到 3DMark 的入口、或反过来，都是正常的，不代表你找错了。

**最可靠的区分方式是包名**，不看图标也不看名称写法：

- 本文这套是 `com.futuremark.pcmark.android.benchmark`；
- 只要包名跟这个不一致（比如没有 `.android`，或后缀不是 `.benchmark`），就不是这套手机版文档对应的应用。

## 二、官方渠道与开发者名

官方入口只有这几个，认准它们就不会下到仿冒品：

- 产品页：[benchmarks.ul.com 上的 PCMark for Android 页面](https://benchmarks.ul.com/zh-hans/pcmark-android)，官网在这里同时提供应用商店入口和 APK 下载入口；
- 官方商店页：[Google Play 上的 PCMark for Android Benchmark](https://play.google.com/store/apps/details?id=com.futuremark.pcmark.android.benchmark)，页面上能看到开发者主体与包名。

判断依据是**开发者主体**：应为 UL Solutions 或其基准测试业务实体（早期材料里署名 Futuremark）。第三方下载站转发的包，开发者信息可能被改掉或抹掉，这种情况优先回到上面两个入口取包。

## 三、两套版本号，别混着看

PCMark 有两套独立的版本号，作用完全不同：

| 版本号类型 | 例子 | 什么时候变 |
| --- | --- | --- |
| 应用版本号 | 3.0.4061 | 改功能、修 bug、适配新系统，更新频繁 |
| 测试版本号 | Work 3.0、Storage 2.0 | 只在测试内容本身需要改动时才变，极少变 |

在设置页里这两套号都能看到。它俩的关系是：**应用版本会不断往上走，测试版本可能一直原地不动**。所以「我的 Work 3.0 和你说的 Work 3.0 是不是一个东西」看的是测试版本，「我装的应用够不够新」看的是应用版本，两个问题不能用一个号回答。记录对比数据时两个都要记，原因见 [分数怎么看懂.md](分数怎么看懂.md)。

## 四、网盘里这一版是什么位置

网盘里那份的信息如下：

| 项目 | 值 |
| --- | --- |
| 应用版本号 | 3.0.4061 |
| 决定它能力的测试版本 | Work 3.0 |
| 包名 | `com.futuremark.pcmark.android.benchmark` |
| 安装包大小 | 50.46 MB |

对照官方的发布记录，3.0.4061 属于 3.0 系列的收尾版本，修掉了「最佳设备」列表更新时卡住的问题。3.0 这一代最大的变化是整体转向 64 位，用 Work 3.0 取代了旧的 Work 2.0，并移除了 Work 1.0、旧版 Storage 与计算机视觉测试。

官方后来把应用继续更新到了 3.1 系列（应用版本号会随时间往上走，具体以官方页面当时显示为准），测试也从 Work 3.0 演进到 Work 3.1。两代之间的关系是：整体总分大体可比，但子项分数会因修复和优化出现差异，官方给出的建议仍然是在同一个版本内部做对比。

**因此会碰到两种取舍**：

- 只想跑出有意义的分、和别人对比：装官方当前版本，并确保双方测试版本一致；
- 手上这台设备用不上更高版本，或者就是想用这一份已经验证过的包：网盘里这份 3.0.4061 完全可用，跑出来的分数同样是有效的 Work 3.0 成绩，只是不要拿它和别人的 Work 3.1 成绩直接比。

从哪拿包、装完要先做什么，见 [下载与安装教程.md](下载与安装教程.md)；装上之后测试项对不上号、或者旧教程里提到的测试找不到，见 [常见问题与排查.md](常见问题与排查.md)。
