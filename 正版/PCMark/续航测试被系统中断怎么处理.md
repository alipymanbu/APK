# PCMark 续航测试被系统中断怎么处理

> 续航测试一跑就是几个小时，中途被系统清理掉是它最常见的失败方式。本篇给出一份「先判断、再设置、最后确认」的处理顺序，以及各品牌系统里需要动的那几个开关。

跑了几十分钟甚至一两个小时的续航测试，回到手机前发现应用已经不在运行，这种浪费最让人恼火。PCMark 官方对这件事的说法很直接：现代设备上的省电功能相当激进，可能让完整的续航测试几乎无法跑完，遇到被强制关闭的情况应当关闭系统的省电功能。本篇就是把这句话落到具体开关上。

## 一、先判断是不是被系统杀的

三种结果要区分开，处理方式完全不同：

| 现象 | 说明 | 处理方向 |
| --- | --- | --- |
| 应用整个退出、测试记录中断 | 被系统回收或主动清理 | 按本篇第二、三节设置系统 |
| 应用还在，但测试停了、设备明显温热 | 多半是温度触发保护或中途被打断 | 降温后重跑，见第四节 |
| 应用还在，但提示测试无法启动 | 前置条件不满足，不是中断 | 检查电量是否到 80%、是否插着线 |

判断依据可以看系统设置里的电池用量页：如果 PCMark 在测试时间段内有被「停止」「冻结」的记录，基本可以确认是系统动的手。

## 二、需要逐项确认的系统开关

下面这些路径来自华为此类厂商的官方支持文档，各品牌菜单命名不同，但功能项是对应的，在自己机型里找同名或近义的项即可：

| 要设置的东西 | 大概在哪 | 设成什么 |
| --- | --- | --- |
| 应用启动管理 | 设置里搜索「应用启动管理」 | 关闭 PCMark 的自动管理，勾选「允许后台活动」 |
| 电池优化 | 设置里搜索「电池优化」 | 找到 PCMark，设为「不允许」（即不允许被优化） |
| 省电模式 / 低电量模式 / 超级省电 | 设置 → 电池 | 全部关闭 |
| 休眠时保持网络连接 | 设置 → 电池 → 更多电池设置 | 开启 |
| 后台进程限制 | 开发者选项 | 设为「标准限制」；同时确认「不保留活动」是关闭的 |
| 多任务卡片加锁 | 多任务界面下拉应用卡片 | 加锁，减小被清理的概率 |

另外两项容易被忽略：

- **第三方管家、清理类应用会主动清后台**，测试期间不要运行它们，必要时先停用；
- **智能省流量**会限制应用在后台使用移动数据，路径一般在「移动网络 → 流量管理」下，测试期间关掉。

开发者选项如果平时不开，用完这些设置后建议关掉，避免误改其他项影响日常使用。

## 三、不是系统的问题：另外几个中断源

| 中断源 | 表现 | 处理 |
| --- | --- | --- |
| 自动锁屏 | 测试中息屏、界面回到桌面 | 把自动锁屏设为最长或保持常亮 |
| 来电与通知 | 弹出横幅、屏幕亮起，测试被打断 | 开免打扰，或直接用不常用的机器号测试 |
| 手滑操作屏幕 | 测试期间画面异常 | 测试全程别碰屏幕 |
| 插上充电线或连接电脑 | 测试判定无效或提前结束 | 测试期间保持断开 |
| 测试包不完整 | 某一子项跑到一半失败 | 确认 Work 3.0 测试包已完整下载 |

这些都不是故障，只是条件没满足。续航测试本身的要求见 [跑分和续航测试怎么测.md](跑分和续航测试怎么测.md)。

## 四、跑之前花一分钟做的清单

- 电量充到 80% 以上，拔掉充电线，断开与电脑的连接；
- 关掉省电模式、超级省电、后台冻结类功能；
- 把 PCMark 加进后台白名单，并在多任务卡片上加锁；
- 关自动亮度，用纯白校准屏把亮度定下来；
- 开免打扰，自动锁屏设为最长，屏幕别放倒扣（会影响散热与亮度）；
- 放在室温、通风、避开阳光直射与其他热源的位置；
- 停用会清后台的第三方管家应用。

## 五、设置完还是跑不完怎么办

先分清是哪一类：

- **每次都在差不多的时间点断**：说明是某个固定的省电策略或清理机制在起作用，回去把第二节的开关逐项再过一遍，尤其是「电池优化」和第三方管家这两项；
- **跑到设备明显发烫后断**：属于温度保护，改善散热位置再跑，别放在被子、沙发这类不通风的地方；
- **换到另一台设备上同样跑不完**：那更可能是通用机制导致的，优先怀疑开发者选项和后台进程限制。

如果这台设备确实无法完成数小时的续航测试，就不必反复硬耗 —— 单独跑性能测试同样是有效结果，只是没有续航数字而已。既然没有续航结果，就用性能分数来对比：性能分数与子项的读法见 [分数怎么看懂.md](分数怎么看懂.md)。

针对应用本身的报错、装不上、按钮点不动这类问题，见 [常见问题与排查.md](常见问题与排查.md)。
