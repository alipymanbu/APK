# PCMark 下载与安装教程

> 本篇讲清网盘里这份安装文件是什么版本、怎么装到手机上、为什么装完还要再下「测试包」，以及首次打开必须先做的三件事。

PCMark for Android 是 UL Solutions（原 Futuremark）给安卓手机和平板做的整机基准测试工具，测的是日常使用下的性能和电池续航，个人使用完全免费、没有广告也没有内购。本篇是安装与首次配置的完整步骤，装完想看怎么跑测试，见 [跑分和续航测试怎么测.md](跑分和续航测试怎么测.md)。

## 一、先确认你要装的是哪个 PCMark

同名或近名的东西有三个，装错了就白折腾：

| 名称 | 跑在哪 | 用来测什么 |
| --- | --- | --- |
| PCMark for Android | 安卓手机 / 平板 | 整机日常性能与电池续航 |
| PCMark 10 | Windows 电脑 | 电脑整机性能与办公续航 |
| 3DMark | 手机 / 电脑 / iOS | 图形与游戏性能（跨平台也有安卓版） |

本文只讲第一个。判断依据是包名：`com.futuremark.pcmark.android.benchmark`。装完之后在系统「应用信息」里点开就能看到，包名对不上说明装的是别的东西。三个产品容易混在哪里、版本号怎么分辨，见 [同名应用与版本怎么认.md](同名应用与版本怎么认.md)。

## 二、拿到安装文件

两条官方渠道都可以走：

- 应用商店：[Google Play 上的 PCMark for Android Benchmark](https://play.google.com/store/apps/details?id=com.futuremark.pcmark.android.benchmark)；
- 官方发布页：[benchmarks.ul.com 上的 PCMark for Android 页面](https://benchmarks.ul.com/zh-hans/pcmark-android)，页面上也有 APK 下载入口，适合在应用商店里搜不到这个应用的设备。

如果你已经从 [PCMark 安装文件资源（夸克网盘）](https://pan.quark.cn/s/44d5e0e97338) 取到了安装包，直接安装即可，不用再下载一次。网盘里这份包的信息如下，装之前可以对照一下：

| 项目 | 值 |
| --- | --- |
| 版本 | 3.0.4061 |
| 包名 | `com.futuremark.pcmark.android.benchmark` |
| 安装包大小 | 50.46 MB |
| MD5 | `312BAA72A3C3C893218959D1C86002ED` |

需要留意的是：**官方现在已经把应用更新到了更高的版本号**（应用版本号会频繁变动，具体以官方页面当时显示为准），网盘里这份是 3.0.4061。两者都能跑同样的 Work 3.0 测试，但结果不要拿来互相比对，原因见 [同名应用与版本怎么认.md](同名应用与版本怎么认.md)。

## 三、安装

1. 把安装包传到手机（数据线、网盘客户端下载都行），在文件管理器里点开；
2. 系统提示「禁止安装未知来源应用」时，去设置里给当前这个文件管理器或浏览器打开「允许安装未知应用」；
3. 装完先别急着删安装包，等确认能正常打开再说。

安装包只占 50 MB 出头，但它不是全部。应用本体、测试包是分开下载的，实际占用要大得多，见下一节。

## 四、装完还要再下「测试包」——这一步绕不过去

打开应用后你会发现，测试项不是现成的，得先点着下载。原因是官方把应用本体和测试内容拆开了，好处是你可以只装自己用得上的那几项，删掉测试包也不会清空已经跑出来的分数。

| 内容 | 占用大小 |
| --- | --- |
| PCMark 应用本体 | 约 75 MB |
| Work 3.0 测试（性能 + 续航测试共用） | 约 200 MB |
| Storage 2.0 测试（存储性能，可选） | 约 100 MB |

官方给出的存储要求是预留 2 GB，所以装之前先看眼剩余空间。下载测试包要联网，几百兆的量，建议在 Wi-Fi 下做。下不动或下到一半失败怎么办，见 [常见问题与排查.md](常见问题与排查.md)。

只想先看看性能和续航，那装 Work 3.0 一项就够；Storage 2.0 是单独测存储读写的，不装也不影响 Work 3.0 使用。

## 五、首次打开建议先做三件事

1. **把界面切成中文**。点右上角的齿轮进设置，第一项 Language 的下拉里选 Simplified Chinese。界面语言只有英文、简体中文、俄语三种，没有繁体中文选项。
2. **看一眼版本号**。同一个设置页往下能看到应用版本号和每个已装测试包的版本号。跑完分要记录数据时，这两个号要一起记 —— 应用版本号和测试版本号不是一回事。
3. **处理系统的省电策略**。不少安卓系统会在电量测试过程中把长时间运行的应用清理掉，导致几小时的测试白跑。稳妥的做法是在系统设置里给 PCMark 关掉后台限制、允许后台活动；国产系统还建议把它加进「不受限制」的白名单。这一步现在花一分钟，比跑到一半被掐掉划算。要改的开关清单一篇列完，见 [续航测试被系统中断怎么处理.md](续航测试被系统中断怎么处理.md)。

## 六、跑之前的最低系统要求

官方列出的最低要求如下，达不到不一定会被拦住，但官方不保证能正常出结果：

| 项目 | 最低要求 |
| --- | --- |
| 系统 | Android 5.0 或更高 |
| 内存 | 1 GB |
| 图形 | 支持 OpenGL ES 2.0 |
| 屏幕分辨率 | 480 × 800 |

满足要求也不代表跑得准，跑测试时的准备动作（关后台、关通知、控温、别插充电线）见 [跑分和续航测试怎么测.md](跑分和续航测试怎么测.md)。
