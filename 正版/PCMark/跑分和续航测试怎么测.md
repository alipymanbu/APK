PCMark 的两类测试用的是同一套工作负载，区别只在跑一次还是反复跑到没电：性能测试十来分钟出分，续航测试要跑几个小时。本篇按「先性能、后续航」的顺序讲操作，两个测试的准备工作有重叠也有区别，别把续航那套前置条件套到性能测试上。还没装好应用与测试包的，先看 [下载与安装教程.md](下载与安装教程.md)。

## 一、性能测试：十来分钟，五个子项

Work 3.0 性能测试在典型手机上大约 10 分钟跑完，五个子项依次执行：

| 子项 | 大致在做什么 |
| --- | --- |
| 网页浏览 3.0 | 渲染页面、滚动缩放、搜索内容、改完内容再渲染一次 |
| 视频编辑 3.0 | 播放、剪辑、保存一段视频 |
| 写作 3.0 | 打开、编辑、保存一份文档，期间对 PDF 做加解密与重新渲染 |
| 图片编辑 3.0 | 打开、编辑、保存一组 4 MP 的 JPEG 图片 |
| 数据处理 3.0 | 解析多种文件格式的数据，再在动态图表上操作并记录帧率 |

**跑之前这样准备**：

1. 关掉后台其他应用，关掉通知提醒；
2. 不插充电线、不连电脑；
3. 放在室温环境下，避开阳光直射和暖气、笔记本出风口这类热源；
4. 如果机器刚用过、背面已经温热，先放几分钟凉下来再跑。

**跑的时候会看到什么**：每个子项都有测试画面，不是干等进度条。全程别碰屏幕 —— 手指触到屏幕会干扰测试；中途想停下就按返回键。

**跑完之后**：如果这是你第一次用这台机器跑，建议隔一会儿再跑一次，两次结果差距在 3% 以内就说明机器状态稳定。个别设备本身性能波动就大，那就多跑几次取平均或取多数。分数怎么读，见 [分数怎么看懂.md](分数怎么看懂.md)。

## 二、续航测试：前提条件比操作步骤更容易踩坑

续航测试就是把性能测试反复循环，一直跑到电量掉到某个阈值以下，用坚持了多久来打分。要跑好几个小时，期间这台设备基本没法做别的事。

**两个硬性条件**：

- 开始前电量必须**不低于 80%**，低于这个值测试根本不会启动；
- 全程**不能插充电线、不能连电脑**，一插上出分就不作数。

这两条也是「RUN 按钮是灰的、点不动」的原因 —— 见 [常见问题与排查.md](常见问题与排查.md)。

**操作步骤**：

1. 把电量充到 80% 以上，拔掉充电线；
2. 关掉后台应用和通知，关掉系统里会主动干预的应用清理功能（具体开关见 [续航测试被系统中断怎么处理.md](续航测试被系统中断怎么处理.md)）；
3. 在设置页里打开纯白校准屏，把屏幕亮度调到固定档位（校准方法见下一节）；
4. 回到测试页点 RUN，然后不用管它，跑完自动出结果；
5. 想中途停止就按返回键。

不同机型停留的电量区间可能略有差别，但都是「从高电量循环跑到低电量」这个逻辑，跑完耗时按小时算很正常。

## 三、屏幕亮度：续航测试里最影响结果的一项

屏幕是手机耗电大头，两台手机亮度不一样，续航分数就没有可比性。官方建议把受测设备都调到同一个亮度，理想值是 200 cd/m²。

没有专业亮度计也能做，两个土办法：

- 用应用里的纯白校准屏，和另一台显示器、灯箱之类的参照物对比亮度；
- 两台设备并排摆着，用眼睛把亮度调成看起来一致。

**不要直接拿系统的亮度百分比当标准**。不同屏幕的最大亮度差得多，A 手机 50% 的亮度和 B 手机 50% 的亮度实际可能差一大截。

**自动亮度一定要关掉**。一边测试一边屏幕自己调亮度，结果没法复现。

## 四、让两次结果能放一起比

官方说自家测试的精度通常在 3% 以内，也就是控制得好的话，同一台设备反复跑，分数会落在 3% 的区间里。要往这个精度靠，几个条件得同时满足：

| 要控制的东西 | 具体做法 |
| --- | --- |
| 环境 | 同一位置、室温、避开阳光与热源 |
| 屏幕 | 关自动亮度，统一到同一亮度档位（续航测试尤其关键） |
| 后台 | 关掉其他应用与通知，测试期间不操作设备 |
| 电源 | 全程不插充电线、不连电脑 |
| 版本 | 应用版本和测试版本都一致，跨版本分数不可比 |
| 次数 | 单次结果仅供参考，多次跑取平均或多数值 |

做严肃对比（比如评测两台机器、验证系统更新前后的差异）时，可以在正式跑之前先重启设备并静置一段时间，让后台活动和温度都回落，再开始测试。

## 五、跑之前顺手检查这几项

- 存储空间够不够：应用本体约 75 MB、Work 3.0 测试约 200 MB，官方建议预留 2 GB；
- 系统的省电模式、超级省电、后台冻结这类功能会不会在测试途中把 PCMark 掐掉 —— 会的话先关；
- 屏幕自动锁屏时间调到最长，或干脆保持常亮，避免测试中息屏；
- 测试页里已装测试包的版本号记一下，和分数一起记，方便以后回溯。

跑完出来一堆数字，哪些能横向比、哪些不能，见 [分数怎么看懂.md](分数怎么看懂.md)。
