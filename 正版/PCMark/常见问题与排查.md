遇到问题先按现象对号入座。PCMark 的多数「故障」其实是前置条件没满足，比如电量不够、插着充电线、系统省电策略在动手，真正需要重装或换版本的情况反而少。

## 一、测试根本启动不了

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 续航测试的 RUN 按钮是灰的，点不动 | 电量低于 80%，或设备正在充电 / 连着电脑 | 充到 80% 以上并拔掉线、断开电脑连接，按钮即可点 |
| 点了 RUN 没反应或闪退 | 对应的测试包没装全 | 在应用内确认 Work 3.0 测试已下载完成，没下完就重新下 |
| 应用装不上 | 系统拦未知来源安装 | 在设置里给当前文件管理器或浏览器打开「允许安装未知应用」 |
| 安装包解析失败 | 安装包传输不完整 | 重新取一次安装包；网盘那份是 3.0.4061，可对照包名与 MD5 确认文件是否完整（见 [下载与安装教程.md](下载与安装教程.md)） |
| 提示空间不足 | 应用本体加测试包远大于安装包本身 | 先清理空间：应用约 75 MB + Work 3.0 约 200 MB，官方建议预留 2 GB |

如果只是想跑性能测试、不测存储，Storage 2.0 那一百兆可以不装，省下的空间留给别的用途。

## 二、跑到一半断了

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 续航测试跑几十分钟后应用被关掉 | 系统的省电 / 后台清理策略杀掉了长时间运行的应用 | 按 [续航测试被系统中断怎么处理.md](续航测试被系统中断怎么处理.md) 逐项放开后台限制，关掉省电模式与清理类应用 |
| 测试中途息屏或回桌面 | 自动锁屏时间太短 | 把屏幕自动锁屏设为最长或保持常亮 |
| 结果明显不完整 | 测试期间被来电、通知、其他应用打断 | 关通知、开免打扰；测试期间不操作设备 |
| 半途不想跑了 | —— | 按设备的返回键即可停止测试 |

**续航测试本身的耗时是按小时算的**，期间这台设备不能做别的事，也不允许插充电线或连电脑。跑之前先把这几个小时空出来，比中途中断重来划算。

## 三、分数不对劲

| 现象 | 排查方向 |
| --- | --- |
| 分数比同机型的人低一截 | 先看是否插着充电线、后台是否有应用、环境温度是否偏高；再重跑一次对比 |
| 重跑两次差距很大 | 设备本身性能波动大或散热不稳，多跑几次取平均；跑前先让设备冷却到室温 |
| 续航结果忽高忽低 | 屏幕亮度没统一、自动亮度没关、联网状态不一致，三者任一项都会显著改变结果 |
| 明显后段掉速 | 看硬件监控曲线：频率下压、温度上抬说明是温控降频，不是硬件故障 |

判断「这个分数算不算正常」的正确参照是官方榜单里**同型号的平均分**，而不是别人的单次最好成绩 —— 榜单点数怎么算、为什么通常比单次跑分低，见 [分数怎么看懂.md](分数怎么看懂.md)。

## 四、界面、版本与兼容

**界面怎么改中文。** 点右上角齿轮进设置，Language 下拉里选 Simplified Chinese。可选语言只有英文、简体中文、俄语三种，没有繁体中文。设置页在这个位置还能看到应用版本号和每个已装测试包的版本号。

**找不到 Work 2.0、Work 1.0、Storage 1.0 和计算机视觉测试。** 这几项在应用 3.0 大版本里已经全部移除并且不再支持，不是你的安装包缺文件。老教程里提到的这些测试项，在当前版本上就是不存在的。网盘里这份是 3.0.4061，属于 3.0 分支，同样没有这些旧测试。

**结果页白屏卡住、榜单刷不出来。** 这两类问题在官方后续版本里修过：白屏挂起在 3.0.4054 已修复，榜单更新时卡住在 3.0.4061 已修复。网盘里这份就是 3.0.4061，本身就是修复后的版本。如果手上的包更旧，换这一份即可。

**繁体系统上显示简体中文。** 这个显示错误在很早的版本里就修掉了，当前版本不存在；若遇到，属于系统语言识别问题，把应用语言手动设为 Simplified Chinese 或跟随系统即可绕开。

**安卓版本要求。** 官方最低要求是 Android 5.0，低于这个版本官方不做支持。装之前对照一下系统版本。

## 五、使用与授权边界

**个人使用免费。** 官方明确说家用版 100% 免费、没有广告、没有内购、没有功能限制，装上就能用。

**商用与批量自动化不在这套免费授权里。** 需要在多台设备上通过 adb 自动化跑分、或用于商业与媒体场景的，走官方的专业版授权，在官方产品页上有对应入口。这件事只需要知道边界在哪，个人自用不受影响。

**跑分成绩会进入对比体系。** 提交的成绩参与官方「最佳设备」榜单的统计，榜单展示的是各机型已收到结果的平均值，不是某一次的最好成绩。这只是统计口径，自己测着玩不用在意。
