## 一、装之前先确认三件事

Beloved 是一款安卓端的 AI 角色扮演聊天应用：装上它，你可以在内置角色列表里挑一个现成的角色开聊，也可以自己设定外貌、声线、性格去建一个角色。本篇只解决「装上、能打开、能进对话」这一段；角色怎么挑、剧情怎么走见另篇。

动手前先把这三样过一遍：

| 检查项 | 怎么看 | 说明 |
| --- | --- | --- |
| 系统版本 | 手机「设置 → 关于手机」 | 本地这份安装包标注的最低要求是安卓 5.2 以上；不同下载站给出的数字并不一致，别被某一个数字卡住，真装不上时见 [常见问题与排查.md](常见问题与排查.md) |
| 剩余存储 | 手机「设置 → 存储」 | 安装包约 30.98M，装完还要留运行缓存，建议至少空出 300M |
| 设备形态 | —— | 这是手机应用，没有所谓「电脑版」；想在电脑上用只能走安卓模拟器 |

## 二、这份包对应哪个版本

网上搜到的多是官方最新版，和你网盘里这一份不一定是同一版，装之前先用下表对一下：

| 项目 | 值 |
| --- | --- |
| 应用名 | Beloved |
| 版本 | 1.0.4 |
| 包名 | `com.be.loved` |
| 安装包大小 | 约 30.98M |
| MD5 | `CC8670923E2715660C9B9B8FEAB9A055` |

想确认文件有没有传坏，可以在电脑上打开 PowerShell，进入安装包所在目录执行：

```powershell
certutil -hashfile .\你的文件名.apk MD5
```

算出来的字符串（不区分大小写）与上表一致，说明文件完整；不一致就重新获取一次，别硬装。

## 三、安装文件从哪拿

安装文件放在夸克网盘的分享里，先转存到你自己的网盘，再下载到手机：**[Beloved 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c436140c0d9b)**。

手机端大致顺序：

1. 在夸克 App 里打开上面的分享链接；
2. 选「保存到我的网盘」，再进自己的网盘目录把安装包下载到手机；
3. 记住下载位置（通常在手机的「下载」目录），下一步要点它。

用电脑的话，可以先把文件下到电脑，再用数据线或聊天软件传到手机，效果一样。

## 四、在安卓手机上安装

1. 打开文件管理器，找到下载好的 `.apk` 文件，点它。
2. 系统提示「禁止安装未知应用」时，点提示里的设置入口，把当前应用（文件管理器或浏览器）的「安装未知应用」权限打开，返回后重新点安装。
3. 看一眼权限列表再点「安装」。这类应用通常会申请麦克风权限（语音对话要用）、存储权限（存聊天里的图片要用），你可以先装，用到了再逐项确认。
4. 装完先别在弹窗里点「打开」，回桌面确认图标出现了再从桌面启动，能少碰一次白屏。

## 五、第一次打开：同意、注册、进首页

1. **同意用户协议与隐私政策**。首次启动会弹出，看完再勾选继续。
2. **注册或登录**。这里通常用邮箱或手机号一类信息注册即可，不需要事先准备复杂资料；具体字段会随版本调整，以你打开时看到的为准。
3. **进首页看角色列表**。能正常看到角色卡片，就说明装好了。挑人、开聊见 [怎么挑角色和开始聊天.md](怎么挑角色和开始聊天.md)。

## 六、装完打不开先别急着重装

多数情况是网络或缓存问题：先切换 Wi-Fi 与移动数据各试一次，再强制关闭应用重开。一直卡在启动画面的话，按 [常见问题与排查.md](常见问题与排查.md) 里的顺序逐条排除，最后再考虑卸载重装。
