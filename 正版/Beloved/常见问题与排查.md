## 一、装不上

本篇把 Beloved 使用中最常遇到的几类问题集中排一遍：装不上、打不开、语音没声音、金币扣得不明白、聊天记录不见了。每条都写清先查什么、再怎么处理。先看安装这一环：

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包出错」 | 下载没下完、文件损坏 | 按 [下载与安装教程.md](下载与安装教程.md) 的方法核对 MD5，不一致就重新获取 |
| 提示「禁止安装」 | 未开启「安装未知应用」 | 点提示里的设置入口，给当前应用放行后再装 |
| 提示「与系统不兼容」 | 系统版本过低 | 本地这份包标注需要安卓 5.2 以上；确认系统版本后仍装不上，就别勉强 |
| 装完找不到图标 | 装进了多用户或隐私空间 | 到「应用管理」里搜一下，确认是否真的装上了 |

## 二、打不开 / 一直卡在启动画面

1. 强制关闭应用，重开一次；
2. 切换网络（Wi-Fi 与移动数据互换）再试；
3. 确认系统时间正常——时间偏差过大会影响联网请求；
4. 前面都不行，卸载后重新安装一次。

## 三、语音对话没反应

- **检查权限**：到「应用管理 → Beloved → 权限」里把「麦克风」打开；
- **检查占用**：后台有通话类应用时，麦克风可能被占，先关掉它们；
- **检查音量**：手机在静音或震动模式下，语音回复会没有声音，确认媒体音量；
- 以上都正常却仍然不出声，先用文字聊，隔一会儿再试语音。

## 四、金币相关问题

- **金币怎么来**：登录、推进剧情、在线互动，见 [金币怎么获得怎么用.md](金币怎么获得怎么用.md)；
- **扣得不明白**：开启新的聊天会话是主要消耗点，操作前先看应用内的提示；
- **余额不刷新**：退出账号重新登录一次，或者稍后再看一次余额。

## 五、记录不见了 / 角色不理人

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 记录没了 | 之前手动删过这段对话 | 删掉之后通常无法找回，重要的内容建议自己另存一份 |
| 换设备记录没跟过来 | 账号未同步 | 确认两台设备登录的是同一个账号；跨端同步以应用内实际表现为准 |
| 角色前后对不上、跳出人设 | 单段对话上下文太长 | 新建一个对话重开，见 [怎么挑角色和开始聊天.md](怎么挑角色和开始聊天.md) |
| 聊到一半它忘了你刚说的话 | 这一轮聊得太长，早先的内容失效 | 新开一段对话，开头复述一遍关键信息，见 [聊天久了角色记不住怎么办.md](聊天久了角色记不住怎么办.md) |
| 昨天交代过的事今天不记得 | 关键信息没写进角色设定 | 把要紧的设定填到角色设定里，见 [聊天久了角色记不住怎么办.md](聊天久了角色记不住怎么办.md) |
| 角色一直不回 | 网络或服务端波动 | 切换网络重试；长时间如此，再检查是否有新版本 |

## 六、还是没解决

先到「应用管理」里确认版本号与包名，正常应为 `com.be.loved` 与 1.0.4。如果你拿到的是同名但不同的应用，本节的办法多半不适用，先按 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 对一下号。
