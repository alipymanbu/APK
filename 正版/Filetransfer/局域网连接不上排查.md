## 一、排查总表

FileTransfer 在局域网里走 FTP 协议，连接不上基本逃不出下面这几类原因。先扫一眼表格，找到对得上的症状再展开：

| 顺序 | 检查点 | 典型症状 |
| --- | --- | --- |
| 1 | 两台设备不在同一个网络 | 手机显示的地址在电脑上完全打不开 |
| 2 | 地址或端口输错 | 报「无法访问此网站」或一直连接失败 |
| 3 | 电脑防火墙拦截 | 手机端显示已连接请求，电脑端无反应 |
| 4 | 路由器开了设备隔离 | 两台都能上网，但互相访问不到 |
| 5 | VPN / 虚拟机网卡捣乱 | 电脑有多个 IP，或 IP 不是 192.168 开头 |
| 6 | 手机端服务掉了 | 之前连得上，中途断开 |

## 二、逐项展开

### 1. 先确认真的在同一个网络

这是出现最多的一种。两种典型情况：

- 手机连了 WiFi，电脑却插在**光猫**上——网络结构是「电脑—光猫—路由器—手机」时，电脑和手机不在同一层，互相够不着。解决办法：让电脑也连到同一个路由器（插路由器的 LAN 口，或连同一个 WiFi）。
- 一台连了**访客网络 / 办公网络**。访客 WiFi 通常做了设备隔离，能上网但设备之间不通。换到主 WiFi 再试。

最快的验证方法：电脑按 `Win+R`，输入 `cmd` 回车，运行 `ipconfig`，看 IPv4 地址是不是 `192.168.x.x` 且与手机设置里显示的 WiFi IP 前三段一致。

还不行就换个底：让电脑直连手机的热点再试一次。热点下能连，说明问题出在路由器或原来的网络；热点下也连不上，重点查电脑端（防火墙、VPN）。

### 2. 地址输对的三个细节

手机上显示的地址要**原样**输入电脑，三个容易错的地方：

- 开头是 `ftp://` 不是 `http://`，也别打成 `https://`——浏览器会自动补 https，补完就打不开了，手动改回 `ftp://`。
- 端口号不能漏。`ftp://192.168.1.5:2121` 里的 `:2121` 是端口，漏掉它电脑会去连默认的 21 端口，自然连不上。
- 输错字符：IP 里是英文句点 `.`，不是逗号；地址里别带空格。

IP 和端口都以手机屏幕上**当前显示**的为准——手机换了网络（比如从 WiFi 切到热点）后 IP 会变，重新看一眼。

还有一种情况：地址没错，但回车后弹出来的是浏览器而不是文件夹窗口——部分 Windows 11 会把 `ftp://` 交给浏览器处理，而浏览器根本打不开 FTP 站点，结果两头都进不去。遇到这种不必折腾系统设置，直接换 [FileZilla 等专门的客户端](用FileZilla等客户端连接手机FTP.md) 连，一步绕开。

### 3. 放行电脑防火墙

Windows 防火墙有时会拦掉 FTP 连接。放行办法：

1. `Win+R` 输入 `control` 打开控制面板。
2. 进入「系统和安全 → Windows Defender 防火墙」。
3. 点左侧「允许应用或功能通过防火墙」。
4. 找到资源管理器（或你用的 FTP 客户端），把「专用」和「公用」都勾上，保存后重试。

也可以临时关闭防火墙测试一次：关了就能连，说明就是它拦的，按上面步骤加白名单即可。

### 4. 路由器的设备隔离（AP 隔离）

有些路由器默认开启 AP 隔离 / 访客隔离，功能是禁止连 WiFi 的设备互相访问——正好挡住这类局域网传输。处理办法：

1. 浏览器打开路由器管理地址，常见的是 `192.168.1.1` 或 `192.168.0.1`（具体看路由器底部标签）。
2. 在「无线设置」或「安全设置」里找「AP 隔离 / Client 隔离 / 访客网络隔离」。
3. 关掉并重启路由器。

公司、学校、酒店的公共网络一般由管理员强制隔离，你改不了设置，用手机热点替代最省事。

### 5. 关掉 VPN、退出虚拟机

VPN 会改走流量路径，VMware、VirtualBox 之类虚拟机软件会给电脑加虚拟网卡，导致电脑出现好几个 IP、FileTransfer 显示的地址对不上号。处理：

- 断开所有 VPN 连接。
- 完全退出虚拟机软件。
- 再跑一次 `ipconfig`，确认电脑当前用的是 `192.168` 开头的真实局域网 IP。

### 6. 手机端服务状态

FTP 服务只在 FileTransfer 前台运行期间有效。传到一半断开，多半是手机被系统清了后台或锁屏断网。可以在系统设置里给 FileTransfer 关掉电池优化、允许后台运行；重试时重新读一遍屏幕上显示的地址，它可能已经变了。

## 三、连上了但传输速度慢

能连上但速度只有几百 KB/s 的话，问题通常不在 FileTransfer，而在 WiFi 这一段路。按影响从大到小：

- **频段**：2.4 GHz 与 5 GHz 是两个速度档，5 GHz 快得多。家里路由器通常两个频段都发，手机 WiFi 详情里能看到当前连的是哪个——连到 5 GHz 那个名字（有的路由器用 `_5G` 后缀区分）再试。
- **信号**：离路由器远一堵墙，速度就可能掉一半；微波炉、无绳电话也工作在 2.4 GHz 频段，用着微波炉传文件会明显变慢。把手机和电脑挪近路由器是最省事的提速办法。
- **抢带宽**：WiFi 是共享的，同网络下有设备在看视频、下载、联机游戏，传输速度就会被分走。传大文件时让别的设备先歇一歇。
- **热点直连**：路由器老旧或信号差时，手机直接开热点让电脑连上，跳过路由器这一环，速度往往反而更高。

另外记住 FTP 的一项固有特性：**没有断点续传**。连接断开，没传完的大文件要整个重来——传几个 G 的视频前先确保手机不会锁屏断网、服务开着；特别大的文件不如先用手机文件管理器压缩，或干脆分几次传。

## 四、排查完还是不行

按顺序做完上面六步仍连不上时，把两台设备、路由器都重启一遍（断电 30 秒再上电）再试，能解决大部分残留的网络状态问题。要是急用，数据线或蓝牙是保底方案，各自适合什么场景在 [与蓝牙数据线云盘的对比.md](与蓝牙数据线云盘的对比.md) 里有一张对照表；FileTransfer 本身的安装与连接操作回顾 [手机与电脑互传文件步骤.md](手机与电脑互传文件步骤.md)。
