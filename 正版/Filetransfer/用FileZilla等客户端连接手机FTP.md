# 用 FileZilla 等客户端连接手机 FTP

> 资源管理器的 FTP 地址打不开、或在 Windows 11 上被浏览器抢走时，换一个专门的 FTP 客户端连 FileTransfer，通常一步就通。

## 一、为什么值得换客户端

Windows 资源管理器自带的 FTP 支持这些年一直在弱化：微软社区里有不少 Windows 11 用户反馈，在地址栏输入 `ftp://` 开头的地址后，窗口不是在资源管理器里打开，而是被默认浏览器（如 Edge）接管，浏览器又打不开 FTP 站点，结果两头都进不去。这不是 FileTransfer 的问题，是 Windows 侧 FTP 关联方式的变化。

换用专门的 FTP 客户端有三个直接好处：

- 不受系统 FTP 关联影响，地址、端口、账号自己填；
- 多数客户端支持并发连接，速度普遍比资源管理器里拖拽更快；
- 断点、重试、错误提示都更清楚，传一大批文件时更好判断进度。

## 二、用 FileZilla 连（免费，最常用）

1. 在官网 [filezilla-project.org](https://filezilla-project.org) 下载 FileZilla Client 并安装（装机时注意跳过捆绑选项，只装客户端版，不用装 Server 版）。
2. 手机端 FileTransfer 先开启服务，记下屏幕上显示的 IP 和端口（形如 `ftp://192.168.1.5:2121`）。
3. 打开 FileZilla，顶部「快速连接」栏按下面格式填：

   | 输入框 | 填什么 |
   | --- | --- |
   | 主机 | 手机 IP，如 `192.168.1.5` |
   | 用户名 / 密码 | 一般留空；若连接后弹出登录框，说明 App 里配过账号，填上对应值 |
   | 端口 | 手机上显示的端口，如 `2121` |
4. 点「快速连接」。左侧是电脑文件，右侧是手机文件，从左边拖到右边就是往手机传，反过来就是导出。

如果连不上，报错信息会明确写「拒绝连接」还是「超时」，比资源管理器一声不吭好排查得多，拿着报错回到 [局域网连接不上排查.md](局域网连接不上排查.md) 对号入座即可。

## 三、其它可用的连法

- **WinSCP**：另一款免费客户端，界面与资源管理器接近，文件协议选 FTP、填 IP 和端口即可，习惯 Windows 窗口操作的话上手更快。
- **浏览器**：地址栏输完整 `ftp://IP:端口` 仍可用于快速下载小文件，但上传、批量操作都不方便，只当应急手段。
- **命令行**：Windows 自带 `ftp` 命令（`Win+R` 输入 `cmd` 后运行 `ftp 手机IP`）能连能传，适合脚本化场景，日常不如前两种直观。

## 四、传大量小文件前先打包

FTP 每传一个文件都要单独建一次连接，几百张照片、上千个小文档一个个传会慢得离谱——这是 FTP 协议本身的特性，客户端再好也救不了。先把文件在电脑上压成一个压缩包（右键 → 压缩为 ZIP），再传这一个包，速度能差出数量级；传到手机后再解压。反过来从手机导出大量照片时同理，先用手机上的文件管理器把照片打包，再一次传完。

连接建立与基本传输的流程见 [手机与电脑互传文件步骤.md](手机与电脑互传文件步骤.md)；如果传输速度本身不理想，频段与信号那几个原因在排查篇的「传输速度慢」一节里。
