# FileTransfer 手机与电脑互传文件步骤

> 本篇讲怎么把 FileTransfer 跑起来：手机端开启服务，电脑端访问，然后双向传文件。还装好的先看 [下载与安装教程.md](下载与安装教程.md)。

## 一、开传之前：把两台设备放进同一个网络

FileTransfer 走 FTP 协议，官方要求在局域网中使用，所以**手机和电脑必须连同一个网络**，常见两种接法：

- 家里 / 办公室：手机和电脑都连同一个路由器的 WiFi（电脑插网线到同一个路由器也算）。
- 没有 WiFi：手机开个人热点，让电脑连这个热点，一样能传，而且不耗手机流量之外的费用。

判断是不是同一个网络最简单的办法：看两台设备的 IP 地址前几段是否一致（比如都是 `192.168.1.x`）。对不上就先调网络，调法见 [局域网连接不上排查.md](局域网连接不上排查.md)。

## 二、手机端：开启服务

1. 打开 FileTransfer，首次使用同意用户协议并允许存储权限（首次启动的设置在安装教程里写过）。
2. 在首页**选择一种存储器访问方式**——决定电脑端能访问到手机的哪部分存储，一般选内部存储即可。
3. 点右上角齿轮进入设置页面，在**连接**一项里可以查看或修改**端口**。默认端口通常就能用；只有端口被别的应用占用时才需要改，改完点确定。
4. 回到主界面，点启动按钮开启服务。开启后屏幕上会显示一个 FTP 地址，形如 `ftp://192.168.1.5:2121`（IP 和端口以你手机上显示的为准）。

这个地址就是电脑访问手机的入口。传输期间别把应用杀掉、尽量别锁屏，服务关了电脑那头自然就断了。

## 三、电脑端：三种方式访问手机

### 方式一：Windows 资源管理器（最顺手）

1. 打开「此电脑」或任意一个文件夹。
2. 点顶部地址栏，清空后输入手机上显示的完整地址，例如 `ftp://192.168.1.5:2121`，回车。
3. 手机存储的目录就出现在窗口里了，拖拽、复制、粘贴都和操作本地文件夹一样。

如果 App 设置了用户名密码，回车后会弹一个登录框，填上即可；没设置就直接进。

### 方式二：浏览器

在电脑浏览器地址栏输入同样的 FTP 地址也能访问，适合只想快速下载一两张照片的场景。注意 FTP 地址是 `ftp://` 开头，不是 `http://`，个别浏览器会自作主张补成 https 导致打不开，手动改回 `ftp://` 就好。另外部分 Windows 11 上输入 `ftp://` 会被直接交给浏览器而不是在文件夹窗口里打开，传输体验很差——这种系统行为改不动，换 [FileZilla 等专门的客户端](用FileZilla等客户端连接手机FTP.md) 更省事。

### 方式三：映射成网络驱动器（常传的话）

经常互传可以把手机挂成一个「盘符」：在「此电脑」上右键 → 「添加网络位置」→ 按 向导粘贴 FTP 地址 → 完成后资源管理器里会多一个指向手机的入口，双击即连（前提还是手机端服务开着）。

## 四、双向传文件

连接建立后，方向随你选：

| 你想做 | 在哪边操作 | 怎么做 |
| --- | --- | --- |
| 手机 → 电脑（导照片、导视频） | 电脑 | 在窗口里进入手机目录，把文件复制、拖到电脑任意文件夹 |
| 电脑 → 手机（装 APK、存文档） | 电脑 | 把电脑里的文件复制、拖进手机目录，落到哪个文件夹就在哪个文件夹 |

批量传：在电脑窗口里按住 Ctrl 逐个点选（或 Ctrl+A 全选），一次拖完。视频、安装包这类大文件走局域网 WiFi 通常也比蓝牙快得多，几分钟到十几分钟量级就能传完一部高清电影（实际速度看你的路由器和 WiFi 信号）。

传完记得回手机端把服务关掉。FTP 服务开着，同网络内的其他设备理论上也能尝试访问这个地址，用完即关更稳妥。

## 五、动了手却连不上

八成是网络环境的事，不是操作错。直接按 [局域网连接不上排查.md](局域网连接不上排查.md) 的清单从上往下过一遍，最常见的原因（不同路由器、防火墙、地址输错）都排在前面。传文件这事的体验值不值，也可以先看 [与蓝牙数据线云盘的对比.md](与蓝牙数据线云盘的对比.md) 再决定用哪种方式。
