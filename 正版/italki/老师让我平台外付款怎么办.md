# 老师让我平台外付款怎么办

> 聊天里冒出「直接转我微信/支付宝更便宜」时，该答应吗——不该，这一篇说清为什么和怎么做。

## 一、先说结论：平台规则不允许

所有学生的付款都必须走 italki 平台，**平台外付款属于严重违反服务条款的行为**——这条规则对老师和学生双向生效（[学生侧官方说明](https://support.italki.com/hc/en-us/articles/206352578-What-should-I-do-if-a-teacher-asks-me-to-pay-outside-of-italki)、[教师侧官方说明](https://support.italki.com/hc/zh-cn/articles/206351758-如果有学生想要在italki平台外付款-我该怎么做)）。所以不管对方给出的理由多充分（「手续费太高」「给你打折」），答案都是不转。

## 二、你实际会承担的风险

平台外付款对你没有任何保护，逐条对着官方规则看：

| 平台内付款 | 平台外付款 |
| --- | --- |
| 平台托管费用，上完课、你确认后才付给老师 | 钱直接进对方口袋，收了钱不上课无处追 |
| 课时有系统记录，出问题平台能介入处理争议 | 没有平台记录，官方明确表示无法协助处理这类争议 |
| 评价公开落在老师主页，受平台监督 | 一切都在台面下，对方换个名字继续 |

一句话：**私下付款省下的那点钱，换掉的是你全部的售后。**

## 三、正确做法（按顺序）

1. **不转账**：不管对方说得多可信，不在平台外付一分钱；
2. **继续走平台**：按 [订课与上课流程.md](订课与上课流程.md) 正常订课、用点数结算；
3. **留存证据**：截图聊天记录里对方要求平台外付款的部分；
4. **举报**：通过 [官方举报入口](https://support.italki.com/hc/zh-cn/articles/206353478-我该怎样举报italki上的不当行为) 或帮助中心的[联系表单](https://support.italki.com/requests/new) 提交，附上截图与课时/老师信息。

## 四、老师这边会付出什么代价

官方对老师的处理写得很重：**接受或要求平台外付款、把学生带离平台的老师，会被取消教师资格，并没收教师钱包里剩余的点数**（[官方警告口径](https://support.italki.com/hc/zh-cn/articles/206351758-如果有学生想要在italki平台外付款-我该怎么做)）。这也意味着两件事：正经老师不会冒这个险；而一个愿意开口的，你更没有理由转钱。

付款方式与手续费的正常路径，见 [点数充值与收费标准.md](点数充值与收费标准.md) 第四节。
