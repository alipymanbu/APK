## 一、钱有三种付法

| 方式 | 怎么用 | 适合什么时候 |
| --- | --- | --- |
| 单节课 | 每约一节付一次款 | 刚开始试不同老师 |
| 课时包 | 一次买同一老师的多节课，通常带折扣 | 认准一个老师之后 |
| italki 点数 | 一次买一批点数，约课时用点数结算 | 不想每节课都走一遍付款 |

官方没有订阅制、没有合同，一节一节买也完全可以。三种方式的入口都在订课流程里（见 [订课与上课流程.md](订课与上课流程.md) 第三节）。

不论选哪种，钱都只在平台内走——**任何一位老师让你绕开平台直接转账，都不要答应**，代价与做法见 [老师让我平台外付款怎么办.md](老师让我平台外付款怎么办.md)。

## 二、一节课多少钱：老师自己定

- 每位老师**自行定价**，平台只给辅导教师和职业教师各设了一条最低时薪线；
- 试用课、单节课、课时包**三种价格互不相同**——试用课是优惠价，课时包通常按折扣计；
- 具体金额以每位老师主页当时显示的标价为准，官方不控制老师调价。

## 三、点数是什么

- 点数（italki Credits）是平台内的虚拟货币，**只能用来购买平台上的老师服务**；
- 买单节课或课时包时，可以用点数直接结算，省去每次付款；
- 点数放在学生钱包里，余额与流水在 [www.italki.com/finance/overview](https://www.italki.com/finance/overview) 查看；
- **已充值的点数不退现金**（官方政策，[原文](https://support.italki.com/hc/en-us/articles/360023115453-What-is-italki-Credits)）。这一点决定了下面第五节的走向——能让点数「回来」的，都是退回钱包继续用，不是退回你的银行卡。

## 四、支付方式有哪些

- 支付方式**按账单国家/地区显示**：常见的有信用卡、PayPal、Skrill、Apple Pay、银联、支付宝；
- **微信支付只在 [www.italki.cn](https://www.italki.cn) 和账单国家为中国时的 App 里出现**；
- App 里找不到以前用过的支付方式时，先查手机的语言与地区设置——部分支付方式受服务商限制不上架；
- 登录后在 Payment 设置页能看到自己当前可用的完整列表（[官方说明](https://support.italki.com/hc/en-us/articles/217489907-Which-payment-methods-can-I-use-to-pay)）。

关于到手价格的三个事实（[官方口径](https://support.italki.com/hc/zh-cn/articles/360023115873-italki点数和支付手续费)）：

- 点数购买**一律以美元结算**；你用其他货币支付时，页面显示的金额受汇率影响、仅供参考；
- 第三方支付通道可能收取额外手续费，**这笔钱不是 italki 收的**；选好支付方式后，付款页会先显示手续费金额再让你确认；
- 用当地货币付款能不能换成美元扣款，以你的银行或支付服务商为准，可能产生货币转换费。

## 五、点数什么时候能退回来

| 情况 | 点数去向 |
| --- | --- |
| 你主动取消课时请求 | 100% 退回学生钱包 |
| 老师拒绝你的请求 | 100% 退回学生钱包 |
| 老师超时未确认，请求过期 | 100% 退回学生钱包 |
| 开课前 24 小时以上、双方同意取消 | 课时点数退回学生钱包 |
| 课后报「出现问题」并达成一致 | 课时点数退回学生钱包 |
| 已充值的点数 | 不退现金 |

退回钱包的点数可以继续约课，不受影响。课程取消与改期的时间线见 [订课与上课流程.md](订课与上课流程.md) 第八节。

## 六、课时包怎么终止

买多节的课时包中途不想跟这个老师了，走「请求终止」（[官方说明](https://support.italki.com/hc/zh-cn/articles/360016299554-如果我想终止课时包-该怎么办)）：

1. 入口：**我的课时 → 课时包详情 → 请求终止课时包**；发起前先把待处理的课取消或处理完。
2. 老师同意 → 未完成课时退款到账；**老师超过 3 天不响应 → 按你的申请自动终止**，未完成课时退款。
3. 退多少按**谁发起**算：
   - **你发起**：已完成课时按未打折的原价扣，退款 = 课时包总价 − 原单价 × 已完成课时数；
   - **老师发起 / 老师无法继续授课**：已完成课时按折扣价扣，未完成部分全退。
4. 老师拒绝 → 进入争议流程，官方发邮件调查双方理由；**3 天内双方都不回邮件，终止申请作废，课时包恢复原状**。

官方的建议是先跟老师沟通再发起，避免事后退款争议。

### 课时包还会到期：延期与过期结算

课时包除了终止还有一条**延期**通道（[官方说明](https://support.italki.com/hc/zh-cn/articles/360022945034-课时包过期会发生什么-我该怎么办)）：

- 到期前 **30 天**起，课时包上会出现「请求延期」按钮；平台会在到期前 **1 个月和 1 周**各提醒你一次；
- 双方同意 → 课时包延长 **1 个月**；你和老师**各有 1 次**发起延期的机会；对方 **3 天不响应，请求自动被接受**；
- 到期时谁都没动：**未完成课时的点数退回你的钱包**；**已完成的课时按未打折的单节原价**从包里结算给老师——按原价算完如果已经超过整包价格，整包的钱都归老师；
- 已经成功约上的课**不受过期影响**，照常上；但只是发出去、还没被接受的请求，可能赶不上到期日。

所以买课时包前先估好节奏：每周稳定上几节、多久能上完，宁可买小包。

## 七、点数会过期

- 账号**连续 12 个月未登录**，点数过期；
- 过期未满 12 个月可以**激活一次**，激活后点数再有效 12 个月；
- 想不踩这条线，隔几个月登录一次账号就够了。

## 八、100% 满意保证：最多退两次试用课

官方的「[100% 满意保证](https://support.italki.com/hc/zh-cn/articles/10196315242649-什么是100-满意保证)」是一条**专门针对试用课**的兜底规则，条件与打法都要看清：

| 项目 | 规则 |
| --- | --- |
| 适用课型 | **仅试用课**（常规单节课、课时包不适用） |
| 触发条件 | 老师缺席，或课的效果没达到你的预期 |
| 次数上限 | **最多 2 次**点数退款 |
| 前提 | 试用课必须是**你自己花钱买的**——用代金券买的不算 |
| 时限 | 试用课时间过后 **48 小时内**联系官方客服 |
| 要提供 | 课时 ID + 不满意的原因 |
| 不受理 | 课时已被标记为「完成」之后再提；违反服务条款的情形 |

金额与条款以官方页面当时显示为准；日常的取消、拒绝、过期场景，按第五节的表走就够了。
