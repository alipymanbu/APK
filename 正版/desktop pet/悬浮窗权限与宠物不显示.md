## 一、先确认一件事：悬浮窗权限给没给

桌宠这类应用全靠「显示在其他应用上层」（悬浮窗）权限活着 —— 没有它，宠物根本画不到屏幕上。所以领养完看不见宠物，第一件事不是重装，而是去查这个权限：

1. 打开系统「设置」，进「应用」找到 Pixel Shimeji（列表里也可能显示为 desktop pet）。
2. 进「权限」或「特殊应用访问」，找到「显示在其他应用上层」（有的系统叫「悬浮窗」「允许显示在其他应用的上层」）。
3. 确认开关是开的。关着就打开，然后回桌面看宠物是否出现。

几个国产品牌的入口略有差异，常见叫法如下（以你的系统实际菜单为准）：

| 品牌 | 常见入口 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 该应用 → 权限管理 → 显示悬浮窗 |
| 华为 / 荣耀 | 设置 → 应用和服务 → 应用管理 → 该应用 → 权限 → 悬浮窗 |
| 原生类（Pixel 等） | 设置 → 应用 → 该应用 → 特殊应用访问 → 显示在其他应用上层 |

另外，系统大版本更新后悬浮窗权限有时会被重置 —— 之前明明养得好好的，升级后宠物没了，先回来看这一项。

## 二、权限开了还是不显示

按顺序试：

1. **重新打开一次应用**：有的版本在授权后需要回到应用里再点一次领养或开始，宠物才会上屏。
2. **重启应用或重启手机**：排除授权后界面卡在旧状态的情况。
3. **重新领养一只**：回应用里的宠物列表再走一遍领养流程，等于重新触发一次上屏。
4. **核对版本与安装完整性**：安装包不完整可能导致功能异常，MD5 核对方法见[下载与安装教程.md](下载与安装教程.md)；确认无误后可卸载重装一次。

## 三、宠物养着养着就消失

宠物的动画要一直挂在屏幕上，很多系统会把它当「后台耗电应用」清掉。宠物过一阵就没了，基本是省电机制在杀它：

- **放宽电池限制**：进「设置 → 电池」，找到该应用，把省电策略从「受限 / 优化」改成「不受限制 / 无限制」（各品牌叫法不同）。
- **在最近任务里锁定**：小米、vivo 等品牌可在最近任务卡片上长按，点锁头图标把应用锁住，避免一键清理时被杀。
- **允许后台运行 / 自启动**：部分品牌还有独立的「后台弹出界面」「自启动」开关，一并打开更稳。

做完上面这些后观察半天到一天，宠物稳定常驻就说明生效了；如果还是频繁消失，把现象（多久消失一次、消失后应用还活着吗）记下来对照[常见问题与解决方法.md](常见问题与解决方法.md)再排查。
