# Lookus 定位不准或收不到通知怎么办

> 本篇按「位置不对」「数据不更新」「通知不来」三类故障整理排查清单，条目来自官方说明与安卓各品牌的系统设置差异。

## 一、先判断是哪一类问题

同样是「感觉不对」，原因完全不同，先归类再对症：

| 现象 | 大概率原因 | 去哪节 |
| --- | --- | --- |
| 位置能看，但偏差大/漂移 | 定位信号弱 | 第二节 |
| 位置长时间不更新 | 网络不通或后台被杀 | 第三、四节 |
| 位置空白 | 对方关闭共享或权限没给全 | 第五节 |
| 报备/提醒收不到 | 通知权限或省电策略 | 第四、六节 |
| 紧急提醒对方收不到 | 通知/悬浮窗/定位权限缺项 | 第六节 |

## 二、位置偏差大：先看定位信号

Lookus 的定位来自手机系统本身的定位能力（官方用户协议里也写明定位受多因素影响、不保证百分之百准确，并提到地图合作方为高德地图），所以漂移多数不是应用的问题：

- 在地下车库、电梯、大型商场内、高架桥下，GPS 信号本来就弱，走出遮挡区后位置会自己回准；
- 确认对方手机的定位方式没有停留在「仅设备/GPS 模式」，开启「高精度」定位（用 GPS + 网络）偏差会明显小；
- Wi-Fi 关闭时定位精度也会下降，哪怕不连网，开着 Wi-Fi 开关对定位有帮助；
- 偏差持续存在时，把应用从后台划掉重开一次，触发重新定位刷新。

## 三、数据不更新：网络不稳是官方给的第一解释

官方 FAQ 对「数据怎么不更新了」的答复是：数据上传依赖网络状态，网络不稳定会造成上传失败或延迟更新。对应的排查：

1. 对方手机确认移动数据开着、信号格数正常； Wi-Fi 环境下路由器假死（连着但上不了网）也会造成这种表现，切换一次飞行模式即可验证；
2. 你这边同样检查自己的网络——收不到更新的另一可能是对方传上来了、你这边拉不下来；
3. 两边网络都正常仍不更新，重启应用；再不行重启手机。

## 四、后台被杀：安卓（尤其国产系统）的头号坑

「刚才还准的，过一小时再看就不动了」，十有八九是系统把应用的后台杀掉了。这一节针对安卓——官方对新版的描述是 iOS 即使应用不在后台运行也能保持定位更新，iPhone 一侧通常不需要下面的处理；两人混搭时先查安卓这边。各品牌的处理位置不同，思路一致：允许 Lookus 后台运行 + 关掉对它的电池优化：

| 品牌 | 设置入口（以实际系统为准） |
| --- | --- |
| 小米/Redmi | 应用信息 → 省电策略 → 无限制；最近任务里下拉卡片加锁 |
| 华为/荣耀 | 设置 → 电池 → 更多电池设置，关闭对该应用的优化；应用启动管理改为手动并允许后台活动 |
| OPPO/一加 | 电池 → 更多设置 → 应用速冻/智能后台，把 Lookus 排除 |
| vivo/iQOO | 电池 → 后台耗电管理，允许后台高耗电 |
| 原生/三星 | 电池 → 应用电池用量 → 无限制 |

做完这些，再把位置权限改成「始终允许」——「仅使用期间允许」在锁屏后等于停更，这是和新手解释成本最高的一条。改完后观察半天，位置更新是否恢复正常。

## 五、位置完全空白：从共享开关查起

配对正常但地图上根本没有对方的位置，按顺序查：

1. 让对方打开 Lookus，看隐私设置里的位置共享是否被关掉（或无意中设成了暂停）；
2. 对方手机检查定位权限是否给了、是否给了「始终允许」；
3. 双方退出账号重新登录，刷新配对与授权状态；
4. 仍空白则确认配对是否还在生效（对方换手机、重装应用后需要重新配对，流程见 [配对绑定与位置共享设置.md](配对绑定与位置共享设置.md)）。

## 六、通知与紧急提醒收不到

应用内提醒（报备、到家、作息、紧急联系）全走系统通知通道，逐项确认：

- 系统设置 → 应用 → Lookus → 通知：全部允许，且没有被设成「静默通知」；
- 免打扰/勿扰模式是否会吞掉这类通知，必要时把应用加入白名单；
- 悬浮窗权限：紧急联系的强提醒弹窗需要它；
- 官方 FAQ 对「收不到紧急联系」的答复就是检查重要通知、定位、悬浮窗这几项权限。

第四节的省电设置同样影响通知：后台被杀后，新通知自然一条也来不了。全查过还不行，可以给官方邮箱写邮件反馈：[lookus@codeffect.top](mailto:lookus@codeffect.top)（官网 [www.lookusglobal.com](https://www.lookusglobal.com/) 上给出的联系方式），描述问题时带上手机型号、系统版本和现象发生的时间段。

## 七、排查完之后

多数「不准」「不来」的问题出在权限与省电这两层，与网络无关的部分很少。如果排查后定位恢复正常但轨迹里仍有空洞，那段缺失的时间就是数据没能上传，补不回来；日常想要提醒更周全，可以把 [轨迹回放与自动报备设置.md](轨迹回放与自动报备设置.md) 里的地点报备配起来用，配合 [手机使用报告与紧急联系.md](手机使用报告与紧急联系.md) 的演练一次，整套功能才算真正跑通。
