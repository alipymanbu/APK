以下按官方帮助中心的现行说明整理（截至 2026 年 2 月），个别入口位置随版本可能不同，以你手上的实际界面为准。

## 一、媒体库怎么组织的

添加文件源后，App 会自动扫描并刮削所有视频文件，然后按五个板块归置：

| 板块 | 收什么 |
| --- | --- |
| 全部 | 电影、电视、综艺的总集 |
| 电影 / 电视 | 对应类型 |
| 系列 | 同一系列电影自动整合（如「007」系列、漫威系列） |
| 未匹配 | 没识别出元数据的文件，重点盯这里 |

默认排序是按上映时间降序，最新的排最上面。顶部的轮播区展示的是智能推荐的影视合集（高分经典、近期新片），不是你自己库里的片。

## 二、找片：搜索与筛选

右上角进搜索页，能做的组合：

- 关键词搜索；
- 按板块、类型、年份、地区、语言筛选；
- 按添加时间、评分、时长、上映时间排序；
- 只看**已观看 / 未观看**——配合下面的观看标记用。

## 三、观看记录与详情页操作

**继续观看**：看了一半的影片出现在这个类目，带进度，点播放接着看。点「继续观看」能展开完整的历史列表，单条左滑删除，或右上角编辑批量删除。

**详情页更多按钮**里还有这些动作：

- **稍后再看**：加入列表，在「我的」页面查看和管理；
- **观看标记**：手动标已看/未看，给搜索筛选用；
- **离线缓存**：把片子缓存下来离线看；
- **下载海报**：横竖版海报都能下载。

## 四、识别错了：重新匹配

刮削是按文件名猜的，文件名乱就会猜错。入口有两个：

- **整部影片**：媒体库、搜索结果或合集里**长按**影片；或进详情页点右下角菜单；
- **单个文件**：「未匹配」列表里点文件；或详情页的媒体信息处单击某个文件。

以剧集为例的操作链：进入重新匹配 → 输入或选择识别的字段 →（多文件源时可选源）→ 选「电视剧」点确定 → 进入季/集匹配页 → **选好季后自动按文件名匹配集数**。文件名规范、按季打包成文件夹的，一次操作就能把整部剧配完。

## 五、单集层面的修正

季选对了但细节不对时，四个动作对应四种情况：

| 情况 | 动作 |
| --- | --- |
| 集数错配（第 3 集认成第 2 集） | 点「选集」手动指定 |
| 数据缺失（总共 30 集只认出 29 集、标题缺失） | 点「自定义」补全 |
| 本来就对，只是跟着整部剧一起改 | 点「移除」→「保留原有」 |
| 文件根本不属于这部剧 | 点「移除」→「移到未匹配」，之后在「未匹配」里单独重新匹配 |

播放层面的设置（音轨、字幕、倍速）见 [字幕设置与播放功能.md](字幕设置与播放功能.md)；如果是文件源本身连不上、列表不刷新，回到 [连接NAS与添加媒体源.md](连接NAS与添加媒体源.md)。
