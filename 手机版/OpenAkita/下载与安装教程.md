## 一、装之前：这个 APK 单独装上不能聊天

OpenAkita 是开源的多 Agent AI 助手：电脑上的桌面端负责思考和干活，手机端负责连过去当块屏幕。你只装手机端、电脑上没跑桌面端，打开看到的就是连接界面，什么任务都发不出去。所以正确顺序是：先把电脑端装好并配好模型，再装这个 APK。装好之后：

- 你在手机上发的每句话，实际是在指挥电脑上那套助手；
- 手机端不带模型、不带独立配置，第一次用必须先填电脑的远程地址（见 [连接桌面端服务器教程.md](连接桌面端服务器教程.md)）。

## 二、安装包从哪拿

两条路，按需选：

1. **网盘**：[OpenAkita 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d6826aa9ad87) —— 已整理好，转存后直接下载。
2. **官方下载页** [openakita.ai/download](https://openakita.ai/download/)：Android APK 和 Windows / macOS / Linux 桌面端在同一个页面上。官方版本更新很勤，页面上的版本号以当时显示为准（检索本文资料时安卓端已到 v1.27.42，之后可能更高）；网盘那份固定是 1.27.9，要追新版就从官方页拿，之后怎么覆盖安装见 [新版本怎么升级.md](新版本怎么升级.md)。

电脑端的桌面应用也从这个页面下载，它才是手机要连的那台「服务」。

## 三、安装步骤

1. 把 APK 传到手机上（直接在手机浏览器里下载，或用数据线、局域网传输到手机）。
2. 点开文件安装。安卓会弹「不允许安装未知来源应用」，按提示对该来源放行即可（不同品牌路径略有差异，一般在 设置 → 安全/隐私 → 安装未知应用 里）。华为、小米、vivo、OPPO 等国产机型还会追加「未经过安全检测」之类的风险提示——这是所有非应用市场安装包都会遇到的例行提醒，选「继续安装 / 手动安装」走完即可。
3. 装完打开：第一屏是戴耳机的小狗吉祥物启动图，随后进入「连接服务器」界面——此时还不能发消息，去走一遍 [连接桌面端服务器教程.md](连接桌面端服务器教程.md)。
