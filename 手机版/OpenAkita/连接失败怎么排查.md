## 一、「测试连接」失败：逐项核对

按下面的表从上往下查，命中一条就处理一条，改完重按一次「测试连接」：

| 检查点 | 怎么查 | 怎么处理 |
| --- | --- | --- |
| 地址抄全了吗 | 对比桌面端「复制远程地址」的结果 | `192.168.1.100:18900` 这种格式原样粘贴，端口不能少 |
| 手机和电脑同一网络吗 | 看手机连的 Wi-Fi 是否与电脑相同 | 换到同一个 Wi-Fi；路由器开了访客网络或 AP 隔离时，两台设备互相看不见，要关掉这类选项 |
| 桌面端还开着吗 | 去电脑上看一眼 | 桌面端没跑就启动它，重新复制一次远程地址 |
| 电脑 IP 变了吗 | 路由器重启、网络重连后 IP 常会变 | 重新复制远程地址再填，旧地址作废 |
| 电脑端放行外部连接了吗 | 桌面端的远程访问 / 外部连接开关 | 有用户反馈需要在电脑端打开「外部连接」才能被手机连上（来自社区用户的使用反馈，各版本开关名称与位置以你的界面为准） |
| 安全软件拦了吗 | 连接时电脑右下角是否弹过拦截提示 | 弹了就放行；没弹也可以临时允许该端口的入站连接再试 |

**先做一步二分**：用手机浏览器直接打开同一个远程地址（官方支持 Web 访问，开启远程访问后浏览器可直接打开，格式如 `http://192.168.1.100:18900`）。浏览器能打开，说明网络是通的，问题出在手机 App 这一侧；浏览器也打不开，问题在电脑或网络那几项——回头重查上表。

## 二、连上了，但它一直不回话

「测试连接」通过只说明手机够到了电脑，不代表电脑上的助手能干活。常见两种：

1. **桌面端没配好大模型**。有用户反馈：装完软件没有配置 LLM 端点就连接，手机端用起来没反应（来自社区论坛的用户反馈）。处理：到电脑桌面端把大模型 API Key 配好，先在电脑上确认能正常问答，再回手机试。
2. **电脑那边正忙或卡住**。它在执行长任务时回复会慢；如果长时间转圈，去电脑上看一眼状态，把卡住的任务停掉再发新的。

## 三、还是不行时

- 电脑重启、网络变动后，回到 [连接桌面端服务器教程.md](连接桌面端服务器教程.md) 把远程地址重新复制一遍——这是最常见的原因；
- 多台手机连同一台电脑时，确认每台都填的当前有效地址，名称备注（如 `家里`）别抄错以为连的是另一台；
- 官方仓库 [github.com/openakita/openakita](https://github.com/openakita/openakita) 的 Issues 里可以搜同类问题，按你的版本号过滤着看。
