# 拍照与录视频教程

## 一、先建立一个概念：特效是实时的

你不需要「先拍完再修图」。defekt 的所有特效都在**取景阶段就渲染出来**——你看着屏幕里的画面已经是加过特效的样子，按下快门或录制键，得到的就是所见即所得的成品。这决定了它的操作顺序：**先选特效、边看边调，再拍**，而不是拍完再找功能。

第一次用建议先拿一张静态照片练手，比直接录视频好控制。

## 二、拍一张带特效的照片

1. 打开应用，进入取景界面；
2. 点界面下方的**特效按钮**（图标位置见界面上圈出的标识），会弹出一整排可选特效；
3. 上下滑动或点选一个特效，**画面立刻变成这个特效的样子**——静态特效是这样，动态特效还会动起来；
4. 选定特效后，点旁边的**色调按钮**，换一组配色，让画面整体偏冷、偏暖或偏艳；
5. 想看「原图长什么样」，点**顶部的手势按钮**，画面切回未加特效的初始状态；再点一次又回到特效状态——**对比用**，不是撤销；
6. 按快门，照片保存到相册。

## 三、录一段带特效的视频

操作和拍照几乎一样，区别只在最后一步：

1. 选好特效与色调后，切换到**录像模式**；
2. 按录制键开始；
3. **录制过程中可以继续滑动换特效**——新特效即时生效，一段视频里能出现多次效果变化；
4. 再按一次结束录制，视频自动保存。

官方注意事项里反复强调的几条，直接决定成片质量：

- **尽量保持手机静止**。特效本身会大幅扭曲画面，你手再晃，成品会糊成一团看不清主体；
- **录制时调整效果**。中途换、中途调参数是这个应用的设计用法，不是 bug；
- **可以把多种特效组合起来用**（叠加、遮罩、参数微调），进阶玩法见 [特效参数与音频反应玩法.md](特效参数与音频反应玩法.md)。

## 四、拍完之后的几件事

- **成片在哪**：拍完的照片和视频会存进系统相册，和你平时拍的东西在一起，用相册就能看、能分享；
- **不满意就重拍**：拍摄时你看到什么就得到什么，录制中途换特效的自由度也只在录制过程中有效——所以录制前先把特效和色调选到大致满意，中途微调，比整段录完再想改省事；
- **换前后摄像头**：自拍和拍外景切换，界面上有对应的切换按钮，用法和系统相机一致。

## 五、常见操作卡点

| 卡点 | 怎么处理 |
| --- | --- |
| 打不开相机 / 一片黑 | 多半是权限没给，去系统设置里把相机权限打开，见 [常见问题与闪退排查.md](常见问题与闪退排查.md) |
| 手势按钮点不动 | 确认当前不是在录制中——录制时的调整入口在特效面板，不在顶部手势按钮 |
| 录出来很卡 | 关掉后台其他占相机的应用；高帧率设置在部分机型上不稳，见排查篇 |
| 找不到从相册导入 | 首屏除拍摄外也有从相册选照片/视频的入口，选中后同样能加特效 |

还没装的话，先看 [下载与安装教程.md](下载与安装教程.md)。
