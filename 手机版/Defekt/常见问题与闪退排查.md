## 一、先定位问题出在哪一层

按「装 → 权限 → 运行 → 成片」的顺序找，绝大多数问题落在其中一层：

| 现象 | 大概率出在哪 | 直接跳到 |
| --- | --- | --- |
| 装不上、装的时候报错 | 安装包 / 系统版本 | 第二节 |
| 打开就闪退、进不去 | 版本兼容 / 数据损坏 | 第三节 |
| 取景一片黑、提示无相机 | 权限 / 相机被占用 | 第四节 |
| 画面卡、录出来掉帧 | 性能 / 设置 | 第五节 |
| 录完找不到文件、没声音 | 保存 / 麦克风权限 | 第六节 |

## 二、安装相关

**提示「禁止安装未知来源应用」**：这不是报错，是安卓的常规拦截。跟着弹窗进设置打开「允许本次安装」即可，装完可以关掉。入口各品牌略有差异（一般在**设置 → 安全/隐私 → 安装未知应用**）。

**提示「解析包时出错」「应用未安装」**：

1. 确认 APK 没下完——文件名带 `.part` 或体积明显小于 10.25M，都是没下完，重新下；
2. 想确认文件完整，按 [下载与安装教程.md](下载与安装教程.md) 里的 MD5 对一遍；
3. 手机剩余空间不足也会装不上，先清理出几百 MB；
4. 提示「与已有应用签名不一致」说明手机里装过同包名的另一个渠道包，先卸载旧的再装。

**系统版本太低**：这份包要求安卓 5.2 以上，低于要求会装不上或装完立刻闪退。版本在**设置 → 关于手机**里看。

## 三、打开就闪退 / 反复崩溃

按命中概率从高到低试：

1. **清缓存**：**设置 → 应用 → defekt → 存储 → 清除缓存**，重开。缓存清掉不影响你的成片（成片在相册里）；
2. **清数据重置**：清缓存没用就**清除数据**——会把应用恢复到初次安装状态（权限要重新给一遍），同样不删相册里的照片视频；
3. **降帧率/画质**：部分机型在高帧率设置下会崩，先把录制相关设置调到默认或更低档再试（详见第五节）；
4. **重装**：还崩就卸载，重新装一遍网盘里的包（走 [下载与安装教程.md](下载与安装教程.md)）；
5. **检查是不是只有某条素材崩**：如果每次都卡在同一条视频/照片上，是那条素材触发的问题，换一条能录说明应用本身没事。

**系统本身很久没重启**也会让相机类应用异常——排查前先重启一次手机，能省掉一半无效尝试。

## 四、取景黑屏 / 提示无法访问相机

Android 只允许一个应用同时占用相机，黑屏最常见的原因是**权限没给**或**相机被别的应用占着**：

1. 去**设置 → 应用 → defekt → 权限**，确认**相机**是允许状态；录视频还要**麦克风**、保存到相册要**存储/媒体**；
2. 把最近任务列表里的其他相机应用、视频通话、直播类应用全部划掉，只留 defekt；
3. 重启手机后再开一次；
4. 安卓 12 及以上还有全局相机开关（**设置 → 隐私 → 相机访问**），它是关的话所有相机应用都会黑屏；
5. 以上都正常仍然黑屏，用系统自带相机拍一张验证硬件——自带相机也黑，那是手机相机的问题，不是这个应用。

## 五、卡顿、掉帧、发热

- **先减负**：录制前清后台，尤其是剪辑、直播、其他相机应用；
- **降低录制设置**：分辨率和帧率往低调一档，实时渲染的压力会明显下降；出问题先用默认档，能稳定录再往上调；
- **别三个重效果同时拉满**：动态特效 + 强参数 + 音频反应全开，中低端机扛不住，见 [特效参数与音频反应玩法.md](特效参数与音频反应玩法.md) 的叠加建议；
- **边充边录会更热**：发热触发降频后画面会突然变卡，属正常现象，降温后再录。

## 六、成片与声音问题

**录完在相册找不到**：

1. 下拉通知栏看录制过程是否被中断（内存不足会中途写盘失败）；
2. 手机剩余存储空间不足时保存会失败，先清出几百 MB；
3. 部分机型需要给足**媒体文件写入**权限，去权限页确认。

**音频反应没反应 / 录进去的声音不对**：

1. 麦克风权限没给——去权限页打开；
2. 环境太安静或灵敏度太低，在音频设置里调灵敏度；
3. 拍摄时手机捂住了麦克风开孔（横握时容易发生），换个握法再试。

**导入相册里的视频失败**：先确认那条视频手机自带播放器能正常播放；损坏或特殊编码的文件导入会失败，换一条测试。

## 七、还没解决怎么办

按「清缓存 → 清数据 → 重启 → 重装」走完仍复现的，记下两件事再找渠道反馈：**手机型号 + 系统版本**，以及**在第几步、做什么操作时出的问题**（截图更好）。重装用的安装包从 [下载与安装教程.md](下载与安装教程.md) 的网盘入口重新拿，避免装到损坏的文件。
