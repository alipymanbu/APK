## 一、这一篇解决什么问题

基础操作（换特效、按快门）五分钟就会，见 [拍照与录视频教程.md](拍照与录视频教程.md)。但 defekt 真正的可玩空间在特效面板深处：**每个特效都带一组自己的参数**，加起来有几十个调节项；再加上遮罩、声音驱动、叠加，同一个特效能调出差别很大的成片。这一篇按「先参数、再遮罩、再声音、最后叠加」的顺序讲。

## 二、调参数：同一个特效的两种长相

在选中某个特效后，面板里会出现属于**这个特效专属**的调节项——不同特效给的参数不一样，这本身就是它的一个特点（不是所有特效都给同一套滑杆）。操作方式：

1. 选中一个特效；
2. 在特效面板里找到参数滑杆/开关，**边拖边看取景画面**——所有调整都是实时预览的；
3. 录制过程中同样可以继续拖，参数变化会一并录进视频。

实用做法：

- **先把参数归到默认，再往两边试**。不知道某个滑杆管什么时，左右拖到头看画面变化，比读说明快；
- **动态特效优先调「速度/强度」类参数**。扭曲、尘化、回声残留这类效果，强度拉满很容易把主体糊掉，中低强度反而更耐看；
- 静态照片可以放心把参数往极端调，动态视频要留余量——画面一直在动，极端参数会让观感更乱。

## 三、形状遮罩：只让画面的一部分出特效

所有特效都可以套一层**形状遮罩**——常见的心形、星形、钻石等二十来种形状，效果只作用在形状范围内（也可以反着来：形状外有特效、形状内正常）。

- **正用**：人像居中、只让背景扭曲，主体保持清晰；
- **反用**：只让脸部/物件出特效，周围正常——具体哪个方向叫「正」以界面上的反转开关为准，切一下就知道；
- 形状可以自由缩放、移动，套在取景框里的什么位置由你定。

遮罩是「特效太抢戏」时最好用的刹车：整体效果太重，就把它圈到局部去。

## 四、音频反应：让画面跟着声音动

开启**音频反应**后，画面会随你对着麦克风说话、唱歌或播放的音乐节奏变化——本质是把声音音量/节奏映射成特效的强度。

怎么用出效果：

1. 拍摄前先开音频反应开关（需要麦克风权限，没给的话按系统提示去开，见 [常见问题与闪退排查.md](常见问题与闪退排查.md)）；
2. **环境要安静**：周围嘈杂时画面会一直被背景噪声推着抖，主体动作反而看不出来；
3. 想做音乐视频，先外放你想用的曲子再录制（或导入带音乐的视频），让特效踩着节拍走；
4. 灵敏度不合适时（一点声音就剧烈反应、或喊话都没反应），在音频相关设置里调灵敏度。

一个提醒：音频反应 + 动态特效 + 手持晃动三样叠加，成片很容易过载。**一次只开一个变量**录几条对比，比全开更容易找到想要的效果。

## 五、多特效叠加

特效可以组合使用——在已经有一层效果的画面上再叠一层。叠加的收益和风险都来自同一件事：**画面信息量翻倍**。

- 叠加时保持**一个主效、一个辅效**：主效决定风格（如扭曲），辅效只做点缀（如轻微噪点/回声）；
- 两层都用强参数基本必然糊，第二层往弱里调；
- 录制中途在两组叠加方案之间切换，一条视频里做出段落变化。

## 六、效果预期管理

几条实践结论，帮你少走弯路：

| 场景 | 建议 |
| --- | --- |
| 手持拍 | 优先弱参数；手机越稳，特效越能「借力」而不是添乱 |
| 拍运动主体 | 特效强度调低，让动作本身当主角 |
| 静物/平面 | 参数可以拉满，静态画面扛得住极端效果 |
| 录制中调参 | 每次调整之间留一两秒，观众才看得出变化是故意的 |
| 高帧率设置 | 部分机型上高帧率会卡甚至闪退，出问题先降帧率，见排查篇 |

成片不理想先别急着怪参数——按 [拍照与录视频教程.md](拍照与录视频教程.md) 里的注意事项，「手机保持静止」这一条对最终观感的影响比任何滑杆都大。
