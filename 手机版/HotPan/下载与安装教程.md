## 一、这是什么应用

HotPan 是一款安卓手机端的云储存（网盘）应用，用邮箱注册账号后，可以把文档、视频、音乐、图片等文件传到云端，换设备登录同一账号还能继续访问。它的安装包很小（6 MB 左右），支持简体中文界面，适合想在手机上备份资料、和别人共享文件的人。

## 二、安装包信息（下载前先核对）

你从网上各处拿到的「HotPan」安装包信息应当一致，下载后可用文件的 MD5 校验值核对是否为同一份：

| 项目 | 数值 |
| --- | --- |
| 应用名称 | HotPan |
| 版本号 | 1.0 |
| 包名 | `top.hotpe.pan.i20604` |
| 安装包大小 | 6.22M |
| MD5 | `7118739EFDECDB515E160F5FD5F34770` |
| 系统要求 | 安卓 5.2 及以上 |
| 界面语言 | 简体中文 |

注意：版本号会随官方更新变化，以你实际下载到的安装包为准；核对 MD5 时用大小写不敏感比对即可。

## 三、从网盘获取安装包

1. 打开 [HotPan 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b607b9a52fbe)；
2. 在网盘页面里找到该应用的安装包文件，转存到你自己的网盘，或直接下载到手机；
3. 下载完成后按第四节的步骤安装。

若你更想从其他渠道获取，也可以自行搜索，但拿到包后建议先按第二节核对包名与 MD5，避免装到仿冒的同名应用。

## 四、安装步骤

1. 用手机浏览器或文件管理器打开下载好的 `.apk` 文件；
2. 系统若弹出「禁止安装来自此来源的应用」，是安卓对未知来源安装的默认拦截 —— 点进设置里允许本次安装（不同品牌手机入口名称略有差异，常见在「安装未知应用」或「外部来源应用安装」）；
3. 点「安装」，等待进度条走完；
4. 装完可直接点「打开」，首次进入会先让你同意用户协议与隐私政策（见 [注册登录账号教程.md](注册登录账号教程.md)）。

安装失败或装上打不开的处理办法见 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 五、安装后的第一次检查

- 在桌面或应用列表里确认出现了 HotPan 图标，点开能进入登录页即为安装成功；
- 若你的手机自带「应用市场」，其中未必收录此应用，应用内也没有强制更新弹窗 —— 是否更新以你后续实际拿到的安装包版本为准。
