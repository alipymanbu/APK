## 一、先对预期有个数

AI 生成是概率性结果，同样的输入跑两次都不一样。应用商店评论区最常见的两条抱怨，正好帮你校准预期：

- **成片偏短**：这类工具产出的是几秒量级的短片，不是完整视频，想要长片得靠多段拼接；
- **相似度不稳定**：生成结果与原图「像不像」，每次都不同，一次不像不代表工具坏了。

所以正确姿势是：把每次生成当抽卡，先小成本试方向，方向对了再投入积分。

## 二、选照片：效果的一半在这

| 适合当素材 | 不适合当素材 |
| --- | --- |
| 单人、正面照 | 多人合影（人物特征容易串） |
| 五官清晰、无遮挡 | 侧脸、低头、手挡脸 |
| 光线均匀（白天窗边最佳） | 强逆光、夜景欠曝 |
| 背景简洁 | 背景杂乱抢戏 |
| 分辨率正常 | 模糊图、截图、翻拍屏幕 |

一张干净的正脸照，比任何提示词技巧都管用。

## 三、模板和提示词怎么分工

- **想稳定出片** → 用模板。模板把风格和动法都定死了，你只需要给照片；
- **想要没人有过的效果** → 写提示词。自由度高，但要多试几次；
- 两者不是二选一：先用模板跑通流程（流程见 [照片变视频完整流程.md](照片变视频完整流程.md)），攒够对结果的感觉后再切提示词。

## 四、提示词写法：一句话套一个公式

按「主体 + 动作 + 环境 + 风格」组织：

```text
一位穿深色西装的男士在落地窗办公室里缓缓抬头，窗外是黄昏城市，电影感镜头
```

四条经验：

1. **具体**：「霓虹灯下的雨夜街道」比「好看的背景」出片概率高得多；
2. **一次只改一个变量**：换风格就只换风格词，别一句话里同时改动作、场景、风格——改坏了不知道是谁的问题；
3. **别贪长**：一两句话足够，堆一堆形容词反而让画面失去重点；
4. **中英文都试试**：同样的意思换种语言写，结果可能不同，哪个出片用哪个。

## 五、生成结果先过一遍检查清单

AI 视频有一些通用败因。生成完先花十秒对照检查，再决定要不要花积分重生成：

| 检查点 | 常见问题 | 对策 |
| --- | --- | --- |
| 脸与手 | 五官漂移、手指粘连 | 换更清晰的正面照重试 |
| 边缘 | 轮廓融化、背景渗色 | 换背景简洁的照片 |
| 主体一致性 | 越跑越不像原图 | 减少提示词里的动作量 |
| 背景异物 | 凭空多出的物件 | 提示词里把场景元素写明确 |
| 画面文字 | 字是乱码 | 别让 AI 生成文字，后期再叠加 |

## 六、控制积分的试错节奏

- 第一轮：默认设置 + 模板，验证这张照片适不适合做素材；
- 第二轮：锁定一个模板，用提示词微调风格；
- 每轮之间回看结果再决定下一步，别连点——每次生成都在扣积分，控制节奏的方法见 [积分与订阅说明.md](积分与订阅说明.md)。

## 七、成片之后还要一道后期

AI 出的短片通常没有配乐和字幕，直接发略显单薄。常规做法是把它导进任意剪辑工具（剪映、CapCut 都行）做三件事：配乐、加字幕、把多段短片拼成一条完整内容。
