# 点击任务怎么设置与启动

> 从确认权限到光点落位，讲清发起一次点击任务的完整步骤，以及任务记录和统计在哪里看。

FingerLike 跑一次任务的流程很短：设次数 → 开始 → 拖光点选位置 → 确认。难点不在步骤，而在「无障碍权限没开」和「光点没落到你想点的位置」这两处。本篇按顺序把每一步说清。

## 一、开始之前的两个前提

1. **无障碍权限已开**：这是最容易漏掉的前提。权限没开时界面照常能用，但你确认位置之后不会发生任何点击。检查与恢复见 [无障碍权限掉了怎么恢复.md](无障碍权限掉了怎么恢复.md)。
2. **模式已选好**：普通模式还是仿生模式，先定下来再开始。两种模式的差别见 [普通模式和仿生模式怎么选.md](普通模式和仿生模式怎么选.md)。

## 二、发起一次任务

1. **填点击次数**：在主界面输入这次要点的次数。次数决定任务什么时候自己停 —— 点满设定的次数就结束。
2. **点「开始任务」**：点下去之后，界面上会出现一个用来定位的光点。
3. **把光点拖到目标位置**：这个光点就是你希望被点的地方。先切到要操作的应用、把目标按钮显示出来，再拖光点，会准得多。
4. **点「确认」**：确认之后自动点击开始跑，此时可以放开手机，让任务自己走完。

哪一步该做什么，对照着看更清楚：

| 你要做的事 | 该在哪一步之前完成 |
| --- | --- |
| 切到目标应用、把目标按钮调出来 | 拖动光点之前 |
| 决定这次点多少次 | 点「开始任务」之前 |
| 决定用普通还是仿生 | 填写次数之前 |

## 三、任务记录和统计

官方在功能特点里列了一项「点击任务记录和统计」，跑过的任务会留下记录，可以回看做过什么。0.0.4 这一版的更新日志里，功能部分还记了两项：

- **耗时预测**：按你设的参数估算这次任务大概要跑多久。次数设得大时，先看这个数再决定要不要现在开始。
- **每日格言**：同一批更新里一起加的功能，与点击任务本身无关。

记录能存多少条、按什么维度统计，官方没有给出固定说明，以你手上这一版的界面为准。

## 四、任务怎么停

- **让它自己结束**：点满设定的次数，任务自动结束，这是最常用的收尾方式。
- **中途取消**：官方说明给出的取消快捷键只针对**桌面端** —— Windows 上是 `Ctrl+Shift+J`，macOS 上是 `Control+Shift+J`；**安卓端的停止方式官方没有写明**，需要中断时以你这一版界面里实际提供的停止入口为准。

## 五、桌面版顺手一提

同一个项目还有 Windows 和 macOS 版，桌面版的流程是「选模式 → 设次数 → 点开始 → 倒计时结束前把鼠标移到目标位置」，和安卓版「拖光点再确认」的写法不一样。网盘里这份是安卓 APK，本篇第二、三节讲的只对安卓版成立。
