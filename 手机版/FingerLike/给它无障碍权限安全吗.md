# 给它无障碍权限安全吗

> 开启前你会看到一条「可以读取屏幕上所有内容」的系统警告。本篇讲这条权限到底能做什么、怎么判断手上的安装包靠不靠得住、以及怎么把风险收窄。

连点器必须拿到系统的无障碍权限，才能在别的应用上模拟点击，而开启时系统会明确警告「可以读取屏幕上的所有内容」。本篇不劝开也不劝关，只讲清这条权限能看到什么、怎么判断手上这份包靠不靠得住、以及用的时候怎么把风险收窄。

## 一、那条警告在说什么

开启时安卓给的原始提示大意是「此应用可以读取屏幕上的所有文字，包括个人数据和密码」。这不是吓唬人：无障碍（辅助功能）这条通道在设计上就是为了**代替使用者看屏幕、操作屏幕**，所以它天然能看到当前界面上的控件与文字，也能代替你点击。

给 FingerLike 开这个权限，是「连点」这件事本身的技术前提 —— 不走这条通道，应用无法在别的应用上面模拟点击。官方也把「无需管理员权限」列在自己的功能特点里，说的就是它不需要 root 这类更深层的东西。

## 二、风险出在哪

| 环节 | 说明 |
| --- | --- |
| 看到屏幕内容 | 权限生效期间，界面上的文字与控件对这个应用是可见的，包括你在输入框里打的内容 |
| 代替你点击 | 权限本身就包含模拟点击，能操作别的应用 |
| 安装包被换过 | 真正容易出事的，是包名对不上、但名字很像的「同款」，权限一样要，背后却不是同一份代码 |

一句话概括：**风险大小很大程度上取决于你装的是哪个包，而不是这条权限的存在本身。** 权限是这类工具绕不开的，来源是你可以选的。

## 三、怎么判断手上这份靠不靠得住

1. **认包名**：这款是 `com.shichen437.fingerlike`。对不上就不是同一款。
2. **认官方渠道**：源码与各平台发布包在 `https://gitee.com/shichen437/FingerLike`，用的是 MIT 开源许可 —— 代码公开，谁都可以去看它到底用了哪些权限。
3. **核对安装包本身**：体积 24.42 MB、MD5 为 `54FFDB7670A47EC843B96A689A92136D`，对照表见 [下载与安装教程.md](下载与安装教程.md) 第一节。
4. **别拿来路不明的「同款」**：名字相近的点击类应用很多，认包名、认开发者比认名字可靠。

## 四、用的时候把风险收窄

- **不在权限生效时输入敏感信息**：支付密码、银行卡号、验证码这几类输入，先结束任务、或在系统设置里临时关掉无障碍权限再做。
- **用完就关**：官方明确说明安卓端关闭应用后需要重新开启无障碍权限。把这个「每次都要重开」的限制反过来当保护用 —— 任务做完就结束应用，权限随之收回，不用一直挂着。
- **定期扫一遍已授权列表**：进「设置 → 无障碍 → 已安装的服务」，把不再使用的应用的无障碍权限关掉。

## 五、这和「会不会被平台判违规」是两件事

上面讲的是设备与隐私层面的风险。「用连点器会不会被平台判定违规」是账号层面的另一回事，取决于各平台自己的规则，见 [普通模式和仿生模式怎么选.md](普通模式和仿生模式怎么选.md) 第三节。
