# 无障碍权限掉了怎么恢复

> 安卓端关掉应用后无障碍权限会失效，这是 FingerLike「明明装了却点不动」最常见的原因。本篇讲怎么判断、怎么恢复、怎么少掉几次。

无障碍权限是 FingerLike 在安卓上能代替你点击的前提，它有两个烦人但正常的特性：关闭应用后会失效，被系统管后台时还可能自己关掉。本篇按「先判断、再恢复、少掉几次」的顺序讲，最后给一张各家系统设置入口的对照表。

## 一、先确认是不是权限掉了

这几条里中任意一条，基本就是无障碍权限失效了：

- 应用能正常打开、能填次数、能拖出光点，确认之后**屏幕上没有任何点击发生**；
- 关过应用（包括用了「结束运行 / 强行停止」，或系统自己把它清掉）之后再打开，就变成上面那种状态；
- 手机重启过，第一次打开 FingerLike 点击就没反应。

判断办法很直接：进「设置 → 无障碍 → 已安装的服务」，看 **FingerLike** 那一项是开还是关。显示关闭，基本就能确定是它。

## 二、为什么连点器一定要这个权限

FingerLike 要在别的应用上面代替你点屏幕，用的是系统给「无障碍 / 辅助功能」留的那条通道。这条通道的定位就是**代替用户操作界面**，所以它不需要 root、也不需要管理员权限 —— 官方把「无需管理员权限」写在自己的功能特点里。

也正因为这条通道权限很大，安卓不允许应用自己给自己开，必须由你手动去系统设置里点一次。所以它「关掉应用后要重开」不是应用自身的问题，而是这类权限的常规行为。

## 三、恢复步骤

路径和第一次开权限完全一样，照着走一遍即可：

1. 打开「设置 → 无障碍」（部分系统叫「辅助功能」，小米系在「更多设置 → 无障碍」）；
2. 进「已安装的服务 / 已下载的应用」，找到 **FingerLike**；
3. 把开关打开，弹窗里选**允许**；
4. 回到应用，确认状态已恢复，再重新发起任务。

各系统入口叫法不一样，对照这张表找：

| 系统 | 大致路径 |
| --- | --- |
| 原生 Android / 类原生 | 设置 → 无障碍 → 已下载的应用 |
| 小米 / 红米（MIUI、HyperOS） | 设置 → 更多设置 → 无障碍 → 已下载的应用 |
| 华为 / 荣耀 | 设置 → 辅助功能 → 无障碍 → 已安装的服务 |
| OPPO / 一加 / realme | 设置 → 系统设置 → 无障碍 → 已安装的服务 |
| vivo / iQOO | 设置 → 快捷与辅助 → 无障碍 → 已安装的服务 |
| 三星 | 设置 → 辅助功能 → 已安装的应用程序 |

菜单名会随系统版本变化，找不到时直接在设置里搜「无 障碍」或「辅助功能」。

第一步的完整上下文（装包、首次授权、最小验证）见 [下载与安装教程.md](下载与安装教程.md)。

## 四、开完过一会又自己关了

上面第三节解决的只是「已经关掉」。如果权限是**开了几分钟、锁屏或待机之后又自己变回关闭**，那通常不是应用本身的问题，而是系统在管后台。按现象对：

| 现象 | 多半是这个原因 | 处理 |
| --- | --- | --- |
| 开完没多久就自己关 | 电池优化停掉了后台服务 | 「设置 → 应用 → FingerLike → 电池」改成**不受限制 / 无限制**；小米系再到开发者选项里关掉「MIUI 优化」 |
| 锁屏、待机一段时间后失效 | 应用被系统列进了休眠名单 | 在「特殊应用权限 → 后台活动管理」里把它移出「应用休眠 / 深度休眠」 |
| 系统更新后要重新开 | 系统更新会重置这类权限 | 按第三节重新开一次 |
| 跟别的点击类应用一起开就失效 | 多个无障碍服务互相冲突 | 一次只保留一个点击类应用的无障碍权限，其余关掉 |

这几条不是某一款应用独有的毛病，截至 2026-09，各家安卓点击类工具的说明基本一致。菜单名会随系统版本变化，找不到时直接在设置里搜「电池优化」「后台」。

如果上面的设置都做过、开关还是反复自动关，依次试：**关掉权限再打开 → 重启手机 → 关掉权限后卸载重装**。重装前先把你的使用习惯记下来，卸载会一并清掉本机设置。

## 五、怎么少掉几次

- **别用「结束运行 / 强行停止」关它**：官方明确写了，安卓端关闭应用后需要重新开启无障碍权限。从最近任务里划掉、在应用详情页点强行停止，都会让权限失效。
- **把电池优化设为不受限制**：在「设置 → 应用 → FingerLike → 电池」里选不受限制 / 允许后台活动，减少系统在后台把它清掉的概率。
- **别用第三方「一键清理 / 加速」工具清后台**：这类工具通常会连无障碍服务一起停掉。
- **重启手机之后，先开权限再发起任务**：重启后无障碍服务需要重新进入已开启状态，顺序别弄反。

权限确认是开着的，却依然点不动，那就不是这一项的问题了。接着排除 [常见问题与排查.md](常见问题与排查.md) 第二节剩下的三条 —— 多数是光点落点偏了，或设定的次数已经用完。
