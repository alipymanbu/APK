几点补充：

- **官方渠道在哪**：源码与各平台发布包在 `https://gitee.com/shichen437/FingerLike`，版本更新记录是同仓库的 `CHANGELOG.md`。想确认手上这份是不是同一款，认包名 `com.shichen437.fingerlike` 最快。
- **别拿错平台的包**：三个平台的产物都叫 FingerLike，但扩展名不同 —— 安卓是 `.apk`，Windows 是 `.exe`，macOS 是 `.dmg`。网盘里这份是 `.apk`，只能装到安卓手机上；想在电脑上运行安卓版，得靠模拟器一类的环境。三个平台的完整对照见 [安卓版和电脑版有什么区别.md](安卓版和电脑版有什么区别.md)。
- **不涉及账号**：官方仓库的说明里没有提到注册、登录或付费项，装完直接就能用，不需要先注册。
- **MD5 怎么用**：下载完用文件管理器看一下文件详情，或用任意校验工具算一次 MD5，与上表一致说明传输过程没有损坏；体积明显小于 24.42 MB 说明没下完，重下一次。

## 二、装之前先确认两件事

1. **官方仓库没有单独标注安卓最低系统版本**，能不能装以你手机实际安装的结果为准；解析失败一类的报错按下表处理。
2. **原包留着别删**：安装包只有 24.42 MB，换机、回退版本或重装都要用到它。

## 三、安装步骤

1. 把 APK 下载到手机。在电脑上下载的话，用数据线或任意传输工具拷进手机存储都可以。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统常把这一项收在「安全」「隐私」「更多安全设置」下面。
3. **点开 APK 完成安装**：系统提示「应用未经过安全检测」时选继续安装，这是非应用商店渠道安装包的常规提示。
4. **装完先别急着点**：下一节的无障碍权限没开，点下去不会有任何反应。

安装被拦下时，不同提示对应的情况不一样，按这张表对：

| 系统提示 | 原因 | 处理 |
| --- | --- | --- |
| 解析包错误 / 解析包时出现问题 | 下载不完整或文件损坏 | 重新下载，下完核对体积是否为 24.42 MB、MD5 是否与上表一致 |
| 应用未安装 | 手机上已装了同包名的版本 | 先卸载旧版再装；卸载会一并清掉旧版的设置 |
| 已阻止安装 / 安全提示 | 未知来源开关没打开 | 回到第 2 步，给打开安装包的那个应用开权限 |

## 四、首次启动：先开无障碍权限

FingerLike 靠系统的无障碍能力去模拟点击，这一步不做完，界面能用但点了不会有反应。

1. 打开 FingerLike，第一次进来会提示需要开启无障碍权限。
2. 进「设置 → 无障碍」（部分系统叫「辅助功能」，小米系在「更多设置 → 无障碍」）→「已安装的服务 / 已下载的应用」，在列表里找到 **FingerLike**。
3. 点进去把开关打开，系统弹出「允许 FingerLike 观察你的操作」之类的提示时选**允许**。
4. 回到应用，看到权限状态显示为已开启即可。

⚠️ **一条官方注意事项**：安卓端**关闭应用后需要重新开启无障碍权限**。所以日常别用「结束运行 / 强行停止」去关它 —— 下次要用时得回设置里再开一次。权限掉了的具体表现与恢复办法见 [无障碍权限掉了怎么恢复.md](无障碍权限掉了怎么恢复.md)。

## 五、装完做一次最小验证

用最小的成本确认「装好了、权限也对」：

1. 打开 FingerLike，把点击次数填一个小数字，比如 5；
2. 点「开始任务」，界面上会出现一个可以用来定位的光点；
3. 把光点拖到屏幕上一处空白位置，点「确认」；
4. 看屏幕上是否被点了 5 次。

第 4 步没反应，先回上一节确认无障碍权限是否仍开着；如果权限是开着的却还是不点，见 [常见问题与排查.md](常见问题与排查.md)。
