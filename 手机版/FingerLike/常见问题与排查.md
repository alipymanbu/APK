## 一、装不上

按系统给出的提示对号入座：

| 现象 | 多半是 | 怎么处理 |
| --- | --- | --- |
| 解析包错误 / 解析包时出现问题 | 下载不完整或文件损坏 | 重新下载，核对体积是否为 24.42 MB、MD5 是否为 `54FFDB7670A47EC843B96A689A92136D` |
| 应用未安装 | 已装同包名的版本，或与旧版签名冲突 | 先卸载旧版再装，卸载会清掉旧版设置 |
| 已阻止安装 / 安全提示 | 未知来源开关没开 | 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里给打开安装包的应用开权限 |
| 提示不兼容 / 无法安装 | 系统版本或应用商店策略限制 | 换一部设备或换安装渠道；本版官方仓库未标注安卓最低版本，无法凭提示判断具体门槛 |

需要重下安装包时，入口是 [FingerLike 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8e5a3b9d233f)。完整安装步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 二、装了、界面能开、点了没反应

按可能性从高到低排：

1. **无障碍权限失效**——这是最常见的原因。界面能用、光点能拖，确认后却什么都没发生，基本就是它。恢复办法见 [无障碍权限掉了怎么恢复.md](无障碍权限掉了怎么恢复.md)。
2. **光点的落点不是你以为的地方**——拖动光点之后又切了应用、滑了屏幕，落点就偏了。重新发起任务，先把目标页面摆好再拖。
3. **次数已经用完**——任务点满设定次数就结束，表现和「被停掉」一样。把次数调大再试一次。
4. **目标区域压根不接受点击**——有些界面元素本身不可点，或者被系统弹窗挡住了。换一处空白区域验证一次，排除是应用问题还是目标问题。

## 三、光点选不准

- **先摆好页面再拖光点**：拖完再切应用、再滚动，坐标就跑了。
- **目标太小时先放大**：把目标按钮放大或用放大手势，落点更好对。
- **改过显示大小或字体大小**：这类工具是按屏幕坐标定位的，系统把「显示大小」「字体大小」调大之后，同一个坐标落到的位置就变了。把显示大小改回默认，再重新拖一次光点。
- **仿生模式本来就不精确**：它在目标附近带随机偏移，这是模式设计，不是选点失灵。要求每次都点准同一个像素位置的，用普通模式。两种模式的差别见 [普通模式和仿生模式怎么选.md](普通模式和仿生模式怎么选.md)。

## 四、同名应用怎么认

网上搜「fingerlike 连点器」会出来好几种点击类应用，名字相近但不是一个东西。用这三条区分：

- **认包名**：这款是 `com.shichen437.fingerlike`。对不上，就不是同一款。
- **认开发者与仓库**：开发者是 shichen437，源码与发布包在 `https://gitee.com/shichen437/FingerLike`。
- **认平台**：同一个 FingerLike 项目还出 Windows（`.exe`）和 macOS（`.dmg`）版，网盘里这份是安卓 APK。桌面版和安卓版的界面、操作流程都不一样，看到「鼠标连点器」「快捷键 Ctrl+Shift+J」这类描述，那是桌面版的内容。两个平台的对照见 [安卓版和电脑版有什么区别.md](安卓版和电脑版有什么区别.md)。

确认了是同款，还想弄清这条无障碍权限的安全边界，见 [给它无障碍权限安全吗.md](给它无障碍权限安全吗.md)。

## 五、版本号对不上

网上第三方页面写的版本往往比网盘里这份新，或者标成 `v0.0.4` 这种带前缀的写法。**判断标准只有一条：网盘里那份安装包的实际版本。** 本文档统一按 0.0.4、包名 `com.shichen437.fingerlike`、体积 24.42 MB 来写。

想确认自己手上装的是哪一版，去「设置 → 应用 → FingerLike → 应用信息」里看版本号，与上面对得上就没问题。要换回这个版本，按 [下载与安装教程.md](下载与安装教程.md) 第一节的入口重新取一次包。

## 六、任务跑起来之后的问题

- **运行期间手动滑屏、点击不响应**：有用户反馈，任务跑起来之后再去手动操作，屏幕可能认不出你的手势，因为点击频率高时系统分辨不过来。需要操作就先结束任务，处理完再重新发起。
- **手机发热、掉电快、屏幕一直亮着**：高频点击本来就会持续占用屏幕与处理器，次数设得大时更明显。开始前先看一眼耗时预测，别让它长时间空跑。
- **点着点着突然不点了**：先回第二节第 1 条查无障碍权限，多半是它掉了，而不是任务本身出错。
