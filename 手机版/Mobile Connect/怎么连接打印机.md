## 一、连接前先核对四条

1. 打印机已通电，屏幕上没有报错或卡纸提示；
2. 打印机已经接入 Wi-Fi（或者准备借应用里的引导把它配进 Wi-Fi）；
3. 手机连的是**同一个路由器**的 Wi-Fi。这条最容易翻车：访客网络、路由器的 AP 隔离、一个手机连流量一个打印机连 Wi-Fi，都会让手机看不见打印机；
4. 双频路由器的话，注意部分 Brother 机型只能入 2.4GHz 网络。「双频合一」（2.4G 与 5G 同名）的设置偶尔会让这类机型配网失败，可先把双频分开再试。

另外提醒一句：这个应用走无线连接，没有「手机用数据线连打印机」的模式，Wi-Fi 是唯一的路。

## 二、在应用里添加打印机

整个流程是引导式的，入口在首页的「添加设备」。打印机还没入网的话，除了借应用配网，也可以用路由器的 WPS 按键一键连接（官方中国支持站把配网方式归为三种：WPS 按键、手机 App 配网、电脑访问 `easysetup.brother.com` 配网），配好网再回应用里添加：

1. 打开应用，点首页的**添加设备**；
2. 打印机还没入过网的，选「把打印机连接到 Wi-Fi」这类选项；已入过网的直接搜局域网里的设备；
3. 在型号框里输入你的机型（例如 `MFC-J4340DW`），点确认；
4. 应用与打印机建立连接，按屏幕提示继续；
5. 给打印机填入 Wi-Fi 密码，等它连上网络；
6. 确认手机此刻也连着同一个 Wi-Fi，点「连接」完成配对。

不同机型的引导界面略有差别，以应用内提示为准。打印机已经在网络里的话，搜索列表里直接选中就能用，不必重走配网。

## 三、搜索不到打印机时按这个顺序排查

| 顺序 | 检查什么 | 怎么处理 |
| --- | --- | --- |
| 1 | 手机与打印机是否同一网络 | 连同一个 Wi-Fi 名，别用访客网络 |
| 2 | 应用有没有位置权限 | 没有位置权限时安卓搜不到局域网设备，去系统设置里补上 |
| 3 | 打印机 Wi-Fi 状态 | 机身上 Wi-Fi 指示灯应处于正常状态，异常就重走一次配网 |
| 4 | 路由器 AP 隔离 | 关闭 AP / 客户端隔离后再搜 |
| 5 | 距离与干扰 | 路由器太远信号弱会搜不到，把设备拉近再试 |

两条补充经验：

- 搜索反复失败时，找应用里的「手动添加 / 输入 IP 地址」类入口，把打印机的 IP 直接填进去（IP 在打印机面板的网络设置里能查到）；
- 有用户反馈机型固件太旧时应用会一直搜不到设备，把打印机固件更新到最新后再试。

另外，应用弹出「启用 Wi-Fi Direct」的提示时，手机与打印机已经在同一 Wi-Fi 下就选否——那是没有路由器时手机直连打印机的方式，家里有正常 Wi-Fi 用不上它。

还不行就重启路由器和打印机再来一遍，多数「搜不到」到这里就解决了。顽固情况翻[常见问题与故障排查.md](常见问题与故障排查.md)里的连接一节。

## 四、连上之后建议做三件事

- 到设备仪表盘里看一眼墨量 / 碳粉读数是否正常，顺便确认机型信息无误；
- 把你最常用的功能（比如扫描）在首页里排到顺手的位置，以后少翻两层菜单；
- 国内的 Brother 机型还能绑定「畅享印」开通远程打印，步骤见[畅享印远程打印怎么开通.md](畅享印远程打印怎么开通.md)。

## 五、换网络与多台设备

- 打印机换了 Wi-Fi（搬家、换路由器、改密码）后，旧网络信息就失效了，在应用里重走一次添加设备即可；
- 家里有多台 Brother 设备可以继续逐台添加，耗材监控最多支持 5 台设备。

装好后怎么用各项功能，见[打印与扫描怎么用.md](打印与扫描怎么用.md)。
