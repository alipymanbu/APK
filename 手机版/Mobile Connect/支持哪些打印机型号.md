## 一、先分清两代应用

Brother 现在有两款移动端打印应用，别装错：

| 应用 | 定位 | 什么时候用 |
| --- | --- | --- |
| Mobile Connect | 较新的应用，也是本文主角 | 机型在支持列表里就用它 |
| iPrint&Scan | 上一代应用 | 老机型不在 Mobile Connect 列表时的官方替代 |

官方口径很直接：机型不支持 Mobile Connect 时，改用 iPrint&Scan。两个应用可以共存，不用二选一。

## 二、支持机型覆盖哪些系列

Mobile Connect 的支持列表覆盖 Brother 近年的打印机、一体机与网络扫描仪。下面按系列归类，每系列列几个已在官方列表中确认的型号示例（截至撰写时；不同国家官网的清单不完全一致，完整清单以官方页面为准）：

| 系列 | 已确认在列的示例 |
| --- | --- |
| 喷墨一体机（DCP-J / MFC-J） | DCP-J1050DW、DCP-J1140DW、MFC-J1010DW、MFC-J4340DW、MFC-J6955DW |
| 黑白激光（DCP-L / HL-L / MFC-L） | DCP-L2530DW、HL-L2350DW、MFC-L2710DW、MFC-L2860DW |
| 彩色激光（DCP-L / HL-L / MFC-L 的 CDW / CDN 型号） | DCP-L3520CDW、HL-L3240CDW、MFC-L3740CDW、MFC-L9670CDN |
| A3 喷墨（HL-J） | HL-J6010DW |
| 网络扫描仪（ADS） | ADS-4100、ADS-4300N、ADS-4500W、ADS-4700W、ADS-4900W |

规律大致是：越新的机型越可能直接在列表里；上市多年、只出过 iPrint&Scan 支持的老机型，多半不在 Mobile Connect 的支持范围。

## 三、怎么确认你的机型能用

1. 打开官方的[适用应用查询页](https://support.brother.com/g/b/oscontents.aspx?ossid=4)；
2. 选择你的机型；
3. 看它列出的适用应用里有没有 Mobile Connect；没有的话按下一节处理。

拿不准型号写法的话，看机身正面或背面的铭牌，型号一般印在 `MFC-` / `DCP-` / `HL-` / `ADS-` 开头的那一串上。

## 四、机型不在列表里时的三条路

1. **换 iPrint&Scan**：官方为老机型准备的替代应用，基础打印、扫描都有；
2. **安卓系统级打印**：装 [Brother Print Service Plugin](https://play.google.com/store/apps/details?id=com.brother.printservice) 后，任何应用菜单里的「打印」都能直接选到 Brother 打印机，不需要专门打开某个应用；
3. **iOS 设备**：同一 Wi-Fi 下用 AirPrint 直接打，不依赖这两款应用。

机型确认支持之后，回到安装与连接：安装见[下载与安装教程.md](下载与安装教程.md)，连接步骤见[怎么连接打印机.md](怎么连接打印机.md)。
