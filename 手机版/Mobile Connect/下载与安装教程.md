## 一、装之前先确认三件事

| 检查项 | 说明 |
| --- | --- |
| 系统版本 | 安卓 7.1 及以上（以应用商店页面标注为准），更低的系统装不上 |
| 存储空间 | 安装包约 43 MB，建议再留 100 MB 以上余量给扫描文件与缓存 |
| 打印机 | 手头是 Brother 打印机 / 一体机 / 扫描仪，且机型在支持列表里；不确定先看[支持哪些打印机型号.md](支持哪些打印机型号.md) |

应用本身免费，打印、扫描这些核心功能没有付费门槛。

## 二、获取安装文件

1. 打开 [Mobile Connect 安装文件资源（夸克网盘）](https://pan.quark.cn/s/67776a3704a1)，先把文件转存到自己的网盘；
2. 在夸克网盘 App 里找到转存的 apk 文件，下载到手机；
3. 下载完成后直接从通知栏或「文件管理 → 下载」里点开它，进入安装流程（见第四节）。

## 三、安装包信息（以本地核对为准）

| 项目 | 值 |
| --- | --- |
| 应用名称 | Brother Mobile Connect |
| 版本 | 1.23.2 |
| 包名 | `com.brother.mfc.mobileconnect` |
| 大小 | 42.91 MB |
| MD5 | `8978e87195a997e9f5f56e69b546aa70` |
| 信息核对日期 | 2026-09-23 |

装之前可以对一下这几项：版本号、大小与上表一致即可放心安装；在意文件完整性的话，用文件管理器或校验工具算一下 MD5 与上表比对。转存后文件名若带「（先保存再下载）」这类后缀目录，属正常存放路径，不影响安装。

## 四、安装步骤

安卓不允许直接安装来路不明的应用，第一次装会碰到「未知来源」开关：

1. 在文件管理器里点开 apk 文件；
2. 系统弹出「不允许安装未知应用」的提示，点「设置」；
3. 打开「允许来自此来源的应用」开关（就是给你的文件管理器放行，路径一般是 设置 → 应用 → 特殊应用权限 → 安装未知应用）；
4. 返回安装页，点「安装」，等待完成；
5. 完成后点「打开」。

不同品牌（小米、华为、OPPO 等）的入口名字略有出入，但都是同一个「允许 XX 安装未知应用」的开关，按提示走到哪一步就放行哪一个应用。

## 五、第一次打开会碰到什么

- **权限申请**：会依次要存储权限（读取你要打印的照片和文档）与位置权限。位置权限别拒绝——安卓规定应用拿不到位置权限就读不到 Wi-Fi 信息，也就搜不到局域网里的设备，它跟「定位你在哪」无关，很多「搜不到打印机」的问题都出在这里。应用可能还会要蓝牙权限，普通家庭 Wi-Fi 场景可以不给，只有用到 Wi-Fi Direct 直连时才需要。
- **首页**：默认是打印、扫描等常用功能的卡片式首页，支持自定义排列，把高频功能挪到顺手的位置。
- **添加设备**：此时应用里还没有打印机，先走添加设备流程，具体见[怎么连接打印机.md](怎么连接打印机.md)。

## 六、和官方商店版本的关系

- 网盘里这份是 1.23.2；官方商店（[Google Play 上的 Mobile Connect 页面](https://play.google.com/store/apps/details?id=com.brother.mfc.mobileconnect)）可能已发布更高版本，功能差异以官方更新说明为准。
- 手机里已经装过商店版本且版本更高时，无法直接用 1.23.2 覆盖（安卓不允许降级覆盖），需要先卸载商店版再装这份；反过来则可以直接覆盖安装。
- 两个安装渠道是同一个包名，不会在手机上并存两份。
