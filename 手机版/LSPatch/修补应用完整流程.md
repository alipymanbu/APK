## 一、修补前把材料备齐

| 材料 | 说明 |
| --- | --- |
| LSPatch 管理器 | 已安装并能正常打开，没有的话先看 [下载与安装教程.md](下载与安装教程.md) |
| 目标应用 | 你想加模块的那个应用：手机上已安装，或手里有它的 APK 文件，两种都行 |
| 模块（可选） | 便携模式需要把模块一起嵌进去，模块本身也是一个 APK，要先装到手机上（0.6 版起也支持修补时直接从存储里选模块文件） |
| 输出目录 | 首次修补时管理器会让你选一个文件夹存放产物，提前建好省事 |

修补模式怎么选（本地 / 便携）直接影响后面勾模块的方式，动手前先读 [本地模式与便携模式怎么选.md](本地模式与便携模式怎么选.md)。

## 二、完整步骤

1. 打开 LSPatch，切到底部「管理」页，点右下角的「+」新建修补；
2. 首次会提示选择存储目录：选你在准备阶段建好的文件夹，按提示给存储权限；
3. 选目标：可以「从存储目录选择 APK 文件」，也可以「选择已安装的应用程序」，效果一样；
4. 选修补模式（本地 / 便携）；
5. 便携模式在这里点「嵌入模块」，勾选你要带的模块（前提是模块已装在手机上，或从存储选择模块文件），选完点右下角的对勾确认；本地模式没有这一步；
6. 点「开始修补」，等日志跑完 —— 快慢取决于应用体积，几秒到几分钟都正常，期间别清理后台；
7. 看到 `done. output apk...` 之类的完成提示即修补成功，产物会存进第 2 步选的目录，文件名形如 `base-数字-lspatched.apk`（不同版本细节有差异，认准 `lspatched` 字样即可）。

## 三、把修补结果装到手机上

有两条路：

- **应用内直接安装**：修补完成的管理器页面里点「安装」。这条路要求 Shizuku 已连接，没连的话会提示失败 —— 属于正常现象，不是修补坏了；
- **手动安装**：打开文件管理器，进第 2 步选的输出目录，找到文件名带 `lspatched` 的 APK，点开安装。这是没有 Shizuku 时最稳的一条路。

## 四、动手前必须知道的事

1. **先卸载原应用才能装上**：修补产物与原应用的签名不同，原应用不卸载，系统会报「签名不一致 / 应用未安装」。卸载意味着原应用的本地数据（聊天记录、存档等）会一起清掉 —— 有这类数据的先备份，再动手；
2. **修补版不走应用商店更新**：同样的签名原因，应用出新版后商店更新会失败。想升级，就用新版 APK 重新修补一遍、再替换安装，流程与本篇相同；
3. **不是所有应用都修得好**：官方在早期发布说明里明确提过「非 root 框架能力有限，不能指望在所有应用上都能工作」。个别应用做了完整性校验或加壳，修补后可能打不开，遇到就换模式或换版本再试，办法见 [常见问题排查.md](常见问题排查.md)；
4. **只装自己动手修补出来的产物**：别人发来的「已修补好」的 APK，无法确认里面除了模块还被塞了什么，不要直接装到自己的手机上。

修补的对象是微信这类聊天应用的话，动手前再读 [微信等聊天应用修补注意事项.md](微信等聊天应用修补注意事项.md) —— 替换官方版、聊天记录、第三方拉起这几笔账要先算清。

修补完怎么确认模块真的生效了，看 [模块嵌入与激活方法.md](模块嵌入与激活方法.md)。
