## 一、装之前先核对这几项

| 项目 | 说明 |
| --- | --- |
| 系统版本 | 安卓 9 及以上（修补生成的应用也会被强制以安卓 9 为最低支持版本） |
| 版本口径 | 本文以网盘收录的 0.8 版安装包（约 12.53 MB）为准，界面细节以你实际安装的为准 |
| 包名 | `org.lsposed.lspatch` |
| Root | 不需要，也不用解锁 Bootloader |

最高能跑到哪个安卓版本，官方的说法是"与 LSPosed 框架一致"，具体上限随系统变化，以官方页面为准。

## 二、从哪里下载

LSPatch 是开源软件（GPL-3 协议），官方发布渠道是 GitHub 仓库 [LSPosed/LSPatch](https://github.com/LSPosed/LSPatch) 的 [Releases 页面](https://github.com/LSPosed/LSPatch/releases)，手机端对应的是官方说明里叫 `manager.apk` 的管理器安装包；仓库里另有供电脑命令行使用的 `lspatch.jar`（需要 Java 环境，用 `java -jar lspatch.jar` 运行），手机上用不到它。

有一点需要知道：官方 GitHub 仓库在 2023 年 12 月已经归档、不再更新，最后正式版本是 0.6；之后市面上出现的更高版本号（包括本文依据的 0.8）来自各家分发渠道，功能与界面以实际安装包为准。

不想在 GitHub 上翻版本的话，直接用开头的 **LSPatch 安装文件资源（夸克网盘）** 拿即可，转存后把里面的 APK 装到手机上就是管理器本体。

## 三、安装步骤

1. 从网盘资源或 GitHub Releases 下载安装包，转存到自己网盘后下载到手机本地；
2. 在文件管理器里点开这个 APK，按系统提示完成安装（它是一个普通应用，不需要额外授权）；
3. 首次打开管理器时，顶部会提示「Shizuku 服务未连接」—— 先不用管，这只影响「修补完成后在应用内直接安装结果」这一个动作，修补本身和手动安装修补结果都不受影响；
4. 进入底部「管理」页时，会让你选一个目录存放修补后的安装包：建议提前新建一个好找的英文文件夹（比如 `Download` 下的 `lspatch-out`），选中后按提示授予存储权限。

## 四、装完先做什么

管理器本身装好只是第一步，它不是拿来直接用的，而是用来「修补」目标应用的。下一步的操作链见 [修补应用完整流程.md](修补应用完整流程.md)；修补前建议先弄清本地模式与便携模式的区别，见 [本地模式与便携模式怎么选.md](本地模式与便携模式怎么选.md)。装好后看到的 Shizuku 提示要不要处理，在 [常见问题排查.md](常见问题排查.md) 里有单独说明。
