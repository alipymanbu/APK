# interpark 外国人购票常见问题与排查

> 本篇汇总外国用户在 interpark 购票时最常卡住的几个环节：支付被拒、姓名不一致、退票规则、搜不到公演，逐条给出排查方向。

## 一、付款时卡被拒（3DS 失败或银行拦截）

外卡付款失败是最高频的问题，常见原因按顺序排查：

1. **3D Secure 没过**：国际版普遍要求 3DS 验证，检查银行 App 或短信是否收到验证请求、有没有被手机拦截；
2. **银行风控**：韩国网站的扣款请求可能被你的银行当成可疑境外交易，出发购票前先向银行报备行程或确认境外线上支付已开通；
3. **卡片种类**：Visa / Mastercard 覆盖面最广，AMEX 与 JCB 部分公演不接受，换一张卡重试；
4. **公演限制**：个别公演对外卡支付另有要求，以购票页提示为准。

如果账号是在韩国本土版注册的，支付渠道基本绑定韩国银行体系，外卡本来就不可用——这种情况下该走的是国际版（对比见 [国际版与韩国版区别.md](国际版与韩国版区别.md)）。

## 二、账号姓名与护照对不上

症状：订单已出，但入场时担心被拒；或注册时发现姓名填错。

- 注册后账户姓名**一般不可修改**，填错时优先联系官方客服处理，处理不了的，重新注册一个拼写正确的账号再下单；
- 抢热门场次之前就把姓名核对好，下单后再发现问题，退改成本会高得多。

## 三、退票规则怎么看

退票手续费按公演各自设定，没有统一标准。以首尔艺术殿堂（예술의전당）公开的规则为例：

| 距开演时间 | 手续费 |
| --- | --- |
| 10 天前 | 免手续费 |
| 开演前 9~1 天 | 票价 10% |
| 当天 | 不可退 |

这份表只说明「退票规则是分时间段的、越临近越贵」，**你那场演出的具体规则以购票页与订单页显示为准**。在 App 里取消订单的具体步骤、退款到账时间，见 [退票取消操作与手续费.md](退票取消操作与手续费.md)。

## 四、门票能不能转给别人

不能自由转让。官方与主办方的口径：

- 账号实名与入场证件绑定，**名义变更原则上不予办理**；
- 部分经纪公司（如 YG）的官方公告明确：转让、代购一经发现会**取消订票**并处置账号；
- 官方认可的转售渠道只有 **Ticketbay**：由平台按规则转售、价格有上限，且部分公演禁止转售票入场。

想处理掉手里的票或想收一张转让票，只走 Ticketbay 这类官方渠道；私下交易的风险是两头都可能被拒绝入场，且钱票两空。

## 五、搜不到想看的公演

可能的原因与对策：

- **该公演没在国际版上架**：部分公演只在韩国本土版销售，国际版搜不到属正常，此时要么找韩国用户协助走本土版，要么留意其他销售渠道；
- **名称关键词不对**：韩国公演多以韩文命名，用艺人的韩文写法或英文名再搜一次；
- **已售罄或未开售**：核对开售时间表，热门场次开售后几分钟内就会清空。

## 六、哪些环节绕不开韩国手机号

没有韩国手机号，你会卡在的地方：

- 韩国本土版的注册与实名认证（这是死门槛，绕不过）；
- 部分公演的事前认证环节。

不会卡住的地方：

- 国际版注册、购票、电子票入场——这条线只需要邮箱、护照和外卡。

所以结论很简单：没有韩国身份就走国际版，别在本土版上耗时间。注册细节见 [账号注册与实名认证.md](账号注册与实名认证.md)。
