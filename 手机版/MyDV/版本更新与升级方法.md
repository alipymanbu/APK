## 一、先确认你现在是哪个版本

两个地方可以对：

- **包本身**：网盘里这份是 **1.1.9**，8.01M，包名 `com.github.mytv.dv`，MD5 `467017F7A4BEF93F19F976CC0ABA9722`（[下载与安装教程.md](下载与安装教程.md) 里有核对方法）；
- **装机后**：电视设置 → 应用 → myDV → 应用信息，版本号一栏显示的是已安装的版本，拿它和官方发布页对。

特别注意：网上能搜到的「最新版」动辄 1.2.x、1.5.x，那是**官方发布页的版本**，和你网盘里转存的这份不是同一个东西 —— 判断要不要升级，以应用信息里那个数字为准，别拿搜索结果里的版本号当自己装的版本。

## 二、新版本从哪来

官方发布页是唯一可信的版本源：[github.com/mytv-android/myDV/releases](https://github.com/mytv-android/myDV/releases)，每个版本都带变更日志。国内直连 GitHub 可能不稳，打不开就从你常用的网盘渠道转存（本文头部那份安装文件资源就是一份离线备份）。

更新节奏：作者是持续迭代的，从 2026 年的版本轨迹看基本是几周一个版本；截至 2026 年 9 月，官方已发布到 **v1.5.27**。这些数字会随时间变化，以官方发布页当时显示为准。

## 三、怎么升级

覆盖安装，不用卸载：

1. 拿到新版本 APK（来源见上节）；
2. 拷到电视上直接点安装，系统会当成同一应用的升级；
3. 装完打开，确认版本号已变。

两个前提：

- **清数据不是升级的必要步骤** —— 覆盖安装会保留设置与已填的 Cookie；
- 只有在新版本出问题想退回时才卸载重装旧版 —— 那会清掉登录态，回退后要按 [Cookie登录账号教程.md](Cookie登录账号教程.md) 重新填一次 Cookie。

## 四、各版本改了什么（选摘）

下面是官方发布页变更日志里与使用直接相关的部分，按版本倒序选摘（完整列表以发布页为准）：

| 版本 | 与你有关的变化 |
| --- | --- |
| v1.5.27 | 界面优化；评论面板可见判定调整；扫码搜索与本地搜索键行为一致；搜索结果翻页加间隔（缓解风控）；修复作者主页、合集、视频详情接口 |
| v1.4.26 | 应用内更新改用多镜像实时测速选源；修复切换视频时声音早于画面；修复合集 API 变动 |
| v1.4.25 | 进度条拖拽显示目标时刻预览图；进入个人主页优先加载「历史」页签（可关）；新增播放量统计上报 |
| v1.3.24 | 视频页支持识别合集并唤起合集列表；修复喜欢 / 收藏 / 合集接口升级导致的取不到数据；修复搜索联想词接口升级触发的风控 |
| v1.3.23 | 音量均衡；「提前缓存下一视频」重新引入（默认关）；用户主页新增合集页签；弹幕和评论支持 emoji 表情图；主页面返回键改为唤起导航栏 |
| v1.2.22 | 「禁用双按返回退出」开关；多用户账户隔离；扫码登录通道（当时标注因限制不可用）；直播画质可独立设置；播放器重试功能 |
| v1.2.20 | 搜索页支持输入作品 ID 直接播放 |

对照你的 1.1.9：上面这些**一个都不在里面**。最影响日常体验的差异是搜索（1.1.9 时期的搜索反馈问题多，后续版本反复在修）、接口类修复（主页 / 合集 / 喜欢打不开，多半是接口变动后老版本没跟上）、以及播放相关的修复。想让这些生效，只有升级一条路。

## 五、哪些情况不建议升

- **用得稳就别动**：推荐流、直播都正常，没有非解决不可的问题，维持现状最省事；
- **急着用就先别升**：新版本偶尔引入新问题（后续版本再修），遇到自己的关键功能在新版反而坏了，按第四节的办法退回旧版；
- **升级前记一下当前 Cookie**：正常覆盖安装不需要重填，但只要涉及卸载，登录态必丢，有备无患。
