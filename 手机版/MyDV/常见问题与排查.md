## 一、视频卡、播着播着一顿一顿

这是被反馈最多的现象，先看两边的说法：

- 有用户反馈部分视频播放会卡，作者在官方仓库首页的回应是「卡是正常的，保持深呼吸」—— 也就是承认现阶段有性能开销，等版本优化；
- 同时也有实测反馈：低配盒子跑基础流程是流畅的，卡主要出在特定视频或网络上。

你可以按这个顺序处理：

1. **先切网络**：换更稳的 Wi-Fi，或把路由器和电视之间的障碍清掉 —— 播放类卡顿多数是网络；
2. **降分辨率**：长按菜单键，把分辨率从「自动 / 1080P」切到 720P 甚至 480P，码率下来了，卡顿通常立刻缓解；
3. **清缓存**：电视设置 → 应用 → 找到 myDV → 清理缓存（清缓存不丢登录，清数据才会把 Cookie 一起清掉）；
4. **换新版**：你手头这版之后官方还在持续修播放相关的问题（例如 v1.4.26 修了「切换视频时声音早于画面」），升级路径见 [版本更新与升级方法.md](版本更新与升级方法.md)。

## 二、搜索点了没反应 / 搜不出来

搜索是这个项目的已知短板：有用户反馈部分版本的搜索功能无法正常使用，多个版本都出现过；官方更新日志里搜索相关的修复也出现得比较频繁 —— 截至 2026 年 9 月的 v1.5.27 里就有「扫码搜索提交与本地搜索键行为一致」「搜索结果翻页请求增加间隔」这类改动，v1.3.24 修过「搜索联想词接口升级导致的风控问题」。

判断与处置：

- **先确认版本**：网盘里这份是 1.1.9，属于较早的版本，搜索相关修复都不在里面 —— 搜不出来时优先考虑升级，而不是反复重试；
- **换关键词或直接给作品 ID**：v1.2.20 起支持在搜索页输入作品 ID 直接打开视频，关键词联想触发风控时这条更稳；
- 升级后仍然搜不了，才需要怀疑网络或接口变动（反馈渠道见第七节）。

## 三、安装阶段的各种拦路

| 现象 | 怎么处理 |
| --- | --- |
| 提示「解析包错误」/ 无法安装 | 安装包没下完整，回 [下载与安装教程.md](下载与安装教程.md) 重新下一遍，别用断点续传到一半的文件 |
| 提示不允许安装未知来源应用 | 设置 → 安全 → 允许安装未知来源 / 未知应用，授权后重装 |
| 被「纯净模式 / 安全检测」直接拦截 | 先在系统设置里关掉这类开关再装 |
| 装完打不开、闪退 | 应用管理里先清缓存；无效就卸载重装（清数据会丢 Cookie，重装后按 [Cookie登录账号教程.md](Cookie登录账号教程.md) 重填一次） |
| 系统版本过低装不上 | 官方仓库标注 Android 6.0 及以上，系统更老的设备没有可用路径，别硬试 |

另外确认一下你装的确实是这个包：网盘那份是 **1.1.9 / 8.01M / 包名 `com.github.mytv.dv`**，MD5 `467017F7A4BEF93F19F976CC0ABA9722`，对不上就是拿错文件了。

## 四、登录不上 / 用着用着掉登录

按出现频率排：

1. **Cookie 没取全**：用控制台 `document.cookie` 取的容易缺敏感字段（官方明确提醒过），换成插件导出的 Header String 格式再试；
2. **复制时截断**：几十上百个字符，手抄漏一段就废，重新导出整段覆盖粘贴；
3. **填完没保存 / 填错了输入框**：回设置页确认一遍内容还在；
4. **Cookie 到期**：登录态本来就有有效期，掉登录是正常现象，重新导出填一份即可，步骤见 [Cookie登录账号教程.md](Cookie登录账号教程.md)。

电视上没法直接粘贴长串是个现实障碍 —— 这属于输入方式问题，不是登录逻辑坏了，处理办法同样在那一篇里。

## 五、按键行为和教程对不上

你在别处看到的教程说「确认键显示详情」，你按出来却是暂停播放 —— 这类差异多半是**版本差异或页面分工**（列表页移焦点、播放页控播放）。以你电视上实际按出来的为准，两套口径的完整对照在 [遥控器按键操作说明.md](遥控器按键操作说明.md)。连按两次返回退出如果突然失效，检查设置里是否开了「禁用双按返回退出」。

## 六、直播看不了 / 直播黑屏、不稳

先分清是不是版本问题。直播相关修复在后续版本里出现得很密（官方发布页更新日志）：

- **v1.2.20 ~ v1.2.22**：优化直播房间 ID 处理逻辑、直播逻辑与 FLV/HLS 线路 —— 直播播放不再复用短视频的缓存和请求头；直播画质可以独立设置；

也就是说，**网络没问题却直播黑屏、加载不出来，而短视频正常**，最直接的排查动作是对照 [版本更新与升级方法.md](版本更新与升级方法.md) 看看自己是不是还停在老版本上。升级前可以先做的两件事：确认直播画质不是拉到了最高档（网络扛不住就往低调）、重启应用让线路重新握手。

短视频和直播**都**打不开，则不是直播接口的问题，回到第一节从网络查起。

## 七、还是没解决

这个项目是开源的，问题可以直接在官方仓库提（[github.com/mytv-android/myDV/issues](https://github.com/mytv-android/myDV/issues)）；提问前先搜一遍 issue，同类问题往往已经有了。反馈时把三件事写清楚：版本号、电视 / 盒子型号与系统版本、具体操作与现象截图，能省掉一来一回的追问。
