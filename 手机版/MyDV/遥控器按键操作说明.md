## 一、按键对照表

官方仓库的操作说明和各论坛的实测反馈有一处口径差异（确认键、左右键在不同页面/版本上表现不同），下面把两边都列出来，你以自己电视上按出来的效果为准：

| 按键 | 官方仓库口径 | 论坛实测口径 |
| --- | --- | --- |
| 上 / 下 | 移动焦点 | 切换上一条 / 下一条视频 |
| 左 / 右 | 移动焦点 | 调整播放进度（快进 / 快退） |
| 确认键 | 暂停 / 播放 | 短按显示或隐藏视频详情；长按进入当前视频发布者主页 |
| 返回键 | 打开导航栏 | 回到导航栏；连按两次退出应用 |
| 菜单键（长按） | —— | 弹出选项面板：弹幕开关、分辨率切换、倍速播放、查看主页 |

两边不冲突的地方是共识：**上下切内容、返回呼出导航栏、连按两次返回退出**。差异集中在确认键和左右键，常见原因是「列表页移动焦点、播放页控制播放」这样按页面分工 —— 装好后在首页和播放页各按一遍，十秒钟就摸清了你这版的实际分工。

## 二、播放页还能怎么操作

除了纯按键，播放页还支持这些动作（官方仓库列出的）：

- **左半屏 / 右半屏点击**：点屏幕左半边显示推荐面板，点右半边显示进度条；进度条出来后继续点左 / 右就是快进 / 快退（触摸屏设备、带鼠标操作的盒子适用）；
- **手势拖拽**：在屏幕上左右拖动来快退 / 快进；
- **确认键点屏幕中间**：暂停 / 播放。

也就是说，同一块屏上「左 = 往回翻内容、右 = 往前推进度」是这套交互的底层逻辑，遥控器和触控是两种映射。

## 三、长按菜单键的选项面板

按住菜单键弹出的那组选项，是播放时最常调的东西：

| 选项 | 用途 |
| --- | --- |
| 弹幕开关 | 视频上的弹幕显示 / 隐藏 |
| 分辨率切换 | 自动、1080P、720P、480P 几档；电视网络不稳时往低了调，卡顿会明显缓解 |
| 倍速播放 | 多档倍速，快进看长视频用 |
| 查看主页 | 跳到当前视频发布者的主页 |

分辨率和倍速这两项在卡顿时最管用，具体判断依据见 [常见问题与排查.md](常见问题与排查.md) 的卡顿一节。

### 弹幕与评论的几个版本差异

你在这块屏上看到的弹幕、评论表现，和版本强相关（官方发布页更新日志）：

- **弹幕里的表情**：v1.3.23 起弹幕和评论支持显示 emoji 表情图像，**弹幕里的表情可以单独关掉** —— 想要干净的弹幕，在播放菜单或设置里找这个开关；
- **弹幕重叠**：v1.3.23 修过弹幕重叠问题，你在这版如果看到弹幕叠在一起，属于已知问题，不是电视坏了；
- **评论面板**：v1.5.27 调整了评论面板的可见判定 —— 评论区有时显示有时不显示的怪现象，在那版之后有收敛。

手头的 1.1.9 早于上面所有版本，按实际界面为准：没有的开关就是没有，别按新版本的教程硬找。

## 四、导航栏与退出

- **返回键**：在任意主页面按返回，呼出的是底部导航栏，不是直接退回上一层 —— v1.3.23 起把「主页面返回键退回推荐流」的行为改成了呼出导航栏，老版本行为可能不同；
- **退出应用**：连按两次返回。如果你的版本在设置里开了「禁用双按返回退出」（v1.2.22 起提供），双按就不管用了，只能从抽屉菜单栏最下方的「退出」退出，或按遥控器的 HOME 键回桌面。

导航栏里能切推荐、关注、直播、搜索这些入口，平时想找功能就先按返回把它叫出来。

## 五、上手顺序建议

1. 首页按几下上下键，确认这版的切换方向；
2. 进一条视频，按确认键看是暂停还是显示详情，按左右键看是移焦点还是调进度；
3. 长按菜单键，把分辨率调成「自动」或固定 1080P，网络一般就选 720P；
4. 连按两次返回，确认能正常退出。

走到第 4 步还没问题，这台电视上的基本操作就通了。剩下偶发的卡顿、搜索无响应之类，去 [常见问题与排查.md](常见问题与排查.md) 对号入座。
