## 一、这是什么，装之前先对一下条件

myDV 是一个第三方开发的抖音电视端客户端（开源项目，作者在仓库里把它叫 my Debug VideoTV），你用电视遥控器就能在大屏上刷视频、看直播、搜索，不需要拿手机投屏。抖音官方没有出电视版，这个项目补的就是这个位置；它的代码托管在 GitHub（[github.com/mytv-android/myDV](https://github.com/mytv-android/myDV)），采用 GPL-3.0 许可。

装之前对一下硬条件：

| 项目 | 要求 |
| --- | --- |
| 系统 | 官方仓库标注 Android 6.0 及以上；系统版本太老的电视/盒子可能装不上 |
| 设备 | Android TV、电视盒子，带遥控器即可操作 |
| 空间 | 安装包本身只有 8.01M，但运行时要留出缓存空间，别把电视存储塞满 |
| 网络 | 需要能连网播放；网络差会直接表现为卡顿（见[常见问题与排查.md](常见问题与排查.md)） |

不登录也能直接刷推荐流，登录是可选项，等你确实要看关注、点赞这类内容时再按 [Cookie登录账号教程.md](Cookie登录账号教程.md) 配置。

## 二、拿到安装包

两条路，任选其一：

1. **网盘**：[myDV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/05cb55fc0b69) —— 转存后按里面的文件名下载即可。
2. **官方发布页**：项目在 GitHub 的 Releases 页发布安装包（[github.com/mytv-android/myDV/releases](https://github.com/mytv-android/myDV/releases)），版本列表最全，但国内直连可能打不开。

两条路拿到的不一定是同一个版本号 —— 网盘里那份的事实信息见下节，官方发布页上永远是最新版，两者差异看 [版本更新与升级方法.md](版本更新与升级方法.md)。

## 三、网盘里那份包的事实信息

下面这几项是**这份安装包本身**的信息，用来确认你下对了文件（网上搜到的版本号、体积常常是另一回事）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.1.9 |
| 包名 | `com.github.mytv.dv` |
| 大小 | 8.01M |
| MD5 | `467017F7A4BEF93F19F976CC0ABA9722` |

在电脑上想核对完整性，可以用系统自带工具算一遍 MD5（PowerShell 或 CMD 里执行）：

```powershell
certutil -hashfile "下载路径\MyDV_v1.1.9.apk" MD5
```

算出来的值和上表对得上，说明文件没下残；对不上就重新下一次，别拿残缺的包去装电视。

## 四、装到电视上

多数电视装第三方 APK 是同一个套路，按顺序做：

1. 把 APK 文件拷进 U 盘，U 盘插到电视上；（或者用电视自带的文件管理器、局域网传输工具把文件送进电视）
2. 电视端打开「设置 → 安全 / 账号与安全」，允许安装来自**未知来源**的应用 —— 不同品牌叫法不一样，找「未知来源」「安装未知应用」这类字样；
3. 打开电视的文件管理器，找到拷进来的 APK，确认安装；
4. 装完打开，界面会按电视横屏和遥控器操作适配，直接就能用上下键刷视频。

部分品牌的电视还有「纯净模式 / 应用安全检测」，会把非应用商店的安装包直接拦下。遇到拦截提示时，先在系统设置里关掉这类开关再装。具体的报错对照（解析包错误、安装后闪退等）统一放在 [常见问题与排查.md](常见问题与排查.md)。

官方仓库还提到一个做法：用同一作者的姊妹项目 mytv-android 来装（需要先装那个项目）。这条路只适合本来就在折腾它的人，普通安装走上面四步就够了。

## 五、装好后先熟悉遥控器

打开就是推荐流，你按上下键切视频。几个先记住的动作：

- **确认键**：暂停 / 播放（部分版本与部分页面上表现为显示或隐藏视频详情，两种反馈都有，见 [遥控器按键操作说明.md](遥控器按键操作说明.md)）；
- **返回键**：呼出导航栏；
- **连按两次返回**：退出应用。

按键的完整对照表、播放菜单里能调什么，都在 [遥控器按键操作说明.md](遥控器按键操作说明.md)，建议先过一遍再瘫到沙发上。
