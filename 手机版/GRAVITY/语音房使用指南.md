## 一、语音房是什么

语音房（音声ルーム）是 GRAVITY 里的实时语音聊天：房主开一个房间，听众进来连麦，全程只出声、不露脸，个性靠头像与房间背景表达。话题不限——日常闲聊、音乐、怪谈故事都有人开房讲；「睡前找个人陪着说话」（寝落ち通話）是这里最常见的用法之一。

## 二、先听：进别人的房

在底部「音声ルーム」页里有几个标签：「フォロー」看关注的人开的房、「すべて」看全部、「HOT」看热门、「グループ通話」是群聊类房间。看到感兴趣的点进去就能听。先泡几天别人的房，是熟悉这个社区说话氛围最快的方式；想系统地了解各板块，回到[匿名社区与星球玩法.md](匿名社区与星球玩法.md)。

## 三、自己开房：每天最多五场

想开麦当房主，点语音房页面里的麦克风按钮。**非会员每天最多开 5 场**（按社区整理的攻略口径，具体次数限制以应用内实际提示为准）；单场没有时长上限，但房里一个听众都没有时，30 分钟后会自动关闭。开房前要设置这几项：

| 设置项 | 说明 |
| --- | --- |
| 房名（ルーム名） | 听众靠它找房间，起得清楚直白更容易进人 |
| 话题标签（ハッシュタグ） | 加上「雑談」「音楽」这类标签，能被搜索到 |
| 分类（ジャンル） | 给房间归类，影响曝光位置 |
| 公开范围（公開設定） | 决定谁能看到这场房 |
| 背景与麦克风权限 | 设房间背景图；决定谁可以上麦 |
| 自动分享 / 关联星球 | 开播自动发帖，或把房间挂在某个星球下 |
| 预约房（予約ルーム） | 定时开播，粉丝会看到预告 |

都设好后点「今すぐ開催」（立即开播）就上场了。房名和标签认真写——它们是陌生人决定进不进来的主要依据。

## 四、连麦与互动

房主可以给听众递麦，听众举手求麦；上了麦就是多人实时语音。冷场时可以备几个话题，或直接开「你划我猜」式的派对游戏——文字区也在同步滚动，不方便开口时打字参与也行。订阅了 GRAVITY STAR 的用户还能在语音房里发图片，这一点写在[会员方案与常见问题.md](会员方案与常见问题.md)里。

## 五、房里的规矩

语音房同样受社区规则约束：骚扰、诽谤中伤、色情内容会直接导致账号被处理（细则见[注册登录与账号管理.md](注册登录与账号管理.md)第六节），在房里索取或交换 LINE 等外部联系方式也是明确禁止的。声音匿名让人大胆，但被封号的判定和发帖区是一样的。
