## 一、先分清是哪种"用不了"

症状不同，处理路径完全不同，先对号入座：

| 症状 | 去哪篇 |
| --- | --- |
| 能打开、能浏览，只有某部番转圈/加载失败 | [播放失败时怎么切换线路.md](播放失败时怎么切换线路.md) |
| 点图标立刻退回桌面、白屏、卡在启动画面不动 | 继续看本文 |

## 二、按代价从小到大的排查顺序

下面的步骤整理自手机厂商（realme、vivo）官方支持文档里"第三方应用闪退/无响应"的处理建议（截至 2026-09，以官方文档当时内容为准），逐条做，做到哪条好了就停：

| 顺序 | 操作 | 你的损失 |
| --- | --- | --- |
| 1 | 重启手机，再打开 | 无 |
| 2 | 设置 → 应用 → LaQoo → 强制停止，再重新打开 | 无 |
| 3 | Wi-Fi 与移动数据互切一次，排除网络问题 | 无 |
| 4 | 长按图标 → 应用信息 → 存储 → **清除缓存** | 无，不丢记录 |
| 5 | 应用信息 → 权限，把存储等所需权限打开 | 无 |
| 6 | 同一位置 → **清除数据** | 会清空本机的收藏与历史记录 |
| 7 | 卸载后重装（安装包见 [下载与安装教程.md](下载与安装教程.md)） | 收藏、历史全部清空 |

第 4 步之前都是零代价的，先做完再考虑 6、7 —— 清数据和重装都会丢掉本机记录（为什么这些记录带不走，见 [追番时间表与收藏提醒.md](追番时间表与收藏提醒.md)）。

## 三、两个容易忽略的环境因素

- **存储空间**：vivo 官方建议给手机保留 20% 以上的剩余存储，空间不足会让应用运行异常。这个包本身只有 5.76M，闪退基本不会是"应用太大"，更可能是手机存储被塞满了。
- **系统版本**：厂商文档提到部分应用未适配最新的 Android 版本。如果你刚升级完系统就出现闪退，这是一条主要嫌疑，处理办法是留意应用的新版本（渠道页显示官方仍在更新，截至 2026-09 已到 1.3.4；版本以你实际拿到的安装包为准）。

## 四、以上都做完还是闪退

按厂商文档的口径，剩下多半是应用自身对这台机型的适配问题 —— 这不是你能在手机上修好的。可行的做法只有等新版本（见 [下载与安装教程.md](下载与安装教程.md) 对版本情况的说明），以及在你能下载到该应用的渠道页留言反馈。
