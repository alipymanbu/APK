## 一、安装类问题

**提示解析包错误 / 安装失败**

1. 重新下载安装包，中途断网最容易出坏包；
2. 核对文件 MD5 是否为 `11A51D81BC37F898FD3D2E52206A97B2`（大小写不影响比对结果），对不上就是包不完整或不是同一份；
3. 确认安卓系统版本满足安装包标注的要求（安卓 5.2 以上）。

**安装按钮置灰或提示禁止安装**

到系统设置里给「浏览器 / 文件管理器」开「安装未知应用」权限，具体步骤见[下载与安装教程.md](下载与安装教程.md)第三节。

**想和官方酷安共存**

包名不同（`com.example.c001apk` 对官方的 `com.coolapk.market`），直接装即可，互不覆盖。

**换渠道的包覆盖安装时提示「签名不一致」**

不同渠道分发的同名安装包可能签名不同，直接覆盖安装会失败。先卸载已装的那份再装新的（卸载会清掉应用内登录状态，重装后需要重新登录）；不想丢当前登录状态，就继续用现在这份，别换包。

## 二、账号与登录问题

- 密码不对：先去官方酷安客户端验证账号能正常登录，再回来登；
- c001apk 里**不能注册**新账号，需要先在官方渠道注册，见[怎么登录酷安账号.md](怎么登录酷安账号.md)第一节；
- 登录过程卡住或报错：按登录篇第三节的顺序排查（验证提示、机型参数选项、错峰重试）；
- 长期使用中突然登录失效：重新登录即可；如果反复失效，见下面第四节。

## 三、内容加载与功能异常

**刷不出内容、评论打不开、图片不加载**

按这个顺序试：

1. 下拉刷新或退出重进，先排除偶发；
2. 清理缓存（设置 → 清理缓存）后重试；
3. 换网络环境（Wi-Fi 与流量互切）再试；
4. 设置里的「随机/自定义机型参数」尝试调整后再试，部分加载异常与设备身份有关（以实际测试为准）。

**某项功能彻底用不了**

c001apk 走的是酷安服务端的接口。酷安一侧调整接口或风控策略时，第三方客户端的对应功能会跟着出问题——这不是你手机坏了，也不是操作错了。

另外有一类「异常」不在客户端层面：发出去的内容别人看不见、账号像被静默限制。这与本篇的排查无关，属于账号风控，自检方法与官方口径见[账号风控与黑号自检.md](账号风控与黑号自检.md)。

## 四、最重要的背景：项目已停止更新

GitHub 仓库 `https://github.com/bggRGjQaUbCoE/c001apk` 已经归档，最后一批代码提交在 2024 年 5 月，Issues 功能也已关闭。这对你意味着：

- **不会再有新版本**，你装到的就是最终形态；
- 第三节里那些「接口调整导致的异常」，**不会再有修复版本**，只能等它自己恢复或换工具；
- 仓库代码仍可访问（AGPL-3.0 开源），GitHub 上存在它的多个社区分支（fork），是否有人持续维护需要你自行查看对应仓库的活跃度；
- 如果只是想要一个「能用的酷安替代客户端」，也可以在 GitHub 搜索「酷安 第三方」找别的仍在维护的开源项目（如 CoolbbsYou：`https://github.com/WaitFme/CoolbbsYou`），维护状态同样以仓库页面为准。

## 五、收尾与重装

- **数据与缓存**：设置页里的「清理缓存」随时可用；卸载重装不会保留应用内的登录状态，重新登录即可。
- **彻底放弃前的收尾**：退出登录（设置里操作）→ 卸载应用；账号本身不受影响，官方酷安照常能用。
- **换个包核对**：从别处下载的安装包拿不准是不是原版时，比对 MD5 是唯一可靠办法，见第一节。
