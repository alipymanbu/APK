## 一、整体结构

按项目说明，c001apk 的功能划分成五大块：**首页、动态、搜索、消息、设置**。你日常的操作基本都在这五块里发生：首页刷内容，动态页看具体帖子和评论，搜索找人和话题，消息处理通知和私信，设置调整外观与行为。

## 二、首页：自己挑板块

首页支持**自定义 Tab**，可选的板块有：

| 板块 | 内容 |
| --- | --- |
| 关注 | 你关注的用户的动态，支持选择关注分组 |
| 应用 | 应用相关内容，可查看应用更新 |
| 头条 | banner、图标卡片入口、广场和动态 |
| 热榜 | 热门内容排行 |
| 话题 | 话题聚合 |
| 数码 | 数码分类内容 |
| 酷图 | 图片内容 |

把不看的板块去掉、只留常看的几个，首页会清爽很多——这是它和官方客户端差别最直观的一处。

## 三、看帖与互动

一篇动态里你能做的事：

- **对动态**：收藏、分享、点赞、举报，不喜欢的发布者可以拉黑，自己的动态可以删除。
- **对评论**：点赞、回复、查看对话（楼中楼串起来看）、按排序方式翻评论；评论同样支持举报和拉黑。
- **对图片**：保存到本地、分享、复制图片链接。
- **发布**：可以发文本动态；带投票的帖子会展示选项和各选项的观点。
- **快捷看评论**：浏览列表时不用点进帖子也能快捷查看评论。

这些互动功能需要登录，没有登录时按钮会引导你先去登录，步骤见[怎么登录酷安账号.md](怎么登录酷安账号.md)。

## 四、搜索：五种对象、可切换排序

搜索支持**动态、应用、数码、用户、话题**五种对象，并且：

- 可以切换搜索类型和排序方式，同一个词在应用和话题里搜出来的是两套结果；
- 有搜索历史，方便回找之前搜过的词；
- 在应用、数码、用户、话题的具体页面里还能再向内搜索。

想找某个应用是否被酷安收录、找某个话题下的讨论，都在这里完成。

## 五、话题、用户、应用三类页面

- **话题 / 数码页**：可以关注、拉黑；数码页的讨论支持排序。
- **用户页**：可以关注、分享、举报、拉黑。
- **应用页**：可以关注、看评论、**下载应用**——也就是说你可以在 c001apk 里直接下载酷安市场收录的安卓应用，这也是不少人拿它当轻量应用市场用的原因。

## 六、设置页：装好后先调这几项

| 设置项 | 作用 | 建议 |
| --- | --- | --- |
| 自定义主题 | 换外观配色 | 按喜好调 |
| 字体大小调节 | 改正文字号 | 觉得字小先来这调 |
| 外部浏览器打开链接 | 点链接时用外部浏览器而非内置页面 | 常在手机上跳网页的话打开更省事 |
| 用户/话题黑名单 | 管理你拉黑过的对象 | 配合正文里的拉黑操作使用 |
| 随机/自定义机型参数 | 调整客户端表明的设备身份 | 排查登录或加载异常时留意它 |
| 清理缓存 | 清掉本地缓存 | 觉得占空间时用 |

设置调完，日常使用中遇到问题（内容刷不出来、登录失效等）时，按[常见问题排查.md](常见问题排查.md)的顺序排查即可。
