## 一、这条路适合谁

额度用完了、又不想为试水花钱，但家里没电脑跑不了[Ollama本地模型离线聊天.md](Ollama本地模型离线聊天.md)——那就走 OpenRouter：注册一个账号拿一个 Key，它的目录里有一批标着 `:free` 的模型，调用不按 token 计费，限流之内随便聊。

## 二、OpenRouter 是什么、为什么省事

它是一个模型聚合网关：一个 Key 就能调数百个模型（各家官方口径为 300+ 个、来自数十家提供商），不用逐家注册。对酒馆玩家真正的意义是两条：其一，换模型不用换账号——在 MiniTavern 的模型下拉里换个名字就行；其二，目录里有免费档模型可选。

## 三、拿 Key 与免费额度规则

1. 到 [openrouter.ai](https://openrouter.ai/) 注册账号。
2. 到 [openrouter.ai/settings/keys](https://openrouter.ai/settings/keys) 生成一个 API Key，复制好。

免费模型（名称带 `:free` 后缀）的限额规则如下——**截至 2026-09，以 OpenRouter 官方 FAQ 当时显示为准**，这类规则会调整：

| 账户状态 | 免费模型每日上限 | 每分钟上限 |
| --- | --- | --- |
| 充值不足 $10 | 50 次请求 | 20 次 |
| 一次性充值满 $10（不是订阅，余额还能用于付费模型） | 1000 次请求 | 20 次 |

一天 50 次对偶尔聊几段够用；重度聊天就得把用量安排好，或按上表充一次值抬额度。

## 四、在 MiniTavern 里配置

大步骤与[AI模型接入与API配置.md](AI模型接入与API配置.md)第二节相同，对应到 OpenRouter 是：

1. 「设置 → 配置LLM」，提供商选 **OpenRouter**。
2. 粘贴上一步的 Key，点「Model」加载模型列表，挑一个名字以 `:free` 结尾的。
3. 「测试连接」→ 成功后「保存设置」。

如果你手上的版本提供商下拉里没有 OpenRouter 这一项，走通用接口也能接：提供商选「Other LLM」，LLM URL 填 `https://openrouter.ai/api/v1`，再填 Key 获取模型列表——OpenRouter 本身就是 OpenAI 兼容接口。

## 五、免费档的三个坑

- **选错模型会真扣费**。模型列表里既有 `:free` 也有付费模型，名字差一个后缀价格天差地别；确认选中的 slug 以 `:free` 结尾再开聊。
- **别开付费备用路由**。账户设置里的 fallback 类选项会在免费模型不可用时自动转付费模型，账单就是这么来的；新账号先把这类开关关掉。
- **免费模型有脾气**。限流（见第三节表格）、排队、高峰期不可用都正常，个别免费模型上下文窗口也偏小——长剧情聊到一半「失忆」，多半是上下文装不下，换个模型或开新对话。

## 六、三条路线怎么选

| 路线 | 花费 | 适合 |
| --- | --- | --- |
| OpenRouter `:free` 模型 | 零（限额内） | 没电脑、想用云端模型质量 |
| 应用内免费额度 | 零（额度有限） | 刚装的试水用户，见[AI模型接入与API配置.md](AI模型接入与API配置.md)第一节 |
| Ollama 本地模型 | 零（要一台电脑） | 想离线、想不限次，见[Ollama本地模型离线聊天.md](Ollama本地模型离线聊天.md) |

配好了但对话出问题，去[常见问题排查.md](常见问题排查.md)第一、二节对号。
