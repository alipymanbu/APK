## 一、这是一款什么应用

MiniTavern 是一个跑在手机上的 AI 角色扮演聊天应用，定位是 SillyTavern（俗称「酒馆」）的移动端替代：你在电脑上玩酒馆需要部署服务、配接口，在手机上装它之后导入角色卡就能直接聊。它自带聊天界面和本地数据存储，模型那边既可以零配置用它给的默认额度，也可以接你自己的 API Key 或局域网里的本地模型。

适合的人：想在手机上玩 SillyTavern 角色卡、但又不想碰 Termux 部署那一套流程的用户。

## 三、获取安装包

从 [MiniTavern 安装文件资源（夸克网盘）](https://pan.quark.cn/s/53fcf6923af5) 转存后下载 `MiniTavern_v1.4.2.apk`。转存到自己的网盘再下载，比直接在分享页在线下载更稳，中途断网也不会白下。

## 四、安装步骤

1. 在手机上打开下载好的 APK 文件。系统会提示「不允许安装未知来源应用」，选择仍要安装，或先去系统设置里给浏览器、文件管理器开「允许安装未知应用」权限（不同品牌的入口名称略有差异，一般在 设置 → 安全 或 设置 → 应用管理 里）。
2. 等安装完成，点打开。
3. 首次启动会看到内置的示例角色卡，点任意一张即可直接开聊——这一步不需要任何 API 配置。
4. 想换自己的角色卡或自己的模型，接着看这两篇：[角色卡导入方法.md](角色卡导入方法.md) 与 [AI模型接入与API配置.md](AI模型接入与API配置.md)。

装完打不开或闪退，先确认手机系统版本满足要求，再卸载重装一次；仍不行就到[常见问题排查.md](常见问题排查.md)对号入座。

## 五、关于版本：网盘这份和官方最新版不是一回事

官方的分发渠道是 [Google Play](https://play.google.com/store/apps/details?id=com.kongyouwangluo.minitavern)、[APKPure](https://apkpure.com/minitavern/com.kongyouwangluo.minitavern) 与 [官网](https://mini-tavern.com/)，版本号会持续更新（以官方页面当时显示为准）。网盘里固定是上表的 1.4.2。两者的差别只在新功能与修复，角色卡玩法和模型接入方式是一致的。

如果你在意校验文件完整性：把下载好的 APK 用文件管理器的属性页或第三方校验工具算一遍 MD5，与第二节表格里的值比对，一致说明文件没在传输中损坏。
