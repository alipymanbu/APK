## 一、为什么会有"我装的到底是不是这个"的疑问

搜"测速"能搜出一堆名字相近的应用：有的叫 Speedtest，有的叫 speedtest5g，有的叫测速网，图标还都是"仪表盘 + 数字"的样式。它们互相之间没有任何关系，各自用各自的服务器、各自的统计口径。装错了不会有什么后果，但**拿 A 的结果去对 B 的说明，就会处处对不上**——比如本系列文档里写的入口、工具和单位设置，换到另一个应用上自然找不到。

所以第一步不是比较速度，而是确认你手机上那个应用的**包名**。

## 二、看包名，这是唯一的硬标准

应用名可以叫得很像，包名不会撞车。在手机上查看：进"设置 → 应用管理 → 找到这个应用 → 应用信息"，里面会列出包名。对照下表：

| 应用 | 包名 | 说明 |
| --- | --- | --- |
| speedtest5g | `cn.nokia.speedtest5g` | 本系列文档对应的应用，中文界面，开发者署名为诺基亚通信系统技术（北京）有限公司，运营方为福建福诺移动通信技术有限公司 |
| Speedtest（Ookla） | `org.zwanoo.android.speedtest` | 国际上最常被提到的那个 Speedtest，开发者是 Ookla，中文界面需在设置里切换 |
| 测速网（SpeedTest.cn） | 各家商店详情页里可以查到 | 国内另一个测速平台，配套的是"网速管家"公众号；它的包名以它自己的域名/品牌为准 |

包名对不上，就说明你装的是另一个应用：功能定位类似，但本文档里的菜单名、工具位置、权限清单都不适用，别按本文档的步骤去它的界面里找。

## 三、几个不用查包名也能分辨的地方

| 线索 | speedtest5g 的表现 |
| --- | --- |
| 界面语言 | 默认就是简体中文，不需要切换 |
| 开发者署名 | 诺基亚通信系统技术（北京）有限公司 |
| 官方入口 | 官方站点 [app.speedtest5g.cn](https://app.speedtest5g.cn/)，同时提供安卓 App 与微信小程序 |
| 应用商店页面 | [应用宝上的 speedtest5g 详情页](https://sj.qq.com/appdetail/cn.nokia.speedtest5g) |

如果某个"测速"应用的开发者是个没听过的个人账号，又找不到对应的官网，那基本可以确定不是这一款。

## 四、不同测速软件的数字为什么对不上

这是最常被问到的一类问题，答案不是"有一个在骗你"，而是**它们测的根本不是同一条路、同一个条件**。Ookla 在其官方帮助里明确写过这一条：不同的测速服务用的服务器位置不一样，出现速度差异很正常。造成差异的主要是这几项：

| 差异来源 | 具体影响 |
| --- | --- |
| 测速服务器不同 | 换成不同城市、不同运营商的节点，结果能差一倍 |
| 并行连接数不同 | 有的工具同时开多条连接压满带宽，有的只开一条，高速宽带下后者吃亏 |
| 测试时长不同 | 时间短的还没跑出稳定值就结束了，结果偏低 |
| 走的线路不同 | 有的绕自家 CDN，有的走通用节点，被运营商的调度策略影响不一样 |
| 单位不同 | 一个显示 Mbps、一个显示 MB/s，看着差 8 倍 |

所以**跨应用比绝对值没有意义**。同一台手机、同一个位置、同一个时刻，两个应用给出一百多和三百多的差值，都属于正常范围。

## 五、想对比，就固定一个应用比

要判断"我家网络这周是不是变慢了"这类问题，需要的是趋势，不是绝对值：

1. 选定一个应用，只用它测（本文档对应的应用在 [下载与安装教程.md](下载与安装教程.md) 有安装说明）。
2. 固定位置、固定服务器、固定时段。
3. 每次测 3 遍取中间值，把结果留在历史里做对比（方法见 [测速记录与网速排名怎么看.md](测速记录与网速排名怎么看.md)）。
4. 拿同一应用不同时间的结果比，不要拿两个应用同一天的结果比。

至于"哪个更准"这个问题，没有权威的横向结论可以引用，本文档也不替你下判断。实际可操作的做法是：用你能固定条件重复测量的那一个，并且认准它自己的历史曲线。
