## 一、测速测的是"你到那台服务器"这一段

每一次测速，都是你的手机和某一台测速服务器之间来回传数据，量出这段路上的速率和延迟。所以换一台服务器，结果就会变——变的这部分来自服务器所在的位置、它当时有多少人在用、以及它和你之间绕了多少跳，跟你家宽带或手机套餐本身没关系。

应用默认是**自动挑选**：综合你所在的位置和服务器当时的响应情况，挑一台通常比较快的。结果页一般会显示本次用的是哪台服务器、在哪个城市，测完顺手看一眼这一行，后面所有对比都要靠它。

列表里的服务器来源不止一种：有的由测速平台自己部署，有的由运营商或机房托管。华为在其官方支持页面里给的选点建议是"选择同一运营商的、离你最近的测速节点可以得到更准确的结果"——因为同运营商的节点通常更接近你日常上网真实走的那条出口路径。自动挑出来的那台如果不是同运营商，按下面第二节的方法手动换一下再对比。

## 二、这几种情况需要手动换

| 情况 | 为什么要换 |
| --- | --- |
| 结果比预期低很多，且反复如此 | 先换一台对比，排除"只是这台服务器当时忙" |
| 结果里服务器所在地离你很远 | 数据绕路，测出来的延迟和速率都不代表本地网络 |
| 想验证某个具体服务快不快 | 换成对应地区的服务器测，比测就近服务器更接近真实场景 |
| 几次结果忽高忽低 | 固定同一台服务器再测，才能判断波动来自网络还是来自服务器 |
| 自动挑中的服务器不是你家运营商 | 同运营商、同城的节点更接近你真实上网的路径 |
| 自动选择一直卡着不动 | 手动指定一台，绕过自动挑选这一步 |

## 三、怎么换

1. 打开应用，进到测速页，找到显示当前服务器名称/城市的位置，点进去。
2. 在服务器列表里选一台。列表里通常能看到服务器名称、所在城市和距离。
3. 想缩小范围时，按城市或运营商筛选，选一台地理上离你近的。
4. 返回测速页，确认显示的服务器已经是你选的那一台，再点开始测速。

选完之后要**连续用同一台测 3 次**再看结论。中途换服务器，之前那几次就不能和后面的混在一起比了。

## 四、用两台服务器做对照

只换一个变量、其他全不动，是排查时最值得先做的一次对照：同一时间、同一位置、同一台设备，只换服务器。

| 对照结果 | 说明什么 | 下一步 |
| --- | --- | --- |
| 两台服务器结果都低 | 问题大概在你的接入网络这一段（信号弱、时段拥堵、路由器） | 换位置或时段再测，见 [测速不准和结果波动怎么排查.md](测速不准和结果波动怎么排查.md) |
| 只有一台低、另一台正常 | 是那台服务器当时的负载或路由问题，不是你的网络 | 把慢的那台从常用服务器里换掉即可 |
| 两台都正常，但访问某个网站慢 | 瓶颈在那个网站自己的服务器或它到你之间的线路 | 与测速无关，不必再调网络设置 |

对照时记得两次测量的间隔要短，中间不要走动、不要切 Wi-Fi。想让结论更稳，可以把两次的结果都留在历史记录里，见 [测速记录与网速排名怎么看.md](测速记录与网速排名怎么看.md)。

## 五、关于服务器，两个容易想歪的点

- **就近不等于一定最快。** 距离近只是"通常"更快，实际走的线路由运营商决定，绕远路的近距离服务器确实存在。所以最终以实测为准，别只看地图上的直线距离。
- **换服务器改不了你的套餐上限。** 服务器只是改变"测哪条路"，不会让带宽变大。如果所有服务器测出来都远低于套餐标称，方向就该转到线路或设备本身，而不是继续换服务器。
