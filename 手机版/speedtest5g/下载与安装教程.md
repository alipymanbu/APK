## 一、先说清这一份是哪个版本

speedtest5g 是一款中文界面的网络测速应用，能测 2G/3G/4G/5G 和 Wi-Fi 的下载、上传、延迟、抖动与丢包，还带一组网络工具。它本身是免费应用，装起来不复杂，真正容易卡住的只有两处：安装包从哪来，以及权限怎么给对。

动手之前，先对着下表确认你手上这一份是不是对的：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | speedtest5g |
| 开发者 | 诺基亚通信系统技术（北京）有限公司 |
| 运营方 | 福建福诺移动通信技术有限公司 |
| 包名 | cn.nokia.speedtest5g |
| 版本号 | 2.2.9 |
| 安装包大小 | 24.76 MB |
| 安装包 MD5 | 7D3C2C7D86B25AC21B941620800703A2 |
| 适用设备 | 安卓手机、安卓平板 |
| 是否需要联网 | 测速、诊断、看排名全程都要网络；只有翻历史记录可以离线看 |

**版本号别拿别处的来对。** 你在搜索结果里看到的版本号，多半是官方当前的最新版，和这一份不是同一个包。判断"我装的对不对"只看两项：包名是不是 `cn.nokia.speedtest5g`，版本号是不是 `2.2.9`。搜索"测速"会出来一堆名字相近的应用（Speedtest、测速网等），它们和这一款没有关系，分辨方法见 [同名测速软件怎么区分.md](同名测速软件怎么区分.md)。

**这里不写死最低系统版本。** 各家第三方页面标注的最低安卓版本互相矛盾（从 4.5 到 5.2 都有人写，而"安卓 5.2"本身就不是一个正式的系统版本号），都不是官方口径。最省事的判断办法就是直接装：能正常装上并打开，就说明你的系统版本够用；真装不上时系统会在安装阶段直接拦下来，不会装到一半坏掉。想先看一眼官方信息，可以打开[应用宝上的 speedtest5g 详情页](https://sj.qq.com/appdetail/cn.nokia.speedtest5g)核对版本号、更新时间与权限清单。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享。相比在搜索结果里随手点一个"立即下载"，从网盘转存再下载的好处是：这一份链接固定，文件不会被下载站中途替换成别的东西。

1. 在手机上打开 [speedtest5g 安装文件资源（夸克网盘）](https://pan.quark.cn/s/eccf2d09f46d)。手机浏览器或夸克 App 都能打开，**建议用夸克 App**——浏览器下大文件容易被切后台打断。
2. 点"保存到我的网盘"，把文件转存到自己账号下。转存之后，下载就不再依赖原分享链接还在不在。
3. 进自己的网盘找到这个文件，点下载，等它落到手机存储里。
4. 下完核对两件事：文件名结尾是不是 `.apk`（这一份的名字形如 `speedtest5g_v2.2.9.apk`）；大小是不是 24.76 MB 左右。差得多的，多半是没下完整，删掉重来。

习惯在电脑上操作的话：在电脑端网盘把文件下载下来，再用数据线拷到手机的 `Download` 目录，效果一样；之后从手机的"文件管理"里点它安装即可。

手上有校验工具的话，可以顺手算一遍 MD5，和上表的 `7D3C2C7D86B25AC21B941620800703A2` 比一比。一致说明传输过程没出错，不一致就重新下一遍。不查也不影响安装，这只是多一层保险。

## 三、安装：系统会拦一次，放行即可

这一份是通过网盘分发、手动安装的，不是从手机自带的应用商店里点"安装"装的，所以点安装包时系统会拦一下，提示"不允许安装来自此来源的应用"之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开"文件管理"，进 `Download`（下载）目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的"设置"，打开**允许安装此来源的应用**开关。
   - 部分机型要去"设置 → 应用 → 特殊应用权限 → 安装未知应用"里，找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独给它放行。
3. 回到安装界面点"安装"，等进度条走完。
4. 出现"打开 / 完成"时，先点"完成"。首次启动前把权限一次性理顺，比进去之后反复弹窗省事。

如果系统提示"应用未安装"，通常是两种原因：安装包没下完整（回去核对大小），或者手机上已经装着一个**签名不同**的同名应用。后一种要先卸掉旧的那份再装，卸载会同时清掉本地测速历史，介意的话先看 [测速记录与网速排名怎么看.md](测速记录与网速排名怎么看.md) 里的记录保存说明。

## 四、首次打开要给的权限

第一次打开时，系统会依次弹权限申请。这个应用要权限的目的是为了测出真实网速和识别当前网络环境，不是每项都必须给。各项的用途和建议对照如下（不同版本弹的项目会有增减，以你手机上实际弹出的为准）：

| 权限 | 用途 | 建议 |
| --- | --- | --- |
| 位置信息 | 用来自动挑选就近的测速服务器，并在结果里标注测速地点 | 建议给。拒绝后自动选服务器会受限，只能手动指定 |
| 电话 / 设备信息（有的机型显示为"电话"） | 读取当前运营商和网络制式，结果页要显示"用的是哪家、几 G" | 可给。不给的话运营商那一行可能显示不出来，测速本身照常 |
| 存储 / 读写手机存储 | 保存测速历史、缓存测速过程中的临时文件 | 可给。较新的版本已经不再申请这一项，属于正常变化 |
| 通知 | 测速完成后的提醒 | 可给可不给，只影响提醒 |
| 修改系统设置 / WLAN 状态 | 检测 Wi-Fi 连接状态、切换测速时的网络状态读取 | 可给，属于测速过程要用到的读取类权限 |

一个实际会遇到的情况：权限弹窗点快了、误点了"不允许"，之后进测速页可能一直停在"正在选择服务器"或测不出运营商。这时不用重装，去系统设置里把对应权限改回"允许"就行。

## 五、装完先做三步自检

不用急着挑网络测，先花一分钟确认这三件事，后面出问题也好定位：

1. **能打开、不闪退**：点图标能进到主界面，看到正中间那个开始测速的按钮。反复闪退的话，多半是安装包不完整，重下一遍再装。
2. **能选到服务器**：点开始测速，看界面有没有走到"正在测延迟 / 正在测下载"这一步。一直卡在选服务器，先照 [测试服务器怎么选.md](测试服务器怎么选.md) 换成手动指定再试。
3. **能出完整结果**：测完能看到下载、上传、Ping 三个数。数好不好看先不管——第一次测出来的数受环境干扰最大，怎么看才靠谱见 [测速结果怎么看.md](测速结果怎么看.md)。

三步都过，就可以正常用了。测速之外，这个应用还有网络诊断、边走边测、游戏测速这些工具，入口和用法见 [网络诊断与游戏测速怎么用.md](网络诊断与游戏测速怎么用.md)。

自检时如果用移动数据测速，注意它走的是真实流量，量级与你的带宽成正比，先看一眼 [测速会消耗多少流量.md](测速会消耗多少流量.md) 再决定在哪测。

- **应用商店**：在[应用宝的 speedtest5g 详情页](https://sj.qq.com/appdetail/cn.nokia.speedtest5g)可以查看当前版本号、更新时间与官方声明的权限清单，用来核对信息最方便。
- **官网**：官方站点是 [app.speedtest5g.cn](https://app.speedtest5g.cn/)，首页提供"安卓 APP"和"微信小程序"两个入口，并附有微信公众号。
- **不想装 App**：同一个官方入口提供微信小程序版，测速这一件事在小程序里也能做；适合只在临时需要时测一下、不想常驻一个应用的人。小程序端的用法差别见 [测速记录与网速排名怎么看.md](测速记录与网速排名怎么看.md)。

安装包只从网盘这一条链接取，不要在搜索结果的"高速下载器"里点——那类页面经常中途塞进别的东西。

## 七、升级与卸载要注意的

- **升级**：新版本会换一个安装包文件名（形如 `speedtest5g_v版本号.apk`），直接装新包覆盖即可，一般不用先卸载。
- **卸载**：卸载会连同本地的测速历史一起清掉。想留着历史，先在应用里把结果记录下来或截图，见 [测速记录与网速排名怎么看.md](测速记录与网速排名怎么看.md)。
- **安装包删了**：任何时候都能回到文首那条 speedtest5g 安装文件资源的链接重新取一份；已经转存过的不受原分享影响。
