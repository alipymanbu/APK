## 一、绑定前准备什么

绑定这一步是让手机认到车，三样东西要备齐：

- **17 位车架号**（VIN），去哪找见下一节；建议先抄在纸上或拍张照，别到输入那一步再满车找。
- **手机蓝牙打开**。绑定要用蓝牙连接车辆，公开渠道的使用介绍都提到：绑定时把车辆启动、打开手机蓝牙，让车和手机处在可连接状态。
- **手机网络正常**。绑定要联网核验，弱网下容易卡在最后一步。

另外，1.3.5 版本起应用加入了 NFC 配对功能（见官方 App Store 更新记录），如果你的手机支持 NFC，也可以在绑定页试试这条路径，以实际界面给出的选项为准。

## 二、车架号（VIN）在哪看

车架号是 17 位的字母数字组合，张雪机车和大多数摩托车一样，常见位置有三处，不同车型可能有差异，以你实车为准：

1. **车架本体**：转向柱（车把正下方）或车架显眼处的铭牌/钢印。
2. **座垫或护板附近**：部分车型贴有整车铭牌。
3. **行驶证**：「车辆识别代号」一栏，抄这一处最不容易错。

应用里也支持扫码识别：绑定页的输入框旁有扫码图标，直接对准车架号条码扫一下即可，扫完仍要逐字核对一遍字母和数字，`O` 与 `0`、`I` 与 `1` 这类形近字符最容易混。

## 三、绑定步骤

1. 打开 ZXJC，点底部导航栏最右侧的「我的」，进入「我的车库」。
2. 点「绑定车辆」按钮。
3. 在输入框填写 17 位车架号（或点扫码图标扫描车架号），核对无误后点「立即绑定」。
4. 绑定完成后进入「爱车」页面，就能看到车辆定位、骑行里程、轨迹等信息。

如果你有多台张雪机车，都在「我的车库」里绑定后，在「爱车」页点左上角的箭头标识即可切换当前查看的车辆。

## 四、绑定失败怎么排查

按出现环节对号入座：

| 卡在哪 | 先检查什么 |
| --- | --- |
| 蓝牙连不上 | 车辆是否已启动、手机蓝牙是否打开、手机与车的距离是否过远 |
| 提示车架号有误 | 逐字核对 17 位，注意形近字符；确认抄的是行驶证或车架铭牌上的那串 |
| 一直转圈不成功 | 手机网络是否正常；换个网络环境（Wi-Fi / 流量切换）再试 |
| 提示已被绑定 | 1.3.3 版本起绑定会记录「首次绑定人」信息；二手车或别人绑过的车，需要走官方售后处理 |

最后一种情况应用内解决不了，直接通过售后渠道提交工单，渠道与流程见 [车联网续费与售后办理.md](车联网续费与售后办理.md)。

## 五、解绑与换绑

应用内的「我的车库」可以管理已绑车辆，但公开资料里没有可确认的独立「解绑」按钮，解绑类操作按情况处理：

| 情况 | 建议做法 |
| --- | --- |
| 车被你自己以前的账号绑着，账号忘了 | 先在登录页用注册手机号找回旧账号，登进去处理，比走售后快 |
| 二手车，原车主没解绑 | 先联系原车主在其应用里解绑或配合提供信息；联系不上，走官方工单，备好购车发票、过户证明、登记证书与身份证 |
| 提示已被绑定但来源不明 | 不要反复重试，也别信网上「快速解绑」的第三方渠道（这类多为诈骗或钓鱼），直接走工单核实 |

走工单时一次把材料给全（车架号、证件、交易凭证），处理会快很多；渠道见 [车联网续费与售后办理.md](车联网续费与售后办理.md)。

绑定之后车辆就进入日常监控状态，位置、里程、报警提醒怎么用见 [远程控车与防盗报警怎么用.md](远程控车与防盗报警怎么用.md)；如果绑定成功但收不到报警推送，排查步骤在 [常见问题与推送不弹窗排查.md](常见问题与推送不弹窗排查.md)。
