## 一、先看网络：要用外网

昆仑ULink 的下载、安装与登录操作，**要求手机处于外网环境**——用移动数据，或关掉集团 wifi、公司 wifi 再试。连着内网 wifi 时，下载页打不开、登录连不上服务器都是常见现象——排查第一步先切网络，别急着折腾应用本身。

## 二、安装阶段

| 现象 | 处理 |
| --- | --- |
| 点安装包没反应 / 提示禁止安装 | 设置里允许本次「未知来源应用」安装，再点一次安装包 |
| 安装包解析失败 | 文件可能没下完整，重新下载（本地包见 [下载与安装教程.md](下载与安装教程.md)） |
| 提示版本过旧或与系统不兼容 | 确认系统为安卓 5.2 以上；过旧的包换新版本装 |

## 三、首次启动与权限

首次打开时那一串授权（文件、相机、麦克风、摄像头）**必须全部允许**。当时点了拒绝，症状会在后面才冒出来：

- 扫码扫不了 → 补相机权限；
- 语音对讲、网络电话没声 → 补麦克风权限；
- 打卡打不上、图片传不上去 → 补文件访问权限。

补救路径：系统设置 → 应用管理 → 昆仑ULink → 权限，全部打开后重启应用。

## 四、登录阶段

- **提示密码错误**：先按 [员工编号登录与密码修改.md](员工编号登录与密码修改.md) 核对默认密码规则；用过默认密码的确认是否已完成强制改密；注意区分大小写、别误触多余字符。
- **收不到验证码**：短信验证依赖集团登记的手机号，换网络环境重试一次，仍收不到就找本单位用户管理员。
- **账号被锁 / 反复失败**：停止重试，直接联系支持人员，别再试错放大锁定时长。
- **版本过旧被拒**：公开材料提到版本过旧也会导致登录异常——先按 [下载与安装教程.md](下载与安装教程.md) 换新包装上再试。
- **怎么都不行 → 清缓存重装（最后手段）**：系统设置 → 应用管理 → 昆仑ULink → 存储 →「清除缓存 / 清除数据」，再重新登录；仍无效就卸载重装（安装包见 [下载与安装教程.md](下载与安装教程.md)）。**清数据会退出登录态**，重装后要重新走一遍登录；子应用的登录态也会跟着失效，装完按下一节的顺序重新登。

## 五、装错应用：昆仑智联不是昆仑ULink

集团名下还有个「昆仑智联」（以及它的私有化版本），它与昆仑ULink 是两套东西：登录方式、下载入口都不一样（昆仑智联私有化版走注册手机号登录、从集团移动应用平台的商店里装）。你如果装的是昆仑智联却输员工编号，或拿着昆仑ULink 的安装包找昆仑智联的客服，都是对不上号的——先看手机上那个图标的名称与包名是不是 `cn.com.cnpc.ulink`。

## 六、子应用（石油年金、安全令等）点不动

子应用依赖昆仑ULink 的登录态。如果你先打开了子应用、昆仑ULink 那边没登录，会跳到昆仑ULink 登录页；登录完成**需要回到子应用再点一次登录**才会进首页。顺序就一句话：先把昆仑ULink 登好，再去装和开子应用。

## 七、实在解决不了：找谁

1. **应用内反馈**：登录昆仑ULink → 「系统设置」→「用户反馈」提交问题（这是官方给的渠道，能在里面登进去就优先用它）；
2. **客服热线**：`4008800114`（集团统一身份认证与相关系统的支持电话）；
3. 与具体业务挂钩的应用（如石油年金）另有项目组联系方式，按单位群里公布的信息联系。
