tin 是 K-pop 粉丝用来做、收集与装饰数码照片卡（photocard）的手机应用，安卓与 iPhone 都有官方包，开发方是韩国的 STAYGE Labs。本篇只解决一件事：把网盘里这份包装进你的设备，并确认装的是哪一版。

## 一、先核对网盘里这份包是哪一版

各下载站挂的版本号是他们自己写的，而网盘里这份是制作文档时实际核对过的那一个，两者常常对不上。本文涉及的版本、包名、体积一律以这张表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | tin |
| 版本号 | 3.14.0 |
| 包名 | `io.stayge.tin` |
| 安装包体积 | 91.29 MB |
| MD5 | `4C585C36AC7D229EBF68626630C85A32` |
| 适用平台 | 安卓手机／平板 |
| 资料登记的系统要求 | 「安卓系统 5.2 以上」 |

四点提醒：

- **判断是不是同一个包，看包名 + MD5，不看名字旁边的数字。** 同一个 APK 在不同站点会被写成不同版本号，体积也常被四舍五入。
- **「tin」这个名字太短，重名应用不少。** 名字对上不算数，包名 `io.stayge.tin` 对上才算；官方应用的全名是 tin - Kpop Photocards。
- **应用免费下载，但含 App 内购买**（官方商店条目标注为「免费」+「App 内购买」，以商店页面为准）。本文这套安装与下图流程本身不涉及付费。
- **上面这份系统要求别当真。** 安卓并没有 5.2 这个正式版本号，这是登记资料的写法问题，不是准数。装上能正常打开就说明你的设备可以，没必要为这个数字反复折腾。

## 二、安卓：装网盘里这份 APK

1. **先转存再下载**：打开 [tin 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d42a09fe3a45)，把 APK 转存到你自己的网盘，再下载到手机。转存这一步别省 —— 分享链接失效后，只有转过存的文件还能找回来。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器、浏览器或网盘客户端）打开开关，再点 APK 安装。
3. **签名冲突就先卸载旧的**：手机里若已装着同包名、但签名不同的版本，覆盖安装会直接失败并提示「应用未安装」。先把旧的卸掉再装这份。
4. **同包名只能留一个**：装这份会覆盖同包名的旧版本，想保留旧版就别装。

官方自己的安卓包挂在 Google Play 上（条目 `io.stayge.tin`），能正常访问商店的话也可以从那里装；网盘这份的好处是不依赖商店、随时可取。两条路的包名一致，装哪个都是同一个应用。官方站点是 [www.tin.cards](https://www.tin.cards/)，应用内功能与规则的官方说明也可以在那里找到入口。

## 三、iPhone / iPad：走 App Store

**网盘里这份是安卓 APK，iPhone 装不了**，两个系统的安装包格式不同。苹果设备请到 App Store 搜 tin（条目全名 tin - Kpop Photocards）安装。商店分区不同可能搜不到，这属于商店分区问题，不是应用本身的问题。

## 四、第一次打开要做什么

首次启动会让你选登录方式，再挑本命艺人。第一次用建议按这个顺序走一遍：

1. 先用**不注册的方式**进去（启动页的 Continue without signing up），把 Play 与 Decorate 各点一次，确认功能能正常打开；
2. 决定长期用之后，**用邮箱注册** —— 在游客状态下注册时，已经收集到的卡、帖子和评论会自动转到新账号；
3. 到卡册里确认刚刚收集的卡确实在里面。

不注册能用哪些、不能用哪些，有明确的边界，见 [第一次打开要设置的几项.md](第一次打开要设置的几项.md)。

## 五、装完做一次最小验证

打开后进 Play（剪影猜卡）随便点一张，能看到剪影图并弹出上传照片的入口，就说明安装没问题。这一步卡住时按现象分头处理：

- 能打开但一直转圈、列表空白 → 多半是网络，见 [常见问题与排查.md](常见问题与排查.md)；
- 想先搞清楚手里的卡是怎么来的 → 见 [怎么获得照片卡.md](怎么获得照片卡.md)。
