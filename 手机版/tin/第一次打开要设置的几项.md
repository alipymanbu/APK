首次启动的那几个选项会决定你后面能不能自制卡、能不能赚扫描仪，选错了回头改比较麻烦。本篇按启动顺序讲每一步怎么选，以及游客模式与注册账号的实际差别。

## 一、启动后的三个选项

按屏幕出现的顺序：

1. **登录方式**：可以「用邮箱注册」，也可以点 **Continue without signing up** 先不注册进去。两条路都能进主界面，差别在下一节。
2. **同意条款**：服务条款与隐私政策需要勾选同意才能继续，没有「只看不勾」的入口。想先看过正文再决定，可以去官方帮助中心（[help.stayge.io](https://help.stayge.io)）把条款读完再回来。
3. **挑本命艺人**：从列表里选你关注的组合与成员，可以多选。选中的会进首页与卡册分区。

## 二、游客模式能做与不能做

不注册就能用，但功能有边界。官方帮助中心给的范围是：

| 能做 | 不能做 |
| --- | --- |
| 收集本命艺人的照片卡 | 看奖励广告赚扫描仪 |
| 玩 Shuffle（随机浏览艺人照片卡） | 创建新照片卡 |
| 查看艺人排行榜 | 发送 / 分享照片卡 |
| 给别人的帖子点赞、评论、回复 | 举报或屏蔽其他用户 |
| 发帖与礼截图（上限 10 条） | 修改资料（昵称、头像等） |

游客账号是**临时的**：**退出登录或删除应用，游客期间的一切都会永久丢失，且无法找回**。所以有两个节点要留意：

- 打算长期用就别拖，早点用邮箱注册；
- 注册时机随时可以：**在游客状态下用邮箱注册，已有的卡、帖子、评论会自动转到新账号**，不用从头再来。

## 三、账号体系与跨应用

tin 的账号走 STAYGE 的统一登录（STAYGE ID），同一套账号也用在同门的投票应用 LiNC 上。这一点在扫描仪那边有实际用处 —— **同一个账号登录后，粉丝点数（Fan Points）在 tin 与 LiNC 之间自动同步**，在一边赚的可以在另一边花，见 [扫描仪与粉丝点数怎么算.md](扫描仪与粉丝点数怎么算.md)。

所以注册时有一个动作值得做对：**邮箱填你已经在用 LiNC 的那个**。两个应用账号对不上，攒的点数就不会归到一起。

## 四、语言与通知

**界面没有中文** —— 官方商店条目标注的支持语言是英语与韩语（以商店页面为准），菜单与设置项不会被翻译，能用翻译功能读的是**别人发的内容**（3.16.0 起）。不熟悉英文界面的话，先把这几个高频词记住，找起来就不费劲：

| 界面上的词 | 对应什么 |
| --- | --- |
| Feed / My Post | 别人的动态 / 自己发过的帖子 |
| Create / Play | 做照片卡 / 猜剪影拿卡 |
| Decorate / Case | 装饰卡 / 卡册 |
| Fan Points / Scanner | 粉丝点数 / 扫描仪 |

另外两件：

- **艺人名搜索**：3.22.0 起支持用韩语搜艺人名；3.21.0 起官方发布的帖子会自动翻译成你的应用语言，3.16.0 起别人发的帖子、评论、回复也能一键翻译。
- **通知**：排名类的实时通知在 3.22.0 里已不再发送；想盯排行榜就直接进首页看，首页有实时 Top 10 排行。

## 五、本命艺人不在列表里怎么办

列表里找不到你要的艺人时，官方给的路径是**通过登记表单提交**，由官方加进列表，应用里不能自己手动添加。表单入口在官方帮助中心的对应条目里。提交后到列表更新为止的这段时间，该艺人的 Play 与 Create 都用不上。

列表更新还可能影响手里的卡：遇到成员变动时，官方会把相关旧卡统一归到卡册的 Others 分组，这个分组怎么看见 [卡册收纳与装饰怎么玩.md](卡册收纳与装饰怎么玩.md)。
