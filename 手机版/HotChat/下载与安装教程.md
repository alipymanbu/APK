## 一、先确认手机能不能装

HotChat 是安卓端应用，安装前对一下下面这几项（以网盘里这份安装包的事实为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.3 |
| 包名 | `com.hotchatai.roleplaywithairoles` |
| 安装包大小 | 67.61M |
| 系统要求 | 安卓 5.2 及以上 |
| MD5 | `56206B00A18B127944EC4FDBAB0F60A1` |

两点注意：

- 系统低于安卓 5.2 的手机装不上，安装器一般会直接报错；
- 下载前看一下存储空间，安装包本身 67.61M，解压安装还要额外占用，建议至少留出 500M 空闲。

## 二、获取安装包

1. 打开 [https://pan.quark.cn/s/0fe9ebee043d](https://pan.quark.cn/s/0fe9ebee043d)（这是 **HotChat 安装文件资源（夸克网盘）**），把应用保存到自己的网盘；
2. 在网盘里找到 `HotChat_v1.0.3.apk`，下载到手机；
3. 下载完成后可以顺手核对一下 MD5 是否为 `56206B00A18B127944EC4FDBAB0F60A1` —— 不一致说明文件在传输中损坏了，重新下载即可（Windows 上可用 `certutil -hashfile 文件名 MD5` 查看，手机上可用任意校验工具）。

另外，网上叫「HotChat」的下载页不止一个（同名的即时通讯应用、网页端平台都存在），拿不准时认准包名 `com.hotchatai.roleplaywithairoles` —— 包名对不上就不是这一款。

## 三、安装步骤

1. 用手机自带的文件管理器找到刚下载的 `.apk` 文件，点它；
2. 系统会弹出「不允许安装来自此来源的应用」之类提示时，按提示进入设置、打开「允许安装未知应用」（不同品牌手机的叫法略有差别，如「安装未知应用」）；
3. 返回继续安装，等进度走完点「打开」；
4. 首次打开需要联网，加载完欢迎页就能直接用 —— 不注册也能先开始聊天。

## 四、装不上 / 安装报错排查

按出现的现象对号入座：

| 现象 | 怎么处理 |
| --- | --- |
| 提示「解析包时出现问题」 | 多半是下载不完整或包损坏：核对 MD5 后重新下载 |
| 提示「应用未安装」 | 先卸载手机里的旧版 HotChat（同包名升级冲突），再装新的 |
| 提示「安装被阻止」 | 按上一节打开「允许安装未知应用」后重试 |
| 提示「存储空间不足」 | 清出至少 500M 空闲空间再装 |
| 提示版本过低 / 不兼容 | 手机系统低于安卓 5.2 时无法安装，这台设备用不了这个包 |

装好之后如果遇到闪退、打不开等问题，直接看 [常见问题与闪退排查.md](常见问题与闪退排查.md)；第一次上手怎么点，看 [新手怎么用.md](新手怎么用.md)。
