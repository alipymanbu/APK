## 一、三个高频问题

**1. 必须注册才能用吗？**
不注册也能直接开始聊天。注册的价值在于数据：对话记录和你自己创建的角色跟着账号走，不注册就只留在当前设备上。细节见 [新手怎么用.md](新手怎么用.md)。

**2. 可以聊中文吗？**
可以。平台默认主打英文用户，但 AI 对多种语言都有支持 —— 你用中文发消息，它就用中文回。界面语言在个人中心的「切换语言」里切，具体中文表现以你实际对话为准。

**3. 是完全免费的吗？**
不是。基础文字聊天免费，更高级的 AI 模型、无限消息额度、更长的角色记忆这类进阶功能走订阅付费。是否订阅看你自己的需要 —— 网上第三方页面给的价格口径互相矛盾（有的写每月 7.99 美元与 22.50 美元两档，有的写 8~30 美元区间，还有的明说「价格未核实」），且未必对应安卓端，**一律以应用内订阅页显示为准**。

## 二、打不开 / 闪退的排查顺序

按顺序做，做到哪一步好了就停：

1. **强停止后重开**：设置 → 应用 → HotChat → 强制停止，再重新打开；
2. **清缓存**：同一位置进「存储」，先只清缓存（不会丢聊天记录），再试；
3. **检查网络**：在 Wi-Fi 和移动数据之间切换一次 —— 这款应用必须联网才能用，网络不通时表现为一直转圈或直接退出；
4. **检查存储空间**：手机剩余空间不足会让应用闪退，清出至少 500M 再试；
5. **检查权限**：在应用权限里确认没有禁掉存储等必要权限；
6. **清除数据**：仍然闪退就清一次数据（**会删掉本机的聊天记录与本地角色**，介意就先注册登录或提前备份）；
7. **卸载重装**：最后用 [下载与安装教程.md](下载与安装教程.md) 里的安装包重装一遍。

## 三、其他典型现象

| 现象 | 原因与处理 |
| --- | --- |
| 打开一直加载、消息发不出去 | 先确认网络能正常上网；网络正常但持续失败，可能是服务端在维护，换个时间段再试 |
| 装的时候提示「解析包时出现问题」 | 安装包下载不完整，回 [下载与安装教程.md](下载与安装教程.md) 核对 MD5 重新下载 |
| 装完点开就闪退、装不上新版 | 手机系统需为安卓 5.2 及以上；同包名旧版残留会导致「应用未安装」，先卸载旧版再装 |
| 装完发现界面跟本篇描述完全对不上 | 搜「HotChat」能搜到好几个**同名不同应用**（比如一款 195M 左右的即时通讯类 HotChat、以及网页端平台），包名不是 `com.hotchatai.roleplaywithairoles` 就不是本文档说的这个；本篇只对这个包负责 |
| 换手机后角色和记录不见了 | 对话记录与自定义角色默认留在原设备，登录账号可随账号保留；换机前先确认已登录 |
| 语音 / 配图功能找不到 | 相关入口在对话界面内，随角色与版本不同可能位置有别，以界面实际显示为准 |

## 四、版本说明

网盘里这份安装包是 **1.0.3**（67.61M，包名 `com.hotchatai.roleplaywithairoles`）。官方后续会更新版本，你看到的功能与界面若与本篇描述有出入，以应用内实际显示为准；要拿新版本时同样先核对包名，避免装成同名的其他应用。
