## 一、安装前先核对这几项

你拿到手的安装包是 1.0.0 版，基础信息如下：

| 项目 | 内容 |
| --- | --- |
| 应用名称 | Mindkit |
| 版本 | 1.0.0 |
| 安装包大小 | 约 77.35 MB |
| 包名 | com.mdbj.zzh |
| MD5 | 5B5FDFF7B1EBA76B745C1C662EEC9665 |
| 开发者 | 深圳市霖云上科技有限公司 |
| 系统要求 | 安卓 5.x 及以上（标注为 5.2 以上，以安装时系统提示为准） |

两点说明：

- 这款应用在应用宝已有更新的 1.0.2 版（2026 年 1 月更新，以商店页面实时显示为准）；网盘里是 1.0.0 版，两个版本的功能差异没有公开的更新说明可查，以实际安装后的表现为准。想直接装商店版，走[应用宝的 Mindkit 页面](https://sj.qq.com/appdetail/com.mdbj.zzh)。
- 装的时候如果报「签名不一致」之类的错误，通常是手机里已经装过另一个同包名的版本，先卸载旧的再装，详见[常见问题解答](常见问题解答.md)。

## 二、从网盘获取安装文件

1. 打开 [Mindkit 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6d67ac226e99)；
2. 把文件转存到自己的夸克网盘（未登录会先要求登录）；
3. 在手机上打开夸克 App，从「我的网盘」里找到刚转存的文件，下载到手机本地存储；
4. 下载完成后在下载列表里点开 apk 文件，进入安装。

网页端也能转存，但后续下载与安装都在手机上操作最方便，建议全程用手机完成。安装包文件名以网盘内实际显示为准（通常形如 `Mindkit_v1.0.0.apk`）。下载完成后看一眼文件大小，应在 77 MB 上下；明显偏小说明没下完，删掉重下，省得装的时候报错。

## 三、允许安装未知来源的应用

安卓 8 及以上，每个「来源」（浏览器、网盘 App、文件管理器）都要单独授权一次：

1. 点开 apk 时系统若提示「不允许安装未知来源应用」，点提示里的「设置」；
2. 打开「允许来自此来源的应用」开关，返回后继续安装；
3. 各品牌手机路径略有差异，也可以手动走：设置 → 应用管理 → 特殊应用权限（或「安装未知应用」），找到你用来下载的那个 App（夸克或浏览器），打开开关。

装完可以把开关关掉，不影响已经装好的应用。

## 四、校验安装包完整性（可选）

如果下载后总是装不上，先核对文件有没有下载完整。把安装包传到电脑上，在文件所在目录执行：

```text
# Windows（CMD 或 PowerShell）
certutil -hashfile Mindkit_v1.0.0.apk MD5

# macOS
md5 Mindkit_v1.0.0.apk

# Linux
md5sum Mindkit_v1.0.0.apk
```

算出的值与本篇开头表格里的 MD5 一致，说明文件是完整的；不一致就删掉重新下载，再装一次。

## 五、装不上时按这个顺序排查

1. 校验文件完整性：按第四节核对 MD5，或直接看文件大小是否在 77 MB 上下；
2. 卸载旧版本：手机里已有同包名应用时，先卸载再装；
3. 清出存储空间：至少留出 1 GB 再试；
4. 确认系统版本：安卓 5 以下的机型装不了这个包；
5. 仍装不上：拿着屏幕上的报错提示，到[安装报错排查](安装报错排查.md)逐条对照处理，或去[应用宝页面](https://sj.qq.com/appdetail/com.mdbj.zzh)确认应用是否仍在正常上架。

装好之后第一次打开怎么用，见[功能与使用入门](功能与使用入门.md)。
