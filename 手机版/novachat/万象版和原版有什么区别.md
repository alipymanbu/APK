# NovaChat 万象版和原版有什么区别

> 搜「NovaChat」会同时搜到万象版和开源原版，两者的使用门槛和安全边界不一样。这篇把区别说清楚，帮你选对要装的那个。

## 一、两者本质差在哪

同一个名字，两条产品线。按渠道公开的口径对比如下：

| 对比点 | 万象版（本篇这套） | 开源原版 |
| --- | --- | --- |
| 使用门槛 | 免登录，打开即用 | 需要自己配置模型接口或 API 密钥 |
| 模型来源 | 内置多套模型通道，应用内切换 | 自备各家服务账号 |
| 形态 | 安卓安装包 | 网页端为主，可自部署 |
| 维护方 | 万物讯联科技（渠道标注） | 开源项目，社区维护 |
| 适合谁 | 想先低成本体验多模型的人 | 重视稳定性、安全性、合规性的人 |

万象版省掉的是配置环节，代价是模型通道不归你管；原版要求你先有可用的服务，换来的是一切数据走你自己配置的接口。第三方渠道给的建议很直接：更在意稳定和合规就选原版开源版（或同类官方免费客户端），万象版当作临时体验的选择。

## 二、如果往万象版里填 API 密钥

这是使用万象版最需要留意的一点，渠道原文的警示是：**不建议填写包含大额余额的 API 密钥**。

实际操作上可以这样做：

- 需要自定义接口时，用小额、可随时作废的密钥；
- 用完即删，不要把主力账号的长效密钥填进去；
- 本地 Ollama 这类不花钱的离线通道没有这个顾虑，进阶用户可以优先考虑。

## 三、别和这些同名产品搞混

搜索引擎里「NovaChat」「Nova」相关结果高度混杂，至少有四个不相干的产品：

| 名称 | 是什么 | 认它的标志 |
| --- | --- | --- |
| NovaChat 万象版 | 本文的安卓端多模型对话应用 | 包名 `xunlian.Nova.Ai.apk1` |
| Nova AI Chatbot | 订阅制聊天助手（约每月 30 美元档） | 应用市场上开发者为 Scaleup，带内购 |
| NovaChat（开源项目） | 网页版聊天前端，需自配接口 | 项目站点域名形如 `novachat.rxliuli.com`，提供插件列表 |
| Nova Chat: Meet AI Soulmate | AI 虚拟角色陪伴聊天 | 主打「AI 角色 / 伴侣」 |

判别方法只有一个：看安装包的包名和来源。安卓端、包名 `xunlian.Nova.Ai.apk1` 的才是本篇文档对应的这套；其余的付费方式、登录要求和功能形态都不同。

## 四、已经装了万象版，还要注意什么

- 版本更新节奏快，跨版本行为可能有差异，重要用法先在低风险对话里试一遍；
- 对话记录默认存本地，涉及敏感信息改用无痕会话（见 [人设定制与对话管理.md](人设定制与对话管理.md)）；「数据只存本地」这句话的两面性，在 [聊天记录存在哪和隐私注意事项.md](聊天记录存在哪和隐私注意事项.md) 里有展开；
- 遇到回复失败、安装报错，按 [常见问题解答.md](常见问题解答.md) 的顺序排查。
