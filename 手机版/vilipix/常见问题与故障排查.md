## 一、先按顺序做四件通用检查

多数故障由下面四类原因引起，先各查一遍，能省掉大量盲目尝试：

1. **网络**：换个 Wi-Fi 或切到流量，看首页能否刷出图；路由器重启一次。
2. **版本**：安装包过旧可能与服务端对不上，用 [下载与安装教程.md](下载与安装教程.md) 里的方式核对当前版本，再决定是否更新。
3. **存储空间**：手机剩余空间不足会导致应用卡死、图片保存失败，清理一批不用的文件再试。
4. **账号状态**：退出后重新登录，能解决一部分「明明有网却没反应」的情况。

## 二、打不开 / 一直转圈 / 说服务器崩了

按出现频率排：

| 症状 | 先做什么 |
| --- | --- |
| 首页空白、一直加载 | 换网络重试；确认不是当前网络屏蔽了图片域名 |
| 提示错误或频繁失败 | 等几分钟再开，服务端抖动时重试比反复杀进程有效 |
| 打开就闪退 | 清应用缓存；仍闪退则重装（包信息核对见 [下载与安装教程.md](下载与安装教程.md)） |
| 只有图片不显示 | 多半是网络或存储空间，回到本篇第一节的 1、3 |

反复出现同一错误时，记录下提示原文，比口头描述「用不了」更容易定位。

## 三、闪退、无响应再往下查

上面四件都排除了仍闪退，按顺序往下走（各品牌安卓的通用做法）：

1. **强制停止后重开**：长按应用图标 → 应用信息 → 强制停止，再打开。
2. **先清缓存**：应用信息 → 存储 → 清理缓存。缓存只存临时文件，清掉不丢登录状态。
3. **再清数据**：同一入口的「清除数据」会删登录状态与本地设置 —— **清之前先确认记得账号、已绑定微信**，否则要重新登录。收藏存在账号里，清数据不会丢。
4. **查权限有没有被禁**：部分机型禁用某项权限会直接闪退，到「应用信息 → 权限」里逐项打开。
5. **留足空间**：运行内存与存储不足都会引发无响应，建议存储保持 20% 以上余量，并清掉后台程序。
6. **系统兼容**：手机刚升过安卓大版本的话，老版本应用可能不适配 —— 换一台同安卓版本的手机对比，若别台正常就是兼容问题，等新版安装包（当前可用版本见 [下载与安装教程.md](下载与安装教程.md)）。
7. **卸载重装**：以上都不行再走这步，会清掉本地数据，注意事项同第 3 条。

在电脑模拟器里出现的闪退与卡顿，多半是模拟器环境（虚拟化、安卓版本）引起的，先看 [电脑上怎么用.md](电脑上怎么用.md) 第三节。

## 四、图片保存失败或相册里找不到

1. 保存时弹出的权限申请选了「拒绝」，图片就不会写进相册 —— 到「设置 → 应用管理 → vilipix → 权限」里把存储/相册权限改为允许，再重存一次。
2. 手机空间不足会导致静默失败，先清理空间。
3. 保存路径在系统相册（多在「下载」分类下），按时间倒序翻；仍没有就是那次下载中断了，重新长按保存，操作见 [保存图片与设置壁纸.md](保存图片与设置壁纸.md)。

## 五、账号与资料设置

**绑定微信**（换设备后免输账号）：

1. 首页点「我的」；
2. 进「设置」；
3. 点「账号管理」；
4. 选「绑定微信」；
5. 在授权页点「允许」。

**设置个人主页背景图**：

1. 「我的」→「个人主页」；
2. 点「编辑资料」；
3. 选「背景图」，挑一张（可以就用刚存的插画，见 [保存图片与设置壁纸.md](保存图片与设置壁纸.md)）；
4. 点「完成」。

**登录异常**：提示账号异常或收不到验证码时，先确认网络，再退出重登；仍不行就检查是否装了会拦截短信/网络的工具。

## 六、版本号对不上怎么办

同一款应用在不同下载页上标着不同的版本号（截至 2026-09 能搜到 4.8.8、4.9.8、5.0.0 等说法），页面上的数字不等于你手机里装的。以「设置 → 应用管理 → vilipix」显示的版本为准；要确认某个安装包是什么版本，按 [下载与安装教程.md](下载与安装教程.md) 的 MD5 与大小核对。

## 七、约稿与互动相关

- 「可约稿」页签找不到：换网络刷新，或该画师当前未开放约稿；
- 申请点了没反应：多半是网络中断，退回主页重新进一次再提交，流程见 [向画师约稿流程.md](向画师约稿流程.md)；
- 关注、评论、收藏失败：先确认已登录，再按本篇第一节的四项检查走一遍。

以上办法都试过仍解决的，把「操作到哪一步、提示什么原文、什么网络环境」记下来，比「打不开」三个字有用得多。
