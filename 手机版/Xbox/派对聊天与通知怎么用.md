# 派对聊天与通知怎么用

> 手机上开派对、发消息、接通知：跨主机和电脑跟朋友说话，不用坐在主机前面等消息。

手机上的 Xbox 应用把两件事做在了一起：聊天和提醒。朋友在打什么游戏、什么时候要开派对、谁给你发了消息，都会进到同一个通知列表里；反过来你也能从手机上发起派对，让家里主机上的人一起进来。

## 一、派对怎么开、怎么进

派对是 Xbox 上的语音房间，参与的人在 Xbox Series X|S、Xbox One、Windows 电脑之间可以互通，你人在手机上也能跟主机上的朋友说话。

**加入一个派对**：收到邀请时点通知里的加入；或者在好友列表里点那个正在派对中的好友，选加入。

**自己开一个**：在应用里创建派对，然后把好友邀请进来。派对建好后，主机上、电脑上的朋友都能加。

**说话用哪个麦克风**：手机自己的麦克风就够用；想听得清楚些，把蓝牙耳机连到手机上。用手机开派对时，主机那边的耳机插孔帮不上忙。

发送文字消息也在同一个地方：好友列表点开好友就是一条会话，用手机键盘打字比手柄选字母快得多。群聊同理。

## 二、通知会告诉你什么

登录之后，这些事件都会推到手机的通知栏：

| 事件 | 通知里能做什么 |
| --- | --- |
| 派对邀请 | 直接加入 |
| 好友的消息 | 打开会话回复 |
| 新好友、新关注 | 查看是谁、接受或忽略 |
| 成就解锁 | 看具体是哪个成就 |
| 捕获上传完成、可以分享了 | 直接去保存或分享 |

这些通知是**跨设备同步**的：你在手机上把一条清了，主机上那条也随之清掉，不会出现「两边各留一堆红点」。

## 三、不想被打扰时怎么收窄

接收范围在账号的隐私与在线安全设置里调，可以限制「谁可以给你发消息」「谁可以邀请你加入派对」这类规则，选项通常包括所有人、好友、好友的好友。改完对全部设备生效，不用在每台设备上重复设。

只想去掉系统通知栏的打扰、又不想漏消息的话，更简单的做法是在手机系统里把应用的通知权限关掉——应用内仍然能看到所有消息，只是不再弹提醒。

## 四、收不到通知，逐条排

1. **系统层通知权限没给。** Android 13 及以上，通知是需要在「设置 → 应用 → Xbox → 通知」里单独授予的权限；拒绝过的话一条通知都不会出现。
2. **应用被系统清了后台。** 这是国产定制系统里最常见的原因：应用闲置几天被自动清理后，就不再收推送。要把电池策略改成「无限制」并允许自启动。
3. **在别的设备上已经看过了。** 同一条通知在主机上点开后，手机上不会再有——这是设计如此。
4. **登录状态掉了。** 通知依赖登录态，登录失效期间什么都不会推给你，重登一次即可，处理办法见 [登录与账号问题排查.md](登录与账号问题排查.md)。
5. **应用版本太旧。** 通知与派对的入口会随版本调整，从 [Xbox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/46bd725ef630) 覆盖装一份新的，登录状态通常保留。

第 2 条的入口各家不一样，按你的手机对号入座：

| 品牌 | 要改的地方 |
| --- | --- |
| 小米 / Redmi（MIUI、HyperOS） | 应用管理里打开「自启动」；电池与性能里给该应用选「无限制」；最近任务里把卡片加锁 |
| 华为 / 荣耀（EMUI、HarmonyOS） | 应用启动管理里关掉「自动管理」，再勾上允许自启动、关联启动、后台活动；电池优化里设为「不允许」 |
| 三星（One UI） | 电池 → 后台使用限制：把它从「休眠应用」「深度休眠应用」里移到「永不进入休眠的应用」 |
| OPPO / 一加 / realme（ColorOS） | 电池 → 电池优化 → 该应用 → 「不优化」；关闭「后台冻结」；手机管家里允许自启动 |
| vivo / iQOO（OriginOS） | 电池里允许「后台高耗电」；i 管家里打开自启动；多任务界面加锁 |

菜单名会随系统版本调整，找不到就在设置里搜「电池优化」「自启动」「后台」这几个词。

## 五、聊天里的图片和片段从哪来

在会话里发截图或游戏片段，内容取自主机的捕获库。所以发不出去时，问题往往不在聊天，而在主机那一侧的上传设置——先把自动上传打开，内容才会出现在应用里。完整链路见 [截图与游戏剪辑保存到手机.md](截图与游戏剪辑保存到手机.md)。派对能建、消息发不出，或者对方一直听不到你，多半落在网络与权限上，对照 [常见问题与排查.md](常见问题与排查.md) 看一遍。
