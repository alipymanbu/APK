# 云游戏和远程游玩有什么区别

> 两个功能名字看着像、入口也在同一个应用里，但它们跑在不同的机器上，条件、成本、适用场景完全不同。

把这两个搞混，最常见的后果是：明明家里没有主机，却一直在找「远程游玩」的入口；或者明明有主机，却为了在手机玩去开了个订阅。下面按「谁在跑游戏」这一条主线把两者分开。

## 一、一句话区别

| | 远程游玩（Remote Play） | 云游戏（Xbox Cloud Gaming） |
| --- | --- | --- |
| 游戏跑在哪 | **你自己家里的主机** | 微软数据中心的服务器 |
| 需要主机吗 | 需要，且必须是 Series X\|S 或 Xbox One | 不需要主机 |
| 需要订阅吗 | 不需要 | 需要含云游戏的 Game Pass 方案 |
| 能玩哪些游戏 | 主机上已安装的，你自己的库全算 | 云端支持的游戏，包括 Game Pass 库与可串流的部分自有游戏 |
| 占用家里主机吗 | 占用，电视上的画面与你同步 | 不占用 |
| 网络要求 | 官方建议 5 GHz Wi-Fi 或移动数据 10 Mbps 下载 | 官方建议至少 20 Mbps |
| 画面上限 | 约 1080p / 60 帧，4K 不支持 | 约 1080p / 60 帧，分辨率会随网络波动 |
| 输入延迟（量级） | 局域网 20~50 ms，跨网络 80~150 ms | 60~120 ms |

最后两行是第三方实测汇总的量级，官方产品页不承诺具体数值，会随你的线路、地区与设备变化。

## 二、云游戏需要准备什么

- **一个 Game Pass 订阅。** 官方 2025 年底的说明里，云端串流已经包含在 Game Pass Essential、Premium、Ultimate 三个方案内，不再只限最高一档。方案名称、价格和包含范围会变，以官方 Game Pass 页面当时显示的为准。
- **系统版本。** 应用本身在 Android 8.0 以上就能装，但**云游戏这一项官方写的是 Android 12.0 及以上**，两个数字不是一回事，别拿前者去推后者。
- **网络。** 官方建议至少 20 Mbps，能用网线或 5 GHz Wi-Fi 就别用 2.4 GHz；移动数据能跑，但流量吃得快。
- **输入方式。** 大部分云游戏需要手柄，一部分游戏提供触屏控制。没手柄也能玩，但可玩的池子会小一圈。
- **手机上的 Xbox 应用**：包从 [Xbox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/46bd725ef630) 或官方商店渠道获取，登录同一个微软账号。

## 三、从哪进去

两条入口，效果一致：

1. **应用内**：安卓版 Xbox 应用登录后，游戏库与 Game Pass 列表里在云端的游戏会带串流入口，点开就是在云上跑。
2. **浏览器**：手机浏览器打开 [xbox.com/play](https://www.xbox.com/play)，登录后同样是云端游戏库。iOS 上官方推荐的就是这条网页路径，Safari 里可以「添加到主屏幕」，用起来接近一个应用。

界面文字会随版本调整，找不到入口时先在游戏库和 Game Pass 列表里找带云端标记的游戏，而不是在主界面上找按钮。

顺带说清一个已经消失的东西：微软早年有一个单独的 **Xbox Game Pass 移动应用**，2024 年 11 月起官方已停止它的新下载，功能都并进了 Xbox 应用。网上还留着「先装 Game Pass 应用」这类旧教程，照做会白折腾——官方这一组应用分别叫什么、包名是什么，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 四、什么时候该用哪个

| 你的情况 | 更合适的 |
| --- | --- |
| 家里有主机，只想换个房间玩 | 远程游玩，不花钱，画质取决于家里网络 |
| 人在外地，想接着玩家里的存档 | 远程游玩（主机保持睡眠并联网） |
| 没有主机，想玩主机游戏 | 云游戏 |
| 家里电视被占，但主机在跑别的 | 云游戏，不占用你家里那台设备 |
| 只想先试玩一下某款游戏再决定装不装 | 云游戏，省掉一次几十 GB 的下载 |

存档是跟着账号走的，所以「手机云游戏玩一半、回家主机接着玩」这条路是通的，进度不会丢。

## 五、两者都卡的时候，先怀疑网络

云游戏和远程游玩的症状很像：画面降质、按键迟滞、突然断开。但排查重点不同——云游戏看的是你到微软服务器的线路，远程游玩看的是你到家里主机这一段。分不清就先做一件事：换成 5 GHz Wi-Fi 或网线再试。设置层面与串流相关的排查，统一收在 [常见问题与排查.md](常见问题与排查.md)；只想把家里的主机串到手机上，直接从 [远程游玩怎么玩起来.md](远程游玩怎么玩起来.md) 看起。
