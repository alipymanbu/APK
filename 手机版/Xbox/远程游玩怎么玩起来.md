# 远程游玩怎么玩起来

> 把主机画面送到手机上玩：不用挪电视机，躺在床上、出差在酒店也能接着玩主机里已装的游戏。

远程游玩（Remote Play）是把主机当成服务器，画面压成视频流发到你手机上，你的按键再传回去。游戏跑在主机上，所以画面质量和帧率就是主机的能力，手机新旧影响很小；反过来，网络一抖，画面就会花、操作就会粘。它和「云游戏」是两回事，本篇只讲远程游玩。

## 一、开工前的四项准备

| 需要的东西 | 具体要求 |
| --- | --- |
| 一台主机 | Xbox Series X\|S 或 Xbox One，Xbox 360 不支持 |
| 主机设置 | 已打开「远程功能」，电源模式为「睡眠」 |
| 账号 | 微软账号与 Xbox 配置文件，手机上登录的必须是主机上那个账号 |
| 网络 | 官方页面的建议是 5 GHz Wi-Fi 或移动数据，下载带宽 10 Mbps 起 |

手机端只用装好 Xbox 应用并登录即可，包本身从 [Xbox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/46bd725ef630) 拿。主机那两项设置在 [用手机完成新主机设置.md](用手机完成新主机设置.md) 的第二节表格里，如果主机早就在用了，按 [远程下载与推送安装.md](远程下载与推送安装.md) 第一节补上就行。

## 二、发起远程游玩

1. 手机连上 Wi-Fi（优先 5 GHz），打开 Xbox 应用；
2. 在主界面找到你那台主机的卡片——主机在睡眠时是灰底「已连接」状态；
3. 点进主机，选**远程游玩**这个入口；
4. 等几秒，主机会从睡眠被唤醒，画面出现在手机上；
5. 结束时长按画面里的退出按钮，或者直接从应用里断开。

官方也给了一条不走应用的路径：用手机浏览器打开 [xbox.com/remoteplay](https://www.xbox.com/remoteplay)，登录同一个账号后同样能进。哪条顺手用哪条，效果一样。

## 三、用手机当屏幕之后，操作怎么解决

三种办法，按体验从好到差：

- **蓝牙手柄**：Xbox 无线控制器或其他兼容手柄，配对一次以后一直能用，射击、竞速、动作类只推荐这种。配对步骤见 [手柄连接与触屏控制.md](手柄连接与触屏控制.md)。
- **触屏控制**：一部分游戏做了屏幕按钮布局，打开游戏后自动出现，适合解谜、回合制这类不吃手速的。
- **没有输入方案时**：游戏里需要按的键在屏幕上找不到，只能先连手柄。

## 四、画质与延迟的现实预期

开始之前先把预期定下来，免得玩两分钟就怀疑设置：

| 项目 | 大致水平 |
| --- | --- |
| 画面上限 | 手机端最高约 1080p、60 帧；4K 远程游玩不在支持范围内，主机本地画面不受影响 |
| 同在局域网 | 第三方实测汇总里输入延迟大致 20~50 ms，动作、竞速多数能接受 |
| 人在外网 | 大致 80~150 ms，回合制、剧情、卡牌合适，射击和格斗会明显别扭 |
| 主机上行带宽 | 从外网连回家时，1080p 大致需要 15 Mbps 以上的上传 |

这些数字来自第三方实测汇总，官方产品页只写了最低带宽要求，不承诺具体档位；应用里实际能选到什么画质，以你当前版本显示的为准。

## 五、画面卡、延迟高，先动这几处

| 现象 | 优先排查 |
| --- | --- |
| 画面糊、马赛克 | 手机是连 2.4 GHz 还是 5 GHz；换到 5 GHz 或换到主机同一路由器下 |
| 操作有迟滞 | 主机尽量走网线，手机靠近路由器；关掉手机后台在大流量的下载 |
| 玩几分钟掉线 | 手机省电策略杀了应用后台；给应用开「无限制后台」 |
| 一直连不上主机 | 主机不在睡眠状态、远程功能关了，或账号不是同一个 |
| 出门在外连不上，家里能连 | 看主机的 NAT 类型：进「设置 → 通用 → 网络设置」，显示「开放」最省事，「严格」时从外网回来容易连不上 |
| 以前能用，突然连不上 | 电源模式可能被系统改成了「关机（节能）」，这种状态不支持远程唤醒，改回「睡眠」 |

远程游玩吃的是上行带宽，家里宽带上行小的时候，把主机接网线往往比换手机更有效。

## 六、这些事它做不到

- **只能玩主机上已经装好的游戏。** 远程游玩不是云游戏，没装的东西它帮不了你，要装先在主机上装（远程下载可以代劳，见 [远程下载与推送安装.md](远程下载与推送安装.md)）。
- **同一台主机同时只服务一路画面。** 你连上时，主机这边会进入远程游玩状态、电视上的画面与你同步，等于把这台主机让给了你。
- **个别内容可能不出画面。** 受内容保护限制的影音类内容，串流时可能出现只有声音或黑屏，这种情况换到主机上本地操作即可，不是应用坏了。

真正「什么都不用准备、打开就能玩」的是云游戏，它不需要你有主机、也不占用家里那台设备，代价是要订阅并且对网络更敏感。两边的取舍见 [云游戏和远程游玩有什么区别.md](云游戏和远程游玩有什么区别.md)；连不上、掉线这类具体故障，实测下来最多的是网络与设置问题，逐条对照 [常见问题与排查.md](常见问题与排查.md)。
