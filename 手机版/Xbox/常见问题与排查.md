# 常见问题与排查

> 主机不出现、下载不动、串流卡、应用闪退——按现象归类，逐条给判断依据。

应用本身出故障的概率，明显低于设置、网络、账号这三类。所以下面的次序是「先排除外部条件，再怀疑应用」，按这个顺序查最省时间。

## 一、应用里看不到我的主机

| 可能原因 | 判断与处理 |
| --- | --- |
| 登错账号 | 应用里的账号要和主机上的一致，不一致就换账号登 |
| 主机没联网 | 主机侧的在线状态是不是正常，能在商店里翻东西就是通的 |
| 主机处于「关机（节能）」 | 这种状态不支持远程唤醒，改成「睡眠」。官方近期的更新会把原本设为「睡眠」的主机改成「关机（节能）」，所以「以前能用、突然不能用」多半出在这里 |
| 远程功能关了 | 主机「设置 → 设备和连接 → 远程功能」打开它 |
| 路由器隔离了设备 | 手机和主机若在不同网段、或主机连的是访客网络，互相看不到 |

最后一条容易被忽略：明明都在家里，手机就是找不到主机，先确认两者连的是同一个路由器的同一个网络。

## 二、远程下载推过去了，主机不动

1. **主机空间不够。** 空间不足时任务会挂起，主机上清出空间后才会继续；应用这边不会显示成失败。
2. **主机在系统更新中。** 更新期间会先排队，更新完成后自动开始。
3. **游戏还没到解锁时间。** 预下载完成的游戏要等到发售时间才能进游戏，但文件应该已经下好了。
4. **主机侧关掉了后台下载。** 主机的电源与更新相关设置里，如果关掉了自动更新或后台安装，睡眠状态下就不会继续下载。

## 三、远程游玩连不上或很卡

先分清是「连不上」还是「连上了质量差」：

- **连不上**：主机必须睡眠 + 联网 + 远程功能开着；三项都对还是不行，重启主机一次。人不在家时再加一条——看主机的 NAT 类型（「设置 → 通用 → 网络设置」），显示「严格」容易连不上，显示「开放」最省事。
- **连得上但糊、卡**：把手机换到 5 GHz Wi-Fi，主机尽量接网线；家里有人在下大文件时，串流质量容易跟着抖。
- **玩几分钟断开**：手机省电策略杀后台，给应用开「无限制后台」。
- **手机上找不到退出按钮**：从应用里断开，或者在主机上按 Xbox 键结束会话。

云游戏卡的时候排查方向不同——它看的是你到微软服务器的线路，不是你家主机。两者区别与各自的门槛见 [云游戏和远程游玩有什么区别.md](云游戏和远程游玩有什么区别.md)，操作细节在 [远程游玩怎么玩起来.md](远程游玩怎么玩起来.md)。

## 四、应用本身的问题

| 现象 | 处理 |
| --- | --- |
| 打开就闪退 | 卸载后重装；装之前清掉手机里旧的残留版本 |
| 界面卡在加载中 | 切一次网络（Wi-Fi 换移动数据）；再不行清应用缓存 |
| 页面内容不刷新 | 下拉刷新；仍不刷新就退出登录再登一次 |
| 提示版本过旧 | 从 [Xbox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/46bd725ef630) 覆盖装一份新的，登录状态通常保留 |
| 安装时提示「应用未安装」 | 手机里有更高版本的同包名应用，先卸载旧的 |

## 五、系统与权限类问题

- **通知不推**：系统给应用的通知权限 + 电池白名单，两项都要放行，见 [派对聊天与通知怎么用.md](派对聊天与通知怎么用.md) 第四节。
- **登录反反复复掉**：同样是电池策略导致的，见 [登录与账号问题排查.md](登录与账号问题排查.md) 第三节。
- **系统版本太低**：应用本身要求 Android 8.0 以上，云游戏那一项要求 Android 12.0 以上，两个门槛不一样，装得上不代表云游戏能用。
- **分不清装的是不是官方那个包**：核包名与开发者署名，官方这一组应用的清单与核对办法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 六、判断「该不该等」

有一类情况不用修：官方服务出了故障。表现是**所有功能同时失效**——登不上、好友列表空、云游戏进不去，而不是只有某一个入口不对。这时看官方状态页 [support.xbox.com/xbox-live-status](https://support.xbox.com/xbox-live-status)，确认后在原地等就行。只坏一个入口，才是本地问题，回上面几节逐条查。

包本身有没有装对，回到 [下载与安装教程.md](下载与安装教程.md) 第一节用包名与 MD5 核一遍；远程下载那套设置，对照 [远程下载与推送安装.md](远程下载与推送安装.md) 第一节两分钟能走完。
