# 同名应用与官方渠道怎么认

> 名字里带 Xbox 的应用不止一个：移动版、Windows 版、家长版、手柄工具，各自是独立的包，装错了不通用。这一篇帮你确认手上这个是什么。

「Xbox」在应用商店里是个被重复使用的名字。有人想装手机端伴侣应用，结果装了电脑版；有人搜到家长管理应用，以为是自己要找的那个；还有人下到第三方商店里同名的仿冒包。分辨这三类问题，只需要看包名和开发者署名。

## 一、官方叫 Xbox 的应用有哪些

官方把这一组应用放在同一处介绍，各自的用途分得很开：

| 应用 | 适用平台 | 包名 | 做什么 |
| --- | --- | --- | --- |
| Xbox（移动版，本套文档对应的这个） | Android、iOS | `com.microsoft.xboxone.smartglass` | 手机上的伴侣应用：好友与派对、消息通知、看截图、远程下载、远程游玩、云游戏入口 |
| Xbox（Windows 版） | Windows 10/11 | 以商店页面标注为准 | 在电脑上逛 Game Pass、装 PC 游戏、查看成就 |
| Xbox Family Settings | Android、iOS | `com.microsoft.xboxfamily` | 家长管理孩子在主机上的游戏活动：屏幕时间、内容限制、消费与好友请求 |
| Xbox Accessories | Xbox 主机、Windows | 主机/电脑内置应用 | 手柄按键映射、摇杆与扳机设置、手柄固件更新 |
| Xbox Insider Hub | Xbox 主机、Windows | 主机/电脑内置应用 | 加入预览计划、提前体验新功能、提交问题反馈 |
| Xbox Game Bar | Windows | 系统组件 | 电脑上的录屏、截图与性能浮层 |

两个「Xbox」同名不同包：**移动版管手机，Windows 版管电脑**，功能不重叠，也不能互相替代。手机端要的功能（派对、通知、远程下载、串流）都在移动版里，从 [Xbox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/46bd725ef630) 取到的就是移动版。

## 二、有一个已经停用了

**Xbox Game Pass 移动应用**曾经是单独一个 App，用来查 Game Pass 游戏库、看新入库提醒、远程下载订阅游戏。官方在 2024 年 11 月停止了它的新下载，相关功能已经并进 Xbox 应用。

所以：如果你在教程里看到「下载 Xbox Game Pass 应用」，那是旧信息，别去找了——现在打开 Xbox 应用，游戏库、订阅状态、远程安装都在里面。老手机上如果还留着那个旧应用，功能会越来越对不上，直接卸载即可。

## 三、三个核对点，确认是官方那个包

| 核对项 | 应该看到什么 |
| --- | --- |
| 包名 | `com.microsoft.xboxone.smartglass`（移动版） |
| 开发者署名 | Microsoft Corporation |
| 来源 | 官方商店的应用页面，或本套文档给出的网盘资源 |

第三方商店里挂着「Xbox」名字、图标也相似的应用不少，其中一部分跟微软没有关系。最省事的判断办法就是核包名：包名对不上，功能界面再像也不要装——它拿不到你的 Xbox 账号数据，也用不了主机联动。

Windows 版和移动版共用「Xbox」这个名字，是官方自己造成的混淆，不算仿冒；区分它们看平台与包名即可，不用怀疑是假货。

## 四、搜到「另一个 Xbox」的几种常见情形

- **想装手机版，搜到电脑版**：搜索结果里 Windows 应用商店的条目排在前面。认平台，不看名字。
- **想装电脑版，装成了手机版**：反过来同样会发生，电脑版的功能（装 PC 游戏、PC Game Pass）在移动版里没有。
- **把家长应用当成主应用**：Xbox Family Settings 只做管理，登录的是家长账号，孩子账号不能登进去，所以要聊天、看截图的人装它没用。
- **装到手机厂商商店里的旧包**：部分厂商商店收录的版本很久没更新，界面与新功能对不上；发现入口缺失时，覆盖安装一份新的即可。

## 五、装之前最后一步

拿到安装包之后，按 [下载与安装教程.md](下载与安装教程.md) 第一节核一遍包名、体积与 MD5，三项都对上，就可以放心装。装完登录之后，如果发现某个入口不存在，先确认是不是「这个应用本来就没这个功能」，再看 [常见问题与排查.md](常见问题与排查.md)；云游戏入口在应用里还是在浏览器里，这件事另有一套判断，写在 [云游戏和远程游玩有什么区别.md](云游戏和远程游玩有什么区别.md)。
