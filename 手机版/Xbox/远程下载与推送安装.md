# 远程下载与推送安装

> 人不在主机旁边也能把游戏装上：在手机上下单或点一下，回家主机上已经下载好了。前提是主机侧两个设置都做对。

远程下载解决的是「回家不想等下载」这件事：几十 GB 的更新，与其晚上坐在电视前干等，不如白天用手机把任务派给主机。它不要求你在主机旁边，但要求主机处于能收指令的状态——这也是大多数人「按了没反应」的真正原因。

## 一、先在主机上做两个设置

这两项都在主机上做，做一次长期有效：

1. **打开远程功能。** 按手柄 Xbox 键 → 「配置文件和系统」→「设置」→「设备和连接」→「远程功能」，把开关打开。英文界面对应 Settings → Devices & connections → Remote features。这是总开关，关着的时候手机发的所有远程指令都无效。
2. **把电源模式设成「睡眠」。** 同一菜单下的电源选项里选「睡眠」（旧称 Instant-On）。睡眠不是关机，功耗与噪音都很低，而且保留了**被远程唤醒**的能力——手机发的指令要靠它把主机叫醒。另一个选项「关机（节能）」更省电，官方给的说法是关机后功耗可以低到睡眠模式的约二十分之一，并且仍能在夜里自动完成更新，代价是**不支持远程唤醒**。所以只要你还想用远程下载，就选「睡眠」。

判断有没有做对很直接：主机进入睡眠后，应用里那台主机的卡片应该显示在线；一直显示离线，就回到上面两步重看一遍。

## 二、用手机买游戏并推到主机

1. 打开应用，进游戏库或搜索框，找到目标游戏；
2. 进游戏详情页，按购买按钮完成购买（支付方式与你账号的区域绑定）；
3. 回到游戏详情或你的库，找到**安装到主机**这类按钮；
4. 在设备列表里选中你要装的那台主机，确认；
5. 应用会提示请求已发出；主机下一个唤醒周期就会开始下载。

**已经买过、只是想在另一台主机上再装一遍**的，直接从第 3 步开始，不用再走购买流程。Game Pass 库里的游戏不用买，订阅有效期内直接点安装即可。

## 三、先排队，回家就开玩

两个能省时间的用法：

| 场景 | 怎么做 |
| --- | --- |
| 游戏还没发售，想首发当天就玩 | 支持预下载的游戏在发售前就能开始下载，解锁时间一到直接进游戏 |
| 主机正在更新系统 | 更新没完时排的安装任务会先排队，更新结束后自动开始 |

预下载和远程下载都要求主机保持睡眠且联网，中途拔电源会让整个队列停下来。

## 四、按了没反应怎么查

按顺序排，基本能命中：

1. **主机是不是真在睡眠？** 处于「关机（节能）」状态的主机收不到远程指令，改回「睡眠」。
2. **远程功能开着吗？** 关着就打开。
3. **主机和目标游戏是否同一个账号？** 用 A 账号买的游戏，B 账号登录的主机不会自动开始下载。
4. **主机存储空间够吗？** 空间不足时任务会挂起等你处理，应用里不会把它算成失败。

还有一条容易忽略：家里路由器如果开了客户端隔离，或者主机连的是访客网络，手机发的指令可能进不到主机，把它接到主网络再试。

## 五、和「远程游玩」不是一回事

远程下载是**让主机去干活**，下载期间手机不参与；远程游玩是**让主机把画面送到手机**，你要一直连着玩。两者经常被混着问，适用范围、网络要求、是否要订阅都不一样，区别单独写在了 [云游戏和远程游玩有什么区别.md](云游戏和远程游玩有什么区别.md)。

如果怎么都找不到「安装到主机」这个入口，先确认应用版本是不是太旧——入口会随版本变，从 [Xbox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/46bd725ef630) 取一份新的覆盖安装即可，登录状态一般保留。装完还是不行，接着看 [常见问题与排查.md](常见问题与排查.md)。
