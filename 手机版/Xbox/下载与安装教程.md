Xbox 是微软官方的手机伴侣应用，装在安卓手机或平板上用。它管的是主机之外的事：看谁在线、发消息、逛 Game Pass、买游戏、把游戏推到主机上装好，也能把主机的画面串流到手机。本篇只管把网盘里这份包放进手机，并让第一次登录顺利走通。

## 一、网盘里这份是哪一版

搜索引擎给的版本号通常是官方最新版，网盘里这份是整理文档时核对过的版本，两者不一定相同。下面这些字段都以这份包为准：

| 项目 | 值 |
| --- | --- |
| 版本号 | 2607.1.1 |
| 包名 | `com.microsoft.xboxone.smartglass` |
| 安装包体积 | 103.56 MB |
| MD5 | `cb62c5d615a0601eb91f4b2221bccc3a` |
| 版本核对时间 | 2026-09-23 |
| 适用平台 | Android 手机、平板 |

包名这一列值得留意：`com.microsoft.xboxone.smartglass` 里的 smartglass 是早年的旧名字，今天的应用已经改叫 Xbox，包名沿用没变。第三方商店里叫「Xbox」的东西不少，用包名核一下，就能确认手上这份是哪一个。安装包本体放在 [Xbox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/46bd725ef630) 里，转存到自己网盘后下载即可。

版本号形如 `2607.1.1`，从官方公开的版本序列看，前四位对应「年份后两位 + 月份」（2607 约等于 2026 年 7 月那一轮），后面两位是小版本修正。官方没有把这条规则写成文档，所以只当参考，具体以官方渠道当时显示的为准。

## 二、装之前先看两件事

**第一，系统版本。** 官方产品页写的是与 Android 8.0 或以上版本兼容。同一个应用在不同商店、不同时间显示的最低系统版本会有出入（有渠道标到 8.1 甚至更高），以你手机上商店页面当时写的为准。系统低于要求时的典型表现是商店直接提示「应用与你的设备不兼容」，或者装好后一部分入口根本不出现。

**第二，别和电脑上那个应用搞混。** Windows 上也有一个叫 Xbox 的应用，那是另一个程序、另一个安装包，负责的是在电脑上逛 Game Pass、装 PC 游戏。本文这份是移动版，两者不能互相替代。Xbox 这套东西里还有 Xbox Family Settings（家长管理）、Xbox Accessories（手柄设置）等独立应用，也都是各自单独的包。分辨办法与官方这几个应用的完整清单，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 三、安装步骤

1. **转存并下载。** 从网盘把 APK 转存到自己的网盘，再下载到手机；在电脑上下载后用数据线拷进手机存储也一样。
2. **允许安装未知来源应用。** 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统常把这项收在「安全」或「隐私」分类下。
3. **点开 APK 安装。** 系统提示「应用未经过安全检测」时选择继续安装，这是第三方来源安装包的常规提示，与包本身是否可靠无关——可靠性靠第一节的包名与 MD5 核对。
4. **手机里已有同包名版本时，这次安装会直接覆盖它。** 登录状态通常保留；想干净重来的话先卸载再装。
5. **遇到「应用未安装」。** 多半是手机里那个同包名版本比这份新——安卓不允许用低版本覆盖高版本，先卸载旧版再装。

## 四、第一次打开要过哪几关

启动顺序不复杂，但卡在哪一步的应对方式完全不同，按这个顺序看：

1. **通知权限。** 系统弹窗问通知权限时给上。拒绝也能继续用，只是派对邀请、好友消息、下载完成这类提醒进不了通知栏。
2. **登录微软账号。** 用你主机上那个账号登录，内容和进度才对得上。没有账号的话在微软账号页面免费创建，账号注册区域会决定商店里能看到什么、哪些功能可用。
3. **处理账号安全验证。** 账号开了两步验证的，这一步要验证码。卡在验证码、提示密码错误、或者干脆转圈登不进去的，处理办法都写在 [登录与账号问题排查.md](登录与账号问题排查.md)。

## 五、装完做一次最小验证

不用连主机，先把能验的验掉：

| 看到的现象 | 说明什么 |
| --- | --- |
| 登录后能看到头像、好友列表、成就 | 账号与网络通了 |
| 能翻到 Game Pass 游戏库、看到游戏详情 | 账号区域与网络没被挡住 |
| 应用里出现了你主机的卡片 | 账号已和主机对上，后面可以走远程相关功能 |

主机出现在列表里之后，如果你手里是一台还没开过箱的新主机，可以直接用应用把它设置完，流程见 [用手机完成新主机设置.md](用手机完成新主机设置.md)。装包本身出问题的概率其实比登录低，真要排查就先看 [常见问题与排查.md](常见问题与排查.md)。
