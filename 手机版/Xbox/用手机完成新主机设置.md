# 用手机完成新主机设置

> 新主机第一次开箱、还没连过网的时候，可以用手机上的 Xbox 应用从头设到底，不必在电视上用手柄一位一位敲。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [远程下载与推送安装.md](远程下载与推送安装.md) · [手柄连接与触屏控制.md](手柄连接与触屏控制.md)

官方给新主机准备了两条路：在主机上用手柄设，或者用手机上的 Xbox 应用设。后者省事在「打字」这一步——账号密码、Wi-Fi 密码、主机名字都在手机键盘上敲，比手柄摇杆选字母快得多。本篇讲的正是这条手机路径，适用于 Xbox Series X|S 与 Xbox One。

## 一、开始之前

- **手机装好 Xbox 应用并登录**：应用本体从应用商店或 [Xbox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/46bd725ef630) 拿，登录用你打算在主机上用的那个微软账号。
- **新主机通电、开机**，屏幕停在没有设置过的初始画面上，先不要在主机上乱按。
- **手机把蓝牙和定位打开**：手机和主机之间靠蓝牙做近距离配对，定位权限用于让应用找到同一房间里的设备。
- **手机连上家里那个 Wi-Fi**，主机后面也要连同一个网络。

## 二、应用里的设置顺序

应用会一步一步往下带，它的顺序和主机端一致，遇到要选的地方按下面这张表来：

| 步骤 | 你要做的事 | 选错了会怎样 |
| --- | --- | --- |
| 连接到主机 | 允许应用查找并连接这台主机，选中屏幕上出现的那台 | 搜不到主机，多半是手机没给蓝牙/定位权限 |
| 语言与地区 | 选语言和所在地区 | 地区决定商店内容与部分服务的可用范围，之后能改但会有次数限制 |
| 主机联网 | 把 Wi-Fi 密码填在手机上，主机跟着连上 | 这一步过不去，后面全部卡住 |
| 系统更新 | 等它更新完，中途不要断电 | 更新没完，接着的设置在旧系统上对不上 |
| 电源模式 | 选「睡眠」（旧称 Instant-On） | 选「关机（节能）」的话，主机睡着后收不到远程指令，见本节下文 |
| 保持更新的内容 | 按需勾：游戏与应用的自动更新、系统更新 | 只影响后台自动更新，后面随时能改 |
| 主机命名 | 给主机起个名字 | 家里两台主机时，改名字才好分辨是哪一台 |
| 登录账号 | 用手机键盘输账号密码 | 登录不上的处理见 [下载与安装教程.md](下载与安装教程.md) 第四节 |
| 数据与安全选项 | 按提示选，涉及个性化数据与广告偏好的都在这 | 都能事后在账号设置里改 |
| 启用远程功能 | **打开** | 关着的话，手机上的远程下载与远程游玩都做不了 |
| 排队安装应用 | 可以在这一步先把想装的游戏排进队列 | 主机还在更新时排的队，会更完再下载 |
| 通知 | 打开 | 关着的话主机侧提醒不会推到手机上 |
| 手柄 | 按提示把无线手柄开机并更新固件 | 固件旧可能连不上或个别按键无响应 |
| 电视设置 | 按你的电视情况选 | 选错最多是画面比例或 HDR 不对，能回头改 |

「电源模式」和「启用远程功能」这两项是多花十秒、后面省很多事的：它们决定了你出门在外能不能用手机把游戏推回家装好、能不能把主机画面串到手机玩。具体用法见 [远程下载与推送安装.md](远程下载与推送安装.md)。

有一个会变的地方要提前知道：微软一直在推更省电的「关机（节能）」模式——官方 2026 年 6 月的说明里提到，正在把原本设为「睡眠」的主机改成「关机（节能）」。这两种模式的关键差别是**关机状态不支持远程唤醒**，而远程下载、远程游玩都依赖唤醒。所以刚设好时远程能用、过一阵却突然不能用了，先回设置里看一眼电源模式是不是被改成了「关机（节能）」，改回「睡眠」就好。

## 三、设置完当场验三件事

| 检查 | 通过的样子 |
| --- | --- |
| 主机联网 | 主机界面能看到在线状态、商店能加载 |
| 远程功能 | 应用里主机的卡片是「在线」，不是灰色离线 |
| 手柄 | 手柄按一下，主机界面有反应 |

三项都过，就可以把手机收起来了。手柄连手机（不连主机）走的是蓝牙，步骤与这里不同，那是另一件事，见 [手柄连接与触屏控制.md](手柄连接与触屏控制.md)。

## 四、之后想改设置去哪改

主机上的设置项，改法分两处：跟账号、通知、隐私有关的，在应用里的「设置」下改；跟主机硬件行为有关的（电源模式、远程功能、画面、存储），在主机上按 Xbox 键进「配置文件和系统 → 设置」改。两边看到的东西不一样，找不到某项时先想清楚它属于哪一类。
