## 一、先认清你拿到的是什么

安卓生态里名字带 openai 的应用不少，动手装之前先对一遍这份包的基本信息：

| 项目 | 值 |
| --- | --- |
| 应用名 | openai |
| 版本 | 1.1.3 |
| 包名 | `com.cats.bochall` |
| 大小 | 9.25 MB |
| 系统要求 | 安卓 5.2 及以上 |
| MD5 | EC334965A2523322379B74A825776F1D |

两点提醒：

- 官方应用市场里 OpenAI 自己发布的 ChatGPT 安卓客户端包名是 `com.openai.chatgpt`，与上表的 `com.cats.bochall` 不同——也就是说这份包不是官方客户端，而是名字套用 openai 的第三方 AI 对话问答应用。两者怎么区分、各适合什么人，见[与ChatGPT的关系](与ChatGPT的关系.md)。
- 上表版本与大小是 2026-09-24 对这份安装包实测得到的数值，只描述网盘里这一份包；官方渠道的版本号现在走到多少，以官方页面当时显示为准。

## 二、获取安装包

安装包在 [openai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/503c2faed4fb)。夸克网盘的分享链接需要先转存到自己网盘再下载：打开链接 → 勾选里面的 apk 文件 → 点「转存」选个位置 → 到自己的网盘里完成下载。没有夸克账号会先被引导注册，手机号即可。

如果转存或下载环节出问题，先确认网盘容量是否已满（剩余空间要装得下这个 9.25 MB 的文件），再换浏览器重试一次。

## 三、核对文件完整性

下载完成后建议核对一次 MD5，确认文件在传输中没有损坏：

```text
certutil -hashfile 下载的文件名.apk MD5
```

在 Windows 的命令提示符里执行（把文件名换成你实际的文件），输出的值与第一节表格里的 MD5 一致就说明文件完整。安卓端也可以用 MT 管理器这类文件管理器直接查看文件的 MD5。对不上就重新下载一次，不要强行安装。

## 四、安装步骤

1. 把 apk 传到手机（网盘 App 直接下载到手机，或数据线/局域网传输均可）。
2. 在文件管理器里点开这个 apk，系统会弹出「允许从此来源安装应用」的提示，给当前文件管理器开权限。
3. 回到安装界面点「安装」，9.25 MB 的包几秒到十几秒就能装完。
4. 提示「解析包失败」多数是下载不完整（先回第三节核对 MD5）或系统版本低于要求（安卓 5.2 以下装不上）。
5. 装完点「打开」进入应用；桌面图标会以 openai 的名字出现。

其他安装与启动环节的异常（点了没反应、闪退、反复要求权限）在[常见问题排查](常见问题排查.md)里按现象分了类，直接对号入座。

## 五、首次启动

第一次打开通常会有两类弹窗：

- **权限申请**：这类对话应用一般会请求网络权限（必须有，否则发不出提问）；个别还会要存储权限用于保存对话记录。按需给即可，用不到的功能可以拒绝。哪些权限属于「要留心」的范围，见[安装包安全自查](安装包安全自查.md)第一节。
- **使用引导**：可能有一两页功能介绍，滑到最后一页点开始就行。

进到主界面后你会看到一个输入框加对话区域，直接打字提问就能开始用。第一句怎么问、后续怎么追问效果更好，见[对话使用入门](对话使用入门.md)。

## 六、更新与卸载

- 通过安装包安装的应用不会自动更新。这个第三方应用一般也没有应用市场提供更新，需要新版时重新获取一份新包覆盖安装（数据通常保留）。
- 想卸载：长按桌面图标 → 卸载，或到系统设置 → 应用管理里找到 openai 卸载。卸载前如果有想留的对话内容，先截图或复制保存。
