## 一、装前：四道检查

按顺序过一遍，每道都只需要几分钟：

**1. 核对指纹值**
如果发布方给了 MD5 / SHA-256，下载完就算一遍对上（Windows 上 `certutil -hashfile 文件名 MD5`）。这份 openai 包对应的值是 `EC334965A2523322379B74A825776F1D`，核对步骤详见[下载与安装教程](下载与安装教程.md)第三节。指纹对不上 = 文件在传输中被改过或没下完整，直接删掉重下。

**2. 多引擎扫描**
把 apk 上传到 [www.virustotal.com](https://www.virustotal.com)，它会用几十个反病毒引擎同时扫。一两个引擎报毒可能是误报，多个知名引擎同时报毒就别装了。不想上传文件的话，电脑端的 Windows Defender 全盘扫一遍也能兜底。

**3. 看权限是否与功能匹配**
Android 官方的设计是：安装前系统会把应用申请的权限列给你看。判断原则一句话——**功能越简单的应用，合理权限应该越少**。一个纯文字对话应用，网络权限是必须的，但下面这些就要多留个心眼：

| 权限组合 | 风险 |
| --- | --- |
| 读取联系人 + 发短信 | 可能产生扣费、泄露人脉 |
| 录音 + 网络 | 对话内容可能被上传 |
| 精确定位 + 网络 | 行踪被持续记录 |
| 无障碍服务（辅助功能） | 能读屏幕上的一切，包括验证码 |

对话类应用如果索要上表里的组合，拒绝授权不影响聊天功能的话就关掉；非要用就得想清楚这层交换。

**4. 只给一个应用「安装未知应用」权限**
Android 8 起这个权限是按应用单独授权的（Android 官方文档明确的设计）。给负责安装的那个文件管理器开就行，**装完建议关回去**——这样浏览器或其他应用以后就没法静默往手机里塞包。

## 二、装后：两件事

- **复查权限**：系统设置 → 应用 → openai → 权限，把当时顺手点了允许、但聊天根本用不上的权限（定位、通讯录、录音）关掉。这个路径 Android 各版本通用，个别机型入口略有差异，在设置里搜「权限」就能找到。
- **开着 Play 保护机制**：预装 Google 服务的设备，Play 保护会持续扫描已安装的应用（包括 sideload 装的），确认它处于开启状态即可，不需要额外操作。

## 三、哪些信号出现就该放弃

- 安装界面弹出的权限与对话功能明显不匹配（见第一节表格）；
- 应用要求先装另一个「下载器」「助手」才能用——这是给自己留永久安装入口的典型手法；
- 支付、登录环节要求填写与聊天无关的信息（身份证、通讯录、短信验证码转发）；
- 用起来发现收费方式属于[免费额度与收费套路](免费额度与收费套路.md)第一节里的高价套路，且找不到任何能对上号的开发主体。

出现任一条，卸载比研究更划算。
