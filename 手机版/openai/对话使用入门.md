## 一、第一句怎么问

主界面就是「输入框 + 对话区」，打完字点发送即可。第一句不用试「你好」这种寒暄，直接给一个具体任务更能看出它的水平，比如：

```text
把这段话翻译成英文：明天上午十点开会，请带上项目进度表
```

```text
帮我列一个三天的青岛旅行计划，预算人均 1500 元
```

```text
用初中生能听懂的话解释一下什么是光合作用
```

对比一下就能发现提问质量的差别：问「青岛好玩吗」只能得到泛泛的介绍；问「三天、人均 1500、要海鲜」这种带条件的，回答才用得上。这类对话应用没有按钮要配、没有菜单要翻，唯一的技术就是**把话说具体**。

## 二、把回答调准的四个习惯

1. **给背景**：「我是安卓手机」「我只有一个周末的时间」——背景决定答案的适用性。
2. **给格式要求**：「用表格列出来」「分三点说」「不超过 100 字」，输出的结构会照你的要求走。
3. **追问而非重问**：回答不够细就接一句「第二条展开讲讲」，上下文会延续；答偏了就指出「我想要的是预算不是攻略」，比重新问一遍省事。
4. **换问法再试**：同一个问题换个角度问，回答质量可能完全不同；某类问题反复答不好，多半是这类内容超出了它的能力，不必死磕。

### 进阶：三种立刻能用的问法

- **先设定角色**：「你是一名小学班主任」再问班级管理的事，回答会比泛泛地问更贴场景——角色等于替它选好了回答的知识范围。
- **复杂任务拆步走**：写长文不要一句「帮我写一篇演讲稿」打发，先让它出提纲，选中一版后让它逐段展开，最后让它通读全文做删改——三步的产出明显好过一步到位。
- **让它先问你**：信息没给全时加一句「开始前先问我三个你最需要确认的问题」，它会主动把缺口补上，省得你来回猜哪里没说清。

## 三、互译怎么用

这个应用的一个明确功能是两种语言的快速互译。翻译场景下有两个比普通对话更好用的写法：

- **成段翻译**：把整段文字贴进去，前面加一句「翻译成英文，保留原格式」，比一句一句发效率高。
- **带语境翻译**：注明「这是发给客户的邮件，语气正式一点」或「这是游戏里的对话，口语化一点」——直译出来的东西往往对但不像人话，给语境能明显改善。

翻译结果不放心时，可以让它「再给一版更口语的」或「逐句解释为什么这样翻」，对照着挑。

## 四、适合丢给它的典型场景

| 场景 | 示例问法 |
| --- | --- |
| 写作起稿 | 「帮我写一条请假信息，语气客气，理由是家里有事」 |
| 解释概念 | 「房贷的等额本息和等额本金差在哪，我该选哪个」 |
| 整理归纳 | 「把这段会议记录整理成待办清单」 |
| 学习辅助 | 「出 5 道高中数学二次函数题，附答案和步骤」 |
| 日常决策 | 「预算 3000 元，帮我对比一下买平板还是笔电更合适」 |

它的回答适合当**底稿与参考**，重要事项（法律、医疗、金额较大的决定）要用其中的结论前，自己再核一遍。

## 五、两件事提前知道

- **回答有长有短**：同一问题不同时间得到的措辞可能不同，这是此类应用的正常表现，不是故障；答得离谱就换问法，见第四节。
- **对话记录去哪了**：退出再进应用，历史记录是否保留取决于它本地的实现，想留的重要回答当场复制或截图最稳妥。
