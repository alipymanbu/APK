## 一、装之前先核对这几点

这份安卓包的固定信息如下，装完后可以对照检查自己拿到的是不是同一份：

| 项目 | 信息 |
| --- | --- |
| 应用名 | itch |
| 版本 | 1 |
| 包名 | com.newh5itch |
| 安装包大小 | 约 20.66 MB |
| MD5 | A4149EF57C8DA55CE107F7BE29D96C2F |
| 系统要求 | 安卓 5.2 及以上 |

几点说明：

- **版本号就是 1**：这不是 itch.io 官方桌面客户端的版本号体系（那套版本号一直在往前走，以官方应用页为准），是这份安卓包自己的版本标识。本套文档里涉及版本号的地方都按上面这行写。
- **包名可以用来验明正身**：想确认设备上已装的是哪一份，在系统的应用详情里看包名是否为 `com.newh5itch`。
- **MD5 是核对安装包完整性的依据**：网盘转存再下载，中间环节多，装不上时先怀疑文件不完整，核对方法见第四节。

## 二、把安装文件资源转到自己手机上

安装包放在夸克网盘里，流程是「转存 → 下载」三步：

1. 点开本页头部给出的 **itch 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/d93527be9a11](https://pan.quark.cn/s/d93527be9a11)，在分享页里勾选安装包，选「转存」保存到自己的网盘账号（没有夸克账号会先要求注册登录）。
2. 打开夸克网盘 App（或网页版），找到刚转存的那份 `itch_v1.apk`，点「下载」到手机本地存储。
3. 下载完成后在通知栏或「我的文件 → 下载」里找到这个 apk，进入安装环节。

手机空间紧张的话，先确认剩余空间大于 100 MB 再动手——安装包本身约 20.66 MB，安装过程还需要等量甚至更大的临时空间。

## 三、安装步骤

1. 点击下载好的 `itch_v1.apk`，系统会弹窗询问是否安装。
2. 第一次装非商店 apk 时，安卓会拦截并提示「不允许安装未知应用」：按提示进入系统设置，给你用来下载的那个文件管理器（或浏览器）开「允许安装未知应用」权限。不同品牌的路径略有差异，一般在「设置 → 应用 → 特殊应用权限 → 安装未知应用」附近。
3. 回到安装页点「安装」，等进度条走完点「打开」即可。

安装完成后建议回系统设置里把刚才开的「安装未知应用」权限关掉，这是装任何非商店 apk 的通用习惯。

## 四、核对 MD5 的两种做法

- **手机上**：部分文件管理器（如 MT 管理器一类工具）长按文件就能看到 MD5，把看到的值和第一节的表格逐字对比，不区分大小写。
- **电脑上**：Windows 在 PowerShell 里执行 `Get-FileHash 文件路径 -Algorithm MD5`；macOS / Linux 用 `md5sum 文件路径`。

对不上就别装了，回网盘重新下载一次；连续两次都对不上，多半是转存或下载环节出了问题。

## 五、装不上怎么办

按命中率从高到低试：

1. 文件不完整 → 重新下载并核对 MD5；
2. 设备系统版本低于要求 → 先满足第一节的系统要求；
3. 存储空间不足 → 清出空间再装；
4. 提示「签名冲突」 → 说明手机上已经装过另一个同名或同包名应用，先卸载旧的再装。

逐条都排掉还是失败，去[常见问题解答.md](常见问题解答.md)里对更完整的排查清单；想先了解这个应用和 itch.io 平台的关系，看[平台背景与独立游戏生态.md](平台背景与独立游戏生态.md)。
