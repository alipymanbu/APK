## 一、itch.io 的来历

itch.io 在 2013 年 3 月上线，创始人是 Leaf Corcoran。它做的事一句话能说清：给独立游戏开发者一个直接发布作品的货架，玩家直接从开发者手里拿游戏。《A Short Hike》《Dicey Dungeons》这些后来登上主机与主流商店的知名独立游戏，最初都在这个平台上发过。截至 2024 年底，平台上托管的项目已经超过一百万个——游戏之外还有漫画、音乐、游戏素材这类创作内容（数字会一直涨，以官网当时显示为准）。

## 二、它和常见游戏商店的差异

| 维度 | itch.io 的做法 |
| --- | --- |
| 分成 | 开发者自己定平台抽成比例，默认 10%，可以调到 0 |
| 定价 | 大量游戏用「随喜付费」（pay-what-you-want），定价 0 也能拿，愿意支持就多付 |
| 版权管理 | 文件原样分发，不给安装包加 DRM 限制 |
| 页面 | 每个开发者可以自定义自己游戏页面的样式 |

这套模式让小团队和个人开发者几乎零门槛上架，反过来也意味着游戏质量参差——你在里面既会捡到宝，也会下到做了一半的实验品，选游戏时多看介绍和截图。

**真要掏钱之前，确认一件事：收款方是谁。** 开发者的收款有两种模式：一种直接打进开发者自己的支付账户，另一种由平台代收、定期结算给开发者（欧洲的增值税由平台代为处理）。两种模式页面上都会写明，看到结算相关提示时留意一下，消费者能感知的差异主要是到账说明与发票口径；细节以 itch.io 官方帮助文档为准。

## 三、Game Jam：限时做游戏的社区活动

itch.io 是各类 Game Jam（限时游戏创作活动）的主要举办地之一：参与者在限定时间（常见 1~3 天）内按主题做出一款游戏并公开，最有名的包括 Game Maker's Toolkit 办的 GMTK Jam。对玩家来说，这些活动意味着平台上持续有大量免费、实验性的小游戏可玩。安卓上没有官方客户端，想逛这些作品用手机浏览器开 [itch.io](https://itch.io) 就行。

## 四、官方客户端与安卓端的现状

- **官方桌面客户端叫 itch**（对，和你要找的东西同名），支持 Windows、macOS、Linux，项目开源，负责下载、自动更新、离线玩浏览器游戏，官方页面在 [itch.io/app](https://itch.io/app)。这个客户端 2016 年前后就有了，2021 年还上架过 Epic Games Store，走的是桌面优先的路子；
- **官方没有出过安卓客户端**，手机上的官方姿势就是用浏览器访问 itch.io 网站；
- 安卓上存在第三方移动客户端，比如 F-Droid 上的开源应用 [Mitch](https://f-droid.org/packages/ua.gardenapple.itchupdater/)，用来安装和更新 itch.io 上的安卓游戏——注意它是社区作品，不是官方出品。

对照上面几条：这份包名 `com.newh5itch`、版本 1 的应用不是官方客户端，公开渠道也查不到它与 itch.io 官方团队的直接关联，按第三方游戏平台应用对待比较稳妥。它提供了一个手机上的游戏库入口，里面的内容需要你自己把关：

3. 想要干净、可核验的 itch.io 体验，优先用浏览器访问官网，或在电脑上装官方客户端。
