## 一、安装前先确认这几件事

| 项目 | 本文口径 | 说明 |
| --- | --- | --- |
| 系统要求 | Android 7.0（API 24）及以上 | 低于 7.0 的系统装不上或无法正常运行，以官方发布页为准 |
| 安装包体积 | 68.28 MB | 下载后体积对不上就别急着装 |
| 版本 | 6.5.0 | 网盘里这份是 6.5.0；官方仓库已发布更高版本，想要新版去官方发布页 |
| 包名 | `org.autojs.autojs6` | 与 Auto.js、Autox.js 等同系应用不是同一个包，可共存但要分清 |

AutoJs6 是开源项目（MPL-2.0 许可），官方渠道是 GitHub 仓库 [github.com/SuperMonster003/AutoJs6](https://github.com/SuperMonster003/AutoJs6)，应用文档在 [docs.autojs6.com](https://docs.autojs6.com/)。它基于已停止维护的 Auto.js（最终版本 4.1.1 Alpha2）二次开发而来，所以网上很多旧教程标题写着 Auto.js，思路也能参考，但界面和功能细节已经不一样了。

## 二、获取安装文件资源

上面网盘块里的链接就是 AutoJs6 安装文件资源（夸克网盘），操作路径是：打开 [AutoJs6 安装文件资源（夸克网盘）](https://pan.quark.cn/s/80cb09f7f013) → 转存到自己网盘 → 从网盘下载 APK 到手机存储。

下载完成后建议核对一下文件信息，防止下到半截或被改名：

- 文件体积约 68.28 MB；
- MD5 为 `DE7DDC21EC16F9059F427E206C436299`，用文件管理器的属性页或专门工具都能算；
- 手机上很多文件管理器自带 MD5 校验入口，位置因应用而异。

如果你更习惯自己从官方渠道拿包，GitHub 仓库的 Releases 页面（[github.com/SuperMonster003/AutoJs6/releases](https://github.com/SuperMonster003/AutoJs6/releases)）提供各版本安装包，版本号以页面当时显示为准。

## 三、安装步骤

1. 用手机文件管理器找到下载好的 APK 文件，点它；
2. 系统弹出「不允许安装未知来源应用」类提示时，按提示允许浏览器或文件管理器「安装未知应用」的权限（各系统入口叫法不同，一般藏在该应用的「安装未知应用」权限页里），允许后返回重试；
3. 点「安装」，等进度走完；
4. 装完点「打开」，第一次进主界面会看到一个脚本文件列表。

安装失败常见两种情况：

- **提示「安装包解析失败 / 损坏」**：先回头核对第二节的两项信息，多数是下载不完整，重新下载再装；
- **提示存储空间不足**：安装包本身 68 MB 上下，安装过程还需要额外空间，清理后再试。

以后出新版本想升级时，直接用新 APK 覆盖安装即可（包名相同），已写的脚本和应用设置都会保留；只有「先卸载再装」才会清掉应用自身的数据——不过你保存在公共目录（下载、文档这类位置）的 `.js` 脚本文件不受卸载影响。

## 四、装完先别急着写脚本

AutoJs6 的自动化操作（自动点击、滑动、控件读取）依赖安卓的「无障碍服务」，这个权限默认是关的，不开的话大部分自动化功能跑不起来。开启方法和「开了很快又被系统关掉」的处理，见 [无障碍权限开启教程.md](无障碍权限开启教程.md)。

权限开好后，从跑第一个脚本开始上手，见 [基础使用入门.md](基础使用入门.md)。用着用着遇到怪问题（脚本跑一半停了、定时任务不触发等），先翻 [常见问题排查.md](常见问题排查.md)。
