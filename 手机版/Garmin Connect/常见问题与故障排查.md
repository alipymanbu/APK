# Garmin Connect 常见问题与故障排查

> 本篇收的是用 Garmin Connect 时实际会撞上的问题：配对搜不到设备、华为手机连接不稳、通知收不到、定位功能失灵、同步没反应，每节都给可操作的排查顺序。

先说结论：Garmin Connect 的大多数问题出在蓝牙和权限上，九成能靠「重配对 + 补权限」解决。本篇按症状分节，每节给官方来源的排查顺序，做完一条就重试一次。

## 一、配对时搜不到设备

1. **重启手表**：关机再开机；没有按键的型号，插上充电线就会自动重启。
2. **App 里删掉旧记录**：更多 → Garmin 设备 → 设备名 → 右上角 → 移除设备（完整步骤见[手表配对与连接设置](手表配对与连接设置.md)第四节）。
3. **系统蓝牙里取消配对**：设置 → 蓝牙 → 找到 Garmin 设备 → 取消配对。
4. **确认手表在配对模式**：屏幕上应有配对动画/二维码/提示文字；不在就进手表设置里的蓝牙或手机选项开启。
5. **从其他手机/平板上移除**：官方不建议一块表同时配多台手机，旧设备不删干净会抢连接。
6. **确认选的型号对**：同系列设备在列表里挨得近，别选错行。
7. **检查「附近设备」权限**（Android 12+）：更多 → 设置 → 手机权限 → 管理权限 → 权限 → 附近设备 → 允许。
8. **重启手机**：重新初始化蓝牙，能清掉卡住的配对通信。

## 二、华为手机连接不稳

官方单独出过说明：蓝牙连接问题的改善条件是 **EMUI 13.00 或 HarmonyOS 3.0 以上**，低于这个版本先升级系统。系统达标后还断连，按这个顺序：

1. 把 App 升到当前版本（官方安装入口见[下载与安装教程](下载与安装教程.md)）。
2. App 里删设备、系统蓝牙取消配对，再重新添加一遍。
3. 允许 App「自动启动」和「后台运行」：设置 → 电池 → 应用启动管理 → 选 Garmin Connect。
4. 手表固件旧也会连不稳：App 会自动检查更新，或把手表连电脑用 Garmin Express 升级（入口见[账号注册与数据同步](账号注册与数据同步.md)）。

官方兼容性说明里明确列了部分未通过内部测试的机型：华为多款、Lenovo S960、Meizu MX4、Samsung J3（J320FN）。这些机型不是连不上，而是可能要反复处理蓝牙问题，配对前有这个预期就行。

## 三、手表收不到通知

按链路从手机侧到手表侧逐层查：

1. **通知读取权限**：手机设置里搜「通知访问」或「访问通知」（部分系统在「特殊访问」里），给 Garmin Connect 打开。
2. **电池优化**：设置 → 应用 → 找到 Garmin Connect → 忽略电池优化；华为机再确认「熄屏后继续运行」开着。
3. **通知渠道**：系统通知中心里确认该 App 的「允许通知」开着，重要的应用再给「优先显示」。
4. **App 内的通知设置**：只勾选想推到手表的应用，全勾反而乱。

iPhone 用户注意：iOS 系统同时最多连 7 个蓝牙设备，超了会挤掉手表。

上面四步只够把常见开关打开；各品牌电池优化的逐品牌路径、iPhone 的显示预览与专注模式设置，整理在[通知设置与后台保活](通知设置与后台保活.md)，通知链路问题建议直接按那篇的五道关走一遍。

## 四、定位相关的功能用不了

App 要定位权限是因为这些功能本身靠位置数据：蓝牙配对（Android 11 及更早）、Connected GPS（手表没有 GPS 时借手机的）、LiveTrack 实时位置分享、援助/事故检测、天气显示、附近的赛段与球场、创建骑行或跑步路线。

某个功能失灵，先按这条路径把定位放到「始终允许」：

1. Garmin Connect → 更多 → 设置 → 手机权限 → 管理权限。
2. 权限 → 定位 → 「始终允许」（没有这个选项就把定位开关打开）。
3. 返回保存，重启手表，再同步一次。

## 五、删设备后 Garmin Pay 没了

从 App 删除设备时，Garmin Pay 钱包会被一并删除——这是官方明确的行为，不是故障。重新添加设备后需要重建钱包（重新录卡）。所以只是想排查蓝牙问题的话，先按第一节的顺序走一遍重配对，多数情况能避开「删设备」这一步。

## 六、同步没反应、数据不上来

1. 确认手机蓝牙开着，App 在后台没被杀（后台限制的设置参考第二节第 3 步）。
2. 打开 App 停在首页等它自动同步，或下拉手动触发。
3. 看手表端的蓝牙图标是否亮着。
4. 还不行就把手表插电重启，再同步一次。

数据上来之后看什么，见[健康数据与运动记录功能](健康数据与运动记录功能.md)；历史数据都在云端账号里，[账号注册与数据同步](账号注册与数据同步.md)有说明。「同步失败」提示反复出现、怀疑服务端故障、或需要用电脑解锁卡死的同步，见[同步失败与数据不更新排查](同步失败与数据不更新排查.md)。
