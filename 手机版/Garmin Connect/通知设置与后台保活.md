# Garmin Connect 通知设置与后台保活

> 手表收不到消息通知，问题几乎都出在五道关里的某一关：手表开关、App 内设置、App 权限、系统通知访问、厂商后台清理。本篇逐关给入口，并整理各品牌的电池优化路径。

通知从手机走到你手腕上要过五道关，任何一关被系统拦住，手表就静音。按顺序逐关检查，比盲目重装省时间。

## 一、五道关逐一核对

### 1. 手表侧的开关

- 手表的「通知」小部件/图标已开启：手表上通常在 设置 → 小部件/图标，或在 App 的设备设置 → 外观 里。
- 手表的通知模式符合预期：手表 设置 → 连接性/电话 → 通知（不同型号菜单略有差异）。
- 「免打扰」是关的：手表 设置 → 系统 → 免打扰。

### 2. App 内的通知设置

打开 Garmin Connect → 左上角菜单 → 设置 → 通知 → App 通知：先开总开关，再按应用勾选要推送到手表的那几个，全勾反而乱。

### 3. App 的手机权限

更多 → 设置 → 手机权限 → 管理权限：短信、联系人、电话这几项与通知相关（安卓需要短信权限；iPhone 需要联系人与电话），哪项关了就打开。

### 4. 系统的通知读取权限

安卓要给 Garmin Connect「通知使用权」：手机设置顶部搜索「通知访问」或「访问通知」（部分系统在「特殊访问」里）开启。iPhone 没这一关，对应动作是：设置 → 蓝牙 → 点手表旁的 (i) → 打开「共享系统通知」。

### 5. 厂商的后台清理

主流品牌的电池优化都可能把 App 清出后台，通知随之断掉。逐品牌路径见下一节。

## 二、各品牌电池优化设置路径

菜单名可能因机型与系统版本而异，找不到就按品牌关键词搜设置（以下路径摘自官方支持文档）：

| 品牌 | 路径 |
| --- | --- |
| 华为 | 设置 → 电池 → 应用启动管理 → 关掉 Garmin Connect 的自动管理 → 手动允许自动启动与后台运行 |
| 小米 | 安全 → 电池 → 应用省电模式 → Garmin Connect → 背景设置 → 无限制 |
| 三星 | 设置 → 应用 → 右上角三点 → 特殊访问 → 优化电池使用 → 找到 Garmin Connect 禁用优化 |
| 一加 | 设置 → 应用和通知 → 查看全部 → Garmin Connect → 高级 → 电池优化 → 不优化 |
| Pixel | 设置 → 应用和通知 → 高级 → 特殊应用访问 → 电池优化 → 所有应用 → Garmin Connect 设为不优化 |
| 摩托罗拉 | 设置 → 电池 → 右上角三点 → 电池优化 → Garmin Connect 设为不优化 |
| LG | 设置 → 电池 → 电池使用情况 → 忽略优化 → Garmin Connect |
| Unihertz | 智能辅助 → 应用程序拦截器 → Connect → 关闭后台清理与启动阻止程序 |

## 三、iPhone 补充两处

1. 显示预览：设置 → 通知 → 显示预览选「始终」或「解锁时」——锁屏预览被关，手表上也出不来内容。
2. 专注模式（iOS 15/16）：勿扰、睡眠、个人、工作这些模式开着时，手表不会弹通知，通知只会进手表的通知小工具。要不要为了通知关掉它，你自己取舍。

## 四、都开好了还是收不到

重启手机和手表再试一次；仍不行，按[常见问题与故障排查](常见问题与故障排查.md)第一节走一遍重配对——连接本身不稳时，通知是第一个躺下的。
