手表同步之后，App 里能看的东西比表盘上多得多。本篇按健康、运动、概览三类列出能看到什么、在哪看。

## 一、数据从哪来、在哪看

数据由手表采集，通过蓝牙同步进 App（连接状态看首页绿点，配对方法见[手表配对与连接设置](手表配对与连接设置.md)）。App 的「重点关注」板块集中放最常用的几项：睡眠分数、身体电量、训练状态。新版支持自定义主页布局，把自己最常看的卡片调整到顺手的位置。

具体到你的表，哪些指标有、哪些没有，取决于手表型号——下表是 App 侧支持的完整口径，以你实际同步出来的结果为准。

## 二、健康类数据

| 指标 | 你能看到的 |
| --- | --- |
| 睡眠 | 时长、睡眠分数、睡眠阶段（浅睡/深睡/快速动眼），附改善建议 |
| 身体电量 | 5～100 的能量值，休息后回升、消耗后下降，用来安排运动或休息 |
| 压力 | 全天压力水平走势 |
| 热量 | 活动消耗与日常代谢分开统计，看运动量够不够 |
| 身体年龄 | 按实际年龄、运动量、静息心率、身高体重估算，与实际年龄对比着看 |
| 体重 | 接佳明智能体脂秤自动同步；没有秤可以手动输入 |
| 女性健康 | 月经周期与孕期记录，附运动和营养建议 |
| 用户洞察 | 把你的睡眠、步数与同年龄段/同性别群体对比 |

## 三、运动记录

- **跑步**：配速、心率、轨迹、训练效果、恢复时间。
- **骑行**：速度、路线、心率，以及踏频/功率等传感器的数据。
- **力量训练**：训练类型、次数、目标肌群。

App 内的训练计划目前免费使用（口径来自官方产品页，以官方当时说明为准）。训练状态、训练负荷、耐力得分这类进阶指标归在概览统计里，见下一节。

## 四、概览统计

概览部分逐项点开能看趋势：心率、步数、HRV（心率变异性）、最大摄氧量、训练负荷、耐力得分。每项都能切换时间维度看走势。

## 五、看的顺序

1. 手表戴着过一天或一场运动。
2. 打开 App 等它自动同步，或下拉手动同步。
3. 首页看当天，概览看趋势。
4. 要翻更全的历史报表、导出记录，去网页版，入口见[账号注册与数据同步](账号注册与数据同步.md)。

同步迟迟不出数的情况，按[常见问题与故障排查](常见问题与故障排查.md)的同步一节处理。
