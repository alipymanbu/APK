# Jibi 卡在加载中与闪退黑屏怎么办

> 应用打不开、卡在「合养加载中」、闪退或黑屏时，按这篇从轻到重处理。

## 一、先分清你遇到的是哪种

三种症状的成因和处理完全不同，别一上来就清数据重装：

| 症状 | 常见原因 | 首选处理 |
| --- | --- | --- |
| 卡在「合养加载中」转圈 | 网络不稳、服务端同步慢 | 切网络 + 重启，**别反复点登录** |
| 打开就闪退 / 黑屏 | 本地缓存损坏、存储不足、版本过旧 | 清缓存 → 仍不行再清数据 |
| 数据错乱、内容对不上 | 同一个设备登了两个账号 | 收敛到一个账号，等同步 |

## 二、卡在「合养加载中」

按顺序试，每做一步等它跑 1~2 分钟再判断：

1. **别反复点登录**——多个第三方页面都特别提醒这一点：狂点登录会让多个请求挤在一起，越点越卡。
2. **换网络**：Wi-Fi 和移动数据互切一次；路由器不稳就重启路由器。加载要联网拉云端数据，网络是第一嫌疑。
3. **杀掉进程重开**：从最近任务里划掉应用，重新打开。
4. **只清缓存**（不清数据）：手机 **设置 → 应用管理 → 找到 Jibi → 存储 → 清除缓存**，然后重启应用。缓存是临时文件，清了不丢进度。
5. 还卡着，稍后再试——可能是服务端在忙；持续多天如此，走应用内反馈。

## 三、闪退或黑屏

从轻到重四步，**每一步都先确认已登录且记得账号**：

1. **看存储空间**：安装包 53.93 MB，运行还要留几百 MB 余量（第三方页面建议预留 500 MB 左右），空间不足是最常见的闪退原因。
2. **清缓存**：同上第二节第 4 步。
3. **清数据**：**设置 → 应用管理 → Jibi → 存储 → 清除数据**（会清掉本地未同步的内容，所以第 1 步里确认登录很重要）。清完重新打开、登录原账号，等云端数据加载回来。
4. **卸载重装**：清数据还不好就重装。装包从 [Jibi 安装文件资源（夸克网盘）](https://pan.quark.cn/s/fb4609b525c4) 重新拿，校验方法见 [下载与安装教程.md](下载与安装教程.md)；重装后登录原账号。

清数据前若有未同步的重要进度，先进应用等一次同步完成（网络正常时打开应用即可触发）再动手。

## 四、别让两个账号打架

有第三方页面明确提醒：**不要在设备上同时登录两个账号**，会造成合养数据错乱。具体表现是小家内容对不上、进度回退这类「数据不对劲」的症状——它不是丢数据，是两套数据在互相覆盖。

处理：退出当前账号 → 重新登录你常用的那个 → 保持只用这一个账号，等同步完成。换手机、借别人设备临时登过，回来也照这个流程收敛一次。

## 五、什么时候放弃自救

出现以下情况就别自己折腾了，直接走应用内客服/反馈（反馈带三件套：版本号、机型、症状截图）：

- 清数据 + 重装 + 换网络都试过，仍然必现闪退；
- 反复出现数据错乱，且确认只用一个账号；
- 卡在加载超过一天且网络与其他应用都正常。

账号、剧情、进度类问题的常规排查在 [常见问题与故障排查.md](常见问题与故障排查.md)；装不上、权限问题在 [下载与安装教程.md](下载与安装教程.md)。
