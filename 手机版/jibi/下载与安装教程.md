## 一、Jibi 是什么

Jibi 是一款「跟梦角合养叽比酱」的养成加 AI 陪伴应用：你先定制一个叫「梦角」的虚拟角色，再和它一起领养电子萌宠 Jibi酱（商店中文名写作「叽比酱」），喂食、玩耍、哄睡，布置属于两个人的小家。本篇只解决一件事——把安装包装进手机并成功打开。

开发者是成都快乐一点科技有限公司（iOS 商店显示为 HappyBit Tech Co., Ltd.），包名 `com.jibi.app`，界面语言为简体中文，应用本身免费下载、含应用内购买。

## 三、安卓安装步骤

1. 从网盘下载 `jibi_v1.3.7.apk` 到手机（用浏览器下载或先转存到网盘客户端再下载均可）。
2. 点开 APK 时系统会拦「禁止安装未知来源应用」——这是 Android 的默认保护，不是病毒提示。按提示进入 **设置 → 安全（或「隐私 / 应用安装」）→ 允许安装未知来源应用**，给你的浏览器或文件管理器放行，返回后继续安装。各品牌路径略有差异：小米在「应用设置 → 安装未知应用」，华为在「安全 → 更多安全设置」，路径名称以你的系统为准。
3. 安装完成点「打开」。首次启动会依次申请网络、通知、相册等权限，按自己的意愿允许或拒绝——拒绝联网类权限会让应用无法工作，其余可后续在系统设置里再改。
4. 进入登录/注册界面后，建议先登录再开始玩法，换手机时同账号才能把小家和养成进度接上（见 [常见问题与故障排查.md](常见问题与故障排查.md)）。

安装失败「解析包出错」或装到一半报错，一般是 APK 没下完整——重新下载一次再装，MD5 对不上就说明文件有问题。

## 四、首次启动会用到的权限

安卓商店页面公示的权限里，日常会真正弹出来的是这几类：

| 权限 | 用在哪 |
| --- | --- |
| 网络访问 | 登录、对话、云端同步——必须给 |
| 通知 | 互动提醒、任务提醒 |
| 相机 / 相册读写 | 给角色或小家上传、更换图片 |
| 录音 | 语音相关的互动功能 |
| 存储读写 | 保存图片与本地缓存 |
| 振动 / 媒体播放控制 | 提示音与语音播放 |

权限以应用实际申请为准，拒绝非必要权限不会影响核心玩法。
