## 一、安装前先核对这些信息

| 项目 | 值 |
| --- | --- |
| 版本 | 4.00.25 |
| 包名 | com.wajijiwa.club |
| 安装包大小 | 78.76M |
| MD5 | 61cd4abc3e2578967fa8ad6aa9a86aa7 |
| 信息核对时间 | 2026-09-22 |

上面这张表是本文所指安装文件资源里那个安装包的实际信息。weecho 迭代较快（2026 年下半年第三方应用市场已收录 4.00.28 及更高版本），想要最新功能可以去官方渠道（官网 [www.weechoapp.com](https://www.weechoapp.com/) 或各应用商店）装最新版；只想用这一版，就按上表核对。

系统要求：第三方应用市场标注为 Android 6.0 或更高版本；iPhone 用户在 App Store 有独立版本，本篇只讲安卓安装。

## 二、从网盘拿到安装包

1. 打开头部的 [weecho 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cf893784a87d)链接；
2. 把里面的安装包转存到自己的网盘，再从网盘下载到手机存储；
3. 下载完成后，可以用文件管理器或校验工具核对一下 MD5 是否与上表一致，不一致说明包没下完整，重新下载即可。

## 三、安装步骤

1. 在文件管理器里点开下载好的 APK 文件；
2. 系统提示"允许安装未知来源应用"时，按手机引导去设置里允许（各品牌入口不同，一般安装时会直接弹出跳转）；
3. 等待安装完成，点打开；
4. 首次打开需要登录，怎么登、登不上怎么办，见 [注册登录与账号管理.md](注册登录与账号管理.md)。

## 四、装不上时的排查方向

- **提示"解析包出错/解析失败"**：包没下完整，重新下载并核对 MD5。
- **提示"应用未安装"**：手机里已装更高版本的 weecho 时，低版本无法覆盖安装；先卸载已装的版本（会清掉本地登录状态与缓存）再装这一版。
- **装好了但打不开**：先重启手机再试；还不行就去 [注册登录与账号管理.md](注册登录与账号管理.md) 看登录与账号相关的排查。
- **提示存储空间不足**：清理出比 78.76M 更大的余量（安装过程需要的空间比包本身大）后再试。

## 五、想在电脑上用

weecho 没有官方 PC 客户端。腾讯应用宝的官方页面提供了在电脑上运行的方案：用"应用宝电脑版"（运行 Android 环境的模拟器）装 weecho——访问 [sj.qq.com](https://sj.qq.com/) 下载应用宝电脑版并安装，在其中搜索 weecho 进入详情页点安装即可，应用宝页面称账号数据可手机电脑跨端互通。这是第三方模拟器方案，以应用宝页面当时的说明为准；本篇网盘里的安卓安装包也可以直接拖进模拟器安装。
