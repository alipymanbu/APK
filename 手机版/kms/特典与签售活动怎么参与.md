## 一、KMS 特典是什么

KMS 特典是 KMStation 作为销售渠道自己加的赠品，和专辑里原本自带的配置分开算。商品标题里的「KMS特典」「KMS幸运卡特典」「独家特典」指的都是这一类。

常见的发放形态：

| 形态 | 规则 |
| --- | --- |
| 按版本给小卡 | 买哪个版本送对应版本的随机小卡，数量随购买张数增加 |
| 拍立得卡加赠 | 同一版本买两张以上时，在普通小卡外再加送随机拍立得卡 |
| 幸运卡特典 | 整张专辑随机掉一张指定款小卡 |
| 早鸟赠品 | 在活动截止日前下单，额外加赠（例如每张随单加一张随机拍立得卡） |

举一个真实活动的结构作参考：某次 NCT WISH 专辑预售把特典分成 VER.1~VER.5 五套，分别对应 Package / Jewel Case / SMini / Big SMini 四个版本与「四版本整套购买」这一情形，4 月 19 日前下单再额外加赠拍立得卡。每一期的规则、样式、门槛都不一样，**下单前把当期商品页的特典公告逐条读完再付款**，避免到手后预期落差。

## 二、签售活动有哪几类

App 与网页商城里常驻的活动形式（首页入口随档期轮换）：

| 形式 | 说明 |
| --- | --- |
| 线上视频签名会 | 中选后与艺人 1 对 1 视频通话进行签名 |
| 线下签售 | 到公告指定的现场参加 |
| 一日店长 | 艺人以「一日店长」形式参与的宣传期活动 |

App 内设有「中签公告」「活动日历」栏目：中选名单在 App 里发布，活动档期看日历。

## 三、参与流程（以官方公告口径为准）

以官方发布过的一次 RIIZE 视频签名会公告为例，流程是：

1. 招募期内进入 App，点开该艺人签名会的招募链接；
2. 通过链接下单购买指定专辑，购买即获得抽选资格；
3. 招募期结束后公布中选名单（公告里写明公布时间与发布位置）；
4. 中选者按公告的时间参加 1 对 1 视频签名会。

每一次活动的时间、抽选规则、限购数量都不同，报名前逐条读当期公告；时间均以公告标注的时区为准。

## 四、粉丝团与交换区

- **粉丝团**标签页按艺人组织内容：活动专区、成员生日周边这类艺人专属商品页都在这里；
- **交换区**用来发帖交换小卡等周边：进首页功能区的「交换区」→ 点右上角「+」→ 选择分类、填写内容、上传凭证 → 提交后在交换区展示。

交换帖子由用户自行发布，交易对象与方式自行把握，上传的凭证图记得打码个人信息。

另外，别忘了在「我的 - 我的订单」里跟进预售订单的物流状态，相关口径见[订单售后与常见问题](订单售后与常见问题.md)。
