## 一、注册前准备什么

- **一个能正常收信的邮箱**：注册走邮箱验证。官方公告里给出的流程就是「选择中文-韩国区域，进行邮箱注册，注册成功即可下单」，没有提到手机号注册；
- **收货信息**：直邮订单要填收件人姓名与电话，可以提前想好写什么。

## 二、注册流程

1. 打开 App，切到「我的」标签，点头像处的「登录/注册」；
2. 语言选中文、地区选韩国（即官方公告说的「中文-韩国区域」），然后用邮箱完成注册；
3. 注册成功后回到「我的」页，头像位置变成已登录状态，即可下单。

没收到验证邮件时，先翻垃圾箱；仍收不到就换一个邮箱再试。

## 三、区域选错了怎么办

区域会影响商品展示与配送范围。注册时选错了，先去「我的」页的设置里找有没有区域切换入口；找不到的话直接联系客服处理（见[订单售后与常见问题](订单售后与常见问题.md)里的客服入口）。

## 四、「我的」页各入口管什么

| 入口 | 用途 |
| --- | --- |
| 我的订单 | 按待付款 / 待发货 / 待收货 / 已完成 / 退款售后五类分组 |
| 我的优惠券 | 查看与使用可用的优惠 |
| 我的收藏 | 收藏的商品，比价与等补货用 |
| 我的足迹 | 浏览记录，找看过的商品 |
| 地址管理 | 维护收货地址 |
| 联系客服 | 下单前后的咨询入口 |

## 五、收货地址怎么填

直邮订单从韩国仓发出，地址要写到国内快递能正常派送的粒度：省市区 + 详细街道地址 + 收件人 + 手机号。建议在「地址管理」里提前填好，下单时直接选，避免临时手填出错。

地址写错是跨境件最常见的麻烦来源：包裹出库后再改地址基本来不及，下单前多看一眼。
