## 一、订单状态对照

「我的 - 我的订单」按五种状态分组，每一步该做什么不一样：

| 状态 | 含义 | 这一步该做什么 |
| --- | --- | --- |
| 待付款 | 已下单未付款 | 在时限内付款，超时订单可能自动取消 |
| 待发货 | 已付款，等仓库出库 | 预售商品等当期出库时间，现货一般更快 |
| 待收货 | 已出库在途 | 在订单详情里查物流进度 |
| 已完成 | 签收结束 | 缺件、破损在这一阶段申请售后 |
| 退款售后 | 有退款/售后单在走 | 跟进处理进度，按需补凭证 |

## 二、退款售后怎么走

1. 进「我的订单 - 退款售后」，找到对应订单发起申请；
2. 写清原因，需要照片、单号等凭证时及时补传；
3. 跟进处理进度，拿不准就同步问客服。

跨境订单的退换规则和国内电商不完全一样，大件或拆封商品退不退得了，下单前先和客服确认一次。具体条款以商品页说明与客服答复为准。

要有心理准备的一点：在投诉平台与媒体报道里，「退款入口难找、客服不回复」是持续多年的常见反馈。申请发出去没回音时，按[预售不发货怎么办](预售不发货怎么办.md)里的路径推进（留证据、盯确认收货倒计时、必要时走 12315），而不是反复等。

## 三、联系客服的几个入口

- App「我的」页底部的「联系客服」；
- 官网公示的联系邮箱：`kms@aka.yeah.net`（以官网当时公示为准）；
- 官方网站：[KMStation 官网](http://www.kmstation.net/) / [KMStation Mall 网页商城](https://client.kmstation.net/)。

问物流问题时，直接把订单号和商品名一起发给客服，来回要少好几轮。

客服入口报错、长时间不回是在公开投诉里出现频率最高的场景之一。换个时段重试、再试官网渠道都不通时，直接按[预售不发货怎么办](预售不发货怎么办.md)第三节的外部渠道推进，别在单个入口上反复耗。

## 四、常见问题

**搜「kms」出来全是激活工具？**
那是 Windows 的 KMS 激活工具，与这个购物应用无关。认准包名 `com.KMStation.benben`，或直接从[下载与安装教程](下载与安装教程.md)里获取 KMStation 安装文件资源。

**价格旁边的 starting 是什么意思？**
起步价：对应最低配置版本的价格，换版本或加购配置后价格会上浮。

**预售要等多久？**
出库时间看商品页标注；出库后还有国际运输与清关，整体时效会浮动。长时间无物流更新再问客服，日常催促意义不大。

**小卡抽重了能换吗？**
App 内有「交换区」可以发帖与其他用户交换，发帖步骤见[特典与签售活动怎么参与](特典与签售活动怎么参与.md)。

**预售超时还没发货？**
先核对商品页承诺的发货时限并截图，然后按[预售不发货怎么办](预售不发货怎么办.md)的路径处理：App 内申请 → 盯物流与确认收货倒计时 → 外部渠道投诉。

**网上搜到的版本号比 1.8.2 新？**
官方会持续发新版本，商店里的版本号通常更新。你手上那份 KMStation 安装文件资源以实际下载到的为准，日常下单与查单不受版本影响；确实需要新功能时，再从官方商店渠道升级。
