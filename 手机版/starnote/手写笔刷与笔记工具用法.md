## 一、新建笔记：先选封面和纸张

进入应用后在「全部笔记」里点新建，先给这本笔记选封面与纸张模板。内置模板里有康奈尔笔记法、麦肯锡笔记法、东京大学笔记法、SQ3R 学习法这类学习法模板，也有网格、点阵、空白和计划本，建好之后在页面设置里还能换。

按场景选：

| 场景 | 顺手的选择 |
| --- | --- |
| 上课/开会记要点 | 康奈尔模板或横线空白页 |
| 刷题 | 网格或点阵，配合图层用（见第三节） |
| 日程与周计划 | 计划本类模板 |

## 二、笔刷与笔盒

| 工具 | 你什么时候用它 |
| --- | --- |
| 钢笔 | 日常书写主力，笔触随力度变化 |
| 铅笔 | 打草稿、画草图 |
| 荧光笔 | 在已有文字上划重点 |
| 马克笔 | 大面积粗线条标注 |

每支笔都能调粗细、透明度与颜色；颜色既可以用官方推荐色集，也可以开调色盘自调。

**笔盒**：把常用的几支笔加进笔盒，再按场景分组——比如「上课组」放一支钢笔一支荧光笔，切换文档时直接选组，不用每次重新调参数。

**实时字迹调整**：开启后手画的直线、波浪线、圆会被自动修整成规整形状；想要保留手绘原样就把它关掉。较新的版本还加了「字迹美化」，能把写完的字迹整体修饰得更工整，你手上这版有没有它，以编辑页菜单为准。

## 三、图层：把批注和原稿分开

图层功能让你把不同内容画在不同的层上：导入的文档算一层，你的批注算一层，贴的图片又是一层。刷题时想对答案就只显示答案层，想重做就清掉批注层，原稿不受影响；做手帐时素材和字迹互不干扰，后期调整也省事。

## 四、文具工具

- **橡皮**：支持反复涂抹擦除的手势，擦字迹不容易误伤旁边的内容；新版还支持压感橡皮；
- **套索**：圈选一段字迹或图片后整体移动、缩放；较新的版本加了精准套索与镜像翻转（水平/垂直）；
- **胶带**：盖住一段内容，复习时点开对答案——背单词、背知识点时用；
- **贴纸**：给笔记加标签、箭头、图标类装饰；
- **尺子**：画直线、量角度（新版支持手动输入角度）；
- **计时器**：限时刷题或专注计时（较新版本加入）；
- **放大镜**：把局部区域放大来写小字，适合在密排文档的行间批注；
- **表格**：在笔记里插入表格做排版。

这些工具的位置和叫法随版本略有差异。工具栏可以自定义，常用手势也能在设置里改；官方帮助中心 [mystarnote.cn/help](https://mystarnote.cn/help) 对橡皮、自定义颜色集与笔刷、手势设置这些都配了图文教程，找不到入口时去那里翻最省事。

## 五、无界笔记与页面扩展

普通笔记是一页一页的，无界笔记是一张无限延伸的画布：画思维导图、列长清单时不受页面边界限制，往哪个方向都能继续写。对导入的文档，可以用「页面留白」把版面调开，在密排的文献旁边空出写字的地方——具体怎么调见 [PDF导入与批注设置.md](PDF导入与批注设置.md)。

写完的笔记想备份或导出成 PDF，见 [备份同步与笔记导出.md](备份同步与笔记导出.md)。
