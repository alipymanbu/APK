## 一、能导入哪些格式

| 格式 | 典型用途 |
| --- | --- |
| PDF | 课件、试卷、电子书、报告 |
| DOC / DOCX | 讲义、通知、报告 |
| PPT | 课件，一页一张幻灯片 |
| EPUB / MOBI / AZW3 | 电子书 |
| CAJ | 知网下载的文献 |
| TXT | 纯文本材料 |
| 图片 | 拍照的纸质资料、截图 |

CAJ 支持对常查文献的人比较实用——不少安卓批注应用不认这个格式。

## 二、导入路径

1. 在应用内新建或进入一本笔记，用「导入」选择设备里的文件；
2. 也可以直接拍照或选图片，把纸质资料拍进来批注；
3. 导入后每一页都可写，选支笔就能直接在页面上写。

## 三、页面留白：给密排文档腾地方

导入的 PDF 排版通常很满，直接批注没地方写字。用页面留白功能把文档往一侧缩，空出的白边就是你写笔记的地方；原文件的排版不动，导出时你的批注也跟着页面一起走。给整本教材留批注位、给试卷留演算位，都是这一个功能。

## 四、双开：一边看文档一边记笔记

开启双开后屏幕分成两块，左边读 PDF、右边写笔记——上课「课件在左、笔记在右」，读文献时把摘录写在旁边，都靠它。入口在编辑界面的视图/分屏设置里，不同版本的叫法略有差异（双开、分屏、并排视图），找不到就在编辑页顶部工具栏找带分屏图标的按钮。官方帮助中心（[mystarnote.cn/help](https://mystarnote.cn/help)）有一篇「双开｜探索笔记的多种玩法」的图文教程。

看视频网课还可以配合画中画：课程视频浮成小窗，你在笔记里接着写，这是官方商店页面写明的用法。

## 五、批注之外能做的事

- **摘录**：把文档里的一段文字或一处图摘出来，引用到另一本笔记里，两处内容互相链接，复习时顺着链接能跳回原文；
- **标签**：给笔记打标签、搭知识框架，官方帮助中心有「标签｜构建知识体系框架」专文；
- **划词翻译**：读外文文献时选中即译；
- **OCR 搜索**：导入的 PDF 与手写内容都能按关键词搜；
- **合并/拆分**：把几份文档合成一份，或把一份拆开重排。
