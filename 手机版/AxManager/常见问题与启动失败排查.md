## 一、症状速查表

| 症状 | 先查什么 | 再做什么 |
| --- | --- | --- |
| 一直「正在搜索配对服务」 | AxManager 是否被允许后台运行 | 按第二节处理 |
| 输入配对码后立刻失败 | 用的是不是 MIUI/POCO | 按第三节改通知样式 |
| 提示 adb 权限受限 | 品牌专属开关 | 按第四节对照表处理 |
| 服务跑着跑着没了 | USB 用途模式、后台限制 | 按第五节逐条检查 |

官方 FAQ 在 [fahrez182.github.io/AxManager/guide/faq.html](https://fahrez182.github.io/AxManager/guide/faq.html)，以下内容以其为底本整理，口径有出入时以官方页面为准。

## 二、一直「正在搜索配对服务」

配对搜索要走本地网络，而很多系统在应用退到后台后就切断它的网络。处理：

1. 在系统设置里找到 AxManager 的电池/后台策略，改成允许后台运行（各品牌入口不同，可搜「机型 + 应用后台运行」）。
2. 确认手机在 Wi-Fi 下，重新走一遍配对流程（步骤见 [无线调试启动与配对教程.md](无线调试启动与配对教程.md)）。

## 三、输入配对码后立刻失败

MIUI / POCO（含澎湃 OS）：在系统设置的通知相关页面里，把通知样式切换为「Android」。原因是配对码输入框靠一条系统通知弹出，MIUI 默认样式会把它挡住。不同 MIUI 版本的入口名称略有差异，找不到就搜「MIUI 通知样式 Android」。

## 四、提示 adb 权限受限

部分国产系统默认给 adb 的权限打了折扣，需要在开发者选项里单独改：

| 系统 | 开发者选项里的操作 |
| --- | --- |
| MIUI（小米 / POCO / 红米） | 打开「USB 调试（安全设置）」——它和「USB 调试」是两个独立开关 |
| ColorOS（OPPO / 一加 / 真我） | 关闭「权限监控」 |
| Flyme（魅族） | 关闭「Flyme 支付保护」 |

改完后重新执行启动步骤即可，不用重装应用。

## 五、服务随机停止

所有设备都建议逐条检查：

1. 允许 AxManager 在后台运行。
2. 不要关闭「USB 调试」和「开发者选项」开关。
3. USB 用途改成「仅充电」：Android 8 在「选择 USB 配置」里选「仅充电」；Android 9 及以上在「默认 USB 配置」里选「不进行数据传输」。
4. Android 11 及以上：打开「停用 adb 授权超时」。

品牌专属操作：

| 品牌 | 操作 |
| --- | --- |
| EMUI（华为） | 开发者选项里打开「仅充电模式下允许 ADB 调试」 |
| MIUI（小米） | 不要用系统「安全」App 里的扫描功能——它会替你关掉「开发者选项」 |
| Sony | 连接 USB 后弹出的对话框不要点确认，点了会改变 USB 用途模式 |

## 六、其他问题

- **闪退**：MediaTek 平台的设备在旧版本上有触发崩溃的情况，v1.4.7 的更新说明里提到加入了对应的回退处理与崩溃报告页面。先升级到新版再用；反馈问题时带上应用内生成的崩溃报告。
- **服务没启动时插件全部失效**：这不是插件坏了，先把服务跑起来。插件相关的其他排查见 [插件与WebUI使用入门.md](插件与WebUI使用入门.md) 第七节。
- **需要重装**：安装步骤与版本核对信息见 [下载与安装教程.md](下载与安装教程.md)。
