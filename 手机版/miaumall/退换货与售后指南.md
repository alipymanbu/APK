## 一、发货前：取消与修改

订单状态不同，代价完全不同：

| 订单状态 | 取消 | 修改 |
| --- | --- | --- |
| 待付款 | 直接在订单上点「取消订单」 | 重新下单即可 |
| 已付款、未打包 | 免费取消，走「申请退款」 | 不能直接改；可申请退款后重新下单 |
| 已打包（已拣货装箱） | 取消会从退款里扣 1,000 日元打包费 | 联系客服尝试调整（换货、加单等），可能产生拆包 / 操作费 |
| 已发货 | 无法取消 | 商品内容无法调整；改地址仍可联系客服协调快递方 |

改地址（收件人、电话、地址）本身也可能被收取最高 1,400 日元的附加费，取决于订单处理到哪一步。想改地址、想调整内容，动作越早越便宜；已发货订单想改地址，费用由快递方与处理状态决定。

另一个省钱路径：付款后 72 小时内发现同款降价，可以按价格保障政策退差价（规则见 [注册登录与下单流程.md](注册登录与下单流程.md)）。

## 二、签收后 7 天：售后窗口怎么用

售后服务的期限是**签收后 7 天**（不含因清关异常、物流原因导致包裹退回的情形）。想退换，按这个顺序走：

1. **先拍照再拆箱**：外包装破损或有不正常开封痕迹的，拆之前先拍下来；拆开后发现商品缺件、破损，同样拍照、保留包装盒。没有证据的索赔基本立不住；
2. 联系在线客服，说明订单号与问题，上传照片，等客服审核并给出处理方案；
3. 如果方案要求寄回商品，客服会填好退货单（含订单号、用户名、联系电话、退货原因），你确认信息无误后随包裹寄出，**退货运输方式选与平台发货相同的那家**；
4. 平台收到退回商品、确认无误后，1–3 个工作日内启动退款或换货流程。

两个坑别踩：

- **不联系客服直接把东西寄回去**，包裹丢了平台不担责；
- 美容仪器收货后**尽快通电测试**，保修认定与 7 天窗口都按签收时间起算。

## 三、可退与不可退对照

以官方退款政策页的口径整理（截至本文撰写，以官方页面为准）：

| 可以申请退款 | 明确不退 |
| --- | --- |
| 签收后 7 天内提出申请 | 7 天之后才提的 |
| 未开封、原装未损坏的商品 | 已损坏或人为改变的物品 |
| 原厂保修范围内的缺陷品 | 缺配件、赠品、说明书、保修卡的 |
| 订单发错（商品或数量不符） | 标注「最终销售」的特价品 |
| 到货时已过保质期的（下单时未标注临期的） | 运输中因温度融化变形的（巧克力、糖果等） |
| 查实非日本正品的 | 因个人过敏反应要求退的护肤 / 美妆品 |
| | 手工制品的轻微外观瑕疵（不影响使用的溢胶、走线） |

另外几条容易被忽略的规则：

- **隐形眼镜、高价商品（美容仪器等）、预购商品**付款后不支持退款，商品页有免责声明，买之前看清楚；
- **医药产品**除质量问题或发错货外，售出后不退不换；
- 化妆品色号与肤色不符、香味不合口味这类「主观不合预期」，不在退换理由里；
- **退货会连累积分与赠品**：订单获得的档位积分、免费赠品会被扣回，已兑换的积分券或已用掉的赠品按价值从退款里扣（积分规则见 [积分获取与兑换规则.md](积分获取与兑换规则.md)）。

## 四、退款到账

- 退款一律**原路退回**（原支付的信用卡、PayPal 等渠道），不能指定别的方式接收；
- 中文平台口径下退款以日元处理，最终到手金额受支付渠道汇率影响；
- 符合条件的退款一般在审核后 1–3 个工作日发起，到账时间取决于你的支付渠道（信用卡账单周期、PayPal 余额等）；
- 包裹因收件人信息错误或无人签收被退回日本的情况，退款会在 3–5 个工作日内处理，但要**先扣掉退回运费**（连同 2,000 日元退回手续费，见 [运费配送与清关.md](运费配送与清关.md) 的附加费一节）。

## 五、缺件与停产

- 包裹发出前商品缺货：官方会先联系你（邮件 / 短信 / 电话），都联系不上时先寄其余商品、盒内放缺货说明，缺货部分约 5–7 个工作日内退款；
- 发错货导致缺件：向客服反馈后由平台核查，核实为平台失误的退款；
- 商品停产或下架：客服会主动联系，给你换货或退款二选一。

处理物流类异常（丢件、显示已送达未收到）的时限要求，见 [运费配送与清关.md](运费配送与清关.md) 最后一节；优惠券、积分、账户类的零散问题收在 [常见问题解答.md](常见问题解答.md)。
