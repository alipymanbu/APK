## 一、配送范围

官方运输政策列出的直邮目的地（截至本文撰写，以结账页实际可选地区为准）：

澳大利亚、新西兰、美国、加拿大、英国、土耳其、新加坡、马来西亚、迪拜、法国、德国、意大利、西班牙、奥地利、爱尔兰、荷兰、秘鲁、印度尼西亚、缅甸、菲律宾、香港、澳门、台湾、保加利亚。

承运商是 FedEx 或 DHL（个别情况经第三方物流中转）。列表里没写到的地区不代表完全寄不了，官方的说法是可以联系客服按地址单独确认。

## 二、运费与免邮门槛

以中文 FAQ 的日元口径（订单金额满门槛免运费）：

| 目的地 | 免邮门槛 | 未满门槛时的运费 |
| --- | --- | --- |
| 澳大利亚、新西兰 | 16,000 日元 | 2,600 日元 |
| 美国、加拿大 | 13,500 日元 | 2,500 日元 |
| 英国及欧盟国家 | 15,000 日元 | 2,500 日元 |
| 其他地区 | 22,500 日元 | 2,500 日元 |

两点补充：

- 面向欧美市场的新版网页商店（miaumall.com）按国家用本币标运费（如美国 29 美元、满 149 美元免邮），与上表的日元口径不是一套数字 —— 以你下单那个渠道结账页算出来的为准；
- 运费里可能包含预缴的进口税费或操作费，具体构成以结账页明细为准。

## 三、处理与运输时间

把「离仓」和「国际派送」两段分开看，才知道包裹到底慢在哪一段：

| 环节 | 一般情况 | 备注 |
| --- | --- | --- |
| 离仓（出跟踪号前） | 3–5 个日本工作日 | 大型活动期间 4–6 个；日本新年、黄金周等假期顺延 |
| 零食类商品 | 下单后约 3–10 个工作日 | 部分商品零库存，下单后才向厂商采购 |
| 隐形眼镜 | 下单后约 3–7 个日本工作日 | |
| FedEx 派送（出跟踪号后） | 约 3–5 个工作日 | 特殊时期或地区 5–10 个工作日 |
| DHL 派送（出跟踪号后） | 约 2–6 个工作日 | 特殊时期或地区 6–8 个工作日 |

大型促销、日本法定假日期间整体可能延到 5–10 个日本工作日，官方在严重延误时会以代金券或余额形式补偿，并通过客服邮件通知。

**欧盟订单的特例**：包裹先在荷兰集拼，跟踪号生成后最长两周内可能都查不到轨迹；这类订单要用 DHL 德国官网（`https://www.dhl.de`）查询，而不是 DHL 全球站。

## 四、重量、件数与附加费

| 项目 | 规则 |
| --- | --- |
| 单票重量上限 | 10 kg；超出部分每公斤加收 1,500 日元（即使已满足免邮也照收），大幅超出时平台有权调整或取消订单 |
| 单票件数上限 | 50 件；部分单品有各自限购数量，购物车会自动调整 |
| 偏远地区附加费 | 收件地址在快递公司划定的偏远地区时加收，标准 2,600 日元（以实际收取为准，由快递方向你收取） |
| 无人认领退回 | 按个人原因未及时签收处理：退回手续费 2,000 日元 + 实际退回运费，重新寄送的费用同样自理 |

## 五、清关与税费

跨境包裹被海关抽检时，可能需要你提供身份证明等文件（护照信息仅用于报关，官方口径为保密处理）。因不配合清关导致包裹退回的，退款会在扣除退回运费和快递费用后发放。

税费按目的地不同差别很大，付款前先看清结账页有没有把税算进去：

- **美国**：官方政策为结账时按订单收取 10% 进口费，页面显示的实付金额即最终价格（免邮订单会标注「Free Shipping with Import Fees Paid」之类字样）；
- **欧盟**：VAT 在结账时一并收取；
- 其他地区：多数情况下收件时可能被快递方或海关要求补税、出示证件，这部分属于当地进口规则，由收件人自理（保加利亚这类需要 EORI 号的地区，官方明确不代办这类文件）。

## 六、查物流与异常件

1. 在 App 里进「我的订单」→「已发货」→「查询发货情况」，复制发货单号；
2. 到 FedEx 或 DHL 官网粘贴查询；欧盟订单按上一节的说明走 DHL 德国官网。

两种常见异常的处理时限：

- **显示「已送达」但没收到**：三个工作日内联系在线客服；期间快递方可能电话或邮件联系你，保持畅通；
- **长期无轨迹 / 疑似丢失**：同样先走客服登记。但注意几种情况不在赔付范围内 —— 收件人姓名或地址写错、地址变更导致无法派送、收件人不配合快递方调查、未在约定时间内联系官方反馈问题。

下单前后悔怎么取消、货不对板怎么退，是另一条流程线，见 [退换货与售后指南.md](退换货与售后指南.md)。
