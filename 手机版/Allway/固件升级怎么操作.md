固件是跑在耳机本体上的那套程序，和手机里装的 Allway 应用不是一回事：应用从应用商店更新，固件只能通过连上设备的应用来升级。这条路径决定了升级的两条硬前提——**设备必须连着、中途不能被断掉**。下面按入口、准备、步骤、失败处理讲一遍。另外提醒一句：应用本身的版本（网盘里那份是 2.16.5）和固件版本是两套编号，别把两个数字混在一起看。

## 一、升级入口在哪

固件升级的入口在设备的设备管理页面里，不在应用的全局设置里：

1. 打开 Allway，进设备列表；
2. 点你的设备进设备主页；
3. 找「固件」/「设备信息」一类的入口，进去就能看到当前固件版本和有没有可用更新。

**只有连上设备才能进这一页。** 显示未连接时先解决连接问题，见 [连不上耳机怎么排查.md](连不上耳机怎么排查.md)。

## 二、升级前的三项准备

| 准备项 | 具体要求 | 不做的后果 |
| --- | --- | --- |
| 电量 | 把耳机放回充电仓充满，升级全程让设备保持有电 | 中途断电可能升到一半失败，甚至设备起不来 |
| 手机 | 连着稳定的 Wi-Fi 或流量，升级期间保持应用停留在前台、屏幕别锁 | 固件包下载中断，或升级过程中断失败 |
| 距离 | 手机放在设备旁边，别走开 | 蓝牙链路中途断开，升级中断 |

升级过程通常要几分钟。这段时间里不要去戴耳机、不要开关充电仓盖、不要切换手机的网络，也不要在应用里点别的页面。

## 三、升级步骤

1. 耳机放回充电仓，保持仓盖打开放在手机旁边；
2. 进设备管理页，点进固件入口，让它检查一次更新；
3. 有可用更新时按提示确认升级，等进度走完；
4. 进度到 100% 后一般会提示升级成功，此时把耳机重新取出、正常连接一次；
5. 回到固件页确认版本号已经变了——这一步别省，能立刻发现「看着像是升级了、其实没成」的情况。

## 四、升级失败或卡住怎么办

按现象处理：

| 现象 | 处理办法 |
| --- | --- |
| 进度条长时间不动 | 先等满十分钟以上，别急着重试；超过这个时间再操作，中途反复点击只会让状态更乱 |
| 提示下载失败 | 检查网络，换个网络环境再试一次，优先用 Wi-Fi |
| 提示升级失败 | 把耳机放回仓里重新取出，重新连上后重试一次 |
| 反复失败 | 先看应用本身是不是最新版本——部分新固件要求较新的应用才能正确处理，应用版本与设备信息不匹配时升级容易失败 |
| 升级后设备连不上 | 先在手机蓝牙设置里忽略设备，重新配对一次；仍不行走官方售后 |

升级过程中途强行退出应用或拔掉设备，是最容易把设备弄到异常状态的操作，尽量避免。

## 五、升级后设置会不会丢

固件升级动的是设备本体的程序，和你在应用里配的灯光、按键映射、音效模式不一定是同一套存储位置，所以存在两种情况：设置保留，或者被重回到默认值。**升级完花一分钟回设备主页过一遍这三项**，比重用几周之后才发现灯光没有反应要省事：

- 灯光开关和颜色偏好；
- 左右耳的手势映射；
- 音效模式的选择。

发现被重置了，按 [灯光效果怎么设置.md](灯光效果怎么设置.md) 和 [触控按键和入耳检测怎么调.md](触控按键和入耳检测怎么调.md) 重设一遍即可，不影响其他数据。

## 六、两条提醒

- **只用应用内的升级入口**。耳机固件不走第三方渠道，任何网盘、论坛里流传的「固件助手」「刷机包」都不要用在设备上，来源不明的东西刷坏了没法恢复。
- **看升级说明再决定**。更新日志一般写明这次改了什么，官方站点 [allwaylife.com](https://allwaylife.com/) 与设备页都能看到版本信息；当前用着没问题、更新内容也和你无关的话，晚一两个版本再升完全可以。
