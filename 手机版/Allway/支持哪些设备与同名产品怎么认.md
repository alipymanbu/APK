# Allway 支持哪些设备与同名产品怎么认

> 本篇讲这个应用管的是哪些型号、哪些功能只对部分型号有效，以及怎么确认自己装的是对的 Allway 而不是同名的别的应用。

Allway 应用和 Allway 品牌设备是一对的：应用本身免费、能随便装，但它只认 Allway 自家的设备，别的品牌耳机即使在系统蓝牙里连上了，也不会出现在它的设备列表里。这也是「装了却没反应」最常见的原因。认设备、认应用、认渠道，这三件事理清，后面几乎所有问题都能对上号。

## 一、官方在支持的设备型号

截至 2026-09，品牌官网 [allwaylife.com](https://allwaylife.com/) 上在列的消费类产品主要有这几类：

| 类型 | 型号举例 | 形态特征 |
| --- | --- | --- |
| 入耳式真无线耳机 | T1 | 带主动降噪、自定义灯光 |
| 开放式（挂耳式）真无线耳机 | OE10 | 不堵耳、运动向、无降噪 |
| 开放式运动蓝牙耳机 | PL10、PL20 | 挂耳、运动向 |
| 蓝牙音箱 | Halo20 | 带灯光 |
| 蓝牙音箱 / 香薰 / 加湿三合一 | Aqua10 | 桌面场景 |

型号在售情况会随时间变化，这份清单只是给你一个对照口径，**你手上那台在不在其中、属于哪一类，以设备页和官方页面当时显示的信息为准**。

## 二、功能与型号的对应关系

同一个应用在不同设备上能做的事并不一样，这是最容易被误会的一条：

| 功能 | 哪些设备有 | 说明 |
| --- | --- | --- |
| 灯光效果 | 带灯型号（T1、Halo20 一类） | 不带灯的型号看不到这一项 |
| 主动降噪 | 入耳式带降噪的型号（T1 一类） | 开放式型号没有降噪可调 |
| 触控手势自定义 | 支持左右耳分别设置的型号 | 带物理按键的型号可映射项更少 |
| 入耳检测 | 入耳式型号 | 开放式结构不涉及 |
| 查找耳机（响铃 + 闪灯） | 支持该项的型号 | 需要设备在蓝牙范围内且已连接 |
| 固件升级 | 支持联网升级的型号 | 走设备管理页内的入口 |
| 助眠音乐 | 应用内入口 | 与设备型号关系不大，需要联网 |

**看到某个入口在别人的截图里有、你的应用里没有，先对照这张表，再怀疑应用。** 官方说明里也明确写过：部分功能仅适用于特定产品。

## 三、怎么确认自己的设备被认出来了

连上设备之后，按这三点判断应用是不是真的认出了具体型号：

1. 设备主页能显示出该型号对应的独有设置项（比如带灯型号才有灯光入口）；
2. 设备管理页能看到当前固件版本号；
3. 断电重连一次，设备仍出现在设备列表里，而不是每次都要重新搜。

三条都成立，说明连接和识别都正常。只连上蓝牙却在应用里找不到设备，多半是权限问题，见 [连不上耳机怎么排查.md](连不上耳机怎么排查.md) 第三节。

## 四、同名应用怎么区分

应用市场里名字相似、甚至完全同名的应用不止一个，混装的后果是设备永远不被识别。认这三项最稳：

| 认什么 | 正确值 |
| --- | --- |
| 包名 | `com.fenda.headset` |
| 开发者主体 | 深圳市大佳田智能有限公司 |
| 官网 | [allwaylife.com](https://allwaylife.com/) |

包名在手机「设置 → 应用 → 应用详情」里能看到；和上表不一致的，就是另一个应用，卸载掉再装本文配套的这一版。同一款应用在苹果设备上也有对应版本，界面与 Android 版不完全一样，别拿 iOS 版的截图对 Android 版的入口。

## 五、官方渠道和售后入口

- **产品与功能说明**：品牌官网 [allwaylife.com](https://allwaylife.com/)，产品页里会写清各型号的关键参数与支持的功能；
- **应用本身**：主流安卓应用商店里可搜到，iOS 侧也有对应版本；
- **售后与维修**：包装、随附说明书和官网上都能找到官方售后联系方式；官方保修的口径、排除项与寄修流程整理在 [保修和售后怎么走.md](保修和售后怎么走.md) 里。购买渠道（电商店铺）的客服同样可以受理。硬件故障不要自行拆机，拆过通常不在保修范围内。

设备连不上、功能找不到、要判断是不是硬件问题，可以先回 [连不上耳机怎么排查.md](连不上耳机怎么排查.md) 走一遍排查清单，再决定是否联系售后。
