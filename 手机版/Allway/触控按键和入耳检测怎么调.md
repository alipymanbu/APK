# Allway 触控按键和入耳检测怎么调

> 本篇讲怎么把左右耳的触控手势改成你想用的功能、能映射哪些操作，以及入耳检测开着和关着有什么差别。

默认的手势映射是厂商按大多数人习惯给的，不一定合你的用法：通勤时想动一下切歌、开车时想唤语音助手、跑步时想直接拨号，这些都可以在 Allway 里改。左右耳是分开配的，改之前先想清楚哪只手更顺手做什么，比改完再反复调要省事。

## 一、先弄清你的耳机是触控还是物理按键

改法不一样，别照抄别人的步骤：

- **触控面板的型号**：手势以「单击 / 双击 / 长按」为主，部分开放式型号还支持在面板上滑动；
- **带物理按键的型号**：可映射的通常只有「双击 / 长按」这类组合，具体以随附说明书为准。

在应用里进设备主页 → 找「按键」/「手势」一类的入口。看不到这个入口，说明你的型号不支持自定义，或者设备当前没连上。

## 二、左右耳分别设置

按键设置是按左右耳分开存的，一个常见做法是把最常用的操作留给惯用手那侧：

| 你想解决的事 | 建议怎么分配 |
| --- | --- |
| 听歌时频繁暂停/继续 | 惯用手那侧给单击或双击 |
| 经常切歌、换播客 | 另一侧给双击，避免和暂停抢同一个手势 |
| 骑车或跑步时要呼叫语音助手 | 给一个不容易误触的手势（长按通常比双击稳） |
| 开车时想少看手机 | 把快捷拨号映射到一个单手好按的手势上 |

改完记得退出页面再进一次，确认设置被记住了。

## 三、能映射哪些功能

可选项会随型号和版本不同，常见的有下面这些——**以你设备上应用里实际给出的可选列表为准**，网上第三方页面里的旧版介绍与当前版本可能有出入：

| 功能 | 说明 | 注意 |
| --- | --- | --- |
| 播放 / 暂停 | 最常用的一个 | 建议放在好按的那一侧 |
| 上一曲 / 下一曲 | 切歌 | 和播放键分开到两只耳朵上，避免误触 |
| 语音助手 | 唤起手机系统自带的语音助手 | 需要手机端授权和管理权限 |
| 快捷拨号 | 拨出指定联系人 | 属于账号相关能力，见第四节 |
| 音量加减 | 部分型号支持 | 面板上滑动实现，不是每个型号都有 |

## 四、快捷拨号和账号绑定

应用里有账号/第三方绑定的入口，拨号一类和账号相关的能力要先在应用内把绑定做完才会出现。**可绑平台、绑定后具体能做什么，都以应用内实际显示为准**；找不到入口说明你这一版或这个型号没有这项能力。

两点提醒：

- 绑定前先想清楚用哪个账号：绑定关系是挂在这个账号上的，换账号就得重做一遍；
- 换手机或换账号之后拨号失灵，先回绑定页确认状态，再怀疑设备。

## 五、入耳检测开和关的差别

入耳检测判断的是「耳机现在戴没戴在耳朵上」，它影响两件事：

| 状态 | 开着 | 关着 |
| --- | --- | --- |
| 摘下一只耳机 | 可以自动暂停，戴上再继续 | 音乐照常在响，声音会外放出来 |
| 佩戴不到位时 | 可能出现「检测到未正确佩戴」一类提示，提示你调整 | 没有提示，但听感（尤其是低频）会明显发闷 |
| 漏音 | 戴好了声音更集中 | 戴偏时装睡都听得见，漏音明显 |

**戴不牢就先去调佩戴位置，再看设置。** 入耳式型号戴得浅、耳塞尺寸不对，都会让入耳检测反复误判——这种情况在应用里怎么调都不会好，换一档耳塞尺寸效果更直接。

## 六、触控不灵敏、按了没反应的排查

映射本身没问题、手也按对了，就是不灵，按这个顺序查：

| 检查项 | 具体做法 | 为什么 |
| --- | --- | --- |
| 触控区是否干净干燥 | 用干布把面板擦干再试 | 出汗、沾水、抹了护手霜时，电容式触控会识别不到或误判 |
| 是不是按得太用力 | 改成轻触，长按类手势要按满约定的时长 | 触控面板靠感应，用力压并不等于更容易触发 |
| 手上是否戴着手套 | 摘掉手套再试 | 隔着一层布料，触控基本无法识别 |
| 出音孔和充电触点是否脏 | 软毛刷轻扫，干布擦触点后放回仓再取出 | 触点接触不良会让耳机状态异常，连带操作失灵 |
| 单只不灵还是两只都不灵 | 只在运动出汗后出现、擦干就恢复的，属使用问题 | 判断要不要走售后，见 [保修和售后怎么走.md](保修和售后怎么走.md) |

擦干净、按对方式、放回仓重新取出之后仍然完全不响应，并且两只都是这个表现，才更可能是硬件问题，把现象拍成视频再联系售后，沟通会快很多。

## 七、改完没生效怎么办

按这四条顺序查：

1. 设置改的是不是当前连着的这台设备（多设备用户容易点错）；
2. 重新进出一次设备主页，让应用把设置重新下发一遍；
3. 手势是不是被两边占用了——同一个手势在同一只耳机上只能做一件事；
4. 双击一直不灵、还伴随断连的，去看 [固件升级怎么操作.md](固件升级怎么操作.md) 有没有可升级版本。

想确认耳机现在到底连着什么状态、电量多少，可以直接用应用里的设备主页看；找不到耳机本体的时候，用 [查找耳机怎么用.md](查找耳机怎么用.md) 里的响铃功能把它叫出来，比翻沙发快。
