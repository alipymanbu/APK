Allway 是 Allway 品牌蓝牙耳机与蓝牙音箱的配套手机应用，管的是「连上设备之后」的事情：看设备连上没有、改灯光、改触控按键、调音效、升级固件、找回丢失的耳机。它不连耳机也能装、能打开，但绝大多数入口都要等设备连上才会出现。本篇按「弄清它是什么 → 核对安装包 → 安装 → 放行权限 → 最小验证」的顺序走一遍。

## 一、先确认你要装的是哪一个 Allway

应用商店里叫「Allway」或近似名字的应用不止一个，装错的话打开会是一套完全不同的界面。认得下面三项，基本不会拿错：

| 认什么 | 值 |
| --- | --- |
| 开发者主体 | 深圳市大佳田智能有限公司 |
| 包名 | `com.fenda.headset` |
| 官网 | [allwaylife.com](https://allwaylife.com/)（Allway 品牌产品的官方站点） |

包名是手机系统里唯一的标识，两个包名不同、名字相同的应用可以同时存在，数据和功能互不相通。装之前对一下包名最稳妥；装完在「设置 → 应用 → Allway」的应用详情页也能看到。

## 二、核对网盘里这份安装包

网上搜到的版本信息通常已经是更新的发布版，而网盘里这份是配文档时核对过的那一版，两者未必是同一个版本号。本文出现的版本号、包名、体积都以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Allway |
| 版本 | 2.16.5 |
| 包名 | `com.fenda.headset` |
| 安装包体积 | 134.46 MB |
| MD5 | `A59D9C92423FC7415E81F5668244CBA2` |

安装包本体在 [Allway 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b53273764a85) 里，转存到自己网盘后再下载到手机。

两点要提前说清：

- **版本号会变**。这个应用的版本号形如 `2.16.5`，官方渠道隔一段时间会发新版。你手上这份就是上表这一版；要装商店里的更高版本是另一回事，届时界面和入口位置可能和本文描述的有差异，具体以官方应用商店页面当时显示的为准。
- **系统要求别照字面抠**。相关页面里对安卓门槛的写法比较含糊，按「近几年的安卓机都能装」理解即可，真正的门槛以你安装时系统的提示为准。这个应用要连蓝牙设备，太老的机型即使装上了，蓝牙相关功能也未必齐全。

## 三、装到安卓手机上

1. **转存再下载**。打开网盘分享页，先转存到自己的网盘，再从自己的网盘下载到手机。夸克分享页直接点下载有时会失败，转存这一步省不掉。
2. **找到文件**。在手机的「文件管理」里找到刚下好的 `.apk` 文件，点击安装。
3. **允许安装未知来源的应用**。系统弹出提示时，给当前用来打开安装包的那个应用（文件管理器或浏览器）授权。Android 8 及以上是逐应用授权的，装完可以关回去；国产定制系统常把这项收在「安全」或「隐私」分类里。
4. **看到「未经过安全检测」属于常规提示**，继续安装即可。
5. **提示「应用未安装」时先看版本**。安卓不允许用低版本覆盖高版本；如果手机上已经装了比 2.16.5 更高的 Allway，想换成本文这份得先卸载旧版，卸载会把应用内数据一并清掉。

安装包本身不涉及付费环节；打开之后要不要登录账号、登录能用上什么，以你首次打开时的实际流程为准。

## 四、首次打开要放行哪些权限

Allway 的价值全在「和设备通信」上，所以权限给不给，直接决定哪些功能能用：

| 权限 / 开关 | 在哪给 | 不给会怎样 |
| --- | --- | --- |
| 蓝牙（Android 12 及以上显示为「附近的设备」） | 启动时的系统弹窗或系统设置 | 连不上设备，等于整个应用都用不了 |
| 定位（Android 11 及以下机型） | 启动时的系统弹窗 | 旧版安卓扫描附近蓝牙设备必须开定位，不给就搜不到耳机 |
| 通知 | 系统设置里的应用详情页 | 收不到连接状态、固件更新一类提醒，功能本身不受影响 |
| 存储 / 文件与媒体 | 按提示给或到系统设置里给 | 升级固件、导出日志一类操作可能失败 |
| 电池优化白名单（允许后台运行） | 系统设置 → 应用 → 电池 | 熄屏一段时间后应用被系统回收，设备状态显示会滞后，重进才刷新 |

Android 12 及以上把蓝牙权限拆成了「附近的设备」，老系统则要借定位权限来扫蓝牙，两条路都对。如果你只想连着耳机听歌、不用应用里任何设置项，那不给通知、不给存储也能用。

## 五、装完做一次最小验证

别等要用的时候才发现装了个不认设备的版本，装完按下面四步过一遍：

1. 打开应用，进设备的添加/搜索入口，看能不能扫到你的 Allway 设备并连上；
2. 连上后进设备主页，确认能看到电量或连接状态一类的实时信息；
3. 随便改一项设置（比如灯光开关或某个触控按键的功能），退出再进，看设置有没有被记住；
4. 去「设备管理」或设置页找固件升级入口，确认这个入口存在。

第 1 步就卡住的，按 [连不上耳机怎么排查.md](连不上耳机怎么排查.md) 逐项排查；连上了但认不出具体型号、或者想确认自己的设备到底受不受支持，见 [支持哪些设备与同名产品怎么认.md](支持哪些设备与同名产品怎么认.md)。
