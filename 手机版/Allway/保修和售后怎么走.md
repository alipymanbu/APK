耳机不出声、连不上、充不进电，很多时候是设置或使用层面的问题，自己几分钟就能排掉；剩下那部分才是硬件故障，要走保修。本篇把官方保修政策里和你直接相关的几条摘出来，再给一份「送修前先自查什么」的清单——按官方口径，非质量原因造成的损坏是不保的，先分清类型能省一次寄件。

## 一、官方保修政策的基本口径

以下内容整理自品牌官网的保修政策页（[allwaylife.com](https://allwaylife.com/) → Warranty Policy），**政策会更新，具体条款以你查看时官方页面显示为准**：

| 项目 | 官方口径 |
| --- | --- |
| 保修时长 | 自购买之日起 2 年（针对原始购买者） |
| 覆盖范围 | 正常使用下因材料或工艺缺陷导致的问题，官方选择维修或更换 |
| 覆盖费用 | 只覆盖零件与人工；运费一类费用官方可视情况要求由购买方承担 |
| 适用对象 | 带 Allway 商标、由 Allway 制造或为其制造的产品；非 Allway 产品与软件不适用 |
| 凭证要求 | 需要能证明原始购买日期的票据或订单记录 |

**票据这一条最容易卡住。** 电商订单截图、发票、纸质小票都属于可用的购买凭证，别等到出问题才去找；在官方渠道之外的店铺买的，售后路径和时效可能不同，见第五节。

## 二、哪些情况不在保修范围

官方列出的排除项里，下面几条是日常最可能踩到的：

- 进水、受潮、长时间处于潮湿环境；
- 摔碰、挤压等外部原因造成的损坏；
- 私自拆机、改装，或非官方指引下的「维修」；
- 和 Allway 不推荐的第三方配件搭配使用造成的问题；
- 正常使用产生的磨损，以及外观划痕、凹陷一类不影响功能的损伤；
- 电池一类的自然老化。

也就是说：**「用坏了」看原因，「用旧了」不保。** 拿不准的，先在官方页面确认一遍再决定是否寄修。

## 三、怎么发起保修

官方给出的流程是四步：

1. **发邮件说明情况**。政策页给出的联系邮箱是 `hi@allwaylife.com`，把设备型号、购买时间、出现的现象写清楚，官方可能会要求你提供照片或视频来确认问题；
2. **等官方确认处理方式**。官方会告知是寄回维修还是更换；
3. **按官方给的地址寄回**。政策写明官方承担运费，方式是先由你垫付、后续报销——寄之前把运费凭证留好；
4. **维修完成或退货签收后，官方再寄出新的或修好的设备**，并告知物流单号。

走这条路径时，把三样东西准备好能省几个来回：**购买凭证、故障现象的清晰视频、设备序列号或型号标识**。

## 四、送修前先自己排一遍

下面这些现象里，相当一部分不用寄件就能解决，先花十分钟过一遍：

| 现象 | 先做什么 | 对应文档 |
| --- | --- | --- |
| 连不上、搜不到 | 权限、配对记录、后台限制逐项查 | [连不上耳机怎么排查.md](连不上耳机怎么排查.md) |
| 只有一只出声、声音发闷 | 清洁出音孔、检查手机声道设置、重新配对 | [连不上耳机怎么排查.md](连不上耳机怎么排查.md) 第四节 |
| 触控按了没反应 | 擦干触控区、确认手势映射、试固件升级 | [触控按键和入耳检测怎么调.md](触控按键和入耳检测怎么调.md) |
| 灯光改了没反应 | 确认型号是否带灯、重进设备页同步 | [灯光效果怎么设置.md](灯光效果怎么设置.md) |
| 升级反复失败 | 换网络、保持应用在前台重试 | [固件升级怎么操作.md](固件升级怎么操作.md) |

只有「完全不开机、充不进电、单只任何设备都连不上」这类现象，才更可能落到硬件上。想确认自己的设备属不属于受支持型号，见 [支持哪些设备与同名产品怎么认.md](支持哪些设备与同名产品怎么认.md) 第一节。

## 五、购买渠道和凭证要留好

- **优先在官方渠道或授权店铺购买**。保修走的是购买凭证，来源清楚的订单处理起来最顺；
- **订单记录别删**。保修期是按购买日期算的两年，电商平台的订单一般可以随时下载，趁早存一份更稳妥；
- **非官方渠道买的设备**：官方政策只针对 Allway 商标的正品，串货、二手、来源不明的设备能不能受理，要走官方客服确认，别先假设一定给修；
- **别自己拆**。拆过一般直接判为不在保修范围，本来能修的也保不了了。
