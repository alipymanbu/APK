## 一、先说结论：桌面版只有一半功能

官方提供了电脑版 WiFiman（下载入口 [ui.com](https://ui.com/download/app/wifiman-desktop)，支持 Windows / macOS / Linux），但**官方帮助文档明确写了：桌面版只支持「UniFi 设备发现」和「Teleport VPN」两项功能，其余功能只在手机版里有**。

| 功能 | 手机版（安卓/iOS） | 桌面版 |
| --- | --- | --- |
| 设备发现（扫局域网、查 IP） | 有 | 有 |
| Teleport 远程 VPN | 有 | 有 |
| 网速测速（Speed） | 有 | 无 |
| 信号强度 / 信道 / 漫游（Signal） | 有 | 无 |
| 平面图信号测绘 | 有（需 LiDAR 设备） | 无 |
| 蓝牙设备扫描 | 有 | 无 |

所以「在电脑上跑个 WiFi 信号分析」这个需求，桌面版做不到——看信号、测信道这些活只能拿手机干。反过来，桌面版的存在意义是下面两件事。

## 二、什么时候用桌面版

1. **人在电脑前找设备 IP**：排查内网设备时不用掏手机，桌面版的发现功能一样能扫出同网段设备的地址与信息（能力范围见[局域网设备发现怎么用](局域网设备发现怎么用.md)，扫描边界——必须同一网络/VLAN——两个版本一致）。
2. **笔记本在外连回内网**：Teleport 在桌面版上同样可用，接受邀请的方式与手机端相同（邀请链接 24 小时有效、一台设备一次，规则见[Teleport远程VPN连接教程](Teleport远程VPN连接教程.md)）。

一句话分工：**扫信号、测速用手机；查地址、连 VPN 手机电脑都行**。

## 三、手机端安装包在哪

桌面版从官方下载页拿；手机端的安卓安装包在 [WiFiman 安装文件资源（夸克网盘）](https://pan.quark.cn/s/db4c585d4e16)，版本、包名、校验值见[下载与安装教程](下载与安装教程.md)。两头是各自独立的安装程序，手机的 APK 装不进电脑，电脑的安装包也装不进手机，别混用。

## 四、两个版本共用的账号与数据

- 两端连的都是同一套 UniFi 网关的 Teleport 邀请体系，网关侧的邀请、撤销操作不区分客户端是手机还是电脑。
- 测速历史、信号测绘这类数据只存在手机版里——桌面版没有对应功能，也就没有这份记录，换端看不到。
