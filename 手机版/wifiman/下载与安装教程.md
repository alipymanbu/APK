## 一、这是什么软件

WiFiman 是 Ubiquiti（优倍快）出的一款免费、无广告的安卓网络工具，包名 `com.ubnt.usurvey`。它干四类事：给当前 WiFi / 蜂窝网络测速、看信号强度与信道、扫描局域网找出在线设备的 IP、以及通过 Teleport 远程连回自己的 UniFi 网络。

家里或办公室用的是 UniFi 路由器（网关 + AP）时它能发挥全部功能；没有 UniFi 设备也能用其中的测速与设备发现——这两部分不挑网络。本篇只讲怎么装上，装好之后怎么用看[测速与信号强度查看](测速与信号强度查看.md)和[局域网设备发现怎么用](局域网设备发现怎么用.md)。

## 三、安装步骤

1. 手机上先装一个能解压/安装 APK 的文件管理器（系统自带的通常就够）。
2. 打开下载好的 `.apk` 文件，系统会提示「禁止安装未知来源应用」—— 这是安卓对非商店来源的常规拦截。
3. 按提示进入「设置 → 允许来自此来源的应用」，打开后返回，继续安装。
4. 装完先别急着打开，先把权限给了（下一节），否则扫描类功能一进去就是空的。

如果你手上的包安装时报「解析错误」或「安装包与已有应用冲突」，多半是下载不完整或与手机上旧版本签名不一致，按[常见问题与故障排查](常见问题与故障排查.md)里的方法核对。

## 四、第一次打开要给的权限

WiFiman 的核心功能都靠「看周围的无线环境」，所以首次启动会连要几个权限，含义分别是：

| 权限 | 不给会怎样 |
| --- | --- |
| 位置信息（定位） | 安卓系统规定：不给定位，应用就拿不到 WiFi 扫描结果。Scan 页会一片空白或只显示自己连着的那个网络 |
| 附近设备 / 蓝牙 | 扫不到周围的蓝牙 LE 设备，发现页的相关列表为空 |
| 通知（可选） | Teleport 连接状态、漫游提醒这类提示不会推送 |

位置权限建议选「使用时允许」。另外安卓系统自身的「设置 → 位置信息」总开关也要打开——应用拿到了权限但系统定位关着，扫描结果照样是空的。这是安卓的系统级规则，不是这个应用特有的毛病，具体表现见[常见问题与故障排查](常见问题与故障排查.md)。

## 五、系统要求

- 本地记录标注：需要安卓 5.2 以上。
- 官方商店当前版本对系统的要求更高（截至 2026-09，新版本要求 Android 8.0 及以上），以官方页面当时显示为准。

两处数字不一致很正常：老版本支持的系统更低，新版本逐步抬高门槛。你装的是哪一版，以那一版在官方商店页面标的要求为准。手机系统太老装不上时，可以试试网盘里这个对系统要求更低的版本。
