Xhorse 的多数能力要挂在账号上才完整：积分、功能授权、设备绑定、在线升级、客服记录都跟着账号走，而不是跟着手机走。本篇按「注册 → 登录 → 绑定设备」的顺序讲一遍，重点说清哪一步最容易出错。

## 为什么必须先有账号

不登录也能打开 App、也能搜到设备，但账号没建好，后面会连着卡：

- 设备绑不上，积分和授权类功能用不了；
- 换手机之后要重新装、重新登录，账号是唯一能把设备认回来的入口；
- 遇到问题找客服时，客服要按账号和设备序列号（SN）查记录。

所以顺序是：**先注册账号 → 登录 → 再连设备 → 再绑定**。倒过来做，绑定那一步多半会报错。

## 注册：国家和地区这一项别随手选

1. 打开 App，进账号相关的入口（一般在「我的」或「账号」里），选注册。
2. 先选**国家 / 地区代码**，再填手机号。注意这里选的是**区号**，不是界面语言。
3. 收验证码，填进去，完成验证。
4. 按提示设置登录密码。

这一步选错国家 / 地区，后果是延后的 —— 注册能成功、登录也正常，但到绑定设备那一步会直接失败，报 `Params error: nation-code`。这是官方资料里记录过的典型情况，解决办法就是用一个**地区与设备实际使用地一致的账号**重新登录再绑，细节见 [常见问题与排查.md](常见问题与排查.md)。

另外，账号绑的是手机号，换了手机号要按新号码重新走一遍注册，别拿旧号反复试验证码。

## 登录与找回

- 密码登录：手机号 + 密码。密码记不住时优先用验证码登录，进去之后再改密码。
- 收不到验证码：先看短信拦截、然后换成手机数据流量试一次，最后再确认号码和区号有没有填错。
- 换手机：装好 App（安装文件在 [Xhorse 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7128fea67d29)），用同一个账号登录，设备列表和积分都会回到你面前，不需要重新买授权。

## 把设备绑定到账号

绑定（部分版本里叫「设备与历史」下的 Combine Device）是把硬件设备和账号关联起来，让账号共享这台设备的积分，并把依赖授权的功能启用起来。

这个入口在不同 App 版本里位置略有差别，按界面提示找即可；如果手机上这份 App 装得比较早、找不到对应入口，用 [Xhorse 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7128fea67d29) 里那份重装一次再操作。

1. 手机蓝牙打开，硬件设备开机（MINI KEYTOOL 是长按电源键 1 秒开机）。
2. App 里先连上设备，确认列表里能看到它，并记下设备屏幕上的 SN 码。
3. 进入绑定入口，从设备列表里选中这台设备。
4. 按提示输入安全码并提交。
5. 回到绑定列表再看一次，确认这台设备已经出现在**已绑定设备**里，才算真的成功。

绑定关系的处理做在账号一侧：同一台设备接到不同账号上会出现不同的可用状态，所以**换账号之前先查一次当前设备的绑定状态**，别直接在新账号上硬绑。设备数量多的场景，建议在账号里给设备做个命名备注，否则一排 SN 码分不清谁是谁。

## 绑定之后可以做什么

| 能力 | 说明 |
| --- | --- |
| 积分共享 | 设备绑到账号后，账号可以共享这台设备的积分 |
| 授权类功能 | 需要 token 或授权才能用的功能，在「功能」页里查看与激活 |
| 在线升级 | 固件与数据的升级入口在 App 内，升级时保持网络和电量 |
| 客服与记录 | 按账号和 SN 查历史记录，沟通时直接报这两项 |
