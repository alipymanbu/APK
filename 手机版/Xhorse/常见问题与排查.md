遇到问题时先分清是哪一层出了毛病：手机和 App 之间、App 和设备之间、设备和你操作的对象之间，三者混在一起查最浪费时间。下面按现象分组。

## 搜不到设备

按这个顺序查，基本能定位到：

1. **手机蓝牙是不是真开着**，以及 App 有没有拿到蓝牙 / 附近设备权限。安卓 12 以后这两项是分开的，只给蓝牙不给「附近设备」照样搜不到。
2. **定位权限**。部分安卓版本把扫描蓝牙设备归在定位权限下，关掉定位就会出现「蓝牙开了但列表空着」。
3. **设备是不是开着、有没有电**。MINI KEYTOOL 长按电源键约 1 秒才开机，屏幕亮起来才算开。
4. **距离和遮挡**。挪到一米以内，把手机从口袋里拿出来，避开金属台面。
5. 还不行就**重启蓝牙、重启 App**，必要时把设备也关掉重开一次。重启过仍然搜不到，卸载 App 重装一遍再试，安装文件在 [Xhorse 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7128fea67d29) 里，转存后重新下载一份。

权限设置的细节在 [下载与安装教程.md](下载与安装教程.md)，配对时怎么按 SN 码选对设备在 [连接MINI KEYTOOL与海豚设备.md](连接MINI KEYTOOL与海豚设备.md)。

## 连上几秒就断、反复重连

这一类的诱因通常是环境和电量，不是软件坏了：

- 设备和手机之间隔着人体、金属台面或佩饰（手链、戒指一类）会明显影响稳定性，换个位置再试；
- 设备电量偏低时蓝牙容易掉，先充电；
- 手机上如果同时连着很多蓝牙设备（耳机、手表、音箱），先把用不上的断掉再连；
- iPhone 上如果反复连不上，进系统设置 → 蓝牙 → 找到这台设备 → 忽略此设备，然后重新在 App 里搜一次。

上面都做过还是掉，重启手机再试一遍。

## 绑定时报 `Params error: nation-code`

这是账号地区的配置问题，不是设备坏了。现象是设备能搜到、能连上，一到绑定就报这个错。

处理办法是用**注册时选对国家 / 地区**的账号登录后再绑：地区选错会一直报这个错，重新注册一个地区正确的账号即可。注册那一步为什么容易选错、以及换号前后的注意事项，见 [注册登录与账号设备绑定.md](注册登录与账号设备绑定.md)。

## 收不到验证码、登录不上

- 先看短信有没有被拦截，再换成手机数据流量重发一次；
- 确认区号和手机号没填错 —— 区号选错，验证码会发到别的地方；
- 同一号码短时间内频繁请求会被限制，等一会儿再试；
- 密码忘了就直接用验证码登录，进去之后再改密码。

## 在线升级失败

- 网络：升级包通常不小，切到稳定的 Wi-Fi 再试；
- 电量：低电量下升级容易中断，插上充电再升；
- 中途不要断电、不要退出 App、不要让手机长时间切后台；
- 设备固件升级和 App 本身的升级是两件事，别只升级其中一个就以为都好了。

## 复制好的钥匙打不开车 / 遥控失灵

先按顺序排除，不要一上来就怀疑数据：

| 可能原因 | 怎么确认 |
| --- | --- |
| 车型或钥匙类型不在支持范围内 | 查设备当前固件与 App 里对应的支持列表 |
| 芯片密码不对 | 回到读原芯片那一步重新读一次 |
| 芯片 / 遥控线圈放置不稳 | 重新放正，保持不动走完整流程 |
| 有些车型不支持直接匹配 | 这类要转 OBD 方式处理 |

确认是车型适配问题、而手上资料又查不到对应车型时，直接找客服要适配指引，通常比自己反复试更快。

## 装不上、装完打不开

提示「无法安装 / 应用未安装 / 解析包出错」，或者装完点开就闪退，先看 [下载与安装教程.md](下载与安装教程.md)：文件完整性（对一下 MD5）、存储空间、系统版本，以及是不是和已装的同包名版本签名冲突。需要重装时，安装文件在 [Xhorse 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7128fea67d29) 里，转存后再下一个新的。

## 找客服前先准备好这几项

能一次说清，沟通效率差很多：

- 账号（手机号）与设备 SN 码 —— SN 就在设备开机后的屏幕上；
- App 版本号与设备固件版本号；
- 出错时的完整提示文字，`Params error: nation-code` 这类错误串照抄下来最有价值；
- 已经做过的排查动作。

客服入口在 App 内。如果是操作结果不对（钥匙不匹配一类），补充说明车型、年份和钥匙类型，会省掉一轮来回。
