# RetroArch 游戏导入与扫描方法

> 本篇讲把游戏 ROM 放到手机哪个位置、怎么用扫描功能生成游戏列表、扫描不出结果时怎么换成宽松匹配，以及给列表补上封面图。

## 一、游戏文件放在哪

RetroArch 不提供游戏本体，你需要自己把游戏 ROM（模拟器用的游戏文件）放进手机存储。两个原则：

- **放 RetroArch 能看到的地方**。安卓 11 以后系统限制变多，`Android/data` 这类目录在部分手机上无法用普通文件管理器直接浏览；最省事的做法是在内部存储根目录建一个自己的文件夹，例如 `RetroArch/roms/`，再按主机分子文件夹：

  ```text
  RetroArch/
    roms/
      GBA/
      SNES/
      PS1/
      ...
  ```

- **文件名尽量保留游戏原名**。扫描功能靠文件名和校验值去数据库里对号入座，乱改名的游戏容易对不上号。

ROM 常见的 `.zip`、`.7z` 压缩包可以直接扫描和加载，不必解压；PS1 游戏建议优先找 `.chd` 格式的整盘镜像，省空间也免换盘。

## 二、扫描前的两步准备

1. 装好对应主机的核心（见 [核心下载与选择.md](核心下载与选择.md)），没装核心扫出来也没法玩。
2. 主菜单 → **Online Updater**（在线更新器）→ **Update Databases**（更新数据库），顺手把 **Update Core Info Files** 也点了。这份数据库是扫描时识别游戏的依据，不更新可能扫不出新游戏。

## 三、扫描与手动导入

**自动扫描**：

1. 主菜单 → **Playlists**（播放列表）→ **Import Content**（导入内容）。
2. 选 **Scan Directory**，选中你放 ROM 的文件夹，确认。
3. 大合集扫描要几分钟，耐心等。扫完主菜单会按主机出现一个个列表。

扫描默认是**严格模式**：文件必须能在数据库里精确对上号（靠校验值或序列号）才会进列表。扫完发现列表缺了不少游戏，通常就是这些没对上号：在 Import Content 菜单里用**手动扫描（Manual Scan）**放宽匹配条件再扫一遍，或用 **Scan File** 逐个指定；未匹配的游戏也会以「未识别内容」的形式进列表。

**手动加载**（偶尔玩一次、懒得建列表）：主菜单 → **Load Content** → 选文件 → 选核心，直接开玩，不生成列表条目。

**多盘游戏**（PS1 一拆二、三张盘的常见）：整盘镜像合并成单个 `.chd` 文件后当一张盘玩，最省心；没合并的逐盘扫描，玩到换盘时在快速菜单 → **Disc Control** 里弹出并插入下一张。玩哪种格式取决于你手头的文件，不必为了格式重下一遍。

如果扫描后游戏打不开，先怀疑缺 BIOS 文件，见 [BIOS与系统文件.md](BIOS与系统文件.md)。

## 四、给游戏列表加封面

主菜单 → **Online Updater** → **Playlist Thumbnails Updater**（播放列表缩略图更新器），选中要补图的主机列表，RetroArch 会联网下载每款游戏的封面、标题画面。图包不小，网络慢会拉很久，也可以只挑自己玩的那几个列表下载。

手动扫描生成的列表，条目名要和缩略图站的命名一致才能配上图，对不上的游戏就一直是灰格子，不影响游玩。

## 五、装好了玩什么

列表、核心、BIOS 都齐了，点游戏直接进。按键不习惯先去看 [手柄与触屏按键设置.md](手柄与触屏按键设置.md)，遇到黑屏、闪退、存档丢失去 [常见问题排查.md](常见问题排查.md)。
