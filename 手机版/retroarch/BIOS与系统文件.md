## 一、什么是 BIOS，哪些主机需要

BIOS 是主机的开机固件，带光驱、带开机画面的主机（PS1、世嘉 CD、Dreamcast、土星、3DO 等）模拟时通常要读取它。RetroArch 和核心都不附带这些文件，需要你自行准备并放入指定目录。

一张速查表（常见家用机/掌机）：

| 主机 | 是否需要 BIOS |
| --- | --- |
| FC、超任、Game Boy、GBC、世嘉 MD | 一般不需要 |
| Game Boy Advance | mGBA 核心没有也能跑，个别游戏需要 |
| PS1 | PCSX-ReARMed 多数游戏免 BIOS，部分游戏必需 |
| 世嘉 CD / PCE-CD | 需要，光驱类主机基本都要 |
| Dreamcast（Flycast） | 需要 |
| 土星、3DO | 需要 |
| NDS（melonDS / DeSmuME） | 部分功能与游戏需要，没有也能启动不少游戏 |

具体某个核心要哪些文件、要不要放子文件夹，以官方核心文档为准，索引页在 [docs.libretro.com/library/bios](https://docs.libretro.com/library/bios/)，每个核心一页，列出所需文件名和 MD5。

## 二、放进哪个目录

BIOS 统一放在 RetroArch 的**系统目录（System/BIOS）**下。查看你的设备上这个目录的实际位置：主菜单 → **Settings**（设置）→ **Directory**（目录）→ **System/BIOS**，右边显示的就是当前路径。

几个实务要点：

- 路径指向的文件夹不存在就手动建一个。
- 多数核心把 BIOS 直接放系统目录根下即可，个别核心要求放进特定子文件夹——这以核心文档为准，别想当然全平铺。
- BIOS 文件**不需要**和游戏 ROM 放在一起，也不用改名伪装成 ROM。
- 新版 RetroArch 在安卓上支持系统的文件夹访问授权（SAF），把 BIOS 放在普通可见目录再在设置里把系统目录指过去，是比塞进 `Android/data` 深处更省心的做法。

## 三、核对文件名与 MD5

放进去不等于放对了。BIOS 损坏或版本不对的症状五花八门：黑屏、闪退、卡在开机画面、声音异常，而且报错往往很模糊，所以官方文档强调用 MD5 核对：

1. 在对应核心的文档页找到所需 BIOS 的**文件名**和 **MD5 值**。
2. 用校验工具（手机上的文件管理器多带「计算校验值」功能）算出你手里文件的 MD5。
3. 两者一致才算对。对不上就换个来源重新找，改名救不了内容错误的文件。

另注意大小写：个别机型/目录环境对文件名大小写敏感，按文档原样命名最稳。

## 四、放好之后怎么验证

BIOS 就位后重新启动游戏：能正常出现主机开机画面（有的核心会跳过）即成功。还是起不来的，按 [常见问题排查.md](常见问题排查.md) 的思路逐项过一遍——先查核心是否装对，再回来看 BIOS 路径与文件名。
