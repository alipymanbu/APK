# RetroArch 核心下载与选择指南

## 一、核心是什么，为什么刚装好什么都玩不了

RetroArch 本体只是一个「壳」，真正干模拟活的是一个个叫**核心（Core）**的插件：FC 有 FC 的核心、PS1 有 PS1 的核心。你刚装好的 RetroArch 一个核心都没有，所以什么都玩不了——先在核心列表里把你要玩的主机对应的核心下载下来，这是装好之后的第一个动作。

## 二、下载核心的步骤

1. 回到主菜单（左下角房子图标），选 **Load Core**（加载核心）。
2. 选 **Download a Core**（下载核心）。
3. 在列表里找到目标主机，点一下就开始下载，装完自动出现在已装列表里。

核心可以同时装多个（不同主机各装一个，或同一主机装几个备选）。列表很长，从上往下按主机英文名排列，例如 `Nintendo - Game Boy Advance` 分组下的就是 GBA 核心。

下载核心需要联网访问 Libretro 的构建服务器，速度慢或一直转圈多半是网络问题，换个网络环境重试；如果核心列表本身很短、只有几十个，说明你装的是 Google Play 渠道的旧版——那个版本的核心被平台政策限制过，换官网渠道的安装包重装即可（见 [下载与安装教程.md](下载与安装教程.md)）。

## 三、各主机推荐核心

同一台主机往往有好几个核心，性能与兼容性差别很大。下表是口碑较好的常用组合（手机上跑得动的优先）：

| 主机 | 推荐核心 | 备注 |
| --- | --- | --- |
| FC / NES | Nestopia UE、FCEUmm、Mesen | Mesen 最准也最吃性能 |
| 超任 / SNES | Snes9x、bsnes-hd | Snes9x 速度快，手机首选 |
| Game Boy / GBC | Gambatte、SameBoy | |
| Game Boy Advance | mGBA | 手机上的默认选择 |
| 世嘉 MD / GG / SMS | Genesis Plus GX | |
| 世嘉 32X | PicoDrive | |
| PS1 | PCSX-ReARMed | 手机端最成熟，多数游戏不需要 BIOS |
| N64 | Mupen64Plus Next | 部分游戏需逐个调插件 |
| 土星 | YabaSanshiro、Beetle Saturn | 土星本身就难模拟，中低端机型慎入 |
| Dreamcast | Flycast | 性能要求较高 |
| PSP | PPSSPP | 强核心，新机型体验好 |
| 街机 | MAME 2003 Plus、FBNeo | 看游戏年代选 |
| NDS | melonDS、DeSmuME | 双屏操作依赖触屏或外接手柄 |

高画质主机（N64 及以后）核心对手机芯片要求直线上升，老手机卡顿先换低配核心再谈调设置。

## 四、核心的更新与删除

- **更新**：主菜单 → **Online Updater**（在线更新器）→ **Update Installed Cores**，一键把所有已装核心升到最新。
- **删除**：主菜单 → **Load Core** → **Installed Core List**（或 Core Manager），选中要删的核心选卸载。删错了大不了重新下载，没有连带影响。

核心版本与游戏兼容性偶尔有牵连：某个游戏在核心更新后出问题，可以在 Online Updater 里看看有没有单独更新该核心的选项，或去 [常见问题排查.md](常见问题排查.md) 找对策。

## 五、装完核心之后

有了核心，下一步就是把游戏文件导进来建立游戏列表，见 [游戏导入与扫描.md](游戏导入与扫描.md)。部分主机（PS1、世嘉 CD、Dreamcast 等）还需要先放好 BIOS 文件，见 [BIOS与系统文件.md](BIOS与系统文件.md)。
