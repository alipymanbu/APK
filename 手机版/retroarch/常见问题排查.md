## 一、安装环节

| 症状 | 原因与处理 |
| --- | --- |
| 提示「没有权限安装应用」 | 点弹窗里的设置按钮，打开对该文件管理器/浏览器的「允许安装未知应用」授权 |
| Play Protect 弹红色警告 | 选「更多详情 → 仍要安装」；老系统上死活装不上时，临时关闭 Play 保护机制扫描再装（步骤见 [下载与安装教程.md](下载与安装教程.md)） |
| 安装按钮点不动、一直转圈 | 清一下安装会话（最近任务里关掉安装器）重试；确认 APK 没下全，网盘文件重新转存下载 |
| 装上后图标点开闪退 | 先确认手机是 64 位设备（近几年的手机基本都是）；存储权限没给也会导致启动即崩，去系统应用信息里补授权 |

## 二、核心下载与游戏加载

**核心列表很短或下载一直失败**：多半装的是 Google Play 渠道的旧版，它连不上官方核心服务器。卸载后换官网渠道的包重装（见 [下载与安装教程.md](下载与安装教程.md)）。渠道没问题还下不动，就是网络到 Libretro 服务器不稳，换个网络再试。

**点了游戏黑屏或秒退**，按这个顺序查：

1. 对应主机的核心装了吗？没装核心游戏起不来。
2. 这台主机要 BIOS 吗？光驱类主机（PS1 部分游戏、世嘉 CD、Dreamcast、土星等）缺 BIOS 就黑屏，核对方法见 [BIOS与系统文件.md](BIOS与系统文件.md)。
3. ROM 文件本身完整吗？解压到一半的文件、来源不明的压缩包是黑屏大户，换一个确认完好的文件试。
4. 换个同主机的其他核心再加载一次，排除核心本身的兼容性问题。

**扫描不出游戏**：先在 Online Updater 里更新数据库再扫；严格扫描模式对不上号的游戏不会进列表，用「手动扫描（Manual Scan）」放宽匹配，或用 Scan File 逐个指定（操作见 [游戏导入与扫描.md](游戏导入与扫描.md)）。

## 三、存档问题

- **游戏内存档丢了**：这类存档存在存档目录里，别用系统清理工具一键清理应用数据——那会把存档一并清掉。换手机迁移时，把 RetroArch 目录下的存档文件一并拷走。
- **即时存档读不出来**：即时存档和核心版本绑定较紧，核心大版本更新后旧即时存档可能失效，游戏内存档不受影响。重要进度用游戏内存档保底。
- 存档目录位置：Settings → Directory 里查看，必要时手动备份整个目录。

存档目录的两种默认位置、`.srm` 与 `.state` 文件的区别、改目录不丢档的顺序、换手机迁移的完整步骤，单独整理在 [存档目录与进度迁移.md](存档目录与进度迁移.md)。

## 四、性能与画面

**游戏卡顿**的排查顺序：换该主机公认的高速核心（对照表在 [核心下载与选择.md](核心下载与选择.md)）→ 游戏内快速菜单把分辨率/内部分辨率类选项调回默认 → 关掉画面滤镜（着色器）→ 手机开性能模式。中低端机型跑 N64、世嘉土星、Dreamcast 这类主机吃力属正常，核心选择比反复调设置更管用。

**画面被拉伸变形或不满屏**：快速菜单 → Video（视频）里调整画面比例与整数缩放；先按主机原始比例（多数是 4:3 或 10:9）设置，再按喜好微调。

**按键错乱**：外接手柄先跑一遍自动配置；只有个别游戏不对，用按游戏的重映射单独修（见 [手柄与触屏按键设置.md](手柄与触屏按键设置.md)）；菜单里确认/取消反了是菜单交换开关的事，不是手柄坏了。

以上都解决不了时，官方文档 [docs.libretro.com](https://docs.libretro.com/) 和 Libretro 论坛有更细的逐核心资料，搜索时带上「核心名 + 症状」命中率最高。
