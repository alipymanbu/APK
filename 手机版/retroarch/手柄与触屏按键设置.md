## 一、屏幕虚拟按键（触屏覆盖层）

没接手柄时，游戏画面上会叠一层虚拟按键。相关开关在游戏运行中调：

1. 游戏中唤出**快速菜单**（Quick Menu，默认返回键或手势可达，具体以你的快捷键设置为准）。
2. 进入 **Controls**（控制）→ **Touchscreen Overlay**（触屏覆盖层）。
3. 这里可以切换预设布局、调整按键透明度与大小，或整个关掉。

虚拟按键的默认布局可以换，比如横版街机游戏换成六键布局。觉得按键挡画面，把透明度调低即可；接了手柄的话直接关掉覆盖层，画面干净得多。

游戏里的按键位置和菜单里的确认/取消是两套东西：菜单里 A 确认还是 B 确认由 **Settings → Input → Menu Controls → Menu Swap OK & Cancel Buttons** 控制，觉得菜单确认键反直觉就在这里调。

## 二、外接手柄

蓝牙手柄和 USB 手柄（含 Type-C 直插）都能用，流程一致：

1. 在系统设置里配对手柄，确认手柄在系统层面能用。
2. 打开 RetroArch，进入 **Settings → Input → Auto Config**（自动配置），开启后 RetroArch 会按内置的配置表自动认出常见品牌手柄的键位。
3. 试试游戏里每个按键。个别键位不对，进 **Controls** 里重映射，改完保存。

重映射可以分三个层级：全局（所有游戏）、按核心、按游戏。只给某个游戏改键位，就在那个游戏的快速菜单 → Controls 里改并保存为该游戏专用，不会污染全局设置。

## 三、快捷键（Hotkey Binds）

手机上没有键盘，组合键全靠手柄或虚拟键上的快捷键设定，位置在 **Settings → Input → Hotkey Binds**。建议优先绑好这几个：

| 功能 | 用途 |
| --- | --- |
| 快捷键启用键（Hotkey Enable） | 其他快捷键都要先按住它，防止误触 |
| 保存即时存档 | 随时存进度 |
| 读取即时存档 | 回到刚才的进度 |
| 快进（Fast Forward） | 跳过开场动画、练级 |
| 退出游戏 | 从游戏返回 RetroArch 菜单 |

没有手柄时，虚拟按键区通常留了一个可自定义的快捷键按钮，在覆盖层设置里绑定。

## 四、即时存档与游戏内存档

两套存档别混淆：

- **游戏内存档**：游戏自己提供的存档（像当年在实体机上的存档），保存在存档文件里，随游戏进度走。
- **即时存档**（Save State）：把当前画面瞬间拍下来，任何时刻可存可读，但只对当前核心有效。

日常两种都建议用：游戏内存档保底，即时存档应付「打 BOSS 前先存一下」。存档文件存在哪、换手机怎么带走整套进度，见 [存档目录与进度迁移.md](存档目录与进度迁移.md)；开了成就硬核模式后即时存档会被整体禁用，取舍见 [RetroAchievements成就设置.md](RetroAchievements成就设置.md)；存档损坏、读不出来的处理见 [常见问题排查.md](常见问题排查.md)。
