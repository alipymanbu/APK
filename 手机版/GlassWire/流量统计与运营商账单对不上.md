# 流量统计与运营商账单对不上：差异从哪来

> 本篇讲一个用流量监控必然碰到的问题：手机统计、GlassWire、运营商账单三个数各不一样——差异从哪来、哪个数该信、GlassWire 自己显示异常怎么修。

## 一、先分清三个数

同一个月的流量，你手里会有三个数字：运营商账单上的、系统设置里的、GlassWire 图表上的。它们本来就**不应该完全一样**：

- **运营商**在计费层计数：统计口径、时间差、计费规则都归它；
- **系统统计**和 **GlassWire** 在手机侧计数。GlassWire 读的就是系统提供的数据接口，正常情况下它和系统统计里的数应当一致（这也是官方工作人员在论坛里的说法）。

所以对账的正确姿势是：先比「GlassWire ↔ 系统统计」——这两个对得上，说明手机侧没毛病；再比「手机侧 ↔ 运营商」——这中间的差异是正常的计费口径差。

## 二、手机侧和运营商对不上的常见原因

| 原因 | 表现 | 怎么办 |
| --- | --- | --- |
| 协议开销 | 手机比运营商多 5%~10% 上下 | 手机把 TCP/IP 头、加密开销、重传都算进去了，运营商多按净流量计——属正常差异，具体口径以运营商为准 |
| 账单延迟 | 刚下完东西，运营商那边还没动 | 运营商的用量报表不是实时的，常有数小时延迟，过几小时再看 |
| 周期没对齐 | 月初月末差一大截 | 把 GlassWire 套餐的账单日设成和运营商同一天（见 [流量套餐限额与超额提醒.md](流量套餐限额与超额提醒.md)） |
| 双卡看错行 | 差异大且固定 | 双卡手机分清统计的是哪张卡 |
| 定向流量 / 零计费应用 | 运营商显示的比手机少 | 把免计费应用在 GlassWire 里标记出来，统计口径才靠近运营商 |

## 三、GlassWire 和系统统计也对不上

这两个理论上应该一致，不一致说明 GlassWire 这边出了状况，按顺序试：

1. **权限被收回了**：GlassWire 读数据依赖「使用情况访问权」，权限丢了数值就不准。最彻底的修法是官方论坛给出的那套——卸载 → 重启手机 → 重装 → 把授权全部重新给一遍；
2. **后台被系统杀了**：数值断档、重启后不自动记录，多是厂商系统杀后台所致。把 GlassWire 加进电池优化白名单，具体品牌的限制说明可参考 [https://dontkillmyapp.com/](https://dontkillmyapp.com/)（官方工作人员在论坛里也推荐这个站）；
3. **用 Data Plan 记账而不是默认统计**：官方建议把流量套餐建起来用它跟踪，口径更准、还能触发提醒。

## 四、到底该信哪个数

- **怕超套餐、防扣费**：以运营商的数为准，它的才是计费依据；
- **日常盯用量、找流量大户**：以手机侧为准——它实时、按应用细分，能直接定位到是谁在偷跑（找大户的步骤见 [流量监控图表怎么看.md](流量监控图表怎么看.md)）；
- 两边各看各的用途，不必强求对平；差异长期异常大（比如差出一倍），优先按第三节排查 GlassWire 本身，仍解决不了再找运营商核实。

排查中碰到统计整体停摆、曲线不动的情况，另见 [常见问题与排查.md](常见问题与排查.md)。
