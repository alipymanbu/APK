## 一、先认清你要装的是哪一份

叫「Voca」的练口语应用有好几个，名字、图标、介绍都很像，但开发方和包名不同，装错了等于装了另一个软件（区分方法见 [怎么分辨同名软件和官方渠道.md](怎么分辨同名软件和官方渠道.md)）。本篇讲的是这一份：

| 项目 | 值 |
| --- | --- |
| 应用名 | Voca AI |
| 版本 | 1.4.0 |
| 包名 | `com.pointone.voca.ai` |
| 安装包大小 | 22.09 MB |
| MD5 | `01A536595DD77DF5C84CB84F518F5510` |
| 信息整理日期 | 2026-09-24 |

线上商店的版本会持续更新，可能比上表新；这几个值只对应网盘里这一份安装包。装完之后以应用内显示的信息为准，系统要求也以安装包标注与官方页面为准。

## 二、从哪里拿安装包

两条路，按你的网络环境选：

1. **官方应用商店**：在手机自带应用商店或 Google Play 里搜「Voca AI」，核对开发者与包名后再安装。这是官方渠道，后续更新也走它。
2. **夸克网盘**：应用商店装不了时，从 [Voca AI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/47f29931d9bf) 转存到自己网盘再下载 APK，然后手动安装。

网盘里的文件夹名是 `vocaai（先保存再下载）`，安装包是 `vocaai_v1.4.0.apk`。下载完先别急着装，对照第一节表格里的 MD5 核对一遍文件是否完整；手机上多数文件管理器没有直接算 MD5 的入口，可以拷到电脑上核对，或至少确认文件大小是 22.09 MB。

## 三、安装步骤

从网盘拿到的是 APK 文件，与商店里点一下就装不同，要手动放行一次「未知来源」：

1. 把 `vocaai_v1.4.0.apk` 下载到手机存储（放在下载目录即可）。
2. 在文件管理器里点这个文件。
3. 首次会提示「不允许安装未知来源的应用」，按提示进入设置，允许当前这个文件管理器安装应用。
4. 回到安装界面，点「安装」，等进度走完。
5. 出现「打开」按钮即表示装好。

如果停在下面这几句提示上，按表处理：

| 提示 | 多半是什么问题 | 处理 |
| --- | --- | --- |
| 不允许安装未知来源的应用 | 系统拦截 | 回到第 3 步放行一次 |
| 解析包时出现问题 | 安装包没下完整 | 删掉重下，别用断点续传，再对照 22.09 MB 与 MD5 |
| 应用未安装 | 手机上已装着同包名但签名不同的版本 | 先卸载旧的那一份再装；卸载会清掉本地记录，动手前先确认账号状态 |
| 应用与你的手机不兼容 | 系统版本过低或处理器架构不符 | 这份包在你这台机器上装不了，换设备或改装商店里的版本 |

## 四、第一次打开：权限、登录、选语言

装好后按顺序处理下面几件事，麦克风那一步不做，它基本没法开始对话：

1. **麦克风权限**：弹权限框时选「允许」。安卓 11 及以上有「仅本次允许」这种一次性授权，退到后台再回来会失效，选「使用应用时允许」更省事。错过弹窗就去 `设置 → 应用 → Voca AI → 权限 → 麦克风` 手动打开。
2. **通知权限**：部分机型会再问通知权限，练习提醒靠它，可按需允许。
3. **登录或先体验**：这一版既能用第三方账号登录，也有一部分不登录就能直接试练；具体给哪几个入口以你手机上的界面为准。打算长期练、又想让记录跟着账号走的话，建议一开始就登录。
4. **选语言与目标**：第一次进入会要你选练哪门语言（官方列出的包括英语、西班牙语、日语等，你这一版能选哪些以应用内列表为准）和练习目标。选完通常可以改，别频繁换——换了语言等于从头开始。

装好之后怎么真正开练，见 [对话练习怎么开始.md](对话练习怎么开始.md)；说完它没反应、界面一直停在等你说话，见 [麦克风没声音怎么办.md](麦克风没声音怎么办.md)。
