## 一、先分清是三种「没反应」里的哪一种

这三种的成因完全不同，先看清楚自己遇到的是哪种，再往下排：

| 现象 | 多半是什么问题 | 去哪一节 |
| --- | --- | --- |
| 它像没听见你，界面一直停在等你说 | 麦克风 | 第二至六节 |
| AI 的声音放不出来 | 音频输出 | 第七节 |
| 它听到的是别的词、一堆乱字 | 环境噪声与说话方式 | 第七节 |

## 二、先查麦克风权限

路径：`设置 → 应用 → Voca AI → 权限 → 麦克风`，必须是「允许」。三种容易被忽略的情况：

- **一次性授权会失效**：安卓 11 及以上的「仅本次允许」，退到后台再回来就没了，改成「使用应用时允许」才稳。
- **系统自动回收**：很久没打开过的应用，安卓会自动收回麦克风权限。「上次还好好的、这次突然不灵」通常就是它，回这一页重新打开即可。
- **总开关被关**：这一页显示「允许」却始终收不到声音时，看系统级的麦克风访问总开关（安卓 12 及以上居多，路径常见为 `设置 → 隐私 → 麦克风访问`，或 `设置 → 隐私 → 权限管理 → 麦克风`），关掉它会全局静音。

## 三、看有没有被别的应用占着

麦克风同一时间只能被一个应用收音。通话、录音、会议、相机、以及别的语音类应用在前台或后台收音时，会把它抢走，而 Voca AI 界面上看不出任何报错，只表现为「没听见」。

把这些应用全部从最近任务里划掉，再回来对着麦克风说一句。悬浮窗录音、后台常驻的语音助手最容易被忽略。

## 四、看外设：蓝牙耳机是不是两边错位

`设置 → 应用 → Voca AI → 权限` 里蓝牙也放行一下，再确认耳机确实连上了。连接不稳时会出现「声音走耳机、麦克风还留在手机上」的错位，结果就是你听得到 AI、它听不到你。

最快的判断办法是换一次收音设备做对比：用有线耳机，或直接对着手机麦克风说。哪一种能正常识别，问题就落在另一种上。

## 五、强制停止再打开

音频服务偶发卡住时，强制停止是最有效的一步：先 `设置 → 应用 → Voca AI → 强制停止`，再重开应用、重新进对话。各家手机的应用信息入口不太一样：

| 机型 | 应用信息入口 |
| --- | --- |
| 华为 / 荣耀 | 设置里搜「应用管理」→ 找到 Voca AI → 强行停止 |
| 小米 / Redmi | 设置 → 应用设置 → 应用管理 → Voca AI → 强行停止 |
| OPPO / realme / 一加 | 长按桌面图标 → 应用信息 |
| vivo / iQOO | 长按桌面图标 → 应用信息 |

## 六、确认网络是通的

对话里的识别要把你的声音传到云端处理，断网或弱网时会出现「说完了但一直没反应」，看起来和麦克风坏了很像。先用浏览器确认能正常打开网页，再回来查应用；Wi-Fi 和移动数据切换一次，能快速判断是不是网络侧的问题。

## 七、AI 没声音、或者识别成一堆乱字

- **AI 的声音放不出来**：先看媒体音量是不是被静音；再看声音是不是被蓝牙耳机或车机接走；再看有没有开免打扰。切一下音频输出设备再试。
- **识别得不准**：按平时的语速说，别一个词一个词地蹦；一次说一到两句，说完停下等它回应，别两边一起说；戴耳机比外放识别率高；找安静环境起步。说完先看界面显示的文字离你说的差多远，来判断是收音问题还是说话方式问题。

如果问题不是「收不到声音」，而是某个功能点进去就要会员，见 [免费版和会员有什么区别.md](免费版和会员有什么区别.md)；如果应用一装完就打不开或闪退，先回到 [下载与安装教程.md](下载与安装教程.md) 用覆盖安装的办法修一次。
