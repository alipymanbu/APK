## 一、开始前先确认三件事

| 检查项 | 要求 | 说明 |
| --- | --- | --- |
| 系统版本 | 安卓 5.2 以上 | 渠道页标注的系统要求，实际以安装时系统检测为准 |
| 存储空间 | 建议预留安装包体积两倍以上 | 安装包约 183 MB，安装过程系统还要解包复制一份 |
| 安装来源授权 | 允许「未知来源应用」 | 见下面第三节，第一次装第三方 APK 都会遇到 |

网盘里这一份安装包的信息，核对时用得上：

| 项目 | 值 |
| --- | --- |
| 版本 | 4.1.7 |
| 包名 | com.poke.pokeindexnew |
| 体积 | 约 183 MB |
| MD5 | 6E5A9638EC35D050F21C5C113B25739E |

## 二、拿到安装包

从 [PokeDex 安装文件资源（夸克网盘）](https://pan.quark.cn/s/40982d532672) 获取，步骤是固定的三步：

1. 打开上面的链接，把安装包**转存到自己的夸克网盘**（分享内容先保存、再下载，这也是文件夹命名里那句提示的含义）；
2. 在夸克网盘客户端里找到转存后的文件，点下载；
3. 下载完成后会得到一个 `.apk` 文件，就在你设置的下载目录里。

## 三、核对文件（建议做，半分钟）

文件下载不完整时，安装会报「解析失败」或「解析包出现问题」，先校验 MD5 可以省去来回折腾：

电脑端（Windows，PowerShell 或 CMD）：

```powershell
certutil -hashfile "你的下载路径\PokeDex_v4.1.7.apk" MD5
```

手机端：不少文件管理器自带「文件校验」或「MD5 校验」功能，在文件的更多操作菜单里找。

比对结果与 `6E5A9638EC35D050F21C5C113B25739E` 一致（大小写不限）就说明文件完整；不一致就重新下载一遍。

## 四、安装步骤

1. 点开 `.apk` 文件，系统会弹「为了手机安全，禁止安装未知来源的应用」之类的提示；
2. 在弹窗里点「设置」，给**你下载所用的那个应用**（浏览器或文件管理器）勾选「允许安装未知应用」，返回继续；
3. 等安装进度走完，点「打开」。

首次启动后你看到的是攻略与资讯列表，底部导航还有图鉴、工具、战队几个板块——每个板块是干什么的，[图鉴查询用法.md](图鉴查询用法.md) 里有逐个说明。

## 五、装好之后建议先改两个设置

- **「当前游戏」**：在设置里选成你实际在玩的那个版本。图鉴里不少资料按这个口径显示，选错了会出现「资料和我玩的对不上」的情况，具体见 [离线使用与多语言设置.md](离线使用与多语言设置.md)；
- **语言**：想要双语界面也在同一处设置里改，把语言选成两种即可。

如果你是从很老的老版本升级上来的，先卸载再装，别直接覆盖——历史版本有过覆盖安装后闪退的记录，处理办法写在 [常见问题解答.md](常见问题解答.md) 里。
