# Sixfast 加速没效果与连不上怎么排查

> 「加速了但没用」有好几种完全不同的表现：进度条走到一半失败、连上了但目标应用还是打不开、连上了但速度没变化、装完就闪退。本篇把这几类分开列，每类给出可执行的判断顺序；另附校园网、公司网络这类环境的判断办法，以及找客服前该准备的信息。

## 一、先分清你遇到的是哪一种

| 现象 | 大概率属于 | 去哪一节 |
| --- | --- | --- |
| 点加速后进度条卡住、反复失败、提示加速失败 | 连接建立不起来 | 第二节 |
| 显示已加速，但视频/网页仍提示地区限制或打不开 | 加速对象没覆盖到 | 第三节 |
| 显示已加速，但延迟、加载速度跟没加速差不多 | 线路或本地网络问题 | 第四节 |
| 应用一打开就闪退、进不去主界面 | 安装或兼容问题 | 第五节 |

**先看剩余时长。** 会员到期或体验时长用完时，界面表现常常是「点得动但走不到最后」，提示语可能是「检测到当前多次尝试加速失败」。这一条不排查，后面几步都是白做。

如果反过来，是你**本地**的应用（Gmail、YouTube 这类）变慢了，那是另一类问题，见 [开了加速本地的软件还能用吗.md](开了加速本地的软件还能用吗.md)。

## 二、连不上、卡在中间、反复失败

按这个顺序试，前一步没解决再走下一步：

1. **确认时长还在。** 见 [注册登录与试用时长怎么算.md](注册登录与试用时长怎么算.md)。
2. **手动换一条线路。** 线路选择里挑延迟数值更低的一条，重新加速。同一条线路连试两三次不通就换，别在同一台上反复点。
3. **清掉加速器在系统里留下的配置。** 应用内客服给过的办法是：进手机系统的网络 / 配置管理界面，把加速器留下的配置项删掉，让加速器重置，再重启客户端加速。不同机型的入口名称不一样，一般在「设置 → 网络与互联网」下面。
4. **重启手机后再试一次。** 上面两步都做完还是不行，用这一步把残留状态清干净。
5. **换一台设备验证。** 同一账号在另一台手机或电脑上加速，如果能通，问题在这台设备；如果都不通，问题更可能在账号状态或目标服务那一侧。

走完这五步还失败，就别继续折腾了，带齐第七节的信息找官方客服。

## 三、连上了，但目标应用还是打不开、还提示地区限制

这一类最多，根子通常是**加速范围没覆盖到你真正在用的那个应用**。

1. **确认目标应用在「已加速应用」列表里。** 加速的是浏览器，你却在用视频 App，那就等于没加速。
2. **没在列表里就添加进去。** 路径见 [加速模式与线路怎么选.md](加速模式与线路怎么选.md) 第三节；添加时若列表是空的，先去补「读取已安装应用列表」的权限。
3. **加完必须重开目标应用。** 从后台彻底清掉，再重新打开；只是切回来不算。
4. **还不行就换线路。** 同一目标换一条延迟更低的线路再试一次。
5. **区分「打不开」和「打开了但内容受限」。** 页面能打开、只是某一块内容看不了，那可能是该内容本身的地域或版权策略，不属于加速范围问题。
6. **清掉目标应用侧留下的旧判定。** 一条同类回国加速器官方 FAQ 里给过的通用做法：关掉那个国内应用的定位权限、清掉它的缓存、重启手机，然后**先连上加速、再打开它**。这一步针对的是「应用自己还缓存着上一次的判定结果」。

## 四、连上了，延迟和速度却没变化

1. **先确认测的是同一个东西。** 加速前记住一个具体数值（比如游戏里的延迟显示、视频起播的等待时间），加速后对比同一个指标。凭感觉容易误判。
2. **换线路对比。** 手动切一条延迟数值明显更低的线路，再测一次，这是排查里性价比最高的一步。
3. **换本地网络对比。** 从 Wi-Fi 切到蜂窝数据（或者反过来）再测。只有某一个 Wi-Fi 下有问题，说明瓶颈在那一侧——重启一次路由器，同时把正在下载、看视频这类占带宽的任务停掉。
4. **避开国内晚间高峰。** 国内时间晚上到深夜是各类国内服务压力最大的时段，同一段时间换不同时间点复测，结论会稳很多。
5. **确认加速对象是你真正在用的那个进程。** 开着加速去玩客户端里的内置小游戏、或者用系统浏览器看视频，不代表目标应用被加速了。

## 五、装完打不开、一进去就闪退

1. **覆盖安装一次。** 不卸载，直接再装一遍同一个包。
2. **清掉应用数据后重新登录。** 应用内的本地缓存出问题时，这一步能解决一部分闪退。
3. **判断是不是版本与新系统不兼容。** 系统版本比这个应用版本新很多时，闪退常是兼容问题。这种情况改从官网或应用商店装最新版，比继续折腾旧包省事。
4. **换设备试。** 同一安装包在另一台手机上正常，说明问题不在包。

## 六、在校园网或公司网络里连不上

宿舍校园网、学校 Wi-Fi、公司内网是这类应用最容易碰壁的地方。表现是：本地网页、社交应用都正常，加速就是建立不起来，或者刚连上就断。

原因是**这些网络本身会对代理、加速器一类的流量做管控** —— 常见手段是只放行少数常用端口、做流量特征识别、对流媒体和下载类流量限速。这是**所在网络的策略，不是你账号或设备出了问题**。

**怎么确认是这个原因**，按这个顺序：

1. **换网络对照。** 关掉 Wi-Fi，用自己的蜂窝数据连一次。蜂窝数据上能连、校园网里连不上，结论基本就出来了。
2. **换一条节点再试一次。** 有些校园网只卡住部分线路，能连上的那条就当备用线路用。
3. **换设备不用试。** 同一个网络下换手机、换电脑通常得到同样的结果，别在这上面花时间。

**确认是网络策略之后，你这一侧没有能改的地方** —— 这类管控是网络管理方的规则，也不该去绕。剩下的选择只有两个：换到你自己可控的网络（蜂窝数据、家庭宽带），或者避开这个网络再用。**别为了绕过网络策略去装来路不明的工具**：给一个本来就要接管全部流量的软件再叠一层不明软件，多出来的那部分风险和你自己的账号安全是绑在一起的。

## 七、找客服前把这些信息准备好

一次性给全，能少好几轮来回：

| 要准备的信息 | 从哪看 |
| --- | --- |
| 应用版本号 | 应用内「我的 / 设置」里的关于页 |
| 账号（手机号或邮箱） | 注册时用的那一个 |
| 设备型号与系统版本 | 手机「设置 → 关于手机」 |
| 用的哪条线路、哪个模式 | 加速界面 |
| 报错原文或截图 | 失败提示页 |
| 出问题的时间点 | 精确到小时，方便对方查那一时段的线路 |

官方入口有三个：应用内在线客服、官方邮箱、官网的问题反馈区。**论坛、群、评论区里自称客服的都不是官方渠道**，涉及账号和付款只走官方入口。
