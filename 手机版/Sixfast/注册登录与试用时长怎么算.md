## 一、账号怎么注册、怎么登录

首次打开 Sixfast，会先让你同意用户协议与隐私政策，之后才进到注册 / 登录页。

| 登录方式 | 说明 |
| --- | --- |
| 手机号 | 收短信验证码，适合随手就用 |
| 邮箱 | 输邮箱收验证码，海外手机号收不到国内短信时更方便 |
| 微信 / Apple ID 等快捷登录 | 一键授权，不用记密码 |

这份登录方式是第三方教程的整理，**以你打开注册 / 登录页时实际显示的选项为准** —— 不同端、不同版本开放的入口可能不一样。

**注册的意义在于「时长挂在账号上」**：会员时长、体验时长都跟着账号走，不跟着设备走。所以换手机、重装应用之前，先确认自己能登录原来的账号，否则剩下的时长看不见。

## 二、新用户能拿到什么、怎么拿到

官网把「新用户注册即获得免费体验时长」写在首页与常见问题里，这也是它建议你先试后买的依据。体验时长的具体时长、能加速哪些内容，以你注册后在应用内看到的数据为准。

**兑换码（口令）的入口在这里。** 官方下载页只写了「使用兑换码」这一步、没给具体路径，下表这两条来自多篇第三方教程、彼此一致：

| 端 | 入口路径 |
| --- | --- |
| 安卓 / iOS | 底部「我的」→「兑换码」，填入口令后提交 |
| PC | 右上角「口令」入口 |

有第三方教程把兑换码的入口写成「会员充值 → 卡卷兑换」，和「我的 → 兑换码」指的应该是同一处。**入口在中文化界面上可能随版本调整，找不到时就在「我的」页和会员页各看一遍。**

**口令从哪来，这一条要分清楚：**

- 官方渠道：官网下载页的使用流程里就列了「使用兑换码」这一步；官网常见问题里也给出过示例口令；官方活动页、应用内活动、官方客服同样会发。
- 非官方渠道：各种论坛、导流页、短视频里贴的口令，以及声称「输入就送大量时长」的说法，来源无法核实，**不建议用**。

**关键的一点：口令是官方活动推广用的，不是长期固定的。** 拿到一个口令先确认它还在有效期内——过期口令提交后会失败，这是正常现象，不代表你账号有问题。

时长用完之后的典型表现是：加速按钮点得动，但走到一半失败，或者提示会员已到期。有用户反馈过一句提示是「检测到当前多次尝试加速失败」，遇到这句先去看 [加速没效果与连不上怎么排查.md](加速没效果与连不上怎么排查.md) 第二节，别一味换线路。

## 三、会员分几档，差别在哪

从 App Store 的内购列表看，Sixfast 的会员**至少有 VIP 与 SVIP 两档**，两档都有按月与连续包月的形式。第三方说明里的差别是「VIP 覆盖应用加速，SVIP 覆盖应用与游戏加速」，**这条没有在官网页面直接查到对应表述，购买前请以应用内会员页的权益对照为准。**

几点实际使用的判断依据：

1. **看你要加速的是什么。** 只用来追剧听歌，和要打国服游戏，需要看的档位可能不一样。
2. **价格会变。** 不同时间、不同活动、不同购买渠道（应用内购 / 官网）的价格都可能不同，任何一篇第三方文章里写的价格都只能当参考。
3. **连续包月要单独管。** 走 App Store 内购的连续包月，退订入口在系统的订阅管理里，不在应用内；安卓端走各自支付渠道，退款规则以对应渠道为准。

## 四、一个账号能用几台设备

官网首页的表述是：**一个账号支持六大平台，同时至多五台设备在线**。第三方文章里出现过「2~3 台」这种更保守的说法，与官网口径不一致，**以官网和应用内实际提示为准**。

实际用起来注意两点：

- **同时在线台数是上限，不是「可以无限登」。** 超过上限时，要么挤掉别的设备，要么新设备登不上，具体表现以你客户端提示为准。
- **各端共用同一份时长。** 手机、电脑、平板、电视登录同一账号，看到的是同一份剩余时间，不需要分别购买。

## 五、换设备、换账号时的三个坑

1. **卸载不退款，也不会暂停剩余时长。** 会员和时长是跟着账号走的订阅，剩余时间以你重新登录之后应用内显示的为准，不会因为你卸载而冻住。想省时长就等真要用的时候再买。
2. **游客状态的数据不跨设备。** 如果一直没注册、只是打开就直接用，换手机就找不回来了。先在旧设备上把账号注册登录好。
3. **登录了另一个账号，会以为「时长不见了」。** 退出登录，用原来那个账号再登一次基本就能恢复，剩余时长会重新出现。

## 六、退款与找客服

| 渠道 | 适合问什么 |
| --- | --- |
| 应用内在线客服 | 加速失败、账号异常、订单与退款，官网把这条列为第一入口 |
| 官方邮箱 `cymsixfast@gmail.com` | 应用内进不去、需要走邮件的沟通 |
| 官网常见问题区 | 平台支持范围、加密与隐私等常规问题 |

官网首页写明「**首次购买享 3 天退款保障**」和「24 小时客服」。申请退款前把这几样准备好，沟通会快很多：订单号或支付凭证、购买时间、账号、遇到的问题现象与报错原文。

**评论区、论坛和群里自称「客服」的人都不是官方渠道**，涉及账号和付款的事只走上面这三个入口。
