# Sixfast 后台掉线与防断线设置

> 症状是「加速成功那一刻是好的，切到游戏或视频里没几分钟就断了」。绝大多数情况下不是线路坏了，而是系统在后台把加速应用清掉了。本篇按手机系统给出要放行的几处设置，并给出「是应用被杀还是网络本身断」的区分办法。

## 一、先确认断的到底是什么

断线时立刻做一个动作，能省下后面一大堆试错：**切回 Sixfast 看一眼加速状态还是不是「已连接」。**

| 你看到的 | 说明 | 处理 |
| --- | --- | --- |
| 加速状态掉回未连接 | 加速进程被系统清理了 | 按第二、三节放行后台 |
| 加速状态还是已连接，但对局/播放仍中断 | 不是加速器被杀，问题在本地网络或目标服务那一侧 | 按第五节对比网络 |

再补一条：断线是**偶发**还是**每次都断**，结论完全不同。偶发的先按第五节的网络对比走；每次都断的，基本可以按后台被清理处理。

## 二、安卓上要放行的几处

系统对后台省电的管控越严，加速被清的概率越高。下面几处按你机型能找到哪几项就设哪几项：

| 位置（名称因机型而异） | 要设成什么 | 作用 |
| --- | --- | --- |
| 设置 → 应用 → Sixfast → 耗电管理 / 电池 | 允许后台活动 | 不让系统在息屏后清理它 |
| 设置 → 电池 → 电池优化 | 把 Sixfast 加入不优化白名单 | 同上，不同机型入口不同 |
| 最近任务（多任务）界面 → 给 Sixfast 加锁 | 锁定 / 不清理 | 一键清理后台时不被顺手清掉 |
| 设置 → 应用 → Sixfast → 自启动 | 允许 | 重启手机后不必手动开 |
| 设置 → 电池 → 省电模式 / 超级省电 | 玩游戏、追剧时关掉 | 省电模式对后台的清理更激进 |

这些设置各机型叫法差别很大，**找不到时就打开手机设置搜「电池优化」「自启动」「后台」三个词**，比逐个菜单翻快。

## 三、应用内自带的防断线设置

Sixfast 在客服页面里提供了按手机型号拆分的「加速防断线设置」教程，里面针对不同品牌的省电策略给出了对应路径。既然是按机型整理的，**先照自己机型那一条做，剩下的再用第二节的通用办法补**。

路径：应用内进入客服入口，找防断线 / 后台保活的设置说明。

## 四、iPhone 上要放行什么

iOS 的管理方式比安卓简单，主要两处：

1. **允许后台刷新。** 「设置 → 通用 → 后台 App 刷新」里找到 Sixfast 打开。
2. **低电量模式。** 低电量模式开着时后台活动会被压得更紧，玩游戏或看直播前先关掉。

iOS 上还有一种「断」不是被杀，而是系统层面的连接被重置：加速状态还在，网络却短暂不可用。它多见于 Wi-Fi 与蜂窝数据之间切换的瞬间，一般会自动恢复，不需要重装。

## 五、判断是加速被清，还是网络本来就在断

按这个顺序对比，能一次定位：

1. **换网络对比。** 从 Wi-Fi 切到蜂窝数据（或反过来）再玩一段。只有某一个 Wi-Fi 下断，瓶颈在那一侧——重启路由器，同时停掉正在下载、云备份这类占带宽的任务。
2. **换时间点对比。** 国内晚间时段国内服务压力最大，同样的用法换到国内深夜时段（也就是你当地的清晨）复测一次。
3. **换线路对比。** 在 [加速模式与线路怎么选.md](加速模式与线路怎么选.md) 第四节里换一条延迟更低的线路，再连续用一段。
4. **换设备对比。** 同一个 Wi-Fi 下用另一台设备加速同一个目标，只有这一台断，就回到第二节继续补设置。

这四步里**只要有一处明显改善**，就说明原因就在那一处，不用继续往下试。

## 六、还是频繁断线怎么办

如果上面都做过、换过线路和网络仍然每次都用不久就断，那就带上这些信息找官方客服：手机型号与系统版本、应用版本号、用的哪条线路与哪个模式、断线发生在打开目标应用后大概多久、断线时加速状态是否还在。信息齐了，对方才查得动。

客服入口见 [注册登录与试用时长怎么算.md](注册登录与试用时长怎么算.md) 第六节。

## 七、断开加速后本地网络仍不正常

如果你已经停止加速、甚至卸载了应用，但本地网络还是不对（部分网站打不开、一直提示要连 VPN、连接被反复重置），那大概率不是线路问题，而是**系统里还留着加速器写进去的通道配置**。两个平台的清理路径不一样。

**iOS**

加速器会在系统里写入配置描述文件，清理入口在「设置 → 通用 → VPN 与设备管理」：

1. 找到 Sixfast 相关的描述文件，点进去选「删除描述文件」。
2. 按提示输入锁屏密码确认。
3. 重启设备。

这一步的操作与路径来自 Apple 官方支持文档；文档同时写明：**删除描述文件会一并删除与它关联的设置、App 和数据**，所以动手前确认这个描述文件确实是加速器写的。

**安卓**

入口在「设置 → 网络和互联网 → VPN」（不同机型名称有差异，有的在「更多连接设置」下面）。把加速器留下的 VPN 条目删掉，再重启手机。

**做完还没恢复**，就重启一次路由器，并把本机的 DNS 换成公共 DNS（如 `114.114.114.114`、`223.5.5.5`）再试。仍然不解，说明问题已经不在这个应用上，按常规网络故障排查。

**顺手一条**：卸载前先点一次「停止加速」，比连着通道直接卸载更稳妥。
