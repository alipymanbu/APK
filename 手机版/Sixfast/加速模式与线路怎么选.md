## 一、加速之前先知道这条链路

Sixfast 的做法是在你设备上开一条通往国内节点的通道，再把你指定的应用流量引进去。由此带出两个必须记住的点：

1. **它按「应用」加速，不按「全部流量」加速。** 没被你加进加速范围的应用，走的是原来的网络。
2. **加速生效的时机是「加速成功之后重新打开应用」。** 已经在跑的应用，加速前开的那个进程不一定接得上，要从后台清掉再打开。

后面的所有操作都建立在这两点上。至于它会不会顺手把你本地的 Gmail、YouTube 一起接管，看 [开了加速本地的软件还能用吗.md](开了加速本地的软件还能用吗.md)。

## 二、主界面上的模式是干什么的

官网首页把模式写成「影音、办公、学习一键切换」；第三方教程里更常出现的是「影音模式」和「游戏模式」两个叫法。**不同版本的叫法与分法不完全一样，以你当前版本的下方/左侧切换区实际显示为准**，但分类逻辑是一致的：

| 模式 | 覆盖的内容 |
| --- | --- |
| 影音 | 国内视频、音乐、直播平台 |
| 游戏 | 国服手游、国服端游 |
| 应用 / 办公 / 学习 | 国内办公、学习、政务类应用与网站 |

先选模式，再选具体要加速的对象，顺序别反。

## 三、把你要用的东西加进加速范围

**加速一个应用（安卓端）**

1. 主界面进入「编辑加速应用」。
2. 界面分成「已加速应用」和「未加速应用」两栏。
3. 从「未加速应用」里找到目标应用，点添加。
4. 返回，切到「应用加速」，开始加速。
5. 加速成功后，把目标应用从后台清掉，重新打开。

**加速一款游戏**

- 进「游戏」模式，用搜索框搜游戏名，点搜索结果里的加速即可。
- 手游和端游走的是同一套逻辑：搜到 → 加速 → 重开游戏。国服与国际服的加速方式一样。

**两个常见的卡点**

- **「编辑加速应用」点不动，或者列表里一个应用都没有。** 先去手机的应用权限里，把「读取已安装应用列表」给到 Sixfast，再回来重开这个界面。
- **想加速的应用搜不到。** 这一条和「支持哪些应用」有关，走应用内反馈提需求比在论坛里等转达快，入口见 [注册登录与试用时长怎么算.md](注册登录与试用时长怎么算.md) 第六节。

## 四、节点该自动选还是手动选

默认状态是自动推荐，它根据你的网络状况挑一条线路。什么情况下值得手动换：

| 情况 | 动作 |
| --- | --- |
| 加速成功但延迟没明显变化 | 进线路选择，手动挑一条延迟数值更低的 |
| 某条线路连不上或中途掉 | 换一条同区域的线路再试 |
| 目标应用仍然打不开 | 先确认应用在加速列表里，再换线路 |

手动选的时候优先看**延迟数值低的**，不要凭城市名或地区名挑。线路列表里可能按地区或运营商分组，同一个地区下多条线路，一条一条试比反复重启应用快。

## 五、加速后自动启动目标应用

安卓端「我的 → 设置」里有「加速后自动启动游戏」这一类开关，默认状态随版本不同。习惯「加速完自己动手开应用」的话可以关掉；要省一步操作就开着。

它只负责帮你把应用拉起来，**不改变「加速成功之后才重开」这条规则**——关掉这个开关，你手动重开的动作一样要做。

## 六、几种常见场景怎么配

| 你的目的 | 模式 | 要点 |
| --- | --- | --- |
| 在手机上看国内视频、听音乐 | 影音 | 加速成功后重开视频/音乐应用；如果仍提示地区限制，见 [加速没效果与连不上怎么排查.md](加速没效果与连不上怎么排查.md) 第三节 |
| 打国服手游 | 游戏 | 搜游戏名 → 加速 → 重开游戏；对局中掉线看 [后台掉线与防断线设置.md](后台掉线与防断线设置.md) |
| 电脑上玩国服端游 | PC 客户端 | 端游在电脑上的加速对象是游戏本体，同样要「先加速、后启动」 |
| 开国内办公系统、上网课 | 应用 / 办公 / 学习 | 浏览器类的对象注意插件版与客户端版的区别，见 [电脑电视和浏览器上怎么用.md](电脑电视和浏览器上怎么用.md) |
| 电视上看国内平台 | 影音 | 电视端先装好客户端，再按上面同样的顺序操作 |

模式是可以随时切换的，选错换回来即可，不需要重装应用。真正决定成败的是加速对象有没有加对、有没有重开。
