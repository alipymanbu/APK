## 一、先确认这一版是什么

Sixfast（官方中文名「六毫秒加速器」）是成都超游猫科技有限公司做的网络加速工具，面向的是身在中国大陆以外、要访问国内网络服务的人：看国内视频、听国内音乐、玩国服游戏、开国内办公与学习系统，都靠它的回国线路把延迟和连接失败压下去。公开渠道能拿到 Android、iOS、Windows、Mac、Android TV 与 Chrome 浏览器插件几个端，本篇讲的是安卓包。

| 项目 | 这一版的情况 |
| --- | --- |
| 适用设备 | 安卓手机 / 安卓平板（官方另有 Windows、Mac、iOS、Android TV、Chrome 插件版） |
| 系统要求 | 应用商店对近期版本标注「Android 6.0 以上」；最低要求会随版本变，以你手机上点安装之后的提示为准 |
| 包名 | `com.qeeyou.apps.accelerator.overseas` |
| 版本号 | 3.20.1 |
| 安装包大小 | 86.43 MB |
| 安装包 MD5 | `440FBF61EB261A72871AD3B76EA30F75` |
| 开发者 | 成都超游猫科技有限公司 |
| 是否必须联网 | 是。注册登录、拉取加速列表、加速本身都要联网 |

三点先说明：

1. **网上搜到的版本通常比这一版新。** 应用商店 2026 年 8 月前后已经在发 3.22 系列，而这一版是 3.20.1。判断「我装的对不对」看包名和版本号能不能对上，不要拿某篇介绍里写的版本号来比；核对方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
2. **「Android 6.0 以上」是商店对近期版本的标注，不是这一版的官方声明。** 最低系统要求会随版本调整，各家商店的口径也不完全一致。装不上时先看你手机上弹的是什么提示，别拿这个数字硬套。
3. **加速器要接管手机的网络流量**，所以装完第一次加速时系统会弹一次连接 / VPN 授权，这一步是它的正常工作机制，不是可疑行为。也正因为如此，**安装包来源要认准官方渠道** —— 一个能接管全部流量的应用，装到来源不明的包上风险比普通应用大得多。

安装包落到本地之后，**先核对包名再装**：包名对得上 `com.qeeyou.apps.accelerator.overseas`，才说明手上这份是官方那个应用。第三方下载站上的包不一定与页面标称的版本一致，而页面上标「高速下载」「安全下载」的按钮还常常先让你装一个下载器，最后拿到的包里装的是什么就不好说了。

**该装哪一版，看你的目的：**

| 你的情况 | 装哪一版 |
| --- | --- |
| 日常使用 | 官网或应用商店里的最新版 |
| 设备上没有可用的应用商店，或者想留一份离线备份 | 本篇开头那条网盘资源里的 3.20.1 版 |
| 只想确认手上这份是不是官方的 | 不用重装，按 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 第二节核对包名、第三节核对 MD5 即可 |

## 三、把安装包取到手机

1. 在手机上打开 [Sixfast 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7bc0cfcd9658)。用手机浏览器或夸克 App 都行，**建议在夸克 App 里打开**，浏览器下大文件容易被打断。
2. 点「保存到我的网盘」，先转存到自己账号下。转存之后就不再依赖原分享的状态了。
3. 进入自己的网盘找到这个文件，点下载，等它落到手机的「下载」目录。
4. 下载完核对两件事：文件名以 `.apk` 结尾；大小在 86.43 MB 左右。差得多的多半没下完整，删掉重下，别续传。

习惯在电脑上操作的：先在电脑端网盘把这个文件下载下来，再用数据线（USB）拷到手机的 `Download` 目录，之后在手机上从「文件管理」里点它安装，效果一样。

## 四、安装时放行一次「未知来源」

这个包不是从手机自带的应用商店装的，安装时系统会拦一下，这是默认行为，不代表文件有问题。

1. 打开「文件管理」，进入 `Download`（下载）目录，找到刚下好的安装包，点它。
2. 系统弹出「为了安全，你的手机不允许安装来自此来源的应用」这类提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 有的机型要自己去「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，找到你刚才用来打开文件的那个 App（文件管理或浏览器），逐个放行。
3. 回到安装界面点「安装」，等进度条走完，出现「打开 / 完成」。
4. 先点「完成」，不要马上点「打开」—— 首次启动前把权限一次给对，省得进去之后反复弹窗。

安装完成后，桌面或应用列表里会出现 Sixfast 的图标。

## 五、首次打开会要的权限

注册登录、加载加速列表、接管流量分别用到不同的权限。应用商店在权限说明里对近期版本给出的用途是这样的（版本不同清单会略有出入，完整清单在商店详情页的「应用权限」入口能查到）：

| 权限 | 商店说明里的用途 | 建议 |
| --- | --- | --- |
| 位置 | 推荐加速节点 | 建议给；不给的话自动选点会失准，需要手动挑线路 |
| VPN / 连接请求 | 加速本身要接管流量 | 加速时必须同意，拒了等于没加速 |
| 读取已安装应用列表 | 编辑加速应用时要列出手机里装了什么 | 建议给，否则「编辑加速应用」界面可能列不出应用 |
| 通知 | 同步应用内的活动信息 | 想要提醒就给，不想被打扰可以拒绝 |
| 存储 / 媒体与音频 | 和客服沟通时发图片、视频 | 用到客服功能前再给也行 |
| 摄像头 | 和客服沟通时拍照 | 同上，不找客服就不必给 |
| 悬浮窗 / 修改系统设置 | 悬浮球翻译功能 | 不用悬浮球可以不给 |
| 日历 | 添加通知提醒 | 可以不给 |

**拒绝某项权限之后功能报错，先回到权限页把它补上，比反复重装省事。** 尤其是「编辑加速应用」里点不动、或者列表是空的那种情况，先去检查读取应用列表的权限。

## 七、装完先做三步自检

别急着去开视频或者开游戏，先花一分钟确认这三件事：

1. **能打开、不闪退**：图标点进去能看到主界面和加速按钮。反复闪退的看 [加速没效果与连不上怎么排查.md](加速没效果与连不上怎么排查.md) 第五节。
2. **能走到注册 / 登录那一步**：首次打开会先让你同意用户协议与隐私政策，之后能进注册 / 登录页。能正常注册或登录，说明账号这一环通了，流程见 [注册登录与试用时长怎么算.md](注册登录与试用时长怎么算.md)。
3. **点加速有反应**：点一次加速，进度走完后界面变成已连接状态（这时系统会弹一次连接授权，同意即可）。点下去没反应或者卡在中间，先看 [加速没效果与连不上怎么排查.md](加速没效果与连不上怎么排查.md) 第二节。

三步都过，就可以按 [加速模式与线路怎么选.md](加速模式与线路怎么选.md) 去挑模式、选节点、加要加速的应用了。

## 八、升级与卸载

- **升级**：新版本会换一个安装包文件名，直接覆盖安装即可。**不要先卸载** —— 卸载会清掉应用本地数据，登录状态也要重来一遍。
- **卸载**：换机或重装前，确认自己已经注册并登录过账号；剩余的会员时长和体验时长都挂在账号上，重装后登录同一账号才能看到。卸载前先点一次「停止加速」；如果卸载后本地网络反而不正常，按 [后台掉线与防断线设置.md](后台掉线与防断线设置.md) 第七节清掉残留配置。
- **安装包丢了**：回到本篇开头那条网盘资源重新取一次即可，已经转存过的版本不受原分享状态影响。
- **系统升级之后打不开了**：先用覆盖安装试一次；还是不行，多半是这一版与新系统不兼容，改从官网或应用商店装最新版更省事。
