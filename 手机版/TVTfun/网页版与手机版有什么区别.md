## 一、先有网页版，后有手机端

TVTfun 的本体是网页站 [tvtfun.net](https://tvtfun.net)，在电脑浏览器直接打开就能看；手机 app 是从网页端转出来的移动端版本，功能围绕同一套番剧库展开。所以你在 app 里看到的首页结构（今日热门、最新更新、热门排行、完结动画、新番日历）在网页版上同样存在，两边的追番体验是同源的。

## 二、两边都有的东西

| 功能 | 网页版 | 手机 app |
| --- | --- | --- |
| 番剧在线播放 | 有 | 有 |
| 新番日历（按周一至周日） | 有，首页展示每天更新数量，可点「查看全部」 | 有，首页顶部就是追番表 |
| 最近更新 / 热门排行 | 有，排行有独立完整榜单页 | 有（对应最新更新、热门排行板块） |
| 作品页信息（连载状态、更新集数、评分、热度） | 有 | 有 |
| 分类筛选与搜索 | 有 | 有（类型/状态/题材筛选） |

网页版首页的板块标题旁都带「查看全部 / 更多」这类入口，点进去是对应的完整列表页——新番日历的「查看全部」是按更新时间排序的作品列表，热门排行也有能一路翻到底的完整榜单页，适合一次翻几十部找番；手机端这些内容收在首页各板块里，翻找的路径更短，一次看到的多是当天的量。

作品页两边展示的是同一套信息：「连载中 | 更新至 X 集」或「已完结 | 共 X 集」的更新状态、评分，还有一个热度数字——数字大的就是近期看得多的作品，挑番时可以拿来当参考。

## 三、使用上的差异

| | 网页版 | 手机 app |
| --- | --- | --- |
| 怎么打开 | 浏览器输入网址 | 桌面图标，点开即用 |
| 适合场景 | 电脑前坐着看，屏幕大 | 通勤、睡前碎片时间 |
| 获取方式 | 无需安装 | 需要 APK 安装包（见[下载与安装教程](下载与安装教程.md)的获取方式） |
| 设备要求 | 有浏览器即可 | 安卓手机 |

账号方面：网页版有账号体系，手机端也有登录入口，但两端账号是否互通暂无官方说明（处理办法见[怎么登录与注册账号](怎么登录与注册账号.md)第四节）；观看本身两端都不要求登录。

## 四、怎么选

给你两条实际判断依据：

- **人在电脑前、想长时间看**：直接开网页版 [tvtfun.net](https://tvtfun.net)，不用折腾安装；
- **通勤路上、躺床上刷**：装手机 app，打开比浏览器快，追番表每天瞄一眼也方便。

两端可以并存着用：白天在电脑上用网页版补番，路上用手机 app 追更新。app 端的完整用法见[追番功能与使用教程](追番功能与使用教程.md)。
