## 一、不登录能不能看

能。多个来源的说法一致：TVTfun 打开后不注册、不登录就能直接挑番播放，观看环节没有账号门槛。具体到你会在应用里做的几件事：

| 动作 | 需要账号吗 |
| --- | --- |
| 浏览番剧列表、看新番日历 | 不需要 |
| 搜索、按类型/状态/题材筛选 | 不需要 |
| 选集播放、调线路/清晰度/倍速 | 不需要 |
| 注册账号、登录 | 只有这一步才需要 |

也就是说，账号相关的入口你可以完全无视；如果你就是想登一个，往下看操作步骤。

## 二、登录入口与步骤

想用账号的话，入口在应用内：

1. 打开 TVTfun，在首页**右上角**找到「登录」按钮，点它会弹出登录窗口；
2. 在输入框里填入账号与密码，点登录；
3. 登录成功后回到首页，就是登录状态。

注意入口位置是「右上角」，首页顶部的番剧海报、日历那些区域点不出登录窗口，别在内容区里找。

## 三、注册新账号

没有账号时，在登录窗口里点「注册」，按页面提示填写：

| 字段 | 说明 |
| --- | --- |
| 用户名 | 自己起，之后用它登录 |
| 邮箱 | 填一个你能正常收信的邮箱 |
| 验证码 | 按页面提示获取后填入；收不到时先确认邮箱没填错，稍等重试，以页面实际提示为准 |
| 密码 | 自己设置 |

填完提交，注册就完成了，回到登录窗口用刚才的账号密码登录即可。

## 四、账号和网页版通用吗

TVTfun 先有网页版（[tvtfun.net](https://tvtfun.net)），手机端是从网页端转出来的。网页版同样有账号体系，但「手机端与网页端的账号是否互通」目前没有找到官方说明——如果你在网页版已经有账号，可以先拿网页版的账号密码在手机端试一次，能登上就是互通；登不上也不影响观看，两边各用各的即可。两个端的差异整理在[网页版与手机版有什么区别](网页版与手机版有什么区别.md)里。

## 五、登录相关的几种小状况

- **打开时又被要求登录**：有用户反馈过免登录打开、偶尔却碰到要输密码的情况。遇到时先确认是不是误触了登录入口；确实被登出了，重新输一遍即可，不影响看番。
- **登录按钮没反应**：多与当时的网络或服务端状态有关，先换个网络环境或稍后再试；播放环节的同类排查思路写在[视频加载失败怎么办](视频加载失败怎么办.md)里，可以参考。
- **忘了密码**：应用内没看到明确的找回入口，先在登录窗口留意有没有「忘记密码」之类的选项；没有的话，到网页版 [tvtfun.net](https://tvtfun.net) 的登录页找找同样的入口，实在找不回就重新注册一个。

登录与观看都就绪后，剩下的就是怎么用得顺手了——首页四大板块、新番日历、倍速与弹幕的用法都在[追番功能与使用教程](追番功能与使用教程.md)里。
