## 一、安装前先了解这款 app

TVTfun 是一款安卓端的动漫追番应用，从同名网页版（[tvtfun.net](https://tvtfun.net)）转出，打开就能浏览番剧列表并在线播放。在主流应用商店里不容易搜到它，常见的获取方式是拿 APK 安装包自己装——本文讲的正是这条路。

本文对应的安装包信息如下，装好后如果怀疑拿到的不是这一版，可以对照核对：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.0 |
| 安装包大小 | 8.28 MB |
| 包名 | com.tvtfun.net |
| MD5 | 859EBEE7F64071F477844DCF4885F722 |
| 语言 | 简体中文 |
| 系统要求 | 安卓（安装包标注的系统门槛很低，近几年的设备基本都能装，以实际安装时提示为准） |

## 二、拿到安装包

1. 打开 [TVTfun 安装文件资源（夸克网盘）](https://pan.quark.cn/s/24e7ce811c5d)；
2. 按页面提示把文件转存到自己的网盘，或直接下载到手机；
3. 下载完成后你会得到一个 `.apk` 文件，它就是安装包本体。

建议在 Wi-Fi 环境下下载。安装包本身不大（8.28 MB），流量下载也不吃力，但后续追番是在线播放，流量消耗主要在观看环节。

## 三、安装步骤

1. 在文件管理器里点开刚下载的 `.apk` 文件；
2. 系统弹出「是否允许安装未知来源应用」时，选择允许（不同品牌手机的入口略有差异，见下一节）；
3. 等安装完成，点「打开」直接进入应用，或回到桌面点 TVTfun 图标。

装好后第一次打开，首页就是番剧列表与更新日历，不需要注册登录就能直接看（登录相关见[怎么登录与注册账号](怎么登录与注册账号.md)）。

## 四、装不上时的常见情况

| 现象 | 原因与处理 |
| --- | --- |
| 提示「禁止安装未知来源应用」 | 系统默认拦截外部 APK。到 设置 → 安全（或 应用管理）里允许该来源安装；小米手机在「纯净模式」里关掉后再装，华为部分机型需要在「更多安全设置」里放开 |
| 安装到一半失败 / 提示包损坏 | 下载过程出问题的可能性最大，删掉重下一次；重下后仍失败，可对照上表 MD5 核对文件完整性 |
| 提示「与已安装应用冲突」 | 手机里装过同包名的旧版本，先卸载旧的再装 |
| 提示系统版本过低 | 设备安卓版本太老，不满足安装包要求；这类情况只能换设备 |
| 手机管家报风险提示 | 侧载 APK 是正常安装方式，提示是否继续由你自行判断；本篇只讲安装动作本身 |

安装过程中如果手机反复弹出拦截窗口，先完成「允许该来源安装」的设置再重试，不要连续点安装。

## 五、想核对安装包时怎么查

第一节表格里的 MD5 就是这个安装包的「指纹」——文件内容有任何一点改动，MD5 都会变。核对办法：

1. **在电脑上**：把 APK 文件传到电脑，打开命令提示符（CMD），输入 `certutil -hashfile "文件完整路径" MD5`，回车后输出的一串十六进制就是 MD5，逐字对照第一节的值（不区分大小写）；
2. **在手机上**：部分文件管理器自带「文件校验」或「属性」功能，能直接算 MD5；没有的话先装后用，这一步不是必做；
3. **最简单的两个对照**：文件大小约 8.28 MB、装出来在应用信息里显示的包名是 `com.tvtfun.net`——这两点对得上，基本就说明是同一份包。

MD5 对不上时不要安装，回到获取渠道重新下载一次再看。

## 六、装好之后

第一次打开 TVTfun，建议先花一分钟把首页的板块结构看一遍，再直接搜一部想看的番试试播放——播放环节遇到黑屏或转圈的情况不在少数，排查顺序写在[视频加载失败怎么办](视频加载失败怎么办.md)里；日常追番的完整玩法（新番日历、分类筛选、倍速、弹幕）见[追番功能与使用教程](追番功能与使用教程.md)。
