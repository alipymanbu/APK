## 一、一句话定位

bilimiao 不是 B 站官方应用，是个人开发者基于 B 站公开接口做的第三方客户端；**看视频的路子一样，界面取舍和功能侧重点不同**。你的账号、收藏、关注在两边是同一套（登录同一个 B 站账号即可），差别主要在下面这张表。

## 二、功能对照

| 维度 | bilimiao | 官方客户端 |
| --- | --- | --- |
| 推荐 / 热门 / 搜索 / 播放 | 有 | 有 |
| 时光机（按时间段翻分区热门） | 有，这是它最早的功能 | 无 |
| 视频下载 | 有，不登录也能下 | 有（缓存） |
| 列表屏蔽关键字 / UP 主 | 有，对分区与搜索列表生效 | 有类似机制，入口不同 |
| 直播、商城等板块 | 无，界面只留看视频相关 | 有 |
| 广告 | 各渠道介绍均提到界面内无广告，以实际体验为准 | 有商业化广告位 |
| 充值支付、开播 | 不做这些事 | 完整支持 |
| 更新与问题反馈 | GitHub / Gitee Release、Issues | 应用商店与官方客服 |

（表中 bilimiao 一列以 2.5.0 版为参照；官方客户端功能以各版本实际为准。）

## 三、什么时候用哪个

- **日常刷视频、翻历史热门、想把界面清一清** → bilimiao，[时光机](时光机时间线使用方法.md)在官方客户端里没有对应功能；
- **充值大会员、开播、买周边、找官方客服** → 回官方客户端，这类涉及账号资产与官方服务的操作只在官方侧完成，见[登录账号的方法](登录账号的方法.md)；
- 两者可以共存，同一账号登录哪边收藏都通，不用二选一。

## 四、用第三方客户端要有数的几件事

- **接口变动会带来波动**：bilimiao 依赖 B 站的接口，B 站那边一改，可能出现部分功能短暂失效的情况（有用户反馈过这类问题）；通常等开发者发新版修复，去 GitHub Release 装新包即可，见[常见问题与故障排查](常见问题与故障排查.md)第五节；
- **不是应用商店分发**：装它要手动装 APK，渠道见[下载与安装教程](下载与安装教程.md)；
- **官方对第三方客户端的态度与功能开放程度可能变化**：以实际能用为准，本文写的功能清单截至 2.5.0 版，之后以官方渠道与实际界面为准。
