## 一、屏蔽标题关键字与 UP 主

如果你刷分区列表时总被某类标题刷屏，或者不想再看到某个 UP 主，可以在设置里加屏蔽规则：

1. 进入应用的**设置**，找到屏蔽相关入口（屏蔽关键字 / 屏蔽 UP 主）；
2. **关键字屏蔽**：输入标题里会出现的词（比如某个营销词、某个综艺名），保存后标题含该词的视频会从列表里消失；
3. **UP 主屏蔽**：输入或选择要屏蔽的 UP 主，其投稿不再出现在列表；
4. 规则支持多条，随时可以回去删改。

生效范围主要是**分区列表（含时光机时间线列表）与搜索列表**——这正是你翻历史热门时最需要清爽的两个地方。推荐页走的是另一套推荐逻辑，屏蔽规则对它不一定生效，以实际表现为准。

## 二、区域限制与代理服务器

部分番剧、影视因为版权只在特定地区可播，点开可能提示无法播放或直接空列表。bilimiao 在设置里提供了**区域限制 - 代理服务器**，给这类请求配一个可用的代理：

1. 进入**设置 → 区域限制 / 代理服务器**；
2. **添加服务器**：填入你自己的代理地址（能翻到可播地区的节点）；
3. 保存后按需开启「使用代理观看视频」，再去试之前失败的视频。

关于这个设置的边界，先说清楚：

- 代理地址得**你自己有**（自建或服务商给的都行），bilimiao 只负责用它发请求，不提供节点；
- 代理支持设置**请求参数与请求头**（2.3.1 版起），一般用默认就行，遇到需要特殊配置的代理再动；
- 只是「部分番剧看不了」时才需要动这里；**全部视频都放不出来**更可能是网络或应用本身的问题，见[常见问题与故障排查](常见问题与故障排查.md)；
- 代理的速度直接决定播放流畅度，节点慢就换一个，别把卡顿都当成应用的问题。

## 三、其他值得顺手调的设置

- **弹幕**：三种模式独立设置、显示行数、样式参数这些都在播放器的弹幕设置里，完整清单见[播放器设置与定时关闭](播放器设置与定时关闭.md)第四节；
- **播放**：长按倍速、进度条显示/隐藏、小窗与定时关闭，见[播放器设置与定时关闭](播放器设置与定时关闭.md)；
- **主题与显示**：多套颜色主题可换，平板可开横屏；手表上文字过大时调「设置 → 视频设置 → 应用内 DPI 设置」，数值越大字越大。
