## 一、下载入口在哪里

下载按钮在**播放页底部的操作栏**里，图标写着「下载」。普通视频和番剧都支持下载，而且**不登录也能下**，默认给的就是最高画质。若操作栏被折叠，先点一下视频呼出控制条。

## 二、操作步骤

1. 打开 bilimiao，用搜索或分区列表找到想下的视频，点进去播放；
2. 点播放页底部的**下载**按钮；
3. 在弹出的「请选择分P下载」面板里**勾选要下的分集**（多 P 视频可以逐个勾），**选择画质**（默认最高，也可以手动降到 720P 省空间）；
4. 点「开始下载」，按钮上会显示已选的数量，任务随即进入下载管理，可以看进度；
5. 下完在**下载管理**界面查看，断网时从这里进入离线播放。

## 三、几个实际会碰到的问题

| 情况 | 说明 |
| --- | --- |
| 下载前先看存储空间 | 高清视频单集几十上百 MB 很常见，空间不足会中途失败；先在下载管理里清掉看过的 |
| 画质档位能到多少 | 多个渠道的介绍都提到不登录也能拿到高画质档位；实际能选到哪一档，以下载面板里列出的为准 |
| 提示区域受限的视频 | 部分番剧对地区有版权限制，下载和播放都会被拦，处理办法见[屏蔽关键字与区域代理设置](屏蔽关键字与区域代理设置.md) |
| 下载失败或卡住 | 先删掉任务重试，仍不行按[常见问题与故障排查](常见问题与故障排查.md)逐条排查 |

## 四、下载的文件在哪

下载的内容由应用自己管理，在「下载管理」界面统一查看、删除，不需要你去文件目录里翻。要清理旧缓存，也从下载管理里删，别手动删应用目录——容易留下索引对不上的残留，下次打开列表里还是删不掉的条目。

另外提醒一句：下载功能是为了你**离线看自己常看的内容**，存下来的视频请自己看，不要拿去转载或再分发。
