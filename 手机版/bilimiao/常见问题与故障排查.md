## 一、先做三步分诊

出问题先别急着重装，按顺序判断，能省一半时间：

1. **换个视频试**：只有当前这个不行 → 多半是这条内容本身的问题（被删、区域限制、大会员专享），见第三节；换几个都不行 → 往下走；
2. **换个网络试**：Wi-Fi 和流量互切一次；能连其他网站但 B 站内容全出不来，先检查手机是否挂了系统代理；
3. **看版本**：与 [下载与安装教程](下载与安装教程.md) 里的表格对一下版本；版本明显偏旧，先升级到新包再复测。

## 二、播放类问题

| 现象 | 排查方向 |
| --- | --- |
| 全部视频加载失败/转圈 | 网络问题优先：切网、关系统代理；仍不行等几分钟再试，可能是 B 站接口临时故障 |
| 只有部分视频（多为番剧）放不出 | 区域限制，按[屏蔽关键字与区域代理设置](屏蔽关键字与区域代理设置.md)第二节配代理服务器 |
| 画面卡顿 | 先降画质（播放器内切换）；确认不是单个视频卡（换一个对比）；再看当前网速是否扛得住所选档位 |
| 有声音没画面 / 花屏 | 先切一档较低画质确认是否解码吃不住；仍异常就记下机型与版本，等新版本修复或去项目页反馈 |
| 弹幕遮挡字幕 | 播放器弹幕设置里调模式或显示行数，详见[屏蔽关键字与区域代理设置](屏蔽关键字与区域代理设置.md)第三节 |

## 三、打不开、闪退、掉登录

- **安装被拦**：系统不让装未知来源 APK —— 对安装来源开启「允许安装未知应用」后重装，见[下载与安装教程](下载与安装教程.md)。
- **打开就闪退**：
  1. 确认系统版本满足要求（安卓 5.2 以上，各渠道标注略有差异）；
  2. 系统设置里对该应用**清缓存**后再开；
  3. 仍闪退则清数据（会丢登录态）或卸载重装；
  4. 只有某个页面闪退 → 记下操作路径，等新版本修复（官方更新日志里修过「时光机列表滚动闪退」「历史页面闪退」这类单页问题）。
- **掉登录**：升级覆盖安装或清过数据后掉登录属正常，重新走一遍[登录账号的方法](登录账号的方法.md)里的流程即可。
- **下载中断**：删任务重试，仍失败见[视频下载与缓存教程](视频下载与缓存教程.md)第三节。

## 四、设备与显示适配

- **平板/横屏**：界面支持横屏与 pad 布局；某页在横屏下错位，先竖屏确认是否只是该页适配问题。
- **安卓手表**：主要适配手机平板，手表上常见「字太大、按钮挤」——到「设置 → 视频设置 → 应用内 DPI 设置」调小 DPI；同时建议开「默认全屏播放」，避免小窗看不清。
- **车机/其他安卓设备**：按手机端同样思路排查，先保证系统安卓版本达标。

## 五、还是解决不了

按优先级试这三条：

1. **升级到最新版**：官方 Release 页（`https://github.com/10miaomiao/bilimiao2/releases`）下载新包覆盖安装，多数单页 Bug 靠升级解决；
2. **换渠道的包对比**：F-Droid 上架的是 FOSS 版（移除了部分闭源库），与 GitHub Release 的包略有差异；一个渠道的包异常，可以换另一个渠道的包重装对比；
3. **带上复现步骤去反馈**：项目在 GitHub / Gitee 开 Issues，也可以进官方页面提到的 QQ 频道交流；反馈时写清设备型号、系统版本、 bilimiao 版本和操作路径，比一句「用不了」有用得多。
