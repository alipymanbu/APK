## 一、这是个什么应用

bilimiao 是个人开发者「10喵喵」做的第三方哔哩哔哩（B 站）安卓客户端，最早叫「哔哩哔哩时光机」，后来逐步补上了推荐、热门、动态、搜索、播放、下载这些日常看视频会用到的功能。界面里没有商城、直播这类板块，你打开就是刷视频。项目源码公开在 GitHub 与 Gitee 上，许可证是 GPL-3.0，F-Droid 商店里也有上架。

安装包目录名、包名这些都是识别同一个应用的依据，装之前可以先核对一下：

| 应用名 | bilimiao（哔哩喵） |
| 包名 | `com.a10miaomiao.bilimiao` |
| 版本 | 2.5.0 |
| 安装包大小 | 39.01M |
| MD5 | `BF9D47D31A2EA8DF2E2DEC84F409498C` |
| 系统要求 | 安卓 5.2 以上（各渠道标注不一，以实际安装结果为准） |

## 二、从哪拿安装包

你手边就有现成的：**bilimiao 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/d3d512bedf03](https://pan.quark.cn/s/d3d512bedf03)。转存到自己的网盘再下载即可，网盘里这一份是 2.5.0 版、39.01M，与上面表格一致。

官方渠道也有几个，看你想装哪一版：

1. **GitHub Release**：`https://github.com/10miaomiao/bilimiao2/releases` —— 官方发布页，版本号与更新说明最权威；
2. **Gitee Release**：`https://gitee.com/10miaomiao/bilimiao2/releases` —— 国内访问通常更快，内容与 GitHub 同步；
3. **F-Droid**：`https://f-droid.org/packages/com.a10miaomiao.bilimiao` —— 商店安装，之后有新版本会自动提示更新；F-Droid 上架的是 FOSS 版（移除了部分闭源库），与 release 页的包略有差异；
4. **开发者个人站**：`https://10miaomiao.cn/project/bilimiao` —— 有版本介绍与备用下载地址。

拿不准的时候核对 MD5：下载完成后用任意校验工具比对 `BF9D47D31A2EA8DF2E2DEC84F409498C`，对得上就是同一份包（以官网页面当时显示为准，版本会更新）。

## 三、安装步骤

1. 把 APK 文件下载到手机（或先传到手机），文件名类似 `bilimiao_v2.5.0.apk`；
2. 点击文件开始安装；系统若弹出「禁止安装未知来源应用」，进入设置对该来源（文件管理器或浏览器）开启允许，再回来装；
3. 装完打开，首次进入是未登录状态，推荐、热门可以直接刷，登录、追动态要先[登录账号](登录账号的方法.md)；
4. 建议顺手到「设置」里看一眼播放与画质选项，把默认画质、弹幕这些按自己习惯调好。

覆盖安装（旧版升级新版）直接装新包即可，包名相同、数据会保留；若出现升级后闪退，先清数据再装，见[常见问题与故障排查](常见问题与故障排查.md)。

## 四、网盘里这个 2.5.0 版更新了什么

- 整体界面改版，侧边栏菜单与播放器都重新做了，部分设置项的位置与旧版不同；
- 新增**独立的定时关闭设置页面**（睡前定时停播，用法见[播放器设置与定时关闭](播放器设置与定时关闭.md)第三节）；
- 菜单新增多级展开。

更早版本的要点（官方更新日志）：2.4.8 加了新版搜索输入界面、恢复 Material You 主题选项、修复部分视频无法播放；2.3.1 把搜索与导航改回侧边拉出、弹幕设置分成三个模式独立设置。完整记录见 GitHub Release 页，以官方页面当时显示为准。

## 五、装完第一次用，先知道这几件事

- **不登录也能看**：首页推荐、热门、搜索、播放都能用；登录后才能看关注动态、发评论弹幕、管理收藏。
- **版本会持续更新**：官方更新节奏不定，版本号以 Release 页面为准；网盘里这份固定是 2.5.0，想追新版就去 Release 页下新包。
- **多端形态**：主要适配手机与平板（支持横屏），也有人在安卓手表上用；手表显示异常的调整办法见[常见问题与故障排查](常见问题与故障排查.md)。
