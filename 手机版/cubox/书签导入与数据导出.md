## 一、导入书签：支持的来源与上限

网页端设置里的导入书签页面支持这些来源：Cubox（官方导出格式）、Chrome、Safari、Firefox、Pinboard、Pocket、Instapaper，以及通用 HTML 书签文件。来源不在列表里时，先从那个服务导出成通用 HTML，再按 Chrome 类型导入，多数能成。

两条限制提前知道：

- **免费账号最多导入 200 条**，整库迁移需要会员（额度对照见[会员价格与免费额度](会员价格与免费额度.md)）；
- 同一批书签重复导入会产生重复项，用 Cubox 的「清除重复链接」功能一键清理。

导入是在后台进行的，量大时标题、描述、图标会分批慢慢补齐，刚导完列表看起来残缺是正常现象。

## 二、导出为文件

在收藏卡片或阅读器菜单里可以找到复制与导出选项：

| 操作 | 说明 |
| --- | --- |
| 复制原链接 | 拿到网页原始地址，可复制成 Markdown 链接用于写作 |
| 复制为纯文本 / Markdown / HTML | 已解析的文章与标注支持这几种格式，可直接贴进笔记软件 |
| 导出为文件 | 支持 .TXT、.Markdown、.HTML、.PDF，用于备份或导入其他 App |

注意格式跟内容类型挂钩：**未被解析成文章的网页，只能导出快照 HTML**；想拿到 Markdown 版本，先确认那条收藏已经被解析成文章了。

## 三、批量导出书签

在「偏好设置 > 导入 & 导出」里，可以把账户中所有带网页链接的收藏（网页、文章、片段）批量导出为**通用 HTML 书签格式**，并保留收藏夹的嵌套层级。换工具或定期备份都走这个口子——这也是会员到期后把数据整体搬走的标准做法。

## 四、深度链接：在外部工具里引用收藏

每条收藏、标注、收藏夹、智能列表、标签都有一个 Cubox 深度链接，点击直接跳回对应内容：

- 客户端里长按列表项（Mac 为右键）选「复制 Cubox 链接」；
- 网页版直接复制当前列表的地址栏 URL。

在 Notion、Obsidian 这类工具里搭建目录或索引时，把深度链接贴过去，可以从你的笔记一键跳回 Cubox 原文；官方还提供同步到 Obsidian、Notion、FlowUs 的插件，按需取用。

## 五、注销账号与数据保留

三件事按时间线排给你：

1. **长期不用会先提醒**：超过 1 年没有登录使用的账号，官方会通过短信或邮件提醒你导出数据；超过通知期后，数据会被永久删除；
2. **主动注销**：在网页版「设置 > 我的帐户」里选择停用帐户，**所有数据彻底删除、无法恢复**。旧版官方 FAQ 还留了一条邮件通道——用注册邮箱发送标题为「删除账户」的邮件至 [hi@cubox.pro](mailto:hi@cubox.pro)——入口找不到时可以走这条；账号删除后有约三个月的安全保留窗口期，期间数据不再展示但仍被保留；
3. **会员到期**：不会清数据，只是回到免费额度，随时可导出（见[会员价格与免费额度](会员价格与免费额度.md)）。

所以无论走哪条路，**先做一遍第三节的全量书签导出**再动手，是唯一稳妥的顺序。
