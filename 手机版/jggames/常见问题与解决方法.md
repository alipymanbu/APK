## 一、安装时提示「解析失败 / 安装失败」

按出现频率从高到低排查：

| 症状原因 | 怎么确认 | 怎么处理 |
| --- | --- | --- |
| 存储空间不足 | 手机「设置 → 存储」看剩余空间 | 清掉不用的文件与旧安装包，腾出空间后重装 |
| 安装包下载不完整 / 损坏 | 文件大小明显小于 2.21 MB | 删掉残包，重新下载（见下方链接） |
| 装了两遍 / 覆盖冲突 | 手机里已有旧的 jggames | 先把旧版本卸载干净，再装这个 1.0 |
| 系统版本低于要求 | 手机「关于手机」里的安卓版本 | 这个包的记录标的是「安卓 5.2 以上」；版本确实过低就换机或换包 |

重新下载安装文件：[jggames 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3511b07a7cc0)（对照 [下载与安装教程.md](下载与安装教程.md) 里的 MD5 与体积核对）。

## 二、弹「禁止安装来自此来源的应用」

这不是包的问题，是系统的未知来源拦截。到 **设置 → 安全（或隐私）→ 安装未知应用**，给你刚才用来打开 APK 的那个应用（文件管理器 / 浏览器 / 夸克）勾上允许，再回到安装界面重试。部分品牌机型在安装时会多一步「仍要安装」的确认，点它即可。

## 三、装完打开就闪退 / 黑屏

1. 先重启手机再打开一次 —— 大部分偶发闪退重启后就恢复；
2. 长按应用图标 → 应用信息 → 存储占用 → **清缓存**（清数据会删掉登录状态，能清缓存先不清数据）；
3. 检查应用权限有没有被系统默认关掉（存储、网络等），在应用信息里放行；
4. 还闪退就卸载重装。**若你在这个应用里登录过账号，卸载前先记好账号信息**，重装后需要重新登录；
5. 以上都无效，多半是这台机型与这版不兼容，留意渠道有没有出新版本。

## 四、进得去但内容加载不出来

- jggames 需要联网使用，先确认 Wi-Fi / 流量至少有一个是通的；
- 在 Wi-Fi 和流量之间切换一次再刷新 —— 单一网络的偶发抽搐很常见；
- 游戏详情、资讯、礼包这些都在线拉取，集中打不开时多半是服务端在维护，过段时间再进；
- 长期打不开就走第三节的清缓存 → 卸载重装流程。

## 五、怎么确认自己没装错包

同名的 jggames 有好几个版本在流传（有的同包名同版本、体积却对不上），装错了功能对不上很正常。打开 **设置 → 应用管理 → jggames → 应用信息**，核对包名是不是 `com.jgg18.h5game`、版本是不是 1.0、体积是不是 2.21 MB；对不上就卸载，按 [下载与安装教程.md](下载与安装教程.md) 重新装对的包，完整的同名条目对照与 MD5 核对方法在 [同名版本怎么区分.md](同名版本怎么区分.md)。

## 六、登入不进去 / 忘记密码

1. 先确认网络是通的，再检查用户名（或邮箱）和密码有没有拼错、大小写对不对；
2. 忘了密码就用登入页的 **重置密碼**，按界面提示用注册时的用户名或邮箱重置（流程见 [注册登录与重置密码.md](注册登录与重置密码.md)）；
3. 提示账号不存在：想想注册时用的是用户名还是邮箱，两个都试一遍；
4. 仍进不去：侧栏的 **支援** 入口是这版界面里能找到的客服通道，从那里反馈你的账号问题。

## 七、下完的游戏找不到安装包

- 安卓的**文件管理**里一般有「安装包」分类（或按类型浏览 → 安装包），下载好的 `.apk` 会归到那里；
- 部分系统装完会**自动清掉安装包**省空间，列表里没有不等于没装上 —— 到 **设置 → 应用管理** 里看游戏在不在，装上了就不用管安装包；
- 想留着安装包备用（换机、重装），在安装前先到文件管理里把它挪到自己记得住的目录；
- 盒子自己的下载目录各版本不一，公开资料里没有 jggames 的具体路径，以应用内下载设置页当时显示的为准。
