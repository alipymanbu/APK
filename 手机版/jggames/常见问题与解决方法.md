## 一、安装时提示「解析失败 / 安装失败」

按出现频率从高到低排查：

| 症状原因 | 怎么确认 | 怎么处理 |
| --- | --- | --- |
| 存储空间不足 | 手机「设置 → 存储」看剩余空间 | 清掉不用的文件与旧安装包，腾出空间后重装 |
| 安装包下载不完整 / 损坏 | 文件大小明显小于 2.21 MB | 删掉残包，重新下载（见下方链接） |
| 装了两遍 / 覆盖冲突 | 手机里已有旧的 jggames | 先把旧版本卸载干净，再装这个 1.0 |
| 系统版本低于要求 | 手机「关于手机」里的安卓版本 | 这个包的记录标的是「安卓 5.2 以上」；版本确实过低就换机或换包 |

重新下载安装文件：[jggames 安装文件资源（夸克网盘）](https://pan.quark.cn/s/adcc0375ba56)（对照 [下载与安装教程.md](下载与安装教程.md) 里的 MD5 与体积核对）。

## 二、弹「禁止安装来自此来源的应用」

这不是包的问题，是系统的未知来源拦截。到 **设置 → 安全（或隐私）→ 安装未知应用**，给你刚才用来打开 APK 的那个应用（文件管理器 / 浏览器 / 夸克）勾上允许，再回到安装界面重试。部分品牌机型在安装时会多一步「仍要安装」的确认，点它即可。

## 三、装完打开就闪退 / 黑屏

1. 先重启手机再打开一次 —— 大部分偶发闪退重启后就恢复；
2. 长按应用图标 → 应用信息 → 存储占用 → **清缓存**（清数据会删掉登录状态，能清缓存先不清数据）；
3. 检查应用权限有没有被系统默认关掉（存储、网络等），在应用信息里放行；
4. 还闪退就卸载重装。**若你在这个应用里登录过账号，卸载前先记好账号信息**，重装后需要重新登录；
5. 以上都无效，多半是这台机型与这版不兼容，留意渠道有没有出新版本。

## 四、进得去但内容加载不出来

- jggames 需要联网使用，先确认 Wi-Fi / 流量至少有一个是通的；
- 在 Wi-Fi 和流量之间切换一次再刷新 —— 单一网络的偶发抽搐很常见；
- 游戏详情、资讯、礼包这些都在线拉取，集中打不开时多半是服务端在维护，过段时间再进；
- 长期打不开就走第三节的清缓存 → 卸载重装流程。

## 五、怎么确认自己没装错包

同名的 jggames 有好几个版本在流传，装错了功能对不上很正常。打开 **设置 → 应用管理 → jggames → 应用信息**，核对包名是不是 `com.jgg18.h5game`、版本是不是 1.0；对不上就卸载，按 [下载与安装教程.md](下载与安装教程.md) 重新装对的包。
