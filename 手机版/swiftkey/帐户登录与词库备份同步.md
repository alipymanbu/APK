## 一、登录能得到什么

SwiftKey 帐户用你的 Google 或 Microsoft 账户创建，应用内"帐户"页即可登录。登录之后才有的东西：

- **备份和同步**：你教出来的词与短语存到云端，换机、重装、丢机都不丢；
- **主题随身带**：换设备登录后主题跟着过来，见[主题与键盘外观设置](主题与键盘外观设置.md)第一节；
- **手机与 Windows 互传剪贴板**：两边登录同一帐户后可跨设备复制粘贴；
- 应用本身免费，装几台设备都行，不登录也能正常打字。

不登录的情况下，官方隐私说明写明：你的个人与语言数据只存在设备本地，不上传。

## 二、开启备份和同步

1. 打开 SwiftKey 应用。
2. 点"帐户"。
3. 点"备份和同步"。
4. 勾选"备份和同步"。

同一页里两个实用的选项与操作：

- **仅限 Wi-Fi 同步**：流量紧张就勾上；
- **手动同步**：该页显示数据上次保存到云端的时间，点圆形箭头图标立刻同步一次（重装前、大改动词库后建议手动推一次）。

## 三、换机或重装时怎么把词库找回来

1. 新设备装好 SwiftKey（来源见[下载与安装教程](下载与安装教程.md)）；
2. 在"帐户"里登录**同一个** SwiftKey 帐户；
3. 保持备份和同步开启，等它拉取，或手动点同步。

两个常见误会：

- "SwiftKey 统计"页在新设备上是空白的，这项统计不迁移，不代表词库丢了，见[词库预测与删词方法](词库预测与删词方法.md)第四节；
- 只卸载应用、没登录过帐户的，本地学习记录随卸载消失，这种没有找回一说，只能重养。

## 四、查看与导出你被记录的词

应用 → 帐户 → "查看并管理你的数据"会打开 SwiftKey 数据门户（`https://data.swiftkey.com/`），用你创建帐户时的同一 Google/Microsoft 账户登录（注意：支持站点的账号登不进门户，两者不是一套）。里面能做三件事：

| 操作 | 位置 | 说明 |
| --- | --- | --- |
| 查看 | View data | 滚动列表看键盘这些年学到的所有词 |
| 导出 | View data → Export all | 把全部词下成一个文件留底；它是快照，之后新学的词要再导一次 |
| 管理帐户 | Manage Account | 全设备登出 / 删除备份 / 永久删除帐户 |

门户里**删不了单个词**——删单个词回到键盘上长按候选条里的词，见[词库预测与删词方法](词库预测与删词方法.md)第二节。

## 五、删除云端数据与注销帐户

- **关掉备份和同步 ≠ 删除云端数据**：开关只管以后传不传，已上传的还在，要单独删；
- **删云端词库备份**：应用 → 帐户 → "删除个性化词典备份" → 确认；
- **登出帐户**：应用 → 帐户 → 注销；登出后不再往云端学新数据；
- **永久删除帐户**：数据门户的 Manage Account 里操作，会把帐户、云端的词与已下载的内容一并清掉，**不可恢复**，执行前先把想留的词导出一份。

真在意输入内容上云的话，最省事的组合是：不登录帐户（数据全在本机）+ 打密码时不依赖"显示密码"，密码字段本来就学不进去。
