## 一、工具栏怎么开、里面有什么

点候选条**左侧的那个图标**展开工具栏；再点一次收起。工具栏集中了这些入口（不同版本略有差异，以你应用内显示为准）：

| 入口 | 用途 |
| --- | --- |
| 搜索 | 必应搜索，结果可直接分享到当前输入框 |
| 聊天 | 必应聊天（AI 对话），在键盘里直接提问 |
| 语气 | 把你已输入的文字改写成"专业 / 休闲 / 礼貌 / 社交帖子"等语气 |
| GIF / 表情 / 贴纸 | 搜索与插入，按场合找图 |
| 剪贴板 | 管理你复制过的内容，见下一节 |
| 翻译 | 边打边译，译完插入输入框 |
| 布局 | 切换全键/九键等布局（中文用法见[中文拼音与模糊拼音设置](中文拼音与模糊拼音设置.md)） |
| 调整大小 / 单手 / 悬浮 | 键盘形态调整，见[主题与键盘外观设置](主题与键盘外观设置.md) |
| 主题 | 换键盘外观 |
| 隐身 | 在不支持的应用里手动关学习，见文末 |
| 设置 | 直达应用设置 |
| 帐户 | 登录与备份同步入口 |

搜索、聊天、翻译、语气这几个功能要联网才能工作，这是它们和纯本地打字功能的区别。

## 二、剪贴板

SwiftKey 自己维护一份剪贴板记录，入口在工具栏：

- 你复制过的文本会按时间列出来，点一条即粘贴到当前输入框，不用再长按粘贴。
- 对常用的那条可以**建快捷方式**，之后从剪贴板里一键插入。
- 剪贴板里存的是你主动复制的内容，想清理就在列表里逐条删。

跨设备复制粘贴是另一回事：登录帐户后，你可以在手机与 Windows 电脑之间互传复制内容（云剪贴板），两边都要登录同一帐户并开启对应同步。

## 三、语音输入

工具栏里的麦克风图标启动语音转文字，说完点一下结束，文字直接进输入框。它是调用系统的语音识别能力，麦克风权限没给的话这里会没反应，去系统"应用 → SwiftKey → 权限"里开。打字与语音随时互切，不用换输入法。

## 四、翻译

工具栏里点翻译，选定目标语言后，你输入的内容会实时给出译文，确认后插入输入框。适合直接用外语回消息的场景；对译文质量有要求的正式文本，建议还是过一遍原文校对。

## 五、隐身模式

密码框这类场景本来就不学习，此外，如果你正处于不想让键盘记录输入内容的对话里，点工具栏的隐身（Incognito）图标手动开启，开启期间的输入不进词库；用完记得关回来，否则这段时间的正常用词也不会被学习。
