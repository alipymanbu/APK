# JoyChat 账号登录与密码重置

> JoyChat 的账号不开放注册，你用哪种账号取决于自己属于哪个组织。本篇讲清三类账号的差别、u00 工号规则、首次登录改密，以及忘记密码时怎么自助重置。

## 一、先对号入座：你的账号属于哪一类

JoyChat 的账号分三个组织：BBA、Dealer、BMW。登录方式差别很大，先看清自己属于哪一类再动手：

| 组织 | 谁属于这一类 | 账号怎么来 |
| --- | --- | --- |
| BBA（办公室员工） | 华晨宝马的办公室员工 | 直接用 Windows 账号密码登录 |
| BBA（生产员工） | 工厂端员工 | 账号和密码通过短信发给你 |
| Dealer | 经销商等合作伙伴 | 用 TAP 系统的账号，密码通过短信接收 |
| BMW | BMW 侧相关用户 | 需自行申请注册，在注册页填写账号并自助初始化密码，注册地址是 [https://id.bba-app.biz](https://id.bba-app.biz) |

还没装应用的，先看 [下载与安装教程.md](下载与安装教程.md)。

## 二、账号格式：工号前面换上 u00

如果你的工号是 P 开头，登录账号不是直接填 P 工号 —— 规则是把 P 换成 u00：工号 P12345 对应的登录账号就是 `u0012345`。第一次登录就卡在这一步的人不少，先确认自己填的是 u00 形式。

## 三、第一次登录：把初始密码改掉

用短信收到的初始密码登录后，第一件事是在应用里把它改成你自己的密码。设新密码时留意规则，不合规会被打回：

- 长度不能小于 10 位；
- 需要同时包含大写字母、小写字母和特殊字符。

密码是实名登录体系的一部分，别图省事设成弱密码，也别把账号借给别人用。

## 四、忘记密码：自助重置步骤

用初始密码登录失败、或者把密码忘了，可以自助重置，不用干等 IT 排队：

1. 用手机浏览器打开 [https://id.bba-app.biz](https://id.bba-app.biz)，进入登录界面；
2. 点击 change password；
3. 选择 reset password via mobile（必须是大陆手机号）或通过邮箱地址重置；
4. 按短信提示拿到新密码，回 JoyChat 用 u 账号登录；
5. 登录后在应用里把密码再改回自己记得住、又符合上面规则的。

重置短信发出去后迟迟不到的，先别反复点重发，按 [收不到登录短信怎么办.md](收不到登录短信怎么办.md) 的顺序查一遍手机侧原因。

## 五、账号密码都拿不到怎么办

如果你不知道自己的账号密码，或者误删了之前公司推送的登录信息短信，打电话给 IT Helpdesk（内线 55555），验证身份后会重新发放账号密码。工会相关应用的业务问题走另一条线 56984。

登录顺利、准备看看里面都有什么的，去 [常用功能上手指南.md](常用功能上手指南.md)；要在 JoyChat 里提交工会入会申请的，流程整理在 [工会入会申请流程.md](工会入会申请流程.md)。
