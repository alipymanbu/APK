# Grammarly 安卓悬浮窗不显示或没有建议怎么解决

> 本篇是排错手册：按「悬浮窗根本不出现 / 有悬浮窗但不出建议 / 提示暂时不可用」三类现象分诊，逐条给处理步骤。

## 一、先分清你遇到的是哪种

同样叫「不能用了」，三种现象的原因完全不同，先对号入座：

| 现象 | 含义 | 直接跳到 |
| --- | --- | --- |
| 打字时悬浮球/悬浮窗压根不出现 | 权限或后台被杀 | 第二、三节 |
| 悬浮窗在，但一个建议都不给 | 连接卡住、文本太短、网络问题 | 第四节 |
| 弹「Grammarly is temporarily unavailable」之类报错 | 服务连接问题 | 第五节 |

排之前先做一件事：**重启手机**。它能清掉一批临时的后台状态，官方排错流程也把这一步放在最前面。

## 二、悬浮窗不出现：先查两项权限

1. **无障碍权限是否还开着**：设置 → 无障碍 → 已安装的应用 → Grammarly。显示「关」就重新打开。两个高频场景要注意：
   - 系统升级后权限会被静默收回——升级完突然失灵，先查这里；
   - 小米等机型上，如果开关点了没反应或报错，先把导航方式切成「按钮导航」（设置 → 显示 → 全屏显示 → 按钮），开完权限再切回手势。
2. **悬浮窗（显示在其他应用上层）权限**：设置 → 应用 → Grammarly → 权限/悬浮窗，确认允许。

这两项权限为什么必需、它拿权限做什么，见 [无障碍权限和隐私说明.md](无障碍权限和隐私说明.md)。

## 三、后台被系统杀掉（各品牌处理）

权限都对却时有时无，多半是省电策略把它的后台服务掐了。按品牌做一遍：

**三星**
1. 设置 → 应用 → Grammarly → 电池 → 优化电池用量，改成「不限制/不优化」——不改的话系统会为省电终止它的无障碍服务。
2. 设置 → 电池和设备维护 → 内存 → 排除的应用，把 Grammarly 加进去，避免一键清理把它清掉。
3. 设置 → 电池和设备维护 → 电池 → 省电，若开着，确认没勾选「限制应用和主屏幕」。

**小米（MIUI/HyperOS）**
1. 设置 → 更多设置 → 无障碍 → 已安装的应用，确认 Grammarly 开着（系统更新后常被关）。
2. 手机管家 → 设置 → 加速管理 → 锁定应用，把 Grammarly 锁进后台。
3. 设置 → 应用设置 → 权限 → 自启动，打开。
4. 手机管家 → 电量 → 应用智能省电，把 Grammarly 设为「无限制」。

**Google Pixel**
1. 应用信息 → 电池使用情况 → 允许后台使用 → 选「不受限制」。
2. 设置 → 无障碍，确认 Grammarly 开启。

**OPPO / 一加（ColorOS 等）**
1. 设置 → 应用管理 → Grammarly → 电池，关闭电池优化（或设为不优化）。
2. 确认无障碍权限处于开启状态。

通用原则就一条：**别让系统为了省电关掉它的无障碍服务与后台连接**。改完回到聊天框打几个英文词验证。

## 四、悬浮窗在，但不出建议

按官方排错顺序来：

1. **重启手机**（前面做过就跳过）。
2. **确认文本够长**：只有几个单词时不出建议是正常行为，不是故障。写满一两句再看。
3. **确认网络正常**：建议是联网算出来的。检查 Wi-Fi/流量能不能上网；用了 VPN 或防火墙就先临时关掉试试；换个网络环境（家里换公司）再试。
4. 仍不行就清缓存：设置 → 应用 → Grammarly → 存储 → 清除缓存 → 重启手机 → 再试。
5. 还不行 → 清除数据（**会退出登录**，清完重新登录）→ 再试。重新登录这一步出问题（报 403、密码不对）不是本篇的范围，见 [登录不上或忘记密码怎么办.md](登录不上或忘记密码怎么办.md)。
6. 最后一步：卸载 → 重启 → 从 [下载与安装教程.md](下载与安装教程.md) 的渠道重新安装。

## 五、提示「暂时不可用」

看到 Grammarly is temporarily unavailable 之类的报错时：

1. 设置 → 网络/连接，修复或重置网络设置（有该选项的话）。
2. 在 Wi-Fi 与移动数据之间切换，确认是不是某一个网络的问题。
3. 关掉输入框再重开（或切换到别的应用打字再切回来）。
4. 退出 Grammarly 账号再登录。
5. 重启手机。

按这个顺序做完仍报错，通常是其服务侧或网络链路的临时问题，隔一段时间再试即可。

## 六、什么时候该怀疑「装的包不对」

如果你是从第三方渠道拿的 APK（比如离线安装包），先核对包名与版本是否与 [下载与安装教程.md](下载与安装教程.md) 里列的一致（包名应为 `com.grammarly.android.keyboard`）。包名对不上、安装后界面完全没见过，就卸载掉换可信渠道的包再排查——权限类排错对一个来路不明的包没有意义。
