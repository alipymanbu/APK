# Grammarly 登录不上或忘记密码怎么办

> 账号进不去的几种情形与对应处理：报错 403、密码忘了、邮箱找不回、账号被停用——步骤全部来自官方支持文档。

## 一、先确认登录入口对不对

输对了邮箱密码还是进不去，先排查入口：

1. 当初用 **Google / Facebook / Apple** 注册的账号，必须在登录页点**对应的按钮**进——直接输邮箱密码会失败。
2. 组织分配的账号（单点登录 SSO）要从组织的身份提供方入口进入，不能直接在普通登录页输密码。
3. 官方支持站注明 **Grammarly 已并入 Superhuman**（含 Go、Grammarly、Coda、Mail 的套件）——账号类问题的最新指引以 [support.grammarly.com](https://support.grammarly.com) 为准。

## 二、报「HTTP ERROR 403 Invalid referer」

安卓端登录时报这个错，官方给的解法是**把默认浏览器临时换成 Chrome**：

1. 设置 → 应用（Apps & notifications）→ 默认应用（Default apps）/ 默认浏览器。
2. 把默认浏览器选成 **Chrome**。
3. 回到 Grammarly 伴随应用重新登录。

登录成功后默认浏览器要不要改回去，按你的使用习惯定。

## 三、忘记密码 / 收不到重置邮件

1. 到重置页 [www.grammarly.com/resetpassword](https://www.grammarly.com/resetpassword) 输入注册邮箱 → **Send me reset instructions**，邮件约 1 分钟内到达，点链接设新密码。
2. 收不到：先查垃圾邮件箱；确认没输错邮箱。官方对「要了重置邮件但没收到」另有专文排查：[I've requested a password reset but I haven't received an email yet](https://support.grammarly.com/hc/en-us/articles/115000089931)。
3. 用 Google/Facebook/Apple 注册、但想设一个独立密码的，官方有对应步骤：[How do I set a password if I registered using Google, Facebook, or Apple?](https://support.grammarly.com/hc/en-us/articles/360058560411)。

## 四、不记得用哪个邮箱注册的

1. 把你常用的所有邮箱都搜一遍关键词 `Grammarly`——它发过的邮件会暴露注册邮箱。
2. 逐个邮箱去 [resetpassword](https://www.grammarly.com/resetpassword) 试：邮箱下有账号才会收到重置信。
3. 付费账号还可以用官方的查找表单提交找回：[payment details lookup](https://support.grammarly.com/hc/en-us/articles/115000089891)。
4. 注册邮箱已经完全用不了（服务商注销等）：官方口径是**用新邮箱重新注册一个账号**，原账号数据不迁移——所以现在就去设一个恢复邮箱很划算（见下节）。

## 五、设一个恢复邮箱（防患）

1. 网页端打开 [account.grammarly.com/profile](https://account.grammarly.com/profile) → **Add recovery email**。
2. 填入备用邮箱 → 到该邮箱收 **15 分钟内有效**的验证码 → 填回验证。
3. 以后主邮箱丢了：登录页点 **Can't sign in?** → **Recover my account** → 输入主邮箱 → 链接会发到恢复邮箱 → 按提示换绑新主邮箱。
4. 限制：恢复邮箱**不能是已绑定其他 Grammarly 账号的邮箱**；免费/Pro/Plus/Business/Education（K–12 除外）账号可用，Enterprise 与 SSO 组织账号暂不支持。

## 六、提示「账号已停用」

看到 *Your account has been deactivated*：这表示账号**被移出了某个组织的订阅**，不是你个人操作导致的。不被加回的话，账号会在 **30 天后永久删除**，之后可以用同一邮箱重新注册。要恢复就联系你所在组织的订阅管理员。

## 七、网络原因的登录失败

登录本质是联网请求，官方排错顺序：修复/重置网络设置 → 重启路由器、确认手机浏览器能上网 → 临时关掉 VPN 与杀毒应用再试 → 换一个网络环境（如从家换到公司）再试。仍不行就截图提交给官方客服（[Contact Support](https://support.grammarly.com/hc/en-us/requests/new)）。

这套网络排查与「出了建议不出来」的排查是同一套，合并看 [悬浮窗不显示或没有建议怎么解决.md](悬浮窗不显示或没有建议怎么解决.md)。还没装或要重装，见 [下载与安装教程.md](下载与安装教程.md)；账号与订阅的关系见 [免费版和Pro版有什么区别.md](免费版和Pro版有什么区别.md)。
