## 一、怎么用这张表

手机端连接失败时，界面上会给出一个数字代码。先在下面两张表里找到对应代码，按「怎么处理」一栏行动。本文只收录手机端作为客户端时高发的代码；完整清单以官方错误码页为准（`https://support.parsec.app/hc/en-us/articles/32381281333012`）。

## 二、连接过程类

| 代码 | 含义 | 怎么处理 |
| --- | --- | --- |
| 6 | 连接请求没被主机及时批准 | 联系主机确认弹窗点了 Accept（或按 `Ctrl+F1`），再重新连 |
| 8 | 连接被主机拒绝或你已被对方屏蔽 | 让主机检查是否误点了 Reject、是否把你拉黑 |
| 9 | 你自己取消了本次连接 | 无需处理，重新发起即可 |
| 11 | 目标电脑满员 | 等空位，或让主机调大席位 |
| 12 | 因长时间无操作被断开 | 重新连接；挂机场景让主机调整闲置踢出时间 |
| 13 | 主机主人自己断开了 | 等对方重新就绪 |
| 99 | 目标电脑已不在线或链接已失效 | 确认电脑开机且 Parsec 在运行；链接入会的话找主机重新生成 |

## 三、网络与设备类（手机端最需要认识的几个）

| 代码 | 含义 | 怎么处理 |
| --- | --- | --- |
| -10 | 找不到可用的视频解码器 | 多为机型太老或解码能力不足，换设备实测 |
| -14 / -18 | 解码视频流失败 / 异常 | 重启 App 再试；安卓端没有「切到软件解码」的退路，反复出现只能让主机降分辨率降帧率（见[延迟高与画面卡顿怎么办](延迟高与画面卡顿怎么办.md)） |
| -19 | 此安卓设备不受支持 | 该机型目前跑不了 Parsec，官方无解，只能换设备 |
| -6023 | 点对点连接建立失败 | 检查两端网络，确认没有双重 NAT / CGNAT（见下文） |
| -6024 | 连不上 Parsec 的 STUN 服务器 | 网络防火墙拦了 UDP 3478 端口，换网络实测 |
| -6101 | 网络阻断了与 Parsec 服务器的通信 | 常见于公司 / 校园网，换手机流量验证 |
| -6112 / -800097 | 设备 IPv6 被禁用或不支持 | 在系统或路由器侧启用 IPv6 后重试 |
| -7000 / -7007 | OpenGL 无法启动 / 版本不兼容 | 手机不满足 OpenGL ES 3 门槛，见[手机与网络要求](手机与网络要求.md) |
| -12007 / -12010 | 网络连接中断 / 主机消失 | 两端网络各查一遍；主机可能死机或断网 |
| -13009 | 主机分辨率超过 4K 上限 | 让主机把显示器分辨率调低再连 |
| -14003 | 主机端抓屏失败 | 主机侧排查显示驱动与多屏设置 |
| -15000 / -15002 | 主机不支持硬件编码 / 编码器失败 | 主机更新显卡驱动、关闭 HDR、降低分辨率 |

## 四、两个反复出现的错误怎么办

**`-6023` / `-6024` 反复出现**：基本可以断定是网络链路问题，而不是手机的问题。依次排查：手机换 5GHz Wi-Fi 或 4G/5G 流量再试一次；确认主机不在双重 NAT 后面（光猫拨号 + 自己路由器再拨号是典型结构）；公司或校园网络里 UDP 被墙就走不通，回家再连。

**`-10` / `-14` / `-19` 这类解码错误**：`-14` / `-18` 先让主机降分辨率、降帧率再试（安卓 App 内没有软件解码选项可切）；`-10` / `-19` 属于设备能力问题，设置救不了，唯一有效的动作是换一台近年主流 SoC 的手机再试，同一台设备上反复卸载重装通常没有意义。

连不上但错误码不在这两张表里，优先去官方错误码页对照；装好还没连过的先回[连接电脑的完整步骤](连接电脑的完整步骤.md)核对主机端是否就绪。
