## 一、整条链路长什么样

手机端 Parsec 只是个「遥控器」，真正干活的是你那台电脑。所以完整流程是三段：

1. **电脑端**装 Parsec 并登录（电脑才能当主机，Windows 10+ 或 macOS 10.15+）；
2. **注册账号**（手机和电脑要用同一个 Parsec 账号体系）；
3. **手机端**登录后点 Connect 连到目标电脑。

安卓端没有主机开关，这一步在手机上不存在——别在手机设置里找了。

## 二、电脑端：装好并登录

1. 到官网 `https://parsec.app` 下载 Windows 或 macOS 版并安装；
2. 启动后注册一个 Parsec 账号（邮箱 + 密码），登录保持在线；
3. Windows 端安装时如果弹出「是否安装手柄支持驱动」，打算用手机端连过去玩游戏的就选是；
4. 保持这台电脑开机、联网、Parsec 挂在后台，它就是你的主机。另外把 Windows 电源设置里的「睡眠」设为「从不」——电脑一旦睡着，手机这边只会看到它离线，连接无从发起。

macOS 也能当主机，但官方说明它更适合办公类操作，手柄与第一人称视角游戏里的鼠标支持不如 Windows 完整。

## 三、手机端：登录并连接（自己连自己的电脑）

这是最常见的用法，全程用同一个账号：

1. 手机上打开 Parsec，用**与电脑端相同的账号**登录；
2. 登录后进入 Computers（计算机）列表，你的电脑会出现在里面；
3. 点该电脑旁的 **Connect**，等待画面出现——手机上现在显示的就是电脑桌面；
4. 结束时在界面里断开连接即可。

看不到自己的电脑？依次检查：两端是否登录同一账号、电脑端 Parsec 是否在运行、电脑是否睡眠关机。仍连不上时看[常见连接错误代码对照](常见连接错误代码对照.md)。

## 四、连别人的电脑（好友 / 快速链接）

**方式一：加好友**

1. 双方各自注册账号，把你的 ID 告诉对方（格式为 `用户名#后缀`，可在个人资料里查看）；
2. 在 Parsec 里通过 Friends 图标发送好友请求，对方接受后成为好友；
3. 对方电脑在线时，你在 Computers 列表里能看到它，点 Connect 发起请求；
4. 主机端会弹窗，选 **Accept** 才能进来——主机不回应，请求超时自动被拒。

**方式二：快速链接**

主机在 Parsec 里点 Share 按钮生成一条邀请链接，把链接发给你；你把它粘贴进 Parsec 界面右下角的输入处发起加入，主机同样要点 Accept 确认。

**权限说明**：默认情况下，访客只有手柄权限；键盘鼠标默认只有主机主人能用。需要让你操作键鼠的话，主机要在会话中点你的头像手动授予。主机会话中随时可以按 `Ctrl+F1` 批准接入请求、按 `Ctrl+F3` 把所有人踢出。

## 五、连上之后手机怎么操作

- **触屏**：点按等于鼠标点击，可以拖动当鼠标移动；
- **手柄**：蓝牙连一个手柄到手机，进入会话后按任意键即可把手柄接到主机上；兼容性、按键错乱与没反应的排查见[手柄连接与按键排查](手柄连接与按键排查.md)；
- **键鼠**：安卓端对键鼠输入的支持仍在完善中，文字输入、精确操作这类场景体验可能不稳定。

连上之后如果画面卡顿、延迟高，优先检查网络条件是否达到[手机与网络要求](手机与网络要求.md)里的门槛。
