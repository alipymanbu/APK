这篇是这个应用的排查总入口：能自己动手解决的都在表里，表里查不到的再走应用内客服。排查的基本方法是先分清问题出在哪一层 —— 是手机装不上（安装层）、登不进去（账号层）、Steam 账号没绑上（绑定层），还是订单卡住（交易层）。分对层，问题基本就定位了一半。

## 一、安装层：装不上、装完不对

| 现象 | 处理 |
| --- | --- |
| 解析包时出现问题 | 重新下载，确认安装包体积在 48.37M 上下，别在下载中途断开 |
| 应用未安装 | 卸载手机上同包名的旧版后再装 |
| 被安全中心拦下 | 在手机安全设置里放行本次安装，用系统自带安装器装 |
| 装好了但版本不是 3.0.7 | 到「设置 → 应用管理 → SteamPY」核对版本号与包名 `com.steampy.app`；对不上说明拿的是别的包 |
| 想重装但手里没包了 | 到 [SteamPY 安装文件资源（夸克网盘）](https://pan.quark.cn/s/56085e56aa73) 重新转存下载，账号数据在服务端，重装不影响订单与余额 |

更细的安装说明见 [下载与安装教程.md](下载与安装教程.md)。

## 二、账号层：登录与验证码

| 现象 | 处理 |
| --- | --- |
| 收不到短信验证码 | 看短信是否被拦到「通知」分类；60 秒后再点一次；换网络环境重试 |
| 提示手机号已注册 | 直接用验证码登录，不需要重新注册 |
| 提示操作频繁 | 短时间索取次数太多被限流，等一段时间再来 |
| 换了手机号 | 先在应用内完成换绑再处理旧号 |
| App 登得上、网页版登不上 | 两边是同一账号，确认手机号是否输成另一个号；网页版首次登录同样要验证码 |

## 三、绑定层：Steam 绑不上

| 现象 | 处理 |
| --- | --- |
| 一直提示令牌错误 | 检查手机时间是否自动同步 —— 令牌按 30 秒一轮生成，时间偏差大会连续失败 |
| 输入的是邮箱验证码却报错 | 确认账号开的是哪种验证：开了手机令牌就填令牌 App 里的 6 位码 |
| 绑定成功但没看到区域入口 | 退出账号重新登录一次刷新状态 |
| 想换绑但换不了 | 先确认没有在途订单，有订单时换绑会让订单归属错乱 |
| 怀疑账号有风险 | 到 Steam 里检查已授权设备并执行「在所有地方退出登录」，之后改密码 |

绑定细节与安全建议见 [注册登录与绑定Steam账号.md](注册登录与绑定Steam账号.md)。

## 四、交易层：下单与收礼

| 现象 | 处理 |
| --- | --- |
| 支付时提示余额不足 | PY 余额不足以抵扣时，剩余部分会走支付方式；两项都不够就减少金额或换商品 |
| 等了很久没收到好友请求 | 卖家排队属正常；先确认 Steam 端没有把请求忽略掉，超过页面提示的等待时间再走订单申诉 |
| 收礼提示地区不可用 | 关掉代理、VPN、加速器，换网络重试，并确认分区与账号区域一致 |
| 手滑拒收了礼物 | 立即在订单页发起申诉说明情况，不要私下联系卖家 |
| 激活码报「该地区不可用」 | 码的区域与账号区域不一致，属于选错区域，见 [地区与分区怎么选.md](地区与分区怎么选.md) |
| 激活报「已被使用」 | 订单页发起申诉，由平台判定 |
| 激活成功但内容不对 | 保留截图走申诉，不要私下解决 |
| 激活成功的码，过几天游戏从库里消失 | 码被 Steam 回收，保留 Steam 的通知截图走申诉；有用户反馈此类情况报平台后退款到原支付渠道 |
| 收到的礼物角上有红色图标 | 这是受限礼物，打开描述看允许兑换的国家/地区，不含你的区域就先别接收 |
| 挂了单却发不出货 | 多为账号处于 Steam 的交易限制期，对照 [卖家账号限制与发货失败.md](卖家账号限制与发货失败.md) 里的清单自查 |
| 想取消订单 | 发货前在订单详情里找取消入口；已发货的按退款流程走 |

流程本身的先后顺序见 [买游戏与代购流程.md](买游戏与代购流程.md) 与 [CDKey买卖怎么操作.md](CDKey买卖怎么操作.md)。

## 五、提现层：钱没到账

| 现象 | 处理 |
| --- | --- |
| 提现提交后没动静 | 当天 24:00 前提的，第二天 24:00 前到账属正常范围 |
| 过了 24 小时还没到 | 看是否碰上非工作日；个别地区银行会再慢一些 |
| 提现被退回 | 多是姓名与卡号不一致，或开户行填的是支行名，改正后重新发起 |
| 发不起提现 | 手续费 1%（最低 1 元、最高 50 元）会从余额里扣，余额不足就发不出 |
| 提现金额填不了小数 | 只支持整数提取，小数部分可用于平台内支付 |
| 提示需要实名 | 累计提现超过 500 元需要先做实名认证，在个人中心里完成 |

规则细节与计算方式见 [卖余额挂单与提现.md](卖余额挂单与提现.md)。

## 六、体验层：卡、慢、不刷新

| 现象 | 处理 |
| --- | --- |
| 页面加载慢、搜索卡 | 先换网络；高峰期访问量大时会是这种表现，隔几分钟再试 |
| 商品列表不刷新 | 退出重进；或下拉手动刷新 |
| 看不到某款游戏 | 先确认分区是否切对，热门游戏缺货也会显示不出来 |
| 通知收不到 | 到手机设置里确认已给应用通知权限，并关掉对它的省电限制 |

## 七、什么时候该找客服

下面这几种情况别再自己试，直接走应用内的客服 / 申诉入口，并把证据一起带上：

- 订单长时间卡在发货环节；
- 激活码无效或与订单内容不符；
- 提现超过承诺时间仍未到账；
- 怀疑账号被盗用或在平台上遇到疑似欺诈。

**入口在哪**：订单相关的问题从「我的」里的订单入口进去，打开对应订单，在这个订单页内提交申诉；比如已购的 CDKey 就在「我的 → 买家 CDK 订单」里按区域查看。入口的具体名称与位置以应用内当时显示的为准，但有一点是确定的 —— **它一定在应用内部，不会出现在聊天软件里**。

**带什么证据最有用**：订单号、发生时间、提示原文的截图、你在 Steam 端的状态截图。一次性给全，能省掉好几轮来回。

**渠道纪律**：只走应用内的官方入口。任何通过聊天软件主动联系你、自称客服的，都按 [交易安全与防骗.md](交易安全与防骗.md) 里写的那几条处理。
