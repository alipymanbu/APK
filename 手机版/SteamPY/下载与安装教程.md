SteamPY（中文名「匹歪」）是上海部恩科技有限公司开发运营的一个 Steam 游戏交易类安卓应用，包名 `com.steampy.app`。你在里面能做的主要是三件事：买卖玩家之间流转的 CDKey、通过代购（用卖家账号的余额以礼物形式把游戏送给你）低价买游戏、以及围绕 Steam 余额的相关交易。它不是 Valve 的官方应用，交易规则最终仍受 Steam 那一侧约束。本篇按「认识形态 → 核对安装包 → 安装 → 处理报错 → 升级重装」的顺序讲。

## 一、先确认你要装的是手机应用

| 项目 | 说明 |
| --- | --- |
| 应用形态 | 安卓手机应用，没有桌面客户端 |
| 包名 | `com.steampy.app` |
| 官方渠道 | 官网 [www.steampy.com](https://steampy.com) 上同时挂着网页版入口、安卓版与 iOS 版下载；手机浏览器可以直接用它的手机网页版 |
| 与 Steam 的关系 | 第三方交易平台。账号、游戏库、礼物最终都归 Steam，出问题时要分清是平台这一侧还是 Steam 那一侧 |

如果你是在电脑上看到这份文档，注意下载到的仍然是 APK 安装包，需要传到手机上安装；电脑浏览器只能打开它的网页版，功能与 App 不完全一致。

另外，本篇和这份安装包只覆盖安卓。如果你用的是 iPhone，这个 APK 装不上，走官网给的 iOS 入口即可；iOS 上有些操作（比如实名认证）需要借助手机自带浏览器打开它的手机网页版来完成。

## 二、安装前先核对包里这几项

下载之前和下载之后都值得对一遍，确认拿到的是完整的那一份：

| 核对项 | 本资源的值 |
| --- | --- |
| 版本 | 3.0.7 |
| 包名 | `com.steampy.app` |
| 安装包体积 | 48.37M |
| MD5 | `134a72936a6b61e672adc8b75d3a94a6` |

以上四项对应的是网盘里这份包（2026-09-22 核对）。官方商店的版本会更新得比这里快，所以这份不一定是当前最新版，但界面入口与操作路径是一致的，下面的步骤照用即可。

装完之后想确认版本：进手机「设置 → 应用管理 → SteamPY」，能看到版本号与包名，与上表一致就没有拿错包。

## 三、安装步骤

1. 打开 [SteamPY 安装文件资源（夸克网盘）](https://pan.quark.cn/s/56085e56aa73)，先把文件转存到自己的网盘账号，再从自己账号里下载。直接在分享页下载容易因为链接变化导致文件下到一半中断。
2. 把 APK 传到手机。数据线拷、用聊天软件的文件传输助手发给自己都行，记一下存在哪个目录。
3. 在手机上打开「文件管理」，找到这个 APK，点它开始安装。
4. 首次安装会被拦一下，提示「不允许安装未知来源的应用」。点提示里的设置入口，把当前用的文件管理器或浏览器的「安装未知应用」开关打开，返回后继续安装。
5. 装完打开。首次启动要联网，同意隐私政策后进入登录页。

有一个坑要提前说：手机如果装过别的渠道的同包名版本，或者装过更名前的旧版，安装时可能报「应用未安装」。处理方式是先卸载旧版再装这份；卸载前先确认旧版里没有还没看完的 CDK 订单。

## 四、首次打开要的权限，拒绝了会怎样

| 权限 | 用途 | 拒绝之后 |
| --- | --- | --- |
| 存储 / 照片 | 上架出售时上传商品图 | 卖东西时选不了图 |
| 相机 | 拍摄商品图 | 同上 |
| 通知 | 好友请求、订单状态这类时效提醒 | 会漏掉「卖家已向你发出好友请求」，容易卡在这一步 |
| 网络状态 | 判断当前网络是否可用 | 可能误报网络异常 |

只买不卖的话，通知权限最值得给；其余权限不给也能浏览和下单。

## 五、装不上、装完打不开怎么处理

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 解析包时出现问题 | 下载不完整，或传输过程中文件被改动 | 重新从网盘下载，确认体积在 48.37M 上下 |
| 应用未安装 | 同包名的旧版本冲突 | 卸载旧版后重装 |
| 被手机安全中心拦下 | 未知来源限制 | 在安全中心里放行本次安装；通过手机自带的安装器装，别用来路不明的第三方安装器代装 |
| 安装后闪退 | 系统版本偏低或缺基础运行环境 | 先升级系统；仍然闪退就按 [常见问题与排查.md](常见问题与排查.md) 第七节说的方式，把现象与截图交给应用内客服 |
| 一直停在启动页 | 网络不通，或手机时间不准 | 换网络重试，把「日期与时间」设为自动获取 |

## 六、升级与重装

官方会持续更新，版本号形如 `3.0.7`，具体数字以官网或应用商店当时显示的为准。

- 网盘里这份是 3.0.7。包名和签名来源一致的情况下，直接用新包覆盖安装即可，登录态与账号数据都在服务端，不用先卸载。
- 如果新版报「未安装」，说明签名与当前手机上那版不一致，这时才需要先卸载旧版。
- 换手机重装不影响数据：订单、CDKey、余额都跟着账号走，重新登录并重新绑定 Steam 就能看到（绑定相关见 [注册登录与绑定Steam账号.md](注册登录与绑定Steam账号.md)）。
