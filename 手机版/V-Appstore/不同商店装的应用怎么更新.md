# 同一个应用装在不同商店里怎么更新

> 你手机上有几个商店时，同一款应用的更新为什么会失败、该回哪个商店更新、什么时候必须先卸载。

## 一、为什么你会同时看到好几个商店提示「可更新」

手机上装了 V-Appstore、国内应用商店，可能还有 Google Play —— 只要某款应用同时在几个商店上架，**它们看到的是同一个已安装应用**，于是每个都可能提示你有新版。这不是装了三份，桌面上仍只有一个图标。

装在哪个商店，由你第一次安装时的来源决定；之后能不能从别处更新，由安卓的两条硬规则决定。

## 二、安卓接受一次更新的条件

这三条全部满足，系统才允许替换，缺一条就失败：

| 条件 | 说明 |
| --- | --- |
| 应用 ID 相同 | 就是包名，例如 `com.vivo.appstore` |
| 签名证书相同 | 新包的签名必须与已装的那份一致（或有合法的密钥轮换凭证） |
| 版本号不低于已装的 | 看内部的 `versionCode`，不是界面上那个 `7.2.7.2` |

关键点在于：**开发者可以为不同商店发布签名不同的包**。安卓官方文档明确写着，这种情况下各商店之间无法互相更新——想从另一个商店接手，必须**先卸载再装**，而卸载会连应用数据一起清掉。

## 三、更新失败时怎么判断

按这个顺序问自己：

1. **提示「解析错误」「安装包无效」或更新到一半失败** → 大概率签名对不上。回想这一款当初是从哪装的。
2. **不确定当初的来源** → 进 `设置 → 应用与权限 → 应用管理 → 该应用`，看安装来源字段（部分机型在「安装来源」或「高级」里能看到）。
3. **来源能确定** → 回那个来源更新，商店侧的排查步骤见 [下载与更新失败怎么解决.md](下载与更新失败怎么解决.md) 第三节。

## 四、该回哪个商店更新

原则一句话：**当初从哪装的，就回哪更新。**

- 从 V-Appstore 装的 → 回 V-Appstore 更新；
- 从国内商店装的 → 回国内商店更新；
- 从 Google Play 装的 → 回 Google Play 更新；
- 从浏览器手动装的 APK → 一般也得手动再装一次新包，或改从某个商店装（首次装到哪个商店，之后就归它管）。

有用户反馈过这样的现象：几个商店同时提示更新，点了其中一个却安装失败，换回最初的来源就成功。这不是商店坏了，是第二节那三条规则在起作用。

## 五、什么时候必须先卸载

只有两种情况需要走到这一步：

- 你**想把这款应用换到另一个商店管理**，而两边签名不同；
- 应用在新商店里的版本号反而**低于**你已装的（回退），系统不允许降级覆盖。

两种都要先卸载，**卸载会清空该应用的全部本地数据**。动手前先确认里面有需要留的东西：账号能登回来的先记住密码，聊天记录、游戏存档这类本地数据该导出的导出。

## 六、让更新别互相打架的省事做法

- **一个应用只认一个来源**：装过一次就固定用那个商店更新，别的商店弹的更新提示忽略即可（那只是它也在同一份已装应用上检测到了新版本）。
- **关掉自动更新，改手动**：不想半夜被几个商店轮流更新的话，开关位置与触发条件写在 [下载与更新失败怎么解决.md](下载与更新失败怎么解决.md) 第三节附注。
- **同一款应用两边版本号不一致是正常的**：各商店上架节奏不同，见 [海外版和国内版有什么区别.md](海外版和国内版有什么区别.md) 第二节。

如果你遇到的不是「更新失败」而是「装上就闪退」，那是另一类问题，见 [海外应用装不上或闪退怎么办.md](海外应用装不上或闪退怎么办.md)。
