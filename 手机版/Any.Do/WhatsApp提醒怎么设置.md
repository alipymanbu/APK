# Any.do WhatsApp提醒怎么设置

> 本篇讲把 Any.do 的任务提醒接到 WhatsApp 上的开通步骤、聊天机器人的用法，以及中文用户最容易踩的几个限制。

## 一、先确认你用得起

WhatsApp 提醒是**付费功能**，只在 Premium 和 Workspace 两档提供，免费版里这项开关是开不了的。计划差异见 [免费版与付费版区别.md](免费版与付费版区别.md)。

另外一个前提：这条路走的是 WhatsApp Business 通道，个别国家或地区无法接通；国内号码能否收到验证码短信，以实际尝试为准。

## 二、开通步骤

安卓、iOS、网页、电脑端入口一致：

1. 打开 Any.do → **Settings** → **Integrations** → **WhatsApp**；
2. 填你的 WhatsApp 手机号，点发送；
3. 收到 6 位短信验证码，填入确认；
4. 把 **Reminders** 开关打开。

开通后你的 WhatsApp 里会多出一个 Any.do 机器人的会话。

## 三、机器人怎么用

- **建任务**：直接给机器人发消息，比如「remind me to call mom at 6pm」，它会跟你确认时间；
- **转发建任务**：把任何聊天里的消息长按转发给 Any.do 会话，消息内容变成任务，再补个提醒时间即可；
- **处理提醒**：到点后 WhatsApp 会收到提醒消息，直接在消息上点延后（snooze）或完成；
- **关通知**：Settings → Integrations → WhatsApp 里关掉 Reminders 开关即可，机器人会话保留。

通过 WhatsApp 建的所有任务和提醒自动同步回你的 Any.do 账号，其他设备照常可见。

## 四、中文用户要提前知道的限制

| 限制 | 说明 |
| --- | --- |
| 回复只有英文 | 自动识别时间支持包括中文在内的十余种语言，你可以用中文写任务；但机器人的**回复永远是英文** |
| 循环提醒设不了 | 循环规则只能在 Any.do 主应用里设好，WhatsApp 里只能设单次提醒 |
| 只管任务 | 这条通道只处理任务提醒，清单管理回主应用做 |
| 不能拉群 | 机器人只服务你一个人，加不进群聊；想记群里的待办，把消息转发给它 |
| 长期不开会话会停推 | 如果 WhatsApp 里那个机器人会话很久没打开过，提醒可能暂停，直到你重新点开会话或重开一次开关 |

## 五、收不到 WhatsApp 提醒时

1. 确认 Settings → Integrations → WhatsApp 里 Reminders 是开的；
2. 去把与 Any.do 机器人的会话点开看一眼（针对上一节说的停推问题）；
3. 确认任务本身设了提醒时间（在主应用里打开那个任务看 Remind me）；
4. WhatsApp 本身收不到任何消息时，是 WhatsApp 层的问题，不是 Any.do 的。

应用内通知链路的问题与 WhatsApp 无关，单独按 [提醒不响与通知排查.md](提醒不响与通知排查.md) 的顺序查。
