## 一、先核对包信息

LocalSend 是一款免费、开源、无广告的局域网文件传输工具，开发者为 Tien Do Nam，源码在 [github.com/localsend/localsend](https://github.com/localsend/localsend) 公开（Apache-2.0 许可）。你要装的这份安卓包信息如下，**以这份为准**：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.17.0 |
| 包名 | `org.localsend.localsend_app` |
| 大小 | 16.68M |
| MD5 | `7b8894382b151fe1c49c1499d2c101f1` |

两点说明：

- 官网下载页给的是官方最新版（本次整理时已是更高版本），**与网盘里这份不是同一个版本号**；版本号、包名、体积一律以上表为准，要看最新版则去官网 [localsend.org/zh-CN](https://localsend.org/zh-CN) 的下载区，并以页面当时显示为准。
- 安卓端最低系统版本要求以官方下载页当时显示为准；社区资料常见说法是 Android 5.0 及以上。

## 二、下载安装包

打开 [LocalSend 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9c2bc2923fcd)，转存后进入 `LocalSend（先保存再下载）` 文件夹，里面的 `LocalSend_v1.17.0.apk` 即安装包，下载到手机存储任意位置即可。

想确认没拿错文件，可以用任意「查看应用信息」类工具读一下下载到的 apk，比对包名是不是 `org.localsend.localsend_app`、MD5 与上表是否一致；对不上就重新下载一次。

## 三、安装：处理两道系统提示

1. 点开下载好的 `.apk` 开始安装。若提示「不允许安装未知来源应用」，按提示跳转到发起安装的那个应用（浏览器或文件管理器）的安装权限开关，打开后返回再装一次。
2. 部分品牌机会再弹一次风险提醒——这是系统对应用商店之外安装包的通用拦截，不代表包本身有问题。核对过上表的包名与 MD5 后，选择继续安装。
3. 装完打开，应用名就是 LocalSend，界面底部只有「接收 / 发送 / 设置」三个页签。

## 四、首次启动：权限给全，否则搜不到人

LocalSend 靠局域网找到对方，第一次启动会请求几项权限，**全部允许**最省事：

| 权限 | 作用 | 拒绝后的典型表现 |
| --- | --- | --- |
| 附近设备 / Wi-Fi 访问（部分机型叫「位置权限」） | 扫描同一网络里的设备 | 「附近的设备」列表一直空着 |
| 通知 | 接收时弹「是否接收」确认 | 对方发来你这边没动静 |
| 本地网络（仅 iPhone/iPad） | 局域网发现与传输 | iOS 上对方永远搜不到你 |

已经拒过的，到系统「设置 → 应用 → LocalSend → 权限」里补开；iPhone 在「设置」里找到 LocalSend，打开「本地网络」。权限没给全的表现和「搜不到设备」完全一样，排查时先看这里——完整顺序见 [搜不到设备怎么办.md](搜不到设备怎么办.md)。

## 五、界面不是中文时怎么改

打开「设置」页，找到 **Language**（语言）一项，点开后选择「简体中文」，界面立即切换，无需重启。装完第一次用建议先把语言改了，再去做互传。

## 六、另一台设备也得装

LocalSend 只在装了它的设备之间工作，两端缺一不可：

- **另一台安卓手机**：同样用上面网盘里的安装包。
- **Windows / macOS / Linux 电脑、iPhone**：到官网 [localsend.org/zh-CN 的下载页](https://localsend.org/zh-CN/download) 按平台取，各端界面与操作基本一致。

两端都装好、连同一个 Wi-Fi、App 都开着，就可以按 [手机和电脑互传文件教程.md](手机和电脑互传文件教程.md) 传第一个文件了。
