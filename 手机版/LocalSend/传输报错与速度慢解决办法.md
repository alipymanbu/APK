## 一、速度慢：按顺序查这四项

| 检查项 | 动作 |
| --- | --- |
| 频段 | 2.4GHz 换成 5GHz Wi-Fi，近距离差距明显 |
| 位置 | 手机靠近路由器，信号弱时反复重传会拖慢整体速度 |
| 有线 | 电脑接千兆有线最稳，无线掉速时它是备选 |
| 带宽占用 | 传输期间停掉网盘同步、视频下载这类抢带宽的任务 |

另一个立竿见影的办法：**大量小文件先打包成一个压缩包再传**。几百张照片逐个传，每个文件都要走一遍确认与建连；打成一个包后只走一次流程，总耗时通常明显缩短。

## 二、`SocketException: No route to host`

**含义**：网络层根本到不了对方。处理：

1. 确认两端在同一个网络（含「访客网络」陷阱，见 [搜不到设备怎么办.md](搜不到设备怎么办.md) 第一节）。
2. 重启路由器，再两端重开 App。
3. 在「设置」里把服务停止后重新启动；手机端把 App 从后台划掉重开也常有效。

## 三、`SocketException: Connection refused`

**含义**：对方设备在线，但端口没通——基本可以锁定**防火墙**。按 [搜不到设备怎么办.md](搜不到设备怎么办.md) 第三节放行 53317 的 TCP 与 UDP 入站。

需要验证是不是规则问题时，可以临时关闭防火墙测一次：通了就说明确实是拦截规则在起作用，**测完立刻恢复防火墙、改成放行规则**，不要把关防火墙当成长期方案。手机端若只在电脑关防火墙后才通，问题一定在电脑这端。

## 四、`Failed to create server socket`

**含义**：默认端口 53317 被别的程序占用，或与系统的临时端口撞上。处理：

1. 两端把端口改成同一个别的值（如 `53318`，步骤见 [搜不到设备怎么办.md](搜不到设备怎么办.md) 第六节），改完彻底退出重开。
2. Windows 上右键以「管理员身份」运行一次，排除权限因素。
3. 任务管理器里检查有没有残留的旧 LocalSend 进程，有就结束掉再开。

## 五、`Error 500`：报错很模糊时按这份清单过

这个码不指向单一原因，它只说明「建立或处理传输的过程中出了一岔」。以下几条是社区用户反复反馈的触发点，按命中率逐个排：

| 检查 | 动作 |
| --- | --- |
| 接收端保存位置失效 | 目标文件夹被移动、删除或只读时最容易触发——改回系统「下载」目录再试（改法见 [修改保存位置与自动接收设置.md](修改保存位置与自动接收设置.md)） |
| 接收端剩余空间不足 | 留出比文件本身更大的空余再传，空间紧张时大文件常以这种模糊报错失败 |
| 文件名怪异 | 过长、带特殊字符的名字，先改短（如 `test.mp4`）再传 |
| 上一次失败的残留 | 两端把 App 完全退出重开，先发一个小文件试水，再发大的 |
| 两台设备时钟差得离谱 | 校准日期与时间后重试 |
| 只有一个方向失败 | A→B 常失败而 B→A 正常，问题在 B 的接收侧（权限、路径、空间） |

## 六、传到一半 `Finished with error`

大文件更容易在中途断掉，按这个顺序处理：

1. **先稳住手机**：系统「设置 → 省电与电池」里把 LocalSend 的省电策略设为「无限制」、允许自启动——息屏后被系统限网是中断的头号原因；传输期间别锁屏，也让电脑不要进入睡眠。
2. 稳网络：关掉抢带宽的程序，全程别切换 Wi-Fi（连着 5GHz 又跳到热点这类切换都会断）。
3. 直接重试一次。关于重发的行为有两种说法：有资料称会从未完成的部分继续、不必从头再来，也有用户反馈要整个重来——无论哪种，原地重试都是第一步。
4. 仍失败时，把文件改个名（去掉特殊字符与过长名称）再传；整文件夹失败就先挑里面的单个文件试，定位是哪个文件的问题。
5. 两端把 App 完全退出重开，或在设置里重启服务后再试；网络环境的排查见 [搜不到设备怎么办.md](搜不到设备怎么办.md)。

## 七、收不到「是否接收」的弹窗

对方明明发了、你这边没反应，通常是系统在杀后台：

- **安卓**：通知权限给全；系统「电池」设置里把 LocalSend 设为不优化、允许自启动，别让它被后台清掉。
- **iPhone**：打开「后台 App 刷新」，并且不要把 App 从多任务里划掉。
- **一劳永逸**：在自己的网络里开快速保存（自动接收），代价与适用范围见 [修改保存位置与自动接收设置.md](修改保存位置与自动接收设置.md) 第三节。

以上都试过仍异常，回看 [手机和电脑互传文件教程.md](手机和电脑互传文件教程.md) 第一节的三条前提，多数是其中某一条没满足。
