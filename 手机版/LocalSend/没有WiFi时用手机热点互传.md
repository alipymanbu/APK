# LocalSend 没有 WiFi 时用手机热点互传

> 没有路由器、在外面、甚至完全没有外网，照样能传。本篇分清三种离线场景各怎么搭网络、热点直连的四个步骤与三条注意，以及它做不到的事——跨公网。

## 一、先分清：要的是局域网，不是互联网

路由器提供的「上网」和「局域网」是两层东西：LocalSend 只用底下那层。所以外网断了、欠费了、压根没信号，都不影响两台设备互传——只要它们在同一个小网络里。常见场景对号入座：

| 场景 | 怎么组网 | 备注 |
| --- | --- | --- |
| 家里/办公室，宽带断了 | 两端继续连原来的 Wi-Fi，路由器不用断电 | 最省事，什么都没改 |
| 没有路由器（路上、会场、别人家） | 一台开热点，另一台连上 | 见第二节 |
| 公共 Wi-Fi / 办公网搜不到人 | 放弃那个网络，改成热点直连 | 见第三节 |

## 二、热点直连四步

1. 任意一台（通常是手机）在系统设置里打开「个人热点 / 便携式热点」。
2. 另一台把它当成普通 Wi-Fi 连上去。
3. 两端都打开 LocalSend（装法见 [下载与安装教程.md](下载与安装教程.md)）。
4. 照常发送与接收，流程与 [手机和电脑互传文件教程.md](手机和电脑互传文件教程.md) 完全一样。

三条要点：

- **热点不需要有外网**。开热点只是把两台设备接到一起，不是让它们上网——手机停机、套餐用尽，只要热点还能开，文件照样通。
- **这条链路不消耗手机流量**。数据只在两台设备之间走，不经过运营商，传几十 GB 也不会产生流量费。
- **想快一点**：手机热点设置里若有 2.4GHz / 5GHz 选项就选 5GHz；两台设备靠近、中间别隔厚墙。传大文件时让开热点的手机接上充电器。

## 三、公共 Wi-Fi 搜不到人，直接切热点

咖啡厅、公司访客网这类网络普遍开了「客户端隔离」，同一网络里的设备互相看不见，而你多半没有路由器管理权限去关它。热点直连等于自建一个只有你们两台的网络，对方的隔离规则够不着——这是 [搜不到设备怎么办.md](搜不到设备怎么办.md) 里查完权限、防火墙仍无解时的绕行方案。

## 四、它做不到的事：发到另一个城市

LocalSend 只在**同一局域网内**工作。两台设备不在同一个网络里（比如文件在你手机、人在北京同事在上海），就互相看不见，这一点多个第三方教程口径一致：跨城市、跨网络的传输需求应当交给网盘或团队协作工具，而不是 LocalSend。它也没有账号体系，做不到「发给某个指定的人」——对方必须和你站在同一个网络里。
