## 一、工作号和你 App 账号的关系

腾云里的管理员、操作员账号，背后对应的是航信的「系统工作号」——你在航信系统里的业务身份，指令权限、订单归属都挂在它上面。航信官方的用户告知书对工作号的定位是：通过与所属单位签署服务协议来明确服务项目、时限、范围与资费，个人在单位之下申请、绑定使用。

所以一个现实结论是：**个人无法凭空注册一个能出票的工作号**。你是代理人机构的员工，就走单位的开户流程；管理员侧的账号审批与权限分配见 [管理员与权限设置.md](管理员与权限设置.md)。

## 二、申请与入网绑定的要求

按航信官方告知书（依据网络安全法实名制要求）整理，申请工作号并完成入网绑定登记时：

| 事项 | 要求 |
| --- | --- |
| 实名信息 | 如实填写真实姓名，自助查询还需填写证件号码 |
| 联系方式（大陆用户） | 提供用户本人手机号 |
| 联系方式（非大陆用户） | 提供所属公司个人邮箱；给不出的，提供本人有效证件（如港澳居民来往内地通行证、台湾居民来往大陆通行证、外国护照等） |
| 双因素认证 | 密码 + 手机短信或邮件验证码；办理入网绑定即视为同意启用 |
| 信息变更 | 提供的信息发生变更，应在 1 个月内更新 |

拒绝提供上述信息、冒用或伪造信息的，航信有权不批准申请、拒绝办理入网绑定。

## 三、密码与保管责任

这几条是告知书的原文要点，也是账号被封、出纠纷时最常被引用的：

- 入网后**立即修改初始服务密码**，密码须达到必要的复杂度，并被提示定期更换；
- 工作号**不得转借、出租、转售、倒卖或赠与他人**，不得用于非授权业务；
- 因本人原因造成工作号丢失、异常的，需承担相应责任；
- 航信有权对工作号的**最大并发登录 PID 数**进行限制——同一工作号同时能登录多少个终端是有上限的，多设备同时用同一个号撞上限时，表现就是「登录不上」，这一点常被误判为故障。

## 四、账号是怎么生成的（历史口径）

据公开流传的航信培训手册，销售系统用户的创建路径是：用加入申请书上的服务系统账号登录服务系统，在用户管理中选定 office code 后系统自动生成登录名（office code + 三位序号），填姓名和密码后即创建完成。这套流程针对的是桌面时代的销售系统，腾云 App 内的管理员建操作员是更上层的封装；你的单位具体走哪条路，以单位与航信的协议及官方指引为准，拿不准就通过 [共翔助手与报障渠道.md](共翔助手与报障渠道.md) 的渠道确认。

实名与绑定这关过了之后，日常登录的操作细节回到 [登录与账号绑定.md](登录与账号绑定.md)。
