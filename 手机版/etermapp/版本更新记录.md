## 一、先说口径

腾云的版本说明有两个公开来源：苹果 App Store「腾云APP」条目的版本历史，和各安卓市场上架页的更新说明。两边对同一版本号的描述不一定同步，发布日期在各渠道之间也对不上，所以本篇**只列版本号与更新要点、不列日期**；以你打开的官方商店页面当时显示为准。

网盘里这份安装包是 **3.12.7**；官方商店当前已到 3.12.8 及之后。

## 二、3.12.x 系列（你手里这份所在的分支）

| 版本 | 更新要点 |
| --- | --- |
| 3.12.8 | 优化用户体验 |
| **3.12.7（本包）** | 优化用户使用体验；安卓渠道说明为「页面优化」 |
| 3.12.6 | 优化使用体验 |
| 3.12.5 | 使用体验优化；处理已知问题 |
| 3.12.3 | 重置密码优化；处理已知问题 |

3.12.x 整体是打磨期，没有大的功能变化——判断「要不要更新」时，基本不用纠结错过什么。

## 三、3.8.x ~ 3.11.x：功能主要在这几版加的

| 版本 | 更新要点 |
| --- | --- |
| 3.11.2 | 通程资源新增 |
| 3.11.1 | 环球影城辅营供应商接入 |
| 3.11.0 | 更新程序改用中台存储服务；appid 登录 |
| 3.10.0 | 外国人国内航班预订 |
| 3.8.25 | 已知问题修复 |
| 3.8.24 | 优价查询权限处理 |
| 3.8.23 | 统一权限管理；添加、删除账号信息 |
| 3.8.22 | 支持邮箱注册及登录；邮箱用户扫码成为操作员；管理员无配置时可新增操作员 |
| 3.8.12 | iOS 新版本适配 |
| 3.8.8 | PCC 操作员、流量套餐操作员新增流量使用记录 |
| 3.8.7 | 管理员添加自己 |
| 3.8.2 | 新增服务协议；审核中的账号可解绑；分享二维码（PCC 管理员，有效期 6 小时）；身份证验证规则修改；黑屏结构化 |
| 3.8.1 | 新渠道用户可用流量套餐发黑屏指令；新增用户隐私协议 |

其中对日常使用影响最大的是 3.8.22：邮箱注册登录与扫码成为操作员都是从这版开始有的；3.8.23 的统一权限管理对应 [管理员与权限设置.md](管理员与权限设置.md) 里的权限组玩法。

## 四、更早的版本（3.x 早期）

据安卓渠道的历史更新说明：3.6.0 加入海外用户登录，3.5.0 支持繁体与英文切换，3.4.0 加入图片安全验证；后来的更新里还出现过「新增 AV 快捷键」「新增黑屏引导操作」两条——对应 [黑屏指令与订单操作.md](黑屏指令与订单操作.md) 里讲的指令输入辅助。

## 五、怎么用这份记录

- 想「追新」：官方商店已高于 3.12.7，但差异多为体验优化，老版本能正常登录出票就不必强求；
- 想确认某个功能有没有：先在 3.8.x / 3.10~3.11 区间找对应版本，版本低于它就说明你这版没有；
- 3.12.7 之后如果长期无新版本可升，结合 [下载与安装教程.md](下载与安装教程.md) 第二节的 eTerm 下线背景与 [常见问题排查.md](常见问题排查.md) 第五节一起看，别把「没更新」当成「没人管」的唯一信号。
