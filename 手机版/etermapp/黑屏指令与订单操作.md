## 一、先认识三个主要模块

打开 App 后，业务界面围绕三个大模块组织，你接到的每件事基本都能归到其中一个：

| 模块 | 你在这里做什么 |
| --- | --- |
| 行程快递 | 把 PNR 转成旅客能看懂的行程单，分享给客人 |
| 预定中 | 盯还没出票的预订，处理待办任务 |
| 处理中 | 跟进正在走的订单，查状态、做出票后的处理 |

## 二、指令输入：把黑屏装进手机

腾云的定位是「移动版黑屏指令前端」，支持航信系统的完整指令集。如果你在桌面黑屏前干过几年，这套东西对你是零学习成本；如果你是新人，先明确一点——指令是要背的，App 不会替你猜，常用的查询、预订、出票指令和桌面端是同一套。

手机上敲指令比电脑键盘难受，所以 App 在输入上做了这些补偿，都值得配一遍：

- **快捷输入**：常用指令缩写，少敲字；
- **自定义快捷指令**：把你每天敲几十遍的那几条存起来，一键调出；
- **历史指令记录**：翻回去重发，不用凭记忆重敲；
- **AV 快捷键**：查航班最高频，后来的版本给 AV 加了专门的快捷键，还有黑屏引导操作帮你对着界面学（这些能力是哪版加的，见 [版本更新记录.md](版本更新记录.md)）。

## 三、从查询到出票的一条线

日常出一张票的动线大致是：查航班（AV 类指令或界面入口）→ 预订舱位 → 录乘客信息 → 出票。对应到 App 的能力上：

1. **国内外航班查询、预订、出票**是主链路，指令和白屏入口都在；
2. **一键全自动出票**：配置好之后的批量出票动作，适合票量大的时段；
3. **预订 / 出票助理**：全流程订单管理，配合「预定中」「处理中」两个模块盯单。

链路上会反复出现的指令名，先混个脸熟（具体语法以航信官方培训资料和单位内部规范为准）：

| 指令 | 干什么 | 你会怎么碰到它 |
| --- | --- | --- |
| AV | 查询航班时刻与舱位 | 手动敲（如 `AV` + 城市对），或用界面的 AV 快捷键 |
| SD | 预订指定舱位 | 白屏里点选舱位时，后台帮你执行的往往就是它 |
| SHOP | 一次性比价 | 搜索报价类功能自动执行，回显多套报价与对应的退改签规则 |
| NM / CT | 写旅客姓名、联系方式 | 录乘客信息时生成 |
| SSR DOCS / SSR 5QIR | 写证件等补充信息 | 团队名单批量导入时自动生成，省掉逐人手敲 |

具体某条指令怎么写属于航信业务培训的范畴，各家公司内部规范也不一样；App 内的黑屏引导和官方培训资料更适合做这件事，本篇不展开指令语法。

## 四、行程快递与云同步

两个不碰黑屏也用得上、但很省时间的功能：

- **行程快递（移动版）**：生成行程单后支持微信分享，客人不用再等截图或纸质单；桌面端 eTerm 时代的行程快递支持多套模板，手机版走的是同一套思路。
- **订单云同步**：手机和桌面端订单数据云端同步，公司电脑上开到一半的单，路上接着处理；多端登录用同一账号（见 [登录与账号绑定.md](登录与账号绑定.md)）。

## 五、权限不对时的表现

指令发出去没反应、提示无权限，多半不是你敲错了，而是管理员没把对应权限勾进你的权限组——尤其是白屏指令类权限。让管理员对照 [管理员与权限设置.md](管理员与权限设置.md) 检查一遍。其他异常看 [常见问题排查.md](常见问题排查.md)；如果 App 已经装好但业务连不上，先回 [下载与安装教程.md](下载与安装教程.md) 读一遍第二节的时代背景。
