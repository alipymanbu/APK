## 一、改完重启了，ID 还是老的

按顺序查三处，多数到第二步就能解决：

1. **是不是没重启**：改完必须完整重启手机，只是锁屏/清理后台不算。再重启一次看结果。
2. **Root 授权是不是没给**：打开 Root 管理器（如你装的那套），看本应用是否在授权列表里、有没有被设成拒绝。没授权时修改操作会静默失败——补授权后重做一遍「修改 → 重启」。
3. **值是不是真的换过**：改完没立刻看，事后忘了旧值。对比历史记录里上一条的日期与取值，确认这次改动确实记录进去了。

三步都对还是没变，按 [修改设备ID步骤.md](修改设备ID步骤.md) 重新走一遍流程；仍不行可以给官方写反馈——发布页留的联系邮箱是 `amazingmobilelab@gmail.com`（官方在说明里写的是：遇到问题先发邮件，别急着打低分）。

## 二、打开应用没弹 Root 授权请求

没弹窗基本是前置条件缺失，逐项排：

- **设备确实 Root 了吗**：没 Root 的机器不会弹，也用不了修改功能（官方明确要求 Root）。先完成 Root 再开本应用。
- **Root 管理器是不是没装好**：有的 ROM 刷完 Root 但管理器没装、或没给它授予权限，先确认管理器本身能正常弹别人的请求。
- **以前拒绝过**：早先点过「拒绝」可能被记住、不再提示。去 Root 管理器里手动找到本应用，把权限改成允许，再重开应用。
- 授权恢复后，先做一次备份，再开始改（见 [修改设备ID步骤.md](修改设备ID步骤.md) 第三节）。

## 三、快速重启卡在开机动画

先说结论：**这种现象官方 FAQ 本身就写明了，按它的说法手机能正常开机出来，不用怕变砖。**

1. 按住电源键强制重启（部分机型是电源键 + 音量下键长按 10~20 秒），等它正常进入系统；
2. 进去以后，以后改 ID 就**别用应用内的快速重启**了，改完直接长按电源键正常重启——效果一样，还稳；
3. 官方的说法是「下次该功能可能就正常了，不能用就忽略它」。想试可以偶尔再试一次，仍卡就永久放弃这个功能。

进不去系统的情况（反复重启出不来）属于个别定制 ROM 的问题，需要进 Recovery 清缓存或求助刷机——这与本应用的数据无关，手机数据按你平时的 Recovery 操作惯例处理。相关背景见 [修改设备ID步骤.md](修改设备ID步骤.md) 第五节。

## 四、想恢复成原来的ID

- 打开应用 → 恢复功能 → 选中备份过的原始 ID → 确认 → **重启生效**。
- 恢复没反应时，先查 Root 授权（本文第二节），再确认当初**备份过**——没备份就没有可恢复的原值，只能翻历史记录里改动前那一条，手动把它填回去改一次。
- 历史记录也空、也没备份的话，原值就找不回来了；这正是「改之前先备份」的原因。

## 五、改完之后某些应用行为不对劲

改 ID 是对整机生效的：**所有**读取设备标识的应用都会拿到新值，所以个别应用出现「认不出这台设备」「需要重新登录」属预期反应。处理办法：

- 临时排查：用恢复功能把 ID 变回原值、重启，看问题是否消失——消失就说明是 ID 变更引起的；
- 确定要保持新 ID：在那个应用里按它自己的流程重新登录/重新初始化即可；
- 提醒：部分应用的用户协议约束设备标识变更，重要账号（支付、社交等）上做这件事前先看条款，是否继续由你自己权衡。
