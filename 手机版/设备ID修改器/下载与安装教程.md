## 一、这是哪个应用

设备ID修改器（官方名 **Device ID Changer**）是 SilverLab™ 出品的一款免费安卓工具，用来查看和更换设备的 Android ID。你在各处会看到「设备ID修改器」「设备ID更改器」「Device ID」这些叫法，说的都是它——认包名最保险：

| 项目 | 值 |
| --- | --- |
| 官方名称 | Device ID Changer |
| 开发者 | SilverLab™ |
| 包名 | `com.silverlabtm.app.deviceidchanger.free` |
| 资费 | 免费（工具类） |
| 官方渠道 | Google Play 里搜索 Device ID Changer，认准上面这个包名 |

注意别和包名相近的同类工具搞混：市面上还有别的「Device ID Changer」（比如包名 `com.aksym.androiddeviceidchanger`），功能描述雷同但不是同一个应用，安装包也互不通用。

## 二、装之前要满足的两个条件

1. **系统版本**：官方发布页写的兼容范围是 Android 4.1 到 Android 12 及更新版本；v1.1.5 的更新日志进一步写了「支持最新的 Android 版本」。具体到你的机型能不能跑，装上一试最准。
2. **Root 权限**：官方发布页在最前面明确写了「你的设备必须已 Root 才能使用本应用」。也有中文下载站声称它免 Root，但这一说法没有得到官方印证——**以官方口径为准**，先把 Root 备好再装，能省一趟来回。

## 四、安装步骤

1. 手机上打开网盘链接，转存后下载 APK 文件。
2. 若是第一次装 APK，系统会弹「禁止安装未知来源应用」——在设置里允许本次安装（各品牌入口略有差异，一般在「设置 → 安全/安装未知应用」里按来源给权限）。
3. 装完打开应用。**首次运行会弹 Root 授权请求，点允许/授予**——拒绝的话应用内的修改功能用不了，详见 [常见问题与排查.md](常见问题与排查.md)。
4. 授权后再按 [修改设备ID步骤.md](修改设备ID步骤.md) 开始操作。
