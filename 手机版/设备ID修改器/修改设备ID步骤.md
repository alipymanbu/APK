## 一、动手前先知道三件事

- **改之前先备份原始 ID**。应用自带一键备份，改完随时能恢复；不备份就改，回头想找回原值只能指望历史记录里还留着改动前那一条——原值一旦没留底，就回不去了。官方也说明过：设备 ID 通常只在恢复出厂设置时才会自然变化，而恢复出厂会清空手机数据，这个备份功能就是让你不必走到那一步。
- **改完必须重启手机才生效**，别改完就去检查，看不到变化。
- 你需要 **Root 权限**才能用修改功能，首次打开时授权弹窗点允许；前提没就绪先看 [下载与安装教程.md](下载与安装教程.md) 第二节。

## 二、三步改一个设备ID

1. **选目标**：在应用的下拉列表里选中你要改的应用或游戏。v1.1.5 起列表支持按名称搜索、并按字母排序，装的应用多时直接搜更快。
2. **改值**：点修改功能，两种给值方式二选一——
   - **随机**：一键生成一个全新 ID，最省事；
   - **手动**：自己输入一个 ID，想和某台旧设备保持一致时用手动。
3. **重启**：改完点重启（或自己手动重启手机），重启后新 ID 才会生效。

重启完成后回到应用里再看一眼当前值，确认已经变成你设的那个，就算完成了。

## 三、备份与恢复原始ID

- **备份**：在备份功能里把当前（原始）ID 存一份。建议在第一次修改之前就做，做完再动手。
- **恢复**：任何时候打开恢复功能，一键把 ID 变回备份过的原值，然后重启生效。
- 恢复也依赖 Root 授权正常——如果恢复没反应，先按 [常见问题与排查.md](常见问题与排查.md) 第四节「想恢复成原来的ID」排查。

## 四、历史记录：改过的ID都在

你每次改过的 ID 都会存进历史列表，日期一并记录。它的实际用处：

- 想回到之前用过的某个 ID——从历史里选它，不必手动抄下来；
- 忘了现在这台设备用的是哪个 ID——翻历史能看到最近几次的取值与时间。

历史记录是本地数据，跟着应用走；卸载重装会丢，需要留底的 ID 自己另外记一份。

## 五、快速重启功能的注意事项

应用里有「快速重启」，比正常重启快，但**不是所有机器都合适**（官方 FAQ 的说法）：

- **需要 Android 8.0 及以上**，且**取决于你的 ROM**；
- 有些定制 ROM 用它可能卡在开机动画——卡住了别慌，照引导加载程序（bootloader）正常开机即可，手机不会变砖；
- 官方也说了：下次这个功能可能又正常了；如果一直不正常，**忽略这个功能、用手动重启代替**即可，改 ID 的效果不受影响。

嫌麻烦的话，每次改完直接长按电源键正常重启，效果完全一样。若真卡在开机动画出不来，按 [常见问题与排查.md](常见问题与排查.md) 第三节处理。

## 六、改完怎么确认一切正常

| 检查项 | 怎么看 | 不对怎么办 |
| --- | --- | --- |
| 新 ID 已生效 | 重启后回到应用，看当前 ID 是否等于你设的值 | 没变 → 按问题篇第一节排查 |
| 能恢复原值 | 用恢复功能把 ID 变回备份值 | 恢复不了 → 按问题篇第四节排查 |
| 记录留底 | 历史列表里能看到本次改动及日期 | 列表为空 → 确认这次修改真的执行成功了 |

跨应用对不上值不是失败——Android 8 起不同应用读到的 ID 本就可能不同，判据与核对规则见 [为什么各应用读到的ID不一样.md](为什么各应用读到的ID不一样.md)。

改的是你自己这台设备、你自己的 ID，属正常工具用途；同时提醒一句：部分应用的用户协议对设备标识变更有约束，拿它操作别处的账号前先看清对方条款，风险自负。
