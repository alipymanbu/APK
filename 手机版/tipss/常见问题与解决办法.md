## 一、本篇讲什么

装 TiPss、用 TiPss 过程中最常撞上的几类问题，按「现象 → 原因 → 处理」列出。先做最便宜的尝试（重启、清缓存），不行再往下走；安装环节的前置步骤在 [下载与安装教程.md](下载与安装教程.md)。

## 二、安装相关

**提示「禁止安装未知来源应用」或安装包打不开**
- 原因：安卓默认拦截来自应用商店之外的安装。
- 处理：按提示进入 **设置 → 安全/隐私 → 允许安装未知来源**，对发起安装的那个应用（文件管理器/浏览器）放行，重新点开安装。

**安装失败，提示解析错误或文件损坏**
- 原因：下载不完整或文件在传输中损坏。
- 处理：重新下载；下载后核对 MD5 是否为 `9BD8DE300EE13DDE9D8160531C823F80`（方法见安装教程第二节），对不上就重下。

**提示存储空间不足**
- 处理：安装需要略大于 58.00M 的可用空间（安装包 + 解压开销），清出 200M 以上再装。

**安装到一半报「与已有应用冲突」**
- 原因：手机里装过同包名（`com.quk.dspzzsq`）的不同版本，签名不一致会拒装。
- 处理：先卸载旧版本再装；卸载会丢应用内数据，私密相册里的内容请先导出备份。

**系统版本太老装不上**
- 本包标注需安卓 5.2 以上；商店对更新版本的最低要求可能更高（如有商店对 1.20 标注 Android 7.0 以上），以官方页面当时显示为准。系统低于要求时无法安装，只能换设备或升级系统。

## 三、闪退与卡顿

按顺序试，多数问题在前两步就解决：

1. **清后台、重启应用**：上滑清掉全部后台再打开；仍不行就重启手机。
2. **清缓存**：长按应用图标 → 应用信息 → 存储占用 → 清理缓存（「清除数据」会删应用内数据，私密相册等内容先备份）。
3. **检查权限**：设置 → 应用管理 → 找到 TiPss → 应用权限，把存储、相机等被拒的权限打开（各权限的用途见安装教程第五节）。
4. **看存储与发热**：手机剩余空间不足或机身过热时系统会降频，剪辑高分辨率视频最容易触发——清空间、等手机降温再试；导出时也可选低一档分辨率。
5. **换网络**：社区内容、在线曲库、模板素材都要联网，Wi-Fi 和移动数据切换试一下。
6. **升级版本**：商店更新到最新版往往已修掉已知崩溃问题；注意网盘里这份是 1.17，商店可能已有更高版本，装哪个由你决定，但同一时间只留一个版本。

## 四、功能用不了：对症查权限

| 现象 | 多半是缺什么 | 处理 |
| --- | --- | --- |
| 相册里选不到素材、导出视频没保存 | 存储权限被拒 | 应用信息 → 应用权限 → 允许存储 |
| 拍照取色打不开或黑屏 | 相机权限被拒 | 同上，允许相机 |
| 社区/模板/曲库加载转圈 | 网络不通 | 换网络，确认不是飞行模式 |
| 发布作品提示要登录 | 没有账号或掉登录 | 「我的」→ 登录/注册（见安装教程第四节） |

位置与电话权限只服务于广告展示和数据统计，拒掉不影响剪辑与取色，按自己意愿选择即可。

## 五、导出的视频在相册里找不到

导出提示成功、相册里却看不到，按厂商官方支持页给的顺序排查：

1. **最近删除**：相册里翻到「最近删除」，被误删的会在这里保留一段时间，长按恢复。
2. **隐藏/屏蔽相册**：检查相册的「隐藏相册」「已屏蔽相册」开关是否把目标相册藏了。
3. **文件管理器直查**：按来源目录找——相机拍摄在 `DCIM/`，应用导出的多在 `Pictures/` 或应用自己的目录；找到的文件可手动移回常用文件夹。
4. **重新触发媒体扫描**：新导出的视频没出现时，开关一次飞行模式或重启手机，让系统重新扫描媒体库。
5. 还不行就回应用重导一次，并确认存储权限没被中途关掉（见上一节）。

## 六、版本新旧的疑问

网盘里这份是 **1.17（58.00M）**，而应用商店页面在同一时期可能显示 1.19、1.20 等更新版本——都是同一应用（包名 `com.quk.dspzzsq`）的不同版本，安装包大小未必相同（如有的商店页标注 1.18 为 58M、1.19 为 133.12MB）。文档里的功能描述以 1.17 为准；商店新版的实际差异以官方页面当时显示为准。

## 七、能在电脑上用吗

TiPss 是手机应用，官方商店页面提供的方式是用应用宝电脑版：电脑上访问 [sj.qq.com](https://sj.qq.com) 下载安装应用宝电脑版 → 打开后搜索「TiPss短视频创作」→ 点安装，之后从桌面图标启动。它运行的是安卓环境，操作逻辑与手机上一致。
