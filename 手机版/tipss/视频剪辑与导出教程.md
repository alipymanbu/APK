## 一、本篇讲什么

本篇按真实操作顺序过一遍 TiPss 的视频剪辑：怎么把素材导进来、怎么剪、怎么加效果、怎么导出分享。你先把 [下载与安装教程.md](下载与安装教程.md) 里的安装与登录做完，再回来看这篇。应用内还内置了新手教程，界面里遇到没懂的按钮，先看它弹出的引导。

## 二、导入素材

1. 打开 TiPss 进入主界面，选择导入图片或视频素材，进入编辑页。
2. **注意：每次只能导入一份素材**——想做多段拼接，是在编辑页里继续添加片段，而不是一次选中一堆文件。
3. 导入时会请求存储权限，拒绝了就选不到相册内容，处理办法见 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 三、剪辑操作

编辑页里你能用到的核心操作：

| 操作 | 你能做什么 |
| --- | --- |
| 裁剪 | 拖动片段首尾，去掉不要的开头和结尾 |
| 分割 | 在时间线上把一段切成多段，单独删改 |
| 拼接合并 | 多段视频接在一起；也支持跳跃式拍摄的素材按顺序接 |
| 曲线变速 | 调整片段速度曲线，做快慢交替的节奏感 |
| 转场 | 在片段衔接处加过渡效果 |
| 九宫格分割 | 把图片或视频切成九宫格并分别保存 |

剪的时候随时可以实时预览：你改一步，画面立即显示效果，不用反复导出查看。

## 四、加效果：滤镜、特效、贴纸、字幕、音乐

- **滤镜与特效**：一键套用，可按画面色彩和明暗再微调；贴纸、动态贴纸直接拖到画面上。
- **字幕**：给口播或卡点视频加文字，支持手动输入与位置调整。
- **音乐**：从内置曲库选配乐，或导入自己的音频；配合曲线变速可以做卡点。
- **画笔涂鸦**：在画面上直接选色涂鸦，做手写标注或创意效果——取色功能拿到的颜色可以直接在这里用，见 [拍照取色与图片取色怎么用.md](拍照取色与图片取色怎么用.md)。

## 五、模板一键成片

不想逐项调，就用模板：选一个模板 → 按提示选入素材 → 等成片自动生成，你再替换文案或微调片段即可。模板适合零基础快速出片；要精细控制每个镜头，还是回到第三节手动剪。

另外还有**分段拍摄**：边拍边接，打破空间限制，15 秒就能上手一段完整小片。

## 六、导出与分享

1. 剪完点导出，可选分辨率（想要更清晰就选高分辨率，代价是文件更大、导出更慢）。
2. 导出完成的视频保存到手机相册；剪辑过程中重要素材可先存进**私密相册**加密保存，避免误删。
3. 要发到社区或社交平台，走应用内分享入口；发布作品需要已登录账号（见 [下载与安装教程.md](下载与安装教程.md) 第四节）。

导出卡顿或失败，按 [常见问题与解决办法.md](常见问题与解决办法.md) 的排查顺序处理。
