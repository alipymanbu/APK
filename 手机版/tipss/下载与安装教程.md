## 一、这是什么应用

TiPss 是一款安卓手机上的视频创作工具，把视频剪辑、图片编辑和拍照取色、图片取色这类取色功能合在一个应用里：你既能用它裁剪、拼接、加滤镜做短视频，也能用它从照片或实景里提取颜色值做设计参考。适合想在手机上快速出片、又偶尔需要取色配色的人。

本篇只讲**怎么把 1.17 这一版装进手机**；装好后怎么剪辑、怎么取色，见另外两篇。

| 版本号 | 1.17 |
| 包名 | `com.quk.dspzzsq` |
| 安装包大小 | 58.00M |
| MD5 | `9BD8DE300EE13DDE9D8160531C823F80` |

下载完成后，你可以在手机的文件管理器里查看文件属性，或用任意 MD5 校验工具核对上面这串 MD5——对得上才说明文件传输完整、没有下残。

## 三、获取并安装

1. 打开 **TiPss 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/116e49f748ed](https://pan.quark.cn/s/116e49f748ed)，把安装包转存到自己的网盘后下载到手机（或先下到电脑再传到手机）。
2. 确认手机剩余空间大于 58.00M，再点开 `.apk` 文件开始安装。
3. 如果系统提示「禁止安装未知来源应用」，按提示进入 **设置 → 安全/隐私 → 允许安装未知来源的应用**，对当前安装来源（文件管理器或浏览器）放行后重试。
4. 安装完成后打开应用，进入首次运行设置。

不同品牌的手机菜单名略有差异，找不到对应选项时，见 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 四、首次运行：协议、登录与注册

1. 首次打开会先弹出用户协议和隐私政策，勾选已阅读并同意后才能进入主界面。
2. 进入后按提示浏览功能；要发布作品或使用社区功能，需要账号：进「我的」→ 点登录/注册。
3. 没有账号就在登录页点「注册」，按要求填写基本信息提交即可；已有账号直接输入登录。

不登录也能用本地的剪辑与取色功能，账号主要用在作品发布与社区互动上。

## 五、安装时会请求哪些权限

商店页面对该应用的敏感权限说明如下（截至本地采集时的口径，具体以应用内实际弹窗为准）：

| 权限 | 用途说明 |
| --- | --- |
| 存储权限 | 读取相册素材、保存导出的视频与图片，是基础功能所需 |
| 位置权限 | 由广告 SDK 获取，用于不同区域的广告展示 |
| 电话权限 | 由统计 SDK 用于用户数、留存等数据统计 |

剪辑与取色至少需要**存储**权限；如果拒绝，导入素材和保存成品都会失败。逐项处理建议见 [常见问题与解决办法.md](常见问题与解决办法.md)。
