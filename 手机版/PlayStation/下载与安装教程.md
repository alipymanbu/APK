## 二、装之前先看系统门槛

官方两个页面写的最低系统版本并不一致，装之前对一下手机的系统版本：

| 来源 | 安卓最低版本 |
| --- | --- |
| 官方产品页 | Android 8.0 或以上 |
| 官方支持页的功能说明章节 | Android 6.0 或以上 |

以商店页面当时标注的为准。系统版本低于要求时，常见表现是商店直接提示「应用与你的设备不兼容」，或者装好后部分功能不出现。

另外一件事值得先知道：这个应用只有手机和平板版本。官方在常见问题里明确写了没有 PC 版，电脑上要用它只能走网页端，不必去找所谓「电脑版」。

## 三、安装步骤

1. **转存并下载。** 从 [PlayStation 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f9ec553a36b4) 把 APK 转存到自己的网盘，再下载到手机；在电脑上下载的话，用数据线或传输工具拷进手机存储也一样。
2. **允许安装未知来源应用。** 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统常把这项收在「安全」或「隐私」分类下。
3. **点开 APK 安装。** 系统提示「应用未经过安全检测」时选择继续安装，这是第三方来源安装包的常规提示，与包本身是否可靠无关——可靠性靠上一节的包名与 MD5 核对。
4. **覆盖安装的心理准备。** 手机里已经有同包名的版本时，这次安装会直接覆盖它，登录状态通常保留；想干净重来的话先卸载再装。
5. **遇到「应用未安装」。** 多半是手机里那个同包名版本比这份新——安卓不允许用低版本覆盖高版本，先卸载旧版再装。

## 四、第一次打开要过哪几关

启动顺序不复杂，但卡在哪一步的应对方式完全不同，按这个顺序看：

1. **通知权限。** 系统弹窗问通知权限时给上。拒绝也能继续用，只是下载完成、好友消息这类提醒进不了通知栏，App 内「游玩」屏幕的通知列表仍然翻得到。
2. **登录账号。** 用你主机上那个 PlayStation Network 账号登录，内容才对得上。没有账号先在官网创建（[官方账号创建指引](https://www.playstation.com/zh-hans-hk/support/account/create-account/)）；账号的注册区域决定了商店里能看到什么。
3. **处理账号安全验证。** 账号开了两步验证的，这一步要验证码；开了密钥（passkey）登录的，直接走密钥。两种情况卡住的处理办法都写在 [登录与两步验证问题排查.md](登录与两步验证问题排查.md)。

## 五、装完做一次最小验证

不用连主机，先把能验的验掉：

| 看到的现象 | 说明什么 |
| --- | --- |
| 登录后能看到头像、在线好友、奖杯收藏 | 账号与网络通了 |
| PS Store 能正常翻列表 | 账号区域与网络没被挡住 |
| 「设定」里能看到配对主机的入口 | 当前版本没有被判定为过旧 |

要让远程下载、存储管理、游戏截取画面这些功能真正可用，还得把手机关联到主机上，这一步在 [扫码登录PS5与配对主机.md](扫码登录PS5与配对主机.md) 里讲。登录环节报错就先看 [登录与两步验证问题排查.md](登录与两步验证问题排查.md)，装包本身出问题的概率其实更低。以后版本更新或重新获取安装包，同样走 [PlayStation 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f9ec553a36b4)。
