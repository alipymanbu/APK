# 游戏截取画面与奖杯怎么看

> 手机上看 PS5 的截图和短片要满足哪些条件、保留多久，以及奖杯收藏在这里能查到什么。

在手机上翻主机的截图与短片，不用坐到电视前，也不用把文件倒腾到 U 盘。但它有硬性条件——画面来自 PS5 主机，而且图片在云端只放一段有限的时间，过期就没了。奖杯则是另一套逻辑，随时可查，不依赖截图功能。开工前先确认手机已经关联主机（[扫码登录PS5与配对主机.md](扫码登录PS5与配对主机.md)）。

## 一、用之前要满足的四个条件

| 条件 | 说明 |
| --- | --- |
| 主机型号 | 截取画面功能面向 PS5 主机；PS4 不在此功能范围内 |
| 主机状态 | 主机需要处于待机模式，并已启用「与互联网保持连接」 |
| 关联关系 | PS5 主机已链接到 App |
| 地区 | 该功能只在可使用 PS App 的国家/地区提供 |

另外，这项功能要求 App 是新版本：官方说明里写得很直接——受支持地区的 PS5 用户，需要把 App 更新到最新的 iOS 或 Android 版本才有这个入口。版本偏旧就先更新，安装包从 [PlayStation 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f9ec553a36b4) 取，或在官方商店直接更新。

## 二、把自动上传打开

两个地方都能开，任选其一：

- **在 App 里开**：进 **游戏库**，找到 **截取画面**，点 **启用**；
- **在主机上开**：进 **媒体相册**，按弹出的提示启用；或者走 **设定** > **截取画面和播放内容** > **截取画面**，把 **自动上传** 打开。

开完之后，主机上后续产生的截图和短片会自动传到云端，然后才在 App 里出现。

## 三、会上传什么、不会上传什么

不是所有内容都进得来，先看清范围再决定怎么录：

| 内容 | 是否上传 |
| --- | --- |
| 通过创建菜单或「创建」键快捷键截取的屏幕截图 | 上传 |
| 时长不超过 3 分钟的游玩短片 | 上传，且分辨率上限 1920x1080，4K 短片不在范围内 |
| 以更高分辨率保存的短片 | 不上传 |
| 获奖时刻、活动挑战的自动截取画面 | 不上传 |
| 启用此功能之前录好的内容 | 不上传，也不会补传 |

短片会带音频：如果当时开了麦克风或派对语音聊天，声音会一并录进去——分享给别人之前先想一下这一点。

## 四、看、存、发

进 **游戏库** > **截取画面** 就是内容库，每条都能做三件事：

1. **下载**：保存到手机本地（系统会向你要相册/存储权限，这一步不给就存不下来）；
2. **分享到派对**：先选 **分享**，再选要通过 Game Base 送达的派对；
3. **分享到别的应用**：选 **分享** > **分享方法**，用手机上支持的应用发出去。

还有一个绕过自动上传的手动通道：在 PS5 上进入游戏主页，打开 **媒体相册**，选中那条截取画面，按「选项」键，选 **上传至PlayStation App**。补录一两条时比等自动上传更快。

## 五、几个容易踩的坑

- **保留期只有 14 天。** 截取画面在云端保留 14 天，从在主机上创建那一刻算起。想长期留存的，务必在这段时间内下载到手机或主机本地。
- **删主机上的原文件不影响 App。** 只要截取画面功能是开着的，14 天内 App 里仍然看得到。
- **不需要 PS Plus。** 官方 FAQ 明确写了这项功能不要求订阅，内容存放在云端供 App 访问。
- **没有 Wi-Fi 也能用，但费流量。** 下载或转发视频尤其吃流量，出门在外先看一眼手机的流量设置。
- **刚启用时库是空的。** 启用前录的东西不会补进来，别误判为功能坏了。

## 六、奖杯收藏在 App 里能做什么

奖杯不走截图那套流程，联网登录后就能看：

| 能看什么 | 说明 |
| --- | --- |
| 自己的奖杯收藏 | 已获得的奖杯与进度一览 |
| 好友的奖杯收藏 | 对比进度时用 |

官方常见问题里提到一点：查看奖杯收藏时主机需要处于待机模式——主机完全关机离线时，主机侧的奖杯同步信息可能与 App 显示的不同步，显示的会更旧。

想在手机上顺手把战果发给朋友，用 [派对消息与屏幕分享怎么用.md](派对消息与屏幕分享怎么用.md) 里的媒体分享路径即可；想腾出主机空间继续录制，回到 [远程下载与主机存储管理.md](远程下载与主机存储管理.md) 看删除游戏那节。功能入口因为版本偏旧而不出现的话，更新用的安装包同样从 [PlayStation 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f9ec553a36b4) 取。
