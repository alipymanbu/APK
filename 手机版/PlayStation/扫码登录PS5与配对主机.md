# 扫码登录PS5与配对主机

> 讲清手机与主机的两种关系：用 App 扫码替 PS5 登录，以及把主机配对给 App；最后是「看不到主机」的排查顺序。

手机上的 PlayStation 和主机之间有两种关系，别混：一种是「用手机替 PS5 登录」，帮你省一遍在电视上输账号密码的功夫；另一种是「把主机配对给 App」，它才决定你能不能远程下载、清主机存储、看主机截取画面。两个入口都在 App 的「设定」里，前提是手机已经装好并登录（[下载与安装教程.md](下载与安装教程.md)）。

## 一、两件事共同的前提

配对类操作失败，九成不是操作步骤错，而是下面某一条不成立：

| 前提 | 说明 |
| --- | --- |
| 账号一致 | 主机上登录的账号，必须和 App 里登录的是同一个 |
| 网络可达 | 手机与主机都要能连上网；主机侧还要打开「与互联网保持连接」 |
| PS4 需认证 | 配对 PS4 之前，那台机器要先认证为「常用 PS4」 |
| App 版本较新 | 新功能（如游戏截取画面）要通过最新版 App 才有入口；更新用的安装包见 [PlayStation 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f9ec553a36b4) |

账号不一致是最常见的一种：不少人在主机上用主号玩、App 里登了另一个区的号，结果就是主机列表一直空着。

## 二、用 App 扫码替 PS5 登录

1. 在 App 里进 **设定** > **在PS5中登录**；
2. PS5 的登录界面会显示一个二维码；
3. 用 App 扫这个二维码；扫不动时选 **手动输入代码**，把主机屏幕上那串代码敲进 App；
4. 主机侧完成登录，不用再用手柄输账号密码。

这一步只解决「登录主机」，与后面的配对是两回事；扫码成功后主机仍然是未配对状态。

## 三、把主机配对给 App

1. 打开 App，进 **设定** > **将主机与App配对**；
2. 按屏幕提示走完配对。

配对成功后各主机能做的事不一样：

| 主机 | 配对后能做什么 |
| --- | --- |
| PS5 | 远程开始下载、管理主机存储空间、从手机启动 PS5 及兼容的 PS4 游戏 |
| 常用 PS4 | 远程向主机开始下载游戏 |

两台主机能做的事不一样，PS5 侧多出管理主机存储、从手机启动游戏这两项。想让远程下载真正跑起来，还要在主机上开「与互联网保持连接」并让主机处于待机模式，细节见 [远程下载与主机存储管理.md](远程下载与主机存储管理.md)。

## 四、「看不到主机」按这个顺序查

1. **账号对不上。** 回到 App 的账号页确认登录的是主机上那个账号，这是首位原因。
2. **PS4 没做常用认证。** 官方支持页明确写：配对 PS4 前要把它认证为常用 PS4。
3. **主机不在线。** 主机完全关机、断网时，配对与远程操作都做不了；先让主机进待机并保持联网。
4. **App 版本偏旧。** 系统提示更新、或者某个入口干脆不出现时，去更新 App —— 更新用的安装包从 [PlayStation 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f9ec553a36b4) 取，也可以直接从官方商店更新。
5. **配对关系丢了。** 换过主机、改过账号、在主机上做过恢复设置，都可能让原来的配对失效，重新走一遍第三节即可。

## 五、和 PS Remote Play 不是同一个应用

两件事经常被当成一件，这里分开说：

- **配对到 App** 解决的是「管理主机」——下载游戏、删游戏、看截取画面；
- **串流玩主机游戏**要另装 PS Remote Play，这是另一个应用。装了它之后，可以从 PlayStation App 里一键发起 Remote Play 连线，省去在两个应用之间来回切。

只想在手机上看消息、买游戏、清存储的话，装好当前这个 App 就够了。已经是「手机 + 主机」都齐全的状态后，下一步最常用的功能是远程下载，去 [远程下载与主机存储管理.md](远程下载与主机存储管理.md)；如果配对前连账号都登不进去，先解决登录，从 [登录与两步验证问题排查.md](登录与两步验证问题排查.md) 的最前面看起。
