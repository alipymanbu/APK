# 登录与两步验证问题排查

> 登录失败、验证码收不到、密钥登不进去、密码忘了，按现象分头处理；顺带说清两步验证与密钥的设置入口。

登录问题经常被笼统说成「App 登不上」，实际上报错位置不同，处理路径完全不同：有的是 App 版本的事，有的是账号密码，有的是二次验证环节，还有一种是账号没问题但主机没配对。先按现象分层，再对号入座，比从第一步乱试快得多。

## 一、先分清卡在哪一层

| 现象 | 大概率原因 | 去哪一节 |
| --- | --- | --- |
| 打开就要求更新，或某个入口根本不出现 | App 版本偏旧 | 本节末尾的更新办法，安装包见 [PlayStation 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f9ec553a36b4) |
| 账号密码提交后提示密码错误 | 密码或登录 ID 记错 | 第六节 账号找回 |
| 密码对了，但要验证码且一直收不到 | 两步验证环节 | 第二、三节 |
| 提示密钥不能用 | 密钥与设备/浏览器不兼容 | 第四节 |
| 登录成功，但主机列表是空的 | 不是登录问题，是配对问题 | [扫码登录PS5与配对主机.md](扫码登录PS5与配对主机.md) |

版本过旧的典型症状不是报错，而是「少东西」——比如更新日志里提过的新入口在你这里找不到。这种时候先更新包，安装文件从 [PlayStation 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f9ec553a36b4) 取，也可以直接在官方商店更新到最新版。

## 二、验证码一直收不到

官方给的排查动作就四步，按顺序做，别跳着来回试：

1. **点重新发送。** 验证码本身会有几分钟延迟，先在登录界面选重新发送再看手机；
2. **重启手机**，然后再试一次；
3. **检查飞行模式**，有没有被误开着；
4. **看手机信号。** 信号本身有问题时，找运营商确认。

走完这四步还是收不到，就只能走 PlayStation 支持的客服渠道，让别人从后端核对账号状态——这一步没有自助办法。

## 三、备用代码是干什么用的

设置两步验证时官方会让你抄下 **10 个备用代码**，这是手机丢了的应急通道：

| 事项 | 说明 |
| --- | --- |
| 用在哪 | 登录界面选「无法接收验证码?」>「使用备用代码登录」，输入其中一个 |
| 能用几次 | 每个代码只能用一次 |
| 快用完了怎么办 | 关掉两步验证再重新开启，就能拿到一批新的备用代码 |
| 换了手机怎么办 | 用掉一个备用代码登录后，先关掉两步验证，再用新手机重新开启 |

没有备用代码、也拿不到原来那个手机号，就只能联系 PlayStation 支持处理账号访问权限，官方文档里把这种情况归为「需要客服恢复」。

## 四、密钥（passkey）登不进去

密钥是用指纹、面容或设备锁代替密码的登录方式，步骤是：登录账号管理 > **安全** > 启用 **使用密钥登录** > **创建密钥**，然后按屏幕提示完成。它出错通常是设备兼容性，而不是账号坏了：

- **浏览器太旧可能不支持密钥。** 遇到这种情况改用密码登录；
- **某些 Android 与 Windows 设备之间用密钥会出问题。** 在登录界面选 **无法使用密钥登录**，改用邮箱或二维码方式登进去；
- **在 Mac 上用密钥做远程相关操作遇到问题**，官方建议改回密码登录。

想彻底从密钥回到密码：登录账号管理 > **安全** > 关闭 **使用密钥登录** > 创建密码。反过来，手机丢了但另一台设备上注册过同一验证方式，也可以在那台设备上登录账号管理，重新注册一个新密钥。

## 五、两步验证自己怎么开、怎么关

| 操作 | 路径 |
| --- | --- |
| 开启 | 登录账号管理 > **安全** > 两步验证状态旁选 **编辑** > 选验证方法：**验证应用程序** 或 **短信** |
| 绑定方式 | 短信填手机号；验证应用程序则扫二维码，扫码失败就复制那串字母数字代码粘进应用 |
| 激活 | 输入短信或应用里收到的验证码，选 **激活**，然后记下备用代码 |
| 关闭 | 在同一个「安全」页面里关闭两步验证状态 |

方法选择上有取舍：短信依赖手机号能收短信，验证应用程序不依赖运营商但要求设备在手上。两者都能开，换设备时先想清楚哪个更适合长期用。

## 六、密码忘了、登录 ID 忘了

两条都从账号管理页的自助入口走：

1. 打开账号管理登录页，选 **无法登录?** > **找回您的账号**；
2. 输入登录 ID（邮箱地址），等一封带安全链接的邮件，邮件可能要几分钟才到；
3. 点邮件里的安全链接，按提示重设密码——新密码要给大小写字母、数字与特殊字符的组合。

如果邮箱本身进不去、或者连登录 ID 都想不起来，自助流程就走不通了，官方把这些情况也归到需要联系支持的范畴。

登录通了、主机也配对上了，接下来就能用远程下载与消息功能：前者见 [远程下载与主机存储管理.md](远程下载与主机存储管理.md)，后者的日常操作见 [派对消息与屏幕分享怎么用.md](派对消息与屏幕分享怎么用.md)。整个应用的第一装与首次登录，则看 [下载与安装教程.md](下载与安装教程.md)。
