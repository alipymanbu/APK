# 派对消息与屏幕分享怎么用

派对（Party）是把好友临时拉进一个语音与消息空间的功能，手机上的操作和主机上基本一致，只是入口换成 App 的底部导航。常见的用法是先把时间与玩什么说定：人还在地铁上，就能在派对里交代清楚，到家直接开。开工前先确认手机已登录账号并装好这个应用（[下载与安装教程.md](下载与安装教程.md)）；手上还没有包的话，从 [PlayStation 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f9ec553a36b4) 取。

## 一、建一个派对并把人拉进来

1. 点屏幕顶部的 **派对** 图标；
2. 点 **创建新派对**；
3. 选一个或多个玩家，派对就算建好了。

派对既能语音也能发消息，两者互不干扰：只想打字不想说话的话，进去以后不点语音聊天就行。

## 二、能发什么消息

在派对消息界面里可以发四类内容：

| 内容 | 适用场景 |
| --- | --- |
| 文字 | 约时间、说战术这类需要留痕的内容 |
| 贴图 | 快速回应，比打字快 |
| 录音 | 不方便听语音聊天、但想完整说一段话 |
| 图像 | 分享截图这类需要看画面的内容 |

想直接分享主机上的截图或短片，不必先存到手机相册再发——在派对消息界面点 **+** 图标，选 **媒体** > **截取画面** 就能挑一张发出去，前提是截取画面功能已经启用，规则见 [游戏截取画面与奖杯怎么看.md](游戏截取画面与奖杯怎么看.md)。

## 三、语音聊天与派对管理

- **开语音**：从派对菜单里选中那个派对，点 **语音聊天** 图标，就和派对成员连上了。
- **安静某个派对**：选派对名称 > **…更多** > **关闭通知**。关掉之后，该派对或群组会显示静音图标，消息不再打扰你，但你仍然在派对里。
- **清人**：你是派对主人时，选中某个玩家 > **踢出派对**，按屏幕说明确认即可。

消息与语音都走网络，用移动数据时注意流量；想省流量可以看下一节的两项设置。

## 四、看朋友的屏幕（屏幕分享）

屏幕分享的画面来自朋友的 PS5 主机，你在手机上观看：

1. 进 **朋友**，点朋友的在线 ID 打开简介；
2. 选 **请求屏幕分享**，对方接受后你就能看到画面。

两种被动接收的情况不用手动操作：

- 你已经在语音聊天室里，朋友针对这个聊天室在 PS5 上启动屏幕分享，画面会自动开始；
- App 退到后台时，收到屏幕分享通知，点那条通知即可拉起观看。

观看的画质可以在设置里调（见下一节）。屏幕分享是直播形式的画面，不适合用来核对游戏内的细节文字，画面清晰度取决于双方网络。

## 五、把推送通知调成你想要的样子

App 的设定菜单里能分别调整游戏、社交媒体、媒体文件和账号这几类推送，粒度比手机系统层面更细：

| 设置项 | 作用 |
| --- | --- |
| 分类推送开关 | 决定哪类事件进手机通知栏 |
| 自动播放视频 | 控制视频在 App 里自动播放的时机 |
| 移动数据的画质 | 限制部分功能在移动网络下的分辨率，减少流量消耗 |

顺手记住一条兜底逻辑：推送全关掉也不会丢通知——**游玩** 屏幕里有通知列表，下载完成、好友消息这类记录仍能翻到。这也是判断问题出在哪一层的办法：列表里有、通知栏没有，就是推送设置或系统权限的事，跟账号无关。

新版本会陆续增加新的功能入口，某些设置在旧版本里可能找不到对应开关。更新用的安装包从 [PlayStation 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f9ec553a36b4) 取，也可以直接在官方商店里更新。通知栏一直是空的、连登录验证码也收不到的话，先排除账号侧的问题：[登录与两步验证问题排查.md](登录与两步验证问题排查.md)。
