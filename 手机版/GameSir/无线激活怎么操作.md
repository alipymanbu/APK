# 无线激活怎么操作

> V-Touch 模式每次都要先激活映射才能用。本篇按顺序列出无线激活的完整步骤、小米机型的前置设置、以及数据线备用方案和激活会失效的情况。

激活的本质是让系统放行 App 模拟出来的触摸，所以它天然依赖开发者选项、USB 调试这类系统开关 —— 这也决定了重启手机、关掉开发者选项就会把它清掉。本篇把无线激活的完整步骤和最常卡住的几个点写清楚。

## 一、什么时候需要激活

先分清你的情况，别白跑一遍激活流程：

- **走 V-Touch（软件映射）**：需要用激活，因为按键是 App 模拟出来的，得先让系统放行。
- **走 G-Touch（硬件映射）**：支持直连的机型**不需要激活**，配好一次配置就长期有效。

所以第一步是确认自己的手柄能不能用 G-Touch（名单见 [手柄连接与模式怎么选.md](手柄连接与模式怎么选.md)）。能用 G-Touch 就别用激活这条路，省事也少踩坑。另外联发科机型不能用 G-Touch，只能老实用激活。

## 二、无线激活（官方推荐）

整套流程不需要数据线，靠手机的无线调试完成。按下面顺序做，中间不要跳步：

1. **开通知权限**。激活最后一步要靠下拉通知栏输入配对码，通知被拦就做不下去。路径：设置 → 通知管理 → GameSir。
2. **开开发者选项**。设置 → 关于手机 → 连续点**版本号** 6 到 8 下，直到提示「已开启开发者模式」。各品牌入口名称不一样，找不到就搜自己机型的开法。
3. **在 App 里发起激活**。打开 GameSir，连接手柄，点**游戏** → 选一个游戏和**软件映射（V-touch）** → 点**启动** → 点**无线激活** → **确认**。
4. **打开无线调试**。设置 → 开发者选项 → **无线调试**，进入后点**使用配对码配对设备**，记住屏幕上显示的 6 位配对码。
   - 这一步之后**不要返回、不要切到别的 App、不要锁屏**，停留在无线调试页面上。
5. **从通知栏完成配对**。下拉通知栏，在 GameSir 的通知里输入那 6 位配对码，点右侧按钮，稍等片刻会提示激活成功。
6. 成功后会自动跳回 App 并提示映射已开启，这时再启动游戏就能用了。

## 三、小米 MIUI 机型要先改一处设置

MIUI 上按上面第 4、5 步做，最常见的卡点是**通知栏出不来输入框**。原因是通知被折叠成了 MIUI 自己的样式：

- 设置 → 通知管理 → **通知显示设置** → 把通知样式切换为**原生样式**。
- 不改这一项，第 5 步会看不到能输入配对码的通知。

## 四、数据线激活（备用方案）

无线调试在某些机型上会被厂商限制，这时改用电脑激活：

1. 在官方帮助中心的「电脑激活使用说明」页下载 **PC 版激活工具**（工具版本以官方页面当时提供的为准）。
2. 手机上开开发者模式，并打开 **USB 调试**。
3. 机型补充项：**小米**还要同时开「USB 安全设置」，**华为（安卓 7.0 以上）**还要开「仅充电模式下允许 ADB 调试」。
4. 用数据线把手机连到电脑，手机上弹「USB 用于」时选**仅充电**或**传输文件**（不同机型提示不同，个别机型只有选了数据传输才能激活）。
5. 电脑上打开激活工具，手机弹出**允许 USB 调试吗**时勾「一律允许」再点确定，然后在工具里点开始激活。
6. 提示激活成功即可拔线开玩。

## 五、激活器这条路在新版已经去掉

早期的小鸡激活器（A3 / A4）是把小硬件插在手机上完成激活。官方更新日志里写明，**4.4.3 版本起去掉了「小鸡激活器」激活方式**，激活器用户需要下载历史版本才能继续用。也就是说在 5.7.5 这一版里，别照着老教程去找激活器入口，用无线激活或电脑激活。

## 六、激活什么时候会失效

激活不是一劳永逸的，下面几种操作会让它失效，需要重做一遍：

| 你做了什么 | 结果 |
| --- | --- |
| 重启手机 | 映射失效，要重新激活 |
| 关闭开发者选项 | 映射失效 |
| 关掉 USB 调试开关 | 映射失效 |
| 无线激活后一直没重启 | 通常可以一直用 |

这也解释了为什么「上次还好好的，今天进游戏按键就没反应了」多数不是手柄坏了 —— 先回忆一下是不是重启过手机，重新激活一次即可。如果是别的原因，见 [常见问题与排查.md](常见问题与排查.md)。
