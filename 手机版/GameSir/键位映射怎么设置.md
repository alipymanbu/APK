# 键位映射怎么设置

> 手游里的技能键位置各家不同，键位映射就是把这套位置搬到手柄上。本篇讲从悬浮窗进编辑、把按键对到技能上、两个摇杆怎么设、以及怎么保存才不白调。

键位映射不是改游戏，而是在游戏画面上盖一层可拖动的按钮，每个按钮绑一个手柄键。整套设置的关键只有三处：开机模式与启动方式要对上、两个摇杆的模式别选错、改完必须保存到外设 —— 这篇就围绕这三处展开。

## 一、映射在哪一层生效

你不需要改游戏本身，要改的是**游戏画面上那层虚拟按键**。App 在游戏上盖一层可拖动的按钮，每个按钮背后绑一个手柄键，你在手柄上按哪个键，游戏里就等于点了一下屏幕对应位置。所以设置的全过程都发生在「悬浮窗 → 调整键位」这个界面里，前提是悬浮窗权限已经开着（见 [下载与安装教程.md](下载与安装教程.md)）。

## 二、从游戏里的悬浮窗进去

1. 先按 [手柄连接与模式怎么选.md](手柄连接与模式怎么选.md) 把模式选好。
2. 回到 App 的「游戏」页，点你要玩的游戏，选启动方式（G-Touch 或软件映射）后点**启动**。
3. 进游戏后屏幕边缘会有一个悬浮窗，点开它。菜单里通常有四项：**显示/隐藏按键**、**手柄连接状态**、**调整键位**、**常见问题**。
4. 先看「手柄连接状态」确认设备在线，再点**调整键位**进入编辑。

没识别到你的游戏时，去「玩游戏 → 我的游戏」右侧点 **+**，把本地已安装的游戏手动加进去，再加完再启动。

## 三、先试自动匹配，再手动改

进编辑界面后**先别动手拖**：

- App 会根据当前游戏自动匹配一套官方预设键位。多数热门手游都有现成方案，能用就直接关掉编辑界面开玩。
- 匹配不上、或者预设和你的手机分辨率对不齐（表现为按键位置整体偏移），再点**调整键位**手动修。
- 手动修的核心动作只有一个：**把悬浮按钮拖到游戏的技能键上，然后按一下手柄上想绑定的那个键**，绑定就完成了。

## 四、调整键位的几个操作

| 你想做的事 | 怎么做 |
| --- | --- |
| 移动按键 | 直接拖动按钮到技能图标上 |
| 改按键大小 | 拖动按钮边缘的箭头区域 |
| 删掉多余按键 | 点按钮上的方框区域 |
| 位置差一点点对不准 | 用「微调」逐格挪 |
| 想换绑成别的键 | 再按一次目标手柄键重新绑定 |

屏幕分辨率不同的手机，同一套预设会整体偏移，这是正常的，不是 App 出错，手动拖回正确位置即可。

## 五、两个摇杆的模式别设错

这是映射里最容易出错的一处，设错的表现是「摇杆能推但角色不动」或「视角乱转」：

| 摇杆 | 用途 | 必须设为 |
| --- | --- | --- |
| 左摇杆 | 控制角色移动 | 摇杆模式 |
| 右摇杆 | 控制视角滑动 | 滑动模式 |

判断依据是它在游戏里承担什么：**管位移的设摇杆，管视角/镜头的设滑动**。射击类游戏右摇杆就是镜头，设成摇杆模式会让视角不动。

## 六、按键属性和组合键

双击任意一个悬浮按键，会打开这枚按键的属性设置，能做几件事：

- 换按键模式，把一个物理键映射成点按、连发等不同行为。
- 加**组合键**，用来一次按出游戏里的多个键。
- 给瞄准相关的按键开陀螺仪辅助：打开准心图标的属性界面勾选**开启陀螺仪辅助**；再到需要生效的那个按键属性里，点**模式**选中**关联切换陀螺仪**。

## 七、保存这一步不能少

改完不保存，退出编辑就全没了：

1. 全部位置调整完成后，点**保存外设**（G-Touch 模式下这一步是必须的，官方常见问题里明确写了「不保存到外设则游戏中不生效」）。
2. 想留成一套自己的方案，用**另存为**给配置起个名字，之后可以在**我的配置**里直接切换。
3. 调乱了点**重置配置**清空当前这套，重新来。
4. 键位配置会自动进云备份，换手机后登录账号可以同步回来，不用一台一台重设，做法见 [账号登录与云备份.md](账号登录与云备份.md)。

同一款游戏的多套打法、或者多款游戏各自的位置，都是靠「我的配置」分开存的，换游戏时先进悬浮窗切配置，不要指望它自动切换。

## 八、设完不生效，先查这三处

1. **模式是否对得上**：手柄开机用的组合键和游戏启动方式必须一致，B+HOME 开机却用 G-Touch 启动就会没反应。
2. **有没有点保存外设**：G-Touch 模式下漏了这步，游戏里按键就是不动。
3. **悬浮窗权限还在不在**：权限被系统回收或手动关掉后，按键层根本没盖上去。

三处都排除了还是不行，往下看 [常见问题与排查.md](常见问题与排查.md)。
