# 固件升级与手柄校正

> 手柄的固件决定它支持哪些功能，摇杆用久了会漂移。本篇讲固件该怎么升、摇杆怎么校正、按键怎么自测，以及升级后必做的那一步。

固件升级和摇杆校正都属于「出问题之前先做一遍」的事：升级能让手柄的新功能生效，校正能把漂移的摇杆拉回中心。这两件事在 App 里都能完成，只有少数型号（以及接收器）必须连电脑。下面按该不该升、怎么升、怎么校的顺序讲。

## 一、什么时候该升级固件

出现下面任意一种情况，先去把固件升到最新：

- 你的手柄官方刚加了新功能（例如某型号新增支持 G-Touch 直连），需要新固件才能在 App 里看到对应选项。
- 游戏里出现按键偶发失灵、震动不触发、扳机行程不对这类问题。
- 官方更新说明里提到修复了你正在遇到的毛病。

反过来，一切正常就不必追新升级 —— 升级本身有中断风险，没必要为了版本号去升。

## 二、在 App 里升级（推荐）

App 内升级不需要电脑，官方也优先推荐这种方式升级手柄固件（官方对启明星手柄的说明里推荐 App 版本在 5.6.10 以上执行升级）：

1. 手机蓝牙先连上手柄，打开 GameSir。
2. 进入你手柄对应的设备页，找到**固件升级**入口。
3. 页面会显示当前固件版本和最新版本，有新版本就点升级。
4. 升级过程中**不要退出 App、不要关手柄、不要远离手机**，等到进度走完提示成功。

## 三、用电脑升级（App 里升不上去时）

部分型号只提供 PC 升级工具（例如接收器就**只能**连电脑升级）。以官方启明星那套流程为例：

1. 在官方帮助中心对应手柄页，下载**PC 升级工具**和**固件包**（具体包名与版本以官方当页提供的为准）。
2. 解压两份压缩包，打开升级工具里的可执行程序。
3. 点选择文件，选中解压出来的固件包文件。
4. 手柄用数据线连电脑，然后马上按住手柄上的 **M + X + B** 键，直到 HOME 灯熄灭；灯没灭就重复这一步。
5. 点**升级**，等进度条到 100% 并提示成功。

接收器的步骤稍有不同：长按接收器**配对键**再插进电脑 USB 口，约 5 秒后指示灯灭灯即进入升级模式，再执行升级。

## 四、升级之后必做一步

升级完成后，**手机蓝牙里的旧配对信息要取消，重新配对连接一次**。跳过这步常表现为：手柄能开机，但 App 里找不到设备，或者连上后按键错乱。接收器则重新拔插一次。

## 五、摇杆校正

摇杆出现「松手后角色还在自己走」「准心自己漂」时，先校正再考虑送修：

1. 重启手柄。重启过程中**手不要碰摇杆**，否则会把偏移位置当成新的中心点，越校越偏。
2. 打开 GameSir，进入该手柄的固件升级页面，在页面**下方**找到**校正摇杆**，按提示走完。
3. 支持校正扳机的型号（如 G8），同一处也能校正扳机行程。

校正完回到手柄测试页推一遍摇杆，看数值能不能回中，回不去就再校一次。

## 六、按键测试

想确认「是某个键坏了，还是映射没配好」，用手柄测试页最快：

- 逐个按下手柄上的按键，看 App 里对应的键位有没有响应。
- 摇杆各方向推到底，看数值是否到边界、松手是否归零。
- 测试正常但游戏里没反应 → 问题在映射或激活，不在手柄，按 [键位映射怎么设置.md](键位映射怎么设置.md) 检查。
- 测试里某个键就没反应 → 先升级固件，再排查物理故障。

## 七、按键、震动、扳机、灯光的设置

在设备页里可以逐项调手柄本身的行为，跟游戏里的键位映射是两回事：

| 想调什么 | 在哪调 |
| --- | --- |
| 按键功能 / 自定义按键 | 设备页的按键设置 |
| 震动强度 | 设备页的震动设置 |
| 扳机行程、摇杆死区 | 设备页的对应项（支持校正的型号还有扳机校正） |
| 灯光效果 | 设备页的灯光设置 |

其中**自定义按键**要单独说一下：与官方合作的部分游戏里按键是固定死的，按起来别扭时可以用它改一套顺手的。官方说明里标注**目前只支持 G6，且固件版本要在 1.22 及以上**，其他型号能不能用得看你手柄当前的支持情况。
