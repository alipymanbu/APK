GameSir 是小鸡手柄的配套 App，官方中文名「小鸡游戏世界」，开发者是广州小鸡快跑网络科技有限公司。装上它、连上手柄，原本只认触屏的手游也能用手柄玩。本篇解决两件事：网盘里这份包是哪个版本，以及怎么把它装进安卓手机、装完要开哪几个权限。

## 一、安装包信息

下面这几项是**网盘里那份安装包**的实际信息，版本号、包名、体积都以它为准确认：

| 项目 | 内容 |
| --- | --- |
| 应用名 | GameSir（中文名：小鸡游戏世界） |
| 包名 | `com.xiaoji.xtouch` |
| 版本 | 5.7.5 |
| 安装包大小 | 65.68 MB |
| MD5 | `BB53632FA79CA6DD7D5CE52FC92E1843` |

有两点要留意：

- **官方最新版可能比这版更高**。App 内会提示有新版本，但更新与否你自己定；下面讲的功能以官方当前的版本说明为准。
- 安装前可以用任意 MD5 校验工具算一遍下载到的文件，与上表对不上说明文件传输出错，重新下载一次。

## 二、系统要求

- 官方帮助中心在 X2、X3 等手柄的 G-touch 教程里标注的是**安卓系统 9.0 以上**，并要求 App 版本在 4.2.8 以上才支持联发科天玑机型，且推荐天玑 720 以上机型使用 G-touch。
- 不同手柄对系统版本和 App 版本的要求不完全一样，具体以官方帮助中心对应手柄的那一页为准。
- 安装包是 `.apk` 形式，安卓 8.0 以后需要在系统里给「安装未知应用」授权，否则点开安装包会没有任何反应。

## 四、安装步骤

1. 把 `.apk` 下载到手机（浏览器下载的通常落在「下载」目录）。
2. 用文件管理器点开这个 `.apk`。系统弹出「禁止安装未知应用」时，点提示里的**设置**，把当前这个来源（浏览器或文件管理器）的「允许安装未知应用」打开。
3. 回到安装界面点**安装**。安装过程约十几秒，包体 65.68 MB，剩余空间不到 200 MB 的机型先清一下。
4. 装完先别急着开游戏，**打开一次 App**，把下一节的权限给全。

## 五、第一次打开要开的权限

这几项不给，后面会以「功能没反应」的形式出现，很容易误以为装错了：

| 权限 | 为什么需要 | 在哪开 |
| --- | --- | --- |
| 悬浮窗 / 显示在其他应用上层 | 进游戏后调键位、切配置、看手柄连接状态全靠它 | 设置 → 应用管理 → GameSir → 权限 |
| 通知 | 无线激活时要下拉通知栏输入配对码，通知被拦就收不到 | 设置 → 通知管理 → GameSir |
| 应用列表 / 已安装应用 | 自动列出手机里能用手柄启动的游戏 | 首次进「游戏」页时按提示授权 |
| 蓝牙 | 与手柄配对、保持连接 | 首次连接时按提示授权 |
| 后台运行 / 自启动 | 免得玩到一半 App 被系统清掉、悬浮窗跟着消失 | 设置 → 应用管理 → GameSir → 自启动；电池策略设为不优化 |

悬浮窗这项最容易被忽略：很多手机默认关闭，得手动到应用权限里找「悬浮窗」或「在其他应用上层显示」。首次进游戏时 App 会主动弹一次引导，跳过去之后就只能自己进设置里开了。

权限给全之后还有一类问题：权限都对，但 App 被系统的省电策略或游戏加速清掉了，表现为玩几分钟悬浮窗就消失。这类要按机型改系统开关，见 [悬浮窗不显示或后台被杀.md](悬浮窗不显示或后台被杀.md)。

## 六、装完先验证这三步

装好只是起点，按顺序把这三件事做完，才算真能用：

1. **连手柄、选对模式** —— 蓝牙连上之后还要选 G-Touch 还是 V-Touch，选错会出现按键乱跳或触屏和摇杆打架，见 [手柄连接与模式怎么选.md](手柄连接与模式怎么选.md)。
2. **配一套键位** —— 悬浮窗里调按键位置并保存，见 [键位映射怎么设置.md](键位映射怎么设置.md)。
3. **按一遍按键测试** —— 在 App 里逐个按键确认有没有响应，摇杆是否居中，有问题先校正再进游戏。
