# 常见问题与排查

> 按现象自查：连不上手柄、映射不生效、延迟、触屏和摇杆打架、按键位置偏、激活掉线，都在这里找对应条目。

排查之前先分清是哪一段出的问题：手柄与手机的连接、App 里的映射配置、系统侧的激活状态。三段里任一段断了，表现都是「按键没反应」。本篇按现象归类，把常见问题的判断顺序和具体操作逐条写出来，对着自己的现象找即可。

## 一、App 里搜不到、连不上手柄

按顺序排：

1. 确认手柄处于**安卓模式**而非 iOS 模式。模式不对时手机蓝牙能看到设备，App 里却认不到。
2. 确认手柄没有被别的设备占着（平板、另一台手机）。蓝牙一次只服务一个已连接的设备。
3. 手柄关机再开机，**先在手机系统蓝牙列表里连上**，再打开 GameSir 进入设备页连接。
4. 还是连不上就强制清除配对：在开机状态下按组合键进入快闪配对状态，清掉旧信息后重配。

## 二、映射设好了，游戏里却不生效

三个最常见原因，逐条对：

| 检查项 | 正确状态 |
| --- | --- |
| 是否点了保存 | G-Touch 模式下必须点**保存外设** |
| 开机模式与启动方式是否一致 | 手柄开机组合键要和游戏里选的启动方式对应，不能一边 B+HOME 一边 G-Touch |
| 悬浮窗权限是否还在 | 权限被回收后按键层没盖上，重新授权 |

## 三、连上了，但按键异常或没反应

1. 先确认开机模式与游戏启动方式一致（同上）。
2. 到手柄测试页逐个按键验证，确认是不是物理按键的问题，方法见 [固件升级与手柄校正.md](固件升级与手柄校正.md)。
3. 测试正常就重启手机、取消配对后重连一次再进游戏。

## 四、触屏和摇杆不能同时用

表现是推着摇杆走位、手指点一下屏幕，角色立刻停下。分两种情况：

- **iQOO 等 VIVO 合作机型**：先把游戏内的「压感按键」功能关掉，触屏与摇杆就能并用。
- **其他安卓机型**：G-Touch 启动方式下会限制同时操作。可以改走 PC 激活的映射方式启动；或者在应用管理里清除 GameSir 的数据，重启 App 后用激活映射服务启动，并在弹框里选择开启**强化映射**。

另一种更省事的做法是按 [手柄连接与模式怎么选.md](手柄连接与模式怎么选.md) 打开**映射强化**（单手手柄基本都要开）。

## 五、操作有延迟

蓝牙延迟多数来自 Wi-Fi 干扰，按代价从低到高试：

1. 把手机切到 **5G Wi-Fi** 频段，避开与蓝牙打架的 2.4G。
2. 登录路由器后台，把频段带宽改成 20M、信道设为 13。
3. 直接改用手机流量玩一局，判断是不是 Wi-Fi 环境的问题。
4. 重启手机。

## 六、虚拟按键位置对不上

不同分辨率的手机会让预设键位整体偏移，处理办法：

- 隐藏手机屏幕底部的虚拟导航键，把操控方式改成**手势控制**。
- 把 GameSir 设为**全屏显示**（各机型入口不同，一般在「显示」里的第三方应用显示比例处）。
- 手动修正：悬浮窗 → 调整键位，把按钮拖到**实际会触发响应**的位置。注意按钮该放的位置不一定正好对齐技能图标，边放边试。

## 七、摇杆不准、松手还在走

先做摇杆校正：**重启手柄时不要触碰摇杆**，避免把偏移当成新中心点，然后到固件升级页面下方点**校正摇杆**，完整步骤见 [固件升级与手柄校正.md](固件升级与手柄校正.md)。校正无效再考虑硬件老化。

## 八、激活后数据线一拔就断

走电脑激活时遇到这个，逐条排：

1. 换一根数据线。**有些线只能充电不能传数据**，是最常见的原因。
2. 确认开发者选项里的 USB 调试是开着的，手机上弹「允许 USB 调试吗」时要勾选并确定。
3. USB 配置选**仅充电**；部分机型还要额外打开「仅充电模式下允许 ADB 调试」。
4. 换别的 USB 配置模式试试，例如 MIDI。

## 九、闪退，或者想恢复到初始状态

- 到系统设置 → 应用管理 → GameSir → 存储，**清除数据**后重新打开，多数异常状态能恢复（键位配置有云备份，清完登录账号同步回来）。
- 若是激活相关的怪问题，清数据后按 [无线激活怎么操作.md](无线激活怎么操作.md) 从头激活一次，往往比逐个排查快。

## 十、几个容易找不到的小功能

| 想做的事 | 操作 |
| --- | --- |
| 手柄的 L3 / R3 在哪 | 左摇杆垂直按下是 L3，右摇杆垂直按下是 R3 |
| 让屏幕出现鼠标指针 | 同时按下 SELECT + L3，用右摇杆移动、A 键确认；再按一次两者取消 |
| 玩 App 列表里没有的游戏 | 玩游戏 → 我的游戏 → 添加本地游戏，再进游戏拖按键 |
| 射击游戏想要陀螺仪辅助 | 准心图标属性里勾选开启陀螺仪辅助，再到对应按键属性里用「关联切换陀螺仪」 |

## 十一、悬浮窗不出现，或玩一会就消失

这两种现象原因不同：**一直不出现**是「悬浮窗权限」没给，**玩一会才消失**是 App 的后台被系统清掉了。前者在应用权限里把「悬浮窗 / 显示在其他应用上层」打开；后者要开自启动、关电池优化，并按小米、vivo、OPPO、红魔等机型做对应设置，完整清单见 [悬浮窗不显示或后台被杀.md](悬浮窗不显示或后台被杀.md)。
