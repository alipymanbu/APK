# 悬浮窗不显示或后台被杀

> 进游戏调不出悬浮窗、玩一会儿悬浮窗就消失、手柄显示已连接但 App 读不到设备 —— 这类问题多数不是 App 出错，而是系统把它的后台限制住了。本篇按机型列出要改的开关。

悬浮窗能不能显示、和 App 会不会被系统清掉，是两件事：前者由「悬浮窗权限」决定，后者由自启动、电池优化、游戏加速这类系统策略决定。两者缺一个，表现都是「进游戏调不出键位」。下面先分清现象，再按机型改后者。

## 一、先分清你遇到的是哪一种

| 现象 | 大概率原因 | 先做哪件事 |
| --- | --- | --- |
| 进游戏完全没有悬浮窗 | 悬浮窗权限没给 | 到应用权限里开「悬浮窗 / 显示在其他应用上层」 |
| 权限开着，进游戏仍没有 | 被系统的游戏加速 / 游戏工具箱接管 | 把 GameSir 从游戏加速名单里移出去 |
| 一开始有，玩一会就消失 | App 后台被清掉 | 开自启动、关电池优化、在最近任务里锁定 |

第一类的完整检查表在 [下载与安装教程.md](下载与安装教程.md) 的权限那一节；本篇重点讲后两类。

## 二、所有安卓机型都适用的三步

不管什么品牌，先做完这三件事，多数「玩一会儿就消失」能解决：

1. **开自启动**：设置 → 应用管理 → GameSir → 允许**自启动**与**关联启动**。
2. **关电池优化**：把 GameSir 的省电策略设为**不优化 / 允许后台高耗电**。
3. **锁后台**：打开最近任务（多任务）界面，在 GameSir 的卡片上点锁定图标，这样「一键清理」不会把它清掉。

## 三、按品牌的路径

各品牌的菜单名差别很大，下面按目前公开教程里给出的路径整理。菜单位置和叫法会随系统版本变化，找不到就在设置里搜关键词（自启动、耗电、游戏）。

**小米 / 红米**

- 安全中心 → 游戏加速 → 右上角设置 → 把 GameSir 移出加速名单或关掉对它的加速。
- 设置 → 应用设置 → 应用管理 → GameSir → 打开**自启动**；电池省电策略选**无限制**。
- 最近任务里锁定它，避免被清理。

**vivo / iQOO**

- 设置里找到**游戏魔盒 / 游戏工具箱**，对 GameSir 关闭（它的悬浮窗会顶掉 App 自己的）。
- 应用管理 → GameSir → 权限里允许**自启动**、**关联启动**，其余相关权限一并给全。
- 应用管理 → GameSir → 电池 → 后台耗电管理选**允许后台高耗电**。

**OPPO / 一加（ColorOS）**

- 桌面的**游戏中心** → 游戏管理，把 GameSir 从列表里移除。
- 应用管理 → GameSir → 耗电管理：允许后台行为，并把「异常耗电优化」设为**不优化**。
- 允许自启动与关联启动，同时确认它没有被「智能省电 / 闲置应用管理」限制。

**红魔（RedMagic）**

- 设置 → 应用 → GameSir → 电池用量 → 电池优化里，把**自启动、关联启动、后台活动**都设为允许。

## 四、手柄显示已连接，但读不到设备信息

这种情况也常是后台被限制引起的，按上面三步处理后重连一次；仍然读不到，再按 [常见问题与排查.md](常见问题与排查.md) 第一节的顺序排查模式与配对。

## 五、改完还是不行

- 到应用管理里**清除 GameSir 的数据**后重开，把残留的异常状态清掉（键位有云备份，登录账号能同步回来，见 [账号登录与云备份.md](账号登录与云备份.md)）。
- 换一次连接方式再试：本来用蓝牙的改用数据线，或反过来。
- 实在调不出悬浮窗时，先退到桌面确认 GameSir 进程还在（不是被清掉），再重新从 App 里启动游戏。
