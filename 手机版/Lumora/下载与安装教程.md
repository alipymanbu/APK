## 一、先确认手机能不能装

Lumora 是一款 AI 角色聊天应用，安卓端就是一个普通单文件 APK。装之前核对这几项：

| 项目 | 要求 / 数值 |
| --- | --- |
| 系统 | 安卓 5.2 及以上 |
| 安装包大小 | 46.51 MB |
| 包名 | `sopy.ryan.aichat.aichat` |
| 版本号 | 1.2.5 |
| 应用分类 | 通讯社交 |

系统低于安装包要求的老机型装不上，安装器会直接报「解析包时出错」。手机可用空间建议留出安装包大小的 3 倍以上（约 150 MB），空间不足是安卓应用装到一半失败最常见的原因。

2. **iOS 设备**：App Store 搜 `Lumora`，商店里的应用全名是「Lumora - Vibey AI Chats」，开发者显示为 Friendly Ryan；系统要求为 **iOS 15.6 / iPadOS 15.6 及以上**（Mac 需 macOS 12.5 且为 Apple 芯片），美区商店显示包体 89.9 MB、分级 16+ —— 各区大小与是否可搜到**以商店当时显示为准**。安卓端的其他公开分发渠道，目前公开资料里查不到可确认的官方地址，别在来路不明的下载站里随便点「立即下载」。

## 三、安装步骤

1. 把 APK 传到手机（网盘 App 内下载、数据线拷贝、浏览器下载都行）。
2. 用文件管理器点开这个 APK。
3. 系统会拦一次「禁止安装来自此来源的应用」—— 这是安卓对非商店来源的默认保护。点提示里的**设置**，为该文件管理器或浏览器打开「允许安装未知应用」，再返回继续装。
4. 装完先别急着打开，去 `设置 → 应用 → Lumora → 权限` 看一眼：通知权限决定角色会不会主动给你发消息；存储 / 照片权限在发图、存图时才用得上，不想给可以进应用后再授权（这两项给不给的判断依据，见 [隐私与数据权限说明.md](隐私与数据权限说明.md)）。

> 提示：国内部分品牌手机（小米、OPPO、vivo 等）装完还会再弹一次「未经过安全检测」的确认页，点「仍要安装」即可；这类提示只说明包不在该厂商应用商店里，不代表文件有问题。

## 四、登录账号

Lumora 打开后要先进账号才能用。公开资料里给出的登录方式有三种：

- **Google 账号**：安卓机上最顺的一条，装了 Google 服务的手机直接选。
- **Apple 账号**：iOS 端用。
- **游客模式（Guest）**：不绑账号先体验。选它之前想清楚一点 —— 游客身份的数据跟着当前设备走，换手机、清数据之后能不能找回，取决于应用当时给的找回入口，**别把长期在聊的角色只挂在游客身份上**。

另外两条登录相关的边界：

- **年龄**：官方商店页的内容分级是 16+，不满足就不要注册使用。
- **记录存在哪**：多个渠道对它的描述一致 —— 聊天记录走「本地加密 + 云端二次加密」，具体口径以官方隐私政策为准。可以确定的是：**用同一个账号登录，你换设备后接着聊才成立**。
