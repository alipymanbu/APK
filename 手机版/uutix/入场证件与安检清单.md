## 一、先确认你的场次是不是实名入场

不是每场演出都查证件。实名入场（入场时核对姓名与证件号）通常出现在粉丝向、高需求场次，主办方会在购票规则与演出公告里写明「入场实名验证」字样：

- 实名场次：购票时填写的证件信息会印在电子票上，入场时人、票、证三者核对，**填错基本等于废票**；
- 非实名场次：出示电子票扫码即可，一般不核对证件。

下单前在演出详情页找「购票须知 / 入场安排」确认属于哪一种，这决定了你购票时填什么、出门带什么。

## 二、实名入场要带的证件

以香港亚洲国际博览馆官网多个演出公布的入场安排为例，通行口径如下（**具体以你那场演出的公告为准**）：

| 观众身份 | 要求出示的证件 |
| --- | --- |
| 香港 / 澳门观众 | 本地身份证件正本 |
| 内地观众 | 往来港澳通行证正本（含有效签注） |
| 经海外入境香港的观众 | 护照正本（须与购票登记用的同一本） |

通用规则，违反任何一条都可能被拒绝入场且不退款：

1. 必须是**实体证件正本**——复印件、照片、截图、网银登录页面、学生证一律不认；
2. 证件上要有可辨认的本人照片，工作人员判断照片与本人落差过大时有权拒绝入场；
3. 证件上的姓名与证件号码要与电子票上登记的完全一致；
4. 经海外入境者的护照若在购票后更换，新护照通常不被接受核对；
5. 实名制票券不得转让给第三方——这也是 [电子票入场与转票.md](电子票入场与转票.md) 里「转票前先查规则」的原因。

## 三、内地观众购票时的对应动作

- **购票时就用将来带去现场的证件**：填证件信息时填往来港澳通行证号码，不要顺手填身份证或护照——核对只认购票登记的那一列；
- **先确认证件状态**：通行证没办、过期或签注用完的，先把证件与签注办好再购票，否则票到手也进不去；
- **名字有生僻字**：电子票上显示问号或乱码时不用慌，多数场次允许现场工作人员人工核对确认后入场，实在不放心先问主办方；
- **同行人各自购票**：实名按人头核对，一票一人，帮朋友买票要填朋友本人的证件信息。

## 四、安检与禁带物品

香港演出场馆的常见口径（各场馆、各场次松紧不同，以当日公告为准）：

| 类别 | 常见规定 |
| --- | --- |
| 随身包 | 鼓励不带包；超过 38×30×20 厘米的包通常禁止带入，无包观众常可走特快通道 |
| 摄影器材 | 专业相机、摄影录音器材禁入；演出中禁止拍照录像，平板也不许用来拍摄 |
| 其他常见禁物 | 长柄伞、自拍杆、折叠凳、外来食品饮料、玻璃瓶、气球、喷雾与利器 |
| 安检流程 | 入场前过金属探测器、接受开包检查 |
| 再入场 | 扫码进场后离场，一般不得凭原票再次进入 |

赴港观众的实际建议：空手或带一个小包（证件、充电宝、手机），装得下就别背大包——省掉寄存排队，安检也快。

## 五、站票（企位）观众额外注意

买的是站票而非座位票时，规则再加一层：

1. 站票按**票面序号**排队入场，序号由下单完成先后自动分配，越早付款序号越靠前；
2. 场馆通常提前数小时开放等候区，按序号分区排队，**迟到过号后你的序号作废**、要排到最后；
3. 站票常有身高或年龄门槛（如未满一定年龄不可入场），带小孩的观众购票前核对公告。

抢站票拼的就是下单速度，准备事项见 [会员预售与抢票攻略.md](会员预售与抢票攻略.md)；入场当天怎么调出电子票，见 [电子票入场与转票.md](电子票入场与转票.md)。
