## 一、创建前先想清楚三件事

Glow 的智能体 = 人设 + 形象 + 声音 + 话题。创建前先决定：

1. **TA 是谁**：性别、性格、职业、背景故事 —— 这些直接决定 TA 聊起来像谁；
2. **TA 怎么说话**：声音设定选哪种音色（有的音色可能涉及会员权益，以应用内实际展示为准）；
3. **给不给别人看**：公开后其他用户能搜到并使用，私密则只有你自己可见。

人设写得越具体（身份、说话习惯、与你的关系），聊起来越不容易出戏。几条用户实测好用的写法：

- **开场白**按「场景 + 你的态度 + 要说的话」写，一条就够 —— 开头堆太多信息，智能体反而抓不住重点；
- 性格别只写一个词（如「活泼」），加一句它的具体表现（如「对熟人话多，对陌生人客气」），否则它会自由发挥；
- 有阶级设定的角色（医生/患者、皇帝/臣子）把**互相的称呼**在开场白里定死，不然聊两句称呼就乱了；
- 声音在创建时选定，创建后想换音色需要重建或在设置里找声音选项（以应用内实际功能为准）。

## 二、创建步骤

创建入口有两条：**发现智能体页的【创建智能体】按钮**，或**首页右上角的【+】**里选创建。流程如下（不同版本界面略有差异，以你装的版本实际显示为准）：

1. 点开创建入口，填写基础信息：昵称、性别、性格/职业、设定描述（背景故事）等；
2. 点下一步，确认一遍已填的信息（这步还能改）；
3. 选择角色**形象**（用滤镜风格 + 形象描述生成，有的版本支持传参考图）；
4. 选择角色**声音**并确认；
5. 点 **【生成智能体】**，创建完成，直接就能开聊。

不想被别人搜到：在创建页面**关闭「公开该智能体」**（私密智能体）。创建完成后直接就能开聊；想先看看别人做的角色长什么样再动手，见 [搜索别人的智能体.md](搜索别人的智能体.md)。

### 填写上限与数量限制

有用户整理的限制如下（以应用内实际提示为准）：

| 项目 | 上限 |
| --- | --- |
| 智能体昵称 | 7 个汉字 |
| 参考名人 | 7 个汉字 |
| 设定描述 | 150 个汉字 |
| 头像描述 | 100 个汉字 |
| 一个账号可创建的智能体 | 5 个 |

字数紧就优先写三样：**性格、说话方式、TA 对你的态度** —— 这三项直接决定聊天体验，头像描述可以往后放。

## 三、羁绊设置：让 TA 用你想要的方式称呼你

「羁绊」是智能体对你的**专属称谓**和你对 TA 的补充设定，只对你自己生效（别人用同一个智能体看不到也用不了）：

- 入口：**智能体详情页 → 编辑「我和智能体的羁绊」**（仅自己可见）；
- 你可以写 TA 叫你什么（比如名字、称呼），再补一句你俩关系的设定；
- 改完之后，TA 在对话里会按这个称谓叫你。

## 四、关联话题：给对话定个方向

每个智能体可以关联**最多 10 个话题**（话题会影响对话走向，比如让 TA 主动聊某个方向）：

- 在智能体设置里添加/管理话题；
- 想取消某个关联：**设置 → 智能体 → 话题列表 → 找到该话题点删除**；
- 想回到不分类的自由聊天：**我的 → 设置 → 话题 → 选「无话题」**，之后新话题可以创建但不分类。

聊久了角色跑偏需要重置、或想彻底删掉重来，处理方法见 [重启删除智能体与聊天记录.md](重启删除智能体与聊天记录.md)；一段剧情想留档，先存进 [记忆簿怎么创建和回溯.md](记忆簿怎么创建和回溯.md)；还没装应用则先看 [下载与安装教程.md](下载与安装教程.md)。
