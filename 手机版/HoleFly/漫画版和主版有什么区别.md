# HoleFly 漫画版和主版有什么区别

## 一、先给结论

搜 HoleFly 会冒出「HoleFly」「HoleFly 漫画版」「HoleFly Windows」好几个名字，它们**不是同一个安装包**：

| 名字 | 是什么 | 包名 |
| --- | --- | --- |
| HoleFly（主版） | 安卓追剧应用，影视为主 | `com.holefly` |
| HoleFly 漫画版 | 独立的漫画阅读应用 | `com.holecomic` |
| HoleFly Windows | 官网提供的电脑版入口 | 不适用 |

包名是安卓区分应用的唯一依据——`com.holefly` 与 `com.holecomic` 不同，手机会把它们当成两个应用，**可以同时装、互不覆盖**。本页网盘里那份是**主版 8.0.11**，包名 `com.holefly`，核对方法见 [下载与安装教程.md](下载与安装教程.md) 第二节。

**漫画版后来改了名字**：有第三方下载页注明漫画版在一次升级后更名为 HoleManga。这条不是官方公告，不同页面写法也不完全一致，你装到的叫什么，以安装包与官方页面当时显示为准。

## 二、主版里明明有漫画，还要装漫画版吗

主版（8.0.11）的首页里带漫画版块，日常翻一翻是够的。漫画版是**单独为阅读做的应用**：横竖滚动、缩放、自动翻页、离线下载、夜间模式这类阅读设置，在漫画版里是独立做过的；主版的漫画版块更像入口，阅读设置没那么细。

怎么选：

- **只想偶尔看几话** → 装主版就够了，不用多装一个；
- **把漫画当主力、在意阅读设置与离线** → 再装漫画版，两个应用各看各的；
- 只装了漫画版却想找电影电视剧 → 那不在它里面，装主版或看 [下载与安装教程.md](下载与安装教程.md)。

## 三、在哪拿这几个版本

- **主版（本页对应那份）**：[HoleFly 安装文件资源（夸克网盘）](https://pan.quark.cn/s/01aa2ea12631)，参数与安装步骤见 [下载与安装教程.md](下载与安装教程.md)。
- **漫画版 / Windows 版**：HOLE 系列的官方页面 [www.holesfly.xyz](https://www.holesfly.xyz) 上分三个入口提供下载（HoleFly、HoleFly 漫画版、HoleFly Windows），页面结构与入口文案以当时显示为准。

## 四、怎么确认手机上装的是哪个

到手机的**设置 → 应用管理**里点开应用名，看「版本号 / 包名」这类信息：

- 包名 `com.holefly` → 主版；
- 包名 `com.holecomic` → 漫画版（或其更名后的版本）；
- 应用列表里**两个都在** → 属正常，它们本来就能共存。

在应用内也能大致区分：主版进来是影视版块与播放页，漫画版进来直接是漫画推荐与书架。装错了包、或者漫画怎么都搜不到，按 [常见问题与解决办法.md](常见问题与解决办法.md) 第一、二节排查。
