## 一、先接受一个前提

免 root、走无线调试的 Shizuku 有两条先天限制，官方手册写得很直白：

1. **每次重启手机都要重新启动一次服务**——这是安卓系统限制，配对不用重做，但「启动」这下省不掉；
2. **服务可能被系统杀掉**——安卓会为省电、省内存清理后台进程，Shizuku 也不例外。

两边口径其实一致：有用户反馈服务「跑几分钟就停」（即便已设电池不限制），官方与社区的通行做法都是「掉了就再启动」，配合下面的设置把频率降下来。root 用户不受此困——直接 root 方式启动，还能设开机自启。

## 二、把服务稳住的设置清单

按顺序过一遍，每条都能独立生效（菜单名各品牌略有差异，以你手机上显示的为准）：

| 在哪里改 | 改成什么 | 作用 |
| --- | --- | --- |
| 设置 → 应用 → Shizuku → 电池 | **不限制 / 不优化** | 避免系统以省电为由杀它 |
| 最近任务里长按 Shizuku 卡片 | **加锁（锁定）** | 一键清后台时不会把它清掉 |
| 设置 → 应用 → Shizuku | 允许**后台运行 / 自启动**（有这两项的品牌） | 部分厂商默认禁止后台联网与自启 |
| 开发者选项 | **停用 adb 授权超时**（Android 11+） | 长期不用后不必重新授权 |
| 开发者选项 → 默认 USB 配置 | **不进行数据传输** | 官方手册建议，防止 USB 模式变化打断服务 |
| 开发者选项 | **不要关闭「USB 调试」和「开发者选项」** | 关了服务必死 |

另外：搜配对服务、启动服务都要访问本地网络，不少品牌在应用切到后台后立刻禁网——所以「允许 Shizuku 在后台运行」这一步在配对卡住时也用得上，见 [Shizuku无线调试配对激活.md](Shizuku无线调试配对激活.md)。

## 三、掉了之后怎么最快拉起来

按成本从低到高：

1. **服务中途掉**：打开 Shizuku 点**启动**。起不来就进「无线调试」把开关关掉再打开，回 Shizuku 重试（官方手册给的就是这招）。
2. **重启过手机**：不用重新配对——进无线调试页面，回 Shizuku 点启动即可；想跳过这步就确认「停用 adb 授权超时」开着。
3. **手边有电脑**：官方的启动命令可以直接重跑，不用碰手机界面：

```sh
adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
```

4. **root 设备**：在 Shizuku 设置里打开「开机自启（root）」，一劳永逸。

每次服务恢复后，ShizukuRunner 不用重新授权——授权是跟着配对走的，掉的只是服务本身。恢复没反应就回 [常见问题与排查.md](常见问题与排查.md) 查整条链路；日常跑命令的用法在 [常用命令与代码合集.md](常用命令与代码合集.md)。

## 四、还是频繁掉怎么办

把第二节的清单全做了仍几分钟一停，说明这台机器的后台策略极狠（部分品牌对非白名单应用就是这个力度）。两条现实的路：

- **接受现状**：把「启动」练成肌肉记忆，掉了一点就好，免 root 的日常就是这样；
- **换 root 路线**：root 方式启动天然不怕后台清理，但 root 的代价（解锁、保修、支付环境）要自己权衡，这里不展开。

社区里还有用 Tasker 之类自动化工具定时拉起 Shizuku 的做法，属于进阶折腾，新手不必上手就搞。
