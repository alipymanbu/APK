## 一、先搞清楚命令怎么填

网上搜到的命令几乎都长这样：`adb shell wm density 420`。在 ShizukuRunner 里**要去掉 `adb shell` 前缀**，只填后面的 `wm density 420`——Runner 本身就是替你发 shell 的那一层，带着前缀反而会报错。

填法：进 Runner 点「更改命令」，把命令写进格子，点右侧的 `>` 运行。没有红色提示就是执行成功了；有红色提示先回 [Shizuku无线调试配对激活.md](Shizuku无线调试配对激活.md) 确认 Shizuku 激活、Runner 已授权，再检查命令本身有没有拼错。命令可以保存成带标题的卡片，管理方式见 [自定义命令与界面设置.md](自定义命令与界面设置.md)。

下面命令按用途分组。**不同品牌同一需求的命令常不一样**，拿不准就先查当前值（`get` 类命令），改完记下原值以便恢复。

## 二、屏幕与显示

| 想做什么 | 查看当前值 | 修改 | 恢复默认 |
| --- | --- | --- | --- |
| 改屏幕密度（dpi） | `wm density` | `wm density 420`（数值按需改） | `wm density reset` |
| 改分辨率 | `wm size` | `wm size 1080x2400` | `wm size reset` |

改 dpi 前先用 `wm density` 记下原始值。数值改得太激进可能让界面挤成一团、按钮点不到，恢复手段见 [常见问题与排查.md](常见问题与排查.md)。

## 三、动画速度

把三个动画缩放都调小，界面切换会明显变快；嫌手机动画慢吞吞就用它：

```sh
settings put global window_animation_scale 0.5
settings put global transition_animation_scale 0.5
settings put global animator_duration_scale 0.5
```

`0.5` 是半速（更快），`1` 是系统默认，想要「秒开」的观感可以试 `0.5` 以下的值。恢复：

```sh
settings put global window_animation_scale 1
settings put global transition_animation_scale 1
settings put global animator_duration_scale 1
```

这组命令是 AOSP 通用的，绝大多数品牌都认。

## 四、刷新率（品牌相关示例）

部分品牌可以用 settings 键直接锁刷新率，例如 vivo/OriginOS 锁 90Hz：

```sh
settings put global vivo_screen_refresh_rate_mode 90
```

没有红色提示即生效；恢复时在系统设置里把刷新率切走再切回（OriginOS 可在变形器里直接恢复）。**这是 vivo 系的键，别的品牌不一定认**——换品牌前先搜「品牌名 + 刷新率 + adb 命令」确认键名，别照抄。

## 五、设备名称

很多手机在设置里改「设备名称」只会改蓝牙/热点名，系统真正的 `device_name` 没变。想改到位分两步：

```sh
settings put global phone_name_verify_switch false
settings put global device_name "你的新名字"
```

第一条关闭改名验证（部分品牌才有这个开关），第二条才是真正写入。改完在路由器后台、文件管理器里看到的就是新名字了。

## 六、应用管理

| 想做什么 | 命令 |
| --- | --- |
| 列出第三方应用 | `pm list packages -3` |
| 卸载某个应用 | `pm uninstall 包名` |
| 卸载系统应用（对当前用户） | `pm uninstall --user 0 包名` |
| 恢复刚卸载的系统应用 | `pm install-existing 包名` |
| 清除某应用数据 | `pm clear 包名` |

**系统应用卸载不可乱来**：桌面、系统界面这类被卸了可能直接黑屏进不去系统。动手前确认包名，优先用 `pm uninstall --user 0`（只对当前用户隐藏，`pm install-existing` 还能救回来），别碰拿不准的包。执行后无红色提示即成功，用 `pm list packages` 复查。

## 七、日常小设置（亮度 / 休眠 / 常亮）

```sh
settings get system screen_brightness
settings put system screen_brightness 150
```

亮度取值 0~255，先 `get` 看当前值再微调；设太低会看不清屏幕，留个余量。

```sh
settings put system screen_off_timeout 600000
```

自动锁屏时长，单位毫秒——`600000` 是 10 分钟，想让它久一点就调大。查当前值把 `put` 换成 `get`。

```sh
svc power stayon true
```

插着数据线/充电时屏幕保持常亮（调试、看教程时省得老是解锁），不需要了就跑 `svc power stayon false`。

## 八、执行结果怎么读

- **没有红色提示** = 命令跑完了（`settings put` 这类成功时本来就没输出）。
- **有红色提示** = 命令没执行或参数错，看提示里的报错对照 [常见问题与排查.md](常见问题与排查.md)。
- 输出特别长的命令（比如 `logcat`）会被 Runner 主动掐断，返回值 141，属正常保护，原因在问题篇讲清楚了。
