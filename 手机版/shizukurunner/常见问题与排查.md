## 一、点运行完全没反应

八成是 Shizuku 那条链路没通，按顺序查三处：

1. Shizuku 首页是否显示**正在运行**？没运行就按 [Shizuku无线调试配对激活.md](Shizuku无线调试配对激活.md) 重新启动（重启手机后服务会掉，属于正常现象，重新点启动即可）。
2. Shizuku 的「已授权应用」里，ShizukuRunner 的**开关开了没**？
3. ShizukuRunner 是否还在**禁止执行状态**——v17 起 Shizuku 未激活时直接不许执行命令，激活前点了就是白点。

三处都正常还不行：关掉无线调试再重新打开，回 Shizuku 点一次启动。

## 二、命令有红色提示

红字 = 命令没跑成，常见三类原因：

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 提示找不到命令 / syntax 错 | 把 `adb shell` 前缀也抄进去了，或拼写错 | 去掉前缀只留命令本体，再核对一遍 |
| 提示权限拒绝 | Shizuku 授权没给，或命令需要 root 而当前是 shell | 去 Shizuku 开授权；确需 root 就用 root 方式启动，并视情况关掉「降权至 shell 身份执行」 |
| 命令执行了但没效果 | 品牌不认这个键 | 该品牌可能改了键名，先用 `settings get` 查真实键值再改，别照抄别家命令 |

执行成功但没有任何输出是正常的——`settings put` 这类命令本来就静默完成。

## 三、返回值 141 / 输出被掐断

命令输出**超过 1000 个字符**时，ShizukuRunner 会强行关闭输出管道并终止命令，返回值 **141**。这不是故障：不掐断的话 APP 会被海量输出卡死（`logcat` 就是典型）。

处理办法：想看长输出的命令，改成把输出重定向到文件再去看文件；只关心结果的命令，加个过滤条件把输出缩短。

## 四、命令停不下来，手机变卡

别在 Runner 里执行 `logcat 2&1 >/sdcard/1.txt` 这类**无穷无尽、又没有输出**的命令：Shizuku 通道下收不到终端控制码，Runner 停不掉它的进程，它会一直跑到你关机。真踩到了直接重启手机解决，之后别再跑这类命令。

同理，长时间刷屏的命令要么加过滤、要么重定向到文件，别裸跑。

## 五、配对阶段的坑（MIUI/HyperOS 为主）

- **通知栏里填不了配对码**：通知样式不对。设置 → 通知与控制中心 → 通知显示设置 → 改成**原生样式**再试。
- **一直提示无法正常工作**：开发者选项里打开**禁止权限监控**，回 Shizuku 重新启动。
- **点「输入配对码」立刻失败**：确认手机连着 Wi-Fi、无线调试确实开着；再重新点一次「使用配对码配对设备」拿新码——配对码有时效，过期的码填了必失败。
- **离开无线调试页面配对就断**：配对过程要停在那个页面完成；能分屏的机型建议分屏操作。

## 六、改完显示不对怎么恢复

改 dpi / 分辨率把界面搞乱了别慌：用手机自带的**显示大小**（设置里的字体与显示）先把可读性调回来，再回 Runner 跑恢复命令——`wm density reset`、`wm size reset`。实在点不到 Runner，让手机保持解锁，用任一能执行命令的方式（如连电脑 `adb shell`）跑同一条 reset 即可。

改动画、改名这类 `settings` 键本身无风险，按 [常用命令与代码合集.md](常用命令与代码合集.md) 里的恢复命令填回原值就行；卸载了系统应用用 `pm install-existing 包名` 找回（仅限当时用 `pm uninstall --user 0` 卸的）。

## 七、Shizuku 跑一阵就自己停了

免 root 的常态，不是 Runner 的问题：安卓会为省电杀后台，重启手机后服务也必然掉。标准处理是「掉了就再启动」——重新配对不用做，进无线调试回 Shizuku 点启动即可。想让它稳一点（电池不限制、锁后台、停用 adb 授权超时等一整套设置），照 [Shizuku服务停止与保活.md](Shizuku服务停止与保活.md) 逐条配齐。

## 八、装不上 / 版本对不上

装的时候提示解析错误，通常是下载不完整或不是这个包——用 [下载与安装教程.md](下载与安装教程.md) 头部的 [ShizukuRunner 安装文件资源（夸克网盘）](https://pan.quark.cn/s/31ef4b96f4e9) 重新拿一份，按文件里的 MD5 核对后再装。系统低于安卓 5.2 也装不上，先确认系统版本。
