## 二、获取 Impulse 安装文件资源

拿到安装包最直接的方式是用本篇头部给出的 [Impulse 安装文件资源（夸克网盘）](https://pan.quark.cn/s/733e2b9e3202)，步骤：

1. 打开链接，先**转存到自己的网盘**（不转存直接下载经常限速）；
2. 在夸克网盘 App 里找到转存后的文件，下载到手机；
3. 下载完成后核对一下文件大小，应与第一节表格里的 2.24 MB 同量级，明显偏小说明没下完整。

## 三、安装步骤

1. 在文件管理器里点开下载好的 APK 文件；
2. 第一次装会提示「未知来源应用」，按你手机品牌的提示允许该来源安装（各品牌入口不同，一般在弹窗里点「设置 → 允许此来源」即可）；
3. 回到安装页点「安装」，等进度走完；
4. 装完直接点「打开」，看到顶部有 Generation / Presets 两个标签的深色界面，就是装对了。

装好后的第一件事可以先去 [频率设置与信号生成.md](频率设置与信号生成.md) 把界面认全，再开始发声。

## 四、装不上或打不开的排查

- **安卓 14 以上直接拒装（最常见）**：Android 14 起系统拒绝安装面向太老安卓版本编译的应用（targetSdkVersion 低于 23，即 Android 6.0 之前的口径）。这款应用的官方版本说明停留在 2015 年 4 月（修复了一些用户反馈的问题），之后没有再发新版，很可能就卡在这条新规上——表现是安装页直接报「应用未安装」。官方给出的绕过方式是用电脑 adb 安装：

  ```bash
  adb install --bypass-low-target-sdk-block 安装包路径.apk
  ```

  也要有预期：这个参数只是放行安装，不代表老应用在新系统上运行正常，装完先试，闪退就是真的不兼容。
- **安装包解析失败**：多半是下载不完整，回到第二节核对大小后重新下载。
- **装完打开就闪退**：先重启手机再试一次；仍闪退说明这份安装包与你的系统不兼容（2015 年的老应用在新系统上偶发），没有官方修复可等。
- **被手机管家/杀毒拦截**：这是一款只有 2.24 MB 的纯发声小工具；确认来源是你自己转存的网盘包后，选择「仍要安装」即可。
