## 一、测试前先把音量调低

纯音信号和音乐完全不同：一段音乐里某频段只出现一瞬间，而纯音会以同一个频率持续轰炸你的耳朵。开始测试前把媒体音量压到三成左右，之后按需逐步加大。同样音量下，低频和高频听起来比中频轻，这是人耳的正常特性，不是设备坏了。

顺带记一个长期用耳的口径——耳机圈常引用的「60-60 原则」：音量不超过设备最大音量的六成，连续收听不超过一小时。测试只是几分钟的事，但扫频时耳朵是全程暴露的，这条原则值得日常保持。

## 二、测耳机 / 音箱的流程

1. **环境安静、有线优先**。蓝牙耳机的编解码会改变频响，也会引入延迟；要测设备真实表现，用有线连接最接近原貌。
2. **先确认两个声道都响**。在 Generation 里输入 440 Hz，正常发声后换几副耳机对比，确认左右单元都有声、音色一致。
3. **按检查点逐个听**。与其无头苍蝇式乱扫，不如按下面的表逐点停留几秒：

| 频率点 | 听什么 |
| --- | --- |
| 60 / 100 Hz | 低频下限：低音炮和低音单元能不能出声、有没有只振动不出声 |
| 440 Hz / 1 kHz | 中频基准：音色是否干净，有没有杂音 |
| 5 kHz | 人耳敏感区：是否有刺耳的峰、毛刺感 |
| 10 kHz | 高频延伸：镲片类声音的亮度来源 |
| 15~18 kHz | 极高频：多数设备在这里开始明显衰减 |
| 20 kHz 以上 | 一般听不到；有杂音是扬声器寄生音 |

4. **记下异常频段**：明显偏小、破音、忽大忽小的位置，这就是这套设备频响上的坑。
5. **换参照物对比**：同一组频率在另一副耳机或另一只音箱上放一遍，异常是否复现，立刻能判断问题在设备还是在你的耳朵。

也可以不逐点听，改用一次完整扫频（起点 20 Hz、终点 20000 Hz）让问题自己暴露出来，扫频的设置方法见 [频率设置与信号生成.md](频率设置与信号生成.md)。

## 三、听力自测怎么做

1. 找一间安静房间，戴耳机，媒体音量调到中等；
2. 从 1 kHz 开始发声，确认自己听得很清楚，然后逐步升高频率：5k、10k、12k、15k、17k、19k；
3. 记下「刚好听不见」的位置。一般规律：人耳可闻范围约 20 Hz 到 20 kHz，高频端随年龄增长逐渐上移收窄，同是成年人，能听到的上限差别很大；
4. 高频听不到先别急着下结论，换一副耳机再试——很多手机和耳机的扬声器在 15 kHz 左右就没有输出了，那是设备的上限，不是你的；
5. **高频变差≠听不清说话**：日常对话的声能集中在 500~3000 Hz，即使你的高频上限已经掉到 12~15 kHz，聊天可能照样没问题——高频听力往往先于言语听力受损，这正是「听得见但听不清」式听损的早期特征。自测出高频上限偏低，把它当作去做正规纯音测听的提醒即可。

这个玩法朋友之间也常用作谈资：高频段的「蚊子音」年轻人听得见、年纪大的人听不见。注意别对人耳长时间播放，也别在教室、办公室这类场合当整蛊工具——你听不见的频率，坐在旁边的年轻同事可能听得一清二楚。

## 四、结果怎么解读

- **自测不是体检**：这套流程只能给你一个粗略印象，不能替代听力检查；真的怀疑听力下降，去做正规听力学检查。
- **低频段忽大忽小**：小房间里这常是驻波在作怪——房间尺寸让某些低频互相抵消或叠加，换个位置听结果就不一样，属于环境问题而非设备损坏。
- **某频段破音**：先降音量再听一次，小音量下不破就是大音量失真（功率不够），小音量也破才是单元问题。
- **外接设备做更正式的测量**：把手机通过 3.5mm 接口接到功放或示波器上，可以做比耳朵更客观的判断，接法见 [进阶用法与外接设备.md](进阶用法与外接设备.md)。
