## 一、先把界面结构认全

打开应用后是一个深色界面，结构只有三块：

- 顶部两个标签：**Generation**（生成信号）和 **Presets**（预设）；
- 右上角三个点的菜单，进去是 **Options**（设置页）；
- 你要的一切发声操作，都从 Generation 标签开始。

## 二、Generation：设定频率并开始发声

Generation 页从上到下依次是：Frequency 输入框、一根滑杆、To frequency 开关、绿色 Start 按钮。

1. **Frequency 输入框**：直接输入频率，单位 Hz，默认 440（标准音 A4 的频率，乐器调音参考值）。想精确就手动输入，想快速试不同频率就用下面的滑杆。
2. **滑杆**：粗调。滑到大致位置后，再用输入框微调到具体数值。
3. **Start 按钮**：点下去开始发声，按钮下方会实时显示当前频率；再点同一按钮停止。
4. 发声时把媒体音量调到合适位置——纯音不响不一定是没在发声，常常只是音量没开。

## 三、To frequency：让频率自己扫起来

勾选 **To frequency** 后会多出结束频率一栏。设定起点和终点后再点 Start，输出就会在两个频率之间连续滑动（扫频），而不是停在一个点上。

典型用法：起点设 20 Hz、终点设 20000 Hz，用一次完整扫频听整条频段，哪一段突然变小、哪一段出现杂音，一听便知。测耳机和音箱的详细流程写在 [测试耳机音箱与听力.md](测试耳机音箱与听力.md)。

注意：扫频会长时间经过 2~5 kHz 这段人耳最敏感的区域，第一次先开小音量，确认受得了再加大。

## 四、Presets：一键直达的预设

Presets 标签里是三组现成的按钮，点任意一个立即以该频率发声：

| 分组 | 按钮频率 |
| --- | --- |
| Anti Mosquito（驱蚊） | 12 kHz / 14 kHz / 16 kHz / 20 kHz |
| Dogs and cats whistle（猫狗哨） | 7 kHz / 10 kHz / 15 kHz / 19 kHz |
| User presets（用户预设） | 440 Hz / 1000 Hz / 2000 Hz / 3000 Hz |

User presets 这一行的右侧有一个小图标，用来把你自己常用的频率存成预设按钮。前两组的具体用法、效果与注意事项，单独写在 [驱蚊与狗哨预设.md](驱蚊与狗哨预设.md)。

## 五、Options：设置页逐项说明

从右上角三个点进入 Options，页面上有两项：

- **Enable sound in sleep mode**（睡眠模式下继续发声）：勾选后锁屏、息屏时输出不中断。想让扫频、驱蚊这类需要长时间运行的模式在锁屏后继续，就保持勾选。
- **Sample rate (Hz)**：采样率，默认 44100（CD 音质采用的标准采样率）。没有明确理由不用改它。

官方功能列表里还有「时长可选（Time span selectable）」一项，对应入口以你手上版本的菜单显示为准。

## 六、一张常用参考频率表

不知道该设多少时，按这张表取数：

| 频率 | 常见用途 |
| --- | --- |
| 165 Hz | 扬声器进水排水的主流口径（完整步骤见 [扬声器进水排水方法.md](扬声器进水排水方法.md)） |
| 60 / 100 Hz | 感受低频下限，试低音炮和低音单元 |
| 440 Hz | 标准音 A4，乐器调音参考 |
| 1 kHz | 中频参考点，确认声道是否都正常发声 |
| 10 kHz | 高频段检查 |
| 15~19 kHz | 成年人听力的边缘地带，测试自己还能不能听见 |
| 20 kHz 以上 | 多数人听不到；扬声器若发出杂音，那是寄生音，不代表你听到了该频率 |

这些频率都能在 Generation 输入框里直接输入；想存成一键按钮就走 User presets。生成出来的信号怎么用、外接设备怎么接，见 [进阶用法与外接设备.md](进阶用法与外接设备.md)。
