## 一、先分清是哪类问题

不同症状起点不同，别混着试：

| 症状 | 从哪开始 |
| --- | --- |
| 点安装包就报错、装不上 | 看[下载与安装教程.md](下载与安装教程.md)的安装一节（空间、来源权限） |
| 装好了，点图标闪退 / 黑屏 / 卡启动页 | 第二节 |
| 能打开，登录不进去、验证码收不到 | 第三节 |
| 能用但对话发不出去、图片传不上 | 第四节 |

## 二、闪退、卡启动页、无响应

按顺序做，每做一步试一次，能省后面的力气（各品牌手机入口略有差异，一般在「设置 → 应用管理」里能找到）：

1. **强停重开**：长按应用图标 → 应用信息 → 强行停止，再重新打开；
2. **重启手机**：很多「玄学」闪退重启就好；
3. **检查更新**：系统设置里把手机系统升到最新，应用也升到最新版——旧版应用与新系统不兼容是闪退的常见原因；
4. **清缓存**：应用信息 → 存储 → 清理缓存（先只清缓存，别上来就「清除数据」，清除数据会删掉本地记录）；
5. **查权限**：应用信息 → 权限，确认相机、麦克风、存储这几项没有被禁用——部分机型禁掉存储权限会导致启动即崩；
6. **腾存储空间**：手机可用空间建议保留 20% 以上，157M 的应用解压运行还要占更多；
7. **卸载重装**：前六步都无效再走到这步——卸载会丢本地数据，账号里的内容以云端为准，重装用 [小荷AI医生 安装文件资源（夸克网盘）](https://pan.quark.cn/s/51c8e591003e) 里那份包即可。

装完还是闪退、且多款应用都闪退，问题多半在系统层：把系统版本升到最新再试。

## 三、登录不进去

官方隐私政策（2026 年 8 月更新版）里写明的登录方式有四种，一种不行换一种：

- **手机号 + 验证码**：最常规的方式；
- **本机号码一键登录**：运营商取号，需授权；拒绝授权不影响换其他方式登录；
- **抖音账号登录**：授权后会同步你的抖音公开信息（头像、昵称）；
- **Apple ID**（仅 iOS）：用 Apple ID 登录后还要绑定手机号完成验证。

排查顺序：

1. 确认手机信号正常、短信没被拦截软件吞掉（先查短信拦截列表）；
2. 换网络试试——Wi-Fi 和移动数据切一下，登录接口被网络环境卡住很常见；
3. 验证码一直收不到：过 60 秒再取、检查是否频繁获取被限流、确认手机号没欠费停机；
4. 提示账号异常：核对是不是换了手机号——账号体系是统一的「小荷」账号，小荷AI医生、小荷健康、小荷医生通用一个账号，手机号就是账号本体。

## 四、能打开但功能用不了

- **对话发不出去**：检查网络；输入框内容是否为空（空消息发不动是正常的）；
- **拍照、传图失败**：去系统设置里把相机、相册权限给上，见[常见问题与使用限制.md](常见问题与使用限制.md)的权限一节；
- **回复一直转圈**：等半分钟让它跑完，AI 生成回复本来就要时间；持续无响应按第二节强停重开。

以上都试过仍不解决：用应用内的用户反馈入口反映具体情况（机型 + 系统版本 + 出问题的步骤），或升级到官方渠道最新版再看。安装包本身的问题（下错、损坏）对照[下载与安装教程.md](下载与安装教程.md)的校验方法查一遍。
