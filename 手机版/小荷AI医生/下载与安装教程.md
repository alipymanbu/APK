## 一、这是个什么应用

小荷AI医生是一款安卓端的 AI 健康咨询应用，运营方是海南小荷健康网络技术有限公司（字节跳动旗下「小荷健康」品牌）。你用文字或语音描述症状，它会像医生问诊一样追问细节，再给出健康建议；也支持拍照解读化验单、拍药盒查说明书。它只做健康咨询，不提供诊断和处方（详见[常见问题与使用限制.md](常见问题与使用限制.md)）。

装之前先对一下手上这份安装包的信息，与下表一致才说明拿对了文件：

| 项目 | 值 |
| --- | --- |
| 版本 | 3.2.0 |
| 包名 | `com.aurora.xiaohe.aidoctor` |
| 大小 | 157.32M |
| MD5 | `cf3beb189666fad1c0c8dc74ff82319b` |

应用在持续更新，官方渠道（应用宝、App Store 等）显示的版本号会比 3.2.0 更高，那是官方最新版，与网盘里这份不是同一个版本——装哪份由你自己定，本文的信息以表里这份为准。

## 二、拿到安装包

小荷AI医生 安装文件资源（夸克网盘）在 [https://pan.quark.cn/s/51c8e591003e](https://pan.quark.cn/s/51c8e591003e)，打开后把应用文件夹转存到自己的网盘再下载，文件夹里是 `.apk` 安装包和一个说明 txt。

下载注意两点：

- 包体 157.32M，建议在 Wi-Fi 下下载，别用流量硬拉；
- 下载工具不要自动改文件名后缀，保持 `.apk` 结尾，否则手机可能认不出这是安装包。

下载完可以校验一下 MD5，确认文件完整没损坏。Windows 上在安装包所在目录开个 PowerShell 执行：

```powershell
certutil -hashfile 小荷AI医生_v3.2.0.apk MD5
```

输出的哈希与上表的 `cf3beb189666fad1c0c8dc74ff82319b` 一致即可；不一致说明文件在传输中出了问题，重新下载一次。

## 三、安装

1. 把 `.apk` 传到手机（数据线、局域网传输、网盘手机端下载都行）；
2. 用手机自带的文件管理器点开这个 apk；
3. 系统会弹「安装未知应用」拦截——这是安卓对非应用商店来源应用的常规提示，确认继续安装即可（不同品牌入口略有差异，一般在弹窗里直接能跳到「允许此来源」的开关）；
4. 等安装进度走完，桌面会出现「小荷AI医生」图标。

安装失败时先看[常见问题与使用限制.md](常见问题与使用限制.md)：157M 的包在安装时会解压出更多占用，存储空间要留够；系统版本过低也会装不上。

## 四、首次启动要处理的事

装好打开，前几步一般是这样：

1. **隐私协议与用户须知**——首次启动会要求你同意隐私政策和《用户使用须知》，不同意用不了完整服务，同意前可以先扫一眼它收集哪些信息；
2. **手机号登录**——账号用手机号注册登录，这是网络实名制的要求，不登录也能看部分内容，但咨询、健康档案这类功能需要账号；
3. **权限按需授权**——相机（拍化验单、拍药盒）、麦克风（语音描述症状）、相册（从相册选报告图）都是在你用到对应功能时才弹授权，可以拒绝，拒绝只影响该功能，别的照常用；
4. **年龄门槛**——官方须知写明本服务不向未满 18 周岁的未成年人提供服务，未成年人需在监护人同意并陪同下使用。
