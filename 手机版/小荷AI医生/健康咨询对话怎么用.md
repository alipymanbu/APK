## 一、核心玩法就是「说症状 → 被追问 → 拿建议」

小荷AI医生的主界面是一个对话框，7×24 小时在线。你把哪里不舒服、多久了、之前吃过什么药这些讲清楚，它不会一次性甩你一段泛泛的科普，而是像医生问诊那样**继续追问细节**——症状持续多长时间、有没有过敏史、有没有基础疾病等。你答得越具体，它给的建议越贴合你的情况。

典型的一轮流程：

1. 在底部输入框输入症状（例如「嗓子疼两天了」）；
2. 它反问几个关键问题，你逐个回答；
3. 它给出分步骤的建议：可能是居家护理方法、需要观察什么、什么情况该去医院哪个科室；
4. 不满意或有新情况，继续追问即可，对话是连贯的。

从 2025 年 3 月起它支持所有科室的咨询，常见病自查、慢病咨询、康复养护这类日常问题都在服务范围内。

## 二、用好输入组件，比纯打字省事

除了自由输入，对话里会出现现成的选项组件，直接点比打字快，也更不容易描述含糊：

| 组件 | 用来填什么 |
| --- | --- |
| 文字选项 | 它把常见回答列成选项，点一下即可 |
| 身体部位 | 指哪里疼、哪里不舒服 |
| 颜色形状 | 描述皮疹、分泌物等可视症状 |
| 体温 / 血糖血压 | 直接选数值，不用自己换算单位 |
| 疼痛程度 | 把「很疼」量化成档位 |

中老年用户打字费劲的话，可以用语音入口描述症状（以你手上版本界面里的实际入口为准）。文字、语音、图片三种形式它都能收。

## 三、问诊之外它还会做什么

一次对话里它能用到的能力不止问答：

- **分步骤方案**：症状分析完给一套条理化的应对步骤，而不是一篇长文；
- **视频与用药参考**：部分症状会配缓解动作的演示和参考药物信息（仅供参考，不构成处方）；
- **就医推荐**：告诉你该挂哪个科、什么情况下该尽快去医院；
- **联网检索**：识别到需要查外部信息的意图时它会联网搜索，回复上方会显示搜索来源——这些来源是第三方网页，内容可能有错漏，自己留个心眼；
- **AI 诊室**：深度健康咨询模式，会问得更细、收集更多信息再回答。

需要解读化验单或拍药盒，直接在对话里用对应入口发起即可，分别见[化验单报告解读教程.md](化验单报告解读教程.md)和[拍药盒查说明书教程.md](拍药盒查说明书教程.md)。

## 四、回答的边界（务必看清）

这是你使用前最该知道的一段：

- 它的回复基于你提供的信息和有限的训练数据生成，**可能出错或遗漏**，重要内容以医生和官方权威资料为准；
- 它**不是**医生，不提供诊断、处方、治疗建议，更不提供紧急医疗服务——回复内容不能作为就医处置的直接依据；
- 遇到急症、症状加重或持续不缓解，直接去医院，别在对话里耗着；
- 未成年人使用需监护人同意，服务仅面向中国大陆用户。
