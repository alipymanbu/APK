## 一、这套教程覆盖什么

Learn Kali Linux 是按主题分章的图文教程集，从 Kali Linux 的基础概念讲起，逐步过渡到各类工具主题。按其商店介绍与章节目录，内容大致分这几块：

- **Kali Linux 基础**：系统是什么、桌面与终端长什么样、基本操作方式；
- **命令类教程**：Linux 常用命令、终端使用方法；
- **网络与脚本类**：网络基础、脚本语言入门（Shell、PHP、HTML 等主题）；
- **工具主题章**：按类别讲安全工具，例如漏洞分析（Vulnerability Analyses）类章节，章内会逐个工具介绍用途，并配 Kali 桌面环境的实操截图；
- **周边知识**：操作系统常识、软件与安全常识类短篇。

全英文呈现——章节标题、正文、配图标注都是英文。读不懂的段落可以配合手机自带的划词翻译或翻译 App 辅助。

## 二、推荐的学习顺序

1. **先读基础章**：搞清 Kali 是 Debian 系 Linux 发行版、终端与桌面的关系，不然后面所有工具章都是空中楼阁。
2. **再过命令章**：`ls`、`cd`、`cat`、`sudo`、`apt` 这类高频命令先混个眼熟，工具章里到处在用。
3. **然后按需挑工具章**：不必从头到尾通读——网络类、漏洞分析类按兴趣与需要跳读即可。
4. **配图里的操作放到电脑上练**：教程配图是电脑上的 Kali 界面，手机上读懂步骤后，照着在虚拟机里敲——环境怎么搭见 [虚拟机练习环境搭建教程.md](虚拟机练习环境搭建教程.md)；敲的时候报错，按 [命令报错与排查速查.md](命令报错与排查速查.md) 对号入座，别卡死在一条命令上。

**怎么算学会了**（每读完一章给自己三条判据）：

- 能不看原文说出这一章的工具**解决什么问题**；
- 能在自己环境里把章里的核心命令**至少敲通一条**，且知道每个常用参数的意思；
- 遇到报错能自己读出报错行的原因层次（命令没装 / 权限 / 网络），而不是只会照抄解决办法。

三条里缺哪条，就回原文补哪块；三条都过，直接进下一章。

## 三、边界要先说清

- 这套教程的价值是**让你认识工具与概念**；照着教程在**未经授权**的系统、网络上动手是违规的。练习只在自己的设备、或自己搭建的靶场环境里做。
- 教程内容随安装包离线内置，不依赖联网；但章节目录深度以你装的这版（2.1，见 [下载与安装教程.md](下载与安装教程.md) 第四节）实际显示为准，别拿网上别处的目录对照。
- 读完想检验：自己在电脑环境里把命令敲一遍、把概念讲给自己听，比反复读更有效。
