## 一、先分清错在哪一层

教程里的命令是在 Kali 终端里跑的，你敲报错时，先看报错行的最后一句——它通常直接说了原因。对照下表定位：

| 报错长这样 | 层次 | 怎么处理 |
| --- | --- | --- |
| `command not found` | 命令不存在/没装 | 见第二节 |
| `Permission denied`（命令能识别） | 权限不够 | 见第三节 |
| `apt: could not resolve` / `Temporary failure resolving` | 网络/DNS 不通 | 见第四节 |
| `404 Not Found` / `Hash Sum mismatch` | 软件源问题 | 见第四节 |
| 提示与教程截图长得完全不一样 | 环境差异 | 见第五节 |

## 二、`command not found`：命令没装或不在路径里

1. **确认拼写**——教程是英文截图，`ifconfig` 与 `ipconfig`（Windows 的）一字之差最常敲错。
2. **命令属于某个软件包**：Kali 不会预装每一个工具，用 `apt search 关键词` 或 `apt-file search 文件名` 找它属于哪个包，再 `sudo apt install 包名` 装上。
3. **刚装完仍找不到**：开个新终端再试；个别情况是 shell 缓存，执行 `hash -r` 后重试。

## 三、`Permission denied`：权限不够

- 涉及系统目录、安装软件、改配置的命令，前面加 `sudo`：`sudo apt install nmap`；
- 提示要输密码时，屏幕**不会显示任何字符**，输完直接回车——这不是键盘坏了；
- 在练习环境里 `sudo` 报「不需要密码以外的错」或干脆不认：Kali 的 root 策略因版本而异，官方文档的通用建议是以普通用户 + `sudo` 使用；手机 NetHunter Rootless 环境里另有差异（部分机型禁 `sudo`，官方文档建议改用 `su -c 命令`，见 [和真正的Kali系统有什么区别.md](和真正的Kali系统有什么区别.md)）。

## 四、apt 更新/安装失败：多半是网络或源

Kali 官方文档把 `sudo apt update && sudo apt full-upgrade -y` 列为装完第一件事，它也最容易在这一步卡住：

- **`could not resolve` / DNS 报错**：网络没通或 DNS 不行。先 `ping -c 3 1.1.1.1` 测连通——通了就是 DNS 问题，换个 DNS（如 `1.1.1.1` 或 `8.8.8.8`）再 `apt update`；不通先修网络（虚拟机检查桥接/NAT 设置，手机检查联网与代理）。
- **`404 Not Found`**：源地址指向了不存在的旧版本。执行 `sudo apt update` 先刷新索引再装；仍 404 说明源配置与你的版本不匹配，按官方文档核对 `/etc/apt/sources.list`（以 [kali.org](https://www.kali.org) Docs 的当前写法为准）。
- **`Hash Sum mismatch` / 下载到一半断**：下载被中断，重跑一次 `apt update` 即可；手机上装 NetHunter 镜像时校验失败的处理，见官方 Rootless 文档的说明。
- **国内直连官方源慢**：这是网络路径问题，可换用镜像源——但换源属于会变的配置，照当时可用的镜像教程做，别背固定地址。

## 五、命令能跑，但和教程截图不一样

不是报错，却最常让人慌：

- **教程配图是 Kali 桌面版**，菜单、图标、窗口位置都是桌面环境的；你若在无桌面的最小环境里练，本来就没有那些图形元素，敲命令不受影响；
- **Kali 是滚动更新**，不同年份版本的工具输出格式、默认选项会变——以你环境里实际输出为准，教程截图只当「长什么样」的参考；
- 差异大到影响使用时，先确认自己环境是否已是最新（`sudo apt update` 后看有没有待升级项，见 [虚拟机练习环境搭建教程.md](虚拟机练习环境搭建教程.md) 第四节）。

## 六、还不行的排查顺序

1. 报错原文整段复制去搜索（英文报错搜英文）；
2. 核对是不是环境问题：`uname -a` 看系统、`apt --version` 看包管理器是否正常；
3. App 本体相关的问题（打不开、闪退）不在这里，见 [常见问题与解决方法.md](常见问题与解决方法.md)；
4. 单条命令反复失败时，先跳过继续读下一节——教程是按主题组织的，卡死在一章不划算，顺序见 [教程内容与学习路线.md](教程内容与学习路线.md)。
