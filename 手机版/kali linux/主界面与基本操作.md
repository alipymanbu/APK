## 一、先知道它是「读教程」的操作逻辑

Learn Kali Linux 没有账号体系，也不需要注册登录：装完打开就是菜单，点进章节就是一页页图文，读完退出即走。整个应用是英文界面（顶栏标题 Learn Kali Linux、菜单项与教程正文都是英文），操作本身很简单——认下面六个卡片按钮就够，遇到不认识的词可以先按字面意思点进去看，不会误改手机任何设置。

## 二、首屏六个入口

首屏是深色卡片式菜单，从上到下：

| 入口 | 作用 |
| --- | --- |
| Let's Start | 主入口，点进去就是教程章节目录，学习从这里开始 |
| Our Apps | 开发者的其他应用列表，与教程内容无关 |
| Tool Box | 工具箱入口，按其字面用途归类的辅助功能区 |
| Share | 把这个应用分享给别人的入口 |
| Feed Back | 反馈入口，遇到内容问题从这里提交 |
| No Ads | 与去广告相关的入口，具体以点开后页面显示为准 |

日常学习只需要记住 **Let's Start**——其余五个是外围功能，不点也不影响读教程。

## 三、章节目录与翻页

1. 首屏点 **Let's Start**，进入章节目录。
2. 目录按主题分章（例如 Vulnerability Analyses Tools 这类安全工具主题章），点任意一章进入正文。
3. 正文页的布局：顶栏左侧是**汉堡菜单（三条横线）**，点它可以随时回到目录换章；右侧是三点菜单。
4. 正文按「小标题 + 段落 + 配图」组织，配图是 Kali 桌面环境的操作截图——图里展示的是电脑上的 Kali 界面，你在手机上做的是**读懂步骤**，真要动手照做，需要在自己的电脑环境里练，见 [教程内容与学习路线.md](教程内容与学习路线.md)。
5. 一章读完想换章：点左上角汉堡菜单回目录，或用系统返回键逐级退出。

## 四、卡住时怎么办

- 点进去的页面看不懂或加载异常：退出重进，或到 设置 → 应用管理 里强行停止后重新打开；
- 应用闪退、白屏：见 [常见问题与解决方法.md](常见问题与解决方法.md)；
- 不确定自己装的版本对不对：回 [下载与安装教程.md](下载与安装教程.md) 第四节核对包名与版本。
