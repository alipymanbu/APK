## 一、为什么练命令要搭虚拟机

App 里的配图都是电脑 Kali 桌面的截图，你要照着敲，就需要一台**出事也不心疼**的机器——虚拟机就是干这个的：它是在你电脑里开的一个窗口系统，和你的 Windows/macOS 完全隔离，弄坏了直接删掉重建，主系统毫发无损；还能在每次实验前拍一个**快照**，玩崩了一键回到实验前。这也是各类安全课程与靶场普遍采用的形态。

## 二、电脑要什么配置

按 Kali 官方文档的口径（[kali.org](https://www.kali.org) → Docs → Installation，具体以官方页面当时显示为准）：

| 项 | 最低 | 建议 |
| --- | --- | --- |
| 内存 | 装桌面版至少 2 GB 给虚拟机 | 整机 8 GB 以上，给虚拟机 4 GB |
| 磁盘 | 20 GB | 50 GB（用动态分配盘，实际占用随使用增长） |
| 处理器 | 1 核 | 2 核 |
| 前置条件 | BIOS/UEFI 里开硬件虚拟化（Intel VT-x / AMD-V） | 同左 |

不开虚拟化时虚拟机起不来，报错里带 `VT-x is disabled` 字样——重启进 BIOS（开机按 F2/Del/F10，因品牌而异）把虚拟化选项打开。

## 三、两种搭法选一个

**路线 A：官方预建镜像（新手推荐）**
1. 装 VirtualBox：到 [www.virtualbox.org](https://www.virtualbox.org) 下载安装包，默认下一步装完。
2. 到 [www.kali.org](https://www.kali.org) → Get Kali → **Virtual Machines** 区，下官方已经配好的镜像（导入即用，免去手动装系统那半小时）。
3. VirtualBox 里 File → Import Appliance，选中下载的镜像导入，启动即进系统。

**路线 B：手动装（多练一手安装流程）**
1. Get Kali → **Installer Images** 区下 64 位安装 ISO；
2. VirtualBox 新建虚拟机：Type 选 Linux、Version 选 Debian (64-bit)，内存 2048 MB 起、动态分配磁盘；
3. 挂载 ISO 启动，按安装向导走完。

两种路线出来的环境一样能用；只想快点开始练命令就选 A。

## 四、进去之后先做三件事

1. **更新**：登录后先 `sudo apt update && sudo apt full-upgrade -y`（官方文档建议装完第一件事就跑它）；
2. **拍快照**：VirtualBox 菜单 Machines → Take Snapshot，起个名——之后每次做实验前都拍一张，崩了随时回；
3. **对齐教程**：回到 App 里挑一章，把图里的命令在虚拟机终端里敲一遍。学习顺序见 [教程内容与学习路线.md](教程内容与学习路线.md)。

## 五、边界不变

虚拟机隔离的是**你自己的电脑**，不是规则：练习对象只限你自己这台虚拟机与自己搭的环境；对非自有系统与网络动手，虚拟机里做也一样违规。只在自己的设备上练，这条对虚拟机、手机（见 [和真正的Kali系统有什么区别.md](和真正的Kali系统有什么区别.md)）都适用。
