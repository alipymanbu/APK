## 一、装之前先弄清它是什么

Learn Kali Linux 是一个**教学类安卓应用**：里面装的是 Kali Linux 的图文教程，你在手机上读教程、翻章节，它本身并不是 Kali 系统，也不会把你的手机变成一台「黑客系统」。想弄清它和真正的 Kali Linux 差在哪，见 [和真正的Kali系统有什么区别.md](和真正的Kali系统有什么区别.md)。

装之前只需要确认两点：

- 手机系统是安卓 5.2 及以上（网盘这份包的系统要求，低于它装不上或打不开）；
- 它是给「学」用的——教程里出现的命令与工具，应当在你自己的电脑或自己搭建的环境里练习，见 [教程内容与学习路线.md](教程内容与学习路线.md)。

## 二、安装包从哪拿

**网盘**：[Learn Kali Linux 安装文件资源（夸克网盘）](https://pan.quark.cn/s/98a282504e4c) —— 打开分享链接，转存到自己的网盘，再从网盘下载到手机（手机浏览器直接下，或先下到电脑再用数据线传）。

下载完对照第四节的 MD5 校验一遍，一致才说明文件传完整了。

## 三、安装步骤

1. 在手机上点开下载好的 APK 文件。
2. 安卓会弹「不允许安装未知来源应用」——按提示对该来源放行即可（不同品牌路径略有差异，一般在 设置 → 安全/隐私 → 安装未知应用 里）。
3. 华为、小米、vivo、OPPO 等机型还会追加「未经过安全检测」之类的风险提示，这是所有非应用市场安装包都会遇到的例行提醒，选「继续安装 / 手动安装」走完即可。
4. 装完打开，首屏是深色卡片式菜单，顶栏写着 Learn Kali Linux，入口怎么用见 [主界面与基本操作.md](主界面与基本操作.md)。

装不上或装完打不开，按 [常见问题与解决方法.md](常见问题与解决方法.md) 逐条排查。

## 四、网盘里那份包的信息

| 项 | 值 |
| --- | --- |
| 应用名 | Learn Kali Linux |
| 版本 | 2.1 |
| 包名 | `learn.kalilinux.tutorial` |
| 大小 | 18.10M（18,981,952 字节） |
| 系统要求 | 安卓 5.2 及以上 |
| MD5 | `2532C461ADB550EC8B0D4D1D7E552C5B` |
| 信息核对时间 | 2026-09-23 |

包名 `learn.kalilinux.tutorial` 是安卓识别这款应用的唯一标识，覆盖升级也不会变。想确认手机上装的是哪一版：设置 → 应用管理 → 搜 Learn Kali Linux → 看版本号，应显示 2.1。

核对 MD5 的办法：电脑上用 `certutil -hashfile 文件名.apk MD5`（Windows）算一遍，与表里逐位比对；不一致说明下载不完整，重新下一次。

网盘这份固定是 2.1。商店渠道的版本会继续往前走，两处版本号不必强行对齐——对照本机信息时以这份为准。
