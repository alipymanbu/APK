## 一、安装阶段的问题

**1. 点 APK 提示「解析包时出现问题」或「安装包损坏」**
先按 [下载与安装教程.md](下载与安装教程.md) 第四节核对 MD5——最常见原因就是下载不完整。MD5 不一致就重新下载；一致仍报错，检查文件传输过程（数据线/蓝牙传的文件偶尔截断），换一种方式重传。

**2. 提示「不允许安装未知来源应用」**
安卓对非应用市场来源的常规拦截。按弹窗引导对该来源放行（设置 → 安全/隐私 → 安装未知应用），再点一次安装。品牌机的「未经过安全检测」提示同理，选继续安装即可。

**3. 提示「与现有版本签名不同」或「应用未安装」**
手机上残留了同包名的旧版本（`learn.kalilinux.tutorial`），且两份包的签名不一致。到 设置 → 应用管理 里卸载旧的再装新的；注意卸载会清掉旧版在本机的阅读进度（若有）。

**4. 系统版本不够**
网盘这份 2.1 要求**安卓 5.2 及以上**。到 设置 → 关于手机 查看安卓版本，低于 5.2 的设备装不上，强行装也会打不开。

## 二、使用阶段的问题

**5. 打开闪退、白屏或卡在启动页**
按顺序试：① 设置 → 应用管理 → Learn Kali Linux → 强行停止后重开；② 重启手机；③ 存储空间不足会导致应用启动失败，先清理出几百 MB 再试；④ 都无效则按第一节方法重装一遍。装完打不开且反复出现的，多半是包在传输中损坏（回到第一节查 MD5）。

**6. 界面全是英文看不懂**
应用本身没有中文切换——顶栏、菜单、教程正文都是英文。处理办法：配合手机自带的划词翻译或翻译 App 读；操作类词汇先记高频的几个（Let's Start = 从这里开始、Tool Box = 工具箱、Feed Back = 反馈），入口说明见 [主界面与基本操作.md](主界面与基本操作.md)。

**7. 找不到能敲命令的地方**
正常——它是教程不是系统，没有终端。想对着练命令，先按 [虚拟机练习环境搭建教程.md](虚拟机练习环境搭建教程.md) 在电脑上把环境搭起来；路线选择见 [和真正的Kali系统有什么区别.md](和真正的Kali系统有什么区别.md) 第三节。

**8. 照教程敲命令报 command not found / Permission denied**
不是 App 的问题，是终端环境的报错，按现象查 [命令报错与排查速查.md](命令报错与排查速查.md)（命令没装 / 权限 / 网络三层各有各的处理）。

**9. 章节目录和网上说的对不上**
以你本机装的这版为准。网盘这份固定是 2.1（核对方法见 [下载与安装教程.md](下载与安装教程.md) 第四节）；网上描述的多是其他版本甚至别的应用，目录深度不必强行对照。

**10. 有没有广告、要不要联网**
商店渠道的版本属免费带内购、含广告的形态；去广告与否以首屏 No Ads 入口点开后的页面为准。教程内容随安装包离线内置，读教程不需要联网；联网只影响广告与反馈类功能。

## 三、账号与数据

**11. 换手机怎么办**
应用没有账号体系、数据不云同步。新手机上重新安装即可——教程随包内置，本来就是全量的；阅读进度类本机数据不迁移，卸载前若有需要可先确认应用内有无导出入口。

**12. 怎么确认新装的包是官方那版**
核对包名 `learn.kalilinux.tutorial` 与版本 2.1、MD5 逐位一致（见 [下载与安装教程.md](下载与安装教程.md) 第四节表），三项都对得上就是同一份文件。
