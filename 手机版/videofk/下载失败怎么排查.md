# VideoFk 下载失败怎么排查

> 本篇汇总 VideoFk 用起来最常见的几类故障：下载到一半停了、粘贴后解析不出来、引擎过旧导致的问题，每类都给可操作的排查顺序。

VideoFk 的解析下载能力来自内置的 yt-dlp 引擎，它遇到的问题大多有规律可循：要么是系统把后台下载杀了，要么是链接本身有边界，要么是引擎版本追不上平台改动。出问题时先按下面的速查表对号入座，再进对应小节处理。

## 一、症状速查表

| 症状 | 最可能的原因 | 先做什么 |
| --- | --- | --- |
| 切后台后下载就停了 | 系统电池策略杀了进程 | 把应用的电池管理设为「无限制」（见第二节） |
| 粘贴后一直解析不出 | 链接不完整，或视频有访问限制 | 核对链接；确认视频是公开的（见第三节） |
| 解析出一大堆不想要的任务 | 粘的是播放列表 / 合集链接 | 见 [支持哪些平台和网站.md](支持哪些平台和网站.md) 第三节 |
| 昨天还能用、今天突然不行 | 平台改了接口，引擎过旧 | 更新 yt-dlp 引擎（见第四节） |
| 下载速度异常慢 | 平台限速或网络波动 | 换网络环境再试 |
| 提示存储空间不足 | 手机空间满了 | 清空间或删旧记录 |
| 应用打不开 / 闪退 | 安装环节的问题 | 见 [下载与安装教程.md](下载与安装教程.md) 第五节 |

## 二、下载到一半停了：把电池管理设为「无限制」

这是官方指引里明确写的一条：**为防止后台下载时系统结束进程，请在系统设置的电池管理中将此应用设置为「无限制」**。

安卓的省电策略会主动杀后台应用，下载任务一进后台就可能被掐断，表现就是「切出去回个消息，回来发现下载停了」。设置路径（不同品牌叫法略有差异）：

1. 系统设置 → 应用管理 → 找到 VideoFk；
2. 进「电池 / 电池优化」；
3. 选「无限制 / 不受限制 / 允许后台运行」。

设完之后跑批量下载才踏实，尤其是多链接批处理任务，跑的时间长，被系统盯上的概率也高。

## 三、粘贴后解析不出来：先分清是链接问题还是能力边界

解析失败先做两步确认，再考虑应用的问题：

1. **核对链接完整性**：粘贴前链接要在剪贴板里完整复制一遍，特别是口令式分享链接，中间缺一段就解析不了。带中文和特殊符号的链接本身是支持的，问题一般出在「没复制全」而不是「符号不认」。还有一种「链接没错但粘错了对象」：粘成播放列表或合集链接，会被当成整个列表解析，只要单条视频就换单视频页地址，见 [支持哪些平台和网站.md](支持哪些平台和网站.md)。
2. **确认视频是公开可访问的**：解析能力有明确边界，以下几类视频无论用什么工具都拿不到——
   - 私密视频（仅作者自己可见）；
   - 需要登录才能看的视频；
   - 有年龄限制、需要账号验证的视频；
   - 平台加了版权保护的内容；
   - 限定地区播放的内容，你所在地区访问不到。

一个快速判别办法：把链接粘到浏览器无痕窗口里打开，**无痕窗口里都看不了的视频，解析不了是正常现象**，不是应用坏了。

链接没问题、视频也公开，还是解析不出来，大概率是平台改了页面结构，引擎需要更新，见下一节。

## 四、解析引擎要时常更新

应用依赖内置的 yt-dlp 引擎识别各平台的视频接口，而**视频平台隔三差五就改自己的接口**，旧引擎对新页面就会失灵——「昨天还好好的今天不行了」基本都是这一类。官方指引也建议开始使用前把 yt-dlp 更新到最新版本。

操作上：

1. 在应用设置里找「更新 yt-dlp / 更新引擎」的入口，更到最新；
2. 更新后重试刚才失败的链接；
3. 某个平台整体失效、其他平台正常时，通常等一次引擎更新就会恢复，期间先用其他来源。

更新前先确认手机能正常联网，网络不通时引擎更新本身也会失败。

## 五、更新之后还不行：剩下的兜底检查

- **换网络试试**：移动数据和 Wi-Fi 各试一次，个别平台对特定网段有限制；
- **重启应用**：清掉后台后重新打开，排除应用状态异常；
- **重发链接**：删掉记录里失败的这条，重新复制粘贴一次，排除剪贴板残留；
- **换一条链接验证**：拿另一条公开视频试，能成说明问题在原链接那条视频上，不是应用整体坏了；
- **安装包损坏**：如果装完就各种异常，回 [下载与安装教程.md](下载与安装教程.md) 重新核对 MD5 并重装。

提取视频的正常流程与每一步的操作细节，见 [怎么提取视频.md](怎么提取视频.md)；下载成功后想转音频或调格式，见 [音频提取与格式设置.md](音频提取与格式设置.md)。
