非商店渠道安装的 apk，装之前值得花两分钟核对一遍——不是走形式，而是因为传输中断、文件被替换这类事恰好发生在「从网盘到手机」这一段。核对不通过的包不要装，重新取一份。

## 一、先对 MD5

本文这套安装包的基准值：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.3 |
| 包名 | com.videofk.seal |
| 大小 | 34.55M |
| MD5 | D399EA2D346596C3B2873D5BEAC78359 |

算出你手上那份的 MD5 再对照：

- **电脑（Windows）**：在命令行里执行

  ```powershell
  certutil -hashfile "videofk_v1.3.apk" MD5
  ```

  （文件名换成你实际的那份；这一命令在 cmd 与 PowerShell 里都能跑。）

- **手机**：多数文件管理器（含各品牌系统自带的「文件管理」）长按文件后进「属性 / 详情」就能直接看到 MD5。

对不上就是文件不完整或被动过：回 [videofk 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8e2830389e1d) 重新转存下载一遍，再核一次，两次都对不上就别装了。

## 二、有条件就做多引擎扫描

在电脑上把 apk 上传到 [www.virustotal.com](https://www.virustotal.com)，它会用几十个杀毒引擎同时扫这份文件：

- **个别引擎报「可疑」**：非商店签名的包常见误报，结合其他核对综合判断；
- **大量引擎同时报毒**：删掉，别装。

这一步对任何渠道拿来的 apk 都适用，不是本应用特有的要求。

## 三、装完看一眼权限

下载类工具的合理权限大致就三类：

| 权限 | 用在哪 |
| --- | --- |
| 存储读写 | 保存下载的视频与音频 |
| 网络 | 解析与下载都在线完成 |
| 后台运行 | 下载切后台不被系统掐断 |

装完到系统「应用信息 → 权限」里过一眼：如果出现读取通讯录、短信、通话记录这类与下载毫无关系的申请，就要警惕——来路不明的「修改版」安装包经常在这一步露馅。

## 四、来源上守一条线

只用你确认过来源的安装包：本文这份走固定分享链接，MD5 对上即可放心装；来路不明的「修改版」「增强版」渠道不要碰。安装环节本身遇到问题（解析包出错、版本不兼容等），处理办法见 [下载与安装教程.md](下载与安装教程.md) 第五节。
