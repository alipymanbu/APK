# VideoFk 怎么提取视频

VideoFk 提取视频的核心流程只有一步主线：复制视频链接 → 粘贴进应用 → 解析 → 保存。整条链路不需要登录任何视频平台账号，解析的是公开可访问的视频。本篇按操作顺序拆开讲，每一步容易卡住的地方都标了处理办法。

## 一、整个流程长什么样

| 步骤 | 你要做的 | 发生在哪 |
| --- | --- | --- |
| 1 | 在视频平台 App 里复制视频链接 | 抖音 / 快手 / B 站 / YouTube 等平台 App |
| 2 | 切回 VideoFk，点粘贴，读入链接 | VideoFk 首页 |
| 3 | 应用自动识别并解析链接 | 自动，无需手动操作 |
| 4 | 确认下载设置，开始下载 | VideoFk 下载页 |
| 5 | 在下载记录里查看，视频保存到手机相册 | VideoFk 记录页 / 系统相册 |

## 二、先把视频链接复制下来

在平台 App 里找到目标视频，用「分享 → 复制链接」把链接放进剪贴板。几个常见平台的位置：

- **抖音**：视频右侧分享按钮 → 复制链接；
- **快手 / B 站**：分享面板里选「复制链接」；
- **YouTube**：分享 → Copy link；
- **Instagram**：帖子右上角菜单 → 复制链接（仅公开帖子有效）。

有一点比较省事：带中文或特殊符号的分享口令式链接（比如抖音那种一长串文案加网址的形式）可以直接解析，不用先手动清理成纯网址。链接没复制完整是解析失败最常见的起点，出问题先回这里核对，排查思路见 [下载失败怎么排查.md](下载失败怎么排查.md)；某个站能不能解析、播放列表链接的坑，见 [支持哪些平台和网站.md](支持哪些平台和网站.md)。

## 三、粘贴并解析

第一次解析前，应用会先要两笔授权：**存储权限**（保存下载的文件要用）和**后台运行权限**（下载切后台不被系统掐断），给上再往下走。之后每次的操作都是同一套：

1. 打开 VideoFk，在首页点**粘贴按钮**，应用会从剪贴板读入你刚复制的链接；
2. 链接读入后应用会自动识别来源平台并开始解析，不需要再手动点解析；
3. 解析完成后会显示这个链接对应的视频信息，下载前可以先**预览**，确认是你要的那条内容再动手，避免下错。

如果想同时处理多条链接，不用一条条来，把多个链接一次性导入即可，见第五节。

## 四、选画质并开始下载

解析完成后点下载，**在开始下载前可以修改本次下载的设置**，这是它和「直接下载」类工具的主要区别——每个链接都可以单独决定参数：

- **画质 / 分辨率**：解析结果提供什么清晰度就选什么，选高分辨率得到的文件体积也相应更大；
- **输出格式**：视频常用 MP4，也支持 MKV 等格式，怎么选见 [音频提取与格式设置.md](音频提取与格式设置.md)；
- 按官方介绍，解析结果不带平台水印，保留原始画质；实际效果以你解析的那条链接为准。

点开始下载后进度会显示在应用内，中途别急着杀掉应用，下载被系统中断的处理办法在 [下载失败怎么排查.md](下载失败怎么排查.md) 里专门讲了一节。

## 五、提取完的视频在哪里

下载完成后视频保存到手机相册，在系统相册里直接就能看到。应用内的**下载记录页**负责查看与管理历史下载，视频和音频的记录都在这一页，包括：

- 回看每一条下载任务的完成状态；
- 管理已下载的视频与音频文件。

相册里找不到时，先去下载记录页核对任务状态，再看文件管理器的「Download」目录。下载列表在任务进行中也能实时查看进度。

保存位置不是只有默认一种：应用设置里可以**分别给视频与音频指定下载目录**，跑批量任务前先指定一个专门的文件夹，事后整理会省事很多。

## 六、一次提取多个视频

要处理一批视频（比如整个合集或多个分享链接），把**多个链接一次性导入**，应用会按列表逐个解析下载，适合批量归档的场景。批量任务里除了视频，还可以按需带上弹幕、字幕、音乐等相关内容一起下载。

批量任务建议一次别塞太多条：单条失败不影响其他链接，但任务列表越长，中途被系统中断的概率越高，先把电池管理设置好再跑大批量，见 [下载失败怎么排查.md](下载失败怎么排查.md)。
