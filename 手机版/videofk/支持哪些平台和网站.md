「支持哪些平台」这个问题没有一劳永逸的固定答案：VideoFk 的解析覆盖面由内置引擎决定，引擎每次更新都可能修复或新增某些站点，也可能因为平台改版暂时失效某个站。本篇给你一份「确认可用」的起点清单，以及一套自己验证任何站点的三步办法。

## 一、商店页与介绍里列出的平台

| 平台 | 出处 | 备注 |
| --- | --- | --- |
| 抖音 | 商店页功能介绍 | 口令式分享链接可直接解析，不用清理成纯网址 |
| 快手 | 商店页功能介绍 | |
| B 站 | 商店页功能介绍 | |
| YouTube | 商店页功能介绍 | 部分视频有地区或年龄限制，属平台侧限制 |
| Instagram | 商店页功能介绍 | 仅公开帖子有效 |
| 小红书等国内平台 | 个别介绍页提及 | 单一来源提到过，未验证，以试解析为准 |

另有介绍页宣称覆盖上百个平台——这个数字无从核实，当参考即可：实际覆盖范围以你手里的链接能不能解析出来为准，某条链接解析失败时按 [下载失败怎么排查.md](下载失败怎么排查.md) 的顺序走一遍再下结论。

## 二、怎么快速判断某个站行不行

三步，一分钟出结论：

1. **先验公开性**：把链接粘到浏览器无痕窗口打开，能正常播放才有解析的可能，无痕窗口都看不了的内容解析不了（具体边界见 [下载失败怎么排查.md](下载失败怎么排查.md) 第三节）；
2. **粘进应用试解析**：复制链接 → 粘贴 → 看能否解析出视频信息；
3. **区分「单站失效」与「整体故障」**：解析失败时，拿另一家平台的公开链接再试一次。另一家能成，多半是那个站改了页面，等一次引擎更新就会恢复；另一家也不成，问题在应用或网络侧，回排查篇逐项过。

## 三、单视频链接与播放列表链接要分清

这是粘贴环节最常见的「粘错了对象」：

| 你粘的 | 会发生什么 | 该怎么做 |
| --- | --- | --- |
| 单条视频页地址 | 解析出这一条视频 | 正常下载 |
| 播放列表 / 合集链接（含 `list=` 参数、合集口令） | 可能被按整个列表解析，一口气列出几十上百条任务 | 只想要其中一条时，改粘单条视频页地址 |

YouTube 的播放列表链接带 `list=` 参数，其他平台的「合集」「合集口令」同理。想要整个列表就让它整列解析，只想留单条就换成单视频地址，两种意图都合理，区别只在粘之前想清楚。

## 四、这些内容不在能力范围内

下面几类无论粘多少次都解析不出来，属于能力边界而不是故障：

- 私密视频（仅作者可见）；
- 需要登录才能观看的内容；
- 有年龄限制、需要账号验证的视频；
- 平台加了版权保护的内容；
- 限定地区播放、你所在地区访问不到的内容。

完整判别办法（无痕窗口测试）见 [下载失败怎么排查.md](下载失败怎么排查.md)。提取一条视频的完整操作流程，见 [怎么提取视频.md](怎么提取视频.md)。
