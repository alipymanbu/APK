VideoFk 是一款安卓端的多平台视频解析工具：把抖音、快手、B 站、YouTube 等平台的视频链接粘贴进去，就能解析出视频文件保存到手机。本篇按「确认条件 → 拿到安装文件 → 安装 → 首次打开」的顺序走一遍。网盘里这份安装包的版本是 1.3，网上商店展示的可能是更新的版本，两者不保证是同一版，版本号与体积以实际下载到的那份为准。

## 一、安装前先确认三件事

| 检查项 | 要求 | 不满足会怎样 |
| --- | --- | --- |
| 系统版本 | 安卓 5.2 及以上 | 装不上，或安装时直接提示不兼容 |
| 存储空间 | 建议预留 200MB 以上 | 安装包本身 34.55M，解析下载的视频还要占额外空间 |
| 网络权限 | 手机可正常联网 | 解析与下载都在线完成，断网状态下没法用 |

安装包本身的核对信息，转存后可以对照：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.3 |
| 包名 | com.videofk.seal |
| 大小 | 34.55M |
| MD5 | D399EA2D346596C3B2873D5BEAC78359 |

## 二、拿到安装文件

安装包通过夸克网盘分享，转存到自己网盘后再下载到手机即可：

1. 打开上面的 [videofk 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8e2830389e1d)；
2. 登录夸克账号，把文件转存到自己的网盘；
3. 在网盘里找到该安装包，选择下载到手机存储；
4. 下载完成后，在系统通知栏或「下载」文件夹里找到 `.apk` 文件。

如果你在电脑前操作，也可以先转存后在电脑端下载，再通过数据线或局域网传到手机。

## 三、安装步骤

1. 点开下载好的 `.apk` 文件，系统会提示「是否安装此应用」；
2. 首次从浏览器或文件管理器安装时，系统可能弹出「不允许安装未知来源应用」的提示，按提示去系统设置里**允许当前来源安装**（不同品牌手机的入口名称略有差异，常见在「设置 → 安全」或弹窗里直接给跳转按钮）；
3. 回到安装界面，点「安装」，等进度条走完；
4. 点「完成」或「打开」。

安卓会自动对安装包做安全扫描，如果弹出「此应用未经过安全检测」之类的提示，属于非商店渠道安装的常规提示，是否继续由你判断；保持安装包来源可靠即可。想在安装前多加一道验证（MD5 对照、多引擎扫描、权限审查），见 [安装包核对与安全检查.md](安装包核对与安全检查.md)。

## 四、首次打开建议先做的两件事

1. **确认下载设置**：官方使用指引建议开始使用前先检查一遍下载设置（保存位置、画质默认值等），确认符合你的习惯再用；
2. **更新解析引擎**：视频平台的接口经常变动，应用依赖内置的解析引擎（yt-dlp），设置里若有「更新引擎 / 更新 yt-dlp」的入口，先把引擎更到最新，能省掉一大类解析失败。

下载设置里具体有哪些项、各代表什么，见 [音频提取与格式设置.md](音频提取与格式设置.md)；引擎更新在解析失败时的作用，见 [下载失败怎么排查.md](下载失败怎么排查.md)。

## 五、装不上或打开报错怎么处理

| 状况 | 先做什么 |
| --- | --- |
| 提示「解析包出现问题」 | 安装包多半没下完整：删掉重新转存下载一次，并核对上一节的 MD5 是否一致（核对步骤见 [安装包核对与安全检查.md](安装包核对与安全检查.md)） |
| 提示版本不兼容 | 确认手机系统是否真的在安卓 5.2 以上（设置 → 关于手机） |
| 安装到一半失败 | 清一下存储空间，重新安装 |
| 打开后闪退 | 重启手机再试；仍闪退就卸载后用同一份安装包重装，排除安装过程损坏 |
| 杀毒软件拦截安装 | 非商店渠道的安装包被误报很常见，确认来源可靠后加入白名单 |

装好之后就可以直接用了，提取视频的具体操作见 [怎么提取视频.md](怎么提取视频.md)。
