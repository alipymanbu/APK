# VideoFk 音频提取与格式设置

> 本篇讲 VideoFk 里两类「不直接下视频」的场景：把视频转成 MP3 之类的音频、给下载任务选输出格式与清晰度。
> **相关文档**：[怎么提取视频.md](怎么提取视频.md) · [下载失败怎么排查.md](下载失败怎么排查.md)

看视频时想留下来的常常不是画面而是声音——背景音乐、播客片段、访谈。VideoFk 在视频解析之外提供音频提取（有些介绍里叫「音视频分离」），可以把视频直接转成 MP3 等音频格式存进手机。本篇讲清楚音频提取怎么操作、输出格式怎么选，以及每次下载前该确认哪些设置。

## 一、什么场景用音频提取

| 场景 | 选什么 |
| --- | --- |
| 只要视频里的歌 / BGM | 音频提取，输出 MP3 |
| 听播客、访谈，不需要画面 | 音频提取，省大量存储空间 |
| 要完整视频 | 正常下载视频（MP4 / MKV），不用音频提取 |
| 既要视频又要音轨里的歌 | 分别下两份（一条选视频、一条选音频） |

音频提取出来的文件和视频一样归入应用内下载记录，在记录页里可以和管理视频一样查看。

## 二、把视频转成音频的操作

流程和提取视频一致，差别只在下载设置那一步：

1. 复制视频链接，粘贴进 VideoFk 解析（完整流程见 [怎么提取视频.md](怎么提取视频.md)）；
2. 解析完成后进入下载设置，把**输出类型从视频切换为音频**，格式选 MP3；
3. 开始下载，完成后在下载记录页找到这条音频。

音频的保存目录可以和视频分开指定：设置里视频与音频的下载目录是两栏，习惯把歌单独归档的话，把音频目录指向音乐文件夹即可。

解析结果里能提供哪些音频规格取决于源视频本身，源视频没有独立音轨可提取时，这一项就选不了，属于正常情况。

## 三、输出格式怎么选

下载前可以修改本次下载的格式设置，视频与音频都支持多种输出格式：

| 你在意什么 | 推荐选择 | 理由 |
| --- | --- | --- |
| 兼容性，随便什么手机都能放 | MP4 | 兼容面最广，相册直接播放 |
| 想保留字幕、多音轨 | MKV | 容器对多流支持更好 |
| 只留声音、存歌 | MP3 等音频格式 | 体积小一个量级 |
| 存储空间紧张 | 选较低分辨率 + MP4 | 分辨率每降一档，体积明显变小 |

分辨率与格式都在**每次开始下载前**的设置里改，改完只影响当前这条任务；下载记录页会按视频与音频分列历史记录，事后核对很方便。

格式的实际可选范围以解析结果为准：MP4、MKV 是常见输出，介绍页还提到兼容 M4V、3GP 等格式——某条链接能给出哪些格式，解析完在下载设置里看到的才算数。

## 四、开始用之前：把下载设置过一遍

官方使用指引专门提醒过一条：**开始使用前，先对下载设置进行确认**。理由很简单——解析完直接点下载，用的就是当前默认设置，默认值不合意的话下出来的东西就要返工。第一次正式使用前，把这几项过一遍：

1. 默认输出格式（视频选 MP4 还是 MKV）；
2. 默认画质档位；
3. 音频输出的默认格式。

设置确认过之后，日常使用就只需要在个别任务上临时改参数，其余直接下载即可。
