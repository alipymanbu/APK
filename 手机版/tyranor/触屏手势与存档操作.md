## 游戏内常用手势

视觉小说在 PC 上靠鼠标点击、滚轮和右键，换成手机后对应的是一套触屏动作。下表是社区整理的常用手势，不同版本的实现可能略有差异，以你装的那个版本实际表现为准：

| 手势 | 对应操作 |
| --- | --- |
| 单击屏幕 | 推进对话 / 确认选项 |
| 长按屏幕 | 唤出游戏菜单（存档、读档、设置） |
| 上滑 | 查看已读文本记录（backlog） |
| 下滑 | 打开设置 |
| 右滑 | 关闭文本框 |
| 双指点击 | 返回 |
| 三指右滑 | 快进文本 |

第一次进游戏，建议先在任意对话界面把这些手势挨个试一遍，比翻设置快得多。

## 存档与读档

1. 长按屏幕唤出菜单，选「存档」（Save）；
2. 选一个存档槽位保存。关键分支前多存一个槽 —— 视觉小说的选项一旦选错，可能要往回读好几章；
3. 读档走同一个菜单里的「读档」（Load），选中槽位回到进度。

两个提醒：

- **存档跟着游戏走**：每个游戏的存档各自独立，互不通用；
- **卸载重装前先备份**：存档写在游戏目录或应用数据里，卸载应用可能连带清掉。换机或清理存储前，把整个游戏目录（含存档文件）复制出来一份。

关于存档的具体落盘位置，各资料的口径不一致：有资料写存放在 `Tyranor/savedata` 一类的目录，也有版本把 KR2 游戏的存档导出到 `Android/data` 下（2.3.4 更新加入的能力）。不同版本行为可能不同，备份时最稳妥的做法是把游戏目录和 `Tyranor` 目录整个复制出来，不依赖单一位置。

## 文本速度、自动播放与跳过

这几项都在菜单的设置里：

- **文字速度**：默认节奏偏慢就调到最快，阅读习惯自己定；
- **自动播放**：自动推进对话，挂机看剧情时用；
- **跳过已读**：二周目或回溯剧情时用已读快进，比三指滑动快得多。

## 画面与声音

- **全屏**：设置里可以隐藏系统状态栏，画面完整不被刘海和状态栏挤占；
- **文本框与字体**：部分版本支持调整文本框透明度，按自己看得清为准；
- **换背景图**：主界面点「其他」→「tyranor 设置」→ 打开「启用背景图片」→ 点「背景图片」导入手机里的图片，确认即可；
- **没有声音时**：先退出模拟器整个重进一次，多数偶发无声重进就好；还不行看 [常见问题排查.md](常见问题排查.md) 的声音段落。
