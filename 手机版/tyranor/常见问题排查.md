# Tyranor 常见问题排查

> 本篇按现象归拢 Tyranor 用起来最常见的故障：游戏不识别、黑屏闪退、卡顿、没声音、补丁怎么放，先对症状再动手。

## 先定位：问题出在哪一环

从装好到玩上，链路是「安装包 → 存储权限 → 游戏目录 → 引擎运行」，故障也按这条链排查：

| 环节 | 典型症状 | 对应段落 |
| --- | --- | --- |
| 权限 | 扫描不到任何游戏 | 游戏不显示 / 不识别 |
| 游戏目录 | 列表有图标但启动失败 | 黑屏 / 闪退 |
| 引擎兼容 | 能进游戏但卡、花屏 | 卡顿与画面异常 |

## 游戏不显示 / 不识别

1. 确认存储权限给全：系统设置 → 应用 → Tyranor → 权限，把「管理所有文件」级别的权限打开；
2. 核对游戏目录里有没有引擎标志文件（`data.xp3`、`root.pfs`、`nscript.dat` 等），判断方法见 [支持的引擎与游戏格式.md](支持的引擎与游戏格式.md)；
3. 游戏路径别套太深的中文与特殊符号，先拿一个英文短路径的游戏试，能识别再放其他的；
4. 用底部「添加」手动指一次路径，别只依赖自动扫描。

## 黑屏 / 闪退

按命中率从高到低排查：

1. **游戏是 PC 原版而不是手机版** —— 这是最常见的黑屏原因。PC 原版目录直接进模拟器，多数停在黑屏或开场就退出；去找这个游戏的手机版资源或手机补丁；
2. **关自动补丁、开兼容模式**：有用户反馈在新系统（Android 14 一类）上「进游戏就闪退」，关掉自动补丁再配合兼容模式后解决 —— 注意顺序是**扫描游戏之前**先关自动补丁，具体步骤见 [自动补丁与兼容模式设置.md](自动补丁与兼容模式设置.md)；
3. **资源本身不完整**：压缩包没解压完、`.xp3` 文件损坏，重新解压一次；
4. **系统与版本不匹配**：老安卓系统对新引擎兼容差，新系统又可能踩上面第 2 条；先拿别的游戏验证模拟器本身正常，再判断是不是这个游戏的问题。

## 卡顿与画面异常

- 在设置里开启对应引擎（尤其 Artemis 系游戏）的兼容模式，社区反馈这一招对卡顿最有效；
- 读取频繁或加载异常的，试试打开「慢速加载」—— 稳定性换速度，而且它需要预留比游戏体积更大的剩余存储空间；
- 清理手机存储，留出比游戏体积更大的剩余空间；
- 有分辨率类选项的话降一档，低端机优先保流畅。

## 没有声音 / 声音异常

1. 先退出模拟器整个重进一次，多数偶发无声重进就好；
2. 检查游戏目录里的音频文件是否完整，怀疑损坏就重新解压；
3. 换外放试一次，排除蓝牙耳机的编解码问题。

## 汉化补丁 / 手机补丁怎么用

视觉小说的补丁（汉化补丁、手机适配补丁）大多是「把文件覆盖进游戏目录」的用法：

1. 把补丁压缩包解压，得到补丁文件；
2. 复制进游戏的原目录，遇到同名文件就覆盖 —— 注意别多套一层子文件夹，补丁文件要和游戏文件在同一层；
3. 重启模拟器再启动游戏。

补丁生效与否跟游戏版本有关：补丁按某个版本的游戏制作，版本对不上会乱码、黑屏甚至闪退。版本不对时，先核对补丁说明里标注的适用版本，再决定是换游戏版本还是换补丁版本。
