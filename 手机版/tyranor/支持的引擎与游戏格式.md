## 支持的引擎一览

Tyranor 整合了多套视觉小说引擎的运行环境，一份安装包能认多类游戏。按社区整理的资料，主要覆盖：

| 引擎 | 游戏目录里的标志文件 | 说明 |
| --- | --- | --- |
| KRKR（吉里吉里 / Kirikiri） | `data.xp3` 或其他 `.xp3` 文件 | 最主要的支持对象，日式 AVG 里占比最高 |
| Artemis Engine | `root.pfs` 或其他 `.pfs` 文件 | 较新的 AVG 常用引擎 |
| RPG Maker / RPG Maker MZ | `js/rpg_core.js`、`js/rmmz_core.js` 一类文件 | 部分作品在手机上性能消耗偏大 |
| Tyrano（TyranoScript / TyranoBuilder） | `index.html` 加 `tyrano/` 目录 | 网页技术做的视觉小说 |
| VN Maker | 以实际目录为准 | — |
| ONScripter | `nscript.dat` 或 `.nsa` 文件 | 2.3.4 版本更新正式加入，支持扫描 SD 卡内的 ONS 游戏 |

「标志文件」是判断引擎最直接的办法：打开游戏文件夹，看到哪类文件就按哪类引擎对待。个别引擎的目录写法以实际游戏为准，认不出来时按 [常见问题排查.md](常见问题排查.md) 的思路排查。

## 怎么判断手上的游戏能不能跑

建议按这个顺序判断，别一上来就试：

1. **看目录**：解压后对照上表找标志文件。一类都对不上，大概率不是模拟器支持的引擎（比如 Ren'Py、Unity 或普通 Windows 程序），换资源比换设置有用；
2. **看是不是手机版资源**：同一款游戏的资源分 PC 版和手机版，模拟器对 PC 原版的兼容有限。社区反馈里能稳定跑的多是带 `data.xp3` / `root.pfs` 的手机版文件，或打过手机补丁的目录；
3. **实跑验证**：放进目录让模拟器扫一遍，列表里出现图标再启动。卡在哪一步，对照 [常见问题排查.md](常见问题排查.md) 处理。

## 同一游戏的不同打包怎么挑

找资源时会遇到同一款游戏的不同打包：有的带完整语音、有的是精简版、有的已内置手机补丁。挑的时候按这个优先级：

- 目录结构完整，上表里的标志文件都在；
- 标明「安卓」「手机版」「移动版」字样的打包；
- 汉化补丁与游戏版本匹配 —— 补丁是按某个版本的游戏做的，版本不对会乱码或黑屏（补丁用法见 [常见问题排查.md](常见问题排查.md)）。

## 引擎支持不等于百分百能玩

对照上表找齐了标志文件，也只是「可以试」。实际能不能玩还取决于：资源是不是为移动端准备过、游戏本身有没有超出手机性能的演出（高清立绘、大量特效）、模拟器版本与游戏的匹配度。遇到「格式都对但就是跑不起来」的游戏，把问题归到资源而不是设置，往往更快解决。

装好模拟器还没放游戏的，先看 [添加游戏方法详解.md](添加游戏方法详解.md)；想先了解安装与获取的，看 [下载与安装教程.md](下载与安装教程.md)。
