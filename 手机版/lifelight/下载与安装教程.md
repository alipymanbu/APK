## 一、安装包从哪里拿

这是一只安卓 APK 安装包，网盘里那份就是下面核对信息对应的版本：

**lifelight 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/ddc2cdc700ed](https://pan.quark.cn/s/ddc2cdc700ed)

打开分享链接 → 转存到自己的网盘 → 在网盘里下载到手机（或先下到电脑再传到手机）。安装包约 66.81 MB，建议在 Wi-Fi 下下载。

## 二、下载前先核对这几个信息

核对 MD5（可选）：装一个 MD5 校验工具，对下载到的 `.apk` 计算校验值，与上表一致即说明文件完整、没有下错。

注意：网上各下载站标的是官方更新版本（如 1.3.4、1.5.x 等），与网盘里这份 1.4.0 不是同一个包，功能说明也以官方当前发布页为准，别拿两处的版本号互相印证。

## 三、安装步骤

1. 在手机浏览器或夸克网盘里把 `.apk` 文件下载到本机；
2. 点击文件开始安装，系统若弹出「禁止安装来自此来源的应用」，这是在拦「未知来源安装」，按提示进入该来源（如文件管理器、夸克）的设置，允许一次即可；
3. 等安装完成，打开应用；
4. 首次启动会先弹隐私协议，点同意后进入引导页（可点继续或跳过）。

装完可以把安装包删掉，下次更新版本时重新从网盘取新包即可。

## 四、首次启动与登录

1. 同意隐私协议；
2. 进入引导页，按提示继续或跳过；
3. 用**手机号 + 验证码**登录；
4. 给自己取一个名字；
5. 写几句当下的感悟；
6. 选择一个专属 AI 朋友，之后就能开始记录和对话了。

登录需要联网，验证码一般几秒内到达；收不到先看手机信号与短信拦截，再核对手机号有没有输错。

## 五、装不上或打不开时

| 现象 | 处理 |
| --- | --- |
| 提示「解析包时出现问题」 | 文件没下完整，重新下载；或核对 MD5 是否一致 |
| 提示「应用未安装」/ 版本冲突 | 手机上已有同包名旧版本且签名不一致，先卸载旧版再装 |
| 提示系统版本过低 | 手机安卓版本低于 5.2，此包无法安装 |
| 安装后闪退 | 清一次应用缓存再打开；仍闪退见[常见问题与故障排查.md](常见问题与故障排查.md) |
| 空间不足 | 清出至少 200 MB 可用空间再装（包体 66.81 M，解压后更大） |

安装、登录都正常后，接着看[心光怎么用与三大界面说明.md](心光怎么用与三大界面说明.md)，先熟悉「今天 / 画廊 / 洞见」三个界面。
