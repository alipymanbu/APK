## 一、先分清你手里的是哪个包

心光两个平台都在维护，但**不是同一个安装包、也不是同一套版本号**。对照如下（iOS 侧数据取自 App Store 页面，安卓侧取自网盘里那份包，截至 2026-09，均以官方当时显示为准）：

| 项目 | 安卓版（网盘这份） | iOS 版 |
| --- | --- | --- |
| 版本 | 1.4.0 | App Store 显示为当时的最新版（版本号体系与安卓不同） |
| 包体大小 | 66.81 M | 89.7 MB（iPhone，另有 Mac 版 121.9 MB） |
| 系统要求 | 安卓 5.2 以上 | iOS 16.1 / iPadOS 16.1 / macOS 12 以上 |
| 覆盖设备 | 手机 | iPhone、iPad、Mac、Apple Watch、Apple Vision |
| 云备份 | 未见官方云备份说明 | iCloud 同步与备份 |
| 解锁方式 | 面容 ID 不适用 | 面容 ID 可额外锁应用 |
| 登录/购买 | 手机号登录，应用内购买 | 手机号等登录，App Store 内购 |

**别混装**：`.apk` 只能在安卓上装；iPhone 上装不了 APK，走 App Store。两边的会员也可能不互通（见[会员价格与水晶球获取.md](会员价格与水晶球获取.md)）。

## 二、功能差异实际在哪

1. **备份**：iCloud、面容 ID、多设备（Mac / Watch）联动是苹果侧独有；安卓侧没有查到对应的云备份功能，策略是勤导出（见[换新手机与数据备份导出.md](换新手机与数据备份导出.md)）。
2. **更新节奏**：官方更新日志（如语音转写准确度、「一拍转文」照片转文字、月刊等）先在 iOS 侧发布，安卓版跟进节奏不同——**两个平台看到的功能列表对不上是正常的**，以你所在平台当时的应用内为准。
3. **系统入口**：iOS 的订阅在系统「设置 → 订阅」里管，安卓看支付渠道；改名字、换声音这类入口两边一致，都在洞见界面的水晶球里。

## 三、鸿蒙用户注意

公开报道提到，华为应用市场的鸿蒙版以「**心光Pro**」的名称上架，带桌面卡片、小艺语音等鸿蒙特性——它与本篇讲的安卓 APK **不是同一个包**，功能与价格以华为应用市场当时显示为准。用鸿蒙手机建议优先在应用市场搜，别直接侧载安卓包（部分鸿蒙版本对安卓包的兼容性有限）。

## 四、跨平台迁移能做到什么程度

- **安卓 ↔ iOS 互搬**：没有查到官方提供跨系统迁移工具；记录要靠导出文件中转——从旧系统导出全量数据，再在新系统里导入，图片附件能否完整还原以实测为准，动手前先在旧机上留一份导出备份。
- **苹果设备之间**：同 iCloud 账号自动同步，换 iPhone / iPad 基本无感。
- **安卓换安卓**：登录同一手机号后按应用内导入恢复。

不确定自己属于哪种情况，先读[下载与安装教程.md](下载与安装教程.md)确认包信息，再按[常见问题与故障排查.md](常见问题与故障排查.md)逐条排查。
