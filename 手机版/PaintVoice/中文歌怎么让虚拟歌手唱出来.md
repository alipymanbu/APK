PaintVoice 的歌词框只认日语音节，直接填汉字是唱不出来的。这一篇把这条规则讲清楚，并给出把中文词转写成假名的完整做法，以及这么做会失去什么、哪些字注定唱不准。

## 一、先记住两条规则

1. **填的是发音，不是汉字。** 官方给的例子是「こんにちは」要按发音写成「こんにちわ」——连日语里都要求按「读出来的音」写，汉字当然更不认。
2. **一个音符唱一个音节**，按音符从左到右的顺序逐个取用。字和音符是一对一配上去的，不存在「一个字落在某个音符上」这种绑定。

这两条决定了后面所有做法：你要做的事，本质上是**把想唱的字，翻译成一串日语音节**。

## 二、日语歌：照抄假名就行

这是最省事的情况：

- 找一份这首歌的**假名歌词**（很多歌词站点、原曲 PV 都给假名版本），逐字照抄，一个假名对一个音符。
- 遇到**长音符「ー」**：不要单独填一个字，把前一个音符在钢琴卷帘上拉长即可。
- 遇到**促音「っ」**：同样不占独立音符，把后一个音的起步稍微留一点空档，听起来就是顿一下。
- 遇到**拨音「ん」**：它自成一个音节，正常占一个音符。

## 三、中文歌：把每个字的读音拆成日语音节

想让虚拟歌手唱中文词，做法是给歌词做一次「转写」。步骤如下：

1. 写出每个字的**拼音**；
2. 把拼音拆成**声母 + 韵母**，分别找最接近的日语假名；
3. 一个音节对一个音符，写进歌词框。

几条好用的对应原则：

| 情况 | 处理方式 | 例子 |
| --- | --- | --- |
| 单韵母 | 直接换成对应假名 | a → あ、i → い、u → う、e → え、o → お |
| 复韵母 | **拆成两个音节、占两个音符** | ai → あい、ao → あお、ou → おう、ei → えい |
| 带鼻音韵尾 | 用拨音 ん 收尾 | an → あん、in → いん、en → えん |
| 声母 | 换成最接近的假名行 | sh → し行、zh → じ行、ch → ち行、f → ふ行 |

举一个整句的例子，「我爱你」可以写成 **うぉ あい に**，也就是三个音符：wo / ai / ni。

### 做这件事之前要知道的代价

- **声调表达不了**。日语假名只有高低，没有汉语的四声，所以「妈 / 麻 / 马 / 骂」这类靠声调区分的字会没法区分。
- **唱出来是日语腔的中文**。这是把音译成日语音节的必然结果，不是设置问题。
- **没有唯一正确答案**。同一个字可以落到哪几个假名，不同人对音准的判断不一样，按实际听感微调就好——反正改一个音节只要改一个音符。

## 四、英文和外来语：用假名拼近似读音

英文单词的处理方式与中文类似：把读音拆成日语音节，用平假名拼出来，一个音节对一个音符。整句英文歌词通常要拆得比看起来更多的音符，别指望一个音符能唱完一个单词。

## 五、什么时候该回头检查

- **音符增删之后**：歌词是按顺序遍历的，中间多一个音符或少一个音符，后面的词会整体串位，必须回头对一遍。
- **听着不对但看不出错**：先怀疑某个字落的音节不对，逐句用部分播放试，比整首听完再找要快。
