这一篇从一张空白曲目开始：先在钢琴卷帘上点出音符，再按顺序把歌词配上，最后播放听效果。中间涉及的工具、轨道和节奏选项，按你实际会遇到的顺序依次说明。

## 一、从新建一首曲目开始

打开应用，首页会列出你已有的曲目。菜单里的新建项用于开一首空曲目，点进去就是编辑画面。编辑画面里要认的三样东西：

1. **钢琴卷帘网格**：横轴是时间（按小节和拍分格），纵轴是音高，你的音符都画在这里；
2. **一排工具按钮**：笔、橡皮、选择范围、播放等，工具决定你手指划过去时是「放音符」「擦音符」还是「选中一段」；
3. **右上角的轨道与音色入口**：用来切换当前正在编辑的是哪条轨道、用的是哪种乐器或歌声。

## 二、点出音符

- 保持笔工具，在网格里**向右拖或点一下**，就会生成一个音符，长度等于你划过的格数。
- 同一个笔工具**向左划**就能把音符擦掉，不必切到橡皮再切回来。
- 音符画出来只是「多高、多长、从哪一拍开始」，唱什么字由歌词决定，歌怎么唱由人声轨决定。
- 和音直接在同一拍上叠加多个不同音高的音符即可。

## 三、加轨道、换乐器

- 从右上角的入口切换当前轨道的音色：先写钢琴、再切到鼓组写一遍，就得到了两条互不干扰的轨道，播放时同时出声。
- 不是当前轨道的音符会以半透明显示，方便你照着贝斯对鼓点、照着主旋律配和声。
- 一条轨道写满一段后，用播放把整段听一遍再往下写，比一次写完整首再听要省事。

## 四、填歌词

这一步是本应用和普通打谱软件最大的区别，也是新手最容易卡住的地方：

- 歌词**不写在音符上，而是按「音符从左到右的顺序」逐个对应**。所以你先填词、后写音符，或者先写音符、后填词，都可以。
- **填的是发音，不是汉字。** 官方给出的例子是「こんにちは」要按发音写成「こんにちわ」。也就是说，歌词框里要输的是日语假名（平假名）。
- 这意味着**直接用中文歌词汉字是唱不出来的**：想唱中文词，得先把每个字的读音转成对应的日语音节再填进去，唱出来也会是日语腔的发音。想唱得像原生中文，这套方案并不合适。
- 歌词中途改起来很快，边听边把不满意的字换掉即可。
- 想唱中文歌词，得先把每个字的读音转成对应的日语音节再填，具体做法见 [中文歌怎么让虚拟歌手唱出来.md](中文歌怎么让虚拟歌手唱出来.md)。

## 五、批量改音高与复制段落

- 用**选择范围工具**（按钮形状是一串小方点）框住一段，可以整体升降音高。
- 升降按**半音**计：例如把「ド」升到「ミ」，是升 4 个半音。
- 范围选择是按列（拍）划分的，跨音高选择有它的脾气，多试两次就顺了；改整段调性时它能省下大量重复劳动。
- 一个小节写好之后复制粘贴，后面复用整小节，是常见做法。

## 六、节奏与长度的边界

写复杂一点的曲子前，先知道这款应用允许的上下限：

| 项目 | 范围 |
| --- | --- |
| 乐器轨道 | 16 条 |
| 人声轨道 | 数量随版本不同（较早版本 4 条，较新版本 8 条），以应用内显示为准 |
| 最短音符 | 128 分音符 |
| 连音 | 三连音、五连音、六连音 |
| 拍子 | 3/4 或 4/4 |
| 曲目长度 | 最长 1024 小节 |
| 速度 | BPM 30 ～ 240 |
| 撤销 | 最多 10 步 |

## 七、把声音放出来

点播放，乐器轨道会直接出声。人声轨道要能唱，前提是它已经选了可用的歌声：自带歌声可以直接用，想换成网上的虚拟歌手，先看 [导入UTAU音源让手机唱歌.md](导入UTAU音源让手机唱歌.md)。

唱出来但觉得太平、没有感情，接着看 [歌声调声怎么做.md](歌声调声怎么做.md)。
