## 一、登录：手机号 + 验证码

Pubby 用手机号注册，第一次打开的流程是：

1. 同意用户协议与隐私政策（不勾选无法继续）。
2. 输入手机号，勾选相关协议后点「获取验证码」。
3. 把收到的短信验证码填进去，完成登录。

没装应用的先看[下载与安装教程](下载与安装教程.md)。验证码收不到是最常见的卡点：确认号码没填错、短信没被系统当营销短信拦截，过几分钟再点一次重发即可。

换手机后用同一个手机号重新登录，账号资料会跟过来；不再用的号码建议先在应用里换成新号，否则找回账号会麻烦。

## 二、资料填写：哪些字段值得认真填

登录后系统会让你完善个人资料。这份资料直接决定别人看到你的第一眼，也是后续推荐的依据之一：

| 字段 | 建议 |
| --- | --- |
| 头像 | 用真实清晰的照片；官方社区导向是「真实交友」，真人照更容易让对方建立信任 |
| 昵称 | 正常起名即可，带广告、导流性质的昵称容易被处理 |
| 兴趣标签 | 挑你真的会聊的填，匹配和「同频」推荐主要靠这些标签对上 |
| 个人简介 | 写清你是谁、想认识什么样的人，比空白强得多 |
| 交友期望 | 按真实意图选，选得越明确，系统推送的对象越对得上 |

应用内提供真人认证，入口和流程以你应用里的实际显示为准；认证过和没认证的账号在可信度展示上不一样，介意对方是不是真人的人自己也会看这一项。

## 三、角色偏好是什么

Pubby 的一个特点是把「关系模式」做成了可选角色，注册时要你选一次偏好：

- **经典角色**：恋人、CP、闺蜜、知己。
- **进阶角色**：爹系男友、依恋系女友、Puppy、Brat 等。

选哪个是按你自己的意愿来的；系统会结合你的资料、兴趣标签和角色偏好来推送契合的人。官方对社区的基本口径是：一切互动建立在尊重、礼貌、安全、真实意愿和双方同意之上——越界的言行在哪个角色设定下都会被处理。

## 四、填完之后

资料和偏好设置完，就可以开始找人聊天了：推荐列表、同城和标签筛选怎么用，见[匹配聊天与动态社区玩法](匹配聊天与动态社区玩法.md)；想先把自己的资料可见范围、在线状态收紧一遍再开始聊，见[隐私设置与防骚扰方法](隐私设置与防骚扰方法.md)。
