## 一、开始一段对话

打开应用，进入对话界面，选一个已经下载好的模型，输入消息发送即可。回复速度由两件事决定：模型参数规模和手机性能，同一个模型在不同手机上速度可能差几倍。选模型的思路见[模型怎么选和手机配置要求.md](模型怎么选和手机配置要求.md)。

## 二、离线可用范围

模型下载到本地之后，对话全程在手机上完成，不需要网络——飞行模式下照常能用。前提是模型已经下载完：没下载模型时，你连第一次对话都开始不了。换句话说，联网只发生在下载模型那一步。

## 三、文本之外：图片、语音、文生图

MNN Chat 支持的不只是文字对话，这些能力由不同类型的模型承担，在模型市场里按需下载：

| 能力 | 你能做什么 |
| --- | --- |
| 文本对话 | 常规问答、写作、翻译等，对应文本模型 |
| 图像理解 | 发一张图片，让模型描述或回答图中内容 |
| 语音理解 | 把你说的话转成文字再对话 |
| 文本生成图像 | 输入描述生成图片（对应扩散类模型） |

一个模型通常只覆盖其中一两种能力：想用图像理解就下载支持视觉的模型，想生成图片就下载文生图模型，具体分类与说明以应用内模型市场显示为准。

## 四、聊天记录在哪

历史会话在侧边栏里查看和回顾。想清空重来，删除对应会话即可，入口位置以应用内为准。

## 五、调参数：让回复更稳定或更多样

设置里有采样相关的选项（如温度 temperature、top_k、top_p、重复惩罚等，具体以你手上版本的设置页为准）。简单记法：想让回答更收敛、少跳脱，把温度调低；想要更有发散性的草稿类文本，适当调高。
