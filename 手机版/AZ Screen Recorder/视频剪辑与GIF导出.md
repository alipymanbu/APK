## 一、从哪进剪辑器

录完的视频会出现在应用主界面（也是应用的文件列表页）里，点开一段视频，下面的操作条里有编辑入口；列表里长按条目可以选中多段做批量处理。不用把视频导出去再找别的应用。

## 二、剪辑器能做的八件事

| 操作 | 适合的场景 | 用法要点 |
| --- | --- | --- |
| 裁剪首尾 | 去掉开头点录制的手忙脚乱和结尾收手机的动作 | 拖两端滑块定出入点 |
| 去除中间段 | 录制中途接了个电话、切出去查了个东西 | 选中中段删除，前后自动接上 |
| 合并多段 | 一个教程分几次录的 | 选多段按顺序拼成一条 |
| 加背景音乐 | 游戏录像配 BGM、vlog 配乐 | 音量可以和原声分开调 |
| 加字幕 | 教程里标步骤 | 手动逐条打，适合字幕不多的片子 |
| 提取帧 | 从录像里抠一张图当封面 | 导出成静态图片 |
| 裁切 / 旋转 | 竖屏录像发横版平台（或反过来） | 裁画面边、转 90 度都在这 |
| 压缩 | 存不动了但舍不得删 | 牺牲一点画质换空间，压缩前的原片建议先备份 |

## 三、转 GIF 的两条路

1. **录制时就选 GIF 输出**：悬浮控制里有 GIF 模式，录出来直接是动图，适合几秒钟的短演示。
2. **先录视频再转**：常规录像录完，在剪辑器里选转 GIF，再截取片段。这样素材还在，一次录制可以出视频和 GIF 两个版本。

GIF 只适合几秒到十几秒的短内容：超过半分钟的动作，转出来的 GIF 体积会大到没法发，不如直接发视频。

## 四、顺手能用的截图功能

悬浮控制里的相机图标就是截图：点一下存一张，应用里的图片编辑还能把多张截图自动拼成一张长图、给敏感区域打马赛克、加文字箭头。录屏之外的小需求基本不用再装第二个应用。

录完发现没声音或声音不对，别急着剪辑，先去 [录屏没有声音怎么办.md](录屏没有声音怎么办.md) 确认音轨问题。
