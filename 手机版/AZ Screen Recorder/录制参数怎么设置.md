## 一、先看懂三个参数的关系

分辨率决定画面尺寸，帧率决定流畅度，码率决定这画面以多大信息量写进文件。三者不是互相独立的：码率跟不上分辨率和帧率，画质会糊；码率给太高，文件会大得没必要。

## 二、分辨率 / 帧率 / 码率对照

下面是常用组合，官方标称的画质上限为 1080p、60 FPS、12 Mbps（更高档位如 2K、4K 只在部分机型上可选）：

| 用途 | 建议组合 | 说明 |
| --- | --- | --- |
| 游戏录制，要发平台 | 1080p / 60fps / 12Mbps | 上限组合，文件也最大 |
| 游戏录制，普通机型 | 720p / 30fps / 8Mbps | 中端机不卡顿的稳妥选择 |
| 教程、操作演示 | 1080p / 30fps / 8Mbps | 画面文字清晰，体积可控 |
| 只是随手记录 | 默认即可 | 改参数的收益不大 |

低配机把参数拉满的典型症状是录制卡顿、成片掉帧——先降帧率，再降分辨率；降完还卡，去 [录制中断与卡顿怎么解决.md](录制中断与卡顿怎么解决.md) 看后台与发热的排查。

## 三、音频来源：录之前必须想清楚

设置里有两条音轨来源，开录前选对，比事后补救省事得多：

- **麦克风**：录你嘴里说的话，适合教程解说、游戏实况配音。
- **内部音频**：录手机自己发出的声音（游戏音效、视频原声）。这条路只有 **Android 10 及以上**的系统支持；另外一部分应用（主要是视频、音乐类）会主动屏蔽被录屏采集，这种情况即使设置全对也录不到声音。

两条路的排查细节都写在 [录屏没有声音怎么办.md](录屏没有声音怎么办.md) 里。

## 四、几个影响体验的控制项

| 设置项 | 在哪用 | 建议 |
| --- | --- | --- |
| 暂停 / 恢复 | 录制中点悬浮按钮或通知栏 | 长录像分几段录，比后期剪掉中间废段省事 |
| 倒计时开始 | 设置里的定时相关选项（以你的版本实际显示为准） | 给自己留点按完开始再切回游戏的时间 |
| 摇一摇停止 | 设置里开 | 手腾不出来时收尾用；容易误触发的话就别开 |
| 显示屏幕触摸点 | 系统开发者选项 + 应用内开关 | 做教程时强烈建议开，观众看得清你点了哪 |
| 录制方向 | 竖屏 / 横屏 | 跟着要录的内容走，游戏中途别转 |

## 五、保存位置

设置里可以选录好的文件存到手机存储还是外置 SD 卡。录长视频前看一眼剩余空间：1080p/60fps 下十分钟的录像能上 1 GB，别录到一半写满了。

录完的成片直接在应用内就能裁剪、合并、转 GIF，操作见 [视频剪辑与GIF导出.md](视频剪辑与GIF导出.md)。
