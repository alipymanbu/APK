## 一、文件管理器的结构

打开应用后的首页就是文件管理器，常用位置：

| 位置 | 用途 |
| --- | --- |
| 文档标签 | 你的 PDF、笔记和文件夹都在这 |
| 档案标签 | 访问手机本机存储和已连接的云盘（安卓从这导入文件） |
| 垃圾 | 删掉的东西先放这里，可恢复或彻底删除 |
| 最近使用 / 我的最爱 | 最多显示 10 条，常用文档可以收藏进来 |
| 全局搜索框 | 搜文档标题，也能搜正文和文本框里的文字 |
| 左下角设定图标 | 备份、恢复、应用版本、数据管理都在这 |

## 二、把 PDF 弄进应用

安卓上有两条路：

1. **本机文件**：文件管理器切到「档案」标签，浏览手机存储，找到 PDF 导入；
2. **云盘**：同样在「档案」里访问云盘目录取文件。前提是手机上装了对应云盘的客户端并用同一账号登录，否则列表里看不到云盘内容。

导入成功的文件会进到一个自动新建的「Download」文件夹里，之后再挪到你想放的目录即可。新建空白笔记走另一个入口：文件管理器右下角的加号快捷菜单 → 新笔记，选封面和纸张模板（空白 / 横线 / 方格等），写完自动保存。

## 三、连接云盘

Flexcil 支持连接主流网盘与 WebDAV：Google Drive、Dropbox、OneDrive、Box 都有入口，WebDAV 在支持列表内（以官方支持页面为准）。连接入口在文件管理器的快捷菜单或设置里。

连云盘的两个实际用途：

- 直接从云盘里取 PDF 来标注，不用先下到本机；
- 把导出的备份文件存到云盘，换机时再从云盘取回。

## 四、备份与恢复（换机必看）

Flexcil 的完整备份是一个 `.flex` 文件，备份和恢复都从「设定 → 备份」进（旧版 Flexcil 1 里叫「备份与恢复」）：

1. 点设定图标 → 进入备份菜单 → 点备份；
2. 选择要备份的文档或文件夹，生成 `.flex` 备份文件；
3. 选择保存位置：云盘、邮件、本机均可；
4. 新设备上把 `.flex` 文件弄到手机里，进「备份 → 恢复」，选中文件执行恢复。

**两个容易踩的坑：**

- **只备份 PDF 或只备份笔记，两者之间的参考链接会丢失**。要完整搬家，备份时把相关文档都选上；
- 用「导出 PDF」的方式搬文件不算备份：导出会丢参考链接，部分批注也可能出问题，只适合把成品发给别人看。

备份、恢复报错的排查见 [常见问题与排查.md](常见问题与排查.md)；**换手机 / 迁到 Flexcil 2 的完整步骤**单写了一篇：[换手机怎么迁移笔记.md](换手机怎么迁移笔记.md)，本节只管备份恢复本身。

## 五、删除与整理

- 长按文件进入编辑模式，可多选后删除、移动、导出；
- 误删的文件在「垃圾」标签里恢复；
- 文件夹可以改颜色、改名，笔记可以换封面和模板；
- 导出时可以选「原始 PDF」或包含手写批注的版本，免费版导出会带水印（以应用内当前显示为准）。

文件都备好之后，回到 [PDF批注与笔记技巧.md](PDF批注与笔记技巧.md) 看怎么用起来；刚装好应用的话从 [下载与安装教程.md](下载与安装教程.md) 开始。
