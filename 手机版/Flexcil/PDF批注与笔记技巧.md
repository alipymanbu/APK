## 一、弹出式笔记：边看边记的基本盘

其他阅读器做「边看边记」通常要靠系统分屏，Flexcil 的做法是在应用内弹出一个浮层笔记本：

1. 打开 PDF，三指上滑（或点工具栏上的文档图标）打开弹出式笔记；
2. 浮层可以移动、缩放，PDF 该翻页翻页，笔记该写写；
3. 选中 PDF 里的文字或图片，直接拖进浮层就完成摘录；
4. 再点浮层的文档图标可以收起。

上课、读论文时这一套基本替代了「电脑看资料 + 本子做笔记」的组合。

## 二、参考链接：笔记里的内容能跳回原文

这是 Flexcil 区别于一般笔记应用的一点：

- 你从 PDF 复制、截取到笔记里的每一段内容，默认都带一条**参考链接**；
- 之后在笔记里点这条内容，会跳回 PDF 里的原始位置；
- 文档阅读器侧边菜单里能看全文档的批注列表和引用列表，复习时按清单回溯很方便。

注意（对应旧版 Flexcil 1）：单独备份 PDF 或笔记其中一者，这层链接会丢，备份时两个都要带上，见 [文件管理与云备份.md](文件管理与云备份.md)。

## 三、批注工具清单

| 工具 | 用法要点 |
| --- | --- |
| 荧光笔 | 有方头/圆头两种，不会把字糊掉；放大后笔迹是矢量，边缘清晰 |
| 钢笔 / 点线笔 / 直线笔 | 直线笔配合尺子画线，点线笔适合做列表符号 |
| 形状工具 | 画框、画箭头，自动整形 |
| 文本框 / 图片 | 在 PDF 上插入打字内容和插图，可用套索工具整体选中移动 |
| 便利贴 | 与手写批注分开的便签，适合写备注 |
| 遮罩笔 | 把原文内容盖住做自测，点开核对答案，背单词、背知识点用 |

付费版（Flexcil Standard）比免费版多出更多笔色与笔槽、笔记封面模板等，边界清单见 [常见问题与排查.md](常见问题与排查.md)，价格以应用内商店显示为准。

## 四、录音与笔记回放

录音和手写是同步的：

1. 打开文档里的录音按钮开始录（需要麦克风权限）；
2. 录音期间你写下的每一笔都记住了时间点；
3. 回放时点笔记上的字迹，录音会跳到写那一笔的时刻。

适合上课跟着老师记：回去复习时哪里没听懂，点一下当时写的那几个字就能重听。

## 五、多页视图与页面整理

- 阅读时可选**单页 / 2 页 / 4 页**视图，横屏看 2 页接近纸质书摊开的效果，另有全屏和纵向滚动模式；
- 长按文档进入页面管理器后，可以复制页、把某一页移动到另一个 PDF、在不同文档间复制粘贴页面；
- PDF 的**大纲（目录）与书签**也能在应用内编辑，改完的结构跟着文档走；
- **合并多个 PDF** 属于付费功能，操作入口在文件管理器，见 [文件管理与云备份.md](文件管理与云备份.md)。

手势怎么把这些动作串起来（选字、截取、撤销的画法）见 [手势操作一览.md](手势操作一览.md)；遇到录音没有声音、链接跳不过去等问题，先查 [常见问题与排查.md](常见问题与排查.md)。
