# Flexcil 手势操作一览

> Flexcil 把选字、截取、删除这类批注动作都做成了「笔手势」：不用先点工具栏再拖选，笔尖一画就出结果。本篇把手势按用途整理成表，方便对着练。

## 一、先分清两种模式

在文档阅读器顶部有「阅读」和「笔手势」两种模式的切换：

- **阅读模式**：手指滑动就是翻页、缩放，笔尖划过去不会产生批注；
- **笔手势模式**：笔尖（或手指）划出的轨迹会被当成手势指令，用来选字、截取、删除。

手势全部失灵时，第一件事就是检查是不是停在阅读模式，具体排查见 [常见问题与排查.md](常见问题与排查.md)。

## 二、手势速查表

| 你想做的事 | 手势 | 说明 |
| --- | --- | --- |
| 给一句话加高亮/下划线 | 在文字上画一条下划线 | 选中后可直接换成高亮色 |
| 选一段文字 | 圈出文字 | 小圈选字、大圈可跨行选 |
| 选一整段 | 在段落两侧画括号（圆括号手势） | 适合整段摘取 |
| 精确选择 | 长按文字 | 弹出选择菜单 |
| 截取一块内容 | 画出 L 形 / 方框 / 长按 | 把文字或图截下来放进笔记 |
| 删除手写内容 | 在字迹上涂抹划掉 | 也可以用橡皮擦工具 |
| 撤销 / 重做 | 两指左滑 / 右滑 | 不同设备略有差异，以应用内置手势说明为准 |
| 打开弹出式笔记 | 三指上滑 | 边看边记的入口 |
| 翻页 | 左右滑动 | 与普通阅读器一致 |

⚠️ 一个重要例外：**扫描版 / 图片版 PDF 没有文字层**，上表里所有「选字」类手势（下划线、圈选、括号）对它无效——官方说明这种情况要先做 OCR；方框、L 形截取手势不受影响。排查思路见 [常见问题与排查.md](常见问题与排查.md)。

## 三、选字之后能干什么

选中文字后菜单里通常有这几类动作：

1. **高亮 / 下划线**：直接给原文加批注；
2. **复制到笔记**：把这段文字拖进弹出式笔记，复制过去的内容会自动带上「参考链接」，之后能从笔记一键跳回原文位置；
3. **词典 / 网页搜索**：查词义或直接搜这句话，读外文文献时常用。

截取的图片同样可以拖进笔记，截图来源会保留链接。

## 四、练手建议

新装好的话，按这个顺序练三分钟就能上手：

1. 打开任意 PDF，确认处于笔手势模式；
2. 用下划线手势划一句话，再用两指左滑撤销；
3. 用方框手势截一小段文字，三指上滑打开弹出式笔记，把它拖进去；
4. 点笔记里刚拖进来的内容，跳回原文，确认参考链接生效。

手势只是入口，批注工具、录音回放这些「选完之后怎么用」的内容在 [PDF批注与笔记技巧.md](PDF批注与笔记技巧.md)；文件从哪来（本地导入或云盘）见 [文件管理与云备份.md](文件管理与云备份.md)。
