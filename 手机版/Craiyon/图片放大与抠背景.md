# 图片放大与抠背景：Craiyon 生成后的加工功能

Craiyon 免费档直出的图分辨率有限，直接拿去发帖或当壁纸常常不够用。生成只是第一步，大图页里还有一排加工入口：放大（Upscale）、抠背景（Remove background）、加动效（Animate）、指令修图（Retouch）。本篇讲每个入口怎么用、什么消耗点数、哪些坑提前避开。

## 一、先分清「生成」和「加工」

两项独立资料口径一致：

- 纯文字生成不消耗编辑点数——免费档无限量，付费档的 Pro 模型走另一套额度；
- 修图（Retouch）和以图生图（把一张图当输入再加工）消耗编辑点数；
- 点数每月刷新，不滚存到下个周期。

省点数的思路随之很简单：先用免费档把描述调到稳定出图（写法见[提示词怎么写.md](提示词怎么写.md)），确定哪张值得用，再花点数加工。

## 二、放大（Upscale）

1. 在九宫格里点开选中的图，进大图页；
2. 选 Upscale，等待处理完成；
3. 处理完再下载，分辨率比直出高一档。

两点提前知道：

- 放大救的是「分辨率不够」，救不了「内容本身画崩」——脸手崩了先重画，别指望放大修好；
- 免费档直出分辨率就是有限的，放大只是在现有档位上提一档；要更高的画质上限，对比见[会员套餐与免费额度.md](会员套餐与免费额度.md)。

## 三、抠背景（Remove background）

- 入口在大图页的加工区，选中后自动识别主体、抠除背景；
- 典型用途：把主体抠出来贴进别的图、做表情包、做封面素材；
- 检索到的资料都把它列为内置功能，对生成的图可用；对上传的照片是否同样支持，以界面当时显示为准。

## 四、加动效（Animate）与指令修图（Retouch）

- Animate：给静态图加简单动效，适合发社交平台的短动态；
- Retouch：用一句话指令做基础修图，消耗编辑点数；
- 部分资料还提到矢量化（vectorise）与分层合成（Studio）入口，属于同一片加工区，以界面为准。

## 五、按需取用

| 你要做什么 | 用哪个 |
| --- | --- |
| 图能用但糊 | Upscale 放大 |
| 想把主体抠出来合成 | Remove background |
| 发个会动的帖子 | Animate |
| 想改图里的局部内容 | Retouch（耗点数） |

加工完的图，下载保存和直出图一致；出图环节本身卡住时，按[生成失败与常见问题.md](生成失败与常见问题.md)排查。
