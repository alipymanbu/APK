Craiyon 的核心动作只有一个：把你写下的一句话描述变成九张图。整个流程不需要注册、不需要付费，从输入到出图通常一分钟上下。本篇把每一步拆开，让你第一次就能把图顺利生成并保存下来。

## 一、主界面就是输入框

打开应用或官网 [craiyon.com](https://www.craiyon.com/)，最显眼的就是提示词输入框。旁边通常还有两个控制项：风格选择和排除词（Exclude elements）输入框。不需要翻菜单，首页填完就能画。

## 二、一次完整生成

1. 在输入框写下想画的内容（写法参考[提示词怎么写.md](提示词怎么写.md)）；
2. 选择风格档：近期资料里出现过「艺术 / 照片 / 动漫 / 插画 / 矢量 / 原图」六档的说法，更早的资料则是「艺术 / 绘画 / 照片 / 无」四档——档位随版本调整，界面以当时显示为准，拿不准就不选；
3. 点 DRAW（生成）按钮；
4. 等待约 45~90 秒，得到 3×3 一组九张图——每一批是同一个描述的九种不同发挥，不是九张一样的图；
5. 出图比例：方形（1:1）所有用户可用，竖版与横版的完整比例选择在付费档——比例不合用就先按方形出，后期自己裁；
6. 也可以上传一张参考图再生成，这属于「以图生图」的加工玩法，消耗编辑点数，规则见[图片放大与抠背景.md](图片放大与抠背景.md)。

## 三、不满意就改了重画

九宫格本身就是批量比稿：

- 全都不行 → 大概率是描述问题，回去改提示词再画；
- 有两张接近 → 保留接近的方向，把描述往那个方向再具体一点；
- 整体对了但有杂元素 → 用排除词去掉，见下一节。

## 四、排除词（Exclude elements）怎么用

排除词是单独的一个输入框，填你不希望在图里出现的东西。官方的用法说明是填「概念」，不是完整句子：

| 你不想要 | 可以填 |
| --- | --- |
| 画面偏蓝 | `blue` |
| 不想出现人 | `people` |
| 对比度太低、发灰 | `low contrast` |
| 海滩图里冒出树 | `trees` |
| 图里长出乱码文字 | `text` |

排除词和正向描述一样作用于整批九张图，改完要重新生成才能看到效果。

## 五、挑图与保存

1. 点九宫格里顺眼的一张，放大查看；
2. 用下载/保存按钮把图存到手机相册；
3. 免费档下载的图带 Craiyon 水印、分辨率有限，需要更高画质或无水印时看[会员套餐与免费额度.md](会员套餐与免费额度.md)；
4. 出图之后还有放大、抠背景、加动效、指令修图这一层加工，入口与点数规则见[图片放大与抠背景.md](图片放大与抠背景.md)。

## 六、等太久或出不来

高峰时段免费用户排在付费用户后面，45 秒到两分钟都算正常范围。超过几分钟没动静、或直接报错，按[生成失败与常见问题.md](生成失败与常见问题.md)排查。
