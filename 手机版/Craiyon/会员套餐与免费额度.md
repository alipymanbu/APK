Craiyon 所有档位都允许把生成的图用于商业用途，免费与付费的差别集中在画质、速度、水印与隐私四件事上。价格信息会过时，本篇只给量级与差别，具体数字以官网为准。

## 一、免费档（Lite）能做什么

- 无限次生成，不需要注册；
- 出图带水印，界面有广告；
- 生成的图默认公开；
- 分辨率有限，可用放大（Upscale）功能改善；
- 商业使用需要注明来源 craiyon.com。

对偶尔画着玩、发社交媒体的人来说，免费档没有硬门槛。

## 二、付费档位买的是什么

官方定价页是 [craiyon.com/pricing](https://www.craiyon.com/pricing)。不同资料检索到的近期口径如下，数字之间有出入，以官网当时显示为准：

| 档位 | 大致价格 | 给你的东西 |
| --- | --- | --- |
| Supporter | 约 5~10 美元/月（多按年计费） | 去广告、去水印、一定额度的 Pro 模型点数（署名口径见[商用与署名注意事项.md](商用与署名注意事项.md)） |
| Professional | 约 20~24 美元/月 | 更多点数、队列优先（有资料记到十几秒出图）、图片默认私密 |
| Ultra | 有资料提到（按年计费） | 点数更多、私密生成、新功能先试 |
| Enterprise | 需联系官方 | 定制模型、批量用量；有 API 接入的宣传口径，也有资料称目前没有面向普通用户的公开 API |

付费档共通的变化：出图更快——免费档一两分钟，付费档有资料记到约 45 秒甚至十几秒；下载无水印高画质；免署名（口径分歧见[商用与署名注意事项.md](商用与署名注意事项.md)）。

## 三、点数（credits）怎么扣

- 放大、抠背景、图像编辑这类「生成之后再加工」的功能消耗点数，普通文生图不消耗；
- 免费档的 Lite 模型不限量，点数用完仍能继续出图，只是用不了 Pro 模型与高级加工；
- 有两项独立资料都提到：点数每月刷新、不滚存到下个计费周期，购买前按实际用量估算；哪些操作耗点数，见[图片放大与抠背景.md](图片放大与抠背景.md)。

## 四、按用途选

| 你的情况 | 建议 |
| --- | --- |
| 偶尔画着玩、发朋友圈 | 免费档够用，接受水印 |
| 经常出图、想直接用图 | Supporter，去水印去广告 |
| 给客户出方案、不想被别人看到 | Professional（图片默认私密） |

## 五、商用与署名

商用是一套按档位变化的规则组合：署名口径（含资料分歧）、图片公开与私密、第三方权利风险，单独成篇讲清了，见[商用与署名注意事项.md](商用与署名注意事项.md)。

遇到排队慢、图崩面这类用起来卡壳的情况，先看[生成失败与常见问题.md](生成失败与常见问题.md)，多数不是档位问题。
