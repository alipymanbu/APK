# AlgerMusicPlayer 怎么登录网易云账号

## 一、哪些功能需要登录

先说清楚登录的边界，再决定要不要折腾：

| 功能 | 不登录 | 登录后 |
| --- | --- | --- |
| 搜索歌曲 / 歌单 / MV | 可用 | 可用 |
| 播放大部分歌曲 | 可用 | 可用 |
| 同步网易云歌单、收藏、播放记录 | 不可用 | 可用 |
| 每日推荐等个性化内容 | 通用内容 | 按你的账号生成 |

账号数据存在网易云那边，换手机、重装应用后重新登录同一账号即可恢复，不需要在应用里做备份。

想离线听歌是另一回事：官方常见问题说明**安卓端暂不支持下载歌曲**，手机上离线听歌走本地音乐扫描这条路，具体见 [下载歌曲离线收听.md](下载歌曲离线收听.md)。

## 二、方式一：扫码登录

5.1.0 版起，扫码登录是登录页的默认首选方式，操作最省事：

1. 打开应用，进**个人中心**（右上角头像入口），点**登录**；
2. 登录页默认就是扫码方式，屏幕上会出现一个二维码；
3. 用另一台设备上装好的**网易云音乐 App**（右上角扫一扫）扫这个二维码；
4. 在网易云 App 里点**确认登录**，回到 AlgerMusicPlayer 等它自动跳转。

注意一个实际限制：一部手机没法用自己的摄像头扫自己屏幕上的二维码。如果你只有一台手机，直接改用下面的 Cookie 或 UID 方式；扫码更适合电脑版、网页版场景。

## 三、方式二：Cookie 登录

Cookie 登录只需要一台设备就能完成：

1. 在电脑浏览器里打开网易云网页版并登录你的账号；
2. 按 `F12` 打开开发者工具，找到 **Application（应用）→ Cookies**，选中网易云的站点；
3. 复制 Cookie 的值（整段，或其中 `MUSIC_U` 这一项的值——以应用内输入框的提示为准）；
4. 回到应用的登录页，切换到 **Cookie 登录**，把复制的内容粘贴进去，点登录。

Cookie 有有效期，过期后需要重新取一次；取 Cookie 时账号还登录在浏览器里就行，不需要退出。Cookie 登录是 4.9.0 版加入的功能，之后还加了自动获取等配套管理设置，入口以应用内实际显示为准。

## 四、方式三：UID 登录

UID 是你的网易云数字 ID：

1. 在网易云音乐 App 里进入**我的 → 个人主页**，通过分享自己的主页拿到主页链接，链接里 `id=` 后面那串数字就是 UID；
2. 回到应用的登录页，切换到 **UID 登录**，输入这串数字；
3. 提交后等待应用加载账号信息。

UID 方式能同步哪些内容，以应用内的实际表现为准；如果发现歌单或收藏不完整，换扫码或 Cookie 方式再试。

## 五、登录遇到问题

登录页转圈不返回、Cookie 提示失效、扫码后没反应，这些情况的排查思路整理在 [常见问题解答.md](常见问题解答.md) 的登录一节，先去那里对照处理。
