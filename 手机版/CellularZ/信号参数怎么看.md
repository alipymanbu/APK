## 一、先打开哪一页

装好后打开应用，主界面顶部是 SLOT1、SLOT2 两张卡槽卡片，分别对应卡槽一和卡槽二里的 SIM 卡；单卡机看正在用的那张。官方按「卡槽 → SIM → 运营商 → 小区及邻区」的层级从上往下排列信息，找某项参数前先想它属于哪一层。往下翻到 Cell Params（小区参数）区，信号质量数值都集中在这里；界面还有 NR-FREQ 一栏，显示当前 5G 的具体频率，数值旁边带动态曲线，适合边走边观察变化。

要看 4G/5G 的数据信号，先把 WiFi 关掉、开着移动数据再看，读到的才是蜂窝信号；连着 WiFi 时看的是 WiFi 那一套数值。

## 二、先记住一条：dBm 绝对值越小越好

信号强度的单位是 dBm，通常是负数，**绝对值越小信号越好**：-65 比 -95 好。以 RSRP 为例的常用参考口径如下（各家划分略有差异，以运营商现网与设备显示为准）：

| RSRP（dBm） | 含义 |
| --- | --- |
| -80 以上（含） | 信号很好 |
| -80 ～ -90 | 良好 |
| -90 ～ -100 | 一般，室内开始吃力 |
| -100 ～ -110 | 差，容易断流、掉话 |
| -110 以下 | 接近无服务 |

系统自带页面显示的 asu 值可以换算回 dBm：LTE 与 5G 下 `asu = dBm + 140`；WCDMA 与 GSM 下 `asu = (dBm + 113) / 2`。比如 SIM 卡状态页显示 asu 45，对应的 RSRP 就是 -95 dBm。

## 三、四个主要参数

| 参数 | 全称 | 含义 | 怎么判断 |
| --- | --- | --- | --- |
| RSRP | 参考信号接收功率 | 收到的服务小区参考信号功率，范围约 -44 ～ -140 | 主要看它，越大越好 |
| RSRQ | 参考信号接收质量 | RSRP 与 RSSI 的比值，范围约 -3 ～ -19.5 | 越大越好，用于比较小区质量 |
| RSSI | 接收信号强度指示 | 整个频带收到的总强度，含干扰在内 | 越接近 0 越强；持续过低说明上行太弱 |
| SINR | 信号与干扰加噪声比 | 有用信号相对干扰与噪声的倍数 | 越大越好；长期为负说明干扰重 |

一个实用的判读组合：RSRP 不差（比如 -85 左右）但 SINR 长时间是负值，多半是同位置有较强干扰源，原地挪半米改善有限；这种点位可以向运营商反馈，请其排查干扰源。反之 RSRP 本身就到 -110 附近，那是覆盖问题，往窗边、室外走通常立刻见效。

## 四、不同制式看不同参数

4G/5G 数据信号主要看 RSRP 与 SINR；2G（GSM）与 3G 看的是 RSSI 或 RxLev，口径不同。举例：手机回落到 2G 时界面显示 GSM900，强度可能接近 0 dBm 甚至出现正值——这不是异常数值，是 2G 的计量口径本来如此，只说明基站就在附近、信号极强。

手机当前驻留哪个制式，卡片上的网络类型会写明，比如 5G_SA 表示 5G 独立组网。制式与频段的对应关系见 [频段与小区信息识别.md](频段与小区信息识别.md)；各制式下能读到哪些参数、TAC/PCI/ECI/RXLEV 这些缩写分别是什么，见 [各制式参数与缩写对照.md](各制式参数与缩写对照.md)。

## 五、和系统自带入口互相对照

不装任何应用也能看信号：安卓拨号盘输入 `*#*#4636#*#*` 进测试菜单（部分品牌屏蔽了该菜单）；iPhone 输入 `*3001#12345#*` 进场测模式；小米等品牌在「设置 → 我的设备 → 全部参数与信息 → 状态信息 → SIM 卡状态」里也能看到实时强度。

这些入口给的是单个数值，Cellular-Z 的差异在于把 RSRP/RSRQ/SINR、邻区列表、频点、动态曲线放在同一页，边走边记录更方便。两边数值对不上时，先确认看的是同一张卡、同一制式，再对比。
