## 一、卫星图能看什么

位置模块里有当前经纬度、海拔与卫星分布图，每颗卫星带信噪比。官方介绍列出的卫星系统：

| 卫星系统 | 所属 |
| --- | --- |
| GPS | 美国 |
| 北斗 | 中国 |
| GLONASS | 俄罗斯 |
| Galileo | 欧盟 |
| QZSS | 日本 |
| SBAS | 星基增强系统 |

能扫到哪些星座取决于手机芯片，界面上扫到几颗算几颗；Android 8 及以上的系统还会显示每颗卫星的具体频率。

## 二、定位类型是什么意思

界面会标出当前位置的定位来源，看一眼就知道坐标可信度：

| 标识 | 来源 | 怎么用 |
| --- | --- | --- |
| GPS | 卫星定位 | 最准，室外空旷处常见 |
| CELL | 基站定位 | 只能到街道级，室内常见 |
| WIFI | WiFi 热点定位 | 楼宇级精度 |
| CACHE | 缓存的上一次结果 | 不是实时位置 |
| OFFLINE / UNKNOWN | 离线或未知 | 别拿这时的坐标下判断 |

坐标按 WGS-84 全球标准输出（官方介绍口径）；国内地图 App 常显示的 GCJ-02 坐标与之存在系统性偏移，把坐标导去其他工具比对位置时，先确认两边用的是同一坐标系。

## 三、卫星列表空白的排查

按顺序来：

1. 走到室外空旷处再试：楼内、车内（尤其贴了金属膜的挡风玻璃）都会大幅削弱卫星信号；
2. 确认系统「位置信息」总开关已开、应用有定位权限——这与主界面空白是同一个前提，见 [常见问题排查.md](常见问题排查.md) 第一节；
3. 等 30 秒到 1 分钟让首次搜星完成，冷启动本来就慢；
4. 飞行模式会影响定位数据的获取，别开着它看卫星。

## 四、NMEA 日志导出与用途

NMEA 是卫星定位模块输出的标准语句格式，应用支持查看与导出（据官方更新记录，5.7 版起提供）。两个典型用途：

- 排查车载导航、行车记录仪的定位漂移：导出一段日志，看卫星数与信噪比在什么位置开始变差；
- 做定位相关的开发或数据预处理：NMEA 原始语句可以直接喂给分析工具。

导出的文件在手机存储里，取文件与备份的路径说明见 [测速与室内覆盖测试.md](测速与室内覆盖测试.md) 第四节。官方 7.2.1 版的更新说明提到对 NMEA 刷新做了优化，以官方更新说明为准。
