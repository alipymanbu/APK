## 一、Band 与频率在哪看

打开应用，选中要查的卡槽（SLOT1 或 SLOT2），往下翻到 Cell Params（小区参数）区：Band 一栏显示当前频段，形如 B1、B3、B7、B20、B41（4G）或 n78（5G）；旁边有 Frequency DL/UL 两行，是下行/上行频率（MHz）；NR-FREQ 显示 5G 的具体频率。频点号（EARFCN/ARFCN）的读取要 Android 7.0 及以上的系统（官方说明），低版本可能看不到频点号；较新版本支持把 NR-ARFCN 频点号直接换算成频率与频段，看到一串频点号时不必再手动查换算公式。

## 二、常见频段对照

中国大陆现网常见的频段如下（公开资料整理，具体归属随运营商重耕会变，以现网为准；完整频段表可查 [维基百科 LTE frequency bands 条目](https://en.wikipedia.org/wiki/LTE_frequency_bands)）：

| 频段 | 频率 | 常见归属 |
| --- | --- | --- |
| B1 | 2100 MHz | 电信/联通 |
| B3 | 1800 MHz（DCS1800） | 移动/电信/联通 |
| B5 | 800 MHz | 电信 |
| B8 | 900 MHz | 移动/联通 |
| B34 | 2010 MHz | 移动 |
| B38 | 2600 MHz | 移动 |
| B39 | 1900 MHz | 移动 |
| B40 | 2300 MHz | 移动 |
| B41 | 2600 MHz（TD2600） | 移动/电信 |
| n28 | 700 MHz | 广电/移动 |
| n41 | 2600 MHz | 移动/广电 |
| n78 | 3500 MHz | 电信/联通 |
| n79 | 4900 MHz | 移动 |

举两个读法实例：界面显示 B41、频率 2645 MHz，就是电信或移动的 4G（TD2600）；显示 GSM900 且强度接近 0 dBm 甚至为正，是 2G 信号且基站就在附近。

## 三、小区参数逐个看

| 参数 | 含义 |
| --- | --- |
| PLMN | 运营商网络编码 = MCC（3 位国家码）+ MNC（2~3 位网络码），如 46011 是中国电信的 4G/5G |
| Cell ID | 小区编号 |
| PCI | 物理小区标识，区分同一片区域里不同小区的无线信号 |
| TAC | 跟踪区代码，运营商分配的位置区编号 |
| Band / 频点 | 当前频段与频域上的位置（ARFCN / NR-ARFCN） |

这几个值做覆盖反馈时很有用：向运营商或物业报「某某位置信号差」时，把 PLMN、Band、PCI、RSRP 一起报过去，对方能直接定位到具体小区。各制式下参数的完整清单与缩写含义，见 [各制式参数与缩写对照.md](各制式参数与缩写对照.md)。

## 四、邻区列表怎么用

部分机型可以在应用里看到邻近小区信息（官方说明为「部分手机可获取邻小区信息」）。把页面往下拉，能看到周围扫到的其他频段与信号强度。用处很直接：

- 当前频段信号差时，看邻区里有没有更强的频段——比如主用频段 -105 dBm，邻区里另一频段 -85 dBm，说明换个位置或靠窗就可能驻留到更好的小区；
- 城市里通常能扫到十个以上信号，农村常常只有一两个，属正常现象；
- 邻区里出现强度接近 0 的 GSM900，说明附近就有基站。

邻区数值的读法与好坏判断见 [信号参数怎么看.md](信号参数怎么看.md)。

## 五、判断手机是不是掉到 2G/3G

网络制式和频段要结合着看：显示 GSM900 是 2G；B3、B41 或 n41、n78 这些才是 4G/5G。手机网络模式被改成「仅 2G」、或当地 4G/5G 覆盖差时会回落，此时网页与测速都明显变慢。先把系统的网络模式调回「4G/5G 自动」再看数值；还不行就是覆盖问题，走测确认弱覆盖范围的方法见 [测速与室内覆盖测试.md](测速与室内覆盖测试.md)。
