## 一、先对号入座：你手机驻留的是哪个制式

看卡槽卡片上的网络类型：LTE 是 4G、NR 是 5G、GSM 是移动/联通 2G、CDMA 是电信 2G、WCDMA 是联通 3G。不同制式下应用能读到的参数不一样，官方功能介绍页给出的清单如下：

| 制式 | 能读到的参数 |
| --- | --- |
| LTE（4G） | TAC、PCI、ECI、RSRP、RSRQ、SINR、EARFCN |
| GSM（2G） | LAC、CI、RXLEV、ARFCN、BSIC |
| WCDMA / TD-SCDMA（3G） | LAC、CI、RXLEV、UARFCN |
| CDMA / CDMA-2000（3G） | NID、BID、SID、CDMA DBM、CDMA ECIO、EVDO DBM、EVDO ECIO、EVDO SNR |

两个版本前提（官方说明）：双卡信息的区分显示要 Android 5.0 及以上；LTE 的 EARFCN 与 GSM 的 ARFCN 要 Android 7.0 及以上的系统才拿得到。

## 二、LTE 缩写速查

| 缩写 | 含义 | 怎么用 |
| --- | --- | --- |
| RSRP / RSRQ / SINR | 参考信号功率 / 质量 / 信噪比 | 好坏对照见 [信号参数怎么看.md](信号参数怎么看.md) |
| TAC | 跟踪区代码 | 报障定位用，见 [频段与小区信息识别.md](频段与小区信息识别.md) |
| PCI | 物理小区标识 | 区分相邻小区，怀疑同频干扰时看它 |
| ECI | LTE 小区唯一编号 | 能精确定位到具体小区 |
| EARFCN | LTE 绝对频点号 | 频段/频率的编号，较新版本可直接换算 |

## 三、GSM / WCDMA / CDMA 缩写速查

| 缩写 | 制式 | 含义 |
| --- | --- | --- |
| LAC / CI | GSM、WCDMA | 位置区码 / 小区码 |
| RXLEV | GSM、WCDMA | 接收电平，GSM 规范按 0～63 编码，值越大信号越强（口径与 dBm 不同） |
| ARFCN / UARFCN | GSM / WCDMA | GSM 绝对频点号 / WCDMA 频点号 |
| BSIC | GSM | 基站识别码 |
| SID / NID / BID | CDMA | 系统 / 网络 / 基站标识 |
| CDMA DBM / ECIO | CDMA | 信号强度（dBm）/ 导频质量 |
| EVDO DBM / ECIO / SNR | CDMA-2000 | EVDO 数据信道的强度 / 质量 / 信噪比 |

读 2G/3G 参数时注意口径：GSM 的 RXLEV 与 LTE 的 RSRP 不是一回事，别拿同一张对照表去套；2G 的强度出现接近 0 甚至正的 dBm 属正常，原因见 [信号参数怎么看.md](信号参数怎么看.md) 第四节。

## 四、不用逐个记，报障时抄那一屏就够

向运营商反馈时的实用做法：把当前页截图，连同位置与时间一起发过去；文字描述带上「制式 + 频段 + RSRP（或 RXLEV）+ PCI 或 CI」四项，对方工程师就能直接定位到小区。信号差到底算覆盖问题还是干扰问题、报障前先自查什么，见 [常见问题排查.md](常见问题排查.md) 第三节。
