首页上的角色都是别人写好的设定，改不了。想聊一个完全照自己想法来的角色，就得自己建一个。创建面板的字段不算多，但每一项填得粗还是细，直接决定往后聊起来是「有个人」还是「一台复读机」。

## 一、从哪里进创建面板

1. 回到首页，点界面中部带「+」的入口；
2. 在弹出的选项里选创建角色（部分版本叫「原创角色」）；
3. 进入编辑页开始填。

按钮文案不同版本略有差别，认「+」和「创建角色」这两个特征就行。

## 二、创建面板要填哪些项

下表按面板上常见的排列顺序给出各项的作用与写法。字段名以你所在版本的应用内实际显示为准，个别版本会多一项或少一项。

| 项目 | 影响什么 | 怎么写更管用 |
| --- | --- | --- |
| 角色名称 | 对话页与角色列表里显示的名字 | 起个具体的名字，别用「AI」「助手」这类泛称 |
| 性别与形象 | 角色在对话里怎么自称、卡片上长什么样 | 用自己的图当形象时，别上传带真实身份信息的照片 |
| 声音（音色） | 语音消息与语音通话里角色的声音 | 想听声音就挑一个，不挑则用默认；用法见 [语音通话与语音消息怎么用.md](语音通话与语音消息怎么用.md) |
| 聊天风格 | 角色整体说话的调性（话多话少、正式还是随意） | 先选风格再写档案，风格定骨架、档案填内容 |
| 角色档案（介绍） | 角色的身份、处境、和你是什么关系 | 这部分是回复质量的来源，值得多花时间 |
| 描述 | 对角色性格与外形的一段集中描述 | 用**行为**写，别堆形容词，见第三节 |
| 初始消息 | 角色对你说的第一句话 | 写一句带钩子的开场，别写「你好，我是 XX」 |
| 背景故事 | 角色的经历，决定后期聊深了会不会空 | 先写身份与当前处境，再写性格是怎么来的 |

**必填项填不全会直接保存失败**，保存时如果只给了笼统提示，回去把上面几栏从头核一遍，看有没有哪一项是空的。

## 三、写法上的四个经验

1. **写行为，不写评价。** 「温柔」这种词在你的语境里是什么意思，模型并不知道；「你说累的时候会先问一句吃了没」它就懂了。描述与档案这两栏，尽量都换成具体动作。
2. **关系和称呼先写死。** 这是最容易翻车的一项。称呼含糊，角色对你的态度就会一会儿一个样，后面在对话里反复纠正也拉不回来。写「认识三年的同事，叫你老张」比写「朋友」管用得多。
3. **初始消息决定开局。** 角色说的第一句如果是「你好呀，今天想聊什么」，你多半只能回一句「随便聊聊」。把初始消息写成「你终于来了，那件事我想了一晚上」，对话一下就有内容可接。
4. **档案别写成长篇。** 多份第三方资料都指向同一件事：设定写得越长，聊到后面越容易把先前说过的事丢掉。按「身份、当下处境、和你的关系」三段各写两三句就够，剩下的细节留到对话里一句句补。

## 四、保存前先预览

填完以后面板上一般有预览入口，能看到角色形象与开场效果。**预览里如果显示不对（形象没上去、声音没生效），先别急着确认生成**，回上一页检查对应的那一栏是否真的填进去了，再重新预览一次。首版可以先按最简配置建出来，聊几句觉得方向对了，再回编辑页往外扩。

## 五、建完以后还能改、能删

- **改设定**：在角色列表里找到这个角色，进编辑页改名称、声音、风格、档案等任意一项，改完保存。改完的新设定从之后的对话开始生效，已经聊过的那段内容不会自动改写。
- **删角色**：在列表里长按该角色，或点它旁边的更多按钮，选删除。**删除后这个角色的信息通常无法恢复**，自建角色尤其要想清楚——它不像官方角色那样能重新找回来。
- **想改一个已有的角色**：与其从头再造一个，不如把原来的复制一份再改，能省掉重写背景的功夫；是否提供复制入口以应用内为准。

## 六、把自己建的角色分享出去

部分版本支持把自己建好的角色分享出去，也能取用别人公开的角色设定来改。**入口位置、是否需要消耗道具、以及你的版本有没有这项，都以应用内当时显示为准。**

真要分享的话，写档案时就别把真实姓名、单位、住址、联系方式写进去——这些内容会跟着角色一起出现在别人能看到的地方。哪些内容会被展示、哪些只留在你自己的账号里，同样以应用内的权限说明为准。
