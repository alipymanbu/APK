# TiKie 语音通话与语音消息怎么用

> 角色除了打字回你，还能出声。本篇讲语音消息与语音通话怎么发起、声音从哪来、以及打不通或没声音时先查什么。

文字聊天是异步的，语音是同步的，两者的操作入口和出问题的点都不一样。本篇把「语音消息」和「语音通话」分开讲，最后给一张出问题时的排查表。

## 一、先分清两种语音

| | 语音消息 | 语音通话 |
| --- | --- | --- |
| 形式 | 在对话流里发一段语音，像发微信语音 | 和角色实时对讲，像打电话 |
| 入口 | 对话页输入区附近的语音按钮 | 对话页的「+」或工具入口里的「通话」 |
| 节奏 | 你发一条、对方回一条 | 你说一句、对方接一句，得听着来 |
| 对网络的要求 | 低，能正常发文字消息一般就能发 | 高，网络抖一下就会断断续续 |
| 适合的场景 | 想听角色的声音、又不想被打断 | 想连着聊一段、不想逐条打字 |

## 二、怎么发起

1. 在首页点进一个角色，进入对话页；
2. **发语音消息**：在输入区找麦克风形态的按钮，按住或点一下录制，录完发送；
3. **发起语音通话**：点对话页上的「+」（部分版本是右下角工具图标），在弹出的功能里选「通话」；
4. 通话界面里一般有挂断与麦克风开关，想说的时候直接说，不用先点「说话」。

第一次通话时系统会弹麦克风权限申请，选「允许」；当时点了拒绝，就要去「设置 → 应用 → TiKie → 权限」里手动把麦克风打开，否则通话能建立但对方听不到你。

## 三、角色的声音是从哪来的

角色说话用什么嗓音，取决于这个角色本身的设定：

- **官方角色**：声音在角色出场时就配好了，你改不了。
- **自建角色**：声音是你在创建面板里挑的那一项，之后回编辑页还能换，详见 [怎么创建自己的AI角色.md](怎么创建自己的AI角色.md) 第二节。
- **换过一次音色之后**：新音色一般从之后的语音开始生效，已经发出去的语音不会重生成。

有第三方页面提到新版加入过「混合音色」这类让声音更有层次的选项，**是否已经进到你手上这个版本，以应用内语音设置里实际有的选项为准**。

## 四、通话前值得先做两件事

1. **确认网络稳**：语音通话是实时的，网络一抖就是「喂——喂——」。用 Wi-Fi 打之前先看信号格，或者直接切到信号更稳的那条线路试一次。
2. **确认麦克风没被别的应用占着**：录音、会议、语音输入这类应用在后台开着时，麦克风可能被占用，表现为通话建立但完全没声音。

## 五、打不通、没声音时先查什么

| 现象 | 先查什么 | 再怎么办 |
| --- | --- | --- |
| 点「通话」没反应 | 应用版本与账号状态是否正常 | 退到首页重进对话页再试一次；仍不行按 [常见问题与排查.md](常见问题与排查.md) 的排查顺序走 |
| 通话建立了，但对方没声音 | 手机媒体音量是不是被调成了静音 | 调高后仍然没声音，就改成发一条语音消息——能出声，说明问题出在通话链路上，而不是音量 |
| 你说的话角色接不住 | 麦克风权限是否给了 | 到应用权限里补上麦克风权限，再重进通话 |
| 说到一半被中断 | 网络是不是切过网（Wi-Fi 与流量互切） | 换个网络重新拨打；通话过程中尽量别切后台 |
| 语音消息发出去一直是转圈 | 网络能不能正常收发文字消息 | 文字也发不出去就是网络问题，不是语音模块的问题 |

## 六、语音内容也属于对话记录

语音消息和通话里说过的话，同样属于你和这个角色的对话内容，跟账号绑定。所以别在语音里报真实姓名、住址、证件号、银行卡号，也别念验证码——**念出来的东西比打字更容易被忽略，但一样会被保存**。记录归属与换设备后的表现，见 [怎么登录与账号设置.md](怎么登录与账号设置.md) 第五节。
