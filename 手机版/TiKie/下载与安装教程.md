TiKie 是安卓端的 AI 角色扮演聊天应用：首页是一批带人设的虚拟角色，挑一个就能开始对话，也能自己捏角色、发语音、抽角色卡牌。本篇只做一件事——把网盘里这份安装包装进手机并正常登进去。

## 一、先确认网盘里这份包是哪一版

应用商店页面上显示的是官方当时的最新版，跟网盘里这份往往不是同一个版本号。本篇出现的版本号、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | TiKie |
| 版本号 | 3.1.4 |
| 包名 | `com.tikie.ai.android` |
| 安装包体积 | 115.26 MB |
| MD5 | `12E37C9F732F7402D5B09BE940F161E6` |
| 适用平台 | Android（手机端 APK） |
| 开发主体 | Junoverse |
| 内容分级 | 第三方商店页标注为年满 16 周岁 |

装之前先弄清三件事：

- **认包名，别只认名字。** 搜「TiKie」会同时带出「Tikie AI」「TiKieAI」这类近名条目，包名对不上就不是同一个应用。这份包的包名是 `com.tikie.ai.android`，装好后在「设置 → 应用 → 应用管理」点进 TiKie 的应用信息页能看到。
- **这是安卓包，iPhone 装不了。** TiKie 另有 iOS 版，那一份只能用 Apple ID 在 App Store 里装，跟网盘里这个 APK 不是一回事。
- **系统要求以官方商店页面为准。** 第三方下载页给出的最低安卓版本互相矛盾（有的写 4.3，有的写 5.2，有的写 11），照哪一个都可能装错。装机前在「设置 → 关于手机」里看一眼系统版本，再对照官方商店页面上登记的要求。版本过低的表现通常是装不上，或者装上打开即退。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [TiKie 安装文件资源（夸克网盘）](https://pan.quark.cn/s/094e565e3eed)，用手机上的夸克 App 打开最省事。
2. **先转存再下载**：选中安装包，转存到自己的网盘目录后再下载到本机。分享链接以后可能失效，转存过的那份不受影响。
3. **核对体积**：下载完成后看一眼文件体积，应当约 115.26 MB。中途断网重连后体积偏小，安装时会直接报「解析包错误」。
4. **想校验完整性**：在电脑上把包算一遍 MD5，结果应与上表一致（大小写不敏感）。

```cmd
certutil -hashfile TiKie_v3.1.4.apk MD5
```

文件名随版本变化，以实际拿到的那个为准。

## 三、安装步骤

1. **给文件管理器开「安装未知应用」权限**：进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把用来打开 APK 的那个应用（文件管理器或浏览器）的开关打开。国产定制系统这项常收在「安全」或「隐私」分类里。
2. **点击 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续，这是侧载安装包的常规提示。
3. **手机上已有更高版本时先卸载**：安卓不允许用低版本覆盖高版本，会直接报「应用未安装」。卸载会一并清掉本机上和角色聊过的记录，动手前先在应用内翻一遍有没有导出或备份的入口（是否提供以应用内为准，相关说明见 [怎么登录与账号设置.md](怎么登录与账号设置.md)）。
4. **报「签名不一致」说明包名撞了**：手机里已经装过同包名、不同来源的版本，按第五节表格处理。
5. **留出安装空间**：安装过程中系统还要展开一份文件，建议预留 500 MB 以上可用空间。

## 四、第一次打开要确认的三件事

1. **能联网**：角色列表和对话回复都要联网才能拿到，应用本身不能离线聊天。打开后一直停在加载状态，就先用浏览器确认手机能正常上网。
2. **能登录进去**：TiKie 目前只支持用 Google 账号登录，第一次进入会让你先同意用户协议，再走 Google 账号授权。这一步卡住的处理方式见 [怎么登录与账号设置.md](怎么登录与账号设置.md)。
3. **能看到角色并发出一句**：首页刷得出角色卡片，说明数据侧通了；随便点进一个角色发一句「你好」，能正常收到回复就算装好了。想自己捏角色的，做法见 [怎么创建自己的AI角色.md](怎么创建自己的AI角色.md)。

## 五、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整 | 核对体积与 MD5，按第二节重新取一份 |
| 提示「应用未安装：签名不一致」 | 手机里已有同包名、不同来源的版本 | 先在应用管理里卸载旧包，再装这份 |
| 安装被安全中心拦下 | 侧载包被系统安全策略拦了 | 在安全中心的拦截记录里选「继续安装」 |
| 点安装没反应 | 「安装未知应用」权限没给 | 回到第三节第 1 步补上权限 |
| 装完打开就闪退 | 系统版本过低、存储不足或包残缺 | 见 [常见问题与排查.md](常见问题与排查.md) 第五节 |

以后换版本或者重装，按第二节的步骤重新取一份即可，安装动作与这次相同。

## 六、装完之后顺手做两件事

- **在应用管理里记一眼包名**：点进 TiKie 的应用信息页，确认包名是 `com.tikie.ai.android`。以后再碰到一个叫「Tikie」的应用，拿这条一对就知道是不是同一个。
- **把网盘里的包留着**：这类应用的版本号走得比文档快，某个新版用着不对劲时，能退回旧版的前提是手上还留着旧包；网盘里转存过的那份是干净的原始文件。
