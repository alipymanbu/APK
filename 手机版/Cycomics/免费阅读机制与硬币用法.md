## 一、一话漫画的三种打开方式

作品页的连载标签里，每一话前面都会挂一个图标，图标决定了这一话怎么读：

| 图标 | 怎么读 |
| --- | --- |
| 「待てばタダ！」 | 等 22 小时，免费读 |
| 带价格（硬币数） | 用硬币读 |
| 「先読み」标签 | 用硬币提前读官方公开日之前的新话，不参与免费等待 |

免费和付费共享同一个入口：同一话既可以等 22 小时，也可以等不及直接花硬币。已经用「待てばタダ」打开、还在阅读期限内的一话，在期限结束前**不能**再花钱购买它。

## 二、「待てばタダ！」规则速查

官方帮助页对这套机制的原始定义，整理成可执行的几条：

- **一次一话**：22 小时的等待（官方叫「チャージ」/充电）按话计算，读完一话后重新充 22 小时才能免费读下一话。
- **期限内可反复看**：用免费方式打开一话后，从开始阅读到阅读期限到期之前，可以重复读；到期就读不了了。期限一过，这话并没有被你「买下」——想永久反复读，见下文硬币部分。
- **灰色图标怎么解锁**：连载标签里灰色的「待てばタダ！」图标，解锁条件有三条，满足其一即可：
  1. 把**前一话**读掉；
  2. 完成**账号绑定**（网页版叫新规注册）；
  3. 应用版不绑定也行——**安装满 24 小时**后自动解锁。
- **等待时间不是死的**：官方活动可能缩短 22 小时的充电时间，以作品页当时的显示为准。
- **范围**：只有挂了该图标的「漫画本编」话数参与；先読み话、以及「巻読み」（合卷内容）不在其中。

## 三、两种硬币，规则完全不同

サイコミ里的硬币分两种，优先级、有效期都不同：

| | プレミアムコイン（付费硬币） | ボーナスコイン（奖励硬币） |
| --- | --- | --- |
| 怎么来的 | 自己充值 | 充值附赠、看广告、每日签到、抽奖等活动发放 |
| 有效期 | 没有 | **可能有**：充值时附赠的没有有效期；看广告、活动发放的随活动而定 |
| 能买什么 | 全部，包括只允许付费硬币购买的内容 | 一般内容 |
| 能否退款 | 购入后不退不换 | 过期作废，不可恢复 |

使用顺序的规则，直接影响你的钱包：

1. 同时持有两种时，**先扣奖励硬币**；
2. 奖励硬币内部按**有效期最近的先扣**；
3. 有效期与余额都可在「マイページ」→「コイン明細」→「有効期限一覧」里查，领硬币时弹出的提示也会标注这次的有效期；
4. 硬币总持有上限为两种合计 99,999,999；
5. 硬币明细只能查到**最近 3 个月**；
6. 领硬币时弹出的提示会标注这批奖励硬币的有效期，想要「永不过期」的奖励硬币，最稳的来源是充值附赠的那部分。

## 四、充值渠道：应用版和网页版不一样

买付费硬币的入口在「マイページ」→「コインを購入」，但两个形态走的支付通道不同：

| 形态 | 支付方式 |
| --- | --- |
| 应用版 | App Store / Google Play 账号内登记的付款方式（苹果内购 / 谷歌内购） |
| 网页版 | 信用卡（3D Secure）、d払い、auかんたん決済、ソフトバンクまとめて支払い、PayPay |

两个硬性规定：网页版**必须登录后**才能购买；付款后硬币迟迟没显示，先等 1 小时，再不行到持有硬币页面按「所持コイン更新」手动刷新——这套处理流程和「买了没到账」的其他排查一起写在 [常见问题排查.md](常见问题排查.md)。

另外，误购不退款，充值前确认好数额。

## 五、不花钱攒硬币的两条路

- **デイリーボーナス（每日奖励）**：看一段视频广告换奖励硬币，每天 0 点重置次数。两个常见的「广告看不了」原因：iOS 系统设置里开了广告限制（设置 → 隐私 → 广告 → 限制追踪广告），网页版开了广告拦截扩展——这两个开关不改，广告刷不出来，硬币也拿不到。广告加载失败还有别的场景，见 [常见问题排查.md](常见问题排查.md)。
- **おみくじ（每日抽奖）**：每天 1 次免费抽，同样 0 点重置，抽中直接发奖励硬币；应用版直接玩，网页版需要先登录。抽奖演出在通信不佳时可能跳过或显示异常，官方说明硬币发放本身不受影响，可在「コイン明細」里核对。

攒硬币的节奏建议：每天两次机会都点掉，硬币到账后先用临期的奖励硬币看想看的话，「待てばタダ」留给不着急的连载——注意 22 小时一话的速度赶不上日更进度，赶新话就花硬币，不赶就一直等。每部作品星期几更新、怎么按题材翻同类，见 [找书与更新日程.md](找书与更新日程.md)。
