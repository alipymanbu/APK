# サイコミ（Cycomics）看不了漫画等常见问题排查

> 本篇把サイコミ最常见的几类故障——漫画打不开、广告刷不出、硬币没到账、期限没到却看不了——按现象给出排查顺序。

## 一、漫画 / スペコン 打不开

按官方帮助页列出的原因，从最可能的开始：

1. **同一话反复打开太多次**：重复观看会触发临时限制——把这一话（或スペコン）的页面**关掉一次**再开，通常就恢复；
2. **网络本身不通或不稳**：确认其他应用能不能联网；
3. **运营商的网页过滤服务**：手机套餐里若开着「网页接入限制 / 过滤」类服务，会被拦；这类拦截有个官方提示的特征——**换到 Wi-Fi 下常常就能看**。关过滤服务要去你运营商 / 通信商的设置里操作；
4. 以上都不行时，带着「マイページ」头像旁的客户 ID 去问官方客服。

## 二、视频广告看不了（影响领硬币）

广告刷不出来，先分清是哪种：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 偶尔转圈刷不出 | 广告库存不足或线路拥堵 | 等一会儿再点；或重启应用 / 浏览器 |
| iOS 上从来不弹出 | 系统开了广告限制 | 设置 → 隐私 → 广告 → 关掉「限制追踪广告」 |
| 网页版从来不弹出 | 浏览器开了广告拦截扩展 | 对 cycomi.com 关掉拦截 |

第三种情况在 [免费阅读机制与硬币用法.md](免费阅读机制与硬币用法.md) 里也提过，因为它是「每日奖励领不到」的头号原因。改完设置还没好，且设备 / 系统本身有异常，就要找设备厂商而不是サイコミ客服了。

## 三、买了硬币没到账

1. 先等 **1 小时**再查（官方明确说到账可能延迟）；
2. 还没显示，到「マイページ」或硬币购买页 / 硬币明细页按「**所持コイン更新**」按钮手动刷新；
3. 核对时注意两点：明细里只保留**最近 3 个月**的记录；奖励硬币可能已经过期作废（过期也会记进「コイン履歴」，服务器忙时晚一点才反映出来）；
4. 误购不退不换——这个没有补救路径，只能在购买前核对。

## 四、灰色「待てばタダ！」图标点不了

三种解锁方式，任选其一：读掉前一话、绑定账号、（应用版）安装满 24 小时。完整规则在 [免费阅读机制与硬币用法.md](免费阅读机制与硬币用法.md)。刚装完应用就想立刻免费读的话，绑定账号是唯一不用等的路。

## 五、阅读期限没过，却提示看不了

这是**公开期限**在起作用，不是故障：サイコミ的内容有两层期限，「閲覧期限」管你手里这份阅览权能用到什么时候，「公開期限」管官方这话还挂不挂着——后者一到，前者还剩多久都没用。价格、期限官方都可能调整，以作品页当时显示为准。想避开这个问题，把常读的话换成**按话购入或巻読み**（这两类无期限），区别见 [阅读功能与追更设置.md](阅读功能与追更设置.md)。

## 六、换机 / 重装后数据没了

先查一件事：卸载前绑定过 Cygames ID 吗？

- **绑过**：新设备上登录同一账号（データ引き継ぎ・ログイン）即可找回硬币与已购内容；
- **没绑**：官方口径是账号信息与硬币随卸载清空、不可恢复、不退款——没有任何找回渠道。

绑定与设备数（3 台设备 + 1 浏览器）的具体操作见 [账号注册与数据同步.md](账号注册与数据同步.md)。

## 七、推送收不到

按顺序查三处：应用内「通知設定」开了没有（「お知らせ通知」/「チャージ完了通知」两个开关）；手机系统设置里サイコミ的通知权限开没开；你是不是在网页版用的「待てばタダ！」——网页版充电完成**不推送**，这是设计如此不是故障。通知系统的边界说明在 [阅读功能与追更设置.md](阅读功能与追更设置.md)。
