## 一、哪些动作必须登录

应用版不绑定账号也能浏览和读免费内容，但官方帮助页把一批高频动作划成了「登录专属」，网页版尤其明显：

| 动作 | 应用版 | 网页版 |
| --- | --- | --- |
| 浏览 / 读免费公开内容 | 可以不登录 | 可以不登录 |
| 用「待てばタダ！」 | 可以不登录 | **必须登录** |
| 购买硬币 | 走商店内购 | **必须登录** |
| 购买先読み / 巻読み等付费内容 | 建议登录 | **必须登录** |
| 参加每日奖励、抽奖等活动 | 可以不登录 | **必须登录** |

结论很直接：**网页版玩任何付费或攒硬币的玩法，先登录再说**；应用版只有绑定后才算把数据攥在自己手里。

## 二、绑定 Cygames ID（アカウント連携）

サイコミ的数据挂在账号上，绑定用的就是 Cygames 通用账号体系 Cygames ID：

1. 应用版：「マイページ」→「アカウント管理」里选「アカウント連携」，用 Cygames ID 完成绑定；
2. 网页版：对应动作叫「新規登録」（新注册），注册即绑定；
3. 绑定后，应用版和网页版可以用**同一个账号**登录，硬币、阅读记录互通。

绑定解决的是三件事：换手机、应用重装、设备丢失——只要在新设备上用同一 Cygames ID 执行「データ引き継ぎ・ログイン」（数据继承 / 登录），数据就回来了。没绑定就操作这三件事中的任何一件，后果见第五节。

另外两个小点：

- 你的「お客様 ID」（客户 ID）显示在「マイページ」头像旁边，联系客服排查问题时会用到，截图存一份；
- 绑定方式以后可以换：「アカウント管理」→「連携方法変更」。

## 三、同时能登录几台设备

官方限制：**设备 3 台 + 浏览器 1 个**。规则细节：

- 登录第 4 台设备时，**登录时间最早的那台**会被自动登出，不需要手动处理；
- 想主动管理：「マイページ」→「アカウント管理」里可以把**当前设备以外的所有设备**一次性登出（借出去的手机、卖掉的旧机都靠这个清掉）；
- 网页版放置一段时间会自动登出；在网吧、公司电脑等公共环境用完，务必手动「マイページ」→「ログアウト」。

## 四、验证邮件收不到怎么办

注册 Cygames ID 或重置密码时收不到邮件，官方列了六个排查方向，按概率排：

1. 把 `noreply@cygames.co.jp` 和 `noreply@contact.cygames.co.jp` 加进邮箱白名单 / 收件许可；
2. 等 30 分钟以上再重试（第一次操作要隔够 30 分钟）；
3. 翻垃圾邮件文件夹；
4. 检查收件箱 / 邮箱容量是否已满；
5. 核对注册时填的邮箱地址有没有打错；
6. 确认注册用的邮箱账号确实是当前这个。

au 运营商邮箱（`ezweb.ne.jp` / `au.com`）额外多一步：关掉或放宽其垃圾邮件过滤（受信リスト設定里把上面两个域名设为许可），否则运营方的回信会被拦。

## 五、卸载与退会：丢的东西不一样

这两个动作的后果不同，动手前对号入座：

| 动作 | 没绑定账号 | 已绑定账号 |
| --- | --- | --- |
| 卸载应用 | 账号信息与持有的**所有硬币直接消失**，官方明言不可恢复、不退款 | 新设备上登录同一 Cygames ID 即可继承 |
| 退会 | — | 书籍、硬币等**全部数据清空**，已购的巻読み也不能再看；处理需一段时间，期间无法撤销 |

退会入口在官方的 [退会页面](https://cycomi.com/auth/leave)（网页版需登录后操作）。判断依据就一条：只要这份数据你以后还要，就先把绑定做掉——两分钟的操作，换掉的是「硬币清零重买」的风险。硬币的损失范围具体有多大，见 [免费阅读机制与硬币用法.md](免费阅读机制与硬币用法.md)。
