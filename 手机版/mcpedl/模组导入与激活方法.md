# MCPEDL 模组导入与激活方法

> 从 MCPEDL 下载的内容要经过「应用内下载 → 导入 Minecraft → 在世界里启用」三步才真正生效。本篇按附加包、地图、皮肤、材质分别写清每一步怎么点，末尾附 zip 手动导入兜底。

## 一、导入前的准备

- 手机上已安装 Minecraft 基岩版（手机版），且能正常进游戏；
- MCPEDL 与 Minecraft 装在同一部手机上——导入是靠系统把文件「交给」Minecraft 完成的；
- 网络可用：浏览目录和下载内容都需要联网；
- 各类内容与文件后缀的对应关系见[内容类型与文件格式.md](内容类型与文件格式.md)，知道手里是什么文件再往下走。

## 二、在 MCPEDL 里下载内容

1. 按分类浏览或用搜索框找到想要的内容，点开详情页；
2. 点下载按钮，等进度走完；
3. 下载完成的条目会出现在应用的下载（Downloads）页，后面的导入就从这里点。

有用户反馈连续下载多个内容时下载按钮可能卡住，重启应用可以缓解；应用卡在加载页进不去属于另一类问题，见[导入报错与加载卡住排查.md](导入报错与加载卡住排查.md)。

## 三、把文件导入 Minecraft

官方推荐的导入路径（以 `.mcpack` / `.mcaddon` / `.mcworld` 为例）：

1. 在 MCPEDL 的下载页点已完成条目旁的下载图标；
2. 系统弹出「选择打开方式」，点 **Minecraft**；
3. 游戏自动拉起并开始导入，屏幕上方出现 `Import started...`，伴随一声提示音；
4. 导入完成显示 `Successfully imported`——此时文件已进游戏，但**还没生效**，接着看第四节。

如果这一步弹出 `Duplicate Pack Detected`、`Failed to import` 之类的提示，按[导入报错与加载卡住排查.md](导入报错与加载卡住排查.md)第二节的对照表处理。

## 四、在游戏里启用（按类型）

**附加包 / 模组（.mcaddon）**

1. 创建新世界或编辑现有世界；
2. 世界设置里点「资源包」（Resource Packs）和「行为包」（Behavior Packs）；
3. 切到「可用」（Available）标签，找到刚导入的包，点「激活」；
4. 附加包通常**资源包和行为包都要激活**，只开一边功能会缺；
5. 部分附加包要求打开「实验性玩法」（Experimental Features）开关，包说明里会写明；开关在创建世界的游戏设置里（Experiments），已有世界也能进世界设置补开，开的时候会弹确认框。注意两点：官方提示实验功能仍在开发中，可能导致世界崩溃或在未来版本不兼容，能不开就不开；开了实验玩法、行为包或作弊的世界，成就不可解锁，影响与恢复办法见[成就被禁用的原因与恢复.md](成就被禁用的原因与恢复.md)。

**地图 / 世界（.mcworld）**

导入完成后回到主菜单，世界列表里直接就有；确认导入完全结束再点进去。

**皮肤**

主界面点「更衣室」（Dressing Room）→「经典皮肤」（挂衣架图标），新导入的皮肤包就在里面。

**材质 / 光影**

- 单个世界使用：世界设置 → 「资源包」→ 激活；
- 所有世界默认生效：游戏「设置 → 全局资源」（Global Resources）里激活。

## 五、.zip / .rar 手动导入兜底

下载到的是 `.zip` / `.rar`（或自动导入一直失败想手动装）时，用文件管理器按下面的顺序处理：

1. 把 `.mcpack` / `.mcaddon` 改名为 `.zip`（部分文件管理器可直接解压专用后缀）；
2. 解压后按内容类型把文件夹放进 Minecraft 数据目录 `games/com.mojang/` 下的对应位置：

| 内容类型 | 放到哪 |
| --- | --- |
| 世界 / 地图 | `games/com.mojang/minecraftWorlds/` |
| 资源包（材质、光影） | `games/com.mojang/resource_packs/` |
| 行为包（模组逻辑） | `games/com.mojang/behavior_packs/` |

3. 重启 Minecraft，再按第四节在世界设置里启用。

目录放错是「导入显示成功、游戏里却找不到」最常见的原因，逐层核对上面三个路径；导入环节的英文报错集中在[导入报错与加载卡住排查.md](导入报错与加载卡住排查.md)里对照处理。
