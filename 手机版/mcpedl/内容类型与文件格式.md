# MCPEDL 内容类型与文件格式

> MCPEDL 里的资源按模组、材质包、光影、地图、皮肤分类，下载下来是 .mcpack、.mcaddon、.mcworld 这类专用格式。本篇讲每类内容是什么、对应哪种文件、进游戏后落在哪。

## 一、五类内容分别是什么

| 类型 | 改变什么 | 常见例子 |
| --- | --- | --- |
| 模组 / 附加包（Add-Ons） | 游戏行为：新生物、新物品、新机制 | 武器模组、新增怪物 |
| 材质包（Texture Packs） | 画面外观：方块与物品的贴图 | 卡通风、写实风贴图 |
| 光影（Shaders） | 光照、阴影、水面效果 | 高清光影包 |
| 地图 / 世界（Maps / Worlds） | 整张世界：存档、玩法、建筑 | 跑酷、生存、恐怖地图 |
| 皮肤包（Skin Packs） | 角色外观 | 人物、动画角色皮肤 |

首页按分类与热度排列，也有搜索框；内容详情页会标注作者、更新日期、适用版本要求与评论区，挑选时先看这几项，尤其是「适用版本」——包要求的最低游戏版本高于你手机上的 Minecraft 版本时，导入后可能不生效或报错。

## 二、下载下来的文件是什么格式

Minecraft 基岩版手机端用专用后缀，MCPEDL 下载的内容大多是这些：

| 后缀 | 装的是什么 | 进游戏后在哪 |
| --- | --- | --- |
| `.mcpack` | 单个资源包（材质、光影、皮肤包） | 世界设置的「资源包」 |
| `.mcaddon` | 成套附加包（行为包 + 资源包一起） | 世界设置的「行为包」和「资源包」 |
| `.mcworld` | 完整的世界（地图） | 主菜单的世界列表 |
| `.mctemplate` | 世界模板 | 创建世界时的模板菜单 |
| `.zip` / `.rar` | 老式打包，需要手动解压 | 手动放进对应目录 |

两点注意：

- 这些格式只适用于**基岩版**（手机版 / Win10 版），Java 版电脑客户端用不了；
- `.zip` / `.rar` 打包的内容要用文件管理器手动处理，步骤在[模组导入与激活方法.md](模组导入与激活方法.md)的手动导入一节。

## 三、导入后去哪找（速查）

- 模组 / 附加包：创建或编辑世界 → 「行为包」「资源包」→「可用」→ 激活；
- 地图：导入完成后直接出现在世界列表；
- 皮肤：主界面「更衣室」（Dressing Room）→「经典皮肤」；
- 材质 / 光影：单个世界在世界设置里激活；想全局默认生效，在「设置 → 全局资源」里激活。

速查表只是方位，完整的点击步骤（怎么把文件导进游戏、每类怎么启用）见[模组导入与激活方法.md](模组导入与激活方法.md)；导入时弹出报错、应用卡在加载页，对照[导入报错与加载卡住排查.md](导入报错与加载卡住排查.md)处理。
