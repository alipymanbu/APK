## 一、用之前先明白一件事

下面这些开关都是给**你自己的设备装你自己的应用**用的，每一个都直接改变系统安装器的行为。默认全不勾时，IWO 的表现最接近系统安装器；遇到装不上的情况，再按需开一两个 —— 不要一次全开，出错了你分不清是哪一项在起作用。前提仍是 Shizuku 正常运行，见 [Shizuku激活与连接失败怎么办.md](Shizuku激活与连接失败怎么办.md)。

## 二、选项清单与适用场景

| 选项 | 作用 | 什么时候用 / 版本差异 |
| --- | --- | --- |
| Allow Downgrade（允许降级） | 允许安装比已装版本更低的版本 | 想退回旧版时勾。但 Android 14+ 系统层只放行 root 或调试版构建的包，勾了也一样可能报 `INSTALL_FAILED_VERSION_DOWNGRADE`，见 [安装失败错误代码解决办法.md](安装失败错误代码解决办法.md) |
| Bypass Low Target SDK Block（绕过低目标 SDK 限制） | 绕过 Android 14 对目标 SDK 过低的应用的安装拦截，等价于 adb 的 `--bypass-low-target-sdk-block` | 只在 Android 14+ 上出现；低版本系统没有这个限制，也就没有这个选项。老应用装不上时勾它，规则线见 [Android 14及以上装不了旧应用怎么办.md](Android 14及以上装不了旧应用怎么办.md) |
| Grant All Requested Permissions（授予全部请求权限） | 安装时自动授出该应用请求的**运行时权限** | 装完不想一个个去设置里点权限时用。特殊权限（无障碍、通知访问等）不在此列 |
| Disable Verification（禁用校验） | 关闭基础包校验，让某些特殊包能装上 | **不跳过签名校验** —— 签名不匹配照样报错，别指望它解决 `UPDATE_INCOMPATIBLE` |
| 指定 installer package（安装来源） | 把应用记录的安装来源字段设成指定包名 | 部分应用会检查安装来源。Android 14 起系统只允许 shell 设 installer 字段，不能再设 originating 字段，见第三节 |
| Install Reason（安装原因） | 设置系统记录的安装原因 | 按需填写，一般场景用不上 |
| Target User（目标用户，按 ID 指定） | 把应用装进指定的用户空间 | 多用户 / 工作资料场景用；Android 10 以下的实现行为不同（0.7.1 修过该版本的 bug）。在工作资料里装还会撞上 shell 权限限制，见错误码那篇 |
| 主题选择（0.9.0 加入） | 界面明暗主题切换 | 纯显示偏好，不影响安装 |

## 三、安装来源字段：Android 14 是一条分界线

IWO 0.4.0 加入了「指定安装来源包名」的能力，0.8.0 又给 Android 14+ 上「能改的字段有限」加了明确警告：Google 从 Android 14 开始限制 shell 用户设置安装来源的能力，installer 字段还能设，originating 字段不行了。你的场景若依赖后者，在 Android 14 及以上没有替代方案 —— 这是系统限制，不是 IWO 的缺陷（官方 FAQ 原样口径）。

## 四、分屏包与批量安装

分屏包与批量安装是系统自带安装器给不了的那部分能力：

1. **自动识别**：一次选择里混着普通 APK 和分屏包（split APK），IWO 会自动检测并把分屏文件归成一组（0.5.0 起）。
2. **支持的打包格式**：普通 `.apk` 之外，可导入 `.apks`（0.6.2 加入）、`.xapk` 与 `.apkm`（0.5.0 起初步支持）。
3. **导入方式**：应用内点「选择文件」；系统「打开方式」里也能选 IWO 直接打开（0.5.0 起提供打开入口）；0.8.0 起还能从别的应用把 APK「分享」给 IWO。
4. **队列管理**：批量安装时队列里可以移除整个应用或单个 APK；进度条下方会显示已完成几个（0.5.0 起）。
5. **典型场景**：换机后一次把攒下的安装包排进去，或装一个被拆成多个分屏包的应用 —— 分屏包必须整组一起装，逐个点系统安装器是装不上的。

## 五、还有一个「加量版」可选

官方 README 点名了一个同类项目 **InstallerX Revived**（[仓库地址](https://github.com/wxxsfxyzm/InstallerX-Revived)）：README 原话是它「包含 Install with Options 的功能以及更多」。作者刻意把 IWO 保持简单 —— 上面这些选项你觉得不够用，可以去看它；只想「选文件、勾一两个开关、装上」的话，IWO 的界面里也够用。

拿不准某个开关要不要开时，先看 [安装失败错误代码解决办法.md](安装失败错误代码解决办法.md) 里它对应的报错场景；还没装好 IWO 本体就从 [下载与安装教程.md](下载与安装教程.md) 开始。
