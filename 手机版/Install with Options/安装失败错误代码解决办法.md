## 一、先确认三件前提

在对照错误码之前，先排除三个最常见的「不是错误码的错误」：

1. **Shizuku 没在运行或没授权给 IWO** —— 现象是没有进度、按钮没反应或直接提示无权限，排查步骤见 [Shizuku激活与连接失败怎么办.md](Shizuku激活与连接失败怎么办.md)。
2. **点了安装但界面一直转圈** —— 旧版本（0.4.2 之前）存在「安装立即静默失败、无限加载」的缺陷，官方已在 0.4.2 修复；一直卡住就把 IWO 升到新版本再试。
3. **安装按钮点了没反应** —— 0.8.0 之前存在「应用未启动时从外部打开 APK，安装按钮失效」的问题（0.8.0 修复），同样先升级。

## 二、常见错误码逐条对照

| 错误码 | 什么意思 | 怎么办 |
| --- | --- | --- |
| `INSTALL_FAILED_NO_MATCHING_ABIS` | APK 里的原生库架构和你手机 CPU 对不上 | 只能换与你架构匹配的版本。x86 设备装不了纯 ARM 包；纯 32 位包在部分新芯片（已砍掉 ARM32 支持的机型）上也装不了 |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE`（signatures do not match） | 新包签名和已装的旧版不一致 | 没有 root 和系统级补丁绕不过：先卸载旧版再装（会丢应用数据）。IWO 的「Disable Verification」**不会**跳过签名校验，它只关基础包校验 |
| `INSTALL_FAILED_VERSION_DOWNGRADE` | 系统拒绝降级安装 | Android 14+ 上降级只有两条路：root，或目标应用本身是调试/测试版构建。勾了「Allow Downgrade」也一样受此限制 |
| `INSTALL_FAILED_USER_RESTRICTED` | 用户或设备策略禁止安装 | 受管配置文件、访客用户里装不了，IWO 无法越过；部分厂商皮肤限制侧载，去开发者选项确认「通过 USB 安装」「USB 调试（安全设置）」是否打开 |
| `Shell does not have permission to access user X` | 在工作资料（Work Profile）里安装时 shell 无权访问该用户 | 在创建工作资料的应用里关掉「禁止调试功能」（Disallow debugging features）限制：在工作资料里打开 TestDPC → 滚到 User restrictions → 点 Set user restrictions → 取消勾选。创建方不提供该选项就只能等开发者加 |
| `INSTALL_FAILED_DEPRECATED_SDK_VERSION` | 应用目标版本低于系统的安装门槛（Android 14 要求 target ≥ 23，Android 15 起 ≥ 24） | 老应用专属的一道拦，勾 IWO 的「Bypass Low Target SDK Block」可绕，规则线与步骤整篇展开在 [Android 14及以上装不了旧应用怎么办.md](Android 14及以上装不了旧应用怎么办.md) |

上面五条与官方 README 的 Troubleshooting/FAQ 口径一致，解释与处理办法均以官方说法为准。

## 三、官方 FAQ 里三个「选项不生效」

**1. 找不到「Bypass Low Target SDK Block」（绕过低目标 SDK 限制）选项**
这个标志是 Android 14 才加入系统的，所以 Android 13 及以下的 IWO 界面里根本不会出现它。反过来，如果你在较老的 Android 上装老应用失败，那不是低目标 SDK 限制的问题（那个限制本身也是 Android 14 才有），要按别的方向排查。这道拦截本身的规则线、报错形态与绕过步骤，整篇写在 [Android 14及以上装不了旧应用怎么办.md](Android 14及以上装不了旧应用怎么办.md)。

**2. 勾了「Grant All Requested Permissions」为什么权限没全给上**
它只自动授予**运行时权限**（相机、麦克风这类），特殊权限（通知访问、无障碍之类要跳设置页单独开的）不在此列，仍要你自己去系统设置里开。

**3. 设置 installer package name（安装来源包名）不起作用**
Android 14 起 Google 收紧了 shell 能改的字段：ADB 还能设 installer 字段，但不能再设 originating package 字段。你的流程如果依赖后者，Android 14 及以上没有绕开办法。此项为官方 README 记载，以官方页面当时显示为准。

## 四、报错之外的两个高频问题

- **装完点开闪退 / 启动失败**：多半是应用本身需要的运行时权限没给、或系统版本不达该应用要求，与 IWO 的安装过程无关 —— 去系统设置里给它补权限、确认它要求的最低 Android 版本。
- **状态显示成功但应用列表里没有**：先在 IWO 里刷新应用列表（它要 `QUERY_ALL_PACKAGES` 权限才能列全已装应用），仍没有就按第二节的错误码重看一次安装结果文本。

如果错误码不在上表里，把 IWO 显示的完整错误文本拿去对照 [GitHub 仓库](https://github.com/zacharee/InstallWithOptions) 的 Issues；装的姿势本身还没走顺的话，回到 [下载与安装教程.md](下载与安装教程.md) 从头过一遍。
