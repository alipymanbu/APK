## 一、为什么必须先跑 Shizuku

普通应用只能以你这个用户的身份干活，而「装应用、改安装参数」这类操作走的是系统里 shell（UID 2000）那一层的接口。Shizuku 的作用就是在你手机上把一个具备 shell 权限的服务跑起来，让 Install with Options 借它的权限调用安装接口 —— 这也是它「不用连电脑敲 ADB」的全部原因。

所以判断顺序很简单：**Shizuku 没装好或没在运行，IWO 就什么都装不了**；Shizuku 正常了，IWO 里的选项才会真正生效。没 root 的情况下，Shizuku 本身也要靠 ADB 或无线调试激活一次。

## 二、三种激活方式，按你的条件选一种

| 方式 | 需要什么 | 特点 |
| --- | --- | --- |
| 无线调试 | Android 11 及以上，就在本机完成配对 | 最常用，不用电脑 |
| ADB（电脑） | 一台电脑 + 数据线，Android 版本不限 | 老系统只能走这条 |
| root | 手机已 root | 最省事，免配对 |

1. **无线调试（Android 11+）**：装好 Shizuku 打开它，按引导进开发者选项打开「无线调试」，用「配对码 + IP 端口」在 Shizuku 里完成一次配对（全程在这台手机上操作），再选「通过无线调试启动」，状态显示「已运行」即成功。
2. **ADB**：电脑装好 adb，手机连上电脑后按 Shizuku 应用里「通过 ADB 启动」给出的命令执行一次。启动脚本的具体路径与命令随 Shizuku 版本变化，以你手机上那个版本界面里显示的为准，不要照搬网上抄来的旧命令。
3. **root**：Shizuku 设置里开「以 root 方式启动」；或者进 IWO 之前先给它 root 授权，跳过 Shizuku 这条链路（IWO 0.3.0 起直接支持 root）。

每次重启手机后，用无线调试方式启动的 Shizuku 服务会停，需要重新启动一次；root 方式的重开成本最低。

配对这一步卡住（一直「正在搜索配对服务」、输完配对码立刻失败、点了启动没反应）是单独一类症状，按现象对照的表在 [无线调试配对失败与启动不了怎么办.md](无线调试配对失败与启动不了怎么办.md)。

## 三、给 Install with Options 授权

Shizuku 运行起来之后，第一次打开 IWO 时 Shizuku 会弹「是否允许」的授权请求，点允许。之后在 Shizuku 的应用管理列表里也能随时查看和撤销这个授权。没有这一步，IWO 界面会一直提示未获得权限。

## 四、IWO 检测不到 Shizuku 时，按这个顺序查

1. **Shizuku 装了吗** —— 没装会提示跳转下载，先装。
2. **在运行吗** —— 打开 Shizuku 看状态；显示未运行就按第二节重新启动，别忘了重启手机后要再来一次。
3. **授权给了吗** —— 到 Shizuku 的授权管理里确认 IWO 在允许列表中。
4. **版本太旧** —— 某些修复（如反射调用导致的安装错误与卡死）是后来版本补上的，应用与 Shizuku 都用较新的版本再试。
5. **用了 Shizuku 的分支 / 隐藏版** —— 官方 README 说明 IWO 兼容原版与使用不同包名、隐藏自己的分支；**0.9.2 这一版专门改进了 Shizuku 检测以支持分支与隐藏的管理器应用**（据 CHANGELOG）。如果你在用分支版仍检测不到，先回到原版 Shizuku 验证一遍，再考虑是否是分支自身的问题。
6. **联发科（MediaTek）设备** —— 官方 README 记录了一个已知坑：Shizuku **13.6.0 在联发科设备上跑不起来**，修复虽已合入仓库但迟迟未发新版。联发科机型如果卡在这里，两条路：把 Shizuku 降到 13.5.4，或改用社区分支（README 里举了 thedjchi 的 Shizuku 分支为例）。此条为官方 README 记载的情况，以 [官方仓库 README](https://github.com/zacharee/InstallWithOptions) 当时显示为准。

## 五、Shizuku 正常但安装仍失败

这属于另一类问题：权限链路通了，是安装本身的报错（签名不匹配、降级限制、ABI 不符等）。错误信息的逐条解释在 [安装失败错误代码解决办法.md](安装失败错误代码解决办法.md)。

如果你还拿不准哪些开关该开、开了会怎样，先看 [高级安装选项怎么用.md](高级安装选项怎么用.md) 再回到报错那篇对号入座。刚装好 IWO、还没走完基础流程的话，从 [下载与安装教程.md](下载与安装教程.md) 第五节接着看即可。
