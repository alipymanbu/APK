## 一、先把流程走对：配对一次，启动每次

无线调试方式下有两件事的频率不一样，很多人卡住是把它们当成了一件：

- **配对只需一次**：开发者选项 → 开「USB 调试」→ 进「无线调试」→ 开「无线调试」→ 点「使用配对码配对设备」→ 在 Shizuku 的**通知**里填入配对码。配对成功后「已配对的设备」里会出现 Shizuku，以后不用再配。
- **启动每次开机后都要做**：受系统限制，手机一重启 Shizuku 服务就停了，要再点一次「通过无线调试启动」。此时无线调试的端口号会变（新版会自动检测，不用手填）。

配对与启动的引导都在 Shizuku 应用里，本篇只解决「照着做了还是不成」的情况。装好 Shizuku 与 IWO 的前置流程见 [Shizuku激活与连接失败怎么办.md](Shizuku激活与连接失败怎么办.md)。

## 二、按症状对照

以下条目整理自 Shizuku 官方手册的常见问题一节，以 [Shizuku 官方文档](https://shizuku.rikka.app/zh-hans/guide/setup/) 当时显示为准：

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 一直显示「正在搜索配对服务」 | 搜索配对服务要访问本地网络，许多厂商在应用切到后台后立刻断它的网 | 允许 Shizuku 后台运行、后台联网（各机型在「设置 → 应用 → Shizuku」里给足后台与自启动权限） |
| 点「输入配对码」后立刻提示失败 | 通知栏样式拦截了输入框 | MIUI / POCO：在系统设置「通知管理 → 通知显示设置」把通知样式切成「原生样式」 |
| 点「通过无线调试启动」没反应、启动不了 | 无线调试状态异常 | 把「无线调试」开关关掉再打开，重试启动 |
| 提示 adb 权限受限 | 厂商给 ADB 加了额外开关 | MIUI / POCO 开「USB 调试（安全选项）」；ColorOS / OxygenOS 关「权限监控」；Flyme 关「Flyme 支付保护」；EMUI 开「仅充电模式下允许 ADB 调试」 |
| 用着用着 Shizuku 随机停止 | 系统杀后台 | 同第一条，给足后台保活 |
| root 方式无法开机自启 | 系统对自启的限制 | 以 Shizuku 官方手册该条的处理为准，或改用每次手动启动 |

厂商差异因机型与系统版本会有出入，同一品牌的新旧系统设置路径也可能变 —— 照不上时以你手机设置里实际出现的项目为准。

## 三、两个特殊环境

- **GrapheneOS**：官方手册提示可能需要关闭「系统设置 → 安全 → Secure app spawning」。
- **联发科（MediaTek）机型**：这是 IWO 侧的已知坑 —— Shizuku 13.6.0 在联发科设备上跑不起来，解决办法是降到 13.5.4 或换社区分支，详见 [Shizuku激活与连接失败怎么办.md](Shizuku激活与连接失败怎么办.md) 第四节第 6 条。

## 四、Shizuku 这边成了，IWO 还报错

配对、启动、授权三步都绿了之后，剩下的失败就与 Shizuku 无关，是安装本身的报错 —— 去 [安装失败错误代码解决办法.md](安装失败错误代码解决办法.md) 对错误码；装旧应用撞的是目标版本拦截，走 [Android 14及以上装不了旧应用怎么办.md](Android 14及以上装不了旧应用怎么办.md)。
