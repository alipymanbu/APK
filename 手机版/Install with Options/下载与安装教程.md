## 一、这是什么、适合谁

Install with Options（下称 IWO）是一个用 Shizuku 以 shell 权限在手机上直接装 APK 的工具，让你不连电脑、不敲 ADB 命令，就能做系统安装器不允许的事：装测试版应用、绕过 Android 14 的目标 SDK 限制、给部分包降级，还能装分屏包（split APK）与一次排队装多个应用。它适合已经会装 Shizuku、手上有各种 APK 想装进手机的进阶用户；如果你只是装一两个普通应用，系统自带安装器就够，不必折腾 Shizuku。

项目开源（MIT 许可），作者 Zachary Wander，源码与发布页在 [GitHub 仓库](https://github.com/zacharee/InstallWithOptions)。

## 三、安装文件从哪拿

本篇配套的安装文件已放在夸克网盘，转存后即可安装：[Install with Options 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5fbe0c775706)。网盘里这版就是上表的 0.9.2 / 12.49M。

想对照官方渠道的话，作者在 GitHub 发布页提供正式包，IzzyOnDroid 的 F-Droid 仓库也收录了它（可用支持该仓库的 F-Droid 客户端自动更新）。两个渠道都是同一个应用、同一个包名，装哪个由你定。

## 四、安装步骤

1. 从上面任一渠道拿到 APK 文件，用文件管理器点它开始安装。
2. 系统会要求你允许该来源安装应用：按提示进入设置、打开「允许来自此来源的应用」（不同厂商叫法略有差异，常见叫「安装未知应用」）。
3. 回来继续安装，装完打开。

IWO 本身只需要「安装应用」与「查询已装应用列表」这类常规权限，装的时候不会向你要存储、无障碍之类额外权限。它的真正权限来自 Shizuku，那是打开应用之后的事。

## 五、第一次打开：先解决权限来源

打开 IWO 后，它会检查本机有没有可用的 Shizuku：

- **没装 Shizuku**：应用会提示你去装，装完还要激活并授权，这是它能装应用的前提；
- **装了但没在运行**：按提示打开 Shizuku 启动它；
- **已 root**：IWO 支持直接走 root，进应用前授予 root 权限即可，可跳过 Shizuku；
- **用 Sui**：也支持（0.7.0 起），Sui 与 Shizuku 同出一位开发者，是另一条免电脑的权限路线。

Shizuku 的安装、三种激活方式（无线调试 / ADB / root）以及「应用检测不到 Shizuku」的排查，单独写在 [Shizuku激活与连接失败怎么办.md](Shizuku激活与连接失败怎么办.md)；配对阶段就卡住的（搜索不到配对服务、配对码填不进），看 [无线调试配对失败与启动不了怎么办.md](无线调试配对失败与启动不了怎么办.md)。

## 六、装第一个 APK 的基本动作

1. 在 IWO 底部点「选择文件」（或从别的应用把 APK 分享 / 用「打开方式」选 IWO 导入，0.8.0 起支持分享导入）。
2. 文件选择器里选中要装的 APK；选中多个文件或分屏包时，IWO 会自动识别并归组。
3. 需要的话在选项区勾上这次要用的开关（默认都不勾，见 [高级安装选项怎么用.md](高级安装选项怎么用.md)）。
4. 点「安装」，等待进度结束。
5. 装完界面会给出结果状态；报错时会显示错误信息，照 [安装失败错误代码解决办法.md](安装失败错误代码解决办法.md) 对号排查。

到这里你就走完了一遍完整链路：拿到文件 → 装好 IWO → 给它权限 → 装上第一个 APK。
