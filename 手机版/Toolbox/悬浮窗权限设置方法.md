## 一、为什么必须要开这个权限

Toolbox 的 M 按钮是**画在游戏画面之上**的悬浮按钮，安卓把这类能力收在「显示在其他应用上层」（也叫「悬浮窗」「在其他应用上层显示」「Display over other apps」「Appear on top」）这个特殊权限里。权限不给，按钮就画不出来 —— 表现为进游戏后什么都正常，就是没有 M。装完 Toolbox 后先把这个开关打开，再按 [下载与安装教程.md](下载与安装教程.md) 走后续步骤。

## 二、各品牌的设置路径

不同厂商把这个入口埋在不同地方，按下表找你自己的机型（菜单字眼略有出入，认「显示在其他应用上层 / 悬浮窗 / Appear on top」这个词）：

| 机型 | 路径 |
| --- | --- |
| 原生安卓（Pixel、摩托罗拉等） | 设置 → 应用 → 特殊应用访问 → 显示在其他应用上层 → 选 Toolbox → 打开 |
| 三星（One UI） | 设置 → 应用 → 右上角菜单「特殊访问」→ 在其他应用上层显示 → 打开 Toolbox 的开关 |
| 小米 / 红米 / POCO（MIUI、HyperOS） | 设置 → 隐私保护 → 特殊权限 → 显示在其他应用上层 → Toolbox → 允许 |
| 其他品牌 | 在设置里直接搜「悬浮窗」或「显示在其他应用上层」，或到 应用 → 特殊访问 附近找 |

嫌翻菜单麻烦就用设置自带的搜索框：输「悬浮窗」「显示在其他应用上层」两个词各试一次，基本都能直达。

## 三、开关是灰色的、或提示「不可用」怎么办

少数机型（尤其低端机）会把这个功能整体禁掉，提示大意是「此功能已关闭，因为它会降低手机速度」。按命中率试：

1. **开发者选项兜底**：设置里打开开发者选项，找「允许屏幕覆盖在设置界面」（Allow Screen Overlays / 允许屏幕叠加）一类开关，打开后再回权限页 —— 原本灰色的开关常就能动了。
2. **从「应用信息」页进**：设置 → 应用 → Toolbox → 权限 / 显示在其他应用上层，有的机型这条近路能绕过被禁的汇总页。
3. **关闭会覆盖屏幕的其他应用**：部分安全类、护眼类、自动点击类应用会抢占悬浮窗能力，临时关掉它们再试。

以上路径按公开的安卓通用教程整理，各家菜单名可能随系统版本调整，以你手机上实际显示为准；仍打不开就到系统设置里搜关键词定位。

## 四、权限打开了还是没有 M 按钮

权限只是前提之一，另两条一起核对：

1. 是不是**从 Toolbox 的图标启动**的（点 Minecraft 快捷方式进去的没有 M）；
2. 是不是已经**进到世界里**了（主菜单界面本来就没有 M）。

两条都对还不出按钮，把 Toolbox 从后台杀掉重开一次；持续不出，按 [常见问题与闪退排查.md](常见问题与闪退排查.md) 查版本兼容与闪退。按钮出现后菜单里各功能怎么点，见 [M菜单常用功能怎么用.md](M菜单常用功能怎么用.md)。
