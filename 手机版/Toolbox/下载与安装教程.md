## 一、这是什么，装之前要明白的一点

Toolbox for Minecraft: PE（一般直接叫 Toolbox）是安卓上的一个「启动器 + 辅助功能层」：**它不是游戏本身**，你先要装好 Minecraft（基岩版 / PE），再从 Toolbox 的图标启动游戏，游戏画面上才会出现它的功能按钮。直接装 Toolbox 而没装 Minecraft，打开后模组功能加载不出来，等于白装。

它的开发者是 MCMrARM（主页 [mrarm.io](http://mrarm.io)），应用闭源，官方给出的常规下载渠道是 Google Play；下面是安装包本身的事实（以本地保存的这份包为准，网上查到的官方最新版不一定和它同一版）：

| 项目 | 值 |
| --- | --- |
| 版本 | 5.4.58 |
| 包名 | `io.mrarm.mctoolbox` |
| 大小 | 38.70M |
| MD5 | `2939556d08d1c9a54baf56ba6949b633` |
| 支持架构 | `armeabi-v7a` / `arm64-v8a` |
| 最低系统 | Android 4.4+（以官方渠道当时显示为准） |

## 二、安装步骤

1. **确认手机上已装 Minecraft**。没装的先装好，Toolbox 只是挂在它上面的一层。
2. **拿到安装包**：Toolbox 安装文件资源（夸克网盘）在 [https://pan.quark.cn/s/ef85a1c65632](https://pan.quark.cn/s/ef85a1c65632)，转存后下载 APK；网盘里这份的版本 / 大小 / MD5 就是上面表格那组数据，下完可以顺手核对一下 MD5 是不是 `2939556d08d1c9a54baf56ba6949b633`。
3. **安装 APK**：点开 APK 按系统提示装即可。如果系统拦「未知来源」，在设置里允许本次安装来源即可，只给这一个安装动作授权就行。
4. **先授「显示在其他应用上层」（悬浮窗）权限**：这一步不做，进游戏后那个 M 按钮不会出现，很多人以为是没装好，其实是权限没给。各品牌机型的入口路径（三星、小米、原生安卓各不相同）与开关灰色的处理，见 [悬浮窗权限设置方法.md](悬浮窗权限设置方法.md)。
5. **从 Toolbox 的图标启动**：桌面点 Toolbox，让它拉起 Minecraft；不要点你平时那个 Minecraft 快捷方式 —— 那样进的是裸游戏，没有 M 按钮。
6. **进世界验证**：进一个存档（先用单人世界最稳），屏幕上能看到 M 按钮即安装成功。点开能出菜单，就可以看 [M菜单常用功能怎么用.md](M菜单常用功能怎么用.md) 了。

## 三、装完没反应怎么办

「装了但没有 M 按钮 / 模组没加载」九成是三件事之一：没装 Minecraft、没从 Toolbox 启动、悬浮窗权限没给。逐条对照 [常见问题与闪退排查.md](常见问题与闪退排查.md) 处理，那边有完整的核对顺序。

## 四、关于版本的一点说明

Toolbox 的版本号形如 5.4.58，更新节奏跟随它要适配的 Minecraft 版本 —— 每当 Minecraft 出新版，Toolbox 常跟着发一个适配版。你手机上装的是网盘里这一版（5.4.58）；以后 Minecraft 升级后如果功能失灵，先想到「两边版本对不上」，处理办法见 [常见问题与闪退排查.md](常见问题与闪退排查.md)。
