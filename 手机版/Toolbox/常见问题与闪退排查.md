## 一、打开后模组功能加载不出来（最常见）

九成的「装了没反应」是下面三条里的一条，按顺序核对：

1. **手机上没装 Minecraft**。Toolbox 只是挂在游戏上的一层，本体没装就什么都加载不出来 —— 先装好 Minecraft 再说。
2. **没从 Toolbox 启动**。点的是桌面的 Minecraft 快捷方式，进的自然是裸游戏。正确做法：桌面点 **Toolbox 的图标**，由它拉起游戏。
3. **悬浮窗权限没给**。系统设置 → 应用 → Toolbox → 权限 → 打开「显示在其他应用上层（悬浮窗）」。权限不给，M 按钮根本画不出来。

三条都对齐后重启一次 Toolbox 再进世界。还不行，往下看闪退一节。

## 二、M 按钮不出现

按钮能出现的前提是「悬浮窗权限 + 从 Toolbox 启动 + 已进到世界里」。桌面图标刚点开闪一下就没了，多数情况是它在后台拉起游戏，属正常启动过程 —— 直接去看游戏画面里有没有 M 按钮。若在某个界面确实没有，退出世界重进一次；仍无效则把悬浮窗权限关掉重开一遍，再按 [下载与安装教程.md](下载与安装教程.md) 的步骤6 复核。

## 三、闪退 / 崩溃

按命中率排查：

- **两边版本对不上**：Toolbox 每隔一段时间发版来适配新的 Minecraft（例如 5.4.57 那次更新说明就是「支持 1.20.80」）。Minecraft 升级到很新的版本、而 Toolbox 还是旧包，就容易一开功能就崩。处理：要么把 Toolbox 升到适配你游戏版本的版本，要么把游戏停在 Toolbox 支持的版本（以 Toolbox 更新说明里列的支持列表为准）。
- **同时开太多功能**：透视 + 全亮 + 快速建造 + 高速移动一起上，低端机容易崩。逐个开、找到肇事的那个。
- **设备内存吃紧**：先清后台再进游戏；大型存档本身占用就高。
- 更新后仍崩：回退到之前能用的那版（网盘里这份 5.4.58 是当前可用基线，见 [下载与安装教程.md](下载与安装教程.md) 的安装包信息表）。

## 四、功能在服务器上无效 / 被封

X-Ray、飞行、瞬时破坏、生成实体这类功能在公共服务器上会被反作弊识别 —— 轻则服务端直接忽略你的操作（表现就是「点了没反应」），重则封禁。这不是 Toolbox 坏了，是服务端在拦。单人世界与本地存档不受影响；去公共服请关掉这些开关，见 [X-Ray透视与小地图使用教程.md](X-Ray透视与小地图使用教程.md) 第七节。
