# iFileSpace 手机外网访问服务器的方法

> 一句话说明：家里部署的 iFileSpace，人一出门手机就连不上是必然的——内网地址出了门就失效；本篇讲给服务器安排外网入口的几条常见路线和怎么选。

## 一、先明白问题出在哪

iFileSpace 服务器装在家里（NAS、软路由或一台常开的电脑）时，手机上填的 `192.168.x.x` 这类地址只在同一 Wi-Fi 下有效，出门用流量必然连不上——这不是 App 出了错，而是这个地址本来就只在局域网内可到达。想让手机在外面也能连上，需要给服务器安排一条外网可达的入口。官方在设计上也点明了这一点：家里部署靠内网穿透或 IPv6 实现公网访问。常见路线有三条，成本与折腾程度各不相同，往下看。

## 二、三条路线对照

| 路线 | 原理一句话 | 成本 | 适合谁 |
| --- | --- | --- | --- |
| IPv6 直连 | 宽带分配的 IPv6 公网地址，手机与服务器直接互访 | 免费 | 家宽已开 IPv6，且手机流量网络也走 IPv6 |
| 内网穿透 | 用一台有公网 IP 的服务器做中转 | 免费中转速度有限；要快就得自己买台云服务器 | 没有 IPv6，或要求稳定可用 |
| 组网工具 | 手机与服务器加入同一个虚拟局域网 | 个人用免费额度够 | 只想自己用，不想把网盘暴露到公网 |

## 三、路线一：IPv6 直连

1. **先测链路**：手机关掉 Wi-Fi 用流量访问 [test-ipv6.com](https://www.test-ipv6.com/)，能给出 IPv6 地址说明手机侧支持；路由器后台看有没有 IPv6 开关，家里宽带的 IPv6 地址以 `2` 或 `240` 等数字开头（而非 `fe80` 开头）才算公网可达；
2. **打开 IPv6**：光猫桥接、路由器拨号的路由器里开启 IPv6；光猫路由模式的话在光猫管理页开；
3. **防火墙别全开**：服务器公网可达后，光猫/路由器的 IPv6 防火墙要么放行服务端口、要么保持开启并单独放行，不要整机关掉；
4. **端口**：家宽的 80、443 端口常被运营商封禁（常见情况），iFileSpace 默认端口 3030 本身就不是常用 Web 端口，直接用它反而省事；
5. **局限要知道**：IPv6 直连要求**两边都有 IPv6**——不少公司 Wi-Fi 只有 IPv4，你到公司就连不回家；另外家庭宽带 IP 会变，配一个 DDNS 动态域名绑住它，手机上填域名而不是 IP，地址变了也不用改。

## 四、路线二：内网穿透（frp 等）

原理是服务器主动连到一台有公网 IP 的中转机上，手机访问中转机：

- **自建 frp** 是最常见的方案：需要另外买一台云服务器当中转。官方论坛管理员在答复「frp 穿透后提示未备案」时给过口径：绑域名走境内服务器要备案，不想备案可以改用香港或境外服务器（2022 年论坛答复）；
- **成品穿透服务**（如花生壳这类）开箱即用，但免费档的带宽与流量限制明显；管理员同样答复过「内网穿透有很多种方案，不一定非要用花生壳」；
- **速度预期**：论坛里管理员对「配置完打开特别慢」的答复是穿透线路质量低所致——免费或低价中转链路上传相册、看视频卡，先怀疑链路再怀疑软件；
- 配好后，手机上填的地址换成中转机给你的地址（域名或 IP + 映射端口）。

## 五、路线三：组网工具（Tailscale / ZeroTier）

这类工具把你的手机和服务器拉进一个虚拟局域网：两边都装客户端、登同一账号，之后手机用一个固定的虚拟网段地址访问服务器，效果与「永远在家连家里 Wi-Fi」一样。

- 不需要公网 IP，也不把网盘暴露到公网，安全性最好操作；
- 免费档的中转节点在境外，直连失败时速度一般；讲究速度可以自建中转节点，做法以工具官方文档为准；
- 代价是**每台要用的设备都得装客户端**——给家人用的话，每人手机上都要装一套。

## 六、打通之后的三件配套事

1. **DDNS**：家宽 IP 会变，路由器或服务器上配一个 DDNS 服务绑住域名，一劳永逸；
2. **HTTPS**：走域名访问建议加反向代理和证书；反代配置记得带上 `proxy_set_header X-Forwarded-Proto $scheme;`，否则会出现网页打得开、文件下载不了的怪症状（排查细节见 [常见问题排查.md](常见问题排查.md)）；
3. **验收**：手机关 Wi-Fi 用流量登录一次服务器；顺手用流量点开一条文件分享链接验一遍——局域网里一切正常、出门全废，是这套配置最常见的遗漏。

外网链路打通后，相册备份在外面也能照常跑，只是照片回传速度取决于链路质量，预期管理见 [相册备份设置.md](相册备份设置.md)；手机端服务器地址的完整填法对照在 [连接服务端与登录.md](连接服务端与登录.md)。
