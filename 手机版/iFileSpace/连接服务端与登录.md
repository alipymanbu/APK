## 一、登录页要填什么

打开 iFileSpace 手机端，你需要提供两个东西：**服务器地址**和**账号密码**。地址指向你自己（或管理员）部署的那台 iFileSpace 服务端；账号是服务端上创建的用户，不是在手机上注册的。两者都有了你就能登录；都还没有，往下看，可以先玩官方演示站。

## 二、还没有服务器？先用官方演示站试一遍

官方提供在线演示站，地址为 [demo.ifile.space](https://demo.ifile.space/)，账号 `demo`，密码 `demo`。把 App 登录页里的服务器地址填成演示站地址，再用这组账号登录，文件浏览、上传、相册备份这些功能都能先摸一遍，跑通之后再决定要不要自己部署一台。

演示站是公开的，所有人都能看到里面的内容，所以别往里放任何私人文件，试试功能就行。

## 三、自己有服务器：地址怎么填

手机上填的地址，就是你平时在电脑浏览器里访问 iFileSpace 用的那个地址。常见几种情况：

| 服务器在哪 | 手机上填的地址 |
| --- | --- |
| 公网云服务器 | `http://服务器IP:3030`，或绑定域名后的 `https://你的域名` |
| 家里 NAS / 软路由 | 同一 Wi-Fi 下填 `http://内网IP:3030`；在外网访问需要先做内网穿透或开通 IPv6，路线对比见 [外网访问服务器的方法.md](外网访问服务器的方法.md) |
| 家里常开的电脑 | 先在电脑上装好服务端（官方提供 Windows / macOS 版），手机与电脑连同一网络后填 `http://电脑内网IP:3030` |

几个要点：

- 服务端默认监听端口是 **3030**（可以在服务端的配置文件里改），端口改过就填改过的那个；
- 手机在流量网络下，填内网地址（`192.168.x.x` 之类）是连不上的，内网地址只在你和服务器处于同一局域网时有效；
- 如果服务端前面挂了 Nginx 反向代理并启用了 HTTPS，手机上就填 `https://` 开头的域名地址。

如果你正要部署服务端：官方提供单文件程序和 Docker 镜像（`lgs821/ifile`），首次运行后在服务器本机浏览器打开 `http://127.0.0.1:3030` 完成初始化，这一步会创建管理员账号。具体步骤见官方快速开始文档 [ifile.space/docs/start](https://ifile.space/docs/start)。

## 四、账号从哪来

- **管理员账号**：首次初始化服务端时创建。忘了密码的话，在服务器终端进入程序目录执行 `./ifile resetpass`，系统会生成新密码并打印在终端里（Docker 部署的先 `docker exec -it ifile /bin/sh` 进入容器再执行）；
- **普通用户账号**：由管理员在服务端后台添加，或者由管理员开放注册后自行注册。免费版本身就支持多用户，一家人或一个小团队共用一台服务器是常见的用法；
- **扫码登录**：手机端 1.0.2 起带扫码登录能力（官方移动端更新记录），入口随服务端版本有差异，以你那台服务端的网页界面显示为准。

## 五、版本搭配与二步验证的坑

两个容易踩的点：

1. **客户端别太旧**：官方在服务端 2.5.6 的更新说明中要求手机端至少为 2.0.3；本教程对应的安装包版本为 2.0.4，满足要求。如果你手上的旧版 App 登录后行为异常，先升级手机端再排查别的；
2. **二步验证**：手机端 2.0.2 起已支持输入两步验证码登录（官方移动端更新记录 2024-04）。但更旧的客户端不支持——官方在服务端 2.3.9（2023 年）的更新说明里写过「开启二步验证后客户端将无法登录」，适用于当时的旧手机端。所以：手机上登录不上且服务端开了二步验证时，先把 App 升到 2.0.4，或让账号所有者在网页端临时关闭二步验证；

登录环节的报错、地址明明没错却连不上，多数能在 [常见问题排查.md](常见问题排查.md) 里对上号；登录成功之后，日常的上传、下载与分享操作见 [文件上传下载与分享.md](文件上传下载与分享.md)。
