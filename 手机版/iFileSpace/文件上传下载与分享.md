## 一、上传速度取决于你选的存储策略

往 iFileSpace 里传文件之前，值得先搞清文件会被存到哪，因为这直接决定上传下载的速度体验：

| 存储策略 | 文件存到哪 | 速度特点 |
| --- | --- | --- |
| 本地存储 | 服务器自己的硬盘 | 走服务器的带宽，公网小水管服务器上传大文件会慢 |
| 对象存储 | 阿里云 OSS、腾讯云 COS、华为云 OBS、又拍云、七牛云、OneDrive、S3 兼容存储 | 客户端直传，不占服务器带宽，速度由你手机到云存储的链路决定 |

官方文档明确说明：第三方存储上传下载均由客户端直连，不经过服务器带宽转发。所以如果你的服务器本身带宽很小（比如 1~5 Mbps 的小水管 VPS），把大文件类存储策略指到对象存储，体验差距会非常明显。存储策略在服务端后台配置，手机端上传时选择对应的空间即可。

## 二、哪些文件能直接在线看

官方给出的可预览格式如下（免费版能力，后续版本可能增加，以官方 FAQ 页面为准）：

| 类型 | 支持的后缀 |
| --- | --- |
| 视频 | webm、ogg、mp4、mov、mpeg、m4v、wmv、flv、rmvb、mkv |
| 音频 | mid、wav、flac、wave、mp3、wma |
| 图片 | gif、png、jpeg、bmp、webp、ico、tif、jpg、svg |
| 文本 | txt、md、json、js、xml、ts、html、css、php、go、java、csv、yaml、sql |

此外，Office 文档与 PDF 支持在线预览，文本文件和 Markdown 文件支持在线编辑（免费版功能列表中有注明）。不在上表里的格式（比如某些冷门视频编码），下载后用本地播放器打开就好，服务端 2.5.9 起还加入了视频转码播放，遇到不能直接播的视频可以留意服务端是否开了这个能力。

## 三、分享的四种方式

官方支持的分享类型有四种，按「给谁看」来选：

| 分享方式 | 适合的场景 |
| --- | --- |
| 直链分享 | 把文件的直接地址发给对方，点开就是文件本身，适合图片、文档这类要直接打开的 |
| 密码分享 | 链接加提取码的形式，适合发给不固定的人群但不想完全公开 |
| 群组分享 | 面向服务端里某个群组成员，比如团队内部共用一批资料 |
| 用户间分享 | 服务端内指定用户之间的私密传递 |

分享是服务器端的能力，手机端和网页端操作的是同一套分享记录。链接发出去之前建议先用另一台设备（或流量网络下的手机）点开验一遍 —— 特别是家宽环境，外网链路没打通时分享链接只有你自己能打开。

## 四、WebDAV：换个 App 也能连你的网盘

iFileSpace 服务端支持 WebDAV（免费版即包含全策略 WebDAV）。对你来说这意味着：手机上不装 iFileSpace 官方客户端、或者临时用别的工具时，也能访问同一份文件 —— 在支持 WebDAV 的第三方文件管理器里填入服务端地址和账号即可挂载。

使用前有两件事在服务端后台确认：WebDAV 的具体连接地址（后台有显示），以及 WebDAV 密码（官方在 2.5.1 版本加入了单独修改 WebDAV 密码的能力，可以和登录密码区分开）。手机端 2.0.4 本身不直接提供 WebDAV 挂载界面，这条路走的是第三方文件管理器。

## 五、离线下载：让服务器替你下

离线下载是服务端的能力：你把下载链接（或种子）交给服务器，由服务器去完成下载，文件直接落到你的网盘空间里，手机端不参与下载过程本身，之后用手机在线看或下载成品即可。免费版包含「服务器本机」离线下载，官方实现上依赖与服务器同一台机器上运行的 aria2（RPC 方式连接）；在另一台机器上跑下载器的「远程离线」属于专业版功能。

这一点和手机端的关系是：白天刷到想存的资源，把链接丢给家里常开的服务器慢慢下，晚上手机打开就是现成的文件 —— 服务器在线时间越长，这套用法越顺。

上传下载环节遇到报错，对照 [常见问题排查.md](常见问题排查.md)；照片类内容的自动备份是独立功能，见 [相册备份设置.md](相册备份设置.md)。
