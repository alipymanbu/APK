# NAVER 韩国旅行要装哪几个应用

> 去韩国旅行，NAVER 家通常要装三个应用：本 app（搜索、新闻、优惠）、NAVER 地图（导航找店）、Papago（翻译）。本篇讲三者的分工、地图怎么切中文、Papago 有哪些翻译方式，按行前准备到行程中的顺序排。
> **相关文档**：[怎么设置中文.md](怎么设置中文.md) · [是什么软件.md](是什么软件.md) · [下载与安装教程.md](下载与安装教程.md)

只装本 app 一个是玩不转韩国旅行的：它管搜索与信息，不管导航，翻译也只有页内翻译这一层。NAVER 家把这三件事拆成了三个应用，共用一个账号。出发前把三个都备齐、该设置的设置好，到了当地就不用手忙脚乱。

## 一、三个应用的分工

| 应用 | 管什么 | 行程中的典型用法 |
| --- | --- | --- |
| NAVER（本 app） | 综合搜索、新闻、购物优惠、附近搜索 | 查店铺营业信息、看优惠活动、逛周边推荐 |
| NAVER 地图（独立应用） | 步行/驾车/公交地铁导航、找店 | 从地铁站走到店门口、查公交到站 |
| Papago（独立翻译应用） | 文字、拍照、语音、对话、离线翻译 | 看菜单、问路、和店员对话 |

三个应用登录同一个 NAVER 账号即可，不需要分别注册。地图与翻译应用各自在官方应用商店搜索安装，名字分别是「NAVER Map, Navigation」和「Naver Papago」。

## 二、NAVER 地图：先把语言切成中文

地图应用支持**韩语、英语、简体中文、日语**四种界面语言，设置路径（Android）：

1. 打开地图应用，点搜索窗右侧的 **MY（头像图标）**；
2. 点右上角的**设置图标（齿轮）**；
3. 点 **Language（语言）**，选简体中文。

语言设置功能从地图应用 5.1.3 版本起支持；5.0 及以上的地图版本要求 Android 8.0 以上才能安装，机型太老的话以应用页面标注为准。要注意地图里的**地点名和搜索结果仍是韩文环境**，界面变中文解决的是看懂按钮和菜单那一层。

## 三、Papago：翻译这一层交给它

Papago 是 NAVER 官方的独立翻译应用，目前支持韩语、英语、日语、中文（简体/繁体）等**14 种语言**互译。功能比本 app 内置的页内翻译全面得多：

| 翻译方式 | 干什么用 |
| --- | --- |
| 文本翻译 | 打字互译，翻译结果附词典释义 |
| 图片翻译 | 拍照自动识别图中文字并翻译（菜单、招牌、路牌） |
| 语音翻译 | 说出句子实时翻成文字和语音 |
| 对话翻译 | 双方各说各的语言，屏幕分栏、自动播报对方译文 |
| 离线翻译 | 提前下载语言包，断网也能用文本翻译 |
| 手写翻译 | 手指写字查询含义 |
| 网站翻译 | 输入网址整页翻译 |

离线翻译在地铁、地下商街这种没网的地方最实用；语言包能不能下、支持哪几对语言以 app 内的下载列表为准。它和本 app 内置翻译器的关系：内置那个只在浏览网页时把当前页翻成中/英/日，没有离线与对话能力，见[怎么设置中文.md](怎么设置中文.md)。

## 四、行前准备清单

1. 三个应用都装好（本 app 安装包见[下载与安装教程.md](下载与安装教程.md)）；
2. 注册或确认 NAVER 账号能登录，注册流程见[账号注册与登录问题.md](账号注册与登录问题.md)；
3. 地图语言切成简体中文；
4. Papago 提前在 Wi-Fi 下下载好中韩离线语言包；
5. 把手机系统语言的地区相关设置检查一遍，避免应用商店搜不到上述应用。

对整个应用还不太了解的话，先看[是什么软件.md](是什么软件.md)再决定要不要全装。
