# NAVER 推送通知怎么关

> NAVER 的推送通知默认开得比较全，本篇讲官方设置里的两层通知开关（app 内按服务关、系统层整关）、夜间免打扰的「礼仪时间」设置，以及关了还来、该来不来时的排查。

装完 NAVER 用几天，你多半会发现通知栏被韩文推送刷屏——内容推荐、活动通知、各类服务提醒都在默认推送。通知有两层开关：**app 内的「通知接收设置」决定哪些服务能推**，**手机系统的应用通知开关决定整个 app 能不能响**。两层都关干净才算真清净，路径均来自官方帮助中心，菜单文字配了中文对照。

## 一、app 内按服务关（推荐先做这里）

1. 打开 app，点**左上角的菜单按钮（≡ 三条杠）**，再点**设置（톱니바퀴，齿轮图标）**；
2. 点**「알림 수신 설정」（通知接收设置）**；
3. 里面先有**总开关（전체 푸시 알림，全部推送通知）**和**内容预览（내용 미리보기）**；
4. 往下的**「서비스별 설정」（按服务设置）**里，邮件、Cafe、购物、支付、健康计步、评论回复等逐项列出，把不想收的服务逐个关成 OFF。

只想保留一两类（比如只收支付相关），把其余全关即可，改动即时反映到推送上。

## 二、夜间免打扰：「礼仪时间」

在「通知接收设置」页面里有一个**「에티켓 시간 설정」（礼仪时间）**开关，打开后可以设定一个**不接收推送的时间段**，比如睡觉时段。比起把通知全关，这个做法能保住白天要紧的提醒，只屏蔽指定时间。官方在评论回复类通知的帮助里给出的就是这个开关，位于通知接收设置页内。

## 三、系统层一次性全关

不想收到任何 NAVER 推送（连设置都懒得挑）：

1. 打开手机**设置 → 应用 → 找到 NAVER**；
2. 进**「通知」**，把**允许通知**整体关掉。

这一层关掉后，app 内各项开关就都推不出来了；Android 13 及以上的机型，第一次启动 app 时弹的那个「允许发送通知」授权，对应的就是这层开关，拒绝过也可以在这里反悔补开。

## 四、关了还来 / 该来不来的排查

| 情况 | 先查什么 |
| --- | --- |
| app 内关了还来横幅 | 另一层没关：按第三节把系统层通知关掉，或回 app 内确认对应服务确实关成 OFF |
| 全关后重装 app 又来了 | 重装会让通知授权回到系统默认，两层都要重新关一遍 |
| 想收的通知收不到 | 按第一节路径确认对应服务是 ON；再查系统层「允许通知」是否开着；登录状态变了也会影响推送，重新登录后观察 |
| 划掉的通知想找回 | 已删除的通知不能恢复，官方帮助明确写了这一点 |

通知权限和别的权限的对应关系（哪个权限管哪个功能），见[核心功能怎么用.md](核心功能怎么用.md)的权限对照表。
