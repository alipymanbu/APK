NAVER 在 Google Play 上架了官方安卓版，国内常见的国行手机因为没有 Google 服务框架，走商店这条路往往装不上，这时候用网盘里的 APK 安装包即可。本篇按「装前确认 → 拿包 → 安装 → 首次启动」的顺序讲，装完先看[怎么设置中文.md](怎么设置中文.md)把看不懂的韩文页面处理掉。

## 一、装之前先确认三件事

| 检查项 | 说明 |
| --- | --- |
| 系统版本 | 官方页面建议在 Android 9.0 及更高版本上安装以获得最佳体验；更旧的机型以安装时的系统提示为准 |
| 存储空间 | 安装包 137.21M，装上后加上缓存与下载内容，建议再留出 1 GB 以上余量 |
| 网络 | 安装不需要联网，但首次启动的首页加载、登录、翻译功能都要网络 |

安装包的核对信息（与网盘里那份一致）：版本 12.11.3、包名 `com.nhn.android.search`、大小 137.21M、MD5 `CEAAF7690EB2B92A60309DA0D3569271`。装完想核对文件完整性：手机上用哈希校验类工具比对 MD5；电脑上 Windows 自带命令即可，在 APK 所在目录执行：

```powershell
certutil -hashfile "naver app_v12.11.3.apk" MD5
```

## 二、从哪拿安装包

两条途径，选一条即可：

1. **官方应用商店**：在 Google Play 搜「NAVER」，认准开发者 NAVER Corp.、包名 `com.nhn.android.search`，点安装。
2. **网盘转存**：手机没有 Google 服务框架、或商店里搜不到时，用 [NAVER 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8b23e7311f65)，转存到自己的网盘后把 APK 下载到手机再安装。

两条途径拿到的都是同一个应用的安卓安装包，区别只在获取方式；没有 Google 服务的手机只能走第二条。

## 三、安装步骤（APK 方式）

1. 把 APK 从网盘下载到手机的「下载」目录。
2. 在文件管理器里点开这个 APK。第一次装会弹「禁止安装未知来源应用」，按你手机的路径去放行：
   - 原生类系统：设置 → 应用 → 特殊应用权限 → 安装未知应用 → 给文件管理器授权；
   - 国产 ROM（MIUI / ColorOS / HarmonyOS 等）：点开 APK 时一般会直接弹窗引导你去对应开关，按提示走即可。
3. 回到文件管理器再点 APK，点「安装」，等进度走完。这个包有一百多兆，安装过程比小应用慢一些，别中途退出。
4. 点「打开」，进入首次启动流程。

安装报错（解析包错误、安装中断）多半是下载不完整或存储不足：重新下载一遍 APK、清出空间后再试。

## 四、首次启动要做的事

1. **登录或先跳过**：不登录也能搜索、看新闻；需要收藏、评论、购物下单再登录，注册与登录见[账号注册与登录问题.md](账号注册与登录问题.md)。登录页右上角可以先把界面切成英文。
2. **给权限**：启动后会逐条申请位置、相机、麦克风等权限。拒绝并不影响搜索与看新闻，只是对应的拍照搜、语音搜等功能用不了，之后随时能到系统设置里补开。
3. **认一下界面**：底部一排是主要板块，顶部一条是搜索栏，先别急着研究每个角落，直接在搜索栏搜一个你知道的韩文词试试手感。

## 五、以后怎么更新

- 从官方商店装的：在商店里更新即可，商店版本号会比本篇的 12.11.3 新。
- 从网盘 APK 装的：拿到新版本 APK 后直接覆盖安装，收藏与账号数据跟着账号走，覆盖安装不丢本地数据；卸载重装前先确认自己记得登录方式。
