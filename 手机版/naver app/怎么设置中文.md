# NAVER 怎么设置中文

> 先说结论：NAVER 的 app 界面本身没有「一键切成简体中文」的开关，本篇讲实际可用的三层办法——登录页切英文、自带网页翻译器把韩文页面翻成中文、拍照识字翻译，以及一份常用韩文菜单对照。

很多教程标题写「NAVER 一键设置中文」，实际装上你会发现：app 的界面文字（按钮、菜单、栏目名）主要是韩文，官方没有提供整套简体中文界面。能做的是「把你看的内容翻成中文」+「把个别界面切成英文」。本篇写的都是 app 自带的功能，不需要装别的东西。

## 一、登录页先切英文

登录那一刻是最容易卡住的，因为登录页整屏韩文。登录页的右上角有语言切换按钮，点开选「English」，登录页变成英文，按英文界面填账号密码即可。登录进主界面后，界面文字仍是韩文为主，靠下面两节解决。

## 二、把韩文页面翻成中文（自带翻译器）

NAVER app 内置了网页翻译功能，打开任何一篇韩文新闻或帖子后：

1. 点页面**底部工具栏右侧的「更多」按钮（⋯ 三个点）**；
2. 选**翻译器（번역기）**运行；
3. 在弹出面板里手动选「原文语言」和「翻译目标语言」，比如韩语 → 简体中文；
4. 页面内容即被翻译，同域名内继续翻页翻译会保持生效；跳到别的网站、或点面板里的「关闭」按钮，翻译模式就结束了。

三个限制要知道：

- 翻译语言目前只覆盖**韩语 ↔ 英语 / 中文 / 日语**，其他语言互翻不支持；
- 翻的是**页面内容**，不是 app 的菜单按钮；
- 手动翻译功能从 6.5 版本起就有，你现在装的 12.11.3 都在支持范围内。

需要离线翻译、对话互译这类更强的翻译能力，官方有独立的翻译应用 Papago，与本 app 的内置翻译器的差别见[韩国旅行要装哪几个应用.md](韩国旅行要装哪几个应用.md)。

## 三、拍照识字翻译（对着实物翻）

看到实物上的韩文（招牌、包装、菜单）想弄懂意思：

1. 点顶部搜索栏里的**相机图标**；
2. 切到**文字识别**模式，对准要看的文字；
3. 识别完成后文字会高亮，点**翻译**即可，也支持复制、听发音。

文字识别与翻译支持韩语、英语、中文、日语四种，识别其他语言可能不出结果。

## 四、常用韩文菜单对照

界面没翻译时，先认住这几个高频词就够用了：

| 韩文 | 意思 |
| --- | --- |
| 검색 | 搜索 |
| 뉴스 | 新闻 |
| 로그인 / 로그아웃 | 登录 / 登出 |
| 설정 | 设置 |
| 고객센터 | 客服中心 |
| 번역기 | 翻译器 |
| 홈 | 首页 |
| 쇼핑 | 购物 |

遇到不认识的菜单，也可以直接截屏后用第二节的方法拍照识别翻译。

## 五、别白折腾的几个方向

- **改手机系统语言**：把系统语言改成中文或韩文，都改变不了 app 菜单的中文显示，别在这上面花时间；
- **找「中文版安装包」**：官方没有出过独立的中文版 app，界面语言是应用内决定的；
- **指望搜索结果变中文**：搜索结果是韩国网页环境，内容翻译靠第二节的翻译器逐页处理。
