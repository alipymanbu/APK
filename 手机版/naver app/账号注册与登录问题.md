不注册账号也能用 NAVER 搜索和看新闻；但收藏帖子、发表评论、使用商城下单、在「我的」里查支付记录，都需要登录。一个 NAVER 账号通用于 NAVER 家的所有应用（地图、网漫、Cafe 等），注册一次即可。注册入口可以在 app 的登录页点注册按钮进，也可以直接访问官网注册页。

## 一、注册流程

1. 打开 app，进入登录页（可先在右上角切英文），点「注册 / Sign up」；
2. 同意服务条款与隐私政策；
3. 设置 **ID 与密码**：ID 只能用**小写字母和数字**，大写字母是不被接受的；密码按页面提示的复杂度要求设置；
4. **手机号验证**：填写手机号并选择国家区号（支持选择海外区号），接收短信验证码填入；
5. 验证通过后补充昵称等信息，完成注册。

几点提前知道：

- **验证码收不到**是海外注册最常见的坎：确认区号选对、号码填对，偶尔会有短信延迟几分钟的情况；实在收不到，换一个时段重发，或换一条注册渠道（网页端）再试。有用户反馈部分海外号码收码成功率一般，属正常现象，多试或换号即可，以注册页当时的提示为准；
- 个别情况下，NAVER 会要求补充额外验证（如身份材料），遇到按页面提示处理即可，不是每号必现；
- 注册页面与流程随版本调整，上面是主干步骤，以你注册时页面显示为准。

## 二、登录常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 提示 ID 或密码错误 | 先检查 ID 是否输成了大写——NAVER ID 不支持大写字母，注意键盘大小写锁定状态 |
| 收不到登录验证码 | 同注册：核对区号与号码、等几分钟再重发；异地或新设备登录时可能触发额外验证，按页面提示走 |
| 换设备后登录被要求额外验证 | 账号安全机制，按提示完成手机验证即可；这也是别忘了注册手机号仍在使用的原因 |
| 忘记密码 | 走登录页的「忘记密码」流程，用注册手机号或邮箱找回 |

账号安全设置（改密码、设备管理、二次验证）在 app「设置 → 我的账号/安全设置」里管理。

## 三、账号通用于哪些服务

一个 NAVER 账号可以在以下地方直接登录，不需要重复注册：

- NAVER 家的各个独立应用：NAVER 地图、NAVER Webtoon、NAVER TV、Cafe 等；
- NAVER 网页版门户与邮箱等配套服务。

反过来，你在 NAVER app 里的收藏、评论、购物记录，登录同一账号在任何设备上都能看到。

- **app 内**：「设置 → 客服中心」，可以提交问题咨询；
- **韩国客服电话**：1588-3820（韩国本地拨打）；
- 官方帮助站点为 `https://help.naver.com`，客服答复以韩语为主，可用翻译工具辅助阅读。
