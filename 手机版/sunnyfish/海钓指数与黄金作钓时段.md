## 一、指数是什么、综合了什么

SunnyFish 每天给出一个 0–100 的海钓指数分，并标出当天的「黄金咬钩时段」。按官方页面与商店页的口径，评分参考这几类环境因子：

| 因子 | 看什么 |
| --- | --- |
| 风力 | 风速与阵风，直接影响船钓安全和矶钓抛竿 |
| 海浪 | 浪高与涌浪，决定近海能不能站礁、船能不能出 |
| 潮汐 | 潮水周期与潮流阶段 |
| 能见度 | 海雾天不适宜出行 |
| 水温 | 影响鱼群活跃度与目标鱼种 |
| 气压 | 气压变化趋势与咬口的关系，是钓友普遍关注的指标 |

月相也参与评分：农历初一、十五前后是大潮汛，潮流更急，这个周期会体现在指数里。

指数只回答「环境条件好不好」，不回答「一定上鱼」—— 钓法、饵料、标点这些变量它不管。

## 二、一套可执行的看分流程

打开指数页后按这个顺序过一遍：

1. **先看分数定大方向**：低分的日子直接改计划，不再细看；中高分的日子进入下一步；
2. **再核风速阵风**：切到逐小时风力，对照你自己的船型或钓位能接受的阈值（船钓与矶钓的安全线不一样，以自身经验为准）；
3. **再看浪**：有效浪高与涌浪周期，站礁主要看浪高，船钓还要看涌浪周期；
4. **最后对时段**：把黄金咬钩时段与潮汐表的涨落潮时间叠在一起，选重合的窗口出发。

这套流程的意义在于：指数是综合分，但每个人的安全底线不同，分高不等于你的船能出。

## 三、黄金咬钩时段怎么用

- 时段按小时给出，适合前一晚看完就定第二天的出发时间与闹钟；
- 时段与潮汐转折、气压变化往往重合，涨落潮的读法见 [潮汐表怎么用.md](潮汐表怎么用.md)；
- 到现场后以实际鱼口为准，指数是提前规划工具，不是实时鱼情。

## 四、和预报数据联动的两个入口

- 想知道「为什么是这个分」：切到海图的天气图层，看风场、浪、气压的空间分布，具体见 [气象图层与海图.md](气象图层与海图.md)；
- 想挑具体钓位：把保存的标点与当天风向、浪向对照，背风一侧的标点通常更可下竿，标点管理见 [钓点保存与海上导航.md](钓点保存与海上导航.md)。

## 五、安全底线

指数再高，出发前也要核对气象部门发布的大风、海雾等预警；预警生效时以预警为准，不要按 App 分数决定出海。

官方的国际版商店页还提到 App 会推送大风、海雾、突发飑线这类即时提醒 —— 出海当天把系统通知权限给 SunnyFish 开着，多一道提醒就多一层保障。
