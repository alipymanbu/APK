## 一、卡片上各字段的意思

LLPower 的电池卡片会实时刷新下面这些数据，插电与放电时都在跳：

| 字段 | 含义 |
| --- | --- |
| 瞬时功率 | 当前充/放电的功率，充电岛上跳动最明显的就是它 |
| 电池电流 | 流入或流出电池的电流，充电为正、放电为负 |
| 虚拟电压 | 经映射还原出的充电电压（见第三节） |
| 电池温度 | 电池本身的温度，夏天边充边玩时涨得快 |
| 供电状态 / 电池状态 | 是否在供电、电池处于充电还是放电 |
| 电源适配器 | 识别到的充电头信息 |
| 系统电池百分比 | 系统报的电量百分比 |

数值会持续自动刷新，你不用手动刷新，也不用一直开着 App —— 充电岛自己会更新。

## 二、为什么测出的电池容量和标称不一样

这是被问得最多的一个。**通常不是软件测错了**：点该卡片右侧的「i」标志，里面有容量测量的完整逻辑说明 —— 容量是按实际充入电量累计估算的，受起止电量区间、温度、充电策略影响，和出厂标称值有出入很正常。看完那页说明你就能判断自己这次的读数可不可信。

## 三、虚拟电压是怎么回事

很多机型的芯片不开放读取真实充电电压的接口，直接读会有明显偏差。LLPower 用了一套虚拟电压映射方案来还原，官方口径是误差控制在 5% 以内，并对天玑系列芯片做了专门适配；单电芯、双电芯两种电池方案都兼容。所以你看到的电压是「估算还原值」，拿它对比充电头标称电压时留这个余量。

## 四、功率读数偏低先别慌

100W 的手机只显示几十瓦、甚至几瓦，绝大多数情况是系统充电策略压的，不是数据坏了：亮屏会限功率、机身发热会降功率、电量接近充满也会降到几瓦。完整解释在 [充电岛不显示怎么办.md](充电岛不显示怎么办.md) 的第四节。

## 五、历史充电记录（2.x 版本）

如果你装的是 2.x 版本，数据不只实时看，还能往回翻（以下功能来自官方更新说明，1.4.0 没有）：

- **充电过程功率曲线**：一次充电全程的功率变化画成曲线，能看出什么时候开始降功率；
- **充电时间预测**：官方说明是基于机器学习的预测，比纯线性估算准一些，但仍是以此前充电习惯为依据的预测值，不是承诺；
- **历史数据筛选**：按条件筛出想找的那几次充电记录；
- **本地备份与还原**：充电记录存在手机本地，支持备份与还原 —— 换机或重装前提一份，能带走历史数据（备份文件在哪、怎么导出，以应用内说明为准）。

这些数据都只存在你手机上，查询与备份操作也都在本机完成。

## 六、想让读数更好看地展示

数据本身改不了，但显示方式可以调：主题、透明度、壁纸在 [主题与小组件设置.md](主题与小组件设置.md)；如果连数据都刷不出来、岛也不弹，那是权限没给到位，回 [下载与安装教程.md](下载与安装教程.md) 走一遍首启配置，再按 [充电岛不显示怎么办.md](充电岛不显示怎么办.md) 排查。
