# 充电岛不显示怎么办

> 灵动岛不弹、不更新、不自动消失、功率数字偏低时，按本篇逐项排查权限与系统适配。

## 一、先确认你的系统有没有「灵动岛」

LLPower 的充电胶囊依赖安卓的「实时活动 / 实时通知」能力，不是所有系统都有。目前已知支持的系统：

| 系统 | 状态 |
| --- | --- |
| OPPO ColorOS 16 及以上 | 支持（充电时可激活灵动岛或锁屏岛） |
| 小米澎湃 OS 最新版本（HyperOS 3.1 及以上） | 支持 |
| 荣耀最新版本 | 理论上支持，有用户反馈可能存在 Bug |
| 其他不支持实时活动的系统 | 走普通通知呈现，不会弹胶囊 |

**所有系统都支持普通通知** —— 如果你的手机不在上面名单里，充电时看到的是一条常规通知而不是顶部胶囊，这是正常表现，不是软件坏了。

补充两点背景（截至 2026 年 9 月，以各厂商页面为准）：

- 各家其实都有自己的胶囊类功能，只是叫法不同 —— OPPO 叫流体云、小米叫灵动胶囊、华为叫实况窗、realme 叫 Mini Capsule。这些系统自带的胶囊默认只显示自家服务；LLPower 走的是系统开放的**实时活动/实时通知**接口，所以能不能弹胶囊取决于你的系统有没有开放、有没有放行，而不是手机品牌本身。
- 同样是「插电显示」，有的系统在桌面/锁屏走胶囊、在应用内走别的样式（比如华为的实况窗与充电气泡并存），这是厂商自己的规格，不只影响 LLPower。

## 二、灵动岛不更新或不自动消失

这种情况在 OPPO 系机型上最常见，原因是厂商对通知与后台的限制比较严格。按顺序试：

1. 打开 LLPower → 设置 → 通知设置 → 重要提示，按页面要求把权限逐项授予；
2. 权限给完还不行，再开「高级保活」—— 官方说明里这是最终手段，能解决大部分被系统杀后台的场景；
3. 系统侧也要放行：在手机设置里找到 LLPower，允许后台运行、允许自启动，并把它加入电池优化白名单（首次进入时那个「立即开启」按钮做的就是这件事，见 [下载与安装教程.md](下载与安装教程.md)）。

如果权限全给了还是老样子，先看看手机是不是刚充了很久、机身偏热，或者软件最近活动太频繁 —— 这两种情况下系统会临时限制它，**放置一会儿通常自己就恢复了**，不用反复重启。

## 三、充电岛压根不弹出来

按这个顺序自查：

1. **是否正在充电**：这个胶囊是随插入充电器弹出、拔出后收起的，不充电时它不出现是设计如此。
2. **通知权限是否给了**：系统设置 → 应用 → LLPower → 通知，确认允许通知且没被归到静默分组。
3. **是否被省电策略杀掉**：同一路径下把「电池用量」设为不限制 / 允许后台运行；在最近任务里下拉锁定该应用（不同品牌叫法略有差异）。
4. **密码与初始配置是否完成**：首次进入要输 `乐哥好`，并完成电池优化授权，没走完引导的安装是跑不起来的。

## 四、显示的充电功率比标称低很多

比如充电头上写 100W，岛上只显示几十瓦甚至几瓦 —— 这基本都是手机充电策略的正常表现，不是读数错误：

- 100W 机型的实际峰值跑到 70W 左右已经算很好了；
- **亮屏会直接限制充电功率**，打开 LLPower 看着它充，比熄屏停在桌面时读到的功率更低；
- 电量低于 70%、温度正常时显示 30W 左右很常见；温度升高或电量接近充满，系统会进一步压低功率，只剩几瓦也正常。

判断读数本身准不准，见 [电池数据怎么看.md](电池数据怎么看.md)。

## 五、已知问题（有用户反馈的）

- **深色模式下颜色没跟着切换**：有用户反馈过，开发者在帖子回复里确认已解决、随下个版本修复。装的是 1.4.0 这类较早版本遇到，属已知情况，等更新即可。
- **2.4.1 在部分 OPPO 机型上界面显示过小**：开发者的回复是特意加入的显示机制。也就是说这是设计取舍而非故障，觉得不合适只能等后续版本调整或换用其他版本（版本以官方发布页当时显示为准）。
- **App 颜色与系统深色模式、界面缩放**这类问题都出现在 2.x 测试版阶段 —— 官方自己也标注当前为测试版，受限于机型与系统差异仍可能有未发现的小问题。遇到样式类的毛病，先确认自己装的版本，再决定是等更新还是退回旧版。
