## 一、能投到哪些设备

Symfonium 的投屏目标与大致能力（以官方说明为准，具体到你的设备型号以实测为准）：

| 目标 | 支持范围 | 注意点 |
| --- | --- | --- |
| Sonos | 播放、分组/退出分组、单个音箱音量调节 | 局域网内发现设备 |
| Chromecast | 基本投屏 | 遇到格式不兼容时会自动转码 |
| UPnP / DLNA | 投屏播放 | 兼容的渲染器上支持无缝播放 |
| Kodi | 作为投屏目标 | — |
| Plex / PlexAmp 客户端 | 投到别的 Plex 播放端 | 适合「手机当遥控器、音箱/电视出声」 |

前提都一样：**手机和目标设备在同一局域网**。投屏不是把文件传过去就不管——手机这一侧仍是控制端，队列、切歌都在 Symfonium 里操作。

## 二、怎么发起投屏

1. 播放页找**投屏/cast 按钮**（如果界面里看不到，检查 `设置 → Interface → Advanced settings` 里的 **Hide Cast Button** 是不是被关了）。
2. 选择目标设备。
3. 选完播放，播放页会切到「控制该设备」的状态；此时手机退出应用甚至锁屏，音箱那边照常播（前提是网络稳定，见下一节）。

投屏状态下，均衡器、ReplayGain 这类**本地 DSP 处理不再作用于目标设备**——声音在渲染器那边解码输出，想调音得在投屏目标自己的设置上调（比如 Sonos 应用里调）。本地听和投屏听的音质策略分开，是正常现象。

## 三、投屏中途掉回本地播放

这是投屏最常见的问题，症状是：正在往 Sonos 上播，过一会儿声音突然从手机出来了，重新选设备又要等半天。按下面顺序查，多数是设备网络而非播放器的问题：

1. **手机是不是在省电断网**：部分设备（尤其带屏的安卓播放器、便携设备）锁屏后会断 Wi-Fi。保持屏幕常亮试一次——如果掉线消失，就是设备的省电策略在断网，去该设备的系统设置里放开 Wi-Fi 休眠。
2. **系统级 Wi-Fi 休眠**：确认手机在 `设置 → WLAN → 高级`（各厂商叫法不同）里没有选「锁屏后关闭 WLAN」。
3. **Automatic renderer reset（自动重置渲染器）**：Symfonium 检测不到渲染器时会自动切回本地播放（这是它防止「你以为在播其实没播」的保护）。设备网络恢复后，你可以在设置里关掉这个自动切换，让它等设备回来——但底层的断网问题依然要解决，否则只是不切回来而已。
4. **Remember last renderer（记住上次的渲染器）**：如果你经常杀掉应用重开，打开这个选项，重开后自动连回上次的设备，不用每次重新选。

一个判断技巧：掉线时**看音箱是不是还在继续播**。音箱还在播 = 只是手机这端「失去控制连接」，问题在手机网络；音箱也停了 = 整个投屏会话断了，多半是路由器/设备侧把连接掐了。

## 四、投屏不出声的常规检查

- 目标设备和手机**不在同一网段**（比如一个连 2.4G 一个连访客网络、路由器开了 AP 隔离）→ 打开设备发现；
- 手机连的是**蜂窝数据**而不是 Wi-Fi → 切回同一局域网的 Wi-Fi；
- 格式问题：Chromecast 对某些编码不认，Symfonium 会走转码，如果你限制过最大码率（见 [离线缓存和下载设置.md](离线缓存和下载设置.md) 的流量部分），确认数值不至于压得太低。

投屏时播放突然中断、服务器数据不对这类问题与投屏无关，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
