## 一、先搞清楚你能加哪些源

Symfonium 的「媒体源」分三大类，添加入口相同，填的东西不同：

| 类型 | 具体支持 | 你需要准备什么 |
| --- | --- | --- |
| 媒体服务器 | Plex、Emby、Jellyfin、Audiobookshelf、Subsonic / OpenSubsonic、Navidrome、Kodi | 服务器地址 + 账号（或 API Key） |
| 网盘 | Google Drive、OneDrive、Dropbox、Box、pCloud | 对应网盘的登录授权 |
| 本地与网络文件 | 手机本地存储、Samba（SMB v2/v3）、WebDAV | 文件路径 / 共享地址 + 账号密码 |

你完全可以同时加好几个源——比如 Plex 主库 + 本地几个文件 + 一个 SMB 共享，Symfonium 会把它们合成一个曲库视图，播放队列也是同一套。

## 二、添加媒体服务器

以最常见的 Jellyfin / Plex / Subsonic 系为例（其他服务器流程一致，只是填写项略有差异）：

1. 打开 Symfonium，进「添加媒体源」（Add provider）入口。
2. 选择对应的服务器类型。
3. 填服务器地址。格式一般是 `http://服务器IP:端口` 或 `https://域名`；家里的服务器用局域网 IP（如 `http://192.168.1.10:8096`），出门也能用的话需要服务器那边做了外网访问。
4. 登录授权：
   - **Jellyfin**：支持 Quick Connect 快速连接，按屏幕提示在服务器端确认即可；也可以用账号密码登录。
   - **Plex**：走 Plex 账号授权；受管账号（managed account）也支持。
   - **Subsonic / OpenSubsonic / Navidrome**：填服务器地址、用户名、密码，或用 API Key。
5. 选要纳入的库，等首次同步完成。

首次同步会把整库元数据拉一遍，库大时这一步可能要跑不少时间，放在 Wi-Fi 下做。同步完曲库怎么保持更新，官方文档有专门一篇讲 provider 数据同步。

### 各服务器能力有差别，别一概而论

不同服务器给 Symfonium 的数据和接口不一样，直接影响你能用哪些功能：

| 能力 | Plex | Emby / Jellyfin | Subsonic / OpenSubsonic | Kodi | Audiobookshelf |
| --- | --- | --- | --- | --- | --- |
| 导入歌单 | 支持 | 支持 | 支持 | 支持 | 支持 |
| 把歌单改动写回服务器 | 支持 | 支持 | 视服务器而定 | 不支持 | 支持 |
| 转码播放 | 支持 | 支持 | 支持 | — | 支持 |

（表中「支持」的前提是服务器端本身提供该数据与接口；老版本 Subsonic 服务器可能要开兼容模式，功能会有取舍。）

一个实用建议：**服务器越老，兼容性越看运气**。Subsonic 系里官方推荐的现代实现有 Navidrome、Gonic、Ampache 等；如果你在用老服务器且各种不对劲，先考虑升级服务器而不是折腾客户端。

## 三、添加网盘与 NAS

- **网盘**（Google Drive / OneDrive / Dropbox / Box / pCloud）：选对应项 → 走一次 OAuth 授权 → 选文件夹。注意网盘类是按「文件夹 + 标签解析」建库的，它会读音频文件的标签元数据来生成曲库，所以**首次扫描比纯文件浏览器慢**，大库建议 Wi-Fi 下跑完第一次。
- **SMB 共享**（NAS 最常见）：填 `smb://服务器/共享名`，选 SMB v2 或 v3，给账号密码。家用 NAS（群晖、威联通等）开 SMB 共享后从这里连。
- **WebDAV**：填地址 + 账号密码，认证支持 Basic 和 Digest 两种。如果服务器端配置了特殊的 realm / auth，客户端可能登不上——这时候去查服务器端日志比在手机上瞎试快。

局域网外要访问 NAS，需要路由器端口转发或 VPN 回家，Symfonium 本身不做内网穿透。

## 四、曲库同步与歌单

- **歌单同步**：服务器类源的歌单会导入 Symfonium；上表标了「写回」的源，你在 Symfonium 里改歌单会同步回服务器，不同步写回的源改动只留在本地。
- **本地文件 / 网盘 / SMB / WebDAV** 这类文件型源：可以导入 M3U / PLS 歌单文件，但改动不会「写回」到哪——本来也没有服务器。
- **全局过滤**：设置里可以按数据源过滤显示内容，比如只想看离线可用的、或只想看某个服务器的曲库。

## 五、连不上时怎么办

服务器类源连不上、同步不全、歌单不同步，九成是地址、账号或服务器端设置的问题。逐项排查的顺序和常见报错，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

连上之后如果你在意「出门没网就不能听」，把自动缓存开起来，做法见 [离线缓存和下载设置.md](离线缓存和下载设置.md)。
