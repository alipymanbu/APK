## 一、游客模式与登录，区别在哪

不用账号也能先体验，但两者的差别很关键：

| | 游客模式 | 登录账号 |
| --- | --- | --- |
| 数据存哪 | 本机 | 云端 |
| 卸载应用后 | 数据全部丢失 | 重新登录就回来 |
| 多设备同步 | 不行 | 手机、平板、电脑互通 |

所以装好应用后尽早登录。多台设备可以同时登录同一个账号，库存与图纸保持同一份。**没开通会员的账号，务必牢记用户名或绑定手机号**，否则账号丢了找不回来。

## 二、会员：哪些免费、哪些收费

基础功能免费用；部分高级功能是会员专享，按需购买。价格参考 App Store 内购页显示的档位（其他渠道与安卓端以官方页面当时显示为准）：

| 档位 | App Store 显示价格 |
| --- | --- |
| 月费会员 | ¥8.00 |
| 年费会员 | ¥58.00 |
| 永久会员 | ¥108.00 |

购买渠道与到账方式：

- **支付宝 / 微信**：购买后实时到账；如果状态没更新，在「我的」页面点「刷新缓存」按钮刷新状态。
- **小红书店铺**：兑换码自动发货，查收短信或小红书订单页的发货详情；长时间没收到就联系店铺客服。
- 账号问题（找回密码、会员找回）：联系**AI豆仓小红书主页橱窗客服**。已开通高级会员的账号都能找回。

用户协议可在官方页面查看：[one.aidoucang.cn/legal/terms](https://one.aidoucang.cn/legal/terms)。

## 三、常见问题速查

| 问题 | 答案 |
| --- | --- |
| 使用要花钱吗？ | 基础功能免费，高级功能会员专享，按需购买 |
| 不知道怎么用？ | 「我的」页面底部有「新手教程」，图文介绍所有功能 |
| 能多设备同时登录吗？ | 可以，数据与账号关联，多端同时在线 |
| 忘记用户名/密码？ | 开通过会员的账号联系小红书主页橱窗客服找回；没开通过的靠用户名或绑定手机号 |
| 链接提取图纸失败？ | 先把图片保存到本地，再从本地导入，见 [图纸上传与色号高亮使用技巧.md](图纸上传与色号高亮使用技巧.md) 第二节 |
| 卸载后数据没了？ | 游客模式数据只在本机，卸载即丢；登录后走云端备份 |
| 安装包从哪拿？ | 见 [下载与安装教程.md](下载与安装教程.md) |

表里的答案如果没覆盖到你的情况，翻应用内「我的 → 新手教程」—— 那是功能级的图文说明，具体按钮在哪都写清了；流程类问题则按表里的指引跳到对应篇章。
