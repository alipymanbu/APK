## 一、AI豆仓是什么

AI豆仓是给拼豆（熨珠手工）玩家用的库存与图纸管理工具：豆子还剩多少、一张图纸要消耗哪些色号、拼完怎么扣库存，都在一个应用里记。安卓、iOS、网页版、小程序都有，数据登录后云端互通。本篇只讲安装包获取与安装步骤；装好之后怎么用，看另外三篇。

你手头如果还没有安装包，安卓用户可以走这两条路：

1. **夸克网盘（本篇头部那条链接）**：[AI豆仓 安装文件资源（夸克网盘）](https://pan.quark.cn/s/33769be0410f)，转存后下载即可。
2. **官方下载页**：官网 [app.aidoucang.cn](https://app.aidoucang.cn/) 上有安卓 APK 下载入口和 App Store 入口，具体文件名与版本号以官网当时显示为准。

## 三、安卓安装步骤

1. 下载 APK 到手机，点开安装。
2. 若系统弹出「禁止安装未知来源应用」，是系统对非应用商店来源包的默认拦截 —— 在设置里允许本次安装即可（不同品牌手机入口略有差异，一般在「设置 → 安全/隐私 → 安装未知应用」）。
3. 装完打开，首次进入是游客模式，可以先随便点点熟悉界面。
4. 核对包名：在 `设置 → 应用管理 → AI豆仓 → 应用信息` 里能看到包名 `cn.aidoucang.app`，与上表一致就是同一个应用。

安装失败或打不开，按症状依次排查：

| 症状 | 处理 |
| --- | --- |
| 提示「禁止安装未知来源应用」 | 按上文第 2 步允许本次安装 |
| 提示「解析文件时出现问题」 | 安装包下载不完整或损坏 —— 重新下载；用 MD5 工具核对文件哈希是否与上表一致，不一致就是包不对 |
| 提示存储空间不足 | 先清理手机存储，留出比安装包（108.55M）更富余的空间再装 |
| 装完闪退、打不开 | 先确认手机系统版本满足下载页标注的要求；仍闪退则清应用缓存、重启手机再试，详见 [账号会员与常见问题解答.md](账号会员与常见问题解答.md) |

## 四、装完先要知道的几件事

- **游客模式的数据只存在本机**：不登录也能用，但卸载应用数据会一起没掉。建议第一件事就是注册登录，让库存和图纸上云，见 [账号会员与常见问题解答.md](账号会员与常见问题解答.md)；登录前想先留底，导出方法在 [库存备份与账号设置教程.md](库存备份与账号设置教程.md)。
- **多端是同一份数据**：同一个账号在安卓 App、iOS App、网页版 [www.aidoucang.cn](https://www.aidoucang.cn/) 和小程序上登录，库存、图纸、作品是互通的。
- **系统要求**：官方下载页会标注当前安装包的系统要求，以页面当时显示为准。
- **学习入口在应用内**：「我的」页面底部有「新手教程」，功能都有图文说明。

装好之后，从 [库存管理与消耗计算教程.md](库存管理与消耗计算教程.md) 那篇的五分钟流程开始上手。
