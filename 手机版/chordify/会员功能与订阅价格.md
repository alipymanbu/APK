## 一、这是什么

Chordify 采用免费 + 订阅的模式：搜歌、出和弦、跟着弹这些核心操作免费，移调、变调夹、变速、循环、导出这几组练习工具放在付费档里。本篇给一张免费/付费对照表，再讲订阅计费规则、价格口径和取消方法——决定掏不掏钱之前先看这篇。

## 二、免费版与会员对照

| 功能 | 免费版 | 会员（Premium） |
| --- | --- | --- |
| 歌曲搜索与和弦识别 | 有 | 有 |
| 动画和弦图（吉他 / 钢琴 / 尤克里里等） | 有 | 有 |
| 个人曲库与跨设备同步 | 有 | 有 |
| 与 YouTube 等播放源配合使用 | 有 | 有 |

| 放慢速度（难点段落跟上节奏） | 无 | 有 |
| 循环片段（反复练某一小节） | 无 | 有 |
| 导出 MIDI 文件 | 无 | 有（见下方档位说明） |
| 导出 PDF 和弦谱 | 无 | 有（见下方档位说明） |

对照口径来自官方商店页的功能清单（截至 2026-09 查阅，以应用内当时显示为准）。**免费档能用几首歌、有没有广告，官方没有稳定的公开口径**，也有用户反馈免费额度这些年在收紧——以你实际安装的版本表现为准。

**档位说明**：官方商店文案在不同时期写法不一样，早期把 MIDI / PDF 导出归在 Premium 里，近期文案则出现「Premium 与 Toolkit」的分层写法（导出功能归在更高一档）。你打开订阅页时看到哪一档就是哪一档，**价格与档位一律以应用内结算页显示为准**。

## 三、订阅怎么计费

- **周期**：按月或按年订阅，年付折算下来比月付便宜（官方商店页提供两种周期）。
- **自动续费**：默认自动续订，除非你在当期结束前至少 24 小时关闭；关闭后当期用到期为止。
- **扣费渠道**：安卓版走 Google Play 扣费，币种按你商店账号所在地区结算；iOS 版走 App 内购买。
- **试用**：是否提供试用、试用多长，以结算页当时显示为准；试用期内取消通常不扣费，但仍以 Google Play 的实际规则为准。

## 四、价格怎么看

各渠道看到的价格差异很大，举几个**实际出现过**的数字（只说明「价格不统一」，不作为报价）：

- App Store 中国区曾显示月订 ¥45 / 年订 ¥363、也有月订 ¥60 / 年订 ¥273 等多组档位；
- 第三方评测文章写过约 $6.99/月、年付折合约 $3.49/月，也有写 $9.99/月、$49.99/年的。

同一天不同来源都能对不上，原因包括地区、平台、促销与档位差异。**唯一可信的数字是你点进订阅页后结算画面上那个**——付之前看清是月付还是年付、是哪个档位。

## 五、怎么取消

1. 打开 Google Play App → 点右上角头像 → 「付款和订阅」→ 「订阅」。
2. 找到 Chordify，点进去选「取消订阅」。
3. 确认后状态会显示「已取消，将于某日到期」——当期权益保留到到期日，之后不再扣费。

iOS 设备订阅的入口在「设置 → 你的 Apple ID → 订阅」。取消入口若与上述路径不一致，以当前版本应用商店的实际界面为准。扣费争议（重复扣费、取消后仍扣）直接找 Google Play 或 Apple 的客服申诉，比找应用更快。其他使用中的问题见 [常见问题与故障排查.md](常见问题与故障排查.md)。
