# XMBOX 与 TVBox 同类播放器的区别

> 搜这类应用时你大概率会同时看到 TVBox、FongMi、影视仓这些名字，本篇讲清它们的关系与取舍。

XMBOX 所属的这一族应用都源自同一条开源脉络：TVBox 把「播放器壳」与「内容源」分离的开源做法被多个开发者接续，衍生出若干分支，XMBOX 是与 FongMi（蜂蜜影视）同源的发行版本。它们装上去的长相、配置方式高度相似，差异集中在细节取舍上。

## 一、这一族应用的关系

| 名字 | 与 TVBox 的关系 | 常被提到的特点 |
| --- | --- | --- |
| TVBox（Q 版） | 原版开源项目路线（q215613905 的 TVBoxOS） | 社区配置生态的起点，支持直播回放 |
| TVBox（T 版） | takagen99 的并行分支 | 界面与图标改版，与 Q 版并行更新 |
| FongMi（蜂蜜影视） | 基于 TVBox 生态的开源重写（[github.com/FongMi/TV](https://github.com/FongMi/TV)） | 自动跳过失效线路、DLNA 投屏、HTTP/3，分 TV 版 / 手机版 / 旧设备兼容版 |
| 影视仓 | TVBox 的多源聚合改版 | 把多个配置「仓」聚合导入 |
| XMBOX | 与 FongMi 同源（包名一致 `com.fongmi.android.tv`） | 在同源功能上做减法，界面精简，手机竖屏适配 |

以上信息均来自社区公开仓库与下载站的说明，各分支的维护节奏不同，具体功能以你实际拿到的版本为准。

## 二、对你实际使用意味着什么

**配置格式大体通用。** 这族应用读的是同一生态的配置：一份 TVBox 格式的点播配置，在 XMBOX、FongMi、影视仓之间通常都能导入。所以你换用其中一个应用时，已经填过的配置地址大概率不用重新找。

**同包名导致不能共存。** XMBOX 与 FongMi 系共用包名 `com.fongmi.android.tv`，同一台设备只能装其中一个，换装要先卸载（TVBox 原版、影视仓的包名不同，通常可以与 XMBOX 并存）。换装注意事项见 [下载与安装教程.md](下载与安装教程.md)。

**操作习惯可以平移。** 「设置里填配置 → 首页出内容 → 播不了先换线路再换内核」这套流程在这族应用里是一致的，你在 [首次使用与接口配置.md](首次使用与接口配置.md) 学到的步骤对它们同样适用。

## 三、怎么在这族应用里做选择

| 你的情况 | 更值得考虑 |
| --- | --- |
| 主要在手机上看，想要竖屏、精简的界面 | XMBOX 这类做了手机适配的发行版 |
| 以电视盒子为主力，要遥控器与语音搜索体验 | FongMi 电视版或同类 Leanback 架构版本 |
| 想同时管理很多份配置、在多「仓」之间切换 | 影视仓这类聚合向改版 |
| 只想装一个，别折腾 | 挑一个维护活跃的用着，配置通用，随时可换 |

对多数从手机入门的用户来说，XMBOX 与 FongMi 手机版的体验差别不大——它们本来就同源，选哪个更多是版本与界面的口味问题，而不是功能有无的问题。
