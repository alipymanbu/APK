# XMBOX 投屏与在电视上使用

> 本篇讲两个场景：把 XMBOX 正在播的内容投到电视上，以及把它直接装进电视或盒子里。

XMBOX 手机版在手机上用竖屏界面，但它并没有把自己锁死在小屏幕里：既支持 DLNA 投屏到大屏，也有同源的电视版发行可以装进电视盒子。两种路径适合的人不同，先看你要哪种。

## 一、DLNA 投屏：手机选片，电视出画面

前提是手机与电视（或支持 DLNA 的盒子）连在同一个局域网下：

1. 电视端保持可被发现的投屏状态（多数智能电视的「无线投屏/多屏互动」开关即是）；
2. 在 XMBOX 里正常播放一部影片；
3. 点播放页的投屏按钮，选择列表里出现的电视设备；
4. 电视接管画面后，手机可以退出播放页做别的，选下一集仍在手机上操作。

投不出来时依次检查：两台设备是否在同一 Wi-Fi（路由器开了「AP 隔离/访客网络」会互相看不见）、电视的投屏服务是否被省电策略杀掉、源本身是否允许被投（个别线路的流会拒绝投屏，换一条线路再试）。

## 二、把 XMBOX 装进电视或盒子

电视盒子和智能电视同样是安卓系统，装法与手机一致：

1. 用电脑或手机下载 APK（来源见 [下载与安装教程.md](下载与安装教程.md)）；
2. 把 APK 拷进 U 盘，U 盘插到电视或盒子的 USB 口；
3. 在电视端用文件管理器打开 APK 安装；电视端没有文件管理器时，先在电视的应用商店里装一个文件管理类应用；
4. 安装完成后打开，配置方式与手机版相同，参照 [首次使用与接口配置.md](首次使用与接口配置.md)。

电视端用遥控器操作，XMBOX 这类同源应用的电视界面基于安卓 TV 的 Leanback 架构，方向键与确认键即可完成全部浏览操作，搜索可以用应用内的语音搜索（需电视端支持语音输入）。

## 三、手机版与 TV 版：同包名，别同时装

XMBOX 的电视版与手机版共用包名 `com.fongmi.android.tv`（与 FongMi 系相同）。这意味着：

- 同一台设备上，手机版和 TV 版只能留一个，后装的会提示冲突或覆盖失败；
- 想换装另一个版本，先卸载现有的再装；
- 配置（填过的源）跟随应用数据，卸载即清空，换装前把配置地址复制留存一下。

## 四、两种方案怎么选

| 场景 | 建议 |
| --- | --- |
| 偶尔在客厅看，用手机操作更顺手 | 手机版 + DLNA 投屏 |
| 电视是主力观影设备，天天用 | 直接装电视版，遥控器操作，体验更稳定 |
| 电视很老、装不了第三方应用 | 手机版投屏是唯一选择；老电视没有联网功能就只能外接电视盒子 |
