## 一、先确认你要装的是哪一版

AutoGLM 有安卓 App、iOS App 和网页端三个入口（网页端见 [网页版怎么用.md](网页版怎么用.md)）。本篇对应的是安卓安装包，这份包的实际信息如下，装完后可以用包名核对是不是同一份：

| 项目 | 信息 |
| --- | --- |
| 应用名 | AutoGLM |
| 版本 | 2.0.20 |
| 包名 | com.zhipu.agent |
| 安装包大小 | 约 122.36 MB |
| 开发者 | 北京智谱华章科技股份有限公司 |

网上的最新版本号随时会变，以你实际拿到的安装包为准。费用方面，2025 年 8 月 2.0 版全量开放时的官方口径是免费、无需邀请码，后续政策有没有变化以官方页面为准。

## 二、安卓安装步骤

1. 打开上面的 AutoGLM 安装文件资源（夸克网盘）链接，把安装包转存到自己的网盘后下载到手机。
2. 在手机文件管理器里找到下载好的 APK 文件，点击安装。
3. 首次安装第三方来源的包时，系统会提示「不允许安装未知来源应用」，按提示去设置里给对应应用（浏览器或文件管理器）授权一次安装权限。各品牌入口不一样，常见路径是「设置 → 安全 / 更多设置 → 安装未知应用」。
4. 安装完成点「打开」，进入登录页。

也可以在应用宝等国内应用商店里搜「AutoGLM」直接装，但商店收录的版本号通常落后于官方最新版，能装到哪个版本以商店当时显示为准。

## 三、装不上时的几个常见原因

| 现象 | 处理 |
| --- | --- |
| 提示「未知来源」被拦截 | 按上面第二步第 3 点，把来源应用的安装权限打开 |
| 提示存储空间不足 | 包本身 122 MB，加上安装过程的解压空间，保证剩余空间在 1 GB 以上再装 |
| 提示签名冲突或已存在同名应用 | 先卸载手机上旧的 AutoGLM 再装（卸载会清掉本地数据） |
| 下载中断、包损坏 | 回网盘重新下载一次，装前对比文件大小是否与上表一致 |

## 四、装完后的登录

打开 App 后需要登录才能给云设备派任务。按官方隐私政策，注册账号需要绑定真实手机号；新版支持本机账号一键登录，也可以走验证码方式，具体以你打开的登录页显示为准。登录后建议先发一条简单任务试试水（比如「现在几点了」这类不涉及支付的问题），确认云端设备能正常启动。账号登录和隐私条款的更多细节见 [云手机账号与隐私安全.md](云手机账号与隐私安全.md)。

## 五、iOS 版的差异

- iOS 版在 App Store 搜「AutoGLM」可以装到，免费，要求 iOS 15.0 或更高（截至检索时，以 App Store 页面为准）。
- 两端的功能主线一致（给云端设备下指令），但版本号更新节奏不同步，界面细节可能有差异。
- 本文讲的是安卓包的安装，iPhone 用户直接走 App Store 即可，不需要网盘里这份 APK。
