## 一、AutoClaw 是另一个产品

AutoClaw 是智谱推出的桌面 AI Agent 应用（官网 `https://autoclaw.zhipuai.cn/`），装在 Windows 10 及以上或 macOS 的电脑上。它和 AutoGLM 手机版是同一家的两条产品线：AutoGLM 手机版操作云端的智能体手机，AutoClaw 在你的电脑上调用本地工具、浏览器和文件来干活。

AutoGLM 手机 App 在 2.0.20 版本的更新说明里出现了「新增 AutoClaw 移动端入口」，也就是 App 里多了一个跳到 AutoClaw 的入口，让你在手机上也能看到和推进电脑上跑的任务，而不是说手机 App 本身变成了 AutoClaw。

## 二、它能干的六类活

按官方页面的分类：

| 能力 | 干什么 |
| --- | --- |
| 办公自动化 | 内置 50 多个预置技能，生成 Word、Excel、PPT、报表、会议纪要 |
| 自媒体运营 | 从选题、标题、正文到多平台改写连续推进小红书笔记、公众号文章、微博推文、短视频脚本 |
| 金融投资 | 接行情数据、整理财报、跑策略回测、出投资分析报告 |
| Web 产品搭建 | 用自然语言描述需求，生成网页、小程序原型、数据看板并在浏览器里预览 |
| 浏览器自动化 | 自动填表、批量截图、网页数据抓取、后台巡检、定时任务 |
| IM 接入 | 在飞书、企业微信、微信等对话框里下任务，结果自动回流到聊天 |

共同点是一条：你只说目标，它自己拆步骤、调工具、连续执行，而不是一问一答。

## 三、费用和获取

- 基础功能免费，按天给免费积分额度；更重的用量有付费方案（截至检索时的口径，具体额度以官方页面为准）。
- 新用户注册时有赠送额度的活动，活动内容和数额经常变，别按文章里的数字预期，以你注册时页面显示的为准。
- 下载入口在官网，装好后用智谱账号登录。

## 四、和 AutoGLM 手机版怎么分工

- **出门用手机版**：点外卖、订票、查评价这类生活任务，发出去就能后台跑，付款时接管一下。
- **坐电脑前用 AutoClaw**：要产出文件（PPT、报表、长文）、要批量操作网页、要定时跑的活，本地电脑执行更合适。
- 两个都用智谱账号，AutoGLM 手机 App 里的 AutoClaw 入口用来在路上跟进电脑上的任务。

另外官方文档里还有个「AutoGLM-OpenClaw」的名字，那是把 AutoGLM 云机接进飞书的开发者玩法，属于智谱开放平台 Coding Plan 的会员权益，普通用户可以先不用管。至于 AutoGLM 家族里 App、网页版、开源框架各自是什么，见 [与开源版的区别.md](与开源版的区别.md) 和 [网页版怎么用.md](网页版怎么用.md)。
