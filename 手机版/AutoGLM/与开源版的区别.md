> 搜「AutoGLM」时会同时碰到智谱的手机 App 和一个叫 Open-AutoGLM 的开源项目，本篇讲清两者差在哪、各自适合谁。

## 一、两个 AutoGLM 不是一回事

- **AutoGLM（手机 App）**：智谱官方出的智能体产品，装上登录就能用，任务在官方的云端设备上执行，你只管下指令。
- **Open-AutoGLM**：同一家公司在 GitHub 上开源的手机 Agent 框架（仓库 `zai-org/Open-AutoGLM`），面向开发者：需要自己接线、自己部署模型，让模型通过 ADB 去操作一台真实或虚拟的安卓设备。

两者技术路线同源，但使用门槛完全是两码事。

## 二、对照表

| 维度 | AutoGLM App | Open-AutoGLM（开源版） |
| --- | --- | --- |
| 面向人群 | 普通用户 | 开发者、研究者 |
| 获取方式 | 应用商店或安装包直接装 | 从 GitHub 仓库克隆部署 |
| 设备要求 | 一台普通安卓或 iOS 手机 | 一台安卓设备，外加一台带算力的电脑 |
| 模型怎么来 | 官方云端现成提供 | 自己部署（官方建议 24GB 以上显存的 GPU），或接现成的模型服务端点 |
| 操作对象 | 云端的智能体手机 / 智能体电脑 | 你自己连接的真实安卓设备或模拟器 |
| 上手成本 | 装完登录即用 | 要配 ADB、Python 环境和模型服务 |
| 费用 | 免费（以官方页面为准） | 代码开源免费，但算力和接口成本自己承担 |

## 三、普通用户该选哪个

只想「让 AI 帮我点外卖、订酒店、做 PPT」，直接用 App 就够了，不用碰开源版：安装和登录见 [下载与安装教程.md](下载与安装教程.md)，AutoGLM 安装文件资源在头部网盘链接里。

开源版适合的场景是：想在自己控制的设备上研究屏幕理解与操作自动化、想看模型每一步的决策过程、或者想把手机 Agent 能力接进自己的程序里。

## 四、走开源路线前的注意事项

- 认准官方仓库地址 `https://github.com/zai-org/Open-AutoGLM`。搜索引擎里排名靠前的「AutoGLM 部署教程」类站点不少是第三方整理的资料页，内容可能与最新版本对不上，安装命令一律以仓库 README 为准。
- 开源版连接的是你自己的手机，涉及支付、验证码、发送消息这类敏感操作时，自己在流程里留好确认环节，别让脚本无人值守地跑。
