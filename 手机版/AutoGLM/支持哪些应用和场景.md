## 一、支持的应用范围

官方口径是支持 50 款以上的主流中文应用，覆盖社交通讯、电商购物、美食外卖、出行旅游、视频娱乐、音乐音频等类别。下面是官方文档里列出的部分：

| 分类 | 应用 |
| --- | --- |
| 社交通讯 | 微信、QQ、微博 |
| 电商购物 | 淘宝、京东、拼多多 |
| 美食外卖 | 美团、饿了么、肯德基 |
| 出行旅游 | 携程、12306、滴滴出行 |
| 视频娱乐 | bilibili、抖音、爱奇艺 |
| 音乐音频 | 网易云音乐 |

这是官方接口文档里列的「部分」名单。注意有两套口径：上面这个「50 款以上」说的是它的操作能力范围；实际装在那台云手机里的 App 数量，据 2025 年 8 月上线时的媒体报道约为 30 到 40 款（两处报道口径不一），而且当时不开放用户自主安装新 App——也就是说，名单之外的应用你没法自己装进云手机，能不能用、什么时候新增，以你 App 里云手机桌面的实际显示为准。不在桌面上的应用，可以试试通过云电脑的浏览器走网页版操作。

## 二、五类高频场景和指令示例

官方推荐的场景集中在五类：外卖选购、商品购买、出行服务、资讯新闻、租房找房。下面这些写法都来自官方示例，可以直接改改关键词就用：

| 场景 | 指令示例 |
| --- | --- |
| 外卖点单 | 在淘宝闪购帮我查找库迪咖啡的经典拿铁并下单 |
| 再来一单 | 用美团再点一单最近的外卖 |
| 商品下单 | 帮我在京东下单购买小米手环 9 Pro |
| 查商品评价 | 打开拼多多搜索笔记本，看销量最高那款的评价 |
| 路线规划 | 规划一条从重庆解放碑到重庆火锅博物馆的步行路线 |
| 周边查询 | 圆明园周围有停车场吗 |
| 订机票 | 帮我查一下明天广州到北京的机票 |
| 订酒店 | 帮我订一晚靠近合生汇地铁口的酒店 |
| 听歌 | 用汽水音乐搜《平凡之路》来听 |
| 有声书 | 用番茄小说播放一本悬疑题材的有声书 |
| 看视频加评论 | 去哔哩哔哩搜索英雄联盟直播并播放 |
| 找租房 | 我在上海黄浦区附近上班，帮我找周边合租，预算 2500 到 3500，南向三居 |

写指令的通用思路：把「用哪个 App、找什么、什么条件」说全，越具体越不容易走偏，展开见 [云手机任务怎么用.md](云手机任务怎么用.md)。

## 三、办公和内容类任务

生活场景之外，它还能操作网页端：官方发布 2.0 时演示过跨网站的完整流程——操作网页版飞书、网易邮箱、知乎、微博、抖音等站点，从信息检索到内容撰写，再到生成视频、PPT 或播客，最后直接完成内容发布。这类长流程任务在电脑浏览器里盯过程、改稿子更方便，见 [网页版怎么用.md](网页版怎么用.md)。

## 四、应用范围会随版本变化

应用支持范围会随版本更新变化：你手机上这份 2.0.20 能操作哪些应用、入口长什么样，都以 App 内实际显示为准。遇到某个应用怎么都操作不了，先更新到最新版再试；用这些应用前的账号登录、隐私条款相关的事，见 [云手机账号与隐私安全.md](云手机账号与隐私安全.md)。
