## 一、入口在哪

浏览器打开官方地址 [https://autoglm.zhipuai.cn/](https://autoglm.zhipuai.cn/)，页面上就是「AutoGLM 的电脑」：一个带编辑器、文件窗口的云电脑界面。未登录时以游客身份也能看到页面和案例，正式派任务需要登录，登录方式以页面实际提示为准。

搜索时注意认准这个官方域名，第三方资料站和文章转载页也可能排在前面，别从那些页面里点下载。

## 二、网页版能做什么

官方首页的案例区展示了任务的主要产出类型，点开能看到完整的执行记录：

| 类型 | 官方案例 |
| --- | --- |
| PPT | 如何培养孩子专注力家长主题PPT、《出师表》课件制作 |
| 播客 | 自媒体知识付费思路、银发经济播客 |
| Markdown 报告 | 今日金价分析、股票中短线技术分析、中奖后理财规划 |
| 网页代理 | 南京照相馆短评撰写并发布 |

也就是说，生活类「操作 App」的任务和办公类「查资料、写内容、做文件、发出去」的长流程任务都能交给它。后一类在电脑大屏上盯着过程、接着改稿子更方便。除了上面四类，官方隐私政策里还提到了语音转文字、智能会议纪要、深度研究报告这类能力，入口以页面实际显示为准。

还有个别指望的事：据发布时的媒体报道，那台云电脑除浏览器外只预装了 LibreOffice 一套办公软件，且不开放自己装软件——所以「让它在云电脑里用某个特定桌面软件」这种需求大概率做不到，产出文件后下载到本地再处理更现实。

## 三、网页版和手机 App 是什么关系

- **同一套云端能力**：App 操作「智能体手机 + 智能体电脑」，网页端直接给你「智能体电脑」的窗口，任务执行逻辑一致。
- **入口互补**：手机上临时派个活用 App；电脑上要盯执行过程、取文件、接着编辑，用网页版省事。任务窗口带「接管」按钮，随时可以自己上手。
- **账号**：两边都是登录后使用，账号体系以官方页面提示为准。

只想在手机上用的话，安装方式见 [下载与安装教程.md](下载与安装教程.md)；两边入口怎么分工，也可以先看 [云手机任务怎么用.md](云手机任务怎么用.md) 再决定。
