## 一、把脚本打包成 APK

Auto.js 免费版自带打包功能，能把你写好的脚本变成一个独立安装包，别人不装 Auto.js 也能运行：

1. 在主界面**长按**你的脚本（或脚本所在文件夹），在弹出菜单里选「打包」。
2. 填写应用名称、包名、版本号，确认权限列表（用到什么勾什么，截图、网络等按需）。
3. 等待打包完成，生成的 APK 会在通知里给出路径，装到任意安卓手机上即可。

几个实际会碰到的事：

- 打包后的应用第一次启动同样要开**无障碍服务**（界面在系统设置里，不会自动跳转），别忘了把 [无障碍服务开启教程.md](无障碍服务开启教程.md) 里的防杀后台设置也做一遍。
- 免费版打包**没有代码加密**，脚本内容可以被还原出来，别把带账号密码的代码打给不熟的人。
- 打包应用的定时任务、开机启动在部分系统上会被拦，行为与直接用 Auto.js 跑脚本时的系统限制一致，排查思路见 [常见问题解答.md](常见问题解答.md) 第五节。
- 上面说的是**单脚本**打包。脚本不止一个、或要带图片等资源时，得用「项目」方式：主界面「+」→ 新建项目，把脚本和资源都放进项目目录，对整个项目打包；界面里引用同目录图片写相对路径即可。

## 二、用 VSCode 在电脑上写、手机上跑

脚本稍长就会发现在手机小屏上改代码很折磨。Auto.js 官方提供了 VSCode 插件（`Auto.js-VSCodeExt`），思路是：电脑装插件起一个服务，手机连过来，之后**代码在电脑上写、运行和保存都在 VSCode 里一键发到手机**。

两端各做一步：

1. **电脑端**：安装 [Visual Studio Code](https://code.visualstudio.com/)，在扩展市场搜 `Auto.js-VSCodeExt` 安装，然后按 `Ctrl+Shift+P` 执行「Start Server」（开启服务器）。
2. **手机端**：打开 Auto.js → 侧边栏 →「连接电脑」，输入电脑在局域网里的 IP（电脑上 `ipconfig` 看 IPv4 地址），连接成功后 VSCode 底部会有提示。
3. 之后在 VSCode 里打开 `.js` 文件，用命令面板（`Ctrl+Shift+P`）搜 Auto.js 相关命令：「Run」直接在手机上运行当前脚本，「Save」把文件保存到手机；日常就是「改完 → Run 看效果」的循环。

手机和电脑必须在**同一个局域网**；公司或校园网常见设备隔离，连不上时换手机热点最快。调试期把 `console.log` 打满，日志会在 VSCode 输出面板里实时滚动，比在手机上看爽得多。

## 三、日常开发的分工建议

| 场景 | 建议做法 |
| --- | --- |
| 短脚本、临时改几行 | 直接手机编辑器改，够用 |
| 写完整项目 | VSCode 写 + 保存即推送，代码留在电脑上好备份 |
| 给别人用 | 打包 APK，按第一节的清单交代权限 |

代码写法上拿不准的函数，翻 [常用API速查.md](常用API速查.md)；还没跑过第一段脚本的话，从 [脚本编写入门.md](脚本编写入门.md) 开始；需要重新拿安装包时回 [下载与安装教程.md](下载与安装教程.md)。
