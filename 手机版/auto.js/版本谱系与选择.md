## 一、一张表看懂 Auto.js 家族

Auto.js 最初是开发者 hyb1996 于 2017 年初发布的开源项目，2020 年停止维护后，作者转向付费的 Auto.js Pro，社区则从 4.1.1 的源码接续出多个免费分支。下表是社区整理的主要脉络（日期为社区年表记录的预估，以各项目仓库为准）：

| 项目 | 开发者 | 免费情况 | 起点 | 现状 |
| --- | --- | --- | --- | --- |
| Auto.js | hyb1996 | 免费（MPL 2.0，附加非商业条款） | 2017 年 1 月 | 2020 年 3 月停止维护，终版 4.1.1 Alpha2 |
| Auto.js Pro 7 / 8 / 9 | hyb1996 | 付费 | 2019 年起 | Pro 9 社区年表标注 2023 年初停止迭代，官方渠道仍在售卖 |
| Auto.js M | TonyJiangWJ | 免费开源 | 2019 年 11 月 | 社区分支 |
| AutoX（Autox.js） | kkevsekk1 及后续维护者 | 免费开源 | 2020 年 7 月 | 持续维护，文档在 `doc.autoxjs.com` |
| AutoJs6 | SuperMonster003 | 免费开源 | 2021 年 12 月 | 持续维护，文档在 `docs.autojs6.com` |

本套文档对应的 4.1.1 Alpha2，就是第一行里那个**免费开源版的最终版本**。

## 二、怎么辨认手里装的是哪个

应用名全都长得像，包名才是身份证：

- `org.autojs.autojs` —— 免费开源版 4.1.1，即本文档对应的包。
- 其他分支（Pro、AutoX、AutoJs6）包名各不相同，安装前在手机「应用信息」里核对一眼，别靠图标和名字猜。

还有一个实用细节：这些应用包名不同，**可以同时装在同一台手机上**互不干扰，想对比着用是可行的。

## 三、停止维护的 4.1.1，为什么还有人在用

几个被社区反复提到的理由，供参考（多为社区说法，无官方出处）：

- **免费、无广告**，不需要注册账号。
- 社区普遍反馈付费版对部分主流应用做了操作限制，而 4.1.1 没有——这也是它被翻出来继续用的主要理由。
- 从 4.1.1 源码接续的分支（AutoX、AutoJs6）保留了它的 API 风格，老脚本稍改就能跑。

代价也要清楚：4.1.1 是 2020 年的安装包，在新版安卓上会遇到无障碍「受限设置」、后台启动限制这些系统收紧措施（见 [常见问题解答.md](常见问题解答.md)），官方不会再发修复版本。

## 四、按需求选

| 你的情况 | 建议 |
| --- | --- |
| 想要免费开源、脚本自己写自己用 | 4.1.1（本套文档对应，安装见 [下载与安装教程.md](下载与安装教程.md)） |
| 手机系统很新、4.1.1 兼容问题多 | 看 AutoX / AutoJs6 这类持续维护的社区分支，对新系统的适配更新更多 |
| 需要 OCR、代码加密打包等 Pro 独有功能 | 走官方付费渠道的 Auto.js Pro |
| 手上有旧脚本 | 三者同源，4.x 的 API 大体通用；Pro 9 的新模块在免费版上没有 |

## 五、换分支要注意什么

- **包名不同可以共存**，但脚本、配置不互通，迁移时要把脚本文件拷过去。
- 写法上以 `text()` / `click()` / `findOne()` 为代表的核心 API 各分支一致，差别在边缘模块（数据库、OCR、通知管理等），老脚本报「模块不存在」多半是撞上了这种差异。
- 查 API 时注意文档版本：4.x 免费版查 [https://hyb1996.github.io/AutoJs-Docs/](https://hyb1996.github.io/AutoJs-Docs/)，其他分支用各自的文档站，混着查会看到免费版没有的函数。
