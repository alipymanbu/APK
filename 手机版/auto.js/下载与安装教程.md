## 一、先看清你要装的是哪一版

搜索引擎里搜 Auto.js，结果常常混着好几个东西：免费开源版、付费的 Auto.js Pro、以及社区接续开发的 AutoX / AutoJs6。它们包名不同、图标不同，但名字都很像。本篇对应的是**免费开源版的最后一个版本**，你拿到的安装包信息如下：

| 项目 | 信息 |
| --- | --- |
| 版本 | 4.1.1 Alpha2 |
| 包名 | org.autojs.autojs |
| 安装包大小 | 16.95M |
| MD5 | 5901F0A00845D351BE1DB106D156EA51 |
| 系统要求 | 采集记录标注 Android 5.2 以上（原文如此，按 Android 5.x 及以上理解；能否安装以你的手机实测为准） |

两个实用判断方法：

- 装完后在系统「应用信息」里看包名，是 `org.autojs.autojs` 的才是免费开源版；Pro 版与其他分支的包名都不同。
- 4.1.1 Alpha2 之后官方不再更新免费版，如果网上看到「更新到 9.x」「Pro 8.x」之类的说法，那是另一条产品线，与本篇的安装包对不上。

各版本之间的来龙去脉、怎么按需求选，在 [版本谱系与选择.md](版本谱系与选择.md) 里单独讲。

## 二、获取安装包

Auto.js 免费开源版官方早已停止维护，官网渠道不再提供这份历史版本的下载，比较省事的办法是从网盘转存：

**Auto.js 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/a6758b43ec4b](https://pan.quark.cn/s/a6758b43ec4b)

打开链接 → 转存到自己的网盘 → 在网盘里下载 APK 文件到手机。如果你手机和电脑在同一局域网，也可以先下到电脑再传过去，都没区别。

## 三、安装步骤

Auto.js 是一个普通 APK，但因为它不在应用商店里分发，安装时会多一步「允许安装未知来源应用」：

1. 在手机文件管理器里找到刚下载的 APK，点它。
2. 系统提示「不允许安装未知来源应用」时，选择「设置」→ 打开「允许来自此来源的应用」→ 返回继续安装。（各家系统的入口名称略有差异，小米叫「安装未知应用」，华为叫「更多设置」里的「外部来源应用下载」。）
3. 等安装完成，桌面上出现 Auto.js 图标。

Android 8.0 以上是**按来源**授权的，不是全局开关，所以不会给手机带来额外的长期风险面。

## 四、装完第一次打开，要开的三个权限

第一次打开 Auto.js 后，别急着写脚本，下面三个权限是日常使用绕不开的，少了任何一个都会在运行脚本时被卡住：

1. **无障碍服务**——Auto.js 找控件、点按钮全靠它，是所有自动化功能的前提。开启路径与常见坑单独写在 [无障碍服务开启教程.md](无障碍服务开启教程.md)。
2. **悬浮窗权限**——Auto.js 的运行控制按钮、布局分析浮层都是悬浮窗形式，不开它就没有「停止脚本」的按钮可用。一般在「应用信息 → 显示在其他应用上层」里打开。
3. **存储权限**——脚本、日志、截图都落在本地文件，不给的话编辑器读写文件会报错。

之后如果要用到找图找色，首次运行相关脚本时 Auto.js 会弹「截图权限」的授权窗口，到时再点同意即可。

## 五、核对一下装进来的包

如果你对来源比较在意，可以在装之前先核对 MD5：把下载到的 APK 用任意校验工具（电脑上 `certutil -hashfile 文件名 MD5`，手机上用文件管理器的文件校验功能）算一遍，结果应为 `5901F0A00845D351BE1DB106D156EA51`。对得上，说明拿到的就是本文描述的这份包。

装好之后就可以从 [无障碍服务开启教程.md](无障碍服务开启教程.md) 开始把环境搭起来，然后用 [脚本编写入门.md](脚本编写入门.md) 跑通第一段脚本。
