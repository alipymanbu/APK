> 按「症状 → 原因 → 处理」整理 Auto.js 4.x 上最常见的几类问题，多数根源是安卓系统的权限与后台限制，不是脚本写错。

## 一、无障碍服务明明开了，脚本还是点不动

按这个顺序排除：

1. **服务被系统重置了**。部分系统（如小米 MIUI）重启手机后自动关闭无障碍服务，去系统设置里再看一眼开关，别只看 Auto.js 界面上写着「已开启」。
2. **界面上根本没有控件树**。游戏画面、视频播放器这类用自绘界面渲染的应用，布局分析里读不出任何控件，`text()` 永远找不到——这类界面只能改用坐标点击（`click(x, y)`），坐标用布局分析看屏幕位置估出来。
3. **控件属性一直在变**。列表类应用刷新后控件 ID 可能变，先重新跑一次布局分析核对。
4. **`findOne()` 没传超时**。不带参数的 `findOne()` 会无限等，看起来像卡死。调试期一律写 `findOne(5000)` 这样的超时版本。

如果连「点击」都执行了但界面没反应，检查目标应用是不是运行在安全键盘、密码输入这类特殊控件上——部分应用的敏感控件不响应无障碍操作，属于应用自身的保护措施。

## 二、Toast 弹出的提示不对劲

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| Toast 前面多了一截应用名 | 定制系统（小米、华为等）给 Toast 统一加的前缀 | 系统行为，改不掉；介意的话改用悬浮窗或日志输出 |
| 切到后台后 Toast 不显示 | 系统限制后台弹 Toast | 给 Auto.js 开通知权限可缓解；Android 11 起自定义 View 的 Toast 在后台一律不显示 |

急用提示又碰上后台限制时，把 `toast()` 换成 `console.log()` 写日志、靠悬浮窗显示，是最稳的做法。

## 三、在后台时 launchApp、截图授权全都没反应

从 Android 10 起（部分国产系统更早），系统禁止应用在后台拉起其他应用或弹出自己的界面，所以脚本在后台跑时，`launchApp()`、请求截图权限这类动作会静默失败。两条路：

- 在 Auto.js 的权限设置里找「后台启动界面」「自启动」这类开关并打开（国产系统大多有，位置在应用信息 → 权限管理里）。
- 绕不开的场景，改成**手动点开 Auto.js 再跑**，或让脚本停在 Auto.js 的前台运行。

## 四、脚本跑几个小时后自己停了，没有任何报错

先确认「真的没有报错」：把日志落成文件再跑，`setGlobalLogConfig()` 可以把日志写到存储卡，停了之后翻日志文件看最后几行。确认没报错之后，常见原因有三类：

1. **内存耗尽**。官方常见问题页明确提到免费版引擎自身存在内存泄露，脚本连续跑几个小时以上就可能被系统回收。缓解办法：把长任务拆成几段、每段跑完主动 `exit()` 重新启动，别写「永不退出」的脚本。
2. **被系统杀死**。长时间高 CPU、高耗电、又没有前台界面的应用最容易被杀。把 [无障碍服务开启教程.md](无障碍服务开启教程.md) 第四节的白名单设置全部做一遍（自启动、电池无限制、锁定后台），保持悬浮窗开着也有帮助。
3. **代码里的死循环或异常没接住**。给主流程套 `try...catch`，把异常写进日志，停的时候就有线索可查。

## 五、定时任务、开机自启动不生效

Auto.js 的定时功能入口在**脚本列表里每个脚本右侧的菜单按钮 → 更多 → 任务**，可以设定时运行、开机自动运行、解锁屏幕后运行等条件（不同版本菜单层级略有差异，找不到就在任务页里翻）。设了却不触发，几乎都是同一个前提没满足：

- **Auto.js 必须活在后台**。系统把它杀了，到点自然没有东西去执行任务——把自启动白名单、电池白名单、后台锁定全部配置好，这是定时任务能跑的前提。
- 打包出来的应用同理：它就是个普通应用，定时和开机自启同样受系统后台策略限制，处理方式与 [打包与VSCode开发.md](打包与VSCode开发.md) 第一节交代的一致。

## 六、其他高频小问题速查

| 症状 | 说明 |
| --- | --- |
| 后台读写剪贴板失败 | Android 10 起的系统限制；可以先弹一个可交互的悬浮窗拿到焦点，再读写 |
| 「Module not found」类报错 | 用了不匹配引擎版本的写法或文件后缀，对照官方文档确认模块名 |
| 截图权限每次都要重新授权 | 系统对屏幕录制授权不放行跨重启的记忆，属正常行为，脚本开头统一写一次 `requestScreenCapture()` 的申请与失败处理 |

以上系统级行为（Toast、后台启动、剪贴板）是安卓平台的统一限制，换任何自动化工具都会遇到，不是 Auto.js 坏了。如果问题出在「选哪一版、和 Pro / AutoX 有什么区别」，看 [版本谱系与选择.md](版本谱系与选择.md)；环境没搭好的话从 [无障碍服务开启教程.md](无障碍服务开启教程.md) 回炉。
