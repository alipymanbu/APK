## 一、先别急着写：应用里自带两份入门材料

装好、开好无障碍服务后，很多人直接上网搜教程，其实 Auto.js 应用里就带了两份现成材料：主界面的「示例」文件夹和「教程」文档。示例覆盖了启动应用、找控件、截图找图等常见场景，每个都能直接运行看到效果；教程则把基本概念过了一遍。先把这两份翻一遍，能省掉大半搜索时间。

## 二、写第一段脚本

在主界面点右下角的「+」新建一个脚本文件，输入下面几行：

```javascript
toast("你好，Auto.js");
launchApp("设置");
```

点运行（悬浮窗上的播放键），你会看到屏幕底部弹出一句提示，然后系统设置被打开——这就是 Auto.js 的工作方式：用 JavaScript 描述「做什么」，无障碍服务替你去执行。

再试一个找控件点击的例子：打开系统「设置」的主界面，然后运行下面这段——

```javascript
// 按控件文字找，找到就点它
let sw = text("蓝牙").findOne(5000);
if (sw) {
    sw.click();
} else {
    toast("5 秒内没找到这个控件");
}
```

`text("蓝牙")` 是选择器，`findOne(5000)` 表示最多等 5 秒。写法上不用背，常用套路就三步：**用 `text()` / `id()` / `desc()` 定位 → `findOne()` 等它出现 → 对它做 `click()` 等动作**。

## 三、控件属性从哪来：布局分析

上一节的 `"蓝牙"` 这个文字是从哪知道的？靠 Auto.js 的「布局分析」：

1. 打开目标应用，停在你想自动化的那个界面。
2. 下拉 Auto.js 的悬浮窗，点「布局分析」→「布局范围分析」。
3. 屏幕上会覆盖一层控件树，点选你关心的按钮或文字，记下它的 `text`、`id`、`desc` 属性。
4. 回到脚本，用对应的选择器去写。

实战经验：**优先用 `id`，其次 `text`**——`id` 在同一个应用里稳定，`text` 会随界面语言或状态变化；都没有的时候才考虑坐标点击，因为坐标换个分辨率就失效。

## 四、运行、日志与停止

- **运行**：编辑器右上角或悬浮窗的播放按钮。
- **看输出**：`console.log("...")` 的内容在侧边栏的「日志」里看；脚本报错也会记在这里，排查问题先看日志再猜，常见症状的对号入座清单在 [常见问题解答.md](常见问题解答.md)。
- **停止**：点悬浮窗的停止键，停掉当前脚本；如果界面卡住点不到，**按一下音量上键**可以停止所有正在运行的脚本，这是 Auto.js 自带的应急开关。
- **定时运行**：主界面右下角的「定时任务」可以给脚本设时间；更灵活的写法是脚本里用 `setInterval()` 定期执行。

脚本多起来以后，你会想把它们打包成独立应用，或搬到电脑上用 VSCode 写、手机上同步运行，这两件事在 [打包与VSCode开发.md](打包与VSCode开发.md) 里讲；写的过程中随时翻 [常用API速查.md](常用API速查.md) 查函数用法。
