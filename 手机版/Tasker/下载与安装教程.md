Tasker 是安卓上的一款自动化工具：你先定好「什么条件下触发」，再定好「触发后依次做哪些事」，之后手机就会自己按这套规则跑，到家自动静音、定时切换设置、按位置调整亮度这类重复操作都可以交给它。它面向愿意花点时间把流程配一次、换取以后长期省事的用户，上手门槛主要在两处：一是概念比普通工具多，二是权限没给全时会看着「配好了却没反应」。本篇只解决一件事——把网盘里这份包正确地装进手机，并让第一次打开就能跑起来。

## 一、先弄清网盘里这份包是哪一版

网上搜到的多半是官方当时的最新版，而网盘里这份是整理文档时核对过的那一版，两者通常不是同一个版本号。下面这些值以网盘里那份包为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Tasker |
| 版本号 | 6.2.22 |
| 包名 | `net.dinglisch.android.taskerm` |
| 安装包体积 | 33.37 MB |
| MD5 | `06DCC04A728092A9DF53CBBEBA1E710F` |

这份包属于官方的 6.2.x 分支。官方在 6.2 这一支里加入了把 Tasker 本身变成网页服务器的「HTTP 请求」事件、与 Matter 灯具联动的实验性操作、工作资料（Work Profile）开关、以及一个能看到当前有哪些任务在跑的通知。这些不是本篇的重点，只是想说明：**你装的是 6.2 系列，别拿更新版本的截图来对界面**——官方后来的版本还在往上走，新增功能的进度以官网更新日志为准。

安装包本体就在头部那条夸克网盘分享里，转存到自己的网盘后下载即可。装之前可以顺手核对一次 MD5：在电脑上用校验工具算一遍，与上表一致再装，能避开下载被截断或被人换包的情况；手机端不方便校验，那就看体积是否与 33.37 MB 接近。

## 二、装之前先确认两件事

**第一，系统版本要够。** 官方的下载页把 6.x 系列挂在「Android 5.0 及以上」这一档，也就是说 Android 5.0 以下的机型装不上，5.0 及以上（含 6、7 等更高版本）都在范围内——这一档划分以官方下载页当时显示为准。真机判断很简单：打开手机「设置 → 关于手机」看系统版本；或者直接装——安卓在设备不兼容时会拒绝安装并提示「应用未安装」或「与你的设备不兼容」，不会给你装上一个半残的版本。

**第二，认包名，不要认名字。** 应用市场里带 task 字样的自动化工具不止一个，图标也可能撞车，系统区分它们靠的是包名。这套文档对应的只有一个：`net.dinglisch.android.taskerm`。装完可以在应用详情里回看一眼包名，确认装的是它。

## 三、安装步骤

1. **转存并下载**：从 [Tasker 安装文件资源（夸克网盘）](https://pan.quark.cn/s/68cc03b45038) 把 APK 转存到自己的网盘，再下载到手机。
2. **把包送到手机上**：手机端直接下载最省事；在电脑上下载的话，用数据线或任意传输工具拷进手机存储即可。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统通常把这项收在「安全」或「隐私」分类下面。
4. **点击 APK 完成安装**：系统若提示「应用未经过安全检测」，选择继续安装即可。
5. **手机里已有 Tasker 时先处理旧的那份**：如果之前从应用商店装过同一款，两份包的签名未必一致，覆盖安装可能报「应用未安装」。这种情况只能先卸载再装，而卸载会连带清掉你已经建好的配置文件和任务——**动手前先按 [导入现成项目与备份恢复.md](导入现成项目与备份恢复.md) 里说的导出一份备份**。
6. **装完先别急着搭自动化**：先跟着下一节把权限过一遍，否则界面都能点，配好的流程却会一动不动。

## 四、第一次打开要做的三件事

1. **打开权限总入口**：在 Tasker 里点右上角菜单 → 更多 → Android 设置。这里有它要用到的各项系统权限，逐项点进去给全。哪些必须给、哪些可以不给、不给会怎样，单独写在 [权限与后台省电怎么设置.md](权限与后台省电怎么设置.md)，这里只强调一句：**这一步不是可选项**，跳过它后面很容易遇到「配置明明对了却不触发」。
2. **确认 Tasker 处于启用状态**：主界面和常驻通知里都能看到开关。关掉它等于让所有自动化停摆，排查问题时这也是第一个要看的点。
3. **跑一次最小验证**：切到「任务」选项卡，新建一个任务，只加一条最简单的操作（例如「提醒 → 闪烁」，英文界面为 Flash），然后点左下角的播放按钮手动运行。看到屏幕弹出提示，说明安装、基础权限和任务执行这条链路是通的。

## 五、关于授权与试用

Tasker 是付费应用，官方提供 7 天试用版的直链下载，试用到期后需要购买授权才能继续用；授权是买断制，不是按月订阅。具体价格、试用规则与购买方式以官方的下载与购买页面当时显示为准——这两样都会变，本篇不写死，需要的可以去 [tasker.joaoapps.com](https://tasker.joaoapps.com/) 查。

需要提醒一点：官方渠道之外的所谓「特别版」既拿不到更新，也可能被塞进额外代码，而自动化工具恰好是权限给得最多的那类应用。本文只指向本文头部那一条资源入口和官方渠道。

## 六、以后出了新版本怎么升级

网盘那条分享是长期有效的：换版本时替换的是里面的安装包文件，**分享链接本身不变**，升级不用重新找地址。

1. 回到本文头部那条分享，看里面是不是已经换成比 6.2.22 更新的包；
2. 直接下载新包点安装。包名相同、签名相同、版本号更高时，安卓允许覆盖安装，已建的配置文件和任务会保留；
3. 若覆盖安装报「应用未安装」，说明签名对不上或版本号反而更低，只能先卸载再装——所以升级前导出备份这一步同样值得做。

有两点要自己留意：它不是从手机自带商店装的，商店不会替第三方来源的应用检查更新，想保持新版得隔一段时间回来看一眼；此外，这类靠后台常驻才能工作的应用，升级后系统有时会把权限重置，升完建议回 [权限与后台省电怎么设置.md](权限与后台省电怎么设置.md) 复查一遍。
