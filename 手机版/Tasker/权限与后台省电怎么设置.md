Tasker 要替你操作手机，就必须拿到相应权限；而它又必须一直待在后台，才能等到条件成立。这两件事在安卓上都要手动放行，且不同品牌手机的入口还不一样。本篇把权限按「用了什么功能才需要」分好类，再整理 Tasker 自身和系统两侧要动的开关——照着做完，绝大多数「配好了没反应」都会消失。

## 一、权限总入口在哪

不用在系统设置的各个角落里翻。打开 Tasker，点右上角菜单 → 更多 → Android 设置，这里就是它要用的各项权限清单，逐项点进去给全即可。

下面这张表按功能归类，方便你只给自己真会用到的：

| 权限 / 设置项 | 用来干什么 | 不给的后果 |
| --- | --- | --- |
| 无障碍服务 | 读取当前屏幕上的内容、判断前台是哪个应用、关闭通知栏等交互类操作 | 应用类条件失灵、界面交互类操作报错 |
| 通知访问 | 读取与操作通知、控制勿扰策略 | 通知相关动作报 `ACCESS_NOTIFICATION_POLICY` 之类的错误 |
| 在其他应用上层显示（悬浮窗） | 安卓 10 及以上系统所需，用于弹窗与场景显示 | 提醒、场景类动作显示不出来 |
| 位置（含后台位置） | 「位置」条件与取当前位置的操作 | 位置类规则不会触发 |
| 附近的 Wifi 设备（安卓 13 及以上） | 判断「Wifi 已连接」与「靠近 Wifi」这类条件 | Wifi 类条件失效 |
| 通知（安卓 13 及以上） | 显示 Tasker 的常驻通知 | 后台运行状态看不到，也更容易被系统清掉 |
| 身体传感器（安卓 13 及以上） | 手势、摇一摇、光线等传感器条件 | 手势类条件失效 |
| 文件与媒体权限 | 读写文件、备份、截图类操作 | 文件类操作报权限错误 |
| 设备管理员 | 系统锁屏功能 | 锁屏类动作不可用 |

两点提醒：

- **无障碍服务是最关键的一项。** 它同时被 Tasker 本体和它的插件使用，且国产系统常会在后台自动关闭它。如果你发现应用类条件隔一阵子就失灵，先回来看这里。
- **按需给，不必全给。** 你只用时间条件做定时任务，那位置、传感器这些完全可以不给——权限给得越少，被系统判定为高耗电应用的概率也越低。

## 二、Tasker 自身还有四个开关

除了系统权限，Tasker 内部有四个偏好设置直接决定它能不能稳定工作、以及耗电多少，位置在菜单 → 首选项 → 监控：

| 设置项 | 建议值 | 为什么 |
| --- | --- | --- |
| 在前台运行（Run In Foreground） | 勾选 | 让系统把它当成「正在运行的应用」，大幅降低被清理的概率。安卓 8 以上一般默认开启 |
| 使用可靠闹钟（Use Reliable Alarms） | 「息屏时」或「总是」 | 关系到定时准不准。选「从不」时，系统会把多个闹钟合并延后，时间条件可能明显晚点，某些机型甚至会因此结束 Tasker 进程 |
| 息屏时监控（Display Off Monitoring） | 按需勾选 | 息屏后还想让哪些条件继续监听，就在这一项里单独开。这里没开的条件，熄屏期间不会被感知 |
| 屏幕关闭全部检查（息屏检查频率） | 先保持默认；确实嫌反应慢再调小间隔 | 息屏期间各条件的检查频率。间隔调大更省电、但判定「已经离开」这类变化会更迟；调小则反应更快、更耗电。这是省电与灵敏度的取舍旋钮 |

如果只有定时任务不准、其他都正常，先回来看第二项——这是官方明确指出的最常见原因。而如果你是觉得耗电偏高、或者反过来觉得反应太慢，该动的是第四项，取舍细节整理在 [怎么控制耗电与后台占用.md](怎么控制耗电与后台占用.md)。

## 三、系统侧：别让它被清掉

安卓从 5.0 起对后台应用管得越来越严，多数机型需要额外放行两步：

1. **把 Tasker 加入电池优化白名单。** 原生安卓的路径大致是：系统设置 → 应用 → 右上角齿轮 → 电池优化 → 所有应用 → 找到 Tasker → 选「不优化」。定制系统会换个说法，通常在「电池」或「省电」分类里找「允许后台活动 / 不受限制」。
2. **允许自启动。** 国产定制系统（小米、华为、OPPO、vivo 等）普遍有「自启动管理」，没放行的话，手机关屏一段时间或重启后 Tasker 可能根本没有被拉起来。

另外两条常被忽略：

- **别装「省电」「冻结」「自动清理」类的第三方工具。** 这类应用会把 Tasker 一起清掉，规则自然不触发。
- **同一个功能如果用了配套小应用，它也要一起放行。** 例如开关 Wifi、切换移动数据这类动作依赖官方的 Tasker Settings 小应用，只给 Tasker 开白名单是不够的，那个小应用也得加入电池优化白名单。

各大厂商的限制细节差别很大，官方给出的做法是去 [dontkillmyapp.com](https://dontkillmyapp.com/?app=Tasker) 上按自己的手机品牌查对应设置——同一个品牌不同系统版本路径都可能不一样，本文不写死具体菜单。

## 四、配完做一次验证

改完权限和后台设置，重启一次手机，然后按顺序确认：

1. 打开 Tasker，主界面能看到「已启用」的状态，常驻通知也在；
2. 打开菜单 → 更多 → Android 设置，逐项看一遍，该给的仍在授权状态（无障碍和通知访问最容易被系统自己关掉）；
3. 跑一条最简单的定时规则：设一个两分钟后触发的时间条件，任务里只放一条「提醒 → 闪烁」，锁屏等它到点；
4. 到点弹出了，说明后台链路通了。没弹，别再猜着改设置——打开运行日志，看它到底有没有被触发、卡在哪一步，方法见 [不生效与定时不准怎么排查.md](不生效与定时不准怎么排查.md) 第六节。

第 3 步特意选在锁屏状态下等，是因为息屏能不能感知，才是这类应用真正难过的那一关；亮屏时跑通不代表夜里也能跑通。
