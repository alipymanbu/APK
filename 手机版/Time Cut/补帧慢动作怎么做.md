## 一、补帧解决的是「放慢之后不跳」

30 帧的视频放慢到 1/4 速，一秒 30 张画面要摊成 4 秒：不补帧就只有两种结果——每张画面重复几遍（看着一顿一顿），或者干脆跳着走。补帧是在相邻两张原画面之间补出中间画面，慢放之后动作仍然连得上。下面的顺序就是照着这件事排的：挑素材 → 选方式 → 定速度 → 预览 → 导出。

先记住一条边界：**补帧效果的上限由原素材决定**。动作幅度过大、画面本身糊、镜头快速甩动时，中间帧算出来就容易变形或重影。这不是参数没调对，而是素材里能提取的运动信息就那么多。同一段素材换补帧方式、或者把倍速降一点，通常就能改善，见第七节。

如果你以前在电脑上做过类似的事，可以这样定位它：官方说明里把补帧这项能力对标电脑上的 Twixtor，把运动模糊对标 RSMB 插件 —— 目标是手机上得到相近的效果，具体差异各家实现不同，以你自己试出来的结果为准。

## 二、素材没选好，后面怎么调都费劲

进应用之前，先按这几条过一遍手上那段素材：

| 素材条件 | 影响 |
| --- | --- |
| 原帧率高（60/120/240 fps） | 可参考的原画面多，慢放后更顺，需要补的帧更少 |
| 原帧率低（30 fps 或更低） | 能补，但大倍速时变形和重影的概率明显升高 |
| 运动方向单一、背景干净 | 最容易补出干净结果 |
| 大量遮挡、人物快速进出画面 | 边缘容易出现拉伸或糊边 |
| 经过多次转发、二次压缩 | 帧间细节已被破坏，可用信息更少 |
| 时长长、分辨率高 | 处理时间成倍增加，见第六节 |

试参数阶段，先截一段 5～15 秒的片段来跑，比直接上整段素材省时间。

上表说的是「素材已经拍好」之后怎么挑。如果素材还能重拍，拍摄端的帧率、快门、光线、稳定这四项怎么定，单独一篇讲：[慢动作素材怎么拍.md](慢动作素材怎么拍.md) —— 拍对了，后面要调的地方会少很多。

## 三、导入与选补帧方式

1. 打开应用，进入补帧 / 速度调节类入口（不同版本入口名可能不同，以你装的这一版显示的为准）。
2. 首次使用会弹媒体权限，权限的作用见 [下载与安装教程.md](下载与安装教程.md) 第五节。
3. 选中一段视频，进入编辑界面。
4. 选补帧方式。可选项通常是三种：光学流、RIFE 深度学习模型、帧混合 —— 三者的差别与挑选办法单独一篇讲：[三种补帧方式怎么选.md](三种补帧方式怎么选.md)。拿不准就先按默认的跑一遍，出问题再换。

## 四、把速度定下来

| 你想要的效果 | 用哪一项 |
| --- | --- |
| 整段统一放慢或加快 | 普通模式，档位在 1/10x 到 10x 的区间里选（以应用内实际可选档位为准） |
| 用现成的快慢套路 | 速度预设 |
| 某一刻定格不动 | 时间冻结 |
| 变速点自己排 | 自定义速度曲线 |

预设、曲线、冻结的具体调法见 [曲线变速与卡点视频怎么调.md](曲线变速与卡点视频怎么调.md)。

## 五、预览时重点看三处

处理完先完整看一遍，别直接导出。三个位置最容易暴露问题：

1. **动作最密的那一段**（跳跃、转身、甩镜头）—— 看有没有明显的画面拉伸或褶皱。
2. **画面边缘与背景**—— 补帧的破绽常常不在主体，而在主体的轮廓和背景交界处。
3. **声音**—— 变速后音轨要不要保留、音高变化能不能接受，见 [曲线变速与卡点视频怎么调.md](曲线变速与卡点视频怎么调.md) 的「声音」一节。

## 六、导出

确认预览没问题再导出。导出时要定分辨率和目标帧率，怎么选见 [帧率转换与导出参数怎么设.md](帧率转换与导出参数怎么设.md)。

处理耗时跟四件事相关：素材时长、分辨率、你选的补帧方式、手机性能。这四项叠加（长素材 + 高分辨率 + 深度学习模型 + 中低端机）时最慢，建议插着充电器处理，中途别切出去做别的重活。

## 七、效果不理想时，按成本从低到高改

1. **降倍速。** 从 1/4 速改到 1/2 速，需要补的帧少一半，变形和重影通常会明显减轻。
2. **换补帧方式。** 同一段素材三种方式各跑一遍对比，只花几分钟，见 [三种补帧方式怎么选.md](三种补帧方式怎么选.md)。
3. **截短素材。** 只保留真正要慢放的那两三秒，其余正常速度。
4. **换更好的原素材。** 用手机原片、或用 60fps 以上重拍一段，这一步成本最高，但效果上限提升也最大。
