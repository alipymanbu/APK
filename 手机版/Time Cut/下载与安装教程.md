## 一、先核对版本、包名与设备

Time Cut 是手机端的视频调速与补帧工具：把普通帧率的素材放慢、把高帧率素材转成别的帧率、给快动作加运动模糊，都在它里面完成。iOS 与安卓两版都在上架状态，网盘里这份是安卓版，下面的步骤都按安卓写。

下表里的版本号、包名、体积、MD5 都是这份安装文件本身的值。网上搜到的「官方最新版」往往已经是另一个版本号，不要拿它来核对。

| 项目 | 值 |
| --- | --- |
| 应用名 | Time Cut |
| 包名 | `com.accarunit.slowmotion` |
| 版本 | 2.6.0 |
| 安装包大小 | 81.01M |
| 安装包 MD5 | `bbdc0712a6c688f2ac3a6b94b128537d` |
| 记录时间 | 2026-09-23 |

三点需要留意：

- **包名认准 `com.accarunit.slowmotion`。** 名字里带 Time Cut 的视频工具不止一个，包名对不上说明你手上这份不是同一个应用。
- **最低系统版本没有统一口径。** 第三方下载页普遍标注安卓 5.0 及以上，这类说明常沿用页面模板；装的时候以你手机给出的提示为准。
- **存储要留余量。** 安装包 81.01M，安装过程还会再占一份；处理视频时应用要写临时文件，建议至少空出 1～2GB。
- **官方上架的是手机版。** 安卓版在 Google Play、iOS 版在 App Store，官方渠道里没有电脑端版本。想在电脑上跑只能借助安卓模拟器，那属于另一套环境，遇到的现象未必和手机上一样。

## 二、从网盘把安装包取到手机

1. 打开 [Time Cut 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f8a3b707d4ce)。
2. 先「保存到我的网盘」，再从自己的网盘里下载。直接下载也能用，但转存之后原分享链接哪天失效都不影响你。
3. 记下文件落在哪，一般在「下载」或「Download」目录。
4. 文件名以网盘里实际显示的为准，通常形如 `Time Cut_v2.6.0.apk`。

打开链接提示失效、或要求提取码时，说明这条分享的当前状态变了，回到上面的资源入口重新取一次。

## 三、装之前校验一次安装包

81M 的文件在网络传输里出错不算少见，装的时候直接报「解析包错误」，而报错不会告诉你是文件坏了。花半分钟验一次更省事。

把 APK 拷到电脑上，在文件所在目录执行：

```powershell
certutil -hashfile "Time Cut_v2.6.0.apk" MD5
```

输出的十六进制串去掉空格后，应当与第一节表里的 `bbdc0712a6c688f2ac3a6b94b128537d` 完全一致（大小写不敏感）。手机上用带 MD5 校验功能的文件管理器也能做同样的事。

对不上就重新下载一次，不要将就着装。

## 四、放行「安装未知应用」

网盘里的包不是从应用商店装的，安卓默认会拦一次。要先给**负责下载这个 APK 的那个应用**（浏览器或网盘客户端）开安装权限，各品牌路径不一样：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 权限管理 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装外部来源应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 生物识别和安全 → 安装未知应用 |
| 原生安卓 / 平板 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

路径记不住就在设置顶部的搜索框里搜「未知应用」或「外部来源」。关键是找到下载这个 APK 的那个应用，把它的开关打开 —— 开给了别的应用一样装不上。

## 五、安装与第一次启动

1. 从通知栏点刚下完的文件，或者打开文件管理器找到 `.apk` 点它。
2. 弹出安装界面点「安装」，等进度走完，桌面出现图标。
3. 首次启动会依次弹权限申请。这个应用要读素材、写成品，真正影响功能的是这几项：

| 权限 | 不给会怎样 |
| --- | --- |
| 照片和视频 / 媒体（存储） | 选不到素材，导出的成片也存不出去 |
| 音乐和音频 | 导入音频、给视频配乐会受影响 |
| 通知 | 只影响提醒，不影响编辑 |
| 麦克风 | 只影响应用内录音；不录旁白可以不签 |

具体弹哪几项、各自叫什么名字，以你手机上显示的为准，上表说的是它们各自的用途。

4. 第一次进去是功能入口列表，多数功能要先选中素材才能往下走。素材怎么导、补帧怎么选，见 [补帧慢动作怎么做.md](补帧慢动作怎么做.md)。

## 六、装不上、装完打不开

按顺序自查，比反复重装有效：

- 提示「解析包错误」「应用未安装」→ 回第三节重新校验 MD5，多半是文件没下完整。
- 提示「已被阻止安装」→ 第四节的权限没开，或者开给了错误的那个应用。
- 点图标闪一下退回桌面 → 先确认系统版本够用、存储余量充足，再按 [常见问题与排查.md](常见问题与排查.md) 里「启动就退」那一节排查。
- 提示空间不足 → 先腾出比 81.01M 更大的可用空间再试，安卓安装时会额外占一点余量。
- 装完是英文界面 → 界面语言跟随系统语言，把系统语言改成简体中文后再进一次。
