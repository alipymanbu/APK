## 一、这一篇管的是按下录制键之前

做慢动作有两条路：一条是拍的时候就用高帧率录，一条是拍完拿普通素材去补帧。第一条路的成片质量上限高得多，因为画面是真实记录下来的；第二条路上限由素材决定。这一篇只讲拍摄前你能控制的事——拍多少帧、快门设多少、在什么光线下拍、怎么拿稳，以及哪些素材天生补不出好结果。

## 二、帧率按「目标慢放倍数」倒推

慢放的本质是「用高帧率拍摄、按低帧率播放」。所以拍多少帧，取决于你要放慢几倍、以及成片按多少帧放：

| 你想放慢到 | 拍摄帧率（成片按 30 fps 算） |
| --- | --- |
| 1/2 速 | 60 fps |
| 1/4 速 | 120 fps |
| 1/8 速 | 240 fps |

三档的代价递增：

- **60 fps** 是最省事的一档，分辨率通常不受影响，文件也不至于过大。
- **120 fps** 是日常慢动作最常用的档，很多手机在这一档会把分辨率降一档（比如 4K 降到 1080p）。
- **240 fps** 只建议拍短片段（跳跃、水花、击球这一两个瞬间），多数机型在这一档分辨率降得更多，画质也更容易变差。

用哪一档，先反推自己到底要放慢多少 —— 只需要 1/2 速却录了 240 fps，白白牺牲画质。手机相机里改帧率的位置各机型不同，通常在「设置 / 更多 / 慢动作」里，以你的机型为准。

## 三、快门速度大约是帧率的两倍

视频拍摄里有一条通用的经验规则：**快门速度取帧率的两倍左右**（也就是常说的 180 度快门）。

| 拍摄帧率 | 常用快门 |
| --- | --- |
| 60 fps | 1/120s 上下 |
| 120 fps | 1/240s 上下 |
| 240 fps | 1/500s 上下 |

快门偏慢，单帧拖影重，慢放后画面发糊；快门偏快，单帧很「脆」，慢放后动作会一顿一顿的。多数手机自带相机不给你手动快门（专业模式或第三方相机 App 才有），这种情况下不用纠结这一项，把精力放在光线和稳定上。

## 四、光线：高帧率是要吃光的

同样的场景，帧率翻倍意味着每一帧的曝光时间减半，进光量也跟着减半。这是室内暗光下拍 120 / 240 fps 画面又糊又噪的直接原因。三条可执行的做法：

1. **优先白天室外**，或把拍摄位置挪到窗边、灯光下。
2. **别用高帧率在夜里拍**。夜拍直接改回 30 fps，再靠补帧做轻量慢放。
3. **要拍 240 fps，就挑最亮的地方**（正午、顶光、水边），暗光下这一档基本没有可用性。

## 五、稳定：慢放会把抖动一起放大

镜头抖在慢放之后变得更显眼，因为同样的位移被拉长到几倍的时间里。能上三脚架、云台就上；只能手持时，拍摄中尽量少走动、少转镜头，靠身体当支架。

需要明确一点：**补帧解决的是「画面之间的连续性」，不解决抖动**。手抖拍出来的素材补完帧，该抖还是抖，甚至会因为画面更清晰而显得更抖。

## 六、这几类素材天生难补

| 素材来源 | 为什么难补 |
| --- | --- |
| 从社交平台下载回来的视频 | 平台上传/下载会再做一次压缩，帧间细节已经损失 |
| 本身已经是慢动作的片段 | 原片就是靠插帧或高帧率放慢的，缺帧更严重 |
| 夜拍、强噪点素材 | 噪点会被当成运动信息，补出来画面发脏 |
| 人物快速进出画面、大面积遮挡 | 遮挡前后的画面对不上，容易出现残影 |

## 七、拍前过一遍的清单

1. 按第二节的表，反推出这次要拍的帧率。
2. 确认这个帧率下分辨率降了多少，可以接受再录。
3. 换到亮的地方，或者补一盏灯。
4. 能固定就固定；手持就减少走动。
5. **先试拍 5 秒，回放确认够清楚，再正式录**。这一步最省事，也最容易省掉。
