# AI翻唱与音色卡片怎么做

> 音色卡片是 Muse AI 里用自己声音翻唱的功能：先录一段自己的声音训练出卡片，再拿它去唱你的作品。本篇讲清流程、门槛和该守的边界。

## 一、翻唱功能解决的是「人声不像我」的问题

默认情况下，Muse AI 生成歌曲的人声是模型给的，跟你本人没关系。AI 翻唱换掉的就是这一层：**训练一张属于你的音色卡片，再用这张卡片去唱你名下的作品**，成品里唱歌的听起来就是你的声音。

它不改变旋律和编曲——换人声和改词是两条独立的线。要换歌词请看 [热歌改编与改词怎么操作.md](热歌改编与改词怎么操作.md)。

## 二、流程：先训卡，再翻唱

1. **录素材**：按应用内音色卡片的引导，录一段你自己的声音。素材是这张卡片的唯一来源，录的时候尽量找个安静环境、用固定的说话或演唱距离，别一会儿远一会儿近；
2. **等待训练**：素材提交后需要一段处理时间，训练完成的卡片会出现在你的音色列表里；
3. **选歌翻唱**：在你的作品里挑一首，应用你的音色卡片重新生成一版人声；
4. **对比试听**：同一首歌可以换不同卡片各生成一版，挑像的那一版留存。

训练和翻唱都会消耗积分，具体额度以应用内当时的提示为准，免费积分的来路见 [积分和会员怎么算.md](积分和会员怎么算.md)。

## 三、想让翻唱更像，先管住素材

音色卡片的效果上限，几乎在你录素材那一步就定死了：

| 素材问题 | 出来的效果 |
| --- | --- |
| 背景有音乐、说话声、空调声 | 卡片带上杂音，唱出来毛糙、发闷 |
| 音量忽大忽小、离麦克风忽远忽近 | 卡片不稳定，同一首歌不同段落像两个人 |
| 一开口就是大声喊 | 卡片偏尖，唱抒情段落会显得硬 |
| 素材太短 | 卡片抓不住你声音的特点，翻唱出来像通用人声 |

一句话：**素材干净、距离稳定、覆盖你平常唱歌的音量范围**，比录得多更重要。

还有一点要先分清，免得把预期放错地方：**音色卡片只改「谁在唱」，不改「怎么念」。** 唱中文还是外语、哪个字唱得准不准，都由生成模型决定，换成你自己的音色也不会让外语发音变标准，换一张卡也不会改变咬字习惯。想改善发音只有改词、缩短句子、重生成这几条路，具体见 [外语歌与多语言输入怎么用.md](外语歌与多语言输入怎么用.md)。

落到具体动作上，录之前对着这张表核一遍：

| 录制要点 | 怎么做 | 不做会怎样 |
| --- | --- | --- |
| 环境 | 关空调风扇，拉上窗帘（减少回音），别在空旷房间 | 卡片带底噪，唱出来一直有沙沙声 |
| 距离 | 与麦克风保持大约一拳，全程固定 | 忽远忽近，同一首歌像两个人唱 |
| 姿势 | 别对着麦克风直吹，稍微偏一点角度 | 喷麦、呼吸声被一起学进去 |
| 音量 | 用你唱歌的正常音量，别刻意喊也别刻意压低 | 卡片音域窄，高音或低音会发虚 |
| 连贯 | 一口气录完整段，别一段段拼 | 段落之间音色对不上，像换了个人 |
| 一致性 | 同一批素材用同一套设备和同一个房间 | 卡片内部自相矛盾，效果不稳定 |

## 四、边界：只能拿自己的声音做卡

这一点没有例外——**只训练和使用你本人（或已明确获得书面授权的人）的声音**：

- 不要用别人的录音、影视片段、别的歌手的成品去训卡，那是侵犯他人声音权益；
- 不要把用别人声音生成的翻唱作品公开传播或商用；
- 用自己声音做出来的翻唱，对外发布前同样要确认你对该作品有发布权。

平台不会替你把这类授权做掉，出了问题是使用者自己的责任。

## 五、翻唱之后往下走

翻唱出来的人声作品，可以接着做两件事：

- **配画面做成 MV**：用虚拟艺人形象给这首歌生成一支 MV，流程见 [AI MV怎么生成与编辑.md](AI MV怎么生成与编辑.md)；
- **下载留存或发到社区**：下载路径与分享方式见 [作品管理下载与分享.md](作品管理下载与分享.md)。

如果翻唱时出现人声断断续续、整段没声音的情况，先当作生成失败处理，按 [常见问题与排查.md](常见问题与排查.md) 里的步骤重试。
