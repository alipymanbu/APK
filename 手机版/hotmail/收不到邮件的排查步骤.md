# hotmail 收不到邮件的排查步骤

> 本篇按命中率排序，逐条排查「新邮件没进来」：先看网页版，再查存储、筛选、规则与发件人侧。

## 一、先定位：网页有还是手机有

打开浏览器登录 [outlook.com](https://outlook.live.com/)，看那封邮件在不在网页收件箱：

| 网页版 | 手机应用 | 结论 |
| --- | --- | --- |
| 有 | 没有 | 客户端问题：同步、筛选、账户状态，往下查第二至第五节 |
| 没有 | 没有 | 账户问题：存储满、规则转发、发件人被拦，往下查第二、第六、第七节 |
| 有 | 部分有 | 大概率是文件夹筛选或同步延迟，往下查第三、第四节 |

这一步决定了你该修手机还是修账户，先做它能少走很多弯路。

## 二、存储空间满了会直接拒收

Microsoft 账户的邮箱与 OneDrive 共用云存储额度。**存储满时新邮件会被退回发件人，而且退回去的邮件找不回来**——这是最硬的一种「收不到」。

- 查存储：登录网页版，账户菜单里找存储 / OneDrive 存储页。
- 处理：删掉收件箱里带大附件的旧邮件、清空已删除与垃圾邮件文件夹，腾出空间后新邮件自然恢复投递。

顺带一提：手机本地存储满一般只影响缓存，不影响服务器收信；真正卡脖子的是上面这个云端额度。

## 三、重点收件箱把邮件分走了

重点收件箱默认开着，把收件箱劈成「重点」和「其他」两栏。新邮件落在「其他」栏时，看起来就像没收到。

- 切到「其他」栏翻一遍；
- 想彻底关掉：侧边菜单 → 设置 → 邮件 → 关闭「重点收件箱」开关，两栏合一。

## 四、邮件进了垃圾邮件或被规则挪走

按顺序检查这几个地方：

1. **垃圾邮件文件夹**：找到误判的正常邮件，标记为「非垃圾邮件」，发件人会被加入允许名单。
2. **屏蔽发件人名单**：设置 → 邮件 → 垃圾邮件 / 屏蔽发件人，把误加进去的地址移出来。
3. **收件箱筛选与排序**：把筛选设为「全部」、按日期排序——有时邮件在，只是被筛选条件藏住了。
4. **自动规则与清理（Sweep）**：设置 → 邮件 → 规则，逐条看有没有把新邮件直接挪走或删除的规则。
5. **转发设置**：如果转发开着，确认「保留转发邮件的副本」也开着，否则邮件被转走、本地看不到。
6. **已删除邮件文件夹**：有些客户端的「删除」其实只是移过去。手机端把它移回收件箱即可；已经从「已删除」里清掉的，在**电脑网页版**打开该文件夹，列表上方有「恢复从此文件夹中删除的项目」入口，30 天内可捞回。注意：手机应用里清空的「已删除」无法这样恢复，必须用电脑。
7. **存档文件夹**：被存档（Archived）的邮件不在收件箱里，去存档文件夹找，找到后「移动到 → 收件箱」。

注意：规则和转发这两项如果**你没设置过却出现了内容**，按账户被盗处理 —— 改密码、退出所有会话、清机关的完整顺序在[账户被盗与异常登录处理](账户被盗与异常登录处理.md)，不要只删一条规则了事。

两个容易忽略的系统规则：

- **垃圾邮件文件夹里的邮件 30 天后自动删除且不可恢复**；重要来信被误判过一次，尽快标「非垃圾邮件」。
- **一年不登录，Outlook.com 邮箱会被关闭并删除邮件**；Microsoft 账户本身两年不登录也会停用。偶尔登录一次即可保活（Microsoft 服务协议口径，以官方页面为准）。

## 五、客户端这一侧的同步问题

网页有、手机没有时，试这几招：

1. 应用内下拉刷新一次；
2. 检查手机网络（换个 WiFi 或流量试试）；
3. 把账户从设置里移除，再重新添加——邮件都在服务器上，删账户不会删掉邮件；
4. 应用版本过旧时同步容易出毛病，升级到最新版再试（升级方式见[常见问题与故障排查](常见问题与故障排查.md)）。

## 六、只有某个发件人收不到

自己这边全查过还没结果，问题多半在发件人一侧：对方的邮件进了你的垃圾箱只是表象之一，更常见的是**对方的发信被你的域名策略拦下**，或者对方服务器进了黑名单。

- 让对方确认发给你的地址拼写正确、没有被退信；
- 你在网页版把对方地址加入允许名单；
- 具体的发件侧配置（SPF / DKIM 这类）属于对方管理员的工作，你只能催、不能替他改。

## 七、还是收不到

逐条做完仍无解，按这个顺序收尾：

1. 换个网络、换个设备登录同一账户试一次，判断是不是这台设备的问题；
2. 用另一个邮箱给你自己发一封测试邮件，观察它最终落在哪个文件夹；
3. 走网页版右上角的帮助 / 反馈入口提交问题，把「哪封邮件、什么时候发的、落在哪个文件夹」说清楚，比描述「收不到」有用得多。

多账户场景下，先确认你查的是**出问题的那个账户**的收件箱——切错账户看起来也像收不到邮件，见[添加账户与切换邮箱](添加账户与切换邮箱.md)。
