## 一、什么情况下才需要填这些

现代邮件应用输入地址密码后会自动探测服务器配置，**多数人根本用不到本篇**。需要手动填的典型场景：

- 应用自动配置失败、卡在「无法连接服务器」；
- 换了一个不支持自动配置的老牌邮件客户端；
- 要把 hotmail 账户加进系统自带的「电子邮件」应用或第三方客户端。

先说清一件事：`hotmail.com` 地址背后就是 Outlook.com 服务，服务器参数两者完全相同，照下表填即可。

## 二、服务器参数速查

| 项目 | 值 |
| --- | --- |
| 用户名 | 你的完整邮箱地址 |
| 密码 | Microsoft 账户密码（老式客户端可能要应用密码，见第四节） |
| IMAP 服务器 | `outlook.office365.com` |
| IMAP 端口 | 993 |
| IMAP 加密 | SSL/TLS |
| POP 服务器 | `outlook.office365.com` |
| POP 端口 | 995 |
| POP 加密 | SSL/TLS |
| SMTP（发件）服务器 | `smtp-mail.outlook.com` |
| SMTP 端口 | 587 |
| SMTP 加密 | STARTTLS |
| 验证方式 | OAuth2 / 新式验证 |

（截至 2026-09 的官方口径，以微软支持页面当时显示为准。）

收件与发件服务器**不是同一个地址**，填的时候别抄串：收件走 `outlook.office365.com`，发件走 `smtp-mail.outlook.com`。

## 三、IMAP 还是 POP，选哪个

| | IMAP | POP |
| --- | --- | --- |
| 邮件存放 | 服务器与所有设备实时同步 | 拉到本地，服务器上按设置保留 |
| 换手机后 | 登录即恢复全部邮件与文件夹 | 本地已拉走的邮件不在新设备上 |
| 多设备同看 | 适合 | 不适合 |
| 默认状态 | 可用 | 默认关闭，需手动开 |

手机 + 网页 + 电脑混用的场景直接选 IMAP。POP 适合「只在一处收信、收完从服务器清掉」的老习惯，选它之前先想清楚你是否只用这一台设备。

## 四、默认关着的 POP / IMAP 开关

直接填参数可能连不上——**Outlook.com 的 POP 与 IMAP 访问默认是关闭的**，要先去网页端打开：

1. 浏览器登录 [outlook.com](https://outlook.live.com/)，进入「设置」→「邮件」→「转发和 IMAP」；
2. 在「POP 和 IMAP」下，打开「允许设备和应用程序使用 POP」或「允许设备和应用程序使用 IMAP」；
3. 保存，再回客户端重试连接。

## 五、连不上的几个高频原因

按命中率排查：

1. **用密码登录被拒**：新式验证要求 OAuth2，老客户端不支持时改用「应用密码」——到 Microsoft 账户安全设置里生成一串专用密码，用它代替普通密码登录。
2. **端口写成默认明文端口**：客户端若自动填了 143（IMAP）/ 110（POP）/ 25（SMTP），手动改成上表的 993 / 995 / 587，并选对应加密方式。
3. **多客户端同时用 IMAP 触发连接错误**：有用户反馈过多个客户端并连时报连接错误，官方给出的处理是到 [account.live.com/activity](https://account.live.com/activity) 查看最近活动，找到对应会话标「这是我本人」，再重连。
4. **公司账户被 IT 限制**：工作 / 学校账户可能要求走新式验证或限定客户端，参数照填也过不去——这类限制在服务端，得找管理员开。

密码或网络本身的问题（连不上网、密码过期）不在这篇的范围，见[常见问题与故障排查](常见问题与故障排查.md)；「参数都对但就是收不到某封信」属于另一类问题，见[收不到邮件的排查步骤](收不到邮件的排查步骤.md)。
