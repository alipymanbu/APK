## 一、首次登录一个 hotmail 账户

打开应用，一般直接停在「输入邮箱地址」的界面，按这个顺序走：

1. 输入完整的邮箱地址（如 `你的名字@hotmail.com`），下一步。
2. 输入 Microsoft 账户密码。hotmail / outlook / live / msn 这几个后缀用的都是同一个 Microsoft 账户体系。
3. 如果这个账户开了两步验证，页面会让你在手机或邮箱里收一个验证码，输入后完成登录。
4. 登录成功后进入收件箱，此时邮件列表是空的还是已有历史邮件，取决于账户本身有没有邮件。

登录失败最常见的两个原因：密码拼错（区分大小写，注意大写锁定）、账户在别处改过密码但这里还存着旧的。密码忘了走 Microsoft 账户的官方找回流程重置，重置后回来重新登录即可。

登录时若收到「异常登录」类的安全提醒，或事后发现账户被动过（规则、转发、自动回复出现陌生内容），处理顺序见[账户被盗与异常登录处理](账户被盗与异常登录处理.md)。

## 二、添加第二个邮箱账户

很多人工作一个邮箱、私人一个邮箱，安卓邮件应用一般都支持多账户并存：

1. 打开侧边菜单（一般在左上角头像或三横线图标）。
2. 进「设置」，选「添加账户」。
3. 输入第二个邮箱地址与密码，按提示完成验证。

添加成功后，侧边菜单顶部会出现账户列表，点不同账户即可在各自的收件箱之间切换；部分应用还提供「统一收件箱」视图，把所有账户的邮件合在一个列表里显示，用不用看你习惯。

Gmail、Yahoo、iCloud 等非 Microsoft 账户通常也能走同样的入口添加，密码验证方式由对应服务商决定。

## 三、两步验证与应用密码

如果你的账户开启了两步验证，而登录的应用走的是「老式密码验证」，输入普通密码会直接被拒。两种解法：

- **优先用验证码登录**：应用若支持，选「使用应用密码」之前先看有没有验证码方式。
- **创建应用密码**：到 Microsoft 账户的安全设置里生成一个专门给第三方客户端用的密码，登录时用它代替普通密码。应用密码是一串随机字符，生成一次用一次，不用记。

公司或学校账户（Exchange / Microsoft 365）还可能遇到额外要求：设备需要注册到公司的 Intune 公司门户、或 IT 管理员在服务端开了限制。这类提示出现时按屏幕指引走，搞不清楚就问自己单位的管理员——客户端这边能做的不多。

## 四、登录后收不到信，先做三步

登录成功不等于邮件正常进来。按这个顺序最快定位问题：

1. **先看网页版**：在浏览器登录 [outlook.com](https://outlook.live.com/)，看新邮件在不在网页收件箱里。
   - 网页有、手机没有 → 问题在客户端这一侧（同步、筛选、账户状态），继续看[收不到邮件的排查步骤](收不到邮件的排查步骤.md)。
   - 网页也没有 → 问题在账户侧（存储满、规则转发、发件人被拦），同样按那一篇的顺序查。
2. **看是不是被筛走了**：重点收件箱分「重点」「其他」两栏，新邮件可能落在「其他」；垃圾邮件文件夹也常收进误判的正常邮件。
3. **重新同步一次**：下拉刷新不灵时，把账户从设置里移除再重新添加，是最干脆的重置手段（邮件都在服务器上，删账户不会删掉邮件本身）。

手动配置收发服务器参数（IMAP / SMTP）的场景见[邮件服务器设置（IMAP与SMTP）](邮件服务器设置（IMAP与SMTP）.md)，一般只有换客户端或自动配置失败时才需要。
