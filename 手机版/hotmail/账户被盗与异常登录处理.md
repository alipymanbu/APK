# hotmail 账户被盗与异常登录处理

> 本篇讲怀疑 hotmail 账户被人动过时，按什么顺序止损：先设备、再密码、后设置清理。

## 一、先确认是不是真的被动过

出现下面任意一条，就值得往下查：

- 收到 Microsoft 发的异常登录提醒（发件人应为 `account-security-noreply@accountprotection.microsoft.com`，不是这个地址的「安全提醒」本身就是钓鱼）；
- 收件箱里出现你没写过的规则、转发、自动回复；
- 有你没操作过的改密码、改安全邮箱的通知；
- 邮件在你不知情的情况下被转走或删掉。

确认方法：浏览器登录 [account.microsoft.com/security](https://account.microsoft.com/security) → 「查看活动」，逐条看最近登录记录。不是你本人的操作，展开后选「这不是我」；在 [account.live.com/activity](https://account.live.com/activity) 里也能做同样的标记。

## 二、止损顺序（别打乱）

按这个顺序做，跳步会白做：

1. **先扫设备**：在你用过这个账户的电脑、手机上各跑一次全盘杀毒。设备本身还带着木马时先改密码，改完照样会被偷。
2. **改密码**：用无痕窗口打开 [account.live.com/ResetPassword.aspx](https://account.live.com/ResetPassword.aspx) 重置，密码要「只在这个站点用过」的强密码。
3. **退出所有会话**：[account.live.com/proofs/Manage](https://account.live.com/proofs/Manage) 页面底部有「退出所有设备」，执行后所有已登录的地方（包括攻击者的）都断开。官方口径是**最长 24 小时内全部生效**，期间别以为没起作用。
4. **开两步验证**：安全设置里开启，至少保证两种可用的验证方式（备用邮箱、手机号、 Authenticator 里至少留住两个）。

做完这四步，攻击者手里那把钥匙就废了。剩下的时间用来清理他留下的「机关」。

## 三、清掉对方留下的机关

全部在网页版 [outlook.com](https://outlook.live.com/) 的设置里，**建议在电脑上做**（手机端查不全规则）：

| 位置 | 查什么 | 处理 |
| --- | --- | --- |
| 设置 → 邮件 → 规则 | 自动转发、自动删除、自动建草稿的规则 | 全删 |
| 设置 → 邮件 → 转发 | 不认识的转发地址 | 移除，并确认「保留副本」状态 |
| 设置 → 邮件 → 自动回复 | 不是你写的外出自动回复 | 关掉、清空文本 |
| 设置 → 邮件 → 垃圾邮件 | 屏蔽名单里混进来的正常地址 | 移出；同时清掉允许名单里的陌生地址 |
| 已连接的帐户 | 不认识的连接账户 | 断开 |
| Microsoft To Do 任务列表 | 会自动生成邮件草稿的任务 | 删除（草稿反复重现常是这条引起的） |

别漏了**应用密码**：安全设置里如果列出你不认识的应用密码，全部撤销——那是对方给自己留的长效钥匙。

## 四、收尾核查

1. 安全信息页（备用邮箱、恢复手机号）逐项核对，删掉不认识的；这些是找回账户的最后一道门，被换掉就全盘皆输。
2. 设备列表里移除不认识的设备。
3. 之后 48 小时留意草稿箱、已发送、收件箱规则有没有「自己长回来」的内容——长回来说明某台设备还没清干净，回到第二节第 1 步重扫。
4. 手机客户端上退出账户、用新密码重新登录一次。

处理完账户侧，如果邮件还是不对劲（少了、被转走了），按[收不到邮件的排查步骤](收不到邮件的排查步骤.md)继续查；登录方式与验证码相关的问题归[添加账户与切换邮箱](添加账户与切换邮箱.md)。

## 五、平时怎么降低中招概率

- 两步验证开着，别关；
- 密码一站一码，别和别的网站共用（撞库是这类被盗最常见的入口）；
- 收到「你的账户异常，点此验证」类邮件，先核发件人域名，再自己手动打开官网，**不点邮件里的链接**；
- 一年内至少登录一次账户：Microsoft 服务协议规定长期不登录（一年未登录 Outlook.com）会被判定为不活跃而关闭服务，两年未登录 Microsoft 账户本身也会被停用，登录一次即可保活。
