## 一、先分清两条路

手机 App 里的 Wan2.2 走官方算力，装上就能用；本地部署是把官方开源的模型权重下到自己电脑上推理，分辨率、时长、采样参数都能自己定，但门槛也实在：需要 NVIDIA 显卡、足够的显存和基本的命令行能力。只是想生成几条视频的话，手机端（见 [手机端AI生视频入门.md](手机端AI生视频入门.md)）是成本最低的路径。

## 二、选哪个模型

官方开源了四个主模型（另有角色动画方向的 Wan2.2-Animate）：

| 模型 | 用途 | 分辨率 | 显存门槛 |
| --- | --- | --- | --- |
| Wan2.2-T2V-A14B | 文生视频 | 480P / 720P | 480P 约 16~24GB；720P 建议 40~80GB（社区口径） |
| Wan2.2-I2V-A14B | 图生视频 | 480P / 720P | 同上 |
| Wan2.2-TI2V-5B | 文生视频 + 图生视频统一模型 | 720P @ 24fps | 约 8GB 起（ComfyUI offload 口径），24GB 从容 |
| Wan2.2-S2V-14B | 音频驱动生成视频 | 480P / 720P | 高 |

个人用户直接看 TI2V-5B：它是为消费级显卡准备的 5B 稠密模型，官方数据是在单张 4090 上约 9 分钟生成一段 5 秒的 720P@24fps 视频；配合 ComfyUI 的显存 offload，8GB 显存也有机会跑起来。两个 A14B 模型采用 MoE 双专家架构（总参数 27B、每步激活 14B），画质与运动表现更强，代价是显存需求，具体数字以官方仓库说明为准。

## 三、代码与权重的官方渠道

- 代码仓库：[https://github.com/Wan-Video/Wan2.2](https://github.com/Wan-Video/Wan2.2)；
- 模型权重：Hugging Face 的 [Wan-AI 组织页](https://huggingface.co/Wan-AI)，或 ModelScope 的 [Wan-AI 组织页](https://modelscope.cn/organization/Wan-AI)（国内网络走 ModelScope 通常更顺畅）；
- 许可：Apache 2.0，具体条款以仓库内的 LICENSE 文件为准。

## 四、环境与下载命令

以下以官方仓库当时的 README 为准，基本流程：

```bash
git clone https://github.com/Wan-Video/Wan2.2.git
cd Wan2.2
pip install -r requirements.txt   # 官方要求 torch >= 2.4.0
```

下载权重（两种方式任选其一，以 TI2V-5B 为例）：

```bash
# Hugging Face
pip install "huggingface_hub[cli]"
huggingface-cli download Wan-AI/Wan2.2-TI2V-5B --local_dir ./Wan2.2-TI2V-5B

# ModelScope
pip install modelscope
modelscope download Wan-AI/Wan2.2-TI2V-5B --local_dir ./Wan2.2-TI2V-5B
```

各模型的启动命令、显存优化开关（如 CPU offload）都在仓库 README 里，会随版本更新，以仓库当前内容为准。

## 五、更省事的图形化路线：ComfyUI

不想碰命令行的话，ComfyUI 官方已内置 Wan2.2 模板与重打包权重，图形界面里选模板就能生视频，显存要求也比裸部署低（8GB 显存配合 offload 可跑 5B 工作流）。四条工作流的选择、模型文件摆放与低配替代方案，见 [ComfyUI图形化生视频.md](ComfyUI图形化生视频.md)；提示词写法不变，参考 [提示词写法与美学关键词.md](提示词写法与美学关键词.md)。

部署或生成报错时，多数与显存不足、torch 版本不匹配有关，排查思路见 [视频生成常见问题.md](视频生成常见问题.md)。
