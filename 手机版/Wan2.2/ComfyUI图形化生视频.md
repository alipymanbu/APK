## 一、ComfyUI 是什么，为什么走这条路

ComfyUI 是节点式的图形界面：把「加载模型 → 输入提示词 → 采样 → 输出视频」连成一张流程图，点 Run 就出片。Wan2.2 开源后，ComfyUI 官方（ComfyOrg）很快提供了原生工作流——模板、重打包权重、教程都是现成的，比自己在命令行里配 Python 环境门槛低得多。ComfyUI 本体怎么装见 [开源模型本地部署.md](开源模型本地部署.md)；生视频的提示词写法与手机 App 完全一致，参考 [提示词写法与美学关键词.md](提示词写法与美学关键词.md)。

## 二、四条官方工作流

官方教程（[docs.comfy.org 的 Wan2.2 章节](https://docs.comfy.org/zh/tutorials/video/wan/wan2_2)）提供了四条：

| 工作流 | 干什么 | 适合 |
| --- | --- | --- |
| Wan2.2 5B TI2V | 文生视频 + 图生视频 | 单卡用户，首选 |
| Wan2.2 14B T2V | 文生视频 | 显存充足、追求更高画质 |
| Wan2.2 14B I2V | 图生视频 | 有高质量首帧图 |
| Wan2.2 14B FLF2V | 首尾帧生成视频 | 给首、尾两张图，生成两图之间的过渡过程 |

加载方式：先把 ComfyUI 更新到最新版，然后在菜单里走「工作流 → 浏览模板 → Video」，选「Wan2.2 5B video generation」等对应模板即可，不用手动搭节点。

## 三、模型文件从哪来

ComfyUI 不直接用 GitHub 仓库里的原始权重，而是用官方重打包版：Hugging Face 的 [Comfy-Org/Wan_2.2_ComfyUI_Repackaged](https://huggingface.co/Comfy-Org/Wan_2.2_ComfyUI_Repackaged)。按所用模板页给出的清单，把扩散模型、VAE、文本编码器三类文件放进 ComfyUI 对应的模型目录——模板教程里逐个列了文件名与存放路径，以页面当时的清单为准。

## 四、显存预期（下载权重前先对号入座）

| 显存档位 | 能跑到什么程度 |
| --- | --- |
| 8GB | 跑 5B 工作流：ComfyUI 自带显存 offload 的情况下可以放下（官方教程口径） |
| 16~24GB（如 RTX 4090） | 5B 从容；14B 工作流跑 480P 可行（社区与云服务商口径） |
| 40GB 以上 | 14B 跑 720P 的建议区间（社区口径 40~80GB） |

不确定自己卡的性能时，先用 5B 模板按默认参数出一条片子再考虑上 14B。

## 五、显卡不够的三条替代路线

- **GGUF 量化版**：社区把 14B 权重量化后发布的版本，显存需求更低，画质有折损；
- **Lightx2v 4 步 LoRA**：把采样步数大幅压低，出片速度提升明显；
- **WanVideoWrapper**：ComfyUI 社区插件，提供更多显存优化开关。

三者都是社区方案，更新快、用法随版本变，动手前先看各自页面的当前说明。生成报错多半出在显存不足或文件放错目录，排查清单见 [视频生成常见问题.md](视频生成常见问题.md)。
