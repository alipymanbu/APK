## 一、装之前先核对安装包

本文用的安装包留档信息如下，装完后如果行为异常（比如要求登录别的服务、频繁弹广告），先回来核对包名是否一致：

| 项目 | 留档值 |
| --- | --- |
| 版本 | 4.17.41 |
| 包名 | `com.flickr.android` |
| 安装包大小 | 约 33.25 MB |
| MD5 | `F94FF9391B0271BFA60B82261C3850DF` |
| 开发者 | Flickr, Inc. |

系统要求：安装包留档标注为 Android 5.2 以上（Android 官方版本序列里并没有 5.2 这个号，一般按「较老的 5.x 设备即可」理解）；你的机型实际能不能装，以官方商店页面当时标注为准。

还没拿安装包的话，从这里取：[Flickr 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4f1b3f4ee1c3)。进网盘后先转存到自己的网盘，再下载到手机。

## 二、安装步骤

1. 在手机上打开下载好的 `Flickr_v4.17.41.apk`；
2. 系统弹出「未知来源 / 允许安装未知应用」提示时，选择允许该来源安装（这是安装非商店应用时 Android 的常规拦截，不是安装包有问题）；
3. 等待安装完成，点「打开」。

可选：想在电脑上确认包没下坏，可以校验 MD5，结果应与上表一致：

```powershell
Get-FileHash ".\Flickr_v4.17.41.apk" -Algorithm MD5
```

手机端的多数文件管理器在文件「属性 / 详情」里也能直接看 MD5。对不上就删掉重新下载一次。

## 三、装完第一步：登录账号

Flickr 需要登录账号才能用。没有账号就在 App 内用邮箱注册一个；已有账号直接登录。注册与登录的具体步骤、密码找回，见 [注册与登录账号.md](注册与登录账号.md)。

登录后建议先做两件事：

- 在设置里确认「自动上传 / Auto-Uploadr」是关是开 —— 它会持续把相册新照片传到账号，免费账号的容量额度有限，开之前建议先看 [免费账号容量限制.md](免费账号容量限制.md)；
- 到系统设置里给 App 通知权限，群组互动和上传完成的提醒才收得到。

## 四、装不上怎么办

- **提示「解析包失败」**：多半是下载不完整，重新下载一次安装包，校验 MD5 后再装；
- **一直卡在「正在安装」**：确认手机剩余空间明显大于 33.25 MB，重启手机再试；
- **安装完成但打不开 / 闪退**：重启一次再开，仍不行按 [常见问题与故障排除.md](常见问题与故障排除.md) 里的条目逐项排查。
