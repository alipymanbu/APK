# 扫描件会上传云端吗

> 这篇讲 TapScanner 怎么处理你的扫描件：哪些会上云、云端存多久、怎么少上传。

## 一、结论先说

**不是所有扫描都上云，但 OCR 和 AI 增强这类功能会把图片送去云端处理。** 扫描合同、证件、账单这类敏感件之前，值得花两分钟读完本篇 —— 依据全部来自官方隐私政策（`tap.pm` 上的 Privacy Policy，版本日期 2025-04-22）与官网说明，不是猜测。

## 二、官方隐私政策说了什么

按官方隐私政策的口径，与你最相关的几条：

| 事项 | 官方口径 |
| --- | --- |
| 什么会上云 | **只有你选中要处理的那张图片**（不会因为你给了相册权限就整本相册上传） |
| 谁在处理 | 用第三方云（政策点名 Cloudflare 与 Amazon Web Services）做图像处理与 OCR 文字提取 |
| 云端存多久 | 照片在最后一次编辑后**云端最多再留 24 小时**，之后删除（让你还能回头改） |
| 加不加密 | 上传的照片加密，**密钥存在你手机本地** —— 官方说法是只有你的设备能解 |
| 视频 | 本地处理，不上传 |
| 用途限制 | 官方声明照片只用于提供编辑功能，不作他用 |

另有一项**自动命名**功能（Smart Auto Naming）：用设备端 OCR 取你文档的前几个词、临时送到服务器生成文件名，用完即删，可在应用设置里关掉。

## 三、网页版是另一回事

官网 [tap-scanner.com](https://tap-scanner.com) 的网页版工具与手机端**不是一套隐私口径**：官网自己的 Trust 页面写明网页工具会把文件发到其托管处理服务，且**不提供选择处理地区的选项** —— 不要默认网页版「本地处理」。在浏览器里传敏感件前，按该页面当时显示的说明判断（截至 2026-09，该页将多项声明标为「待补证据」，即官方自己也没承诺的部分）。

## 四、你实际可以做的几件事

按「上传得越少越好」的原则，扫描敏感件时：

1. **不用的功能不触发**：只做「拍照 → 裁剪 → 滤镜 → 保存 PDF」这条主流程时，按官方口径不会上云（滤镜是否含云端增强项，各版本实现不同，拿不准就当它会上传）；一动 OCR、AI 增强就会上云处理。
2. **关掉自动命名**：应用设置里禁用 Smart Auto Naming，省掉一次文本外发。
3. **扫完即走**：证件、银行卡这类件用完就从应用里删除；云端那份按官方口径 24 小时内自己也会清。
4. **要长期存的自己加密**：给 PDF 加密码后再外发（见 [PDF合并拆分与格式转换怎么做.md](PDF合并拆分与格式转换怎么做.md) 第五节），比依赖云存储更稳。
5. **云备份自己选**：备份到 Google Drive / Dropbox / OneDrive 是应用里**你主动开启**的同步，不开就不传 —— 它与「处理上云」是两回事。

## 五、还想知道更多

- 完整隐私政策入口：官方站点 `tap.pm` 上的 Privacy Policy（页面标注最后更新 2025-04-22，以官网当前版本为准）；官方支持邮箱 `tap-support@tap.pm`，数据相关的疑问可以直接问它。
- 「我的文件到底清没清干净」这类问题，官方口径与你的实际版本可能有时差 —— 拿不准就按第四节从严处理。扫描本身的操作见 [扫描文档转PDF怎么用.md](扫描文档转PDF怎么用.md)，OCR 会触发上云的场景见 [图片转文字与电子签名怎么用.md](图片转文字与电子签名怎么用.md)。
