## 一、这些功能在什么位置

扫描并保存只是第一步，实际用文件时你多半还要**整理**它：几个 PDF 合成一个、一个 PDF 拆出几页、压缩到能发邮件、转成能编辑的 Word。TapScanner 把这类操作做在同一套界面里——在应用的文档列表中打开目标文件，工具栏里就有对应的 PDF 工具入口（合并、拆分、转换、压缩、加密等）。文件还没扫的，先过 [扫描文档转PDF怎么用.md](扫描文档转PDF怎么用.md)。

## 二、合并与拆分

| 想做的事 | 操作 |
| --- | --- |
| 几份文件合成一份 | 选「合并」→ 按顺序加入多个 PDF/图片 → 确认页序 → 保存新文件 |
| 一份文件拆成几份 | 选「拆分」→ 按页码范围或逐页提取 → 每段存成独立文件 |
| 调整页序/删多余页 | 打开文件进页面管理 → 拖动排序、删除不要的页 → 保存 |

拆分常用于「合同只要其中 3 页」；合并常用于「把多张票据凑成一份报销单」。操作前留一份原文件，整理类操作都建议「另存新文件」而不是原地覆盖。

## 三、格式互转

官方资料列出的转换能力（以你装的版本里实际入口为准）：

- **图片 → PDF**：把相册里的照片、截图合成一份 PDF；
- **PDF → 图片**：把 PDF 每页导出为 JPG/PNG；
- **PDF → Word**：转成可编辑的 doc/docx（扫描件转 Word 的编辑质量取决于原图清晰度与 OCR 效果，见 [图片转文字与电子签名怎么用.md](图片转文字与电子签名怎么用.md)）；
- **Word → PDF**：把文档转成固定版式的 PDF 再发送。

## 四、压缩：发得出去的体积

PDF 太大发不了邮件/聊天工具时，用压缩功能减小体积。规律是：压缩率越高、体积越小，文字与图片的清晰度损失也越多——纯文字文档可以压得比较狠，含照片的文档压完记得放大检查一遍字迹是否还清楚。要打印或存档的版本，保留一份未压缩的原件。

## 五、加密与打印

- **密码保护**：给敏感 PDF 设密码，没密码打不开——分享身份证件扫描件、合同前值得加一道。
- **打印**：应用支持直接把扫描件发到打印机（同一 Wi-Fi 下的打印机），适合要纸质回执的场景。
- **分享**：导出后可直接走邮件、社交/聊天工具发送；也可以备份到云端（Google Drive、Dropbox、OneDrive 等，以版本内实际支持列表为准），换设备不丢文件。
