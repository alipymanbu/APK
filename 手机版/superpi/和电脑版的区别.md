## 一、「用圆周率跑分」这件事的来历

电脑上有个 1995 年出自东京大学研究团队的老程序 Super PI：它让 CPU 把圆周率算到指定位数，谁用时短谁算得快。因为计算过程对主频和内存延迟特别敏感、又几乎只吃一个核，它成了超频圈里同时衡量**性能**与**稳定性**的经典项目 —— 电脑版最常用「1M」（一百万位）档做成绩对比，顶级玩家会跑「32M」（3200 万位）来验稳定性。

这个安卓版 SuperPi 干的就是同一件事的简化版：算圆周率到你选的位数，把用时当作单核跑分。你看到的「用时 N 毫秒」，和电脑上那个「XX 秒」是同一个口径 —— **越短越快**。

## 二、手机版 vs 电脑版，差在哪

| 对比项 | 电脑版 Super PI | 这个手机版 SuperPi |
| --- | --- | --- |
| 档位 | 16K 到 3200 万位共 12 档 | 五个档：100 万 / 200 万 / 400 万 / 800 万 / 1600 万位 |
| 界面 | 菜单 + 对话框，还有校验和防作弊机制 | 一屏搞定：选档 → 点「开始」 |
| 结果 | 秒（精确到小数点后三位） | 毫秒 |
| 用途语境 | 超频后的稳定性验证 | 手机单核性能的快速对比 |
| 环境变量 | 电压、内存时序、散热 | 机身温度、后台负载、省电模式 |

用法上的实际差别：电脑能稳定地连跑几十分钟测稳定性，手机一发热就降频 —— 所以同一台手机的成绩波动比电脑大，测法见 [跑分成绩不稳定怎么排查.md](跑分成绩不稳定怎么排查.md)。

## 三、安卓上的同名应用不止一个

搜「Super Pi」会出来好几个不同的应用，包名才是区分依据：

| 应用 | 包名 | 特点 |
| --- | --- | --- |
| **本篇这个 SuperPi** | `xyz.imxqd.superpi` | 中文界面、五档位、一屏操作 |
| Super PI（Rhythm Software） | `com.rhmsoft.pi` | 老牌安卓移植，档位从 8K 到 400 万位，跑完给一份 CPU 信息报告 |
| SuperPI Benchmark（Curciolab） | `com.itcurciolab.benchmarkpi` | 带单线程 / 双线程 / 四线程压力测试 |

确认自己装的是哪个：到「设置 → 应用 → 应用信息」看包名，是 `xyz.imxqd.superpi` 就是本篇这一款；安装包的核对方法见 [下载与安装教程.md](下载与安装教程.md) 第二节。三个应用的口径都是「算得越快成绩越好」，但档位与报告格式不同，成绩之间不能直接互比。

## 四、什么时候该用它

- 想快速知道手机**单核**处于什么水平，几秒出结果，够用；
- 想对比两台手机谁的 CPU 快 —— 同档位各跑三次，看谁的用时短；
- 想看手机**持续性能** —— 直接上八百万、一千六百万位，观察越跑越慢的程度。

它不反映多核、GPU 与内存表现，也不提供电脑版那种防作弊校验 —— 当作参考量级用就好，具体读数方法见 [跑分结果怎么看.md](跑分结果怎么看.md)。
