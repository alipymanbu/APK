## 一、安装包从哪拿

SuperPi 是个 3MB 以内的小工具，安装包以网盘分享的形式获取：

- **SuperPi 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/4a965e8cb89d](https://pan.quark.cn/s/4a965e8cb89d)

打开链接 → 转存到自己的网盘 → 在网盘里下载 `.apk` 文件到手机（或先下到电脑再传到手机）。文件夹里通常还带一个「先保存再下载避免失效」的说明文本，跟着提示走即可。

## 二、装之前先核对文件信息

网盘里这份包的信息如下，下载完可以对一眼，防止拿错文件：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0 |
| 包名 | `xyz.imxqd.superpi` |
| 大小 | 2.96M |
| MD5 | `3DAE7FDF14176D64279B400D2B82879A` |

在电脑上核对 MD5（Windows 自带命令，把路径换成你保存的位置）：

```powershell
certutil -hashfile "C:\path\to\xyz.imxqd.superpi.apk" MD5
```

输出的 32 位十六进制与上表一致，说明文件完整、没在传输中损坏。包名可以在安装前用 apk 查看工具确认，或安装后到「设置 → 应用 → SuperPi → 应用信息」里看，显示的包名应当是 `xyz.imxqd.superpi`。

## 三、安装步骤

1. 把 `.apk` 复制到手机上，用文件管理器点它开始安装。
2. 手机默认会拦「未知来源」的应用：按提示允许本次安装（不同品牌路径略有差异，一般在安装被拦的弹窗里直接有「仍要安装」，或到「设置 → 安全/隐私 → 允许安装未知应用」里给文件管理器授权）。
3. 安装完成后打开，你会看到一个只有标题栏、五个档位和一个「开始」按钮的界面 —— 具体操作见 [跑分结果怎么看.md](跑分结果怎么看.md)。

## 四、系统要求与安装失败怎么办

- 系统要求 **Android 5.2 及以上**（以安装时的实际提示为准；过旧的系统会直接提示解析包错误）。
- 包体只有 2.96M，安装失败基本不是空间问题，常见原因是：
  - **提示「已损坏」或「解析出错」** —— 多半是下载不完整，回到第一步重新下载，或先用第二节的 MD5 核对；
  - **提示「禁止安装未知来源应用」** —— 按第三节第 2 步授权后重试；
  - **提示与已有应用冲突** —— 手机里若装过同包名的旧版本，先卸载再装。
- 装完跑不出成绩、或成绩忽高忽低，见 [跑分成绩不稳定怎么排查.md](跑分成绩不稳定怎么排查.md)。
