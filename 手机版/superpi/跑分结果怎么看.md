## 一、界面就一屏

打开 SuperPi，整屏只有四样东西：

- 顶部标题栏：**SuperPi**；
- 中间一行大字状态：没跑过时显示 **「尚未跑分」**，跑完后变成 **「用时 N 毫秒」**；
- 五个单选档位：**一百万位 / 两百万位 / 四百万位 / 八百万位 / 一千六百万位**（默认选中「两百万位」）；
- 底部紫色的 **「开始」** 按钮。

界面里看不到广告位，也不需要注册 —— 选档、点开始，就这么一个动作。

## 二、跑一次的步骤

1. 点选一个档位（想先看个大概就保持默认的「两百万位」）；
2. 点 **「开始」**；
3. 等几秒，大字会从「尚未跑分」变成「用时 N 毫秒」——这个毫秒数就是你的成绩；
4. 换档位可以再点一次「开始」，成绩会覆盖上一次显示。

## 三、五个档位各是什么意思

档位指的是**要算出圆周率小数点后多少位**。位数越大，计算量越重，跑得越久；同一台手机跑大档位，还能顺带看出它连续高负载下会不会越跑越慢。

| 档位 | 适合场景 |
| --- | --- |
| 一百万位 | 快速对比，几秒出结果 |
| 两百万位 | 默认档，日常对比的常用档 |
| 四百万位 | 中等时长，能看出轻微降频 |
| 八百万位 | 较重负载，观察持续性能 |
| 一千六百万位 | 最重档，跑完耗时明显变长 |

应用截图里那台演示机的成绩：**两百万位 2326 毫秒、八百万位 10834 毫秒** —— 你可以照这两个档位各跑一次，和它粗略对一下量级。

## 四、用时数字怎么读

- **用时越短，说明这颗 CPU 算得越快**。它测的是单核性能，与你有几个核关系不大。
- 只跟**同一档位**的成绩比：两百万位的 2326 毫秒和八百万位的 10834 毫秒没有可比性。
- 同型号手机之间也别只跑一次就下结论 —— 机身热不热、后台干不干净都会影响几秒内的结果，测法见 [跑分成绩不稳定怎么排查.md](跑分成绩不稳定怎么排查.md)。

## 五、一份参考成绩（200 万位）

网上有玩家整理过各款芯片跑两百万位的用时，可当量级参考（设备状态不同，结果会有出入）：

| 芯片 | 200 万位用时 |
| --- | --- |
| i5-1038NG7 | 3 秒 |
| 骁龙 870 | 3.3 秒 |
| 骁龙 855 | 4.4 秒 |
| 天玑 1000Plus | 4.8 秒 |
| 骁龙 835 | 7.6 秒 |
| 骁龙 821 | 7.8 秒 |
| 骁龙 660 | 9.5 秒 |
| 骁龙 662 | 10.4 秒 |
| 骁龙 808 | 16 秒 |

差距基本和各芯片的代际性能差对应。想了解这个测试的来头、以及它和电脑上那个老牌 Super PI 是什么关系，见 [和电脑版的区别.md](和电脑版的区别.md)；还没装的话先看 [下载与安装教程.md](下载与安装教程.md)。
