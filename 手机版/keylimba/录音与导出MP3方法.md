## 一、录音入口在哪

Keylimba 不是单独做一个「录音机」，而是把录音做成了**循环录音（looper）**：录一段 → 循环播放这段 → 可以在循环之上继续叠弹，也可以停下导出。入口是**琴面左下角的按钮**：

- 手机版：左下角按钮即录制；录完后旁边的控件负责播放与停止。
- 网页版（仅供参考，手机版不适用）：左 Shift 键在「录制 → 播放 → 停止」之间循环切换，右 Shift 开关菜单。

录进去、导出来的都是你弹的这段琴声本身。

## 二、录一段

1. 点左下角的录制按钮，进入录制状态。
2. 正常弹琴。想录完整一首，就从头弹到尾；想先试一段短的，弹几拍即可。
3. 录制的内容会自动进入循环播放——你可以停下来听，也可以在它循环的同时**叠弹新的一层**（这是 looper 的典型用法：一段当底、一段当旋律）。
4. 不满意就停止并重新录，录好的段落不会影响你的键数、标签等设置。

触感反馈、菜单音这些属于界面反馈项，与琴声是两回事，设置位置见 [界面设置与调音说明.md](界面设置与调音说明.md)。

## 三、回放与导出

- **回放**：录制状态切到播放即可循环听；切到停止结束。
- **导出**：录完后点击**旁边的箭头按钮**，会给出保存 / 分享入口，把这段演奏**以 MP3 格式保存到本地**或发给别人。这个能力是 5.5 版加进来的；7.1 版还把导出文件的体积调小了，同一段旋律导出的文件比老版本更小。
- 保存成功后，用手机的文件管理器按「最近文件」或音频分类就能找到；具体落在哪个目录因手机品牌与安卓版本而异，在文件管理器里按修改时间找最快。

## 四、几个实际会碰到的点

| 现象 | 说明 |
| --- | --- |
| 想导出却发现只有分享没有保存 | 用系统分享面板里的「保存到文件 / 本地存储」类目标；不同机型这里不一样 |
| 导出的 MP3 开头有一段静音 | 老版本录的内容前面会带空白，官方更新日志（3.3 版）提过已去掉开头的静音，若你用的版本仍有，更新版本即可 |
| 录完声音发闷、有回声 | 菜单里有混响（echo）强度设置，5.5 版加入、7.0 版起可细调（官方商店更新日志），把它调低即可 |
| 录音想留档 | 应用内的录音跟着应用走，**卸载应用会丢**，重要的段落导出成 MP3 后另行备份 |

录出来的音准、音色取决于你在 [界面设置与调音说明.md](界面设置与调音说明.md) 里选的调与音色——导出的 MP3 就是你当时听到的那套声音，后期改设置不会改变已导出的文件。
