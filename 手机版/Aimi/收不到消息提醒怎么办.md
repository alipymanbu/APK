# Aimi 收不到消息提醒怎么办

> 这篇讲 Aimi 消息不提醒、提醒延迟时，按什么顺序查手机设置 —— 通知权限、后台、省电、勿扰逐项过。

## 一、先分清是哪种「收不到」

三种情况查法不同，先对号入座：

| 现象 | 更可能的原因 |
| --- | --- |
| 一直不提醒，打开应用才看到新消息 | 系统通知权限没给、或后台被清（见下节） |
| 提醒延迟几分钟到几小时 | 省电/省流量模式在限制后台联网（见第四节） |
| 应用压根收不到消息、聊天转圈 | 不是提醒问题，是网络或应用本身 —— 按 [常见问题与故障排查.md](常见问题与故障排查.md) 排 |

另外一条华为支持页注明的**正常现象**：手机重启后一段时间收不到提醒 —— 重启后应用还没被系统拉起，手动打开一次 Aimi 即可恢复。

## 二、把通知权限给全

按华为、vivo 客服页的通用路径（各家菜单名略有差异）：

1. 手机「设置 → 通知（通知与状态栏）→ 应用通知管理」，找到 Aimi。
2. 打开「允许通知」，下面的**横幅/悬浮、锁屏、角标、提示音**按需全开。
3. 关掉「静默通知」类选项 —— 静默意味着只进通知栏、不响不弹。
4. Android 13 以上首次启动会弹一次通知权限询问 —— 当时点了「不允许」的话，通知类功能全部失效，就是在这里补开。
5. 部分应用还要在**应用内**再开一次：进 Aimi 的设置里找消息提醒开关，确认打开。

## 三、别让系统把后台清掉

后台被杀 = 应用收不到推送。三件事（vivo 客服页口径）：

- **自启动**：「设置 → 搜索『自启动』」，允许 Aimi 自启动。
- **后台加锁**：最近任务里找到 Aimi 的卡片，**下滑加锁**（卡片右上角出现锁图标），防止一键加速把它清掉。
- **后台耗电**：「设置 → 搜索『后台耗电管理』」，给 Aimi 开「允许后台高耗电」。

华为机型对应的是「设置 → 应用启动管理 → 关闭自动管理，手动允许自启动与后台活动」；部分品牌叫「后台运行白名单」，同一个东西。

## 四、关掉省电与省流量的限制

这俩是**提醒延迟**的头号原因（Android Authority 与各厂商支持页口径一致）：

- **省电模式**：「设置 → 电池」，关掉省电模式；三星等品牌是在「后台使用限制」里把 Aimi 设为不受限。
- **电池优化**：「设置 → 搜索『电池优化』→ 所有应用 → Aimi → 不允许」。
- **省流量模式**：「设置 → 流量管理 → 智能省流量」关掉，或把 Aimi 加进豁免名单 —— 省流量模式下应用后台不联网，推送自然到不了。
- **后台流量**：长按 Aimi 图标 → 应用信息 → 流量，确认「允许后台流量」开着。
- **休眠不断网**：「设置 → 搜索『休眠时始终保持网络连接』」打开（鸿蒙 5 以上对应「允许休眠时通知」）。

## 五、检查勿扰与专注模式

- 手机侧：「设置 → 声音与振动 → 勿扰」确认没开；开了的话所有应用提醒都会静音。
- 专注/睡眠模式同理 —— 它们会按白名单放行通知，Aimi 大概率不在白名单里。
- 应用侧：个别对话若开了「消息免打扰」，只有那一路不提醒（见 [角色聊天与形象设置怎么用.md](角色聊天与形象设置怎么用.md)）。

## 六、查完还不行

按 [常见问题与故障排查.md](常见问题与故障排查.md) 的第二、三节走一遍：清缓存、确认网络通、必要时卸载重装（重装后所有权限要重新给一遍，包括本篇的通知权限）。若确认是换了手机才失效 —— 新手机上要从通知到后台整套重设，且先用 [账号登录方法.md](账号登录方法.md) 的方式把账号登回去，消息才会同步过来。
