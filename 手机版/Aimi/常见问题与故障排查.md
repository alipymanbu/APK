## 一、安装失败 / 装不上

| 现象 | 原因与处理 |
| --- | --- |
| 弹「禁止安装来自此来源的应用」 | 安卓对非商店安装的默认拦截。去「设置 → 安全/隐私 → 安装未知应用」给浏览器或文件管理器授一次权限，返回重装（详见 [下载与安装教程.md](下载与安装教程.md)） |
| 提示「应用未安装」 | 多半是包没下完整或与现有版本冲突。先核对 MD5（`EC72351E371B7BABDCB1B84BFAC754E0`），不对就重新下载；仍失败则先卸载手机里的旧版再装 |
| 提示「解析包出错」 | APK 文件损坏，重新下载一份 |
| 系统版本过低 | 这份包要求安卓 5.2 以上，低于该版本装不上 |

## 二、打开就闪退 / 打不开

按厂商客服的通用排查顺序（vivo、真我、华为支持页口径一致），从便宜到贵依次试：

1. **重启应用**：后台划掉重开；或「设置 → 应用管理 → Aimi → 强制停止」后再打开。
2. **重启手机**：清掉临时故障，成本最低。
3. **查网络**：Wi-Fi 和移动数据互切一次 —— Aimi 全程要联网，网络不通时有的表现为白屏/转圈。
4. **清缓存**：长按图标 → 应用信息 → 存储 → 清理缓存（清缓存不丢登录状态；**清除数据**会把账号信息一起清掉，确认后再用）。
5. **给权限**：应用信息 → 权限，把存储等所需权限打开。
6. **查兼容性**：系统与应用都升到最新；Android 15 等新系统上部分第三方应用未适配，属应用自身问题，等更新。
7. **卸载重装**：桌面长按图标卸载，再从 [Aimi 安装文件资源（夸克网盘）](https://pan.quark.cn/s/22d2fa1a236d) 重新下包装（装前备份要留的聊天相关内容，重装会清本地数据）。

## 三、登录不上去

- 先确认网络（见上节第 3 条），再核对邮箱与密码是否输对（自定义密码区分大小写）。
- 谷歌登录失败常见的两个原因是设备没登谷歌账号、或当前网络连不上谷歌服务 —— 换网络环境再试，或改用邮箱登录（见 [账号登录方法.md](账号登录方法.md)）。
- 邮箱登录「不需要注册、填邮箱设密码即登录」是该应用的设计，别再去找注册页。

## 四、同名应用认错（重要）

叫「Aimi」的不止一个，装错、查错资料都会发生：

| | 本篇讲的 Aimi | 豌豆荚的 Aimi |
| --- | --- | --- |
| 包名 | `com.ai.aimi.android.prod` | `com.qidian.aimi` |
| 开发商 | 第三方页面标注 DaHeng Network | 北京奇点创智科技有限公司 |
| 版本/大小（页面记录） | 1.0.2 / 95.67M | 1.2.5 / 47.36MB |

认**包名**不认名字：装完在「设置 → 应用信息」里看包名是不是 `com.ai.aimi.android.prod`。查资料时也一样 —— 同名的还有 iOS 商店里的「Aimi AI: Chat With Soulful AI」（开发者 MapsPeople Inc，英文界面）和一个叫 Aimi 的 AI 音乐生成平台（aimi.fm），都不是本篇这套包，别把它们的收费、功能说明安到这个应用头上。

## 五、发了消息，AI 没回

聊天页表现是消息发出去了、一直没见回复，先别当故障：

1. **等一会**：回复本身有生成时间，网络切换后旧界面也可能短暂没刷新 —— 退出会话再进，让同步跑完，别连点发送。
2. **查角色状态**：确认这个角色还启用着、没被你禁用（见 [角色聊天与形象设置怎么用.md](角色聊天与形象设置怎么用.md)）。
3. **切网络重进**：Wi-Fi 与移动数据互切一次，重新打开该会话。
4. 都试过仍不回：换一个角色发一条测试 —— 全都不回按 [收不到消息提醒怎么办.md](收不到消息提醒怎么办.md) 与本篇第二、三节查网络与应用状态；只有某一个角色不回，多半是该角色的设定或状态问题。

## 六、提醒相关的问题

消息不提醒、提醒延迟不在本篇展开 —— 那是一整套系统设置（通知权限、后台白名单、省电、勿扰），见 [收不到消息提醒怎么办.md](收不到消息提醒怎么办.md)。

## 七、付费与订阅怎么看、怎么取消

第三方页面两种说法并存：第一手游网标注「免费（软件内购买项目）」，另有页面描述核心聊天功能免费。**以应用内实际显示为准**。若你开通了订阅：

- 取消路径：应用内 → 账户设置 → 按提示取消（逗游转载的应用内 FAQ 口径）。
- 取消后当期计费周期内仍可用，到期不再扣费。

## 八、隐私与数据

应用内 FAQ 的口径是：聊天记录采用行业标准方法加密、未经同意不与第三方分享、用户可随时删除聊天记录，详见应用内的隐私政策。首次启动时的「同意权限与隐私政策」那一步可以先读一遍再点（见 [账号登录方法.md](账号登录方法.md)）。

## 九、还没解决？

把「哪一步、什么提示、什么机型 + 安卓版本」记下来，先在应用内找反馈入口提交；同时留意应用更新 —— 闪退类问题若是新版本引入的，等下个版本修复是常态。装不上包的问题也可回到 [下载与安装教程.md](下载与安装教程.md) 重新核对 MD5 与安装步骤。
