## 一、官方给的版本口径只有一行

官方仓库（`HdShare/WAuxiliary_Public`）的问题表里，适配版本写的是：

> 理论适配 8.0.44~8.0.65 国内与 PLAY 版本

三个信息点：

- **区间是 8.0.44 到 8.0.65**，国内版和 Google Play 版都在内；
- **「理论」二字是官方自己写的** —— 意思是按代码逻辑推断的覆盖范围，不是每个版本逐个实测过；
- 超出这个区间（比如 8.0.66 及以后，或比 8.0.44 更老），官方没有承诺，**不生效属于预期内**。

微信版本怎么看：微信里「我 → 设置 → 关于微信」能看到版本号。装了新版本发现模块失灵，先看这里是不是已经跑出区间了。

**这个区间有多容易踩出去**：对照微信官方更新日志，8.0.65 发布于 2025-11-07，而截至 2026-09 官方 Android 版本已经走到 8.0.78（2026-09-09）—— **上界之后微信又发了十来个版本**。只要开着自动更新，你几乎必然在某次升级后跑出区间。完整时间线、怎么把微信留在区间里、升出去之后怎么处理，见 [微信版本超出适配范围怎么办.md](微信版本超出适配范围怎么办.md)。

## 二、功能级的适配是另一份数据

官方只给区间，**每个功能各自适配到哪个版本**这份明细不在官方文档里，来自第三方下载站整理的适配表。两边口径不同，照下表理解：

| 功能 | 标注的适配范围 |
| --- | --- |
| 阻止撤回 | 理论全版本 |
| 自动登录 | 理论全版本 |
| 自动原图 | 理论全版本 |
| 表情游戏 | 理论全版本 |
| 虚拟定位 | 理论全版本 |
| 模拟扫码 | 理论全版本 |
| 订阅列表 | 理论全版本 |
| 平板模式 | 理论全版本 |
| 圆形头像 | 理论全版本 |
| 通话限制 | 理论全版本 |
| 消息详情 | 标注适配 8.0.45 |
| 精确数量 | 标注适配 8.0.45 |

读这张表要注意两件事：

1. **「理论全版本」指的是微信的版本，不是模块的版本** —— 它说的是这类功能的实现不依赖微信的特定内部结构，不是说你在任何微信版本上都一定用得了。
2. **带 `[测]` 标记的功能是实验性功能**（如消息详情、调试日志输出），第三方整理里明确标了测试字样。实验功能在你当前的微信版本上失效，属于正常现象，不必急着换模块版本。

## 三、模块版本和微信版本要分开看

这两个是独立的变量，排查问题时别搅在一起：

- **微信版本**决定「模块能不能在你这个微信里跑起来」—— 见本篇第一节。
- **模块版本**决定「有哪些功能、修了哪些 bug」—— 见 [版本号怎么看与更新日志.md](版本号怎么看与更新日志.md)。

常见的组合问题是：微信升到了 8.0.66，模块还是去年的版本 —— 这时候先确认微信是否已出区间；微信没出区间而功能失效，才是模块版本太旧，去官方发布页换新模块。

## 四、微信升级前值得做的一件事

微信的正式版更新节奏不由你控制，自动升级很可能一夜之间把你留在区间的版本升出去。想保持稳定，可以在微信的「设置 → 通用 → 自动下载微信安装包」里设为「仅 Wi-Fi 下」或干脆关闭，升不升级由你自己决定。

升级前的备份用微信自带的「设置 → 聊天 → 聊天记录备份与迁移」，这一步与模块无关，但模块失效后你大概率要换版本试，有备份就进退自如。
