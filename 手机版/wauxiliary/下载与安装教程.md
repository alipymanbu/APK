## 一、装之前先确认三件事

WAuxiliary 不是装上就能用的普通 App，它是给微信打补丁的 Xposed 模块。缺任何一环，装完也不会有任何效果：

| 前提 | 说明 |
| --- | --- |
| 一部已装好 Xposed 框架的手机 | 通行做法是 LSPosed（官方致谢名单里就列了 LSPosed）。LSPosed 一般通过 Magisk 或 KernelSU 这类 Root 方案安装，**没有 Root 的手机走不通这条路** |
| 微信在模块支持的版本区间内 | 官方口径是理论适配 8.0.44~8.0.65 的国内版与 Play 版，详见 [支持的微信版本与功能适配.md](支持的微信版本与功能适配.md) |
| 安卓系统版本 | 本篇这份安装包要求安卓 5.2 以上 |

只有一台没 Root 的备用机、又特别想试，可以去找支持免 Root 方案的容器类工具（如太极、VirtualXposed 这类把微信装进隔离环境的做法），但**能否跑通取决于工具自身对新版微信的支持**，与 WAuxiliary 本身无关，这里不展开。

## 二、拿到安装包

从 [WAuxiliary 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b319c40659b4) 转存，文件夹里就是安装包。本篇对应的那一份事实如下（网上搜到的往往是更新的版本，别混着对）：

| 项 | 值 |
| --- | --- |
| 版本 | 1.2.5.r1067.b0841e6 |
| 包名 | `me.hd.wauxv` |
| 大小 | 10.84M |
| MD5 | `B83F7121760462E37E71A60B29A51A6C` |
| 系统要求 | 安卓 5.2 以上 |
| 记录日期 | 2026-09-23 |

想核对下载过程中文件有没有损坏，把 apk 放到电脑上跑一句就行：

```powershell
certutil -hashfile WAuxiliary.apk MD5
```

输出的哈希与上表对得上，就是同一份文件。

## 三、安装与激活（按顺序做）

1. 确认手机上的 LSPosed 管理器能正常打开，且微信本身已登录过一次。
2. 安装 WAuxiliary 的 apk（直接点开安装即可，它只是一个普通的模块管理界面）。
3. 打开 **LSPosed 管理器 → 模块**，找到 WAuxiliary，把开关打开。
4. 进入它的**作用域**，勾选**微信**。只勾微信就够 —— 作用域越大，出问题的面越大。
5. **强制停止微信**（设置 → 应用 → 微信 → 强制停止），或直接重启手机。
6. 重新打开微信，再打开 WAuxiliary 的界面，按需要把功能开关逐个打开。

第 5 步不能省：Xposed 模块是在微信进程启动时注入的，不停掉旧进程，你勾的开关一个都不会生效。

两个安装期的常见卡点：

- **桌面上找不到 LSPosed 管理器**：部分安装方式下管理器没有独立图标，**有教程提到**可以在拨号盘输入 `*#*#5776733#*#*` 直接唤出 —— 该入口并非所有版本都有，唤不出来就回 Magisk / KernelSU 的模块列表里找它的启动项。
- **微信在你操作途中自己升级了**：升出区间的话，前面几步做得再对也不会生效。版本区间怎么对照见 [支持的微信版本与功能适配.md](支持的微信版本与功能适配.md)，想彻底关掉自动升级见 [微信版本超出适配范围怎么办.md](微信版本超出适配范围怎么办.md)。

装完想确认模块真的挂上了，最直接的验证是打开某个功能后到微信里看效果 —— 比如开「阻止撤回」后让对方撤回一条消息。没反应就按 [模块激活后不生效怎么排查.md](模块激活后不生效怎么排查.md) 逐项过一遍。

## 四、卸载与回退

- **关功能**：在 WAuxiliary 界面里把开关关掉即可，不用动微信。
- **彻底停用**：LSPosed 里关掉模块开关 + 取消作用域，再强制停止微信。
- **卸载模块本身**：普通卸载 App 就行，微信本体不受影响（模块不修改微信安装包）。
- **回退微信版本**：微信升级到超出 8.0.65 之后如果模块失效，降级微信前**务必先用微信自带的聊天记录备份与迁移功能备份数据**，微信降级会丢数据这件事与模块无关，但会让你一并踩上。
