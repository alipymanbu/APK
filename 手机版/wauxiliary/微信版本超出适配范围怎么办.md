## 一、先看清楚差了多远

WAuxiliary 官方给的适配上界是**微信 8.0.65**。微信官方更新日志（`weixin.qq.com/updates`）里，Android 版的发布时间是这样的（截至 2026-09 官方页面显示）：

| 版本 | 发布日期 | 相对适配区间 |
| --- | --- | --- |
| 8.0.63 | 2025-09-09 | 区间内 |
| 8.0.64 | 2025-09-29 | 区间内 |
| **8.0.65** | **2025-11-07** | **适配上界（含）** |
| 8.0.66 | 2025-12-02 | 已出区间 |
| 8.0.67 | 2025-12-30 | 已出区间 |
| 8.0.68 | 2026-01-20 | 已出区间 |
| 8.0.70 | 2026-03-30 | 已出区间 |
| 8.0.71 | 2026-04-21 | 已出区间 |
| 8.0.72 | 2026-05-15 | 已出区间 |
| 8.0.74 | 2026-06-08 | 已出区间 |
| 8.0.76 | 2026-07-08 | 已出区间 |
| 8.0.77 | 2026-08-21 | 已出区间 |
| 8.0.78 | 2026-09-09 | 已出区间 |

两个结论：

- **区间上界之后微信已经又发了十来个版本** —— 你手机上如果开着自动更新，跑出区间几乎是必然的。
- 适配是**双向卡死**的：老于 8.0.44、新于 8.0.65 都不在官方承诺内。模块不生效时先对一眼版本号，别先怀疑安装步骤（安装层面的检查见 [模块激活后不生效怎么排查.md](模块激活后不生效怎么排查.md)）。

区间会不会跟着扩大，取决于模块是否还在更新 —— 以 [官方仓库](https://github.com/HdShare/WAuxiliary_Public) Releases 页面当时显示为准，判断方法见 [版本号怎么看与更新日志.md](版本号怎么看与更新日志.md)。

## 二、把微信留在区间内的三件事

前提说清楚：**这是拿「不升级微信」换「模块可用」**，微信不升级意味着新功能、安全补丁也一并不来。要不要这么换，你自己权衡。

1. **关掉微信的安装包自动下载**：微信「我 → 设置 → 通用 → 自动下载微信安装包」，选「仅 Wi-Fi 下」或不下载。这样至少它不会半夜替你把包准备好。
2. **别点升级弹窗**：微信隔段时间会弹「有新版本」。点了，区间就没了。想点之前先看一眼「关于微信」里的当前版本，对照上表。
3. **给自己留一份当前安装包**：还在区间内的微信，**现在就导出一份 apk 留底**（文件管理器里找到安装包导出，或用系统自带的备份功能）。这是你手里唯一可靠的回退来源 —— 等到升出去了再找 8.0.65 的安装包，就得去第三方下载站碰运气，版本真假与文件完整性都没法保证。

## 三、真升出去了：降级微信的步骤与代价

**先做这一步，不能省**：微信「我 → 设置 → 聊天 → 聊天记录备份与迁移」，把记录备份到电脑或另一台设备。**微信从高版本降回低版本，聊天记录大概率不兼容**，没有备份就等于放弃历史记录。

备份完成后再谈降级：

1. 用第二节留底的那份安装包覆盖安装（版本号更低时，部分机型要求先卸载微信再装 —— **卸载即清数据**，所以上面那次备份是前提）。
2. 装完重新登录，再按 [下载与安装教程.md](下载与安装教程.md) 的步骤确认模块生效。
3. 登录回来后立刻做两件事：关掉自动更新（第二节）、重新开一次聊天记录备份。

**不推荐的做法**：去第三方下载站找「微信 8.0.65 历史版本」。这类站点的包既不是官方分发，也常与标称版本对不上 —— 一个来路不明的微信安装包，风险比模块本身大得多。手里没留底、又不想卸载重装，那就**停在当前版本等模块更新**，这是更稳的选择。
