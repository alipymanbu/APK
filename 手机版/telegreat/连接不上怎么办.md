# Telegreat 连接不上怎么办

## 一、先判断是哪一类问题

| 现象 | 更可能的原因 | 处理 |
| --- | --- | --- |
| 一直 Connecting / 时好时坏 | 当前网络到服务器的连通性 | 见第二节 |
| 能打开但验证码收不到 | 验证码渠道问题 | 见 [验证码收不到怎么办.md](验证码收不到怎么办.md) |
| 消息能收但图片、视频加载失败 | 本地缓存或版本过旧 | 见第四节 |

## 二、连不上服务器的排查顺序

1. **换网络试一次**（WiFi 与移动数据互换）。换网后立刻正常，说明问题出在原来的网络环境，而不是应用；
2. Telegram 的连通性因地区与运营商而异。如果你的网络环境本身无法直连，应用内置了代理设置：**Settings → Data and Storage → Proxy**，支持 SOCKS5 与 MTProto 两种类型，可以添加你自己拥有的代理服务；
3. 添加方法：Proxy 页 → **Add Proxy** → 填服务器地址、端口与密钥 → 保存后连接测试显示延迟（Ping）即生效，用开关控制启用与否；
4. 服务端偶发故障也会造成全局连不上——多台设备、多个网络都失败时，等一会儿再试；
5. 一个容易漏掉的组合场景：**登录收验证码时不要挂着代理**。共享出口 IP 的验证请求可能被延迟或拒绝（多方反馈），先断开代理直连请求一次，通过登录后再按需挂回。

代理设置只影响 Telegram 自身的连接，不要在来源不明的渠道随便拿代理配置填进去——你所有的流量都会经过那台服务器。

## 三、后台收不到消息、通知不响

- 部分 ROM 的省电策略会杀后台：把应用加入**自启动**白名单、**关闭电池优化**、允许后台运行（各家系统入口不同，一般在 设置 → 应用管理 → 电池 / 自启动）；
- 单个群或频道不响，是会话内右上角的免打扰在起作用；
- 挂着代理使用时，通知延迟往往随代理稳定性波动，先按第二节确认连接本身稳定。

## 四、版本与数据问题

- 太旧的版本可能因服务端协议更新而行为异常：升级到新版本，安装包信息见 [下载与安装教程.md](下载与安装教程.md)，同包名覆盖安装即可；
- 媒体加载失败或占用空间过大：**Settings → Data and Storage → Storage Usage → Clear Cache** 清缓存，云端内容会按需重新拉取；
- 应用状态彻底异常时，退出登录再重新登录，云端记录会自动恢复——秘密聊天是例外，退出登录即丢失。

按第二节处理完仍然连不上，多半是网络环境对 Telegram 的连通性本身受限，先解决连通性，再回到应用内操作。
