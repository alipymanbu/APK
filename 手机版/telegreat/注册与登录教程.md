## 一、账号体系：一个手机号一个账号

Telegram 账号与手机号绑定：号码没注册过，首次登录就是注册；注册过，登录看到的就是原账号的云端聊天。Telegreat 这类客户端与官方版共用同一套账号体系，同一号码在任何客户端登录，云端记录都一样。

使用第三方客户端前值得知道的一件事：Telegram 的开源许可允许第三方构建，但登录第三方客户端等于信任它的构建者。账号里有敏感对话的话，这个权衡你自己做。

## 二、登录 / 注册步骤

1. 打开应用，点 **Start Messaging**；
2. 选择国家区号，输入手机号，点 **Next**；
3. 等验证码。送达渠道有三种：短信、语音电话、以及——如果你的号码已在别的设备登录过——直接发到那台设备的 Telegram 应用内；
4. 输入验证码；
5. 设过两步验证（云密码）的会再要求输密码；
6. 新号码设置姓名与头像，进入主界面。

## 三、验证码收不到

验证码不一定走短信：**已登录设备的应用内 → 短信 → 语音电话**才是它的发送顺序，很多人等不来的码其实躺在旧设备的应用里。完整排查顺序、语音验证码的用法、以及「Too many attempts」限制的应对，单独整理在 [验证码收不到怎么办.md](验证码收不到怎么办.md)。

连通性本身有问题（应用连服务器都连不上）时验证码根本发不出来，先看 [连接不上怎么办.md](连接不上怎么办.md)。

## 四、两步验证（云密码）

- 作用：即使验证码被截获，没有云密码也登不进账号。它与「应用锁」是两回事——应用锁只锁这一台设备上的应用，云密码守的是整个账号；
- 设置位置：**Settings → Privacy and Security → Two-Step Verification**，设置时可以留一个密码提示，并**务必绑定恢复邮箱**；
- 忘记密码时的三条路：
  1. **绑过恢复邮箱**：登录页点 Forgot password，邮箱收重置码，设新密码即可，云端聊天不受影响；
  2. **没绑邮箱，但还有已登录的设备**：在 Settings → Privacy and Security → Two-Step Verification 里点 Forgot password，等待 7 天重置期——期间聊天与账号数据完好，7 天后回来确认即可重设密码；
  3. **没绑邮箱，也没有任何已登录设备**：只剩「想起密码」或「重置账号」两个选项，重置账号会清空全部聊天、群组和联系人。
- 还有一条要知道：**联系官方客服也找不回云密码**，官方无法验证你是号主，这正是设置恢复邮箱的意义。

## 五、多设备与扫码

- Telegram 支持**无限设备同时在线**：**Settings → Devices** 里能看到所有登录中的会话，可逐个终止；
- 桌面端 / 网页端登录用扫码最方便：桌面端显示二维码，手机端在 **Settings → Devices → Link Desktop Device** 里扫它；
- 已登录的设备本身就是验证码的备用通道：新设备登录时，验证码可以直接发到旧设备的应用内确认；
- 换手机不用迁移数据：新手机登录同一号码，云端记录自动同步。秘密聊天是唯一的例外，它不跨设备。

## 六、号码被封与账号自毁

- 新号码大量加人、群发广告容易被判垃圾行为而封号；如果确认误封，向官方支持申诉，号码被封的申诉地址是 `recover@telegram.org`（以官方页面为准）；
- 账号有「自毁时限」：默认 6 个月不上线自动注销，可在 **Privacy and Security → Delete my account** 里调为 1 / 3 / 6 / 12 个月。不打算常用又想保留账号的话，记得偶尔上线一次。

登录成功后想把手机号码藏起来、不让别人通过通讯录搜到你，设置方法见 [账号隐私设置.md](账号隐私设置.md)。
