# Telegreat 验证码收不到怎么办

## 一、先搞清楚验证码发到哪去了

Telegram 不一定用短信发验证码。发送优先级是：**已登录设备的应用内 → 短信 → 语音电话**。如果你的手机号曾在任何设备上登录过 Telegram，验证码很可能已经发到那台设备的应用里，而你的短信箱永远是空的——这是最多人踩的坑。有旧手机、旧平板或桌面端还挂着登录的话，先去那边看应用内消息。

确认没有其他登录设备后，再按下一节的顺序排查短信渠道。

## 二、短信收不到的排查顺序

1. **先等 60~90 秒再动**。国际短信经常延迟，倒计时没走完就点重发是无效操作；
2. 点登录页的**「收不到验证码」（Didn't get the code）**入口，在弹出的选项里选**语音验证码**——系统打电话念数字给你，多数情况下比短信通道更稳；
3. **双卡手机确认卡槽**：验证码发给你的注册号码，如果收码卡在副卡槽或被设置了短信拦截，切换主副卡或临时关掉另一张卡再试；
4. **挂着 VPN / 代理的话先断开**：共享出口 IP 的验证请求可能被延迟或拒绝（多方反馈），断开后用直连网络重新请求一次；
5. **核对号码格式**：区号选对、号码里不要多出前导 0 或空格，双卡时别把数据卡当成收码卡填进去；
6. **检查短信拦截**：骚扰拦截、境外短信过滤、运营商侧的国际短信屏蔽都会吞验证码——给自己发一条普通短信确认卡没问题，再检查拦截记录。

验证码有有效期，收到后尽快输入，过期就按上面的顺序重新请求一次。

## 三、提示 Too many attempts（操作过于频繁）

短时间内反复请求验证码会触发官方的风控限制，之后无论怎么点都不会再发码，提示通常是「Too many attempts, try again later」。这个冷却短则几分钟、长则 24 小时，期间任何排查手段都没有用，只能停手等它解除。

所以正确姿势是：每一轮只请求一次，配合第一节的优先级先去已登录设备找，等够时间再走语音通道，而不是连续狂点重发。

## 四、语音验证码的注意点

- 选了语音后电话通常在几十秒内拨入，自动播报一串数字，听不清就挂断重选一次；
- 保证**来电不被拦截**：勿扰模式、来电拦截、对陌生境外号码的拦截都要先关掉，否则验证电话会静默失败；
- 漫游状态下接这类境外电话可能按国际通话计费，介意资费的话改用已登录设备授权或换网络后再收短信。

## 五、全部试过还是收不到

- 换个时间段再试，国际短信路由在高峰期丢包更明显；
- 虚拟运营商号码、物联网卡、部分新号段收验证码困难的反馈一直存在——换一个常规在用的手机号往往一次就过；
- 网上任何「代收验证码」「接码平台」都不要碰：验证码环节由官方网关直接下发，第三方无法介入，声称能代收的基本是骗局，等于把账号交出去。

验证码过了这一关还有两步验证密码要过，密码忘记的处理见 [注册与登录教程.md](注册与登录教程.md) 第四节；如果连应用本身都连不上服务器、验证码根本发不出来，先去 [连接不上怎么办.md](连接不上怎么办.md) 解决连通性。
