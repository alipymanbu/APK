## 一、网站原有功能，在手机上都有对应页面

客户端按移动端重新设计了布局，覆盖 bgm.tv 网站的绝大部分页面。下面这些你在客户端里都能直接用：

| 功能 | 干什么用 |
| --- | --- |
| 条目 / 角色详情 | 查作品信息、制作人员、声优、出场角色 |
| 时间线 | 看好友与全站的动态 |
| 超展开 | 全站讨论的聚合入口，相当于社区首页 |
| 时光机 / 用户空间 | 个人中心与别人的主页 |
| 每日放送、搜索、排行榜、目录、年鉴、标签、日志、小组 | 找番与社区浏览 |

带链接的页面支持网页预览（只能看不能操作），遇到需要完整功能的页面会跳到浏览器。

## 二、客户端独有的扩展功能

这些是网页端没有、或者体验明显不同的部分，也是很多人装客户端的理由：

- **bilibili、豆瓣收藏有限同步**：可以把这两个平台的收藏同步到 bgm.tv，省去手工重复标记。同步范围有限制，具体支持哪些类型以应用内说明为准。
- **CDN 中间层加速**：封面图片与大部分脱敏静态数据走了客户端自己的加速层，网页版卡住时客户端经常还能刷出来。设置里还有与数据源头、图片代理相关的选项（不同版本的叫法和位置有变化），封面大面积加载失败或历史图片打不开时，换一个节点或代理再试。
- **词云**：条目、人物、帖子的讨论关键词可视化，扫一眼就知道一部作品的讨论焦点。
- **照片墙**：个人收藏的封面按时间铺开成墙，回顾自己一年看了什么很好用。
- **猜你喜欢 / AI 推荐、关联系列、评分月刊、分类排行**：发现类功能，比排行榜更垂直。
- **番剧截屏、游戏截图预览**：条目下直接预览截图，不用跳图站。
- **多规则超展开屏蔽、用户拉黑**：对吵闹的讨论版按关键词屏蔽帖子，对特定用户屏蔽其动态。
- **本地文件夹条目管理**：扫描本地视频文件夹，按文件夹名（支持罗马音）匹配条目，看完直接在客户端点格子。
- **小圣杯**：社区的角色交易「空气游戏」，客户端里做了独立的界面。

## 三、界面自定义：把高频入口往前放

客户端的自定义选项相当多，常用的几类：

1. **主题**：跟随系统或手动切换浅色 / 深色。
2. **字体大小**：正文与列表的字号可调，长文阅读体验自己调到舒服为止。
3. **布局与首页模块**：首页展示哪些模块可以调整，建议把搜索和每日放送放在前面。
4. **通知设置**：追的条目更新提醒在这里开关，只留真正在追的，避免通知轰炸。

具体选项的位置在不同版本里有过调整，找不到时去设置页里逐组翻一遍，或按关键词在设置内搜索。

## 四、功能多但定位别搞混

扩展功能再多，这个客户端也不是播放器——它管理进度、索引播放源，但不在应用内直接播放视频。这层定位的来龙去脉见[为什么不能直接看番.md](为什么不能直接看番.md)。刚装好、还没登录账号的，先回到[追番进度管理怎么用.md](追番进度管理怎么用.md)把账号这一步走完。
