## 一、账号在网页端注册，客户端只管登录

bgm.tv 的账号体系在网站侧，客户端里没有注册入口。流程分两段：

1. 在电脑或手机浏览器打开 bgm.tv 官网（多个入口域名：bangumi.tv、bgm.tv、chii.in），点注册。
2. 填写邮箱等信息，邮箱必须是能正常收信的。
3. 打开邮箱，把收到的激活码填回注册页面完成激活。
4. 激活成功后，回到手机上打开 Bangumi 客户端，在「我的」页面点「去登录」，用刚注册的账号登录。

注册入口与填写项以官网当时显示为准；激活码有时效，收到邮件后尽快填，过期就得重新走一遍注册。

## 二、登录走的是授权页面

客户端登录不是简单输一次密码：它会拉起 bgm.tv 的授权页面，你在页面上确认授权后回到客户端。所以遇到登录问题时，先确认网页端能正常打开——授权页打不开，客户端侧怎么重试都没用。授权过期后客户端会要求重新授权，重新走一遍登录即可，账号数据不受影响。

## 三、注册与登录环节的高频坑

- **激活邮件收不到**：先翻垃圾邮件箱；还不行就换一个常用邮箱重新注册。
- **激活或登录时反复报错**：有用户反馈把地址栏里的 http 换成 https 再操作就正常了，也有反馈用 http 域名时登录会陷入验证码循环。注册登录这类涉及账号的操作，统一用 https 域名访问更稳。
- **登录状态留不住、每次打开都要重新登**：登录页有个「不保存登录状态」的选项，有用户反馈它容易被理解反——留意这个选项的勾选状态，选错就会每次掉登录。
- **登录成功但数据不对**：确认客户端里加载的是你自己的账号，多账号用户尤其注意，操作方法见[常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、账号里到底存了什么

收藏状态、评分、进度、发出的吐槽都记录在 bgm.tv 服务端，与哪台设备无关：卸载重装客户端、换手机、换电脑登录，这些数据都还在。本地能丢掉的只有缓存和登录状态，重新登录就能找回。账号注册好之后的日常操作，从[追番进度管理怎么用.md](追番进度管理怎么用.md)接着看。
