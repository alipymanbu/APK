## 一、先搞清楚它的分发渠道

Bangumi 安卓客户端（包名 `com.czy0729.bangumi`）是一个开源的 bgm.tv 第三方客户端，作者把它放在 GitHub 上发布，安装包直接挂在 GitHub Releases 页面。按作者的说明，它没有在 Google Play 上架（曾被举报下架），也没有国内应用商店的官方版本——你在各家应用商店搜到的同名安装包，都是第三方转载，版本可能明显滞后。

所以判断一份安装包「正不正」，主要看包名是不是 `com.czy0729.bangumi`、版本号与 GitHub Releases 页面对不对得上。版本号更新很快，网上的介绍页面常年停留在旧版本，以发布页当时的最新版为准。

## 四、安装步骤

1. 在手机上打开刚下载的 apk 文件（用系统自带文件管理器，或浏览器下载列表里点开）。
2. 系统会提示「不允许安装未知来源应用」，按提示允许当前这个来源（文件管理器或浏览器）安装，装完可以把该权限收回。
3. 回到安装界面，点安装，等待完成。
4. 打开应用，首次启动需要登录 bgm.tv 账号，登录相关的问题见[常见问题与解决方法.md](常见问题与解决方法.md)。

## 五、装不上时按这几条排查

| 现象 | 先查什么 |
| --- | --- |
| 点安装没反应或秒退安装页 | 存储空间是否够用（安装包 36.28M，安装后占用更大），删掉一些东西再试 |
| 提示解析包出错 | 安装包可能没下完整，重新下载一次，有条件可核对 MD5 是否为上表中的值 |
| 提示版本不兼容 | 系统版本过旧，客户端更新较频繁，新版本对系统版本的要求以发布页说明为准 |
| 覆盖安装被拒绝 | 确认手机里没有装过来源不同的同名应用（包名相同但签名不同就不能覆盖），先卸载旧的再装 |
| 安装完成后启动闪退 | 先重启一次手机再试，仍闪退则确认下载的是安卓版本而不是其他平台的包 |

## 六、升级与卸载

- **升级**：直接在旧版本上覆盖安装新版本 apk 即可，收藏与进度数据存在 bgm.tv 账号里，覆盖安装不会丢。
- **卸载**：卸载会清掉本地缓存与登录状态，但 bgm.tv 账号里的收藏、评分、进度都还在服务端，重新登录即可找回。
