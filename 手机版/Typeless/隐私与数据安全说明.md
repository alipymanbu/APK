## 一、官方口径先列清楚

按官网「设计私密」板块与定价页的说明：

| 官方声明 | 对你意味着 |
| --- | --- |
| 零云端数据留存（zero data retention） | 口述内容处理完就丢，官方服务器上不留底 |
| 不用于模型训练 | 你的语音和文字不会拿去训练 Typeless 或第三方的模型 |
| 音频不在云端存储 | 录音实时处理，不落云盘 |
| 历史默认只存本机 | 听写历史只在你手机上，别处访问不到 |
| 合规认证 | GDPR、ISO 27001；HIPAA 相关控制仅企业版提供 |

这些是官方的宣传口径，不是可独立验证的审计结论；介意的话，把它当作「厂商承诺」看待，再配合下一节自己动手收紧。

## 二、你自己能控制的几个开关

上面的承诺之外，应用内还有几个你说了算的地方：

1. **历史保留时长**：**永久 / 1年 / 1个月 / 1周 / 24小时 / 从不** 六档可选，不想留任何痕迹就选「从不」，见[历史记录与自定义词典](历史记录与自定义词典.md)。
2. **逐条删除 / 全部删除**：历史记录里对单条左滑删除，或右上角菜单一键清空。
3. **云同步默认关**：历史跨设备云同步是可选功能（Pro 档能力），不开它，历史只在本机。开了它，历史会到你登录的其他设备上——电脑是公用的话想清楚再开。
4. **麦克风权限**：系统级开关，随时可以在「系统设置 → 应用 → Typeless → 权限」里收回；收回后口述不可用。
5. **原始音频**：本机的每条历史都带着原始音频，可以主动分享出去，也能单独删掉。

## 三、联网这件事绕不开

Typeless 的语音处理在云端做（这正是它能去语气词、自动排版的原因），**没有离线模式**——断网时高质量转写不可用。也就是说：不希望音频离开手机的场景（涉及敏感内容的口述），这块键盘并不适合；日常消息、邮件、笔记的口述，按官方口径处理完不留存。

## 四、登录方式与账户痕迹

登录支持 Google、Apple、邮箱三种。用 Apple 登录时可以选「隐藏邮箱」转发地址，少暴露真实邮箱。订阅与付款信息在账户页里管理，方法见[免费额度与Pro订阅](免费额度与Pro订阅.md)；设备丢失时，历史里那些没删的转录是主要暴露面——换机或卖机前，先在旧设备上执行「全部删除」。
