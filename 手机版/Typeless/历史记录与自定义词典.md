## 一、历史记录：每条口述都有底

在 Typeless 里点**历史记录**（History）就能看到全部口述内容，包括你向它提问的记录。单次听写超时自动保存的内容也落在这里。

对某一条转录，手机上的操作都靠「轻点」和「左滑」：

| 你想做的 | 手机上的动作 |
| --- | --- |
| 复制内容 | 轻点该条即可复制；或左滑后点**复制** |
| 反馈转写质量 | 左滑 → **反馈**，写下或口述改进建议 |
| 识别失败想重来 | 左滑点**重试**，用同一段音频再处理一次 |
| 拿原始音频 | 左滑 → **更多** → **分享音频**，发给其他应用 |
| 删掉这一条 | 左滑 → **更多** → **删除转录内容**，确认即可 |
| 清空全部 | 历史记录右上角**更多**菜单 → **全部删除** |

## 二、保留多久自己定

历史记录默认**只存在你的设备上**，其他地方访问不到。在**保留历史记录**选项下可以选：**永久 / 1年 / 1个月 / 1周 / 24小时 / 从不**。不想留痕就选「从不」。

较新的版本加入了**云同步**：在历史记录里开启后，手机上口述的内容在电脑端也能看到，反之亦然；开启时要一并选择云端保留的时长。注意**云同步属于 Pro 档的付费能力**（官方定价页把它列在 Pro 一栏），免费版的历史只在本机。要不要把历史放上云是你的选择，不开它照样能用；这块的完整数据口径见[隐私与数据安全说明](隐私与数据安全说明.md)。你手上的版本有没有这个开关，以应用内显示为准。

## 三、词典：让它记住你圈子里的词

人名、项目代号、行业术语，通用模型第一次听很容易写错。词典就是为此准备的：

- **自动添加**：口述后你手动改正某个词，Typeless 会记住你的写法，把它放进词典的「自动添加」分组。也就是说**每次改错都是在训练它**。
- **手动添加**：点词典右下角的**添加**图标，输入想让它识别的单词或短语，确认即可。（电脑端另有「导入 CSV」批量导入，手机上只能一条条加。）
- **编辑或删除**：点某个词直接编辑；或左滑选择**编辑 / 删除**。词多了点右上角的**搜索**图标按全部或部分内容查。
- 顶部的**全部 / 自动添加 / 手动添加**三个页签用来过滤查看。

典型用法：入职第一天先把手头项目名、同事名字、常拼错的专有名词批量加进去，之后口述周报和会议记录的返工率会明显下降。

## 四、和历史记录配合的几个习惯

- 说到 8 分钟倒计时才收尾的长内容，先去历史记录确认自动保存的那条在不在，再决定要不要重说。
- 对同一段音频反复失败的内容，别连着重试，先检查网络和环境，见[常见问题与故障排查](常见问题与故障排查.md)。
- 翻译出的成稿同样留在历史里，想对照「我说的」和「它翻的」，就在这里看，见[翻译设置与用法](翻译设置与用法.md)。
