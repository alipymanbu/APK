Garena 手机版把聊天做成了常驻功能，好友体系跨手机端和 PC 端通用 —— 你在手机上加的好友，对方用 PC 客户端登录时照样能聊。本文讲加好友的两条路、聊天里能发什么，以及消息发不出去时先查什么。前提是你已经登录了账号，没登录先看 [账号注册与登录方法.md](账号注册与登录方法.md)。

## 加好友前先找到聊天入口

打开应用后点上方（或底部）的聊天 / 好友入口，这里集中了好友列表、加好友和会话记录。不同版本的入口位置可能微调，认准「聊天」或「好友」字样即可。

## 两种加好友的方式

**方式一：按好友 ID 搜索**

1. 进聊天入口，选「查找好友 / Add Friend」；
2. 输入对方的好友 ID（让对方在他的个人资料页把 ID 报给你）；
3. 搜到后发送好友申请，等对方通过。

**方式二：扫码添加**

查找好友页通常同时提供二维码：你的二维码在自己的资料页里，见面时让对方扫你的码（或你扫他的），比手动输 ID 快得多。

具体按钮文案以你应用里的实际界面为准；搜不到人多半是 ID 输错 —— 让对方直接发一串 ID 文字给你，复制粘贴最稳。

## 聊天里能做什么

加上好友之后，会话里可以：

- 发文字消息，单聊或群聊；
- 发语音、发图片（比如发一张战绩截图、一局回放的画面）；
- 在群聊里约组队时间、丢攻略链接。

聊天和游戏是联动的：从资讯或战绩页看到某个好友的动态后，可以直接切到聊天里去聊，不用自己退出去翻好友列表。

## 好友在用 PC 客户端怎么办

不用怎么办 —— 直接发。Garena 的聊天在手机端和 PC 端是互通的，你的好友哪怕此刻坐在电脑前用 Garena PC 客户端，你从手机发的消息他也能收到，回你也是同一条会话。这也是很多玩家装手机版的主要理由：人不在电脑前也不掉线。

## 消息发不出去、收不到时先查三样

1. **网络** —— 应用需要联网，Wi-Fi 和流量切一下试试；
2. **是否登录态失效** —— 长时间没用后可能被登出，回到登录页重新登录；
3. **应用版本过旧** —— 太老的版本可能连不上服务器，按 [登录不上等常见问题排查.md](登录不上等常见问题排查.md) 里的思路排查。
