meteoblue 把多个气象模型的预报画在同一张图里对比：哪张图免费、哪张要订阅，一张图上多条线怎么区分，模型分歧大的时候该信谁——这些官方说明都讲了，但第一次打开照样容易懵。本篇按"在哪打开 → 逐张怎么读 → 分歧大怎么办"的顺序讲。图表样式以 2.8.4 实际显示为准，网页端入口更多但读法相同。

## 一、在哪打开

选定地点后，在地点页往下翻，找**图表（Meteograms / 气象图）**一区（2.8.4 的入口位置以实际界面为准，不同版本摆放略有差异）。常用几张：

| 图名 | 讲什么 | 免费可看 |
| --- | --- | --- |
| 多模型（MultiModel） | 各模型预报画在一起对比 | 是 |
| 全合一（All-in-One） | 单图汇总主要参数 | 是 |
| 5 天 / 7 天气象图 | 温度、降水、风的分图 | 部分是 |
| 14 天逐小时、雪、农业、航空等 | 更专业的变量与更长时效 | 多为订阅内容 |

免费与付费的边界随版本调整，具体以图上是否有锁标/订阅提示为准；订阅差异另见 [免费版与订阅的区别.md](免费版与订阅的区别.md)。

## 二、多模型图逐张读法

官方对每张子图的读法说明如下，照着对号入座即可：

1. **温度图**：每个模型一条线、一个固定颜色，图例列在左侧（模型名 + 颜色）。黄色背景是白天时段；**虚线是所有模型的平均值**。
2. **降水图**：蓝色柱是一小时累计降水量（mm）；**颜色越深，表示预测降水的模型越多**。
3. **天气现象图标行**：浅蓝底=晴，浅灰=少云，深灰=浓云。
4. **风速图**：读法与温度图相同——每模型一条线，黄底为白天，虚线为平均。
5. **风向图**：每个点是一个模型在对应时刻的预测，自下而上按方位排列。
6. **相对湿度图**：各模型的百分比，0% 为全干、100% 饱和。

两个前提要知道：

- **参与对比的模型数量随地区变化**——有的模型只覆盖特定区域，某些地点能对比的模型就是少一些，这不是故障。
- 图上变量取自模型直接输出，**没有按所选地点的海拔、地形精调**，看局地小气候时要有这个预期。

图例里反复出现的几个模型名，知道来历对判断分歧有帮助：**NEMS** 是 meteoblue 自家的模型家族（官方说明 2013 年起业务运行）；**ECMWF** 是欧洲中期天气预报中心的全球模型；**GFS** 是美国国家环境预报中心的全球模型。三者的覆盖范围与分辨率各不相同，同一地点的结论有出入是正常的。

## 三、模型分歧大时怎么办

多模型图的用法一句话：**线挤在一起=各家看法一致，预报可信；线散开=分歧大，预报随时可能改**。官方给的四条应对：

1. 给你的安排准备一个"什么天气都能执行"的备选方案。
2. 更频繁地刷新预报、看更新。
3. 更频繁地对照实际天气演变（配合 [降水雷达与地图用法.md](降水雷达与地图用法.md) 的雷达图层）。
4. 重要活动如果强依赖天气，考虑推迟。

另有两类天气天生难报，模型一致也不等于准，官方明确列了这些预报局限：

- **雷暴**：发生的具体位置和时间几乎无法提前报准，降水量和冰雹都可能出入很大。
- **平流雾/低云**：多数模型和卫星都看不见它，模型可能一致地"报晴"，但实际起雾。
- **复杂山地**：低云和降水可能在模型没捕捉到的情况下快速生成，"本地没雨、几公里外在下"很常见。

## 四、和免费图怎么配合用

日常快查用全合一（All-in-One）就够；要判断"明天到底会不会下"再打开多模型对比分歧度；出远门前两天开始每天早晚各刷一次，观察预报是否稳定——连续几天各模型越靠越拢，可信度就在上升。图怎么看只是第一步，雷达实况对照见 [降水雷达与地图用法.md](降水雷达与地图用法.md)；还没装应用的话，回 [下载与安装教程.md](下载与安装教程.md)。
