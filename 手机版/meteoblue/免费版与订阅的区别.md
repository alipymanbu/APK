# meteoblue 免费版与订阅的区别

> 本篇讲 meteoblue 的付费墙在哪：免费版能用到什么程度、应用内订阅和网页端 point+ 各解锁什么、两套体系为什么不互通。

meteoblue 不装订阅也能完成日常查天气，付费解锁的主要是更长时效的图表、更多专业图层和去广告。付费有两套体系：手机应用内的订阅，以及官网上的 point+ 订阅——名字相近、互不通用，买错地方用不上才是最贵的。本篇把边界列清楚，价格与档期随官方调整，以购买页当时显示为准。

## 一、免费版能用到什么程度

以下内容免费、可直接用：

| 内容 | 说明 |
| --- | --- |
| 基础预报 | 当前天气、逐小时、7 天概览与 14 天趋势 |
| 常用气象图 | 5 天气象图、全合一（All-in-One）等（多模型图以图上是否有锁标为准） |
| 基础地图图层 | 温度、云量、降水、风等常见变量 |
| where2go 寻阳、离线缓存、桌面小组件 | 均不收费（用法见 [离线模式与桌面小组件.md](离线模式与桌面小组件.md)） |

代价是界面上有广告，部分深层图表和地图图层带锁。基础功能没有"只能用几天"的试用期限制，装上（见 [下载与安装教程.md](下载与安装教程.md)）就是长期可用。

## 二、应用内订阅解锁什么

在应用设置/订阅页购买，按月或按年付费（具体档期与价格以订阅页显示为准）。解锁方向：

- **去广告**：界面里不再出现第三方广告。
- **扩展内容**：更多气象图与专业图层，如 14 天逐小时图表、更细的降水与风数据；航空（Air/Stueve/探空）、农业（AGRO）、雪线（SNOW）、天文视宁度（Seeing）这类专业向图表也属于订阅内容。
- **更多地图图层**：热指数、大气稳定度、海浪等（见 [降水雷达与地图用法.md](降水雷达与地图用法.md)）。

## 三、网页端 point+ 解锁什么

point+ 是官网（[www.meteoblue.com](https://www.meteoblue.com)）的订阅，在网页浏览器里使用，官方说明的要点：

- 提供 1/3/6/12 个月几种时长；注册账户后可**免费试用一次，14 天**。
- 解锁网页端的高精度图表、动态地图与工具，含航空探空图、天文 Seeing、完整天气档案库，以及高分辨率雷达/卫星历史影像（回溯至 2019-12-20 起的逐分钟动画）。
- 订阅附带给网页去广告。
- **不自动续费**：订阅期结束自动终止，不订阅不扣费，是否续购由你决定。

point+ 的订阅与图表功能以官网当时页面为准；手机浏览器打开官网也能用 point+，相当于"在手机上看网页版"。

## 四、两套体系互不通用

两边的付费分开管理：官方对网页端去广告的说明里明确写了它"不能转移到 meteoblue 应用"，订阅权益同理按端分开——**在一端购买，不能解锁另一端**。选择建议：

| 你的使用习惯 | 更合适的选择 |
| --- | --- |
| 主要在手机应用里查 | 应用内订阅 |
| 要打印气象图、查历史档案、看探空图 | point+（网页端） |
| 两边都用得多 | 按主力端订阅一个，先各用免费部分，确有需要再买另一边 |

先试用再掏钱：point+ 有官方 14 天试用（注册后一次）；应用内订阅是否提供试用，以订阅页当时显示为准。

## 五、恢复购买与取消

官方 FAQ 对"订阅后仍显示广告/权益没生效"给了成套排查步骤，按顺序做：

**Android**：

1. 彻底关闭应用后重新打开。
2. 卸载重装（先到"设置 → 应用"确认列表里已没有 meteoblue，再装回来）。
3. 系统设置 → 应用 → meteoblue → 存储，清除缓存与数据后重开应用。
4. 仍不行，把手机型号、系统版本和问题截图发给官方客服。

**iOS**：

1. 彻底关闭应用后重新打开。
2. 点左上角菜单（九个小方块图标），在出现页面的右下角点购物车图标进入商店页；若左侧按钮显示"恢复（Restore）"，点它恢复购买。
3. 重启手机后再重复上一步。
4. 卸载重装后再试一次。
5. 仍不行，把机型、系统版本和问题截图发给官方客服。

其余两件事：

- **不想续费**：应用内订阅在对应商店的订阅管理里取消；point+ 本身不自动续费，到期不用管。
- **换了手机后权益消失**：用同一个应用商店账户登录，再按上面的恢复步骤走一遍。
