# ScreenStream 不在同一 wifi 怎么远程投屏

> 手机和看画面的人不在同一个网络时，用 Global 模式（WebRTC）：一个串流 ID 加密码，对方用浏览器就能连上，还带声音。

## 一、这条路和 Local 模式的区别

Local 模式要求手机和观看设备在同一个网络里；人在外地、对方用流量、或你们隔着办公室和家，就走 Global 模式。它的连接方式不靠 IP 地址，而是靠**串流 ID + 密码**：手机开播后拿到一个 ID，你把 ID 和密码发给对方，对方在任何支持 WebRTC 的浏览器里输入就能看到画面。传输端到端加密，支持屏幕、麦克风和设备内部声音。

两个前提先确认：

1. **你装的是带 Global 模式的构建**——官方说明里 Global 模式只在 Google Play 版里提供，F-Droid 版没有。主界面翻不到 Global 页就说明这份构建不带，换渠道重装见[下载与安装教程](下载与安装教程.md)。
2. **手机和观看端都要能上网**——这条路靠互联网牵线，断网就连不了。

## 二、手机端：开播并拿到串流 ID

1. 打开应用进入 **Global 模式**页。
2. 先在设置里**给串流设一个密码**——这是你的画面唯一防线，不要空着。
3. 点启动，系统弹屏幕捕获授权时点"立即开始"。
4. 界面上会显示本次的**串流 ID**。

ID 和密码就是对方的全部入场券，用聊天工具发给对方即可；演示结束记得点通知栏里的停止。

## 三、观看端：浏览器输入 ID 和密码

1. 对方在电脑或手机浏览器打开官方网页客户端：[https://screenstream.io](https://screenstream.io)。
2. 输入你发过去的串流 ID 和密码。
3. 连上后画面直接出现在网页里，Chrome、Edge、Firefox、Safari 这些支持 WebRTC 的现代浏览器都可以。

观看端同样零安装——不需要装任何软件，有浏览器就行。

## 四、声音也能一起传

这是 Global 模式相对 Local 模式的一个实质差异：Local 模式只有画面没有声音，而 Global 模式可以把**麦克风**和**设备内部声音**（如手机正在播放的声音，取决于设备支持情况）一起传过去。远程帮家人调手机时把麦克风打开，边看边说，效率高得多。音频开关在 Global 模式的音频设置里，开播前勾选即可。

## 五、带宽与安全要心里有数

| 事项 | 官方口径 | 对你的影响 |
| --- | --- | --- |
| 观看人数与带宽 | 每个观看端各占一份手机上行带宽 | 两个人同时看，上行压力翻倍；人多时卡顿先找这里 |
| 加密 | 端到端加密 + 密码 | 画面内容本身有保护，密码别设太弱 |
| 连接撮合 | 需要互联网，官方的公共开源服务负责牵线 | 双方网络都要能正常上网；画面数据在设备之间点对点传输 |

连不上时的排查（ID 输错、浏览器太旧、断网等常见项）按[连接失败与画面延迟排查](连接失败与画面延迟排查.md)第五节逐条过；想先看清三种模式的整体取舍，回[三种投屏模式怎么选](三种投屏模式怎么选.md)。
