## 一、这条流程能让你做到什么

手机连着 Wi-Fi，电脑连着同一个网络：你在手机上点两次，然后在电脑浏览器里输入一个地址，手机屏幕就出现在浏览器里了。电脑端零安装、零插件，Chrome、Edge、Firefox、Safari 都能看。还没装应用的话先看[下载与安装教程](下载与安装教程.md)。

## 二、开始前的两个前提

1. **手机和电脑在同一个网络里**：最常见是同一个 Wi-Fi。没有 Wi-Fi 时，用手机开热点让电脑连上来，或者用 USB 网络共享，都属于"同一个网络"，一样能投。
2. **知道电脑端有浏览器就行**：不需要在电脑上装任何接收端。

有一个坑提前避开：不少公共或访客 Wi-Fi 开了"设备隔离"，同一网络下的设备互相不可见，这种网络里这套流程走不通，具体见[连接失败与画面延迟排查](连接失败与画面延迟排查.md)。

## 三、完整步骤

1. 手机上打开 ScreenStream，进入 **Local 模式**页。
2. 点**启动**（Start）。系统弹出屏幕捕获授权时点**立即开始**；首次还会要通知权限，建议给。
3. 应用界面上会显示一个完整地址，形如 `http://192.168.x.x:8080`——**以应用里实际显示的为准**，别凭记忆猜 IP。
4. 电脑上打开浏览器，把那个地址原样输进地址栏，回车。
5. 如果你设置过 PIN，浏览器会先要 PIN；没设则直接看到画面。
6. 看完想停：在手机的通知栏常驻通知里点**停止**（Stop），浏览器里的画面随之断开。

整个过程手机端要一直保持应用在前台或后台运行、通知栏常驻在。系统把后台杀掉投屏就断了，这也是"投着投着画面冻住"的头号原因。

## 四、多个浏览器窗口同时看

打开那个地址的浏览器窗口数量不限——你可以同时开两个窗口、也可以让办公室另一台电脑一起看。但注意官方说明里的机制：**每个观看窗口都各占一份带宽和一份手机 CPU**。三个人同时看，手机要发三份数据，卡顿概率随之上升。人多时优先保证 Wi-Fi 质量，或者减少同时观看的窗口数。

## 五、画面大小和方向怎么调

Local 模式页里能改画面的发送形态，改完观看端刷新即可生效：

| 想要的效果 | 去哪调 |
| --- | --- |
| 画面更清晰、但更占带宽 | 图像设置里按**精确分辨率**指定输出尺寸 |
| 流畅优先、画质将就 | 图像设置里按**百分比**缩小，比如缩到 50% |
| 只投屏幕的一部分（比如只投一个 App 的区域） | 图像设置里用**裁剪**框选范围 |
| 投竖屏内容到横着的显示器 | 图像设置里调整**旋转** |

低带宽环境下把分辨率降下来，是改善卡顿最立竿见影的一招；具体参数入口的名称以你装到的版本界面为准。调完还是卡，按[连接失败与画面延迟排查](连接失败与画面延迟排查.md)的延迟一节逐项过。

## 六、安全提醒：Local 模式不加密

Local 模式的 PIN 只是"不知道 PIN 的人进不来"，画面数据本身在网络里是不加密的。在家里、办公室自己的 Wi-Fi 下用没问题；在酒店、咖啡店的网络上投屏幕内容（尤其会弹通知的那种），想一想观看者只有你一个吗。需要跨网络且加密的投法，用 Global 模式，对比见[三种投屏模式怎么选](三种投屏模式怎么选.md)。
