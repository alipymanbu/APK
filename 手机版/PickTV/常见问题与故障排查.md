## 一、安装阶段的问题

装不上、报错弹窗的对照表在 [下载与安装教程.md](下载与安装教程.md) 第五节，先看那边。这里只补两条高频的：

- **提示「解析包时出现问题」**：九成是文件没拷全。核对体积约 48.10M、MD5 为 `53DD94CE7749FC30F9573E028BABCFFC`，不对就重新下载。
- **提示「禁止安装未知来源应用」**：系统安全开关没开，位置常见在 `设置 → 账号与安全` / `设置 → 安全`，允许后再点一次 APK。

## 二、打开后一片空白 / 没有内容

**先说结论：这不是故障。** PickTV 出厂不带影视源，没配置接口之前首页就是空的。按 [影视源接口怎么配置.md](影视源接口怎么配置.md) 第三节填一个地址，加载完成就有内容了。

填了还是空的，逐条对：

| 情况 | 判断 | 处理 |
|---|---|---|
| 从没填过地址 | 设置里的点播输入框是空的 | 填接口地址，见接口篇 |
| 填了但一直转圈 | 加载进度不动 | 地址打不开：核对抄写是否完整，换一个地址 |
| 填了、加载完仍空白 | 进度走完但没分类 | 地址格式不匹配或本身是空清单，换一个地址 |
| 设备根本没联网 | 其它 app 也上不了网 | 先连 Wi-Fi / 网线，联网后重开软件 |

## 三、播放卡顿、黑屏、有声无画

按顺序试，多数情况在前三步解决：

1. **降画质**：播放菜单里从超清降到标清。网络波动是最常见的卡顿原因。
2. **看直播卡还是点播卡**：只有直播卡 → 多半是该源的直播线路慢，换源（主界面左上角）；点播也卡 → 查网络。
3. **重启路由器与软件**：退出 PickTV 重开，让接口重新加载一次。
4. **黑屏但有声音**：解码问题，试着换一部片确认是否片源本身的问题；同一源的片都黑就换源。
5. **换了源还是所有片都卡**：设备性能或网络带宽的问题——关掉后台应用，用测速确认宽带，老旧盒子建议全程用标清。

### 只在晚上卡？先分清是谁的问题

有用户反馈，同一条宽带下，**其他视频 app 播放流畅、唯独 PickTV 这类第三方源卡**，且集中在晚上 8~10 点——这个时段大家都在线，源站服务器最容易过载。判据很直接：

| 现象 | 结论 | 处理 |
|---|---|---|
| 其他 app 也卡 | 宽带或局域网的问题 | 查路由器、测速、错峰 |
| 其他 app 流畅，只有 PickTV 卡 | 当前源的线路在高峰时段过载 | 换源、降画质，或过一阵再看 |
| 只有某个台 / 某部片卡 | 该条线路单点故障 | 换个台、换部片，等源方修复 |

高峰时段卡是源的问题，**换宽带、重启路由器通常没用**——换源才是对症的。

更多播放操作（画质、进度、收藏）见 [点播与直播操作指南.md](点播与直播操作指南.md)。

## 四、突然全部内容消失 / 源失效

用得好好的某天打开全空了，几乎都是**接口地址失效了**——这类地址是第三方维护的，失效、换域名、改路径都很常见。处理：

1. 回 [影视源接口怎么配置.md](影视源接口怎么配置.md) 换一个新地址粘进去。
2. 换完在浏览器里先打开新地址确认能访问，再贴进软件。
3. 直播频道跟着源走，换源后频道列表会变，属正常现象。

## 五、直播换不了台 / 频道列表出不来

- 直播播放中按**菜单键或 OK 键**才出频道列表（见 [点播与直播操作指南.md](点播与直播操作指南.md) 第四节），直接按返回会退出播放。
- 频道列表是空的 → 当前源不带直播线路，换一个带直播的源。
- 只有某几个台打不开 → 源的单条线路挂了，换个台或换源。

## 六、闪退、卡死、越用越卡

| 现象 | 处理 |
|---|---|
| 一打开就闪退 | 先清缓存（`设置 → 应用 → PickTV → 清除缓存`）；不行就卸载重装，重装后需重填接口，建议先把地址抄下来 |
| 覆盖新版本后闪退 | 同上：清缓存 → 卸载重装 |
| 用几天越来越卡 | 清一次缓存；盒子内存小的话定期重启设备 |
| 遥控器按键没反应 | 确认焦点在播放器上（按一下方向键看有没有高亮）；部分盒子需在系统设置里给遥控器开启 HDMI-CEC 控制 |

## 七、还是解决不了

先用最小变量定位：**换一个接口地址** → **换一部片 / 换个台** → **换一个网络**（手机开热点试）。三步里哪一步恢复正常，问题就在那一层——地址问题见接口篇，片源问题换源即可，网络问题查宽带。设备本身装不上则回到 [下载与安装教程.md](下载与安装教程.md)。
