## 一、为什么装完是空的

PickTV 是 TVBOX 那一类播放器：**它只提供播放器，不提供内容**。片源列表由一个「影视源接口地址」提供——那是一个网址，指向一份描述「有哪些站、哪些分类、视频地址怎么取」的配置文件。你在软件里填上这个网址，它加载完才会有电影、剧集、直播频道可看。

所以「打开没内容」不是故障，是还没配置，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 二、接口地址长什么样

接口是一个普通的 http/https 网址，通常以 `.json` 结尾或指向一个 `api.json`，例如：

```
http://example.com/tv
https://example.com/api.json
```

（上面只是格式示例，不是可用地址。）

它可能是单个接口文件，也可能是一份「仓」（聚合多个接口的清单）。这类地址的时效性很强——**今天能用的地址过一阵可能就失效了**，所以别指望一个地址用到老，失效了就换一个，见第五节。

从哪找地址：网上有不少玩家整理的接口分享帖、交流群、代码仓库。你自己找一个贴进去试即可；本篇只讲怎么填，不保证任何具体地址长期可用。

## 三、配置步骤（照着点）

1. 打开 PickTV，进入主界面后点**右上角的设置**。
2. 点设置菜单里**最上面的「点播」**选项。
3. 在输入框里**粘贴你的接口地址**，点确定。
4. 等软件加载完成（底部会有加载进度），然后返回主界面。
5. 加载完，首页就会出现影视分类，可以开始找片了。

配置完的入口在**主界面左上角**，那里显示当前用的是哪个影视源。

## 四、换源与多源切换

一个源不好用（片少、加载慢、失效）就换：

1. 回主界面，点**左上角的影视源**入口。
2. 在列表里选另一个已配置的源；列表里没有的话，回第三节再粘一个新地址。

多备两三个地址轮流试是常态——哪个源的分类合你口味、更新快，就常用哪个。

## 五、地址填了没反应 / 加载失败

| 现象 | 处理 |
|---|---|
| 确定后一直转圈 | 地址本身打不开。确认网址一个字符没抄错（这类地址常带中文域名或长路径，粘贴时容易截断）；换一个地址试 |
| 加载完首页还是空的 | 地址能打开但格式与播放器不匹配，或它本身只是个空清单。换一个地址 |
| 用了一阵突然全空 | 地址失效了，这类地址失效很常见。换新地址即可，见第四节 |
| 想确认地址能不能访问 | 在手机或电脑浏览器里先打开这个网址，能看到 JSON 文本就说明地址本身是通的 |

更多打不开的情形汇总在 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 六、配置好了之后

- 找片、播放、直播换台的操作看 [点播与直播操作指南.md](点播与直播操作指南.md)。
- 还没装软件的话，先看 [下载与安装教程.md](下载与安装教程.md)。
- 接口地址填过一次后软件会记住，下次打开不用重填；卸载重装才会丢。
