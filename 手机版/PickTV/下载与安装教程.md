## 一、PickTV 是什么

PickTV 是一款装在智能电视、电视盒子上的安卓播放器，属于 TVBOX 那一类：**装好后本身不带影视内容**，要你填一个影视源接口地址才会有片可看。配好之后点播（电影、剧集、动漫、纪录片）和直播都能看，界面按遥控器操作设计，大字分区，没有弹窗广告。

装它之前先想清楚一件事：它是「播放器 + 你自己配置的源」的组合，装完第一件事不是找片，而是配置接口——那一步在 [影视源接口怎么配置.md](影视源接口怎么配置.md) 里讲。

网络上名字相近的播放器很多，包名各不相同。本文对应的安装包以这份信息为准：

| 项目 | 值 |
|---|---|
| 应用名 | PickTV |
| 包名 | `com.peektv` |
| 版本 | v1.0.0 |
| 安装包大小 | 48.10M |
| MD5 | `53DD94CE7749FC30F9573E028BABCFFC` |
| 系统要求 | 安卓 5.2 及以上 |
| 形态 | 电视 / 盒子端（安卓） |

网上下载站标着的版本号和体积常常与上表对不上——那些是其他渠道的版本，**你实际装的以表里这份为准**。想核对 U 盘里拷的是不是同一份文件，比对 MD5 即可。

## 二、安装包从哪拿

从 [PickTV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8042a54b524d) 转存或下载 APK 文件。下载完先确认文件体积约 48.10M、后缀是 `.apk`，再进行下一步。

下载到电脑上最顺手——反正最终要通过 U 盘送进电视。

## 三、U 盘安装步骤（电视 / 盒子）

1. 准备一个 U 盘，在电脑上把下载好的 `.apk` 文件拷进 U 盘根目录。
2. 电视或盒子上打开设置，把「允许安装未知来源的应用 / 安装未知应用」设为允许。不同品牌叫法不同，常见位置是 `设置 → 账号与安全`、`设置 → 安全`、`设置 → 通用 → 外部来源应用`。
3. 把 U 盘插进电视的 USB 接口。没自动弹出提示的话，打开系统自带的「文件管理 / U盘 / 媒体中心」找到它。
4. 点那个 `.apk` 文件，弹出安装界面后确认安装，等进度走完。
5. 装完先别拔 U 盘——打开应用确认能进主界面，再退出、拔盘。

手机上装法一样：允许安装未知来源，再用文件管理器点 APK 安装。手机版装上后界面是竖屏适配的，操作逻辑与电视版一致。

### U 盘格式：电视认不出来先查它

U 盘插上电视没反应、或能看到 U 盘却看不到里面的 APK，多半是 U 盘格式电视不认。三种格式的差别（按主流电视与盒子的实测情况，以你的设备实际表现为准）：

| 格式 | 电视端兼容性 | 单文件上限 | 建议 |
|---|---|---|---|
| FAT32 | 最好，几乎所有电视 / 盒子都能读 | 4GB | **首选**。PickTV 才 48.10M，远不到上限 |
| exFAT | 主流安卓 5.0 以上一般支持 | 无上限 | FAT32 不认时的备选 |
| NTFS | 部分老旧电视、盒子不识别 | 无上限 | 不建议用于电视 |

在电脑上右键 U 盘 → 属性就能看当前格式。要格式化的话**先备份 U 盘里的文件**（格式化会清空）。

拷完文件后在电脑上「安全弹出」再拔，防止写入没落盘；有条件的可以先在电脑上双击 APK 确认安装界面能弹出来，确认文件完整。

### U 盘之外的安装方式

不方便反复插拔 U 盘时，还有两条路（都需要电视和手机 / 电脑在**同一个 Wi-Fi**）：

- **远程推送**：电视上先装一个带「远程推送」功能的应用市场（如当贝市场，同样用 U 盘先装一次），打开其远程推送页会给出网址或二维码；手机浏览器打开该网址上传 APK，电视端自动触发安装。
- **局域网共享**：电脑上把 APK 所在文件夹设为共享，电视用文件管理器的「局域网」入口找到共享文件夹，直接点 APK 安装。

两条路装的都是同一个 APK，装完后的注意事项与下节相同。

## 四、装完第一次打开注意什么

- **需要联网**。点播和直播都走网络，没连 Wi-Fi 或网线时进去是一片空白。
- **第一次打开大概率没有内容**——这是正常现象，不是装坏了。PickTV 出厂不带影视源，先按 [影视源接口怎么配置.md](影视源接口怎么配置.md) 填一个接口地址，加载完成才会有片。
- 遥控器是主要输入设备，配置接口时要在输入框里粘贴地址，见接口篇的具体步骤。
- 打不开、进不去、播放异常，按 [常见问题与故障排查.md](常见问题与故障排查.md) 逐条查。

## 五、安装时的报错对照

| 提示 | 原因 | 处理 |
|---|---|---|
| 「解析包时出现问题 / 包损坏」 | 拷贝不完整或下载中断 | 核对体积是否约 48.10M、MD5 是否为 `53DD94CE7749FC30F9573E028BABCFFC`，不对就重新下、重新拷 |
| 「禁止安装未知来源应用」 | 系统安全开关没开 | 回到第三节第 2 步，允许后再点一次 APK |
| 「安装失败 / 应用未安装」 | 存储空间不足，或旧版本残留冲突 | 清出几百 MB 空间；仍失败就先卸载旧版再装 |
| 「与已有应用签名冲突」 | 设备上装过同名不同签名的包 | 卸载原有的再装（已配置的接口地址会丢，需重填，见 [影视源接口怎么配置.md](影视源接口怎么配置.md)） |
| 安装按钮是灰的、点不动 | 未知来源开关没生效 | 部分品牌要先在 `设置 → 关于本机` 连点版本号激活开发者选项，才能看到安装权限开关 |
| U 盘里看不到 APK 文件 | 文件名带特殊字符，或电视文件管理器只认安装包入口 | 把 APK 改成纯英文数字名；或到 `设置 → 应用 → 安装包` 里找 |
| 装完桌面找不到图标 | 部分系统不给第三方应用建快捷方式 | 到 `系统设置 → 应用 → 已安装应用` 里找；部分系统长按主页键可把应用固定到主界面 |

## 六、覆盖安装与卸载

同一个包名（`com.peektv`）的新版本 APK 可以直接覆盖安装，已配置的影视源接口一般会保留。若覆盖后闪退，先在应用管理里清一次缓存；还不行就卸载重装——卸载前把接口地址抄下来，装完重填一遍。
