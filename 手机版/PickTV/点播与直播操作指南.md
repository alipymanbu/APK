## 一、先确认影视源已配好

PickTV 的所有内容都来自你配置的影视源。如果首页是空的，先按 [影视源接口怎么配置.md](影视源接口怎么配置.md) 把接口填上——下面的搜片、播放、直播全都以「已经加载出内容」为前提。

首页左上角显示当前在用哪个源；分类区通常按电影、剧集、动漫、纪录片等分区排列，方向键选中回车进入。

## 二、点播：搜片与播放

1. 选主界面的**搜索**入口，用遥控器在输入框里打片名——支持片名、演员等关键词，输入即匹配，不用翻页找。
2. 结果里选中目标，进入详情页。
3. 详情页里点**开始播放**，软件自动进入全屏。

几个播放中的常用动作：

| 想做什么 | 操作 |
|---|---|
| 暂停 / 继续 | OK 键（回车） |
| 快进快退 | 方向键左右 |
| 调清晰度 | 播放中调出菜单选画质：标清 / 高清 / 超清 |
| 退出全屏 / 退出播放 | 返回键 |
| 换集 | 详情页或播放菜单里选集数 |

**画质怎么选**：网络一般就选标清，保证不卡；宽带给力再上高清、超清。卡顿先降画质，无效再看 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 三、进度记忆与收藏

- **播放进度自动记**：中途退出或切出去，下次打开同一部会直接接续上次的位置，不用手动拖进度条。
- **收藏**：详情页有收藏按钮，把常看的剧加进收藏专区，下次从收藏直达，不用再搜。

注意：进度和收藏是存在本机的，**卸载重装会清空**（见 [下载与安装教程.md](下载与安装教程.md) 的覆盖安装与卸载一节）。

## 四、直播：怎么看电视直播

1. 回主界面，选**直播**选项，会出现直播小窗口。
2. 点小窗口，进入全屏播放。
3. 播放中按遥控器的**菜单键或 OK 键**，唤起电视频道列表。
4. 上下选台、回车确认，即可切到想看的频道。

直播频道列表由当前影视源提供——换源后频道也会跟着换，切源入口在主界面左上角（见 [影视源接口怎么配置.md](影视源接口怎么配置.md) 第四节）。

## 五、遥控器操作速查

| 按键 | 场景 | 作用 |
|---|---|---|
| 方向键 | 浏览 | 移动焦点、选分类 / 选片 |
| OK（回车） | 浏览 / 播放 | 进入 / 暂停继续 |
| 返回 | 任意 | 退回上一级、退出全屏 |
| 菜单键 | 直播播放中 | 唤起频道列表 |
| 菜单 / 选项键 | 播放中 | 调出画质、选集等菜单 |

不同盒子的遥控器按键叫法略有出入，找不到菜单键时看遥控器上标着「菜单 / Menu / 设置」的那个。

## 六、画面比例与黑边

PickTV 会按电视屏幕比例自动适配画面，一般不用手动调。如果某台设备上出现黑边或画面被拉伸，先在电视自身的「画面比例 / 图像模式」里设成「原始 / 16:9 自动」，再试播放器——多数情况是电视端设置抢了默认值。

播放卡、黑屏、有声无画的排查在 [常见问题与故障排查.md](常见问题与故障排查.md)。
