## 一、它是怎么拦广告的（先看懂再配）

你在浏览器里打开网页时，请求本来是直接发往网站的。经典版 Adblock Plus 装上后，会在手机本机开一个代理端口（默认 2020），所有经过这个端口的网页请求先由它过一遍——命中过滤规则的广告请求直接丢弃，其余照常放行。所以「拦广告」这件事的前提是：**流量确实经过了它**。

这也决定了两件事：

- 无 Root 时，安卓不允许它自动改系统代理，你得手动把 WiFi 代理指到本机端口上；
- Root 时，它拿到了改系统设置的权限，可以自动配置。

旧官方资料标注这套方案的系统门槛是 Android 2.2 及以上、代理模式需要 Android 3.0 以上。这份 1.3 是面向旧系统的老应用，在新版安卓上能否正常驻留后台，以你实际安装后的表现为准。

## 二、无 Root：给 WiFi 手动配代理

无 Root 模式只能过滤 **WiFi 网络**下的流量，移动数据管不到。而且安卓的代理是**按 WiFi 逐个设置的**——换一个热点就要重配一次。

以常见的原生系统路径为例（你手机的菜单叫法可能略有不同）：

1. 打开「设置 > WLAN」，长按当前已连接的网络名称。
2. 在弹出的菜单里选「修改网络」（有的系统是点网络名旁的齿轮进详情）。
3. 展开「高级选项」，找到「代理」，把「无」改成「手动」。
4. 主机名填 `localhost`，端口填 App 里显示的端口（默认 `2020`），保存。

配置完打开 Adblock Plus 主界面，确认开关处于开启状态，再用浏览器开个网页试试。各家系统把代理菜单藏的位置不一样，找不到入口时对照 [各品牌WiFi代理设置入口.md](各品牌WiFi代理设置入口.md)；主界面长时间停在「等待流量」的处理也见那篇第三节。

三个容易踩的点：

- 主机名必须是 `localhost`（或等价的 `127.0.0.1`），不能填别的；
- 端口要和 App 设置里显示的监听端口一致，改过就要跟着改；
- 关掉 App 或卸载之前，**先把 WiFi 代理改回「无」**，否则网络会整个断掉（原因见第四步）。

## 三、Root：自动配置

已 Root 的设备在首次启动 Adblock Plus 时，它会请求超级用户权限，同意之后由它自动完成 WiFi 与移动数据（APN）的代理配置，不需要你逐个热点去设。

使用中的注意点：

- 授权时选择「永久允许」，否则每次开机重建代理都会再弹一次；
- Root 模式下移动数据的流量也会经过它，这是无 Root 模式做不到的；
- 如果手机刷过机或换过 Root 方案，代理可能被还原，重开一次 App 让它重新配置即可。

## 四、停用、卸载前必做的恢复

代理是把双刃剑：Adblock Plus 不在运行，代理却还指着那个端口，结果就是**所有网页都打不开**。所以两类操作前都要先恢复：

| 你要做的事 | 先做什么 |
| --- | --- |
| 暂时不用拦截 | 在 App 里关闭过滤开关；无 Root 设备再把 WiFi 代理改回「无」 |
| 卸载 App | 先把每个配过代理的 WiFi 改回「无」，再卸载；Root 设备先在 App 内停用过滤，让它还原 APN 设置 |

配过代理的 WiFi 忘了是哪几个，就到「设置 > WLAN」里逐个检查当前网络的代理项。恢复操作细节也可以参考 [广告拦不住与断网排查.md](广告拦不住与断网排查.md) 的断网部分。

## 五、拦不到的边界

这套本地代理方案只能看到**未加密的 HTTP 流量**。现在大量网站与广告走 HTTPS 加密连接，这部分内容它既读不了也拦不了——所以配好之后「大部分广告消失、个别广告还在」是正常现象，不是你配错了。过滤规则层面的效果调优见 [过滤规则与可接受广告设置.md](过滤规则与可接受广告设置.md)。
