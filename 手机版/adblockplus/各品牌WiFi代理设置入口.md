# 各品牌安卓手机的 WiFi 代理设置入口

> 经典独立版无 Root 要靠 WiFi 手动代理工作，而各家系统把这个入口藏的位置都不一样。本篇按品牌整理常见路径，并讲配好之后怎么确认生效。

## 一、为什么值得单独列一篇

给 WiFi 配代理这一步，是经典独立版无 Root 用法里唯一需要动系统设置的地方，但安卓各家定制系统的菜单位置、叫法差异很大——同一个动作，原生系统叫「代理」，有的系统藏在「高级设置」里，有的要点网络名旁的小齿轮。下面这张表按品牌整理了常见路径，你对照着找即可。

代理要填的两个值是一样的：主机名 `localhost`，端口填 Adblock Plus 设置里显示的监听端口（默认 `2020`）。原理与整体流程见 [过滤模式与代理设置.md](过滤模式与代理设置.md)。

## 二、各品牌入口对照

| 品牌 / 系统 | 常见路径 |
| --- | --- |
| 原生系统 / Pixel | 设置 > 网络和互联网 > WLAN → 点当前网络旁的齿轮 → 高级选项 → 代理 → 手动 |
| 三星（One UI） | 设置 > 连接 > WLAN → 点当前网络名旁的齿轮 → 高级 → 代理设置 → 手动 |
| 小米 / 红米（MIUI） | 设置 > WLAN → 长按当前网络 → 修改网络 → 高级设置 → 代理 → 手动 |
| 华为 / 荣耀（EMUI / HarmonyOS） | 设置 > WLAN → 长按当前网络 → 修改网络 → 显示高级选项 → 代理 → 手动 |
| OPPO / 一加 / 真我（ColorOS） | 设置 > WLAN → 长按当前网络（或点右侧详情）→ 编辑 → 高级设置 → 代理 → 手动 |
| vivo / iQOO（OriginOS） | 设置 > WLAN → 点当前网络进详情 → 代理 → 手动 |

以上路径按各系统常见写法整理，菜单名称随系统版本会有出入，**最终以你手机里实际显示的为准**。找不到「代理」选项时，分别试试「长按网络名」和「点网络名旁的齿轮」这两条路——绝大多数系统二选一。

## 三、配好之后怎么确认生效

1. 用浏览器随便开一个网页，能正常加载（代理链路通了）。
2. 打开 Adblock Plus 主界面，过滤开关处于开启、状态不再显示等待流量。
3. 在「设置 > WLAN」里重进该网络的详情，确认代理项保存住了（个别系统保存后会把「手动」悄悄退回「无」，需要再存一次）。

如果 Adblock Plus 界面长时间停在「等待流量」（Waiting for traffic on port 2020），说明没有任何流量经过代理：先确认第 3 步的配置还在，再重启一次手机——官方发布页评论区最常见的反馈就是重启后恢复；重启无效的，有用户反馈把该 WiFi 的配置删掉、重新连接后再配代理可以解决。更完整的处理顺序见 [广告拦不住与断网排查.md](广告拦不住与断网排查.md)。

## 四、配不了或配了没用的情况

- **菜单里根本没有手动代理项**：少数精简系统或极老系统没有这个设置项，这类设备无 Root 模式走不通，只能考虑 Root 模式或放弃。
- **公司、校园网络**：部分网络环境会在路由器侧限制或干脆禁用代理行为，表现是配完代理后网页打不开。先改回「无」确认网络本身没问题，再判断是不是环境限制。
- **换热点要重配**：代理按 WiFi 逐个保存，家里配好了，到公司还得再配一次公司那个热点。
