## 一、这份 1.3 是哪一代

Adblock Plus 起家是浏览器扩展（开源项目，由德国公司 eyeo 维护），2012 年 11 月才推出安卓独立 App——也就是你现在装的这一支，包名 `org.adblockplus.android`。它 2013 年 3 月随一批广告拦截应用一起从 Google Play 下架，此后官方以「官网直接发 APK」的方式分发这个系列。1.3 发布于 2015 年 3 月，官方更新重点是兼容当时的 Android 5.0（Lollipop）、降低内存占用并新增 12 种语言翻译；截至 2026-09，官方博客上这支独立 App 的发布记录仍停在 1.3。

注意它的「老」是双重的：发布年代早，而且它的拦截方案（本机代理 + HTTP 过滤）在今天的加密网页环境下效果天然受限。这两点决定了它和现行产品是**两套思路**，不是简单的新旧关系。

## 二、官网现在提供什么

截至 2026-09，`adblockplus.org` 上面向安卓的官方产品是这些（以后会不会变，以官网当时显示为准）：

| 官方现行产品 | 形态 | 拦截范围 |
| --- | --- | --- |
| Adblock Browser | 一款内置拦截的浏览器 | 只在它自己里面 |
| Adblock Plus for Samsung Internet | 三星浏览器的内容拦截扩展 | 只在三星浏览器里 |
| 桌面浏览器扩展 | Chrome / Firefox / Edge / Opera / Safari 扩展 | 对应桌面浏览器 |

经典独立版在官网的下载页与说明页都已下线，这也是为什么搜索引擎的结果里现在几乎找不到它的踪迹。

## 三、按需求怎么选

| 你的目的 | 建议 |
| --- | --- |
| 想拦浏览器以外的东西（无 Root 想覆盖尽量多的流量） | 经典独立版 + 代理配置，接受「HTTPS 拦不到」的边界 |
| 只想让上网的浏览器干净 | 现行官方方案更省事：装了就能用，不需要碰代理设置，对新网页技术的兼容也好得多 |
| 用的是三星手机、只用自带浏览器 | Adblock Plus for Samsung Internet 一装即可 |
| 设备很老、系统很旧 | 经典独立版本来就是为旧系统设计的，现行 Adblock Browser 对老系统反而可能装不上 |

两代产品**可以共存**，包名不同互不干扰；但别指望用现行的浏览器方案替代经典版的系统级代理，反之亦然。

## 四、更新与版本口径

- 经典独立版当年自带更新检查机制（新版发布会自动提示下载），但官网的分发页已下线，这条通道如今形同虚设——把 1.3 当作实际上的最终版本来对待即可。网上如果看到更高的版本号，先核对包名是不是 `org.adblockplus.android`，官方现行安卓产品的包名是另一套。
- 各篇文档涉及版本、大小、包名的口径，一律以安装包本身为准（1.3 / 5.75M / `org.adblockplus.android`），不引用官网最新版信息。
- 想了解现行方案的最新情况，直接看官网 `adblockplus.org`。
