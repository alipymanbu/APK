# TapTap 怎么赠送游戏给好友

> 想把付费安卓游戏送给朋友：从购买到发出兑换码、再到对方成功兑换的完整流程，以及「明明买过却提示要付费」的处理。

## 一、先确认送的是付费游戏

只有**付费游戏**存在「赠送」这回事——免费游戏好友自己点下载就行，不需要你送。赠送的载体是一串**兑换码**，不是直接把安装包发给对方：你付款后拿到兑换码，好友凭码在兑换入口换出游戏。所以送之前先想好送哪款，在 TapTap 里搜到它的详情页。

## 二、赠送步骤

按官方客服帖给出的流程：

1. 打开要赠送的付费游戏详情页，点**右上角的两点（更多）**。
2. 选**「赠送给好友」**，可以给好友附一句话留言。
3. 确认订单并完成支付，支付成功后会生成一串**兑换码**。
4. 到 **侧边栏 → 订单中心** 里把这串兑换码发给好友（微信、QQ 什么方式都行）。
5. 好友在 TapTap 的**兑换中心**输入兑换码，即可领取游戏。

兑换码发出去之后，自己就不要再拿去兑换，避免好友输入时提示已被使用。

## 三、自己买过却提示「需要付费」

先别重复付款，大概率是**登错了 TapTap 账号**。官方客服给的核对办法有两条：

- 点头像 → 侧边栏 → **订单中心**，看有没有这笔订单；
- 点头像 → 个人中心 → **已购买的游戏**，看这款在不在列表里。

换回当时付款的那个账号登录，游戏就会显示「下载」。想用支付凭证反查当时用的是哪个账号，可以用官方客服帖里的订单查询页 [www.taptap.com/payment/order/search](https://www.taptap.com/payment/order/search)，从支付宝/微信的付款记录里找订单号查询。

## 四、买完之后的事

- **换手机、卸载重装**：已购游戏跟着 TapTap 账号走，登录同一账号就能再次下载，不用重新买。
- **想等折扣**：付费游戏常有首发折扣，周年庆、春节等节点折扣力度较大，官方客服帖建议多关注活动期。
- **提示「达到激活上限」**：联系 TapTap 在线客服处理（侧边栏的客服入口）；注意部分游戏厂商自己还另设激活次数限制，那种要找游戏方客服。

游戏装好后下载或安装出问题，见 [安装失败与解析包错误排查.md](安装失败与解析包错误排查.md)；第一次装 TapTap 本体见 [下载与安装教程.md](下载与安装教程.md)。
