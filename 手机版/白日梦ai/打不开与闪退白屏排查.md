## 一、本篇怎么用

白日梦AI 是个强联网应用，界面内容基本靠云端渲染，所以「打不开」的原因通常不在应用本身，而在**安装包、网络、缓存**三处。下面按你看到的现象对号入座，从最省事的手段试起，每一步做完回来试一次，别一上来就卸载重装。

## 二、症状：点开只有白屏

应用商店的公开评论里就有用户反馈「打不开、只有白色」的情况，属于相对常见的现象。按顺序试：

1. **等 10~20 秒**——首次进入要拉取大量云端素材，冷启动慢不等于坏了；
2. **切网络**——Wi-Fi 和移动数据互换一次。公司/校园 Wi-Fi 常拦截这类云端接口，换 4G/5G 往往直接就好；
3. **清缓存**——长按应用图标 → 应用信息 → 存储占用 → 清理缓存（清缓存不丢账号，「清除数据」才会）；
4. **强制停止再开**——应用信息里点「强行停止」，重新打开；
5. **核对安装包**——确认包名是 `com.aibrm.app`、版本 1.2.3（对照 [下载与安装教程.md](下载与安装教程.md) 的表格），来路不明的包建议直接换成网盘里那份重新装；
6. **换环境验证**——用浏览器打开 [aibrm.com](https://aibrm.com/)：网页端能正常打开，说明问题在手机端；网页端也白屏，就是网络或服务端的事，等一等或换网络即可。

## 三、症状：一点就闪退 / 停止运行

安卓通用排查顺序（对任何应用都适用）：

1. 重启手机后再开一次；
2. **检查权限**——设置 → 应用 → 白日梦AI → 应用权限，把存储、相机、麦克风等常用权限打开，部分 ROM 禁掉某项权限会直接导致闪退；
3. **清理后台与存储空间**——可用空间长期低于两成时，系统会优先杀掉这类占内存的应用；
4. **清缓存**（同上，先别清数据）；
5. **系统版本**——把手机系统升到最新，个别旧版 ROM 与新版本应用不兼容；
6. **卸载重装**——重装前确认账号能重新登录（账号在云端，本地无进度就无所谓），重新装的包用 [下载与安装教程.md](下载与安装教程.md) 里核对过的那份。

## 四、症状：注册收不到验证码

有公开教程给出的口径：验证码发送有频率限制——**同一 IP 五分钟内最多 20 条、一天最多 100 条**。触发限制就只能等；没触发限制时通常是网络或服务端卡顿，隔几十秒重试一次即可。换 Wi-Fi 与移动数据各试一次，能解决大部分「收不到」的情况。

## 五、症状：生成卡住 / 扣了积分没出片

1. **先别重复点生成**——每次点击都可能再扣一次积分，价目见 [梦币计费规则与省钱技巧.md](梦币计费规则与省钱技巧.md)；
2. 等待几分钟：长视频渲染本身就要排队，中途杀应用会中断任务；
3. 依旧没动静就清缓存重启，回作品列表看任务是否还在；
4. 确认是否属于 [积分与梦币使用说明.md](积分与梦币使用说明.md) 里说的「积分不足被拦」——有时是动作没扣成、任务根本没提交，而不是提交后失败；
5. 反复出现「扣费无产出」，带订单与任务截图走应用内反馈入口联系官方，别再自行重试。

## 六、症状：下载视频失败 / 相册里找不到

按公开教程整理的处理顺序：

1. **查相册权限**——这是最常见原因：没给白日梦AI 存储/相册权限，点了下载也落不进相册。去系统设置 → 应用 → 白日梦AI → 权限里放开；
2. **换网络重试**——下载走网络，网络不稳会直接失败；
3. 仍失败就按第二节清缓存后重试；
4. 以上都无效时，卸载后重新安装（包用 [下载与安装教程.md](下载与安装教程.md) 里核对过的那份），再试一次；
5. 还不行就带截屏/录屏和作品链接走应用内反馈联系官方。

## 七、什么时候该怀疑是服务端

如果满足下面两条，基本不用在自己手机上折腾了：

- 同一时间**换了几种网络**都白屏/超时；
- **网页端** [aibrm.com](https://aibrm.com/) 也打不开或功能异常。

这种情况等官方恢复即可；期间想继续写作或改稿，可以先把文案准备好，等服务恢复直接进 [文字生成视频教程.md](文字生成视频教程.md) 的流程。
