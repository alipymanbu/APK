## 一、一句话认识 TwiNote

TwiNote 是一款安卓备忘应用，界面长得像你每天刷的社交时间线：你写下的每一条内容都是一条「推文」，有头像、有昵称、有点赞和转发的数字。区别在于——这一切只发生在你的手机里，没有任何人能看到，也没有真正的关注者。开发者是 Chartreux，官方描述里给它的定位是「社交网络风格的备忘录」。

它不是个新面孔：第三方应用目录显示安卓版 2019 年底就上架了应用商店，此后一直在更新；同一开发者后来还出了 iPhone / iPad 版（两个平台互相独立，见[常见问题与使用注意](常见问题与使用注意.md)第七节）。

## 二、它和真实社交网络差在哪

两者共用同一套视觉和操作逻辑：写内容、看时间线、翻别人的主页。差别在「另一端有没有人」：

| | 真实社交平台 | TwiNote |
| --- | --- | --- |
| 内容去向 | 发布到公网，别人能看到 | 只存在你的手机里 |
| 账号 | 实名注册、有真实粉丝 | 你自己捏出来的，粉丝数随手填 |
| 互动数字 | 别人点出来的 | 你自己设定的 |
| 联网需求 | 必须联网 | 不发出去，写完就存本地 |

也就是说，它借的是「发动态」这个你已经非常熟悉的动作，省掉的是「被围观」这件事。写下来的内容默认仅自己可见，也不会自动分享到任何地方。

## 三、三种典型用法

官方描述把用途归成三类，你大概率会用到其中一种：

| 用法 | 你做的事 |
| --- | --- |
| 私人日记 | 记当天发生的事、当时的情绪，像发日常动态一样积累成时间线 |
| 角色对话 | 给几个自建账号各配图标和台词，让他们在你的时间线里互相对话 |
| 灵感速记 | 冒出一个念头就随手写一条存着，之后靠日历或排序翻出来 |

**当日记用**：把一天的事和感受写成一条条动态。喜欢用社交界面记录的人，往往觉得这比打开一本空白笔记页更容易动笔；回看时也像在刷自己过去的动态，配合日历能直接跳到某一天（见[主题与日历等设置说明](主题与日历等设置说明.md)）。

**当剧本和对话草稿用**：这是 TwiNote 最有辨识度的一种玩法。你可以添加任意多个账号，给每个账号起名、配头像、写简介，然后让它们在你的时间线上你一句我一句——写短篇、构思设定、玩角色扮演的人常用这个方式把对话落成一条一眼能跟上头绪的动态串。具体操作步骤在[账号与推文自定义教程](账号与推文自定义教程.md)里逐步拆开讲。

**当灵感本用**：突然冒出的想法、看到的句子、临时要做的事，一条发出去就存好了。短句的形式反而逼你把想法浓缩，之后翻起来也快。

## 四、还自带这些东西

除了上面三种玩法，应用里还有几样实用件：把某条内容导出成图片、按日历回看、给界面换主题、调字号、给笔记排序。这些都在哪里设置、怎么用，见[主题与日历等设置说明](主题与日历等设置说明.md)；导出图片和备份方面有几个已知的坑，见[常见问题与使用注意](常见问题与使用注意.md)。
