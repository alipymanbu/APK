# TwiNote 账号与推文自定义教程

> 本篇讲怎么把 TwiNote 里那个空白账号填成你想要的样子：账号信息、第一条动态、互动数字和多账号对话。

## 一、先接受一张白纸

第一次打开 TwiNote，你会看到一个什么都还没有的界面：没有名字、没有头像、没有关注者，时间线也是空的。这不是没装好——所有东西都等着你亲手填。也正因为它一开始就是空壳，你可以把每一个细节布置成自己想要的形态。

## 二、把账号信息填起来

从你的个人主页进入编辑，逐项填：

1. **昵称**：时间线上每条动态旁边显示的名字。
2. **头像与顶部横幅图**：头像出现在每条动态旁，横幅图铺在主页顶部。
3. **简介**：主页上的一句话自我介绍。
4. **关注者与关注数**：这两个数字随你填，想让主页看起来是什么量级就填什么量级。

填完回到时间线，你的账号就是「活的」了。

## 三、发第一条动态

1. 点界面上的**加号**。
2. 写内容，需要的话配上图片。
3. 发出后它会出现在时间线里。
4. 写错了或想补充，点开那条动态可以**修改**，也可以删掉重来。

这一步和你在任何社交平台发帖的动作几乎一样，区别只有一条：发出之后没有任何人收到通知，它只是安静地躺在你的时间线上。

## 四、给动态配互动数字

每条动态的点赞、转发、引用转发数量都可以单独设定。你可以在发的时候顺手设好，也可以之后回去改。想让某一条看起来「被很多人讨论过」，就把这几个数字调上去；想让它看起来无人问津，留零就行。

这些数字是布置出来的，不是统计出来的——清楚这一点，后面的用法才不会拧巴。

## 五、让几个账号聊起来

这是 TwiNote 区别于普通备忘录的核心玩法，步骤是：

1. 在应用里**添加新的账号**，数量不限。
2. 给每个账号分别配昵称、头像、简介，让它们看起来是不同的人。
3. 用不同账号交替发动态，你一句我一句，一条对话就顺着时间线长出来了。
4. 还可以设定账号之间的关注关系，让某个角色的主页上出现「关注了谁」。

写短剧、构思角色设定、玩虚拟对话的人常用这一招：一条时间线就是一场戏，每个账号就是一个演员。三样东西决定这场戏好不好看——人设（第二节的账号信息）、台词（第三节的动态内容）、气氛（第四节的互动数字）。

## 六、把布置好的场面导出成图片

某一条动态或整个页面布置好了，可以**保存成图片**存在手机相册里。导出入口就在动态或页面的菜单里，存出来的是普通图片文件，可以直接发给别人或当素材用。

导出前有两件事建议先知道：一是图片画质和尺寸有一些已知限制（大图可能发糊）；二是对外分享这类自导内容时，最好让看的人知道这是摆拍的虚构场面——界面太像真的社交平台了。这两点展开都在[常见问题与使用注意](常见问题与使用注意.md)。
