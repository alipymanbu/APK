## 一、支持的格式清单

三类来源，装进仓库后都能扫：

| 类别 | 支持的格式 |
| --- | --- |
| 图片目录 | JPG、JPEG、PNG、BMP、WEBP、HEIC、GIF |
| 压缩文件 | ZIP（CBZ）、7Z（CB7）、RAR（CBR）、TAR（CBT） |
| 电子书 | EPUB、MOBI、AZW3、PDF |

要点：

- **图片目录**指「一整个文件夹装图片」的漫画，按章节分文件夹放即可；
- 压缩包的扩展名和漫画专用扩展名是对应的：`.zip` 与 `.cbz` 一回事，`.rar` 与 `.cbr` 一回事，能读前者就能读后者；
- 不在表里的格式（比如 `.djvu`）不要硬塞，扫不出来先对照这张表。

## 二、压缩包内部结构怎么摆才会被认出

压缩包不是随便打包都能读，程序只认特定位置的图片。**0.3.7 是一条分界线**，两个口径都写给你，按你装的版本对号入座：

**0.3.7 及以后（含本篇对应的 0.4.1.0）**，ZIP/CBZ 支持包内多章节、多目录：

- 单行本压缩包（放在仓库根目录下）：提取 zip 内的章节；
- 章节漫画压缩包：加载 zip 内**所有**章节的图片；
- 包内根目录**同时存在目录和图片**时：优先加载目录，舍弃根目录下的图片。

**0.3.7 之前的旧版本**只认两种位置：

- 压缩包根目录下的图片；
- 与压缩包**同名**的一级目录下的图片（若包内只有一个目录，无论名字是否相同都会读取）；
- 两种情况同时存在时只取根目录的图片，**其他任何目录里的文件都不处理**。

实操建议：打包时要么「图片全放根目录」，要么「一个与压缩包同名的目录装下所有图」，这是两个版本通吃的摆法。扫不出来时先按这节查结构，再查 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 三、7Z（CB7）建议当备选

7Z 的压缩率更高，但**读取速度相对较慢**，可能影响翻页体验。整理漫画时优先压成 ZIP/CBZ，手头只有 7Z 的再用它——这条是官方注意事项里明确写的取舍，不是格式不支持。

## 四、电子书格式的两个注意点

- EPUB、MOBI、AZW3、PDF 走的是排版阅读逻辑，字号、翻页设置在阅读菜单里调，见 [阅读设置与书架管理.md](阅读设置与书架管理.md)；
- PDF 里的大图在个别机型上有过加载不出来的问题，0.3.7 已修复——还在旧版本上的话，升级后再试。

手上的漫画扫不进列表时，仓库与刷新的排查步骤在 [本地仓库添加与封面设置.md](本地仓库添加与封面设置.md)。
