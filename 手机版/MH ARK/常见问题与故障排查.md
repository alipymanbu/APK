## 一、添加了仓库，列表却是空的

按出现频率从高到低查四件事：

1. **文件权限没给**：首次启动拒绝过文件访问，扫描自然是空的。到**系统设置 → 应用 → MH-ARK → 权限**里把文件访问打开，回仓库管理重新刷新；
2. **格式不支持**：对照 [支持的漫画格式与压缩包结构.md](支持的漫画格式与压缩包结构.md) 的清单，不在 JPG/PNG/ZIP/RAR/EPUB 那张表里的扫不出来；
3. **选错了目录**：仓库要指向漫画的**上级目录**（包着各章节文件夹的那层），选到单个文件或层级不对会扫空；
4. **没刷新**：往仓库里新放了文件，要在本地仓库管理界面对该仓库手动刷新才会出现在列表里。

## 二、封面显示不对或一直是默认图

- 章节漫画的封面优先取根目录下 `_cover_` 图片，没有才用第一章第一张；单行本则忽略 `_cover_` 直接用首图——规则详见 [本地仓库添加与封面设置.md](本地仓库添加与封面设置.md) 第三节，先确认图片放的位置符合规则；
- **自定义封面在刷新仓库后被默认封面替换**：这是旧版本的已知问题，0.3.7 的更新日志明确修复了它，还在旧版本上就先升级；
- 换过封面文件名的，检查同一仓库里封面文件名是否统一。

## 三、某本漫画点开加载失败或显示不全

| 现象 | 先查什么 |
| --- | --- |
| 整本打不开 | 格式是否在支持清单里；文件是否下完整（重新解压/重下一次） |
| 压缩包只读出一部分 | 包内目录结构不符合识别规则，按格式篇第二节重打包 |
| 个别机型加载失败 | zip/cbz/epub 读取失败、切换章节崩溃、PDF 大图不显示，0.3.7 更新日志都列过修复项，先升级版本 |
| 翻页卡、大图慢 | 关闭阅读配置里的「32 位颜色解码」，并确认在用较新版本（旧版本扫描大仓库内存占用高，会连带卡顿） |

## 四、安装失败或装上就闪退

- 安装被拦：按弹窗允许「本次安装未知来源」，步骤见 [下载与安装教程.md](下载与安装教程.md) 第四节；
- 空间不足：清理出比安装包 18.71M 更充裕的余量再装；
- 装上闪退：先确认拿的是**包名 `com.mhdh.mh_ark`、版本 0.4.1.0** 的包（各下载站同名安装包很多，版本体系混乱，认准下载与安装篇里那张核对表）。

装上后打不开、闪退、无响应时，按下面的顺序逐条试（这是安卓应用的通用排查顺序，手机厂商支持文档也是这么建议的）：

1. **强行停止再重开**：**设置 → 应用 → MH-ARK → 强行停止**，然后重新打开；
2. **清缓存，先别清数据**：**设置 → 应用 → MH-ARK → 存储 → 清除缓存**。缓存异常是常见诱因；但**不要顺手点「清除数据」**——它会把应用重置，阅读进度、书签、书架等存在应用里的东西可能一并清掉；
3. **重启手机**：后台程序多、内存吃紧时，闪退多半来自内存不足，重启能清掉临时状态；
4. **看系统与存储**：系统版本过旧、剩余存储空间过少都会导致应用异常，各留出余量再试；
5. **卸载重装**：以上都无效就重装（见 [下载与安装教程.md](下载与安装教程.md)）。重装会丢进度和设置，但**漫画文件本身在手机存储里，不受影响**，重装后重新添加仓库即可。

仍闪退就重新获取安装文件：[MH-ARK 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e823d6f2b757)。

## 五、看到「到期」提示是怎么回事

有用户反馈在部分版本里见到过「到期」类提示。MH-ARK 是本地阅读工具，**不是订阅制**：本地漫画的读取不依赖任何授权期限。第三方页面的说法是这类提示多与版本更新提醒或误报有关，更新到新版本后一般就不再出现；若提示来自你添加的某个远程地址，则以该地址自身的说明为准。

## 六、有没有 iOS 版？网上版本怎么分辨？

- **只有安卓版**：多个渠道的常见问题里都写明目前没有 iOS 版本，应用商店里搜同名的都不是它；
- 网上同名安装包版本号各异（0.3.x、0.4.x 都有），下载站页面的介绍文字也常常互相抄、与实际版本对不上。分辨方法只有一条：**核对包名 `com.mhdh.mh_ark` 与版本号**，以 [下载与安装教程.md](下载与安装教程.md) 里的核对表为准。
