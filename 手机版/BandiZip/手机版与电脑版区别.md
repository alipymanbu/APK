## 一、版本与获取渠道：两回事

**电脑版**由韩国 Bandisoft 开发，官方站点 [www.bandisoft.com](https://www.bandisoft.com)（中文页 [cn.bandisoft.com](https://cn.bandisoft.com)）提供 Windows 与 macOS 版下载，截至 2026-09 官方页面显示最新版为 v7.46（以官方页面为准）。版本号是「7.46」这种两段式。

**手机端**（安卓）没有像桌面版那样统一的官方下载入口，应用市场与网盘渠道流通的包版本各异。本文网盘资源里的这份安装包是 **v7.6.0.1**、包名 `com.winzip.android`、31.30M——注意这个版本号是四段式，与桌面版的 7.46 不是同一套编号，别拿「网上最新版」来对应网盘里这份。获取方式见 [下载与安装教程.md](下载与安装教程.md)。

网上对「BandiZip 有没有官方安卓版」的说法并不一致：Bandisoft 官网的帮助与下载页只列 Windows/macOS；部分韩文资料称安卓端无官方 App、iOS 另有独立 App；而国内多个应用市场页面标注了安卓版并署名 Bandisoft。两说并列于此，不影响你用网盘里这份包，但关系到你对渠道的判断，自行取舍。

## 二、功能与交互差异

| 维度 | 电脑版（Windows/macOS） | 手机版 |
| --- | --- | --- |
| 入口 | 文件管理器右键菜单、双击压缩包 | App 内浏览、其他应用「打开方式」分享进入 |
| 解压 | 解压至此 / 智能解压 / 解压到新文件夹 | App 内选目标位置 |
| 创建压缩包 | zip、7z、zipx、tar、tgz、lzh、iso、gz、xz 等 | 以实际界面为准，日常以 zip / 7z 为主 |
| 分卷与加密 | 分卷压缩、AES-256 加密、文件名加密 | 加密以实际界面为准，分卷以打开为主 |
| 专业版功能 | 密码管理器、修复压缩包、密码恢复、包内图片预览、反恶意软件扫描（桌面版付费版功能） | 无对应项 |

## 三、授权方式差异

桌面版走「免费版 + Professional 付费版」双轨：免费版覆盖日常压缩解压，上表里的专业版功能（密码管理器、修复、恢复等）要买 Professional 授权，价格与边界以官方购买页为准。手机端的收费方式与桌面版授权不通用，以你装的版本实际显示为准。这些桌面版专属工具里最常被问到的是密码恢复——密码忘了怎么办的完整分支见 [压缩包密码忘了怎么办.md](压缩包密码忘了怎么办.md)。

## 四、什么时候用哪个

- **在手机上收发压缩包**：微信收到 zip、要把照片打包发人，用手机版当场解决；
- **大文件、批量处理、修复损坏包**：搬到电脑上用桌面版，格式支持更全、出错时的工具更多；
- **两端配合**：手机上解不了的格式传电脑处理，电脑上压好的包传回手机分发。

格式支持的具体差异对照见 [支持哪些压缩格式.md](支持哪些压缩格式.md)；手机端的操作流程见 [怎么解压与压缩文件.md](怎么解压与压缩文件.md)。
