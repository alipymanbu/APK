## 一、先把安装包转存并下载到手机

BandiZip 的安装文件资源放在夸克网盘里，手机上操作最快：

1. 在手机浏览器打开 BandiZip 安装文件资源（夸克网盘）：<https://pan.quark.cn/s/5fb6846378d2>；
2. 登录夸克账号后点「转存」，把文件存到自己网盘（分享链接里的文件不转存直接下载，部分情况会被限制）；
3. 打开手机上的夸克 App，在「我的网盘」里找到刚转存的文件；
4. 勾选后点「下载」。安装包约 31.30M，移动网络下几秒到几十秒即可完成；
5. 下载完成后直接在下载列表里点开 APK，或者去手机的「文件管理 → Download」目录里找。

## 二、安装步骤与未知来源授权

APK 不是从应用商店装的，安卓默认会拦一道，授权一次即可：

1. 点开下载好的 APK，系统弹「为了手机安全，禁止安装未知来源应用」类提示；
2. 点「设置」进入该来源（一般是夸克或你的文件管理器）的安装授权页；
3. 打开「允许安装未知应用」开关，返回重新点 APK；
4. 按提示点「安装」，等进度条走完点「打开」。

不同品牌的入口略有差异，但都是**按来源授权**而不是全局开关：小米在「设置 → 隐私保护 → 特殊权限 → 安装未知应用」，华为在「设置 → 安全 → 更多安全设置 → 安装外部来源应用」，三星在「设置 → 生物识别和安全性 → 安装未知应用」。找不到就直接在弹出的提示里点「设置」，系统会带你到对应页面。

## 三、安装包信息核对

网盘资源里这份 BandiZip 安装包的关键信息如下，装之前可以核对一遍：

| 项目 | 值 |
| --- | --- |
| 版本 | v7.6.0.1 |
| 包名 | com.winzip.android |
| 大小 | 31.30M |
| MD5 | 207076411e4ca024ff755051b00aa34d |

版本与大小在手机的文件管理器里长按 APK →「详情」就能看到。MD5 手机上多数文件管理器不支持直接算，可以等装完后用电脑核对：把 APK 传到电脑，在命令行执行：

```powershell
certutil -hashfile "BandiZip_v7.6.0.1.apk" MD5
```

输出的第二行应与上表 MD5 一致（大小写不敏感）。对不上说明文件在传输中损坏或被改名替换，回网盘重新下载一份即可。

## 四、装好之后先做两件事

1. **给存储权限**：首次打开时系统会请求访问手机文件的权限，选「允许」，否则看不到压缩包也解不了压；
2. **确认能读到你的压缩包**：把一个测试用的 zip 放进下载目录，在 App 里浏览到它并打开。走不通的话看 [解压失败与乱码处理.md](解压失败与乱码处理.md)。

桌面版与手机版的功能和获取渠道差异，见 [手机版与电脑版区别.md](手机版与电脑版区别.md)；装好后的日常操作见 [怎么解压与压缩文件.md](怎么解压与压缩文件.md)。

## 五、点「安装」却提示失败怎么排查

| 提示 | 大概率原因 | 处理 |
| --- | --- | --- |
| 应用未安装 | 手机上已装过同包名但签名不同的旧版本 | 到「设置 → 应用」里找到同名应用卸载后再装 |
| 应用未安装 | 存储空间不足（安装需要约包体积 2~3 倍的临时空间） | 清出至少 1G 再装 |
| 解析包时出现问题 | APK 下载不完整或被改坏 | 核对大小（31.30M）与 MD5（第三节），重下 |
| 反复弹安全风险提示 | 国产 ROM 对商店外安装的常规提醒 | 选「继续安装 / 仍然安装」，来源可靠时安全提示不拦正常安装 |

装完打开就闪退的，先重启一次手机再试；仍闪退多为系统版本或兼容问题，换一台设备交叉验证能快速分清是包的问题还是机器的问题。
