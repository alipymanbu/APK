## 一、排查前先确认三件事

大部分故障都出在这三处，先别急着卸载重装：

1. **网络通不通**：开个浏览器随便开个网页试试，网页都打不开就先修网络；
2. **是不是最新的安装包**：老版本对新环境的兼容问题，重新拿一份安装包覆盖安装就能解决（获取方式见 [下载与安装教程.md](下载与安装教程.md)）；
3. **手机存储还剩多少**：播放缓存和下载文件都要占空间，剩余空间太小会出现各种奇怪的表现。

## 二、搜索没有结果

- **换短关键词**：只输歌名里最核心的两三个字，比完整歌名加歌手更容易命中；
- **换关键词类型**：歌名搜不到就换歌手名试，反过来也一样；
- **检查输入**：错别字、全角半角混用都会导致搜不到；
- **多试几次**：搜索走网络请求，服务端偶尔响应慢，等一会儿再搜一次。

搜索本身是跟着网络走的，换了网络环境（比如从 Wi-Fi 切到流量）后再搜一次，往往就正常了。

## 三、歌曲播放失败或卡顿

| 现象 | 先做什么 |
| --- | --- |
| 点开没声音 | 确认媒体音量没被静音，别只调铃声音量 |
| 转圈不出声 | 切到信号好的网络再播，在线播放对网速有要求 |
| 播放中途卡住 | 退出播放页重新点开这首歌 |
| 这首一直失败，别的歌正常 | 换这首歌的另一个版本搜，原音源可能有问题 |
| 全部歌都失败 | 回第一节确认网络，再重启一次应用 |

下载到本地的歌不依赖网络，在线播放反复失败时，把常听的歌下载下来听是最稳的绕法，步骤见 [下载歌曲与音质选择.md](下载歌曲与音质选择.md)。

## 四、下载失败或文件不对

- **进度不动**：网络断了或太慢，换网重试；
- **半路失败**：删掉不完整的任务重新下；
- **提示空间不足**：清出足够空间再下，无损音质文件大，下之前先看剩余容量；
- **下完放不出来**：文件可能不完整，删掉重下一次；还不行就换普通音质档位，个别歌曲的高档位源本身不稳；
- **提示下载完成，文件管理器里却找不到**：先按 [下载的歌曲存在哪里.md](下载的歌曲存在哪里.md) 第二节的方法按时间排序、搜歌名找一遍，多数是存进了应用自己的目录而不是你以为的位置。

## 五、装完打不开或闪退

1. **重启手机**再开一次，这一步能解决一大半"点了没反应"；
2. 检查安装包是否完整：MD5 对不上说明下载不完整，重新下载安装（核对信息见 [下载与安装教程.md](下载与安装教程.md) 第四节）；
3. 清一下应用缓存再试；
4. 还不行就卸载后重装一遍，重装不会影响你之前下载到手机存储里的歌曲文件。

按上面的顺序排完仍无解的，多半是当时的服务端或网络环境问题，隔天再试往往自己就好了。
