## 一、传输是端到端加密的

官方对安全的核心表述只有一条但分量足够：**屏幕共享、聊天、文件传输的全部流量都做端到端加密**——连接双方之外（包括厂商自己）看不到会话内容，远程会话的内容也不会被存储。你在会话里敲的密码、传的文件，走的都是这条加密通道。

作为对照，很多同类产品只做传输加密而不做端到端，服务端理论上能看到画面。这一点是 HopToDesk 官方反复强调的差异位，也是把隐私敏感的远程场景交给它的前提。

## 二、开箱即用的网络友好性

官方 FAQ 明确：**不需要改路由器、不需要防火墙开端口**，两端能上网就能建立连接。这是它和 Windows 远程桌面、VNC 这类需要端口转发的工具在使用门槛上的实质区别——少一套网络配置，就少一类配错导致的安全暴露面。

## 三、可开启的保护项

| 保护项 | 作用 | 建议 |
| --- | --- | --- |
| 两步验证（2FA） | 给账号再加一道动态码，密码泄露也进不来 | 用了官方仪表板账号就开 |
| IP 白名单 | 只接受指定来源 IP 的连接 | 固定办公网络访问家里设备的场景很合适 |
| 直接 IP 连接 | 不经中间服务器、点对点直连 | 内网环境可优先走这条 |
| SOCKS5 代理 | 让连接走你指定的代理通道 | 有统一出口审计的网络环境用 |

这些选项都在客户端的设置里，属于「开了更稳」的层级，不设也能正常用。

## 四、开源与开发主体

- **开源**：HopToDesk 源代码公开（仓库在 [github.com/hoptodesk/hoptodesk](https://github.com/hoptodesk/hoptodesk)，AGPLv3 许可），个人与商用都免费。代码可审计意味着安全声明可验证。
- **开发主体**：Play 商店页面标注的开发者为 Begonia Holdings LLC（美国），支持邮箱 `contact@hoptodesk.com`，官方帮助中心在 [help.hoptodesk.com](https://help.hoptodesk.com/)。
- **数据声明**：官方 Play 商店的数据安全栏目声明不与第三方共享数据、不收集数据——这类声明以厂商自述为准，介意的话结合上一条的开源属性自行判断。
- **企业侧合规工具**：SOC 2、HIPAA、GDPR 等的合规就绪自评、条件访问策略与完整审计日志，属付费仪表板的企业档功能；个人使用用不上，选型时知道有这一层即可。

对「信令与中转由谁运营」有更高要求的话，把整条链路搬进自己的服务器是终极答案，做法见 [自建服务器怎么弄](自建服务器怎么弄.md)。

## 五、自己能做的几个加固动作

1. **永久密码设强一点**：无人值守场景下这道密码就是门锁，见 [无人值守访问设置](无人值守访问设置.md)。
2. **临时凭据不留存**：一次性帮人之后，别把对方的 ID / 密码留在最近连接列表里。
3. **无障碍权限用完可关**：安卓端的「允许远程控制本机」依赖无障碍服务；如果你平时只用手机控电脑，把这个权限关掉，需要被控时再开（权限说明见 [下载与安装教程](下载与安装教程.md)）。
4. **会话结束即断开**：远程操作完主动断开会话，别让连接挂着。
