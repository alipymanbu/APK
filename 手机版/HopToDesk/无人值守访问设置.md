# HopToDesk 无人值守访问设置

> 这篇讲怎么让一台电脑或手机在**没人守着**的情况下也能被远程连上：永久密码、后台常驻、开机自动可连，以及隐私模式、关机唤醒这两个配套动作。

## 一、为什么会「连不上」

默认情况下，别人连你的设备需要在屏幕上点一次「允许」——人在旁边时这很好用，但想在公司连家里的电脑、或远程帮父母修手机时，那头根本没人点。无人值守访问解决的就是这个问题：给设备设一个**固定密码**，对方凭 ID + 密码直接进来，不再等人批准。

## 二、电脑端（Windows）

Windows 分两种运行形态，无人值守能力不一样：

| 形态 | 怎么进入 | 能做到什么 |
| --- | --- | --- |
| 便携模式 | 下载的 `.exe` 直接双击运行 | 设好永久密码、保持窗口开着，就能被连；窗口一关，连接能力随之停止 |
| 安装模式 | 主窗口**左下角点 Install**（可能弹 UAC 确认） | 装上后台服务，开机自启；重启后、没人登录时（锁屏 / 登录界面）也能被连 |

官方的建议很直接：**要长期远程访问的电脑，就装成服务**。另外一些高权限动作（对 UAC 弹窗、Ctrl+Alt+Del 安全桌面、管理员权限程序的操控）在便携模式下要么不可用、要么要经会话菜单里的 Request Elevation 提权——追求完整能力就装成服务。

macOS 和 Linux 没有便携 / 安装之分，装好即是常驻应用（macOS 带 LaunchAgent，Linux 注册 systemd 服务）。

## 三、电脑端设永久密码

在 HopToDesk 主窗口的安全 / 密码设置里设置固定密码（与左上角随机显示的临时密码是两回事）。设好之后：

- 对方用你的设备 ID + 这个固定密码连接，不再需要人工允许；
- 密码不要用临时密码那种短随机串，设成自己记得住、别人猜不到的；
- 换密码时记得同步更新自己手机里保存的连接信息（保存方法见 [手机控制电脑指南](手机控制电脑指南.md)）。

## 四、手机端（安卓）被控的前提

安卓机想当「被控端」，两个硬前提（详见 [下载与安装教程](下载与安装教程.md)）：

1. **装的包要有被控能力**：官网渠道的 `.apk` 支持，Google Play 商店版只有客户端功能，装错了连不上；
2. **开了无障碍服务**：否则对方只能看画面、动不了。

## 五、多台设备的统一管理（可选）

如果你手上有三五台以上的设备要长期维护，官方提供仪表板（Dashboard，`dashboard.hoptodesk.com`）做集中管理：设备列表、状态监控、会话记录、团队协作都在上面。起步有免费档（前几台设备），更多设备与团队功能才涉及付费，具体额度以官方页面为准。

安卓设备还能作为**看板 / 售货机式设备**接入仪表板：在 App 的 Settings 里点 Add to Dashboard，粘贴邀请码即可——之后设备重启也保持在线，并向仪表板上报 CPU、内存、磁盘、电量状态，适合连锁店的播放屏、测试机农场这类无人盯守的部署。

## 六、远程时不想被旁边人看到：隐私模式

无人值守的进阶需求：你深夜远程操作公司电脑，操作内容会同步显示在那台电脑的屏幕上，谁路过谁看见。HopToDesk 的**隐私模式（Privacy Mode）**解决这个——连接后把被控电脑的本地屏幕黑掉，你的操作只在远程端可见。

平台限制要记一条：官方帮助中心写明，Windows 上的隐私模式靠驱动级黑屏实现，**需要在安装模式（装了后台服务）下才可用**，便携模式没有这一项。隐私敏感操作（网银、密码管理器）之前先确认电脑端是安装模式（切换方法见第二节）。

## 七、设备关机了：先唤醒再连

经常远程的那台电脑被家里人或同事关了，会话自然建不起来。官方仪表板里给这类离线设备提供了 **Wake（唤醒）**按钮：向它发送 Wake-on-LAN 魔术包，把设备从关机状态唤醒。两个前提：

1. **同一局域网里还有另一台在线设备**当「敲门人」（魔术包从它发出去，官方说明唤醒包经由同一本地网络里的在线设备代发）；
2. 被唤醒设备的主板 / 网卡支持并开启了网络唤醒（这是平台层面的通用要求，通常在 BIOS 里开）。

家里有一台常开的 NAS / 树莓派 + 一台常关机的台式机，是最典型的组合。唤醒之后走正常的连接流程即可。

想把这些设备的中转都换到自己手里，见 [自建服务器怎么弄](自建服务器怎么弄.md)；无人值守的安全面（密码、加密、权限）见 [安全与隐私说明](安全与隐私说明.md)。
