## 先确认一个前提

HopToDesk 的设计是**不需要**端口转发和防火墙配置的（官方 FAQ 明确说明），所以「连不上」先别急着改路由器——按下面的症状对号入座，问题几乎都出在两端的软件状态上。

## 症状排查表

| 症状 | 最可能的原因 | 先查这个 |
| --- | --- | --- |
| 输 ID 连不上 | ID 抄错或抄了别的设备的 | 被控端主窗口左上角重新核对设备 ID，逐位对 |
| 提示密码错误 | 输的是另一台的密码，或密码已换 | 临时密码以被控端窗口当前显示为准；设过永久密码的以永久密码为准（见 [无人值守访问设置](无人值守访问设置.md)） |
| 电脑那头没人，永远等「允许」 | 没配无人值守 | 电脑端设永久密码并装成后台服务，见 [无人值守访问设置](无人值守访问设置.md) |
| 重启电脑后连不上 | 便携模式没装服务，关了窗口就断了 | 在电脑上点主窗口左下角 Install 装成服务 |
| 连上手机但只能看、点不动 | 安卓端没开无障碍服务 | 系统设置 → 无障碍 → 给 HopToDesk 开启 |
| 手机端收不到别人的连接 | 装的是 Google Play 版（仅客户端） | 换官网 `.apk` 渠道的包，渠道差别见 [下载与安装教程](下载与安装教程.md) |
| 手机上收不到连接请求弹窗 | App 被系统杀后台 | 给 HopToDesk 关掉电池优化 / 允许后台运行，再试 |
| 设备列表里显示离线，根本点不动 | 设备被关机 / 断网了 | 同局域网有另一台在线设备时，可用仪表板的 Wake 按钮发网络唤醒，见 [无人值守访问设置](无人值守访问设置.md) |
| 画面卡顿、延迟高 | 网络带宽被占用 | 关掉两端的大流量应用；仍然差就切换网络再测 |
| 文件传输入口不见了 | 你在用浏览器网页会话 | 文件传输依赖装好的客户端，改用 App 发起会话（见 [屏幕共享与文件传输](屏幕共享与文件传输.md)） |

## 逐项展开的几个高频坑

### 1. 临时密码和永久密码分不清

被控端窗口里 ID 下方显示的是**临时密码**，验证方便但适合有人在场的场景；要做无人值守，必须单独设置**永久密码**，两者是并行的两条验证路。连不上先想清楚自己该用哪条。

### 2. Windows 高权限窗口操作不了

会话里遇到 UAC 弹窗、任务管理器、锁屏界面点不动，不是连接坏了——这些高权限界面在便携模式下受限。处理方式：电脑端装成服务（Install 按钮），或在会话的 Actions 菜单里用 Request Elevation 申请提权（见 [无人值守访问设置](无人值守访问设置.md)）。

### 3. 特殊网络环境的备选路

绝大多数家庭与办公网络开箱即用；如果身处限制严格的网络（部分企业网、校园网），客户端设置里还有两条正规备选：**直接 IP 连接**与 **SOCKS5 代理**，按自己网络的管理要求配置（选项说明见 [安全与隐私说明](安全与隐私说明.md)）。

### 4. 都试过了还是不行

- 两端都升级到较新版本再试（官方更新说明里提及过网络层的改进；有用户反馈过某版本的鼠标侧键问题，官方回应已在修复——保持客户端新版本能少踩这类坑）；
- 换一条网络路径验证（手机开热点连另一端），用来区分「软件问题」还是「网络问题」；
- 仍无解时，官方支持邮箱 `contact@hoptodesk.com` 与帮助中心 [help.hoptodesk.com](https://help.hoptodesk.com/) 是正规求助渠道。

另有一个排查方向容易被忽略：如果你们两端都改过网络指向（自建了信令服务器），连接异常要先确认**两端用的是同一套网络配置**，回滚到默认网络再试一次最快定位（自建相关见 [自建服务器怎么弄](自建服务器怎么弄.md)）。
