## 一、两端各准备什么

远程桌面是两端的事，开工前确认：

- **被控的电脑**：装好 HopToDesk 桌面客户端（Windows / macOS / Linux 都有，官网 [www.hoptodesk.com](https://www.hoptodesk.com/) 下载），打开后主窗口左上角会显示一串**设备 ID**，ID 下方是**密码**。这两个值就是你要填、要输的东西。
- **主控的手机**：装好安卓版 HopToDesk（安装与权限见 [下载与安装教程](下载与安装教程.md)），不需要注册账号。

官方的设计是点对点直连，不需要在路由器或防火墙上开端口转发——两端都能正常上网，连接这件事就不需要额外的网络配置。

## 二、连接五步

1. 在手机上打开 HopToDesk。
2. 把电脑上看到的**设备 ID** 填进连接输入框（对应桌面端的「Control Remote Desktop」位置）。
3. 点连接，等两端建立会话。
4. 验证身份，两条路二选一：被控电脑前有人，让对方点**允许**；没人，直接输入那台电脑的**密码**。
5. 验证通过，手机上出现电脑的实时画面，开始控制。

第一次连陌生电脑建议走「对方手动允许」，确认双方都是自己人之后，再用密码直连省事。

## 三、连上之后怎么操作

- **看与操作**：手机屏幕上就是电脑桌面，直接点按拖动；窗口顶部有缩放选项，细节看不清就放大。
- **打字**：会话里可以直接把手机输入法的文字敲进电脑。
- **传文件**：连接窗口里带文件传输入口，手机和电脑之间对拷文件不用另开渠道（细节见 [屏幕共享与文件传输](屏幕共享与文件传输.md)）。
- **聊天**：会话内可以发即时消息，适合一边操作一边沟通。

## 四、常用电脑建议固定下来

如果你每天都要连同一台电脑，别每次都手输 ID：

- 把常用的设备 ID 和密码**保存下来**，并给每台起个好认的昵称（比如「公司台式机」「家里 NAS」），下次从列表里点一下就连。
- 如果那台电脑经常没人值守，光有密码不够——它得保持可连接状态，这要在电脑端做无人值守配置，见 [无人值守访问设置](无人值守访问设置.md)。

## 五、手头没法装软件时：浏览器里也能连

如果你用的是别人的电脑、公司管控装不了软件的机器，或者一台 Chrome OS 设备，还有一条替代路：官方的 Web Connect。在仪表板（`dashboard.hoptodesk.com`）的设备列表或 Quick Connect 里选 **Web** 方式，连接会经 `web.hoptodesk.com` 直接在浏览器里打开，不需要安装任何东西，手机浏览器同样能用。

代价是功能缩水：网页会话里**没有文件传输入口**（这项依赖装好的桌面客户端，见 [屏幕共享与文件传输](屏幕共享与文件传输.md)），操作手感也不如客户端。应急够用，长期用还是装个客户端。

## 六、反方向也成立

这套流程倒过来就是「电脑控制手机」或「手机控制另一台手机」：被控端换成装了 HopToDesk 的安卓机，其余步骤一样。只是安卓端**被控**有两个额外前提——装的是带被控能力的安装包、开了无障碍服务，否则连得上也点不动，具体见 [下载与安装教程](下载与安装教程.md) 第三节。
