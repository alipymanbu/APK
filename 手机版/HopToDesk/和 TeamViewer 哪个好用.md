## 一、先看费用模型：免费到哪一层

这几家的关键差异不在「有没有免费版」，而在**免费的边界画在哪里**：

| 工具 | 客户端费用 | 付费的起点 |
| --- | --- | --- |
| HopToDesk | 个人与商用都免费，连接不要求账号 | 只有要用仪表板管理大量设备才付费（有免费档，付费方案自每月 15 美元档起） |
| TeamViewer | 仅个人免费，付费方案自每月约 24.9 美元起 | 商用即需要授权 |
| AnyDesk | 仅个人免费，付费方案自每月约 28.9 美元起 | 商用即需要授权 |
| Splashtop | 以订阅为主，入门方案自每年约 72 美元起 | 基本是订阅制 |

（对手定价取自 HopToDesk 官方对比页，页面标注于 2026 年 8 月核实；各厂商随时可能调整包装，决定前以对方官网现价为准。）

TeamViewer 免费版还有一个第三方文章反复描述的现象：其商业使用检测可能把个人用户的会话判为商用并限制时长，解封需人工申诉。官方自己的口径则始终是「个人使用免费」。两条口径并列放在这里，判断交给你。

## 二、功能清单对照

以官方对比页列出的条目为准（HopToDesk 一侧全部为自有功能）：

| 能力 | HopToDesk | 说明 |
| --- | --- | --- |
| 免账号连接 | 有 | 填设备 ID 即连，TeamViewer 需要账号 |
| 浏览器里发起连接 | 有（免费） | TeamViewer 的浏览器访问在付费方案里 |
| 屏幕共享 / 文件传输 / 聊天 / 声音 | 全有 | 基本盘一致 |
| 端到端加密 | 有 | TeamViewer 用 RSA 2048 + AES 256（传输加密），AnyDesk 用 TLS 1.2 + AES 256；口径不同，见 [安全与隐私说明](安全与隐私说明.md) |
| 无人值守 / 会话录制 / 隐私模式 / 远程打印 / WOL 唤醒 / 剪贴板同步 | 全有 | 这些常被以为要付费的功能，这里都在免费客户端里 |
| 自托管 / 私有部署 | 有 | 见 [自建服务器怎么弄](自建服务器怎么弄.md) |
| 多语言 | 约 44 种 | TeamViewer 约 30、AnyDesk 约 28 |

## 三、第三方怎么定位它

- 2026 年 5 月的一篇横评（Tech2Geek）把它归为「轻量、开源、隐私优先」的一档，与 RustDesk 同列开源阵营，适合不想碰订阅制的用户。
- GetApp 目录页当前评分 4.5 / 5（基于 11 条评论），「性价比」维度分最高。
- 有用户反馈**速度不如 AnyDesk**，另有用户提到某版本鼠标侧键（前进 / 后退）失灵、官方在评论区回应修复中——单一来源的说法，听个方向即可：对流畅度敏感就先在自己两台设备上实测（客户端是便携式的，试用不留痕）。

## 四、怎么判断该选哪个

三句话版：

1. **个人 / 家庭 / 小团队，预算敏感**：HopToDesk 的免费无时限 + 商用免费，是它和 TeamViewer / AnyDesk 最实质的差别。
2. **要给客户看自己的品牌、开工单、管大舰队**：这几家都能做，HopToDesk 靠仪表板付费层实现，起步门槛低一些；成熟 IT 团队已有 TeamViewer 生态的话，迁移成本才是主要考量。
3. **对隐私口径要求高**：端到端加密 + 开源可审计这条组合，是它区别于 TeamViewer / AnyDesk 传输加密方案的地方。
