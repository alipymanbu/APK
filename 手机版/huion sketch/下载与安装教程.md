Huion Sketch 是绘王（Huion）面向安卓手机出的免费绘画应用，画速写、线稿、水彩小图、概念草图都行，也可以配合绘王数位板使用。本篇只解决三件事：安装包从哪来、怎么装、装完第一屏长什么样。

## 一、这份安装包的基本信息

| 项目 | 值 |
| --- | --- |
| 版本 | 4.0.4 |
| 包名 | `com.huion.inkpaint` |
| 安装包大小 | 44.39M |
| MD5 | `473e90adaae6affef578169a6e1a1915` |
| 适用设备 | 安卓手机 |

两点说明：

- 版本、大小、MD5 是这份网盘安装包的实测信息（2026-09 采集）。官方 [Google Play 页面](https://play.google.com/store/apps/details?id=com.huion.inkpaint) 上的版本会随官方更新，可能比这份新，装哪份由你自己定。
- 下载完可以先核对 MD5，对得上说明文件没坏。手机上用带校验功能的文件管理器就能查看。

## 二、从夸克网盘获取安装包

1. 打开 [Huion Sketch 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f19a7dc0970b)；
2. 把里面的安装包**转存到自己的网盘**再下载，比直接从分享页下载更稳；
3. 打开手机上的夸克网盘 App，找到刚转存的文件，点下载；
4. 下载完成后在通知栏或「传输列表」里点开这个 APK 文件，进入安装。

## 三、安装步骤

1. 点开 APK 后，系统会问是否允许安装；
2. 如果提示「禁止安装未知来源应用」，去系统设置里给**夸克网盘 App**（或你用来打开 APK 的应用）开「允许安装未知应用」权限。不同品牌手机入口略有差异，一般在 设置 → 应用管理 → 对应 App → 安装未知应用；
3. 回到安装界面点「安装」，等进度走完；
4. 装完点「打开」，或从桌面图标进入。

安装前留够手机剩余空间：安装包 44.39M，装完占用会更大，之后的画作文件也会额外占空间。

## 四、第一次打开会看到什么

应用里有两个入口图标，对应两种用法：

- **调色板图标**：完整绘画模式，笔刷、图层、滤镜都在这边，认真画画从这里进；
- **笔记本图标**：极简速记模式，顶部只留几支常用笔和取色，随手记灵感用。

第一次进去建议顺手把存储权限给上，否则保存作品、导出到相册都可能失败。界面里各工具的位置和用法见 [绘画界面与基础操作.md](绘画界面与基础操作.md)；打算接绘王数位板画的，先看 [连接绘王数位板与快捷键.md](连接绘王数位板与快捷键.md)。

## 五、装不上或打不开的排查点

- **提示解析包出错**：多半是下载不完整，重新下载并核对 MD5；
- **空间不足**：清出足够空间再装；
- **系统版本过旧**：应用对安卓版本有要求，装不上时以官方 [Google Play 页面](https://play.google.com/store/apps/details?id=com.huion.inkpaint) 标注的系统要求为准；
- **能装但闪退**：先补上存储权限再试；仍然闪退就按 [闪退卡顿与连接无反应排查.md](闪退卡顿与连接无反应排查.md) 第二节的顺序处理。

画好的作品怎么导出、怎么转到电脑上继续改，见 [导出格式与电脑端继续创作.md](导出格式与电脑端继续创作.md)。
