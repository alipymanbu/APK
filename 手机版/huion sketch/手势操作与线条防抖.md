手机屏幕小，效率全靠手势和快捷操作。本篇把手势整理成一张表，再讲防抖怎么帮稳线条——这两样熟练之后，单手也能画出干净的图。

## 一、多点触控手势对照表

| 手势 | 作用 |
| --- | --- |
| 双指轻点 | 撤销上一笔 |
| 双指捏合 / 张开 | 缩放画布 |
| 双指旋转 | 旋转画布角度 |
| 三指轻点 | 重做（另有官方资料写作「恢复画布」，实际行为以你的版本为准） |
| 长按屏幕 | 唤出吸管取色 |
| 绘制中另一根手指轻点 | 画出正圆、正方形或特定角度的直线 |

最后一条最容易被忽略：勾轮廓想画个标准圆时，先用笔画个大概，同时另一根手指点一下屏幕，应用会把线条规整成正圆——正方形和指定角度的直线同理。

「恢复画布」与「重做」的差异提示：如果你三指轻点后画布视图被复位而不是重做，那就是你装的版本走的是前一种逻辑，按实际体验记就行。

## 二、防抖（Stabilizer）

防抖的作用是**实时平滑你落笔的抖动**，下笔歪歪扭扭的锯齿会被抹顺。两个场景必开：

- **勾线稿**：手机屏幕小、手指粗，不防抖的线没法看；
- **画长弧线**：一笔到位的弧线，防抖能压掉中途的手抖。

防抖程度越高线条越顺，但笔头跟随感会变钝，写字、速写时可以调低或关掉，正式勾线再开。要是勾线时明显感觉笔跟不上手，先把防抖降一两档——这也是官方对线条延迟的第一条建议，更多延迟原因见 [闪退卡顿与连接无反应排查.md](闪退卡顿与连接无反应排查.md) 第三节。

## 三、撤销与重做

三条路，按顺手程度选：

1. **双指轻点**撤销、**三指轻点**重做（见上面手势表）；
2. 画布**右下角的箭头按钮**，单手操作时最方便；
3. 接了绘王数位板的话，数位板上的按键可以直接映射成撤销/重做，不用碰屏幕，见 [连接绘王数位板与快捷键.md](连接绘王数位板与快捷键.md)。

养成重要节点前复制一层做备份的习惯，比事后狂按撤销可靠（图层操作见 [图层与混合模式.md](图层与混合模式.md)）。

## 四、笔画统计

你画的每一笔都会被记录并计数，作品完成后能看到这幅画总共画了多少笔。对练习者来说这是个直观的量尺——同样一张图，笔数从 500 降到 300，说明概括能力在涨。
