# Huion Sketch 闪退卡顿与连接无反应排查

> 本篇按官方客服给的顺序排查 Huion Sketch 的闪退、卡顿，以及作画时线条延迟、数位板连接不上这几类问题。

用的时候无非四类毛病：打不开或闪退、画着画着卡、笔迹跟不上手、数位板没反应。本篇按「先分清症状 → 走对应顺序」来写，别一上来就重装——重装会连画廊里的作品一起清掉，放最后一步。

## 一、先分清症状再去哪一节

| 症状 | 看哪节 |
| --- | --- |
| 打不开、闪退、整个应用卡死 | 第二节 |
| 能画，但线条延迟、跟不上手 | 第三节 |
| 数位板接上没反应、笔没压感 | 第四节 |
| 上面都试过没解决 | 第五节 |

## 二、闪退、打不开、卡死：官方给的排查顺序

官方客服在支持社区里给过针对这个应用的标准排查顺序，照着走：

1. **把应用升到最新版**——不少闪退是旧版本的已知问题，新版本里已修；
2. 手机 设置 → 应用 → Huion Sketch → 存储，点**清除缓存**；
3. **重启手机**再打开应用；
4. 前三步都无效才**重装应用**。

重装前必须先做一件事：把画廊里的作品**导出到设备相册**（导出步骤见 [导出格式与电脑端继续创作.md](导出格式与电脑端继续创作.md)）。卸载会连应用内画廊一起清掉，相册里导出过的那份才留得住。

另外两个常见外因顺手排除掉：手机存储所剩无几时应用容易卡死，清出空间再试；后台同时挂太多重应用也会挤掉可用内存。

## 三、画的时候线条跟不上手

笔迹延迟多半不是手机坏了，是设置压出来的：

- **防抖/平滑开太高**：平滑等级越高、笔跟手越钝，官方给的建议就是**把平滑调低**来换响应速度。勾细线时高防抖，铺大色块时调低，见 [手势操作与线条防抖.md](手势操作与线条防抖.md)；
- **笔尖磨秃**：压感笔笔尖磨损会出线延迟和打滑，换一颗新笔尖是几块钱成本的事；
- **数位板走无线时**：改用有线连接再试，无线的稳定性天然差一截（连接方式见 [连接绘王数位板与快捷键.md](连接绘王数位板与快捷键.md)）。

画布越大、图层越多也越吃性能，卡顿集中在大文件上时，把不用的图层合并掉。

## 四、数位板连接不上、笔没反应

这类问题的根源在连接层而不是应用本身：OTG 线不支持数据传输、型号不在手机连接支持列表、首次授权被拒，都是常见原因。完整的排查清单写在 [连接绘王数位板与快捷键.md](连接绘王数位板与快捷键.md) 的「连接后没反应的排查点」一节，照着过一遍。

## 五、都试过还不行：找官方

以上顺序走完仍没解决，直接到官方支持站 [support.huion.com](https://support.huion.com/) 提交工单。发之前准备好这几样，能少一轮来回：

- 应用版本号（应用内关于/设置页能看到）；
- 手机型号与安卓系统版本；
- 问题的具体表现，能附一段录屏最好。
