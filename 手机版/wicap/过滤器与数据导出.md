## 一、为什么先设过滤器

手机待机时后台也在不断收发数据——推送、同步、心跳包全都会进捕获列表。不过滤直接开抓，几分钟内列表就会被无关流量填满，你要找的那几条反而翻不到。所以第三方教程普遍建议：**开抓之前先把过滤器设好**，把捕获范围压到你要观察的那部分。

Wicap 提供过滤策略，第三方介绍里的口径是可按 IP、端口、协议类型或关键词来定制过滤规则。第一次用先用默认过滤器跑通流程（见[抓包使用教程.md](抓包使用教程.md)），有明确目标后再收紧。

## 二、过滤设置的思路对照

| 你的目标 | 建议的过滤思路 |
| --- | --- |
| 看某次网页访问的请求 | 过滤 HTTP/80 端口相关流量，捕获期间只开浏览器 |
| 确认某应用是否在请求某域名 | 不过滤，抓完后在结果里按域名关键词搜 |
| 只看 DNS 查询 | 按协议过滤出 DNS，看设备把哪些域名解析到了哪些地址 |
| 排查某 IP 的连接行为 | 按 IP 过滤，只留与该地址往来的包 |

一个实用的顺序是「**抓前过滤 + 抓后筛选**」配合：抓前用宽一点的过滤条件避免漏掉目标，抓完再用关键词在结果里缩小范围。两种手段都试过还是找不到目标流量，按[常见问题与报错处理.md](常见问题与报错处理.md)的「抓不到数据」一节排查。

## 三、捕获数据存在哪

多个第三方教程提到：停止捕获后，数据会自动保存到设备存储（老教程的说法是 SD 卡）。具体保存目录随版本与系统而变，你可以在应用内找导出/分享入口确认实际路径。捕获文件一般能直接在文件管理器里看到，建议抓完就给文件改个带日期的名字，避免多轮捕获互相覆盖。

## 四、导出到电脑继续分析

第三方介绍提到 Wicap 支持把捕获内容导出为 pcap 兼容格式，可用 Wireshark 等电脑端工具打开做二次分析。流程大致是：

1. 在 Wicap 里停止捕获，用导出/分享入口把文件存到存储（或直接用系统分享发给电脑）。
2. 把文件传到电脑（数据线、局域网传输都行）。
3. 用 Wireshark 打开该 `.pcap` 文件，即可用它的过滤器、统计与解码功能深挖。

以上能力以你手上这份 2.8.0 的实际表现为准——如果你导出的文件 Wireshark 打不开，退一步用 Wicap 内的复制/分享功能把关键包内容拿出来分析。

## 五、手机抓和电脑抓怎么分工

| 场景 | 更顺手的做法 |
| --- | --- |
| 快速确认「刚才那个操作发了什么请求」 | 手机上 Wicap 直接看，当场出结果 |
| 需要统计、图表、协议深解码 | 手机抓完导出 pcap，交给电脑端 Wireshark |
| 长时间监控网络 | 电脑端工具更合适，手机别长时间挂着捕获 |
| 没带电脑、现场排查 | Wicap 的主场，抓完立刻看 |

两边的定位是接力而不是替代：手机端负责「在现场、马上抓」，电脑端负责「抓回去、慢慢抠」。安装环节还没走通的话，先回[下载与安装教程.md](下载与安装教程.md)；工具定位与版本口径见[是什么与适用场景.md](是什么与适用场景.md)。
