## 一、安装环节

**提示「解析包错误」/ 安装到一半失败**

1. 核对安装包完整性：这份包大小 3.78M、MD5 为 `C64F411273960DF38FCB21DF457DADA7`，用校验工具对一下，对不上就重新下载（下载入口见[下载与安装教程.md](下载与安装教程.md)）。
2. 检查手机剩余存储空间，不足时清理后再试。
3. 之前装过 Wicap 其他版本或 Demo 版的，先卸载旧的再装。

**装好后图标点不开 / 直接闪退**

多半是 root 环境问题，往下看第二节；确认设备确实已 root 再排查，没 root 的设备无法使用这个工具。

## 二、root 与 Magisk 相关

**超级用户授权弹窗不出现**

重启一次 Wicap 让它重新发起请求；仍不弹的话，到 Magisk/你的 root 管理器里确认 Wicap 没有被设成「拒绝」，可以手动删掉授权记录让它重新申请。

**Magisk Superuser 下点了开始没反应、或应用直接退出**

官方应用介绍里写明了这种情况的处理：**临时把 SELinux 切到 Permissive 模式**。具体做法（需要有终端或 adb 的环境）：

```bash
setenforce 0
```

执行后再打开 Wicap 试一次。这只是排查用的临时措施，**测完建议改回强制模式**：

```bash
setenforce 1
```

官方功能清单里带「内置 root 终端」——你的版本若提供这个入口，`setenforce` 命令可以直接在应用内执行，不必另装终端应用；没有该入口就用 Magisk 自带终端或 adb shell。

部分第三方教程还提到 root 方案本身要正常运行（授权服务可用），抓包工具依赖它才能拿到系统级捕获权限。

## 三、抓包环节

**能开始，但列表里没有数据 / 数据很少**

1. 检查过滤器是不是设得太严——把条件放宽或先用默认过滤器重抓一次，过滤器用法见[过滤器与数据导出.md](过滤器与数据导出.md)。
2. 确认捕获期间目标应用真的发生了网络动作：捕获暂停时去操作目标应用，别让两边同时闲着。
3. 确认是按**后台键**切出去的，不是返回键——按返回键会把捕获直接退出，这是多个教程都强调的坑。
4. 检查 Wicap 有没有被系统省电策略杀后台：把它加入电池优化白名单或锁定后台再抓。

**抓到了连接，但 HTTPS 内容是一堆乱码/密文**

正常现象。HTTPS 是加密通信，你只能看到连接对象与加密后的数据。第三方资料对 Wicap 能否解密 HTTPS 说法不一，不要按「能看到明文」来规划用途；要确认应用行为时，先从 DNS 查询与连接目标入手。

**安卓 11 及以上系统表现异常**

官方在 2.8.2 的更新记录里写有「Android 11+ requirements」，说明新系统对旧版本有适配门槛。你手上这份 2.8.0 在安卓 11+ 设备上若出现打不开、点了开始没反应，先按第二节把 SELinux 排查做完；仍不正常时，多半是版本与新系统的匹配问题，属于已知风险而不是你操作错了。

**界面卡顿 / 数据量大到翻不动**

缩短单次捕获时间；开抓前先过滤；一轮抓完立刻停止并清掉旧记录再抓下一轮。

## 四、数据与导出

**找不到捕获的文件**

停止捕获后数据会存到设备存储，具体目录随版本与系统而变，在应用内的导出/分享入口能看到实际路径，详见[过滤器与数据导出.md](过滤器与数据导出.md)。

**导出的文件在电脑上打不开**

先用 Wireshark 试；打不开就退回用 Wicap 内的复制/分享功能把关键包内容拿出来。更完整的排查（格式确认、0 字节文件、换导出路径）单独列在[导出pcap用Wireshark打开.md](导出pcap用Wireshark打开.md)第四节，导出格式支持情况以你手上这份 2.8.0 的实际表现为准。

## 五、其他

**这份 2.8.0 和网上说的最新版不一样**

正常。官方后续还发过 2.8.2、2.8.3，但网盘里这份就是 2.8.0，功能主线一致，版本脉络对照写在[是什么与适用场景.md](是什么与适用场景.md)。基础操作流程见[抓包使用教程.md](抓包使用教程.md)。
