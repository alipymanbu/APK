## 一、装之前先确认三件事

1. **root 已经就绪**。Wicap 运行需要 root/超级用户权限，设备上要已经有可用的 root 方案（Magisk、SuperSU 等）。没有 root 的设备装上也抓不了，先解决权限问题再回来。
2. **安卓版本满足要求**。这份包对应的说明标注为「安卓 5.2 以上」，官方对相近版本标的是 Android 4.4+，以实机安装结果为准。
3. **允许安装未知来源应用**。安装包来自网盘而非应用商店，需要在系统设置里允许「安装未知应用」（路径因系统版本而异，一般在「设置 → 应用 → 特殊访问权限」附近）。

## 二、获取安装包

从下面的 **Wicap 安装文件资源（夸克网盘）** 进入，把分享内容转存到自己的网盘后再下载到手机（或先下到电脑再传到手机都行）：

[Wicap 安装文件资源（夸克网盘）](https://pan.quark.cn/s/75fc1e213ccc)

这份包的版本是 2.8.0、大小 3.78M、MD5 为 `C64F411273960DF38FCB21DF457DADA7`。如果你下载后用校验工具算出的 MD5 与这个值一致，说明拿到的是同一份包；不一致就重新下载一次再装。

## 三、安装步骤

1. 在文件管理器里找到下载好的 `.apk`，点它。
2. 系统弹出安装确认时按提示继续；首次会引导你给文件管理器开「允许安装未知应用」。
3. 等安装完成，桌面出现 Wicap 图标。

**安装失败的常见处理**：

- 提示「解析包错误」→ 先核对 MD5（见上节），再检查手机剩余存储空间是否充足，删掉旧包重下。
- 提示与已装应用冲突 → 如果你之前装过 Wicap 的其他版本或 Demo 版，先卸载再装。
- 提示 CPU 架构不兼容 → 极少见，这份包同时带 armeabi-v7a 与 arm64-v8a 支持，一般不会遇到。

## 四、首次启动与授权

1. 打开 Wicap，它会请求 root/超级用户权限——在 Magisk（或你的 root 管理器）弹出的授权窗口里点**允许**，建议勾选「记住选择」。
2. 授权通过后进入主界面，就可以开始第一次抓包了，完整流程见[抓包使用教程.md](抓包使用教程.md)。
3. **用 Magisk 的设备如果点了开始没反应或直接退出**：官方介绍里明确提到这种情况——临时把 SELinux 切到 Permissive 模式再试。具体命令与操作步骤写在[常见问题与报错处理.md](常见问题与报错处理.md)里，用完记得按那篇说的改回来。

## 五、装好之后

第一次捕获建议从最简单的场景练手：开着捕获去浏览器打开一个网页，回来看抓到了什么。具体操作顺序与界面各栏的含义，见[抓包使用教程.md](抓包使用教程.md)；抓不到数据、闪退等问题都在[常见问题与报错处理.md](常见问题与报错处理.md)。
