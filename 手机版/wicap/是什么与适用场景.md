## 一、它是什么

Wicap（官方上架名 Sniffer Wicap，开发者 evbadroid）是一款移动端数据包捕获工具，捕获对象是手机的 WiFi 与 LTE 网络流量。你可以把它理解成「装在手机里的嗅探器」：不用把手机连到电脑上配置代理，直接在手机本机启动捕获，就能逐条查看设备收发的网络数据包，看到源/目标地址、端口、协议和内容分层。

它与常见的免 root 抓包应用（如 Packet Capture 一类，走 VPN 虚拟网卡路线）走的是不同路线：**Wicap 需要 root 权限才能工作**。第三方评测普遍把这一点列为其与同类工具最大的差别——有 root 时捕获更完整，没 root 则完全用不了。官方应用介绍里也写明：如果与 Magisk Superuser 配合不工作，可临时把 SELinux 切到 Permissive 模式（具体见[常见问题与报错处理.md](常见问题与报错处理.md)）。

官方渠道曾同时维护两个版本：免费的 Demo（包名 `com.evbadroid.wicapdemo`）与付费的 Pro（包名 `com.evbadroid.wicap`）。你从网盘拿到的这份安装包，包名是 `com.evbadroid.wicap`。

官方当年在应用商店页的功能介绍里列出的能力，值得你在预期里先挂上号：**在 Wi-Fi、3G、LTE 多个接口上并行捕获**；过滤条件可按协议类型、协议参数以及**载荷里的文本**来定；开放网络下部分网卡支持混杂模式；内置数据包统计、十六进制查看器与 root 终端；支持 Wireshark 的 cap/pcap 格式。日常用得最多的是过滤、统计、导出这三块，分别写在[抓包使用教程.md](抓包使用教程.md)与[导出pcap用Wireshark打开.md](导出pcap用Wireshark打开.md)里。

## 三、什么人用得上

- **开发者与测试人员**：在真机上确认自家应用的接口请求有没有发出去、发到了哪个地址，不必连电脑抓包。
- **网络排查**：手机上网异常时，看某次操作期间设备实际在连什么地址、什么协议在跑。
- **学习网络协议**：直接观察 DNS、TCP、HTTP 等协议在真实流量里的样子，第三方介绍把它与 PC 端 Wireshark 放在同一类用途里。
- **局域网自查**：官方描述提到可以了解当前 WiFi 上正在建立的连接——用来检查自己的网络里有哪些设备与连接活动。

## 四、预期要放对的地方

- **没有 root 就不用考虑**：装得上也跑不起来，这是第一道门槛。
- **HTTPS 流量默认是密文**：大部分应用与网站的通信都是加密的，抓到的 HTTPS 内容只能看到连接对象与加密数据本身。第三方资料对它能否解密 HTTPS 说法不一，不要按「开箱就能看明文」来规划你的用途。
- **只用于自己的设备与自己的网络**：捕获数据可能包含账号信息等敏感内容，分析对象请限定在你有权操作的设备与应用。
