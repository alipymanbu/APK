## 一、先弄清楚它装在哪

Sweezy Cursors 是给电脑换鼠标指针的工具，官方的安装入口有两个：Chrome 浏览器走 Chrome 网上应用店，Edge 浏览器走 Microsoft Edge 加载项。官方说明其他 Chromium 内核浏览器（Brave、Opera、Vivaldi 等）也能走 Chrome 商店入口安装。想在浏览器之外、整个 Windows 系统里换指针，则不走「安装」这条路，而是从官网直接下载光标文件，具体做法见 [Windows鼠标指针替换方法.md](Windows鼠标指针替换方法.md)。

截至 2026-09 检索，官方渠道没有安卓或 iOS 客户端——如果你在手机上搜到了安装包，先对照本篇第五节再看。

## 二、在 Chrome 里安装

Chrome 网上应用店的扩展页：[Sweezy Cursors - Custom Cursor for Chrome](https://chromewebstore.google.com/detail/gdcfjidbchfpojnfifkgghbamkdmbdaf)

1. 打开上面的商店页（或在商店里搜索 Sweezy Cursors）；
2. 点「添加至 Chrome」；
3. 弹窗里点「添加扩展程序」；
4. 装完后点浏览器右上角的拼图图标，把 Sweezy Cursors 固定到工具栏——之后换光标就是一次点击的事；
5. 点扩展图标打开光标面板，挑一个光标点选即生效；面板里还能调光标大小，用开/关开关随时切回默认指针。

补充两个官方口径：官网光标卡片上的「Add Cursor」按钮会把该光标存进你的扩展库，之后在面板对应分类里点选即可；添加前可以先看预览效果。装之前想核对权限与数据收集情况，见 [安全与权限自查指南.md](安全与权限自查指南.md)。

商店页当时显示的数据（2026-09 检索，会随时间变化，以商店页为准）：评分 4.8、约 60 万用户、扩展体积 617KiB、支持 54 种语言（含简体与繁体中文）、版本 4.0.5（2026-02-22 更新）。

## 三、在 Edge 里安装

Edge 加载项页：[Sweezy Cursors - Custom Cursor for Edge](https://microsoftedge.microsoft.com/addons/detail/mkfhpcgekfegendoikpbobhefdmgbaoi)

流程与 Chrome 一致：打开页面 → 点「获取」→ 确认安装 → 工具栏出现图标 → 点开挑光标。装完如果光标没变，先刷新当前页面再试，更多情况见 [光标不生效与常见问题排查.md](光标不生效与常见问题排查.md)。

## 四、浏览器之外：官网的光标文件

官网 [https://sweezy-cursors.com/](https://sweezy-cursors.com/) 不要求安装也能取用：每个光标的详情页都提供多种格式的下载文件，其中 `.cur`（静态指针）与 `.ani`（动态指针）可以直接设置进 Windows 系统，让桌面、资源管理器这些浏览器之外的地方也换成同一套指针。下载与设置步骤见 [Windows鼠标指针替换方法.md](Windows鼠标指针替换方法.md)。

## 五、手机和平板能用吗

官方没有提供手机版客户端：手机上的 Chrome、Edge 都不支持安装桌面版浏览器扩展，所以「手机换光标」这条路目前走不通，Sweezy Cursors 的用法集中在电脑端。

本应用名称对应的安装文件资源收录在 [Sweezy Cursors 安装文件资源（夸克网盘）](https://pan.quark.cn/s/98d0dc49ea9b)（收录版本 v4.0.3、大小 20.00M，2026-09-23 收录）；电脑端日常使用走上面第二、三节的浏览器扩展入口即可，版本更新情况以官方页面为准。
