# 替换 Windows 系统鼠标指针：Sweezy Cursors 光标文件怎么用

> 浏览器扩展只管浏览器窗口；这一篇讲怎么把官网下载的 `.cur` / `.ani` 光标文件设置进 Windows，让整个系统都换指针。

## 一、扩展换不到的地方，用文件来换

Sweezy Cursors 的浏览器扩展只改变网页里的指针；桌面、文件夹窗口、本地软件这些地方它管不到。想把指针换成同一套风格，走官网的光标文件下载，再用 Windows 自带的鼠标设置指过去，不需要额外装任何软件。

## 二、光标详情页里能下载到什么

在官网点开任意一个光标，详情页会按用途拆成几个文件（以页面当时显示为准）：

| 下载项 | 格式 | 用途 |
| --- | --- | --- |
| Windows Cursor | .ani | 动态指针文件，带动画 |
| Windows Pointer | .cur | 静态指针文件 |
| Cursor Image / Pointer Image | .png | 光标的原始图片 |
| Roblox Cursor / Roblox Pointer | .png | 官网为 Roblox 场景单独提供的图片，替换进客户端的步骤见 [Roblox光标替换步骤.md](Roblox光标替换步骤.md) |
| Complete Pack | .zip | 该光标全套文件的打包 |

同一套光标里，箭头、链接手型等不同角色可能各有一个文件，替换时按角色分别指过去。

## 三、替换步骤（以 Windows 10 为例）

1. 在磁盘上先建一个固定目录存放光标文件——官方建议放在「文档」下，例如 `文档\Sweezy Cursors`，并提醒 Windows 可能因源文件被挪动而丢失自定义指针；
2. 从官网光标详情页下载 `.cur` 或 `.ani` 文件，存进这个目录；
3. 打开设置，搜索「鼠标」，进入「其他鼠标选项」（官方口径：设置 → Bluetooth 和设备 → 鼠标 → 其他鼠标设置）；
4. 切到「指针」选项卡，先换「正常选择」（主箭头）与「链接选择」（手型）这两个角色——官方教程也只要求换这两个，就能覆盖绝大多数场景；
5. 点「浏览」，选中刚下载的文件，需要的话再逐个替换其余角色；
6. 点「应用」，立即生效。

Windows 11 的入口在「设置 → 蓝牙和其他设备 → 鼠标 → 其他鼠标选项」，与上面第三步是同一条路径。

## 四、动态与静态怎么选

`.ani` 是动画指针，效果醒目，但在个别程序里显示不如静态稳定；`.cur` 是静态指针，兼容性最好。同一个角色二选一即可，不必都设置。

## 五、想换回系统默认

回到「指针」选项卡，把「方案」下拉框换回系统默认方案（方案名以系统显示为准），所有角色一次性还原。

一个常被踩的坑：指针文件被移动、重命名或删除后，已指向它的角色会失效。所以第三步才强调先建固定目录——设置完之后别再挪动那些文件。
