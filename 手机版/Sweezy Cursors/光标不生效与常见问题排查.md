## 一、常见问题对照

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点选光标后页面没变化 | 生效需要页面刷新，安装前就已打开的标签页尤其如此 | 刷新当前标签页再看 |
| Chrome 商店页、浏览器设置页里不变 | 浏览器内部页受规则限制 | 正常现象，换普通网页验证 |
| 标签栏、地址栏仍是默认指针 | 浏览器界面不受扩展控制 | 正常现象 |
| 其他浏览器提示未安装扩展 | 官方入口只有 Chrome 商店与 Edge 加载项 | 换 Chrome 或 Edge 使用 |
| 装了多个换光标扩展后行为混乱 | 同类扩展互相冲突，官方建议一次只用一个 | 只保留一个，其余停用或删除 |
| 个别网站光标始终不换 | 网站自身样式覆盖或拦截扩展脚本 | 官方说明属正常现象，换普通网站验证 |
| 系统指针换完又失效 | 指针文件被移动或删除 | 文件放固定目录后重新指一次 |

下面把其中几条展开说清。

## 二、哪些地方一定不生效

扩展页的官方说明写得很明确：按 Google 的规则，扩展不能作用于 Chrome 网上应用店页面与浏览器内部页面（主页、设置、下载页等），也不能改浏览器导航栏（标签、按钮、地址栏、工具栏）。除此之外的普通网页基本都生效。想验证光标是否正常，开一个普通网页看就行，不用对着浏览器设置页较劲。

## 三、其他浏览器能不能用

官方说明任何 Chromium 内核浏览器都能从 Chrome 网上应用店安装（Brave、Opera、Vivaldi 等），Edge 用户另有加载项入口。不过有用户反馈在 Opera GX 里会遇到「提示未安装扩展」的情况——官方口径与个别用户反馈两边并列在此：先按官方说法从 Chrome 商店装一次试试，不行就换 Chrome 或 Edge 验证，排除是浏览器本身的问题。

## 四、恢复默认指针

- **浏览器里**：打开扩展面板，切回默认光标，网页指针即恢复；
- **Windows 系统里**：鼠标属性 →「指针」选项卡 →「方案」选回系统默认，操作路径见 [Windows鼠标指针替换方法.md](Windows鼠标指针替换方法.md) 第三、五节。

## 五、隐私与安全

商店页上开发者声明不收集、不使用你的数据（声明内容以商店页当时显示为准）。权限逐项含义、第三方独立评估与五步自查方法，见 [安全与权限自查指南.md](安全与权限自查指南.md)；一般使用问题也可以去官方社区论坛 [sweezy.community](https://sweezy.community/) 发帖提问。
