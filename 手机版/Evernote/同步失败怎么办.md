# 同步失败怎么办

> 新笔记别的设备看不到、登录卡住、列表空白 —— 按这套顺序排查，多数不用重装。

## 一、先分清是哪种「不同步」

三种症状，原因完全不同，别混在一起处理：

| 症状 | 更可能是 |
| --- | --- |
| 新记的东西传不上去 / 别的设备看不到 | 同步问题：网络、服务连接 |
| 登着登着被登出、列表整体空白 | 设备数超限被踢下线，或登错了账户 |
| 只有某几条找不到 | 排序设置不一致，或笔记在废纸篓 / 别的笔记本里 |

## 二、标准排查顺序（按官方排查建议整理）

从上往下做，每做一步就看一眼有没有恢复，恢复了就停：

1. **换网络试**：Wi-Fi 和流量互切一次。同步走网络，最常见原因就是当前网络连不上 Evernote 服务器。
2. **确认应用是最新版**：旧版本可能连不上已升级的服务端。从商店装的等商店更新；APK 装的自己去下个新版覆盖安装（笔记在云端，覆盖安装不丢）。
3. **重启应用，再重启手机**：后台进程卡死的表现有时和「不同步」一模一样。
4. **退出登录 → 重启手机 → 重新登录**：这一步能解决相当一部分顽固同步问题。放心做，笔记在云端。
5. **去网页端 `app.evernote.com` 看一眼**：网页上笔记都在，说明数据没问题，纯粹是手机端的事；网页上也缺，才需要怀疑账户或数据层面。
6. **检查排序设置**：手机和电脑的笔记列表排序方式（按更新时间 / 按创建时间）是否一致 —— 两边设置不同，看起来就像「笔记没同步过去」，其实是排序把旧笔记排到后面了。

以上都不管用，再考虑卸载重装（**重装前必须先在网页端确认所有笔记都在**，必要时先导出备份），并从应用里导出活动日志一并反馈给官方支持。

## 三、登录卡在「Signing In...」

登录界面一直转圈，通常是这几种：

- **网络拦了登录请求**：换网络（尤其试试流量）。Evernote 是境外服务，部分网络环境下连接不稳。
- **账户密码对但登的是错入口**：用 Google 登录的账户，用邮箱密码去登会失败，反之亦然 —— 注册时用了哪种，登录就选哪种。
- **开了两步验证但没带验证码**：从受信任设备以外的新设备登录时要输验证码，检查邮箱 / 验证器。

## 四、设备数超限：笔记「凭空消失」

免费版只允许 **1 台设备**同步（Starter 是 3 台）。你在手机上正常用着，电脑一登录，手机端就会被登出 —— 打开应用看到的是空白列表，像极了笔记全没了。

**笔记没丢**，它在服务器上、也在刚登录的那台设备上。处理办法二选一：

- 回到手机端重新登录（电脑端会被踢下线）；
- 设备确实多，升套餐或在不用的设备上退出登录腾出名额（各档位设备数见 [免费版和付费版区别.md](免费版和付费版区别.md)）。

长期只用一台手机的，电脑上用完网页版记得退出，省得来回互相踢。

## 五、国际版与「印象笔记」账户混淆

Evernote（国际版）和国内的「印象笔记」是**两套独立服务，账户不互通**。如果你以前用过印象笔记，现在登 Evernote 看不到以前的笔记 —— 不是同步失败，是根本不在一个账户体系里。

判断方法：看你登录用的邮箱注册的到底是哪个服务。两家的笔记无法自动互通，确有需要只能逐条导出再导入。另外，同一个 Evernote 账户如果先后用不同方式登录（邮箱 / Google / Apple），也会出现「登上了却是空列表」—— 退回你最初注册的那种方式登即可。

## 六、什么时候才需要重装

只有满足两个条件才走到重装这一步：**网页端确认数据完整** + **导出了活动日志**。重装解决的是手机本地的缓存与状态问题，数据本身在云端 —— 反过来，不看网页端就直接重装，万一是登错了账户，你会以为数据真丢了。

重装后仍不同步，就是服务端或账户层面的问题了，带上日志、设备型号、症状出现时间找官方支持。
