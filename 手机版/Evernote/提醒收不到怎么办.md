# 提醒收不到怎么办

> 设了提醒但到点没动静：先把系统权限配齐，再排查手机的后台清理。

## 一、提醒是怎么发出来的

先理解机制，排查才有方向：你给笔记设的提醒存在服务器上，到点后由**手机本地的 Evernote 应用**弹出通知 —— 也就是说，这条链上有三处都能断：

1. 应用内的提醒没设成功；
2. 系统不让 Evernote 发通知；
3. 系统把 Evernote 从后台杀了，到点时应用根本没在跑。

按这个顺序从上往下查。

## 二、确认提醒本身设上了

打开那条笔记，点闹钟图标设置日期与时间（有的版本是点「设置日期」）。设成功的标志是笔记上出现醒目的时间标记。这一步没设上，后面全白搭 —— 先在应用里随手设一个一分钟后到期的提醒，作为后面每步排查的验证手段。

## 三、打开系统的通知权限（关键一步）

Evernote 官方帮助文档给出的 Android 路径：

1. 手机**设置 → 应用**（有的机型叫「应用管理」）；
2. 在列表里找到 **Evernote**；
3. 在应用信息页确认两项都开着：**通知**、**闹钟与提醒**（Alarms & reminders）。

只开「通知」不开「闹钟与提醒」，是这类应用最典型的漏配 —— 提醒走的正是闹钟与提醒这一路。找不到这两项说明系统版本较老，路径以你的机型实际显示为准。

## 四、手机系统的省电清理（国产 ROM 重点）

权限开了还收不到，多半是系统把 Evernote 的后台杀了。这在国产 ROM 上非常常见，各品牌的处理思路一致（以下以华为官方文档的路径为例，其他品牌同理）：

| 动作 | 华为路径（其他机型找对应项） |
| --- | --- |
| 允许后台运行 | 设置 → 搜索「应用启动管理」→ 找到 Evernote → 关闭自动管理 → 勾选允许自启动、允许后台活动 |
| 豁免电池优化 | 设置 → 搜索「电池优化」→ 选择所有应用 → Evernote → 设为**不允许** |
| 关省电模式 | 设置 → 电池 → 关闭省电模式 |
| 锁定后台 | 多任务界面下拉 Evernote 卡片加锁，防止一键清理时被杀 |

两条补充：

- **别用「一键清理」杀后台后再指望提醒**：清理后应用没在跑，到点自然弹不出来。要么让 Evernote 常驻，要么设完提醒打开一次应用。
- **重启手机后第一波提醒可能缺席**：重启后应用尚未启动，这是系统机制，打开一次 Evernote 即恢复。

## 五、检查「拦通知」的开关

还有几个与 Evernote 无关、但会吞掉提醒的设置：

- **勿扰模式 / 专注模式**开着时，非白名单应用一律静音不弹 —— 检查勿扰的定时规则；
- 通知渠道里 Evernote 被设成了**静默通知**（不响不亮屏，只进通知栏）；
- 锁屏通知被关，人不在手机前时看不到横幅。

这些在 设置 → 通知 里逐项核对，具体名称随机型不同。

## 六、还是不行的两个方向

1. **换设备验证**：同一条提醒在电脑端（Windows/Mac）设一次 —— 电脑端到点弹了，说明账户和提醒本身没问题，就是手机端的系统设置；电脑也不弹，检查电脑的时区与时间是否正确。
2. **确认没登错账户**：提醒设在 A 账户、手机登着 B 账户，到点当然不会响。国际版与「印象笔记」是两套服务，账户混淆的表现之一就是「设了的东西全找不到」，详见 [同步失败怎么办.md](同步失败怎么办.md)。

排查过程中每改一处，就用第二节那个一分钟后到期的提醒验证一次 —— 别改完一轮才测，分不清是哪一步起的作用。
