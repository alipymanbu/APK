# Arc Player 有画面没声音怎么办

> 本篇专讲「视频能放、声音出不来」的排查：从误触静音到 AC3/EAC3/DTS 音轨不支持，按顺序对号入座。

## 一、先排除不是故障的三种情况

| 现象 | 检查 |
| --- | --- |
| 完全没声 | 媒体音量是不是被手势滑到了 0：播放界面上竖向滑动就是音量手势，误触很常见，先按音量键把媒体音量拉起来 |
| 戴蓝牙耳机没声 | 先重连耳机再放；蓝牙编解码协商失败也会哑音，换有线耳机对比一次就能定位 |
| 只有这一个视频没声 | 大概率是文件或音轨问题，跳到下面第三节 |

## 二、错误提示带「audio format not supported」：音轨编码不支持

有画面、没声音，或弹出「This audio format (EAC3) is not supported」这类提示，是安卓播放器最典型的无声原因：视频里的音轨用了 AC3、EAC3、DTS、MLP 这类编码，而设备或播放器不带对应的解码器。这一结论在多个独立来源的排查文章里口径一致；部分机型还会把这类音轨原样交给设备解码，设备不支持就直接无声。

按这个顺序处理：

1. 在播放设置里找音轨切换入口，换一条音轨（多音轨的 MKV 常有 AAC 备选轨）。
2. 界面里如果有「硬件加速/软解码」切换，切到软解码再放。
3. 找同一个视频的另一种封装版本（音轨改成 AAC 或 MP3 的）。
4. 用电脑把音轨转成 AAC 再拷回手机，转码只动音频，几分钟就好。
5. 都不行就换一个自带软解的播放器（如 VLC）验证，能出声就确认是解码能力差异，文件本身没坏。

## 三、视频本身就没声

- 把文件拷到电脑上放一次：电脑上也无声，就是源文件的问题，换资源。
- 电脑有声、手机无声，再回头走第二节的音轨排查。
- 顺带核对文件是否下载完整：大小明显小于正常版本的多半是半截文件，重新下载。

## 四、还没解决

- 通知栏或控制中心的媒体音量条、勿扰模式也过一遍，部分机型勿扰会压掉媒体声。
- 换几个不同来源的视频各放一次，都不出声就反馈给开发者（邮箱见[播放常见问题解答.md](播放常见问题解答.md)），附上视频格式与音轨信息。
