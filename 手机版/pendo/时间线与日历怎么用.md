## 一、时间线：所有内容的一条主干

Pendo Note 不分「笔记页」「待办页」「日程页」，笔记、日志、待办清单、日历事件全部按时间排成一条时间线。你写下的一切默认按发生时间排列，往下翻就是过去记过的东西，顶部是最近的。

这条设计带来的实际用法：

- **想到什么写什么**：不用先想清楚「这算笔记还是待办」，直接写，之后再归类；
- **按时间回找**：找上周记的内容时按时间线翻，比在多个分类里来回切快；
- **全局搜索**：记不清时间时用搜索按关键词找。

## 二、自然语言写日程（Calendar Event IQ）

官方介绍里着墨最多的就是这个能力：你用平常说话的方式把计划写下来，它来理解时间和重复规则，然后同步进系统日历。

官方举过这样的例子：

```text
Go to gym every Tue & Thur at 8pm for 3 weeks
（每周二、周四晚 8 点去健身房，坚持 3 周）
```

写成（或用语音说出）这样一句复杂计划，它就能理解其中的星期、时刻与持续周期，直接建进系统日历。你不需要在表单里一个个填开始时间、重复规则、结束日期。

要注意的前提：这一步要写入的是**系统日历**，所以第一次用时需要给 Pendo Note 日历读写权限；同步的目标是你系统日历里已有的账户（比如手机上登录的系统日历账号），事件会跟着系统日历走。

## 三、单字母快捷指令

写完内容后，**另起一行**输入指令字母再回车，就能直接把刚写的内容变成对应的东西：

| 指令 | 作用 |
| --- | --- |
| `C` | 把当前内容建成日历事件 |
| `T` | 把当前内容建成待办清单 |
| `E` | 把当前内容作为邮件发送 |

安卓商店页明确提到的是上面这三个。iOS 与 Mac 版还支持更多指令（比如 `S` 分享、`Co` 把粘贴的联系人信息解析成新联系人），安卓版是否包含以你手上的版本实际表现为准。

用熟之后，整条流程就是：写内容 → 敲一个字母 → 完成，全程不用离开输入法。

## 四、日历视图与图表

- **日历视图**：按月份查看，每一天会标出当天有多少条内容、各类型有几条，哪天忙哪天空一目了然；切换年月可以往前翻或往后排计划；
- **每日/每周图表**：用直观的图表呈现你每天、每周的计划量，适合周日晚看看下周排了多少事。

## 五、一条建议的上手路径

1. 先随手写两条今日要做的事，各敲一个 `T` 变成待办；
2. 写一条含时间的计划，敲 `C` 看它怎么进系统日历；
3. 打开日历视图确认事件落位；
4. 之后按自己的习惯，把每天固定用的时间线当日记本、把要排期的内容交给 `C`。
