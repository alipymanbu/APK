## 一、安装前先核对这几个信息

Pendo Note 是 Lychee Isle（App Store 上的主体名为 Shenzhen Lychee Isle Co., Ltd.）出品的笔记应用，2014 年先在 iOS 上线，后来出了安卓版。下面是本文对应这份安装包的实际情况，装之前可以先核对一遍：

| 项目 | 内容 |
| --- | --- |
| 版本 | 2.2.3 |
| 包名 | `com.pendoapp.pendo` |
| 安装包大小 | 71.34 MB |
| MD5 | `31DA37894429949B3296887082C8847A` |

注意版本号线：安卓版是独立的 2.x 系列号，和 iOS 版的 8.x 不是一套编号，别拿应用商店里的 iOS 版本号来对照安卓安装包，具体差异见[安卓版与iOS版区别.md](安卓版与iOS版区别.md)。

## 二、从网盘获取安装文件

安装包不放在应用商店里，而是通过夸克网盘分享获取，步骤如下：

1. 打开上面的 **Pendo Note 安装文件资源（夸克网盘）** 链接；
2. 把文件转存到自己的网盘（需要登录夸克账号）；
3. 在夸克网盘客户端里找到转存后的 APK 文件，下载到手机本地存储。

下载完成后建议顺手核一下文件大小是否在 71 MB 上下，明显偏小说明没下完整，重下一次再装。

## 三、安装步骤

安卓默认不允许安装来自应用商店之外的安装包，需要先给文件管理器或网盘客户端放行：

1. 打开手机「设置」，找到「安全」或「更多设置」里的**安装未知应用**（不同品牌入口名称略有差异：小米在「隐私保护」相关项下，华为在「安全」里，OPPO/vivo 在「安全与隐私」里，以你手机实际菜单为准）；
2. 在应用列表里找到你用来打开 APK 的那个应用（文件管理器或夸克网盘），允许它「安装未知应用」；
3. 回到下载好的 APK 文件，点击安装；
4. 弹出权限确认时按需允许，等待安装完成。

## 四、首次启动建议做的设置

装完第一次打开，Pendo Note 的核心功能会用到这几类手机权限，建议按用途开启：

- **日历读写**：把写好的日程同步进系统日历是这款应用的核心能力，不给日历权限这条链路就走不通；
- **通知**：如果你想靠它提醒待办和日程，通知权限要开；
- **照片/存储**：往笔记里插图、生成分享长图时会用到。

权限随时可以改：在系统「设置 → 应用 → Pendo Note → 权限」里逐项调整即可。

## 五、装不上时的排查顺序

按出现概率从高到低试：

1. **提示包损坏或解析失败**：多半是下载不完整，删掉重下，必要时用 MD5 工具核对文件指纹是否等于上表中的值；
2. **提示存在冲突**：手机里可能装过其他渠道的同包名版本，先卸载旧的再装；
3. **安全软件拦截**：部分手机管家会把非商店来源的安装拦下来，在拦截记录里选择允许；
4. **存储空间不足**：71 MB 的安装包加上安装过程的空间开销，保证至少几百 MB 余量再装；
5. **系统版本过旧**：如果安装按钮直接置灰或提示不兼容，说明当前系统版本达不到要求，只能升级系统或换设备。
