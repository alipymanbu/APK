## 一、导入的思路

FunBox 的表情面板支持外部导入，其中被多篇教程反复提到的一条路子，是借 Telegram 的转换机器人把贴纸包转成 FunBox 可识别的格式，再凭返回的 ID 在模块里导入。一次转一包，转完永久留在你的面板里，与在线库互不干扰。

## 二、操作步骤

1. 在 Telegram 里找到转换用的 Bot（多篇教程提到的是 `@QToolHelperBot`，是否仍在服务以实际可用性为准）。
2. 把你想要导入的贴纸包发给这个 Bot。
3. 选择「转换到 FunBox」，Bot 会返回一个 ID。
4. 打开 FunBox 的表情面板，在导入入口填入这个 ID，完成导入。

## 三、导入失败先看这几处

| 现象 | 先检查什么 |
| --- | --- |
| Bot 完全没反应 | Telegram 本身能否正常收发消息；Bot 是否还在服务（第三方 Bot 说停就停，与 FunBox 无关） |
| 返回了 ID 但导入失败 | ID 是否复制完整；FunBox 版本是否较旧（导入接口随版本更新过） |
| 导入成功但表情加载不出 | 是否联网；在线表情需联网获取，只有已下载的能离线用 |
| 个别贴纸包转不动 | 包内格式特殊或 Bot 暂不支持，换个包试，能转的先转 |

Bot 属于第三方服务，不在 FunBox 本体的控制范围内。实在转不动的贴纸包，退回手动路线：把图片逐张保存进面板（做法见 [表情面板与语音面板用法.md](表情面板与语音面板用法.md)），稳定但费时；导入接口报错这类模块侧的问题，按 [故障排查与常见问题.md](故障排查与常见问题.md) 处理。
