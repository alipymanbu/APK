## 一、两条路线的区别

| | LSPosed 路线（常规用法） | 内置版路线 |
| --- | --- | --- |
| 前提 | Root + Magisk / KernelSU + LSPosed | 不需要 Root |
| 装的是什么 | FunBox 模块本体（独立 app）+ 官方微信 / QQ | 被第三方重新打包、预装了模块的微信 / QQ 安装包 |
| 更新 | 模块与聊天软件各自独立更新 | 想换版本要等重新打包的整包，本体一升级模块就失效 |
| 信任成本 | 模块与聊天软件分开装，来源各自清晰 | 装的是动过的聊天软件本体，内容全凭打包者 |

先说清一点：本篇开头那份夸克网盘资源是 **FunBox 模块本体**，对应 LSPosed 路线；内置版是第三方另行打包的东西，**不在那份资源里**，找不找、信不信由你自己判断。

## 二、内置版渠道写明的注意事项

分发渠道对内置版的注意事项（转述自渠道说明，原话口径以渠道页面为准）：

- 内置版微信**不与原版微信共存**，装之前要先卸载原版微信；
- **不支持第三方 app 跳转微信**，从别的应用里点链接拉不起微信；
- 安装前**务必备份聊天记录**；
- 使用期间**不要自行升级微信版本**，升级会破坏内置的模块。

这四条每一条都在压缩你正常使用微信的空间 —— 接受之前先想清楚值不值。

## 三、比常规路线多出来的风险

- **安装包来源不可核对**：常规路线里微信是官方的、模块是独立的；内置版里微信本体被动过，有没有夹带别的东西你无从验证。
- **风控面更大**：改过的客户端特征比「官方微信 + 模块注入」更明显。
- **更新被锁死**：官方微信一出新版，你就得等打包者跟进；期间要么停在旧版，要么换回官方版 —— 换回之前先备份聊天记录。
- 社区流传的集成版说明里也出现过「限制部分功能、禁止高危功能」的标注，说明打包者自己也在往回缩边界。

## 四、务实建议

- 主力机、常用账号：走 LSPosed 路线，别碰内置版；
- 备用机想尝鲜：用小号，装前备份，装后别升级；
- 想从内置版回到官方微信：先备份聊天记录 → 卸载内置版 → 装官方微信 → 恢复记录；
- 模块本体装完怎么激活见 [下载与安装教程.md](下载与安装教程.md)，风险全貌见 [账号风险与安全须知.md](账号风险与安全须知.md)；内置版不生效、闪退这类问题，排查思路与常规版一致，见 [故障排查与常见问题.md](故障排查与常见问题.md)。
