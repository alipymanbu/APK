## 一、FunBox 是什么形态的应用

FunBox 不是一款独立的聊天软件，而是一个跑在 LSPosed（Xposed）框架里的模块。装上后它没有自己的聊天界面，而是在微信、QQ（第三方插件仓库的收录信息里还提到 TIM）的聊天窗口里加出表情面板和语音面板，让你长按就能保存、发送表情和语音。所以「装完 apk」只是第一步，「在框架里勾作用域」才是能不能用起来的关键，流程见 [作用域配置与面板入口.md](作用域配置与面板入口.md)。

模块早先叫 HaveFunPanel，4.0.0 版起改名为 FunBox，搜旧资料时两个名字指的是同一个东西。第三方插件仓库的收录信息里标注的开发者为 Hicores，没有可查的官网；版本是否还在维护，以你下载渠道的更新说明为准。

## 二、装之前先确认两件事

| 前提 | 说明 |
| --- | --- |
| 已装好 LSPosed 框架的手机 | LSPosed 一般通过 Magisk / KernelSU 这类 Root 方案安装。更新日志里提过 Zygisk 模式与「内置」用法（把模块嵌进应用安装包的免 Root 路线），能否跑通取决于你自己的环境，本文按主流的 LSPosed 路线写 |
| 微信 / QQ 本体能正常登录 | 模块只在你勾选的应用内生效，本体登录异常时先解决本体的问题 |

只有一台没 Root 的备用机又想试，社区流传的内置版路线（模块被嵌进微信 / QQ 安装包的免 Root 做法）不需要 Root，但它装的是第三方改过的聊天软件本体，约束与风险都更多，先读 [免Root内置版注意事项.md](免Root内置版注意事项.md) 再决定。

## 三、拿到安装包并核对

从 [FunBox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/30bb5933b4d5) 转存即可，文件夹里就是安装包。这份包的档案信息如下（网上搜到的往往是更新的构建，别混着对）：

| 项 | 值 |
| --- | --- |
| 版本 | v698 |
| 包名 | `have.fun` |
| 大小 | 3.85M |
| MD5 | `A98E4D946FBCAE5E0A973F8AB525092C` |
| 系统要求 | 安装包信息标注安卓 5.2 以上 |
| 记录日期 | 2026-09-23 |

想确认下载过程没把文件弄坏，把 apk 放到电脑上跑一句（文件名换成你实际的）：

```powershell
certutil -hashfile funbox.apk MD5
```

输出的哈希与上表对得上，就是同一份文件。

FunBox 的版本号早期是三段式（如 4.8.0），后来改成纯递增数字（社区可见 589、698、966 这些编号），所以「v698」和「698」是同一种编号的不同写法。

## 四、安装与激活（按顺序做）

1. 安装 apk。它自带一个普通的管理界面，装完能打开就说明本体没问题。
2. 按系统提示给 FunBox 开悬浮窗权限与存储访问权限，后面保存表情、语音都依赖这两项。
3. 打开 LSPosed 管理器 → 模块，找到 FunBox，把总开关打开。
4. 进入它的**作用域**，勾选微信和 QQ，需要哪个勾哪个；只勾真正要用的那一个也行，作用域越小越稳。
5. **强制停止微信 / QQ**（设置 → 应用 → 强制停止），或者直接重启手机。
6. 重新打开微信，进「设置」页，能看到多出来的 FunBox 面板入口，就是激活成功了。

第 5 步不能省：模块是在聊天应用进程启动时注入的，旧进程不重启，你勾的开关一个都不会生效。

设置页里没出现入口、或面板呼不出来，按 [故障排查与常见问题.md](故障排查与常见问题.md) 逐项过；动手前建议先读一遍 [账号风险与安全须知.md](账号风险与安全须知.md)，把风险边界弄清楚再用。
