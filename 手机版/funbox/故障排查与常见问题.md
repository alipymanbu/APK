## 一、装完没有任何效果

按顺序过：

1. LSPosed 管理器里 FunBox 总开关是否打开、作用域是否勾了微信 / QQ；
2. 勾完有没有**重启作用域**（强制停止聊天应用或重启手机）—— 这是最常漏的一步；
3. 微信「设置」页有没有出现面板入口（入口位置见 [作用域配置与面板入口.md](作用域配置与面板入口.md)）；
4. 以上都对还不行，把 LSPosed 升到较新版本再看；
5. 用 Zygisk 方式加载的，再看管理器里的模块开关有没有被关 —— 有用户整理的更新说明提到它会遵循 KernelSU 的模块开关（disable 文件），开关关着就不加载。

**有用户教程提到**一个对照点：LSPosed 日志里出现 `Failed to init Isplant` 之类的提示，属于框架适配问题，不是模块本身坏了 —— 看到它就把排查重心放到框架版本上，别在模块里来回折腾。

## 二、QQ 里的入口与菜单异常

| 现象 | 说明 |
| --- | --- |
| 安卓 12 上 QQ 找不到模块入口 | 更新日志（v4.9.2）专门修过这一项，老版本模块在安卓 12 上确实有这个问题，先升级模块 |
| 新版 QQ 长按菜单不显示 | v5.4.0 修过一次；v589 又修过模块导致 QQ 部分界面显示异常的问题。QQ 本体升级后模块跟着失效是常态，等模块更新适配 |
| QQ 群里收到特定动图就闪退 | v589 加了「阻止闪退」开关，拦下已知的异常动图（如龙舟动图），在模块设置里找这个开关打开 |

## 三、功能开了但用不了

- **功能无法启用**：确认模块版本较新（有教程建议 v966 以上 —— 你手上这份是 v698，个别新特性没有属正常）；重启手机或重新授权权限；部分机型关掉省电模式再试。
- **存储空间不足 / 保存失败**：进 FunBox 设置的存储管理清临时文件；素材多就整体迁移到外部存储。历史上「存储路径第一次点不动」「设无效路径后闪退」都修过，路径设不动先升级版本。
- **表情加载不出**：在线表情要联网获取，只有已下载的能离线用；网络环境受限（DNS 解析异常一类）时在线资源可能一直转圈 —— 有用户整理的更新说明提到，模块已改用 DoH 解析来缓解 DNS 污染，转圈先换个网络环境再试。
- **流量异常**：更新说明里提过对异常图片加载做拦截、减少偷跑流量；群里图多想省流量的话，去模块设置里找相关开关。
- **推荐不准**：长按不匹配的推荐表情选「不再推荐此类」，用一阵后会明显减少。

## 四、几个常见疑问

**Q：FunBox 免费吗？**
各收录渠道均按免费工具收录；向你收费的渠道不属于正常口径。

**Q：必须 Root 吗？**
主流用法是 LSPosed 框架，而它需要 Root 环境（Magisk / KernelSU 等）。不想 Root 也有社区流传的内置版路线（装的是改过的聊天软件本体），约束与风险见 [免Root内置版注意事项.md](免Root内置版注意事项.md)。装与激活见 [下载与安装教程.md](下载与安装教程.md)。

**Q：会读我的聊天内容吗？**
面板的保存、推荐功能都发生在聊天应用进程内，会接触到消息内容；介意就把推荐类开关关掉，只用手动存发。完整讨论见 [账号风险与安全须知.md](账号风险与安全须知.md)。

**Q：微信 / QQ 更新后模块失效怎么办？**
先停用模块确认本体正常，再等模块更新适配；本体回退不推荐，原因见 [账号风险与安全须知.md](账号风险与安全须知.md)。

**Q：表情、语音素材从哪来？**
在线库下载、自己录制、本地文件导入，以及 Telegram 贴纸包整包转换导入（流程见 [Telegram表情包导入方法.md](Telegram表情包导入方法.md)）。
