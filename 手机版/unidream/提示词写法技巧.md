# UniDream 提示词写法技巧

> 本篇讲怎么把描述词写清楚：同一个想法，描述的颗粒度不同，出图差距很大。给你一套能套用的结构和改写示例。

## 一、先照着官方示例找感觉

官方给的示例描述都很短：**「白雪皑皑的山坡」「海上飓风与小船」「由新海诚绘画的一条美人鱼」**。拆开看，一句话里至少有一样东西：

| 成分 | 例句里的体现 |
| --- | --- |
| 主体 | 山坡 / 小船 / 美人鱼 |
| 场景或状态 | 白雪皑皑 / 海上飓风 |
| 风格参照 | 由新海诚绘画 |

最短可以短到一个主体加一个修饰（官方第一句就是这样），加上风格参照则更接近你脑子里那张图。

## 二、把描述写具体的四个加法

| 加什么 | 不够具体 | 更具体 |
| --- | --- | --- |
| 光线时间 | 一座山 | 清晨薄雾中的一座雪山 |
| 色彩基调 | 一个女孩 | 红头发、蓝色裙子的女孩 |
| 视角构图 | 一只猫 | 俯视视角打盹的橘猫 |
| 风格参照 | 一片森林 | 水彩风格的一片森林 |

一次加一两项就够，元素堆太多会互相打架。拿不准哪个词起了作用时，每轮只改一处再生成，前后对比就能看出来。

## 三、中文能直接用吗

可以，输入中文描述即可生成。某次结果始终不对味时，试两件事：把长句拆短、只留核心元素；或者把风格单独点明（「日系动漫风」「油画风」）。应用内「每日灵感」社区里能看到别人的作品和配套描述词，抄一条改两个词是上手最快的路径；刷到喜欢的作品还能用「尝试同款」直接生成。

## 四、图生图时的描述词

图生图的描述说的是「你想要它变成什么」，而不是「图里有什么」。自拍转动漫，写「日系动漫风格的少女头像，明亮色调」比只写「一个女生」更能拉住风格；具体操作见 [图生图与局部修改教程.md](图生图与局部修改教程.md)。

## 五、想让画面里出现文字时，降低预期

描述里写「招牌上写着 XX」「举着写有 XX 的牌子」这类要求要谨慎：有用户反馈生成结果里的文字经常是错的、乱的（字母顺序错乱、笔画糊成一团），这是目前 AI 绘图的普遍短板。想用图做海报、配文，更稳的做法是生成不带字的干净画面，文字后期用修图 App 自己加。

描述都写到位了还是出不来想要的图，剩下的多半是等待、保存这类环境问题，按 [常见问题排查.md](常见问题排查.md) 查。
