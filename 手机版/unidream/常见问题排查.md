## 一、生成一直转圈 / 等待时间异常

1. 先看网络：AI 绘图要把请求发到云端生成，网络差会一直卡在排队状态，换 Wi-Fi / 流量对比一次。
2. 高峰时段（晚上）排队会变长，等几分钟再下结论。
3. 退出重进一次应用；频繁复现就清后台再试。
4. 以上都无效，检查装的是不是较旧版本，去官方渠道看有没有新版（官网：[unidreamapp.com](http://unidreamapp.com/)）。

## 二、出图和描述对不上

- 描述太短、太笼统是最常见原因，按 [提示词写法技巧.md](提示词写法技巧.md) 第二节把主体、光线、风格补具体。
- 风格选错了方向：写实风格下写动漫描述自然出不来二次元，风格和描述要一致。
- 画面局部错误（比如手部）用改图修，别整张重抽，见 [图生图与局部修改教程.md](图生图与局部修改教程.md)。

## 三、生成的东西去哪了 / 找不到图

- 应用内：作品一般保存在「我的作品 / 个人中心」里，先去那里翻。
- 手机里：保存到本地的图在系统相册的对应目录，个别手机需要重启相册才刷新。
- 保存失败多半是没给存储权限：到系统设置 → 应用 → UniDream → 权限，允许照片和媒体 / 存储权限后再存一次。

## 四、要收费吗 / 生成次数有限制吗

- 基础的文生图、图生图可以免费体验；应用带每日签到领额度的机制，签到后能多生成。
- 部分高级模型、加速出图这类增值项可能消耗会员或额外次数，具体以应用内当时展示的规则为准。
- 免费额度用尽时会提示等待或升级会员，不想花钱就等次日签到额度恢复，或把描述词写得更准、减少试错次数（见 [提示词写法技巧.md](提示词写法技巧.md)）。

## 五、重装、更新与版本

- 网盘里收录的是 3.7.1 版（147.40 MB），安装包仍在 **[UniDream 安装文件资源（夸克网盘）](https://pan.quark.cn/s/189c6415ef4d)**；官方渠道的版本可能更新，两者不是一回事。
- 覆盖安装要求前后同一签名；如果手机里装过其他渠道的 UniDream，覆盖失败就先卸载再装（先备份应用内作品）。
- 卸载重装后应用内的生成记录一般不会保留，重要作品先保存到手机相册。

## 六、反馈渠道

应用内的问题在「我的 / 设置」里一般有意见反馈入口；官网 [unidreamapp.com](http://unidreamapp.com/) 的支持中心也可以留言。安装环节卡住的话，直接看 [下载与安装教程.md](下载与安装教程.md) 第四节。
