## 一、安装前先看这份信息

| 项目 | 内容 |

| 适用系统 | Android 5.1 及以上（以官方商店页面为准） |
| 开发者 | 广州光锥元信息科技有限公司 |

两点说明：

- 上表是**网盘里这一份安装包**的实际情况。应用商店里的版本通常更新，功能与界面可能略有差异；想用收录的 3.7.1 版，就从网盘拿。
- 手机里已经装过旧版 UniDream 的话，一般可以直接覆盖安装；提示「签名不一致」时，先把旧版卸载再装。

## 二、从夸克网盘拿到安装包

1. 打开 **[UniDream 安装文件资源（夸克网盘）](https://pan.quark.cn/s/189c6415ef4d)**（手机上建议用夸克 App 打开，浏览器也可以）。
2. 选中文件后**转存**到自己的网盘，或直接下载。
3. 转存后在网盘里找到这个文件，点**下载**，等进度走完。安装包 147 MB 左右，建议在 Wi-Fi 下进行。

## 三、安装步骤

1. 在手机文件管理或通知栏里找到下载完成的 `.apk` 文件，点它。
2. 系统询问「是否允许安装来自此来源的应用」时按提示允许（不同品牌叫法略有差别，以 MIUI 为例在「更多设置 → 应用管理 → 特殊应用权限 → 安装未知应用」里开）。
3. 回到安装界面点「安装」，等待几十秒。
4. 装完点「打开」。首次启动可能要加载资源、申请权限，允许它访问照片与媒体文件，否则生成后的图保存不到相册。

## 四、装不上时的几种常见情形

| 提示 / 现象 | 原因 | 处理 |
| --- | --- | --- |
| 解析包时出现问题 | 下载不完整或传输中损坏 | 删掉重下；经 PC 中转的话先核对 MD5（见下节） |
| 签名不一致 / 无法覆盖安装 | 手机里有另一个来源装的旧版 | 卸载旧版（先备份需要保留的作品）再装 |
| 存储空间不足 | 剩余空间小于安装包加运行余量 | 清出至少 3~4 GB 再试 |
| 系统版本过低 | Android 版本低于要求 | 升级系统，或换满足要求的设备 |
| 安装一直卡住 | 安装器被暂停或手机过热 | 清后台后重试 |

安装成功但用的时候出问题，去 [常见问题排查.md](常见问题排查.md) 按现象对号入座。

## 五、可选：核对安装包 MD5

想确认手里这份包和收录时完全一致，可以校验 MD5，正确值是 `09C216BAD4DAAE174C09F2FAD7ED1223`。

把安装包拷到 Windows 电脑后，在文件所在目录执行：

```text
certutil -hashfile unidream_v3.7.1.apk MD5
```

输出中那串十六进制与上面一致即通过。手机上也可以用带「文件校验」功能的文件管理器算一遍。

装好之后，从 [文生图入门教程.md](文生图入门教程.md) 开始上手。
