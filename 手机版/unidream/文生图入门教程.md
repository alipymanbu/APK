## 一、还没装好的先看这里

UniDream 是一款 AI 绘画应用：你输入一句描述，它按你选的风格把图画出来，也支持拿现成图片改风格。手机版安装包可从 [UniDream 安装文件资源（夸克网盘）](https://pan.quark.cn/s/189c6415ef4d) 获取，安装步骤见 [下载与安装教程.md](下载与安装教程.md)。装好后打开应用，首页能看到几类入口：文生图（AI 梦境 / 艺术作品生成）、图生图、改图等，不同版本的入口名称可能略有差别，以应用内实际显示为准。

## 二、第一次生成：完整流程

1. 首页选择文生图入口。
2. 在描述框里写下你想画的内容，例如「白雪皑皑的山坡」「海上飓风与小船」「由新海诚绘画的一条美人鱼」——这是官方给出的几个示例，直接照填也能出图。
3. 选画布比例（1:1、9:16 之类）。
4. 选一种艺术风格。
5. 点「开始绘画」，通常等十几秒；高峰期会更久。每次生成会消耗一次额度（免费额度每天签到可领，口径见 [会员与免费额度说明.md](会员与免费额度说明.md)）。
6. 出图后点图上的预览（小眼睛）图标放大看效果，满意就点右上角保存或分享。

写描述没头绪时，看看生成页里有没有这些辅助：**咒语生成器**（从现成的描述词库里挑着组合）、**AI 智能扩写**（把你的一句话自动补写丰富）、**随机灵感**（抽一个方向再改）。这些辅助随版本差异较大，以应用内实际有没有为准；没有的话，照 [提示词写法技巧.md](提示词写法技巧.md) 的结构自己写也不慢。

## 三、画布比例与风格怎么选

| 用途 | 建议比例 |
| --- | --- |
| 头像、朋友圈方图 | 1:1 |
| 手机壁纸 | 9:16 竖版 |
| 电脑桌面、横幅 | 16:9 横版 |

风格决定整张画的画风：二次元 / 动漫、写实、油画、水彩、印象派等都在可选之列，应用里也会不定期上新节日主题风格，以应用内风格列表为准。同一句描述换一个风格再画一次，是快速找到自己喜欢效果的办法。

## 四、生成之后能做什么

- **保存 / 分享**：出图页右上角可以直接存到手机或分享出去。
- **投稿**：把作品投到社区里，其他人能看到、也能参考你的描述词。
- **尝试同款**：刷到别人的作品时，可以基于同一句描述、同一风格生成属于你的一张。
- **继续加工**：画面局部不满意就进改图；想换整体风格走图生图，两条路都写在 [图生图与局部修改教程.md](图生图与局部修改教程.md) 里。

## 五、出图慢或等待很久怎么办

生成要排队，高峰期等上几分钟属正常。超过平时的等待时间还在转圈，先检查网络，再退回首页重进一次；反复出现的话按 [常见问题排查.md](常见问题排查.md) 的「生成一直转圈 / 等待时间异常」一节查。

描述词写得好不好，直接决定出图像不像你想要的东西——下一步建议读 [提示词写法技巧.md](提示词写法技巧.md)。
