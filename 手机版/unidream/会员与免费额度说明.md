## 一、免费能用到什么

- 应用免费下载，基础的文生图、图生图都能免费体验。
- 官方给免费用户的机制是**每日签到领免费绘画卡**：每天可以领一张，用它先试效果再决定要不要付费。签到入口在应用内的活动 / 任务页，具体形式以应用内实际显示为准。
- 每次生成消耗一次额度，部分高级功能消耗得更快；额度计数以应用内显示为准。

先把免费额度用在刀刃上：描述词写得越准，试错次数越省，参考 [提示词写法技巧.md](提示词写法技巧.md)。

## 二、订阅与价格

| 项 | 口径 |
| --- | --- |
| 国际版订阅价 | 每月 4.99 美元或每年 24.99 美元（应用商店页展示，截至本篇整理时；以商店页 / 应用内当时展示为准） |
| 付费形式 | 有月订、年订；也有用户提到过终身买断选项，以应用内实际档位为准 |
| 国内版价格 | 以应用内实际展示为准，档位与国际版不一定相同 |
| 自动续费 | 订阅到期前会自动续扣；不想续就在手机系统的订阅管理里关闭（iPhone 在「设置 → 账户 → 订阅」，安卓看你当时的支付渠道） |

## 三、额度用完了怎么办

1. 等次日签到把免费额度补回来，这是最常规的路。
2. 检查是不是重复生成了同一版：换风格重画、微调描述都会各扣一次，想清楚再点。
3. 出图后先把满意的存到相册，避免回头为找回同一张再花额度。

## 四、订阅前值得知道的几件事（用户反馈汇总）

以下都是来自应用商店评论区用户反馈的个案，供参考、不构成结论：

- 有买了会员甚至终身买断的用户反馈，生成次数仍存在上限、补充周期不明确——所以**下单前先用免费额度把常用功能都试一遍**。
- 有用户反馈换机或重装后出现过会员状态没恢复的情况，购买凭证要留好，出问题找官方客服处理。
- 评论区还反馈过内容审核趋严的情况（2026 年前后），部分描述会被拦下；这属于平台规则，跟是否付费无关。

价格、额度规则这类信息随时会调整，**一律以应用内当时展示为准**。安装环节的问题回 [常见问题排查.md](常见问题排查.md)，还没装的话从 [下载与安装教程.md](下载与安装教程.md) 开始；第一次上手生成看 [文生图入门教程.md](文生图入门教程.md)。
