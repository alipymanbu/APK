## 一、打开一首谱之后你会看到什么

选好歌进入谱面页，屏幕主体是横向滚动的六线谱，播放时光标逐拍前进，声音是应用内置的仿真吉他音色在演奏，不用你自己开伴奏。谱面开头第一小节旁会标这首歌的调弦方式，非标准调弦（比如 Drop D）一眼能看出来。

一首歌通常不止一条音轨：主音吉他、节奏吉他、贝斯、鼓常常各占一轨。播放器下方的调音台（Mixer）负责所有音轨的显隐与音量。

## 二、练琴用得上的几组控制

**跟原曲对照**（这是官方之外很多播放器做不到的一点）：可以把播放音源换成同步的原曲音频，你跟着真歌一起弹，检查自己的节奏。

**变速**：放慢播放速度且不改变音高。新歌先 0.5 倍速把指法顺下来，再逐步加回原速，这是最典型的用法。

**循环**：圈定几个小节反复播放，抠 solo 或过渡句时全靠它，不用每次手动拖回起点。

**Solo 与静音**：Solo 是只听你正在学的那一轨，其余全消掉；静音是把自己那轨消掉、保留乐队其他声部当伴奏跟着弹。两者配合：先用 Solo 听熟，再切静音跟练。

**准备拍数（Count-in）与节拍器**：播放前给你几拍预备时间，避免按下播放立刻手忙脚乱。

**变调（Pitch Shift）**：整体移动播放音高。歌是降半音调弦而你手上的琴是标准调弦时，用它把播放音高抬上来对齐，不用真的重新调琴。

其中变速、循环、Solo、静音、变调、Count-in 属于 Plus 订阅功能，免费与付费的完整对照见[免费与付费功能区别](免费与付费功能区别.md)。

## 三、鼓谱与特殊说明

- **看鼓谱**：谱面标题下方有一排小图标，点鼓棒图标即可把谱面切换成鼓的记谱显示。
- **音轨自动切换**：一首歌里同一把吉他的段落分散在多轨（清音、失真交替）时，桌面浏览器和手机浏览器版可以开自动切轨，播放到哪段自动跳到对应音轨；这个开关在安卓**应用**里没有，属于浏览器版功能。
- **钢琴与管乐玩家**：六线谱对钢琴、管乐基本没有参考价值，个别谱子带钢琴轨也只是方便用吉他去弹那些段落，官方没有传统五线谱记谱。
- **尤克里里玩家**：曲库里尤克里里谱很少，多数人是在吉他谱上借位按弦。

## 四、桌面端快捷键（手机浏览器同样适用）

在电脑浏览器或手机浏览器上使用 Songsterr 网页版时，这些快捷键可用：

| 按键 | 作用 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| Backspace | 回到开头 |
| 左 / 右方向键 | 光标前移 / 后移 |
| 上 / 下方向键 | 光标行上移 / 下移 |
| T | 显示音轨 |
| S | 切换播放速度 |
| L | 循环开 / 关 |
| Alt + M | Solo 开 / 关 |
| M | 当前轨静音 / 取消 |
| C | Count-in 开 / 关 |
| N | 节拍器开 / 关 |

双击某一拍可直接从那一拍开始播。安卓应用内的操作以触屏为主，功能入口与上表一一对应。

## 五、声音和预期不一致时

先查两件事：一是当前轨是不是被静音了（调音台里看图标）；二是这首歌是否非标准调弦（谱首标注），音高对不上多半是这个原因。仍解决不了的，去[常见问题与故障排查](常见问题与故障排查.md)。想把打开过的谱缓存下来离线练，看[离线看谱与收藏同步](离线看谱与收藏同步.md)。
