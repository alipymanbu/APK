## 一、播放相关的核心设置

设置页从导航抽屉进入，下面这些选项值得先过一遍：

| 选项 | 作用与取值 |
| --- | --- |
| Playback engine | 播放引擎在 ExoPlayer 与 MediaPlayer 之间切换 |
| Gapless playback | 无缝播放，两首歌之间不留空隙（安卓 4.1+） |
| Crossfade | 交叉淡入淡出，时长 500 毫秒到 15000 毫秒可调 |
| Keep shuffle mode | 开启后点单曲也保持随机模式；关闭后点单曲即顺序播放 |
| Playback position | 记住长音频的播放位置，听播客、有声书很有用 |
| Bluetooth autoplay | 连上蓝牙音频设备后自动开始播放 |
| Disable car autoplay | 禁止连上车机蓝牙后自动播放（部分车型上无效） |
| Sound balance | 调整耳机左右声道平衡 |
| Last.fm scrobbling | 把收听记录自动上报到 Last.fm，开启步骤见[Last.fm收听记录上报设置.md](Last.fm收听记录上报设置.md) |

音频焦点方面还有一个「降低音量」开关：来通知或导航播报时，把音乐临时压低而不是完全暂停。

### 引擎怎么选

1.13.1 版起设置里出现了引擎切换。日常使用保持默认即可；如果你遇到播放卡顿、无缝播放不生效、某些格式放不出来这类问题，切换到另一个引擎再试，多数情况下能解决。两种引擎的取舍是：一个更新、对新格式和各机型的表现更一致；一个是安卓自带的老引擎，个别老机型上反而更稳。

### 交叉淡入淡出的三个限制

- 只对本地播放、正常倍速播放生效。
- 需要先开启无缝播放（安卓 4.1 以上）。
- 时长从 500 毫秒到 15000 毫秒，听现场专辑或串烧时比较明显。

## 二、睡眠定时器与音量均衡

- **睡眠定时器**：睡觉前听歌可以设定时器，到点自动停止播放。入口在主界面和正在播放页的工具栏里：打开后输入时长（如 20 分钟）点「set」生效；再次打开同一菜单点「stop」取消；勾选「play last song to end」则是把当前列表放完再停。
- **ReplayGain 音量均衡**：按文件里预写的增益标签拉平歌曲响度，模式选择与前提条件见[音量均衡ReplayGain设置.md](音量均衡ReplayGain设置.md)。

## 三、主题

主题在设置页更换，两个版本合计 20 个预置主题，分深色、浅色两类，免费版可用其中 4 个基础主题。换主题前可以先在预览对话框里看效果；选定后立即生效，不需要重启应用。设置页里还有应用信息、反馈入口（官方支持邮箱与论坛帖）等常规项。

## 四、免费版与 Pro 版的功能分界

免费版没有试用期，可以一直用，和 Pro 版是两个独立应用。分界如下：

| 功能 | 免费版 | Pro 版 |
| --- | --- | --- |
| 无广告、无缝播放、文件夹浏览、桌面小部件 | 有 | 有 |
| 智能播放列表、睡眠定时器 | 有 | 有 |
| ID3 标签编辑、Last.fm 记录 | 有 | 有 |
| Chromecast 投屏、Android Auto | 有 | 有 |
| 基础主题 | 4 个 | 4 个 |
| 额外主题 | 无 | 16 个 |
| 主题自定义 | 无 | 有 |
| 5 段均衡器、9 组预设 | 无 | 有 |
| 低音增强、混响 | 无 | 有 |

两个结论直接说清楚：

1. **在免费版里找不到均衡器不是故障**——均衡器只在 Pro 版里，免费版没有这个功能；Pro 版音效页里的均衡器、低音增强、混响等具体用法见[均衡器与音效设置.md](均衡器与音效设置.md)。
2. Pro 版在 Google Play 上是付费应用，购买记录绑定谷歌账号，同一账号的多台设备不用重复购买。如果买了 Pro 版：先启动 Pro 版让它自动迁移免费版里的收藏、播放历史等数据，迁移完成后再卸载免费版。

没有谷歌框架或不想付费的用户，用免费版即可，功能边界就是上表。安装包获取见[下载与安装教程.md](下载与安装教程.md)（相关链接在文首）。
