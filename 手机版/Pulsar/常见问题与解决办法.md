# Pulsar Music Player 常见问题与解决办法

> 本篇汇总 Pulsar 实际使用中最高频的几类问题：扫不到歌、播放中途停、随机/顺序不对、投屏中断、媒体库错乱，全部给出可执行的步骤。

## 一、新歌或整批音乐扫不出来

按顺序做三件事：

1. **先手动重扫**：工具栏点「Rescan library」。可以切到后台挂着让它慢慢扫。注意扫描只发现新增文件，不会更新已有歌曲的信息。
2. **确认格式受支持**：Pulsar 播放能力跟随安卓系统，个别小众格式（如某些 ape、dsf）系统本身不支持就放不了，完整清单见安卓官方媒体格式说明页：[https://developer.android.com/guide/topics/media/media-formats.html](https://developer.android.com/guide/topics/media/media-formats.html)。
3. **还不行就重建系统媒体库**：见本篇第六节。

另外，如果扫出来的是铃声、通话录音这类不想要的音频，不用删文件，把所在目录加入排除列表即可，做法见[排除文件夹与曲库整理.md](排除文件夹与曲库整理.md)。

## 二、播放几分钟后自动停

最常见的根源是系统电池优化把后台播放杀掉了。官方 FAQ 给出的三步：

1. 系统设置 → 电池 → 电池优化，找到 Pulsar，选「不允许优化（Don't optimize）」。
2. 如果你的机型没有这一项：设置 → 应用 → Pulsar → 电池，改成「不受限制（Unrestricted）」。
3. 设置 → 应用 → Pulsar → 通知，打开「显示通知」和「媒体播放」选项。

国产深度定制系统（如省电策略更激进的机型）可能还要额外把 Pulsar 加入后台白名单、锁定后台，路径因机型而异，但方向一致：别让系统杀它。

## 三、想顺序播放，却一直在随机

- 直接点列表里的第一首歌就是顺序播放；那个大的悬浮随机按钮才是乱序入口。
- 如果点单曲也进随机：去设置的播放选项关掉「Keep shuffle mode（保持随机模式）」，详见[播放设置与音效选项.md](播放设置与音效选项.md)。

## 四、投屏（Chromecast）找不到设备或中途断开

| 现象 | 处理 |
| --- | --- |
| 找不到投屏设备 | 确认手机用的是 Wi-Fi 而不是蜂窝网络，且和投屏设备在同一个 Wi-Fi |
| 投几分钟就断 | 系统设置 → Wi-Fi → 高级 → 休眠时保持 Wi-Fi 连接 → 选「始终（Always）」 |
| 反复中断 | 投屏期间保持手机屏幕常亮 |
| 仍被杀后台 | 按本篇第二节处理电池优化 |

## 五、车载（Android Auto）上找不到或不显示

Pulsar 支持 Android Auto：车机上可以浏览专辑、艺术家和文件夹视图，播放页带随机/循环按钮，专辑与艺术家封面也会显示（以上为官方更新日志列出的能力）。

车机上不显示 Pulsar 或列表加载不出来时，按通用排查顺序检查：

1. 手机上打开 Android Auto 应用 → 「自定义启动器（Customize launcher）」里确认 Pulsar 已勾选。
2. 设置 → 应用 → Pulsar → 电池，改为不受限（同本篇第二节）。
3. 把 Pulsar 和 Android Auto 都更新到较新版本再连——官方更新日志显示 1.12.12 修复了曲库很大时 Auto 加载报错的问题，1.13.10 又修复了一批兼容性问题，老版本遇到这类情况先升级。

## 六、媒体库信息错乱：重建系统媒体数据库

曲库显示混乱（重复条目、信息张冠李戴）时，重建系统媒体库值得一试。这一步只重建系统媒体数据库，不会动你的音乐文件：

1. 设置 → 应用 → 右上角三点菜单 → 显示系统应用。
2. 找到「Media Storage（媒体存储）」→ 清除数据。
3. 重启手机，等几分钟让媒体库重建，再打开 Pulsar 重新扫描。

## 七、在 SD 卡上编辑标签报权限错误

安卓 4.4 的 SD 卡对应用只读，无法改标签；安卓 5.0 以上按 Pulsar 弹出的系统流程授予写 SD 卡权限即可继续编辑。标签编辑的完整用法见[播放列表与标签编辑.md](播放列表与标签编辑.md)。

## 八、找不到想要的功能

最典型的是均衡器：**免费版没有均衡器**，5 段均衡器、9 组预设、低音增强、混响都在 Pro 版里，分界表见[播放设置与音效选项.md](播放设置与音效选项.md)，Pro 版音效页的用法见[均衡器与音效设置.md](均衡器与音效设置.md)。其余功能开关基本都能在设置页里找到。
