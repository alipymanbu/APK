## 一、先确认你手里这份安装包

网盘里这份 Pulsar 安装包的实际情况如下，装完后可以核对：

| 项目 | 值 |
| --- | --- |
| 应用名称 | Pulsar（Pulsar Music Player） |
| 版本 | 1.13.11 |
| 安装包大小 | 13.51 MB |
| 包名 | com.rhmsoft.pulsar |
| MD5 | 13A2097A4F74B778F35954C440677F79 |

说明两点：

- 1.13.11 是官方更新日志里的正式版本（该版本新增斯洛文尼亚语支持）。官网现在推的最新版可能已经更高，但网盘里能拿到的是上面这一版，功能差异以官方更新日志为准。
- 支持的音频格式跟随安卓系统本身，常见格式 mp3、aac、flac、ogg、wav 都在列，完整清单见安卓官方的媒体格式说明页。

## 二、下载与安装步骤

1. 打开上面的 [Pulsar 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4548b1f88148)，把里面的 apk 文件转存或直接下载到手机。
2. 在手机文件管理里点开下载好的 apk。如果系统提示「禁止安装未知来源应用」，按提示去设置里允许你的文件管理器（或浏览器）安装应用，这一步只在安装时需要。
3. 等安装完成，点「打开」直接进入应用。

安装阶段常见的小状况：

| 状况 | 处理 |
| --- | --- |
| 提示解析包错误 | 多半是下载不完整，重新下载一次再装 |
| 手机上已有旧版本 | 直接覆盖安装即可，播放数据会保留 |
| 想确认文件没被改动 | 对照上表的 MD5 值，用文件管理器或校验工具比对 |

## 三、第一次打开要做的事

1. **授权媒体访问**：首次启动会请求访问手机音乐文件的权限（安卓 11 及以上通常显示为「音乐和音频」），必须允许，否则曲库会是空的。
2. **等首次扫描完成**：授权后 Pulsar 会自动扫描手机里的音频文件，按专辑、艺术家、文件夹、流派分类展示。
3. **没扫到歌就手动刷新**：在工具栏点「Rescan library（重新扫描曲库）」。注意扫描只负责发现新增加的文件，不会更新已有歌曲的信息。详细排查步骤见[常见问题与解决办法.md](常见问题与解决办法.md)。

扫描完成后的界面怎么用（六个标签页、正在播放页、通知栏控制），见[使用入门与界面导览.md](使用入门与界面导览.md)。

## 四、更新与卸载

- **更新**：用新版 apk 覆盖安装即可，无需先卸载；播放列表、收藏等数据会保留。
- **卸载**：直接在系统设置里卸载即可。免费版没有试用期限制，之后想再用重新安装就行。
- 如果你以后在 Google Play 购买了 Pro 版，注意先启动一次 Pro 版让它迁移数据，再卸载免费版，两者的关系见[播放设置与音效选项.md](播放设置与音效选项.md)。
