## 一、智能播放列表：自动生成，不用维护

打开导航抽屉的「Playlists」，除了你自建的列表，还有四个自动生成的智能列表：

| 智能列表 | 内容 |
| --- | --- |
| Favorites（收藏） | 正在播放页点心形按钮加入/移出 |
| Most played（最常播放） | 按播放次数自动统计 |
| Recent played（最近播放） | 按最近播放时间排序 |
| Recent added（最新添加） | 最近加入曲库的歌 |

如果你在主界面开了播放列表标签页，这四个智能列表默认排在自建列表上面；不想看到它们，在工具栏里把智能列表隐藏即可。

## 二、自建播放列表

- 新建：在播放列表页用工具栏的对应操作新建列表，再从专辑/歌曲页把歌加进去。
- 排序：按住列表里某首歌右侧的四线图标上下拖动，调整播放顺序。
- 播放：整个列表可以顺序播，也可以点悬浮随机按钮乱序播。

### 备份与恢复（换机必看）

播放列表支持备份成文件，换手机时可以直接带走：

**安卓 11 及以上**：系统限制了直接写存储的权限，备份时 Pulsar 会把你选中的列表打包成一个 zip，由你选择保存位置（比如网盘或电脑）。包内是 m3u 格式的列表文件。

**安卓 10 及以下**：备份是纯文本文件，直接放在应用数据目录：

```text
免费版：/storage/emulated/0/Android/data/com.rhmsoft.pulsar/files/playlists
Pro 版：/storage/emulated/0/Android/data/com.rhmsoft.pulsar.pro/files/playlists
```

恢复时的两个要点：

1. m3u 文件复制到新手机后，安卓系统一般会自动识别导入，不用手动恢复。
2. 如果系统没自动导入，把备份解压到 `/storage/emulated/0/Music/pulsar/playlists/`，再到播放列表页点工具栏的「Restore（恢复）」手动扫描 m3u 文件。

## 三、标签编辑：改对歌名、封面和艺术家

曲库乱（同一张专辑被拆成好几张、艺术家名不对）多半是文件标签的问题，Pulsar 内置了三类标签编辑器：专辑、艺术家、歌曲。从对应详情页进入编辑即可修改标题、艺术家、专辑、封面图等字段，改动会写回音频文件本身。

编辑 SD 卡里歌曲的标签时如果报权限错误：安卓 5.0 以上需要在弹出的系统流程里授予 Pulsar 对 SD 卡的写权限；安卓 4.4 的 SD 卡对应用只读，改不了。其他权限类问题见[常见问题与解决办法.md](常见问题与解决办法.md)。

## 四、歌词显示

歌词在正在播放页里看，支持两类来源：

- **内嵌歌词**：写在音频文件标签里的歌词（ID3 的 USLT / SYLT），其中带时间轴的同步歌词体验最好，播放时会自动高亮当前行。
- **独立歌词文件**：与歌曲对应的 `.lrc` 文件。

显示与关闭的三个入口，都只在**当前这首歌本身带歌词**时才生效：

1. 当前歌曲带歌词时，正在播放页工具栏会出现一个显示器样式的歌词按钮，点它开关。
2. 双击专辑封面图也能快速开关歌词。
3. 歌词不显示时，先确认文件是否真的带了歌词（或旁边有 `.lrc` 文件）。

注意：Pulsar 不提供歌词在线下载（版权原因），歌词需要自己随音频文件一起准备。

## 五、封面与艺术家图片

缺封面的专辑会由 Pulsar 自动从网络补齐，相关开关都在设置里：

| 开关 | 作用 |
| --- | --- |
| Show artwork | 是否显示封面与艺术家图片 |
| Download artwork | 是否联网下载缺失的封面 |
| Download only on Wi-Fi | 只在 Wi-Fi 下下载，省流量 |
| Artwork on lock screen | 播放时锁屏显示专辑封面 |

不满意的封面可以在标签编辑器里手动指定图片，改动会写回文件本身。播放相关的其余设置（无缝播放、交叉淡入淡出等）见[播放设置与音效选项.md](播放设置与音效选项.md)。
