## 一、装不上或装完打不开

按出现频率从高到低对照：

| 现象 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| 安装时提示解析错误 | APK 是否下完整 | 对照 [下载与安装教程.md](下载与安装教程.md) 的 MD5 表核对，不一致就重新下载 |
| 提示「禁止安装来自此来源的应用」 | 未知来源权限 | 在「设置 → 安全/隐私 → 安装未知应用」给浏览器或文件管理器授一次权，返回重装 |
| 安装器提示空间不足 | 可用存储 | 至少留 311.4 MB 可用空间，再额外留 100~500 MB 给更新与缓存 |
| 点图标闪退 | 系统版本与内存 | 下载页标的要求在安卓 5.2 以上（另有页面写 Android 7.0 以上），系统过旧或后台占用过高都会闪退，先重启、清后台再试 |
| 一直转圈进不去 | 网络 | 首次启动必须联网，换 Wi-Fi 或流量重试；这类应用基本无法离线使用 |

这几条是第一手游网常见问题与各下载页给出的口径，都属于通用排查；逐条试完仍不行，见最后一节的反馈渠道。

## 二、登录方式与登不上

- **能用什么登**：多个教程显示登录入口在「我的 / 立即登录」页，其中 Facebook 登录是被反复提到的方式；另有页面写支持多种登录方式，以你屏幕上实际列出的选项为准。
- **第三方账号登不上**：先确认设备上装了 Facebook 客户端且能正常登录，再回 LinkAI 走一遍；网络环境也需要能访问对应服务。
- **换手机后聊天还在不在**：对话与角色跟账号走，用同一个账号登录才能看到；没登录时产生的记录是否保留，以实际表现为准，重要的内容别只留在一处。

## 三、语言改不了 / 找不到设置

改中文的完整三步在 [界面语言怎么改成中文.md](界面语言怎么改成中文.md)。要点重复一次：入口是**左上角头像**进的设置页里的 `Language`，选完**必须点页面最下方的保存**——只选不保存，退出就还原了。

## 四、区分同名应用（最容易踩的坑）

| 你搜到的东西 | 是不是本篇这款 |
| --- | --- |
| 包名 `com.aigc.ushow.ichat`、官网 [www.linke.ai](https://www.linke.ai)、官方名 Linky AI | 是，本套文档讲的就是它 |
| `link-ai.tech` 的「LinkAI 一站式 AI 智能体平台」 | 不是，那是开发者做智能体接入与 API 的平台 |
| 名字也叫 Linky / linkyai 的其它页面 | 认包名，包名不是 `com.aigc.ushow.ichat` 就不是同一个 |
| 部分页面署名「用户自制」、包名 `com.hycl.archive` 的 Linky | 不是，包名完全不同 |

认包名不认名字，这一条能挡掉大部分「装错了」的情况。

## 六、付费与扣费疑问

该应用下载安装免费，应用内有订阅与购买项。订阅是不是自动续费、金币和订阅各管什么、价格区间多少、去哪取消续订，全部整理在 [金币怎么获得与订阅权益.md](金币怎么获得与订阅权益.md)——**遇到扣费问题先看那篇**，这里只重复最关键的一条：扣款走的是 Apple 或 Google 的订阅管理，取消入口不在 LinkAI 应用里。

## 八、电脑上能不能用

可以先用网页版 [www.linke.ai](https://www.linke.ai)（浏览器打开即可，账号与手机端同一套），不想在手机上装 APK 时它是最快的试用入口；说明见 [下载与安装教程.md](下载与安装教程.md) 第七节。
