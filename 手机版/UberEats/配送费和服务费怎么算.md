## 一、一单的钱花在哪

| 费用项 | 怎么定 |
| --- | --- |
| 菜品小计 | 菜单价，由商家定价 |
| 外送费 | 按距离、商家远近、需求情况浮动 |
| 服务费 | 通常约为购物篮金额的 10%，按没用优惠折抵前的总额计算，可能有上下限 |
| 小额订单费 | 订单金额低于门槛时收取，金额各商家不同 |
| 小费 | 自愿，100% 归外送员，见[小费怎么给能给多少](小费怎么给能给多少.md) |
| 税费 | 按所在地区规则收取 |

这些项目在下单前的费用信息页都列得出来，选商家之前就能看到外送费是多少。

## 二、外送费为什么时高时低

按官方说明，外送费主要看三件事：

- **距离**：离得越近越便宜，选店前就会显示金额；
- **需求**：高峰期外送员不够时，高需求区域的外送费会上浮，商家名和结账页会出现闪电符号提示；
- **配送方式**：选「优先」要多付一笔，选「稍等」可以换更低的外送费。

## 三、服务费

- 通常按订单商品金额的约 10% 收，计算基数是**没用任何优惠折抵之前**的总额；
- 可能有最低或最高限额，具体以费用信息页显示为准；
- 不同地区、不同商家类型（餐厅 / 生鲜杂货）的口径可能不同，以结账页为准。

## 四、小额订单费

- 订单金额低于某个门槛时收取，多数餐厅都有这条，金额由商家自定；
- 官方给的免掉办法很直接：**再加几件商品，把金额凑过门槛**就不收了；
- 门槛和金额各地区、各商家不一样，以结账页显示为准。

## 五、下单时的预授权扣款

用信用卡或借记卡付款时，下单瞬间会先产生一笔「预授权扣款」（authorization hold）：

- 它只是确认卡能扣成功，不是实际扣款；
- 在账单上会短暂显示为待处理交易，通常 3~10 个工作日内消失；
- 取消订单后看到的待处理款项，同样是预授权在走撤销流程，见[取消订单和退款要多久](取消订单和退款要多久.md)。

## 六、想少花一点，能做的是这几件

- 凑单过小额订单门槛，免掉小额订单费；
- 不赶时间就选「稍等」档，用等待换低外送费；
- 避开闪电符号标记的高需求时段或商家；
- 部分地区有会员类方案（Uber One）可免外送费、降服务费，值不值要先算自己的订单频率，见[UberOne会员划算吗](UberOne会员划算吗.md)。

## 七、常见疑问

- **为什么账单上有两笔？** 一笔是预授权、一笔是实扣，预授权会在几天内消失，不是收了两次钱；
- **优惠码在哪输？** 「账户 → 优惠（Promotions）」里查看详情和添加优惠码，折扣规则以页面说明为准；
- **付款方式在哪加？** 「账户 → 钱包 → 添加付款方式」；
- **金额和页面显示对不上？** 先核对是不是服务费、税费、小额订单费没算进去，仍然对不上再找客服。
