## 一、能不能退，看商家接没接单

按官方的取消政策，退款比例跟着订单状态走：

| 取消时机 | 退款 |
| --- | --- |
| 商家接单之前 | 全额退款 |
| 商家接单之后、外送员取餐之前 | 部分退款（常见口径：收全单减外送费） |
| 外送员取餐之后 | 常见口径是收全款，能退的很少 |

结论只有一条：**想取消越早动手越好**，商家一旦开始备餐，能退的部分就变少了。具体比例以你所在地区取消时的页面提示为准。

另一种拿不到退款的情况与取消无关：外送员到了、联系不上你、餐送不出去，会照常扣款——等餐时保持手机畅通，处理细节见[订单迟迟不到怎么办](订单迟迟不到怎么办.md)。

## 二、怎么取消

1. 打开 App 里「订单」，找到这笔订单；
2. 进订单详情，找「帮助」或取消入口；
3. 按页面提示选取消原因，确认后系统按上面的规则算退款。

按钮的具体位置随版本可能有变化，订单详情页里按「帮助」走就能找到入口。临时想改地址不用取消，能改则改，见[地址填错了怎么改](地址填错了怎么改.md)。

## 三、退款多久到账

| 情形 | 参考时长 |
| --- | --- |
| 预授权（取消后的待处理款项） | 3~10 个工作日内撤销 |
| 信用卡 | 约 7 个工作日，视发卡行而定 |
| 手机支付（各类支付服务） | 约 7 个工作日 |
| 借记卡 | 几天到更久都有可能，个别情况长达两个月 |

到账时间的大头在发卡行和支付服务那边，平台侧处理完后只能等银行侧入账。超时没到账，先查支付方的账单明细，再带截图找客服。

## 四、为什么看到两笔扣款

下单时先有一笔「预授权扣款」用来确认卡可用，实际扣款是另一笔。两笔处理速度不同步时，账单上看起来像扣了两次：

- 预授权会在几天内自动消失，不用自己操作；
- 订单取消后，预授权同样在 3~10 个工作日内撤销；
- 确认不是预授权的陌生扣款，再按「账户有不明扣款」的流程找客服。

总金额和结账页对不上时，先去[配送费和服务费怎么算](配送费和服务费怎么算.md)把费用构成对一遍，再判断该不该找客服。

## 五、餐有问题（没送到 / 少了 / 错了）怎么办

这类不算「取消」，走的是售后：

1. 订单详情页里点「帮助」；
2. 按提示选问题类型（未送达 / 缺件 / 送错 / 质量问题）；
3. 按页面要求提交，客服团队会处理，退款或补发的口径以处理结果为准。
