# Smallpdf 压缩不到目标大小怎么办

> 报名系统、邮件附件常常限定「1MB 以内」「300KB 以内」，压完还是超标时，按这里的顺序排查与替代。

## 一、先认清一件事：没有「输入目标大小」的入口

官方帮助中心明确说过，压缩工具**故意不设任何自定义参数**——没有「压到 300KB」这种输入框，输出大小无法指定，只能压完看结果。你在别的工具里见过「目标大小」功能，在这里就是没有，不用再找。

## 二、为什么你的文件压不动

官方博客列过四类「拒绝变小」的文件，对照一下你手里的是哪种：

| 文件构成 | 为什么压不动 |
| --- | --- |
| 扫描件 / 图片型 PDF | 整个文件就是一叠图片，图片数据占绝大头 |
| 高分辨率图片 | 降采样后依然清晰，压缩算法下不去手 |
| 页数多 | 每页看着简单，叠起来基数就大 |
| 内嵌字体、矢量、图层 | 保清晰度的东西本身就是重量 |

同一页数的两个 PDF，压缩结果可以差出几倍，取决于上面哪种成分占大头。

## 三、压完还超标，按这个顺序换动作

1. **换强力档再压一次**（Pro 功能）：对扫描件、图片多的文件最有效，代价是画质下降；
2. **先删页再压**：封面、空白页、附录用「删除页面」去掉，再重新压缩——砍内容永远比压算法狠；
3. **拆成几个小文件**：一个 450KB 的文件不如两个 300KB 的好传，某些系统还只认单文件限额；
4. **回源头重建**：手里有 Word 原稿的，别压 PDF 了，回 Word 里把图片压缩、另存为 PDF，一步到位；
5. **扫描件重新来**：重新扫描时用黑白/灰度滤镜，新文件往往比压旧的更小。

## 四、免费额度撑不起反复试

「压一次 → 看大小 → 不行再来一次」这个循环很费每日次数——免费账户每天只有一两次任务额度（商店页与帮助中心的口径分别为每天 1 次、2 次），试三轮可能就到顶了。要把文件压到达标再交付，Pro 或 7 天试用更现实，账目见 [免费额度与Pro订阅.md](免费额度与Pro订阅.md)。
