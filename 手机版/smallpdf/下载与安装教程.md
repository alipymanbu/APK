## 三、安装步骤与「未知来源」授权

从浏览器或网盘 App 安装 APK 时，安卓会拦一道「未知来源应用」，各品牌放行路径略有差异：

| 品牌 | 设置入口（常见） |
| --- | --- |
| 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装未知应用 |
| vivo / iQOO | 设置 → 安全与隐私 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 安全性和隐私 → 更多安全设置 → 安装未知应用 |

给「下载来源的那个 App」（通常是浏览器、文件管理器或夸克网盘）授予「允许安装」权限，回到安装页继续，装完桌面会出现 Smallpdf 图标。不同系统版本菜单名可能不同，找不到就搜系统设置里的「安装未知」。

## 四、校验安装包完整性（可选）

担心传输过程中文件损坏，可以在电脑上比对 MD5（手机端一般没有现成工具）：

```powershell
Get-FileHash "smallpdf_v1.84.0.apk" -Algorithm MD5
```

输出的哈希与第一节表格里的 MD5 一致，说明文件完整；不一致就重新下载一次再装。

## 五、首次启动

- App 会按需申请权限：**相机**（扫描纸质文件用）、**文件/存储**（读取本地 PDF 用）。拒绝后对应功能的入口会提示重新开启，到系统设置的「应用权限」里补授即可。
- 不登录账号也能直接用压缩、转换、合并这些基础工具；登录后才用得了云同步（Google Drive、Dropbox、OneDrive 与 Smallpdf 自家云存储）。
- 装好之后先看看每个工具能做什么：[功能与工具一览.md](功能与工具一览.md)。免费账户每天有任务次数上限，遇到「次数用完」的提示属于正常现象，处理方式见 [免费额度与Pro订阅.md](免费额度与Pro订阅.md)。

另外，如果你的设备能正常访问 Google Play，也可以直接从商店安装 Smallpdf——商店里永远是最新版，版本号会比网盘里这份高。
