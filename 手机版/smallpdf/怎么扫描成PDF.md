## 一、扫描的完整步骤

官方给的流程一共六步，在手机上依次是：

1. 打开 App，点中间的圆形（蓝色）按钮；
2. 选「用相机扫描」（Scan with camera）；
3. 对准纸质文件拍照；
4. 加滤镜、裁剪、旋转，调到字迹清楚；
5. 满意就点「使用」（Use），还要扫更多页就继续拍；
6. 全部拍完点「完成」（Done），生成一个 PDF。

多页文档的顺序是**先逐页拍完、再点完成**——这样所有页面合进同一个 PDF，而不是每页一个文件。

## 二、把扫描件拍清楚的实操点

- **光线**：均匀的正面光，避开自己的影子；逆着窗户拍最容易发灰；
- **铺平**：纸张卷边、折角会在裁剪后露出来，先压平再拍；
- **裁剪**：拍完用裁剪框贴住纸张边缘，去掉桌面、手指这些背景，成片观感立刻接近真扫描仪；
- **滤镜**：纯文字文档用黑白或灰度档，字更黑、文件更小；带印章、彩色表格的用原图或增强档；
- **分辨率**：只在需要放大看细节（票据编号、签名）时才追求高分辨率，日常归档用默认档即可。

## 三、OCR：让扫描件可搜索、可复制

扫描生成的是图片型 PDF——肉眼看得见字，搜索框里搜不到，也没法复制。OCR（文字识别）就是给这类文件「装上文字层」：

- 在 Smallpdf 里对扫描件跑一次 OCR，识别结果可搜索、可复制、可继续转换；
- 识别语言以 App 内可选项为准，中文文档先确认语言列表里有中文再跑；
- OCR 免费账户可用，但受每日次数限制；把它用在真正需要检索的文件上，别浪费在随手归档的页面上。

## 四、扫完之后常见的三条去向

| 目的 | 用哪个工具 |
| --- | --- |
| 文件太大发不出去 | 压缩（见 [怎么压缩PDF.md](怎么压缩PDF.md)） |
| 要编辑里面的内容 | 先 OCR，再转 Word / Excel |
| 需要签字盖章 | 填写签名工具直接在 PDF 上签 |

扫描结果默认存成 PDF；想换格式，打开扫好的文件，点右上角的更多选项图标，选「转换为…」（Convert to…），可选 Word、JPG、Excel、PPT。扫描原件排版复杂的，转换完先逐页核对再发——官方 FAQ 自己也承认扫描件的排版「不总能正确带过去」。

扫描失败、拍完闪退这类故障，去 [常见问题与解决.md](常见问题与解决.md) 对着排查，多数是相机权限没给够。
