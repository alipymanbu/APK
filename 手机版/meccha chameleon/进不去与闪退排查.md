## 一、症状速查表

| 你遇到的现象 | 优先怀疑 | 跳到哪节 |
| --- | --- | --- |
| 主界面点哪个按钮都弹同一个提示 | 网络没通 / 需要加速器 | 第二节 |
| 点 Play 后一直加载，进不了对局 | 网络不稳、加速器没开 | 第二节 |
| 能进房间但画面里别人画的颜色半天才出来 | 房主网络慢 / 同屏人数多 / 本机帧率低 | 第三节 |

## 二、点按钮弹提示 / 卡在加载

有用户反馈「点哪个按钮都弹同一个提示」，这类问题几乎都出在网络链路上，按顺序试：

1. **确认 Wi-Fi 能正常上网**，切换一次 Wi-Fi 与移动数据。
2. **开网络加速器后重新进游戏**。多个第三方下载站的教程第一步都写着「游戏需加速器启动」，这是进不去时最先该试的一项。
3. 加速器换了节点还是卡，**重启游戏**（完全退出后台再进），必要时重启手机。
4. 仍然进不去，卸载后按 [下载与安装教程.md](下载与安装教程.md) 重装一遍 —— 注意装之前核对包名是不是 `com.isaac.bechameleon`。

## 三、画面延迟与画笔显示不同步

对局中出现「别人画的颜色过一会儿才显示出来」，有教程的常见问题里列过三个可能原因，按这个顺序排查：

- **房主的网络速度较慢**：延迟跟房主走，换一个房主或换一局通常就好了。
- **你自己的帧率低**：在设置里关掉光影等高消耗选项、降低画质，帧率上来同步会跟上。
- **同屏人数多**：多人同时作画时游戏会主动降低同步频率来减轻负载，这是设计如此，等人少的局即可。

## 四、装不上、闪退、打不开

- **安装被拦**：先在系统设置里允许安装未知来源应用，路径见 [下载与安装教程.md](下载与安装教程.md) 第三节。
- **安装包下到一半**：285.43M 的包网络中断会留下不完整文件，装不上就重新下载，别反复点那个坏文件。
- **装完闪退**：先确认手机系统版本达到安装时的提示要求（第三方站点标注不一，有写安卓 4.3 以上、也有写 5.2 以上，以你手机的提示为准）；再看存储空间是否充足，体积大的包解压后占用会翻倍。
- **和别的同类游戏装在一起**：同玩法的其他产品包名不同（例如 `gg.com.kbf.anti.relax.game`），可以共存；如果你本来想装的就是这个包，装完到设置 → 应用列表里确认包名为 `com.isaac.bechameleon`。

## 五、房间进了陌生人 / 语音没声音

**房间进了陌生人**：创建服务器时如果**没设密码，任何人都能自由进出**（多份教程的常见问题里都提到过）。处理办法：

- 本局：踢人或直接重开一个新房。
- 下局：创建时把密码填上，把密码或房间 ID 只发给要一起玩的人，做法见 [联机开房与好友对战.md](联机开房与好友对战.md)。

**语音没声音、队友听不到你**：多半是麦克风权限在安装或首次启动时被拒了。打开系统设置 → 应用 → 找到这个游戏 → 权限 → 把「麦克风」改成允许。不同品牌菜单名不一样，有的叫「设置 → 隐私 → 权限管理」，也可以在桌面长按应用图标 → 应用信息 → 权限管理里改。只影响语音功能，不影响进对局。

## 六、有玩家反馈的已知现象

以下是玩家公开反馈里出现过的几类现象，都没有区分具体版本，遇到时先按这个思路处理：

| 现象 | 先试 |
| --- | --- |
| 点了匹配之后黑屏、只显示一张背景图 | 完全退出游戏重进；仍黑屏就按第二节查网络 |
| 当搜寻方时被门框、模型卡住过不去 | 换个角度移动或重开一局，多出现在特定位置 |
| 在某张地图里卡进一个房间出不来 | 退出本局重开；记下地图名，有更新先升到最新安装包 |
| 匹配到的对手行为像机器人 | 换个时段匹配，或开私人房叫真人朋友 |

这些属于反馈类信息，无法确认是否已在新版本修复 —— 拿到安装包后先核对版本，遇到更新优先升级。

## 七、还没解决

把「卡在哪一步、屏幕上最后一句提示是什么、用的什么网络」这三件事记下来，换个时段再试一次 —— 联机类游戏的服务器波动常有时间性，隔半小时恢复的情况很常见。若确认是安装包本身的问题，回 [下载与安装教程.md](下载与安装教程.md) 重新核对版本与包名后重装。
