## 一、一局游戏的完整流程

这游戏没有教程关，规则全靠一局打完就懂。流程固定分三段：

1. **进图与分阵营**。你和其他玩家进入同一张地图，一部分人当躲藏方、一部分人当搜寻方（具体怎么分由所选模式决定）。
2. **躲藏方有 180 秒涂色时间**。你是一个纯白小人，用内置画笔从墙上、地板上、家具上吸取颜色涂到自己身上，再摆一个姿势贴住某个位置，让自己看起来像环境的一部分。
3. **时间到，全员转为搜寻**。躲藏方不能再改伪装，只能保持静止；搜寻方开始在地图里找人，把所有躲藏者揪出来。躲藏方只要活到最后就是赢家，搜寻方则要在倒计时结束前找完所有人。

一局大概五到八分钟，输了立刻能开下一局，出局的人下局照样参战。

## 二、主界面上的三个入口

- **Play（开始）**：最常见的入口，点了直接进随机匹配，系统把陌生玩家凑齐后开局。适合一个人想随时开一局。
- **头像**：点界面上你自己的头像，会进入头像选择界面，可以换成别的形象。这只是外观，不影响对局。
- **组队图标**：界面侧边的组队入口，用于开自己的房间、拉好友进来。想和朋友玩、或者想自己控制地图与模式，走这个入口，步骤见 [联机开房与好友对战.md](联机开房与好友对战.md)。

## 三、躲藏方要做什么

躲藏方的目标不是「找个角落蹲着」，而是「让自己看起来不像人」。三个动作按顺序来：

- **先选位置**，别一进图就原地开始画（选点的重要性见 [躲藏伪装与搜寻技巧.md](躲藏伪装与搜寻技巧.md)）。
- **再吸色涂满全身**：用取色工具点一下身边的墙面或地板，拿到准确颜色，再用大笔刷把身体铺满；遇到有明暗变化的区域，分几层铺。
- **最后摆姿势**：贴墙、趴地、蜷缩都行，目的是把「人形轮廓」拆掉。伪装做完就别乱动了，倒计时结束前的任何移动都会让努力白费。

## 四、搜寻方要做什么

搜寻方拿的是观察力，不是运气：

- **优先怀疑「形状不对」的东西**：画框里多出来的一块、墙角多出的人形轮廓、桌面上不该有的立体物。
- **再看颜色与光影**：色块比周围亮或暗一档、阴影方向和房间里其他物体不一致，都是破绽。
- **靠近确认再出手**：看到可疑色块先走近看清楚，误击不扣分，但浪费的是你的时间。
- 有些角落（油画内部、吊顶、桌底、缝隙）是躲藏方的高发点位，走过时记得抬头低头都扫一遍。

## 五、基本操作对照

界面上的按钮会随版本调整，以下是各版本教程里稳定的对应关系，具体以你手机上的实际界面为准：

| 你想做的事 | 操作 |
| --- | --- |
| 移动 | 屏幕一侧的虚拟摇杆 |
| 调整视角 / 观察四周 | 滑动屏幕；有的人也会用它转到侧面看自己画成什么样 |
| 吸取环境颜色 | 打开涂色面板后用取色（吸管）工具点环境 |
| 换笔刷、调笔刷大小 | 在涂色面板里切换笔刷类型与粗细，先大笔刷铺底再小笔刷修细节 |
| 换姿势 | 打开姿势面板选站立、趴下、蜷缩、侧卧等 |
| 换头像 | 主界面点头像 |

手机屏幕小，建议先把视角灵敏度和画笔手感在设置里调顺手，再开始认真对局。

## 六、模式与地图怎么选

开房或匹配时会让你选模式，各站教程里出现过的模式名称大致是这几类：

| 模式 | 规则差异 |
| --- | --- |
| 经典躲猫猫 | 躲藏方撑到倒计时结束、搜寻方在时限内找完人，各按各自目标判胜负 |
| 感染模式 | 被找出来的躲藏方就地转为搜寻方，越到后面搜寻方越多、场面越乱 |
| 全员转搜寻 | 所有人先一起躲，时间一到一起开找，按找出的数量算成绩 |

**这些名称来自不同站点的教程，没有标明对应哪个安装包** —— 你手上这份到底有哪几种，以创建房间时模式下拉列表里实际列出的为准；第一次开房拿不准就选默认那一项，打一局自然就懂。

地图同理：列表里有哪几张就玩哪几张，不同地图的墙面纹理、光影和藏点差别很大，选点思路要跟着换（见 [躲藏伪装与搜寻技巧.md](躲藏伪装与搜寻技巧.md)）。
