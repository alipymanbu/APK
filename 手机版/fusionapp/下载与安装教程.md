## 一、装之前先弄清它是干什么的

FusionApp 是安卓上的「网页转应用」打包工具：你在里面填一个网页地址、选一套界面模板，它能直接生成一个独立安装包，装到桌面上像普通应用一样点开。适合你想把自己常去的网站、个人主页、在线工具页变成一个常驻图标的场景。

装之前注意三点：

- 它**只有安卓版**，没有对应的 iOS 版；
- 公开资料称其由酷安开发者寒歌开发（与「一个木函」同一作者），**查不到官网与应用商店页面**，所以别去找「官方最新版」对照，版本信息以拿到的安装包为准；
- 系统要求：**安卓 5.2 及以上**。

## 二、安装包从哪拿

**网盘**：[FusionApp 安装文件资源（夸克网盘）](https://pan.quark.cn/s/30a795c5e444) —— 转存到自己的网盘后直接下载到手机。

下载完对照下面第四节的 MD5 算一遍哈希，一致才说明文件传完整了。

## 三、安装步骤

1. 把 APK 传到手机上（手机浏览器直接下载，或用数据线、局域网传输）。
2. 点开文件安装。安卓会弹「不允许安装未知来源应用」，按提示对该来源放行即可（不同品牌路径略有差异，一般在 设置 → 安全/隐私 → 安装未知应用 里）；华为、小米、vivo、OPPO 等机型还会追加「未经过安全检测」之类的风险提示，这是所有非应用市场安装包都会遇到的例行提醒，装不装由你自己判断，流程上选「继续安装 / 手动安装」即可走完。
3. 装完打开，首页很空：右下角一个 **+ 号**就是创建新应用的入口，左上角是菜单。第一次从哪开始见 [网页打包成应用教程.md](网页打包成应用教程.md)。

装好后若打开就闪退、或提示版本过低，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、网盘里那份包的信息

| 项 | 值 |
| --- | --- |
| 应用名 | FusionApp（网盘文件夹名 `fusionapp`） |
| 版本 | 2.0.0-beta4 |
| 包名 | `net.fusionapp` |
| 大小 | 8.68M |
| 系统要求 | 安卓 5.2 及以上 |
| MD5 | `281049A216B96346990D9CDF87186D4D` |

几点说明：

- 包名 `net.fusionapp` 是安卓识别这款应用的唯一标识，升级也不会变；想确认手机上装的是哪一版，到 设置 → 应用管理 里搜 FusionApp 看版本号即可。
- 版本后缀 `beta4` 说明这是 2.0.0 系列的第 4 个测试版，不是正式终版；2.0.0 一系的公开更新日志提到过「增加工程打包加密」「修复工程图片显示在图库的问题」，具体到你手里这版有没有，以应用内显示的版本号为准。
- 网盘这份固定是 2.0.0-beta4，界面语言为简体中文；网上别处流传的版本号可能比它新，**以这份能对上 MD5 的为准**。
