## 一、实时画面的常用操作

在设备列表点摄像头进入实时画面，画面上常见的控件：

| 控件 | 作用 |
| --- | --- |
| 抓拍 | 把当前画面存到手机相册 |
| 录像 | 手动录一段，存手机本地 |
| 麦克风 / 喇叭 | 双向语音（见下一节） |
| 方向键 | 云台机型上下左右转动视角 |
| 画质 / 全屏 | 切清晰度、放大画面 |

夜视：光线暗下来红外灯自动开启，画面转黑白属正常；部分机型可在设置里调红外灯模式。

## 二、双向语音

1. 进实时画面，点麦克风图标。
2. 第一次会弹麦克风权限申请，允许。
3. 按住说话，松手结束，声音从摄像头喇叭播出。

听不到对方声音时，检查两处音量：手机的媒体音量（不是铃声音量）、设备设置里摄像头自己的喇叭音量。

## 三、移动侦测 / 声音侦测报警

1. 实时画面点右上角设置（齿轮）→ 报警设置。
2. 分别开移动侦测、声音侦测，按需调灵敏度：灵敏度高，报警多、误报也多。
3. 开启后，摄像头检测到动静会推消息和照片到手机。
4. 部分机型支持给报警设生效时间段，以 App 内实际出现的选项为准。

## 四、推送收不到

按顺序查：

1. **系统通知权限**：手机系统设置 → 应用 → Foscam → 通知，确认为允许（安装时拒了就在这里补开）。
2. **App 内没开报警**：回到上一节，确认移动侦测 / 声音侦测是开的。
3. **后台被杀**：不少国产手机（小米、华为、OPPO 等）默认杀后台，要把 App 加入后台白名单 / 允许自启动，否则锁屏后收不到推送。
4. 如果是画面本身打不开而不是不推送，那不是报警设置的问题，按 [摄像头连不上怎么办.md](摄像头连不上怎么办.md) 排查。

## 五、抓拍与手动录像存在哪

抓拍的图片、手动录的视频默认存在手机相册（不同版本 App 的入口名称略有差异），不需要 SD 卡，也不会自动上传云端——SD 卡与云端那套是另一条线，报警触发录像的存放位置见 [录像存储与回放.md](录像存储与回放.md)。
