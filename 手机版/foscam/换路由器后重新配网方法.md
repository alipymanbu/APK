# Foscam 换路由器后重新配网方法（改 WiFi 密码 / 搬家）

> 换了路由器、改了 WiFi 名或密码之后摄像头离线：先判断还能不能打开画面，再选「App 内改 WiFi」或「恢复出厂重加」。

## 一、先判断走哪条路

打开 App，点这个摄像头：

- **实时画面还能打开**（在家里 WiFi 下）→ 走方式一，不用恢复出厂。
- **画面打不开 / 列表里显示离线** → 走方式二，恢复出厂重新添加。

## 二、方式一：App 内直接改 WiFi

前提是网线能把摄像头接到（新）路由器上：

1. 网线把摄像头接到路由器，等一两分钟。
2. App 里打开这个摄像头的实时画面——**能打开画面这条路才走得通**，打不开就直接方式二。
3. 进设备设置 → WiFi 设置，选新的 WiFi 名，输入新密码。
4. 配置完成后拔掉网线，等几十秒，摄像头会自己连上新 WiFi。

## 三、方式二：恢复出厂重新添加

1. 先在 App 里把这个摄像头**删除**——旧记录不删，后面加不上去。
2. 摄像头通电，长按 Reset 键 12~15 秒恢复出厂。
3. 手机连上新的 WiFi，按 [添加摄像头教程.md](添加摄像头教程.md) 扫机身二维码重新配网。
4. 恢复出厂后要重设摄像头的用户名和密码：用户名最长 20 位，密码 6~12 位。

## 四、新路由器上的一个坑

不少新路由器默认把 2.4GHz 和 5GHz 合并成一个名字（双频合一），只认 2.4GHz 的机型这时候配不上网。到路由器后台把两个频段**分开成两个名字**，让摄像头连 2.4GHz 那个；配完之后路由器想改回合并模式可以，但摄像头记住的还是那个单独的 2.4G 名字。

另一类改不动的情况：这一路都试完还是离线，按 [摄像头连不上怎么办.md](摄像头连不上怎么办.md) 的逐项核对走一遍，多数是卡在 2.4G 频段和密码字符上。
