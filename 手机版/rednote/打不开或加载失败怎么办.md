# rednote 打不开或加载失败怎么办

> 本篇按故障现象给排查顺序：应用打不开、图片视频加载不出、闪退白屏、登录态异常，各自对应的处理办法。

## 一、先分清是哪一类「打不开」

| 现象 | 大概率原因 | 先做什么 |
| --- | --- | --- |
| 点图标没反应 / 闪退 | 版本与系统不匹配、缓存损坏 | 重启手机；不行再走第三节 |
| 能打开但白屏 | 网络 or WebView 异常 | 换网络（Wi-Fi ↔ 流量）再开 |
| 打开了但图片/视频转圈 | 网络慢、CDN 抖动 | 下拉刷新；换网络 |
| 提示「网络异常」但浏览器能上网 | 应用联网权限被关 | 系统设置里查应用联网权限 |
| 登录态丢失、反复要求登录 | 账号或本地数据异常 | 见第四节 |

## 二、网络与加载问题

1. **先换网络再判断**：Wi-Fi 和移动数据互切一次，能加载就是原网络的问题（公司/校园 Wi-Fi 常见对部分域名的限制）；
2. **下拉刷新或杀掉应用重开**：信息流是分页拉取的，个别请求失败会卡住整页；
3. **关掉省流模式/无图模式**：设置里的流量节省选项会让图片默认不加载，看起来像「加载失败」；
4. **系统时间要准**：手机日期时间不对会导致部分请求的证书校验失败，表现就是网络类报错，开「自动获取时间」即可。

## 三、应用本身的问题

按代价从小到大：

1. **清缓存**：系统设置 → 应用管理 → rednote → 存储 → 清除缓存（注意是「缓存」，不是「清除数据」，后者会清掉登录态）；
2. **检查剩余空间**：剩余空间低于 1 GB 时大应用容易闪退，清出空间再试；
3. **升级版本**：老版本在系统升级后常出现兼容问题，商店里更新到最新（官方最新版本号以商店页面为准，写作时已高于 9.32.0）；
4. **覆盖重装**：直接重新安装一份 APK 覆盖，安装文件获取方式见 [下载与安装教程.md](下载与安装教程.md)；同包名覆盖不会丢登录态，但为稳妥起见先确认能收到验证码；
5. **老机型最后手段**：Android 5.0~7.x 的设备如果清缓存、重装都无效，多半是系统 Web 组件过旧导致白屏，这类只能升级系统或换设备解决。

## 四、登录与账号类异常

- **提示账号异常**：先退出登录再重新登录；用的是第三方登录（微信/Apple/Google）就换回当初注册的那个方式；
- **换设备后登不上**：验证码登录最直接，流程见 [注册与登录方法.md](注册与登录方法.md)；
- **反复闪退到无法操作**：换一台设备先登同一账号改密码，再回来重装登录。

## 五、重装前的两个提醒

1. **rednote 与小红书同包名**，重装覆盖即可，不存在「两个都装」；关系的详细解释在 [和小红书什么关系.md](和小红书什么关系.md)；
2. 清除数据/卸载重装会丢本地草稿与离线内容，重要草稿先发成「仅自己可见」的笔记再操作。
