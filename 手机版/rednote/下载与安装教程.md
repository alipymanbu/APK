## 一、安装前先确认三件事

| 检查项 | 参考值 | 说明 |
| --- | --- | --- |
| 系统版本 | Android 5.0 及以上 | 第三方应用商店口径，以官方商店页面为准；系统过老会装不上或频繁闪退 |
| 存储空间 | 至少留 1~2 GB | 本篇对应的安装文件约 150.31 MB，安装后解压展开占用更大，后续缓存还会持续增长 |
| 安装渠道 | 官方商店或可信来源 | rednote 与小红书是同一个应用（包名 `com.xingin.xhs`），认准官方渠道，避免装到改名换皮的仿冒应用 |

## 二、从官方应用商店安装

这是多数人的首选，更新由商店托管：

- **Google Play**（海外设备）：搜索 `rednote` 或 `Xiaohongshu`，开发者显示为行吟信息科技（上海）有限公司。
- **国内应用商店**：国内安卓商店通常以「小红书」名称上架，直接搜「小红书」即可 —— 装的就是同一个应用，只是商店里用的名字不同。rednote 与小红书的关系见 [和小红书什么关系.md](和小红书什么关系.md)。

装完打开，按提示注册或登录，流程见 [注册与登录方法.md](注册与登录方法.md)。

## 三、从安装文件（APK）安装

什么时候需要这条路：设备上没有 Google Play、商店里搜不到、或者你想固定用某一个版本不被自动升级。

**1. 拿到安装文件**

本文以 9.32.0 这一版安装文件为例，它的核对信息如下，拿到包后可照此验证：

| 项目 | 值 |
| --- | --- |
| 版本 | 9.32.0 |
| 安装包大小 | 150.31 MB |
| 包名 | `com.xingin.xhs` |
| MD5 | `F605491516BEAF3D5269D4D9AFD9224A` |
| 适用平台 | 安卓（arm64-v8a / armeabi-v7a） |

rednote 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/02b63020677e](https://pan.quark.cn/s/02b63020677e)。转存到自己网盘后即可下载到手机。

**2. 核对文件（可选但建议）**

如果你在意包的完整性，可以在电脑上用命令核对 MD5 是否与上表一致：

```powershell
Get-FileHash "下载路径\rednote_v9.32.0.apk" -Algorithm MD5
```

**3. 安装步骤**

1. 把 APK 传到手机存储，用系统文件管理器点开；
2. 系统弹「禁止安装未知来源应用」时，按提示允许该文件管理器安装应用（各品牌设置入口不同，一般在弹出框里直接点「设置」→ 打开开关）；
3. 回到安装界面点「安装」，等待完成；
4. 打开应用，首次启动会请求网络、存储、相机等权限，按需授予。

**4. 一个容易懵的点：已装了小红书怎么办**

rednote 和国内版小红书是**同一个包名** `com.xingin.xhs` 的同一个应用。所以：

- 手机上已装小红书 → 再装这份 APK 等于**覆盖更新**，登录状态和本地数据一般会保留，图标名称可能变成 rednote 或维持原样（取决于系统语言与版本）；
- 已装 rednote → 商店里看到「小红书」有更新，直接升级也是同一个应用，不会变成两个。

不存在「同时装 rednote 和小红书两个」的情况，别被「双开」类说辞带偏。

## 四、安装失败或装完打不开

按出现顺序排查：

1. **提示「解析包出错」**：安装文件下载不完整，重新下载一次并核对大小是否约 150.31 MB；
2. **提示「与应用不兼容」**：系统版本低于要求，确认 Android 版本；
3. **进度条卡住或中途失败**：清一下存储空间，重启手机再装；
4. **装上了但闪退/白屏**：多与机型、系统 WebView 或网络环境有关，逐条试 [打不开或加载失败怎么办.md](打不开或加载失败怎么办.md) 里的排查步骤。

另外，本文写作时官方商店的版本已高于 9.32.0（第三方商店显示约 9.47，2026 年 9 月下旬口径），以官方页面为准。用商店安装的用户直接升级即可，不必追平某个具体版本号。

## 五、确认自己装的是哪个版本

排查问题或对照教程前，先看版本号：打开应用，进入「我」→ 右上角菜单 →「设置」→「关于小红书」（入口名随版本略有差异），里面会显示当前版本号。商店更新的用户版本号会持续前移，用 APK 安装的用户停在安装时的那个版本 —— 这也是「同一篇教程，你的界面和别人的不一样」最常见的解释。
