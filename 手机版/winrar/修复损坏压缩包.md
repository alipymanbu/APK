# WinRAR 手机版修复损坏压缩包指南

> 压缩包解到一半报错、提示文件损坏时，先别急着重下。本篇讲用 WinRAR（应用正式名 RAR）自带的修复命令处理损坏的 RAR 与 ZIP 压缩包，以及什么情况下修得好、修不好时怎么办。

## 一、修复功能能做什么

修复命令对 **RAR 与 ZIP** 两类压缩包都可用，但修复效果跟压缩包本身的「底子」直接相关：

| 压缩包情况 | 修复预期 |
| --- | --- |
| RAR5 格式且打包时带了恢复记录 | 效果最好。这类包的修复能力官方做过专门增强，能处理数据错位、内容丢失这类较大范围的损伤 |
| 打包时生成过 `.rev` 恢复卷 | 某个数据卷损坏时，恢复卷可以把缺的数据补回来（补卷规则见下一节） |
| 没带恢复记录的 RAR / ZIP | 也能跑修复命令，但结果不保证，能否救回取决于损坏的位置与程度 |

所以「修得好不好」有一半取决于当初打包的人有没有留恢复记录；你自己打包时建议加上，做法见 [压缩文件与分卷打包.md](压缩文件与分卷打包.md)。

## 二、恢复卷能补几个卷

`.rev` 恢复卷只在**分卷压缩包**上生效，规则来自 RAR 工具族的通用文档：

- 每个恢复卷能重建**一个**缺失或损坏的卷。比如 30 个卷配 3 个恢复卷，任意缺 3 卷都能补回来。
- 恢复卷数量少于缺失数量时，重建就不可能了——所以重要任务多配几个恢复卷不亏。
- RAR5 格式的恢复卷比被保护的卷略大，因为它额外存了这些卷的校验信息。
- 生成恢复卷之后原卷不能再改动（包括加锁），改过之后恢复流程会失效。

安卓端的具体操作入口以应用内实际提供的为准；分卷本身怎么解，见 [分卷压缩包怎么解.md](分卷压缩包怎么解.md)。

## 三、修复步骤

1. 在文件列表里勾选要修的压缩包。
2. 点右上角三点菜单，找到**修复**命令（测试、修复、基准测试都在这个菜单附近）。
3. 确认后应用开始处理，完成后会生成一个新文件，原文件不会被覆盖。
4. 对修复出来的新文件再跑一次解压，能完整解开就说明救回来了。

修复前建议先跑一次**测试**命令：先确认到底是不是真损坏，避免把「密码不对」「分卷缺失」当成损坏白修一轮。

## 四、修不好时的三条路

- **换源重下**：损坏多数发生在传输环节，从原下载处重新拿一份，常常一步到位。
- **补齐分卷**：分卷包缺卷时报的错跟损坏很像，先把所有卷凑齐、放进同一目录，再判断要不要修。
- **交叉验证**：换一个解压工具打开同一份文件；如果别的工具也报错，基本可以确定问题在文件本身，不在工具。

解压报错现象与原因的完整对照，整理在 [解压失败与常见问题.md](解压失败与常见问题.md)。
