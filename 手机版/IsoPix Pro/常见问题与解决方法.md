## 一、这是什么场景

使用 IsoPix Pro 过程中卡住了：装不上、打不开、找不到东西、少个功能。本篇按「症状 → 原因 → 处理」给判断依据，安装步骤本身见[下载与安装教程.md](下载与安装教程.md)。

## 二、安装类

**症状：提示「解析包时出现问题」或安装中止。**
按顺序排查：① 下载是否完整（核对大小是否 0.85M、MD5 是否 `BA18AB5B3ADD91C6F9702ABC380A42EC`）；② 系统是否低于安卓 5.2——这份包要求 5.2 以上，低版本装不上；③ 存 APK 的路径是否在系统临时目录或被清理软件动过，换个目录重下再装。

**症状：点了安装没反应 / 被拦下。**
这是未知来源拦截：按弹窗指引给当前安装来源（文件管理器或浏览器）临时放行，装完再关。不同品牌手机入口不同，一般在「设置 → 安全/隐私 → 安装未知应用」。

## 三、运行类

**症状：点图标闪退或黑屏。**
按顺序排查，每做一步试一次，不行再做下一步（这是各手机厂商支持文档通用的排查顺序）：
1. 核对设备满足安卓 5.2 以上、装的是完整未损坏的包（核对方法见上一条）；
2. 强行停止后重开：长按应用图标 → 应用信息 → 强行停止，再打开；
3. 清理后台、重启手机，排除临时性卡顿；
4. 检查存储空间：手机可用空间长期见底会导致应用异常退出，留出余量再试；
5. 清除缓存：应用信息 → 存储 → 清除缓存（缓存不含你的图；**清除数据会删掉应用内的设置，先确认没存过的东西已经存过**）；
6. 卸载后重新安装（重装前确认已保存的作品在【储存图档】选的位置有文件）。

官方发布说明提到曾在 1.4.5 修复「选择要载入的文件时可能出现的错误」——若你的闪退**只发生在打开文件选择器时**，先核对手上版本号是否低于 1.4.5，是否更新以官方页面当时显示为准。

**症状：画着画着卡住不动。**
先等几秒再操作，部分操作会有短暂无响应；仍不动就返回重进——没有存过的图会丢，重要图随时【档案】→【储存图档】存一版，这是最可靠的习惯。

## 四、界面与显示类

**症状：界面全是英文。**
界面语言跟随安卓系统语言：把系统语言设为中文，重启应用后菜单即为中文（档案、设定/帮助等）。这不是应用内的多语言开关，应用本身没有单独的语言选项。

**症状：看不清像素格 / 格线颜色碍眼。**
到【设定/帮助】里开像素网格；Pro 版还能自订网格大小与颜色。想让界面直接显示文件与图像信息，也是设定里的一个显示开关（Pro 功能）。

## 五、功能找不到类

先确认你装的是 Pro 版（包名 `com.nullium.isopix.pro`，版本 1.3.2）再排查，以下选项**只在 Pro 版存在**，免费版 IsoPix 没有：

| 找不到的功能 | 属于 |
| --- | --- |
| RGB / HSV 数值直接输入 | Pro 独有 |
| 改变画布大小 | Pro 独有 |
| 从其他图像文件导入 / 粘贴 | Pro 独有 |
| 18 格调色盘（默认 6 格） | Pro 独有（设定里切换） |
| 自订网格大小、颜色 | Pro 独有 |
| 自订应用背景色 | Pro 独有 |

版本差异造成的功能缺失详见[下载与安装教程.md](下载与安装教程.md)；调色盘与网格在设定里的位置见[新手使用教程.md](新手使用教程.md)。

## 六、找不到刚存的图

【储存图档】会弹出保存位置选择，图就存在你当时选的路径；换过手机或清理过存储就更容易忘。按这个顺序找：

1. **回应用里找**：【菜单】→【档案】，用载入类操作按文件名找。
2. **相册的「所有照片」里翻**：有的相册首屏只显示部分图集，右滑进「图集 / 所有照片」按保存时间排，新存的图一般在最前。
3. **文件管理器里搜**：按文件名搜索；不记得名字就筛「图片 → PNG」（存出的格式是 PNG，见[支持的图片格式与导出说明.md](支持的图片格式与导出说明.md)），到 Downloads、Pictures、DCIM 这几个常见目录挨个看。
4. **重启手机再刷新相册**：文件在、相册没刷出来是常见情况——图片实际存在但相册索引没更新，重启后一般就显示了。
