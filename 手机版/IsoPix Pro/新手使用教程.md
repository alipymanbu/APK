## 一、这是什么场景

装好 IsoPix Pro、想尽快画出第一张像素图：本篇按「新建 → 画 → 存」的顺序过一遍核心操作。界面在系统语言为中文时显示中文，下文按中文菜单名讲；如果你的界面是英文，按同样的位置操作即可。

## 二、新建画布

1. 点屏幕左下角的【菜单】。
2. 选【档案】。
3. 选【创建新图】，按需要的像素尺寸建一张新画布。

之后所有绘制都发生在这块画布上。想在画的过程中调整画布大小（比如画完发现周围留白不够），用【档案】里的改变画布尺寸功能——这是 Pro 版选项。

## 三、屏幕两侧的工具

绘画界面两侧排着工具按钮，常用的几类：

| 工具 | 干什么 |
| --- | --- |
| 笔 / 橡皮 | 有不同大小可选，逐像素画与擦 |
| 基本图形 | 直线、矩形、圆等，画规整形状 |
| 范围灌色 | 一键填满封闭区域 |
| 取色 | 从画布上直接吸取当前颜色 |
| 选取 | 框选一块区域，可复制、剪切、粘贴，粘贴前能旋转、翻转 |
| 撤销 / 重做 | 画错了往回退，退多了再往前恢复 |

**手势**：双指同时拖动或捏合可以缩放、移动画布；界面也提供了缩放按钮作为备选，不想用手势就点按钮。放大到像素格清晰可见再画细节，是像素画的基本操作习惯。

## 四、调色与网格

- **调色盘**：默认 6 个颜色格；Pro 版可在设定里改成 18 格。常用颜色可以用保存/读取颜色的功能存下来，换图继续用。
- **精准选色**：Pro 版支持直接输入 RGB 或 HSV 数值来定颜色，做品牌色、照着色卡抄颜色时用它，比在色轮上拖准。
- **像素网格**：设定里可以打开像素格线，格子边界看得清，落笔不会错位；Pro 版还能自订网格的大小与颜色，画精灵图（sprite）时把网格调成精灵的分块尺寸很实用。

## 五、横竖屏都能画

应用支持横放与竖放两种界面方向，跟着系统自动旋转即可；小屏竖着画大图、横屏画宽图，按画布形状选。

## 六、画完怎么保存

1. 点【菜单】→【档案】。
2. 选【储存图档】，选好位置与文件名确认。

存出来的格式是 PNG，透明背景的作品也能存住（背景透明选项在设定里，详见[支持的图片格式与导出说明.md](支持的图片格式与导出说明.md)）。存过的图从同一组【档案】菜单里载入继续改。

## 七、更多设置在哪

点【菜单】→【设定/帮助】进入设定与帮助页：网格、调色盘格数、背景色、界面信息显示这些开关都在这里。找不到某个选项时，先确认装的是不是 Pro 版（核对包名与功能差异见[下载与安装教程.md](下载与安装教程.md)），仍找不到就查[常见问题与解决方法.md](常见问题与解决方法.md)。
