# Citra MMJ 游戏文件放哪与怎么识别

装好 Citra MMJ 只算完成了一半：模拟器本身只是个运行环境，安装包里没有任何游戏。能玩什么、列表里能出现什么，完全取决于你放进去的游戏文件。这篇讲清哪种文件能被识别、放在哪个目录最省事，以及看不到游戏时按什么顺序排查。

## 一、先明确一件事：模拟器里没有游戏

安装包里只有模拟器本体，不带任何游戏、也不带联网取游戏的入口。**游戏文件需要你自己准备**，本文不提供任何获取渠道，也不讨论这类渠道。想清楚这一点之后再往下看，能省掉很多「为什么装好了什么都没有」的困惑。

## 二、哪种文件格式能被识别

放进目录后能被应用认出来的，主要是这两类容器：

| 扩展名 | 是什么 | 实际影响 |
| --- | --- | --- |
| `.3ds` | 卡带镜像 | 与 `.cci` 是同一种容器（NCSD），只是扩展名不同，两个都能直接用 |
| `.cci` | 卡带镜像 | 同上，常见于从卡带导出的文件 |
| `.cia` | 安装包格式（CTR Importable Archive） | 需要先「安装」进模拟的主机里才能启动，安卓端这条路走得不顺，见下 |
| `.app`、`.cxi` 等 | 拆开后的单个内容块 | 不是完整的一份游戏，通常不会被当成一条游戏记录列出来 |

**关于 `.cia`**：这种格式在安卓端要先安装再运行，而安装过程依赖系统的文件访问框架，实际表现常常是安装中途出错、或者装完启动不了。除非你有明确理由，**优先用 `.3ds` / `.cci`**。

## 三、加密还是解密，这一步决定成败

3DS 的卡带镜像有加密与已解密两种状态。零售卡带导出得到的通常是加密的，**加密镜像在这个模拟器里加载会失败**，界面或日志上给出的提示往往就是 `ROM Encrypted` 这一类字样。

判断与处理顺序：

1. 先在应用里试着加载一次，看是不是报加密相关的错；
2. 如果是，换用已经解密的镜像文件，这是最省事的路子；
3. 别一个个文件试运气——同一批文件如果都是同一个来源导出的，往往加密状态也一致。

## 四、把文件放在哪里

目录选对能省掉后面大半的排查：

1. **建一个固定目录**，例如 `Download/3ds` 或存储根目录下的 `3ds`，把同一批游戏都放进去；
2. 目录名用纯英文，避免空格与特殊符号，减少路径被系统改写的机会；
3. 一个参考结构：

```text
/storage/emulated/0/3ds/          ← 你自建的目录，记住这一层
├── 游戏A.3ds
├── 游戏B.cci
└── 子目录/游戏C.3ds              ← 子目录也能扫到，但为了排查方便，建议先放平
```

三个常见的坑：

- **云盘的「在线文件」不是本地文件**。网盘客户端里没下载下来的占位文件，模拟器读不到。确认文件属性里显示的是实际占用空间，而不是「云端」。
- **不要放在 `Android/data` 下的别人家目录里**。Android 11 之后部分定制系统把这个区域对新装应用完全隔离，放在那里的文件扫不到。自己新建的目录反而更稳。
- **外置存储卡注意文件系统**。FAT32 格式的卡单文件上限是 4 GB，超过就写不进去；3DS 上体积大的游戏很容易过线，遇到「拷到一半失败」先查这一条。

## 五、在应用里添加游戏目录

1. 打开应用，进设置里找添加游戏目录的入口；
2. 在弹出的目录选择器里，**选到第四节里那个目录本身**（例如 `3ds`），不要选到它的上一级，更不要选整个存储根；
3. 确认返回后，回到主界面让列表刷新一次；
4. 目录里的文件会被逐个读取，文件多的时候这一步要等一会儿，读到一半界面没反应不等于卡死。

## 六、列表里没有游戏，按这个顺序查

别一上来就重装，按下面顺序走一遍，前四条能解决绝大多数情况：

1. **目录有没有选对**：是不是把它上一级目录选了，或者选到了别的目录；
2. **格式对不对**：回到第二节核对扩展名，`.cia` 与拆开的内容块都不会正常列出；
3. **有没有报加密**：回到第三节；
4. **存储权限给全了没有**：进「设置 → 应用 → Citra MMJ → 权限」确认存储是「允许」而不是「仅在使用时允许」；
5. 上面四条都排除了，**换一个已知能用的游戏文件再试一次**。能出列表，说明问题在刚才那个文件本身——体积是 0 字节、传输中途断掉、或者扩展名看着对其实是别的东西。

## 七、更新与追加内容放哪

3DS 上的「更新包」和「追加内容」不是本体文件的一部分，是单独分发的内容，要单独装进去：

- 装成之后它们落在用户目录的 `sdmc/` 下，**不在你放游戏文件的那个目录里**，所以你在 `3ds` 目录里找不到它们是正常的；
- 因此备份时不能只备份自己的 `3ds` 目录，`sdmc/` 要一起备份，做法见 [存档与进度怎么备份迁移.md](存档与进度怎么备份迁移.md)；
- 卡带本体放进 `3ds` 目录就能直接认，更新与追加内容走的是安装包那条路，而这条路在安卓端成功率不高。装不进去时，先保证本体能正常玩，别为了补内容把已经能用的环境搞乱。

## 八、文件与存档是两回事，别混在一起备份

游戏文件是你自己放进去的素材，删了可以再拷一份；存档是玩出来的进度，删了就没了。两者的备份范围与做法不同，**不要把游戏文件目录当成存档备份**，具体做法见 [存档与进度怎么备份迁移.md](存档与进度怎么备份迁移.md)。
