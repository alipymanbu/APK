3DS 模拟器出问题的原因集中在几处：存储权限、游戏文件本身、图形驱动、以及散热。这篇按「你看到什么」分节，每节只给能动手的步骤，不解释原理。遇到问题直接跳到对应那一节，不要从头重装。

## 一、装不上、装上打不开

| 现象 | 先做什么 |
| --- | --- |
| 提示「应用未安装」 | 手机里已装了更高版本，或装了另一个包名的变体；先卸载再装 |
| 提示与设备不兼容 | 系统版本低于这份包的要求，或设备不是 64 位处理器 |
| 装完打开就退到桌面 | 先卸载后重装一次，直接覆盖安装遗留的旧数据是常见诱因 |
| 安装界面反复弹安全提示 | 这是第三方渠道安装包的常规提示，按提示继续即可 |

装之前该核对的版本号、包名、体积，见 [下载与安装教程.md](下载与安装教程.md) 第一节的表格。

## 二、应用能进，但列表里没有游戏

这是最常见的一类，按顺序查四条：

1. **目录有没有选对**：选到了自建目录的上一级、或者选到了存储根目录，都会扫不出东西；
2. **格式对不对**：只认卡带镜像（`.3ds` / `.cci`）这类完整文件，安装包格式与拆开的内容块不会正常列出；
3. **文件是不是真的在本地**：网盘客户端的在线占位文件读不到，确认文件属性里显示的是实际占用空间；
4. **存储权限给全了没有**：进「设置 → 应用 → Citra MMJ → 权限」，确认存储是「允许」而不是「仅在使用时允许」。

**放在 `Android/data` 下面的游戏文件也扫不到**——Android 11 之后部分厂商系统把这个区域对新装应用完全隔离，把文件挪到自己新建的目录里再试。完整的目录建议见 [游戏文件放哪与怎么识别.md](游戏文件放哪与怎么识别.md)。

## 三、提示加密、加载失败

界面上或日志里出现 `ROM Encrypted` 一类的字样，说明这份镜像是加密状态，模拟器加载不了：

- 换用已解密的镜像文件，这是最省事的路子；
- 不要靠换模拟器版本去绕，这条路走不通；
- 同一批文件如果来源一致，加密状态通常也一致，不用一个个试。

## 四、提示缺少系统文件或字体

这类提示出现在启动某个游戏之后，而不是应用启动时：

1. **先确认首次运行的文件释放有没有被打断**。应用在第一次启动时会把内置的字体与常用系统文件释放到用户目录，中途被杀进程、或者装完立刻用清理工具清理，都会让这一步做不完整。卸载重装一次、启动后先别操作它，等它自己完成；
2. **检查存储权限**。权限给得不全时，释放过程会静默失败；
3. **检查用户目录里的 `sysdata` 子目录还在不在**。用第三方清理工具「深度清理」把这里清掉是常见诱因，遇到这种情况只能重装让它重新释放一次。

## 五、没有声音，或者声音断续

- **完全没声音**：先调手机音量与静音开关，再确认应用内音频相关选项没有被关成静音；
- **断续、卡顿伴随掉帧**：声音问题是卡顿的附属现象，按第八节先解决帧率，声音通常跟着好转；
- **只有某个游戏有声音问题**：记录下来单独处理，这类多是该游戏的兼容性问题，不代表模拟器整体坏了。

## 六、手柄连上了但按键没反应

这一类按「先系统、后应用」的顺序查最省事，完整的五步排查在 [手柄与触屏按键设置.md](手柄与触屏按键设置.md) 第六节。这里只列最常被忽略的三条：

| 现象 | 多半是什么原因 |
| --- | --- |
| 所有键都没反应 | 蓝牙配对残留，删掉记录重配一次 |
| 只有个别键不灵 | 映射表里那几项是空的，重进映射页指定一次 |
| 有线能用、无线不行 | 问题在蓝牙链路，不在应用 |

## 七、画面花屏、贴图错位、只剩一块屏、进游戏黑屏

**花屏、贴图错位、背景色异常**这类现象的归因通常很单一：**图形驱动与渲染后端不匹配**。

1. 在设置里把渲染后端换到另一个选项，用同一款游戏对比；
2. 换完记得重启一次应用，有的机型不重启不生效；
3. 只有个别游戏出问题的，多半是该游戏自身的兼容性问题，换后端能缓解就保持现状；
4. 背景色异常、整块贴图变黑这类明显错误，换回兼容性更好的那个后端基本都能解决。

**只剩一块屏、或者两块屏摆得不对**，这不是驱动问题，属于屏幕布局参数的问题，改法见 [双屏怎么摆放与横竖屏设置.md](双屏怎么摆放与横竖屏设置.md)。

**进游戏黑屏、只出声音**，按这个顺序试：

1. 先等半分钟。部分游戏首次加载会黑屏较长时间，急着杀进程反而会打断首次初始化；
2. 换一次渲染后端再进；
3. 把内部分辨率降一档再进，个别游戏在特定档位下必然黑屏；
4. 以上都无效就记下是哪一款游戏——这类通常与设置无关，别在这上面耗时间。

## 八、卡顿、掉帧

不要一上来就重装，按 [画面设置与卡顿优化.md](画面设置与卡顿优化.md) 的顺序走一遍，优先动这三项：

1. 打开帧率显示，先确认「是不是真的在掉帧」，某些游戏本来就是 30 帧；
2. 把内部分辨率降到 1x 试一次，这是单项收益最大的一步；
3. 换渲染后端再试一次；
4. 玩二三十分钟后才开始卡的，是机身过热降频，不属于设置问题，注意散热与别边充边玩。

## 九、怎么确认自己装的是哪一版

进应用的设置或关于页面看版本号，与 [下载与安装教程.md](下载与安装教程.md) 第一节表格里的 `99a89d290` 对一下。对不上说明是另一份包，本文涉及的设置项名称与位置可能与你看到的不完全一致。

怀疑安装包不完整、或者想换一份干净的：从 [Citra MMJ 安装文件资源（夸克网盘）](https://pan.quark.cn/s/75e83d96efbb) 重新转存下载，装之前先卸载旧版，并按 [存档与进度怎么备份迁移.md](存档与进度怎么备份迁移.md) 备份一次用户目录。

## 十、要不要换成别的分支

原 Citra 官方项目在 2024 年 3 月停止维护，此后社区分成几支继续做，其中两支合并成了 Azahar，另有一支就是这份 Citra MMJ。两边都在维护，功能与设置项名称有差异。这不是「哪个坏掉了」的问题，属于选哪条路的问题，本篇不替你下结论；需要对比时注意一点：**换分支等于换用户目录，先备份**，做法同 [存档与进度怎么备份迁移.md](存档与进度怎么备份迁移.md)。
