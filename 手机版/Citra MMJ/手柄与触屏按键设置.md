3DS 有实体按键、摇杆和一块下屏触摸屏，手机上要复现这套操作，只有三条路：屏幕按键、蓝牙手柄、有线手柄。这篇按这三条路分别给做法，最后给出「连上了但按不动」的排查顺序——这一类占了实际操作问题的多数。

## 一、先决定用哪套输入

| 方式 | 适合场景 | 主要短板 |
| --- | --- | --- |
| 屏幕按键 | 通勤路上随手玩、躺床上玩 | 挡画面，需要一段时间适应；动作类容易误触 |
| 蓝牙手柄 | 长时间玩、动作与赛车类 | 需要配对；部分廉价手柄摇杆回中不准 |
| 有线手柄 / 2.4G 接收器 | 平板、电视盒子、桌面场景 | 要带转接头，手机端着不方便 |

用平板或电视盒子时手柄几乎是必须的，用手机的竖屏姿势则屏幕按键更方便。两种可以同时开着，不冲突。

## 二、屏幕按键：位置、大小与隐藏

屏幕按键的布局是可以逐项调整的，改动逻辑不复杂：

1. 进设置里的按键编辑入口，界面会变成可拖动状态；
2. **按住某个按键拖到想要的位置**，这类分支的调整步长比较小，适合把十字键、ABXY 这类成组的按键对齐；
3. 拖动的同时通常可以缩放按键，屏幕小的机型把按键适当缩小能少挡一块画面；
4. **想藏掉某个按键**，在编辑状态下对它操作即可（不同版本入口可能不同，以应用内说明为准）；藏掉不用的按键比缩小全部按键更有效。

一份可以直接照抄的布局思路：左手区放十字键与摇杆，右手区放 ABXY，L / R 放到屏幕上缘两侧。这样拇指移动距离最短，也不容易压住画面中心。

## 三、连一个蓝牙手柄

1. 手柄进配对模式（多数手柄是长按某个组合键直到指示灯快闪，具体看手柄说明书）；
2. 手机进「设置 → 蓝牙」，在可用设备里找到它并配对；
3. **先在系统层面确认能识别**：进系统的手柄测试或游戏控制器页面，摇杆、十字键、ABXY 都动一下，确认没有哑键；
4. 系统里正常之后，再打开模拟器，此时应用一般会直接认到它。

顺序不要颠倒：**先系统、后应用**。系统都认不到的手柄，模拟器里调多久也没用。

## 四、把手柄按键映射到 3DS 的按键

映射表大致如下，进设置里的输入 / 按键映射入口逐项指定：

| 3DS 上的按键 | 手柄上通常映射到 | 备注 |
| --- | --- | --- |
| 十字键 | 手柄十字键或左摇杆 | 两者都可指定，按游戏习惯选 |
| A / B / X / Y | 手柄对应的 A / B / X / Y | 注意不同品牌的按键字母位置不同，别按位置、按字母 |
| L / R | 手柄的 L / R 肩键 | 3DS 只有一对肩键 |
| Start / Select | 手柄的 + / − 或菜单键 | 部分游戏靠它存档，别漏 |
| 摇杆（Circle Pad） | 左摇杆 | 模拟量输入，用十字键代替会失去力度感 |
| C 摇杆（New 3DS 机型才有） | 右摇杆 | 手柄没有右摇杆时，可用十字键顶替部分操作 |

映射完**一定要在游戏里实测**：进标题菜单把每个键都按一遍，比事后在战斗中才发现 B 键没绑要省事得多。

## 五、下屏的触摸操作怎么处理

3DS 的下屏是触摸屏，模拟器里这块屏同样可以点。用手机玩时直接用手指点下屏区域即可；用电视加手柄玩时，触屏操作没有现成的实体键可对应，只能靠把下屏在画面上方摆到顺手的位置，或者换回触屏设备处理这类步骤。下屏在画面上占多大、摆在哪个位置，会直接决定你点得准不准，摆法见 [双屏怎么摆放与横竖屏设置.md](双屏怎么摆放与横竖屏设置.md)。

## 六、手柄连上了但按键没反应

按这个顺序查，每一步都能排除一类原因：

1. **系统层测试**：回系统的控制器测试页，确认手柄本身是好的。坏在这一步就与模拟器无关。
2. **重新配对**：删掉蓝牙记录重新配一次。蓝牙连接残留是「连上了却按键全无」最常见的原因。
3. **检查映射表是否为空**：装上手柄之后再进映射页面看，有的版本在新设备接入时需要重新指定一次。
4. **换连接方式验证**：有 OTG 转接头的话，插上线试一次。有线正常、无线不行，问题在蓝牙链路而不是应用。
5. **关掉手柄自身的特殊模式**：部分手柄有「手机模式 / 电脑模式」之分，切到手机模式再配对。

五步走完仍然不行，再换一只已知能用的手柄交叉验证一次：换上去正常，说明是原手柄或它这一路配对的问题；换上去一样不灵，问题就在手机或这一份安装包上。如果还伴随画面卡顿、输入延迟偏高，按 [画面设置与卡顿优化.md](画面设置与卡顿优化.md) 把帧率与垂直同步这两项调一下，延迟感会明显改善。
