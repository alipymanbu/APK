Citra MMJ 是安卓上的任天堂 3DS 模拟器，属于社区在原 Citra 项目停止维护之后继续维护的安卓分支。这类模拟器都不在应用商店里，安装包只能手动装，装好之后还要自己准备游戏文件才能玩起来。这篇只解决第一件事：把网盘里这份包装进手机，并把首次运行需要的东西配齐。

## 一、先弄清网盘里这份包是哪一版

网上能搜到的是官方后来发布的新版，而网盘里这份是制作文档时核对过的那一版，两者未必是同一个版本号。本文涉及的版本号、包名、体积一律以下表为准：

| 应用名 | Citra MMJ |
| 版本号 | 99a89d290 |
| 包名 | `org.citra.emu` |
| 安装包体积 | 15.06 MB |
| MD5 | `9731C3D387472B77E95DE12235E5ED25` |

安装包本体就在本篇开头那个网盘入口里，转存到自己网盘后再下载。

**关于版本号**：这条分支的发布编号通常用日期形式（例如 `20251112`），而网盘里这份包的版本号显示为 `99a89d290`，是另一种编号形式的一次构建。后续编号以发布页当时显示的为准，本文不预判。

**关于系统要求**：这份包的说明里标注的是「Android 5.2 及以上」，社区资料里常见的说法是「Android 7.0 及以上」，两边并不一致，这里不替你裁决，装的时候以系统给出的提示为准。另有两条是硬门槛：

- **设备必须是 64 位处理器**：32 位设备要么装不上，要么装上也没有可用帧率；
- **内存建议 4 GB 及以上**，多数社区资料建议 6 GB 以上更稳。

真正决定跑得动跑不动的是芯片的 GPU 与驱动，同一个版本号在不同机型上的表现差别很大，这一点在 [画面设置与卡顿优化.md](画面设置与卡顿优化.md) 第三节里有更具体的说明。

## 二、四个 APK 变体，网盘里这份是哪一个

同一次发布通常会出四个安装包，差别只在**包名**与**用户目录位置**：

| 变体 | 包名 | 说明 |
| --- | --- | --- |
| 标准版 | `org.citra.emu` | 最常见的一份，用户目录放在外部存储根目录 |
| Antutu 变体 | `com.antutu.ABenchMark` | 包名与标准版不同，**可以和标准版同时装在手机上** |
| StorageAccess 版 | 上面两者之一 | 用户目录改到 `Android/data` 下，适配 Android 11 之后的存储限制 |
| StorageAccess + Antutu | 组合 | 同时具备上面两条特征 |

怎么挑：

1. **先看存储权限给不给得上。** Android 11 及以后，标准版有时会被系统挡住对外部存储根目录的写入，表现是启动后提示目录不可用或保存设置失败，这种情况直接换 StorageAccess 版。
2. **想同时留两份对比版本**，就用标准版加 Antutu 变体：包名不同，两者互不覆盖，各有独立的用户目录与设置。
3. 网盘里这份是**标准版（`org.citra.emu`）**。它和 StorageAccess 版的用户目录不是同一个，换变体之后游戏列表与存档不会自动跟过去，换之前先看 [存档与进度怎么备份迁移.md](存档与进度怎么备份迁移.md)。

## 三、安装步骤

1. **转存并下载**：从 [Citra MMJ 安装文件资源（夸克网盘）](https://pan.quark.cn/s/75e83d96efbb) 把安装包转存到自己的网盘，再下载到手机或电脑。
2. **把包送到手机上**：手机端直接下载最省事；在电脑上下载的话，用数据线或任意传输工具拷进手机存储即可。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统的这项开关通常收在「安全」或「隐私」分类下面。
4. **点击安装包完成安装**：系统提示「应用未经过安全检测」属于第三方渠道安装包的常规提示，继续安装即可。
5. **回装低版本要先卸载**：安卓不允许用更低的版本号覆盖更高的版本，会直接报「应用未安装」。卸载会**一并清掉用户目录里的设置**，介意的话先看 [存档与进度怎么备份迁移.md](存档与进度怎么备份迁移.md)。
6. **装完先别急着打开**：先看下一节把权限过一遍，否则首屏可能停在目录报错上。

## 四、首次启动：权限与自动释放的文件

第一次打开通常会弹存储权限，给全即可。给不全的表现很直接：应用启动后提示找不到用户目录，或者界面能进但任何目录都读不到。

有一个和不少模拟器不一样的点：**首次运行时，应用会把内置的字体与常见系统文件释放到用户目录里**，并且不覆盖目录里已有的同名文件。所以第一次启动会比之后慢一些，属于正常现象。如果你看到提示说缺少系统文件或字体，先确认这一步有没有被中途打断——启动过程中用清理工具杀进程是常见诱因，详见 [常见问题与排查.md](常见问题与排查.md)。

## 五、用户目录在哪，里面放什么

后面几篇会反复用到这个信息，先记下来：

```text
citra-emu/                  ← 用户目录（标准版：外部存储根目录）
├── config/                 ← 设置文件（布局、画面、按键这些参数都在这）
├── sdmc/                   ← 游戏存档、已安装的更新与追加内容
├── nand/                   ← 模拟出来的主机数据
├── sysdata/                ← 系统文件：字体一类的数据
└── load/                   ← 贴图替换之类的额外内容
```

StorageAccess 版的路径不同，在 `Android/data/org.citra.emu/files/` 下面；Antutu 变体的目录名里带它自己的包名，与标准版各占一份。

两条结论：

- **整个 `citra-emu` 目录就是你的全部数据**，备份与迁移都只针对它一个，不用去区分哪个文件管什么，做法见 [存档与进度怎么备份迁移.md](存档与进度怎么备份迁移.md)。
- **用户目录在外部存储根目录时，卸载应用通常不会清掉它**；用 StorageAccess 版（目录在 `Android/data` 下）时，卸载会连目录一起被系统清掉。这是换变体、重装之前必须先想清楚的一件事。

## 六、装完做一次最小验证

1. 打开应用，确认没有卡在权限或目录报错上；
2. 进设置改一项再退出，重进后设置还在，说明用户目录可写；
3. 确认没有反复触发「首次释放文件」那种长时间等待；
4. 此时应用里还是空的、没有任何游戏，这是正常的，接着看 [游戏文件放哪与怎么识别.md](游戏文件放哪与怎么识别.md)。

## 七、这条分支现在是什么状态

原 Citra 官方项目在 2024 年 3 月停止维护，此后社区分成几支继续做：其中两支后来合并成了 Azahar，另有一支就是这里的 Citra MMJ，一直在维护安卓端。社区对比里常见的一个说法是：MMJ 在非骁龙芯片机型上的表现更好一些，这也是这条分支到现在还有人用的主要原因。选哪个不是本篇要下结论的事，两个装在同一台手机上对比也不冲突。这条分支的源码与发布记录在 `github.com/weihuoya/citra`，需要核对来历时可以去看。
