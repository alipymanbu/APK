## 一、按机型对号入座

佳能给 SELPHY 配的手机应用有两款，装哪个取决于你的机型：

| 机型 | 该装什么 |
| --- | --- |
| SELPHY CP1500 | 只装 **SELPHY Photo Layout**。佳能产品页明确：装这一款就能完成从布局到打印的全过程，不用再装 Canon PRINT |
| SELPHY CP1300 / CP1200 / CP910 / CP900 | **SELPHY Photo Layout**（做布局与装饰）＋ **Canon PRINT**（负责实际打印，官方应用页注明这几款「必须单独安装 Canon PRINT」） |
| SELPHY QX20 / SQUARE QX10 | 装 **SELPHY Photo Layout**（QX 系列不在 Canon PRINT 的支持列表里） |

先按这张表把应用装对，再去做连接；SELPHY 的连接步骤见 [连接打印机的方法.md](连接打印机的方法.md) 第三节。

## 二、SELPHY Photo Layout 是干嘛的

它是佳能专门给 SELPHY 做的「排版 + 打印」应用，强项在布局：打印原始照片只是基础，还能拼贴、拼图、打印证件照、把一张大图平铺到多张纸上、做书签版式，以及给照片加邮票、文字、二维码这类装饰后打印（CP1500 还支持图案覆膜）。截至 2026-09 的功能清单以 [官方应用页](https://app.ssw.imaging-saas.canon/app/zh/spl.html) 当时显示为准。

系统要求也留意一下：官方列出的支持范围是 Android 12～16、iOS 17 及以后——手机系统太老的话，装不上最新版，这时 CP 系列老机型反而只剩 Canon PRINT 一条路可用。

## 三、Canon PRINT 在 SELPHY 上承担什么

对 SELPHY 用户来说，Canon PRINT 的角色更像个「打印执行者」：CP1300、CP1200、CP910、CP900 这四款要从手机打印，任务得经它发出去；SELPHY Photo Layout 做好的版面也是靠它落到纸上。它还能看打印机状态。

一个老机型的例外要记着：**CP900 不支持 Ad Hoc 模式**的直连打印，要用架构模式（通过无线路由器连接）。

装 Canon PRINT 前先核对版本与包名，别和佳能其他打印应用弄混，核对方法见 [下载与安装教程.md](下载与安装教程.md)。

## 四、两款应用从哪拿

- SELPHY Photo Layout：App Store / Google Play 搜「SELPHY Photo Layout」，以官方页面为准；
- Canon PRINT：除了应用商店，也可以从这里的 [Canon PRINT 安装文件资源（夸克网盘）](https://pan.quark.cn/s/aa9b875e3ca0) 获取安卓安装包（版本、包名、MD5 等信息见 [下载与安装教程.md](下载与安装教程.md)）。

两款应用都装的用户，日常拍照打印走 Photo Layout，查打印机状态、发普通打印任务用 Canon PRINT，分工不冲突。
