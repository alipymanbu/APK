## 一、打印照片

1. 打开 Canon PRINT，确认顶部已选中你的打印机；
2. 选「照片打印（Photo Print）」；
3. 从手机相册里挑要打的照片；
4. 设置纸张尺寸、纸张类型、是否留边框；
5. 点「打印」。

想打出好效果，主要在第四步下功夫：纸张类型选得和实际放进打印机的纸一致（普通纸选普通纸，照片纸选照片纸），颜色和干燥表现才正常；不留白边选无边框，但部分机型不支持无边框，以机型说明为准。

用 SELPHY 打印机、想做拼贴、证件照、平铺这类版式打印的，佳能另有专门的 SELPHY Photo Layout，选型见 [SELPHY打印机该用哪个应用.md](SELPHY打印机该用哪个应用.md)。

## 二、打印文档

1. 首页选「文档打印（Document Print）」；
2. 挑选要打印的文档——这一步需要手机处于联网状态；
3. 配好份数、纸张等设置后点「打印」。

注意两点：文档打印要求手机能上网（官方步骤里注明了这一点），只连打印机热点不联网时会选不了文件；能打什么格式的文档随机型和版本有差异，打不了的文件先转成常见格式再试。

## 三、扫描到手机

带扫描功能的机型可以把文件扫成图片存进手机：

1. 把原稿放到打印机稿台或进纸器上；
2. 应用里选「扫描（Scan）」；
3. 设置文档类型、彩色模式（彩色/灰度/黑白）、文档尺寸、保存格式（JPEG/PDF 等）；
4. 点「扫描」，完成后预览，把结果保存到手机、发邮件或用其他应用打开。

扫描件保存在哪可以事先在应用设置里指定，找不到文件时先去设置里看保存路径。

## 四、用手机下复印指令（安卓）

有复印功能的机型，你不用站在打印机前按键，直接在安卓手机上操作：

1. 应用里选「复印（Copy）」；
2. 把原稿放到稿台玻璃上；
3. 按需设置：份数、纸张尺寸、纸张类型、缩放比例、浓度、打印质量；
4. 点「彩色复印」或「黑白复印」；
5. 弹出密码框时输入打印机序列号（见 [连接打印机的方法.md](连接打印机的方法.md) 第五节）。

用手机拍照当原稿复印时，可以先做透视校正，把拍歪的文档拉正再打。

## 五、打印网页内容

在应用内可以直接打印网页，适合打一张菜谱、一张票据页面这类临时需求：打开应用里的网页浏览入口，加载页面后选打印即可。网页排版和屏幕显示不一定一致，打印前先用预览确认。

## 六、看打印机状态与墨水

应用首页能看到已注册打印机的在线状态和墨水余量；部分机型还能在应用里查耗材的型号、访问在线说明书。打印颜色淡、缺色这类质量问题对应的清洗、校准等维护动作，入口在打印机面板或电脑驱动里，不在手机应用里做（处理顺序见 [常见问题与故障排查.md](常见问题与故障排查.md) 第四节）。

## 七、云打印（PIXMA Cloud Link）

部分机型支持通过 PIXMA Cloud Link 直接从云服务打印，或把扫描件直接发到云上，支持的服务包括 Dropbox、Google Drive、Evernote 等。它依赖打印机的云连接功能，可用的服务随地区和时间变化，以打印机上显示的列表为准；用之前要按提示登录对应账号。

## 八、打印过程中别做这两件事

进度画面出现后：

- **不要断开 Wi-Fi 或切换网络**——手机一断网，任务可能打一半就废了；
- **不要直接杀掉应用**——图片可能打不完整。

等打印结束回到待机画面再去做别的。打错了、卡住了，到 [常见问题与故障排查.md](常见问题与故障排查.md) 处理。
