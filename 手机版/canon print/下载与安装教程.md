## 一、先弄清你要装的是哪个应用

佳能的打印类应用不止一个，装错后面会浪费不少时间：

| 名称 | 说明 |
| --- | --- |
| Canon PRINT | 本篇的主角。旧名 **Canon PRINT Inkjet/SELPHY**，佳能官网页面注明「应用程序名称已变更」，包名 `jp.co.canon.bsd.ad.pixmaprint`，面向家用喷墨打印机与 SELPHY 照片打印机 |
| Canon PRINT Business | 面向办公机型（imageCLASS 等激光/复合机）的另一款应用，与本文的不是同一个 |
| Canon Print Service | 安卓的**打印插件**，不能独立使用，装在系统打印服务里用，不是这篇文章讲的打印应用 |

网盘里这份安装包的基本信息（以此为准，网上搜到的可能是不同版本）：

- 版本：**3.6.0**；安装包大小约 **46.97 MB**
- 包名：`jp.co.canon.bsd.ad.pixmaprint`
- 开发者：Canon Inc.
- 系统要求：安装包标注为安卓 5.2 以上（以官方页面为准）

截至 2026-09，佳能中国官网的[移动应用下载页](https://www.canon.com.cn/supports/app/)显示的版本同为 3.6.0（2025 年 10 月更新）。不同渠道发出来的包**包名和版本可能不一致**，装好后以你手上这份的属性为准。

## 二、从网盘获取安装包

安装包放在夸克网盘里，步骤如下：

1. 打开上面的 Canon PRINT 安装文件资源链接（夸克网盘分享页）；
2. 选择「保存到我的网盘」，把它转存到自己账号下；
3. 在自己的网盘里找到这个文件夹，把 APK 文件下载到手机（或先下到电脑再传过去）。

如果链接打不开或转存失败，多半是分享已过期，需要分享者重新生成一份。

## 三、安装步骤

1. 在手机上点开下载好的 APK 文件；
2. 系统提示「不允许安装未知来源应用」时，按提示允许浏览器或文件管理器安装应用（安卓各版本入口不同，一般在弹窗里直接给「仍要安装」或跳转到设置开关）；
3. 点「安装」，等待完成；
4. 首次启动会申请若干权限（本地网络 / Wi-Fi 信息、存储等），用于搜索局域网内的打印机与保存扫描件，按需允许——拒绝过多权限会导致后面搜不到打印机；
5. 装好后别急着操作，先去把打印机连上：具体见 [连接打印机的方法.md](连接打印机的方法.md)。

## 四、核对安装包完整性

转存、下载环节都可能出现文件损坏，装之前可以核对一次 MD5：

- 安装包 MD5：`AB7C86C30048B36EE47784C5214DFD96`（字母不区分大小写）
- 核对方法：安卓上用支持校验的文件管理器计算 APK 的 MD5，与上面比对；电脑上可用 `certutil -hashfile 文件名 MD5`（Windows）或 `md5sum 文件名`（Linux/macOS）。

不一致说明下载过程出了问题，重新下载一份再装。

## 五、装不上或装完打不开

先排查这几件事：安装包是否完整（回到上一节核对 MD5）、手机剩余存储是否够、是否从旧版本覆盖安装时被系统拦截。卸载后重装一次通常能解决；仍然不行的话，到 [常见问题与故障排查.md](常见问题与故障排查.md) 按现象对号入座。
