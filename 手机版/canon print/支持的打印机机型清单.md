## 一、怎么判断你的机型支不支持

佳能官网按「系列」公布支持范围，同一系列下个别型号可能不支持，所以核对口径是：**先对系列，再对型号**。下面的清单整理自佳能中国官网移动应用下载页（截至 2026-09），官方页面会随新机型上市更新，最终以 [官网页面](https://www.canon.com.cn/supports/app/) 当时显示为准。

## 二、喷墨打印机

| 产品线 | 支持的系列 |
| --- | --- |
| PIXMA 家用喷墨 | TS、TR、MG、MX、G、E、PRO、MP、iP、iX 系列 |
| MAXIFY 商用喷墨 | MB、iB、GX 系列 |
| imagePROGRAF 大幅面 | PRO、TM、TA、TX、TZ、GP、TC 系列 |

各系列均有「部分型号除外」的说明，具体到某一款（比如 TS8370、G4010、iP110 这类具体型号），以官网支持列表为准。

## 三、小型照片打印机（SELPHY）

- CP900 系列、CP910、CP1200、CP1300、CP1500；
- 注意：**CP900 不支持 Ad Hoc 模式**的无线直连，要用架构模式（即通过无线路由器连接）打印；
- 方形照片打印机 QX20 / SQUARE QX10 不在这份清单里，手机端走佳能的 SELPHY Photo Layout 应用。

SELPHY 各机型该装哪个应用、两个应用怎么分工，见 [SELPHY打印机该用哪个应用.md](SELPHY打印机该用哪个应用.md)；直连操作步骤见 [连接打印机的方法.md](连接打印机的方法.md) 第三节。

## 四、激光打印机 / 复合机

官网清单里也列了激光产品线：imageCLASS 系列、imageCLASS X 系列、i-SENSYS 系列、i-SENSYS X 系列、Satera 系列。办公机型要注意，佳能对这类设备另有专门的 **Canon PRINT Business** 应用，功能与家用版不同，按机型页的推荐选应用。

## 五、机型相关的常见坑

- **功能随机型缩水**：同一应用，有的机型能打印+扫描+复印+云打印，有的只能打印。买耗材、查墨水量这类功能也一样，部分功能和服务不适用于某些打印机，以机型说明为准；
- **老机型先升固件**：个别老型号要先把打印机固件升到指定版本才能正常配对（旧规格页对 PRO-1 标注过需固件 v1.1 以上这类要求），配对失败时查一下机型固件更新；
- **频段限制**：喷墨打印机走 2.4GHz 频段，路由器若把两个频段分成不同名字，打印机要注册在 2.4GHz 那个 SSID 上；
- **连接方式随机型不同**：有没有无线直连、有没有蓝牙通信，都按机型定，别拿 A 机型的教程硬套 B 机型。

## 六、机型不支持时的替代路子

- **iPhone / iPad**：多数带 Wi-Fi 的佳能打印机支持 AirPrint，系统级直接打，不需要装这个应用；
- **安卓**：部分机型可用 **Canon Print Service** 打印插件（Android 4.4 起，从 Google Play 装，装完在系统打印服务里出现）；更新的安卓设备也可走 Mopria 打印服务。

插件方式只能打印，扫描、复印、墨水状态这些还是得回 Canon PRINT 这类应用里做。装不上应用或搜不到机型时，去 [常见问题与故障排查.md](常见问题与故障排查.md)。
