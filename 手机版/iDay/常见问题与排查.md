# iDay 常见问题与排查

> 本篇汇总 iDay 用起来最常碰到的几类问题：提醒不响、计时中断、白噪音无声、换机数据、装不上，每类给出按顺序排查的步骤。

## 一、到点了没有提醒

提醒不响，九成是系统把通知或后台拦了。按顺序查：

1. **通知权限**：系统设置 → 应用 → iDay → 通知，确认「允许通知」开着；
2. **自启动**：国产手机在「启动管理 / 自启动管理」里把 iDay 设为允许自启动；
3. **电池优化**：把 iDay 加入电池优化白名单（华为叫「启动管理→手动管理」，小米叫「省电策略→无限制」，OPPO/vivo 叫「允许后台运行」，叫法各机型不同）；
4. **后台锁定**：在最近任务界面把 iDay 卡片下拉锁定，防止一键清理把它杀掉；
5. **勿扰模式**：检查系统勿扰/专注模式是否屏蔽了应用通知。

改完之后可以设一个一两分钟后的提醒实测一次，别等到真要用时才发现还是不响。

## 二、专注计时中途被打断或后台被清

锁屏一段时间后发现计时停了，通常也是后台被杀：

1. 按第一节把自启动、电池策略、后台锁定都设好；
2. 长时间专注（1 小时以上）时尽量把应用留在前台，或保持屏幕常亮；
3. 部分机型的「深度省电 / 超级省电」会冻结所有后台，专注期间别开。

如果设置都正常还是频繁中断，可以到应用内反馈渠道或应用商店评论区看看是否有同机型用户遇到类似问题。

## 三、白噪音没有声音

1. 先按音量键，确认**媒体音量**（不是铃声）没被调到零——专注界面播的环境音走媒体通道；
2. 确认手机没处于静音或勿扰状态；
3. 断开蓝牙：白噪音可能正往已连接的耳机或音箱送，而你以为它该从扬声器出声；
4. 还不行就退出专注重新进入一次，或重启应用。

## 四、换手机或重装后，数据还在吗

应用的专注记录、任务清单存在手机本地。换机或卸载重装前：

1. 先在应用内设置里找「备份 / 同步 / 导出」入口，有就先备份；
2. 公开资料里没有查到 iDay 云同步的明确说明，别默认换机会自动带走数据；
3. 换机时可以先试厂商自带的换机工具（华为「手机克隆」、小米「小米换机」、OPPO/vivo「互传」等），它们能把应用连同部分数据整体搬过去；iDay 的记录能否完整带出因机型与系统版本而异，搬完先打开应用核对一遍；
4. 如果数据已丢，任务和倒计时重建成本不高，专注历史则找不回来——所以重要的统计数据想留档，可以定期截图保存。

## 五、装不上或打开闪退

1. **安卓版本**：确认系统满足安装要求（各渠道标注为安卓 5.2 以上）；
2. **安装包完整性**：重新下载一次安装包，大小应在 32 MB 上下，明显偏小说明没下完；
3. **核对包名**：装好后如果不确定是哪个应用，在系统设置的应用列表里按包名 `com.wzf.fanqie` 找；
4. **存储空间**：手机剩余空间不足会导致安装或运行异常，清理后再试；
5. **闪退**：重启手机再开一次；仍闪退就卸载后换一个时间重新安装，或到应用商店反馈。

安装与首次启动的完整步骤见 [下载与安装教程.md](下载与安装教程.md)。
