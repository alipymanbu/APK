> 应用界面没有官方中文，本篇讲清界面语言现状、高频界面词对照、站内中文作品的入口与实际预期。

很多中文用户装完第一件事就是找语言设置，结果没找到——不是你漏了，是它没有。本篇把「界面是英文怎么办」和「怎么读中文写的作品」分开讲清。

## 一、界面语言现状

- 官方应用的界面语言只有英文（应用商店的语言标注就是 English），**应用内没有切换界面语言的选项**，也没有官方中文界面。
- 界面是英文不影响读中文文：界面语言与作品语言是两回事，语言筛选只作用于作品列表（入口见下一节）。

## 二、高频界面词对照

认得下面这些词，日常使用基本无障碍：

| 界面词 | 意思 |
| --- | --- |
| Library | 书库（你收藏与下载的书都在这） |
| Downloaded | 已下载（离线可读的分区） |
| Follows / Favorites | 追更 / 收藏，两者的区别见[私信论坛与消息通知.md](私信论坛与消息通知.md) |
| Reviews | 评论 |
| Forums / Community | 论坛 / 社区合集 |
| Crossover | 交叉（两部作品混同） |
| Complete / In-Progress | 完结 / 连载中 |
| Rating | 分级（K / K+ / T / M） |
| Words / Chapters / Updated | 字数 / 章节数 / 更新时间 |

## 三、站内的中文作品从哪进

站内作品按**写作语言**归档，中文是其中一个分区：

1. 网页端：进某个 fandom 页面，把语言下拉筛选切到 Chinese，列表就只剩中文文。
2. 应用端：浏览与搜索同样带语言筛选，用法见[找书与筛选技巧.md](找书与筛选技巧.md)。

**实际预期先放好**：FFN 的中文分区存量以早年积累的文为主，更新频率远低于英文区；中文同人圈的创作与讨论主力长期在其他平台，这里更像一个小众角落。想在站内读中文，靠语言筛是正路；指望中文区有英文区那样的更新量，大概率会失望。

## 四、机器翻译读文

官方在应用功能里列出了 Translation：用内置 AI 引擎把故事翻译成你的语言读。两点注意：

- 这个功能随版本迭代，你手上的安装包（64.0）能不能用、藏在哪一级菜单，以应用内实际显示为准；
- 机器翻译的译文只能应付「追情节」，精读或涉及文字梗的章节，别只依赖它。

翻译功能找不到、或界面其他地方有疑问时，先去[常见问题与故障排查.md](常见问题与故障排查.md)过一遍排查顺序。
