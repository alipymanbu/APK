# FanFiction.Net 找书与筛选技巧

> 本篇讲在 FanFiction.Net 里怎么按主分类、交叉设定、分级、语言这些条件，把想看的同人作品筛出来。
> **相关文档**：[离线缓存与听书设置.md](离线缓存与听书设置.md) · [写作发布与文档编辑.md](写作发布与文档编辑.md) · [常见问题与故障排查.md](常见问题与故障排查.md)

---

站内作品量以百万计，直接翻列表没有意义，找书效率取决于筛选器用得顺不顺。本篇从最粗的分类讲到最细的条件组合，最后给出两个比搜索引擎更快找到好文的入口。

## 一、先认九大主分类

站内所有作品按原作载体归进九个主分类，你追的原作属于哪类，就从那个分类进：

| 主分类 | 收什么 |
| --- | --- |
| Anime/Manga | 日本动画与漫画 |
| Books | 小说原著 |
| Cartoons | 欧美动画片 |
| Comics | 欧美漫画（超英等） |
| Games | 电子游戏 |
| Misc | 不好归类的杂项 |
| Movies | 电影 |
| Plays/Musicals | 戏剧与音乐剧 |
| TV Shows | 电视剧 |

每个主分类下再按具体作品（fandom）细分，比如 TV Shows 下面是各部剧的独立页面。找到目标 fandom 后，它的页面里还有角色（Characters）维度的进一步细分。

## 二、交叉（Crossover）单独有一个入口

两个不同世界观混在一起的同人归为 crossover，不在单个 fandom 的页面里，要进分类下的 Crossover 区找。想搜「A 作品 × B 作品」的组合，用全局搜索直接输两部作品名更快；较新版本的全局与交叉搜索里还加了「排除某类别」的筛选项（官方更新日志 v66.0 引入）——你手上如果是 64.0 这一代的安装包，未必有这个选项，以应用内实际为准。

## 三、把筛选器用顺

fandom 页面和搜索结果里都能叠加这些条件：

| 筛选维度 | 选项与用法 |
| --- | --- |
| 分级（Rating） | K / K+ / T / M 四档，含义见下方对照表 |
| 状态（Status） | Complete（完结）/ In-Progress（连载中），不想追坑就选完结 |
| 题材与角色（Genre / Characters） | 按标签排除或指定；看某个角色戏份就按角色筛 |
| 篇幅 | 字数区间与章节数 |
| 排序 | 更新时间 / 评论数 / 收藏数 / 追更数，找热门文按 Favs 排最直接 |

分级对照（官方口径，站内禁止发布 MA 级内容）：

| 分级 | 相当于 | 内容边界 |
| --- | --- | --- |
| K | 全年龄 | 无粗口无出格内容 |
| K+ | 8 岁以上 | 轻度冲突与打斗 |
| T | 13 岁以上 | 中度暴力、粗口，类 PG-13 |
| M | 16 岁以上 | 成人主题、强粗口，类 R；未成年人按站规不应阅读 |

默认列表通常只展示 K 到 T 的内容，M 级文要在设置里确认年龄后才会显示。

## 四、按语言筛，找中文作品

站内作品按**写作语言**归档，中文是其中一个语言分区：进 fandom 页面后把语言筛选切到 Chinese，列出来的就是中文写成的文。两点实际预期要先放好：

- 中文分区的存量以早年间积累的文为主，新文更新频率远低于英文区；
- 应用界面本身是英文的，语言筛选只管作品，不管界面，这一点别搞混。

界面词中英对照与站内机器翻译功能，见[界面语言与中文设置.md](界面语言与中文设置.md)。

## 五、两个比大海捞针快的入口

1. **社区合集（Community）**：老读者手工整理的专题书单，按题材建站、按质量收文。在分类页进 Community 区，找一个和口味对上的社区，等于直接拿到一份现成书单。
2. **收藏列表顺藤摸瓜**：找到一篇对胃口的文后，看作者还写了什么、被谁收藏，同好作者的收藏夹命中率通常高于随机搜索。

筛到想看的文之后，第一件事是加收藏或追更（两者的区别见[私信论坛与消息通知.md](私信论坛与消息通知.md)），第二件就是下载离线包，见[离线缓存与听书设置.md](离线缓存与听书设置.md)。

## 六、用搜索引擎定点找文

只记得情节、记不清书名时，站内搜索和通用搜索引擎配合用最快：

1. **站内搜索是「先搜后筛」**：把记得的标题或简介关键词输进搜索框，结果页右侧用 fandom、角色、语言、分级逐层收窄，最后锁定目标。
2. **通用搜索引擎加站点限定**：在搜索框输入 `site:fanfiction.net 加关键词`，只出这个站的结果。选词诀窍是用文中**独特的短语或设定名**，比用书名更容易命中被讨论过的文。
3. **跨站兜底**：同一篇文在 FFN 与 AO3 两边都有的情况很常见，站内搜不到时拿标题去另一边搜一遍；两站的找文逻辑与分工差别见[和AO3有什么区别.md](和AO3有什么区别.md)。
