# FanFiction.Net 注册登录与账号设置

不登录也能读文，但要收藏、追更、下载同步、发评论就得有账号。本篇只讲账号这一件事：注册的门槛与步骤、登录方式、设置项里几个影响别人怎么找到你和联系你的开关。

## 一、注册前要知道的几条规矩

- **年龄门槛**：官方要求注册者年满 13 岁，未满 13 岁需有监护人同意，注册时要勾选年龄确认。
- **需要有效邮箱**：激活邮件、评论与追更提醒都发到这个邮箱，邮箱被服务商退信时部分站内功能会被暂停。
- **免费**：注册与使用账号功能不收费。
- **笔名可改**：注册时填的 Pen Name（笔名）不是一次定终身，之后在账号设置里随时能改。
- **登录凭据是邮箱 + 密码**：站内登录不记用户名，认邮箱，记密码时按邮箱账号记。

## 二、注册步骤

1. 打开 [www.fanfiction.net](https://www.fanfiction.net/) 或应用内的注册入口，点右上角 Register。
2. 依次填写：笔名、邮箱（输两遍确认）、密码（输两遍确认）。
3. 勾选已读服务条款（TOS）与年龄确认，填完人机验证提交。
4. 到注册邮箱里收激活邮件，点邮件里的链接完成激活。

**收不到激活邮件**：先查垃圾箱；等久了还没到，换一个常用邮箱重注册比反复等待快。官方 FAQ 的说法是，如果站方发出的邮件被你的邮箱服务持续拒收，相关提醒功能会停用，直到你重新开启——所以注册用的邮箱别填一个很少登录的。

## 三、登录与多设备同步

- 应用里登录用**邮箱 + 密码**，不是笔名。
- 书库（Library）、追更（Follows）、收藏（Favorites）、阅读进度都挂在账号上：换手机、平板再登录同一账号，这些数据会自动同步过来——官方把这条列为应用功能之一（Syncing）。
- 一台设备上的**离线下载**不等于云同步：已下载到本机的故事只存在这台设备上，换设备要重新下载，见[离线缓存与听书设置.md](离线缓存与听书设置.md)。

## 四、账号设置里值得先动的几项

登录后进账号设置（Settings），这几项决定别人能不能联系到你：

| 设置项 | 建议做法 |
| --- | --- |
| Private Messaging 开关 | 想收私信就保持开启；关了别人无法给你发站内信 |
| 匿名评论（Anonymous reviews） | 默认允许未登录访客评论；不想收到匿名评论就关掉 |
| Display Email / Display Location | 决定邮箱和所在地是否公开展示，介意隐私的按需关闭 |
| 笔名（Pen Name） | 随时可改，不影响已发布的作品与关注关系 |

## 五、登录不上先查什么

1. 确认输入的是**注册邮箱**而不是笔名。
2. 密码区分大小写；最近改过密码的话，别用输入法记住的旧密码自动填充。
3. 换网络再试（Wi-Fi 与流量互换）。
4. 用浏览器登录 [www.fanfiction.net](https://www.fanfiction.net/) 验证账号本身是否正常——网页能登录而应用不能，多半是应用侧故障，处理顺序见[常见问题与故障排查.md](常见问题与故障排查.md)。
5. 密码忘了走登录页的找回流程，重置邮件同样发到注册邮箱。

注册登录都通了之后，第一件值得做的事是把追更和推送配好，见[私信论坛与消息通知.md](私信论坛与消息通知.md)。
