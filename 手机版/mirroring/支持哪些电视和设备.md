## 一、官方列出的支持设备

应用商店官方描述给出的接收端清单如下（型号支持会随电视固件更新变化，以官方页面当时显示为准）：

| 类别 | 具体设备 |
| --- | --- |
| 智能电视 | LG、三星、索尼、TCL、小米、海信等品牌的大多数机型 |
| 投屏器 / 棒 | Google Chromecast、亚马逊 Fire Stick 与 Fire TV、Roku Stick 与 Roku TV、AnyCast |
| 其他 | 其他 DLNA 接收器、其他无线适配器 |

手机端要求：本地记录标注安卓 5.2 以上；另有第三方页面标为 Android 6.0 或更高版本，以你的设备实际能否安装为准。

## 二、Miracast 和 DLNA 是两条路

投屏能不能成，取决于你的电视在哪条路上，两者的差别：

| | Miracast（镜像） | DLNA（推送） |
| --- | --- | --- |
| 投的是什么 | 手机整屏，操作实时同步 | 单个视频 / 图片 / 音乐文件 |
| 走什么链路 | Wi-Fi 直连为主 | 走局域网，手机可息屏 |
| 电视端要开什么 | 「无线显示 / 屏幕镜像 / Miracast」开关 | 「DLNA 服务 / 多屏互动」开关 |
| 典型用途 | 游戏、网课、演示 | 追剧、放照片、放幻灯片 |

一条实用判据：电视设置里能搜到「屏幕镜像 / Miracast / 无线显示」字样的，镜像那条路就通；只找到「DLNA / 多屏互动 / 投屏服务」的，就主要用推送。两条都有的电视，两种都能用。

## 三、官方给的操作前提

商店描述里的操作指南就四条，前提不满足后面都白试：

1. 手机和智能电视连到**同一个 Wi-Fi**；
2. 手机上启用「无线显示」；
3. 电视上启用「Miracast」；
4. 搜索并完成设备配对。

另外两条官方注意事项：使用前确认电视和安卓设备**都支持**无线显示与屏幕镜像功能；为了正确连接设备，**建议关闭 VPN**。

## 四、哪些情况大概率不支持

- **老电视**：非智能电视、没有无线模块的型号，需要另配 Chromecast / AnyCast 这类投屏器才有接收能力。
- **电视固件太老**：菜单里翻遍了也没有 Miracast / 无线投屏入口的，先查电视品牌官网的该型号说明书确认是否支持。
- **投屏器固件不匹配**：接了 Dongle 但手机始终搜不到，见 [搜不到设备怎么排查.md](搜不到设备怎么排查.md) 的排查顺序。
- **同一网络被隔离**：路由器开了 AP 隔离或访客网络时，即使两端都「支持」也发现不了彼此——这不算不支持，改路由器设置即可。

## 五、按品牌找开关

各品牌电视的投屏开关位置已在 [手机投屏到电视步骤.md](手机投屏到电视步骤.md) 第四节列了对照（LG 的 Screen Share 路径、小米电视的「无线投屏」、其他品牌的常见叫法），连电视时照着开；本篇清单与那节重复时，以那里的步骤顺序为准。
