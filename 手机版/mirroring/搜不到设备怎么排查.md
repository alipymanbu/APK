# 搜不到设备怎么排查

> 按症状查：搜不到、连上就断、电视黑屏、画面卡顿、音画不同步。

## 一、先做一遍通用三步

不管哪种症状，先把这三步走完再往下查：

1. 手机和电视连**同一个 Wi-Fi**（同一路由器，别一个连光猫一个连路由器）。
2. **关掉手机 VPN / 代理**——官方 FAQ 明确把「VPN 没关」列为搜不到设备的头号原因。
3. **重启三样**：路由器、电视（或盒子）、手机，按这个顺序重新上电再试。

## 二、设备列表是空的 / 搜不到电视

- 确认电视的投屏开关已打开（各品牌位置见 [手机投屏到电视步骤.md](手机投屏到电视步骤.md) 第四节）。
- 关掉路由器的 **AP 隔离** 和**访客模式**（登录路由器管理界面，在「设备管理」里找，改完重启路由器）。小米官方支持页与华为官方支持页都把 AP 隔离列为搜不到设备的常见原因。
- 手机别连信号放大器 / Mesh 子节点后电视连主路由这种「看似同一网络实则被隔离」的组合，先都接到同一台路由上验证。
- 手机系统里附近设备 / WLAN 扫描权限被禁的话，去设置里允许。
- 电视端开着「公共场所限制」之类的限制项会拒绝被发现，暂时关掉再搜。

## 三、连上过一会就断

- **手机自动切网**：部分手机的 WLAN 智能切换（华为叫 WLAN+）会在信号波动时自动换网络，导致镜像中断——投屏期间关掉它。
- **电池优化杀后台**：官方 FAQ 指出，电池优化可能让手机在息屏时关掉 Wi-Fi，把 Mirroring 加入电池优化白名单（或允许后台活动）即可。
- **离太远 / 干扰大**：手机与电视尽量 5 米以内、中间少隔墙；2.4GHz 频段拥挤时，能切 5GHz 就切。
- 游戏等大内存应用可能被系统清后台导致断连，投屏前先关掉不用的应用。

## 四、电视上没画面（黑屏）但手机正常

1. 先检查电视的**信号输入源**是否切到了当前连接（Chromecast、Fire TV、盒子各占一个输入）。
2. 再看你的**手机是不是息屏 / 锁屏了**——镜像方式下手机黑屏电视就黑，把手机点亮即恢复，详见 [手机息屏后电视黑屏怎么办.md](手机息屏后电视黑屏怎么办.md)。
3. 换一个内容试：有版权保护的视频（部分影视 App 的投屏）会被限制只出声音不出画面，这属于内容方限制，不是故障。
4. 重启电视后重新连一次。

## 五、画面卡顿、延迟高

| 动作 | 说明 |
| --- | --- |
| 换 5GHz Wi-Fi | 手机和电视都连同一个 5GHz 网络，是缓解卡顿最有效的一步 |
| 缩短距离 | 两端靠近路由器与电视，中间别隔承重墙 |
| 关扫描 | 投屏时关掉手机的 WLAN 扫描、蓝牙扫描（华为官方建议，会占传输信道） |
| 降低画质 | 播放端切较低清晰度，码率太高电视解不过来就会卡 |
| 重启网络设备 | 路由器断电 30 秒再上电，清掉异常连接 |

## 六、声音和画面不同步

长时间镜像后音画会逐渐错位（音、画走两条处理通路，耗时不一致）。处理顺序：断开重新连一次；手机和电视都改连 5GHz；电视端若有「游戏增强 / 低延迟模式」开关，打开它（是否支持以机型为准）。

## 七、还没解决

以上都试过仍不行，先把手机和电视换个网络环境验证（比如都连手机热点）：热点下能用说明是路由器网络问题，热点下也不行再查设备是否属于 [支持哪些电视和设备.md](支持哪些电视和设备.md) 里不兼容的情形。应用内的反馈渠道是官方邮箱 `casttotv.feedback@gmail.com`，反馈时附上手机型号、电视型号与已试过的步骤。
