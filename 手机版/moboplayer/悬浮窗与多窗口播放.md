## 一、悬浮窗播放：先给权限再谈体验

按 Home 键回桌面、或切到别的应用时，视频缩成一个小窗继续播，这就是悬浮窗模式。它依赖系统的「显示悬浮窗」权限，**这个权限默认是关的**，要先手动开：

不同品牌的设置路径（来自官方帮助页；同品牌不同系统版本菜单名会有出入，找不到就照着「应用管理 → MoboPlayer → 悬浮窗」这个思路找）：

| 品牌 | 路径 |
| --- | --- |
| 小米（旧版系统） | 其他应用管理 → MoboPlayer → 权限管理 → 显示悬浮窗 |
| 小米（新版系统） | 安全中心 → 授权管理 → 应用权限管理 → 显示悬浮窗 |
| 华为 | 手机管家 → 通知管理 → MoboPlayer → 悬浮窗管理 |
| 魅族 | 安全中心 → 权限管理 → 通知；或 设置 → 应用管理 → MoboPlayer → 权限管理 |
| OPPO | 播放视频进入悬浮窗模式 → 手机管家 → 权限隐私 → 悬浮窗管理 → 选中 MoboPlayer |

两个配套开关：

- **开启悬浮窗**：进入播放界面后选择悬浮窗模式即可。
- **Home 键联动**：播放页面右上角「⋯」→「设置」→ 勾选「Home 键开启悬浮窗模式」后，按 Home 键就直接缩窗；不想要这个行为就把勾去掉，避免每次回桌面都弹小窗。

## 二、锁屏/悬浮窗播放一段时间后闪退

官方帮助明确提到过这个现象：部分机型上，锁屏播放和悬浮窗播放跑一段时间会被系统杀掉。根因是厂商的省电策略把后台应用冻结了，处理思路以 OPPO 为例：

1. 打开手机**设置 → 电池**。
2. 找到 MoboPlayer。
3. 把**后台冻结**和**检测到异常时自动优化**两项的开关去掉。

其他品牌思路相同：在电池/省电/应用启动管理里，把 MoboPlayer 设为不受后台限制、允许后台运行。设置一次即可长期生效。

## 三、多窗口播放：一次看多个画面

适用场景：同时盯着多路比赛、多个监控画面类的视频。

操作：在文件列表页面**长按文件名** → 从右下角「更多」里选**多窗口播放**。

两条硬限制（官方帮助原文）：

- **只支持硬解播放的视频**——软解的文件加不进来，先把解码方式切回硬解；
- **最多同时打开 5 个视频**——超出就开不了新的，屏幕尺寸也会让第 4、5 个窗口小到看不清，实际建议两三个以内。

多窗口对芯片压力不小，开多了卡顿是正常的；窗内单个视频的手势操作（音量、亮度、进度）在 [常见问题排查.md](常见问题排查.md) 的手势与快进部分有完整说明。
