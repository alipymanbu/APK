## 一、常见的能直接播的格式

本地视频不用先转码就能直接播。下面是公开资料与长期使用中常见的可播格式：

| 类型 | 常见格式 |
| --- | --- |
| 视频 | MP4、MKV、MOV、AVI、RMVB、RM、WMV、FLV、3GP |
| 视频编码 | H.264、H.265/HEVC、DivX、XviD 等 |
| 音频（单独或内嵌音轨） | MP3、WMA、FLAC、WAV、M4A、RA、AAC |

注意三点：

- 「容器格式能播」不等于「任何编码组合都能播」。同一个 MKV 里塞一条冷门编码的音轨，就可能出现画面正常但没声音的情况。
- 官方没有给出一份固定的支持清单，实际表现以你手机上的测试为准；上面表格覆盖的是绝大多数日常文件。
- 4K、高码率 H.265 这类高负载视频能不能流畅播，主要看手机芯片本身的能力（见下面硬解部分）。

## 二、软解与硬解：差别在哪、什么时候换

播放同一个视频，你有两种解码路径：

| | 硬解 | 软解 |
| --- | --- | --- |
| 靠什么干活 | 手机芯片里专门的解码电路 | CPU 通用运算 |
| 耗电 | 低 | 明显更高 |
| 兼容面 | 只支持芯片认识的编码 | 兼容面广，冷门编码也能解 |
| 适用场景 | 常规 MP4/MKV、长视频连续看 | 芯片不支持的老编码、高分辨率文件 |

实操建议：

- 大多数情况不用管它，应用会自动选。
- 硬解出现花屏、绿块、画面拉伸异常时，切到软解通常就能解决；软解卡顿时换硬解试试。
- **多窗口播放只支持硬解播放的视频**（最多同时 5 个），想把多个画面摆在一起看，就别用软解那个文件。
- 切换入口在播放界面的设置项里（不同版本菜单位置略有差异），切换后从当前位置附近继续播放即可。

## 三、「有画面没声音 / 有声音没画面」先查什么

按命中概率从高到低排：

1. **有画面没声音**：先点播放界面的音轨图标（音符样式）确认音轨没有被切到空轨；多音轨文件（比如双声道+解说的 MKV）常遇到。还不行就把音量键设置查一遍——它的音量键可以设成快进快退（见 [常见问题排查.md](常见问题排查.md)），误改了会以为「没声音」。
2. **有声音没画面**：八成是编码超出了硬解能力。切软解重试；软解也黑屏，说明这条编码流当前版本处理不了，换个容器封装或转码后再试。
3. **画面卡但声音正常**：高码率 4K 用软解时的典型表现，切硬解，或把倍速调低一档再试。
4. **完全打不开、列表里没有这个文件**：先确认扩展名是常见视频容器；列表里看不到多半是扫描问题，不是格式问题。

格式能播、但字幕挂不上或显示乱码的，直接看 [字幕加载与设置.md](字幕加载与设置.md)。
