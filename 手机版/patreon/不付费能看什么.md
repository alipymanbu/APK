## 一、先把结论摆出来

Patreon 账号本身免费，注册不收钱，不付费也能用一部分：看创作者的公开帖、加免费关注、（创作者开了才有的）免费试用。会员专享帖、专属音视频与文件下载、部分评论和私信，要付费档位才解锁。你先用免费的部分判断这个创作者值不值得花钱，再决定要不要订阅。

## 二、不花钱的四条路

### 1. 公开帖（Public）

创作者标为公开的帖子，**不登录也能看** —— 从创作者主页往下翻，没有上锁标记的就是公开内容。有的创作者还会把几个月前的付费帖改成公开，隔段时间回来看一次常有收获。

### 2. 免费关注（Join for free）

2022 年起创作者可以在主页放**免费档位**，任何人都能加、不需要填支付方式：

1. 打开创作者主页，看右侧（或页面上的）会员档位列表。
2. 有一档标着 `Free` 就点 `Join for free`。
3. 之后标给免费档的帖子会出现在你的动态里，更新也会发到你注册邮箱。

**免费成员能做与不能做的**（各创作者可自行调整，以页面实际为准）：

| 事项 | 免费成员 | 付费成员 |
| --- | --- | --- |
| 看公开帖 | 可以 | 可以 |
| 收创作者的邮件更新 | 可以 | 可以 |
| 看会员专享帖 | 不可以 | 可以 |
| 下载专属音频 / 视频 / 文件 | 不可以 | 可以 |
| 在帖子里评论 | 看创作者设置，可能受限 | 一般可以 |
| 给创作者发私信 | 不可以 | 高档位才有 |

没有 `Free` 这一档的创作者，说明他只设了付费档 —— 这是对方的选择，不是你操作错了。

### 3. 免费试用（Free trial）

部分创作者给付费档位开 7 天左右的试用，在加入时会显示 `Free trial` 字样。两点注意：

- 试用到期**会自动转成付费订阅**，不想续就按 [取消会员与退款操作.md](取消会员与退款操作.md) 在扣款日前处理。
- 只有创作者开了才有，页面没出现就是没有，不存在「人人都能领」的试用。

### 4. 单篇购买

有指南提到，开了这项的创作者允许你**只买单独一篇**（入口文案类似 `Sell this post`），不必订整个月。这是创作者侧的功能，页面上没出现这个按钮就是没开，以实际显示为准。

## 三、哪些做法不算「不付费能用」

以下几类绕开了创作者的授权，属于违反服务条款，账号会被停用：

- 改链接、抓取归档、去第三方镜像站看被上锁的内容；
- 反复注册多个账号去蹭试用；
- 把付费下载转发到别处传播。

判断标准很简单：**你在应用里正常点开能看的，就是允许看的；需要绕一下才看到的，就不是。**

## 四、什么时候值得升级成付费

拿这张表对照你自己的情况，够两条就该考虑订阅了：

| 你的需求 | 免费档给不了的原因 |
| --- | --- |
| 想第一时间看到新内容 | 会员帖先发、公开帖滞后，甚至不公开 |
| 想听完整音频 / 下载到本地 | 专属内容只对付费档开放 |
| 想参与社区群聊 | 群聊是付费权益的一部分 |
| 想在评论区说上话 | 有些创作者只对付费成员开放评论 |

订阅步骤与支付方式见 [订阅创作者与付款方式.md](订阅创作者与付款方式.md)。

## 五、哪些点击会扣钱

- 浏览、搜索、看公开帖、点 `Join for free`：**不产生任何扣款**。
- 点 `Become a patron` 之后**选了付费档位并确认支付方式**：才会扣钱。
- 走到填卡号那一步随时可以退出，没点确认就不会扣。

已经在付费档位上想退回来，处理方式见 [取消会员与退款操作.md](取消会员与退款操作.md)（取消后可选择保留免费关注，继续收公开更新）。
