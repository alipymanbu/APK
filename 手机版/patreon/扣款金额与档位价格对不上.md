> 档位页面写的是美元价，账单上却是另一个数：先分清是汇率与手续费、入账时点，还是真的多扣了，再决定找谁。

## 一、先确定差在哪一类

| 现象 | 多半属于 |
| --- | --- |
| 账单人民币金额 ≠ 档位美元价按当天汇率算出的数 | 换汇手续费 + 银行自己的汇率 |
| 同一笔款先显示一个数、入账后变成另一个数 | 授权冻结与实际入账不同，等入账后再说 |
| 账单日期与扣款日期对不上 | 计费周期或入账延迟 |
| 同一时间出现两笔扣款 | 可能真有问题，见 [常见问题与故障排查.md](常见问题与故障排查.md) |

先按第一类往下看，多数情况到不了「多扣」那一步。

## 二、从美元价到人民币账单，中间过了几道

创作者的档位多以美元定价，你在应用里看到的也是这个原始标价。它变成账单上的人民币金额，中间要过两段：

| 环节 | 谁在算 | 会产生什么 |
| --- | --- | --- |
| 卡组织清算 | Visa / MasterCard 等 | 按卡组织当天汇率换算，可能加收外币转换费 |
| 发卡行记账 | 你的银行 | 用银行自己的汇率入账，有的按入账日、有的按出账日 |

- **外币转换费**：有持卡人科普汇总称，大陆发行的 Visa / MasterCard 卡这类费用通常为交易金额的 **1.5%**（个别卡 1%～1.2%），具体以发卡行公告为准。
- **汇率时点**：多家银行的结算时点不统一，消费日与入账日汇率不同就会产生差价（有媒体采访时得到的业内说法）。
- **免转换费的卡**：部分全币种信用卡按银行宣传免收货币转换费，少一道费用，但汇率差仍在。

所以「标价 $5、账单扣了 ¥40 出头」这类差额，通常不是 Patreon 多收了你的钱，而是这两段的成本。

## 三、自己核对的顺序

1. 看档位页的标价币种与账单的入账币种是否一致（美元档位对人民币账单，必有换算）。
2. 按扣款日的汇率估算一个范围，再把 1%～1.5% 的手续费算进去，看账单是否落在这个范围里。
3. **等入账完成再比**：授权阶段显示的金额与最终入账可能不同，先别急着申诉。
4. 对照账单上的扣款日期与应用里的会员计费日期，确认是同一笔。

## 四、什么情况才算真的对不上

出现下面任一条，就值得走申诉流程：

- 换算后金额与标价差距**明显超过**正常手续费范围；
- 同一笔会员出现两笔扣款，或取消后仍被扣；
- 扣款金额与你实际选择的档位对不上（比如选了低档却按高档扣）。

处理顺序：

1. 先在应用里核对会员与档位（步骤见 [订阅创作者与付款方式.md](订阅创作者与付款方式.md) 第六节）。
2. 属于 Patreon 侧的扣款问题，带扣款时间、金额、账单截图走 [support.patreon.com](https://support.patreon.com/)。
3. 属于换汇差价的，联系**发卡行**问汇率与费用口径 —— 换汇发生在银行那一段，Patreon 侧改不了。
4. 走商店（Google Play / Apple）扣的，同时看该商店的账单与申诉入口。

已付费部分退不掉的情况，见 [取消会员与退款操作.md](取消会员与退款操作.md) 第五节。
