# Patreon 订阅创作者与付款方式

## 一、订阅前先看两件事

- **先确认这个创作者有没有免费档** —— 公开帖与 `Join for free` 能看的范围，见 [不付费能看什么.md](不付费能看什么.md)；那里已经够用就不用花钱。
- **档位与价格由创作者自己定**，平台不统一定价；每个档位对应一份权益说明，先读清楚再点。
- **扣款模式由创作者选**，不同模式扣款时间差很多（见第三节），页面上写的是哪种就按哪种算。

## 二、App 里订阅的六步

1. 登录后点搜索入口（人形加放大镜那个图标），输入创作者名字。
2. 打开对方主页，点 Become a patron。
3. 在档位列表里选一档，点 Join。
4. 按提示确认所在国家 / 地区，需要时填邮编。
5. 选支付方式并填信息（见下表）。
6. 点确认，扣款成功即成为会员。

| 支付方式 | 用它要满足什么 |
| --- | --- |
| 信用卡 / 借记卡 | Visa 或 MasterCard，且开通国际线上支付 |
| PayPal | 账户状态正常、邮箱已验证、绑定的卡可用 |
| Venmo | 页面出现这个选项才可用 |

页面上出现哪几个选项由你的地区与账号决定，只列出其中一两种也是正常的。

## 三、四种扣款模式的区别

官方帮助列出的计费模式里，作为支持者你最常碰到这几种：

| 模式 | 什么时候扣钱 | 取消时要多留心 |
| --- | --- | --- |
| 按月订阅（加入日扣款） | 每月在你加入的那一天 | 提前量见 [取消会员与退款操作.md](取消会员与退款操作.md) |
| 按月预付 | 每月月初左右扣下一期 | 同上 |
| 按创作扣款 | 创作者发布付费新帖时产生扣款 | 取消后仍可能有最后一笔 |
| 按年 | 一年扣一次 | 已付的那一年一般不退 |

某位创作者用哪种，以他主页上写的为准。

## 四、支付被拒的常见原因

按 PayPal 官方帮助与用户反馈，出现「付款被拒绝」先查这几项：

1. **卡不支持国际支付** —— 国内银行发行的卡要单独确认这点，最直接的判断是拿它买一笔其他外币交易试试。
2. **卡信息与账单地址过期** —— 有效期、账单地址改过没同步。
3. **PayPal 账户受限、邮箱未验证、卡未验证** —— PayPal 帮助页把这三项列为付款被拒的主要原因，按它给的条目逐条处理。
4. **网络环境** —— 有用户反馈切换网络节点后才成功（单一来源，仅作可能原因参考）。

换支付方式重试前，先确认上一笔没有留下冻结授权，别连着提交造成重复扣款。

## 五、账单上会显示什么

按第三方汇总，这笔扣款在账单里通常显示为 `PATREON Membership`、`CKO Patreon Membership` 或 `PAYPAL PATREON` 这类字样，**一般不带创作者名字**。所以看到一笔眼生的 Patreon 扣款，先回应用把自己的会员列表翻一遍（顺序见 [常见问题与故障排查.md](常见问题与故障排查.md)）再下结论。实际字样以你的发卡行账单为准。

## 六、订阅后改档位

创作者页右上角三个点 → Your membership → Edit membership，选新档位保存。改档位与换支付方式都在这个入口附近，具体文案以当前版本界面为准。

不想续了怎么退，见 [取消会员与退款操作.md](取消会员与退款操作.md)。
