## 一、先分清是哪一类故障

三类问题的原因和解法完全不同，先对号入座：

| 现象 | 更可能是哪的问题 | 先看哪节 |
| --- | --- | --- |
| 装不上、安装报错 | 安装包没下全 / 系统禁止未知来源 | 第三节 |
| 打开就闪退、点播页崩溃 | 缓存、权限、版本过旧 | 第二节 |
| 能打开但播不动、一直缓冲 | 网络、清晰度、片源 | 第四节 |

## 二、闪退 / 打不开

按顺序试，每做一步就打开一次应用看是否恢复，能停就停：

1. **重启**：先强制停止应用再打开；不行就重启手机——多数偶发闪退到这一步就好了。
2. **清缓存**：长按 Koznak 图标 → 「应用信息」→ 「存储占用」→ 先只「清除缓存」。注意「清除数据」会把登录态和本地设置一起清掉，需要能记住账号手机号才做这一步。
3. **查权限**：同一处「应用权限」里确认存储（读写文件）已允许——离线下载、缓存播放依赖它；缺权限是安卓端闪退的常见原因。
4. **升版本**：版本过旧会与系统不兼容。你手上的安装包版本见[下载与安装教程.md](下载与安装教程.md)，官方发了新版就换新包装上（装新版前先卸载旧版）。
5. **卸载重装**：以上都无效就卸载后重装。重装会丢本地观看记录，但账号收藏与会员权益跟着账号走，装好用原手机号登录即可。

反复闪退还有一个背景值得知道：**App Store 评论区确有用户反馈过闪退现象**（属用户反馈而非官方结论）。若你的机型上每次都必现，属于机型/系统兼容问题，自查解决不了就带机型与系统版本走「我的 → 帮助中心 → 在线客服」反馈，入口细节见[会员开通与支付问题.md](会员开通与支付问题.md)。

## 三、装不上

- 安卓会默认拦截应用商店以外的安装包，按系统提示到设置里放行本次安装，步骤见[下载与安装教程.md](下载与安装教程.md) 第三节；
- 装到一半失败，多半是包没下全：重新下载，或用安装篇表格里的 MD5 比对校验，一致才继续装；
- 新装前先卸载同名旧版，避免签名或数据冲突导致安装失败。

## 四、播放卡顿、缓冲慢

1. **切清晰度**：播放页把清晰度从「高清/超清」降到「自动」或更低档，弱网下立竿见影；
2. **换网络**：Wi-Fi 和移动数据互切对比一下；能定位到是某一侧网络的问题，就固定用快的那边；
3. **清缓存**：长期不清缓存会越用越卡，按第二节第 2 步处理一次；
4. **直播对时间**：直播卡还有一种可能是系统日期不对（日期偏差会影响直播流加载），确认手机日期时间是自动的；
5. **片源本身**：个别片源加载慢，换个片或稍后重试；点播类问题可参考[怎么看电视直播和维语剧集.md](怎么看电视直播和维语剧集.md) 里播放页的操作。

以上都试过仍不行，把「机型 + 系统版本 + 版本号 + 出问题的片名/频道 + 截图」打包给在线客服，一次说全能少一轮来回。
