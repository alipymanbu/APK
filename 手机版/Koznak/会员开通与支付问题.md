## 一、会员是什么、哪些内容要会员

Koznak 里部分内容免费看，带 VIP 标识的片源需要开通会员才能播。会员是官方在应用内提供的付费权益，开通走应用内的正规支付通道，价格与权益会随活动调整——各档位的价目见第三节（带检索时间，最终以付款页面当时显示为准）。你要判断「这部片要不要会员」，看播放页有没有 VIP 标记即可。

## 二、在哪开通

1. 打开 Koznak，点底部「我的」；
2. 在「我的」页面找「会员」入口点进去；
3. 选套餐，按提示完成支付（支持的支付方式以页面显示为准）；
4. 支付成功回到播放页，VIP 内容应可正常播放。

如果你还没装应用，先按[下载与安装教程.md](下载与安装教程.md)装好。

## 三、价格与套餐（iOS 内购价目）

iPhone 端 App Store 页面列出的内购价目如下（截至 2026 年 9 月检索时的显示，之后可能调整，以你付款页面当时的价格为准）：

| 档位 | 价格 |
| --- | --- |
| 7 天会员包 | ¥8.00 |
| 单月 VIP | ¥25.00 |
| VIP 月续费 | ¥19.00 |
| 会员 3 个月 | ¥68.00 |
| 半年 VIP | ¥128.00 |
| 单部影片 | ¥3.00 |

几点提示：

- **续费比单买便宜**：同是月卡，首购 ¥25、续费 ¥19——打算连着用就直接开续费档；
- 安卓端与 iOS 端是各自独立的支付渠道，价目未必相同，安卓机上以应用内「会员」页显示为准；
- iPhone 上买错了或扣款异常，可通过 App Store 的「报告问题」页面向 Apple 申请退款（走苹果官方流程，与应用内客服是两条通道）。

另外有第三方页面提到「每日签到领积分、积分可兑换会员」这类活动（单一来源，未见官方页面确认），是否还在办、怎么兑，以应用内活动页当时显示为准。

## 四、官方帮助中心列过的支付问题

官网帮助中心（[www.koznak.tv](http://www.koznak.tv/) 的「帮助中心」，应用内「我的 → 帮助中心」也能进）专门整理了这些支付类问题，都是用户实际会碰到的：

- **购买 VIP 注意什么**；
- **无法购买 VIP**（支付按钮点不动、拉不起支付页）；
- **iPhone 用户购买 VIP，钱扣了之后还没生效**；
- **购买了 VIP，但是过几天又显示不是会员**；
- **购买 VIP 之后看视频免流量吗**（配套的「流量扣费」主题也一并在帮助中心里）。

处理思路：先确认扣款是否真的成功（看支付平台账单，而不是只看银行短信），再下拉刷新或重进「我的」页刷新权益状态；半小时以上仍未生效，把订单号、支付时间、账号手机号准备好，走下面的客服通道找官方处理——退款与补发权益只能由官方后台操作，你自己在应用里反复重装、重登是没用的。（应用打不开、闪退导致进不了支付页的，先看[闪退与播放卡顿怎么处理.md](闪退与播放卡顿怎么处理.md)。）

## 五、找官方客服的通道

- **应用内**：「我的 → 帮助中心 → 在线客服」，这是官方说明里推荐的问题反馈入口；
- **微信公众号**：`koznaktv`；
- **微博**：[@Koznak阔孜纳克](https://weibo.com/koznak)；
- **官网**：[www.koznak.tv](http://www.koznak.tv/)，页面上有帮助中心与联系方式。

反馈时把「账号手机号 + 支付时间 + 订单号 + 问题截图」一次给全，能少一轮来回。账号本身的登录、密码问题，见[投屏与账号登录问题排查.md](投屏与账号登录问题排查.md)。
