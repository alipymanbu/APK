## 一、界面就三块，先认清楚

打开应用，屏幕从上到下是：

1. **标题栏**：写着 HTML Runner。
2. **按钮行**：加载文件、运行、保存，三个按钮从左到右固定排列，任何时候都在。
3. **上下分屏**：上半部是代码编辑区（白底、等宽字体），中间一条横线，下半部是网页效果预览区。

写代码在上半部，看结果在下半部，不用来回切页面——你改完一按「运行」，下半屏就换成新渲染的页面。

## 二、默认那段示例代码是给你试手的

新装打开后，编辑区里已经有一段完整 HTML，核心是这两行：

```html
<h1>Hello HTML Runner!</h1>
<p>编辑这段代码并点击运行</p>
```

直接点「运行」，下半屏就会出现加粗的 **Hello HTML Runner!** 和那行中文说明。看到它就说明安装和运行链路都是通的，可以往下改了。

## 三、改代码 → 运行 → 再改的循环

1. 点编辑区把光标定位到要改的地方，用手机输入法改字。比如把 `Hello HTML Runner!` 改成你自己的标题。
2. 点顶部的**运行**。下半屏会按最新代码重新渲染。
3. 不满意就继续改，改完记得再点一次运行——下半屏显示的是最近一次运行的结果，看到旧效果时先想想是不是还没重新运行。
4. 想加样式或脚本，按 HTML 的常规写法放进同一个文件里，比如 `<style>` 写在 `<head>` 中、`<script>` 写在 `<body>` 末尾，然后照常点运行看效果。

小提示：编辑区和预览区各占一半屏幕，代码长的时候预览区看着局促，可以先专注上半部写完，再点运行统一看效果。

## 四、手机上打字的两个实际问题

- **缩进与换行**：手机键盘没有 Tab 键，需要缩进时空格顶替即可，HTML 对缩进并不敏感，不影响渲染结果。
- **长代码滚动**：代码写多了编辑区可以上下滚动查看，三个按钮始终排在顶部，随时点得到运行。

## 五、写完想留底

代码改满意了点**保存**，按提示输入文件名（例如 `test.html`）即可存到手机里，下次用**加载文件**接着改——具体见 [加载文件与保存文件怎么用.md](加载文件与保存文件怎么用.md)；存下来的文件想在浏览器里当成品打开，见 [保存的网页文件怎么在浏览器里打开.md](保存的网页文件怎么在浏览器里打开.md)。

运行不出来、下半屏空白或一直弹提示时，见 [常见问题与排查.md](常见问题与排查.md)；还没装的话先看 [下载与安装教程.md](下载与安装教程.md)。
