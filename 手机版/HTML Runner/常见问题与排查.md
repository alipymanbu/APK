## 一、打开就弹「Detected problems with API compatibility」

提示框原文是：

```
Detected problems with API compatibility
(visit g.co/dev/appcompat for more info)
```

这是安卓系统对应用所用旧版兼容库的例行告警，**不是安装包损坏、也不是病毒提示**。点「确定」关掉即可，关掉后编辑区、三个按钮、运行预览都照常可用。每次冷启动可能都会弹一次，属正常现象；只要它不挡住按钮，不用为它做任何设置。装完第一屏就卡在这里不敢往下走的，直接按 [下载与安装教程.md](下载与安装教程.md) 第五节操作。

## 二、点了「运行」下半屏没变化

按顺序查三处：

1. **是不是没点运行**：改完代码不会自动刷新，必须点顶部的**运行**，下半屏才会按新代码重新渲染。
2. **代码是不是写错了**：HTML 标签没闭合（`<p>` 没写 `</p>`）、把内容写到了 `</body>` 之外，都会导致渲染出来的效果和预期不一样。先把代码改回能显示的最小示例（`<h1>标题</h1>`），确认能出效果，再一小段一小段加回去。
3. **是不是加载了别的文件**：点过加载文件后，编辑区显示的是导入文件的内容，运行的也是它。想回到自己写的代码，重新输入或从保存的文件里挑回来。

## 三、保存的文件在手机里找不到

- 到文件管理器的**下载（Download）目录**按你输入的文件名找；对话框里输入什么名字就是什么名字，包括你自己写的 `.html` 后缀。
- 没写后缀的文件，有些文件管理器会显示成未知类型，按名字搜比按类型翻更快。
- 保存和运行是两件事：只点了运行没点保存，手机里不会多出文件。细节见 [加载文件与保存文件怎么用.md](加载文件与保存文件怎么用.md)。

## 四、加载文件列表里看不到我的文件

- 系统文件选择器默认可能停在「最近」或某个目录，手动切到「下载」或你实际存放的目录再找；
- 扩展名不是 `.html` 的文件（比如 `.txt`）未必会列出来，先把文件名改成 `.html`；
- 在微信里收到的文件，先「另存为 / 保存到手机」，再回应用里点**加载文件**选它。

## 五、卡顿、闪退、找不到按钮

有用户反馈在个别机型上遇到过卡顿、闪退，以及在某个版本里「找不到保存按钮」的情况——这类反馈来自单一网友留言，未必代表你的机型会遇到。真碰到时按成本从低到高处理：

1. 杀掉应用重开（闪退多发生在刚启动那几秒）；
2. 编辑区代码很长时先清空，用最小示例试，排除是内容过长导致；
3. 重装：按 [下载与安装教程.md](下载与安装教程.md) 重新从网盘拿包覆盖安装，网盘那份固定是 1.0。

## 六、版本与来源的确认

这款应用没有可查到的官网与应用商店页面，网上流传的介绍与截图真假混杂。要确认手机上装的就是那份包，看 设置 → 应用管理 → HTML Runner 的版本号（应为 1.0）与包名（`com.html.runner`），安装包信息对照 [下载与安装教程.md](下载与安装教程.md) 第四节的 MD5。
