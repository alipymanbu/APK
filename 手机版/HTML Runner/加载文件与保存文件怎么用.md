## 一、加载文件：把现成的 HTML 导进来

按钮行最左边的**加载文件**，用来打开手机本地已有的网页文件：

1. 点**加载文件**，会调起系统的文件选择界面；
2. 在里面找到你的 `.html` 文件（一般在「下载」或你存放文件的目录里）选中它；
3. 文件内容进入上半部编辑区后，点**运行**，下半屏就是这个文件渲染出来的样子。

适合的场景：别人发你一份网页文件、你自己上次存的练习、从电脑拷过来的页面，都能直接接着改。

**从微信等应用里直接打开**：在聊天里收到 `.html` 文件时，点开预览 → 右上角「用其他应用打开 / 其他方式打开」→ 在应用列表里选 HTML Runner，文件就会进到编辑区。不同机型的菜单名略有差别，以你手机上实际显示的为准；列表里没出现 HTML Runner 时，说明该机型没把这个应用列为可打开方式，改用上面「先存下来再加载文件」的办法。

## 二、保存：输入文件名，存进手机

按钮行最右边的**保存**，把编辑区当前内容存成文件：

1. 点**保存**，弹出「保存文件」对话框，输入框里的提示是「输入文件名（例如：test.html）」；
2. 按提示带上 `.html` 后缀起名，比如 `页面练习.html` 或 `test.html`；
3. 点**保存**确认，点**取消**则放弃这次保存。

存完后到手机的「下载」（Download）目录里找——文件名就是你刚输入的那个。找不到时用文件管理器按文件名搜索，具体排查见 [常见问题与排查.md](常见问题与排查.md)。

## 三、几个容易踩的点

- **文件名要自己带后缀**：对话框只让你输入文件名，`.html` 需要你自己写上，否则存出来的文件有些管理器不会识别成网页。
- **保存的是代码，不是截图**：存的是编辑区里的源码，下次用**加载文件**能原样接上继续改。
- **同名文件**：用同一个名字再保存，就是覆盖上一份；想留旧版就在文件名里加个日期，比如 `练习-0926.html`。
- **顺序别搞反**：先改代码 → 点运行确认效果 → 再点保存。运行和保存互不触发，点了保存不会自动帮你渲染。

改代码与运行的完整流程见 [手机上怎么写和运行网页代码.md](手机上怎么写和运行网页代码.md)；还没装应用先看 [下载与安装教程.md](下载与安装教程.md)。
