## 一、装之前先弄清它是干什么的

HTML Runner 是一个安卓上的网页代码编辑器：上半屏写代码，下半屏看渲染出来的网页效果，顶部固定三个按钮——加载文件、运行、保存。它适合你想在手机上随手改一段 HTML、立刻看效果的场景，比如上课练习、在外面收到别人发来的网页文件想打开看看。

装之前注意两点：

- 它是独立的手机应用，不需要配合电脑或账号，装完打开就能写；
- 这款应用查不到官网与应用商店页面，版本信息以能拿到的那个安装包为准，别去别处找「官方最新版」对照。

## 三、安装步骤

1. 把 APK 传到手机上（手机浏览器直接下载，或用数据线、局域网传输）。
2. 点开文件安装。安卓会弹「不允许安装未知来源应用」，按提示对该来源放行即可（不同品牌路径略有差异，一般在 设置 → 安全/隐私 → 安装未知应用 里）；华为、小米、vivo、OPPO 等机型还会追加「未经过安全检测」之类的风险提示，这是所有非应用市场安装包都会遇到的例行提醒，选「继续安装 / 手动安装」走完即可。
3. 装完打开：顶部是标题栏 HTML Runner，下面一排「加载文件 / 运行 / 保存」三个按钮，编辑区里已经带了一段示例代码。第一次打开可能先弹一个提示框，见下一节。

## 五、第一次打开会弹的提示

部分机型打开时会弹一个英文提示框：

```
Detected problems with API compatibility
(visit g.co/dev/appcompat for more info)
```

这是系统对旧版本兼容库的例行告警，不是安装包损坏。点「确定」关掉后，编辑区和三个按钮都能正常使用，具体处理与后续影响见 [常见问题与排查.md](常见问题与排查.md)。

装好之后怎么开始写第一段代码，见 [手机上怎么写和运行网页代码.md](手机上怎么写和运行网页代码.md)。
