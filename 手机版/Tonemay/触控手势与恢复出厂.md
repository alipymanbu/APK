## 一、为什么单独写手势这件事

耳机的核心操作都压在指甲盖大小的触控区上，而**每代型号的手势定义并不一样**——M4 上「右耳三击」是切换降噪，别家耳机可能是切歌。下面这套手势以 M4 为例整理自公开的用户使用指南，作为参照；你的耳机具体怎么按，以随机说明书或 app 内的帮助页为准（app 连上耳机后，说明书与视频教程入口见 [功能设置一览.md](功能设置一览.md) 的功能对照表）。

## 二、M4 的触控手势（供参照）

| 操作 | 手势 |
| --- | --- |
| 播放 / 暂停 | 轻触任意一边一下 |
| 接听 / 挂断电话 | 轻触任意一边一下 |
| 下一曲 | 轻触右耳两下 |
| 上一曲 | 轻触左耳两下 |
| 呼出 / 退出语音助手 | 轻触左耳三下 |
| 降噪 / 关降噪 / 通透 循环切换 | 轻触右耳三下 |
| 游戏模式开 / 关 | 轻触左耳四下 |
| 恢复出厂设置 | 无连接状态下，单击左耳或右耳五下 |

从这张表能看出一个规律：**左耳管「往回」和工具类（上一曲、语音助手、游戏模式），右耳管「往前」和听感类（下一曲、降噪切换）**。记不住全部时，先记住这个大方向，具体几下试一两轮就有肌肉记忆了。

## 三、重启、重置、恢复出厂是三件事

排查耳机问题时这三个词经常混着用，实际对应三种力度：

| 动作 | 怎么做（以官方 FAQ 与 M4 指南为参照） | 适用场景 |
| --- | --- | --- |
| 重启耳机 | 长按电源键 10 秒 | 偶发连不上、触控迟钝 |
| 重置配对 | 恢复出厂后重新配对 | 换手机用、清掉旧配对记录 |
| 恢复出厂 | 无连接状态单击任意一边 5 下（M4；其他型号看说明书） | 配对关系混乱、怎么都搜不到 |

恢复出厂会**清空耳机里记忆的配对设备**，做完之后所有之前连过的手机都要重新配一遍——这是它和重启最大的区别。所以排查顺序永远是先重启、后恢复出厂；恢复出厂解决不了的，才是该找售后的硬件问题。

## 四、触控失灵时的顺序

官网 FAQ 给的排查顺序照做即可：

1. 用干燥软布擦触控区（汗渍、油渍是最常见的失灵原因，运动后尤其明显）；
2. 确认没有误开「触控锁定」类功能（部分型号在 app 或说明书里有这个开关）；
3. 重启耳机；不行再恢复出厂。

**触控区域不需要按压**，轻触即可——用力按或按太久没反应，多数时候是手势没对上而不是坏了。个别型号的触控灵敏度可以在 app 里调，连上后翻一下设置页。

## 五、误触频繁怎么办

开放式（OWS/耳夹）和运动场景的用户反馈里误触较多，处理思路不是「修」而是「改」：

- 在 app 的按键自定义里，把容易误碰的那个手势（通常是长按或轻触一下）改成低风险动作，比如「无操作」；
- 检查佩戴角度——耳夹式戴偏了，头发或衣领蹭到触控区就是一次误触；
- 帽檐、眼镜腿反复磕碰触控区的，换一边耳朵戴或调整耳机出仓方向。

触控改不好、物理损坏类的（进水、磕碰后彻底没反应），直接走售后，见 [常见问题排查.md](常见问题排查.md) 最后一节。
