## 一、这份安装包的基本信息

Tonemay 是唐麦（Tonemay）耳机的官方配套手机应用，用来做耳机配对引导、EQ 调音、按键自定义、固件升级这类耳机端管理。安卓版的安装包信息如下（以安装包实测为准，官方页面上的版本号可能更新）：

| 项目 | 值 |
| --- | --- |
| 应用名称 | Tonemay |
| 版本 | 1.0.57 |
| 包名 | com.yscoco.tangmai |
| 安装包大小 | 159.08 MB |
| MD5 | FF62782F7E66B37E1E5FC4050049CB41 |
| 开发者 | 深圳市极麦科技有限公司 |
| 系统要求 | 官方标注需安卓 5.2 以上（以官方页面为准） |

上面的版本、大小、MD5 对应的是网盘里实际存放的那份包。官网和应用商店会随更新推进到更新的版本号，功能差异一般不大，但如果你在意「装出来的 app 版本和文档描述一致」，就用上面这份。

## 二、从夸克网盘获取安装包

1. 打开 **[Tonemay 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9367c2c89c2e)**；
2. 把安装文件转存到你自己的夸克网盘，再从网盘客户端下载到手机；
3. 下载完成后得到一个 `.apk` 文件，直接在手机通知栏或文件管理器里点开它。

手机上没有装夸克客户端时，浏览器里也能转存，但后续下载要装客户端才方便。转存这一步不能省——分享链接不保证长期有效，转存到自己网盘后资源就稳定归你管了。

## 三、安装步骤与「未知来源」授权

安卓手机默认只允许从应用商店装应用，装这个 apk 时会碰到一次授权：

1. 点开 apk，系统弹出「是否允许此来源安装应用」时选择允许（不同品牌叫法不同：小米叫「安装未知应用」，华为叫「允许安装外部来源应用」）；
2. 回到安装界面点「安装」，等进度走完；
3. 点「打开」或回桌面找到 Tonemay 图标启动。

个别品牌的系统管家会先扫一遍 apk 再放行，提示「风险应用」时选择「继续安装」即可——包名 `com.yscoco.tangmai` 与开发者（深圳市极麦科技有限公司）对得上就是官方包。装完想再核对一遍，可以看下一节的 MD5 校验。

## 四、安装后要开哪些权限

首次启动 Tonemay 会陆续申请几个权限，**蓝牙和定位这两项不同意就连不上耳机**，这是安卓系统扫描蓝牙设备的机制要求：

| 权限 | 用途 | 不开的后果 |
| --- | --- | --- |
| 蓝牙（部分机型显示为「附近设备」） | 搜索并连接耳机 | 无法添加耳机 |
| 位置信息 | 安卓 11 及以下扫描蓝牙必需；只用于设备扫描 | 搜不到耳机 |
| 存储 | 保存固件升级包、缓存 | 固件升级不可用 |

安卓 12 及以上的机型，「位置」一项大多被「附近设备」取代，弹窗允许一次即可。如果你跳过了授权又找不到在哪里补，到系统「设置 → 应用管理 → Tonemay → 权限」里逐项打开。

## 五、校验安装包完整性（可选）

下载完成后想确认包没下坏，可以在电脑上用 PowerShell 核对 MD5：

```powershell
Get-FileHash "C:\Users\你的用户名\Downloads\Tonemay_v1.0.57.apk" -Algorithm MD5
```

输出的哈希值与第一节表格里的 `FF62782F7E66B37E1E5FC4050049CB41` 一致（不区分大小写），说明包完整。对不上就重新下载一次再装。

## 六、苹果手机怎么办

这套 apk 只适用于安卓手机。iPhone 用户在 App Store 里搜「Tonemay」能找到同名的官方应用（开发者显示为 Shenzhen Jimaitech Co., Ltd），要求 iOS 15 及以上，地址是 [https://apps.apple.com/cn/app/tonemay/id6476390987](https://apps.apple.com/cn/app/tonemay/id6476390987)。iOS 版与安卓版功能基本对齐，但安装方式完全不同，不需要也不存在「转存 apk」这一步。

装好之后下一步就是把耳机连上，具体操作见 [怎么连接耳机.md](怎么连接耳机.md)；装的过程或连的过程卡住了，先翻 [常见问题排查.md](常见问题排查.md)。
