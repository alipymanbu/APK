## 一、连接前先确认两件事

**第一，你的耳机得是「能被 app 管」的那一版。** 唐麦不少型号分标准版和「APP 版 / 智联版」两档（电商页面的商品名里会写「APP版」「智联APP」字样），只有带智联功能的那一版才能被 Tonemay 识别和管理；标准版耳机用手机蓝牙听歌没问题，但 app 里扫不到它。各产品线的适配情况单独整理在 [耳机型号适配清单.md](耳机型号适配清单.md)。

**第二，权限给足了。** 首次启动 app 时弹出的蓝牙、定位（或「附近设备」）权限全部允许，跳过了就去系统设置 → 应用管理 → Tonemay → 权限里补开。这是搜不到耳机最常见的原因之一。

## 二、通过 Tonemay 添加耳机（推荐流程）

1. 确认手机蓝牙已打开；
2. 把耳机从充电仓取出（头戴式则开机），保持开盖或开机状态，让耳机进入配对模式——大部分型号首次使用会自动进配对，指示灯快闪；
3. 打开 Tonemay，进入添加设备（扫描）页面，等列表出现你的耳机型号；
4. 点对应条目，按提示完成连接。

连接成功后，主界面会显示左右耳和充电仓的剩余电量，之后每次开盖靠近手机，耳机一般会自动回连。

一个值得知道的细节：耳机在手机蓝牙列表里的名称通常是「Tonemay + 型号」（例如 Tonemay M4），配对成功会有提示音。如果你在蓝牙列表里看到多个相近的名字（比如旧配对残留的条目），选与耳机实际型号一致的；配对名与实际型号对不上时优先信任指示灯状态——快闪才是真的在等你连。

## 三、不用 app、直接在手机蓝牙里连

不装 Tonemay 也能听歌：手机「设置 → 蓝牙」里搜索设备，点耳机名称连接即可。区别在于——耳机 EQ、按键自定义、固件升级这些进阶功能只在 app 里有，纯蓝牙连接只能用默认设置。

两种方式可以并存：先在手机蓝牙里配对过一次，再用 app 管理它，这是很多人实际在用的组合。反过来，如果耳机已经被另一台手机连着，app 这边就扫不到——先在旧设备上断开或忽略配对，再回到 app 扫描。

## 四、扫描列表里没有你的耳机

按命中率从高到低逐项试：

| 现象原因 | 处理 |
| --- | --- |
| 耳机没进配对模式（指示灯慢闪或不闪） | 把耳机放回充电仓、合盖 5 秒再取出；头戴式长按电源键重新开机 |
| 耳机被其他设备占用 | 官方 FAQ 提到耳机支持记忆 5 台设备，先断开其他已连接设备的蓝牙 |
| 蓝牙/定位权限没给 | 系统设置 → 应用 → Tonemay → 权限，逐项打开 |
| 电量太低 | 先把耳机和充电仓充电 15~30 分钟再扫 |
| 距离或干扰 | 手机和耳机放 1 米内，远离路由器等 2.4GHz 干扰源 |
| 型号本身不支持 app | 对照 [耳机型号适配清单.md](耳机型号适配清单.md)，确认手里这版是「APP 版」 |

上面这些都试过仍不行，重启耳机（官方 FAQ 给的方法是长按电源键 10 秒）或重置耳机后再扫一遍。更细的排查步骤在 [常见问题排查.md](常见问题排查.md)。
