## 一、设置从哪进

主界面右上角的齿轮图标点开就是设置菜单；语言设置也可以从左下角地球按钮直接进（见[支持的语言与自动识别.md](支持的语言与自动识别.md)）。下面按「你想干什么」列常动的几项。

## 二、常动的设置项

| 你想干什么 | 去改哪项 |
| --- | --- |
| 翻完不想让它念出来 | 「翻译后自动朗读」关掉；只想静音一次就临时调低音量 |
| 译文念得太快 / 太慢 | 播放速度设置 |
| 屏幕字太小看不清 | 字体大小设置 |
| 日语译文想看罗马字 | 译文输出设置里的「显示罗马字」开关 |
| 说话总被提前截断 | 关掉端点检测（语音识别的自动停顿判断） |
| 不想收新公告的红点提醒 | 关掉「新公告通知」 |

「自动朗读」和「端点检测」是两个最容易找不到的：前者不出声时先查它，后者说话被打断时先关它，两条对应的症状分别在[常见问题与解决方法.md](常见问题与解决方法.md)第三节、第二节有完整排查。

## 三、公告红点是怎么回事

设置菜单和「公告」入口上冒红点 = 有新公告。点开公告列表红点就消；嫌它烦，把「新公告通知」关掉即可，之后仍可以手动进公告列表看。旧公告会在一段时间后从列表消失，想留的要自己截图。

## 四、翻译历史的五条规则

1. **存多少**：最多 1000 条，超了新的顶掉最老的 —— 没有归档导出，特别在意的句子趁早复制走。
2. **存谁的话**：只存你这一侧的输入，对方说的内容不进历史。
3. **删单条 / 多条**：进历史页可删，安卓版支持勾选多条一起删；目前**没有「一键全删」**，全清只能逐批勾选。
4. **换手机不继承**：历史只存在本机，换机型、重装都不会带过去。
5. **断网也能看**：翻译必须联网，但历史列表离线照样能打开。

删除和查看的入口都在设置菜单的历史项里，翻旧记录的场景见[语音翻译怎么用.md](语音翻译怎么用.md)第五节。

## 五、隐私上你该知道的两句

应用首次启动要你同意使用条款与隐私政策；语音与翻译结果在云端处理，官方说明这类输入数据会被用于多语言语音翻译技术的改进。介意的话，用完把历史清掉、别在敏感场合说敏感内容。
