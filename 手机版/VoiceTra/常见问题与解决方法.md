> 把你用 VoiceTra 时最可能撞上的问题按症状列出来：麦克风、没声音、连不上、翻不准、装不上，逐条给排查动作。

## 一、提示「未允许使用麦克风」或收不进声音

去系统设置把权限补开，安卓路径：

1. 打开**设置**应用；
2. 进**应用和通知 / 应用权限 / 默认应用**一类的菜单；
3. 点**应用权限 → 麦克风**；
4. 在列表里把 VoiceTra 打开。

权限给了还是没声，顺手确认手机没插耳机占着麦克风、没被别的录音应用霸占。

## 二、说话老是被中途截断、识别不准

- **被截断**：端点检测会在你停顿时提前收尾，去设置里把它关掉（见[设置与翻译历史.md](设置与翻译历史.md)），说完自己按确认。
- **识别不准**：设备离嘴 3 厘米左右、语速放平稳、环境别太吵；一次说太长容易出错，拆成短句效果更好。
- **结果里少了几个字**：点输入结果可以手工改字再翻，不必重说。

## 三、翻译结果没声音或音量小

按顺序过一遍，多数无声问题出在前两条：

1. 手机没处于静音模式、媒体音量已调上来（能放别的 App 的声音但 VoiceTra 没有，就查这一条）；
2. 设置里「翻译后自动朗读」是开着的；
3. 当前目标语言本身不支持语音输出 —— 语言页里没有喇叭图标就是不支持，只能看文字；
4. 以上都正常仍很小声，点翻译结果右侧的喇叭单独重放一次。

## 四、报「无法连接语音翻译服务器」

翻译在云端做，这个报错就是网络链路的问题，不是你的操作问题：

- 先确认 Wi-Fi / 移动数据本身能上网，换个网络再试；
- 网络正常时多半是服务端在忙，隔一会儿重试即可；
- 公司、校园网有上网过滤的，需要放行网络访问（官方不公开它使用的主机名与 IP）；
- 想彻底确认是不是网络的锅：**断网状态下历史记录仍能打开、翻译却不行**，就是正常的「必须联网」特性 —— 它没有离线模式。

流量方面，官方口径一次语音翻译约传输 100KB 数据；出国用建议连 Wi-Fi 或买境外流量包，漫游流量费很贵。

## 五、翻译结果明显不对

1. 先看「反向翻译」行 —— 它和你的原意不符就拆短句重说；
2. 它按一句一句的旅行会话设计，整段长文、只翻一个单词都容易翻坏，这不是故障；
3. 地名、人名官方登记了大量常用词但不保证全有，翻错可到官网 [voicetra.nict.go.jp](https://voicetra.nict.go.jp/) 的纠错页提交；
4. 输入的语言选错了也会整句跑偏 —— 看底部绿色标签是不是你的语言，切换见[支持的语言与自动识别.md](支持的语言与自动识别.md)。

## 六、装不上、闪退、卡在条款页

| 症状 | 原因与处理 |
| --- | --- |
| 商店提示无法安装 | 系统版本不达标（安卓需 10 及以上，以官网当时显示为准） |
| 安装包解析失败 | 下载不完整，重新下载并核对 MD5（参数见[下载与安装教程.md](下载与安装教程.md)） |
| 打不开、闪退 | 先重启手机；仍不行就重装一遍，安装包在本目录[下载与安装教程.md](下载与安装教程.md)里指了获取渠道 |
| 条款页一直不出现、卡死 | 到应用商店更新 Android System WebView（安卓 5/6）或 Chrome（安卓 7），重启应用 |

## 七、历史与数据类疑问

历史只存你这一侧的输入、最多 1000 条、换手机不继承、没有「一键全删」，这些规则和删除方法统一写在[设置与翻译历史.md](设置与翻译历史.md)，这里不重复。

官方支持渠道：官网 [voicetra.nict.go.jp](https://voicetra.nict.go.jp/) 上有 FAQ 与联系邮箱 `voicetra-support(at)khn.nict.go.jp`（把 (at) 换成 @；答复只用日语或英语）。
