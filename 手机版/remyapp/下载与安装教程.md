## 一、先弄清楚：你装的是什么

Remy 是华为与 KIRI 合作首发的 3D 空间记忆应用，它在华为应用市场（AppGallery）首发分发——所以装 Remy 的第一步，是先有一台装着华为应用市场客户端的设备。

网盘资源里放的是**华为应用市场安卓客户端安装包**（文件口径：版本 15.1.1.301，约 56.80M，包名 `com.huawei.appmarket`），不是 Remy 本体的安装包。装好客户端后，你在市场里搜索 Remy 就能进到它的页面。

如果安装时遇到拦截或报错，直接翻[常见问题排查](常见问题排查.md)。

## 二、从网盘拿到安装包

1. 打开 [Remy 安装文件资源（夸克网盘）](https://pan.quark.cn/s/04400fa9858a)；
2. 把文件转存到自己的夸克网盘，再从网盘客户端下载到手机存储里；
3. 下载完成后在手机的文件管理器里找到这个 `.apk` 文件，准备安装。

拿到包后想核对文件是否完整，可比对 MD5 值：`F4907D6F67F190C1EDC6E4B9BEC95200`。

## 三、按设备类型选安装方法

你的设备是哪种，决定要不要额外操作：

| 设备 | 怎么装 |
| --- | --- |
| 其他品牌的安卓手机/平板（安卓 5.0 及以上） | 直接点开 APK 安装；系统提示「未知来源应用」时按提示允许即可 |
| 华为 EMUI 设备 | 直接找到 APK 点击安装 |
| HarmonyOS 2.0 | 直接安装，如提示密码验证则输入锁屏密码 |
| HarmonyOS 3.0 ~ 4.x | 先到「设置 > 系统和更新 > 纯净模式」关闭「增强防护」，再安装，并在安装界面勾选「已了解此应用未经检测，可能存在风险」后继续 |
| HarmonyOS 5.0 及以上（纯血鸿蒙） | 装不了 APK：这类系统只支持鸿蒙原生包（.hap/.app），不再兼容安卓安装包；不过设备本身自带应用市场，不需要装这个包 |
| iOS 设备 | 不支持 |

安装完成后，建议先核对客户端版本：打开「我的 > 设置 > 检查更新」，有更新就升到新版本——官方排查「无法下载应用」问题的第一步就是更新客户端。

## 四、装好后怎么找到 Remy

1. 打开华为应用市场，登录华为帐号（部分设备不登录无法安装应用）；
2. 搜索「Remy」；
3. Remy 是鸿蒙生态的独家首发应用：HarmonyOS 设备在应用市场里搜到后直接安装；其他品牌安卓设备上能否搜到、能否运行，以市场内的实际搜索结果与官方说明为准（详见[安卓与鸿蒙设备适配说明](安卓与鸿蒙设备适配说明.md)）。

其他品牌的安卓设备建议顺手装一下 HMS Core（华为移动服务）：应用付费、安装记录、游戏充值这类功能都挂在华为帐号上，装好 HMS Core 再登录帐号会更顺。Remy 到底是个什么应用、装好后能玩什么，见[是什么与3D空间记忆玩法](是什么与3D空间记忆玩法.md)。非华为设备从获取客户端到登录帐号的完整分步流程，见[非华为手机装华为应用市场步骤](非华为手机装华为应用市场步骤.md)。
