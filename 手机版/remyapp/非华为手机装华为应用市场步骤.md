# 非华为手机装华为应用市场与 HMS Core 的步骤

> 本篇写给用其他品牌安卓手机的人：从拿到客户端安装包，到装好 HMS Core、登录华为帐号的完整流程。

## 一、先确认你的设备符合条件

- 其他品牌的安卓手机/平板：官方口径支持大多数安卓 5.0 及以上设备；
- 华为设备（EMUI / HarmonyOS）：自带应用市场，不需要按本篇操作；
- iOS 设备：不支持。

设备类型的完整对照（含鸿蒙各版本能不能装 APK）见[安卓与鸿蒙设备适配说明](安卓与鸿蒙设备适配说明.md)。

## 二、拿到客户端安装包：两条路

1. **网盘资源**：[Remy 安装文件资源（夸克网盘）](https://pan.quark.cn/s/04400fa9858a)里就是客户端安装包（版本 15.1.1.301 口径），转存后下载到手机即可；
2. **官方网页版**：用手机浏览器访问华为应用市场网页版（[appgallery.huawei.com](https://appgallery.huawei.com/#/Featured)），页面上的下载入口在**左上角**（用电脑浏览器打开时在**右上角**）；官方提示手机上用 Chrome 打开时需要 Chrome 100.0.4896.58 或更新版本。

两条路拿到的是同一个客户端，任选其一。

## 三、安装客户端

按系统执行：三方安卓设备直接装（按系统提示允许「安装未知来源应用」）；华为 EMUI 设备直接装；HarmonyOS 3.0~4.x 先关纯净模式的「增强防护」。完整对照表见[下载与安装教程](下载与安装教程.md)的安装方法一节。

## 四、装 HMS Core（华为移动服务）

非华为设备上，应用付费、安装记录、游戏充值这类功能都要挂在华为帐号上，官方建议登录前先装 HMS Core：

1. 打开设备自带的应用商店搜「HMS Core」，能搜到就直接装；
2. 搜不到就在应用市场里搜「HMS Core」安装；
3. 更新方法：设置 > 华为帐号 > 设置 > 检查新版本。

## 五、登录华为帐号

打开应用市场「我的」页登录。登录不上时：先换网络试，再确认系统日期与时间开了自动设置，仍不行就更新 HMS Core 或删除其数据（设置 > 应用管理 > HMS Core > 存储）——更完整的排查见[常见问题排查](常见问题排查.md)。

## 六、装完了去哪找 Remy

应用市场顶部搜索「Remy」。Remy 是鸿蒙生态的独家首发应用，能否在你的设备上搜到，以市场内实际结果与官方说明为准，详见[安卓与鸿蒙设备适配说明](安卓与鸿蒙设备适配说明.md)。
