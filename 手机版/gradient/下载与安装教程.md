## 一、安装前先核对包信息

Gradient 是 Ticket To The Moon, Inc. 开发的 AI 照片编辑应用。你手上这份安装包来自第三方整理，与官方商店在架的最新版不一定同版，动手前先核对这几项：

| 项目 | 这份安装包的值 |
| --- | --- |
| 应用 | Gradient（AI 照片编辑） |
| 包名 | `com.tickettothemoon.gradient.photo` |
| 版本 | 2.13.4 |
| 安装包大小 | 213.94 MB |
| MD5 | `98E211C40543EACF0E64E35141C4E3ED` |
| 开发者 | Ticket To The Moon, Inc. |

包名是最可靠的核对点：`com.tickettothemoon.gradient.photo` 与 Google Play 上架的应用一致，装上后应用商店能识别出它。

想校验文件完整性，在 Windows 上可以用自带的 certutil（在 APK 所在目录执行）：

```powershell
certutil -hashfile "gradient_v2.13.4.apk" MD5
```

输出的哈希与表中 MD5 一致，说明文件没有在传输中损坏。手机端用带「文件校验」功能的文件管理器也能查。

## 二、把安装文件拿到手机

1. 打开上面的 **gradient 安装文件资源（夸克网盘）** 链接，先把资源**转存到自己的网盘**（不转存直接下载，分享失效后就没法续传了）。
2. 在夸克网盘 App 里找到转存后的 APK 文件，下载到手机存储。
3. 下载完确认文件大小约 214 MB；明显偏小说明没下完，删掉重下。

## 三、安装

1. 在文件管理器里点开 APK。首次安装会提示「未知来源应用」，按提示允许你正在用的文件管理器安装应用（不同品牌路径不同，一般在 设置 → 应用 → 特殊应用权限 里）。
2. 点「安装」，等进度走完再点「打开」。
3. 首次启动会申请照片 / 存储权限，允许后才能从相册选照片进行编辑。

安装包本身 213.94 MB，解包安装后占用更大，手机剩余空间建议留出 1 GB 左右再装。

## 四、系统要求

官方商店对**当前在架版本**标注的系统要求以 [Google Play 页面](https://play.google.com/store/apps/details?id=com.tickettothemoon.gradient.photo)为准。本文这份 2.13.4 属于较早的版本，对系统版本的要求通常低于在架新版；是否满足以安装时系统给出的实际提示为准。

## 五、安装失败先查这几项

- 文件没下完整（大小远小于 214 MB、点开提示「解析包出现问题」）→ 删掉重新下载；
- 手机剩余空间不足 → 清出 1 GB 左右再装；
- 系统版本过低 → 安装时系统会直接提示不满足要求；
- 之前装过同包名的损坏版本 → 先卸载旧版再装。

逐一排查仍装不上的，看 [常见问题与故障排查.md](常见问题与故障排查.md)。
