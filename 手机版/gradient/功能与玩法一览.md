## 一、打开之后怎么用

打开应用后，主界面是一列功能入口，每个入口对应一类玩法；绝大多数玩法的流程都是同一个三步：**选照片 → 等处理 → 保存或分享**。本文对应的是 2.13.4 版安装包，入口的名称与排布可能和商店在架的新版有差异，以你手机上实际显示的为准。

## 二、功能速查表

下表按官方商店页列出的功能整理：

| 你想做什么 | 找哪类入口 | 说明 |
| --- | --- | --- |
| 测自己和哪位名人最像 | AI 测试（名人相似） | 玩法与照片要求见 [AI趣味测试怎么玩.md](AI趣味测试怎么玩.md) |
| 把自己的脸变成卡通形象 | AI 测试（卡通角色） | 同上 |
| 一键磨皮、亮眼 | 美颜滤镜 | 多为「点一下套用」，可换不同风格多试几次 |
| 照片变成油画、动画画风 | 艺术滤镜 | 风格滤镜类，生成需要等待 |
| 上一键妆容 | 妆容滤镜 | 从淡妆到浓妆都有，可叠加调整 |
| 调整身材比例 | 身材滤镜 | 对全身照效果更明显 |
| 试发型、发色 | 发型 | 先试再决定要不要真去剪 |
| 去掉路人、杂物 | 物体移除 | 涂抹要删的区域，适合清理背景 |
| 改脸部光影 | 面部补光 | 逆光、阴天拍的人像常用 |
| 美白牙齿、调整笑容 | 牙齿与微笑 | 笑容幅度别调太大，容易假 |
| 裁剪、旋转、亮度对比度 | 经典工具 | 不依赖 AI 处理的基础编辑 |

## 三、哪些功能会撞上订阅墙

官方的口径是 Gradient Unlimited 订阅解锁「全部工具、滤镜与功能」。免费版到底能免费用哪些，官方没有公开清单，实际判断方法很简单：

1. 点进某个滤镜或测试；
2. 弹出价格 / 订阅页 → 这一项需要订阅；
3. 直接进入编辑界面 → 免费可用。

不用预设哪个一定免费：同一个列表里免费入口和订阅入口混在一起，撞墙就换下一个玩。有第三方目录把免费版的边界概括成「少量滤镜加基础编辑可用」，也见过「全部功能免费」的说法——后者与官方商店页的订阅说明直接冲突，**以官方口径为准**。订阅价格与取消步骤见 [订阅价格与自动续费说明.md](订阅价格与自动续费说明.md)。

## 四、编辑完的照片去哪了

用应用内的保存 / 分享按钮导出后，照片会出现在系统相册里，在图库中按最近时间找即可。注意：生成中途直接退出应用，结果不会自动保存，只能重新跑一遍。

还没安装的，先看 [下载与安装教程.md](下载与安装教程.md)；玩的过程中遇到问题，查 [常见问题与故障排查.md](常见问题与故障排查.md)。
