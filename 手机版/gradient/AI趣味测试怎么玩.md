## 一、有哪些测试

- **名人相似**：上传一张你的照片，看 AI 认为你和哪位名人长得像，一般给出一个最像结果加若干候选；
- **卡通角色**：把你的脸转成卡通形象；
- **动物相似**：看你「像哪种动物」，结果同样是一张可保存的拼图；
- **古典肖像 / 文艺复兴画风**：把你的照片改画成 15 世纪古典油画风格的肖像；
- **血统估计**：AI 判断你「像哪些国家 / 地区的人」。这类结果纯属娱乐，**不构成任何真实的族裔或血缘结论**，当个乐子看就好；
- 其他不定期上线的 AI 小测试：版本不同，列表不同，以应用内实际显示为准（2.13.4 与商店新版可玩的测试不完全一样）。

## 二、照片怎么选（决定成败的一步）

- **单人正脸**，不戴墨镜、口罩，脸在画面里占比别太小；
- **画面里别出现第二张脸**：合照里检测到的可能不是你；
- **光线均匀**，别逆光；侧脸、低头、运动模糊的照片容易测不出，或结果飘忽；
- 同一个人换不同照片，结果可能不一样（尤其是名人相似和血统估计），属于这类功能的正常现象，不用反复重测较真；
- 别用别人的照片去测，一是没意义，二是涉及他人肖像。

## 三、跑一个测试的完整步骤

1. 主界面进入 AI 测试类入口，选想玩的测试；
2. 从相册选照片（或直接拍一张）；
3. 等处理完成。人像生成需要一点时间，中途杀掉应用就得从头再来；
4. 出结果后点保存 / 分享，把图导出到相册再发出去；应用内直接分享走的是系统分享面板，和平时发图一样。

名人相似这类测试的结果通常是一张「你 → 名人」的渐变拼图：你的照片开头、名人照片收尾，中间两张过渡画面；底部可以切换方形 / 长条两种版式。对结果不满意，可以直接点「下一个」再看另一位匹配对象，不用重选照片。不同版本的按钮名称和版式略有差异，以实际界面为准。

## 四、常见失败与处理

| 现象 | 先做什么 |
| --- | --- |
| 一直「处理中」或中途报错 | 换一个稳定的 Wi-Fi / 流量重试，再不行清应用缓存重开 |
| 提示「未检测到人脸」 | 换正脸、清晰、光线好的照片 |
| 点进去直接弹订阅页 | 这项需要 Gradient Unlimited，处理思路见 [订阅价格与自动续费说明.md](订阅价格与自动续费说明.md) |
| 结果没保存就没了 | 生成后没有点保存，只能重跑；导出位置见 [功能与玩法一览.md](功能与玩法一览.md) |

还没解决的，按现象查 [常见问题与故障排查.md](常见问题与故障排查.md)。
