## 一、两档会员有哪些权益

2025 年 11 月，官方把会员制度全面改版：基础聊天对所有用户保持免费，付费集中在 MMPro / MMPro+ 两档订阅。官方公告列出的会员权益如下（具体档位与额度以 App 内 VIP 权益页为准，截至 2026-09）：

| 权益 | 说明 |
| --- | --- |
| 金平糖发放 | 订阅期间每月送糖 |
| 记忆专用折扣 | 给角色添加「记忆」时享折扣 |
| 角色扮演设定 | 按角色细分性格与语气 |
| 去广告 | 关闭广告位 |
| 高级语音消息 | Premium 语音消息，可播放数扩展 |
| 会话重播 / 推进次数增加 | 「会话重播」「会话推进」额度变大 |
| 角色持有栏位扩展 | 能同时持有的自建角色更多（见 [角色创建与AI绘图.md](角色创建与AI绘图.md)） |
| 群聊数量增加 | 可创建的群聊更多（见 [群聊与发现页玩法.md](群聊与发现页玩法.md)） |
| 备忘录收藏数扩展 | 收藏上限提高 |
| 角色图像生成 | 会员档可用 |

MMPro 与 MMPro+ 的差别在额度与深度，逐项数值官方没有公开对照，开通前在 App 内权益页核对你要的那几项。

## 二、会员还是单买金平糖

官方公告引用付费会员的反馈，普遍说法是订阅比按次充值划算。判断标准看你用不用得上**创作类权益**：

- 只是偶尔买糖聊天 → 单次充值够用（充值入口见 [金平糖获取与商店消费.md](金平糖获取与商店消费.md)）；
- 常画图、常给角色加记忆、常建群、烦广告 → 这几项叠起来，订阅档通常更合。

## 三、订阅与解约

- 付费需年满 18 岁（官方订阅条款明确此要求）；
- 支付走订阅渠道：安卓经 Google Pay，iOS 经 Apple Pay，官方条款还提到日本便利店支付等当地方式；
- 订阅周期自开通日起算，具体档位与到期日在账户信息里查；
- 解约随时可办：到期前在 App 内管理画面（或对应商店的订阅管理）关闭自动续订，权益保留到本期结束。

订阅价格按地区与设备不同而不同，以支付页实际显示为准。

## 四、别忽略免费的部分

改版后的口径是「基础聊天体验完全免费」——免费额度（每日任务、看广告、邀请好友）与付费订阅并不冲突，很多权益的缺口可以先用免费攒糖补。免费获取的三条路见 [金平糖获取与商店消费.md](金平糖获取与商店消费.md)。
