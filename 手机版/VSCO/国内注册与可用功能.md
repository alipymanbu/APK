## 一、注册方式：只用邮箱

VSCO 官方支持页有一篇专门面向国内用户的指引（截至 2026-03），要点很明确：

- 选 **Sign up with email**（邮箱注册）；
- **不要**用 Sign in with Apple 或 Sign in with Google；
- **不要**用 Sign up with phone（手机号注册）；
- 官方提到 `qq.com` 后缀的邮箱实测可以顺利完成注册。

如果打开应用连注册、登录按钮都看不到，官方给的排查办法是把应用从后台彻底关掉再重开一次。

完整的注册步骤与账号管理在 [注册登录与账号管理.md](注册登录与账号管理.md)，这里不重复。

## 二、注册之后，哪些功能能用

官方同一篇指引里给了功能可用性表（截至 2026-03，以官方页面为准）：

| 功能 | 是否可用 |
| --- | --- |
| 编辑（Editing） | 可用 |
| Studio（本地素材库） | 可用 |
| Feed（关注动态） | 不可用 |
| Discover（发现页） | 不可用 |
| Profile（个人主页） | 不可用 |
| Spaces（共创空间） | 不可用 |
| Publishing（发布） | 不可用 |
| Messaging（私信） | 不可用 |

翻译成大白话：**把它当修图工具用没问题**，编辑和 Studio 这条主线都在；社区那一侧（看别人的作品、发自己的作品、私信）当前用不了。修图功能的用法见 [滤镜与修图功能指南.md](滤镜与修图功能指南.md)。

## 三、登录转圈、加载失败的排查

- 先确认其他应用能正常联网；
- 换一个网络环境再试——部分网络访问 VSCO 服务器不稳定；
- 把应用彻底关掉再重开；
- 换新设备登录时留意邮箱，可能收到一封设备验证邮件，点完验证才能继续。

注册成功后滤镜带锁、会员状态不对，看 [会员订阅与免费版区别.md](会员订阅与免费版区别.md)；其他疑难杂症集中在 [常见问题与解决方法.md](常见问题与解决方法.md)。
