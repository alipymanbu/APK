## 一、先分清哪些不要钱

| 能力 | 免费账号 | 会员 |
| --- | --- | --- |
| 预设（滤镜）数量 | 十余款（官方不同页面标注 10~16 款不等，以应用内实际显示为准） | 200+ 款完整预设库 |
| 基础调节工具 | 有（曝光、对比度、饱和度、裁剪等） | 有 |
| RAW 照片编辑 | 无 | 有 |
| 视频编辑 | 无 | 有 |
| 保存自定义配方 | 无 | 有 |

这些数字会随版本变动，以你打开应用后看到的为准；档位与价格的细节见 [会员订阅与免费版区别.md](会员订阅与免费版区别.md)。

## 二、把照片导入 Studio

1. 底部导航进「Studio」（工作台），这是你本机的照片池；
2. 点「+」从相册选照片，可以一次选多张；
3. 点其中一张进入编辑。

注意：Studio 里的照片存在手机本地、不在云端，卸载应用或清理数据前先把要留的导出到相册。

## 三、套滤镜与调参数

- 进编辑页后，滤镜列表在下方横排，点缩略图即可预览效果；
- 再点一次已选中的滤镜会弹出**强度滑杆**——不用非得 100%，拉到 60~80% 往往更接近真实胶片的观感；
- 「调整」页签里是参数工具：曝光、对比度、饱和度、色温，以及颗粒（Grain）、褪色（Fade）这类胶片质感工具；
- 裁剪和倾斜（Skew）用来修正水平线与透视，拍歪的楼、倾斜的海平面都能救回来。

## 四、配方（Recipes）：把调好的组合存下来

会员可以把自己调好的一套「滤镜 + 参数」存成配方，下一张照片一键套用，这是保持整组照片色调统一最省事的做法。免费账号没有这一项，只能手动重复同样的调整。

## 五、RAW、视频和拼贴

- **RAW**：会员可以直接导入相机的 RAW 文件编辑，白平衡和影调的调整余地比 JPEG 大得多；
- **视频**：会员能用与照片同一套预设剪视频，支持裁剪、变速和 HSL 调色；
- **拼贴 / 蒙太奇**：用现成模板或空白画布把多张照片拼成一张；蒙太奇（Montage）还可以把照片、视频、形状分层叠放，调每层的不透明度做二次曝光效果。

## 六、导出与保存

1. 编辑完成后点「下一步 / 保存」；
2. 选「保存到相册」，照片会写进系统相册；
3. 也可以直接分享到其他应用，或发布到 VSCO 自己的社区——带 #VSCO 标签有机会被官方精选收录。

两个容易踩的坑（官方说明过的）：

- **批量导出多张照片时，先把屏幕自动锁定关掉**（或导出期间保持触屏），否则导出会中途停止；
- 相册里找不到刚导出的照片，把相册排序切成「最近添加」再看。

想把 Studio 里的照片一次全部搬出来：设置 → Preferences → Export all images。

预设列表里点了却弹出锁定提示，就是会员内容——常见疑问集中在这篇：[常见问题与解决方法.md](常见问题与解决方法.md)。
