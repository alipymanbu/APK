## 一、第一次打开：先注册

VSCO 打开后要先有账号才能进编辑界面，注册入口就在首屏：

1. 打开应用，点注册（Sign up）；
2. 选 **Sign up with email**（邮箱注册）——国内用户注意：官方明确建议不要用手机号、Apple 或 Google 方式注册，原因与细节见 [国内注册与可用功能.md](国内注册与可用功能.md)；
3. 去邮箱收验证邮件——不在收件箱就翻一下垃圾箱；
4. 验证通过后设置昵称等资料，进入主界面。

注册时用常用邮箱，以后换手机、找回会员权益都靠它。

## 二、换手机 / 多设备使用

- 同一账号可以在安卓、iOS 和网页版（`vsco.co`）登录使用；
- 换新手机：装好应用后用原来的邮箱登录，账号资料与会员状态会恢复；**Studio 里的照片只存在手机本地、不跟账号走**（官方口径），换机、卸载或清理应用数据之前，先把要留的照片导出到相册；

## 三、账号相关操作入口

| 想做什么 | 去哪做 |
| --- | --- |
| 改头像、昵称 | 应用内「个人资料」页 |
| 退出登录 | 设置里的账号选项 |
| 找回密码 | 登录页点「忘记密码」，走邮箱重置 |
| 注销账号 | 官方帮助中心 `vs.co/help` 提交申请 |

## 四、登录不上怎么办

- **提示密码错误**：先走「忘记密码」重置，别反复试；
- **验证邮件收不到**：检查垃圾箱，或换一个邮箱重新注册；
- **一直转圈进不去**：先确认其他应用能正常联网，再换个网络环境试试——VSCO 服务器在部分网络下访问不稳定；
- **登录时要求设备验证**：换新设备登录可能触发一封设备验证邮件，去邮箱点完确认再回应用继续。
