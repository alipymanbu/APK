## 一、账号与登录

| 问题 | 处理 |
| --- | --- |
| 提示「超过最大试玩次数」 | 试玩额度用完了，注册真实账号是官方解决办法，完整步骤见[注册流程与试玩限制.md](注册流程与试玩限制.md)；卸载重装不会重置次数 |
| 忘记密码 | 在登录页找「忘记密码」入口走找回流程（注册时填的邮箱就是用在这里）；入口找不到时联系应用内客服渠道 |
| 换手机想接着聊 | 聊天记录存云端，新设备登录**同一个账号**即可，不需要迁移文件 |
| 注册时提示异常 | 换网络环境再试；用户名被占用就换一个 |
| 验证或登录一直转圈 | 检查网络与系统时间是否准确，时间偏差会导致证书校验失败 |

## 二、对话记录问题

- **记录会丢吗**：记录保存在云端，正常情况下不会因为卸载重装而丢失；删掉的记录没有本地找回一说，动手前想清楚；
- **想彻底重开一段**：用对话设置里的「清除记录」或「重置记忆」，比手动删快，也不影响角色卡本身；
- **历史里翻不到早前的内容**：先确认登录的是同一个账号，再确认当时聊的不是被你清除过的那段对话。

## 三、角色「人设崩了」（OOC）

聊得越久越容易崩，处理顺序从轻到重：

1. **查记忆容量**：容量调太大反而会把无关内容搅进上下文，日常对话 2~4 条更稳；
2. **补硬约束**：把「不许出现 XX」「永远第一人称」这类铁律写进角色的**前置词**，比在详细设定里念叨有效；字段写法见[角色卡创建与导入方法.md](角色卡创建与导入方法.md)；
3. **用世界书兜底**：反复被聊丢的设定（地名、规则、关系）拆成关键词条目放进世界书，命中即注入；
4. **重置当前对话**：已经聊崩的上下文会持续污染后续回复，重置是最干脆的止损。

## 四、回复异常

| 现象 | 可能原因与处理 |
| --- | --- |
| 回复被截断、说到一半停了 | 多为触发内容审查所致；可尝试换一种问法，或查看积分退还规则（见[积分消耗与收费模式.md](积分消耗与收费模式.md)第五节） |
| 一直「思考中」不出结果 | 网络波动或高峰期排队，先等一分钟；反复出现就切换网络或换一个模型 |
| 回复报错提示模型异常 | 当前模型服务波动，切换到其他模型通常立刻恢复 |
| 回复内容明显答非所问 | 检查是否切错了模型档位，或上下文已被带偏，重置对话重开 |

## 五、角色卡导入失败

按出现频率排：

1. **格式不对**：确认拿到的是角色卡文件本身（PNG 或 JSON），不是网页截图或压缩包；JSON 用文本编辑器打开能看到内容才算对；
2. **校验不通过**：旧版或第三方导出的卡字段可能对不上。较新的版本放宽了导入校验，旧版角色卡和导出的世界书配置大多能重新导入——用你手上的版本实测为准；
3. **导入成功但设定残缺**：回去检查源卡的「详细设定」「开场白」字段是否本来就空着，DZMM 只能识别卡里写了的东西；
4. **PNG 卡被二次压缩过**：经聊天软件转发再下载的图片常被压缩，内嵌数据损坏，让分享方原文件重发。

## 六、模型与参数

- **在哪切模型**：对话进行中或角色设置里都有模型选择，不同模型风格差异明显，多试几个找到贴合角色的那个；
- **温度、TopP 这类参数**：普通使用保持默认即可；想要更天马行空再调高温度，追求稳定输出就调低；
- **改了参数立刻生效吗**：对当前对话的后续回复生效，之前已经生成的回复不会重算。

排查不到的问题，去应用内帮助中心或社区论坛发帖，附上「手机型号 + 系统版本 + 应用内显示的版本号 + 报错截图」会快很多；如果问题出在安装环节（装不上、闪退），先回[下载与安装教程.md](下载与安装教程.md)第五节的清单过一遍。
