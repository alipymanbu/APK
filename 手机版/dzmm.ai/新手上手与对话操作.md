## 一、界面各处在哪

第一次打开先把五个常用位置认全，之后所有操作都在这几处之间切换：

| 位置 | 能做什么 |
| --- | --- |
| 首页 | 热门推荐与核心功能入口，刚登录看到的第一个页面 |
| 探索 / 广场 | 浏览全部角色，按标签筛选类型，点角色封面进入角色页 |
| 消息 | 你所有的对话线程列表；部分版本在这里也能进创建角色入口 |
| 左上角菜单 | 弹出功能面板：创作、设置、活动等都从这里进 |
| 右上角历史 | 翻看当前这段对话之前的记录 |

不同版本个别入口的位置会有调整（比如创作入口在右上角或左上角菜单两处都有），认功能不认位置就行。

## 二、从挑角色到发出第一条消息

1. 进「探索 / 广场」，用标签把角色按类型筛出来；
2. 点开感兴趣的角色封面，先看创作者写的说明与设定简介；
3. 选一场**开场白**开始——开场白决定了剧情从哪个场景切入，挑一个你接得住的；
4. 在输入框直接打字发送，也可以先顺着开场白回一句；
5. 对角色回复不满意，可以刷新重答，或退出来换一场开场白重开。

不想挑角色、想自己造一个或导入现成的角色卡，操作在[角色卡创建与导入方法.md](角色卡创建与导入方法.md)。

## 三、同时和多个角色聊

每个角色是一条独立的对话线程，互不干扰：你可以在消息页来回切换，这条线聊日常、那条线跑剧情，互不影响上下文。线程不用手动保存，聊过的都留在消息页里，随时点回去接着聊。

## 四、语音、背景与外观

- **语音聊天**：对话支持语音互动，入口在聊天界面里，第一次使用按提示开麦克风权限；
- **动态背景特效**：聊天界面可切换背景特效，在对话设置里调；
- **夜间模式**：设置里可切换深色外观，夜间使用更不刺眼。

## 五、记忆怎么运作、怎么调

角色能记住你之前聊过的内容，这是它区别于「每次都从头认识你」的普通聊天机器人的关键。但记忆不是无限携带的，你要管一个参数：

- **记忆容量**：决定每轮对话携带多少条历史上下文。默认值偏大，长对话时消耗涨得快；日常闲聊调到 2~4 条足够，代价是更久之前的事会「忘掉」；
- **清除记录 / 重置记忆**：每段对话都可以清除记录，角色也能单独重置记忆。想让一段剧情完全从零开始，用重置比逐条删快得多；
- **跑偏就重置**：角色明显不像原设定时，与其花好几轮纠正，不如直接重置当前对话重开，省时间也省积分（消耗逻辑见[积分消耗与收费模式.md](积分消耗与收费模式.md)）。

## 六、对话记录与多设备

聊天记录保存在云端，登录同一账号就能在任何设备上翻到历史记录，换手机不用迁移。翻旧记录用对话内右上角的历史按钮；想清掉某些记录，在对应对话的设置里操作，清之前确认云端已经同步，删了就没有本地找回一说。
