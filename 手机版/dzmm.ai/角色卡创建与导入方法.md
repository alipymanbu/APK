## 一、角色从哪来：三条路

| 来源 | 适合谁 | 在哪操作 |
| --- | --- | --- |
| 挑现成的 | 只想马上开聊 | 探索 / 广场页，官方与用户上传的角色都有，热门角色每日更新 |
| 自己创建 | 想要完全贴合自己设定的角色 | 主页右上角「创作」或「+」号 |
| 导入酒馆角色卡 | 已经在其他工具里有角色卡（PNG / JSON 文件） | 创作页里的导入入口 |

三种方式拿到的是同一种东西——一张带完整设定的角色卡。建好之后的使用方式完全一样。

## 二、创建角色：入口与各字段的作用

入口：应用主页点右上角「创作」或「+」号，进入编辑页；部分版本在消息页和左上角菜单里也有创作入口，找不到就换这两处看。

编辑页的字段不少，各管一摊，先分清主次再动手：

| 字段 | 写什么 | 对对话的影响 |
| --- | --- | --- |
| 角色名、头像 | 名字可手填；头像支持本地上传或 AI 生成 | 基础标识，对话中 AI 会以此自称 |
| 详细设定 | 性格、背景故事、说话风格、外貌、身份 | **核心字段**。AI 是否贴合人设主要看这里写得清不清 |
| 前置词（提示词） | 只写 AI 必须遵守的硬规则 | 约束力最强，适合放「永远第一人称」「不要自称 AI」这类铁律 |
| 后置词（可选） | 每轮自动附加的场景提示 | 维持氛围一致，比如固定「当前场景：雨夜码头」 |
| 世界书 | 给地名、专有名词各写一段注释 | 对话命中关键词时自动注入，防止长对话把设定聊丢 |
| 记忆设定数 | 携带上文的消息条数 | 数字越大越「记得住」，但积分消耗也越高，建议 2~6 条，具体权衡见[积分消耗与收费模式.md](积分消耗与收费模式.md) |
| 模型与参数 | 选择底层模型，调温度等参数 | 不同模型说话风格差别明显；温度高更放飞，默认值更稳 |

### 一个能直接套的设定模板

详细设定支持整段文本，可以按下面这个骨架填，比想到哪写到哪稳得多：

```text
【角色基础】
姓名：（角色名）
身份：（职业 / 种族 / 与你的关系）
性格：（两三个关键词，例如：谨慎 + 毒舌 + 重感情）
口头禅：（一句有辨识度的话，可省）
外貌：（两三句即可）
背景：（三句以内说清来历）

【对话风格】
1. 先用括号给一句心理独白，再开口说话
2. 单次回复不超过 X 行
3. 不谈论与现实无关的政治话题

【记忆规则】
记住：你的称呼、已发生的关键事件
遗忘：与现实世界有关的信息
```

模板里的「对话风格」部分也可以挪到前置词里——放哪取决于你希望它多硬：要 AI 无条件遵守就放前置词，希望它只是默认风格就留在详细设定里。

## 三、导入外部酒馆角色卡

DZMM 支持一键导入常见的酒馆角色卡，导入后系统自动识别卡内的角色设定，点开就能聊。操作步骤：

1. 准备好角色卡文件，常见格式是 **PNG**（图片内嵌设定）或 **JSON**（纯设定数据）；
2. 进入创作页，选择导入入口，选中文件；
3. 导入后检查识别出的设定是否完整（尤其是详细设定和开场白），确认保存；
4. 在角色列表里点开它，选一场开场白开始对话。

导入失败或识别不完整的情况不少见，多数是文件格式或版本兼容问题，逐项对一下[常见问题与故障排查.md](常见问题与故障排查.md)里的导入失败清单。

## 四、世界书怎么写才真的有用

世界书不是把背景故事整段贴进去，而是拆成一条条「关键词 → 注释」：

- 每条注释控制在三五十个字，写清「这是什么、有什么规则」；
- 只给**对话里真的会被提到**的名词建条目，冷门设定建了也不触发；
- 较新的版本支持概率触发：把同一条目设为概率模式并分配触发概率，多条概率内容可以用归一化按钮自动平均分配。适合「偶尔提起的传闻」这类不想每次都注入的内容；
- **世界书配置支持导入导出**：可以把建好的世界书存成文件备份，也能把别人分享的配置文件导进来，换设备或换角色复用设定时不用重打一遍。

## 五、发布到社区（可选）

自建的角色卡可以分享到社区，别人能在探索页刷到、也能收藏使用。发布前自己过一遍内容：设定、开场白是否合规，头像与立绘是否是你有权发布的素材。发布后的角色别人可以评价与反馈，后续修改在创作页的「我的作品」里进行。
