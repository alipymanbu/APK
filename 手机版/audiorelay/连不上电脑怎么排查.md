## 一、按这个顺序查（八成停在前两步）

**1. 是不是同一个网络**

手机和电脑必须在同一个局域网里。逐项确认：

- 手机连的 WiFi 和电脑连的是**同一个**（手机用流量、或电脑插网线连的是另一张网，都不算）。
- 不要连**访客网络（Guest）** —— 路由器的访客网络天然隔离设备，互相看不见。
- 两边 WiFi 频段都是 2.4GHz 或都是 5GHz 不是硬要求，但不同频段下互相发现偶尔会失灵，排除时可以先把手机切到与电脑相同的频段试一次。

**2. 路由器有没有隔离设备**

不少路由器（尤其公共网络、Mesh 的访客开关）默认禁止设备互访。到路由器管理页找这些词并关掉：**AP 隔离 / Access Point Isolation / Client Isolation / Guest Mode / Port isolation**。家用路由器一般默认关着，公司网和随身 WiFi 上很常见。

**3. 防火墙**

- 先**临时关掉**电脑防火墙试一次：能连了，说明就是它 —— 别就这么用着，去防火墙设置里给 AudioRelay 加例外，然后把防火墙开回来。
- Windows 的**网络配置文件要设成「专用」**：设置 → 网络和 Internet → 选中当前连接 → 把网络类型从「公用」改为「专用」。公用网络下系统会拦入站连接。
- 当初装电脑端时如果取消勾选过 `Add firewall rules`，重装一遍并保持勾选 —— 这条是官方排查文档明说的。

**4. VPN 在捣乱**

开着 VPN 时，要在其设置里放行局域网：打开「Allow LAN traffic」这类选项，关掉「Make invisible on LAN」这类隐身选项。没找到对应开关就先断开 VPN 再试。

**5. 还不行，做一次链路确诊**

- 用手机 ping 电脑（任意 ping 工具 App 都行）。**ping 通了却连不上**，查端口：电脑上运行

```cmd
netstat -ano | findstr "59100"
```

  AudioRelay 用的是 **59100** 端口，被别的程序占着就处理掉。开了 Hyper-V / Docker 的机器还要确认这个端口没被系统保留。
- ping 不通，回头重做第 1、2 步 —— 问题在网络层，不在软件。

**6. 反复重连、连上就断**

两端版本都更到最新（电脑端重启会提示更新，手机端到商店页更新），版本差太多会出现协议对不上、无限重连。电脑端报错「连接已断开或有东西在拦截」时，回到第 3、4 步。

## 二、USB 共享开了却列表里没条目

按 [电脑音频投到手机怎么听.md](电脑音频投到手机怎么听.md) 第三节开完 USB 网络共享后，电脑上会多一块网络适配器。官方支持人员给过的处理是：**到 Windows 网络设置里，把这块新网络从「公用」改成「专用」** —— 系统把它当公共网络时会拦掉 AudioRelay 的入站连接，列表自然刷不出条目。改完重开电脑端试。

注意 USB 线本身要能传数据：只充电的线会让手机只弹「充电」选项、根本没有「USB 网络共享」开关，换根线。

## 三、卡顿与丢包：连得上但体验差

连接正常、声音却断断续续时，按收益从大到小试：

1. **关掉不需要的蓝牙** —— 蓝牙和 2.4GHz WiFi 同频段，会互相干扰。
2. **电脑改接网线**，把 WiFi 让给手机。
3. **换 5GHz 频段**（5GHz 一般明显更好），或换到人少的 WiFi 信道。
4. **手机凑近路由器**，或关一次 WiFi 再开（有时就这么治好了）。
5. 彻底要求稳，走 USB 连法。

以上都做完还卡，缓冲与输出模式那层还有调的余地，见 [延迟和音质怎么调.md](延迟和音质怎么调.md) 第二节。

## 四、报错代码对照

电脑端弹出的错误信息对应的处理，官方错误码页给的口径：

| 报错 | 处理方向 |
| --- | --- |
| 「连接已断开或有东西在拦截」 | 回本篇第一节第 3、4 步（防火墙 / VPN） |
| `Socket error 10013` / `BIND_SOCKET_ERROR` | 端口被占用或被系统拦，查 59100 |
| `COMException - 0x88890008` | 电脑音频格式不被支持：关音效增强、换采样率，见 [延迟和音质怎么调.md](延迟和音质怎么调.md) 第四节 |
| `Child process exited with code 1` 启动失败 | 更新显卡驱动；仍不行切软件渲染，按官方社区「白屏幕」帖的操作走 |

查不到对应项时，带上报错原文与两端版本，去 [community.audiorelay.net](https://community.audiorelay.net/) 的 Help 区发帖，或发邮件到官方支持地址（页面上有）。
