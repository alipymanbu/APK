## 一、先说清这一份是哪个版本

AudioRelay 是一款把手机和电脑互相串起来传声音的工具：你既可以把电脑的声音投到手机上听（手机当音箱），也可以把手机的麦克风声音送给电脑用（手机当麦克风）。它靠局域网或 USB 线传输，电脑端和手机端各装一个，两边都开着才能工作。

动手前先对一下手上这份手机端安装包：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | AudioRelay（官网与商店的写法，全大小写如前） |
| 包名 | com.azefsw.audioconnect |
| 版本号 | 0.26.1 |
| 安装包大小 | 12.96 MB |
| 安装包 MD5 | D47B11B189B6B35C4AC42E6199706899 |
| 系统要求 | 安卓 5.2 及以上 |

**版本号别拿别处的来对。** 官网下载页现在挂的电脑端版本已经是另一条线（写这篇时是 0.27.x），官方还另有一个 1.0.0 早期访问版在测 —— 看到比 0.26.1 新的版本号属正常，这一份是固定的某一个版本，不是「当前最新版」。判断手上这份对不对只看两项：包名是不是 `com.azefsw.audioconnect`，版本号是不是 `0.26.1`。

**「安卓 5.2 以上」是安装门槛，不是功能门槛。** 装上之后要注意：把**手机自己的声音**发出去（做服务器）这个玩法，官方写明需要手机至少安卓 10；而「手机听电脑的声音」「手机麦克风给电脑用」这两个主力玩法不受这条限制。系统版本不够时，对应入口点了没反应，回看 [常见问题与设置速查.md](常见问题与设置速查.md)。

**电脑端是另一个程序，别在手机包里找。** 电脑端（官方叫 server）从官网下载页取，[audiorelay.net/downloads](https://audiorelay.net/downloads) 上有 Windows / Linux / macOS 三版，版本号与手机端各走各的。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享。相比在搜索结果里随手点一个「立即下载」，从网盘转存再下载的好处是文件固定，不会被下载站中途换成别的东西。

1. 在手机上打开 [audiorelay 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1b885e468fbf)。手机浏览器或夸克 App 都能开，**建议用夸克 App**——浏览器下大文件容易被切到后台打断。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存之后就不再依赖原分享链接还在不在。
3. 进自己的网盘找到这个包，点下载，等它落到手机存储里。
4. 下完核对两件事：文件名结尾是不是 `.apk`（这一份形如 `audiorelay_v0.26.1.apk`）；大小是不是 12.96 MB 左右。差得多就是没下完整，删掉重来。

习惯在电脑上操作也行：在电脑端网盘下载，再用数据线拷到手机的 `Download` 目录，之后从手机「文件管理」里点它安装，效果一样。

手上有校验工具的话可以顺手算一遍 MD5，和上表的 `D47B11B189B6B35C4AC42E6199706899` 比一比：一致说明传输没出错，不一致就重新下一遍。不查也不影响安装。

## 三、安装：系统会拦一次，放行即可

这一份是手动安装的，不是从手机自带应用商店点「安装」装的，所以点安装包时系统会拦一下，提示「不允许安装来自此来源的应用」之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开「文件管理」，进 `Download` 目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，找到你刚才用来打开文件的那个 App 单独放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」——电脑端还没装，先把电脑那侧理顺再一起开。

## 四、电脑端：装的时候别取消勾选

到 [audiorelay.net/downloads](https://audiorelay.net/downloads) 下载你系统对应的桌面版（Windows 10 及以上有官方安装包；Linux、macOS 也在同一页）。安装向导一路下一步即可，但**安装选项里的防火墙规则勾选（`Add firewall rules`）不要取消** —— 这一条是电脑能被手机找到的前提，官方在排查文档里明确说过：当初没勾就得重装补上。装完打开电脑端，它会自动在局域网里宣告自己，等着手机来连。

macOS 侧官方文档注明还需要额外装一个虚拟音频设备才能把 Mac 的声音发出去，以官网文档当时显示为准。

## 五、装完先做两步自检

1. **两端能不能看见对方**：手机和电脑连在同一个 WiFi 下，打开手机端切到 `Player`（播放）页，列表里应该出现你的电脑名。看不见就照 [连不上电脑怎么排查.md](连不上电脑怎么排查.md) 过一遍——十有八九是防火墙或网络隔离。
2. **声音能不能过去**：电脑端开着、手机点了电脑之后，在电脑上放一段视频，声音应该从手机出来。具体操作在 [电脑音频投到手机怎么听.md](电脑音频投到手机怎么听.md)；没声音的话看 [常见问题与设置速查.md](常见问题与设置速查.md)。

两步都过，安装环节就结束了。

## 六、升级与卸载要注意的

- **升级**：手机端新版本会换一个安装包文件名，直接装新包覆盖即可，一般不用先卸载。注意电脑端与手机端版本要配得上——两边差得远会出现反复重连，处理办法见 [连不上电脑怎么排查.md](连不上电脑怎么排查.md)。
- **卸载**：手机端直接在系统设置里卸载即可，它不改系统设置；电脑端用系统的「应用和功能」卸掉。卸载不影响已经转存到网盘的安装包。
- **安装包删了**：任何时候都能回到文首那条 audiorelay 安装文件资源的链接重新取一份；已经转存过的不受原分享是否还在影响。
