# AudioRelay 电脑音频投到手机怎么听

> 本篇讲 AudioRelay 最常见的玩法：电脑没音箱或音箱太差时，把电脑正在播的声音实时投到手机上外放。无线怎么连、USB 怎么连、连上之后在哪看延迟，一篇讲完。

## 一、先弄清谁是服务器、谁是播放器

这套玩法里两端分工是固定的，第一次用最容易搞混：

| 端 | 角色 | 干什么 |
| --- | --- | --- |
| 电脑端 AudioRelay | 服务器（Server） | 抓住系统正在播的声音，等着被连 |
| 手机端 AudioRelay | 播放器（Player） | 主动找电脑、连上去、把收到的声音放出来 |

所以动作顺序永远是：**先开电脑端，再开手机端去连它**。只开一边不会有反应。两端都装好、都启动之后，走下面的连法。

## 二、无线连法（最常用）

前提：手机和电脑在**同一个 WiFi** 下（不需要能上网，但必须是同一个局域网）。

1. 电脑上打开 AudioRelay，让它开着（最小化也行，别退出）。
2. 手机上打开 AudioRelay，切到 `Player`（播放）页。
3. 列表里点你的电脑名。连上后页面会显示连接状态与延迟数据。
4. 电脑上随便放点东西——浏览器视频、音乐播放器都行。声音会从手机出来。

之后电脑端可以选要抓哪个输出设备（插了耳机想投外放时，先确认电脑端选的设备对）。手机端这时就是一块外放：手机音量键直接调大小。

**连不上列表里没有电脑？** 不是这一步的问题，去 [连不上电脑怎么排查.md](连不上电脑怎么排查.md) 逐条过。

## 三、USB 连法（延迟最低、最稳）

官方口径是 USB 连接的体验明显好于 WiFi。没有 WiFi 或者网络太差时用它：

1. 用数据线把手机连到电脑（普通充电线即可，用手机原装线最稳）。
2. 手机下拉通知栏，找到「USB 用途 / USB 选项」，把 **USB 网络共享（USB tethering）** 打开。有的机型在「设置 → 网络和互联网 → 热点和网络共享」里。
3. 等几秒，电脑会识别出一块新网络适配器。
4. 回到 AudioRelay，服务器列表里会**多出一个条目**（对应 USB 这条路），点它就连上了。

两个注意点：

- **USB 网络共享可能让电脑走手机流量。** AudioRelay 自己的数据是局域网内传的、不计流量，但这块新网络对电脑来说是一条新互联网通路，别的程序可能顺着它上网。怕扣流量就三选一：手机同时连着 WiFi、关掉手机移动数据、或开飞行模式再单独开 USB 共享。
- **开了共享列表里却没出现条目？** 多半是防火墙把这块新网络当成了「公用网络」。在 Windows 网络设置里把它的网络配置文件改成**专用**，再看列表——这条是官方支持人员在论坛给出的处理办法，详见 [连不上电脑怎么排查.md](连不上电脑怎么排查.md)。

## 四、连上看哪几个数

连接建立后，手机端页面上能看到实时数据，判断卡不卡先看它们：

- **延迟（latency）**：正常在 10 毫秒上下。这个量级看视频、打游戏都无感。
- **丢包（packet loss）**：应该是 0%。不为 0 说明网络在丢数据，会听到断续。
- **缓冲（buffer）**：接近或超过 100 毫秒就说明在靠缓冲硬撑，网络其实跟不上，照 [延迟和音质怎么调.md](延迟和音质怎么调.md) 调。

数都正常但你仍觉得慢，先怀疑一件事：**你是不是在用蓝牙耳机听** —— 那时的延迟来自蓝牙本身，跟这套传输无关，展开见 [延迟和音质怎么调.md](延迟和音质怎么调.md)。

## 五、几台手机同时听

一个电脑端可以被多台手机同时连上，声音会同步发给每一台（多房间、多人各用各的手机听同一台电脑）。**这是付费功能**：只要有一台安卓设备买了 premium、并用它连过一次服务器，多连接就解锁到服务器重启为止；那台买了 premium 的设备后来断开也照样解锁。免费状态下只允许一台设备连。价格与解锁条件以官方页面当时显示为准，详见 [常见问题与设置速查.md](常见问题与设置速查.md)。

## 六、断了、慢了怎么办

挂机久了被手机系统清掉、WiFi 忽好忽坏，都会让连接断开或变卡：

- 手机退到后台后被系统省电机制杀了，会表现为越用越卡或直接断 —— 处理办法见 [常见问题与设置速查.md](常见问题与设置速查.md)。
- 网络本身就抖：优先把电脑接网线、手机和电脑尽量凑近路由器，或换到 5GHz 频段，完整清单在 [连不上电脑怎么排查.md](连不上电脑怎么排查.md) 的「卡顿与丢包」一节。
- 想彻底稳，回 USB 连法。
