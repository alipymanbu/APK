# AudioRelay 手机麦克风当电脑麦克风怎么用

> 本篇讲反方向的玩法：电脑没有麦克风、或电脑自带麦太差时，把手机的麦克风声音送进电脑，让会议、直播、录音软件把手机当麦克风用。三个页面各点哪里、装出来的 Virtual Mic 在哪选，逐步走完。

## 一、这条链路长什么样

声音的走向和「电脑投声音到手机」正好反过来：

```text
手机麦克风 → 手机端开「麦克风」采集 → WiFi/USB 传给电脑
→ 电脑端出现一个虚拟麦克风（Virtual Mic）→ 会议/录音软件选它
```

所以电脑端这次扮演的是**播放器**（它来收声音、交给虚拟麦克风），手机端扮演**服务器**（它来发声音）。两边页面要点的 tab 和上一篇正好互换，别照抄上一篇的点法。

## 二、三步接通

**第 1 步：手机端开麦克风采集**

1. 手机打开 AudioRelay，切到 `Server`（服务器）页。
2. 在音源列表里点 **microphone（麦克风）**。
3. 首次会弹权限申请，允许它录声音。授权后手机端就是一个在跑的服务器了。

**第 2 步：电脑端接过来**

1. 电脑打开 AudioRelay，切到 `Player`（播放）页。
2. 找到输出模式，选 **Mic**（麦克风模式）——默认是放声音的模式，这一步必须切。
3. 在服务器列表里点你的手机。连上后，电脑的虚拟麦克风里流的就是手机收到的声音。

**第 3 步：让软件用上虚拟麦克风**

到这一步电脑上多了一个叫 **Virtual Mic** 的录音设备，但软件不会自动用它，二选一：

- **设成全局默认（推荐）**：任务栏右键声音图标 → 声音设置 → 录音设备 → 找到 `Virtual Mic (Virtual Mic for AudioRelay)` → 设为默认设备，同时设为默认通信设备。之后所有软件都走它。
- **在单个软件里选**：进 Zoom / Discord / Skype / 录屏软件的麦克风设置里，直接选 `Virtual Mic`。

## 三、手机那侧要注意的

- **别锁屏太狠。** 手机作为采集端要一直跑在后台，被系统省电机制清掉后电脑那边会掉线或没声，处理见 [常见问题与设置速查.md](常见问题与设置速查.md)。
- **离嘴近一点。** 手机放桌上当麦，收的是桌上的动静；开会时把手机拿到面前，效果比凑近电脑上那颗坏麦好。
- **来电会打断。** 手机正在打电话时麦克风被通话占用，采集会中断；挂断后重新点一下麦克风音源即可。

## 四、接通了却没声音，按这个顺序查

1. **电脑端模式选对没**：`Player` 页输出模式必须是 `Mic`，不是默认的放音模式。
2. **软件选的设备对没**：软件里选的是不是 `Virtual Mic`，而不是电脑自带麦。
3. **手机端权限给了没**：`Server` 页的麦克风音源旁边如果显示异常，多半是录音权限被拒，去系统设置里补。
4. **列表里连上没**：电脑 `Player` 页能看到手机且状态是已连接。连不上走 [连不上电脑怎么排查.md](连不上电脑怎么排查.md)。

社区里还有一类反馈是「显示已连接但就是没声」，这类问题通常卡在上面第 1、2 步的模式或设备选择上，先自查这两处再去论坛提问（提问时带上两端版本号，官方支持在 [community.audiorelay.net](https://community.audiorelay.net/) 的 Help 区回帖）。

## 五、和「投声音到手机」能同时开吗

可以，两个方向用的是不同的音源与模式，互不冲突：手机 `Server` 页同时点亮麦克风音源、电脑 `Player` 页连手机放声音，两条流各走各的。唯一约束仍是上一篇提过的多连接付费规则（[电脑音频投到手机怎么听.md](电脑音频投到手机怎么听.md) 第五节）。更常见的实际冲突反而在手机侧——手机上别的 App 抢占麦克风或播放焦点时会把采集挤掉，开关位置见 [常见问题与设置速查.md](常见问题与设置速查.md)。
