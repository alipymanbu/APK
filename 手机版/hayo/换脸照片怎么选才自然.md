## 一、什么样的照片出效果最稳

换脸结果不自然，八成是原照片的问题。挑照片对着这张清单勾：

| 条件 | 为什么重要 |
| --- | --- |
| 正脸、面部朝向正 | 侧脸、低头的脸和模板角度对不上，融合处会变形 |
| 五官无遮挡 | 眼镜、口罩、刘海遮眼都会让 AI 去猜五官，猜错就崩 |
| 光线均匀 | 强逆光、阴阳脸会让肤色过渡不自然 |
| 表情自然、闭嘴照 | 大笑、龇牙的表情轮廓最难融合 |
| 单人入镜、背景简单 | 背景里有第二张脸容易干扰识别 |
| 清晰度够 | 模糊照片放大后全是涂抹感 |

手机前置摄像头直出、白天靠窗拍的半身照，通常就够用。

## 二、生成后不自然怎么调

1. **先换照片，再谈其他**：融合痕迹明显时，换一张更标准的照片重试，比反复提交同一张快得多。
2. **对着问题部位换照片**：发际线接不上多半是角度问题，肤色断层是光线问题，五官变形是清晰度问题——按症状挑下一张。
3. **接受多次尝试**：同一张照片多生成几次，结果会有差异，挑最好的一张留下。

## 三、上传人脸前的三条边界

1. **只用自己的脸，或拿到明确授权的脸**。名人与他人的肖像不要传——换脸类应用对公众人物肖像普遍有检测与限制，传了也多半被拦。
2. **产出用途要干净**：做头像、和朋友玩梗没问题；拿去冒充本人、伪造误导性内容，平台会封，法律上也有风险。
3. **读一遍授权条款**：人脸属于敏感个人信息，上传前看一眼应用内的用户协议与隐私政策（官方隐私政策：`https://www.hayo.com/privacy-policy`），确认平台怎么存、怎么用你上传的照片，不接受就不用。
