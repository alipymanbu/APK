## 一、收不到验证码 / 登录不上

按顺序排查：

1. **翻垃圾箱**：验证邮件被归进垃圾/订阅邮件的概率很高，直接搜索发件人或「hayo」关键词。
2. **等一分钟再重发**：验证码发送有间隔，连点重发反而都被限流。
3. **核对邮箱地址**：注册时多打一个字母，验证码就发去了不存在或别人的邮箱；登录不上时先确认你输的邮箱和注册时完全一致。
4. **换网络再试**：公司/校园 Wi-Fi 有时会拦邮件服务或接口请求，切流量往往就通了。
5. **卸载重装只解决应用损坏**：如果应用本身能开到登录页，重装不会改善收码问题，别反复重装。

## 二、发消息或生成没反应

| 现象 | 先检查什么 |
| --- | --- |
| 消息发出去一直转圈 | 网络是否可达：切换 Wi-Fi 与流量对比 |
| 提交绘画任务后被退回 | 剩余额度是否为 0，每小时额度是否用满 |
| 提示任务排队很久 | 同时跑的任务是否已达上限；等队列消化，不要反复提交 |
| 对话中途突然中断 | 会话过长或服务端繁忙，开个新会话重试 |
| 别的应用都能联网、只有它转圈 | 关掉代理/VPN 再试；检查是否禁用了它的联网或后台数据（安卓的流量管理、电池优化里看） |

额度相关规则在[会员订阅与生成额度说明.md](会员订阅与生成额度说明.md)里列了对照表，生成被拦时先看额度再看网络，顺序别反。

## 三、闪退 / 打不开

1. **确认安卓版本**：低于应用要求的版本（安卓 5.2 以上）会起不来或频繁闪退，这种只能换设备或用官方支持的版本。
2. **清后台重进**：与其他大型应用同跑时内存吃紧会闪退，先清后台。
3. **重启手机**：连续闪退时的老办法，但有效。
4. **重装**：安装包不完整导致的闪退，删掉后重新下载安装（拿包方式见[下载与安装教程.md](下载与安装教程.md)）。
5. **装错应用**：如果闪退的是「另一个 hayo」（语音聊天或交友那两个），本篇帮不了你——先按包名确认装的是 `com.hayo.client`，区分方法见下载与安装教程第一节。

## 四、界面能开但内容加载不出来

按顺序试：

1. **清应用缓存**（安卓：设置 → 应用 → Hayo AI → 存储 → 清除缓存；注意别点「清除数据」，那会退登录）。
2. **开关一次飞行模式**，重置网络连接；不行就重启手机。
3. **挂代理或 VPN 时先关掉**：连接路径一变，部分接口会直接失败，关掉往往就恢复。
4. **时间不对会导致安全校验失败**：提示证书错误、内容死活加载不出来时，检查手机系统时间是否准确、是否开了自动对时。

## 五、以上都试过还没解决

走官方反馈渠道：官网 [https://www.hayo.com](https://www.hayo.com)，反馈页 `https://feedback.hayo.com`。反馈时带上这些信息能少一轮来回：手机型号与安卓版本、应用版本号、做了什么操作、报错提示原文或截图。

能正常用之后，绘画和写作的具体玩法分别在[AI绘画与换脸功能怎么用.md](AI绘画与换脸功能怎么用.md)与[AI聊天与写作怎么用.md](AI聊天与写作怎么用.md)。
