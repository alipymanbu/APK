## 一、安装前先了解这款应用

Lanerc 是一款安卓端的动漫在线观看应用，前身是 Omofun（这段沿革单独写在[和Omofun是什么关系](和Omofun是什么关系.md)里）。它没有上架国内主流应用商店，搜索引擎里也很难直接找到可靠的安装入口，常见的获取方式就是拿 APK 安装包自己装——本篇讲的正是这条路。

本篇对应的安装包信息如下，装完后如果怀疑拿到的不是这一份，可以对照核对：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.6 |
| 安装包大小 | 约 30.7 MB（以实际下载到的文件为准） |
| 包名 | com.clggjv.xcjfmd.ffo |
| MD5 | 3CE06BA444797CE2BD8E9301AFD648B1 |
| 语言 | 中文 |
| 系统要求 | 安卓（安装包标注的系统门槛很低，近几年的设备基本都能满足，以实际安装时提示为准） |

两点先说清楚：

1. **包名是辨真伪的关键**。搜索 Lanerc 会撞到好几个同名但内容不同的应用，官方发布页（[lanercpro.cn](https://www.lanercpro.cn)）对应的那一支，包名就是表格里这个；具体的辨析方法见[安装包核对与同名应用区分](安装包核对与同名应用区分.md)。
2. **版本会更新**。官方发布页显示的版本号可能已经高于 1.0.6，本篇表格只描述网盘里这一份安装包；要不要追新版，以官方页面说明为准。

## 二、拿到安装包

1. 打开 [Lanerc 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9d1d7c0aa0ea)；
2. 按页面提示把文件转存到自己的网盘账号，或直接下载到手机；
3. 下载完成后你会得到一个 `.apk` 文件（文件名形如 `Lanerc_v1.0.6.apk`），它就是安装包本体。

安装包本身不大，流量下载也不吃力；装好后的观看是在线播放，流量主要消耗在看视频的环节，建议日常在 Wi-Fi 下使用（离线缓存的用法见[播放与离线缓存怎么设置](播放与离线缓存怎么设置.md)）。

## 三、安装步骤

1. 在文件管理器里点开刚下载的 `.apk` 文件；
2. 系统弹出「是否允许安装未知来源应用」时选择允许。安卓 8.0 以上一般是：设置 → 应用管理 → 特殊应用权限 → 安装未知应用，给你用来打开安装包的那个文件管理器（或浏览器）放行；小米机型可能要先在「纯净模式」里关闭拦截；
3. 回到文件管理器重新点开安装包，等安装完成，点「打开」或回桌面点图标进入。

第一次打开通常会有基础设置或权限请求（如存储权限，离线缓存要用到），按需允许即可。

## 四、装不上时的常见情况

| 现象 | 原因与处理 |
| --- | --- |
| 提示「禁止安装未知来源应用」 | 系统默认拦截外部 APK，按第三节的路子先放行来源，再重试安装 |
| 安装到一半失败 / 提示包损坏 | 下载过程出问题的可能性最大，删掉重下一次；重下仍失败就核对 MD5（方法见第五节），对不上说明文件在传输中出了岔子 |
| 提示「与已安装应用冲突」 | 手机里已经装过同包名的版本（可能是旧版或别处拿的包），先卸载旧的再装 |
| 手机管家报风险提示 | 侧载 APK 被安全软件标记是这类应用的高频现象，先别急着点继续，按[安装包核对与同名应用区分](安装包核对与同名应用区分.md)里的顺序核对完再决定 |

## 五、怎么核对拿到的文件

第一节表格里的 MD5 是这份安装包的「指纹」，文件内容有任何一点改动它都会变。核对办法：

1. **在电脑上**：把 APK 传到电脑，打开命令提示符（CMD），输入 `certutil -hashfile "文件完整路径" MD5`，输出的十六进制串逐字对照第一节的值（不区分大小写）；
2. **在手机上**：部分文件管理器自带「文件校验」或「属性」功能，能直接算 MD5；没有这个功能就先装后用，这一步不是必做；
3. **两个快速对照**：文件大小约 30.7 MB、装出来在应用信息里显示的包名是 `com.clggjv.xcjfmd.ffo`——这两点对得上，基本就是同一份包。

MD5 对不上时不要安装，回到获取渠道重新下载一次再看。

## 六、装好之后

第一次打开建议先花两分钟认识首页结构，再直接搜一部想看的番试播——找番的几条路径、分类怎么筛、收藏追番怎么做，都写在[怎么找番和追番](怎么找番和追番.md)里；播放器里能调什么（清晰度、倍速、弹幕、离线缓存）见[播放与离线缓存怎么设置](播放与离线缓存怎么设置.md)。之后遇到打不开、点开就退的情况，按[闪退打不开怎么排查](闪退打不开怎么排查.md)的顺序处理。
