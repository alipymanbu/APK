## 一、信息流加载失败或一直转圈

- 先用浏览器确认能否打开 `e621.net`。站点服务器在海外，网络波动时客户端会先于浏览器表现出加载慢或失败。
- 只在移动数据或只在 Wi-Fi 下失败时，换个网络再试一次，先把网络环境因素排除掉。
- 网络环境受限时，客户端设置里提供**通过代理服务器连接**的选项；有自建代理条件的话，填入代理信息后重试。
- 缩略图能出但点开的大图卡住，多是原图体积大 + 网络慢，稍等或换网络再看。

## 二、登录失败

按顺序核对：

1. 用户名密码是否输入正确——最稳的验证方式是先在浏览器里登录一次站点网页版，能登上说明凭据没问题。
2. 注册后**邮箱是否已验证**。没点验证邮件里的链接，账号处于未激活状态，客户端里也登不上。
3. 注册入口是否处于开放状态。站点偶尔阶段性调整注册政策，以官方页面当时的显示为准。
4. 切换过站点（e621 ↔ e926）的话，客户端对两个站点分别保持会话，发现登录状态没跟过去就再登一次。
5. 登录页如果要求的不是密码而是**API 密钥**：密钥在站点网页端的账号设置里生成，复制粘贴进来即可（不同客户端版本要求的凭据形式可能不同，以登录页提示为准）。
6. 忘记密码走站点网页端的找回流程。

更多注册与登录背景见[账号注册与登录.md](账号注册与登录.md)。

## 三、关注标签收不到通知

- 通知依赖客户端在后台检查新帖，机型的省电策略把后台杀掉是最常见的原因：在系统设置里允许该应用后台运行 / 自启动，并把通知权限打开。
- 关闭电池优化后观察一天，仍收不到再回来排查。
- 想确认关注标签本身有没有新帖，可直接打开主菜单里的 Followed tag posts（关注标签的帖子汇总）列表核对，不依赖通知。

## 四、广告问题

- 网盘这份是 web 版安装包，内置的广告是**可选的**，进设置直接关闭即可，不需要任何额外操作。
- 如果想要完全没有广告模块、也不连 Google/Firebase 的版本，官方另提供 clean 版 APK，可在作者官网 [zepiwolf.se/tws/](https://zepiwolf.se/tws/) 下载。

## 五、下载失败

- 打开下载管理器（Queued downloads），失败任务会显示具体错误信息，点手动重试；不会自动补跑，也不会留下 0 字节文件。
- 反复失败先查两项：应用的存储权限是否被拒；手机剩余空间是否够。
- 连续大批量下载时，偶发的临时性失败可能与站点限速有关——官方 API 文档给的速率上限是每秒 2 次请求。表现为零星几条失败，停一小会儿再点重试通常就好；整批全挂才需要往网络方向排查。
- 批量下载整本漫画时中途断网，重试失败的那几页即可，不必整本重来。操作细节见[图片下载与批量保存.md](图片下载与批量保存.md)。

## 六、闪退与异常行为

- 先确认版本：作者迭代很快，很多崩溃在后续版本已修复。网盘这份为 beta-4.13.1（信息表见[下载与安装教程.md](下载与安装教程.md)），想升级去官网 [zepiwolf.se/tws/](https://zepiwolf.se/tws/) 拿最新包。
- 官方反馈渠道有三个：官网页面下方的评论区、Telegram 更新频道 `@thewolfsstash`、反馈讨论群 `@WolfsStash`，也可私信作者 `@ZepiWolf`。反馈时带上机型、系统版本与复现步骤，处理得快。
- 换 clean 版或 Play 版也是绕开崩溃的常见办法——不同发行渠道在个别机型上表现会有差异。

## 七、想清掉占用空间

- 清缓存：设置里可调缓存上限，调小即触发清理；缓存只影响浏览速度，已下载保存的文件不受影响。
- 彻底重置：卸载重装会清掉全部本地数据（黑名单、搜索历史等都是本地存储），重装前把黑名单内容抄一份能省不少重配时间。
