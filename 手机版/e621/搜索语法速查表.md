## 一、基本组合

把若干标签写进同一个搜索框，就是在组合查询：

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| `标签A 标签B` | 同时满足（且） | `雪地 城市` |
| `标签A or 标签B` | 满足其一即可（或） | `猫 or 狗` |
| `~标签A ~标签B` | 与 `or` 等价的旧写法 | `~猫 ~狗` |
| `-标签` | 排除 | `城市夜景 -人物` |
| `(标签A 标签B)` | 分组，先算括号内 | `(猫 or 狗) 雪地` |
| `-(标签A 标签B)` | 整组排除（两者都不要） | `-(深夜 车内)` |
| `前缀*` | 通配符，匹配任意结尾 | `inter*` |

标签之间用下划线连接空格：想搜的标签本身带空格时（如某角色名「izzy musa」），写成 `izzy_musa`。

## 二、常用 metatag

metatag 不描述画面内容，而是描述帖子本身的属性，前缀后跟冒号：

| 写法 | 作用 | 示例 |
| --- | --- | --- |
| `rating:` | 按评级筛选（s / q / e） | `rating:s` |
| `score:` | 按用户评分筛 | `score:>=100` |
| `favcount:` | 按收藏数筛 | `favcount:>50` |
| `date:` | 按发布日期筛 | `date:>=2024-01-01` |
| `age:` | 按发布时间距今筛 | `age:<1week`（最近一周） |
| `order:` | 改变排序 | `order:score`（评分从高到低） |
| `status:` | 按帖子状态筛 | `status:active` |
| `type:` | 按文件类型筛（jpg / png / gif / webm 等） | `type:png` |
| `id:` | 按帖子编号 | `id:4000000` |
| `user:` | 按上传者 | `user:某用户名` |
| `fav:` | 按收藏过的人 | `fav:某用户名` |
| `inpool` / `pool:` | 是否属于合集 / 指定合集 | `inpool`、`pool:某合集名` |
| `parent:` / `child:` | 父子帖（组图）关系 | `parent:none` |

`order:` 还有几个常用值：`order:random`（随机）、`order:favcount`（按收藏数）、`order:comment`（最近有评论）。

数值与日期都能写区间：`score:100..500`（100 到 500 分）、`date:2024-01-01..2024-06-30`（半年内）。

## 三、写复杂查询前的三条限制

站点对查询复杂度有限制，写不出来通常是撞上了它们，而不是语法错了：

- **标签数量上限与账号等级挂钩**：匿名与普通账号一次能组合的标签数少（常见口径为 2 个），Gold 及以上等级放宽（6 个）。升级、确认自己等级，见站点帮助页，以官方说明为准。
- **通配符与分组数量有限**：一次搜索里通配符、分组的个数都有上限，超出会被拒绝。
- **深度翻页有限**：同一个查询不能无限往下翻页。

以上均以官方速查页为准：[e621.net/help/cheatsheet](https://e621.net/help/cheatsheet)（站点内的帮助页，语法有更新时以它为准）。

## 四、同一套语法用在哪

- **搜索框**：直接输入，配合撤销 / 重做与搜索历史使用，见[搜索技巧与标签用法.md](搜索技巧与标签用法.md)。
- **黑名单**：一行一条，支持本页全部组合写法，比如用 `rating:e -某标签` 这种「评级 + 排除」的复合条件精准挡内容，配置入口见[黑名单与内容过滤设置.md](黑名单与内容过滤设置.md)。
- **保存搜索与关注标签**：把本页的查询条件存起来长期复用，或让后台盯着组合条件出新帖；想整本囤合集的话，配合 `inpool` 类查询再进[图片下载与批量保存.md](图片下载与批量保存.md)。
