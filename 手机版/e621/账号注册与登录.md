# e621 账号注册与客户端登录方法

> 本篇讲怎么注册 e621 账号、在客户端里登录，以及登录之后能多做的那些事（投票、收藏、评论、关注标签通知）。

## 一、没有账号也能用，但有几个功能要登录

先说清楚边界，再决定要不要注册：

- 不登录就能做：浏览、搜索、下载保存、看评论、使用应用本地的黑名单与过滤设置。
- 必须登录才能做：给帖子投票（upvote / downvote）、收藏（favourite）、发表评论、发评论回复，以及让「关注标签」的新帖通知跟着账号走。

也就是说，只看不互动的话可以跳过本篇；想参与社区，往下走。

## 二、注册 e621 账号

账号是在站点上注册的，与客户端无关：

1. 用浏览器打开 `e621.net`，在页面顶部找到注册（Sign up）入口。
2. 填写用户名、邮箱地址和密码，提交。
3. 到邮箱里收验证邮件，点验证链接激活账号。收不到就先翻垃圾邮件箱。
4. 按站点规则，注册与使用需要达到所在地区的法定成年年龄。

两个注意点：

- 注册入口是否开放、是否需要额外验证，以官方注册页当时的显示为准（站点偶尔会阶段性调整注册政策）。
- e621 与 e926 共用同一套账号体系，注册一次两边通用。

## 三、在客户端里登录

1. 打开客户端，从侧边栏菜单进入登录页。
2. 输入 e621 的用户名与密码，提交。
3. 登录成功后，帖子页会出现投票与收藏按钮，评论也可以直接发。

补充两点：

- 如果你把站点切换成了 e926（或反之），发现登录状态没有跟过去，再登录一次即可——客户端对两个站点分别保持会话。
- 密码找回走站点网页端的流程，客户端里没有独立入口。

## 四、登录后建议顺手做的两件事

- **关注标签（Followed tags）**：把常追的标签关注起来，客户端会在后台检查新帖并推送通知；登录状态下关注列表跟着账号走。操作细节见[搜索技巧与标签用法.md](搜索技巧与标签用法.md)。
- **核对黑名单**：黑名单与过滤在登录前后都能用（应用本地设置），但登录后浏览体验与账号偏好一致会更顺，配置方法见[黑名单与内容过滤设置.md](黑名单与内容过滤设置.md)。

登录环节卡住（密码明明对却登不上、验证邮件不来等），直接翻[常见问题与故障排查.md](常见问题与故障排查.md)里的登录相关条目。
