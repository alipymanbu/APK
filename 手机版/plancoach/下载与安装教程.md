## 一、先确认你要装的是哪一份

PlanCoach（计划教练）是一款把「拖着不想干的事」拆成极小步骤的抗拖延工具，官方主力版本在 iOS，官网只放 App Store 下载入口。安卓这边没有上架主流应用商店的公开记录，你能拿到的就是一个 APK 安装包，装之前先核对这份包的指纹，避免下错文件：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.0 |
| 包名 | `com.zhaodao.zijidelu` |
| 安装包大小 | 117.30M |
| MD5 | `AAB856A9F37706D86F8207CCE30007EA` |
| 系统要求 | 安卓 5.2 及以上 |

说明两点：

- 网上各下载站标注的安卓版本号并不统一（有的写 1.10.6，有的写 1.0.0），**以你手里这个安装包显示的版本为准**；本文其余章节涉及版本的地方也都指这一份。
- 核对 MD5 可以用电脑上的校验工具，也可以在手机装个校验类 App 扫一下；MD5 对不上说明文件在传输中损坏或不是同一份，重新下载即可。

## 二、安装步骤（安卓）

1. 从上面的 [PlanCoach 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3fe2ea6fa3d6) 把 APK 转存到自己的网盘，再在手机上下载（或先下到电脑再传到手机）。
2. 用手机文件管理器找到这个 `.apk` 文件，点它开始安装。
3. 系统会弹「不允许安装来自此来源的应用」——这是安卓对商店外安装的正常拦截。点提示里的**设置 / 更多设置**，打开「允许来自此来源的应用」（有的机型叫「安装未知应用」），然后返回继续安装。
4. 等安装完成，打开应用。首次启动会请求通知、麦克风等权限：要使用提醒与免手语音功能就把对应权限给上，不给也不影响核心的计划与打卡功能。

> 不同品牌的入口位置略有差别，但路径都是「设置 → 应用 → 特殊权限 / 安装未知应用」，在系统设置里搜「未知」两个字一般能直达。

## 三、装不上、打不开的排查顺序

按命中率从高到低依次试，能解决就停：

1. **解析包错误 / 安装包损坏**——多是下载中断造成。重新从网盘拉一次完整文件，或核对 MD5 是否一致。
2. **安装被拦截**——确认第二步的「允许安装未知应用」是对**你正在用的安装来源**（文件管理器或浏览器）打开的，不是全局开关。
3. **与已装版本冲突**——如果你手机上已有一个同包名但签名不同的 PlanCoach（比如来自别的渠道），先卸载旧的再装这份；覆盖安装签名不一致会直接报错。
4. **闪退 / 一闪而过**——先重启手机；再进「设置 → 应用 → PlanCoach」清缓存、确认权限齐全；存储空间紧张（剩余不足 1GB 左右）也会导致启动失败，清出空间再试。
5. **系统版本过低**——这份包要求安卓 5.2 及以上，低于该版本的设备装了也跑不起来。

以上都无效时，大概率是包本身与你的机型不兼容，换一个安卓版本更高的设备试一次就能定位问题。

## 四、安装后值得先做的两件事

- **允许通知**：PlanCoach 的计划靠提醒推动（进行中的任务有持续提醒），拒绝通知权限等于自废一半功能。
- **记住数据可以导出**：官方明确数据可导出，不依赖云端存续。换机或重装前先在 App 内找导出入口，把历史计划导出来，重装后不至于从零开始。详见 [常见问题与会员价格.md](常见问题与会员价格.md)。
