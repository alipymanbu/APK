# dynamicSpot 哪些通知会显示在灵动岛上

灵动岛本身不生产内容，它是一层显示窗口：内容全部来自安卓的通知系统。你勾选了哪些应用、那些应用发通知时带了多少信息，直接决定了岛上能看到什么。理解这一点，很多「为什么它不显示我的某个应用」的疑问就自然有答案了。本篇按内容类型拆开讲。

## 一、能上岛的几类内容

| 类型 | 岛上会看到什么 | 前提 |
| --- | --- | --- |
| 消息类通知 | 应用图标、发送者、一小段正文 | 该应用在清单里被勾选 |
| 音乐播放 | 专辑封面、曲目名、播放/暂停、上一首/下一首、可拖动的进度条 | 音乐应用把播放状态交给系统通知 |
| 计时器与倒计时 | 剩余时间实时递减 | 计时器应用的进行中通知保持常驻 |
| 充电与电量 | 充电百分比、低电量提醒 | 无需额外授权，属于系统事件 |
| 通话 | 来电或通话中的状态 | 电话应用的通知未被系统特殊处理 |
| 持续进行的任务 | 导航距离、正在录的音、下载进度这类常驻通知 | 应用把状态写成 ongoing 通知 |

这里的关键词是「通知」。任何应用只要按安卓的常规方式发了通知，并且被你勾选，就有机会上岛；反过来，一个应用如果压根不发通知，或者你手动把它的通知权限关了，它就不可能出现在岛上——dynamicSpot 没有绕开通知系统的能力。

## 二、音乐是体验最完整的一类

音乐播放是灵动岛最像原版的场景：黑条里能显示封面和曲目，展开后可以暂停、切歌、拖动进度条；部分版本还支持跟随音乐节奏的律动效果。需要知道的限制是：这些控制项完全依赖音乐应用对外暴露的播放状态。

所以你会看到两种结果——主流音乐、播客类应用通常控制完整；一些小众播放器或者自带播放器的短视频应用，可能只显示曲目名、按钮点不动，或者干脆不上岛。这不是设置没给对，而是对方应用没把播放状态放进通知里。想验证，就在播放时下拉系统通知栏看一眼：通知栏里有没有媒体控制条。通知栏里都没有的，岛上也不会有。

## 三、把它当通知灯用

官方把「通知灯 / LED 替代」列为这个应用的功能之一，指的就是这种用法：现在大量手机取消了正面呼吸灯，桌面上一放，来消息只有声音、看不出亮没亮过。灵动岛可以在每次通知时在顶部闪一下，起到同样的提示作用。

想让它更像呼吸灯而不是弹窗，按三步收：

1. **清单只留两类**：未接来电和即时通讯。其余全部取消勾选，否则屏幕顶部一直在闪；
2. **关掉这些应用的系统横幅**：否则一次消息会有「灵动岛闪一下 + 横幅弹一次」两段动画，反而更吵。关横幅的路径见 [灵动岛与系统横幅重复弹出怎么关.md](灵动岛与系统横幅重复弹出怎么关.md)；
3. **弹出时长调到最短**：目标是「亮一下、扫一眼是谁发的，然后自己收回去」。

两处要提前知道的边界：它只在**亮屏状态**下出现，屏幕全黑时不会有任何显示，所以替代呼吸灯的前提是你常把手机正面朝上放在桌上；另外底部没有常亮的残留提示，想事后确认有没有漏消息，还是要看通知栏。

## 四、点、长按、滑动分别做什么

岛上黑条被点到的反应，可以在应用的交互设置里改。默认的一组大致是：

- **点一下**：展开或直接打开对应的应用；
- **长按**：展开成更大的卡片，看更完整的内容，部分通知支持直接在卡片里回复；
- **滑动**：把这条通知从岛上划掉。

对多数人来说，值得动一动的只有「点一下」这个动作。默认的「点了就跳进应用」在只想扫一眼内容时会打断你手上的事，改成「点按仅展开」之后，它会安静很多。

## 五、应用清单怎么筛才不烦

清单里勾得越多，岛上弹得越频繁。一个实用的收敛办法是分三天做：

1. **第一天全勾**，正常用手机，留意哪些弹出让你觉得挡事；
2. **第二天起把挡事的删掉**——购物、资讯、游戏推送这类通常是第一批被删的；
3. **一周后再看一遍**还剩哪些，剩下的基本就是真正常用的那几个。

留下的一般是即时通讯、音乐、闹钟/计时器，这三类占了灵动岛八成以上的实际价值。至于通知内容本身，Android 13 之后部分应用支持自定义通知样式，如果某个应用上岛后只显示「1 条新消息」而不显示正文，那是该应用自己没把正文放进通知，去掉原文隐藏设置后才会显示。

## 六、什么情况下它接不住

- **应用的通知被系统设成静默或低优先级**：这类通知本来就只进通知栏、不弹窗。若某个应用完全没反应，先把系统通知设置里该应用的「静默」关掉，再等一条新消息试；
- **应用用的是自己的悬浮窗**：比如游戏加速器、录屏工具自带的角标，那是应用自己画的，跟通知无关，dynamicSpot 管不到；
- **系统把该应用的通知归类到「其他」并默认收起**：在系统通知设置里把对应类别放开即可；
- **开了勿扰或专注模式**：这段时间的通知在多数机型上不触发弹窗。

如果清单里明明勾了、通知栏里也确实有，岛上就是不动，那就是权限或后台被限制了，按 [常见问题与排查.md](常见问题与排查.md) 的顺序查。对外观不满意，回到 [灵动岛位置大小与颜色怎么调.md](灵动岛位置大小与颜色怎么调.md)；想知道这些能力哪些属于免费版、哪些需要 Pro，看 [免费版与 Pro 版有什么区别.md](免费版与Pro版有什么区别.md)。
