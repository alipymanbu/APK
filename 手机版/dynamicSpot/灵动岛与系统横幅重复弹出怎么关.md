装上 dynamicSpot 之后最常见的一个抱怨是：来一条消息，顶部先弹一次系统横幅，紧跟着灵动岛也弹一次，等于同一件事被通知了两遍。这不是设置没调好，而是两套机制在同时工作——本篇讲清它为什么必然重复，以及三种能真正解决它的做法。

## 一、为什么两个都会弹

dynamicSpot 拿到的是**通知使用权**，这意味着它能「读」到通知，但安卓没有给第三方应用「拦下别的应用的横幅」这种能力。所以：

- 应用发出通知 → 系统照常按自己的规则弹横幅、进通知栏；
- 同一时刻，dynamicSpot 通过通知使用权也收到了这条通知 → 在顶部画一次灵动岛。

两条链路互不干涉，所以必然重复。**灵动岛不是替换系统横幅的开关**，它只是一层额外的显示。想只留一个，就得从系统通知设置里动手。

## 二、做法一：关掉该应用的横幅（推荐）

这是最干净的做法。以常见的路径为例：

设置 → 通知与状态栏 →（找到那个应用）→ 通知管理 → **关闭「横幅通知」**，保留「允许通知」「锁屏通知」。

关掉横幅之后：

| 项目 | 关闭横幅前 | 关闭横幅后 |
| --- | --- | --- |
| 屏幕顶部弹窗 | 系统横幅 + 灵动岛，两次 | 只有灵动岛 |
| 通知栏里的记录 | 有 | 仍有 |
| 灵动岛能否读到 | 能 | 仍能 |

关键在最后一行：**灵动岛读的是通知本身，不是那条横幅**。关掉横幅不会让它失灵，这一点可以先放心试。

各家系统的入口名称略有差异：

| 系统 | 横幅开关的位置 |
| --- | --- |
| 原生 Android | 设置 → 应用 → 该应用 → 通知 → 该类别 → 「弹出式通知」 |
| 小米 / 红米 | 设置 → 通知与状态栏 → 该应用 → 关闭「悬浮通知」 |
| 华为 / 荣耀 | 设置 → 通知和状态栏 → 该应用 → 关闭「横幅通知」 |
| OPPO / 一加 / realme | 设置 → 通知与状态栏 → 该应用 → 关闭「横幅」 |
| vivo / iQOO | 设置 → 通知与状态栏 → 该应用 → 关闭「悬浮通知」 |
| 三星 | 设置 → 通知 → 该应用通知类别 → 关闭「弹出窗口」 |

部分系统把通知按类别拆开（聊天消息、群消息、其他），需要逐个类别看，只关掉你最常收到的那一类通常就够了。

## 三、做法二：只对高频应用动手

没必要把所有应用都改一遍。判断标准是「哪些应用的通知你既想看到、又嫌它弹两次」：

- **即时通讯类**（消息、群消息）：值得关横幅，看灵动岛就够了；
- **音乐、计时器**：这类通常不弹横幅，不用处理；
- **验证码、外卖、快递**：横幅里的数字和进度需要一眼看清，建议保留横幅，把这类应用从灵动岛清单里去掉。

按这个思路筛一遍，需要动设置的通常不超过五个应用。哪些该留在岛上，可以参考 [哪些通知会显示在灵动岛上.md](哪些通知会显示在灵动岛上.md)。

## 四、做法三：不改系统设置，改灵动岛自己

如果你不愿动系统通知设置（比如担心影响别的地方），还有两个折中办法：

1. **把弹出时长调短**：系统横幅大约几秒后自己消失，把灵动岛的停留时间也调到相近，两段弹窗会前后衔接，观感比同时出现两条好一些；
2. **把该应用从灵动岛清单里取消**：如果你觉得系统横幅已经够用，那这个应用本来就不需要上岛。

这两个都属于「缓解」，重复本身还在。要彻底只留一个，还是得回到第二节。

## 五、两个可以放心的点

- **不影响消息接收**：上面所有操作都只改「怎么显示」，不改「收不收得到」。关掉横幅之后，消息照样进通知栏、照样响铃震动。
- **可以随时改回来**：每一项都是一次开关，觉得不合适按原路打开即可，不会留下副作用。

如果关完横幅发现灵动岛也不弹了，那说明是通知使用权或后台被限制，跟横幅没关系，按 [常见问题与排查.md](常见问题与排查.md) 的顺序查。如果你手机上除了系统横幅，还有系统自带的灵动胶囊/实况窗在弹，那是另一回事，见 [自带实况窗和灵动胶囊冲突怎么办.md](自带实况窗和灵动胶囊冲突怎么办.md)。
