dynamicSpot 是 Jawomo 出的一个安卓小工具：它在屏幕顶部画一条黑色胶囊，把通知、音乐播放、计时器、充电状态这些实时信息收进去显示，点一下展开、长按看更多。它的定位是「给安卓补一个顶部实时状态区」，不替换系统通知栏。本篇只解决一件事：把网盘里这份包装进手机，并让首次启动的引导页顺利走完。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本信息多半是发布时的最新版，而网盘里这份是整理文档时核对过的那一版，两者未必是同一个版本号。下面这些值以网盘里那份包为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | dynamicSpot |
| 版本号 | 2.01 |
| 包名 | `com.jamworks.dynamicspot` |
| 安装包体积 | 8.21 MB |
| MD5 | `0B1B0B339500A524AB340495B28D4AEF` |

安装包本体就在头部那条夸克网盘分享里，转存到自己网盘后下载即可。

安装前可以顺手核对一下 MD5：在电脑上用校验工具算一遍，和上表一致再装，能避开下载过程中被截断或替换的情况。手机端下的包一般不方便校验，那就只看体积是否与 8.21 MB 接近。

关于系统版本，这里给个提醒：第三方下载站抄来抄去的最低安卓版本从 8.0 到 12 都有，彼此并不一致，这些数字不能当依据。想确认自己这台手机能不能装，按下面两步走：

1. 打开官方的 Google Play 页面（`https://play.google.com/store/apps/details?id=com.jamworks.dynamicspot`），在「关于此应用」里找它标注的最低 Android 版本，与手机上「设置 → 关于手机」里的系统版本对照；
2. 拿不准就直接装——安卓在设备不兼容时会拒绝安装，直接提示「应用未安装」或「与你的设备不兼容」，不会给你装上一个半残的版本。

另外，第三方评测里有一条一致的反馈：系统版本越旧，实时状态（计时器倒计时、音乐进度）的同步越容易出现延迟。系统偏旧的机型装完，先重点试这两个场景。

## 二、装之前要核对的两件事

**第一，不需要 root。** 它不属于那类要先获取系统最高权限、刷机或解锁才有用的工具，就是一个普通 APK：装上之后所有授权都在系统设置里逐项完成。凡是要求你先获取系统最高权限再用的说法，都跟这个应用无关。

**第二，别装成同名的另一个应用。** 应用市场上叫「灵动岛」「Dynamic Island」的应用有一大堆，图标和名字都长得像，但包名各不相同。系统认的是包名，只有 `com.jamworks.dynamicspot` 才是本文这套文档对应的那个应用。

容易出现的情况是：你之前装过某个别的灵动岛应用，两者会同时存在、同时往屏幕顶部画东西，看起来像「叠了两条黑条」或者互相抢位置。如果出现这种画面，先进系统设置的应用列表里把不是 `com.jamworks.dynamicspot` 的那个卸掉或停用，再回来配置 dynamicSpot。

## 三、安装步骤

1. **转存并下载**：从 [dynamicSpot 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0ef422e72813) 把 APK 转存到自己的网盘，再下载到手机。
2. **把包送到手机上**：手机端直接下载最省事；在电脑上下载的话，用数据线或任意传输工具拷进手机存储即可。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统通常把这项收在「安全」或「隐私」分类下面。
4. **点击 APK 完成安装**：系统若提示「应用未经过安全检测」，选择继续安装即可，第三方渠道的安装包都会走这一步。
5. **想装低版本要先卸载**：安卓不允许用更低版本的安装包覆盖更高版本，会直接报「应用未安装」。手机里已有更高版本时，先卸载旧版再装，应用内的设置会一并清掉。
6. **装完先别急着点开就用**：先跟着下一节的引导把权限走完，否则灵动岛不会出现。

## 四、首次启动会走的权限引导

第一次打开，应用会用一个引导页按顺序把几项系统权限要过去。这不是可跳过的欢迎页，跳过了灵动岛就不会显示。三项权限的分工大致是：

| 权限 | 作用 | 不给会怎样 |
| --- | --- | --- |
| 通知使用权 | 读到你勾选的那些应用发来的通知 | 灵动岛上什么都不显示 |
| 悬浮窗（在其他应用上层显示） | 让黑条能画在任何界面之上 | 切到别的应用后灵动岛消失 |
| 无障碍服务 | 处理展开、点按这类交互，并维持弹窗 | 能显示但交互异常，或显示不持久 |

引导页里通常还会让你顺手勾选「哪些应用的通知要上岛」，这一步可以先全选，之后再收窄。每一项目标权限在系统设置里的具体位置、各家手机品牌入口的差别，以及权限被系统回收后怎么补回来，都写在 [首次配置与权限怎么给.md](首次配置与权限怎么给.md)，这里不重复。

## 五、装完做一次最小验证

1. 把上面三项权限给全，回到应用主界面；
2. 在应用列表里勾上一个你常用的消息类应用（比如短信或即时通讯工具）；
3. 让另一台设备给自己发一条消息，看屏幕顶部会不会冒出黑色胶囊；
4. 点一下胶囊，看是否跳到对应应用；长按看一下会不会展开成更大的卡片。

四条都过，说明安装与权限这一关已经通了，接着可以调外观（[灵动岛位置大小与颜色怎么调.md](灵动岛位置大小与颜色怎么调.md)）和决定哪些应用上岛（[哪些通知会显示在灵动岛上.md](哪些通知会显示在灵动岛上.md)）。第 3 步没反应先别怀疑安装包，九成是通知使用权或悬浮窗没真正打开，对照 [常见问题与排查.md](常见问题与排查.md) 逐项查。

## 六、以后出了新版本怎么升级

网盘那份分享是长期有效的：更新版本时替换的是里面的安装包文件，**分享链接本身不变**，所以升级不用重新去找地址。

1. 回到本文头部那条分享，看里面是不是已经换成比 2.01 更新的包；
2. 直接下载新包，点安装。包名相同、版本号更高时，安卓允许覆盖安装，**原有设置（位置、尺寸、应用清单）会保留**；
3. 万一覆盖安装报「应用未安装」，说明新包的签名与手机里那份对不上、或版本号反而更低。这种情况只能先卸载旧版再装，代价是设置要全部重配一遍。

有一点要自己留意：它不是从手机自带应用商店装的，商店通常不会替第三方来源的应用检查更新，想保持新版得隔一段时间回网盘看一眼。另外别在一个手机上同时装本文这份和别的渠道的同包名安装包——签名不一致同样会报「应用未安装」。如果只是想留着旧版试试，那就干脆别升级。

想换回旧版、或者装完发现某个场景不如预期，先看 [常见问题与排查.md](常见问题与排查.md)，里面有卸载与重装的注意事项。
