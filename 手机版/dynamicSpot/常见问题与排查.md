灵动岛这类应用的问题大多不是「坏了」，而是某一项权限或系统策略被改动后没被注意到。下面的排查顺序按「改动概率从高到低」排，从上往下查通常几步就能定位。

| 现象 | 先查什么 | 对应小节 |
| --- | --- | --- |
| 完全不出现 | 通知使用权 / 悬浮窗是否还在 | 一 |
| 昨天能用今天不行 | 无障碍是否被系统关掉、有没有开省电模式 | 二 |
| 只有个别应用不上岛 | 该应用的通知识别方式 | 三 |
| 上岛了但内容为空 | 应用是否开了通知原文隐藏 | 三 |
| 位置挡住摄像头或状态栏 | 垂直位置与尺寸 | 四 |
| 和系统自带功能重叠 | 机型自带的实况窗/超级岛 | 五 |
| 同一条消息弹两次 | 系统横幅没关 | 见 [灵动岛与系统横幅重复弹出怎么关.md](灵动岛与系统横幅重复弹出怎么关.md) |
| 耗电变快、滑动发涩 | 动画与勾选的应用数量 | 六 |

## 一、灵动岛完全不出现

按顺序确认三件事：

1. **通知使用权还在不在**。系统大版本更新、清理工具「一键优化」之后这一项可能被关掉。路径见 [首次配置与权限怎么给.md](首次配置与权限怎么给.md) 里的对照表。
2. **悬浮窗权限是否开启**。这一项关掉时的典型表现是：在应用内部看不到，退回桌面偶尔闪一下。
3. **是不是刚刚才装、引导页被跳过了**。首次启动的引导不是欢迎页，跳过后需要进应用再走一遍，或者在系统设置里手动补权限。

三项都在、仍然不出现，做一次最简验证：让另一台设备给自己发条短信，看岛动不动。如果短信也不动，但音乐播放时岛会出现，说明权限部分生效、是通知读取这一环断了，把通知使用权关掉再重开一次。

## 二、昨天能用，今天不显示

这类「时好时坏」几乎都出在两个地方：

**第一，无障碍服务被系统收回了。** 很多安卓机型在重启后会关闭第三方应用的无障碍服务，需要你手动再打开一次。判断方法就是进系统设置的「无障碍 → 已下载的应用」看它是不是显示为「已关闭」。

**第二，后台被系统掐了。** 各家对后台应用的容忍度不同，可以按下面的方向找：

| 系统 | 需要放开的项 |
| --- | --- |
| 小米 / 红米 | 应用信息里的省电策略设为「无限制」，并在权限设置里打开「自启动」 |
| 华为 / 荣耀 | 应用启动管理里关掉「自动管理」，手动允许自启动、关联启动、后台活动；电池优化里设为「不允许」 |
| OPPO / 一加 / realme | 电池设置里的应用耗电管理允许后台运行 |
| vivo / iQOO | 电池设置里允许后台高耗电，并加入自启动白名单 |
| 三星 | 电池 → 后台使用限制里，把该应用加入「永不进入休眠的应用」 |

上面的名称各家会随版本改，找不到就在设置里搜「自启动」「电池优化」「后台」。另外，省电模式打开时系统会主动压制后台，排查期间先关掉它。

三个容易被忽略、但确实会让应用被清理的地方：

- **把应用卡片锁住**：进入多任务界面，把 dynamicSpot 的卡片下拉加锁（部分机型是点卡片上的锁图标）。加锁后的应用不会被「一键清理」清掉，这比改各种权限开关更直接。
- **关掉开发者选项里的两个坑**：开发者选项中的「不保留活动」和「后台进程限制」都会强行结束后台进程，装上这类应用后应确认前者关闭、后者为「标准限制」。没开过开发者选项的机子不涉及这一项。
- **第三方管家类应用**：安全管家、清理大师这类工具做「一键优化」时会把后台服务一并结束，权限设置也可能被重置。排查期间先别用它们清理。

## 三、只有部分应用不上岛，或者内容是空的

- **通知栏里有没有？** 下拉通知栏看一眼那个应用的通知在不在。通知栏里都没有的，岛上不可能有。
- **是不是静默通知？** 在系统通知设置里把该应用对应类别从「静默」放开。
- **是不是只显示「1 条新消息」？** 这是应用自己开了「隐藏通知内容」。到那个应用的通知设置里关掉原文隐藏，岛上才会显示正文。
- **是不是勿扰/专注模式？** 这两种模式下多数机型不触发弹窗，先确认没开着。
- **是不是在清单里被误删？** 回到应用的通知设置，确认它仍被勾选。

## 四、位置挡住了摄像头或状态栏

这是纯外观问题，去 [灵动岛位置大小与颜色怎么调.md](灵动岛位置大小与颜色怎么调.md) 调「垂直位置」和「尺寸（宽/高）」。判断标准很简单：黑条正好把摄像头挖孔整个盖住、又不压到状态栏右侧的电池图标，就是位。横屏用得多的人，还要单独看一眼横屏下的位置。

## 五、和手机自带的功能叠在一起

近几年的系统几乎都自带一个顶部实时状态区：小米叫超级岛 / 焦点通知，华为叫实况窗，OPPO、vivo 也有各自的叫法。它和 dynamicSpot 同时开着时，会出现两条黑条上下叠着、或者互相抢位置的情况。

处理方式就是**只留一个**：系统自带的那套已经够用，就把 dynamicSpot 停用；反过来就进系统设置把自带的关掉或收窄。注意一个容易被忽略的区别——系统自带的那套只覆盖主动接入过它的应用，接不进来的第三方应用只有 dynamicSpot 能显示，所以取舍时值得先看一眼你常用应用在自带清单里的覆盖情况，具体做法见 [自带实况窗和灵动胶囊冲突怎么办.md](自带实况窗和灵动胶囊冲突怎么办.md)。

## 六、耗电变快、滑动发涩

灵动岛的渲染是一层持续存在的悬浮窗，本身负担不大，但下面两项会明显增加消耗：

- **动画开得很花、弹出时长设得很长**：每次通知都要跑一段动画，频率高的时候感知明显；
- **勾选的应用过多**：等于让更多通知都走一遍弹窗流程。

想省电就按这两条往回缩：动画调简单、弹出时长调短、应用清单只留常用的几类。做完还觉得耗电异常，可以先把 dynamicSpot 停用一天做对比——这是判断「是不是它造成的」最快的办法。

## 七、想卸载时的一个小注意

卸载前建议先进系统设置的无障碍页面，把 dynamicSpot 的服务关掉，再卸载应用。部分机型在无障碍服务仍处于启用状态时直接卸载，会留下一个失效的空白条目，虽然不影响使用，但要手动清掉。

如果卸载重装后所有设置都回到初始状态，那是正常现象——应用的设置不会跟着重装保留，位置、尺寸、应用清单都需要重新配一遍。安装包与后续版本更新统一从 [dynamicSpot 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0ef422e72813) 取用；覆盖安装与升级的步骤写在 [下载与安装教程.md](下载与安装教程.md) 的第六节。
