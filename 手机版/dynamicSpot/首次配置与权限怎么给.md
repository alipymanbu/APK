灵动岛能不能正常显示，几乎全部取决于这一次授权有没有给全。它不是「给一项就能用」的应用：少了通知使用权，岛上没内容；少了悬浮窗，一切到别的应用就没了；无障碍被系统收走，弹窗会变得不持久。本篇按「先给权限、再选应用、最后调外观」的顺序把它走完。

## 一、三项权限分别管什么

| 权限 | 系统里的名字 | 它负责的部分 | 缺了会看到什么 |
| --- | --- | --- | --- |
| 通知使用权 | 通知使用权 / 通知访问 | 读取你勾选的应用发出的通知内容 | 灵动岛完全不出现，或只出现音乐、充电这类系统事件 |
| 悬浮窗 | 在其他应用上层显示 / 显示在其他应用上层 | 允许黑条画在当前界面之上 | 在应用内看不到，退回桌面才偶尔闪一下 |
| 无障碍服务 | 无障碍 / 已下载的应用 / 已安装的服务 | 支撑点按、长按展开与弹窗保持 | 能显示但点不动、长按不展开，或几秒后自己消失 |

这三项里，**浮动窗和通知使用权是硬门槛，无障碍关系到交互是否完整**。应用里通常把三项做在同一个引导页上，逐个跳转过去打开即可；如果当时跳过了某一项，回应用主界面重新走一遍引导，或按下面的路径手动补。

## 二、手动补齐的路径

不同厂商把这三项放在了不同位置，按你手机的系统对号入座：

| 系统 | 通知使用权 | 悬浮窗 | 无障碍 |
| --- | --- | --- | --- |
| 原生 Android / 类原生 | 设置 → 应用 → 特殊应用权限 → 通知使用权 | 设置 → 应用 → 特殊应用权限 → 在其他应用上层显示 | 设置 → 无障碍 → 已下载的应用 |
| 小米 / 红米（MIUI、HyperOS） | 设置 → 应用设置 → 应用管理 → 特殊权限 → 通知使用权 | 设置 → 应用设置 → 应用管理 → 特殊权限 → 显示在其他应用上层 | 设置 → 更多设置 → 无障碍 → 已下载的应用 |
| 华为 / 荣耀 | 设置 → 应用 → 应用管理 → 特殊访问权限 → 通知使用权 | 设置 → 应用 → 应用管理 → 特殊访问权限 → 显示在其他应用上层 | 设置 → 辅助功能 → 无障碍 → 已安装的服务 |
| OPPO / 一加 / realme | 设置 → 应用 → 特殊应用权限 → 通知使用权 | 设置 → 应用 → 特殊应用权限 → 显示在其他应用上 | 设置 → 系统设置 → 无障碍 → 已下载的应用 |
| vivo / iQOO | 设置 → 更多设置 → 权限管理 → 权限 → 通知使用权 | 设置 → 更多设置 → 权限管理 → 悬浮窗 | 设置 → 更多设置 → 无障碍 → 已下载的服务 |
| 三星 | 设置 → 应用程序 → 特殊访问权限 → 通知使用权 | 设置 → 应用程序 → 特殊访问权限 → 显示在其他应用上层 | 设置 → 辅助功能 → 已安装的服务 |

上面的层级是常见布局，厂商在系统大版本更新时改过入口位置，以你手机上实际看到的为准。找不到某个入口时，最快的方法是在系统设置的搜索框里直接搜「通知使用权」「悬浮窗」「无障碍」这几个词。

## 三、无障碍授权时的那个弹窗不用怕

打开无障碍服务时，系统会弹一段很长的警告，大意是「该应用可以查看屏幕内容、替你做操作」。这是安卓对无障碍权限的固定提示，任何用这条权限的应用都会看到同样的话。

关于这条权限，官方在应用介绍里写明：dynamicSpot 使用无障碍服务 API 只是为了把灵动岛弹窗画出来、便于多任务操作，**不通过这条 API 收集或共享数据**。如果你对权限本身敏感，判断标准可以放简单些——这条权限是弹窗能长期存在的前提，关掉它就得接受灵动岛不稳定；不能接受就别用这个应用，而不是开着权限再指望它不去用。

## 四、决定哪些应用的通知上岛

权限给完之后，进入应用的「通知」相关设置，里面是一个应用清单：勾上的应用，发通知时会通过灵动岛弹出来。两个实用建议：

- **先全选，再回删**。一开始不知道哪些应用会真的上岛，先全勾上跑一两天，把打扰你的、或者弹出来内容没意义的那些取消掉，比一开始逐个挑要快。
- **优先收消息、音乐、计时器这三类**。这三类是灵动岛最有用武之地的场景；购物、资讯类应用的通知弹在岛上既挡视线又没信息量，可以一律关掉。

具体的分类与取舍方式，见 [哪些通知会显示在灵动岛上.md](哪些通知会显示在灵动岛上.md)。

## 五、权限会被系统悄悄收回

这是这类应用最常见的「昨天还好好的，今天不显示了」的原因：

- **系统重启后，部分机型会把无障碍服务关掉**，需要手动再打开一次；
- **系统更新、清理类工具做「一键优化」之后**，悬浮窗与自启动设置有可能被重置；
- **省电模式打开时**，系统会更积极地把后台服务掐掉，灵动岛表现为一段一段地失灵。

所以出现「突然不显示了」，第一件事不是重装，而是按下面这份清单逐项看一眼——每一项在系统设置里都能直接看到开关状态：

| 检查项 | 看到什么才算正常 |
| --- | --- |
| 通知使用权 | 列表里有 dynamicSpot，且处于已开启状态 |
| 悬浮窗 | 该应用的「在其他应用上层显示」为允许 |
| 无障碍 | 「已下载的应用」里 dynamicSpot 显示为已开启 |
| 电池 / 后台 | 该应用未被省电策略限制，自启动为允许 |

上面四项都对、依然不弹，再做一次最小复现：让另一台设备给自己发条短信，盯住屏幕顶部。如果短信也不弹，把通知使用权关掉再打开一次——这一步会让应用重新注册监听，卡住的读取多半能恢复。完整的排查顺序在 [常见问题与排查.md](常见问题与排查.md)。权限都齐了，就可以开始调外观了：从 [灵动岛位置大小与颜色怎么调.md](灵动岛位置大小与颜色怎么调.md) 里的位置与尺寸两项入手，先把黑条对上你手机的前置摄像头。
