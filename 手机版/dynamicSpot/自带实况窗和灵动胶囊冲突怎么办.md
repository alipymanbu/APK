# dynamicSpot 自带实况窗和灵动胶囊冲突怎么办

> 手机自带「实况窗」「超级岛」这类功能时，它会和 dynamicSpot 抢同一块屏幕顶部。本篇讲清两者覆盖范围差在哪、怎么取舍。

近几年的安卓系统几乎都自带了一个「顶部实时状态区」：小米叫超级岛 / 焦点通知，华为叫实况窗，OPPO、vivo 等也有各自叫法。它和 dynamicSpot 属于同一类东西，同时开着就会出现两条黑条抢位置、同一条信息显示两次。想让观感干净，只能二选一——但选哪个，取决于你常用哪些应用。

## 一、先认清两边的覆盖范围不一样

这是决定取舍的关键，也是很多人没意识到的一点：

| | 系统自带的实况窗 / 超级岛 | dynamicSpot |
| --- | --- | --- |
| 数据来源 | 应用主动接入系统接口 | 读安卓通知系统 |
| 覆盖范围 | 只覆盖**已接入**的应用（不同机型清单不同，随时在变） | 你勾选的任何会发通知的应用 |
| 能显示什么 | 通话、计时器、录音、外卖、打车、航班、音乐等场景 | 消息、音乐、计时器、充电、通话，以及各种第三方应用的常驻通知 |
| 外观是否可调 | 大多由系统与该应用共同决定，用户只能整体开关 | 位置、尺寸、颜色、动画、时长都能自己调 |

举几个已知的接入情况作为参考（官方清单会随版本更新，以你手机上实际出现的为准）：

- **华为实况窗**支持外卖配送、航班、高铁、打车、导航、音乐与听书、通话、录音、录屏、计时器、快递取件等一批场景，清单在华为官网可以查到；
- **小米澎湃 OS 的超级岛/焦点通知**需要应用方按开发者文档接入通知接口并申请焦点通知权限，因此只有一部分应用会出现在系统岛上。

由此可以得出一条实用的判断：**你手机自带的那套覆盖不到的应用，正是 dynamicSpot 的用武之地**。如果你的常用应用里有一半没出现在系统岛上，那 dynamicSpot 更值得留。

## 二、冲突长什么样

- **同一条信息出现两次**：来电、计时器、音乐这类两边都能识别的场景最容易重；
- **两条黑条并列或叠着**：自带胶囊占据状态栏，dynamicSpot 自己画一条，位置撞在一起；
- **偶尔互相挤掉**：一条出现后另一条消失，看起来像「闪烁」。

## 三、怎么让出位置

**如果决定用系统自带的**：把 dynamicSpot 停用或卸载，然后在系统设置里确认实况窗/超级岛的开关是打开的。停用前建议先关掉它的无障碍服务再卸载，理由见 [常见问题与排查.md](常见问题与排查.md) 最后一节。

**如果决定用 dynamicSpot**：把系统自带那套关掉或收窄。以华为机型为例，官方给出的路径是：

1. 设置 → 通知和状态栏 → 实况窗：逐个应用关掉旁边的开关（部分应用支持这样单独关）；
2. 设置 → 通知和状态栏 → 状态栏 → 「显示实况窗」总开关。

其他品牌的控制入口在系统设置里随版本变化，名称可能是「实况窗」「超级岛」「灵动胶囊」「原子岛」这类，直接在设置里搜这几个词即可。**如果某个应用的自带胶囊无法单独关闭**，剩下的办法是把这个应用从 dynamicSpot 的清单里去掉，让它只走系统那一套——这样两条黑条不会同时出现，代价是这一个应用的外观听系统的。

## 四、一个省事的分配方案

不想逐个研究哪些应用该归谁，可以按下面这个思路分：

- **系统覆盖得好的**（外卖、打车、航班、导航、通话、计时器）→ 交给系统自带的，从 dynamicSpot 清单里删掉；
- **系统覆盖不到的**（各种第三方聊天、邮件、下载、录屏工具）→ 交给 dynamicSpot。

这样两边各管一段，屏幕顶部不会重复，也不用为了关掉一堆开关去翻设置。至于系统横幅和灵动岛之间的重复，那是另一层问题，处理办法见 [灵动岛与系统横幅重复弹出怎么关.md](灵动岛与系统横幅重复弹出怎么关.md)。
