## 一、从首页到时间线

1. 打开 InShot，首页点「视频」，从相册选一段或多段素材（可多选，一次导进同一项目）。
2. 导入后看到的是一条**单轨时间线**：画面预览在上方，素材轨在中间，工具栏在底部。常用工具直接排在主界面上，不用进子菜单找。
3. 选中时间线上的某一段（点击它，出现白框），底部工具栏才会切换成针对这一段的操作，比如分割、变速、删除。

操作错了点左上角撤销箭头，一段一段往回退。

## 二、分割、裁剪与拼接

| 想做的事 | 怎么做 |
| --- | --- |
| 从中间剪掉一段 | 移动播放头到切断点 → 选中素材 → 点「分割」→ 两段之间再点删除 |
| 掐头去尾 | 选中素材，拖动素材两端的白色边框向内收 |
| 拼接多段视频 | 首页导入时多选；或点「+」继续追加，段与段自动顺序相接 |
| 保留画面中间、去掉黑边 | 用「画布」以外的裁剪工具，框住要留的区域 |
| 调整片段顺序 | 长按某段拖动到目标位置 |

导出后的成片长度 = 时间线上所有片段按顺序相加，剪掉的段落不计入。

## 三、画幅与画布

InShot 支持多种画幅比例，常见对应关系是：

| 比例 | 典型用途 |
| --- | --- |
| 1:1 | 正方形构图，朋友圈、Instagram 帖子 |
| 9:16 | 竖屏短视频，抖音、快手、短视频平台 |
| 16:9 | 横屏，YouTube、B 站、电视 |

点「画布」选比例。竖屏素材放进横屏画布时，两侧会留空，空出部分可以用模糊背景或纯色/自定义背景图填充；反过来横屏素材进竖屏画布同理。

## 四、变速与倒放

- 选中片段点「变速」，InShot 的速度范围是 **0.2x 到 100x**，小于 1x 是慢放、大于 1x 是快放。
- 「曲线变速」可以在一个片段内做快慢变化，比如开头正常、中间慢动作、结尾加速。
- 「倒放」把片段从尾到头播，适合做「东西飞回手里」这类效果。个别片段点了倒放没反应，先把它转成常见格式再试。

慢放倍数越低，画面越可能出现卡顿感，属正常现象，不影响导出。

## 五、转场与滤镜

- 转场加在**两段素材的接缝**上：点时间线段与段之间的白色方块，从转场库里选。官方提供的转场数量在 60 种以上，部分标注 Pro 的转场只有会员能用；免费版能用什么、水印怎么处理，见 [去水印方法与免费版限制.md](去水印方法与免费版限制.md)。
- 滤镜加在**单段素材**上：选中片段 → 「滤镜」，有 VHS、Glitch、Retro、RGB 等风格，同一片段也可以再用「调节」手动改亮度、对比度、饱和度。
- 想让全部片段统一色调，就逐段加同一个滤镜、用同样的参数。

## 六、剪完之后

剪完不要急着关应用，先在预览里完整过一遍，确认无误再点右上角导出按钮。导出参数怎么选、各平台推荐什么分辨率，见 [导出视频画质与参数设置.md](导出视频画质与参数设置.md)；导出后画面右下角带 InShot 水印的处理办法，见 [去水印方法与免费版限制.md](去水印方法与免费版限制.md)。
