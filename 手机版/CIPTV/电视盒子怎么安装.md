## 一、先确认你的设备能装

- **安卓电视盒子、安卓智能电视**：能装，这是 CIPTV 这类直播应用最常见的用武之地，界面本身就按遥控器操作设计。
- **运营商送的 IPTV 盒子（电信 / 联通 / 移动定制机）**：多数出厂就锁死了第三方应用安装，有的还带白名单校验，设置里根本没有「未知来源」开关。这类盒子装不上是系统限制，不是你操作不对，别硬折腾；用自己买的盒子或智能电视更省事。
- 先把 APK 拿到电脑上：打开 [CIPTV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5487d268ceaf)，转存后在电脑浏览器登录夸克网盘网页版下载。

## 二、U 盘安装（最通用）

1. 电脑上把 APK 拷进 U 盘。**顺手把文件名改成纯英文短名**（如 `ciptv.apk`）：部分老盒子不支持中文或长文件名，安装失败往往出在这一步。
2. U 盘插到盒子或电视的 USB 口。
3. 打开设备自带的**文件管理 / 媒体中心**，找到 APK，用遥控器点**安装**。
4. 弹出「禁止安装」时，去开未知来源开关（第三节）。
5. 盒子的文件管理器看不到 APK（有的会隐藏安装包）：装一个能在电视上浏览文件、打开 APK 的第三方文件工具，再进 U 盘找。

## 三、打开「未知来源」开关

各家叫法和位置不同，认这几个词：「未知来源」「允许安装未知应用」「安装未知应用」。常见位置大致如下（系统升级后菜单可能变动，以你设备实际菜单为准）：

| 设备 | 大致路径 |
| --- | --- |
| 原生 Android TV / Google TV | 设置 → 设备偏好设置 → 安全和限制 → 未知来源 |
| 小米 / Redmi 盒子电视 | 设置 → 账号与安全 → 安装未知应用 |
| 天猫魔盒类 | 设置 → 安全 → 未知来源 |
| 华为 / 荣耀智慧屏 | 设置 → 安全 → 允许安装第三方应用（部分型号默认锁死，无此选项） |

Android 8 以后是按应用授权：要允许的是**你用来打开 APK 的那个应用**（文件管理器等），不是全局放开。

## 四、局域网推送（不用 U 盘）

1. 手机和电视盒子连同一个 Wi-Fi。
2. 手机应用商店里找一个「电视推送 / 远程安装」类工具。
3. 部分工具有两截：先在盒子上装接收端，再从手机端推送 APK。
4. 推送完成后在盒子上确认安装。

## 五、「解析包错误」逐条对

| 原因 | 处理 |
| --- | --- |
| APK 没下完整 | 回电脑重新下载再拷 U 盘；别用盒子自带浏览器直接下载 |
| 文件名是中文或太长 | 改成 `ciptv.apk` 这类纯英文短名再装 |
| 系统太老 | 安卓版本过低的盒子跑不了新包；换设备，或改用旧版包 |
| 装过同名的其他包 | 先卸载旧包再装：签名不一致时覆盖安装会直接失败 |
| 运营商定制盒子 | 系统锁死了安装权限，见第一节，多数无解 |

装好后的频道加载不出来、卡顿等问题见 [常见问题与播放排查.md](常见问题与播放排查.md)；手机与电视的安装路径总览见 [下载与安装教程.md](下载与安装教程.md)。
