## 一、直播源是什么、什么时候需要它

直播源就是一个频道列表的网址（常见为 M3U / M3U8 格式的文本链接），应用读到它之后，频道清单就按它来。两种情况会用到：

- 内置频道里**没有你想看的台**（某个地方台、外语台之类）；
- 内置列表里**大片频道失效**，想整批换成新的列表。

公开介绍提到：把公开合法的 IPTV 源链接粘贴进去，应用可自动加载数量可观的频道，并支持 HLS、RTMP 等主流流媒体协议。

## 二、导入步骤

1. 先拿到一个**公开渠道发布的**频道列表链接。来源不明的列表不要用，里面的频道地址没法核对。
2. 打开 CIPTV 的**设置**，找**直播设置 / 直播源**相关入口（不同版本叫法有差异，认「直播源 / 自定义频道」字样）。
3. 把列表链接粘贴进去，确认后应用会重新加载频道清单，几十秒到几分钟不等，取决于列表大小。
4. 回到直播页，频道数变多即导入成功。

入口找不到时别硬找，以你手上版本的实际菜单为准；导入后频道异常的处理见 [常见问题与播放排查.md](常见问题与播放排查.md)。

## 三、导入前先验一眼源

浏览器直接打开源链接（或把文件下载下来用记事本打开），一分钟就能判断成色：

- 开头是 `#EXTM3U`、往下是一排 `#EXTINF` 行 → 是正经的频道列表；
- 每个 `#EXTINF` 行的下一行是一个 `http(s)://` 开头的地址 → 结构正常；
- 打开是 HTML 网页、或提示 404 / 超时 → 这不是源或已经失效，别浪费时间导。

M3U 列表就是纯文本，长这样（示例为虚构地址，仅示意结构）：

```m3u
#EXTM3U
#EXTINF:-1 tvg-name="CCTV-1" group-title="央视",CCTV-1 综合
http://example.com/live/cctv1.m3u8
```

`group-title` 是频道分组名，应用里频道列表的分组就按它来。扩展名 `.m3u8` 只代表文件用了 UTF-8 编码：带中文频道名的列表优先选 `.m3u8`，纯 `.m3u` 遇到中文容易乱码。

## 四、选源的三个判断标准

| 看什么 | 判断依据 |
| --- | --- |
| 更新时间 | 列表页一般标更新日期，越新越可能可用；放了一两个月的源失效比例明显上升 |
| 频道数量 | 数量上千的列表杂讯也多，先试小而新的，再试大而全的 |
| 链接形态 | 源链接应以 `.m3u` / `.m3u8` 结尾，或内容是纯文本频道列表；普通网页链接不是源 |

公开免费源的常态是时效短：这周能用、下周挂掉很正常，保持「能换」的预期即可。

## 五、源失效的判断与更换

- 症状：频道列表能加载，但点开一片黑屏或全部转圈，大概率是源失效或被限流。
- 先换一两个频道，确认是个别台挂了还是整表挂了；整表挂了就换新源，回到第二节重做。
- 换源前把旧链接留个备份，方便对照哪些台是新表里没有的。

## 六、频道整理

- **书签 / 收藏**：常用的台收藏起来，从收藏列表直达，避免每次翻长列表。
- **自定义频道列表**：导入后按自己的习惯整理分组（公开介绍提到支持自定义频道列表）。

直播的日常操作（换台、线路、回放）见 [怎么看电视直播.md](怎么看电视直播.md)。
