## 一、安装环节

| 症状 | 先做的动作 |
| --- | --- |
| 提示「禁止安装未知来源应用」 | 去**设置 → 安全**（或「安装未知应用」）里，允许你用来打开 APK 的那个应用安装 |
| 提示「解析包错误 / 解析失败」 | 多半是 APK 没下完整，重新下载一次；**文件名改成纯英文短名**（如 `ciptv.apk`）再试，部分设备不支持中文或长文件名 |
| 安装后点开就闪退 | 确认设备系统版本不算太旧：安卓版本过老的盒子和电视对新包兼容性差，换设备或换旧版包再试 |
| 运营商定制的 IPTV 盒子怎么都装不上 | 出厂锁死了第三方安装、甚至带白名单校验，多数无解，换非定制设备 |

安装的完整步骤见 [下载与安装教程.md](下载与安装教程.md)；电视盒子上的装法与「解析包错误」的逐条处理见 [电视盒子怎么安装.md](电视盒子怎么安装.md)。

## 二、登录与密码

公开渠道的介绍口径一致：**无需注册、无需登录，打开即看**。如果你手上的包在启动时要求输入密码、激活码或手机号，先怀疑包本身 —— 这类应用常被第三方改包后二次分发。回到安装教程核对版本与来源：本篇安装包为 1.3.2，包名 `com.ciptv.app`。

## 三、频道黑屏 / 一直转圈

按顺序做：

1. **换个台**：只有个别台不行，就是那个台的源挂了，等会儿再看；整片台都不行，继续下一步。
2. **换线路**：播放界面里手动切换播放线路，同一频道常有多条线路。
3. **换源**：导入的直播源整表失效时，换一个新源，步骤见 [直播源导入与频道管理.md](直播源导入与频道管理.md)。
4. **查网络**：手机流量换 Wi-Fi、Wi-Fi 换热点各试一次，排除网络波动。

## 四、卡顿、缓冲多

- 电视盒子尽量**插网线**；Wi-Fi 环境优先连 5GHz 频段，2.4GHz 拥挤的环境卡顿最明显。
- 把清晰度降到高清或标清档再试，带宽不稳时硬扛高清晰度只会更卡。
- 盒子内存小的，先关掉后台其他应用再进应用。
- 晚间时段整体变卡，多与网络拥塞有关，不是设置问题。

## 五、有画面没声音 / 有声音没画面

- 进**设置 → 播放器设置**（不同版本叫法略有差异），切换解码方式（软解 / 硬解）后重进频道，这是这类播放应用最见效的一招。
- 电视外接了功放或音响的，先确认电视本机音量没有被静音，再查外部设备的输入源。

## 六、手机上看着不对劲

- 界面按电视横屏设计，竖屏打开会显得空，**横过来看**才正常。
- 手机上看某些台比电视上卡，多与手机网络有关：切换 Wi-Fi / 流量对比一下即可分辨。

日常直播操作见 [怎么看电视直播.md](怎么看电视直播.md)。
