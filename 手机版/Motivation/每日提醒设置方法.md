# Motivation 每日提醒设置方法

> Motivation 的主角是「定时推到你面前的语录」。本篇讲怎么设定提醒的时间与频率、换推送内容，以及提醒太吵或收不到时往哪调。

## 一、提醒是怎么工作的

你不需要打开应用——到点后它会发一条带语录的通知。推什么内容由你勾选的分类决定，几点发、发几条由应用内的提醒设置决定。

首次启动时跳过了通知授权的话，提醒不会响：去系统「设置 → 应用 → Motivation → 通知」手动打开。

## 二、设置提醒时间与频率

在应用内找「提醒 / Reminders / 通知设置」类入口（不同版本叫法略有差异）：

- **时间点**：把提醒对齐到你的作息——起床后一条、午后低谷一条、睡前一条是常见的配法；
- **频率**：从每天一条到一天多条不等，按自己的耐受调；
- 想让工作日和周末不一样，就分别调整或临时关掉部分提醒（以应用内提供的选项为准）。

改完即生效，以收到的下一条为准。

## 三、换推送内容：改分类

觉得语录不对味，先改分类再怀疑别的——推送内容完全跟着分类走。分类清单与改法见 [功能与主题自定义.md](功能与主题自定义.md)。开始新计划就加对应主题，阶段结束就取消勾选，分类跟着生活状态走，收到的句子才有用。

## 四、提醒太吵怎么办

按暴力程度从小到大：

1. **降频率**：应用内把每日条数调少、把时间挪到不打扰的时段；
2. **改通知形式**：系统「设置 → 通知」里把它设为静默通知（不响铃、不弹横幅，只安静地进通知栏）；
3. **临时停**：应用内关闭提醒，想看语录时改用桌面小组件（见 [小组件使用指南.md](小组件使用指南.md)）；
4. **彻底关**：长按某条通知选「关闭此类通知」，或系统里直接停用它的通知权限。

## 五、收不到提醒先查这几处

按命中概率排序，逐项过：

1. **通知权限（总开关与分类开关都要看）**：系统「设置 → 应用 → Motivation → 通知」里，除了总开关，下面每个**通知类别**还有独立开关——总开关开着但某个类别被单独关掉，是很容易漏查的一种。安卓 13 起新装应用还要单独授予通知权限，装的时候拒绝了就一直静默；
2. **电池优化与后台限制**：把应用设为「不受电池优化限制」或「无限制」；三星手机额外查「设置 → 电池 → 后台使用限制」，把它从「休眠应用 / 深度休眠应用」里移出来；部分系统有「暂停不常用应用的活动」开关，一并关掉对它的暂停；国产系统（MIUI、ColorOS、HarmonyOS 等）通常还要在最近任务里给它加锁，防止一键清理杀掉它；
3. **后台数据**：应用详情里的「流量使用情况」允许后台数据；开了「省流量模式 / Data Saver」的，把它加进白名单；
4. **勿扰与专注模式**：勿扰不一定会拦下通知本身，可能只是压掉了铃声和横幅——通知其实躺在通知栏里；
5. **用通知历史核对**：「设置 → 通知 → 通知历史」能显示最近收到过哪些通知。历史里有它，说明推送正常、是你没看到；历史里也没有，再回到前面几项查。

调完还不来，看 [常见问题解答.md](常见问题解答.md)。
