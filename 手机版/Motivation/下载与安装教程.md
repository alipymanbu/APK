## 一、安装前先确认这几点

Motivation 是 Monkey Taps LLC 出品的每日语录应用，安卓端的安装文件是 `.apk` 格式，需要你手动安装，不是从应用商店点一下就完的那种。

动手前核对三件事：

| 检查项 | 要求 |
| --- | --- |
| 系统版本 | 安卓手机；多数第三方应用市场对相近版本的标注是 Android 8.0 起，以安装时手机弹出的提示为准 |
| 存储空间 | 安装包约 168.92 MB，建议再留出至少 500 MB 空闲空间给安装过程 |
| 安装来源 | 网盘安装文件，安装时系统会请求「允许安装未知应用」权限 |

本文对应这份安装文件的具体版本：

| 项目 | 值 |
| --- | --- |
| 应用名称 | Motivation - Daily quotes |
| 版本 | 4.70.1 |
| 包名 | com.hrd.motivation |
| 安装包大小 | 168.92 MB |
| MD5 | ED2FCB8F630B58C82E6094BC0F3C6305 |

官方在 [Google Play](https://play.google.com/store/apps/details?id=com.hrd.motivation) 上的版本号通常已经高于 4.70.1；如果你想装的就是本文对应的这一版，按下面流程走即可。

## 二、拿到安装文件

安装文件放在夸克网盘里：[Motivation 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5528d339fba2)。

流程两步：

1. 打开上面的分享链接，先把文件**转存到自己网盘**（转存后才能正常下载）；
2. 在网盘客户端里找到该 APK 文件，下载到手机本地存储。

在电脑上下载的，之后用数据线、局域网共享或聊天工具的「文件传输助手」传到手机都行。

## 三、（可选）核对文件完整性

想确认下载的文件没损坏，就比对 MD5，正确值是 `ED2FCB8F630B58C82E6094BC0F3C6305`（不区分大小写）。

Windows 上，在安装包所在目录打开终端执行：

```powershell
certutil -hashfile "Motivation_v4.70.1.apk" MD5
```

macOS / Linux 上：

```bash
md5sum Motivation_v4.70.1.apk
```

部分安卓文件管理器（如 MT 管理器）在文件属性里也带 MD5 查看。校验值对不上就重新下载一次，别强行安装。

## 四、安装步骤

1. 在文件管理器里点开下载好的 APK；
2. 首次安装会提示「不允许安装未知来源应用」——按提示进系统设置，对「文件管理器」（或你用的浏览器）勾选「允许安装未知应用」，返回后继续；
3. 等安装完成，点「打开」。

三种常见拦路情况：

- **提示存储空间不足**：清理后重试，安装过程占的空间比安装包本身大；
- **提示解析包出现问题**：多半是下载不完整，重新下载并核对 MD5；
- **手机上已装过旧版**：同包名（com.hrd.motivation）可以直接覆盖安装；但从别的渠道装过非官方版本的话，先卸载再装。

装完想先把每日提醒调好，直接看 [每日提醒设置方法.md](每日提醒设置方法.md)。

## 五、首次启动会经过什么

第一次打开，应用会带你做一个简短的初始设置，核心就两件事：

1. **选感兴趣的分类**——决定你每天收到什么主题的语录（自我成长、健身、亲密关系等，分类清单见 [功能与主题自定义.md](功能与主题自定义.md)）；
2. **开通知权限**——它的核心用法是到点把语录推到通知栏，不给通知权限就收不到提醒。

当时跳过了也没关系，之后都能在应用设置里改。一条龙路径：选分类 → 保持通知开启 → 回桌面加一个小组件（见 [小组件使用指南.md](小组件使用指南.md)）。
