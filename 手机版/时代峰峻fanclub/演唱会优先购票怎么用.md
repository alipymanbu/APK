## 一、机制本身：官方协议怎么写的

官方会员服务协议（T-FAMILY 会员服务协议，[tfapk.tfent.cn](https://tfapk.tfent.cn/)）里与你直接相关的几条：

- 高级会员**有机会**参与优先购票活动——是「有机会」，协议明确写了**不保证**每位会员都能抽中或购得门票；
- 核准观演人数 5000 人以上的大型演出：面向公众销售的票**不低于 85%**（这是监管硬性规定，优先购票只能占剩下的部分）；海外及港澳台地区在不违反当地政策的前提下，高级会员可获得 100% 可售票的优先购票数；
- 5000 人以下的中小型演出：优先购票数以监管部门审核为准；
- 因不可抗力或政策原因无法提供优先购票权益时，**时代峰峻不承担违约责任，会员无权据此要求退还会费**。

两条推论你自己算：优先购的池子本来就不大，「开了高会 = 必有票」不成立；以及**会费一旦开出去，退的口子比你想的窄**（退款话题见 [高级会员开通与权益.md](高级会员开通与权益.md)）。

## 二、完整链路（以近期活动公告为例，时间以当次公告为准）

历年活动的打法基本一致，流程五步：

1. **你得先有券**：截止时间点前已是有效高会、且实名认证无异常的账号，会拿到一张**购票特权券**，以站内信通知（查询路径：App 内「我的 → 消息 → 官方消息」）。
2. **券会下发到你的大麦账号**：优先购不是在本 App 里付款，而是去**大麦 App** 用券买票。
3. **在公告的时间窗内购票**：每场演出单独公告一个时间窗（例如 12:00–14:00），过窗作废。
4. **一券一张**：特权券不等于门票、不能抵扣票价，一张券只能买一张票，不可转让、不可售卖。
5. **入场核验**：一人一证一票，入场刷购票时绑定的**身份证原件 + 人脸识别**；购票成功后观演人信息不可更改，转售票、黄牛票无法入场。

没在时间点收到券的补救渠道写在当次公告里（常见做法是发邮件到官方指定地址并附会员 ID，如 `letter@tfent.cn`，**以当次活动公告为准**）。

## 三、双平台一致原则（有券也下不了单，多半出在这）

粉丝整理、且与多份活动公告相互印证的核对清单，抢票前逐条对：

| 你该核对的 | 要求 |
| --- | --- |
| 高会绑定手机号 vs 大麦绑定手机号 | 必须**同一个号** |
| 高会实名认证信息 vs 大麦观演人信息 | 必须**同一套身份** |
| 身份信息绑定的高会账号数 | 同一身份仅可正常绑定**一个**高会账号，重复认证会标「异常」，异常账号拿不到券 |
| 演出所在地 vs 证件类型 | 内地举办的演出只能用**身份证**购票，港澳通行证、护照都不行 |

换句话说：抢票前别动实名信息、别换绑手机号、别新注册第二个月会号——这几件事任何一件做了一半，都可能让券和票两头落空。

## 四、什么时候开会员、在哪儿开

- **时机**：券的发放看「截止时间点是否仍有效」，想赶某场演出的优先购，要在公告的截止时间前开通或续费，当天才充往往来不及。
- **渠道价差**：有用户反馈，iOS 在 App 内开通的内购价高于安卓侧常见价位（内购抽成的常态做法），并流传着「走官方小程序按安卓价开通」的路子。**价格随时变动，两边都以你付款页当时显示的金额为准**，别按任何帖子写死的数字下单。
- 开通动作本身见 [高级会员开通与权益.md](高级会员开通与权益.md)，开通前把那篇里的退款口径一起看了再付钱。

## 五、几个容易踩的坑

- **特权券过期不候**：时间窗错过就是错过了，公告不会为你重开，责任自负是协议明写的。
- **别信「代抢」**：代抢要你的账号与身份信息，媒体曝光过多起收钱不出票的代抢骗局；而且入场绑的是你本人的身份证，信息给了别人，票抢到也未必是你的。
- **发票**：官方协议写明会员服务到期无纠纷后，可在交易订单内申请开票——要报销或留凭证的，走订单里的正规入口。
- **协议会变**：以上比例与规则摘自现行协议，官方保留调整优先购票数的权利，每次以 App 内协议与当次活动公告的最新表述为准。
