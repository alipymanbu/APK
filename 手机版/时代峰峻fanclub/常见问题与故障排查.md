## 一、症状速查表

下表问题都能在官方更新日志里找到对应修复版本，**先看你的版本低于修复版本就直接升级**，高于修复版本还复现才走后面的细节：

| 症状 | 官方修复/变化版本 | 快速解法 |
| --- | --- | --- |
| 登录页协议弹窗点不了「同意」 | 5.1.8 | 升级到 5.1.8 及以上 |
| 泡泡消息通知无声音、被系统折叠 | 5.1.8 | 升级；再检查系统通知权限 |
| 泡泡图片/视频下载后显示拍摄地点 | 5.1.8 | 升级（属旧版泄露元数据的问题） |
| 部分机型偶发闪退 | 5.0.4 | 升级；仍闪退见第三节 |
| 防伪码绑定页白屏 | 多版本迭代处理 | 见第四节 |
| 海外号码无法注册/登录 | 5.2.0 起支持海外号码 | 升级到 5.2.0 及以上 |
| 图形验证（人机校验）体验问题 | 5.2.2 优化交互 | 升级到 5.2.2 及以上 |

版本号一律以 [应用宝详情页](https://sj.qq.com/appdetail/com.sf.tf) 当时显示为准；网盘那份固定为 5.1.9（关于它的事实见 [下载与安装教程.md](下载与安装教程.md)）。

## 二、通用三步排查

1. **升级应用**：这个应用修 bug 的节奏很密，你遇到的坑多半别人先踩过、官方已在下一版修掉。先升到最新版再复现问题。
2. **重启 + 清缓存**：杀掉进程重开；仍异常就去系统设置里清一次缓存（清缓存不丢账号数据，数据在服务器侧）。
3. **换网络复现**：Wi-Fi 和流量各试一次。能定位是网络问题还是应用问题——校验类、直播类内容对网络尤其敏感。

三步都无效，才值得去「我的」里找官方客服反馈，反馈时带上机型、系统版本、应用版本号，能省一轮来回。

## 三、闪退与白屏的深挖方向

按顺序试，每做一步复现一次：

1. 确认系统版本不过旧——官方商店页标注的最低系统要求以 [应用宝详情页](https://sj.qq.com/appdetail/com.sf.tf) 当时显示为准，系统太旧是装得上但跑不动的常见原因；
2. 卸载后重装最新包（覆盖装不能修复损坏的本地文件；账号权益跟号走，卸载不丢，见 [下载与安装教程.md](下载与安装教程.md) 第五节）；
3. 手机剩余存储不足时应用加载图片视频容易崩，先清出 1GB 以上再试；
4. 用「手机管家」类工具查一下是否误拦了应用权限（存储、通知、相机扫码是最常被误关的三项）。

## 四、防伪码绑定白屏

这是评论区反馈最集中的一个：扫码页一直白屏，真卡假卡分不出来。已知信息是**有人反馈后自行恢复**，说明服务端或版本侧修过。你的处理顺序：升级到最新版 → 换网络重进绑定页 → 改用手动输入防伪码（不走相机，绕开相机权限与扫码渲染）→ 仍失败就过几小时再试。防伪码本身不会失效，晚绑不影响商品归属。

## 五、泡泡（聊天功能）相关

泡泡是 5.1.5 加入的试运营功能（TF 家族四代练习生已上线，其余家族陆续开放），5.1.7、5.1.8 连修两轮，集中在消息通知与图片视频质量上。你如果遇到「收不到泡泡通知」，按三层查：应用内泡泡设置 → 系统对该应用的通知权限 → 手机的省电策略是否把应用后台杀了（国产 ROM 的默认激进省电是消息折叠重灾区）。找不到泡泡入口则是版本太旧，它在 5.1.5 才出现。泡泡的发送规则、发送失败与审核拦截的完整处理见 [泡泡功能怎么用.md](泡泡功能怎么用.md)。
