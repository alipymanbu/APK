# 同名应用与官方渠道怎么认

> 叫 Seele 的东西不止一个：认清开发者、包名和版本号，别装错也别下错版本。

## 一、先记住你要的是哪一个

聊天用的 Seele 是 **BANANAWORLD K.K.** 开发的应用，官方英文名就是 Seele。它能做的事是「挑 AI 角色聊天、自己创建角色、语音和 3D 形象互动」，属于陪伴与角色扮演类。

搜这个名字时最容易碰上的是另一家：`seeles.ai` 上的 SEELE 是一家做 AI 游戏生成的公司，产品是提示词生成游戏的云端工作台，跟聊天应用没有任何关系。名字都叫 Seele，但开发的不是同一家公司，做的也不是同一件事。

## 二、三个能立刻辨认的标识

| 标识 | 认哪个 |
| --- | --- |
| 开发者 | BANANAWORLD K.K. |
| 包名 | `com.bananaworld.seele` |
| 应用名 | Seele |

装之前看一眼安装详情里的开发者名，对不上的直接放弃。装完之后也能核对包名，手机上「设置 → 应用 → Seele → 应用信息」里能看到。

## 三、官方渠道长什么样

官方渠道是应用商店里由 BANANAWORLD K.K. 发布的 Seele 页面——苹果侧在 App Store，安卓侧在 Google Play，页面上会写明开发者、版本和系统要求。想确认某条信息（最低系统版本、支持哪些玩法），以这个页面的说法为准。

至于第三方下载站，它们的介绍大多互相转抄、更新时间也对不齐，作为了解功能的参考可以，作为版本依据不行。

## 四、版本号对不上就是别处的东西

同一批下载站上，这个应用的版本号出现过从 2.10.9 到 8.9.25 的多种写法，而包名和安装包大小却写得一致——这说明其中一部分是随手填的，不是真实版本。

判断办法很简单：**先看包名，再看版本**。

- 包名不是 `com.bananaworld.seele` → 那是别的应用，不管名字多像；
- 包名对得上、但标注的版本与安装包大小明显对不上（比如写着 8.x 却仍是 212M 级别的包） → 该页面不可信。

本地这一份的版本信息如下，可直接对照：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.10.9 |
| 包名 | `com.bananaworld.seele` |
| 安装包大小 | 约 212.25M |
| MD5 | `8bb0ae4fb52a64b3745ed5ebe08ae6b4` |
