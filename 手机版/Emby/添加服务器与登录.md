## 一、登录用的账号密码从哪来

手机客户端自己不注册账号，你输入的用户名和密码是**服务器那边**设的：

- **服务器是你自己的**：装 Emby Server 时，启动向导会让你创建管理员账号，用它登录即可。
- **是别人邀请你用的**：向服务器主人要一个账号（对方在服务器后台给你建用户），拿到用户名和密码再来登录。

所以第一次打开 App 卡在登录页时，先确认手里有没有这两个东西，没有就先解决服务器那一侧。

## 二、方式一：同一 WiFi 下自动搜索

App 第一次启动会进入连接向导，并自动搜索同一局域网内正在运行的 Emby Server。你在家、手机和服务器连的是同一个路由器时，搜索结果里一般会直接列出服务器名称：

1. 打开 App，等待搜索结果出现。
2. 点选你的服务器。
3. 输入用户名和密码，登录。

自动搜索依赖局域网广播（UDP 7359 端口），有些路由器开了 AP 隔离或访客网络会把它拦掉，搜索列表一直空着就是这个原因，改用方式二手动添加即可。

## 三、方式二：手动添加服务器地址

搜索不到、或者你要连的服务器在外网时，用「添加服务器」手动输入地址：

1. 在连接向导或服务器列表页选「添加服务器」（Add Server）。
2. 输入服务器地址，格式是 `协议://地址:端口`，例如服务器在局域网里就是 `http://192.168.1.10:8096`。
3. 点连接，成功后输入用户名密码登录。

几个地址相关的要点：

- **端口**：Emby Server 默认用 `8096`（HTTP）和 `8920`（HTTPS）。局域网内一般写 `http://服务器IP:8096` 就能连上。
- **服务器 IP 怎么查**：在跑服务器的那台电脑上打开 `http://localhost:8096`，进控制台（Dashboard），「In-Home (LAN) access」一栏显示的就是它的局域网地址。
- **IP 建议固定**：路由器重启后设备 IP 可能变化，导致昨天还能连今天连不上。在路由器的 DHCP 保留（静态地址分配）里给服务器机器绑一个固定 IP，可以一劳永逸。
- **外网地址**：服务器主人如果配置了外网访问（域名、端口转发或内网穿透），地址就填他给你的那个；没配置的话，出了家门这个客户端是连不回去的。

地址填对了但仍然连不上，逐项排查的方法在[常见连接问题排查.md](常见连接问题排查.md)。

## 四、方式三：Emby Connect

Emby Connect 是官方提供的免费辅助登录方式，适合「记不住服务器地址」的场景：你在 [https://emby.media](https://emby.media) 注册一个 Connect 账号，服务器管理员把服务器上的用户与你的这个邮箱绑定之后，你在 App 里选「使用 Emby Connect 登录」（或用 PIN 码流程），不用手输服务器地址就能找到并连上那台服务器。

两点边界要清楚：

- 它只负责「帮你找到服务器」，影片数据仍然是你手机直连服务器传输的，不经过官方中转。
- 前提是服务器管理员那边做了绑定，只注册 Connect 账号、服务器没绑定，是连不上任何东西的。

## 五、连上之后

登录成功就进入媒体库首页，可以浏览和播放了。播放不流畅、字幕不显示这类问题，先去[播放设置与格式支持.md](播放设置与格式支持.md)对照设置；想换一台服务器或管理已添加的多个服务器，在侧边栏的服务器设置里切换即可。
