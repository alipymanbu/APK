# Emby 安卓手机版连不上服务器的排查方法

> 本篇按顺序列出手机客户端连不上 Emby 服务器时的排查步骤：从搜索列表为空，到手动地址连不上，逐项对照。

## 一、先分清两种情况

- **自动搜索列表是空的** —— 多半是网络环境把「发现」机制拦了，App 和服务器其实都正常。
- **手动输地址也连不上** —— 这才轮到查服务器本身和防火墙。

两种情况的排查路径不同，按下面顺序走。

## 二、搜索列表为空的排查

1. **确认手机和服务器在同一个网络里**：手机连着移动数据、或者连了访客 WiFi，都搜不到家里服务器。切到和服务器同一台路由器的 WiFi 再搜。
2. **路由器开了 AP 隔离 / 访客网络隔离**：这种模式下同一路由器下的设备互相不可见，自动搜索（依赖 UDP 7359 广播）必然失效。关掉隔离，或直接跳到手动添加地址。
3. **直接手动添加**：搜索不出来不代表连不上，用地址直连的成功率高得多，方法见[添加服务器与登录.md](添加服务器与登录.md)第三节。

## 三、手动地址也连不上的排查

按命中率从高到低逐项查：

| 步骤 | 查什么 | 怎么判断 |
| --- | --- | --- |
| 1 | 服务器开着没有 | 去服务器那台机器上看 Emby Server 进程在不在运行（Windows 任务管理器、macOS 活动监视器、Linux `ps -e`） |
| 2 | 地址写对没有 | 在**同一 WiFi 下的另一台设备**（手机浏览器即可）打开 `http://服务器IP:8096`，能打开网页端就说明服务器正常，问题在 App 侧填写的地址 |
| 3 | 服务器 IP 变了没有 | 路由器重启后 IP 可能轮换，去服务器机器的控制台（Dashboard）看当前「In-Home (LAN) access」显示的地址，和 App 里填的对一下；经常变就在路由器里做 DHCP 保留固定 IP |
| 4 | Windows 网络配置文件 | 服务器是 Windows 时，检查网络连接的属性是「专用（Private）」而不是「公用（Public）」—— 系统更新或改过网络设置后常被切回公用，公用配置下会拒绝局域网连接 |
| 5 | 防火墙放行端口 | 服务器防火墙需要放行 TCP `8096`、`8920` 和 UDP `7359`（Windows 自带防火墙一般装 Server 时会自动加规则，第三方安全软件则常常不会） |

第 2 步是分水岭：浏览器都打不开服务器页面，问题一定在服务器或网络那一侧，继续在手机 App 里重试没有意义。

## 四、在家能用，出门就连不上

这是外网访问没配置的表现，不是 App 故障。手机客户端连外网服务器需要服务器那一侧做了公网暴露（域名 + 端口转发、反向代理或内网穿透），然后把外网地址填进 App。这部分配置在服务器侧，见官方文档 [https://emby.media/support/articles/Connectivity.html](https://emby.media/support/articles/Connectivity.html)；服务器主人没做的话，你在外网就只能等回家再连。

## 五、连上了但播放不正常

能进媒体库但播放卡顿、转码频繁、字幕不显示，属于播放问题：转码相关的按[播放卡顿与转码排查.md](播放卡顿与转码排查.md)查，字幕相关的按[字幕不显示与字幕下载.md](字幕不显示与字幕下载.md)查，码率与格式的基础设置在[播放设置与格式支持.md](播放设置与格式支持.md)。
