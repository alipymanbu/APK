## 一、先从现成角色挑起

Joyland 的角色列表由社区创作的 bot 组成，量级在数万这个级别（官方口径，以应用内当时显示为准）。挑的时候看三个地方就够：

- **简介与开场白**：开场白写了什么基调，聊起来大概就是什么基调 —— 比如侦探角色的开场白是一桩案子，浪漫向角色的开场白是搭话。开场白敷衍的角色，后面往往也敷衍。
- **标签**：角色卡上的标签（流派、性格、关系设定）比标题更能说明它是什么类型。
- **互动量**：卡片上显示的对话数 / 评论数是社区热度参考，新角色没数据不代表差，但热门角色踩坑概率低。

不确定要不要收藏，先点进去聊三四轮再决定 —— 文字聊天在各档位下都不限量，慢慢试不费钱；积分主要花在图片与工具上（见 [会员价格与积分规则.md](会员价格与积分规则.md)）。

## 二、自己捏一个角色

不想在别人的设定里聊，就自己建。创建页里你填的每一项都会成为角色的行为约束：

| 填什么 | 作用 |
| --- | --- |
| 名字、年龄 | 角色的自称与自我认知 |
| 外貌 | 影响它描述场景与自己时的用词 |
| 性格 | 最关键的一项 —— 毒舌还是温柔、主动还是被动全看它 |
| 世界观 / 背景故事 | 决定它知道什么、不知道什么，避免聊出设定外的内容 |
| 说话风格 | 短句还是长句、口头禅、称呼你的方式 |
| 关系设定 | 朋友、对手、恋人……决定开场距离 |

**省事的做法**：官方帮助中心提供用 JSON 或 PNG 快速导入角色的入口（`help.joyland.ai` 的 create / quick 页面），社区里也会有人分享角色卡，导入后改两处设定就能用。

**自建角色的两条经验**：

1. 背景故事别写成小说，写成**规则**更有效 —— 「他讨厌被人命令」「她不知道现代科技」这类条目比一大段生平更能稳住人设。
2. 性格与背景矛盾时，以性格为准生效，聊天跑偏先改性格那一栏。

## 三、Persona：让角色认识「你」

角色卡管的是「它是谁」，Persona 管的是「它是怎么认识你的」。你在 Persona 里填的名字、身份、说话方式，会在对话里被当成你本人使用 —— 不填的话，角色只能靠你在聊天里的表现猜你是谁，前后容易不一致。

- 免费档最多建 3 个 Persona，Standard 20 个，Premium 50 个（各档上限见 [会员价格与积分规则.md](会员价格与积分规则.md)）。
- 换一类玩法（比如从现代校园换到奇幻冒险）就换一个 Persona，别一个 Persona 用到底。

## 四、聊天里的常用操作

- **重新生成**：对某条回复不满意，用重新生成换一版，不用自己重打一遍话。人设漂了也先用这招，换一版往往就回来了。
- **图片消息**：角色能发图，消耗积分或按每日额度发（免费档有每日条数上限，付费档更宽，具体数字以应用内当时显示为准）。
- **Flow Mode（流畅模式）**：部分角色页标注了 `Flow Mode`，这是更强调连贯叙事的对话模式，官方会做限时免费，入口以角色页当时显示为准。
- **长对话的节奏**：一次性把场景推进太远，角色容易丢线索。场景切换时主动在话里交代一句时间地点，比依赖它自己记更稳。

## 五、角色记不住前面的事是正常的

记忆是分档的：免费档只有当前会话内的上下文，Standard 给跨会话的短期记忆，Premium 才是长期记忆 —— 所以免费档聊过几十条再回来，角色忘了你昨天说过什么，不是 bug。想让它记住长期设定，要么升档，要么把关键设定写进角色背景与 Persona（这招不花钱，见 [会员价格与积分规则.md](会员价格与积分规则.md)）。

要是记忆问题之外还伴随闪退、发不出消息，那是另一类问题，排查在 [常见问题与故障排查.md](常见问题与故障排查.md)。
