## 一、先读官方规则（服务条款原文口径）

Joyland 服务条款（最后更新 2025-05-14）对订阅写了四条硬规则，付费前就该知道：

1. **自动续费**：订阅会按你提供的支付方式持续扣费，**直到你取消为止**。
2. **要取消必须赶在下个计费周期续费之前** —— 已经扣掉的那一期不会因为中途取消而停下。
3. **不退部分周期**：月付用了半个月、年付用了半年，中途取消都不退当期已付的钱。
4. **到期不续费就自动降回 Free 档**：不是封号，是权益回到免费档。

## 二、取消订阅的正确位置

**订阅在哪开通的，就去哪取消**，删 App、卸载应用都不算取消：

| 开通渠道 | 取消路径 |
| --- | --- |
| iOS（App Store 内购） | `设置 → 顶部 Apple ID → 订阅 → Joyland → 取消订阅` |
| Google Play | `Play 商店 → 头像 → 付款和订阅 → 订阅` |
| 微信支付代扣 | `微信 → 我 → 服务 → 钱包 → 支付设置 → 扣费服务 → 关闭` |
| 支付宝代扣 | `支付宝 → 我 → 设置 → 支付设置 → 免密支付/自动扣款 → 关闭` |

取消成功后页面会显示到期时间 —— **当前周期内会员仍可用到到期日**，这是正常的，不是没取消掉。

## 三、取消了还在扣钱，怎么办

这是有用户反馈过的情况（第三方评测引述的应用商店与 Trustpilot 投诉，2026 年）：有用户称在续费前已取消、仍被扣款，联系客服后未获处理。**这类反馈是单一来源，不等于每个人都会遇到**，但处理路径值得先备好：

1. **截图留证**：取消成功的页面、扣费记录、与客服的对话，全部截图保存。
2. **核对扣费方**：看账单是 App Store / Google Play / 微信 / 支付宝哪一侧扣的 —— **在支付渠道侧投诉，比找应用客服更快有结论**。iOS 走 Apple 支持的报告问题，微信 / 支付宝在扣费详情页有投诉入口。
3. **在支付渠道直接关掉代扣**：就算应用侧取消失败，把支付渠道的自动扣款关掉，后续不会再扣。
4. **金额有争议**：国内渠道可向消协渠道投诉（如黑猫投诉等公开平台），海外渠道可走 Trustpilot 与应用商店的退款流程。上海消保委等机构对「自动续费未显著提醒」的争议有公开的处理口径，可作参考。

## 四、三个容易被扣的坑

- **早鸟价只在首期**：官方价格表挂着早鸟优惠（见 [会员价格与积分规则.md](会员价格与积分规则.md)），续费时是否恢复原价、恢复多少，**以扣款前应用商店显示的价格为准** —— 这是消保委公开调查里最常见的会员费争议类型（首期 9.9 元、次月按原价扣）。
- **扣费前没有提醒**：自动续费的扣款提醒由支付渠道与应用共同负责，没人提醒不等于没续费。**自己在日历上给续费日前一天设个提醒**最可靠。
- **删 App = 取消**：错。App 删了，代扣协议还在支付渠道那边，照扣。

## 五、什么情况值得争取退款

- **完全没使用过就扣费**（注册即扣、误触开通）：证据齐（时间线、未使用记录），走支付渠道申诉，成功率最高。
- **用了大部分时间后中途取消**：条款明确不退部分周期，这条路基本走不通，别浪费精力。
- **扣费价格与约定不符**（首期价直接续成原价且无提醒）：属于「未显著提示」的典型争议，截图账单后向支付渠道与消协渠道同时提。

还没决定买不买的，先看 [会员价格与积分规则.md](会员价格与积分规则.md) 的三档对比；付费后遇到登录、闪退问题在 [常见问题与故障排查.md](常见问题与故障排查.md)。
