## 一、最快路径：一键移除背景

官方帮助文档给 Android 版的快捷路径（2026 年 3 月更新）：

1. 首页选 Create new（新建），从相册挑一张照片；
2. 进 Actions（动作）菜单，选 Remove background（移除背景），背景被自动识别并隐藏 —— 它背后其实是一层蒙版；
3. 打勾确认。

适合主体清晰、背景不太杂乱的照片；边缘抠得不干净就换下面的精细路径。

## 二、精细路径：选区 → 应用为蒙版

1. 新建项目导入照片；
2. 选 Select area（选择区域）→ Tap select（点选），复杂画面可换套索、魔棒或对象选择；
3. 应用选区；
4. 选 Apply as mask（应用为蒙版），主体与背景就此分离。

这条路的好处是选区完全由你控制，多人照片、边缘复杂的主体更稳。选区工具的差异对照见[图层与选区使用方法.md](图层与选区使用方法.md)。

## 三、换背景：素材的五个来源

主体抠出来后，点 Add image（添加图像）放进新背景，可选来源：

| 来源 | 说明 |
| --- | --- |
| 添加照片 | 从设备相册取图 |
| Adobe Stock | 官方素材库的免费内容 |
| 拍照 | 现场用相机拍一张 |
| Lightroom | 从 Lightroom 目录取图 |
| 浏览（Browse） | 从设备文件里选 |

放进来后用 Layer properties > Transform 调整新背景的大小、旋转与位置。想把背景直接换成 AI 生成的画面，就选 Generate background（生成背景）按描述生成，这属于生成式功能，额度口径见[生成式填充与AI修图.md](生成式填充与AI修图.md)。

## 四、把新背景垫到底层

图层面板里**长按新背景图层，拖到带蒙版的主体层下方**，它才会以背景身份显示。面板里长按拖动就是调整图层顺序的方法，图层各项操作的完整说明在[图层与选区使用方法.md](图层与选区使用方法.md)。

## 五、融不进去时用 Harmonize

换完背景最常见的破绽是光线对不上。Actions 菜单里选 Harmonize，它会按新背景调整主体的颜色与光线，还会补投影。官方教程给的微调组合：

1. Select area → subject（主体）；
2. 点 Adjust，加一个调整图层，把剩余的颜色或影调修正限制在主体范围内。

Harmonize 的更多背景与生成式功能的关系见[生成式填充与AI修图.md](生成式填充与AI修图.md)。

## 六、导出

换完照常走分享导出，格式与保存细节见[新手入门与界面操作.md](新手入门与界面操作.md)。想要透明底的主体图：把背景层隐藏后再导出 PNG（以导出结果为准）。
