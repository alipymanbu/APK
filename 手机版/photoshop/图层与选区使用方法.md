## 一、图层体系：和桌面版同一套思路

手机版保留了桌面版 Photoshop 最核心的图层体系：每个素材、每笔绘画、每次调整都可以单独占一层，层与层之间可叠、可遮、可调顺序。用过桌面版的话经验可以直接迁移；没接触过的话，记住一条就够：**改动只作用于当前选中的图层**。

## 二、图层属性（Layer properties）逐项看

| 属性 | 作用 |
| --- | --- |
| 混合与不透明度（Blend & opacity） | 混合模式决定当前层与下方层的像素如何相互作用，变色、明暗这类效果都靠它；不透明度控制当前层的可见程度，100% 完全可见、0% 完全透明 |
| 修改蒙版（Modify mask） | 调整图层蒙版的属性，控制图层哪些部分显出来 |
| 变换（Transform） | 缩放、旋转、斜切、扭曲、透视 |
| 其他操作 | 删除、锁定、复制、显示/隐藏、上移一层、下移一层、剪贴（clip） |

复制图层后再改，是最稳的保险做法；锁定可以防止误触改到已经调好的层。重排顺序在图层面板里**长按拖动**即可（紧凑面板同样支持）—— 换背景这类多素材项目里，把新背景垫到蒙版层下方是高频操作，完整步骤见[抠图换背景实操步骤.md](抠图换背景实操步骤.md)。

## 三、图层样式（Layer styles）

在 Tools 工作区进入 Layer properties → Layer styles，Android 版可用的样式：

| 样式 | 效果 |
| --- | --- |
| 描边（Stroke） | 沿对象轮廓描一圈颜色 |
| 投影（Drop shadow） | 在图层内容后方加落影 |
| 颜色叠加（Color overlay） | 用纯色填充内容 |
| 外发光（Outer glow） | 从外边缘向外发散光晕 |
| 斜面和浮雕（Bevel and emboss） | 用高光与阴影模拟立体感 |
| 内阴影（Inner shadow） | 在内容边缘内侧加凹陷阴影 |
| 内发光（Inner glow） | 从内边缘向内发散光晕 |
| 图案叠加（Pattern overlay） | 给图层铺一层重复图案做质感 |
| 光泽（Satin） | 内部柔和的明暗起伏，做丝绒质感 |

选定样式后调大小、颜色、不透明度，打勾确认生效。

## 四、八种选区工具怎么选

| 工具 | 适合场景 |
| --- | --- |
| 点选（Tap select） | 点一下就选中一个对象或区域，最快的「选中然后删掉/替换」路径 |
| 快速选择画笔（Quick select brush） | 涂抹式扩大选区，适合边缘不规则的主体 |
| 套索（Lasso） | 徒手画出任意形状的选区 |
| 矩形 / 椭圆 | 规则几何选区 |
| 魔棒（Magic wand） | 按颜色相似度选取，纯色背景抠图 |
| 对象选择（Object select） | 自动识别画面里的对象再选 |
| 画笔（Brush） | 像画画一样精细涂出选区 |

官方的 iPhone/Android 功能对照里，iPhone 的 Quick select 与 Brush select 在 Android 上分别对应快速选择画笔与画笔，能力一致，只是叫法不同。

## 五、选区 + 蒙版 = 局部调整

标准组合：先用选区工具框出目标区域，再在图层属性里创建蒙版 —— 之后的调色、加效果都只落在选区内，画面其余部分不受影响。生成式填充也建立在选区之上，实操见[生成式填充与AI修图.md](生成式填充与AI修图.md)。

调色类改动建议挂在调整图层上，再用蒙版收范围；具体调整项在[修图调色工具详解.md](修图调色工具详解.md)，工具入口不熟的话回[新手入门与界面操作.md](新手入门与界面操作.md)。
