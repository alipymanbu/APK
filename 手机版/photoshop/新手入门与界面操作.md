## 一、打开后的首页

登录账号后先看到首页，这里放着你的最近作品，也是所有新项目的起点：

| 区块 | 作用 |
| --- | --- |
| 最近作品 | 列出你编辑过的项目，点开继续改 |
| 从相册选图 | 选一张设备里的照片开始编辑 |
| 新建空白画布 | 自定义尺寸，从零开始画 |
| Adobe Stock | 从 Adobe 官方素材库选指定尺寸的图 |
| Learn（学习） | 分 Must know（核心概念）、How-to（分步教程）、Made with Photoshop（创作者案例）三栏 |

刚上手建议先把 Learn 里的 Must know 过一遍 —— 官方把图层、选区这些核心概念做成了手机上的短教程。

## 二、新建项目的几种来源

点 Create new（新建）后可以选择素材来源：

- **空白画布**：自定义尺寸；
- **添加照片**：从相册导入；
- **拍摄**：直接调相机拍一张；
- **Adobe Stock**：官方素材库；
- **浏览（Browse）**：从设备文件里选图。

应用还带文生图能力（Generate image，输入文字描述生成图片），入口与开放程度随版本更新变化，以你应用内实际显示为准。另外首页与菜单里还有 Actions（动作）这类快捷入口，一键抠图换背景的完整路径拆到[抠图换背景实操步骤.md](抠图换背景实操步骤.md)。

## 三、编辑工作区布局

进入编辑后，主要操作集中在屏幕下方与图层入口里：

| 区域 | 内容 |
| --- | --- |
| 选择区域（Select area） | 点选、快速选择画笔、套索、魔棒、对象选择等选区工具 |
| 修图（Retouch） | 污点修复、移除、仿制图章、减淡、加深 |
| 绘画（Paint） | 画笔，可调大小、硬度、不透明度、流量 |
| 尺寸（Size） | 按社交平台比例调整画面比例 |
| 撤销 / 重做 | 撤销或恢复上一步 |
| 分享（Share） | 导出 PNG 或其他格式 |
| 图层属性（Layer properties） | 混合与不透明度、蒙版、变换、锁定、复制、剪贴等 |

省略号菜单里还有三样值得知道：Learn（快速技巧视频）、Report an issue（报告问题）、Settings（设置，含云同步相关选项）。

## 四、几个基本手势与习惯

- 双指缩放、平移画布；修细节前先放大，比在整图上抠准得多；
- 动手前先确认在哪个图层上操作，点错图层是手机修图最常见的返工原因，图层体系见[图层与选区使用方法.md](图层与选区使用方法.md)；
- 拿不准的操作直接试，撤销按钮随时能回来；
- 上手顺序建议：先拿单张照片练去杂物与调色（[修图调色工具详解.md](修图调色工具详解.md)），再练选区与图层，最后试 AI 生成类功能（[生成式填充与AI修图.md](生成式填充与AI修图.md)）；
- 单张照片的简单任务用底部工具就够，多素材合成才需要图层加蒙版的完整流程。

## 五、导出与分享

编辑完成后点分享（Share）按钮导出。基础路径直接出 PNG；分享面板里的 Advanced Export（高级导出）可选 PNG、JPEG、PSD、TIFF 等格式，还能指定文件大小与格式选项 —— 这是官方帮助文档 2026 年 2 月的口径，你设备上实际提供哪些以应用内显示为准。发社交平台之前，先用 Size 工具把比例调成对应平台的规格，省得上传后再被裁。导出文件的保存位置以应用内分享面板的提示为准。

关于 PSD 要多说一句：官方新闻稿把「打开并编辑任意 Photoshop 文档（PSD）」的完整格式支持列为付费计划（Photoshop Mobile and Web 计划）的能力，高级导出能不能直接出 PSD 随版本与订阅状态不同 —— 两边口径以你打开应用那一刻的实际显示为准，别照搬文章。
