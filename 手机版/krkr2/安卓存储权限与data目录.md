# Kirikiroid2（krkr2）安卓存储权限与data目录

> 本篇解决「krkr2 里看不到游戏文件」：权限开关在哪、安卓 11~16 对 `Android/data` 目录的限制、怎么用文件管理器把游戏搬进模拟器能读到的位置。

## 一、先对症：你是哪种「看不到」

| 症状 | 原因 | 去哪节 |
| --- | --- | --- |
| 模拟器里整个列表空白 | 存储权限没给 | 第二节 |
| 能看到别的文件夹，唯独找不到你放游戏的目录 | 你放的位置被系统限制（如 `Android/data`） | 第三、四节 |
| SD 卡里的游戏看不见 / 打不开 | 机型对 SD 卡读取不稳定 | 第五节 |

## 二、把权限给够

权限分两级，逐级检查：

1. **文件与媒体**：长按 krkr2 图标 → 应用信息 → 权限 → 允许「文件与媒体」。
2. **管理所有文件**：安卓 11 及以上，很多机型要再打开「管理所有文件」这个总开关（设置 → 应用 → krkr2 → 权限，或 设置 → 应用 → 特殊应用权限 → 所有文件访问权限）。只给第一级、不给第二级，是「列表空白」的常见原因。

给了权限还空白，重启一次手机再试。

## 三、为什么 Android/data 进不去

从安卓 11 起，系统逐步收紧对 `内部存储/Android/data` 的访问；到安卓 13/14/15/16，大多数文件管理器打开这个目录只会得到「拒绝访问」或一片空白。这是系统层面的限制，不是手机坏了，也不是 krkr2 出了问题。

krkr2 在权限不足时的替代方案是读自己的专属目录——这个目录恰好也在 `Android/data` 下面，所以你需要在文件管理器里先解决「进得去」的问题：

```text
/storage/emulated/0/Android/data/org.github.krkr2/files/
```

网上旧教程写的是 `Android/data/org.tvp.kirikiri2/files/`，那是另一种打包版的包名。规律是 `Android/data/<模拟器包名>/files/`，你装的是哪个包名就换成哪个。

## 四、用 MT 管理器搬游戏文件夹

普通文件管理器进不去 `Android/data` 时，用 MT 管理器（2.14.3 及以上版本）：

1. 打开 MT 管理器，进入 `内部存储/Android/data`。
2. 弹出系统授权窗口时按提示**同意 / 使用此文件夹**——这是安卓官方的目录授权弹窗，同意后 MT 就能长期读写该目录。
3. 找到 `org.github.krkr2/files/`，把整个游戏文件夹**移动或粘贴**到这里。
4. 打开 krkr2，在内置文件浏览器里切换到上面这个路径，进入游戏文件夹点 `data.xp3`。
5. 以后所有游戏都可以照此放进这个目录，路径固定不用再找。

机型备注：三星 One UI 6.x 及以上对这一套限制更严，MT 授权的成功率明显低；个别机型只能靠电脑连接（ADB）操作，属于极端情况。

## 五、SD 卡与内置存储

- 能放**内置存储**就别放外置 SD 卡：读卡不稳定会表现为「看不到文件」「卡在加载」。
- 游戏已经在外置卡上且读不到：先用文件管理器把游戏文件夹复制到内置存储，再从模拟器里选新位置。
- 放在普通内置存储目录（如 `Download`、自建的游戏目录）则不受 `Android/data` 限制，只要权限给够就能看到。

搬完目录还是报错，回 [常见问题与报错处理.md](常见问题与报错处理.md) 对着现象查表；导入与启动流程本身见 [游戏导入与运行步骤.md](游戏导入与运行步骤.md)。
