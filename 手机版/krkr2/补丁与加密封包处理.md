# Kirikiroid2（krkr2）补丁与加密封包处理

> 本篇解决「点 data.xp3 弹报错」：判断游戏是不是缺补丁、补丁去哪找、放进哪个目录，以及带转换工具的补丁怎么处理。

## 一、什么游戏需要补丁

吉里吉里游戏的资源包（`.xp3`）有的带加密，krkr2 读取时需要这款游戏**对应的补丁文件**才能解开。三种情况对号入座：

| 你的资源 | 需要额外操作吗 |
| --- | --- |
| 标注「krkr2 版 / Kirikiroid2 版」，目录里有 `patch.xp3` | 不用，补丁已随包带上，游戏会自动读 |
| 社区所说的「高压版」封包 | 一般无加密，直接点开即可 |
| 普通日文原版 / 汉化版，点开就报错 | 大概率缺补丁，按下面流程补 |

前提别忘：游戏本体应是你合法获得的那一份，补丁只是让它在 krkr2 上跑起来。

## 二、去哪找补丁

社区维护着一份按游戏名整理的补丁列表（Kirikiroid2 补丁铺，属于开源项目 zeas2/Kirikiroid2 的配套页面）：

- 补丁列表：[https://zeas2.github.io/Kirikiroid2_patch/patch/](https://zeas2.github.io/Kirikiroid2_patch/patch/)
- 项目仓库：[https://github.com/zeas2/Kirikiroid2](https://github.com/zeas2/Kirikiroid2)

用法：在列表里按**游戏名**搜索，命中后点 GET 下载。没命中也可以先试下一步，只是有失败概率。以上地址截至本文检索时可用，若失效就以 GitHub 搜 Kirikiroid2 顺藤摸瓜为准。

## 三、补丁放进哪个目录

补丁解压后通常是 `xp3filter.tjs` 和 `patch.tjs` 两个文件（有的资源给的是 `patch.xp3`）：

1. 把这些文件**全部复制到游戏的根目录**——就是 `data.xp3` 所在的那个文件夹，与 `.xp3` 文件同级。
2. 重新打开 krkr2，点 `data.xp3` 启动。
3. krkr2 启动游戏时会自动执行目录里的 `patch.tjs` / `xp3filter.tjs`，不需要你手动选它们。

放错了层级（比如放进了上层文件夹或子文件夹）是「放了补丁还报错」的第一原因。

## 四、补丁里带 krz_xp3conv.exe 的怎么办

有些游戏的补丁（尤其是 KirikiriZ 引擎做的游戏）除了 `.tjs` 文件还带一个 `krz_xp3conv.exe`。这个 exe 是给**电脑**用的转换工具，流程变成两步：

1. 把补丁和游戏放在**电脑**的同一个游戏目录里，双击运行 `krz_xp3conv.exe`，等控制台出现「按任意键继续……」之类的完成提示，说明包已转换 / 解密完成；
2. 把处理完的整个游戏文件夹再复制到手机里，按常规方法启动。

没有这个 exe 的补丁就直接跳过这一步，按第三节放文件即可。

## 五、「更新 patch.tjs」报错

游戏运行中弹出与 `patch.tjs` 更新相关的报错：回第二节的补丁列表，重新下载这款游戏最新的 `patch.tjs`，覆盖游戏根目录里的旧文件再启动。

## 六、放完补丁还报错

按经验，报错九成以上是游戏文件本身损坏（下载不完整、解压中断），而不是补丁问题：

1. 重新解压一遍游戏压缩包；
2. 确认没有用网盘的在线解压（容易残缺）；
3. 换一份资源对照；
4. 流程性的排查顺序见 [常见问题与报错处理.md](常见问题与报错处理.md)，解压环节的坑见 [游戏导入与运行步骤.md](游戏导入与运行步骤.md)。
