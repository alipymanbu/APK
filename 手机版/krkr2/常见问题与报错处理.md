## 一、按现象查表

| 现象 | 优先处理 |
| --- | --- |
| 内置浏览器一片空白，看不到游戏文件夹 | 给存储权限；安卓 11+ 移到 `Android/data` 目录，见第二节与 [安卓存储权限与data目录.md](安卓存储权限与data目录.md) |
| 点 `data.xp3` 弹报错 | 游戏缺对应补丁，见第三节与 [补丁与加密封包处理.md](补丁与加密封包处理.md) |
| 长时间停在加载界面 | 重启手机；把游戏移到内置存储 |
| 游戏中黑屏 / 花屏 / 贴图错乱 | 全局设置里切换渲染器，见 [画面与性能设置.md](画面与性能设置.md) |
| 文字底部被裁一行 | 换字体或强制默认字体，见 [画面与性能设置.md](画面与性能设置.md) |
| 存档消失 | 多是清理软件删了缩略图，见 [存档与全CG存档替换.md](存档与全CG存档替换.md) |
| SD 卡里的游戏打不开 | 移到内置存储再试 |
| 打开就闪退 | 清后台重进；确认游戏是 krkr 引擎；重装模拟器 |
| 提示「SDK 版本较低」 | 正常现象，直接忽略 |

## 二、看不到游戏文件（权限与目录）

1. 长按 krkr2 图标 → 应用信息 → 权限，允许「文件与媒体」；安卓 11 及以上把「管理所有文件」打开。
2. 权限已给仍看不到：把整个游戏文件夹移到 `内部存储/Android/data/org.github.krkr2/files/` 下，再到模拟器里切到这个路径找。网上教程写 `org.tvp.kirikiri2` 的，那是另一种打包版的包名，换成你实际安装的这个。
3. 安卓 13/14 对 `Android/data` 目录限制更严，普通文件管理器可能进不去，用 MT 管理器这类支持该目录跳转的工具操作。

这两条的系统层原因与 MT 管理器的完整搬移步骤，展开见 [安卓存储权限与data目录.md](安卓存储权限与data目录.md)。

## 三、点 data.xp3 报错（缺补丁）

报错最常见的原因是游戏的 xp3 包带加密，需要**这款游戏对应的补丁文件**才能正常读取：

- 标注「krkr2 版 / Kirikiroid2 版」的资源一般已带补丁（目录里常见 `patch.xp3`），不用额外处理；
- 没带的话，按游戏名去社区整理的 Kirikiroid2 补丁仓库（GitHub 上搜 Kirikiroid2 能找到）找对应补丁，把 `xp3filter.tjs`、`patch.tjs` 等文件放进游戏目录再启动；
- 社区所说的「高压版」封包一般无加密，通常可以直接点开；
- 补丁放好后重新点 `data.xp3`。

游戏文件本身损坏（下载不完整、解压失败）也会报同样的错：先重新解压一遍再下结论。补丁的来源、放置位置与带转换工具的补丁处理，展开见 [补丁与加密封包处理.md](补丁与加密封包处理.md)。

## 四、游戏中途报错，按这个顺序试

1. 全局设置里切换渲染器（OpenGL ↔ 软件渲染）；
2. 勾选强制使用默认字体；
3. 临时把 `patch.xp3` 移出游戏目录，跳过报错点存一个档，再把补丁移回来读档；
4. 临时把 `savedata` 文件夹改名，测试问题是否与存档有关；
5. 重新解压游戏；
6. 换一份游戏资源对照。

## 五、还是解决不了

- 确认游戏确实是吉里吉里引擎（目录里有 `.xp3` 文件）；
- 到 Kirikiroid2 的 GitHub 仓库 issue 区、相关游戏社区，按「游戏名 + 报错内容」搜，同款游戏多半有人踩过同样的坑；
- 安装阶段的问题回 [下载与安装教程.md](下载与安装教程.md) 核对步骤，导入阶段的坑回 [游戏导入与运行步骤.md](游戏导入与运行步骤.md)。
