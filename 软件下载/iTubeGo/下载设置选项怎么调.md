## 一、下载弹窗里的三个开关

每次点红色下载按钮，弹窗底部都有三个开关，它们会记住你上次的选择，所以**设一次就够**：

| 开关 | 打开后 | 什么时候该开 |
|---|---|---|
| WiFi download only | 只在连着 WiFi 时才真正开始下载，用流量时任务挂着不动 | 流量有限、常下大体积视频时 |
| Download on startup | 下次打开应用自动恢复没下完的任务 | 想让昨天断掉的下载自己接着跑 |
| Download Limit | 限制一次入队的下载数量 | 批量下播放列表时只想要前若干条 |

注意一个组合坑：**「仅 WiFi」开着 + 此刻用流量 = 任务一直停着不动**。看起来像下载失败，其实是没连 WiFi。遇到任务不动先查这个开关，再查网络（排查见 [常见问题与故障排查.md](常见问题与故障排查.md)）。

## 二、存到 SD 卡还是手机内存

应用支持把下载目的地改到外部 SD 卡，给手机内部存储腾空间。在设置里把下载路径指向 SD 卡即可，之后新下载的文件都落过去；已下完的文件不会自动搬家，要腾空间就到 `Files` 区重新安排。没有 SD 卡的手机跳过这节，文件继续留在应用目录里，从 `Files` 区进照样能看能播。

改完路径后建议先下一小条视频验证落点对了，再开始批量任务。

## 三、主页站点图标自己加

主页预加载的站点有限，你可以把常去的站加进去：

1. 在主页「Other Sites」区域点 **Add**。
2. 填一个你认得出的标题（随便起，比如「我常看的站」）。
3. 粘贴该站的网址，点 **OK**，图标就出现在主页上。

以后下载时直接从这个图标进，省去先开浏览器再输网址的步骤。

## 四、书签：把值得回访的链接存下来

用内置浏览器打开想存的视频页，点右上角 **Bookmark**，确认标题和网址后点 `OK` 即可收进书签。下次从书签直接进、直接下 —— 比重新搜一遍快。它的定位是「收藏入口」，不是下载记录；下载记录在 `Files` 区。

## 五、检查更新与注册

**检查更新**：点左上角三横线菜单 → **Check for updates**。已经是最新版会直接告诉你「已是最新」；有新版则给出安装入口。网盘里这份是 2.6.4（见 [下载与安装教程.md](下载与安装教程.md)），装完想升到别处的版本就走这里。

**注册**：免费版的下载次数是有限制的（官方指南原话：free trial 版本有下载数量限制）。如果你有序列号，进左上角菜单 → **Register**，填注册邮箱 + license code 后点 `Register`。两条实操建议：

- 邮箱和码**直接复制粘贴**，手打容易错一个字符就提示无效；
- 码无效的常见原因按顺序排查：还没收到邮件（下单后码不是立刻生效）、码用错了产品、码过期、邮箱与码不匹配。自己排查不明白就发邮件到 [contact@itubego.com](mailto:contact@itubego.com)（官方支持邮箱），附上注册窗口截图。

没有序列号就点注册窗口里的「Have not ordered?」跳去官网购买页 —— 价格与授权政策以官网当时显示为准。

## 六、后台下载别被系统杀掉

下载中切出应用是它的正常工作方式（支持后台下载），但不少安卓系统会回收后台应用，任务会因此中断。两条措施：

1. 系统设置里把这个应用的省电策略改成「无限制」（小米：设置 → 省电与电池 → 应用智能省电；其他品牌路径类似）；
2. 即使被杀，`Download on startup` 开着的话，下次打开应用会自动接着下。

若任务反复断，转到 [常见问题与故障排查.md](常见问题与故障排查.md) 逐条排。
