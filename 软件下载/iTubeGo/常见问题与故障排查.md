## 一、下载失败：官方给的四条排查

按官方支持中心给的顺序自查，覆盖大多数「点了没反应 / 一直失败」的情况：

1. **网络本身通不通**。先用手机浏览器随便开个网页确认网络正常 —— 不是所有「下载失败」都出在应用上。
2. **复制的 URL 对不对**。链接常因为多复制了一个参数、或复制到分享短链而残缺，重新从视频页复制一次再试。
3. **这条视频本身是否可下**。私享/会员专属、加了访问保护的视频解析不了；同时确认这个站点在支持范围内（清单见 [支持哪些网站与输出格式.md](支持哪些网站与输出格式.md)）。
4. **换一种送链接的方式**。内置浏览器直接下、复制链接自动识别、从别的 App 分享进来 —— 三种方式的解析路径不完全一样，这条不行换那条（操作见 [视频与音乐怎么下载.md](视频与音乐怎么下载.md)）。

四条都试过仍失败，把应用的运行日志发给官方：菜单里进 Help → Open Log Folder，把打开的 Log 文件夹压缩后发到 [contact@itubego.com](mailto:contact@itubego.com)。

## 二、Facebook 视频下载失败的专项处理

Facebook 是官方单独列过处理步骤的一个，因为它需要登录态：

1. 下载失败时会弹提示，点提示里的链接，应用会用**内置浏览器**打开这条视频。
2. 如果你从没在内置浏览器里登录过 Facebook，先登录你的账号。
3. 登录成功后视频页右下角会出现下载按钮，点它。
4. 回到 `Download` 区确认任务起来了。

本质原因：不登录就看不到可解析的媒体流。登录只发生在应用内置浏览器里，不需要把 Facebook 密码填到别处。

## 三、安装阶段的问题

| 现象 | 原因 | 动作 |
|---|---|---|
| 弹「不允许安装未知来源应用」 | 系统默认拦第三方来源 | 跟随提示进设置，允许这一次来源，返回安装 |
| 弹「应用未安装」 | 存储空间不足 | 清出至少两倍安装包体积的空间再装 |
| 弹「解析包时出现问题」 | apk 损坏 | 核对 MD5（命令在 [下载与安装教程.md](下载与安装教程.md)），不符就重新下载 |
| Play Protect 弹「已阻止安装」 | 商店对非商店来源的例行拦截 | 核对 MD5 无误后点「仍然安装」 |
| 「安装未知应用」菜单点不动 / 置灰 | 三星等品牌的「自动拦截器」类安全设置在拦 | 进 设置 → 安全和隐私 临时关掉自动拦截器再试 |

「未知来源」权限在安卓 8.0 后是**按来源应用单独授权**的（用哪个应用打开 apk 就给哪个授权），详细路径与装完如何收回权限见 [下载与安装教程.md](下载与安装教程.md)。

## 四、任务一直不动 / 中断

- **先看「仅 WiFi」开关**：开着而你正用流量，任务就停着等 WiFi，不是故障（开关位置见 [下载设置选项怎么调.md](下载设置选项怎么调.md)）。
- **再看是不是被系统杀了后台**：切走后过一会儿回来任务没了进度 —— 给应用设「无限制」省电策略，并确保 `Download on startup` 开着。
- **网络在下载途中断过**：到 `Download` 区手动恢复；恢复不了就停掉重下这一条，已下完的其他条目不受影响。
- **换了网络后突然全部失败**：先用第一条的「网络通不通」验证新网络 —— 部分公司/学校网络会限制这类连接。

## 五、装好了但打不开 / 闪退

1. 确认系统版本：这个包要求安卓 5.2 及以上（版本信息见 [下载与安装教程.md](下载与安装教程.md)）。
2. 确认 apk 没装残：MD5 对不上的包装出来可能启动即崩 —— 卸载干净，重新从网盘拿一份装。
3. 存储权限没给时部分功能会异常，进系统设置 → 应用 → iTubeGo → 权限，把存储权限打开。

## 六、还查不出去哪问

官方支持中心（[itubego.com/support](https://itubego.com/support/)）有 FAQ，客服邮箱 [contact@itubego.com](mailto:contact@itubego.com)。求助时带上三样东西：手机型号与安卓版本、失败的那条视频的链接、出错提示的截图 —— 少一样往返一次。
