## 一、先认清这个包是哪一版

iTubeGo 是 iTubeGo Studio 出品的安卓视频 / 音频下载工具，官网在 [itubego.com](https://itubego.com/zh-cn/)（有桌面版，见 [支持哪些网站与输出格式.md](支持哪些网站与输出格式.md)）。你手上这份安装包的信息如下，装之前先对一遍：

| 项目 | 数值 |
|---|---|
| 版本号 | 2.6.4 |
| 包名 | `com.luckydogsoft.itubego` |
| 安装包大小 | 29.82M |
| MD5 | `06ABC5F3C91BA0F420FA04AE642E8811` |
| 最低系统要求 | 安卓 5.2 及以上 |
| 记录时间 | 2026-09-24 |

两点提醒：

- **版本号会随时间往前走**。网上搜到的、官网下载页给的可能是更新的一版，而网盘里存的是 2.6.4 这一版 —— 涉及版本号、体积、包名，一律以上表为准。
- **包名决定了它会不会覆盖你手机里已有的同类应用**。iTubeGo 在 Google Play 上架那一版的包名是 `com.ld.videodownload`，与这里的 `com.luckydogsoft.itubego` 不同，两版签名也不同，装在一起互不覆盖，可以同时存在。

## 二、从网盘拿到安装包并装上

1. 打开 [iTubeGo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/208a5f1914c6)，把整个文件夹转存到你自己的夸克网盘（需要夸克账号）。
2. 在手机上打开夸克网盘，找到 `iTubeGo_v2.6.4.apk`，点它。
3. 系统会弹「不允许安装未知来源应用」（或「安装被阻止」）—— 跟随提示跳到设置，允许这一个来源的安装，再返回点安装。
4. 装完打开。首次进入是主界面：上面是网址栏与内置浏览器，下面预加载了 YouTube 等常用站点图标，不需要先登录账号。

如果你是在电脑上下载再传到手机，核对 MD5 可在 Windows 上执行：

```powershell
certutil -hashfile "iTubeGo_v2.6.4.apk" MD5
```

输出应与表里的 `06ABC5F3C91BA0F420FA04AE642E8811` 一致（大小写不敏感）。对不上说明包在传输中损坏了，重新下一份再装。

## 三、装不上的三种情况，先对号入座

- **提示「应用未安装」**：多半是手机存储不够。安装时系统要解包，可用空间至少留出安装包体积的两倍（这里约 60MB 以上），清完再装。
- **提示「解析包时出现问题」**：apk 文件本身损坏或没下完整 —— 重新下载，或换台设备试；先用上面的 MD5 命令确认文件完整。
- **系统版本过低**：这个包要求安卓 5.2 及以上，系统低于它会直接拒绝安装。

还有一种是被 Google Play Protect 拦下（弹「已阻止安装」）：安装来源不是商店时它常会误报，点详情里的「仍然安装」即可；不放心就先用上面的 MD5 命令确认文件没被动过。其余疑难见 [常见问题与故障排查.md](常见问题与故障排查.md)。

### 「未知来源」权限是按来源应用单独给的

安卓 8.0 起，这个权限不再是全局一个开关，而是**谁打开 apk、就给谁授权** —— 你用夸克网盘下载并点开 apk，要授权的是夸克；换用文件管理器打开，又要给文件管理器单独授一次。手动路径：设置 → 应用 → 特殊应用权限 → 安装未知应用 → 选中那个来源应用 → 打开「允许来自此来源」。三星手机入口略有不同：设置 → 安全和隐私 → 更多安全设置 → 安装未知应用。

两个补充：

- **三星的「自动拦截器」（Auto Blocker）会额外拦一道**，并可能让上面那个授权菜单直接置灰 —— 装不上先去 设置 → 安全和隐私 里把它临时关掉，装完再开。
- 装完这一单后，可以回到该来源把权限关掉，下次要装再开 —— 不影响已装好的应用。

## 四、装完先确认这几件事

这几项不影响打开应用，但决定了你第一次下载能不能成：

- **存储权限**：第一次点下载按钮时会弹权限请求。拒绝了文件存不进去、下载直接失败 —— 想下载就允许。
- **要不要允许它后台跑**：下载中切到别的应用是正常的（后台下载是它的设计），但系统省电策略可能把它回收导致任务中断。在意的话，在系统设置里把这个应用的省电策略改成「无限制」（不同品牌路径不同，小米在「设置 → 省电与电池 → 应用智能省电」）。
- **下载路径默认在应用私有目录**：文件都收在应用内的「Files」区里，想存到 SD 卡省空间，见 [下载设置选项怎么调.md](下载设置选项怎么调.md)。

装好后从哪开始：直接看 [视频与音乐怎么下载.md](视频与音乐怎么下载.md)，三种把链接送进应用的方式都在那里。
