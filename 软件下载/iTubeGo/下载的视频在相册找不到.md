# 下载的视频在相册找不到

> 下载明明完成了，相册里却刷不出来 —— 先确认文件在不在，再按顺序把相册那边修通。

## 一、先分清是「没下成」还是「相册没显示」

这两个症状看起来一样，处理方向完全相反，所以先做一步确认：

**打开 iTubeGo 的 `Files` 区，找那条文件**。

- **Files 里有** → 下载成功了，问题出在相册那一侧，走第二节往下排。
- **Files 里也没有** → 下载根本没完成，回 [常见问题与故障排查.md](常见问题与故障排查.md) 第一节按四步排查。

`Files` 区是应用内查看已下载文件的入口，支持搜索、播放、排序、删除 —— 它是判断「文件到底在不在」的权威位置，相册不是。

## 二、Files 里有但相册没有：四个按顺序试的动作

第三方应用存进来的视频不会自动出现在相册里，这是安卓的媒体扫描机制决定的常见现象（多个手机厂商的支持文档都单独立过这个问题）。按成本从低到高试：

1. **换相册视图再看**。不少相册默认停在「最近」或按月份分组，切到「所有照片 / 图集 → 所有照片」按时间翻一遍 —— 新保存的排在最前。
2. **用文件管理器确认文件位置**。打开手机自带的文件管理，按修改时间找，或直接看 `Movies`、`Download`、`iTubeGo` 这几个常见落点。**如果你在下载设置里把路径改到了 SD 卡**（见 [下载设置选项怎么调.md](下载设置选项怎么调.md)），去 SD 卡对应目录找，相册对 SD 卡上的媒体同样要扫描。
3. **重启手机让相册重新扫描**。媒体库有时不会即时刷新，重启是最省事的触发方式。
4. **查相册有没有把它藏起来**。部分品牌有「私密保险箱 / 隐藏照片」功能，被移进去的视频在普通相册里不显示 —— 进设置 → 隐私里翻一下。

## 三、都不行：让相册重建索引

以 realme / OPPO 系为例（其他品牌路径类似）：长按相册应用 → 应用详情 → 存储占用 → 清除数据，之后相册会重新扫描全部媒体。**这一步不会删除照片原文件，但收藏、排序等相册自身的记录会丢** —— 相册里有重要整理记录的话先跳过这步。

## 四、文件始终只在应用里怎么办

如果你在文件管理器里怎么都找不到那个文件，而 `Files` 区里能正常播放 —— 说明它存在应用自己的私有目录里（下载路径没改过时就是默认状态）。这种文件系统层面接触不到，只能在 iTubeGo 内部使用：播放、删除都在 `Files` 区做。想把它挪到相册可见的位置，办法是在下载前就把保存路径设成 SD 卡或公共目录（见 [下载设置选项怎么调.md](下载设置选项怎么调.md)）—— **路径在下载那一刻定死，已下完的文件不能在应用内改道**，需要的话重新下一次（参数怎么选见 [视频与音乐怎么下载.md](视频与音乐怎么下载.md)）。
