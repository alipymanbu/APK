## 一、站点范围：官网上写的数字，和实际能下的

官方安卓版页面宣称支持 1000+（官网另一处写 10000+）个站点 —— 两个数字都在官网出现过，说明他们计数口径不一，**你只该关心具体站名**。官方页面明确列出的站点包括：

| 类别 | 站点 |
|---|---|
| 综合视频 | YouTube、Dailymotion、Vimeo、TikTok |
| 社交平台 | Facebook、Instagram、Twitter、VK |
| 音乐音频 | SoundCloud、MixCloud、Vevo、Bandcamp、niconico |
| 其他 | OK.RU、Coub、U-NEXT |

三条实际使用规律：

- **YouTube 仅 APK 版支持**。官方下载页明确注明这一条：Google Play 上架那一版不含 YouTube 下载（受商店政策限制），官网 APK 与网盘里这份才有。所以别拿 Play 版试 YouTube，失败不是你操作的问题。
- **未列出的站不代表不能下** —— 智能链接检测认得媒体流就能解析，站点清单只是「官方背书过」的部分。判定某站行不行，最快的办法是实际送一次链接（三种方式见 [视频与音乐怎么下载.md](视频与音乐怎么下载.md)）。
- **站点本身改版 / 加防护会导致解析失效**，这是常态。失效时按 [常见问题与故障排查.md](常见问题与故障排查.md) 第一节的四步排。

## 二、输出规格对照表

**视频**（Type 选 Video）：

| 档位 | 说明 |
|---|---|
| 360p / 720p | 标清、高清，体积小，适合手机上看 |
| 1080p | 全高清，多数视频的默认选择 |
| 1440p / 2160p | 2K 与 4K —— **仅当源视频本身有该分辨率时可选**，弹窗里没列出就是源站没有 |

**音频**（Type 选 Audio）：

| 档位 | 说明 |
|---|---|
| 70kbps | 体积最小，语音类内容够用 |
| 128kbps | 常规音质，听歌的性价比档 |
| 320kbps | 最高档，当铃声、存有声书选它 |

**输出格式**：视频存 MP4，音频存 MP3、AAC、M4A。下载时先转换再落盘，转换在 `Download` 区可见。音频的 ID3 标签（标题、封面、艺术家、专辑等）会随文件保留，所以下载的歌进音乐播放器后歌名、封面通常不用手动补。

## 三、手机版和桌面版别搞混

iTubeGo 同时有安卓版和 Windows / macOS 版，官网首页给的功能说明有相当一部分是**桌面版**的，照着在手机上找会找不到：

| 能力 | 安卓版（本篇这份） | 桌面版 |
|---|---|---|
| 分辨率 | 官方安卓页列到 2160p（4K） | 官网标 8K |
| 站点数量宣称 | 1000+ | 10000+ |
| 字幕下载 | 官方安卓页未列 | 官网标注支持（含 SRT 导出） |
| 视频剪辑 | 未列 | 官网标注内置剪辑 |

判断某功能手机版有没有，以**安卓版页面与应用内实际选项**为准，不以官网首页为准（首页主推桌面版）。桌面版是独立的安装包与独立授权，和这里的安卓 apk 无关。

## 四、格式选错了怎么补

`Files` 区里已下好的文件**不能在应用内改格式** —— 格式在下载那一刻就定死了。要换格式只能重新下一次：点开那条视频重新走下载流程，在弹窗里改 Type / Quality（步骤见 [视频与音乐怎么下载.md](视频与音乐怎么下载.md)）。所以下大批量之前，先下一两条把档位试对，再全选下（见 [下载设置选项怎么调.md](下载设置选项怎么调.md)）。
