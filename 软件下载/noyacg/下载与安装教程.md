## 一、这是个什么应用

NoyAcg 是一个安卓端的 ACG 内容应用，漫画阅读是其中最常用的部分，另有社区讨论区。它主要通过官网与各类分享页面分发安装包，第一次打开就要注册账号才能正常使用。

| --- | --- |
| 版本 | 2.4.9 |
| 包名 | `asia.noy.now` |
| 安装包大小 | 21.73M |
| MD5 | `9ECCBAC1F9F56D7619A774D7B09BF1D8` |
| 系统要求 | 安卓 5.2 及以上 |
| 信息核对日期 | 2026-09-23 |

网上的下载站往往登记着更新的版本号，那些多半是另一个包（见第四节），两者的大小、MD5 都对不上。你装哪个版本，就按哪个版本的信息判断，别混着比。

## 二、拿到安装包

1. 打开上面的 **NoyAcg 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/75ac3373ae73](https://pan.quark.cn/s/75ac3373ae73)。
2. 把里面的 APK 转存到自己的网盘，或直接下载到手机。
3. 下载完先核对一下：文件名应为 `noyacg_v2.4.9.apk`，大小约 21.73M。对得上就是这份包。

手机浏览器下载的 APK 通常落在「下载」目录里；从网盘 App 里下载的，位置由网盘客户端决定，装之前在文件管理器里找到它即可。

## 三、安装步骤

1. 点开 APK 文件。系统会提示「不允许安装来自此来源的应用」—— 这是安卓对侧载安装的常规拦截，不是这个包有问题。
2. 在提示里进入「设置」，打开**允许来自此来源的应用**（不同厂商的叫法略有差别，有的叫「安装未知应用」）。
3. 返回，点「安装」，等进度走完。
4. 装完先别急着打开，把安装器界面关掉即可。首次打开会停在登录/注册页，接着按 [注册流程与邀请码获取.md](注册流程与邀请码获取.md) 注册账号。

如果安装时提示「解析包时出现问题」或「应用未安装」，一般是下载不完整或与已有版本冲突，处理办法见 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 四、包名差异：`asia.noy.now` 与 `asia.noy.th` 不是同一个包

这是装之前最容易踩的坑。网上能搜到的 NoyAcg 资料里，登记的包名有两种：

| 包名 | 常见版本号 | 与本文这份的关系 |
| --- | --- | --- |
| `asia.noy.now` | 2.4.9 | **本文这份就是它**，网盘里也是它 |
| `asia.noy.th` | 3.1.x / 3.2.x / 3.3.x | 另一个包，版本号更高，大小约 15~18M |

包名不同，对安卓来说就是两个不同的应用：

- **覆盖安装会失败**，或者装完后两个图标并存；
- 账号数据、书架、阅读进度**不保证互通**；
- 两份安装包的 MD5 也完全不同，用校验工具比对时必然对不上。

所以别拿 `asia.noy.th` 的安装包去「升级」`asia.noy.now`。要升级就找同一个包名的新版；找不到同包名的新版，就一直用手上这份，功能上不影响注册与阅读。

判断某个下载页属于哪一支，看它登记的包名就行。第三方下载页把 `https://release.noymanga.com/` 登记为官网，而那个发布页挂的也是 `asia.noy.th`（3.x）那一支 —— 从那儿拿到的包不是本文这份，别混装。同类信息也一样：**包名对不上，其它字段（大小、MD5、更新日志）就都没有可比性**。

顺带说明版本号：`asia.noy.th` 那支的更新日志（如「智能书签」「图片预加载优化」）**不适用于本文这份 2.4.9**，别看到别人截图里有自己找不到的功能就以为装错了。资费与广告的口径同样有分歧，见 [收费与广告情况.md](收费与广告情况.md)。

## 五、卸载与重装

卸载会连带清掉本机缓存的图片与登录状态，书架、收藏、积分这类存在服务器上的数据不受影响，重装登录后照常在。

重装时同样要先卸干净再装，不要在旧版本上直接叠装另一个包名的包 —— 那样会得到两个并存的应用，占空间也容易搞混。装完打不开、闪退或图片空白的处理，见 [常见问题与解决办法.md](常见问题与解决办法.md)。
