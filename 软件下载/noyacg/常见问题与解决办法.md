## 一、先做这三步（多数问题到这就解决了）

1. **换网络**：Wi-Fi 与手机流量互换一次。这个站的服务器链路对网络环境敏感，同一条内容换个网络就正常，是常见现象。
2. **换线路**：应用内切到另一条分流线路再进同一章节，线路选择见 [漫画阅读与线路切换.md](漫画阅读与线路切换.md) 第三节。
3. **只清缓存**：设置 → 应用 → 存储 → **清除缓存**。**不要点「清除数据」** —— 那会把登录状态和本地记录一起清掉，清完得重新登录。

三步都做了还不行，再往下看具体症状。

## 二、安装类

| 症状 | 处理 |
| --- | --- |
| 安装时提示「解析包时出现问题」 | 下载不完整，删掉重下；下完核对大小约 21.73M |
| 提示「应用未安装」 | 旧版本没卸干净，先卸载再装；两个包名并存的先删掉重复的那个 |
| 不允许安装来自此来源 | 系统的侧载拦截，在提示里打开「允许来自此来源的应用」 |
| 装完有两个图标 | 装了不同包名的包（`asia.noy.now` 与 `asia.noy.th`），删掉多余的那个，只留一个 |

包名与版本的差别在 [下载与安装教程.md](下载与安装教程.md) 第四节。

## 三、注册类

- **提示「今日已达注册上限」**：站方的每日注册量上限，等次日零点（间隔 24 小时）再试；急用就换一个没用过的邀请码。
- **提示邀请码无效**：网上流传的码大多已失效，去官网 [www.noy.asia](https://www.noy.asia/) 或官方论坛 [forum.noy.asia](https://forum.noy.asia/) 拿当期的码；较新的版本邀请码可留空。
- **点了注册没反应**：多半是网络到注册接口不通，回到本篇第一节换网络；仍不行就重装一次再试。
- **滑块拖了不通过**：把图块拖到严丝合缝再松手，手抖没对准会直接判失败，多试两次。

字段怎么填、步骤怎么走，见 [注册流程与邀请码获取.md](注册流程与邀请码获取.md)。

## 四、图片不加载 / 整页空白

按命中率排序：

1. **换线路**：图片一格格出或整页空白，通常是当前线路不顺，切线路最直接；
2. **换网络**：Wi-Fi 与流量互换，判断是不是本地网络到该线路不通；
3. **清缓存**：损坏的缓存会让图片反复加载失败，清一次缓存再进；
4. **等一会儿**：某部作品单章图片特别多时，加载慢是常态，先退出该章再进，或换个章节测一下 —— 只有这一部有问题就是这部的资源问题，所有作品都这样才是网络或线路问题。

## 五、白屏、闪退

- v2.4.9 已修复部分场景下的白屏与闪退，先确认自己装的是不是这个版本（见 [下载与安装教程.md](下载与安装教程.md) 的信息表）；
- 闪退集中在某一个动作上时（比如点某类贴文必崩），那是该场景的缺陷，换一条路绕开：不进那个页面、或改用网页端 [www.noy.asia](https://www.noy.asia/) 看同内容；
- 反复在同一处闪退，先清缓存，再卸载重装（**书架、积分在服务器上，重装不丢**，本地缓存会重新拉）；
- 向社区反馈闪退时写清楚「做了什么动作后闪退」，只说「闪退了」没法定位。

## 六、整体打不开、加载特别慢

- **先分清是应用还是网络**：手机流量下打开官网 [www.noy.asia](https://www.noy.asia/) 试试；官网也打不开，是网络到这条链路不通，换网络或稍后再试；
- **App 与网页端互为备份**：App 打不开时网页端常能进，反过来也一样，两条路至少通一条就能继续用；
- **有用户反馈部分网络环境下直连不稳**，这种情况换线路、换网络各试一次就能判断是不是自己这侧的问题 —— 别人能开你不能开，重点在网络环境；所有人都开不了，等站方恢复即可。

## 七、社区与积分异常

- 贴文里图片或楼层缺一块 → 下拉刷新或重进该贴，属渲染问题；
- 积分数目对不上 → 先看积分记录页的流水，再判断，规则说明见 [社区互动与积分说明.md](社区互动与积分说明.md) 第四节；
- 自己发的内容不见了 → 先确认是不是点了自主删除；被站方处理的会在检举后按社区审查规则走，Q&A 入口在社区内。

## 八、其他高频疑问

**iPhone / iPad 能装吗？** 手上这份是安卓 APK（`asia.noy.now`），iPhone 装不了 APK。网上有页面标注「支持系统：安卓 / iOS 11.0」，但那只是**单一下载页的登记**，没有对应的 iOS 安装渠道、也没见到 App Store 链接 —— 按现有信息，iPhone 上直接用网页端 [www.noy.asia](https://www.noy.asia/) 是唯一可靠的路子（账号与 App 通用，见 [漫画阅读与线路切换.md](漫画阅读与线路切换.md) 第四节）。等有官方 iOS 版了，以官网当时显示为准。

**要花钱吗？** 公开资料两种说法并列，装完自己验，见 [收费与广告情况.md](收费与广告情况.md)。

**换了手机，账号和书架还在吗？** 在。数据存在服务器上，新手机装好包（[下载与安装教程.md](下载与安装教程.md)）登录同一邮箱即可；记得选回当初那个服务器分区，见 [注册流程与邀请码获取.md](注册流程与邀请码获取.md) 第五节。
