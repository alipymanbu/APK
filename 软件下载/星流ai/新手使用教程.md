## 一、这是什么、适合谁

星流是 LiblibAI（哩布哩布AI）旗下的 AI 设计工具，官方定位「一站式创意设计 Agent」：你用一句中文描述需求，它拆解任务后生成图片、视频、3D 模型或音频，生成结果放在一块无边画布上继续改。本篇带你走完「登录 → 第一张图 → 存图」的完整流程。**注意：截至 2026-09-26，官网公告星流将于 2026-10-10 24:00 停止服务**，还没迁移的作品要抓紧处理，见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 二、注册与登录

1. 打开 App（安装见 [下载与安装教程.md](下载与安装教程.md)），首次启动先同意隐私政策与用户协议。
2. 在登录页用**手机号**注册/登录，也可以按页面提供的微信、QQ 等方式进入；网页端（[www.xingliu.art](https://www.xingliu.art/)）与手机端是同一套账号，登录一次通用。
3. 登录成功后，新用户通常能拿到一笔赠送积分用于试用。有评测（2025-07）记录过「首次登录 3 次免费体验 + 150 积分、邀请好友再得 200 积分」，赠送额度官方会调整，以你登录后账户里实际显示为准。
4. 遇到「注册不了」「收不到验证码」，先按 [常见问题与解决方法.md](常见问题与解决方法.md) 里的步骤排一遍。

## 三、手机端：生成第一张图

1. 进入创作界面，点输入框。
2. 输入提示词。写法要点：
   - 用**具体描述**代替形容词 —— 「一条大江穿城而过，傍晚灯光，电影感构图」比「好看的风景」出图稳定得多；
   - 多个画面要素用逗号分隔，主体、场景、风格、用途各写一项；
   - 中文即可，不用翻译成英文。
3. 需要特定风格时，先在**模型/模板区**挑一个风格模板再生成（App 内有「如何使用模板进行图片制作」一类的引导入口，选模板 → 套用 → 改提示词 → 生成）。
4. 点**生成**，等渲染完成。系统一般一次给多张候选，点开逐张看。
5. 满意的图可以直接**保存到本地**；想以此为基准继续出图，点**「作为参考」**再写新一轮提示词，让它顺着这张的风格走。

## 四、网页端的四块区域（功能更多）

网页版界面分四块，先认位置再动手：

| 区域 | 位置 | 你能做什么 |
| --- | --- | --- |
| 工具栏 | 左上 | 切换模式、插入画布、上传图片、打开 AI 工具箱 |
| 生成器设置 | 工具栏下方 | 选基础模型、图片/颜色参考、生图尺寸 |
| 画布区 | 中间 | 预览、拖拽、选中图片后用高清放大 / 扩图 / 去背景 / 擦除等工具 |
| 对话区 | 最右侧 | 输入需求与修改指令，让 Agent 干活 |

改图有两种路子：**选中图片按 Tab 进快速编辑**，用一句话改（「把天空改成蓝色」）；或者把要求发给右侧对话区，让它按工作流重做 —— 每次处理会打包成可回溯的工作流，改坏了能回到上一步。

## 五、提示词怎么写效果更稳

- **先给方向再给细节**：Agent 收到模糊需求时会先返回几个优化后的方向让你选，选一个再往下走，比直接抽卡省积分。
- **文字内容写进提示词**：海报上的标题、日期要明确写出（比如「顶部标题『新品上市』，底部日期『1010』」），否则它会自己编词。
- **中文文字有翻车概率**：有实测（2025-07）记录过画面里的中文出现乱码、或被替换成英文的情况，多生成几次或把中文字数减少能提高成功率；反复强调「用中文」不一定立刻生效。
- **一次不满意就换描述**：生成有随机性，同一需求多出 2~3 张再挑，比死磕一张更划算（积分消耗见 [会员价格与积分说明.md](会员价格与积分说明.md)）。

## 六、图片之外：视频、3D、音频

2.0.2.2000 的更新说明是「设计师 Agent」上线，对应三类新能力：

- **一键生成套图**：一句话要一整套物料（主图 + 延展图 + 社媒封面），Agent 自己拆任务；
- **视频随心造**：接入可灵、海螺等视频模型，输入需求后它做分镜、画面、口型、配乐，输出 MP4；
- **3D 模型**：文生 3D / 图生 3D，可导出 GLB；另有定制背景音乐/音效的音频生成。

这些都在功能菜单里选类型后输入需求即可，和生图同一套交互。积分消耗比图片高不少，动手前先看一眼账户余额。
