## 一、这篇讲什么

匹配完成后（流程见 [怎么匹配另一半.md](怎么匹配另一半.md)），你们的专属空间里会多一颗蛋，围绕它的三件事官方页面基本不写：怎么让它快点破壳、贝壳从哪来花到哪去、小屋与奇遇里的入口都藏在哪。本篇把这些一次讲清，日常功能的全貌见 [玩法与日常功能.md](玩法与日常功能.md)。

版本提醒：本仓库安装包为 4.26.3，种田奇遇、上学奇遇等玩法在更新的版本里才出现，4.26.3 里不一定有；下文的入口与数值也可能随版本调整，一律以你应用内的实际显示为准。

## 二、小 Suki 怎么快点破壳

蛋破壳靠两人的互动积累，这些行为都算数：

- 每天上线；
- 完成每日问答；
- 写心情日记；
- 发每日叨叨；
- 做任务（部分任务支持看视频加速）。

有第三方资料称互动量足够时最快约 13 天破壳，实际速度由每天的任务完成量决定——把它当成每天顺手点一遍的事，比攒着一天补完有效。

## 三、贝壳：小屋经济从哪来

小屋里买家具、加房间用的货币是贝壳。来源：

| 来源 | 说明 |
| --- | --- |
| 完成任务 | 主力渠道，日常任务顺手做 |
| 抓娃娃 | 小游戏入口 |
| 日常互动 | 养成与问答过程中产出 |

第三方资料列出的加房间价格是第一层 500、第二层 1500、第三层 3000 贝壳，会随版本调整，以应用内为准。

## 四、小屋与奇遇操作速查

不同版本入口位置有差异，下表供对号入座（以应用内实际显示为准）：

| 想做什么 | 去哪操作 |
| --- | --- |
| 进房产系统 | 两指缩小屏幕，或点右上角小房子图标 |
| 放家具 | 房产系统 → 装修 → 选择家具放置 |
| 移动家具 | 主页长按家具拖动，后移动的在上层 |
| 加房间 | 房产系统 → 建筑 |
| 进奇遇玩法 | 点小 Suki，左上角「奇遇」（有上学奇遇、种田奇遇等） |
| 改自己头像 / 昵称 / 性别 | 主页设置 → 点自己头像 |
| 改小 Suki 的称呼 | 设置 → 「suki称呼」 |
| 换小 Suki 证件照 | 左上角小 Suki 头像 → 最上方证件照 → 更换 |

种田奇遇的流程：匹配后从右侧「种田奇遇」进入种植区，和小 Suki 双人互动合成大萝卜，种出后进入高级玩法区，继续做任务积累足迹点数，向下一处风景出发。

## 五、亲密度怎么看

应用里没有一个直接的数字面板告诉你谁更亲近。有用户总结的经验是：小 Suki 的头像更靠近谁，与谁的亲密度就更高。想让它往谁那边挪，靠的还是问答、日记、小游戏这些每天的实际互动。
