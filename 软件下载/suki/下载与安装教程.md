## 一、装之前先过一遍这四项

Suki 是一款情侣双人互动应用（安卓手机版），两个人各装一份、互相匹配后一起用。装之前确认这四项，能省掉后面大部分麻烦：

| 检查项 | 要求 | 说明 |
| --- | --- | --- |
| 手机系统 | Android 7.0 及以上 | 第三方应用市场对较新版本的标注，供参考；以安装时手机的实际提示为准 |
| 存储空间 | 预留 1 GB 以上 | 安装包约 189.32 MB，安装后占用更大，运行中还会持续产生图片与缓存 |
| 网络 | 全程联网 | 注册、匹配、问答与日记同步都要联网，断网时功能明显受限 |
| 配对对象 | 对方手机也装好 | 核心玩法需要两个人一起用，没有匹配对象时基本没有内容可玩 |

本篇对应的安装包信息如下，装完有疑问时可以拿来核对：

| 项目 | 值 |
| --- | --- |
| 版本 | 4.26.3 |
| 包名 | com.masseffect.suki |
| 安装包大小 | 约 189.32 MB |
| MD5 | EBBAE43718E9244D7B3BAEDC02B8EF2A |

官方更新很频繁，应用商店里显示的最新版本号大概率比上表高。新版本与 4.26.3 在核心玩法上差别不大；想确认官方最新版本，以 [App Store 应用页](https://apps.apple.com/cn/app/id6475341654) 或国内应用商店当时显示为准。

## 二、从网盘把安装包拿到手机

安装包在这里：[Suki 安装文件资源（夸克网盘）](https://pan.quark.cn/s/073edce75b38)。取用流程：

1. 复制链接，用浏览器打开；
2. 登录夸克账号后选择「转存」，把文件存到自己网盘；
3. 在手机夸克 App（或网页版）里找到转存后的文件，下载到手机存储；
4. 下载完成后，通知栏或「下载」目录里会出现一个 `.apk` 文件。

想核对文件是否完整，可以对比下载后的大小（约 189.32 MB），或校验上表中的 MD5。

## 三、安装步骤

1. 在文件管理器里点开下载好的 `.apk` 文件；
2. 系统弹出「允许安装未知应用」提示时，允许当前文件管理器或浏览器安装应用（装完可以再把该权限关掉）；
3. 等待安装进度走完，点「打开」；
4. 首次打开按提示完成注册或登录，然后去匹配另一半，具体见 [怎么匹配另一半.md](怎么匹配另一半.md)。

## 四、装不上时的逐项排查

按出现频率从高到低：

| 现象 | 多半是 | 怎么处理 |
| --- | --- | --- |
| 点 apk 没反应或闪退回桌面 | 文件没下完整 | 删掉重下，核对大小与 MD5 |
| 提示「解析包时出现问题」 | 安装包损坏，或系统版本低于要求 | 重新下载；仍报错则检查 Android 版本 |
| 提示「存储空间不足」 | 剩余空间不够 | 清出 1 GB 以上再装 |
| 提示「应用未安装」且手机上原本装过 Suki | 来源不同的安装包签名信息对不上 | 先卸载旧版再装；卸载前先看 [怎么解绑与换绑.md](怎么解绑与换绑.md) 里的备份建议 |
| 安装中途卡住不动 | 后台占用高或存储写入慢 | 重启手机后重试 |

## 五、苹果手机怎么办

文首这份安装包只适用于安卓。iPhone 用户在 App Store 里搜「Suki」即可，开发者显示为重庆代码循环科技有限公司（[App Store 页面](https://apps.apple.com/cn/app/id6475341654)，名称与版本以商店当时显示为准）。iOS 版与安卓版功能接近，两端账号与配对关系能否互通，以实际登录后的表现为准。
