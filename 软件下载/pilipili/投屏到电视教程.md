## 一、投屏的前提

- 电视 / 盒子 / 投影支持投屏（支持 DLNA 协议的智能电视基本都行，拿不准就问设备厂商）；
- 手机和电视连的是**同一个 Wi-Fi** —— 这是投屏能不能用的第一条件；
- 路由器没开「AP 隔离」和访客模式，中间也没串信号放大器，这几样都会让两台设备互相看不见。

## 二、操作步骤

1. 电视开机，停在能接收投屏的状态；
2. 手机上打开 pilipili，进一个视频的播放页；
3. 点屏幕调出播放工具条，找**投屏图标**（一般是个小电视标志，多在播放器右上角）；
4. 点它，等设备列表刷出来，选中你家电视的名字；
5. 连上后画面切到电视上，手机变成遥控器，进度、音量都能在手机上控。

不同版本的入口位置略有差异，找不到图标时在全屏工具条里挨个找小电视标志（以上步骤按分发页教程与通用投屏流程整理，以你手上版本的界面为准）。

## 三、搜不到设备 / 投屏卡顿

| 现象 | 按顺序试 |
| --- | --- |
| 设备列表是空的 | 确认两台设备在同一 Wi-Fi；重启电视和路由器；关掉路由器的 AP 隔离 / 访客模式 |
| 连上了但卡顿、画面糊 | 电视端网速不稳或带宽被别的设备占着；先在手机端把画质档位调低再投，见 [播放画质与弹幕设置.md](播放画质与弹幕设置.md) |
| 有画面没声音 | 检查电视与手机两侧的音量和静音设置；个别老电视对某些音轨格式不支持，换个内容试 |
| 投屏中途断开 | 投屏期间保持 pilipili 在前台、别让手机休眠过狠；Wi-Fi 信号差就把设备挪近路由器 |

投屏效果依赖电视端的支持程度，个别内容因格式原因投不了属正常现象，换手机端观看即可。打不开、闪退这类与投屏无关的问题，去 [闪退与加载失败排查.md](闪退与加载失败排查.md)。
