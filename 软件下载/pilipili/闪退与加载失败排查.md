## 一、先对症状

| 症状 | 大概率原因 | 先做哪步 |
| --- | --- | --- |
| 点图标闪退 / 打不开 | 权限异常、缓存损坏、机型兼容 | 第二节 |
| 视频一直转圈 / 加载失败 | 网络或内容源的问题 | 第三节 |
| 后台切回来就闪退 | 旧版已知问题 | 升级到 4.2（见第四节） |
| 弹幕卡顿掉帧 | 弹幕密度高、内存紧 | [播放画质与弹幕设置.md](播放画质与弹幕设置.md) 的弹幕与极速模式两节 |
| 无规律偶发闪退 | 适配面有限，稳定性依赖版本迭代 | 第二节，并保持更新到最新版 |
| 离线缓存播不了 | 缓存写入不完整 | [离线缓存与空间管理.md](离线缓存与空间管理.md) 第三节 |

## 二、闪退的通用排查（按顺序做）

1. **重启应用**：从后台划掉 pilipili 再打开；
2. **重启手机**：清掉临时故障，代价最小；
3. **清应用缓存**：长按图标 → 应用信息 → 存储 → 清除缓存（离线缓存可能受影响，重要内容先处理）；
4. **检查权限**：应用信息 → 权限，把存储相关权限打开；
5. **卸载重装**：前面都无效再做，本地数据会丢；安装包从 [下载与安装教程.md](下载与安装教程.md) 里的网盘资源重新取。

## 三、加载失败的排查

1. **换网络**：Wi-Fi 和流量互相切一下，很多「加载失败」是当前网络到源之间的路不通；
2. **重置连接**：开飞行模式 30 秒再关掉，重新连网；
3. **换个视频试**：只有个别内容加载失败是源的问题，过段时间再看；全都失败才是你这边的问题；
4. 全都失败且换网无效 → 清应用缓存（第二节第 3 步）后重试。

## 四、版本与反馈相关的已知点

- 据分发页更新说明，4.2 版修复了部分机型后台切换闪退的问题，并优化解码逻辑、减少卡顿与音画不同步。还在用旧版的话，先升级再排查，安装步骤见 [下载与安装教程.md](下载与安装教程.md)；
- 低配机器持续卡顿，把设置里的「极速模式」打开，见 [播放画质与弹幕设置.md](播放画质与弹幕设置.md) 第五节；
- 有用户反馈这款应用偶尔会无规律闪退（分发页评论区，单条反馈，供参考）。这类问题只能靠版本迭代修：保持用最新版，闪退频率通常会随更新下降。

以上都试过还解决不了，多半是机型兼容问题：等下个版本，或在这台设备上换用其他播放工具。
