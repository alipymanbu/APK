# 应用授权与一键激活

> Tasker、冰箱这类自动化、后台管理应用要完整工作，需要系统授予特殊权限，光从应用商店装上是不够的。本篇讲这些授权是什么、Zhang3Tool 的一键激活帮你省掉什么、激活后怎么确认生效。

## 一、这些应用为什么要「激活」

安卓把写入系统安全设置这类权限（`WRITE_SECURE_SETTINGS`）收得很紧，正常安装流程不会授予。拿到它的常规做法是连电脑执行 adb 命令，以 Tasker 官方文档给出的命令为例：

```bash
adb shell pm grant net.dinglisch.android.taskerm android.permission.WRITE_SECURE_SETTINGS
```

每换一个应用就要查一次它的包名、敲一次命令，对没碰过命令行的人门槛不低。Zhang3Tool 走 Shizuku 拿到同样的执行能力后，把这些授权做成了图形界面里的「一键激活」—— 你选应用、点按钮，命令它替你执行。第三方介绍里提到可激活的对象有 Tasker、Sense、冰箱这类工具，具体列表以你手里的版本在应用内显示的为准。

## 二、激活步骤

前提：Shizuku 已启动、Zhang3Tool 已授权（没做先看[Shizuku激活与授权步骤.md](Shizuku激活与授权步骤.md)）。

1. 打开 Zhang3Tool，进入工具板块，找到「一键激活」或按应用分类的激活入口；
2. 选择要激活的应用；
3. 点激活并等结果提示，一般几秒内完成。

激活动的是权限配置，不修改应用本体；反悔时在被激活的应用内或系统设置里撤销授权即可。

## 三、怎么确认激活成功

最可靠的验证是去被激活的应用里做原来做不了的事：

| 验证点 | 成功的表现 |
| --- | --- |
| 应用内权限自查页 | 不再列出「缺少 WRITE_SECURE_SETTINGS」之类提示 |
| 原本受限的功能 | 直接可用，不再弹引导你去 adb 授权的教程页 |

以 Tasker 为例：拿到该权限后，读写系统设置类的自动化动作可以正常执行，应用不再要求额外授权。

## 四、激活失败先查这些

- Shizuku 服务是否还在运行（手机重启后必然停止，重新启动即可）；
- Zhang3Tool 的 Shizuku 授权是否被系统回收；
- 机型差异：部分厂商系统会限制 adb 级操作，对应解法见[常见问题排查.md](常见问题排查.md)的「adb 权限受限」一节。

授权这类操作成功时通常没有声响，失败时才弹提示 —— 点完激活多看一眼结果提示，别默认成功。
