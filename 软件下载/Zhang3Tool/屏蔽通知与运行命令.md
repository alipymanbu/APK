## 一、屏蔽运营通知

很多应用的「运营通知」（活动推荐、内容推广类）在系统通知设置里藏得深，逐个关很费劲。这个功能做的事：

- **一键屏蔽**应用的运营通知；
- **应用白名单**：把不想被波及的应用加进去，屏蔽时跳过；
- **恢复通知设置**：屏蔽反悔了可以还原。

建议的操作顺序：先加白名单，再执行屏蔽 —— 白名单保护的是重要通知（验证码、私聊消息），屏蔽前加好，能省掉事后排查「谁的消息没收到」的麻烦。

屏蔽完想确认效果，让装了推广通知的应用挂一会儿，看通知栏是否还冒同类消息。误伤重要应用时，先查白名单里有没有它，没有就加上，再用「恢复通知设置」还原后重新屏蔽。

## 二、运行 CMD 命令

命令页可以直接输入命令并查看结果，适合想直接操作系统但不想连电脑开 adb 的场景。

**界面提供的操作：**

| 操作 | 说明 |
| --- | --- |
| 输入命令并运行 | 结果直接显示在下方 |
| 清空 / 复制结果 | 长输出想拿去搜索时用 |
| 快捷命令 | 六个可长按绑定的位置，把常用命令固定住，省得每次手输 |

**能力边界：** 这里的命令以 Shizuku 提供的 adb shell 级权限执行。日常的系统设置读写、应用管理类命令都在范围内；要求 root 权限的命令会执行失败或无效果 —— 这不是故障，是权限边界，换什么命令都一样。

**第一次用，先跑这几条只读命令找感觉**（只查看、不改动任何东西）：

```bash
pm list packages
```

列出手机上全部应用的包名，想确认某个应用的包名时用它（可接 `grep` 过滤，如 `pm list packages | grep weixin`）。

```bash
dumpsys battery
```

查看电池状态：电量、充电状态、温度，排查耗电问题时先看这个。

```bash
getprop ro.build.version.release
```

读取当前安卓版本号，确认系统版本时不用再去设置里翻。

**给不熟命令行的人的建议：** 不确定一条命令是干什么的，先复制去查清楚再运行；命令操作没有「后悔药」，回车前多看一遍参数。

## 三、两个功能共同的依赖

这两个功能都走 Shizuku，提示「服务未运行」时按[Shizuku激活与授权步骤.md](Shizuku激活与授权步骤.md)重新启动即可；其他执行异常先过一遍[常见问题排查.md](常见问题排查.md)。
