# Shizuku 激活与授权步骤

> Zhang3Tool 的系统级功能都依赖 Shizuku 服务，这一步没做完，工具箱里大部分开关点下去都会提示服务未运行。本篇讲三种启动方式怎么选、无线调试怎么配对、授权怎么给。

## 一、三种启动方式，先选一条

Shizuku 官方手册给出三种启动方式，按你的设备情况选：

| 启动方式 | 适合谁 | 是否需要电脑 |
| --- | --- | --- |
| 通过无线调试启动 | 安卓 11 及以上、未 Root 的手机 | 不需要 |
| 通过连接电脑启动 | 未 Root 且安卓 10 及以下的设备 | 需要 |
| 通过 Root 启动 | 已经 Root 的设备 | 不需要 |

绝大多数未 Root 的新机型走第一行就够了。不确定时先确认自己的安卓版本再选，能省掉中途换路的折腾。

## 二、无线调试方式（安卓 11+，推荐）

第一次使用需要「配对」，只需一次；之后每次重启手机要重新「启动」（不用重新配对）。

**准备工作：**

1. 在网络上搜索你的机型怎么打开「开发者选项」（一般是设置里连点版本号 7 次）；
2. 在开发者选项里启用「USB 调试」；
3. 进入「无线调试」并开启。

**配对（仅需一次）：**

1. 打开 Shizuku，选择「通过无线调试启动」，点开始配对；
2. 回到系统「无线调试」页面，点「使用配对码配对设备」；
3. 屏幕会显示 6 位配对码，此时把 Shizuku 的通知栏通知拉下来，在输入框里填入配对码；
4. 等待配对成功的提示。

**启动：**

- 配对成功后回到 Shizuku 点「启动」，状态变成运行中即可。

官方手册提醒：如果无法启动，尝试禁用再重新启用「无线调试」开关。

## 三、连接电脑方式（安卓 10 及以下）

1. 电脑安装 adb（Android 官方 platform-tools 即可），解压后在目录里打开命令行窗口；
2. 手机开启 USB 调试后用数据线连电脑，首次连接手机上会弹出「是否允许调试」，勾选「总是允许」后确认；
3. 命令行里执行 `adb devices`，设备列表里出现你的手机序列号才说明连接正常（PowerShell 环境下命令要写成 `./adb`）；
4. 执行启动命令（适用于 Shizuku v11.2.0+，也就是 Shizuku 页面上给你的那条）：

```bash
adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
```

5. Shizuku 显示运行中即可拔线。

命令敲完没反应时，先回头确认第 3 步的设备列表 —— 多数失败都出在授权弹窗被误点「拒绝」。

## 四、给 Zhang3Tool 授权

Shizuku 显示运行中之后：

1. 打开 Zhang3Tool；
2. 首次使用系统级功能时会弹出 Shizuku 授权对话框，点允许；
3. 之后工具箱里的各功能就可以正常调用了。

Zhang3Tool 在 Shizuku 服务没在跑时会明确提示你，看到这类提示就回到上面第二步重新启动 Shizuku，不是软件坏了。

## 五、重启手机之后要做什么

这是 Shizuku 的系统限制：**每次重启手机后，Shizuku 服务都会停止**，需要重新执行「启动」动作（无线调试方式不用重新配对，直接启动即可）。装完头几天觉得「怎么又不行了」，十有八九是这个原因。

更详细的手册与常见报错见 Shizuku 官方用户手册：[https://shizuku.rikka.app/zh-hans/guide/setup/](https://shizuku.rikka.app/zh-hans/guide/setup/)；配对卡住的场景另见[常见问题排查.md](常见问题排查.md)。
