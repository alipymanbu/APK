## 一、提示「Shizuku 服务未运行」

几乎所有功能的异常提示都指向这一条。按顺序检查：

1. Shizuku 本体装了没有 —— 没装的话先从官方渠道装（Google Play / F-Droid / GitHub `RikkaApps/Shizuku` Releases）；
2. Shizuku 里服务是不是运行中 —— 重启手机后服务一定停止，要重新启动（不用重新配对）；
3. Zhang3Tool 的授权还在不在 —— 偶尔系统回收授权，重新允许一次即可。

对应操作步骤都在[Shizuku激活与授权步骤.md](Shizuku激活与授权步骤.md)。

## 二、无线调试配对卡住

**一直显示「正在搜索配对服务」：**

- 确认手机连着 Wi-Fi（无线调试不走流量，但要在网络环境里工作）；
- 确认「无线调试」开关本身是开的，且停留在该页面；
- 官方手册的建议：禁用再重新启用无线调试，然后重试。

**点「输入配对码」后立刻失败：**

- 配对码有时效，超时就作废，重新点「使用配对码配对设备」拿新的码，快速填入；
- 填码时别关掉系统那个配对弹窗。

这两条是 Shizuku 官方手册列出的高频问题，换设备迁移时同样适用。

## 三、屏蔽通知后，重要消息收不到了

屏蔽动作是按应用生效的，白名单没加就会一起被屏蔽。处理：

1. 打开屏蔽通知功能，检查白名单里有没有该应用；
2. 没有就加入白名单；
3. 用「恢复通知设置」还原该应用的通知权限，再重新执行屏蔽。

判断标准：验证码、私聊、日程提醒类应用，永远先加白名单再屏蔽。

## 四、开了墓碑模式后个别应用不正常

表现为推送延迟、后台应用唤不醒。验证方法：关闭墓碑模式开关，观察该应用是否恢复正常 —— 恢复了就说明是它，按自己的使用习惯取舍（详见[墓碑模式开启方法.md](墓碑模式开启方法.md)第四节）。系统 OTA 升级后设置可能被重置，也属于这一类「突然不正常」。

## 五、安装包校验与安装失败

**想确认拿到的包是本文对应的版本：**

| 核对项 | 应为 |
| --- | --- |
| 版本 | 1.2 |
| 包名 | com.zhang3.tool |
| MD5 | 34205848A065AA12F236CD23AFFA3959 |

MD5 核对方法：手机上用带校验功能的文件管理器或哈希工具算 APK 文件的 MD5；电脑上用 PowerShell：

```powershell
Get-FileHash "Zhang3Tool_v1.2.apk" -Algorithm MD5
```

结果（不区分大小写）与上表一致即可。

**安装时提示无法安装 / 包异常：**

- 下载过程被中断是最常见原因，删掉重新下载再装；
- 确认没有和设备上已有的不同签名版本冲突（装过其他渠道的同包名版本时，先卸载旧的）；
- 存储空间不足也会报安装失败，清理后重试。
