## 一、先说蓝勾：它能证明什么

照片验证的蓝勾只做一件事：核对一张实时自拍与资料照片里的人脸是否相符。它不核对身份、不核对动机，也不核对该账号此后的行为。

这不是猜测。2026 年 4 月有记者公开演示过：用盗来的照片成功创建了多个「已验证」的 Tinder 资料账号。多个安全机构的报告也持同一口径：蓝勾是低门槛证明，不是安全认证。

所以你的判断依据应该是**行为信号**而不是任何徽章。下面两节列出的是多个独立安全来源（Norton、Moonlock 等）反复印证过的高频信号——单独一条出现未必是骗子，两条以上同时命中就值得警惕。

## 二、资料页的六个信号

滑动阶段就能看出的问题，一个都没命中再右滑也不迟：

| 信号 | 具体表现 |
| --- | --- |
| 照片完美得不像生活 | 全是影棚级精修、异国景点大片，没有一张像朋友随手拍的 |
| 简介是模板句 | 「爱旅行爱笑爱美食」式万能简介，套在任何人身上都成立 |
| 简介带外部链接或引流 | 「加我 IG/Snap：@xxx」、投资平台链接、任何可点的网址 |
| 职业人设过于光鲜 | 模特、军医、海外工程师、继承家业，配上常年出差设定 |
| 自称常驻海外 | 长期在远洋、驻外、油气平台——为「没法视频/没法见面」预设理由 |
| 资料信息互相矛盾 | 年龄、职业、城市对不上，或与聊天中自述冲突 |

## 三、聊天里的四个信号

配对之后的对话比资料页更能暴露问题，四个信号按出现顺序排：

1. **回复快得反常、话术带模板味**：真人会去上班、会睡觉；秒回、句式浮夸、答非所问、你说的细节对方接不住，是脚本或代聊的典型特征；
2. **几轮就要求转去其他平台**：刚聊没多久就要你加 WhatsApp、Telegram 或另一个陌生 App——离开平台后举报链路断了，很多木马链接也是在这一步发的；
3. **始终拒绝视频通话**：约好视频总有「网络不好」「在开会」等理由，一拖再拖。真人对视频的接受度远高于骗子；
4. **升温快、谈钱早**：几天内建立深度关系、开始聊「带你做投资」「加密货币平台」「帮我收个款」「买张礼物卡证明心意」——任何形式的钱都是终点信号，到此为止直接举报。

其中「验证码」骗局要单独提防：对方以「帮我收个验证码」为由要你手机收到的短信验证码。给了，你的手机号就可能被绑进别人的账号或支付体系。**任何人都不能给验证码**，包括自称官方客服的——Tinder 官方不会向你要验证码。

## 四、常见套路对照表

| 套路 | 剧本走向 | 你会失去什么 |
| --- | --- | --- |
| 机器人钓鱼 | 配对秒回 → 发链接或「验证」页 → 盗号或装木马 | 账号、支付信息 |
| 投资盘（杀猪盘） | 数周情感铺垫 → 展示虚假盈利截图 → 引入假投资平台 → 越充越多 | 本金与「利润」 |
| 引流代聊 | 资料与聊天都在把你导去直播、刷单、色情充值平台 | 时间与金钱 |
| 借号收码 | 借你手机号收验证码「注册个东西」 | 号码被用于黑产 |

## 五、拿不准时的三步核实

1. **提视频**：直接约一次视频通话，这是成本最低、准确率最高的一步，骗子大概率推脱；
2. **问具体细节**：问对方资料里写过的地点、经历的具体细节，编造的人设接不住追问；
3. **观察钱字出现的时间**：正常交往不会在见面前谈钱。「任何形式的金钱请求 = 终止」这条线不需要例外。

## 六、确认是骗子之后

按顺序做四件事：

1. **截图留证**：资料、聊天记录、转账凭证都截下来，举报与报案都用得上；
2. **App 内举报**：对方资料页与聊天页都有举报入口，举报后取消配对；
3. **检查自己的账号**：如果你给过验证码或点过链接，立即改掉相关账号密码、检查绑定关系；给过钱的，立刻联系付款渠道（银行、支付平台）申请拦截或冻结；
4. **报案**：涉及金额损失，向当地警方报案并提交证据，不要因为金额不大就放弃——同一伙人往往在多个平台同时作案。

## 七、日常习惯

识别之外，两条习惯能挡掉大部分风险：不在资料与聊天里透露住址、证件、财务信息；不点配对对象发来的任何链接。配合 [账号安全与常见问题.md](账号安全与常见问题.md) 里的赴约安全清单使用，线上线下的面就都盖住了；蓝勾怎么拿、为什么仍然值得拿，见 [注册登录与资料设置.md](注册登录与资料设置.md)。
