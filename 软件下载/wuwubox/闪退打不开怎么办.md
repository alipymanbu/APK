## 一、先分清是哪一种

「打不开」其实是三件不同的事，处理路径完全不一样，先对号入座：

| 现象 | 归哪类 |
| --- | --- |
| 安装时就报错，装不上 | 第二节 |
| 装好了，点图标闪退或黑屏一下就退 | 第三节 |
| 能打开，但里面没内容、一直转圈 | 不是打不开，是网络问题 → [播放卡顿怎么调.md](播放卡顿怎么调.md) |

## 二、安装阶段报错

按报错文案选一条：

- **「解析包时出现问题」/「无法打开文件」**：apk 文件损坏或没下载完整。回到 [下载与安装教程.md](下载与安装教程.md) 重新从 [wuwubox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d45563a0235a) 下载，下载完核对大小约 109M 再装；
- **「已阻止安装未知来源应用」**：权限没开，各品牌设置路径见 [提示被禁止安装未知应用怎么办.md](提示被禁止安装未知应用怎么办.md)，开完再点一次安装；
- **「安装包与已安装的应用签名不一致」**：手机里残留着另一个来源的同名应用，先卸载旧的再装（收藏、缓存会一并清掉，介意就先备份或跳过这步）；
- **「存储空间不足」**：安装需要解压空间，先清理手机存储，一般留出安装包大小 1.5 倍以上的余量再试；
- **「设备系统版本过低」**：分发页标注系统要求为安卓 5.2 以上，以安装时的实际提示为准；确实过低的机器装不上。

## 三、闪退、点开就没反应

按出现频率排序，逐条试到哪条管用为止：

1. **先把应用彻底关掉重开**：从后台划掉再点图标，偶发的启动失败这一步就解决了；
2. **清缓存**：「设置 → 应用管理 → wuwubox → 清理缓存」。只清缓存，别点「清除数据」（会清掉播放历史与设置）；
3. **检查剩余存储与内存**：存储快满时应用写不进临时文件，容易启动即退；后台开的应用太多也会被系统杀掉，清一批后台再试；
4. **检查网络**：首屏就要拉数据，断网、或连着需要网页认证才能上网的 Wi-Fi 时，应用可能直接退出。换 Wi-Fi 或切流量试；
5. **更新系统**：系统组件过旧会导致个别应用启动失败，把手机系统更新到最新；
6. **卸载重装**：以上都不管用，卸载后重新下载安装（拿包位置见 [下载与安装教程.md](下载与安装教程.md) 第三节）。重装会清掉本地的收藏与缓存。

## 四、反复出现时的判断

- **只有这一个应用闪退、别的都正常**：多半是这份包与你的机型不兼容，换一个时间重新下载装一次（下载中断产生的坏包是闪退的常见原因）；
- **装完第一次能用、之后开始闪退**：从「清缓存」开始走第三节，不要一上来就卸载，避免把本地数据清没了还没定位到原因；
- **重装后依然闪退**：确认包名是否为 `com.jylorqs.wtmfz`（见 [下载与安装教程.md](下载与安装教程.md) 第二节）—— 对不上说明装的不是这份包，重新获取即可。

排除完仍要看片，界面与操作见 [安装后怎么用.md](安装后怎么用.md)；能打开但播不动的走 [播放卡顿怎么调.md](播放卡顿怎么调.md)。
