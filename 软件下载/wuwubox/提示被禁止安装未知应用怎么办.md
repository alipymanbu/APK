## 一、这个提示是什么意思

装 wuwubox 时若弹出「不允许安装未知来源的应用」「文件管理被禁止安装应用」这类提示，说明系统把应用商店之外的安装包拦下来了 —— 这是安卓的默认安全策略，不是你的包坏了，也不用重下。开一个开关就能装，关键是**权限授予的对象**：安卓是按「发起安装的那个应用」给权限的，你用文件管理器点的安装包就给文件管理器授权，用浏览器下载后直接安装就给浏览器授权。给错了对象，开关打开了照样装不上。

完整的下载与安装流程见 [下载与安装教程.md](下载与安装教程.md)。

## 二、各品牌的设置路径

下面的路径整理自各品牌官方支持文档与公开教程（截至 2026-09，系统版本不同措辞略有差异，以你手机上的实际文案为准）：

| 品牌 | 设置路径 |
| --- | --- |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 → 找到文件管理或浏览器，打开「允许安装应用」 |
| 小米 / 红米 | 设置 → 隐私保护 → 特殊权限设置 → 安装未知应用 → 选中发起安装的应用 → 打开「允许来自此来源的应用」 |
| OPPO / realme / 一加（ColorOS 12 及以上） | 设置 → 密码与安全 → 系统安全 → 外部来源应用（安装未知应用）→ 打开对应应用的开关 |
| OPPO / realme（ColorOS 11） | 设置 → 安全 → 安装外部来源应用 |
| 其他品牌 | 在「设置」的搜索框里直接输「未知」或「安装未知」，定位到该开关后授予给实际打开安装包的应用 |

两个通用要点：

- **认准发起安装的应用**：从哪个入口点的 apk，就开哪个应用的权限，别无脑全开；
- 装完这一次若不想留着该权限，可以再回来关掉 —— 权限是随时可逆的。

## 三、弹「风险提示」「未经审核」怎么选

开了未知来源权限后，部分品牌还会再弹一层安全提示，常见文案有「该应用存在风险」「安装包未经安全审核」「未通过安全检测」等，各品牌措辞不同。选择前先核对两件事：

1. 文件是不是你刚从 [wuwubox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d45563a0235a) 下载的那份（大小约 109M，包名 `com.jylorqs.wtmfz`，核对方法见 [下载与安装教程.md](下载与安装教程.md) 第二节）；
2. 下载过程有没有中断（大小明显不对就是没下完整，回去重下）。

两件都对得上，就按弹窗给的入口继续（不同系统分别写作「继续安装」「了解风险」后确认等），装完即恢复默认拦截状态。弹窗若提示的是「与设备不兼容」「CPU 不兼容」这类硬性拒绝、根本没有继续选项，说明不是权限问题 —— 转到 [闪退打不开怎么办.md](闪退打不开怎么办.md) 第二节按安装失败排查。
