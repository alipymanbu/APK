T2S 后台朗读被掐，多数出在系统省电机制上，而各家系统的入口藏得不一样。本篇按品牌整理具体的设置路径，来源是收录各品牌后台限制的社区站点 dontkillmyapp.com（T2S 官方排查文档也推荐它）——菜单叫法和层级随系统版本变化，动手前以你手机上的实际界面为准。

先记住两个前提：

- **T2S 和朗读引擎应用都要设**，只放行一个照样断；
- 设完做一次实测：息屏连续听十分钟以上，还断再回来补漏。

## 一、小米（MIUI）

1. **自启动**：安全中心 → 应用管理 → 权限 → 自启动管理，把 T2S 和引擎都打开；部分版本在 设置 → 应用设置 → 应用管理 → 对应应用 → 自启动；
2. **省电策略**：安全中心 → 电池 → 省电策略，找到这两个应用选「无限制」；
3. **任务锁定**：打开最近任务，把卡片**下拉**（或长按卡片点锁形图标）加锁，锁定的应用不会被一键清理顺手杀掉。

MIUI 还有一个「应用智能省电」入口：设置 → 电量与性能 → 应用智能省电 → 对应应用 → 无限制。不同 MIUI 版本菜单名有出入，找到「后台权限」「省电策略」这类字样就对了。

## 二、华为 / 荣耀（EMUI / Magic OS）

1. **应用启动管理**：设置 → 应用和服务（或应用）→ 应用启动管理，找到 T2S 和引擎，关掉「自动管理」，改为手动，弹出的三个开关（允许自启动、允许关联启动、允许后台活动）**全部打开**；
2. **电池优化**：设置里搜「电池优化」（或「忽略电池优化」），点「全部应用」，找到这两个应用选「不允许」（即不优化）；
3. 有荣耀用户分享过一条更短的路：设置 → 辅助功能 → 无障碍 → 文本转语音里把引擎选好，再到应用启动管理里手动放行——路径和上一条是一回事，你的系统里哪条能走通走哪条。

部分 EMUI 版本还有更激进的后台查杀，普通设置压不住，官方社区文档（dontkillmyapp.com 的 Huawei 页）有详细说明，需要时按那边的指引处理。

## 三、三星（One UI）

1. **电池优化**：设置 → 应用 → 对应应用 → 电池 → 允许后台活动（或「电池优化」里选「全部」→ 找到应用 → 不优化）；
2. **休眠应用**：设置 → 电池 → 后台使用限制，检查「深度睡眠应用」「休眠应用」列表，把 T2S 和引擎从里面移出来；
3. **未使用应用**：如果系统里有「移除未使用应用的权限」开关（设置 → 应用 → 未使用的应用），保持关闭，否则长期不点开会失去权限。

## 四、OPPO / 一加（ColorOS）

1. **自启动**：设置 → 应用 → 自启动（或手机管家 → 权限隐私 → 自启动管理），放行两个应用；
2. **电池优化**：设置 → 电池 → 更多（或应用耗电管理），把 T2S 和引擎设为「允许后台运行 / 不优化」；
3. **任务锁定**：最近任务里下拉卡片上锁；
4. 一加的部分机型有「高级优化」（设置 → 电池 → 右上角菜单），里面的「深度优化」「睡眠待机优化」也会掐后台，一并关掉。

## 五、其他品牌

大同小异，套路就三个词：**自启动**、**电池优化白名单**、**后台运行权限**。在系统设置里逐个搜这三个词，把 T2S 和引擎都放行。找不到入口时，直接搜「你的机型 + 允许后台运行」，或者去 [dontkillmyapp.com](https://dontkillmyapp.com/) 按品牌查——那个站点按厂商维护了完整的设置路径，还收录了各机型的截图。

设置完还断的话，回到 [后台朗读中断怎么解决.md](后台朗读中断怎么解决.md) 按完整排查顺序过一遍；语音引擎本身的配置见 [朗读引擎与音色设置.md](朗读引擎与音色设置.md)，实在压不住时的导出兜底方案见 [导出音频文件的方法.md](导出音频文件的方法.md)。
