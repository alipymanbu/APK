## 一、安装失败或解析包出错

按顺序查三样：

1. **系统版本**：这份安装包要求 Android 8.0 及以上，低于 8.0 会直接提示解析失败；
2. **包完整性**：重新从网盘下载一遍，下载中断会得到残缺的 APK；核对 MD5 应为 `4F1ED64464954AF0E0353F08B1AF7BE9`；
3. **安装器授权**：确认给「用来打开 APK 的那个文件管理器」开了「允许安装未知应用」，换一个文件管理器打开也一样要重新授权。

完整安装流程见 [下载与安装教程.md](下载与安装教程.md)。

## 二、功能点了没反应，多半是权限被拒

导入视频没反应、保存失败、录音不能用，通常不是功能坏了，是对应权限没给：

| 现象 | 缺的权限 |
| --- | --- |
| 选不了相册里的视频图片 | 读取音视频媒体 / 存储 |
| 剪完保存不了 | 存储写入 |
| 录音、配音没声音 | 麦克风 |
| 处理完成收不到提醒 | 通知 |

处理路径：手机「设置」→「应用」→「剪画」→「权限」，把要用的那项改为允许，回到 App 重试即可，不用重装。

## 三、怎么清空本地作品

剪辑产生的工程和成品都留在手机本地，想一次性清掉：

1. 打开剪画，点底部导航栏「我」；
2. 进「设置」；
3. 点「清空本地作品」，弹窗确认后执行。

不同版本的菜单入口可能略有差异，找不到就以你手上版本的设置页为准。

注意弹窗里那句话：清除后文件不可找回。只想删个别作品的话，在作品列表里单条删除更稳妥，别一键全清。

## 四、任务一直转圈或处理失败

- **粘贴链接解析不了**：先确认链接完整（分享页复制的是全链）；部分平台或非公开视频不在解析范围内，这类改用「导入本地视频 + 框选擦除」的本地处理路子；
- **云端功能卡在排队**：网络波动会导致任务挂起，杀掉 App 重进再看；在线版这边任务完成后靠通知提醒，通知权限记得开；
- **大文件上传慢**：在线版在云端处理，上传速度取决于你的带宽，急用时改用 App 本地处理。

各功能的操作步骤在 [视频去水印与音频提取怎么用.md](视频去水印与音频提取怎么用.md)。

## 五、网盘里这版和商店最新版差在哪

网盘收录的是 2.16.4；商店现行版本以商店当时显示为准（截至成文为 3.0.0，新增了图片改字功能）。对基本剪辑、去水印、音频提取这些常用链路来说没有区别，不必为了一个功能专门升级；需要图片改字再去商店装新版。版本与功能对照见 [软件简介与功能一览.md](软件简介与功能一览.md) 第三节。

## 六、它和 GitHub 上那个 OpenCut 是什么关系

没有关系，只是重名。安卓上的「剪画」（包名 `com.lestream.cut`）是深圳市徽音科技有限公司的手机应用；GitHub 上的 OpenCut 是另一个面向网页与桌面端的开源剪辑项目，装法、界面、功能都不同。判断你该看哪套文档：手机上装 APK 的，看这套；找开源项目的，去它自己的仓库页。
