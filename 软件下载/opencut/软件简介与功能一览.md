## 一、这是个什么软件

OpenCut 中文名叫「剪画」，是深圳市徽音科技有限公司出品的安卓端音视频剪辑工具。它的定位是「轻量剪辑 + 素材处理」：视频裁剪拼接、变速倒放这类基础剪辑都在时间线上完成，同时配了一批一条流程就能出结果的工具——去水印、音频提取、人声分离、文案提取等，不需要多轨操作经验。

官方除了安卓 App，还提供[在线网页版](https://www.lestream.cn)和微信小程序，三种形态共用同一套功能思路，细节差异见第四节。

一个容易混淆的点：GitHub 上有一个同名的开源视频剪辑项目 OpenCut（面向网页与桌面端），它和本篇讲的安卓 App「剪画」**不是同一个产品**，开发团队、安装方式、功能都不同。如果你要找的是安卓手机上的剪辑工具，那么你要的就是「剪画」这个 App。名字相近的还有一个「剪映」，那是字节跳动的产品，和剪画逐项对比见 [和剪映的区别.md](和剪映的区别.md)。

## 二、功能一览

按官方商店页的功能说明，2.x 版本的主要功能如下：

| 功能 | 一句话说明 |
| --- | --- |
| 短视频去水印 | 复制视频链接即可解析保存，去掉画面上的平台水印 |
| 音频提取 | 把视频里的声音转成 MP3 保存 |
| 人声分离 | 从音频或视频里拆出纯人声、纯伴奏 |
| 文案提取 | 识别视频、音频里的语音，生成文字 |
| 视频翻译 | 把视频内容翻译成其他语言并生成字幕 |
| 音频剪辑 | 裁剪、合并、拼接音频，给音频加背景音乐 |
| 图片修复 | 把模糊照片做清晰化处理 |
| AI 动漫 | 实拍视频转二次元动漫风格 |
| 图片转动漫 | 实拍照片转二次元动漫风格 |
| 表情包制作 | 把视频片段做成 GIF 表情包 |

基础剪辑能力（裁剪、分割、拼接、变速、倒放、旋转、滤镜、转场、多段字幕）在时间线编辑里都有，上面这批工具是它的特色入口。

## 三、版本情况

| 版本 | 状态 | 说明 |
| --- | --- | --- |
| 2.16.4 | 网盘收录版 | 2025 年 10 月前后发布的版本，功能以第二节表格为准 |
| 3.0.0 | 商店现行版本 | 2026 年 9 月前后更新，新增图片改字功能；以官方商店页面为准 |

网盘里那份就是 2.16.4，包名 `com.lestream.cut`，与商店版是同一个应用。新版本只是增补功能，不是必装项，老版本的基本剪辑与素材处理流程不受影响。

## 四、App、在线版、小程序怎么选

| 形态 | 入口 | 适合场景 |
| --- | --- | --- |
| 安卓 App | 手机安装 | 功能最全，素材在本地反复剪辑、多段工程 |
| 在线网页版 | 浏览器打开官网 | 电脑上临时处理一条视频，免安装 |
| 微信小程序 | 微信内搜索 | 手机上偶尔用一次，不想占存储 |

在线版和小程序的处理在云端完成，官方说明是处理过的视频 3 小时后自动清除；App 则在你手机本地干活，素材与工程都留在设备里。怎么进入在线版、各形态功能差异，见 [在线版与微信小程序使用指南.md](在线版与微信小程序使用指南.md)。

## 五、登录与付费是什么口径

按官方隐私政策的表述：

- **登录**：支持微信登录、QQ 登录，以及移动 / 联通 / 电信手机号一键登录；
- **付费**：隐私政策里提到微信支付与支付宝支付绑定，说明 App 内存在需要付费的场景；具体哪些功能要花钱、价格多少，以 App 内实际展示为准，公开资料没有一份可靠的价格表；
- **在线版**：官网标称「免费开始」使用，各功能的次数限制同样以页面当时显示为准。

商店页面把这款应用标注为「年满 18 周岁」，给未成年人使用前先看 [常见问题与解决方法.md](常见问题与解决方法.md) 里「未成年人能用吗」那一条。

想直接装 App 的话，转 [下载与安装教程.md](下载与安装教程.md)；装好之后最常用的两个功能怎么操作，见 [视频去水印与音频提取怎么用.md](视频去水印与音频提取怎么用.md)。
