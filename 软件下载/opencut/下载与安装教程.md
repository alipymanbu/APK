## 一、安装前先确认三件事

| 检查项 | 要求 | 说明 |
| --- | --- | --- |
| 系统版本 | Android 8.0 及以上 | 该安装包最低 SDK 为 26；商店现行版本同样要求 8.0+，以官方商店页面为准 |
| 存储空间 | 建议预留 200MB 以上 | 安装包约 38.55MB，安装后连同缓存、剪辑工程会占更多 |
| 安装来源 | 需允许「安装未知应用」 | 从网盘下载的 APK 不走应用商店，首次安装时系统会要求你给文件管理器授权 |

网盘里这份是 2.16.4 版，几个可用于核对的信息：

| 项目 | 值 |
| --- | --- |
| 版本号 | 2.16.4 |
| 安装包大小 | 38.55MB |
| MD5 | `4F1ED64464954AF0E0353F08B1AF7BE9` |

下载完成后如果担心文件不完整，可以用文件管理器自带的属性页或第三方校验工具算一下 MD5，与上表一致即为此包。

## 二、从网盘获取安装包

1. 打开 [OpenCut（剪画）安装文件资源（夸克网盘）](https://pan.quark.cn/s/3a8484618c67)；
2. 转存到自己网盘后，用夸克 App 把 APK 下载到手机本地存储；
3. 记住下载位置（一般在 `Download` 或夸克的下载目录）。

安装包也可以从应用商店获取，但商店给到的是当时的最新版本，版本号、包体大小可能与上表不同。

## 三、安装步骤

1. 在文件管理器里找到刚下载的 APK，点它；
2. 第一次会弹「不允许安装未知应用」，点「设置」→ 打开该文件管理器的「允许安装未知应用」→ 返回再点一次安装；
3. 等安装进度走完，点「打开」直接进入，或回桌面点「剪画」图标。

装好后桌面图标显示的名称是「剪画」。

## 四、首次启动会要哪些权限

按官方商店页的权限说明，你在使用对应功能时它可能申请以下权限，弹窗时按需同意即可：

| 权限 | 用在什么时候 |
| --- | --- |
| 存储 / 读取音视频媒体 | 保存剪辑结果、导入手机里的视频音频图片 |
| 摄像头 | 拍摄照片或视频作为素材 |
| 麦克风 | 录音、上传音频类素材 |
| 系统设置 | 引导你到系统设置里开启上述权限 |
| 通知 | 任务处理完成后提醒你、接收客服消息 |

只做「导入本地视频 → 剪辑 → 保存」这条最常用的链路，同意存储相关权限就够了，其余可以在用到对应功能时再给。

## 五、装不上或打开闪退

安装中断、提示解析失败、打开就退等情况，按现象逐项排查：先确认系统版本达到 Android 8.0，再确认安装包下载完整（MD5 与上表一致），最后清理一下存储空间重装。具体的排查清单写在 [常见问题与解决方法.md](常见问题与解决方法.md) 里，两篇对着看即可。
