# PeakVisor 3D地图与路线规划怎么做

> 本篇讲 PeakVisor 的另一半核心：怎么打开 3D 地图、怎么传送探索、怎么规划徒步路线并导出 GPX，顺带把图层与 Flyover 视频一起说清。

## 一、打开 3D 地图的两条路

从相机识别界面进 3D 地图有两个入口：

- 把手机朝地面方向压低，**双击屏幕上的罗盘**；
- 点右上角的 **3D Map** 按钮。

反过来想回相机识别界面：把手机重新举向地平线，或点标签按钮。这两个界面就是 PeakVisor 的两个主场，来回切换很频繁，手势值得记熟。

## 二、传送探索（Teleport）

默认显示的是你当前位置，但地图支持搜索并传送到全球任意山区——阿尔卑斯、喜马拉雅、落基山都可以直接跳过去看，山名、线路、山屋信息一应俱全，出发前做功课主要靠这一步。

注意免费版对传送有限制（官方说法是每天只能探索一个位置，以应用内当前规则为准）；想不限次传送、想把传送的区域缓存下来离线看，属于 Pro 的范围，见[免费版和Pro订阅区别.md](免费版和Pro订阅区别.md)。

## 三、规划一条徒步路线

在 3D 地图上点任何一个地点（停车场、山屋、山峰都行），从信息面板选 **Plan Routes** 进入规划，常用操作：

| 操作 | 干什么 |
| --- | --- |
| Start Here | 把路线起点设在你选的位置 |
| Set Destination | 把路线终点设在你选的位置 |
| Extend Here | 在已有路线上继续延伸，可以逐段拼出完整行程 |
| Close Loop | 让路线绕回起点，适合走环线 |

路线建好后，路线面板里直接给出**距离、累计爬升/下降、海拔剖面图**，还会显示最大与平均坡度。规划时可以顺手看缆车与山间小屋的开放状态和联系方式——在欧洲山区这条尤其有用，很多线路要靠缆车省掉一大段爬升。

## 四、不知道走哪条：Discover Mode

3D 地图上点双筒望远镜图标进入 Discover Mode，按距离、爬升量筛选附近的徒步线路，能看其他用户留下的照片，合适的收藏进个人资料，适合到了陌生地方临时找走法。

## 五、GPX 轨迹导入与导出

- **导入**：「Menu → Import → Import Trails or Bookmarks」，支持 GPX / KML / KMZ / IGC；也可以在文件管理器里用「分享到 PeakVisor」打开轨迹文件。导入后出现在 Profile 的 Saved Trails 或 Bookmarks 里；
- **导出**：在路线面板点「…」→ Share → **Export as GPX**，发给没用这应用的同伴也能看；
- **发送到 Garmin**：同一处 Share 菜单里有 Export to Garmin / Send to Garmin。注意两点：只有**公开路线**能导出，发过去落在 Garmin Connect 的 Courses（Suunto 则在 Routes）而不是活动记录里；连接与排障的完整流程见[Garmin与Suunto设备连接.md](Garmin与Suunto设备连接.md)。

## 六、图层与 Flyover 视频

地图右上角打开 Topo 图层开关，常用三样：**Winter**（冬季模式）、**Slope Angles**（坡度角）、**Aspects**（坡向）——冬天走雪线这三层建议都开。地图还带实时雪深读数和逐点天气预报，预报按你点的那个具体 GPS 坐标计算，能照顾到海拔与坡向带来的差异。

**Flyover** 是把任意路线（走过的或没走的都行）生成一段 3D 飞行预览视频，出发前看一遍等于心里把路线飞了一遍。回放卡顿就进高级设置开「60fps Flyover」。

## 七、离线才是山里的正事

3D 地图默认吃流量，山里没信号就会白屏，出发前按[离线地图下载方法.md](离线地图下载方法.md)把目标区域提前下好。路线建好、地图下好、GPX 导好，再翻一遍[常见问题与故障排查.md](常见问题与故障排查.md)确认没有踩坑，就可以出门了。
