# PeakVisor 常见问题与故障排查

> 本篇把 PeakVisor 的高频问题归成一张排查清单：标签不对、地图空白、路线建不出来、轨迹丢记录，各自怎么对症处理。

## 一、先学会用官方 Demo 排除「不会用」

不少「故障」其实是操作没熟。应用自带演示场景：「Menu → Virtual Demos」选一个地点，所有功能都能在这个虚拟位置上试，不消耗你的定位也不受实地环境影响。怀疑自己操作有问题时先在 Demo 里复现一遍，复现不出来就说明是环境问题，再往下对号入座。

## 二、识别与标签类

| 现象 | 处理 |
| --- | --- |
| 标签整体和真山对不上 | 手动校准全景层（拖动对齐），或拿太阳对准黄圈；iOS 用户顺带检查系统设置里的指南针校准开关 |
| 某座山没有标签 | 双指放大全景层再找；仍没有就开高级设置的「Enlarged Labels & Thick Silhouettes」 |
| 信息面板显示日出日落而不是距离 | 点面板里的太阳图标即可在两种显示间切换 |
| 山峰/缆车/数据有缺漏 | 在该对象的信息卡里用 **Edit Suggestions** 提交修正，或写信给 `feedback@peakvisor.com` |

校准的完整手法见[山峰识别怎么用.md](山峰识别怎么用.md)第二节。

## 三、地图与路线类

| 现象 | 处理 |
| --- | --- |
| 地图空白或模糊 | 先下载离线地图（Menu → Map Coverage，步骤见[离线地图下载方法.md](离线地图下载方法.md)）；已下载还这样，检查「仅 Wi-Fi 下载」设置和手机剩余存储 |
| 路线生成不出来或不出现 | 确认起终点都设了（Start Here / Set Destination），换替代方案再试；无路区域用 Off-trail 配合海拔剖面自行评估地形 |
| Flyover 视频卡顿 | 高级设置里开「60fps Flyover」 |

## 四、轨迹与记录类

| 现象 | 处理 |
| --- | --- |
| 轨迹记录断了一截 | 检查 GPS 权限和「后台运行」权限是否被系统省电策略掐了（国产 ROM 尤其常见，把应用加入自启动/后台白名单） |
| 记录整条丢失 | 少见情况可用高级设置里的 **Restore Recorded Track** 找回（官方建议在客服指导下用） |

## 五、GPX 与设备同步类

| 现象 | 处理 |
| --- | --- |
| GPX/KML 导不进 | 确认格式在支持列表（GPX / KML / KMZ / IGC）；改用系统「分享到 PeakVisor」的方式打开文件；导入后在 Profile 的 Saved Trails 或 Bookmarks 里找 |
| Garmin/Suunto 不同步 | 到「Menu → Import」里重新登录一次对应账号，确认手表侧已配对、权限已给全；路线从 Garmin 发过来的先确认设备在 Garmin Connect 里配对成功 |
| 路线发到手表后「找不到」 | 路线在 Garmin 的 **Courses**、Suunto 的 **Routes** 里，不在活动记录里；发送的前提是路线已设为公开 |

连接步骤、公开路线的限制与逐项排障见[Garmin与Suunto设备连接.md](Garmin与Suunto设备连接.md)。

## 六、都试过还不行

应用内有直达开发者的通道：「Menu → Talk to the Developer」。描述问题时带上机型、系统版本和能复现的操作步骤，比一句「用不了」管用得多。
