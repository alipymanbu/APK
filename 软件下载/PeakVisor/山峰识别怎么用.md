## 一、相机识别是默认首屏

打开 PeakVisor，第一屏就是相机取景界面：把手机举起来对准地平线，视野里的山峰会被逐个标上名字、海拔和距离。官方口径是可识别全球超过一百万座山峰、丘陵、孤丘等对象；标签不只覆盖山峰，湖泊、垭口、山间小屋（hut）、火山这类地理要素也会出现在全景里。点任何一个标签，屏幕底部会弹出信息面板：山峰的档案里除了海拔，还有地形突起度、所属山脉、国家公园或保护区归属、照片与维基百科条目；点面板里的太阳图标，还可以在距离和日出日落时间之间切换显示。

不想出门也能用：用搜索或传送（Teleport）功能跳到世界任何山区的虚拟视角，同样的标签效果，常用来提前认一遍目标线路的山。想练操作又怕弄乱设置，进「Menu → Virtual Demos」选一个演示地点，所有功能都能在演示场景里试。

## 二、罗盘校准：官方教程里排第一的技能

标签位置不对（比如标签悬在半空、明显和真山错位）是最常碰到的问题，处理手段就是手动校准全景：

1. 用手指把带标签的全景层左右或上下拖动，直到标签与真实山体轮廓完全重合；
2. 白天最省事的参照物是太阳：把取景画面里的太阳对准全景层上的大号黄圈，整层标签基本就正了；
3. 点左下角的小罗盘图标可以取消手动校准，恢复手机硬件罗盘的原始读数。

为什么老要校：手机的磁力传感器精度有限，还容易被电磁噪声带偏（低温、大风环境下更明显）。校准不是一劳永逸的，识别结果看着不对劲就随手拖一下。顺带一提，iOS 系统设置里有「指南针校准」开关（位置服务 → 系统服务），安卓机型一般直接靠应用内手动对齐解决。

## 三、放大与显示模式

- **放大找标签**：全景层支持缩放，某座山没标名字时先双指放大，缩放级别越高标签越密；
- **标签还是太小**：进高级设置（Advanced Settings）开「Enlarged Labels & Thick Silhouettes」（放大标签与加粗轮廓）；
- **切换显示形态**：通过照片按钮在几种模式间切换——Virtual（3D 着色山体全景）、Silhouette（山体轮廓线）、仅标签三种；另有 Terrain 模式不调用相机，是传送到异地后的默认视图。

右上角的 3D 按钮可以直接跳进当前位置的 3D 地图（双击罗盘也行），地图侧的用法见[3D地图与路线规划.md](3D地图与路线规划.md)。

## 四、给旧照片补山名标签

爬山时用系统相机拍的照片，事后也能导进来让 PeakVisor 标上每座山的名字，适合发朋友圈或做行程记录：

1. 进「Menu → Import → Photo Import」；
2. 挑一张**带 GPS 位置信息（geotag）**的照片——没有位置信息的照片应用算不出该叠加哪个角度的全景，这是最容易踩的坑；
3. 拖动全景层对齐照片里的山形（和第二节的校准是同一套手法）；
4. 留下需要的标签、删掉多余的，保存后即可分享。

照片对得越准，标签错位越少。标签密度不够时先放大再删减，比对着密密麻麻一堆标签硬挑省事。

## 五、识别不准时的检查顺序

按顺序过一遍：标签整体错位 → 做第二节的手动校准；个别山没标签 → 放大全景层；还是不行 → 检查定位权限是否给了；怎么调都异常 → 翻[常见问题与故障排查.md](常见问题与故障排查.md)第二节，那里把标签类问题归拢成了一张排查清单。
