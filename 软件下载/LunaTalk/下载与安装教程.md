## 二、获取安装包

从 [LunaTalk 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f2e26bae81d3) 转存到自己网盘，再在手机上下载安装，步骤：

1. 在电脑或手机浏览器打开上面的网盘链接，登录夸克账号后点「转存」；
2. 手机打开夸克 App，找到刚转存的文件（文件名为 `LunaTalk_v1.0.apk`，以网盘内实际显示为准），点「下载」；
3. 下载完成后点开 APK，系统第一次会提示「不允许安装未知来源应用」，按提示去设置里允许夸克（或你用的浏览器）安装应用，再返回安装页继续；
4. 安装完成后点「打开」进入应用。

不用网盘也可以走官方渠道：iOS 在 App Store、安卓在 Google Play 或其他应用商店搜 `LunaTalk`；官方还提供网页版，浏览器访问即可，不必安装（官方帮助文档见 [help.lunaailab.com](https://help.lunaailab.com)）。

## 三、注册与登录

1. 打开应用，点「Sign Up / 注册」；
2. 输入邮箱或手机号，设置并确认密码；
3. 完善个人资料：头像（可跳过）、昵称、兴趣标签。

注册和聊天都需要联网。不登录也可以浏览角色，但发不了消息，想聊天必须注册登录。

有用户反馈注册页面在部分网络环境下可能加载缓慢或失败，遇到一直转圈的情况，换一个网络环境再试；收不到验证码、登录不上等其他卡点，见[注册登录与常见问题排查.md](注册登录与常见问题排查.md)。

聊天记录保存在云端，换手机、换平板之后登录同一个账号，记录还在。

## 四、认识主界面

登录后底部主要有四个入口：

| 入口 | 用途 |
| --- | --- |
| 首页 | 浏览推荐角色 |
| 广场 | 按榜单与标签找角色，详见[角色广场使用指南.md](角色广场使用指南.md) |
| 创作 | 自己写角色卡并发布，详见[自建角色与发布教程.md](自建角色与发布教程.md) |
| 我的 | 个人资料与偏好设置；界面语言在这里切换（简中 / 繁中 / 英 / 日 / 韩） |

## 五、装好之后

先去「我的 → 偏好设置」把语言调成简体中文，再从广场挑一个角色开始第一段对话。对话界面的工具按钮、聊天设置与模型选择，见[对话与聊天设置详解.md](对话与聊天设置详解.md)；聊得多了会涉及积分消耗，见[积分会员与无限卡区别.md](积分会员与无限卡区别.md)。
