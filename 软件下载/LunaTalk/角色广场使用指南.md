## 一、广场的榜单分类

广场首页按榜单与题材把角色分成十几类，常见的有：

| 分类 | 里面是什么 |
| --- | --- |
| 男神榜 / 女神榜 | 人气最高的男性、女性角色 |
| 总榜 / 周榜 / 月榜 / 上月榜 | 按总热度与发布时间排列的角色 |
| 有奖主题 | 参加官方征稿活动的角色 |
| 模拟系统 | 模拟器、系统流玩法类角色 |
| 原创角色 | 作者原创设定 |
| 游戏动漫 / 影视小说 | 同人改编角色 |
| 互动故事 | 有主线剧情的角色 |
| 历史人物 | 历史人物向角色 |
| 功能助手 | 偏工具属性的助手型角色 |

官方精选里还有两个榜单：「作者榜」是人气角色卡作者的排行；「世界榜」是热门角色卡合集的排行（官方标注世界功能尚未完成，群聊功能以后才有，目前只作合集展示）。

## 二、按标签和关键词搜索

广场顶部有搜索栏，可以按标签找，比如：世界、西幻、东幻、修仙、武侠、现代、都市、游戏、校园等。标签远不止这些，以应用内实际列表为准。

搜索有个实际的坑：**关键词是每个作者自己写的，同一意思写法不统一**。搜不到想要的内容时，换近义词再试（比如「老师」搜不到就试「教师」），或者把关键词缩短到一两个字。

## 三、角色卡详情页看什么

在广场点开任意角色的头像进入详情页，值得先看的几处：

- **名字与头像**：进入详情的入口；
- **作者**：点作者名可以看他写过的其他角色卡；
- **简介与开场白**：简介交代背景设定，开场白是角色对你说的话，也决定剧情从哪里开始；
- **聊天次数与粉丝数**：间接反映这张卡的人气。

详情页下方还有几项功能设置：聊天设置（只对本卡生效）、模型选择、永久记忆与自动语音（这两项是会员权益，见[积分会员与无限卡区别.md](积分会员与无限卡区别.md)）。

## 四、挑角色的实用判据

- 先读开场白：开场白写得细的卡，后续对话的起点通常更顺；
- 看粉丝数与聊天次数：两个数都高的卡，一般不容易写崩；
- 点进作者主页：作者名下多张卡质量稳定的话，他的新卡也值得顺手关注；
- 看简介有没有写清背景与规则：没写清的卡，聊起来要靠自己补设定。

## 五、关注与发布

喜欢某张卡可以关注作者或角色，方便下次直接找到。自己写了角色卡也可以发布到广场给别人用，写法与发布路径见[自建角色与发布教程.md](自建角色与发布教程.md)；挑好角色之后怎么调对话，见[对话与聊天设置详解.md](对话与聊天设置详解.md)。
