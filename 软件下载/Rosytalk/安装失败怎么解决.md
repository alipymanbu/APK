# Rosytalk 安装失败怎么解决

> 这篇只处理「点了安装没反应 / 提示应用未安装 / 解析包出错」这类报错，按报错对照着查。

## 一、先看你撞上的是哪一种

安卓侧装 APK 的报错基本就那几类，先对号入座（报错原文与截图以你手机实际显示为准）：

| 报错表现 | 最常见的原因 | 先做什么 |
| --- | --- | --- |
| 「禁止安装来自此来源的应用」 | 没给当前来源开安装权限 | 按提示去开「安装未知应用」权限（见 [下载与安装教程.md](下载与安装教程.md) 第四节） |
| 「解析包时出现问题」 | APK 下载中断、文件不完整 | 删掉本地这份重新下载，下完先核对 MD5 |
| 「应用未安装」 | 空间不够 / 与已装版本签名冲突 | 清出 1~2GB 可用空间；若手机上已有旧版（含商店版），先卸载再装 |
| 「与设备不兼容 / 版本过低」 | 手机系统低于安装包要求 | 本包记录的最低要求是安卓 5.2，低于它就换设备或用商店版 |
| 装到一半弹「风险提示 / 已拦截」 | 系统安全扫描（如 Play Protect）拦了非商店来源 | 按提示选「仍要安装」；不确定时先核对 MD5 再决定 |
| 提示「版本降级 / 无法降级」 | 手机上已装了更新的版本 | 安卓不允许直接装更低版本：先卸载高版本再装这份（会丢本地数据） |

## 二、按顺序排查（通用五步）

1. **看空间**：设置 → 存储，确认可用空间至少 1~2GB（安装需要解压空间，约为 APK 体积的 2~3 倍；这份包 72.26M，但安装过程要的远不止这个数）。
2. **重下安装包**：删掉现在的 APK 重新从网盘下，别用传了多次、改过后缀的文件；下完用 [下载与安装教程.md](下载与安装教程.md) 第二节的 MD5 核一遍。
3. **卸载旧版再装**：只要手机上装过 Rosytalk（不管哪个渠道装的），签名不一致就会报「应用未安装」—— 先卸载，再点这份 APK。注意：卸载会清掉本地应用数据，聊天记录若没同步到账户就找不回了（是否同步见 [角色聊天功能怎么用.md](角色聊天功能怎么用.md) 第三节）。
4. **重启再装**：重启手机，重新打开文件管理器点击 APK。
5. **换安装入口**：换个方式打开同一个文件 —— 浏览器下载的用文件管理器装，文件管理器装不动就换浏览器下载后再装。

## 三、还装不上就换一条路

五步都走完仍然失败，说明这台设备和这个包过不去（系统版本、厂商限制、芯片架构都可能），别死磕：直接改用 Google Play 商店安装（搜 Rosytalk，包名 `com.rosytalk.ai`），商店会自动适配你的机型；或者到 [下载与安装教程.md](下载与安装教程.md) 第五节看官网的下载入口。

## 四、装上了但打不开、闪退

装完点了没反应、打开就闪退，按手机厂商通用的排查顺序来（各品牌菜单名略有差异）：

1. **强停重开**：设置 → 应用 → Rosytalk → 强行停止，再重新打开。
2. **清缓存**：同一个页面进「存储」，先只清缓存（清数据会删本地记录，放在最后一步）。
3. **查权限**：确认麦克风、存储等权限没被禁用 —— 部分机型权限被拒会导致功能异常甚至闪退。
4. **看系统与存储**：把系统更新到最新；可用内存不足（剩余不足两成）也会引发闪退，先腾空间。
5. **切网络试**：Wi-Fi 换流量再开一次，排除网络侧拦截。
6. **卸载重装**：以上都无效再走这步，重装前确认聊天记录已随账户同步（见 [角色聊天功能怎么用.md](角色聊天功能怎么用.md)）。

仍闪退就是包与这台机型不兼容，换商店版（见 [下载与安装教程.md](下载与安装教程.md) 第五节）；登录环节报错不再走这条链，见 [账号注册与登录报错排查.md](账号注册与登录报错排查.md)。
