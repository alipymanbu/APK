## 一、一局是怎么走的

Akinator 的玩法只有一件事：你心里定一个真实或虚构的角色，它提问、你作答，它靠你的回答一轮轮缩小范围，最后给出一个名字让你确认。整套动作没有操作门槛，真正决定结果的是「你有没有提前想清楚」和「答得是否如实」。

一局的标准顺序是：

1. **先定角色**。开始之前就想好，并且中途不换人——换人会让你前面几题的答案互相矛盾，后面再怎么答也拉不回来。
2. **点「挑战我」**，选主题（人物 / 电影 / 动物 / 物体）。
3. **逐题作答**。每题从下面列出的几个选项里挑一个，答完自动跳到下一题。
4. **它给出猜测**。屏幕上会显示一个名字，让你确认是不是这个人。
5. **确认或否认**。猜对了这一局就结束；猜错了告诉它不是，它会继续问。
6. **收尾**。要么它猜中，要么它放弃、让你自己把想要的角色名字输进去。

题量并不固定。**通常十几个到二十几个问题之间就会给出第一个猜测**；角色越冷门，问题数越多，猜不中也很正常，这属于这套玩法本身的特性，不是版本出了问题。公开资料里常把它类比成「20 个问题」（20 Questions）那一类猜谜游戏，这是个概括性的说法，不是固定题数——想专门让它失手，办法另开一篇，见 [怎么难住灯神.md](怎么难住灯神.md)。

## 二、五个回答分别在什么时候选

中文界面下的选项大致是「是 / 否 / 不知道 / 大概是 / 大概不是」，不同语言版本用词略有差别，含义是对应的：

| 回答 | 含义 | 什么时候选 |
| --- | --- | --- |
| 是 | 确定符合这个问题 | 你对这个属性有把握时 |
| 否 | 确定不符合 | 你对这个属性有把握时 |
| 不知道 | 无法判断 | 你本来就不清楚这个细节时 |
| 大概是 | 偏向符合，但不完全确定 | 印象里像，但拿不准时 |
| 大概不是 | 偏向不符合，但不完全确定 | 印象里不像，但拿不准时 |

**中间那三个选项是给「拿不准」准备的，别把它们当摆设。** 对这个角色的某个属性没把握时，选「不知道」一般比硬选一个方向更稳妥：一个选错的属性会把后面几轮的提问方向带偏，而「不知道」相当于把这一条先放过去，让它在别的属性上继续缩小范围。

## 三、怎么答才更容易被猜中

1. **挑有公开身份的角色。** 名人、影视动漫角色、公众人物这类都可以。只对你自己或小圈子里的人有意义的称呼不在它的库里，考它没有意义——官方对角色库的规则说得很清楚，只接受公众人物。
2. **如实答，不要为了难倒它而乱答。** 故意给假信息，它会在几题之内跑偏，最后给出一个完全不沾边的名字，问题出在答案而不是它。
3. **前后一致。** 同一局里对同一个属性给互相矛盾的回答，等于把前面的推理作废。
4. **接受冷门角色猜不中。** 你选的角色越边缘，它需要的问题越多、给出正确答案的概率越低。想验证它准不准，先用一个大众角色试一局。

## 四、发现自己答错了：退回去改

部分版本的界面在题目下方提供「修正」这类入口，可以退回上一题，把答错的选项改掉再继续。点错一个关键属性又不改，后面几题会沿着错误的方向问下去，最后的结果往往离你心里那个人很远。

修正入口的位置和叫法各版本不完全一样，一般在作答按钮的相邻位置，找不到时按当时界面上的提示操作即可。

## 五、它猜错或猜不中时能做什么

- **猜错了**：直接告诉它不是，它会接着问下一轮。问题问到一定数量仍然没有结果时，它会请你把心里那个名字输进去。
- **输名字之后有两条路**：如果库里有相似的角色，它会列出候选让你挑；确实没有，你可以把这个角色提交进它的数据库。
- **提交有硬规则**：只接受公众人物，你和朋友之间才知道的角色即使提交了也不会通过；提交内容还要经过审核，不会立刻出现在库里。官方 FAQ 里对「添加人物」「添加问题」「上传图片」三项都写了要审核。
- **图片和问题也能补**：游戏结束时可以给角色推荐新名字、推荐图片，或者补充一个问题，同样要过审核这一关。

## 六、让它猜你的朋友和家人：MyWorld 玩法

手机端还有一个网页版没有的玩法，官方的叫法是 MyWorld（官方中文下载页写作「我的世界体验」）。它把「猜名人」换成「猜你身边的人」：你把亲友收进自己的图库，让灯神去猜他们。官方对它的说明里特别提到一点——即使你自己没在玩，**把手机递给朋友接着玩，也能让他们参与进来**。

两条边界值得先说清：

- **亲友走的是 MyWorld 这条线，不进公共角色库。** 官方 FAQ 明确写了，公共库里只接受公众人物，私人角色不能提交。所以别指望把朋友的名字塞进公共库、让所有玩家都猜得到。
- **各版本的入口和叫法不完全一样。** 有的版本放在主界面，有的在设置或个人页里；找不到时以应用内当时的入口为准。

## 七、玩之前值得知道的三条边界

**第一，全程联网。** 提问和角色库都在线上，断网时打不开、进不去都是正常的网络表现，不是应用坏了。排查方式见 [常见问题与排查.md](常见问题与排查.md)。

**第二，结果不一定全年龄适宜。** 应用商店对它的年龄分级标在 12+ / 13+ 一档（不同商店与地区的标注不一样，以你看到的那个商店页面为准），库里也包含成人向的角色内容。带小孩玩之前，先在设置里打开内容过滤——官方管它叫 child filter（儿童过滤），这项功能官方自己也列在功能表里。

**第三，基础玩法之外还有一层进度体系。** 每日挑战、Aki 奖、荣誉殿堂、Geniz 点数这些是手机端才有的；它们怎么拿、怎么攒，另开一篇讲，见 [每日挑战和Aki奖怎么拿.md](每日挑战和Aki奖怎么拿.md)。界面还没换成中文的话，先看 [界面语言怎么切换成中文.md](界面语言怎么切换成中文.md)。
