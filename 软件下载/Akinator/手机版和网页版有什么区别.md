## 一、一句话结论

同一个游戏、同一家开发方，两个入口。网页版打开就能玩、不用装，但玩法最精简；手机端多了电影主题、账号进度和每日挑战这一层。想长期玩、在意记录，就用手机端；只想随手玩一局，网页版完全够用。

## 二、主要差在哪

| 对比项 | 手机应用 | 网页版 |
| --- | --- | --- |
| 怎么开始 | 先装应用 | 浏览器打开就能玩 |
| 可选主题 | 人物、电影、动物、物体 | 一般只有人物、动物、物体 |
| 账号与进度 | 可注册账号，Aki 奖与 Geniz 跟账号走 | 与手机端账号不通用 |
| 奖励玩法 | 每日挑战、Aki 奖、荣誉殿堂 | 通常没有这一层 |
| 独有玩法 | 另有 MyWorld（官方中文页写作「我的世界体验」）这类手机端玩法，可以把它猜出的亲友收进自己的图库 | 没有 |
| 广告 | 免费版带广告；官方内购的药水项目（商店页写作「高级药水」或「终极药水」）会移除广告并解锁更多角色 | 页面上有广告位 |
| 语言 | 应用商店标注 17 种（含中文） | 按站点语种提供，官方有分语种的入口 |
| 是否联网 | 必须 | 必须 |
| 版本 | 装完是固定版本，要自己跟进更新 | 每次打开都是服务器当前版本 |

表里的功能划分来自官方商店页说明与公开资料的整理，各项可能随版本调整，具体以你打开时看到的为准。

## 三、网页版从哪进

官方按语言分了站点，常用的两个入口：

- 中文站：[cn.akinator.com](https://cn.akinator.com/)
- 英文站：[en.akinator.com](https://en.akinator.com/)

另有面向手机浏览器的移动网页版 `https://us.akinator.mobi/`，手机上不想装应用时可以用它。站点地址以官方当前提供为准。

除手机应用和网页版这两条线之外，本文不介绍其它客户端；在电脑上想玩，用上面这些网页入口即可，不必去找来路不明的所谓电脑版。

## 四、什么场合用哪个

| 你当时的情况 | 用哪个 |
| --- | --- |
| 第一次想试试这是什么 | 网页版，不用装 |
| 想拿每日挑战、Aki 奖，攒点数换精灵外观 | 手机端 |
| 换手机想把成绩带走 | 手机端 + 注册账号 |
| 和朋友凑在一起随手猜几局 | 两边都行，界面小的用手机端更方便 |
| 手机上不想多装一个应用 | 移动网页版 |
| 电脑前临时玩一下 | 网页版 |

手机上想装一个的话，安装文件资源在 [Akinator 安装文件资源（夸克网盘）](https://pan.quark.cn/s/63e9b6f8055e)，装法见 [下载与安装教程.md](下载与安装教程.md)。

## 五、两个常见的误解

**「网页版登录手机端账号就能同步进度」——不成立。** 公开资料里对这一点说法一致：网页端不与手机端账号打通，Aki 奖、Geniz 这类记录只存在手机端账号里。要在不同手机之间搬成绩，靠的是手机端账号，不是网页版。以官方页面当页说明为准。

**「网页版是精简版，所以猜得不准」——不对。** 两个入口背后是同一家开发方的同一套猜人机制，差别主要在可选主题数量、有没有奖励体系和界面形式上，不在准确度上。真觉得猜不准，先回头检查自己是怎么答的，见 [怎么玩和答题技巧.md](怎么玩和答题技巧.md)。

## 六、两个入口的共同点

- **都必须联网。** 官方明确写了 Akinator 需要互联网连接才能使用，网页版和手机端在这一点上一样，断网都玩不了。
- **都靠你自己先定好角色。** 中途换人、故意乱答，在哪个入口都会跑偏。
- **猜不中时都能补救。** 两个入口都允许继续追问，也都可以在你给出名字之后把它提交进库里；提交规则同样是只收公众人物、需要审核。
