## 一、先说清这份包是哪一个版本

Akinator 是一款猜人物的问答游戏：你心里定一个真实或虚构的角色，它用一连串是非题把范围一步步收窄，最后说出你心里想的那个人是谁。开发者是法国的 Elokence SAS，中文环境里它常被叫作「网络天才」。装它本身没有难度，容易卡住的只有两处——安装包从哪来，以及第一次进游戏时的语言选择。

动手之前，先对着下表确认手上这一份是不是对的：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | Akinator |
| 开发者 | Elokence SAS |
| 包名 | com.digidust.elokence.akinator.freemium |
| 版本号 | 9.1.16 |
| 安装包大小 | 66.06 MB |
| 安装包 MD5 | 2b0adfe6a268534d462d3d1e235c45de |
| 是否需要联网 | 全程联网；提问和角色库都在线上，没有网络进不去 |

**包名里带 `freemium` 的是免费含广告的那一份。** 官方渠道上另有一个付费包（`com.digidust.elokence.akinator.paid`），同一个游戏、不同的售卖形式，玩法内容一致。你从应用商店搜到的可能是其中任意一个，认准包名比认图标可靠。

**版本号以你手上这份为准，别拿搜索结果里的数字来对。** 你在第三方站点看到的 Akinator 版本号，大多是官方当前最新版，和这份 9.1.16 未必相同，各站标注的安装包大小也互相打架。判断「我装的对不对」只看两项：包名是不是上表那一个，版本号是不是 9.1.16。

**这里不写死最低安卓版本。** 各家第三方页面标注的系统要求从安卓 5.2 到更高都有，互相矛盾，不是官方口径。省事的判断办法是：先在手机上打开应用商店里的 Akinator 页面，如果显示「此应用与你的设备不兼容」，那就是装不上；能点「安装」，说明你的系统版本够用。真不兼容时系统会自己拦下来，不会装到一半坏掉。

**安装包大小不等于装完占用。** 上表的 66.06 MB 是下载体积；装到手机上之后，解压出来的内容加上运行产生的缓存，实际占用会比它明显大。装之前，手机上至少按安装包大小的两三倍留出空闲空间。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享。相比在搜索结果里随手点一个「立即下载」，从网盘转存再下载的好处是：链接是固定的，文件不会被下载站中途替换成别的东西，转存到自己账号之后，也不受原分享是否还在的影响。

1. 在手机上打开 [Akinator 安装文件资源（夸克网盘）](https://pan.quark.cn/s/63e9b6f8055e)。手机浏览器或夸克 App 都能打开，**建议用夸克 App**——浏览器下大文件容易被切后台打断。
2. 点「保存到我的网盘」，把文件转存到自己账号下。
3. 进自己的网盘找到这个文件，点下载，等它落到手机存储里。
4. 下完核对两件事：文件名结尾是不是 `.apk`；大小是不是 66.06 MB 左右。差得多的，多半是没下完整，删掉重来。

如果你更习惯在电脑上操作：在电脑端网盘下载下来，再用数据线拷到手机的 `Download` 目录，效果一样；之后从手机的「文件管理」里点它安装即可。

手上有校验工具的话，可以顺手算一遍 MD5，和上表的 `2b0adfe6a268534d462d3d1e235c45de` 比一比。一致说明传输过程没出错，不一致就重新下一遍。不查也不影响安装，这只是多一层保险。

## 三、安装：系统会拦一次，放行即可

这一份是通过网盘分发、手动安装的，不是从手机自带应用商店点「安装」装的，所以点安装包时系统会拦一下，提示「不允许安装来自此来源的应用」之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开「文件管理」，进 `Download`（下载）目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要去「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独给它放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时，先点「完成」。第一次启动时一次性把语言理顺，比进去之后再翻设置省事。

## 四、第一次打开：先联网，再选语言和主题

打开之后不会直接问你是不是要开始，而是先过两三步铺垫。按下面顺序走：

1. **先确认手机连着网。** Akinator 官方自己写明了它需要互联网连接才能用，提问、角色库、结果都在线上；飞行模式或断网时进不去是正常现象，不是装坏了。
2. **选语言。** 首次进入会列出可选语言，**列表要往下滑才能看到「中文」**——官方在应用商店的说明里专门提醒过这一点，别以为列表第一屏没有就是没有。这一步选错，后面看到的会是别的语种的界面；进游戏之后也能改，做法见 [界面语言怎么切换成中文.md](界面语言怎么切换成中文.md)。
3. **选主题。** 手机端除人物外还提供电影、动物、物体几类。第一次玩选「人物」最直接，心里想的角色最好是有名有姓、别人也认识的公众人物或知名虚构角色，命中率明显更高。
4. **点「挑战我」。** 点之前先把角色定下来，中途换人会明显影响结果；完整的答题思路见 [怎么玩和答题技巧.md](怎么玩和答题技巧.md)。

## 五、装不上、打不开时按这张表走

| 现象 | 多半是什么 | 先做什么 |

## 六、升级与卸载要注意的

- **升级**：这一份是网盘里的固定版本，装完不会跟着官方自动升级。想要新版本，从官方应用商店更新，或等网盘里换上新的安装包重新装；换包直接覆盖安装即可，一般不用先卸载。
- **卸载**：卸载会清掉本机的数据。Aki 奖、Geniz 点数这类记录只有注册过账号才会跟账号走，登录同一账号还能取回（做法见 [每日挑战和Aki奖怎么拿.md](每日挑战和Aki奖怎么拿.md)）；从没注册过账号的话，卸载等于清零。
- **安装包删了**：不要紧，文首那条 Akinator 安装文件资源的链接随时能再取一份；已经转存过的，不受原分享是否失效的影响。
