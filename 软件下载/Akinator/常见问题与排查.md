## 一、进不去、一直转圈、提示网络问题

Akinator 全程联网，官方自己也写明它需要互联网连接才能使用。所以「打不开」「一直转圈」「提示检查网络连接」这三类现象，先按网络问题查，不要急着卸载重装——重装并不能解决线路的问题。

1. **换一次网络**。Wi-Fi 和移动数据互相切换，看是不是只在某一种网络下出问题。
2. **关掉 VPN、代理或加速器再试**。这是很常见的一类原因：这类工具改变出口线路之后，应用连不上服务器的情况不少见。
3. **完全退出应用再打开**。从后台任务里把它划掉，不是按返回键退到桌面。
4. **重启手机**，把卡住的网络状态清掉。
5. **换个时间再试**。服务器短时不可用或临时维护时，你这边做什么都没用，等一会儿通常会自己恢复。

## 二、打开就闪退、白屏，或题目卡住不动

按代价从低到高试，前两步不会动你的数据：

1. **清应用缓存**。安卓上的位置是「设置 → 应用 → Akinator → 存储 → 清除缓存」，只清缓存不会删账号数据。
2. **核对安装包是不是完整的**。文件大小对不对，见 [下载与安装教程.md](下载与安装教程.md) 里那份包的信息表；没下完整是闪退的常见原因。
3. **卸载重装**。注意卸载会清掉本机数据，动手前先确认账号已注册并处于登录状态，否则 Aki 奖、Geniz 会一起消失（见第四节）。
4. **系统版本过旧**。在应用商店的 Akinator 页面上看是否显示兼容，不兼容就是这个原因，没有别的办法绕过去。

题目停在同一道不往下走、或者同一道题反复出现，也是同一类问题：多半是本地会话数据卡住了。先完全退出应用重开，不行再清一次缓存。在网页版上遇到同类现象，就清掉该站点这一个域名下的缓存与 Cookie 再重新打开，不要动整台浏览器的数据。

## 三、猜得不准、总是猜错

多数情况不是应用的问题，而是答题方式。按顺序自查：

1. 这一局中途是不是换了人？换人会让前后答案互相矛盾。
2. 拿不准的题是不是硬选了「是」或「否」？这类题应当选「不知道」。
3. 你选的角色是不是太小众？冷门角色猜不中是常态，不是版本缺陷。
4. 上一题是不是点错了却没退回修正？

完整的答题思路与修正入口见 [怎么玩和答题技巧.md](怎么玩和答题技巧.md)；如果你要的就是「让它猜不中」，那是另一套选角色的思路，见 [怎么难住灯神.md](怎么难住灯神.md)。

## 四、账号和成绩：换手机怎么带走

- 应用内可以创建账号。官方说明是：注册之后，你赢到的 Aki 奖和 Geniz 余额会被记录下来，换设备也能同步。
- 从没注册过账号的，记录只存在本机，卸载或换机就没了。打算长期玩，先把账号建了再看别的。
- 换手机的顺序：旧机确认处于登录状态 → 新机装同款应用 → 登录同一账号。
- 登录不上：先按第一节排网络；用第三方账号登录时，先确认那个平台自己能不能正常登录。
- 奖项、点数的完整说明见 [每日挑战和Aki奖怎么拿.md](每日挑战和Aki奖怎么拿.md)。

## 五、广告、付费项目和「是不是装错了」

- **免费版带广告是官方的设计**，不是装错了。包名里带 `freemium` 的那一份就是免费版，官方渠道另有一份付费包，同一个游戏、不同售卖形式。
- 应用内有官方付费项目，其中一档是药水（商店页写作「高级药水」或「终极药水」，英文 Premium Potion / Ultimate Potion，各版本译名不同），按官方说明会移除应用内广告、解锁更多角色，并允许你自定义精灵形象；此外还有点数和装扮相关的购买项。
- 这些只能通过官方渠道的应用商店完成，价格与项目名称以你所在商店页面当时显示为准。
- 网盘里这一份是免费版，账号功能和官方付费项目的入口都在它里面，不需要另外装别的东西。
- **不要从官方商店之外的渠道拿安装包**。来源不明的包可能因为签名对不上而装不上，也可能装上了却登不进账号，解决不了任何问题。

## 六、中文界面找不到

最常见的原因是**没有把语言列表滑到底**——官方在应用商店的说明里专门提醒过这一点，先把这一条排除掉。其余三种情况按下面的对照表处理：

| 现象 | 处理 |
| --- | --- |
| 改完语言界面没变 | 退回主界面再进一次；还是老样子就完全退出应用重开 |
| 语言列表缺项、少了好几种 | 装的可能是来源不明的旧包；换成官方应用商店的当前版本，或按 [下载与安装教程.md](下载与安装教程.md) 重新取一份安装资源 |
| 怀疑被系统限制 | 检查手机上的家长控制、应用限制里有没有针对 Akinator 的限制项，以及有没有语言相关的限制 |

上面几条都排除了还是找不到中文，就到官方站点 [cn.akinator.com](https://cn.akinator.com/) 上找官方给出的常见问题与联系入口反馈，并说明你的机型和语言列表里缺的是哪几项。

## 七、安装包报错与设备不匹配

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 安装时提示「解析包出错」 | 安装包没下完整 | 回网盘重下，核对大小 |
| 提示「应用未安装」 | 机器上已有同名应用、签名冲突 | 先卸掉旧的再装 |
| 装到一半失败 | 手机存储空间不足 | 清出空间再装 |
| 网盘链接打不开了 | 原分享失效 | 已经转存过的不受影响；没转存的重新取一份：[Akinator 安装文件资源（夸克网盘）](https://pan.quark.cn/s/63e9b6f8055e) |
| 苹果设备装不上 | 这份是安卓安装包 | iPhone / iPad 用 App Store 里的版本 |

## 八、以上都不管用的时候

先分清是「普遍问题」还是「只有你这边」：换一个网络、换一台设备试同一件事。只有你这台机器出问题，多半是本机环境（存储、权限、系统版本），而不是应用本身。

记录现象时抓重点：在哪一步、屏幕上是什么提示、什么机型和系统版本。这样去官方渠道提问，比只写一句「打不开」有用得多。「官方渠道」指的就是官方站点本身——它的常见问题与联系入口都在 [cn.akinator.com](https://cn.akinator.com/) 上，先在那一层找。

另外，网盘里那一份是固定版本，官方渠道当前版本可能已经修掉了你遇到的问题——这也是「先升级再试一次」经常有效的原因。
