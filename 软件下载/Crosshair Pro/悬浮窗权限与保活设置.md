## 一、悬浮窗权限怎么开

Crosshair Pro 的准星是叠加在游戏画面上方的悬浮层，安卓把这类能力单独做成一个权限，默认是关闭的：

1. 打开手机「设置」，进入「应用管理」（部分系统叫「应用与权限」）；
2. 找到 Crosshair Pro，进入「权限管理」；
3. 开启「显示在其他应用上层」（小米叫「显示悬浮窗」，华为叫「允许悬浮窗」）；
4. 回到应用重新启动一次，确认准星能出现在桌面上，再进游戏。

首次启动 Crosshair Pro 时它一般会主动弹出这个权限的申请页，直接跳转授权也可以。

## 二、为什么准星会「用着用着消失」

国产安卓系统对后台进程很激进：你切进游戏后，系统可能为了省电把 Crosshair Pro 的后台进程清掉，悬浮层随之消失。所以除了悬浮窗权限，还要做两件事：

- **锁后台**：打开最近任务（多任务）界面，长按 Crosshair Pro 的卡片，点锁形图标（部分系统是下拉卡片锁定）；
- **关电池优化**：在应用信息页的「电池」里，改成「不受限制」或「不允许优化」。

不同品牌的路径差别不小，按下面这张表对号入座：

| 品牌 / 系统 | 要做的事 |
| --- | --- |
| 小米 / 红米（MIUI / HyperOS） | 开「显示悬浮窗」；「自启动」设为允许；最近任务里锁定卡片 |
| 华为 / 荣耀（HarmonyOS / EMUI） | 开「允许悬浮窗」；电池优化改为「不允许优化」；启动管理改成手动管理并允许后台活动 |
| OPPO / vivo（ColorOS / OriginOS） | 手机管家里开悬浮窗权限；开「允许关联启动」；最近任务锁定 |
| 三星（One UI） | 开「出现在顶部」权限；电池设为「不受限制」（白名单） |
| 其他原生类系统 | 授权「显示在其他应用上层」即可，一般不需要额外保活 |

## 三、准星不显示的排查顺序

进游戏看不到准星时，按这个顺序查，多数在前两步就能解决：

1. **权限层面**：悬浮窗权限是否真的打开了（重装应用后权限会被重置，很多人栽在这里）；
2. **后台层面**：按第二节的保活设置核对一遍，尤其电池优化那一步；
3. **开关层面**：回到 Crosshair Pro 主界面，确认准星开关是开启状态，选中的样式落屏了没有（部分 Pro 样式要先看完视频才落屏，详见[常见问题解答](常见问题解答.md)的视频解锁条目）；
4. **游戏层面**：游戏是否以全屏/沉浸模式运行——个别游戏的全屏模式会盖住普通悬浮层，可以在 Crosshair Pro 里尝试重新落一次准星；
5. **冲突层面**：如果手机上还装着别的悬浮窗类工具（录屏悬浮条、通知弹窗工具等），先关掉它们再试，悬浮层之间会互相抢占。

## 四、两个容易误触的点

- 准星悬浮层的位置是可以拖动的，进游戏后手指从它附近划过可能把准星拖偏；调好坐标后尽量从准星以外的区域起手操作，或在校准完成后直接锁定位置（如果应用内提供该选项）；
- 部分系统的「游戏模式 / 游戏助手」会拦截或收纳悬浮窗，若准星在特定游戏里总消失，去游戏助手的悬浮窗设置里给 Crosshair Pro 放行。
