## 一、准星看不清的四种常见原因

按出现频率排，对着自查：

| 原因 | 典型表现 | 处理方向 |
| --- | --- | --- |
| 透明度调得太低 | 准星若有若无，换个场景就更找不到 | 透明度拉回 70%~90% 区间 |
| 准星颜色和地图撞色 | 白色准星进雪地图就消失 | 换高对比颜色，或加描边 |
| 样式太细太小 | 远距离时根本看不见线 | 加粗线条、放大尺寸 |
| 游戏画面过亮或过暗 | 亮图看不清浅色、暗图看不清深色 | 选中间亮度颜色 + 黑色边框 |

有第三方评测专门提到过这款应用的已知短板：**部分准星样式在特定背景下会显得过透、不易辨认**，即使把可见度调到较高档也可能出现。遇到这种样式，直接换一个更实心的，比反复调参数更快。

## 二、颜色怎么选：跟地图走

准星颜色的唯一标准是「和当前画面拉开距离」，按地图类型选：

| 地图类型 | 避开的颜色 | 推荐颜色 |
| --- | --- | --- |
| 雪地、亮色城市 | 白、浅灰、浅黄 | 亮绿、青色、品红 |
| 沙漠、土黄场景 | 黄、橙、沙色 | 青色、亮绿 |
| 夜图、暗色室内 | 深蓝、黑、深紫 | 白色、亮黄、青色 |
| 混合地图（进进出出） | 任何单色都可能撞 | 中间亮度色 + 黑色描边 |

红绿色觉异常的用户留意：红/绿这组最常见的准星配色可能都不明显，青色（cyan）和品红（magenta）是更稳的选择。

## 三、边框与尺寸的组合拳

- **加黑色边框**：给准星加 1~2 像素的深色描边后，浅色准星在雪地、沙漠里的辨识度会明显提高——深色边框负责「圈住」准星，浅色主体负责「亮出来」；
- **尺寸往大调一档**：如果你不是嫌准星挡目标，而是经常「找不到准星在哪」，说明它小了，先放大一档再看；
- **换成点样式**：细十字线在小屏幕上容易断续，实心圆点没有这个问题，找不到线的场合换点往往立竿见影。

调参入口和各参数的完整说明在[准星样式与参数设置](准星样式与参数设置.md)的参数表里，这里不重复。

## 四、视力不佳的玩家：一套醒目起点配置

这款应用的官方介绍里明确写了它是为「视觉上有困难的玩家」设计的，可以给更大的准星。如果你看普通准星吃力，不用从小配置慢慢试，直接按这套起步：

| 参数 | 起点 | 说明 |
| --- | --- | --- |
| 样式 | 实心圆点或粗十字 | 形状越简单，越容易一眼定位 |
| 大小 | 明显大于默认值 | 判断标准：不用刻意去找，余光就能感知到它在哪 |
| 颜色 | 青色或亮黄 + 黑边框 | 对比度优先于美观 |
| 透明度 | 90%~100% | 先保证「看得见」，习惯后再降 |
| 位置 | 维持屏幕正中 | 移动准星位置会增加定位负担 |

用一阵子之后再逐步调小、调淡——参数会随适应程度变化，但「高对比 + 形状简单」这两条不要动。

## 五、调完还是时有时无

看不清和「干脆消失」是两个问题：如果准星一会儿在一会儿不在，或者进了游戏就没影，那是权限和后台的问题，不是参数问题，按[悬浮窗权限与保活设置](悬浮窗权限与保活设置.md)的排查顺序走一遍；装不上、打不开这类问题则回到[常见问题解答](常见问题解答.md)和[下载与安装教程](下载与安装教程.md)。
