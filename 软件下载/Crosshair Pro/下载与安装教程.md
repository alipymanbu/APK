## 一、装之前先核对这份安装包

Crosshair Pro 在不同应用商店上架的版本号并不一致（有的渠道还停留在 6.x、7.x 的编号，有的跳到 22.x），装的时候不用纠结商店页写的数字，**以你手里这份安装包的实际信息为准**：

| 项目 | 内容 |
| --- | --- |
| 版本 | 15.9 |
| 包名 | `com.customscopecommunity.crosshairpro` |
| 安装包大小 | 15.60M |
| MD5 | `4AA218CCC3A86DCDD7F1146DEAC4E604` |
| 系统要求 | 安卓 5.0 及以上（部分商店页面标注 7.1+，以安装时的实际提示为准） |

MD5 的用法：如果你对安装包的完整性有疑问，可以用校验工具算一下 MD5，和上表比对，一致说明文件没损坏、也没被调包。电脑上不用装任何工具，用 Windows 自带的命令行就能算——把 APK 拷到电脑上后，在命令提示符里执行（文件路径换成你自己的）：

```text
certutil -hashfile "C:\Users\你的用户名\Downloads\Crosshair Pro_v15.9.apk" MD5
```

输出的第二串十六进制就是 MD5，比对时忽略大小写。手机端的文件管理器多数不带 MD5 功能，建议拷到电脑上核对。

## 二、获取安装文件

1. 打开上面的 Crosshair Pro 安装文件资源（夸克网盘）链接（[https://pan.quark.cn/s/3b5d090b3101](https://pan.quark.cn/s/3b5d090b3101)），转存到自己的网盘后下载 APK 文件；
2. 下载完成后，在通知栏或文件管理器的「下载」目录里找到这个 APK。

手机浏览器直接下载 APK 经常会被安全提示拦一道，转存到网盘客户端再下载是最省事的路径。

## 三、安装步骤

1. 点击 APK 文件，系统会提示「禁止安装未知来源应用」，点「设置」进入对应页面，允许你所用浏览器或文件管理器「安装未知应用」；
2. 返回安装页，点「安装」，等进度条走完；
3. 点「打开」启动 Crosshair Pro，首次启动会依次请求权限（悬浮窗是核心权限，不给的话准星不会出现在游戏画面上）；
4. 按提示授完权限，回到应用主页选一个准星样式，就能进游戏看效果了。

首次启动那一步只给悬浮窗权限通常还不够，国产系统的后台管控也会把悬浮层掐掉——具体怎么设置，看[悬浮窗权限与保活设置](悬浮窗权限与保活设置.md)这一篇，小米、华为、OPPO/vivo 的路径各不相同。

## 四、装不上的对照表

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 下载不完整、文件损坏 | 重新下载一次，核对 MD5；多次失败就换网络再下 |
| 点安装后一闪而过 | 存储空间不足 | 清出至少 1GB 空间再装 |
| 提示「与已安装应用冲突」 | 手机里已有同包名的旧版本，且签名不同 | 先卸载旧的 Crosshair Pro 再装 |
| 安装按钮置灰 | 系统禁止了「安装未知应用」的来源 | 回到系统设置，给当前下载来源（浏览器/文件管理器）放行 |
| 装完打不开 | 系统版本过低 | 确认安卓版本 ≥ 5.0，个别渠道包要求 7.1+ |

先别急着进对局。推荐的顺序是：把准星样式和参数调好，再到训练场校准位置，最后才进实战——具体调法和校准步骤见[准星样式与参数设置](准星样式与参数设置.md)；使用过程中高频的问题（要不要 Root、会不会被游戏拦、掉帧怎么办）集中整理在[常见问题解答](常见问题解答.md)。
