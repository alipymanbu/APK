## 一、先分清两种"收不到"

- **一条通知都没有**：权限被拒，或 app 后台被系统杀掉了；
- **通知要迟到几分钟**：省电策略在延迟投递，验证请求有时效，等它到时早已过期。

两种都先确认手机网络正常（Wi-Fi 或流量至少通一个），再往下查。

## 二、通知权限：最常见的拦路虎

安装时要是点了"拒绝"，之后一条验证都收不到。安卓 13 起通知是运行时权限，首次启动会弹窗；当时拒了就到这里补：

- 系统设置 → 应用 → PingID → 通知 → 允许；
- 顺手检查具体通知渠道没有被单独关掉（有的系统允许按类别关闭）。

权限一直开着还是收不到，问题多半在下一节的省电策略。

## 三、安卓：省电与后台策略逐项排查

1. **电池优化改为"不受限制"**：长按 PingID 图标 → 应用信息 → 电池 → 选"不受限制"；
2. **允许后台流量**：省流量模式会把后台 app 的联网一起拦掉，把 PingID 加入不受限名单或关掉省流量；
3. **别用"强行停止"**：从设置里强停一个 app 后，安卓在你再次打开它之前不会投送任何推送——这是系统标准行为，任何 app 都绕不开。杀后台也同理，尽量用"锁定"代替清理；
4. **关闭休眠类开关**：部分系统有"暂停不活跃应用的活动"（app hibernation）选项，关掉对 PingID 的休眠；
5. **品牌专项**（菜单名称随品牌与系统版本有差异，以自己手机实际设置为准）：

| 品牌 | 要动的开关 |
| --- | --- |
| 华为 EMUI | 手机管家 → 应用启动管理 → PingID 改"手动管理"，自启动 / 关联启动 / 后台运行三项全开；同时把 Google Play 服务也设为允许自启并保持 Google 账号已登录（社区与推送服务商的排障指引都点名这两步） |
| 小米 MIUI / HyperOS | 给 PingID 开自启动；省电策略选"无限制"；最近任务里给 app 加锁 |
| OPPO / 一加 / realme | 电池优化里对 PingID 选"不优化"；允许自启动 |
| 三星 One UI | 电池 → 后台使用限制 → 确认 PingID 不在"休眠/深度休眠"名单，加入"从不休眠的应用" |

各品牌 killed-background 差异可参考 [dontkillmyapp.com](https://dontkillmyapp.com/) 的汇总。

## 四、iPhone：官方排障文档点名的四个开关

PingID 官方排障文档对 iOS 收不到通知明确列了这几项（设置路径以你的系统版本为准）：

- **定时推送摘要**：关闭，或把 PingID 移出摘要名单；
- **专注模式**：关闭，或把 PingID 加入允许的通知列表；
- **低数据模式**：设置 → 蜂窝网络 → 蜂窝数据选项 → 关闭；
- **低电量模式**：设置 → 电池 → 关闭——省电模式会限制 app 后台运行，推送会明显迟到。

顺带把 PingID 和 iOS 系统都保持更新，官方文档把"升级 app / 升级系统"也列进了排障步骤。

## 五、推送实在不来的兜底：OTP

验证请求不弹，直接打开 PingID——app 主界面就显示当前的一次性密码（OTP），把它输到登录页的验证框里即可。前提与细节见 [验证方式与一次性密码用法.md](验证方式与一次性密码用法.md)；配对环节的首次验证请求不来，处理方式相同（见 [设备配对与首次激活步骤.md](设备配对与首次激活步骤.md)）。权限、后台、网络都查过还是不行，联系组织 IT 查账号侧配置。
