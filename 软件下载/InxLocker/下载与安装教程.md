## 一、InxLocker 是什么

InxLocker 是一个 Xposed 模块，拦截安卓系统里的应用安装与卸载请求，并把它们转交给你指定的安装器处理。典型场景：手机是 ColorOS、MIUI 这类深度定制系统，点开 APK 只能用系统自带安装器，你希望换成自己喜欢的安装器，或者想在卸载时多一道确认 —— 这类需求都归它管。

要留意：它只在 Xposed 框架下工作。手机还没 Root、没装 Xposed 框架的话，先看 [Xposed框架环境准备.md](Xposed框架环境准备.md)。

## 二、下载与安装包信息

本文引用的 [InxLocker 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7c41f72f5c48) 里是 1.4 版安装包，转存到自己的网盘后即可下载。核对信息如下（以此包为准，官方可能有更新版本）：

| 项目 | 值 |
| --- | --- |
| 应用名称 | InxLocker |
| 版本 | 1.4 |
| 包名 | `io.github.chimio.inxlocker` |
| 安装包大小 | 4.07 MB |
| MD5 | `4138CC2583AC3F4B036AFBB6B9A7A888` |

下载后像普通 APK 一样安装即可；安装完成后桌面上会出现 InxLocker 图标。此时先别急着打开 —— 它还没激活，直接用不会有任何效果。

## 三、安装前的准备

| 需要什么 | 说明 |
| --- | --- |
| 已 Root 的安卓手机 | 解锁 Bootloader 并刷入 Root 方案（Magisk、KernelSU 等），各机型步骤不同，按你的机型搜对应教程 |
| Xposed 框架 | 推荐 LSPosed（需要 Magisk 的 Zygisk 开关已打开） |
| 系统版本 | 安装包标注 Android 5.2 以上；实际可用性以你所用 Xposed 框架的系统要求为准（例如 LSPosed 官方要求 Android 8.1 及以上，以其发布页为准） |

环境没就绪就装模块，现象是「装上了但一点反应都没有」，这是最常见的白忙场景。

## 四、在 LSPosed 里激活模块

1. 安装好 InxLocker 的 APK。
2. 打开 LSPosed 管理器，进入「模块」列表，找到 InxLocker，打开启用开关。
3. 点进 InxLocker 的作用域（Scope）设置，勾选两类对象：
   - **系统框架（System Framework）**—— 拦截系统级的安装分发，大多数场景必须勾；
   - 你希望做安装转发的具体应用（比如某个总在后台静默装东西的应用）。
4. 重启系统（或者至少重启被勾选的应用）。

改作用域之后必须重启对应进程才生效 —— 只勾了新应用没重启，那个应用里的安装请求不会被拦截。

## 五、验证模块是否生效

激活并重启后，随便装一个小体积 APK：如果弹出来的是你在模块里设置的目标安装器，而不是系统默认安装器，说明链路已经通了。第一次使用时打开 InxLocker 应用，在「默认安装器设置」里先选好目标安装器再测（配置方法见 [默认安装器设置与重定向配置.md](默认安装器设置与重定向配置.md)）。

如果测了没反应，按 [常见问题与使用注意.md](常见问题与使用注意.md) 第一节的排查清单逐项过一遍。

## 六、桌面图标隐藏后怎么打开

InxLocker 支持隐藏桌面图标。隐藏之后想改设置，不用重新安装：打开 LSPosed 管理器，在模块列表里点 InxLocker 就能直接进入它的设置界面。
