## 一、这份包是哪个版本

网盘里发出去的包与官方商店的最新版常常不是同一个版本，装之前先把手里这份的实际情况对清楚：

| 项目 | 值 |
| --- | --- |
| 应用名称 | MediBang Paint（官方系列名，安卓版同时支持平板与智能手机） |
| 版本 | 28.20 |
| 包名 | `com.medibang.android.paint.tablet` |
| 安装包大小 | 62.93M |
| MD5 | `dc098218cfecc56ad38aa85c725ebd7c` |
| 系统要求 | 安卓 8.0 及以上（官方系统需求页口径） |
| 信息核对日期 | 2026-09-22 |

版本号一直在往前走，检索时第三方应用市场的版本列表已到 28.25（**以官方页面当时显示为准**）。落后几拍不影响画画，判断标准是装上后功能是否正常；个别「装了才碰得到」的坑见 [常见问题与解决办法.md](常见问题与解决办法.md)。

包名里带 `tablet` 不代表手机装不了 —— 官方对这版产品的定位就是「同时支持平板与智能手机」，安卓端只是沿用了平板版的包名。

## 二、从哪拿安装文件

1. 打开 [MediBang Paint 安装文件资源（夸克网盘）](https://pan.quark.cn/s/177eca914d7b)，把里面的 APK 文件转存到自己的网盘；
2. 下载到要安装的设备上（手机、平板均可）；
3. 下载完先对一下：大小是不是 62.93M、MD5 是否与上表一致 —— 对不上说明文件在传输中损坏，重新下载再装。

也可以走官方渠道：Google Play 搜包名 `com.medibang.android.paint.tablet`，链接在 [play.google.com/store/apps/details?id=com.medibang.android.paint.tablet](https://play.google.com/store/apps/details?id=com.medibang.android.paint.tablet)；或者到官网 [medibangpaint.com](https://medibangpaint.com) 的 Android 版下载页拿官方直链 APK（版本与文件名**以官网当时显示为准**）。商店版和这份 APK 包名相同，是同一个应用的两个获取途径。

## 三、安装步骤

1. 在文件管理器里点开这个 APK。系统会拦一句「禁止安装未知来源应用」—— 这是装第三方 APK 的常规拦截，进设置给你用的文件管理器开「安装未知应用」权限即可（各品牌路径略有差别，一般在「设置 → 应用 → 特殊权限」里）。
2. 点安装等进度走完。装好之后占用的空间比安装包本身大，装之前留出至少两倍空间。
3. 装完点打开，先进的是 MediBang Paint 自己的作品库（不是直接进画布），新建一张画布就能开始画 —— 界面怎么摆、画布怎么建，见 [界面与画布入门.md](界面与画布入门.md)。

## 四、装不上时按报错对号入座

| 报错/现象 | 原因 | 动作 |
| --- | --- | --- |
| 「解析包时出现问题」 | 包没下完整或传输中损坏 | 对照第一节核对 62.93M 与 MD5，不符就重新下载 |
| 「应用未安装」/签名冲突 | 设备上已装商店版，签名与这份不一致 | 先卸载商店版再装；卸载前先导出作品，见第六节 |
| 安装按钮点不动、直接失败 | 存储空间不足，或系统版本低于要求 | 清出空间；系统低于安卓 8.0 的设备装不了这一版 |
| 安装中提示「风险应用」 | 国产系统对非商店 APK 的通用提醒 | 确认来源后选择继续安装 |

## 五、装商店版还是装这份 APK

- 追最新版、设备能正常访问 Google Play → 用商店版，更新走商店；
- 设备没有 Play 服务，或就是要网盘里这份确定的 28.20 → 用这份 APK；
- 两者同包名，**同一台设备上二选一**，来回换要先卸载旧的（先救作品再卸载）。

## 六、卸载或重装前，先把作品救出来

MediBang Paint 的作品默认存在应用自己的存储里，直接卸载会把没导出的画稿一起带走。动手卸载前做一件事就够：把要留的稿子导出成 png/jpg/psd 放到设备公共目录，或登录账号传到云端（云端规则见 [云端同步与多设备协作.md](云端同步与多设备协作.md)）。怎么导出、平时怎么开自动备份、闪退后从哪找回稿子，步骤见 [画稿保存与崩溃恢复.md](画稿保存与崩溃恢复.md)。之后想再装回来，从本文开头的安装文件资源入口重新拿包即可。
