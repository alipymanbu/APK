## 一、先搞清楚：个人账号和团队是两回事

eteams 按团队组织内容，你的审批、日报、考勤都挂在某个团队下面。账号体系分两层：

- **个人账号**：用手机号或邮箱注册即可拥有，注册后在官网首页点「注册」、或在 App 登录页注册，就能得到一个可体验的 demo 环境——先建几条数据、把各模块点一遍，是熟悉产品的推荐方式。
- **团队**：一个人创建团队（成为系统管理员），其他人被邀请加入。你的公司大概率已经有团队了，让管理员邀请你，比自己注册一个新团队更省事。

手机浏览器打开官网或直接用装好的 App，注册后按提示就能完成团队创建。团队创建者默认就是系统管理员，权限最高；管理员还可以按模块指定「应用管理员」，比如让人事负责人管人事类应用，分工不需要都挤在一个人身上。

管理员人事变动要提前交接：按官方系统管理员手册的口径，系统管理员可以指定其它管理员、也可以取消管理员，但整个团队**必须保留 1 名系统管理员**，且最后一名系统管理员无法退出或解散团队（该口径出自官方较早版本的管理员手册，具体以当前后台实际为准）。所以有管理员要离职时，先把继任者的管理员身份指定好，再处理他的账号，别到「最后一名」卡住团队。

## 二、免费版和付费版的边界

按官方帮助中心的口径：注册后可享受 **7 天全功能免费体验**，试用结束后降为免费版。需要付费的情况有四类：

| 场景 | 说明 |
| --- | --- |
| 购买标准版 | 试用期结束想继续用完整功能，与服务顾问签订购买合同 |
| 定制开发 | 标准产品满足不了的需求，评估工作量后签二开合同 |
| 续费 | 已购产品到期后续签 |
| 扩容 | 增加存储空间、短信量等 |

团队已用空间在「系统设置 → 团队授权信息」里能看到，接近上限时系统会提醒。价格会随官方政策调整，以官方销售页面当时显示为准。

## 三、邀请同事加入团队

邀请是管理员账号的操作，官方给了四条路，按团队规模选：

1. **逐个邀请**：点击「添加和邀请同事」，输入被邀请人的姓名和手机号或邮箱，系统自动创建账号密码并发送给对方。
2. **复制链接**：在邀请界面复制邀请链接，直接发给同事，对方点开即加入。
3. **微信邀请**：微信扫一扫转发邀请链接给微信好友，注意二维码仅 1 小时内有效，过期要重新生成。
4. **批量导入**：按官方模板整理 Excel 后上传，一次导入整个部门。几十人以上的团队别逐个加，直接用这条。

两个实用细节：被邀请人**不需要自己注册**，用系统发来的账号密码登录即完成激活；账号还没激活也不影响你先给他派任务、建项目，对方登录后就能看到。邀请记录在后台的「邀请列表」里可以查，没及时激活的可以重新邀请。

## 四、登录入口不止手机 App 一个

同一个账号可以从这些端口进：

| 端口 | 入口 |
| --- | --- |
| 手机 App | 登录页输入账号密码，或用绑定的第三方账号（QQ、微博、微信）授权登录 |
| 企业微信 | 管理员在企业微信后台完成 eteams 应用授权后，成员在工作台直接用，无需另装 App |
| 微信服务号 | 关注服务号后可处理审批、考勤等轻量操作 |
| 电脑网页版 | 浏览器打开官网登录 |
| Windows/Mac 客户端 | 官方下载桌面客户端 |

企业微信集成需要管理员操作：在后台管理中心的「基础设置 → 企业微信」里授权通讯录套件，保持 eteams 组织架构与企业微信一致，再到「云桥」里授权 eteams 应用。做完之后成员在企业微信工作台里就能用，通知也会推到企业微信里。

账号本身建议顺手做两件事：把密码设成字母、数字、符号中至少两种的组合且不低于 6 位；在「个人资料 → 设备管理」里检查授权登录的设备，发现不认识的设备及时移除。

登录出问题（手机授权提示、验证码不到、密码忘掉）的逐项处理方法，见 [账号与常见问题排查.md](账号与常见问题排查.md)。账号跑通之后，最先用起来的通常是考勤打卡，设置方法在 [移动考勤打卡指南.md](移动考勤打卡指南.md)。
