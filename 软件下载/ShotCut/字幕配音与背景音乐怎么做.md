## 一、自动字幕：适合口播类视频

用自动字幕可以把视频里的人声转成文字并铺到画面上，省掉逐句手打的时间。入口在编辑界面的**字幕 / 文本**相关功能里，选中要识别的片段后启动识别。

用之前先知道三件事：

- **是免费试用制**。官方应用商店页写明 AI 转写提供免费试用，试用额度用完后需要按应用内提示处理。它是按次数/额度计，不是无限用；额度的算法与订阅规则见 [会员订阅与试用怎么算.md](会员订阅与试用怎么算.md)；
- **识别质量取决于音源**。人声清楚、背景噪音小、少夹英文与专业词的片段，识别最准；
- **一定要人工过一遍**。同音字、人名、地名、数字最容易错，识别完逐句核对，比后期被观众挑错划算。

识别完成后，字幕会作为一条条文字对象出现在时间线上，位置、字号、出现时机都能单独调。

## 二、手动加字与文字动画

不依赖自动识别时，手动加字更可控。做法是让播放头停在要出现文字的位置，选**添加文本**，然后：

| 要调的项 | 说明 | 常用取值 |
| --- | --- | --- |
| 字体与颜色 | 决定可读性 | 深色画面上用白字加深色描边 |
| 字号与位置 | 字幕别压住关键画面 | 口播字幕放底部留白区 |
| 出现时长 | 短了看不清 | 一行字幕停留 1.5~3 秒 |
| 动画 | 让文字进退有节奏 | 淡入/缩放适合开头结尾 |

文字动画（弹跳、旋转、渐显等）建议**只在标题和重点句上用**。每句话都加动画，观众注意力会被文字拖走，反而看不清内容。

另外一个提高可读性的小技巧：文字背后加一层**半透明底条**或**阴影**，遇到复杂背景时字幕不会糊在画面里。

## 三、背景音乐与音效

免版税的音乐库和音效库在**音乐 / 音频**相关功能里，可以按分类找，也可以搜索关键词。

几个实操要点：

1. **音量要压下去**。背景音乐的音量通常调到人声的 20%~30%，让人说话时能听清；音乐主音量在音频轨上单独调；
2. **用关键帧做起伏**。在有人说话的位置把音乐压低、没人说话时抬回来，这就是常说的「闪避」，效果比全程一个音量好；
3. **音效按需点一下**。转场、翻页、提示这类位置叠一个短音效即可，别整片铺满；
4. **时长对齐**。音乐长度和画面长度不匹配时，宁可裁音乐，也不要让画面迁就音乐留出大片空镜。

素材来源还有一条路：导入你自己的音频文件，当作背景音乐使用。前提是**你有权使用它**——商用或公开发布时，第三方平台的音乐可能触发版权问题，用应用内标注为免版税的资源更稳妥。

## 四、配音与提取音频

**配音（画外音）**：在需要讲解的位置启动录音功能，直接对着手机说，录完的音频会落到时间线上单独一条轨道。

- 在安静房间、把手机麦克风朝向自己，离嘴 15~20 厘米左右，声音最干净；
- 一次录一小段、录错就重录这一段，比一口气录五分钟再返工轻松；
- 录完先听一遍有没有爆音、有没有环境噪音再往下剪。

**提取音频**：把一段视频里的声音单独取出来，用作素材。

1. 导入含目标声音的视频，选中它；
2. 用**提取音频 / 分离音频**功能，把声音拆成独立音轨；
3. 原先的视频画面可以删掉（只留声音），新音轨可以拖到别处使用。

反过来「把视频转成纯音频文件」（比如导出成 MP3）在导出面板里做，见 [导出设置与画质怎么选.md](导出设置与画质怎么选.md)。

## 五、音画不同步怎么排查

| 现象 | 常见原因 | 处理顺序 |
| --- | --- | --- |
| 导入的某段素材本身就没声音 | 原文件无声，或该片段被静音 | 先用系统播放器放一遍原文件；原文件有声音，就回时间线看该片段的静音开关与音量 |
| 人声比画面慢半拍 | 后期单独挪动过音轨 | 把音轨拖回与画面同起点，重新对齐 |
| 整片声音越来越慢 | 对视频做了变速、但音频没同步变速 | 检查该片段是否只改了画面速度，重新处理整段 |
| 配音听着忽大忽小 | 录音距离不稳定，或音乐闪避没做 | 重录这一段，或给音乐补关键帧 |
| 导出后完全没声音 | 某层音轨被静音，或音量被拉到 0 | 回时间线逐层检查音轨的静音与音量 |

排查的逻辑是**先看轨道、再看片段、最后看导出设置**，三层都过一遍基本能定位。更多成品问题见 [常见问题与排查.md](常见问题与排查.md)。
