## 一、装不上

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「解析包失败」 | 安装包没下完整 | 删除后重新从网盘取一次，并按 [下载与安装教程.md](下载与安装教程.md) 核对 MD5 |
| 提示「应用未安装」 | 空间不足，或与同包名的旧版本冲突 | 清出空间；如机器上已有同包名应用，先卸载再装 |
| 一直停在「正在安装」 | 系统权限没放行 | 到「设置 → 应用 → 特殊权限 → 安装未知应用」给安装来源放行 |
| 提示「与设备不兼容」 | 系统版本低于最低要求 | 升级系统；或换一台系统版本更高的设备 |

## 二、打不开、闪退

- **首次打开就闪退**：先重启手机再试一次，多数是第一次启动时的缓存问题；
- **打开后卡在启动页**：检查是否禁用了 ShotCut 的存储/媒体权限——权限被拒时部分版本会在读相册这一步卡住；
- **用一会儿就退回桌面（后台被杀）**：到系统设置的电池/后台管理里，把 ShotCut 设为**不受限制**或加入白名单，避免系统在后台把它清掉；
- **升级系统后打不开**：卸载后重新装一次网盘里的这份（3.3.1）。升级系统带来的兼容问题，重装常能解决。

## 三、素材导不进来

按这个顺序查，基本能定位：

1. **权限**：先看照片/媒体权限是否给了。没给的话，相册里能看到视频、应用里却读不到；
2. **格式**：手机拍的常见格式（MP4/MOV 等）通常都支持，但如果素材是从别处下载的特殊编码文件，可能读不进。换一段自己手机拍的视频试，能读进就说明是那个文件的格式问题；
3. **文件位置**：存放在外置 SD 卡或云盘占位文件里的素材，先复制到手机本机存储再导入；
4. **文件是否还在**：如果导入后你把相册里的原文件删了或移动到别的目录，项目里对应的片段会变空——剪辑过程中别整理相册。

## 四、剪的时候卡

- **预览一卡一卡**：常见于在配置一般的手机上处理 4K 素材。先把项目比例和分辨率降到 1080p 再剪，导出时按需提高；
- **时间线拖动不跟手**：关掉后台其他大应用再剪；素材太多时，可以先把不用的片段删掉再调整；
- **添加特效后变慢**：同一段画面叠了多层特效。把特效合并成一层、或缩短特效生效区间，通常能明显改善；
- **发热严重**：长时间剪辑的正常现象。接上电源、避免边充边用大负载，别在低电量时做长片导出。

## 五、导出相关

| 现象 | 先做什么 |
| --- | --- |
| 导出到一半失败 | 清出手机空间（成片体积的 2 倍以上）再重试 |
| 导出后相册里找不到 | 到导出面板确认保存目录，或在系统文件管理里搜文件名 |
| 导出很慢 | 降低分辨率与清晰度档位，具体取舍见 [导出设置与画质怎么选.md](导出设置与画质怎么选.md) |
| 导出后没声音 | 回时间线逐层检查音轨是否被静音、音量是否被拉到 0 |
| 导入的素材没声音 | 先用系统播放器放一遍原文件；原文件有声音，就回时间线看该片段是否被静音、音量是否为 0 |
| 预览里有会员标记的素材 | 换成不带会员标记的素材或模板，以应用内标注为准 |

导出过程中**别切到别的应用长时间挂后台**，部分手机的后台清理会打断导出。

## 六、账号与付费

- **不登录能用吗**：基础剪辑可以。模板、云空间与 AI 功能一般要登录后才完整；
- **AI 字幕怎么算**：官方应用商店页写明是**免费试用**，额度用完需按应用内提示处理；
- **导出有免费额度吗**：普通导出不带水印，属于免费范围；带会员标记的素材或模板可能受限，具体以应用内当时标注为准；
- **想退订阅 / 关自动续费**：这类扣费走的是应用商店的订阅体系，到**应用商店**里取消，而不是在应用内找按钮。Google Play 的路径是「头像 → 付款和订阅 → 订阅 → 找到 ShotCut → 取消订阅」；苹果设备在「设置 → 你的 Apple 账户 → 订阅」里取消。**注意：只卸载应用不会停止扣费**，必须走这一步。试用天数、扣费时间点与退款口径，见 [会员订阅与试用怎么算.md](会员订阅与试用怎么算.md)。

## 七、找不到某个功能

版本差异是主因：你装的是 3.3.1，网上截图可能来自更新的版本；也有一部分功能只在登录后或特定机型上出现。定位办法：

1. 先在编辑界面下方的功能条里逐项翻一遍，很多功能在二级菜单里；
2. 确认素材已选中——多数功能只对选中的片段生效，没选片段时按钮是灰的或点了没反应；
3. 还找不到的，按 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 确认自己看的教程是不是讲错了产品（桌面开源版 Shotcut 的教程在手机版上对不上）。

排查的统一逻辑是**先看权限、再看版本、最后看素材**。这三层过完还解决不了，再去官方渠道反馈更有效率。
