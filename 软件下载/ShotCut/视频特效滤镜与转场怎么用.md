## 一、先分清三类东西别用错

新手最容易混的是这三个，作用位置完全不同：

| 类型 | 作用范围 | 典型用法 |
| --- | --- | --- |
| 滤镜（Filter） | 整段素材从头到尾 | 统一调色、黑白、复古感 |
| 特效（Effect） | 通常按时间段生效、可叠加 | 故障、VHS、霓虹、闪光 |
| 转场（Transition） | 只作用在**两个片段之间** | 淡入淡出、叠化、滑入 |

判断口诀：**想改「味道」用滤镜，想加「花活」用特效，想改「衔接」用转场**。选错了会觉得「怎么全片都被改掉了」或「怎么只有一个角变了」。

## 二、特效与滤镜怎么施加

入口在编辑界面下方的功能条上，找**特效 / 效果（Effects）**标签：

1. 把播放头移到要处理的片段上；
2. 打开特效面板，按分类浏览——常见分组有复古、故障（Glitch）、VHS、霓虹、电影感、节日等；
3. **点一下先预览**，效果自动套到预览画面；
4. 满意再确认应用，然后拖动时间线上的竖条，**指定这段特效从哪一秒到哪一秒生效**。

两条实操建议：

- **别一上来就叠三层**。同一段画面叠多个特效，容易出现噪点堆砌、颜色发脏。先从单层试，确认方向再加第二层；
- **控制出现的时长**。特效在观众注意力要落点的那一刻出现最有效，整段铺满反而看不出效果。

滤镜的用法类似，但它是整段生效，适合先把一批素材的色调统一，再去做特效。常见滤镜风格包括电影感的橙青、复古胶片、黑白，以及不同平台的流行色调包。

## 三、转场：让两个镜头衔接

两个片段相邻时才可以加转场。做法是把播放头停在两段交界处，打开转场列表选择样式，然后**调整转场时长**——拖两端可以拉长或缩短。

- **淡入淡出 / 黑场过渡**：正式、不抢戏，适合段落之间做分隔；
- **叠化**：两个画面短时重叠，适合时间流逝、回忆；
- **滑入 / 推拉 / 缩放类**：节奏快，适合卡点短视频。

转场时长有个经验值：**卡点短视频用 0.3~0.5 秒，日常 Vlog 用 0.5~1 秒**，太长会显得拖。同一个视频里样式别换得太勤，两三种来回用就够了。

## 四、绿幕抠像与背景移除

这两个功能都是「把主体从背景里拎出来」，但适用素材不同：

| 功能 | 适用素材 | 前提 |
| --- | --- | --- |
| 绿幕抠像（Chroma Key） | 纯色背景（绿幕/蓝幕）拍摄 | 背景颜色要单一、光照均匀 |
| 背景移除 / 智能抠像 | 普通实拍画面 | 主体与背景有一定区分度 |

绿幕抠像的操作顺序：

1. 选中带绿幕的片段，打开**绿幕 / Chroma Key**功能；
2. 用**取色器**点画面里的背景色，软件会把这个颜色抠掉；
3. 如果边缘残留绿色，微调**强度 / 容差**，直到人物轮廓干净；
4. 在下方轨道放入要当作新背景的图片或视频，主体就会叠加在新背景上。

抠像效果不好，八成出在**拍摄环节**而不是软件：绿幕要拉平、别有褶皱，人物离幕布远一点避免绿色反光打到身上，光线尽量均匀。换背景的具体成品做法，见 [字幕配音与背景音乐怎么做.md](字幕配音与背景音乐怎么做.md) 里配音与合成的思路。

## 五、叠加与画中画

想把两个画面同时放在屏幕上（比如一边讲解一边放演示），用的是**叠加 / 画中画（PIP）**：

- 两个片段分别放在不同的图层（轨道）上，上层会自动盖住下层；
- 选中上层片段，用**缩放与位置**把画面缩小并拖到角落；
- 需要上层画面以不规则形状出现时，配合**蒙版**裁出想要的范围。

分层是叠加的基础：一层一个元素。音频、视频、图片、文字各占一层，调整顺序时只动对应那一层，别把所有东西塞进同一条轨道。

## 六、模板怎么用

模板库里有一批现成的成片模板（如短视频模板、特效模板），用法是**先套模板，再替换里面的素材**：

1. 从模板库挑一个接近你想要风格的，应用后时间线上会出现预设好的结构与特效；
2. 逐个把模板里的占位素材换成你自己的视频或照片；
3. 需要改文案的地方替换文字，需要改音乐的地方换成自己的音频；
4. 试播确认节奏，再导出。

**注意**：模板里的部分素材、音乐可能属于会员范围，套用前留意应用内是否有会员标记，避免导出时才发现受限。哪些能用、哪些要会员，以应用内当时标注为准。

特效堆得太满反而拖慢节奏，做完一层先试播一遍。确认画面没问题之后，下一步一般是加字幕与配音，见 [字幕配音与背景音乐怎么做.md](字幕配音与背景音乐怎么做.md)。
