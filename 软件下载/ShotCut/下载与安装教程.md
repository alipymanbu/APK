## 一、先对准版本，再动手装

这份资源是 **Android 手机版**的 ShotCut，包名 `video.editor.videomaker.effects.fx`。装之前先把下面这张表记住——报问题、对功能、看教程，都按这一版为准。

| 项目 | 这一份的值 |
| --- | --- |
| 应用名 | ShotCut |
| 版本 | 3.3.1 |
| 包名 | video.editor.videomaker.effects.fx |
| 安装包大小 | 128.40 MB |
| MD5 | `eec65c73b94bc5746cfcf423d99c6215` |
| 开发商 | Shotcut Video Workshop |
| 整理/核对日期 | 2026-09-22 |

官方渠道上的最新版通常已经是更高的版本号，两者不一定是同一版。你手上这份是 3.3.1，所以界面上的按钮位置、特效名称、导出面板的选项，都以**你装的这一版**为准；网上看到的新版截图对不上属正常。

另外提醒一句：网络上搜「ShotCut」很容易搜到同名的**桌面开源剪辑软件**（那个是另一款产品，官网在 `shotcut.org`），两者不是同一个应用。区别与辨认方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 二、装之前确认两件事

**第一，系统版本。** 这是安卓应用，对系统版本有最低要求，低于要求的设备会出现「商店里搜不到」「装到一半失败」。你的系统版本在「设置 → 关于手机 → Android 版本」里看。第三方下载站当前标注的最低系统版本是 Android 8.0，实际以应用商店页面当时显示的为准——版本要求会随更新变化。应用商店页上如果显示「此应用与你的设备不兼容」，那就是系统版本不够的直接信号。

**第二，剩余空间。** 安装包本身 128.40 MB，装完后的占用会明显更大：应用本体、运行缓存、以及你自己剪的草稿和导出的成片都要占地方。手机上留出安装包体积三倍左右的空余，后面剪片子时才不容易因为空间不足中断。

## 三、从网盘取包并安装（安卓）

1. 在手机或电脑上打开 **ShotCut 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/151911d30221](https://pan.quark.cn/s/151911d30221)，转存或直接下载其中的安装包（`.apk` 文件）；
2. 如果是在电脑上取的包，把 `.apk` 传到手机的「下载」目录，用数据线或聊天工具传文件都可以；
3. 在手机的文件管理器里进入「下载」，点这个 `.apk` 文件开始安装；
4. 首次安装会被系统拦一下，提示「不允许从此来源安装应用」。到「设置 → 应用 → 特殊权限 → 安装未知应用」里，给你刚才点安装的那个应用（文件管理器或浏览器）放行，然后回来重新点安装；
5. 安装完成后，桌面或应用列表里会出现 ShotCut 图标，点开即可。

两条经验：**不要**用「在线解压」「重命名改后缀」的办法处理安装包，那会让包直接损坏；安装过程中如果提示「解析包失败」，多数情况是包没下完整，删掉重新下一次即可，不用怀疑手机。

## 四、核对安装包是否完整

从网盘下载到电脑之后，建议先核对一次 MD5，确认文件在传输过程中没有损坏。Windows 上用 PowerShell：

```powershell
Get-FileHash -Algorithm MD5 ".\ShotCut_v3.3.1.apk"
```

输出的哈希值与本文第一节表格里的 MD5 一致，说明这一份包是完整的；不一致就重新从网盘取一次。这一步能省掉「装到一半报错、却不知道是包的问题还是手机的问题」的折腾。

## 五、第一次打开建议先做的几项

- **先给素材权限**。导入视频和照片要用到「照片/媒体」权限，录配音或录音要用「麦克风」，导出保存要用「存储/媒体」相关权限。用不到的先不给，等功能触发时系统再问一次也行。
- **登录不强制**。多数基础剪辑（导入、裁剪、拼接、加音乐、加字）不用登录就能做；模板、云空间与 AI 类功能通常要登录账号后才完整。
- **看清免费与付费的边界**。官方应用商店页写明：普通导出**不带水印**；AI 字幕等 AI 功能是**免费试用**制，试用额度用完后需要按应用内页面提示处理。哪些素材、哪些特效属于会员范围，以应用内当时标注为准。试用天数、自动扣费时间点与取消办法见 [会员订阅与试用怎么算.md](会员订阅与试用怎么算.md)。
- **先在设置里看两样**：一是语言，二是导出默认保存位置（默认多在系统相册或 Movies 目录）。剪长片前把保存位置放到空间充裕的那块存储上，比导出到一半才发现满了要省事。

## 六、装不上、装完打不开

| 现象 | 常见原因 | 先做这一步 |
| --- | --- | --- |
| 提示「解析包失败」 | 安装包下载不完整 | 删掉重下，或按第四节核对 MD5 |
| 提示「应用未安装」 | 空间不足，或与已装的同包名应用冲突 | 清出空间；若已装有别的来源的同包名版本，先卸载再装 |
| 系统不让点安装 | 未放行「安装未知应用」 | 见第三节第 4 步 |
| 装完点开就退回桌面 | 系统版本过低，或缓存异常 | 重启手机后再试，仍不行见 [常见问题与排查.md](常见问题与排查.md) |
| 导入素材时应用没反应 | 媒体权限没给 | 到系统设置里给 ShotCut 放开照片/媒体权限后再试 |

安装环节的排查顺序统一是：**包完整 → 空间够 → 系统版本够 → 权限放行**。四步都过还装不上，再按排查那篇往下走。
