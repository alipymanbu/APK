# MyComic 数据源切换方法

> MyComic 的漫画、小说、番剧内容都来自内置数据源，某个源搜不到、加载慢时，换一个源往往就能解决。本篇讲切换的具体路径与换源时机。

## 一、先搞清「源」和「内容」的关系

MyComic 把漫画、小说、番剧三种内容放进同一个应用，你看到的作品都来自它内置的数据源。据公开收录页记载，这类版本内置了十几个漫画接口与小说源。同一部作品在不同源里的收录范围、章节进度可能不一样，所以「换个源再搜」是这个应用里最常用的补救动作——搜索结果跟随你当前选中的源。

## 二、切换数据源的四步

1. 打开 MyComic，进入左下角的「我的书架」；
2. 点页面左上角的切换按钮；
3. 在弹出的小窗口里选择想用的数据源；
4. 切换完成后返回搜索页，用关键词重新搜索即可。

换源之后，搜索与排行榜都按新源给出；书架里已收藏的作品不受切换影响。

## 三、数据源的配置与开关（较新版本才有）

据同名开源项目的发行记录（`https://gitee.com/luqichuang/MyComic/`，v1.11.6 起），数据源可以在「个人中心 → 数据源配置」里选择关闭，搜索页也会把不同数据源的结果分类展示。本文介绍的安装包是 v1.11.5，界面里未必有这两个入口——找不到属正常，不是坏了。

## 四、什么情况该换源

| 情况 | 建议 |
| --- | --- |
| 搜某部作品没有结果 | 换一个源再搜，不同源收录范围不同 |
| 详情页或正文图片一直转圈 | 换源，或按 [漫画加载不出来怎么办.md](漫画加载不出来怎么办.md) 逐项排查 |
| 某个源整体响应很慢 | 先换到快的源看内容，稍后再回来试 |
| 想对比章节进度 | 在两个源里分别搜同一作品，看各自更新到哪一话 |

## 五、源里没有时的补充路径：本地导入

MyComic 支持手动导入本地漫画文件。某个源里找不到、或你手里本来就有文件时，可以把文件导入后直接在应用内阅读，不再依赖数据源。导入入口在应用内的书架/菜单区域，不同版本的入口位置可能略有差异，以你手上版本的实际界面为准。

## 六、换源之后仍不行

按 [漫画加载不出来怎么办.md](漫画加载不出来怎么办.md) 的顺序继续排查：换网络、重启应用、核对版本。日常找书与追更的操作见 [阅读操作与离线缓存.md](阅读操作与离线缓存.md)。
