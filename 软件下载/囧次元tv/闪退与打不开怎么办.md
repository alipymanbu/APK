# 囧次元TV 闪退与打不开怎么办

> 应用点开就退回桌面、卡在开屏、或直接没反应时，按本篇的顺序一步步排，多数情况用不到重装。

## 一、先分清是哪种「打不开」

不同的表现，原因差很远，先对号入座：

| 表现 | 更可能是哪一侧 |
| --- | --- |
| 只有这一个应用打不开，别的都正常 | 应用本身：缓存、数据、版本 |
| 所有应用都卡、都退 | 电视/盒子：内存、存储、系统 |
| 打开几秒就退回桌面 | 存储快满、缓存损坏、设备过热 |
| 停在开屏转圈进不去 | 网络或服务端（见 [常见问题与故障排查.md](常见问题与故障排查.md) 第二节） |

**先看剩余空间**：电视「设置 → 存储」（有的叫「设备偏好 → 存储」）。可用空间低于几百 MB 时，各种应用都会开始闪退——盒子系统本身要占几个 GB，标称 8G/16G 的盒子实际可用远比标称少。

## 二、按顺序处理（前两步解决大部分）

1. **彻底退出再进**：不是按返回键回桌面就完了，在最近任务里把它彻底关掉再打开；焦点和播放状态会重新初始化。
2. **断电冷启动**：把电视/盒子电源插头拔掉，等 30~60 秒再插回开机。这一步清的是运行内存，比在菜单里点「重启」更彻底。
3. **清缓存**：设置 → 应用 → 找到囧次元 → 存储 → **清除缓存**。缓存是临时文件，清掉不丢登录、不丢收藏。
4. **清数据**：上一步还不管用再点**清除数据**。这会把本机的登录状态一起清掉，装回后重新登录一次即可——观看历史与收藏跟账号走，重新登录会回来（见 [登录方式与账号同步.md](登录方式与账号同步.md)）。
5. **查权限与网络**：设置 → 应用 → 囧次元 → 权限，确认存储、网络相关权限没有被禁用；网络类问题按 [常见问题与故障排查.md](常见问题与故障排查.md) 排。
6. **查系统时间**：设置 → 日期与时间，开自动获取。时间偏差过大时，应用与服务端的连接校验会失败，表现就是打不开或一直转圈。
7. **重装**：以上都无效才走这步，按 [下载与安装教程.md](下载与安装教程.md) 卸载后重新安装（先卸载再装，能顺带解决签名冲突）。

## 三、还没修好的两个方向

- **换一份安装包**：安装包在传输中损坏，装是装上了但运行时缺文件，会反复闪退。从 [囧次元TV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/be11f39085d7) 重新取一次，装前对照 MD5 `67CB1865A2710B432B8A0E0F940B215C` 核验（详见 [下载与安装教程.md](下载与安装教程.md) 第二节）。
- **设备本身太旧**：各收录页标注的最低要求是 Android 4.0 或更高（以官方页面当时显示为准），但系统版本达标不等于硬件扛得住——几年前的低端盒子跑不动新版本应用时，卡顿与闪退会一起出现，这类设备没有软件侧的解法。

## 四、什么时候该怀疑服务端

你打不开、但别人也反馈打不开，或者开屏一直转圈且网络本身没问题——那多半是服务端在维护或出状况。这种情况下本地怎么折腾都无效，换个时间段再打开即可。
