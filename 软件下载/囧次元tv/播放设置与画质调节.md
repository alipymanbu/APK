## 一、播放页上的常用操作

进播放页后，用遥控器方向键呼出控制条，你常动的是这几项：

| 操作 | 说明 |
| --- | --- |
| 选集 | 直接跳到第 N 集，不必一集集退回去 |
| 切换线路 | 同一部番配了多条播放源，这条转圈就换下一条 |
| 调清晰度 | 按当前网速在几档画质之间切；网差先降档，画面糊一点但不卡 |
| 弹幕开关 | 觉得挡画面就关掉 |
| 拖进度 | 左右方向键快进快退 |

**遇到一直转圈，第一反应是切线路**——多数「加载慢」是单条源的问题，不是你宽带的问题（排查顺序见 [常见问题与故障排查.md](常见问题与故障排查.md)）。

## 二、清晰度怎么选

- 家里 50M 以上宽带、路由器就在客厅 → 选高清/超清，大屏上看低档位会明显发糊；
- 网速不稳、看一会儿卡一会儿 → 先降到流畅档确认不卡，再逐档往上调；
- 大屏电视本身分辨率高，但**先保证不卡比档位高更重要**——卡三秒的超清不如顺畅的高清。

具体的档位名称各版本不完全一样，以播放页上列出的为准。

## 三、弹幕与画面设置

- **弹幕**：播放页里可开关；追新番时开着有氛围，回看经典时关掉更清爽；
- **画面比例**：画面被拉伸/压扁时，在播放设置里调播放比例；
- **画面锁定**：家里有小孩误触遥控器时，锁定画面可以防止进度被乱跳；
- 这些设置都在应用的设置/播放设置里，改动即时生效，重启应用也会记住。

## 四、个人中心里有什么

个人中心是你追番的账本，里面有：

- **观看历史**：按最近看过排列，点进去直接续播；
- **我的收藏**：详情页点过收藏的番都在这，新集更新后从这里进最快；
- **离线缓存**：已下载到本地的剧集，断网时也能看。缓存文件是应用专属格式，**只能在本应用内播放**，拷到别的播放器打不开；
- **清理缓存**：看久了占空间，在这里清一下（会清掉播放产生的临时数据，你的收藏和历史不受影响）；
- **退出登录**：换账号时用，见 [登录方式与账号同步.md](登录方式与账号同步.md)。

## 五、手机与电视怎么配合用

同一账号登录后，习惯的分工是：在手机上翻榜单、搜索、把要追的番收藏好，回家在电视上打开个人中心直接看。观看进度两端共享，手机上没看完的那一集，电视打开会提示接着播。

如果你想把手机上正在播的内容投到电视（手机端播放页有 TV 图标，需两端同一 Wi-Fi），那用的是手机端的功能；TV 版本身就在大屏上，不需要投屏这一步。
