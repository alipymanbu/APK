## 一、安装阶段的三个坑

1. **提示禁止安装** → 电视「设置 → 账号与安全」里没开「未知来源应用」，放行后重装；
2. **提示解析包失败** → 安装包没下完整，重新下载一次；从 [囧次元TV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/be11f39085d7) 取包时注意别只下了个残缺文件，可对照 MD5 `67CB1865A2710B432B8A0E0F940B215C` 核验；
3. **签名冲突装不上** → 电视里有旧版本，先卸载旧的再装。

详细的电视/手机安装步骤在 [下载与安装教程.md](下载与安装教程.md)。

## 二、播放一直转圈、加载慢

按这个顺序试，通常前两步就能解决：

1. **切线路**：同一部番有多条源，当前这条不通不代表都通；
2. **降清晰度**：从超清降到高清或流畅，先保证连续播放；
3. **查网络**：电视「设置 → 网络」看信号强度，离路由器远就靠近一点，或改有线连接；
4. **重启应用**：退出再进，播放页的线路状态会重新拉一遍；
5. **重启路由器与盒子**：连续多部番都卡时，问题多半在网不在片源。

## 三、遥控器失灵 / 界面按不动

- 确认你装的是 **TV 版**：手机版界面不是按遥控器逻辑排的，装错端会出现「方向键能动但确认键没反应」；
- 退出应用重进一次，界面焦点会重新初始化；
- 检查遥控器本身：蓝牙遥控器重新配对，红外遥控器对准电视接收窗；
- 电视盒子的遥控器没电也会表现为「时灵时不灵」，先换电池。

## 四、搜不到想看的番

用更短的关键词、或用正式全名再搜一次；新番有收录延迟，过几天再试。详见 [怎么搜索动漫.md](怎么搜索动漫.md) 第三节。

## 五、登录与同步相关

| 症状 | 处理 |
| --- | --- |
| 收藏/历史没同步过来 | 两端是否登录了同一账号（见 [登录方式与账号同步.md](登录方式与账号同步.md)） |
| 邮箱验证码收不到 | 查垃圾邮件、核对地址，稍等一两分钟刷新 |
| 验证码一直提示错误 | 逐字核对刚收到的那一条（有大小写就区分大小写）；它有有效期，过期就重新获取一条；刚提交就报错且确定没输错，多半是服务端在维护，换个时间再试 |
| 扫码提示失败 | 二维码过期就退出重进登录页刷新 |
| 点了「登录」一直没反应 | 网络侧问题，回到第二节排 |

## 六、缓存与存储

- **缓存的视频拷到别处放不了**：正常现象，缓存是应用专属格式，只能在本应用内播放；
- **存储空间不足 / 应用变卡**：两处可清——① 应用内个人中心的「清理缓存」；② 电视「设置 → 应用 → 囧次元 → 存储 → 清除缓存」（应用彻底没反应时，菜单不一定进得去，走系统这条路更稳）。别的应用占用的空间去「设置 → 存储」里卸应用解决；
- **清完缓存历史没了**：历史跟账号走，重新登录一次即可恢复；只有在「清除了应用全部数据」时才会连本机记录一起清掉；
- **盒子整体空间怎么看**：设置 → 存储（或设备偏好 → 存储）。删掉不再用的应用、清掉旧安装包，比装「清理大师」类工具可靠（这类工具本身就占空间）。

## 七、打不开、闪退、卡在开屏

这一类不在这篇里铺开，单独走 [闪退与打不开怎么办.md](闪退与打不开怎么办.md)：从「彻底退出重开 → 断电冷启动 → 清缓存 → 清数据 → 重装」逐级往下，每一级都写清了代价（会不会丢登录）。

## 八、还是不行的兜底顺序

1. 退出应用重进；
2. 重启电视/盒子；
3. 卸载后重装一次（按第一节第 2 点重新取包并核对 MD5）；
4. 换一部番试播——只有这一部不播是片源问题，所有番都不播才继续往下查网络与设备。
