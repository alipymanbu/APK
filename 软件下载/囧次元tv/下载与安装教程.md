## 一、先确认你要装的是哪个端

囧次元同一套账号下有手机版和 TV 版，两者的安装包**互不通用**：手机版装到电视上往往遥控器按不动，TV 版装到手机上则界面是按大屏排的。你在电视、电视盒子上装的应该是 TV 版（包名 `com.jiongciyuan.tv`）。

本文给的这份 TV 版安装包事实如下（以本地这份文件为准，网上各收录页写的新版本号是别处的包，未必是同一个）：

| 项目 | 值 |
| --- | --- |
| 版本 | v1.0.0.0 |
| 包名 | `com.jiongciyuan.tv` |
| 安装包大小 | 16.07M |
| MD5 | `67CB1865A2710B432B8A0E0F940B215C` |
| 分类 | 影音播放（大屏追番） |

系统要求方面，各收录页标注的是 Android 4.0 或更高版本，具体以官方页面当时显示为准；实际能不能跑起来，取决于你的电视盒子是不是太老。

## 二、获取安装包

安装包在 [囧次元TV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/be11f39085d7) 里，文件名带版本号、以网盘里显示的为准。电视本身一般没有浏览器，所以路径是「手机/电脑下载 → 转存 → 拷进 U 盘 → 插电视安装」：

1. 手机或电脑打开上面那条夸克网盘链接，转存后下载 `apk` 文件到本地；
2. 把文件拷进 U 盘根目录（别塞进太深的多层文件夹，电视文件管理器里翻不到）；
3. U 盘插电视 USB 口，等着电视弹出「检测到移动存储设备」的提示。

如果你想自己核对文件没下错，可以比对 MD5 是否等于 `67CB1865A2710B432B8A0E0F940B215C`——大小写无所谓。

## 三、电视上安装（U 盘方式）

多数电视的安装流程一致，差异只在「打开 U 盘」的入口叫什么名字：

1. **先放行**：电视「设置」→「账号与安全」（有的叫「安全」→「未知来源应用」）→ 允许安装未知来源应用。不打开这一项，点 apk 会直接被拦。
2. **插 U 盘**，等提示弹出后打开「文件管理器」，导航到 U 盘，找到 apk 点安装，按提示走完。
3. 如果插上 U 盘**没有任何提示**：用遥控器进「我的应用」→ 打开「高清播放器」（或「媒体播放器」）→ 切到「设备 / 移动存储设备」标签 → 找到 U 盘里的安装包安装。
4. 装完回到桌面，图标出现在「我的应用」里即可打开。

几个电视品牌特有的坑：

- 有些机型默认「禁止外接设备接入」或「禁止安装第三方应用」，要先在设置里关掉这两项；
- 小米电视等机型把安装入口放在「高清播放器」里而不是文件管理器，按上面第 3 步走；
- 安装过程中如果电视提示「风险」「有害应用」，那是系统对一切非应用商店来源的统一提示，你确认包来源没问题后自行决定是否继续。

## 四、手机上安装

手机装起来简单：下载 apk → 文件管理器里点开 → 允许「安装未知应用」→ 装完打开。装好后它和电视端用同一个账号（见 [登录方式与账号同步.md](登录方式与账号同步.md)）。

注意手机端和 TV 端是两套界面，不要拿手机端的安装包去电视装。

## 五、装完打不开 / 装不上的处理

按症状对照：

| 症状 | 处理 |
| --- | --- |
| 点 apk 提示「禁止安装」 | 设置里没开「未知来源」，回去按第三节第 1 步放行 |
| 提示「解析包时出现问题」 | 包没下完整，重新下一次；或你的系统版本太低，装不了这个包 |
| 提示「未安装应用」/空间不足 | 电视可用空间不够——安卓安装时要临时解包，占用比 apk 本身大；去设置里清缓存、卸掉不常用应用腾出几百 MB 再装 |
| 提示「安装包与已安装的应用签名不同」 | 先卸载电视上旧的囧次元，再装新包 |
| 插 U 盘无反应 | 换一个 USB 口；确认 U 盘是 FAT32/exFAT（部分电视不认 NTFS）；按第三节第 3 步走高清播放器 |
| 装完图标点了闪退 | 按 [闪退与打不开怎么办.md](闪退与打不开怎么办.md) 从「彻底退出重开」往下排 |
| 装完一切正常但进不去 | 网络或服务端问题，见 [常见问题与故障排查.md](常见问题与故障排查.md) 第二节 |
