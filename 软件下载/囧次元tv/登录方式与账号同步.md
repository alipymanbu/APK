## 一、登录入口在哪

打开应用后，在首页顶部就能看到登录按钮，点它进入登录界面。不登录也能浏览推荐与分类，但收藏、观看历史这类跟人走的功能要登录后才有。

## 二、三种登录方式怎么选

登录页给你三个选项，按你在电视前的条件挑一个：

| 方式 | 操作 | 适合谁 |
| --- | --- | --- |
| 手机扫码 | 用手机上的囧次元手机版扫电视上显示的二维码 | 手机已装同款应用、懒得用遥控器打字的人（**最省事**） |
| 邮箱验证码 | 填邮箱 → 收验证码 → 填进去 | 没有现成账号、第一次注册的人 |
| 账号密码 | 直接输入注册好的账号和密码提交 | 已有账号、手边没有手机的人 |

**扫码登录**的前提是手机端装了囧次元并已登录；二维码有时效，页面上那张图过期了就退出重进一次登录页刷新。

**邮箱验证码**是新用户注册的常规入口：填常用邮箱，去收件箱（也看一眼垃圾邮件）取码填入。收不到时先确认邮箱地址没打错，再等一两分钟刷新。验证码填进去一直报错时，按第五节的对座行处理——先核对字符与大小写，再确认它没过期（有效期通常很短，过期就重新获取一条）。

**账号密码**适合电视端固定机顶盒场景：输入一次，以后开机基本保持登录状态。密码忘了就走邮箱验证码这条路重设，别在电视上反复试错。

## 三、登录成功后你会得到什么

- **观看历史同步**：手机上看到第 7 集，电视打开接着第 7 集往下播，不用记集数；
- **收藏同步**：在手机上加进「我的收藏」的番，电视端个人中心里同样能看到；
- **进度记忆**：应用自己记录播放进度，下次打开直接续播。

前提是**两端登录的是同一个账号**——这一点最容易出问题：手机扫码登的是 A 账号、电视上又用 B 邮箱登了一次，两边历史就永远对不上。

## 四、换设备、退出与重登

- 换了新电视/新盒子：装好应用后用同一账号登录，收藏与历史会跟着过来；
- 要把账号从这台电视上退出来（比如要给别人用）：进个人中心 → 退出登录；
- 登录状态掉了（应用更新、清了数据）：重新走一遍第二节的流程即可，账号数据在服务端，不受本机影响。

## 五、登录类问题速查

| 症状 | 处理 |
| --- | --- |
| 扫码提示失败 | 手机端与电视端账号体系要一致；二维码过期就退出登录页重进一次 |
| 邮箱收不到验证码 | 查垃圾邮件箱；核对地址拼写；换网络（有的邮箱服务商在当前网络下延迟大） |
| 验证码填了报错 | 逐字符核对刚收到的那条（含大小写）；多半是已过期，重新获取一条再填；确定没输错还报错，等十几分钟再试（服务端可能在维护） |
| 电视上打字太慢 | 改用扫码登录，绕开遥控器输入 |
| 两端历史对不上 | 确认两边登录的是同一账号，见第三节 |
| 想保留记录但要换号 | 先在旧账号里确认收藏与历史已同步，再退出登录换新号 |

若登录页本身打不开或一直转圈，多半是网络侧的问题，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
