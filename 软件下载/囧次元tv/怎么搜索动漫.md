## 一、两条找番路径：分类栏和搜索框

找番就两个入口，首页上都摆在明处：

- **分类栏**：适合「今天想看国漫 / 日漫 / 动漫电影」这种大方向明确的情况；
- **搜索框**：适合「我就要找某某这一部」。

首页的板块大致是：我的、推荐、日漫、国漫、动漫电影、其他动漫（不同版本板块名可能略有出入，以你界面上显示的为准）。用遥控器上下左右方向键在板块间移动，选中的封面按确认键进详情页。

## 二、用搜索框精确找

1. 用遥控器选中首页上方的**搜索按钮**（放大镜图标）；
2. 弹出虚拟键盘后输入番剧名称关键词——不用打全名，打前几个字通常就能出结果；
3. 在结果列表里选中目标番剧，回车进详情页；
4. 详情页里选集、选线路、选清晰度，开始播放（这一步详见 [播放设置与画质调节.md](播放设置与画质调节.md)）。

搜索是按关键词匹配的，输入的角色名、题材词（比如「冒险」「科幻」）也能命中一批结果，用来找口味相近的作品。

## 三、搜不到时怎么办

| 情况 | 处理 |
| --- | --- |
| 全名搜不到 | 换更短的关键词，或只打作品名的前两三个字 |
| 简称搜不到 | 用完整正式名再搜一次；有的番在站内用的是译名而非原名 |
| 刚播出的新番搜不到 | 资源是持续更新的，过几天再试，或留意应用新版本 |
| 结果里没有你要的 | 该作品可能尚未收录，先在分类栏里按题材挑替代的看 |

**别用整句描述去搜**——搜索框匹配的是名称类关键词，长句子反而会让结果变空。

## 四、进详情页之后先看这几处

搜到并点进去之后，详情页上你要关注的是：

- **剧集列表**：选集，连载中的番这里会标出更新到第几集；
- **收藏按钮**：把这部番收进「我的收藏」，更新后好找（要先登录，见 [登录方式与账号同步.md](登录方式与账号同步.md)）；
- **线路与清晰度**：开播前先选好，卡了再换（见 [播放设置与画质调节.md](播放设置与画质调节.md)）。

收藏和播放历史都会记在你的账号里，电视和手机两端都能看到。
