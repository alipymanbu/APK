## 一、安装前先核对安装包信息

lutube 是一款安卓端的影视播放应用，内容覆盖电影、电视剧、综艺、短剧与直播。这类应用一般不在应用商店上架，需要你直接安装 APK 文件，所以装之前先把手里的安装包和下面这份信息对一遍：

| 项目 | 值 |
| --- | --- |
| 版本 | v1.1.90 |
| 安装包大小 | 27.51M |
| 包名 | com.lhlsjf431.android |
| MD5 | 9B59F13114976FF6B54B64FBD6650616 |
| 系统要求 | 安卓 5.2 以上（渠道标注值，以安装时的实际提示为准） |

用手机上的文件管理器或 MD5 校验工具算一下安装包的 MD5，与上表一致说明文件完整、没有被改动过。版本号和体积以你实际拿到的文件为准——网上搜到的「最新版」与这份安装包不一定同一个版本，不影响正常安装使用。

## 二、从哪里拿安装包

安装包从 [lutube 安装文件资源（夸克网盘）](https://pan.quark.cn/s/958002d9bd3a) 获取，完整步骤是：

1. 打开网盘链接，选择**转存到我的网盘**（直接下载也可以，但转存更稳）；
2. 在自己的网盘里找到对应文件夹，下载其中的 APK 文件到手机本地存储；
3. 下载完成后在通知栏或「文件管理 → 下载」里找到这个 APK。

手机存储空间紧张的话，先确认剩余空间大于 100M——安装包本身 27.51M，安装过程还需要额外的解压空间。

## 三、安装步骤（重点是放行未知来源）

安卓默认禁止安装商店之外的应用，所以第一次装会卡在授权这一步：

1. 点击下载好的 APK，系统弹出「禁止安装」或「出于安全考虑」提示；
2. 点提示框里的**设置**（或「更多设置」）；
3. 找到**允许安装来自此来源的应用**（安卓 8.0 以后按来源授权，授权的是你用的文件管理器或浏览器，不是 lutube 本身），打开开关；
4. 返回安装界面，点**继续安装**，等待完成。

老一些的安卓版本（8.0 之前）则是「设置 → 安全 → 未知来源」整体开关，勾选后安装，装完建议把开关关回去。

## 四、提示「风险应用」或报毒时怎么处理

有不少用户反馈，安装这类从网页分发的 APK 时，手机管家或杀毒软件会弹「风险应用」「恶意软件」提示。这是分发渠道的常见现象，不代表文件一定有问题，你可以这样核实：

1. **先核对 MD5**：回到第一节那张表，算出来的 MD5 与 `9B59F13114976FF6B54B64FBD6650616` 一致，说明文件和发布时是同一份；
2. **确认后仍要装**：在杀毒软件的拦截提示里选择「继续安装」或「信任此应用」，不同品牌的入口名称略有差异；
3. **无法确认来源时不要硬装**：如果你手里的安装包不是从上文网盘入口拿的，MD5 又对不上，稳妥的做法是重新获取一份。

装完之后如果打开闪退、或视频放不出来，去 [常见问题排查.md](常见问题排查.md) 按现象找对应处理办法。

## 五、华为 / 鸿蒙手机额外一步

华为鸿蒙系统默认开启**纯净模式**，只允许从应用市场安装应用，直接装 APK 会被拦下。处理办法：

1. 打开「设置」，搜索**纯净模式**（部分版本在「安全和隐私」里）；
2. 选择**关闭纯净模式**（部分版本叫「退出增强模式」）；
3. 回到文件管理重新点击 APK 安装。

其他品牌的类似功能：小米叫「纯净模式」，OPPO 系叫「安装防护」，处理思路相同——临时关闭、装完可以再开回来。装好之后首次打开的登录操作，见 [账号登录与注销步骤.md](账号登录与注销步骤.md)。
