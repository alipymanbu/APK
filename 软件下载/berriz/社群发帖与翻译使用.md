## 一、发帖前先对这张限制表

Berriz 社群能发什么、能发多少，官方给了一套硬数字：帖子 10000 字符、留言 300 字符、图片单张 10MB。翻译和语言设置也在同一套菜单里。本篇把这些限制与路径整理成可照做的清单。

| 项目 | 限制 |
| --- | --- |
| 帖子正文 | 最多 10000 字符 |
| 图片 | 最多 10 张，单张 10MB 以内 |
| 链接 | 最多 1 个，仅支持 Berriz、YouTube、X（原 Twitter）、Instagram、Melon |
| 草稿 | 不提供临时保存，写到一半退出就没了 |

违反服务指南或让他人不适的帖子、留言会被直接删除且不事先通知；上传前自己确认一遍内容版权与来源。

## 二、留言的三条规则

1. **最多 300 字符**，发布后**不能修改** —— 要改就删掉重发。
2. 短时间内大量发布会被**临时限流**，等一会儿再发。
3. 艺人发的留言固定在顶部、按时间倒序显示，最多展示 30 条 —— 想翻更早的艺人留言不必往下拉。

## 三、翻译功能怎么触发

- **社群内**：点内容旁的"翻译"按钮，即时翻译该条内容。
- **直播聊天**：艺人发的消息会按你设置的翻译语言**自动翻译**，不用逐条点。
- 翻译语言共 18 种，与应用语言是两套设置，可以"界面用中文、翻译成日文"这样混搭。

## 四、语言设置的三端路径

应用语言目前提供 4 种：韩语、英语、日语、汉语（简体），默认跟随设备语言。改法：

| 端 | 路径 |
| --- | --- |
| 应用 | 登录 → 设置 → 应用程序使用环境设置 → 应用语言 / 翻译语言 |
| 手机网页 | 登录 → 设置 → 服务语言设置 → 服务语言 / 翻译语言 |
| 电脑 | 登录 → 右上角我的图标 → 语言 / Language → 服务语言 / 翻译语言 |

两个坑：**语言设置只对当前设备生效**，换新设备登录要重新设一次；改完没变化就**重启应用**再看。

## 五、资料被改、被限了怎么办

头像或昵称因不当内容受限时，系统可能不通知就替你改掉；多次受限会进一步限制你在该社群的活动。觉得改得不对，走官方客服中心的 1:1 咨询申诉。

想在社群里攒数字道具的话，发帖、评论、点赞都算活动，产出的贴纸进收纳柜（该功能见官方客服中心 FAQ）；会员专属内容见 [粉丝俱乐部会员认证.md](粉丝俱乐部会员认证.md)，直播端的翻译与环境要求见 [直播与常见问题.md](直播与常见问题.md)。
