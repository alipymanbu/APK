## 一、开播前先对环境

直播看不看得了，官方客服中心给了明确门槛：20Mbps 以上网络、Android 10+/iOS 16+、电脑端最新版 Chrome/Safari/Edge。环境达标还打不开，多半是浏览器设置没放行。本篇先对环境再排查。

| 项目 | 官方要求 |
| --- | --- |
| 网络 | 建议 20Mbps 以上，不满足时观看可能受限 |
| Android | 10 及以上，并安装最新版本的 Berriz 应用 |
| iOS | 16 及以上 |
| Windows | 10 及以上 |
| macOS | 官方标注"10 及以上"（照客服中心原文，以官方页面当时显示为准） |
| 浏览器 | 最新版 Chrome、Safari、Edge |

注意"最新版本应用"这条：如果你手机上装的是网盘里那份 1.12.0，直播能否正常进以实际播放为准，进不去就先升级到官方最新版再试。

## 二、电脑播放器打不开

官方给的排查点就三个，检查浏览器里这三项是否都设为"允许"：

1. **受保护的内容**（受保护媒体 / DRM 相关设置）；
2. **JavaScript**；
3. **Cookie**。

三项全开后刷新页面再进直播间。

## 三、其他高频问题速查

| 问题 | 处理 |
| --- | --- |
| 语言改了没变化 | 重启应用；换新设备登录后要重新设置（路径见 [社群发帖与翻译使用.md](社群发帖与翻译使用.md)） |
| 登录被提示要解锁 | 按提示收验证邮件解锁，流程见 [注册与登录指南.md](注册与登录指南.md) |
| 应用打开就闪退 | 依次试：重启手机 → 长按图标进"应用信息 → 存储占用"清缓存 → 升级到最新版 → 卸载重装（装回后要重新登录） |
| APK 装不上 | 按 [下载与安装教程.md](下载与安装教程.md) 的排查表逐行试 |
| 直播卡顿 | 先确认网速达标；Wi-Fi 与移动数据换着试一次 |
