## 一、一句话定位

Xender 是「设备直连传文件」的工具：两台设备自己建链路，文件不经过任何服务器，所以**没网也能传、也不按流量计费**。下面按「能传什么 → 传多快 → 附带功能」三块讲，帮你判断它是不是你要的那个工具。

## 二、支持的文件类型

官方列的范围是全类型文件，没有按后缀做限制：

- 图片（照片、截图、动图）
- 音频（音乐、录音）
- 视频（含大体积电影文件）
- 办公文档（PDF、表格、演示文稿等）
- 应用安装包（APK，含已装应用导出）
- 任意其它文件 / 整个文件夹

两条官方口径值得注意：

- **传输中不压缩**——照片和视频按原字节过去，不会出现「传过去画质变差」；
- **不限制单个文件大小**——传几个 G 的视频不用切片，实际能否一次成功还取决于两台设备的剩余空间与电量。

## 三、速度

官方页强调「快」但没给数字；流传较广的约 40 MB/s 是第三方在 Wi-Fi 6 设备上的实测参考值。真实速度由三件事决定：

1. 两台设备里**较慢的那台**的 Wi-Fi 网卡（老设备 802.11n 是硬上限）；
2. 频段与距离——5 GHz 快但穿墙弱，2.4 GHz 稳但慢；
3. 是否同网直连——绕开路由器、由一台建热点直连，通常最稳。

传输不耗流量、也不需要互联网；只有连电脑时若不同 Wi-Fi 会退到 Cloud Mode（限 10 MB，见[连接电脑传输文件.md](连接电脑传输文件.md)）。

## 四、附带的功能

Xender 不只是传输管道，应用内还带着这些：

| 功能 | 你会怎么用到 |
| --- | --- |
| 文件管理器 | 浏览、删除、整理手机文件；可当个轻量文件管理器使 |
| 换机搬家（Replicate） | 一键把旧机数据导进新机，见[手机之间传文件与换机.md](手机之间传文件与换机.md) |
| 群发 | 同一批文件发给多台设备，一次连、多台收 |
| 内置播放 | 收到的音视频不离开应用就能预览 |
| 社交平台内容保存 | 官方页列有 WhatsApp、Instagram、TikTok 等平台的视频/状态保存入口，以及 YouTube 转 MP3（Tomp3）；入口是否可用取决于版本与地区 |
| 存储位置切换 | 设置里可把收件目录改到 SD 卡（有卡槽才显示） |

## 五、平台覆盖

| 平台 | 客户端 |
| --- | --- |
| 安卓 | Google Play 或 APK 安装 |
| iPhone / iPad | App Store |
| Windows / Mac / Linux | 不用装软件，浏览器开 `web.xender.com` 扫码 |

跨平台互传都要求**双方都装了 Xender**（电脑除外，浏览器即可）。安卓传 iPhone 的具体步骤在[手机之间传文件与换机.md](手机之间传文件与换机.md)。

## 六、它不做什么

- 不做云端存储——文件不落服务器，也就没有「换个手机登录就能下载」这回事，换机得靠 Replicate 现场搬；
- 不做微信式的聊天与转发——它是点对点管道，两端都得在场；
- 不承诺跨公网传输——两台设备必须能互相发现（同网或直连热点），这是它「免流量」的另一面。
