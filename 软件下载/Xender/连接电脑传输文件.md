# Xender 连接电脑传输文件

## 一、先选哪条路

官方 FAQ 把手机连电脑分成两种模式，差别只在**两台设备是不是在同一个 Wi-Fi 上**：

| | Direct Mode（直连模式） | Cloud Mode（云端模式） |
| --- | --- | --- |
| 前提 | 手机和电脑连**同一个 Wi-Fi** | 不在同一 Wi-Fi |
| 传输量限制 | 无 | **单次 10 MB** |
| 适合 | 传照片、视频、整个文件夹 | 临时救急传个小文件 |

结论很直白：**能同网就同网**，用 Direct Mode；Cloud Mode 那个 10 MB 上限连一首高清歌都勉强，别指望它干重活。

电脑端**不用装任何软件**，浏览器就是客户端——Windows、Mac、Linux 都一样。

## 二、同 Wi-Fi 扫码（推荐）

1. 电脑浏览器打开 `web.xender.com`，页面上会出现一个二维码。
2. 手机打开 Xender，点 **Connect PC**（连接电脑）。
3. 用手机扫电脑屏幕上的码，两台设备自动连上。
4. 之后双向都能拖：把电脑文件拖进浏览器页签 = 存进手机；在页面里点手机上的文件 = 下载到电脑。

连之前先确认三件事，少一件就可能扫了没反应：

- 手机和电脑在**同一个 Wi-Fi 名**下（路由器把 2.4 GHz 与 5 GHz 拆成两个名字时，两边要在同一个名字下；访客网络通常会隔离设备，别用）；
- 两边的 **VPN 都先关掉**（VPN 会打断局域网互相发现）；
- Windows 首次弹防火墙提示时点**允许访问**，这一次点完以后都不再问。

## 三、没有 Wi-Fi 时：用手机热点直连

室外、酒店、没有路由器的场合，反过来让电脑连手机的热点：

1. 手机 Xender 里切到 **Connect PC** 模式，按提示打开**个人热点**。
2. 电脑连上这个手机热点。
3. 手机屏幕上会给出一个局域网地址，形如 `http://192.168.43.1:33455`。
4. 电脑浏览器**原样输入这个地址**（连端口号一起，别删 `http://`、别改写成 `https://`，输在地址栏而不是搜索框里），手机端点确认，即连上。

这条路同样不耗流量——热点是本地直连，数据没有出这台手机。传大文件时把手机屏幕保持常亮，熄屏容易中断（详见[连接失败与传输慢的排查.md](连接失败与传输慢的排查.md)）。

## 四、传输中的三个实用细节

- **速度上限取决于 Wi-Fi 硬件**：有第三方实测给出约 40 MB/s 的峰值（Wi-Fi 6 设备上），老手机的 802.11n 网卡才是瓶颈，换网络没用，得换设备；实际以你自己的环境为准。
- **文件不压缩**：图片、视频按原样过去，不会像聊天软件那样被压一轮（官方口径）。
- **会话会超时**：浏览器页面放太久不动会断开，重新扫一次码即可，文件不受影响。

## 五、连不上时

扫码没反应、页面打不开、传到一半断，这类问题九成出在网络环境而不是软件本身，按顺序过一遍：同网判断 → VPN → 防火墙 → 手机亮屏，完整清单在[连接失败与传输慢的排查.md](连接失败与传输慢的排查.md)。安装与权限没配好的情况，则回到[下载与安装教程.md](下载与安装教程.md)。
