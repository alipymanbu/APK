## 一、先做的三个基础动作

1. 两台设备把 Xender **完全划掉重开**（从最近任务里划掉，不是按 Home），设备列表会刷新。
2. 两台设备**重启一次**——系统层的 Wi-Fi/P2P 状态卡住时，应用怎么点都没用。
3. 换个角色试：原本接收的改成发送，经常一换就连上了。

做完还不好，再按下面的症状对号入座。

## 二、搜不到对方设备

| 检查项 | 怎么查、怎么改 |
| --- | --- |
| 定位权限 | 安卓 12 起没有定位权限就扫描不了附近设备。**设置 → 应用 → Xender → 权限 → 位置**，打开；同时确认**精确定位**开关是开的，只给「大致位置」常常仍连不上 |
| Wi-Fi / 热点权限 | 同一页面把「更改 Wi-Fi 连接状态」（或近场设备）给到允许 |
| 两台设备不在同一网络 | 同 Wi-Fi 场景下两边要在**同一个 Wi-Fi 名**下；路由器把 2.4 G 与 5 G 拆成两个名字时最容易踩；**访客网络默认隔离设备**，别用 |
| 移动数据干扰 | 安卓的「智能网络切换」会因为热点「没网」把它关掉——传的时候**把两台的移动数据都关掉** |
| VPN / 广告拦截 | 任何一边开着 VPN 都会打断局域网发现，配对期间先关，连上后再开回来 |
| 位置离得远 / 有遮挡 | 两台设备靠近点，隔墙会明显衰减 |

## 三、连电脑时扫码没反应

按[连接电脑传输文件.md](连接电脑传输文件.md)的三条前提逐条核：同网判断（含访客网络、双频拆名）→ 两边 VPN → Windows 防火墙点「允许访问」。手机端在热点直连模式下，电脑要输入的是屏幕上**带端口号的完整地址**（形如 `http://192.168.43.1:33455`），漏掉端口或写进搜索框都会打不开。

扫不动二维码本身，则把发送方屏幕**亮度调高**、擦一下接收方摄像头镜片，再拉近距离重扫。

## 四、传到一半停住

- **屏幕熄了**：大文件传输期间保持亮屏，或找到应用内的「传输时保持常亮」开关打开。
- **被系统杀了**：**设置 → 应用 → Xender → 电池 → 不限制**（各 ROM 也叫「无限制」「允许后台活动」）。省电模式也会限后台，传的时候先关省电。
- **同一时间在跑下载/更新**：把后台大流量任务停掉，让出带宽与 CPU。

## 五、速度太慢（明显低于预期）

| 现象 | 原因与处理 |
| --- | --- |
| 只有几百 KB/s ~ 几 MB/s | 一端是老网卡（802.11n），硬件就是天花板——换 5 GHz 频段、或换台新点的设备 |
| 忽快忽慢 | 两台离路由器太远 / 中间隔承重墙；靠近一点，或改成手机建热点直连（不经过路由器） |
| 电脑端慢 | 电脑用网线接同一台路由器，绕开无线网卡瓶颈 |
| 走了 Cloud Mode | 没在同一 Wi-Fi 时会退到云端模式，官方标明限 10 MB —— 让两台连同一个 Wi-Fi 即可 |

第三方实测在 Wi-Fi 6 设备上可达约 40 MB/s 量级，但那是设备条件都拉满的参考值，实际以你环境里跑出来的为准。

## 六、装不上 / 打开就闪退

- **解析错误、安装包损坏**：下载不完整——重新下载并核对 MD5（见[下载与安装教程.md](下载与安装教程.md)的参数表），或系统低于安卓 5.2。
- **打开即闪退**：先清缓存——**设置 → 应用 → Xender → 存储 → 清除缓存**（别点「清除数据」，会把设置一起清掉），再重启应用；仍崩就重启手机，最后再考虑重装。
- **文件列表是空的**：存储权限没给，去权限页把「文件 / 所有文件访问」打开。

以上都试过仍无解，重装一遍：先卸载、再装（跨大版本升级偶尔会报包冲突，先卸再装能绕开）。
