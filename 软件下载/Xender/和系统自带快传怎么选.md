## 一、三句话说清各自是谁

- **Quick Share**：谷歌自带（2024 年由 Nearby Share 更名），安卓 8.0+、ChromeOS、Windows 上开箱即用，不用装新应用；但**不支持 iOS 与 Mac**（截至 2026-09 未提供 macOS 客户端）。
- **LocalSend**：开源跨平台（安卓 / iOS / Windows / macOS / Linux），官网标注端到端加密、无广告无追踪、不用账号。
- **Xender**：第三方老牌工具，覆盖安卓 / iPhone / 电脑浏览器，功能最杂（换机搬家、群发、内置文件管理），代价是有广告，加密口径见[安全与隐私说明.md](安全与隐私说明.md)。

## 二、对照表

| | Quick Share | LocalSend | Xender |
| --- | --- | --- | --- |
| 双方都要装吗 | 安卓新机基本自带 | 是（全平台都装） | 手机要装，电脑用浏览器即可 |
| 支持 iOS / Mac | 否 | 是 | 是（iPhone 装 App、电脑开网页） |
| 免流量离线传 | 是 | 是 | 是 |
| 需要账号 | 需谷歌账号在场做配对 | 不需要 | 不需要 |
| 广告 | 无 | 无 | 有 |
| 加密口径 | 系统级（谷歌实现） | 官网标注端到端加密 | 官方称传输加密，非端到端（见[安全与隐私说明.md](安全与隐私说明.md)） |
| 传速度 | 有第三方测试约 80 MB/s 量级 | 官网称跑满本机 Wi-Fi 上限 | 官方口径最高约 40 MB/s |
| 拿手好戏 | 安卓机之间小文件秒传 | 混合系统 + 在意隐私 | 对端是 iPhone / 老电脑、换机搬家、群发 |

速度数字全部是各工具口径与第三方测试的参考值，受设备网卡、频段影响大，以你自己两台设备实测为准。

## 三、按场景选

1. **两台都是安卓新机，传一两张图**：直接用 Quick Share，不用装任何东西。
2. **对端是 iPhone 或 Mac**：Quick Share 走不通，用 Xender（流程见[手机之间传文件与换机.md](手机之间传文件与换机.md)）。
3. **电脑只是临时收个文件**：Xender 开浏览器扫码即可（[连接电脑传输文件.md](连接电脑传输文件.md)），不用给电脑装软件。
4. **混合系统、传得多、介意广告与加密**：给常传的设备都装上 LocalSend，一次配置长期用。
5. **换新手机整机搬家**：用 Xender 的 Replicate（[手机之间传文件与换机.md](手机之间传文件与换机.md)），系统自带的换机向导也是备选。
6. **一根 USB 线就能解决的大批量传输**：永远最快也最稳，无线工具的价值在于没线、人不在跟前的时候。
