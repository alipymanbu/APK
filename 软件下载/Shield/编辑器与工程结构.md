## 一、底部四个标签

打开 Shield 后，屏幕底部一共四个标签：左端第一个标着「主页」，第三个是「市场」；中间的书本图标与最右侧的人形图标对应工程和个人相关页面，名称以你界面上的显示为准。下面按你会碰到的顺序逐个说。

## 二、主页：已装应用一览

主页是一张竖向列表，把设备上已安装的应用逐行列出，每行三样信息：应用名、版本号、完整包名，行尾还有一个带小虫图标的圆形按钮。想确认「这个应用到底是哪个包」「手机里装了几个同类应用」，在这里翻比去系统设置里一层层点快得多。应用装得多时，点右上角的放大镜按名字搜。

列表里出现陌生包名又想知道它是哪来的，可以对着包名先搜一下再决定动不动它。

## 三、编辑器界面

进入代码编辑页后，你会看到这些部件：

| 部件 | 位置 | 用途 |
| --- | --- | --- |
| 文件名标签 | 代码区顶部 | 显示当前打开的文件，如 main.lua |
| 行号 | 左侧灰色列 | 对照报错信息定位出错的行 |
| 语法高亮 | 正文 | 字符串、关键字、注释用不同颜色区分 |
| 运行按钮 | 顶栏三角图标 | 运行当前脚本 |
| 撤销 / 重做 | 顶栏弧形箭头 | 回退或恢复刚才的编辑 |
| 更多菜单 | 顶栏三点 | 其余编辑操作 |
| 符号快捷栏 | 屏幕底部 | 一键输入 `( ) [ ] { }` 引号、等号等编程符号 |

顶栏左侧显示当前工程名。要在多个文件之间切换，用工程抽屉（下一节）。

## 四、工程目录与文件角色

编辑页左上角展开抽屉，能看到工程内的文件树。从抽屉顶部显示的路径看，工程放在手机内部存储的 `AndroLua/project/<项目名>/` 目录下，典型的结构是这样：

```text
AndroLua/project/<项目名>/
├── java/
├── init.lua
├── layout.aly
└── main.lua
```

几个文件的角色：`main.lua` 是入口脚本，编辑页里点运行时执行的就是它；`layout.aly` 承载界面布局描述，是 AndroLua+ 体系的布局文件；`init.lua` 记着工程的应用名、版本与包名，打包成 APK 时靠它。各文件更细的分工与打包规则见 [AndroLua工程与打包.md](AndroLua工程与打包.md)；市场里数量最多的 ALP 文件就是这一整套工程的打包形式，见 [市场与文件类型.md](市场与文件类型.md)。

## 五、运行一个脚本

编辑页顶栏点三角图标即可运行当前脚本；改错了随时用顶栏的撤销箭头退回。跑不起来或报错时，Lua 的报错信息通常带脚本名与行号，对照编辑器左侧行号就能定位到出错那行；更多排查思路见 [常见问题与排查.md](常见问题与排查.md)。
