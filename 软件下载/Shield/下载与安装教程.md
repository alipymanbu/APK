## 一、装之前先认识它

Shield 是一款运行在安卓手机上的 Lua 开发工具：打开后能看到设备上已装应用的名称、版本与包名列表，内置带语法高亮与行号的 Lua 代码编辑器，可以直接打开并运行 AndroLua+ 风格的工程，另有一个按文件类型归档在线内容的「市场」页。作者在 GitHub 上有公开主页（[github.com/Depolarization](https://github.com/Depolarization)），名下还有其他安卓开发工具项目。

这款应用没有上架常见应用商店，获取方式以 APK 安装包直接安装为主，下文按这个路径走。

## 二、核对安装包信息

从网盘拿到安装包后，先对照下表确认这份包的基本信息。网上能搜到的可能是更新的版本，**这里的数字只对你拿到的这份安装包负责**：

| 项目 | 内容 |
| --- | --- |
| 版本号 | 2.0 |
| 包名 | `github.depolarization.shield` |
| 安装包大小 | 约 19.16 MB |
| 系统要求 | 安卓 5.2 及以上 |
| MD5 | 250EF359BFC6FC74822F711495D4B531 |

版本号以后可能更新，以你实际拿到的安装包为准。

## 三、下载与安装步骤

1. 打开 **Shield 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/1ba1905718c4](https://pan.quark.cn/s/1ba1905718c4)，把安装包转存到自己的网盘后用手机下载，或先下到电脑再传到手机；
2. 在手机的文件管理器里找到这个 APK 文件，点它开始安装；
3. 首次安装会弹出「未知来源」提示：按提示去系统设置里允许你的文件管理器「安装未知应用」，再返回继续安装；
4. 等安装完成，点「打开」。

不同品牌手机的授权入口不一样，找不到开关时在系统设置里直接搜「未知来源」或「安装未知应用」。

## 四、核对 MD5（可选但建议）

安装前可以校验一下文件完整性：用文件管理器自带的属性页，或任意 MD5 校验工具读出 APK 的 MD5 值，与第二节的 `250EF359BFC6FC74822F711495D4B531` 对比。不一致说明文件在传输中损坏或不完整，重新下载一次即可。

## 五、首次打开

安装完成首次打开，你会停在「主页」标签：一张已安装应用的列表，每行显示应用名、版本号和包名，右上角是搜索入口；底部还有工程、市场等标签。各界面怎么用，接着看 [编辑器与工程结构.md](编辑器与工程结构.md)。

装的过程卡住了，直接翻 [常见问题与排查.md](常见问题与排查.md)。
