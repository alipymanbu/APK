## 一、市场页长什么样

底部切到「市场」标签，会看到一张按文件类型分组的卡片列表：每张卡片上是类型缩写、文件数量和一句中文说明，右上角还有一个下载图标。点进某一类，就能看到这类文件的具体条目。

## 二、类型对照表

市场里出现的类型缩写与含义如下（数字会随时间变化，以你打开时的界面为准）：

| 缩写 | 界面里的说明 | 是什么 |
| --- | --- | --- |
| CPP | C++语言文件 | C/C++ 源码文件 |
| ALP | AndroLua+工程文件 | AndroLua+ 的工程文件，对应编辑器里打开的那套工程 |
| APK | Android程序包文件 | 安卓安装包 |
| REG | Windows注册表文件 | Windows 注册表脚本 |
| APPX | Windows分配文件 | Windows 应用安装包 |
| M3U8 | （界面未标注） | 常见的视频播放列表索引格式 |

当时看到的量级：ALP 一类有 3000 余个文件、APK 一类 1000 余个，其余类型多为个位数。你打开时数字明显不同属正常，列表内容一直在变。

## 三、ALP 工程文件怎么用

ALP 是市场里数量最多的一类，它和 [编辑器与工程结构.md](编辑器与工程结构.md) 里说的工程是同一套东西：`main.lua` 入口、`layout.aly` 布局、`init.lua` 与 `java/` 目录。从市场把 ALP 文件拿到手后，从工程入口或文件管理器打开即可在编辑器里继续编辑、运行；具体入口位置以你界面上的显示为准。工程文件各自管什么、怎么从工程打成 APK，见 [AndroLua工程与打包.md](AndroLua工程与打包.md)。

拿不准某个 ALP 文件里装的是什么时，先看它在市场里的名称与说明，别急着导入运行——来路不明的脚本和来路不明的 APK 一样要留个心眼。

## 四、下载 APK 类文件前想一下

市场里的 APK 与你从 [下载与安装教程.md](下载与安装教程.md) 拿到的 Shield 安装包不是一回事：那些是第三方上传的应用，来源与完整性都没有保证。安装前留意三点：

1. 确认文件名与说明和你想要的东西一致；
2. 系统「安装未知应用」授权只授给你信任的那个文件管理器，不要全局放开；
3. 装完若出现频繁弹窗、后台耗电异常等行为，直接卸载。
