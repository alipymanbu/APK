# TVBox 电视盒子安装与遥控器操作

> 本篇讲把安装包送进电视盒子的两条路径（U 盘与 adb），以及用遥控器操作大屏界面时要注意的几点。

电视盒子装应用比手机麻烦一点，麻烦的地方不在应用本身，而在盒子的系统限制与遥控器这种输入方式。本篇把这两件事拆开讲。

## 一、先确认盒子能不能装

三条都满足再往下走：Android 5.0 及以上；ARM 架构（这份包只含 `armeabi-v7a` / `arm64-v8a`）；系统允许安装第三方应用（部分定制系统会禁止侧载，需要在设置里打开「允许安装未知来源应用」或开发者选项）。

安装包从 [TVBox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/68ea6aef41ac) 取。

## 二、U 盘安装（不需要电脑，最省事）

1. 在电脑上把 APK 拷到 U 盘根目录，文件名用纯英文更省事；
2. U 盘插到盒子上，打开盒子自带的「文件管理 / 媒体中心」类应用找到这个文件；
3. 点击安装。若盒子提示「不支持该文件类型」或找不到 APK，先在盒子上装一个第三方文件管理器，用它的安装入口打开；
4. 安装过程中如果报「应用未安装」，多数是第三节说过的签名冲突，或系统版本不达标。

## 三、用 adb 安装（手上有电脑时更稳）

适合盒子已经能进开发者选项、或者你想批量装多台设备的情况。先把调试打开：在盒子「开发者选项」里开启 USB 调试 / 网络调试（部分盒子需要连点「版本号」七次才会出现开发者选项）。

```bash
adb connect 192.168.1.100:5555
adb install -r TVBox.apk
```

- `adb connect` 的地址换成盒子在路由器上拿到的局域网 IP，端口默认 `5555`；
- 盒子重启后调试端口通常会关掉，需要重新 connect；
- 同一台盒子上先装了别的 TVBox 变体时，`adb install` 也会因签名不一致失败，加 `-r` 覆盖不了，得先 `adb uninstall` 卸载旧的。

## 四、遥控器怎么用

大屏界面靠**焦点**走，不是触摸：方向键移动焦点，确认键执行，返回键退出。三点容易上手不顺：

- **焦点会乱跑**。列表滚动、弹窗出现时焦点可能被界面抢走 —— 这是这类应用在盒子上的常见现象，方向键再推一下通常就回来了；
- **菜单键要会用**。很多操作（切换线路、调整画面、调出播放菜单）在长按确认键或菜单键后的弹层里，只看画面上的按钮是找不到的；
- **输入配置地址很痛苦**。用遥控器一个字一个字敲长地址非常费劲，能用手机端推送就尽量用推送；没有推送条件时，把配置放到 U 盘或共享目录里再导入，也比手敲省事。

实在用不惯遥控器，可以外接 USB 鼠标或飞鼠（体感遥控器），操作会接近手机。

## 五、大屏显示上的两件事

**字小、界面被裁。** 先在电视的「画面比例 / 屏幕缩放」里确认是「全屏/16:9」而不是「点对点」；改完再回应用里调画面比例，顺序反了会白调。

**播放画面被拉伸或上下有黑边。** 这是应用内的画面比例设置，不是电视的问题，怎么选见 [播放内核与画面设置.md](播放内核与画面设置.md)。

## 六、装完的检查清单

1. 应用能正常打开，首页是空白的（正常）；
2. 遥控器方向键能把焦点送到设置入口；
3. 授予存储权限后，能读到 U 盘或本地目录里的视频文件。

装完打不开、或者装上就退回桌面，按 [常见问题与排查.md](常见问题与排查.md) 里「装不上 / 打不开」那几行逐条排除。安装包与后续版本统一从 [TVBox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/68ea6aef41ac) 取用。
