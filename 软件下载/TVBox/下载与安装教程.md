TVBox 是安卓上的开源影视播放器，它本身不含内容：装完首页是空的，要你自己准备一份配置文件才会有可看的东西。本篇只解决一件事 —— 把网盘里这份包装进设备，并把第一次打开要配的几项配齐。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本号通常是当时的最新发布版，而网盘里这份是制作文档时核对过的版本，两者未必是同一个。本文所有版本号、包名、体积以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | TVBox |
| 版本号 | 1.0.20260227-1116 |
| 包名 | `com.github.tvbox.osc.tk` |
| 安装包体积 | 28.21 MB |
| MD5 | `d9c8abc7a393430d41a5ee48b421f7c5` |
| 系统要求 | Android 5.0 及以上 |

安装包本体在 [TVBox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/68ea6aef41ac) 里，转存到自己网盘后下载即可。

有两点得先说明白：

- **版本号怎么读**。这个应用的版本号形如 `1.0.<打包日期>-<时刻>`，后半段就是构建时间。所以「日期靠后的更新」这个判断是成立的，而网上流传的版本极多、名字也相近，认打包时间比认名字可靠。
- **包名分叉**。同一个 TVBox 名下有多个分支与再编译版，包名各不相同（本文这份是 `com.github.tvbox.osc.tk`）。包名不同就是两个独立应用，**不能互相覆盖安装**，数据也不互通。如果你之前装过别的版本，先想清楚要留哪一个。

## 二、装之前要核对的两件事

**第一，系统版本。** 这份构建要求 Android 5.0 及以上。停在 4.x 的老盒子、老电视即使装上，也可能打不开或闪退。

**第二，芯片架构。** 这份包只包含 `armeabi-v7a` 与 `arm64-v8a` 两种 ARM 架构，**没有 x86 版本**。绝大多数电视盒子和手机都是 ARM，但少数 x86 平板与模拟器会装不上。

## 三、安装步骤

1. **转存并下载**：从 [TVBox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/68ea6aef41ac) 把 APK 转存到自己网盘，再下载到手机或电脑；
2. **把包送到设备上**：手机端直接下载最省事；电视盒子用 U 盘或 adb 安装，具体操作见 [电视盒子安装与遥控器操作.md](电视盒子安装与遥控器操作.md)；
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关；
4. **签名冲突就先卸载**：设备里若已有同包名、不同签名的 TVBox 变体，安装会报错退出。先卸掉旧的那个再装；
5. **装完先别急着找内容**：先把下一节的三项过一遍。

## 四、第一次打开要做的事

打开后你会看到一个空白首页 —— **这是正常的，不是装坏了**。TVBox 是「壳」，首页要等配置里指定了站点，才会长出海报与分类。

需要处理的三项：

| 要做的 | 在哪 | 说明 |
| --- | --- | --- |
| 授予存储权限 | 首次启动的系统弹窗 | 读本地视频、导入配置文件都要用它 |
| 找到设置页 | 首页的「设置 / 我的」入口 | 配置地址、播放器内核等都在这里改 |
| 填配置地址 | 设置里的配置相关项 | 应用按这份配置请求第三方站点，首页才会出现内容 |

配置本身是一份 JSON（含站点、解析、直播等字段），由外部提供，可用性也由外部决定。有一点要提前知道：它是**存在应用里的、不跟账号走** —— 换设备（比如手机换到盒子）要各自填一遍，或者把配置文件带过去导入。**本文只说明这个机制，不涉及任何具体的配置来源**；这类地址的稳定性与内容来源都与本应用无关，请自行判断后再用。

## 五、装完做一次最小验证

暂时没有配置也不影响先验证播放链路：

1. 往设备里放一个常见格式的视频文件（MP4、MKV 都行）；
2. 在应用里用文件选择的方式打开它；
3. 能正常出画面、出声音，说明安装与解码都没问题。

卡在第一步，先看 [常见问题与排查.md](常见问题与排查.md)。想直接放电脑或 NAS 上的片子，接着看 [本地与局域网视频播放.md](本地与局域网视频播放.md)。

安装包与后续版本更新，统一从 [TVBox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/68ea6aef41ac) 取用。
