## 一、现象速查

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 安装包点不开、解析失败 | 文件没下完，或系统版本低于 Android 5.0 | 重新下载安装包；核对系统版本 |
| 提示「应用未安装」「签名不一致」 | 设备里已有同包名、不同签名的变体 | 先卸载旧的那个再装 |
| 装上打开就退回桌面 | 系统版本不够，或芯片架构不是 ARM | 换设备，或换到匹配的构建 |
| 首页空白 | 尚未填配置，或配置里的站点已失效 | 属正常现象，见第二节 |
| 能打开但一直转圈、播不出来 | 源站限速、线路失效、晚高峰 | 换线路，或换个时间再试 |
| 找不到想看的内容 | 当前配置覆盖的站点里确实没有 | 不是应用故障，见第二节 |
| 画面卡、音画不同步、花屏 | 解码方式或内核不匹配 | 见 [播放内核与画面设置.md](播放内核与画面设置.md) |
| 字幕挂不上或乱码 | 文件名规则、字幕编码、内核支持 | 见 [字幕音轨与弹幕设置.md](字幕音轨与弹幕设置.md) |
| 局域网共享连不上 | 不在同一网段、账号权限、SMB 版本 | 见 [本地与局域网视频播放.md](本地与局域网视频播放.md) |
| 遥控器焦点乱跳、按了没反应 | 大屏焦点适配问题 | 见 [电视盒子安装与遥控器操作.md](电视盒子安装与遥控器操作.md) |

## 二、首页空白不是故障

这是最容易被误判的一条。TVBox 自身不带任何内容，**首页空白正是它未经配置时的正常样子**。判断标准很简单：

- 空白 + 能进设置页 + 能播本地文件 → 一切正常，缺的只是配置；
- 空白 + 连设置页都进不去、或者打开就闪退 → 才是安装问题，回到上一节表格的头三行。

配置是一份由外部提供的 JSON，可用性也由外部决定，失效后首页会重新变空，这属于该机制的固有特性，不是应用坏了。**具体配置从哪里来不在本文讨论范围内**，请自行判断来源与内容后再使用。

## 三、卡顿要分清是网络还是解码

先粗分，再细查：**换个文件、换个时间各试一次**，把范围缩到「文件、时段、设备」三者之一：

- 只有某个文件卡、别的都正常 → 先怀疑文件本身，不是应用；
- 固定时段（比如晚上）整片卡 → 网络或源站侧限速，白天再试一次就能验证；
- 换到手机上同一个源流畅、盒子上卡 → 盒子的性能差异，属于正常现象。

粗分的结果指向网络或解码时，再按 [播放内核与画面设置.md](播放内核与画面设置.md) 最后一节的缓冲数去确认。**重装应用通常改善不了这三类问题**，白折腾一轮，还会把播放记录与已填配置清掉。

## 四、装完想回退或换版本

**同一支的版本升级**：直接装新版本覆盖即可，播放记录与已填配置通常都会保留 —— 这也是判断「这几个包算不算同一支」的实用办法：能覆盖安装的，就是同包名同签名。

**换回旧版本或换成别的分支**：必须先卸载再装。注意两点：卸载会清掉播放记录与已填配置；不同包名的变体属于不同应用，换包名等于重新开始，数据不会带过去。
