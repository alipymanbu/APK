## 一、先判断问题是不是信道

信号强度和信道拥挤是两回事，先用两分钟分清你要治的是哪一个：

| 现象 | 更可能是 | 该看哪篇 |
| --- | --- | --- |
| 离路由器远的位置慢，近的位置快 | 信号问题 | [信号强度与图表解读.md](信号强度与图表解读.md) |
| 任何位置都慢，但信号读数不差 | 信道拥挤/干扰 | 本篇 |
| 晚上特定时段才慢 | 邻居网络多起来后的信道竞争 | 本篇 + [测速与设备扫描.md](测速与设备扫描.md) |

判断依据很简单：在应用里看一眼周围有几个网络。公寓楼里 2.4GHz 频段扫出十几个网络很常见，大家挤在少数几个信道上，互相抢空气时间，谁都快不起来。

## 二、用信道评分找空闲信道

WiFi Analyzer 会给每个信道算一个占用评分，并有专门的信道推荐视图：

1. 切到信道评分页，应用会列出当前频段各信道的占用情况，并给出「当前网络最佳信道」和「新网络推荐信道」两类建议。
2. 评分越高（星级越多）的信道越空闲；评分低的信道说明周围网络挤在那里，要避开。把应用推荐的那个信道号记下来。
3. 对照主界面曲线图确认一下：目标信道那条横向位置上，曲线是不是确实稀疏。

一个常见的误读：自己家的网络现在用的信道，和应用推荐的不一样，这不奇怪——路由器默认信道多半是出厂设置，从没按环境调整过。

## 三、2.4GHz 与 5GHz 的差别

应用按频段分开显示网络，两个频段要分开看：

- **2.4GHz**：信道少、穿墙能力强、覆盖远，但也是大家默认都在用的频段，最拥挤。这个频段上互不重叠的信道组只有少数几个，通常认为 1、6、11 是首选；把路由器改到这三个之一、并避开邻居正在用的那个，是常规做法。另外，挤在这个频段的不是只有路由器——微波炉、蓝牙耳机、部分无线摄像头和婴儿监护器都工作在 2.4GHz 附近，它们一开动，曲线就会出现一阵明显的抖动，这正是「一到饭点网就卡」的常见来由。
- **5GHz**：信道数量多得多，互相重叠的情况少，速度上限也高，缺点是穿墙衰减快，隔一堵墙信号就明显变弱。设备支持的话，把「近距离高速用 5GHz、远距离覆盖交给 2.4GHz」是常见的搭配。
- **6GHz**：更新的版本支持分析 6GHz 频段（Wi-Fi 6E），但前提是手机和路由器硬件都支持；网盘里这份 v7.9 是否带这个频段的显示，以实际界面为准。

## 四、把路由器改到推荐信道

应用只负责告诉你该改到哪个信道，改的动作要在路由器管理界面完成：

1. 手机或电脑连上家里网络，浏览器进路由器管理地址（常见的是 `192.168.1.1` 或 `192.168.0.1`，具体以路由器背面标签为准）。
2. 找到「无线设置 / Wi-Fi 设置」里的「信道 / Channel」选项。
3. 从「自动」改成第二节里记下的信道号，保存，路由器会重启无线部分。
4. 回到应用再扫一遍，确认自己网络的曲线已经挪到了新信道上，且周围没有别的网络挤在同一位置。

改完信道后如果家里某个智能家居设备突然连不上网，先想到这一层：个别只支持 2.4GHz 的老设备对信道也挑（有的只认 1~11 这段），把它重新配一次网，或者把路由器信道在推荐结果里再换一个，通常就能解决。

改完之后用应用里的测速功能验证效果，见 [测速与设备扫描.md](测速与设备扫描.md)。如果 2.4GHz 实在避不开干扰（楼里网络太多），把常用设备切到 5GHz 往往比反复调信道更见效。
