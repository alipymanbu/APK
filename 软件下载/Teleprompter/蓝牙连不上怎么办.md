# Teleprompter 蓝牙遥控器连不上怎么办

> 遥控器搜索不到、配对失败、连上了但按键没反应时，按这篇的顺序排查，大多数情况出在电池、定位服务和配对路径上。

## 一、先看遥控器的指示灯

NEEWER 遥控器（RT113 说明书口径，其他型号同理）用指示灯颜色和状态区分两种模式：

| 指示灯状态 | 含义 |
| --- | --- |
| 蓝灯闪烁 | 正在配对模式，可以被搜到 |
| 蓝灯常亮 | 已经连上 |

搜索不到遥控器时，先确认它是不是还在闪烁——长按电源键重新开机，让它回到闪烁状态再搜。完全不亮基本就是电池问题，RT111/RT113 换新 AAA 电池，注意正负极。

## 二、搜不到设备：按这四步走

官方说明书给的排查顺序：

1. **电池**：确认装对、电量足（第一节）。
2. **蓝牙**：手机系统设置里确认蓝牙已开。
3. **定位服务**：把手机的定位服务（位置信息）也打开——部分机型的蓝牙扫描依赖它，这是官方页面特别提醒、也最容易漏的一步。
4. **重启两端**：遥控器关机重开一次，手机蓝牙开关一次或直接重启手机。

周围蓝牙设备多的时候（耳机、手表都连着），官方 FAQ 对同类问题的建议是把其他蓝牙连接先断开再搜，减少干扰。

## 三、配对路径不对：换一条路重试

这是官方材料里口径不太一致、也最值得试的一处：

- X14 的官方商品页**明确要求**遥控器在 Teleprompter 应用内连接，不要直接走系统蓝牙；
- X12 的官方说明书把「只在系统蓝牙里配对、没在应用里连」列为按键失灵的原因之一；
- RT113 的官方商品页则说在系统蓝牙设置里配对即可。

三条都是官方口径，对应不同型号和批次。所以卡住时的实际解法是：

1. 先在手机蓝牙设置里对这个遥控器执行「取消配对 / 忽略此设备」；
2. 然后换**另一条路径**重来：原来在系统蓝牙配的，改到应用内搜「NEEWER RT…」连接；原来在应用内连的，改走系统蓝牙；
3. 连上后进播放界面按一下播放键验证。

两种路径的完整步骤见[蓝牙遥控器配对与控制.md](蓝牙遥控器配对与控制.md)。

## 四、连上了但按键没反应

官方说明书的排查项：

- 确认用的是**官方 NEEWER Teleprompter 应用**（包名 `com.neewer.teleprompter_x17`），第三方套壳应用收不到遥控指令；
- 完全退出应用再重新打开（不是切后台，是杀掉重进）；
- 检查应用是否为较新版本，商店里能更新就更新——应用商店版本会随时间更新，以商店页面为准。

还没装应用的，从[下载与安装教程.md](下载与安装教程.md)开始。

## 五、以上都试过还不行

- 把遥控器拿到离手机更近的地方再连（隔墙、跨房间会搜不到或频繁掉线）；
- RT111/RT113 换一组新电池再试——电量不足是这类遥控器连不上的常见原因；
- 遥控器本身不支持 Windows 电脑，如果你是在电脑上试，这不是故障，是它根本不面向这个平台。

若怀疑遥控器硬件损坏，走 NEEWER 官方售后渠道，不要自行拆修。
