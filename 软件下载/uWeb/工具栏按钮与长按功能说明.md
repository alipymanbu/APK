## 一、先把两条工具条调出来

uWeb 的按钮分挂在两条工具条上，呼出手势不一样（据官方内置手册）：

- **顶部工具条**：从浏览器顶部往下拉，或短按底部工具条上的页面搜索按钮。
- **底部工具条**：从左下角或右下角往里滑，或从顶部/地址栏下方下拉。
- **更多工具可以左右滑动**——按钮多到一屏放不下时，横着滑就看到了。
- 连点「后退」按钮会退出当前窗口。

## 二、主工具条按钮

| 按钮 | 短按 | 长按 |
| --- | --- | --- |
| 刷新/中断 | 刷新或停止当前网页 | 弹出功能选择（背景色、地址栏功能等） |
| 后退 | 后退 | 智能翻页（往前翻历史页） |
| 前进 | 前进；没有前进历史时智能翻页 | 弹出系统菜单 |
| 设置 | 打开设置 | 显示系统设置项 |
| 窗口管理 | 切换/管理窗口 | 打开全局用户 CSS 样式（访问 `css/` 目录） |
| 主屏 | 回主屏 | 打开新窗口 |
| 更多工具 | 展开更多工具按钮 | 弹出全局 JS 脚本设置（访问 `js/` 目录） |

「智能翻页」就是[常见问题与使用技巧.md](常见问题与使用技巧.md)里讲的自动往前/往后翻页机制，长按后退、前进触发的是同一套逻辑。

## 三、更多工具里的按钮

| 按钮 | 短按 | 长按 |
| --- | --- | --- |
| PC | 伪装成桌面浏览器 | 左上角弹出菜单，选更多用户标识（配置文件 `default.uas`） |
| JS | 关闭/打开 JavaScript | 弹出脚本菜单（`bookmarklet/` 目录下的 js 文件） |
| IMG | 关闭/打开图片显示 | 弹出特色服务菜单（`default.urls`） |
| 五角星 | 添加书签 | 显示常用链接（`default.link`） |
| 时钟 | 访问历史 | 显示预定义命令（`default.cmds`，见[地址栏命令与快捷操作.md](地址栏命令与快捷操作.md)） |
| 放大镜 | 页内搜索（按 `>`）或联网搜索（回车） | 唤出远程脚本菜单（`default.rjs`） |
| 链接 | 复制链接 | 对选中内容执行自定义操作（`default.select`） |
| 分享 | 分享网址；在主屏时对剪贴板文本做处理 | 显示输入法短语（`default.input`） |
| X | 退出浏览器 | — |
| 上/下三角 | 跳到页首/页尾 | — |
| 喇叭 | 朗读：优先朗读搜索栏里的非网址文本、再读选中内容、最后整页；再按一次中断 | — |
| 纸张 | 文本重排（长网页折成适合屏幕的段落） | — |
| 云下载 | 保存在线网页 / 复制本地内容到目录 | — |
| 人像 | 切换账户（配置档案） | — |

两个开箱即用的组合：

- **不想看某页的图**：点 IMG 关掉图片——官方手册注明关闭 JS / IMG 来屏蔽内容**没有性能损失**，详见[广告屏蔽与内容过滤方法.md](广告屏蔽与内容过滤方法.md)。
- **学外语发音**：地址栏敲单词后按朗读，它专为朗读地址栏文本设计。

## 四、长按链接与长按图片

- **长按链接**：菜单里有「新窗口打开」——当链接是小书签时，脚本会作用于除本窗口外的最后一个窗口；还有「屏蔽根域名」，一键把该链接的根域名整棵树挡掉（用法见[广告屏蔽与内容过滤方法.md](广告屏蔽与内容过滤方法.md)）。
- **长按图片**：出特色服务菜单（自动全屏播放、转码、存为搜索引擎等，见[地址栏命令与快捷操作.md](地址栏命令与快捷操作.md)）。

## 五、记不住怎么办

长按体系的规律只有三条：**主按钮长按 = 进阶配置入口（`css/`、`js/`、系统设置），更多工具按钮长按 = 对应配置文件的菜单（`default.xxx`），链接/图片长按 = 对该对象动手**。配置文件都能在[官方配置文件列表](https://torappinfo.github.io/uweb/zh/filenames/index.html)页直接点开编辑，改法与保存时机见[常见问题与使用技巧.md](常见问题与使用技巧.md)。
