## 一、先建立一个心理预期

uWeb 走的是「极简界面 + 长按出一切」的路线：屏幕上能看到的按钮很少，功能大量藏在长按菜单、地址栏命令和配置文件里。所以新手最容易遇到的情况是「这功能在哪」——答案通常是**长按那个元素试试**：长按链接、长按图片、长按工具栏按钮、长按后退/前进键，各有各的菜单。

上手难度这件事，有第三方用户反馈可以参考：虫部落论坛 2019 年的一个帖子里，发帖人认为 uWeb 的入门操作比 Via、荟萃、雨见这类同类浏览器「要难出不少」，并建议**从多引擎配置入手**是最快的入门路子——本套的[搜索引擎配置教程.md](搜索引擎配置教程.md)就是按这个思路组织的。

本篇按你第一次打开的顺序，把最常用的几件事过一遍；进阶的命令与快捷操作在[地址栏命令与快捷操作.md](地址栏命令与快捷操作.md)。

## 二、界面与菜单

- **地址栏**：输网址直接跳，输关键词直接搜，还支持 `!` 开头的命令行（见地址栏那篇）。
- **底部工具条**：常用功能（书签、历史、窗口等）的入口都挂在这条工具栏上，具体按钮可以自己定制。呼出手势有讲究：**从左下角或右下角往里滑**、或从顶部/地址栏下方下拉出底部工具条；**从浏览器顶部往下拉**出顶部工具条。更多工具一屏放不下时可以左右滑。
- **菜单怎么呼出**：手机没有实体菜单键时，**长按底部工具条上的前进按钮**即可弹出菜单——这是官方文档给出的通用入口，找不到某功能时先用它。
- **长按链接**：弹出的菜单里有复制、在新窗口打开、以及运行脚本等选项。
- **长按图像**：配置过「特色服务」后，这里是各种一键操作的入口（详见地址栏那篇）。

## 三、地址栏是核心

地址栏承担了三个角色，熟练之后大部分操作都不用翻菜单：

1. **打开网址**：完整 URL 回车即达。
2. **搜索**：直接输入一句话回车，走的是你配置的默认搜索引擎（配置方法见[搜索引擎配置教程.md](搜索引擎配置教程.md)）。
3. **命令**：`!` 开头的行按命令执行，`.js` 文件名可当作命令跑，长按历史按钮能调出预置的常用命令。

## 四、第一次上手建议做的几件事

1. **把搜索引擎换成你常用的**：官方文档站提供成批的配置链接，点一下就能把引擎加进主屏；也可以在访问任意网站搜索一次后，用菜单里的「添加为搜索引擎」现做现用。
2. **调出常用菜单**：长按前进按钮弹菜单，把书签、历史这些常用项的位置熟悉一遍。
3. **了解保存时机**：uWeb 不会在你每改一项设置时立刻写盘——**没有正常退出或没转入后台就直接清掉进程，改动会丢**（表现为下次打开还是老样子）。改完配置后按 Home 键让它进后台一次，或正常退出，再清后台，详见[常见问题与使用技巧.md](常见问题与使用技巧.md)。
4. **知道去哪查文档**：官方文档站 [torappinfo.github.io/uweb/zh/](https://torappinfo.github.io/uweb/zh/) 按主题分了四十多个页面，从搜索引擎、命令到 Android TV 都有；本套文档讲的是你最常碰到的那部分。

## 五、常用操作速查

| 你想做的事 | 怎么操作 |
| --- | --- |
| 呼出菜单 | 长按底部工具条的前进按钮 |
| 搜索 | 地址栏直接输入关键词回车 |
| 把当前网站存为搜索引擎 | 打开该网站并搜索一次 → 菜单 →「添加为搜索引擎」 |
| 打开链接的更多选项 | 长按链接 |
| 图片/资源的一键操作 | 长按图像（需先配置特色服务） |
| 跑一条预置命令 | 长按历史按钮（配置命令并重启后可用） |
| 临时看 PC 版网页 | 切 PC 模式，配合宽屏显示与强制缩放，见常见问题那篇 |
| 某个按钮不认识 | 逐个对照[工具栏按钮与长按功能说明.md](工具栏按钮与长按功能说明.md) |
| 页面广告太多 | 关 JS/IMG 或封根域名，见[广告屏蔽与内容过滤方法.md](广告屏蔽与内容过滤方法.md) |

## 六、它还能做什么（知道有这回事即可）

官方功能清单里还包括：自定义纸张大小的 PDF 导出、矢量长截屏、朗读（TTS）、文本重排、资源嗅探、翻译、阅读模式、网址重定向、多账号切换、网盘离线下载、文件管理、webdav/http 备份恢复、自动翻页、网站独立设置（UA、禁脚本、无图）、网络唤醒等。其中不少要靠配置文件或脚本才能启用——先用熟上面的基础操作，需要哪个再回头查官方文档对应页面。

另有面向 Windows / macOS / Linux 的桌面简化版 Ebrowser，官方页面有单独介绍；本套文档只覆盖安卓端。
