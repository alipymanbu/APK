## 一、地址栏就是命令行

uWeb 地址栏支持 `!` 开头的命令行输入（配物理键盘体验更佳），也可以直接把一个 `.js` 文件当命令执行。这意味着你不必在层层菜单里找功能——常用动作配成命令后，地址栏敲两个字符就走。命令本身是一行 shell 或脚本，具体写在配置文件里，下面几节是最常用的几类入口。

## 二、常用命令（长按历史按钮调出）

官方文档提供了成批的[常用命令配置](https://torappinfo.github.io/uweb/zh/cmds/index.html)，点击配置链接即可自动添加；**强制清空后台重启后，长按历史按钮**就能看到它们。每条命令的格式是「名称:前缀:命令体」，官方示例里比较实用的几条：

```text
清空缓存::toybox rm -rf /data/data/info.torapp.uweb/cache
本地备份配置::toybox cp -r /data/data/info.torapp.uweb/files /sdcard/Download/uweb
本地恢复配置::toybox cp -r /sdcard/Download/uweb/* /data/data/info.torapp.uweb/files/.
清空应用数据库::rm -rf /data/data/info.torapp.uweb/databases/*
```

- **本地备份/恢复配置**：换机或重装前跑一次备份，装好后跑恢复，书签、引擎、脚本原样回来。
- **清缓存/清数据库**：浏览器变卡、状态异常时的自愈手段。
- 部分命令（解冻/冻结某 App、发消息到电视等）需要 root、Termux 或改 IP，命令页里都标了前提，没有对应环境就别点。

## 三、特色服务（长按图像按钮调出）

另一组入口挂在**长按图像按钮**上，配置来自 `default.urls` 文件，官方的[特色服务配置页](https://torappinfo.github.io/uweb/zh/urls/index.html)给出大量现成条目，点击配置链接自动添加，**强制清空后台重启后生效**。URL 里用 `%u`（当前网址）、`%t` 等占位符。常见用法：

| 服务 | 干什么 |
| --- | --- |
| 重定向/编辑 | 打开重定向或编辑当前地址 |
| 保存为搜索引擎 | 把当前地址存成引擎 |
| 保存到桌面 | 给当前页面建桌面快捷方式 |
| 中文简体 GB18030 / 繁体 BIG5 | 乱码页面转码查看 |
| 查看源码 `view-source:%u` | 看页面源码 |
| 翻译类（有道/谷歌等） | 一键把当前页送进翻译服务 |
| 自动全屏播放 | 视频页直接全屏播 |

注意版本差异：官方注明 1144 以下版本的配置要删掉末尾的 `%u`——如果你用的是老版本，配置不生效先看这里。

## 四、小书签（bookmarklet）

小书签就是存在书签里的 JavaScript。uWeb 的做法省事：**不用手工输入脚本，把小书签网站直接加进书签即可**；运行时长按书签出菜单，选「在新窗口中打开」，脚本就作用于最后一个窗口。官方技巧里还提到，小书签在带 CSP 限制的站点也能跑，并且可以设置成对同类网址自动应用。

## 五、地址栏自动补全

地址栏会按 `default.autoc` 文件里的条目做补全提示，把常输的网址、查询模板、AI 提示语放进去（每行一条），敲前几个字就能整句补上。两个配套玩法：

- 补全出来的文本**以空格开头**时，它不会当作网址处理，而是作为输入内容填给当前页面里获得焦点的元素——相当于一个自定义输入法。
- 查询历史会累积在 `query.log`，官方命令页有现成命令把它合并进自动填充列表并去重。

## 六、手势与工具栏定制

- **手势**：官方文档有专门的[手势配置页](https://torappinfo.github.io/uweb/zh/gesture/index.html)，可以把滑动、长按等动作绑到指定操作上。
- **工具栏定制**：[工具栏定制页](https://torappinfo.github.io/uweb/zh/icons/index.html)说明了如何增删底部按钮；自定义的菜单、按钮、手势都能挂上「内部功能链接」「URL 服务」「shell 命令」这三类动作，也就是说前面几节配好的东西，都可以绑成一次点击。每个按钮短按/长按的默认行为先对照[工具栏按钮与长按功能说明.md](工具栏按钮与长按功能说明.md)，再决定改哪里。

## 七、一条配置怎么走完全程

以「一键把当前页发到剪贴板并转二维码」这类需求为例，路径是固定的：先在命令/服务配置里写好一行 → 强制清空后台重启 → 长按对应按钮（历史/图像）触发 → 顺手把它绑到工具栏按钮或手势上。**所有配置共用同一个保存规律**：改完要正常退出或转入后台一次，否则清掉进程后改动会丢（详见[常见问题与使用技巧.md](常见问题与使用技巧.md)）。

想给地址栏加更多「输入即出结果」的玩法（计算器、作图、词典），配合搜索引擎配置效果最好，见[搜索引擎配置教程.md](搜索引擎配置教程.md)。
