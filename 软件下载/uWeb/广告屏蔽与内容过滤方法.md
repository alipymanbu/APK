# uWeb 广告屏蔽与内容过滤方法

> 在 uWeb 里挡广告、屏蔽不良内容的几种手段：关按钮、封根域名、按站点定制，按需选一种即可。

## 一、先选档位：你只想清爽一点，还是要连根拔

uWeb 提供的过滤手段分四档，动手成本从低到高。只挑一档用就行，不必全上：

| 档位 | 手段 | 适合 |
| --- | --- | --- |
| 一键开关 | 关闭 JS / 关闭 IMG 按钮 | 快速看清页面到底靠什么弹广告 |
| 域名封锁 | 不良信息拦截（`default.hosts`） | 一次配置，整棵域名树永久挡掉 |
| 单点处置 | 长按链接 →「屏蔽根域名」 | 刷页时随手封掉刚冒出来的域名 |
| 站点定制 | 特定网站脚本/样式、仅图片/仅视频模式 | 只想改个别网站的显示方式 |

## 二、一键开关：关 JS 或关 IMG

底部工具条「更多工具」里的 **JS** 按钮切 JavaScript、**IMG** 按钮切图片（按钮位置见[工具栏按钮与长按功能说明.md](工具栏按钮与长按功能说明.md)）。官方手册对这招的评价是**没有性能损失**——很多广告靠脚本弹出，关掉 JS 页面立刻干净，代价是依赖脚本的功能（登录、下拉加载）也会失效，所以它更像诊断手段：先关掉看广告还在不在，就知道该往哪档走。

## 三、域名封锁：不良信息拦截（default.hosts）

这是官方主推的一档，思路是**把根域名连同它的一切子域名、孙域名一起挡掉**，而不是逐条网址去封：

1. 准备文件 `default.hosts`，**每行一个域名**——懒得从零写就直接在[「绝杀完整域名树」攻略页](https://torappinfo.github.io/uweb/zh/adblock_domain/index.html)点样例链接覆盖生成；
2. 在系统设置里启用「不良信息拦截」选项；
3. 重启后生效，列表里的域名整棵树都进不来。

**取域名的技巧**：封的时候只取最后两段（`example.com` 这种粒度），`com.cn` 这类两段不超过 6 字符的可取四段——取太细等于没封，取太粗会误伤同站的正常页面。域名行还支持两个可选的正则（域名前缀、整条网址），用 Java 正则语法；普通用户用不到，留空即可。

## 四、单点处置：长按一条链接直接封根域名

浏览中撞到不良链接，不必打开配置文件：

1. 长按那条链接（图片则长按图片）；
2. 菜单里选**「屏蔽根域名」**；
3. 弹出的域名按上面的技巧改成最后两段，确定。

它写进的就是 `default.hosts`，和上一节殊途同归。没有链接可长按的场景（内容由脚本注入），官方给了三条替代路径，按顺序试：

- 长按 **JS** 按钮，执行「背景图片」或「看图模式」，把可疑图片显示出来后再长按它封根域名；
- 长按设置开启**资源嗅探**（`types.sniff` 填 `js`，刷新后关掉选项），在嗅探结果里长按可疑外链封根域名；
- 用「列出外部脚本」小书签生成外链清单，长按可疑域名执行「屏蔽根域名」。

## 五、站点定制：只改这一个网站的显示

- **仅图片 / 仅视频模式**：长按窗口管理按钮选「仅显示图片」或「仅显示视频」，图文/视频站点只剩主体内容；还有「禁用伪元素」「禁用 iframe」两个开关。想让某个书签永久生效，保存书签时在网址前加前缀（仅图片 `i:0mc32:`、仅视频 `i:0mc16:`）。
- **标记不良元素**：长按 JS 按钮执行「标记不良元素」，点页面上碍眼的元素，它会生成 CSS 屏蔽代码并按网站存起来；官方提示若该元素样式里出现过 `display`，改用 `transform:scale(0)!important` 更稳。
- **拦截外链脚本**：长按设置选「拦截外链脚本」，额外挡掉第三方可疑资源，白名单写 `js.allow`。
- **URL 正则**：高级用法 `url.deny`，按正则挡指定网址（Java 语法，`#` 开头为注释）。

以上均是**你自己设备上的浏览过滤设置**，只影响本机看到的内容；改完遵守保存时机规则（见[常见问题与使用技巧.md](常见问题与使用技巧.md)）。

## 六、没生效时查这三处

1. **选项勾了吗**：「不良信息拦截」在系统设置里，别只写了文件忘了开开关；
2. **重启了吗**：配置类改动一律要强制清空后台重启才生效；
3. **域名取太细了吗**：封了 `ad.example.com` 挡不住 `cdn.example.com`，退回最后两段再试。

三处都对还不行，就按[常见问题与使用技巧.md](常见问题与使用技巧.md)的出错诊断流程抓 logcat，看拦截选项到底加载了没有。
