## 一、装之前先对上这几项

DD373 是安卓手机应用，官方名称就是 `DD373`（运营方为新乡市嘟嘟网络技术有限公司）。装之前先用下表核对你手里的包，版本不对说明拿到的不是这一份：

| 项目 | 值 |
| --- | --- |
| 应用名称 | DD373 |
| 包名 | `com.dd373.app` |
| 版本 | 4.0.17 |
| 安装包大小 | 48.69M |
| 安装包 MD5 | `e05871c23a8c7b13af7029e35a007e4b` |
| 适用平台 | Android 手机 |

需要留意的是：官方渠道上架的版本会随更新往上走，本页写的版本号是这份安装包本身的版本，不是官网当前最新版。想装最新版就去官方下载页，想装这一版就用上面对应的包。

## 二、安装包从哪来

有两种来源，各自解决不同的问题：

- **官方下载页**：官方提供的手机客户端下载页在 [cms.dd373.com/default/app_down.html](https://cms.dd373.com/default/app_down.html)，页面上标着开发者与当时的应用版本号，以页面上显示的为准。走官方渠道拿到的一定是最新版。
- **已经存好的安装包**：如果官方页面当时访问不了，或者你希望装的是与你手头文档、订单记录对得上的固定版本，可以直接取现成的安装包文件：[DD373 安装文件资源（夸克网盘）](https://pan.quark.cn/s/17805ed29c20)。取回来先按下一节核对 MD5 再装。

两个来源的包没有功能差别，区别只在版本新旧。

## 三、装到安卓手机上

1. 把 `.apk` 文件传到手机（数据线拷贝、网盘转存到手机、或先在手机上直接下载都可以），记下它放在哪个目录，一般在文件管理器的「下载」里。
2. 在文件管理器里点这个 apk 文件。系统会弹出安装确认页，页面上能看到应用名称与它申请的权限。
3. 如果系统提示「不允许安装未知来源应用」，去「设置 → 应用 → 特殊应用权限 → 安装未知应用」（不同品牌路径略有差异，有的叫「未知来源应用」），把当前这个文件管理器或浏览器的开关打开，再回去点安装。
4. 点「安装」，等进度走完，桌面或应用列表里就会出现图标。
5. 部分机型装完会提示「该应用未经安全检测」，这只是因为包不是从系统自带应用商店装的，选「继续安装 / 仍然安装」即可。

装好后不必急着登录，第一次打开会先要求同意用户协议，具体见 [注册登录与实名认证.md](注册登录与实名认证.md)。

## 四、核对安装包有没有被改动

安装前建议顺手对一次 MD5，尤其是在群里、论坛里拿到的转发包：

**在电脑上（Windows）**：把 apk 放在任意目录，在 PowerShell 里执行

```powershell
certutil -hashfile "D:\下载\DD373.apk" MD5
```

**在手机上**：用带文件信息功能的文件管理器打开该 apk 的属性页，直接看 MD5 或 SHA1 一栏。

结果应当与第一节表格里的 `e05871c23a8c7b13af7029e35a007e4b` 完全一致。**不一致就不要装** —— 说明这个文件和本页描述的版本不是同一份，可能被替换过。

## 五、首次打开会遇到的几件事

- **同意协议**：启动后先出现用户服务协议与隐私政策，同意后才能进首页。
- **申请权限**：系统会在此过程里弹权限申请，主要围绕网络与文件读写。你可以在「设置 → 应用 → DD373 → 权限」里随时查看和收回任何一项；收回文件读写权限会影响上传截图、保存图片这类操作。
- **弹窗与通知**：订单状态变化、客服消息会通过应用内通知与系统通知推送，如果发现收不到，到系统设置里确认没把它的通知关掉。
- **登录方式**：打开后首页右上角是登录入口，账号密码、手机验证码都支持，注册入口也在同一个位置。

## 六、什么时候该更新

分两种情况：

- 官方发布新版本、你希望用新功能 → 从官方下载页取新版覆盖安装即可，账号数据不会因为换包丢失。
- 你已经在按某一份文档核对订单、版本、流水，不想中途换版本 → 继续用现有版本没问题，客户端版本不影响你的账号余额、订单记录（这些都存在平台账号里，不跟客户端绑定）。

覆盖安装时不要先卸载旧版，直接装新包，否则需要重新登录。
