## 一、先记住一条铁律

**平台客服不会主动联系你谈钱。** 担保交易的官方说明里写得很直白：交易过程中，客服不会主动联系买卖双方，由买卖双方自主交易，遇到问题由你主动去联系接手客服。寄售订单虽然由平台交易员代发货，但也不会让你往任何私人账户打钱。

所以：凡是**先找上你**、自称客服、要你转账或扫码的，基本可以直接按骗子处理。

## 二、几种常见骗术怎么认

| 骗术 | 典型特征 | 你该做的 |
| --- | --- | --- |
| 假冒客服 | 主动加你好友、催你「订单异常需要退款」、让你提供验证码 | 不要提供任何验证码；去官方[安全中心](https://kf.dd373.com/safecenter.html)核验客服身份，或直接在订单里点「联系接手客服」反向确认 |
| QQ 资料障眼法 | 把 QQ 号写进昵称里，或把号码改成带下划线的邮箱形式，冒充官方号码 | 不以昵称、邮箱形式的数字为准，只用安全中心的验证入口 |
| 假链接 / 钓鱼站 | 有人在聊天里发网址让你登录、领奖、验货 | 不要点别人发的站内或站外链接；自己手输官方域名进站 |
| 相近字域名 | 用和官网只差一两个字符的域名 | 只认 [www.dd373.com](https://www.dd373.com/) 及其官方子站，其余一律不进 |
| 恶意二维码 | 让你扫码「付保证金」「解冻订单」 | 平台的支付在订单收银台内完成，凡让你扫码付款给个人的，基本可以判定是骗局 |
| 站外低价 | 卖家说「加联系方式私下交易更便宜」 | 拒绝。站外交易平台不认，钱追不回来，且双方索要站外联系方式本身就会被封号 |
| 代练 / 上号骗局 | 以「帮你上号做活动、代充」为由索要账号密码 | 不把账号交给任何人，官方多次提示这类骗法 |

## 三、四条能防住大多数坑的习惯

1. **全程留在站内**。沟通用订单聊天，付款用订单收银台。一旦有一方要往站外走，停手。
2. **不给也不问联系方式**。官方明文规定：买卖双方不得主动提供或向对方询问联系方式，查实会做封停账户处理。这条既是规则，也是保护你的。
3. **只从官方入口进站**。把 [www.dd373.com](https://www.dd373.com/) 加入书签，从任何其他渠道收到的链接都不要直接登录取。
4. **每步留痕**。聊天记录、订单截图、发货录屏都存着，纠纷处理看的就是这些材料。

## 四、真出了问题找谁

按问题性质分开走，别都往一个入口挤：

| 问题 | 入口 |
| --- | --- |
| 这笔订单的货不对、卖家不发货 | 订单详情页 →「申请接手客服介入」 |
| 账号被找回、被封、角色丢失 | 「我购买的商品」里找到订单 → 申请理赔 |
| 账户被封停 | 客服中心的账户解封申诉 |
| 手机号停用无法自助换绑 | 手机换绑申诉 |
| 身份证姓名变更 | 修改实名申诉 |
| 遇到可疑客服 | 安全中心 → 举报假客服 |
| 其他咨询 | 客服中心在线咨询；官方 7×24 客服热线 `0373-5805373` |

申诉提交后可以在申诉结果查询入口跟进度，不用反复提交同一件事。

## 五、找回包赔和永久包赔管什么

包赔是针对**账号类商品**的售后：买卖双方谁买的保险，权益人都是买家。

**保障范围**

- 账号类：账号被找回、账号被封禁、角色丢失。
- 游戏币 / 装备 / 道具类：被卖家申诉找回、被官方扣除、因交易被封号。

**两种形式**

- **找回包赔**：卖家发布商品时承诺支持，交易成功后货款在包赔有效期内冻结在平台；期内被恶意找回，核实后全额原路退给买家，期满未出问题则货款自动打给卖家。
- **永久包赔 / 交易安全险**：购买保障期限为 365 天的交易安全险会附赠永久包赔；商品交易成功后，账号被卖家找回或被运营商收回，可凭保险凭证申请赔付。赔付比例按你购买的合同类型执行，不同合同的比例不同。

**怎么申请**

1. 在「我购买的商品」里找到需要理赔的订单，直接申请理赔。
2. 客服在 3 个工作日内主动联系你处理。
3. 准备材料：身份证正反面照片、账号使用异常的截图或录屏，以及其他能证明被找回的凭证。

**不赔的几种情况**

- **账号转手了**：账号一旦再次出售、转借、赠与他人或长期托管，包赔自动失效。
- **反馈太晚**：游戏账号的找回痕迹不是永久可查的，官方要求出现找回后第一时间申请；超过 7 天才反馈，造成的损失要买家自行承担。
- **不是找回导致的损失**：盗号、骗号、封号、冻结这类形式上的受损，不享受包赔，平台会按实际情况尽力协助。
- **自己违规**：点不明活动链接、让人上号代做活动、在不安全环境登录，导致账号出事，不在赔付范围。
- **骗赔**：谎称账号被找回、隐瞒外借或共享来骗取赔偿，一经发现按诈骗处理。

## 六、卖家这一侧同样要用上

卖家被骗的典型场景是「买家引导站外交易」和「冒充客服让你先放款」。对应做法：

- 所有沟通留在订单聊天里，**不接站外联系**；
- 发货凭证（截图/录屏）保存 7 天以上；
- 只按订单系统里的状态推进，不放「先给货后补单」这种人情；
- 费率、结算与取消规则以订单页与官方公告为准，别信截图里的说法。

信用分高低会直接体现在买家选不选你，所以维护好自己的成交记录，比事后解释有用。
