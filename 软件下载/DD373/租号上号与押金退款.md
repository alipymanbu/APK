## 一、租号和买号的区别

买号拿到的是账号本身，租号拿到的是**一段时间内的使用权**：账号密码不在你手里，你要通过官方提供的上号器，由它自动帮你输入账号密码登录游戏。所以租号有两个买号不存在的问题 —— 上号器装不上/报错，以及押金的退还。

租号页面的入口在租号首页或租号大厅，它和商品交易是两条并列的业务线。

## 二、租号的完整流程

1. **选号**：进租号大厅，先选游戏，再按你的要求用高级筛选缩小范围，点开商品详情看具体信息。
2. **下单**：在商品列表该条后面点「立即租号」，或在详情页点「立即租号」。
3. **支付**：订单支付页支持银行卡 / 信用卡、支付宝、花呗、微信支付，也可以用账户余额兑换的钻石支付。支付页中途关掉没付成的，到「我的 DD373 → 帐号租赁 → 我租到的帐号 → 待支付」里找回来继续付。
4. **取登录码**：支付成功后进「我的 DD373 → 我租到的帐号」，点右侧「订单详情」，复制登录订单号。
5. **上号**：打开上号器，录入用户名与登录码，点开始游戏，等它自动把账号密码输进去。
6. **开玩**：进游戏期间不要手动改密码、不要切号，租期到点自动失效。

## 三、上号器怎么装、怎么用

上号器是 PC 端工具，官方下载页在 [act.dd373.com/shq/index.html](https://act.dd373.com/shq/index.html)。官方给出的使用要点如下：

- **安装前先关掉所有杀毒软件**，装完再开。
- 自动更新失败或反复循环更新时，重新下载最新版本的上号器。
- 输入登录码后点登录，选「普通登录」，上号器会自动输入账号密码。
- **自动输入的过程中不要动鼠标键盘**，一动就可能登录失败。
- 登录失败就关掉上号器，重新走一遍上号流程。

登录码忘了去哪找：个人中心 →「租赁的商品 / 我租到的帐号」里能查到。

## 四、上号器报错对照

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 找不到游戏路径，请手动启动游戏 | 上号器没定位到游戏客户端 | 先手动打开该游戏（租绝地求生的账号则先打开 Steam 客户端），再点开始游戏 |
| 请关闭电脑管家 / 360 安全管家等软件后登录 | 安全软件拦截了模拟输入 | 关掉电脑上的安全软件再上号 |
| 检测到环境异常 | 环境里有第三方辅助工具 | 见下一节的违规清单，这类订单会被直接终止 |
| 找不到相关订单信息 | 登录码或用户名输错 | 复制粘贴登录码，别手输 |
| 密码错误 | 自动输入过程被打断，或卖家侧改过密码 | 重开上号器再来一次；仍不通就到网站申请维权，原因选「密码错误导致无法登陆」，核实后退款 |

## 五、押金与退款：什么情况退多少

| 情况 | 处理结果 |
| --- | --- |
| 正常租用、无违规 | 押金在 48 小时内返还到平台账户 |
| 卖家侧问题（密码错误、中途被顶号、卖家自己在线） | 核实后退还全部租金，并降低该卖家的排序分 |
| 账号本身有问题（异地限制、帐号锁定、需要令牌或邮箱验证导致进不去） | 核实后退还全部租金 |
| 不可抗力（服务器维护、大规模网络问题） | 按实际可玩时长扣除押金 |
| 自己中途撤单 | 15 分钟内撤单全额退款；超过 15 分钟不满 1 小时按 1 小时租金计，之后依次类推 |
| 自己违规使用导致卖家维权成立 | 从押金里扣钱赔付卖家 |

**续租**：官方租号说明里写明「当时未开通续租支付入口，开通后会以公告告知」。这份说明发布时间较早，实际以站内当前是否有续租入口为准。

## 六、哪些行为会直接进黑名单

上号器会检测运行环境。租号期间如果电脑上开着这些工具，会被判定环境异常，**订单即刻终止并纳入全网黑名单**：卡屏器、连招工具、语音脚本工具、无限视距、按键精灵、第三方网吧特权软件、换肤、画质美化、鼠标宏、各类第三方盒子，以及任何游戏外挂。

另外两类后果更重：

- 使用账号过程中违反游戏官方行为准则，导致账号被裁决、禁赛、禁言等处罚 → 结束订单并**扣除全部押金**补偿卖家；三次及以上，冻结 DD373 账户。
- 试图开启外挂或脚本 → 结束订单、扣全部押金、纳入全网黑名单（换号重新注册也不能再租），严重情形平台保留追究法律责任的权利。

对判定有异议的，可以按官方公告里给出的复核方式提交登录码与用户名申诉。

## 七、租号期间的两条常识

- **不要改账号密码、不要绑自己的东西**。账号所有权不在你这里，改动会立刻触发风控并让订单作废。
- **不要给卖家或任何人提供站外联系方式**，也不要接受「私下转租给你更便宜」这类提议 —— 与买号一样，规则同样禁止，见 [订单安全与防骗怎么把握.md](订单安全与防骗怎么把握.md)。
