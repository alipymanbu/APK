## 一、安装与启动

这一节管的是「装不上、打不开」：从系统拦截、安装包异常到启动闪退，按现象对下表处理；涉及安装步骤与包校验的完整说明在 [下载与安装教程.md](下载与安装教程.md)。

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包下载不完整或被改过 | 重新取一次安装包（[DD373 安装文件资源（夸克网盘）](https://pan.quark.cn/s/17805ed29c20)），按 [下载与安装教程.md](下载与安装教程.md) 第四节核对 MD5 |
| 提示「应用未安装」 | 手机上已装了同包名但签名不同的版本 | 先把旧版本卸载，再装新包 |
| 提示未知来源被拦截 | 系统默认不允许装非商店来源的应用 | 到「设置 → 应用 → 特殊应用权限 → 安装未知应用」里放行当前的文件管理器或浏览器 |
| 装完桌面没有图标 | 图标被收进了应用抽屉 | 在应用列表或设置的应用管理里搜 `DD373` |
| 启动后闪退 | 系统版本过低、缓存损坏，或包本身异常 | 先重启手机再试；仍闪退就换一份安装包重装（不卸载数据也会保留在账号侧） |
| 装的是旧版本想升级 | 新旧包共存 | 直接覆盖安装即可，不要先卸载，卸载会要求重新登录 |

## 二、登录与验证码

- **收不到短信验证码**：先确认手机号没输错、信号正常、没被系统拦截软件拦下；再点一次「获取语音验证码」走语音通道。频繁点发送会被限流，等几分钟再试。
- **提示密码错误**：走「找回登录密码」，用绑定的手机号重置。
- **用户名忘了**：到帮助中心的「如何找回用户名」按流程核验找回。
- **账号被锁定或封停**：到客服中心提交账户解封申诉，并在申诉结果查询里跟进，不要重复提交。
- **换了手机号登不上**：原号还能收短信就走自助换绑；收不到就走手机换绑申诉。详见 [注册登录与实名认证.md](注册登录与实名认证.md) 第六节。

## 三、实名与账户信息

- **能不能跳过实名**：不能。未填身份信息、未满 18 岁、身份证与姓名不匹配的账号都不支持使用平台功能。
- **实名信息填错了**：实名信息自己改不了，要去客服中心提交修改实名申诉。
- **改常用联系手机 / QQ**：在「账户设置 → 基本信息」里直接改，不需要额外验证 —— 注意这只是「常用联系方式」，和登录绑定手机是两回事。

## 四、订单与交易

| 现象 | 原因与处理 |
| --- | --- |
| 订单详情页找不到「联系接手客服」 | 订单未支付，或交易已结束时不支持联系接手客服；这两种情况改走咨询客服 |
| 付了钱订单还停在待付款 | 支付页面中途关闭导致订单没提交成功，到「我是买家 → 我购买的商品 → 待支付」里把订单找回来继续付 |
| 卖家迟迟不发货 | 普通担保订单一般要求在 15 分钟内、标注赔付的订单在 20 分钟内完成交易；超时你可以选择不等，由客服按卖家责任取消订单 |
| 收到的和描述不一致 / 少货 | 不要点确认收货，直接在订单里申请客服介入并上传证据 |
| 账号到手后想退货 | 先核实问题再决定；已确认收货的订单要走纠纷流程，材料越全处理越顺 |
| 租号上不去 / 上号器报错 | 先对着 [租号上号与押金退款.md](租号上号与押金退款.md) 第四节逐条排；仍不行按那里写的方式申请维权 |
| 想找客服催进度 | 接手客服只管本订单；咨询、投诉类的走客服中心的在线咨询 |

关于发货时限、货款到账时间这些规则细节，见 [寄售和担保有什么区别.md](寄售和担保有什么区别.md) 与 [卖东西怎么发布商品与提现.md](卖东西怎么发布商品与提现.md)。

## 五、资金与提现

- **提现不到账**：支付宝通常 5~20 分钟到账，银行卡 20 分钟~2 小时。先等满对应时长；银行侧系统维护期间会整体延迟，维护后按顺序处理。
- **提现失败**：到「我的余额 → 资金记录 → 提现记录」看状态栏写的失败原因。最常见的是**账户实名姓名与银行卡开户名不一致**，其次是卡号输错。
- **提现被扣了一笔**：那是提现转账服务费，按渠道费率收取，另有最低与最高收费。
- **余额里有却提不出来**：先看是不是 48 小时限制（充值与退款进来的钱要满 48 小时）或还处在「锁定中」状态，这两种都不是故障。
- **想核对账目**：资金明细里逐笔看收入、支出、手续费与提现记录。
- **订单完成了但余额没变**：带找回包赔的订单，货款会在包赔有效期内冻结在平台，期满才放行；未开包赔的账号订单通常 1~7 天到账。这是规则，不是出错。

费率档位、到账时间、48 小时限制与锁定状态的完整说明在 [提现手续费和到账时间怎么算.md](提现手续费和到账时间怎么算.md)。

## 六、客户端本身

- **版本号对不上**：官方渠道的版本会随时间更新，本仓库文档里写的版本号是某一份安装包本身的版本。想看版本就从应用内「设置 / 关于」查看。
- **搜不到某个游戏**：先确认游戏名拼写，再试首页的图标模式或首字母定位；确实没有的品类可以先逛「求购」，让卖家来接单。
- **通知收不到**：检查系统里该应用的通知权限是否被关，以及是否被电池优化限制后台。
- **想换手机用**：账号数据在平台侧，换设备后登录同一账号即可，订单与余额都跟着账号走。

按问题类型走对应入口，能省掉来回转接的时间：

| 类型 | 入口 |
| --- | --- |
| 某笔订单的具体问题 | 订单详情页 → 申请接手客服介入 |
| 代练、租号、费率、规则咨询 | 客服中心在线咨询 |
| 账号申诉类（解封、换绑、改实名） | 客服中心 → 申诉中心 |
| 疑似假客服 | 安全中心 → 举报假客服 |
| 其他 | 官方 7×24 客服热线 `0373-5805373` |

客服中心入口：[kf.dd373.com/servicecenter.html](https://kf.dd373.com/servicecenter.html)，帮助中心在 [kf.dd373.com/helpcenter.html](https://kf.dd373.com/helpcenter.html)，规则与费率调整会发在[公告中心](https://kf.dd373.com/noticecenter/a.html)。
