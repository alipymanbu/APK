## 一、打开与基本输入

CalcKit 默认打开的是工具箱列表；如果你希望一启动就进计算器，到 **Settings（设置）→ Calculator** 里打开 **Calculator Visible on Start** 即可。

输入区支持这些操作，写长式子不用一次按到位：

- 输入框**可以编辑**，光标能移到式子中间改数字，不用清空重来；
- 支持**复制 / 粘贴**，可以把式子或结果发给别人；
- **边输入边出结果**：式子还没按等号，结果已经在下方显示；
- 支持直接写数学表达式，例如 `5E4` 表示 50000。

## 二、常用按键与符号

常用的几类按键和它们的写法：

| 按键 | 作用与示例 |
| --- | --- |
| `MC` `MR` `M+` `M-` | 内存四件套：清空、取出、累加、累减 |
| `ANS` | 引用上一次的计算结果 |
| `%` | 百分比。`50 + 25% = 62.5`、`50 - 25% = 37.5`、`50 × 25% = 12.5`、`50 ÷ 25% = 200` |
| `π` / `e` | 圆周率 / 自然常数 |
| `x²` `x³` `xⁿ` | 平方、立方、任意次幂（输入 `^`） |
| `√` `³√` `ⁿ√` | 平方根、立方根、n 次方根，如 `√(16)` |
| `x!` | 阶乘，如 `4! = 24` |
| `log` / `ln` | 以 10 为底 / 以 e 为底的对数 |
| `sin` `cos` `tan` 等 | 三角函数、反三角、双曲函数及反双曲函数 |
| `abs` `ceil` `floor` | 绝对值、向上取整、向下取整 |
| `EXP` | 科学计数，输入 `E`，如 `5E4` |

注意 `%` 的行为和有些计算器不同：加减法里是「在 50 的基础上加 25%（即 12.5）」，乘除法里按字面百分比处理，算账时先留意这个差别。

## 三、把按键换成你常用的

计算器上 20 个彩色功能键都可以换：

1. 先到设置里打开 **Enable editing buttons**；
2. 回到计算器界面，**长按**要改的功能键；
3. 屏幕弹出全部内置函数的网格，点一个即可替换；
4. 其余按键同样操作。

比如你常用 `floor` 而不用双曲函数，就可以把 `sinh` 那格换成 `floor`。

## 四、历史记录

按 `=` 或 `C` 时，式子和结果自动存进历史。历史界面有两个标签页：

- **History**：最近 50 条计算，每条存表达式、结果和时间；
- **Saved**：你主动保存的条目。

点任意一条，会把它的**结果**追加到你当前的式子末尾；**长按**一条会弹出更多选项：

- **Use Result** / **Use Expression**：把结果或原式追加到当前输入；
- **Copy**：把「式子 = 结果」整条复制到剪贴板；
- **Save**：转存到 Saved 标签；
- **Delete**：删除该条。

算账连续、需要反复引用之前数字的场景（比如对账、做作业），这个历史比反复重按省事得多。

## 五、悬浮计算器

悬浮计算器是一个能浮在其它应用上面的完整版科学计算器，功能与主计算器相同——聊微信、看网页时可以随手算。

第一次使用要授权「显示在其他应用上层」（Display over other apps）：

1. 进入科学计算器；
2. 点右上角的**悬浮计算器**按钮；
3. 系统自动跳到「显示在其他应用上层」的权限页；
4. 在列表里找到 **CalcKit**，打开**允许显示在其他应用上层**；
5. 按返回键回到应用，悬浮窗就会出现。

悬浮窗本身的调整方式分版本：网盘里这份 7.2.0 在**设置菜单**里调透明度（7.1.x 等早于 7.6.0 的版本同理）；7.6.0 起官方改成在悬浮窗上直接操作——窗口自带拉伸手柄调大小、滑杆调透明度，设置菜单里的对应项也随之移除了。7.6.0 还新增了同样悬浮的**记事本**（Floating Notepad），算题时可以把中间数字抄在上面，这份 7.2.0 里没有该功能。不用的时候把悬浮窗收起或直接关闭即可；如果点了按钮没反应，九成是上面第 4 步的权限没打开。

## 六、桌面快捷方式

想不进应用直接算：**长按**桌面上的 CalcKit 图标 → 点**小组件（Widgets）** → 把 **Calculator** 拖到桌面。单个工具（比如某个换算器）也能做成快捷方式，常用工具摆桌面可以省掉找工具的步骤。

装好应用还没动手的话，从 [下载与安装教程.md](下载与安装教程.md) 开始；想找某个具体工具，看 [都有哪些计算器和换算工具.md](都有哪些计算器和换算工具.md)。
