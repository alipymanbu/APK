## 一、开始前先确认两件事

1. **系统版本**：本篇对应的安装包在整理时的记录为需要 Android 5.2 及以上。如果你装的是从官方渠道拿到的更新版本，系统要求以官方页面标注为准（新版要求可能更高）。
2. **存储空间**：安装包本身约 12 MB（本篇对应的包为 11.95 MB），加上安装后的占用，预留几十 MB 就够。

CalcKit 在官方渠道是免费应用，带广告，另有付费的 Premium 档位；免费档已覆盖内置的全部计算器与换算工具。

## 二、获取安装文件

从上面的 **CalcKit 安装文件资源（夸克网盘）** 链接进入，把里面的安装包转存到自己的网盘后，用夸克网盘手机版下载到本机，得到一个 `.apk` 文件。

如果你更习惯官方渠道，也可以在 Google Play 搜索 `CalcKit`（包名 `com.ivanGavrilov.CalcKit`），或访问官网 `https://calckit.io/` 查看官方入口。注意：网盘里这份是 7.2.0 版，官方渠道的版本更新（截至 2026-09 官方页面为 8.3.0），两者可能不是同一个版本。

## 三、安装步骤

1. 打开手机自带文件管理器（或夸克网盘的下载完成页），点刚才下载的 `calckit_v7.2.0.apk`；
2. 系统会提示「不允许安装未知来源应用」，点提示里的**设置**入口，给浏览器或文件管理器打开**允许安装未知应用**的权限；
3. 返回安装页，点**安装**；
4. 装完点**打开**，第一次进入会看到工具箱列表，从这里进入各类计算器与换算工具。

不同品牌手机的提示文字略有差别（小米/华为等会有额外的「风险确认」弹窗），选**继续安装**即可，这是安卓对非应用商店安装包的统一提示。

## 四、核对安装包信息

安装前或安装后想确认手里这份包对不对，可以对照下表：

| 项目 | 值 |
| --- | --- |
| 应用名称 | CalcKit: All-In-One Calculator |
| 包名 | `com.ivanGavrilov.CalcKit` |
| 版本 | 7.2.0 |
| 安装包大小 | 11.95 MB |
| MD5 | `3014E0E6C766E39553D0F8B17857F6D2` |
| 信息整理时间 | 2026-09-23 |

装好后可以在手机的「设置 → 应用管理 → CalcKit」里看到版本号；MD5 需要借助文件管理器或校验工具查看，能对上就说明文件完整、没有被改过。

## 五、装不上或提示风险怎么办

按提示对号入座：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 一直停在「正在安装」或报「应用未安装」 | 手机里已有同包名的 CalcKit，且与这份包签名不一致 | 先卸载已有的 CalcKit 再装；卸载会清掉应用内数据 |
| 提示「解析包时出现问题」 | 下载不完整，文件损坏 | 删掉重新下载，下载完再核对一遍大小与 MD5 |
| 提示存储空间不足 | 剩余空间小于安装所需 | 清理空间后重装 |
| Play Protect / 系统安全扫描弹出警告 | 对非商店来源安装包的例行提示 | 选「仍要安装」；介意的话可先校验第四节表格里的 MD5 |

## 六、装好之后

打开 CalcKit 后默认进的是**工具箱**列表，全部工具按分类摆放。想先看看里面都有什么，读 [都有哪些计算器和换算工具.md](都有哪些计算器和换算工具.md)；想马上上手主计算器，读 [科学计算器怎么用.md](科学计算器怎么用.md)。

后续官方出新版后，直接用新版安装包覆盖安装即可，历史记录与自定义工具会保留；网盘里这份 7.2.0 不会自己更新，需要新版就去官方渠道取。另外提醒一句：卸载应用或恢复出厂会把收藏、自建工具和历史记录一并清掉，换机前先做备份，步骤见 [换手机怎么迁移数据.md](换手机怎么迁移数据.md)。
