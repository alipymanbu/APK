# CalcKit 换手机怎么迁移数据

## 一、哪些数据需要搬

CalcKit 的收藏、历史记录、自建工具都存在**应用本地**，卸载就没了——这些要在卸载旧手机的应用之前导出来。应用本身不用搬，在新手机上装一份即可（安装步骤见 [下载与安装教程.md](下载与安装教程.md)）。

## 二、完整备份：一个 JSON 文本搬全部

官方在设置里提供了完整备份入口，收藏、自建工具、历史记录等都在里面：

**旧手机上导出：**

1. 打开 CalcKit 的 **Settings（设置）**，拉到最底部找 **Full CalcKit Backup** 区块；
2. 点 **Create Backup**，会生成一段 JSON 格式的文本；
3. 把这段文本存到任何地方——复制进网盘、发给自己邮箱都行。

**新手机上恢复：**

1. 新手机装好 CalcKit；
2. 打开之前存的那份备份文本，**全选复制**内容；
3. 打开 CalcKit 的 Settings，点 **Restore Backup**。

两个必须知道的限制：恢复会**覆盖**新手机上已有的全部数据（收藏、工具、历史），**没有撤销**；所以官方也建议这一步在刚装好的干净应用上做。

## 三、自建工具可以单独导出

如果你只想搬几个自建工具、不动整体数据，Custom Tools 里的**导入 / 导出**是更细粒度的路子：逐个导出工具文件，到新手机上再导入。操作细节在 [自定义计算器制作教程.md](自定义计算器制作教程.md) 的导入导出一节。自建工具本身也在完整备份的覆盖范围内，两种方式选一种即可，别混着来以免对不上版本。

## 四、Premium 会自动跟过去

Premium 绑定的是 **Google 账号**，不绑设备：

1. 新手机登录同一个 Google 账号；
2. 打开 CalcKit，保持网络畅通；
3. 等 5~10 秒，授权状态自动恢复，广告消失。

没有恢复出来时，先查 Google 账号是否一致、网络是否可用。Premium 的内容与购买方式见 [免费版和Premium有什么区别.md](免费版和Premium有什么区别.md)；新手机装好后想改中文界面，见 [怎么把界面改成中文.md](怎么把界面改成中文.md)。
