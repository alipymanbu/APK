## 一、入口与基本流程

打开 **Custom Tools** 菜单，点 **Create New Tool** 新建。一个应用里可以建的工具数量没有限制。

做工具的整体流程：起标题 → 加变量 → 给变量写公式 → 需要的话配单位下拉。整个过程不写代码，公式就是普通的数学表达式。

## 二、标题与描述

- **Title（标题）**：显示在 Custom Tools 列表里的名字，起一眼能认出的；
- **Description（描述）**：多行文本，在工具界面单独占一个标签页（左滑或点 Description 按钮看到），支持基础 Markdown 语法——可以把公式的使用前提、口径说明写在这里。

## 三、变量：Number 与 Choice

每个工具最多 **25 个变量**，分两种类型：

- **Number（数值）**：既能当输入、也能当输出的数值项，是工具的主体；
- **Choice（选项）**：下拉选择项，用来做「模式切换」这类非数值输入。

Number 变量的几个关键设置：

| 设置 | 作用 |
| --- | --- |
| Identifier（标识符） | 其它变量公式里引用它用的名字，默认是单字母 A–Z（不含 E） |
| Name（名称） | 屏幕上显示的标签，比如「长」「宽」 |
| Formulas（公式） | 这条变量的计算式；一行一条，也可以不填（不填就是纯输入项） |
| Unit(s)（单位） | 显示在输入框右侧，可做成下拉（见第五节） |
| Default value | 输入框为空时用的默认值 |
| Disabled | 打开后该输入框禁用，用来标记「这是结果项」 |

变量之间是**双向求解**的：你改任何一个变量的值，关联的其它变量跟着重算。所以同一个工具既可以从长宽求面积，也可以从面积和长反推宽，不用做两个工具。

变量标识符在 Premium 里可以起自定义名字（比如 `LENGTH`、`WIDTH`），公式从 `Z = X * Y` 变成 `AREA = LENGTH * WIDTH`，回头再改公式时不容易认错。

## 四、公式怎么写

每个变量的公式写在它自己的 Formulas 框里，**一行一条**，想写几条写几条。公式里用其它变量的标识符参与运算。

官方文档里的重量换算示例：工具里有千克（X）、克（Y）、毫克（Z）、盎司（A）、磅（B）、吨（C）几个变量。千克这条的 Formulas 里写了五条公式，分别把其它单位**换算回千克**：克 `Y/1000`、毫克 `Z/(10^6)`、盎司 `A/35.274`、磅 `B/2.205`、吨 `C*1000`。本质就是：一个变量要能从哪些单位换过来，就在它的 Formulas 里给每个来源各写一条。

可用的函数除了四则，还包括三角函数、对数、取整、绝对值等一整套数学函数；常量里还有黄金比例（phi）与 tau（2π），7.0.0 起可用。完整的函数清单见官方文档 `https://calckit.io/docs/custom-tools`。

## 五、单位下拉怎么做

Unit(s) 栏填一行文本就是固定单位标注；**每行写「倍率 + 单位名」就能生成下拉菜单**。官方文档里矩形计算器的例子，边长变量填：

```text
0.001 km
1 m
100 cm
1000 mm
```

- 每行=倍率（空格）单位名；
- 基准单位的倍率是 `1`（例中是米），其它单位填「1 基准单位 = 多少个该单位」的倒数关系：1 m = 0.001 km，所以 km 填 `0.001`；1 m = 100 cm，所以 cm 填 `100`。

填好后使用工具时该输入框右侧就是下拉，选哪个单位就按哪个单位解释输入值，内部统一换算到基准单位再算公式——这也是给自己做单位换算器的最短路径。

## 六、不用从零开始：复制与社区库

两条省事的路：

1. **复制内置工具**：内置的 150+ 计算器和换算器都能复制一份再改。你需要的工具和内置某个差不多（比如就差一两个单位），复制后改公式和单位下拉，比新建快得多；
2. **社区库（Community Library）**：7.0.0 起免费开放，里面是其他用户发布做好的工具，可以直接使用；你也可以把自己做的工具发布上去。

## 七、导入导出与分享

自建工具不会锁死在手机里：

- **导入 / 导出**：工具文件可以导出保存、再导入到另一台设备（换手机时和应用的完整备份配合用，完整迁移流程见 [换手机怎么迁移数据.md](换手机怎么迁移数据.md)）；
- **复制 / 粘贴 / 分享**：工具支持整体复制，也能分享给别人；
- **网页嵌入**：在 CalcKit 的网页版里，内置工具和自定义工具都能生成嵌入代码放进自己的网页。

另外，应用底层的**完整备份**（Settings → Full CalcKit Backup）同样覆盖自建工具——不想逐个导出时，做一次完整备份即可全部带上；注意恢复备份会整体覆盖目标设备上的数据。

## 八、做一个小例子检验流程

用「BMI 计算器」当练习题，五步就能走完整个流程：

1. 新建工具，标题写「BMI 计算」；
2. 加两个 Number 变量：X（名称「体重 kg」）、Y（名称「身高 m」），都不写公式（纯输入）；
3. 加第三个 Number 变量 Z（名称「BMI」），公式一行：`X / (Y * Y)`；
4. 把 Z 的 Disabled 打开，标成输出；
5. 保存后回到工具列表点开它，填入体重身高，BMI 直接出结果。

跑通这个再回头看第五节的单位下拉，就能应付大多数自建需求了。做好的工具配合桌面快捷方式使用最顺手，设置方法在 [科学计算器怎么用.md](科学计算器怎么用.md)；想知道内置工具里哪些可以复制来改，读 [都有哪些计算器和换算工具.md](都有哪些计算器和换算工具.md)。
