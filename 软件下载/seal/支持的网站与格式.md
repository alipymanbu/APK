## 一、支持范围：跟着 yt-dlp 走

Seal 不自己实现「抓取」，它把这活儿全交给 yt-dlp —— 所以**能下哪些站，取决于 yt-dlp 当前支持哪些站**。官方 README 的表述就是「下载 yt-dlp 支持的视频平台上的视频与音频」，没有给出封闭的站点清单。

对你的实际影响有三条：

1. **清单是动态的**。今天能下的站，明天可能因为站点改版突然失败；反过来新站点也可能哪天就被支持了。这就是 [下载失败怎么解决.md](下载失败怎么解决.md) 里反复出现「先更新 yt-dlp」的原因。
2. **判断方法**：把你手上的链接贴进 Seal 试一次，能解析出选项面板就是支持；直接报错就是当前版本不支持或需要额外条件。
3. 二手资料常写「支持 100+ 平台」这个量级，可作参考，但**不是官方承诺的固定清单**。

常见类型举例（能否长期可用以实际解析结果为准）：短视频平台、视频分享站、音频站、社媒平台的公开帖子 —— 这些属于 yt-dlp 长期维护的对象。

## 二、下不了的内容：三条硬边界

| 内容类型 | 为什么不行 |
| --- | --- |
| DRM 保护的流媒体（正版影视、音乐平台的受保护内容） | DRM 不是 Seal 或 yt-dlp 能解开的，也不该去解 |
| 需要登录才能看的私有 / 会员 / 未公开内容 | 抓取方拿不到你的登录态就看不到该内容；即便拿到，也只能处理你**自己有权访问**的内容 |
| 明确禁止下载的站点 | 用不用是你的判断，Seal 只提供工具 |

一句话：**Seal 处理的是公开可访问、且你有权访问的内容**。别指望它替代正版客户端的离线功能。

## 三、能存成什么格式

设置里「格式」这组决定输出形态，常见组合：

| 目标 | 路线 | 常见格式 |
| --- | --- | --- |
| 要画面 | 下视频 | MP4（兼容性最好）；合并后也可为 MKV |
| 只要声音 | 提取音轨 | MP3 / M4A |
| 学习用 | 视频 + 字幕 | 内嵌字幕的视频文件 |

三个要点：

1. **可选格式与清晰度由站点返回的流决定**。面板里列出什么才能选什么；指定一个站点没有的档位会报「请求的格式不可用」。
2. **档位不是一张稳定的菜单**。站点会按单个视频、地区、客户端增减档位 —— 上个月还能选的组合这个月可能就没了，**换一个视频可选项就变**是常态，不是你哪里点错了。
3. **高清晰度往往需要合并**。很多站点把画面与音轨分成两条流分别提供，选高清晰度时 Seal 会先分别下载再合并成一个文件 —— 这也是为什么有些失败出在「合并」环节，还有「下完没声音」这种半成品（排查见 [下载失败怎么解决.md](下载失败怎么解决.md)）。合并由 Seal 内置的 FFmpeg 完成，无需你另外安装。
4. **要 MP4 就未必拿得到最高档**。站点的高清晰度流未必提供 MP4 封装，此时把格式放宽（或接受面板给出的其他封装）才能拿到那一档；执着于 MP4 通常意味着接受低一档的清晰度。
5. **默认格式可以固化**。在「设置 → 格式」里设好默认，之后每次弹面板就不用重新勾。

## 四、字幕：能下也能嵌

对提供字幕的站点，你可以让 Seal 把字幕一并下载，并**内嵌进视频文件**（播放器直接显示，不需要外挂 `.srt`）。字幕语言在设置里指定，站点没提供该语言时会自动退化或跳过 —— 具体行为随站点而变，以实际结果为准。

## 五、音频附加信息：元数据与封面

提取音频时可以顺手把**元数据**（标题、艺人、专辑等）与**视频封面图**写进音频文件。这不是默认就开的，需要你在设置里勾上（开关位置见 [高级设置与自定义命令.md](高级设置与自定义命令.md)）。打开后，播放器里显示的是封面与歌名，而不是一串下载时的文件名。

## 六、播放列表与批量

贴播放列表链接即可一次下整列（操作见 [新手使用教程.md](新手使用教程.md)）。批量场景下最容易触发站点的频控，成功率与单个链接不是一回事 —— 失败率高时先看 [下载失败怎么解决.md](下载失败怎么解决.md)。
