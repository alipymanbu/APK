## 一、设置结构导览

点首页左上角齿轮进设置，各组管什么（以实际界面为准）：

| 分组 | 管什么 | 值得动的 |
| --- | --- | --- |
| 通用 | 引擎更新、播放列表行为等基础项 | **更新 yt-dlp**（排障第一步） |
| 下载文件夹 | 保存目录、文件名输出模板 | 记住目录、自定义文件名 |
| 格式 | 视频/音频格式、清晰度、字幕、音轨合并 | 设成你的默认组合 |
| 网络 | aria2c 外部下载器等网络相关开关 | 大文件下载打开 aria2c |
| 自定义命令 | yt-dlp 命令模板的增删改 | 进阶玩法，见第五节 |

三件核心组件都随安装包自带、由应用统一初始化：**yt-dlp**（找地址）、**FFmpeg**（合并音视频、转码、把字幕与元数据写进文件）、**aria2c**（可选的下载引擎）。所以你在手机上不需要像电脑那样逐个安装配置它们 —— 出问题时的手段是「更新引擎 / 换开关」，而不是「补装依赖」。

## 二、aria2c：让大文件下得更稳

「设置 → 网络」里有一项**用 aria2c 作为外部下载器**。aria2c 是一个开源命令行下载器，Seal 内置了它；打开后由它负责实际传输。按 aria2 官方文档的口径，它能把一个文件切成多路连接并行拉取，并支持断点续传 —— 这正是「大文件、网络抖动」场景下比默认传输更稳的原因。

怎么判断该不该开：

- 文件大（几百 MB 以上）、网络抖动、下到 90% 断掉 —— 打开试试；
- 开着出问题（个别站点不兼容、反而失败）—— 关回去，默认下载器照样能用。

两个附带注意：并发路数开太多时，**有的服务器会反过来限速你的 IP**（aria2 官方文档自己也这么提醒），所以别为了「更快」去乱调并发参数；开关是可逆的，拿不准就两种各试一次，以你实际的下载结果为准。

## 三、更新 yt-dlp 与更新通道

「设置 → 通用」里的更新项不只是排障用的日常维护项：

- **平时**：站点改版是常态，隔一两周手动更新一次，能挡掉大部分「突然下不了」。
- **报错时**：先更新再排查，顺序见 [下载失败怎么解决.md](下载失败怎么解决.md)。
- **更新通道**：有的版本支持在该项的齿轮里选通道（如 stable 与其他通道）。稳定优先选 stable；stable 覆盖不到的新问题，再考虑其他通道，出错就切回来。
- **通道的差别**：stable 是经过常规发布的稳定版；nightly 这类通道更新更频繁、修得更早，代价是可能引入新问题 —— **日常用 stable，只有在「站点刚改版、stable 还没跟上」时才临时切过去试，问题一解决就切回来**。界面上实际提供哪些通道以你看到的为准。

注意：更新走的是官方渠道（GitHub 的发布接口），这正是 F-Droid 给 Seal 标注「依赖非自由网络服务」的原因 —— 该标注指的是更新检查依赖 GitHub API，不是应用本身闭源（许可证 GPL-3.0-only，源码在 [GitHub](https://github.com/JunkFood02/Seal)）。

## 四、文件名与保存位置：输出模板

「设置 → 下载文件夹」里除了改目录，还能改**文件名输出模板** —— 决定下完的文件叫什么。默认通常是按站点标题命名，你可以改成自己的规则，比如「标题-作者」「日期-标题」这类组合（模板语法以设置页内的说明为准）。

实用建议：下载目录固定到一个你记得住的位置（如 `Movies` 下自建一个子目录），列表批量下载几十个文件时才不会在一堆目录里翻。

## 五、自定义命令模板：把 yt-dlp 的参数搬进按钮

这是 Seal 给进阶用户留的口子：**你可以在模板里写 yt-dlp 的命令行参数，之后一键套用**，不必每次手敲。README 对它的描述是「用模板执行自定义 yt-dlp 命令」「管理应用内下载与自定义命令模板」。

典型用法（参数含义以 [yt-dlp 官方文档](https://github.com/yt-dlp/yt-dlp) 为准）：

```bash
# 只下某个指定清晰度、输出为 mp4 的一组常用参数，存成模板
-f "bv*[height<=1080]+ba/b" --merge-output-format mp4
```

操作流程（按钮名称以实际界面为准）：

1. 进「设置 → 自定义命令」，添加一条新模板；
2. 填入参数并保存，起一个你记得住的名字；
3. 下载时在面板里选用该模板；
4. 写错了就编辑或删除该模板，官方也支持把模板导出分享。

三条安全边界：

- **只写参数、不要写你没看懂的整串命令** —— 模板会原样喂给引擎，写错的表现是直接报错；
- 模板里的参数会覆盖面板里你勾的选项，两者冲突时以模板为准（所以模板名最好带上它会改变什么）；
- 参数要服务于**你自己的正当下载**，不写绕过授权、绕过站点限制的用法。

## 六、其他几组里值得知道的开关

- **字幕与元数据**：「格式」组里有字幕语言/是否内嵌、音频是否写入元数据与封面的选项，效果分别见 [支持的网站与格式.md](支持的网站与格式.md) 第四、五节。
- **播放列表行为**：「通用」组里调整列表链接的处理方式，批量场景见 [新手使用教程.md](新手使用教程.md) 第四节。
- **电池优化**：Seal 会请求「忽略电池优化」，批量下载时允许它，可以减少系统在后台把下载掐断的概率。
