## 一、Seal 是什么

Seal 是一款安卓上的视频与音频下载工具，界面是 Material Design 3 风格，底层调用的是开源命令行工具 yt-dlp —— 也就是说，你在手机上点几下按钮，就能完成原本要在电脑终端里敲一长串参数才能做到的事。它免费、开源（GPL-3.0-only），没有广告与内购。本篇只讲「拿到安装包并装上」，装好之后怎么用见 [新手使用教程.md](新手使用教程.md)。

开发者署名 JunkFood02，官方仓库在 [GitHub](https://github.com/JunkFood02/Seal)，包名 `com.junkfood.seal`。

## 二、先确认装哪一份：架构怎么选

Seal 的每个版本会同时发布多个 APK（同一版本号下按 CPU 架构分包），装错架构会装不上或运行异常。官方 README 的建议是：

| 你的手机 | 选哪份 |
| --- | --- |
| 近几年的主流安卓手机（绝大多数） | `arm64-v8a` 版，官方明确推荐大多数设备装这份 |
| 不确定自己是什么架构 | `universal`（通用）版，能覆盖绝大多数设备，体积也最大 |
| 老旧 32 位设备 | `armeabi-v7a` 版 |
| 模拟器 / 个别 Intel 芯片 | `x86_64` / `x86` 版 |

同一版本的文件名里会带架构与构建类型，形如 `Seal-1.13.1-universal-release.apk`（版本号以官方页面当时显示为准）。

## 四、安装步骤

1. 从上面任一渠道把 APK 下到手机（用浏览器下载会进「下载」列表，点开即可）。
2. 首次安装非应用商店来源的 APK，系统会要求你允许该来源「安装未知应用」—— 在弹窗里授予浏览器或文件管理器这个权限，再返回继续。
3. 在安装确认页点「安装」，等进度条走完显示「应用已安装」。
4. 点「打开」启动 Seal；也可以回桌面找图标。

装完即可删除安装包文件，不影响已装的应用。F-Droid 渠道安装后会有更新提醒；GitHub / 网盘渠道需要自己回头比对版本号。

## 五、第一次打开：要做的两件事

1. **过一遍用户指南**。首次启动会弹出使用引导，里面有「打开设置」入口，直接点进去把保存目录、默认格式看一眼。
2. **给足存储权限**。Seal 需要读写手机存储才能把文件落到你能找到的目录（其申请的权限包含读取/修改共享存储、查看网络连接、显示通知、请求安装更新等）。系统弹权限请求时选允许；如果当时点了拒绝，后续下载会失败，补救见 [下载失败怎么解决.md](下载失败怎么解决.md)。

设置界面常驻入口在**首页左上角的齿轮图标**。里面分「通用 / 下载文件夹 / 格式 / 网络 / 自定义命令」几组，日常要改的东西都在这儿，逐项说明见 [高级设置与自定义命令.md](高级设置与自定义命令.md)。

## 六、系统要求

- **安卓版本**：F-Droid 页面对 1.13.1 各构建标注「需要 Android 5.0 或更新」；国内一些分发页标注的口径更高（如「安卓 5.2 以上」）。以安装时系统的实际提示为准。
- **CPU 架构**：见第二节。
- **联网**：下载全程需要网络，Seal 会申请完整的网络访问权限。
- **不支持的内容**：需要登录才能看的私有内容、以及站点用 DRM 保护的流媒体（各类正版影视平台），不在它能处理的范围内 —— 能不能下，取决于 yt-dlp 是否支持该站点，详见 [支持的网站与格式.md](支持的网站与格式.md)。
