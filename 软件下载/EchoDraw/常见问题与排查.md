## 一、装不上、点开就退

这一类问题基本与设备环境有关，跟包本身好坏无关。先用包信息对一次胃口：版本 1.0、包名 `plus.H58B23835`、大小 4.24 MB。

| 现象 | 排查顺序 |
| --- | --- |
| 安装时提示「解析包错误」 | 1）文件没下完 → 删掉重下；2）下到的是半成品文件 → 重下后核对大小；3）手机系统版本低于包内要求（标注为 Android 5.2 及以上） |
| 提示「应用未安装」 | 手机里已有签名不同的同包名版本，先卸载旧的再装 |
| 点安装没有任何反应 | 「安装未知应用」权限没给当前文件管理器，或被安全类应用拦了安装行为 |
| 装好点开一闪就退 | 系统版本过低；或安装过程中权限被中断，卸载后重新装一次 |
| 提示存储空间不足 | 安装包只占 4 MB 出头，但要留出存画作图片的空间，清出几百 MB 再试 |

完整的取包与授权步骤见 [下载与安装教程.md](下载与安装教程.md)；包本身要用 [EchoDraw 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3fe220fe9e4e) 里的那一份，别用来源不明的同名片包。

## 二、登录与账号

EchoDraw 用**邮箱 + 验证码**的方式登录，没有密码这一项，所以「登不上」绝大多数是验证码环节的问题：

1. **收不到验证码**：先看邮箱的垃圾邮件/广告邮件文件夹，验证码邮件经常被判进去；再看邮箱地址有没有多打空格或把域名写错。
2. **验证码填了说已过期**：重新获取一次，拿到后立刻填，别在别的页面停留太久。
3. **换手机后作品不见了**：数据跟账号走，确认新手机上用的是同一个邮箱登录。
4. **不想用了会不会删数据**：按官方说明，不再续费或暂时停用都不会删除已上传的作品、目标与记录，内容保留在账号里。
5. **同一邮箱换设备登录**：登录后会自动同步你的画作、打卡与成长轨迹，不用手工导数据。

## 三、相机页打不开、画面发黑

描摹功能靠相机，这一类问题几乎都是权限或占用：

- **整片黑屏** → 进系统设置给 EchoDraw 补授相机权限。首次安装时如果点过「拒绝」，之后不会再自动弹窗。
- **偶尔黑、切一下就恢复** → 有别的应用在后台占着摄像头（相机、扫码、视频通话类），把它切掉再回 EchoDraw。
- **画面糊、对不上焦** → 镜头没合焦，退出描摹页重新进一次；同时擦一下镜头。
- **轮廓对不准** → 这不是故障，是操作顺序问题：先固定手机再导入参考图，中途别挪手机。具体做法见 [照片描摹与网格线怎么用.md](照片描摹与网格线怎么用.md)。

## 四、上传与数据

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 选完图点保存没反应 | 网络不通，或账号登录状态掉了 | 检查网络后重新登录再传 |
| 说上传数量已达上限 | 普通账号有试传额度，用完需开通会员 | 见下方「会员与额度」；已上传的内容不受影响 |
| 作品列表里少了刚传的那条 | 停在编辑页没点保存 | 重新走一遍保存流程，字段填完再退出 |
| 打卡天数、总时长是 0 | 未登录，或上传时没填时长 | 登录后重新确认；时长按填写值累加，空着按 0 计 |
| 换设备后统计清零 | 登录了另一个邮箱账号 | 用原账号登录即可恢复 |

上传时每个字段的建议填法见 [作品上传与画集整理.md](作品上传与画集整理.md)，数据口径见 [打卡目标与成长数据怎么看.md](打卡目标与成长数据怎么看.md)。

如果你确认操作没问题、现象却反复出现（比如上传每次都在同一进度卡住），可以按「包不对」处理一次：先用 [EchoDraw 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3fe220fe9e4e) 里的包卸载重装，再登录原账号，作品数据不会因此丢失。

## 五、会员与额度

官方对会员的说明比较清楚，常见疑问基本就这三条：

- **只有一档**。不设多个等级，也不做限时优惠、不卖永久会员。
- **额度限制只在上传数量上**。普通账号可以试传少量作品把流程走一遍，持续使用需要订阅；订阅时长与价格以应用内支付页当时显示为准。
- **停止续费不会清数据**。作品、目标、打卡记录都保留；差异只在新增上传是否还受额度限制。

需要注意的一点：会员权益、价格与档位属于官方会调整的内容，本文写的是规则性说明，具体数字请以你手机上应用内的页面为准。

## 六、隐私与作品版权

- **作品存放位置**：你上传的图片、目标与记录只存在自己的账号里。按官方说明，不会被团队查看，也不会用于 AI 模型训练或其它二次用途。
- **默认可见性**：作品列表默认不对外公开，别人不会自己看到你的画；只有你主动发起的分享行为才会让内容离开账号。
- **参考图与作品的边界**：描摹时导入的参考照片只是屏幕上的叠加图层，不会被写进你的相册；但把它当作品发出去属于另一回事 —— 发出去的应该是你在纸上画的那张，只传自己的画。
- **官方渠道**：关于功能范围与数据处理的完整说明，以官方发布页为准，入口见 [www.echodraw.com](http://www.echodraw.com)。

隐私与版权这块的疑问，如果不属于上面任意一条，也可以先按「是不是包不对」自查一遍：用非标准来源的包，功能表现与官方说明不一致是常事，标准和取包入口见 [下载与安装教程.md](下载与安装教程.md)。
