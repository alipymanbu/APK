# SafeHaven 怎么搜索和安装应用

> 装好 SafeHaven 之后的使用篇：怎么在店里翻应用、搜应用，详情页上哪些信息值得看，以及装应用时系统还会拦你一次的那道权限。

## 一、先弄清一件事：你是在「用商店装别的应用」

SafeHaven 自己是商店，你打开它是为了在里面装其他应用。它收录的对象以开源应用为主，目录规模与 Play 商店不是一个量级，所以在里面搜不到某个大厂应用属于正常情况，不代表商店出了故障。

你还没装上它的话，先看[下载与安装教程.md](下载与安装教程.md)。

## 二、浏览：从分类和榜单开始逛

打开应用后，首页就是主目录，按分类和榜单组织。你可以：

- 在首页滑动浏览各个分类分区，先看榜单了解店里有哪类应用；
- 点进某个应用卡片进入详情页，先看信息再决定装不装。

第一次用建议先把榜单翻一遍，对这个店「有什么」建立概念，再决定自己要装什么——它的目录以开源与独立应用为主，商业大厂应用不多。

## 三、搜索：直接找目标应用

底部有独立的搜索入口，点开输入框，输入应用名称即可检索。几个实用技巧：

- 店内收录名以英文原名为主，搜中文名可能搜不到，换成英文名再试；
- 名字记不全就只输关键词片段，结果列表里认图标与开发者；
- 搜出来的结果点进详情页，别急着点安装，先看下面这节要说的信息。

## 四、详情页先看什么再装

这是 SafeHaven 与一般第三方商店最大的不同点：详情页上会把来源信息直接摆出来。你重点看这几项：

| 看什么 | 说明 |
| --- | --- |
| 源码仓库地址 | 应用能直接点进源码页，说明收录时登记了开源仓库 |
| 验证状态 | 开发者已通过仓库验证的，可信度比未验证上架高一档 |
| 安全扫描结果 | 上架前经过扫描的应用会标注；扫描没过或来源存疑的别装 |
| 签名与元数据 | 版本、大小、包名这些基本信息，装前扫一眼避免装错 |

这些标志背后的机制分别是什么意思、怎么分级，在[安全吗与信任机制.md](安全吗与信任机制.md)里展开讲。简单原则：**优先装「已验证源码 + 扫描通过」的应用**；详情页上来源信息空白的，自己掂量。

## 五、搜不到某个应用时，先对照这几种情况

店里的目录不是全量收录，有明确的边界。搜不到想要的应用，多数是下面几种原因之一：

- **包太大**：单 APK 超过 100 MB 的应用收不进来，大体量应用基本缺席；
- **项目停更**：目录按官方说明同步上游仓库时只取近 12 个月有更新的项目，长期停更的老应用可能不在；
- **来源没覆盖**：目录由开发者提交、社区投稿和上游仓库（F-Droid、IzzyOnDroid）同步构成，收录范围以这些渠道为准，与 F-Droid 重合的部分见[和F-Droid有什么区别.md](和F-Droid有什么区别.md)；
- **版本刚发**：上游新版本要等商店的定期检查才会出现，官方说明这一检查每 6 小时批量跑一轮，晚几个小时再搜；
- **设备架构不匹配**：x86 构建被整体排除，模拟器与 x86 设备装不了部分应用。

## 六、安装与后续更新

详情页上有安装按钮，而且页面往下滚动时按钮会置顶常驻，翻介绍时随时能点：

1. 点「安装」，会弹出系统安装确认窗；
2. 第一次在 SafeHaven 里装应用时，系统会要求授予它「安装未知应用」的权限——和当初装 SafeHaven 本身那一步一样，在弹出的设置页里打开开关再返回；
3. 确认后等安装完成，之后可以在系统的应用列表里找到新装的应用。

后续更新：商店会做版本校验，有新版的应用在列表里会体现出来，进详情页点更新即可；如果是通过 IzzyOnDroid 仓库装的 SafeHaven 本体，它自己的更新由你的 F-Droid 类客户端负责。

装完遇到打不开、装不上的情况，先回到[下载与安装教程.md](下载与安装教程.md)第四节对照排查；对某个应用不放心时，按[安全吗与信任机制.md](安全吗与信任机制.md)里的自查方法核一遍。
