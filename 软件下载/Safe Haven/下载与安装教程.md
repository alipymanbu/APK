## 一、先把安装包拿到手

SafeHaven 不是从 Play 商店装的（它本身就是一个商店类应用），所以要先把 APK 安装包弄到手机上。按你方便的方式选一种：

| 渠道 | 适合情况 | 说明 |
| --- | --- | --- |
| 夸克网盘 | 想要本页对应的 2.0.1 版 | 打开 [SafeHaven 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a93bc126a702)，转存到自己网盘后下载 APK；包约 18.82 MB |
| 官方商店页 | 想要最新版 | 访问 [https://store.colourswift.com/app/com.colourswift.safehaven](https://store.colourswift.com/app/com.colourswift.safehaven) 下载 |
| IzzyOnDroid 仓库 | 已在用 F-Droid 类客户端 | 在客户端里添加 IzzyOnDroid 源后搜索安装，后续更新自动提醒 |
| GitHub Releases | 想看每次更新记录 | 在源码仓库的 Releases 页面取各版本安装包 |

安装包基本信息（以本页网盘资源为准）：版本 2.0.1，包名 `com.colourswift.safehaven`，大小 18.82 MB，MD5 为 `88FBC63E254C9C5D57B338A6B1112B37`。

## 二、安装步骤

安卓对「从商店以外装应用」有权限门槛，所以装到一半会被系统拦一下，这是正常流程：

1. 在手机上打开下载好的 APK 文件（网盘下载的从下载目录打开即可）；
2. 系统弹出「不允许安装未知应用」的提示时，选择「设置」→ 打开你用来打开 APK 的那个应用（浏览器或文件管理器）的「允许安装未知应用」开关；
3. 返回安装界面，点「安装」，等进度走完；
4. 装完点「打开」，第一次启动会加载商店目录，联网状态下稍等片刻。

如果第 2 步找不到开关，路径一般是「设置 → 应用 → 特殊应用权限 → 安装未知应用」，不同品牌 ROM 的措辞略有差别。

## 三、装完后先确认两件事

**版本号**：进应用的关于或设置页看版本，网盘这份应为 2.0.1。官方迭代很快，想要新版本就按上面表格里的官方渠道更新。

**安装包是不是官方签发的**：ColourSwift 发布的官方 APK 有一把固定的签名证书，SHA-256 值为：

```text
9c67f4224888f60e093cf7eab9b194e6d4cd73bb11313638c47b17f0d5f34ec4
```

会折腾的用户可以在电脑上用 Android SDK Build Tools 核对：

```bash
apksigner verify --print-certs 安装包文件名.apk
```

输出里的证书 SHA-256 与上面一致，说明这份包出自官方之手。这一步做不做随你，机制怎么运转、还有哪些自查手段，在[安全吗与信任机制.md](安全吗与信任机制.md)里有更完整的说明。

## 四、装不上、打不开的几种常见原因

- **提示「解析包出现问题」**：多半是下载没完成或文件损坏，重新下载一遍，核对 MD5 再装；
- **安装按钮按了没反应**：检查是否还在「允许安装未知应用」这一步没走完；
- **启动后一直加载不出内容**：商店目录要从服务器拉取，检查网络；它的商店接口是联网服务，服务器端维护时确实会加载失败，等一段时间再试；
- **手机系统版本过低**：这份安装包记录的系统要求为安卓 5.2 以上，过老的设备建议先升级系统；
- **系统多出一道旁加载拦截**：谷歌正在推行开发者验证，2027 年起装未验证开发者的应用可能要走额外流程，目前第一波不涉及这个店，细则见[谷歌开发者验证新规后还能装吗.md](谷歌开发者验证新规后还能装吗.md)。
