## 一、先核对手机条件

Gal Lop 是安卓端的视觉小说创作与阅读应用，装之前先对一眼这张表，免得白下载一趟：

| 项目 | 数值 |
| --- | --- |
| 版本 | 1.0 |
| 安装包大小 | 27.56 MB |
| 包名 | com.gallop.app |
| 系统要求 | Android 5.2 及以上 |
| 界面语言 | 简体中文 |

两点提醒：

- 安装包约 27.56 MB，再加上应用运行产生的数据，建议手机至少留出 200 MB 空闲空间；
- 版本号会随更新变化，以上是本文记录的这一版，新版本以安装包页面实际显示为准。

## 二、从网盘拿到安装包

1. 打开上面的 Gal Lop 安装文件资源（夸克网盘）链接；
2. 把文件转存到自己的网盘（页面里有「保存到网盘」的按钮）；
3. 在夸克网盘客户端里找到刚转存的 `Gal Lop_v1.0.apk`，点下载到手机本地。

转存这一步不能省：分享链接里的文件只有先放进自己的网盘，才能正常下载与长期使用。

## 三、安装步骤

1. 在手机文件管理里找到下载好的 apk，点击它；
2. 系统如果弹出「禁止安装未知来源应用」的提示，按提示允许当前来源安装（不同品牌手机入口不同，一般在弹窗里点「设置」→ 打开「允许安装」再返回）；
3. 回到安装界面点「安装」，等进度走完；
4. 点「打开」进入应用，首次启动按引导操作即可。

## 四、装不上时按这几条排查

| 现象 | 常见原因 | 处理办法 |
| --- | --- | --- |
| 提示「解析包出错」 | 下载不完整、文件损坏 | 重新下载一遍；担心文件不对时，可比对 apk 的 MD5 是否为 `6ACD6E0953DD072A3E40B25E016D11CA` |
| 提示「与应用不兼容」 | 系统版本低于要求 | 确认系统为 Android 5.2 及以上；部分老机型即使满足版本也可能装不上 |
| 提示存储空间不足 | 手机剩余空间太小 | 清理出足够空间后重试 |
| 安装按钮灰色点不动 | 未授予「安装未知应用」权限 | 到系统设置里给文件管理器或网盘客户端开「允许安装未知应用」 |
| 装好后闪退 | 运行内存被占满 | 关掉后台应用重开；仍闪退可重启手机再试 |

排查完还装不上的，先换一台设备试一次，可以快速判断问题出在安装包还是手机本身。搜到的版本、体积和本文对不上时，先看[同名版本区分与下载认准](同名版本区分与下载认准.md)；装好之后从哪下手，见[创作入门与首个作品](创作入门与首个作品.md)；使用中的其他疑问，翻[阅读书架与常见问题](阅读书架与常见问题.md)。
