MOLDIV 内置两套相机：Pro Camera 主打实时滤镜与手动控制，Beauty Camera 专管自拍美颜，另有 Photo Booth 连拍模式。本篇讲每种模式怎么进、各选项是干什么用的，以及老机型用实时滤镜卡顿时的取舍。

## 一、为什么用应用内相机而不用系统相机

MOLDIV 的滤镜能在取景时就实时套用（官方对安卓 3.4.x 的相机标注 194 款实时滤镜，与编辑功能里同一批），实时虚化也能在取景时预览，拍完即所见。习惯「拍完再修」的话，应用内相机可以完全不用，直接在编辑功能里导照片。

## 二、Pro Camera：实时滤镜与手动选项

1. 首页进 Camera（相机），默认就是实时滤镜模式，左右滑动滤镜缩略图换效果。
2. 实时虚化在工具栏里开，取景画面上直接能看到背景虚掉的效果。
3. 需要精细控制时进相机设置，按需开下面的手动项。

| 相机选项 | 作用 |
| --- | --- |
| 静音快门 | 快门不出声，安静场合拍照用 |
| 手动白平衡 | 按环境光校色，灯光复杂的室内有用 |
| 闪光灯常亮（torch 模式） | 补光当手电用，不只拍摄瞬间闪 |
| 数码变焦 | 捏合屏幕缩放，倍率越高画质越差 |
| 网格 | 构图参考线 |
| 地理位置标记 | 给照片写坐标，需要位置权限 |
| 自拍定时 | 延时释放快门 |
| 镜像模式 | 前置自拍按镜像保存，招牌文字不反 |
| 自动保存 | 拍完自动进相册，不用手动点保存 |

## 三、Beauty Camera：美颜调节

美颜滤镜专门为人像准备，磨皮强度实时可调——取景画面上直接看效果，边看边调到自然为止，比拍完再修省一轮。拍完还想再调整，编辑功能里另有人像修整项（瘦脸、放大眼睛这类），以实际界面为准。

## 四、Photo Booth

Photo Booth 是连拍式的大头贴模式：连续拍数张自动拼成一格一格的贴纸相，出图就是拼好的成片，不用再进拼图功能。具体张数与版式以应用内显示为准。

## 五、卡顿与耗电

实时滤镜与实时虚化都要持续处理取景画面，是相机功能里最吃性能的两项，老机型或低电量时最明显。取景卡顿就先把滤镜切到无效果再拍，后期在编辑里补滤镜——同一批滤镜，出来的效果一致。相机打开黑屏或闪退的情况则多半不在相机本身，排查顺序见 [常见问题与解决方法.md](常见问题与解决方法.md)。
