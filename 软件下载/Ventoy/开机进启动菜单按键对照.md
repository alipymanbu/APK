## 一、常见品牌按键对照

开机出现品牌 Logo 的瞬间按键，多数机型需要连按：

| 品牌 | 常见按键 | 说明 |
| --- | --- | --- |
| 联想 | `F12` 或 `Fn+F12` | 笔记本多数系列适用；部分老机型用 `F9` |
| 戴尔 | `F12` | 笔记本与台式机常见做法 |
| 惠普 | `Esc` 后再按 `F9` | 开机按 `Esc` 进入 Startup Menu，再选 Boot Device Options |
| 华硕 | 按住 `Esc` 再按电源键 | 官方做法；部分机型也可在 BIOS 界面里按 `F8` 调出 Boot Menu |

以上是常见机型的做法，个别型号有差异，以开机画面底部的提示或品牌官方说明为准。都试不通就用兜底顺序：`F12`、`F11`、`F9`、`F8`、`Esc` 挨个试。

## 二、按键时机与手法

- **时机**：开机自检初期、Logo 刚出现就按；按晚了菜单不弹出，只能重启重来。这类一次性启动菜单只对本次开机生效，不会改动 BIOS 里保存的引导顺序；
- **手法**：每秒 1~2 次连续按，直到菜单出现，只按一次容易错过窗口期；
- **台式机**：可以从按下电源键开始就有节奏地按（每 2 秒一次也来得及），直到屏幕出现提示。

## 三、按了没反应的排查

1. **时机不对**：等看到 Logo 才开始按往往已经晚了，重启后从按电源键起就连按；
2. **U盘没被识别**：U盘要在开机前就插好；启动菜单里根本没有 U 盘条目时，先把U盘插到别的电脑上确认它能正常读取；
3. **快速启动（Fast Boot）开着**：部分机型开机会跳过 USB 设备枚举，BIOS 里把它关掉（华硕机型的路径是 Advanced → Boot → Fast Boot → Disabled，其他品牌入口类似）；
4. **安全启动拦截**：菜单里看不到 UEFI 启动条目、或选了之后引导报错，进 BIOS 暂时关闭 Secure Boot 再试（华硕机型：Security → Secure Boot → Secure Boot Control → Disabled，保存重启）；
5. **键盘没就绪**：无线键盘的接收器在开机初期可能还没加载完，换有线键盘再试。

## 四、菜单弹出之后

在菜单里认出你的U盘（UEFI 机器选带 `UEFI:` 前缀的条目、老机器选不带前缀的），选哪一项、进了 Ventoy 菜单怎么操作，见 [启动U盘在电脑上怎么用.md](启动U盘在电脑上怎么用.md)。
