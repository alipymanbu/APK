# 手机制作 Ventoy 启动U盘完整步骤

> 不开电脑，一部安卓手机加一根 OTG 线，就能把普通U盘做成 Ventoy 多系统启动盘。本篇从接线到放镜像文件，按顺序走一遍全流程。

## 一、开始前准备

| 要准备的东西 | 说明 |
| --- | --- |
| 安卓手机 | 电量留足，安装过程按应用提示保持前台运行 |
| U盘 | 建议 8GB 起步；要放 Windows 安装镜像的话，单个镜像就有 5GB 上下 |
| OTG 转接头 | 手机 Type-C 转 USB-A；手机和U盘都是 Type-C 口的话可以直接连，不需要转接头 |
| 镜像文件（ISO） | 提前下载到手机存储，比如 Windows 或 Linux 发行版的安装镜像 |

**动手前必看**：给U盘安装引导的过程会**格式化U盘**，里面现有的所有数据都会被清掉，重要文件先备份到别处。

## 二、把U盘接到手机上

1. U盘插进 OTG 转接头，再接到手机；
2. 打开应用前，先在系统设置里搜「OTG」，确认开关是打开的——不少品牌默认关闭，这是「插上没反应」最常见的原因；
3. 打开应用，等几秒让它认出U盘。

认不出盘的话，直接翻 [U盘不识别与制作失败排查.md](U盘不识别与制作失败排查.md)，不用在这耗着。

## 三、选分区方案：GPT 还是 MBR

这一步决定U盘将来能在什么电脑上引导，选错是最常见的「做成了但启动不了」的原因：

| 分区方案 | 适合的电脑 | 注意 |
| --- | --- | --- |
| GPT | 较新的电脑（UEFI 启动） | 勾选 Secure Boot Support，安全启动开着也能引导 |
| MBR | 较老的电脑（传统 Legacy BIOS 启动） | 兼容老平台 |

拿不准给哪台电脑用：查那台电脑的品牌 / 主板规格页看启动方式；实在确定不了，先按现在主流的 GPT 做，不行再换 MBR 重来一遍（重装引导会再次格式化U盘，镜像文件先挪走）。

## 四、安装引导到U盘

1. 确认界面显示的设备是你的U盘（容量对得上），点 INSTALL；
2. 弹出的「会清空磁盘」类警告确认继续；
3. 保持应用在前台，等它格式化并写入引导，通常几分钟内完成；
4. 完成后U盘被分成两个部分：一个放镜像文件的主分区，一个引导分区。

两个常用按钮：

- **Update**：之后新版本出了，用它升级U盘里的引导；
- **Clear**：把U盘恢复成普通盘（移除引导）。

关于费用：免费版安装引导要消耗应用内金币（看广告获取），拷贝镜像文件本身不消耗；每次具体消耗多少，以应用内实际提示为准。

## 五、把 ISO 镜像放进U盘

1. 用应用内置的文件管理器，或手机系统的文件管理器，把 ISO 复制到U盘的主分区；
2. 多个镜像可以共存，也能建子目录分类存放；
3. 单个超过 4GB 的镜像注意：FAT32 文件系统放不下，要选 exFAT 或 NTFS（在安装引导那一步选，改选要重装一遍引导）；
4. 除了从手机往U盘拷，也可以按应用商店页的说明，在应用内直接把镜像下载到U盘；
5. 拷完在系统里**弹出 / 卸载**U盘，再拔线。

镜像文件本身去哪里下、认准哪些官方入口，见 [ISO镜像官方下载渠道.md](ISO镜像官方下载渠道.md)。

## 六、拿到电脑上用

到这里启动盘就做好了。插到目标电脑、开机进启动菜单、在 Ventoy 界面里选镜像，具体操作见 [启动U盘在电脑上怎么用.md](启动U盘在电脑上怎么用.md)。
