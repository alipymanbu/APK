# 和电脑版有什么区别

> 搜「Ventoy」会同时撞见两个东西：电脑上的官方开源工具，和手机上这个第三方应用。本篇讲清两者的关系、各自能做什么，免得装错、用错。

## 一、两个东西，不是一套软件

| | 电脑版 Ventoy | 手机版 Ventoy（本应用） |
| --- | --- | --- |
| 开发方 | [`ventoy.net`](https://www.ventoy.net) 的开源项目 | 第三方开发者 MixApplications |
| 运行环境 | Windows / Linux | 安卓手机 |
| 出场身份 | 官方原版 | 商店名称就带 Unofficial（非官方）标注 |
| 获取渠道 | 官网下载页 | [Google Play 商店页](https://play.google.com/store/apps/details?id=com.mixapplications.ventoy_app) |

两者做的是同一件事：给U盘写入 Ventoy 引导，把它变成多系统启动盘。手机版通过 OTG 直连U盘来完成，做盘时不需要电脑在场。

## 二、装出来的U盘一样吗

一样。不管用哪个做的，插到电脑上引导后看到的都是标准的 Ventoy 界面：列出U盘里的镜像文件、方向键选择、`F3` 切目录树、`Ctrl+d` 走 Memdisk 模式。U盘本身的用法也相同：镜像随时增删，不用重新格式化。

## 三、功能边界差异

| 事项 | 电脑版 | 手机版（本应用） |
| --- | --- | --- |
| 制作 / 升级 / 移除引导 | 支持 | 支持（应用内 INSTALL / Update / Clear 按钮） |
| 费用 | 完全免费、开源 | 基础功能免费，装引导消耗金币，另有付费 Pro 版 |
| 插件配置（主题、自动安装脚本等） | 支持，有图形配置器 | 应用内没有对应功能（以实际界面为准），这类进阶需求要用电脑版 |
| 需要的硬件 | 一台能开机的电脑 | 一部支持 OTG 的安卓手机 |

## 四、什么时候用哪个

- **电脑已经趴窝、身边只有手机和U盘**：手机版是此时的主力——做一个启动盘去救那台电脑；
- **手边就有电脑**：直接用电脑版；
- **两边混用也行**：手机做的盘，之后照样能在电脑上维护（升级引导、增删镜像），两边的产物是同一种盘。

## 五、手机版的费用机制

免费版可以正常做完一个启动盘，但安装引导这一步要消耗应用内金币（通过看广告获取），拷贝镜像文件不消耗；商店内另有付费的 Pro 版本，去广告、不受金币限制。具体价格与机制以 Google Play 商店页当时显示为准。
