## 一、应用认不出U盘

按命中率从高到低排查：

1. **OTG 开关没开**：系统设置里搜「OTG」，不少品牌默认关闭，打开后重插一次；
2. **转接头不传数据**：有些 OTG 头只能充电、不能传数据（拿充电线改的尾插最常见），换一个正经的 OTG 转接头；
3. **U盘本身有问题**：把U盘插到电脑上确认能正常读写，排除U盘已损坏；
4. **换直连方式**：手机和U盘都是 Type-C 口的话，用双 Type-C 数据线直连，绕开转接头这个变量。

## 二、点安装没反应或中途失败

| 检查点 | 说明 |
| --- | --- |
| 应用内金币余额 | 免费版安装引导要消耗金币（看广告获取），余额不够会装不了；拷镜像不消耗 |
| 安装过程是否被中断 | 按应用提示保持前台运行直到完成，中途拔线、强退应用都会导致失败 |
| U盘写保护 | 部分 U盘侧面有物理写保护开关，拨到锁定状态就写不进去，拨回解锁 |
| 设备选对了没 | 确认界面里显示的设备容量和你的U盘一致，别把别的存储设备当成目标 |

金币攒起来麻烦的话，应用有付费的 Pro 版本，去广告、没有金币限制（以商店页当时说明为准），按需自己取舍。

## 三、引导装好了，但电脑上不对劲

- **电脑上看到的U盘容量变小 / 分区结构和以前不一样**：正常现象。引导装完后U盘是「镜像分区 + 引导分区」的结构，资源管理器里一般只显示放文件的那个分区；不认识的小分区别手动删除或格式化；
- **插电脑能认盘，但从U盘启动不了**：这不是U盘坏了，是引导方式没对上，处理办法见 [启动U盘在电脑上怎么用.md](启动U盘在电脑上怎么用.md) 的排查表。

## 四、镜像拷不进去

1. **提示空间不足**：看主分区剩余容量是否大于镜像文件大小；
2. **单个大文件复制失败**：文件系统是 FAT32 时单个文件上限 4GB，Windows 10/11 的安装镜像普遍超过这个数——回手机上重装一遍引导并选 exFAT / NTFS（重装会再次格式化，先挪走已有文件）；
3. **拷到一半断开**：先在系统里弹出U盘再拔线；反复失败就换线，或改用双 Type-C 直连。

## 五、都试过了还是不行

回到最初的两件套验证：U盘插电脑确认好坏、换一个 OTG 转接头。这两样中有一个是坏的，后面所有步骤都白搭。应用本身的安装问题（装不上、闪退）见 [下载与安装教程.md](下载与安装教程.md)。
