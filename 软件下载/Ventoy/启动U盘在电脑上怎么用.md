## 一、从U盘启动的三个动作

1. 启动U盘插到目标电脑的 USB 口上；
2. 按下电源键后立刻连续敲启动菜单键；
3. 在弹出的启动设备菜单里选中你的U盘，回车。

启动菜单键没有统一标准，常见的有 `F12`、`F11`、`F9`、`F8` 和 `Esc`，开机画面底部通常有一行小字提示（Boot Menu 字样），以自己机器的提示为准；各品牌具体按哪个键，对照表见 [开机进启动菜单按键对照.md](开机进启动菜单按键对照.md)。

## 二、启动菜单里选哪一项

- UEFI 启动的机器：选带 `UEFI:` 前缀的U盘条目；
- 老机器（Legacy BIOS）：选不带前缀的U盘条目；
- 两个条目都有的话，优先选与你做盘时分区方案匹配的那个：GPT 方案配 UEFI 条目，MBR 方案配不带前缀的条目。选反了轻则进不去 Ventoy 菜单，重则直接提示找不到引导。

## 三、在 Ventoy 菜单里挑镜像

引导成功后你看到的是标准的 Ventoy 选择界面：

- 界面上列出U盘里所有镜像文件，方向键移动、回车启动；
- 镜像多了可以按 `F3` 切换成目录树模式，按目录找文件，再按一次切回列表；
- 某些小体积镜像（WinPE、Live CD 这类）在个别老机器上启动失败时，先按 `Ctrl+d` 再选镜像，走 Memdisk 模式——整个镜像先读进内存再启动，成功率高一些但占内存，不适合几 GB 的安装镜像；再按一次 `Ctrl+d` 恢复默认。

这些快捷键属于 Ventoy 引导本身，跟你用手机还是电脑做的盘无关。

## 四、启动失败先查这两处

| 现象 | 先查什么 |
| --- | --- |
| 提示 Secure Boot / 安全启动相关错误 | 进 BIOS 把 Secure Boot 暂时关掉再试；或回手机上重做一遍引导、勾上 Secure Boot Support |
| 直接黑屏或提示找不到引导 | 启动模式对不上：换启动菜单里另一个U盘条目试试；还不行就回手机上把分区方案换成另一边（GPT 换 MBR，或反过来） |

注意：通过手机应用重装引导会再次格式化U盘，镜像文件先拷回手机或电脑存一份。

## 五、U盘还能当普通U盘用吗

能。引导装好之后，U盘的日常存取不受影响，你随时可以往里放普通文件；镜像文件也可以随时增删、替换，不需要重新格式化。换系统或换镜像时，直接操作文件就行。
