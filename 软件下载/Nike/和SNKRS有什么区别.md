# Nike App 和 SNKRS 有什么区别

> 耐克官方的应用不止一个：购物主力 Nike App、球鞋发售的 SNKRS、跑步与健身各一个，再加微信小程序。这篇讲清各自管什么、你该装哪个。

## 一、五个官方入口的分工

| 入口 | 管什么 | 你什么时候需要它 |
| --- | --- | --- |
| Nike App（`com.nike.omega`） | 全品类购物 + 会员中心 | 日常买鞋买衣服，看会员权益 |
| SNKRS（`com.nike.snkrs`） | 限量球鞋发售：发售日历、抽签、店铺预约 | 蹲限量款发售 |
| Nike Run Club | 跑步记录与跑步指导 | 有跑步习惯 |
| Nike Training Club | 训练课程 | 在家或健身房跟练 |
| Nike 微信小程序 | 轻量下单与售后入口 | 不想装 App 时临时买 |

应用商店里搜「Nike」经常把这些混在一起列出来，认包名最稳；装哪个、怎么装见 [下载与安装教程.md](下载与安装教程.md)。另注意系统门槛：SNKRS 中国在商店里标注 Android 9 以上（以应用商店当时标注为准），老手机先核对系统版本再装。

## 二、买限量球鞋走哪个

- 发售相关的事都在 SNKRS：新款提醒、发售日历、SNKRS 抽签（Draw）、部分款式的店铺预约（SNKRS Pass）；登记规则、付款时限与到店提货细节见 [限量发售与抽签规则.md](限量发售与抽签规则.md)。
- 但不是只有 SNKRS 能买：普通款直接在 Nike App 下单更省事，官网有售的它都有。
- 两个应用登录同一个 Nike 账号，会员身份与权益互通。

## 三、账号与权益怎么互通

一套账号密码走遍所有官方入口：官网、App、SNKRS、小程序通用。会员权益（免邮、退换、尖货）在哪个入口下单都生效；只有生日礼遇这类与账号资料挂钩的，要求用注册手机号登录才能收到，权益明细见 [会员注册与权益详解.md](会员注册与权益详解.md)。

## 四、按需求选装

- 只想买鞋买衣服：装 Nike App 就够，不装 SNKRS 不影响普通购买。
- 要蹲限量发售：Nike App + SNKRS 都装，发售日历与抽签在 SNKRS 里操作。
- 跑步 / 健身：另装 Nike Run Club 或 Nike Training Club，与购物互不影响。
