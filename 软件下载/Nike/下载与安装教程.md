## 一、先认准要装的是哪个应用

耐克官方在手机上不止一个应用，商店里搜「Nike」会出来好几个，先对准要装的这个：

| 应用 | 包名 | 用途 |
| --- | --- | --- |
| Nike App（本文主角） | `com.nike.omega` | 购物 + 会员中心，官网有售的它都有 |
| SNKRS | `com.nike.snkrs` | 限量球鞋发售：发售日历、抽签、店铺预约 |
| Nike Run Club / Nike Training Club | — | 跑步记录 / 训练课程，与购物无关 |

装错了不影响账号（账号通用），但你要的功能可能在另一个应用里。分不清就先看 [和SNKRS有什么区别.md](和SNKRS有什么区别.md)。

| 途径 | 适合谁 | 注意点 |

| 手机应用商店搜「Nike」 | 大多数人 | 认准开发者与包名，别点到 SNKRS |

| 直接用安装文件资源 | 商店里搜不到、商店版本更新慢 | 转存后下载 apk 安装，见下一节版本核对 |

走第三条的话，Nike 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/687334a21aad](https://pan.quark.cn/s/687334a21aad) ，转存到自己的网盘后把 apk 文件下载到手机，点开即可安装。

## 三、安装前核对版本

网上能搜到的永远是官方最新版，而安装文件资源里的是采集当时的版本，两者可能不是同一版。这份安装包的信息：

| 项目 | 值 |
| --- | --- |
| 版本 | 24.14.1 |
| 包名 | com.nike.omega |
| 大小 | 84.45M |
| MD5 | 82BD0CCBA2781E9B5865C95CEEEFE775 |
| 采集时间 | 2026-09-27 |

MD5 用来核对文件是否下载完整：部分文件管理器自带「校验 MD5」功能，比对一致再装。版本号只代表这份包的口径，界面与功能以你实际打开的为准。

## 四、安装步骤

1. 把 apk 文件放进手机存储：网盘 App 内转存后下载，或数据线从电脑拷贝均可。
2. 在文件管理器里点这个 apk。首次安装会提示「不允许安装未知来源应用」，按提示去系统设置里允许你的文件管理器安装应用，不同品牌手机的入口名称略有差异。
3. 回到文件管理器继续安装；装完可以把刚才的「安装未知来源应用」授权关掉。
4. 安装包本身 84.45M，再留出缓存与数据的空间，手机存储建议预留 200M 以上。

## 五、首次启动与登录

- 需要联网。首次打开会请求相机、相册等权限：相机用于扫码查物流、扫商品条码这类场景，相册用于保存图片或上传头像。权限都可以拒绝，不影响浏览与下单。
- 注册会员要手机号 + 短信验证码 + 登录密码。如果你在耐克官网、SNKRS 或微信小程序注册过，直接用同一账号登录，账号是通用的。
- 生日资料是选填项，但生日礼遇要求提前填好并注册满 2 个月，条件见 [会员注册与权益详解.md](会员注册与权益详解.md)。

登录进去之后，先弄清会员权益再下单，购物流程与时效见 [购物下单与配送时效.md](购物下单与配送时效.md)。
