## 一、发售走哪几个渠道

官方发售条款里写明的适用渠道是：Nike App、SNKRS App 与 Nike 官网。也就是说热门款不一定只在 SNKRS 出现，Nike App 里同样会有发售登记入口。每场发售的开始时间与登记时段，以该场发售邀请页面公布的为准。

## 二、登记规则（发售条款口径）

- 参与发售要先登录 Nike 会员账号，按页面提示完成登记；**同一场发售活动，每个账号只限登记一次**，后续登记无效。
- 普通发售：开始后即可登记，系统按登记时间与库存情况随机抽选，直到售罄。
- 抽签发售：在公布的登记开放期内提交登记，截止后统一随机抽选，所有参与者机会均等；结果取决于有效登记总数与库存。
- 条款里明确写着：官方不对任何人在发售活动中获得购买资格做出任何保证。

## 三、付款时限很短

官方抢购贴士的口径：订单生成后，付款有效期一般为 **10 分钟**（以发售页实际规定为准），超时机会就没了。所以发售前就该备好：

- 在 SNKRS 设置里提前保存鞋码、付款信息、配送信息；
- 设备支持指纹 / 触屏验证的就开启，缩短结算时间；
- 心仪的款点「通知我」，并允许 App 推送通知，发售提醒才收得到。

## 四、SNKRS Pass（到店提货的抽签）

SNKRS Pass 是 SNKRS 中国 App 里的会员专属线下抽签，与线上抽签的规则差异不小：

| 环节 | 规则 |
| --- | --- |
| 参与 | 在 SNKRS「动态」里找到该 Pass，在抽选时间内提交尺码 |
| 定位 | 靠 GPS 确定你附近的提货店铺，需要开启位置服务与推送通知 |
| 修改 | 姓名、鞋码、店铺一经提交不能改 |
| 中签后 | 按页面信息去指定线下店铺付款提货，App 内不付钱，店铺也不配送 |
| 证件 | 带照片的证件原件（驾驶证 / 学生证 / 护照 / 军人证），姓名须与 Pass 一致 |
| 代提 | 不允许，只有 Pass 上显示的本人能买 |
| 次数 | 每款每人一次预订机会，也不能在多家店同时抽 |
| 过期 | Pass 只在标注的提货期内有效，过期作废；中签了不去提也不强制购买 |

## 五、两条会被拒的线

官方发售贴士明确禁止两类行为：**代购销售**（以转售为目的购买，被认定后账号可能被禁止购买甚至永久关闭）与**不公平购买**（以任何方式做出的不公平购买行为，订单可能被拒绝或取消）。自己正常买不受影响。
