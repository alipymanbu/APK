## 一、它认哪些本地内容

Venera 的「本地漫画」入口支持两类东西：**符合结构要求的图片文件夹** 和 **特定格式的压缩包**。随手解压出来的一堆图片、或任意格式的压缩包，直接丢进去是不认的 —— 结构要求如下（摘自官方文档 `doc/import_comic.md`）。

### 文件夹结构（两种之一）

**无章节型**：

```text
漫画文件夹
├── cover.jpg      ← 封面，可省略
├── img1.png
├── img2.png
├── img3.png
└── ...
```

**带章节型**：

```text
漫画文件夹
├── cover.jpg      ← 封面，可省略
├── 第1话
│   ├── img1.png
│   ├── img2.png
│   └── ...
└── 第2话
    ├── img1.png
    └── ...
```

规则要点：

- 图片文件名随意，但**扩展名必须是有效的图片格式**；页序按文件名字母序排，想控制顺序就把文件名编成 `01、02、03…`；
- `cover.[ext]` 存在就当封面，不存在就拿第一张图当封面；
- 文件夹名 = 漫画标题，子文件夹名 = 章节标题。

### 压缩包格式

只支持 Comic Book Archive 这一类，扩展名为：

| 扩展名 | 说明 |
| --- | --- |
| `.cbz` | zip 打包的漫画归档 |
| `.cb7` | 7z 打包的漫画归档 |
| `.zip` | 结构需与上面的文件夹规则一致 |
| `.7z` | 同上 |

`.rar`、`.cbt`、`.pdf` 不在支持列表里，需要先转格式或解压成目录再导入。

## 二、导入步骤

1. 把整理好的文件夹或压缩包放到手机存储里（位置随意，记得住就行）；
2. 打开 Venera →「本地」→「导入」；
3. 选中文件或目录，确认后它会出现在本地列表里，用文件夹名当标题、子文件夹名当章节；
4. 点封面进详情，再点章节开始读。

导入后按上面的结构自查：**导入后是空的、或章节顺序乱了**，九成是结构或文件名序号问题，回第一节对照。

## 三、换了手机 / 丢了数据库：恢复本地下载

下载过的漫画和本地数据库（`local.db`）是分开存的。迁移时保住了下载文件夹但丢了数据库，可以按路径重新扫描登记：

1. 确认「设置」里的本地存储路径指向那个装着漫画的文件夹；
2. 「本地」→「导入」→「恢复本地下载」；
3. 应用扫描当前路径重建条目 —— **不复制文件、不加收藏**，同标题 / 同目录的重复项会自动跳过。

这是纯本地操作，不会联网。详细的报错处理在[常见问题排查.md](常见问题排查.md)。

## 四、阅读时你能调什么

本地与在线漫画共用同一个阅读器，常用设置：

- **翻页方式**：滚动 / 点击翻页 / 仿真翻页等模式，按习惯选；
- **画面缩放**：支持缩放与双击放大，1.6.3 版本还增强了缩放逻辑、修掉了图片加载时滑动手势误触发返回的问题（该版本更新说明）；
- **外观**：背景色、亮度这类护眼项在阅读器设置里调，晚上看建议直接切深色背景；
- **离线下载**：在线源的详情页有下载按钮，勾选章节即可离线保存；已下载的内容会进本地列表，管理方式与本篇导入的一致。

想把「收藏、历史、多文件夹整理」这些用法也摸熟，配着[漫画源添加与管理.md](漫画源添加与管理.md)一起看 —— 收藏分组对本地与在线条目都生效。
