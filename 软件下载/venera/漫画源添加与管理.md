## 一、先理解「空壳 + 源脚本」这个设计

Venera 本体不内置、也不抓取任何漫画网站内容。你在里面看到的在线漫画，全部来自一个个**漫画源** —— 一个几十到几百 KB 的 `.js` 脚本，里面写清了某个漫画站的接口怎么调、页面怎么解析。加一个源，软件就多一个能搜、能翻的站；源坏了（改版、换域名），那个站就打不开，但不影响软件本身，换一个新脚本即可。

这个设计对读者的实际意义：

- 装完是空的，不是 bug，是刻意的 —— 见[下载与安装教程.md](下载与安装教程.md)；
- 源失效很常见，**排查办法在**[常见问题排查.md](常见问题排查.md)，本篇只讲「怎么加、怎么管」。

## 二、加载官方源列表（推荐先做这一步）

Venera 官方维护了一个源列表仓库（[github.com/venera-app/venera-configs](https://github.com/venera-app/venera-configs)），里面有几十个源脚本，按下面的步骤一次性加载：

1. 打开 Venera，主界面进入「漫画源」页面；
2. 点「漫画源列表」（首次进去列表是空的，正常）；
3. 在仓库地址栏填入官方源列表地址：

```text
https://cdn.jsdelivr.net/gh/venera-app/venera-configs@main/index.json
```

   这是官方仓库的 CDN 镜像地址（官方文档推荐的加载地址）；想直接连 GitHub 原仓库也可以用 [github.com/venera-app/venera-configs](https://github.com/venera-app/venera-configs) 的原始文件地址。
4. 点刷新 / 加载，列表会显示各个源的名称、版本与简介；
5. 勾选你要的源，点右侧添加。加完返回「发现」页，就能看到这些源的内容了。

**选源的实用建议**：不必全加。加得越多，聚合搜索越慢、也越容易撞上个别失效源拖累体验；先加两三个你常用、更新勤的，缺了再补。

## 三、用配置文件导入单个源

拿到别人分享的单个 `.js` 源文件时（从网页、群文件、网盘下载的都算）：

1. 把 `.js` 文件存到手机里；
2. 「漫画源」页 → 点「使用配置文件」；
3. 选中那个 `.js` 文件，导入成功后它会出现在源列表里。

两条注意：

- 文件必须是 `.js`，且是按 Venera 的源规范写的（官方仓库里 `_template_.js` 是模板，别人随口给的脚本未必兼容）；
- 同一个源重复导入会更新为新版本，不会变成两个。

## 四、更新与删除源

| 操作 | 位置 | 说明 |
| --- | --- | --- |
| 更新 | 漫画源列表 → 对应源 | 官方仓库的源会随上游脚本更新；显示新版本时点更新即可 |
| 删除 | 漫画源页 → 长按 / 管理项 | 移除后该站内容从发现与搜索中消失，书架里已收藏的条目会失去入口，删之前想一下 |
| 检查失效 | 漫画源列表 | 某个源的站打不开、图裂，先更新源，再按[常见问题排查.md](常见问题排查.md)处理 |

**源脚本的更新频率由社区决定**：官方 README 标注项目已停止维护，但源列表仓库 [venera-app/venera-configs](https://github.com/venera-app/venera-configs) 截至 2026-09 仍有提交（各源仍有修复与新增）。两边状态都以页面当时显示为准；如果哪天源列表也不更新了，按[常见问题排查.md](常见问题排查.md)里「项目停止维护后的应对」一节处理。

## 五、想写自己的源（选读）

Venera 的源用 JavaScript 写，官方文档在仓库的 `doc/comic_source.md`，模板与 API 定义在 [venera-app/venera-configs](https://github.com/venera-app/venera-configs) 的 `_template_.js` 与 `_venera_.js`。写好后既可以走第三节的「使用配置文件」自用，也可以给官方仓库提 PR 让所有人用上。这条路需要能读写 JS，普通使用者跳过即可，不影响前面所有功能。
