## 一、Venera 是什么

Venera 是一款开源的漫画阅读器（GitHub 项目地址 [github.com/venera-app/venera](https://github.com/venera-app/venera)），GPL-3.0 许可，用 Flutter 写成，同一套代码覆盖 Android、iOS、Windows、macOS、Linux 五个平台。它本身**不带任何漫画内容** —— 软件是个空壳，看在线漫画要靠自己添加「漫画源」（JavaScript 脚本），看本地漫画要自己导入文件。适合手里有本地漫画文件、或愿意折腾几个漫画源的人；装完什么都不配，主界面基本是空的，这不是安装坏了，见[漫画源添加与管理.md](漫画源添加与管理.md)。

本篇对应的信息以网盘里那份安装包为准：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.6.3 |
| 包名 | `com.github.wgh136.venera` |
| 大小 | 44.33M |
| MD5 | `f70a03ad336dbd8b35a0282ff09f7a4c` |
| 采集时间 | 2026-09-21 |

网盘里是安卓 APK。Venera 的 Windows / macOS / Linux 版本走 GitHub 的 [Releases 页面](https://github.com/venera-app/venera/releases)；安卓版也可以从 [F-Droid](https://f-droid.org/packages/com.github.wgh136.venera/) 装（F-Droid 上 1.6.2 版标注需要 Android 7.0 及以上，1.6.3 的系统要求以官方页面当时显示为准）。

## 二、拿安装包

1. 打开 [https://pan.quark.cn/s/7f0f4b8d28c3](https://pan.quark.cn/s/7f0f4b8d28c3)（Venera 安装文件资源，夸克网盘分享链接）；
2. 转存到你自己的网盘，或直接在浏览器 / 夸克 App 里下载；
3. 下完核对一下文件名，应为 `venera_v1.6.3.apk`，大小约 44.33M。

想换其他平台的包，去 [github.com/venera-app/venera/releases](https://github.com/venera-app/venera/releases) 选对应格式：Windows 有安装版 `.exe` 与便携版 `.zip`，macOS 是 `.dmg`，Linux 有 `.deb`。版本号会随时间变化，以页面当时显示为准。

## 三、安卓安装步骤

1. 把 `venera_v1.6.3.apk` 传到手机（数据线、网盘、微信文件传输均可）；
2. 点开文件开始安装。如果系统弹出「禁止安装未知来源应用」，点提示里的设置项，给当前安装来源（文件管理器或浏览器）打开「允许安装」，再退回继续；
3. 装完打开，首次启动会请求存储相关权限 —— 允许后才能导入本地漫画与下载章节，拒绝的话本地漫画与离线下载都用不了；
4. 进入主界面。此时界面里几乎没有内容，属正常状态。

**安装包校验（可选）**：介意包体完整性的，可比对 MD5 是否为 `f70a03ad336dbd8b35a0282ff09f7a4c`（Windows 可用 `certutil -hashfile venera_v1.6.3.apk MD5` 命令查看）。对不上说明下载不完整或不是这份包，重新下载。

## 四、装完先知道的几件事

- **主界面分两块**：本地漫画（自己导入的文件）与网络漫画（通过漫画源在线看）。两块都得自己喂内容。
- **想在线看**：下一步去[漫画源添加与管理.md](漫画源添加与管理.md)加源，否则搜索与发现页没有结果。
- **想看手里的文件**：去[本地漫画导入与阅读.md](本地漫画导入与阅读.md)，注意 Venera 对本地文件的目录结构和压缩包格式有明确要求，随便放的文件夹它不认。
- **项目状态**：官方仓库 README 标注「由于本人精力有限，此项目已停止维护，欢迎 fork」（截至 2026-09 的公开信息）。也就是说不会再有官方新版本，遇到问题的应对方式见[常见问题排查.md](常见问题排查.md)。
