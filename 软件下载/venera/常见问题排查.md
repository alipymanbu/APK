## 一、漫画源打不开 / 搜索没结果

按出现频率从高到低查：

| 现象 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| 发现页空、搜索无结果 | 有没有加过源 | 先按[漫画源添加与管理.md](漫画源添加与管理.md)第二节加载官方源列表 |
| 某一个源打不开、详情页报错 | 源是否已更新 | 漫画源列表里看有没有新版本，先更新源 |
| 更新后还是打不开 | 源所属站点是否改版/换域名 | 这类要等社区修脚本；去 [venera-app/venera-configs](https://github.com/venera-app/venera-configs) 看该源的提交记录与 issue，若已有修复就重新导入最新 `.js` |
| 所有源都打不开 | 网络本身 | 检查手机网络；部分站点对网络环境有要求（有用户反馈需要特殊网络环境才能访问，属站点侧限制，与 Venera 无关） |
| 提示登录失效 / 无法评论评分 | 源的账号功能 | 源支持登录才可用；退出重登，仍失效则是站点接口变动，等源更新 |
| 发现页少了某个源的整个分页 | 刚删过源 | 删源会连带清掉它带来的发现页 / 分类页，不是丢数据 —— 重新添加该源即恢复（见[漫画源添加与管理.md](漫画源添加与管理.md)第四节） |
| 搜索只覆盖一部分源 | 搜索参与没全开 | 搜索只统计启用了搜索参与的源，逐个检查源的启用项（见[漫画源添加与管理.md](漫画源添加与管理.md)第四节） |

**判断口径**：只有单个源坏 = 等源更新；所有源都坏 = 查自己的网络。别一上来重装软件 —— 源数据不在安装包里，重装解决不了源的问题。

## 二、图片裂图 / 加载一半卡住

1. 先确认是**全部图裂**还是**个别章节裂**：全部裂 → 网络问题或源的图片 CDN 挂了，稍后重试或换源看同一部；
2. 个别章节裂 → 多半是该源该章节的图床问题，换源（同一个漫画往往多个源都有收录）是最实际的办法；
3. 本地漫画裂图 → 检查图片文件扩展名是否有效、文件是否损坏，按[本地漫画导入与阅读.md](本地漫画导入与阅读.md)的结构要求重排。

## 三、本地漫画导入不进去 / 章节顺序乱

对照这三条（全部出自官方 `doc/import_comic.md` 的硬性要求）：

- **结构不对**：目录里必须是「图片平铺」或「章节子文件夹」两种结构之一，多套一层（比如 `漫画/第1话/第1话/`）就不认；
- **格式不对**：压缩包只收 `.cbz` / `.cb7` / `.zip` / `.7z`，`.rar` 要先解压；
- **顺序乱**：页序按文件名字母序，文件名没有零填充（`1, 2, 10, 11` 会排成 `1, 10, 11, 2`）—— 把文件名编成 `01, 02, …` 再导入。

## 四、下载失败 / 下载好的漫画不见了

- **下载失败**：先看网络；再确认目标源能正常在线阅读（源本身坏了，下载也一样坏）。下载队列支持暂停 / 恢复，单个任务失败可单独重试；1.6.3 版本起「导入漫画」里还有恢复下载相关功能，中断后不必从零开始。
- **漫画不见了但文件还在**：数据库与文件分开存，文件夹还在就能救 —— 按[本地漫画导入与阅读.md](本地漫画导入与阅读.md)第三节「恢复本地下载」重建索引。
- **换了安装包版本**：只要本地存储路径没变、下载文件夹没删，恢复操作同样适用；路径变了就先在设置里把路径改回去再扫。

## 五、项目停止维护后的应对

官方仓库 README 写明「由于本人精力有限，此项目已停止维护，欢迎 fork」（截至 2026-09 的公开信息）。对你的实际影响与对策：

- **软件还能正常用**：阅读、导入、源加载都不依赖官方服务器，停更不影响存量功能；
- **不会有官方新版本**：遇到 bug 没人修，可去 [github.com/venera-app/venera](https://github.com/venera-app/venera/issues) 搜同类 issue，看社区 fork 有没有接续版本（以仓库当时状态为准）；
- **源比软件活得久**：漫画源列表仓库 [venera-app/venera-configs](https://github.com/venera-app/venera-configs) 截至 2026-09 仍在更新 —— 在线看漫画的可用性主要取决于源，不是软件本体；
- **保留好安装包**：官方不再发布新版后，现有安装包就是唯一可得版本，建议自己存一份 —— [Venera 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7f0f4b8d28c3)，其他渠道见[下载与安装教程.md](下载与安装教程.md)。

## 六、权限与存储问题

安卓版首次启动会要求存储权限。拒绝后：本地漫画列表读不到文件、章节下载存不进去。处理：系统设置 → 应用 → Venera → 权限，把存储（或「所有文件访问」）打开，重启应用。F-Droid 页面显示该应用会请求网络、外部存储读写与生物识别（指纹）权限 —— 指纹用于锁应用这类功能，不需要可以不给。

## 七、功能异常时先确认装的是正版

网上能搜到多个自称「Venera」的安卓包，其中部分包名是 `com.gyxy.veneralhg`（厂商标注也不同），**不是开源项目 [venera-app/venera](https://github.com/venera-app/venera) 的产物**。仿冒包的问题在于：漫画源、数据格式与正版不通用，在里面遇到的「源加不上」「数据打不开」可能是包本身的问题，怎么排查都没用。

装的是不是正版，核对一次就够：系统设置 → 应用 → Venera → 应用信息里看包名，正版是 `com.github.wgh136.venera`。对不上的处理与正版渠道汇总在[下载与安装教程.md](下载与安装教程.md)第四节。
