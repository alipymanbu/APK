## 一、先弄清三张表的区别

打开 SetEdit，你会先在几张表之间选择。安卓把系统设置存在一个数据库里，拆成了三张权限等级不同的表：

| 表 | 内容 | 能不能直接改 |
| --- | --- | --- |
| SYSTEM | 系统层的基础设置，比如屏幕亮度、刷新率、字体缩放 | 能，装完就能改 |
| SECURE | 涉及安全与用户隐私相关的设置 | 默认禁止，需要 ADB 授权 |
| GLOBAL | 影响整台设备全局行为的设置（如飞行模式、ADB 开关） | 默认禁止，需要 ADB 授权 |

授权方法见 [下载与安装教程.md](下载与安装教程.md) 第五节。没授权时点进 SECURE 或 GLOBAL 只能看不能改。

## 二、找到一个键值：先搜再改

三张表里动辄几百上千条键值对，一屏一屏翻不现实。两个定位办法：

1. **表内搜索**：每张表顶部有搜索框（2.1 版起支持），输入关键词即可过滤，比如搜 `refresh` 就能看到刷新率相关的所有键；
2. **知道确切键名时直接搜全名**，比如 `peak_refresh_rate`，一步到位。

同一个键名有时会同时出现在 SYSTEM 和 GLOBAL 两张表里，值还不一样。改之前注意顶部选中的是哪张表——改错表是「改了没生效」的常见原因之一。

## 三、改一个已有的键

1. 在列表里点一下目标条目，会弹出编辑窗口；
2. 选「Edit value」，输入新值，保存；
3. 部分改动立即生效，也有一部分要重启手机或重新进入相关界面才生效——改完没反应先别急着下结论，重启一次再看。

改值之前把原值抄下来（截图或记在本子上都行）。这是整个 SetEdit 使用流程里最重要的一步，出问题时你只有靠原值才能改回去，具体恢复路径见 [改坏了怎么恢复.md](改坏了怎么恢复.md)。

## 四、新增一个键

有些效果需要「新建」一个系统里本来不存在的键：

1. 点右下角的加号；
2. 输入键名和值；
3. 保存后新条目会出现在列表最上方。

键名必须和你的系统认识的名字完全一致，多一个字母、少一个下划线都不会生效。社区流传的键值清单见 [常用键值与场景.md](常用键值与场景.md)，但键名是否存在于你的设备上，以搜出来的结果为准——不同品牌、不同系统的键名集合差别很大。

## 五、删除一个键

点开条目后有删除选项。注意区分两种情况：

- 删**你自己加的键**：没问题，随时可以再加回来；
- 删**系统原有的键**：后果取决于系统和这条键的用途，可能某项功能就此异常。所以系统原有键优先用「改值」而不是「删除」，除非你明确知道删除是正确做法。

## 六、3.0 版新增的两个功能

网盘里这份 3.0 版（对应官方 v3.0-rc01）比 2.x 多了两个实用入口：

- **重启后修改设置**：有一部分键会在系统开机时被重新写回默认值，改了白改。这个选项让应用在你重启后再把值写进去，专治「重启后被重置」这类键；
- **创建快捷方式**：给某个键值操作建一个桌面快捷方式，下次不用翻进应用再找，点快捷方式直接改。

有 root 的设备还有一条路：应用会自动用 root 授权并修改，省掉 ADB 步骤，还支持通过 Magisk 的 `resetprop` 修改系统属性——这属于进阶用法，普通设备用不上。

## 七、改坏了先别慌

改完发现应用闪退、界面异常或某个功能失灵，先按 [改坏了怎么恢复.md](改坏了怎么恢复.md) 里的步骤把值改回原值。绝大多数问题在回退之后就会消失，这也是为什么第三节的「记录原值」值得多花一分钟。
