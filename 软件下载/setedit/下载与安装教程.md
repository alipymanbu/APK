## 一、先核对你要装的版本

SetEdit 是安卓系统设置数据库的编辑器，可以查看和修改 SYSTEM、SECURE、GLOBAL 三张表里的键值对。它是开源应用（GPL-3.0 协议），作者为 Muntashir Al-Islam，官方源码发布在 [GitHub](https://github.com/MuntashirAkon/SetEdit)。

网盘里这份安装包的版本信息如下，装之前可以先核对一下：

| 项目 | 值 |
| --- | --- |
| 应用名 | SetEdit（Settings Database Editor） |
| 版本 | 3.0（官方发布序列对应标签 v3.0-rc01） |
| 包名 | io.github.muntashirakon.setedit |
| 大小 | 1.80 MB |
| MD5 | 3330D4EEB15A199033BEA5630D59253B |

版本号、包名与体积以这份本地信息为准；官方后续若发布新版本，以官方发布页当时显示为准。

## 二、下载安装包

从 [SetEdit 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d2b6485c8c15) 转存后下载 APK 文件到手机。下载完成后建议先核对一下文件大小是否在 1.80 MB 上下，明显偏小通常说明没下完整。

## 三、常规安装步骤

1. 在手机上点开下载好的 APK 文件；
2. 系统会提示「是否允许安装」，确认后等待安装完成；
3. 如果手机开了「纯净模式」或「禁止安装未知来源应用」，按提示临时允许本次安装即可。

安装本身不需要 root，普通用户权限即可完成（Android 14 及以上除外，见下一节）。

## 四、Android 14 及以上装不上怎么办

SetEdit 刻意把目标 API 停在较低级别——作者在官方说明里解释过：从 Android 6.0 开始，新系统不允许低权限应用直接修改部分设置项，停在这个级别是为了让应用在没有 root 和 ADB 的情况下也能改得动 SYSTEM 表。

副作用是：Android 14 起系统禁止直接安装目标 API 过低的应用，双击 APK 会安装失败。官方给的解决办法是用 ADB 安装：

```powershell
adb install --bypass-low-target-sdk-block SetEdit.apk
```

设备已 root 的话，也可以在 root shell 里执行：

```shell
pm install --bypass-low-target-sdk-block SetEdit.apk
```

两条命令里的 `SetEdit.apk` 换成你实际的文件名或路径。手机端没开 USB 调试的话，先到「设置 → 关于手机」连点版本号打开开发者选项，再开「USB 调试」。

一个高频坑：从网页复制命令时，`--bypass` 前面是**两个连续的半角连字符**。有些页面或输入法会把它转成中文破折号「——」或只剩一个横线，命令就会报「找不到 install 命令」之类的错。报错先数一下横线数量。

## 五、装完先授权：不改 SECURE 和 GLOBAL 就等于白装

安卓默认禁止普通应用修改 SECURE 和 GLOBAL 两张表（SYSTEM 表可以直接改）。这两张表恰恰藏着最多值得调的键，所以装完后建议立刻用 ADB 授权一次，手机连电脑后执行：

```shell
pm grant io.github.muntashirakon.setedit android.permission.WRITE_SECURE_SETTINGS
```

（在 `adb shell` 里执行，或者直接把整条 `adb shell pm grant ...` 贴在电脑命令行里跑。命令报 SecurityException 的话，别反复重试，直接跳 [授权失败怎么解决.md](授权失败怎么解决.md)。）

两点补充：

- 只想浏览键值、不改东西的话，可以不授权——查看功能不依赖这个权限；
- 不确定命令输对没有时，应用内也有提示：点进 SECURE 或 GLOBAL 表时，应用会弹出说明和同一条授权命令，可以直接从弹窗里复制。

## 六、有 root 设备的情况

从 3.0 版开始，root 设备上的体验简单了很多：应用会自动用 root 授权所需权限，不再需要手动敲上面的 `pm grant` 命令；也可以直接用 root 权限改设置。也就是说，同一份 APK，root 设备装完打开就能改全部三张表。

## 七、装完之后

装好并授权后，打开应用选一张表就能开始改键值了，具体操作见 [怎么用.md](怎么用.md)。改之前建议先看一眼 [改坏了怎么恢复.md](改坏了怎么恢复.md) 里「记录原值」那一段——这个应用改的是系统数据库，手抖的代价比普通应用高。
