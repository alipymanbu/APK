# Widgetsmith 怎么添加到桌面

> 本篇讲把 Widgetsmith 的小组件放上手机桌面的完整流程：先在应用里挑样式，再通过桌面的小组件列表放置，以及放置后的替换、挪动和移除。

## 一、先装好应用

添加组件的前提是手机上已经装好 Widgetsmith。还没装的先看 [下载与安装教程.md](下载与安装教程.md)，装好再回到本篇。

## 二、在应用里挑好样式

1. 打开 Widgetsmith，确认顶部停在「小组件」标签；
2. 通过分类标签（时钟组件、倒数日、唯美文字、节日、累计日）或搜索找到想要的样式；
3. 点开样式看预览，确认后用页面上的「+ 添加小号组件」这类按钮，把它登记为要用的组件（按钮上标的是组件尺寸，中号、大号对应各自的按钮）。

这一步做完，组件就挂在这个应用名下了，接下来只需要把它摆到桌面上。应用左上角还有一个视频按钮，里面是添加步骤的演示，卡在哪一步可以点开对照。

## 三、把组件摆上桌面

1. 在桌面空白处长按，直到出现编辑菜单；
2. 点「小组件」「窗口小工具」或「添加工具」（不同品牌叫法不一样）；
3. 在列表里找到 Widgetsmith，会看到小、中、大几种尺寸可选；
4. 按住想要的尺寸，拖到桌面的目标位置松手；
5. 组件放到桌面后如果让你选样式，选刚才在应用里登记的那个。

常见桌面的入口差异：

| 桌面 | 长按空白后找的入口 |
| --- | --- |
| 小米（MIUI / 澎湃 OS） | 添加工具 |
| 华为 / 荣耀 | 窗口小工具 |
| OPPO / 一加 | 小组件（或叫「插件」） |
| vivo | 原子组件（或叫「小组件」） |
| 原生安卓（Pixel 一类） | Widgets |

系统版本不同菜单名称会调整，找不到就在桌面编辑模式里翻一遍带「小组件 / 小工具 / 插件 / Widgets」字样的选项。

## 四、放置之后怎么改

- **换样式**：长按桌面上的组件，进编辑或更换样式，再挑应用里登记好的另一个样式；
- **挪位置**：长按组件直接拖动；
- **删掉**：长按拖到「移除 / 删除」，这只是从桌面拿掉，不影响应用里已经登记的样式。

加完发现组件不刷新、显示旧数据，处理办法见 [常见问题与刷新排查.md](常见问题与刷新排查.md)；想顺便给桌面配一张动态壁纸，看 [动态壁纸怎么设置.md](动态壁纸怎么设置.md)；组件里能改哪些内容，见 [小组件样式怎么改.md](小组件样式怎么改.md)。
