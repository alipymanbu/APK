## 一、这份安装包的基本信息

Widgetsmith 是一款安卓桌面小组件与动态壁纸应用，用来在手机桌面上放时钟、倒数日、唯美文字、节日、累计日等装饰组件，应用内还带一个动态壁纸区。网上能搜到的版本更新很快，下面这些信息以网盘里这一份安装包为准：

| 项目 | 信息 |

| 版本 | 20241111（按日期命名的版本号） |
| 包名 | com.assmart.widget |
| 大小 | 25.59M |
| MD5 | 8F4CC5B4193756089B4137EA0B73E1AF |
| 系统要求 | 安卓 5.2 以上 |
| 开发者 | 南京大智若愚网络科技有限公司 |

转存下载后如果装不上或提示文件异常，先核对一下文件大小是否与上表一致，不一致多半是下载不完整，重新下载一次再装。

## 二、从网盘拿到安装包

安装文件放在夸克网盘里，需要先转存到自己网盘再下载：

1. 打开 [Widgetsmith 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8662531aec33)；
2. 选择转存到自己的夸克网盘（未登录会先要求登录，没有夸克账号需要先注册一个）；
3. 在自己网盘里找到转存的 APK 文件，下载到手机。

## 三、安装步骤

1. 在手机的文件管理里点开下载好的 APK；
2. 首次安装会提示「不允许安装未知应用」，按提示跳到设置页，允许来源应用（文件管理器或浏览器）安装应用，返回后重试；
3. 等待安装完成，点「打开」。

不同品牌手机的提示文案有差别（小米、华为、OPPO、vivo 各有叫法），但都是安装时弹出那个设置页里打开一次开关，装完可以再关掉。

## 四、首次打开

- 打开后主界面有两个标签：**小组件** 和 **动态壁纸**，样式浏览主要在「小组件」页；
- 组件样式按「时钟组件 / 倒数日 / 唯美文字 / 节日 / 累计日」等分类排列，顶部可切换热门、最新或按分类翻；
- 天气、日历这类组件的数据靠系统权限支撑（位置、日历等），一般在你实际添加对应组件时才会请求，按需允许即可。

装好后的第一件事是把组件放上桌面，具体见 [怎么添加到桌面.md](怎么添加到桌面.md)；样式怎么挑怎么换，见 [小组件样式怎么改.md](小组件样式怎么改.md)。装完打不开或报错，直接翻 [常见问题与刷新排查.md](常见问题与刷新排查.md)。
