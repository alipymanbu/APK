## 一、样式从哪找

样式都在应用内的「小组件」标签里，按分类排列：

| 分类 | 适合做什么 |
| --- | --- |
| 时钟组件 | 桌面主时钟、翻页钟、指针钟这类时间显示 |
| 倒数日 | 距离某个日子还有多少天，比如考试、纪念日 |
| 唯美文字 | 放一句话、座右铭之类的纯文字组件 |
| 节日 | 节气、节日主题的应景组件 |
| 累计日 | 从某天起累计了多少天，比如在一起多少天、坚持多少天 |

页面上方有「热门 / 最新 / 分类」的切换和搜索框，想快点找到合适的样式，先翻热门是最省事的路子。

## 二、尺寸与数据

- 组件分小、中、大三档，对应桌面上不同的格子数，应用里的添加按钮会标明尺寸（比如「+ 添加小号组件」）；
- 组件的数据源包括时间、日期、天气、日历、步数、照片相册、自定义文本等，选的样式决定了显示哪几项；
- 天气、日历、步数这类数据需要对应权限，权限没给的话对应栏目会空白或停在旧数据，处理见 [常见问题与刷新排查.md](常见问题与刷新排查.md)。

## 三、能改什么

- 字体样式、颜色、背景色调这类外观项，在具体样式的编辑页里调整；
- 照片相册类组件可以选你自己的照片做背景；
- 部分组件支持点击动作：直接启动某个应用、发短信、播放音乐，适合把组件当快捷入口用。

能改到什么程度取决于具体样式，编辑页里没有的选项就是该样式不支持，换个样式再试就行。要是想要的改动超出了样式给的范围，「自己搭组件」的另一条路子更合适，两条路线的取舍见 [和KWGT怎么选.md](和KWGT怎么选.md)。

## 四、给不同时段换着用

可以给同一个桌面位置准备几个样式，按需要换着放：比如上班时间挂日历、下班换回时钟。要不要做定时自动切换，以应用内实际提供的功能为准；设置完成后留意组件是否按预期变化，发现不生效先看 [常见问题与刷新排查.md](常见问题与刷新排查.md)。

挑好样式还没放上桌面的，照 [怎么添加到桌面.md](怎么添加到桌面.md) 操作即可。
