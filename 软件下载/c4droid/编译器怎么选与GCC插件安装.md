## 一、三个编译器的分工

打开「三点菜单 → 设置 → 选择编译器」，你会看到 TCC、GCC、G++ 三个选项。选错是编译报错最常见的原因，按下表对号入座：

| 选项 | 装没装插件 | 适合写什么 | 注意 |
| --- | --- | --- | --- |
| TCC | 内置，无需插件 | 纯 C 小程序、练习题 | 出 `Illegal instruction` 就换 GCC |
| GCC | 需要 GCC 插件 | C 程序、Makefile 项目 | 写 C 用它，不要选 G++ |
| G++ | 需要 GCC 插件 | C++ 程序、Qt/SDL 图形程序 | C++ 的头文件写法有讲究，见第三节 |

判断口诀：**写 C 选 GCC，写 C++ 或图形程序选 G++，快速跑个 C 片段用 TCC。**

## 二、手动安装 C++ 支持

首次启动应用会主动提示装 C++ 支持，跟着提示走即可；没提示或当时跳过了，按下面手动补：

1. 确保手机有 **100MB 以上的可用内部存储**（不够会导致安装失败或启动闪退）；
2. 安装 **GCC plugin for C4droid**（同一开发者的独立插件应用，免费）。注意顺序：先有 C4droid 本体，插件才能装上；
3. 打开该插件，按提示把编译器**安装到内部存储**；
4. 回到 C4droid：设置 → 选择编译器 → 选 **G++**；
5. 回编辑器写代码，编译。

GCC 插件里打包的 GCC 版本：官方 8.01 的更新日志写的是「将 GCC 更新到 10.2」，你在插件里看到的版本号应与之相符，对不上说明插件不是这一套（以插件内实际显示为准）。

插件装好但编译时仍报 `arm-linux-androideabi-g++: not found`、或应用反复提示「插件需要更新」，按 [常见报错与解决方法.md](常见报错与解决方法.md) 的「插件相关报错」一节处理。

## 三、写 C++ 的两个语法点

装好插件只是第一步，代码写法也要对：

```cpp
#include <iostream>        // 不要写成 iostream.h
using namespace std;       // 放在 int main 之前

int main() {
    cout << "hello" << endl;
    return 0;
}
```

- 用 `#include <iostream>`，**不要**用老式写法 `iostream.h` —— 后者会报头文件找不到；
- 加 `using namespace std;`，否则 `cout`、`endl` 会报未声明。

这两个点是最常见的「装了插件还是编不过」的原因，报 `iostream` 相关错误先回这节核对。

## 四、C 与 C++ 之外的选项

- **调试器**：断点、变量观察，装了 GCC 插件后可用，用法见 [运行代码与编辑器操作.md](运行代码与编辑器操作.md)；
- **Git 集成**：设置里可关联仓库，日常写练习用不到，不展开；
- **图形程序**（Qt/SDL/SDL2）：除了 G++ 还要装 SDL 插件，识别规则单独写在 [SDL与Qt图形程序编译.md](SDL与Qt图形程序编译.md)。

## 五、换编译器后的验证

换完选项别急着写大程序，先编译一段最小代码验证：

```c
#include <stdio.h>
int main() {
    printf("ok\n");
    return 0;
}
```

能输出 `ok` 说明当前编译器就绪；报错就带着错误信息去 [常见报错与解决方法.md](常见报错与解决方法.md) 查对应条目。
