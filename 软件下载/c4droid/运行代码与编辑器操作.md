## 一、跑通第一个程序

1. 打开应用，点新建得到一个空白文件；C 程序从 `#include <stdio.h>` 和 `int main` 写起；
2. 写完先保存：按 Ctrl+S，或长按保存按钮选「另存为」；
3. 点**编译**按钮；有外接键盘就按 Ctrl+B；
4. 编译没报错后点**运行**（Ctrl+R），程序输出显示在内置终端里；
5. 要改代码，回编辑器改完再编译一次，循环这个过程。

普通 C 程序用默认的 TCC 编译器就能跑通。如果编译时报 `Illegal instruction` 或你写的是 C++，要先换编译器，步骤见 [编译器怎么选与GCC插件安装.md](编译器怎么选与GCC插件安装.md)。

## 二、菜单里有什么

主界面右上角的三点菜单里，你会用到这几项：

- **设置** —— 选择编译器（TCC / GCC / G++）、主题、界面布局等都在这里；
- **补全 / 查找 / 跳转到行** —— 编辑辅助，对应快捷键见下表；
- **导出** —— 把编译结果导出为可执行文件或 APK；
- **安装 GCC**（部分版本叫「插件」）—— 补装编译器插件的入口。

## 三、快捷键速查

用外接键盘（蓝牙键盘最方便）时这些键直接可用；纯触屏就用长按操作那张表。

| 快捷键 | 作用 |
| --- | --- |
| Ctrl+B | 编译 |
| Ctrl+R | 运行 |
| Ctrl+S / Ctrl+O | 保存 / 打开 |
| Ctrl+C / Ctrl+V / Ctrl+X | 复制 / 粘贴 / 剪切 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+F | 查找 |
| Ctrl+L | 跳转到指定行 |
| Ctrl+A | 全选 |
| Ctrl+D（或 Ctrl+Space） | 自动补全；Ctrl+Space 可能被安卓系统占用 |
| Ctrl+X（终端内） | 关闭终端（8.01 版新增） |

## 四、长按操作速查

不接键盘时，长按工具栏按钮有额外功能：

| 长按对象 | 效果 |
| --- | --- |
| 新建按钮 | 删除当前文件 |
| 保存按钮 | 另存为 |
| 打开按钮 | 最近的文件 |
| 编译按钮 | 配置当前目录（多文件 / Makefile 项目用，见 [SDL与Qt图形程序编译.md](SDL与Qt图形程序编译.md)） |
| 运行按钮 | 带参数运行 |
| 标签页 | 关闭该标签 |

## 五、触屏上没有 Ctrl 键怎么办

手机软键盘没有 Ctrl，上面那张快捷键表看着就用不上了 —— 实际影响比看起来小：

- **编译、运行、保存都有对应的按钮和长按操作**（第三节、第四节两张表覆盖了同样的动作），日常写代码不需要 Ctrl；
- **要顺手的快捷键就接一个外接键盘**：蓝牙键盘直接配对，有线键盘通过转接头连，接上后 Ctrl+B、Ctrl+R 全部可用；
- 另有用户反馈用系统的按键映射类工具把音量键模拟成 Ctrl（单一来源，未验证；且这类工具在中文输入法下多半不生效）—— 不折腾也完全够用。

## 六、代码文件存哪、怎么打开

- 写完及时保存（Ctrl+S 或长按保存按钮选「另存为」）；**重要代码别只留在应用里** —— 长按「打开」按钮能看到最近文件，换设备或重装应用后它们不一定还在；
- 想集中管理：在手机存储根目录建一个专门的文件夹（多个教程都建议这么做），保存时选到那里，之后找 `.c` 文件都从这里进；
- 从文件管理器或其他位置打开文件时，系统会弹存储权限请求，按提示允许即可；
- 编译出来的可执行文件不在代码文件夹里（在应用的内部存储，见第七节），别在文件夹里找它。

## 七、编译结果去哪了

编译产物默认落在应用的内部存储中，终端程序的输出则直接显示在内置终端里。想把产物拿出来（分享给别人、装到别的手机），走菜单里的**导出**：命令行程序导出为可执行文件，带界面的程序导出为 APK。有教程提到导出的文件名用英文更稳妥，避免部分环境下的兼容问题。

## 八、断点调试

编辑器支持断点与变量观察，步骤是：

1. 先在系统设置 → 应用权限里给 C4droid 开启**悬浮窗权限**（部分机型不开就出不来调试窗口；多篇教程的第 1 步都是它）；
2. 点某一行的行号，该行标红即下好断点；
3. 点运行，程序停在断点处，出现提示窗口即进入调试状态。

调试只对需要单步排查的程序用，日常写练习题用不到。

## 九、界面不顺手怎么调

设置里可以换主题、移动标签和按钮的位置（官方称之为可定制界面），把编译/运行按钮挪到顺手的地方。改完布局后所有长按操作仍然有效，只是位置变了。
