## 一、C4droid 是什么

C4droid 是安卓平台上的 C / C++ 编译器加集成开发环境：你直接在手机上写代码，点编译、点运行，编译与运行都在本机完成。官方商店页的写法是 "C4droid - C/C++ compiler & IDE"，开发者为 n0n3m4，官方渠道是 [play.google.com](https://play.google.com/store/apps/details?id=com.n0n3m4.droidc)。本篇只讲「怎么把它装到手机上并跑起来」。

## 二、这一版的基本信息

下表是手头这个安装包的事实，装之前可以先核对：

| 项目 | 值 |
| --- | --- |
| 版本号 | 8.01 |
| 包名 | `com.n0n3m4.droidc` |
| 安装包大小 | 53.22M |
| MD5 | `F6C9F6941593F2CF73B57B2E30896E60` |
| 界面语言 | 中文 |
| 系统要求 | 安卓 5.2 以上（以安装时的提示为准） |

需要核对 MD5 时，用任意文件校验工具算一遍，和上表一致再安装，避免下到一半损坏的包。

## 三、下载与安装步骤

1. 打开 [C4droid 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3ea1c3bf1552)，转存后下载安装包到手机；
2. 安装前先看一眼文件大小是否接近 53.22M，差别大就重新下载；
3. 点击安装包安装。系统若提示「不允许安装未知来源应用」，在弹出的设置里允许本次安装即可；
4. 装完首次启动会自动解压一次，等它跑完再操作。

如果手机里装过旧版 C4droid（或其他汉化版本），安装时可能弹签名冲突提示 —— 这是新旧包签名不一致导致的，处理办法见 [常见报错与解决方法.md](常见报错与解决方法.md) 里的「安装时提示签名冲突」一节。

## 四、首次启动会发生什么

- 启动后应用会提示你安装 C++ 支持（即 GCC 插件）。这一步可以先跳过：默认的 TCC 编译器写普通 C 程序够用，之后想写 C++ 再按 [编译器怎么选与GCC插件安装.md](编译器怎么选与GCC插件安装.md) 补装。
- 应用的编译、运行都在本机完成，不需要联网；官方说明里编译器是离线工作的。
- 装完后你看到的主界面就是代码编辑器，写代码的流程见 [运行代码与编辑器操作.md](运行代码与编辑器操作.md)。

## 五、插件是怎么回事

C4droid 本体之外还有两个独立的插件应用，都是按需装：

| 插件 | 作用 | 什么时候需要 |
| --- | --- | --- |
| GCC plugin for C4droid | 提供 GCC / G++ 编译器 | 写 C++、要用 Qt/SDL 图形程序、遇到 TCC 的 Illegal instruction 报错 |
| SDL plugin for C4droid | 提供 SDL / SDL2 图形库 | 要编译带画面的程序 |

安装顺序有讲究：**先装 C4droid 本体，再装插件**，顺序反了插件找不到主程序。插件与本体必须来自同一套签名，混装两套不同来源的包会互相冲突 —— 出现这种情况就把本体和插件全部卸载，重新按顺序装一遍。

顺带说明：关于插件和本体谁先装，公开教程里有两种说法 —— 一种是上面的「先本体后插件」，另一种是「先装插件、再装本体」（据称本体首次启动会自动把插件数据解压进去，插件装完桌面不显示图标也属正常）。两种说法都有人实践过；无论按哪种装，装完后插件不生效就按 [常见报错与解决方法.md](常见报错与解决方法.md) 的「插件相关报错」一节排查。

## 六、注意事项

- 官方说明该应用只支持 ARM 处理器的设备；如今主流手机都是 ARM，一般碰不到这条限制。
- 编译出来的程序默认放在应用自己的内部存储里（早期官方文档给的路径是 `/data/data/com.n0n3m4.droidc/files/temp`，以实际版本为准），想把可执行文件或 APK 拿出来用应用内的「导出」功能，见 [运行代码与编辑器操作.md](运行代码与编辑器操作.md)。
- 版本会随时间更新，本篇描述的是 8.01 这一版；以官方页面当时显示为准。
