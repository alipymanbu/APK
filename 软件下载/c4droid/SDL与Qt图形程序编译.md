## 一、先满足两个前提

编译图形程序前，这两项必须到位：

1. 编译器选 **G++**（设置 → 选择编译器），见 [编译器怎么选与GCC插件安装.md](编译器怎么选与GCC插件安装.md)；
2. 安装 **SDL plugin for C4droid**，装法与 GCC 插件相同（先本体后插件）。

8.01 版的更新说明里有一条「Qt 不再需要任何第三方应用程序」，即 Qt 程序现在只靠本体加 GCC 插件就能编。

## 二、应用怎么知道你要编图形程序

C4droid 靠扫描源码里的头文件包含串来判断编译模式：

| 你写的包含语句 | 识别为 |
| --- | --- |
| `#include "SDL.h"` | SDL |
| `#include "SDL2/SDL.h"` | SDL2 |
| `#include "android_native_app_glue.h"` | NativeActivity |
| Qt 头文件（如 `QApplication`） | Qt |

由此得出两条实用规则：

- **别把识别用的 include 注释掉** —— 官方明确说注释掉这些行不会改变识别结果，反而编译时缺头文件；
- 单文件 Qt 程序要在源码**末尾**再加一行 `#include "你的文件名.moc"`，用 `.pro` 文件编译时不需要这一步。

## 三、多文件与 Makefile 项目

项目不止一个源文件、或目录里有 Makefile 时：

1. 打开该目录下的任意一个源文件；
2. **长按编译按钮**（按钮被隐藏/移动时走「编译设置」），进入当前目录的配置；
3. 选好编译模式；有的模式（如 makefile）要求填**结果可执行文件名**，别漏填；
4. 点确定 —— C4droid 会在该目录生成 `.c4droid` 配置文件保存这份设置；
5. 之后照常点编译、运行，应用会按项目方式构建。

这份 `.c4droid` 文件跟着目录走，换文件打开同一目录不用重新配。配置没点确定就退出，改动会被丢弃，这是「配了好几次都没生效」的常见原因。

## 四、移植现成的开源库

官方列过移植方法：与常规 Makefile 构建基本相同，多数库要做少量修补。已测试过的库有 `gmp`（只能放内部存储）、`mpfr`、`mpc`、`libxml2`、`neon`、`sqlite`、`SDL_gfx`（需 `--disable-mmx`）。移植涉及交叉编译的细节，官方之外的资料真假混杂，遇到具体报错优先对照 [常见报错与解决方法.md](常见报错与解决方法.md)，没有把握的写法不要照搬论坛结论。

## 五、程序在手机上跑起来

编译出的带界面程序可以直接在本机运行；要安装到别的设备，用菜单里的**导出**生成 APK。终端类程序导出的是可执行文件，拷给别人后需要在类 shell 环境里执行。导出相关操作见 [运行代码与编辑器操作.md](运行代码与编辑器操作.md) 第七节。
