## 一、先核对安装包信息

这份安卓安装包的关键参数如下，装之前对一眼，装完也可以在「设置 → 应用管理」里核对包名：

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.6.2 |
| 包名 | `com.noventure.minishorts` |
| 大小 | 40.86M（42,843,591 字节） |
| MD5 | `870FCAF6C15DC49C6C39721AC76BEED0` |
| 系统要求 | 安卓系统 5.2 以上 |
| 信息记录时间 | 2026-09-23 |

开发者是 NOVENTURE PTE. LTD.。另外注意：**安卓端和 iOS 端是两条独立的版本线** —— App Store 里 iOS 端的版本号（如 1.15.0，以商店页面当时显示为准）和这份安卓包的 1.6.2 不是一回事，版本号不同不代表安装包过期。

## 二、从网盘拿到安装包

1. 打开 [MiniShorts 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bf93f5998f0a)，先把文件夹转存到自己的网盘，再从自己的网盘下载；
2. 手机上用夸克 App 或手机浏览器打开上面的链接，直接下载也行；
3. 文件夹里的安装包文件名是 `minishorts_v1.6.2.apk`，另有一个说明 txt，一并留着即可。

下载是否完整，看文件大小是否接近 40.86M —— 差得多说明没下完，别急着装（处理办法见 [闪退打不开怎么排查.md](闪退打不开怎么排查.md)）。

## 三、手机上安装的步骤

1. 点击下载好的 `.apk` 文件开始安装；
2. 首次从浏览器或文件管理器安装，系统会拦一道「禁止安装未知应用」—— 按提示进入该来源的授权开关，允许后再返回继续安装；
3. 安装完成后打开，**应用的内容是在线加载的，打开时需要联网**；
4. 想确认装的是不是同一个应用：设置 → 应用管理 → 找到 MiniShorts → 查看包名，应为 `com.noventure.minishorts`。

## 四、装不上时先看这三条

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | 安装包没下完整 | 删掉重下，回到第二步 |
| 「与系统版本不兼容」类提示 | 手机系统低于安卓 5.2 | 看 [闪退打不开怎么排查.md](闪退打不开怎么排查.md) 的系统一节 |
| 点了没反应 / 一直转圈 | 安装器卡住 | 关掉后台再点一次安装包；仍不行就重启手机再装 |

## 五、校验安装包完整性（可选）

对完整性有要求的话，在安装包所在目录打开 PowerShell，运行：

```powershell
certutil -hashfile minishorts_v1.6.2.apk MD5
```

输出的 MD5 与表格里的 `870FCAF6C15DC49C6C39721AC76BEED0` 一致，说明文件从下载到传输没有损坏。
