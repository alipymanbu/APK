# 语音输入与拍照提问怎么用

> 讲手机上最常用的几类操作：打字聊天、拍照给 Claude 看、用嘴代替打字的两种方式（听写与语音模式）、桌面小组件，以及让它直接操作你手机里的其他应用。

## 一、打字聊天与传附件

对话框里直接输入问题发送即可。输入框旁的附件按钮可以把文件、图片传进对话，让 Claude 帮你读文档、分析表格、解释截图里的内容。对话列表里长按某条对话可以改名或删除，找历史对话从首页往下翻。

## 二、拍照与图片提问

输入框点图片/相机按钮，两种用法：

- **现拍**：对准要问的东西（外文菜单、仪器面板、手写笔记），拍完直接发。
- **相册选图**：把已经存在的截图或照片传进去。

配上具体的问题效果好于只发图，比如「把这张菜单翻译成中文并推荐不辣的」比单发一张图有用。

## 三、听写（语音转文字）

输入框右侧的麦克风图标是**听写**：你说的话转成文字填进输入框，你检查后点发送，Claude 以文字回复。

首次使用会让你选语音输入语言。改语言的位置：右上角头像 > Speech Input Language。

**关键限制：听写支持的语言列表里没有中文。** 目前支持的是英语、法语、德语、印地语、意大利语、日语、韩语、葡萄牙语、俄语、西班牙语、土耳其语、乌克兰语。你想用中文输入，老老实实打字；想对着它说英语，听写可以用。

官方说明语音转文字后不保留录音、不用于训练模型。

## 四、语音模式（连续对话）

输入框里麦克风旁边的**声波图标**是语音模式，与听写的区别是：这是真正的来回对话，你说完它开口答，不用看屏幕。所有套餐（含免费版）可用，目前是 beta 功能。

- **免提模式**：默认，你只管说，停顿时它接话。适合安静环境。
- **按键说话**：嘈杂环境在设置里切成按住说话、松开发送，抗干扰更稳。
- 对话中点左下角设置可以换音色与语速。
- 语音对话与文字对话可以无缝切换，上下文保留；语音用量同样计入套餐限额。
- 免费版也能用，但付费版可以在语音里用更强的模型、调用你连接的外部工具（邮件、日历等）。

一句话分清：**想「说给自己记下来、发给它处理」用听写；想「来回讨论一个问题」用语音模式。**

## 五、桌面小组件

长按桌面空白处 > 小组件 > 找到 Claude > 拖到桌面，可拖边调整大小。小组件上三个按钮：

| 按钮 | 作用 |
| --- | --- |
| 星形聊天按钮 | 直接开新对话 |
| 相机按钮 | 开新对话并立即调起相机拍图提问 |
| 麦克风按钮 | 开新对话并开始语音听写 |

小组件发起的操作同样计入你的套餐用量。

## 六、让它联动手机里的其他应用

聊天中你可以在对话里直接让 Claude 帮你操作手机上的常用应用（官方 2026 年加入的能力，所有套餐可用）：

| 你说 | 它做 |
| --- | --- |
| 「帮我起草一条短信给同事说会议推迟」 | 调起短信/WhatsApp/Slack 等并预填内容，你确认后发送 |
| 「写封邮件说明项目进展」 | 调起邮件应用并预填正文 |
| 「我明天有什么安排」「周四中午建个会」 | 读/写你的日历 |
| 「明早 7 点叫我」「定个 20 分钟计时器」 | 通过时钟应用设闹钟/计时器 |
| 「附近有哪些公园」 | 申请定位权限后在地图上展示并导航 |

几个边界要知道：提醒事项（Reminders）目前只在 iPhone 版有；它不能直接读你的通讯录；健康数据联动（走 Health Connect）仅限美国地区 Pro/Max 用户且要 Android 14+。第一次用某项联动会弹权限申请，允许对应权限才生效，之后在系统设置里随时可关。
