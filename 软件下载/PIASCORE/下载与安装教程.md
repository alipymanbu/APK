## 一、装之前先核对这几件事

本文口径对应下面这份安装包（版本、大小都以它为准；商店页面上标的其他版本号与这份不是同一个文件）：

| 项目 | 信息 |
| --- | --- |
| 应用名 | PIASCORE |
| 版本 | 2.2.6 |
| 包名 | com.syjxx.piano |
| 安装包大小 | 208.32M |
| MD5 | 62CBA08EB56675491BA17CF2B6305A13 |
| 开发者 | 深圳市坤焱科技有限公司 |

- 这是安卓应用（APK 文件），装在安卓手机或平板上。iPhone/iPad 装不了 APK，那边的同名应用走 App Store，是另一回事（区别见[常见问题与解决方法.md](常见问题与解决方法.md)的同名辨析一节）。
- 安装包 208.32M，装完再加上导入的乐谱缓存会更大，动手前手机至少留 1GB 可用空间。
- 系统要求按采集记录标注为安卓 5.2 及以上，实际以安装时系统弹出的提示为准。

## 二、获取安装文件资源

打开 PIASCORE 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/0549286bc6d7](https://pan.quark.cn/s/0549286bc6d7)。手机上有夸克网盘 App 的直接点开转存到自己的网盘，再把里面的 `PIASCORE_v2.2.6.apk` 下载到手机存储；下载完记一下所在目录，下一步要找它。

## 三、安装步骤（含「未知来源」授权）

1. 手机上还没有夸克网盘的，先在应用市场装一个，用它打开上面的分享链接，转存后把 APK 下载下来；
2. 打开手机「文件管理」，找到刚下载的 APK，点它；
3. 系统第一次会拦一下：提示「禁止安装未知应用」时，按提示去允许「文件管理」（或你用来下载的那个应用）安装未知应用，返回后继续；
4. 等安装进度走完，点「打开」。第一次启动会来要权限，给哪些看下一节。

## 四、首次启动会要哪些权限

按用途决定给不给，不给的功能到时候再补开也行：

| 权限 | 干什么用 | 建议 |
| --- | --- | --- |
| 存储（读/写） | 从相册导入乐谱、读取下载的 PDF | 建议给，不给没法导谱 |
| 网络 | 在线搜谱、IMSLP 与云盘取谱 | 用在线功能就要给 |
| 相机 | 把纸质乐谱拍进应用 | 不拍谱可以拒 |
| 麦克风 | 录音工具录自己的演奏 | 不录音可以拒 |

事后想改：系统「设置 → 应用 → PIASCORE → 权限」里逐项开关。

## 五、装不上、打不开怎么排查

- **点 APK 没反应，或提示「解析包错误」**：多半是没下完整，重新下载一次；不放心就校验 MD5——电脑上执行 `certutil -hashfile "PIASCORE_v2.2.6.apk" MD5`，结果与上面表格一致（字母不区分大小写）说明文件没坏；
- **提示「应用未安装」**：手机里已经装过别的渠道的同包名版本，签名对不上，先把旧的那个卸载再装；
- **提示存储空间不足**：清理出至少 500M 再装；
- **装完点了闪退**：先重启一次手机再试；还不行就按[常见问题与解决方法.md](常见问题与解决方法.md)里的症状接着查。
