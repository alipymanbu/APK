## 一张表看清四套方案

车机互联方案不止一种，它们干的都是同一件事——把手机屏幕投到车机上用。区别主要在「给谁用」：

| 方案 | 能用的手机 | 手机端通常叫什么 |
| --- | --- | --- |
| Apple CarPlay | iPhone | 系统自带，无需安装 |
| HUAWEI HiCar | 华为及鸿蒙系统手机 | HiCar 智行 |
| 百度 CarLife | 兼容面最广的安卓机 | CarLife+（需安装 app） |
| ICCOA Carlink | 小米、OPPO、vivo 系国产安卓（含一加、真我、iQOO、红米、魅族等） | CarWith / Car+车联 / 智能车载 |

你的手机是什么牌子，能用的方案基本就定了：iPhone 只有 CarPlay 一条路，华为走 HiCar，小米 / OPPO / vivo 系对应的正是 ICCOA Carlink。这也是为什么很多车主会关心它——国产安卓机保有量大，而 CarPlay 和 HiCar 都覆盖不到。

## 车里的多套方案是什么关系

一辆车往往同时内置好几套互联方案，车机应用中心的「手机互联」里会并列出现 CarPlay、HiCar、Carlink 几个图标。它们互不冲突，你的手机属于哪个阵营就点哪个图标，别的用不上也不用管。

有的车型在**同时存在多套方案、且还没连接任何手机**时，长按方向盘上的智能语音键会弹出方案选择页，让你点选要用哪一套（是否支持这个操作以你的车型为准）。

## Carlink 和手机里的 CarWith、Car+车联、智能车载是什么关系

这三者是同一套协议在各家手机上的**实现入口**，不是三个别的功能：

- 小米 / 红米：设置 → 更多连接 → **CarWith**；
- OPPO / 一加 / 真我：设置 → 连接与共享 → **Car+车联**（或智慧车联）；
- vivo / iQOO：设置 → 更多连接 → **智能车载**（或 Jovi InCar）。

也就是说，如果你的手机系统里已经有这些入口，连接支持 Carlink 的车机时用的是它，不需要再装独立 app。独立安装包（即本套文档附的那份）主要给两类情况：手机系统里没有内置车联入口的，以及车机端或使用场景明确要求装独立客户端的。

## 车机不支持 Carlink 怎么办

先看车机还支持哪几套：应用中心「手机互联」里有什么就用什么，手机端配对应的方案（iPhone 用 CarPlay，安卓普遍可以装 CarLife+）。都不支持的话，要么等厂商 OTA——不少车型是上市后通过系统升级才加入 Carlink 的（长城系 2024 年上半年就给 30 多款车型批量推送过），要么考虑后装互联盒这类硬件产品，是否兼容你的车型需要自行核实。
