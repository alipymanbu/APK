# ICCOA Carlink 连接失败怎么办

## 排查之前，先做一遍基础重置

大部分连接问题靠这一套动作解决，先做完再看下面的对症项：

1. 手机和车机的蓝牙、WiFi 开关**全部关掉再打开**；
2. 确认手机 WiFi 没有连着任何热点（车机热点也别连）；
3. 手机别开 VPN、代理类软件——有用户反馈开着就连不稳；
4. 把手机和车机上的**旧配对记录全部删掉**（手机端取消与车机的蓝牙配对、删掉 Carlink 连接记录，车机端忽略这台手机），然后按首次连接流程重新配对；
5. 检查车机系统有没有可升级的版本，升到最新再试。

## 对症排查

### 症状一：手机弹窗根本不出现

- 手机没亮屏解锁：进 PIN 码页面前手机要保持解锁亮屏，锁屏状态弹不出确认框；
- 车联开关被关了：小米去设置 → 更多连接 → CarWith → 连接与提示；OPPO 在设置 → 连接与共享 → 智慧车联；vivo 在设置 → 更多连接 → 智能车载；
- 手机离中控屏太远：靠近到半米以内；
- 一次只认一部手机：车机正连着别的手机时不会响应你，先按上一节断开并忽略当前设备。

### 症状二：PIN 码输完还是连不上

- 重做一遍「基础重置」，尤其是删除旧配对记录；
- 无线反复失败时改试**有线**：换一根确认能传数据的数据线（连电脑能传文件的那种），插车机前置 USB-A 口。

### 症状三：连上几秒就断，手机报 WLAN 错误

这是论坛里被吐槽最多的一种，多见于小米手机连接部分升级过车机的车型：

- 先删光手机和车机上的配对记录重新连，多数人这一步就好了；
- 关掉手机上的 VPN 和各类代理；
- 车内温度特别高时（夏天暴晒后），前几分钟容易断一次，等它自动重连，开一段空调后大多恢复稳定；
- 一直不行就是手机系统与车机版本不匹配，等两边的 OTA 更新，期间先用有线连接。

### 症状四：用着用着断线、反复重连

- 无线连接受干扰和温度影响，改用有线最直接；
- 检查手机是否开了省电模式把后台杀掉了：把 Carlink 加入省电白名单 / 自启动允许；
- 中途手动关过蓝牙或 WiFi 也会断，连接过程中别动这两个开关。

### 症状五：有线插上没反应

- 换一根确定能传数据的数据线（最常见原因就是充电线）；
- 换 USB 口，部分车型的 Type-C 口或后排接口不支持互联，用前排 USB-A；
- 有些手机需要打开 USB 调试模式后才响应车机连接。

## 两个「不是故障」的情况

- **手机地图和车机地图不能同时导航**：一边开始导航，另一边会自动退出，这是设计如此，不是断线；
- **某些应用投到车机上功能不全**：部分应用适配了车机小窗模式、部分没适配，具体以手机厂商的适配进度为准。

## 还是不行

按顺序试：先用有线顶着 → 等手机系统或车机系统的下一次更新（这类问题多数最终靠版本更新解决）→ 在质保期内直接找 4S 店或品牌客服。排查流程本身有疑问的，回到 [连接车机的步骤.md](连接车机的步骤.md) 一步步对着做。
