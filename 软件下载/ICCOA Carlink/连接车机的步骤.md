## 连接前先检查这五件事

无线连接失败多半是准备没做对。上车后按这份清单过一遍：

1. **车机蓝牙打开**。车机端没开蓝牙时，进入连接界面一般会自动帮你开，但保险起见先手动确认。
2. **手机蓝牙打开**。
3. **手机 WiFi 打开，但不能连任何热点**——包括车机自己的热点和其他设备的热点。这是最容易踩的坑：WiFi 开着但连着东西，连接就会失败。
4. **手机保持解锁亮屏状态**，尤其在车机端进入 PIN 码页面之前，锁屏状态弹不出连接确认框。
5. **小米 / 红米手机**额外检查：设置 → 更多连接 → CarWith → 连接与提示，确认这个开关是打开的（默认打开，但有人关过就再也弹不出来）。

OPPO 和 vivo 的对应入口是：OPPO 在设置 → 连接与共享 → 智慧车联（或 Car+车联）；vivo 在设置 → 更多连接 → 智能车载（或 Jovi InCar）。同样的道理，里面的连接开关保持打开。

## 首次连接：PIN 码配对

第一次连接要在车机上进 PIN 码页面做一次配对：

1. 把手机放到中控屏附近（半米以内）。
2. 在车机应用中心找到「手机互联」（有的车叫「手车互联」），点 **ICCOA Carlink**，车机会显示一个 PIN 码界面。
3. 手机端会弹出连接确认框，在弹窗里**输入车机显示的 PIN 码**，点连接。
4. 车机端确认后，连接建立，车机屏幕上出现 Carlink 的桌面。

## 第二次开始：点一下就连

配对成功过一次的设备，之后再连不用输 PIN 码：车机进入手机互联的 ICCOA Carlink 界面，手机端弹出连接确认，点一下「连接」就完成。

## 有线连接（更稳，推荐先用）

如果你的车机 USB 口支持，用数据线连也可以，而且**有线更稳**——不少无线容易掉线的用户，最后都用有线顶着用：

- 数据线必须是**能传数据的线**，只能充电的线连不上。判断方法：把手机用这根线连电脑，能传文件才是数据线。
- 前置的 USB-A 口一般可以，部分车型 Type-C 口不支持，接了没反应就换口。
- 插上线后流程和无线一样：车机进 ICCOA Carlink，手机弹窗确认。

## 断开连接

三种方式，任选其一：

- 连接成功后，下拉手机通知中心，点「断开连接」；
- 在车机的 Carlink 界面里点「断开连接」按钮；
- 直接下车锁车——车辆锁车下电、或你带着手机走出连接距离，连接会自动断开。

## 自动回连怎么用

临时下车（没锁车下电）再上车，支持自动回连，前提有两个：

1. 手机端车联设置里的「自动连接」开关是打开的（默认打开）；
2. 上次断开是**被动断开**——也就是你直接下车走人，没有手动点过断开按钮。手动断开过的，这次不会自动回连。

上车前保持手机蓝牙和 WiFi 开着，上车后不用管它，几秒内自己连上。不想用自动回连，就在各品牌的设置入口里把「自动连接」关掉（路径见上面的品牌对照）。

## 换一部手机来连

车机一次只记得一部手机。已经连着 A 手机时，B 手机想连，要先断开并「忽略」当前记忆的设备：把手机蓝牙或车机蓝牙关掉 5 秒再开，或在手机上取消与车机的蓝牙配对，或删掉手机端 Carlink 的连接记录，也可以在车机端忽略该互联设备——做完任意一个，再用 B 手机走首次配对流程。

## 车里不止一套互联方案时

不少车的「手机互联」里同时躺着 CarPlay、HiCar、Carlink 几个图标，它们互不冲突，你的手机属于哪个阵营就点哪个。拿不准该点哪个，见 [车机互联方案怎么选.md](车机互联方案怎么选.md)。

连上了之后能干什么，见 [车机投屏功能一览.md](车机投屏功能一览.md)；哪一步卡住了，去 [连接失败怎么办.md](连接失败怎么办.md) 对症排查。
