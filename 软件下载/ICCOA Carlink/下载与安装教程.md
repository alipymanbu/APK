## 本篇适用的安装包

ICCOA Carlink 是手机与车机互联的工具：把手机上的导航、音乐、电话搬到汽车中控屏上，开车时的操作都在车机大屏完成。它有两种形态——很多小米、OPPO、vivo 手机系统里已经内置了车联入口（小米叫 CarWith，OPPO 叫 Car+车联或智慧车联，vivo 叫智能车载或 Jovi InCar），这类手机**优先用系统内置的入口**，不用另装 app；而一些没有内置车联功能的手机、或者车机端要求装独立客户端的情况，才需要单独安装这份应用。

如果你打算装的是独立安装包，先核对下面这些信息（这是本套文档所附安装包的实际情况，和官网最新版可能不是同一个版本）：

| 项目 | 信息 |

| 包名 | com.ucarhu.demo |
| 安装包大小 | 5.48 MB |

## 下载安装包

进入 [ICCOA Carlink 安装文件资源（夸克网盘）](https://pan.quark.cn/s/133633ef8324)，转存到自己网盘后下载 APK 文件到手机即可。建议用手机浏览器直接下载，省得再从电脑传一遍。

下载完可以先核对一下文件：文件大小应在 5.48 MB 左右。在意文件完整性的话，可以用文件管理器查看属性里的 MD5 值，和上表的 MD5 比对，一致说明文件没在传输中损坏。

## 安装步骤

1. 在手机文件管理器里找到下载好的 APK 文件，点它。
2. 系统会提示「无法安装未知来源应用」或「出于安全考虑，已禁止安装」，这是安卓对非应用商店安装的默认限制，点「设置」或「仍要安装」继续。
3. 按品牌找到对应入口允许一次安装：
   - 小米 / 红米：设置 → 隐私保护 → 特殊权限 → 安装未知应用；
   - OPPO / 一加 / 真我：设置 → 安全 → 安装未知应用（或安装外部来源应用）；
   - vivo / iQOO：设置 → 安全 → 更多安全设置 → 安装未知应用。
4. 允许后回到安装界面，点「安装」，几秒就能装完。
5. 装完桌面上会出现 ICCOA Carlink 的图标。

安装时的几个注意点：

- **存储空间**：5.48 MB 很小，但手机剩余空间太少（低于 1 GB）时有些系统仍会报安装失败，清一下再装。
- **旧版本冲突**：如果手机里已经装过同包名的旧版本，直接安装新版本会覆盖升级，不用先卸载。
- **安装被拦截**：部分手机自带的手机管家会弹「此应用存在风险」，如果是你自己下载的安装包，选「继续安装」即可。

## 装完之后

打开 app，授权它需要的蓝牙和附近设备权限（连接车机全靠这两样），然后就可以去车上试连接了。具体流程见 [连接车机的步骤.md](连接车机的步骤.md)。

先别急着去车上——建议先翻一下 [支持的车型与手机.md](支持的车型与手机.md)，确认你的车机支持 ICCOA Carlink：它需要**车机端本身也支持**才能连，单装手机端 app 是连不上的。装好了却连不上，则直接看 [连接失败怎么办.md](连接失败怎么办.md)。
