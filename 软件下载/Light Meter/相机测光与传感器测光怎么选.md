# 相机测光与传感器测光怎么选

> Light Meter 主界面最上面的「相机仪表」和「传感器仪表」是两种完全不同的测光方式，选错入口读数会差得远，本篇讲清它们的差别、各自的用法和局限。

## 一、先分清两种光

- **反射光**：被摄对象反射进镜头的光。「相机仪表」用手机摄像头看着主体测，跟相机内测光的工作方式一样——你指哪它测哪，画面里的亮部暗部都会影响读数。
- **入射光**：直接照到被摄对象身上的光。「传感器仪表」读的是手机上那颗环境光传感器接收到的光，不管主体是深色还是浅色，读数都不受影响。

按官方说明（官网：[www.lightmeter.dev](https://www.lightmeter.dev/)），相机仪表在 iOS 和 Android 上都有，传感器仪表只有 Android 版提供。如果你在 iPhone 上用同名应用，会找不到传感器仪表这个入口。

## 二、对照表

| | 相机仪表 | 传感器仪表 |
| --- | --- | --- |
| 测的是 | 反射光 | 入射光 |
| 依赖硬件 | 摄像头 | 环境光传感器 |
| 怎么测 | 对准主体，看画面读数 | 把手机放到主体位置，传感器朝回相机方向 |
| 适合 | 大多数场景，边构图边测 | 人像、逆光、大块黑白背景等容易骗过反射测光的场景 |
| 局限 | 画面里大面积白或黑会把读数带偏 | 手机必须有环境光传感器；读数受遮挡和角度影响 |

## 三、相机仪表：默认从这里开始

大多数情况下用相机仪表就够了：

1. 进入「相机仪表」，先把 ISO 设成实际拍摄用的值——装 ISO 400 的胶卷就设 400；
2. 对准要拍的主体，让主体占住画面中间；
3. 读屏幕给出的光圈和快门组合，照着设置相机。

对着雪地、白墙这类大面积亮部，读数会偏暗（它想把白色压成灰色）；对着黑背景里的小主体，读数会偏亮。碰到这类场景，要么凑近主体测，要么改用传感器仪表。

画面明暗分布复杂时，还可以只测局部：把想测的那一小块区域放大（新版本支持点击画面中具体位置取点测光，操作方式以你的版本为准），或者分别对准场景里最亮和最暗的两处各测一次，两个读数一比就知道这场景的明暗跨度装不装得下，再决定保亮部还是保暗部。

## 四、传感器仪表：前提与用法

1. 确认手机有环境光传感器。绝大多数 Android 手机都有，个别机型没有——进「传感器仪表」后读数一动不动、用手挡住屏幕顶部也没反应，基本就是没有；
2. 传感器一般在手机正面顶部附近，别让手指、手机壳或支架挡住；
3. 用法是「位置替换」：你站在哪里拍，就把手机放到被摄主体的位置，让传感器朝回你的相机方向读数。

逆光拍人像时这个方法比对着镜头测靠谱得多——你测的是打在脸上的光，而不是画面里那片刺眼的天空。

## 五、拿不准就两个都测

同一场景两个入口各测一次，读数差一档以内属正常——它们本来就测的不是同一个东西。差得太远时优先怀疑：传感器被挡住、摄像头正对着强光源、或场景明暗分布极端。读数出来后还留多少余量，跟胶片种类有关：负片容错大，反转片容错小。

参数读出来之后怎么落到相机上，见[测光操作与曝光参数读取](测光操作与曝光参数读取.md)；读数不稳定或跟别的表对不上，见[常见问题与测光不准的对策](常见问题与测光不准的对策.md)；想把整体偏差系统校准掉，见[测光偏了怎么校准](测光偏了怎么校准.md)。
