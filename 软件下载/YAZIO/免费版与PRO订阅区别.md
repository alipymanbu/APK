## 一、先说结论：免费版能完成核心闭环

记饮食、算热量、看体重变化这条主线，免费版完整可用：食物数据库与搜索、条码扫描、热量与三大宏量营养素记录、体重与活动记录、16:8 断食、基础数据同步都在免费范围内。很多人只用免费版就够了。

PRO 补的是记录效率（AI 拍照、提前规划）、数据深度（更多营养素与更长统计）和体验（去广告、自定义日记）。下表按官方帮助中心列出的 PRO 权益整理：

| 能力 | 免费版 | PRO |
| --- | --- | --- |
| 食物日记、食物库搜索、条码扫描 | 有 | 有 |
| 热量、碳水、蛋白质、脂肪记录 | 有 | 有 |
| 16:8 断食计划 | 有 | 有 |
| 5:2 / 6:1 / 1:1 断食计划 | 无 | 有 |
| AI 拍照记录食物 | 无 | 有 |
| 提前记录未来几天的膳食 | 无 | 有 |
| 智能食物评分（营养一眼判断） | 无 | 有 |
| 详细营养素（脂肪酸、纤维、糖、盐、维生素、矿物质） | 无 | 有 |

## 二、订阅从哪买、怎么收钱

PRO 有两个购买渠道：

1. **应用内购买**：走 Google Play 账号扣款，按订阅周期自动续费，到期前 24 小时内取消才不会续上下期；
2. **官网订阅**：在 [www.yazio.com](https://www.yazio.com) 登录账号购买，扣款与续费走官网渠道。

官方偶尔提供 **7 天 PRO 免费试用**，只在官网发放、应用内订不了。要注意试用到期会自动转成付费订阅，不打算续费的话，在到期前去 [www.yazio.com/app/account](https://www.yazio.com/app/account) 登录后点「取消订阅」即可；取消了也能用满 7 天试用。

## 三、取消订阅：在哪买的去哪取消

取消订阅的入口由购买渠道决定，YAZIO 官方无权替你取消应用商店的订阅：

| 购买渠道 | 取消路径 |
| --- | --- |
| Google Play（应用内购买） | Play 商店 → 头像 → 付款和订阅 → 订阅 → 选中 YAZIO → 取消订阅 |
| App Store（iOS） | App Store → 账户 → 订阅 → 关闭 YAZIO 自动续订 |
| 官网购买 | 登录 [www.yazio.com/app/account](https://www.yazio.com/app/account) → 找到订阅 → 取消订阅；或应用内「个人资料 → 设置 → 账户 → 订阅 → 取消订阅」 |

取消后订阅在当前已付费周期结束时才失效，期内 PRO 功能照常可用。两个容易中招的点：

1. **取消不等于退款**，已扣的费用不退；
2. **卸载应用或删除账号都不会终止订阅**，扣款会继续，必须按上表主动取消。

## 四、退款找谁

原则：在哪买就找谁退。Google Play 购买的找 Google 客服走官方退款流程；App Store 购买的找 Apple 客服；官网购买的按德国消费者保护规则有 14 天无理由撤回期，可通过 [www.yazio.com](https://www.yazio.com) 的撤回表单或发邮件到官方支持邮箱办理。

订阅状态在应用里查：「个人资料 → 设置 → 账户 → 订阅」。账号层面的问题（删除账号、数据去向）见 [数据同步与账户管理.md](数据同步与账户管理.md)。
