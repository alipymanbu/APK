## 一、先按这个顺序排查

常见问题基本落在四类里，按顺序过一遍，别一上来就重装：

1. **网络** —— 换 Wi-Fi / 流量试一次（很多「搜不出来」就是断网）；
2. **账号** —— 退出重登，确认没登错账号（手机号与微信是两个入口）；
3. **版本** —— 是否刚升级后出的问题，去商店看有没有新版本；
4. **服务端** —— 换网页版 [metaso.cn](https://metaso.cn) 对照：网页版也不行就不是你手机的问题，等恢复或走反馈。

## 二、登录与验证码

有用户反馈遇到「不是提示网络错误、就是验证码错误」，登录不上时按这个顺序试：

1. 确认手机号输入无误、手机能收到短信（拦截短信里找找验证码）；
2. 换个网络环境重发（收不到验证码常见于当前网络不稳）；
3. 隔一两分钟再试，别连点触发频率限制；
4. 还不行就**改用微信登录**绕开短信通道，先用起来。

## 三、闪退、卡顿、显示异常

以下均有用户在应用商店反馈过，属「有用户反馈」级别，未必人人复现：

| 现象 | 处理 |
| --- | --- |
| 一点进去就闪退 / 黑屏 | 升级到商店最新版；仍闪退则卸载重装（账号数据在云端，见 [下载与安装教程.md](下载与安装教程.md)） |
| 页面滑动卡顿 | 先确认是最新版；旧机型持续卡顿就通过应用内反馈报机型与版本 |
| 升级后只能显示半个屏幕 | 重启应用与手机；仍半屏则卸载重装当前商店版 |
| 图片共享类快捷指令要点两次允许 | 系统授权弹窗的常规行为，按系统提示再点一次即可 |

## 四、答案与引用不对

- **引用点不开 / 打开是 404**：引用是搜索当时抓取的快照，源网页后来被移动或删除就会失效 —— 不是应用坏了。换一条引用核验，或把关键结论拿去别处交叉验证。
- **有用户反馈答案「张冠李戴」**：正确找到了来源、却把内容安到了它头上。所以**重要的数据、引用、专业结论务必点开来源自己读一遍**，别直接抄。批量核对一段文章时，可用官网的「事实核验」功能（[metaso.cn/fact](https://metaso.cn/fact)）：粘贴文章后它会拆出事实主张逐条找证据比对，结论仍要你最终判断。
- **答案感觉被压缩得偏离问题**：通常是问题给的信息不够。把背景、时间范围、想要的答案形式一次说清，再看结果，提问方法见 [三种搜索模式怎么选.md](三种搜索模式怎么选.md)。

## 五、搜索慢或没反应

- 研究模式本身就要跑更久（有第三方整理给出的参考量级：简洁约 2~3 秒、深入约 5~8 秒、研究约 10~15 秒，**实测受网络与问题复杂度影响**）—— 先确认不是自己选错了强度。
- 「没反应」先等一两分钟重试；长而复杂的问题偶尔会导致检索失败，缩短问题再发一次。
- 反复失败走第一章的四步排查，仍不行就应用内反馈。
