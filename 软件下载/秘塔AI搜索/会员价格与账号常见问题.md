## 一、免费能用到什么程度

不登录也能发起搜索；登录后有每日免费额度（有公开资料称注册用户每天约 100 次免费额度，**以应用内当时显示为准**）。日常「简洁 / 深入」查资料基本够用，**研究模式、批量生成类功能**是额度消耗大户，重度用会先撞到限额。

## 二、会员与积分的价格口径

苹果 App Store 中国区页面展示的内购项目包括（**价格以官方商店当时显示为准**，会调整）：

| 项目 | 页面标价 |
| --- | --- |
| 月度会员 | ¥39.00 |
| 年度会员 | ¥228.00 |
| 1000 积分 | ¥12.80（另有 H3 积分档 ¥10.80） |
| 知识库额度 1000 点 | ¥3.50 |
| 知识库额度 10000 点 | ¥34.00 |

要点：

- 支付走应用内购买或支付宝等官方给的路径，**别在第三方代充渠道付钱** —— 既无保障也容易踩账号风险。
- 官方协议写明：积分有明确的消耗费率，**长期积分 12 个月内过期**；会员权益、未到期服务与账号绑定。
- 开通自动续费的，续费前可在系统订阅管理里关闭；安卓端与 iOS 端的购买项不互通，换系统前先看清楚。
- **开发者另有一套搜索 API 计费**（按次计费，有第三方整理称约 0.03 元/次并含免费额度，**以官方 API 页面登录后的实际定价为准**），与上面的 C 端会员是两回事，普通用户可忽略。

## 三、登录与多端

- 登录方式：**手机号验证码**或**微信**（官方隐私政策写明）。秘塔各产品共用一个中心账号，一个号通行搜索、专题、API 等产品。
- 换手机 / 用平板与网页版：登录同一账号即可同步历史与专题；对不上先确认两端是同一种登录方式（手机号与微信是两个入口）。
- 数据存储在境内，日志保留不少于 6 个月（官方隐私政策口径）。

## 四、注销账号前必看

官方注销须知的硬性条件，缺一个都可能注销失败：

1. **先取消自动续费** —— 未取消的，账号可能无法注销；
2. 权益结清：会员、未到期服务、未提现收入等按须知处理，未处理视为放弃；
3. 无未完成订单、无投诉举报/诉讼等纠纷；
4. 注销后：**该号无法登录任何秘塔产品、无法恢复**，账号下个人信息删除或匿名化，已购权益一并清除；处理时限最长不超过 15 个工作日。

只是不想被打扰的话，先退订消息通知比注销温和得多。

## 五、反馈与故障

- 使用问题在应用内「用户反馈」提交表单，或联系官方客服；注销相关问题官方公布的联系邮箱是 `support-1@metasota.ai`。
- 搜索没反应、结果异常时，先确认网络、再退出重登；仍不正常可换网页版 [metaso.cn](https://metaso.cn) 对照，是端的问题还是账号的问题。
- 具体现象（验证码收不到、闪退、半屏、引用点不开）的逐条排查见 [常见问题与故障排查.md](常见问题与故障排查.md)；安装层面的报错（解析包失败、签名冲突）见 [下载与安装教程.md](下载与安装教程.md)；模式选择与结果核验见 [三种搜索模式怎么选.md](三种搜索模式怎么选.md)。
