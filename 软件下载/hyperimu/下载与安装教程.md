## 一、HyperIMU 是干什么用的

HyperIMU 是开发者 ianovir（Sebastiano Campisi）发布的安卓工具，用途是把手机变成一台 IMU（惯性测量单元）：按你设定的间隔，把加速度计、陀螺仪、磁力计、GPS 等传感器的读数打成 CSV 或 JSON 数据包，走 TCP/UDP 发给同一局域网里的电脑，或者直接存成手机本地的 CSV 文件，供你做实时处理或离线分析。

拿到它之后通常要配合电脑端一起用（比如官方在 GitHub 上提供的 Python 版 [HIMUServer](https://github.com/ianovir/HIMUServer)），只装在手机上能做的主要是看实时图表和存文件。手机端怎么选传感器、怎么定采样间隔，见[传感器选择与采样率设置.md](传感器选择与采样率设置.md)。

## 三、下载与安装步骤

1. 打开 [HyperIMU 安装文件资源（夸克网盘）](https://pan.quark.cn/s/abd8f0be37f0)，把里面的 APK 文件（文件名形如 `hyperimu_v3.1.4.3.apk`）转存到自己的网盘，再下载到手机；
2. 在手机上点开下载好的 APK。系统第一次会提示「不允许安装未知来源应用」，按提示允许「来自此来源的应用」安装权限后再回来继续；
3. 等安装完成，点「打开」直接进入应用，或稍后从桌面图标进入；
4. 想核对安装包有没有被动过，可以用任意 MD5 校验工具算一遍文件 MD5，与上表的 `977456EBF28405F4962905819D4D7A46` 比对，一致说明文件与记录时相同。

## 四、第一次打开看什么

- **主界面中间的转轮**：点一下开始发送/记录数据，再点一下停止。第一次点它多半「什么都没发生」——因为默认传输协议是 `None`（只采样、不外发），这是最多人踩的第一个坑，处理办法见[连接不上与收不到数据的解决办法.md](连接不上与收不到数据的解决办法.md)；
- **左上角抽屉菜单**：传感器列表（Sensor List）、数据包预览（Packet Preview）、采集文件（Acquisitions）、设置（Settings）、Pharos 都从这里进；
- **图表按钮**：采集运行时点它看实时信号曲线。先在这里确认传感器确实在出数，再去折腾电脑端。

另外两点提前说：要用 GPS 或 NMEA 定位数据的话，装完首次使用时系统会要定位权限，允许即可；屏幕熄灭可能让采集停下，设置里有对应的 Stay awake 选项（见[传感器选择与采样率设置.md](传感器选择与采样率设置.md)）。

要把数据实时发到电脑，接着看[数据推流到电脑的连接设置.md](数据推流到电脑的连接设置.md)；只想把数据存成文件拿回去分析，直接看[CSV文件保存位置与数据格式.md](CSV文件保存位置与数据格式.md)。
