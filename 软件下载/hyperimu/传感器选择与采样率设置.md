## 一、去哪里选传感器

还没把应用装上手机的话，先看[下载与安装教程.md](下载与安装教程.md)。

打开左侧抽屉菜单的 **Sensor List（传感器列表）**，里面列出这台手机上所有可用的传感器，勾了哪些，数据包里就带哪些。几个实际建议：

- 只勾你要用的。每多一个传感器，每条数据包就多三个数值，采样间隔短、传感器又多时，流量和电量消耗都会明显上去；
- 陀螺仪（Gyroscope）、加速度计（Accelerometer）、磁力计（Magnetometer）这类轴类传感器，每个固定输出 X、Y、Z 三个值；
- GPS 与 NMEA 0183 属于附加数据，要用它们得给应用定位权限，而且室内没信号时输出的是 0。

选好的组合可以在同一页面存成配置清单：不同场景（比如「只发陀螺仪」和「全套加 GPS」）各存一份，切换时不用重新一个个勾。

## 二、开跑前先预览一遍

抽屉菜单里的 **Packet Preview（数据包预览）**能把当前配置下每条数据包的字段逐个列出来。开跑前看一眼，能确认两件事：传感器勾对了、字段顺序和你电脑端解析的顺序一致。字段顺序怎么读，见[CSV文件保存位置与数据格式.md](CSV文件保存位置与数据格式.md)。

## 三、采样间隔与数据包选项

抽屉菜单 **Settings** 里与采集直接相关的选项：

| 选项 | 作用 | 使用建议 |
| --- | --- | --- |
| Sampling Rate | 采样间隔，单位毫秒，对所有传感器统一生效 | 要抓动作细节就把间隔调小（代价是数据量大）；只记录变化趋势可以放到几百毫秒，省电省流量 |
| Server IP address / Server Port number | 电脑端的地址与端口，只在 UDP、TCP、JSON 三种协议下生效 | 与电脑端收包程序保持一致，配置方法见[数据推流到电脑的连接设置.md](数据推流到电脑的连接设置.md) |
| Persistent | 开启后，即使电脑端掉线，手机端也会持续尝试重连而不是直接停掉 | 长时间挂机采集建议开 |
| Prequel Packet | 开启后第一条包发送的是传感器名称而不是数值 | 用来给电脑端做字段对照，正式长期采集时可关 |
| # Terminator | 数据包结尾用 `#` 代替默认的换行符 | 与电脑端的切包设置必须一致，两边各改各的会一切一个错 |
| Stay awake | 主界面停留时屏幕不会熄灭 | 只在主页面生效；采集期间不想被熄屏打断就开着 |
| Play Sounds | 应用提示音开关 | 按需 |

## 四、附加数据：时间戳、电量、GPS、NMEA

数据包除了传感器本体，还能按需带上附加字段，在设置里逐项开关：

- **包头**（排在传感器数值前面）：Timestamp（毫秒级时间戳）、MAC address（设备网卡地址）、Battery（电量百分比、充电状态 1/0、是否接电源 1/0）；
- **包尾**（排在传感器数值后面）：GPS（纬度、经度、海拔）、NMEA（GPS NMEA 0183 语句，每三条一组，组内用分号分隔，超过三条按顺序拆到后续包里继续发）。

开了这些字段，收到的包就不再只有传感器数值。电脑端解析时要按固定顺序把包头、包尾留出来，别把它们当成传感器数值算进去；具体位置见[CSV文件保存位置与数据格式.md](CSV文件保存位置与数据格式.md)。数据发出去电脑收不到时，按[连接不上与收不到数据的解决办法.md](连接不上与收不到数据的解决办法.md)逐项排查。
