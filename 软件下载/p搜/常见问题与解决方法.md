## 一、打开后连不上服务器，搜索一直出不来

按顺序试：

1. **等十几秒**。应用启动后要先连服务器，冷启动时多给它一点时间；
2. **重启应用**：完全退出（从最近任务里划掉）再打开，多数连接问题这一步就好了；
3. **验证手机网络**：开个网页确认网络本身通的 —— 网页能开而 P搜连不上，才轮到下一步；
4. **查安全软件**：装了带联网管控的安全软件时，看它是否拦了 P搜 的联网请求，放行即可；
5. **换网络再试**：Wi-Fi 与移动数据各试一次，能定位是不是当前网络环境的问题。

连上之后左下角会显示连接状态，含义见 [穿透模式与连接状态判断.md](穿透模式与连接状态判断.md)。

## 二、搜不到资源，或结果比以前少很多

- 先看左下角状态：若处于「已进入穿透模式」，结果量与正常状态不同是正常的，含义与取舍见 [穿透模式与连接状态判断.md](穿透模式与连接状态判断.md)；
- **缩短关键词**：「某某剧 第一季 1080p 蓝光」这类长串命中率低，拆成核心词分几次搜；
- **换同义词**：资源的命名习惯与你打的字未必一致，片名用原名、简称各搜一次；
- **换个时间段再搜**：冷门词的收录情况随时间波动，晚上搜不到的，换个时段再试；
- **怀疑是网络环境限制**：p2p 类服务在部分网络下会被限制（表现为「怎么搜都空、网页却正常」），把 Wi-Fi 与移动数据各试一次，差异明显就是网络侧的问题，换着用即可。

## 三、结果一堆，点开却都是打不开的

搜索结果是全网 P2P 网络里的索引，天然混着失效与假的条目，自己筛：

| 特征 | 处理 |
| --- | --- |
| 体积明显偏小（正片类内容却只有几十 MB） | 先按大小排一遍，这类直接划掉 |
| 扩展名是 `.exe`、`.rar` 且体积很小 | 手机上用不到 `.exe`，多半是给电脑下的伪装包，别点开 |
| 文件名带「预告」「花絮」「解析」「工具」 | 不是正片，跳过 |
| 详情里地址残缺、复制不全 | 换下一条 |

筛选的详细思路在 [磁力与网页搜索怎么用.md](磁力与网页搜索怎么用.md) 第二、五节。

## 四、复制了链接，下载工具没反应

1. 确认复制的是**完整地址**（磁力链接以 `magnet:` 开头，复制断了会缺尾巴）；
2. 确认你的下载工具**支持磁力协议** —— 不支持的工具收不了这种任务；
3. 手动粘贴：在下载工具里新建任务，把链接贴进去，不依赖自动跳转；
4. 链接有效但任务一直 0 速度：是该资源做种人少，换一条结果，不是 P搜 的问题；完整排查见 [磁力下载速度慢怎么办.md](磁力下载速度慢怎么办.md)。

## 五、安装失败、装完闪退

安装与首次启动的问题统一按 [下载与安装教程.md](下载与安装教程.md) 排查，重点三条：

- 系统拦「未知来源」→ 去 **设置 → 应用 → 特殊应用权限 → 安装未知应用** 给下载用的应用开开关；
- 安装包不完整 → 用头部网盘重下，MD5 与教程里的核对表比对；
- 装完打不开 → 先确认包名是 `com.Huosu.p2psearcher`，名字像但包名不对的是别的应用。

## 六、网盘里的版本和商店显示的不一样

正常现象。网盘固定放一份可用的包（版本以 [下载与安装教程.md](下载与安装教程.md) 的核对表为准），商店与各下载站的版本号各自更新、经常不一致，以对应页面当时显示为准。要哪一份自己定：要固定可复现的用网盘那份，要新的用商店那份（包名一致即可）。
