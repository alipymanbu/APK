# Winlator 容器与显卡驱动怎么选

> 容器是 Winlator 里运行 Windows 程序的隔离环境，建容器时的几个选项直接决定游戏能不能跑、跑多快。本篇把每个选项一次讲清。

## 一、容器是什么

容器就是 Winlator 给你造的一台「虚拟 Windows 电脑」：有自己的 C 盘、开始菜单、注册表。每个容器的设置互相独立 —— 你可以给老游戏建一个低分辨率容器、给 3D 游戏建一个高配置容器，互不干扰。程序全部装在容器里，删容器就等于把里面的 Windows 环境整个删掉，游戏文件本身如果放在手机 Download 目录则不受影响。

主界面点 **+** 新建容器，起个名字，然后面对的就是下面这几个选项。

## 二、屏幕分辨率

容器建的 Windows 桌面分辨率，也是游戏的渲染分辨率，直接决定帧数：

| 分辨率 | 适用 |
| --- | --- |
| 800×600 | 最稳最快，兼容性最好，低配机首选 |
| 960×544 | 16:9 折中方案，中端机常用 |
| 1280×720 及以上 | 只有旗舰机才建议，帧数压力大 |

社区经验：先从 800×600 或 960×544 起步，跑顺了再升档；帧数低就降回来。分辨率在快捷方式里也能按游戏单独覆盖（见[游戏怎么导入与运行.md](游戏怎么导入与运行.md)第四节）。

## 三、图形驱动

这是**最关键**的一个选项，按你手机的 GPU 类型选：

| GPU 类型 | 推荐驱动 | 说明 |
| --- | --- | --- |
| 骁龙 / Adreno | Turnip | 官方主打方案，性能最好，骁龙机型无脑选它 |
| Mali（联发科、部分三星） | Vortek 或 VirGL | Vortek 自 v10 起支持 Mali；不行就退 VirGL（慢但通用） |
| 都不行 | VirGL | 通用兜底，任何设备能跑但性能最低 |

选错驱动的典型症状是游戏黑屏或直接崩溃 —— 换一个驱动再试是排查第一步（见[常见问题与闪退排查.md](常见问题与闪退排查.md)）。

## 四、DX 包装器

Windows 游戏按 DirectX 版本渲染，包装器负责把它转到你的 GPU 上，也是按游戏选：

| 包装器 | 适用场景 |
| --- | --- |
| WineD3D | 兼容面最广的默认项，先跑不通的游戏用它打底 |
| DXVK | DirectX 9/10/11 的 3D 游戏首选，Adreno 机型上通常比 WineD3D 快 |
| VKD3D | DirectX 12 游戏用，实验性 |
| CNC DDraw | DirectDraw 时代的最老游戏（老策略、老即时战略） |

经验顺序：3D 游戏先试 DXVK，不行退 WineD3D；DX12 游戏才碰 VKD3D；最老的一批游戏直接 CNC DDraw。

## 五、Box64 预设与其他选项

- **Box64 预设**：分兼容、性能、稳定（Stability）等几档，决定翻译层的取舍。官方建议是「不稳就先动 Box64 预设」，位置在容器设置 → Advanced 标签页；Unity 引擎游戏官方给了两个方案：换 Stability 预设，或在快捷方式里加启动参数 `-force-gfx-direct`。
- **CPU 亲和性**：控制 Winlator 能用哪几个核心，默认不动，调试时再碰。
- **环境变量**：老游戏打不开时，官方给的配方是加一条 `MESA_EXTENSION_MAX_YEAR=2003`。
- **WoW64 模式**：Advanced 页里的实验开关，普通玩家不用开。
- **Win 组件**：按需开关 DirectSound 等组件，默认即可。

## 六、一个新容器的推荐起点

不想逐项研究的话，骁龙机型直接照这个组合建：

```
分辨率：960×544（低配机改 800×600）
图形驱动：Turnip
DX 包装器：DXVK（3D 游戏）；跑老游戏再换 CNC DDraw 或 WineD3D
Box64 预设：默认
音频驱动：默认
```

Mali 机型把图形驱动换成 Vortek（v10+），其余相同。

## 七、容器建好后

先查一下 GPU 能力：容器跑起来后，开始菜单里有 GPUInfo 工具（v10 起），能看到当前驱动支持的特性。然后就可以往容器里放游戏了，见[游戏怎么导入与运行.md](游戏怎么导入与运行.md)；跑起来不够快，按[怎么调最流畅.md](怎么调最流畅.md)的顺序调。
