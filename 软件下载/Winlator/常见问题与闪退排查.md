## 一、安装与启动阶段

| 现象 | 处理 |
| --- | --- |
| 提示「无法安装 / 解析包出错」 | 安装包没下完整，重新下载；网盘资源那份的 MD5 是 `99681D7E5E1E8F10538F75FD98B48C01`，可用校验工具核对 |
| 安装按钮点不动 | 先到系统设置 → 安装未知应用，给浏览器/文件管理器开权限 |
| 首次启动卡住不动 | 是在释放内置运行文件，低端设备要几分钟，不要杀后台 |
| 打开就闪退 | 确认设备是 64 位安卓；再确认安装包来源可靠（官方 Releases 或本文网盘资源），被改名打包的来路不明安装包先弃用 |

## 二、游戏打不开 / 闪退

按命中率从高到低逐条试：

1. **换 Box64 预设**：容器设置 → Advanced → Box64 preset，换一档再跑。官方文档把这条列为不稳时的第一动作。
2. **换图形驱动**：骁龙机型确认在用 Turnip；换驱动后黑屏/崩溃减轻或加重的，说明就是驱动兼容问题。对照见[容器与显卡驱动怎么选.md](容器与显卡驱动怎么选.md)。
3. **换 DX 包装器**：3D 游戏 DXVK 不行换 WineD3D，反之亦然；最老的游戏换 CNC DDraw。
4. **老游戏专门配方**：容器设置 → Environment Variables 加一条 `MESA_EXTENSION_MAX_YEAR=2003`（官方给老游戏的通用解法）。
5. **.NET 程序报错**：容器开始菜单 → System Tools → Installers，安装 Wine Mono。v10.0 Hotfix 给 Wine Mono/Gecko 的安装加了备用下载地址，装不上时保持联网重试。
6. **Unity 游戏闪退**：Box64 预设换 **Stability**，或在该游戏快捷方式里加启动参数 `-force-gfx-direct`。
7. **装了 DirectX 组件还报缺 dll**：把游戏自带的 DirectX 运行库安装包（dxsetup 之类）放进 Download 目录，在容器里跑一遍。

每次只改一个设置，改完立刻重试，才能知道是哪一条起效。

## 三、画面问题

- **游戏窗口很小、缩不满屏**：在该游戏快捷方式设置里打开 **Force Fullscreen**，低分辨率老游戏专用（官方建议）。
- **进游戏黑屏但有声音**：先换 DX 包装器，再换图形驱动；两者都试过还黑，降分辨率。
- **画面花屏、贴图错乱**：典型驱动兼容问题，换 DXVK/WineD3D 与 Turnip/VirGL 组合排查。
- **中文显示方块/乱码**：容器里缺中文字体，装字体与补语言变量的做法见[怎么调成中文.md](怎么调成中文.md)。
- **想看当前 GPU 能力**：容器开始菜单里的 GPUInfo 工具（v10 起）能看到驱动与特性支持。

## 四、声音问题

- **声音爆音、断续**：官方给的办法是调大音频平均延迟 —— 在容器的 ALSA/PulseAudio 配置里把 average latency 调高，老游戏如 Unreal Gold 调到 90ms 即可解决。
- **完全没声音**：检查容器设置里的音频驱动是否被动过，先恢复默认再试。

## 五、输入没反应

手柄识别不到、按键错乱、键鼠失效这类问题集中在[手柄键盘鼠标怎么用.md](手柄键盘鼠标怎么用.md)第五节，先查系统层面识别，再查 XInput/DirectInput 选边。

## 六、还查不出原因时

- 容器设置里有 **Logs** 选项（v7 起），导出日志能看到最后崩在哪一步；
- 开始菜单的 **Task Manager**（v10 改进版）能看进程是否还活着；
- 都解决不了，去官方仓库 [github.com/brunodev85/winlator](https://github.com/brunodev85/winlator) 的 Issues 搜同款报错，或升级到最新版 —— 不少「老毛病」在新版本里已经修掉（Vortek 修复、Steam 启动修复等都写在官方更新日志里）。安装包获取见[下载与安装教程.md](下载与安装教程.md)。
