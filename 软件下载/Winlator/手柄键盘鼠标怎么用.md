# Winlator 手柄键盘鼠标怎么用

> Winlator 支持三种输入方式：屏幕虚拟按键、外接手柄、键鼠。本篇讲各自怎么接、怎么配，以及纯触屏玩法的设置。

## 一、外接手柄

蓝牙或 USB 直连的手柄，开机配对后 Winlator 能直接识别，游戏里不需要额外驱动：

- **输入 API 要按游戏选**：容器设置（或快捷方式设置）里可以选 XInput 或 DirectInput。多数新游戏用 XInput；个别游戏（如 Dragon's Dogma Dark Arisen、Street Fighter IV 这类）对 DirectInput 支持更好，识别不到就换另一边。
- **多手柄与震动**：支持多只手柄同时连接与震动反馈，从 v11.0 起加入；手柄实现重做与手柄型号选择在 v11.1。你用的是本文网盘资源的 v10.0 Hotfix 的话，这两项没有，但单手柄的基础支持完整。

## 二、虚拟手柄（纯触屏玩法）

没有外设也能玩：Winlator 自带 Input Controls（输入控制）编辑器，在屏幕上叠一层虚拟按键。

- 进入方式：容器设置或运行游戏前的控制选项里，选择/编辑控制方案；
- 能改的东西：虚拟摇杆、按键的位置与大小，每个键映射到键盘键值或手柄键值；
- **给每个游戏配独立方案**：编辑好的方案可以保存成 profile，在快捷方式设置里指定（每个游戏用自己的一套布局，互不干扰）；
- **纯触屏建议关掉鼠标**：v8 起有「禁用鼠标输入」选项，专门配合虚拟手柄使用 —— 开着鼠标，手指点虚拟按键时容易误触光标。

老游戏用十字键+两颗键的简单布局就够；需要多键的 3D 游戏建议把常用键放在拇指自然落点，别照抄手柄位置 —— 屏幕上没有握持参照。

## 三、键鼠

USB 或蓝牙键鼠接上就能用，体验接近小电脑：

- **鼠标指针捕获**（v10 起的选项）：打开后外接鼠标的指针会被锁进游戏窗口里，玩第一人称、FPS 类游戏必开；
- **光标跟随触点**（v8 起的选项）：用手指点屏幕时光标移到手指位置，配合触屏操作 Windows 界面用；
- **音量键当按键用**：v11.1 起可以把音量上/下键绑定为游戏按键（网盘这份 v10.0 Hotfix 没有）；
- **打字**：容器里打字最稳的方式就是外接键盘；屏幕键盘在 v11.0 改进了拉丁字符的支持，重度输入场景建议配外设。容器内的中文输入现状见[怎么调成中文.md](怎么调成中文.md)第五节。

## 四、MIDI 设备

v10.1 起支持 MIDI 输入/输出设备，少数音乐类软件与游戏用得上。同样不属于网盘这份 v10.0 Hotfix 的功能范围。

## 五、没反应时先查这两处

1. **外设本身在安卓里能不能用**：先把蓝牙/USB 设备接在系统层面确认能识别，再进 Winlator；
2. **游戏的输入 API**：手柄在系统里正常、游戏里没反应，多半是 XInput/DirectInput 选错了边，换另一边再试。

排除之后还是不行，看[常见问题与闪退排查.md](常见问题与闪退排查.md)；游戏本身没导进去的，回[游戏怎么导入与运行.md](游戏怎么导入与运行.md)。
