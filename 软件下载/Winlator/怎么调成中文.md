# Winlator 怎么调成中文

> Winlator 官方界面暂时没有简体中文，容器里的中文游戏还常显示方块或乱码。本篇把这两件事分开讲清，各给可行做法。

## 一、先分清两件不同的事

说「调成中文」时，其实是两个互不相干的问题：

| 问题 | 原因 | 本篇对应 |
| --- | --- | --- |
| 应用自己的菜单是英文 | 官方没做简体中文界面 | 第二节 |
| 游戏里中文显示方块/乱码 | 容器里没有中文字体 | 第三、四节 |

先把这两件事分开，再对症处理，免得白折腾。

## 二、应用界面：暂时没有简体中文

官方内置的界面语言里，简体中文始终缺席：v10.1 的更新日志加入了葡萄牙语与俄语，截至 v11.2 的更新日志没有新增语言。也就是说，你装任何官方版本，菜单都是英文或上述语言。

现实的做法：

- 界面常用词汇就那几十个，配合本套文档的对照说明足够用（比如 Graphics Driver = 图形驱动、Screen Size = 分辨率，各篇里都有中文解释）；
- 想要官方中文，只能等后续版本 —— 关注官方 GitHub Releases 页即可；
- **不建议**为此去找所谓「汉化版」「修改版」安装包：来路不明的包有安全风险，出问题也查不到根源，装回官方版本最省心。

## 三、游戏内中文乱码：给容器装中文字体

游戏里的中文变成方块、问号或乱码，原因是容器（那个虚拟 Windows 环境）里没有中文字体，程序找不到字就只能显示占位符。解法是把一个中文字体装进容器 —— 这是社区里通行的做法，具体入口以你版本的界面为准：

1. **准备字体文件**：最稳妥的来源是你自己 Windows 电脑的 `C:\Windows\Fonts` 文件夹，把宋体（simsun.ttc）复制出来，传到手机的 Download 目录（传法见[游戏怎么导入与运行.md](游戏怎么导入与运行.md)第二节）。简体游戏用宋体即可。
2. **装进容器**：运行容器进入 Windows 桌面，打开文件管理器进 D 盘（对应手机 Download），把字体文件复制到 C 盘的 `windows\Fonts` 文件夹里；部分版本双击字体文件会弹出预览窗口，点「安装」也可以。
3. **重启容器**再进游戏，看中文是否正常。

繁体游戏（一些老 galgame、港台游戏）常用细明体（MingLiU），同样的方法放进 Fonts 目录。

## 四、乱码还在：补语言环境变量

字体装了仍乱码，再补一条环境变量：

1. 退出容器，在容器设置里找到 **环境变量（Environment Variables）** —— 就是官方给老游戏加 `MESA_EXTENSION_MAX_YEAR=2003` 的那个地方（位置说明见[容器与显卡驱动怎么选.md](容器与显卡驱动怎么选.md)第五节）；
2. 新增一条 `LC_ALL`，值为 `zh_CN.UTF-8`；
3. 保存并重启容器再试。

不是每个游戏都需要这一步：多数游戏字体装好就正常，个别游戏要靠这个变量把语言环境切到中文。两个手段都试过仍不行，看第六节。

## 五、中文打字的现状

容器里没有开箱即用的中文输入法：有用户反馈直接调安卓输入法打中文会失效，外接实体键盘是更稳的输入方式（键盘连接见[手柄键盘鼠标怎么用.md](手柄键盘鼠标怎么用.md)第三节）。只是给游戏填个角色名的话，用英文或拼音先凑合也是常见选择。容器内中文输入目前没有官方方案，别在这上面耗太久。

## 六、还是不行

- **只有个别游戏乱码**：那个游戏可能依赖特定字体，拿「游戏名 + 字体」去搜它的字体需求，按同样方法装进 Fonts 目录；
- **所有游戏都乱码**：确认字体真的进了 C 盘的 `windows\Fonts`（在容器的文件管理器里能看到），重启容器再试；
- **彻底没辙**：去官方仓库 [github.com/brunodev85/winlator](https://github.com/brunodev85/winlator) 的 Issues 搜「Chinese」「font」相关讨论；版本太旧的话先升级再试，安装包获取见[下载与安装教程.md](下载与安装教程.md)。
