## 一、装之前先看设备

Winlator 要跑在 **64 位（ARM64）安卓设备**上，手机、平板都可以，不需要 root。你在它里面运行的是 Windows（x86_64）程序，对硬件有实际消耗，动手前可以对照一下：

| 项目 | 建议 | 说明 |
| --- | --- | --- |
| 处理器 | 骁龙（Adreno GPU）机型优先 | 官方内置的 Turnip 驱动面向 Adreno，兼容性最好 |
| GPU | Mali 设备可用 Vortek 或 VirGL | Vortek 自 v10 起支持 Mali（官方更新日志），效果弱于 Adreno 方案 |
| 内存 | 6GB 起更稳 | 跑 3D 游戏时内存余量直接影响成败 |
| 存储 | 预留 5GB 以上 | 本体解压加每个容器里安装的游戏都要占空间 |

这是社区经验值；官方仓库没有公布硬性的最低安卓版本，装得上就能试。设备太旧跑不动的话，先看[是什么应用.md](是什么应用.md)第三节的预期管理。

## 二、从哪里拿安装包

正规来源有两个：

1. **官方 GitHub Releases**：[github.com/brunodev85/winlator/releases](https://github.com/brunodev85/winlator/releases) —— 开发者发版的唯一页面，认准 `brunodev85/winlator` 这个仓库，截至 2026-09 最新版为 v11.2。
2. **本文开头的 Winlator 安装文件资源（夸克网盘）**：撰写本文时保存的一份离线安装包，版本为 **v10.0 Hotfix**（包名 `com.winlator`，约 155.17 MB，MD5 `99681D7E5E1E8F10538F75FD98B48C01`）。访问 GitHub 不方便时，直接转存这一份即可安装。

两份都能正常用，区别只在版本号：v10.0 Hotfix 已能覆盖大多数老游戏与中等强度 3D 游戏；Steam 兼容、多手柄震动、HUD 显示这些是 v11.x 才加入的特性，有需要再去 Releases 页拿新版。

提醒：网上有一批以 Winlator 名义出现的第三方站点（winlator.dev、winlator.me、winlator.ru 等），它们不是开发者官网，页面内容互相矛盾。官方站点只有一个：[winlator.org](https://winlator.org/)，安装包认准官方 Releases 或上面的网盘资源。

## 三、安装步骤

1. **允许安装未知来源应用**（一次性设置）：系统设置 → 安全/隐私 → 安装未知应用，给你用来打开安装包的那个应用（浏览器或文件管理器）开权限。
2. **安装 APK**：在文件管理器里点开下载好的 Winlator 安装包，点「安装」。
3. **首次启动**：打开 Winlator，它会在第一次启动时释放内置的运行文件，低端设备可能要几分钟，这期间不要退出，等它自己完成。
4. **给存储权限**：首次启动会申请文件访问权限，允许它 —— 之后把游戏文件放进 Download 目录、在容器里读取，都靠这个权限。

## 四、装完第一件事：建容器

Winlator 装完还不能直接跑 Windows 程序，你要先建一个「容器」（一个隔离的 Windows 环境），程序都在容器里运行：

1. 主界面点 **+** 新建容器；
2. 起个名字，其余选项先不动；
3. 骁龙机型用默认设置即可；Mali 机型把图形驱动换成 Vortek 或 VirGL —— 怎么选见[容器与显卡驱动怎么选.md](容器与显卡驱动怎么选.md)。

建好容器后，下一步就是把游戏或软件放进去，见[游戏怎么导入与运行.md](游戏怎么导入与运行.md)。

## 五、装不上或打不开

- 安装时提示「无法安装 / 解析失败」：多半是安装包没下完整，重新下载再装；网盘那份的 MD5 见第二节，可用校验工具核对。
- 首次启动一直转圈：是在释放内置文件，耐心等完，别杀后台。
- 装好了但一开容器就闪退：见[常见问题与闪退排查.md](常见问题与闪退排查.md)。
