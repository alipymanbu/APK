# Winlator 是什么应用

> 一句话：Winlator 是一个安卓应用，让 Windows（x86_64）程序直接跑在安卓手机上。本篇讲清它的定位、能跑什么、跑不动什么，帮你决定装不装。

## 一、它的定位

Winlator 是巴西开发者 brunodev85 的开源项目（[github.com/brunodev85/winlator](https://github.com/brunodev85/winlator)），官网是 [winlator.org](https://winlator.org/)。它借助 Wine 与 Box86/Box64 两个开源组件，让你把 Windows 的 exe 程序装进它的「容器」里直接在手机上运行 —— 不用连电脑、不用串流，离线也能用。

几个常被问到的点：

- **免费开源**：没有订阅、没有内购，源码公开在 GitHub 上。
- **不需要 root**：普通权限即可运行。
- **同一游戏比电脑慢是正常的**：它跑的是 x86/x86_64 的 Windows 程序，程序指令在运行时被翻译给手机的 ARM 处理器，性能有折损。
- **程序存在「容器」里**：容器是隔离的 Windows 环境，相当于给每个用途建一台小电脑，具体见[容器与显卡驱动怎么选.md](容器与显卡驱动怎么选.md)。

## 二、能跑什么

- **老游戏与经典游戏**：DirectX 9 时代的 2D 与 3D 游戏，是兼容性最好的一档；DirectDraw 时代的最老游戏还有 CNC DDraw 这类专用包装器兜底。
- **DirectX 9/10/11 的 3D 游戏**：经 DXVK 或 WineD3D 转译，骁龙中高端机（845 及以上）跑多数此类游戏有可玩帧率。
- **DirectX 12 游戏**：官方从 v7 起引入 VKD3D，属于实验性支持，能起来的游戏有限。
- **Windows 下的工具软件**：.NET 程序可在容器里装 Wine Mono 后运行；部分人用它跑 Steam 上的老游戏（Steam 兼容在 v11.x 里持续改进）。

## 三、跑不动什么（预期管理）

- **新 3A 大作**：手机性能跟不上，帧率会明显低于 PC，调优空间见[怎么调最流畅.md](怎么调最流畅.md)，但调不出 PC 原生体验。
- **需要 DX12 特性较多的游戏**：VKD3D 实验性支持，起不来或不稳很常见。
- **对性能敏感的联网对战游戏**：翻译层本身有开销，帧数不稳时对局体验差。

同一份游戏在不同手机上表现差异很大，判断标准很简单：先用一个低分辨率容器试跑，跑得起来再逐步调高要求。

## 四、版本节奏与更新日志

版本号形如 `主版本.次版本`（如 v10.1、v11.2），发版节奏是 Beta → Final，出错就补 Hotfix。几个和你手上版本有关的节点：

- **v9.0**：新增图形驱动 Vortek（实验性）。
- **v10.0**：Vortek 支持 Mali 设备，改善 D3D9 游戏的动画与卡死问题。
- **v10.0 Hotfix**：给 Wine Mono/Gecko 安装加了备用下载地址，修复 Vortek 问题 —— 这是本文网盘资源的版本。
- **v10.1**：加入虚拟光驱 X:（可加载 ISO/BIN/CUE 镜像）、MIDI 设备支持、葡萄牙语与俄语界面。
- **v11.x**：Steam 兼容改进、多手柄与震动、HUD 模式、界面明暗主题、可作为前台服务常驻。

官方最新版到 2026-09 为 v11.2。注意：截至 v11.2 的更新日志，官方界面的内置语言只有英语、葡萄牙语、俄语，**暂无简体中文**；界面词汇对照与中文游戏显示的问题，见[怎么调成中文.md](怎么调成中文.md)。

## 五、外设支持

支持蓝牙或 USB 直连的手柄、键盘、鼠标，也支持自定义屏幕虚拟按键（纯触屏可玩）。v10.0 Hotfix 已有 XInput/DirectInput 选择与虚拟手柄编辑；多手柄、震动、手柄型号选择是 v11.x 加的。细节见[手柄键盘鼠标怎么用.md](手柄键盘鼠标怎么用.md)。
