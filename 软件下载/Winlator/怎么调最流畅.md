# Winlator 怎么调最流畅

> 同一个游戏在手机上比电脑慢是翻译层的正常代价，但顺序对了能把可玩性拉满。本篇给一套从见效最大到见效最小的调优顺序。

## 一、先有一个能看帧数的开关

调优前先把帧数显示打开，不然所有调整都是盲调：

- 容器设置里有 **Show FPS** 选项（v7 起就有），勾上后游戏画面会显示当前帧率；
- v11.0 加了独立的 **HUD 模式**，信息更全 —— 网盘这份 v10.0 Hotfix 用 Show FPS 就够。

## 二、调优顺序（从收益大到小）

### 1. 降分辨率

这是见效最猛的一档。在容器设置或快捷方式设置里改 **Screen Size**：1280×720 掉帧就降到 960×544，还卡就 800×600。老游戏在 800×600 下帧数经常直接翻倍，画面文字发虚可以接受就好。

### 2. 确认图形驱动没选错

骁龙（Adreno）机型必须是 **Turnip**；选成 VirGL 性能直接腰斩。Mali 机型在 Vortek 和 VirGL 之间都试一遍，谁快用谁。对照表见[容器与显卡驱动怎么选.md](容器与显卡驱动怎么选.md)第三节。

### 3. 换 DX 包装器

3D 游戏在 Adreno 上 **DXVK 通常明显快于 WineD3D**，跑 WineD3D 卡的游戏先换 DXVK 试试；反过来，DXVK 下花屏、闪退的游戏退回 WineD3D 换稳定。DirectDraw 时代的老游戏用 CNC DDraw。

### 4. 动 Box64 预设

容器设置 → Advanced 页的 **Box64 preset**：求帧数换性能向预设，官方文档明确说「不稳就先动 Box64 预设」。预设名以你版本里实际显示的为准。

### 5. 用快捷方式做逐游戏调优

不要在容器层面反复改 —— 容器是所有游戏共用的。正确做法是给每个游戏建快捷方式（见[游戏怎么导入与运行.md](游戏怎么导入与运行.md)第四节），在快捷方式设置里单独覆盖这一个游戏的分辨率、驱动、预设。这样 A 游戏的调优不会毁掉 B 游戏。

### 6. 游戏内设置同步降

容器外调完，游戏内的画质选项也要降：阴影、抗锯齿、视野距离这几个最吃性能，关掉立竿见影；内部分辨率缩放类选项优先调低。

## 三、官方点名的两个配方

这两条来自开发者仓库的官方建议，直接照抄：

| 问题 | 做法 |
| --- | --- |
| Unity 引擎游戏卡顿 | Box64 预设换 **Stability**，或在该游戏快捷方式的启动参数里加 `-force-gfx-direct` |
| 老游戏打不开 | 容器设置 → Environment Variables 加 `MESA_EXTENSION_MAX_YEAR=2003` |

## 四、进阶两招

- **CPU 亲和性**：容器设置里可以勾选核心，把性能核留给 Winlator；默认全勾即可，极端压帧数时再关掉小核试试。
- **前台服务**：v11.2 起可把 Winlator 设为前台服务常驻，避免切出去回消息被系统杀掉、回来重进游戏 —— 网盘这份 v10.0 Hotfix 没有此选项，玩的时候尽量别切后台。

## 五、调完还是不流畅

那就是设备性能到了上限。换低一档分辨率、换轻量游戏，或者升级到官方最新版试试（v11.x 对 Vortek、纹理解码、Steam 都有性能改进）。仍然异常卡顿、闪退的，按[常见问题与闪退排查.md](常见问题与闪退排查.md)排查，别当性能问题硬扛。
