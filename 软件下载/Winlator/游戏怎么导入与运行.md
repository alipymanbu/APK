# Winlator 游戏怎么导入与运行

## 一、前提：容器已经建好

导入游戏之前，先按[容器与显卡驱动怎么选.md](容器与显卡驱动怎么选.md)建一个容器并确认能启动到 Windows 桌面。游戏都装在容器里，容器没建好后面都无从谈起。

## 二、把游戏文件传到手机

1. 用数据线把手机连电脑（或用任意网盘/局域网传文件），把游戏文件复制到手机的 **Download** 目录（内部存储/Download）。建议给每个游戏单独建一个文件夹，方便管理。
2. 绿色版（解压即玩）整包复制；安装版把安装程序（setup.exe 之类）复制进去就行，装完可以删。

放 Download 目录的原因：进入容器后它就是现成的 D: 盘，不用折腾路径。

## 三、进容器安装或运行

1. 打开 Winlator，在容器上点菜单（⋮）→ **Run**，等它启动到 Windows 桌面；
2. 打开桌面上的文件管理器/资源管理器，进 **D: 盘** —— 它对应的就是手机的 Download 目录（这是社区教程一致的说法，以你版本里的实际盘符为准）；
3. 找到你刚复制的游戏文件夹：
   - **安装版**：双击 setup.exe，像在电脑上一样点完安装向导，装进容器的 C 盘；
   - **绿色版**：直接双击游戏主程序的 exe 就能跑。

安装大游戏需要耐心，手机上这一步比电脑慢不少。

## 四、建快捷方式，以后一键启动

每次进容器翻文件夹太麻烦，给游戏建一个桌面快捷方式：

1. 退出到 Winlator 主界面，点进你的容器；
2. 用内置的文件管理器找到游戏主程序的 .exe；
3. **长按这个 .exe**（或点它旁边的菜单图标），选 **Create Shortcut**；
4. 回到主界面，快捷方式已经出现，以后点它就直接进游戏。

快捷方式不只是启动入口，它还能**单独覆盖这一个游戏的设置**：长按主界面上的快捷方式 → Settings，可以为它单独改分辨率、图形驱动、DX 包装器、Box64 预设、额外的启动参数、专属的虚拟按键布局。容器里其他游戏不受影响 —— 这是调优的基本手法，见[怎么调最流畅.md](怎么调最流畅.md)。

## 五、光盘版游戏：ISO/BIN/CUE 镜像

部分老游戏运行时要读光盘。Winlator 从 **v10.1** 起内置虚拟光驱 X:，支持把 ISO/BIN/CUE 镜像挂载上去（开始菜单里的系统工具可加载镜像）。注意：本文网盘资源的版本是 v10.0 Hotfix，**没有**这个功能，有光盘版游戏需求的去官方 Releases 页升级新版。

## 六、Steam 游戏

Steam 客户端在 v11.x 里兼容性持续改进（v11.0 改进启动、v11.1 支持从开始菜单安装 Steam Legacy、v11.2 加了运行 Steam 游戏时的省内存选项），属于能用但吃配置的玩法，建议 8GB 内存以上的骁龙机型再试。网盘这份 v10.0 Hotfix 没有这些改进，Steam 需求请用新版。

## 七、游戏跑不起来怎么办

- 双击没反应、闪退、黑屏 → 逐项过一遍[常见问题与闪退排查.md](常见问题与闪退排查.md)；
- 能进游戏但卡成幻灯片 → 看[怎么调最流畅.md](怎么调最流畅.md)的调优顺序；
- 手柄/键盘没反应 → 看[手柄键盘鼠标怎么用.md](手柄键盘鼠标怎么用.md)。
