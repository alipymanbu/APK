## 一、你拿到的是什么权限

DirtyPipeRoot 给你的是**临时** root：它不往系统分区里写东西、不解锁 bootloader，靠内核漏洞在当前这次开机里拿到超级用户权限。**手机一重启，权限就没了**，要再用就得重新跑一遍。

这意味着两件事：出问题时重启就能回到原样，风险相对可控；同时它不是「一次 root 永久有效」的方案，每次开机都得重来。

## 二、跑之前的准备

- **连上 Wi-Fi**。执行过程中要联网下载 Magisk 框架，纯靠流量也能跑，但 Wi-Fi 下成功率更稳。
- **电量保持充足**。别在剩百分之几电的时候操作。
- **先备份重要资料**。虽然重启即恢复，但任何提权操作都带风险，重要数据先挪走，见 [常见问题与注意事项.md](常见问题与注意事项.md)。
- **先看机型过不过**。点开始测试拿到绿色结果再往下走，红色说明没戏，详见 [支持机型与系统版本要求.md](支持机型与系统版本要求.md)。

## 三、获取步骤

1. 打开 DirtyPipeRoot，点主界面的**开始**按钮做检测。
2. 看结果颜色：**绿色** = 可以获取临时 root；**红色** = 这台机器不行，到此为止，别反复试。
3. 绿色时，点右上角的**三个点**菜单，选其中的获取选项执行提权。
4. 等待执行完成。过程中应用会自动下载并安装 Magisk 框架，**耗时取决于网速**，网络正常时一般几秒就好；下载依赖网络，中途断网会导致这一步失败。
5. 执行完毕后，按下一节的方式确认权限真的到手了。

## 四、怎么确认成功了

提权完成后从这两处交叉验证：

- 桌面上出现了 **Magisk 应用**（它是自动装上的，不是你手动装的）；
- 有需要 root 的应用发起 `su` 请求时，会弹出授权窗口让你批。

两处都对上，说明临时权限已经生效，你可以开始做卸载预装、清理之类需要超级用户权限的操作了。若 Magisk 出现了但授权弹窗不出现，重启手机后按本篇步骤重新跑一遍即可。

## 五、重启之后

**重启 = 权限清零**，这是设计如此，不是故障：

- 开机后 Magisk 应用可能还在桌面上，但底层的临时权限已经失效，需要 root 的操作会全部失败；
- 想再用，重新打开 DirtyPipeRoot 按第三节再执行一次即可，不需要重装应用；
- 平时不打算用 root 功能时，重启一次就能让手机回到完全无提权的状态，这也是这类临时方案的安全底色。

## 六、拿到权限后能做什么

有了临时超级用户权限，常见玩法有这几类：

- **卸载系统预装应用**：那些平时「卸载」按钮是灰的系统 app，现在可以真正移除，省空间也少后台；
- **清理顽固广告软件**：对付赖在后台反复自启的那类；
- **深度释放存储空间**：扫掉普通权限碰不到的目录里的残留文件；
- **跑需要 root 的工具**：这类工具运行时会发起 `su` 请求，在授权窗口放行即可。

用完记得：**重启一次，权限就干净退场**。更多踩坑场景见 [常见问题与注意事项.md](常见问题与注意事项.md)。
