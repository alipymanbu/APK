# Magisk提示安装与更新时怎么办

> 临时 root 装上的 Magisk 会不停提示「安装」和「更新」—— 在 DirtyPipeRoot 这种未解锁 bootloader 的场景下，这些按钮不能乱点。本篇讲为什么危险、正确做法是什么、点错了怎么收场。

## 一、先说结论

拿到临时 root 后桌面上会多出一个 Magisk 应用。它打开后往往会提示「安装」「更新」或显示版本异常 —— **在本工具的场景下，一律不要点**。你只需要用它的「超级用户」页给应用授权，其它按钮全部忽略。

这不是保守，是有实打实的翻车案例：有公开的 Dirty Pipe root 项目在说明里明确写着「不要在 Magisk 应用里点安装，会导致手机变砖」；也有用户反馈（单一帖子口径，2026 年 9 月）在三星手机上临时 root 后点了一下 Magisk，手机再也进不了系统，最终走售后换了主板。

## 二、为什么这个按钮危险

把两件事放在一起看就明白了：

1. DirtyPipeRoot 给你的是**未解锁 bootloader** 状态下的临时权限 —— 系统分区的完整性校验并没有对你关闭；
2. Magisk 应用里的「安装 → 直接安装」做的正是**把自身写进 boot 分区**这类持久化改动。

平时走「先解锁 BL 再 root」那条路的用户点了没事，是因为解锁已经放开了校验；你这条临时路径没解锁，重启时校验一旦发现 boot 分区被动过、又无法通过验证，就可能卡在开不了机。**权限是临时的，点「安装」想做的事却是永久的** —— 这正是矛盾所在。

## 三、正确用法：只碰这两个地方

| 你想要的 | 该怎么点 |
| --- | --- |
| 给某个应用授权 root | 打开 Magisk → **超级用户**页 → 在列表里允许；或由该应用发起请求时在弹窗里点允许 |
| 查看 root 是否还在 | 看 [临时root获取教程.md](临时root获取教程.md) 的确认方法，重启后权限没了就重新执行一遍 |

**一律不点**：主界面上的「安装」「直接安装」「更新」，以及任何要你选镜像文件的入口。工具自动装好的这份 Magisk，在本次开机里已经能用，它提示的「安装」是给自己做持久化，你不需要。

## 四、更新提示怎么处理

Magisk 应用提示新版本时同样先忽略。真想更新，等你不再需要 root 的时候（重启后、或已卸载 DirtyPipeRoot）再更 —— 那时更新的只是一个普通应用的 APK，不涉及任何分区改动；而且没了 root 权限，它想写也写不进去，上面说的风险自然不存在。

## 五、如果已经点了

- 手机还能正常开机：什么都别再动，直接重启，临时权限本来就会清零；后续按本文只用超级用户页。
- 手机开不了机了：别反复强制重启、别继续在 Magisk 里试选项 —— 这类在未解锁设备上被改过关键分区的情况，案例反馈最终是走官方售后/线刷渠道解决的，你自己能做的补救非常有限。这也是 [常见问题与注意事项.md](常见问题与注意事项.md) 里把「先备份」放在第一条的原因。
