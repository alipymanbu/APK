## 一、安装前先核对三件事

| 检查项 | 要求 | 在哪看 |
| --- | --- | --- |
| 系统版本 | 安卓 5.2 及以上（安装包标注的口径） | 手机「设置 → 关于手机 → Android 版本」 |
| 存储空间 | 安装包约 129.38 MB，建议再预留 500 MB 以上空闲 | 「设置 → 存储」 |
| 安装来源 | 需要允许「安装未知应用」，见第三节 | —— |

OfferToday 主要面向香港求职场景，界面支持中文与英文（具体语言选项以 App 内为准）。手机号注册需要能正常接收短信，邮箱注册需要能收验证邮件。

如果你更习惯官方渠道，也可以在 App Store 搜「OfferToday」装 iOS 版；安卓官方应用商店上架情况以当地商店为准，本文只负责这份 apk 的安装。

## 三、允许安装未知来源应用

apk 不是从应用商店下载的，安卓默认会拦。以原生安卓 8 及以上为例：

1. 「设置 → 应用 → 特殊应用权限 → 安装未知应用」；
2. 找到你用来打开 apk 的那个应用（夸克、文件管理器或浏览器），打开它的「允许安装未知应用」开关；
3. 回到下载位置，重新点 apk 开始安装。

不同厂商的入口名称略有差异：小米/Redmi 在「设置 → 隐私保护 → 特殊权限」；华为/荣耀在「设置 → 安全 → 更多安全设置 → 安装外部来源应用」；OPPO/vivo 一般在「设置 → 安全 → 安装未知应用」。找不到就直接在系统设置里搜「未知」。

## 四、安装与首次打开

1. 点 apk →「安装」，等进度走完（Play Protect 或厂商安全扫描可能多花十几秒）；
2. 若弹出「未知应用」风险提示，确认安装包来自上文网盘且 MD5 与第二节一致后，选择「仍要安装」；
3. 打开 App，首次启动会请求通知、存储等权限，按需允许（通知权限影响后面说的职位提醒）；
4. 进注册页时需要选身份：找工作的选「求职者」，招人的选「僱主」——两种身份同一个账号可以随时切换，详见 [注册登录与账号管理.md](注册登录与账号管理.md)。

注册要求年满 18 周岁，这是官方服务协议里写明的门槛。

## 五、装不上 / 打不开的对照排查

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 「无法解析安装包」 | 文件没下完整 | 删掉重下；下载完成后核对第二节表格里的 MD5 |
| 安装到一半失败 | 存储空间不足 | 清出至少 500 MB 再装 |
| 提示「已存在同名更高版本」或签名冲突 | 手机里装过其他来源的 OfferToday | 卸载旧版再装（注意：卸载不会保留聊天与账号数据，先确认账号密码可找回） |
| 点开 apk 没反应 | 文件管理器没拿到安装权限 | 按第三节给文件管理器开「安装未知应用」 |
| 装好但一开就闪退 | 系统版本低于要求，或厂商兼容问题 | 核对安卓版本；仍闪退可把系统更新到最新再试 |
