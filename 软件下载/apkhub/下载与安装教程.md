## 一、开始前先了解的三件事

1. **它是什么**：apkhub 是一款装在安卓手机上的应用商店类工具，聚合软件与游戏资源，日常怎么用见 [怎么用.md](怎么用.md)；
2. **这版是什么**：本篇对应的安装包为 **4.1.2** 版，约 **29.41M**，包名 `com.dream.apkall`，系统要求 Android 5.2 及以上 —— 以你从网盘拿到的那份为准，网上介绍页写的版本号可能与此不同；
3. **它不在系统商店里**：apkhub 不通过系统自带商店分发，安装时 Android 会拦一道「未知来源」，下面第三节处理。

## 二、获取安装文件

打开 **apkhub 安装文件资源（夸克网盘）** [https://pan.quark.cn/s/9f8949f066f0](https://pan.quark.cn/s/9f8949f066f0)，把里面的 `apkhub_v4.1.2.apk` 转存到自己的网盘或直接下载，再弄到手机上：

- **手机端**：在夸克 App 里转存后，从「文件」里点开这个 APK，直接进入安装；
- **电脑端**：下载后用数据线、局域网共享等方式把 APK 传到手机存储，再在文件管理器里点开。

## 三、安装前的两处设置

1. **允许「安装未知应用」**：Android 8.0 起这项不再是全局开关，而是**按应用授权** —— 给你用来打开 APK 的那个应用（夸克、浏览器或文件管理器）开「允许安装未知应用」。入口一般在「设置 → 应用 → 特殊权限 → 安装未知应用」；个别品牌藏得深一点：

   | 品牌 | 常见入口（以手机实际菜单为准） |
   | --- | --- |
   | 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
   | 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
   | OPPO / 一加 | 设置 → 安全 → 安装未知应用 |
   | vivo | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
   | 三星 | 设置 → 应用 → 特殊访问权限 → 安装未知应用 |

2. **留够存储空间**：安装包约 29.41M，加上安装后的占用，手机剩余空间建议至少 100M。

## 四、安装步骤

1. 在文件管理器里点开 `apkhub_v4.1.2.apk`；
2. 系统弹「是否安装此应用」时点「安装」；
3. 装完点「打开」，或回到桌面点图标；
4. 首次启动若弹网络、存储等权限请求，按需允许 —— 网络权限必须给，否则内容加载不出来。

## 五、装完先核对一次

到系统「设置 → 应用」里找 apkhub，确认版本号显示 4.1.2、包名是 `com.dream.apkall`。对不上就说明拿到的不是这份安装包；想进一步校验安装包文件本身，用 MD5 比对，方法见 [版本核对与更新管理.md](版本核对与更新管理.md)。

## 六、装不上时

- **「解析包时出现问题」**：安装包多半在传输中损坏，回到第二节重新取一份再装；
- **点安装没反应**：回到第三节，确认「安装未知应用」的授权给对了那个打开 APK 的应用；
- **装上了却连不上、页面空白**：看 [常见问题排查.md](常见问题排查.md)。
