# apkhub 常见问题排查

> 本篇汇总 apkhub 最常见的几类故障：连不上、搜不到、下载失败、装不上、闪退，按现象给排查顺序。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [怎么用.md](怎么用.md) · [版本核对与更新管理.md](版本核对与更新管理.md)

---

> [!IMPORTANT]
> **apkhub 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/9f8949f066f0](https://pan.quark.cn/s/9f8949f066f0)

## 一、排查前先看这里

先确认两件事，能省掉大半弯路：

1. **手机网络正常**：随便开个网页或别的联网应用试试，先排除网络本身的问题；
2. **存储够用**：安装包约 29.41M，加上安装占用，剩余空间建议至少 100M。

对不上号就先看速查表，再跳到对应小节：

| 现象 | 先做什么 | 对应小节 |
| --- | --- | --- |
| 页面一直转圈 / 无法连接 | WiFi 与流量互换一次 | 二 |
| 搜索没结果 | 换关键词，再清缓存 | 三 |
| 下载失败 / 卡住 | 切网络、查存储 | 四 |
| 解析包出错 / 点安装没反应 | 重新取安装包、查「安装未知应用」授权 | 五 |
| 登录不上 | 核对账号、查网络 | 六 |
| 闪退 / 打不开 | 重启应用、清缓存、重装 | 七 |
| 应用内更新失败 | 清缓存重启，不行就重装 | 八 |

下面按现象逐项排查。

## 二、页面一直加载 / 提示无法连接

1. 在 WiFi 和移动数据之间切换一次再试；
2. 用同一网络打开其他需要联网的应用，确认不是网络问题；
3. 网络正常但 apkhub 还是连不上，多半是它的服务端临时不可用，过段时间再打开；
4. 还有一种情况：你要打开的内容本身要从谷歌商店拉取（见 [怎么用.md](怎么用.md) 第三节），网络访问不了谷歌时这一步会一直卡住，换到能访问谷歌服务的网络环境再试。

## 三、搜索没结果

1. 确认关键词没有错别字，换个说法再搜一次；
2. 清一下应用缓存（系统「设置 → 应用 → apkhub → 存储 → 清除缓存」），再重启 apkhub；
3. 清缓存无效就重启手机再试；仍不行可能是服务端问题，稍后再试。

## 四、下载失败 / 进度卡住

1. 切换网络后重试；
2. 检查剩余存储是否够；
3. 从最近任务里划掉 apkhub，重新打开再下；
4. 反复失败就先放一会儿再试 —— 服务端波动时，隔一段时间点一次比连续反复点有效。

## 五、装不上 / 提示解析包出错

- **「解析包时出现问题」**：安装包多半在传输中损坏或不完整，重新从 apkhub 安装文件资源（夸克网盘）[https://pan.quark.cn/s/9f8949f066f0](https://pan.quark.cn/s/9f8949f066f0) 转存、下载一次，再装；
- **点安装没反应**：检查「安装未知应用」的授权给对了打开 APK 的那个应用没有，完整步骤见 [下载与安装教程.md](下载与安装教程.md)；
- **提示与已装应用冲突**：先卸载旧版本再装新的。

## 六、登录不上

1. 核对账号与密码（如果该版本需要登录才能用）；
2. 确认网络正常；
3. 以上都排除后还是登不上，多半是服务端问题，稍后再试。

## 七、闪退或打不开

1. 从最近任务划掉 apkhub 再重新打开；
2. 清除缓存（方法见第三节）后重试；
3. 还闪退就卸载重装，安装包从开头的 apkhub 安装文件资源（夸克网盘）重新取；
4. 重装后仍闪退，确认系统版本满足要求（安装包标注 Android 5.2 及以上）。

## 八、更新失败

应用内更新失败时：清缓存 → 重启应用 → 再试一次；仍失败就卸载后重新安装，安装包获取与核对见 [下载与安装教程.md](下载与安装教程.md) 和 [版本核对与更新管理.md](版本核对与更新管理.md)。
