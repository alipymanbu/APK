## 一、先分清两种运行模式

JsxposedX 在不同的手机环境里能用起来的方式不止一种，动手前先对号入座：

| | 免 Root 虚拟环境 | Root + LSPosed/Xposed 环境 |
| --- | --- | --- |
| 前提 | 普通手机，无需解锁 Bootloader | 手机已 Root，LSPosed/Xposed 已激活 |
| 上手难度 | 低，装上就能跑 | 前期要把框架环境搭好 |
| 适合 | 先体验功能、做轻量调试 | 长期稳定的正式分析环境 |
| 官方文档口径 | 应用介绍中写明支持免 Root 虚拟环境加载模块 | 官方快速开始把 Root 与 LSPosed/Xposed 激活列为前置条件 |

两种模式的功能表现不完全一致，部分拦截能力在个别系统版本或个别应用上会受限。你如果不确定自己的场景该走哪条路，可以先用免 Root 模式把流程跑通，再决定要不要搭正式环境。

还要留意一点：免 Root 模式依赖应用的虚拟化环境，个别厂商 ROM 对这类环境限制较严，应用可能起不来或功能异常。遇到这种情况先看 [模块加载与作用域.md](模块加载与作用域.md) 第五节的说法，再决定换模式还是换设备。

## 二、环境检测面板在哪、看什么

打开 JsxposedX 首页就是环境检测面板，四项状态分别对应：

| 状态项 | 含义 | 不正常时影响什么 |
| --- | --- | --- |
| Root | 是否取得 Root 权限 | 走 Root 模式的功能 |
| Xposed | LSPosed / Xposed 是否处于激活状态 | Xposed 项目相关脚本与模块加载 |
| AI | AI 服务是否可达 | AI 分析、AI 辅助功能 |
| Frida | Frida 环境是否就绪 | Frida 注入脚本 |

官方建议的检查顺序是 **Root → Xposed → AI → Frida**：先把运行模式的地基（Root 或虚拟环境）确认了，再看框架激活，最后才是 AI 和 Frida 这两个按需项。

## 三、每一项的核对办法

1. **Root**：走 Root 模式才需要。确认你的 Root 管理器（Magisk/KernelSU 之类）里已经给 JsxposedX 授权。
2. **Xposed**：确认 LSPosed（或你用的同类框架）已安装并激活，且 JsxposedX 已勾选进作用域；勾完通常要重启系统才生效。
3. **AI**：这一项在 AI 配置完成并测试通过后才会正常。配置方法见 [AI功能配置与使用.md](AI功能配置与使用.md)，不用 AI 功能可以不管它。
4. **Frida**：需要对应的 Frida 模块与配置就绪，官方单独维护了一个 Frida 模块仓库 [`github.com/dugongzi/jsxposedx-frida`](https://github.com/dugongzi/jsxposedx-frida)。不用 Frida 也可以先跳过。

## 四、检测通过之后

面板各项正常后，回首页按官方推荐流程走：

1. 需要 AI 的，先完成 AI 配置并点「测试连接」；
2. 添加你的目标应用；
3. 按任务选择入口：快捷功能、AI 分析、Xposed 项目或 Frida 项目。

入口怎么选、每个入口里有什么，见 [项目管理与快捷功能.md](项目管理与快捷功能.md)。面板某一项一直显示异常、反复排查无果的，把现象对照 [常见问题与注意事项.md](常见问题与注意事项.md) 里的清单过一遍。
