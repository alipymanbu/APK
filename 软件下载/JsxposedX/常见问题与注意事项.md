## 一、开关开了，目标应用里没反应

按这个顺序排查，多数情况能定位：

1. **确认目标应用是从 JsxposedX 里启动的**。开关只对它拉起的应用生效，你从桌面直接点开目标应用，改动不会体现。
2. **确认开关所在的项目对应的就是这个应用**。工作区按应用隔离，A 项目的开关管不到 B 应用。
3. **核对模块作用域**。模块只对勾进作用域的应用生效，新装模块或换目标应用后先核对两边有没有互相勾上，细节见 [模块加载与作用域.md](模块加载与作用域.md)。
4. **改完开关后重启一次目标应用**。已在运行的应用不会热生效。
5. **看环境检测面板**。Xposed 项异常时模块类功能整体不工作，先解决环境，见 [环境检测与运行模式.md](环境检测与运行模式.md)。
6. **应用自身的限制**。部分系统版本或个别应用会限制拦截能力，这类无解，换环境或换目标验证。

## 二、AI 那一项一直异常

十有八九是配置问题，按五条顺序查：API 类型对不对 → Base URL 是不是 API 端点 → 有没有多拼请求路径 → 模型名写法 → API Key 里有没有空格换行。完整步骤与示例在 [AI功能配置与使用.md](AI功能配置与使用.md) 的排查一节。不用 AI 功能的话，这项异常不影响其他功能，可以放着不管。

## 三、升级版本要注意什么

- 你网盘里那一份是 6.0.2（2026-09-23 整理），官网最新版可能更高，升级以官方发布页为准。
- **升级前先导出项目里的脚本与日志**。卸载重装（签名冲突时的常规处理）会清空工作区数据。
- 升级后第一次打开，先回首页看环境检测面板再干活，6.0.2 这版本身就调整过面板识别逻辑与工作区日志存储。

## 四、这个工具允许用在什么场景

官方在 README 里把边界写得非常明确，转述如下：

**允许的用途**：软件调试、程序分析、内存机制学习、开发测试、授权环境下的研究。

**明确禁止**：游戏作弊与外挂、自动化违规操作、干扰服务器或客户端正常运行、未授权修改第三方程序数据、违反法律法规或平台规则的一切使用。

配套的三条提醒：

1. 免 Root 不等于能突破应用自身的安全防护，别指望它绕过一切；
2. **脚本来源要甄别**，社区里现成的脚本不要来路不明就加载进自己手机；
3. 对线上应用做操作可能触发平台风控，影响你自己的账号，责任由使用者自担。

简单说：在自己的设备、自己的账号、获得授权的环境里做学习与调试，没问题；越界使用的后果官方明确不兜底。
