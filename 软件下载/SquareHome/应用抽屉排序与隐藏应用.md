# Square Home 应用抽屉排序与隐藏应用

> 本篇讲 Square Home 应用抽屉的用法：智能排序的逻辑、固定按名称排、搜索，以及把不想见的应用藏起来再找回来的完整做法。

## 一、抽屉在哪

两种用法：

- 从主页上的抽屉磁贴或磁贴组里点开；
- 整页铺开：在页面管理器按「新建页面」时选应用抽屉，让它独占一页，左右滑动就能到。

抽屉顶部带搜索框，装了几百个应用时，搜索比翻页快得多。

## 二、智能排序是怎么回事

抽屉底部菜单栏上的排序按钮是**临时排序**，只对当前这一次生效。想固定排序方式，到 `Home options` → `App drawer` → `Sort order`：

- **Smart**（默认）：按使用习惯排。它会记录你每次打开应用的时间段、所在位置、耳机插没插，把「这个场景下你最可能用」的应用顶到前面——早上是天气和资讯，插上耳机是播放器。顶部挑选的数量可以在抽屉选项里调；建议先用几天再决定要不要换。
- **Name**：老老实实按名称排，位置永远稳定，适合「我就要固定顺序」的人。

## 三、搜索的几个省力技巧

- **索引字母滑动搜索**：不用先点放大镜再点字母——手指按住放大镜图标直接滑到索引字母上松手，一步到位。
- **非英文名的应用也能按英文名搜**：界面语言不是英文时，用英文名首字母（比如 M）也能搜到本地图标叫「地图」的应用，官方在索引里同时匹配了英文名。
- **一个字母命中太多时**：选索引里的 `...` 进入多字母输入搜索；想让它成为默认搜索方式，把抽屉选项里的 **Use search index** 关掉即可。
- **快速滚动**：排序方式为 Smart 或 Name 时，在抽屉**右缘上下滑动**可以按首字母快速定位。

## 四、隐藏应用与找回

把不常用的、或不想被人一眼看到的应用从抽屉里藏掉：

1. 在抽屉里长按该应用；
2. 按图标上的 `-` 按钮，它就从列表里消失。

注意两点：

- 桌面上已有的磁贴不跟着消失，要一并处理得去磁贴上删；
- **藏了不等于删了**：点抽屉底部菜单栏的标签按钮，选 `hidden` 分类，所有被藏的应用都在这里，长按再按 `+` 就恢复显示。

## 五、两个进阶玩法

- **Windows Phone 式右滑抽屉**：把应用抽屉作为独立页面添加到主页**右侧**（页面管理器 → 新建页面 → 应用抽屉），左右滑动就能从磁贴页滑进应用列表——这正是老 Windows Phone 的操作方式。
- **抽屉排序临时切一下**：抽屉底部菜单栏的排序按钮只影响当次浏览，找完东西就恢复默认；不用为了一次性的查找去改持久设置。

## 六、联系人直达

联系人同样能做成磁贴或独立页面：新建页面时选 Contacts，常用联系人一人一块磁贴，点开直达，不用进通讯录一层层翻。大磁贴、少层级的组合，也很适合给长辈布置手机。
