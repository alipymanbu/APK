## 一、这是一款什么应用

Square Home 是一款安卓第三方桌面启动器（launcher），把主屏换成 Windows Phone / Windows 10 那种 Metro 磁贴风格：所有应用变成大小不一的方块磁贴，页面内纵向滚动、页面之间横向滑动。开发者在 Google Play 上的署名是 Total_Apps，官方版本免费、无广告；官方博客（FAQ 也在上面）见 [squarehome2.blogspot.com](https://squarehome2.blogspot.com/)，商店页面为 [Google Play 上的 Square Home](https://play.google.com/store/apps/details?id=com.ss.squarehome2)。

它适合的人群很明确：

- 用过 Lumia 或 Windows Phone，想找回磁贴桌面的老用户；
- 装的应用多、觉得常规图标网格翻页太累的人——磁贴布局信息密度高，一屏能放下更多常用入口；
- 平板等大屏设备用户——官方对大屏做了专门适配。

本文的版本号、体积等以文首网盘资源里的 3.4.10 安装包为准；官方后续仍在更新，新版本的界面与选项可能略有差异，以官方页面为准。

## 三、安装步骤

1. 从 SquareHome 安装文件资源（夸克网盘）（见文首引用块）把安装包转存到自己的网盘，再下载到手机；也可以先下到电脑，再用数据线传到手机。
2. 在手机上点开安装包。系统提示「禁止安装未知来源应用」时，按提示允许「来自此来源的应用」即可，装完可以把开关关回去。
3. 安装完成后，桌面上会出现**两个图标**：`Square Home` 和 `Home options`（启动器设置）。前者是桌面本体，后者集中放了全部设置项——不是装重复了，别把其中一个当垃圾卸掉。

## 四、首次启动与设为默认桌面

1. 点开 `Square Home`，第一次会进入快速设置向导（Quick setup wizard），跟着走几步就能生成一个可用的磁贴主页。
2. 按主页键时系统可能弹出「选择主屏幕应用」，选 `Square Home` 并勾选「始终」。
3. 没弹出来的话手动设置：系统设置 → 应用 → 默认应用 → 主屏幕应用（不同机型叫法略有差异，关键词是「主屏幕 / Home / 桌面」），选 `Square Home`。
4. 想换回原来的桌面：在同一处「主屏幕应用」里选回系统桌面即可，Square Home 里做的布局不会因此丢失。

设了默认桌面又被弹回选择框，或重启后变回原桌面，按这三条排查：

- **装了多个桌面类应用在互相抢占**（之前试过的其他启动器也算）：把不用的启动器卸载或停用，再设一次默认；
- **省电策略把它当后台应用清理了**：把 Square Home 加入电池优化白名单（设置 → 电池 → 电池优化，找 Square Home 改为「不允许优化」）；
- 设完**重启一次**，让系统把默认项固定住。

各品牌的定制系统（MIUI、ColorOS 等）还可能有自己的「锁定桌面」或「默认应用管理」入口，位置以你的机型为准。

## 五、卸载时的两个坑

- **先解除设备管理员**：如果你用过 Square Home 的「锁定屏幕」动作，它可能被激活为设备管理员，直接卸载会提示失败。先到 系统设置 → 安全 → 设备管理器（部分机型叫「设备管理应用」）取消激活，再卸载。
- **先切回原桌面**：它还是默认桌面时直接卸载，部分机型会反复弹「默认应用已失效」。先在「主屏幕应用」里切回系统桌面，再卸载就干净了。

## 六、装完先做哪几件事

- 跟着向导生成第一版主页，之后随时可以重构，方法见[磁贴编辑与页面管理.md](磁贴编辑与页面管理.md)；
- 到 `Home options` 里把磁贴列数、色调调成自己顺手的；
- 动手改布局前先做一次备份，出问题一键还原，步骤见[备份恢复与常见问题.md](备份恢复与常见问题.md)。
