# Square Home 动态磁贴与小组件设置

## 一、让磁贴显示通知与未读数

`Home options` → `Live tile` 里有三条路，可以叠加着用：

| 方式 | 工作方式 | 特点 |
| --- | --- | --- |
| Notifications | 读取状态栏通知，把内容推到对应应用的磁贴上 | 需要授予通知使用权；计数按通知推算，不一定准 |
| Unread Gmails | 直读 Gmail 收件箱的未读数 | 需要额外授权；Gmail 的计数比通知方式准 |
| 第三方角标 API | 兼容部分厂商与启动器定义的角标接口 | 只有少数应用支持，有比没有强 |

建议把 **Use notification icon** 保持开启：磁贴会在应用图标与通知文字 / 图片之间轮播，好认也好用。不想看文字或图片的话，分别关掉「关闭通知文本」「关闭通知图片」两个开关。

## 二、通知突然不显示了

最常见于国产系统：通知权限还开着，但 Square Home 的后台服务被省电策略杀掉了。按这个顺序排查：

1. 系统设置里找到 Square Home 的电池策略，改成「无限制 / 不受限」；
2. 国产系统再看「自启动 / 关联启动」这类开关；
3. 还不行就把通知使用权关掉再重新授予一次。

各家厂商的省电选项名称五花八门，按你的机型搜「{品牌} 应用后台保活」能找到对应位置。

## 三、磁贴上的音乐控制

播放音乐或视频时，对应媒体应用的磁贴上会自动出现播放 / 暂停控制。YouTube、Poweramp 这类主流播放器都支持——在磁贴上直接按一下就能暂停，不用切进应用。

## 四、内置小部件一览

以下内置件都从 `+` 磁贴 → `Widget` 里添加，耗电与内存开销都小：

- 时钟类：模拟时钟、数字时钟、日历、事件日历；
- 状态类：电池环、内存环、存储环、SD 卡环、系统监视器；
- 工具类：手电筒、指南针；
- 装饰类：照片幻灯片（轮播一个文件夹里的图片）。

照片幻灯片读不到 SD 卡里的图，多半是选目录时没进到 SD 卡的挂载路径：要选到 `/storage/XXXX-XXXX/你的图片文件夹`（`XXXX-XXXX` 是系统给 SD 卡分配的 ID），按文件夹名字直接找是找不到的。

## 五、加第三方小组件

1. 按 `+` 磁贴 → `Widget` → `Android widget`，从系统小组件列表里挑一个；
2. 小组件内容显示不全时，长按它 → 选项图标 → `Margins`，把边距改成**负值**，内容就能铺满整块磁贴。

第三方小组件有个通病：恢复备份或换机后需要逐个重新配置，原因与处理见[备份恢复与常见问题.md](备份恢复与常见问题.md)。

## 六、内存与耗电

- 桌面卡、内存吃紧：把重小组件收进**磁贴组**——组没打开时里面的组件不会创建；图片尽量用 jpg 而不是 png。
- 疑似耗电：这个应用本身在后台基本不干活。到系统设置的「电池用量」报表里核对，如果它占得多，通常是某个第三方小组件的问题，逐个移除就能定位。
