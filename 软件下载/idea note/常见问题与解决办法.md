# Idea Note 常见问题与解决办法

> 工具条不见了、语音识别不出字、提醒不响、卸载不掉……这篇把 Idea Note 用起来最容易卡住的问题集中列出。

## 一、屏幕边缘的工具条不见了

按顺序查：

1. **悬浮窗权限还在不在**：系统设置 → 应用 → Idea Note → 「显示在其他应用上层」，重新允许一次。部分系统在应用更新或重启后会回收这个权限。
2. **是不是被一键清理杀掉了**：电池优化放行、最近任务里锁定卡片，完整步骤见 [悬浮窗与快捷唤醒怎么设置.md](悬浮窗与快捷唤醒怎么设置.md)。
3. **重启一次 Idea Note**，让悬浮服务重新挂上。

## 二、语音识别不出字 / 没反应

按「一个字不出」「出了但错得多」「个别词反复错」三种情况分开排查，完整方法见 [语音识别不准怎么调.md](语音识别不准怎么调.md)。最基础的两条：

1. **麦克风权限**：系统设置 → 应用 → Idea Note → 权限 → 麦克风，选允许。
2. **联网**：识别需要网络。断网时录音可能照录，但出不了文字。

## 三、长按 Home / 音量减唤不出来

- 长按 Home 在多数系统上要先把 Idea Note 设为「辅助应用」才生效，各品牌设置路径见 [悬浮窗与快捷唤醒怎么设置.md](悬浮窗与快捷唤醒怎么设置.md)。华为等部分系统不支持改长按 Home 的行为，这类机型用音量减或侧边工具条。
- 音量减只占「长按」动作，短按调音量不受影响；唤不出来时回设置里确认选的是音量减唤醒。
- 3.5.8 移除了辅助功能入口，网上旧教程让你去开辅助功能的那一步可以跳过。

## 四、提醒到点不响

1. **通知权限被关**：系统设置 → 应用 → Idea Note → 通知，打开。
2. **后台被清**：电池优化放行、最近任务锁定，见 [悬浮窗与快捷唤醒怎么设置.md](悬浮窗与快捷唤醒怎么设置.md)。
3. **免打扰拦截**：部分系统的免打扰时段会吞掉提醒通知，需要在免打扰规则里单独放行。

## 五、卸载按钮是灰的 / 卸载失败

如果你在应用内开启过「设备管理器」权限，系统会禁止直接卸载。先到系统设置的安全（或设备管理器）页面，取消 Idea Note 的激活，再正常卸载。

## 六、同步失败 / 新手机看不到旧数据

- 先确认登录的是**同一个分区**（国区 / 港区）的账号，两个分区数据不互通；分区选错看到的就是一个空账号。
- 在应用里手动点一次同步按钮再看结果；上传额度耗尽时语音会同步不上去，额度说明见 [云端同步与换机迁移.md](云端同步与换机迁移.md)。
- 国区同步域名有过无法访问的用户反馈（2023 年的记录），同步一直转圈时可以稍后再试，或换一个分区验证。

## 七、安装失败

1. **安装包不完整**：重新下载后核对大小 38.26M 与 MD5，数值见 [下载与安装教程.md](下载与安装教程.md)。
2. **包名冲突**：手机里如果装过其他渠道的 Idea Note，先卸载旧的再装。
3. **存储空间不足**：清出足够空间再装。

## 八、这个应用还在更新吗

有用户反馈它的版本停在 2024 年的 3.5.8，此后未见更新；酷安页面挂的版本号与 Google Play 渠道也互不相同。已装应用的本地功能（记录、悬浮窗、提醒）不受停更影响，照常能用；但云同步服务能否长期可用取决于开发者一侧，重要便签建议定期自行备份一份，别把它当成唯一的存放处。
