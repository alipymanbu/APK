# Idea Note 悬浮窗与快捷唤醒怎么设置

> Idea Note 的核心体验是「任意界面调出胶囊」，这篇讲悬浮窗权限怎么开、有哪几种唤出方式、怎么防止它被系统清掉。

## 一、先把悬浮窗权限打开

1. 打开 Idea Note，进入「设置」。
2. 找到悬浮便签（悬浮窗）的开关，点击启用。
3. 系统会跳到「显示在其他应用上层」的授权页，把 Idea Note 设为允许。
4. 返回应用，开关生效后，屏幕边缘会出现一条工具条。

不开悬浮窗时，你仍然可以从通知栏进应用正常记录；但「侧边调出」「任意界面速记」这两个玩法都依赖悬浮窗权限。

## 二、三种唤出方式

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| 侧边工具条 | 点一下工具条，或从屏幕边缘向左滑 | 最常用，任何界面都能调出 |
| 通知栏 | 下拉通知，点 Idea Note 的通知 | 工具条被误关、或暂时不想让它悬浮时 |
| 物理按键快捷唤醒 | 见下一节 | 开车、单手、不方便触屏滑动时 |

## 三、快捷唤醒：长按 Home 或音量减

在「设置 → 快捷方式 → 快捷方式唤醒」里可以选：

- **音量减（建议先试这个）**：长按音量减键唤出记录窗。它只占用「长按」这个动作，短按调音量不受影响。
- **长按 Home**：多数系统要先把 Idea Note 设为「辅助应用」才能生效，各品牌路径不同：
  - 通用路径：设置 → 辅助应用，选择 Idea Note。
  - MIUI：设置 → 更多应用 → 右上角「默认应用设置」→ 语音助手 → 系统快捷唤醒 → 选 Idea Note。
  - 一加：设置 → 按键 → 长按操作 → 选「搜索助手」（需要装有 Google 服务）。
  - 华为等部分系统不支持修改长按 Home 的行为，这类机型用音量减或侧边工具条。

注意：3.5.8 这一版已经移除了「辅助功能」相关入口，网上旧教程会让你去开辅助功能权限，新版里没有这个选项是正常的，跳过那一步即可。

## 四、防止后台被系统清掉

悬浮窗和快捷唤醒都要求 Idea Note 常驻后台。国产系统默认会杀后台，被清掉之后工具条就消失、语音也录不了。按这五步设置：

1. **电池优化**：系统设置 → 电池 → 电池优化，找到 Idea Note 选「不优化 / 允许后台运行」。
2. **通知使用权**：系统设置里的「通知使用权」（部分系统叫通知读取权限），给 Idea Note 打开，防止被一键清理误杀。
3. **设备管理**：按应用内提示激活「设备管理器」。这条有副作用：卸载 Idea Note 之前要先到系统设置里取消激活这个权限，否则卸载按钮是灰的，详见 [常见问题与解决办法.md](常见问题与解决办法.md)。
4. **最近任务锁定**：打开最近任务列表，把 Idea Note 的卡片锁定（出现小锁图标），一键清理时就轮不到它。
5. **自启动**：多数国产系统在应用管理（或应用信息）里另有「自启动」开关，把它打开，系统重启后工具条才能自己回来。

设置完锁屏再亮屏试一次：工具条还在，说明防杀生效了；还是消失的话逐条回查，各家系统的入口名称差异见 [常见问题与解决办法.md](常见问题与解决办法.md)。
