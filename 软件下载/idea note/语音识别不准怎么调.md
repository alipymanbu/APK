# Idea Note 语音识别不准怎么调

> 分三种情况排查 Idea Note 的语音识别：完全不出字、错字偏多、个别词反复出错；每种给对应的处理办法。

## 一、先分清是哪种「不准」

| 现象 | 多半是 | 去哪节 |
| --- | --- | --- |
| 说了半天一个字都没出 | 权限或网络问题 | 第二节 |
| 字出了，但错得多 | 环境、语速、说话方式 | 第三节 |
| 别的都对，某几个词反复错 | 专有名词、同音字 | 第四节 |

## 二、完全不出字：先查权限和网络

1. **麦克风权限**：系统设置 → 应用 → Idea Note → 权限 → 麦克风，选「允许」。在悬浮窗里录音走的是同一个权限，这里关了哪都录不了。
2. **确认联网**：识别需要联网，断网时录音可能照录、文字出不来；等恢复网络后这条不会自动补转写，需要重录或手动补字。
3. **说话时机**：先点麦克风、看到录音状态再开口；开口太早，前几个字可能没被录进去。

## 三、错字偏多：改环境、改说法

- **贴近手机、避开噪音源**：地铁、风扇、电视声都会抢识别；能换个安静处就换，不行就把手机拿近一点。
- **语速放慢、句间停顿**：连续长句连说不断，丢字和粘连都会变多。
- **一条胶囊只说一件事**：按「对象 + 要做的事 + 时间」的顺序说，例：「周三下午三点给房东转房租」。一句话塞进好几件事，回头整理更费劲。
- **中英混说先拆开**：一句话里中英文夹着说，错字通常更多；英文词单独记一条更稳。

## 四、个别词反复错：用原声对照改

Idea Note 每条语音便签都保留原声，这是纠错最直接的抓手：

1. 点开识别结果，重听一遍原声，确认自己当时说的是什么。
2. 对照原声把错字改掉 —— 尤其人名、地名、App 名、数字这类专有名词，机器最容易错，你看原声一眼就能定。
3. 反复出现的固定说法（比如某个项目名），记完顺手改一次，之后听到那段录音就知道该改成什么。

改不动的情况：录音本身含糊（当时语速太快、环境太吵），就别逐字抠了，按记忆重录一条，比改十处错字快。

## 五、还是不行的时候

- 悬浮窗里录没反应、应用里正常：回查悬浮窗权限和后台保活，步骤见 [悬浮窗与快捷唤醒怎么设置.md](悬浮窗与快捷唤醒怎么设置.md)。
- 权限、网络都正常却长期一个字不出：先退出应用重开一次，再不行就重启手机；最后才考虑卸载重装（重装前先把便签同步或备份好，迁移要点见 [云端同步与换机迁移.md](云端同步与换机迁移.md)）。
