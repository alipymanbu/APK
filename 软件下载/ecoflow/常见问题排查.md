## 一、搜不到设备 / 配对不上

按顺序核对：

1. 设备开机了吗？屏幕亮起、电量指示正常才算开；
2. 手机的蓝牙和 Wi-Fi 都开着，搜索走的是其中一种，都开最稳；
3. 手机离设备近一点，隔一两堵墙就会明显变差；
4. 这台设备是不是已经绑在别人的账号下——一台设备只绑一个账号，被绑过的设备不会出现在你的搜索列表里，先让原账号解绑；
5. 蓝牙搜索只显示「尚未添加过」的设备，之前加过的话直接去设备列表里找，不用重新搜。

## 二、配网一直失败

- **路由器是 2.4 GHz 吗**：设备目前只支持 2.4 GHz Wi-Fi，5 GHz 频段搜不到。双频路由器常把两个频段拆成两个名字（一个带 5G 字样），认准不带 5G 的那个连；
- **密码对不对**：密码错设备就上不了网，删掉重新输入；
- **Wi-Fi 图标闪烁了吗**：配网要求先长按 IOT 键让图标闪起来，图标不闪说明设备还没进入配网状态，重按一次；
- **家里 Wi-Fi 本身能上网吗**：设备连上一个断网的 Wi-Fi，结果一样是离线，先拿手机连同一个 Wi-Fi 验证。

## 三、设备显示离线

- IoT 模式下设备离线，基本是「设备端断网」：路由器重启过、设备离路由器太远、家里停电都会导致；
- 设备重新联网后，App 这边不一定立刻恢复，重新打开设备列表等它刷新；
- 户外没有 Wi-Fi 时改用直连或蓝牙，步骤见 [设备连接与配网方法.md](设备连接与配网方法.md) 的第四、五节；
- 直连模式下如果手机自己连回了家里的 Wi-Fi，设备就会从列表里消失，这是正常的，直连就守着那一台。

## 四、直连模式的几个「不能」

| 现象 | 原因 |
| --- | --- |
| 升级不了固件 | 直连模式下手机连的是设备热点、没有互联网，固件升级做不了 |
| 解绑操作点不动 | 同上，解绑需要联网 |
| 列表里只有一台设备 | 手机同时只能连一个 Wi-Fi，直连模式一次只对着一台 |
| Wi-Fi 图标一直闪 | 直连模式下图标本来就一直闪烁，不是故障 |

这些都不是设备坏了，重启设备回到 IoT 模式就恢复正常。固件升级升不了、升级中途卡住的情况，单独整理在 [固件升级步骤与失败处理.md](固件升级步骤与失败处理.md)。

## 五、收不到验证码 / 忘记密码

- 验证码 5 分钟内有效，过期就重发；收不到先翻垃圾邮件或拦截记录，再点「没有收到验证码」按页面提示重试；
- 忘记密码走登录页的「忘记密码」，用账号对应的邮箱或手机号接验证码后重设；
- 设备绑定在账号上，换手机用同一账号登录后设备列表还在，不用重新配网。

## 六、以上都对不上

对照 [下载与安装教程.md](下载与安装教程.md) 核对安装包版本、换一版安装包重装，仍解决不了就通过官网的客服支持渠道反馈，把设备型号和 App 版本号一并写清楚，能省一轮来回。
