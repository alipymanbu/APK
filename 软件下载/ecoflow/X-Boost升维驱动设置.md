# EcoFlow X-Boost 升维驱动设置

> 本篇讲 X-Boost 升维驱动什么时候用得上、在 App 哪里开关、哪些电器适合，以及它在哪两种情况下不生效。

## 一、它是干什么的

当你要带的电器功率超过电源的额定输出功率时，普通情况下会触发过载保护、直接断掉交流输出；X-Boost 开启后，电源能以自身额定输出功率去驱动这台高瓦数电器。注意它并不是让输出功率凭空变大，而是放宽「能带动」的范围——各机型可带动的功率上限不同，以你机型的官方页面标注为准。

## 二、在 App 哪里开关

路径：打开 App 进入设备页面 → 设置里找 X-Boost（部分界面写作「升维驱动」）→ 开或关。

默认状态因机型与销售地区而异：官方手册里有的机型写默认开启（如国行 DELTA 3 系列），有的写默认关闭（如海外版 DELTA 3 Plus），还有机型写总输出超额时会自动启用——所以有时你什么都没设，它也已经工作了。以你设备设置页的实际显示为准。

## 三、两种情况下它不生效

- **充电中开着交流输出**（旁路模式）：X-Boost 不可用，想带大功率电器就先停掉充电；
- **X-Boost 开关本身被关掉**：到设置里重新打开。

另外它对电器类型有偏好：加热类、电机类电器最合适；带电压保护的精密仪器（官方特别提醒过这类）不适合走 X-Boost，一台电器到底能不能带，官方的建议是以实际测试为准。

## 四、开了还是带不动

按顺序核对：

1. 确认设备没处在「充电中 + 交流输出开启」的旁路状态；
2. 确认设置里 X-Boost 是开着的；
3. 确认电器属于加热/电机类，而不是精密仪器；
4. 仍然触发过载保护，把电器功率与机型额定输出对照着到 [常见问题排查.md](常见问题排查.md) 走一遍，输出异常的排查也在这篇里。
