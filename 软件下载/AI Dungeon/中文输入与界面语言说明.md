## 一、直接给结论

**中文可以直接输入**：你打中文的行动与台词，AI 能读懂并接着写，这是多数中文玩家的常规玩法。**但输出质量比英文场景波动更大** —— 同一个模型，中文续写的流畅度、用词和对设定的跟随程度都可能打折扣（社区玩家反馈，因模型而异）。想稳定用中文玩，靠下面几招，而不是指望某个开关。

## 二、界面为什么是英文

AI Dungeon 由海外团队 Latitude 开发，官方帮助文档与主要界面均为英文；官方没有公布过中文界面选项。**以应用内设置里是否出现语言项为准** —— 若你的版本里有，按界面走即可；没有就是英文界面，不影响中文游玩。

界面高频英文对照：

| 英文 | 含义 |
| --- | --- |
| `Take a Turn` | 进行一轮 |
| `Do` / `Say` / `Story` / `See` | 行动 / 说话 / 旁白 / 生图 |
| `Retry` / `Edit` / `Erase` | 重生成 / 编辑 / 删除 |
| `Undo` / `Redo` / `Continue` | 撤销 / 重做 / 续写 |
| `My Stuff` | 我的内容（冒险与场景） |
| `Discover` | 发现（社区场景） |
| `Scenario` / `Adventure` | 场景 / 冒险 |

## 三、让 AI 稳定回中文的四个做法

1. **全程只用一种语言**。中英混着写（设定英文、行动中文）会让它在两种语言间摇摆，风格也跟着乱。想中文玩就从开局到结局都中文。
2. **开局就定下语言基调**。第一轮直接用中文开场，或在 AI Instructions 里写一句「全程使用简体中文」—— 放进 [故事卡与记忆系统怎么用.md](故事卡与记忆系统怎么用.md) 讲的设定区，后面每轮都会带上。
3. **换更适合多语言的模型**。社区玩家经验：不同模型的多语言能力差别很大，免费档里有模型明显更适合非英语写作，也有几个对非英语较吃力。具体哪家强以当时应用内列表实测为准 —— 拿不准就在同一段剧情上换模型各试一轮，看谁的中文最顺。
4. **开局多 Retry**。中文开局最容易出现半中半英的句子，连续重生成几次，从候选里挑一条纯中文的，后面就会顺着这条的风格写。

## 四、社区的多语言脚本（进阶，按需）

社区有一个免费开源的多语言场景脚本 **LoLa（Localized Languages）**，支持简体中文、繁体中文等大量语言，安装后会改写你与 AI 的输入输出语言处理。要点：

- 它是**场景脚本**，不是官方内置功能，装在你游玩的场景上；
- 启用路径：`Account Settings > Gameplay` 里把两个 `Allow Scripts` 开关都打开，再按场景页的安装说明添加；
- 脚本作者建议把回复长度设在 200 token 左右、开局阶段多用 Retry、保持单一语言输入 —— 这些与本篇第三节一致；
- 效果同样**因模型而异**，作者自己也注明了部分模型对非英语支持较弱。

是否需要装取决于你玩的场景：英文场景直接中文游玩够用就不必折腾；跑社区的多语言场景时它才有意义。

## 五、网络与连通性

AI Dungeon 的故事生成与存档都在云端，**必须联网**，没有离线模式。官方服务部署在海外，国内不同网络环境下打开速度与稳定性因人而异（用户反馈，官方未就中国大陆访问单独说明）—— 打不开、一直转圈时先换网络环境试，网络类问题的排查见 [常见问题与故障排查.md](常见问题与故障排查.md)。
