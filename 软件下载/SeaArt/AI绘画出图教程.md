## 一、出图的完整流程

在 SeaArt 里出一张图，顺序固定成四步：**选模型 → 写提示词 → 调参数 → 生成并保存**。

1. **选模型与风格**。社区模型库覆盖 Checkpoint、LoRA、Pony 等家族，风格从二次元、写实到油画、3D 都有；官方商城页标称 1M+ 模型（数字随官网更新，以 [www.seaart.ai](https://www.seaart.ai) 当时显示为准）。先定风格再写提示词，比写完提示词再回头挑模型稳定。
2. **写提示词**。官方文档的说法：清晰详细的描述是关键；画面越具体，越要把主体、风格、构图写全。中文等自然语言可直接描述，不需要翻译成英文。
3. **调参数**。尺寸 / 宽高比、批量张数、步数这些按需调。试新模型时先用默认或偏低参数跑一张看方向，确认了再上正式参数 —— 参数越高越慢，也越容易触发报错（见 [生成失败与登录问题排查.md](生成失败与登录问题排查.md)）。
4. **生成与保存**。点生成等结果，出图后在作品里下载 / 保存到手机（按钮以界面为准）；要更高分辨率，用官方的图像增强（image upscaler）放大。

每次生成扣多少见 [算力和体力消耗说明.md](算力和体力消耗说明.md)：点生成前页面会标出本次预估消耗，余额不足时等每日额度刷新，或换消耗低的模型先试。

## 二、提示词怎么写

官方 FAQ 归纳的三条，直接当检查清单用：

- **写清楚再点生成**：清晰详细的文字提示是出好图的关键；非常具体或复杂的画面，需要更详细的描述才能逼近你想要的结果。
- **按结果逐步改**：官方建议拿生成结果反推提示词，一轮轮优化，而不是一次写很长一段全推翻。
- **用负面提示排除**：不想要的元素写进负面提示（官方文档里叫「负标签」），比只在正面提示里写「不要 XX」直接。

写正面提示时按「主体 → 风格 → 构图 / 光线」的顺序组织，一段里塞太多互不相干的要求，模型会各取一部分。示例结构（只是结构示意，具体内容按你要的画面写）：

```text
正面：一名穿风衣的女性站在雨夜街头，霓虹灯光，电影感构图，高细节
负面：模糊，多余手指，低质量
```

## 三、图生图和常用工具

除纯文生图外，官方 Google Play 商店页列出的可用能力有这些（App 内以实际界面为准）：

| 工具 | 你拿它做什么 |
| --- | --- |
| 图生图 | 上传底图再加提示词：保留构图换风格 |
| 局部重绘 | 涂抹一块区域单独重画，修手指、换背景都用它 |
| 草稿成图 | 先出低配草稿定方向，再出精图 |
| 背景移除 | 一键抠图，成品图二次加工 |
| AI 滤镜 | 给照片套风格化效果 |
| LoRA / ControlNet | 控制角色形象与姿态，出图一致性更高 |
| Clone & Try | 看中社区作品，一键复制它的风格与流程再改成自己的 |

第一次用建议从 Clone & Try 起步：挑一张接近你目标的社区作品复制过来，在它的提示词和模型上改，比从空白框开始摸索快。

## 四、出图的边界（先知道再动手）

- **内容有红线**：官方内容准则禁止违法、暴力、色情、侵权等生成，NSFW 内容有过滤机制；被拦与误拦的处理见 [生成失败与登录问题排查.md](生成失败与登录问题排查.md) 第三节。
- **商用看条款**：官方 FAQ 的口径是「不禁止商用，但也不对商用造成的相关风险负责，风险由用户自行承担」—— 把生成结果用到商品、广告前，自己过一遍官方服务条款。
- **免费额度够不够试错**：每日额度与单次消耗在 [算力和体力消耗说明.md](算力和体力消耗说明.md)，先算清楚一张图的成本再决定批量跑还是小批试。
