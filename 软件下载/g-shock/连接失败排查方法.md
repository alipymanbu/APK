# G-SHOCK Connected 连接失败排查方法

> 表怎么按都连不上、自动对时突然不跑了、表上闪 ERR——这篇把卡西欧官方说明书里列过的坑按「先查手机、再查表、最后重置」的顺序过一遍。

## 一、先查手机的五个设置

按官方应用说明书的要求逐项核对，缺一个都可能连不上：

| 检查项 | 应该是 |
| --- | --- |
| 蓝牙 | 开 |
| 位置信息 | 开（Android 8 及以下选高精度） |
| G-SHOCK Connected 的通知 | 开——关闭后应用无法正常工作，这是官方原文的措辞 |
| 应用联网 | 允许（省流模式下可能被拦） |
| 飞行模式 | 关 |

## 二、省电优化是最大的隐形杀手

Android 8 以后，系统为了省电会限制应用在后台的蓝牙活动，表现就是：**应用开在前台一切正常，切到后台自动对时就不跑了、手机搜索也收不到**。官方给的解法：

- 在系统的电池/省电设置里，把 G-SHOCK Connected 设为「不限制后台」「不优化」或加入省电白名单；
- 国产系统还要额外放行：自启动、后台锁定（下拉通知栏把应用卡片上锁）、关联启动（视机型）。

各品牌设置入口不同，找不到就在系统设置里搜「电池优化」或「自启动」。

## 三、Android 9~12 的已知问题：熄屏后连不上

官方说明书专门列了一条：**手机重启后、解除飞行模式后、蓝牙开关后，如果屏幕处于熄灭状态，部分手机会连不上表**（自动时间校正等后台功能也不动）。这不是表坏了，处理办法：

1. 把 G-SHOCK Connected 切到前台（打开它），再和表连接一次；
2. 配了多块表的，把每块表都连一遍；
3. 之后后台连接就恢复正常了。

出现场景还包括电池耗尽重启、系统升级重启等，怀疑后台连接停了就手动连一次。

## 四、看表上的反应判断问题在哪

| 表的表现 | 说明 | 处理 |
| --- | --- | --- |
| 蓝牙图标没出现 | 没进入连接模式 | 重新长按连接键（计时模式下按住约 2 秒） |
| 显示 ERR 后退回计时模式 | 连接失败 | 手表离手机近一点重试；确认手机蓝牙开着 |
| 表没电进入省电状态 | 蓝牙功能被关停 | 光动能表放光线下充电后再试 |
| 什么反应都没有 | 按键没按对 | 拿表背模块号查说明书，确认按键位置和时长 |

## 五、最后手段：删配对重新来

上面都试过还不行，就把配对信息清掉重来：

1. 在 G-SHOCK Connected 里找到配对/连接设置，删除当前手表的配对（应用里有删除配对的入口）；
2. 手表侧如果说明书有「删除配对」操作，一并执行；
3. 按配对流程从头再来，见[手表配对连接步骤.md](手表配对连接步骤.md)。

再不行就重启手机再来一遍。注意：如果你的表实际应该配的是 CASIO WATCHES 而不是这个应用（型号对照见[支持手表型号一览.md](支持手表型号一览.md)），怎么按都连不上是正常的——先确认应用没装错。
