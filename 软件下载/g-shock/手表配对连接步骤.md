# G-SHOCK Connected 手表配对与连接步骤

> 应用装好后，这一步是把手机和 G-SHOCK 蓝牙表正式「认亲」。这篇按顺序列配对前的手机设置、手表侧的按键操作、配对之后的日常连接，以及多块表、多台手机的注意点。

## 一、配对前先把手机调好

按卡西欧应用说明书的口径，下面这些没设置好，配对和后续使用都会出问题：

| 设置项 | 要求 |
| --- | --- |
| 蓝牙 | 打开 |
| 位置信息 | 打开（Android 8 及以下要选「高精度」模式） |
| 应用通知 | 打开——官方明确说明通知关闭会导致应用无法正常工作 |
| 数据联网 | 允许 G-SHOCK Connected 联网（时间校正、地图都要用） |
| 飞行模式 | 关闭 |
| 开发者选项 | 如果开过，建议关掉 |

省电类设置（电池优化、自启动管理）在配对阶段不一定会拦住你，但会让后面的自动连接失效，建议顺手设为「不优化」，详见[连接失败排查方法.md](连接失败排查方法.md)。

## 二、手表进入连接模式

不同表款的按键位置不同，共同点是**长按**：

1. 在表的计时模式下，按住说明书指定的那个按钮约 2 秒，直到表盘上出现蓝牙图标（指针表的指针会转到 Bluetooth 标记位置）；
2. 松手后表进入待连接状态，几十秒内没连上会自动退回计时模式，重新长按即可。

具体按哪个键：表背面刻有模块号（4 位数字，如 3459、5554），拿模块号到卡西欧支持站的说明书页面查，一查就能看到图示。

## 三、在应用里完成配对

1. 打开 G-SHOCK Connected；
2. 首次启动按引导选择语言、同意条款；
3. 在应用的主画面选择添加/连接手表，应用开始扫描附近的 G-SHOCK；
4. 手表进入连接模式后，应用列表里出现你的表，点它完成配对；
5. 配对成功后回到应用主画面，可以看到表的连接状态、电量等信息。

## 四、日常连接（配对过一次之后）

配对信息会留在表和应用两边，之后的连接不用再做配对：

- 打开应用，把表带到手机旁边，多数情况下会自动连上；
- 没自动连就长按表上的连接键，手动触发一次；
- 断开（比如换了城市长期不用）后再用，同样长按连接键重连。

## 五、多块表 / 多台手机

- 一块表通常能记住不止一台手机的配对信息（官方在早期蓝牙表的指南里写明可存 10 台），但**同一时刻只能连一台**；换手机连之前，把原来那台手机的蓝牙关掉，否则表会一直尝试连旧手机；
- 配了多块表的话，手机重启或蓝牙重开之后，建议把每块表都在应用里手动连一遍——这是官方针对 Android 9~12 给出的要求，具体原因见[连接失败排查方法.md](连接失败排查方法.md)。

## 六、一块表只能绑定一个应用

G-SHOCK Connected 和新的 CASIO WATCHES **不能同时绑同一块表**。如果你打算迁到 CASIO WATCHES，必须先在 G-SHOCK Connected（3.0 以上）里完成应用内迁移，再去 CASIO WATCHES 配对；顺序反了会连不上，日志数据也可能带不过去。完整迁移步骤见[迁移到 CASIO WATCHES 步骤.md](迁移到 CASIO WATCHES 步骤.md)，型号分工见[支持手表型号一览.md](支持手表型号一览.md)。
