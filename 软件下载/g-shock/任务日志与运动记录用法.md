# G-SHOCK Connected 任务日志与运动记录用法

> GG-B100、GPR-B1000、GBD-800 这几款带传感器的型号，连上应用后能干的事不止对时：记录登山路线、看步数卡路里、给目的地指方向。这篇按功能写清楚哪些表有什么、在应用里怎么用。

## 一、先对号入座：你的表有哪些记录功能

| 功能 | 主要型号 |
| --- | --- |
| 任务日志（路线记录） | GG-B100 |
| GPS 导航 | GPR-B1000 |
| 位置指示器 | GG-B100、GPR-B1000 |
| 计步（Step Tracker） | GBA-800、GMA-B800、GMD-B800、GBD-800 |
| 飞行日志 / TIME & PLACE | 视型号（官方应用说明书列出，见你表型的说明） |

表款不带对应传感器的话，应用里不会出现对应功能入口——这不是装错了应用，是你的表本来就没有。

## 二、任务日志：把登山路线留在地图上

GG-B100 的用法：

- 表自己测海拔，手机负责 GPS 定位，两者合起来自动生成一条带高度变化的路线，记录在应用里；
- 途中想标记某个点（比如垭口、岔路），可以手动加一个海拔点，路线图上会落一个标记；
- 回程在应用里回看整条轨迹，配合地图显示。

注意轨迹依赖手机的 GPS 和定位权限，手机没带在身上或者位置权限没给，记录会缺数据。

## 三、位置指示器：先存一个点，表给你指方向

- 在应用里把当前位置记录为目的地；
- 之后在表上启动位置指示器：**方向由秒针指向**，表盘液晶上显示直线距离；
- 适合「记下停车点再去逛」这类场景。

指向精度取决于 GPS 信号，在室内或高楼之间会飘。

## 四、计步与卡路里

GBA-800 / GBD-800 这批计步款：

- 表负责累计步数，应用里看每天/每周/每月的步数趋势和目标完成情况；
- 按步数与身体数据估算消耗的卡路里；
- 目标值在应用里改，改完同步到表。

要运动心率、跑步轨迹这类更专业的记录，你的表得是 G-SHOCK MOVE 清单里的运动款（GBD-H1000、GBX-100 等）——那批表用另一套应用，见[支持手表型号一览.md](支持手表型号一览.md)第二节。

## 五、这些数据迁移时能带走吗

官方公告把话说得很明确（以官方公告为准）：

- **日志数据带得走**：应用里保存的活动记录、任务日志等，按官方流程迁移后会转移到 CASIO WATCHES；
- **3D 地图带不走**：G-SHOCK Connected 的 3D 地图显示是它独有的功能，CASIO WATCHES 不支持，迁移后这一项就没有了；
- **资料和设置要重配**：个人资料信息、应用里配置的其他设置，都要在 CASIO WATCHES 里重新弄一遍。

迁移要求 G-SHOCK Connected 3.0 以上，且**先完成应用内迁移、再用新应用配对手表**，顺序错了数据可能带不过去；完整步骤见[迁移到 CASIO WATCHES 步骤.md](迁移到 CASIO WATCHES 步骤.md)。

计步之外的时间类功能（闹钟、世界时间、手机搜索）见[自动时间校正与世界时间设置.md](自动时间校正与世界时间设置.md)。
