## 一、支持型号清单

以下为卡西欧官方下载页标注的支持型号（截至官方页面显示，后续以官方页面为准）：

| 型号 | 系列 | 特点 |
| --- | --- | --- |
| GPW-2000 | GRAVITYMASTER | GPS + 电波混合对时 |
| GPR-B1000 | RANGEMAN | GPS 导航、三重感应 |
| GG-B100 | MUDMASTER | 四重传感器、防泥防尘 |
| GWR-B1000 | FROGMAN | 碳壳蛙人表 |
| GWF-A1000 | FROGMAN | 指针蛙人表 |
| GR-B100 | G-STEEL | 碳纤表圈 |
| GST-B100 / GST-B200 / GST-B300 / GST-B400 | G-STEEL | 太阳能指针款 |
| MTG-B1000 / MTG-B2000 | MT-G | 全金属混合结构 |
| GMW-B5000 | 全金属方块 | 初代 5600 的金属版 |
| GW-B5600 | 方块 | DW-5600 的蓝牙版 |
| GBA-800 / GMA-B800 / GMD-B800 | 800 系列 | 计步表款 |
| GBD-800 | G-SQUAD | 计步运动款 |

查自己的表支持与否：翻到表背，看刻的型号（如 GG-B100）或模块号，对照上表；上表没有的型号，拿模块号去卡西欧支持站（`support.casio.com`）搜索确认。

## 二、卡西欧手表应用分工对照

| 应用 | 给哪些表用 |
| --- | --- |
| **G-SHOCK Connected** | 上表 19 款 |
| CASIO WATCHES | 2022 年 5 月之后发布的新款蓝牙表（GA-B2100、GM-B2100、DW-B5600、MRG-B5000 等），以及 BABY-G / OCEANUS / EDIFICE / PRO TREK 的新款 |
| G-SHOCK MOVE | 运动数据款：GBD-H1000、GBD-100、GBD-200、GBD-300、GBX-100、GBA-900、GSW-H1000 |
| G-SHOCK+ | 更早的 GB-5600 / GB-6900 系列（初代蓝牙表） |
| MR-G Connected / OCEANUS Connected / EDIFICE Connected / PRO TREK Connected | 对应品牌的独立款（也在逐步并入 CASIO WATCHES） |

注意 GBD-800 属于 G-SHOCK Connected，而长得像它的 GBD-100/200/300 属于 G-SHOCK MOVE——一字之差应用就不同，认准完整型号。

## 三、G-SHOCK Connected 已按官方计划并入 CASIO WATCHES

卡西欧官方公告（2023 年发布，支持页可查）：各型号专用应用停止支持并统一并入 CASIO WATCHES，其中 **G-SHOCK Connected 的计划截止时间为 2023 年 7 月底**。对使用中的你，实际影响是：

1. **已装的还能用**：应用可以继续打开、继续连表，但官方不再做新功能与系统适配更新；
2. **装新机要留意**：新手机、新系统上出了问题不再有修复，重装只能靠安装包存档或官方支持页入口；
3. **官方推荐新用户直接用 CASIO WATCHES**：下载渠道在官方支持页与应用商店都有；
4. **迁移有讲究**：要把日志数据带到 CASIO WATCHES，G-SHOCK Connected 必须先升到 3.0 以上，而且**先完成应用内迁移、再去 CASIO WATCHES 配对**——顺序反了数据可能带不过去。完整步骤、带得走带不走的功能清单，见[迁移到 CASIO WATCHES 步骤.md](迁移到 CASIO WATCHES 步骤.md)。

如果你不打算迁移，继续用 G-SHOCK Connected 即可，时间校正、闹钟同步这些核心功能照常工作，用法见[自动时间校正与世界时间设置.md](自动时间校正与世界时间设置.md)。
