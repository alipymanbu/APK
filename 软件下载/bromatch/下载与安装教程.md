## 一、安装前先核对设备与版本

BroMatch 是手机端应用，安卓与 iPhone 各有一套：

| 项目 | 安卓版 | iPhone 版 |
| --- | --- | --- |
| 获取方式 | 安装包直接安装 | App Store 搜索 BroMatch |
| 系统要求 | Android 6.0 或更高（以官方商店页面为准） | iOS 13.0 或更高 |
| 本篇所附安装包 | v1.3.65，约 126 MB | 不适用（本资源为安卓安装包） |
| 包名 | com.jts.liuzi | — |

两点提醒：

1. 网盘里这份是 **v1.3.65**（采集于 2026-09-23）。官方商店的版本号随更新向前走，装完后在应用内检查更新即可升到最新，不必刻意追求商店版本号一致。
2. 应用年龄分级 18+，注册需要完成实名认证，未成年设备装了也无法正常使用。

不方便用安装包时，也可以走商店渠道：安卓在小米应用商店、腾讯应用宝搜索 BroMatch 安装，iPhone 在 App Store 安装。商店跟着官方更新走，版本更新；网盘资源版本固定，商店下架或版本不适配时仍可用。

## 二、从网盘获取安装包的步骤

1. 打开上面「BroMatch 安装文件资源（夸克网盘）」的链接；
2. 按页面提示把文件转存到自己的网盘（或直接下载）；
3. 取出 `bromatch_v1.3.65.apk`，等下载完成再操作，不要在传输中断时强行安装。

## 三、安卓安装步骤

1. 打开手机自带的「文件管理」，找到刚下载的 APK；
2. 点按安装包，系统会提示「是否允许从此来源安装应用」，按提示允许一次；
3. 回到安装界面点「安装」，等待进度走完；
4. 点「打开」进入应用，首次启动会要求同意用户协议与隐私政策；
5. 如提示需要存储、相机等权限，按需允许——头像认证环节要用到相机。

各权限对应的功能，允许前可以先对上号：

| 权限 | 用在哪 |
| --- | --- |
| 相机 | 头像认证、拍摄动态 |
| 麦克风 | 语音消息 |
| 位置 | 附近的人、同城推荐 |
| 照片与文件 | 发图文动态、保存内容 |
| 通知 | 匹配与消息提醒 |

后开启也来得及：拒绝掉的权限，之后用到对应功能时系统会再次询问。

国产手机（小米、OPPO、vivo、华为等）的额外注意点：

- 部分机型的「纯净模式」会拦下非商店来源的安装包，需要在设置里临时关闭再装；
- 安装完成后可以把「未知来源安装」权限收回，不影响已装好的应用运行。

## 四、安装失败的排查清单

按出现顺序逐项对照：

| 现象 | 先做什么 |
| --- | --- |
| 提示「解析包出错」 | 重新从网盘下载一次，确认文件大小约 126 MB，传输中断的包解不开 |
| 提示「与设备不兼容」 | 核对安卓版本是否在 6.0 以上；老机型存储空间不足也会报这个 |
| 进度卡在安装中 | 重启手机后重试；确认剩余存储大于安装包体积的两倍 |
| 装完点开闪退 | 先看系统版本是否过低，再尝试清除应用数据后重新打开 |

以上步骤走完仍装不上，换一台满足系统要求的设备是最快的验证方式。

## 五、装好之后先做什么

首次进入的路线是：同意协议 → 手机号注册/登录 → 完善资料 → 实名认证。认证是使用聊天等功能的前提，具体每一步要准备什么，见 [注册登录与实名认证.md](注册登录与实名认证.md)；认证通过后怎么用起来，见 [匹配聊天与社区玩法.md](匹配聊天与社区玩法.md)。
