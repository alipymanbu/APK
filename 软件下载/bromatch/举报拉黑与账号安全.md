## 一、遇到骚扰：举报与拉黑

聊天或动态评论区遇到言语骚扰、诱导转账、发布不当内容的人，处理路径固定两步：

1. 进入对方资料页或聊天窗口，找到菜单里的「举报」，选择对应类型提交；
2. 同一入口可以「拉黑」，拉黑后对方无法再向你发消息。

举报提交后进入平台复核，由平台处理，你不需要再与对方交涉；拉黑是即时的，不等复核结果。

除了逐个处理，还可以主动收紧接收面：在消息设置里调整消息权限，过滤陌生人的打扰。有用户反馈这套组合（拉黑 + 举报 + 消息权限）基本能挡住日常骚扰。

遇到涉及金钱的对话（借款、投资、诱导去其他平台转账），无论对方资料看起来多真实，一律停止对话并举报——这是所有社交平台的通用防骗原则，实名平台也不能豁免。

## 二、认证信息与个人隐私

注册时提交的身份证信息与头像核验材料，官方口径是加密存储、仅用于身份核验、不流转至第三方；隐私政策的完整文本可在应用商店页面的「隐私政策」入口查看。

日常使用中，真正的风险点大多不在平台侧，而在自己的操作：

- 不要在聊天里发送身份证照片、住址、工作证件等敏感材料，即使对方也是「已认证」；
- 实名信息只用于平台核验，不要响应任何「查看我的认证材料」之类的请求；
- 动态里注意别带出可定位的常驻信息（小区门牌、固定通勤路线等）。

## 三、账号本身的日常防护

| 场景 | 建议做法 |
| --- | --- |
| 换手机 | 用同一手机号 + 验证码登录即可，旧设备上的会话在新设备登录后自动失效 |
| 验证码 | 任何索要短信验证码的行为（包括自称客服）都拒绝，平台客服不需要验证码 |
| 密码 | 注册后设置独立密码，不要与其他平台复用 |
| 注销 | 在应用内的账号设置里按流程操作；注销后身份信息与账号的对应关系决定再次注册能否成功，重要会话先自行备份 |

## 四、公开场合的线下见面

从线上聊到线下见面时，用平台内已有的信息做基础核验（认证标识、动态记录的时间跨度），选择公共场所、告知朋友行程。这三条与 [匹配聊天与社区玩法.md](匹配聊天与社区玩法.md) 里的线下活动建议是同一套逻辑。

## 五、账号被误判怎么办

如果自己的账号被限制或被他人恶意举报，通过应用内的反馈渠道提交说明，等待平台复核；复核期间不要另注册新号，同一身份信息的多个账号可能让判定变得更复杂。
