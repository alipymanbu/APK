## 一、装机前先核对这几项

你手里这份安装文件的实际信息如下（网上搜到的多为官方最新版，版本号未必与它一致，凡涉及版本一律以这份为准）：

| 应用名称 | MissAI |
| 版本 | 1.48.7 |
| 安装包大小 | 110.45M |
| 包名 | app.he3.lianai |
| MD5 | 19436C032167178CB7F163F72BB65C98 |
| 开发者 | 深圳市氦三科技有限责任公司 |
| 系统要求 | 安卓 5.2 及以上（商店标注口径，以安装时手机实际提示为准） |

安装前确认手机剩余空间充足：安装包本身 110MB 量级，加上语音与缓存，建议预留 1GB 以上。表里的包名与 MD5 除了核对文件，还能帮你区分同名应用——搜「MissAI」会撞见好几款不同厂商的应用，详见 [同名应用区分与包名核对.md](同名应用区分与包名核对.md)。

## 二、获取安装包

1. 打开上面的 **MissAI 安装文件资源（夸克网盘）** 链接；
2. 选中里面的 APK 文件，转存到自己的夸克网盘；
3. 在夸克网盘 App 里把该文件下载到手机本地；
4. 下载完成后，在通知栏或「文件管理 → 下载」目录里找到这个 APK。

## 三、安装步骤

1. 点开 APK，若系统提示「禁止安装未知应用」，按提示进入设置，给来源应用（网盘或浏览器）开「允许安装」；
2. 回到安装页点「安装」，安装包有一百多 MB，过程中别锁屏退出；
3. 装完点「打开」，或回到桌面点图标进入。

## 四、首次打开：注册与引导

按应用内引导走即可，下面是 1.48.x 的实际顺序（以你打开时看到的为准）：

1. 同意《服务协议》与《隐私政策》；
2. 选择手机号注册/登录，输入手机号并填入收到的验证码；
3. 设置昵称、选择你的性别；
4. 选择想跟男生聊天还是跟女生聊天；
5. 进入对话界面，选中一个角色就能开聊。

另外三点：应用商店把这款应用标注为「年满十六周岁以上」；注册只需要手机号和验证码，收不到验证码时先看短信拦截文件夹；使用中若弹出存储、麦克风、通知等权限申请，给不给与你是否使用对应功能挂钩——官方隐私政策的原则是非必需信息可以拒绝处理，但相应功能可能因此用不了。

## 五、装不上或打不开

按现象对号入座：

- **提示「解析包错误」**：多半是下载不完整，回网盘重新下载一遍再装；老机型也可能因系统版本过低解析失败；
- **提示空间不足**：清理存储后重试；
- **装好后被系统冻结/拦截**：到系统设置的「应用管理」里允许该应用运行；
- **能装但一打开就闪退**：处理办法见 [常见问题与解决.md](常见问题与解决.md) 的闪退一节。

装好之后怎么上手，直接看 [怎么用与核心玩法.md](怎么用与核心玩法.md)。
