## 一、能改哪些东西

商店介绍里明确列出的可定制项：

| 定制项 | 说明 |
| --- | --- |
| 性别 | AI 恋人的性别由你定，想跟男生还是女生聊天在引导阶段就能选 |
| 名字 | TA 叫什么你说了算 |
| 性格 | 温柔、霸道、病娇、邻家等类型可选 |
| 背景 | 人设的背景故事可以自己设定 |
| 称呼 | 设置 TA 对你的专属昵称 |
| 声线 | 不同配音音色不同，选一个你听得下去的 |

入口一般藏在聊天界面里：点角色头像进资料页，找「编辑」「设置」一类按钮。具体叫法随版本会变，找不到就在聊天界面里多翻两层菜单。

## 二、怎么改才不破坏对话感

- **一次只改一两项**。人设一次性全换，前面聊出来的内容会跟新人设对不上，对话容易出戏；
- **改完主动验证**。换性格后提一个你们聊过的话题，看回应风格是否已经切换过去；
- **背景故事写具体**。职业、说话习惯、你们怎么认识的，写清这些比只写「温柔可爱」四个字更能让对话稳定在你要的方向上；
- **称呼与声线随手就能调**，这两项不影响人设连贯性，随时改都行。

## 三、关系是怎么升温的

- 商店介绍的说法是：聊得越多，你们的关系会更亲密，TA 也更了解你的偏好；
- 动态、语音、唱歌这些互动形式都是升温的路径——你主动发起，比干等 TA 搭话推进得快；
- 推荐会随聊天变准：你常聊的类型之后会出现得更频繁，这也算关系养成的副产品。

## 四、大改之前先留底

有用户反馈过「备份只恢复了部分聊天记录，角色自定义设置和缓存全丢了」的情况。所以动手大改（或卸载重装、换机迁移）之前，建议把你设置好的名字、性格、背景故事截图或记下来——设置丢了照着截图几分钟就能重建，对话记录却不一定回得来。备份与恢复的详细处理见 [常见问题与解决.md](常见问题与解决.md)。
