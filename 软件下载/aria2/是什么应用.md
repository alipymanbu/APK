# Aria2App 是什么应用

> 一句话说清 Aria2App 的定位：它是开源下载引擎 aria2 的安卓管理端，既能本机直接下载，也能远程操控服务器上的 aria2。

## 一、先分清两个名字：Aria2App 与 aria2

搜索引擎里这两个词经常混在一起，装错了会白折腾一场：

| 名字 | 是什么 | 装在哪 |
| --- | --- | --- |
| aria2 | 开源命令行下载引擎，支持 HTTP/HTTPS、FTP、SFTP、BitTorrent、Metalink，由 Tatsuhiro Tsujikawa 开发 | 电脑、NAS、路由器、服务器 |
| Aria2App | 本文要装的应用，包名 `com.gianlu.aria2app`，作者是 Gianluca Altomani（GitHub 上叫 devgianlu） | 安卓手机 |

Aria2App 通过 aria2 的 JSON-RPC 接口与 aria2 通信 —— 你在手机界面上的每次点按，最终都转成 RPC 指令发给某个 aria2 实例。这个「实例」可以在别的设备上，也可以就在你这台手机里。

## 二、两种工作方式

| | 本机直接下载 | 管理远程服务器 |
| --- | --- | --- |
| aria2 跑在哪 | 手机里（Aria2App 内置了 aria2） | 电脑 / NAS / VPS 上 |
| 需要配置吗 | 不需要，装上就能用 | 需要在服务器端开启 RPC，再在 App 里建 profile |
| 文件落在哪 | 手机存储 | 服务器磁盘；要用 DirectDownload 才能取回手机，见 [DirectDownload怎么设置.md](DirectDownload怎么设置.md) |
| 典型场景 | 手机上下个直链、磁力 | 你已经有 NAS/服务器在挂 BT、跑批量下载，想在手机上操控 |

本机方式开箱即用；远程方式才是它和普通下载 App 拉开差距的地方 —— 一部手机可以同时添加多台 aria2 服务器，逐台管理。

## 三、能添加哪些下载

按官方功能清单，Aria2App 可以处理：

- HTTP(S) 与 (S)FTP 直链下载
- BitTorrent 种子与磁力链接（内置种子搜索引擎）
- Metalink 下载
- 从浏览器里点链接发起下载（把链接交给 Aria2App 接管）
- 用 URI 文件批量导入任务（每行一个资源，多镜像用空格隔开）

任务层面你能做的：暂停、恢复、停止；查看每个任务的基础与深度信息（peers、服务器统计、每个文件的状态）；单独改某个任务的参数或 aria2 的全局选项；接收下载进度的实时通知。这些操作的入口见 [添加下载任务的几种方式.md](添加下载任务的几种方式.md)。

## 四、开源、许可与来源

- **源码**：[GitHub - devgianlu/Aria2App](https://github.com/devgianlu/Aria2App)，约 1.6k star。
- **许可**：GPL-3.0-only，免费使用，无广告。
- **上架渠道**：Google Play 与 F-Droid。F-Droid 页面给它标了一个 `NonFreeNet` 反特性 —— 应用会连到作者自己的网络服务（`gianlu.xyz`）与第三方 IP 归属地查询服务（`extreme-ip-lookup.com`），这两处不是开源服务，介意的话知道即可，不影响正常使用。
- **同作者的配套应用**：Aria2Android（包名 `com.gianlu.aria2android`），作用是把 aria2 作为服务常驻在你的安卓设备上 —— 想让手机本机跑一个独立 aria2 服务再由 Aria2App 操控时可以用它。
