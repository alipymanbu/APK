## 一、配置文件放在哪、怎么生效

aria2 支持配置文件启动：默认会找 `$HOME/.aria2/aria2.conf`（Windows 下是用户目录对应路径），也可以启动时用 `--conf-path=文件路径` 显式指定。所有命令行参数去掉 `--` 前缀、写成 `键=值` 就是配置文件里的一行。改完重启 aria2 进程才生效；配置项的完整清单与默认值以 [aria2 官方手册](https://aria2.github.io/manual/en/html/aria2c.html) 为准。

## 二、最小可用配置（直接抄）

```ini
# RPC：Aria2App 的唯一控制通道
enable-rpc=true
rpc-listen-all=true
rpc-secret=换成你自己的令牌
rpc-listen-port=6800

# 下载目录
dir=/home/你的用户名/downloads

# 断点续传：aria2 重启后接着上次的进度
continue=true
input-file=/home/你的用户名/.aria2/aria2.session
save-session=/home/你的用户名/.aria2/aria2.session
save-session-interval=30
```

这五行 RPC 配置与 [怎么连接远程服务器.md](怎么连接远程服务器.md) 里命令行参数逐项对应；session 两行是为了 aria2 或服务器重启后任务列表不丢 —— 没有它，进程一断所有未完成任务都要重新加。

## 三、跑 BT 建议补的几行

```ini
# 补充 tracker，多个地址用逗号分隔
bt-tracker=http://tracker1.example.org/announce,udp://tracker2.example.org:6969/announce

# 做种限制：不设的话会一直做种占着上传带宽
seed-ratio=1.0
seed-time=60

# 磁盘相关
file-allocation=none
```

`bt-tracker` 列表来源与为什么有效，见 [磁力与BT下载怎么提速.md](磁力与BT下载怎么提速.md)第三节；`seed-ratio`（分享率达到 1.0 就停）与 `seed-time`（做种满 60 分钟就停）按你的磁盘与带宽情况调。

## 四、下载行为常调的几项

| 配置项 | 作用 | 常见取值 |
| --- | --- | --- |
| `max-concurrent-downloads` | 同时进行的任务数 | 3~5，太多会互相抢带宽 |
| `split` | 单任务分块数 | 大文件直链给 8~16 |
| `max-connection-per-server` | 单服务器最大连接数 | 直链慢时先调它（部分站点会封高频连接） |
| `max-overall-download-limit` | 全局限速 | 0 = 不限；共享带宽的机器建议留余量 |
| `user-agent` | 请求 UA | 个别站点拒绝默认 UA 时换浏览器 UA |

这些属于 aria2 全局默认，任务建好后仍可以在 Aria2App 里对单个任务单独覆盖改（App 端入口见 [添加下载任务的几种方式.md](添加下载任务的几种方式.md)）。

## 五、改完怎么验证

1. 重启 aria2 进程（`systemctl restart` 或重新运行命令）；
2. 电脑浏览器开 `http://服务器IP:6800/jsonrpc?jsonrpc=2.0&method=aria2.getVersion&id=1`，能返回 JSON 就说明 RPC 正常；
3. 手机上用 Aria2App 连一次并添加测试任务，文件出现在 `dir` 指定的目录即全链路打通。

连不上时按 [连接失败与常见问题.md](连接失败与常见问题.md) 排查；下到服务器后的文件要取回手机，走 [DirectDownload怎么设置.md](DirectDownload怎么设置.md)。
