## 一、前提：那台设备上得先跑着 aria2

Aria2App 管远程服务器走的是 aria2 的 JSON-RPC 接口（HTTP 或 WebSocket）。如果你还没在电脑/NAS/服务器上装 aria2，先装好它（Linux 上一般是包管理器直接装 `aria2`，Windows 用官方发布的 zip 包），再按下面把 RPC 模式挂起来。

## 二、服务器端：把 aria2 以 RPC 模式挂起来

最直接的启动命令：

```bash
aria2c --enable-rpc --rpc-listen-all --rpc-secret=换成你的令牌 --dir=/你要保存的目录
```

几项含义：

- `--enable-rpc`：打开 RPC 接口，这是 Aria2App 唯一的远程控制通道；
- `--rpc-listen-all`：允许局域网/外网连入（不加就只监听本机，手机连不上）；
- `--rpc-secret`：访问令牌，**强烈建议设**，没有它任何知道你地址的人都能往你服务器上下东西；
- `--dir`：默认下载目录。

长期挂着建议写成配置文件（`aria2.conf` 里对应 `enable-rpc=true`、`rpc-secret=...`、`dir=...`），再配 systemd 或开机脚本 —— 一份能直接抄的最小配置与各配置项说明见 [服务器端配置怎么写.md](服务器端配置怎么写.md)。配置项的完整口径以 [aria2 官方手册](https://aria2.github.io/manual/en/html/aria2c.html) 为准。

不改端口的话，RPC 默认监听 **6800**。记住这台机器的 IP 和这个端口，下面要填。

## 三、App 端：建一个 profile

在 Aria2App 里新建配置（profile）时，官方 Wiki 给的填法规则是：

- **地址**：只填地址本身，不带协议、不带端口、不带路径。比如完整地址是 `ws://example.com:6800/jsonrpc`，地址栏就填 `example.com`；
- **端口**：只填数字，如 `6800`；
- **endpoint**：保持默认 `/jsonrpc` 不动，除非你服务器端改过。

局域网场景就填内网 IP（如 `192.168.1.8`）；公网场景填域名或公网 IP，并且路由器上要把 6800 端口映射到那台机器。

## 四、认证方式：用令牌，别用密码

App 里认证有三种：令牌（token）、用户名密码、不认证。

- **令牌**：填你在 `--rpc-secret` 里设的那个字符串，这是 aria2 官方推荐的唯一方式；
- **用户名密码**：对应 `--rpc-user` / `--rpc-passwd`，aria2 已官方弃用（deprecated），新部署不要再走这条；
- **不认证**：只在纯内网、且你清楚风险时才考虑。

## 五、加密：要不要勾 SSL/TLS

勾上后 App 会走 HTTPS/WSS 连接。如果你用的是自签名证书：

- 填入证书文件的完整路径，或者把证书装进系统信任区；
- 证书必须是给 aria2 配的那一份（服务器端对应 `--rpc-certificate` 选项）。

只在内网玩、没配证书的话，不勾加密也能连，前提是网络环境你可信任。

## 六、按网络环境自动切地址

这是 profile 里最容易被忽略、也最实用的功能：一个 profile 可以针对不同联网状态填不同地址 —— **始终**（Always）、**WiFi**（可绑定指定 SSID）、**移动网络**、**蓝牙热点**、**以太网**。

典型用法：

- 在家连 WiFi（绑你家 SSID）→ 填服务器的内网地址 `192.168.1.8:6800`；
- 移动网络 → 填公网域名或做了端口映射的地址；
- 配了多条就必须指定一条「默认」，都不匹配时用它兜底。

注意一条 profile 里不能同时设「始终」和其他条件 —— 「始终」会覆盖其余所有条件。

## 七、连上之后

- 添加任务：见 [添加下载任务的几种方式.md](添加下载任务的几种方式.md)；
- 服务器上已经下好的文件想拉回手机：用 DirectDownload，配置见 [DirectDownload怎么设置.md](DirectDownload怎么设置.md)；
- 填完连不上：按 [连接失败与常见问题.md](连接失败与常见问题.md) 从头排查，多数是地址带了 `http://` 前缀、令牌不一致、或端口没放行。

另一种本机玩法：想让 aria2 就跑在你手机里、又被 Aria2App 操控，可以用同作者的 Aria2Android 常驻一个本机 aria2 服务，profile 地址填 `127.0.0.1` 即可；或者直接用 Aria2App 内置的下载器，连 profile 都不用建。
