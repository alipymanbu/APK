## 一、先决定任务落在哪

添加任务前想清楚一件事：这个任务是要下到手机本机，还是下到某台 aria2 服务器上。

- **本机**：用 Aria2App 内置的下载器（应用自带 aria2），不依赖任何 profile。存储位置建议选内置存储，外置 SD 卡在新版安卓上有写入限制，原因与绕法见 [连接失败与常见问题.md](连接失败与常见问题.md)。
- **远程**：先在任务页选中目标服务器的 profile（多个服务器可同时挂着），新任务会加到选中的那台上。远程连接没配好的先看 [怎么连接远程服务器.md](怎么连接远程服务器.md)。

## 二、HTTP(S) 与 (S)FTP 直链

新建任务的输入框里贴直链即可。aria2 本身支持多连接分段下载，服务器端配置允许时，单个文件会同时开多路连接拉快。部分站点需要 Cookie 或请求头才能下，这类参数可以在单个任务的选项里补，不用动全局配置。

单任务里最常改的几个参数（均为 aria2 标准选项，完整口径以官方手册为准）：

| 参数 | 什么时候改 |
| --- | --- |
| `max-connection-per-server` | 直链慢时先调它（部分站点会封高频连接，报错就降回去） |
| `split` | 大文件分更多块，配合上一项用 |
| `user-agent` / `referer` | 站点拒绝默认请求头时，换成浏览器的值 |
| `max-download-limit` | 只限这一个任务的速度，`0` 为不限 |

## 三、种子与磁力（BitTorrent）

官方功能清单里 BitTorrent 相关的能力：

- 直接添加 `.torrent` 种子文件或 `magnet:?xt=...` 磁力链接；
- 用**内置种子搜索引擎**找资源 —— 搜索服务走的是作者自己的网络服务（这也是 F-Droid 标注 `NonFreeNet` 的原因之一），能用与否取决于该服务的现状；
- 下载中可以看 peers 与服务器统计，了解连上了哪些节点。

磁力链接第一次解析元数据会等一段时间（要先把 DHT 网络里的节点摸清），不动才正常，别急着取消。加进去了却没速度，按 [磁力与BT下载怎么提速.md](磁力与BT下载怎么提速.md) 的顺序排查。

## 四、Metalink

把 `.metalink` / `.meta4` 文件交给 Aria2App 即可。Metalink 的价值是一个任务里带多个镜像源和分块校验，aria2 会在下载时自动挑源、逐块校验，和 BT 类似的可靠性。

## 五、URI 文件批量导入

有一批直链要一次性加进去时，做成 URI 文件导入，格式规则（官方 Wiki 口径）：

- **每一行**描述一个要下载的资源；
- 同一个资源的多个镜像写在**同一行**，用空格分隔；
- 不同资源绝不能写进同一行 —— 混了之后 aria2 会把它们当一个任务的多源去下，轻则失败重则文件损坏，而且它不会报错提醒你；
- 磁力链接每行只能放一条。

合法示例：

```text
http://mirror1.site.com/file.zip http://mirror2.site.com/file.zip
http://site2.com/other_file.zip
magnet:?xt=urn:btih:248D0A1CD08284299DE78D5C1ED359BB46717D8C
```

## 六、从浏览器接管下载

你在浏览器里点下载链接时，可以把该链接分享给 Aria2App 处理 —— 官方功能清单里写的是「点浏览器里的链接就能发起下载」。实际路径是系统的分享/打开方式选择器：点链接后选 Aria2App，它会替你把任务建好。哪些浏览器、哪些链接类型能唤起它，取决于系统对链接的处理方式，试一下最直接。

## 七、任务加好后的日常操作

- **暂停 / 恢复 / 停止**：任务列表里逐个操作；
- **看细节**：每个任务可以展开看基础信息与深度信息（peers 列表、每个文件各自的状态与进度，多文件任务里还能只选部分文件下）；
- **改参数**：单任务的选项可以单独调（比如只改这一个任务的速度上限），也可以改 aria2 的全局选项；
- **实时通知**：开了通知权限后，任务进度变化会推送到通知栏，可以只盯你选中的那几个任务。

下到服务器上的文件怎么弄回手机：走 DirectDownload，见 [DirectDownload怎么设置.md](DirectDownload怎么设置.md)。
