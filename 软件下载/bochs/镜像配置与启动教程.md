## 一、先明白：Bochs 启动需要哪几样东西

Bochs 本身只是模拟器硬件，开机要靠这几样凑齐：

1. **BIOS 文件** —— 首次启动时已由应用自动复制到 `/Android/data/net.sourceforge.bochs/files/`，你不用另外下载；
2. **磁盘镜像**（`.img`）—— 一个装好了系统的虚拟硬盘文件，这是你要自己准备的核心文件；
3. **配置** —— 告诉它「硬盘是哪个文件、从哪启动、内存多大」，安卓版可以在图形设置界面点出来，也可以直接编辑 `bochsrc.txt`。

镜像从哪来：网上有现成的 Windows / Linux / DOS 镜像包（常见格式是 zip 压缩包，里面是一个 `.img`），也可以在电脑上用虚拟机装好系统后把磁盘文件拷过来。镜像怎么选、能跑什么，见 [能运行的系统与性能.md](能运行的系统与性能.md)。

## 二、镜像放哪、怎么命名

- **存放位置**：应用数据目录 `/Android/data/net.sourceforge.bochs/files/`。安卓 11 之后系统对 `/Android/data` 做了访问限制，用普通文件管理器可能看不到，需要管理器支持该路径访问，或直接在 Bochs 的设置界面里用文件选择器指定镜像的实际位置（比如放在 `Download` 目录）。
- **命名**：多篇教程与用户反馈的统一口径是——**找不到镜像就闪退时，把镜像改名为 `c.img` 或 `andows.img`**。这两个名字是各篇 Bochs 教程里最常见的默认镜像名，按它命名最省事。
- 改名、移动最好在**应用退出时**做，别在模拟运行中操作镜像文件。

## 三、方式 A：在设置界面里配置（推荐新手）

打开 Bochs 后的设置界面分几个选项卡，按下面顺序点：

1. **存储（Storage）选项卡**：勾选「主储存器」，点右侧「选择」，按路径找到你的 `.img` 镜像 → OK。
2. （可选）勾选「副储存器」+「虚拟文件分配表（vvfat）」，选一个手机上的文件夹 —— 这是手机与虚拟机互传文件的共享目录，需要时再配。
3. **硬件（Hardware）选项卡**，逐项设置：
   - **CPU 型号**：默认即可，各型号都能选；
   - **内存**：按镜像需求拉（Windows XP 建议 256M 起，Win95/98 64~128M 够用），拉满一般也没事，卡就适当调小；
   - **显卡**：随便选一个，但**右边 PCI 槽要与显卡名匹配**（名字里含同样字符的配对，比如 cirrus 配 cirrus）；
   - **声卡 / 网卡**：需要镜像里装了对应驱动才有效，**一般不选**；
   - **「其他」选项卡不要动**。
4. 点右上角**黄色播放三角**（Start）开始启动。

## 四、方式 B：直接编辑 bochsrc.txt（进阶）

Bochs 的配置文件叫 `bochsrc`，安卓版对应 `bochsrc.txt`，用文本编辑器打开改。核心几行长这样：

```
megs: 256
romimage: file=BIOS-bochs-latest
vgaromimage: file=VGABIOS-lgpl-latest
ata0-master: type=disk, path="c.img"
boot: disk
```

- `megs` —— 内存大小（MB）；
- `path="c.img"` —— 硬盘镜像文件名，**要与你实际放的文件名一致**；
- `boot` —— 启动顺序（`disk` 从硬盘启，装系统时可能要改成 `cdrom` / `floppy`）。

官方手册对格式的要求很严格：**空格数、大小写都要照格式写**（见 [bochsrc 手册](https://bochs.sourceforge.io/doc/docbook/user/bochsrc.html)）。写错一行就会启动失败，改完存盘再启动。

## 五、启动与退出

- 点播放三角后，正常流程是：BIOS 自检 → 读硬盘 → 进系统。第一次进系统可能要几分钟，指令级模拟就是慢，属正常。
- **退出要走正常途径**：先在虚拟机里点「开始 → 关机」把系统关掉，等它关完再退出 Bochs 应用。镜像写到一半被强制切断有损坏风险，坏了轻则进不去系统、重则整个镜像要重做。
- 启动卡住或闪退，按 [闪退与黑屏排查.md](闪退与黑屏排查.md) 对照处理。
