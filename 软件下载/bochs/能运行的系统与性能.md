## 一、先压住预期：它是指令级模拟，慢是常态

Bochs 是**逐条指令翻译执行**的模拟器（不是硬件加速虚拟化），在手机上跑 x86 系统，速度大致相当于当年那台机器跑在更低主频上 —— 进系统几分钟、点个菜单等一下，都正常。你要的是「能在手机上跑起来」，不是「流畅办公」。真需要快，桌面上的同名项目也一样慢，这不是手机端的毛病。

## 二、能运行哪些系统

按资料来源分两档：

**上游官方口径**（[Bochs 主页](https://bochs.sourceforge.io/)）：能在模拟环境里运行大多数操作系统，点名了 **Linux、DOS、Microsoft Windows**；CPU 可模拟从早期 386 到 x86-64 的型号。

**用户实测反馈**（多篇教程与用户评价，仅供你选镜像时参考）：

| 系统 | 用户反馈的情况 |
| --- | --- |
| MS-DOS / FreeDOS | 最轻量，进得快，适合怀旧软件与老游戏 |
| Windows 95 | 反馈普遍比 98 快，且对触屏相对友好 |
| Windows 98 | 能跑，但「卡在启动画面」的问题在 98 上最常见 |
| Windows XP | 能跑，内存建议 256M 起，镜像大、进系统慢 |
| Linux（如老版 Ubuntu） | 有用户反馈可启动，需镜像自带对应网卡驱动 |

注意：以上为二手反馈，不是实测结论 —— 同一个镜像在不同手机上表现可能不同，选镜像前多看几篇同类反馈。

## 三、性能参考值

有教程给出的「跑得动」的手机参考配置：**CPU 至少四核 1.7GHz、内存至少 1GB、存储读写至少 20MB/s**（数值来自用户教程，截至该文发布时，以你实际体验为准）。

卡顿时可做的事，按性价比排序：

1. **关掉后台应用**，把内存让给模拟器；
2. **降低分辨率与颜色深度**（设置里调显示相关项）；
3. **调小 `megs` 内存**——不是越大越好，镜像用不了那么多就别浪费；
4. 换更轻的镜像（DOS/95 比 XP 轻得多）。

## 四、联网、声音、共享文件的边界

- **联网**：用户反馈里明确说**这个安卓版目前上不了网**（有用户说自己碰到过一次能开网页，重启后就再也不行）。上游 Bochs 本身带虚拟网卡能力，但安卓端口这边按「不可用」预期即可。
- **声音**：设置里有声卡选项，但**要镜像里装了对应驱动才出声**；很多现成镜像没装驱动，选了也没声音。
- **共享文件**：想把手机文件放进虚拟机，用设置里的「副储存器 + 虚拟文件分配表（vvfat）」挂一个手机文件夹（配法见 [镜像配置与启动教程.md](镜像配置与启动教程.md)）。注意 vvfat 模式**不支持 Bochs 的存档/恢复功能**（上游手册口径）。

## 五、存储要留多少空间

- 应用本体 12.79M；
- 系统镜像：DOS 类几十 MB，Win95/98 常见 1~2GB，XP 常见几 GB；
- 系统运行时会持续往镜像里写数据，**存储要留出富余**，别卡着剩余空间装系统。

空间不够时最稳的做法是换小镜像，而不是解压到一半硬撑 —— 写入中断留下的半成品，就是 [闪退与黑屏排查.md](闪退与黑屏排查.md) 里的「镜像损坏」。
