## 一、什么时候需要自己做镜像

网上下的现成镜像（别人装好的系统）能直接用，但有两种情况你得自己做：想跑的系统没有现成镜像；或现成镜像里装的东西不对路，想自己从零装一遍。自己做镜像的完整思路就一句 —— **在电脑上建一个空白虚拟硬盘，把系统装进去，再把这个文件拷到手机**。

## 二、格式选什么：raw，别选 qcow2

Bochs 认的是**扁平（raw）格式**的磁盘镜像 —— 一个文件就是一块完整硬盘。用 QEMU 系工具建镜像时要显式指定：

```
qemu-img create -f raw c.img 4G
```

这条命令生成一个 4GB 的空白硬盘文件 `c.img`（`qemu-img` 是 QEMU 配套工具，Windows/Linux 都有打包；命令含义见 [QEMU 官方文档](https://www.qemu.org/docs/master/tools/qemu-img.html)）。

| 格式 | 能不能给 Bochs 用 |
| --- | --- |
| `raw` | 直接用，推荐 |
| `qcow2` | **不能直接用**，要先转：`qemu-img convert -O raw in.qcow2 out.img` |
| `vmdk` / `vdi` | 同样要先转成 raw |

大小按目标系统估：DOS 几百 MB 够，Win95/98 建议 1~2GB，XP 建议 4GB 起。**建大不吃亏**（raw 稀疏文件只在写入时占实际空间），建小了装到一半空间不够才麻烦。

Bochs 官方工具链里也有个建盘工具 `bximage`（图形界面，问你 type / drive / size 然后生成 `.img`），效果与 `qemu-img -f raw` 一样，用哪个顺手用哪个。

## 三、把系统装进镜像的两条路

**路线 1：电脑虚拟机里装（最直观）**

1. 用 `qemu-img` 建好空白 `c.img`；
2. 在电脑虚拟机软件（VirtualBox / VMware / QEMU 都行）里把 `c.img` 挂成硬盘、系统 ISO 挂成光驱；
3. 正常走完系统安装，装好关机；
4. 把 `c.img` 拷到手机的 Bochs 目录，在设置里挂上启动。

QEMU 命令行示例（`-boot d` 表示先从光驱启，装完去掉它就是从硬盘启）：

```
qemu-system-x86_64 -m 256 -hda c.img -cdrom system.iso -boot d
```

**路线 2：直接在 Bochs 里装（纯手机操作，慢）**

1. 空白 `c.img` 拷进手机并挂为硬盘，系统 ISO 转成光驱镜像挂上（`boot` 设为 `cdrom`）；
2. 启动后从光驱进安装程序，把系统装进 `c.img`；
3. 装完把 `boot` 改回 `disk`。

这条路对触屏操作要求高（分区、输命令都要打字），建议先看 [触屏与键盘操作.md](触屏与键盘操作.md)、接好外接键盘再动手；安装过程在指令级模拟里会非常慢，是正常现象（见 [能运行的系统与性能.md](能运行的系统与性能.md)）。

## 四、拷到手机前的三件事

1. **确认镜像已正常关机卸载**：电脑上虚拟机要正常关机，别在运行中直接拷文件，半成品数据读出来就是坏镜像；
2. **命名**：拷过去后按 [镜像配置与启动教程.md](镜像配置与启动教程.md) 的口径命名（`c.img` / `andows.img` 最保险）；
3. **先在电脑上验一遍**：同一个 `c.img` 在电脑虚拟机能正常进系统，再往手机拷 —— 电脑上都进不去的镜像，手机上更进不去，省一趟来回。
