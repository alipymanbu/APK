## 一、这是个什么软件

Bochs 是一个开源的 x86 架构 PC 模拟器（上游项目主页：[bochs.sourceforge.io](https://bochs.sourceforge.io/)，源码在 [github.com/bochs-emu/Bochs](https://github.com/bochs-emu/Bochs)），用纯软件逐条指令模拟 CPU、内存、BIOS、显卡这些 PC 硬件，所以在它里面能装真实的 x86 系统（DOS、Windows、Linux 都行）。

你在手机上装的这个 APK 是它的 **安卓移植版**，由 Lyubomyr Lisen 与 Maxim Voloshin 移植、界面部分基于 pelya 的 libSDL 移植（移植源码见 [github.com/lubomyr/bochs](https://github.com/lubomyr/bochs)）。它与上游同用 LGPL 开源许可。

**本篇附带的这份安装包信息（以本地文件为准，网上搜到的是别处的版本）：**

| 项目 | 值 |
| --- | --- |
| 版本 | 2.6.11 |
| 包名 | `net.sourceforge.bochs` |
| 安装包大小 | 12.79M |
| MD5 | `CE6076AA37F956A7AF172DA590E858EE` |
| 系统要求 | 安卓 5.2 以上 |
| 对应上游版本 | Bochs 2.6.11（上游于 2020-01-05 发布该版本；上游最新版以[官方发布页](https://sourceforge.net/projects/bochs/files/bochs)为准） |

## 二、获取安装包并安装

1. 从 [bochs 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a88de00c46dd) 下载 APK 到手机。
2. 下载完可先核对一下大小是否为 12.79M，对得上再装。
3. 点击 APK 安装。安卓会弹「不允许安装未知来源应用」，按提示允许该来源（不同系统路径略有差异，一般在 设置 → 安全/安装未知应用 里给文件管理器或浏览器授权）。
4. 装完先别急着配镜像，先做下一步的首次启动。

## 三、首次启动：等它把文件复制完

第一次打开 Bochs，它会把 BIOS 等运行文件复制到应用数据目录（`/Android/data/net.sourceforge.bochs/files/`），**这一步要等它跑完**：

1. 打开应用，保持在前台，等到屏幕上出现 BIOS 画面或启动界面。
2. 看到画面说明运行文件已就位，此时**先退出应用**（Bochs 没有系统镜像时不会自己开机，先退出、再去放镜像，步骤最清楚）。
3. 接下来要放磁盘镜像、改配置，照 [镜像配置与启动教程.md](镜像配置与启动教程.md) 做即可。

## 四、安装前后要记住的三件事

- **装完不是就能用**：Bochs 只是「一台没装系统的裸机」，你还得给它一个磁盘镜像文件（`.img`），否则打开只会停在 BIOS 画面或直接退出。
- **别装错包名**：正版包名是 `net.sourceforge.bochs`，如果手机上已装了别的 x86 模拟器（如 Limbo、ExaGear），它们的镜像与配置互不通用。
- **空间要留够**：应用本体才 12.79M，但系统镜像动辄几百 MB 到几 GB，装之前先看下存储剩余空间。

装好之后的问题（闪退、黑屏、卡住不动）统一看 [闪退与黑屏排查.md](闪退与黑屏排查.md)。
