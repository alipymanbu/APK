# Bochs 触屏与键盘操作

> 手机上没有鼠标键盘，这篇讲怎么用触屏、音量键与虚拟键盘把虚拟机操作顺。

## 一、先建立手感：屏幕就是触摸板

进系统后，你的手指对应的是**笔记本那种触摸板**，不是直接戳屏幕：

- **在屏幕上滑动** = 移动鼠标指针（指针移动方向跟手指走）；
- **点按屏幕** = 鼠标左键单击；
- **双击**：先滑到目标上，快速点两下；点不准时改用「单击选中 + 按回车键打开」更稳。

小屏上指针操作天生费劲，第一次用建议接个外接鼠标（蓝牙或 OTG 都行），手感会好一大截。

## 二、按键映射（用户教程反馈的默认口径）

多篇用户教程给出的映射一致，按下表操作（不同版本可能有差异，以你机器上实际手感为准）：

| 手机按键 / 动作 | 对应 PC 操作 |
| --- | --- |
| 滑动触屏 | 移动鼠标指针 |
| 点按屏幕 | 鼠标左键单击 |
| 音量上键 | 鼠标左键单击 |
| 音量下键 | 鼠标右键单击 |
| 菜单键 | 回车（Enter） |
| 返回键 | Esc |
| 点屏幕左下角 | 唤起手机输入法 |

这套映射正好补上触屏最难的两件事：**右键**（音量下键）和**回车**（菜单键）。老系统里双击麻烦，就用「音量上键单击选中 → 菜单键回车打开」替代。

## 三、打字：唤起手机输入法

要在虚拟机里输入文字（比如登录框、命令），点屏幕左下角唤起输入法，直接在手机键盘上打 —— 字符会送进虚拟机。注意：

- 中文输入法打进去的是中文字符，DOS 这类环境未必认；**英文与数字符号最稳**；
- Ctrl、Alt、Esc 这类功能键，用返回键（Esc）或键盘上带修饰键的布局解决；
- 输入法不弹出时，先确认手机键盘没被禁用，再重启应用试一次（见 [闪退与黑屏排查.md](闪退与黑屏排查.md)）。

## 四、文件怎么进虚拟机（共享文件夹）

想把手机上的文件放进虚拟机系统里用，两条路：

1. **共享文件夹（推荐）**：在设置里勾「副储存器 + 虚拟文件分配表（vvfat）」选一个手机文件夹（配法见 [镜像配置与启动教程.md](镜像配置与启动教程.md)）。
2. **HDD 文件夹**：有教程反馈在内存卡根目录建 `HDD` 文件夹、把文件放进去，重启虚拟机后会在系统里挂成一个盘（老版教程口径，是否生效看你这个版本）。

放进文件后**重启一次虚拟机系统**才会挂上，别急着在系统里找。

## 五、退出与回来

- 想临时切出：按手机主页键（Home）回桌面，Bochs 进程还活着；
- 再点开 Bochs 图标继续刚才的会话；
- 彻底结束：**先在虚拟机里正常关机**，再退出应用（原因见 [闪退与黑屏排查.md](闪退与黑屏排查.md) 的「保命操作」）。
