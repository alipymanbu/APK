## 一、订阅价格与规则

根据应用在 App Store 公布的订阅说明（安卓侧的金额与周期以应用内支付页面为准）：

| 项目 | 说明 |
| --- | --- |
| 价格 | 49 元 / 月 |
| 免费试用 | 3 天，试用期内不收费 |
| 自动续订 | 不关闭就会在周期结束时按 49 元/月 续订 |
| 关闭时限 | **到期前 24 小时**关掉才不会扣下一期 |
| 扣费提醒 | 每次扣费前 3 天发邮件提醒 |
| 管理入口 | 设置 → Apple ID → 订阅 |

**3 天试用是最容易踩坑的一环**：它是自动续订的入口，试用期内不开「取消续订」，第 4 天就会按月扣款。建议开通当天就顺手把续订关掉——试用照常生效，到期自然停，不会被扣。

## 二、苹果手机怎么取消

1. 打开 **设置** → 点顶部的 **Apple ID（你的名字）** → **订阅**。
2. 在列表里找到苏诺之音（Suno AI 音乐创作）。
3. 点 **取消订阅**，系统会提示你可用到当前周期结束。

取消后当期权益仍然保留，到期后失效。这一步只能在手机上操作，别去网页里找入口——苹果的内购订阅只有这一个官方管理处。

## 三、安卓手机怎么取消

安卓的续订跟着**实际扣款渠道**走，三种常见情况：

- **应用内支付宝/微信支付**：一般在应用的「我的 → 设置 → 自动续费管理」里直接关，关完当场生效。
- **微信扣费服务**：微信 → 我 → 服务 → 钱包 → 支付设置 → 自动续费，选中后关闭。
- **支付宝免密支付/自动扣款**：支付宝 → 我 → 设置 → 支付设置 → 免密支付/自动扣款，选中后解约。

找不到对应条目，说明当前没有生效的自动扣款协议，无需处理。扣款渠道以你当时支付页面显示的为准；仍不确定，可对照应用内「会员/订阅」页面的说明操作。

## 四、取消后还能用吗

- 当期会员到期前，已开通的功能照常可用；
- 到期后应用回到未订阅状态，生成次数、会员专属工具按未订阅口径计算；
- 已经生成并保存在应用里的作品，不会因为退订被删除（云端存储的具体保留时长以应用内说明为准）。

## 五、关于扣费与退款

对扣费有异议，先确认是不是「试用期忘了关」或「到期前 24 小时之后才关」这两种最常见的情况（前者见第一节）。苹果渠道的扣费走 Apple，退款要在 Apple 的报告问题页面申请；安卓渠道向对应支付平台申诉。应用商店的购买记录里能查到每一笔扣款的时间与金额，先把记录截图留好再申诉。

另外，苏诺之音官方还提供单独的**音乐版权申请**服务（音频、歌词向版权局做登记，需实名认证，标注 5 个工作日下证）——它与会员订阅是两码事，收费独立，不包含在 49 元/月 里。

想先确认这款应用值不值得开会员，可以对照 [和官方Suno有什么区别.md](和官方Suno有什么区别.md) 看清它与另一款同名应用的差别；安装、生成过程中的问题见 [常见问题与解决方法.md](常见问题与解决方法.md)。
