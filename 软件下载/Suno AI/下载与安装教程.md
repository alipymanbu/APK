## 一、先确认你要装的是哪一个

「Suno AI」这个名字市面上有两款完全不同的应用：一款是国内团队做的中文 AI 音乐创作应用（中文名**苏诺之音**，下面讲的就是它），另一款是美国 Suno, Inc 出的官方应用。两者开发方、包名、账号体系都不一样，装错会白白浪费时间。区分方法看包名，详见 [和官方Suno有什么区别.md](和官方Suno有什么区别.md)。

本篇要装的这一款，安装包事实如下（以本地保存的这份 APK 为准，网上搜到的版本未必相同）：

| 项目 | 值 |
| --- | --- |
| 应用名 | Suno AI（苏诺之音） |
| 版本 | 1.0.0.3 |
| 包名 | `com.csd.musicai` |
| 安装包大小 | 14.43M |
| MD5 | `D6F891D370880C00D38E7D0F05D248D8` |
| 开发者 | 深圳市超时代软件有限公司 |
| 系统要求 | 安卓 5.2 及以上（以安装时的提示为准） |

下载别的渠道的安装包时，可以用上面的 MD5 核对是不是同一份文件（校验工具算出的值逐字符一致才算对上）。

## 二、从网盘获取安装包

1. 打开 [Suno AI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ebe3a096da6d)，把分享内容转存到自己的网盘。
2. 在网盘里找到该应用的文件夹，里面是 `.apk` 安装包与一个说明用的 txt。
3. 在手机上打开夸克，进入刚转存的文件夹，点击 apk 文件开始下载；也可以先在电脑上下载好，再通过数据线、局域网传到手机。

文件夹名末尾带「（先保存再下载）」是刻意的：网盘分享链接可能失效，先转存到自己账号里就不用担心拿不到了。

## 三、安装步骤

1. 点击下载好的 apk 文件，系统会弹出安装界面。
2. 如果提示「不允许安装未知来源的应用」，按提示进入设置，允许**当前这个来源**（比如夸克）安装应用，再返回继续装。不同品牌的入口名称略有差别，常见路径是：设置 → 安全/隐私 → 安装未知应用。
3. 等安装完成，打开应用。

整个安装包只有 14.43M，正常几秒到十几秒就能装完。若安装界面提示「解析包时出现问题」或「应用未安装」，多半是下载不完整或系统版本过低，按 [常见问题与解决方法.md](常见问题与解决方法.md) 里的对应条目处理。

## 四、安装时会见到的权限提示

这个应用声明的权限覆盖网络、存储与安装相关几类，实际弹出哪些由你手机的系统版本与使用场景决定：

| 权限 | 什么时候会用到 |
| --- | --- |
| 网络访问、查看 WLAN 连接 | 生成音乐、加载内容都需要联网 |
| 读取/写入外部存储、SD 卡 | 把导出的音频文件存到手机里 |
| 请求安装文件包 | 只有应用内引导你装别的安装包时才会用到 |
| 修改系统设置 | 部分机型上调整与播放、铃声相关的设置项 |

拿不准的权限可以先拒绝再观察：拒绝存储权限通常只影响「导出音频到本地」，不影响在线生成。若因为误拒导致功能不灵，去 设置 → 应用 → 找到该应用 → 权限 里重新允许即可。

## 五、装完打不开怎么办

装上了但闪退、白屏或卡在启动页，先按 [常见问题与解决方法.md](常见问题与解决方法.md) 逐条排查；确认自己装的是不是官方那款、版本对不对，可以对照 [和官方Suno有什么区别.md](和官方Suno有什么区别.md)。能正常进入后，第一次上手从 [灵感模式和自定义模式怎么选.md](灵感模式和自定义模式怎么选.md) 看起。
