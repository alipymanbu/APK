## 一、先分清是哪一种「闪退」

「闪退」在实际使用里至少是五种不同的问题，先对号入座再动手：

| 现象 | 大概率原因 | 先做什么 |
| --- | --- | --- |
| 点开 Game Killer 应用本身就退出 | 安装包不完整或系统版本过低 | 对照[下载与安装教程.md](下载与安装教程.md)第五节重新下载安装 |
| 游戏加进 Box 时失败或卡住 | 存储空间不足——克隆是把游戏复制一份，占用直接翻倍 | 清出空间（建议留 2 GB 以上）再克隆 |
| 游戏在沙箱里一点启动就退出 | 沙箱与该游戏的兼容性问题 | 跳到第三节，升级是第一手段 |
| 玩一段时间后被退出 | 设备发热降频、内存被其他应用挤占 | 放凉设备、清后台后重试 |
| 游戏能玩但悬浮球不出现 | 悬浮窗权限被系统关了 | 系统设置 → 应用 → Game Killer → 「显示在其他应用上层」打开 |

## 二、克隆与启动失败的几个具体检查点

1. **被克隆的游戏是本机已装的正身**。Box 加不进游戏时，先确认那个游戏还装在手机上、没有处于「已停用」状态。
2. **沙箱副本与原版是两份数据**。在沙箱里闪退不代表原版也闪退，反过来也一样——排查时先弄清出问题的是哪一份。
3. **32 位与 64 位**。部分老游戏按 32 位打包，沙箱对两类包的处理有差异；官方更新说明里就专门修过「32 位 Box 存档导入失败」（5.3.4.2）。碰到存档导入失败的老游戏，优先升级应用而不是反复重试。
4. **强联网游戏的数据在远端**。启动时要联网校验的那类游戏，在断网模式或网络不稳时可能直接退出——先把断网模式关掉试试。

## 三、升级是性价比最高的手段

沙箱兼容性是官方更新说明的常客：从 5.2.3 到 5.3.5，几乎每一版都在提「沙箱兼容性提升 / 游戏适配性更好」，5.3.6 更是直接写了「优化部分游戏启动首次闪退的问题」。这意味着：

- 你踩到的「某游戏在沙箱里启动就闪退」，很可能就是官方在某次更新里修掉的那一批；
- 排查顺序应当是**先升级再看别的**——各版本变化见[版本与更新说明.md](版本与更新说明.md)，升级前先按[常见问题解答.md](常见问题解答.md)第六节把沙箱里要保留的存档处理掉。

## 四、升级后仍闪退的通用做法

下面这些是安卓设备通用的排查动作（不是这个应用特有的问题，也未必每次都管用），逐个试：

1. 系统设置 → 应用 → Game Killer → 清除缓存（不动数据）；
2. 重启手机再进沙箱；
3. 换一个分身空间重新克隆同一个游戏，排除这个分身环境本身坏了；
4. 关掉「断网模式」这类会改变沙箱内环境的开关后再启动。

## 五、反馈渠道

5.3.3 起官方在应用内加了反馈渠道（更早的 5.2.3 更新说明里还提到过 Telegram 反馈通道），反馈时把这几样一起给出去，来回会快很多：游戏名、游戏版本、你用的 Game Killer 版本（查法见[版本与更新说明.md](版本与更新说明.md)第四节）、闪退发生在哪一步。入口位置以应用内实际显示为准。
