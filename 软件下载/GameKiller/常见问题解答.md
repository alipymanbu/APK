## 一、需要 root 吗

5.x 系列不需要。这一版走的是沙箱方案：游戏被克隆进 Box 里运行，工具在沙箱内部生效，全程不要求 root。需要 root 的是早年另一个同名的内存修改工具（见下一题），两者别混。

## 二、搜出来的好几个「Game Killer」，是同一个东西吗

不是。这个名字下至少有三个完全不同的应用，认包名最可靠：

| 应用 | 包名 | 它是什么 |
| --- | --- | --- |
| 本篇讲的这个 | `com.gk.speed.booster.tool` | 游戏工具类应用：资源浏览 + Box 沙箱 + 悬浮工具 |
| Google Play 上的拼图游戏 | `com.gamefun.killer` | 一款用你手机里已装应用的图标做谜面的休闲猜谜游戏，与游戏工具毫无关系 |
| 早年的内存修改工具 | 各类镜像站版本不一 | 多年前就停止维护的老工具，现在网上流传的来源混杂 |

安装前核对一眼包名（方式见[下载与安装教程.md](下载与安装教程.md)第四节的核对表），装错名字相同的东西是最常见的弯路。

## 三、为什么会弹广告

免费使用伴随广告，这是它官方更新说明里反复出现的主线：5.3.2.2 说「调整广告弹窗，降低出现频率」，5.3.3 起加入会员福利，5.4.0 又改成了看一次广告解锁功能的策略。具体到 5.3.5 这一版，广告出现的形式与频率以应用内实际显示为准。

## 四、为什么申请这些权限

| 权限 | 用在哪 |
| --- | --- |
| 存储（读写） | 导入本机游戏与存档文件、缓存下载内容 |
| 安装未知应用 | 沙箱克隆与资源下载后要在应用内完成安装，系统要求单独授权 |
| 网络 | 资源列表、下载管理器都要联网 |
| 显示在其他应用上层 | 悬浮球与悬浮工具；不给这个权限，游戏里看不到悬浮球 |

## 五、有些游戏在沙箱里启动不了，或工具不生效

先按顺序过一遍：

1. 游戏是不是**从 Box 里启动**的——点系统桌面图标启动的原版不在沙箱里，工具自然不管用。
2. 悬浮窗权限（见上一节）给了没有。
3. 游戏本身对沙箱环境的兼容性。官方更新说明从 5.2.3 到 5.3.5 每一版都在提沙箱兼容性改进，说明这本来就是这类应用的主要摩擦点；启动闪退时先把应用升到可用的最新版再试，逐项排查见[游戏闪退与不兼容排查.md](游戏闪退与不兼容排查.md)。
4. 强联网、数据存远端的游戏，很多本地工具类功能对它不起作用——这不是设置问题，是数据不在你这边的物理限制。

## 六、怎么卸载干净

两步，顺序别反：

1. 先卸载沙箱里克隆出来的游戏副本（在 Box 列表或分身空间里删，入口以应用内实际显示为准）。
2. 再在系统设置 → 应用里卸载 Game Killer 本体。反过来的话，残留的沙箱副本要再手动找一遍。

卸载会连带清掉沙箱内的进度与存档，有要保留的东西先处理完再动手。
