## 二、5.3.5 更新了什么

按官方更新说明，5.3.5 的改动是四条：

1. 沙箱 Box 版本升级，游戏适配性更好；
2. 优化存档下载效率；
3. 本地游戏存档及变速工具匹配；
4. 其他体验优化与问题修复。

对日常使用的直接影响：从 5.3.4 之前升上来的用户，最直观的感受是沙箱里能正常跑的游戏变多了，变速工具与本地存档的配合更稳。

## 四、怎么查自己装的是哪个版本

两种查法任选：

- 系统设置 → 应用管理 → 找到 Game Killer → 看「版本号」；
- 部分版本可在应用内右上角三个点的菜单里找到「关于 / 设置」入口查看版本。

查完回到[下载与安装教程.md](下载与安装教程.md)第四节核对包名是否为 `com.gk.speed.booster.tool`，排除装到同名应用的情况。

## 五、要不要升级

分三种情况：

- **只是想把工具用起来**：5.3.5 已经覆盖沙箱、变速、连点器、多开这一整套核心能力，够用。
- **碰到具体兼容性问题**（某游戏在沙箱里闪退、悬浮球不显示）：优先升级再试，5.2.3 以来每一版更新说明都在处理这类问题，新版本大概率已修掉你踩的那个坑；排查步骤见[游戏闪退与不兼容排查.md](游戏闪退与不兼容排查.md)。
- **在意界面与策略差异**：5.3.3 之后广告与会员策略有变化，升级前先看当版官方更新说明，确认接受再动。
