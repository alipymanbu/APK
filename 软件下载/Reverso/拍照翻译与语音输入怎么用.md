# Reverso 拍照翻译与语音输入怎么用

> 拍照翻译和语音输入是 Reverso 手机端最省事的两条取词路径，适合菜单、路牌、说明书，以及不方便打字、不熟悉拼写的场合。这篇讲这两条路径分别怎么用、拍得准的要点，以及它们共同的前提与限制。

## 一、先想清楚该用哪种输入

同一个词，用键盘打、用嘴说、用相机扫，效果差别不小。大致这么分：

| 场景 | 更省事的做法 | 原因 |
| --- | --- | --- |
| 会拼写、只是不确定意思 | 键盘输入 | 最准，不受发音和光线影响 |
| 不知道拼写，或语言用的是非拉丁字母 | 语音输入 | 绕过拼写这一关，直接出声 |
| 菜单、路牌、说明书、药品盒 | 拍照翻译 | 不用逐字敲，整块取词 |
| 安静场合 / 不方便出声 | 键盘或拍照 | 语音需要麦克风权限与环境 |

## 二、语音输入怎么用

1. 确认已经给过麦克风权限（没给过会在第一次使用时弹出申请，同意即可；当初拒绝了，去系统设置的权限里补上）。
2. 在输入区找到语音入口，点一下开始说话。
3. 说完后，识别出来的文字会落在输入框里，再按普通查词的方式提交。
4. 识别结果不对时，直接改文字或重说一遍，不必从头开始。

**几个实际坑：**

- **俄语、阿拉伯语、希伯来语这类语言**，键盘上根本没有对应字母，硬敲很不现实 —— 语音输入在这类语言上的收益最大。
- **专有名词和人名**识别容易走样，识别后最好扫一眼再提交。
- **语音需要联网**，飞行模式或断网时用不了，见 [离线词典与离线可用范围.md](离线词典与离线可用范围.md)。

## 三、拍照翻译怎么用

1. 确认已给相机权限。
2. 从拍照入口打开相机，把要翻译的文字放进取景框。
3. 对准、稳住，让文字尽量占满画面，然后拍照。
4. 识别出的文字会给出对应译文；识别不准时可以裁掉无关部分再拍一次。

**拍得准的几个要点：**

| 问题 | 表现 | 改法 |
| --- | --- | --- |
| 光线不足 | 识别出乱码或漏字 | 挪到亮处，或用手电筒补光 |
| 抖动 / 距离太远 | 文字糊成一片 | 靠近平一点，双手稳住，等对焦完成再按 |
| 角度太斜 | 行首行尾被吃掉 | 尽量正对拍摄，避免大角度俯拍 |
| 画面里文字太杂 | 混入不需要的段落 | 只框住你要的那一块 |

**适合拍的对象：** 餐厅菜单、路牌、商品包装、说明书、药品盒上的用法用量说明。**不适合的：** 手写体、艺术字体、屏幕反光严重的页面 —— 这类识别率明显会掉。

## 四、相机取词之后还能做什么

拍照识别出来的结果，和你手动输入一个词得到的是同一套内容：能看到多个候选译文、点词性标签筛选、看例句、听发音、复制、加星标收藏。

所以遇到看不懂的整段外文，比较顺的流程是：**先拍照取词 → 看译文和例句 → 把里面真正要记的词星标收藏 → 回头在背单词里练**。收藏和练习的具体做法见 [收藏夹与词汇表怎么管理.md](收藏夹与词汇表怎么管理.md)。

## 五、这两条路径的共同限制

- **都要联网。** 语音识别和拍照识别都在服务端完成，断网时两个入口都用不了。
- **都要对应权限。** 权限没给或在系统里被收回，入口会直接不可用，不是应用坏了。
- **都只是取词的快捷方式。** 真正决定翻译质量的是取到的文字准不准 —— 文字识别错了，后面的译文多半也跟着错。识别结果能改就改，别将错就错。
