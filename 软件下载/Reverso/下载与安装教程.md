## 一、这份安装包对应的是什么

Reverso 是 Reverso 官方（官网 [www.reverso.net](https://www.reverso.net/)）推出的一套翻译与语言学习工具，网页版、浏览器扩展和手机端共用同一个账号体系。网盘里这份是**安卓手机 / 平板版**，相机取词、语音搜索、拍照翻译、离线词典这些都在手机端。

先把这份包的识别信息记下来，装之前装之后都用得上：

| 项目 | 值 |
| --- | --- |
| 应用名 | Reverso |
| 版本 | 14.2.0 |
| 包名 | `com.softissimo.reverso.context` |
| 安装包大小 | 约 84.36 MB（110,544,602 字节） |
| MD5 | `8C7AAF0F23A92D6AA612A5B17EC1BFBC` |
| 记录时间 | 2026-09-23 |

这里的版本号是**网盘里这份安装包**的版本，不等于应用商店此刻的最新版。装完想确认自己装的是哪一版，在应用内的设置 / 关于里能看到。

## 二、系统要求怎么对

安卓端的系统版本门槛由官方在应用商店页面标注，并随版本更新调整，**以商店当页显示为准**。装之前对一下两处：

1. 手机「设置 → 关于手机」里的 Android 版本号；
2. 应用商店页面上标注的最低 Android 版本。

手机和平板都用同一个包。iOS 版和电脑端是另外的安装方式，本文不覆盖。

## 三、拿安装包

在手机上打开 [Reverso 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4499800555fe)，先转存到自己的网盘，再下载到手机本地；也可以直接下载到本地。转存的好处是链接失效后文件仍在自己的网盘里，重装、换机都不用再找。

下载完先在文件管理器里看一眼：

| 核对项 | 预期 | 对不上怎么办 |
| --- | --- | --- |
| 后缀名 | `.apk` | 下成压缩包或被改名的，重新下载 |
| 体积 | 约 84.36 MB | 明显偏小说明传输中断，删掉重下 |
| MD5（可选） | `8C7AAF0F23A92D6AA612A5B17EC1BFBC` | 用文件管理器或校验工具算一次，对不上就重下 |

## 四、安装步骤

1. 在文件管理器里点开刚下好的 `.apk`。
2. 如果系统弹出「禁止安装未知应用」「此来源不允许安装」，按提示进「设置 → 安全 / 应用 → 特殊权限 → 安装未知应用」，把**你正在用来打开这个文件的那个应用**（文件管理器或浏览器）的开关打开，再回来重试。
3. 确认安装，等待进度走完。安装过程本身不需要联网下载额外数据，但建议保持网络，方便首次打开时加载。
4. 装完回到桌面或应用抽屉，找到名为 Reverso 的图标。
5. 首次打开时按引导选择你常用的语言对，就可以直接查词，**不需要登录**。

## 五、第一次打开建议做的三件事

**第一件：选好语言对。** 主界面上的两个语言选择器分别代表「从哪种语言」和「到哪种语言」，按你实际要用的语言对设一次，后面查询不用每次重选。

**第二件：想清楚要不要登录。** 不登录就能查词、听发音、看例句；登录的意义是让收藏夹、词汇表和搜索历史在手机、网页和浏览器扩展之间同步。要同步再登录，见 [注册登录与多设备同步.md](注册登录与多设备同步.md)。

**第三件：按需给权限。** 第一次用到对应功能时系统才会弹权限申请，给不给只影响那一个功能：

| 权限 | 什么时候用 | 不给会怎样 |
| --- | --- | --- |
| 麦克风 | 语音搜索入口 | 语音输入用不了，只能用键盘打字 |
| 相机 | 拍照翻译 | 相机取词用不了，手动输入仍正常 |
| 存储 / 文件 | 下载离线词典、保存内容到本地 | 离线词典包下不下来 |

不需要的功能就别给权限，用到时再开也来得及。

## 六、升级、卸载与数据

- **升级**：应用商店里更新即可。网盘里这份固定是 14.2.0，不会跟着商店走；想换版本，从商店或新的安装包覆盖安装都行，同一个包名可以覆盖，不用先卸载。
- **卸载**：长按图标卸载即可。卸载会清掉应用本地的离线词典与本地历史。
- **数据能不能留下**：收藏夹、词汇表、搜索历史这类和账号绑定的数据，只要之前登录过，重装后登录同一账号就会回来（见 [注册登录与多设备同步.md](注册登录与多设备同步.md)）；没登录过的本地数据，卸载即丢。

## 七、装不上时先看这几条

- 提示「解析包错误」「应用未安装」：多半是下载不完整或包与系统版本不匹配，先按第三节核对体积、重下一遍，再对一下商店页的系统要求。
- 提示「已存在更高版本」：手机上已经装了更新的一版，先卸载旧的再装这份，或直接继续用商店版。
- 安装按钮点不动：检查是不是开了「仅允许通过商店安装应用」这类系统开关。
- 装上了但一打开就退出：先重启手机再开一次，仍不行见 [常见问题与排查.md](常见问题与排查.md)。
