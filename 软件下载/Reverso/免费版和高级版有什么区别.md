# Reverso 免费版和高级版有什么区别

> Reverso 的核心查词功能是长期免费的，高级版主要去掉广告并放开次数与离线能力。这篇讲免费版够不够用、高级版多出哪些东西、在哪买怎么退订，以及为什么卸载了应用还会继续扣费。

## 一、免费版到底给多少

免费版不是试用版，核心功能是长期免费的：

- 单词、短语、整句的查询；
- 多语言对与多候选译文；
- 真实语料例句；
- 发音、同义词、动词变位；
- 拍照翻译、语音搜索；
- 收藏夹、词汇表；
- 抽认卡、测验、游戏等学习功能。

代价是**界面里会有广告**。对绝大多数「查词 + 偶尔复习」的用法来说，免费版已经够用，不必急着付费。

## 二、高级版多出来的部分

高级版（官方叫 Premium）主要在下面几个方向做增强：

| 方向 | 具体差别 |
| --- | --- |
| 广告 | 去掉广告 |
| 查询次数 | 结果不限量 |
| 离线 | 最近 500 条搜索可在离线历史中查看 |
| 学习 | 更完整的个性化练习程序 |
| 跨产品 | 一套 Premium 覆盖 Reverso 系多个产品，含文档翻译额度 |

**另一处差别是单次可翻译文本的长度。** 在浏览器扩展这类入口上，免费层能翻译的文本有长度上限（第三方评测给出的口径是：未登录约 150 字符、登录后约 300 字符），高级版解除这个限制。手机端是否也是同样的数字，以应用内提示为准 —— 整段文章这类需求，本来就该走文档翻译那条线。

其中**离线历史条数**是免费版和高级版最直接的差别，经常在没网环境里翻旧查询的话，这一项值得重点关注，细节见 [离线词典与离线可用范围.md](离线词典与离线可用范围.md)。

## 三、文档翻译是另一条线

Reverso 还有「文档翻译」这条产品线：上传 Word、PDF、PPT、Excel 之类的文件，保持版式翻成目标语言。它和手机端的查词是两套东西，计费方式也不一样（按字数 / 文档额度）。

如果你只是日常查词，这部分可以先不管；有整份文件要翻的需求时，再单独去了解它的额度规则。**具体的套餐档位、字数额度和文件大小限制，以官方页面当时显示为准。**

## 四、在哪买、多少钱

- **购买入口**：应用内的订阅页，或官方网站的订阅 / 定价页。
- **价格**：随地区、平台（应用商店内购还是官网订阅）和活动变化，**不同入口可能不一样，以你实际看到的当页价格为准**。订阅前顺手比一下手机内购和官网两个入口。
- **订阅范围**：官方口径是高级版覆盖 Reverso 系多个产品，不是只对手机端一个应用生效。

## 五、怎么退订

订阅走的是哪个渠道，就在哪个渠道退：

| 订阅渠道 | 退订位置 |
| --- | --- |
| Google Play（安卓） | Play 商店 → 个人资料 → 付款和订阅 → 订阅，选中 Reverso 这一项取消 |
| App Store（iOS） | 系统设置 → 你的 Apple ID → 订阅，选中对应订阅取消 |
| 官网 / 网页订阅 | 登录 Reverso 账号，在订阅管理里取消 |

**两个必须知道的点：**

1. **卸载应用不等于退订。** 订阅挂在应用商店账号或官网账号上，卸载照旧会续费，必须去对应渠道取消。
2. **取消后不是立刻失效。** 一般可以用到当前订阅周期结束，之后不再续费；**在到期前可能无法再次订阅同一档**，具体以官方说明为准。

## 六、要不要买，按这三点判断

- 只是偶尔查词、能忍受广告：**免费版就够**；
- 经常断网还要翻历史、或明确不想看广告：高级版值得考虑；
- 有整份文档要翻译：先看文档翻译那条线的额度，再决定要不要上更完整的档位。

订阅和账号绑在一起，换设备时用同一个账号登录即可，不受影响。数据同步的机制见 [注册登录与多设备同步.md](注册登录与多设备同步.md)，订阅本身的购买与退订见本文第四节、第五节。
