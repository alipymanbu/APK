## 一、安装阶段

| 现象 | 常见原因 | 处理办法 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包下载不完整，或与系统版本不匹配 | 核对体积是否约 84.36 MB、重下一遍；再对一下商店页的系统要求 |
| 提示「应用未安装 / 安装失败」 | 手机上已有签名不同的同包名应用 | 先卸载旧版，再装这份 |
| 提示「已存在更高版本」 | 现装版本比这份新 | 直接继续用现成的，不必降级 |
| 安装按钮点不动 | 系统限制仅允许商店安装 | 关掉该限制，或改用商店版 |
| 文件管理器里打不开 apk | 后缀被改过 / 下成了别的文件 | 确认后缀是 `.apk`，重新下载 |

安装步骤的完整流程见 [下载与安装教程.md](下载与安装教程.md)。

## 二、打开与运行

| 现象 | 排查顺序 |
| --- | --- |
| 一打开就闪退 | 重启手机 → 确认系统版本满足要求 → 卸载重装 |
| 界面是英文 / 语言不对 | 在设置里改应用语言；这跟「查询用的语言对」是两回事 |
| 界面卡在加载 | 换网络（切到别的 Wi-Fi 或用流量）再试；被网络环境挡住的接口会一直转圈 |
| 耗电偏快 | 常驻通知、后台刷新这类开关按需关；只在用的时候开应用 |

## 三、查词与结果

- **译文明显不对**：先看两个语言选择器是不是源和目标弄反了；再把整句输入进去，用例句判断。
- **查不出某个词**：换一种词形（比如动词用原形）再查一次；短语和习语往往不在单词条目里，直接按整句查。
- **结果里的例句不合适**：例句来自真实语料，偶尔会带俚语或粗话，用结果旁的反馈入口标记即可。
- **复制不出来**：长按译文本身选中再复制，比点按钮更稳。
- **某个语言查不到，或功能比别的语言少**：先确认这组语言对在不在支持范围内；有的语言只能走释义词典旁路，扩展功能也会更少，见 [支持哪些语言和语言对.md](支持哪些语言和语言对.md)。

更多用法见 [单词和整句怎么翻译.md](单词和整句怎么翻译.md)。

## 四、语音与拍照

- **点了没反应**：先查麦克风 / 相机权限是不是被拒了或在系统里被收回，补上权限再试。
- **一直识别不出**：确认当前有网 —— 语音和拍照识别都需要联网，断网时用不了。
- **识别结果错得离谱**：语音尽量在安静环境说；拍照注意光线、距离和角度，别斜着拍、别离太远。
- **拍出来一堆无关文字**：只框住你要的那一块再拍。

## 五、离线相关

- **离线查不了词**：多半是这个语言对的离线词典没下载过，去设置里下好再试。
- **离线词典下不动**：需要联网下载，检查网络与存储空间是否够。
- **离线时听不到发音、看不到完整例句**：这两项依赖在线数据，离线会缩水，属正常范围。

判断「哪些能用、哪些必须有网」，见 [离线词典与离线可用范围.md](离线词典与离线可用范围.md)。

## 六、账号与同步

- **收藏 / 历史没同步过来**：先确认两端登录的是**同一个账号**；再稍等一会儿刷新。
- **验证邮件收不到**：查垃圾邮件夹，过几分钟重新发一次。
- **忘了密码**：在登录页走邮箱重置流程。
- **换机后离线词典没了**：离线词典按设备本地保存，不跟账号走，新设备要重新下载。

账号相关的完整说明见 [注册登录与多设备同步.md](注册登录与多设备同步.md)。

## 七、广告与订阅

- **广告太多想清掉**：高级版去掉广告并放开结果数量，差别与价格口径见 [免费版和高级版有什么区别.md](免费版和高级版有什么区别.md)。
- **卸载了还在扣费**：订阅挂在应用商店或官网账号上，卸载不影响续费，必须去对应渠道取消。
- **取消后想马上重新订阅**：官方口径是当期结束前可能无法再次订阅同一档，以官方说明为准。

## 八、需要重新装一次的时候

如果排查到最后只能重装：

1. 重装前确认之前**登录过账号**，收藏与历史才有云端备份；
2. 卸载旧版；
3. 用 [Reverso 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4499800555fe) 里的安装包重新装上，步骤见 [下载与安装教程.md](下载与安装教程.md)；
4. 装上后登录原账号，等数据同步回来。
