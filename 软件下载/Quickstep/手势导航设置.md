## 一、在哪里打开或关闭手势导航

原生系统的入口是：**设置 → 系统 → 手势 → 系统导航**，在里面二选一：

- **手势导航**：屏幕底部只剩一条横条，所有操作靠滑动；
- **三按钮导航**：底部是返回、主屏幕、最近任务三个键。

不同品牌的菜单层级有差异：有的放在 **设置 → 显示 → 导航栏**，有的叫「全面屏手势」或「系统导航方式」，找不到时直接在设置顶部搜索「导航」最快。两种模式随时可以互切，切换后立刻生效，不用重启。

想用命令行确认当前模式的开发者，可以连 ADB 后执行 `adb shell settings get secure navigation_mode`，返回 `2` 是手势，`0` 是三按钮。

## 二、手势对照表

| 手势 | 动作结果 |
| --- | --- |
| 从屏幕底部上滑 | 回到主屏幕 |
| 底部上滑后停住不松手 | 打开最近任务（多任务卡片） |
| 从左或右屏幕边缘向内滑 | 返回上一级 |
| 沿底部横条向左或右滑 | 在最近用过的两个应用之间快速切换 |
| 进入最近任务后，沿卡片横向滑动 | 逐个浏览后台应用；把卡片往上甩掉即关闭该应用 |

上滑幅度和停顿时长决定结果：一滑到底不犹豫是回桌面，上滑中途停一下才出多任务——很多「多任务打不开」的情况其实是停顿时间不够，松手太快就变成回桌面了。

## 三、底部提示条要不要隐藏

部分系统允许在导航设置里关掉底部那条手势提示横条。注意它只是视觉提示，**隐藏后手势依然有效**，不是关闭手势导航；但如果你的设备手势识别本来就不灵敏，留着横条有助于对准起手位置。

## 四、手势没反应时按这个顺序查

1. **确认模式**：进导航设置看当前选的是不是「手势导航」，三按钮模式下上滑当然没有反应；
2. **确认默认桌面**：如果你装了第三方桌面并设为默认，手势由哪一方接管在不同系统上表现不同，部分第三方桌面只支持三按钮模式；想全手势体验，把默认桌面切回系统桌面（方法见 [更换默认桌面方法.md](更换默认桌面方法.md)）；
3. **确认桌面没在崩溃**：手势是 Quickstep 接的，它一崩溃手势跟着失灵，先按 [已停止运行怎么办.md](已停止运行怎么办.md) 把崩溃处理掉；
4. **桌面整个没了**（手势和图标全无反应）：这是桌面组件丢了，直接按 [下载与安装教程.md](下载与安装教程.md) 的第四节补救安装。
