## 一、它在手机里是干什么的

Quickstep 是安卓的**系统桌面（启动器，launcher）**。你在手机上看到的这些界面，都由它负责：

- 主屏幕：壁纸、图标摆放、小组件、文件夹；
- 应用抽屉：从下往上滑调出的完整应用列表；
- 最近任务：上滑停住出现的多任务卡片；
- 手势导航：全面屏手势（上滑回桌面、边缘内滑返回）就是它接管的。

它从 Android 9 起随系统预装，包名为 `com.android.launcher3`，代码是 AOSP（安卓开源项目）Launcher3 的一部分。多数品牌机出厂时会在这个基础上做自己的定制，也有不少机型（原生系、摩托罗拉、诺基亚等入门与原生向机型）直接沿用这个名字。

## 二、为什么应用列表里能看到它

因为它是以系统应用的身份存在的。不同品牌的处理方式不一样：

| 情况 | 你看到的现象 |
| --- | --- |
| 原生系 / 部分入门机型 | 应用列表里直接叫 Quickstep，图标是一栋小房子 |
| Pixel | 与 Pixel Launcher 合为一体，通常不单独显示 |
| 三星、小米、OPPO 等定制系统 | 用自家桌面（One UI 主屏幕、MIUI 桌面等），Quickstep 一般不露出 |
| 部分定制机的底层 | 桌面换成自家皮肤，但手势与多任务部分仍可能由它承担 |

所以「列表里突然看到一个没装过的 Quickstep」不代表手机被装了陌生软件——它本来就在系统里，只是你之前没翻到那一页。

## 三、能不能卸载、能不能停用

- **普通方式卸载不了**：它是系统应用，应用详情页里没有「卸载」按钮。
- **不要主动停用它**：停用（或在 root 后删除）之后，主屏幕会失去承载者，典型后果是**重启后桌面空白、只能看到状态栏和通知栏**。到那时恢复起来反而麻烦，应急流程见 [桌面空白怎么应急恢复.md](桌面空白怎么应急恢复.md)。
- **不用删也不吃亏**：如果你是不喜欢它的外观才想删它，正确的做法是装一个第三方桌面并设为默认，原桌面留在原地当备胎即可，步骤见 [更换默认桌面方法.md](更换默认桌面方法.md)。

## 四、它安全吗，为什么出现在耗电排行里

它是系统自带组件，不是病毒，也不存在「偷偷监控」的性质——这类疑虑在刚发现系统里多出一个陌生名字时很常见，但它只负责界面与切换，行为范围就是主屏幕和最近任务。

至于耗电排行、存储占用里出现它的名字：桌面是常驻进程，你每次亮屏回到主屏幕都在用它，出现耗电记录属于正常现象，不需要也没有必要去「优化」它。

## 五、什么情况下才需要单独一份安装包

系统里自带的 Quickstep 平时不用你操心。真正需要独立安装包的是这几种场景：

1. 桌面被误删或停用后，重启一直停在空白桌面；
2. 系统桌面反复崩溃，想用一份完整的包替换回来；
3. 模拟器、自刷的系统里本来就没带桌面。

这份安装包为 v3.0.12（约 5 MB），获取入口见本页顶部的网盘链接，装好后怎么设为默认、装不上时怎么办，都在 [下载与安装教程.md](下载与安装教程.md) 里。
