## 一、先确认你是不是需要装它的那种人

Quickstep 正常情况下是随系统预装的，不需要你动手。需要单独装一份的典型场景：

| 场景 | 表现 |
| --- | --- |
| 桌面被误删 / 误停用 | 重启后桌面空白，只剩状态栏，应用打不开 |
| 系统桌面反复崩溃 | 「Quickstep 已停止运行」弹个不停，主屏幕闪退 |
| 模拟器 / 自刷系统缺桌面 | 开机进得了系统但没有主屏幕 |

本篇以网盘里那份 v3.0.12 安装包（约 5 MB，包名 `com.android.launcher3`）为准。

## 二、下载与安装前的准备

1. 通过 [Quickstep 安装文件资源（夸克网盘）](https://pan.quark.cn/s/056687f7cf01) 转存并下载安装包到手机存储；
2. 允许安装来源不明的应用：进入 **设置 → 应用 → 特殊应用权限 → 安装未知应用**，给你用来打开安装包的那个应用（文件管理器或浏览器）授予「允许安装」。

桌面还能正常显示时，下面第三节就够了；桌面已经空白的话，直接跳到第四节。

## 三、桌面正常时的安装步骤

1. 用文件管理器找到下载好的 APK，点它；
2. 弹出安装确认时点「安装」；
3. 装完按 Home 键（或做上滑回桌面的手势），系统会让你选择用哪个桌面，选 Quickstep 并勾选「始终」；
4. 如果没弹出选择框，去 **设置 → 应用 → 默认应用 → 主屏幕应用（Home 应用）** 手动指定。

## 四、桌面已经没了怎么装

没有桌面时，图标打不开、文件管理器也点不了，但系统本身还活着。两条路按顺序试（如果不确定桌面是被停用还是被删、或装完仍空白，完整的应急判断流程另见 [桌面空白怎么应急恢复.md](桌面空白怎么应急恢复.md)）：

**路线 A：从通知栏绕进去（能成最省事）**

1. 在空白桌面上下拉通知栏，点右上角的设置齿轮进入系统设置；
2. 在设置里搜索「文件」或「文件管理」，如果设备自带文件管理器还能进，就在里面找到下载好的 APK 安装；
3. 通知栏进不了设置的话，试试长按齿轮图标进入详细设置，或者用另一个手机把安装包通过蓝牙 / 近距离分享发过来，部分系统的分享完成页可以直接点「打开」。

**路线 B：用电脑 ADB 安装（最可靠）**

1. 手机进 **设置 → 关于手机**，连点「版本号」7 次打开开发者选项；再到 **开发者选项** 里打开「USB 调试」；
2. 电脑下载 Google 官方的 platform-tools（地址：[developer.android.com/tools/releases/platform-tools](https://developer.android.com/tools/releases/platform-tools)），解压备用；
3. 手机用数据线连电脑，首次连接在手机上确认授权；
4. 在解压目录打开命令行，依次执行：

```bash
adb devices
adb install -r Quickstep_v3.0.12.apk
```

`adb devices` 能列出设备说明连接正常；第二条执行完出现 `Success` 即安装成功，随后做一次上滑手势，桌面应该就回来了。

## 五、装不上的几种情况

| 提示 | 多半是什么问题 |
| --- | --- |
| 「解析软件包时出现问题」 | 下载不完整，或系统版本达不到这个包的要求；重新下载一次再装 |
| 安装按钮置灰 / 提示与设备冲突 | 设备上已经存在同包名（`com.android.launcher3`）的系统应用且签名不同，系统拒绝覆盖——品牌定制机常见；这种情况装第三方桌面更实际，见 [更换默认桌面方法.md](更换默认桌面方法.md) |
| 装完点开就闪退 | 系统与这版包不匹配，参考 [已停止运行怎么办.md](已停止运行怎么办.md) 的排查顺序处理后，考虑改走换桌面的路线 |

装好之后如果手势导航（上滑回桌面那条）没有反应，去 **设置 → 系统 → 手势 → 系统导航** 里确认当前模式，具体对照见 [手势导航设置.md](手势导航设置.md)。
