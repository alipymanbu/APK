# Quickstep 桌面空白怎么应急恢复

> 桌面图标全消失、只剩状态栏时的从零恢复流程：先用通知栏应急，再用电脑 ADB 把桌面找回来。

## 一、先分清：桌面是「没了」还是「崩了」

两种情况的开机表现接近，但处理路径不同：

| 现象 | 状态 | 去哪篇 |
| --- | --- | --- |
| 反复弹「Quickstep 已停止运行」，偶尔还能看到图标 | 桌面在，崩溃 | [已停止运行怎么办.md](已停止运行怎么办.md) |
| 开机直接黑屏桌面，图标一个都没有，只能拉通知栏 | 桌面没了 | 本篇 |

桌面「没了」通常是这几种原因：停用或 root 后误删了 Quickstep；用 ADB 精简系统应用时把桌面一起干掉了；刷机 / 恢复出厂后桌面组件没有装回。**手机数据本身没有丢**——应用、照片都在，只是没人把它们「摆出来」。

## 二、通知栏应急：先给自己弄一条能操作的入口

没有桌面时，通知栏是唯一还能用的界面，大多数机型支持这几招：

1. 从屏幕顶部下滑打开通知栏，很多系统把**设置齿轮**放在这里，点进设置；
2. 进了设置后搜索「USB 调试」，在开发者选项里打开它——如果搜不到「开发者选项」，先去「关于手机」连点「版本号」7 次解锁；
3. 顺便在设置里搜「文件」：自带文件管理器若还能进，直接在里面装 APK 是最快的路（装哪个包、怎么授权安装，见 [下载与安装教程.md](下载与安装教程.md) 第二、三节）。

通知栏里连设置入口都没有的机型，直接跳到下一节用电脑。

## 三、电脑 ADB 恢复：三条命令按序试

电脑装好 Google 官方 platform-tools（[developer.android.com/tools/releases/platform-tools](https://developer.android.com/tools/releases/platform-tools)），手机连数据线、开 USB 调试，在解压目录打开命令行。Windows 把下面命令里的 `grep` 换成 `findstr`。

**第 1 步：确认连接与桌面包还在不在**

```bash
adb devices
adb shell pm list packages | grep launcher
```

第二条输出里有 `com.android.launcher3` 说明桌面的程序本体还在系统里（多半只是被停用），走第 2 步；什么都没有说明桌面组件已被移除，直接走第 4 步。

**第 2 步：被停用的，重新启用**

```bash
adb shell pm enable com.android.launcher3
```

执行完桌面会自己重新拉起，不用重启。这条路对应「之前用 ADB 或某些优化工具停用过桌面」的情况，只改启用状态，不动任何数据。

**第 3 步：被「按用户卸载」的，装回现有组件**

```bash
adb shell cmd package install-existing com.android.launcher3
```

ADB 精简系统应用时用的 `pm uninstall -k` 这类命令只是把应用对当前用户隐藏，程序包还留在系统分区里——这条命令把它重新挂回来，恢复后跟没删过一样。

**第 4 步：组件真没了，装一份完整包**

```bash
adb install -r Quickstep_v3.0.12.apk
```

安装包从 [Quickstep 安装文件资源（夸克网盘）](https://pan.quark.cn/s/056687f7cf01) 转存下载，放到命令行所在的目录再执行；出现 `Success` 后按一次 Home 或做上滑手势，桌面应该就回来了。

## 四、没有电脑时的两条绕路

- **借另一台手机中转**：用能正常用的手机访问本页顶部的网盘链接，把安装包通过蓝牙或就近分享传过来；部分系统的分享完成通知里能直接点「打开」，若弹出安装界面就能就地装上；
- **电脑网页端远程装第三方桌面**：手机连着 Wi-Fi 且登录过 Google 账号的话，在电脑浏览器打开 Play 商店网页版（`play.google.com`），远程把任一第三方桌面推装到手机上——装好后桌面入口就有了，之后再决定要不要补装 Quickstep（默认桌面的设置方法见 [更换默认桌面方法.md](更换默认桌面方法.md)）。国内无 Google 服务的设备用不了这条，跳过。

## 五、都不行时的兜底

上面全部走完桌面还没回来，剩下的路只有恢复出厂（关机后用「电源键 + 音量键」的组合进 Recovery 模式，具体按键因机型而异，多数机型是电源键 + 音量上；选清除数据）。它会抹掉手机里的应用和数据，**动手前尽量把照片、通讯录备份出来**——哪怕只能进通知栏，部分机型的备份入口也能从设置里够到。恢复出厂后系统桌面会随固件自动装回，一般不再需要本篇顶部的独立安装包。
