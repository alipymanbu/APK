## 一、网页版打不开、排版错乱

官方帮助中心明确说过：**网页版（[welearn.sflep.com](https://welearn.sflep.com)）要用电脑浏览器访问，不要用手机浏览器**。手机浏览器打开时页面错位、连线题做不了、功能缺失都是这个原因，不是你设备坏了。

| 问题 | 处理 |
| --- | --- |
| 手机浏览器打开排版乱 | 换到电脑上，用 Chrome、Edge 或 Firefox 打开 |
| 在手机浏览器上学习，时长与进度没记上 | 手机浏览器上学习时间、进度等记录保存不正常，官方提醒为保障学习数据务必用电脑访问；已丢的记录补不回来 |
| 电脑浏览器打开也异常 | 换 Chrome / Edge / Firefox 之一再试；仍异常清缓存或换设备 |

## 二、录音失败（口语题、跟读题录不上）

App 端与网页端的原因和排查方法不同，完整的分端排查（麦克风权限、换网络、重启设备、浏览器授权）单独成篇，见 [录音失败排查.md](录音失败排查.md)。最快的两个自查：App 端先看麦克风权限是否为「允许」，网页端先用电脑本地「录音机」确认麦克风硬件没坏。

## 三、登录提示要注册、课程不见了

典型原因是登录到了另一个账号上。排查顺序：

1. 想想有没有注册过多个账号（手机号注册的、学校发的学号账号），逐个登录确认课程在哪个里。
2. 误点「注册」会生成一个空账号——退出，回登录页用原手机号登录。
3. 忘记密码走登录页的「忘记密码」重置，**不要重新注册**。
4. 都不行就用 App 或网页版的「联系客服」反馈，提供注册手机号。

详细步骤见 [注册登录与账号问题.md](注册登录与账号问题.md)。

## 四、激活码无效或提示已被使用

| 报错 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示激活码无效 | 输错字符（0/O、1/I 易混）；码不完整 | 对照教材重新输入一遍 |
| 提示已被使用 | 自己重复输入过；教材是二手、码被用过 | 联系客服，提供教材 ISBN、激活码照片、购书凭证 |
| 课程加上了但内容对不上 | 教材版次与课程不匹配 | 确认课程名与册数，必要时让老师指认课程 |

二手教材的激活码大概率已被使用，购买前先问清楚。激活与加班级的完整步骤见 [激活课程与加入班级步骤.md](激活课程与加入班级步骤.md)。

## 五、加入班级后看不到任务

1. 确认加的是**这门课**下的班级（不同册数班级码不同，加错册数的班什么都看不到）。
2. 让老师在班级管理面板里核对你是否在名单里。
3. 老师还没发布内容的话，班级页自然是空的，等老师发。

## 六、成绩与进度相关

- **成绩怎么算**：学习时长、进度、客观题正确率、班级任务等多项指标乘权重，老师可调权重，具体标准问任课老师，构成说明见 [课程学习与成绩说明.md](课程学习与成绩说明.md)。
- **进度不更新**：先确认网络通畅；换设备后登录同一账号刷新；仍不更新联系客服。
- **想重做作业**：「发现 → 课堂活动 → 历史记录」里找。

## 七、都解决不了时找谁

| 问题类型 | 找谁 |
| --- | --- |
| 账号找回、课程核对、激活码异常 | App / 网页版的「联系客服」 |
| 班级码、班级名单、作业与成绩规则 | 任课老师 |
| 安装、闪退、系统兼容 | 先看 [下载与安装教程.md](下载与安装教程.md) 的排查表，解决不了再联系客服 |
