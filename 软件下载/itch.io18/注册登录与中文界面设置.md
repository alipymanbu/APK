## 一、先想清楚要不要注册

注册不是必须的：不登录也能浏览 itch.io、下载免费游戏、离线玩网页游戏。以下场景才需要账号：

| 场景 | 是否需要登录 |
| --- | --- |
| 下载免费游戏、离线玩网页游戏 | 不需要 |
| 购买付费游戏、下载已购内容 | 需要 |
| 关注开发者、收新作通知 | 需要 |
| 把游戏加进收藏（Collection） | 需要 |

itch.io 账号是全平台通用的：同一个账号在网站、桌面客户端、Mitch 里登录，购买记录和收藏都是同步的。

## 二、注册步骤

注册在 Mitch 内置的网页里完成，流程和电脑上一样：

1. 在 Mitch 里打开 itch.io，点页面上的 **Register**（注册）。
2. 填三样东西：**用户名**（全网唯一）、**密码**、**邮箱**（用于验证邮件，务必真实可收信）。
3. 选择你的主要用途：**玩游戏 / 下载内容** 或 **发布内容**——只是玩的话选前者，这个偏好以后能改。
4. 勾选同意服务条款，点 **Create account** 创建账号。
5. 打开注册邮箱，点验证邮件里的链接激活账号。没收到就翻翻垃圾邮件箱；邮箱填错了，换一个邮箱重新注册一个账号即可。

注册界面默认是英文，按上面五步对应着填就行；登录之后可以按下一节把界面切成中文。

## 三、把界面切成中文

itch.io 网站自带简体中文界面，设置一次全局生效：

1. 登录后点右上角你的头像/用户名，进 **Settings**（设置）。
2. 在左侧找到 **Language**（语言）。
3. 把 **Preferred Language** 切换成 **Chinese (Simplified)**（简体中文）。
4. 点页面底部的保存按钮，刷新后整个网站界面变成中文。

两个「语言」别混淆：Mitch 应用本身的界面语言跟随手机系统语言（它自带包括简体中文在内的多语言包）；上面改的是 itch.io 网站内容的语言——你在应用内浏览器里看到的页面、按钮文字用的是后者。

## 四、账号安全的两个建议

- **开两步验证**：在账号设置的安全相关选项里可以绑定验证器应用（TOTP），之后登录除了密码还要输一次动态码，账号被盗风险大幅降低。
- **邮箱要保得住**：买过游戏后，收据和永久下载链接都发到注册邮箱，换邮箱前先把账号邮箱改掉（见[买游戏与付款方式.md](买游戏与付款方式.md)第三节），否则换机重装时已购内容找不回来。

注册登录都弄好后，回到[怎么下载游戏.md](怎么下载游戏.md)接着装第一个游戏；安装环节还没走通的，从[下载与安装教程.md](下载与安装教程.md)开始。
