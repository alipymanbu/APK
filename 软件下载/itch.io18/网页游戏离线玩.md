## 一、离线玩网页游戏是怎么回事

itch.io 上有大量只提供 HTML5 版的游戏，正常情况下你得开着浏览器在线玩。Mitch 从 2.0.0 起支持把这类游戏整包下载下来，断网也能从应用里直接打开玩——这是它相对「用浏览器开 itch.io」最实际的差异，也是坐地铁、飞机这类没网场景里最用得上的功能。

能不能离线，取决于游戏本身：

| 游戏形态 | 离线结果 |
| --- | --- |
| 纯本地运行的 HTML5 游戏（单机、无服务器验证） | 整包下载后可完整离线玩 |
| 需要连服务器的游戏（在线排行、联机、账号验证） | 文件能下载，但断网后玩不了核心内容 |
| 仅提供 APK 的安卓原生游戏 | 与网页离线无关，走 APK 安装流程 |

## 二、怎么把网页游戏装成离线版

1. 在 Mitch 里打开游戏页（找的时候认准页面上有「Run game」按钮、平台标注含 HTML5 的作品）。
2. 进入游戏页的下载区域，选择 HTML5 对应的下载项，Mitch 会把游戏文件整体抓下来。
3. 下载完成后，游戏出现在库（Library）里；之后在库中点开即玩，不需要网络。
4. 想从桌面直接进，见下一节的快捷方式。

部分游戏页同时挂着 APK 和 HTML5 两种文件，选错了装出来的不是网页版；区分方法见[怎么下载游戏.md](怎么下载游戏.md)开头的对照表。

## 三、把网页游戏固定到桌面（快捷方式）

2.2.0 起，Mitch 支持把已安装的网页游戏做成安卓启动器快捷方式——在支持的启动器上，游戏会像普通应用一样出现在桌面图标列表里，点图标直接进游戏，不用先开 Mitch 再翻库。

操作入口在库（Library）里：长按游戏卡片调出菜单（长按菜单本身是 2.2.2 加入的），里面可以做与该游戏相关的管理操作。生成的快捷方式在不同启动器上支持程度不同，个别桌面可能不显示，这种情况下从 Mitch 库里启动即可。

## 四、存档与数据放在哪

网页游戏的存档保存在 Mitch 应用内的浏览器数据里，跟着应用走，不生成独立的存档文件。这意味着：

- **卸载 Mitch = 丢掉所有网页游戏存档**，换机、重装前没有官方导出入口——这一点有用户在社区里提过，目前没有导出方案，重装前想清楚。
- APK 安装的原生游戏不受此影响，它们的存档由各自的游戏自己管理。

所以如果你的网页游戏进度很值钱，别轻易卸载应用；平时也不用做任何操作，存档就在原地。

## 五、离线玩不动的常见原因

- 游戏本身要连服务器（联机、在线验证），断网自然玩不了，这不算故障。
- 只下载了一部分（下载中途断网），重新进库点开该游戏补一次下载即可。
- 下载按钮点了没反应之类的通用问题，转[下载失败与安装报错排查.md](下载失败与安装报错排查.md)处理。
