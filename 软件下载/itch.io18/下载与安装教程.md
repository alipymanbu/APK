## 一、Mitch 是什么

Mitch 是 itch.io 的第三方安卓客户端，由开发者 gardenapple 维护，用 GPL-3.0 许可开源。itch.io 是一个独立游戏分发平台，上面大量作品提供安卓 APK 或者 HTML5 网页版本，但官方只有网站和桌面客户端，没有出过安卓应用——Mitch 补的就是这个位置：把 itch.io 的移动网页包进应用内浏览器，同时接管安卓游戏的下载、安装与更新。

几个你装之前最好先知道的点：

| 项目 | 说明 |
| --- | --- |
| 应用名 | Mitch |
| 定位 | itch.io 的非官方安卓客户端 |
| 本文对应版本 | 2.3.3（官方 2024-11-24 发布） |
| 包名 | `ua.gardenapple.itchupdater` |
| 安装包体积 | 约 9.52 MB |
| MD5 | `0A0AC1327029D10EFFA211B6C5143B12` |
| 系统要求 | Android 5.0（Lollipop）及以上，以官方页面说明为准 |
| 许可 | GPL-3.0，源码托管在 SourceHut |
| 界面语言 | 支持简体中文在内的十余种语言 |

注意它不是官方应用，也不上架 Google Play——开发者在新版更新说明里提过，新版申请的 `QUERY_ALL_PACKAGES` 权限属于 Google Play 会拒绝的类型，所以常规获取渠道是 F-Droid 应用商店和开发者在 itch.io 上的发布页，第三方渠道拿到的包请自行核对包名与完整性。

### 和直接用手机浏览器开 itch.io 比

不装任何应用、直接用手机浏览器开 itch.io 网站当然也可以，两条路的差别在下载之后：

| 场景 | 手机浏览器 | Mitch |
| --- | --- | --- |
| 装安卓游戏（APK） | 下载 APK 后自己找文件、手动安装，以后更新靠重新下载 | 自动接手下载与安装，已装游戏集中管理、有新版会提示更新 |
| 玩网页游戏 | 每次都要在线开 | 能整包下载成离线版，断网也能玩 |
| 下载入口 | 游戏页下载链接各自为政 | 下载、安装、更新收在一个库里 |

所以判断很简单：只偶尔下一个免费游戏，浏览器就够用；打算持续在手机上玩 itch.io 的游戏，装 Mitch 省掉的是每次找文件、手动装、查更新的重复劳动。安装步骤见下面第四节。

## 二、从哪获取安装包

两条路，选一条即可：

**路线 A：网盘资源（适合直接装）**。从上面的入口转存 [Mitch 安装文件资源（夸克网盘）](https://pan.quark.cn/s/11b45d15ed6d)后下载 APK，对应的就是本文写的 2.3.3 版。下载完建议顺手核对一下 MD5（见下一节），再进行安装。

**路线 B：F-Droid（适合长期自动更新）**。装一个 F-Droid 商店，在里面搜 Mitch 直接安装，之后版本更新会由商店推送。缺点是国内访问 F-Droid 的源速度不稳定，首次下载可能较慢。

两条路线各有适合的场景：只想先把某个游戏装上玩，走 A 最快；打算长期把 Mitch 当 itch.io 的手机入口用，走 B 省心。如果之后想从一条路线换到另一条，先看[下载失败与安装报错排查.md](下载失败与安装报错排查.md)里「覆盖安装失败」一节，避免签名不一致导致装不上。

## 三、核对安装包（可选但建议）

拿到 APK 后可以核对 MD5，确认文件没有在传输中损坏：

```text
MD5：0A0AC1327029D10EFFA211B6C5143B12
```

安卓上可以用带校验功能的文件管理器，或者在电脑上用 `certutil`（Windows）核对：

```powershell
certutil -hashfile "下载的文件名.apk" MD5
```

算出的值与上面一致再装；不一致就重新下载一遍。

## 四、安装步骤（侧载流程）

Mitch 不走应用商店时属于「侧载安装」，安卓系统会拦一道，流程如下：

1. **找到 APK 文件**：在文件管理器里打开刚下载的 `.apk`（通常在 `Download` 目录）。
2. **允许安装来源**：第一次点安装时，系统会提示「出于安全考虑，手机不允许安装未知来源应用」，并给一个「设置」入口；进去把「允许来自此来源」打开（允许的是你用来打开 APK 的那个文件管理器或浏览器，不是允许整个系统）。
3. **回到安装页点安装**：等待安装完成即可，安装包只有 9.52 MB 左右，几秒钟的事。
4. **打开应用**：首屏会加载 itch.io 的移动版网页，能正常刷出游戏列表就说明装好了。

不同品牌手机对侧载授权的入口名称与层级不一样，多数藏在「设置 → 应用」或「安全」分类下的「安装未知应用」里，找不到入口时可以参考[下载失败与安装报错排查.md](下载失败与安装报错排查.md)的第一节。

## 五、首次启动做点什么

装完第一次打开，建议按这个顺序过一遍：

1. **浏览游戏**：应用内浏览器直接打开的就是 itch.io 移动站，你可以当普通网站刷，也可以切到浏览标签按类型、标签筛选。
2. **登录账号（可选）**：不登录也能下载免费游戏；登录后才能买付费游戏、访问已购内容和收藏。
3. **装第一个游戏**：找一个标了「Android」或「HTML5」的免费游戏，点页面上的下载按钮，Mitch 会接手下载并弹出安装确认。具体操作见[怎么下载游戏.md](怎么下载游戏.md)。
4. **看看设置里的开关**：Mitch 自带屏蔽跟踪与分析的选项，也在意隐私的话可以确认一下是否开启；界面语言在系统语言为中文时会直接显示中文。

之后日常用的就是「浏览 → 下载 → 库」这条线，遇到下载不动、安装被拦的情况，直接查[下载失败与安装报错排查.md](下载失败与安装报错排查.md)。
