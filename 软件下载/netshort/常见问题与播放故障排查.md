## 一、通用排查顺序

任何故障都先走这三步，能解决一大半：

1. **切网络**：Wi-Fi 和移动数据互换一次，很多「服务器连不上」其实是当前网络的 DNS 或运营商线路问题。
2. **彻底重启应用**：从最近任务里划掉再开，而不是只退回桌面。
3. **查版本**：太旧的版本与服务器协议不匹配会出现各种奇怪现象，确认自己用的版本后，按需参照 [下载与安装教程.md](下载与安装教程.md) 的说明处理。

## 二、按症状排查

### 打开应用一直转圈 / 提示网络错误

1. 换网络重试（见通用排查第一步）。
2. 检查手机时间：系统时间不准会导致与服务器的安全连接校验失败，把「自动设置时间」打开。
3. 用了代理或 VPN 的先关掉试，NetShort 是海外服务，但代理节点本身不通时会连不上。
4. 都不行就等半小时再试，短剧应用在高峰期偶发服务器繁忙，这类问题等一等比反复刷新管用。

### 视频卡顿、画质糊

1. 播放页里把清晰度调低一档，先保流畅。
2. 关掉后台大流量应用（下载、在线会议之类）。
3. 老旧机型在长时间刷剧后会因发热降频变卡，锁屏让它凉几分钟。

### 黑屏有声音 / 画面不动

1. 退出该集重新进入。
2. 清一下应用缓存：系统设置 → 应用 → NetShort → 存储 → 清除缓存（注意是「缓存」不是「数据」，清数据会丢本机进度）。
3. 只有个别剧黑屏就是那部剧的资源问题，换个剧验证，然后放弃这部剧或等它修复。

### 离线下载失败

1. 确认这部剧本身支持下载（只有部分内容支持，见 [播放与离线观看.md](播放与离线观看.md)）。
2. 检查剩余存储空间，缓存视频很占地方。
3. 换 Wi-Fi 环境再下，移动数据下大文件容易中途断。
4. VIP 的离线下载权益只覆盖可下载内容，不是所有会员剧都能缓存。

### 金币没到账 / 解锁失败

1. 解锁失败先确认网络正常，再点一次。
2. 金币没到账去任务页看任务完成条件是否真的达成（比如「观看完整视频」差几秒不算）。
3. 看完推广视频金币没入账是有用户反馈过的情况：先退出应用重进再查任务页，多数是记账延迟；反复发生就别再耗时间刷这类渠道，攒金币的路子见 [免费看剧与攒金币方法.md](免费看剧与攒金币方法.md)。
4. 充值类问题对订单与扣款记录，走商店侧申请，见 [金币与VIP订阅.md](金币与VIP订阅.md) 的充值与退款一节；订阅扣费异常（找不到订阅、取消后仍在扣）单独成篇，见 [取消订阅与继续扣费处理.md](取消订阅与继续扣费处理.md)。

### 通知 / 更新提醒太频繁

在系统设置 → 通知里单独关掉 NetShort 的通知权限即可，应用内的提醒开关只管一部分，系统权限是总闸。

## 三、什么情况该放弃排查

- 卸载重装后问题依旧，且换了网络也一样——大概率是服务端问题或该地区不可用，等官方修复。
- 想确认是不是普遍问题，可以去官方 Facebook 或 YouTube 主页看有没有其他用户反馈同样情况（官方账号入口见 `https://www.facebook.com/profile.php?id=61564956644828` 与 `https://www.youtube.com/@NetShort-app`，以实际页面为准）。
- 账号本身的异常（被封、被盗）走官方协议页面的联系方式申诉，不要反复注册新号。
