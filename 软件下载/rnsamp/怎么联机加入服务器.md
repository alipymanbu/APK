## 一、联机前的两个前提

1. **数据包已下载完成**。没装数据包的直接点服务器，游戏起不来 —— 先按 [下载与安装教程.md](下载与安装教程.md) 第四节走完。
2. **权限已允许**。存储权限被拒时，你选了服进去仍会停在单机模式，看着像「联机没生效」，实为权限问题，见 [闪退与进不去排查.md](闪退与进不去排查.md)。

## 二、选服与进图步骤

1. 在主界面点**服务器**入口，打开服务器列表；
2. 从在线服务器里挑一个（官方站点的说法是服主可把服务器提交到在线列表，玩家不用手输 IP；列表一般会显示延迟与人数，优先挑延迟低的）；
3. 选定后**填写游戏昵称**，点开始游戏；
4. 等加载完成即进入服务器。

也有教程提到可以自行填服务器 IP 直连 —— 手上有具体服的地址时，在服务器界面找「直接连接 / 手动输入」类入口填入即可，界面文案以你装的版本实际显示为准。

## 三、注册与登录：`/r` 命令

多数服务器进图后要先注册账号才能游玩，用聊天框命令完成：

```text
/r 昵称      注册（首次注册后昵称即绑定账号）
/r 密码      登录
```

三条注意事项，多个来源口径一致：

- `/r` 与后面的内容之间**必须有一个英文空格**；
- **没改密码前，默认密码就是你注册时填的昵称**；
- 注册过一次即可，之后每次进服用 `/r 密码` 登录。

另有用户反馈提到部分工具的账号体系用 QQ 邮箱注册（填邮箱前缀 + QQ 号 + `QQ密码@qq.com`）—— 这与游戏内的 `/r` 命令是两套东西，只有界面上明确要求你注册时才照它的提示填，别把两者混着用。

## 四、服务器类型都是些什么

选服时会看到不同标签，含义大致如下（具体玩法由各服自己定）：

| 类型 | 大致玩法 |
| --- | --- |
| DM | 死亡竞技，见面就打 |
| TDM | 团队死亡竞技，分阵营对抗 |
| RP / RPG | 角色扮演，按人设生活、打工、做任务 |
| 赛车 | 竞速图与车辆对局 |
| 娱乐 | 玩法杂糅，各服差异大 |

第一次玩建议从 RP 类的中文服入手：规则写在服务器简介里，进服先看公告再行动。

## 五、进不去服的常见原因

- **提示版本过旧 / 弹窗登录进不去**：服务器已启用新版登录机制，老客户端被限制进入 —— 升级 RnSAMP 到新版本再试（各版本情况见 [版本更新日志与下载渠道.md](版本更新日志与下载渠道.md)）。
- **频繁掉线、连不上**：先切网络（Wi-Fi 与流量互换）排除网络问题，再按 [闪退与进不去排查.md](闪退与进不去排查.md) 查客户端侧。
- **被服务器拒绝**：部分海外服务器的管理方对手机版客户端持保留态度，有服务器管理员公开表示手机版不稳定、不支持手机版玩家进服，因手机版出的问题他们不负责 —— 换个对手机版友好的服是更省事的做法（该说法来自服务器方表态，不代表所有服务器的规则）。

另外注意：单机/联机的模式开关、昵称与画质等选项的位置，见 [单机与联机模式切换与设置.md](单机与联机模式切换与设置.md)。
