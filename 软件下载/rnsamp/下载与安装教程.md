## 一、RnSAMP 是什么

RnSAMP 是一款安卓端的《侠盗猎车手：圣安地列斯》多人联机启动器（SA-MP 移动端），由 IGTASAMP 开发，早期叫「SAMP工具箱」，后来更名为 Rn-SAMP。你用它在手机上把单机版圣安地列斯切换成联机模式、选服务器、改昵称，再启动进服。它不需要 root 权限，安装后直接用。

官方发布页在 [samp.fun](http://samp.fun)，官方下载走蓝奏云渠道，另有官方腾讯频道供交流（入口见 [版本更新日志与下载渠道.md](版本更新日志与下载渠道.md)）。

## 二、先核对包信息

网盘里这一份的包信息如下，装之前先比对，避免拿到的是别的包：

| 项 | 值 |
| --- | --- |
| 版本 | v9.1 |
| 包名 | `com.samp.game` |
| 大小 | 78.79M |
| MD5 | `A3D9A565CF656426F604C0EA13C0C834` |
| 系统要求 | 安卓 5.2 以上 |

两点说明：

- **版本以本地这份为准**。官方页面上挂的永远是最新版，可能比 v9.1 新，也可能不是同一个构建；装哪个版本不影响下面的步骤，但服务器侧的最低版本要求以 [版本更新日志与下载渠道.md](版本更新日志与下载渠道.md) 记的规则为准。
- 校验 MD5 用任意文件校验工具算一遍即可，32 位十六进制与上表逐字对上才算拿到完整包。下载中断是最常见的安装失败原因，文件大小不对直接重下。

## 三、获取安装文件

安装文件（APK）从 RnSAMP 安装文件资源（夸克网盘）获取：[https://pan.quark.cn/s/b76a6a92db2d](https://pan.quark.cn/s/b76a6a92db2d)

转存到你自己的网盘后再在手机上下载，或先下到电脑再传手机 —— 两种都行，重点是下完核对第二节的 MD5。网盘里的文件夹名带「先保存再下载」字样，意思是先转存再下载，避免分享被撤后失效。

## 四、安装步骤

1. **装 APK**：把 APK 传到手机，点开安装。若系统提示「禁止安装未知来源应用」，在弹出的设置里允许本次安装即可（各品牌路径略有差异，一般在设置 → 安全 → 安装未知应用）。
2. **首次启动授权**：第一次打开会请求存储等权限，**点允许**。这一步很关键 —— 拒绝授权会导致游戏数据包写不进去、或进游戏后仍停留在单机模式，详见 [闪退与进不去排查.md](闪退与进不去排查.md)。
3. **下载游戏数据包**：进入主界面后按提示下载游戏数据包（首次安装必做，APK 本身不带游戏本体数据）。这一步要联网下载较长时间，建议在 Wi-Fi 下进行，中途别锁屏。
4. **进主界面**：数据包完成后回到主页，你会看到服务器列表、设置等入口 —— 到这里安装就算完成了。

## 五、装完没进去的三种常见情况

- **装完打开就闪退**：先按 [闪退与进不去排查.md](闪退与进不去排查.md) 的通用三步（清缓存、重启、查存储空间）走一遍，多数是数据包没下完整。
- **进游戏还是单机模式**：多半是第 2 步的权限被拒了，回到系统设置里把权限重新打开。
- **进服时提示版本过旧**：服务器侧已启用新版弹窗登录，老版本客户端会被拒之门外，需要升级到较新的版本再试。

装好之后怎么选服、注册账号，见 [怎么联机加入服务器.md](怎么联机加入服务器.md)。
