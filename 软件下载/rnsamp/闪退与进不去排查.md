## 一、先走通用三步

闪退类问题九成落在下面三件事里，按顺序做，做完再看具体症状：

1. **清缓存**：设置 → 应用 → RnSAMP → 存储 → 清理缓存（清缓存不删数据，放心点）；
2. **重启手机**：把卡住的后台进程与临时文件清掉；
3. **查存储空间**：可用空间低于一成时安卓应用极易闪退，先腾出几个 GB 再试。

三步都无效，再往下对照具体症状。

## 二、症状对照表

| 症状 | 多半是这个原因 | 你该做的 |
| --- | --- | --- |
| 进游戏后仍是单机模式 | 启动时拒绝了 RnSAMP 的权限 | 系统设置 → 应用 → RnSAMP → 权限，重新允许存储；有防护软件的话先放行它 |
| 进改车店就闪退 | 该车辆不支持改装，或你装了 MOD 引发冲突 | 先不碰这家店的改装；装过 MOD 的临时禁用再试 |
| 装了 MOD 后联机异常 | MOD 只在本地生效，兼容性没保证 | 可以继续联机，但其他玩家看不到你的 MOD；报错就撤掉 MOD |
| 跳机/高空落地必崩 | 跳跃高度设置过高 | 把高度调回限定范围 —— 多个来源一致表示调到过高会 100% 崩溃 |
| 爬墙时直接掉下来 | 攀爬状态下一直推摇杆前进 | 爬墙时松开前进方向，让角色自己爬 |
| 加载卡死 / 黑屏 / 反复闪退 | 数据包没下完整或损坏 | 回到 [下载与安装教程.md](下载与安装教程.md) 重下数据包，先删掉旧数据包目录再下 |
| 进服频繁掉线 | 网络不稳，或该服对手机版不友好 | 切换 Wi-Fi/流量；换服试（见 [怎么联机加入服务器.md](怎么联机加入服务器.md) 第五节） |
| 进服瞬间被弹回 | 昵称没过服务器校验 | 按 [进服报错与昵称规则.md](进服报错与昵称规则.md) 第一节改昵称 |
| 安装时提示设备不支持 | 系统版本或 CPU 架构不匹配 | 见 [进服报错与昵称规则.md](进服报错与昵称规则.md) 第三节 |

## 三、降低闪退概率的两个设置

- **关掉阴影与车辆反光**：多份教程都给了这条，尤其低端机型，把这两项关掉能明显减少对局中闪退。设置项位置见 [单机与联机模式切换与设置.md](单机与联机模式切换与设置.md)。
- **别开一堆后台**：联机时后台挂着大型应用会抢内存，进服前清一下后台。

## 四、数据包损坏怎么确认

数据包出问题的典型表现是：启动后卡在加载画面、黑屏、或每次都在同一位置闪退。核对方式：

1. 看下载是否完整 —— 文件大小与提示的对不上就是没下完；
2. 版本是否匹配 —— 数据包与客户端版本不一致时会读不出来，重下当前版本对应的数据包；
3. 重下前**删掉旧的数据包目录**，避免残留文件干扰，下完重启手机再进。

## 五、被服务器封了怎么办

进服后被踢、进不去同一台服务器，先分清是客户端问题还是服务器处罚：

- 换别的服能进、只有这一台进不去 → 大概率是该服的处罚或对手机版的限制，按服务器自己的申诉渠道处理；
- 所有服都进不去 → 回到第一节的通用三步，那是客户端侧的问题。

需要提醒的是：有海外服务器管理员公开表态称手机版客户端不稳定、可能引发误封，其服务器对手机版玩家的问题概不负责 —— 这类服务器上用手机版，风险由自己承担（此为个别服务器方立场，各服规则以其公告为准）。
