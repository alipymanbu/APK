## 一、昵称报错：Unacceptable NickName

进服瞬间被弹回、提示昵称不可接受，是 SA-MP 系服务器最常见的入服校验。通用规则如下（各服可在此基础上收紧，以屏幕上给的提示为准）：

- 长度 **3~20 个字符**；
- 只允许 `a-z`、`A-Z`、`0-9`，外加**一个**下划线 `_`；
- **不能有空格** —— 尤其是从别处复制昵称时，开头或结尾常带着一个看不见的空格，肉眼查不出来，重新手打一遍最稳；
- 中文昵称多数服务器不收，进不去就先换纯英文试。

改完昵称重新进即可；想中途退出在聊天框输入 `/quit`，或按 ESC 选 Quit Game。另外注意：昵称与账号的绑定关系见 [怎么联机加入服务器.md](怎么联机加入服务器.md) 第三节 —— 换昵称可能等于换账号。

## 二、黑屏进不去

黑屏的表现是选完服停在一片黑、不加载也不退出，按可能性从高到低：

1. **文件权限没给** —— 回系统设置确认 RnSAMP 的存储权限是允许状态，这是黑屏最常见的原因；
2. **机型老旧、性能不够** —— 老旧机型上黑屏与闪退都高发，先清后台、重启手机再试；
3. **客户端文件不完整** —— 按 [下载与安装教程.md](下载与安装教程.md) 第二节核对 MD5，包不对就重装。

## 三、提示与设备不兼容

安装或启动时被系统/客户端告知设备不支持，分两种情况：

- **系统版本过低**：RnSAMP 要求安卓 5.2 以上，低于此先升级系统（或换机）；
- **CPU 架构不兼容**：移动端 SA-MP 生态有「部分启动器不支持 arm64 新机型 / 需要 32 位支持」的公开报道（如 Pixel 7 系列被点名无法运行某些启动器），**但 RnSAMP 是否受同类限制没有查到公开资料** —— 你手上这台如果装得上、打得开，就不用管这类说法；真装不上，以安装时给出的具体报错为准再排查。

## 四、卡在文件校验 / 加载很慢

进服前的文件校验等很久，先确认两件事：

- **手机别在低性能状态**：校验吃 CPU，清后台、别边充电边玩高温机；
- **客户端是否被动过**：改动过的客户端在校验环节容易过不去甚至被服务器拒 —— 装完用 MD5 核对一遍，装的是 [下载与安装教程.md](下载与安装教程.md) 里那份就不用担心这个。

## 五、报错对照速查

| 你看到的 | 先做 |
| --- | --- |
| Unacceptable NickName | 按第一节改昵称（查空格、查长度、查字符） |
| 黑屏 | 给文件权限 → 清后台重启 → 核对 MD5 |
| 提示设备不支持 | 看系统版本是否 ≥ 5.2，其余按第三节 |
| 校验/加载极慢 | 清后台，确认包是原版未改动 |
| 进去后被立刻踢出 | 不是昵称就是服务器侧限制，见 [闪退与进不去排查.md](闪退与进不去排查.md) 第五节 |

按表做完还进不去，把屏幕上的报错原文带到 [怎么联机加入服务器.md](怎么联机加入服务器.md) 第五节逐条对照。
