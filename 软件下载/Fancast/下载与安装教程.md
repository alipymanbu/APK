Fancast 是韩国 QUICKWINSTUDIO 做的全球 K-POP 粉丝平台，KBS 音乐银行的事前投票、KGMA 等颁奖礼的官方投票都在这个应用里进行。本篇只解决一件事：把网盘里这份安装包装进安卓手机，并把第一次打开要处理的提示过一遍。想装 iOS 版的话，本文的 APK 用不上，走官方商店那条路，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 一、先确认网盘里这份是哪一版

网上搜到的版本信息通常是官方当时的最新发布版，而网盘里这份是制作文档时核对过的那一版，两者未必是同一个版本号。本文出现的版本号、包名、体积以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Fancast |
| 版本号 | 1.0.34 |
| 包名 | `com.contentsmadang.fancast` |
| 安装包体积 | 72.16 MB |
| 安装包文件名 | `Fancast_v1.0.34.apk` |
| MD5 | `B021DFCC0E1F375D1454EAA15CBDE6F8` |
| 适用平台 | Android |
| 开发者 | QUICKWINSTUDIO |

装之前顺手核对两件事：**包名**必须是 `com.contentsmadang.fancast`，**体积**应该在 72.16 MB 上下。对不上就说明拿到的不是这份文件。

关于版本号：官方在 2025-09-24 发布了 1.0.34，之后继续按 `1.0.x` 递增发版。官方在 1.0.41（2026-07-24）起把应用整体改名为 coogoong，现在商店里能看到的是 1.0.44、1.0.46 这类更新的版本号，具体以官方页面当时显示的为准。

关于系统要求：官方商店页面标注 Android 5.0 及以上可以安装。安装时如果系统提示「应用与你的设备不兼容」，基本就是系统版本低于这个要求。

## 二、把安装包取到手机上

1. 打开 [Fancast 安装文件资源（夸克网盘）](https://pan.quark.cn/s/36c9b3449110)，先转存到自己网盘再下载——直接下载的临时文件，链接失效后就找不回来了。
2. 在手机网盘里找到 `Fancast_v1.0.34.apk` 下到本地。手机直接下载最省事，免得再从电脑传一遍。
3. 下载完成后核对体积约 72.16 MB。只有几十 KB 的多半是把网盘页面存成了文件，别拿去安装。

## 三、安装步骤

1. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统的这项开关常收在「安全」或「隐私」分类下。
2. **点开 APK 安装**：系统提示「应用未经过安全检测」时选择继续安装，这是非商店渠道安装包的常规提示。
3. **同包名版本要先卸载**：手机里如果已经装过其它渠道获取的同一个包名版本，覆盖安装可能报「应用未安装」，原因是两个包的签名不同。先把旧的那份卸载，再装这一版。
4. **装完先别急着调设置**：能正常打开、能进到登录页，就说明包本身没问题。后面的注册、选艺人、投票都在应用内完成。

## 四、第一次打开会遇到什么

- **会先让你登录或注册**。这一步不做完，投票、社区、商城这几个模块都进不去。七种注册方式的差别见 [注册登录与账号设置.md](注册登录与账号设置.md)。
- **注册流程里会让你设昵称、至少选一个喜欢的艺人，并选一次界面语言**。选中的艺人会直接决定首页推给你的活动和榜单，选错了在「My Page」里可以改。
- **首页不是内容流，而是活动入口和签到入口**。第一眼看上去空或按钮多属正常，日常要用的两个位置是底部导航的 Vote（投票）和 Store（商店，攒资源也在这里）。
- **需要能连到海外服务器**。网络到不了服务器时，表现是一直转圈、登录失败或列表刷不出来，这与安装包本身无关，见 [常见问题与排查.md](常见问题与排查.md)。
- **会申请两类权限**：

| 权限 | 用途 | 不给会怎样 |
| --- | --- | --- |
| 存储（必需） | 下载艺人图片、保存应用数据 | 图片与部分资源加载异常 |
| 位置（可选） | 官方说明中标注为可选 | 不影响使用，部分活动的地区相关内容可能受限 |

Fancast 的权限清单里没有联系人、短信、通话记录这类项目。

## 五、这份包和官方渠道是什么关系

- 官方发布渠道是 **Google Play**（[play.google.com/store/apps/details?id=com.contentsmadang.fancast](https://play.google.com/store/apps/details?id=com.contentsmadang.fancast)）和 **App Store**（[apps.apple.com/us/app/fancast-discover-somethin-new/id1641638840](https://apps.apple.com/us/app/fancast-discover-somethin-new/id1641638840)）；官方在 X 上的账号是 `@fancastofficial`，改名后为 `@coogoong`、`@coogoong_global`。
- 网盘里这份 1.0.34 是文档制作时核对过的版本，**不是官方最新版**，也不会自己弹更新提示。需要新版本时，重新走一遍本文的取包与安装流程即可。
- **它只有 Android 版**。iPhone 装不了 APK，要去 App Store 装 iOS 版。
- 想确认拿到的是不是原版包，看两项就够：**包名 `com.contentsmadang.fancast`、开发者 QUICKWINSTUDIO**，两项都对就是原版。改名前后为什么名字不一样、还有哪些官方渠道，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 六、卸载与换版本

- 同一个包名在系统里只能存在一个，换版本就是「卸载旧的、装新的」，或者用同签名的新包覆盖。
- 卸载会一并清掉应用数据。Fancast 的账号数据存在服务器上，用原来的注册方式重新登录，攒下的心与关注关系还在；但**没登录就攒下的本地数据会丢**，所以装好后第一件事是完成注册登录。
- 装完先确认能登录、能打开投票页，再谈攒资源的事。打不开就接着看 [常见问题与排查.md](常见问题与排查.md)。
