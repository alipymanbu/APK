Fancast 的账号门槛、数据范围和注销路径都写在官方的隐私政策里，不在应用界面里。本篇把它翻成人话，并给出注销前后要自己处理的几件事。下文口径来自官方隐私政策页（[m.fanca.io](https://m.fanca.io/)，适用日期 2026-06-15，运营方为韩国 QUICKWINSTUDIO），条款会更新，以官方页面当时显示的为准。

## 一、注册年龄门槛

官方政策写得比较明确：**平台不面向儿童**——韩国本国用户需满 14 岁，境外用户需满 16 岁。政策同时说明，一旦发现收集到儿童的信息，会删除信息并终止该账号。

注册流程里确实会让你声明年龄是否符合要求，但没有强制实名。这条门槛的实际意义是：**用别人的信息过这一关，风险落在你自己账号上**，被判定不符时处理方式是删除数据加终止账号，不是警告。

## 二、注册和使用中会被收集什么

| 场景 | 必填 | 选填 |
| --- | --- | --- |
| 邮箱注册 | 昵称、使用语言、是否满 14 岁、设备标识 | 出生日期 |
| 第三方账号登录（Google / Apple / X / Kakao / Naver / LINE / Facebook） | 该平台的公开昵称 | 邮箱地址 |
| 使用过程中自动收集 | 设备标识、服务使用记录、访问日志、IP、位置信息、投票与道具发放记录 | — |

两件事值得提前知道：

- **设备标识是必收项**。官方写明：拒绝提供设备标识，服务就无法使用。账号识别是以「加密后的设备标识 + 手机号组合」的方式做的。
- **手机号不是注册必填**，但注册流程会用到设备标识，所以换设备时登录本身的验证方式还是你选的那家平台账号。

## 三、看广告攒心时，数据会流向广告主

这一条藏在政策的「第三方提供」里，日常用不到但值得知道：**为了判断你的看广告行为是否真的完成、以及该不该给你发心，官方会把加密后的设备标识提供给广告主**，保留期限写到「广告结束为止」。除了这项，政策里写明的对外提供只有「你主动同意第三方营销」和「依法配合调查」两种情况。

所以在广告页停留时被读取的只有加密设备标识这一类信息，不涉及你的昵称、邮箱、投票记录。

## 四、数据会留多久

| 数据类型 | 保留期 |
| --- | --- |
| 一般账号信息（邮箱、昵称、设备标识、投票与道具发放记录等） | 注销后 3 个月以内 |
| 不正当使用记录 | 1 年 |
| 契约与撤销、付款与供货记录 | 各 5 年 |
| 投诉与纠纷处理记录 | 3 年 |
| 本人确认相关记录 | 6 个月 |
| 访问记录（登录日志） | 3 个月 |

**「注销」不等于数据立刻全消失**：一般信息 3 个月内清除，而涉及付款、纠纷、访问日志的部分按韩国相关法律要求另存一段时间。这不是应用自己加的条款，是当地电商与通信保密类法规的要求。

## 五、放一年不用会被休眠

官方政策写明：**连续一年未使用的账号会被转为休眠账号，个人信息单独分离保管**。休眠状态下所有服务都用不了，想恢复就重新登录一次——只要在转换生效前登录或使用过，转换就不会发生。

长期只拿来看榜单、不投票不签到的话，记得偶尔打开一次，避免被休眠时正好赶上投票窗口。

## 六、不想要了怎么注销

应用里没有把注销做成一个大按钮，按下面顺序找：

1. **先在应用内找**：My Page / 设置里的账号菜单，或直接走客服中心（1:1 咨询）提出注销请求。不同版本入口位置不同，以你装的那一版实际菜单为准。
2. **找不到就走邮件**：官方隐私政策的联系方式是 `fancastofficial@gmail.com`。邮件里写清三样东西——**注册方式（邮箱或哪家平台）、昵称、请求注销**，处理结果会回到你的邮箱。

注销前建议先自己处理掉这三件事，否则就跟着数据一起没了：

- **把手里剩下的心花掉或投掉**：注销不退还任何已购买或已领取的资源。
- **截图留档**：投票凭证、支付订单号这类需要时用来对账的东西，注销后查不到。
- **解绑支付方式**：如果之前在应用商店里绑定过付款方式，注销应用账号不会连带解绑商店那边的付款信息，需要自己到商店账号设置里去取消。

## 七、有隐私方面的疑问找谁说

- **应用内**：My Page → 客服中心 → 1:1 咨询，账号、支付、投票异常都可以走这里。
- **邮件**：`fancastofficial@gmail.com`，官方政策里列出的个人信息保护负责人邮箱。
- **政策原文**：[m.fanca.io](https://m.fanca.io/) 上是最新版，改动会在应用内「公告」里提前 7 天通知。

注册方式怎么选、多账号怎么处理，见 [注册登录与账号设置.md](注册登录与账号设置.md)；登录不上、验证码收不到这类问题见 [常见问题与排查.md](常见问题与排查.md)。
