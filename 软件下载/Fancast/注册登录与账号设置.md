Fancast 的账号是「注册方式 + 昵称 + 关注艺人」三件套，全部免费。不注册也能浏览部分页面，但投票、攒心、社区都进不去，所以装好后的第一件事就是把它办完。本篇按注册顺序一步步说。

## 一、先选注册方式

注册入口在首次打开应用的引导页，也可以在登录页切换到注册。可选的方式有七种，按你的实际情况选：

| 注册方式 | 适合谁 | 注意点 |
| --- | --- | --- |
| 邮箱 + 密码 | 不想把社交账号关联进来的人 | 验证邮件可能被丢进垃圾箱，处理办法见 [常见问题与排查.md](常见问题与排查.md) |
| Google 账号 | 手机上有 Google 服务的人 | 流程最短，一次点选即可 |
| Apple ID | iPhone 用户，或想少留个人信息的人 | 需要设备上已登录 Apple ID |
| X（原 Twitter） | 追星号本来就活跃在 X 的人 | 需要用 X 的账号授权 |
| Kakao | 有 Kakao 账号的人 | 韩国本地最常用 |
| Naver | 有 Naver 账号的人 | 韩国本地常用 |
| LINE | 常用 LINE 的人 | 需要用 LINE 授权 |

第三方账号登录只是借用它做身份验证，**攒下的心、投票记录、关注关系都挂在 Fancast 的账号上**，不在 Google 或 X 那边。所以选定一种方式后就固定用它登录，换方式登录等于换了一个新账号。

## 二、注册流程里要填的四步

1. **同意条款**：勾选后进下一步。
2. **设昵称**：这是你在榜单、社区、应援板上显示的名字，注册后一般不能在应用内随意重复改，起名时想清楚。
3. **至少选一个喜欢的艺人**：这一步决定首页活动、榜单和投票提醒推给你哪些内容。可以多选，也可以以后在「My Page」里补。
4. **选界面语言**：流程里会给一次语言选择。可选语言随版本不同，以你装的那一版实际列出的为准，别按网上的截图找选项。

整个过程几分钟就能走完，不需要实名、不需要绑定手机号。

## 三、注册完的三件设置

| 要设置的项 | 位置 | 为什么值得改 |
| --- | --- | --- |
| 关注的艺人 | My Page → My Artists | 首页活动、投票提醒的筛选依据；不设就看不到针对性的榜单入口 |
| 界面语言 | 引导流程里选，或应用内设置项 | 决定菜单用哪种语言显示，选错了各页面按钮叫法都对不上 |
| 心（Hearts）余额与有效期 | My Page → Hearts | 判断当前能投几票、哪些心快过期，做法见 [蓝心黄心怎么攒怎么用.md](蓝心黄心怎么攒怎么用.md) |

## 四、多账号怎么处理

同一个设备上注册多个账号是被允许的，换成不同注册方式（或用不同的邮箱）就能各建一个。几个实情先说清楚：

- **每个账号的签到、看广告额度、任务进度都是各算各的**，所以多账号能多攒一份心。
- **投票计入的是名次，不是账号数**。同一活动里多个账号投给同一位艺人，票数会累加，这点和单账号连续投没有区别。
- **账号之间是各自独立的**：加好友、送心这些互动要自己发起，攒下的余额不会跟着你换账号走。
- **多账号意味着多份登录态**，切换频繁时容易在换设备后记不清哪个邮箱对应哪个号。建议注册时就把「账号—艺人—用途」记在便签里。

## 五、换手机与卸载重装

- Fancast 的账号和投票记录存在服务器上，换设备后用**同一个注册方式**登录，数据跟着账号走。
- **换设备前先确认注册方式还记得**：用邮箱注册的，账号就是那个邮箱；用第三方注册的，账号是那家平台的授权，只要那家账号还在就能登回来。
- 卸载重装不影响服务器上的数据，但**本地没同步上去的临时状态会丢**，所以重装后先登录再操作。
- 登录不上去分两种情况：账号本身没问题但网络到不了服务器，或者注册方式记错了。两者的排查顺序不同，见 [常见问题与排查.md](常见问题与排查.md)。

## 六、年龄门槛与长期不用会怎样

- **有年龄门槛**：官方条款写明平台不面向儿童——韩国本国用户需满 14 岁，境外用户需满 16 岁，注册流程里会让你声明是否达到这个年龄。判定不符时官方会删除数据并终止账号。
- **连续一年不登录会被休眠**：账号转为休眠后所有服务都用不了，个人信息单独保管；想恢复就重新登录一次。
- 只打算拿来看榜单、不签到不投票的话，记得**偶尔打开一次**，免得账号休眠时正好错过投票窗口。

这两条都出自官方隐私政策，完整口径与注销办法见 [账号注销与隐私数据.md](账号注销与隐私数据.md)。
