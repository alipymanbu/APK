## 一、注册与登录

CPnow 用**手机号**注册登录，没有单独的用户名体系：

1. 装好打开应用（装包这一步见 [下载与安装教程.md](下载与安装教程.md)）；
2. 在登录页输入手机号，收短信验证码填进去；
3. 首次用的手机号按引导完成注册、补完资料（头像、兴趣标签等）；
4. 换手机、重装应用后，用同一个手机号收验证码就能登回原账号。

登录方式、验证码接收的具体界面以应用内当时显示为准。收不到验证码的处理见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 二、协议与隐私政策在哪看

官方两份协议都在应用内「我的 → 设置 → 协议与隐私」一类入口里，也可以直接打开网页版：

- 用户协议：[h5.iyidui.com.cn 用户协议](https://h5.iyidui.com.cn/webview/page/social/view/user_agreement/index.html)
- 隐私政策：[h5.iyidui.com.cn 隐私政策](https://h5.iyidui.com.cn/webview/page/social/view/user_secret_agreement/index.html)

注册前至少扫两处：**信息共享的对象**与**位置信息的使用方式** —— 你后面关不关定位权限，都是以这两份文本写的行为为准。

## 三、权限逐项说明：哪些能关

装完后可以在**系统设置 → 应用 → CPnow → 权限**里逐项改，不必一次给全。关掉后的实际影响如下（清单取自应用商店公示的权限列表，截至检索时，以应用内实际请求为准）：

| 关掉什么 | 你会失去什么 | 能不能关 |
| --- | --- | --- |
| 精确位置 | 同城推荐、按距离找搭子会不准或不可用 | 可以只给「仅使用期间」，不给精确位置就当纯线上用 |
| 麦克风 | 语音连麦、语音房、K歌全用不了 | 不连麦就能关 |
| 相机 | 视频通话、拍摄发动态 | 不拍就不给 |
| 通知 | 新消息没有提醒，要自己打开应用看 | 建议留着，否则容易漏消息 |
| 悬浮窗 | 语音房挂件之类无法在其他应用上层显示 | 可关 |
| 后台 / 电池优化 | 应用退到后台后可能收不到消息 | 系统「省电策略」设成不限制，消息才及时 |

权限是按需给的：先只开通知和网络，用到哪个功能再开哪个，是更稳妥的顺序。

## 四、账号里值得先设的几项

- **资料与可见范围**：个人资料填兴趣标签会影响系统推荐，填得越具体，匹配到同好的概率越高（官方介绍里的一键匹配就是按兴趣标签、语种偏好、活跃时段推人）。
- **位置共享**：不想被同城的人按距离筛到，就把位置权限改成「仅使用期间」或直接拒绝，功能影响见上表。
- **谁可以给我发消息**：在设置里找消息权限类选项，把陌生人可打扰的范围收窄，能明显减少垃圾招呼（具体选项名以应用内为准）。

## 五、账号注销

应用内提供注销入口（一般在「我的 → 设置」里，具体路径以应用内为准）。点之前把注销页上这三行说明看完：

1. **余额**：还剩多少金币、未使用的虚拟物品怎么处理 —— 先自己对一遍账，见 [金币充值与价格说明.md](金币充值与价格说明.md)；
2. **手机号**：注销后这个号码能否马上注册新账号、原聊天关系还在不在；
3. **不可逆**：资料与历史能否恢复，写清楚了才算数，没写清楚就当不能恢复。

只是想清静一段时间，优先用「退出登录」而不是注销 —— 账号还在，随时能登回来。
