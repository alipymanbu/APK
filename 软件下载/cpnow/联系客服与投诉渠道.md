## 一、最快的入口：应用内客服

官方在消费者投诉平台的回复里给出的路径是：

**打开 CPnow → 「我」→「帮助与客服」→「联系客服」**

官方同一条回复还提到客服热线，号码在页面上显示（投诉平台的转贴里被打码了），**以你应用内「帮助与客服」页面当时显示的为准**。金额类、账号类问题优先走这条 —— 有订单号和注册手机号，客服才好查单。

## 二、投诉平台上的官方主体叫什么

在黑猫消费者服务平台（[tousu.sina.cn](https://tousu.sina.cn)）上搜这个应用，会出现**两个商家名下的受理记录**：

| 商家名 | 说明 |
| --- | --- |
| [CPnow官方App](https://tousu.sina.cn/company/view/?couid=8218869244) | 当前名称的官方受理主体 |
| [ForU官方](https://tousu.sina.cn/company/view/?couid=7974496489) | 该应用早前叫 ForU（公开资料与用户投诉中都提到过这个旧名），旧名下的受理主体，历史投诉在此 |

两家名下都能提交、也见到过官方回复。**提交时认准这两个主体**，别投到名字相近的无关商家去，白等一轮。

## 三、不同问题走哪条路

| 你遇到的问题 | 首选渠道 | 备用渠道 |
| --- | --- | --- |
| 退款、充值不到账 | 应用内客服（带订单号） | 支付宝订单投诉 / iOS 退款页，详见 [金币充值与价格说明.md](金币充值与价格说明.md) 第五节 |
| 举报某个账号或评论 | 应用内举报入口（见 [举报屏蔽与防骗注意事项.md](举报屏蔽与防骗注意事项.md) 第一节） | 客服补充提交截图 |
| 账号登录不上、异常受限 | 应用内客服，提供注册手机号 | 应用商店的开发者反馈入口 |
| 个人信息的查阅、更正、删除 | 政策第九章 + 客服（见 [游客模式与隐私政策说明.md](游客模式与隐私政策说明.md) 第六节） | 投诉平台 |
| 应用本身的功能故障 | 先按 [常见问题与故障排查.md](常见问题与故障排查.md) 自查 | 仍不解决再找客服，带上机型与版本号 |
| 客服长时间不处理 | 黑猫投诉等平台提交（主体见第二节） | 12315 |

## 四、投诉时把这几样备齐

1. **订单号与支付凭证**：金额、时间、支付方式截图；
2. **时间线**：哪天开始用、哪天充的、哪天提的诉求，按顺序写清；
3. **聊天记录截图**：涉及纠纷对象的，截完整上下文，别只截一句；
4. **账号信息**：注册手机号、充值 ID、应用版本号（设置里可查）；
5. **你已走过的渠道**：写明「已在应用内客服反馈 X 次未果」，处理方能少问你一轮。

材料齐、诉求具体（退款写明金额）的工单，平台方能直接对照材料处理，少来回问你几轮；处理时限以平台当时规则为准。
