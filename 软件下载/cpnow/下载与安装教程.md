两条路，任选其一：

商店与网盘的版本号不必一致，只要包名相同就是同一个应用，可以直接覆盖安装。

## 三、安装步骤

1. 把 APK 文件下载到手机（用手机浏览器打开网盘链接下载，或先转存再用网盘 App 下载）。
2. 点击 APK 开始安装。若系统弹出「禁止安装来自此来源的应用」，这是「未知来源安装」的开关：按提示进入**设置 → 允许安装未知应用**，给你的浏览器或文件管理器临时开一次权限，装完可以关掉。
3. 存储空间建议至少留出 300MB：安装包本身 106.98M，安装后应用加上缓存还要占一份。
4. 装完打开，按提示允许基础权限（见下一节）。

装不上或打不开时，按 [常见问题与故障排查.md](常见问题与故障排查.md) 里的「安装失败」一节处理。

## 四、首次打开要给哪些权限

CPnow 是社交应用，位置、麦克风、相机这几项决定核心功能能不能用；其余可以先拒绝、用到再开。以下清单取自应用商店公示的权限列表（截至检索时，以应用内实际请求为准）：

| 权限 | 用在哪 | 建议 |
| --- | --- | --- |
| 位置（大概 / 精确） | 同城推荐、找附近的搭子 | 想用同城功能就允许；不想暴露位置可在系统里改「仅使用期间」 |
| 麦克风、录音 | 语音连麦、语音房、K歌 | 要连麦就允许 |
| 相机、拍摄照片和视频 | 视频通话、发动态 | 要用再给 |
| 读写文件与文档 | 保存图片、传照片 | 允许 |
| 悬浮窗（以悬浮窗形式显示） | 语音房最小化挂件之类 | 可拒绝，拒绝后部分挂件功能不可用 |
| 通知（POST_NOTIFICATIONS） | 消息提醒 | 建议允许，否则收不到新消息提醒 |
| 网络状态 / WLAN | 断线重连 | 允许 |
| 请求安装包 | 应用内更新自己 | 允许才能在应用内升级 |

每一项都能在**系统设置 → 应用 → CPnow → 权限**里随时改，不必一次给全。拿不准要不要注册的，还可以先用游客模式逛一圈再决定（见 [游客模式与隐私政策说明.md](游客模式与隐私政策说明.md) 第一节）。

## 五、版本号对不上怎么办

同一个应用在不同渠道的版本号经常不一样，你可能同时看到好几个数字：

- 应用宝页面显示 3.1.800（更新时间 2026-08-17）；
- 小米应用商店显示 3.2.300（更新时间 2026-09-24）；
- iOS 商店显示的又是另一套版本号体系；
- 本文核对的这份安装包是 3.0.500（核对日期 2026-09-22）。

这不是你装错了。各渠道审核上架节奏不同，版本号会错开一段时间；**具体某个渠道当前是多少，以该渠道页面当时显示为准**。判断「是不是同一个应用」不要看版本号，看这三点：包名 `cn.com.iyidui`、开发者「天津米连网络科技有限公司」、MD5（只有手上的包能算）。

## 六、升级与降级

- **升级**：从应用商店装的，直接在商店里点更新；从 APK 装的，在应用弹出更新提示时按提示覆盖安装，或重新从上面网盘入口取新包（网盘里的包以实际分享内容为准）。
- **降级**：版本号更低的包装不上高版本时，先卸载再装。卸载会清掉应用的本地数据，账号靠手机号登录找回（见 [注册登录与账号设置.md](注册登录与账号设置.md)）；拿不准就先别卸。
