## 一、安装失败 / 提示解析包错误

按出现概率从高到低逐条排掉：

1. **包没下完**：文件大小应为 106.98M，明显偏小就是传输中断，重新下载；
2. **包与系统不兼容**：确认包名是 `cn.com.iyidui`、没装成别的同名应用；
3. **存储不足**：留出至少 300MB 再装；
4. **降级安装被拦**：手机上已有更高版本时，低版本装不上 —— 先卸载再装（数据影响见 [下载与安装教程.md](下载与安装教程.md) 第六节）；
5. **来源未授权**：系统拦截来自浏览器的安装时，按提示给该来源开一次「允许安装未知应用」。

## 二、打开就闪退 / 语音时闪退

- **首次打开闪退**：先重启应用；再进系统设置把「省电策略 / 后台限制」改成不限制，部分机型的过度省电会让应用启动即被杀；
- **进语音房闪退**：官方更新日志里出现过「修复部分安卓机型语音连麦闪退」，先确认版本是最新（商店里看更新时间）；
- **更新后闪退**：清缓存（设置 → 应用 → CPnow → 存储 → 清除缓存，**别点清除数据**，那会退出登录并清本地记录），还不行再考虑重装；
- **装了非商店渠道的旧包**：版本太旧在新系统上容易崩，换商店里的最新版试。

## 三、收不到消息 / 没有通知提醒

先按权限逐项核对：

1. 系统通知权限里 CPnow 是否允许（`POST_NOTIFICATIONS`）；
2. 应用内「消息通知」开关是否打开；
3. 系统「省电策略 / 后台运行」是否被限制 —— 被限制时应用退到后台就收不到推送；
4. 勿扰模式与通知渠道（声音、横幅）是否单独关了；
5. 网络本身通不通（浏览器随便开个网页试一下）。

## 四、同城 / 附近的人不准，或压根不显示

- 位置权限是否给了**精确位置**，只给「大概位置」时距离会明显变粗；
- 手机的定位服务开关、是否只在 GPS 开着时才定位；
- 在 Wi-Fi 下且没开定位时，部分机型定位精度很差，切到移动数据再刷新；
- 完全不想被按距离筛到，就把权限改成「仅使用期间」或拒绝 —— 这是设置选择，不是故障（见 [注册登录与账号设置.md](注册登录与账号设置.md) 第三节）。

## 五、充值后金币没到账

1. 先分清在哪个端充的：网页端要填**充值 ID**，填错会充到别的账号上；
2. 在应用内刷新余额，或在充值页重新查询一次；
3. 网页端支付成功后到账可能有延迟，等几分钟再看；
4. 还是不到账，带上**支付订单号、充值 ID、支付时间截图**找应用内客服；
5. 第三方代充渠道出的问题，不在官方渠道内，官方一般不认账 —— 要充走应用内或官方充值页（见 [金币充值与价格说明.md](金币充值与价格说明.md) 第四节）。

## 六、图片加载慢、弱网卡顿

- 官方更新记录提过「修复部分机型弱网环境下图片加载缓慢」，先升到最新版；
- 弱网时切到信号好的网络，或关掉「仅 Wi-Fi 加载图片」类开关减少等待；
- 房间里语音断续，通常是带宽被占，关掉后台下载再进房；
- 手机本身发热降频也会导致卡顿，退掉几个后台应用再试。

## 七、版本号 / 大小与别人对不上

不同渠道的版本号本来就不同（应用宝 3.1.800、小米 3.2.300、本文这份包 3.0.500），**对不上不代表装错**。判断同一应用只看三点：包名 `cn.com.iyidui`、开发者「天津米连网络科技有限公司」、MD5 `024e037716ae50a6d736bf59720d219f`（最后一条只有手上的包能算）。详见 [下载与安装教程.md](下载与安装教程.md) 第五节。

## 八、登录不上 / 收不到验证码

- 手机号是否输错、是否被运营商短信拦截（看拦截短信文件夹）；
- 隔 60 秒再取一次，短时间内反复请求会被限频；
- 换网络再试：数据与 Wi-Fi 各来一次；
- 号码换了运营商或长期欠费停机，可能收不到行业短信，换回常用号码再试；
- 实在登不上，走「我 → 帮助与客服 → 联系客服」，提供注册手机号处理（完整渠道见 [联系客服与投诉渠道.md](联系客服与投诉渠道.md)）。
