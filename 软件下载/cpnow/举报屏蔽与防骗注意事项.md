## 一、举报：两处入口

CPnow 的举报入口有两处（公开的使用指南给出的步骤，以应用内当时界面为准）：

1. **举报某个人**：在对方资料页或聊天页，点人物旁边的 **【…】** → 点**举报**，选类别提交；
2. **举报某条评论**：进评论区，**长按**那条评论 → 选举报。

举报时把理由选准（骚扰、虚假信息、诱导消费、不当内容），能附截图就附 —— 证据越完整，平台那边越有的放矢（见第三节）。

## 二、屏蔽与拉黑

不想再收到某人的消息，除了举报还有屏蔽：

- 在对方资料页 / 聊天页的 **【…】** 菜单里找「屏蔽 / 拉黑」，屏蔽后对方无法再给你发消息、看你的动态（具体范围以应用内说明为准）；
- 房间里被某人刷屏，可以让房主或管理员禁言对方；
- 彻底清静的终极手段是**退出登录**一段时间（见 [注册登录与账号设置.md](注册登录与账号设置.md) 第五节，注意注销与退出不是一回事）。

## 三、平台公示了哪些审核机制

按公开报道的口径，CPnow 采用「AI 审核 + 人工巡查」过滤不当言论与骚扰，并在产品内提供举报与屏蔽功能。**这是报道里的说法，不是你可验证的承诺** —— 实际处理速度与结果，取决于你提交的证据是否完整，所以第一节里的截图很关键。

官方协议层面能看到的两份文件是 [用户协议](https://h5.iyidui.com.cn/webview/page/social/view/user_agreement/index.html) 与 [隐私政策](https://h5.iyidui.com.cn/webview/page/social/view/user_secret_agreement/index.html)，其中写了行为规范与信息处理方式，遇到要举证的纠纷时，这两份是你的依据。

## 四、用户反馈里高频出现的几种情形

应用商店评论与消费者投诉平台上，反复出现的说法集中在几类（**以下均为用户单方陈述，未经官方确认，仅供你识别风险信号**）：

| 信号 | 具体表现（用户描述） |
| --- | --- |
| 刚注册就大量主动招呼 | 头几天收到很多条陌生人的主动搭话，话术相似 |
| 快速推进关系 | 认识不久就要求「绑关系」「官宣」「送礼物」确认 |
| 逐级加码 | 从几块钱的小额开始，金额一次次抬高 |
| 线下不见面 | 聊了很久约不出来，一到花钱的环节就很积极 |
| 停止付费后冷淡 | 不充值后对方不再回复或直接拉黑 |

这些描述在 iOS 商店 2.1 分的评论区和黑猫投诉平台的多条记录里都能看到；同一时间应用宝显示 4.8 分、291.4 万下载。**两边的口径摆在一起**，谁真谁假由你自己判断 —— 这里只提醒：上表任意占两条以上，就值得停下来。

## 五、遇到诱导充值，怎么止损

1. **先停手**：不点任何新的付款确认，截图保存聊天记录、订单号、支付凭证；
2. **收权限**：把对方屏蔽、关掉免密支付与自动续费（iOS 的取消路径见 [金币充值与价格说明.md](金币充值与价格说明.md) 第三节）；
3. **平台内处理**：用第一节的入口举报该账号，同时找应用内客服提交订单与截图；
4. **平台外处理**：支付宝订单发起投诉、iOS 内购走退款页、或到消费者投诉平台与 12315 提交材料；
5. **金额较大或涉诈骗**：带聊天与转账记录到当地派出所报案。

判断标准很简单：**对方催你花钱的速度，比你们建立信任的速度快**，就按上面五步走。

## 六、日常把风险降下来

- 位置权限给「仅使用期间」，不给精确位置时也能线上聊（见 [注册登录与账号设置.md](注册登录与账号设置.md) 第三节）；
- 涉及线下见面，选公共场所、告诉朋友行程、自己安排往返；
- 不发身份证、家庭住址、验证码、支付密码，任何环节都不发；
- 想玩语音房与组队这类低风险场景，从 [找搭子与房间玩法教程.md](找搭子与房间玩法教程.md) 的公开房间进，比一对一深聊安全。
