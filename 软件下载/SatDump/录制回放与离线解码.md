## 一、为什么要「先录后解」

过境窗口只有十几分钟，实时解码一旦参数没调对，数据就直接浪费了。把原始基带录下来有三个实际好处：

- **参数可以事后慢慢试**：增益、pipeline 选项错了，重解一次就行，不必等下一次过境；
- **换电脑处理**：手机录的文件拷到电脑用桌面版解，性能不足时更稳；
- **留下可复现的样本**：同一份基带能对比不同版本 SatDump 的解码效果，也能发给别人帮你诊断。

代价是磁盘：基带是未压缩的原始采样，采样率越高文件越大 —— 手机上录之前先确认剩余空间，高采样率的 L 波段链路更是动辄上 GB。

## 二、怎么录

**GUI 路线（推荐新手）**：

1. 主界面 **Add → Recorder** 添加录制器；
2. Device 面板选好 SDR、频率、增益、采样率（参照 [手机端接收卫星信号教程.md](手机端接收卫星信号教程.md) 第四节）；
3. 切到 Recording 面板，指定输出目录与基带格式，点开始；
4. 卫星过境期间录制持续写盘，结束后停止即可。

录制可以与实时解码（Processing 面板）同时进行：实时出的图让你心里有底，基带留给事后精修。

**命令行路线**（桌面版，适合自动化）：

```bash
satdump legacy record baseband_name --source airspy --samplerate 6e6 --frequency 1701.3e6 --general_gain 18 --bias --timeout 780 --baseband_format cf32
```

要点：

- `--source` 指定 SDR 设备，先跑 `satdump sdr_probe` 能列出可用设备与 ID；
- `--samplerate` 单位是 Hz，`6e6` 即 6 MSPS；`--frequency` 同样以 Hz 为单位，填目标卫星下行频率；
- `--timeout` 是录制秒数，按过境时长设；
- `--bias` 给天线端 LNA 供电用，没接有源天线别开。

## 三、怎么离线解码

**GUI**：File → Processing 打开离线处理窗口（1.2.x 是主界面的 Offline Processing 标签页），依次选：

1. **pipeline**：与录制时的卫星和链路对应；
2. **输入文件**：刚录的基带；
3. **输入层级（Input Level）**：告诉它这是基带（baseband）、帧数据还是软符号 —— 层级选错会解不出任何东西；
4. **采样率等参数**：与录制时保持一致；
5. 点 Start，处理完结果自动出现在结果树里。

**命令行**：

```bash
satdump pipeline metop_ahrpt baseband /path/to/metop_baseband.cs16 metop_output_directory --samplerate 6e6 --baseband_format cs16
```

格式对应关系：`baseband_format` 要与录制时的格式一致（cf32/cs32/cs16/cs8/cu8 等），采样率也要照抄录制值，对不上轻则解码失败，重则出一堆噪点图。完整管线与参数见官方文档的 Satellite pipelines 页。

## 四、结果文件怎么找、怎么用

解码输出按 pipeline 与日期分目录存放，典型内容：

- **图像/产品文件**：各通道图像与合成图，产品数据（1.2.0 起含产品元数据文件）；
- **帧与遥测数据**：原始帧、json 形式的遥测，供进一步分析；
- 在 GUI 里，解完的卫星会出现在 Root 的 Products 分类下，点选仪器 → 应用预设（Presets）→ Apply 出图。

**地图投影**：原始图像是沿轨道条带的，要叠地图得走投影流程 —— 对当前图像点 Add to Proj，或用菜单 Current → Image to Handler 把图像拖到 Projection 项上，选 Equirectangular（等距圆柱）并开自动模式，点 Project 即可得到带地理坐标的图。想加国界线、城市点，用 Current → Add Overlay 再 Apply。

**保存**：菜单栏 Current → Save Image 导出当前看到的图。

## 五、命令行三兄弟对照

| 命令 | 干什么 | 什么时候用 |
| --- | --- | --- |
| `satdump legacy record` | 只录基带 | 人不在电脑旁、只想要原始数据 |
| `satdump legacy live` | 边收边解 | 命令行自动化接收站 |
| `satdump pipeline` | 离线解已有文件 | 事后处理录制结果 |

三个命令都支持把模块参数直接写在后面（如 `--gain`、`--bias`、`--dc_block`），加 `--help` 可看当前版本的完整参数表。命令行输出目录、基带格式等默认值可在配置文件（`satdump.cfg`）里改。
