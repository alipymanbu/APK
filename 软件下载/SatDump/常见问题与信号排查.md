## 一、设备检测不到

| 现象 | 先查什么 |
| --- | --- |
| Windows 上设备列表为空 | SDR 驱动没装对：RTL-SDR 类设备要用 Zadig 把它绑定到 WinUSB；插在 USB 3.0 口上换个口试 |
| Linux 上认不出 | DVB-T 驱动占用了设备，按社区通行做法解绑驱动并加 udev 规则 |
| Android 上列表为空 | OTG 线是否支持数据传输（很多充电线只有供电脚）、供电是否够 —— 换线换口是第一试法；再确认你的 SDR 型号在官方支持列表内（[支持的SDR设备与天线怎么选.md](支持的SDR设备与天线怎么选.md)） |
| 能看到设备但打不开 | 通常被别的程序（SDR++、SDR# 等）占用着，关掉它们再试 |

## 二、瀑布图里根本没有信号

按这个顺序排除，命中即停：

1. **时间对不对**：用过境预报核对卫星是否正在头顶上方 —— 没到时间、已过境都收不到，这是新手最常见的「故障」；更要紧的是**目标卫星还在不在发信号**：NOAA POES 已于 2025 年全部退役，照老教程等 NOAA APT 永远等不到（[能接收哪些卫星与频率.md](能接收哪些卫星与频率.md) 第三节）；
2. **频率对不对**：对照 [能接收哪些卫星与频率.md](能接收哪些卫星与频率.md) 与 pipeline 内置参数，手输频率打错一个数字就完全偏了；
3. **天线对不对**：137 MHz 卫星要用 V 形偶极/turnstile，拿 FM 收音机天线去收卫星是收不到的；把天线挪到窗边、室外，避开金属窗框与电器；
4. **增益太低**：瀑布图整体黑死时把增益往上推，直到能看出底噪。

**别用自动增益**：RTL AGC / Tuner AGC 是为 DVB-T 这类宽带信号设计的，面对卫星的窄带信号会把增益抬得过高，结果反而更糟 —— 手动增益，慢慢推到信号最清楚为止。

## 三、看得到信号却解不出图

- **pipeline 选错了**：信号形态对不上卫星，解出来全是噪点 —— 核对 pipeline 名是否同时匹配卫星与链路（拿 NOAA 的历史录音就不能用 Meteor LRPT 的管线去解）；
- **输入层级/采样率对不上**：离线处理时 Input Level 与采样率要和录制时一致（[录制回放与离线解码.md](录制回放与离线解码.md)）；
- **多普勒没修正**：低轨卫星过境中频率漂移，未开跟踪修正时解码会断断续续，尤其 L 波段以上更明显；
- **信号本身太弱**：先用另一台设备或另一根天线确认信号质量，弱信号怎么调参数都救不回来。

## 四、出图了但质量差

| 症状 | 判断与处理 |
| --- | --- |
| 图像横向断条、有黑缝 | 信号在过境中途掉了：天线方位没跟住、被建筑物遮挡，或增益偏低 —— 提高增益、换更开阔的位置 |
| 瀑布图整片发白、噪点糊满 | 增益过高导致饱和，往回调，让信号峰值明显高出底噪但不顶满刻度 |
| 图像整体偏暗或通道错色 | 用管线的校准/合成预设（Presets）重新 Apply；部分定量化产品需要校准数据支持 |
| 同一卫星两次接收质量差很多 | 天气、遮挡、周边电磁环境都会影响；对比两次的过境仰角与天线位置更有诊断价值 |
| 接收十几分钟后程序卡顿 | 性能不足：降低采样率、关闭实时解码只保留录制，或换电脑处理 |

**增益不是越高越好，两种说法都有依据**：有经验帖指出最大增益会把 RTL-SDR 推到过载、解码反而变差；也有收 L 波段 HRPT 的指南说 RTL-SDR 基本都要把增益拉满。两者的场景不同 —— 弱信号、窄带的 137 MHz 链路重在「信号清楚但不顶满」，宽带强信号链路则往往要拉高。判断标准始终是看瀑布图：峰值明显高出底噪、整片不发白，就是当前天线与环境下的合适位置。

**环境干扰的排查顺序**：

1. **视线（line of sight）是第一位的** —— 比天线和 SDR 都重要：山顶、开阔农田最好，城市里选天台、公园这类天空无遮挡的位置；
2. **远离干扰源**：开关电源、LED 灯、电力线载波都会产生宽频噪声，天线离电脑、路由器、充电器越远越好；
3. **别贴着 FM 广播发射台收**：距离约 1 km 以内，强到 SDR 直接过载，什么都收不到 —— 这种位置换多好的天线都救不回来。

## 五、软件与版本类问题

- **升级后打不开旧结果**：版本规则里「次版本变更可能不向后兼容」（1.1.0 发布说明），老版本生成的产品文件在新版本里可能打不开，反向亦然 —— 混用版本前先备份 `config`；
- **Windows 便携版升级后跑不起来**：按官方 1.2.0 发布说明，别把新 zip 解压进旧目录，解到新目录再拷 `config` 过去；
- **缺 DLL 报错**：装 Visual C++ 运行库；
- **要不要追新版本**：稳定版与 Alpha 版的选择标准见 [下载与安装教程.md](下载与安装教程.md) 第二节 —— 工作流正常就不必折腾；
- **界面全是英文**：官方无中文界面，本文档的中文说法与英文菜单名的对应关系在各篇开头附近都有标注。
