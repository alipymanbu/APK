## 一、手机端能做什么、不能做什么

SatDump 的 Android 版是桌面版的完整移植，接收、录制、实时解码、离线处理都能做，但有两条硬边界你得先知道：

- **SDR 型号受限**。官方下载页写明，Android 上目前只支持 RTL-SDR、Airspy、Airspy HF、LimeSDR Mini、HackRF 这几种 —— 不是所有桌面能用的 SDR 手机都能用。
- **靠 USB OTG 连接**。手机本身没有射频接收能力，SDR 要通过 OTG 转接线插到手机上；设备供电不足是手机端最常见的掉线原因。

如果你的 SDR 不在支持列表里，桌面版是唯一出路（见 [支持的SDR设备与天线怎么选.md](支持的SDR设备与天线怎么选.md)）。

## 二、准备清单

1. 装好 SatDump（[下载与安装教程.md](下载与安装教程.md)）；
2. 支持列表内的 SDR 设备一根 + 对应的 OTG 线（Type-C / Micro-USB 按你的手机选）；
3. 匹配频率的天线 —— 收 NOAA、Meteor 这类 137 MHz 气象卫星，一根 V 形偶极天线就够起步；
4. 户外或窗边开阔的接收位置：卫星在地平线以上才有信号，提前用过境预报工具查时间与方位。

## 三、接上设备：确认 SDR 被认出来

1. OTG 线连接手机与 SDR，插稳；
2. 打开 SatDump，进入录制器（Recorder）的设备（Device）选择处；
3. 下拉设备列表，能看到你的 SDR 型号即为连接成功。

列表里什么都没有，先换一根 OTG 线、换一个接口试（供电问题是第一位的），仍不行按 [常见问题与信号排查.md](常见问题与信号排查.md) 的「检测不到设备」一节处理。

## 四、加一个录制器并调参

在主界面用 **Add → Recorder**（添加录制器）开一个接收任务，然后在 Device 面板里设置三个关键参数：

| 参数 | 怎么设 |
| --- | --- |
| 频率（Frequency） | 填目标卫星下行频率，例如 NOAA APT 在 137 MHz 频段（具体见 [能接收哪些卫星与频率.md](能接收哪些卫星与频率.md)） |
| 增益（Gain） | 先调到中等偏上，过境时再微调：瀑布图整片发白是增益过高，波形几乎贴底是过低 |
| 采样率（Sample Rate） | 按链路带宽选：APT/LRPT 这类窄带信号 1~2.4 MSPS 足够；带宽大的链路用更高值 |

**多普勒修正**：低轨卫星过境时相对速度极高，频率会前后漂移几百 kHz。1.2.x 的录制器里有对应的跟踪/多普勒选项，接收 NOAA、Meteor 时把它打开，信号才不会在过境中途跑出通道。

## 五、选 pipeline 并开始解码

1. 在录制器的 Processing（处理）区，从 pipeline 列表里选与目标卫星匹配的那条，例如收 NOAA APT 就选 NOAA APT 相关 pipeline，收 Meteor-M 的 LRPT 就选 Meteor LRPT；
2. 在 pipeline 设置里指定输出目录（Android 上建议指向手机存储里你找得到的文件夹）；
3. 卫星到点后点开始，实时解码出图。

**选错 pipeline 是「有信号却不出图」最常见的原因** —— 瀑布图里明明能看到信号，但解码结果是噪点或空白。判断标准很简单：pipeline 的名字要同时对上「卫星 + 链路」，对照 [能接收哪些卫星与频率.md](能接收哪些卫星与频率.md) 核对一遍。

## 六、录制与回放：手机更适合「先录后解」

实时解码对手机性能有压力，且过境只有短短十几分钟，一次失误就没了。更稳的玩法是**先录基带、过完境再解码**：

- 录制（Recording）与实时解码可以同时开：录制把原始基带存下来，实时解码同步出图；
- 录完后用 File → Processing（离线处理）加载基带文件反复重解，参数怎么试都不影响已经到手的数据；
- 手机上录的文件可以通过数据线拷到电脑，用桌面版接着处理，输出目录配置见 [录制回放与离线解码.md](录制回放与离线解码.md)。

## 七、手机端特有的几个注意点

- **屏幕别熄**：接收过程中让手机保持常亮，或在系统设置里允许 SatDump 后台运行，熄屏可能中断接收；
- **横屏更够用**：录制器的瀑布图与参数面板横向排布，横屏能一次看全；
- **发热降速**：长时间高采样率接收会让手机明显发热，性能不足时会出现掉帧、掉数据，休息或降低采样率即可；
- **结果文件在哪**：解码输出在你设置的输出目录里，Android 上按 pipeline 与日期分文件夹存放，用文件管理器即可查看。
