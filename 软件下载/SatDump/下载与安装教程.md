## 一、这是什么软件

SatDump 是一款开源的卫星数据接收与解码软件：你用一个软件定义无线电（SDR）设备接收卫星下行信号，它负责把信号解码成图像与数据产品。实时解码、录制基带、离线处理、地图投影，这些环节都在同一个程序里完成，不用在多个软件之间倒腾。

你适合用它的几种情况：

- 手头有 RTL-SDR 这类几十元的接收器，想亲手收一张卫星云图（当前首选目标是 Meteor-M 系列，见 [能接收哪些卫星与频率.md](能接收哪些卫星与频率.md)）；
- 想在手机上完成接收与解码，不想背笔记本电脑；
- 需要处理录制好的基带文件，或需要校准、带地图投影的定量化产品。

别把它当成「装上就能看到卫星图像」的播放器 —— 你得有 SDR 硬件与天线，或者有别人录好的信号文件，才能真正跑起来（见 [支持的SDR设备与天线怎么选.md](支持的SDR设备与天线怎么选.md)）。

版本号规则是官方在 1.1.0 发布说明里定的：`主版本.次版本.修订号`，主版本变 = 兼容性彻底断裂，次版本变 = 可能不向后兼容（老版本生成的产品文件可能打不开），修订号变 = 普通小更新。

**版本怎么选**：截至 2026 年 9 月，官方下载页的稳定版仍是 1.2.2；官方从 2026 年 6 月起开始发布 2.0.0 的 Alpha 测试版，并说明 1.2.x 系列已被其取代，但 Alpha 阶段意味着部分工作流还没稳定，官方也提醒升级前先确认你用的功能是否已就绪。**你手上的工作流跑得顺，就不必追 Alpha 版**；具体以官方下载页当时显示为准。

## 三、Android 安装

网盘里放的是 **Android 版 1.2.2 安装包**，[SatDump 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bdac963bda10)，转存后下载即可。这份包的实际参数（以本机留存的记录为准）：

- 版本：1.2.2
- 包名：`org.satdump.SatDump`
- 体积：70.25M
- MD5：`828B4937EDD38CC536A3FC9EEAFF652D`

安装步骤：

1. 从网盘下载 `SatDump_v1.2.2.apk` 到手机；
2. 手机设置里允许「安装未知来源应用」（不同品牌路径不同，一般在「设置 → 应用 → 特殊权限」里）；
3. 点击 APK 完成安装；
4. 首次启动会请求文件读写等权限，接收与保存结果都要用，建议允许。

**系统要求**：官方下载页标注 Android 9.0 及以上。部分渠道的页面会写更低的安卓版本要求，以官方口径为准 —— 装不上或一运行就闪退时，先确认系统版本。

**其他获取渠道**：官方文档说明 Android 端首选 F-Droid（[f-droid.org/packages/org.satdump.SatDump](https://f-droid.org/packages/org.satdump.SatDump)），其次才是 GitHub Releases 上的 APK。F-Droid 会自动跟踪更新，网盘这份 1.2.2 则固定不变 —— 两条路线装的都是同一个应用（包名一致），可按你对更新频率的偏好选。

## 四、Windows / macOS / Linux 安装

桌面版与 Android 版是同一套软件的两种形态，功能基本一致：

- **Windows**：官方下载页提供 x64 与 arm64 的「安装版」和「便携版」两种。程序依赖 Visual C++ 运行库，正常机器多半已装好，缺了会报缺少 DLL，去微软官方支持页装一次即可。
- **macOS**：分 Intel 与 Apple Silicon（M 系列）两种 DMG，按芯片选。
- **Linux**：官方提供 Ubuntu 22.04 / 24.04 与 arm64 的 deb 包；官方文档同时说明，在 Linux 上自行编译是推荐路线，deb 只是省事的替代。

**便携版升级的坑**（官方 1.2.0 发布说明原话）：不要把新版 zip 直接解压进旧目录覆盖，要解到一个新目录，再把旧目录里的 `config` 文件夹拷过去 —— 直接覆盖会出现升级后跑不起来的情况。

## 五、装完先确认这三件事

1. **界面语言**：SatDump 没有官方中文界面，菜单与选项都是英文；本文档里的中文说法（如「录制器」「离线处理」）对应的英文名会在各篇里标出。
2. **软件不会自带卫星数据**：第一次打开没有图像可看属正常，你还需要 SDR 硬件与天线（[支持的SDR设备与天线怎么选.md](支持的SDR设备与天线怎么选.md)），或一段录好的信号文件（[录制回放与离线解码.md](录制回放与离线解码.md)）。
3. **能识别你的 SDR 吗**：接上 SDR 后在软件里看设备列表能否列出它；认不出来是高频问题，按 [常见问题与信号排查.md](常见问题与信号排查.md) 处理。
