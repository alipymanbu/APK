## 一、手势：不碰按钮的三种基本操作

播放界面直接在画面上滑就能调，多篇教程的描述一致：

| 手势 | 作用 |
| --- | --- |
| 屏幕左半边上下滑 | 调亮度 |
| 屏幕右半边上下滑 | 调音量 |
| 横向滑 | 拖动进度快进/快退 |

双指捏合可调速（与倍速列表共用，见下节）。

## 二、画质：WiFi 与流量分开设

官方支持 DASH 自适应码率，可切 4K、1080P60、HDR 等画质（高画质通常与账号等级相关，能选到哪些以你账号实际可选的为准）。设置路径：

1. 首页右上角齿轮进入设置；
2. 找到播放设置（不同版本里可能叫「播放与画质」）；
3. 分别配置 **WiFi 下画质** 与 **移动流量下画质**。

把流量那档调低一档，出门在外不容易一边看一边心痛流量。

## 三、倍速：一处编辑，处处生效

倍速列表是集中管理的，路径为 **设置 → 播放与画质 → 播放速度**，在那里：

- 编辑播放器的倍速列表（增删自定义档位）；
- 选一个默认播放速度；
- 需要临时快进时，长按调出独立的 1.0x–8.0x 滑块，或用常用倍速快捷点，也可以直接点当前数值输入。

播放器菜单里的倍速选项和双指调速共用这份列表 —— 在设置里加了档位，播放器里就能选到。

## 四、后台播放与「听视频」

想锁屏后继续听，两条路：

- **开关式**：进设置，往下滑找到「后台播放」，把开关打开；
- **听视频模式**：进入听视频界面，可在沉浸式与黑胶唱片样式之间切换，带歌词、播放列表与定时关闭，并与系统媒体中心联动（锁屏与通知栏控制）。

看直播回放或长视频想只听声音时，这套最省电。

## 五、画中画与横竖屏

播放中退出应用可进入画中画小窗继续看；平板与折叠屏有侧边栏与影院布局，横竖屏方向策略可自行调整。这些开关同样在设置里，装好后建议逐个过一遍（官方 README 也建议安装后进设置按自己习惯调整默认值）。

## 六、弹幕相关设置在哪

弹幕的显示效果（透明度、字号、速度等）在设置的弹幕项里调；如果你还想按关键词过滤或高亮弹幕，那属于插件能力，见 [插件系统使用说明.md](插件系统使用说明.md)。播放本身卡顿、黑屏的问题，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
