## 一、插件在应用里的哪个位置

打开应用进「设置」，里面能找到插件中心（不同版本可能叫「插件」）。装好后第一件事不是找插件，而是把主开关和自己要的那几个启用 —— 内置插件随主应用分发，不需要额外下载。

## 二、内置插件清单（截至 2026-09 官方 README 所列 10 个）

| 插件 | 你用它做什么 |
| --- | --- |
| 空降助手 | 按社区数据库跳过视频里的恰饭段落，数据来自 BilibiliSponsorBlock |
| 去广告 | 过滤信息流与界面里的广告位 |
| 弹幕增强 | 弹幕屏蔽规则支持正则与前缀语法，可按关键词过滤、高亮 |
| Anime4K | 实时画质增强，低分辨率片源看着更锐 |
| 夜间护眼 | 夜里关灯看时压低画面刺激 |
| 今日推荐单 | 生成一份当天的推荐清单 |
| 初见推荐 | 按初次接触的口味做推荐（实现致谢 TabulaBili 系列项目） |
| CDN 属地优选 | 选更适合你网络的 CDN 节点，播放卡顿时值得开 |
| DLNA | 投到同一局域网里的电视/盒子 |
| Google Cast | 投到 Chromecast 类设备 |

播放卡顿时优先试「CDN 属地优选」，投屏则按你家里的设备二选一，具体设置与搜不到设备的排查见 [投屏到电视的设置与排查.md](投屏到电视的设置与排查.md)（播放侧的其他设置见 [播放设置与手势操作.md](播放设置与手势操作.md)）。

## 三、JSON 规则插件：不用装包也能改行为

如果你只想改「推荐流里不出现什么」「弹幕里屏蔽什么」，用 JSON 规则插件就够，不需要重新编译：

1. 写好或拿到一份规则文件（`.bp` / JSON 格式）；
2. 在插件中心选「从 URL 导入」或导入本地文件；
3. 导入后启用，规则立即对推荐流/弹幕生效。

规则里可以按字段做过滤，例如把某类时长、某关键词的条目直接隐藏。规则怎么写，官方仓库的 `docs/PLUGIN_DEVELOPMENT.md` 有完整格式说明。

## 四、导入第三方插件前，先看能力声明（重要）

官方 README 特意加了警告：导入第三方插件前要审阅它的规则与能力声明，尤其是这几类敏感能力 ——

- `NETWORK`：插件能发网络请求；
- `LOCAL_HISTORY_READ` / `LOCAL_FEEDBACK_READ`：能读你的本地观看记录；
- `PLAYER_CONTROL`：能接管播放器。

只从你信得过的来源装插件；一份声称要读本地历史的「弹幕过滤」插件，就该多想一下。这与 [登录账号的几种方式.md](登录账号的几种方式.md) 里「登录信息只存在本地」的边界是同一件事：本地数据是否被读走，取决于你装了什么。

## 五、外部插件包目前的成熟度

外部 `.bpplugin` 包的 SDK、包格式、签名校验已经就绪，但**外部 Dex 执行仍处于预览阶段** —— 也就是说，社区直接发给你的插件包，装上后行为未必稳定，别把它当成日常依赖。源码级原生插件适合能自己编译 APK 的用户，普通用户不必碰。功能异常或导入失败的排查见 [常见问题与故障排查.md](常见问题与故障排查.md)。
