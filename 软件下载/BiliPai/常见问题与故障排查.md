## 一、安装阶段

**提示「不允许安装未知来源应用」**
对发起安装的那个来源（浏览器、文件管理器、夸克）临时打开允许，装完可关。系统设置里的路径一般是：设置 → 应用 → 特殊权限 → 安装未知应用。

**安装包解析失败 / 装到一半报错**
先确认包完整：按 [下载与安装教程.md](下载与安装教程.md) 里的 `certutil` 命令核对 MD5，不一致就是传输中断，重新下载。另注意官方说明 CPU 架构「优先面向 64 位设备」，极老的 32 位机型可能装不上。

**系统版本太低**
要求 Android 8.0 及以上，低于它会直接装不上或秒退。

## 二、启动与闪退

按成本从低到高试：

1. 重启手机，清理后台再开；
2. 长按应用图标 → 应用信息 → 存储占用 → 清缓存（**先别清数据**，清数据会丢登录态）；
3. 换网络环境（WiFi 切流量）再开；
4. 卸载后重装同包名 APK，登录状态需要重新走一遍 [登录账号的几种方式.md](登录账号的几种方式.md)。

如果是**特定机型闪退**：官方 CHANGELOG 记录过「修复三星 Android 13 闪退」，说明这类问题会随版本修掉 —— 先升级到最新版再判断是不是机型不兼容（版本以官方 `CHANGELOG.md` 为准）。

## 三、登录相关

**扫码没反应 / 二维码扫不出来**
二维码有有效期，先刷新重新生成；再确认两台设备网络正常。不行就换手机号密码或短信验证码登录 —— 官方提供四种方式，一种不通换一种（对照表见 [登录账号的几种方式.md](登录账号的几种方式.md)）。

**登录后动态、发现板块是空的**
先确认登录态真的建立了（个人中心能看到账号信息）。仍为空则退出重登一次。

**担心账号安全**
登录信息按官方说明只保存在本地。要降低风险，重点是装的包别被篡改 —— 核对 MD5、从官方渠道或头部那条安装文件资源拿包，比纠结客户端本身有用。

## 四、播放相关

| 症状 | 先查什么 |
| --- | --- |
| 画面卡、缓冲慢 | 开「CDN 属地优选」插件换节点；切网络试 |
| 选不了高画质 | 账号权限与登录态；DASH 高画质与账号等级相关，能选哪些以实际为准 |
| 弹幕挡画面 | 设置里调弹幕透明度/字号；要按关键词屏蔽，用「弹幕增强」插件 |
| 锁屏后没声音 | 后台播放开关没开，去设置里打开（路径见 [播放设置与手势操作.md](播放设置与手势操作.md)） |

**直播能不能看？** 两种口径并列给你：官方 README 的核心能力里列有「直播：分区浏览、HLS 播放、实时弹幕」；而部分使用反馈称「实时直播因接口限制暂未开放，仅支持直播回放」。实测以你装的版本为准 —— 直播分区能进且有画面就是能看，进不去或一直缓冲就先升级版本再下结论。

## 五、缓存相关

- **下到一半停住**：断点续传会接着下，先等一轮；仍不动就按 [离线缓存视频怎么用.md](离线缓存视频怎么用.md) 的顺序查网络、登录态、剩余空间。
- **状态显示等待合并**：DASH 的音视频分片在合并，等它跑完，不是坏任务。
- **想用别的播放器打开缓存文件**：做不到，缓存仅在应用内播放。

## 六、插件相关

导入失败或插件没生效：确认文件格式与导入路径、插件开关是否打开；外部 `.bpplugin` 包的 Dex 执行仍在预览阶段，不稳定属已知情况（详见 [插件系统使用说明.md](插件系统使用说明.md)）。装了可疑插件后出现异常行为，直接卸载该插件再看是否恢复。
