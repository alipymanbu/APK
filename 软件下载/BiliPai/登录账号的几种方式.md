## 一、哪些功能要登录，哪些不用

不登录也能用：首页推荐流、分区标签切换、点开视频直接播放。

必须登录才能用：动态（关注的 UP 主更新）、发现类板块、收藏与历史同步、评论与互动、消息通知。多篇使用反馈都提到「底部的动态以及发现板块需要登录后才能使用」，你打开后如果发现这两个入口是空的或提示登录，属正常。

## 二、四种登录方式怎么选

官方 README 列出的登录方式有四种，按场景挑一个就行：

| 方式 | 适合场景 | 操作 |
| --- | --- | --- |
| 扫码登录 | 手边有已登录 B 站的设备（另一台手机、平板或电脑浏览器） | 最省输入，对账号密码在键盘上暴露的担心也最小 |
| 手机号 + 密码 | 只有这一台设备 | 直接输手机号和密码 |
| 短信验证码 | 忘记密码、或不想输密码 | 手机号收码填入 |
| Cookie 导入 | 前三种都走不通时的兜底 | 从浏览器复制已登录的 Cookie 填进去 |

具体入口路径是各家教程描述一致的那条：**「我的」→「安全登录」**，进去后在几种方式里选一个。首次启动时如果你停在「开始探索」页，先点它进主界面，再从底部进「我的」。

## 三、登录之后你该确认的三件事

1. **动态能不能刷**：底部切到动态，能看到关注 UP 主的新内容即登录成功。
2. **收藏与历史在不在**：个人中心里点开收藏夹与播放历史，与网页端对得上就说明同步正常。
3. **互动是否正常**：随便进一个视频发一条弹幕或点个赞，能成功说明账号权限没问题。

## 四、登录信息保存在哪

按官方 README 的说明，登录信息只保存在本地设备，不会主动上传；权限请求尽量收敛，使用统计默认只记录匿名日活与基础使用情况。你在系统「应用权限」里逐项查看时，也可以自己核对它申请了哪些权限。

另外注意一点：登录能不能顺利走通，也取决于你装的包是否完整、是否被篡改。走 [下载与安装教程.md](下载与安装教程.md) 里那条校验 MD5 的流程，比什么都稳。

## 五、登录不上怎么办

扫码没反应、验证码收不到、登录后状态没保住，先看 [常见问题与故障排查.md](常见问题与故障排查.md) 里的对应小节，那里按「网络 → 方式替换 → 重装」的顺序给了排查步骤。
