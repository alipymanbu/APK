# 投屏到电视的设置与排查

> 讲用 BiliPai 把视频投到电视/盒子：投屏插件怎么开、找不到设备怎么排、投上之后画质和卡顿怎么处理。

## 一、先满足两个硬前提

1. **手机与电视/盒子连在同一个 WiFi**：DLNA 与 Google Cast 都靠局域网发现设备，不同网段（比如一个 2.4G 一个 5G 且路由器开了隔离）就搜不到；
2. **投屏插件已启用**：进设置的插件中心，把 **DLNA**（投局域网内的电视/盒子）和 **Google Cast**（投 Chromecast 类设备）按你家设备启用 —— 这两个都是内置插件，不用额外下载（插件中心在哪见 [插件系统使用说明.md](插件系统使用说明.md)）。

## 二、投屏操作

播放页调出控制菜单，找投屏入口，等它搜到设备后点选名称即可。连接成功后手机可以退出播放页干别的，投屏内容不中断；进度、清晰度仍在手机端控制。

## 三、搜不到设备，按这个顺序排

B 站官方投屏帮助列出的排查点，对走 DLNA 协议的客户端同样适用：

| 检查点 | 具体动作 |
| --- | --- |
| 同一网络 | 确认手机与电视连的是同一个 WiFi，电视端投屏/多屏互动开关已打开 |
| 设备支持 | 电视或盒子本身要支持 DLNA/Cast，不确定就问厂商客服 |
| 路由器设置 | 关闭 AP 隔离与访客模式，改完重启路由器 |
| 网络中继 | 用了信号放大器或运营商路由（CMCC/ChinaUnicom/ChinaNet）容易搜不到设备，尽量让两端直连主路由 |
| iOS 权限 | iPhone 用户到「设置 → 隐私 → 本地网络」确认对该应用的权限已打开 |
| 重启大法 | 重启应用与电视端投屏服务后再搜一次 |

都试过仍搜不到，备选方案是电视端装 B 站电视版（云视听小电视）用其自身投屏接收，或用手机系统的无线投屏（镜像画面，延迟更高）。

## 四、投上之后的画质与卡顿

- **清晰度**：投屏清晰度受片源、账号等级与接收端策略影响。华为官网帮助页提到的口径是：手机侧大会员投屏最高 4K、非大会员最高 1080P（截至该页所写，以实际表现为准）。
- **卡顿/音画不同步**：优先让手机与电视都连 5GHz 频段；官方帮助建议 50M 以上宽带；仍卡就先把清晰度降一档 —— 手机端的画质分 WiFi/流量两档设置，路径见 [播放设置与手势操作.md](播放设置与手势操作.md)。
- **老电视延迟高**：DLNA 是把地址交给电视端自己拉流，比手机镜像稳；如果你走的是系统镜像方案，换回 DLNA 通常能明显改善。

投屏失败且与网络无关的其他情况（闪退、登录掉线等），回到 [常见问题与故障排查.md](常见问题与故障排查.md) 的总表。
