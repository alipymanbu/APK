# ScratchJr 打不开与闪退排查

> 本篇针对 ScratchJr 在安卓平板上打不开、闪退、卡在启动画面的情况，给出按成本从低到高的排查顺序。

## 一、先分清是哪一种「打不开」

| 现象 | 多半属于 | 先做 |
| --- | --- | --- |
| 图标点了没反应 | 应用没装好或系统卡顿 | 重启平板再点 |
| 卡在启动画面不动 | 启动阶段出错 | 强制关闭后重开，不行再清缓存 |
| 打开后闪退回桌面 | 内存或存储不足 | 关掉后台应用，清出存储空间 |
| 装的时候就失败 | 系统版本或设备不兼容 | 见安装教程的排查表 |

## 二、按成本从低到高排（安卓通用做法）

1. **重启平板**——最便宜，先做。老平板开久了内存紧张，点开应用最容易卡；
2. **关后台应用**——让出内存再打开 ScratchJr；
3. **清理存储空间**——存储贴着上限跑就容易闪退；安装包本身只有 26.62 MB，但平板剩余空间建议至少留出几百兆；
4. **清应用缓存**——设置 → 应用 → ScratchJr → 存储 → 清除缓存。注意「清除数据」会把平板上保存的所有项目一起删掉，别急着点；
5. **更新应用**——早期版本出现过卡在启动画面的已知问题，官方后续版本修复过；用旧安装包装的，换新版再试；
6. **重装**——上面都无效再卸载重装。卸载会连项目一起删掉，重装前先把要留的项目通过邮件导出一份（步骤见 [项目保存与分享.md](项目保存与分享.md)）。

## 三、老平板的额外注意

- 系统低于 Android 5.0 是装不上，不是闪退——那是兼容问题，回到 [下载与安装教程.md](下载与安装教程.md) 核对设备要求；
- Android 5~7 的老平板往往能跑，但开样例项目、切页时慢半拍属于正常现象，别当成故障反复重启；
- 平板存储贴满时，先删旧照片、旧视频，比反复清应用缓存管用。

## 四、还是不行

把现象记下来（卡在哪一步、提示什么字），再对照 [常见问题解答.md](常见问题解答.md) 区分「应用故障」和「操作问题」——孩子说「打不开」时，很多时候其实是项目列表里找不到项目，或者打开的是另一页。
