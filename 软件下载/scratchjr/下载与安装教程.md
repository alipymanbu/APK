## 一、先看设备能不能装

ScratchJr 只按平板的尺寸设计，手机和电脑不在官方支持范围内。对照下面这张表再决定装不装：

| 设备 | 能不能装 | 说明 |
| --- | --- | --- |
| 安卓平板（7 英寸及以上，Android 5.0 或更高） | 能 | 官方建议用 7 英寸以上屏幕的设备 |
| 安卓手机 | 官方不支持 | 界面按平板布局设计，小屏上会挤 |
| Chromebook（可运行 Google Play 应用） | 能 | 装的就是安卓版 |
| Fire 平板（2014 年之后） | 能 | 从 Amazon 应用商店安装 |
| Windows / macOS 电脑 | 没有官方桌面版 | Windows 11 可通过系统内的 Amazon Appstore 安装，M1/M2 芯片的 MacBook 可装 iPad 版，但导出、导入项目这类功能会受限 |

官方对设备与系统要求的说明在 `https://www.scratchjr.org/`，以官方页面为准。

## 二、安装包从哪拿

夸克网盘里有一份 Android 安装包（APK），转存到自己网盘后就能下载到平板安装：

- 版本：1.5.11
- 包名：`org.scratchjr.android`
- 大小：26.62 MB
- MD5：`7F17BDF3FE0A7968999D2E204C9F2B30`

拿包入口：[ScratchJr 安装文件资源（夸克网盘）](https://pan.quark.cn/s/adcc058cb862)。

下载完可以先核对一下 MD5，和上面的一致就说明包是完整的（各平台核对方式不同，搜「你的系统 + 校验 MD5」即可）。应用商店里的版本号可能比这份新或旧，以你实际下载到的那份为准。

## 三、安装步骤（安卓平板）

1. 打开上面的网盘链接，把安装包**转存**到自己的夸克账号，再从网盘下载到平板本地存储；
2. 用平板自带的「文件管理」找到下载好的 APK 文件，点开它；
3. 系统提示「未知来源应用」或「是否允许安装」时选择允许（不同系统的入口不一样，有的在安装时弹窗授权，有的要先去「设置 → 安全」里打开开关）；
4. 等安装完成，点打开。

安装不需要注册账号，也不要求登录，打开就能直接用。

## 四、装完第一件事：切中文界面

ScratchJr 默认是英文界面。打开应用后，点左上角的**齿轮图标**，在弹出的语言列表里选「简体中文」或「繁體中文」，界面立刻切换，不用重启应用。

想开始拼第一个脚本，看 [界面与积木入门.md](界面与积木入门.md)，按里面的步骤就能拼出第一段会动的动画。

## 五、装不上时的排查

| 现象 | 多半是 | 怎么办 |
| --- | --- | --- |
| 提示「不兼容」或安装按钮灰色 | 系统版本低于 Android 5.0，或设备被识别为手机 | 换 Android 5.0+ 的平板；旧设备可尝试商店提供的最后兼容版本 |
| 安装到一半失败 | 存储空间不足 | 安装包本身 26.62 MB 不大，但建议平板至少留出几百兆空间 |
| 装好了但点开没反应 | 系统后台占用或安装残留 | 重启平板再试一次 |
| 「允许未知来源」找不到开关 | 厂商定制系统位置不同 | 在设置里搜「未知来源」或「安装未知应用」 |

装好之后遇到角色不动、声音录不进这类使用问题，去 [常见问题解答.md](常见问题解答.md) 对号入座；应用打不开或闪退，看 [打不开与闪退排查.md](打不开与闪退排查.md)；做好项目想传到别的平板，看 [项目保存与分享.md](项目保存与分享.md)。
