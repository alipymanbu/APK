## 一、官方网站上的免费材料

`https://www.scratchjr.org/` 的 Learn / Teach 区放着一整套免费材料（以官网当时显示为准）：

| 材料 | 干什么用 |
| --- | --- |
| 界面指南（PDF） | 逐个讲编辑器每个区域，适合大人先读一遍再教孩子 |
| 积木说明（PDF） | 六类积木逐块解释，可打印出来当对照表 |
| 绘画编辑器指南（PDF） | 改角色、自画角色的工具说明 |
| 提示与技巧（短视频） | 存项目、加角色、用触发积木等具体操作演示 |

这些 PDF 在官网直接下载，不用注册任何账号。

## 二、成体系的课程与活动

- **CAL（Coding as Another Language）**：ScratchJr 的官方课程，官网的介绍口径是把编程与儿童的表达、思考放在一起教（截至 2026-09 检索，材料在官网可查）；
- **The Official ScratchJr Book**：官方出的纸质书，按活动一步步带，需另行购买；
- **ScratchJr Coding Cards**：一套 75 张的活动卡片，一张卡一个小任务，适合给孩子抽卡挑战，需另行购买；
- **样例项目**：应用里自带 8 个，是零成本的第一批活动素材。

## 三、一台平板几个孩子共用

ScratchJr 没有账号体系，所有项目都堆在同一个列表里。两个孩子共用一台平板时：

- 约定**项目命名带名字**（如「小明-恐龙故事」），列表里一眼分清谁是谁；
- 教孩子点 Home 保存再换人，避免下一个孩子接着上一个的工程改；
- 想长期留底的项目，定期按 [项目保存与分享.md](项目保存与分享.md) 的办法导出到邮箱。

## 四、给孩子排活动的两个口径

- **先改后建**：头几次让孩子改样例项目（换角色、改数字），比从零开始容易出成果；
- **每次只引入一类新积木**：上一节用动作类，下一节再上触发类，攒到四类就能拼出完整的小故事。

动手步骤回看 [界面与积木入门.md](界面与积木入门.md)，改角色、录声音的方法见 [角色绘制与声音录制.md](角色绘制与声音录制.md)。
