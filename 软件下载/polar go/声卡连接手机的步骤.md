# Polar Go 声卡连接手机的步骤

> 本篇讲怎么把 Polar Go 声卡接到安卓手机上并用 App 认出它：双 USB-C 口怎么分、OTG 权限在哪放行、耳机和电容麦怎么接。

## 一、连接前的准备

| 要准备的 | 说明 |
| --- | --- |
| 数据线 | 盒内附带一根 USB-C 转 USB-C 线；iPhone（Lightning 口机型）需另购可传数据的转换器，盒内没有 |
| 支持 OTG 的手机 | Android 9.0 以上且 USB-C 口支持 OTG，这是官方的最低要求 |
| 电量或供电 | 声卡内置电池，也可以插着电源边充边用，见本文第四节 |

先确认声卡的电源开关能拨动、LED 有反应，再开始连线。

## 二、连接的五个步骤

1. **开机**：把声卡上的电源开关拨到开。电池供电或 USB 供电都能开机；
2. **分清两个口**：声卡上有两个 USB-C 口，插手机的是标着 **USB** 的那个（音频和数据都走它），标着 **POWER** 的那个只管充电；
3. **连线**：用数据线把 USB 口与手机连起来；
4. **放行 OTG**：手机弹出「是否允许访问 USB 设备」之类的提示时点允许——这是安卓对 OTG 外设的常规询问，允许一次后一般不再问；
5. **打开 App 确认**：打开 Polar Go App，能读到声卡、界面上出现可调的通道参数，就是连上了。

连上后先别急着录音，把增益和预设调好再开工，见 [调音与预设怎么用.md](调音与预设怎么用.md)。

## 三、耳机与耳麦怎么接

- 声卡上 3.5mm 输出口是 **TRRS** 规格，普通耳机和带麦克风的耳机都能插；
- 耳机音量由声卡上的 **OUTPUT 旋钮**控制，跟手机音量是两回事——耳机里没声音先拧它；
- 带麦耳机的麦克风走耳机这根线进声卡，不用另接设备；
- 注意：**INPUT 旋钮只调 XLR/6.35mm 输入口的增益**，内置立体声麦克风的增益不受它影响，要在 App 里调。

## 四、边录边充电的接法

内置电池官方标称可用数小时（不同页面标 4~6 小时不一，以官方页面为准），短内容一条电池就够了。要录一整场直播，就用第二根线：

- **USB 口** → 手机（音频数据）；
- **POWER 口** → 充电宝或充电头（供电）。

两个口同时插着不会冲突，这也是它设计双口的目的。充电口不通数据，别把两个口接反。

## 五、什么时候开 48V

+48V 幻象电开关只服务电容麦克风：把电容麦接到 XLR/6.35mm 组合输入口后，按下 48V 开关它才有声音。动圈麦、吉他、贝斯这些**不需要也不必开**。用完先关 48V 再拔麦克风线，这是说明书给的操作顺序。

## 六、连上之后

设备识别正常后，下一步是调声音：各通道的增益、混响、五档预设都在 App 里调，见 [调音与预设怎么用.md](调音与预设怎么用.md)；要直接开播或录视频，看 [直播内录与视频录制.md](直播内录与视频录制.md)。卡在某一步就查 [常见问题与故障排查.md](常见问题与故障排查.md)。
