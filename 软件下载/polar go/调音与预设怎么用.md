## 一、App 的三个标签页

打开 App 后底部（或侧边）是三个标签：**Home**（调音主界面）、**Camera**（录视频）、**Settings**（设置）。日常调音只在 Home 页进行，所有参数改动实时生效，边调边对着耳机听就行。录像页的用法单独写在 [直播内录与视频录制.md](直播内录与视频录制.md)。

## 二、两路通道分别怎么调

Home 页上有两路可以调的通道，参数不完全一样：

| 通道 | 对应声源 | 可调的参数 |
| --- | --- | --- |
| 输入通道（INPUT） | 从 XLR/6.35mm 组合口接进来的麦克风、吉他、贝斯、键盘 | Gain（增益）、Space（混响）、内置效果 |
| 麦克风通道（MIC） | 声卡内置的立体声麦克风、带麦耳机的麦克风 | Gain（增益）、Body / Clarity（EQ）、Space（混响）、Magic Wand（一键调音） |

两条实用经验：

- 增益宁可先低再加。手机喇叭上听不出来，戴耳机看 App 里的电平，接近顶但不爆红灯的位置合适；
- 内置麦克风那一路**不受声卡机身上 INPUT 旋钮控制**，增益只能在 App 里调，找不到旋钮不要去拧机身。

## 三、五档预设怎么选

App 内置五档预设，官方给的名字与适用场景如下：

| 预设 | 适合的场景 |
| --- | --- |
| Vocal | 人声演唱、口播 |
| Guitar | 木吉他、电吉他录进声卡的场合 |
| Podcast | 播客对谈、纯说话类内容 |
| Ambient | 环境声、氛围类的收录 |
| Flat | 不做修饰，全靠自己后期调 |

选好预设后再微调增益与混响，调到满意后可以保存成自己的参数组合。官方商店页还提到一点预设的内部逻辑：每一档预设会联动调整 Magic Wand 与灵敏度等参数，适配的语境包括原声吉他、人声与口播、鼓、ASMR 与特殊音源。每档具体改了哪些参数值，官方没有公布明细，以实际听感为准。

## 四、Magic Wand 一键调音

麦克风通道里有个 **Magic Wand** 开关，官方的说法是「像一个随队调音师」——按当前预设自动把多个参数调到合适位置。不想手动琢磨 EQ 和增益时，先开 Magic Wand 听一遍效果，再手动补少量调整，比从零开始快。

## 五、混响（Space）怎么加

任意一路输入都能加 Space 混响，官方对它的定位是自然的空间感与立体声宽度，不是那种夸张的卡拉 OK 混响。口播和演唱各给少量即可，录乐器想让声音干净就归零，后期再在剪辑软件里加。

## 六、调完一定按 Save

这是说明书专门强调的一条：**改完参数要按 Save 按钮**，当前的增益、混响、预设组合才会写入声卡硬件。写入之后，下次单独给声卡开机（不连手机）也会按这套参数工作。不按 Save 直接关机或断开，改动就丢了，下次又回到旧参数。

## 七、调完之后

声音调好了，接下来要么录视频、要么直接开播，路径见 [直播内录与视频录制.md](直播内录与视频录制.md)；遇到参数不生效、通道读不到的情况，先去 [常见问题与故障排查.md](常见问题与故障排查.md) 对一遍检查项。
