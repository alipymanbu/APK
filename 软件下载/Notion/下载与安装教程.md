## 一、两条获取路径

Notion 是 Notion Labs, Inc. 出的笔记、文档与任务管理应用，安卓、iOS、桌面、网页都有客户端。你在手机上装它，通常走这两条路：

| 路径 | 怎么拿 | 特点 |
| --- | --- | --- |
| 网盘转存 | 打开 [Notion 安装文件资源（夸克网盘）](https://pan.quark.cn/s/298a50a299e9)，转存后把 APK 下载到手机安装 | 拿到的是固定某一版（信息见第二节），不会自动更新 |
| Google Play 商店 | 商店搜 Notion，认准开发者 **Notion Labs, Inc.**（[商店页面](https://play.google.com/store/apps/details?id=notion.id)） | 自动更新；你的设备如果访问不了 Google Play，就走网盘这条线 |

官方总入口是 [notion.com](https://www.notion.com)，桌面版、网页版、移动版的下载链接都在上面；遇到账号问题也可以从这里进[Notion 帮助中心](https://www.notion.com/zh-cn/help)。

## 二、安装前核对安装包信息

网盘里这份安装包的事实如下，下载后可逐项核对（以网盘文件实际内容为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 3.1.300 |
| 大小 | 100.06 MB |
| 包名 | `com.qingdou.android` |
| MD5 | `9A50A6031ED6676CFF15FD3242D1E8EB` |
| 信息记录日期 | 2026-09-23 |

文件名是 `Notion_v3.1.300.apk`。有两点差异需要你知道：

- **包名与官方版不一致**：Google Play 官方版的包名是 `notion.id`，这份记录写的是 `com.qingdou.android`，两边对不上。你没法只靠文档判断哪边为准，最可靠的办法是拿到文件后自己核对 —— 安装前用任意「查看 APK 包名」的工具打开文件看一眼，安装后对照官方商店截图确认界面确实是 Notion。
- **包名不同不会覆盖安装**：安卓按包名区分应用，`com.qingdou.android` 与 `notion.id` 会作为两个应用并存，不会互相覆盖或顶掉。装完发现桌面上有两个，认准界面与官方截图一致的那个用。

版本号、大小这类信息会随发布变化：网盘这份固定在 3.1.300，商店里官方版会持续更新，两边的版本号不要互相套用。

## 三、系统要求

官方帮助中心（[系统要求页](https://www.notion.com/zh-cn/help/system-requirements-for-notion)，截至 2026-09）给出的门槛：

| 平台 | 要求 |
| --- | --- |
| 安卓 | Android 8 及以上 |
| iOS | iOS 17.0 及以上 |
| Windows | Windows 10 21H2 及以上 |
| macOS | macOS 12 及以上 |
| 网页版 | Chrome 最近 8 个主要版本；Firefox / Safari / Edge 最近 2 个主要版本 |

网盘这份安装包的记录里标注「安卓 5.2 以上」，与官方的 Android 8 不一致 —— 两处口径并列给你：设备低于 Android 8，官方版跑不起来；这份包在低版本设备上能不能运行，以你实际安装、启动的结果为准。

## 四、安装步骤

1. 按第一节的路径把 APK 下载到手机（文件大小应约 100 MB，明显偏小说明没下完整，回去重下）。
2. 用文件管理器点这个 APK 安装。手机若弹出「禁止安装未知应用」，去「设置」里给对应的浏览器或文件管理器开启「安装未知应用」权限，再装一次。
3. 装完打开应用，进登录/注册界面（见下一节）。
4. 如果装完的界面与 Notion 官方商店截图完全不符，回头核对第二节的包名 —— 文件与描述不符就不要继续用它。

## 五、注册与登录

没有账号就先在应用里注册一个。Notion 支持的登录方式（官方[登录帮助](https://www.notion.com/zh-cn/help/log-in-and-out)）：

- 邮箱 + 发到邮箱的验证码；
- 邮箱 + 密码；
- `Google 登录`：要求 Notion 账号邮箱与 Google 邮箱相同，开了两步验证的要第二台设备确认；
- `Apple 登录`：要求与 Apple ID 邮箱相同，支持面容 ID / 触控 ID；首次使用时若选「隐藏我的电子邮件」，会生成一个全新账号，**这种方式无法再关联到已有的 Notion 账号**；
- `Microsoft 登录`：要求与 Outlook / Office 邮箱相同；
- 密钥（passkey）：密码的替代方案，存在账号设置里；
- SAML SSO：商业版或企业版、且工作空间所有者开启了才可用。

从新设备登录时你可能收到一封「新登录提醒」邮件：是你自己就忽略；不是你，就在邮件里点「不是我」，那次登录会被立刻登出，页面会带你去改密码或开启多因素验证的地方。
