## 一、触屏手势对照表

会话内使用「鼠标」或「触摸板」输入模式时，官方定义的手势如下：

| 手势 | 作用 |
| --- | --- |
| 单指滑动 | 移动光标 |
| 双指捏合 | 放大 / 缩小画面 |
| 三指滑动 | 滚动屏幕 |
| 单指点按 | 左键单击 |
| 长按 | 右键 |
| 三指点按 | 鼠标中键 |

先把这套手势练熟，手机上操作电脑桌面基本就不卡手了：看大画面用双指缩放，滚长页面用三指滑，右键菜单靠长按。

## 二、会话菜单：长按徽标唤出

会话进行中，**长按屏幕上的 AnyDesk 徽标**打开会话菜单；**双击徽标**后可以把它拖到屏幕任意位置，别挡住要操作的区域。

菜单里能做的事（官方口径）：

- 结束会话；
- 调整传输画质；
- 切换输入控制、剪贴板同步、隐私屏幕的开关；
- 管理音频与显示设置；
- 启动或停止 VPN、会话录制；
- 向被控的 Windows 电脑发送 Ctrl+Alt+Del、请求提权；
- 被连设备有多个显示器时切换显示器；安卓端可开关全屏。

画质、剪贴板这些开关正好对应两类常见问题：卡顿先降画质；剪贴板不同步先来这里确认开关，传输相关的完整方法见[文件传输方法.md](文件传输方法.md)。

## 三、用 Windows 键盘按安卓导航键

从 Windows 电脑控制安卓设备时，AnyDesk 提供键盘快捷键触发安卓的导航动作：按住 **Ctrl+Alt+Shift** 再按对应按键，可以触发主页、返回这类系统级操作。具体键位对照以官方文档为准。

## 四、卡顿或掉线了怎么办

操作层面能做的是：会话菜单里降画质、关掉用不到的开关；如果是连接本身不稳，按[连接失败与黑屏排查.md](连接失败与黑屏排查.md)排查；手机端被控时掉线多半是电池优化杀后台，见[被控掉线与后台保活设置.md](被控掉线与后台保活设置.md)。
