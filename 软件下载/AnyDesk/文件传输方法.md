# AnyDesk 手机与电脑互传文件的方法

> 连着会话就能在手机和电脑之间传文件：手机怎么把文件推给电脑、电脑怎么把文件给手机、剪贴板怎么同步，本篇按官方文档的操作路径讲。

## 一、手机传文件到电脑

会话进行中，按这个路径操作（官方文档口径）：

1. 打开会话菜单，进 **Actions（操作）**，选 **Transfer a file to the remote device**（向远程设备传输文件）；
2. 在手机上选中要传的文件；
3. 切到电脑端，打开资源管理器，进入你想存放文件的文件夹；
4. 在文件夹空白处右键，选「粘贴」，文件就落在电脑上了。

## 二、电脑传文件到手机

反方向走剪贴板加会话菜单的组合：

1. 在电脑上选中文件，用右键菜单或快捷键复制；
2. 回到手机的会话界面，通过会话菜单里的传输动作接收文件。

两边剪贴板是同步的，短文本最省事：电脑上复制一段文字，手机端会话里直接粘贴即可；文件类的传输入口以你会话菜单里实际显示的选项为准（不同版本菜单位置略有差异）。

## 三、不想被同步剪贴板怎么办

剪贴板同步是双向的，如果你在电脑端不想让连接方读取剪贴板：

- 在被控电脑的 **设置 > 安全 > 权限**（按权限配置文件管理）里，关闭「访问剪贴板」与「通过剪贴板传输文件」两项；
- 前者把文本与文件的剪贴板同步全关，后者只关文件传输；
- 也可以在每次连接的接受窗口里临时开关。

## 四、没装控制插件也能传文件

一个容易被误解的点：传文件**不依赖控制插件**。官方说明，即使设备因为没装插件而不能被完整远程控制，文件传输在所有安卓版本上都可用。也就是说，一台只是「能投屏」的手机，照样可以和电脑互传文件。

另外，桌面平台（Windows、macOS、Linux）之间有独立的文件管理器会话，手机端没有这个独立入口，传文件都走会话菜单。

## 五、传不动时先查这两处

- 手机端选不到文件：多半是 AnyDesk 没拿到存储权限，去系统应用权限里补上；
- 传到一半失败：会话断开传输就会中断，先按[连接失败与黑屏排查.md](连接失败与黑屏排查.md)把会话稳定下来再传，大文件建议两端都待在网络好的环境。
