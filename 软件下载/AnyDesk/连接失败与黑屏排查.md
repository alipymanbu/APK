# AnyDesk 连接失败与黑屏排查

> 连不上、连上黑屏、会话中途断开——先把现象对上号，再按对应方向处理。本篇混用官方排障文档与社区常见做法，官方口径都标了出处。

## 一、先分清三种现象

| 现象 | 大概率方向 |
| --- | --- |
| 发起连接没反应 / 一直失败 | ID 输错、对方不在线、防火墙拦截、网络问题 |
| 连上了但黑屏 / 停在「等待画面」 | 被控端屏幕授权没给、显示驱动或显示器问题 |
| 用着用着断开 | 安全软件拦截、网络波动、电池优化杀后台、电视端辅助功能被关 |

## 二、连不上

按顺序核对：

1. **核对 ID 与在线状态**：ID 是 9~10 位数字，逐位核对别把 0 看成 O；确认对方设备开着、AnyDesk 在运行；
2. **网络两头都查**：任一端断网或信号差都连不上；
3. **看错误码**：官方把 `anynet_unknown`、`win32_10054`、`win32_10060`、`win32_10061` 这类错误归因为外部因素中断——对方设备断电断网、防火墙或杀毒软件结束会话、路由器/代理/VPN 拦截。

官方给出的处理步骤：

- 两端防火墙都放行 AnyDesk；杀毒软件把 AnyDesk 加入信任或例外列表；
- 在客户端 **设置 > 连接 > 通用** 里，取消勾选「允许直接连接（Allow direct connections）」；
- 还不行，发起连接时在 ID 或别名后面加 `/np`，例如 `000111222/np`；
- 如果断开总是发生在固定间隔（比如每 30 秒或每 10 分钟一次），基本可以断定是安全软件在拦——去它的拦截日志里找记录，把 AnyDesk 设为信任。

## 三、连上但黑屏或「等待画面」

分两端处理：

**电脑被控时黑屏：**

- 先看显示器：确认被控电脑接了显示器且处于唤醒状态；没有显示器的主机（无头主机），社区常见做法是接一个 HDMI 虚拟头；
- 社区常见经验：显卡驱动过旧也会出不来画面，更新驱动后重连；会话画质选「平衡」、把分辨率调低、关闭硬件加速后重试。这些属于用户社区总结的解法，非官方口径，逐条试。

**手机被控时黑屏：**

- 系统投屏弹窗必须在手机上当场确认，没点「允许」画面就不会传输——即使配置了无人值守访问也一样（官方说明，见[被控端权限与控制插件.md](被控端权限与控制插件.md)）；
- 两端 AnyDesk 版本差距过大时可能出现兼容问题，把两端都更新到官方当前版本再试（版本以官方页面为准）。

## 四、安卓设备特有的三种断连

1. **电视设备（Android TV / Fire TV）**：辅助功能设置被禁用时，控制插件无法激活，正在进行的远程控制会话会意外中断。先到电视系统设置里把辅助功能开回来；
2. **投屏授权没人确认**：被控端弹出的投屏提示需要有人在设备旁点掉，没人点会话就立不起来或维持不下去；
3. **电池优化杀后台**：官方说明，系统的电池优化为省电会在应用退到后台 30~60 秒后自动关闭它，正在进行的会话随之中断——把 AnyDesk 和控制插件都移出电池优化，逐品牌步骤见[被控掉线与后台保活设置.md](被控掉线与后台保活设置.md)。

## 五、都试过还不行

- 到官方支持站 `https://support.anydesk.com` 查对应报错的文章，官方文档按错误码逐条给出了原因与修法；
- 两端把 AnyDesk 更新或重装到最新版再连一次；手机端的安装途径见[下载与安装教程.md](下载与安装教程.md)。
