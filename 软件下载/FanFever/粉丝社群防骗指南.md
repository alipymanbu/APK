## 为什么追星场景容易被盯上

求票心切、想离偶像更近一步、怕错过活动——这些情绪正是骗子的切入点。各地反诈中心 2026 年仍在反复通报：骗子长期蹲守在粉丝群、短视频私信、社交平台这些地方，而追星社区天然就是它们聚集的场所。

## 常见诱饵与对应套路

以下四类都出自警方拆解过的真实案例，出现时先打问号：

| 诱饵说法 | 实际套路 |
| --- | --- |
| 「内部票 / 低价转票 / 代抢门票」 | 诱导脱离平台私下转账，收款后编造「未备注、订单冻结」等理由，再冒充客服骗你多次转账「刷流水」 |
| 「官方投票只在专属群开展，跟我进群」 | 把你从公开平台引到私密群，群里冒充「警官」声称要核查，恐吓 + 骗开屏幕共享 |
| 「免费领签名照」「我是明星助理」 | 取得信任后用「未成年人操作导致账号冻结要赔偿」等话术恐吓，诱导用家长手机转账 |
| 「我是官方客服，帮你办理退款」 | 让你加所谓的官方客服私人账号，以流水不足、解冻账户为由连环要钱 |

## 四条判断底线

来自反诈民警的公开提示，原样适用：

1. **凡是付款后要求再转账才能退款、出票的，都是诈骗**——正规平台不存在「刷流水解冻」这种操作；
2. **不脱离平台交易**——买票走官方票务平台，App 内能完成的事不要加微信、支付宝私下转账；
3. **公安不会通过网络办案**——亮「警官证」照片、视频通话要求配合调查的，直接挂断；
4. **凡是要求屏幕共享的，一律拒绝**——共享屏幕等于把验证码和银行信息摊开给对方看。

## 在 FanFever 里具体注意什么

- **认准官方身份**：社区里按明星划分的频道多为粉丝搭建，艺人本人和工作室未必入驻。自称「明星本人 / 工作室 / 助理」来私信的，先默认是假的；艺人官方入驻了哪些平台，以艺人自己公布的官方账号清单为准；
- **进群不交钱**：加入频道与群组不需要先付费。凡说「进内部群要先转账 / 买资格」的，直接举报；
- **投票不走站外**：平台投票在 App 内的活动页进行，不需要去外部群，更不需要向个人转账买票数（投票玩法见 [行程资讯与投票应援玩法.md](行程资讯与投票应援玩法.md)）；
- **交易留在平台内**：与其他粉丝交换内容或物品时，脱离 App 的私下转账没有任何保障；
- **涉及未成年人**：家长管好支付密码、关闭免密支付；孩子遇到恐吓信息（「账号冻结要赔偿」「不发律师函」）第一时间告诉家长，不要自己按对方指引操作。

## 已经被骗了怎么办

立即停止转账，保存聊天记录、转账凭证、对方账号信息，拨打 110 报警，并向平台举报对方账号。拦阻资金的黄金时间在最初几小时，越早报警越有希望。装不上、登不进这类技术问题则看 [常见问题排查.md](常见问题排查.md)，别把两类问题混在一起。
