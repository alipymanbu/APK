# PakePlus 手机上把网页打包成 APK 的完整步骤

> 本篇讲装好 PakePlus 安卓客户端之后，怎么在手机上从零把一个网址或一个本地网页文件夹打成能安装的 APK。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [GitHubToken获取与配置教程.md](GitHubToken获取与配置教程.md) · [常见问题与报错排查.md](常见问题与报错排查.md)

---

> [!IMPORTANT]
> **PakePlus 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/4db1190dc6e1](https://pan.quark.cn/s/4db1190dc6e1)

## 一、动手前的三件事

1. 手机上已经装好客户端。还没有的话，从 **PakePlus 安装文件资源（夸克网盘）** 获取即可，安装步骤见 [下载与安装教程.md](下载与安装教程.md)。
2. 想清楚要打包什么：一个网址，或者一个已经做好的网页项目文件夹（里面必须有 `index.html`）。
3. 打包方式二选一：本地打包不用任何账号；云端打包需要 GitHub 账号（授权登录或填 Token，见 [GitHubToken获取与配置教程.md](GitHubToken获取与配置教程.md)）。

## 二、新建项目

1. 打开客户端，点 `+` 按钮新建项目。
2. 填项目名称。名称有三条硬规矩：不能以数字开头；不能和已有项目重名；只能包含字母、数字、下划线、短横线，不能有空格、中文和特殊字符。
3. 确定后等待项目创建完成，会自动跳到配置页面。

## 三、填好四项必填配置

| 配置项 | 要求与注意点 |
| --- | --- |
| APP 名称 | 支持中文和英文，**不能带空格**，这是装到手机后显示的名字 |
| 网站地址 | 填 `http` 或 `https` 开头的网址；也可以选本地 html 文件，或 Vue/React 编译后的 dist 文件夹 |
| APP 标识（APP ID） | 只允许小写字母、数字、下划线；段不能以数字开头；不能有连续点、首尾点；不能与其他项目重复 |
| 版本号 | 你自己定义，用来区分这个 APP 的不同版本 |

其中 APP ID 最容易填错：它相当于这个 APP 在系统里的身份证，填得不合规会直接打不出来，报错时先回来检查这一项。

## 四、可选项按需配

不配也能打包，需要时再回来看：

- **APP 图标**：可以上传本地图片，不填就用默认图标。
- **窗口模式**：桌面、iPhone、iPad、Android 外观或自定义，决定打出来的 APP 窗口长什么样。
- **过滤元素**：填 CSS 选择器，可以把页面里不想看到的元素（比如广告位）从窗口里滤掉。
- **脚本文件**：支持注入自定义 JS，官方标注「不懂代码不要动」，新手直接跳过。
- **开发调试**：打开后可以在预览窗口里调试页面，排查显示问题时有用。

## 五、预览、发布、拿包

1. 点**预览**，先看这个 APP 最终显示出来是什么样子，不满意回头改配置。
2. 确认无误后点**保存**，开始编译，等它跑完。
3. 发布时选目标平台：只需要安卓就单选安卓；要给 iPhone 用就连 iOS（免签）一起选，一次同时出 APK 和 IPA。
4. 编译完成会自动进到发布页面，点 **APK** 下载安卓版；iOS 也可以扫页面上的二维码直接装，或者点名称复制下载链接，到浏览器里打开下载。
5. 如果编译失败，右上角会显示错误提示，按提示改配置重新来；常见报错对着 [常见问题与报错排查.md](常见问题与报错排查.md) 查。

## 六、把打好的 APK 装进手机

下载下来的 APK 和普通应用一样安装：点开 → 允许未知来源 → 装完打开。注意这一步装的是**你刚打包出来的那个 APP**，和第一步装的 PakePlus 客户端是两个东西，别弄混。

要给 iPhone 用就下 IPA。iOS 产物走免签方式，通过安装描述文件装进手机——装完还要信任开发者才能打开，完整步骤见 [IPA装不上或打开闪退怎么办.md](IPA装不上或打开闪退怎么办.md)；安卓产物要求 Android 7.0 及以上、iOS 产物要求 iOS 15.6 及以上（以官方文档说明为准）。

## 七、打本地网页文件夹的额外注意点

- 文件夹根目录必须有 `index.html`，没有就打不出来。
- 走云端打包时，文件夹里**单个文件别超过 10M**（受 GitHub 限制），视频、大图这类资源改成外部链接引用，或先压缩再放进去。
- 本地打包没有这个大小限制，大文件项目优先走本地，两种方式的取舍见 [本地打包和云端打包的区别.md](本地打包和云端打包的区别.md)。
