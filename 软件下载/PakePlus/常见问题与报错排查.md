## 一、编译失败，发布页报错

1. 先看右上角的错误提示，它一般会直接指出哪一项配置有问题。
2. 按下面顺序排查最常见的三个原因：
   - 网址填错或原网站本身打不开：先在浏览器里开一遍确认能访问，且以 `http` 或 `https` 开头。
   - APP 标识（APP ID）不合规：对照本篇第二节的规则重查一遍。
   - 打本地文件夹时缺 `index.html`，或云端打包时单个文件超过 10M。
3. 改完配置重新发布即可，不需要重建项目。

## 二、项目名称或 APP ID 填不进去

两套命名规则容易混，分开记：

| 项目 | 规则 |
| --- | --- |
| 项目名称 | 字母、数字、下划线、短横线；不能以数字开头；不能与已有项目重名；不能有空格、中文、特殊字符 |
| APP 标识（APP ID） | 只允许小写字母、数字、下划线；段不能以数字开头；无连续点、首尾点；不能与其他项目重复 |

APP 名称（显示名）倒是宽松，中英文都行，只有一条：不能带空格。

## 三、Token 测试一直转圈或提示不可用

- 核对粘贴的 Token 是否完整：GitHub 的 Token 只在生成时显示一次，复制不全或已过期都会这样。
- classic Token 检查是否勾齐 `repo`、`workflow`、`user` 三个权限；细粒度 Token 对照权限清单查。
- 网络不通也会导致转圈，正常耗时是二十秒左右，可以换个网络环境重试。
- 还不行就重新生成一个再测。完整步骤见 [GitHubToken获取与配置教程.md](GitHubToken获取与配置教程.md)。

## 四、打出来的 APP 装不上

- **安卓**：打包产物要求 Android 7.0 及以上（以官方文档说明为准），系统版本低了装不上属于门槛问题，不是包坏了。安装时同样要允许「未知来源应用」。
- **iOS**：走免签方式，通过安装描述文件装入，要求 iOS 15.6 及以上；装完点开闪退或提示未受信任，是还没信任开发者，完整处理见 [IPA装不上或打开闪退怎么办.md](IPA装不上或打开闪退怎么办.md)。
- 下载中断导致包不完整也会装不上，回发布页重新下载一遍。

## 五、打出来的 APP 打开是空白或报错

打出来的 APP 是原网页的独立窗口，原网站的状态直接决定它的状态：

- 原网站打不开、改版、强制登录，APP 里表现一样。
- 登录按钮点了没反应、白屏（尤其是 Google 授权登录），多半是服务方拒绝在独立窗口里授权，区分与替代方案见 [打出来的APP登录不上怎么办.md](打出来的APP登录不上怎么办.md)。
- 页面显示不对时，打开项目的开发调试模式进预览窗口排查，或检查过滤元素里是不是把正常内容一起滤掉了。

## 六、网页版和客户端用哪个

官方提供了浏览器里直接用的网页版（`https://pakeplus.netlify.app/`），但官方自己标注它还不是稳定版本，并推荐用客户端。手机上就用安卓客户端即可。

## 七、桌面版和这份安卓客户端是什么关系

两套独立安装包：安卓客户端装在手机上，桌面版从官方发布页 `https://github.com/Sjj1024/PakePlus/releases` 下载，版本号各自独立，桌面版还支持 Windows 7 以上系统和绿色免安装版本（以官方页面为准）。配置和打包流程两边一致，Token 各配各的。

## 八、退出登录前要知道的事

退出登录会删除并清空本地所有记录，包括 Token 和全部项目数据。只是想换账号的话，先确认项目数据里有没有要留的备份。
