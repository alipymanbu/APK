## 一、两条路线分别是什么

- **云端打包**：项目文件放到你自己的 GitHub 仓库，编译由 GitHub 完成，客户端负责提交和取结果。需要 GitHub 账号和 Token。
- **本地打包**：整个打包过程在客户端本机完成，官方给出的耗时是三十秒上下。不需要任何账号和 Token。

两条路线都要先装好客户端。还没有的话，从 **PakePlus 安装文件资源（夸克网盘）** 获取，安装步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 二、逐项对照

| 对比项 | 云端打包 | 本地打包 |
| --- | --- | --- |
| GitHub 账号/Token | 需要 | 不需要 |
| 打包耗时 | 几分钟（含排队） | 官方标注约 30 秒 |
| 文件大小限制 | 单个文件建议不超过 10M（受 GitHub 限制） | 不限制文件数量和大小 |
| 多平台安装包 | 支持，一键同时编译 | 以客户端当时提供的选项为准 |
| 失败后的信息 | 发布页和右上角看错误提示 | 客户端内看提示 |
| 前置准备 | 配 Token（一次） | 无 |

## 三、按场景选

- **手机上现打现用、没配过 GitHub**：走本地，省掉整个 Token 环节。
- **想同时出安卓、iOS、桌面多份安装包**：走云端，它支持一键同时编译多平台。
- **项目里有超过 10M 的大文件**（本地视频、大图片）：云端会被 GitHub 的单文件限制卡住，走本地，或者把大文件改成外部链接。
- **想让产物挂在 GitHub 发布页、换设备也能下载**：走云端，产物在发布页随时取。

## 四、两条路线共同的边界

官方在文档里写明了几条使用边界，两条路线都适用：

- 这个工具只负责打包，**不支持软件签名**。
- 打包出来的软件**仅限自己使用**，请勿传播或用于商业用途，否则后果自负。
- iOS 产物走免签方式，通过描述文件安装；安卓产物要求 Android 7.0 及以上、iOS 产物要求 iOS 15.6 及以上（以官方文档说明为准）。

还有一点值得单独提醒：打出来的 APP 本质上是那个网页的独立窗口，**内容仍然要联网加载**，原网站打不开、改版或要求登录，APP 里也一样受影响。
