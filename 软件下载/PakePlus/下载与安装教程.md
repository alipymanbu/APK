## 一、这个安卓版是什么

PakePlus 是一个把网页变成独立应用的开源打包工具：输入一个网址（或一个本地网页文件夹），它帮你生成一个可以单独安装、单独打开的 APP。本篇说的是它的**安卓客户端**——装在手机上、在手机上完成配置和打包的那一份；Windows、macOS、Linux 桌面版是另外的安装包，见本篇第六节。

装上它之后，你在手机上就能走完「填网址 → 预览 → 打包 → 拿到 APK」整个流程，不需要电脑，也不需要在手机上装任何开发环境。

几点说明：

- 这份安装包标注的适配系统是安卓 5.2 以上；它打出来的 APP 另有系统门槛，见 [常见问题与报错排查.md](常见问题与报错排查.md)。
- 装完后可以在系统设置 → 应用管理里核对包名是不是 `com.xiaoshen.pakeplus.android`，确认装的是这一份。

## 三、从夸克网盘拿安装包

本篇开头的网盘提示块就是 **PakePlus 安装文件资源（夸克网盘）** 入口：打开链接 → 转存到自己网盘 → 把 APK 下载到手机。2.51M 的体积，几秒钟就能下完。

## 四、安装步骤

1. 在手机上点开下载好的 APK 文件。
2. 系统提示「不允许安装未知来源应用」时，按弹窗提示允许「来自此来源的应用」；不同品牌手机的入口名称略有差异，一般在安装弹窗里直接给开关。
3. 等安装完成，点打开。

安装本身不需要联网验证账号。装完能不能立刻开始打包，取决于你选哪种打包方式，见下一节。

## 五、第一次打开：先想好走哪条打包路线

打开后会看到项目列表和配置界面。打包分两条路线：

- **云端打包**：编译在 GitHub 上完成，需要先登录 GitHub 或填入 Token，支持一次出多平台安装包。怎么配见 [GitHubToken获取与配置教程.md](GitHubToken获取与配置教程.md)。
- **本地打包**：在手机上直接完成，不需要任何账号和 Token。两条路线的详细对比见 [本地打包和云端打包的区别.md](本地打包和云端打包的区别.md)。

路线选好之后，跟着 [手机上把网页打包成APK的步骤.md](手机上把网页打包成APK的步骤.md) 走就行。

## 六、桌面版去哪下

如果你想在电脑上打包，去官方发布页 `https://github.com/Sjj1024/PakePlus/releases` 下载对应系统的安装包，版本以页面当时显示为准。桌面版和安卓客户端是两套独立的安装包，版本号各自独立，不能互相替代。
