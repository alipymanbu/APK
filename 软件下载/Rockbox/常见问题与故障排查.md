## 一、一启动就闪退 / 打不开

按顺序试：

1. **再点一次图标重新启动**。Rockbox 在部分机型上偶发启动即退，社区讨论里常见这种现象，重开一次往往就进去了 —— 不是你装错了。
2. **确认系统版本达标**。安装页标注需要安卓 5.2 以上，系统太老会装不上或运行异常，见 [下载与安装教程.md](下载与安装教程.md) 第四节。
3. **确认包没损坏**。重新下载并核对大小 38.84M、MD5 `1A577B2C5A8C8B40879A8AE761500CC0`（网盘那份的记录值，新包以实际信息为准）。
4. **旧版本先卸载再装**。跨大版本覆盖安装出现异常时，卸载重装最省事 —— 设置会丢，但曲库文件都在手机里，重新扫描即可，见 [音乐导入与扫描教程.md](音乐导入与扫描教程.md) 第二节。

## 二、扫描不到音乐

三步定位，前两步最常见：

1. **权限**：系统设置 → 应用 → Rockbox → 权限，确认「文件和媒体」已允许。拒绝状态下扫描结果必然是空的。
2. **格式**：文件是否在支持清单里，扫不出来最多的就是格式不支持或扩展名与实际编码不符，对照 [支持的音频格式与CUE分轨.md](支持的音频格式与CUE分轨.md) 的表格。
3. **位置**：文件是否真在手机存储里（插 SD 卡、OTG 盘、其他目录的情况以你版本的扫描范围为准）；不确定就先用文件浏览直接点它，点得开说明文件没问题，是扫描范围的事。

## 三、播放中途自己停了

- 先**拖动进度条快进两次** —— 社区经验里这个动作能把卡住的播放状态带回来，属于成本最低的一步。
- 再查是否开了**睡眠定时器**：它到点会正常停止播放，开关位置见 [播放设置与书签睡眠定时.md](播放设置与书签睡眠定时.md) 第六节 —— 听歌入睡设了定时忘了关，是最容易误判成「自己停了」的一种。
- 还不行就暂停后重新点开同一首歌；反复出现在同一首文件上的话，优先怀疑该文件本身损坏。有声书场景顺手用书签记一下位置，重启后能直接跳回，见 [播放设置与书签睡眠定时.md](播放设置与书签睡眠定时.md) 第五节。

## 四、界面是「口口」乱码或一直英文

这是显示层的问题，不影响播放，按 [中文设置与主题切换.md](中文设置与主题切换.md) 处理：满屏方块走「默认字符编码 → 简体中文」那条路，纯英文界面直接在语言菜单里选中文。

**歌词不滚动、中文歌词是方块**是同一根因的另一个出口 —— 歌词文件的位置、命名与编码单独走 [歌词显示怎么设置.md](歌词显示怎么设置.md)。

## 五、声音不对：太小声、忽大忽小、低频发闷

| 现象 | 先查这里 |
| --- | --- |
| 整体太小声 | 手机系统音量是否调满；ReplayGain 是否把某些歌压低了，见 [均衡器与音效设置教程.md](均衡器与音效设置教程.md) 第三节 |
| 歌与歌之间音量忽大忽小 | 开 ReplayGain，专治这个 |
| 低频发闷 / 高频刺耳 | 均衡器是不是被预设改过，进均衡器菜单恢复默认再听 |
| 左右声道一边大一边小 | 平衡（Balance）滑块归零 |

## 六、版本与包名核对

网盘那份的包名是 `org.rockbox`、版本 `mickwv-v2andrio`（记录日期 2026-09-23）。装到手机后在系统设置 → 应用 → Rockbox → 应用信息里能看到包名，与 `org.rockbox` 对上就说明装的是这份。版本号会随打包时间变化，以你实际下载到的文件信息为准；安装包本身怎么核对见 [下载与安装教程.md](下载与安装教程.md) 第二节。
