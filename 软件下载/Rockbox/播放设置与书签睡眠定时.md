# Rockbox 播放设置与书签睡眠定时

> 本篇讲播放相关的几个实用开关：随机与重复、快进快退的步长、启动恢复进度，以及书签和睡眠定时怎么用。

## 一、这些设置都在「常规设置 → 播放」附近

入口：设置 → 常规设置（General Settings）→ 播放（Playback）；书签与睡眠定时的入口分散在播放界面的菜单里，下面逐个说。具体条目名以你手上这份的菜单为准，认英文关键词（Shuffle / Repeat / Resume / Bookmark / Sleep）更稳。

## 二、随机与重复

| 选项 | 作用 |
| --- | --- |
| 随机（Shuffle） | 关 = 按列表顺序；开 = 打乱顺序播 |
| 重复（Repeat） | 关 / 单曲循环 / 全部循环 三档，按需选 |

放在播放设置里调，也可以在播放界面的快捷菜单里切 —— 日常切歌序、切循环这两个动作最高频。

## 三、快进快退的步长

长听有声书、播客的人最需要这项：默认快进步长对长音频偏小，按一下进不了多少。播放设置里与「快进/快退」（FFwd/Rewind）相关的两项：

- **最小步长（Min Step）**：按一下前进/后退多少秒 —— 有声书建议调到 15~30 秒量级，具体数值看你习惯；
- **加速（Accel）**：长按时步长是否持续放大，开着长按可以一下跨好几分钟。

改完当场在播放界面长按验证：步长合不合适，按两下就知道。

## 四、启动接着上次播（Resume on Startup）

播放设置里的「启动恢复」（Resume on Startup）开着时，下次打开 Rockbox 会回到上一次的播放位置继续，不用重新翻文件找进度。听长内容（有声书、专辑连播）建议保持开启；只想每次从头开始就关掉。

## 五、书签：给有声书打点

书签记住的是「某首文件播到哪」，对有声书、长录音最有用：

1. **打书签**：播放中打开播放界面的菜单，选书签（Bookmark）相关项保存当前位置；
2. **回到书签**：主菜单或播放菜单里选最近书签（Recent Bookmark）即可跳回；
3. **停止自动记**：设置里有「停止时写书签」（Bookmark on Stop）一类开关，开着的话每次按停止都会自动存档，下次直接接着播。

注意两点规则（官方手册口径）：书签**按文件夹存放**（同一文件夹的文件书签存在一起），**同一首文件可以存多个**。删掉音频文件或改名，对应书签会跟着失效 —— 整理文件前先想清楚。

## 六、睡眠定时：听着睡不吵一夜

睡眠定时到点后自动停止播放，睡前听东西必备。入口两处：

- 播放界面的快捷菜单里通常有「睡眠定时」（Sleep Timer）选项，部分版本在正在播放界面就能直接调；
- 设置的播放相关菜单里也有同类条目。

设好时长（如 15 / 30 / 60 分钟，以实际列表为准）就不用管了。它与 [常见问题与故障排查.md](常见问题与故障排查.md) 第三节「播放中途自己停了」是同一件事的两面 —— 排查非预期停止时，先确认是不是定时开着忘了关。

## 七、播放异常时的顺序

改了播放类设置后出的问题（不按预期顺序走、进度恢复不对），先在播放设置里找「恢复默认」（Reset to defaults）逐组还原，再对照 [常见问题与故障排查.md](常见问题与故障排查.md) 定位。音效类设置的还原见 [均衡器与音效设置教程.md](均衡器与音效设置教程.md) 第二节。
