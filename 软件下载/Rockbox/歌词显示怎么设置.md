# Rockbox 歌词显示怎么设置

> 本篇讲怎么让 Rockbox 播歌时显示同步歌词：歌词文件放哪、叫什么名、支持哪些格式、不显示时查什么。

## 一、先把歌词文件备好

Rockbox **不联网抓歌词** —— 显示的是你自己放进手机的歌词文件（常见为 `.lrc` 格式，网上有大量歌词站可以下载）。它带一个歌词插件（官方手册里叫 Lrcplayer），播放时读同名歌词文件、按时间标签逐行滚动。

两个硬条件，缺一个都不显示：

1. **文件名与歌曲文件完全同名**（`歌曲.flac` 配 `歌曲.lrc`，只改后缀）；
2. **放在正确位置**，见下一节。

## 二、歌词文件放哪

按优先级，插件会在这些地方找歌词：

| 位置 | 说明 |
| --- | --- |
| 歌曲所在的目录 | 与音频文件同目录，最省事的放法 |
| 歌曲目录下的 `Lyrics`（或 `lyric`）子目录 | 中文社区常见的放法，与官方手册的 `Lyrics` 子目录规则一致 |
| 集中的 `/Lyrics` 目录 | 所有歌词统一放一个文件夹，靠同名匹配 |

放完进歌词插件刷新即可。整张专辑的歌多时，建议建一个 `Lyrics` 子目录把该专辑的歌词全放进去，目录不会被歌曲列表弄乱。

## 三、支持哪些歌词格式

| 格式 | 说明 |
| --- | --- |
| `.lrc` | 最常见，逐行时间标签歌词 |
| `.lrc8` | 与 `.lrc` 相同，但用 UTF-8 编码 —— 中文歌词优先用这种，能绕开编码问题 |
| `.snc` / `.txt` | 简单时间轴格式，部分歌词站提供 |
| 内嵌标签 | MP3 文件内嵌的 SYLT / USLT 歌词标签，不用外挂文件 |

`.lrc` 里的时间标签要写成 `[mm:ss]`、`[mm:ss.xx]` 或 `[mm:ss.xxx]` 这三种形式之一（分:秒，可带小数毫秒）；`[ti:标题]`、`[ar:歌手]`、`[offset:偏移毫秒]` 这几个头部标签也认。**没有时间标签的行会被直接忽略** —— 这是「歌词有了却不滚」的常见原因。

## 四、中文歌词显示成乱码

歌词是中文、显示出来是方块或乱码，走两步（与界面乱码同一个根因）：

1. 设置 → 常规设置 → 显示 → 默认字符编码，选 `Simp.Chinese (GB2312)`；
2. 换用 UTF-8 编码的歌词文件（`.lrc8`），或把 `.lrc` 另存为 UTF-8。

详见 [中文设置与主题切换.md](中文设置与主题切换.md) 第三节。

## 五、不显示时按这张表查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 完全没有歌词界面 | 没打开歌词插件 | 在插件（Plugins）菜单里找到歌词插件再进一次 |
| 插件开了但空白 | 文件名与歌曲不同名，或位置不对 | 对照第二节的三个位置，逐个试 |
| 歌词显示但不跟唱滚动 | 时间标签格式不认，或整份没有时间标签 | 换一份标准 `.lrc`；核对标签是否为 `[mm:ss]` 系列 |
| 中文全是方块 | 编码没对上 | 走第四节两步 |
| 只有第一行对 | 时间轴偏移 | 用歌词里的 `[offset:毫秒]` 标签整体平移，或换歌词源 |

还查不出问题的（扫不到歌、闪退之类），汇总在 [常见问题与故障排查.md](常见问题与故障排查.md)。
