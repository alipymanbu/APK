## 一、先决定：直接聊别人建的，还是自己写

JanitorAI 的角色库是社区贡献的，量很大，按标签（动漫、历史、游戏、恋爱向……）筛比按推荐翻快。多数人前几次聊天直接挑现成的就行 —— 挑角色的要领是先看简介和开场白：开场白写得细的角色，后面回复质量通常也稳；只有三行简介配张图的，进去往往没话聊。

想自己写，从主菜单进 **Create Character**（手机端在头像菜单里）。下面讲字段。

## 二、角色卡各字段填什么

| 字段 | 必填 | 填什么 |
| --- | --- | --- |
| 角色图片 | 是 | 卡片封面图，需符合社区规范 |
| Character Name | 是 | 显示在卡片顶部的名字，如 `Dan Smith \| 退休律师` |
| Character Chat Name | 否 | 聊天时角色怎么称呼自己，比上面短 |
| Character Bio | 否（建议填） | 给**读者看**的简介，支持 HTML 排版；不参与对话 |
| Tags | 至少一个 | 决定角色能不能被搜到；最多 10 个，可自定义 |
| Personality | 是 | **真正喂给模型的部分**：性格、外貌、背景、说话方式、示例对话都写这里 |
| Scenario | 否 | 场景、时代、角色与你人设的关系，短 |
| Initial Message | 是 | 开场白，同时给回复定文风基调 |

三条实操经验：

- **Personality 是权重最高的框**，示例对话也建议放这里。官方给的经验值是常驻内容控制在 2500 token 以内 —— 超了不会报错，但聊久了模型会更快忘事（人格、场景、聊天记忆、你的 Persona 是要一直占着上下文的，加起来涨得很快）。
- **开场白用第三人称写**效果最稳，能明显减少模型替你说话（把你的台词也写了）的毛病。
- **Bio 和 Personality 别混**：Bio 是门面，写给路过的人看，可以挂外链；Personality 才是角色的行为说明书。

## 三、发布前：私有还是公开

保存时选可见性：**Private** 只有你自己能用，**Public** 进公开库被所有人搜到。建议先私有测几轮，改到满意再转公开；公开后随时能编辑或删除，但别人收藏过的引用可能失效，别反复上下架。

## 四、自己先测一轮

角色保存后用 **Test Chat**（或 `+ New Chat`）开一局，自己发几条不同风格的消息试：

1. 角色是否始终自称设定的名字、不突然替你说话；
2. 开场白定的文风有没有被保持住；
3. 长句子、多人场景它接不接得住。

发现问题回角色页改 Personality / Initial Message 再测，改完的生效是即时的。测试时若回复迟迟不出来或报错，先别急着改角色 —— 多半是模型那一侧的问题，排查顺序见 [常见问题与故障排查.md](常见问题与故障排查.md)；换模型的办法在 [模型与API设置教程.md](模型与API设置教程.md)。

## 五、你的 Persona：让角色「认识你」

角色面向读者的一面讲完了，还有你自己的那一面。**Persona** 是你在聊天里扮演的身份（名字、外貌、年龄、穿着），角色会按你写的设定来回应你。主 Persona 在 设置（Settings）→ Appearance 里编辑，附加人设在 My Personas 里加（上限 100 个）；进聊天前在角色卡的头像菜单里切换要用哪个。

一个坑：**每次新开聊天默认回落到主 Persona**，不管你上一局用的是哪个；另外主 Persona 用的就是你的头像，换头像会连带改掉人设形象，两者目前分不开。写 Persona 时少写性格标签 —— 写了角色容易反过来替你这个人格化，你就不好操作自己的发言了。

没有账号建不了角色，先回 [注册与登录教程.md](注册与登录教程.md) 把号办了。
