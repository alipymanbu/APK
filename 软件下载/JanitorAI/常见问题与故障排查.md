## 一、第一步永远是：是所有人都坏了，还是只有你坏了

JanitorAI 是在线服务，服务端高峰拥堵、模型通道抽风都很常见。先去社区渠道（官方 Discord 的公告频道、Reddit 的 r/JanitorAI_Official）扫一眼：**大家都在报 = 你做什么都没用，等就是了**；只有你坏 = 往下走。

分清楚这个，能省掉一半瞎折腾。

## 二、发不出消息 / 报 failed to fetch

按顺序做，哪步好了停哪步：

1. **查网络**：开别的网页试试；Wi-Fi 和移动数据互切一次。网络通不了，客户端怎么重启都白搭。
2. **看当前用的模型**：聊天窗口顶部的模型切换器。报 429 / rate limit 是**所选模型通道**的限流，不是平台挂了 —— 等几分钟、切回 JanitorLLM、或换你自己的密钥通道继续。配置方法见 [模型与API设置教程.md](模型与API设置教程.md)。
3. **重启应用**：手机端把客户端彻底划掉再开；网页端刷新。
4. **清缓存**：安卓在 设置 → 应用 → JanitorAI → 存储 里清缓存（别点「清除数据」，那会把本地登录态一起抹了）。
5. **换入口对照**：同一账号在网页版发同一条消息。网页版通 = 客户端的问题，重装客户端（安装包见 [下载与安装教程.md](下载与安装教程.md)）；网页版也不通 = 服务端或账号，往下看。

## 三、页面打得开，但角色不回答

界面能加载说明账号与网络基本正常，问题在生成那一环：

- **内置模型高峰期慢**：换个人少的时段，或临时切别的模型通道。
- **刚换的外接配置不生效**：先保存设置再刷新页面，然后发条测试消息；`Model Name` 和 `Proxy URL` 有没有多空格、拼错字符。
- **只有某一个角色不答**：可能是该角色被作者转了私有、被下架、或触发了内容审核 —— 主页正常、唯独它打不开，就是这种情况，换个角色验证。
- **卡在等待室（Waiting Room）**：人满排队，别狂点刷新，刷新不进反而容易被反复踢回队尾，等它自己放行。

## 四、手机客户端里内容比网页少

客户端为符合应用商店审核，默认以受限模式运行，部分角色、图片、聊天在手机上被隐藏或限制。这不是安装包坏了，也不用重装。要调整：用浏览器登录网页版（与客户端同一个账号）→ 头像 → Settings → **Privacy & Display** → 找到移动端内容开关打开 → 把客户端从后台彻底杀掉重进，设置才会同步过来。这一步只能在网页版做，客户端内没有这个开关。

## 五、登录异常速查

| 症状 | 先做什么 |
| --- | --- |
| 密码错误 | 走 Forgot Password 重置，邮件五分钟没到翻垃圾箱 |
| unauthorized / 会话过期 | 完全退出 → 清该站 cookie → 重新登录 |
| 一直转圈登不进 | 按第一节判断是不是服务端故障，多半等一会就好 |
| 换了手机记录没了 | 多半登成了另一个账号（邮箱号与 Google/Discord 号不互通），换登录方式再试 |

细节在 [注册与登录教程.md](注册与登录教程.md)。

## 六、闪退、装不上

- **装不上**：先确认允许了「未知来源安装」，再核对安装包完整性（大小应为 72.46M 左右）；下载残了就重下。
- **打开就闪退**：先升级到新版 APK 覆盖安装；仍闪退再卸载重装 —— 聊天记录在服务端，重装不丢，但卸载前要确认账号密码还在手上。
- **系统版本太低**：安装包要求安卓 5.2 及以上，低了就是装不了。
