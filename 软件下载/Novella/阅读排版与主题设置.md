## 一、设置面板从哪呼出

**在阅读页点击屏幕中央**即可呼出设置面板，字号、间距、背景、亮度都在这一层面板里。调完即生效，切到别的书也沿用同一套设置；显示模式的切换不影响阅读进度，翻回来还是原处。

## 二、文字与排版

| 项目 | 你可做的调整 |
| --- | --- |
| 字号 | 滑杆/档位连续调，从很小到很大都有余量 |
| 段落间距 | 段与段之间的空隙 |
| 左右边距 | 页面两侧留白（v1.6.0 加入与段间距一起调的选项） |
| 简繁转换 | 同一本简体/繁体内容可切换显示 |
| 首行缩进 | 缩进渲染在 1.7.0 做过修正，观感与网页端一致 |

具体数值范围（有人整理过字号 10–30px、行距 1.2–2.0 之类），**以应用内滑杆的实际两端为准**，本篇不替你确认这些数字。

## 三、背景与主题

- **预设纯色背景**：黑白灰与护眼色系都备好了，选一个就走。
- **自定义背景色**：自己调配颜色，白天/夜间可以各存一套。
- **三种模式**：浅色、深色、纯黑（OLED）三种模式随系统或手动切换。
- **动态主题色**：详情页会**从书籍封面提取主色调**用作页面主题色；OLED 模式下的封面取色与深色背景效果在 1.7.0 优化过，纯黑模式下封面不会再显得发灰。

夜间看书记得切到深色或纯黑，背景亮度也可以单独降（面板里有亮度项）。

## 四、翻页与大屏布局

- **翻页方式**：点击左右翻页、上下滑动等模式可选，切模式不丢进度。
- **双页布局**：v1.6.0 加入 **Expanded** 与 **Split** 两种双页阅读布局，平板、大屏、横屏下一页能排两栏，纸质感更接近实体书。
- **章节内进度滑块**：阅读器弹出的信息面板里有章节内进度条（1.7.0 加入），不用一页页翻着找中间某段。
- **状态栏选项**：阅读器可选是否显示系统状态栏（1.7.0 加入）；OLED 机型上开着状态栏时注意对比度设置。

## 五、图片相关的两个开关

- **长按图片预览**：有开关项控制长按是否触发图片预览（1.7.0 加入），漫画、插图多的书里误触率高时可以关掉。
- 详情页三击分享那类入口在[找书与榜单筛选.md](找书与榜单筛选.md)，不重复讲。

## 六、升级后观感变了？看这几处改动

1.7.0 是一次「阅读器大改版」，覆盖安装后页面跟以前不一样的地方主要有：

| 改动 | 你可能注意到的 |
| --- | --- |
| 章节标题统一并简化 | 标题样式比旧版更整齐，占用高度变了 |
| 首行缩进渲染修正 | 段首缩进位置更规整，中文书尤其明显 |
| 脚注改为与网页端一致的内联星号标记 | 带脚注的书不再是跳来跳去的样式 |
| 相邻章节预渲染 | 翻到下一章更跟手，少白一下 |
| 图片页底部间距调整 | 漫画、插图页下沿留白变了 |
| 状态栏对比度修复（Android 启动屏） | 亮色主题下顶部不再发灰 |

这些只是**外观与手感的变化，不动你的进度和设置**。对不上号时先确认装的是不是同一版本。

## 七、调完不舒服怎么办

先确认改的是**阅读器内**的设置而不是系统字号；仍不对劲（字体发虚、行距错乱、颜色突兀），按[常见问题与故障排查.md](常见问题与故障排查.md)的显示异常一节处理。
