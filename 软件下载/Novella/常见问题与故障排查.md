## 一、安装类

**安装时提示解析错误 / 安装包损坏**
先校验 MD5（做法在[下载与安装教程.md](下载与安装教程.md)第五节），对不上就重新下载这一份；对得上仍报错，多为系统版本过低或芯片架构不匹配，看下一问。

**系统版本够不够**
各页面对最低安卓版本的标注不一致（7.0 / 5.2 / 4.3 都见过）。以你实际拿到的包和官方页面当时显示为准；装不上时优先怀疑系统版本，而不是反复重装。

**装完就闪退**
依次试：重启手机 → 清除应用数据 → 确认安装包 MD5 一致 → 换一份完整下载的安装包重装。仍闪退，把你机型与系统版本记下来，去项目的 [github.com/celia-sh/Novella](https://github.com/celia-sh/Novella) 的 Issues 搜同款反馈。

**覆盖升级后设置和书架还在吗**
在。同包名覆盖安装不动本地数据；只有**卸载重装**才会清掉本地书架与设置，那种情况下靠同步还原（见[书架与云端同步.md](书架与云端同步.md)）。

**权限给了还是读不到本地书**
去 **设置 → 应用 → Novella → 权限 → 存储** 确认状态；Android 13 及以后要把「照片和视频」「音乐和音频」「文件」这几项都放行，只给其中一项仍可能读不到。权限清单与用途对照在[下载与安装教程.md](下载与安装教程.md)第七节。

**没网时某章打不开**
那一章没缓存完。离线只能读已下载完的章节，联网补一次缓存再看（见[找书与榜单筛选.md](找书与榜单筛选.md)第五节）。

## 二、显示与阅读类

**字体显示不正常（发虚、行距错乱、颜色突兀）**
进阅读页设置，依次调「字体大小」「排版间距」「字体类型」，再把浅色/深色/纯黑模式切一遍——多数显示异常是模式与背景色打架造成的，不是坏了。

**切换显示模式会不会丢进度**
不会。切模式、翻页模式都不影响阅读进度，切回来还在原处。

**平板/横屏排版难看**
用 v1.6.0 起的 Expanded 或 Split 双页布局（见[阅读排版与主题设置.md](阅读排版与主题设置.md)）。另有用户反馈 iPad 端排版与同步表现不佳——**单一来源的用户评论，仅作参考**，不同设备实际体验以你自测为准。

**书架一多就卡**
同样有用户反馈书架条目很多时会卡顿（单一来源）。可行的缓解：给书架做分组或清理不再追的条目、关闭动态主题色提取、切到纯黑模式。

## 三、账号与同步类

**注册收不到邮件、登录被拦**
按[注册与登录教程.md](注册与登录教程.md)第四、五节的顺序排查：垃圾箱 → 地址拼写 → 隔几分钟重试 → 换邮箱。

**同步没反应 / 换机后书架是空的**
九成是「两台设备没指向同一个 Gist 或同一个账号」，其次 GitHub 授权失效。步骤与诊断入口在[书架与云端同步.md](书架与云端同步.md)。

## 四、资料与版本类

**搜到的介绍和实际对不上（VIP、看广告赚积分、英文小说平台）**
那是别的应用或下载站的串写。本文这款是**轻书架第三方客户端**，公开资料一致指向「核心阅读功能免费、无广告干扰」；判断依据仍是包名 `sh.celia.novella`。同名应用的区分表在[下载与安装教程.md](下载与安装教程.md)第一节。

**免费还是要付费**
多个来源口径一致：核心阅读功能免费、无广告。至于是否有可选的内购项，各下载站标注不一（有的写「提供应用内购买项目」），**以应用内实际显示为准**，本篇不替你下结论。

**它是不是开源的**
是。许可证为 AGPL-3.0，代码在 [github.com/celia-sh/Novella](https://github.com/celia-sh/Novella)，项目主页 [novella.celia.sh](https://novella.celia.sh/)。仓库说明里提到正从 Dart 迁移到 TypeScript（iOS 端用 React Native 重写、原 Flutter 实现在 `archive/flutter` 分支）——所以**同一时期看到「Flutter 客户端」和「React Native 重写」两种说法都正常**，不冲突。

**榜单里筛不到想要的书**
先确认筛选没把标签屏蔽掉了：屏蔽规则会一直生效，直到你在筛选设置里取消（见[找书与榜单筛选.md](找书与榜单筛选.md)）。
