# 电脑版怎么连接同步

> 本篇讲桌面版怎么装、怎么用手机扫码绑定、哪些内容会同步哪些不会，以及连不上时怎么查。

## 一、手机是主设备，电脑只是「挂在下面的屏」

Viber 的账号绑在手机号上，**必须先在手机上装好并激活，电脑端才能用**——桌面版没有独立注册入口，顺序不能反。理解这一点，后面所有行为都好解释：电脑端是手机授权出来的一个显示端，手机掉线或被登出，电脑端也跟着没戏。

系统要求（官方口径）：

| 平台 | 最低要求 |
| --- | --- |
| Windows | Windows 7 及以上 |
| macOS | macOS 10.12 及以上 |
| Linux | 64 位 Ubuntu、Fedora 等指定发行版 |
| 平板 | 与手机共用同一个安装包，装完用手机号激活即可 |

## 二、绑定步骤

1. 到官方下载页 [www.viber.com/download](https://www.viber.com/download) 取桌面版安装包，装完打开；
2. 界面上会出现一个二维码；
3. 手机上打开 Viber：更多 > 扫描二维码（部分版本在聊天列表右上角），对准电脑屏幕；
4. 手机上点确认，电脑端几秒内完成激活，开始同步。

绑多个电脑都可以，每个都要单独扫码。想解绑就直接在电脑上退出登录，或在手机的「已连接设备」里移除。

**定期看一眼设备列表**：更多 > 设置 > 账户 > 电脑和平板（菜单名随版本略有出入），这里列出所有连着的电脑、平板。手机丢了或借给外人用过之后，回来第一件事就是清这个列表——不认识的设备一律移除，处理顺序见 [手机丢了怎么找回账号.md](手机丢了怎么找回账号.md)。开了两步验证的话，从新设备扫码绑定时还会额外要求你输 PIN。

## 三、同步范围：哪些有、哪些没有

这是问得最多的一块，**新设备连上后不会凭空变出全部历史**：

**会同步的**
- 联系人、群成员身份、社区订阅；
- 连接**之后**收发的新消息、新通话；
- 群聊与频道的在线状态，通话可以打到电脑上响铃。

**同步不全的**
- **旧聊天记录**：连接时只拉最近一部分，更早的历史可能不完整；
- **已下载的媒体**：图片、视频、语音在电脑上多数要重新点开下载，原文件在手机上被清掉后电脑也拿不到；
- **设备各自的设置**：通知开关、铃声这类是各端独立的。

所以电脑端适合「接着聊」，不适合当归档。真要留底，靠手机端的备份，见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、通话在设备之间挪

- 来电时手机和电脑会同时响，哪边接都行；
- 通话中想换设备：手机上会出来一个「转到电脑 / 转到手机」的按钮，点一下无缝切过去（两端都要在线）；
- 手机端保持后台运行，否则电脑端会连不上——安卓上需要给这个应用开自启动与后台运行权限，各厂牌路径见 [下载与安装教程.md](下载与安装教程.md)。

## 五、电脑端看不到的东西，不是坏了

三类「缺失」是设计如此，别反复重装排查：

1. **隐藏聊天**：带 PIN 的会话在电脑端根本不出现，也没有 PIN 输入框，只能回手机上看；
2. **完整旧历史**：如第三节所说，只同步最近的部分；
3. **通话记录明细**：部分历史通话记录不跨设备带过去。

## 六、连不上 / 打不开二维码时

按顺序试，多数能解决：

1. **杀毒软件与防火墙**：桌面版要联网收发，被安全软件拦掉就会一直转圈——在防火墙的放行列表里加上这个程序，安全软件里给它信任；
2. **二维码扫不上**：手机与电脑的版本都更新到最新（旧版扫码协议对不上），手机相机别贴太近，屏幕反光也会失败；
3. **激活后过一会儿又掉线**：多半是手机端被登出了——在另一台设备上激活会让前一个登录退出，回手机确认登录状态；
4. **手机在后台被杀**：安卓的省电策略会杀掉后台连接，把应用加入白名单/自启动，再重新扫码。

还是不行，手机和电脑都重启一遍再扫，比在设置里翻来翻去快。
