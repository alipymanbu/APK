# 收不到验证码与登录不上怎么办

> 本篇只解决一件事：注册或登录时验证码不来、流程卡住、账号登不上，按什么顺序排查。

## 一、先分清卡在哪一步

三种症状，原因完全不同：

| 症状 | 更可能的原因 |
| --- | --- |
| 点了发送，短信一直不来 | 号码/短信通道问题，见第二节 |
| 界面一直转圈，连「发送」都点不出 | 网络连不上服务器，见第三节 |
| 输完码提示失败、被限制 | 重试过于频繁或账号状态问题，见第四节 |

## 二、短信验证码收不到

按命中概率从高到低逐条排：

1. **号码格式**：国家区号必须对——中国大陆填 `+86`，区号后直接接手机号，别在号码前面多补一个 0；
2. **手机欠费或停机**：能打电话不代表能收短信，先用这号码发条普通短信试试；
3. **信号太弱**：短信走的是最基础的信道，信号一格时也该能收——把手机拿到窗边，或重启一次信号；
4. **拦截软件吞了**：查手机自带的短信拦截、骚扰过滤，以及第三方安全软件的短信记录，把发件通道加白名单；
5. **运营商侧屏蔽**：曾向运营商申请过短信屏蔽的号码收不到，打客服核实；
6. **改用语音来电验证**：注册界面通常提供「语音来电」选项，电话报码比短信稳定得多，短信死活不来时直接换它；
7. **隔一会儿再试**：短时间反复点发送会被限流，越点越收不到，等几分钟再操作。

## 三、界面一直转圈、连发送都点不了

这不是验证码的问题，是应用没连上服务器：

1. 先在浏览器里打开 [www.viber.com](https://www.viber.com) —— 打不开就说明当前网络到不了它的服务器，换个网络（公司/学校 Wi-Fi 换成手机流量，或反过来）再试；
2. 关掉飞行模式、确认 Wi-Fi 本身能上网（打开一个别的网页验证，别只看信号图标）；
3. 系统时间不对也会让加密握手失败：设置 > 系统 > 日期与时间，打开「自动确定」；
4. 装的是 [下载与安装教程.md](下载与安装教程.md) 里那份安装包的话，先确认应用确实是完整安装的（能打开、能进到输号码界面），安装包损坏的表现通常是闪退而不是卡验证码。

## 四、提示失败、被限制、账号登不上

- **重试太勤**：连续多次输错或反复请求验证码，会被临时限制——停一段时间（半小时以上）再试，期间别反复点；
- **在新设备上激活会把旧设备登出**：换手机后老手机突然登不上是正常现象，不是被盗；在新手机上用同一个号码激活即可；
- **提示「该号码已注册」**：那说明这个号本来就有账号，直接走登录流程，不用再注册；
- **换了号码**：账号跟着手机号走，换号基本等于重新开始——旧号码收不到码就无法验证身份，这点没有客服后门可走。

## 五、电脑端的登录是另一回事

电脑版没有自己的验证码流程，它靠手机扫码授权（[电脑版怎么连接同步.md](电脑版怎么连接同步.md)）。所以「手机能登、电脑扫不上码」时，该查的是二维码与防火墙，不是验证码通道——别在电脑上找收码入口，找不到的。
