主流程的问题（装不上、权限开不了、后台被杀）各有专门一篇，本篇收的是那些不值得单开一页、但真用起来一定会碰到的小事。按问题找对应小节即可。

## 一、通知栏老是弹「GKD 可以查看和控制您的屏幕」

这是 play 渠道特有的问题：Google Play 政策要求以支持残障人士为主要用途才能声明无障碍工具，play 渠道的包没有这个声明，系统就定期提醒你。gkd 渠道（官网、GitHub、网盘安装包）有声明，不弹这条通知。被烦到了就用 gkd 渠道的包覆盖安装，不需要卸载，两个渠道的区别详见[下载与安装教程](下载与安装教程.md)。

## 二、应用图标怎么变了 / 想换回来

GKD 有默认和深色两套图标，第一次显示哪套取决于你安装时系统的深色模式设置，而且系统切深色模式时它不跟着自动换。想换图标有三个办法：

- 到 系统主题 → 图标包，换一个图标包再换回来；
- 重启手机；
- 同版本覆盖安装一遍 GKD（无需卸载）。

## 三、通知栏快捷开关与深链

GKD 在系统下拉面板注册了几个快捷开关，比进应用切换快得多：

| 开关 | 作用 |
| --- | --- |
| GKD | 打开或关闭无障碍权限 |
| HTTP服务 | 打开或关闭 HTTP 服务 |
| 悬浮按钮 | 打开或关闭悬浮按钮，点出现的按钮可捕获快照 |
| 捕获快照 | 点击后捕获当前应用界面快照 |

另外它支持从浏览器或其他应用直接打开链接跳到应用内页面：`gkd://page` 是首页、`gkd://page/1` 是高级设置、`gkd://page/2` 是快照记录。

## 四、换手机怎么把规则带走

两种方式，都在 首页 → 订阅 → 右上角菜单：

1. **导出/导入数据**（直接法）：旧手机导出数据 → 文件管理器里手动选路径保存 → 新手机在同一个菜单里导入。缺点是文件管理器里手动选路径比较绕；
2. **经聊天软件中转**（官方推荐，更顺手）：旧手机导出数据后分享到 QQ 发给自己 → 新手机在 QQ 里点开这个文件 → 用其他应用打开 → 选 GKD 导入数据。QQ 换成任何支持「用其他应用打开」的传输软件都行。

订阅的远程部分不用担心 —— 新手机重新添加订阅链接就会拉到最新版，要迁移的只是本地订阅和设置。

## 五、Shizuku 是干嘛的（可选，不需要 Root）

先说结论：GKD 本身不需要 Root，Shizuku 是完全可选的增强项。授权 Shizuku 后，GKD 可以调用更多系统 API 获取更多状态、启用更多优化（多与后台与权限相关）。官方文档特别提到两点：

- 原版 [RikkaApps/Shizuku](https://github.com/RikkaApps/Shizuku) 已很久没有维护记录，且部分设备上只能部分工作（GKD 会提示「服务连接部分失败」）；
- 官方文档建议改用仍在维护的分支项目 [thedjchi/Shizuku](https://github.com/thedjchi/Shizuku)。

只想「装上就能用」的话，跳过这一节完全没问题；被后台杀得厉害、按[后台保活与耗电优化](后台保活与耗电优化.md)处理后仍不理想的，再考虑这条路。

## 六、规则开了但界面不动，怎么查

按顺序过一遍，多数卡壳都在前三条：

1. 无障碍开关还亮着吗（去 GKD 首页看，别凭感觉）；
2. 对应应用的规则组勾选了吗 —— 默认订阅是手动按应用启用的，步骤见[订阅规则添加方法](订阅规则添加方法.md)；
3. 订阅更新了吗 —— 进订阅页手动检查一次更新，应用改版后旧规则会失效；
4. 是不是后台被杀了 —— 症状和解法见[后台保活与耗电优化](后台保活与耗电优化.md)；
5. 单个应用跳错或误点，先关掉它的规则组单独验证，确认是规则本身的问题后反馈给订阅作者。

这一条清单只覆盖入口级检查；走完还不跳的（规则休眠、flutter 页面不触发事件这类更深的坑），照[开屏广告没跳过怎么排查](开屏广告没跳过怎么排查.md)的顺序细查。

## 七、隐私与权限边界

装之前最常问的几个疑问，按官方口径汇总：

- **无障碍权限意味着什么**：GKD 能读取屏幕上的控件内容和执行点击 —— 这是它工作原理本身，也是权限敏感的原因。你启用哪些规则组、哪些应用，决定了它实际会去动什么；
- **数据去哪了**：官方介绍称应用仅在本地运行、使用时不需要网络权限；订阅规则只是拉取一份文本规则文件，你的使用记录不在其中；
- **代码能不能看**：GKD 开放源代码（[gkd-kit/gkd](https://github.com/gkd-kit/gkd)），任何人可审查；
- **唯一要主动留心的点**：快照上传是你主动发起的公开行为（见[快照捕获与规则调试](快照捕获与规则调试.md)的隐私提示），除了这一步，日常使用没有向外界提交界面的环节。
