# KOReader calibre 无线传书连不上怎么办

> 手机上搜不到 calibre、点了连接没反应、连上又掉线：按「同一网络 → 服务开着 → 手动填地址 → 查防火墙」的顺序逐项排查，本篇是排查清单。

## 一、先查三件事

1. **两台设备在同一个 Wi-Fi**：手机和开 calibre 的电脑必须在同一网络。访客网络、公司网络常把设备互相隔离，开着 VPN 也可能把流量带走——先关掉试试。
2. **calibre 侧服务已开**：calibre 工具栏点「连接」启动无线设备连接，按钮变色才算开着。
3. **地址没填错**：calibre 开启服务时会显示本机 IP，KOReader 侧填的应该就是这个 IP；端口默认 9090（除非你在 calibre 里改过）。

## 二、自动发现搜不到：手动填 IP

KOReader 的自动发现靠路由器广播，Wi-Fi 扩展器、多子网、某些路由器的隔离规则都会让它失效——这也是「昨天还好好的、今天就搜不到」的最常见原因：

1. 在电脑上确认 calibre 显示的 IP（如 `192.168.1.100`）。
2. KOReader 里进 calibre → 无线设置（Wireless settings），服务器地址选手动（Manual），填 IP 和端口 9090。
3. 回 calibre 菜单点「连接」。

手动填地址比自动发现可靠，多数「搜不到」的问题到这一步就解决了。

## 三、还是连不上：查防火墙与杀毒

连不通的另一半原因在电脑侧拦截：

- **Windows**：第三方杀毒/安全软件拦入站连接很常见，把 calibre 加入白名单，或临时退出测试。
- **Linux**：ufw、nftables 这类防火墙拦掉入站是用户论坛里的高频案例，有用户放行后立即恢复。
- **macOS**：系统设置 → 网络 → 防火墙，确认 calibre 允许传入连接。

验证思路：在同一网络里用另一台设备访问 calibre 的 OPDS 地址，能打开说明服务正常，问题就出在防火墙或地址上。

## 四、连上了但老掉线、发不了书

- **闲置一段时间就断**：有用户反馈无线连接闲置几分钟会自动断开，属正常行为，要用时重连即可。
- **calibre 里「发送到设备」是灰的**：多半是连接其实没握上，回第二节手动填 IP 重连。
- **书发过去列表里没有**：等几秒刷新书库；还不显示就回 [怎么导入图书.md](怎么导入图书.md) 检查存储目录，或看 [常见问题与解决办法.md](常见问题与解决办法.md) 第三节。
