## 一、KOReader 是什么

KOReader 是一个开源电子书阅读器，GitHub 项目地址 [github.com/koreader/koreader](https://github.com/koreader/koreader)，采用 AGPL-3.0 许可证，由志愿者社区开发维护。它最初面向电子墨水屏阅读器，后来也提供安卓版与 Linux 版；同一项目还有 Kindle、Kobo 等电纸书设备版，本套文档只讲安卓版。

你装它通常是为了解决两类问题：扫描版 PDF、DjVu 这类「字是图片」的书没法舒服地读；各种格式的书（EPUB、Mobi、TXT、CHM 等）想在一个应用里统一管理、自由调排版。

安卓版在 F-Droid 开源应用商店收录，包名 `org.koreader.launcher.fdroid`，界面支持中文。这套文档里所有安装包信息以网盘里那份为准，网上各信息站的版本号与系统要求常常和它对不上，别互相套用。

## 二、安装包从哪拿

两条路，任选：

1. **网盘转存**：打开 [KOReader 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1dcde1250372)，把安装包下载到手机。拿到的是固定一版（v2025.04），不会自动更新。
2. **官方渠道**：GitHub 发布页 [github.com/koreader/koreader/releases](https://github.com/koreader/koreader/releases) 提供 arm64、arm、x86 三种架构的 APK，并附 SHA256 校验值；也可以从 F-Droid 商店安装、随商店自动更新。官方网站是 [koreader.rocks](https://koreader.rocks/)，官方用户指南（含中文版）也在上面。

两条路拿到的未必是同一版：网盘这份固定在 v2025.04，官方渠道会随发布更新（截至 2026-09 官方已发布到 v2026.07 系列，以官方发布页当时显示为准）。

## 三、装前核对安装包信息

网盘里这份安装包的记录如下，下载后可逐项核对：

| 项目 | 值 |
| --- | --- |
| 版本 | v2025.04 |
| 大小 | 31.00 MB |
| 包名 | `org.koreader.launcher.fdroid` |
| MD5 | `215EEF1A3B6339D5C0DC8B2276F1D801` |
| 信息记录日期 | 2026-09-27 |

- **核对大小**：下载完成的文件应约 31 MB，明显偏小说明没下完整，删掉重下。
- **核对包名**：装之前用任意「查看 APK 信息」的工具确认包名是 `org.koreader.launcher.fdroid`；网上转载这份安装包的第三方站点不少，信息常有出入，包名对不上就不要装。
- 版本号按「年份.月份」规则命名（v2025.04 即 2025 年 4 月版），别处出现更高版本号属正常，两边不要混着对。

## 四、系统要求

公开信息有三个口径，全部并列给你：

| 来源 | 要求 |
| --- | --- |
| 网盘安装包的记录 | 安卓 5.2 以上 |
| F-Droid 页面对旧版本（v2023.08）的标注 | Android 4.3 以上 |
| 部分第三方 APK 信息站 | Android 4.3 / 4.4 以上 |

以你实际安装、启动的结果为准：设备版本低于要求时装不上、或启动就闪退，就是过不了；装上能正常用，就以实际为准。架构方面，2017 年之后的主流手机与平板对应 arm64 包，较老设备与模拟器对应 arm、x86 包。

## 五、安装步骤

1. 按第二节的路径把 APK 下载到手机（约 31 MB，核对第三节的信息）。
2. 用文件管理器点这个 APK 安装。首次会提示「未知来源」，去「设置 → 应用」里给文件管理器或浏览器开启「安装未知应用」权限，再装一次；从 F-Droid 商店装则没有这一步。
3. 装完桌面会出现 KOReader 图标。安卓按包名区分应用：如果之前装过 F-Droid 渠道的 KOReader（包名同为 `org.koreader.launcher.fdroid`），再装就是覆盖升级；包名不同则会并存成两个图标。

## 六、首次启动要做什么

1. **授予文件访问权限**：第一次打开会请求访问设备文件，同意后它才能扫描到手机里的书；权限给漏了的话，去「设置 → 应用 → KOReader → 权限」补开。
2. **指定书库目录**：把电子书集中放在一个固定目录（比如 `Books`），扫描后书库列表更清爽；怎么把书弄进手机见 [怎么导入图书.md](怎么导入图书.md)。
3. **确认界面语言**：菜单里找「设置 → 语言」，切到中文。

装完先看你的书是哪种格式：[支持哪些电子书格式.md](支持哪些电子书格式.md)；想改字号、行距、边距，看 [字体与排版怎么调.md](字体与排版怎么调.md)。
