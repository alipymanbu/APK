## 一、装之前先确认这几件事

Poipiku 是一个面向二次元爱好者的插画、漫画分享社区，你可以在上面发草稿、练习稿、未完成的图，也可以看别人的作品并互动。本篇对应的是它的安卓客户端，界面默认中文。社区里也常把它叫「破皮裤」——读音相近的叫法，搜到这两个名字指的多半是同一个东西。

装之前核对一下这份安装包的基本信息（以安装包实际信息为准）：

| 项目 | 信息 |
| --- | --- |
| 版本 | 232 |
| 包名 | `com.lengmou.poipikugj` |
| 安装包大小 | 6.21M |
| MD5 | AA9CE9764860A1942A8BB5149461EA4F |
| 系统要求 | 安卓 5.2 以上 |

几点说明：

- 这个体积很小，近几年的安卓手机基本都能装，不需要特意腾出很大的存储空间。
- 它不是从手机自带应用商店装的，属于「从安装包安装」，所以需要你手动允许一次「安装未知来源应用」的权限（下面第三步会讲）。
- 如果你手机上已经装过别的渠道来源、包名不同的同名应用，二者可以并存，不会互相覆盖；但不建议同时登两个，容易分不清账号。

## 二、安装文件从哪拿

本篇配套的 Poipiku 安装文件资源放在夸克网盘：[https://pan.quark.cn/s/611897c014af](https://pan.quark.cn/s/611897c014af)。

操作路径：

1. 用手机上的夸克 App 打开上面的链接（或把链接复制到夸克 App 里）；
2. 把安装包转存到自己的网盘空间；
3. 在网盘里找到转存后的安装包，点下载，落到手机本地存储。

转存之后再下载，是为了保证文件完整、不怕原分享失效。下载完成后你就拿到了一个 `.apk` 文件。

## 三、安装步骤

1. 在手机文件管理里找到刚下载的 `.apk` 文件，点它。
2. 系统会弹出「是否允许安装」的提示；第一次装会先跳到设置页，让你允许「来自此来源的应用」或「安装未知应用」，按提示打开开关后返回再点安装。
3. 等安装完成，点「打开」直接进入，或回桌面找图标。

装不上或装好后打不开的常见原因：

- **存储空间不足**：清理一下再装；
- **安装包没下完整**：回网盘重新下载一次，再用第四节的 MD5 核对；
- **装好了但闪退、白屏**：先清一次缓存（系统设置 → 应用管理 → Poipiku → 存储 → 清除缓存）再打开，不行就重启手机；安卓的网页组件 WebView 版本过旧也会让页面加载异常，可以在应用商店里把它更新到最新。

## 四、核对安装包有没有下错

如果你对文件完整性有要求，可以核对 MD5。安装包的 MD5 应为：

```text
AA9CE9764860A1942A8BB5149461EA4F
```

核对方法任选其一：

- 部分手机文件管理器支持长按文件 →「属性 / 详情」直接看 MD5；
- 用应用商店里的校验工具类 App，选中该 `.apk` 计算 MD5 后与上面的值对照。

对不上就说明文件下错了或没下完整，重新下载一遍即可。

## 五、装好之后先做什么

打开应用就是登录注册入口。你需要先注册一个账号才能发作品和互动，具体步骤见 [注册与登录步骤.md](注册与登录步骤.md)；注册完想了解怎么发图、怎么控制谁能看到你的图，见 [作品发布与隐私设置.md](作品发布与隐私设置.md)。
