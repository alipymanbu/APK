## 一、先分清「收藏」和「保存」

收藏是把图收进 Poipiku 的收藏夹，图还在平台上，换设备登录也能看（整理思路见 [浏览搜索与收藏技巧.md](浏览搜索与收藏技巧.md)）；保存是把图片文件下载到你自己的手机或电脑里，离线也能看。两者互不影响，想长期留图建议两个都做。

## 二、App 里怎么存图

1. 打开想保存的作品，进入作品详情或作者主页的图片预览；
2. 点开大图，等图片完整加载——加载到一半就存，存到的可能是缩略图；
3. 长按图片，弹出保存选项后确认，图片会存进系统相册；
4. 长按没反应的话，用手机截屏兜底。

不同版本的菜单叫法可能略有差异，以你 App 内实际显示为准。

## 三、网页版存原图：开发者工具法

App 里长按存到的有时是压缩过的预览图。想要上传时的原图，可以用电脑浏览器走网页版（[poipiku.com](https://poipiku.com/)）：

1. 打开想保存的作品，点开大图模式，等图加载完；
2. 按 `Ctrl + Shift + I`（Mac 是 `Cmd + Option + I`）打开浏览器开发者工具，切到「Elements」面板；
3. 在元素树里逐段展开，找到 id 为 `DetailIllustItemLink` 的链接节点（一般在作品详情相关的节点附近，需要往下多翻几段）；
4. 点击这个链接，图片会在新标签页单独打开；
5. 在新标签页里右键图片 →「图片另存为」，选好文件夹保存。

如果元素树里一时找不到这个 id，确认你打开的是大图页而不是列表页，再从头展开找一遍；页面结构以后可能调整，以当时的实际页面为准。

## 四、存图之后的两条边界

1. **只留自己看**：存下来的图是别人画的，私下欣赏没问题；转发时保留作者署名和出处，别当成自己的图二次发布，也别拿去商用。
2. **尊重作者的控权设置**：作者给作品设了密码或预览垫子，就是不想让图随便扩散（设置方法见 [作品发布与隐私设置.md](作品发布与隐私设置.md)）；这类图你能看到已经是作者授权的范围，文件就别再往外传了。
