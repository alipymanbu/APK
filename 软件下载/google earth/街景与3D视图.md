# Google Earth 街景与 3D 视图使用教程

> 本篇讲 Google Earth 手机版里最出片的两样东西怎么进：街景（站到街道上看四周）和 3D 视图（把城市楼群立起来看），以及翻历史街景的方法。手势不熟的先看 [界面与基础操作.md](界面与基础操作.md)；想量这块地多大，见 [测量距离与标记地点.md](测量距离与标记地点.md)。

## 一、进街景的步骤

街景在手机版里不是独立按钮，要先有个地点：

1. 搜索一个地点，或直接把地球拖到目标位置点一下；
2. 弹出的信息卡或底部栏里找**街景小人**（黄色小人图标），点它；
3. 地图上出现**蓝色高亮**的线条或区域——蓝色画到哪，街景就拍到哪；
4. 点一段蓝色区域，直接「站」到地面上。

进去之后你就站在路中间，四周是 360 度实景照片。

## 二、街景里的操作

| 想做什么 | 做法 |
| --- | --- |
| 环顾四周 | 拖动屏幕 |
| 沿路前进 | 屏幕上出现白色箭头，点箭头顺路走 |
| 缩放 | 右下角放大 / 缩小按钮 |
| 回正北 | 右下角罗盘 |
| 退出 | 左上角返回 |

看完想看平面的，退出街景回到地球视角即可，之前搜的地点还保留着。

## 三、翻历史街景：看这条街几年前的样子

同一个地点往往拍过多轮，可以对比变迁：

1. 按第一节的步骤进街景；
2. 找**「查看更多日期」**入口，打开时间轴；
3. 拖动滑块或点缩略图，切换到某一年；
4. 看完点「返回最新图像」回到当下。

不是每个地点都有多轮存档——只有被重拍过的路段才翻得出历史，翻不出来就是只有一轮。

顺带说明：能翻「卫星照片」年代的历史影像滑块是电脑版 Google Earth Pro 的工具，手机版没有这个入口，手机上可翻时间的只有街景时间轴。两款应用的分工对比见 [和谷歌地图有什么区别.md](和谷歌地图有什么区别.md)。

## 四、3D 建筑：把城市立起来

卫星图是平的，但全球数百个城市的中心城区有建模好的 3D 楼群。玩法：

1. 搜一个大城市（纽约、东京、上海这类核心城区成功率最高）；
2. 双指张开放大；
3. 双指按住**同向上滑**，把视角从垂直往下压成斜着看，楼群立体感就出来了；
4. 配合旋转手势绕着看。

3D 素材覆盖不到的城市（多数中小城市）压平视角也只有平贴图，属于正常现象，不是你的手机问题。

## 五、这里怎么是灰的 / 没有街景

- **街景覆盖不均**：全球只有部分地区拍了街景，覆盖范围以 Google 的街景覆盖说明页为准（`https://www.google.com/streetview/`）；乡村、小岛、部分国家整片没有蓝色线条，就是没拍过；
- **影像糊**：放大超过当地影像分辨率上限，图就糊了，缩小一档反而清楚；
- **飞行动画卡住不动**：网络拉不动大图，参考 [黑屏或加载不出来的解决方法.md](黑屏或加载不出来的解决方法.md)。

想量这块区域多大、多远，用的是另一个工具，见 [测量距离与标记地点.md](测量距离与标记地点.md)；还没装应用的，回 [下载与安装教程.md](下载与安装教程.md)。
