## 一、涂鸦选择：不用描边的抠图方式

官方当年主打的就是这个工具：不用沿着边缘描，在想要的部分上**涂几笔**（绿色笔迹），在不想要的部分上也**涂几笔**（红色笔迹），它按你的笔迹判断边界并生成选区。适合主体和背景颜色差得比较开的照片。

1. 进入选区工具里的涂鸦选择；
2. 在要保留的主体上涂绿；
3. 在背景上涂红；
4. 确认后得到选区。不满意就撤销重来，或进下一步细化。

## 二、边缘细化：对付头发这类难点

涂鸦选择的边界在头发、毛边这类地方往往毛糙。配套手段是边缘细化（Refine Edge）：在选区边缘用手指抹一圈，让它重新判断这一圈的归属。头发丝不必一根根抠，抹过发梢区域即可，误差比手描小得多。

抠完之后两种去处：

- 直接在选区内做调整，改动只作用于这一块；
- 把选区内容提取 / 复制到新图层，再换背景、加别的素材。

## 三、图层的常用操作

| 操作 | 做法 | 什么时候用 |
| --- | --- | --- |
| 新建图层 | 图层面板里新建 / 添加 | 每做一类改动单独一层，方便回头单独改 |
| 调整叠放顺序 | 选中图层后上移 / 下移 | 上面一层会盖住下面一层 |
| 改不透明度 | 图层属性里的滑杆 | 叠图、做水印这类半透明效果时常用 |
| 复制图层 | 图层菜单里复制 | 动手改之前先复制一份留底 |
| 合并图层 | 见下一节 | 确认不再单独改动之后 |

不同版本的菜单叫法略有出入，找不到时在图层面板里长按图层，或点图层旁的菜单入口找同名项。

## 四、合并图层怎么做、什么时候做

1. 在图层面板里选中要合并的两层中**靠上**的那一层；
2. 在图层菜单里选「向下合并 / 合并图层」一类的项（叫法随版本略有差异）；
3. 两层并成一层。要合并多层，从最下面那层开始逐层向上重复。

两个提醒：

- **合并不可逆**。合并前把参与合并的图层各复制一份，或整层留底，之后不满意还有得退；
- **没必要的合并不如不并**。保持分层到导出前一步，改动余地最大；需要把全部可见内容并成一层时（比如下一步做整体滤镜）再动手。

抠好的图层想存成图片发出去，步骤在 [导出与保存.md](导出与保存.md)；选区工具在界面哪个位置，回 [功能与工具入门.md](功能与工具入门.md) 对照。
