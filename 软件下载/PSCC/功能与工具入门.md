## 一、界面从哪认起

打开后先看到的是项目首页：你建过的每个项目一张缩略图。点新建会问你从哪取图——拍照、从相册选、从本地文件选，或者开一块空白画布。进入某个项目后才是编辑区：画布占大部分屏幕，顶部一排是撤销、重做这类常用动作，工具入口沿屏幕边缘排布。

它当年就是为竖屏手机设计的（官方对手机版的定位是拿在手里改图），按钮偏大，靠点按加手势操作。具体某个按钮的位置随版本略有差异，下面只讲每类工具的用途与用法。

## 二、常用工具对照

| 你想做的事 | 用什么 | 说明 |
| --- | --- | --- |
| 把照片调亮 / 调对比 | 调整类工具 | 亮度对比度、色相饱和度、黑白、曝光这一类，作用范围可选整图、当前图层或选区 |
| 加滤镜效果 | 效果 / 滤镜类 | 官方商店页介绍里列了专业效果、绘画效果与滤镜笔刷，具体目录以你装到的版本为准 |
| 抠出一块区域 | 选区工具 | 矩形、椭圆、套索、魔棒，以及它有特色的涂鸦选择，步骤见 [抠图与图层操作.md](抠图与图层操作.md) |
| 叠一张图上去 | 图层 | 新建图层后从相册或文件再进一张，层与层之间互不影响 |
| 写字 | 文字工具 | 官方介绍提到文字可加描边、投影、淡出这些效果 |
| 涂抹 / 擦除 | 画笔 / 橡皮擦 | 笔刷大小、硬度、不透明度可调 |
| 用摄像头取材 | 相机填充 | 拍一张照直接填充到选中的图层区域，是官方当年列出的特色功能 |

## 三、一个最简单的上手流程

1. 新建项目，从相册选一张照片；
2. 进调整类，拖亮度 / 对比度滑杆，画布实时变化，满意点确认；
3. 加一个文字层，输入几个字，拖到想要的位置；
4. 某一小块不满意，先用选区工具框出来再调，改动只落在选区内；
5. 做完先别急着关——改动存在项目里，成品要另外导出才能用，步骤见 [导出与保存.md](导出与保存.md)。

## 四、动手前值得知道的三件事

- **12 兆像素上限**：官方商店页写明支持最大 12 MP 的图像。现在手机拍的照片普遍超过这个数，导入大图时留意画面有没有被缩小，印刷用途别指望原分辨率。
- **调整可以只作用在选区或图层**：全图一调全变；先选区再调整，是更精细的用法。
- **撤销一直在**：顶部撤销按钮随时退回上一步，大胆试。拿不准某个效果，先复制一层再动手，原图层留底。

工具认得差不多了，进阶的抠图与图层合成在 [抠图与图层操作.md](抠图与图层操作.md)；还没装上、或想先弄清这包的来历，回 [下载与安装教程.md](下载与安装教程.md)。
