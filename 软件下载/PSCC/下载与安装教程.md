## 一、先弄清你要装的是什么

PSCC 是流传较广的一个叫法，对应的安装包包名为 `air.com.adobe.pstouchphone`，与 Adobe 当年面向手机的图像编辑应用 Photoshop Touch（手机版）的包名一致。这款应用官方在 2015 年 5 月宣布停止销售与更新，Google Play 商店早已下架；官方公告还专门说明，安卓用户一旦卸载，就无法再从商店重装，只能靠自己留存的安装包。

所以你现在能装到的，都是当年版本的安装包在用户之间转存流传的结果。本文用的安装文件资源就在开头网盘块里，版本、大小、MD5 以下面这张表为准。

## 二、核对你要装的文件

| 项目 | 值 |
| --- | --- |
| 应用名 | PSCC |
| 包名 | `air.com.adobe.pstouchphone` |
| 版本（包内标注） | 9.9.9 |
| 安装包大小 | 23.04 MB |
| MD5 | `7DEBC83B74160A648449C8FCCE8639D5` |

关于版本号有两点值得知道：

- Adobe 官方从未发布过 9.9.9 版。官方商店时代手机版的最终版本是 1.3.7，9.9.9 是流传包里常见的自标号，不代表官方更新记录。
- 网上搜「PSCC / Photoshop Touch 最新版」看到的说法五花八门，判断手头这份包是什么，以包名加 MD5 为准，别看标题。

## 三、安装步骤

1. 打开 [PSCC 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8ac79b7abdf8)，转存到自己的网盘后下载到手机存储；
2. 在文件管理器里找到下载好的 `.apk` 文件（约 23 MB）；
3. 点开安装。系统会提示「允许从此来源安装应用」，按提示允许一次即可；
4. 安装完成点打开，等它进入项目首页。

如果你是在电脑上下载、再传给手机，传完后同样从第 2 步开始。

## 四、装不上时先查这几处

| 现象 | 先查什么 |
| --- | --- |
| 提示「应用未安装」 | 手机里是否装过别的同名或同包名的包，有就先卸载再装（签名不同会顶掉） |
| 安装按钮点不了 / 一闪而过 | 存储剩余空间是否够；重启手机再试一次 |
| 文件管理器里找不到 apk | 确认下载是否完成（完整包约 23 MB，半截文件装不了） |
| 装上了但打开就闪退 | 跳到 [常见问题与兼容性.md](常见问题与兼容性.md)，多与安卓版本兼容有关 |

装好之后从哪下手，看 [功能与工具入门.md](功能与工具入门.md)；做过修改想存成图片，看 [导出与保存.md](导出与保存.md)。
