## 一、为什么要直连

官方项目页专门写了一节「音频线路电平转麦克风电平」：直连比声学耦合可靠，能避开回声、失真与环境噪声。收弱信号（卫星、短波远台）时，这一步带来的画质差别很直观。

但直连不是拿一根两头 3.5mm 的音频线插上就完事——这恰恰是大多数人第一次会踩的坑。

## 二、手机耳机口的三个事实

官方说明里给出的事实，决定了线缆不能直通：

1. **电平不匹配**：电台线路输出（line-out）的信号摆幅约 1 伏，而麦克风输入期待的是毫伏级信号——直接灌进去会严重过载，必须衰减；
2. **偏置要隔断**：手机通过耳机口给麦克风供电（偏置电压），直通线会把这个直流送到发送端，造成失真，需要隔直；
3. **手机要「认出」麦克风**：手机靠 TRRS 插头第二环与套筒之间的电阻识别「插着的是麦克风」，缺了这个电阻可能根本不从耳机口收音。

另外，普通立体声耳机（TRS 插头）插进手机的 TRRS 座时，套筒与第二环正好被短接——所以耳机能正常出声，但自己做线时要按 TRRS 的引脚定义来，别想当然。

## 三、官方给的参考电路

官方 README 给的是「1:1 音频变压器 + 电阻衰减」方案，靠变压器实现电气隔离——一次侧与二次侧不共地，顺带解决地环路问题、也保护两端设备：

```
 [Line IN] O---[R1]---+||+---+---|C1|---+---O [Ring 2]
                      S||S   |          |
                  T1: S||S  [R2]       [R3]
                      S||S   |          |
[Line GND] O----------+||+---+----------+---O [Sleeve]
```

官方给出的参考值：

| 元件 | 作用 | 参考值 |
| --- | --- | --- |
| T1 | 1:1 音频变压器，电气隔离 | 600Ω 阻抗 |
| R1 | 初级串联，衰减兼提高源端阻抗 | 2.2kΩ（1k~10kΩ 均可，换 10kΩ 电位器可调衰减量） |
| R2 | 次级并联，阻尼谐振、兼做衰减 | 100Ω |
| C1 | 隔直电容 | 2.2µF 薄膜电容（1µF~100µF 均可，低于 1µF 会伤低频成分） |
| R3 | 麦克风识别电阻，接在 Ring 2 与 Sleeve 之间 | 2.2kΩ（2kΩ 附近均可） |

接线端含义：Line IN / Line GND 接电台或声卡的线路输出；Ring 2 / Sleeve 接 TRRS 插头（插手机耳机口）。

## 四、不想动手的替代路线

- **买现成的转换线**：搜「line to mic 衰减线」「手机麦克风输入转换器」，成品里已经做好衰减与识别电阻（是否带隔直与隔离元件，买前看说明）；
- **继续用声学耦合**：设备少、图省事时就扬声器对麦克风，把 [解码失败与图像异常排查.md](解码失败与图像异常排查.md) 里的音量与环境建议做好，多数场景够用；
- **SDR 用户**：电脑端解码软件也成熟（如 Windows 上的 MMSSTV、Linux 上的 QSSTV），可电脑解码为主、手机只做移动端补充。

## 五、装好线之后

首次接好后，拿一段确定良好的 SSTV 音频（或等一次已知活动）验证整条链路：界面有响应 → 校准头识别 → 出图。之后遇到异常，先区分「线的问题」还是「信号的问题」，再回到 [解码失败与图像异常排查.md](解码失败与图像异常排查.md) 对表处理；声学耦合与直连的差异，[SSTV收图入门.md](SSTV收图入门.md) 里也有交代。
