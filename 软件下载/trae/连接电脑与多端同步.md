# TRAE 移动端连接电脑与多端同步

> 把手机上的 TRAE 和电脑里的 TraeWork 桌面版配对后，你可以直接在手机上给电脑派任务、同步看进度。本篇整理官方的配对步骤、有效期与同步规则。
> **相关文档**：[移动端功能与用法.md](移动端功能与用法.md) · [常见问题解答.md](常见问题解答.md)

## 一、配对前备齐两样东西

- 手机装好 TRAE 移动端，电脑装好 TraeWork 桌面版（桌面版在 [www.trae.cn/download](https://www.trae.cn/download) 下载，支持 macOS 12+ 和 Windows 10/11）；
- 两端用**同一个手机号**登录。

## 二、配对步骤（按官方文档）

1. 手机上打开 TRAE 移动端，用手机号登录；
2. 在首页左下角点「任务运行环境」，弹出「选择任务运行位置」面板；
3. 点「连接我的电脑」；
4. 在电脑上打开 TraeWork 桌面版，确认用的是同一个手机号；
5. 电脑端进「设置 → TRAE 移动端」，打开「允许 TRAE 移动端控制当前设备」开关；
6. 在「仅必要内容会存储在云端」弹窗点确认——官方说明：为支持跨设备访问，对话内容和 AI 生成的产物（文档、代码变更等）会存云端；
7. 按提示授权移动端访问电脑的 `/documents` 目录；
8. 配对完成后，电脑会出现在手机的「选择任务运行位置」列表里，状态为「在线」，**有效期 180 天**；
9. 可选：打开「保持电脑处于唤醒状态」，任务执行期间电脑不会睡眠。

## 三、给电脑派任务时注意两点

- Work 与 Code 模式在电脑环境下都要先选一个产物文件夹；Code 模式在云端环境下则是选 GitHub 仓库和分支，两种模式的区别见[移动端功能与用法.md](移动端功能与用法.md)；
- 派给电脑的任务是本地任务，进度只在手机和那台电脑之间同步，网页版看不到。

## 四、有效期与断开处理

- 180 天到期后配对失效，按第二节步骤重新连一次即可；
- 换电脑、重装系统同理——重新走一遍配对流程，两端手机号一致是前提；
- 要派长时间运行的任务，先把「保持电脑处于唤醒状态」打开，避免电脑中途睡眠导致任务中断。

## 五、连不上 / 提示「服务异常」按这几步排查

官方支持在社区答复里给过一套排查顺序，按从常见到少见排：

1. 确认手机端与电脑端登录的是**同一个手机号**，且电脑端「设置 → TRAE 移动端」里的「允许 TRAE 移动端控制当前设备」开关处于打开状态；
2. **彻底退出**电脑端再重开——macOS 上只点窗口红叉时后台进程还在运行，等于没重启，要用 Command + Q 或在程序坞右键图标选「退出」；Windows 也从托盘图标退出再重开；
3. 提示「服务异常，请重试」时先换网络：切 Wi-Fi 或连手机热点；开着代理（VPN）或在公司内网时，先关代理或换普通网络再试；
4. 仍不行就把两端都退出登录、重新登录一次，再走一遍第二节的配对。

以上是官方账号针对当时版本的答复，具体菜单名以你手上的版本为准。

遇到登录或授权上的其他问题，看[常见问题解答.md](常见问题解答.md)。
