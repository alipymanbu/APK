## 一、移动端现在的定位

按官方文档（[docs.trae.cn](https://docs.trae.cn) 移动端快速开始）的说法，TRAE 移动端是一个跨设备的任务下发中心：操作界面在手机上，任务执行却可以在云端沙箱，也可以在你配对好的电脑上。你在手机上选目标设备和工作路径、下发指令，AI 智能体在对应环境里执行，进度和结果随时回到手机上看。

> 版本提示：网盘里的 1.0 是早期版本，形态与现在不同（见第五节）。本节到第四节按官方当前文档整理，具体界面以你手机上装的版本为准。

## 二、两种模式怎么选

| 模式 | 适合干什么 | 云端环境 | 电脑环境 |
| --- | --- | --- | --- |
| Work 模式 | 文档、数据、演示稿等非编码任务 | 直接在对话框输入指令发送 | 发送前先选一个存放 AI 产物的文件夹（可用已授权目录里现有的，也可新建） |
| Code 模式 | 编码、调试、代码库相关任务 | 发送前先选代码仓库和分支，需提前授权 GitHub | 同样先选产物文件夹 |

云端 Code 模式要先授权 GitHub 才能选仓库分支，授权入口见官方文档的 GitHub 集成页。

## 三、下发任务的一般流程

1. 用手机号登录移动端；
2. 在对话界面选好模式与运行环境（云端，或已配对的电脑）；
3. 点输入框左下角的「+」加上下文，可选项：相机（拍照）、照片（相册选图）、文件（从手机存储选，仅 Work 模式支持）、技能（选在桌面版和网页版里启用的技能）；
4. 输入指令（文字或语音）发送，等任务跑完。

云端执行的对话与任务都按积分计费，派任务前先弄清自己的免费额度，见[积分与会员套餐.md](积分与会员套餐.md)。

## 四、看进度、领结果

- **任务中心**：对话界面点左上角「<」进入，能看到当前账号的全部任务，可按「全部任务」「云端」「{设备名称}」筛选；
- **三端同步**：手机、桌面版、网页版用同一账号登录时，云端任务在三个客户端实时同步；电脑上跑的本地任务只在手机和那台电脑之间同步，网页版看不到；
- **产物预览**：支持预览文档、代码、Web 页面；注意移动端只能预览云端任务生成的 Web 页面，本地任务生成的网页要用桌面版或网页版看。

把任务直接派到自己电脑上跑，需要先做一次配对，步骤见[连接电脑与多端同步.md](连接电脑与多端同步.md)。

## 五、1.0 早期版本长什么样

公开资料对早期移动端（1.0 时期）的描述是：一个面向手机端的 AI 编程助手，提供对话模式（可选 DeepSeek R1 / DeepSeek V3、豆包 1.5-pro 等模型）与 Builder 模式（DeepSeek R1 / V3），手机号登录后直接使用。与现在的「任务下发中心」形态差别较大——具体功能与可选模型以你实际安装的版本界面为准，模型清单这类信息随版本调整，不要按早期资料去套用最新版。

使用中碰到登录、升级提示这类问题，先翻[常见问题解答.md](常见问题解答.md)。
