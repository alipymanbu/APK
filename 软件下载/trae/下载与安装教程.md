## 二、安装步骤

1. 打开 [TRAE 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2af8ccee5576)，把整个文件夹转存到自己的网盘；
2. 在手机夸克 App 里找到转存的文件夹，下载其中的 APK 文件（文件名形如 `trae_v1.0.apk`，以网盘里实际显示为准）；
3. 点开下载完成的 APK，系统若提示「禁止安装未知来源应用」，按提示去系统设置里允许夸克（或你的浏览器）安装应用——各品牌手机入口不同，一般在「设置 → 安全 / 隐私」附近；
4. 回到安装页继续，装完点「打开」，用手机号登录即可进入。

装完不知道能干什么，先看[移动端功能与用法.md](移动端功能与用法.md)。

## 三、想用最新版该去哪

- **应用商店**：手机自带应用商店搜「TRAE」，这是官方当前主推的获取方式；
- **官网**：[www.trae.cn/download](https://www.trae.cn/download) 提供 iOS 与 Android 两个移动端入口，也有桌面版与网页版；
- **iOS 注意**：官方文档明确提示，TRAE 应用未上架美区 App Store，美区 Apple ID 搜不到，需要换其他地区的 Apple ID。

两版的取舍：网盘里的 1.0 适合想固定用某个早期安装包的场景；日常使用建议直接装商店最新版——模型清单、积分政策这类会随版本调整的内容，以最新版和官方页面为准（积分与会员政策的细目整理在[积分与会员套餐.md](积分与会员套餐.md)）。具体差异见[常见问题解答.md](常见问题解答.md)。

## 四、装不上 / 打不开怎么排查

- **提示「解析包出错」**：多为下载不完整，重新下载一遍再装，装前可核对体积是否约 106 MB；
- **安装按钮点不动**：部分手机自带的「纯净模式 / 应用管控」会拦第三方安装包，在系统设置里临时放行后再装；
- **打开后要求升级**：1.0 是早期版本，服务端可能要求升级才能继续用，按提示去应用商店装最新版；
- **登录收不到验证码**：先核对手机号、换个网络环境再试；仍不行就换最新版重试。
