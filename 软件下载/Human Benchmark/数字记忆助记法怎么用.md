## 一、为什么 7 位是个坎

网页版的说法是普通人可靠记住的数字长度在 7 位左右——这也是心理学里「记忆组块」的经典口径。超过 7 位，靠逐位硬背基本到头，可行的路线是**把多位数字压缩成一个「组块」**：一个词、一个画面。网页版官方页推荐的三个体系里，最适合上手的是主佐记法（Mnemonic major system）。

## 二、主佐记法：数字变辅音

核心只有一张映射表——每个数字对应一组**发音相近的辅音**（按音不按字母拼写）：

| 数字 | 对应辅音 |
| --- | --- |
| 0 | s、z、软音 c |
| 1 | t、d、th |
| 2 | n |
| 3 | m |
| 4 | r |
| 5 | l |
| 6 | ch、j、sh、软音 g |
| 7 | k、硬音 c、硬音 g、q |
| 8 | f、v、ph |
| 9 | p、b |

三条使用规则：

- **元音和 h、w、y 不算数**，可以随便加进来拼词；
- **只看发音不看拼写**：`action` 的 c 发 k 音、t 发 sh 音，编码是 762 而不是 712；
- **不分开读的双写辅音只算一次**：`muddy` 是 31 而不是 311。

举例（维基百科条目里的原例）：圆周率 3.1415927 可以编成三个词——`meteor`（314）、`tail`（15）、`pink`（927），想象「一颗流星拖着尾巴砸进粉色颜料」，三段画面比一串数字好背得多。

## 三、套进测试里的用法

1. 数字串出现后**先按 3–4 位切组**，每组用映射表转成一个词；
2. 把几个词**串成一句荒诞画面**——越离谱越难忘；
3. 数字隐去后，心里过一遍画面，**按词反推出数字**再输入；
4. 输入节奏跟不上就先输前半段、默诵后半段的词。

一个现实提醒：**现编词来不及**。测试里数字只出现几秒，临场从 729 现想单词反应不过来。可行的做法是平时把两位数组合（00–99）各备一个固定词，测试时直接取用，这套「固定挂钩词」的思路在记忆法体系里叫 peg system，维基百科的主佐记法条目里有对应的词表可参考。

## 四、预期管理

- 前几次测试分数**可能不升反降**——编码本身要花时间，生疏期正常；
- 熟练后收益是阶梯式的：7 位以上每多突破一组，成绩就上一个台阶；
- 助记法解决「记得住」，解决不了「读得快」——分组读数的基本功（见 [提高成绩的技巧.md](提高成绩的技巧.md) 第三节）仍然要先打底。

练到什么算有效果，参考 [成绩参考标准.md](成绩参考标准.md) 第三节的口径：隔几天重测，稳定上行才算数；还没装上的从 [Human Benchmark 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9a7b85e9c416) 取安装包。
