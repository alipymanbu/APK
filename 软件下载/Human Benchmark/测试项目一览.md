## 一、八个测试对照表

| 项目 | 玩法 | 结束条件 | 成绩 |
| --- | --- | --- | --- |
| 反应时间 Reaction Time | 红色方块变绿的瞬间尽快点击 | 连续测 5 次 | 5 次的平均毫秒数 |
| 序列记忆 Sequence Memory | 记住按钮亮起的顺序，再按同样顺序点一遍 | 点错一次 | 走到的最长序列长度 |
| 瞄准训练 Aim Trainer | 目标出现后尽快点中 | 击中 30 个目标 | 总用时与平均每个目标的毫秒数 |
| 数字记忆 Number Memory | 记住屏幕上的数字串并输入，每轮加长一位 | 输错一次 | 记住的最大位数 |
| 词语记忆 Verbal Memory | 逐个出词，见过的点 SEEN、没见过的点 NEW | 累计失误 3 次 | 坚持的轮数 |
| 黑猩猩测试 Chimp Test | 数字在格子里闪现后隐去，按 1→N 的顺序点出位置 | 失败 3 次 | 通过的最大数字数 |
| 视觉记忆 Visual Memory | 方块闪白后记住位置，方块隐藏后把它们点回来 | 一关错 3 块掉 1 条命，共 3 条命 | 到达的关卡 |
| 打字 Typing | 把屏幕给出的文本照着打完 | 打完全文 | WPM（字数/分钟）× 准确率 |

几点说明：

- 反应时间测 5 次取平均，是为了抵消单次的运气成分，别因为第一次紧张就下结论；
- 序列记忆、数字记忆是「一错就结束」，词语记忆、黑猩猩测试、视觉记忆都给了容错（3 次失误或 3 条命），前者拼爆发、后者拼持久；
- 打字成绩把准确率直接乘进 WPM 里，打错一个词比慢半拍扣得多。

## 二、哪些项目在手机上受限

这套测试里有两个项目原本是给键鼠设计的：

- **瞄准训练**：网页版明确说明用鼠标或平板屏幕体验最好，触控板很难打出好成绩；手机上用手指点按，成绩口径和鼠标玩家不同，横向比较意义不大；
- **打字**：需要实体键盘，网页版会直接提示你换桌面设备；手机上就算有虚拟键盘，测的也不是通常意义上的「打字速度」。

剩下的反应时间、四项记忆类测试都是「点按」为主，手机竖屏点按反而顺手，这也是手机版最适合的场景。详细取舍见 [网页版与手机版对比.md](网页版与手机版对比.md)。

## 三、测完的成绩在哪看

每项测完界面会直接给出本次成绩。网页版还支持注册账号后保存历史记录（反应时间测满 5 次就能存档），App 内的记录方式以你手上的版本界面为准。

想把成绩测准再谈好坏，下一步可以直接翻 [成绩参考标准.md](成绩参考标准.md)；看完觉得自己反应偏慢或者数字记不住几位，[提高成绩的技巧.md](提高成绩的技巧.md) 里按项目给了练法。
