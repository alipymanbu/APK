## 一、定位：搭档，不是替代

对这个问题，官方常见问题页（[miidii.tech/blog/faq](https://www.miidii.tech/blog/faq)）的原话口径是「系统屏幕使用时间的完美搭档」——它不试图替代系统功能，而是补上系统做得粗、做不了的部分。两者不是二选一的关系。

## 二、能力对照

| 能力 | 系统屏幕使用时间 | OffScreen |
| --- | --- | --- |
| 使用总时长统计 | 有，系统级 | 有，与系统误差官方口径在每天 15 分钟内 |
| 拿起次数、平均查看时长等细分维度 | 部分系统提供 | 有，维度更细（第一次拿起 / 最后放下 / 最长锁屏 / 最长连续使用 / 睡眠时长） |
| 每日动态时间轴 | 一般没有 | 有，按动作回放一天 |
| 提醒（连续使用 / 拿起次数 / 熬夜 / 日报周报） | 少量系统提供基础项 | 五类提醒都可设 |
| 应用限额 | 有（部分系统支持密码保护） | 有，安卓国内版到限额后禁止使用 |
| 专注计时（番茄钟 / 倒计时 / 时间累加） | 没有 | 有，含白名单、标签、白噪音 |
| 数据卡片分享 | 没有 | 每日 / 每周总结与专注卡片 |

一句话概括分工：**系统负责「管住」，OffScreen 负责「看清 + 提醒 + 专注」**。

## 三、怎么搭配用

两边的强项互补，实操上这样分工最省心：

1. **硬约束交给系统**：对孩子设备或自控力极差的时段，用系统屏幕使用时间设应用限额并配密码——系统层的限制最难绕过；
2. **自我管理交给 OffScreen**：统计数据用来看清习惯（见 [屏幕使用数据怎么看.md](屏幕使用数据怎么看.md)），提醒挑战用来戳破无意识刷手机（见 [提醒挑战与应用限额怎么设.md](提醒挑战与应用限额怎么设.md)），专注计时用来完成学习与工作任务（见 [专注计时怎么开始.md](专注计时怎么开始.md)）；
3. **两者同时开着不冲突**：应用限额这一层两边可以并存，谁先触发算谁的。

## 四、别和 iOS 版搞混

应用商店里还有一款「OffScreen - 自律番茄钟，不做手机控」，是同一家开发者（杭州谜底科技 / MD Studio）的 iOS 版本，界面与功能同源但细节不同（iOS 版有 StandBy、Apple Watch 等平台特性）。搜索资料时注意区分平台，安卓机上认准包名 `tech.miidii.offscreen_android.domestic` 的国内版安装包——从 [下载与安装教程.md](下载与安装教程.md) 的网盘资源获取即可，装好后按 [后台被杀数据不准怎么排查.md](后台被杀数据不准怎么排查.md) 把权限与保活设置好，统计数据才能跑准。
