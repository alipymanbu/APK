## 一、先看哪几个数

OffScreen 首页给出的不是单一「屏幕时间」一个数，而是一组互相印证的维度。每个数的读法不一样：

| 维度 | 怎么读 |
| --- | --- |
| 每日拿起次数 | 次数很多、单次很短，说明你是在「无意识确认」，其实并没多少新消息 |
| 平均查看时长 | 配合拿起次数看：次数少但每次很长，是深度刷；次数多每次几秒，是习惯性点亮 |
| 第一次拿起时间 | 你的一天实际从几点开始摸手机 |
| 最后一次放下时间 | 睡前刷了多久的一个参考锚点 |
| 最长锁屏时长 | 最长一次没碰手机的时间段，专注做得好不好看它 |
| 最长连续使用 | 最长一次不间断亮屏，对应护眼与作息风险 |
| 睡眠时长 | 按昨晚最后一次锁屏到今早第一次拿起推算的区间 |

官方常见问题页（[miidii.tech/blog/faq](https://www.miidii.tech/blog/faq)）给出的准确度口径是：权限开齐、应用没被强行退出的正常使用下，OffScreen 与系统屏幕使用时间的数据误差每天不超过 15 分钟。数字明显超出这个范围时，按 [后台被杀数据不准怎么排查.md](后台被杀数据不准怎么排查.md) 处理。

## 二、每日动态：时间轴回放

统计页里的「每日动态」用时间轴展示你一天内每次拿起与放下的动作，精确到每次持续多少秒。想知道「我的时间到底碎在哪」时看这个最直观：早上通勤、午休、睡前是三段典型的高频亮屏时段，对着时间轴能对出自己的固定习惯。

## 三、按周、月、年回看

日数据之外，OffScreen 支持按一周 / 一个月 / 一年三个维度回看历史：

- **周视图**：看七天里哪天最失控、哪天管得最好；
- **月视图**：适合检验一个「少玩手机」的决定坚持了多久；
- **年视图**：长周期趋势，变化慢，不必天天看。

专注类的数据也单独汇总：累计专注时间、失败次数、各标签（学习 / 工作 / 阅读等自定义标签）的周 / 月 / 年专注时长，都能分别查看。

## 四、每日总结与每周总结卡片

每日总结会汇总当天的屏幕使用情况并与前一天对比；每周总结计算一周中每天的平均使用时长并与前一周对比。两张卡片都可以直接生成图片分享或保存。把它们当成复盘的仪式感来用：每天睡前看一眼日报，周日看一眼周报，比天天盯实时数据更有用。

商店收录页还提到支持桌面小组件，把使用时长与专注数据直接放到桌面上看（以你手上的版本实际提供为准）——不想为瞄一眼数据专门点开应用的话，加一个小组件最省事。

## 五、看到数据之后怎么办

数据只是第一步，真正减少使用靠两件事：给自己上提醒与限额（见 [提醒挑战与应用限额怎么设.md](提醒挑战与应用限额怎么设.md)），以及在需要专注的时段用它的计时器把手机扣下（见 [专注计时怎么开始.md](专注计时怎么开始.md)）。它与系统自带屏幕时间的分工差异，见 [和系统屏幕使用时间有什么区别.md](和系统屏幕使用时间有什么区别.md)。
