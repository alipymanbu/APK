## 一、这一篇讲什么

录音是 AudioLab 里参数最集中的一个入口：点开始之前，会先让你把文件名、用途、声道、采样率、格式一次定好。这些参数选错，轻则文件白录、重则存不到系统里。本篇把每个参数讲清楚，顺带解决「录一半自己停了」这个最高频的坑。

## 二、点「录制音频」后先出一个弹窗

主界面点 **录制音频**（麦克风图标），允许麦克风权限后，先看到参数弹窗：

| 字段 | 常见取值 | 说明 |
| --- | --- | --- |
| 输入文件名 | `AudioLabRecording_20-05-24_16-28` 这类 | 默认按「日期_时间」生成，可自己改，改了好找 |
| 使用为 | 音乐 等 | 决定录完归到哪一类；要当铃声/音乐用就保持「音乐」 |
| 源 | DEFAULT | 录音输入源，一般不动；设备接了多个输入时在这里切 |
| 通道 | 立体 / 单 | 立体声文件更大，纯人声记录用「单」就够 |
| 采样率 | HZ_44100 | CD 级采样率，常规录音保持默认即可 |
| 音频格式 | WAVE / MP3 / AAC / M4A | WAVE 体积大但无压缩，MP3 体积小方便分享 |

选好点 **开始** 录制，录完点停止；录完的文件可以直接进剪辑界面掐头去尾（见 [剪裁音频与制作铃声.md](剪裁音频与制作铃声.md)）。

## 三、设置页里的输出默认值

左上角菜单 → **设置**，与录音、导出相关的几项：

- **输出默认音频格式**：WAV / MP3 二选一，外加 **音频比特率**（默认 128 kbps）与 **音频采样率**（默认 HZ_44100）。这里定的是之后每次导出的默认值，剪辑完保存时不用再逐次挑。
- **主题**（dark 等）与 **更改语言** 在同一页。

**采样率和比特率怎么选**，记住两条就够：

| 你录的是 | 建议 | 理由 |
| --- | --- | --- |
| 人声、会议、语音备忘 | MP3 + 128 kbps | 体积小，语音听清绰绰有余 |
| 音乐、要二次剪辑的素材 | WAVE，或把比特率调高一档 | 留足余量，反复编辑不掉质 |

比特率越高文件越大，这是硬币两面；采样率则要**全程保持一致**，剪辑、转换时换来换去只会白增体积或丢细节。

## 四、录一半断了：把电池优化关掉

这是最容易被当成 bug 的现象：锁屏或切到后台，录音停了，切回来发现后半段没有输出。设置页里自己写明了原因 —— 电池优化会让它在后台无法工作，导致录制意外停止、后台没有输出创建。改法：

1. 打开 **设置 → 让 AudioLab 在后台运行**，按页面给的路径操作：**电池 → 管理电池使用 → 无限制**（不同品牌机型路径略有差异，有的在「电池优化」列表里把它改成「不允许优化」）。
2. 录音前顺手把屏幕常亮打开、别手动清后台，双重保险。
3. 改完录一段长的验证：锁屏放两分钟再回来看波形是否连续。

录完怎么处理文件、常见故障怎么排，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
