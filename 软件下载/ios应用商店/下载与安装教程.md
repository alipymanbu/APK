## 一、装之前，先确认你要装的是什么

它是一个**安卓 APK**，不是 iPhone 上那个 App Store，两者的关系见 [与苹果官方商店的区别.md](与苹果官方商店的区别.md)。安装文件的固定信息如下（以这组数值为准，网上下载站标注的版本可能不同）：

| 项目 | 数值 |
| --- | --- |
| 版本 | 3.0.0 |
| 包名 | `com.yfzy.appstore` |
| 安装包大小 | 15.15M |
| MD5 | `a87c56791f9346ac244b0d22ddbd3acc` |

这组数值同时是核对依据：从网盘下载到的 `.apk` 大小应为 15.15M 左右，用电脑上的校验工具算 MD5 应与上表一致；对不上说明包不完整或不是这一个包，别继续装。

## 二、拿到安装包

1. 打开 [ios应用商店 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d3deabe8705e)，把应用文件夹转存到自己的网盘；
2. 在网盘里找到 `.apk` 文件下载到手机（或先下到电脑再传到手机）；
3. 下载完成后按第一节的表格核对大小与 MD5。

网盘里的文件夹名带「（先保存再下载）」字样，这是提醒你先转存再下载 —— 分享链接可能被取消，转存到自己网盘后就不再依赖原分享。

## 三、开启「安装未知应用」权限

安卓不允许应用商店以外的来源直接装 APK，**必须先授权，否则点安装包会被系统拦下**。授权入口随安卓版本不同：

| 系统 | 路径 |
| --- | --- |
| Android 8.0 及以上（原生） | 设置 > 应用和通知 > 特殊应用权限 > 安装未知应用 |
| Android 7.1.1 及以下 | 设置 > 安全 > 未知来源 |
| ColorOS 12 / realme UI 3.0 及以上 | 设置 > 密码与安全 > 系统安全 > 外部来源应用（安装未知应用） |
| 小米 MIUI / HyperOS | 设置 > 隐私保护 > 权限管理 > 安装未知应用（以实际菜单为准） |
| 三星 One UI | 设置 > 生物识别和安全性 > 安装未知应用（以实际菜单为准） |

两个关键点：

1. **Android 8 之后是「按应用授权」**：你要用哪个应用发起安装（浏览器、文件管理器），就给哪一个开权限，不是一个全局开关；
2. 授权对象也包括**本应用自己** —— 你用它下载的应用同样要它有这个权限，第一次下载时系统会弹同样的提示，照上面的路径打开即可。

## 四、安装与首次打开

1. 在文件管理器里点开下载好的 `.apk`；
2. 若弹出「禁止安装未知应用」之类提示，按提示跳到设置页，给来源应用授权后返回重试；
3. 点「安装」，等进度走完；
4. 打开后它会请求网络与存储等权限 —— 下载应用必须联网、保存安装包必须写存储，按需允许即可；不想给的权限可以之后在设置里单独关。

装完可在 设置 > 应用 > 找到该应用 的信息页核对版本是否为 3.0.0，与第一节表格对上就说明装的是同一个包。

## 五、装完建议收一下权限

下载功能用完后，可以把第三节里给来源应用开的「安装未知应用」权限关掉（路径相同，关掉开关即可），需要再下载时重新打开。这是安卓上比较稳妥的日常用法：权限随用随开，不用就收。
