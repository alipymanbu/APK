## 一、先看这三样信息

反馈问题或自己排查前，先把这三样对齐，八成的问题都能归到其中一类：

1. **安装包本身**：大小应为 15.15M、MD5 应为 `a87c56791f9346ac244b0d22ddbd3acc`、版本 3.0.0（包名 `com.yfzy.appstore`）；
2. **系统权限**：「安装未知应用」是否已给对应来源应用授权；
3. **网络与存储**：当前网络能否正常打开网页、手机剩余空间是否大于待下载体积。

## 二、症状对照表

| 症状 | 多半是这个原因 | 处理动作 |
| --- | --- | --- |
| 点安装包提示「禁止安装 / 未知来源」 | 系统没给来源应用授权 | 按 [下载与安装教程.md](下载与安装教程.md) 第三节的路径打开对应开关，返回重试 |
| 弹「安全提醒 / 纯净模式 / 检测到风险应用」 | 系统安全审核拦截（不是权限问题） | 按品牌走放行路径，见 [系统提示有风险不让安装怎么办.md](系统提示有风险不让安装怎么办.md) |
| 安装时提示「解析出错 / 应用未安装」 | 包不完整或损坏 | 重新下载，下载后核对 15.15M 与 MD5 再装 |
| 打开就闪退 / 停在启动页 | 安装不完整，或存储、网络权限没给 | 设置 > 应用 > 该应用 > 先「强行停止」再「清除数据」，重新打开；仍闪退就卸载后重装 |
| 里面下载应用时一直转圈、没进度 | 网络不通或存储空间不足 | 换一个网络（Wi-Fi / 流量）各试一次；清理出大于目标应用体积的剩余空间 |
| 下载完成但装不上（弹未知来源提示） | 它自己没有安装权限 | 把「安装未知应用」权限授给**它自己**（不是给浏览器），路径同上 |
| 下载完找不到文件 | 存储路径不清 | 用文件管理器按应用名搜索；或在它的下载列表里查看记录 |
| 搜得到、点下载没反应 | 单条资源问题 | 换个同类应用试：能下说明只是这条资源异常，稍后再试或换个版本 |

## 三、排除顺序（从最常见到最少见）

1. **权限**：先确认「安装未知应用」已授权 —— 安装商店类应用的问题里这是最高频的一项；
2. **网络**：换网络重试一次，排除当前网络对下载域名不通；
3. **存储**：剩余空间按安装包体积的 **3 倍**预留 —— 安装时系统要解压，华为官方说明的口径是「预留安装包 3 倍以上的空间」；下载阶段至少留 1.5 倍；
4. **包**：重新下载安装包并核对大小、MD5 —— 只有这一项对不上，才需要去动安装包；
5. **重装本体**：以上都排除后，卸载重装本应用（数据不重要的情况下），这一步放在最后是因为要重来一遍安装流程。

## 四、还是解决不了时

把这四样整理好再去找人问或去对应渠道反馈：**机型与系统版本**、**本应用版本号**（设置里查，应为 3.0.0）、**卡在哪一步的截图**、**第几节对照表里的哪个症状**。信息齐了，问题基本能一次定位；缺了这些，来回补问会多花好几轮。
