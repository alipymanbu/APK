## 一、模板的两种来源：预设与自定义

QNET 里你点「启动」时选的那个东西就是**弱网模板**，它决定了被测应用跑在什么样的网络下。模板有两条来路：

- **系统预设模板**：在【网络场景】切页里，覆盖常见的 2G/3G/4G 网络模板、100% 丢包、断线重连、WiFi 与 4G 切换这类常用项。点模板右下角的【添加】，编辑保存后就进到你的【工作台】。注意**预设模板不能编辑**（可以删除），要改参数就基于它另存一份自定义的。
- **自定义模板**：【工作台】或【网络场景】右上角的【新增】按钮 → 模板类型选【自定义模板】，自己组合参数。这是真正做专项测试时的主力。

新增入口还有一个快捷路径：【网络场景】页每项推荐模板的【添加】按钮 → 进入编辑 → 保存，等于把别人的参数抄一份到自己名下再改。

## 二、场景模板：按真实环境一键配

模板类型选【场景模板】时，你不用填具体参数，只要描述「我要哪种真实环境」：

- **网络选择**：客户端所处地区、服务器所处地区、运营商类型、网络类型（还有一份【场景模板(全球)】，覆盖海外地区）。
- **场景选择**：电梯、地铁、高铁、地下停车场、WiFi 穿墙、视频网络标准、语音网络标准等 —— 这些是官方按真实环境测出来的网络波形，一键模拟。
- 最后填个【模板描述】，点右上角【保存】。

适合「我就想看看这 App 在地铁里什么表现」这种按场景验收的需求。要精确控制某个参数（比如固定 300ms 延时 + 5% 丢包），就得用自定义模板。

## 三、自定义模板参数逐项说明

自定义模板里可填的参数如下（这是本篇核心，填之前先知道每个值到底在控制什么）：

| 参数 | 单位 | 控制什么 |
| --- | --- | --- |
| 网络带宽 | kbps | 限制上下行最大带宽容量。例：限 1024kbps 后，下载速度只剩 128KB/s 左右 |
| 网络延时 | ms | 上下行延时约等于设置值 |
| 延时抖动 | — | 对每个包按概率做抖动，延时在 0 ~ 抖动值之间随机产生 |
| 随机丢包 | % | 按概率对每个包丢弃 |
| 连续丢包 | — | 成段丢包，可做出周期性断网的效果 |
| 周期弱网 | — | 按「放行时长 / 弱网时长」交替切换，弱网期内按所选类型生效 |
| 协议控制 | — | 只对指定协议生效，支持 TCP / UDP / ICMP / DNS |
| 弱网 IP | — | 只对指定 IP 生效，多个 IP 用竖线 `\|` 分隔 |

几个用得最多的参数，展开说：

**延时与抖动怎么配合**。只填延时是「恒定慢」，真实弱网更常见的是「一会儿快一会儿慢」—— 延时填个基线（如 200ms），抖动再填一个幅度（如 300ms），包的实际延时会在 0~300ms 间随机浮动，波形就活跃起来了。QNET 会动态探测你当前网络到远端服务器的真实延迟，再叠加你设置的上下行延迟，尽量让实际延迟贴近设定值 —— 所以在好网络下测出来的数值不会和你填的完全一样，属正常。

**随机丢包 vs 连续丢包**。随机丢包是每个包独立掷骰子，模拟「信号差但还通着」；**连续丢包可以做出周期性断网**，常用在测游戏流畅性、验证 App 对网络波动的恢复能力（断一下 → 恢复 → 再断）。周期弱网的两种弱网类型：

- **完全丢包**：弱网时长内的包直接丢掉，等于那段时间断网；
- **Burst**：模拟路由器在判断网络不通时把包存起来、网络一恢复就爆发式推出去 —— 你会看到恢复瞬间一波延迟尖峰，很多 App 的「重连后卡一下」就是这个引起的。

**协议控制是干什么的**。比如你只想让 UDP 100% 丢包，验证 App 在不支持 UDP 的运营商网络下的表现，而 TCP 不受影响 —— 把协议选成 UDP、丢包填 100 即可。协议类型支持 TCP、UDP、ICMP、DNS。

**填参数的一般套路**：先只改一个参数看效果，定位问题后再叠加。一次性把延时、丢包、限速全拉满，出了问题你分不清是哪个参数造成的。

## 四、模板的改、删、查

在【工作台】切页上管理已有模板：

- **更新**：点模板右侧文字进编辑页，改完保存；
- **删除**：在模板上向左滑，出现【删除】按钮；
- **查找**：模板多了以后，用上方搜索框按名称关键字过滤。

改完模板不影响正在跑的弱网 —— 要让新参数生效需要重新启动，或者直接用 adb 的 update 指令热更新（见 [adb命令自动化弱网测试教程.md](adb命令自动化弱网测试教程.md)，注意它是**全量更新**，没写的参数会被重置为默认值）。

## 五、把模板跑起来

模板备好后，回【工作台】：启动栏左侧选应用（可选单个应用，也可选【全部应用】做设备全局弱网）→ 点选刚建的模板 → 点【启动】。首次点启动会要悬浮窗和 VPN 两个权限，流程见 [下载与安装教程.md](下载与安装教程.md)。启动之后测试中怎么暂停、怎么临时切模板，看 [悬浮窗控制与抓包导出教程.md](悬浮窗控制与抓包导出教程.md)。
