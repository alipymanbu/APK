## 一、游戏打不开

按顺序过一遍，多数问题停在前两步：

1. **文件解压对了吗**：游戏必须解压成文件夹（模拟器不认 `.zip/.7z/.rar`），且用支持对应格式的解压软件；漏解的典型表现是双击没反应或报缺 DLL。
2. **路径放对了吗**：ET 版认 `内部存储/ExaGear/`，ED 版认 `内部存储/Download/`，放错位置模拟器里根本看不到文件。进游戏后如果路径选择器出错，把整个游戏文件夹复制进**模拟器的 C 盘**再运行（见第 4 条）。
3. **游戏包完整吗**：部分游戏包里带 `filecheck.exe`，双击跑一遍，结果**全绿**才算完整；有非绿色项就重新下载或修复该游戏包。
4. **Android 7 以上的路径兼容问题**：这个系统段上模拟器的文件选择器可能选不准路径，绕开办法是把游戏直接复制到模拟器虚拟出来的 C 盘（进入环境后的 `C:` 盘符对应目录）里运行；若属于模拟器自身的 bug，升级到更新版本的构建能改善。
5. **别装到 SD 卡**：设备报存储错误时应用无法装到 SD 卡——清理内置存储、重启，或在设置里把应用移回内部存储。

## 二、一打开就闪退

闪退基本是运行环境没就位，按 [下载与安装教程.md](下载与安装教程.md) 第四节核对：

- 根目录有没有 `bass.so`（必须在内置存储**根目录**，不能在子文件夹）；
- `Android/obb/com.eltechs.ed/` 下有没有数据包；
- 首次启动的解包是否被打断——被打断就删掉残留数据重来一遍，解包过程别锁屏。

## 三、3D 游戏卡顿或跑不动

- 纯 2D 老游戏对手机没什么压力；**3D 游戏（走 DirectX 9 一类）要专门的 D3D 运行版本**，且对 CPU 要求高——非旗舰芯片（当年的骁龙 8 系或麒麟 970 以上才比较稳）很容易严重卡顿。
- 卡顿时先调低环境里的分辨率、把色深降到 16 位，再关掉后台应用重试。
- 需要 DirectX 10 及以上的游戏跑不了；64 位游戏也一律跑不了，边界见 [能玩哪些游戏与配置要求.md](能玩哪些游戏与配置要求.md)。

## 四、能打开游戏但玩不了：画面、输入、报错

| 症状 | 先试这几步 |
| --- | --- |
| 光标点不准 / 手势不灵 | 换控件包（通用的 oxygen 最稳），见 [触摸操作与虚拟键盘设置.md](触摸操作与虚拟键盘设置.md) |
| 调不出虚拟键盘 | 检查「显示在其他应用上层」权限是否给了、后台限制是否解除 |
| 进游戏要输名字但看不见字 | 属于字库缺失的常见现象：随便敲，敲完点弹窗左边的方框确认即可 |
| 双击 exe 报错 / 闪退 | 先确认该游戏有人在同版本上跑通过；试 32 位运行环境、试调分辨率，逐步排除 |
| 部分按键没反应 | 挖屏幕左右边缘的隐藏热键，或换用带侧边键盘的启动方式 |

## 五、还没解决怎么办

单个游戏能不能跑，很大程度取决于游戏本身——先把「文件完整性、路径、分辨率、控件包」四个变量各试一轮，再缩小范围查具体报错文字。若同一台手机上**别的游戏能跑、只有这一个不行**，问题基本在游戏包本身而非模拟器；反过来，所有游戏都闪退，回头重走一遍安装与数据准备（[下载与安装教程.md](下载与安装教程.md)）。
