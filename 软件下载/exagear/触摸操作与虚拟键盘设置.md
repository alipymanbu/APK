## 一、默认操作：手指就是鼠标

ExaGear 里游戏画面是原封不动的 PC 画面，操作靠覆盖在上面的虚拟层：单指拖动移动光标、点击 = 左键，具体手势取决于你选的**控件包**（下一节）。选「带侧边鼠标键盘启动」时，屏幕边缘会多出一排按键（`ESC`、方向键、输入切换之类），游戏内要按的键优先从这里找。

## 二、控件包怎么选

不同游戏适合不同的控件包，进游戏前在操作模式里选（各版本菜单名略有差异）。社区常用的几套与其对应的游戏类型：

| 控件包 | 惯用场景 |
| --- | --- |
| ferrum | 《辐射》1、2 这类需要频繁点选的 RPG |
| magnesium | 《魔法门》6/7/8 这类回合制 RPG |
| alluminium | 《铁血联盟 2》这类战棋 |
| argentum | 《奥秘》这类界面按键多的 RPG |
| oxygen | 通用兜底：相对位移触摸 + 左侧热键，什么游戏都能用 |

几点通用经验：

- argentum 这类包里**长按分两种模式**（默认长按 = 右键；切到附加模式后长按 = 长按左键），当前模式会显示在画面右上角的指示灯上，点指示灯即可切换。
- 部分控件包在屏幕左右边缘藏了热键，找不到按键时先摸一下屏幕边缘。
- 选错了随时能换：退出游戏回环境/启动选项里重新选操作模式即可，不改动游戏文件。

## 三、虚拟键盘怎么调出来

玩需要大量输入的游戏（起名、聊天、输命令），要靠悬浮虚拟键盘。常见做法是配合 InputBridge 这类悬浮输入工具：

1. 把 InputBridge 数据解压到一个好找的文件夹。
2. 打开 ExaGear，并允许它「显示在其他应用上层」（悬浮窗权限）。
3. 在 ExaGear 界面里点 `import`，选中刚才解压的 InputBridge 文件，语言选中文。
4. 在系统设置里**不要限制它后台运行**，整个过程别把软件清掉。
5. 回到 ExaGear，点右上角齿轮图标，点那个眼镜形状的图标，虚拟键盘就浮出来了。

若你装的包自带键盘切换键（侧边栏里的输入条按钮），优先用自带的——少一层依赖。

## 四、外接键鼠与手柄

手机连上蓝牙或 OTG 键盘、鼠标后，ExaGear 直接就能识别：键盘敲字、鼠标移动都会被游戏接收，外接手柄按键也能映射进游戏。屏幕小、触摸点不准时，接一套键鼠是最直接的解法——尤其是即时战略这类要框选、狂点的游戏。

触摸不灵、按键调不出来这类故障，多半和悬浮权限或控件包选择有关，排查见 [常见问题与解决办法.md](常见问题与解决办法.md)。
