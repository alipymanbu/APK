# ExaGear 下载与安装教程

> 讲怎么把 ExaGear 装进安卓手机并完成首次启动前的数据准备（APK、OBB 数据、`bass.so`）。

## 一、装之前先确认三件事

1. **处理器必须是 ARM 架构**（ARMv7 带 NEON 及以上）。ExaGear 是把 x86 指令翻译成 ARM 指令来跑的，Intel x86 平台的安卓老设备反而不支持，这点官方说明里写得很明确。
2. **系统建议 Android 5.0 及以上**。ExaGear 各系列里较新的版本（Strategies 3.1.9+、RPG 2.6.8+、Windows Emulator 1.0.1b+）都要求 Android 5+，更早的老版本才兼容 Android 4。
3. **留足存储空间**：本篇用到的这份包 APK 就有 63.54M，装完还要放运行数据与游戏本体，游戏动辄几百 MB 到几 GB，先把手机内置存储清出几 GB 再动手。

另外要心里有数：ExaGear 只能跑 **32 位 x86 的 Windows 程序**，64 位程序一律不行（详见 [能玩哪些游戏与配置要求.md](能玩哪些游戏与配置要求.md)）。

## 二、拿到安装文件

安装需要三样东西：**ExaGear 的 APK**、**运行数据包（OBB）**、**`bass.so` 动态库文件**。

- APK：[ExaGear 安装文件资源（夸克网盘）](https://pan.quark.cn/s/561282c37c32)
- 运行数据与 `bass.so`：通常随附在同一批资源的压缩包里（常见命名如 `main.31.com.eltechs.ed.obb`、`Edfix` 之类的数据压缩包），解压后按下面第四节放置。

本篇涉及的安装包事实（以这份文件为准，网上搜到的官方最新版未必是它）：**版本 3.5.0，包名 `com.eltechs.et`，大小 63.54M，MD5 `501f2dca3199cddc4bb3b5b19e895a22`**。下载完可以算一下 MD5，对得上说明文件完整。

## 三、安装 APK

1. 把 APK 文件拷到手机上，点开安装。
2. 系统会提示「禁止安装未知来源应用」——需要在设置里允许本次安装：Android 8 及以上在「设置 → 应用 → 特殊应用访问 → 安装未知应用」里给你的文件管理器开权限；Android 7 及以下在「设置 → 安全」里打开「未知来源」。
3. 装完**先不要急着打开**，先把数据放好（下一节）。

## 四、补齐运行数据（OBB 与 bass.so）

ExaGear 本体只是个外壳，真正的运行环境在数据包里。两步：

1. **OBB 放到固定目录**：把数据包解压，得到的 `com.eltechs.ed` 文件夹（里面是 `main.xx.com.eltechs.ed.obb`）整个移动到：

```text
内部存储/Android/obb/com.eltechs.ed/
```

文件夹不存在就手动新建。注意目录名是 `com.eltechs.ed`——即使你装的 APK 包名是 `com.eltechs.et`，多数社区数据包仍按 `com.eltechs.ed` 这个路径放，两者不冲突；如果安装包根目录有自己的提示，以提示为准。

2. **`bass.so` 放到存储根目录**：把压缩包里的 `bass.so` 文件移动到手机内置存储的**根目录**（也就是一打开文件管理就能看到的那一层，不能在任何子文件夹里）。ED/ET 变体闪退多半就是这个文件没到位。

Android 11 及以上访问 `Android/obb` 可能被系统拦，换一个支持该路径的文件管理器（如 MiXplorer、Solid Explorer）操作，必要时用「显示内部存储」后再进。

## 五、首次启动

1. 打开 ExaGear，首次启动会解包运行数据，**耐心等几分钟，过程中别退后台、别锁屏**。
2. 解包完成后进入主界面；如果一进去就提示缺数据或直接闪退，退出后回头核对第四节的两个路径，再重开。
3. 部分整合程度高的包首启就能直接进主界面——那说明数据已内置，第四节做过的步骤也不冲突，跳过即可。

进主界面后，安装就算完成了。接下来怎么建「环境」、把游戏放进去并跑起来，见 [游戏添加与启动教程.md](游戏添加与启动教程.md)；遇到卡死、闪退、游戏打不开，见 [常见问题与解决办法.md](常见问题与解决办法.md)。
