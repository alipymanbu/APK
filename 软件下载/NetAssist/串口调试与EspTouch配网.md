## 一、这两个功能是给什么场景用的

NetAssist 的主战场是 TCP/UDP，但做硬件联调时经常顺手用到另外两项（均来自其开源仓库 README 的功能清单）：

- **Serial（串口）**：手机通过 OTG 线接 USB 转串口适配器，直接和设备的串口对话；
- **Esp Touch（配网）**：给 ESP8266 / ESP32 一类 Wi-Fi 模块下发路由器名称与密码，省去逐台手动配置。

两项都不是装机即用，各自要先备好外围条件，下面分别说。

## 二、串口调试的接法

你需要：一根 OTG 线（或 Type-C 直转 USB-A 的转接头）+ 一个 USB 转串口适配器（如 CH340、CP210x 这类常见芯片的小板）。

1. 用杜邦线把适配器的 TX/RX/GND 接到目标设备串口（TX 接 RX、交叉相接）；
2. OTG 线把适配器接到手机，手机弹出「是否允许应用访问 USB 设备」时点允许；
3. 在 NetAssist 里新建串口连接，选对串口设备与波特率（双方波特率必须一致，常见的有 9600、115200）；
4. 打开后即可收发，格式同样支持文本与十六进制。

注意事项：

- 适配器芯片种类多，手机是否认得出来取决于驱动支持范围，常见主流芯片一般没问题，冷门芯片以实际插入结果为准；
- 部分工程机型自带的物理串口也可以调，但这类口在不少机型上受系统限制（可能需要 root），能否用以你的机型实测为准；
- 收不到数据先查接线（TX/RX 是否交叉）与波特率，再查 OTG 供电是否正常。

## 三、Esp Touch 配网步骤

适用前提：你的智能模块支持 Esp Touch 配网协议（乐鑫系模块大多支持，非乐鑫模块以模块说明书为准）。

1. 手机连上**要给模块用的那个 Wi-Fi**（配网是把当前 Wi-Fi 的名称和密码告诉模块，所以手机在哪、模块就进哪）；
2. 让模块进入配网等待状态——具体操作（长按按键、上电闪烁等）看模块自己的说明书；
3. 打开 NetAssist 的 Esp Touch 页面，输入当前 Wi-Fi 名称与密码，点发送；
4. 模块拿到配置并联网成功后，页面上会出现确认信息；多台设备可以连着一起配。

容易失败的几个点：

- **2.4G 才行**：多数模块只认 2.4G 频段，手机别连 5G Wi-Fi 配网（双频合一的路由器要注意分开或关闭双频合一，以模块规格为准）；
- **信号别太差**：模块离路由器太远，配包解析成功率会明显下降，配不上先挪近再试；
- **配网方式不止一种**：如果模块说明书给的是 SmartConfig/AP 配网等其他方式，对应关系要看模块侧支持哪一种，Esp Touch 只是其中之一。

配好网之后，模块就有了 IP，回过头用《TCP服务端与客户端互测步骤》或《UDP通信与广播测试》里的方法去和它通信验证。
