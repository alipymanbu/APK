## 一、先核对安装包信息

装之前把手里的安装包对一遍。下表是这份安装包的实际情况（版本 1.0.7 与开源仓库标注的 versionName 一致；后续若有更新，以仓库页面为准）：

| 项目 | 值 |
| --- | --- |
| 应用名称 | NetAssist（网络调试助手） |
| 版本 | 1.0.7 |
| 包名 | com.letter.socketassistant2 |
| 安装包大小 | 4.06M |
| MD5 | 413E0BF779D8409AE9E244D74B5F72CE |
| 开发者 | 开源项目 SocketAssistant（GitHub 用户 NevermindZZT），MIT 许可 |
| 收费方式 | 免费开源 |

两个核对要点：**包名** `com.letter.socketassistant2` 是认应用最可靠的标识——商店里叫「网络调试助手」的应用不止一个，包名不同就是另一款软件；**MD5** 可用来确认下载下来的文件没有被调包。

## 二、两种获取渠道

1. **GitHub 开源仓库**：项目地址 [github.com/NevermindZZT/SocketAssistant](https://github.com/NevermindZZT/SocketAssistant)，MIT 许可，源码公开，可从仓库的发布页取安装包；
2. **夸克网盘**：手机访问 GitHub 不方便时，从 [NetAssist 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6765565701b5) 转存后下载 APK 手动安装，内容就是上表那个 1.0.7 版。

两种渠道拿到的是同一个应用，差别只在更新方式：仓库渠道跟着项目走，APK 手动装则要再下新包覆盖。

## 三、安装步骤（APK 直装）

1. 从网盘把 APK 转存后下载到手机存储；
2. 点开安装包，系统首次会提示「不允许安装未知来源应用」，按提示允许本次安装（入口一般在 设置 → 安全 → 安装未知应用，不同厂商叫法略有差异）；
3. 回到安装界面点「安装」，等进度走完；
4. 点「打开」进入应用。不需要注册账号，也没有联网激活环节；
5. 打开后主界面是连接列表，点进去建第一个连接就能开始测试——手机与电脑互测的具体流程见《TCP服务端与客户端互测步骤》。

## 四、需要哪些权限

按你会用到的功能分：

| 权限 | 用在哪 |
| --- | --- |
| 网络（INTERNET） | TCP/UDP 收发数据的基础权限，不给无法工作 |
| Wi-Fi 状态 | 读取当前网络信息、显示本机 IP |
| 位置（部分机型） | 使用 Esp Touch 配网时，部分系统版本要求位置权限才能读取当前 Wi-Fi 名称，按弹窗提示授予即可 |

只做 TCP/UDP 调试的话，网络权限是关键；配网与串口功能用到时再授予对应权限，具体见《串口调试与EspTouch配网》。

## 五、对手机的要求

- 安卓 5.0 及以上（源码 build.gradle 标注 minSdk 21），应用本体只有 4.06M，老手机也能装；
- 基础的 TCP/UDP 调试**不需要 root**；
- 测试时手机要和被测设备（或电脑）处在同一个网络里——同一 Wi-Fi 或手机自己开的热点都行，网络不通导致的连不上，直接对照《连接不上与常见问题排查》逐项检查。
