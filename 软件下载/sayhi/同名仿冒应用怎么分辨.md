## 一、先看一个真实例子

2026-09 检索时，App Store 中国区搜「Say Hi Translate」，排在前面的是一个名为「Say Hi Translate - Translator」的应用：开发商是 **Innovia IT Solutions**，带应用内购买，安装包约 77.9 MB，2025 年才上架。它与原版 SayHi Translate 没有任何关系，只是名字高度相似。

原版也在同一个商店里，但混在搜索结果里不好认。所以别按名字找，按下表核对。

## 二、原版的四个硬特征

| 核对点 | 原版的样子 |
| --- | --- |
| 开发商 | **SayHi LLC**，关联亚马逊（即「SayHi - An Amazon Company」） |
| 安卓包名 | `com.sayhi.android.sayhitranslate` |
| 安装包体积 | 约 28 MB（远小于动辄 70 MB 以上的套壳应用） |
| 上线时间 | iOS 2011 年、Android 2017 年上架；应用内没有任何内购与订阅 |

四个特征里有三个对得上才可信；开发商名字对不上，直接排除。

## 三、仿冒版的常见特征

- **名字加了空格、连字符或后缀**：原版写作「SayHi Translate」，中间没有空格、不带「- Translator」之类的尾巴；
- **带应用内购买 / 订阅**：原版是完全免费、无内购的，出现任何价格按钮都不是原版；
- **上架时间很近**：原版十年前就在了，2024 年后新上架的「同名」应用基本可以直接划走；
- **要求与翻译无关的权限**：原版只用到麦克风、网络（可选通知），首启就要通讯录或存储全权限的要警惕。

## 四、从第三方 APK 站下载怎么核对

有的渠道会重新打包 APK。下载后先核对两样东西再安装：

1. 安装后核对包名是否仍是 `com.sayhi.android.sayhitranslate`（重打包的常会改包名）；
2. 用 MD5 比对文件是否被改过，方法见[下载与安装教程.md](下载与安装教程.md)的第四节——本文网盘里的 **sayhi 安装文件资源（夸克网盘）** 也建议按同样方法核一遍 MD5。
