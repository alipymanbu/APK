## 二、安装步骤

1. 从网盘把 APK 文件下载到手机存储；
2. 在文件管理器里点开这个 APK。系统若提示「禁止安装未知来源应用」，按提示允许**来自该文件管理器**的安装（不同品牌的路径：设置 → 安全 / 应用管理 → 安装未知应用）；
3. 点「安装」，等进度走完；
4. 点「打开」或回到桌面点图标启动。

如果手机上装了带「安装前扫描」的安全类应用，报毒提示通常源于「第三方渠道 APK」这个来源本身，核对过上面表格里的包名与 MD5 后再决定是否继续。商店里同名不同开发商的仿冒应用不少，安装前可先过一遍[同名仿冒应用怎么分辨.md](同名仿冒应用怎么分辨.md)的核对表。

## 三、第一次打开要过哪几关

1. **使用条款**：首屏会显示条款，点「继续」即可；
2. **麦克风权限**：语音翻译必须录音，弹窗时选「允许」。拒绝了这个权限，按麦克风按钮就不会有反应——装完才发现没反应的，十有八九是这里（补救方法见[常见问题与注意事项.md](常见问题与注意事项.md)）；
3. **通知权限**：有的系统还会问是否允许通知。官方说明这只用于推送新语言提示与产品消息，拒绝不影响翻译，按需选即可；
4. **主界面**：过完前几关就是翻译主界面，中间两个麦克风按钮各对应一种语言，左右各有语言选择器。

到这里就能用了，不需要注册账号。界面各按钮是干什么的，见[语音翻译与对话模式.md](语音翻译与对话模式.md)。

## 四、核对安装包（可选）

想确认下载到的文件和表格里那份一致，可以算一下 MD5：

```bash
# Windows（PowerShell 或 CMD）
certutil -hashfile "下载的文件名.apk" MD5
```

```bash
# macOS / Linux
md5sum "下载的文件名.apk"
```

算出的值与 `B0DA8C7630C9826943167AD8BF0C89DA` 一致，说明文件完整未改动。部分安卓文件管理器（如 MT 管理器）的长按菜单里也自带 MD5 校验。

## 五、装完先做两件事

1. **试一句**：把语言对调成「中文 ↔ 英语」，对着麦克风说一句话，确认能出翻译、能读出声；
2. **调常用语言对**：语言选择器里把两侧换成你最常用的组合，下次打开会记住这个设置。
