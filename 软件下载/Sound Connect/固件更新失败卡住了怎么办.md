## 一、先认症状，确认走这篇

出现以下任意一条，就是索尼官方「固件更新无法完成」专文覆盖的场景：

- 更新中弹「**软件传输失败**」，进度走不下去；
- 停在「**请稍等……软件下载中……**」页面不动；
- 停在「**请稍等……更新中……**」页面不动。

先别重复点更新——以下干扰因素不清掉，点多少次都一样断。

## 二、官方列的中断原因（逐条对照）

| 干扰项 | 你要做的事 |
| --- | --- |
| 手机还连着其他蓝牙设备（手表、手环） | 全部断开；另一台注册过 Sound Connect 的设备也别连着 |
| 耳机与手机蓝牙不稳 | 两边贴近，别隔着身体 |
| 电量偏低 | 耳机和手机都充满再试 |
| Wi-Fi / 2.4GHz 干扰 | 远离微波炉、无绳电话、拥挤的 Wi-Fi 环境 |
| **自动关机开着**（真无线） | App「系统」里把自动关机设为**不关闭**——默认是开的，未佩戴约 5 分钟就关机，更新必断 |
| 手机省电模式开着（安卓） | 关掉省电模式再更新 |
| 耳机放在充电盒里 | 更新时把耳机**戴在头上或拿在身边**，别闷在盒里 |

## 三、救回流程（卡住时照做）

1. **先取消**：在更新界面点「取消」，别让卡死的进度条挂着。
2. **关掉所有其他蓝牙设备的电源**，包括已注册到 Sound Connect 的设备和穿戴设备。
3. **重启手机**。
4. **退出 Sound Connect**（从后台划掉，不是只按 Home）。
5. **充满电重来**：耳机与手机充满，打开 App 连上耳机，**先播放一首歌确认两侧都出声**——两侧都正常才开始更新。
6. 自动关机确认已设为「不关闭」，然后重新发起更新；期间关掉手机上其他应用，耳机与手机保持近距离。

## 四、传输中断了，进度会丢吗

不会。按官方说法与实测反馈，耳机下次开机重新连上 App 后**会从中断处继续传输**，重新走一遍更新流程即可，不用从零开始。安卓全程约 40 分钟（iPhone 更久），中间别切后台、别锁屏杀进程（完整注意事项见 [耳机固件更新教程.md](耳机固件更新教程.md)）。

## 五、还不行：重置 → 初始化

前四节都做了仍卡住，剩下两级手段（因型号而异，查你型号的帮助指南）：

1. **重置耳机**：清临时故障，**配对信息与设置保留**——先做这个。
2. **初始化耳机**：恢复出厂 + 删光配对记录，重置无效才用；做完要从头配对（[连不上耳机怎么办.md](连不上耳机怎么办.md)）。

初始化后仍更新失败，耳机可能有硬件问题，联系售后。

## 六、预防比救容易

- 把「**自动下载软件**」打开（设备设置 → 系统），新固件在信号好的时候提前下好；
- 更新前扫一遍第二节的表格，尤其**自动关机与省电模式**这两条默认值是坑；
- App 版本太旧会直接发起不了更新——部分固件要求 App 12.3.0 或以上（你手头版本见 [下载与安装教程.md](下载与安装教程.md)）。
