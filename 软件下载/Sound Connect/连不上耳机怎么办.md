# Sound Connect 搜不到耳机、连不上怎么排查

## 一、先分清是哪一层断了

三种症状的排查方向完全不同，先对号入座：

| 症状 | 断在哪一层 |
| --- | --- |
| App 里搜不到耳机 | 蓝牙发现环节（权限、配对状态、App 版本） |
| 手机蓝牙列表里有点了连不上 | 系统配对环节（旧配对记录残留） |
| 已连上但设置改不动、电量不显示 | App 与耳机的控制链路（缓存、版本） |

## 二、基础检查（先做完这四条）

官方支持页给的第一层排查就这几样，多数问题到此为止：

1. **App 是不是最新版**：把 Sound Connect 更新到最新版再试——索尼明确说「某些型号需要特定版本的 App 才能正确连接」，版本旧了会直接搜不到。
2. **手机蓝牙开了吗**：下拉快捷开关确认；同时确认手机没有开「仅 Wi-Fi」之类的省电模式。
3. **耳机在配对模式吗**：真无线耳塞放回充电盒再取出；头戴式关机再开机。拿不准就先放回盒中关盖，再重新开盖。
4. **电量**：耳机和充电盒都充够电，低电量时部分型号直接不广播蓝牙。

## 三、还不行，按官方顺序逐级走

以下每做完一步就试一次，好了就停：

1. **重启手机**。
2. **重启耳机**：真无线 = 放回充电盒再取出；头戴式 = 关机再开机。WF-1000XM5 有个已知细节——从充电盒取出时**先右（R）后左（L）**，等固件升到最新后才不分先后。
3. **杀掉 App 重开**：在手机的后台任务列表里把 Sound Connect 划掉，再重新打开。
4. **忘记设备重新配对**（最常解决问题的一步）：
   - 安卓：系统设置 → 设备连接 → 蓝牙 → 在「已保存的设备」里点型号右侧的设置图标 → 忘记 → 忘记设备；
   - iPhone：设置 → 蓝牙 → 点设备旁的「i」→ 忽略此设备。
   然后让耳机重新进配对模式，从头配一遍。
5. **清 App 缓存 / 数据**：安卓系统设置 → 应用 → Sound Connect → 存储 → 先清缓存，不行再清数据（清数据会丢 App 内的设置，注意 [耳机固件更新教程.md](耳机固件更新教程.md) 里提过的自动下载开关等需要重设）。
6. **卸载重装 App**：商店或安装包重装一遍再连（[下载与安装教程.md](下载与安装教程.md)）。
7. **重置手机网络设置**：安卓「设置 → 系统 → 重置 → 重置 Wi-Fi、移动网络和蓝牙」；iPhone「设置 → 通用 → 传输或还原 iPhone → 还原 → 还原网络设置」。这会清掉所有 Wi-Fi 密码和蓝牙配对，做好心理准备再点。
8. **换台手机试**：另一台手机能连上，问题在原手机；也连不上，问题在耳机侧。
9. **重置 / 初始化耳机**：走到这一步才动它。具体按键组合因型号而异，查你型号的索尼帮助指南（如 WH-1000XM6、WF-1000XM5 都有专门的「重置耳机」「初始化耳机以恢复出厂设置」页面）。初始化会把耳机的配对记录和设置全部清空。

## 四、连上了但 App 里设置不生效

- **电量显示全空**：控制链路其实没建立，走一遍第三节第 4 步的「忘记 → 重配」。
- **改了设置没反应**：点完停一两秒再切页面，设置是异步写进耳机的，立刻退出可能没写完。
- **App 反复断开又重连**：先确认耳机固件是最新版（见 [耳机固件更新教程.md](耳机固件更新教程.md)），旧固件连新版 App 是常见组合故障。
- **开着多点连接时另一台设备抢线**：不是故障，是多点的正常行为，切换规则见 [多设备连接与LE Audio设置.md](多设备连接与LE Audio设置.md)。

## 五、几个容易被忽略的原因

- **App 只支持手机**：索尼明确说它「仅适用于安卓智能手机或 iPhone，与电脑不兼容」——在 PC 或 Chromebook 上装不上、连不了都属正常；耳机连电脑本身是通的，那是系统侧设置问题，见 [耳机连电脑没声音怎么设置.md](耳机连电脑没声音怎么设置.md)。
- **耳机还连着别的手机**：多数索尼耳机同时只保持一条活动连接，旧手机蓝牙开着会被它优先回连，先把旧手机蓝牙关掉。
- **安卓权限**：蓝牙权限被系统回收会导致时好时坏，到系统设置里确认没被「省电策略」限制了后台（详见第六节）。
- **区域功能差异**：部分功能（如某些流媒体联动、语音助手）在特定国家/地区不可用，页面上没有该选项不一定是故障。

## 六、App 被系统杀后台：时好时坏的真凶

安卓的省电机制会把 Sound Connect 冻在后台，表现为：耳机明明开着、App 却搜不到，或更新通知永远不弹。**症状是「时好时坏」而不是「一直不行」**——每次手动打开 App 又正常了，基本就是这一层。按你手机品牌把这几处打开（入口名各家不同，认关键词）：

| 要开的东西 | 常见入口 |
| --- | --- |
| 后台运行 / 允许自启动 | 设置 → 应用 → Sound Connect → 省电策略 / 后台活动，选「允许」 |
| 关闭电池优化 | 设置 → 电池 → 电池优化，找到 Sound Connect 改为「不优化」 |
| 后台锁定 | 多任务界面把 Sound Connect 卡片下拉加锁，别让它被一键清理扫掉 |
| 关闭省电模式 | 系统省电/低电量模式开着时，后台推送与蓝牙活动都受限 |
| 通知权限 | 设置 → 应用 → Sound Connect → 通知，全部允许 |

第三方「手机管家」类应用有自己的后台白名单，装了的话把 Sound Connect 加进白名单，否则它照样被清。改完把 App 从后台划掉重开一次让设置生效。

## 七、卡在「连接中」转圈不动（已知个例）

索尼社区有用户反馈：某次 App 更新后，WF-1000XM5 打开 App 就停在「正在连接」界面不动，耳机放歌正常、就是 App 进不去（**单一来源的用户反馈，截至 2026-09 未见官方公告确认，按下列步骤试，无效不必恋战**）。社区版主给的处理与第三节重合，浓缩成三步：

1. 系统设置 → 应用 → Sound Connect → 存储，先清缓存再清数据（会丢 App 内设置，登录态也要重来）；
2. 蓝牙设置里忘记耳机——注意**别选名字带 `LE-` 前缀的那条**，删的是不带前缀的主连接；
3. 重新打开 App，按引导从头配对。

若这招在你机器上也反复复发，与其折腾降版本，不如先用手机蓝牙直连听歌（功能不受影响），App 侧等新版修复再处理。
