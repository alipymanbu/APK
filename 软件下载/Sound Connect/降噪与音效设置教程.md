## 一、先搞清设置在哪个区

App 主界面按功能分成几个页签，设置项按页签归位（不同型号显示的页签略有差异，没有的项就是你的耳机不支持）：

| 页签 | 你来干什么 |
| --- | --- |
| 状态 | 看电量、看当前连的是哪台设备、切多点连接 |
| 声音 | 降噪 / 环境音 / 均衡器 / 空间音效——本文主角 |
| 系统 | 按键自定义、多点连接开关、固件更新入口 |
| 服务 | Quick Access、使用记录等附加功能 |

## 二、降噪与环境音怎么调

1. 进「声音」页签，最上面就是**噪声控制**：在「降噪」「环境音」「关闭」之间切。
2. **降噪**档位高的耳机（如 1000X 系列）还能选档位强度；只有两档的型号就是强/弱两下。
3. **环境音**决定你听多少外界声：想一边过马路边听歌边听见车声就调高，坐办公室想专注就调低。
4. **自适应声音控制**（有的型号叫「自适应音效控制」）打开后，App 会根据你的动作和地点（停留/步行/奔跑/交通工具）自动切降噪档。你只需要在它的设置页里把每种状态调成你想要的档位，之后就不用手动碰了。它靠位置判断场景，所以**位置权限必须给**，不给就一直停在手动档。

## 三、均衡器与低音

- **均衡器（EQ）**：「声音」页里点均衡器，先试预设（散步、健身房、地铁、定制等命名因型号而异），不合口味就拖自定义曲线。改完当场听一首常听的歌再定，别拿没听过的曲子调。
- **CLEAR BASS（低音增强）**：独立的低音滑杆，只推低频不带响整体音量，嫌低音薄就加一格。
- **DSEE**（DSEE HX / DSEE Extreme，型号而异）：把压缩音源的高频细节补回来的开关。听流媒体、播客可以开着；部分型号在播放高码率音源时它不起作用，属正常。
- 想保留多套口味：先存一个自定义 EQ，换场景时一键切回，不用每次重拖。

## 四、空间音效与头部追踪

- **360 Reality Audio**：把普通立体声模拟成环绕声场。第一次用要走「用耳朵拍照」的贴合度检测——找安静地方，把耳机戴正再开始，中途别说话。
- **头部追踪**（部分型号 + 安卓）：开启后声音会随头部转动固定在空间里。转头时声音位置不动才说明生效。
- 检测失败最常见的原因是耳塞没戴紧或环境太吵，摘下重戴再测一次；始终失败见 [连不上耳机怎么办.md](连不上耳机怎么办.md) 的排查思路。

## 五、通话与语音相关

- **Speak-to-Chat（说聊即聊）**：一开口自动把音乐暂停并切入环境音，说完自动恢复。开会多的人建议开着，嫌误触发多就把它关掉或调长暂停时间。
- **通话时捕捉自己的声音**：部分型号支持把你的声音送进耳机里，戴着重型耳罩通话时不用摘。
- **语音助手**：「系统」页里可指定唤起哪家助手；国内可用性因型号与地区而异，页面上没有就是不支持。
- **人声增强（Voice Boost）**：对白、播客听着小不是故障，把聆听模式切到「人声增强」即可（支持的型号可**双击左耳**直接切）。通话时该模式不生效；音量整体上不去、两边音量不同步这类问题另有排查路径，见 [音量太小与手机音量不同步怎么办.md](音量太小与手机音量不同步怎么办.md)。

## 六、改完没生效怎么办

1. 点完设置停一两秒再退出页面，设置是异步写进耳机的。
2. 检查 App 与耳机固件是否都是最新版——音效类开关依赖固件实现，旧固件可能没有这个项（升级方法见 [耳机固件更新教程.md](耳机固件更新教程.md)）。
3. 首次配对后个别设置是耳机出厂值，不显示在 App 里，重新连一次让它读全。
4. 彻底不动了就走 [连不上耳机怎么办.md](连不上耳机怎么办.md) 的第四节。
