## 一、先搞清楚你面对的是一排模型，不是一个

当贝AI 是聚合型助手：同一个输入框，背后可以挂不同的大模型。官方公布接入的包括 **DeepSeek-R1 671B 满血版**、**DeepSeek-V3**、**豆包**、**通义千问**、**Kimi** 等，网页端与手机端的模型列表会随时间增减，以你界面上「模型切换」面板实际列出的为准。

不同模型擅长的事不一样，切换不是玄学，按任务挑就行：

| 你正在干的事 | 建议倾向 |
| --- | --- |
| 复杂推理、逻辑链长的难题、代码调试 | DeepSeek-R1（满血版，带思考过程） |
| 快速问答、日常闲聊、要响应快 | 非思考类模型（如 V3 / 豆包 / 通义千问） |
| 中文长文案、营销稿、小红书风格 | 通义千问、豆包这类中文语料强的 |
| 长文档续写、万字以上内容 | 支持超长上下文的模型（列表里标注长文本的） |

**切换入口**：在输入区左下角（或输入框附近的模型名）点开「模型切换」面板，选中即生效，下一条消息就走新模型。v1.1.5 的更新日志里专门提到「改进了模型切换界面，操作更直观」——如果你之前用过旧版，入口位置可能挪过，以当前界面为准。

## 二、联网开关：问实时问题前先打开

模型本身的知识有截止时间，问「今天票房多少」「本周有什么新剧」这类题，要先在输入区把**联网**开关打开，它才会带着搜索结果回答。v1.1.5 还专门优化了联网搜索结果在财经、影视类查询上的准确性。

实用习惯：

- 问**时效性内容**（新闻、票房、股价、赛程、新版本）→ 开联网；
- 问**写作风格、代码逻辑、翻译**这类不需要外部信息的 → 不用开，省一步是一步；
- 开了联网还是答错时间，检查问题里有没有写清日期范围（比如「截至本周日」），AI 对模糊时间词的处理不稳定。

## 三、怎么把问题问好

同样的模型，问法不同结果差很多。核心原则是**把需求说具体**：

- 差：「帮我写邮件」
- 好：「用打工人语气写一封病假邮件，卑微但不失礼貌，200 字以内」

几个通用套路：

1. **给角色和场景**：「你是资深 HR，帮我改这份简历」比「改简历」强一档。
2. **给约束**：字数、语气、格式（表格 / 分点 / 代码块）、输出几版。
3. **给素材**：要改写的内容直接贴进去，或用附件上传 / 知识库（见 [知识库与智能体使用指南.md](知识库与智能体使用指南.md)）。
4. **追问而不是重开**：第一轮结果不满意，直接说「第二段太啰嗦」「语气再正式一点」，模型带着上下文改，比重新描述一遍准。

## 四、长文本与语音输入

- **长文本**：官方口径支持 10 万字级别的长文本连续创作，适合整篇报告、小说、方案这类一次成型的输出。写长文时一次要完比挤牙膏式分段更稳；中途要改就继续追问。v1.1.5 优化了长文本生成时的内存占用，减少闪退概率 —— 之前一写长文就闪退的，装这个版本会明显好转。
- **语音输入**：输入区有语音按钮，点开后口述需求即可（如「帮我生成今天的工作日报」），系统识别成文字后再发送。识别不准时的处理办法见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、v1.1.5 这版改了什么

网盘里这份是 v1.1.5，这一版的更新日志要点：

1. 新增对 DeepSeek R1 0528 最新版的支持，推理与逻辑连贯性提升；
2. 修复部分安卓设备启动卡顿；
3. 优化长文本生成的内存占用，减少闪退；
4. 改进模型切换界面；
5. 加强联网搜索结果准确性（财经、影视类查询）。

也就是说，你装的这份已经是带上述修复的版本；再新的官方版以官方发布页当时显示为准。
