## 一、高频疑问速查

| 问题 | 实际情况 |
| --- | --- |
| Ta 能记住我之前说的话吗 | 能记住聊过的要点（喜好、习惯、约定），之后的对话里主动呼应；这是「记住重点」而不是逐字存稿 |
| 聊天记录会被别人看到吗 | 对话属于你的账号内容；隐私政策的官方文本在 `https://momood.gmiao.com/momood/agreement/privacy.html`，收集哪些信息以它为准——第三方介绍里「绝对不收集」这类说法与协议口径并不一致，别当真 |
| 有广告吗 | 多个第三方介绍与用户反馈都提到无弹窗广告；实际以你装的版本为准 |
| 支持语音吗 | 支持发语音消息与语音电话；语音电话消耗糖果，见 [糖果与付费规则说明.md](糖果与付费规则说明.md) |
| 换手机了记录还在吗 | 有第三方资料称聊天记录支持云端同步、换机可延续；能否同步以你实际登录后看到的为准，重要内容别只留这一份 |
| iOS 和安卓是同一个应用 | 是，同一个产品：App Store 与安卓渠道都由长沙糖喵网络科技有限公司发布，但两端版本号各自更新，不保证同号 |
| 会员和糖果各多少钱 | iOS 端 App Store 有公示档位（糖果 6/18/38/98 元四档，会员月度 28、季度 68、年度 168 元），完整表与注意事项见 [会员与内购价格说明.md](会员与内购价格说明.md) |

## 二、装不上 / 打不开 / 闪退

按顺序排查，哪步解决了就停：

1. **系统版本**：安卓 5.2 以下装不上或运行不稳（本地包的最低要求）。
2. **安装包完整性**：下载中断会得到残包——重新下一遍，或用 MD5 比对本地记录（`882304A7A8C895E4093EA77599ED0316`），对不上就是文件有问题（安装包从 [MoMood 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c0b7b2a36062) 重新取）。
3. **未知来源权限**：安装时没给「允许安装未知应用」会直接中断，给一次再装。
4. **闪退/卡死**：先清缓存（系统设置 → 应用 → MoMood → 清理缓存），再重启手机；仍闪退则说明当前版本与你的机型不兼容，换官方渠道的新版本试。
5. **收不到验证码**：检查手机信号与短信拦截黑名单；换网络（Wi-Fi ↔ 流量）重发一次。

## 三、登录收不到验证码、账号登不上

- 验证码短信被骚扰拦截拦走是最常见原因，去短信应用的「拦截/垃圾箱」里找。
- 手机号换过运营商或停机复机后，号码可能仍未恢复接收，联系客服处理。
- 协议约定：**账号不得转让、出借、出租、出售、分享**，违者会被临时封停甚至永久封禁；账号或密码被盗用时应立即联系官方，否则损失自负。

## 四、回复突然变「内容不合规」或变敷衍

这是内容审核在起作用：应用有审核团队，涉色情、暴力、人身攻击、广告等内容会被删除并对账号处理（协议写明发现后 24 小时内删除）。另外：

- 官方口径是正常聊天不受影响；若你反复触发拦截，**不要去搜所谓「话术绕过」教程**——协议把利用规则漏洞的「作弊行为」列为可封号项，媒体也报道过这类灰产话术在兜售，风险由账号承担。
- 只是想要回复正常点：把话题拉回日常、重发明白的句子，通常就恢复了。
- 角色明显跑偏时，回 [自定义角色与角色广场玩法.md](自定义角色与角色广场玩法.md) 检查人设设定，改完再聊。

## 五、举报、投诉与客服

- **端内**：「我的」→「意见反馈」，可举报不良内容与投诉。
- **邮箱**：权利通知与投诉发官方客服邮箱 `service@gmiao.com`；产品另有联系邮箱 `momoodapp@163.com`（官网公示）。
- **协议与隐私政策**：`https://momood.gmiao.com/momood/agreement/protocol.html` 与 `https://momood.gmiao.com/momood/agreement/privacy.html`。

## 六、未成年人使用

协议明确：未成年人应在法定监护人陪同下审阅并遵守协议，未成年人使用行为视为已获监护人认可。第三方媒体曾报道过 AI 陪伴类应用中未成年人消费与内容尺度的问题——如果你家里有未成年人在用，重点盯两处：一是充值/糖果消耗（规则见 [糖果与付费规则说明.md](糖果与付费规则说明.md)），二是聊天内容，必要时用系统层面的家长控制限制安装与支付。
