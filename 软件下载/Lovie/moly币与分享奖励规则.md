## 一、moly 币是什么

moly 是 Lovie 官方活动体系里的奖励单位。目前公开可见的获取途径有两个：一是官方的「分享獎勵」活动，把你的 Lovie 使用内容发到社交平台，通过审核后按互动表现领 moly；二是直接购买——App Store 商店页的内购清单里列有 600 Moly（$0.99）、3500 Moly 等档位（美元标价，以你所在商店实际显示为准）。应用本身免费下载（含应用内购买），moly 能兑换什么官方分享页没有逐项列出，以应用内当前说明为准。

## 二、分享奖励怎么参与

活动流程是固定的四步，来自官方分享页：

1. **发布内容**：可以用自己的聊天截图、角色推荐、语音互动片段或短剧情视频，发到支持的平台。
2. **加入话题**：建议带上 `#Lovie`、`#AI聊天`、`#虛擬陪伴` 这类标签，方便官方确认投稿。
3. **提交链接**：通过官方投稿表单提交贴文链接，表单入口在官网 [lovie.chat/share](https://lovie.chat/share) 页面；贴文要**至少保留 3 个月**。
4. **等待审核**：投稿通常 3 个工作天内审核，通过后发放奖励；超时未收到可以发邮件问 [support@lovie.chat](mailto:support@lovie.chat)。

支持的平台有四个：Instagram、TikTok、Threads、小红书。内容必须是原创，转发搬运他人的内容不算数。

顺带说一下常被一起搜的「邀请码」：截至本文整理，官方公开渠道里没有看到 Lovie 有邀请码或推荐码机制，和邀请好友最接近的官方玩法就是上面这个分享奖励活动。

## 三、奖励档位

奖励按贴文的互动量分五档，官方公布的对应关系如下（截至本文整理时的规则，后续可能调整，以官方页面为准）：

| 贴文互动量 | 可领奖励 |
| --- | --- |
| 0 - 100 | 100 moly |
| 100 - 200 | 200 moly |
| 200 - 400 | 400 moly |
| 400 - 500 | 500 moly |
| 500 以上 | 1200 moly |

互动量越高档位越高，注意档位是按边界跳档的——互动量刚过一条线，奖励就可能翻倍，投稿前先看清自己贴文目前落在哪一档。

## 四、热门题材参考

官方在分享页明确点名了最近的热门玩法——「封鎖」：你封鎖角色、或角色突然反过来封鎖你之后，角色会给出各种委屈、吃醋、嘴硬的反应。官方列的建议题材包括：角色突然封鎖你的瞬间、你封鎖他后的第一句反应、解封后的后续对话、不同角色封鎖反应的对比。想投稿又不知道发什么，从这几个方向入手最容易出效果。

## 五、储值入口

官方另有一个优惠储值页 [lovie.chat/charge](https://lovie.chat/charge)，打开后需要先**绑定 Lovie 账号**才能看到对应的储值选项与专属优惠。

App Store 商店页的内购清单还列出了这些项目（截至本文整理，价格与档位以商店实际显示为准）：

| 内购项目 | App Store 标价 |
| --- | --- |
| VIP 会员（月卡） | $3.99 |
| VIP 会员（季卡） | $9.99 |
| VIP 会员（年卡） | $14.99 |
| 600 Moly | $0.99 |
| Voice Clone | $0.99 |
| 聊天气泡 / 已读样式 | 各 $0.99 |

VIP 会员的具体权益官方商店页没有展开说明；Voice Clone（声音克隆）与聊天气泡这类装饰项，可以在应用内对应功能处看到实际效果后再决定要不要买。
