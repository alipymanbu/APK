## 一、先看懂「关于本机」页

主界面下滑进入「关于本机」，页面分两段：

**设备信息**

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| 耳机名称 | NewBuds | 当前蓝牙名，可改（见第四节） |
| 耳机型号 | NB-T2101 | 买配件、找说明书时要报这个 |
| SN 号 | T22013R00049E3 | 出现质量问题联系售后时用 |

**版本信息**

| 字段 | 说明 |
| --- | --- |
| 当前耳机版本 | 耳机此刻运行的固件版本，示例 V3.0.7.0 |
| 耳机版本更新 | 服务端有的新版号，示例 V3.1.1.0；后面带红点就说明有可用更新 |

上表里的版本号是**界面示例值**，你看到的实际数字以页面当时显示为准。

## 二、OTA 升级步骤

1. 确认耳机与充电盒都有电（建议都高于 50%），把两只耳机都放进盒内、开盖连上 App。
2. 进「关于本机」，「耳机版本更新」有红点即有新固件，点它开始下载。
3. 下载阶段会申请**存储权限**——这是给固件升级包用的，不给就下不下来（权限用途说明见 [下载与安装教程.md](下载与安装教程.md)）。
4. 安装阶段耳机自动重启，**不要把耳机放回盒里合盖、不要退出 App**，等进度走完。
5. 回到页面刷新，「当前耳机版本」变成新版本号即成功。

升级失败的常见原因与处理（耳机厂商官方支持页给出的排查口径基本一致，逐条适用）：

| 现象 | 处理 |
| --- | --- |
| 一直停在下载中 | 检查网络；确认存储权限已给 |
| 安装到一半中断 | 把耳机放回盒内充电，重新开盖连 App，再进页面——多数会自动续装 |
| 页面一直不显示新版本 | 固件是分批推送的，隔天再看；有红点才有得升，没有就不用等 |
| 报传输失败 / 反复中止 | 三件事先排除：耳机电量低于 30%（充满再试）；手机连着别的蓝牙设备（把手表等断开）；手机开了省电模式（关掉） |
| 怎么试都不成 | 耳机与手机贴到 50cm 以内、离开路由器与微波炉等干扰源，退出 App 重进再升一次 |

升级期间的通用纪律：**别切后台、别放音乐、别把耳机戴出蓝牙范围**。升级包要在蓝牙链路上传完整，中途断连就会回到起点。

## 三、电量怎么看

主界面顶部三格电量分别对应左耳、右耳、充电盒。几个实际用法：

- **出门前看充电盒**：盒里电量决定路上还能补几轮。
- **单耳异常掉电快**：若 L/R 两格差距明显（一边掉得飞快），多半是那只耳的充电触点脏了或没放好——清洁与重置的完整步骤见 [单耳没声音或充不进电怎么办.md](单耳没声音或充不进电怎么办.md)。
- **电量长期显示异常**（如一直 100% 不动）：先重启 App，再断开重连一次；仍不正常时看 [连不上耳机怎么办.md](连不上耳机怎么办.md) 走一遍基础排查。

## 四、改耳机名与提示音语言

同一页还能做两件小事：

- **改耳机名称**：点「耳机名称」输入新名字保存。改的是蓝牙里显示的名字——换手机重连时你在蓝牙列表里看到的就是它，起个自己认得出的。
- **提示音中英文切换**：App 的「提示音」设置里可在中文与英文提示音之间切换（连接、电量低这类播报）。

改完名称后，旧手机蓝牙列表里可能还留着老名字的记录，重新配对一次即可刷新。
