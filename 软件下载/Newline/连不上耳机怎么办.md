# Newline 耳机连不上、搜不到怎么排查

> 这篇按「先易后难」的顺序排查：App 里搜不到耳机、手机蓝牙连不上、连上后设置不生效，分别怎么办。

## 一、先分清是哪一层断了

三种症状的排查方向完全不同，先对号入座：

| 症状 | 断在哪一层 |
| --- | --- |
| App 里搜索不到耳机 | 蓝牙发现环节（权限、配对状态） |
| 手机蓝牙列表里有、点连接失败 | 系统配对环节（旧记录冲突） |
| 已连上但 App 里设置不生效 | App 与耳机的控制链路 |
| 连上了但某只耳机不响 | 不是连接问题，见 [单耳没声音或充不进电怎么办.md](单耳没声音或充不进电怎么办.md) |

## 二、App 里搜不到耳机

按顺序过，做到哪步好了就停：

1. **位置权限给了吗**：安卓把蓝牙扫描归在位置权限下，不给就一个设备也搜不到。系统设置 → 应用 → Newline → 权限，把位置设为「使用时允许」（各权限用途见 [下载与安装教程.md](下载与安装教程.md)）。安卓 12 及以上的机型也可能以「附近设备」的名义要权限——同样是给它，效果等同；有开发者文档说明，安卓 6~11 需位置权限、12+ 改用附近设备权限，两种系统上弹的窗名字不同、给法一样。
2. **手机蓝牙开了吗**：下拉快捷开关确认，别只开 Wi-Fi。
3. **耳机进入配对状态了吗**：把耳机从盒中取出、开盖，多数耳机开盖即进入可被发现状态；拿不准就先放回盒里、关盖，再重新开盖。
4. **距离拉近**：把耳机盒拿到手机 1 米内，中间别隔墙。
5. **耳机电量**：电量过低时部分耳机会直接不广播。放回盒里充 10~15 分钟再试。
6. **关掉别的连接源**：耳机若已连着另一台手机/平板的蓝牙，先把那台的蓝牙关掉——耳机通常只保持一条活动连接。

## 三、手机蓝牙里连不上

手机蓝牙列表能搜到、点它却连不上，基本是旧配对记录残留：

1. 手机蓝牙设置里找到该耳机，选「忽略此设备 / 取消配对」。
2. 关蓝牙 → 等 10 秒 → 再开。
3. 耳机重新开盖进配对状态，重新点它连接。

忽略后第一次连接会要求重新配对，属正常。若列表里同时出现两个同名条目，把两个都忽略再重搜，只连新冒出来的那个。

## 四、连上了但设置改不动

1. **先看 App 首页**：三格电量能正常显示，说明控制链路是通的，设置没生效多半是点了没等同步——点完停一两秒再切出去。
2. **电量显示全空**：连接实际没建立。走一遍第二节的第 3、4 步重连。
3. **手势改了没反应**：手势页右上角有「重置」，先重置再重改（细节见 [手势自定义设置.md](手势自定义设置.md)）。
4. **升级页面打不开**：OTA 需要网络 + 存储权限，缺一个都会卡住（见 [耳机固件升级教程.md](耳机固件升级教程.md)）。

## 五、换了手机之后连不上

换新机是最容易踩的场景，按这个顺序做就顺了：

1. 新机先装好 App（[下载与安装教程.md](下载与安装教程.md)），权限一次给全——尤其是位置/附近设备。
2. **旧手机的蓝牙先关掉**：耳机多数只保持一条活动连接，旧机蓝牙开着会一直被它优先回连，新机怎么搜都慢或搜不到。
3. 新机蓝牙里如果残留着从旧机同步过来的配对记录，先「忽略」再重搜——记录指向的密钥在旧机上，直接点连接会失败。
4. 还不行就走第三节的「忘记 → 重启蓝牙 → 重配对」完整一轮。

## 六、都不行时的兜底动作

依次试这三招，成本从低到高：

1. **重启两端**：手机蓝牙开关关开一次；耳机放回盒内关盖 10 秒再开盖。
2. **换台手机试**：另一台手机能连上，说明问题在原手机的系统蓝牙栈；连不上，问题在耳机侧。
3. **查固件**：在能连上的状态下看「关于本机」有没有可用升级，先升到最新再连（见 [耳机固件升级教程.md](耳机固件升级教程.md)）。

走到这还不行，带上「关于本机」页里的**耳机型号与 SN 号**联系售后——报上这两个能省掉一轮来回询问。
