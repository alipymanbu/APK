## 一、这是个什么 App

Newline 是给 Newline 品牌蓝牙耳机做配套控制的手机 App，开发者是新线科技有限公司（官网 [www.newline.com.cn](http://www.newline.com.cn)）。你在手机系统蓝牙里只能"连上"耳机，而降噪档位、均衡器、手势这些设置都要靠这个 App 调。买的是 NewBuds 这类 Newline 耳机，就装它。

安装包是普通安卓 APK，不从应用商店分发也能装，下面给的步骤按 APK 手动安装写。

## 三、下载与安装步骤

1. 从上面的网盘链接拿到 `Newline` 安装包（[Newline 安装文件资源（夸克网盘）](https://pan.quark.cn/s/31bfc079ac94)）。
2. 在手机上点开这个 APK，系统会弹"是否允许安装未知来源应用"——给浏览器或文件管理器开这个权限，返回继续装。
3. 装完先别急着打开，先确认耳机有电、充电盒里耳机已取出，减少下一步配对时的麻烦。
4. 打开 App，按提示授予它请求的权限（各条权限是干什么的见下一节）。
5. 开手机蓝牙，把耳机放进配对状态，在 App 里搜索并连接。搜不到时按 [连不上耳机怎么办.md](连不上耳机怎么办.md) 排查。

## 四、系统要求

不同渠道页面标注不一致：有的写「安卓 5.2 以上」，有应用商店页面写「Android 8.0 以上」。**以你手机实际能否装上为准**——点安装后系统若提示版本不满足，说明这台设备过不了校验，别强行绕。

## 五、安装时的权限请求分别是什么

App 申请的权限看着多，逐条对下来都有明确用途（依据应用商店页面公示的权限说明）：

| 权限 | 用途 |
| --- | --- |
| 粗略位置 / 精确位置 | 用于蓝牙交互传输（安卓系统把蓝牙扫描算进位置权限，不给就搜不到耳机） |
| 存储 | 用于更新耳机固件时下载升级包 |
| 请求安装文件包 | 用于 App 自身更新版本 |
| 访问电话状态 | 用于发生 Bug 时记录手机所处状态 |
| 蓝牙配对 / 访问蓝牙设置 | 与耳机建立连接、读写耳机设置 |

只想连耳机用基本功能的话，**位置权限是必须给的**，其余按需。权限给错了也随时能在系统设置里改。想看官方怎么声明这些数据的用途，厂商公开了 App 隐私政策：[newline.com.cn/newline-app-user-privacy-agreement](https://newline.com.cn/newline-app-user-privacy-agreement)。

## 六、装完第一次用，先做三件事

1. **确认版本**：进 App 的「关于本机」页，能看到耳机型号、SN 号与固件版本（界面字段见 [耳机固件升级教程.md](耳机固件升级教程.md)）。
2. **确认电量显示正常**：主界面应同时显示左耳、右耳、充电盒三格电量。
3. **调一档降噪试试**：把噪音控制切到「降噪」，能听出环境声变小就说明连接与控制链路都通了，具体档位区别见 [降噪与音效设置.md](降噪与音效设置.md)。
