## 一、装之前先核对这几个信息

Alarmy 是 Delight Room 出品的任务型闹钟，安卓版中文名叫「使命闹钟」。如果你是从网盘转存安装包离线安装，先核对安装包本身的信息，避免装错版本：

| 项目 | 本篇对应的安装包 |
| --- | --- |
| 应用名称 | Alarmy（使命闹钟） |
| 版本 | 25.31.2 |
| 包名 | droom.sleepIfUCan |
| 安装包大小 | 216.47 MB |
| MD5 | 7C109E3F1702C84E8B0293D1F6205089 |

几点说明：

- **版本号 25.31.2 是这份安装包的版本**。官方商店里的最新版号通常更新，功能上会有差异，以你实际打开的界面为准。
- **包名 `droom.sleepIfUCan` 是官方安卓包名**，可以用包名查看工具核对，确认不是套壳的仿冒包。
- 较新的 Alarmy 版本对安卓系统版本有一定要求（普遍要求 Android 10 及以上），安装前以手机安装器给出的提示为准。
- 安装包约 216 MB，加上运行缓存，建议手机至少预留 1 GB 空间。

## 二、安装步骤

1. **转存安装包**：打开上面的 Alarmy 安装文件资源（夸克网盘）链接，把里面的 APK 文件转存到自己的网盘，再下载到手机本地存储。
2. **点开 APK 安装**：在手机文件管理器里找到下载好的 APK，点它。首次安装会弹「允许安装未知应用」的提示。
3. **放行安装来源**：按提示进入系统设置，给你用来打开 APK 的那个应用（一般是「文件管理」或浏览器）勾选「允许安装未知应用」，返回后继续安装。
4. **等安装完成**：安装包较大，低配手机上解析可能要等十几秒，不要中途取消。
5. **打开应用**：装完直接点「打开」，或从桌面图标进入。

### 常见拦截与处理

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「禁止安装未知来源应用」 | 手机没放行安装来源 | 按弹窗指引给文件管理器/浏览器开「安装未知应用」权限 |
| 提示「解析包时出现问题」 | 下载不完整或系统版本过低 | 重新下载一遍 APK；仍失败则核对本机安卓版本 |
| 安装按钮置灰 | 有安全类应用拦截或开了安装审计 | 临时退出安全软件再装；部分机型需关闭「纯净模式」（如华为/荣耀） |
| 提示存储空间不足 | 剩余空间小于安装包体积 | 清出 1 GB 以上空间再装 |

华为/荣耀等机型若开了「纯净模式」，侧载 APK 会被直接拦下，需要在设置里退出纯净模式或关闭「增强服务」后再装；小米机型在「开发者选项」里也可能需要关闭「MIUI 优化」之外的安装校验项。不同系统版本的开关名称略有差异，以手机上实际提示为准。

## 三、首次启动要给的权限

Alarmy 是闹钟应用，能不能准时响、能不能弹出关闹钟界面，全靠系统权限。首次启动会陆续向你申请，建议一次给全：

| 权限 | 用途 | 不给会怎样 |
| --- | --- | --- |
| 通知 | 闹钟提醒、就寝提醒 | 收不到就寝提醒通知 |
| 悬浮窗（显示在其他应用上层） | 在任何界面上弹出闹钟解除界面 | 闹钟会响，但关闹钟的界面可能不弹出（Android 10 及以上尤其明显） |
| 相机 | 拍照任务、AI 找物任务 | 拍照类任务用不了 |
| 存储 / 音频文件 | 加载自定义铃声、保存任务照片 | 不能用自己的音乐当铃声 |
| 精确定位（可选） | 今日面板的天气信息 | 只影响天气显示 |
| 设备管理器（可选） | 「防止卸载」功能 | 防卸载开关无效 |

其中**悬浮窗权限**最容易被漏掉——它通常不会在首次启动时主动弹申请，需要你手动到系统设置里开。开法见 [闹钟不响的排查方法.md](闹钟不响的排查方法.md) 的权限清单部分。

## 四、装完后的第一件事

按这个顺序做一遍，之后闹钟才靠得住：

1. **设置一个几分钟后的测试闹钟**，选普通铃声、不加任务，确认能响、能弹界面。
2. **进系统设置把电池优化对 Alarmy 放行**（这是安卓上闹钟不响的头号原因，路径见[排查篇](闹钟不响的排查方法.md)）。
3. **如果打算用拍照/扫码任务**，提前在清醒时把参考照片或二维码注册好——到了早上现弄根本来不及。
4. **给早上容易被自己关掉闹钟的人**：把「防止再次入睡」「防止关机」「防止卸载」三个开关打开，具体作用见 [防止再睡与防卸载设置.md](防止再睡与防卸载设置.md)。

## 五、升级与重装

- **升级**：从应用商店渠道装的直接在商店里更新；离线安装的要换新 APK 重装，数据一般会保留。网盘里这份 25.31.2 是固定的历史版本，不会自动更新。
- **重装/换机**：Alarmy 的闹钟数据存在本地，卸载重装后闹钟需要重新设置。换机前别指望闹钟列表跟着走，新机上按上面的步骤重新配一遍即可。
- **卸载**：如果发现卸载按钮置灰、长按删除无效，多半是开了「防止卸载」，需要先回应用里把这个开关关掉，详见 [防止再睡与防卸载设置.md](防止再睡与防卸载设置.md)。
