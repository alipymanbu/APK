## 二、安装包从哪里拿

两条路，按你的网络环境选：

1. **夸克网盘资源**：直接转存 [Send Anywhere 安装文件资源（夸克网盘）](https://pan.quark.cn/s/164813ffe03f)，把里面的 APK 文件下到手机。适合不方便访问 Google Play 的环境，拿到的是上面表格里那份 23.3.0 的包。
2. **官方渠道**：Google Play 上架页（搜索 Send Anywhere，开发者是 Rakuten Symphony Korea）；官网 `https://send-anywhere.com` 也提供各平台入口。走这条路拿到的是当时的最新版，版本号以上架页显示为准。

不管走哪条路，装完后核对一下包名是 `com.estmob.android.sendanywhere`，避免装到同名山寨应用。

## 三、Android 安装步骤

从网盘拿到的 APK 不走商店安装，系统会按「未知来源应用」处理：

1. 用手机自带的文件管理器找到下载好的 APK 文件，点它。
2. 系统弹出「是否允许安装」时，选择允许；部分系统会跳到「未知来源/安装未知应用」设置页，给对应的文件管理器或浏览器授权后返回再装。
3. 等安装完成，桌面出现 Send Anywhere 图标。

安装失败时最常见的两种情况：一是文件没下完整（重新下载并核对 MD5），二是收到的 APK 用某些应用内直接打开装不了——换成系统文件管理器再试，具体见[传输失败与常见问题.md](传输失败与常见问题.md)。

## 四、第一次启动要过的事

- **存储权限**：应用会请求访问照片和存储，不给它就选不了要传的文件，也存不了收到的文件。给。
- **设备可见性**：同一个 Wi-Fi 下装了 Send Anywhere 的设备会互相出现在设备列表里，这只是展示，不代表已经连上。不想被附近设备看到，进设置把「可被发现」一类的开关关掉（不同版本叫法略有差别，以应用内实际显示为准）。
- **登录不是必须的**：只用六位数字键传文件，不注册不登录也能用；要用链接分享、设备直传这些功能才需要登录账号。

## 五、其他平台怎么用

Send Anywhere 不只有安卓版。你手里的另一台设备是什么，决定你该怎么配对：

| 平台 | 用法 |
| --- | --- |
| iPhone / iPad | App Store 装 iOS 版 |
| Windows / macOS / Linux | 官网提供桌面客户端下载 |
| 电脑不想装东西 | 直接在浏览器打开 `https://send-anywhere.com` 用网页版 |
| Chrome / Outlook | 有浏览器扩展和 Outlook 插件，适合往邮件里塞大附件 |

手机和电脑之间怎么互传，操作细节都在[手机与电脑互传文件方法.md](手机与电脑互传文件方法.md)里；收完的文件落在哪，见[接收文件保存在哪里.md](接收文件保存在哪里.md)。
