漫蛙3（Manwa3）是安卓手机上的漫画阅读应用，启动后先选线路再进内容。它没有上架国内主流应用商店，安装包靠网盘这类渠道传递，所以装之前先核对清楚手上这份是哪一版。本篇按「核对 → 装之前 → 安装 → 第一次打开」的顺序走完。

## 一、先核对这份包是哪一版

网上能搜到的多是当前最新版，和网盘里这份往往不是同一个版本号。本篇出现的版本、包名、体积以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | 漫蛙3（Manwa3） |
| 版本号 | 1.1.21 |
| 包名 | `com.example.manwa3` |
| 安装包体积 | 43.90 MB |
| MD5 | `A1BF2A1D2723BA60ACEF65F4613CB322` |
| 系统要求 | 安卓 5.2 以上（渠道标注口径） |
| 核对时间 | 2026-09-23 |

安装包本体在 [漫蛙3 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ac878b1b7f80) 里，转存到自己的网盘再下载到手机。

四点提醒：

- **版本会往前走**：公开报道里出现过 1.1.26 一类更新的版本号，界面与个别入口可能有差异；具体哪个版本对应什么功能，以你手机上这份的实际界面为准。
- **MD5 怎么用**：下载完用文件管理器看文件详情，或用任意校验工具算一次 MD5，与上表一致说明传输过程没损坏；体积明显小于 43.90 MB 就是没下完。
- **认包名**：想确认手机上装的是不是这一款，看应用详情里的包名是不是 `com.example.manwa3` 最直接。同名的山寨包在第三方下载页不少，包名对不上就不是这份。
- **安全提示怎么理解**：非商店渠道的安装包，安装时系统提示「未经过安全检测」是常规现象。对包有疑虑，先做上面的 MD5 核对，而不是照搬网上「关闭安全软件再装」的说法 —— 校验一致就够了，关防护没有必要。

## 二、装之前确认三件事

1. **系统版本**：渠道标注的最低要求是「安卓系统 5.2 以上」。这是个不常见的写法（安卓官方的版本序列里没有 5.2，相邻的是 5.0 和 5.1），稳妥的理解是：近几年的设备基本没问题，安卓 5.x 及以下的老设备能不能装只能实测，安卓 4.x 的旧机器不用试了。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）开开关。国产定制系统常把这一项收在「安全」「隐私」「更多安全设置」下面，找不到就在设置里搜「未知」。
3. **想清楚旧的漫蛙2**：如果手机上还有上一代应用，注意有公开报道称旧版已停止服务、官方引导迁移到这一代。正确顺序是「新的装好、确认能正常进 → 再处理旧的」，别先卸 —— 上一代的书架和本地缓存不会自动搬过来，两代的差异与迁移步骤见 [和漫蛙2有什么区别.md](和漫蛙2有什么区别.md)。

## 三、安装步骤

1. 从网盘把安装包下载到手机；在电脑上下载的话，数据线或任意传输工具拷进手机都行。
2. 在文件管理器里点开这个 APK。
3. 系统问「是否允许安装」时选允许；提示「应用未经过安全检测」时选继续安装，这是第三方渠道安装包的常规提示。
4. 装完点打开，直接进首次启动。

装的时候被拦，按这张表对：

| 系统提示 | 原因 | 处理 |
| --- | --- | --- |
| 解析包错误 / 解析包时出现问题 | 下载不完整或文件损坏 | 重新下载，下完核对体积是不是 43.90 MB、MD5 是否与上表一致 |
| 应用未安装 | 手机上已有同包名但签名不同的版本 | 先卸载旧版再装；卸载会连本地缓存一起清掉，介意就先看缓存篇 |
| 已阻止安装 / 未知来源 | 开关没给对应用 | 回到第二节第 2 步，给「打开安装包的那个应用」开权限，不是给本应用开 |
| 安装到一半空间不足 | 手机存储满了 | 清出至少 1 GB 再装；43.90 MB 只是安装包体积，装完的实际占用会更大 |

## 四、第一次打开：选线路进首页

首次启动一般停在选线路的界面，几条线路随便点一条进入；进不去就退出来换另一条，这一步的细节与排查在 [线路连不上怎么办.md](线路连不上怎么办.md)。
