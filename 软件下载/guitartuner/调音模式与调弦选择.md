## 一、先认识调音界面

打开应用默认进的就是调音界面：屏幕上是一排弦位和一个指针式指示器。你拨一根弦，指针会告诉你这根音是偏高还是偏低，指针停在中间、整根弦判绿，就说明这根调准了。点界面上的调弦名称（比如 Standard），会打开乐器与调弦的选择菜单。

## 二、自动模式（默认开着）

自动模式是默认状态：你随便拨一根弦，应用自己判断你正在调哪一根，然后给出偏高偏低的提示，你照着拧弦钮就行。

- 适合日常练琴前快速过一遍六根弦；
- 操作节奏：拨一根 → 看提示 → 微调 → 等它变绿 → 换下一根；
- 弦没有跑得很离谱时，自动模式基本几分钟就能调完整把琴。

## 三、手动模式：弦跑得太远时用

点击调音界面上任意一根弦的图标，就切到了手动模式：先给你播放这根弦的标准音作参考，你再拨弦对照调整。

手动模式两个典型场景：

- **新换的弦**——新弦拉力没稳定，一会儿一跑，用标准音对照着收比较稳；
- **弦太松或太紧**——偏差大的时候自动模式可能认错弦（把 5 弦当成 4 弦），手动指定弦位就不会猜错。

调整到接近标准音之后，再切回自动模式做精细收尾，是最省事的组合。

## 四、支持哪些乐器和调弦

能调的不止吉他：6 弦、7 弦、12 弦吉他，尤克里里、贝斯、曼陀林、小提琴、班卓琴等弦乐器都在支持列表里，每样乐器的标准音对照见[支持乐器与标准音对照](支持乐器与标准音对照.md)。调弦方面，除了各乐器的标准调弦，还有一百多种常用调弦可选，常见的几类：

| 调弦类型 | 什么时候会用到 |
| --- | --- |
| Drop D / Drop C / Drop A | 降音系，摇滚、金属常用 |
| 开放调弦（Open Tuning） | 滑棒、指弹、民谣编配 |
| 降半音 / 降全音 | 跟原唱碟或乐队合不上时的整体下移 |
| 半音阶调音器 | 上面都不适用时的兜底，任意音高 |

要注意的是：标准调弦免费，上面这些特殊调弦大多要订阅会员才能用，具体口径见[免费功能与订阅区别](免费功能与订阅区别.md)。

## 五、琴头显示与实用设置

- **琴头样式**：调音界面的琴头图示可以在「3+3」和「6 in line」之间切换，选一个跟你手里这把琴的弦钮布局一样的，拧弦时不容易搞错方向；
- **左手模式**：左手持琴的人在设置里可以镜像界面；
- **音符命名**：习惯唱名的话可以把 CDEFGAB 切成 Do Re Mi 显示；
- **专业级精度**：对音准要求高的场景可以在设置里打开更高精度模式，日常调音用不到就不用开。

不同版本的设置项位置和叫法可能略有出入，以你手上的实际界面为准。

## 六、调音习惯上的三条建议

1. 每次练琴前都调一遍——弦只要放了一阵就会跑，别信「昨天调过」；
2. 一次只拨一根弦，拨完让它自然震动，不要连续扫弦；
3. 指针乱跳或认错弦时，别硬拧，先去[调音不准常见问题排查](调音不准常见问题排查.md)把环境和方法过一遍。
