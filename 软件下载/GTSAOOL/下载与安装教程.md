## 一、这是个什么软件

GTSAOOL 是安卓端的 GTA 系列游戏社区工具，开发者主体为长沙梨月月网络科技有限公司，官方入口是 [www.angxb.cn](https://www.angxb.cn/)（页面上只有一个下载按钮和一个微信公众号入口）。你在手机上装它，主要是为了三件事：给《圣安地列斯》（GTASA）和《罪恶都市》（GTAVC）装 MOD 与 CLEO 脚本、下载这两款游戏的安装包、以及用它内置的联机模块连服务器。

它不是游戏本体，装完后你还需要单独装 GTASA 或 GTAVC —— 好在这一步它自己也能帮你做（见第四节）。本篇只讲工具本身的获取与安装；装好之后怎么用，见 [功能页与CLEO脚本用法.md](功能页与CLEO脚本用法.md)。

## 三、安装步骤

1. 从上面任一途径把 APK 文件下载到手机（用文件管理器点开它）。
2. 系统弹出「安装未知来源应用」提示时，允许文件管理器或浏览器安装该来源的应用（各品牌路径不同，一般在 设置 → 安全/隐私 → 安装未知应用）。
3. 等安装进度走完，点「打开」或回到桌面找图标。
4. 首次启动时它会申请存储权限 —— 给它。后面导入 MOD、解压整合包、下载游戏全都依赖读写手机存储，拒绝了软件基本处于半瘫痪状态。

**系统要求**：官方页没有公布明确的最低安卓版本；第三方页面有标注「安卓 5.2 以上」的说法，也有「完全兼容安卓 9」的问答，均非官方口径，仅供参考。实际能否安装，以你手机点开 APK 时系统是否报错为准。

## 四、装完第一次打开：先关电池优化

打开软件后你会看到五个功能页（怎么分工见 [功能页与CLEO脚本用法.md](功能页与CLEO脚本用法.md)）。首次进入时有一件事值得先做：**按它的提示关闭手机的电池优化**。

原因是这类工具在游戏运行时要保持后台服务活着，而国产安卓的后台管理很爱杀进程 —— 你切出去吃个饭回来功能全没了，多半就是电池优化把它的后台掐了。各品牌大致路径（不同系统版本措辞略有出入，以你手机上实际显示的为准）：

- 小米/红米：设置 → 应用设置 → 应用管理 → GTSAOOL → 省电策略 → 无限制
- 华为/荣耀：设置 → 电池 → 更多电池设置 → 关闭「休眠时始终高耗电限制」+ 应用启动管理里改为手动管理、允许自启动与后台活动
- OPPO/realme/一加：设置 → 电池 → 更多设置 → 关闭「睡眠待机优化」，并在应用耗电管理里允许后台运行
- vivo/iQOO：设置 → 电池 → 后台高耗电 → 允许 GTSAOOL 后台高耗电
- 通用兜底：设置 → 应用 → GTSAOOL → 电池 → 选择「不限制」

关完之后，如果你第一次用它给游戏装 MOD，接下来按 [模组导入与GPU格式选择.md](模组导入与GPU格式选择.md) 走一遍即可；遇到打不开、闪退、加载失败，直接翻 [闪退与常见问题排查.md](闪退与常见问题排查.md)。
