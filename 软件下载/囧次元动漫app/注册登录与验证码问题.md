## 一、什么情况需要登录

有用户反馈：点「立即播放」时提示**获取信息失败**，这类情况通常需要先注册登录，登录后即可正常观看。另外换手机时，登录同一账号能把播放记录带到新设备上。不涉及登录的功能（浏览首页、分类翻页）一般可以直接用。

## 二、邮箱注册步骤

1. 进入「我的」页面，选择注册。
2. 填邮箱地址，点获取验证码。
3. 去邮箱收件箱找验证码邮件，填进框里，设置密码完成注册。
4. 回到登录页，用邮箱 + 密码登录。

## 三、收不到验证码

验证码发到你填的邮箱里，按下面的顺序找，绝大多数落在前两步：

| 排查 | 具体做法 |
| --- | --- |
| 垃圾邮件箱 | 验证码邮件常被邮箱过滤进「垃圾邮件 / 垃圾箱 / 订阅邮件」，先翻这几个文件夹 |
| 地址填错 | 逐字符核对刚填的邮箱，多一个点、少一个字母都收不到 |
| 等一会再重发 | 邮件有延迟，隔几分钟再点「重新发送」；**短时间内别连点**，连点反而会被系统限流 |
| 换个邮箱试 | 某些邮箱服务商对自动发送的验证码拦截较重，换个常用邮箱注册最快 |
| 服务端故障 | 上面都试过还没有，可能是应用侧验证码服务在维护，过一段时间再试 |

## 四、登录相关的其他报错

- **提示网络错误 / 获取信息失败**：先按 [常见问题与故障排查.md](常见问题与故障排查.md) 把网络这一层排除掉——网络通了还报错，才是账号侧的问题。
- **验证码填对了却提示错误**：确认填的是登录页当前这一封（不是旧邮件里的过期码），过期了就重新获取一封。
- **忘记密码**：走登录页的找回/重置入口，用注册邮箱重新收码设置。

## 五、多端登录（电脑端 / 电视端）

有页面提到：**1.5.7.1 及以上版本**，在「我的」页面右上角有「扫一扫」，可以扫电脑端或电视端的登录二维码，账号、播放历史、收藏在各端之间同步（该说法来自公开教程页，实际是否具备以你装的版本界面为准）。注意扫码登录解决的是「在另一个设备上登同一账号」，与充值无关——各端的会员权限是独立的，详见 [收费与会员情况.md](收费与会员情况.md)。

## 六、装回旧版本 / 换设备

重新装应用时用 [下载与安装教程.md](下载与安装教程.md) 里网盘的安装包即可；装完登录同一邮箱账号，播放历史会跟着账号走。若新装的版本登录不上而旧版本正常，多半是版本与服务端不兼容——软件站上的更新版本可以装来试试，装之前照旧核对包名 `com.jumang.jiongciyuan`。
