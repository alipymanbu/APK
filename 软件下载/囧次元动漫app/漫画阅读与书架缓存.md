## 一、漫画入口在哪

番剧和漫画在同一个应用里，找法一致：

- **搜索**：首页顶部搜索栏输漫画名或关键词；和搜番一样，也支持按角色名、作者名搜。
- **分类**：首页按题材分类排列（热血、恋爱、悬疑等），点分类直接筛。
- **今日更新**：首页的更新区能看到当天更新的章节，追连载从这进。

找到漫画点进详情页，与番剧详情页不同的是这里出的是**章节目录**，点章节直接进阅读界面。

## 二、加书架（收藏追更）

详情页点「加入书架」，这部漫画就收进你的书架，下次从书架直接进、不用再搜。新章节更新时书架里会有提醒。注意：**书架跟账号走**，换设备前先登录，否则书架是空的（登录问题见 [注册登录与验证码问题.md](注册登录与验证码问题.md)）。

## 三、缓存章节到手机

有网时把漫画下到本地，通勤路上没网也能看：

1. 进漫画详情页，点「缓存」按钮。
2. 在章节目录里点选要下的章节；**长按章节目录可批量选中**，一次下多话。
3. 下载完成后，在「我的漫画 / 暂存」里查看已缓存内容。

和缓存番剧一样，缓存前确认手机存储余量；空间不足时的排查见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、阅读时的操作

| 想做的事 | 操作 |
| --- | --- |
| 翻页 | 点屏幕右下角的箭头图标切上一章 / 下一章；也可以拖底部进度条跳话 |
| 缩放看细节 | 双指捏合放大、缩小画面 |
| 横屏 / 竖屏 | 支持横竖双模式，躺着单手看切竖屏更省力 |
| 深浅色 | 阅读界面有月亮 / 太阳图标，切深色、浅色主题 |
| 切换话数 | 阅读界面最后一个图标可直接跳话 |

部分版本提供夜间护眼模式与弹幕评论（边看边发），具体以你装的版本界面为准。

## 五、漫画也要收费吗

和番剧同一套规则：大部分免费，部分精品章节可能要金币或会员——两边口径与签到攒币的做法见 [收费与会员情况.md](收费与会员情况.md)。缓存已下载章节不额外收费。
