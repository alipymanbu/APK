## 一、搜索一部番

1. 打开应用，点顶部的搜索框。
2. 输入动漫名字，输入过程中下方会出联想提示，点提示里的那部直接跳；没提示就点键盘上的搜索。
3. 结果列表里点中意的一部进详情页；系列作品多的时候（同一 IP 有好几季、好几个版本），按列表里的信息挑你要的那一部。
4. 详情页里选集数，点「立即播放」进播放页。

首页也能直接翻：热门推荐、分类入口按题材筛，找不着关键词的番时从分类走更省事。

搜索还有几个不显眼的用法：

- **按角色名、作者名也能搜**——只记得主角叫什么、不记得番名时直接输角色名。
- **筛选条件**：搜索页支持按年份、地区、类型筛选，找老番（指定年份）或只看某一地区产的番时用它收窄范围。
- **搜不到结果**：先确认番名没打错（全角/半角都试试），再换短一点的关键词；有版本的更新日志提过「修好了部分用户搜不到内容」的问题，搜不到时先看看是不是版本旧了。

同一个应用里**漫画也是这样搜的**，只是点进去出的是章节目录，操作见 [漫画阅读与书架缓存.md](漫画阅读与书架缓存.md)。

## 二、播放时你能调什么

| 想做的事 | 操作 |
| --- | --- |
| 切换清晰度 | 播放页调出控制条，选清晰度档位；网络差时调低一档更稳 |
| 调倍速 | 播放设置里选倍速档位 |
| 开 / 关弹幕 | 播放界面的弹幕开关；嫌弹幕挡画面就直接关掉 |
| 看评论 | 播放页下方评论区，可以发表看法、回复别人 |
| 暂停 / 进度 | 点一下画面调出控制条，拖进度条跳转 |

播放页的按钮平时隐藏，**点一下画面才会显示**——找不到投屏、清晰度这些按钮时先点一下画面。

## 三、缓存到手机离线看

在有网的时候把番下到本地，没网也能看：

- 在作品详情页找到下载入口，选集数开始缓存；
- 也有页面提到可以在主界面**长按**作品条目直接唤出下载按钮。

缓存文件会占存储空间，缓存前确认手机余量足够；存放位置和清理方式见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、追更与历史

- **播放历史**：你看过哪些、看到第几集，从历史记录里直接续上，播放进度会自动记忆。
- **更新提醒**：热门新番更新后会出现在首页的更新区域，按分类页浏览当天新增的作品。
- **个性化推荐**：首页推荐位按你的观看记录出同类作品；觉得推得不准，主动搜几部对胃口的番能帮它校准方向（该说法来自公开介绍页，实际效果因人而异）。

## 五、需要登录才能看怎么办

有用户反馈：部分番剧点「立即播放」会提示**获取信息失败**，这时需要先注册登录再看。注册只要一个邮箱，步骤和收不到验证码的处理见 [注册登录与验证码问题.md](注册登录与验证码问题.md)。另外，个别集数点开若提示需要金币或会员，那是付费内容档位，收费口径与签到攒币见 [收费与会员情况.md](收费与会员情况.md)。

## 六、投到电视上看

手机屏太小就投屏：播放页右上角有投屏按钮，前提是**手机和电视连在同一个 WiFi**。完整步骤和搜不到设备的排查在 [投屏到电视上怎么看.md](投屏到电视上怎么看.md)。
