## 一、先分清是哪一层的问题

排查顺序固定为：**网络 → 应用缓存 → 账号 → 安装包**。这样逐层排除，不会瞎试：

1. **网络层**：同一 WiFi 下别的应用能不能正常上网？
2. **应用层**：只有这一个应用转圈、别的都正常 → 清它的缓存。
3. **账号层**：清完还是不行、且报错与播放/登录有关 → 按账号问题处理。
4. **安装层**：装完就打不开、或越更新越坏 → 重装。

## 二、播放加载错误 / 一直转圈

公开资料给的排查步骤（按顺序做）：

1. **切换网络**：WiFi 和移动数据来回切几次，重新加载页面——最常见就是当前网络到源站不通。
2. **看别的应用**：同一网络下其他应用都联网正常，说明是应用侧服务器的问题，等一会儿再试；其他应用也都不通，那是你网络本身的问题，先修网络。
3. **重启手机**：把所有服务关掉重开一遍，清掉残留的连接状态。
4. **清缓存**：设置 → 应用 → 找到囧次元动漫 → 清理缓存（别点「清除数据」，那会把登录态一起清掉）。
5. **给手机腾空间**：存储快满时应用加载会异常，删掉不常用的东西留出余量。

## 三、提示网络错误

- 先确认网络本身能用（打开任意网页试试），再回到应用重试。
- 用了代理 / VPN / 私人 DNS 的话先关掉——这类中转常把应用的请求拦在半路。
- 账号相关接口报网络错误的，网络层排除完就转 [注册登录与验证码问题.md](注册登录与验证码问题.md)。

## 四、闪退 / 打不开

| 现象 | 处理 |
| --- | --- |
| 点图标闪一下就退 | 先清缓存再打开；不行就按 [下载与安装教程.md](下载与安装教程.md) 重装一遍（网盘那份安装包可重新下） |
| 播某一集时才闪退 | 换一集、换一个清晰度试；只在特定剧集崩多与该资源有关，跳过即可 |
| 更新后开始闪退 | 某些版本的更新日志明确修过「部分机型闪退」（如 1.5.8.0 那版）；越更新越崩就装回稳定版本，换版本前后都要核对包名 `com.jumang.jiongciyuan` |
| 老机型装不上 | 系统版本过低会装不上，有页面标注要求安卓 4.3 以上，以安装时提示为准 |

## 六、还是不行的时候

把这三样凑齐再排查效率最高：**报错原文截图、当时的网络环境（WiFi 还是流量）、应用版本号**（设置或应用信息里能看到，网盘这份是 1.5.8.3）。版本号对得上 [下载与安装教程.md](下载与安装教程.md) 的表，说明包没问题；对不上就先换回核对过的安装包，再看问题还在不在。
