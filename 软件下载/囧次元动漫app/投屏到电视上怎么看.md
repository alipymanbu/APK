## 一、前提条件（先核对这两条）

1. **手机和电视连在同一个 WiFi**。这是投屏最常翻车的一点：手机走流量、电视连 WiFi，或者两个设备一个连 5G 频段一个连 2.4G 频段（有些路由器会把它们分开成两个网络），都搜不到设备。
2. **电视端的投屏功能已开启**。电视要开着，并且处于能被搜索的状态——智能电视一般在设置或首页有「投屏 / Miracast / 屏幕镜像」入口，机顶盒与电视棒同理。

## 二、投屏步骤

1. 打开囧次元动漫，找到要投的番，进播放页（手机上先播起来）。
2. 点播放页**右上角的投屏按钮**（TV 图标）。按钮平时隐藏，**点一下画面**才会显示出来。
3. 在弹出的选项里点「投屏」，应用开始搜索同一网络下的设备。
4. 搜索结果里点你的电视设备名，连接成功后手机上会显示正在投屏，画面切到电视。
5. 断开投屏：回到投屏面板里点断开，或直接在电视端退出。

## 三、搜不到设备怎么办

按顺序排查，每条都是实际最常见的原因：

| 现象 | 处理 |
| --- | --- |
| 列表里根本没有设备 | 确认手机与电视在同一 WiFi；重启路由器让两者重新拿到同网段地址 |
| 电视不在列表里 | 确认电视的投屏功能已开启、没进屏保；老电视需要外接电视棒才支持 |
| 连上了但没画面 / 秒断 | 两边都重启一次：关掉投屏 → 退出应用 → 重开再连 |
| 搜到了但点不动 | 路由器若开了「AP 隔离 / 访客网络」，关掉或把两台设备都放进主网络 |

投屏依赖局域网，与应用本身的账号登录无关——但番剧要能正常播起来才谈得上投（需要登录的番先按 [注册登录与验证码问题.md](注册登录与验证码问题.md) 处理）。

## 四、投屏卡顿、画质糊

- 投屏走的是局域网 + 在线流：先把 [怎么搜索与播放动漫.md](怎么搜索与播放动漫.md) 里的清晰度调低一档，缓冲压力会小很多。
- 手机离路由器远、信号弱时，把手机挪近一点或换到 5G 频段（前提是电视也能连上同一个）。
- 电视本身解码能力有限时，先在手机上确认这部番能流畅播——手机都卡就不是投屏的问题。
