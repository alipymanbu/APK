## 三、安装步骤

1. 点开下载好的 APK 文件；
2. 系统会提示「不允许安装未知来源应用」，按提示去设置里允许——各厂商入口不同，常见在 **设置 → 应用管理 / 安全** 里，允许的对象是你用来打开文件的那个应用（浏览器、文件管理器或夸克）；
3. 返回后继续安装，等进度走完；
4. 点「打开」，或从桌面图标进入。

装不上时先查两点：

- **文件大小对不上**：对照第一节表格，3.55M 左右才是完整包，差得远说明下载不完整，重下即可；
- **提示签名冲突**：手机上装过同名但来自其他渠道的包，先卸载旧的再装。

## 四、装完第一步：打开与登录

打开后直接进入 flave.ai 的主界面：顶部是分类与搜索，底部一排标签（Explore / Generate / Create / Chat / Premium）。右上角有 **Sign In** 按钮——浏览角色不强制登录，但要开始聊天就得先登录，支持邮箱和 Google 两种方式，具体见[注册登录与账号问题](注册登录与账号问题.md)。
