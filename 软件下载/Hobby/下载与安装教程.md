## 一、先确认你要装的是哪一端

Hobby 由上海微烽科技有限公司开发，是一款面向手机的 AI 角色扮演社交应用，分安卓与 iOS 两个版本，界面语言为简体中文。两端功能大方向一致（创建虚拟角色、剧情互动、社区玩法），但分发渠道、体积和年龄分级要求不同：

| 项目 | 安卓版 | iOS 版 |
| --- | --- | --- |
| 获取方式 | APK 安装包 | App Store（仅 iPhone） |
| 本篇对应的安装包版本 | 2.6.3 | 以 App Store 页面显示为准 |
| 安装包体积 | 约 287.54 MB | 体积更大，以商店页面为准 |
| 年龄分级 | 年满 16 周岁（第三方市场标注） | 18+（App Store 标注） |

先想清楚自己用哪端，再往下看对应的装法。

## 二、安卓版：下载与安装步骤

安卓版在国内各应用市场的收录版本不一，直接用 APK 安装包装最省事。本文提供的 **Hobby 安装文件资源（夸克网盘）** 在头部链接处，转存后把 APK 传到手机即可安装。步骤如下：

1. 在电脑或手机上打开头部的夸克网盘链接，把资源转存到自己的网盘（部分大文件需要客户端或 App 内操作）；
2. 把 APK 文件下载到手机本地存储；
3. 在手机文件管理器里点开这个 APK。首次安装会提示「允许安装未知来源应用」，按手机品牌路径放开一次权限：
   - 小米 / 红米：设置 → 隐私保护 → 特殊权限 → 安装未知应用；
   - 华为 / 荣耀：设置 → 安全 → 更多安全设置 → 安装外部来源应用；
   - OPPO / vivo / 一加：设置 → 安全（或应用管理）→ 安装未知应用；
4. 回到文件管理器重新点开 APK，等待安装完成；
5. 打开 Hobby，按提示用手机号注册或登录。

两点提醒：

- 安装包约 288 MB，确认手机剩余空间在 1 GB 以上再装，避免装到一半失败；
- 如果手机上已装过旧版本，直接安装新版通常会在原数据上升级，聊天记录一般保留；但**卸载重装不保证保留本地数据**，重要剧情建议先确认账号已登录。

## 三、iOS 版：App Store 安装

iOS 版只在 iPhone 上提供（不支持 macOS），在 App Store 搜索「Hobby」或「HobbyAI角色扮演」即可找到，开发者显示为 Shanghai Weifeng Technology Co., Ltd.。注意两点：

- iOS 版标注 18+，登录的 Apple ID 地区会影响能否搜到；
- iOS 版体积明显大于安卓版（以商店页面当前显示为准），下载前确认 Wi-Fi 环境与剩余空间。

## 四、版本口径：为什么网上版本号和安装包对不上

你可能在各类下载站看到 2.6.x、2.7.x 等不同版本号。原因很简单：官方在持续更新，各站收录时间不同。**本文提供的安装包是 2.6.3 版**（包名 `com.weifeng.hobby`，大小 287.54 MB，MD5 为 `872EC9C1CA02816C4EF5E8B64ADBF8C7`，于 2026-09-21 校验），以这份为准即可正常安装使用；想追新版本则以官方渠道当时发布的为准。核对 MD5 可以确认手里的包没被改动过：

```powershell
Get-FileHash .\Hobby_v2.6.3.apk -Algorithm MD5
```

输出的哈希值与上面给出的 MD5 一致（忽略大小写）就说明包是完整的。

## 五、安装失败的自查顺序

装不上或打开就出问题时，按这个顺序排查，多数情况能当场解决：

| 现象 | 先做的事 |
| --- | --- |
| 点 APK 没反应或提示解析失败 | 重新从网盘下载一次，对比 MD5；传输中断导致包损坏是最常见原因 |
| 提示空间不足 | 清理出 1 GB 以上空间，APK 本体加首次运行缓存都不小 |
| 安装到一半中断 | 关掉手机管家的「安装拦截」，或换一个文件管理器再试 |
| 装上后闪退 | 确认安卓系统版本较新（老系统对大体积应用支持差）；重启手机再开 |
| 反复闪退，重启也没用 | 按顺序试：强制停止后重开 → 清除应用缓存（设置 → 应用管理 → Hobby → 存储 → 清除缓存）→ 检查应用权限是否被禁 → 最后才考虑卸载重装（卸载会丢本地未同步数据，先确认账号能登录） |
| 部分功能用不了（如语音） | 到系统设置的应用权限里逐项放开麦克风、存储等权限 |
| 打开后一直转圈 | 多为网络问题，切换 Wi-Fi / 流量；官方维护时段也会这样，等一会儿再试 |

iOS 端遇到应用无响应或闪退，Apple 官方建议的排查顺序是：强制关闭后重开 → 重启设备 → 在 App Store 检查应用更新 → 最后才是删除重装（删除会丢失应用内数据）。完整说明见 [Apple 官方支持页](https://support.apple.com/zh-cn/119876)。
