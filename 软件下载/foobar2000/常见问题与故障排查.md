## 一、媒体库里没有歌，或新歌不出现

- 确认目录已经加进媒体库，且加的是**实际存音乐的目录**（见 [媒体库扫描与标签整理.md](媒体库扫描与标签整理.md)）；
- 把该目录在媒体库里关掉再重新打开，强制重建索引；
- 扩展名不在支持清单里的文件不会进库，先对照 [支持哪些音频格式.md](支持哪些音频格式.md)；
- 扫描还在进行中时列表不全，等它扫完再判断。

## 二、某个文件播放报错或没声音

1. 在文件夹视图里直接点这个文件播放，排除媒体库索引的因素；
2. 对照格式清单：清单外格式转码成 FLAC / MP3 再放；
3. 报错涉及 AC3 / DTS 这类多声道编码、耳机里只有噪声的，是编码本身的特性，换支持多声道的输出设备或转码后播放；
4. 响度忽大忽小不是「放不了」，去 [均衡器与DSP音效设置.md](均衡器与DSP音效设置.md) 查 ReplayGain 设置。

## 三、网络电台卡在 0:00

这是 1.6.2 的已知场景：电台流停在 0:00 时，**再点一次同一个电台**就会重新发起连接，而不是毫无反应（官方 1.6.2 更新日志明确了这个行为）。反复连不上时：

- 用「打开位置」直接贴该电台的流地址测试，地址失效就换一条备用流；
- 部分电台流有地域或并发限制，换网络环境（比如换 Wi-Fi / 流量）再试。

## 四、SMB / FTP / UPnP 连不上

按顺序查：同一网段与 AP 隔离 → 服务器防火墙端口 → 用户名密码（SMB 的 guest 与普通账号是两种登录）→ 自动发现失败改**手动输入服务器地址**。每一步的具体操作见 [局域网播放与网络电台.md](局域网播放与网络电台.md)。

「手机当 FTP 服务器让电脑传文件」这个方向的连接问题（含手机省电策略杀后台服务），见 [电脑传歌到手机的方法.md](电脑传歌到手机的方法.md) 第四节。

## 五、老设备装不上或频繁闪退

- **装不上**：看系统版本——现行 2.x 要求 Android 7.0 或更新；老设备退回 1.6.x 线，版本对照见 [下载与安装教程.md](下载与安装教程.md)。
- **闪退**：确认 APK 架构与机型匹配（32 位 / 64 位分开提供），换对应架构的包重装。

## 六、开日志定位疑难问题

设置里可以打开控制台日志（console logging）：1.6.2 起开启日志时会**保存此前积累的日志**，所以问题复现之后再开日志也不算晚。自查或向社区反馈前，先开日志、复现一遍、再对照报错信息。

## 七、后台播放被杀 / 通话后不恢复

- 锁屏或切后台一段时间后播放自己停了：多半是系统省电策略在限制，去系统设置的电池页把 foobar2000 设为不受优化限制（或允许后台运行）再试；这类限制在国产 ROM 上通常还有「后台纯净模式」之类的独立开关。
- 来过一通电话之后播放不接续：官方在移动版 2.25 的发布说明里明确修复了「通话后播放停止」的问题——1.6.x 旧版线上如果困扰明显，权衡是否升版本线，取舍见 [下载与安装教程.md](下载与安装教程.md)。

按上面几节排查仍无解的，记下报错原文和复现步骤，去官方支持论坛发帖比盲试更省时间。
