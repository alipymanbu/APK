## 一、官方格式清单（本地音频文件）

官方格式页列出的原生支持格式如下（其中「音频 CD」仅限 Windows 版，手机上没有光驱）：

| 类型 | 格式 |
| --- | --- |
| 有损压缩 | MP3 / MP2 / MP1、AAC、M4A（容器内含 AAC 与 Apple Lossless）、Ogg Vorbis、Opus、Musepack、Speex、WMA、AC3、DTS |
| 无损压缩 | FLAC 与 Ogg FLAC、WavPack、Monkey's Audio（APE）、TAK、Apple Lossless（M4A 内） |
| 无压缩 | WAV、Wave64、RF64、AIFF、AU/SND |
| 容器 / 流封装 | Matroska/WebM、MPEG Transport Stream（.ts） |

清单以 [官方格式页](https://www.foobar2000.org/formats) 当时显示为准，个别格式可能随版本增减。

## 二、网络电台流格式

官方列出的网络电台流支持：MP3、AAC、Ogg Vorbis、Ogg FLAC、Opus、HLS。播法见 [局域网播放与网络电台.md](局域网播放与网络电台.md)。

## 三、无损党的几个具体点

- **FLAC**：直接支持，不需要装任何插件。
- **Apple 无损（ALAC）**：`.m4a` 封装的 ALAC 直接支持；`.m4a` 里装 AAC 的普通曲库文件同样能播。
- **APE（Monkey's Audio）与 TAK**：都在官方支持清单里；个别高压缩等级文件在旧版上的解码表现以你实机为准。
- **AC3 / DTS**：在清单里，但属于多声道编码，普通耳机或单声道外放听到的可能只是混在一起的噪声，这不是播放器坏了。

## 四、放不了的文件怎么办

1. 先核对扩展名与上面清单；清单外的格式（冷门编码、带 DRM 的流媒体下载文件等）播不了。
2. 确实要听，常见做法是先在电脑上转码成 FLAC 或 MP3 再拷进手机（foobar2000 桌面版自带转换器，其他转码工具也行）。
3. 文件本身能播、但媒体库里找不到它，那是索引的问题不是格式的问题，去看 [常见问题与故障排查.md](常见问题与故障排查.md)。
