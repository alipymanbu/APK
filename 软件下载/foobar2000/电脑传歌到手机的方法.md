# foobar2000 怎么把电脑里的歌传到手机

> 汇总几种把音频文件从电脑弄进手机的路子：数据线、局域网共享，以及用 foobar2000 移动版自带的 FTP 服务器让电脑直接来取文件。

## 一、先想好：传过去放在哪

- 建一个专用音乐目录（`Music` 或存储卡上的自建目录），按你习惯的结构放文件；之后把这个目录加进 foobar2000 的媒体库，步骤见 [媒体库扫描与标签整理.md](媒体库扫描与标签整理.md)。
- 别散落着放：下载目录、聊天工具缓存目录里的歌难管理，以后换机整理也麻烦。

## 二、数据线：最稳的一条路

USB 连接手机，选「文件传输（MTP）」模式，在电脑上把文件直接拖进音乐目录。不依赖网络、速度稳；唯一常见的坑是线——不少 USB 线只能充电不能传数据，插上没反应先换一根线再怀疑别的。

## 三、局域网：不用插线的两条路

**电脑当服务器、手机来取**：电脑开 SMB 共享或 FTP 服务，手机端在 foobar2000 的 Media Servers 页添加对应书签，用法见 [局域网播放与网络电台.md](局域网播放与网络电台.md)；也可以用手机文件管理器挂载共享后拷贝。

**手机当服务器、电脑来取存**：用 foobar2000 移动版自带的 FTP 服务器，见下一节。

## 四、用 foobar2000 自带的 FTP 服务器传

1. 手机与电脑连同一个 Wi-Fi。
2. 应用设置的工具（Utilities）类目下找到 FTP Server，配置用户名与密码（可以留空）、端口（默认 21，被占用就换一个）。
3. 要从电脑往手机**上传**文件，需要打开写权限（Allow write access 一类的开关）；只从手机往外下载就不必开。
4. 启动服务后，界面会显示 `ftp://手机IP:端口` 形式的地址，记下它。
5. 电脑端在资源管理器地址栏输入这个地址，或用 FileZilla 之类的 FTP 客户端连接，像普通文件夹一样拖拽传输。
6. 传完把服务关掉；新文件若没出现在媒体库里，按 [常见问题与故障排查.md](常见问题与故障排查.md) 第一节强制重扫。

连不上的常见原因：两边不在同一网段、手机省电策略把后台服务杀了、路由器开了 AP 隔离。设置项的具体名称随版本略有差异，以你实机界面为准。

## 五、换机时的顺带建议

新手机装好应用后，把整个音乐目录**保持原有结构**整体拷过去，再加进媒体库重扫一遍，浏览习惯不用重新适应；旧手机上的 FTP 共享目录如果被电脑书签引用过，换机后只需按新地址重新连一次。
