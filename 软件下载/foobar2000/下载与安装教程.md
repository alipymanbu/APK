## 一、先搞清楚：这是哪个 foobar2000

foobar2000 是 Windows 上知名的老牌本地音乐播放器，作者 Peter Pawlowski（曾参与 Winamp 开发）。安卓版 2016 年上架 [Google Play](https://play.google.com/store/apps/details?id=com.foobar2000.foobar2000)，与桌面版同名同源，定位仍是「本地文件播放器」：不带在线曲库，放的是你自己拷进设备的音频文件，官方页面明确写了对设备文件的处理不附带遥测与数据收集。

本篇以网盘收录的这一版为准：**版本 1.6.2**（官方更新日志显示 2024-09-30 发布），安装包 16.29 MB，包名 `com.foobar2000.foobar2000`，MD5 `8CCE7052C0301600C9C162C7679A21D1`。官网现在主推的已经是 2.x 系列，新功能都发生在那条线上；1.6.x 属于旧版维护线，以修 Bug 为主。

## 二、版本线怎么选

| | 2.x（现行线） | 1.6.x（旧版线；网盘收录的是 1.6.2） |
| --- | --- | --- |
| 系统要求 | Android 7.0 或更新 | 官方旧硬件支持页对 1.5/1.6 这条线的口径是 Android 4.1 或更新（以官方页面为准） |
| 更新节奏 | 持续加新功能，版本号已与桌面版同步 | 以 Bug 修复为主 |
| 适合谁 | 近几年的手机 / 平板 / 电视 | 老设备，或你只想用一套自己熟悉的旧版 |

判断依据很简单：设备系统版本够 7.0 就装 2.x；老手机、老车机、旧平板装 2.x 报错或不兼容的，退回 1.6.x 这条线。

## 三、三条获取渠道

1. **官网 APK 直装**：[www.foobar2000.org/android](https://www.foobar2000.org/android) 按 32 位 / 64 位 / x86 分开提供 APK，免费下载，官方定位为免费软件。

3. **网盘离线包**：要装和本文口径一致的 1.6.2（不连商店、不想下最新版），用这份 **[foobar2000 安装文件资源（夸克网盘）](https://pan.quark.cn/s/82ada347c88c)**，转存后把 APK 拷到手机安装即可。

## 四、APK 安装步骤

1. 把 APK 文件放进手机存储（数据线、网盘 App 下载、局域网传输都行）。
2. 在文件管理器里点开 APK。第一次会提示「不允许安装未知来源应用」——Android 8 及以后按**来源**授权：只允许当前这个文件管理器安装应用即可，不必全局放开。
3. 装完在桌面打开。首次启动会让你选歌曲列表的展示模式（按歌手/专辑、按文件夹等），选一个顺眼的，以后在设置里可以换。

## 五、装完先做两件事

1. **把音乐放进去**：先把文件从电脑传进手机（数据线、局域网、应用自带 FTP 服务器几条路子见 [电脑传歌到手机的方法.md](电脑传歌到手机的方法.md)），拷到 `Music` 或自建目录，再到应用里把这些目录加进媒体库，具体步骤见 [媒体库扫描与标签整理.md](媒体库扫描与标签整理.md)；不确定你的文件它认不认，先对照 [支持哪些音频格式.md](支持哪些音频格式.md)。
2. **核对安装包**：在意原包完整性的话，安装前用校验工具比对 APK 的 MD5（第一节给的值），一致才算原包。
