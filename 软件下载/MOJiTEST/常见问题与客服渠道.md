## 一、装不上 / 打不开

按出现顺序排查：

| 现象 | 先查什么 | 处理 |
| --- | --- | --- |
| 点 APK 没反应 | 文件是否下载完整 | 对照 MD5 重新下载（校验方法见 [下载与安装教程.md](下载与安装教程.md)） |
| 提示解析包错误 | 安装包是否被改动过 | 换从 [MOJiTest 安装文件资源（夸克网盘）](https://pan.quark.cn/s/565444415709) 重新转存下载 |
| 安装到一半失败 | 存储空间 | 清出安装包两倍以上的空间再装 |
| 装上闪退 | 系统版本是否 Android 5.2+ | 系统过旧先升级系统 |

## 二、换手机后学习记录还在不在

学习记录、词书进度、已购内容都跟着**登录的账号**走。换机前在旧手机上确认当前登录的账号（手机号或第三方登录），新手机上用**同一个方式**登录，进度在应用内刷新后回来。

两个容易踩的点：

- 手机号登录和第三方登录是两个不同的账号身份，平时用 A 方式、换机后用 B 方式登录，看起来就是「记录丢了」；
- 换机前不确定登录方式时，先在旧手机的应用内查看当前账号信息，截图留存。

## 三、已购买的套餐找不回来

按这个顺序处理：

1. 确认登录的是**购买时用的那个账号**（上一节说的身份混用问题，九成出在这里）；
2. 在应用内的恢复购买入口操作一次；
3. 还不行就联系客服，提供：支付渠道、订单号或支付时间、当前登录账号——三样齐了处理最快。

具体的免费 / 付费范围对照，见 [会员套餐与内购价格说明.md](会员套餐与内购价格说明.md)。

## 四、联系官方客服

| 渠道 | 入口与用法 |
| --- | --- |
| 应用内微信客服 | 【设置 → 联系我们 → 微信客服】，发送「人工」接入服务队列 |
| 客服在线时间 | 工作日 9:00~18:00，节假日休息 |
| 微信公众号 | 「MOJi辞書」（官方指定客服入口，Test 用户同样走这里） |
| 邮箱 | `mojisho.support@mail.shareintelli.com`（应用商店官方介绍页给出） |
| 官网 | [test.mojidict.com](https://test.mojidict.com/)，页脚有「联系我们」 |

购买、账号类问题走人工客服；使用方法类问题先翻应用内的「使用指南」，多数操作问题里面有现成答案。

## 五、桌面小组件与学习提醒

- **桌面小组件**：在桌面空白处长按 → 进「小组件 / 窗口小工具」列表 → 找到 MOJiTest，拖到桌面；样式与展示内容在小组件设置里调，用来在碎片时间瞄一眼单词；
- **学习提醒**：在应用设置里开，定一个每天确定有空的时间点；提醒不灵时先查系统是否给了应用通知权限——很多手机默认把教育类应用的通知关了。

以上处理不了的问题，回到第四节找人工客服。
