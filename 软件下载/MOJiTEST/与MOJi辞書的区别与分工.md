## 一、一句话分清

两款应用都出自巨核信息科技（广州）有限责任公司，但分工不同：

- **MOJiTest**：备考练习场——词书背词、JLPT 真题与专项刷题、错题本、自习室都在这里；
- **MOJi辞書**：词典工具——日中查词是主业，官方的备考栏目内容（语法辨析、真题阅读精析、NHK 听力）也挂在这边及其网站 [www.mojidict.com](https://www.mojidict.com/) 上。

名字像、图标像，但它们是两个独立应用，商店里要分开安装。

## 二、你要做的事在哪个应用里

| 你想做什么 | 去哪个应用 |
| --- | --- |
| 背词书、刷 N1-N5 真题、整理错题 | MOJiTest |
| 查一个单词的释义、例句、发音 | 两个都能查，MOJi辞書 的词库更全 |
| 看语法辨析专栏（每周二更新） | MOJi辞書 / 其官网 |
| 看历年阅读真题精析（N1~N5 分级） | MOJi辞書 / 其官网 |
| 磨耳朵听 NHK 日语新闻 | MOJi辞書 / 其官网 |
| 电脑浏览器上查词 | MOJi辞書 的网页版与网页插件 |

做题时遇到生词不必切去辞書——MOJiTest 做题界面支持长按选词直接查，查完接着做；要深挖例句和用法时再开辞書。

## 三、买的时候别串

两款应用的付费内容**分开售卖、互不包含**：MOJiTest 卖词书与真题套餐，MOJi辞書 卖自己的会员。官方做促销时也常把它们拆成单项再给组合价——比如「辞書会员 + Test 的 JLPT 套餐」是两笔内容拼一个优惠，不是一张通用会员卡。

下单前认清两点：

1. 你现在打开的是哪个应用，在哪个应用内下的单，权益就只在哪个应用里；
2. 想配齐「背词 + 查词」两套工具的，按两个应用分别付费的思路算总账，别指望买一个送另一个。

各套餐的价格参考与挑选思路见 [会员套餐与内购价格说明.md](会员套餐与内购价格说明.md)。

## 四、客服入口挂在辞書名下

官方指定的客服渠道是微信公众号「MOJi辞書」——Test 的用户也走这个入口（官方在应用介绍里明确写着「客服找这里」）。找不到客服入口时按 [常见问题与客服渠道.md](常见问题与客服渠道.md) 里的方式联系。

## 五、怎么配合着用

按备考阶段配合效率最高：

1. **平时**：MOJiTest 清背词任务、按分项刷题；生词随手收藏，当天在辞書里查透一个最碍事的；
2. **周末**：翻一遍 Test 的错题本和收藏夹；在辞書的栏目里补本周做错的语法点；
3. **考前**：Test 按考试时长做整卷模拟；辞書的阅读真题精析当精读材料用，逐句过一遍近几年阅读。

还没装 MOJiTest 的，安装步骤在 [下载与安装教程.md](下载与安装教程.md)；背词与刷题的用法分别见 [词书选择与背词计划.md](词书选择与背词计划.md) 和 [真题刷题与专项练习指南.md](真题刷题与专项练习指南.md)。
