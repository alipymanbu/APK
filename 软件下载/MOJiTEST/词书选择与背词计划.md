## 一、按考试目标选词书

词书按考试线组织，先对号入座：

| 你的目标 | 对应词书 |
| --- | --- |
| JLPT N5 / N4（入门考级） | 对应级别词汇词书（红宝书覆盖 N1~N5） |
| JLPT N3 / N2 / N1（主流考级） | 对应级别词汇词书 + 新完全掌握（N1~N3） + 真题词汇 |
| 考研日语（203） | 考研日语蓝宝书、白宝书 |
| 高考日语 | 高中日语必修、选修词库（含人教版教材配套） |
| 手里在用某套教材 | 红宝书、官方绿宝书（完整录入）、新完全掌握 |

词书库共 100+ 本，以上是官方介绍里点名的人工精校词书。选词书的原则只有一条：**跟你正在备考的那条考试线一致**，不要同时开两本同级别的词书——进度互相拖，一本都背不完。

## 二、背词计划是怎么排的

选定词书后，应用按艾宾浩斯遗忘曲线给你排每日任务：新词按固定节奏出现，旧词在快忘的节点安排复习。这意味着：

- **每天把当日任务清完**比「今天多背 200 个」重要——断一天，复习队列就往后堆；
- 每日新词量可以在设置里调，宁可调低到能天天完成，也不要定一个三天就弃的量；
- 完成每日复习任务后会自动开启**拼写进阶题型**，难度比选择题高，用来检验是真会了还是看着眼熟。

打卡日历会记录累计学词量、学习天数和学习时长，坚持打卡还能拿勋章——这些是记录工具，别把它们当目标。

## 三、题型自选：官方提醒过的一个坑

背词题型可以自定义，但官方在应用内明确提示过一条经验：**【看单词选释义】和【看单词选错义】两个题型建议只选一个**，两个同时开容易影响做题准确率——两种题型对同一批词反复出，会互相干扰判断。

设置时先只开「看单词选释义」，过一周如果发现正确率虚高（是靠排除法做对的），再换成「看单词选错义」加强辨析。

## 四、难词单独管

背词过程中遇到的难词可以**一键收藏**，收进单独的生词本反复看。实用组合：

1. 每天背词时随手收藏记不住的词，不打断当日进度；
2. 周末集中过一遍生词本，已经记住的移出；
3. 做真题和专项训练时遇到的生词也收进来——两处收藏汇成一本，考前只翻这一本。

## 五、发音与提醒设置

- **发音**：词书的发音模式、语速快慢、发音次数都能调。备考听力的建议把发音次数设为一次——考试里听力只放一遍，平时就按这个标准练；
- **学习提醒**：在设置里定一个固定时间提醒背词。提醒时间定在你每天都有空的点（通勤、午休），不定在「理想作息」的点上——定错了只会天天关提醒。
