## 一、角色总是「忘事」

官方 FAQ 的解释：角色只能「看到」有限的对话上下文，较早提到的事一旦不在近期上下文里，就会被「忘掉」。你能做的：

1. 把关键设定写进设定集（lorebook），比在对话里反复提醒可靠，用法见 [角色创建与群聊用法.md](角色创建与群聊用法.md)；
2. 重要信息在对话中段再自然提一次，别只开头说一遍；
3. 有评测提到聊天内的 Author's Note 能把长期细节固定在上下文里，且在其云端模型实测中 30 多条消息后角色仍记得细节——不代表所有模型都这样，功能入口以应用内为准；
4. 上下文档位越大忘得越慢，订阅更高档位可扩大上下文（见 [免费与付费区别.md](免费与付费区别.md)）。

## 二、发消息没反应 / 回复很慢

手机版聊天走云端模型，可按这个顺序排查：

1. 确认手机网络正常（切一下 Wi-Fi / 流量对照）；
2. 换一个模型再试——云端模型的速度受当时负载影响，免费档那批模型高峰期可能偏慢；
3. 对话拖得越长上下文越大、回复越慢，新开一个对话立刻变轻快；
4. 想换剧情走向重开时留意：有评测指出当时同一角色只保留一个对话线程，切走向得清空重来（以当前版本为准）；
5. 还不行就确认应用是不是太旧，按第三节的更新方式处理。

## 三、安装与更新问题

- **解析失败 / 安装包损坏** → 核对文件是否下载完整（完整包约 51.28 MB，明显偏小就是没下完），重下再装，步骤见 [下载与安装教程.md](下载与安装教程.md)；
- **旧版本的兼容问题** → 从 Google Play 更新到当前版（版本号在 0.0.x 持续演进，以商店页面为准）；
- **后台被杀** → 手机版聊天是实时请求，应用被系统清理后重开即可，聊天记录默认存本机、不会因此丢失（数据口径见 [聊天记录与隐私说明.md](聊天记录与隐私说明.md)）。

## 四、账号与数据

- **不登录能用吗** → 能，官方明确登录是可选项；登录换的是云同步、更多模型与订阅功能。
- **删号会删掉什么** → 服务器侧的云端数据（云端角色、云端故事）全部清除、不可恢复；本机聊天、角色与故事不受影响。
- **手机上删聊天很麻烦** → 有用户反馈手机版暂无批量删除按钮，多条对话只能逐条删。
- **在国外登录不上** → 官方在个别国家/地区屏蔽了官网登录（英国用户被挡有官方回复确认，日本可用）；以官方渠道与你所在网络的实测为准。
- **遇到 Bug 或要反馈** → 官方渠道有 Discord、Reddit（`https://www.reddit.com/r/HammerAI`）、X（`https://x.com/HammerAIDotCom`），官网 FAQ 页也有直接反馈入口。

## 五、内容边界与角色纠纷

- 平台有官方内容规范（Content Guidelines），聊天、自建角色、发布故事都要在规范内；页面见 `https://www.hammerai.com/content-guidelines`。官方条款要求用户至少年满 18 周岁（或当地成年标准），角色库含成人向内容，搜索另有 Safe / Mature 分级过滤（第三方评测口径）——低龄设备安装前家长自己把握。
- **自己的角色被别人冒用发布** → 官方 FAQ 提供移除申请渠道，提交时带上角色名、你原作页面的链接和移除说明。
