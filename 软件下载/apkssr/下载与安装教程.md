关于系统要求，这里要说明一句：安装包信息页上写的是「需要安卓系统 5.2 以上」，而 Android 的官方版本号里并没有 5.2 这一档，这类写法通常是页面模板沿用了旧数值，实际的最低兼容版本以你手机上安装时的拦截提示为准。判断自己的机器装不装得上，最省事的办法是直接拿安装包试装一次，系统不接受会明确告诉你，不会留下半装状态。

## 二、装之前要核对的两件事

**第一，别和同名的另一份包装混。** 这份包的包名是 `site.cacolu.laroxyz`。叫 apkssr 的应用在各路下载站上不止一个，靠名字和图标分不出谁是谁；不同包名在系统里就是两个互不相干的应用，**无法互相覆盖安装**，数据也各算各的。如果你手机上已经装过一个，先按 [同名应用与版本怎么认.md](同名应用与版本怎么认.md) 第三节看清它的包名，再决定留哪一个。

**第二，先备好存储空间和网络。** 安装包本身 19.32 MB，装完占用会更多；安装过程中系统要同时放下安装包与解包后的文件，**空闲空间按安装包体积的 2~3 倍留（也就是 60 MB 上下）比较稳**，这一点在空间吃紧的旧机型上才会成为问题。应用本身要联网才能拉到内容，首次打开如果网络不通，界面往往会停在加载状态而不是弹错误提示。

想顺手确认下载的包有没有传坏，可以在电脑上算一遍 MD5，结果应当与上表逐位一致。Windows 用系统自带命令即可：

```cmd
certutil -hashfile apkssr_v3.8.4.apk MD5
```

macOS 与 Linux 上的等价写法：

```bash
md5 apkssr_v3.8.4.apk        # macOS
md5sum apkssr_v3.8.4.apk     # Linux
```

（文件名随版本变化，以你实际拿到的文件为准。）

## 三、安装步骤

1. **转存并下载**：先把网盘里的 APK 转存到自己的网盘，再下载到手机或电脑。
2. **把包送到手机上**：手机端直接下载最省事；在电脑下载的话，用数据线、文件传输助手或任意传输工具拷进手机存储。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给你用来打开安装包的那个应用（文件管理器或浏览器）打开开关。各家路径不同，Android 13 之后的机型还多一层限制，逐机型路径见 [安装权限怎么开.md](安装权限怎么开.md)。
4. **点击 APK 完成安装**：系统提示「应用未经过安全检测」或「来自未知来源」时，选择继续安装即可。这是所有侧载安装包都会遇到的常规提示，不代表文件有问题。
5. **覆盖安装要看版本高低**：安卓不允许用更低版本的安装包覆盖更高版本，会直接报「应用未安装」。如果你手机上那份版本号已经高于 3.8.4，要先卸载旧版再装这一份。
6. **装完先别急着点开**：先把下一节的三处过一遍，否则首屏可能停在一片空白或加载中的界面上。

## 四、第一次打开要看的三处

1. **网络**：应用的主界面、检索和下载都依赖联网。打开后如果一直停在加载动画，先在浏览器里确认手机能正常上网，再回来看 [常见问题与排查.md](常见问题与排查.md)。
2. **它向你要的权限**：这类应用常见的是存储权限（读写下载下来的文件）和「安装未知应用」。如果弹出与检索、下载都无关的权限申请（比如读取短信、通讯录、设备管理器），直接拒绝即可，不影响基本使用。
3. **版本是否对得上**：打开「设置 → 应用 → 全部应用」，找到它点进应用信息，版本号应显示 3.8.4。对不上说明装的不是网盘里这一份。

## 五、装完做一次最小验证

1. 打开应用，确认主界面能正常显示、不会自动退出；
2. 在应用内的搜索或列表里点开任意一条内容，能看到详情页，说明联网这一侧通了；
3. 退出再重进一次，确认不会每次打开都重新加载到超时；
4. 回设置里再核一次版本号，确认为 3.8.4。

后续换版本或重装，仍然从网盘资源里取用。安装过程中被系统拦下、报解析包错误、装完闪退这几类情况，处理办法集中在 [常见问题与排查.md](常见问题与排查.md)。
