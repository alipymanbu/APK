# HPmod 悬浮窗权限在哪里开

> 进游戏呼不出 HPmod 面板，多半是悬浮窗权限没开。各品牌把这个权限放在不同菜单、还起了不同名字，本篇给你路径对照表和通用找法。

## 一、先确认要开的是这项权限

拿这两个症状对号入座，别开错地方：

| 症状 | 要处理的是什么 |
| --- | --- |
| HPmod 自己能打开，进游戏后呼不出面板 | 悬浮窗权限（本篇） |
| 点开 HPmod 就退回桌面 | 不是权限问题，按 [闪退打不开怎么办.md](闪退打不开怎么办.md) 的清单查 |

悬浮窗权限做的事只有一件：**允许应用把窗口叠在其他应用上面**。它在不同品牌里的叫法不一样 —— 悬浮窗、显示在其他应用上层、Draw over other apps，说的都是它。HPmod 要在游戏画面上叠一层控制面板，靠的就是这项权限。

## 二、各品牌的路径对照

下表取自各厂商公开的支持文档（截至各文档所示，菜单名可能随后续系统更新调整）：

| 品牌 / 系统 | 路径 |
| --- | --- |
| 原生 Android（Pixel 等） | 设置 > 应用 > 特殊应用权限 > 显示在其他应用上层 |
| 华为（HarmonyOS） | 设置 > 应用和服务 > 权限管理 > 悬浮窗（"应用"或"权限"页签下都能找） |
| OPPO（ColorOS 13 及以上） | 设置 > 应用 > 特殊应用权限 > 悬浮窗 |
| OPPO（ColorOS 12） | 设置 > 应用 > 悬浮窗 |
| OPPO（ColorOS 11 ~ 11.3） | 设置 > 应用管理 > 显示在其他应用上层 |
| 三星、小米、vivo 等 | 用设置顶部的搜索框搜"悬浮窗"或"显示在其他应用上层" |

找不到菜单时的通用办法就两条：**在设置里直接搜这两个词**；或者长按 HPmod 图标 → 应用信息 → 权限 / 高级权限里找。找到后把 HPmod 那一项打开，重进游戏即可。

## 三、开的时候注意两点

这两条来自厂商支持文档本身的提示，不是额外猜测：

- **只给你信得过的应用开**。华为与 OPPO 的支持文档都写明：开启悬浮窗后可能产生弹窗广告。这项权限是通用的，管它的是哪个应用，开之前先确认是自己刚装的那个 HPmod（包名 `mk.hp`，见 [下载与安装教程.md](下载与安装教程.md) 的信息表）。
- **这项权限不等于交出数据**。它只决定"窗口能不能叠在上层"，不涉及通讯录、相机这些；HPmod 的存储权限是另一项，授予与回收在同一个权限管理页面里操作。

## 四、开了还是呼不出来

按顺序再过三步：重启 HPmod 再进游戏（权限改动有时要重启应用才生效）→ 把权限关掉重开一次 → 按 [闪退打不开怎么办.md](闪退打不开怎么办.md) 核对游戏版本是否匹配、内存是否充足。这几步都排除后仍呼不出，多半不是权限层面的问题了。
