## 一、先看清你要装的是什么

HPmod 是安卓端的《我的世界》第三方辅助工具，独立安装，不挂在游戏里。装之前对照下面这张表，确认你拿到的包和这份资料是同一个东西：

| 项目 | 数值 |
| --- | --- |
| 版本 | 1.0 |
| 包名 | `mk.hp` |
| 安装包大小 | 8.91M |
| MD5 | `CF8BEEBEA9416588803A3282A52B45CF` |
| 系统要求 | 安卓 5.2 及以上 |
| 语言 | 简体中文 |

注意：网上各软件收录页会写"公益 9.6""10.0"之类的宣传版本名，但落到包上往往还是同一个 `mk.hp`、v1.0。**版本号、包名、体积一律以本表为准**（表里的事实取自 2026-09-23 的实际安装包）。另外，你手机上《我的世界》本身分中国版与国际版两套，装 HPmod 前先分清自己用的是哪套，见 [支持中国版还是国际版.md](支持中国版还是国际版.md)。

## 二、下载与安装步骤

1. 打开 [HPmod 安装文件资源（夸克网盘）](https://pan.quark.cn/s/717ae85a2deb)，把 APK 转存到自己的网盘后下载到手机；电脑上下的话，再传到手机。
2. 在手机的文件管理器里点击这个 `.apk` 开始安装。
3. 如果弹出"禁止安装来自此来源的应用"，是系统的未知来源拦截：按提示进入设置，允许当前来源（文件管理器或浏览器）即可，装完可以再关掉。
4. 装好先别急着进游戏 —— 下一节的权限先授了，游戏内才调得出面板。
5. 打开 HPmod，再启动《我的世界》。

## 三、首次启动要授的权限

各收录页的开启说明都只有一句："授权软件部分权限后即可在游戏中打开使用"。结合它的用法，你大概率会碰到这两类授权：

- **悬浮窗 / 显示在其他应用上层**：游戏内调出控制面板靠的就是它，不给这项，进游戏后多半什么也呼不出来；
- **存储**：读写配置与进度用。

不确定它具体弹什么，装完第一次启动时按需点允许即可。事后也能改：设置 → 应用 → HPmod → 权限。权限没给全的典型表现是进游戏没反应或直接闪退，排查见 [闪退打不开怎么办.md](闪退打不开怎么办.md)；悬浮窗这项在各品牌手机里的菜单位置不一样，对照表见 [悬浮窗权限在哪里开.md](悬浮窗权限在哪里开.md)。

## 四、核对安装包没下错

下载的渠道一多，包就容易被换过。用 MD5 对一遍最省事，Windows 上在 APK 所在目录执行：

```powershell
certutil -hashfile HPmod_v1.0.apk MD5
```

输出与 `CF8BEEBEA9416588803A3282A52B45CF` 完全一致（不区分大小写）就是同一个包；对不上就删掉，回到上面第二节的网盘链接重新拿一份。手机上没有现成工具的话，装一个 MD5 校验类应用也能算。

## 五、装完第一步做什么

按 [自动搭路功能使用教程.md](自动搭路功能使用教程.md) 的顺序走一遍：进功能面板 → 选搭路模式 → 速度先调到慢档试跑 → 挂上快捷键。第一次就开快档，机器带不动时排查起来会绕远路。
