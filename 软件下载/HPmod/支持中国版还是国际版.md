## 一、手机上的《我的世界》其实是两个东西

同叫《我的世界》，安卓上你装的只可能是下面两版之一：

| | 中国版 | 国际基岩版 |
| --- | --- | --- |
| 开发 / 运营 | Mojang 授权、网易代理 | Mojang（微软） |
| 怎么拿 | 应用商店或官网免费下载 | Google Play 等商店一次性买断 |
| 安卓包名 | `com.netease.x19` | `com.mojang.minecraftpe` |
| 账号 | 网易账号（渠道服则是渠道账号） | 微软账号 |
| 更新节奏 | 通常落后国际版约一年（第三方文档口径，截至其撰写时） | 与全球同步 |

另外两点先摆清：**Java 版只能在电脑上运行，手机与它无关**；中国版对个人存档有额外的加密处理，**两版的存档与联机互不相通**（第三方文档口径）。

## 二、HPmod 支持哪一版

先把证据边界说清楚：各收录页对 HPmod 的口径只有"适配各类游戏版本"这一句，**没有任何公开资料点名中国版或国际版** —— 公开资料没写死的事，这里不替你选边。能确认的只有：

- HPmod 是安卓应用（包名 `mk.hp`），只可能与安卓上的这两版发生关系，与电脑 Java 版无关；
- 你本机装的是哪版，只有你自己知道 —— 装好 HPmod 后按 [自动搭路功能使用教程.md](自动搭路功能使用教程.md) 跑一次慢档：能呼出面板、能正常搭路，就是匹配的；呼不出或秒退，先查 [闪退打不开怎么办.md](闪退打不开怎么办.md) 清单里的第 3 条（游戏版本配不配）。

## 三、存档不互通，对你意味着什么

1. **换版本等于存档重来**：中国版的存档带不到国际版，反之亦然。动念换版本之前先把存档复制一份（备份做法见 [会不会封号与账号安全.md](会不会封号与账号安全.md) 第三节）。
2. **联机只能同版本**：和朋友开房间前先对齐各自用的是哪一版 —— 版本不同的房间进不去，不是 HPmod 的问题。
3. **两版的更新不同步**：同一时期两版的游戏版本号本就不一样，"我这版最新、他那版旧"很正常，先分清是版本差异还是真故障，再决定要不要动 HPmod。

## 四、装之前再核一遍包

无论你用哪一版游戏，HPmod 的安装包都是同一份：v1.0、`mk.hp`、8.91M，核对方法见 [下载与安装教程.md](下载与安装教程.md) 第四节。
