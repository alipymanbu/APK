扣子（Coze）是字节跳动旗下的 AI 助手应用，安卓端安装包名为 `com.coze.space`，开发者主体为北京春田知韵科技有限公司。你在手机上用文字、语音或拍照交代一件事，它会拆解步骤、调用工具并把结果交付给你，适合想把资料整理、写作、日程这类日常事务交给 AI 处理的人。本篇只讲「它是什么、能做什么」，安装方法见 [下载与安装教程.md](下载与安装教程.md)。

## 它能替你做哪些事

按官方文档列出的场景，手机上比较常用的有这些：

| 场景 | 你要做的 | 你拿到的 |
| --- | --- | --- |
| 日常问答与方案 | 发一条消息描述需求 | 对话里直接给结果，可继续追问修改 |
| 办公三件套 | 说清主题与要求 | 文档、Excel、PPT 成品文件 |
| 视频 / 海报 / 播客 | 给主题或素材 | 从剧本到成片的创作产物 |
| 编程项目 | 描述想要的网页、App 或小程序 | 可预览、可部署的应用项目 |
| 会议旁听 | 开会时打开旁听 | 实时转写 + 会后纪要、结论、待办 |
| 话题追踪 | 订阅关注的主题 | 持续收集的行业动态与进展 |
| 日程与邮件 | 一句话创建定时任务 | 到点自动执行，结果回传 |

具体怎么在手机上把这些事派出去，见 [怎么用手机端发起任务.md](怎么用手机端发起任务.md)；做这些事会消耗积分，额度与价格见 [积分与收费标准.md](积分与收费标准.md)。

## 三种 Agent，区别在哪

扣子里的 Agent 是「替你干活的角色」，分三类，选错会影响任务能不能做：

| 类型 | 跑在哪 | 适合什么 |
| --- | --- | --- |
| 扣子 Agent | 扣子云端，开箱即用 | 日常办公、内容创作、资料整理，新手默认用它 |
| 云端 Agent | 扣子提供的云电脑 | 长任务、自动化、代码开发，不占你的手机和电脑 |
| 本地 Agent | 你自己的电脑 | 要读本机文件、跑本地代码或软件的任务 |

两点容易被误解的地方：

- 云端 Agent 里接入的 Claude Code、Codex CLI 等框架，用的是扣子平台提供的模型，**不能登录你自己的 Claude / OpenAI 账号**，也不消耗你个人订阅的额度。
- 手机端发起的任务若涉及本地电脑，需要先在电脑端授权连接，手机只是下达指令的一端，见 [多端同步与项目协作.md](多端同步与项目协作.md)。

## 手机版和网页版是什么关系

同一个账号下，网页端（`coze.cn`）、桌面端与移动端的项目、对话、文件和任务进度会自动同步：电脑上开工的方案，通勤路上可以在手机里继续追问；手机上拍的纸质材料，回去能在电脑上接着编辑。各端不另收费，区别只在于电脑端能处理本地文件、手机端胜在随时派活。

## 适合谁用

- 想把周报、纪要、资料汇总这类重复性文字工作交给 AI 的人；
- 需要在外面跑、只能用手机推进工作的人（语音、拍照都能直接派任务）；
- 对编程有一点兴趣、想用自然语言做网页或小程序尝鲜的人（注意这类任务消耗积分较多，见 [积分与收费标准.md](积分与收费标准.md)）。

如果你只是偶尔问几个问题，用免费积分就够；要长期派活，先把收费规则看明白再决定。
