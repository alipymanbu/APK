很多人分不清扣子（Coze）和豆包：两个都是字节跳动的 AI 应用，图标都常驻手机桌面，但分工不一样——豆包是「你问它答」的聊天助手，扣子是「你说需求、它执行交付」的任务型 Agent。本篇把两者的差异列成对照，帮你判断该装哪个（不少人最后是两个都装）。扣子本身是什么，先看 [是什么软件.md](是什么软件.md)。

## 一张表看懂定位差异

| 对比项 | 豆包 | 扣子 |
| --- | --- | --- |
| 交互方式 | 提问 → 它回答 | 交代任务 → 它自己拆步骤执行 |
| 典型场景 | 问答、闲聊、查资料、写段文案 | 整理资料、做 PPT、剪视频、开发小程序、盯日程 |
| 模型 | 字节自家豆包模型 | 豆包、Kimi、GLM、Minimax 等主流模型可切换 |
| 工具能力 | 以对话为主 | 可接插件与 MCP，能操作云电脑、云手机等设备 |
| 产出形态 | 对话里给答案、给文字 | 交付成品文件：文档、PPT、视频、可部署的应用 |
| 定时执行 | 不擅长 | 建日程到点自动跑，结果回传对话 |

## 用起来的体感差别

同一个需求在两边做法不同，拿「做一份周末出游攻略」举例：

- 在豆包里，你提问，它基于自己的知识给一份文字攻略，你再逐条追问；
- 在扣子里，你交代需求，它可以结合插件与联网能力自己查、自己整理，最后交付一份文档或表格，还能顺手把出发提醒建进日程。

再拿「每周汇总一遍行业新闻」举例：豆包适合你每周想起来去问一次；扣子适合建一个话题追踪或日程任务，让它到点自己跑，你在手机上看结果就行。怎么建这类任务，见 [怎么用手机端发起任务.md](怎么用手机端发起任务.md)。

## 费用逻辑也不一样

豆包的日常问答基本不设门槛；扣子按积分计费——每日登录能领免费积分，重度任务（视频、云设备、编程）消耗大，需要订阅套餐才够用。具体额度、价格与省积分做法，见 [积分与收费标准.md](积分与收费标准.md)。

## 怎么选

| 你的情况 | 更适合 |
| --- | --- |
| 平时问问题、查资料、随手写点东西 | 豆包 |
| 想把整理资料、做 PPT、写周报这类活整个交出去 | 扣子 |
| 需要定时自动执行的任务（每日早报、定时提醒） | 扣子 |
| 想用自然语言做个网页或小程序 | 扣子 |
| 只想要一个免费聊天助手，不想管积分 | 豆包 |

两个 App 不冲突：装扣子（安装途径见 [下载与安装教程.md](下载与安装教程.md)）之后，豆包照样可以留在手机上当日常问答工具，按任务的性质各用各的。
