## 安装步骤

1. 把 APK 下载到手机存储；
2. 在文件管理器里点开这个 APK；首次安装会提示「禁止安装未知来源应用」，点提示里的「设置」→ 允许该来源安装（不同品牌叫法略有差异，华为/小米/OPPO 都有这一步）；
3. 回到安装界面点「安装」，等进度走完；
4. 点「打开」进入 App，按提示登录账号（支持手机验证码等方式，也可以用抖音授权登录）。

体积约 55 MB，装完后首次打开还会下载数据，建议预留 500 MB 以上的可用空间。

## 装不上或打不开怎么办

| 现象 | 处理 |
| --- | --- |
| 提示「解析包错误」 | 多半是下载不完整，重新下载一遍后核对 MD5 再装 |
| 卡在「允许未知来源」这一步 | 部分系统要在「设置 → 应用 → 特殊权限 → 安装未知应用」里，对文件管理器单独放行 |
| 安装完点开闪退 | 先确认系统版本满足安装包要求（这份包对系统要求不高，标注支持安卓 5 以上），再重启手机试一次 |
| 装好后收不到验证码 | 检查是否被短信拦截类 App 拦下，或换抖音授权登录绕开短信验证 |
