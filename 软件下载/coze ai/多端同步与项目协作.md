# 扣子多端同步与项目协作怎么用

> 讲扣子（Coze）手机、电脑、网页三端怎么接力，项目和普通对话有什么区别，以及当前版本几个绕不过去的限制。

扣子（Coze）的网页端、桌面端、移动端共用同一个账号，项目、对话、文件和任务进度自动同步：电脑上开工的活，路上用手机接着推进；手机上拍的材料，回电脑上继续编辑。本篇讲同步的规则、什么时候该建「项目」，以及几个容易踩的限制。

## 各端怎么分工

| 端 | 拿来做什么 |
| --- | --- |
| 移动端 | 随时派任务、语音输入、拍照上传、开会开旁听 |
| 桌面端（Windows / macOS） | 处理电脑里的本地文件、连接本地软件 |
| 网页端（`coze.cn`） | 不装客户端时的替代；订阅购买与取消在这里操作更稳 |

手机想把活派给你的电脑做（比如整理电脑里的某个文件夹），要先把电脑端装好并授权连接，之后在手机上就能遥控它干活。

## 对话同步的三条规则

1. **同账号各端打通**：项目、对话、文件、设置自动同步，换设备不用迁数据；
2. **渠道之间对话不打通，但记忆打通**：你在飞书、微信里和它的对话，在 App 里看不到聊天记录，但它记得你交代过的事；
3. **已归档对话还在**：旧版留下的历史对话在「对话 → 已归档对话」里找。

## 什么时候该建项目

普通对话只有一条主线，话题容易越聊越乱。项目是独立的工作空间，适合长期、多主题并行的情况：

| 对比项 | 普通对话 | 项目 |
| --- | --- | --- |
| 上下文 | 共用一个主对话 | 每个项目独立，互不干扰 |
| 成员 | 只有你 | 可邀请人类成员和 Agent |
| 协作方式 | 直接对话 | @ 成员或 @ Agent 派任务 |
| 文件与产物 | 混在对话里 | 留在项目内，方便回溯 |

手机上建项目：在对话列表点「+」→ 选「新建项目」→ 填项目名并选择加入的 Agent。两个注意点：

- **项目协作属于付费权益**：免费版开不了多人协作，哪一档能开、每项可加多少人，见 [积分与收费标准.md](积分与收费标准.md) 里的套餐表；
- Agent 可以 @ 人类成员，但目前**不能直接 @ 另一个 Agent**，只有人才能给 Agent 派活。

## 当前版本的几个限制（截至 2026 年 9 月）

这些是官方 FAQ 明确写着的「暂不支持」，用之前心里有数：

- **不能删除聊天记录**：出于隐私与数据安全的设计，对话内容删不掉，介意的内容不要发；
- **不能重置或清空对话**：想要全新开始，只能新建一个 Agent 重新认识；
- **不能删除已创建的 Agent**：闲置的 Agent 不产生费用，放着即可；
- **云端 Agent 登不了你自己的模型账号**：Claude Code、Codex CLI 等云端框架用的是平台模型，不支持登录你的 Claude / OpenAI 订阅；
- **扣子编程 Agent 和视频 Agent 加不进普通项目**：编程项目本身支持多人协作，但普通项目里加不了这两类。

这些限制以官方文档的最新说明为准，很可能随版本更新变化。第一次上手还是从派任务开始，流程见 [怎么用手机端发起任务.md](怎么用手机端发起任务.md)；还没装的话先看 [下载与安装教程.md](下载与安装教程.md)。
