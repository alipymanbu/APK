扣子（Coze）可以免费用：每日登录送免费积分，轻度的问答、小任务用免费额度就能覆盖；任务越复杂、跑得越久，扣的积分越多，长期重度使用才需要考虑付费套餐。以下价格与额度整理自官方文档（截至 2026 年 9 月），随时可能调整，以官方页面为准。

## 哪些动作会耗积分

| 动作 | 说明 |
| --- | --- |
| 与 Agent 对话派任务 | 每次互动都消耗，任务越复杂消耗越多 |
| 创建 / 执行日程 | 建日程扣一次，每次到点执行再扣一次 |
| 视频、海报、PPT 等创作 | 按产物复杂度计，视频是消耗大头 |
| 云手机 / 云电脑 | 按设备规格与在线时长计 |
| 编程项目 | 与编程 Agent 对话开发网页、App、小程序都消耗 |
| 文件存储、邮箱 | 限时免费，正式计费时间以平台公告为准 |

## 套餐价格（个人版）

| 套餐 | 月费 | 每月积分 | 备注 |
| --- | --- | --- | --- |
| 个人免费版 | 0 元 | 每日登录领取 | 基础对话与小任务够用 |
| 个人进阶版 | 39.9 元 | 3 万 | 可接入自定义模型、去视频水印 |
| 个人高阶版 | 99 元 | 9.9 万 | 可用云设备、创建云端 Agent、项目协作 |
| 个人旗舰版 | 199 元 | 19.9 万 | 云设备可扩容、增购 |
| 个人尊享版 | 999 元 | 99.9 万 | 新模型优先内测等 |

团队版（198 元起）与企业版（498 元起）面向多人协作与组织管理，个人用户一般用不到；具体档位与权益以官方订阅页为准。

## 一次任务大概扣多少

官方文档给出过参考案例（数值仅供参考，不同任务浮动很大）：

| 任务类型 | 参考消耗（积分） |
| --- | --- |
| 创建一条日程 | 约 34 |
| 发一封邮件 | 约 39 |
| 做一张营销海报 | 约 72 |
| 做一份 PPT | 约 263 |
| 用云手机刷一次微博 | 约 238 |
| 开发一个小程序 | 约 1756 |
| 制作一段完整视频 | 约 25000 |

从这组数字能读出实用结论：**问答、日程这类轻任务是「免费积分」的舒适区；做视频、跑云设备是积分黑洞**，免费额度撑不住，动笔前先想清楚这个任务值不值。

## 充值与取消，注意这两个坑

- 官方 FAQ 明确提示过：**在 App 内可能无法升级或取消订阅**。要买套餐、改套餐或退订，去网页端（`coze.cn`）的订阅页操作更稳妥；
- 支付渠道以官方页面实际显示为准，App 内充值入口受限时不要反复重试，先换网页端。

## 省积分的几个做法

- 日常小问题用免费积分，别动不动开视频项目；
- 创建日程任务前想清楚频率：每日执行的任务每次都扣分，低价值的高频任务删掉；
- 简单文档自己把要求一次性说全，减少来回返工的对话轮数。

积分余额与消耗明细都在 App 的账户页面可以查，建议重度使用前先看一眼前几天的消耗量再决定买哪档套餐。安装与登录问题回到 [下载与安装教程.md](下载与安装教程.md)；任务怎么派见 [怎么用手机端发起任务.md](怎么用手机端发起任务.md)。
