## 一、两条路线的来路

Zotero 是免费开源的文献管理软件（[www.zotero.org](https://www.zotero.org/)），手机端现在有两条能用的路线：

| | Zoo for Zotero（本网盘这份） | Zotero 官方安卓版 |
| --- | --- | --- |
| 开发方 | mickstar（Michael Johnston），个人开源项目 | Zotero 官方团队 |
| 开源 | 开源（MIT 许可，[github.com/mickstar/Zoo-For-Zotero](https://github.com/mickstar/Zoo-For-Zotero)） | 不开源 |
| 获取 | 本网盘，或作者 [GitHub 发布页](https://github.com/mickstar/Zoo-For-Zotero/releases) | Google Play（包名 `org.zotero.android`） |
| 时间线 | 3.1a 发布于 2024-05；截至 2026-09，GitHub 最新为 v4.0.0（2025-08，更新日志称适配安卓 16、改版了注册页与附件存储管理） | 2024-09 起公测，2025-06 官方发布；公测期团队答复的最低系统是安卓 6，以商店页面为准 |

两边的时间信息都会随发布变化，以各自发布页当时显示为准。

## 二、功能清单对照

两边都有官方口径，原样列给你自己比对。

**Zoo for Zotero 有**（应用官方描述与作者论坛答复）：

- 浏览个人库、集合、群组库（应用介绍列明支持集合含子集合的层级组织）
- 搜索
- WebDAV 附件同步，双向（改动可传回服务器）
- 附件按需下载（点开才拉取）
- 附件标注同步
- Zotero 笔记的创建、编辑与删除（第三方收录的应用介绍口径，以你手上版本实测为准）
- 自定义存储路径
- 只支持官方 Zotero 账号同步；缓存文献库、仅同步变更

**Zotero 官方安卓版有**（官方博客列出的功能）：

- 同步个人与群组文献库
- 查看与编辑条目详情
- 集合整理
- 笔记
- 阅读 PDF，加高亮、笔记、图片类标注
- 在浏览器或其他应用里分享 URL 直接保存进文献库
- 按 DOI、ISBN、PMID 等标识符添加条目
- 自动抓取文献元数据
- 扫图书条码加入文献库
- 自动下载文章 PDF（限于无需登录即可访问的 PDF，受安卓系统限制）

## 三、按需求对照着选

| 你的情况 | 参考去向 |
| --- | --- |
| 想在手机上保存网页、DOI、扫条码收新文献 | 官方版有这条采集链路；Zoo for Zotero 的官方描述未提及 |
| 附件放在自己的 WebDAV（如 Nextcloud）上 | Zoo for Zotero 明确支持 WebDAV 双向；官方版沿用 Zotero 的 WebDAV 体系，配置项以官方文档为准 |
| 想自定义附件存储位置（如 SD 卡目录） | Zoo for Zotero 有自定义路径设置 |
| 想在手机上直接做高亮、笔记类结构化标注 | 官方版列明支持；Zoo for Zotero 依赖外部编辑器改文件写回，桌面端标注有用户反馈不可见 |
| 主要用群组文献库共享文献 | 两边的群组附件都只能走 Zotero 官方存储、额度记在群主账号上（官方口径），见 [群组文献库与共享同步.md](群组文献库与共享同步.md) |
| 在意更新频率与长期维护 | 官方版由官方团队持续更新；Zoo for Zotero 的节奏看作者发布页 |

两边登录的是同一套 Zotero 官方账号，文献库本体存在 Zotero 的同步服务上，换用哪个客户端都不用搬数据。数据同步与附件存储的口径两边一致（免费 300 MB 或 WebDAV），详见 [账号登录与文献库同步.md](账号登录与文献库同步.md)。

## 四、网盘这份对应哪个版本

网盘里固定是 Zoo for Zotero 3.1a（对应作者 2024-05-23 的发布，信息记录于 2026-09-27），和官方安卓版的版本号体系无关，不要拿官方版的功能清单去要求这份旧客户端。装哪份、怎么装，见 [下载与安装教程.md](下载与安装教程.md)；装好后怎么翻库、怎么写回 PDF，见 [文献库浏览与PDF标注.md](文献库浏览与PDF标注.md)。
