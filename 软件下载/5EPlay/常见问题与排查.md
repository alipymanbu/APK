这篇把 App 用起来最容易卡住的几类问题按现象归类：先给一条自己能试的，再给还不行时的下一步。账号与扫脸的细节另外指到对应篇章，不在这里重复。

## 安装与启动

| 现象 | 先试这一步 | 还不行再看 |
| --- | --- | --- |
| 提示「解析包错误」 | 重新下载安装包，确认文件完整 | 核对 MD5，换网络重下 |
| 提示「安装失败」 | 检查存储空间与「未知来源」权限 | 重启手机后再装 |
| 被系统直接拦下 | 关掉「纯净模式」后重装 | 用文件管理器打开安装包 |
| 装好后闪退、白屏 | 清除应用缓存后重开 | 卸载重装 |
| 换手机后装不上 | 确认安卓版本是否过低 | 改用官方下载页的当前版本 |
| 想升到新版本 | 到官方下载页取当前版本覆盖安装 | 用网盘那份按本文版本重装 |

包名与 MD5 的核对值写在[下载与安装教程.md](下载与安装教程.md)里。如果只是安装包本身下载不完整、需要重新取一份，安装文件资源在这里：[5EPlay 安装文件资源（夸克网盘）](https://pan.quark.cn/s/36bb219b768e)。

## 登录与账号

| 现象 | 先试这一步 | 还不行再看 |
| --- | --- | --- |
| 一直登录不进去 | 切换 Wi-Fi 与移动数据 | 确认账号是否已实名、是否被冻结 |
| 收不到短信验证码 | 检查是否被拦截、换网络重发 | 稍等片刻再试，或走身份信息找回 |
| 忘记密码 | 用手机号验证码找回 | 用身份信息验证找回（需较新版本） |
| 想换手机号 | 「设置 - 账户信息 - 修改绑定手机」 | 完成身份验证后再改 |
| 提示账号被冻结 | 官方口径：非法行为冻结只能等系统自动解禁 | 邮件联系平台核实 |

细节步骤见[注册登录与账号安全.md](注册登录与账号安全.md)。

## 扫脸认证

| 现象 | 处理 |
| --- | --- |
| 提示「扫脸失败次数过多」 | 联系人工客服增加次数后重扫 |
| 提示「认证失败」 | 在失败界面下方上传底照，等 1~3 个工作日审核，通过后再扫 |
| 反复扫不过 | 先解决光线、遮挡、镜片反光，再重试 |
| 不确定要不要扫 | 只在优先匹配等受信场景会被要求 |

完整说明见[扫脸认证与优先匹配.md](扫脸认证与优先匹配.md)。

## 数据与推送

| 现象 | 先试这一步 | 还不行再看 |
| --- | --- | --- |
| 刚打完的对局没显示 | 等几分钟后下拉刷新 | 区分看的是 5E 战绩还是官匹战绩 |
| 官匹战绩空着 | 在「我的 - 战绩板块 - 官匹战绩」按提示绑定 | 到电脑端走一遍平台匹配用的 Steam 绑定 |
| 分数和记忆对不上 | 确认是否跨赛季（赛季切换会重置） | 对照官方赛季公告 |
| 收不到推送 | 打开系统通知权限 | 关掉对该 App 的省电限制 |
| 消息中心不刷新 | 切网络后重进页面 | 检查 App 是否为较新版本 |

数据口径与指标含义见[战绩与数据怎么看.md](战绩与数据怎么看.md)。

## 分数、举报与冻结

| 现象 | 处理 |
| --- | --- |
| 赛季切换后分数被重置 | 每个赛季都会重置并给出隐藏分，规则见[天梯分与段位怎么算.md](天梯分与段位怎么算.md) |
| 新赛季看不见段位 | 先打完定级赛，段位才会落定 |
| 提交了举报没回音 | 绑微信服务号接收进度；官方说明问题不存在时不一定会回邮件 |
| 账号被冻结 | 非法行为冻结只能等系统自动解禁，有疑问发邮件核实 |

举报与封禁的完整口径见[举报作弊与处理进度怎么查.md](举报作弊与处理进度怎么查.md)。

## 什么时候该找客服

上面都试过还解决不了，再走官方渠道，按问题类型选：

- **一般使用问题**：走官方在线客服入口，或发邮件到 `support@5eplay.com`。
- **反作弊、举报、封禁申诉**：发邮件到 `anticheat01@5eplay.com`；按官方说明，若反馈的问题不存在，不一定会收到回复。
- **实名认证与扫脸次数**：扫脸次数只能由人工客服增加，走 App 内客服入口最快。

联系前把账号 ID、问题出现的时间与页面上看到的原文准备好，一轮就能说清的事别拖成几轮。
