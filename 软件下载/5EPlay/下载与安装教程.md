5EPlay 是 5E 对战平台的手机客户端，用来看 CS 赛事资讯、查自己和别人的战绩、逛社区，也是平台账号做实名与扫脸认证的入口。这篇先让你确认手上这份安装包对不对，再给出手机上的安装步骤，最后说明它和电脑端客户端的关系。

## 先认一下这份安装包

| 项目 | 值 |
| --- | --- |
| 应用名 | 5EPlay |
| 版本 | 7.1.6 |
| 包名 | `com.fiveplay` |
| 安装包大小 | 148.27 MB |
| MD5 | `24d92ce4ee74d734b47ba2d82bdedbac` |
| 适用平台 | 安卓（Android） |
| 运营主体 | 杭州乐于战网络科技有限公司 |

版本号会随时间往前走，官方下载页上通常已经是更高的版本（本文核对时显示 7.2.5，以官方页面为准）；本文列的是**网盘里这一版**，与网盘资源一一对应。两者不是同一版时，功能入口可能略有差别，以你手机上实际显示为准。

装之前可以对一下包名和 MD5：包名应当是 `com.fiveplay`，MD5 应当与上表一致。对不上说明文件不完整，重新转存下载一次。

## 装之前先确认两件事

1. **系统版本**。官方页面没有写明最低安卓版本，第三方下载站多标注 Android 5.2 及以上，这个数只能参考，以你手机实际能否装上为准。
2. **存储空间**。安装包本身约 148 MB，装完之后的数据与缓存会让占用继续增长，建议先留出 1 GB 以上余量。

官方下载入口有两处：官网 [www.5eplay.com](https://www.5eplay.com) 与 App 下载页 [csgo.5eplay.com/app](http://csgo.5eplay.com/app)。这两处给的是官方最新版、且会随版本更新；网盘那份则固定在上表这一版。

## 在手机上安装的步骤

1. 在夸克网盘里打开分享链接，把安装包转存到自己的网盘再下载；先转存可以避免原链接失效后找不到文件。
2. 下载完成后，在手机的「文件管理 - 下载」里找到这个 `.apk` 文件，点开安装。
3. 系统提示「未知来源应用」时，允许本次安装，装完可以再关掉这个开关。
4. 部分手机的「纯净模式」会拦截非应用商店的安装包，装之前先到设置里临时关闭。
5. 装好后桌面上会出现 5EPlay 的图标，点击打开。

如果你不想手动翻文件管理，也可以把文件转存到自己的夸克网盘后直接点开安装：[5EPlay 安装文件资源（夸克网盘）](https://pan.quark.cn/s/36bb219b768e)。

## 第一次打开要做什么

- 启动后先弹用户协议与隐私政策，同意之后才进得去。
- 接着是登录：用 5E 账号（用户名、邮箱或手机号）加密码，或者用手机号验证码；具体提供哪几种以页面实际显示为准，登录方式细节见[注册登录与账号安全.md](注册登录与账号安全.md)。
- 平台账号需要完成**实名认证**才能使用全部功能，未实名的账号在部分入口会被拦下，处理办法同样在那篇里。
- 如果你打算打**优先匹配**，会用到扫脸认证，做法与失败处理见[扫脸认证与优先匹配.md](扫脸认证与优先匹配.md)。

## 它和电脑上的客户端不是一回事

| | 5EPlay App（本文的安装包） | 5E 对战平台客户端 |
| --- | --- | --- |
| 运行平台 | 安卓手机 | Windows 电脑 |
| 主要用途 | 看资讯、查战绩、逛社区、账号与认证操作 | 实际进入游戏对局、匹配排位 |
| 版本节奏 | 与客户端各自独立 | 与 App 各自独立 |

装了 App 不等于能在电脑上打平台对局，两边要分别装。App 倒是有一个直接用处：在网页端或客户端选择「扫码登录」时，可以用 App 里的扫一扫完成，省去输密码。

两端各管哪些事、哪些入口只存在于电脑上，单独列在[哪些事要去电脑上做.md](哪些事要去电脑上做.md)里。

## 装不上或打不开怎么办

| 现象 | 先试这一步 | 还不行再看 |
| --- | --- | --- |
| 提示「解析包错误」 | 重新下载安装包，确认文件完整 | 核对 MD5、换网络重下 |
| 提示「安装失败」 | 检查存储空间与「未知来源」权限 | 重启手机后再装 |
| 被系统直接拦下 | 关掉「纯净模式」再装一次 | 换用文件管理器打开安装包 |
| 装好后闪退 | 清除应用缓存后重开 | 卸载重装 |

更多登录、推送、数据不同步一类的问题见[常见问题与排查.md](常见问题与排查.md)。
