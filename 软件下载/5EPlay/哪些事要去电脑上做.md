> 一个 5E 账号分两端用：哪些事手机 App 里就能办完，哪些必须回到电脑上的客户端，为什么有些入口在手机上翻不到。

「手机上装了 5EPlay，为什么电脑上还要再装一个」——这是两端并存带来的最常见疑问。答案是同一个账号、两种用途：App 管信息与账号事务，客户端管实际对局。这篇把分工列清楚，省得你在手机上翻半天找不到入口。

## 一个账号，两端登录

App（安卓手机）与 5E 对战平台客户端（Windows 电脑）用的是同一个 5E 账号，登录后看到的是同一份数据：App 里查到的天梯分就是客户端打出来的分，客户端的对局也会出现在 App 的战绩里。

两端的登录相互独立，各自登录一次即可。不想在电脑上敲密码时，可以在登录页选「扫码登录」，用 App「我的」界面右上角的扫一扫完成。

## 手机上就能办的

| 事情 | 入口 |
| --- | --- |
| 实名认证的登记、查看与换绑 | 「我的 - 设置 - 账号管理 - 实名认证」 |
| 查看实名下的所有账号、解绑某个账号 | 「我的 - 设置 - 账号管理 - 名下账号管理」 |
| 修改绑定手机 | 「我的 - 设置 - 账户信息 - 修改绑定手机」 |
| 找回密码（手机验证码 / 身份信息验证） | App 登录页的找回入口 |
| 扫脸认证 | 按 App 内提示完成 |
| 看赛事、查战绩、逛社区 | 首页、赛事、大数据、社区几个板块 |
| 扫码登录网页端与客户端 | 「我的」界面右上角扫一扫 |
| 接收处理进度通知 | App 内弹窗，配合绑定微信服务号 |

## 要回到电脑上做的

| 事情 | 说明 |
| --- | --- |
| 进入对局、匹配排位 | App 不能打平台对局，这是客户端的核心用途 |
| 5EBOX 与游戏内设置 | 包括云端同步、道具设置这类客户端内的设置项 |
| 找搭子 / 组队大厅 | 官方公告里的入口在「PLAY - 优先排位创建房间」下的「找搭子」，属于客户端界面 |
| 赛季通行证任务与兑换商店 | 任务在对局中产生，也在同一套界面里结算 |
| 道具商城购买与改名卡使用 | 购买在客户端商城，改名在个人资料界面，具体以客户端当时界面为准 |
| 约战、跑图训练房间 | 房间类功能都在客户端 |

## 客户端跑不起来时先看这条

官方在下载页写明：**5E 对战平台不支持在虚拟机、Hyper-V、Windows 预览版（Insider）以及 Mac 系统环境下运行**。如果你的电脑正是其中一种环境，装好也进不去，这不是安装包的问题。

手机上那份包怎么装、安装包怎么核对，见[下载与安装教程.md](下载与安装教程.md)；数据指标怎么读，见[战绩与数据怎么看.md](战绩与数据怎么看.md)；扫脸与受信账户相关，见[扫脸认证与优先匹配.md](扫脸认证与优先匹配.md)。
