## 一、先把源接进来，首页才有东西

HamHub 装完是空的，它不内置任何影视内容，你看的每一部片都来自你自己挂的源。整个流程三步：新增媒体源 → 选类型并登录 → 等解析完成。挂好之后再把目录标成「媒体文件夹」或建成资料库，首页才会出现海报墙。

它能接的源分三类（官方公布的支持范围）：

| 类别 | 具体支持 |
| --- | --- |
| 媒体服务器 | Emby、Jellyfin、Plex、飞牛影视 |
| 云盘平台 | 阿里云盘、百度网盘、115 网盘、光鸭云盘 |
| 网络协议 | SMB、WebDAV、FTP、FTPS |

## 二、添加媒体源的完整步骤

1. 打开 HamHub，在首页点**新增媒体源**（有的版本叫「添加媒体源」）。
2. 进入类型选择页，按你要挂的东西挑一种：网盘选对应的云盘项，家里的 NAS 或共享文件夹选 SMB/WebDAV/FTP，自建服务器选 Emby/Jellyfin/Plex。
3. 以阿里云盘为例：选中后跳转登录页，用你的账号授权登录，点**完成**回到应用。
4. 授权成功后，源会出现在列表里。进入该源的目录，长按（或走菜单）把影视目录标记为**媒体文件夹**，这些文件就会铺到首页海报墙上。
5. 想要更规整的分类，就再建**资料库**：创建时选「电影」或「电视剧」类型、起名、设识别语言，把一个或多个目录加进去——同一个资料库可以混来自不同源的目录；选了父目录时子目录自动包含，不会重复扫描。
6. 新增或改动目录后会自动触发扫描，你也可以在首页手动重新扫描，进度显示在界面上。

同一份资源不需要在多个源里重复添加；一个网盘账号授权一次即可，后续换目录只要在源里重新选。

## 三、为什么你的文件没生成海报墙（命名规则）

这是新手最常撞的一堵墙：源挂上了、目录也选了，首页却是一串文件名而不是海报。原因几乎都是文件命名没被识别——HamHub 靠片名与季集号去匹配资料。官方给的规则如下，核心只有一条：**一部片一个文件夹，剧名 + S01E01 不能缺**。

**文件夹**：一部电影或一部剧单独建一个文件夹，别全堆在一个目录里；文件夹名建议 `片名(年份)`，括号用半角（英文输入法）。

```text
星际穿越(2014)/
绝命毒师(2008)/
```

**电影文件名**：完整片名（中英文都行，谁在前无所谓）+ 年份 + 分辨率等信息。

```text
星际穿越(2014)/Interstellar.星际穿越.2014.720p.BluRay.x264.mp4
```

**电视剧文件名**：剧名 + `SXXEXX` 季集号，后缀信息可省——关键是剧名和 S01E01。

```text
绝命毒师(2008)/Breaking.Bad.绝命毒师.S01E01.2008.1080p.Netflix.WEB-DL.mkv
绝命毒师(2008)/绝命毒师.S01E01.mkv
```

**特别篇与花絮**：仍以原剧名开头，**季数写 00**，后接集数与类型。

```text
权力的游戏(2011)/Game.of.Thrones.权力的游戏.S00E01.Behind.the.Scenes.720p.HBO.mkv
```

改完命名回首页重新扫描一次；还是不出海报，就按 [播放失败与闪退排查.md](播放失败与闪退排查.md) 里「路径不识别」那一节往下查。

## 四、在线播与下载播怎么选

源挂上后，点开视频默认直接在线串流，手机不占空间；要坐飞机或进电梯前，先把片**离线下载**到本地，飞行模式也能看。4K、杜比 HDR 这类高码率内容对网络更敏感，在线播卡顿时优先考虑下载后播放，能支持的格式见 [支持的视频与字幕格式清单.md](支持的视频与字幕格式清单.md)。

还没装应用的话，安装步骤在 [下载与安装教程.md](下载与安装教程.md)。
