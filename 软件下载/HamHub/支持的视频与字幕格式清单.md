## 一、本篇解决什么问题

网盘里的资源命名五花八门，封装与编码更是各不相同——下完播不了，多半是格式不在支持范围里。下面三张表是官方公布的格式清单，转存或下载前对照一遍，能省掉一次白下。清单以官方发布页当时显示为准，版本更新后可能有增减。

## 二、视频格式

| 常见封装 | 说明 |
| --- | --- |
| MP4、MKV、MOV、AVI、FLV、WMV、TS、WEBM | 最常见的一批，网盘资源基本都在这里 |
| MPEG、M4V、OGV、OGM、RMVB、ASF | 老资源与录制文件 |
| H.264 (AVC)、H.265 (HEVC)、AV1、VP9、VC1 | 主流编码，4K 资源多为 H.265 |
| MTS/M2TS、BDMV、VOB、ISO/IMG、DVDMEDIA、DVR-MS、WTV | 蓝光原盘、光盘镜像与录像格式 |

音频编码支持 AAC、AC3/E-AC3、Dolby TrueHD、DTS、DTS-HD MA、FLAC、MP3、OGG、PCM、WMA——杜比与 DTS 这类多声道源文件能解，但手机外放听不出多声道效果，接耳机或音响才有意义。

## 三、字幕格式

| 类型 | 支持的格式 |
| --- | --- |
| 文本字幕 | SRT、SUB、SSA/ASS、TMP、TXT、VTT、Timed Text、MPL2、MICRODVD、SMI、XSUB |
| 图形字幕 | PGS、DVDSUB、VOBSUB、DVB |

外挂字幕与视频同名、放在同一目录下，一般会被自动带出来；内封字幕则在播放界面里切。ASS/SSA 带特效排版，渲染效果与桌面播放器会有差距，这是移动端的常见现象，不是文件坏了。

## 四、播放时能调什么

- **多音轨切换**：一部片里有国语/英语/评论轨时，在播放页的音轨入口里换，不用换文件。
- **字幕切换与调节**：多语言字幕同理，选中即用。
- **手势操作**：左右滑动快进快退、上下滑动调亮度与音量、双指缩放画面。
- **片头片尾自动跳过**：识别到剧集的片头片尾后自动跳，追剧时少点几下。
- **4K 与杜比视频 HDR**：高动态范围内容需要设备屏幕与解码都支持才看得到效果；播放卡顿时先考虑降码率版本或下载后播（见 [新增媒体源与网盘挂载教程.md](新增媒体源与网盘挂载教程.md)）。
- **离线下载播放**：把文件下到本地再播，飞行模式可用。

## 五、格式支持但依然播不动时

格式在表里却卡住、黑屏或只有声音，问题通常出在解码路径、码率超出设备能力或网络带不上来，而不是格式本身不在清单里。逐条排查步骤见 [播放失败与闪退排查.md](播放失败与闪退排查.md)；文件还没装的话先看 [下载与安装教程.md](下载与安装教程.md)。
