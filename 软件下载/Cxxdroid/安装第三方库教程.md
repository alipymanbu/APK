## 一、本篇解决什么

写课程作业级别的代码用不上本篇；一旦你要 `#include <boost/...>`、`#include <sqlite3.h>`，或者想在手机上画个窗口（SDL2），就需要先装库。Cxxdroid 内置了一个**包管理器 + 自带仓库**，里面是常见 C/C++ 库的**预构建包**——装完不用自己配头文件路径和链接参数，这正是它比「手动塞 `.h` 文件」省事的地方。

**这一步需要联网**（下载库包），编译运行本身仍然不需要。

## 二、官方仓库里有哪些库

| 类别 | 库 | 说明 |
| --- | --- | --- |
| 常用基础库 | Boost、SQLite、ncurses、libcurl | 官方描述明确列出的预构建包 |
| 图形库 | SDL2 | 免费可用，画窗口、做 2D 小游戏用它 |
| 图形库 | SFML、Allegro | 官方描述里带 `*` 标记，属于 Premium 版功能 |

用大库（尤其 Boost）时占的空间明显更多，提前照 [下载与安装教程.md](下载与安装教程.md) 的空间要求留足 200MB 以上。

## 三、装库的步骤

1. 确认手机已联网。
2. 打开 Cxxdroid 的包管理器入口（在主菜单/工具菜单里，界面以你装的版本为准）。
3. 在列表里找到目标库，执行安装，等下载完成。
4. 回到编辑器，在代码里直接 `#include` 该库的头文件，例如：

```cpp
#include <sqlite3.h>
#include <boost/filesystem.hpp>
```

5. 点运行按钮编译。如果报 `file not found` 或链接错误，按 [常见报错与解决方法.md](常见报错与解决方法.md) 对照处理——多数情况是库没装上、或头文件名写错。

官方对新库的移植请求是接受反馈的：功能清单里写明会优先移植常用库，遇到仓库里没有的库，可以按官方页面提供的渠道提交需求（不保证一定加）。

## 四、库相关的许可口径（官方原文的意思）

官方在应用的法律说明里划了几条线，你把自己的程序发出去之前值得知道：

- 应用内置的 Busybox 与 GNU ld 按 (L)GPL 授权，可向官方索取对应源码。
- 内置 Clang 是官方的修改版，源码未开放，其专有部分不允许被复用到其他产品里。
- 应用自带的示例代码可用于学习教学，但**不得把这些示例或其衍生品放进竞品产品**。
- 用 Cxxdroid 编译出的二进制，如果链接了它的专有库，同样受上述限制约束。

一句话：自己学习、写作业、做练习完全没问题；拿它做商业产品前，按官方页面当时公布的条款核对一遍（以官方最新口径为准）。

## 五、装不上的时候

- **列表里没有这个库**：官方仓库只收录一部分库，没有的就是没移植，等官方更新或改用标准库/自己实现。
- **装了还报找不到头文件**：先确认安装是否完成、头文件名拼写，再看 [常见报错与解决方法.md](常见报错与解决方法.md)。
- **下载失败**：包管理器需要网络，切到正常能上网的网络重试；编译报错与网络无关，别混在一起排查。
