## 一、本篇解决什么

装好 Cxxdroid 之后，你最先要做的三个动作是：**新建文件 → 保存 → 运行**。这三步都有固定的按钮位置，第一次找不到很正常。本篇把这条主线走通，再补上编辑器里真正会用到的功能；编译报错转 [常见报错与解决方法.md](常见报错与解决方法.md)。

## 二、新建并运行第一个程序

1. 在主界面点**文件夹图标**，在菜单里选 `New`，新建一个源码文件。
2. 输入你的代码。键盘上方有**扩展符号栏**，C++ 常用符号（`{}`、`<>`、`::`、`#` 等）都在上面，不用切到符号页慢慢找。
3. 再点文件夹图标，选 `Save as`，给文件起名并保存——**后缀别省略**：`.c` 的文件按 C 编译，`.cpp` 的文件按 C++ 编译。
4. 点屏幕下方的**圆形（播放）按钮**，它会编译并运行当前文件。
5. 运行结果出现在运行窗口里；程序要你输入时（`cin` / `scanf`），直接用键盘输入、回车继续。

编译错误会直接显示在运行窗口里（形如 `fatal error: ...`），先看 [常见报错与解决方法.md](常见报错与解决方法.md) 里有没有对应条目。

## 三、多个文件：升级成项目

一个文件写不下、或想拆多个源码文件时：

1. 点右上角 `...` 按钮。
2. 选 `Upgrade to project`。
3. 输入项目名，点 `create`。

之后就能在项目里加多个源码文件一起组织；较新的版本支持基于 CMake 的项目构建（以你装的版本界面为准），适合课程里的多文件作业。单文件的临时代码不必升级项目，直接保存运行更快。

## 四、编辑器里真正会用到的功能

| 功能 | 说明 |
| --- | --- |
| 语法高亮 + 主题 | 关键字、字符串分色显示，主题可换 |
| 实时代码预测与代码分析 | 输入时给补全与检查；官方功能表里带 `*` 的这一行（实时代码预测、自动缩进、代码分析）标注为仅 Premium 版可用，见 [免费版与付费版区别.md](免费版与付费版区别.md) |
| 扩展符号栏 | C++ 常用符号都在键盘上方，不必翻符号页 |
| 标签页 | 多文件同时开着切换，不用来回重开 |
| 跳转到指定行 | 代码长了以后按行号直达 |
| 文件重命名 | 在文件菜单里直接改名 |
| 字符编码 | 支持 utf-8、utf-16、shift_jis 等常见编码，打开乱码时先看这里 |
| HTML 预览 | 写 HTML 时可以直接在应用内预览效果 |
| 一键分享 | 把代码传到 Pastebin |

## 五、终端与交互模式

- **终端**：应用内置了一个完整的终端模拟器，运行编译出的程序、执行命令行操作都在这个窗口里进行；终端支持历史命令与字体缩放。
- **REPL（解释器模式）**：基于 CERN Cling，可以逐行输入表达式立刻出结果，适合试一小段语法、验证一个函数的行为，不用先建文件。学习新语法时比整程序编译快得多。
- **内置示例**：应用自带一批开箱即用的示例程序，第一次上手可以先打开示例改着跑，再写自己的文件。

## 六、保存与找文件

源码文件保存在应用自己的数据目录里，用应用内的文件菜单就能浏览、打开、重命名。想把代码带去电脑上继续写，用分享功能导出（邮件、云盘等方式均可）。传输代码时注意编码统一用 utf-8，避免中文注释变乱码。

## 七、代码能写到什么程度

- **语言标准**：官方没有标明默认用哪一版 C++ 标准；有第三方资料称支持 C++11 / C++14 / C++17，但没有官方页面背书。拿不准时最稳的办法是写一小段目标特性的代码（比如 `std::optional` 属于 C++17）直接编译验证——能过就是支持，报语法错误就是这版没开。
- **内联汇编**：官方功能表明确写了支持 Clang 语法的内联汇编，写底层实验代码也能编。
- **多文件与构建**：单文件直接跑；要多文件组织就升级成项目，较新版本支持基于 CMake 的构建（见第三节，以你装的版本界面为准）。
- **调试**：没有断点调试器（官方列为开发中），边界在这里——需要看程序内部状态时走打印与 REPL，见 [常见报错与解决方法.md](常见报错与解决方法.md) 第七节。
- **大工程**：它是给学习与小项目设计的工具，上千行、几十个源文件的工程在手机上编译与操作都会很难受，这类活儿还是回电脑上做。
