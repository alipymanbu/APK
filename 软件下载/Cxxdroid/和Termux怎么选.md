## 一、本篇解决什么

搜「手机上写 C++」，绕不开两个名字：Cxxdroid 和 Termux。两者都能在安卓上编译运行 C/C++，但形态完全不同——选错了要么觉得「怎么这么难用」，要么觉得「功能怎么这么少」。本篇只摆事实，你按自己要干的活儿选。

## 二、两者分别是什么

- **Cxxdroid**：带图形界面的 C/C++ IDE。打开就是编辑器，点按钮编译运行，内置编译器、包管理器、终端与 REPL，全程离线可用。它面向学 C/C++ 的场景设计（详见 [新建文件与运行教程.md](新建文件与运行教程.md)）。
- **Termux**：安卓上的终端模拟器 + Linux 环境（[官方站点 termux.dev](https://termux.dev/)），不需要 root。它本身不是 IDE：装完是个命令行，包通过 APT 管理（与 Debian/Ubuntu 同一套用法），自带 Bash/Zsh、Vim/Emacs/nano，用 Clang 编译 C/C++，也有 CMake、pkg-config，要调试时可以装 lldb 或 gdb（Cxxdroid 没有调试器，见 [常见报错与解决方法.md](常见报错与解决方法.md) 第七节）。

## 三、逐项对照

| 维度 | Cxxdroid | Termux |
| --- | --- | --- |
| 形态 | 图形界面 IDE，装完即用 | 纯终端，编辑器要自己装（Vim 等） |
| 上手成本 | 会用手机 app 就会操作，运行点按钮 | 要先学会命令行、vim 基本操作、Linux 包概念 |
| 编译器 | 内置，离线直接编译 | 需要 `pkg install clang` 装一次（装包要联网，之后编译同样离线） |
| 第三方库 | 内置包管理器，Boost/SQLite/SDL2 等预构建包一键装 | APT 仓库里按名字装，包的覆盖面更广但要自己拼编译参数 |
| 调试 | 无调试器（官方列为开发中），靠打印与 REPL | 可装 lldb / gdb，能下断点 |
| 附带能力 | 专注 C/C++：编辑、编译、运行、示例 | 一整套 Linux 工具链：Python、Node、Git、ssh、curl 等都能装 |
| 手机适配 | 扩展符号栏、触屏优化的运行按钮 | 默认为实体键盘设计，触屏输命令体验一般，建议外接键盘 |
| 输入法兼容 | 有中文输入问题的反馈案例（处理办法见 [常见报错与解决方法.md](常见报错与解决方法.md) 第五节） | 终端里输中文同样依赖输入法表现 |

## 四、按场景选

- **上课/竞赛练 C++、交作业**：选 Cxxdroid。打开就能写，跑完直接看输出，不需要懂 Linux。
- **第一次学命令行、以后想走开发路线**：两个都装。用 Cxxdroid 保底交作业，拿 Termux 练命令行——它们不冲突。
- **要断点调试、看变量**：去 Termux 装 gdb/lldb，Cxxdroid 给不了这个。
- **除了 C/C++ 还要 Python、Git、ssh 这些工具**：Termux 是完整 Linux 环境，装一个顶一堆；只想写 Python 的话，同一家厂商还有 Pydroid 3（包名 `ru.iiec.pydroid3`，与 Cxxdroid 同为 Lider Soft KZ 出品），形态和 Cxxdroid 一样是图形 IDE。
- **流量紧张、纯离线环境**：Cxxdroid 装完后编译运行零联网；Termux 首次装包必须联网，之后同样能离线编译。

## 五、一句话版

要**图形界面、开箱即用、专注交作业**，用 Cxxdroid（[下载与安装教程.md](下载与安装教程.md)）；要**命令行、调试器和一整套 Linux 工具**，用 Termux。两边的能力边界都在上表里，按缺什么补什么。
