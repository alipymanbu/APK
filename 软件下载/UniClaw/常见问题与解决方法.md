## 一、打开就弹更新，不更新用不了怎么办

有用户反馈：打开应用会弹强制更新提示，不更新就停在原地，正写到一半的内容只能等。从反馈看应用端没有跳过选项，你能做的：

1. 直接更新，等它装完再继续手头的活；
2. 为防更新期间没网或临时用不了，先把当前能用的安装包留在网盘里（见 [下载与安装教程.md](下载与安装教程.md)），换机、回滚都有得用；
3. 更新后如果行为变了（入口挪位置、功能改名），以你更新后的实际界面为准，本文提到的界面描述可能滞后。

## 二、安装失败

按出现频率排查：

| 现象 | 原因与处理 |
| --- | --- |
| 提示「不允许安装来自此来源的应用」 | 正常拦截，按弹窗进入设置打开允许安装未知来源，再返回继续 |
| 提示空间不足 | 安装包 61.00M，安装时还需额外解压空间，建议至少留出几百 MB 空余再试 |
| 安装包打不开 / 解析错误 | 多半是下载不完整，重新下载一次；装之前可用 MD5 与 [下载与安装教程.md](下载与安装教程.md) 里的值比对 |
| 装完找不到图标 | 搜包名 `com.chagent.claw` 定位；部分机型的「纯净模式」会隐藏未上架应用，去安全设置里关掉相关拦截 |

## 三、登录不上或协议页打不开

登录与隐私协议都依赖网络。先切换网络（Wi-Fi 与移动数据互换）重试；隐私协议正文也可以直接在浏览器打开 [隐私政策页面](https://clawpackage.csagentai.com/app/uniclaw-privacy-policy.html) 查看，不受应用内加载影响。

## 四、我搜到的 UniClaw 怎么跟你写的不一样

「UniClaw」这个名字目前被多家产品同时使用，搜到的很可能不是同一个东西：

| 你搜到的 | 它是什么 | 跟本篇的关系 |
| --- | --- | --- |
| 手机端 AI 智能体应用（包名 `com.chagent.claw`） | 本篇系列讲的就是它 | 对应 |
| [uniclaw.ai](https://uniclaw.ai/zh) | OpenClaw 智能体的付费托管平台（网页服务，$12/月起） | 不是同一个产品 |
| 联通云智电脑 / 联通云盘里的 UniClaw | 运营商的云电脑与云盘功能 | 不是同一个产品 |
| 移远通信的 UniClaw 框架 | 面向嵌入式硬件的开发框架 | 不是同一个产品 |

认准**包名 `com.chagent.claw`** 与本篇的安装包信息，就不会走错。

## 五、想确认手里的包没被改过

拿校验工具算一下安装包的 MD5，与 `87078e7851699dcbb33845f7a9327880` 一致即为同一份文件，具体比对方法在 [下载与安装教程.md](下载与安装教程.md)。版本以网盘里那份为准，网上别处的「最新版」与它对不上是正常的。
