## 一、先核对安装包信息

你在网盘里拿到的应该是这样一个包，下载前后可以对照下表确认没拿错：

| 项目 | 值 |
| --- | --- |
| 应用名称 | UniClaw |
| 版本 | 1.0.0 |
| 包名 | `com.chagent.claw` |
| 安装包大小 | 61.00M |
| MD5 | `87078e7851699dcbb33845f7a9327880` |
| 系统要求 | Android |
| 记录时间 | 2026-09-23 |

几点说明：

- **版本以网盘里这份为准**。你在网上别的地方看到的可能是更新版，安装包大小、MD5 都会对不上，别用它们来校验。
- 想确认文件传输完整，可以在电脑上用任意 MD5 校验工具算一遍安装包的 MD5，与上表一致即说明文件没损坏。
- 包名是安卓系统识别应用的唯一标识。以后升级、备份、排查冲突时，认的是 `com.chagent.claw`，不是界面上显示的名字。

## 二、从网盘获取安装包

1. 打开 [UniClaw 安装文件资源（夸克网盘）](https://pan.quark.cn/s/29a8b765b21d)。
2. 把应用文件夹转存到自己的网盘，或直接下载里面的 APK 到手机。文件夹内除了安装包，还有一份说明用的 txt，保留即可。
3. 传到手机后，用文件管理器找到这个 APK（文件名类似 `UniClaw_v1.0.0.apk`，以网盘内实际显示为准）。

> 网盘里的这个文件夹建议「先保存再下载」——链接长期有效，换手机、换版本时回来再取一次就行，不必每次去网上重新找包。

## 三、安装

安卓安装第三方 APK 的流程各家略有差别，整体是这样：

1. 点开 APK 文件，系统会提示「不允许安装来自此来源的应用」——这是正常的拦截。
2. 按提示进入设置，打开**允许安装未知来源应用**（有的机型是在弹窗里直接给开关）。
3. 返回继续安装，等待进度走完。
4. 装完点「打开」，或回到桌面找 UniClaw 图标。

安装失败的常见原因（存储空间不足、机型安全策略拦截、APK 下载不完整）见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、首次启动与登录

1. 打开应用，先会让你**选择头像、填写昵称**，定制你的专属 Agent——这是首次进入的必经步骤，随便选好就能继续。
2. 之后进入登录页，按提示选择登录方式完成登录。
3. 登录前会要求你查看并同意隐私协议，建议真的点开看一遍：隐私政策全文可在 [隐私政策页面](https://clawpackage.csagentai.com/app/uniclaw-privacy-policy.html) 查看。

登录成功后就进入聊天主界面了，怎么用见 [新手使用教程.md](新手使用教程.md)。
