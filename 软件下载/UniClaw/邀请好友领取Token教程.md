## 一、Token 是什么

Token 是大模型处理文本的计量单位——你每提一个问题、它每生成一段回复，都会消耗 Token。所以「免费领 Token」领的就是一段可用额度，用完之前的对话照常，用完之后能不能继续、怎么续，以应用内的额度页面显示为准。

## 二、邀请新用户的操作路径

1. 进入**我的**界面；
2. 点击**邀请新用户**；
3. 复制你的邀请链接，发给好友；
4. 好友通过你的链接完成安装注册，邀请即算成功，奖励 Token 会到账。

整个过程不需要你填任何额外资料，核心就是「复制链接 → 等对方完成」。

## 三、几件要注意的事

- **奖励数量以应用内页面显示为准**。不同活动期的奖励可能调整，界面上写多少就是多少，别拿别处看到的数字当准数。
- **发链接给真会用的人**。邀请的判定条件是对方完成安装并注册，链接发给从不点开的人等于白发。
- **自己先正常用起来**。邀请属于附加额度，不是使用前提——应用本体装好、登录进聊天界面才是主线，见 [新手使用教程.md](新手使用教程.md)。
- 如果你的邀请入口找不到或点击无反应，多半是版本问题或网络没加载出来，排查见 [常见问题与解决方法.md](常见问题与解决方法.md)。
