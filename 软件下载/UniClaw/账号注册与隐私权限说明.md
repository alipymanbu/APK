## 一、注册一个账号需要给什么

| 信息 | 说明 | 是否必要 |
| --- | --- | --- |
| 手机号 | 用于注册、登录验证与安全保护 | 必要 |
| 短信验证码 | 校验身份 | 必要 |
| 出生日期 | 只用来判断是否达到最低注册年龄 | 必要 |
| 昵称 | 1-20 字符，作为账号标识 | 必要 |
| 头像 | 图片文件，作为账号标识 | 非必要 |
| 用户 ID | 6-20 位英文数字，系统生成，便于别人搜索添加你 | 系统生成 |

两条硬性限制：

- **未满 14 周岁不能注册**——出生日期就是为这道校验存在的，填的时候按实际填。
- 政策写明出生日期**只用于年龄校验**，不用于商业用途或精准营销。

## 二、用起来之后，它会记录什么

官方政策按功能分了这几类，值得你在同意前扫一遍：

| 功能 | 收集的内容 | 目的 |
| --- | --- | --- |
| 社交通讯 | 好友关系、群聊信息、聊天记录、平台内通讯录 | 收发消息与好友管理 |
| AI 交互 | 你与 Agent 的对话、你发的指令、AI 生成内容、Agent 配置、Token 消耗记录 | 提供对话服务、维持上下文、Token 统计与计费 |
| 充值支付 | 充值金额、时间、订单号、支付渠道标识 | 完成支付；银行卡号与支付密码由第三方支付机构处理，应用不存 |
| 设备与日志 | 设备型号、系统版本、设备标识符、网络类型、操作与崩溃日志 | 适配设备、安全风控、故障排查 |

三个与你直接相关的口径（均为政策原文意思）：

- 平台通讯录**只指你在应用内建立的好友与群聊关系，不会主动读取手机本地通讯录**。
- 你与 AI 的对话数据**可能在脱敏处理后用于改进 AI 服务质量**——敏感内容别往对话里贴。
- AI 生成的内容会标注「AI」标识，方便你区分人类消息与机器生成。

## 三、系统权限：哪些能关、关了影响什么

政策承诺：即便授权，功能未运行时也不收集信息；不同意权限不影响基本功能，只影响对应附加功能。你可以在手机系统「设置」里关，也可以在应用内**「个人中心 - 权限管理」**逐项查看和开关。

| 权限 | 用在什么地方 | 关掉后的影响 |
| --- | --- | --- |
| 麦克风 | 语音输入、录音、实时会话记录 | 无法语音输入与实时会议记录 |
| 相册 | 单聊群聊里传照片视频、保存生成内容到相册 | 无法选多张图片作参考图、无法用生成功能保存 |
| 相机 | 拍照改头像、扫码 | 无法拍照当头像、无法扫码 |
| 读取媒体数据 | 知识库上传本地文件、保存 AI 生成的文件 | 无法在知识库等场景上传本地文件 |
| 通知 | 推送功能与服务消息 | 可能收不到重要通知 |
| 剪切板 | 快速输入提示词、打开分享口令 | 需要手动粘贴，功能本身不受影响 |

## 四、第三方推送与风控 SDK

应用集成了多家厂商的推送 SDK（OPPO、vivo、小米、华为、荣耀、魅族）用于消息推送，另有微信 SDK（分享与支付）与阿里云设备风险识别（检测异常设备、识别作弊欺诈），它们会收集设备信息、网络信息、应用信息。各 SDK 的详细范围与隐私政策链接在官方隐私政策末尾逐条列出，装之前想细看就去翻那一节。

## 五、注销账号与数据删除

- 政策明确：你可以**通过账号注销功能永久删除所有 Agent 相关数据**；注销后停止提供服务，并按法律要求删除或匿名化处理个人信息。
- 具体入口以应用内当前版本为准（一般在「个人中心」的账号设置里）；找不到就用政策第九条的联系方式找客服。
- 只想停用某项权限、不想注销，用上面第三节的「个人中心 - 权限管理」即可，不必走到注销这一步。

注册之后怎么开始用，见 [新手使用教程.md](新手使用教程.md)；对安装包本身有疑问，见 [下载与安装教程.md](下载与安装教程.md)。
