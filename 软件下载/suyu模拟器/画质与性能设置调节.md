## 一、设置在哪进

主界面的齿轮图标进总设置（位置各构建略有差别，多在左上角），与本篇相关的几个分组：

- **系统 / System** —— 限速、掌机/主机模式
- **图形 / Graphics** —— 图形 API、分辨率、精度、着色器缓存
- **GPU 驱动管理器 / GPU driver manager** —— 换自定义显卡驱动（仅骁龙 Adreno 机型有意义）
- **音频 / Audio**、**控制 / Controls** —— 分别见 [手柄与触屏按键设置.md](手柄与触屏按键设置.md)

设置对全局生效；个别模拟器还支持「单个游戏单独设置」，在游戏图标上长按或进游戏属性调 —— 重的、轻的游戏分开配比一套参数打天下省心。

## 二、先按这个顺序调，别一次全动

调优的顺序比具体数值更重要，按这个次序来，每改一项就跑一次游戏看效果：

1. **图形 API（Vulkan / OpenGL）**：默认若是 OpenGL，先切到 Vulkan。公开教程的口径一致 —— Vulkan 在骁龙 Adreno 上普遍更快更稳；切过去反而报错、花屏，再切回 OpenGL 对照。这一步就能分流掉一半的机型问题。
2. **分辨率缩放**：掉帧先降。0.75x（掌机模式 540p/810p 一档）是第三方教程里最常给的折中值；还卡就 0.5x，机器强（骁龙 8 Gen 系 + 散热）再往 1x、1.5x 抬。**分辨率是帧数的第一杀手**，别的没调之前先动它。
3. **精度（Accuracy）**：图形精度 Normal 就够，High 只会更吃性能 —— 除非你遇到特定游戏的贴图错误，才针对那一个游戏调高。
4. **限速（Limit Speed）**：锁 100%（即原机帧率）。有教程建议开「Always On」，防止个别游戏跑飞导致功耗飙升、机身发烫。
5. **磁盘着色器缓存（Disk Shader Cache）**：开着 —— 第一次进游戏卡是编译着色器，缓存住之后第二次就顺了。反复闪退时可以先关掉它做排查变量。
6. **CPU 精度与后端**：保持默认（Auto / 精度 Normal）。CPU 精度调高只对个别模拟错误有效，代价是明显掉帧。

调完还卡，才轮到换 GPU 驱动（第四节）；驱动也换过还不行，多半是机型本身不够力，回 [下载与安装教程.md](下载与安装教程.md) 第四节的门槛对照一下。

## 三、第一次进游戏卡顿是正常的：着色器缓存

一个几乎所有教程都会单独解释的现象：**同一场景第一次进必卡，第二次就顺了。**

- **为什么**：Switch 游戏的着色器（画面效果的小程序）要从主机格式翻译成你手机 GPU 能跑的格式，第一次遇到就现场翻译一次，翻译过程就是那一下卡顿。翻译结果存进**着色器缓存（Shader Cache）**，之后直接取用。
- **你要做的**：开着「磁盘着色器缓存（Disk Shader Cache）」，然后**把卡的地方玩过去** —— 公开教程对首次卡顿的统一建议就是「继续玩到缓存建立完成，之后重进该场景会明显变顺」。
- **异步编译**：设置里若有「Async Shader Compilation（异步着色器编译）」开关，建议开 —— 它把翻译挪到后台做，代价是新效果出现时可能迟一两拍才显示，换不卡顿是划算的。
- **什么时候清缓存**：缓存损坏的表现是固定位置花屏、图形错乱（错误代码 0008-0000 一类，见 [闪退黑屏与打不开排查.md](闪退黑屏与打不开排查.md)）—— 这时清掉缓存重建即可，代价是之后要重新卡一遍。没有上述症状就别清，白攒的缓存清了可惜。
- **缓存吃存储**：大型游戏的缓存能到 GB 级，见 [下载与安装教程.md](下载与安装教程.md) 第四节的存储预留。

## 四、GPU 驱动管理器：骁龙机型的翻盘手

设置 → GPU 驱动管理器，可以给模拟器换一个不随系统的显卡驱动。这在 Switch 模拟里很关键：**报「An error occurred initializing the video core」（视频核心初始化错误）的，官方与各教程的统一结论就是 GPU 驱动不兼容，换自定义驱动是主要解法。**

怎么用：

1. 只有高通骁龙（Adreno GPU）机型有得换。天玑、Exynos、Mali 机型没有对应驱动，这个入口对你没用，问题也只能从图形 API 与分辨率那边想办法。
2. 驱动分两类：**Qualcomm 官方驱动**（从手机提取、偏稳定）与 **Mesa Turnip**（开源、偏性能）。社区整合包以 AdrenoToolsDrivers 为代表，按你的 Adreno 具体型号选（Adreno 640/730/740 等，型号可在设置 → 关于手机里查，或用 GPU 信息类 App 看）。
3. 下载后 **zip 不要解压**，在模拟器里点「安装驱动 / Install」直接选 zip 文件，装完在列表里选中它。
4. 拿不准就「Fetch / 获取推荐驱动」—— 部分构建提供按钮，会给出一个建议版本。

**版本兼容的坑（有用户反馈，截至 2025 年末的社区帖）**：

| 情况 | 反馈结论 |
| --- | --- |
| Adreno 6xx 系列 | 不支持 Turnip 25.x 之后的版本，会崩溃，最高用到 24.x |
| Adreno 6xx + 安卓 10 | 需要特定的 `turnip-v12-adpkg`，但有卡死、闪退的反馈 |
| Adreno 8xx 系列 | 26.x 之后的版本可用 |

驱动换完要**重启应用**才生效。换错了的表现通常是游戏打不开或花屏 —— 换回上一个能跑的驱动即可，驱动本身不会弄坏手机。

## 五、发烫、耗电与后台

这一块有独立一篇讲透：[发热降频与续航设置.md](发热降频与续航设置.md)。这里只留与调参直接相关的三条 —— 机身发烫后系统降频、帧数跳水是自我保护而非模拟器 bug，降分辨率 + 锁 100% 限速是最有效的缓解；长时间游玩外挂散热（半导体背夹之类）对稳帧有实际帮助；游戏切出去回来被杀是后台策略，到系统设置给 suyu 模拟器开「后台运行/无限制」。

## 六、每个游戏的推荐起步参数

拿不准时照这张表设，再按第二节的顺序微调：

| 项目 | 起步值 | 什么时候动 |
| --- | --- | --- |
| 图形 API | Vulkan | 报错/花屏时切 OpenGL 对照 |
| 分辨率 | 0.75x | 掉帧降 0.5x，强机升 1x |
| 图形精度 | Normal | 个别游戏贴图错误时对该游戏调 High |
| 限速 | 100% 常开 | 不动 |
| 着色器缓存 | 开 | 排查闪退时临时关 |
| CPU 精度 | Auto | 不动 |
| GPU 驱动 | 系统默认 | 视频核心报错或骁龙机想提性能时换 |

调参没有统一最优解：同一台手机、不同游戏的最优点差得很远，你要的只是「这一款能稳定玩」。
