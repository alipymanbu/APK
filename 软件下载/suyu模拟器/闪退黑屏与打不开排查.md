## 二、APK 装不上

1. **解析包错误 / 安装包损坏**：文件应约 41.4 MB，重新下载一次（[下载与安装教程.md](下载与安装教程.md) 第二节有链接与核对方法）。
2. **禁止安装未知应用**：文件管理器或浏览器没有安装权限 —— 设置 → 应用 → 特殊权限 → 安装未知应用，给对应 App 授权后重装。
3. **与已装应用冲突**：手机里已有其他包名的 suyu/yuzu 系模拟器且签名不同，会装不过去。先卸载旧的（**卸载前先按 [存档备份与迁移.md](存档备份与迁移.md) 导出存档**），再装。
4. **系统版本过低**：第三方教程站的口径是安卓 10/11 以上（各来源不完全一致，截至 2026-09）。低于门槛的机型装不上是预期结果，不是你操作错了。

## 三、打开就闪退

按命中率排序试：

1. **芯片不支持**：天玑、Exynos、Mali GPU 机型在同类 Switch 模拟器上公开反馈以「起不来」居多（[下载与安装教程.md](下载与安装教程.md) 第四节有各来源口径）。若你正是这类机型且前两条都无效，基本可以判定是硬件生态问题，等更新比折腾有用。
2. **内存不足**：4GB 内存机型冷启动就容易被系统杀。关掉后台再试，仍不行说明低于门槛。
3. **没装固件或固件不匹配**：部分构建在首次进入主界面前就要求固件 —— 照 [密钥与固件配置说明.md](密钥与固件配置说明.md) 装一遍。
4. **清数据重来**：设置 → 应用 → suyu 模拟器 → 存储 → **清除缓存**（先别清除数据，那会删掉密钥与固件的配置）。清缓存解决不了再考虑清数据，然后按首次向导重走一遍。

## 四、报「视频核心初始化错误」

`An error occurred initializing the video core` 是这类模拟器最出名的一条报错，**含义明确：GPU 驱动不兼容**，与密钥、游戏文件无关。处理顺序：

1. 图形 API 从 OpenGL 切到 Vulkan（或反过来）—— [画质与性能设置调节.md](画质与性能设置调节.md) 第二节第 1 步。
2. 骁龙机型换自定义 GPU 驱动（Turnip / Qualcomm），这是各教程给出的主解法 —— [画质与性能设置调节.md](画质与性能设置调节.md) 第四节，含 Adreno 6xx 版本上限的坑。
3. 换过驱动仍报错：确认你查到的驱动型号与手机的 Adreno 具体型号一致，装错型号是常见翻车点。
4. 非骁龙机型没有驱动可换：这套报错在你机器上可能无解，只能等构建跟进支持。

## 五、黑屏、有声无画、花屏

| 表现 | 先试 |
| --- | --- |
| 完全黑屏 | 换图形 API（Vulkan ↔ OpenGL）；关掉磁盘着色器缓存再进一次 |
| 有声音、没画面 | 图形 API 与驱动不匹配，按第四节换驱动 |
| 花屏、贴图错乱 | 换驱动版本；对这一款游戏把图形精度调到 High 再试 |
| 分辨率拉太高后异常 | 分辨率缩回 0.75x 或 0.5x |
| 换驱动/改设置后反而坏了 | 回退到上一个能跑的配置 —— 改一项、测一次，别一次改一堆 |

## 六、游戏列表是空的

- **目录没授权成功**：设置 → Add Games 重新选文件夹，系统文件选择器里必须点到底部的「USE THIS FOLDER」，只浏览进去不算授权。
- **文件夹里没有可识别文件**：模拟器只认 NSP/XCI 后缀的游戏文件，放别的（zip 未解压、下载工具的 `.tmp`/`.crdownload`）不会显示 —— 下载完的压缩包先解压、改回正确后缀。
- **文件在受限目录**：安卓 11+ 的「下载」目录授权正常，但部分文件管理器移动过的文件权限会丢，把游戏整体挪到一根目录下（如 `Games/`）再授权一次。

## 七、加载到一半闪退

1. **先分清是哪类闪退**：报视频核心错误的走第四节；不报错直接回桌面的，按下面来。
2. **固件与密钥版本不匹配**是这一类的头号原因 —— 两边要同一版本世代，见 [密钥与固件配置说明.md](密钥与固件配置说明.md) 第一节。
3. **游戏文件本身损坏**：下载中断、解压不完整都会。重新拿一份，或先用别的、体积小的游戏验证「模拟器本身能跑」。
4. **这一款就是跑不动**：模拟器的兼容性按游戏逐个变化，轻量独立游戏普遍能跑，大型 3D 作品对机器与驱动都挑。同款游戏在别人的骁龙旗舰上能跑、你的中端机不能，大概率是机型差异而非你配置错了。

## 八、什么时候该重装

上面全试过仍卡死，重装前先做两件事：**导出存档**（[存档备份与迁移.md](存档备份与迁移.md)）与**留好密钥/固件原始文件**（[密钥与固件配置说明.md](密钥与固件配置说明.md) 第五节）。重装后重走向导，配置项（图形、手柄映射）需要重做，按 [画质与性能设置调节.md](画质与性能设置调节.md) 第六节的表五分钟能恢复。

## 九、报错代码速查

有的报错不弹文字说明，只给一串 `0008-xxxx` 形式的代码。下面是公开教程整理出的常见代码对照（不同构建的代码措辞可能有出入，以你的实际弹窗为准）：

| 代码 | 含义 | 对应动作 |
| --- | --- | --- |
| 0008-0000 | 着色器缓存损坏/不完整 → 画面错乱 | 清着色器缓存重建，见 [画质与性能设置调节.md](画质与性能设置调节.md) 第三节 |
| 0008-0080 | 着色器编译失败 | 多为驱动过旧或不兼容，先清缓存，再换驱动 |
| 0008-0083 | 图形驱动过旧 | 骁龙机换自定义驱动，见第四节 |
| 0008-0042 | 显存/内存不够 | 降分辨率与纹理设置，清后台 |
| 0008-0041 | 内存不足 | 关后台应用、重启模拟器；长期不足说明机型低于门槛 |
| 0008-0040 | 缓存缺失 | 重启模拟器一般会自动重建 |
| 0008-0070 / 0071 | 手柄未识别 / 不支持 | 见 [手柄与触屏按键设置.md](手柄与触屏按键设置.md) 第四节 |
| 0008-0063 | 音画不同步 | 通常是性能不足拖累，降画质；或调大音频缓冲 |
| 0008-0050 | 联机功能不可用 | 这类模拟器不支持完整联网对战，属预期结果 |

代码只是把症状说得更准，动作仍然按本篇第一节的速查表分流 —— 图形类走第四、五节，输入类走手柄篇，内存类先降参数。
