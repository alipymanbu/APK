## 一、两条路：触屏虚拟按键还是实体手柄

suyu 模拟器（yuzu 系代码）的输入分两种形态：

- **触屏虚拟按键**：屏幕上浮现一套 Switch 按键，适合随手玩、没带手柄的场景。缺点是遮画面、没有物理反馈。
- **蓝牙实体手柄**：Xbox/PlayStation/Switch Pro/各类手游手柄都能用，映射好了体验最接近主机。

触屏能玩，但 Switch 游戏本身是按实体按键设计的 —— 公开教程的普遍建议是：有条件就配一副手柄，触屏留作应急。选手柄时一条被反复提到的硬指标是**摇杆**：普通摇杆用久了会漂移（表现为人物自己走动），买手柄优先看「霍尔摇杆」（Hall Effect）这类标注防漂移的型号；接口上 Type-C 直插的延迟比蓝牙低，预算与手感按你习惯挑。

先在 设置 → 控制（Controls）里把基础项定了：**控制器类型（Controller type）** 默认是 Pro Controller，用触屏掌机玩法的建议改成 **Handheld（掌机）** —— 掌机模式下按键布局与屏幕一体，跟真机掌机形态一致；连实体手柄玩则保持 Pro 也行。

## 二、接蓝牙手柄的完整步骤

1. 手柄先进配对模式（各品牌方式不同，查手柄说明书），手机蓝牙里连上它。
2. 进 suyu 模拟器 设置 → 控制 → **Player 1**。
3. **输入映射（Input mapping）** 里筛选/选择你的手柄设备，多数手柄会**自动完成映射**，直接可用。
4. 没自动映射的，逐个点按键条目，按手柄上对应的键完成绑定。
5. 保存为一个用户配置（Profile）—— 换手柄、换游戏时切配置比重新映射快。

**四个实操注意点**：

- **AB 位置相反**：Xbox 布局的手柄接上后，A/B 与 Switch 原生位置是反的（Xbox 的 A 在下，Switch 的 B 在下）。觉得「确认变取消」了，就在映射列表里把这两个键对调 —— 点中映射条目再按手柄实际键即可。
- **摇杆映射多试两遍**：左摇杆映射错的表现是进游戏人物走位异常或视角乱转，映射完进游戏实际走一下验证。
- **Home / 截屏键建议不映射**：这两个对应模拟器自身的呼出菜单与截图，误触会打断游戏；想用时从游戏内菜单呼出更稳。
- **震动**：映射列表里有震动开关，手柄支持震动的建议勾上，体感反馈影响不少游戏的手感。

## 三、触屏虚拟按键怎么调

控制设置里与触屏相关的项：

- **开关触屏控制**：不想要悬浮按键（比如接了手柄）就关掉，画面立刻干净。
- **震动反馈**：虚拟按键的振动，手机马达给力就开。
- **布局调整**：按键位置、大小、透明度可调 —— 屏幕小的机型把按键调小、往边缘挪，别压住游戏 UI。

体感/陀螺仪：部分游戏要靠倾斜手柄瞄准，模拟器能否用手机的陀螺仪代偿，取决于具体构建与游戏（yuzu 系早期安卓版对体感类功能的公开说明是「尚未提供或仍在完善」）。你在控制设置里看到「体感 / Motion」一类条目就有，没有就是这版不带，不用找。

## 四、输入相关的问题速查

| 现象 | 原因 | 动作 |
| --- | --- | --- |
| 手柄连着但游戏没反应 | 没在 Player 1 里选手柄，或映射为空 | 设置 → 控制 → Input mapping 选设备 |
| A/B 确认与取消反了 | Xbox 布局 vs Switch 布局差异 | 对调这两个键的映射 |
| 人物自己走动/视角乱转 | 摇杆映射错位或手柄摇杆漂移 | 重新映射摇杆；换别的手柄试以定位是手柄还是映射问题 |
| 屏幕按键挡视线 | 触屏控制开着 | 控制设置里关掉或缩小 |
| 手柄玩一半断连 | 蓝牙休眠/省电策略 | 手柄充满电、靠近手机；手机蓝牙设置里关闭该手柄的省电限制 |
| 进游戏完全无法操作，但菜单能点 | 游戏本身需要特定控制器类型（掌机/Pro） | 切换 Controller type 后重进游戏 |

输入配置和图形设置一样是**每台机器自己的一套**，调好后在 Profile 里存住；换手机或重装应用后配置会丢，照本篇重做一遍即可（原始手柄还是那副，映射逻辑不变，几分钟能恢复）。
