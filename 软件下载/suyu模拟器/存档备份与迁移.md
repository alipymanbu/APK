## 一、先建立一个认知：存档放在应用私有目录里

suyu 模拟器的存档、密钥、固件、设置全在应用的私有数据区，**卸载应用 = 一起消失**，而且安卓 11+ 起普通文件管理器大多**进不去这个目录**（Scoped Storage 限制）。所以「能玩」和「存档丢不了」是两件事，后者必须你主动做。

## 二、存档路径在哪

公开信息给了几套路径，**互相有出入、且都属于「有用户反馈」级别的单来源**，全部列给你，按命中去找：

| 来源 | 路径 |
| --- | --- |
| 同源模拟器（yuzu 安卓版）的常见存档路径口径 | `Android/data/<包名>/files/nand/user/save/0000000000000000/<游戏ID>/` |
| 一个中文软件站的 suyu 页面 | `/sdcard/Suyu/saves/` 或 `/data/user/0/com.suyu.emulator/files/saves/` |

注意第二条里的包名（`com.suyu.emulator`）与网盘这份安装包的包名（`dev.suyu.suyu_emu.relWithDebInfo`）**对不上**，照抄会找不到 —— 所以更稳的做法不是猜路径，而是走第三节的**应用内导出**，或直接在文件管理器里按包名搜 `nand`、`save` 关键字定位。存档文件常见扩展名为 `.sav`、`.dat`。

## 三、备份存档的两条路

**路线 A：应用内导出（优先用这条）**

设置 → 数据管理 / 存档管理一类的入口（不同构建措辞不同），找到导出/备份选项，把存档导到手机内部存储的普通目录。导出成功后文件在普通目录里，云盘、电脑随你搬。

**路线 B：直接复制存档文件**

能访问到存档目录时（部分文件管理器、连电脑用 MTP 可以），把整个游戏对应的存档文件夹复制出来：

1. 定位到存档根目录（第二节的路径，按你的包名调整）。
2. 按游戏 ID 找到目标文件夹 —— 存档是按游戏分文件夹的，整个文件夹一起拷，别只拷单个 `.sav`（同目录下往往还有配套数据）。
3. 复制到安全位置，建议命名带上日期与进度（如 `xxx_20260926_第二章`），恢复时一眼能认。

**备份频率**：长流程游戏每次下线前备一次；轻量游戏一周一次够用。备份文件同时存两处（云盘 + 电脑/另一台设备）才算数。

## 四、换手机 / 重装应用怎么恢复

1. 旧机上先导出存档（第三节），同时留好 `prod.keys` 与固件原始文件（[密钥与固件配置说明.md](密钥与固件配置说明.md) 第五节）。
2. 新机装好 suyu 模拟器，**先把首次向导走完**（密钥、固件、游戏目录都要配好），否则恢复进去的存档没法验证。
3. 把备份的存档文件夹放回存档路径的同一位置（`0000000000000000/<游戏ID>/` 这一层），路径要一模一样。
4. 进游戏确认读档。读不到就回头核对：包名对不对、游戏 ID 文件夹有没有放错层级。

**注意**：应用内配置（图形参数、手柄映射 Profile）不随存档走，需要按 [画质与性能设置调节.md](画质与性能设置调节.md) 与 [手柄与触屏按键设置.md](手柄与触屏按键设置.md) 重做一遍。

## 五、从别的模拟器把存档接过来

yuzu 系各分支（含 suyu 与后续分支）的存档目录结构是同一套 `nand/user/save/` 布局，**同源模拟器之间拷文件夹是可行的**，多份教程验证过 Ryujinx ↔ yuzu 互转的路径写法：

1. 在来源模拟器里打开存档目录（桌面版一般右键游戏 → 打开存档目录；安卓版按第二节路径找）。
2. 复制整个游戏存档文件夹。
3. 粘贴到 suyu 的 `nand/user/save/0000000000000000/` 下，**文件夹名保持原样** —— 存档靠游戏 ID 目录名认人，改名会认不出。
4. 重启模拟器进游戏验证。

来源不同的模拟器（非同源项目）目录布局可能不一样，对不上就别硬搬，先在目标位置比对同款游戏 ID 的文件夹结构。转移前照例先备份两边的原始存档 —— 拷坏了还能回退。

## 六、几个别踩的坑

- **别在游戏运行时复制存档**：正在写入的数据拷出来可能是半截的，恢复后读档失败。先退出游戏再操作。
- **卸载前一定要先导出**：清数据、卸载、换包名重装，都会让私有目录里的存档一起没。
- **别拿「云同步」当备份**：模拟器本身不提供存档云同步，能同步的只有你主动导出去的那份拷贝。
- **恢复后先跑一次再覆盖**：新机上先用空存档进一次游戏，确认能正常存读，再把备份覆盖上去 —— 万一路径放错，至少知道是恢复的问题而不是模拟器本身跑不起来（那属于 [闪退黑屏与打不开排查.md](闪退黑屏与打不开排查.md) 的范畴）。
