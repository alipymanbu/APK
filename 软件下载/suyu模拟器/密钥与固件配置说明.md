## 一、这两样东西分别是什么

suyu 模拟器本身只是一个壳，真要跑游戏还得给它两样数据，缺一个游戏都进不去：

| 文件 | 作用 | 缺了会怎样 |
| --- | --- | --- |
| `prod.keys`（密钥） | 解密游戏文件的加密内容 | 游戏列表里点进去提示「你的 ROM 已加密」或直接退出 |
| 固件（Firmware） | 提供 Switch 系统程序、字体、系统库 | 部分游戏闪退、系统菜单（QLaunch）打不开、存档相关功能异常 |

**两者的版本必须对齐**：固件太旧而密钥新（或反过来），典型表现是装完固件照样闪退、或者游戏能开但字体乱码。公开教程的一致口径是「固件版本需要与 prod.keys 的版本匹配」，对不上就换一边。

**合规边界先说清**：密钥应当从你自己的 Switch 主机上提取（通过主机上的 Homebrew 工具导出），固件同样来自主机自身；游戏文件 NSP/XCI 也应当是你自己购买的卡带或数字版的备份。模拟器只提供「读取你自己的数据」的能力，不提供、也不指向任何第三方密钥或游戏资源的获取渠道 —— 本文也不会给。从不明网站下载的密钥与固件还有一层现实风险：这类文件是打包传播的重灾区，顺带夹带恶意软件的情况并不少见。

## 二、首次启动时怎么选

向导走到 Select Keys 这一步时（见 [下载与安装教程.md](下载与安装教程.md) 第六节）：

1. 提前把 `prod.keys` 放到手机里一个固定目录（别放在「下载」根目录跟一堆安装包混着，建议单独建个只放密钥和固件的空目录）。
2. 点 **Select Keys**，在弹出的系统文件选择器里导航到该目录，选中 `prod.keys`。
3. 有的发行包同时带 `title.keys`，能选就一并选上；只有 `prod.keys` 也够用。
4. 下一步 **Install Firmware**：选固件压缩包（zip）**本身**，不要先解压 —— 多份教程明确写了这一步「不要解压」，直接选 zip 交给模拟器装。
5. 最后 **Add Games** 选游戏目录，完成向导。

装完固件后，主界面的齿轮设置里（不同构建叫「管理 suyu 数据 / 安装固件」一类）可以重复装：固件装漏了、装错了版本，都从这里重装，不需要重装整个应用。

## 三、已经进主界面了，怎么回头补

向导被跳过或当时选错了文件，不用重装应用，两条路：

- **补密钥**：设置里有「选择密钥 / Select Keys」入口（不同构建的措辞略有差别），点进去重新选 `prod.keys` 所在文件，选完回到游戏列表下拉刷新。
- **补固件**：设置 → 管理数据 / Install Firmware，按第二节第 4 步的方式选固件 zip。

判断有没有生效最直接的办法：点一个游戏，不再弹「已加密」提示、能进到加载画面，就是密钥生效；能过加载画面进到游戏内标题界面而不闪退，就是固件也对上了。

## 四、症状对照：卡在哪一环

| 你看到的现象 | 多半是 | 动作 |
| --- | --- | --- |
| 列表提示「ROM 已加密」/「Encryption keys are missing」 | 没选密钥，或选的不是 `prod.keys` | 回第二节重选 |
| 能进加载画面就闪退 | 固件缺失或版本与密钥不匹配 | 重装匹配版本的固件 |
| 闪退且提示视频核心初始化错误 | 这不是密钥问题，是 GPU 驱动/图形 API | 见 [闪退黑屏与打不开排查.md](闪退黑屏与打不开排查.md) |
| 游戏列表整个是空的 | 游戏目录没授权成功 | 设置里重新 Add Games，注意系统授权页要点「USE THIS FOLDER」 |

## 五、换手机、重装应用之后

密钥、固件、存档都在应用的私有目录里，卸载应用就一起没了。换机或重装前，把密钥与固件的原始文件（你手里的那份 zip 和 `prod.keys`）在手机里单独留一份，装完新应用照第二节重新指一遍即可；游戏存档是另一回事，走 [存档备份与迁移.md](存档备份与迁移.md)。
