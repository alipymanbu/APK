# ckck 按键与方向键串键测试

> 本篇讲怎么用 ckck 把手柄上的按键逐个按一遍，以及方向键「串键」这种间歇性故障怎么测出来。

按键是手柄里最容易出问题的部分：轻则接触不良偶尔断触，重则一个键触发另一个键。ckck 的按键测试页负责前者，方向键串键测试页负责后者，两页的用法和判读方式不一样。

## 一、按键测试页：先把「全键位」按一遍

进入按键测试页后，界面会按手柄的键位排布画出一圈按键图形，动作键默认按 **XBOX 布局**排列（A / B / X / Y、LB / RB、LT / RT、SELECT / START、L3 / R3 等）。

操作方法：

1. 把手柄拿在手里，**依次按下每一个键**，按下时留意界面上对应的图形有没有变化。
2. 正常工作的键会在按下时出现颜色变化，没变化的说明这次按键没有被识别到。
3. 左右摇杆也可以在这一页拨动，页面上会同步显示摇杆的坐标数值，用来快速确认摇杆有输入。
4. 按完一轮后，把摇杆分别拨向四个角和正上下左右，再松手，观察坐标能不能回到中心附近。

判读表：

| 现象 | 说明 | 下一步 |
| --- | --- | --- |
| 按下即有颜色变化 | 该键正常 | —— |
| 按很多次偶尔亮一次 | 接触不良的早期表现 | 反复按同一个键多次复核，再判断是否送修 |
| 完全没反应 | 该键没被系统识别 | 先确认键位布局是不是选了 XBOX 布局，排除了布局问题再当硬件故障 |
| 按一个键、另一个键也亮 | 串键 | 用下面的方向键串键测试页做定量确认 |
| 按一次却触发两次、或松开后仍亮着 | 按键开关磨损的典型表现 | 反复按同一键复核；确认后属硬件问题，不是设置能改的 |
| 摇杆松手后坐标不回中心 | 可能是漂移 | 见 [摇杆漂移与死区怎么看.md](摇杆漂移与死区怎么看.md) |

注意动作键布局：XBOX 布局下 A 在下方、B 在右侧，和 Switch 手柄的 A / B 位置是反的。看到「按 A 亮 B」先别急着判故障，确认一下自己按的位置和界面标注是否对应。

还有一种「按键不对」跟手柄无关：ckck 里每个键都对得上，进游戏之后功能却不一样 —— 那是游戏自己的按键映射问题，处理方式见 [手柄按键错乱和键位对不上.md](手柄按键错乱和键位对不上.md)。

## 二、方向键串键测试页：用次数把偶发问题逼出来

串键（按上却触发左，或者一次按下触发两个方向）往往是偶发的，靠手按两下看不出来。这一页的做法是**按固定顺序重复按压，再统计有没有出现计划外的方向**。

1. 选定按压次数，页面上有 **50 次、100 次、200 次** 三档。
2. 自己定一个固定顺序，例如「上下上下」或「左右左右」，然后按这个顺序持续拨动方向键，中途不要改顺序。
3. 按满选定次数后测试结束，查看统计结果。
4. 结果里**出现固定顺序之外的方向**，就说明方向键存在串键。

次数怎么选：

| 次数 | 适用场景 |
| --- | --- |
| 50 次 | 快速过一遍，确认方向键基本可用 |
| 100 次 | 常规排查，偶发串键多数能在这一档暴露 |
| 200 次 | 怀疑有间歇故障、或者要给人看结论时用，样本更多更可信 |

## 三、肩键与扳机键别漏

方向键和动作键之外，肩键（LB / RB）与扳机键（LT / RT）同样要在按键测试页按一遍 —— 这两个键在游戏里使用频率高，磨损也更集中。扳机键还要单独看「能不能读出中间数值」，那是另一件事，做法见 [扳机与震动测试怎么做.md](扳机与震动测试怎么做.md)。

按键测试本身不产生记录文件，结论靠你按下时观察界面；测完如果发现某个键确实有问题，可以顺便把摇杆那一页也跑一遍，因为漂移和接触不良常出现在同一台用久了的手柄上。
