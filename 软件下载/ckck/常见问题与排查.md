# ckck 常见问题与排查

> 本篇把 ckck 用起来常见的几类问题归到一起：装不上、连不上、读数不动、读数乱跳，各自给一条排查顺序。

ckck 的测试项目虽然多，出问题的位置其实很集中：多数卡在「连接」这一步，少数是读数本身有波动。下面是按现象归类的排查清单，照着顺序走，别跳步。

## 一、装不上、装完打不开

| 现象 | 排查 |
| --- | --- |
| 提示「解析软件包时出现问题」 | 安装包没下完。**ckck 安装文件资源（夸克网盘）** 里那份的 MD5 是 `B957D9E5D820166CA7336B1F8CDA41B1`，重新下载后核对一次 |
| 反复提示「禁止安装未知应用」 | 授权对象错了：要给**打开安装包的那个应用**（文件管理器 / 浏览器）开权限，不是给 ckck 开 |
| 装完打开就退出 | 系统版本低于这份包的门槛，换更新的系统版本或设备 |
| 装完和别人说的界面不一样 | 先确认包名。进「设置 → 应用」看包名是不是 `com.qx.ckck`，同名应用不止一个 |

版本、包名、体积这些以这份安装包为准，安装步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 二、手柄连上了，界面没反应

这是最常见的一类。按顺序排除：

1. **按一下按键**。ckck 明确要求连接手柄后按动按键才会识别成功，只配对不按，界面会一直是初始状态。
2. **确认权限**。附近设备权限（安卓 12 以下叫位置权限）没给，系统蓝牙里显示已连接，ckck 里却读不到数据。
3. **确认手柄没被别的设备占着**。蓝牙手柄多数只能同时连一台设备，先在电脑或其他手机上断开。
4. **忽略设备后重新配对**。系统里残留的旧配对记录会导致「连上但没数据」，删掉重配通常能解决。
5. **有线换一根线 / 去掉转接头**。OTG 头质量差会导致供电不足，手柄灯亮但数据不通。

详细步骤见 [手柄怎么连接和配对.md](手柄怎么连接和配对.md)。

## 三、某个按键没反应

- 先看键位布局：ckck 默认按 **XBOX 布局** 排布动作键，A 在下、B 在右，和 Switch 手柄的位置是反的。位置对不上会把正常键看成坏键。
- 反复按同一个键十几次，只有偶尔亮一次 —— 属于接触不良的早期表现。
- 按一个键另一个也亮 —— 用方向键串键测试页，以 100 次或 200 次做定量确认，做法见 [按键与方向键串键测试.md](按键与方向键串键测试.md)。
- 按一次却触发两次、或者松开后还亮着 —— 属于按键开关磨损，不是设置能改的。
- ckck 里每个键都对得上、进游戏功能却不一样 —— 那是游戏的按键映射，处理方法见 [手柄按键错乱和键位对不上.md](手柄按键错乱和键位对不上.md)。
- 肩键和扳机键别漏测，这两个键磨损更集中。

## 四、摇杆数值不动或一直跳

| 现象 | 原因方向 | 处理 |
| --- | --- | --- |
| 怎么拨都是 0 | 连接层问题或按键未识别 | 回第二节的排查顺序 |
| 松手后数值不回中心 | 摇杆漂移 | 用漂移测试页定量（见 [摇杆漂移与死区怎么看.md](摇杆漂移与死区怎么看.md)），处理顺序见 [摇杆漂移了怎么处理.md](摇杆漂移了怎么处理.md) |
| 静止时数值轻微抖动 | 无死区摇杆的正常表现 | 页面上有说明，轻微抖动不算故障 |
| 每次归中的值都不一样 | 手柄是无死区设计 | 不是故障，判据见摇杆那一篇的第四节 |

## 五、回报率数字偏低或忽高忽低

- 蓝牙连出来的读数本来就低，参考值是 125Hz 左右，想要更高请换有线或 2.4G 接收器。
- 测的时候中途停顿、来回答变方向，会把「异常次数」抬上去、平均回报率压下来 —— 重置后保持匀速重测。
- 在电脑浏览器里测的话，浏览器只采样 200Hz 以下，测更高回报率要先点页面上的连接手柄设备按钮。
- 前后两次差别很大时，先怀疑测试时手柄本身在晃，再怀疑手柄。

完整口径见 [回报率测试怎么看.md](回报率测试怎么看.md)。

## 六、测出手柄有问题，接下来做什么

| 测出来的问题 | 能自己做的 | 自己解决不了的 |
| --- | --- | --- |
| 摇杆漂移、行程不圆 | 先在游戏里加大死区应急，再做清洁与校准，顺序见 [摇杆漂移了怎么处理.md](摇杆漂移了怎么处理.md) | 校准后偏差依旧明显，属硬件老化 |
| 方向键串键 | 重新按固定顺序复测，确认不是手法问题 | 复测仍串键，属硬件问题 |
| 按键偶尔断触 | 反复按压确认发生频率 | 频率随使用上升的，考虑送修 |
| 震动马达没反应 | 换另一个马达类型再试一次 | 两个马达都无反应，属硬件问题 |
| 回报率偏低 | 换有线连接对比 | 有线仍明显偏低是规格问题，不是故障 |

ckck 只负责给出读数，判断之后要不要校准或送修，取决于你测到的是「偏差」还是「故障」—— 偏差可以校准，故障校准不掉。

## 七、手机上装 ckck，还是用电脑网页版

同一套测试官方有两条路：手机上的 ckck 应用，和电脑浏览器里打开的官方网页版测试页。选哪条，看你手柄接在哪台设备上。

| 对比项 | 手机上的 ckck | 电脑上的官方网页版 |
| --- | --- | --- |
| 要不要安装 | 需要装这份安装包 | 不用装，打开网页即可 |
| 测回报率 | 上限由系统和手柄本身决定 | 浏览器默认只采样 200Hz 以下，测更高要先点「连接手柄设备」 |
| 用哪个手柄 | 蓝牙手柄、OTG 接的有线手柄 | 插在电脑上的手柄 |
| 适合的场景 | 随手拿手机测、在安卓掌机上测 | 桌面环境测有线手柄、不想装应用时 |
