扳机和震动是手柄上最容易被忽略的两项：扳机出问题通常不会像按键那样彻底失灵，只是手感变差；震动出问题则直接被当成「这游戏没震感」。ckck 的这两页就是用来把「手感问题」变成可看的数值。

## 一、扳机线性测试页

页面把扳机按下深度映射成 **0 到 255** 的数值，并画成柱状图。左侧是左扳机（LT / L2），右侧是右扳机（RT / R2），按下去的同时页面上会出现对应的进度统计。

操作步骤：

1. 进入扳机线性测试页，握住手柄。
2. **缓慢**按下扳机，从完全松开到按到底，一次按满全程。
3. 盯住柱状图：数值应当随着你按下深度连续往上走，而不是从 0 直接跳到 255。
4. 重复几次，左右扳机分别测。

| 现象 | 结论 |
| --- | --- |
| 按下过程中出现中间数值（如 60、120、180） | 线性扳机，按下深度能换算成不同强度 |
| 只在两端跳变、中间没有数值 | 非线性扳机，只有「按下 / 没按下」两种状态 |

页面下方还有三组统计，含义各不同：

- **触发数据个数**：这次测试期间累计采到的数据条数，用来确认你到底按了几下、有没有采到。
- **单向触发数据个数**：只记录第一次单方向触发的数据总数。
- **单向连续触发数据个数**：同方向连续触发的条数。

数值偏少通常是按得太快或中途停顿造成的 —— 线性扳机要的就是「慢按」，慢按一次得到的有效数据往往比快按几次更多。

最常踩的坑是拿它当「按不按得动」的测试：扳机按不按得动，在按键测试页按一下就能看出来；这一页要解决的是「按到一半有没有反应」。判断游戏里是否支持力度油门、刹车深度一类操作，看的就是这里有没有中间数值。

## 二、震动测试页

震动测试页要你先选马达类型，再触发震动：

| 马达 | 是哪一类 | 触发后应该感觉到什么 |
| --- | --- | --- |
| 手柄马达 | 主振动马达 | 整个手柄一起震，强度明显 |
| 扳机马达 | 副马达，各手柄的安装位置不一样 | 震感更局部、更集中，握把不一定有明显感觉 |

操作与判读：

1. 按手柄说明书把手柄调成能收到触发指令的状态（部分手柄需要先连上并保持连接稳定）。
2. 在页面上选择要测的马达，触发一次，感受震动是否出现、强度是否正常。
3. 换到另一个马达重复一次，确认两个马达都有响应。
4. 触发了但完全没震感，换一个马达类型再试一次 —— ckck 把两个马达分开触发，一个没反应不代表另一个也是坏的。

震动是否「正常」没有绝对数值，靠的是对比：同一台手柄左右两侧震感差别很大、或者震动起步与停止有明显拖沓，才说明有问题。

## 三、这两页配合着看

扳机和震动的毛病经常出现在同一台用久了的手柄上。测的顺序建议是：

1. 先用按键测试页确认扳机键「按下去有反应」；
2. 再用扳机线性测试页确认「按到一半有中间数值」；
3. 最后用震动测试页确认两个马达都能触发。

三步都不通过、或者只有第一步不通过，处理方向完全不同，这也是为什么这两页不能只看一眼就下结论。测完摇杆那一页顺手跑一次，能得到这台手柄比较完整的状态记录，做法见 [摇杆漂移与死区怎么看.md](摇杆漂移与死区怎么看.md)。
