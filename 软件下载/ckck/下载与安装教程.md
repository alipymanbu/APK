ckck 是一款免费、不用注册账号的安卓端手柄检测工具，由深圳市七熊科技有限公司开发：把手柄连上手机后，你就能逐项检查按键、摇杆、方向键、扳机与震动马达是否正常。本篇只解决「装」这一步 —— 装在哪、怎么装、装完给什么权限。

## 一、先确认装在哪台设备上

ckck 测的是「连上来的手柄」，所以装在你手边能连手柄的那台设备上就行。

| 设备 | 能不能装 | 说明 |
| --- | --- | --- |
| Android 手机 | 可以 | 主要使用场景，蓝牙手柄、有线手柄都能接 |
| Android 平板 / 安卓掌机 | 可以 | 只要系统版本达标；大屏下的界面排布以实际显示为准 |
| iPhone / iPad | 用不了这份包 | 这份资源是安卓安装包；官方另有 iOS 版，不在这份资源里 |
| Windows / macOS | 用不了这份包 | 想在电脑上测，可以直接用官方网页版测试页，见 [手柄怎么连接和配对.md](手柄怎么连接和配对.md) 里「在电脑上测」一节 |

## 二、系统门槛

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 最低系统版本 | 安卓 5.2 及以上 | 各渠道页面标注的安卓小版本号不完全一致，装前以发布页当时标注的为准 |
| Root | 不需要 | 它读的是系统本来就会向普通应用开放的蓝牙与手柄输入数据 |
| 蓝牙 | 测蓝牙手柄时必需 | 有线手柄走 USB / OTG，不需要蓝牙 |
| 网络 | 非必需 | 测试读的是本机接上来的手柄输入，不需要联网 |
| 存储 | 很小 | 这份安装包 9.30M，见第五节的版本信息 |

想确认自己手机的安卓版本，进「设置 → 关于手机 → Android 版本」看一眼即可。

## 三、安装步骤

1. 打开 **[ckck 安装文件资源（夸克网盘）](https://pan.quark.cn/s/251d8f1ca61f)**，把安装包转存到自己网盘或直接下载到手机本地存储。
2. 在手机上点开下载好的安装包。系统弹出「禁止安装未知应用」时，在弹窗里给**当前打开安装包的那个应用**（文件管理器或浏览器）打开「允许安装未知应用」，再返回重装。
3. 按提示装完，从桌面图标进入即可。

给「打开安装包的那个应用」授权、而不是给 ckck 授权，是这一步最容易搞错的地方 —— 装在后面的应用此时还没有权限可言。

## 四、装完第一次打开要做什么

ckck 靠蓝牙与手柄通信，所以第一次启动的重点是把这两个权限给到位：

1. 启动后会先弹出「跳转蓝牙页面」的提示，按提示去系统的蓝牙设置里把已配对的手柄连上，再回到 ckck。
2. 系统申请**附近设备**权限时选择允许 —— 安卓把蓝牙扫描归到这一类权限下，不给就连不上蓝牙手柄。安卓 12 以下是按**位置**权限申请的，同样要允许。
3. 连上手柄后，在测试页里**按动一下手柄上的按键**，界面才会把它认出来（页面本身也有这句提示）。
4. 不需要注册或登录账号，也不需要开无障碍之类的特殊权限。

权限给错、或者手柄连上了但界面一直没反应，按 [常见问题与排查.md](常见问题与排查.md) 里的顺序排查。

## 五、这份安装包对应的版本信息

文档里凡涉及版本号、包名、体积，都以这份包为准（官方渠道上能搜到的通常是更新的版本，和这份不是同一个）：

| 项目 | 值 |
| --- | --- |
| 应用版本 | V1.9.1 |
| 包名 | `com.qx.ckck` |
| 安装包大小 | 9.30M |
| MD5 | `B957D9E5D820166CA7336B1F8CDA41B1` |

包名是认版本最可靠的一条：叫 ckck 或「ckck 手柄测试」的应用在各类站点上有多个条目，装完进「设置 → 应用」看一眼包名是不是 `com.qx.ckck`，就能确认装的是这一版。想把文件核对一遍的话，在电脑上用任意 MD5 校验工具对安装包算一次，与上表逐位比对即可。

## 六、装不上的几种情况

| 现象 | 原因方向 | 处理 |
| --- | --- | --- |
| 提示「解析软件包时出现问题」 | 文件没下完或传输中断 | 重新转存、重新下载，再按上表核对 MD5 |
| 反复提示「禁止安装未知应用」 | 授权给了错误的对象 | 在弹窗入口给打开安装包的那个应用授权，而不是给 ckck 授权 |
| 装完打开就闪退 | 系统版本低于这份包的门槛 | 确认系统版本，或换用更新的版本 |
| 装完能进但连不上手柄 | 蓝牙权限或配对状态问题 | 见 [手柄怎么连接和配对.md](手柄怎么连接和配对.md) |
