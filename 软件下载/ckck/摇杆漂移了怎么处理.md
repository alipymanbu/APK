# ckck 摇杆漂移了怎么处理

> 本篇讲测出摇杆漂移之后按什么顺序处理：先加大死区、再清洁、再校准，以及什么时候该放弃自修。

用 ckck 的漂移测试页测出摇杆松手后自己报数，接下来该做什么，取决于漂移有多严重。**处理顺序应当从代价最小的一步开始** —— 先在支持该设置的游戏里加大死区应急，再清洁摇杆根部，最后才做校准，而不是先拆手柄。相当一部分轻微漂移不用拆机就能改善，本篇给的就是这套顺序和它的止步线。

## 一、先量化：偏差值决定走哪条路

回到 [摇杆漂移与死区怎么看.md](摇杆漂移与死区怎么看.md) 的漂移测试页，把手柄平放桌面、静止 3 秒，记下左、右摇杆的平均偏差值。这个数是后面所有判断的基线 —— 处理完要**用同一页、同一方法复测**才能对比出有没有改善。

| 偏差程度 | 表现 | 建议方向 |
| --- | --- | --- |
| 轻微、需要盯着才看得出来 | 大部分游戏里感觉不到 | 先不动，记录基线，过一段时间再测一次看有没有变差 |
| 明显，静止时坐标持续偏离中心 | 游戏里角色或视角自己走 | 按下面第二、三步处理 |
| 严重，明显偏离 | 基本没法正常用 | 跳过前两步，直接考虑送修或更换 |

## 二、第一步：在游戏里加大死区（零成本）

死区是「摇杆动了这一段，系统当作没动」的范围，很多游戏的控制设置里都能调。轻微漂移最省事的做法就是**把死区调大到盖住漂移量**，让游戏忽略那几个偏移值。

代价要说清楚：死区调大之后，小幅拨动摇杆的操作会被一起忽略，精细操作变得迟钝。所以调的时候一点点加，加到漂移不影响操作为止，别一次拉满。部分指南给的经验起点是 8%~12% 区间，但不同游戏提供的档位和判定方式都不一样，以你自己在游戏里的实际手感为准。

这一步只是「让游戏忽略问题」，不解决漂移本身 —— 手柄在别的游戏里、或者在不支持调死区的游戏里，问题照旧。

## 三、第二步：清洁摇杆根部

摇杆漂移里有相当一部分来自灰尘与碎屑落在摇杆机构里，这类靠清洁能改善。

可以自己做的：

1. 先把手柄关机、断开连接。
2. 用棉签蘸**高浓度异丙醇**（或专用的精密电子清洁剂），轻轻擦拭摇杆根部一圈。
3. 擦的时候把摇杆推到各个方向，让清洁剂进到缝隙里，操作完等它完全挥发再开机。
4. 装回后进 ckck 的漂移测试页复测同一项，对比偏差值有没有收小。

不方便用棉签的位置，可以配合压缩空气吹一吹摇杆周围的缝隙。

**不要**拿普通水、酒精浓度不明的湿巾、或者食用油类去擦，也不要往缝隙里灌清洁剂。

## 四、第三步：按手柄厂商的官方方式校准

如果清洁完偏差还在，接着做校准 —— 校准让手柄重新「认」当前摇杆的中心位置。各平台都有官方入口：

| 平台 | 官方校准入口（以页面上实际显示为准） |
| --- | --- |
| Windows | 设置 → 蓝牙和其他设备 → 选中手柄 → 校准 |
| Xbox 手柄 | 用 Xbox Accessories 应用查看并校准，顺带可以更新手柄固件 |
| Switch | 系统设置 → 手柄与感应器 → 校准摇杆 |
| PlayStation | 设置 → 设备（配件）→ 控制器 → 校准相关选项 |

校准的通用做法是**按屏幕提示把两个摇杆各推满一圈再松手归中**。校准完同样回 ckck 复测，别凭手感判断有没有好。

有两个容易踩的点：

- **校准前先确认摇杆处于静止状态**，手柄放平、别压着摇杆再开始，否则会把当前偏移当成新的中心。
- **校准治的是「中心认错了」，治不了磨损**。如果偏差来自摇杆机构本身的物理损耗，校准只能短暂掩盖。

## 五、什么时候不要再自修

出现下面这几种情况，继续自己折腾收益很低，交给维修或直接换手柄更划算：

| 情况 | 原因 |
| --- | --- |
| 清洁加校准之后，复测偏差没有收小 | 属于物理磨损，软处理无效 |
| 圆周率测试里轨迹有固定缺口 | 某个方向的读值已经不稳定，不是中心偏移问题 |
| 换一台设备复测结果一样 | 排除掉线的因素，问题确实在手柄上 |
| 手柄还在保修期内 | 自行拆机会影响保修，先走售后 |

拆开手柄做深度清洁、更换摇杆机构这类操作需要工具和动手经验，弄坏外壳、扯断排线的风险不低，**不建议把它当成常规处理步骤**。真要换件，找官方售后或有维修资质的店家。

## 六、处理完别忘了记一笔

漂移是会随时间变差的。建议的做法是：把处理前、处理后的平均偏差值记下来（同一个测试页、同样的静止时间），过一两个月再测一次。数值缓慢变大是正常的磨损过程，突然跳变则说明手柄可能被摔过或进过水 —— 这两种情况的处理方式不一样。
