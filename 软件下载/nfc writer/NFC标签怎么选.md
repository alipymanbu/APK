## 一、三种芯片的差别

三种都是恩智浦（NXP）的 NTAG21x 系列标签芯片，都符合 NFC Forum Type 2 标准，手机都能读写；差别主要在容量：

| 芯片 | 用户可用容量 | 能装下什么 |
| --- | --- | --- |
| NTAG213 | 144 字节 | 网址、文本、WiFi 配置 |
| NTAG215 | 504 字节 | 名片信息、较长的网址或组合内容 |
| NTAG216 | 888 字节 | 完整名片信息，或多条记录 |

容量数字来自 NXP 官方数据手册。三种芯片都支持写入后锁定，也有密码保护功能，重要标签写完记得处理，见 [制作碰碰贴与NFC名片](制作碰碰贴与NFC名片.md) 的注意点。

## 二、按用途选

- **只想一碰连 WiFi、开个网页** → NTAG213 最便宜也够用；
- **要做 NFC 名片** → 选 NTAG215 或 216，名片记录占的空间比直觉大；
- **不确定写什么、想留着以后折腾** → 直接 NTAG216，一步到位。

## 三、商品页上的词都什么意思

1. **NTAG213/215/216**：芯片型号，决定容量；
2. **抗金属**：自带隔磁层的标签，才能贴在金属表面（汽车、金属桌面）正常工作；普通标签贴金属上会失灵；
3. **圆形滴胶 / 方形贴纸 / 卡片**：外形差异，芯片一样、写法一样，按贴的位置选形状；
4. **13.56MHz / ISO14443A**：手机 NFC 的工作频率与协议，商品页带这两个标注的就是手机能用的标签。
