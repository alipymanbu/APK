## 一、先准备标签

电商平台搜「NFC 标签」就能买到空白贴纸，常见的 NTAG213、NTAG215、NTAG216 都能用，可用容量从 144 字节到 888 字节不等，型号之间的具体差别见 [NFC标签怎么选](NFC标签怎么选.md)。只写个网址或 WiFi，NTAG213 够用；要塞完整名片信息，选容量大一点的。

## 二、写入步骤

1. 打开 NFC Writer，切到「写卡-自定义（NDEF）」页面；
2. 选要写的数据类型：文本、网址、WiFi、名片、电话、短信、邮件都支持；
3. 按类型填内容，比如选 WiFi 就填网络名称和密码；
4. 把空白标签贴到手机背面感应区，点写入，保持不动直到提示成功。

## 三、几个直接能用的场景

| 做什么 | 写什么 | 贴在哪 |
| --- | --- | --- |
| 客人自助连 WiFi | WiFi 信息 | 路由器旁、前台 |
| 快速交换联系方式 | 名片信息 | 工位、手机壳背面 |
| 一碰打开常用网页 | 网址 | 车载支架旁、桌面 |
| 提醒事项 | 文本 | 门口、冰箱门 |

写好之后，别的 NFC 手机碰一下就会触发对应动作——连 WiFi、存联系人、开网页，不需要对方装任何东西。

## 四、两个注意点

1. **写错了可以重来**：NDEF 标签没锁定前可以反复擦写，重新走一遍写入流程覆盖即可；
2. **不想被人改的标签要锁**：锁定之后标签就不能再改了，锁定前确认内容已经写对；锁死后无法恢复，重要标签先试写一遍再锁。
