# 空白门禁卡买 UID 还是 CUID

> 复制门禁卡要买空白卡，UID 和 CUID 两种名字很像的卡差别不小——手机写卡只能选 CUID，本篇说清原因和挑选注意点。

## 一、结论先说

用手机写空白卡（不管配哪个应用），直接买 **CUID**。UID 卡是给专用读卡器用的，手机写不了它的卡号，买回来大概率白花钱。

## 二、为什么手机写不了 UID 卡

两类卡都能改 0 扇区（存卡号的那一段），但改的方式不同：

| 对比 | UID 卡 | CUID 卡 |
| --- | --- | --- |
| 改卡号的方式 | 需要专用读卡器发的后门指令 | 普通写卡指令就行 |
| 手机能不能写卡号 | 不能（手机不发后门指令） | 能 |
| 写错了 | 能用读卡器救回来 | 可能整卡报废 |
| 遇到会屏蔽复制卡的门禁 | 常被屏蔽 | 相对少见 |

这也是为什么 [写门禁卡步骤](写门禁卡步骤.md) 里强调买 CUID：不是偏好，是手机只写得动这一种。

## 三、买的时候看什么

1. **认准「CUID」「可手机写入」字样**：商品页只写 UID 卡或 GEN1 的不要买（GEN2 才对应 CUID）；
2. **确认频率 13.56MHz、容量 1K（S50）**：门禁复制用的就是这一规格；125kHz 的 ID 卡是另一个物种，手机完全用不了；
3. **形状按用途挑**：卡片形适合贴手机壳，滴胶扣、手腕带适合当钥匙扣，芯片一样、写法一样；
4. **一次多买几张**：CUID 写坏了救不回来，多备几张不心疼。

## 四、买回来之后

写卡步骤见 [写门禁卡步骤](写门禁卡步骤.md)；写不进去、写完刷不开门，先去 [读卡失败怎么办](读卡失败怎么办.md) 排查。写卡用的应用从这里获取：[NFC Writer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/907d1f82e87b)。
