# NFC Writer 读卡失败怎么办

> 本篇汇总 NFC Writer 读卡没反应、数据读不全、写入失败这几类问题的排查方法，按顺序过一遍基本都能定位。

## 一、贴卡没任何反应

按命中概率从高到低排：

1. **NFC 没开**：下拉通知栏确认 NFC 开关是亮的；部分手机重启后 NFC 会自动关；
2. **感应区没找对**：安卓手机的 NFC 感应区大多在后置摄像头周围，卡片贴上去后小范围上下挪动；
3. **手机壳太厚**：金属壳、磁吸壳、带卡槽的手机壳会隔断感应，摘壳再试；
4. **卡本身不是 NFC 卡**：老式 ID 卡（125kHz）看起来和门禁卡一模一样，但手机 NFC 读不出任何东西，这种卡手机方案走不通；
5. **标签贴在金属面上**：普通 NFC 标签贴在金属表面会失灵，隔磁层的抗金属标签才行。

## 二、能读到卡但数据不全

| 读到的结果 | 说明 |
| --- | --- |
| 只有 UID，没有扇区数据 | 卡片加密了，或不是 MIFARE Classic |
| 提示不支持的卡类型 | CPU 卡（银行卡、身份证、升级过的门禁） |
| 部分扇区显示问号或星号 | 对应扇区有密钥保护，属正常现象 |

能读到什么程度取决于卡本身，不是操作问题；卡型对照见 [支持哪些卡片类型](支持哪些卡片类型.md)。

## 三、写入失败

1. **空白卡类型对不上**：复制 MIFARE Classic 数据要用同类型空白卡（推荐 CUID），NTAG 贴纸装不下这类数据；反过来用门禁空白卡写 NDEF 也不行，选卡见 [空白卡买UID还是CUID](空白卡买UID还是CUID.md)；
2. **有扇区没写全**：个别情况一次没写完整，把卡再贴一次补写；
3. **标签是只读的**：锁定过的标签不能再写，换一张新的；
4. **中途移开**：写入过程手机和卡要贴稳，动了就会失败，重来即可。

写入流程本身见 [写门禁卡步骤](写门禁卡步骤.md)，做标签见 [制作碰碰贴与NFC名片](制作碰碰贴与NFC名片.md)。

## 四、别忽略的一步

往空白卡写入前，先确认原卡数据已经在读取记录里（读成功的卡会自动存进记录，可以在记录里左划改名或删除）。格式化这类不可逆操作，先备份再动手。
