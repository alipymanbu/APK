## 一、一张表看懂两者

| | 手机上的油猴 App（网盘这份） | 电脑上的 Tampermonkey 扩展 |
| --- | --- | --- |
| 形态 | 独立的安卓浏览器，脚本管理器内置 | 装在 Chrome / Edge / Firefox / Safari / Opera 里的扩展 |
| 包名 / 标识 | `m.you.hou` | Chrome 版 ID 为 `dhdgffkkebhmkfjojejmpbldmpobfkfo`，Firefox 版 ID 为 `firefox@tampermonkey.net` |
| 开发者 | 多家下载站标注为泗阳县前来网络科技有限公司 | Jan Biniok |
| 官方页面 | [www.youhouzi.cn](http://www.youhouzi.cn/) | [tampermonkey.net](https://tampermonkey.net/) |
| 脚本来源 | 内置插件库 + Greasy Fork 等公开脚本站 | Greasy Fork、OpenUserJS 等公开脚本站 |
| 脚本文件 | `.user.js`，与扩展版同一套规范 | `.user.js` |
| 系统要求 | 本地记录标注安卓 5.2 以上 | 随宿主浏览器（Chrome 120+ 等，以商店页为准） |

关键的一点：**脚本本身是同一套东西**。你在电脑上用的 `.user.js` 脚本，多数能直接装进手机这个 App 里跑——两边的差异在「宿主环境」（一个自带浏览器，一个寄生在浏览器里），不在脚本语言。当然，手机页面是移动端排版，某些为桌面页写的脚本要换适配了手机版的同类脚本，见 [常见问题与排查.md](常见问题与排查.md)。

## 二、什么人该用哪个

- **只在手机上想让网页变好用**：装这个 App 最省事，不用折腾浏览器兼容；
- **电脑上重度用脚本、手机只是偶尔看**：手机上没必要再维护一份脚本列表；
- **要在手机上用官方 Tampermonkey 扩展本身**：走下面第三节的路，而不是这个 App。

## 三、手机上用官方扩展的两条路

官方 FAQ 列出的安卓方案有两个，都不需要这个 App：

1. **Firefox 安卓版 + 官方扩展**：先装 Firefox Android，再从 [Firefox 附加组件页](https://addons.mozilla.org/firefox/addon/tampermonkey/) 安装 Tampermonkey（该版本为 MV2）；
2. **Microsoft Edge 安卓版 + 官方扩展**：官方提供二维码入口（`tampermonkey.net` 首页的 Android 区块），扫码引导安装 Edge 后再装扩展。

另外官方 FAQ 提到的 Legacy 版（MV2）可运行在 Kiwi 浏览器上，但同一页明确标注 **Kiwi 浏览器已停止维护、不推荐继续用**——这条路只在你已经装着 Kiwi 时才有讨论价值。

## 四、两套能不能共存

能。手机上同时装这个 App 和 Firefox + 官方扩展互不冲突，脚本文件也可以互相导入（两边都认 `.user.js`）。实际使用中一般留一套主力即可：要内置广告过滤、嗅探、投屏这些浏览器功能就用这个 App，只要纯粹的脚本管理就用 Firefox + 官方扩展。
