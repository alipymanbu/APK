## 一、脚本装了但页面没变化

按这个顺序查，前三步解决掉大部分情况：

1. **刷新页面**——脚本在页面加载时执行，改完开关不刷新等于没改；
2. **看脚本管理里的开关**——是绿色启用状态吗，脚本的作用站点里包含你打开的这个网址吗；
3. **看安装时的加载是否完成**——通过「网络文件」粘贴链接装的脚本，如果保存时还没加载完，列表里会是一个空脚本，删掉重装、等加载完再保存；
4. **更新脚本**——目标网站改版后，旧脚本常因找不到原来的元素而失效，在脚本管理里检查一次更新；
5. **换适配移动端的脚本**——脚本是按桌面网页结构写的，手机上的页面 DOM 不同，功能就对不上；找标了适配手机版的同类脚本。

## 二、页面被改坏了（内容缺失、按钮错位）

典型原因是某个脚本改了不该改的元素。定位办法是**二分排查**：

1. 脚本管理里把所有脚本全部关闭，刷新页面——正常了，说明问题确实在脚本；
2. 只开第一个脚本，刷新；正常再开第二个……直到复现，最后开的那个就是元凶；
3. 对元凶的选择：能等就等作者更新，等不了就停用它，或者用同功能的另一个脚本替换。

如果是广告过滤造成的正文误伤（关掉全部脚本后内容还是缺一块），改查 [广告过滤与翻译功能怎么用.md](广告过滤与翻译功能怎么用.md) 里过滤规则那一节，把该站点的过滤临时关掉验证。

## 三、安装类问题

| 现象 | 原因与处理 |
| --- | --- |
| 点 `.apk` 提示不允许安装 | 「设置 → 安全/安装未知应用」里给对应的文件管理器或浏览器开权限，重装 |
| 安装时提示解析错误 | 安装包没下完整——核对文件大小是否为 13.81M，不对就重新下载 |
| 提示与已装应用冲突 | 手机上存在同包名（`m.you.hou`）的旧版本，先卸载再装；注意卸载会丢已装脚本，可在卸载前从脚本管理里导出备份 |
| 提示系统版本过低 | 本地记录标注需安卓 5.2 以上（不同渠道标注不一），以手机的提示为准 |

## 四、脚本相关的安全习惯

脚本是别人写的代码，会在你打开的网页里执行，所以：

- **只从可信脚本站安装**，来路不明的脚本链接不要点；
- **在银行、邮箱这类敏感页面把脚本全关掉**再操作，这是脚本管理开关存在的意义之一；
- **看安装确认页的作用范围**——一个要修改你全部网站的脚本，装之前多想一下；
- 定期清理不再用的脚本，装得越多，页面出怪问题时越难排查（见第二节的排查法）。

## 五、版本与渠道差异

同一个名字的安卓油猴 App 在不同下载站有不同版本号与包名（例如有的渠道是别的包名、更高的版本号）。**网盘里这份固定是 5.13.3 / `m.you.hou` / 13.81M**（见 [下载与安装教程.md](下载与安装教程.md) 的核对表）——搜索到的教程截图与你手机上界面不一致时，先确认装的是不是这份，再对照教程。
