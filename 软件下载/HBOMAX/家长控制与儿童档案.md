## 一、儿童档案能拦住什么

HBO Max 的档案分成人（Adult）与儿童（Kids）两类，一个账号最多 5 个。儿童档案的关键差异：

- 首页与搜索结果只出现**不高于所选分级**的内容；
- 有独立的儿童版首页（低龄组可以点角色头像找片），看什么、看到哪都有自己独立的记录；
- 看不了账号管理功能 —— 改密码、订阅信息这些入口对儿童档案不可见；
- 可以开启「Kid-Proof Exit」（儿童防退出），离开儿童档案要输 4 位 Parent Code。

新注册的账号会自带一个默认儿童档案（可看 TV-PG 与 PG 内容），可以直接编辑或删掉。

## 二、建儿童档案的步骤

1. 选头像档案 → **+ New Profile**（档案多于 3 个时可能要横向滑动）。
2. 选一个头像或 Skip。
3. 输名字（1~14 个字符）。
4. 打开 **Kids Mode**。
5. 选**分级组**，默认 Pre-teens（见下一节表格）。
6. 可选：打开 **Kid-Proof Exit**，防止孩子自己退出。
7. 填孩子的出生日期 → Save。

## 三、分级组怎么选

| 分级组 | 对应分级 | 大致内容边界 |
| --- | --- | --- |
| Little Kids | TV-Y | 面向最低龄观众 |
| Big Kids | TV-Y7 / TV-G / G | 可能有轻度幻想或喜剧式暴力，基本无粗口与性内容 |
| Pre-teens | TV-PG / PG | 可能有轻度脏话、暗示性对白、中等暴力（默认档） |
| Teens | TV-14 / PG-13 | 可能有粗口、性暗示场景、较强暴力 |

两点提醒：

- 出生日期未满 18 的儿童档案**关不掉 Kids Mode**；成人档案也不能改成儿童档案。
- 出生日期填错自己改不了，要联系官方处理 —— 建档时一次填对。

## 四、防止孩子跑进成人档案

- **给成人档案设 Profile PIN**：任何成人档案都能设 4 位 PIN，孩子点进成人档案要输码。
- **Kid-Proof Exit + Parent Code**：孩子退出儿童档案时，要点 Exit Kids Profile 并输入 4 位 Parent Code。
- 档案切换行为跟设备有关：电视上，上次用的是儿童档案就直接进它；上次用的是成人档案会停在「谁在看」选择页。手机 / 平板 / 电脑则总是直接进上次的档案。

## 五、分级不生效？按这两条查

- **设备上的家长控制更严时以设备为准**：例如 iPhone 系统级家长控制比应用内分级严格时，HBO Max 会跟随设备的限制；另一面，HBO Max **不跟随**电视提供商侧设置的家长控制。
- 确认改的是当前在用的那个儿童档案：档案 → Manage Profiles → 选中儿童档案 → 调整分级组或 Kid-Proof Exit。

界面语言、字幕语言也按档案独立设置，儿童档案可以单独设，见 [字幕与语言设置.md](字幕与语言设置.md)；档案数量、删除档案等基础操作见 [账号注册与订阅计划.md](账号注册与订阅计划.md)。
