## 一、播放时切换字幕与音轨

字幕和音轨不在设置页里改，而是在播放器里：

1. 开始播放后点一下屏幕，调出播放控制。
2. 选「音频和字幕」图标（Audio and Subtitles）。
3. 在弹出的三栏里按需选：
   - **Subtitles（字幕）**：选一种语言，或选 Off 关闭；
   - **Closed Captions（隐藏式字幕）**：选形如 `English - CC` 的条目；
   - **Audio（音轨）**：选配音语言；想关掉「旁白解说」（Audio Description，目前仅英语提供），在这里改选一个不含 Audio Description 的语言。
4. 点 X 保存，继续播放。

一部片子有哪些字幕和配音语言，以它在播放器里实际列出的为准 —— 不是所有片目都配了你想要的语言。

## 二、默认语言按什么规则选

- HBO Max 会播放**你上一次选中的音频语言**。
- 从没选过的话，跟随当前档案的**界面显示语言**（Display Language，见下一节）。
- 你的偏好在这部片子上不可用时，回落到英语音轨。

所以「上次明明选了某个语言的配音，换一部剧又变回英语」，多半是那部片子没有对应音轨，回落到了英语。

## 三、界面显示语言（Display Language）

界面文字的语言按**档案**设置，改一次全设备生效：

1. 选你的头像档案，进 **Manage Profiles**。
2. 点要改的档案。
3. 选 **Display Language**，挑一种语言，Done 保存。

可选语言列表以设置页实际显示为准（不同地区的可选项有差异）。每个账号最多 5 个档案，档案怎么建、成人档案与儿童档案的差别，见 [账号注册与订阅计划.md](账号注册与订阅计划.md)。

## 四、字幕样式（大小、颜色、透明度）

字幕外观不在 HBO Max 应用里调，各端入口不同，且**改动不跨设备同步**：

| 端 | 入口 |
| --- | --- |
| 安卓手机 / 平板 | 系统设置里搜 Caption（字幕），选 Caption style 调整 |
| iPhone / iPad | 系统设置 → 辅助功能 → 字幕与隐藏式字幕 → 样式 |
| 网页 [HBOMax.com](https://hbomax.com/login) | 头像档案 → Settings → Subtitle Style，可调字体、颜色、大小、透明度 |
| 部分电视 | 应用内「字幕样式」设置；没有这项就走电视系统设置 |

## 五、字幕关不掉 / 下载的集数语言不对

- 在应用里关了字幕却还显示：HBO Max 会跟随**设备系统级**的字幕设置，去系统设置的辅助功能里检查字幕是否被系统打开。
- 下载离线视频时，应用按你当次选的音轨和字幕打包语言，想换语言先在播放器里选好再下，规则细节见 [离线下载与多设备观看.md](离线下载与多设备观看.md)。
- 播放器打不开、字幕一直加载不出来这类问题属于播放故障，按 [播放报错与卡顿排查.md](播放报错与卡顿排查.md) 处理。
