## 一、先看你的套餐能不能下

下载只支持手机 / 平板端（iPhone、iPad、iPod touch、Android 手机平板、Amazon Fire 平板），且按套餐有区别（档位详情见 [账号注册与订阅计划.md](账号注册与订阅计划.md)）：

| 套餐 | 离线下载数量（全部移动设备合计） |
| --- | --- |
| Basic with Ads | 无下载功能 |
| 移动端基础版（仅部分市场） | 15 个 |
| Standard | 30 个 |
| Premium | 100 个 |

三条额外的硬上限（官方帮助中心口径，视可用情况而定）：

- 同一部剧集**最多同时下载 25 集**（所有移动设备合计）。
- 电影类内容 Standard 与 Premium **合计最多 30 部**同时在设备上。
- 个别内容类别有额外限制，下载按钮呈灰色或干脆没有，就是这部片子不让下。

## 二、下载步骤

1. 用手机或平板登录 HBO Max，确认设备剩余存储够用。
2. 找到想下的片子：可以下载的，标题简介旁会有**下载图标**（向下箭头）；没有这个图标就是不可下载。
3. 想指定语言，先在播放器里选好音轨与字幕再下 —— 应用按你当次选中的语言打包（例如选了泰语音轨和字幕，就下泰语的；原声是英语时还会一并带上英语）。
4. 点下载图标开始，图标会显示进度；中途想取消就点进度图标再选取消。
5. 下完后在应用的「下载」页里找到并播放。

## 三、有效期、续期与删除

| 规则 | 时限 |
| --- | --- |
| 下载后一直没看 | 30 天后过期（或官方下架该片时失效） |
| 开始看之后 | 48 小时内要看完，到期即失效 |
| 过期了想接着看 | 在下载页选「延长下载期限」，需联网 |

删除：在下载页点该内容旁的对勾图标 → 删除下载；剧集可进剧集页 → 编辑 → 点集数旁的 X 逐集删。「延长下载期限」需要联网才能操作，一直续不上就先按 [播放报错与卡顿排查.md](播放报错与卡顿排查.md) 排网络。

数量上限是**按账号**在所有移动设备上合计的：旧设备上的下载不删就继续占额度。设备已经不在手边时，可以登出该设备 —— 登出不会删它上面的下载，未观看的会在 30 天后自动过期、腾出额度。

出行不用重新下载：官方帮助中心的口径是，已下载的内容可以在**任何国家或地区**观看。

## 四、下载画质与流量设置

入口：头像档案 → **App Settings** → **Download Settings**。

- **Video Quality**：Good / Better / Best 三档，Best 占存储最多；
- 可设置**仅 Wi-Fi 下载**，避免蜂窝数据跑流量；
- 同一页能看到设备剩余可用存储。

## 五、同时能几台设备看

- Standard：**2 台设备**同时播放（Full HD）。
- Premium：**4 台**同时播放（4K UHD、Dolby Atmos 视片源而定；体育直播限 2 台；4K 的完整条件见 [4K画质与杜比音效观看条件.md](4K画质与杜比音效观看条件.md)）。
- Basic with Ads：2 台；移动端基础版：**1 台**，且只能在手机或平板上看。
- 部分市场的移动端基础版不支持隔空播放（AirPlay）与 Chromecast 投屏。

超过上限时，新设备会播不出来，先停掉一台正在观看的，或登出不用的设备。
