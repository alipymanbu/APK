## 一、先说清楚：没有中文界面

Myket 是面向伊朗用户的商店，界面语言只有**波斯语和英文两种**，第三方介绍与实际界面都确认它不提供中文；第三方 APK 信息站收录它时也只标注英、波两种应用语言（截至 2026-09），两个来源对得上。官方对波斯语体验的投入（本地内容团队、波斯语配音影视、本地社区）也决定了它的重心不在于多语言。

把语言设置成「跟随系统」也不会变出中文 —— 系统语言是中文时，它只会回落到默认的波斯语。所以第一次打开想看懂界面，唯一的选择就是切成英文。

## 二、把界面切到英文的步骤

按 v10.x 的界面整理，不同版本入口位置可能略有差异：

1. 打开 Myket，点首页**右上角的头像图标**，进入个人页面（My-Market）。
2. 点该页面**右上角的齿轮样式设置图标**，进入设置（Settings）。
3. 在设置列表里找到 **Language** 选项，点开。
4. 弹窗里选 **English**，确认后整个界面同步切换。

一次设置长期生效，不需要每次启动都改。如果在英文界面里找不到这些入口，对照这一串：头像（右上角）→ My-Market → 齿轮 → Settings → Language。

## 三、切了英文之后，哪些地方还是波斯语

界面框架变成英文，但内容层面的波斯语不会消失，提前有数：

| 位置 | 切英文后 |
| --- | --- |
| 按钮、菜单、设置项 | 英文 |
| 应用与游戏的介绍文字 | 以波斯语为主，看开发者有没有写英文版 |
| 用户评论区 | 基本全是波斯语 |
| 电影剧集条目 | 标题多为英文，配音与字幕是波斯语 |
| 搜索结果 | 搜英文关键词能出结果，本地应用要用波斯语原名才搜得到 |

最后一条最实用：**搜本地应用时直接贴波斯语原名**，或者从分类页里翻，靠英文关键词硬搜伊朗本地应用经常一无所获。

## 四、看不懂波斯语内容时的应对

1. **屏幕翻译**：各品牌安卓机基本都带「屏幕翻译」或「智能侧边栏翻译」类功能（名称因品牌而异），对着详情页整屏翻一遍，比逐句复制省事。
2. **认关键字**：详情页真正影响你操作的其实就几个词 —— Install（安装）、Update（更新）、Open（打开）、Size（大小），认得这几个就能完成绝大部分流程。
3. **善用评论区篇幅**：评论多且评分高的应用，本地用户已经替你踩过坑；看不懂可以翻译前几条热评。

语言切好之后，下一步就是把应用装起来，操作细节见 [应用下载与游戏数据包安装.md](应用下载与游戏数据包安装.md)；如果连语言设置页都进不去（应用打不开、白屏），先去 [常见问题与解决方法.md](常见问题与解决方法.md) 排查应用本身的问题。还没装 Myket 的，从 [下载与安装教程.md](下载与安装教程.md) 开始。
