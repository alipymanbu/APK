## 一、哪些内容是免费的

书可以随便逛、随便加入书架，每本书的前面若干章节免费读；往后翻到某一章会开始要金币。换句话说，免费的部分够你判断一本书值不值得追，追到后半程基本都要消耗金币。

## 二、金币从哪来

| 渠道 | 说明 |
| --- | --- |
| 每日签到 | 每天点一次领小额金币，连续签满一周通常有加成 |
| 看视频 / 广告 | 在任务或章节解锁页看一段广告视频换金币，每天限固定次数 |
| 阅读挑战 | 每天读满一定时长给奖励，活动期常有 |
| 社交任务 | 关注官方 Facebook、邀请好友、发评论之类，做完给一次性的金币 |
| 活动奖励 | 节日活动、新书活动偶尔会送金币，留意应用内活动页 |
| 充值购买 | 应用内直接买金币包或订阅套餐，价格以你手机应用商店显示的为准 |

三点提醒：

1. 金币余额挂在账号上，不登录就领不了，登录方式见 [注册登录与账号同步.md](注册登录与账号同步.md)；
2. **奖励金币有有效期，而且普遍不长**：多位用户反馈做任务领的金币几天内就过期（有说 5 天、也有说 2 天的），官方活动送的币有效期则长得多；以你金币页每笔余额旁标注的到期时间为准。领了就当天用掉最稳；
3. **解锁时先扣哪种金币要注意**：有用户反馈解锁时会优先消耗付费金币、奖励金币反而留到过期；解锁前看一眼消耗明细，发现不对就先花掉奖励金币。

## 三、追更成本怎么估

免费章节看完之后，一本追到完结要花多少金币，差别极大。下单（尤其是付费）之前先看两个数字：

| 要看的数字 | 在哪看 | 判断 |
| --- | --- | --- |
| 总章节数 | 书的目录页，拉到底看总章数 | 上千章的书不少见，按每章扣费折算总账会很惊人 |
| 更新速度 | 目录页的更新时间 | 常见日更一到两章，有的作者隔几天才更、甚至断更快一个月 |

多位读者反馈追完一本长书的总花费远超一本电子书的定价——热门书勾着人一章章往下读，钱就在不知不觉里花出去了。给自己设个预算上限，是这类应用最实用的习惯。

## 四、怎么用金币解锁章节

1. 打开一本追到付费章节的书；
2. 翻到带锁标记的那一章，点它；
3. 弹出解锁提示，显示本章要多少金币，点确认消耗金币解锁；
4. 解锁过的章节记录在账号里，重装后登录同账号一般仍可读；个别用户反馈遇到过重新上锁的情况，真碰上就带着账号信息找客服核对。

金币不够时，解锁页会引导你去做任务或充值，按自己的节奏选就行。

## 五、充值与付费方式

- 充值走的是应用内购，实际扣款走你手机上绑定的应用商店支付方式（Google Play 或 App Store 账号）；
- 不同地区的金币价格和套餐不一样，以你账号所在地区的商店页面显示为准；
- **先小额试水**：已消耗的金币基本退不回来，客服流程也要用英文写邮件，第一次充值别一上来就买大额包；
- 想先算一笔账：按上一节的两个数字估算总成本，再决定是做任务白嫖还是小额充值。

## 六、付费和账号有问题找谁

官方客服邮箱：`contact@goodnovel.com`，写了邮件要附上你的账号信息和订单截图，处理会快一些。官方还提供一份意见收集表单（在应用内关于页或官网可以找到入口）。

付费前先确认已经登录到正确的账号，不然金币和解锁记录会挂到别的账号上。其余日常使用疑问汇总在 [使用常见问题.md](使用常见问题.md)；应用还没装的话，先看 [下载与安装教程.md](下载与安装教程.md)。
