## 一、哪些内容是免费的

书可以随便逛、随便加入书架，每本书的前面若干章节免费读；往后翻到某一章会开始要金币。换句话说，免费的部分够你判断一本书值不值得追，追到后半程基本都要消耗金币。

## 二、金币从哪来

| 渠道 | 说明 |
| --- | --- |
| 每日任务 | 签到、阅读时长、分享之类的日常任务，做完领少量金币 |
| 看视频 / 广告 | 在任务或章节解锁页看一段广告视频换金币，数量比每日任务多一点 |
| 活动奖励 | 节日活动、新书活动偶尔会送金币，留意应用内活动页 |
| 充值购买 | 应用内直接买金币包或订阅套餐，价格以你手机应用商店显示的为准 |

两点提醒：

1. 金币余额挂在账号上，不登录就领不了，登录方式见 [注册登录与账号同步.md](注册登录与账号同步.md)；
2. 有用户反馈任务领的金币有几天有效期、过期清零。不管这个说法在你那版是否成立，**领了就尽早用**总是不吃亏的。

## 三、怎么用金币解锁章节

1. 打开一本追到付费章节的书；
2. 翻到带锁标记的那一章，点它；
3. 弹出解锁提示，显示本章要多少金币，点确认消耗金币解锁；
4. 解锁过的章节记录在账号里，重装后登录同账号仍可读。

金币不够时，解锁页会引导你去做任务或充值，按自己的节奏选就行。

## 四、充值与付费方式

- 充值走的是应用内购，实际扣款走你手机上绑定的应用商店支付方式（Google Play 或 App Store 账号）；
- 不同地区的金价和套餐不一样，以你账号所在地区的商店页面显示为准；
- 想先算一笔账：看看自己追的书每天更几章、每章多少金币，再决定是做任务白嫖还是小额充值。

## 五、付费和账号有问题找谁

官方客服邮箱：`contact@goodnovel.com`，写了邮件要附上你的账号信息和订单截图，处理会快一些。官方还提供一份意见收集表单（在应用内关于页或官网可以找到入口）。

付费前先确认已经登录到正确的账号，不然金币和解锁记录会挂到别的账号上。其余日常使用疑问汇总在 [使用常见问题.md](使用常见问题.md)；应用还没装的话，先看 [下载与安装教程.md](下载与安装教程.md)。
