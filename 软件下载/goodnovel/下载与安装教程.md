## 一、安装前先确认三件事

| 项目 | 说明 |
| --- | --- |
| 系统版本 | Android 5.0 及以上（以官方应用商店页面标注为准） |
| 存储空间 | 安装包约 37.73 MB，加上运行缓存，建议手机至少留出 500 MB 空余 |
| 安装来源 | 安装包来自网盘而不是应用商店，安装时系统会要求你允许「未知来源 / 安装未知应用」 |

## 二、获取安装文件

安装包在夸克网盘里：**GoodNovel 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/2060db626120](https://pan.quark.cn/s/2060db626120)

1. 打开链接，把文件夹里的 `.apk` 安装包（版本 3.7.4）转存到自己的夸克网盘；
2. 用夸克网盘 App 把它下载到手机本地存储；
3. 想核对文件是否完整，可以看它的 MD5：`37FB4058AB3A5CE8074712B2B5CE32A2`（32 位，注意大小写不影响比对结果）。

网盘里这一份是 3.7.4 版。官方后来还在更新，Google Play 上的版本号已经更高；用哪一版由你决定，本套文档的版本号、包名、体积都以这份安装包为准。

## 三、安装步骤

1. 在手机上点开下载好的 `.apk` 文件；
2. 弹出「禁止安装未知来源应用」提示时，点「设置」→ 打开「允许从此来源安装」，返回继续；
3. 点「安装」，等进度条走完；
4. 点「打开」直接进入应用，或回桌面找 GoodNovel 图标。

不同品牌的手机路径略有差别：小米在「安装应用」弹窗里给授权，华为会多一步「继续安装」确认，OPPO / vivo 一般在弹窗里直接勾选「仍要安装」。

## 四、装好了，第一次打开会看到什么

1. 启动后会先让你选读者类型（男性 / 女性频道），用来决定首页推荐的内容倾向，选错也没关系，后面能改；
2. 不注册账号也能直接逛书，但换手机后书架和阅读进度不会跟着走；想同步就先登录账号，做法见 [注册登录与账号同步.md](注册登录与账号同步.md)；
3. 界面默认是英文，语言选项里没有中文，具体能调哪些设置见 [阅读设置与界面导览.md](阅读设置与界面导览.md)。

## 五、安装失败怎么排查

| 现象 | 先查什么 |
| --- | --- |
| 提示「解析包错误 / 应用未安装」 | 安装包很可能没下完整，重新转存、重新下载一遍，再核对 MD5 |
| 提示存储空间不足 | 清一下手机空间，安装包本体加运行余量，500 MB 比较稳 |
| 手机上已装过其他版本 | 先卸载旧版再装；数据会丢，先确认书架进度已同步到账号 |
| 一直卡在「安装中」 | 重启手机后重试；仍不行就换个文件管理器打开 `.apk` 再装 |

装上之后登录或使用中碰到的问题，比如登录方式、金币怎么领、书架怎么同步，都整理在 [使用常见问题.md](使用常见问题.md) 里。
