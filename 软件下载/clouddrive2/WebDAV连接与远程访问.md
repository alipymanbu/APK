## 一、WebDAV 服务的地址与账号

| 项目 | 内容 |
| --- | --- |
| 服务器地址 | `http://<设备 IP>:<端口>/dav` |
| 用户名 | 登录 CloudDrive2 的邮箱（也可以只填 `@` 前面那一段） |
| 密码 | 登录 CloudDrive2 的密码 |

端口的说明要单独讲：官方手册标注独立部署的核心服务用 **19798**，安卓应用自带的那个核心监听 **29798**；也有第三方教程写的是 19798。两边不一致时，以应用「WebDAV」页或界面上实际显示的地址为准。

## 二、用播放器直接连（免 Root 最常用的方式）

以 Kodi 为例：

1. 文件 → 添加视频 → 浏览；
2. 选「添加网络位置」；
3. 协议选 WebDAV，服务器地址、用户名、密码三项按上面表格填；
4. 确定后这个源里就是你的网盘目录，视频、音乐都能直接播放。

MX Player、nPlayer 这类播放器的「网络」或「流媒体」入口也是同样三项：地址、账号、密码。连上之后播放与字幕相关的设置见[影音播放与字幕设置.md](影音播放与字幕设置.md)。

## 三、SAF：让支持它的应用直读文件

安卓版还支持系统的存储访问框架（SAF）：在支持 SAF 的文件管理器或应用里，把 CloudDrive2 当作文档提供方选中，不 Root 也能直接读写里面的文件。哪些第三方应用支持 SAF，以那个应用自己的说明为准。

## 四、局域网里访问

- 手机上的 CloudDrive2 起来之后，同一 Wi-Fi 下的电脑、平板打开 `http://<手机 IP>:<端口>` 也能进管理界面，操作的是同一份云盘账号；
- 反过来，如果你家里 NAS 或电脑上已经跑着 CloudDrive2 核心服务，可以在应用里用「地址 + API 令牌」把它连过来，离线下载、跨云复制这类任务就落到那台服务器上执行，令牌在服务端「API 令牌」页创建。

## 五、接到 Emby / Jellyfin

家里 NAS 或电脑上跑着 Emby、Jellyfin 的话，官方提供了对应的插件（官网下载页的「Emby / Jellyfin plugin」一节）。接法：在服务端「API 令牌」页给插件建一个专用令牌——给 Emby / Jellyfin 插件用的令牌要多勾两项插件所需的权限——再把令牌填进插件。媒体服务器扫库时读挂载出来的目录或 WebDAV 地址，看到的和手机里是同一份云盘。

## 六、要不要开到公网

把 19798 这类端口直接暴露到公网，意味着任何人都能试着连你的管理界面。想在外面用的话，更稳妥的是走 VPN 或带鉴权的内网穿透，别让管理界面裸奔在公网上。

连不上、白屏这类问题的排查顺序见[常见问题与排查方法.md](常见问题与排查方法.md)；有 Root 想直接挂成本地目录的看[挂载网盘到本地教程.md](挂载网盘到本地教程.md)。
