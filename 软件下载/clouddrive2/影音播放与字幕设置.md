## 一、视频播放能力

| 能力 | 说明 |
| --- | --- |
| 蓝光原盘 | 直接播放云端的蓝光 ISO 或 BDMV 文件夹，带真实光碟菜单，HDMV 与 BD-J 两种菜单都能用 |
| HDR 与杜比视界 | HDR10、HDR10+、杜比视界 P5 / P7 / P8（P7 含完整增强层 FEL）；TS / M2TS 重封装的片源也能识别出 HDR 与帧率 |
| 高分辨率 | 4K、8K、AV1；硬件解码器解不动的 H.264 High Profile 会自动回退到软件解码 |
| 3D | 支持 MVC 3D 立体蓝光 |
| 不完整镜像 | 截断的镜像会跳过菜单、直接播放正片 |

杜比视界能不能出效果取决于设备：电视或盒子本身要支持杜比视界输出；不支持的机器上同一个文件会以 HDR10 播放，这是输出端的能力差异，不是片源问题。

## 二、字幕

- **外挂字幕**：支持 .ass / .srt；播放蓝光时也能在会话内渲染 PGS 字幕；
- **AI 字幕翻译**：优先翻译已有字幕轨（包括对 PGS 图形字幕做 OCR），没有字幕轨时才用语音识别。可以完全在设备端跑——音频不出手机；也可以接远程 API（OpenAI、Groq、Qwen，或你自建的服务）；
- **字幕回存**：生成出来的字幕可以存回网盘，换台设备接着用，不用重新生成。

## 三、音乐与 DSD

- 格式：DSF、DFF、SACD ISO，DSD64 到 DSD1024 都能放；
- USB DAC：插上后应用按解码器自己声明的规格输出，支持 DoP 与原生 DSD，超过解码器能力的档位自动转 PCM；
- 界面有媒体通知与锁屏控制，cue 表也支持；整张 SACD ISO 放在网盘里点开就能听，不必先同步到本地。

## 四、电视盒子上的使用

同一个应用也能装到 Android TV 或电视盒子，遥控器操作蓝光菜单、字幕加载这些同样可用。电视侧的安装路径、遥控操作与杜比视界输出条件单独成篇，见[安卓电视盒子使用教程.md](安卓电视盒子使用教程.md)；用第三方播放器连网盘时走 WebDAV，见[WebDAV连接与远程访问.md](WebDAV连接与远程访问.md)。

## 五、片源在云端，不必先下载

几十 GB 的蓝光原盘点开就放，不用先下载到本地，也不用先挂载。播放卡顿先查网络带宽，再确认片源所在的网盘限不限速；用第三方播放器连这个应用时，地址与端口那套配置在[WebDAV连接与远程访问.md](WebDAV连接与远程访问.md)里。网盘账号还没接进来的先看[添加网盘与授权登录.md](添加网盘与授权登录.md)。
