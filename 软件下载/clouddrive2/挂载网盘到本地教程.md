# CloudDrive2 挂载网盘到本地教程

## 一、先确认：手机挂载需要 Root

安卓系统没有向普通应用开放本地文件系统挂载，官方帮助页也写明：**没有 Root 的系统无法把云盘挂载到本地文件系统**，多云盘备份、WebDAV 服务等其余功能不受影响。你的手机没 Root 的话，直接看第三节的替代路径。

## 二、有 Root 的挂载步骤

1. 打开应用时允许 Root 权限；
2. 管理界面进「挂载点」页，点「添加挂载点」；
3. 填这几项：

| 项目 | 填什么 |
| --- | --- |
| 挂载名称 | 随意，显示用 |
| 源目录 | 要挂出去的目录：可以是某个网盘的根目录或它下面的任意一层，填 `/` 则把所有已连接的云盘一起挂出去 |
| 挂载点 | 一个空目录 |
| 选项 | 勾「只读」防误删误改；勾「启动时自动挂载」让它跟着服务一起起来 |

4. 挂好后用文件管理器进那个目录，网盘文件就在里面，手机上其他应用也能直接打开里面的文件。

## 三、没有 Root 的替代路径

- **WebDAV 连接**：播放器、文件管理器通过 WebDAV 协议连上来使用，效果接近，步骤见[WebDAV连接与远程访问.md](WebDAV连接与远程访问.md)；
- **SAF 直读**：支持存储访问框架的应用可以直接把 CloudDrive2 当文档源读写。

## 四、挂载点的额度

免费账号能建 **1 个**本地挂载点，核心会员不限数量（各档权益以 [www.clouddrive2.com/pricing.html](https://www.clouddrive2.com/pricing.html) 为准）。挂载点数量不影响云盘账号的添加数量，两者是分开算的。

## 五、挂上之后注意两件事

- 在挂载目录里删除文件，删的是网盘上的真实文件，没有回收站可捞，批量操作前先看清列表；
- 在网盘自己的 App 或网页上做的改动（上传、改名、删除），挂载目录里要刷新一次才会反映出来；开启「目录缓存持久化」后，刷新会把新读到的内容和已存缓存比对，差异会照常触发实时增量备份——备份相关规则见[手机相册备份到网盘.md](手机相册备份到网盘.md)，其他问题见[常见问题与排查方法.md](常见问题与排查方法.md)。

云盘账号还没添加的话，先看[添加网盘与授权登录.md](添加网盘与授权登录.md)。
