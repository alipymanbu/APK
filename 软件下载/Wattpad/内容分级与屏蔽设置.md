# Wattpad 内容分级与屏蔽设置

> 本篇讲怎么把不想看到的内容从 Wattpad 里关掉：成人内容开关、屏蔽标签（Blocked Tags）、静音与举报，以及这套过滤的实际边界。

Wattpad 是用户自由发布内容的平台，题材跨度大，标了「Mature（成人）」的作品在推荐流里默认会出现。你要做的是把两层开关按自己的需要调好——推荐流过滤和标签屏蔽，两分钟的事。

## 一、关掉推荐流里的成人内容

- **App 端**：首页右上角头像旁的图标点开 → 把「Include Mature」开关关掉（灰色即生效），成人题材就不再进你的推荐。
- **网页端**：登录后进 Settings → Content Preferences → 关掉 Mature Content → Apply Changes。

**这个开关的真实边界要清楚**：它只影响「推荐」，不影响「搜索」。你或者家里人用标签搜索，依然能搜到成人内容；想彻底不见到某类题材，用下一节的标签屏蔽。

## 二、屏蔽标签（Blocked Tags）

比分级开关更精确的手段，直接把不想见的题材标签拉黑：

1. 首页右上角头像旁的图标点开，找到「Blocked Tags」。
2. 在输入框里输入要屏蔽的标签，边打会出现候选，选中即可；想屏蔽多个就继续加。
3. 加完点「SAVE」保存。

两个填写规则（家长指引类来源实测整理）：**每个标签写成一个词**（比如 `selfharm` 而不是 `self harm`），空格会被当成新标签拆开；保存后这些标签的作品不会再出现在你的推荐流里。

## 三、静音与举报：管住「人」这一层

内容之外，骚扰和违规评论靠这两个工具处理：

| 工具 | 操作 | 效果 |
| --- | --- | --- |
| 静音（Mute） | 进对方主页 → 右上角三点 → Mute → 再确认 | 对方不能关注你、私信你、在你主页和作品下留言 |
| 举报用户 | 对方主页 → 右上角三点 → Report → 选理由并说明 | 平台按社区准则处理 |
| 举报作品 | 作品页右上角三点 → Report → 先选大类再选细分理由 | 未正确标注成人内容、仇恨言论等都在受理范围 |

## 四、年龄门槛与注册信息的关联

- 服务条款要求的最低注册年龄是 **13 岁**，但苹果 App Store 把这个应用评为 **17+**——差距正来自上面的成人内容问题。
- 注册时填写的**出生日期**影响内容分级相关入口的可用性，多个家长指引类来源提到未成年生日会看不到成人内容开关；给孩子注册或共用设备时，把日期填对比事后补救省事。
- 平台没有年龄验证，靠自觉申报，所以设备侧的管控（系统屏幕时间、应用锁）在家庭场景里比应用内开关更可靠。

## 五、给别人写作品时的对应义务

反过来，如果你是作者：作品里含成人题材就要把分级标成 Mature，并打上对应标签；不标或错标会被读者举报。作者侧的分级设置在发布流程里，见[写作与发布流程.md](写作与发布流程.md)。

推荐流还是不断出现不想看的内容、或屏蔽后没生效，到[常见问题排查.md](常见问题排查.md)对一下现象；账号层面的设置（密码、邮箱）在[注册登录与账号设置.md](注册登录与账号设置.md)里。
