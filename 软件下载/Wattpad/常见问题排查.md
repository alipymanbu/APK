症状 → 原因 → 处理，按现象对号入座；每条都给可以直接执行的步骤。通用先手棋只有两步：**切换网络重试**（Wi-Fi 与流量互换）和**彻底杀掉 App 重开**，多数偶发问题这两步就解决了。

## 一、登录不上

| 现象 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| 密码错误 | 大小写、输入法大小写锁定（密码区分大小写） | 用「Forgot Password?」重置，见[注册登录与账号设置.md](注册登录与账号设置.md)第四节 |
| 用 Google/Facebook 登录失败 | 手机上对应的账号是否还登着 | 先确认 Google/Facebook 本身能登录，再回 Wattpad 重试 |
| 一直转圈 | 网络被拦截 | 换网络重试；公司或校园网常见拦截，换热点验证 |
| 提示邮箱已注册 | 邮箱绑过另一个账号 | 一个邮箱只能绑一个账号，用那个账号登录或找回 |

**Session 过期（Your session has expired）**：网页端出现基本是浏览器清了 Cookie 或禁止了 Cookie，允许 Cookie 后重新登录；App 端长时间未操作后要求重登属正常，重新登录即可。

## 二、收不到系统邮件

重置邮件、验证邮件收不到，按顺序查：

1. **垃圾邮件箱**，这类邮件最常被误杀；
2. 邮箱地址是否输错（注册用的是不是当前这个邮箱）；
3. 等几分钟再触发一次——邮件有延迟；
4. 邮箱服务商的反垃圾设置里把 `wattpad.com` 加白名单。

## 三、换手机后书架「丢了」

书架没丢，是登错了号。书架、进度、阅读清单、已解锁的付费章节全部绑定账号：

1. 确认新手机用的是**当初同一种登录方式**（Google 注册就点 Google 登录）；
2. 用邮箱登录查无此书架时，换回第三方方式登录试试；
3. 两个账号的书架不能合并；实在找不回注册方式，用注册邮箱走密码重置流程验证账号归属。

离线缓存的章节**不会**跨设备迁移，登对账号后重新下载即可，见[阅读功能与离线缓存.md](阅读功能与离线缓存.md)。

## 四、App 闪退、卡顿、白屏

1. 彻底关闭 App 再开；
2. 手机存储剩余空间不足 1 GB 时先清空间（缓存离线章节很吃存储）；
3. 检查是否有系统更新与 App 更新，旧版本与新内容的兼容问题多见于久未更新的安装包；
4. 仍不行再卸载重装——重装**不丢账号数据**，但会清掉本地离线缓存，重装前把要看的书提前缓存回账号书架即可。

## 五、作品相关

| 问题 | 原因与处理 |
| --- | --- |
| 刚发布的作品搜不到 | 新作品收录有延迟（几分钟到几小时）；先确认作品状态是公开（Published）而不是草稿（Draft），再等收录 |
| 某章读者读不了 | 检查该章是否误存为草稿；被取消发布的章节不会出现在读者端 |
| 想举报违规内容 | 作品页或用户主页右上角三点菜单 → Report，选理由提交 |
| 作者删了章节/作品 | 作者侧删除不可恢复，读者端缓存的章节还在你本地，但刷新后就没了 |

## 六、内容与账号的其他问题

| 问题 | 原因与处理 |
| --- | --- |
| 推荐流不断出现成人内容 | 关掉「Include Mature」开关并按需拉黑标签，App 与网页端的操作路径见[内容分级与屏蔽设置.md](内容分级与屏蔽设置.md)；注意过滤只影响推荐，搜索仍能搜到 |
| 收到骚扰私信或恶意评论 | 先静音（Mute）对方，再视情况举报，两步的操作细节同见[内容分级与屏蔽设置.md](内容分级与屏蔽设置.md)第三节 |
| 想彻底注销账号 | 网页端操作、先备份作品、先取消订阅，完整步骤见[注销账号前的准备与步骤.md](注销账号前的准备与步骤.md) |

## 七、广告与付费的争议

- 章节间广告多是免费版的正常行为，不是故障；去广告靠 Premium 订阅，付费章节靠金币，两者的边界见[会员付费与金币解锁.md](会员付费与金币解锁.md)。
- 扣费问题（误扣、重复扣、退订后仍扣）走 Google Play / App Store 的订单退款流程，应用内没有退款入口。
- 「会员状态消失」先核对登录的账号，会员不跨账号共享。

以上仍解决不了的，走 App 内的官方帮助入口（设置 → Help / Help Center）提交工单，附上报错截图与操作步骤，处理效率比反复重试高。
