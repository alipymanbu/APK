# Wattpad 注销账号前的准备与步骤

> 本篇讲怎么把 Wattpad 账号彻底关掉：动手前要备份和取消的东西、网页端注销步骤、注销之后哪些东西会一起消失。

注销是**不可逆**操作：作品、书架、评论、私信一并删除，用户名会被释放给别人注册。多个独立来源的步骤一致，都指向**网页端**操作，App 内通常没有这个入口。下面按「先备份 → 再取消订阅 → 最后注销」的顺序走。

## 一、动手前先做三件事

1. **备份自己的作品**：注销后你写的所有故事会被永久删除，读者端也看不到。动手前把自己的章节复制或导出保存到本地（网页端打开自己的作品逐章复制最稳妥；有导出选项时以页面当时提供的格式为准）。
2. **取消 Premium 订阅**：订阅挂在 Google Play / App Store 账号上，不先取消，注销后可能继续扣款。取消路径见[会员付费与金币解锁.md](会员付费与金币解锁.md)第二节。
3. **记下想留的联系方式与书单**：书架、阅读清单、别人的作品链接都会消失，想以后再读的先存个清单。

## 二、注销步骤（网页端）

1. 浏览器打开 [www.wattpad.com](https://www.wattpad.com) 并登录（手机浏览器同样可行）。
2. 右上角点头像 → Settings。
3. 设置页**滚到底部**，右侧有「Close Account」。
4. 按页面要求填写离开原因（可跳过）。
5. 勾选「Yes, I'm sure. Please close my account」这类确认框。
6. 输入账号密码验证身份。
7. 点「Close Account」提交，账号进入关闭流程。

App 内找不到这个入口属正常，不要在 App 里反复找；用浏览器走上面的流程即可。

## 三、注销之后会发生什么

| 会消失 | 说明 |
| --- | --- |
| 你发布的全部作品 | 不可恢复，读者与关注者都无法再访问 |
| 书架、阅读清单、阅读进度 | 一并清空 |
| 你发过的评论、投票、私信 | 全部删除 |
| 用户名 | 被释放，别人可以注册同名账号 |

两个常见疑问：

- **邮箱还能再用吗**：可以，同一邮箱注销后能注册新账号，但旧账号的数据拿不回来。
- **注销和长时间不登录是一回事吗**：不是。不登录账号还在、内容都留着；只有走完 Close Account 流程才算注销。

## 四、拿不准就先不停用

只是不想被消息打扰，不必注销：静音特定用户、关通知、关成人内容推荐这些可逆手段见[内容分级与屏蔽设置.md](内容分级与屏蔽设置.md)和[注册登录与账号设置.md](注册登录与账号设置.md)。真要离开，按本文流程走完即可，注销后遇到登录类异常（邮箱被占用、提示已注册）在[常见问题排查.md](常见问题排查.md)有对应条目。
