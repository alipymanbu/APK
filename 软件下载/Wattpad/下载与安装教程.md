Wattpad 是一个「读 + 写」一体的故事社区：你能免费读大量连载小说，也能自己开作品发章节。本篇按拿到安装包 → 装上 → 打开能用的顺序讲，装完之后的第一件事（注册账号）见[注册登录与账号设置.md](注册登录与账号设置.md)。

## 一、装之前先确认三件事

| 检查项 | 说明 |
| --- | --- |
| 系统版本 | 本篇对应的安装包记录标注需安卓 5.2 以上；官方商店里的新版对系统要求可能更高，以安装时的系统提示为准 |
| 存储空间 | 安装包约 54 MB，装好后加上缓存与离线章节，建议再留出 500 MB 以上余量 |
| 网络 | 安装本身不需要联网，但首次启动登录、选兴趣分类都要网络 |

安装包的核对信息（与网盘里那份一致）：版本 11.23.2、包名 `wp.wattpad`、大小 53.97M、MD5 `7C3F02A2BDCBDB8758189699D452FCF3`。

## 二、从哪拿安装包

两条途径，选一条即可：

1. **官方应用商店**：在 Google Play 搜「Wattpad」，认准开发者 Wattpad.com，点安装。
2. **网盘转存**：如果手机装不了 Google Play（国行 ROM 常见），可以用 [Wattpad 安装文件资源（夸克网盘）](https://pan.quark.cn/s/afd38193ef01)，转存到自己的网盘后下载 APK 到手机再安装。

两条途径拿到的都是安卓安装包，区别只在获取方式；离线安装的场景（没有 Google 服务框架的手机）只能走第二条。

## 三、安装步骤（APK 方式）

1. 把 APK 从网盘下载到手机的「下载」目录。
2. 在文件管理器里点开这个 APK。第一次装会弹「禁止安装未知来源应用」，按你手机的路径去放行：
   - 原生类系统：设置 → 应用 → 特殊应用权限 → 安装未知应用 → 给文件管理器授权；
   - 国产 ROM（MIUI / ColorOS / HarmonyOS 等）：一般点开 APK 时会直接弹窗引导你去对应开关，按提示走即可，不同版本路径略有差异。
3. 回到文件管理器再点 APK，点「安装」，等进度走完。
4. 点「打开」，直接进入首次启动流程。

安装报错（解析包错误、安装中断）多半是下载不完整或存储不足，重新下载一遍 APK、清出空间后再试；仍然失败的话，把具体报错对着[常见问题排查.md](常见问题排查.md)查。

## 四、首次启动要做的事

1. 选择你是想「读」还是「写」（或两者都要），这决定首页给你推什么。
2. 勾选几个感兴趣的题材（言情、奇幻、悬疑、同人等），推荐流会按这个来。
3. 登录已有账号，或现场注册一个——不登录没法收藏与评论，注册步骤见[注册登录与账号设置.md](注册登录与账号设置.md)。
4. 进首页后先搜一两本想看的书，点进详情页点「添加到 Library（书库）」，之后从底部 Library 标签进。怎么把书缓存下来断网读，见[阅读功能与离线缓存.md](阅读功能与离线缓存.md)。

## 五、以后怎么更新

- 从官方商店装的：在商店里更新即可，商店版本号会比本篇的 11.23.2 新。
- 从网盘 APK 装的：想换新版就重新拿一份新 APK 覆盖安装，书架与账号绑定在账号上，覆盖安装不丢数据；卸载重装前先确认自己记得登录方式。
