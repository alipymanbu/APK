Wattpad 的内容按「故事 → 章节」组织，免费内容直接读，付费章节另算（见[会员付费与金币解锁.md](会员付费与金币解锁.md)）。本篇只讲读这一侧：找书、调阅读器、缓存到本地。

## 一、找书与加入书库

- **搜索**：顶部放大镜，按书名或作者搜，支持关键词模糊匹配。
- **浏览**：首页按你注册时选的兴趣类型推内容；也可以按标签（tag）翻，标签是这里主要的分类方式。推荐流受内容分级开关影响，不想看到成人向内容先去调设置，见[内容分级与屏蔽设置.md](内容分级与屏蔽设置.md)。
- **加入书库（Library）**：书详情页点「Add to Library」。之后底部 Library 标签就是你的书架，追更、续读都在这里。

想整理的话，在书库里建阅读清单（Reading List），把书按自己的标准分组，比如「追更中」「看完的」。

## 二、段落评论与投票

Wattpad 最有辨识度的交互是**按段落评论**：

1. 阅读时长按某一段文字，会弹出这一段的评论列表。
2. 你可以看别人对这一段的想法，也可以直接发自己的。
3. 想支持作者就点星星（vote），每章都能点一次。

作者看得到每段的评论数，所以评论是和作者互动最直接的渠道；很多连载作者会按评论反馈调整后面的剧情走向。

## 三、阅读器设置

阅读时点屏幕中央唤出菜单，点设置图标可以调：

| 项目 | 可调内容 |
| --- | --- |
| 字体 | 衬线体 / 无衬线体切换，字号多档 |
| 排版 | 行距、页边距 |
| 主题 | 白底、米黄、暗色、纯黑（OLED 屏夜间省电友好）等几档 |
| 亮度 | 阅读器内独立亮度 |

设置是全局记忆的，调一次对所有书生效。

## 四、离线缓存（断网也能读）

**前提：书必须先加入 Library。** 缓存有两条路径：

- **路径 A（书架批量）**：底部 Library 标签 → 找到那本书 → 点书封面下方的下载图标，整本已发布章节开始缓存。
- **路径 B（单本）**：打开那本书 → 右上角三点菜单 → 选「Download / 下载」，效果一样。

缓存进度会在封面上显示；完成后哪怕开飞行模式，从 Library 点进去照常读。建议在 Wi-Fi 环境下缓存，省流量也快。

**三条限制要记住**：

1. 缓存的是**当时的章节**，作者后来更新（或修改）的部分不会自动出现在离线内容里，重新连网后再点一次下载即可刷新。
2. 付费章节即便整本缓存，也以解锁状态为准，没解锁的章节离线状态依然读不了。
3. 清理 App 数据或缓存会**把已缓存的章节一起清掉**，清理前想清楚；系统存储管理里的「清除缓存」对这类应用内离线内容同样有影响。

换手机时离线缓存不会跟过去（跟账号走的是书架和进度，不是本地缓存），新手机上重新点一遍下载即可。

读完想动笔的，写作侧的流程在[写作与发布流程.md](写作与发布流程.md)；阅读中遇到「缓存失败」「章节打不开」之类的问题，[常见问题排查.md](常见问题排查.md)里有对应条目。
