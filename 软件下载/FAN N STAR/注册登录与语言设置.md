# FAN N STAR 注册登录与语言设置

> FAN N STAR 不提供独立的账号密码注册，全部靠海外社交账号一键联动登录，界面默认韩语但可以切英文和日文。本篇讲怎么注册、怎么切换语言、怎么给联动账号配上专属 ID 和密码，以及登录卡住的常见处理。

## 一、注册前准备：挑一个你能长期用的 SNS 账号

FAN N STAR 的账号体系是「SNS 联动」——登录某个社交账号即完成注册，不用单独设密码。可选的登录方式包括：

| 登录方式 | 说明 |
| --- | --- |
| Twitter / X | 海外粉丝社区教程普遍推荐，稳定 |
| Google | 手机能正常访问 Google 服务时方便 |
| Facebook | 可用 |
| Kakao | 韩国本土账号；有粉丝教程反映它时灵时不灵，不作为首选 |
| LINE | 可用 |
| 微博 | 国内用户可用 |
| Apple | 仅 App 内提供，网页版没有 |

挑选原则很简单：选一个你手机上已经登录着、且不打算注销的。账号丢了，投票攒的星星和等级就都找不回来。另外，网页版（官方的 en / jp / cn 分站）与 App 是同一套账号，用哪个登录方式注册的，两边都能登。

## 二、注册步骤

打开 App 后按这个流程走一遍：

1. 点屏幕上方的星形图标，进入登录页。
2. 在上面表格里选一个 SNS 方式，跳转到对应平台授权。
3. 勾选同意服务条款。
4. 设置用户名（昵称）：输入后点 check 按钮确认没被占用，被占用就换一个。
5. 选择你的本命偶像（关注哪位艺人）。这一步选的是 App 给你定制的关注对象，以后首页内容、投票推荐都围绕它。
6. 确认注册，回到 App。

一个来自海外粉丝教程的提示：注册走完后如果某些功能仍提示未登录，去「个人资料」页再点一次登录即可，这是联动登录偶发的不同步。

## 三、切换界面语言

默认是韩语，看不懂不用硬猜：

1. 进入首页（Home）。
2. 点左上角的三横线菜单。
3. 点地球图标，进入语言列表。
4. 选择你要的语言。应用内至少提供韩语、英语、日语选项，有没有加入中文界面以你手机上弹出的语言列表为准；官方另外维护了一个中文网页版（`cn.fannstar.tf.co.kr`），看不懂韩英日的读者可以拿网页版对照着认功能位置。

切到英语后，界面词条如 Vote（投票）、Daily Stars（每日任务）、Star（星星）就都对得上本套文档其他篇目里的叫法了。

## 四、给联动账号配上专属 ID 和密码

靠 SNS 登录有个隐患：哪天那个社交账号失效或换机失败，就进不去了。官方 FAQ 给了解法——联动账号也能设一套独立的简易 ID 和密码：

1. 进入「我的信息修改」（我的资料 / My Info）。
2. 设置简易 ID 与密码。

设置后即使 SNS 授权出问题，也可以用这套 ID 密码直接登录。建议注册完就顺手做这一步。

## 五、登录不上的几种情况

- **授权页打不开或转圈**：取决于你选的 SNS 平台在你网络环境下能否访问，和 FAN N STAR 本身无关。卡在 Kakao 或 Facebook 就换 Twitter / X 或 Google 试试。
- **提示「网页或应用存在安全隐患」**：有用户反馈长期使用的账号突然弹这个提示、重装也没用。属于官方风控误伤的情况，走 App 内的 1:1 询问提交申诉，别急着注销重建——旧账号的星星与等级不一定能迁移。
- **App 内登录状态频繁掉**：先把语言设置里的推送授权打开再重新登录一次；仍不行就按上一条走申诉。
