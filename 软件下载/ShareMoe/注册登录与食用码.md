## 一、注册入口在哪

1. 打开 ShareMoe，点右下角「我的」。
2. 在登录页点「没有账户?」（部分版本写作「暂无账号」）进入注册页。
3. 按页面提示填写用户名、邮箱、密码等信息（不同版本字段略有差异，以实际页面为准）。

## 二、食用码是什么、怎么获取

食用码是注册 / 启用账号需要的凭证码，多份用户资料都把「注册需要食用码」列为第一道门槛。获取途径以注册页的实际提示为准，目前能确认的有两条：

- 注册页点「获取食用码」，按提示跳转到合作商店购买；
- 官方活动、社群或公告偶有发放（官方口径：没有固定统一的获取渠道）。

两点提醒：

- 网上流传的所谓「16 位通用邀请码」无法验证有效性，多数早已失效，别把注册流程赌在上面；
- 平台明确不存在「万能验证码」，所有验证码都是系统动态生成、单次有效。

## 三、收不到验证码怎么办

按常见程度逐项排查：

| 现象 / 原因 | 处理 |
| --- | --- |
| 手机号或邮箱填错 | 检查拼写、是否多空格 |
| 手机欠费、信号差 | 换网络环境或充值后重试 |
| 验证码短信被系统或拦截软件屏蔽 | 到骚扰拦截记录里找 |
| 刚办携号转网，运营商数据未同步 | 等一段时间再试 |
| 短时间内获取次数过多，或服务端临时故障 | 隔一会儿再点获取 |

反复失败时，先确认账号信息本身没有输错，再考虑服务端问题。

## 四、账号异常怎么办

官方反馈论坛设有「账户异常集中反馈处」专帖（截至成文仍在持续更新回复），登录被拒、账号被标记异常这类问题，集中去那个帖子里反馈最有效。论坛入口见 [常见问题与使用注意.md](常见问题与使用注意.md) 的信息渠道汇总。
