## 一、装之前先知道的几件事

- ShareMoe 是安卓应用，安装包是一个 `.apk` 文件，约 15.71M，应用本体免费、部分功能内购。
- 各渠道标注的最低安卓版本并不一致（4.3、5.2 都出现过），近几年的安卓手机基本都能装；老机型以安装时的系统提示为准。
- 国内应用商店一般搜不到它，常见获取方式就是 apk 安装包——所以装完最好按第四节核对一遍。

## 二、安装包从哪来

两个途径，按需选择：

1. **本页顶部的夸克网盘链接**（固定为 3.0.2 版）：点开 [ShareMoe 安装文件资源（夸克网盘）](https://pan.quark.cn/s/dfcce81ae7c7) → 转存到自己网盘 → 下载 apk 文件。这份包的信息：版本 3.0.2、包名 `app.net.sharemoe`、约 15.71M。
2. **官方发布渠道**：官方反馈论坛的公告帖会发新版本的安卓安装包（截至成文，公告已到 4.1.0，通过多家网盘链接分发）。具体入口见 [常见问题与使用注意.md](常见问题与使用注意.md) 的信息渠道汇总，各版本更新内容与旧版本注意事项见 [版本更新与iOS版.md](版本更新与iOS版.md)。

第三方下载站的安装包版本混杂、可能被重新打包，建议只从能核对包名与版本号的渠道获取。

## 三、安装步骤

1. 点开下载好的 apk 文件；系统若提示「禁止安装未知来源应用」，按提示去设置里允许对应来源（浏览器或文件管理器）安装应用——各品牌路径略有差异，通常在「设置 → 安全 / 更多安全设置 → 安装未知应用」。
2. 回到安装页点「安装」，等待完成。
3. 打开应用，按提示同意用户协议（若有）。

## 四、核对装到的是哪个版本

装完后建议核对一遍，避免装到被改过的包：

| 核对项 | 应为 |
| --- | --- |
| 包名 | `app.net.sharemoe` |
| 版本号 | 3.0.2（本篇对应的安装包） |
| 安装包大小 | 约 15.71M |
| 安装包 MD5 | `84164805DBA19BAA9CDC2C94E0C5FA35` |

- 包名与版本号：系统「设置 → 应用管理 → ShareMoe」里看；应用内一般在「我的 / 关于」也能看到版本号。
- MD5：对 apk 文件本身用校验工具比对，字母大小写不影响结果。
- 应用商店里另有名为「ShareMoe官方」的应用（包名 `com.qt6`、体积只有 3.5M 左右），并不是本应用；无论从哪个渠道装，都以包名 `app.net.sharemoe` 为准。
