## 一、找图的几种方式

| 方式 | 怎么用 | 适合场景 |
| --- | --- | --- |
| 关键词搜索 | 底部导航进「搜索」，输入作品名、角色名或标签 | 目标明确，知道要找什么 |
| 标签 / 分类筛选 | 顺着分类与标签往下点 | 只想按画风、题材闲逛 |
| 画师维度 | 按画师 ID 或名字检索 | 想看某位画师的更多作品 |
| 榜单 / 热门 | 看日榜、周榜、月榜（入口以当前版本为准） | 追当下最热门的作品 |
| 个性化推荐 | 首页「猜你喜欢」一类入口 | 根据浏览与收藏记录发现新图 |

界面为全中文，支持用中文关键词搜索；搜索结果按标签、热度等维度综合排序。

4.1.0 版起新增了「专题画作」入口（pixiv 专题、danbooru 专题），旧版本没有这两个入口；版本详情见 [版本更新与iOS版.md](版本更新与iOS版.md)。

## 二、浏览与预览

- 列表是瀑布流排布，点缩略图进入作品页看大图与详情。
- 多页作品与长图加载较慢，网络不好时先等缩略图出完再点进去，能少开空页面。

## 三、保存与批量下载

- **单张**：作品页里找保存 / 下载入口，选原图保存。新版对下载交互做过调整（有老用户反馈「点图片直接下载」的旧操作变了），找不到入口时先升级到最新版再找。
- **批量**：多选作品后批量下载原图，适合整画集式的收集。
- 保存结果到系统相册或文件管理的图片目录里找（不同系统路径不同）。

还没装应用的话，从 [ShareMoe 安装文件资源（夸克网盘）](https://pan.quark.cn/s/dfcce81ae7c7) 拿安装包，步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 四、设为壁纸

1. 在系统相册打开保存好的图 → 「更多 / 设为壁纸」。
2. 全面屏机型按提示裁剪适配；横竖比例差太多的图裁完构图会变，挑接近屏幕比例的竖图更省事。
3. 应用内的壁纸类目可以直接按竖图找，省一步裁剪。

## 五、画质与流量

- 下载的是原图级别的文件，单张可达数 MB；批量下载前留意流量套餐与剩余空间。
- 有第三方整理的介绍提到应用内置本地超分放大（约 2 倍），入口与实际效果以你手上的版本为准。
