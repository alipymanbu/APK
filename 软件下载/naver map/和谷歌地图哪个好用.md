## 一、先回答最常搜的：韩国为什么用不了谷歌地图

谷歌地图在韩国**能打开、能搜地点，但给不出完整的步行、驾车、公交导航**。原因不是网络也不是账号：韩国限制高精度地理数据出境，谷歌的地图数据处理在境外服务器，拿不到本地应用用的那套细粒度路网数据（多篇 2026 年的独立攻略交叉印证）。

- **2026 年 2 月**，韩国政府对谷歌的数据出口给了**有条件批准**，但截至 2026 年年中，谷歌地图在韩国**仍未上线完整的逐步导航**（以当时实际功能为准）；
- 实际表现：步行路线只到街区边缘、公交线路缺或不准、实时公交缺失、小巷子绕不过去。

所以去韩国的结论很稳定：**导航用本地应用，谷歌地图留着查英文评价与收藏**。

## 二、三个应用怎么分工

| 场景 | 更合适的选择 |
| --- | --- |
| 公交换乘、地铁出口号、实时到站 | NAVER Map |
| 找餐厅、看评价（英/中/日文界面） | NAVER Map |
| 驾车导航、通行费预估、车道级引导 | NAVER Map |
| 离线地图下载 | KakaoMap（多篇测评把它列为 KakaoMap 的强项） |
| 打车（接 Kakao T） | KakaoMap |
| 英文界面、评价与收藏习惯 | 谷歌地图 |

两份 2026 年的攻略给的建议一致：**两个本地应用都装、不冲突，都是免费的**；只挑一个的话，多数行程 NAVER Map 够用，KakaoMap 当备胎互相印证结果。

## 三、NAVER Map 相对的具体优势

多篇独立测评交叉印证的口径：

- **公交信息细**：实时公交倒计时到分钟、地铁标到**具体出口编号**，换乘还能提示坐到第几节车厢下车最方便出站；
- **搜索吃得下多语言**：英文、韩文、罗马拼音都能搜（如输入 `Gangnam Station` 直接命中），中文搜法见 [中文界面设置方法.md](中文界面设置方法.md)；
- **驾车更靠谱**：多条候选路线带实时路况、预计到达时间与**通行费预估**，复杂立交有车道级提示（细节见 [驾车导航与实时路况.md](驾车导航与实时路况.md)）；
- **资料层厚**：商家照片、菜单、评价由 NAVER 的评价体系支撑，出门前查店特别顺手。

## 四、用本地应用也要知道的两件事

- **交通卡照样要带**：应用只给你车费预估与路线，**上车刷卡付费仍然要用 T-money 这类交通卡或支持的支付方式**，导航应用本身不代扣车费；
- **流量是刚需**：路线与实时到站都在线拉取，落地前按 [下载与安装教程.md](下载与安装教程.md) 装好、配好权限，韩国当地再补一张能上网的 SIM/eSIM，没网时地图会明显变慢。

## 五、出发前的最省事顺序

1. 在家有 Wi-Fi 时先把应用装好、切成中文（[下载与安装教程.md](下载与安装教程.md) → [中文界面设置方法.md](中文界面设置方法.md)）；
2. 把第一个目的地搜一遍，让应用缓存基础数据；
3. 落地开流量后先查一条公交路线试跑（[公交换乘与地铁查询教程.md](公交换乘与地铁查询教程.md)），有问题按 [闪退打不开怎么解决.md](闪退打不开怎么解决.md) 排查。
