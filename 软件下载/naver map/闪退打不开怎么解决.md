## 一、先分清你是哪种「打不开」

不同症状起点不同，别一上来就重装：

| 症状 | 先看哪节 |
| --- | --- |
| 点图标白屏一下就退回桌面 | 第二节的 1~4 步 |
| 地图能开，但一直转圈、图片不加载 | 第三节（网络问题） |
| 安装时就装不上 | 第四节（安装问题） |
| 能开但定位漂、导不了航 | 那是权限问题，去 [定位不准怎么办.md](定位不准怎么办.md) |
| 卡在登录页、反复退回 | 去 [NAVER账号注册与登录.md](NAVER账号注册与登录.md) 第五节 |

## 二、官方排查顺序（从轻到重）

NAVER 帮助中心给的移动端错误通用处理顺序，照做即可：

1. **彻底关掉再开**：从后台把应用划掉，重新打开 —— 临时加载问题一半死在这一步；
2. **清缓存**：设置 → 应用 → NAVER Map → 存储 → **清除缓存**（清缓存不会丢你的 NAVER 登录状态，但外部站点的登录信息会被清掉）；
3. **校对日期与时间**：设置 → 通用 → 日期和时间 → 打开「自动设置」；已经开着的，取消再勾一次，然后重启手机；
4. **升级 / 重装**：前三步没用就升级到最新版；还不行按「**卸载 → 重启手机 → 再装**」的顺序重装（安卓官方口径明确要求中间重启一次）。

两个官方明确点名的坑：

- **Root / 越狱设备**可能无法正常服务 —— 手机改过系统的话，先在一台正常设备上验证是不是这个原因；
- **私有 DNS 设了 `dns.adguard`** 一类拦截地址会触发网络错误，改回「自动」再试。

## 三、网络类：能开但加载不出来

1. **换个网**：同一 Wi-Fi 下出的问题，切到 4G/5G，或换一个 Wi-Fi 验证（官方给的第 5 步就是这个）；
2. **看是不是普遍故障**：换个时间点再开，几分钟后恢复就是服务端的事，不用动手机；
3. **查存储空间**：剩余空间太少时应用会边跑边出错，清出几百 MB 再试（安装 APK 时同样吃空间，见下一节）。

## 四、安装阶段就失败的常见原因

- **存储不够**：这份安装包 149.28M，解压安装还要额外空间，建议先留出 1GB 左右的余量；
- **未知来源权限没开**：按 [下载与安装教程.md](下载与安装教程.md) 第四节重新走一遍；
- **下到一半的残包**：文件不完整必然装不上，重新下载后先核对大小（149.28M）与 MD5（`2c0d352a79a68829da2cfc74d5e24436`）再安装。

## 五、都试完还不行

带上「问题描述 + 出问题那一步的截图」走官方客服的**问题反馈入口**（帮助中心页底部的「咨询/문의」按钮）。描述里写清三件事：手机型号与系统版本、应用版本号、从哪一步开始出错 —— 缺了这些信息，来回补充会多花一倍时间。
