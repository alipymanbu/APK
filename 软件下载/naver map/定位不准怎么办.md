# NAVER Map 定位不准怎么办

## 一、先按这个顺序查（官方排查口径）

定位不准九成出在设置上，按下面顺序走一遍：

1. **系统位置开关**：设置 → 位置 → 确认是「使用中」状态；
2. **定位增强**：设置 → 位置 → 精确度提升 → 把 **Wi-Fi 查找、蓝牙查找**打开 —— 室内与楼群里 GPS 信号弱，靠这两项辅助定位；
3. **应用权限**：设置 → 应用 → NAVER Map → 权限 → 位置 → 选「**始终允许**」或「**使用应用时允许**」；
4. **精确位置**：同一个权限页把「**精确位置**」（정확한 위치）开关打开。官方明确写了：不开精确位置，接收的位置误差**最大可能差出数公里**。

四步都对还偏，再看下面两节。

## 二、常见场景与对应处理

| 现象 | 多半是哪种情况 | 处理 |
| --- | --- | --- |
| 蓝点在室内不动或跳 | GPS 信号被楼挡住 | 走到窗边、门口刷新；确认 Wi-Fi 查找已开 |
| 位置整体偏几百米 | 用了 Wi-Fi 定位、数据库未更新 | 切到移动数据（4G/5G）看是否恢复 |
| 导航中途漂到高架/隧道旁 | 定位源切换、误差放大 | 开精确位置；开车时用磁吸支架靠近挡风玻璃 |
| 刚开机就定位慢 | 缓存的 Wi-Fi 位置信息还没建立 | 等几十秒，或开关一次位置再开 |

官方还提示了一点：Android 的 Wi-Fi 定位依赖 Google 侧的 Wi-Fi 位置数据更新，在该数据刷新前，Wi-Fi 定位可能给出错误位置 —— 同一环境下 Google 地图也偏的话，就是这个原因，改用移动数据网络下的定位更可靠（会走流量）。

## 三、权限路径速查

不确定自己的系统在哪一级菜单，按这个最短路径找：

```text
设置 → 应用 → NAVER Map → 权限 → 位置 → 始终允许 / 使用应用时允许
                                      └ → 精确位置：开
```

改完权限后把应用完全退掉重开一次（后台划掉），再看蓝点是否归位。手机系统版本不同，菜单措辞略有差异，以自己手机上的为准。

## 四、还是不准时的两个旁证

- **拿另一个地图对照**：两个地图在同一位置都偏，是环境或手机的问题；只有一个偏，才是这个应用的数据问题；
- **换条路线验证**：查公交时若只有某一条路线的步行段不对，可以在路线详情页底部点「信息修改建议」把错误点报上去（入口说明见 [公交换乘与地铁查询教程.md](公交换乘与地铁查询教程.md) 第六节）。

开车场景对定位最敏感，权限配好之后再对照 [驾车导航与实时路况.md](驾车导航与实时路况.md) 检查一遍；还没装应用的先回 [下载与安装教程.md](下载与安装教程.md) 把首次权限给对。
