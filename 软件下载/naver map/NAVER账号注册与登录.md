## 一、先说结论：不登录也能用大半功能

查路线、看实时公交、驾车导航这些核心功能**不需要登录**，装好就能用。需要账号的是这几类：

- **收藏与清单同步**：保存的地点、自己建的清单要跨设备保留，得登录账号；
- **餐厅预约**：在应用里订位**必须注册并登录**，不登录点不到确认那一步；
- **家 / 公司快捷地址**：绑定后配合导航语音「回家」使用（见 [驾车导航与实时路况.md](驾车导航与实时路况.md) 第五节）。

## 二、注册流程

入口在应用内：搜索窗右侧 **MY 图标** → 登录页 → **注册 / 가입**，然后：

1. 阅读使用条款与隐私政策，点确认；
2. 按表单填写注册信息（邮箱、密码、生日性别等，以页面实际要求为准）；
3. 完成后回到 MY 页，点「我的资料」确认 ID 已生成；
4. 回到应用重新登录一次，收藏与预约功能即解锁。

注册页各版本长得不一样，但都在 MY → 登录这一层里；找不到就先把界面切成中文（路径见 [中文界面设置方法.md](中文界面设置方法.md)）。

## 三、用在预约时要填的资料

在 NAVER Map 里预约餐厅，个人信息页要求至少填这几项：

| 字段 | 填什么 |
| --- | --- |
| 姓名 | 建议用**护照上的拼音名**，到店核对方便 |
| 生日 / 性别 | 按实际情况填 |
| 联系电话 | 可以填**本国手机号**，不必是韩国号码 |

填完进到预约确认页，选日期、时间、人数提交；之后在 MY 页里查、改、取消预约。

## 四、外国用户：没有韩国手机号的验证

长期困扰外国用户的是「绑手机号」这一步。据第三方整理的官方旅游服务信息，**2026 年 6 月起 NAVER 面向护照签发地不在韩国的用户开放了护照验证**，凭外国护照即可完成身份验证、使用旅游相关的预约与支付功能；具体开放的服务范围以 [NAVER 官方页面](https://map.naver.com/) 当时显示为准，不能假定每个预约或支付界面都可用。

另有用户反馈：**非韩国 IP 登录时偶尔触发防诈骗限制，出现暂时登不上去的情况** —— 这是单一来源的说法，遇到时换个网络时段再试，不要反复输错密码把账号锁住。

## 五、登录异常速查

| 现象 | 建议动作 |
| --- | --- |
| 密码连错多次被锁 | 等冷却时间走完，或在网页端走「找回密码」 |
| 登录后收藏没了 | 确认登的是注册时那个 ID；换过账号会各存各的 |
| 注册收不到验证邮件 | 检查垃圾邮件箱；邮箱地址重填一遍再提交 |
| 一登录就闪退回地图 | 先清一次应用缓存，再看 [定位不准怎么办.md](定位不准怎么办.md) 的权限设置 |

账号与权限都正常后，就可以回到日常用法：查一条路线看 [公交换乘与地铁查询教程.md](公交换乘与地铁查询教程.md)；还没装应用先看 [下载与安装教程.md](下载与安装教程.md)。
