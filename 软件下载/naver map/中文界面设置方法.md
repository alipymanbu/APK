# NAVER Map 中文界面设置方法

> 界面默认是韩文，这篇讲怎么切到简体中文，以及用中文搜地点时的几个坑。

## 一、切到简体中文的官方路径

按官方帮助中心给的路径（安卓）：

1. 打开 NAVER Map，点搜索窗右侧的 **MY** 图标（头像 / 人形图标）；
2. 点右上角的**设置图标（齿轮）**；
3. 找到 **언어 / Language** 一项，点进去；
4. 从 **韩语 / 英语 / 简体中文 / 日语** 四种里选「简体中文」（界面文字为中文时显示为「简体中文」）；
5. 切换语言会自动重启应用，确认后重开就是中文界面。

两点注意：

- **没有繁体中文**，只有简体；
- 部分老教程写的是「左上角三条杠菜单 → 设置 → Language」，那是旧版界面的入口；新版以「MY → 齿轮 → 语言」为准，找不到时两个入口都点一遍即可。

## 二、版本门槛

- 语言设置功能**从 5.1.3 版本起提供**；
- 5.0 及以上版本只能装在 Android 8.0 及以上系统；
- 网盘里这份是 6.9.1.3，满足条件。装了更老的版本、设置里没有「语言」一项时，先升级版本（见 [下载与安装教程.md](下载与安装教程.md)）。

## 三、换成中文后，搜索还是搜不到？

界面是中文不等于中文什么都搜得到，搜地点时按这个优先级试：

1. **韩文名**最准：出发前把店家的韩文名复制好，粘进搜索框，基本不会失手；
2. **简体中文**可以用，但**繁体字搜不到** —— 同一个地点，用简体写才匹配得上；
3. **电话号码**是捷径：商家只要在 NAVER 登记过电话，直接搜号码就能定位到店，同样建议提前复制好；
4. 搜公交线路号、地铁站名用数字与站名即可，与界面语言无关（查询方法见 [公交换乘与地铁查询教程.md](公交换乘与地铁查询教程.md)）。

## 四、地图标注与评价的翻译

- 界面语言管的是**按钮与菜单**；地图上的韩文地名是否显示中文，随版本与地区不同，以你实际看到的界面为准；
- 商家详情页里有翻译入口（界面上是「查看翻译」一类按钮），可以把用户评价翻成你设置的语言；
- 导航语音提示的语言与界面语言是两回事，官方功能说明写的是「多语言地图 + 英语导航」，中文语音是否有、在哪开启，以当时版本的设置项为准，拿不准就到设置里逐项看。

## 五、改回韩文或英文

路径相同：MY → 齿轮 → 语言 → 选韩语或英语，应用同样会重启一次。把语言切回韩文后，本套文档里的界面名词请按位置对照理解，功能位置不变。
