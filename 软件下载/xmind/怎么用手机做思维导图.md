## 一、从新建到第一张图

装好后打开 App，新建导图时第一步就是选结构——结构决定了节点往哪个方向长，后面改动结构比新建时选对要费事，所以先想清楚这张图是干什么用的再选。选完进入画布，点中央主题开始输入，回车加子主题，用快捷按钮在选中节点旁加分支。手机上没有键盘快捷键，主要靠点选节点后弹出的操作条来加主题、改内容。

做歪了不用怕：长按节点可以拖动换位置，删掉一个分支重建也只是几秒钟的事。

## 二、结构怎么选

Xmind 移动版内置的结构不止思维导图一种，官方列过的有 10 多种，常用的这几类各管一件事：

| 结构 | 适合往里放什么 |
| --- | --- |
| 思维导图 | 默认选择，发散类的想法整理 |
| 逻辑图（向右组织图） | 有先后或从属关系的步骤、流程 |
| 鱼骨图 | 找原因，一个问题拆成几条成因 |
| 时间轴 | 按时间排的事件、计划、里程碑 |
| 组织结构图 | 层级分明的汇报关系、分类体系 |
| 矩阵图 | 两个维度交叉的对照（比如人 × 任务） |
| 树形图 / 树型表格 | 内容多到导图画不下、需要收敛排布时 |

同一张图里不同分支可以用不同结构（官方叫多结构组合），比如总图用思维导图发散，其中一个项目分支单独切成时间轴。建图后点分支根节点就能改它的结构，不用推倒重来。

## 三、往主题里加东西

光有文字的导图很快会变成一坨线，下面这些内容按需往节点上加，都在选中节点后的操作条或「+」菜单里：

- **标记（Marker）**：优先级、进度、星标这类小图标，扫一眼就知道轻重缓急。
- **标签**：给节点归类，配合筛选能快速把某一类的节点挑出来。
- **笔记**：长段说明文字收进笔记里，画布上只留短标题，需要时点开看。
- **语音备注**：开会、上课时不想打字，直接录一段挂在节点上。这个功能在免费档是否开放要看 App 内实际显示（见 [免费版和Pro区别.md](免费版和Pro区别.md)）。
- **超链接 / 主题链接**：跳网页，或跳到本图内的另一个节点，做索引时很有用。
- **图片和贴纸**：从相册插图片，或用内置贴纸；部分贴纸属于订阅内容。
- **附件**：把文件挂到节点上，导图变成一个带材料的目录。

## 四、大纲视图：内容多的时候换一种干活方式

画布上的节点一多，手机屏幕里拖起来很累。点大纲视图切换，导图就变成一份缩进列表：加内容、调层级、上下移动都在列表里完成，比在画布上点小圆点快得多。整理完再切回画布看全貌——这两个视图是同一份数据的两种看法，来回切不影响内容。

实际用起来有个顺手的节奏：想法乱的时候先用大纲快速把条目录进去，条理出来了再切画布调结构和视觉。

## 五、两件小事顺手设置掉

- **深色界面**：设置里切深色主题，画布和界面一起变暗，晚上用不那么刺眼。
- **搜索替换**：图大了以后找某个关键词，用搜索定位节点，比肉眼找快。
