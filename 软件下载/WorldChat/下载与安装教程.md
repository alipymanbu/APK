WorldChat 是盐城屯房基科技有限公司出的跨国聊天应用：用手机号注册之后，你可以跟不同国家的用户文字、语音或视频聊天，收发消息时会做语言互译。它只发手机端安装包，本篇只做一件事——把网盘里这份包完整装进手机并正常打开。

## 一、先确认网盘里这份包是哪一版

应用商店页面显示的是官方当时的最新版，跟网盘里这份往往不是同一个版本号。本篇出现的版本号、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | WorldChat |
| 版本号 | 1.2.0 |
| 包名 | `com.zerophil.worldchat` |
| 安装包体积 | 180.70 MB |
| MD5 | `e4633b2875efa18a758ddf7f25334b23` |
| 适用平台 | Android（手机端 APK） |
| 开发者 | 盐城屯房基科技有限公司 |

装之前先弄清四件事：

- **认包名，别只认图标和名字。** 应用商店里搜「WorldChat」会连带出现若干近名条目（例如名字很像的 WorldTalks），装错了账号和聊天对象都对不上。这份包的包名是 `com.zerophil.worldchat`，装好后进「设置 → 应用 → 应用管理」点开 WorldChat 就能看到。
- **版本号是三段式，迭代不算慢。** 官方按 `x.y.z` 递进，近期依次出现过 1.1.6、1.1.9、1.2.0、1.2.1、1.2.3（以各应用商店当页显示为准）；网盘里这份是 1.2.0，不是商店页上那一版。想装最新版就到官方商店页取，想跟本文记的事实对上就用网盘这份。
- **系统要求没有统一口径。** 各应用商店对不同版本标注过 Android 6.0 以上、7.0 以上、8.0 以上等不同要求，能不能装以安装时系统的提示为准；系统太旧会直接报「应用未安装」。
- **没有电脑版。** 官方只发手机端 APK，想在电脑上用只能走安卓模拟器；iOS 设备装不了这份包。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [WorldChat 安装文件资源（夸克网盘）](https://pan.quark.cn/s/87b1925024ae)，在手机夸克 App 里打开最省事。
2. **先转存再下载**：选中安装包，转存到自己的网盘目录，再下载到本机。分享链接以后可能失效，转存过的那份不受影响。
3. **核对体积**：下载完成后看一眼文件体积，应当约 180.70 MB。中途断网重连后体积偏小，安装时会直接报「解析包错误」。
4. **想校验完整性**：在电脑上把包算一遍 MD5，结果应与上表一致（大小写不敏感）。

```cmd
certutil -hashfile WorldChat_v1.2.0.apk MD5
```

文件名随版本变化，以实际提供的那个为准。

## 三、安装步骤

1. **给文件管理器开「安装未知应用」权限**：进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把用来打开 APK 的那个应用（文件管理器或浏览器）的开关打开。国产定制系统这一项常收在「安全」或「隐私」分类里。
2. **点击 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续，这是侧载安装包的常规提示。
3. **手机上已有更高版本时先卸载**：安卓不允许用低版本覆盖高版本，会直接报「应用未安装」。卸载会一并清掉本机数据，动手前确认聊天内容是否还需要。
4. **报「签名不一致」说明包名撞了**：手机里已经装过同包名的另一个来源版本，处理办法见本篇第五节的表。
5. **留出安装空间**：180 MB 多的包在安装时系统还要再展开一份，建议预留 500 MB 以上可用空间。

## 四、第一次打开要确认的三件事

1. **能联网**：WorldChat 不能离线聊天，收发消息、看动态都要联网才动得了。打开后卡在加载页，先用浏览器确认手机能正常上网。
2. **能登录进去**：第一次进入会先弹隐私政策与用户协议，同意后按提示用手机号注册登录（官方隐私政策生效日期为 2025 年 8 月 27 日）。收不到验证码的处理见 [注册登录与账号安全.md](注册登录与账号安全.md)。
3. **放行通知权限**：不放开通知权限，别人发来的消息不会有提醒。权限怎么补，见 [权限与隐私怎么设置.md](权限与隐私怎么设置.md)。

## 五、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整 | 核对体积与 MD5，按第二节的步骤重新取一份 |
| 提示「应用未安装：签名不一致」 | 手机里已有同包名、不同来源的版本 | 先在应用管理里卸载旧包，再装这份 |
| 提示「应用未安装」且没有别的原因 | 系统版本低于该版本的要求 | 换一个系统要求更低的版本再装 |
| 安装被安全中心拦下 | 侧载包被系统安全策略拦了 | 在安全中心的拦截记录里选「继续安装」 |
| 点安装没反应 | 「安装未知应用」权限没给 | 回到第三节第 1 步补上权限 |
| 装完打开就闪退 | 系统版本过低、存储不足或包残缺 | 见 [常见问题与排查.md](常见问题与排查.md) |

以后换版本或者重装，按第二节的步骤重新取一份即可，安装动作与这次相同。
