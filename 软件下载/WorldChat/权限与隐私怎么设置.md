装完 WorldChat 会向你申请一批权限，哪些必须给、哪些可以拒、拒了会少掉哪个功能，官方文档里其实逐条写了。本篇先把官方列出的权限一条条对照给你看，再讲个性化推荐、剪贴板与第三方推送这几处该在哪关。三份依据是官方 [WorldChat 隐私政策](http://www.tunfangji.com/worldchat/privite.html)、[应用权限申请与使用情况说明](http://www.tunfangji.com/worldchat/agreement/appPermissions.html) 与 [第三方信息共享清单](http://www.tunfangji.com/worldchat/agreement/informationSharing.html)。

## 一、官方列出的十个权限，一条条对着看

下表用途一列照抄官方权限说明，最后一列是不给这项权限时的实际后果：

| 权限 | 官方写的用途 | 不给会怎样 |
| --- | --- | --- |
| 位置 | 发布动态时带上大致位置 | 动态不带位置信息，其他功能照用 |
| 存储 | 读取相册、拍照或录像文件保存 | 不能从相册选图、不能保存自己拍的内容 |
| 电话 | 读取设备码，用于聊天消息推送定位设备，并保证登录设备唯一 | 消息推送的定位与设备唯一校验受影响 |
| 读取听觉媒体 | 聊天过程中的语音文件录制与传输 | 语音消息与通话受影响 |
| 摄像头 | 拍照、录像 | 不能视频通话，也不能拍照发图 |
| 系统设置 | App 内部分功能的悬浮窗提示 | 悬浮窗提示类功能受影响 |
| 麦克风 | 录像时录音、发送语音消息 | 不能发语音，也不能语音或视频通话 |
| 通知 | 及时向你推送系统通知 | 收不到消息与通话提醒 |
| 蓝牙 | 拨打语音、视频通话 | 用不了蓝牙耳机 |
| 读取视觉媒体 | 聊天时发送图片的访问 | 发不了图片 |

## 二、哪些可以拒

- 官方写明：**麦克风、相册（存储）、蓝牙均不会默认开启**，只有你明示授权后才会在对应功能里使用，你也随时可以撤回授权。
- 除了「为实现业务功能或根据法律法规要求所必需的必要信息」，其余都可以拒绝，且不影响其他功能——这是官方隐私政策开篇的原话。
- 唯一的例外是手机号。隐私政策写明手机号是网络实名制要求的必要信息，不提供就用不了聊天、交友功能，详见 [注册登录与账号安全.md](注册登录与账号安全.md) 第一节。

## 三、撤权限、改设置在哪里做

| 要改的东西 | 在哪儿改 |
| --- | --- |
| 单项权限 | 设置 → 应用 → 应用管理 → WorldChat → 权限 |
| 通知 | 同一路径下的「通知」，可以只关某一类提醒 |
| 个性化推荐 | 应用内「我的 → 设置 → 个性化推送」 |

## 四、个性化推荐与剪贴板

- **个性化推荐**：官方隐私政策写明，开关打开时会在授权范围内收集你使用产品时的输入信息（包括对话内容及搜索文本）与行为信息（包括点击、搜索、浏览、分享记录以及对生成内容的反馈），用于推荐相关性更高的内容。关掉路径是应用内「我的 → 设置 → 个性化推送」；关闭后不再展示个性化推荐内容，但仍可继续浏览与偏好无关的普遍性内容。
- **剪贴板**：官方写明，为了让内容跨应用分享更顺畅，会读取剪贴板内容（例如从别处复制来的链接、文本）。介意的话，复制完验证码、卡号这类敏感内容后，不要马上切到 WorldChat，用完随手清一次剪贴板。

## 五、第三方 SDK 会拿到什么

官方「第三方信息共享清单」把接入的合作方逐条列了出来，跟日常使用关系最紧的是两类：

| 类别 | 具体 SDK | 官方写的用途 | 触发时机 |
| --- | --- | --- | --- |
| 推送 | 华为推送、小米推送、OPUSH、魅族推送、vivo 推送 | 推送消息 | 在对应品牌手机上推送消息时 |
| 一键登录 | 极光一键登录 | 一键登录 | 你使用一键登录时 |

推送类 SDK 拿到的是设备标识符、设备硬件与系统信息、网络信息这几类；一键登录 SDK 还会涉及手机号与位置相关信息，只在你走一键登录这条路径时触发。官方同时注明：合作方代码可能因其版本升级、策略调整导致数据处理类型变化，以其公示的官方说明为准。

## 六、数据存哪、留多久

- **存储地点**：官方写明，境内运营过程中收集和产生的个人信息存储于中华人民共和国境内，目前不向境外传输。
- **留存期限**：手机号在注册登录期间持续保留；你输入的信息、反馈信息、点赞点踩等，在未撤回、删除或未注销账号期间保留；注销账号或超出必要期限后删除或匿名化处理，法律法规要求留存的信息除外。

## 七、注销账号

注销属于不可逆操作。官方隐私政策写明，注销后个人信息会被删除或匿名化处理（法规要求留存的除外），动手前先确认没有还要保留的聊天内容。

## 八、未成年人

官方隐私政策单独列了「未成年人条款」一节。如果你的孩子会用这台设备，建议先到官方隐私政策页把这一节自己读一遍，再决定要不要给 ta 装。

## 九、投诉与举报

官方隐私政策写明会保存你与客服之间的沟通记录；涉及投诉他人时，可能把账号信息、联系方式与投诉内容提供给消费者权益保护部门及监管机关。个人信息相关的投诉与疑问，可以发到官方隐私政策「联系我们」一节留的邮箱 `tfj@tunfangji.com`。
