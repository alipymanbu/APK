这篇只收「按一个顺序查就能有结论」的问题：装不上、登不进、收不到提醒、通话连不上、图片发不出去。需要展开讲的，这里指到对应文件，不重复。

## 一、装与开

| 现象 | 先动哪一步 |
| --- | --- |
| 提示「解析包错误」 | 重新取一份包，核对体积 180.70 MB 与 MD5，步骤见 [下载与安装教程.md](下载与安装教程.md) 第二节 |
| 提示「签名不一致」 | 手机里已有同包名的另一来源版本，先卸载旧的再装 |
| 点安装没反应 | 补上「安装未知应用」权限 |
| 打开就闪退 | 先清出 500 MB 以上可用空间并重启手机；仍闪退就换一份包重装；还是不行的联系官方客服 |
| 安装后图标找不到 | 部分定制系统的桌面会折叠新装应用，进「设置 → 应用 → 应用管理」里能找到入口 |

## 二、登录

| 现象 | 先动哪一步 |
| --- | --- |
| 验证码收不到 | 按 [注册登录与账号安全.md](注册登录与账号安全.md) 第三节的五步顺序查 |
| 换手机后登不上 | 在「设置 → 应用 → 应用管理」里确认装的是本包（`com.zerophil.worldchat`），再重新登录一次 |
| 提示登录设备异常 | 官方写明登录设备唯一，同一账号不在两台手机上同时在线；另一台上退出后重试，仍不行找客服 |
| 换了手机号 | 换号前先在应用内把绑定关系改掉，别直接弃用旧号，原因见 [注册登录与账号安全.md](注册登录与账号安全.md) 第四节 |

## 三、怎么找到人聊起来

官方公开材料里没有逐步的「加好友」操作说明，能确认的只有推荐逻辑这一条：隐私政策写明，推荐会参考「你关注的动态内容或不同国籍的动态发布者」。落到实际使用上：

1. **从应用内的推荐或按国籍的分类进入对方资料页**，这是最短的路径；具体入口与按钮名称以你手机上实际显示的为准。
2. **先看资料页的三项再决定聊不聊**：国籍、语言、最近的动态。三样都空、或者彼此对不上，就多留个心眼，判据见 [陌生人交友怎么防骗与保护隐私.md](陌生人交友怎么防骗与保护隐私.md) 第二节。
3. **「关注」和「黑名单」是两个方向的开关**：关注是把对方和他的动态收进你自己的信息流；黑名单是让对方联系不到你。两个入口都在应用内，位置以实际显示为准。

## 四、消息与通知

| 现象 | 先动哪一步 |
| --- | --- |
| 收不到消息提醒 | 打开通知权限，并把 WorldChat 设为「允许后台运行」、允许自启动 |
| 消息延迟、提示连接中断 | 换一条网络（Wi-Fi 与流量互切）再试；应用商店评论区里有用户反映过这类现象，多与网络有关 |
| 图片发不出去 | 补上「存储」「读取视觉媒体」两项权限 |
| 对方收不到我发的消息 | 先确认是不是把对方加进了黑名单；确实拉黑过就先移出来再发 |
| 消息里的译文空着 | 见 [消息翻译怎么用与不准怎么办.md](消息翻译怎么用与不准怎么办.md) 第二节 |

## 五、语音与视频通话

| 现象 | 先动哪一步 |
| --- | --- |
| 点通话没反应 | 补上麦克风、摄像头权限，然后重启应用 |
| 有来电但错过 | 允许后台运行与自启动，否则锁屏后收不到邀请 |
| 接起来没声音 | 先把蓝牙关掉，用手机听筒试一次 |
| 画面卡、声音断续 | 换网络，并停掉后台占带宽的下载任务 |

完整排查顺序见 [语音视频通话怎么打通.md](语音视频通话怎么打通.md) 第三节。

## 六、权限与隐私

| 现象 | 先动哪一步 |
| --- | --- |
| 不知道某个权限是干什么的 | 见 [权限与隐私怎么设置.md](权限与隐私怎么设置.md) 第一节的权限对照表 |
| 想关掉个性化推荐 | 应用内「我的 → 设置 → 个性化推送」 |
| 想撤回某项权限 | 设置 → 应用 → 应用管理 → WorldChat → 权限 |
| 不想让剪贴板内容被读 | 复制验证码、卡号后别马上切进 WorldChat，用完清一次剪贴板 |

## 七、遇到骚扰或疑似骗子

| 现象 | 先动哪一步 |
| --- | --- |
| 不想再收到某人的消息 | 用黑名单把他拉黑（应用商店评论区有用户提到 WorldChat 有黑名单功能，入口以应用内实际显示为准） |
| 对方开口要钱、要你下载别的 App | 一律不转、不装；六个典型信号与判断依据见 [陌生人交友怎么防骗与保护隐私.md](陌生人交友怎么防骗与保护隐私.md) 第二节 |
| 照片被对方拿去乱传 | 先截图留存证据，再在应用内投诉该账号，情节严重的直接报警 |
| 已经被骗了 | 保留聊天与转账记录、对方账号信息，尽快拨打 110 或到就近派出所报案 |
