## 一、排查前的三个前提

按官方 wiki 的说法，连接类问题**九成出在防火墙**，其余多数是网络配置。动手前先确认三件事，能省掉大部分弯路：

1. 手机与电脑在**同一个 WiFi**（路由器分 2.4G/5G 两个名字时，两边必须连同一个名字，不确定就把两个都试一遍）；
2. 手机**移动数据已关**（开着会让应用报错误的 IP）；
3. 两端应用都升到当前版本（版本差太多可能静默连不上）。

## 二、症状一：搜不到服务器 / 一直「连接中」

按命中率从高到低逐项试：

| # | 检查项 | 怎么做 |
| --- | --- | --- |
| 1 | 防火墙拦截（最常见） | 暂时关闭 Windows Defender 防火墙与安全软件测试；能连上就重新开启，并把 `VTube Studio.exe` 加入防火墙例外。**PC 版更新后例外可能失效，需要重新加** |
| 2 | Windows 网络配置文件 | Windows 设置里把当前网络设为「专用网络」，「公用网络」会拦设备互访 |
| 3 | 路由器隔离（AP 隔离） | 部分路由器/访客网络/酒店网络禁止设备互访，换常规家用网络测试；路由器隐私设置也可能拦，进路由器后台确认 |
| 4 | VPN | 关掉 VPN 再试，VPN 常把设备藏起来互相不可见 |
| 5 | 杀毒软件 | 暂时退出杀软测试 |
| 6 | 服务器列表为 0 / IP 不对 | 重启两端应用；电脑上 `Win+R` 输入 `cmd` 回车，再输 `ipconfig`，把列出的 IPv4 地址手动填进手机端的连接设置里试 |
| 7 | 网络扩展设备 | Mesh 路由器、无线扩展器、Nest 之类设备可能造成隔离，直连主路由测试 |

手机完全找不到电脑时，可以先用手机上的「网络扫描工具」类应用确认两台设备在局域网内是否互相可见——不可见就是网络本身的问题，跟 VTube Studio 无关，先修网络。

## 三、症状二：连上了但卡顿 / 延迟大

官方给的延迟参考：WiFi 下延迟不应超过约 10 毫秒，电脑走网线时可低于 1 毫秒。超出明显就按下面排查：

- **换 5GHz WiFi**：2.4GHz 频段拥挤且干扰多，是手机端卡顿的头号原因，路由器有 5GHz 就连它；
- **电脑改网线**：电脑用网线接路由器、手机连同一个路由器的 5GHz WiFi，比双 WiFi 稳得多；
- **重启路由器**：听起来敷衍但经常有效；
- **换 WiFi 信道**：邻居路由器同信道会互相干扰，路由器后台改信道；
- **手机离路由器近一点**：隔一两堵墙后 5GHz 衰减很快。

安卓版没有 USB 直连（只有 iOS 有），以上 WiFi 优化就是安卓端的全部手段；追求极致稳定可以在手机上用 USB-C 转 网口的转接器走有线（属于通用网络方案，不是应用功能）。

## 四、症状三：播着播着掉线

| 原因 | 特征 | 处理 |
| --- | --- | --- |
| 免费版时长限制 | 每次连接固定时长后断开，重连又恢复 | 不是故障，是版本限制，见 [免费版与PRO版区别.md](免费版与PRO版区别.md) |
| 电脑 IP 变了 | 重启路由器/电脑后连不上 | 电脑改为路由器后台绑定静态 IP，或重新手动填 IP |
| 手机省电策略 | 熄屏/切后台后断 | 给 VTube Studio 关电池优化、允许后台运行，直播时保持充电 |
| 手机过热降频 | 长时间直播后越来越卡 | 开 Streaming Mode、摘手机壳（见 [手机端追踪设置.md](手机端追踪设置.md)） |
| 版本不匹配 | 更新了一端之后开始掉线 | 两端一起更新 |

## 五、还是不行

以上都试过仍连不上，多半是网络环境本身有特殊配置（公司网络、校园网、运营商定制光猫）。可以先在手机热点上做对照测试：电脑连手机热点、两端互连——热点下能连上就说明家里路由器配置有问题，问题范围立刻缩小。官方社区支持走 Discord（`https://discord.gg/vtubestudio`），提问前把上面做过的测试列出来，能少走一轮来回。
