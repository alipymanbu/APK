## 一、手机版的产出方式就是录屏

安卓版没有直播功能（直播要靠 PC 版，见 [连接手机到电脑.md](连接手机到电脑.md)），在手机上产出视频只有一条路：**把屏幕上的模型画面录下来**。官方文档提到手机版内置了录屏功能——录屏幕画面并连同麦克风声音一起录，录制时画面角落有红点提示，点红点随时停。你手上的版本如果没找到这个内置选项，直接用系统自带的屏幕录制功能代替，产物等价。

## 二、录之前过一遍这五项

| 检查项 | 要点 |
| --- | --- |
| 模型已加载并动起来 | 先对着镜头说话确认追踪正常，别开录了才发现模型僵着 |
| 机位与光线 | 录出来的僵硬动作救不回来，先按 [手机端追踪设置.md](手机端追踪设置.md) 与 [提升追踪效果的方法.md](提升追踪效果的方法.md) 调好 |
| 手机状态 | 电量充足（可边充边录，但注意发热）、存储空间够、亮度调到你想要的观感 |
| 免打扰 | 开启勿扰模式，微信、短信的横幅会永久录进视频里 |
| 竖屏还是横屏 | 屏幕方向就是成片方向，竖屏素材就竖着录 |

## 三、免费版水印与商用口径

- 录屏录的是手机屏幕，所以**免费版的水印会一起录进视频**。介意就去掉水印——买 PRO 的第一个理由就是它（口径见 [免费版与PRO版区别.md](免费版与PRO版区别.md)）；
- 录屏本身**不受「连电脑推流时长限制」影响**——那条限制只管往 PC 推数据，纯本机录屏与它无关；
- 按官方许可协议，用这套软件创作出的音视频内容归你，可以私下保存也可以公开发布（含商用）；但商用本身要求你持有至少一份付费版（PRO 或 DLC），免费版录的素材拿去接商单不在许可范围内。

## 四、想要更高的成片质量

手机录屏有两个先天短板：模型 UI 会被一起录进去（除非应用内隐藏了界面元素），且成片没有透明背景、只能整屏使用。要求高一点的做法是改走电脑路线：手机只当追踪摄像头，模型在电脑上渲染，OBS 里以透明背景录制或直播——这是多数 VTuber 的标准工作流，连接方法见 [连接手机到电脑.md](连接手机到电脑.md)。

手机录屏适合的场景：竖屏短视频素材、快速试模型效果、不想开电脑的随手录。两类产出不冲突，按当天的内容形态选。
