# VTube Studio Live2D 模型导入方法

> 本篇讲 Live2D 模型从哪里来、一个能用的模型文件夹里该有什么、怎么导入 PC 版再发到手机，以及加载失败时的排查顺序。

## 一、先对齐格式：它只认 Live2D

VTube Studio 只支持 **Live2D Cubism** 格式的 2D 模型，VRM（VRoid Studio 导出的 3D 模型）等 3D 格式一律不能加载。拿到模型的常见途径：

- **应用内置示例模型**：装完就有，多数来自 Live2D Inc.，直接用于商业直播前先确认其许可条款；
- **现成模型**：Booth 等平台有大量标明「Live2D 模型 / VTube Studio 对应」的成品模型，购买时认准文件里含 `model3.json` 与 `moc3`；
- **委托制作**：画师出立绘、建模师（rigger）用 Live2D Cubism 编辑器绑定为可动模型，交付的就是一套模型文件夹。

分发渠道给你的多为 zip 包，先完整解压，得到一个模型文件夹再操作。

## 二、模型文件夹里应该有什么

一个能被 VTube Studio 正常加载的模型文件夹，通常包含以下文件（文件名前缀随模型名变化）：

| 文件 | 作用 | 必需性 |
| --- | --- | --- |
| `xxx.model3.json` | 模型索引文件，VTube Studio 靠它识别整套模型 | 必需 |
| `xxx.moc3` | 模型本体（顶点、变形器、参数全在这里） | 必需 |
| 纹理图片 | 模型的贴图（可能多张） | 必需 |
| `xxx.physics3.json` | 物理演算（头发、衣物摆动） | 建议有，缺了模型就没有物理效果 |
| `xxx.cdi3.json` | 参数显示信息 | 可选，VTS 不依赖 |
| 模型图标 png/jpg | 显示在模型列表里 | 可选但建议放一张 512x512 的 |

导出侧的关键点（委托制作时可以直接把这条发给建模师）：Cubism 编辑器导出时选 **SDK 版本（3.0 / 3.3 / 4.0）** 并**勾选导出物理演算文件**——物理文件必须在导出时写进 `model3.json`，事后补放不生效。加载失败时第一件事就是核对上面这张表，少一个必需文件整套模型就起不来。

## 三、导入 PC 版（手机端模型的前置步骤）

安卓版没有直接从手机文件系统导入模型的入口，自己或买来的模型要先在 PC 版里导入，再推到手机。所以哪怕你只用手机，PC 版这一步也绕不开。

1. 打开 PC 版 VTube Studio（Steam 版），双击主界面调出菜单，点**模型图标**打开模型列表；
2. 点 **Import your own model**，弹窗里点 **open folder**，会直接打开模型的存放目录；
3. Steam 版这个目录默认是安装目录下的 `VTube Studio_Data\StreamingAssets\Live2DModels`（手找的话就在 `...\steamapps\common\VTube Studio\` 里面）；
4. 把**整个模型文件夹**放进 `Live2DModels`——注意是连文件夹一起放，不是把里面的文件散着拷进去；
5. 回到应用重开模型列表，新模型应该出现；没立刻出现就把列表关掉重开一两次（列表不会自动刷新）。

首次加载新模型时会弹出 **Auto-Setup（自动设置）** 询问：它按 Live2D 默认参数 ID 自动把面部追踪输入映射到模型参数。用标准参数做的模型直接点确定即可；以后想重跑，在设置的模型页里可以再次触发。

## 四、把模型发到手机

手机与电脑连上之后（连接步骤见 [连接手机到电脑.md](连接手机到电脑.md)）：

1. PC 版打开模型设置（人形图标）；
2. 选**发送模型到设备**，把当前模型推给手机；
3. 手机端打开模型菜单，加载刚收到的那一个，手机屏幕上就会显示同一个模型。

模型参数、相机设置在两端共享：PC 上跑过 Auto-Setup、调过的数值，手机端直接生效，不用重复配置。模型复杂、纹理很大时，手机端加载会明显比 PC 慢，极端情况下可能卡顿甚至闪退——纹理过大的模型优先在 PC 上用。

## 五、加载失败的排查顺序

| 现象 | 先查什么 |
| --- | --- |
| 列表里根本没出现 | 文件夹是否放对位置；是「整个文件夹」还是散文件；列表刷新（关掉重开） |
| 点了没反应/报错 | `model3.json` 与 `moc3` 是否都在；zip 是否完整解压 |
| 模型加载了但头发衣物不动 | 物理文件没导出或没注册进 `model3.json`，要回 Cubism 重新导出 |
| 手机能用但很卡 | 纹理过大，回 Cubism 降纹理分辨率重新导出 |
| 追踪不动模型 | 不是导入问题，是参数映射问题，先跑 Auto-Setup，再看 [手机端追踪设置.md](手机端追踪设置.md) 的灵敏度部分 |

导入环节本身与网络无关；如果模型在 PC 上正常、发到手机后追踪断断续续，那是连接问题，去 [连接问题与卡顿解决.md](连接问题与卡顿解决.md)。装好应用还没走过一遍基础设置的话，从 [手机端追踪设置.md](手机端追踪设置.md) 开始。
