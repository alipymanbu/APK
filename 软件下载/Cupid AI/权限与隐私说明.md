## 一、它需要哪些权限

权限查询平台 Exodus 对 Google Play 上该应用某个版本（1.1.1）做过静态分析，列出 **20 项权限**。与你日常使用关系最大的几项：

| 权限 | 用途推测 |
| --- | --- |
| `INTERNET` / `ACCESS_NETWORK_STATE` / `ACCESS_WIFI_STATE` | 联网聊天（回复由服务端生成，不联网用不了） |
| `POST_NOTIFICATIONS` | 推送通知（可在系统设置里关掉） |
| `USE_BIOMETRIC` / `USE_FINGERPRINT` | 生物识别，通常用于应用锁或验证 |
| `BILLING` / `CHECK_LICENSE` | 应用内购买与授权校验 |
| `RECEIVE_BOOT_COMPLETED` / `WAKE_LOCK` / `FOREGROUND_SERVICE` | 开机自启与后台运行 |
| `AD_ID` 等 AdServices 相关 | 广告标识与归因（配合内置广告组件） |

注意：这份报告针对的是商店上的 1.1.1 版本；网盘这份 1.0.7 的实际权限清单，以你安装时系统弹出的提示为准。

## 二、内置的广告与分析组件

同一份 Exodus 报告显示，该版本的安装包里带有 **13 个追踪类组件**的代码特征，包括 Google AdMob、AppLovin、Facebook、InMobi、ironSource、Mintegral、Pangle、Unity Ads、Firebase Analytics、Crashlytics 等。这类组件常见于带广告变现的免费应用 —— 意味着你在使用中可能遇到广告，且部分使用数据会被统计分析。

## 三、对你意味着什么

结合上面两条，几个实用建议：

1. **聊天内容会经过网络与服务端**，别在对话里提交身份证号、银行卡、住址、密码这类敏感信息；
2. **通知权限**不需要就在系统设置里关掉，不影响聊天；
3. **计费权限**说明应用内有付费点，遇到充值引导先看清价格与周期再决定；
4. 给不该给的权限（如通讯录、位置）如果被申请，直接拒绝 —— 上表之外的新权限请求，安装时留意一下。

## 四、聊天记录与账号

游客模式下的记录通常只留在本机；登录后记录能否跨设备同步，以应用内实际表现为准（详见 [注册登录与游客体验.md](注册登录与游客体验.md)）。由于回复由服务端生成、且应用带分析组件，稳妥的理解是：**聊天内容未必只存在你手机上**。想清理时，可在应用内删除对话；卸载前想清楚哪些记录还要。

Exodus 报告原文见 [reports.exodus-privacy.eu.org](https://reports.exodus-privacy.eu.org/en/reports/719147/)（英文）。安装或使用中遇到其他问题，见 [常见问题与解决办法.md](常见问题与解决办法.md)。
