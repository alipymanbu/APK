## 一、装之前先确认两件事

AstroBox 是 AstralSight 团队开发的开源穿戴设备工具箱（GitHub 仓库 `AstralSightStudios/AstroBox-NG`，AGPL v3 协议），主要用途是给小米 / Redmi 手环手表安装第三方表盘与快应用、查看设备状态，也支持 vivo 部分手表。动手下载前先确认：

1. **你的手环 / 手表型号是否受支持**。支持清单随版本变化（截至 2026-09：小米手环 9 / 9 Pro / 10 系列、小米 Watch S3 / S4 / S5、REDMI Watch 5 / 6 等受支持；小米手环 8 系列及更早机型已不支持），完整清单见[连接手环设备方法.md](连接手环设备方法.md)。
2. **装在哪个平台**。安卓手机只是其中一种，AstroBox 同时提供 Windows、macOS、Linux、iOS 版本，本文以安卓 APK 为主线。

## 三、从哪下载

- **夸克网盘**：本文开头的 [AstroBox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8a01ff89f9df) 就是上面 1.1.0 这版，转存后下载里面的 `AstroBox_v1.1.0.apk` 即可。
- **GitHub Releases**：官方在 [github.com/AstralSightStudios/AstroBox-NG/releases](https://github.com/AstralSightStudios/AstroBox-NG/releases) 发布 Windows / Linux / Android 包，想跟最新版本走就走这里。

- **官网入口**：[astrobox.online](https://astrobox.online/) 首页有各平台下载入口。

## 四、安卓安装步骤

1. 从上面任一渠道拿到 APK 后，在手机上点开。系统首次会提示「不允许安装未知来源应用」，按提示允许「来自此来源的应用」后继续安装。装完找不到 APK 时，去文件管理器的 `Download`（下载）文件夹找，浏览器下载的通常在其子文件夹里（用夸克下载就在 `Download/QuarkDownloads`）。
2. 首次打开要配权限，米坛知识库特别提醒必须完整给到，否则连接设备会出问题：
   - **位置权限**：要选「精确位置」——这是安卓蓝牙连接的要求，应用本身不采集位置；
   - **蓝牙权限**：设为始终允许；
   - **附近设备权限**：建议手动再查一遍，长按桌面 AstroBox 图标进应用详情 → 权限管理 → 打开「附近设备」。
3. 登录小米 / vivo 账号的页面由 WebView 打开。安卓版有两种包：**带 WebView** 与**不内置 WebView**。设备较老或遇到闪退时，米坛知识库建议优先选带 WebView 的版本；登录闪退的完整处理见[常见问题与排查.md](常见问题与排查.md)。

## 五、V1 与 V2 是两代应用

AstroBox 有两代：早期的 V1（Legacy）与用 Rust 重构后的 V2（NG）。网盘里这份 1.1.0 属于 V1 时代的包，官方现在主推 V2，两代的功能与插件生态并不完全互通（部分 V2 专属能力 V1 用不了）。米坛知识库明确提示：**安装 V2 前先卸载 V1**，否则会带来一些问题——先用这份 V1 上手、之后想转 V2 的话，记得先卸载再装。

## 六、系统要求（截至 2026-09，以官方页面为准）

| 平台 | 要求 |
|---|---|
| Android | 官方当前版本标注 10 及以上；网盘这份 1.1.0 的采集记录标注 Android 5.2 以上可用，老系统以实机表现为准 |
| Windows | Windows 10 20H2 及以上；电脑需自带蓝牙才能连手环 |
| macOS | macOS Sonoma（14）及以上；下载时区分 Apple 芯片（ARM）与 Intel 芯片（x86）两种包 |
| iOS / iPadOS | 16.5 及以上；米坛知识库建议 26.5 以上，低版本很多功能跑不动 |
| Linux | Debian / RedHat 系发行版 |
| 浏览器版 | Chromium 119 及以上（部分功能） |

## 七、装完之后先做什么

第一次打开 AstroBox 时里面还没有任何设备，先把手环 / 手表连上才能装表盘。连接步骤见[连接手环设备方法.md](连接手环设备方法.md)；连好之后装资源的流程见[表盘与快应用安装指南.md](表盘与快应用安装指南.md)。
