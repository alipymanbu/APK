## 一、先说分工

两个都是 Google 家的（Waze 2013 年被收购），底层地图数据同源，但分工从根上就不一样：谷歌地图是「全场景地图工具」，驾车只是它管的一小块，还管公交、步行、骑行、查店与离线地图；Waze 是「只管开车」的工具，所有设计都围绕「这一趟怎么最快到」，路况信息靠司机实时上报，堵车绕路比谁反应都快。

## 二、一张表看差异

| 维度 | Waze | 谷歌地图 |
| --- | --- | --- |
| 定位 | 只做驾车导航 | 驾车/公交/步行/骑行全做 |
| 路况信息 | 司机实时报点：事故、施工、测速摄像头、路障等 | 也有报点功能，种类和密度不及 Waze |
| 绕路策略 | 激进，发现更快的路立刻改 | 稳健，倾向维持原路线 |
| 离线地图 | 不支持，必须有网 | 支持提前下载离线区域 |
| 查店与评分 | 弱 | 强，评论、营业时间、街景齐全 |
| 公共交通 | 无 | 有，且带实时班次信息 |
| 语音 | 多语言多口音、名人语音、可自录 | 常规官方语音 |
| 车机投屏 | Android Auto / CarPlay 都支持 | 同样支持 |
| 界面 | 信息少、图标大，驾驶时一眼能看清 | 信息密度高，功能入口多 |
| 广告 | 导航界面有少量赞助位 | 广告形态更多 |
| 费用 | 免费 | 免费 |

## 三、什么时候用哪个

- **每天固定通勤、最怕堵**：Waze 的实时报点和激进绕路就是为这个场景设计的，别人刚报的事故能让你提前两公里变道；
- **去陌生城市、要查店做攻略**：谷歌地图的地点数据、评论、街景、离线地图更靠得住；
- **流量紧张或出境漫游**：只有谷歌地图能提前下离线包，Waze 没网基本没法用；
- **两个都用**：常见的做法是查店和做攻略用谷歌地图，上车发动后切 Waze 导航，两者各干各的活。

## 四、几个容易误解的点

- **数据同源，路况不同**：底层地图都是 Google 的，但实时报点来自各自的社区；2024 年起谷歌地图也在吸收双方社区的报点（部分报点能看到来自哪个应用），不过覆盖与时效仍不对称，别指望在谷歌地图里看到 Waze 上的全部临时封路。
- **广告能减不能免**：Waze 免费靠导航界面里的少量赞助位，在设置的隐私项里关掉「个性化广告」后，广告还会出现，只是不再针对你投放。
- **计分与等级是装饰**：Waze 有报点积分和等级（新用户从「baby Wazer」起步），纯社区趣味设定，不影响导航质量，可以无视。
