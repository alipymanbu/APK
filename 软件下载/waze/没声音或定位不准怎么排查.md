# Waze 没声音或定位不准怎么排查

> 两类最高频的故障按表排查：语音不播报先查三档声音模式与三层音量，定位飘先查权限与省电策略，都给具体入口。

## 一、语音不播报：按这三层查

第一层是 Waze 自己的声音模式（设置 → 语音和声音）：**全部声音 / 只报提醒 / 静音**三档。「只报提醒」不念转向、只报测速与事故这类警报；彻底没声多半是被切到了「静音」。选中的语音包也可能没下载完整，换一个官方语音包试试，能念就是原包的问题。

第二层是手机媒体音量：导航正在播报时按音量键，调的才是对的通道；提前或事后按，调的可能是铃声通道。

第三层是车载音量：连蓝牙或车机时，车机里的导航音量是独立一路，要单独调高。连接相关的问题（蓝牙出声、CarPlay 黑屏、投屏断开）按[车机怎么连接.md](车机怎么连接.md)第五节的顺序过。

三层都对还不出声：重启应用 → 重启手机 → 重装（重装前先登录账号保住收藏地点）。

## 二、定位不准或提示 GPS 信号弱

| 现象 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| 一直「GPS 信号弱」 | 位置权限 | 系统设置里把 Waze 的位置权限给到「使用期间允许」或「始终允许」；只给「每次询问」会反复掉定位 |
| 行驶中定位断续 | 省电策略 | 把 Waze 移出电池优化与省电限制，允许后台运行；省电模式常会直接限制 GPS |
| 完全不动 | 飞行模式 / GPS 卡死 | 确认飞行模式关着；重启手机刷新一次 GPS |
| 地下停车场、隧道、高楼间飘 | 物理遮挡 | 出到开阔处通常半分钟内恢复；金属或磁吸手机壳也会挡信号，可摘掉试 |
| 位置长期偏移 | 缓存 | 安卓在系统设置「应用 → Waze → 存储」里清缓存；iPhone 卸载重装（先登录同步数据） |

顺手把系统日期时间改成「自动」也值得一查，时间错乱会影响定位解算。

## 三、耗电快、发热明显

耗电大头是屏幕常亮和持续定位，这两项省不掉，能省的是：

- 屏幕亮度调低或改自动；车上有充电线就常插着；
- 不导航时把应用从最近任务里划掉，别让它常驻后台；
- 明显发烫时先查手机壳散热与阳光直晒，再查是否还有其他应用同时在定位。

## 四、还是不行

先把 Waze 与手机系统都更新到最新版，很多怪问题在新版本里已修复；然后重装一次，重装前登录账号，收藏地点与设置跟着账号走，自定义语音需要重录。声音模式与报点开关的设置入口见[语音与报点设置怎么调.md](语音与报点设置怎么调.md)；安装包与版本核对见[下载与安装教程.md](下载与安装教程.md)。
