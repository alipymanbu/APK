# Waze 车机怎么连接

> 三种上车方案：Android Auto（安卓车机）、CarPlay（苹果车机）、只有蓝牙的老车，各自的接法与连不上时的排查顺序。

## 一、先判断你的车属于哪种

| 车上有什么 | 方案 | 效果 |
| --- | --- | --- |
| 支持 Android Auto 的车机 | 数据线（部分车型无线） | Waze 完整投到车机屏，可触屏操作 |
| 支持 CarPlay 的车机 | 数据线或无线 | 同上，iPhone 走这套 |
| 只有蓝牙，没有投屏 | 手机支架 + 蓝牙音频 | 地图在手机上，声音走车喇叭 |
| 车机自带 Android Automotive（无需手机） | 车机应用商店直接装 Waze | 独立运行，不依赖手机 |

Waze 是 Android Auto 与 CarPlay 都官方支持的应用，投屏后报点、绕路、语音播报照常，只是界面换成精简的车机版。注意两点：一是连车机后不能改设置、不能用社区聊天类功能，这是防分心的限制，不是故障；二是 CarPlay 上路线偏好只能在导航进行中改，想出发前设好「避开收费 / 渡轮 / 高速」，先在手机上设好再连车，具体见[避开收费站和高速怎么设.md](避开收费站和高速怎么设.md)第二节。

## 二、Android Auto（安卓手机）

1. 手机装好 Waze 并打开过一次；
2. 车停稳，用**数据线**把手机接上车的 USB 口（必须是数据线，纯充电线投不了屏）；
3. 车机上打开 Android Auto，在应用列表里点 Waze；首次会弹权限确认，允许后就能在车机屏上规划路线；
4. 无线 Android Auto 只在部分较新车型上支持，官方要求手机 Android 11 以上；不确定自己车支不支持，先用有线接一次最稳。

部分车型的设置入口叫法不同（可能在「连接设备」或「Android Auto」应用里），找不到就把车机说明书翻到投屏那一页对照。

## 三、CarPlay（iPhone）

1. iPhone 装好 Waze；
2. 用数据线连接，或按车型说明用无线 CarPlay；
3. 车机屏进入 CarPlay 主屏，点 Waze 图标；
4. 若列表里没有 Waze，去 iPhone 的「设置 → 通用 → CarPlay」里检查它是否被隐藏，勾上就会出现在车机屏。

## 四、老车只有蓝牙怎么办

地图留在手机上（架在支架上），语音提示通过蓝牙走车喇叭：

1. 手机与车机正常配对蓝牙；
2. 开始导航后，把车机音源切到蓝牙媒体音；
3. 声音太小或没声，按[语音与报点设置怎么调.md](语音与报点设置怎么调.md)第二节的三层音量顺序排查。

这套方案不能在车机屏上看地图，但报点提示、语音播报都正常，是老车最省事的用法。

## 五、连不上时按顺序排查

- **车机应用列表里没有 Waze**：先更新手机里的 Waze，再到 Android Auto 设置或 iPhone 的 CarPlay 设置里确认它没被隐藏；
- **投屏反复断开**：换一根确定能传数据的线（最常见的原因），或换车上另一个 USB 口；
- **车机屏有图、没声音**：车机里导航音量是独立一路，单独调高它；
- **行驶中不能输目的地**：车机上输地址通常要求车辆挂 P 挡，这是安全限制；出发前先设好路线再走；
- 都不行就把手机和车机各重启一次再试。

再往下的故障（黑屏、定位飘）多与系统版本有关：保持 Waze 与手机系统都是最新版；权限、缓存、重装这类通用排查见[没声音或定位不准怎么排查.md](没声音或定位不准怎么排查.md)，官方帮助页（[support.google.com/waze](https://support.google.com/waze)）可按条目查。安装包与版本核对见[下载与安装教程.md](下载与安装教程.md)。
