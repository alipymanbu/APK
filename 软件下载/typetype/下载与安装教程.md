## 一、这是什么软件，装之前先对一下条件

typetype 是一款安卓实用工具合集，把手持弹幕、屏幕录制、文件传送、屏幕方向控制这类平时要装好几个 app 才能干的事装进了一个包里，适合不想为单一小功能装一堆 app 的人。这一篇只讲「怎么拿到安装包、怎么装上、第一次打开要给哪些权限」；装好之后每个功能怎么用，看开头列的相关文档。

装之前先确认这几项，对不上就别装：

| 项目 | 值 |
| --- | --- |
| 系统要求 | Android 7.0 及以上（应用汇详情页标注） |
| 版本 | 1.8 |
| 安装包大小 | 40.29M |
| 包名 | `xiaofei.acter.fans` |
| 开发者 / 运营者 | 贵州花悦锌科技有限公司（应用宝详情页信息） |
| 应用类型 | 系统工具类 |

系统低于 Android 7.0 的手机装不上，先在「设置 → 关于手机」里确认系统版本。

## 二、从哪拿安装包

安装文件在夸克网盘：[typetype 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c741d611a07e)。打开链接 → 转存到自己的网盘 → 在网盘里找到 `typetype_v1.8.apk`（所在文件夹名是 `typetype（先保存再下载）`）→ 下载到手机。

下载完可以核对一下文件没损坏，MD5 应为：

```text
1dfe2d9d57803b92bca9cdc06dd79e04
```

用手机上任意一款文件校验工具查看 apk 的 MD5，跟上面这串逐字符一致就说明文件完整。不一致说明下载中断了，重新下一次。

## 三、安装步骤

1. 用手机浏览器打开上面的网盘链接，把 apk 下载到本机（或先转存再从网盘里下）。
2. 在「文件管理」里点开 `typetype_v1.8.apk`。
3. 系统会弹「禁止安装来自此来源的应用」—— 这是安卓对非应用商店安装的默认拦截。点提示里的「设置」，在应用列表里找到 typetype（或「安装未知应用」对应的入口），把开关打开，再退回继续安装。
4. 安装完成后点「打开」，或回桌面点图标。
5. 第一次进入会连续弹几个权限申请，见下一节，按需给。

不同品牌的开关名字略有差别：小米叫「安装未知应用」、华为/荣耀叫「外部来源应用下载」、OPPO/vivo 在「手机管家」里设，路径都是「设置 → 应用 → 特殊权限」那一层，逐级找即可。

## 四、第一次打开要给哪些权限

typetype 的几个核心功能都依赖系统权限，不给就用不了：

| 功能 | 要的权限 | 不给会怎样 |
| --- | --- | --- |
| 屏幕录制 | 屏幕录制 / 显示在其他应用上（悬浮窗） | 点「开始录屏」没反应，或录出来是黑屏 |
| 屏幕方向控制 | 悬浮窗 + 修改系统设置 | 方向面板弹不出来，选了方向也不生效 |
| 文件传送 | 存储 / 文件访问 | 扫码后读不到要传的文件 |

权限可以在第一次弹窗时点「允许」，也可以事后去「设置 → 应用 → typetype → 权限」里逐项补。具体每个权限的开关路径和不生效的排查，见 [常见问题与权限说明.md](常见问题与权限说明.md)。
