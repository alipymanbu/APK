## 一、这一篇解决什么

换新手机、把旧机照片倒过去、或者把同事发来的安装包转到自己手机 —— 这类短距离传文件，用 typetype 的「文件传送」就行：两部手机连同一个 Wi-Fi（或其中一部开热点），扫码配对，走局域网直传，不消耗流量。官方简介里把这套能力写成「手机传输：实现两部手机同步数据，方便你进行数据迁移」。

两部手机都得装 typetype，装法见 [下载与安装教程.md](下载与安装教程.md)。

## 二、先把权限给了

文件传送页要读取手机里的照片、视频、文档，第一次进入会申请文件访问权限：

1. 打开 typetype → 进「文件传送」；
2. 弹出「允许访问照片、媒体和文件」→ 点「允许」；
3. 拒绝过的话，去「设置 → 应用 → typetype → 权限 → 文件 / 存储」里手动打开。

权限不给，扫码连上了也读不出可传的文件列表（报错排查见 [常见问题与权限说明.md](常见问题与权限说明.md)）。

## 三、传文件的完整步骤

1. **两部手机连同一个 Wi-Fi**，或者让发送方开热点、接收方连上它 —— 局域网是传输通道，不在同一网络里扫不出设备。
2. 接收方打开 typetype → 「文件传送」，页面提示「点击下方扫描二维码即可接收传送的文件」，点下方的绿色**接收文件**按钮，屏幕出现一个二维码。
3. 发送方同样进「文件传送」，点**扫一扫 / 发送**，扫接收方的二维码，两台设备配对成功。
4. 发送方在文件列表里勾选要传的内容 → 点发送 → 接收方确认接收，进度条走完即完成。

传完的文件落在接收方的 typetype 接收记录里，同时也会写进系统相册 / 文件管理对应分类，两边都能找到。

## 四、能传哪些类型

文件传送页按类型分好了格子，每个格子上有文件数和占用空间：

| 分类 | 内容 |
| --- | --- |
| 图片 | 相册照片、截图 |
| 视频 | 录屏、拍摄视频 |
| 音频 | 录音、音乐文件 |
| 文档 | PDF、表格、压缩包等 |
| 应用 | 已安装 app 的安装包 |
| 联系人 | 通讯录条目 |

换机迁移时建议按分类全选一次传完，比一个个挑快；联系人那项别漏，旧机通讯录就靠它带过去。

## 五、传到电脑，以及几个使用边界

- **传电脑**：官方简介提到该应用「支持电脑传输功能」。用法与手机互传同理 —— 电脑与手机处于同一网络，在电脑浏览器里打开 typetype 给出的地址扫码连接。具体界面以 1.8 版实际显示为准，连不上就先确认防火墙没拦、且两者在同一个网段。
- **距离**：走的是局域网，隔着楼层用移动流量就传不了；出差在外让一方开热点即可。
- **流量**：同一 Wi-Fi 内互传不走蜂窝流量，这也是「零流量同步」的含义 —— 它省的是流量，不是距离。
- **速度**：取决于路由器，大文件建议 5GHz 频段或直连热点，比 2.4GHz 稳得多。

录好的视频想传出去，见 [屏幕录制怎么用.md](屏幕录制怎么用.md) 第四节。
