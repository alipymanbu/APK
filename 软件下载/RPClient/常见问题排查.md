## 一、发消息没有回复 / 请求失败

按命中率从高到低查：

1. **模型配置没建或没启用** —— 2026.3.1 起应用会对「模型未配置」给出提示与设置引导（旧版本以界面实际提示为准）。先确认 设置 → 模型配置 里有一条**已启用**的配置。
2. **测试连接不过** —— Key、服务地址、模型名三项逐一核对，详见 [模型配置方法.md](模型配置方法.md) 第三、四节。
3. **Key 失效或欠费** —— 去服务商后台确认额度；RPClient 不经手任何计费。
4. **摘要额度不足** —— 长期记忆的摘要生成也消耗 Token，额度不够时应用会提示（摘要失败时新版本不会用不完整结果覆盖有效摘要）。
5. **上下文超长被拒** —— 人设 + 世界书 + 历史消息合计超过模型支持的上下文上限，服务商直接拒收。收法：砍世界书常驻条目、调低 Token 预算、减少参与请求的历史消息条数（2026.3.1 起有「参与模型请求的历史消息数量」设置，默认最近 500 条，设 0 不限制；本地记录不会删）。详见 [世界书与提示词进阶.md](世界书与提示词进阶.md)。
6. **网络不通达** —— 手机网络能否直连该服务地址；自建服务的证书问题见 [模型配置方法.md](模型配置方法.md) 第四节。

**服务商返回的状态码可以先定位大方向**（各服务商通用语义，具体文案以服务商为准）：

| 状态码 | 指向 | 先查什么 |
| --- | --- | --- |
| 401 | 鉴权失败 | Key 是否复制完整、首尾有没有空格 |
| 403 | 拒绝访问 | Key 是否失效/被吊销、账号有无该模型权限、服务商是否限制地区 |
| 400 | 请求格式被拒 | 模型名拼写、地址路径（`/v1` 重复或缺失）、预设里有没有服务商不认的参数 |
| 429 | 请求太频繁 | 触发限流，等一会再试；群聊与长上下文请求更费额度 |
| 5xx | 服务商侧故障 | 先重试，再看服务商状态页；换模型/换路线测 |

**最小化测试法**贯穿始终：短提示 + 已知可用模型先跑通 —— 通了说明连接没问题，问题在卡、世界书或预设；只有某一个角色失败，也是查那个角色的上下文，不是查网络。

## 二、角色卡 / 世界书导不进来

| 症状 | 处理 |
| --- | --- |
| 报格式错误 | 确认是 JSON 或带元数据的 PNG，不是改后缀的文件 |
| 人设缺字段、行为怪 | 官方明确 RPClient 与 SillyTavern **在部分高级字段和运行行为上仍可能存在差异**，不是你操作错 |
| 导入后消息被改写 | 角色卡内嵌 Regex 脚本默认未获执行授权，检查是否有已放行的脚本在跑（见 [世界书与提示词进阶.md](世界书与提示词进阶.md)） |
| 批量导入中断 | 单文件失败不中断整批（2026.2.3 起），看汇总里的失败项单独处理 |

## 三、RPClient 和 SillyTavern 是什么关系

**RPClient 不是 SillyTavern 的安卓移植版** —— 这是官方 README 的原话口径。它参考了 SillyTavern 的角色卡、世界书、Prompt 与 Regex 生态并提供导入导出兼容，但部分高级字段与运行行为仍有差异。常见对比口径是：SillyTavern 面向 PC、功能更全但需要一定技术基础；RPClient 面向手机、装好配个 API 就能用 —— 你按自己的设备与折腾意愿选。角色卡可以在两边互导（以实际兼容情况为准）。

## 四、要花钱吗 / 数据存在哪

- **应用本身免费开源**（MIT 许可），不收订阅费、不设会员；调模型 API 的费用由你的服务商按其价格收取，与 RPClient 无关。
- **聊天记录、角色、世界书、应用配置默认存在本地**，不会被上传到第三方（但你的对话内容会随请求发送给你配置的模型服务商，服务商怎么处理看其隐私政策）。
- 想换手机或重装：先**导出**角色卡（V2 JSON / PNG）、世界书与聊天归档，再迁移。

## 五、升级后出问题

官方警告：项目仍在开发中，**数据结构、界面和兼容行为可能继续调整**。因此：

- 升级前没备份的，先别卸载 —— 数据还在本地，卸载才可能丢。
- 升级后角色/世界书读不出来，先用导出的原始文件重新导入；仍然失败，去 [github.com/KafuuNeko/RPClient](https://github.com/KafuuNeko/RPClient) 的 Issues 搜同款，报障时按官方要求附**脱敏后**的角色卡/世界书 JSON、Provider 协议、模型名与复现步骤 —— **不要公开 API Key、私密对话与未经授权的角色资源**。

## 六、界面不是中文 / 界面样式不对

- RPClient 支持 12 种界面语言（含简体中文、繁体中文、英语、日语等），在设置里切换，改完以应用提示为准（部分版本需重启生效）。
- 主题跟随系统 / 浅色 / 深色三档（2026.3.1 起），横屏布局与导航栏遮挡问题在后续版本有修复 —— 遇到显示异常先确认自己的版本，安装包版本对照见 [下载与安装教程.md](下载与安装教程.md)。

## 七、版本怎么核对

包名恒为 `me.kafuuneko.rpclient`；版本号规则为 `V年.大版本.小版本`（如官方 Releases 的 V2026.3.1），历史版本与更新说明在 [github.com/KafuuNeko/RPClient/releases](https://github.com/KafuuNeko/RPClient/releases) 可查。核对自己装的是哪版时，以应用内设置显示的版本为准，**具体最新版本号以官方页面当时显示为准**。
