## 一、RPClient 是什么

RPClient 是一款 Android 上的**本地优先 AI 角色扮演聊天客户端**：角色卡、世界书、聊天记录、应用设置默认都存在你手机本地，模型请求则直接发到你自己配置的服务商。它开源（MIT 许可），代码在 [github.com/KafuuNeko/RPClient](https://github.com/KafuuNeko/RPClient)。

几条先说清楚的边界：

- **它不提供模型服务**。装完不会自带能聊天的 AI，你得自己配一个模型 API（见 [模型配置方法.md](模型配置方法.md)）。
- **它参考了 SillyTavern 的角色卡、世界书、Prompt、Regex 生态**，能导入那一套格式，但官方明确说明它**不是 SillyTavern 的安卓移植版**，部分高级字段和运行行为仍有差异（详见 [常见问题排查.md](常见问题排查.md)）。
- 项目仍在积极开发中，数据结构与兼容行为可能调整 —— 官方建议**导入重要角色卡前保留原始文件、定期备份**。

## 三、系统要求

- **Android 8.0（API 26）及以上** —— 这是官方 README 写的口径。网上有页面写「安卓 5.2 以上」，与此冲突，以官方为准。
- **只有 Android 版**。仓库里有用户问过 Windows / macOS 版（截至 2026-09 官方仓库该讨论仍开着，没有发布计划），电脑上想用同款生态得自己权衡。
- 安装 APK 需要系统允许「安装未知来源应用」（各家手机入口不同，一般在 设置 → 应用 → 特殊权限 里）。
- **配模型和聊天都必须联网**（模型在云端，请求要发出去）；聊天记录、角色、世界书这些存在本地，查看它们不依赖网络。
- 体积不大（网盘这份 19.14M），**流量消耗取决于你的对话量与模型服务商**。

## 四、装完第一次怎么跑

照官方「快速开始」走四步就能进入状态：

1. 安装并打开 RPClient。
2. 进 **设置 → 模型配置**，选一个现成模板（ChatGPT、Gemini、Claude、DeepSeek、Grok、OpenRouter 都有）或新建配置。
3. 填 **API Key、模型名、服务地址**，点测试连接，通过后启用该配置。
4. 创建一个角色，或导入现成的 JSON/PNG 角色卡，然后新建会话开始聊。

第 2、3 步是新手最容易卡住的地方，参数怎么填见 [模型配置方法.md](模型配置方法.md)；角色怎么来见 [角色卡导入与创建.md](角色卡导入与创建.md)。装完先跑通一条链，再回头折腾世界书和提示词（[世界书与提示词进阶.md](世界书与提示词进阶.md)）。

## 五、升级前该做什么

官方在 README 里挂了明确警告：项目仍在开发中，**数据结构、界面和兼容行为可能继续调整**。所以：

- 升级前把重要的**角色卡、世界书、聊天记录**导出一份留在手里（角色卡可导出为 V2 JSON 或带元数据的 PNG）。
- 从旧版本跨大版本升级后如果出现角色或世界书读不出来，先别急着删数据，对照 [常见问题排查.md](常见问题排查.md) 里的排查顺序处理。
