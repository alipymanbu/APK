## 一、参会人常用操作

| 操作 | 在哪、怎么做 |
| --- | --- |
| 静音 / 取消静音 | 会中工具栏点麦克风图标；轮不到你发言时先静音 |
| 开关摄像头 | 工具栏摄像头图标；网络不稳时关视频能缓解卡顿 |
| 屏幕共享 | 工具栏「共享屏幕」，选单个窗口或整个桌面；共享时其他人可以批注，批注内容能保存 |
| 白板 | 共享时选白板，提供笔、文字、图形工具，适合边讲边画 |
| 聊天与表情 | 侧边聊天面板发消息、发表情 |
| 美颜与滤镜 | 视频设置里开启 |
| 虚拟背景 | 视频设置里替换背景，环境不想出镜时用 |
| 同声传译 | 主持人指派译员后，参会人自行切换语种声道收听 |

## 二、主持人能做什么

主持人的控制项都围绕维持会议秩序：

- 一键全员静音，也可单独关闭某个人的视频；
- 锁定会议，开启后新参会人进不来；
- 把违规的参会人移出会议；
- 开启等待室，参会人先在门外等主持人放行；
- 逐项控权：谁能共享屏幕、谁能聊天、谁能录制；
- 给共享屏幕加水印，降低会议内容被截图外传的风险。

安全机制方面，官方口径是会议信息传输采用 SSL 与 AES-256 加密，配合密码、锁定会议、等待室等功能防止信息泄露。

## 三、一直「连接中」或提示网络错误

这是入会环节最高频的问题。按官方手册给的判断方法：

1. 先用浏览器打开 `voovmeeting.com`，看能不能访问——打不开说明是你本机或所在网络的问题，不是应用的问题；
2. 网络通但应用还在转圈，切换一下网络（Wi-Fi 换流量，或反过来）再试；
3. 仍然进不去，找主持人核对会议号和密码是否给全、会议是否已被锁定。

## 四、字幕与翻译

会中支持同声传译：主持人指派译员、分配语种声道，参会人在会中自行切换声道收听对应语言的翻译。字幕与转写的多语言翻译能力官方在持续更新，具体支持哪些语言以你客户端里实际显示的为准。

## 五、版本差异导致的对不上

网盘资源里这份安装包是 1.16.4 版（版本信息见 [下载与安装教程.md](下载与安装教程.md)）。官方最新版可能已经调整了界面入口或新增了功能，如果你按本篇的描述找不到某个按钮，先在应用内更新到最新版再对照，或直接以应用内实际界面为准。
