## 一、官方排障三问（先过这三关）

官方文档把「效果不好」归结为三个最常见的原因，按顺序自查：

1. **同步的时间偏移准不准？**——数据时间轴和画面差几毫秒，补偿就会整体错位，表现为稳完反而有「反向拉扯」。
2. **镜头配置文件准不准？**——配置不对，画面先被错误地去畸变，再怎么稳都是歪的。
3. **滚动快门读出时间填得对不对？**——读出时间不准，快门畸变补偿过度或不足，快速摆动的片段会扭曲。

三问对应的检查动作分别在下面第二、三节和 [镜头配置文件怎么校准.md](镜头配置文件怎么校准.md)。

## 二、同步这一关怎么过

- 先点参数页的**自动同步**，让它自己找偏移；同步点稀疏、抖动单一的素材，把「最大同步点数」从默认的 3 往上加。
- 你大致知道数据早了/晚了几秒，就把**陀螺大致偏移**先填上——自动同步默认只在 5.0 秒的搜索窗口（同步搜索尺寸）里找，超出窗口它找不到。
- 手机当外置记录器、或两个设备分开开机时，时间差常超出默认窗口，**这一步最常被漏**。
- 同步做完看结果：稳完的片段若在原地抖动方向上「补过头」，回到同步重做，而不是先去调平滑度。

## 三、镜头配置文件这一关

- GoPro 8+、DJI 等有官方内置配置的机型会**自动加载**，确认输入页的镜头配置文件栏不是空的。
- 没自动加载的，先在搜索框按机型名搜；搜不到就自己校准，步骤与判据在 [镜头配置文件怎么校准.md](镜头配置文件怎么校准.md)。
- **宽高比必须和素材一致**——搜索时宽高比不匹配的配置会被淡化，硬用会导致画面边缘拉伸。
- 电影机素材（如 RED）不同分辨率用的传感器区域不同，**不能跨分辨率套配置**，要用同分辨率校的那份。

## 四、拍摄端的干扰：防抖别叠着用

- **手机内置防抖（EIS）开着，Gyroflow 直接不起效**；**光学防抖（OIS）关不掉时会和它打架**（官方文档明确写了这两条）。已拍完的素材没法关掉拍摄时的防抖，只能认这个先天损失，下次拍前先关。
- 部分相机开了机内增稳（如 GoPro HyperSmooth）的素材，Hero 8 及之后官方明确支持处理；更早机型官方没给这条说明。
- 拍摄时若开了**锁死构图的取景防抖**（有些手机叫「超级防抖」），画面已被机内裁切过，再稳的余地很小。
- **运动模糊救不回来**：官方拍摄指南明确说，拖影在稳完之后仍留在原方向上，和稳出来的运动对不上，画面会「发糊发飘」——根子在拍摄时快门太慢。180° 快门规则（快门 = 2 倍帧率）**不适用于任何数字稳**，动作类素材要往更快的快门拍（如 30fps 用 1/120 这种 90° 快门）。已经拍糊的素材后期无解。
- **画幅给少了，后面怎么调都缺料**：GoPro 官方文档说 4:3 传感器配 `wide` 档能给稳出最多的可用画面；拍的时候省下的裁切余量，后期是补不回来的。

## 五、两个手改字段：帧率与旋转

- **帧率错**：可变帧率素材（高帧拍、慢放存）必须把输入页的帧率改成拍摄时的真实帧率，否则数据与画面对不上——这是官方文档点名的坑（典型值 119.88、59.94、29.97、25）。判据：文件属性写的帧率和你拍摄时设的帧率不一致。
- **旋转错**：竖拍/倒拍的素材方向不对，先在输入页「旋转」里改成正确朝向，再做同步。方向都不对，同步和稳定的结果没法看。

## 六、数据压根没读进来

- 看输入页「包含陀螺仪数据」是不是「无」，以及运动数据区的**统计面板**：读进来了各轴会显示采样率，一直是 `0 Hz` 就是没有数据。
- 内嵌数据没有 → 换素材或挂外置日志；外置日志没读到 → 换格式重导（支持的格式见 [支持哪些相机和陀螺仪数据.md](支持哪些相机和陀螺仪数据.md)）。
- 数据毛刺严重（波形全是高频尖刺）→ 打开**低通滤波器**，截止频率先用官方建议的 50 Hz。
- 确实没有任何数据、也不想补录 → 可以试官方的无数据模式（载入视频 → 选镜头配置 → 自动同步改走光流估算），但那是基础功能，只适合轻晃场景，详见 [没有陀螺仪数据的视频也能稳吗.md](没有陀螺仪数据的视频也能稳吗.md)。

## 七、稳了但「过稳」或「不够稳」

这是参数取向问题，不是故障，两个旋钮解决：

| 症状 | 先动哪里 |
| --- | --- |
| 画面被裁太多、构图缩水 | 平滑度调低；视场角若被改到 1.0 以下，往 1.0 或更大回调（大于 1.0 会露出更外圈画面，出现黑边就退回来） |
| 走路的低频晃动还在 | 平滑度调高（默认 0.500 往上调；越往上调越吃裁切余量） |
| 地平线歪着不回正 | 勾「锁定地平线」 |
| 补偿太猛、边缘拉扯变形 | 降平滑度、收紧最大旋转（Pitch / Yaw / Roll）上限 |
| 画面四周出现黑边 | 稳定设置里改用「动态缩放」（Dynamic zooming，桌面版在稳定设置里，手机版看高级选项有无同名项） |
| 画面被放得过大、视角无端变窄 | 稳定算法换回「默认」——官方 FAQ 说「画面过度放大」多半就是算法选错了档 |
| 稳完反而更抖、横线呈波浪（果冻效应） | 高频振动混进了数据：给运动数据开**低通滤波**（官方 DJI 页建议截止频率别低于 30 Hz）；无人机还要回头查机械振动源（相机软安装、桨叶动平衡、电机频率与 IMU 采样打架），软件治不了机械病 |

调完一批参数导一段短片验证，别整段 4K 跑完才发现方向不对——预览区就能先看个大概。要是怀疑是自己把参数改乱了，官方 FAQ 的第一条建议就是**整套参数重置回默认**再从头调（桌面版在右下 Advanced 里的「Reset all settings to defaults」，手机版对应入口以你手上版本的界面为准）；仍拿不准的可以直接去官方 Discord 讨论组（[discord.gg/YaUtNpWTUh](https://discord.gg/YaUtNpWTUh)）提问。
