## 一、先看这一项：包含陀螺仪数据

Gyroflow 稳画面靠的是「拍摄时记录的运动数据」，不是光流猜出来的。视频导进输入页后，看**视频信息**里的「包含陀螺仪数据」一项：

- 显示**有** → 数据已经在文件里，直接去参数页做同步。
- 显示**没有** → 要么这段素材本来就没记数据，要么得手动挂一份外置日志（见第三节）。

运动相机、无人机、部分微单会把数据内嵌在视频文件里；没有内置陀螺仪的设备，就得用别的设备把数据记下来。

读数据时顺手看一眼**采样率**：官方 FAQ 给的参考是 GoPro 200 Hz、DJI 与 Insta360 1000 Hz、Sony 2000 Hz；**50 Hz 是绝对下限**，比这还低的数据量撑不起精细的补偿，效果会肉眼可见地变差。

## 二、内置陀螺仪的设备（官方支持清单）

下表是官方 README 列出的运动数据来源（截到官方仓库当时的清单，完整版以 [github.com/gyroflow/gyroflow](https://github.com/gyroflow/gyroflow) 为准）：

| 类别 | 型号 / 格式 |
| --- | --- |
| 运动相机 | GoPro HERO 5 及之后；DJI Action 2/4/5、Avata / Avata 2、Neo、O3 Air Unit；Insta360 OneR / OneRS / GO 系列 / GO2 / GO3 / GO3S / Ace / Ace Pro；Runcam 5 Orange、Thumb 系列；Hawkeye Firefly X Lite |
| 微单 / 摄影机 | Sony a1、a7c、a7 IV、a7s III、a9 II、a9 III、FX3 / FX6 / FX9、RX0 II、RX100 VII、ZV1 / ZV-E10 / ZV-E1、a6700 等 |
| 电影机素材 | Blackmagic RAW（`.braw`）、RED RAW（`.r3d`，V-Raptor / KOMODO） |
| 无人机飞控 | Betaflight 黑盒（`.bfl` / `.bbl` / `.csv`）、ArduPilot 日志（`.bin` / `.log`） |
| 通用格式 | Gyroflow 自有的 `.gcsv` 日志、CAMM 格式 |
| 其他记录器 | Runcam CSV、XTU S2Pro / S3Pro、WitMotion WT901SDCL、Vuze XR、KanDao Obsidian Pro / Qoocam EGO 等 |

几个对实际使用有影响的点：

- **GoPro HERO 8 及之后**连「已经开着 HyperSmooth 拍出来的素材」也能稳（官方说明）。
- **GoPro 8+、DJI 这类机型有官方镜头配置文件，载入即用**；其余机型要么在库里搜，要么自己校准。
- 数据内嵌在视频里时，**那台运动相机本身就能当其他设备的记录器**——把它绑在摄影机上拍，回导出它的数据来稳摄影机的素材。
- **DJI 系有硬条件**：机内防抖（EIS / RockSteady）必须关、FOV 必须选 Wide，否则相机**根本不会把陀螺仪数据写进文件**；Ultrawide、Normal、「Natural Wide」这些档位都不记录数据。另外 DJI Action 3、DJI FPV 与 Osmo 360，官方文档写明不支持、也不会支持。
- **4GB 分段**：GoPro 与 DJI 单文件到 4 GB 会切成多段（每段各带各的数据）。官方桌面版把整段序列一起拖进去就能先合并再稳（File joiner 功能）；手机上若没有合并入口，先在电脑上处理这几段。

## 三、没有内置陀螺仪时：挂外置日志

外置日志就是在拍摄的同时，用另一个设备把陀螺仪数据记成文件，后期在输入页「运动数据」里点「打开文件」载入。常见做法：

- **用另一台运动相机 / 手机当记录器**：手机上能记传感器数据的 App 有 Sensor Logger、Sensor Record、Open Camera Sensors、MotionCam Pro 等（官方文档列出的推荐）。手机装在相机上时的安装方向，要在「IMU 朝向」里对应改。
- **无人机用飞控黑盒**：Betaflight / ArduPilot 的日志直接载入。
- **自定义记录器**：只要能输出 `.gcsv` 或 CSV 就行。

日志和视频是两个独立的时间轴，所以载入后**必须做同步**——操作在 [使用教程与参数设置.md](使用教程与参数设置.md) 第四节。

## 四、用手机自己拍的视频：两个坑

官方文档专门写了手机场景的两条限制，不注意会直接毁掉稳定效果：

1. **手机的光学防抖（OIS）关不掉时会干扰结果**——OIS 在拍摄时已经在动镜头，Gyroflow 再按数据补一次，两套动作打架。
2. **手机内部的电子防抖（EIS）开着时，Gyroflow 不起效**——要拍能稳的素材，先在相机设置里把「防抖 / 稳定」关掉再拍。

一句话：**想要 Gyroflow 稳得好，拍摄端的防抖要让路**。已经用开着防抖的素材拍完了，效果怎么救见 [画面抖动效果不好怎么排查.md](画面抖动效果不好怎么排查.md)。

## 五、手机也能当「记录器」用

手机不拍视频、只记录陀螺仪数据，把数据绑到另一台相机的素材上用，也是官方支持的玩法（外置陀螺仪记录器）。这时你要多处理一件事：**IMU 朝向**——手机怎么绑在相机上（横贴、竖贴、屏幕朝上……）决定数据坐标怎么转，装法不对就得在参数里把朝向修正过来，否则稳定方向全错。录制与安装方式的细节，官方文档的移动设备页有说明（[docs.gyroflow.xyz](https://docs.gyroflow.xyz)）。
