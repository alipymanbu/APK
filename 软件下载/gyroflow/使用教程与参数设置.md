## 一、整体布局

装好之后（没装先看 [下载与安装教程.md](下载与安装教程.md)），界面分两半：

- **上半是预览区**：中间虚线框「点击这里打开一个视频文件」，下面是播放/逐帧按钮、打点按钮和菜单按钮，右上角 `1x` 控制预览倍速。
- **下半是三个页签**：`输入`、`参数`、`导出`。桌面版把这三块摆在左中右三栏，手机版收成了页签，内容一一对应。

一遍跑通的顺序就是页签顺序：输入页把料备齐 → 参数页做同步和稳定 → 导出页出片。

## 二、输入页：打开视频与视频信息

点「打开文件」（或直接点预览区）选一个本地视频。载入后「视频信息」里会列出检测到的相机、镜头、尺寸、时长、帧率、编解码器、像素格式、音频、旋转，以及最关键的一项——**包含陀螺仪数据：是/否**。

两个可手改的字段：

- **帧率**：一般不用动。你要是处理的是「高帧率拍、放慢后存」的可变帧率素材（比如文件里是 120fps、实际按 30fps 放），把它改成拍摄时的真实帧率（NTSC 制式常见 23.976 / 29.97 / 59.94 / 119.88，PAL 是 25 / 50 / 100）。
- **旋转**：竖着拍、倒着拍导致画面方向不对时，在这里按度数填旋转角。

「包含陀螺仪数据」显示没有数据，先看 [支持哪些相机和陀螺仪数据.md](支持哪些相机和陀螺仪数据.md) 确认你这类素材的数据从哪来。

## 三、输入页：镜头配置文件与运动数据

**镜头配置文件**：搜索框里可以按相机名找内置配置（GoPro 8+、DJI 等机型通常自动加载，不用管）；没有的点「创建新...」走校准流程，步骤在 [镜头配置文件怎么校准.md](镜头配置文件怎么校准.md)。同一个配置文件在**宽高比相同、画面来自同一块传感器区域**时可以跨分辨率复用，搜索时宽高比不匹配的配置会被淡化提示。

**运动数据**：数据内嵌在视频里（GoPro / Sony / Insta360 等）时自动就位；要挂外置日志（无人机黑盒、另一台相机当记录器、手机记的传感器日志）就点这里的「打开文件」。可用的选项：

| 选项 | 作用 |
| --- | --- |
| 低通滤波器 | 数据毛刺多（尤其无人机）时打开，官方建议截止频率先试 50 Hz，越低滤得越狠 |
| 旋转 | 陀螺仪坐标和镜头坐标没对齐时做角度修正 |
| 陀螺仪偏差 | 修正开机静置时的零偏 |
| IMU 朝向 | 外置记录器时按安装方向填（默认 `XYZ`） |
| 积分方法 | 由数据推算姿态的算法，下拉选择，默认 `Complementary` |
| 统计 | 打开统计面板，看陀螺仪/加速度计各轴的采样率（Hz）与波形 |

**统计面板值得养成习惯地看一眼**：数据真读进来了，各轴会显示采样率而不是 0 Hz；一直是 0 就说明没读到数据，后面同步做得再好也白搭。

## 四、参数页：同步

同步解决的是「数据记录时间和出像素的时间差了几毫秒」——对不齐，补偿就会补错位置。字段：

- **自动同步**：先点它。它会在时间轴上找若干个同步点，用画面运动和陀螺仪数据对齐时间偏移。
- **陀螺大致偏移**：你心里有数差多少秒时直接填，能大幅缩小自动同步的搜索范围（单位秒，默认 0.0）。
- **同步搜索尺寸**：自动同步的搜索窗口，默认 5.0 秒。偏移超出这个窗口就找不到，需要先填「大致偏移」。
- **最大同步点数**：参与计算的同步点上限，默认 3。素材长、抖动模式变化大时可以加。
- **高级选项**：里面有按第几帧分析、每个同步点分析时长、光流方法等细项，第一次不用碰。

判同步做没做好，看导出的画面有没有「补错位」的拉扯感——官方给的第一条排障问题就是「同步时间偏移准不准」，详见 [画面抖动效果不好怎么排查.md](画面抖动效果不好怎么排查.md)。

## 五、参数页：稳定

- **视场角（FOV）**：控制输出画面的取景范围，默认 1.000。**小于 1.0 是放大裁切**（画面显得更稳，但构图缩水）；**大于 1.0 是往回收、露出更外圈的画面**（用足稳定余量，调过头边缘会出黑边）。官方典型用法是保持 1.0，配合下面的平滑度来换取稳定。
- **算法**：下拉框选平滑算法，默认那档就是起点；不同算法适配的运动形态不一样（有的只做去畸变不平滑、有的不擅长快速剧烈运动），逐个试比看参数表更快。
- **平滑度**：默认 0.500。低 = 保留更多原始运动，高 = 更接近云台的死稳（官方口径：0 等于不平滑，调到 1 以上需要更多裁切余量）。走路、骑行这种低频晃动主要靠它压。
- **锁定地平线**：勾上后强制地平线水平，拍歪了也给你掰平；素材本身有意倾斜构图时别勾。
- **最大旋转**：限制 Pitch / Yaw / Roll 各轴的补偿上限，防止补偿幅度过大把画面拉变形。
- **高级选项**：滚动快门校正、逐轴平滑等细项在这层（滚动快门读出时间填错反而劣化，没把握别动）；处理黑边的「动态缩放」（Dynamic zooming）选项也在这一层（以你手上版本的界面为准）。

## 六、导出页

1. **输出路径**：点右侧 `...` 选目录，务必选一个你找得到、空间够的位置。
2. **编码**：下拉选择，默认 `H.264/AVC`，拿不准就别动；这个项目在桌面端还支持 H.265/HEVC 等输出，手机版下拉里具体有哪些以界面为准。
3. **输出大小 / 比特率**：界面默认都显示 0；不改就按默认行为导出，想强制指定分辨率或码率时再填数字。**要输出竖屏**：把两个尺寸框中间的锁图标解开，直接填 9:16 的尺寸（如 `1080x1920`）——这是官方 FAQ 给的竖屏导出法。
4. **使用 GPU 编码**：勾上走硬件编码，导出快很多；导出报编码错误时把它关掉再试，能定位是不是硬件编码器的问题。
5. **导出音频**：默认勾选，稳完的视频保留原声。
6. 点**导出**按钮开跑，进度条走完即出片；`高级选项` 里还有更细的编码参数。

导出完把成品拖回预览区再看一遍，不满意就回参数页改，这个循环就是它的工作方式。
