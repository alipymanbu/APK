# Gyroflow 镜头配置文件怎么校准

> 你的相机不在内置配置清单里？拍一段棋盘格素材，自己做出一份镜头配置文件。

## 一、什么时候需要校准

镜头配置文件告诉 Gyroflow 这颗镜头的畸变长什么样——它是稳定计算的地基，配置不对，同步做得再准画面也是歪的（官方排障三问之一，见 [画面抖动效果不好怎么排查.md](画面抖动效果不好怎么排查.md)）。

- **GoPro 8+、DJI、Insta360 运动相机、Sony 部分机型等有官方内置配置**，载入素材自动生效，跳过本篇。
- **配置库里搜不到、或你的镜头 + FOV + 宽高比组合没被覆盖**，就需要自己校准。
- 换了外接镜头、改了拍摄 FOV 档位、宽高比变了，旧配置也就不适用了。

## 二、录制校准素材

1. 打开你要校准的**那台相机**（配置是给相机 + 镜头 + FOV + 宽高比这一套组合的），进 Gyroflow 的镜头配置文件 →「创建新...」，打开其中的标定板功能（官方界面叫 Open calibration target），屏幕会显示棋盘格图案。
2. 把棋盘格图案**全屏放在一台平面显示器**上——曲面屏不行（官方文档明确写了弯曲的显示面无效）。
3. 选好你之后拍摄会用的相机参数，**关键是 FOV / 焦距与宽高比**——校准哪档就用哪档拍。
4. 对着屏幕缓慢移动相机，覆盖这些视角：
   - 棋盘格充满整个画面
   - 拉远距离拍
   - 斜着拍
   - 画面每条边缘与棋盘格边缘对齐
   - 棋盘格角对准画面角
5. **结尾加一段快速左右摆头（yaw）**——这是给滚动快门校正用的参考动作，别省。

## 三、分析并导出配置文件

1. 镜头配置文件 →「创建新...」，选中刚录的校准视频。
2. 跑自动校准，或手动添加校准点（Add calibration point，桌面上是在时间轴的右键菜单里）补帧。
3. **把结尾那段快速左右摆动裁掉**（校准分析不需要它，它是留给滚动快门参考的）。
4. 处理完看画面：直线应该被拉直了，**重投影误差通常要小于 5 像素**才算过关。
5. 填好配置信息（机型、FOV、宽高比等），滚动快门读出时间知道就填，然后导出这份镜头配置文件。

配置文件是 JSON 格式，存在本地，之后在镜头配置文件的「打开文件」里随时载入复用，也可以收藏进搜索列表。

## 四、复用规则（别拿错配置）

| 场景 | 能不能用同一份配置 |
| --- | --- |
| 只改了帧率 | 能，畸变与帧率无关 |
| 只改了分辨率、**宽高比相同且画面来自同一块传感器区域** | 能，配置会按分辨率自动缩放 |
| 宽高比不同 | 不能 |
| FOV 档位不同 | 不能，各校一份 |
| 不同分辨率用不同传感器区域的机型（如 RED） | 不能跨分辨率复用 |

搜索配置时 Gyroflow 会校验宽高比、把不匹配的淡化掉——**顺着淡化提示走，别硬选**。

## 五、校准完效果还是不对

按顺序回到排查流程：先确认同步做没做对（[画面抖动效果不好怎么排查.md](画面抖动效果不好怎么排查.md) 第二节），再确认滚动快门读出时间没瞎填；素材本身有没有陀螺仪数据、防抖有没有叠着开，分别见 [支持哪些相机和陀螺仪数据.md](支持哪些相机和陀螺仪数据.md) 和排查篇第四节。参数怎么调则在 [使用教程与参数设置.md](使用教程与参数设置.md)。
