## 一、装之前先弄清楚的一件事

OpenClaw 是一个开源的个人 AI 助手项目：你在 WhatsApp、Telegram 这类聊天软件里给它发消息，它按你的指令去干活。安卓上的应用只是整套系统里的「手机端」，完整能力通常还要有一台电脑或服务器在后台跑着服务端（行话叫 Gateway 网关），手机负责让你随时跟它对话。

所以装之前建议先想好三件事：

- **手机**：一部能正常安装第三方 APK 的安卓手机；
- **模型密钥**：一个可用的大模型 API 密钥，没有它装好也答不了话，见 [配置AI模型与API密钥.md](配置AI模型与API密钥.md)；
- **后台主机**：一台能常开的电脑或服务器；只有手机没有主机时能不能用，见 [安卓端与电脑端如何配合.md](安卓端与电脑端如何配合.md)。

## 二、获取安装文件资源

从 [OpenClaw 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0bf72f68cc25) 进入分享页，夸克网盘的分享不能直接下到手机，先转存再下载：

1. 把链接复制到浏览器打开，登录夸克账号后点「转存」，存到自己网盘里；
2. 用夸克网盘客户端（手机版即可）找到转存后的文件，下载 APK；
3. 下载完成后先别急着点安装，按下面表格核对一下文件。

本次这份安装包的信息如下（以你实际下载到的文件为准）：

| 项目 | 信息 |
| --- | --- |
| 版本 | 4.9.15 |
| 包名 | com.baidu.bce |
| 大小 | 23.41 MB |
| MD5 | B957812F57454B66E6857E437871D210 |

MD5 可以用手机文件管理器的「文件校验」功能，或在电脑上执行 `certutil -hashfile 文件名 MD5` 来算，和表里对得上说明文件完整。

## 三、安装步骤

1. 在手机上点开下载好的 APK；第一次装会提示「禁止安装未知来源应用」，按提示允许你的下载来源（浏览器或文件管理器）「安装未知应用」；
2. 回到安装页点安装，等待完成；
3. 装完桌面上会出现应用图标。

三个提醒：

- 官方对安卓端的分发渠道是 Google Play 和 GitHub 发布页，不同渠道安装包的签名身份可能不同。之后如果想换渠道安装、又提示「签名不一致」，需要先卸载旧版再装新版——卸载会清掉应用在本地的数据，先备份重要内容；
- OpenClaw 迭代很快，你手上的版本和官网最新版的界面可能对不上，操作时以实际界面为准；
- 社区教程提醒过：应用商店里出现过仿冒 OpenClaw 的假应用，装之前认准来源，最好按上文表格核对文件指纹。

## 四、装完之后先做什么

装好只是开始，真正能用还差两步：

1. 在后台主机上把服务端跑起来，官方文档（[docs.openclaw.ai](https://docs.openclaw.ai/zh-CN/)，有中文页面）里有完整的安装向导；
2. 在手机应用里把手机和主机配对、接上聊天渠道，具体见 [聊天渠道绑定与配对.md](聊天渠道绑定与配对.md)。

装完连不上、打不开之类的状况，按 [常见问题排查.md](常见问题排查.md) 的清单逐项对。
