# OpenClaw 常见问题排查

> 装不上、连不上、发消息没反应、用量异常——按「症状 → 先查什么」整理成一份排查清单，从上往下对。

## 一、APK 装不上或装完打不开

| 症状 | 先查什么 |
| --- | --- |
| 提示「禁止安装未知来源应用」 | 系统设置里给下载来源（浏览器/文件管理器）开「允许安装未知应用」 |
| 提示「签名不一致/存在冲突」 | 之前装过别的渠道的包，先卸载旧的再装；卸载会清掉应用本地数据 |
| 提示解析失败/安装包损坏 | 重新下载一遍，并核对 MD5（本次网盘包的指纹见 [下载与安装教程.md](下载与安装教程.md)） |
| 打开就闪退 | 存储与内存是否吃紧；重启手机再试；记录系统版本，去项目仓库搜有没有同类反馈 |

## 二、手机连不上主机

1. 两端是不是同一网络（或同一 Tailscale 虚拟网）；路由器开「AP 隔离/访客网络」时两端互相看不见；
2. 主机上的服务在不在跑：主机上执行 `openclaw gateway` 看是否正常监听；
3. 手机端是不是被系统杀后台：把常驻通知留着，电池优化设为「不限制」；
4. 之前配过、现在失联：在手机端删掉网关记录，重新走一遍配对；
5. 想让旧手机长期当主机，部署与保活细节见 [旧手机部署成主机的步骤.md](旧手机部署成主机的步骤.md)。

## 三、主机端的官方排障命令

OpenClaw 自带一组排查命令，在主机上按顺序跑一遍，多数问题能定位到在哪一层（用法以官方文档为准）：

```
openclaw status
openclaw gateway status
openclaw logs --follow
openclaw doctor
openclaw channels status --probe
openclaw nodes status
```

手机端作为节点连上后，工具调用报错的关键字直接对照：

| 报错关键字 | 含义与处理 |
| --- | --- |
| `NODE_BACKGROUND_UNAVAILABLE` | 手机应用在后台，切到前台再重试（相机、录屏、定位这类能力只在应用前台可用） |
| `*_PERMISSION_REQUIRED` | 对应系统权限没给（相机/麦克风/定位/屏幕录制），去系统设置里授权 |
| `CAMERA_DISABLED` | 应用设置里相机开关被关了 |
| `LOCATION_DISABLED` / `LOCATION_PERMISSION_REQUIRED` | 定位模式没开或权限没批 |
| `SYSTEM_RUN_DENIED` | 命令被执行审批或白名单拦了，属正常防护，怎么调整见 [限制助手权限的配置方法.md](限制助手权限的配置方法.md) |

## 四、连上了，发消息却没反应

按顺序查：

1. 渠道白名单：你的号码/账号在不在 `allowFrom` 里；
2. 模型密钥：有没有过期、额度用完、填错（见 [配置AI模型与API密钥.md](配置AI模型与API密钥.md)）；
3. 主机端服务状态与日志：控制台里看会话有没有收到消息；
4. 心跳/自动任务是不是把用量吃光了，导致新消息排在后面。

## 五、模型用量比预期高

- 控制台里看用量统计，定位是哪类任务在消耗；
- 定时任务与心跳是常见的「隐形消耗」，不需要就关掉；
- 日常问答换低一档的模型，复杂任务再切高档位；
- 官方 FAQ 给的个人用量量级是每月 5~20 美元（截至 2026 年，以官网为准），长期明显超出就该查任务设置。

## 六、想更新版本

- 尽量沿同一条渠道更新（当初从哪装的就从哪更新）；
- Google Play 与独立 APK 两条渠道的签名身份可能不同，跨渠道切换时系统可能要求先卸载旧版——卸载会清本地数据，先备份工作区与配置；
- OpenClaw 更新很勤，版本动态看项目的 GitHub 发布页：[github.com/openclaw/openclaw](https://github.com/openclaw/openclaw)。

## 七、还是解决不了

带上三样东西去项目仓库的 issue 区搜或提问：系统版本、应用版本、报错日志或截图。官方文档（[docs.openclaw.ai](https://docs.openclaw.ai/zh-CN/)）的排障章节也值得先翻一遍，很多问题的答案就写在里面；涉及权限收紧的取舍见 [安全设置与隐私建议.md](安全设置与隐私建议.md)。
