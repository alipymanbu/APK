## 一、先想好用哪个聊天软件当入口

OpenClaw 可以接的渠道有 20 多个（WhatsApp、Telegram、Discord、Slack、Signal 等，清单以官方文档为准：[docs.openclaw.ai](https://docs.openclaw.ai/zh-CN/)）。选的时候注意两点：

- **建议用专用号码/账号**：把私人号直接接上去，每条消息都会变成给助手的指令，很容易误触发，官方也建议给助手单独一个号；
- **渠道接在主机一侧**：渠道是接在 Gateway 上的，手机应用本身不保管渠道。

## 二、接入渠道的一般流程（主机端）

以官方文档的推荐流程为准，大致是：

1. 主机上执行 `openclaw channels login`（接 WhatsApp 时会出二维码，用助手的那个号去扫）；
2. 打开网页控制台，在渠道页里勾选或补充要用的渠道；
3. 在配置里给渠道加白名单（比如 WhatsApp 的 `allowFrom`），只允许你自己的号码跟助手说话；
4. 用你自己的号发一条消息测试。

白名单在配置里大概长这样（字段名以官方文档为准）：

```json5
{
  gateway: { mode: "local" },
  channels: {
    whatsapp: { allowFrom: ["+8613000000000"] }
  }
}
```

另外：群聊里助手能看到所有人的消息，也可能跟着别人的指令走，敏感指令建议只认你自己的账号，更多边界见 [限制助手权限的配置方法.md](限制助手权限的配置方法.md)。

## 三、安卓手机怎么配对到主机

手机端的角色是「配套节点」，配对之后才算真正接进系统：

1. 确保手机和主机能互相够到：最简单是同一个局域网；不在同一网络时，常见做法是用 Tailscale 组网后走加密连接；
2. 打开手机应用，进入网关/Gateway 设置页，选择发现到的主机或手动填主机地址；
3. 按提示完成配对（首次配对可能要在主机端确认）；
4. 配对成功后，主机状态页里应该能看到这台手机。

两个具体细节（以官方文档为准）：

- 主机端的网关常用 `openclaw gateway --port 18789` 这样的方式启动，手动填地址时端口就是它；
- 同一局域网里手机端靠自动发现找主机；跨网络时官方推荐 Tailscale Serve 这类入口，把连接升级成 `wss://` 加密地址，明文 `ws://` 只允许在局域网、`localhost` 这类私有地址上用。

有 Wear OS 手表的话还有配套手表应用，通过已配对的手机连主机，可以看会话、回消息、叫停正在跑的任务。

注意：远程接入方式的安全取舍见 [安全设置与隐私建议.md](安全设置与隐私建议.md)。

## 四、连不上时先查这四样

- 手机和主机是不是真的在同一网络（路由器的访客网络、AP 隔离会把两端隔开）；
- 主机上的服务在不在跑（主机上执行 `openclaw gateway` 或对应的服务管理命令看状态）；
- 有没有被系统休眠杀掉：手机上那条常驻通知别划掉，电池优化里把该应用设为不限制；
- 配对信息过期：删掉手机里的网关记录重新配对。

还解决不了就按 [常见问题排查.md](常见问题排查.md) 的清单逐项排。
