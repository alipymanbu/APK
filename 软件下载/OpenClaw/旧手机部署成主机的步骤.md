## 一、先认清这条路线的定位

官方安卓应用（形态见 [下载与安装教程.md](下载与安装教程.md)）定位是配套节点，不承担完整服务端；「手机自己当主机」走的是 Termux 终端环境的社区路线。多个独立社区教程都记录过做法，但它不在官方主线支持范围里，出了问题主要靠自己查。给旧手机派这个用场之前，先接受这一点。

## 二、手机要满足什么条件

社区教程给的门槛（以你的实际机型为准）：

| 条件 | 要求 |
| --- | --- |
| 机型年代 | 2019 年之后，骁龙 855 一档或 Pixel 4 及以上 |
| 内存 | 4GB 起步，6GB 才舒服 |
| 存储 | 空闲 8GB 以上（走 Ubuntu 方案还要再吃约 3GB） |
| 网络 | 稳定 Wi-Fi；移动数据下连接容易因心跳断线 |
| 供电 | 常年插电；长期满电满载伤电池，有「充电上限保护」的机型建议开着 |

## 三、三种做法怎么选

| 做法 | 特点 | 适合谁 |
| --- | --- | --- |
| 整包应用（社区的 openclaw-termux 类应用） | 一个 APK 装完自带 Termux/Ubuntu/Node，首次启动自动拉环境 | 只想跑通、最省事 |
| 原生 Termux + Node.js | 省内存（社区口径省 30~40%）、启动快；个别依赖 Linux 专属组件的技能跑不了 | 内存小、想要轻量 |
| Termux + proot Ubuntu | 兼容性最好，技能与插件基本都能跑；最重、最慢 | 想要接近电脑端体验 |

## 四、原生 Termux 的参考步骤

Termux 要装 F-Droid 版（[f-droid.org](https://f-droid.org/en/packages/com.termux/)；应用商店里的版本多年没更新，会有兼容问题）。核心命令（以社区教程与官方文档为准）：

```bash
pkg update && pkg upgrade -y
pkg install -y nodejs git python sqlite openssl ffmpeg
termux-setup-storage
npm install -g openclaw
termux-wake-lock
openclaw start
```

跑起来后，控制台在本机的 3000 端口（社区教程口径）；想在同一 Wi-Fi 下的电脑上打开，用手机的局域网 IP 加端口访问。

## 五、保活清单（成败在此）

安卓对后台进程下手很狠，做完这一节才算「能常驻」：

1. 电池优化设为「不优化/无限制」（设置 → 应用 → 对应应用 → 电池）；
2. 三星机型另关「让应用休眠」「深度休眠」；小米/MIUI 关「省电策略」并允许「自启动」；
3. Termux 里执行 `termux-wake-lock`，防止 CPU 休眠；
4. 通知栏那条常驻通知别划掉，划掉进程就可能被杀；
5. 常年插电，避免断电关机；
6. 用一台不再日常使用的旧机专门干这事，重启、折腾都不影响主力机。

## 六、第一次启动常踩的坑

- 首次启动要下载和解包环境，几分钟到十来分钟都正常，别当卡死；
- 社区教程普遍提到首次启动会遇到 `trim` 相关报错，跟着教程里的处理步骤走即可；
- 用移动数据时 WebSocket 心跳容易断，导致工具调用失败，尽量挂 Wi-Fi；
- WhatsApp 扫码接渠道时保持屏幕常亮，扫一次过（渠道接入见 [聊天渠道绑定与配对.md](聊天渠道绑定与配对.md)）。

## 七、跑起来之后的用量参考

社区教程的实测口径（随机型与任务量浮动，以你的实测为准）：内存占用约 200~500MB；待机耗电约每天 5~10%；安装与环境占存储约 500MB 起，Ubuntu 方案再加约 3GB。

跑起来之后的报错按 [常见问题排查.md](常见问题排查.md) 处理；要开放给外网访问之前，先把 [安全设置与隐私建议.md](安全设置与隐私建议.md) 过一遍。
