## 一、为什么必须先配模型

OpenClaw 本身是一套帮你「接渠道、记上下文、执行任务」的开源框架，真正理解和回答话的是你接上去的大模型。没有模型密钥，你在聊天软件里发什么它都不会有像样的反应，所以这一步通常排在渠道接入之前。

## 二、能接哪些模型

主流的大模型 API 都可以接，比如 GPT 系列、Claude 系列、Gemini 系列，也支持接本地部署或其他兼容接口。具体支持列表和写法以官方文档为准：[docs.openclaw.ai](https://docs.openclaw.ai/zh-CN/)。

选型的粗略参考（按你自己的预算和使用量决定）：

| 场景 | 常见做法 |
| --- | --- |
| 先试试水 | 选便宜的档位，跑通流程再换 |
| 日常问答、提醒 | 中小档位模型通常够用 |
| 复杂任务（写代码、长文处理） | 高档位模型，注意用量 |
| 不想用云端 API | 自建本地模型，对机器配置要求高 |

## 三、密钥在哪里填

1. **首次引导**：主机端装好后运行 `openclaw onboard`，向导里会让你选模型、填密钥，跟着走完即可；
2. **之后修改**：配置文件默认在主机的 `~/.openclaw/openclaw.json`，模型与密钥相关条目在这里改（路径与字段名以官方文档为准），改完重启服务生效；
3. **控制台**：OpenClaw 带网页控制台，主机上执行 `openclaw dashboard` 可以打开，里面有模型与用量相关的设置页。

手机端一般不需要单独填密钥：安卓应用是配套节点，模型在 Gateway 一侧配置，手机配对之后共用同一套配置。

## 四、花销大概是什么量级

OpenClaw 项目本身开源免费，花销主要来自模型 API 用量。官方常见问题给的量级是：个人自用每月大约 5~20 美元（截至 2026 年，以官网为准）。几个控制花销的习惯：

- 让它做复杂任务前先想清楚要什么，减少来回追问的轮次；
- 在控制台里定期看用量统计，发现异常早处理；
- 定时任务（心跳、自动巡检）默认也会消耗模型调用，不想要可以先关掉，官方文档里有对应开关；
- 大任务分批做：一次塞进几千封邮件这类任务，既烧 token，长对话触发自动压缩后还可能把你设的规矩挤丢，分批处理两头都省（约束怎么写进配置见 [限制助手权限的配置方法.md](限制助手权限的配置方法.md)）。

## 五、填了密钥还是没反应

按顺序查：密钥有没有填错（多余空格、过期）、模型名称是否写对、主机端服务是否在运行。都排过还不行，就按 [常见问题排查.md](常见问题排查.md) 的清单继续。
