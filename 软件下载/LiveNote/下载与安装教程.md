## 一、这是一份什么软件

LiveNote 是一款电子翻页手账（手写日记）应用：你把图片或 PDF 导进来，它排成一本可以滑动翻页的电子手账本，翻起来跟翻实体本子一样。应用由北京简而一科技工作室（个人独资）开发，安卓与苹果生态都有对应版本；这篇装的是**安卓版**。

适合你的情况：想在手机上做电子手账、把照片或现成的 PDF 模板排成相册式手账、并且希望界面干净（公开资料口径为无广告）。

## 二、先确认手机能不能装

| 项目 | 要求 |
| --- | --- |
| 系统 | 安卓 5.2 及以上（安装时以手机的实际提示为准） |
| 包型 | 单个 APK 安装包，非应用商店渠道包 |
| 空间 | 安装包 53.66M，解压安装后建议预留几百 MB 可用空间 |
| 权限 | 首次导入图片/PDF 时会请求相册与文件读取权限 |

系统版本太低会直接装不上或装完闪退，先在手机「设置 → 关于手机」里确认系统版本，装不上再对照 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、安装步骤

1. 在手机上点击下载好的 `LiveNote_v0.1.0.apk`；
2. 系统弹出「是否允许安装未知来源应用」时，对**当前这个安装来源**（文件管理器或浏览器）临时授权，装完可以关掉；
3. 按提示点「安装」，等待进度走完；
4. 装完点「打开」，或回桌面找 LiveNote 图标。

已经装过旧版也不用先卸载——同包名直接覆盖安装，手账数据保留在本机（覆盖前想稳妥点，先看 [手账封面设置与管理.md](手账封面设置与管理.md) 里的导出办法备份）。

## 五、首次启动

1. 打开后先过隐私与用户协议页，点「我同意」才能进主界面；
2. 主界面左侧的图标点开，里面就是隐私政策、用户协议和反馈入口——不同意前想先看条款，从这里进；
3. 进去后首页是空的，底部中间的「+」就是做手账的入口，完整流程见 [翻页手账制作教程.md](翻页手账制作教程.md)。

## 六、版本说明

- 手上这版是 **0.1.0**（53.66M），更新记录为：图片 PDF 导入、封面管理——也就是「导入素材做翻页手账 + 管封面」这条主线。
- 网上公开渠道能看到更高的版本号（如 0.10.0，体积明显更大，手写笔触、贴纸模板等功能更全），**以官方页面当时显示为准**。本文档系列涉及版本号、包名、大小的地方，一律以第三节表格（网盘里那份包）为准。
- 想确认自己装的是哪版：手机设置里的应用信息能看到版本号，包名应为 `com.nange.livenote`。
