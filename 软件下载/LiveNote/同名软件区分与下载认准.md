# 同名软件区分与下载认准

> 搜 LiveNote 会出来好几款完全不同的应用——锁屏备忘、语音转写、翻页手帐都叫这个名字。这篇教你认准本文档系列讲的那一款，别下错。

## 一、先认清：本文讲的是哪一款

| | 本文的 LiveNote | 容易混淆的同名应用 |
| --- | --- | --- |
| 是什么 | 翻页手帐、手写日记（拟物翻页的电子手账本） | ① 锁屏备忘类（备忘录显示在锁屏上）；② 语音转写类（录音转文字） |
| 开发者 | 楠 唐（App Store 开发者名）／北京简而一科技工作室（安卓侧厂商） | 其他同名开发者（如 LVNT 等） |
| 包名 | `com.nange.livenote` | 各不相同 |
| 平台与类别 | 安卓 + 苹果生态，效率/手帐类 | 多为 iPhone 单端工具类 |

判断标准就一条：**你下的这个是不是「翻页手帐、手写日记」**——商店页副标题带「翻页手帐」「手写日记」、介绍里有拟物翻页和 PDF 手账模板的，才是它。

## 二、下载时怎么认准

1. **安卓**：认准包名 `com.nange.livenote`。装完在「设置 → 应用 → LiveNote → 应用信息」里能看到包名，对得上才继续；
2. **苹果**：在 App Store 搜「LiveNote 翻页手帐」这类带功能词的组合，别只输 LiveNote；进入应用页看副标题是否为「翻页手帐、手写日记」、开发者是否为「楠 唐」（以商店当时显示为准）；
3. **图省事**：直接从头部的 **LiveNote 安装文件资源（夸克网盘）** 拿安卓包（`https://pan.quark.cn/s/b7699e4e6f28`），包名、大小都对得上 [下载与安装教程.md](下载与安装教程.md) 第三节的表格。

## 三、已经下错了怎么处理

- **界面完全不一样、找不到「+」导入手账**：下的是同名的另一款，卸掉重下，按第二节认准；
- **图标像但功能对不上**：查应用信息里的包名，不是 `com.nange.livenote` 就是下错了；
- 同名应用之间**数据不互通**，下错的那款里写的内容跟这款没关系，删掉不损失本文这款的数据。

## 四、装对了的自检清单

- [ ] 应用信息里包名是 `com.nange.livenote`
- [ ] 首次打开是隐私与用户协议页，点「我同意」进主界面
- [ ] 首页底部中间有「+」，点开能选「导入图片」「导入 PDF」
- [ ] 版本号与 [下载与安装教程.md](下载与安装教程.md) 第三节表格一致（0.1.0）

四条全中就是对的版本，接下来直接看 [翻页手账制作教程.md](翻页手账制作教程.md)。
