# LiveNote 常见问题与故障排查

> 这篇收集你用 LiveNote 时真正会碰到的问题：装不上、打不开、导入失败、导出找不到、新旧版本功能不一样，逐条给排查动作。按现象对号入座即可。

## 一、安装与启动类

### 1. 点 APK 提示「无法安装」

按顺序排查：

1. 看系统版本：本应用要求**安卓 5.2 及以上**（以安装时手机实际提示为准），版本不够换台设备装；
2. 看存储空间：安装包 53.66M，安装需要额外空间，清出几百 MB 再试；
3. 看来源授权：装第三方 APK 需要对当前安装来源临时授权「允许安装未知应用」；
4. 确认包没下完整：回到头部的 **LiveNote 安装文件资源（夸克网盘）** 重新下载，包名应为 `com.nange.livenote`；

### 2. 装完一点就闪退

- 先确认装的是不是这个包：应用信息里包名是 `com.nange.livenote`、版本 0.1.0；
- 系统版本刚好卡在下限附近时容易不稳，换更高版本系统试；
- 覆盖安装出问题就先卸载再装（**卸载会清掉本机手账**，先导出 PDF，见 [手账封面设置与管理.md](手账封面设置与管理.md) 第四节）。

### 3. 首次打开停在协议页

必须点「我同意」才能进主界面；想先看条款，点页面左侧图标进去有隐私政策与用户协议。不点同意进不去，这是正常流程不是故障。

## 二、导入类

### 1. 点「导入图片」选不到照片

这是权限问题：允许 LiveNote 读取相册/存储权限。安卓上在「设置 → 应用 → LiveNote → 权限」里把存储（照片和视频）改为允许，回到应用重新点「+」。

### 2. PDF 导入失败或没反应

- 确认文件是标准 PDF：带打开密码的、损坏的、异常巨大的文件都可能导不进去；
- 换一份 PDF 验证：能导 A 不能导 B，问题在 B 这个文件；
- 从文件管理器里直接点开该 PDF 看看能否正常打开，先排除文件本身损坏。

### 3. 导入顺序和想的不一样

翻页顺序就是导入时的排列顺序。选图时按想翻阅的顺序挑；顺序错了，目前最省事的办法是删掉重导一本（删除入口在手账右上角三个点里）。

## 三、导出与数据类

### 1. 导出 PDF 后找不到文件

- 导出时留意屏幕上的保存提示（路径或「已保存」位置）；
- 到手机相册和文件管理器的最近文件里按时间找；
- 找不到就重新导出一次，这次注意看提示。导出文件只带走版面内容，翻页动画不会保留在 PDF 里——这不是导出失败。

### 2. 手账会不会丢、能不能同步到别的手机

- 手账数据在**本机**，卸载、清理数据、换机会没——所以每本做完导出 PDF 存网盘/电脑（见 [手账封面设置与管理.md](手账封面设置与管理.md) 第四节）；
- 关于云同步，公开资料口径不一：有的说支持加密云端同步多设备互通，有的说仅本地存储不收集数据。**以你装的这版里实际有没有同步入口为准**，没有就靠导出 PDF 手动备份；
- 换手机没有「账号恢复」这回事，靠的是导出的 PDF。

### 3. 覆盖升级后数据还在吗

同包名覆盖安装一般保留本机数据，但升级前最稳的还是先把手账导出 PDF（见 [下载与安装教程.md](下载与安装教程.md) 第四节）。

## 四、版本差异：网盘这版和网上看到的不一样

这是被问得最多的：你装的是 0.1.0，搜出来的却是 0.10.0，功能对不上。

| | 网盘里这份（0.1.0） | 网上公开渠道常见的更高版本（如 0.10.0） |
| --- | --- | --- |
| 版本 / 大小 | 0.1.0 / 53.66M | 0.10.0 / 153.15M（以官方页面当时显示为准） |
| 更新记录 | 图片 PDF 导入、封面管理 | 公开介绍里多了手写笔触细化、LivePhoto 动态照片、异形裁剪、语音转文字、更多模板贴纸等 |
| 主线 | 导入图片/PDF → 翻页手账 → 封面管理 → 导出 | 同一条主线，素材与创作工具更丰富 |

处理办法：

- 想要网盘这份（0.1.0）：从 [LiveNote 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b7699e4e6f28) 装，功能预期按上表左列；
- 想要更高版本：留意官方渠道的更新（版本号会持续变化，以官方页面为准）；
- 两版操作主线一致：都是点「+」导入 → 命名 → 翻页编辑 → 三点菜单导出，所以本文档系列的步骤通用，具体按钮形态以你那版界面为准。

## 五、还没解决？

先缩小范围：换一台安卓 5.2+ 的设备装同一个 APK——能装说明问题在原设备（系统版本/权限/空间），不能装说明包或兼容性问题。这两条路分别回到本文第一、二节对应的条目继续排。
