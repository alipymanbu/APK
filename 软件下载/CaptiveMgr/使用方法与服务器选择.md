## 一、五分钟速通流程

按这个顺序点，多数设备到这里就收工：

1. 启动 CaptiveMgr，完成 root 或 Shizuku 授权（方式选择见 [下载与安装教程.md](下载与安装教程.md) 第四节）。
2. 在备选服务器里选 **MIUI**。
3. 点**应用**。
4. 点**刷新图标**（本质是开关一次飞行模式，触发系统重新探测），稍等几秒。

感叹号或叉消失即成功。这个修改写进系统设置后是持久的，不用开机自启、不用每次手动跑，除非刷机或恢复出厂才需要重来。

## 二、备选服务器怎么挑

挑服务器的标准只有一个：你的网络环境下它能稳定返回 204。内置候选的差别：

| 候选 | 特点 | 适合 |
| --- | --- | --- |
| MIUI（小米验证服务器） | 延迟低、稳定，社区口碑里最常用 | 拿不准就先选它 |
| 高通中国 | 不少国产 ROM 出厂内置的就是这类地址 | MIUI 候选测不通时换它 |
| V2EX 社区地址 | 社区维护的公开 204 地址 | 备用选项 |
| 自定义地址 | 手动输入任意支持 204 的地址 | 你自建或另有来源时 |

选完先别急着应用，用应用里的**服务器测试工具**测一下地址栏里的地址：返回 **204** 为正常。有的服务器用空文件返回 200 也能凑合，但不是所有系统都认，优先选返回 204 的。测出超时或异常就换下一个候选，别硬应用一个不通的地址——应用了不通的地址，感叹号一个都不会少。

想用自定义地址又没有现成来源，国内大厂公开的检测地址可以作为备选（社区长期使用的整理，可用性随时间变化，应用前务必先跑测试工具验证；小米地址即内置的 MIUI 候选）：

| 地址 | 来源 |
| --- | --- |
| `http://connect.rom.miui.com/generate_204` | 小米 MIUI |
| `https://www.google.cn/generate_204` | 谷歌中国域名（大陆可直连） |
| `http://connectivitycheck.platform.hicloud.com/generate_204` | 华为 |
| `http://wifi.vivo.com.cn/generate_204` | vivo |
| `http://wifi.oppo.com/generate_204` | OPPO（网友整理，未经长期验证） |

内置候选里的"高通中国"没有公开的固定地址，直接用应用内置项即可，不用手填。

## 三、两个开关各管什么

- **检测开关**：关掉后系统不再做网络检测，图标永远干净；代价是在酒店、校园网这类需要网页登录的网络里，系统不会再自动弹登录页，你得自己手动打开浏览器访问任意一个非 HTTPS 网站来触发登录。常在家用网络就用不着关它。
- **HTTPS 开关**：安卓 7 起检测请求默认走 HTTPS，判定更准。个别服务器只支持 HTTP 不支持 HTTPS 时，把这个开关关掉、或换一个支持 HTTPS 的地址即可。地址能不能走 HTTPS，同样先用测试工具验证。

## 四、刷新图标与恢复默认

- **刷新图标**：应用新地址后图标不会立刻变，点它（或自己开关一次飞行模式）让系统重新探测。服务器地址正确、网络正常时，感叹号会在几秒到几十秒内消失。
- **恢复默认**：把服务器地址栏清空再应用，就回到系统出厂的检测地址。想换回国内地址随时再改。

## 五、应用之后没变化？

先跑一遍服务器测试工具确认地址可达，再确认授权没掉（Shizuku 设备重启后服务要重新启动），仍不行的按 [常见问题与解决方法.md](常见问题与解决方法.md) 逐条对。想知道这套检测机制为什么长这样，回 [wifi感叹号是什么原因.md](wifi感叹号是什么原因.md)；还没装好的回 [下载与安装教程.md](下载与安装教程.md)。
