## 一、怎么确认自己装的是这个应用

同名应用很多，装之前装之后都可以核一下，最靠得住的是包名，其次看安装包大小和 MD5：

- 包名应为 `app.kanju.app`。
- 安装包大小 55.79M，MD5 是 `4BFDBF23AF2734A056A8A39C1593803C`。

装完之后想核对，在手机「设置 → 应用 → 全部应用」里找到它，进「应用信息」页面，部分系统可以直接看到包名；看不到的可以用第三方应用信息工具查。如果包名对不上，那你装的其实是另一个同名软件，遇到的问题也和本篇无关。同名软件怎么逐个区分，见 [同名应用与版本怎么认.md](同名应用与版本怎么认.md)。

## 二、安装环节

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「已被阻止安装」 | 系统没给下载它的应用开安装权限 | 见 [下载与安装教程.md](下载与安装教程.md) 第四节，给对的 App 开「安装未知应用」 |
| 提示「解析包错误」 | 安装包没下完整或被改动过 | 从 [51TV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0c6bfb06a54d) 重新下载，再按教程第三节校验 MD5 |
| 提示「应用未安装」「与已有应用冲突」 | 手机上已有同一包名的另一个版本 | 先卸载旧的再装，卸载前确认不需要保留里面的记录 |
| 下载时被要求输入手机密码 | 系统对非应用商店来源的安装做的安全验证，不是应用要的 | 输一次即可；想少弹这一步，在设置里搜「验证」或「身份验证」，把验证范围调窄，各品牌选项名不同 |
| 装完桌面没有图标 | 部分启动器把它归进了应用抽屉，或安装未真正完成 | 去应用抽屉里翻一遍；找不到就重装一次 |

## 三、启动与账号

| 现象 | 处理 |
| --- | --- |
| 点图标闪退 | 先确认系统不低于安卓 5.2；再在设置里给它清一次缓存；仍闪退就卸载重装 |
| 一直卡在启动页 | 换个网络（流量 / 另一个 WiFi）试，启动时要联网校验；被系统限制后台也会卡住 |
| 登录后过一会儿又要重新登 | 把应用加入电池优化白名单，别让它被后台清理，见第五节 |
| 收不到验证码 | 查垃圾短信拦截、核对号码、等几分钟再发 |
| 播放历史和收藏在不同设备上对不上 | 确认两台设备登的是同一个账号 |

## 四、播放环节

出现播放问题，先做的一件事就是换播放源，这一步能解决掉绝大部分情况，具体位置和判断标准见 [播放源切换与卡顿排查.md](播放源切换与卡顿排查.md)。

| 现象 | 先做这一步 |
| --- | --- |
| 一直缓冲、转圈 | 换源 |
| 黑屏但进度条在走 | 换源 |
| 只有声音没画面 | 换源 |
| 某一集点不开，其他集正常 | 只换这一集的源 |
| 所有片子都打不开 | 换网络，不是片子的问题 |
| 画面掉帧、发烫 | 关掉省电模式，降一档清晰度 |
| 字幕不显示 | 这条源可能没带字幕，换源试 |

## 五、耗电、流量与后台

| 现象 | 说明与处理 |
| --- | --- |
| 看剧时手机发烫 | 高清晰度解码的常态，降一档清晰度、别边充边看会好一些 |
| 后台一会儿就被杀掉 | 到手机设置的应用管理里，把它的省电策略设为「无限制」，并允许后台活动 |
| 流量用得比预计快 | 高清晰度一集几百 M，出门前用 WiFi 缓存好；关掉「仅用流量时自动播放」这类开关 |
| 待机也掉电 | 用完从多任务里划掉，别让它挂在后台 |

## 六、投屏环节

投屏的完整排查顺序在 [投屏到电视怎么看.md](投屏到电视怎么看.md) 第三节，这里只列最容易漏的三条：

- 手机和电视必须在同一个 WiFi 下，手机走流量时一定搜不到设备。
- 电视端的投屏入口要先打开、停在等待连接的界面。
- 路由器的「AP 隔离」开着会挡住设备互相发现，需要登录路由器后台关掉。

## 七、关于更新和卸载

- **提示更新**：如果应用内弹更新提示，更新后版本可能不再是 5.3.2，那不是本篇描述的版本。想保持在网盘里那一版，就别点更新。
- **卸载**：在手机设置的应用管理里卸载。卸载会同时清掉这个应用的缓存影片和本地记录，如果里面有已经下好的内容，先确认不再需要了再卸。
- **卸载后残留**：卸载完到手机存储里看一下可用空间有没有回来；如果少了几个 G，多半是缓存目录没被清掉，手动删掉那个以应用名命名的文件夹即可。

## 八、还是没解决的问题

按这个思路缩小范围，比在本篇里反复找条目有效：

1. **确定是普遍问题还是个别问题**——换一部片、换一个网络各试一次。换个片子就好了，那是那个片子挂的源的问题，不是你手机的问题。
2. **确定是应用问题还是系统问题**——打开手机里另一个视频类应用，如果它也不正常，问题在手机系统或网络。
3. **确定是不是版本问题**——如果你已经点过更新，先卸载再装回网盘里那一版（5.3.2）看看现象是否消失。
