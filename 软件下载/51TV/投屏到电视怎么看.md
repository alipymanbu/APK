## 一、投屏前先满足两个前提

这两条缺一条，后面怎么点都不会成功：

1. **手机和电视（或电视盒子）连的是同一个网络**。判断标准就一条：两台设备是不是挂在同一个路由器下面。家里有 2.4G 和 5G 两个信号时，只要路由器没做隔离，多数情况下能互通；但如果手机自己开着热点、电视连的却是家里 WiFi，或者电视连的是光猫自带的另一个 WiFi，两边就不在同一个网里，一定搜不到。（反过来把电视连上手机热点，两边就同网了，这个招数第四节能用来自测。）
2. **电视那头支持接收投屏**。2016 年之后的智能电视多数自带投屏功能（协议上叫 DLNA 或 Miracast，各品牌叫法不同）；老电视接一个安卓盒子也行。电视和盒子都不支持的，中间加一个投屏器插在 HDMI 口上也能用。

第 2 条拿不准的时候，直接问电视品牌型号对应的客服最快，别在手机上反复试。

## 二、投屏的具体步骤

1. 先把电视打开，切到投屏相关的界面。海信、创维、TCL 这类一般在「我的应用」里有个「无线投屏」「多屏互动」之类的入口，打开后它会显示等待连接。
2. 手机连上和电视相同的 WiFi。
3. 在 51TV 里找到要看的片子，进入播放页。
4. 点播放画面上方或右上角的 **TV** 图标（就是那个小电视形状的按钮）。
5. 弹出设备列表后，选中你家的电视名称，等两三秒连上。
6. 电视上开始播放后，手机这一端可以继续当遥控器用，也可以放到一边。

投屏成功后如果只是手机屏幕镜像过去了、画质模糊，说明走的是「屏幕镜像」而不是应用内投屏；退出重来一次，从应用内的 TV 按钮进，走的是更省电也更清晰的这条路。

## 三、设备列表搜不到电视时，按顺序查这五条

| 顺序 | 查什么 | 具体怎么做 |
| --- | --- | --- |
| 1 | 是不是同一个 WiFi | 手机上关掉移动数据，确认连的 WiFi 名和电视上显示的一致 |
| 2 | 电视端的投屏功能开了没 | 回电视上打开「无线投屏」入口，让它停在等待连接的界面 |
| 3 | 路由器有没有开 AP 隔离 | 登录路由器后台，关掉「AP 隔离 / 客户端隔离」，这个开关会挡住设备互相发现 |
| 4 | 权限给全了没 | 手机上检查 51TV 有没有被授予「附近的设备 / 局域网」这类权限（老一点的系统上这项在「定位」里），缺了会搜不到 |
| 5 | 重启一遍 | 电视和盒子断电重开，手机 WiFi 断开重连，然后再搜一次 |

这五条走完还是搜不到，问题基本在电视那一端，跟手机上的应用没关系了。

## 四、几个开关会悄悄破坏投屏

设备能搜到、也连上了，但中途断，或者明明在同一个 WiFi 下永远搜不到——问题常常出在下面这几个开关上。它们的名字里都不带「投屏」两个字，所以最容易被漏掉：

| 开关 | 在哪找 | 为什么会挡 |
| --- | --- | --- |
| WLAN+ / 智能网络切换 | 手机的 WiFi 设置里 | 信号一弱它就自动切到移动数据，等于换了个网络，投屏随即断开。投屏期间先关掉 |
| 双频合一 | 路由器后台 | 手机走 5G、电视走 2.4G 时两台设备可能互相看不见。临时关掉双频合一，或让两者连到同一个频段 |
| 定位权限 | 手机设置 → 应用 → 51TV → 权限 | 安卓上应用要先拿到网段信息才能发现设备，这项没给就搜不到 |
| 公共场所限制 | 电视端设置（小米电视在 设置 → 账号与安全 → 公共场所限制） | 开着时会直接拒绝接收投屏，需要关掉 |

**想一次判断问题出在哪端，用手机热点试**：打开手机热点，让电视连上这个热点，再投一次。能投上去，说明是路由器的问题（多半是双频或 AP 隔离）；还是不行，问题在电视那一端。

## 五、投屏连上之后，手机能做什么

- **控制播放**：拖动进度条、暂停继续、调音量、换清晰度、选集，这些都是从手机上操作的。
- **手机同时能另外用**：不少应用支持投屏后手机切到别的页面，但能不能这么做取决于该片的播放方式，试一下就知道了——如果一切走手机就断，那就老老实实把手机放在旁边。
- **中途换片**：换另一部片子时，多数情况下要重新点一次 TV 图标重新连接，不是无缝切换。

## 六、投屏卡顿、断流、有声音没画面

| 现象 | 先查这个 |
| --- | --- |
| 画面卡顿、不断缓冲 | 路由器旁边别同时有大文件下载或另一路投屏；把清晰度从最高档往下调一档 |
| 播一会儿自己断开 | 手机有没有自动锁屏后被系统深度省电冻结，见 [常见问题与排查.md](常见问题与排查.md) 第五节 |
| 有声音没画面 | 换一个播放源再投一次，多半是这个源本身的问题，见 [播放源切换与卡顿排查.md](播放源切换与卡顿排查.md) |
| 电视上画面比例不对、有黑边 | 在电视遥控器上按「画面比例」或「屏幕缩放」，切到自适应模式 |

投屏本身不额外消耗什么，但它对网络稳定性的要求比手机本地播放高——手机播着不卡不代表投到电视上也不卡，因为画面要实时转出去。
