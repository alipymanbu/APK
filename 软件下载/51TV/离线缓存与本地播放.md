## 一、缓存之前先接受三件事

1. **这个功能要登录**。公开介绍把「需要登录才能使用」写得很明确，缓存和收藏一样，都挂在账号上。
2. **不是每一集都能缓存**。能不能下载取决于这一条源是否允许，同一个剧里有的集能下、有的集点不动，是常事，不是你的手机坏了。遇到下不了的集数，换一条源再看缓存按钮是否可点。
3. **缓存的量要提前想好**。一整季电视剧按每集几百 M 算，几个 G 起步。出门前用 WiFi 下，别用流量下。

## 二、缓存一部片子的步骤

1. 进入想看的片子，打开播放页。
2. 在播放界面找到下载按钮（多在右上角的菜单区，图标是向下箭头）。
3. 点开后进入选集界面，勾选要缓存的集数。可以整季全选，也可以只挑中间几集。
4. 确认后开始下载，界面上会出现进度。想一次下多部，回到列表重复上面的动作即可。

下载过程中把应用切到后台一般不会中断，但如果被系统省电策略清掉了进程，进度会停住，见第五节。

## 三、下载好的内容在哪看

- **应用内**：一般在「我的」或播放页的下载入口里，能看到正在下载和已完成两个列表，已完成的那部分直接从那里点开播放，不消耗流量。
- **文件管理器里找不到文件是正常的**。这类应用把缓存放在自己的私有目录里，普通文件管理器看不到，也不建议手动去挪动——挪走之后应用就认不出来了。
- **安卓 11 之后连 `Android/data` 都不给进了**。系统从这一代开始限制文件管理器访问应用数据目录，所以就算你用数据线把手机连到电脑，也照样翻不到缓存文件。这不是应用特意藏起来，是系统层面的限制，换个文件管理器也一样。

所以判断缓存占了多少空间，看的是手机设置里的存储统计，不是去找具体文件：

| 看哪里 | 能看到什么 |
| --- | --- |
| 设置 → 应用 → 找到 51TV → 存储 | 应用占用的总空间，缓存越多这里越大 |
| 设置 → 存储 | 手机整体还剩多少可用空间 |

## 四、缓存占空间太多，怎么清

在应用内的下载管理里删，是最稳妥的方式：

1. 进入下载管理，切到「已完成」。
2. 选中看完的剧集，长按或者点右上角的编辑，批量删除。
3. 确认删除后，空间才会真正释放。

如果应用里删不动、或者想一次清干净，可以在手机设置的「应用 → 51TV → 存储」里点「清除缓存」。注意这两个按钮的区别：

| 按钮 | 后果 |
| --- | --- |
| 清除缓存 | 删掉缓存的影片，账号和设置一般保留 |
| 清除数据 | 相当于把应用恢复成刚装好的状态，登录状态、本地记录全没了，需要重新登录 |

优先用第一个。第二个只在应用出了乱七八糟的问题、需要「重新来一遍」时才用。

## 五、缓存中断或进度不动

- **进度卡在 0% 不动**：换一条源，缓存走的是当前选中的那条源。
- **下到一半停了**：先看网络是否还连着；再确认手机没有把应用的后台活动冻结（省电模式是最常见的原因）。
- **明明有空间却提示存储不足**：缓存过程中会有临时占用，剩余空间要明显多于要缓存的总量才稳。先清出更多空间再试。
- **换手机后缓存没了**：缓存文件存在本机上，不跟着账号走。换机后需要在新的手机上重新缓存。这一点和收藏、播放历史不同，后者会跟着账号同步。

## 六、没有网络的时候能做什么

| 状态 | 能做的事 |
| --- | --- |
| 完全无网（飞行模式） | 只能播已缓存完成的内容，其他一律打不开 |
| 只有流量 | 能正常用，但注意消耗——高清晰度一集剧几百 M，别在没 WiFi 的时候随手缓存 |
| WiFi 换到流量 | 已经缓存好的内容照常播，不受影响 |

出门前留十分钟把要看的集数缓存完，是这类应用最省心的用法：飞机上、地铁里、信号差的酒店，都不受影响。
