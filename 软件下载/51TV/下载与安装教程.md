## 一、装之前先对一遍版本和要求

下面这些是网盘里那份包的实际信息。网上搜到的「最新版」常常已经是另一个版本号，装之前以这张表为准，装完在应用里核对也对得上。

| 项目 | 值 |
| --- | --- |
| 应用名 | 51TV（部分应用商店写作「51看剧」） |
| 包名 | `app.kanju.app` |
| 版本 | 5.3.2 |
| 安装包大小 | 55.79M |
| 安装包 MD5 | `4BFDBF23AF2734A056A8A39C1593803C` |
| 系统要求 | 安卓 5.2 及以上 |
| 界面语言 | 简体中文 |

三条判断：

- 手机系统低于安卓 5.2 的，装上去多半是装完闪退或直接提示不兼容，不用折腾。
- 手机存储要有 60M 以上的空闲空间，安装包本身 55.79M，装完还会占一点。
- 这个包是手机端应用，不是给电视盒子或电脑直接用的；想在大屏上看，走投屏这条路，步骤见 [投屏到电视怎么看.md](投屏到电视怎么看.md)。

## 二、从网盘把安装包取到手机

1. 打开 [51TV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0c6bfb06a54d)。
2. 先点「保存到我的网盘」，再下载。直接下载也能用，但转存到自己的网盘之后，原分享链接以后失效了也不影响你。
3. 等文件下载完，记下它在手机里的位置，多数浏览器会放在「下载」或「Download」目录。
4. 文件名通常形如 `51TV_v5.3.2.apk`，以网盘里实际显示的名字为准。

如果打开链接提示失效或需要提取码，说明这条分享已经不是当前状态，换成最新的一条再试。

## 三、动手装之前校验一下包

安装包从网络传到手机，中间出过错的话，装的时候会报「解析包错误」。花半分钟校验一次，能省掉后面一堆莫名其妙的排查。

用电脑校验最省事，把 APK 拷到电脑上，在文件所在目录执行：

```powershell
certutil -hashfile "51TV_v5.3.2.apk" MD5
```

输出的十六进制串去掉空格后，应该和第一节表里的 `4BFDBF23AF2734A056A8A39C1593803C` 完全一致（大小写不敏感）。手机上也可以用带 MD5 校验功能的文件管理器做同样的事。

对不上就重新下载一次，别将就着装。

## 四、先去系统里放行「未知来源」

网盘里的包不是从应用商店装的，安卓默认会拦一次。要先给下载它的那个应用（浏览器或夸克）开安装权限，各品牌路径不一样：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 权限管理 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装外部来源应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 生物识别和安全 → 安装未知应用 |
| 原生安卓 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

路径记不住没关系，在设置顶部的搜索框里直接搜「未知应用」或「外部来源」，基本都能跳到同一页。找到负责下载的那个应用，把开关打开。

## 五、安装与第一次打开

1. 从通知栏点刚下载完的文件，或者打开文件管理器找到那个 `.apk` 点它。
2. 弹出安装界面点「安装」，等进度走完，桌面出现图标。
3. 图标下方显示的名称以安装后实际显示为准，可能写作「51TV」也可能是「51看剧」，不用因为名字对不上就怀疑装错了——认包名更可靠（核对方法见 [常见问题与排查.md](常见问题与排查.md) 第一节）。
4. 首次启动会依次弹权限申请。真正影响功能的是这几项：

| 权限 | 不给会怎样 |
| --- | --- |
| 存储 / 照片和视频 | 缓存下载用不了，播放记录也可能写不进去 |
| 网络 | 打不开内容 |
| 通知 | 只影响推送提醒，不影响观看 |
| 附近的设备 / 局域网 | 投屏搜不到电视 |

具体弹哪几项、叫什么名字，以你手机上实际弹出的为准，上面只是它们各自的用途。

5. 启动后如果直接要求登录，正常，这个应用多数功能要登录才展开，见 [注册登录与多设备同步.md](注册登录与多设备同步.md)。

## 六、装不上或者装完打不开

按这个顺序自查，比反复重装有效：

- 提示「解析包错误」「应用未安装」→ 回到第三节重新校验 MD5，文件多半没下完整。
- 提示「已被阻止安装」→ 第四节的未知来源权限没开，或开了但给错了应用。
- 装好后点图标没反应、闪一下退回桌面 → 看手机系统版本是否低于安卓 5.2；仍不行的，到 [常见问题与排查.md](常见问题与排查.md) 第三节按「闪退」一条排查。
- 装到一半提示空间不足 → 先清出不小于安装包大小的空间再试，安卓在安装时要额外留出余量。
