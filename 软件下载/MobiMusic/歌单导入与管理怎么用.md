## 一、导入歌单的完整步骤

MobiMusic 支持把其他平台的歌单按 ID 搬进来，不用一首首重新搜。通用流程：

1. 点底部导航栏的**歌单**，进入歌单管理页。
2. 点右上角的**三个点**图标，打开更多功能菜单。
3. 选择**导入歌单**，进入导入设置界面。
4. 选择来源平台（QQ 音乐 / 网易云音乐 / 酷我音乐等），把歌单 ID 填进去，点确定完成导入。

**歌单 ID 从哪拿**：到原平台的歌单详情页，点「分享」，分享文案里那串数字或字母就是歌单 ID（有的版本分享出来直接是链接，粘进去也行，新版本会自动识别来源平台）。歌单 ID 可以直接显示在歌单详情的更多菜单里，能复制就复制。

导入后歌单里的歌曲会按原顺序排好，曲名、歌手都保留 —— 但能不能全放出来取决于当前音源里有没有这些歌，缺的那几首等切换音源后可以手动补。

## 二、自建歌单怎么管理

- **新建**：歌单页点「新建歌单」，起个名字（比如「通勤」「跑步」「老歌」），建好后往里加歌。
- **加歌**：播放页或歌曲列表的「加到歌单」入口，选目标歌单即可；同一首歌可以进多个歌单。
- **删除歌曲**：在歌单里长按或滑动调出删除，新版本会弹确认框，防止误删。
- **跨歌单移动**：把歌从一个歌单添加到另一个歌单，入口和加歌相同（早期版本存在添加无效的问题，遇到就升级版本再试）。

## 三、收藏与云同步

- **收藏**：播放页的红心 / 收藏会把歌存进你的收藏列表，跟自建歌单分开管理。
- **云同步**：切到「云端」板块，开启云同步后，本地歌单和收藏会备份上去，换手机登录同一个状态就能恢复。同步依赖网络，开关和恢复入口都在云端页内。
- **注意**：云同步备份的是**歌单清单**（歌名、顺序），不是音频文件本身。下载到本地的歌换设备后要重新下载，见 [歌曲下载与本地音乐管理.md](歌曲下载与本地音乐管理.md)。

## 四、导入失败或导入后缺歌怎么办

按下面顺序排查，多数情况能解决：

1. **ID 填错了** —— 分享文案里除了 ID 还常带标题和链接，只粘 ID 那一串；有的平台分享出来是整条链接，直接粘链接、让应用自己识别。
2. **平台选错了** —— 来源平台要和歌单实际所在的应用一致，选错会解析失败。
3. **导入成功但少了几首** —— 说明当前音源没有这几首的版权或资源，换音源（见 [搜索与在线听歌教程.md](搜索与在线听歌教程.md)）后到原歌单里手动补搜。
4. **歌单太长导入超时** —— 几百首的大歌单在网络差时容易中断，换个稳定网络重试一次。

还不行就看 [常见问题与解决办法.md](常见问题与解决办法.md) 里对应的排查条目。
