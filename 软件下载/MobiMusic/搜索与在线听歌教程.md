## 一、先搞懂「音源」这件事

MobiMusic 自己不存歌曲，你听到的歌来自它接入的几条音源线路（QQ 音乐、网易云音乐、酷我音乐等）。这决定了两件你会天天碰到的事：

- **同一首歌在不同音源里结果不一样**。这条线路没有、换一条可能就有了；音质档位也随音源而变。
- **某条线路突然没反应，不等于应用坏了**。线路会抽风，切换音源通常就能继续听，排查步骤见 [常见问题与解决办法.md](常见问题与解决办法.md)。

首页默认展示的是网易云的榜单，界面右上角有当前音源标识，点它就能切换到 QQ 音乐、酷我等其他榜单源 —— 榜单和搜索结果都会跟着换。

## 二、从发现页找歌

打开应用进的就是发现页，你不用搜也能直接听：

- 页面顶部是**搜索框**，想听具体的歌直接输入歌曲名 / 歌手名 / 专辑名。
- 主体是各类**实时榜单**：热歌榜、新歌榜、短视频热曲榜、影视金曲榜等。榜单数据随音源平台更新，具体有哪几栏以你装的版本实际界面为准。
- 榜单列表里点任意一首就直接进播放，不需要二次确认。

## 三、搜索怎么用

1. 在搜索框输入关键词，回车或点搜索图标。
2. 结果列表按歌曲 / 歌手 / 专辑分组（以实际版本为准），点哪首播哪首。
3. 结果旁边有**聚合搜索**入口，可以切换搜索平台 —— 默认结果里没有你要的歌时，换个平台搜是最有效的第一招。
4. 搜索结果里如果标着无版权或灰色，说明这条音源确实没有，聚合搜索换源试试。

进阶一点的用法：用「歌名 + 歌手」一起搜能显著减少同名歌曲的干扰；搜专辑名则会把整张专辑的结果聚在一起，方便按专辑顺序听。

## 四、播放页能做什么

点任意一首歌进入播放页，这里的常用操作：

| 操作 | 效果 |
| --- | --- |
| 暂停 / 播放、切歌 | 底部常规控制条 |
| 拖进度条 | 快速定位到歌曲任意位置 |
| 点播放页中的歌名 | 直接带着这个词去搜索（新版本行为，老版本可能无此入口） |
| 歌词开关 | 显示 / 隐藏歌词，可开悬浮歌词在界面上层看词 |
| 下载图标 | 选音质把歌存到本地，详见 [歌曲下载与本地音乐管理.md](歌曲下载与本地音乐管理.md) |
| 加入歌单 / 收藏 | 把当前歌存进自建歌单，详见 [歌单导入与管理怎么用.md](歌单导入与管理怎么用.md) |

播放页还会提供音效与均衡器入口（不同版本叫法不同），想调就调，不调也能正常听。

## 五、后台播放与通知栏控制

切到别的应用或锁屏后，歌曲默认继续播，通知栏有快捷控制（暂停 / 切歌）。如果你的手机把 MobiMusic 的后台权限收紧了，会出现「一切走就停」的情况 —— 到 **设置 → 应用 → MobiMusic → 省电策略 / 后台运行** 里允许它后台运行即可，各品牌叫法略有差异（省电、自启动、后台弹出界面都是常见入口）。

## 六、几个设置值得先改

进「我的 → 设置」，这几项通常第一轮就该按自己习惯调：

- **默认音源**：你最常听的歌在哪条线路上，就把默认切过去，省得每次都手动换。
- **播放音质**：在线播放的默认档位。移动网络下建议选标准档省流量，Wi-Fi 下再开高音质。
- **歌词与主题**：歌词显示样式、界面主题都在这一区，按喜好改即可。

设置项的具体位置随版本略有出入，以你装的版本实际界面为准。
