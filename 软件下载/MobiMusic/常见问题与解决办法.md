# MobiMusic 常见问题与解决办法

> 播放失败、下载没反应、装不上、闪退 —— 用 MobiMusic 时最常撞到的几类问题，按症状逐条排查。

## 一、歌播不出来 / 一直加载

按这个顺序试，通常第 1 或第 2 步就能解决：

1. **换音源**。这是最常见的原因：当前线路没这首歌或线路本身抽风。播放页或搜索结果里切换音源再点一次。
2. **聚合搜索换平台搜**。默认平台没有的歌，换 QQ 音乐、网易云、酷我挨个试。
3. **检查网络**。Wi-Fi 和移动数据互切一下；能打开网页但歌加载不出来时，多是线路问题而非网络问题。
4. **重启应用**。彻底划掉再打开，让线路重新初始化。

## 二、歌曲能搜到但下载失败

- **看应用给的失败原因**（新版本会直接显示）：提示无版权 / 无资源 = 这条线路本来就没有，换音源再下。
- **音质档位选太高**：部分线路只提供 128k / 320k，选 FLAC 会失败，降一档重试。
- **存储权限没给**：到系统设置里给 MobiMusic 打开存储 / 文件访问权限，否则文件写不进去。
- **空间不足**：下载前看一眼手机剩余空间，FLAC 一首十几 MB 起步。
- **批量下载被限制**：部分音源对一次批量下载有数量上限，分几次下即可。

详细操作见 [歌曲下载与本地音乐管理.md](歌曲下载与本地音乐管理.md)。

## 三、装不上或装完闪退

1. **没给安装来源权限**：按提示到 **设置 → 应用 → 特殊应用权限 → 安装未知应用**，给下载用的浏览器或网盘开开关。
2. **包下错了**：对一下包名是不是 `com.mobimusic`、MD5 是否和 [下载与安装教程.md](下载与安装教程.md) 里那张表一致，对不上就重新下。
3. **系统版本过低**：安装包会提示最低系统要求，不满足就装不上。
4. **闪退先清缓存**：长按应用图标 → 应用信息 → 存储占用 → 清理缓存（清数据会删掉歌单等应用内数据，先想清楚再清）。
5. **权限缺项**：到应用信息 → 应用权限里，把存储等权限打开，缺权限是闪退的常见诱因。
6. **还不行就卸载重装**：重装前记下自建歌单（云同步开着的话，恢复登录状态即可找回清单）。

## 四、一切走就停 / 后台不播

手机系统在后台收紧了应用的网络和运行权限。到 **设置 → 应用 → MobiMusic** 里找省电策略、后台运行、自启动这类选项，全部放开（各品牌叫法不同）。清理后台任务时也注意别把它划掉。

## 五、歌单导入后不对劲

- 解析失败：歌单 ID 粘错了（要把分享文案里的 ID 单独粘出来，别连标题一起）、来源平台选错。
- 导入了但少歌：当前音源没那些歌的资源，换音源后手动补。
- 把歌从一个歌单加到另一个歌单没反应：这是旧版本的已知问题，升级到新版本解决。

完整步骤见 [歌单导入与管理怎么用.md](歌单导入与管理怎么用.md)。

## 六、启动时看到开屏广告

旧版本（1.4.0 之前）的开屏广告逻辑去除得不彻底，有几率偶然出现开屏广告 —— 这是版本的已知问题，不是你装错了包。升级到 1.4.0 及以上版本就没有了。收费与广告的整体情况见 [收费与广告情况.md](收费与广告情况.md)。

## 七、版本和界面对不上

网盘里那份是 **1.2.5 / 41.22M**（核对信息见 [下载与安装教程.md](下载与安装教程.md)），网上软件站的最新版已经走到 1.4.x、体积也大得多。同一篇文章配的截图可能来自更新的版本，界面按钮位置对不上很正常 —— 找不到某个入口时，先确认自己装的是哪个版本：**设置 → 应用 → MobiMusic → 应用信息**里能看到版本号。功能差异不大时按文字描述找，差得多就考虑升级。
