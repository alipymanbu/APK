## 一、下载一首歌的步骤

1. 打开目标歌曲的播放页。
2. 点顶部的**下载图标**。
3. 在弹出的音质选项里挑一档（各档含义见下表），确认。
4. 下载完成后到「我的 → 我的下载 / 下载管理」里查看。

| 音质档位 | 适合场景 |
| --- | --- |
| 128k | 省空间省流量，通勤外放、日常听个响够用 |
| 320k | 高品质 MP3，体积与音质比较均衡，多数人选这档 |
| FLAC | 无损压缩，耳机听感差别明显，体积约为 320k 的 2~3 倍 |
| FLAC 24bit | 比 FLAC 更高规格（部分版本提供），有对应设备才听得出差别 |

**不是每个音源都提供全部档位**：某首歌选不到 FLAC，通常是这条线路没这个资源，换音源再下即可。下载失败且应用给出了具体原因时，按提示处理（多是线路问题，换源重试）；新版本在一条音源下载失败时会自动换源重试。

批量下载也支持：在专辑页或歌单页可以整批下，不用一首首点（部分音源对批量下载有数量上限，以实际提示为准）。

## 二、下载的歌存在哪、怎么换位置

1. 进「我的 → 下载管理」。
2. 点右上角的**文件夹**图标。
3. 在这里可以选择 / 更改下载保存位置。

建议：

- **优先存到 SD 卡或手机存储的独立目录**，卸载重装应用前不容易把歌一起清掉。
- 换过位置后，旧位置的歌不会自动搬过去 —— 想统一的话先把旧文件移动到新目录，再让应用重新扫描。
- 存储空间紧张时定期清理：下载管理里能看到已下载内容，删掉不听的即可。

## 三、本地音乐：扫描与播放

切到「本地」板块，应用会扫描手机里的音频文件（MP3、FLAC 等常见格式都认），把你以前用别的播放器下好的歌也纳入管理。

- **首次扫描会稍慢**（新版本已优化，老版本要多等几秒），扫完列表就是你手机里全部能播的文件。
- 扫不到某首歌时按顺序查：文件是否在很深层的目录里、格式是不是少见的冷门格式（常见格式里 MP3、FLAC 是明确支持的）、有没有给应用存储权限（见 [下载与安装教程.md](下载与安装教程.md) 第五节）。
- 扫描是只读的，不会动你的原始文件；删除操作要在确认后才会真删文件。

## 四、离线场景怎么用

- 已下载的歌在**断网时照常播放**，入口在下载管理或本地音乐里，不依赖网络。
- 在线播放才耗流量；流量紧张时，到设置里把默认播放音质调低一档（入口见 [搜索与在线听歌教程.md](搜索与在线听歌教程.md) 第六节），下载则留到 Wi-Fi 下再做。
- 想知道流量花在哪了，新版本的「流量消耗日志」会按应用记录消耗，入口在我的或设置页。

## 五、下载相关问题

下载失败、找不到下载的文件、播放本地文件报错，先看 [常见问题与解决办法.md](常见问题与解决办法.md) 里的对应条目 —— 绝大多数是音源没资源（换源）、存储权限没给、或者下载目录被系统清理这三种原因。
