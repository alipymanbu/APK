## 一、先搞懂「战斗配置」这个概念

FGA 里真正决定「怎么打」的是一份**战斗配置（Battle Config）**：它记录你这套队伍第几回合放哪个技能、用哪几张指令卡、选哪个助战、刷多少次。你可以建多份配置——比如「活动 3 加成队」「周回暴击队」各一份，跑哪个本就切哪份，不用每次重填。

你在 FGA 主界面看到的 `Battle`、`Lottery` 这类条目是**脚本**（干什么活），战斗配置是**参数**（怎么干）。第一次上手只需要先建一份配置并选中它，之后点播放就直接用这份配置开跑。

## 二、技能释放序列怎么写

在战斗配置里点「技能序列 / Skill Maker」，你会拿到一个按回合组织的编辑界面，往里加动作即可。常用动作：

| 动作 | 含义 |
| --- | --- |
| 从者技能 1~9 | 前排三个从者各自的三个技能，按屏幕位置从左到右数 |
| 御主技能 1~3 | 御主礼装的三个技能；需要选目标就再点目标从者 |
| 换人（Order Change） | 编入了换人礼装时用：先点换人技能，再选下场与上场的从者 |
| 宝具 | 第几回合放哪位从者的宝具（如 `NP1` 表示第一位放宝具） |
| 指令卡 | 本回合打哪几张卡（不填则由它的默认选卡逻辑补） |

几个实战上的注意点：

- **技能动画时间可以加等待**。如果你的从者技能动画特别长，点太快会和画面不同步，可在该动作后加一点等待时间；拿不准就先照默认跑一遍，卡了再加。
- **不确认技能会拖慢速度**：FGO 设置里如果有「技能使用确认」，关掉它，脚本少点一次确认、跑得更快也更稳。
- **敌人消失动画同理**，游戏设置里把动画速度调成二倍速，能明显缩短单场时间。

## 三、指令卡选择

同一份配置里可以指定选卡策略，常见两种：

- **指定卡序**：直接写死打哪几张卡（比如固定宝具 + 两张色卡），适合队伍固定、打法固定的周回。
- **默认逻辑**：不写死时 FGA 按自己的优先级挑卡。你要做的只是别把矛盾的开关同时打开（比如既指定卡序又开暴击优先）。

默认逻辑之下还有几个可调的优先级开关（不同版本界面措辞略有差异）：

| 开关 | 效果 | 什么时候开 |
| --- | --- | --- |
| 从者优先 | 优先打指定从者的卡 | 队伍里有一位核心输出、想让宝具后的指令卡集中到他身上 |
| 暴击星优先 | 优先选暴击率高的卡（高暴击率区间才触发） | 队伍靠暴击打输出、上一回合攒了星星 |
| 跳过从者卡面检查 | 选卡更快，但可能选到较弱的卡 | 追求速度且队伍练度碾压时 |

选卡只影响指令阶段；技能与宝具怎么放仍以第二节的序列为准，两者叠加成一整回合的行动。

## 四、全局设置里值得动的几项

战斗配置之外还有一层全局设置，对所有脚本生效：

| 设置 | 建议 |
| --- | --- |
| 游戏服务器 | 默认「自动检测」即可；检测错了手动指定（见第五节） |
| 跳过剧情 | 刷本时开着，遇到剧情直接跳 |
| 补充 AP（体力） | 可选用苹果；**圣晶石补充默认藏起来，别开**——那是真金白银 |
| 掉落截图 | 想统计掉落就开，会往相册/目录里存图 |
| 助战从者按自己人处理 | 助战放技能时当自己人算，队伍带助战输出时有用 |

另外两组「什么时候停」的条件也值得先想好，免得它把你的心血（体力、苹果）一口气耗光：

- **次数限制**：刷够 N 场就停，配苹果剩余数量一起用——先设小数试跑一轮，确认流程没问题再放大。
- **退出条件**：体力耗尽停、背包 / 礼物箱满了停、遇到首通奖励停，这类开关命中即正常退出，不是故障。哪次「它自己停了」，先回想是不是命中了这些条件，再去 [常见问题与解决方法.md](常见问题与解决方法.md#三脚本跑一半自己停了) 对号入座。

## 五、脚本类型与服务器

点播放后弹出的脚本选项里，日常用得到的：

- `Battle`：主战场，刷本、活动本都用它，配合战斗配置跑。
- `Lottery`：活动抽奖池连抽，刷完素材自动把池子抽空。
- `Friend Gacha`：好友点数卡池，每天清一次。
- `Gift Box`：领取礼物箱，防止箱子满了漏奖励。

服务器方面，FGA 支持日服、国服、台服、美服、韩服等主要服务器（有的版本还区分同服务器的不同客户端变体），默认自动检测——它靠无障碍服务识别当前运行的是哪个 FGO 包。检测失灵时到全局设置里手动指定对应服务器即可，各服务器的资源与识别图是分开适配的，选错了脚本会认不出界面。

## 六、一份配置的典型填法

以最常见的「三回合速刷周回」为例：

1. 新建战斗配置，起个能认出来的名字。
2. 技能序列：第 1 回合放哪几个增伤技能 → 第 1 回合放哪位宝具 → 第 2、3 回合同理。
3. 指令卡：指定卡序或留默认。
4. 助战：切到 [助战选择设置教程.md](助战选择设置教程.md) 指定要抱的从者与礼装。
5. 次数与体力：填想刷的场数、用不用苹果。
6. 保存并选中这份配置，进游戏点播放。

跑不动或者跑一半出岔子，按 [常见问题与解决方法.md](常见问题与解决方法.md) 对症排查。
