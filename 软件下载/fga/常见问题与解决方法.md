## 一、无障碍服务自己关掉了（跑着跑着没反应）

**症状**：昨天还好好的，今天脚本点了没动静；到系统设置里一看，FGA 的无障碍服务不知道什么时候被系统关了。

**原因与处理**：安卓会以「省电」为名回收长时间后台的服务，无障碍是重灾区。做三件事：

1. 系统电池设置里把 FGA 设为「无限制 / 不优化」，部分厂商（小米、OPPO、vivo、华为等）还要额外允许**后台运行**与**自启动**。
2. 到无障碍列表里把 FGA 的服务关一次再开——直接开往往没反应，切一下才生效。
3. 改完设置后重启一次手机再测，让系统记住豁免。

若你的系统有「锁定后台」（最近任务里下拉加锁），把 FGA 也锁上。各品牌（小米 / OPPO / vivo / 华为 / 三星）的具体菜单路径整理成了单独一篇：[手机后台保活设置.md](手机后台保活设置.md)，照着填完再回来测。

## 二、Android 13 侧载安装后无障碍开不了（受限设置）

**症状**：在无障碍设置里，FGA 的开关是灰的，提示「受限设置」或「此设置已被管理员限制」。

**原因**：Android 13 起，**不是从应用商店装的 APK** 默认不许开无障碍，防止流氓软件偷偷拿权限。这是系统策略，不是安装坏了。

**处理**（菜单措辞各厂商略有差异）：

1. 设置 → 应用 → 找到 FGA → 右上角菜单里选「允许受限制的设置」（有的叫「解除限制」）。
2. 确认后再回无障碍列表，开关就能打开了。
3. 部分机型找不到该菜单，可先到「设置 → 安全」里临时关闭相关限制，开启无障碍后再恢复。

## 三、脚本跑一半自己停了

**症状**：脚本正常跑了若干场，中途自己结束了，FGA 通知也还在或已消失。

按出现频率排查：

1. **系统杀了后台**——见第一节，电池白名单没做全。锁屏挂机前先确认通知栏的 FGA 前台服务通知还在；通知没了就是被杀。
2. **截屏权限掉了**——媒体投影授权被系统回收，脚本识别不了画面只能停。到 FGA 里把服务关一次再开，重新点「立即开始」授权；根治办法是给 FGA 开自动截屏授权（路径因厂商而异）。设备已 root 的话，可在高级设置里改用 root 截图模式，摆脱每次授权。
3. **体力补充的停止条件命中**——你设了刷若干场或用完某种苹果就停，属正常行为不是故障。
4. **触发了停止开关**——部分版本支持「礼装掉落就停」「首次通关奖励就停」这类开关，命中即正常退出。

## 四、点播放没反应 / 悬浮按钮不见了

1. **悬浮窗权限没给**——播放按钮本身是悬浮层，没权限就画不出来。到系统「显示在其他应用上层」里给 FGA 打开。
2. **按钮在但点不动**——检查无障碍是否开着（第一节），点击动作靠无障碍执行，关了就只有个壳。
3. **按钮被游戏挡住了**——部分全屏游戏会盖住悬浮层，把 FGA 的悬浮窗层级调高（厂商「后台弹出界面」权限也顺手开一下）。
4. 还不行就两个 App 都重启：先关 FGA 服务，再杀掉 FGO 重进，顺序反了容易出现授权串了的问题。

## 五、点的位置不准（点击偏移）

**症状**：脚本在点空白处、或总差那么一点距离，图像也「认不出」。

1. **刘海屏 / 挖孔屏 / 手动改了游戏分辨率**——识别以画面区域为基准，画面被裁或被黑边挡住就会整体偏移。先把游戏内分辨率设为默认的高清档，别用「自定义区域」类的缩放选项；有「画面缩放/游戏画面区域」设置的机型恢复默认。
2. **平板与折叠屏**——横竖屏方向要与游戏一致，展开/折叠后重新跑一次脚本（画面尺寸变了）。
3. **系统显示大小/字体缩放被调过**——改回默认再试，界面布局一变，识别坐标全部失效。
4. 以上都正常但就是偏，重开一次 FGA 服务让它重新截屏校准。

## 六、脚本卡在某个画面不动

**症状**：不报错也不停止，就停在某个界面不点下一步。

1. **先看是不是弹窗挡住了**——游戏公告、签到、掉线重连提示、升级弹窗，这些非常规画面它有时不认识。手动关掉弹窗，脚本通常自己就接上了。
2. **别让别的悬浮物压在游戏上**——录屏工具、游戏加速浮窗、另一款脚本的按钮都会干扰识别。全部关掉再跑。
3. **游戏大更新后新增了界面**——识别图没跟上就会卡。等 FGA 更新到适配新版本的构建（官方发布页下载最新版），或到其 GitHub 的 issues 里看是否已知问题。
4. **剧情对话没跳过**——若剧情未自动跳过，卡在对话框上，检查全局设置里的「跳过剧情」是否开启。

## 七、助战一直匹配不上

这不是系统问题而是配置问题，单独一篇讲了排查顺序：见 [助战选择设置教程.md](助战选择设置教程.md) 第五节。最常见的两个原因是条件勾太多、礼装图过期。

## 八、还有问题去哪问

FGA 是开源项目，官方站点有 Troubleshooting 指引，问题多半已有人问过：

- 官方排错页：[Troubleshooting Guide](https://github.com/Fate-Grand-Automata/FGA/wiki/Troubleshooting)

提 issue 时带上：手机型号与系统版本、FGA 版本（安装包信息见 [下载与安装教程.md](下载与安装教程.md) 第二节）、卡住时的界面截图，能省掉大半来回。
