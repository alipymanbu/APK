# FGA 手机后台保活设置

> 按品牌给出现成的设置路径：怎么让 FGA 锁屏挂机时不被系统杀掉，以及怎么验证设置生效了。

## 一、为什么挂机会被杀

FGA 靠一个常驻后台的服务维持运行：截屏识别画面、经无障碍执行点击。你一锁屏，安卓的省电机制（Doze 休眠）就开始削减后台活动；而小米、OPPO、vivo、华为、三星这些厂商在原生机制之上还叠了自己的「应用清理」，激进得多——**实际挂机挂不住，几乎都是厂商那一层干的**，原生安卓反而温和。

所以要做的不是「优化 FGA」，而是**逐层把 FGA 从省电管控里放出来**。下面按品牌给路径；菜单措辞随系统版本不同略有差异，以你手机上实际显示为准。

## 二、先做这三件通用设置

无论什么品牌，先把这三步做了，能解决大部分被杀的情况：

1. **电池优化白名单**：设置 → 电池 → 电池优化（有的在「更多电池设置」里）→ 找到 FGA → 选「不优化」。
2. **最近任务锁定**：打开 FGA 后进多任务（最近应用）界面，把 FGA 的卡片下拉或点锁图标加上锁——加锁的卡片不会被「一键清理」清掉。这一步防的是你顺手清后台时把它带走。
3. **关掉省电模式**：设置 → 电池 → 关闭「省电模式 / 低电量模式」。省电模式一开，上面两条都可能被系统压回去。

## 三、各品牌的针对性设置

| 品牌 | 要动的设置 |
| --- | --- |
| 小米（MIUI / HyperOS） | 设置 → 应用设置 → 应用管理 → FGA → 省电策略 → **无限制**；再到手机管家 / 安全中心的「自启动管理」里允许 FGA 自启动。HyperOS 的部分开关在「应用权限 → 后台启动」里 |
| OPPO（ColorOS） | 设置 → 电池 → 关闭「智能耗电保护」，进「自定义耗电保护 / 耗电保护」找到 FGA 选**允许后台运行**（低版本路径是关掉「后台冻结」与「检测到异常时自动优化」）；另在「应用管理 → 自启动」里放行 |
| vivo（Funtouch / OriginOS） | 设置 → 电池 → **后台高耗电** → 允许 FGA；自启动需要在「权限管理 → 自启动」里手动打开——vivo 默认全部拦 |
| 华为 / 荣耀（EMUI / HarmonyOS） | 设置里搜「应用启动管理」→ 找到 FGA → 关闭「自动管理」→ 手动打开**允许后台活动**与允许自启动；再把 FGA 加进「应用启动管理」旁的省电白名单。HarmonyOS 5 起系统清理更狠，多任务下拉加锁这一步必做 |
| 三星（One UI） | 设置 → 电池 → 后台使用限制 → 把 FGA 加进「**从不休眠的应用**」；同时检查「自适应电池」里 FGA 没被归到受限组 |

两个跨品牌的坑：

- **部分厂商的限制在重启后会复位**（小米较常见）。挂机前如果刚重启过手机，进设置扫一眼 FGA 的省电策略还在不在「无限制」。
- **开发者选项里的「不保留活动」「后台进程限制」**如果被改过，会额外杀进程——没改过就不用管，改过就恢复成默认。

## 四、怎么验证设置生效了

设置改完，跑一次十分钟的实测，别等挂一夜才发现白挂：

1. 随便进一个能重复刷的本，让 FGA 跑起来。
2. 锁屏，把手机放着 10 分钟。
3. 解锁回来检查两处：**通知栏里 FGA 的前台服务通知还在不在**、**脚本是不是还在继续打**。

两处都正常才算过关。通知没了 → 是进程被杀，回第二节、第三节补设置；通知在但脚本停了 → 不是保活问题，按 [常见问题与解决方法.md](常见问题与解决方法.md) 第三节排查（多半是截屏权限掉了）。

另外提醒一句：边充边挂时如果开了「优化充电」「智能充电」之类的功能，长时间满电对电池不好，可挂机时用它、平时关掉它，按你自己的取舍来。设置做完回到 [下载与安装教程.md](下载与安装教程.md) 第六节，那里的说法和本篇是同一件事。
