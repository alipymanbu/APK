## 一、装之前先确认三件事

OTTOhub 是围绕主播 Otto（电棍）粉丝圈「吉吉国」的视频社区，社区本体是网站 [ottohub.cn](https://ottohub.cn)，安卓客户端是它的原生入口之一。动手装之前，先核对：

| 事项 | 说明 |
| --- | --- |
| 设备 | 安卓手机；iOS 用户去官方下载中心 [download.ottohub.cn](https://download.ottohub.cn/) 找对应入口，OTTOhub 有 iOS 版 |
| 安装包体积 | 本篇对应的安装包为 10.73M，手机留出少量剩余空间即可 |
| 版本 | 本安装包为 v1.5.2（2026-09-23 打包信息）；官方仍在更新，新版本以[官方下载中心](https://download.ottohub.cn/)当时显示为准 |

官方在同一下载中心还提供同系列的其他产品：**OTTOMEDIA**（iOS、macOS、Android、Windows）与 **OTTOhub静画**（Android、iOS），需要时也在 [download.ottohub.cn](https://download.ottohub.cn/) 一并获取。

不想装客户端也可以直接用手机浏览器访问移动版网页 [m.ottohub.cn](https://m.ottohub.cn)，功能与社区内容一致，只是没有客户端顺手。

## 二、获取安装文件

两种来源，按需选一种：

1. **本篇提供的离线包**：从「OTTOhub 安装文件资源（夸克网盘）」（见本页顶部）转存后下载 `ottohub_vv1.5.2.apk`。适合手机浏览器直接下载不便、或想留一份安装包备份的情况。
2. **官方渠道**：打开 [download.ottohub.cn](https://download.ottohub.cn/)，在 OTTOhub 一栏选 Android。想始终用最新版，走这条。

无论哪种来源，装之前都可以按下一节的方法核对文件完整性。

## 三、安装步骤

1. 把 `.apk` 文件传到手机（如果是在电脑上下载的），或直接在手机上完成下载。
2. 在文件管理器里点开这个 apk。第一次装会弹「未知来源 / 允许安装未知应用」提示，按手机提示允许对应文件管理器或浏览器的安装权限。
3. 点「安装」，等进度走完。
4. 打开 app，能看到社区首页即为成功。要发弹幕、评论、投稿这些互动，需要先有账号，流程见 [注册登录与账号等级.md](注册登录与账号等级.md)。

安装被拦截、装不上时，先看 [常见问题与解决办法.md](常见问题与解决办法.md) 的「安装失败」一节。

## 四、核对安装包完整性（可选）

下载环节出问题时，可以核对 MD5 判断文件有没有损坏。本篇安装包的 MD5 为 `C20A6177B6C3DE0107A867619263997D`。

Windows 电脑上用 PowerShell 核对：

```powershell
certutil -hashfile "D:\下载\ottohub_vv1.5.2.apk" MD5
```

输出与上面那串一致（不区分大小写）即文件完整；不一致就重新下载一遍再核对。

## 五、以后想换新版本怎么办

安卓覆盖安装即可：从官方下载中心拿到新的 apk，直接装在旧版本上面，不需要先卸载。如果覆盖安装报「签名不一致」之类错误，先卸载旧的再装新版，账号数据在服务端，登录回账号即可，具体排查见 [常见问题与解决办法.md](常见问题与解决办法.md)。
