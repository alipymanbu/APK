## 一、首页与找内容

打开 app 先看到的是社区首页。找内容有三条路：

- **分区浏览**：内容按分区归档，首页按分区挑着看，想看音 MAD 就进音 MAD 的分区。
- **搜索**：顶部搜索框直接搜关键词，比如某个梗的名字；搜动态、搜视频都从这里进。
- **热议排行**：首页的热议区域把当前热度高的内容排出来，想知道最近圈子里在玩什么梗，看这里最快。

OTTOhub 的内容围绕 Otto（电棍）相关创作展开：鬼畜、音 MAD、二创、直播切片，也有用户日常向的动态闲聊。推荐位本身不带算法推荐，看到的基本是编辑与热度筛选的结果，想看什么更多靠你自己搜。

## 二、看视频

播放页里能用到的：

- **弹幕**：播放页带弹幕区，发弹幕需要账号到 UNO 级（50 经验），纯看不受限制。
- **评论与楼中楼**：点评论入口进入评论页，可以针对某条楼层的评论再回复一层，形成楼中楼。
- **相关内容**：播放页的推荐区域列同站的其他视频，不带算法，按序翻即可。

不少视频是从 B 站转载来的二创作品，标题或简介里会带原作信息；看到喜欢的可以顺着原作链接去原作者主页。

## 三、刷动态

动态是图文帖子流，玩法和视频区平行：

- 动态可以加标题，标题会公开展示在列表里；
- 编辑动态时支持 Markdown 基础排版，会写的可以用它把帖子排得整齐些；
- 动态区也走搜索与分区两条路找内容。

社区里不少公告、活动帖（比如投稿比赛）都发在动态区，想参与活动记得常翻。

## 四、互动方式

登录之后（注册见 [注册登录与账号等级.md](注册登录与账号等级.md)），可用的互动有：

| 动作 | 说明 |
| --- | --- |
| 点赞 / 冷藏 | 对认可的内容点赞或收藏；收藏在站内叫「冷藏」。两者都不公开展示，只有你自己在个人页能看到 |
| 评论 / 楼中楼 | 视频与动态都能评论，楼层里可以再套一层回复 |
| @某人 | 评论里 @ 对方，对方会收到站内信件提示 |
| 关注 | 关注感兴趣的用户，对方的新内容更好跟进 |
| 私信 | 站内信箱收发私信 |

发弹幕同样属于互动，但门槛比上面这些都高一点——要 UNO 级，见前文。

## 五、音乐推荐页

除了视频和动态，站内还有独立的音乐推荐与查询页，收录社区常用的曲目资源。做音 MAD、鬼畜想找素材出处，或者单纯想听圈子里流传的曲子，从这里翻。

## 六、看不懂圈里的词怎么办

刷内容时高频出现的「冷藏」「♿」「别急」「韭菜盒子」这类词，都是吉吉国圈子里的功能叫法与梗，第一次见会一头雾水。对照表见 [吉吉国用语与梗入门.md](吉吉国用语与梗入门.md)，看完基本能对上号。

## 七、看完之后

想自己动手投稿视频或发动态，先读 [投稿与社区规则须知.md](投稿与社区规则须知.md)——投稿要过人工审核，规则红线在那一篇里。碰到加载慢、按钮用不了之类的问题，去 [常见问题与解决办法.md](常见问题与解决办法.md) 对症排查。
