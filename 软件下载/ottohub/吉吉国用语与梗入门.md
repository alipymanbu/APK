## 一、吉吉国是什么

OTTOhub 的内容几乎全部围绕一个人展开：**电棍 otto**，本名侯国玉，《英雄联盟》前职业选手（先后效力 YG、V5 等队），退役后成为游戏主播，现在斗鱼直播（房间号 12306）。

- **otto 这个 ID** 的来历：他的幸运数字是 8，otto 是意大利语的「八」。
- **吉吉国王**：本名「侯国玉」写起来形近「猴国王」，加上外形被观众调侃，这个外号叫开了，连直播平台给他认证的也是「吉吉国王」。
- **吉吉国民**：粉丝群体的自称，与「吉吉国王」相对。你在 OTTOhub 注册后拿到的第一个称号就是它。
- **动物园**：电棍与炫神、山泥若等主播的粉丝群体交集密切，这几个圈子被合称为「动物园」，相关创作文化也叫「动物园文化」。

围绕他的直播语录与二创，逐渐形成了自成体系的圈层文化——「吉吉国」。OTTOhub 就是这个圈子自建的视频社区，社区百科 OTTOWiki（[wiki.ottohub.cn](https://wiki.ottohub.cn/)，与 OTTOhub 同属一个社区）负责整理这些人物与梗的来龙去脉。

## 二、站内功能词：不是梗，是功能名

这几个词你在用功能时会直接碰到，先分清哪些是功能、哪些是玩梗：

| 词 | 实际含义 |
| --- | --- |
| 冷藏 | 就是收藏。站内把收藏功能叫「冷藏」，被你冷藏的内容不公开展示，只有你自己在个人页能看到 |
| 超管 | 审核员。负责给投稿「通过 / 打回」，由达到等级的活跃用户向站长申请而来 |
| 鞍山大法庭 | 发布封禁公示的官方账号。谁被删号、为什么被删，公示都发在这里 |
| 轮椅英雄 | 给站点捐赠过的人拿到的称号。名字来自下一节的「轮椅」梗 |

## 三、内容区高频梗速查

看视频、刷动态时最常撞见的梗，按出现频率整理（来源以社区百科的整理为准，细节以 [wiki.ottohub.cn](https://wiki.ottohub.cn/) 各条目为准）：

| 梗 | 一句话解释 |
| --- | --- |
| 稳健棍 | otto 的另一个外号。出自他职业生涯的对局与采访：形容自己打法「稳健」，被观众调侃至今 |
| 轮椅 / ♿ | otto 早年腿部有伤，定制过专用电竞椅，被观众戏称坐轮椅；二创标题里大量出现 ♿ 符号，「轮椅英雄」称号也源于此 |
| 韭菜盒子 | 直播点外卖被漏送韭菜盒子，与商家对线的名场面，「那我缺的营养这一块谁给我补」成为流传语录 |
| 吹唢呐 / 愉悦送走 | 直播中回击带节奏观众的原话，衍生出「嘟嘟嘟」等调音素材 |
| 别急 | 出自二创作者 DJGun 的直播回应「主播都没急你们急什么」，现在是圈内最高频的口头禅之一，常见变体「我知道你很急，但你先别急」 |
| 德州之夜 | otto 职业生涯早期打德州扑克一夜输掉大额现金的旧事，常被拿来玩梗 |
| 海绵宝宝XX | otto 的微博 ID 叫「海绵宝宝电棍儿」，粉丝仿照这个格式起名 |
| 引流狗 | 贬义：跑到不相关的地方到处刷电棍梗的人。圈子里对这种行为反感，别学 |

## 四、新人怎么用这份对照

- **先潜水几天**。把上面的词对上号，再看视频和动态就不会一头雾水；圈内的交流方式偏抽象，硬接梗容易被认出来。
- **玩梗有边界**。在 OTTOhub 站内玩梗是常态，但跑到别的社区四处刷梗就是「引流狗」，不受欢迎；投稿相关的内容红线见 [投稿与社区规则须知.md](投稿与社区规则须知.md)。
- **想深挖去百科**。本篇只收最常用的十来个；人物、事件级别的来龙去脉，OTTOWiki 上有完整条目（如「电棍otto」「说的道理」等），社区官方账号也在站内可以直接关注。

等级、称号这些成长线的内容，见 [注册登录与账号等级.md](注册登录与账号等级.md)；具体怎么找内容、怎么互动，见 [社区功能与玩法入门.md](社区功能与玩法入门.md)。
