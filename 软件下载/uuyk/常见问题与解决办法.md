## 一、注册/登录收不到验证码

按命中率从高到低排查：

1. **短信被拦截**：查手机的短信拦截/骚扰信息文件夹，验证码经常被归进去；
2. **信号弱**：换到信号正常的位置重发，或稍等 1 分钟再点「获取验证码」；
3. **频繁重发触发限制**：短时间内连续点发送会被限流，等几分钟再试；
4. **号码填错**：确认区号与手机号无误后重新提交；
5. **关掉第三方短信拦截 App** 的验证码拦截规则后再试。

仍收不到就换个时段试；注册流程本身见 [注册与登录方法.md](注册与登录方法.md)。

## 二、安装失败 / 提示解析错误

| 现象 | 原因与处理 |
| --- | --- |
| 点 APK 无反应或被拦 | 未允许该来源安装应用，按 [下载与安装教程.md](下载与安装教程.md) 第三节放行 |
| 「解析软件包时出现问题」 | 文件下载不完整或损坏——重新下载，或校验 MD5 是否为 `27A7C1B90F32E5B87555E6DDEDF8268B` |
| 「存储空间不足」 | 清出 500M 以上可用空间再装 |
| 「与系统版本不兼容」 | 确认系统在安卓 5.0 以上；再老的机型装不了 |

## 三、打开就闪退 / 卡顿

1. **先看重启**：杀掉应用重开，多数偶发闪退到此解决；
2. **清缓存**：设置 → 应用 → uuyk → 存储 → 清除缓存（**别点清除数据**，那会退出登录、丢本机草稿）；
3. **权限是否给全**：位置、麦克风、摄像头缺权限时，部分页面一进就崩或白屏，补开权限再试（对照 [下载与安装教程.md](下载与安装教程.md) 的权限表）；
4. **系统版本过低**：安卓 5.x 跑 109M 的大包本身就吃力，卡顿属硬件瓶颈，换机或用轻量场景；
5. **重装**：以上都无效就卸载重装，账号不丢（手机号登录即可，见 [注册与登录方法.md](注册与登录方法.md)）。

## 四、匹配不到人 / 定位不准 / 收不到消息

- **按距离匹配是空的**：八成是位置权限没给或被系统「仅使用期间」限制，去系统设置把位置改为允许；
- **定位偏得离谱**：打开系统定位开关、选高精度模式，室内信号差时走到窗边；
- **别人发的消息收不到**：检查通知权限是否被系统默认关闭（国产 ROM 常见），以及是否把消息通知关了；
- **被限制互动**：未完成真人认证的账号会有限制，去个人页找认证入口。

## 五、版本对不上 / 找不到下载

- 手里装的显示 1.0.0、1.0.1 或 1.0.3 都正常：网盘这份固定是 **1.0.1 / 109.28M**，商店渠道截至 2026 年 9 月已是 **yuto 1.0.3**（2026-04-01 更新，页面标称 109.55~111.38MB）——同包名改名、版本线与渠道包差异，集中看 [yuto改名是怎么回事.md](yuto改名是怎么回事.md)；**认包名 `tm.yuuk.com`，别认应用名**；
- 同一个包在不同商店**大小、MD5 对不上不是文件坏了**（各家渠道各自打包），校验只在同一份文件内有意义，详见 [下载与安装教程.md](下载与安装教程.md) 第二节；
- 安装包随时可从 [uuyk 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b27132f1fb5b) 重新获取；
- 想确认官方渠道的当前版本，看应用宝收录页 [sj.qq.com/appdetail/tm.yuuk.com](https://sj.qq.com/appdetail/tm.yuuk.com)（以页面当时显示为准）。

## 六、一进就要充会员、要你花钱

有用户在应用宝评论区反馈「一进去就充会员」（2026-08 的评论，单一用户反馈，仅作提示）。判断要不要掏钱之前：

- **先弄清哪些要花钱**：哪些功能免费、哪些要会员，以应用内实际限制为准——注册后先把免费部分用明白，别在刚进去、还没看清价值时下单；
- **充值前看清三样**：价格与扣费周期（自动续费与否）、退款规则、充值对象是不是官方页面——凡是从聊天里发来的「充值链接」「优惠链接」一律不点；
- **礼物道具是虚拟消费**：送出即消耗，通常不可退，花之前当消费决策做。

## 七、识别交友里的钱套路

陌生交友场景里高发的骗钱套路（据各地公安反诈通报的共性套路）：

| 阶段 | 对方的话术 | 你的判断动作 |
| --- | --- | --- |
| 建立信任 | 聊得投缘、快速升温，约见面 | 正常，但别因此放松警惕 |
| 小额返利 | 让你小额付费后「返利」兑现 | 第一次就停：真返利是钓鱼 |
| 名目加码 | 「认证费」「车费」「保证金」「任务没做完」 | 任何要你继续打钱才能见面/提现的，全是套路 |
| 层层加码 | 说你「操作失误」「账户冻结」要继续垫付 | 立即停止，保存聊天与转账记录 |

三条铁律：**不见面不谈钱、任何充值只走应用内官方页面、发现异常先停手再报警（110 / 96110）**。账号安全与隐私条款见 [匹配聊天与动态广场怎么用.md](匹配聊天与动态广场怎么用.md) 与应用内《隐私政策》：[cdn.mengpaxing.com//vodMl21305651.html](http://cdn.mengpaxing.com//vodMl21305651.html)。

## 八、账号异常怎么处理

- **异地登录 / 被顶号**：立刻用手机号重新登录夺回会话，改掉能改的验证方式，检查应用内有没有「登录设备」列表、踢掉不认识的设备（没有该入口就跳过）；
- **被限制互动 / 提示违规**：多半是资料或行为触发了风控——换正常头像资料、完成真人认证后再观察；仍受限就走应用内申诉/客服入口（以应用内实际提供的渠道为准）；
- **换手机**：手机号就是账号，装回应用登录即可，见 [注册与登录方法.md](注册与登录方法.md)。
