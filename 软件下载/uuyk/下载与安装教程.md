## 一、uuyk 是什么

uuyk 是一款安卓端的陌生人社交（交友）应用，包名 `tm.yuuk.com`，由重庆蓝雨猩网络科技有限公司开发运营。你在里面按兴趣匹配陌生人、刷动态广场、用文字/语音/视频和别人聊天。它没有独立官网，主要通过应用商店与安装包渠道获取；应用宝收录页见 [sj.qq.com/appdetail/tm.yuuk.com](https://sj.qq.com/appdetail/tm.yuuk.com)——截至 2026 年 9 月该页显示的名字已是 yuto、版本 1.0.3、评分 4.50、5000+ 次下载，改名与版本来龙去脉见 [yuto改名是怎么回事.md](yuto改名是怎么回事.md)。本篇只讲「拿到安装包并装上」，装好之后怎么注册见 [注册与登录方法.md](注册与登录方法.md)。

网盘里存的是**打包时那一版**的安装包，事实如下（以这份为准，别拿商店页面的数字来对）：

从这里取 [uuyk 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b27132f1fb5b)：打开分享页 → 转存到自己的网盘 → 在网盘里下载 `uuyk_v1.0.1.apk`。文件夹里附了一份说明 txt，跟着它操作可以避免分享失效后找不到文件。

两点提醒：

- 商店渠道（应用宝、豌豆荚等）后来可能已经上架更高版本，甚至显示了别的应用名（同包名 `tm.yuuk.com` 在部分商店页面显示为 yuto）；**核对身份看包名**，别只看名字，详见 [yuto改名是怎么回事.md](yuto改名是怎么回事.md)。
- 下载完可以校验 MD5 是否与上表一致（文件管理器或校验工具均可），不一致说明文件在传输中损坏了，重新下载。**这个 MD5 只对网盘这一份有效**——商店渠道的包是各自打包的，字节数和 MD5 都不同，属正常现象。

## 三、安装步骤

1. 在手机浏览器或网盘 App 里下载 APK 文件；
2. 点击 APK，系统会弹「禁止安装未知来源应用」——这是安卓对非商店来源安装的默认拦截；
3. 按提示进入设置，允许该来源（浏览器或网盘）安装应用，返回后继续安装；
4. 等进度走完，点「打开」进入注册流程。

装完可以把「安装来源允许」关回去，下次装别的包再开即可。安装失败或提示解析错误的处理见 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 四、首次启动要给的权限

首次打开会连续弹权限申请。每一项对应的实际功能（按商店页面公示的权限用途）：

| 权限 | 不给会怎样 |
| --- | --- |
| 位置 | 用不了按距离匹配、附近的人这类功能 |
| 麦克风 | 发不了语音消息、打不了语音/视频通话 |
| 摄像头 | 拍不了照、发不了视频，真人认证也做不了 |
| 存储 | 图片缓存与相册发图受影响 |
| 电话（设备信息） | 部分风控与设备识别功能异常 |

不涉及的功能可以先拒绝，之后在系统设置里随时补开：设置 → 应用 → uuyk → 权限。完整的权限政策见官方《隐私政策》：[cdn.mengpaxing.com//vodMl21305651.html](http://cdn.mengpaxing.com//vodMl21305651.html)。

## 五、系统与空间要求

- 系统要求按商店页面标注的 **Android 5.0 以上**（最低 API 21）来准备；更老的机型以能否正常装上、跑起来为准。
- 安装包 109.28M，解压安装后占用更多，**机身可用空间最好留出 500M 以上**，空间不足会装到一半失败。
- 安卓 13/14 上首次安装第三方 APK 属正常行为，按第三节放行即可；装上后闪退的排查见 [常见问题与解决办法.md](常见问题与解决办法.md)。
