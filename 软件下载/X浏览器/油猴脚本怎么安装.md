# 油猴脚本怎么安装

> X浏览器 内置了脚本管理器，装油猴脚本不需要再装 Tampermonkey 扩展；本篇讲三种安装方式、管理入口和装了不生效怎么查。

## 一、先搞清楚：你不需要装「油猴插件」

在电脑 Chrome 上用油猴，得先装 Tampermonkey 扩展再往里装脚本。X浏览器 把这套管理器做进了浏览器本身 —— 你直接把脚本装进去就行，**不要再去找 Tampermonkey 的 apk 或扩展包**，浏览器不认第三方插件安装包，装了也是白装。

已装的脚本统一放在：**设置 → 用户脚本**（也可以在地址栏输入 `x:sc` 直接跳过去）。这里是唯一的管理入口，启用、停用、删除都在这。

## 二、三种安装方式，按你手上有什么选

### 方式一：地址栏直接打开脚本地址（最快）

你已经知道某个脚本的 `.js` 地址时：

1. 把地址粘进地址栏，回车。
2. 浏览器识别出这是用户脚本，会弹安装提示。
3. 点安装，脚本立刻出现在「设置 → 用户脚本」里。

官方文档用一个测试脚本演示这条路（`https://www.xbext.com/download/code/gm-hello.js`），装完打开 `www.example.com` 能看到它弹的对话框，可以拿它先验证脚本功能本身是通的。

### 方式二：从 Greasy Fork 网站点安装

[Greasy Fork](https://greasyfork.org/) 是最大的脚本分享站，开发者多、更新也勤。以随便一个脚本为例：

1. 打开脚本详情页，点「安装此脚本」。
2. **第一次**这么操作时，站点会弹一个对话框问你有没有脚本管理器 —— 因为 X浏览器 已经内置了，直接点「我已经安装了用户脚本管理器，让我安装」。
3. 再点一次安装，这次弹的就是浏览器自己的脚本安装提示，确认即可。
4. 装完回到「设置 → 用户脚本」能看到它。

这一步的绕弯是站点设计造成的，不是浏览器出错，记住「先点已安装、再点一次安装」就行。

### 方式三：从帮助里的测试脚本入手

设置 → 用户脚本 → 左上角「帮助」→「使用油猴脚本」→ 页面里的「测试脚本」按钮，可以直接装一个示例脚本看效果。适合第一次接触、想先确认功能没坏的场景。

## 三、装完怎么管

- **启用 / 停用**：脚本列表里逐个开关。排查问题时先把脚本全停掉再逐个开，能很快定位是哪个脚本引起的。
- **删除**：5.6.0 起，删除脚本时会一并删除这个脚本产生的数据（旧版需要你自己清）。
- **脚本选项（GM 函数）**：脚本声明的权限、`GM_cookie`、`GM_download` 这类能力由浏览器提供，5.6.0 对它们的兼容性做了优化 —— 如果某个脚本在老版本上报 GM 函数用不了，先升到这一版再试。
- **停用单个网站上的脚本**：不想让某个脚本在某站跑，用站点设置里的选项针对该域名关掉，不影响其他网站。

## 四、脚本装上了但没反应，按这四条查

官方给的排查顺序，覆盖面基本够：

1. **脚本是不是启用状态** —— 列表里开关没开，后面都白搭。
2. **匹配规则有没有覆盖当前网页** —— 看脚本元数据里的 `@match` / `@include` / `@exclude`。脚本写的是 `example.com`，你在别的域名下当然不生效。
3. **Greasy Fork 点安装没反应** —— 就是第二节说的那层「我已安装管理器」对话框，按提示再点一次。
4. **手机上体验差 / 脚本报错** —— 大量脚本是给电脑浏览器写的，装之前先读脚本作者的说明，确认它兼容移动端。这一条能挡掉大部分「装了不能用」的咨询。

补充一条实践判断：**脚本和广告拦截都可能改动页面**。如果一个页面既异常又装了脚本，先去站点设置里停掉脚本、再关掉该站的广告拦截，二分定位 —— 这个思路和 [常见问题与故障排查.md](常见问题与故障排查.md) 里排页面异常的顺序是一致的。

## 五、脚本能用来做什么（决定你要不要折腾它）

浏览器本身解决「看网页」，脚本解决「按我的规矩看网页」。常见的几类：

- 页面翻译、词典查词
- 智能下一页（长文自动翻页）
- 搜索结果排序调整、去水印类页面增强
- 快速搜索工具条（在页面上直接换引擎搜索）

想找脚本，除了 Greasy Fork，官方还整理了一份[常用脚本站点清单](https://www.xbext.com/favorites/popular-user-script-sites/)。挑脚本时只装你真的会用的 —— 脚本常驻内存，装太多会让浏览器变卡，这在 [常见问题与故障排查.md](常见问题与故障排查.md) 的卡顿一节里也是官方列的原因之一。
