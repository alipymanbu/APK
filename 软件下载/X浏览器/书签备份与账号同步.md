# 书签备份与账号同步

> 账号为什么只有邮箱一种、同步和备份分别覆盖哪些数据、换手机或重装时怎么把书签找回来。

## 一、账号只有邮箱这一种

登录入口在**设置 → 用户中心**（地址栏输 `x:me` 直达）。官方在 FAQ 里明确回答过：**不提供手机号注册，也不支持 QQ / 微信等第三方账号登录**，理由是不想获取这些隐私敏感信息 —— 邮箱只用于密码找回和反馈通知。

所以两点实际影响：

- 你没法用「手机验证码登录」这种路径，**记住邮箱和密码比在别的 App 里更重要**。
- 账号只是数据同步的载体，不登录也能正常用浏览器，只是没有云端那份。

## 二、同步和备份各覆盖什么

这两件事常被混为一谈，范围其实不一样：

| 数据项 | 云端同步 | 本地备份 |
|---|---|---|
| 主页快速访问网址 | 有 | 有 |
| 收藏夹（书签） | 有 | 有 |
| 全部设置 | 有 | 有 |
| 自定义拦截规则 | 有 | 有 |
| 密码 / 自动填充数据 | 有 | 有 |
| 当前打开的标签 | 有 | 有 |
| 用户脚本 | 有 | 有 |
| 历史记录 | 不含 | 备份包含 |
| 离线文件 | 不含 | 备份包含 |

一句话记法：**同步管「配置 + 书签」，备份额外把历史和离线文件也打进去**。你如果主要担心历史记录丢，得靠备份，不能只靠同步。

## 三、四条保险，按需叠加上

1. **登录云端账号** —— 有网就能拉回来，前提是记得邮箱密码。
2. **开启自动同步到云端** —— 数据一变就推上去，不用手动点。设置项在用户中心里。
3. **本地自动备份** —— 默认**每周**把用户数据备份到手机公共下载目录下的 `com.mmbox.xbrowser` 目录（周期可调）。⚠️ 这是官方 FAQ 给的路径，你装的是 `com.xbrowser.play` 那一版，**实际目录名可能随包名不同，以你手机里看到的为准**。
4. **手动备份** —— 设置 → 用户中心 → 备份用户数据，定期导出一份到公共下载目录。换机前跑一次最稳。

有了 1+2，重装后登录即可恢复；1、2 都不可用时，第 3、4 条的本地文件是你最后的退路。**卸载重装不会带走公共下载目录里的备份文件**。

## 四、从别的浏览器把书签导进来

几乎所有浏览器都支持导出 HTML 格式的书签，导入路径：

1. 在旧浏览器里把书签导出成 `.html` 文件。
2. 把文件存到手机的公共下载目录（通常是 `/sdcard/Download`）。
3. 打开 X浏览器 → 设置 → 用户中心 → 从 html 文件导入书签。
4. 选中那个文件，确认导入。

还有更省事的一条：**直接用 X浏览器 打开这个 html 文件，或者从别的应用「分享」给 X浏览器** —— 浏览器会自动识别书签文件并导入。多级目录结构能保留，重复项会去重。

反向导出（备份到 html）同样在用户中心里，导出的文件可以再导入回任何支持 html 书签的浏览器，属于通用格式，不用担心被锁死。

## 五、桌面浏览器的书签怎么过来

官方提供了一个**书签同步助手浏览器插件**：在电脑浏览器上装插件，用你在 X浏览器 里的同一个邮箱账号登录，两边书签就能对上。这条链路是官方专门为「电脑收藏了、手机想看」做的，比手动导出 html 少两步。插件入口在官网 [www.xbext.com](http://www.xbext.com) 的工具页（[书签同步助手](https://www.xbext.com/tools/xbrowser-bookmark-sync/)）。

## 六、几个会被问到的边界

- **两版 X浏览器 的数据不互通**：Play 版（`com.xbrowser.play`）和国内版包名、签名都不同，是两个独立应用，各自的书签和设置分开保存。从一版换到另一版，得靠 html 导出导入或本地备份文件搬数据，不能指望云端自动合并 —— 账号虽是同一个，两版的同步实现也彼此独立。同时装着两版时，改设置只改了其中一版。
- **同步撤销**：讨论区有用户问过「怎么撤销书签同步」，官方没有公开的专门开关 —— 想停就关掉自动同步；要清云端数据，目前得走官方反馈渠道（FAQ 页面底部有反馈入口和作者邮箱）。
- **忘记手势锁**：你给历史记录、某个收藏夹目录、站点密码管理设过手势锁的话，忘了别急着重装 —— 地址栏输 `x:info`，页面底部有 `Reset gesture unlock password` 选项可以重置。重装是下策，因为它会把没备份的东西一起清掉（见 [常见问题与故障排查.md](常见问题与故障排查.md)）。
- **密码存在哪**：记住密码与自动填充数据会跟着同步和备份走。这些是明文可读的站点账号，**别在这台共用设备上同步你的重要账号**，需要的话在站点设置里单独禁用该站的自动填充。
