## 一、先把三个菜单分清楚

浏览器里有三类菜单，定制路径不同，混着找会浪费时间：

| 菜单 | 什么时候出现 | 定制路径 |
|---|---|---|
| 主菜单 | 点底部菜单按钮，左右滑翻页 | 设置 → 外观/定制 → 菜单设置 → 主菜单 |
| 长按菜单 | 在链接、图片、文字上长按 | 设置 → 外观/定制 → 菜单设置 → 长按菜单 |
| 页面工具箱 | 对当前页面操作：翻译、保存、嗅探、网站设置 | 装了用户脚本后，脚本选项也会出现在这里 |

长按菜单是「按元素给选项」的：长按链接给打开/复制/分享，长按图片给保存/识图，长按文字给复制/翻译。某个功能找不到时，先想想它是不是应该在长按菜单里 —— 那里被你改过的话，项会被藏掉。

## 二、手势：两类，都在「设置 → 手势设置」

- **长按手势**：每个工具栏按钮都能绑一个长按动作。比如把「恢复刚关闭的标签」绑到前进按钮上，误关页面后长按一下就回来。
- **快捷触碰手势**：在屏幕上画形状触发动作。官方给的例子是画一个反向开口的 `c`（`ɔ`）来恢复刚关闭的标签；撤销可以连续执行，直到把关掉的标签全找回来。
- **工具栏滑动手势**：工具栏本身支持左右滑和向上滑，绑什么动作同样在手势设置里改。

两个附带效果值得一提：手势设置里能调**长按延时**（5.6.0 调整过主页图标进入拖拽模式的延时，减少误触），以及给某个按钮绑「切换搜索引擎」（见下一节）。

## 三、搜索栏：切换引擎、放底部、当标签定位器

**切换搜索引擎有四种方式**，挑顺手的一种：

1. 主页上**长按搜索框**。
2. 输入关键字后**长按搜索框右侧的搜索按钮**。
3. 在手势设置里给某个工具栏按钮绑「切换搜索引擎」。
4. 装一个[快速搜索工具条脚本](https://www.xbext.com/user-scripts/quick-search-bar-plus/)增强。

**加自定义引擎**：设置 → 高级设置 → 添加自定义搜索引擎 → 新增，把查询参数替换成 `%keywords%`。比如 Google 搜索 `test` 的地址是 `https://www.google.com/search?q=test`，那对应的自定义串就是 `https://www.google.com/search?q=%keywords%`。保存后它会出现在切换列表里。

**搜索栏放底部**：设置 → 外观/定制 → 浏览器布局方式。单手大屏使用时这个位置比顶部顺手很多，不少人装完第一件事就是改它。

**搜索栏还能当标签定位器**：直接输入页面标题里的关键词，浏览器会列出已打开的匹配标签，点一下跳过去。开了一堆标签找不着目标页面时，这个比翻标签列表快。

## 四、标签列表的几个动作

- **调顺序**：拖标签右侧的 favicon 图标。
- **快速关闭**：在标签上左右滑。
- **长按标签**：弹出操作菜单 —— 锁定、关闭、保存到收藏、复制标签链接。
- **锁定的标签**不会被「关闭全部标签」一起关掉，留常用页面用这个。
- **启动时要不要恢复上次的标签**：设置 → 基本设置 → 启动恢复上次未关闭标签，可选「询问」或「禁用」。

有用户反馈左右滑关标签容易在上下滑时被误判（官方讨论区有这条反馈）—— 如果你中招了，改用长按菜单里的关闭，或者关掉标签页再开。

## 五、地址栏快捷网址

输入这些直接跳转，也可以加到主页快速访问里一键点：

| 快捷网址 | 跳到哪 |
|---|---|
| `x:home` | 主页 |
| `x:bm` | 收藏 / 书签管理 |
| `x:dl` | 下载管理 |
| `x:his` | 历史记录 |
| `x:st` | 设置 |
| `x:sc` | 用户脚本管理 |
| `x:rf` | 广告拦截规则 |
| `x:me` | 用户中心（账号） |
| `x:help` | 帮助文档 |
| `x:info` | 浏览器信息页（含重置手势密码的入口） |

个别快捷网址在某些版本上会失灵（讨论区有 `x:his` 打不开历史的反馈，同批其他快捷网址正常）。遇到这种，从菜单进对应页面即可，功能本身没坏。

## 六、几个影响手感的开关

这些不在手势菜单里，但决定了你每天点多少次：

- **返回不重载**：设置 → 高级设置 → 打开「超级缓存」，前进/后退时不再重新加载页面，翻回上一页快很多。
- **强制页面缩放**：移动版网页不让缩放时，设置 → 高级设置 → 强制页面缩放。
- **页面渲染异常时先别怪手势**：链接点不动、区块空白这类问题，多半是拦截规则或脚本造成的，排查顺序见 [常见问题与故障排查.md](常见问题与故障排查.md)。
- **记住密码与自动填表**：设置里开启后会存网站账号密码，数据跟着用户中心一起备份，见 [书签备份与账号同步.md](书签备份与账号同步.md)。
