## 一、开关和规则页在哪

- **拦截规则总入口**：地址栏输入 `x:rf`，或从设置里进广告拦截。
- **单站开关**：点地址栏左侧的站点图标，或「页面工具箱 → 网站设置」，里面可以只对当前域名关掉拦截。
- **菜单里的拦截开关**：主菜单里也有，用来临时放行看一眼。

刚装好时建议先把**订阅规则**勾上，只靠默认规则拦得住的广告有限 —— 官方的口径也是「订阅一些第三方拦截规则就能达到很好的效果」。

## 二、两类规则，决定了你遇到的两种现象

X浏览器 的拦截规则分两大类，理解这个分类能解释你在使用中看到的大部分怪现象。

| 维度 | URL 拦截规则 | 隐藏元素规则 |
|---|---|---|
| 生效时机 | 资源请求发出前 | 页面渲染之后 |
| 拦的是什么 | 广告 JS / CSS / 图片等资源地址 | 已经嵌在页面里的广告模块 |
| 省流量 | 通常省 | 一般不省（资源多已加载） |
| 典型副作用 | 规则太宽会误杀正常功能 | 广告先闪一下再消失 |
| 什么时候用 | 广告以独立资源形式加载 | 广告混在正文 DOM 里 |

对应到你实际看到的两件事：

- **广告闪一下才消失** —— 隐藏元素规则要等元素渲染完才能移除，这个闪烁是工作方式决定的，不是拦截失效。
- **有些广告死活拦不掉** —— 官方给的原因是广告没有独立的资源地址（要用元素规则），或者网站把广告逻辑和正常业务混在一起（规则得写得更细）。这种情况就轮到手动标识出场，见下一节。

规则语法上，浏览器兼容了绝大部分 ABP 规则语法，也扩展了自己的一套；官方做过测试，导入大量规则后页面渲染性能仍然正常（具体测试数字以[官方文档](https://www.xbext.com/docs/ad-block-overview.html)当时显示为准）。第三方测试站 [ADBlock Tester](https://adblock-tester.com/) 给过它满分，这个分数的时效以该测试站为准。

## 三、漏网的广告：手动标识

规则库不是万能的，某个站突然冒出新样式广告时，手动标一次最直接：

1. 长按那块广告区域。
2. 在弹出的长按菜单里选标识广告相关选项。
3. 浏览器会给出几个候选元素让你确认（选太大会把正文一起藏掉，选太小只藏掉一半 —— 拿不准就逐个试）。
4. 确认后该元素被隐藏，规则会记下来，下次访问同一个站自动生效。

这条路径的价值在于：**你只需要标一次**，规则是持久的。长按菜单本身可以定制（设置 → 外观/定制 → 菜单设置 → 长按菜单），如果你常用的标识入口被别的项挤掉了，去那里调。

## 四、订阅与管理规则

- **订阅第三方规则**：官方推荐的主流规则库有 EasyList、AdGuard 等，在规则页里勾选订阅即可。
- **自定义规则**：规则页支持自己添加，语法参考官方的 [URL 拦截规则](https://www.xbext.com/docs/how-to-write-url-block-rule.html) 与 [隐藏元素规则](https://www.xbext.com/docs/how-to-write-hide-element-rule.html) 两篇。
- **例外规则**：某条规则把正常功能挡了，用 [例外规则](https://www.xbext.com/docs/how-to-write-exception-rule.html) 放行，而不是把整条规则删掉 —— 否则广告会跟着一起回来。
- **强力拦截**：官方另有一个「强力拦截模式和规则」，针对顽固站点加强拦截，具体开关与适用范围见[官方说明](https://www.xbext.com/docs/about-strong-adblock.html)。这类模式误杀概率更高，建议只对确实需要的站点开，并配合站点设置使用。

## 五、拦截把网页搞坏了，按这个顺序退回来

页面出现链接点不动、区块空白、排版错乱时，**拦截规则排在排查第一位**（官方给的顺序里它就是第一条）：

1. 先关掉广告拦截，看页面是否恢复正常 —— 是的话，说明是某条规则误杀。
2. 恢复拦截后，针对这个站点单独关（站点设置），或去规则页找到刚订阅的那条规则临时停用，二分定位是哪一条。
3. 页面正常了就别再动它；如果只想放行一个元素，用例外规则。

同一套排查里后面还有禁用脚本、检查是否禁用了 JS、清理缓存、重置设置几步，完整顺序在 [常见问题与故障排查.md](常见问题与故障排查.md)。别一上来就重置 —— 重置会把你的自定义规则和手势设置一起清掉。

## 六、几个绕不开的边界

- **拦截不等于去水印或去推广内容**：正文里的推荐位、信息流里的原生广告，只要它们就是页面内容本身，元素规则能藏，但站点改版后就会失效，需要重新标。
- **规则越多越吃资源**：订阅一堆规则库不会让拦截效果线性变好，反而增加匹配开销。挑两三个主流库，够用就行。
- **某些站点会检测拦截**：遇到「请关闭广告拦截」提示，用站点设置对该域名关掉拦截再访问，这是站点自己的策略，浏览器这边没有开关能绕过它。
