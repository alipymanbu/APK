## 一、总原则：从最便宜的改动开始

官方 FAQ 给的所有排查都隐含同一个顺序：**换环境 → 关你自己的配置 → 清缓存 → 重置**。重排成一张对照表，照着走能省掉大部分无用功：

| 步骤 | 做什么 | 代价 |
|---|---|---|
| 1 | 重启浏览器（彻底退出再进） | 无 |
| 2 | 换网络（Wi-Fi / 蜂窝各试一次） | 无 |
| 3 | 换一个浏览器开同一网址 | 无 |
| 4 | 关广告拦截 | 丢当前拦截状态 |
| 5 | 禁用用户脚本 | 无（脚本还在） |
| 6 | 检查是否禁用了 JS / Cookies | 改回即可 |
| 7 | 清页面缓存 | 丢缓存，不丢书签 |
| 8 | 重置为默认设置 | **丢全部自定义设置、手势、规则** |

第 8 步是核武器 —— 你的手势绑定、自定义引擎、拦截规则会一起没。走到第 7 步还不行，先备份（见 [书签备份与账号同步.md](书签备份与账号同步.md)）再重置。

## 二、某些网页打不开

按官方给的四步：

1. 退出浏览器重进，再开一次。
2. 换网络环境试，Wi-Fi 和蜂窝数据分别测。
3. 用别的浏览器开同一网址 —— **别人都打不开就不是浏览器的问题**，是站点本身挂了。
4. 关掉广告拦截，看是不是规则误杀。

第 5 种情况官方也点明了：**有些未备案网站或恶意站点会被网络层面阻断**，这跟浏览器无关，换什么浏览器都一样。另外如果某些页面在 UC / QQ 浏览器能开、在 X浏览器 不行 —— 官方解释是那些浏览器带服务器中转模式，官方提供了一个 x5 内核分支版本用于接近的场景（见 [官网分支页](https://www.xbext.com/branch/xbrowser-x5-branch/)），是否需要你自己判断。

**连主页都打不开**时，检查系统 WebView 组件：X浏览器 用的是系统提供的 WebView 内核，你在系统里禁用、冻结或清掉了 Android System WebView / Chrome，浏览器会整体无响应。去系统应用列表确认它处于启用状态。

## 三、页面异常：链接点不动、区块空白、排版错乱

官方顺序，别跳步：

1. **关广告拦截** —— 拦截规则最容易误杀页面元素，这一步能解决的占比最高。
2. **禁用用户脚本** —— 脚本会改写页面结构，功能增强和页面破坏是同一把刀。
3. **检查是否禁用了 JS** —— 大部分现代网页没 JS 渲染不出来，设置 → 高级设置里确认没全局禁用。
4. **清页面缓存** —— 主菜单第二屏（菜单左滑）→ 清理。
5. **重置为默认设置** —— 最后一招。

定位到是拦截还是脚本之后，**针对这个站点关掉它**（点地址栏左侧图标 → 网站设置），而不是全局关掉 —— 否则你其他网站的拦截也一起废了。细节见 [广告拦截设置与规则订阅.md](广告拦截设置与规则订阅.md) 和 [油猴脚本怎么安装.md](油猴脚本怎么安装.md)。

## 四、页面能打开，但登录不进去

登录功能依赖 Cookies，去这两处确认没被禁用：

- 设置 → 高级设置 → **禁用 Cookies**（应为关闭状态）
- 设置 → 安全及隐私 → **隐私模式不禁用 Cookies**

隐私模式本身不保存记录，如果你在隐私模式下登录，关掉窗口就得重新登 —— 这是模式定义，不是故障。

## 五、卡顿

官方列的四个原因，按可能性排序自查：

1. **标签开太多** —— 内存不够时系统频繁换页，IO 上升就卡。作者给的经验值是 **200 个标签以内不会有明显影响**（这个数字是作者测试结论，你的机型不同结果不同）。
2. **网页本身吃资源** —— 某些站点渲染时占满 CPU，关掉那个标签试试就知道。
3. **第三方脚本太多** —— 脚本常驻内存和 CPU，逐个禁用定位。装脚本别贪多，见 [油猴脚本怎么安装.md](油猴脚本怎么安装.md)。
4. **缓存过多** —— 定期清理。

## 六、占用空间越用越大

安装包只有 2.63M，涨的是浏览缓存（图片、JS、音视频资源文件）。两条路：

- 手动：主菜单第二屏 → **清理**。
- 自动：设置 → 高级设置 → 开启**自动清理页面缓存**。

清理缓存**不会**删你的书签和设置；要清得更干净就用「清除数据」，但那会连设置一起清 —— 操作前先确认已备份。

## 七、切到后台就被系统杀掉

X浏览器 **没有申请高优先级后台进程**（这是它保持纯净的取舍），所以普通优先级进程极易被系统回收。两条降低概率的办法：

1. 别开太多标签、别开着重内存页面切后台 —— 占用越低越不容易被优先回收。
2. 改系统对这个应用的省电策略。小米的路径是「设置 → 省电与电池 → 设置 → 应用智能省电」，其他品牌在「应用省电 / 后台管控」里找。

被杀不是崩溃，重开后按启动恢复设置决定要不要找回上次的标签。

## 八、几个具体症状

- **返回键被劫持**（怎么按都回不去上一页）：**长按浏览器的后退键**，会弹出该页面的返回路径列表，直接选要回到哪一层。这是恶意网址劫持返回键的典型表现，浏览器这边的解法就是长按。
- **忘记手势解锁密码**：地址栏输 `x:info`，页面底部 `Reset gesture unlock password` 重置。别用重装来解决 —— 没备份的数据会一起没。
- **手机里有两个 X浏览器**：不同渠道包名不同导致的并存，不是中毒。详见 [下载与安装教程.md](下载与安装教程.md) 第四节。
- **某些文件下载不了**（如站点导出配置文件时浏览器不识别、不弹下载）：**有用户反馈**换其他浏览器可以正常触发，官方未给出对应开关。可先试关闭该站的广告拦截（有些下载链接被规则误判），仍不行就用系统自带浏览器完成这一次下载。
- **标签滑动误关**：讨论区有反馈在上下滑动标签时被误判成左右滑而关掉。目前没有开关能关掉这个手势，改用长按菜单里的关闭更稳。

## 九、还是解决不了

官方 FAQ 页面（[www.xbext.com](http://www.xbext.com) 的 docs/faq）带搜索框，按关键字能找到更细的条目；FAQ 页底部提供反馈入口和作者邮箱，反馈时把**机型、系统版本、复现步骤**带上，比一句「用不了」有效得多。

如果你的问题是**安装包本身**（装不上、MD5 对不上、要换版本），回到 [下载与安装教程.md](下载与安装教程.md) —— 网盘里那份 5.6.0 的获取方式与核对方法都在那一篇，安装文件在这里：[X浏览器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/94158ffaeea8)。
