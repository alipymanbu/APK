## 一、安装文件从哪来

ReadAny 是开源软件（GPL-3.0 协议），官方渠道有两个：

| 渠道 | 地址 | 说明 |
| --- | --- | --- |
| 官网 | [https://codedogqby.github.io/ReadAny/](https://codedogqby.github.io/ReadAny/) | 项目介绍与各平台下载入口 |
| GitHub Releases | [https://github.com/codedogQBY/ReadAny/releases](https://github.com/codedogQBY/ReadAny/releases) | 全部历史版本，更新最快 |

不想自己挑版本的，直接用上面网盘里那份安卓安装包即可：版本 1.2.0、约 42.84M、包名 `com.readany.app`、文件 MD5 为 `361666F553B1D293E04C45C2C423CC6A`，转存到自己的网盘后就能下载安装。官方随后又发布了更新的版本，想要最新功能的可以去 Releases 页面，以当时显示的版本为准。

## 二、安卓手机安装步骤

1. 把 APK 下到手机：用上文的 [ReadAny 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5b9ab3e3eb63)，或在 Releases 页面选 `.apk` 文件。
2. 点开 APK，系统大概率会拦一次「来自未知来源的应用」——在弹窗里选择仍要安装，或到「设置 → 应用 → 特殊权限 → 安装未知应用」里，给提供这个文件的应用（浏览器或文件管理器）放行，装完建议再关掉。
3. 安装完成后打开，首次启动是一个设置向导（选语言、配 AI 服务、配检索和翻译），跟着走完就能用；AI 那一步怎么填，见 [AI助手怎么配置.md](AI助手怎么配置.md)。
4. 向导结束后先导入一两本书试读，方法在 [导入书籍与支持格式.md](导入书籍与支持格式.md)。

对系统版本有具体要求的，以官方发布页标注为准；装不上多半是系统版本过低，或者安装包没下完整（可比对上文给出的 MD5）。

## 三、桌面版与其他平台

ReadAny 不只有手机版，桌面三端都在同一个 Releases 页面下载：

| 平台 | 安装方式 |
| --- | --- |
| Windows | 下载安装器（`.msi` 或 `.exe`，以页面当时提供为准）双击安装 |
| macOS | 按芯片选包：Apple Silicon 与 Intel 分开下载；或用 Homebrew 安装（见下） |
| Linux | `.deb` 包或 `.AppImage` |
| iOS | 通过 TestFlight 参加测试，入口在官网 |

macOS 用 Homebrew 装更省事，终端里执行两条命令：

```bash
brew tap codedogQBY/readany
brew install --cask readany
```

macOS 首次打开若提示「已损坏，无法打开」，是系统安全机制拦的，两条处理办法写在 [常见问题与解决方法.md](常见问题与解决方法.md) 里。

## 四、装完先做什么

按大多数人的顺序：先把常读的书导进来，再看书遇到不懂的让 AI 讲（需要先配好一个 AI 服务），随手划线记笔记、定期导出。三件事分别对应 [导入书籍与支持格式.md](导入书籍与支持格式.md)、[AI助手怎么配置.md](AI助手怎么配置.md)、[高亮笔记与阅读统计.md](高亮笔记与阅读统计.md)。
