## 一、同步能带走什么、用什么方式

同步的是阅读进度、高亮、笔记这些阅读数据——默认它们只存在本机，配置同步后才按你填的服务器地址在设备间流转。三种方式任选其一：

| 方式 | 需要什么 | 适合 |
| --- | --- | --- |
| WebDAV | 一个支持 WebDAV 的网盘或自建服务 | 日常多设备同步，最通用 |
| S3 兼容对象存储 | 地址、桶名、Access Key、Secret Key 四项 | 已有对象存储、数据量大的 |
| 局域网同步 | 两台设备连同一个网络 | 换新手机做一次性迁移，不经过外部服务器 |

S3 与局域网同步是 1.1.7 加入的能力；局域网同步走的是本机网络直传，敏感数据不出家门。

## 二、WebDAV 完整配置步骤（以坚果云为例）

1. 网页登录坚果云，右上角账号名进「账户信息」→「安全选项」，在第三方应用管理里「添加应用」，生成一个**应用密码**。同步时填的是它，不是登录密码。
2. 回到 ReadAny，在设置里找到同步相关页，选 WebDAV，填三项：
   - 服务器地址：`https://dav.jianguoyun.com/dav/`
   - 账号：坚果云注册邮箱
   - 密码：刚生成的应用密码
3. 验证连接通过后，先手动做一次**全量上传**，把本机数据推上去。
4. 第二台设备装好 ReadAny、填同一套参数，验证通过后做一次**全量下载**，之后打开自动同步。

其他支持 WebDAV 的服务（Nextcloud、群晖、自建 NAS 等）步骤相同，只是服务器地址格式不同，以各自服务商的说明为准。坚果云免费版有每月上传/下载流量限制，数据量大时留意流量提示。

## 三、自动同步与冲突处理

- 打开自动同步后，后台按设定的间隔传输，间隔可以在设置里调，怕费流量的调稀一点。
- 两台设备同时改过同一条笔记或高亮时，同步会做合并处理，不需要手动挑一边；合并不放心的，到笔记面板里核对一遍。
- 改动迟迟没出现在另一台设备时，先手动触发一次同步，再看两台设备各自的同步状态提示定位卡在哪。

## 四、失败排查

1. 认证失败：确认填的是应用密码而非登录密码；应用密码重新生成后旧密码立即作废。旧版本有过 WebDAV 认证问题，1.2.0 已修复，报认证错误先升级到 1.2.0 以上。
2. 局域网同步找不到设备：确认两台设备在同一个网络、路由器没开访客隔离；Windows 端的路径处理问题在 1.2.0 修复过。
3. 传到一半失败：数据量大或网络不稳时，先同步小部分数据试通整条链路，再全量传输。
4. S3 全量失败：四个参数逐字核对，桶名拼错是最常见的翻车点。

同步相关的报错在 [常见问题与解决方法.md](常见问题与解决方法.md) 里还有汇总。同步服务再怎么配，本机数据始终是完整的——服务器挂了不影响你继续读。
