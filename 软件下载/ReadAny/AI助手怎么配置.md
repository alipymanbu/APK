## 一、先选一个 AI 服务商

AI 对话、摘要、语义搜索、翻译都要靠一个 AI 服务来干活，你需要先备好其中一家的访问凭证：

| 服务商 | 需要准备 | 适合谁 |
| --- | --- | --- |
| OpenAI | API Key，在 [platform.openai.com](https://platform.openai.com/) 申请 | 已有账号的人 |
| Anthropic Claude | API Key，在 [console.anthropic.com](https://console.anthropic.com/) 申请 | 同上 |
| Google Gemini | API Key，在 [aistudio.google.com](https://aistudio.google.com/) 申请 | 想零成本先试水的 |
| DeepSeek | API Key，在官方开放平台申请 | 国内支付方便的 |
| Ollama | 本机或局域网机器上装好 Ollama 并拉取模型，不需要 Key | 不想花钱、在意隐私的 |
| 自定义接口 | OpenAI 兼容的服务地址 + Key | 已有中转或自建接口的 |

云端服务按调用量计费，读得多花得也多；Ollama 免费但吃本机性能，电脑配置一般的话跑小参数模型更稳。还没有任何账号、想先把流程跑通的，Gemini 的免费额度或本地 Ollama 是起步成本最低的两条路。

## 二、在哪里配置

- 首次启动的设置向导里有单独的「AI 配置」步骤：选服务商、填 Key、选模型，走完即可。
- 之后想改，进「设置 → AI」。每个端点都提供「拉取模型」和「测试连接」——测试连接会真实发一次最小请求，填完先点它验证，比存了配置等报错快得多。
- 向导里的「智能检索」一步配的是语义搜索要用的向量化模型。这一步可以跳过：跳过后语义搜索用不了，普通搜索和阅读不受影响。

## 三、各家的配置要点

- OpenAI / Claude / Gemini / DeepSeek：粘贴 Key，从模型列表里选一个即可；不同模型在长文问答上的表现差异明显，建议用常读的那本书实测一次再定。
- Ollama：地址填本机或局域网机器的服务地址（本机默认端口是 11434），模型名要与 `ollama list` 里显示的一致。
- 自定义接口：填服务地址（Base URL）与 Key，保存后用「测试连接」验证；排查问题时可以查看并复制最终请求地址，确认地址拼接是否正确。

## 四、对话怎么用

- 阅读界面呼出 AI 面板直接问。它知道你当前读到的位置、刚选中的文字和已有的高亮，所以「这一章在讲什么」「这个词在这本书里指什么」这类问题直接问就行，不用先把上下文粘贴给它。
- 先选中一段再提问，回答会围绕这段展开；回答会附上原文出处，点一下就能跳回原文对应位置核对。
- 大活也接得住：「帮我逐章总结这本书」这类请求，它会一章一章取内容、逐章出总结；人物关系、核心概念这类梳理，还可以让它整理成思维导图。
- 技能系统里内置了摘要、概念解释、人物关系梳理等预设技能；有固定用法的话可以自建技能，把自己的提问套路存下来反复用。

## 五、语义搜索与翻译

- 书内搜索除了普通关键词，还支持按意思找：搜「主角失去能力的转折」，哪怕原文用的是完全不同的措辞也能命中相关段落。
- 手机版从 1.1.6 起不再内置本地向量化模型（安卓安装包因此从 200 多 MB 缩到几十 MB），所以在手机上要用语义搜索，得在检索设置里配一个向量化服务接口；桌面版仍默认本地完成、可离线。
- 翻译支持 AI 翻译或 DeepL，覆盖 19 种语言；自建了 DeepL/DeepLX 服务的可以把地址改成自己的，双语对照阅读就用这个功能。
- 整章翻译单独有开关：翻到某章一键出整章译文，译文可以单独显示，也可以和原文对照显示。
