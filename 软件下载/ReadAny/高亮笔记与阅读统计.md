## 一、标高亮

阅读时选中一段文字（手机长按、电脑用鼠标选），在弹出的菜单里选颜色即可，共五种：黄、绿、蓝、粉、紫。

建议按用途固定一套自己的规则，比如黄色记金句、绿色记有疑问的地方、蓝色记术语，回头翻笔记时不用重读全书就能定位到每类内容。已标的高亮集中在笔记面板里，点任意一条能跳回原文位置。

## 二、写笔记

- 选中文字后除了标色，还可以直接附一条笔记；笔记用 Markdown 编辑，工具栏齐全，所见即所得。
- 成段的想法可以在笔记面板单独开一篇，不必绑在某段原文上。
- 笔记和高亮会跟着书走，开启多设备同步后，手机上划的线在电脑上也能看到（同步怎么配，见 [WebDAV同步怎么设置.md](WebDAV同步怎么设置.md)）。

## 三、导出到别处

笔记和高亮可以整批导出，出口有五种：Markdown、HTML、JSON、Obsidian、Notion。

- 用 Obsidian 或 Notion 管理知识的，选对应格式导过去，能直接汇进你已有的知识库结构里。
- 只要一份备份或想在别处二次加工的，Markdown 或 JSON 就够。

定期导出一次是好习惯：本地数据虽然稳妥，但导出成通用格式后，换任何阅读工具都不怕。

## 四、阅读统计在哪看

- **热力图**：整年的阅读情况一图看完，样式类似 GitHub 的贡献图，哪天读了、读多少一目了然。
- **趋势图**：按日、周、月查看阅读时长的变化。
- **连续天数**：记录最长连续阅读多少天，适合给自己定打卡目标。
- **单书维度**：每本书花了多长时间、读到多少，判断一本书值不值得继续花时间。

统计基于你实际打开阅读的时间，不需要手动打卡。开启多设备同步后，各端的数据会汇到一起。
