## 一、ReadAny 免费吗

开源协议是 GPL-3.0，源码公开，自己从源码构建永远免费。官方发布页直接下载的版本也是免费的；只有上架应用商店的版本可能收少量费用，用来覆盖签名证书与持续开发成本。从安装文件资源里拿到的包不涉及商店收费。

## 二、我的书和笔记存在哪

书籍、高亮、笔记、阅读进度都保存在设备本地。不开启同步时，任何内容都不会发往外部服务器；开启 WebDAV 或 S3 同步后，才按你填的服务器地址传输。在意隐私又需要多设备的，用自己搭建的 WebDAV 服务最稳妥。

## 三、界面怎么调成中文

设置里有语言选项，在英文和简体中文之间切换。多数版本在右下角「我的（Me）」→「外观与语言（Appearance & Language）」里选简体中文即可；首次启动向导的第一步也会让你选语言。装完发现是英文的，改完设置立刻生效，不用重装。

## 四、安装与启动问题

- **安卓提示「禁止安装未知来源应用」**：到系统设置里给本次安装放行，路径因机型不同，一般在「设置 → 应用 → 特殊权限 → 安装未知应用」附近，给提供安装包的那个应用放行即可，装完建议关回去。还没拿到安装文件的，从 [ReadAny 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5b9ab3e3eb63) 转存获取。
- **macOS 提示「已损坏，无法打开」**：先到「系统设置 → 隐私与安全性」允许从任何来源下载的应用；仍不行就把应用拖进「应用程序」文件夹，在终端执行下面这条命令后再开：

  ```bash
  sudo xattr -rd com.apple.quarantine /Applications/ReadAny.app
  ```

- **Windows 装完打不开**：确认下载的安装包与系统匹配（不同架构的包别混装），重新下载一遍再试；杀毒软件拦截时把安装包加入白名单。

## 五、AI 不回答或报错

1. 先用配置页的「测试连接」跑一次，它会真实发一条最小请求，能直接暴露问题出在哪一环。
2. Key 类报错：检查 Key 是否复制完整、是否已过期、账户余额或额度是否用完。
3. Ollama 连不上：确认服务真的在运行，地址端口填对（本机默认 11434），模型名与 `ollama list` 里显示的一致。
4. 网络问题：部分服务商的接口在部分地区需要代理才能访问，检查代理是否生效。
5. 能回答但质量差：换一个模型试试，不同模型对长文问答的效果差异明显；也可以把问题指向具体章节或选中一段再问，回答会更准。

配置项的具体位置和各家 Key 的申请入口，见 [AI助手怎么配置.md](AI助手怎么配置.md)。

## 六、同步失败怎么办

还没搭好同步的，先按 [WebDAV同步怎么设置.md](WebDAV同步怎么设置.md) 把配置走通，再回来对号入座：

- **WebDAV**：逐一核对服务器地址、账号、密码；不同服务商的地址格式不同，以服务商的帮助说明为准。
- **S3**：地址、桶名、Access Key、Secret Key 四项都要核对，错一项就全量失败。
- 先手动触发一次全量上传或全量下载做验证，确认通了再打开自动同步；自动同步的间隔可以在设置里调。
- 两台设备同时改过同一条笔记时，同步会做合并处理；如果状态一直不对，看应用内的同步状态提示，必要时重新做一次全量传输。
- 旧手机换新手机，可以用局域网快传做一次性迁移，不经过外部服务器。

装好后还没导入书的，先回 [导入书籍与支持格式.md](导入书籍与支持格式.md) 把书库建起来。
