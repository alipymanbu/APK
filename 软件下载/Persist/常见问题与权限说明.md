## 一、权限清单与用途对照

官方应用说明里给出了每条权限的用途，逐条对照如下。安装时只给「修改系统设置」也能跑基础功能，其余按需再给：

| 权限 | 官方说明的用途 |
| --- | --- |
| 完全网络访问 / 查看网络连接 | 报错反馈、Google 地图、使用统计 |
| 读取日历 | 按日历事件排程预设 |
| 修改系统设置 | 更改高级音量设置（核心权限） |
| 粗略与精确定位 | 检测位置变化，触发按位置的排程 |
| 控制振动 | 通知振动 |
| 读写外部存储 | 访问自定义图标与铃声 |
| 开机自启动 | 重启后恢复音量设置 |
| 读取手机状态 | 在所有安卓版本上分离铃声与通知音量 |

不用对应功能就把权限留着不用管的思路也可行，但更稳妥的做法是反过来：**哪个功能异常，先回来查这张表**。比如按位置自动切预设不灵，多半是定位权限被省电策略收走了；锁音量、排程整体失灵这类后台限制问题，排查见[锁音量与排程失效排查.md](锁音量与排程失效排查.md)。

## 二、铃声和通知音量为什么分不开

不少机型出厂把振铃和通知音量绑成一条，调一个动两个，这是系统行为，不是应用改坏的。这个应用提供分离 / 链接选项，但有两层前提：

1. **能不能分**取决于机型与系统支持程度（官方对独立铃声 / 通知音量的描述是「与硬件有关」），官方帮助中心专门有一篇「为什么有些音量被关联」（Why Are Some Volume Levels Linked）讨论这个问题；
2. 分离功能依赖「读取手机状态」权限，不给这条权限，分离选项可能不工作。

所以遇到「分不开」先做两件事：给齐权限，再在应用设置里找铃声 / 通知音量的分离开关。实在分不开的机型（系统层绑死），分离选项会保持灰色或无效，这属于设备限制。

## 三、能不能把音量调到系统最低值以下

这个问题官方帮助中心也有一篇专门条目（How Do I Decrease Volume Levels Below My Phone's Minimum?）。每台设备的最小音量档位由系统定，应用能做的是在这套档位上给你更细的控制，具体能做到哪一步以官方那篇的说明与你机型的实际表现为准——去[官方帮助中心](https://netroken.zendesk.com/hc/en-us)搜标题即可。

## 四、免费版与升级的口径

| 项 | 说明 |
| --- | --- |
| 基础音量调节、预设 | 免费可用 |
| 自动排程、桌面小组件、通知收藏 | 属于升级解锁范围，安装后有完整试用窗口（早期官方描述为 24 小时），到期后以应用内提示为准 |
| 广告 | 免费版有广告 |
| 官方帮助中心 | 付费相关内容归在 Payments 分类下，共四篇：如何获得免费功能、退款政策、Volume Control+ 包含什么、恢复之前的购买 |

付费与试用政策会随版本调整，上面只是框架；到你手上时以应用内实际弹出的说明为准。应用包本身的获取方式见[下载与安装教程.md](下载与安装教程.md)。

## 五、版本与更新

- 本文各篇以安装包 **v6.8.2** 为准（2026 年 5 月前后的版本，该版更新内容为 Bug 修复）。
- 官方商店此后的更新仍在继续（2026 年 9 月已到 6.12.1，含预设编辑改进、Android 16 通知分组优化等），版本号会持续变化，以官方页面为准。
- 从本安装包升级到更高版本：直接用新版 apk 覆盖安装即可，预设会保留；但**同包名不同签名**的包不能互相覆盖（会报签名冲突），遇到就先卸载旧的，代价是预设丢失——升级前把关键预设的各条数值抄一份保险。

## 六、换机与备份

官方帮助中心有 Backup Feature（备份功能）专文，换机或重装前建议先到帮助中心看这篇的操作说明，把预设与设置备份出来再迁移。迁移后如果小组件没跟上，按[桌面小组件与悬浮音量.md](桌面小组件与悬浮音量.md)第二节的两步（挪回内存 + 重启）处理。

与音量锁、口袋锁相关的疑问见[音量锁与音量上限设置.md](音量锁与音量上限设置.md)；应用隐私政策的原文在[Netroken 官网](https://netroken.ca/privacypolicy)。
