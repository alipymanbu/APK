## 一、六种小组件一览

桌面小组件都是**活的**：不跳转应用，直接在桌面上完成操作。官方列出的六种：

| 小组件 | 布局 | 桌面上能做什么 |
| --- | --- | --- |
| 预设 | 1x1 | 一触套用指定的一套音量设置 |
| 预设列表 | 1x1 | 弹出全部预设，选哪个套哪个 |
| 音量锁 | 1x1 | 直接改或锁定某条音量 |
| 振动 | 1x1 | 切换振铃和通知的振动设置 |
| 响铃模式 | 1x1 | 在静音 / 振动 / 正常之间切换 |
| 仪表板 | 4x1 | 多条音量滑条摆在一起，实时拖动调整 |

搭配建议：预设小组件配你最常用的那个场景（比如「睡眠」），仪表板放桌面第二屏当「调音台」，响铃模式小组件给开会前一键静音用。预设怎么建，见[音量预设与定时切换.md](音量预设与定时切换.md)。

## 二、小组件不出现怎么办

官方说明里点名的两个已知原因，先按顺序查：

1. **应用装在 SD 卡里了**：装在 SD 卡上的应用，小组件在部件抽屉里不出现。把应用挪回手机内存（设置 → 应用 → Persist → 存储 → 更改存储位置），挪完可能要重启。
2. **部分安卓版本需要重启一次**：装完或更新后部件抽屉里没有新组件，先重启手机再看，官方明确说「某些 Android 版本可能需要重启后小组件才会显示」。

两个都不是的，检查桌面启动器是否限制了第三方小组件（个别品牌的极简模式、儿童模式会这样）。

## 三、悬浮音量按钮

悬浮按钮是一个浮在其他应用上面的圆形控件，点了直接出音量控制和预设——全屏看视频、玩游戏时不用退出或下拉通知栏。

开启后系统会要求授予**「显示在其他应用上层」（draw over other apps）**权限，这是悬浮窗类功能的必要条件，不给的话悬浮按钮不会出现。用不到这个功能时可以把权限收回、按钮关掉，不影响应用其余部分。

## 四、通知栏收藏与快捷方式

把常用预设钉在通知栏里，下拉即可一键套用，也可以从通知直达音量控制。这个入口适合「桌面不想放组件、又嫌进应用麻烦」的用法：通知常驻一条，点开就是你的常用预设列表。

通知快捷方式与桌面小组件同属升级解锁范围（免费试用期内可先体验），免费版与升级的具体口径见[常见问题与权限说明.md](常见问题与权限说明.md)。

装应用、给权限的步骤在[下载与安装教程.md](下载与安装教程.md)；如果小组件和通知都正常但你锁的音量总被改回去，大概率是音量锁在起作用，对照[音量锁与音量上限设置.md](音量锁与音量上限设置.md)第一节看音量条颜色即可确认。
