# Volume Control（Persist）锁音量与排程失效排查

> 本篇讲 Persist（Volume Control）最常见的一类故障：音量锁锁不住、自动排程到点不触发、通知收藏消失——多数不是应用坏了，而是后台进程被系统或厂商的省电策略停掉了。先装好应用并给齐权限（见[下载与安装教程.md](下载与安装教程.md)），再按本篇排查。

## 一、哪些现象指向「后台被杀」

下面这些表现背后往往是同一个原因——应用在后台被系统停掉，锁音量和排程都没有进程去执行：

| 现象 | 常见误判 |
| --- | --- |
| 锁了的音量还是被改、且没被拉回 | 以为音量锁坏了 |
| 时间 / Wi-Fi / 位置排程到点不动 | 以为排程功能不可用 |
| 重启手机后音量设置、锁定状态没恢复 | 以为「开机自启动」没作用 |
| 通知栏收藏、常驻通知某天消失 | 以为通知功能不稳 |

音量锁的原理是「有应用改音量时把它拉回来」，排程是「到点由应用来改音量」——两者都要求应用在后台活着。锁的具体用法见[音量锁与音量上限设置.md](音量锁与音量上限设置.md)。

## 二、先做通用修复：把应用移出电池优化

这是所有安卓手机通用的第一步（路径在不同系统版本上措辞略有差别）：

1. 打开系统设置 → 应用 → 找到 Persist（Volume Control）。
2. 找到「电池」或「电池优化 / 特殊访问权限 → 电池优化」入口。
3. 把列表切到「所有应用」，选中 Persist，改为**「不优化 / 允许后台活动」**。
4. 回到应用信息页，确认「自启动」开关是开的。

改完做一次验证：设一个两三分钟后触发的时间排程，锁屏等着看它是否生效；或者锁屏放置过夜，第二天检查音量锁是否还在。

## 三、品牌机型加做的几步

不少厂商在安卓原生省电之上叠了自己的管控，光做第二节不够。下面是常见品牌的额外路径（各品牌界面随版本变化，以你手机的实际设置为准）：

| 品牌 | 额外要查的地方 |
| --- | --- |
| 小米 / 红米（MIUI / HyperOS） | 应用信息 → 自启动；省电策略改为「无限制」。系统更新后这些设置可能被重置，故障复发先回查 |
| 华为 / 荣耀 | 电池 → 启动管理 → 改为手动管理，允许自启动、关联启动、后台活动 |
| OPPO / 一加 / realme | 电池 → 更多设置里的「应用速冻 / 睡眠待机优化」，把本应用移出；允许完全后台行为 |
| vivo | 应用信息 → 自启动管理；电池里的后台高耗电允许 |
| 三星 | 电池 → 后台使用限制，确认本应用不在「休眠 / 深度休眠」列表里 |
| 原生类（Pixel 等） | 通常做完第二节即可，个别情况查「自适应电池」 |

提一句预期：允许后台运行后耗电会有轻微增加，这是后台保持活跃的正常代价。

## 四、改完仍失效的三个方向

1. **权限被收走**：对照[常见问题与权限说明.md](常见问题与权限说明.md)第一节的权限表逐条检查，尤其「修改系统设置」和「读取手机状态」，有些系统会在一段时间后自动回收。
2. **同类应用冲突**：另一个音量管理或免打扰工具在跟本应用抢着改音量，先停用对方观察。
3. **确认是哪条音量在变**：用应用内锁定时的提示（振动或声音，见[音量锁与音量上限设置.md](音量锁与音量上限设置.md)第四节）定位到底是哪个环节改了音量，再对症处理。

排程本身的搭建方法（时间 / Wi-Fi / 蓝牙 / 位置 / 日历五类触发）见[音量预设与定时切换.md](音量预设与定时切换.md)。
