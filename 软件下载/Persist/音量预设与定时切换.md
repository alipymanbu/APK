## 一、七类音量流各管什么

安卓把声音分成几条独立的「流」，系统自带的音量键一次只能调其中一条。这个应用把七条流放在一个界面里让你分别设值：

| 音量流 | 管的是哪些声音 |
| --- | --- |
| 闹钟 | 闹钟响铃 |
| 媒体 | 视频、音乐、游戏的声音 |
| 振铃 | 来电铃声 |
| 通知 | 短信、各类应用通知音 |
| 通话语音（语言） | 通话中对方的声音 |
| 蓝牙 | 蓝牙耳机、车载音箱的音量 |
| 系统 | 按键音、解锁音等系统提示音 |

调整方式就是在应用主界面拖动各条滑条。有的机型默认把振铃和通知音量绑在一起，能不能拆开、怎么拆，见[常见问题与权限说明.md](常见问题与权限说明.md)第二节。

## 二、建一个预设

预设就是「七条音量的一套取值」打包存档，之后一键套用。以「开会」为例，你可以把振铃和通知压到最低或静音、媒体设为零、闹钟保留——到会上一键应用即可。

操作路径（应用主界面 → 预设 / Presets 区域 → 新建或编辑，不同版本的入口位置略有差别，以应用内界面为准）：

1. 在主界面把各条音量滑条调到想要的值。
2. 保存为预设，起个好认的名字（按场景起名比按时间起名好用：`开会`、`睡眠`、`耳机`）。
3. 以后要改直接编辑这份预设，不用从头再调。

已有的预设可以复制一份再改，适合做「开会-强静音」和「开会-保留闹钟」这种变体。

## 三、一键切换的三种方式

1. **应用内**：打开应用，点预设列表里的目标预设。
2. **通知栏快捷方式**：把常用的预设钉在通知里，下拉通知栏就能切，不用进应用。这个入口在通知快捷方式设置里配置。
3. **桌面小组件**：预设、预设列表两种小组件都能一触套用，详见[桌面小组件与悬浮音量.md](桌面小组件与悬浮音量.md)。

## 四、自动切换：按条件套用预设

手动切总归要记得切，自动排程解决的是「忘了切」的问题。应用支持的触发条件有五类：

| 条件 | 典型用法 |
| --- | --- |
| 时间（时刻 / 周期） | 每晚十点自动套「睡眠」预设；工作日早八点恢复「日常」 |
| Wi-Fi | 连上公司 Wi-Fi 自动静音，离开家里 Wi-Fi 恢复响铃 |
| 蓝牙 | 连上车载蓝牙自动调高媒体音量 |
| 位置 | 到健身房自动套「运动」预设 |
| 日历事件 | 日历里有会议时自动静音，不用手动设 |

另外还有一个**预设定时器**：临时套用某个预设一段时间（15 分钟、1 小时等），到点自动恢复之前的状态。适合「午休静音两小时」「陪孩子写作业一小时」这类一次性场景，不用事后记得改回来。

使用建议：优先用时间触发，条件最简单；位置和 Wi-Fi 触发依赖定位或网络状态，偶尔会有延迟；日历触发要求应用能读到日历（对应「读取日历」权限）。

Wi-Fi 与蓝牙这两类触发在官方帮助中心各自有单列的专文（Wi-Fi Schedule / Bluetooth Schedule），配置细节以[官方帮助中心](https://netroken.zendesk.com/hc/en-us)为准。排程到点不触发时，多半是应用后台被系统限制，排查步骤见[锁音量与排程失效排查.md](锁音量与排程失效排查.md)。

## 五、免费版能用哪些

自动排程和小组件属于应用内升级解锁的范围。装好后有一段完整试用窗口（早期官方描述为 24 小时），期间可以先把这些排程都搭好试试顺不顺手，再决定要不要升级；官方帮助中心也单独有一篇「如何获得免费功能」，具体口径以应用内提示与官方帮助页为准。安装与获取方式见[下载与安装教程.md](下载与安装教程.md)。

搭好预设之后，建议顺手把怕误触的音量锁上，两件事配合用才稳：见[音量锁与音量上限设置.md](音量锁与音量上限设置.md)。
