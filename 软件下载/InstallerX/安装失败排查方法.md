# 安装失败排查方法

> 点了安装没反应、还是弹系统安装器、授权失败、安装中途报错——按"哪一步断了"对号入座排查。

## 一、先判断断在哪一步

安装失败基本分三类，排查路径完全不同：

| 现象 | 断点 | 去哪修 |
| --- | --- | --- |
| 点 APK 弹出的还是系统安装器 | 接管没生效 | 本文第二节 |
| 弹出授权请求 / 提示授权器不可用 | 权限没到手 | 本文第三节 |
| InstallerX 弹出来了，但安装报错 | 安装环节出错 | 本文第四节 |

## 二、还是弹系统安装器

这是被问得最多的一类，按顺序检查：

1. **锁定过没有**：进 InstallerX 设置看"锁定为默认安装器"是否处于已锁定状态，没有就先锁；
2. **锁定顺序对不对**：必须先选好授权器再锁定，顺序错了锁定不生效；
3. **系统重置了锁定**：小米 / HyperOS、ColorOS、OriginOS 这类系统可能把默认安装器重置回去，重新锁一次；反复被重置的机型，处理思路见 [锁定默认安装器方法.md](锁定默认安装器方法.md) 第四节；
4. **还锁不上**：个别系统对安装入口管控极严，纯靠 InstallerX 可能接管不了，这是系统侧限制。

## 三、授权失败

**Shizuku 相关**：

- 提示 Shizuku 未运行：Shizuku 在重启手机后会停，重新"通过无线调试启动"一次，步骤见 [Shizuku授权与激活方法.md](Shizuku授权与激活方法.md)；
- 授权列表里找不到 InstallerX：先在 InstallerX 里发起一次授权请求让它出现在候选里；
- 无线调试配对不上：确认手机与配对时连的是同一 Wi-Fi，配对码要在通知弹出后尽快输入，超时作废就重新生成。

**ROOT 相关**：ROOT 授权失败时 InstallerX 会给提示，先确认你的 ROOT 管理器（Magisk / KernelSU 等）本身工作正常，再回 InstallerX 重试授权。

**Dhizuku 相关**：Dhizuku 走设备管理员机制，权限弱于 Shizuku，部分高级操作（如某些安装来源声明场景）做不到；授权总是不顺畅的话换 Shizuku 是更省事的路线。

## 四、安装环节报错

| 报错 / 表现 | 原因 | 处理 |
| --- | --- | --- |
| 版本类错误，装不上旧版 | 没开允许降级 | 在安装选项里勾"允许版本降级"，详见 [安装选项设置指南.md](安装选项设置指南.md) 第四节 |
| 提示需申明有效安装者 | 系统校验安装来源 | 在安装选项里调整"声明安装者"的设置，以机型实际要求为准 |
| 解析失败 | 安装包格式没被正确识别 | APK、XAPK、APKS 及含 APK 的 ZIP 压缩包都可直接装，无需手动解压（其余冷门格式以应用内实际支持为准）；反复解析失败先换一份包试试 |
| 装到一半卡住不动 | 后台被系统冻结 | 把 InstallerX 加入电池白名单 / 后台无限制，重新发起安装 |
| 点安装直接闪退 | 通知权限被禁 | 通知栏安装依赖通知通道，去系统设置把 InstallerX 的通知权限打开 |
| 装完了，应用打不开或提示缺数据 | 分包容器里的 OBB 数据没就位，或架构不匹配 | 处理办法见 [XAPK与分包格式安装方法.md](XAPK与分包格式安装方法.md) 第三节 |
| 提示签名冲突 / UPDATE_INCOMPATIBLE | 设备上已有同名应用、但来自别的渠道签名不同 | 先卸载旧版再装；卸载会清数据，先备份 |

## 五、排除安装包本身的问题

以上都正常还失败，就该怀疑包了：

- 核对 MD5：以本文档对应网盘包 1.7 版为例，MD5 应为 `D0974195D6DF1E952678E701596A6F60`，对不上说明下载过程有损坏，重新下载；
- 换一个 APK 试：换一个能装，说明问题在那个包本身（签名损坏、架构不匹配），不是 InstallerX 的问题；
- 架构不匹配：分包格式的包（XAPK 等）在解析时自动按设备匹配，单个 APK 的包则可能只含特定架构，换对应架构的包。

排查完仍无解的，可以去官方 GitHub 仓库（见 [下载与安装教程.md](下载与安装教程.md) 第一节）的 issue 区搜相似报错。
