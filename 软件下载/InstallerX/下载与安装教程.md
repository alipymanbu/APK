## 一、InstallerX 是什么

InstallerX 是一款安卓第三方应用安装器，作者是 Rosan（GitHub 上的 [iamr0s](https://github.com/iamr0s/InstallerX)），以 GPL-3 协议开源。它的用途是替换系统自带的安装程序：不少国产系统对外来安装包弹自家确认页、限制较多，你可以改用 InstallerX 来接管安装过程，并获得对话框安装、通知栏安装、自动安装、允许降级安装、安装后自动删除安装包等选项。

本文基于的版本信息（以安装包实物为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.7 |
| 包名 | `com.rosan.installer.x` |
| 大小 | 2.57M |
| MD5 | `D0974195D6DF1E952678E701596A6F60` |

注意包名这一栏：原版 InstallerX 的包名是 `com.rosan.installer.x`；社区后来还有一个由 wxxsfxyzm 维护的分支叫 InstallerX Revived，包名多一段 `.revived`。两者设置界面与功能有差异，查资料、对照教程时先看清楚你装的是哪一版。

## 二、安装前要确认的三件事

1. **系统版本**：官方 README 标注的支持范围是 Android 5.0～13；1.7 这一版把 target API 升到了 Android 14。更新的系统上能否正常使用，以官方发布页当时的说明为准。
2. **授权通道**：InstallerX 需要借助 ROOT、Shizuku 或 Dhizuku 之一拿到安装权限。手机没有 ROOT 也不用放弃，走 Shizuku 是最常见的路线，具体见 [Shizuku授权与激活方法.md](Shizuku授权与激活方法.md)。
3. **允许安装未知来源应用**：装 InstallerX 本身这一步，走的还是系统安装器，系统会先问你是否允许从这个来源安装应用，同意即可。

## 三、获取安装文件

安装包从这里的 InstallerX 安装文件资源（夸克网盘）转存获取：[https://pan.quark.cn/s/63730afdbf40](https://pan.quark.cn/s/63730afdbf40)。转存到自己网盘后下载得到 `InstallerX_v1.7.apk`（2.57M）；如果你对文件完整性有要求，下载后可以核对 MD5 是否为上表的 `D0974195D6DF1E952678E701596A6F60`。

官方渠道也在：GitHub 仓库 [iamr0s/InstallerX](https://github.com/iamr0s/InstallerX) 的说明里列了酷安等发布入口，想追新版本可以去那里看，但注意官方渠道给的是最新版，与网盘里这份 1.7 不一定是同一个版本。

## 四、安装 InstallerX 本身

1. 在文件管理器里点开下载好的 APK；
2. 系统弹出确认页，点安装；若提示需要允许"安装未知应用"，按提示给文件管理器授权后重试；
3. 装完点打开，首次进入会有一次同意页，同意后进入主界面。

装好只是第一步——这时你点任何 APK，系统调用的仍然是原来的安装器，InstallerX 还没有接管。

## 五、装完后的三步设置（总览）

接管过程一共三步，每一步的细节在对应篇章里：

1. **选授权器**：ROOT / Shizuku / Dhizuku 三选一（或多选按顺序尝试），没 ROOT 优先 Shizuku，Dhizuku 的激活见 [Dhizuku激活与授权方法.md](Dhizuku激活与授权方法.md)；
2. **锁定为默认安装器**：这一步必须在选完授权器之后做，否则没有权限锁定；
3. **试装验证**：随便找一个 APK 点安装，弹出 InstallerX 的安装对话框才算接管成功。

三步的具体操作分别见 [Shizuku授权与激活方法.md](Shizuku授权与激活方法.md) 和 [锁定默认安装器方法.md](锁定默认安装器方法.md)；哪一步卡住了，去 [安装失败排查方法.md](安装失败排查方法.md) 对号入座。
