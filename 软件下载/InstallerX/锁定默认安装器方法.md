# 锁定默认安装器方法

> 不把 InstallerX 锁定为默认安装器，点 APK 时系统调用的还是老安装器；本篇讲锁定步骤、锁定前的必要条件，以及小米、OPPO、vivo 等系统上锁不住时的处理。

## 一、为什么必须先选授权器再锁定

"锁定为默认安装器"这个动作本身也需要特权——InstallerX 要替你改系统的默认安装器角色，靠的是授权器给的权限。所以顺序是死的：

1. 先进**设置**，把**授权器**选好（ROOT / Shizuku / Dhizuku，选法见 [Shizuku授权与激活方法.md](Shizuku授权与激活方法.md)、[Dhizuku激活与授权方法.md](Dhizuku激活与授权方法.md)）；
2. 再回来点**锁定为默认安装器**。

顺序反了或授权器还没生效就去点，要么按钮没反应，要么直接提示没有权限锁定。这也是很多人第一次设置失败的原因。

## 二、锁定步骤

1. 打开 InstallerX，进入**设置**页；
2. 确认授权器已选好且可用（Shizuku 用户此时 Shizuku 应处于运行状态）；
3. 点**锁定为默认安装器**；
4. 弹出确认时再点一次**锁定**，完成。

锁完做个验证：在文件管理器里随便点开一个 APK，弹出来的是 InstallerX 的安装对话框而不是系统安装页，就说明接管成功。如果还是老安装器弹出来，直接翻 [安装失败排查方法.md](安装失败排查方法.md)。

## 三、锁定成功后又被系统弹回去

部分国产系统会在系统更新、重启或自家安全策略触发时，把默认安装器重置回系统自带的那一个。表现为：明明锁过，过几天点 APK 又变回老安装器。遇到这种情况：

- 重新进 InstallerX 再点一次锁定即可，一分钟的事；
- 这个问题在 InstallerX 1.7 的更新说明里也有一条"修复锁定默认安装器"，版本太旧的话可以先升级再锁；
- 顺手养成习惯：装机后隔一阵发现安装又走了系统流程，第一反应就是回来看锁定状态。

## 四、各系统上的差异

不同厂商对第三方安装器的限制强度不一样，读者反馈较多的情况：

| 系统 | 常见表现 | 处理思路 |
| --- | --- | --- |
| 小米 / 红米（MIUI / HyperOS） | 锁定后可能被系统重置 | 重新锁定；有用户反馈可借助 LSPosed 类工具拦截转发，属于进阶玩法 |
| OPPO（ColorOS） | 锁了仍弹系统安装器，锁死较严 | 有用户反馈需要冻结系统安装组件或配合 Xposed 模块才能彻底接管 |
| vivo（OriginOS） | 与 ColorOS 类似，限制偏严 | 同上，普通锁定可能不够 |
| 华为（HarmonyOS / EMUI） | 安装入口管控严格 | 不少用户反映接管困难，做好"锁不上"的心理准备 |
| 类原生 / Pixel | 基本一次锁定长期有效 | 无需额外处理 |

这些差异来自系统侧的策略，InstallerX 本身解决不了厂商的限制；锁不上但报错信息明确的，先看 [安装失败排查方法.md](安装失败排查方法.md) 里有没有对应条目。

## 五、不想锁成默认，还能用吗

可以。即使不锁定，你也可以在文件管理器里用"打开方式"选择 InstallerX 来装单个 APK，只是每次都要手动选一遍。偶尔装包的人这样反而清净；经常装包、想让每个 APK 都自动走 InstallerX 的，还是锁上省事。
