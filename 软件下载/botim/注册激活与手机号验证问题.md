## 一、注册流程：账号就是手机号

没有用户名密码那一套，一个手机号对应一个账号：

1. 打开应用，选国家并填手机号——中国大陆选 `+86`，号码本身不带 0 和空格；
2. 选接收方式：**短信验证码**或**语音来电**，短信一直不来就换语音试试；
3. 输入收到的验证码，进入主界面；
4. 按提示授权通讯录，应用会把通讯录里同样在用 botim 的人标出来，方便直接开聊。

还没装应用的话，先看 [下载与安装教程.md](下载与安装教程.md)，把包和权限备齐再回来。

## 二、验证码收不到的逐项排查

按顺序过一遍，多数情况出在前三条：

| 排查项 | 怎么做 |
| --- | --- |
| 号码格式 | 国家码选对（大陆是 `+86`），号码去掉前导 0、不带空格与符号 |
| 信号与话费 | 信号差就换个位置；欠费停机收不到任何短信 |
| 短信拦截 | 系统的骚扰拦截、第三方拦截软件里翻一下，把验证码短信放出来 |
| 重发与等待 | 点「重新发送」，连续请求之间留一两分钟，请求太密会被限流 |
| 换网络 | 从 Wi-Fi 换成流量（或反过来）再请求，运营商路由不同，成功率不同 |
| 换接收方式 | 短信通道不行就选语音来电验证，念一遍数字填进去 |
| 换时间 | 深夜偶发通道拥堵，隔一段时间再试 |

全试过还不行，走文末的客服渠道反馈，把手机号、运营商、报错截图一起给。

## 三、提示「手机号不能使用」怎么办

一部分用户在注册时碰到手机号被提示不可用的反馈，可按这个顺序处理：

1. **核对国家码与号码**：格式错了会被当成无效号，回到第一步的格式要求；
2. **换网络环境重试**：个别网络出口会触发风控，换 Wi-Fi/流量后往往就过了；
3. **换个时段再试**：短时间内反复请求验证，号码可能被临时限制，等几个小时；
4. **联系官方客服**：发邮件到 `customerservice@botim.me`，附手机号与报错提示的截图，让客服核实号码是否被限制。

以上是从通用的注册故障排查思路出发的处理办法，具体到某个号段是否被支持，以官方客服的答复为准。

## 四、换手机号怎么处理

分两种情况，口径以官方帮助中心（[botim.me](https://botim.me) 的 FAQ 区）为准：

- **钱包账户的换绑**（主要面向阿联酋用户）：旧号还能收短信时，走 Me > Wallet > Settings > Account > Phone Number 按提示换；旧号收不到短信时，发邮件到 `customerservice@botim.me`（主题写 `change phone number`），附上新旧号码与号码归属证明，走人工审核。
- **普通账号的手机号**：官方 FAQ 显示换号能力在逐步开放中，能不能直接在应用里改以你当前版本显示为准；改不了就先用旧号登录，再问客服。

换号前先把常用设备的登录维持住，别急着注销，避免两头够不着。

## 五、两条安全提醒

- 验证码等于账号钥匙，任何人（包括自称客服的）索要验证码都不要给。
- 同一个手机号在新手机上激活后，注意确认旧设备是否还停在登录状态，不用了就在旧设备上退出，减少账号暴露面。
