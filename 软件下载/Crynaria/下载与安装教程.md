## 一、先确认你要装的是哪个版本

Crynaria 最初是 PC 端的同人动作游戏，后来移植到安卓平台。不同渠道放出的包版本号写法不一（第三方站点出现过 0.x、1.2 等多种写法），**以你手里安装包的属性为准**。

本资源为安卓版，采集口径如下：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.0 |
| 安装包大小 | 73.82M |
| 包名 | `com.chengtaisheng.plbk.n04094489268c44e29de0e5334ae0922c` |
| MD5 | `3c1a0a62bafc175beec513b763713a02` |

如果你下载后想核对文件是否完整，可以用校验工具比对 MD5；对不上就说明下载不完整，重下一次即可。

## 二、从夸克网盘获取安装文件

Crynaria 安装文件资源放在夸克网盘里，获取分两步：

1. 打开上面的网盘链接，把里面的安装包**转存到自己的网盘**（未转存直接下载可能受限）；
2. 打开夸克网盘客户端（手机端或 PC 端均可），找到刚转存的文件，下载到手机存储。

建议在 Wi-Fi 环境下载，安装包约 74M，流量下载也不算大，但转存和下载在客户端里操作更稳。

## 三、安装步骤

1. 在手机文件管理里找到下载完成的 apk 文件，点开；
2. 系统弹出「未知来源应用」提示时，允许从该来源安装（不同品牌入口不同：部分手机在弹窗里直接给「设置」入口，部分要去「设置 → 安全 → 更多安全设置」里开「未知来源应用下载」）；
3. 等安装完成后点「打开」。

关于系统要求：各下载站口径不一致（安卓 4.4 到 7.1 以上都有提及），开发者没有给出明确的官方门槛。多数较新的安卓机型可以直接装；装不上就按下面第四节排查。

## 四、安装失败的常见原因

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | 下载不完整或文件损坏 | 重新下载，核对 MD5 |
| 安装到一半失败 | 手机存储不足 | 清出至少 1G 空间再装 |
| 提示「存在冲突的同名应用」 | 手机里已有同包名的旧版本 | 先卸载旧版再装 |
| 点击 apk 没反应 | 文件管理器关联异常 | 换用系统自带文件管理打开 |

装好之后进游戏就黑屏、闪退的情况，转到 [常见问题与解决方法.md](常见问题与解决方法.md) 处理。
