## 二、安装失败 / 提示解析错误

1. **下载没下完**：安装包应为 94.69 MB，体积差一截就是没下完，重新下载并核对 MD5（`fba672ee9b9c525f9f7f8d348a55f34e`），见 [下载与安装教程.md](下载与安装教程.md)；
2. **没开「安装未知应用」**：给文件管理器或浏览器开开关，路径见安装篇第三节；
3. **与旧版本签名冲突**：手机里有同名不同签名的，先卸载再装；
4. **机型太老**：官方没公布最低 Android 版本，装不上就是这台设备不受支持，别硬刷。

## 三、打不开、闪退、白屏

按顺序试，每一步不行再走下一步：

1. 确认装的是完整包（MD5 对得上）；
2. 重启手机再打开 —— 排除偶发进程残留；
3. 清一次缓存（「设置 → 应用 → LongCat → 存储 → 清除缓存」），**别点「清除数据」**，那会把登录态一起清掉；
4. 换网络再试（Wi-Fi 和流量切一下）：白屏很多时候是连不上服务端，不是应用坏了；
5. 以上都无效，从官方渠道装一个较新版本覆盖，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 四、登录不上、验证码收不到

| 检查 | 说明 |
| --- | --- |
| 手机号/账号有没有输错 | 最常见，逐位核对 |
| 短信被拦截 | 查骚扰拦截文件夹；连着要验证码太频繁会触发频率限制，等几分钟再试 |
| 网络 | 登录请求发不出去时换个网络 |
| 版本太旧 | 极老版本可能已不被服务端支持，覆盖安装新版 |

登录方式以你装的版本界面实际列出的为准，界面没有的登录方式就是这个版本不支持，见 [第一次打开要设置的几项.md](第一次打开要设置的几项.md)。

## 五、发消息没反应、一直转圈

1. **先等一轮**：开了深度思考、或开了联网搜索，响应本来就慢，别急着打断；
2. **看输入框**：输入为空时发送键是灰的，这是正常置灰不是故障；
3. **换网络重发**：转圈超过一两分钟，先切网络；
4. **重启对话**：某一轮把话题带进死胡同，回列表开个新会话再问；
5. **还是不行**：退出登录重登一次；重登仍无效，多半是服务端临时状况，隔段时间再来，不必反复卸载重装。

问题问法本身导致「答非所问」的，看 [深度思考与联网搜索怎么用.md](深度思考与联网搜索怎么用.md) 第四节。

## 六、语音没声音、通话打不起来

1. **麦克风权限**没给 → 按 [第一次打开要设置的几项.md](第一次打开要设置的几项.md) 开；
2. **连了蓝牙耳机但没给权限**：断开耳机用外放试一次，能听到就是耳机链路的问题；
3. **手机静音/勿扰模式**：先检查系统音量与勿扰开关；
4. **网络**：通话对网络比打字敏感，弱网先换网；
5. **通话界面找不到摄像头入口**：视频通话是逐步开放的，这个版本没有就是没有，见 [语音通话与音视频交互怎么用.md](语音通话与音视频交互怎么用.md) 第五节。

## 七、生图不出来、图里字错了

- **出不来**：先确认不是权限问题（照片/存储权限），再确认不是网络，最后确认不是自己中途退出了对话 —— 生成是跟着那轮对话走的；
- **图里字有错**：直接在那轮对话里指出错在哪、要求只改文字，别整图重画（重画会把好部分也换掉），操作见 [AI生图和用嘴改图怎么用.md](AI生图和用嘴改图怎么用.md) 第三节；
- **改几轮画风崩**：回到效果最好的一轮重新往下改，别在崩掉的版本上继续堆要求。

## 八、界面缺入口、功能找不到

各应用商店的版本号不同步，网盘这份 1.9.5 也未必是当前最新。**入口没有 = 这个版本还没上这个功能**，先去 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 的渠道表更新到较新版本再看；更新后仍然没有，就是该功能对你的账号或地区尚未开放，等官方发布，不要因此判定安装包有问题。

数据要保留的话，更新覆盖安装即可，登录状态与对话记录跟着账号走（见 [下载与安装教程.md](下载与安装教程.md) 第六节）。
