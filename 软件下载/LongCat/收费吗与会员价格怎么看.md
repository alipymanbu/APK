# LongCat 收费吗与会员价格怎么看

关于收费，网上信息混着三类完全不同的东西：手机 App 本身、给开发者用的 API 平台、以及与官方无关的第三方定价站。三者的价格互相不通用，先分清楚再看要不要付钱。

## 一、手机 App：下载不收钱，付费项以界面为准

iOS 商店页对这个应用的标注是**免费**（下载不收费，以商店页当时显示为准）。截至检索时，官方渠道没有公布过 App 内的会员套餐或订阅价格 —— 所以判断「现在要不要花钱」只有一个可靠办法：

> **打开 App，看有没有充值 / 会员入口。** 没有入口就是不收费；有入口就以入口上明示的价格与权益为准，付款前把续费规则读一遍。

别用第三方文章里的数字代替界面 —— 那些数字见第四节。

## 二、API 开放平台收费是另一码事

你在搜「LongCat 收费」时会撞到 Token、按量付费这些词，那是**给开发者调用模型接口用的平台**，跟手机 App 是两个产品：

| 项目 | API 开放平台的规则（官方口径） |
| --- | --- |
| 计费方式 | Token 资源包（一次买断固定额度，购买后 30 个自然日内有效）＋ API 按量付费（先充值余额、按实际消耗扣费） |
| 实名认证 | 只在充值付费时才需要；不认证也能继续用平台的免费额度 |
| 与 App 的关系 | 互不打通 —— App 不会因为你在平台充了值就解锁会员 |

来源是官方平台的更新日志与开放平台协议，入口在 [longcat.ai](https://longcat.ai/)。**普通用户装 App 用不着碰这一页。**

## 三、「限时免费到某月某日」这类说法怎么信

检索时能看到「免费体验至某年某月某日」「首调用送多少 Token」这类限时说法，出处多是第三方下载站与介绍页，官方公告里查不到对应内容。处理原则：

- 官方与第三方冲突时，**以官网、App 界面为准**；两边口径不一致的事实并列知道即可，别拿第三方的截止日期吓自己；
- 时限类信息本身就容易过期，写进备忘前先回官方页面核一遍。

## 四、网上那些「LongCat 会员定价页」是谁

搜索结果里存在按月按年卖「LongCat Image」会员的定价站（Basic / Professional / Enterprise 套餐那种版式），这类站点：

- 与官方无隶属关系，**官方渠道从没公布过这套订阅**；
- 卖的是它们自己的积分包，和你手机里这个 App 的账号不互通；
- 同类混淆还有一批，完整对照见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

一句话判断：**凡是先要你付款才能「解锁 LongCat」的页面，都先回到官方渠道核对** —— 官方入口只有 [下载与安装教程.md](下载与安装教程.md) 第五节列的那几个。

## 五、不确定时的自查顺序

1. 打开 App 看有没有付费入口（第一节）；
2. 对照商店页是否仍标注免费；
3. 疑似官方的收费公告，到 [longcat.ai](https://longcat.ai/) 与 App 内公告核对；
4. 核不了的，宁可先不付 —— 装 App 这条链路本来就不需要花钱，见 [常见问题与排查.md](常见问题与排查.md)。
