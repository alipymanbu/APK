## 二、装之前要确认的三件事

| 要确认的 | 怎么确认 |
| --- | --- |
| 系统版本 | 官方与商店页面都没写死最低 Android 版本，只标注为 Android 平台。机型较旧就直接装一次，装不上再考虑换设备，本文不对具体版本下结论 |
| 存储空间 | 安装包 94.69 MB，装完还要占运行缓存，建议预留 500 MB 以上 |
| 网络 | 首次打开需要联网并登录，装之前先确认网络可用，否则会卡在登录页 |

## 三、安装步骤

1. 打开网盘入口，把 APK 转存到自己的网盘，再下载到手机；
2. 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给你用来打开安装包的那个应用（文件管理器或浏览器）打开开关；
3. 点击 APK 完成安装。系统提示「应用未经过安全检测」时选择继续安装即可，这是第三方渠道安装包的常规提示；
4. 手机里若已经装过同名但签名不同的版本，安装会失败 —— 先卸载旧的那个，再装这一份。

打开后会要求登录，登录与权限怎么处理写在 [第一次打开要设置的几项.md](第一次打开要设置的几项.md)。这里只说装完立刻要验证的三处：

| 看什么 | 为什么现在就看 |
| --- | --- |
| 能发出第一条消息 | 发出去且有回复，说明登录与网络这两关都过了 |
| 输入框旁能选到图片/文件上传 | 判断多模态这条链路是否可用 |
| 找得到语音入口 | 判断麦克风权限有没有给对，详见 [语音通话与音视频交互怎么用.md](语音通话与音视频交互怎么用.md) |

三处都能走到，说明这份包本身是好的；后面再出问题，基本落在账号、网络或权限上，按 [常见问题与排查.md](常见问题与排查.md) 逐条排除。

## 五、官方渠道有哪些

网盘这份是 1.9.5，想要最新版可以走官方渠道（各渠道版本号不同步，以页面当时显示为准）：

- **iOS**：在 App Store 搜索「LongCat」，商店页全称是「LongCat-美团旗下AI助手龙猫」；
- **Android**：在应用宝等正规商店搜包名 `com.meituan.longcat.android`，运营者显示为北京三快科技有限公司；
- **网页版**：[longcat.ai](https://longcat.ai/) 提供 Web 端体验，不用装 App 也能用，与 App 是否共用账号记录以实际体验为准。官方协议还写明服务形态包括网页、PC 客户端与移动应用 —— PC 端是否存在、从哪下，以官网当时页面为准。

## 六、更新与卸载

- **更新**：从官方渠道覆盖安装即可，登录状态与对话记录跟着账号走；
- **卸载重装**：卸载前先确认要留的对话还在账号里，本地缓存会随卸载清掉；
- **换手机**：安装包始终从上面那个网盘入口取用，别用来路不明的安装包，认包名 `com.meituan.longcat.android` 最稳。

装不上、装完打不开、或者卡在登录页，按 [常见问题与排查.md](常见问题与排查.md) 里对应的现象处理。
