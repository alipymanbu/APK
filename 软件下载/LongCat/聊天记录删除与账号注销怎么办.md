# LongCat 聊天记录删除与账号注销怎么办

「删掉记录」和「注销账号」是两件后果完全不同的事，弄混容易误伤：一个只动你这台手机，一个会把账号连同数据一起处理掉。本篇按从轻到重的顺序讲，先想清楚要删到哪一层。

## 一、先判断你要删的是哪一层

| 你的目的 | 该动哪一层 | 对应操作 |
| --- | --- | --- |
| 手机空间不够、想清一清 | 本地缓存 | 第二节，卸载重装或清缓存 |
| 某条对话不想留在这台手机上 | 本地显示 | 第三节，App 内删除 |
| 彻底不要这个账号和它的数据 | 账号 | 第四节，注销账号 |
| 换新手机，旧手机不留痕迹 | 两者结合 | 第五节 |

## 二、只清本地：清缓存与卸载

不碰账号、最安全的一层：

- **清缓存**：「设置 → 应用 → LongCat → 存储 → 清除缓存」。缓存清掉不影响登录状态与对话记录；
- **卸载**：本地缓存随卸载一起清掉，但**账号里的对话还在** —— 重新装回来登录，记录照样在。只想腾空间，卸载就够，不必注销。

## 三、删账号里的对话记录

对话记录跟着账号走，删除层级以你装的版本界面为准：

1. 先在会话列表里找删除入口（长按或滑动单条会话，常见交互是这两种），把不想留的对话删掉；
2. 界面上找不到删除入口时，官方《LongCat隐私政策》第五节赋予你对个人信息的删除权 —— 按政策里「如何联系我们」给出的官方渠道提出删除请求，由官方处理；
3. 别把「清空这台手机」当成「删掉数据」：只要账号还在，记录就还在服务器侧，换设备登录能重新看到。

## 四、注销账号：入口与后果

注销入口是官方隐私政策里写明的路径，不用找客服绕圈：

```
侧边栏 → 设置 → 注销账号 → 在线操作
```

后果按官方口径（《LongCat隐私政策》「注销账号」条）：

- 注销成功后，除法律法规及相应的国家标准另有规定外，**你的个人信息会被删除或作匿名化处理**；
- 账号注销后不能再用它登录，与之绑定的对话记录也随之失去入口；
- **这一步不可逆** —— 想清楚再点，尤其是只想「换绑手机号」的，换绑和注销是两回事，先在设置里找换绑入口。

政策全文随时可查：[LongCat隐私政策](https://longcat.chat/privacy/zh/privacy-policy/)。

## 五、换手机时怎么做才对

| 目的 | 做法 |
| --- | --- |
| 旧手机给家人用，记录不留在旧机 | 退出登录 + 清缓存即可，账号数据不动 |
| 新手机要用原来的记录 | 新机装 App 登录同一账号，记录跟账号走 |
| 旧手机彻底报废且不要账号了 | 走第四节注销 |

**换手机不需要注销账号** —— 这是最常见的误操作，注销之后记录找不回来。安装包照旧从 [LongCat 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2b20d773c34c) 取，步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 六、未成年人账号的删除

按官方《未成年人隐私保护政策》，未满 18 周岁的使用需监护人同意；监护人可以要求访问、更正、删除未成年人的个人信息，也可以注销账号，入口同第四节，拿不准就走隐私政策里的官方联系渠道。
