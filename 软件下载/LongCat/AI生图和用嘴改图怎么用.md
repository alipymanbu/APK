LongCat 的图片能力分三块：凭文字画出来（文生图）、拿已有图当底改（图生图与改图）、以及让它看懂你传的图（图片理解）。本篇按「先生成、再修改、再识图」的顺序讲操作。

## 一、文生图：一句话生成

在输入框里直接描述要的画面，它会生成图片。描述里给全四样东西，出图就稳：

1. **画什么**：主体明确，「一个在窗边看书的女生」比「一张好看的图」强十倍；
2. **什么风格**：摄影感、插画、水彩、3D 渲染……不写它就替你默认；
3. **构图与画幅**：特写还是全景、横图还是竖图（发朋友圈和做封面要的画幅不一样）；
4. **画面里的字**：海报、招牌、封面这类带文字的图，把要写的字逐字列出来。

第 4 点官方资料里专门提过：它对中文文字的渲染做了优化，牌匾、海报标题、书籍封面上的中文以及生僻字、书法字体都比较准，多行排版也会自动匹配字号行距。**但再准也建议生成后把画面上的字逐字读一遍**，错了就下一轮改。

## 二、图生图：拿现成图当底

不想从零画，就把图交给它当参考：

- **上传方式**：输入框旁的图片/加号入口，从相册选或现场拍（拍照要给相机权限，见 [第一次打开要设置的几项.md](第一次打开要设置的几项.md)）；
- **给参考图下指令**：「照这个构图换季节」「把这件衣服换成藏蓝色」—— 说得越具体，改得越贴；
- **无参考图也能改**：先文生图，再在生成结果上继续对话改。

## 三、用嘴改图：自然语言做二次编辑

生成之后不满意，不用换工具，直接在对话里接着说。官方公布的编辑能力覆盖十几类任务，你实际会用到的主要是这几种：

| 你想干的事 | 可以这么说 |
| --- | --- |
| 加/减东西 | 「把最左边的饮料去掉」「桌上加一只白猫」 |
| 换风格 | 「换成水彩风」「变成胶片质感」 |
| 换视角 | 「拉远镜头，多露一点室内」「换个俯拍角度」 |
| 改人像 | 「头发改成灰色，面带微笑」（保留五官和姿态） |
| 改画面里的字 | 「标题改成『秋日限定』」 |
| 局部指定 | 「红圈里加个白色的钟」这类圈选+描述 |

两个使用上的注意点：

- **多轮改图要一次说一件事**：一口气塞五个要求，改完容易整体跑偏；拆成几轮，每轮确认效果再继续；
- **人像、宠物主体的连续修改会尽量保持原样**，但改的轮数多了质感会有损耗 —— 关键版本先自己存一张。

## 四、让它看懂你传的图（图片理解）

传图不等于生图。你传一张截图、一段报错、一道题，不加任何「生成」字眼直接问「这是什么问题」「这题怎么解」，它走的是识图分析。这条链路依赖照片/存储权限，没给就先去开。

识图回答里的数字、代码建议同样要自己核对，它是照着图读的，读错行、看漏字都可能。
