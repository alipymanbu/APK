## 二、安卓端从哪获取

安装包从 [Aseprite 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8ea65b6f0dcf)获取：打开链接 → 转存到自己的网盘 → 从网盘把 APK 下载到手机本地。下载完成后，在通知栏或「文件管理」的下载目录里找到这个 APK 文件，点它开始安装。

这份安装包标注的系统要求是「安卓 5.2 以上」（原文如此，属于对系统版本要求很低的一类），近几年的安卓手机基本都能装，手机、平板均可运行。

## 三、它和桌面版 Aseprite 是什么关系

搜 Aseprite 时最常见的资料是它的桌面像素画软件（官网地址 `https://www.aseprite.org`，付费，支持 Windows / macOS / Linux）。有一个背景值得先知道：桌面版官方开发者在社区论坛公开答复过（2026 年 4 月，以官方页面为准），暂不推出官方手机版，优先维护桌面版。所以安卓上以「Aseprite」名义分发的应用来自第三方，是针对触屏重做的像素画应用，与桌面版不是同一套程序。

两边功能思路同源（图层、逐帧动画、洋葱皮、调色板），但界面、版本号各自独立，桌面版的更新日志、快捷键和教程截图不能照搬到手机上，遇到对不上号的教程先确认对方讲的是哪个端。截至本文检索时，安卓之外暂无对应的 iOS 版本。各渠道简要对照：

| 渠道 | 要点 |
| --- | --- |
| 安卓（本文这份安装包） | APK 直接安装，无需应用商店；版本 1.3，中文界面 |
| 桌面版（官网） | 付费软件，官网提供购买与试用，界面为英语为主（可装中文语言包） |
| iOS | 暂无对应版本 |

## 四、安装步骤

1. 从上面第二节的网盘链接转存并下载 APK 到手机。
2. 点开 APK，系统若提示「禁止安装未知来源应用」，按提示进入设置，允许你的文件管理器或浏览器「安装未知应用」。
3. 回到安装页点「安装」，包体 70 多 MB，等待进度走完。
4. 点「打开」进入应用，第一次启动会先弹出软件政策，同意后进入主页。

安装被拦截时，不同手机的处理路径略有差别：小米在「设置 → 更多设置 → 特殊权限 → 安装未知应用」，华为在「设置 → 安全 → 更多安全设置 → 安装外部来源应用」，其他品牌一般搜「未知来源」就能找到对应开关。

## 五、装不上时的排查顺序

按命中概率从高到低：

1. **提示「解析包时出现问题」**——多半是下载不完整，重新下载一遍，再对一次第一节的 MD5。
2. **存储空间不足**——安装包本体 73.76 MB，加上安装过程的解压占用，留出 300 MB 以上余量比较稳。
3. **点了没反应或秒退**——先重启手机再装一次；仍不行把「安装未知应用」的授权关掉重开，重新走一遍授权。
4. **装上了但闪退**——确认系统版本不低于标注要求，还是闪退就到[常见问题与技巧.md](常见问题与技巧.md)对照更多情况。

装好之后从哪下手画第一张像素画，看[新手绘画入门.md](新手绘画入门.md)；画完想发朋友圈或给游戏当素材，导出方法在[导出GIF与精灵表.md](导出GIF与精灵表.md)。
