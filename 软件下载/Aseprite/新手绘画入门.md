## 一、第一次打开的完整路径

首次启动的流程是固定的，按下面四步走：

1. 打开应用，同意软件政策（只出现一次）。
2. 进入主页后，点左下角的绿色「+」号，进入创建页面。
3. 按需选择画布内容：可以从创作中心挑一个示例角色或模板直接改（脸型、配色都能调整），也可以新建空白画布自己画。
4. 画完点右上角的保存图标，作品会留存下来，随时能回主页继续编辑。

界面本身就是中文的，不需要找语言设置。

## 二、画布尺寸怎么定

像素画和普通绘画不同，画布是以「像素个数」计的，几十像素就算大画布了。新手按用途选：

| 用途 | 常见尺寸 | 说明 |
| --- | --- | --- |
| 微型图标、道具 | 8×8 / 16×16 | 每一格都要有意义，练「取舍」的最佳尺寸 |
| 头像、小图标 | 16×16 / 32×32 | 数格子的级别，改错成本低，最适合练手 |
| 表情包 | 64×64 / 100×100 | 细节多一点，导出后仍清晰 |
| 游戏角色 | 32×32 / 48×48 | 独立游戏常用规格 |
| 场景、插画 | 128×128 以上 | 工作量大，建议先画小图找感觉 |

画布宁可开小不开大：像素画的清晰感来自「每个像素都看得清」，尺寸越大越接近普通涂鸦，反而丢了这个味道。

## 三、基础工具速查

画板界面里常用的就这几个，逐个试一遍就能上手：

| 工具 | 干什么 | 用法提示 |
| --- | --- | --- |
| 铅笔 | 一格一格描像素 | 主力工具；笔画粗细可调 |
| 橡皮 | 擦除 | 擦过头用撤销找回来 |
| 油漆桶 | 整片填色 | 填封闭区域，轮廓有缺口会「漏色」到整个画布 |
| 形状 | 直线、矩形、圆 | 先画轮廓再填色，比手描省事 |
| 吸色 | 取画布上已有颜色 | 保持配色统一时常用 |

双指捏合缩放画布：放大到每一格像素都清楚，是像素画和普通画画手感差别最大的一点。打开网格显示（画布被分成清晰的小格）能帮你对准落笔位置。

线条画毛了、轮廓出现毛糙的台阶，是新手第二常见的问题，修法单独整理成篇，见[描边与抗锯齿技巧.md](描边与抗锯齿技巧.md)。

## 四、配色从哪来

- 右侧调色板区取色，先从现成配色开始，别一上来就自己调色。
- 一张小图控制在 4~8 种颜色以内，颜色多了画面容易脏。
- 想给作品换一套风格，用调色板管理功能整体替换配色，比一块一块重涂快得多——具体见[图层与调色板管理.md](图层与调色板管理.md)。
- 自检土办法：把图想象成黑白（或眯眼看），如果各色块之间分不出深浅，说明明暗对比不足——像素画里「深浅拉开」比「色相丰富」更要紧。

## 五、画错了怎么办

撤销 / 重做是像素画里用得最频繁的操作，画错一两格直接撤销，不必橡皮来回擦。建议养成「画几笔就看看整体」的习惯：缩放到正常大小看一眼，再放大继续，避免只在放大状态下画，成图一看比例全歪。

保存入口固定在编辑界面右上角的保存图标。作品保存后导出成 GIF 或图片序列的方法，见[导出GIF与精灵表.md](导出GIF与精灵表.md)。
