## 一、安装与启动类

| 现象 | 处理 |
| --- | --- |
| 装不上、提示未知来源 | 按[下载与安装教程.md](下载与安装教程.md)第五节的排查顺序走 |

## 二、绘画操作类

**手指画不准、总落错格**——三个手段叠加用：放大到单格像素清晰可见再落笔、打开网格显示对准位置、画完缩小检查整体。用触控笔会稳很多，但没有也能画，像素画本来就是「格子艺术」，放大就是你的纠正手段。

**画错了一大块**——撤销是第一反应；反复调整同一区域时，先把当前状态多复制一层图层留底，改崩了删层重来，比一步步撤销快。

**颜色越画越多、画面变脏**——给自己立规矩：只从调色板取色，不随手吸色调色。重构配色见[图层与调色板管理.md](图层与调色板管理.md)。

**轮廓毛糙、台阶忽长忽短**——这是新手第一观感问题，有单独的修图流程（台阶节奏检查法、抗锯齿的加与不加），见[描边与抗锯齿技巧.md](描边与抗锯齿技巧.md)。

## 三、保存与导出类

| 问题 | 答案 |
| --- | --- |
| 作品存哪了 | 编辑界面右上角的保存图标；主页里随时能找到并继续编辑 |
| 想发给别人 | 先导出成 GIF / PNG，导出方法见[导出GIF与精灵表.md](导出GIF与精灵表.md) |
| 导出的图在手机里找不到 | 到相册的最近项目、或文件管理器的 Download / Pictures 目录按时间找 |
| 发出去的图变糊 | 先确认导出时放大了整数倍、传的是原图；聊天软件会压缩图片，关不掉就先放大再发（口径见[导出GIF与精灵表.md](导出GIF与精灵表.md)） |
| 换手机怎么办 | 先在旧手机把作品逐个导出成文件，新手机装好后导入；只靠应用内存档换机容易丢 |

## 四、动画类

**动画看着卡顿**——按这个顺序查：① 每帧时长是否全部一样（关键动作应该停一拍）；② 相邻两帧位移是否过大（放大看洋葱皮，一步挪太多就会跳）；③ 帧数是否太少，循环动作低于 4 帧很难顺。调法都在[逐帧动画与洋葱皮.md](逐帧动画与洋葱皮.md)。

**洋葱皮的影子干扰画画**——它是半透明的前后帧参照，只在对位时开，画细节时关掉；或减少显示的帧数、换灰度模式降低干扰。

**做多段动作混在一起**——用标签把不同动作的帧分组（走路一段、攻击一段），导出时按标签出图，不会互相串。

## 五、进阶小技巧

- **平铺模式**：打开后画布四周会出现镜像 / 重复预览，画背景纹理（砖墙、草地）时能直接看到拼接效果，接缝一次到位。
- **对称绘画**：画左右对称的角色（脸、正面站姿）时开启对称，画一半另一半自动跟上。
- **像素完美描线**：线条工具比手描更容易走出干净直线；圆和椭圆先用形状工具起形，再手动修掉不满意的格。
- **从模板起步**：创作中心里的示例角色（脸型、配色可调）不是摆设——拆开看它的图层结构和配色数量，是学别人怎么组织作品的最快途径。

基础操作还不熟的话，回到[新手绘画入门.md](新手绘画入门.md)把流程过一遍；作品做完的出口（GIF / 精灵表 / PNG 序列）见[导出GIF与精灵表.md](导出GIF与精灵表.md)。
