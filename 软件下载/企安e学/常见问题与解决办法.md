## 一、先分清是哪一类问题

企安e学的问题基本落进三类：**账号侧**（后台没你这个人）、**权限侧**（摄像头、存储没给）、**应用侧**（包旧了、缓存坏了）。判断顺序按下面走，能少跑很多冤枉路：

| 症状 | 先怀疑 | 去哪看 |
| --- | --- | --- |
| 登录提示账号不存在 | 后台没录入 | 找单位管理员 |
| 登录提示密码错误 | 默认密码记错 | [登录账号和默认密码.md](登录账号和默认密码.md) |
| 人脸页打不开 / 黑屏 | 摄像头权限被拒 | 本篇第三节 |
| 登进去一片空白、没课程 | 班级与课程没分配 | 找单位管理员 |
| 点安装就失败 | APK 下载不完整 | [下载与安装教程.md](下载与安装教程.md) |
| 用一会儿就卡、闪退 | 版本旧、缓存脏 | 本篇第四节 |
| 每日一练没做被判错、周练不见了 | 规则本来如此 | [每日一练积分怎么算.md](每日一练积分怎么算.md) |

## 二、登录类

**提示账号不存在**：单位还没把你的手机号或身份证号录进后台，或者录的号与你填的对不上（换过手机号最常见）。登录页没有自助注册，也没法自己改，把你的姓名+手机号发给管培训的同事核对即可。

**提示密码错误**：默认密码是**手机号后六位**，不是身份证后六位、也不是全号。想不起来就让管理员在后台重置，登录页通常不提供找回。

**收不到验证码**：先看是否停机、是否被拦截软件吞了；换个方式用「账户密码登录」往往当场就绕过去了。连点重发会被限流，等倒计时结束。

## 三、人脸与权限类

**进人脸环节黑屏、闪退或一直转圈**：九成是摄像头权限。去系统设置 → 应用 → 企安e学 → 权限，把「相机」打开；顺手把「存储 / 文件」也给了，课程视频缓存才正常。

**人脸反复比对不通过**：按 [考试人脸识别注意事项.md](考试人脸识别注意事项.md) 里的姿势与光线要求再试一次；仍不过就是底图照片的问题，只能让管理员删底图、你重新上传，自己刷是刷不过来的。

**考试中途闪退回不到试卷**：先别重装，重新登录后回「任务 → 我的培训」看这场考试的状态 —— 还没结束就接着答，已显示交卷就以列表为准；状态确实不对再找管理员处理后台记录。

## 四、应用本身卡顿、闪退

- **先升到最新版**：商店里官方一直在更新（截至检索时商店页版本已高于本文整理的 v2.2.1，具体以官方商店页面当时显示为准）。装新版直接覆盖安装，不用卸载，账号和课程记录在服务端，不会丢。
- **清缓存**：系统设置 → 应用 → 企安e学 → 存储 → 清除缓存。缓存是视频进度的临时数据，清掉最坏情况是重新加载，不影响已完成的课时记录。
- **换新手机后数据看着变少**：学习记录跟着账号走，不跟设备走 —— 用同一个账号登录就在。前提是同一个手机号，用别的号登录等于一个全新账号。
- **多台设备交替用**：允许，进度以服务端为准；但**别两个人共用一个账号**，随机抓拍会记录实际操作者（见 [考试人脸识别注意事项.md](考试人脸识别注意事项.md)）。

## 五、什么时候必须找管理员

自己排完还剩这几种，都得单位管理员在后台操作，你在手机上无解：

1. 账号没录入、密码要重置、换绑手机号；
2. 底图照片要删掉重传；
3. 班级、课程、考试没分配到你名下；
4. 考试状态异常（进不去考场、交了卷没记录）。

把「姓名 + 手机号 + 具体现象 + 截图」一次性发给对方，比来回问三趟能省不少时间。
