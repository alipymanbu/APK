# 常见问题与故障排查

> 按「装不上 → 打不开 → 播不了 → 登录异常 → 数据丢失」的顺序排查 BiliPure 的高频问题。

## 一、安装失败 / 装不上

按顺序排除：

1. **系统版本不够**：安装时提示版本过低，对照本地记录的「安卓 5.2 以上」要求，过低就只能换设备。
2. **未知来源没开**：弹「禁止安装来自此来源的应用」时，按提示给浏览器或文件管理器打开「安装未知应用」开关，详见 [下载与安装教程.md](下载与安装教程.md)。
3. **安装包不完整**：断点下载、网络中断都会让 APK 损坏。从 [BiliPure 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d8ef8be45399) 重新下载 `BiliPure_v1.0.apk` 再装；下载后可用 `certutil` 核对 MD5（方法见 [和BiliPai是同一个软件吗.md](和BiliPai是同一个软件吗.md)）。
4. **与已装应用冲突**：若手机里已有包名相同的应用（包括签名不同的同包名包），先卸载旧的再装。

## 二、打开就闪退 / 黑屏 / 无响应

1. **清缓存**：设置 → 应用 → 应用管理 → 该应用 → 存储占用 → **清除缓存**，重开。
2. **清数据**：清缓存无效再**清除数据**（会清掉本地搜索与观看记录，登录信息也会退出，见第五节）。
3. **查权限**：同一页面的「应用权限」里，把存储等权限打开。
4. **重启手机**：清掉临时故障再说。
5. **卸载重装**：以上都无效就卸载，重新从网盘下载安装（回到第一节第 3 条）。

## 三、视频打不开 / 黑屏 / 卡顿

1. **先换视频**：只有一条打不开就是该视频源本身的问题，换一条测试；条条都打不开才继续往下查。
2. **换网络**：Wi-Fi 与流量互切一次；或关掉代理 / VPN 再试 —— 直链播放对网络出口很敏感。
3. **清缓存**：按第二节第 1 条操作后重启应用。
4. **验证是不是登录态的问题**：有用户在**别的**第三方客户端上反馈过「扫码登录后视频打不开、退出登录反而能播」（单个用户的反馈，不代 BiliPure 必然如此）。如果你的现象一致，先退出登录确认是否与登录态相关，再决定是否换用扫码或密码方式重登。
5. **弹幕卡顿**：网络切换后仍卡，等视频缓冲几秒或换个时段再看。

## 四、搜索没结果 / 列表加载不出来

- 关键词换成标题里的核心词（去掉长句），再试一次。
- 结果页切换筛选条件（播放量 / 发布时间 / 弹幕数，见 [搜索与播放设置怎么用.md](搜索与播放设置怎么用.md)）。
- 整个列表都空 → 先按第三节第 2 条排查网络；网络正常仍为空，可能是接口侧变动，只能等新版本。

## 五、登录不上 / 登录后异常

- **扫码页打不开**：确认手机网络正常、扫码确认端（官方 App）处于已登录状态，再重试。
- **密码登录失败**：改用扫码方式，避开输入环节的兼容问题。
- **登录后视频反而放不出来**：按第三节第 4 条退出登录验证。
- **登录方式只有两种**：扫码与账号密码，见 [登录账号与观看数据同步.md](登录账号与观看数据同步.md)；界面里没有的登录方式就是不支持。

## 六、清数据会丢什么

| 操作 | 本地搜索 / 观看记录 | 账号里的收藏、关注 |
| --- | --- | --- |
| 应用内清空搜索历史 | 只清搜索记录 | 不受影响 |
| 系统里「清除数据」 | 全部清掉，登录态也退出 | 不受影响，重新登录即恢复 |
| 卸载应用 | 全部清掉 | 不受影响，重装登录即恢复 |

收藏与关注存在账号侧，这也是「卸载重装不心疼」的原因。

## 七、关于版本与更新

手里这个包是 **1.0**（19.80M）。它没有应用商店渠道，不会自动提示更新；有无新版、去哪里拿，以发布方当时提供的为准。换包前先核对新包的包名与 MD5（[和BiliPai是同一个软件吗.md](和BiliPai是同一个软件吗.md)）。

也要有「停更」的心理准备：同类第三方项目已有两次收到函件后停止维护的先例（见 [第三方客户端登录会封号吗.md](第三方客户端登录会封号吗.md)）。所以某天突然搜不出、播不了，先按第四节判断是不是接口侧变动 —— 那种情况等不来修复，换回官方 App 即可（取舍见 [和官方哔哩哔哩App有什么区别.md](和官方哔哩哔哩App有什么区别.md)）。
