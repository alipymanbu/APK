## 一、这是个什么形态的应用

CosyVoice输入法是通义云启（杭州）信息技术有限公司出的安卓输入法应用，包名 `com.tongyi.funaudio.cosyvoice`，手机和平板都能装 —— 小米应用商店把它归在「实用工具」，明确标注支持手机、平板两类设备。它和传统输入法的区别是主用语音：你在微信、浏览器、备忘录等任意 App 的输入框里口述，它把话转成文字填进去，同时保留九宫格、全键盘这些打字方式兜底。

这款应用 2026 年 6 月 27 日首次发布，同期上线 macOS、iOS 与安卓三端；Windows 版在官网上标注为「敬请期待」（截至 2026-09 检索，以官网当时显示为准）。安卓商店里的名字是「CosyVoice输入法」，iOS App Store 里叫「CosyVoice」，开发者是同一家。

## 二、安装包从哪拿

两条路，按你的情况选：

1. **网盘这份**：[CosyVoice输入法 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5a3e876b8404)。这是保存下来的那一版，具体事实如下（与商店里的最新版不是同一版，属正常）：

   | 项目 | 值 |
   | --- | --- |
   | 版本 | 1.1.0 |
   | 包名 | `com.tongyi.funaudio.cosyvoice` |
   | 大小 | 17.25M |
   | MD5 | `9a7d0a655ee8b31e1b30adc3f8c1ce2c` |
   | 保存日期 | 2026-09-22 |

2. **官方渠道**：手机应用商店搜「CosyVoice输入法」，或到[官网](https://cosyvoice.org.cn)找对应平台的下载入口。商店里的版本通常比网盘这份新 —— 小米应用商店在 2026-09-20 的版本是 2.0.0、93.97M，**具体以商店当时显示为准**。

两条路拿到的是同一个包名 `com.tongyi.funaudio.cosyvoice`，覆盖安装不会变成两个应用，账号数据跟手机号走。

**体积差一大截是正常的**：网盘这份 1.1.0 只有 17.25M，商店的 2.0.0 是 93.97M —— 中间隔着好几个版本的功能累加（随记、九宫格、暗黑模式都是 1.4.0 之后才有的，见 [随记功能与AI总结怎么用.md](随记功能与AI总结怎么用.md)）。装哪一版由你定；本文其余各篇写的是较新版的界面，老版找不到对应入口时以应用内实际界面为准。

## 三、安装步骤

1. 从网盘把 `CosyVoice输入法_v1.1.0.apk` 下到手机。
2. 点开文件开始安装。系统若弹「禁止安装来自此来源的应用」，是拦截未知来源 APK 的常规提示 —— 去设置里允许本次安装即可（不同品牌路径略有差异，一般在「设置 → 安全/隐私 → 安装未知应用」）。
3. 装完先别急着打开，按下一节把输入法启用并切过去。

**校验是不是同一份包**（可选）：装之前用文件管理器或校验工具比对 MD5，与上表一致即为网盘里这份。

## 四、启用并切换输入法（第一次必做）

输入法类应用装完不会自动生效，必须手动走一遍：

1. 打开 CosyVoice输入法，按引导进入「启用输入法」，在系统的输入法列表里打开它。这一步系统会弹一条安全提示（安卓对所有第三方输入法都会弹），看完自己决定。
2. 回到应用，进入「切换输入法」，把它设为当前正在使用的输入法。
3. 打开任意能输入的界面，点输入框 —— 弹出来的键盘应该已经换成 CosyVoice输入法。
4. 首次点语音输入时按提示点「继续」，并允许**麦克风**权限。不给麦克风，语音转文字就用不了；打字功能不受影响。

小米应用商店列出的该应用权限如下：

| 权限 | 用途 |
| --- | --- |
| 录音 | 语音转文字的必需权限 |
| 查看网络状态 / 开关 WLAN / 更改网络连接 / 完全的互联网访问 | 转写与纠错走云端，需要联网 |
| 控制振动器 | 按键振动反馈 |
| 防止手机休眠 | 长时间录音转写时不中断 |
| 前台服务（麦克风类型） | 录音过程中保持运行 |

**录音与网络是必需的**，其余属常规配套；具体怎么管控见 [隐私政策与权限说明.md](隐私政策与权限说明.md)。

## 五、首次启动会经历什么

- **登录**：应用用手机号注册并登录（接收验证码的那个手机号，也是官方与你联系的方式之一）。隐私政策写明：拒绝提供手机号，就无法使用该应用。桌面端另外支持淘宝账号登录。
- **界面语言**：可在个人主页里切换界面显示语言，默认是中文。
- **首页能看到什么**：累计口述字数、过往的输入历史；界面中间的图标是热词入口，点进去能查看已有热词并手动添加新的，具体见 [方言识别与热词设置.md](方言识别与热词设置.md)。
- **权限按需给**：麦克风是语音输入的门槛，其余权限等用到对应功能时再给也不迟。

## 六、装不上或打不开时

解析包错误、安装后闪退、键盘唤不出来，多半是下载不完整、权限没给齐或默认输入法没切过去 —— 完整的排查顺序见 [常见问题与故障排查.md](常见问题与故障排查.md)。
