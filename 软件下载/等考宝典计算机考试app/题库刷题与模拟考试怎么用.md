## 一、先想清楚你要考什么

你刷题的目的是过 NCRE，所以第一步是在 app 里选对**级别和科目**（一级 MS Office、二级 Python 这一层）。选错了练得再熟也是白练 —— 科目清单与 app 的覆盖对照见 [考试科目与题库覆盖范围.md](考试科目与题库覆盖范围.md)。考试什么时候考、怎么报名，见 [报名时间与考试形式.md](报名时间与考试形式.md)。

## 二、各模块是干什么的

官方介绍里列出的功能，按你的使用顺序整理：

| 模块 | 你拿它做什么 |
| --- | --- |
| 知识点专项练习 | 按章节逐个知识点过，第一遍打基础用它 |
| 历年真题 | 一整套一整套地做，最接近真实卷面 |
| 模拟考试 | 限时整卷，练时间分配 |
| 错题练习 | 收做错的题，考前反复过 |
| 考前押题 / 密卷 | 考前一段时间的冲刺卷 |
| 视频解析（选择题/综合题考点视频） | 题看解析还看不懂时，看对应考点的讲解视频 |
| 直播公开课 | 有固定时间的直播课，需要预约 |

## 三、一条比较稳的刷题路径

1. **章节/知识点练习过一遍**，错题自动进错题库。
2. **做 2~3 套历年真题**，严格按考试时长（二级 120 分钟）计时，中间不查资料。报语言类、数据库类科目的，每次做完单独看选择题正确率 —— 它不到一半总分就直接不及格，规则见 [考试科目与题库覆盖范围.md](考试科目与题库覆盖范围.md) 第四节。
3. **针对错题回炉**：错题库里哪类错得多，回对应章节再练。
4. **考前一周做模拟考试与押题卷**，把分数稳定在目标线上。

手机上刷选择题、看解析效率最高；**二级 MS Office / WPS 的操作题，手机上只能看题和看演示，你必须在电脑上亲手做一遍** —— 真实考试是 Windows 上机操作，看会了不等于会做。电脑上怎么还原考场环境、怎么计时，见 [操作题上机练习方法.md](操作题上机练习方法.md)；考试安排见 [报名时间与考试形式.md](报名时间与考试形式.md)。

## 五、视频和直播怎么看

- **录播视频**（真题解析、考点视频）：在对应题目或课程入口点开即看，部分是内购内容，非会员会提示付费。
- **直播课**：需要预约；给了日历权限的话，预约成功会在系统日历里加一条提醒。直播错过了通常有回放，以 app 内实际入口为准。

视频播放不出来（黑屏、转圈、没有声音）按 [常见问题与解决方法.md](常见问题与解决方法.md) 排查。
