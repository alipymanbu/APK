## 二、从网盘拿安装包

1. 打开 [等考宝典计算机考试 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e55afad127fa)。
2. 转存到你自己的网盘（或直接下载），文件名是 `等考宝典计算机考试app_vv8.9.6.apk`。
3. 手机上下载的话，用夸克 App 打开分享链接 → 转存 → 在网盘里点该文件下载；电脑上下载后可以传到手机。

安装包约 46.5M，建议在 Wi-Fi 下下载。

## 三、安装步骤

1. 在文件管理器里点这个 `.apk`。
2. 如果系统提示「禁止安装来自此来源的应用」：点提示里的**设置**（或到 设置 → 安全/隐私 → 安装未知应用），给对应的来源（比如文件管理器、浏览器、夸克）打开「允许」，返回再点安装。
3. 安装完成后点「打开」，或回桌面找图标。
4. 装完可以把安装包删掉，应用本身不依赖这个 apk 文件。

部分品牌手机（小米、华为等）在首次安装时还会问一次「是否允许安装」，按屏幕提示确认即可。

## 四、首次启动要给的权限

打开后它会逐项要权限，用途如下，按需给：

| 权限 | 它拿去做什么 |
| --- | --- |
| 存储 | 保存题库数据和题目图片 |
| 摄像头 | 设置头像时拍照 |
| 日历 | 预约直播课时加提醒 |
| 电话（读取设备信息） | 统计崩溃与错误日志 |

不确定的可以先拒绝，用到对应功能时再给 —— 比如不约直播可以不给日历。

## 五、装完核对

到 设置 → 应用 → 等考宝典计算机考试 → 应用信息，看版本号是不是 `8.9.6`。想确认安装包没下错、没损坏，可以在电脑上校验 MD5（PowerShell 里执行）：

```powershell
certutil -hashfile "等考宝典计算机考试app_vv8.9.6.apk" MD5
```

输出应为 `b493a2769b0755d4eb7b779cf573949e`（大小写不敏感），不一致说明文件不完整或被改过，重新下一次。

装不上、装完打不开，按 [常见问题与解决方法.md](常见问题与解决方法.md) 逐条排；装好了想先看刷哪些题，看 [题库刷题与模拟考试怎么用.md](题库刷题与模拟考试怎么用.md)。
