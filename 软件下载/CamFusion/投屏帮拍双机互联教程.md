## 一、投屏帮拍解决什么问题

一个人给你拍人像时，最常见的别扭是：模特看不到取景框，姿势表情全靠摄影师喊。CamFusion 的投屏帮拍把摄影师手机的取景画面实时同步到模特手机上，模特自己就能看到「镜头里的我」，边看边调整；确认姿势到位后直接远程触发快门，不用来回跑。

适合的场景：

- 朋友互助拍人像，谁都不想反复「再拍一张试试」；
- 你独自出片时把一台旧手机当「镜子」用，随时看自己在画面里的状态；
- 短视频分镜拍摄，需要另一端帮忙确认构图。

## 二、连接步骤（热点直连）

互联走的是两台手机之间的直连，不依赖路由器和流量：

1. **主拍摄手机**（装在相机位的那台）：进系统设置打开「个人热点」，可以不给热点连任何外网；
2. **模特手机**：Wi-Fi 列表里连上这个热点，注意连的是同一个频段（2.4 GHz 或 5 GHz 二选一，两端一致）；
3. 两台手机都打开 CamFusion，在首页找到「投屏帮拍」入口（不同版本也叫双机互联帮拍，名字以你手机上的为准），按界面提示建立互联——进入功能页后两端先各选角色：拍摄端选「摄影师」，预览端选「模特」，选反了画面方向就对不上；
4. 连上后模特端出现实时取景画面，模特边看边调姿势表情；
5. 由摄影端或模特端远程触发快门，成片保存在主拍摄手机里。

如果你还没装应用，安装与版本口径见 [下载与安装教程.md](下载与安装教程.md)。

## 三、设备方面的注意点

- 两台手机都要能正常打开 CamFusion，这是最基本的前提；官方没有公布机型兼容清单，实际能不能连以你手上的两台设备试了为准；
- 互联靠热点直连，对手机品牌没有公开的限制说明，安卓对安卓是最稳的组合；
- iOS 版是另一套安装包，官方资料里没有提跨安卓 / iOS 互联的说明，跨系统组合不要抱预期。

## 四、连不上时的排查顺序

按下面这张表从上往下试，多数问题出在前两行：

| 现象 | 先查什么 |
| --- | --- |
| 模特手机搜不到热点 | 主拍摄手机的热点是否真的开着；热点频段若是 5 GHz，老旧设备可能搜不到，改成 2.4 GHz 再试 |
| 搜到了但连不上 | 两台手机离近一点；关掉各自的 VPN 和「智能选网」类功能 |
| 连上但画面卡住不动 | 双方都杀掉 CamFusion 后台重新进；确认连接建立时没有弹窗在等确认 |
| 画面同步但延迟明显、卡顿 | 实时预览走的是局域网直连传输，把两台手机上占带宽的后台应用（视频、下载类）关掉；距离再拉近一点 |
| 画面有但快门没反应 | 确认哪一端是「拍摄端」——远程快门是从非拍摄端触发的，端别搞反了 |
| 系统弹「该热点无法上网是否保持连接」 | 选保持连接，直连本来就不走外网，这一步点了取消会直接断开 |

## 五、拍的时候怎么配合更顺

- 开拍前先定机位高度和距离，模特端固定能看到全身或半身，再开始调姿势，避免边拍边挪三脚架；
- 远程快门和倒计时二选一就够了：有人拿手机就用远程快门，手机架起来就设倒计时；
- 拍完的成片在主拍摄手机的相册里，模特端只是预览屏，别在模特端翻找照片。
