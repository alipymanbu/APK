## 一、先弄清你要装的是哪个版本

网上应用商店能搜到的 CamFusion 是官方最新版，版本号走得很快；下面这份表格是**本次网盘里这份安装包的实际信息**，装之前先对一眼：

| 项目 | 信息 |
| --- | --- |
| 版本号 | 3.4.1 |
| 安装包大小 | 350.92 MB |
| 包名 | com.example.remote_camera |
| MD5 | 7A71D326016B15A9E63CEEF7E3C81E51 |
| 系统要求 | 安卓 5.2 以上（以实际安装环境为准） |
| 开发者 | 量界信息技术（澄迈）有限公司 |

两个提醒：

1. **版本差异会影响功能入口**。官方商店里的新版（5.x 系列）在功能命名和界面上有调整，你看到的攻略截图若和你手机上的对不上，多半是版本差异，以应用内实际界面为准。
2. **可以核对文件完整性**。在电脑上下载好安装包后，用 PowerShell 执行 `certutil -hashfile "文件路径.apk" MD5`，输出的值与上表 MD5 一致说明包没下坏。

## 二、从网盘转存到手机

还没转存的，先把 [CamFusion 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9e0202ec85a3) 保存到自己的网盘，再按下面的顺序走：

1. 手机打开夸克 App，登录账号，打开上面的分享链接，点「保存到网盘」转存到自己账号里；
2. 转存完成后，在「我的网盘」里找到这个 APK 文件，点「下载」到手机本地；
3. 下载完成后在通知栏或夸克的下载列表里点开 APK，系统会弹出安装确认；
4. 第一次装会提示「禁止安装未知来源应用」，按提示跳到系统设置，允许你的文件管理器（或夸克 App）安装应用，再回到安装页点「安装」；
5. 等安装进度走完，点「打开」或回桌面点图标启动。

也可以在电脑上下载 APK 后用数据线传到手机再安装，路径不影响结果，关键是装的就是这一份 350.92 MB 的包。

## 三、安装前的三项检查

- **存储空间**：安装包本身 350.92 MB，安装解压后占用的空间更大，手机存储建议至少留出 1 GB 余量；
- **旧版本冲突**：手机里如果之前装过其他来源的 CamFusion，签名不一致会导致安装失败，先卸载旧版再装；
- **电量与网络**：350 MB 的包建议在 Wi-Fi 环境下下载，电量低于 20% 时先充电再装，避免安装中途断电。

## 四、安装报错对照表

| 现象 | 常见原因与处理 |
| --- | --- |
| 「解析包时出现问题」 | 包下载不完整，回网盘重新下载一遍，或下载后核对 MD5 |
| 「应用未安装」/ 安装按钮灰色 | 手机里有旧版本残留，先卸载；部分机型需在系统设置里关闭「纯净模式 / 安装拦截」 |
| 「存储空间不足」 | 清理出 1 GB 以上空间再装 |
| 装完点开没反应 | 参照 [常见设置与问题排查.md](常见设置与问题排查.md) 的启动问题一节逐项试 |

## 五、装完后的第一步

首次启动 CamFusion 会依次请求相机、照片（相册）、麦克风等权限：相机权限不给没法拍摄，相册权限影响你导入照片和保存成片，建议按需允许。进到首页后你会看到补光美拍、视频抽帧、投屏帮拍这些功能入口，从哪里开始用，分别见 [补光美拍与创意玩法.md](补光美拍与创意玩法.md)、[视频抽帧与实况照片导出.md](视频抽帧与实况照片导出.md) 和 [投屏帮拍双机互联教程.md](投屏帮拍双机互联教程.md)。
