## 一、常用设置项在哪

下面这些入口来自公开资料整理，不同版本界面命名会有出入，找不到就以你手机上的实际菜单为准：

**闪光灯**：进入相机界面，点右上角的功能菜单（省略号图标），最上面一栏是闪光灯开关，按需开、关或自动。

**高分辨率**：首页左上角的三个圆点进设置，找到「高分辨率」开关打开。开了之后拍出来的原片细节更多、文件也更大，存储紧张的话拍完及时导出清理。

**自动拍照**：设置页里找「自动拍照 / 定时拍摄」类选项，可以开关定时模式并调整参数，架起手机拍合照时用得上。

**账号登录**：切到「我的」页面，点左上角的游客头像，在弹窗里点登录，选邮箱登录，填入邮箱地址和收到的验证码即可。登录用于账号相关能力（如跨设备同步），不登录以游客身份拍摄也不受影响。邮箱验证码收不到时先翻垃圾邮件箱；提供手机号验证码的版本可以换手机号登录。

**开屏动画**：进「我的」页面（首页右下角的人物图标），点设置，里面有开屏动画的开关，关掉以后启动直接进功能页。不同版本这个开关的位置可能有出入，找不到就在设置页里翻一遍。

## 二、安装与启动故障对照

| 现象 | 处理 |
| --- | --- |
| 打开就闪退 | 先确认已允许相机权限（部分机型权限被拒时启动会直接退出）；不行就重启手机再试 |
| 启动卡在开屏 | 等待时间过长时杀后台重进；反复卡住参考安装篇核对包是否完整 |
| 拍摄画面卡顿 | 关掉高分辨率档试一下；后台应用清一清，中低端机型高分辨率拍摄压力不小 |
| 前后双摄画面不同步 | 多见于旧机型：前后摄像头帧率对不齐属于硬件限制，先更新到新版看是否改善，改善不了就避开双摄同框拍重要素材 |
| 相册里看不到拍的照片 | 检查相册（存储）权限是否被拒，权限补上后重新拍一张验证 |
| 导出的照片找不到 | 见 [视频抽帧与实况照片导出.md](视频抽帧与实况照片导出.md) 的导出位置一节 |

安装环节的报错（解析包错误、安装按钮灰色等）在 [下载与安装教程.md](下载与安装教程.md) 的报错对照表里，两篇配合看。

## 三、会员与导出

官方商店页对权益的口径是一致的：Pro 会员可以无限导出图片并去掉广告。几点你需要知道的：

- **免费额度**：第三方资料整理的 3.4.x 时期口径是免费版每月约 10 张照片、6 个视频的导出额度，实际剩余额度以应用内「个人中心」的显示为准，导出前先看一眼，免得拍完才发现额度用完；
- **iOS 端**：App Store 页面标注的订阅价为每周 1.99 美元、每月 3.99 美元、每年 9.99 美元（截至 2026 年 9 月，以 App Store 当时显示为准）；内购列表里还出现过终身买断档位，具体档位与价格以你设备上的应用内页面为准；
- **取消续费**：订阅随账号自动续费，应用内无法直接终止扣费——iOS 去「设置 → Apple ID → 订阅」里关，安卓去系统设置里对应账号（如 Google 账户）的订阅管理里关；续费扣款发生在到期前 24 小时，想退要提前动手；
- **安卓端价格**：以应用内会员页为准，公开资料里没有统一报价；
- **遇到问题要反馈**：官方联系邮箱是 [support@quantum-realm.ltd](mailto:support@quantum-realm.ltd)，隐私政策与用户协议在官方页面（`https://mirrorcamera.sharpofscience.top/privacy.html`），以应用内「联系我们」入口指向的地址为准。

## 四、权限清单：每一项给不给

首次启动会集中弹权限，各项权限的用途：

| 权限 | 不给的后果 |
| --- | --- |
| 相机 | 无法拍摄，投屏帮拍、抽帧全部用不了 |
| 照片 / 存储 | 无法导入照片做抠图，导出也会静默失败 |
| 麦克风 | 录制带声音的视频受影响，只拍照可以不给 |
| 网络 | 投屏帮拍的建立过程与账号登录需要，拒了会影响这两项 |

给的路径都在系统「设置 → 应用 → CamFusion → 权限」里，随时可以改。
