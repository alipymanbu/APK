## 一、基本公式

文生图提示词的通用写法是按层描述，这几层覆盖了绝大多数场景：

```
主体 + 风格 + 光线 + 构图 + 细节
```

| 层 | 回答的问题 | 常用词举例（英文效果更稳） |
| --- | --- | --- |
| 主体 | 画面里是什么 | `a lighthouse on a rocky cliff`（别只写 `a house`） |
| 风格 | 像什么画种/质感 | `oil painting` / `watercolor` / `anime` / `cinematic photo` |
| 光线 | 什么光、什么氛围 | `golden hour` / `neon glow` / `soft shadows` / `rim lighting` |
| 构图 | 镜头怎么看它 | `close-up` / `wide angle` / `shallow depth of field` / `bird's eye view` |
| 细节 | 材质与收尾 | `detailed fur` / `metallic surface` / `film grain` / `8K detail` |

写的时候抓 4~6 个强描述词就够，别把想到的词全堆进去——堆太多反而出一张杂乱的图。

## 二、常见错误写法

多份提示词指南点名的几类问题，都直接对应「出图不对劲」：

- **只有一两个词**：`a cat` 这类词让模型自己脑补一切，结果随机性极大；
- **风格互相打架**：`minimalist hyper-detailed`（极简又超细节）这类矛盾组合会让画面两头不靠；
- **写成小作文**：长段落叙事不是提示词的正确形态，按公式分层写短句更有效；
- **重复同一个词指望加强**：重复不加深效果，只会占用描述预算；
- **忽略画幅**：构图重要时记得在 starryai 里选好画布比例（1:1 / 4:3 / 9:16），比例和构图词要配套。

## 三、同一需求的改写示例

从弱到强改写一条提示词，感受各层加上去的变化：

```
弱：a dragon
中：a dragon on a castle tower
强：a biomechanical dragon perched on a Gothic cathedral tower,
    concept art, dramatic rim lighting, detailed metallic scales,
    low angle shot
```

再比如把随手拍风景变成插画：

```
弱：beautiful lake
强：a turquoise mountain lake at dawn, soft watercolor illustration,
    gentle mist over the water, warm ambient glow, wide angle
```

## 四、starryai 里能帮上忙的工具

- **风格预设**：一千多个预设本身就是打包好的「风格+质感」描述，选一个预设、提示词里集中写画面内容，是新手最省力的组合；
- **Prompt Builder**：应用内自带的提示词组装工具，不知道从哪下笔时用它按层补齐描述；
- **Evolve**：先随便生成一轮，从 4 张里挑最接近的，再演化迭代——比第一轮就追求完美更省积分（积分口径见 [收费与积分说明.md](收费与积分说明.md)）。

## 五、语言与迭代习惯

- 提示词支持中文输入，但英文描述的匹配精度通常更高；中文可以先用翻译工具过一遍再粘进去；
- 把提示词当草稿迭代：每轮只改一层（比如只换光线词），对比改动带来的差异，比整句重写更容易摸到规律；
- 出图持续翻车（手部崩坏、面部崩坏）属于模型的已知短板，处理手段集中在 [常见问题与解决方法.md](常见问题与解决方法.md) 第二节，先看那里再怀疑自己的提示词。
