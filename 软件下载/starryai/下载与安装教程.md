## 二、从夸克网盘获取安装包

1. 打开头部列出的 **starryai 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/57572d308d22](https://pan.quark.cn/s/57572d308d22)，转存到自己网盘后下载 `starryai_v2.16.1.apk` 到手机；
2. 下载完成后在通知栏或文件管理器里点开这个 apk 文件；
3. 如果下载到的是电脑，再传到手机时用数据线、微信文件传输助手、或任意你顺手的传输方式都行，apk 文件本身不挑传输方式。

## 三、核对安装包完整性（MD5）

网盘下载大文件偶尔会传不完整，装不上「解析包出现问题」时，先核对 MD5 再怀疑别的：

- **在电脑上核对**：Windows 打开 PowerShell 执行 `certutil -hashfile "starryai_v2.16.1.apk" MD5`（文件路径按实际位置写），输出值与 `35576FF16558A1FFED37007EED0330F1` 一致（不分大小写）就是完整包；
- **在手机上核对**：部分文件管理器自带「文件属性/校验值」功能，能看到 MD5 就直接比对；没有的话装到手机上再核比较折腾，建议传回电脑核一次；
- **对不上怎么办**：删掉重新下载一次；再对不上就换网络环境下载。

## 四、安装步骤（安卓）

第一次安装非商店来源的 apk，安卓会拦一道，不同的手机品牌拦截的位置略有差别：

1. 点击 apk 文件，系统弹出「是否允许安装」时选「允许」；
2. 若提示「禁止安装未知来源应用」，按提示跳到设置页，把「允许从此来源安装应用」的开关打开（小米在「应用设置-权限管理」，华为在「更多安全设置」，OPPO/vivo 在「安装外部来源应用」里，名称以你的系统为准）；
3. 回到安装界面点「安装」，等待十几秒到一分钟；
4. 装完点「打开」，或在桌面找到 starryai 图标点开。

## 五、装不上或打不开的常见原因

| 现象 | 原因与处理 |
| --- | --- |
| 提示「解析包时出现问题」 | 安装包没下完整，重新下载一次；或手机安卓版本低于包的要求 |
| 提示「应用未安装」且手机里装过 starryai | 同包名旧版还在，先卸载旧版再装；签名不一致时只能卸载后重装 |
| 提示存储空间不足 | 清出至少 200 MB 空闲空间再装（安装过程比包体本身更占空间） |
| 安装成功但一打开就闪退 | 先重启手机再试；仍闪退多半是系统版本或机型兼容问题，可到官方渠道看是否有适配说明 |
| 打开后一直转圈/白屏 | 生成功能需要联网，检查网络；国内直连访问其服务器不稳定时，换网络环境再试 |
