## 一、先分清是哪种症状

| 症状 | 大概率原因 | 直接看 |
| --- | --- | --- |
| 打开一直转圈 / 报「creature data」加载失败 | 网络取不到数据 | 第二节 |
| 报「JSON parse error」 | 官方数据端出错 | 第二节第 6 条 |
| 装不上、安装被拦截 | 未知来源权限没给 | [下载与安装教程.md](下载与安装教程.md) |
| 驯完时间和游戏里差很多 | 倍率没设对 | [服务器倍率设置方法.md](服务器倍率设置方法.md) |
| 击昏发数比实际少 | 武器列表没按自己数值填 | [驯服计算器使用教程.md](驯服计算器使用教程.md) |
| 换机后设置全没了 | 设置存在本地，重装即清 | 第四节 |

## 二、数据加载失败怎么办

App 每次启动都要从官网拉最新生物数据，所以**没有网络就什么都查不了**。官方给的排查顺序是这样的，从上往下试：

1. **强行关闭再开**：`设置 → 应用 → Dododex → 强行停止`，然后重新打开。很多报错只是没清干净的进程状态。
2. **手动刷新数据**：点左上角菜单 → **Settings / Multipliers** → 拉到最底部点 **Check for New Data**，让 App 重新拉一遍。
3. **换网络试**：Wi-Fi 不行走流量，或反过来。能判断出是 App 的问题还是这条网络的问题。
4. **检查有没有单独禁掉这个 App 的流量**：手机状态栏显示有网、App 却报 `Network request failed`，多半是流量权限被单独关了（`设置 → 应用 → Dododex → 流量`）。
5. **确认浏览器能打开官网**：用手机浏览器访问 [dododex.com](https://www.dododex.com)。有些网络（学校、公司、或运营商的家庭控制功能）会拦游戏类站点，官网打不开 App 也就取不到数据。
6. **报 JSON parse error**：这是官方数据端本身的错误，等它修，或把完整报错截图发给开发者（见第六节）。
7. **重装（最后手段）**：前六步都无效再重装。**重装会丢掉本地设置** —— 倍率、收藏、自定义武器列表都要重填，先把数值抄下来。

## 三、装完打不开 / 闪退

- 先确认装的包和手机系统对得上（本地记录标注安卓 5.2 以上，较新版本官方商店标注 7.1 以上，以安装时的提示为准）。
- 检查是否有系统更新待装、存储是否快满。
- 清一次缓存：`设置 → 应用 → Dododex → 存储 → 清除缓存`（**先只清缓存**，清数据会连本地设置一起删）。
- 还不行就按 [下载与安装教程.md](下载与安装教程.md) 重新下载安装包核对 MD5，再装一次。

## 四、本地设置丢了怎么快速恢复

重装、换机、换版本都会清掉存在本地的东西。开新设备前先抄三样：

1. **倍率数值**（驯服速度、进食速度、孵蛋速度、成长速度）—— 事后凭记忆很难还原，而它决定了所有计算结果，见 [服务器倍率设置方法.md](服务器倍率设置方法.md)；
2. **自定义武器列表**的伤害数值；
3. 收藏的生物与配方（这个只能重点）。

## 五、数值不对、估算偏低

- **时间和游戏对不上**：先按 [服务器倍率设置方法.md](服务器倍率设置方法.md) 逐项核对，重点检查活动周末有没有翻倍、单人设置的开关状态。
- **击昏发数比实际少**：按下面四条依次排除 —— 官方给的说法是这四类最常见：
  1. **两发间隔没设对**：麻醉在两发之间是会掉的，间隔填得太短等于高估了累积量；填法见 [驯服计算器使用教程.md](驯服计算器使用教程.md)。
  2. **实际打得太慢或脱靶**：你打的间隔比设定的长，掉的量抵掉了几发。
  3. **实际打得太快**：上一发的麻醉还在结算，画面没晕不等于不够 —— 等积压走完再判断，别继续加射。
  4. **命中判定偏差**：客户端画面和服务器判定会不同步，看着打中、服务器算作未命中；爆头也一样，命中盒的位置不总和你以为的一致。小型快速生物更容易出现。
  排除完仍觉得离谱，官方口径是「多带补给」并把实测反馈给他们。
- **属性计算器数字不对**，四个已知原因：
  - 你填的是**驯服后的生物** —— 它只算野生的，驯后算法完全不同；
  - 服务器**改过野生生物属性**，这类自定义值它不支持；
  - 装了改属性的**模组**（比如提升飞行生物耐力的那类），它不支持；
  - 你在 **ARK Mobile** 上查飞行生物的耐力 —— 手游版数值和 PC/主机不同，那一项算不准。
- **有效度比预期低**：不是算错，是打晕时掉血太多或喂的食物口数太多，见 [驯服有效度怎么保住.md](驯服有效度怎么保住.md)。
