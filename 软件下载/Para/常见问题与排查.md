## 一、怎么快速定位是哪一类问题

本篇按「装不上 / 打不开 / 数字人不回复 / 没声音 / 记录丢了」五类现象来组织：先教你怎么判断属于哪一类，再逐类给排查顺序。原则是——先做便宜的操作，卸载重装放最后。

| 现象 | 更可能是 | 先做 |
| --- | --- | --- |
| 装都装不上 | 安装包或系统权限 | 见第二节 |
| 打得开但一直转圈 | 网络或服务端 | 见第三节 |
| 能进、能看，但数字人不理你 | 会话或记忆状态 | 见第四节 |
| 声音有问题 | 权限或系统通道 | 见第五节 |
| 记录不见了 | 账号或本地数据 | 见第六节 |

## 二、装不上：解析包错误、安装按钮点不动

1. **「解析包时出现问题」**：文件没下完或者传坏了。回 [下载与安装教程.md](下载与安装教程.md) 第二节核对文件大小与 MD5，对不上就重下。
2. **安装按钮是灰的**：多数是「安装未知应用」权限没开，或者系统里还留着一个同包名的高版本安装记录。先在「设置 → 应用」里搜 `com.ymtx.abc`，有的话卸载残留再装。
3. **提示「应用未安装」**：先在「设置 → 存储」里留出 1GB 以上空间 —— 安装包 109.33M，装完加上运行缓存会占更多。
4. **装完桌面没有图标**：在应用抽屉里搜一次「Para」；确实没有，说明安装没成功，回到第 1 步。

## 三、打得开但一直转圈、动态刷不出来

按顺序做，前三步能解决绝大多数情况：

1. **切换网络**：Wi-Fi 与移动数据各试一次。这类应用在国内直连，网络环境正常时不应该卡在加载页。
2. **确认没有被系统限制联网**：在「设置 → 应用 → Para → 流量使用」里，确认「移动数据」和「Wi-Fi」都是允许的。
3. **强制关闭再打开**：从后台任务里划掉，重进。
4. **看是不是只有广场刷不出来**：只有广场空、数字人那边正常，说明不是你的网络问题，隔一段时间再看。
5. **清一次应用缓存**（不是「清除数据」）：设置 → 应用 → Para → 存储 → 清除缓存。清缓存不会删账号与聊天记录，清除数据会，别点错。

## 四、数字人不回复、回复变敷衍

先分清是「网络问题」还是「记忆问题」：

- **发出去的消息一直是发送中** → 网络类，回到第三节；
- **秒回，但内容答非所问、来回就那几句** → 上下文类，按下面处理：
  1. 换话题，别重复追问同一句；
  2. 回「记忆」里检查有没有一条错误的旧信息在带偏它，删掉后再试；
  3. 强退重开一次，让它重新加载上下文；
  4. 还是不行，换到「扮演」模式给它一个明确场景，通常是旧语境卡死了。

具体的记忆纠错方法见 [记忆与好感度怎么用.md](记忆与好感度怎么用.md) 第三节。

## 五、语音没声音、说话识别不准

先做一次 30 秒分流测试：进通话说一句短话，看屏幕上有没有出现和你说的内容相关的文字。

- **有文字、没声音** → 问题在输出侧，走第 2、3 条；
- **连文字都没有** → 问题在输入侧，走第 1、4 条。

不要两边一起改，改完一轮再测一次，否则你分不清是哪一步起了作用。

1. **确认麦克风权限**：设置 → 应用 → Para → 权限 → 麦克风，允许。注意首次拒绝过之后，系统可能不会再自动弹窗，必须自己进来开。
2. **媒体音量不等于铃声音量**：通话是媒体流，先把媒体音量调上去；再确认没开「勿扰模式」、没连着一副已经拿掉的蓝牙耳机 —— 声音常被路由到已断开的设备上。
3. **蓝牙是输入问题的头号原因**：连着蓝牙耳机、手表、车机时，系统会把默认输入切到它们。**断开蓝牙再测一次**，如果通了，说明是输入设备被抢，改成用手机自带麦克风即可。
4. **用系统录音做对照**：打开手机自带的录音机录 10 秒。录音也没有波形，说明是设备或系统权限的问题，不用再折腾应用；录音正常而 Para 不行，才是应用侧的问题。
5. **你说的它听错**：说完在文字框里核对一遍再发，转错了直接改文字。噪音大的环境先换地方，或者戴上耳机缩短停顿，识别率会明显好一些。
6. **声音断断续续**：网络问题，见第三节。

## 六、聊天记录不见了、换手机怎么办

- **同一账号换设备**：先确认登录的是同一个账号，记录是跟着账号走的。
- **想知道内容存在哪、怎么删**：见 [聊天内容和隐私怎么把握.md](聊天内容和隐私怎么把握.md)，里面有删除入口的查找顺序。
- **自己手滑清了数据**：在上一步的「清除数据」按钮上出过问题的，本地记录很难找回，只能从零开始。所以**重要信息别只留在聊天里**，写进「记忆」的也更稳一些。
- **卸载重装的顺序**：重装不会自动恢复本地内容，重装前先在「记忆」里把要紧的信息截图或抄下来。重装需要重新获取安装包，入口仍是 **[Para 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b3b468ebdace)**，装完按 [下载与安装教程.md](下载与安装教程.md) 第二节核对一遍文件。

## 七、要不要重装：给一个判断标准

重装只解决「本地文件损坏」这一类问题，不解决网络和服务端问题。所以：

1. 先做完第三节和第四节的排查；
2. 只有**每次都卡在同一个界面、清缓存无效**时，才卸载重装；
3. 重装前先记录账号密码，否则登不回去，前面的记录也一起丢。

最后提醒一句：网上名字里带 Para 的应用不止这一款，**认准包名 `com.ymtx.abc`** 再操作，别按别的应用的教程去改设置。
