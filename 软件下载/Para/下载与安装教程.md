## 一、Para 是什么，装之前先对一件事

Para 是深圳市游迷天下科技有限公司开发的一款安卓 AI 陪伴类应用。装好之后你会看到两个区：一边是你的专属数字人（官方也叫「AI 伴侣」），能文字聊天、发语音、通话；另一边是真实用户发的动态广场。本篇只解决「怎么装上、怎么进得去」，数字人怎么捏、怎么聊分别见另两篇。

同名应用是这一款最需要先排除的坑：**名字里有 Para 的应用不止一个**，还有做企业内网接入的、做翻译的。安装前请在安装包的详情页确认包名：

| 检查项 | 应该是什么 |
| --- | --- |
| 应用名 | Para |
| 包名 | `com.ymtx.abc` |
| 开发者 | 深圳市游迷天下科技有限公司 |

包名对不上就不是这款，别装。装完也可以回手机「设置 → 应用 → Para」里再核一次包名。

## 二、这份安装包对应的版本

下面这份信息是本资源里那一版的实际情况，和网上搜到的「最新版」多半不是同一版：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.9 |
| 包名 | `com.ymtx.abc` |
| 安装包大小 | 约 109.33M |
| MD5 | `8629CCA867D787171C53100D340F1C74` |

想确认文件有没有传坏，可以在电脑上打开 PowerShell，进入安装包所在目录执行：

```powershell
certutil -hashfile .\你的文件名.apk MD5
```

算出来的字符串与上表一致，说明文件完整；不一致就重新下载一次，别硬装。

手机上也可以核对：多数安卓机在「文件管理」里长按 apk 选「属性 / 详细信息」能看到文件大小，比对上表的 109.33M 即可。

**你的手机能不能装，不用提前查表。** 这一版没有权威的最低安卓版本可抄 —— 各渠道给的数字互相矛盾，按它们的数字去卡自己反而容易误判。直接装就行：系统不支持时，安装那一步会明确报错，不会把手机装坏。

界面是按手机竖屏排的：平板和折叠屏能装能用，但展开后的布局会显得比较空。

## 三、安装文件从哪拿

安装文件放在夸克网盘的分享里，转存到你自己的网盘后再下载到手机：**[Para 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b3b468ebdace)**。

手机端操作顺序：

1. 在夸克 App 里打开上面的分享链接；
2. 点「保存到我的网盘」，再进自己的网盘目录，把 apk 下载到手机；
3. 记住下载位置（一般是手机里的「下载」目录），下一步安装要用到。

用电脑操作的话，可以先把文件下到电脑，再用数据线或聊天软件传到手机。走数据线传的时候记得传完整文件，别用「压缩后传输」的图片模式，否则 apk 容易损坏。

## 四、在安卓手机上安装

1. 打开文件管理器，找到下载好的 `.apk` 文件，点它。
2. 系统提示「禁止安装未知应用」时，点提示里的设置入口，把当前应用（文件管理器或浏览器）的「安装未知应用」权限打开，返回后重新点安装。
3. 看一下权限列表，确认后点「安装」。首次安装系统还可能弹「Play 保护机制」之类的扫描提示，选继续安装即可。
4. 装完先别急着在弹窗里点「打开」，回到桌面确认图标已经出现，再从桌面启动。

装在安卓平板上流程一样，权限与安装入口的叫法可能略有差别，找不到时用系统设置里的搜索框搜「未知应用」。

## 五、第一次打开：同意、注册、完善资料

1. **同意协议**。首次启动会弹出用户协议与隐私政策，看完再勾选继续。
2. **注册或登录**。按页面提示走完，具体要填哪些字段以你打开时看到的为准 —— 这类应用的注册方式改版比较勤。
3. **完善你的资料**。进主页后先把自己的昵称、身份设定填一下：数字人的回应会参考这些信息，先填完再开聊，能少一轮「重新自我介绍」。
4. **看它先开口**。一般首次进入时它已经先打过招呼了，你直接接着回就行。第一次聊什么、模式怎么切，见 [怎么和数字人开始聊天.md](怎么和数字人开始聊天.md)。

## 六、装完打不开先别急着重装

多数情况是网络或权限问题，不是安装包坏了：先切换 Wi-Fi 与移动数据各试一次，再强制关闭应用重开。如果一直卡在启动画面、或者进得去但数字人不回话，按 [常见问题与排查.md](常见问题与排查.md) 里的顺序逐条排除，最后再考虑卸载重装 —— 重装要用到第二节那份文件信息重新核对一遍。
