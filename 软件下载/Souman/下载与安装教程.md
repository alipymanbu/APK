## 一、安装前先了解的信息

Souman（搜漫）是一款安卓手机上的漫画阅读应用，聚合多条漫画源，打开即可浏览，没有电脑版，也没有 iOS 版。下面是这份安装包的基本信息——网上各渠道标称的版本号并不统一，判断你拿到的是哪一份，以这几项为准：

| 项目 | 这份安装包的值 |
| --- | --- |
| 版本号 | 3.0.9 |
| 包名 | `com.uniyun.Uaa701B671.browser` |
| 安装包大小 | 约 29.54M |
| MD5 | `8FFBE02409FC4C8DB2BC80C33AED3049` |
| 系统要求 | 安卓 5.2 以上 |

版本号为什么各渠道对不上、怎么确认自己装的是哪份，单独写在 [版本号差异与同名应用区分.md](版本号差异与同名应用区分.md) 里。

## 二、从哪里拿到安装包

安装包放在夸克网盘里，通过分享链接转存获取。下面这条就是 **Souman（搜漫）安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/bcf1c628c6d3](https://pan.quark.cn/s/bcf1c628c6d3)

1. 打开链接，选择「保存到网盘」，把文件转存到自己的夸克账号；
2. 在夸克网盘（手机 App 或电脑客户端）里找到转存后的文件，下载到手机存储；
3. 下载完成后，直接点开 apk 文件进入安装。

## 三、安装步骤

1. 在手机文件管理器里找到下载好的 apk 文件，点开；
2. 系统首次会提示「不允许安装未知来源应用」，按提示允许当前来源（浏览器或文件管理器）安装；也可以到「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给对应的下载来源打开开关（不同品牌手机的菜单名称略有差异）；
3. 回到安装界面，点「安装」，等待完成；
4. 完成后点「打开」进入应用。首次启动如弹出网络、存储等权限申请，按需允许——看漫画要联网，缓存到本地要存储权限；有教程提到不给存储权限的话，后续可能缓存不了漫画。

## 四、装不上时按这个顺序排查

| 现象 | 先查什么 |
| --- | --- |
| 提示「解析包出错」 | 安装包多半没下完整，重新下载一遍再装 |
| 提示版本不兼容 | 手机系统版本低于要求；各渠道对这个应用的系统要求标注不一，以你手机安装时的实际提示为准 |
| 提示存储空间不足 | 清出至少 1～2 倍安装包大小的空间再试 |
| 「安装」按钮点不了 | 「安装未知应用」权限没有给到下载来源，回上一步补开 |
| 装好了但打不开、闪退 | 处理方法见 [常见问题与解决方法.md](常见问题与解决方法.md) |

装好之后建议先做两件事：到「漫源设置」里把源理一遍，再去搜想看的漫画，见 [漫源设置与切换方法.md](漫源设置与切换方法.md)。另外，装完可以把「安装未知应用」的开关关回去，需要装下一个包时再开（有教程建议这样更稳妥）。
