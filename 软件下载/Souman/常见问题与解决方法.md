## 一、搜不到想看的漫画

处理顺序：换源 → 换关键词 → 过几天再搜，具体步骤见 [漫源设置与切换方法.md](漫源设置与切换方法.md)。再补两点：

- 换别名试试：很多作品有简称或别名，用作者名、角色名也能搜到；
- 源的内容随时在变，今天没有不代表一直没有，隔几天重搜一次值得。

## 二、图片加载慢或显示不出来

1. 先换网络再刷新——Wi-Fi 与移动数据互换一遍，排除本地网络问题；
2. 换一条源重新打开同一部作品：加载慢常常只是当前那条源的服务慢；
3. 高峰时段明显变慢的话，把画质调低一档再试（入口见 [阅读设置与离线缓存.md](阅读设置与离线缓存.md)），或者换个时间段看；
4. 还慢就清一次应用缓存再试，方式见 [缓存位置与清理方法.md](缓存位置与清理方法.md)。

## 三、安装失败

按现象对号入座，完整安装步骤与系统要求见 [下载与安装教程.md](下载与安装教程.md)：

| 提示 | 处理 |
| --- | --- |
| 解析包出错 | 安装包没下完整，重下再装 |
| 版本不兼容 | 手机系统版本不够，以安装时系统提示为准 |
| 空间不足 | 清出足够空间再装 |
| 按钮点不了 | 补开「安装未知应用」权限 |

## 四、打开闪退或卡在启动页

1. 先核对系统版本是否满足要求（本文配套那份要求安卓 5.2 以上）；
2. 重启手机再打开；
3. 到系统「设置 → 应用」里清除该应用的**缓存**后重试——注意别点「清除数据」，那会把阅读记录与缓存一起清掉；
4. 有教程提到个别机型闪退与系统 WebView 组件有关：到应用商店把「Android System WebView」更新一遍再试；
5. 看着看着被系统杀掉、回来要重新加载：把这个应用加进省电/后台白名单，看的时候少切后台；
6. 还不行就卸载重装。重装前想一下：已缓存的章节一般不会保留，看完的先别急着卸。

## 五、要不要注册账号

多数教程与商店介绍提到搜漫无需注册即可浏览。你拿到的那份如果要求登录，按实际界面的提示处理即可；不同版本的安装包行为可能不一样（原因见 [版本号差异与同名应用区分.md](版本号差异与同名应用区分.md)）。

## 六、怎么更新到新版本

各渠道版本互不同步，不存在一个「官方最新版」的统一入口；本文配套的安装文件资源固定为 3.0.9。要不要换别的版本，先核对包名再决定，方法见 [版本号差异与同名应用区分.md](版本号差异与同名应用区分.md)。
