## 一、阅读菜单怎么调出来

在漫画阅读页面点一下**屏幕正中间**，会唤出阅读菜单；再点一下或按返回即可收起。翻页切换、章节列表、阅读设置入口都在这个菜单里，找不到设置时先试试点屏幕中间。

## 二、常用的阅读设置

不同版本的设置项名称可能略有出入，以你设备上的实际界面为准，常见有这几样：

| 设置 | 作用 |
| --- | --- |
| 翻页方式 | 在上下滚动与左右翻页之间切换；也可以把音量键设成翻页键，单手看更方便 |
| 阅读画质 | 调整加载与下载的清晰度，一般有标清、高清、超清几档；画质越高越费流量、越占空间 |
| 夜间模式 | 深色背景，晚上关灯看屏幕不那么刺眼 |
| 智能去边 | 裁掉页面四周的留白，同样的屏幕宽度能显示更多内容 |
| 预加载下一页 | 部分版本有这一项，开了之后翻到下一页基本不用等图 |

## 三、缓存到本地的方式（不同版本不一样）

「怎么把漫画存到本地」这件事，不同版本的安装包口径不同，两类说法都来自商店教程：

- 有教程说漫画是**看的过程中自动下载**的，看到哪里存到哪里，没有分卷下载的选项；
- 也有教程给出管理入口：「我的 → 离线缓存」，可以批量管理已缓存的章节。

以你设备上的实际界面为准。共同点是：看过的章节一般会留在本地，断网时也能从书架直接打开；下次接着看，点作品页的「续看」即可。缓存前先定画质——手机空间紧就选标清，想存住反复看再选高清、超清。

缓存文件存在哪、怎么删、空间不够先删什么，单独写在 [缓存位置与清理方法.md](缓存位置与清理方法.md) 里；**别在系统设置里点「清除数据」**——那会把阅读记录和缓存一起清掉。

## 四、书架与阅读进度

看过的章节进度会自动记录，下次从书架点开直接续读，不用手动翻到上次的位置；把漫画加进收藏，下次点开可以直接选「续看」。整理书架时长按条目一般可以删除或排序，以实际界面为准。

有教程提到：看的时候频繁切后台可能丢阅读进度；如果手机一杀后台就得重新加载，把这个应用加进省电白名单会好一些。

缓存之后如果出现「本地章节打不开」之类的情况，处理方法汇总在 [常见问题与解决方法.md](常见问题与解决方法.md)；想换条源找新书，见 [漫源设置与切换方法.md](漫源设置与切换方法.md)。
