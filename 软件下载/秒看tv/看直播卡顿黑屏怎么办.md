# 秒看TV 看直播卡顿黑屏怎么办

> 这篇按「先网络、后软件、再频道源」的顺序排查播放问题：卡顿转圈、黑屏有声无画、频道打不开。

## 一、先分清你遇到的是哪类问题

不同症状的病根不在一个地方，排查顺序也不同：

| 症状 | 更可能的原因 |
|---|---|
| 所有频道都卡、转圈 | 网络不行 |
| 只有个别频道卡 / 打不开 | 那个频道的源挂了 |
| 有声音没画面、画面全绿/花屏 | 解码方式与设备不匹配 |
| 打开就黑屏、进不去列表 | 安装包或版本问题 |
| 打开就闪退回桌面、看一会自己退 | 缓存损坏或存储不足（见第四节） |
| 时好时坏、晚上比白天卡 | 带宽被家里其他设备挤占 |

**判断网络的最快办法**：退出软件，用同一台电视打开系统自带的视频应用播一段——也卡就是网络问题，只有秒看TV 卡就往下看第二节之后的内容。

## 二、网络侧先做三件事

1. **优先插网线**。电视盒子的 Wi-Fi 天线弱、且 2.4G 频段干扰大，直播这种持续拉流的场景，有线比无线稳得多。
2. **离路由器近一点测**：把设备挪到路由器旁边试播，明显变好就是信号问题——换 5G 频段或拉网线解决。
3. **掐掉抢带宽的设备**：手机在后台备份相册、别人在看 4K 视频，都会把直播挤卡。晚高峰卡先想到这一条。

网络确认没问题后，再动软件侧。

## 三、软件侧的四个调整

按顺序试，每改一项就回到播放页验证一次：

1. **换解码方式**。进设置找「解码 / 硬解软解」，在硬解与软解之间切一下——花屏、绿屏、有声无画基本都是解码对不上，切换后通常立刻见效。
2. **降清晰度**。设置里把画质从「超清/自动」调到「高清」，对小水管宽带立竿见影。
3. **清缓存**。系统设置 → 应用 → 秒看TV → 清除缓存（**别点清除数据**，那会把自建频道一起清掉，得重输分享码，见 [自建频道分享码怎么用.md](自建频道分享码怎么用.md)）。
4. **重启设备**。盒子长期不重启会越来越卡，断电重启一次再试。

## 四、闪退、打开就崩、看一会自己退

闪退几乎都出在设备侧，不在频道侧，按命中率排：

1. **存储快满了**。`系统设置 → 存储` 看剩余空间，低于几百 MB 就先删几个不用的应用——存储不足时应用写不进临时文件，最典型的表现就是点开即退。
2. **缓存损坏**。`系统设置 → 应用 → 秒看TV → 清除缓存`（还是那句：别点清除数据）。不少闪退清完缓存就能解决。
3. **后台堆满了**。老盒子内存小，同时挂着一堆开机自启的应用。关掉后台、或在系统里限制一下后台进程数量再试。
4. **装错了端**。把手机版包装进了电视，图标能出来但一点就退——核对包名是不是 `com.supertv.mobile.hdkan`，见 [几个版本怎么分辨.md](几个版本怎么分辨.md)。
5. **设备太老或系统太旧**。以上都试过还崩，且这台设备本来就卡——恢复出厂设置是最后一招（会清掉所有应用，装机步骤重来一遍，见 [下载与安装教程.md](下载与安装教程.md)）。

## 五、频道源侧

- **单个频道打不开**：换个台验证。只有它坏就是源的问题，等它恢复或换一个来源相同的台——不是你操作错了。
- **自建频道整体打不开**：码过期了的可能性最大，换一个 6 位码重输，步骤见 [自建频道分享码怎么用.md](自建频道分享码怎么用.md)。
- **列表加载不出来 / 打开即空**：检查网络后重启软件；持续为空则考虑安装包问题——回到 [下载与安装教程.md](下载与安装教程.md) 重新核对 MD5 并重装。

## 六、还没解决时

把三样信息记下来再求助或换渠道：设备型号（电视 / 盒子品牌型号）、症状（卡还是黑、全频道还是个别）、你已经试过哪几步。有这几项，无论是问别人还是自己再搜，都能大幅缩小范围；对照 [遥控器按键操作指南.md](遥控器按键操作指南.md) 确认一下操作入口没找错，也常常能省一轮折腾。
