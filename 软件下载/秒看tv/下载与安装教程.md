## 一、秒看TV 是什么

秒看TV 是一款装在智能电视、电视盒子上的安卓直播软件，打开后直接进频道列表看央视、卫视、地方台等电视直播，操作方式和传统电视换台一样。它不走应用商店，安装包是 APK 文件，需要你自己拷到设备上装——这也是本篇要讲的事。

你在搜索引擎里会看到一堆名字很像的软件（秒看电视、秒看TV高清版、秒看影院……），包名也各不相同。本文对应的安装包信息以本地这份为准：

| 项目 | 值 |
|---|---|
| 应用名 | 秒看TV |
| 包名 | `com.supertv.mobile.hdkan` |
| 版本 | v5.0.0 |
| 安装包大小 | 22.93M |
| MD5 | `7D840E86C67F5CCD743BD9D1DA406D0E` |
| 形态 | 电视 / 盒子端（安卓） |

网络上流传的最新版号与体积和上面这张表常常对不上——那些是官方后续版本的信息，**你实际装的以表里这份为准**（也就是网盘里那份）。想核对 U 盘里拷的是不是同一份文件，比对 MD5 即可。

## 二、安装包从哪拿

从 [秒看TV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/618c2fad294a) 转存或下载 APK 文件。文件名是 `秒看TV_v5.0.0.apk` 这种形式，下载完先确认文件体积约 22.93M、后缀是 `.apk`，再进行下一步。

下载到电脑或手机上都行——反正最终要通过 U 盘（或读卡器 + SD 卡）送进电视，所以在电脑上下最顺手。

## 三、U 盘安装步骤（电视 / 盒子）

1. 准备一个 U 盘，在电脑上把下载好的 `.apk` 文件拷进 U 盘根目录（放根目录最好找）。
2. 电视或盒子上找到设置里的安全项，把「允许安装未知来源的应用 / 安装未知应用」设为允许。不同品牌叫法不同，常见位置是 `设置 → 账号与安全`、`设置 → 安全`、`设置 → 通用 → 外部来源应用`。
3. 把 U 盘插进电视的 USB 接口。部分电视会自动弹出检测到 U 盘的提示；没弹的话，打开系统自带的「文件管理 /U盘 / 媒体中心」，找到 U 盘。
4. 在 U 盘里点那个 `.apk` 文件，弹出安装界面后确认安装，等进度走完。
5. 装完先别急着拔 U 盘——打开应用确认能进频道列表，再退出、拔盘。

手机上装法完全一样：设置里允许安装未知来源，然后用文件管理器点 APK 安装。

## 四、装完第一次打开注意什么

- **需要联网**。直播走网络，没连 Wi-Fi 或网线时进去只有空频道列表。
- 第一次启动会加载频道列表，等几秒是正常的。
- 遥控器是主要输入设备，装完可以先看 [遥控器按键操作指南.md](遥控器按键操作指南.md) 熟悉换台与菜单。
- 如果打开就黑屏、或者频道转圈打不开，按 [看直播卡顿黑屏怎么办.md](看直播卡顿黑屏怎么办.md) 逐条排查。
- 频道列表不合口味、想加自己的频道，见 [自建频道分享码怎么用.md](自建频道分享码怎么用.md)。

## 五、安装时的报错对照

| 提示 | 原因 | 处理 |
|---|---|---|
| 「解析包时出现问题 / 包损坏」 | U 盘拷贝不完整，或下载中断 | 核对文件体积是不是 22.93M、MD5 是否为 `7D840E86C67F5CCD743BD9D1DA406D0E`，不对就重新下、重新拷 |
| 「禁止安装未知来源应用」 | 系统安全开关没开 | 回到第三节第 2 步，允许未知来源后再点一次 APK |
| 「安装失败 / 应用未安装」 | 存储空间不足，或残留旧版冲突 | 清出几百 MB 空间；仍失败就先卸载旧版再装 |
| 「与已有应用签名冲突」 | 电视上装过同名但不同签名的包 | 卸载原有的再装（自建频道会丢，需重输分享码，见 [自建频道分享码怎么用.md](自建频道分享码怎么用.md)） |
| 装完桌面找不到图标 | 部分系统不给第三方应用建快捷方式 | 到 `系统设置 → 应用 → 已安装应用` 里找，或用文件管理器再点一次 APK 选择「打开」 |

## 六、覆盖安装与卸载

同一个包名（`com.supertv.mobile.hdkan`）的新版本 APK 可以直接覆盖安装，观看历史与自建频道配置一般会保留。若出现覆盖后闪退，先在系统设置的应用管理里清一次缓存；还不行就卸载重装（自建频道的分享码需要重新输一遍，见 [自建频道分享码怎么用.md](自建频道分享码怎么用.md)）。

网上下载站标着比 v5.0.0 更新的版本、体积也对不上——那是渠道最新版，不是这份存档；要不要升级、怎么认包，见 [几个版本怎么分辨.md](几个版本怎么分辨.md)。
