## 一、先弄清你手里是哪种遥控器

秒看TV 装在电视或盒子上，输入设备分三类，操作范围不太一样：

| 遥控器 | 典型按键 | 对秒看TV 的影响 |
|---|---|---|
| 电视原装红外遥控 | 方向键、OK、菜单、返回、音量、频道 +/- | 全部功能可用（本文按它讲） |
| 盒子自带蓝牙遥控 | 方向键、OK、返回、主页、语音键 | 全部功能可用 |
| 万能遥控 / 手机虚拟遥控 | 可能缺菜单键或数字键 | 缺的键会挡住部分入口，见第四节 |

盒子遥控记得先和盒子配对（一般是「主页 + OK」长按进入配对），没配对时按什么都没反应，容易误判成软件卡死——先用盒子自己的界面验证遥控器是好的，再怀疑软件。

## 二、播放页常用操作

| 你想做什么 | 按键操作 |
|---|---|
| 上一个 / 下一个频道 | 方向上 / 方向下（或频道 +/- 键） |
| 调出频道列表 | 方向左，或按 OK |
| 确认选台 | 方向键移到台名 → 按 OK |
| 调出顶部栏 / 二级菜单 | 方向上调出顶栏，或按菜单键 |
| 收藏当前频道 | 在频道列表里光标停在该频道 → **长按 OK** |
| 退出当前界面 | 返回键 |
| 调音量 | 音量 +/-（不离开播放页） |

多数版本的频道列表支持按数字键直接输台号跳台；你的遥控器没有数字键就只能靠方向键逐个翻。

## 三、进菜单后能做什么

从顶栏或菜单键进入的二级菜单，通常有这几类入口：

- **频道分类切换**：央视、卫视、地方是基本盘，往下一般还分少儿、财经、新闻、体育、电竞、综艺等专题，以及 24 小时轮播经典影视的「轮播」类和你自己加的「自建」（见 [自建频道分享码怎么用.md](自建频道分享码怎么用.md)）。分类名各版本略有出入，以界面为准。
- **节目单 / EPG**：主流频道能拉到当天节目预告，光标停在频道上稍等或按方向右即可展开；从节目单能进回看和预约——完整用法见 [节目单回看与预约怎么用.md](节目单回看与预约怎么用.md)。
- **设置**：清晰度、解码方式、开机进直播等选项。**排查播放问题时第一步就是进这里**，对照 [看直播卡顿黑屏怎么办.md](看直播卡顿黑屏怎么办.md) 调。
- **收藏列表**：把长按 OK 收藏的频道集中放在一处，每天开机直接从这里进，省去翻分类。

## 四、按键不好使时的替代方案

- **遥控器上没有「菜单」键**：用方向键把光标调到屏幕顶部，呼出顶栏后进设置——菜单键不是唯一入口。
- **长按 OK 不收藏**：部分遥控器的长按识别慢，按住不动 2 秒以上再松；仍不行就到频道列表里找「收藏」项手动加。
- **数字键输台号没反应**：该版本可能不支持台号直跳，用方向键换台即可。
- **按键延迟或失灵**：先换组电池、去掉遥控器与电视之间的遮挡（红外遥控要对着电视下方的接收窗），排除硬件问题后再怀疑软件。
