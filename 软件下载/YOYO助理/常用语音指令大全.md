## 一、开口前的三个状态

YOYO助理有静默、聆听、思考三种状态：静默时不收音；你唤醒它后进入聆听，这时说话才有效；说完它进入思考并执行。**听清「叮」一声再开口**，抢在聆听之前说话会整句丢掉。

想连续追问，先在 设置 > 荣耀AI&YOYO > YOYO助理 里打开**连续对话**（见 [唤醒方式设置教程.md](唤醒方式设置教程.md) 第三节），否则每句都得重新喊唤醒词。

## 二、日常高频指令

唤醒后直接说，不用带唤醒词：

| 你想做的事 | 可以这么说 |
| --- | --- |
| 查天气 | 「今天天气怎么样」「明天下雨吗」 |
| 设闹钟 / 定时 | 「早上七点叫我」「定个 9 点的闹钟」 |
| 建提醒 | 「提醒我下午去超市购物」 |
| 打开应用 | 「打开微信」「打开相机」 |
| 调设置 | 「把音量调大」「打开蓝牙」「把屏幕调暗一点」 |
| 扫码 / 付款 | 「打开乘车码」「打开付款码」 |
| 换个声音 | 「换个声音」——直接进播报音色界面（详见 [播报音色怎么换.md](播报音色怎么换.md)） |
| 找手机 | 唤醒后说「**你在哪儿**」——手机会亮屏、振动并响铃回应「我在这里」 |
| 扬声器清灰 | 唤醒后说「**清灰**」，手机震动除尘约 30 秒 |

**找手机要求语音唤醒已开启**（按提示录过唤醒词），手机离得太远或声音太小可能叫不应；通话中、录音中无法用唤醒词唤起。

**清灰**过程中让手机平放、别捂住扬声器，30 秒左右自动结束。

## 三、进阶玩法

### 1. 一句话跨应用操作

「导航回家」「帮我拍一张照片」「把这段话发给某某」这类指令，YOYO助理会直接拉起对应应用并执行到那一步。具体能代办到什么程度因机型与系统版本而异，试一句你常用的就知道了。

### 2. 深度思考模式（接入 DeepSeek 的问答）

唤醒 YOYO助理后，点输入框上方的 **YOYO头像** 可切换到**深度思考模式**；没有该入口的，点上方「**智能体**」选 DeepSeek 也能用。这两条路各有版本门槛：

| 功能 | 版本要求 |
| --- | --- |
| 深度思考版（头像切换） | MagicOS 8.0 及以上，YOYO助理 90.0.1.405 及以上 |
| 智能体商店（能选到 DeepSeek） | YOYO助理 80.0.1.503 及以上 |

版本够了但找不到入口，进 **设置 > 荣耀AI&YOYO > YOYO助理 > 添加桌面快捷方式**，再从桌面下滑全局搜索「YOYO助理」打开。查版本号见 [一直显示准备中怎么解决.md](一直显示准备中怎么解决.md) 第二节。

### 3. 用方言说指令

在 **AI实验室 > 方言识别** 里选好方言后，直接用方言下指令即可；也可以唤醒后说「用四川话聊天」临时切换。支持的方言以你手机列表里实际有的为准。

## 四、指令没被执行时

先分清是「叫不醒」还是「醒了但听不懂」：叫不醒走 [无法唤醒怎么办.md](无法唤醒怎么办.md)；醒了但一直转圈或回「准备中」，走 [一直显示准备中怎么解决.md](一直显示准备中怎么解决.md)。两个都正常却仍答非所问，多半是环境噪音或麦克风被遮挡，靠近一点、安静一点再说一次。
