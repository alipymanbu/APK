## 一、语伴是怎么推荐给你的

匹配的依据是注册时填的**母语**与**兴趣语言**，再加上国籍、爱好这些资料项：你中文母语、标了想学英语，系统优先推「英语母语、想学中文」的人——互相都有练习价值，才聊得起来。资料填得越全，推得越准；兴趣标签当时跳过了的，去个人资料补上即可（字段影响见 [注册与登录教程.md](注册与登录教程.md) 第四节）。

## 二、自己筛：不想被动等推荐

推荐列表之外有**自定义筛选**，可按这几个维度过滤：

- **国家/地区**：只想和某个国家的人聊就选它；
- **共同兴趣**：按标签交集筛；
- **学习目标**：按对方想学的语言筛。

筛选是叠加生效的——同时选「泰国 + 想学中文」就只出这一撮人。筛完右滑喜欢 / 左滑跳过，互相喜欢才进聊天列表（匹配玩法各版本界面略有差异，以你装的版本为准）。

## 三、打第一句招呼

匹配成功后第一条消息决定对方回不回：

- 用对方的语言打个招呼，输入框旁的【转换】按钮可以直接把中文转成对方语言发出（见 [聊天翻译功能怎么用.md](聊天翻译功能怎么用.md)）；
- 从对方资料里的兴趣切入，比「在吗」有效得多；
- 对方资料页的动态能当话题库——他发过什么，就聊什么。

## 四、发一条动态

动态是认识陌生人的第二条路（不靠匹配、靠内容）：

1. 点屏幕底部中间的**地球图标**进动态页；
2. 点右上角**相机图标**进入发布页；
3. 输入文字，下方可加图片、视频、表情；
4. 需要的话点翻译把文字转成其他语言再发——动态是全球流，翻成英语看到的人更多；
5. 点右上角【发布】。

别人可以给你的动态点赞、评论，你回评就能搭上话。浏览动态时同理：外文旁点【查看翻译】。

## 五、匹配不理想时调这几项

先对一下「人都在哪」：白鲸出海 2024 年对这类语言社交产品的统计显示，下载靠前的市场是**菲律宾、印尼、中国、美国、俄罗斯**，用户年龄集中在 18~30 岁、男女比例大致均衡（数据截至其发文时间，以实际为准）。也就是说你刷到的国外用户大概率来自东南亚——时差与活跃时段对不上时，换你当地的晚上时段刷，匹配效率通常更高。

| 现象 | 调整 |
| --- | --- |
| 推来的人都不是想聊的 | 补全母语/兴趣语言/兴趣标签，让推荐重算 |
| 想固定聊某个国家 | 用第二节的筛选，保存常用条件 |
| 一直刷不到人 | 换时段（见上），或扩大国家筛选范围 |
| 主页没人理 | 换头像、补个人介绍，动态里露两条内容 |
| 想直接进房间聊 | 去语音房，围观和上麦都不依赖匹配（见 [语音房与K歌玩法说明.md](语音房与K歌玩法说明.md)） |
