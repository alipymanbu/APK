## 一、注销之前先做三件事

按官方隐私政策（更新日期 2026-08-03）与用户协议，注销是**彻底**操作，做完再回头找不回：

1. **先退订 VIP**：自动续费不会因为账号注销而停，扣款走的是你的支付账户。退订路径见 [会员与Yee币充值说明.md](会员与Yee币充值说明.md) 第四节，账号没了、下个周期照样扣款的情况是真实存在的。
2. **导不出的就先截图**：聊天记录、动态、好友列表注销后会被删除，协议写明注销请求收到后会「对你的信息进行删除处理」。有需要留念的内容先自己存。
3. **确认登录的手机号还活着**：注销前后都可能要收验证码或做身份验证；官方政策写明「可能会要求你提供身份证明」才响应注销请求。

## 二、App 内注销的两套路径

官方隐私政策给的正式入口是：**「设置」-「帐号安全」-「注销帐号」**。

不同版本的菜单名有出入，市面教程还流传另一套走法，找不到上面那个入口时可以照它找：

1. 点底部导航最后一项进「我的 / 个人中心」；
2. 点【设置】；
3. 进【账户 / 账户管理】，页面底部有【删除账户 / 注销帐号】；
4. 勾选须知、选择注销原因，提交。

两套路径指向同一个功能——**按你装的版本实际菜单名找**，认「注销 / 删除账户」这几个字即可。两条都找不到（罕见情况），直接发邮件到 `support@yeetalkapp.com` 请求注销，写清注册手机号与账号 ID。

## 三、注销、退出、封号不是一回事

| 你做的事 | 结果 |
| --- | --- |
| 退出登录 | 账号与数据都在，验证码登录即回 |
| 注销帐号 | 资料、聊天、好友按政策删除，不可恢复 |
| 被封号 | 账号还在但进不去，提示与申诉见 [常见问题与账号安全.md](常见问题与账号安全.md) 第三节 |

协议同时写明：你可以随时注销，Yeetalk 也可在怀疑你违反协议时暂停或终止你的账号，且**不提前通知**；被终止后，除非收到解除通知，否则无法再注册或使用服务——这是「先守规则」比「事后申诉」便宜的原因。

## 四、哪些资料你自己改不动

- **昵称、头像、个人介绍、出生日期**：个人主页的编辑入口里自己改。
- **国籍、母语、性别**：这不是随便改的字段——它决定匹配与翻译的走向，改错了等于换个身份。**有流传的客服培训资料**（一份公开流传的客服业务考试问卷）称：这三项需要把 **账号 ID、更换原因、本人手持身份证照片**发到 `support@yeetalkapp.com`，审核通过后由人工修改。此流程未经官方页面明文确认，以客服答复为准；改之前先发邮件问一句最稳。
- **注册用的手机号**：换号需要走客服，别直接弃号——验证码收不到，[注册与登录教程.md](注册与登录教程.md) 里的找回手段就全失效了。

## 五、关于「显示 IP 来源」

部分用户发现自己资料旁显示了 IP 属地，问能不能藏。上述同一份流传客服资料的口径是：**按当地法规，部分地区需要显示 IP 来源，由网络运营商提供，不支持隐藏**；如果你看到的属地和实际位置不一致，先检查自己是否开了 VPN 之类的代理。这条只对「自己的显示」有效，别拿它当位置工具用。

## 六、只想躲开某个人，不用注销

被骚扰时的代价从小到大：**拉黑（黑名单）→ 举报**。举报入口在对方**个人主页右上角的「...」**菜单里；聊天室里房主、主持人有踢人维护秩序的权限（见 [语音房与K歌玩法说明.md](语音房与K歌玩法说明.md)）。账号本身没问题就别注销——注销是删号重来，拉黑是删掉这个人，两者的成本差一个数量级。
