## 一、整体流程三步走

PlainApp 的用法可以概括成：手机上启动，电脑上打开。前提是**手机和电脑连在同一个 Wi-Fi 下**。

1. 手机打开 PlainApp，点「启动」（部分版本叫「开始」），界面会出现一个地址，形如 `http://192.168.1.50:8080` 或 `https://192.168.1.50:8443`；
2. 电脑上打开任意浏览器（Chrome、Edge、Firefox 都行），输入这个地址；
3. 页面打开后，你就进入了手机的网页管理面板，文件、照片、短信、投屏都在这里操作。

官方的说法是 60 秒内能跑通 —— 卡住的通常只有网络这一步，排查方法集中在 [连不上打不开怎么办.md](连不上打不开怎么办.md)；如果症状是「亮屏好好的、锁屏后就断」，那是系统省电在杀后台，见 [锁屏后断开与后台保活设置.md](锁屏后断开与后台保活设置.md)。

## 二、地址与端口怎么读

PlainApp 可能同时列出好几个地址，都试一遍即可：

| 形态 | 说明 |
| --- | --- |
| `http://192.168.x.x:8080` | 明文 HTTP 地址，不会弹证书警告，图省事可用它 |
| `https://192.168.x.x:8443` | 加密 HTTPS 地址，浏览器会弹证书警告（见下节） |
| `plainapp.local:8080` | 局域网组播发现的域名，部分网络环境下打不开，打不开就用 IP |

注意**冒号后面的端口不能漏**，`192.168.x.x` 少了 `:8080` 是打不开的。手机的 IP 由路由器分配，重启路由器后可能变化 —— 以 PlainApp 界面当时显示的地址为准，别死记旧地址。

## 三、浏览器报「连接不是私密的」怎么办

弹「您的连接不是私密的」「证书不受信任」这类警告是**正常现象**：PlainApp 用自签名证书做加密，浏览器没法向公共 CA 验证它。处理方式：

- 点「高级」→「继续访问（不安全）」；
- 或者改用它给的 `http://` 地址，绕开警告。

这只会出现在首次连接，之后浏览器可能记住你的选择。连接加密这件事本身在 [常见问题与版本差异.md](常见问题与版本差异.md) 里有更完整的说明。

## 四、网页面板里有什么

打开后你看到的是一个完整的手机管理面板，常用入口：

- **文件**：内部存储、SD 卡、U 盘都能浏览，上传下载改名移动删除都在网页上做，详见 [文件传输与照片视频管理.md](文件传输与照片视频管理.md)；
- **照片 / 视频 / 音乐**：直接在浏览器里翻相册、播视频，不用先把文件拷到电脑；
- **短信与通话记录**：电脑上读短信、发短信、查通话记录（商店版没有这几项，见 [常见问题与版本差异.md](常见问题与版本差异.md)）；
- **通讯录**：大屏幕搜索、编辑联系人；
- **屏幕镜像**：把手机画面实时投到浏览器，玩法见 [屏幕镜像与电视投屏.md](屏幕镜像与电视投屏.md)；
- **通知同步**：手机通知实时出现在电脑网页上；
- **应用管理**：列出已安装应用、导出 APK 备份；
- **笔记 / RSS / 书签**：这些也能在网页端一并管理。

## 五、把网页固定到桌面（PWA）

经常用的话，建议把网页面板固定成桌面图标，点开就是独立窗口、没有浏览器地址栏：

1. 用 **Chrome 或 Brave** 打开 PlainApp 的网页地址；
2. 地址栏右侧点安装图标，或菜单里选「安装 PlainApp / 创建快捷方式」；
3. 桌面出现图标后，下次点它直达面板。

官方下载页说明 PWA 固定支持 Chrome 和 Brave；手机端服务没启动时，点开图标只会看到打不开的页面，先回手机把服务跑起来即可。

## 六、手机上不连电脑也能用的部分

PlainApp 本身也是一个独立的手机应用：Markdown 笔记、RSS 阅读器、音视频播放器、DLNA 电视投屏、番茄钟、分贝计、设备间 P2P 聊天，都可以只在手机上用，不需要电脑连过来。这些功能与网页端共用同一份数据，笔记在手机写、网页上照样能看到。
