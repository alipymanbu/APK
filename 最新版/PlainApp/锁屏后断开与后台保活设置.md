# PlainApp 锁屏后断开与后台保活设置

## 一、先确认是不是这个问题

PlainApp 的服务跑在手机后台，而 Android 会主动清理后台进程。如果你的症状是下面这样，八成是省电策略把它杀了，不是网络坏了：

- 亮屏时一切正常，手机**锁屏放几分钟后**，电脑突然打不开网页、传输中断、镜像画面冻结；
- 回手机看，PlainApp 里的服务**已经停了**（或地址消失了），重新点「启动」立刻又能连上；
- `ping` 手机 IP 一直通，但浏览器就是打不开页面 —— 说明网络没问题，是手机上的服务没了。

亮屏状态下就连不上，那是网络层问题，按 [连不上打不开怎么办.md](连不上打不开怎么办.md) 排查；只有「锁屏后才断」才走本篇。

## 二、为什么会断：三层省电在叠着管你

- **Android 自带的 Doze 与 App Standby**：屏幕关掉、设备静止一段时间后，系统限制后台进程的网络与计算；
- **厂商的省电层**：小米（MIUI/HyperOS）、华为（EMUI）、vivo、OPPO、三星等品牌在原生机制之上又加了自己的清理策略，通常比原生更狠；
- **最近任务里被划掉**：在多任务界面把 PlainApp 上滑移除 = 强制停止，服务立刻没，跟省电设置无关。

PlainApp 这类「必须常驻后台才有用」的应用，在部分品牌的默认设置下会被当成普通闲置应用清掉 —— 这也是所有常驻类应用（消息、闹钟、投屏）共同的坑，[dontkillmyapp.com](https://dontkillmyapp.com) 这个开发者资料站按品牌收录了对应的关闭方法。

## 三、通用三步（任何品牌先做这三步）

1. **电池设置改成不受限**：系统设置 → 应用 → PlainApp → 电池（或「电量优化」），把选项从「优化 / 受限制」改成 **「不受限制 / 不优化 / 允许后台活动」**（各品牌叫法不同，选最宽松那一档）。
2. **加进电池优化白名单**：部分系统要单独操作 —— 设置里搜「电池优化」，切到「全部应用」，把 PlainApp 设为**不优化**（华为等机型是这样）。
3. **在最近任务里锁定它**：多任务界面找到 PlainApp 卡片，下拉或点锁形图标把它**锁定**；以后清理后台时不要上滑划掉它，划掉就是强制停止。

改完先看效果（验证方法见第五节），没生效再按品牌加码。

## 四、各品牌的加码项

菜单路径随系统版本变动，以你手机上实际显示为准；查不到就到 [dontkillmyapp.com](https://dontkillmyapp.com) 按品牌翻对应页面：

| 品牌 | 常见的额外开关 |
| --- | --- |
| 小米 / Redmi（MIUI、HyperOS） | 应用信息里的「自启动」要开；「省电策略」选无限制；部分机型重启后设置会复原，升级系统后记得复查 |
| 华为 / 荣耀（EMUI、HarmonyOS） | 「应用启动管理」里关掉「自动管理」、手动允许自启动与后台活动；另在设置里搜「电池优化」设为不优化 |
| vivo | 「自启动」与「后台高耗电」逐个允许（默认要手动开） |
| OPPO / realme（ColorOS） | 「耗电管理 / 后台冻结」里允许后台运行与自启动 |
| 三星（One UI） | 设置 → 电池 → 后台使用限制，确认 PlainApp 不在「睡眠应用 / 深度睡眠应用」名单里 |

另外检查一条通用设置：设置里搜「**休眠时保持 WLAN 连接 / 睡眠时保持网络连接**」—— 部分机型锁屏一段时间会断 Wi-Fi，PlainApp 的服务还在、电脑却摸不到它，症状与被杀进程一样。

## 五、怎么验证设置生效了

1. 按上面改完，重启一次 PlainApp 服务；
2. 手机**锁屏**，静置 5～10 分钟；
3. 电脑浏览器重新打开地址：能打开 → 生效；还是打不开 → 回手机看服务是否又停了 —— 停了说明省电项还有漏网的，回到第三节第 1 步核对选的是不是最宽松档，再按第四节查品牌项。

## 六、代价与边界

把后台限制放开的代价是**待机耗电略增**（系统放开的正是它想省的那部分），这是保活绕不开的交换，值不值取决于你用它的频率。长期不用时，主动在 PlainApp 里停掉服务即可，比让系统杀更省电。镜像、DLNA 发现这类功能同样依赖服务在线，设置做完它们的「用一会就断」会一起好转，功能入口见 [屏幕镜像与电视投屏.md](屏幕镜像与电视投屏.md)。
