## 一、两条路先分清

同样是「把手机画面弄出去」，PlainApp 给了两个不同方向的方案，别混着找按钮：

| | 屏幕镜像（到电脑浏览器） | 电视投屏（DLNA） |
| --- | --- | --- |
| 画面去哪 | 电脑浏览器页面里 | 同一网络里的智能电视 |
| 走哪个入口 | 网页面板的「屏幕镜像」 | 手机端 App 内的投屏 |
| 技术方式 | WebRTC 实时串流 | DLNA / Chromecast |
| 能力 | 整个手机屏幕实时显示，带音频 | 把照片、视频、音乐推给电视播放 |
| 前置条件 | 手机服务已启动 + 电脑已连上面板 | 手机与电视在同一网络 |

## 二、屏幕镜像到浏览器

1. 手机端 PlainApp 服务保持启动；
2. 电脑浏览器打开面板（连接方法见 [电脑浏览器连接教程.md](电脑浏览器连接教程.md)）；
3. 进入「屏幕镜像」，手机上确认投屏许可，浏览器里就会出现手机画面。

几个你会碰到的参数：

- **帧率**：官方标称最高 30fps，看文档浏览够用，别指望它当游戏直播；
- **音频**：串流支持带声音，演示 App、刷视频时声音会跟着过来；
- **画质三档**：自动 / 高清 / 流畅 —— 网络稳选「高清」，路由器不给力或画面卡就切「流畅」，「自动」交给它自己权衡。

镜像是实时链路，对局域网质量敏感：电脑若走着 VPN、或手机换了网络，画面会断 —— 症状与处理见 [连不上打不开怎么办.md](连不上打不开怎么办.md)。

## 三、电视投屏（DLNA / Chromecast）

这条路**在手机端 App 里操作**，不需要电脑：

1. 确认电视与手机连在同一个 Wi-Fi（不同频段 2.4G/5G 一般也算同一网络，连不上就先核对路由器设置）；
2. 在 PlainApp 里打开照片、视频或音乐，播放界面找投屏（TV Cast）按钮；
3. 选中你的电视，画面/声音就会推过去，手机可以继续干别的。

它遵循 DLNA 与 Chromecast 两类协议，兼容哪些机型以你的电视实际表现为准；投不出去时先核对「同一网络」这个条件，再重启电视的投屏服务。

## 四、什么时候用哪条

- 想让**同事看一眼你手机上的东西**（演示、调试、回消息）→ 镜像到浏览器，电脑屏幕就是输出；
- 想**在电视上放手机里的视频和照片** → 直接 DLNA 投屏，电视解码更稳，手机还能锁屏；
- 只是想**把文件送到别的设备** → 用不着投屏，走 [文件传输与照片视频管理.md](文件传输与照片视频管理.md) 的传输即可。

电视投屏与镜像都属于「在同一网络里互相发现」的功能，网络本身有问题时它们会一起失效，排查统一入口是 [连不上打不开怎么办.md](连不上打不开怎么办.md)。
