## 一、PlainApp 是什么

PlainApp 是一款免费开源的 Android 应用：你在手机上启动它，它会在本机跑一个网页服务，然后你用电脑浏览器打开同一 Wi-Fi 里的地址，就能在网页上管理这台手机 —— 传文件、看照片视频、发短信、投屏，电脑端什么都不用装。它不注册账号、不走云端、无广告，代码在 [GitHub 仓库](https://github.com/plainhub/plain-app) 公开。

你会关心的几项基本事实：

- 包名 `com.ismartcoding.plain`，官方要求 **Android 9.0 或更高**（手机与平板都支持）；
- 网盘里那份安装包是 **3.0.16 版本、85.68M**；
- 官网在 [plainapp.app](https://plainapp.app/zh)，下载页汇总了所有官方渠道。

## 二、安装包从哪拿

### 夸克网盘（转存即用）

打开 [PlainApp 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6d1a9a6c3cb2)，转存后在手机上下载安装即可 —— 网盘这份是 **3.0.16、85.68M** 的完整包，装完直接可用，不需要再挑架构。文件名与包名对得上（`com.ismartcoding.plain`），拿不准来源时认准这两个就行。

### 官方渠道（三条，各有取舍）

官方下载页是 [plainapp.app 的下载页](https://plainapp.app/zh/download)，上面的三条渠道对比如下（版本号以该页当时显示为准）：

| 渠道 | 适合谁 | 与完整版的差异 |
| --- | --- | --- |
| GitHub Releases | 想第一时间更新、要完整功能 | 无差异，功能最全，且支持应用内自动更新 |
| Google Play | 图省事、习惯商店自动更新 | **缺短信/通话、应用管理、通知镜像**（商店政策限制），更新也更慢 |
| F-Droid | 只在意开源审核 | **缺 AI 图片搜索**（依赖的库不满足其开源标准），上架常滞后 |

下载页还提供直接下载 APK 的直链，以及给中国用户准备的 gh-proxy 备用地址，以官方页面当时显示为准。

**拿不准就选 GitHub 版**：功能完整、发版最快。三个渠道的包名相同，互相覆盖安装即可，装完设置与数据都还在。

## 三、安装步骤

1. 把 APK 弄到手机上：手机端网盘直接下载，或电脑下载后用数据线 / 微信文件助手等发过去。
2. 点击 APK 安装。若系统拦「禁止安装未知来源应用」，按提示为当前来源（浏览器、文件管理器或网盘应用）打开允许开关，再返回安装。
3. 装完首次打开，会弹权限申请：存储 / 媒体权限用于浏览与传输文件，短信、通知、通讯录权限对应网页端的短信收发与通知同步 —— 你打算用哪个功能就授哪个，拒绝了之后也能去系统设置里补开。

装好之后的下一步是启动服务并在电脑上打开它，见 [电脑浏览器连接教程.md](电脑浏览器连接教程.md)。

## 四、版本与更新

PlainApp 的版本号形如 `3.0.16`，随发布递增。你手头网盘这份是 3.0.16；官网最新版本会继续往前走，具体以 [官方下载页](https://plainapp.app/zh/download) 当时显示为准。

- **GitHub 版**：支持应用内置的自动更新，也可以随时去 Releases 页手动下一个新 APK 覆盖安装；
- **商店版**：等商店审核通过才更新，节奏通常慢一截；
- 覆盖安装不会丢笔记、设置等数据；升级前若不放心，可先把重要文件导出一份。

如果你装的是商店版、发现少了短信之类的功能，原因见 [常见问题与版本差异.md](常见问题与版本差异.md)；装完连不上网页，按 [连不上打不开怎么办.md](连不上打不开怎么办.md) 排查。
