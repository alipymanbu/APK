## 一、先记住一句话

**没有万能参数组合**——不同模型的训练方式不同，偏好的采样器和 CFG 范围也不同。调参的原则：从模型发布页给的示例设置起步，保持其余值在默认附近，**一次只改一个变量**，出的图才有对比意义。

## 二、各参数是干什么的

| 参数 | 作用 | 范围 | 推荐起始值 |
|---|---|---|---|
| 提示词 | 告诉模型你想看到什么 | — | 简短、具体 |
| 反向提示词 | 告诉模型你想避开什么 | — | 只加几条明显要避的问题 |
| 采样器 | 决定「从噪声到图片」怎么走 | 见下表 | DPM++ 2M（Karras 默认关） |
| 步数 | 这个过程走多久 | 1–50 | 24，图没画完加到 28~30 |
| CFG | 模型多强烈地听你的提示词 | 1–30 | 5–8 |
| 去噪强度 | 图生图里原图能被改多少 | 0–1 | 图生图用 0.75–0.85 |
| 种子 | 用哪个随机起点 | 0–4294967295 | 随意，满意后固定住 |

## 三、采样器怎么选

| 采样器 | 特点 | 什么时候用 |
|---|---|---|
| DPM++ 2M | 均衡稳定 | 默认就选它，拿不准时的首选 |
| DPM++ 2M SDE | 每步注入少量噪声，纹理更丰富 | 想要更细的质感；代价是同种子也不可复现 |
| Euler A | 风格自由、纹理活泼 | 想要更多变化 |
| Euler | 确定性，比 Euler A 稳 | 想要可控、可复现的结果 |
| LCM | 极低步数快速生成 | 配 4~8 步用，通常是 DMD2 类模型 |

采样器旁边的 **Karras 开关**会把噪声调度切成 Karras 曲线，在 20~30 步区间常能换来更干净的细节。看到模型作者写「DPM++ 2M Karras」，就是选 DPM++ 2M 并打开这个开关（LCM 不支持该开关）。

## 四、步数与 CFG

**步数**：从 24 起步；图片看着「没画完、糊」时加到 28 或 30；用 LCM 时改用更低的步数。步数越高越慢，收益递减。

**CFG（提示词强度）**参考：

- 1–4：宽松跟随，画面自由但可能跑题
- 5–8：均衡，通常最佳
- 9–14：紧跟提示词，可能出现伪影
- 15+：基本只有模型特别推荐时才用

一个**性能技巧**：NPU 路径下把 CFG 设为 1 会跳过一半的推理计算，单步耗时约减半——这正好是 LCM / DMD2 类模型需要的设置，普通模型别这么设。

## 五、图生图的去噪强度

去噪强度决定输出能偏离原图多远：

| 数值 | 效果 |
|---|---|
| 0.2–0.4 | 小修小改，轻度风格化 |
| 0.5–0.7 | 明显改动，原图结构还在 |
| 0.75–0.85 | 大幅重绘，构图大致保留 |
| 0.9–1.0 | 变化很大，构图可能偏移 |

从 0.8 左右起步比较稳；想保构图就往下调，想换风格就往上调。

## 六、种子与「能不能复现同一张图」

种子是生成的随机起点，固定种子 + 固定模型 + 固定参数 = 有机会拿到同一张图。但**可复现性因模式而异**：

| 模式 | 同一芯片 | 不同芯片 |
|---|---|---|
| CPU | 完全一致 | 完全一致 |
| GPU | 完全一致 | 可能不同 |
| NPU | 完全一致 | 可能不同（按芯片量化调优） |

实际用法：同一台手机上调提示词做 A/B 对比，三种模式都可靠；想把种子发给别人复现，要注明你用的**模式和芯片**；要逐位精确复现就用 CPU 模式。

## 七、默认参数与重置

每个模型都有自己的默认参数，优先级依次是：模型自带代码默认值 → 模型包里的 `config.json`（DMD2 模型的 `LCM`/`CFG 1`/少步设置就是这样带进来的）→ 全局默认值。**首次打开模型、以及每次点「重置」**都会套用解析出的默认值；你手动保存过的值永远优先。

另外两个与速度、内存相关的机制：

- **CLIP 缓存**：编码过的提示词结果会按模型存到磁盘，重复提示词下次直接复用（含 Textual Inversion 嵌入的提示词不走缓存）；可在 设置 → 文件管理器 里清除。
- **低内存模式**（SDXL 默认开启）：换内存占用，开启更稳、关闭更快；16GB 以上内存的设备可以关掉换速度。
