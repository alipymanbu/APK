## 一、先确认这是你要的东西

Local Dream 是一款**在手机本地运行 Stable Diffusion 的开源安卓应用**：出图不上传服务器、不联网也能生成，免费无广告。它由开发者 xororz 开源，代码仓库在 [github.com/xororz/local-dream](https://github.com/xororz/local-dream)。

装之前先对一下手机：**高通骁龙芯片**能走 NPU 加速（出图最快），其他芯片也能走 CPU/GPU 模式。完整支持列表见 [芯片兼容性与NPU加速说明.md](芯片兼容性与NPU加速说明.md)。

## 二、安装包从哪拿（三个渠道）

| 渠道 | 拿到什么 | 适合谁 |
|---|---|---|
| 夸克网盘 | 固定版本的安装包，转存后下载 | 想要稳定版本、习惯网盘留存的用户 |
| GitHub Releases | 官方最新版 | 想追新版本的用户 |
| Google Play | 商店安装版 | 手机能访问商店、图省事的用户 |

**网盘里那份包的准确信息**（以这份为准，别拿网上的数字对照）：

- 版本：2.6.0
- 包名：`io.github.xororz.localdream`
- 大小：53.64M
- MD5：`2db5e045b937309ece3ec94a319320b3`

从网盘拿包：打开 [Local Dream 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b49a3d464c24)，转存到自己的网盘后下载到手机即可。

Google Play 上的版本与 GitHub 版**功能一致**，但按商店政策**多一层内容过滤**（NSFW 过滤）；想要与官方仓库完全一致的版本就走 GitHub Releases（[github.com/xororz/local-dream/releases](https://github.com/xororz/local-dream/releases)，版本号以该页面当时显示为准）。

## 三、安装步骤

1. 把 APK 文件传到手机（网盘 App 内直接下载、数据线、聊天工具传文件都行）。
2. 在文件管理器里点这个 `.apk`，系统会提示「不允许安装未知来源应用」—— 点提示进入设置，**允许本次安装来源**（只针对你点击的这个来源开启，不必全局放开）。
3. 返回后继续点安装，等待进度走完。
4. 装完先别急着打开：模型文件需要另外联网下载，见下一节。

包名安装后可在「设置 → 应用 → 已安装应用」里找到 `io.github.xororz.localdream` 核对；版本号在应用内的关于/设置页面能看到，装的是网盘这份就应显示 2.6.0。

## 四、首次启动注意三件事

1. **第一次打开需要联网下载模型**——应用本身是离线出图的，但内置模型（几十 MB 到几 GB）要点下载才会有。断网状态下既下不了模型，也没法直接出图。
2. **NPU 模型只在支持的芯片上出现**。如果你的手机不支持，模型列表里看不到 NPU 款是正常现象，不是下载坏了 —— 判定规则见 [芯片兼容性与NPU加速说明.md](芯片兼容性与NPU加速说明.md)。
3. **先从内置模型选一个**，别一上来就折腾自定义模型。内置列表会按你的芯片自动挑对应变体，下载完成后直接就能出图，流程见 [生成第一张图教程.md](生成第一张图教程.md)。

## 五、版本怎么理解

- 网盘这份是 **2.6.0**（53.64M），是转存时的固定版本，适合当「稳定档」长期用。
- 官方仓库还在持续更新，GitHub Releases 上的版本号会比它新；升级前记得应用内有「分享参数 / 历史备份」类功能，重要图片和参数可以先备份再换版本。
- 装不上、装好打不开、出图报错等问题，按 [常见问题与故障排查.md](常见问题与故障排查.md) 逐条排。
