# Local Dream 常见问题与故障排查

## 一、点生成完全没反应 / 任何模型都跑不起来

Local Dream 的界面和设备上的推理后端之间走的是本机回环地址 `127.0.0.1:8081` 的本地 HTTP 通信，**任何拦截 localhost 流量的东西都会让生成直接起不来**。按顺序查：

1. **关掉 VPN / 代理类应用**——它们最常见的副作用就是转发或拦截本地流量。
2. **检查系统的「网络受限 / 后台冻结 / 省电策略」**——部分国产 ROM 会阻断应用的本地 socket，到系统设置里把 Local Dream 的网络权限放开、省电策略改成无限制。
3. 改完重开应用再试。

这是「完全跑不起来」时**最先该查的两项**，多数情况在这里就解决了。

## 二、模型列表里没有 NPU 模型

不是下载坏了：**不支持的芯片上，NPU 模型根本不会出现在下载列表里**（应用按芯片隐藏，防止你下错包）。对照 [芯片兼容性与NPU加速说明.md](芯片兼容性与NPU加速说明.md) 的芯片表——你的芯片不在表上就走 CPU/GPU 模式，SD1.5 照样能用；在表上却看不到，才需要进一步排查（先确认应用是最新版）。

## 三、联发科（MediaTek）设备 GPU 出图花屏 / 结果是乱的

部分联发科设备缺失 GPU 运行时需要的 OpenCL 库，用 GPU 路径会出花屏或错误结果。**这是设备侧缺库导致的，换模型、调参数都改变不了**：把推理模式切成 **CPU** 再生成；如果你的芯片本身在 NPU 支持列表里（联发科一般不在），就用 NPU。

## 四、用 NPU 生成时切到后台，卡住了

NPU 路径在部分设备上，某一步推理进行中切到后台会卡死。**预防大于补救：NPU 生成时让应用留在前台**。真卡住了：

- 等前台服务的提示消失，或直接划掉应用重开；
- 下一次生成别切后台——长时间、大批量的任务要么在前台挂着，要么改用 CPU/GPU 模式跑。

## 五、模型下载失败 / 下不动

1. 到设置里**切换下载源**：Hugging Face、hf-mirror 或自定义 URL——直连超时时切镜像通常立竿见影。
2. 模型下载支持**后台进行**，切走界面不会中断，不必守着进度条。
3. 下载的是体积几十 MB 到几 GB 的模型文件，先确认手机存储空间足够、网络本身稳定。

## 六、SDXL 跑不动 / 内存不够

SDXL checkpoint 对内存的要求远高于 SD1.5：

- **低内存模式**（SDXL 默认开启）会改成「用时加载、用完释放」，保持默认最稳；
- 设备内存在 **16GB 以上**、且想要更快的重复生成速度，可以关掉它换速度；
- 手机端能出图的档位有限，SDXL 只在 8 Gen 3 及以上的 NPU 上提供，CPU/GPU 模式跑不了它（详见 [芯片兼容性与NPU加速说明.md](芯片兼容性与NPU加速说明.md)）。

## 七、安装包装不上 / 装完打不开

- 安装时提示不允许未知来源：按系统提示对**本次安装来源**放行后重试，步骤见 [下载与安装教程.md](下载与安装教程.md)。
- 装完点开闪退或打不开：确认安装的是 [Local Dream 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b49a3d464c24) 里对应版本的包，对照文件大小 53.64M、包名 `io.github.xororz.localdream`；来源不明的同名包不建议安装。
- 能打开但一张图都出不来：回到本篇第一节查本地通信拦截。

## 八、想复现别人发的图但结果不一样

先确认三件事：**模式相同吗**（CPU/GPU/NPU）、**芯片相同吗**、**模型与参数逐项一致吗**。跨设备复现的规则见 [生成参数调节指南.md](生成参数调节指南.md) 的种子表格——GPU/NPU 跨芯片本就可能不同，要逐位一致只能用 CPU 模式。
