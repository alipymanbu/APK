# MikuMikuPhoto 模型与姿势数据导入方法

> 应用自带的模型和姿势很有限，本篇讲怎么把 MMD 圈的 `.pmd` / `.pmx` 模型与 `.vpd` 姿势放进手机，让应用认出来。

## 一、先分清三种文件

| 后缀 | 是什么 | 从哪来 |
| --- | --- | --- |
| `.pmd` | MMD 模型文件（MMD ver3.x 起支持） | 模型配布页 |
| `.pmx` | 扩展模型文件（MMD ver7.31 起支持） | 模型配布页 |
| `.vpd` | 姿势数据文件 | 姿势配布页（姿势常从动作数据里提取） |

MikuMikuPhoto 的官方说明只认这三种。注意版本差异：官方说明按 2.0.5 的口径写明支持 `.pmx`，但更新记录里「PMX enabled」是 2.0.0 才加上的——你手里 1.0.14b 这类早期构建，稳妥起见优先用 `.pmd` 模型试。

## 二、往手机的哪个文件夹放

按官方说明，应用从存储里一个固定结构的 `MikuMikuPhoto` 文件夹读取自定义数据：

```text
MikuMikuPhoto
├─Data
└─UserFile
   ├─Model    ← .pmd / .pmx 模型放这里
   └─Pose     ← .vpd 姿势放这里
```

老说明里写的「SD Card」指当年的存储卡；现在的手机没有插卡一说了，对应的就是内置共享存储的根目录——文件管理器打开后看到的顶层位置。如果手机里暂时找不到这个文件夹，先启动一次应用再回来看。

## 三、导入的完整步骤

1. 用数据线把手机连上电脑（USB 模式选「文件传输 / MTP」），或直接在手机上用文件管理器操作；
2. 找到存储根目录下的 `MikuMikuPhoto` 文件夹；
3. 把 `.pmd` / `.pmx` 模型文件放进 `UserFile/Model`；
4. 把 `.vpd` 姿势文件放进 `UserFile/Pose`；
5. 断开连接；
6. **重启应用**——官方步骤里明确要求重启后才会读到新文件。

两个细节：

- 模型通常不是单个 `.pmd` 裸文件，还带着贴图等一串同目录文件。从 1.4 版起官方支持把「装着模型的那整个文件夹」原样拷进 `Model`，不用拆散文件；
- 重启后列表里没有新模型，先确认文件确实放进了 `UserFile` 下面的对应子目录，而不是 `MikuMikuPhoto` 根目录或 `Data` 里。

## 四、模型与姿势去哪里找

官方说明推荐的入口是 VPVP wiki 的模型数据汇总页；具体哪个站有什么、下载密码怎么找、日文包乱码怎么解、拿之前要过哪两层规约，[MMD模型与姿势去哪下载.md](MMD模型与姿势去哪下载.md) 按渠道整理了一份清单。

数据拿到手，接着往下走导入步骤。

## 五、放进去了但应用里不显示

按顺序排查：

1. **没重启应用**——新文件要重启后才被读到，这是官方写明的规则；
2. **放错层级**——文件在 `MikuMikuPhoto` 根目录或 `Data` 下，没进 `UserFile/Model` / `UserFile/Pose`；
3. **版本不认格式**——早期构建对 `.pmx` 的支持存疑，换 `.pmd` 模型再试；
4. **模型文件没带齐**——只拷了 `.pmd` 本体、丢了贴图文件，角色会载入失败或显示异常，优先按「整个文件夹」的方式拷。

排查通过后，回到 [拍照合成使用步骤.md](拍照合成使用步骤.md) 的 Character / Pose 一步就能选到新内容；应用还没装好的，先回 [下载与安装教程.md](下载与安装教程.md)。
