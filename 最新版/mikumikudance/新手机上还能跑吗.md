## 一、先说结论

装得上，跑不跑得动按这个顺序验：能装 → 打开不闪退 → 相机有画面 → 自带模型载入正常 → 自己导入的模型能读。五关都过就能正常用；卡在哪一关，对应下面哪一节。

## 二、64 位限制对它不适用

近年不少新机型只支持 64 位应用，很多老 APK 因此直接装不上。但解包这份 1.0.14b 可以看到，里面没有存放 CPU 专属代码的 `lib/` 目录——它是纯 Java 应用，不挑 CPU 架构，64 位机型不会因为架构问题拒绝它。装不上的时候，原因一般出在系统设置，而不是应用本身。

## 三、安装环节可能遇到的两道提示

- **未知来源**：新系统默认禁装商店之外的应用，按 [下载与安装教程.md](下载与安装教程.md) 第三节给浏览器或文件管理器授权即可；
- **安全扫描提示风险**：对没有商店记录的老包，系统安全组件可能弹风险提示。来源你自己把关，确认是你要的那份再继续装。

## 四、相机与存储这两个老接口

- **相机**：应用用的是老式相机接口，官方最后一次更新（公开记录到 2.0.5，2018 年前后）也没有做新系统适配。取景黑屏这类问题在新机型上偶有发生，没有设置可救。而且按公开更新记录，「用相册照片合成」的入口是 1.1.0b 才加的，你手里这份 1.0.14b 未必有——相机模式彻底不工作的设备，这份应用几乎没有替代用法。
- **存储**：它按老规则直接读共享存储根目录的 `MikuMikuPhoto` 文件夹。按旧标准编写的应用在新系统上仍保留这种老式访问方式，所以 [模型与姿势数据导入方法.md](模型与姿势数据导入方法.md) 里的文件夹方案在新机型上大概率照用；应用读不到新文件时，先重启一次应用再看。

## 五、装上了但表现异常

- **打开就闪退**：先重启手机再试一次；仍闪退说明这台设备跑不动它，没有调参余地；
- **相机黑屏**：到系统设置的权限管理里确认相机权限没被关掉——老应用一般在安装时就已被授权，个别系统或清理工具会改动它；
- **渲染发暗或轮廓异常**：官方说明里就写明个别机型卡通着色不生效、轮廓线不可调，老应用在新 GPU 上的渲染差异只会更多——能出图就算可用。
