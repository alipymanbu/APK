> 从选入口、载入角色到按快门，本篇按实际操作顺序走一遍 MikuMikuPhoto 的拍照合成流程。

## 一、启动时二选一：现拍还是用旧照

打开应用，先在两个入口里选一个：

- **Launch Camera**——现场取景，角色实时叠进相机画面；
- **View Photo**——从相册挑一张已有照片当背景来合成。

按官方说明，推荐 **View Photo**。你手里这份 1.0.14b 是最初期的构建：从公开更新记录看，「用已有照片合成」是 1.1.0b 才加入的功能——如果启动界面没有 View Photo 这个入口，是版本原因，不是应用坏了。

## 二、合成一张照片的完整步骤

**用已有照片（View Photo）**：

1. 按 **Photo**，从相册选一张照片当背景；
2. 按 **Character**，选一个角色载入；
3. 按 **Pose**，给角色选一个姿势；
4. 长按屏幕并拖动，把角色挪到合适的位置；
5. 在屏幕上滑动，旋转角色的朝向；
6. 按快门，合成结果保存成照片。

**现场拍照（Launch Camera）**：从第 2 步开始完全一样，只是没有第 1 步——背景就是镜头正在拍到的画面。

这份 1.0.14b 的货底，按安装包内容实测：模型三个——`miku`、`rin`、`len`（初音未来、镜音铃、镜音连）；姿势九个——站立三款（stand1/2/3）、走（walk）、跑（run）、出拳（punch）、挥手（good_bye）、旋转（rotate）、cowabunga。文件名就直接出现在应用的选择列表里。

嫌这几样不够用，先去 [模型与姿势数据导入方法.md](模型与姿势数据导入方法.md) 补货再回来拍。

## 三、手势速查

| 手势 | 作用 |
| --- | --- |
| 长按并拖动 | 平移角色位置 |
| 单指滑动 | 旋转角色 |
| 双指捏合 / 张开 | 缩放角色大小 |

官方说明里列过两条机型差异：Android 2.3.1 以下屏幕方向固定；2.2 以下没有双指缩放。另外个别机型上卡通着色（toon shading）不生效、轮廓线（contours）不可调——碰上「别人有我没有」的情况，先对照这几条再怀疑自己操作错了。

## 四、画面参数都在 Option 里

快门之前想让角色更像「长在照片里」，调这几项：

| 参数 | 管什么 |
| --- | --- |
| Light / LightColor | 灯光位置与颜色 |
| Shadow / ShadowColor | 阴影与阴影颜色 |
| Eye / Lip / Brow / Accessory | 眼、唇、眉的表情细节与饰品 |
| Contours | 轮廓线 |
| Effect | 模糊效果 |
| Shading | 角色明暗着色 |
| Etc | 其余杂项 |

调光照时对照背景照片里的光源方向，合成痕迹会更小。

安装包里还带黑白（mono）、深棕（sepia）整屏色调、高斯模糊、投影阴影等着色器——Option 各项试出来的效果大致就是这几种能力，哪个按钮对应哪种效果，以你界面上的实际表现为准。

## 五、你的调整会被记住

按官方说明，应用退出时保存当前状态，下次启动直接恢复。做到一半退出不用重调；反过来，如果某次打开发现角色位置、参数都不对，多半是上次退出时留下的样子，不是应用坏了。

想给画面换角色、换姿势，见 [模型与姿势数据导入方法.md](模型与姿势数据导入方法.md)；应用本身还没装好的，回 [下载与安装教程.md](下载与安装教程.md)。
