## 一、饰品是怎么送到你手里的

在 Carry 上成交只是第一步，饰品的转移由 Steam 的交易系统完成：

1. 平台撮合成交后，你的 Steam 账号会收到一笔交易报价；
2. 打开 Steam 手机应用（或电脑客户端、确认邮件）查看这笔报价；
3. 逐项核对无误后，在 Steam 手机应用的确认器里确认；
4. 等物品送达，Steam 库存里就能看到饰品。

确认这一步谁也替不了你：报价里的对方资料、物品名称、磨损档位、所属游戏标签，对过再点确认；对不上就拒绝。从下单价到这一步的衔接见 [买饰品流程与筛选技巧.md](买饰品流程与筛选技巧.md)。

## 二、什么情况会被暂挂

Steam 有交易暂挂机制（规则以 [Steam 官方说明](https://help.steampowered.com/zh-cn/faqs/view/34A1-EA3F-83ED-54AB)为准）：

| 情况 | 结果 |
| --- | --- |
| 送出物品的账号启用 Steam 令牌手机验证器未满 7 天 | 物品被暂挂最长 15 天后才送达 |
| 验证器已启用满 7 天 | 交易不再暂挂 |
| 你取消了一笔正在暂挂中的交易 | 触发 7 天交易冷却，Steam 客服也无法解除 |

注意暂挂看的是**送出物品那一方**的账号状态：

- **卖家**：刚开启 Steam 令牌就急着卖，前 7 天的每一单都会被暂挂拖上最多 15 天，见 [卖饰品手续费与提现规则.md](卖饰品手续费与提现规则.md)；
- **买家**：饰品迟迟不到，先想想是不是对方在暂挂期，去订单记录与 Steam 侧的报价状态核对，别急着下结论。

## 三、动饰品之前就该锁好的账号设置

- **开启 Steam 令牌手机验证器**：在 Steam 手机应用里开启。它既是使用 Steam 社区市场的官方前提，也是免暂挂的唯一路径（见上表），开启后等满 7 天再生效；
- **定期自查 API key**：打开 [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey)，出现自己没创建过的 key 就立即吊销并改密码 —— 多份交易安全指南指出，最主流的盗饰手法「交易重定向」正是靠不明 API key 监控并调包你的交易报价；
- **不从别人发来的链接登录 Steam**：假登录页会顺手在你账号下生成 API key；登录只走自己输入的网址或收藏夹；
- **认准客服渠道**：Steam 官方客服只通过 [help.steampowered.com](https://help.steampowered.com/) 服务，不会通过 Discord、Telegram 等第三方聊天工具主动找你谈账号或物品；Carry 平台的事务在应用内与订单页处理。

## 四、确认前必做的核对动作

「交易重定向」的套路：骗子拿到你账号的 API key 或控制权后，在你发出交易的瞬间取消它，再冒用同名同头像的账号发来一份几乎一样的报价，赌你在确认器里看都不看就点确认。每笔确认前做四个核对（依据 Steam 官方防骗说明与多方交易安全指南）：

1. 核对**对方资料**与你的交易对象一致；
2. 核对**物品名称、磨损档位、所属游戏标签** —— 冒牌饰品常挂在别的免费游戏名下，游戏标签不对就是假的；
3. 翻一眼**交易报价历史**：出现过「一笔被取消、紧接着内容相同的新报价」，就是调包进行中，立即取消并改密码；
4. 对方越催「快点确认」越要放慢 —— 施压是骗局的标配。

## 五、真被骗了怎么办

按多方公开资料的口径：对你本人确认过的交易，Steam 客服一般不返还物品；2025 年起 CS2 引入了交易保护机制，部分受保护物品在交易后 7 天内有机会撤销，能否挽回以 Steam 官方说明为准。所以这件事只能前置预防：设置按第三节锁好，确认按第四节核对。

平台侧的问题（付了款没收到报价、订单状态对不上）在 Carry 应用内的订单记录里核对状态，通过平台自己的渠道反馈处理，别转去平台外找人「私下解决」。
