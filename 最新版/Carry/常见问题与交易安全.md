## 一、版本差异：1.0.1 与 1.1.0

网盘里这份安卓包是 v1.0.1，公开渠道的安卓与 iOS 版已到 1.1.0。按 iOS 端 1.1.0 的更新日志，两代版本差在：

- 新增挂件模版显示与模版搜索；
- 新增背包：通过活动获得的饰品可在背包中查看和取回；
- 新增收款设置：**上架出售前需先绑定支付宝**；
- 出售订单增加了手续费显示；
- **取消钱包余额**：出售所得直接转入绑定的支付宝；
- **取消求购、供应、批量购买**功能。

对应到实际使用：在 1.0.1 上你可能还能看到求购入口，新版本上没有；卖饰品的到账方式两代也不一样，对照见 [卖饰品手续费与提现规则.md](卖饰品手续费与提现规则.md)。v1.0.1 当时的公开更新说明只有一句「优化交易安全机制」，没提别的改动。

## 二、几个端怎么选

| 端 | 说明 |
| --- | --- |
| 安卓 App | 主力端，功能最全；安装包资源见 [下载与安装教程.md](下载与安装教程.md) |
| 网页端 | 官网 [www.carryskin.com](https://www.carryskin.com/)，浏览器直接用，不用安装 |
| iOS「Carry市场」 | 在 App Store 搜「Carry市场」，按开发者 Sanyang Pilot (Hainan) Technology Co Ltd 核对，系统要求以 App Store 页面为准 |
| 电脑上跑 App | 通过应用宝电脑版运行安卓应用，装法见 [下载与安装教程.md](下载与安装教程.md) 第四节 |

同一账号多端通用，但余额、订单状态以平台服务端为准，切换端后刷新一下再看。

## 三、交易安全注意

- 平台侧的口径是 **AI 算法检测交易**，为交易护航；这是平台自己的措施，替代不了你自己的确认习惯；
- Steam 侧的每一笔交易，**在你自己的 Steam 手机确认器里逐笔确认**再放行 —— 收到自己没发起过的交易报价，一律拒绝；
- 平台账号实名与支付宝实名一致才提得出钱，账号别借给别人用，要求见 [注册登录与Steam账号绑定.md](注册登录与Steam账号绑定.md)；
- 第一次大额交易前，先用小额把全流程走一遍（绑定 → 下单 → 收货或到账），确认每个环节都通再加量；
- **调包骗局**：饰品交易最主流的盗饰手法是「交易重定向」—— 靠不明 API key 监控并调换你的交易报价；定期到 Steam 的 API key 页面自查、每笔确认前逐项核对，完整动作见 [Steam交易确认与防盗号设置.md](Steam交易确认与防盗号设置.md)；
- **交易暂挂**：新启用 Steam 令牌的账号送出物品会被 Steam 暂挂最长 15 天，买卖两边都可能遇到，规则见 [Steam交易确认与防盗号设置.md](Steam交易确认与防盗号设置.md)。

## 四、同名牌与易混项

- **App Store 搜「Carry」**：排前面的是一款旅行打包清单应用，与本平台无关；本平台的 iOS 版叫「Carry市场」；
- **其他饰品平台**：网易 BUFF、C5Game、IGXE 等与 Carry 是不同家的产品，功能定位相近，但账号、余额、手续费规则互不相通，别混着看价。

## 五、找不到某个功能时

按这个顺序排查：

1. **先核对版本**：1.0.1 与 1.1.0 的功能差异见本文第一节，求购、钱包余额这类入口随版本变；
2. **再对入口路径**：本文各篇写的是 v1.0.1 时期的界面路径，新版本措辞可能不同，在「我的」与设置里找相近字样；
3. **还不确定**：以你手上应用的实际界面为准，或到官网 [www.carryskin.com](https://www.carryskin.com/) 核对当前版本的功能说明。
