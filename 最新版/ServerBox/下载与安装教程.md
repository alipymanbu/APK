## 一、ServerBox 是什么

ServerBox 是一款开源的服务器工具箱（开源项目名 flutter_server_box，作者 lollipopkit），装在安卓手机上，通过 SSH 连接并管理你的 Linux / Unix 服务器：看 CPU、内存、磁盘、网络的状态图表，用 SSH 终端敲命令，用 SFTP 传文件，也能管理 Docker 容器、进程和 Systemd 服务。

它不需要在服务器上装任何组件——只要目标机器能正常 SSH 登录，手机端装上 App 就能连。

## 二、安装前确认三件事

1. **手机系统版本**：官方在 F-Droid 发布的版本要求 Android 7.0 及以上（不同时期的要求可能变化，以 [F-Droid 页面](https://f-droid.org/packages/tech.lolli.toolbox/) 标注为准）。
2. **手机 CPU 架构**：安装包分三种架构——`arm64-v8a`（2016 年之后的绝大多数手机）、`armeabi-v7a`（较老的机型）、`x86_64`（模拟器、少数平板）；不确定就选 `arm64-v8a`。
3. **服务器可连通**：目标是 Linux、macOS 或 Termux 这类 Unix 系统，Windows 服务器连不了。

## 四、安装步骤

1. 把 APK 下载或复制到手机存储；
2. 用文件管理器点开 APK，系统提示「未知来源应用」时，按提示允许该文件管理器安装应用；
3. 点安装，等进度走完；
4. 打开 App，首页就是「服务器」列表页（右下角「+」用来添加服务器），首次使用先去添加一台服务器。

这份安装包约 41 MB，比常见小工具略大，属于正常体积。

## 五、版本与文件校验

- 网盘里这份的版本是 **1.0.1480**，包名 `tech.lolli.toolbox`。官方一直在更新，想要新版本就去 GitHub Releases 或 F-Droid 拿，装新版直接覆盖即可，配置会保留。
- 需要核对文件是否完整时，比对 MD5：`90816430DB100EBA9D836248BF7DDA9D`（MD5 只对同一个文件有效，不同渠道不同版本的包对不上是正常的）。

## 六、会用到哪些权限

以 F-Droid 页面列出的权限清单为准，与核心功能相关的主要有：

| 权限 | 什么时候用 |
| --- | --- |
| 完全的网络访问 | SSH / SFTP 连接服务器，必须允许 |
| 前台服务 | 后台保持连接、执行传输任务 |
| 通知 | 使用推送提醒类功能时 |
| 生物识别硬件 | 开启应用锁（指纹 / 面容）时 |
| 存储读写 | SFTP 从手机上传、下载文件到手机 |

另有相机、录音等权限，SSH / SFTP 连接并不依赖它们，介意的话可以在系统设置里单独关闭，不影响正常使用。

## 七、升级与重装

- **升级**：新 APK 直接覆盖安装，服务器配置保留；从 F-Droid 安装的，用 F-Droid 客户端更新即可。
- **重装 / 换机**：服务器列表、密钥、设置都只存在手机本地，卸载即全部丢失。动手前先在 App 的备份页导出备份，新环境里再导入恢复，具体做法见「添加服务器与SSH连接配置」的备份部分。
