## 一、SSH 终端

连上服务器后，从服务器详情页进终端（App 底部也有「终端」标签页）。它就是一个交互式终端，你平时在服务器上敲什么，这里就敲什么：`sudo`、`vim`、`htop`、`systemctl` 都照常。

手机上用终端，三个点最有用：

- **虚拟按键**：手机键盘没有 Esc、Tab、Ctrl 这些键，App 提供了一排虚拟按键补足；在设置里可以决定显示哪些、怎么排序，看不懂的图标在同一处有说明。
- **选字复制**：在终端里长按并滑动，可以选中字符后复制。
- **字体缩放**：觉得字太小，可以在设置里调文本缩放（隐藏设置项 `textFactor`，见「常见连接问题排查」）。

### 终端老是自己断开

两边都要查：

1. **服务器端**：SSH 服务配置了会话存活时间，或中间的 NAT / 防火墙把空闲连接掐了——可调服务器 sshd 的 `ClientAliveInterval` / `ClientAliveCountMax`；
2. **手机端**：省电机制把 ServerBox 的后台进程杀了——系统设置里找到 ServerBox，允许后台运行、关闭电池优化。

其他断连场景见「常见连接问题排查」。

## 二、Snippet：把常用命令存起来

底部的「代码片段」标签页用来存反复要敲的命令：重启某个服务、看日志尾部、清缓存……存好后在终端里随时调用，不用每次手打。

Snippet 支持参数化占位符，发出去之前会替换成实际值：

| 占位符 | 替换成 |
| --- | --- |
| `${host}` / `${port}` / `${user}` | 服务器的主机 / 端口 / 用户 |
| `${pwd}` / `${id}` / `${name}` | 密码 / 服务器 ID / 名称 |
| `${ctrl+c}`、`${alt+c}` 这类 | 对应按键动作，如 Ctrl+C |

按键类占位符可以组合，比如 `${ctrl+b}d` 就是 Tmux 的 Detach。用法是写进片段里，如：

```bash
ssh ${user}@${host} -p ${port}
```

## 三、自动运行：连上就执行的命令

服务器编辑页里有「自动运行」入口：把一段命令设为自动运行，每次连上这台服务器就自动执行。典型用途：

- 连上先 `cd` 到常用目录；
- 直接 `tail -f` 某个日志；
- 连接后顺手带一句 `tmux attach`。

自动运行同样支持 Snippet 的那套占位符，可以组合出「连上后按用户名跳目录」这类固定流程。

## 四、SFTP 文件管理

底部的文件标签页（SFTP）用来在手机和服务器之间传文件：

- 浏览服务器目录，**上传**本地文件、**下载**服务器文件到手机；
- 新建文件 / 文件夹、搜索、目录跳转；
- **内置编辑器**：直接打开服务器上的文本文件（配置文件、脚本）改几行、保存回去，省掉「下载 → 本地改 → 传回去」三步。

常用场景对照：

| 你要做的事 | 用哪个 |
| --- | --- |
| 改一行 nginx / sshd 配置 | SFTP + 内置编辑器 |
| 把手机里的照片备份到服务器 | SFTP 上传 |
| 把服务器上的日志拉到手机里看 | SFTP 下载 |
| 大量文件打包搬家 | 先在终端 `tar` 打包，再 SFTP 下载那一个包 |

传输任务在下载管理里查看。大文件传输别在后台挂太长时间——手机省电策略可能把任务杀掉，原因和对策同终端断连那一节。
