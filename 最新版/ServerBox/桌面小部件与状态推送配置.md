## 一、为什么需要 ServerBox Monitor

桌面小部件、推送这类「不开 App 也要工作」的功能，运行环境里没有 SSH 连接，拿不到常规数据。官方的做法是提供一个装在**服务器上**的组件 ServerBox Monitor：它把服务器状态通过 HTTP 接口吐出来，小部件和推送从这些接口取简化数据，它还自带一个网页面板。

不装 Monitor 的影响范围只有这一层——App 内的图表、SSH、SFTP、容器管理全部照常用；缺的只是「不开 App 也有状态」这部分能力。

Monitor 怎么装、App 怎么以 monitor 方式接入，见 [Monitor部署与远程访问配置.md](Monitor部署与远程访问配置.md)；官方原文：[github.com/lollipopkit/flutter_server_box/blob/main/monitor/README_zh.md](https://github.com/lollipopkit/flutter_server_box/blob/main/monitor/README_zh.md)

## 二、安卓桌面小部件配置步骤

1. 在系统桌面长按空白处 → 添加小部件 → 选 ServerBox；
2. 把小部件上显示的 **ID** 记下来；
3. 打开 App 设置，点「Config home widget link」；
4. 新增一条键值对：**键 = 小部件 ID**，**值 = 能返回服务器状态的 URL**（一般是 Monitor 提供的状态接口地址）；
5. 保存，回到桌面点一下小部件立即刷新。

要点：

- 可以放多个小部件，各自配不同的 URL，分别盯不同服务器；
- 安卓小部件的刷新时机由系统调度，不会高频自动刷新，想看最新数据就点一下它；
- 小部件走的是 HTTP 接口而不是 SSH，所以服务器侧必须先把 Monitor 装好、URL 能访问，小部件才有内容。

## 三、关于推送

推送同样依赖 Monitor。官方 Wiki 里对推送的说明目前以 iOS 为主（在 App 设置里取 Token 配置，且自编译版本用不了官方推送服务）；安卓端的配置方式与功能边界以官方文档的更新为准：[github.com/lollipopkit/flutter_server_box/wiki](https://github.com/lollipopkit/flutter_server_box/wiki)。

只想要「服务器出事能知道」的话，还有一条不依赖推送的路：桌面放一个小部件定期扫一眼，配合 Monitor 自带的网页面板在电脑上常开。

## 四、配好之后还是不显示？

按顺序查：

1. 服务器上 Monitor 跑起来没有——浏览器直接访问你填的那个 URL，能返回状态数据才算通；
2. URL 是不是填错了——键必须是小部件上显示的那个 ID，别把多台机器的 ID 混了；
3. 手机能不能访问到该地址——内网部署的 Monitor，手机不在同一局域网时是打不开的；
4. 以上都对还不行，重启一下小部件所在的桌面（或重启手机）让它重新拉取。
