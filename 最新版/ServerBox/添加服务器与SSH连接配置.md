## 一、添加前需要准备什么

- 一台能 SSH 登录的服务器：IP 或域名、SSH 端口（默认 22）、用户名，以及密码或私钥；
- 手机与服务器网络互通：同一局域网、服务器有公网 IP，或你已经做好了内网穿透；
- 服务器系统是 Linux、macOS、Termux 等 Unix 类系统——Windows 服务器不在支持范围。

## 二、手动添加一台服务器

在首页「服务器」页点右下角「+」进入编辑页，逐项填写：

| 字段 | 填什么 |
| --- | --- |
| 名称 | 随意，只用于显示，建议带上用途（如「博客机」） |
| 主机 | IP 或域名 |
| 端口 | SSH 端口，默认 22，改过端口就填实际值 |
| 用户 | 一般是 `root` 或你自己的普通用户 |
| 密码 | 密码登录就填在这里 |

两个开关按需设置：

- **密钥认证**：打开后改用私钥登录（见下一节）；
- **自动连接**：打开后进 App 会自动连这台服务器，不用每次手点。

保存后回到列表页点卡片即可进入详情。一直连不上的话，按「常见连接问题排查」里的顺序过一遍。

## 三、用私钥登录

不少云服务器默认禁用密码登录，只能用私钥。整条链路分两半：服务器上要有你的公钥，App 里要选对私钥——两头对上才登得进。

**服务器侧**（在还能登录的前提下做一次）：

1. 把公钥装到你要登录的那个用户的 `~/.ssh/authorized_keys` 里——`ssh-copy-id 用户名@服务器IP` 一条命令搞定，或手动把 `.pub` 文件内容追加进去；
2. 权限太开放 OpenSSH 会静默忽略公钥：`~/.ssh` 要 700、`authorized_keys` 要 600，归属是你登录的那个用户；
3. 公钥装在哪个用户名下，就只能用哪个用户名登录——装给 `root` 不等于能用 `ubuntu` 登。

**App 侧**：

1. 打开服务器编辑页的「密钥认证」开关，按界面提示录入或选择私钥（带口令的私钥把口令一起填上）；
2. 保存后连接测试一次，确认能用再撤掉密码登录的旧方式。

建议先用密码方式验证「网络通、配置对」，再切换成私钥，这样出了问题好分辨是网络原因还是密钥原因。认证失败的逐条排查见「常见连接问题排查」。

## 四、多台服务器：导入与批量迁移

一台台加太慢时有两条路：

- **编辑页顶部的「导入」**：把已有配置导入成服务器条目；
- **备份页的批量导入**：按官方 Wiki「Bulk import servers」一节给出的 JSON 格式准备文件，进 App 的备份页选择批量导入即可。文件格式以官方 Wiki 为准：[github.com/lollipopkit/flutter_server_box/wiki](https://github.com/lollipopkit/flutter_server_box/wiki)。

## 五、备注与标签

服务器编辑页还支持给每台机器写**备注**、打**标签**。机器多了以后，标签是首页列表里最快的筛选方式——按「生产 / 测试」「国内 / 海外」这类维度打，找机器不靠记名字。

## 六、给服务器卡片做点自定义

- **自定义 Logo**：在服务器卡片设置里填一个图片 URL，卡片就会显示它。URL 里支持两个占位符：`{DIST}` 会替换成发行版名（`debian`、`ubuntu`、`centos`、`arch`、`alpine` 等），`{BRIGHT}` 会替换成当前主题明暗（`light` / `dark`）。例如 `https://example.com/{DIST}.png` 实际请求的是 `https://example.com/debian.png`。
- **自定义命令**：在服务器设置底部用 JSON 填命令，例如：

  ```json
  {
    "内存": "free -h"
  }
  ```

  保存后，服务器详情页会出现「自定义命令」卡片，点开就能看对应输出。把命令名写成 `server_card_top_right`，输出会直接显示在首页卡片右上角——常见用法是自定义温度采集。
- **长按卡片**：可以编辑配置，也可以直接挂起或关机这台服务器。这是真关机，手滑前想一下。

## 七、数据备份与迁移

服务器列表、私钥、设置都只存在手机本地，卸载 App 就全没了。换机或重装前的标准动作：

1. 在 App 的备份页导出备份文件；
2. 新环境装好后，用备份页的导入功能恢复；
3. 多台服务器的批量迁移走「批量导入」。

安装包丢失时，从「下载与安装教程」里的渠道重新获取即可。
