# ServerBox 常见连接问题排查

> 连不上、超时、频繁断线，是用 ServerBox 最常碰到的三类问题。本篇先教你用报错关键字分辨失败类型，再按现象给排查顺序，顺带收一下隐藏设置、日志和备份这几个应急手段。

## 一、先分清是哪种失败

手机上那行报错本身就带方向：

| 报错关键字 | 多半是 | 先查什么 |
| --- | --- | --- |
| Connection refused（连接被拒） | 服务器那头明确拒绝了 | SSH 服务在不在跑、端口对不对、防火墙 / 安全组放没放行 |
| Connection timed out（超时） | 数据包根本没到服务器 | IP 写对没有、网络可不可达、手机自己的网络环境 |
| Permission denied（认证失败） | 网络已通，卡在账号验证 | 下一节的认证专查 |

通用前提（官方明确说过）：ServerBox 只支持 Unix 类服务器（Linux、macOS、Termux 等），**连不了 Windows 服务器**，且建议服务器端用较新的 OpenSSH 版本。

## 二、认证失败（Permission denied）专查

按命中率从高到低：

1. **用户名错**：各家云镜像的默认用户不一样——Ubuntu 镜像是 `ubuntu`，Amazon Linux 是 `ec2-user`，不少 VPS 直接给 `root`，树莓派是 `pi`。用户名错的话，服务器在验证密钥之前就把你拒了；
2. **公钥没装到服务器上**：App 里选的私钥，它的公钥必须出现在你要登录的那个用户的 `~/.ssh/authorized_keys` 里。在还登录得上的通道里补一句 `ssh-copy-id 用户名@服务器IP`，或手动把 `.pub` 文件的内容追加进去；
3. **权限太开放**：OpenSSH 会静默忽略权限不对的公钥文件——`~/.ssh` 要 700、`authorized_keys` 要 600，归属是你登录的用户；
4. **服务器配置限制**：sshd 里 `PasswordAuthentication no` 时密码登录必被拒（走私钥）；`PermitRootLogin no` 时 root 登录必被拒（换普通用户）。

一个常见误区：公钥装给了 `root`，不等于能用 `ubuntu` 登录——公钥跟着用户走。

## 三、连接超时

连接超时默认很短（5 秒左右），手机网络慢、服务器在境外、域名解析慢时容易触发。超时时间可以在隐藏设置里调：

1. 在首页抽屉里**长按设置项**，进入 JSON 编辑模式；
2. 加一条 `"timeOut": 15`（单位是秒），保存生效。

JSON 编辑属于高级功能，改错可能导致 App 打不开——改之前先把现有 JSON 内容复制出去备份一份。

## 四、连上但频繁断线

- **服务器端**：SSH 有会话存活时间限制，或中间的 NAT / 防火墙掐掉空闲连接——调 sshd 的 `ClientAliveInterval` / `ClientAliveCountMax`；
- **手机端**：省电机制把 ServerBox 后台杀掉——系统设置里允许后台运行、关闭对 ServerBox 的电池优化；
- **网络切换**：Wi-Fi 与蜂窝之间切换时连接本来就会重建，属正常现象。

## 五、改坏了设置打不开 App

隐藏设置的 JSON 改错，最严重的后果是 App 启动不了。应急顺序：

1. 系统设置里**清除 ServerBox 的应用数据**（比重装快，效果等同恢复出厂：设置回默认、服务器清空，需重新添加）；
2. App 本身装坏了才考虑卸载重装，重装前记得已导出过备份；
3. 安装包没有了，从 [ServerBox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b974924a12ac) 重新获取。

## 六、看日志与反馈问题

- App 首页右上角有**日志入口**，出问题时先打开看一眼；
- 官方 Wiki 收了常见问题的官方解答：[github.com/lollipopkit/flutter_server_box/wiki](https://github.com/lollipopkit/flutter_server_box/wiki)（自定义 Logo、自定义命令、批量导入、小部件配置都在里面）；
- 要去 [GitHub Issues](https://github.com/lollipopkit/flutter_server_box/issues) 反馈时，按官方要求附上完整日志，并先确认问题出在 App 而不是服务器本身。

## 七、防患于未然

- 服务器配好就在**备份页导出一份备份**，换机、重装、清数据都不慌；
- 改隐藏设置前，把改动的键名和原值记在备注或别处，方便回滚；
- 认证类问题十有八九出在服务器端配置，App 侧能做的只有选对私钥和放宽 `timeOut`。
