## 一、应用打不开、闪退、页面空白

官方给的「简单错误解决法」就是一张固定清单，按顺序做完再看有没有好转（安卓口径，iPhone 同理、更新入口换成 App Store）：

1. 关掉应用再打开；
2. 登出后重新登录（路径见 [注册登录与账号找回.md](注册登录与账号找回.md)）；
3. 清理存储空间——应用缓存、应用数据、相册里的照片视频都算；
4. 确认**没有在别的设备上同时登录**（一机一账号是硬规则）；
5. 重启手机；
6. 更新应用：Google Play 里搜到 Celeb Champ 后**别点「打开」，点应用图标**进入详情页，出现「更新」就点；
7. 更新手机系统：设置 → 软件更新 → 下载并安装。

清单走完还不行，先回 [下载与安装教程.md](下载与安装教程.md) 核对两件事：系统是否满足**安卓 5.2 以上**、装的是不是 `com.nwz.celebchamp` 这个包名。都对的话就是重装一次（先登出再卸载，装完用原登录方式登回）。

## 二、看广告不给玫瑰 / 广告加载不出来

排查步骤在 [玫瑰花获取与有效期.md](玫瑰花获取与有效期.md) 第三节完整给了（登录状态 → 网络 → 隔几秒再点 → 重置广告 ID → 广告平台可能没量），这里补两条常见根因：

- **iOS 限制了广告跟踪**会导致广告放不出来：设置 → 隐私保护 → 广告 → 关掉「限制广告跟踪」。
- **连续快速点**是最常见的自伤操作：官方明确建议两条广告之间留几秒间隔。

另一个「看起来像 bug」的其实是额度：**每天广告上限就是 10 次、每次 3 玫瑰**，拿满后再点不给，不是故障。免费攒取的完整规则在 [玫瑰花获取与有效期.md](玫瑰花获取与有效期.md)。

## 三、充值扣款了但玫瑰没到账

官方口径分两段：

1. **扣款成功却没到账的，3~7 天内会自动取消这笔扣款**，不用自己折腾；
2. **超过 7 天既没退款也没到账**，找应用商店客服：

| 商店 | 官方 FAQ 给出的联系方式 |
| --- | --- |
| Google Play | 080-085-1500、02-531-9000（拨通后按 0 转人工） |
| App Store | 080-333-4000 |

**根本买不了（点不动购买）**多是商店侧问题：支付方式变更、卡片信息过期、额度超限都会导致失败——先去商店把支付方式改对。另有一个官方给的小偏方：支付时如果**看不到「청약철회규정（撤回申请规定）」确认按钮**、卡在下一步进不去，把手机**屏幕尺寸与字体调小**再试。

## 四、要退款

退款不走应用内按钮，按官方流程发邮件到 [celebchamp@mbcplus.com](mailto:celebchamp@mbcplus.com)，正文写清三样：

1. Celeb Champ 昵称；
2. 购买日期；
3. 要退的商品（金额与玫瑰数量）。

官方收到后先确认可否退款，再告知后续步骤。另外记住：**付费买的玫瑰在账号注销时一起清零**，别用注销代替退款（见 [注册登录与账号找回.md](注册登录与账号找回.md)）。

## 五、免费充值站的任务出了问题

免费充值站（看广告攒玫瑰）背后是多家广告平台，官方要求**按你当时点的那个入口分别报**：

| 你用的入口 | 报障路径 |
| --- | --- |
| 「간단한 광고（简单广告）」 | 左侧菜单 → 보상내역（奖励记录）→ 点该条广告 → 고객문의 작성（写客服咨询） |
| 「빠른 광고（快速广告）」 | 左侧菜单 → Status → 点该条广告 → report issue |
| 「다양한 광고（多样广告）」 | 参与목록 → 도움말 → 最底部「궁금해요（有疑问）」提交 |

官方标注这类受理**按顺序在 7~10 天内处理**，发完等回复即可。

## 六、找官方的三条路

自己排完仍解决不了，按省事程度：

1. **应用内**：首页右上菜单 → 1:1 문의하기（1:1 咨询）→ 填标题与正文发送。安卓机会带出详细账号信息，**别删那段**，删了会难查。
2. **邮件**：[celebchamp@mbcplus.com](mailto:celebchamp@mbcplus.com)，写昵称 + 机型 + 问题现象 + 截图。
3. **官网咨询按钮**：[celebchamp.co.kr](https://celebchamp.co.kr/) 顶部。

提工单前先把「第几条排查做到哪一步、什么现象」写清楚，来回追问会慢很多。装机阶段的问题则先看 [下载与安装教程.md](下载与安装教程.md)。
