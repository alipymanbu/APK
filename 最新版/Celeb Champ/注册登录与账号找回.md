## 一、注册只有四种入口

Celeb Champ 没有自己的用户名密码体系，官方 FAQ 写明只能用你**已有的**这四种账号注册登录：

| 登录方式 | 说明 |
| --- | --- |
| Kakao（카카오톡） | 韩国最常用的社交账号 |
| Facebook | — |
| Google | — |
| Apple | 仅 iPhone |

注册流程：打开应用选一种方式 → 勾选全部条款 → 设昵称 → 至少选 1 名应援明星 → 进首页。

三个要点：

- **昵称规则**：2~16 字符，韩文、英文、数字、表情符号、特殊符号都可以。改昵称的路径是 首页右上菜单 → 昵称旁人形图标 → 내정보（我的信息）→ 昵称右侧的修改按钮。
- **应援明星至少设 1 个**，不设用不了服务。你想支持的明星不在列表里，可以在应用内发 1:1 咨询申请添加（官方口径：偶像团体除外，个人歌手与演员经审核可加）。
- **别随手换登录方式**。你这个 Celeb Champ 账号的身份就挂在所选 SNS 账号上，换一种方式登进去的可能是另一个空账号，玫瑰与投票记录不会跟过来。

## 二、一机一账号是硬规则

官方 FAQ 明确：投票、玫瑰攒取等**全部服务按「一台设备一个账号」运行**，一台手机只能用一个账号。玫瑰攒取那侧还有两条官方列明的「攒不到」情形：

- 同一台设备上换账号登录，即使重新攒取也不给；
- 换了设备，但该账号此前已在别的机器上攒过，也不给。

所以别指望靠多开、换号在同一台机器上翻倍攒玫瑰，规则上就不成立（详见 [玫瑰花获取与有效期.md](玫瑰花获取与有效期.md)）。

## 三、登出与「账号不见了」怎么找回来

登出路径：首页右上角菜单按钮 → 昵称旁的人形图标 → 내정보（我的信息）画面最下方的 로그아웃（登出）。

「我打开应用发现账号没了、数据都是空的」通常是下面几种情况，官方 FAQ 给的处理办法是：

1. **换了登录方式**——你可能原来用 Kakao、这次点了 Google。把已登录的会话整体登出，再按原来那一种方式重新登。
2. **SNS 那边改了 ID 或密码**——去对应 SNS 重新登录一遍，再回 Celeb Champ 用同一种方式进。
3. **不记得当时用的哪种**——发 1:1 咨询，附上「要找的账号昵称 + 大概在哪几个月用过」（写个大致区间就行），官方能帮你查是哪种 SNS 登的。应用本身查不到、也无法重置 SNS 的密码，密码问题要去对应 SNS 找回。
4. **原来用于登录的邮箱已注销**——官方明说这种情况**难以恢复或改绑**，这是最麻烦的一种，尽量别让登录用的邮箱先死掉。
5. **换了环境后 Kakao 那一步过不去**——Kakao 官方有「海外登录 / 国家别登录限制」这类账号安全开关（多个独立来源提及，具体以 Kakao 账号安全设置为准），你在境外网络、或新设备上首次用 Kakao 登录时可能被拦。先去 Kakao 账号的安全设置里看有没有地域限制与保护措施提示，按提示完成验证；反复失败就直接改用 Google 登录进应用（前提是当初注册用的就是 Google——**换一个 SNS 登进的是另一个空账号**，这条见本篇第一节）。

## 四、注销账号前必须知道的后果

注销路径：首页右上菜单 → 昵称旁人形图标 → 내정보 → 画面底部「셀럽챔프 탈퇴」（注销）按钮，确认注意事项后完成。

官方列明的后果，逐条都不可逆：

- 内容参与记录（投票记录等）与**持有的玫瑰全部消失，无法恢复**；
- 删除项包括：昵称、应援明星设置、玫瑰余额、玫瑰使用与攒取明细；
- 账号信息立即删除，**同一个 SNS 账号要 30 天后才能重新注册**，且旧数据不迁移。

手上有付费买的玫瑰时，注销前先把余额投掉或想清楚——付费玫瑰的定义是「退出会员前无使用期限」，但注销那一刻一起清零。

## 五、官方联系方式

账号问题自己处理不了时：

- 应用内：首页右上菜单 → 1:1 문의하기（1:1 咨询），填标题与正文发送。安卓机上发信时会带出详细账号信息，别删掉那段——官方 FAQ 特别提示删了会难查。
- 邮件：[celebchamp@mbcplus.com](mailto:celebchamp@mbcplus.com)，写清昵称、机型、问题现象并附截图。
- 官网顶部的咨询按钮：[celebchamp.co.kr](https://celebchamp.co.kr/)。

装不上或打开就出问题，先回到 [下载与安装教程.md](下载与安装教程.md) 核对包参数，再按 [常见问题与故障排查.md](常见问题与故障排查.md) 排查。
