## 一、录音没反应 / 提示需要麦克风权限

这个应用的一切评分都基于录音，麦克风权限是刚需。识别完全没反应时按顺序排查：

1. 系统级开关：部分机型的快捷设置面板里有「麦克风访问」总开关，误触关掉会导致所有应用录不了音，先确认它是开的；
2. 应用级权限：「设置 → 应用 → BoldVoice → 权限 → 麦克风」，选「仅在使用中允许」；
3. 蓝牙耳机抢麦：连着蓝牙耳机时录音可能走耳机麦，音质差会拖垮评分，排查时先断开蓝牙再试；
4. 多应用占用麦克风：后台有别的应用在录音可能产生冲突，清后台后重试；
5. 以上都无效就重启手机再试。

## 二、评分普遍偏低，像识别不准

分数异常低多数是录音质量问题，不是你发音不行。按命中率从高到低检查：

| 检查点 | 判断方法 |
| --- | --- |
| 环境噪音 | 换到安静房间重测同一句，分数明显回升就是噪音问题 |
| 收音距离 | 对着手机底部麦克风孔正常音量读，别隔太远或用很小的声说 |
| 蓝牙麦克风 | 断开蓝牙耳机改用手机自带麦克风，很多耳机麦为通话优化、录音音质差 |
| 语速 | 刻意一个词一个词往外蹦反而影响整句评估，按平时说话的节奏读 |
| 麦克风孔堵塞 | 手机壳挡住麦克风孔或孔里积灰，用录音机应用录一段自查音量 |

如果换环境、换收音方式后单个音依然稳定低分，那就是真实的薄弱音，回到每日训练里针对练（见 [发音测评与每日训练怎么用.md](发音测评与每日训练怎么用.md)）。

## 三、订阅与扣费问题

- **试用期结束被扣费了**：订阅走的是 Google Play / App Store 渠道，扣费后想退，在 Play 商店订单记录或 App Store 报告问题页面发起退款申请，说明是误续订；渠道有各自的退款裁定规则，越早申请越容易通过。
- **想取消但找不到入口**：取消不在应用内。安卓在 Play 商店「付款和订阅 → 订阅」里操作，iOS 在系统设置「订阅」里操作，详细步骤见 [免费试用与订阅价格说明.md](免费试用与订阅价格说明.md)。
- **价格和别人不一样**：订阅按你所在地区的商店定价以本地货币扣费，与官方美元标价存在折算差异，属正常现象，以你商店订阅页显示的金额为准。

## 四、账号与数据

- **换手机后进度还在吗**：登录同一账号即可延续学习记录，所以重装或换机前留意自己用的是邮箱登录还是其他方式，别换个登录方式就找不回数据。
- **网页端能练吗**：官方提供网页端入口 [start.boldvoice.com](https://start.boldvoice.com)，手机上的账号在网页端同样可用，适合想在大屏前跟视频课的场景。

## 五、安装与启动类问题

- **安装包点开没反应或报解析错误**：多为下载不完整，重新获取安装包并核对 MD5（`A4E965B919BC2F10F9619702EC7DEF3C`）后再装，完整流程见 [下载与安装教程.md](下载与安装教程.md)。
- **首次启动卡在引导问卷**：问卷需要联网完成，确认网络可用后重进；实在过不去就清应用数据重走一遍引导。
- **AI 对话场景没有声音回复**：检查媒体音量（不是铃声音量）与系统「勿扰模式」，对话应用的语音播放走媒体通道。
