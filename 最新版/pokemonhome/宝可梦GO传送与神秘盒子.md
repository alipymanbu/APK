## 一、传送前要满足的两个前提

1. **GO 里绑定了 Nintendo 账号**：在 GO 的地图界面点精灵球 → 设置 → 「已连接的设备和服务」→ Pokémon HOME，用你 Pokémon HOME 绑定的那个 Nintendo 账号登录（绑定细节见[账号绑定与登录问题](账号绑定与登录问题.md)第四节）；
2. **手机版 Pokémon HOME 的新手教程已完成**：教程没走完，传送过来的宝可梦没法正常接收。还没装手机版的话，从[下载与安装教程](下载与安装教程.md)开始。

## 二、传送步骤与 GO 传送器能量

1. 在 GO 的设置里进入 Pokémon HOME 分区，点「传送宝可梦」（Send Pokémon），打开 GO 传送器；
2. 传送器靠 **GO 传送器能量**工作，每只宝可梦消耗不同——选中的时候界面会显示需要多少；
3. 能量随时间自动恢复；第一次使用时传送器是满的，急用可以在 GO 里花 PokéCoin 立即充满；
4. 选好宝可梦，确认列表后点「传送」；
5. 传完**必须打开手机版 Pokémon HOME 手动接收**，宝可梦才会落进盒子——不接收它会一直挂着。

省能量的一条经验：越稀有的宝可梦消耗越大，社区普遍反馈传说宝可梦（尤其异色的）能量消耗特别高。只是想凑数换神秘盒子的话，送普通常见的就行，别拿稀有货当燃料。这条是社区经验，官方只说明了「消耗取决于宝可梦本身」。

## 三、送不出去的宝可梦

下面这些在 GO 传送器的选择界面里根本不会出现，官方口径如下：

| 类型 | 说明 |
| --- | --- |
| 晃晃斑（Spinda） | 整个种类不能传 |
| 收藏（最喜爱）的 | 先取消收藏再试 |
| 搭档宝可梦 | 先换搭档 |
| 正在防守道馆的 | 先撤回 |
| 穿装扮的 | 活动装扮类一律不能传 |
| 暗影宝可梦 | 暗影状态不能传；净化后的可以传（净化状态到 HOME 后会消失） |
| 超级进化状态 | 先取消超级进化 |
| 极巨化（含超极巨化） | 不能传 |
| 特殊精灵球捕获的 | 如 GO 狩猎球（GO Safari Ball）捕获的不能传 |

另外两种「传得过去但会变」的情况：**幸运**和**净化**状态传到 HOME 后会消失；用的是普通精灵球的就按普通传送。

## 四、传送途中的形态变化

部分宝可梦在传送到 HOME 的路上会变成指定形态，官方确认页会提前标注，这不是故障：

| 原形态（GO） | 传到 HOME 后 |
| --- | --- |
| 骑拉帝纳·起源形态 | 骑拉帝纳·别种形态 |
| 樱花儿·晴天形态 | 樱花儿·阴天形态 |
| 飘浮泡泡（太阳/雨水/雪云样子） | 飘浮泡泡（普通样子） |

清单会随 GO 新增内容扩充，以后传送前看一眼确认页的提示最稳妥。

## 五、神秘盒子：传送附带的奖励

第一次把宝可梦传送到 Pokémon HOME 后，GO 会自动送你一个**神秘盒子**（Mystery Box）。打开盒子，美录坦（Meltan）会持续出现在你周围一段时间，抓它攒糖果、进化美录梅塔（需要 400 颗糖果）都靠这条路。

盒子的使用规则（官方口径）：

- **再次激活要同时满足两个条件**：距上次打开满 3 天，**并且**这期间又向 HOME（或 Let's Go 皮卡丘/伊布）传了一只宝可梦；
- **走不走都一样**：美录坦的出现频率与移动无关，站桩刷和边走边刷效率相同；
- **熏香和诱饵模块不影响**美录坦的出现；
- **异色美录坦**只在特定活动期间开放，平时开盒抓不到；部分活动还会缩短盒子的冷却时间。

两条社区经验，供参考：HOME 里还有宝可梦没收时，可能领不到新盒子——传完记得先去 HOME 点接收；开盒时间有限，提前备好蔓莓果和好的球再开。
