## 一、支持的游戏清单

与 Switch 游戏的互传只在 **Switch 版 Pokémon HOME** 里操作；手机版负责的是与 Pokémon GO 的传送、交换和领取神秘礼物。官方列出的兼容游戏：

| 平台 | 游戏 |
| --- | --- |
| Nintendo Switch | 宝可梦 朱 / 紫 |
| Nintendo Switch | 宝可梦传说 阿尔宙斯 |
| Nintendo Switch | 宝可梦 晶灿钻石 / 明亮珍珠 |
| Nintendo Switch | 宝可梦 剑 / 盾 |
| Nintendo Switch | 宝可梦 Let's Go 皮卡丘 / Let's Go 伊布 |
| iOS / Android | Pokémon GO |

清单会随新游戏发售而更新，兼容性以官方页面当时公布为准。部分宝可梦在特定游戏之间的传送有额外限制，传送前应用会提示。

## 二、传送方向的限制：有去不一定有回

把宝可梦传进 Pokémon HOME 不代表它还能传回原游戏——每个游戏的图鉴范围不同，HOME 里有的宝可梦，目标游戏不一定收。最典型的是 Pokémon GO 这条线：**从 GO 传到 HOME 的宝可梦不能回 GO**。

传送前的确认页会标明这只宝可梦能不能去目标游戏，确认页上看清再按。有些形态在传送途中会变（比如不同形态的宝可梦会回到普通形态），确认页同样有标注。

反方向（Switch 版 3.0.0 起）有个实用功能：把宝可梦从 HOME 传进联动游戏时，可以在它**学过的招式列表**里调整它携带的招式，不用回游戏里专门回忆；限定这些游戏里能学到的招式，个别招式除外。传回游戏前先把招式配好，到家就能直接用。

## 三、从 Pokémon GO 传送到 HOME

前提有两条：GO 里绑定 Nintendo 账号（步骤见[账号绑定与登录问题](账号绑定与登录问题.md)第四节），以及手机版 Pokémon HOME 的教程已完成。整体流程是：在 GO 的设置里选「已连接的设备和服务」→ Pokémon HOME → 传送宝可梦，消耗 GO 传送器能量把选中的送过来，最后**在手机版 Pokémon HOME 里手动接收**，宝可梦才会落进盒子。

两个最容易踩的坑：一是**这条线是单程**，送出去的宝可梦回不了 GO（见第二节）；二是**传完必须来 HOME 接收**，不接收它会一直挂着，后续的传送奖励也可能拿不到。

完整细节——传送器能量的恢复与补充、哪些宝可梦送不出去（暗影、极巨化、装扮、晃晃斑等）、传送途中的形态变化、第一次传送附赠的神秘盒子（美录坦）怎么玩——单独整理在[宝可梦GO传送与神秘盒子](宝可梦GO传送与神秘盒子.md)里。

## 四、从 Pokémon Bank 搬入（付费版）

Pokémon Bank 是 3DS 时代的云端寄放服务。把 Bank 里的宝可梦搬进 HOME 的功能**只对 Premium 会员开放**，免费版看不到这个入口。手里有 3DS 世代老存档、又想把宝可梦延续到 Switch 游戏里的话，这是官方唯一的通路，这也是不少人订阅 Premium 的直接原因（订阅对比见[会员价格与权益对比](会员价格与权益对比.md)）。

## 五、神秘礼物：在手机上领 Switch 游戏的奖励

手机版可以领神秘礼物，包括两类：

- **给 Pokémon HOME 自己的礼物**：比如完成特定图鉴后配信的闪光宝可梦，领到后直接放进 HOME 的盒子；
- **给 Switch 游戏的礼物**：在 HOME 里取得序列号或密码，再到对应的 Switch 游戏里输入领取。

领礼物的入口在手机版菜单里，跟着界面走即可；配信通常有截止时间，看到活动就尽快领。

## 六、HOME 点数：存宝可梦攒出来的积分

每往 HOME 的盒子里存一只宝可梦，都会积累 HOME 点数。在 **Switch 版**里可以把它换成游戏内点数：剑盾里换 BP（对战点数），朱紫里换 LP（联盟点数）。手机版看得到点数但兑换在 Switch 版做，这也是「两端绑同一账号」的实际收益之一。
