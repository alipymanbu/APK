# Thanox 智能冻结与后台清理教程

> 想让不常用的应用"冻住"或退后台就被清掉，Thanox 里有一组功能负责这件事：智能冻结、后台运行（锁屏清理与一键加速）、乖巧模式。本篇讲三者的分工、每个开关的作用和怎么选冻结方式。

## 一、三个功能各管什么

| 功能 | 触发时机 | 动作 |
| --- | --- | --- |
| 智能冻结 | 息屏时、应用被移出最近任务时 | 冻结你指定的应用 |
| 后台运行（锁屏清理） | 息屏后（可设延迟）、点首页"一键加速"时 | 强行停止不允许后台运行的应用 |
| 乖巧模式 | 检测到应用回到后台时 | 主动停止该应用的后台服务 |

三者可以叠加使用：智能冻结管"点名冻结的应用"，锁屏清理管"息屏后留着的进程"，乖巧模式管"退到后台就收敛服务"。

## 二、智能冻结怎么用

1. 打开智能冻结页面，点右上角的 + 号，把要冻结的应用加入列表——加入的瞬间就会执行一次冻结；
2. 列表里**黑白图标 = 当前处于冻结状态，彩色图标 = 当前解冻状态**，状态一眼可查；
3. 想用某个被冻结的应用时，直接点列表项启动，Thanox 会先解冻再打开它。

## 三、两种冻结方式怎么选

在设置里可以选冻结方式，两种的行为差别很大：

| | PM Disable | Suspend |
| --- | --- | --- |
| 原理 | Android 系统自带的"停用"应用能力 | Android 提供给设备管理的"挂起"能力 |
| 冻结后桌面图标 | 消失 | 保留灰色图标 |
| 直接点图标会怎样 | 应用已停用，无法启动 | 弹出"应用已被管理员限制使用"的对话框（系统行为） |
| 怎么再打开 | 只能从智能冻结页面、你创建的快捷方式或代理应用启动 | 配合"检测并解冻"（DOL）可自动解冻 |
| 官方定位 | 最常用的冻结方式 | 需要保留图标提示时用 |

选 PM Disable 就要有心理准备：冻结的应用会从桌面上消失，找不到入口的人会以为应用被卸载了；同时它也收不到推送消息，即时通讯类应用怎么取舍见[冻结后收不到通知怎么办](冻结后收不到通知怎么办.md)。

## 四、检测并解冻（DOL）

"检测并解冻"（官方简称 DOL）的意思是：Thanox 监测到"有启动这个应用的请求"时自动解冻它——你从桌面或其他应用里点开被冻结的应用，不用再手动去解冻。

设置里的"**自动打开活检解冻**"开关，就是给新加入智能冻结的应用自动开启 DOL，省得一个个去开。开着它，Suspend 方式冻结的应用点开就能自动解冻；PM Disable 方式的应用图标已消失，仍要从智能冻结页面或快捷方式进。

## 五、后台运行：锁屏清理与一键加速

1. 打开"后台运行"总开关；
2. 默认所有应用都允许后台运行（列表开关全开），**把某个应用的开关关掉，它就进入"锁屏清理 + 一键加速"的范围**；
3. 设置页两个实用选项：
   - **锁屏清理延时**：息屏后等一会儿再清理。延时期间你重新亮屏，本次清理就取消了，等下次息屏再重新安排——所以短暂息屏不会反复杀应用；
   - **不清理正在播放音频的应用**：避免听歌听一半被杀；
4. 首页的"**一键加速**"按钮：随时手动执行一次同样的清理，不等息屏。

## 六、乖巧模式

有些应用退到后台后，启动的服务会一直挂着跑。乖巧模式的机制是：**检测到应用回到后台，就主动停掉它启动的后台服务**。

官方在文档里给了明确的使用边界：

- 适合：不常用的、不依赖后台服务的应用；
- 慎用：依赖后台服务才能正常工作的社交类应用——消息收不到、推送断掉多半是把它加进了乖巧模式。

乖巧模式和后台启动是联动的：开了乖巧模式的应用，它的后台启动请求会被以 `BLOCKED_STANDBY` 的原因拦掉，查启动记录时别把这个当成"后台启动开关"误关了（原因代码对照见[后台启动拦截教程](后台启动拦截教程.md)）。
