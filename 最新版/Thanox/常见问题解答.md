## 一、安装与激活类

### 装完 APK，功能全是灰的 / 没反应？

正常现象。Thanox 要激活后才生效，先按[激活教程](激活教程.md)走完 Xposed 或 Magisk 流程再回来看。排查顺序：框架本身是否激活 → 作用域是否勾了"Android 系统" → 是否重启过。

### 更新后提示未激活 / 功能失效？

最常见的原因是更新后没有重做激活动作：

- Xposed 模式：去 Xposed 管理器重新勾选 Thanox 模块并重启；
- Magisk 模式：重新导出补丁（或用新 APK 改名 `.zip`）并刷入。

有用户反馈过另一种情况：限制了 Xposed 管理器的广播权限，导致更新后模块识别失败——不要限制它的广播权限，或每次更新后手动重新勾选。

### 更新前要做什么准备？

官方在应用描述里的建议：更新前先做好设备无法开机的准备（备份）。这类打补丁的工具更新出问题时，能回滚比什么都重要。

### 能不能和"应用管理"（X-APM）一起用？

官方答复：不能。

### 没有 Root 能用吗？

能，走 Shizuku 路线：先启动 Shizuku，再在 Thanox 里切到 Shizuku 模式。这条路线功能比 Xposed 模式少，步骤见[无Root激活教程](无Root激活教程.md)。

### 更新后卡在开机进不去系统怎么办？

从框架侧回滚：Magisk 与 Xposed 类框架都有模块开关或安全模式入口，临时停用 Thanox 的模块或补丁即可回到系统。这也是官方建议更新前先做备份的原因。

## 二、运行与功能类

### Thanox 需要保活或自启动吗？

官方答复：只有在情景模式里使用了 `su` 命令时，才需要允许 Thanox 后台启动（MIUI 等系统要进自带的安全管家里允许自启动）；除此之外**不需要保活、不需要自启动**。

### 清除 Thanox 的应用数据，配置会丢吗？

不会丢功能配置。官方说明：各功能的数据存放在系统目录（`/data/system/thanos` 加一串随机字符），系统设置里的"清除数据"只清掉应用层的界面配置。

### 拦了后台启动之后，某个应用反而不好用了？

大概率拦到了它依赖的组件。官方例子：拦截 HMS Core 的后台启动会导致华为运动健康无法正常登录。去后台启动功能的启动记录里看原因代码定位，需要放行就加一条 `ALLOW` 规则，对照表见[后台启动拦截教程](后台启动拦截教程.md)。

### 智能冻结的应用想临时用一下怎么办？

直接点智能冻结列表里的应用，Thanox 会先解冻再启动；或给应用开启"检测并解冻"（DOL），从任何入口点开都自动解冻。操作细节见[智能冻结与后台清理](智能冻结与后台清理.md)。

### 为什么 Magisk 模式下功能比别人的少？

官方自己标注 Magisk 模式是实验性、功能相对较少。要功能全就换 Xposed 模式（需要 LSPosed 之类的框架）。

### 冻结应用后收不到消息通知？

机制如此：被停用或强停的应用收不到推送，不是故障。每种冻结方式的影响与取舍见[冻结后收不到通知怎么办](冻结后收不到通知怎么办.md)。

## 三、版本与获取类

### 网盘里这份和官方最新版是同一个版本吗？

不一定。官方渠道更新较快，本文各篇提到的版本号、包名、安装包大小，都以本文配套的这份安装包（v8.9）为准；想看最新版本去官方渠道（酷安、GitHub、Google Play），以官方页面当时显示为准。

### 还有别的问题去哪问？

官方在 GitHub 仓库（[github.com/Tornaco/Thanox](https://github.com/Tornaco/Thanox)）和 Telegram 频道接受反馈；功能层面的排查也可以先翻[下载与安装教程](下载与安装教程.md)和[隐私与权限管控](隐私与权限管控.md)里对应的章节。
