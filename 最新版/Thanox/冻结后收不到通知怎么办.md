# Thanox 冻结后收不到通知怎么办

> 冻结或清理了某个应用之后，它的消息推送也跟着没了——这不是故障，是机制如此。本篇讲为什么、每种冻结方式对推送的影响、即时通讯类应用怎么取舍、以及冻结之外还有什么会拦推送。

## 一、为什么冻结会断推送

消息推送到达的前提是应用在后台活着。被停用（PM Disable）的应用整个处于关闭状态，推送服务自然也停了——这和系统"强制停止"一个应用后推送中断是同一个道理，属于 Android 系统行为，不是 Thanox 出了问题。

## 二、各功能对推送的影响

| 你的操作 | 推送会怎样 |
| --- | --- |
| 智能冻结（PM Disable） | 收不到：应用被停用，冻结期间完全离线 |
| 智能冻结（Suspend） | 大概率收不到：页面被挂起、后台被限制（以实际表现为准） |
| 后台运行（该应用开关默认开着） | 不清理它，推送不受影响 |
| 后台运行（把该应用开关关了） | 息屏清理后被强停，到下次打开前的消息会漏 |
| 乖巧模式 | 退后台就停服务，接收推送的服务也在内；官方明确建议社交类应用别开 |
| 后台启动（开关关了或规则拦了） | 可能拦掉推送相关的拉起请求，去启动记录确认 |

## 三、怎么取舍

- **即时通讯类（微信、QQ 这类）**：官方对乖巧模式给过明确边界——别用于依赖后台服务的社交类应用；智能冻结同理，慎加。真要约束它，用"后台运行"保持默认放行，或只拦它的关联启动；
- **消息不重要的应用**：随便冻。PM Disable 冻结后图标会消失，想用时从智能冻结页面进；
- **折中方案**：Suspend + 检测并解冻（DOL），点开图标就自动解冻——但冻结期间推送依然是断的，接受这一点再冻；
- **临时要用**：直接点智能冻结列表里的应用，Thanox 会先解冻再启动。

## 四、冻结之外的原因排查

收不到消息不一定是冻结造成的：

- **后台启动拦了推送进程**：去后台启动功能的启动记录里看有没有针对它的 `BLOCKED` 记录，原因代码对照见[后台启动拦截教程](后台启动拦截教程.md)，确认后加一条 `ALLOW` 规则放行；
- **系统侧的省电策略**：电池优化、省流量模式同样会延迟或吞掉推送——这类问题在 Thanox 之外，去系统设置里给应用放开后台运行与联网权限。
