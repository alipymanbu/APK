# Thanox 无 Root 激活教程

> 没有 Root、也没装框架？Thanox 还有一条 Shizuku 路线可以激活"精简版"。本篇讲三种激活方式对 Root 的要求、Shizuku 怎么启动、Thanox 里怎么切、这条路的功能边界在哪。

## 一、先分清三条路要不要 Root

| 激活方式 | 需要 Root 吗 | 说明 |
| --- | --- | --- |
| Xposed 模式 | 通常需要 | LSPosed 这类框架一般以 Magisk 模块形式安装，属于 root 环境 |
| Magisk 模式 | 需要 | Magisk 本身就是 root 管理方案 |
| Shizuku 模式 | 不需要 | Shizuku 的官方定位就是免 root 使用系统能力 |

所以"没 Root 能不能用 Thanox"的答案是：能用，走 Shizuku。但多位第三方资料与官方更新日志的口径一致——这条路线的功能比 Xposed 模式少，属于精简版。

## 二、先把 Shizuku 跑起来

Shizuku 是一个独立应用，先安装并启动它。Shizuku 官方手册给出三种启动方式：

| 方式 | 条件 | 特点 |
| --- | --- | --- |
| 通过 root 启动 | 已 root | 最省事 |
| 通过无线调试启动 | Android 11+ | 无需电脑；先"配对"一次；每次重启后要重新启动 Shizuku |
| 通过连接电脑启动 | 未 root 的 Android 10 及以下 | 需要电脑上的 adb 环境；每次重启后同样要重来 |

无线调试的配对流程：开发者选项里开启 USB 调试与无线调试 → 在 Shizuku 里点配对 → 系统弹窗"使用配对码配对设备" → 把配对码填进 Shizuku 的通知 → 回到 Shizuku 点启动。

要点：**免 root 时 Shizuku 不是开机常驻的**，手机每次重启后要重新执行启动步骤，Thanox 的功能在这期间不可用。

## 三、在 Thanox 里切到 Shizuku 模式

- 官方更新日志确认过 Shizuku 支持（5.1.2 版本起提及"Shizuku 版本新特性"）；本文配套的 v8.9 晚于该版本，应用内是否有入口以实际界面为准；
- 有第三方资料提到入口的进法：在 Thanox 设置里**连续点击"核心信息"一类的条目**，会切出模式选择，选 Shizuku 模式；
- 切换时 Shizuku 会弹窗询问是否允许 Thanox 使用，选允许，然后按应用内提示完成激活。

这一步的界面细节各版本差异较大，上面仅供参考，以你手上的版本实际显示为准。

## 四、Shizuku 模式的边界

- **功能少**：多位第三方资料一致反映 Shizuku 模式功能少于 Xposed 模式，具体哪些功能可用以应用内显示为准；
- **隐匿做不了**：隐匿依赖 Xposed 作用域（见[隐私与权限管控](隐私与权限管控.md)），Shizuku 路线下用不了；
- **重启要重连**：免 root 的 Shizuku 重启后要手动再启动，别以为是 Thanox 坏了。

## 五、Magisk 补丁方式还要不要考虑

把两边口径并列放在这里：官方文档目前仍把 Magisk 模式列为可用激活方式（Android 11+，实验性，功能相对较少）；也有第三方资料提到"Magisk 补丁激活当前不维护"。如果你已经在用 Magisk，可以按[激活教程](激活教程.md)试；遇到问题再换 Xposed 或 Shizuku 路线。
