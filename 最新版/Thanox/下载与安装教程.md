## 一、这是什么，适合谁用

Thanox 由开发者 Tornaco 开发（同一作者还有 ShortX），定位是系统与应用管理工具，功能集中在三块：

- **后台管控**：后台启动拦截（关联启动）、后台运行清理、智能冻结、乖巧模式；
- **隐私管控**：隐匿（对指定应用隐藏 SIM 卡、序列号等信息）、打开其他应用管控、应用锁；
- **自动化与改跳转**：情景模式（条件 + 动作的规则引擎）、移花接木（替换应用内页面跳转）。

它的大部分功能不是跑在普通应用里，而是要在系统进程里完成（见[激活教程](激活教程.md)），所以装机门槛比一般工具高：设备上需要有 Xposed 框架、Magisk 或 Shizuku 这类环境，并且你要接受"更新后可能要重新勾选模块、重新刷补丁"这类维护动作。官方在应用描述里明确提示过：不推荐新手盲目使用，更新前建议先做好备份。

## 三、系统要求

- **系统版本**：Android 6.0 及以上。官方文档给出的版本对应关系如下（以官方页面当时的说明为准）：

| Android 版本 | 对应 Thanox 版本线 |
| --- | --- |
| 6.0 - 11 | 2.x |
| 12 | 3.x 起 |
| 13 | 4.x 起 |
| 14 / 15 | 5.x 起 |
| 16 | 6.x 起 |

- **ROM 兼容**：官方说明基于 AOSP 开发，类原生系统理论上都兼容，大部分国产 ROM 也可以。实际是否正常要看你的机型与 ROM 组合，个别厂商系统（如 MIUI 类）对自启动、后台权限有额外限制，碰到问题先去系统自带的管家类应用里放行 Thanox。
- **环境要求**：想真正用上功能，还需要 Xposed 框架（如 LSPosed）、Magisk 或 Shizuku 之一，具体差别见[激活教程](激活教程.md)。

## 四、安装步骤

1. 从上面的网盘资源或其他渠道拿到 APK 文件（本文配套为 v8.9，约 20.36M）；
2. 在文件管理器里点开 APK，系统会提示"未知来源应用"，允许本次安装来源后继续；
3. 等待安装完成，打开 Thanox；
4. 首次打开后你会看到功能都处于未激活状态——这是正常的，装完 APK 只完成了第一步，还需要按[激活教程](激活教程.md)操作后，各功能才真正生效。

## 五、更新时的注意事项

更新 Thanox 与更新普通应用不一样，两条官方明确要求的动作要记住：

- **Xposed 模式**：每次更新 Thanox 后，都要重新去 Xposed 管理器里勾选 Thanox 模块并重启设备，否则功能会失效；
- **Magisk 模式**：每次更新 Thanox 应用后，都要同步重新导出并刷入新的 Magisk 补丁。

另外官方在应用描述里建议：更新前先做好设备无法开机的心理与备份准备。万一更新后出问题，排查思路见[常见问题解答](常见问题解答.md)。
