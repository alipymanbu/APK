# Thanox 移花接木教程

> 移花接木是 Thanox 里比较特别的功能：配置应用内页面之间的跳转，把"本来要去页面 B"替换成"直接去页面 C"。本篇讲它能干什么、怎么拿到页面标识、怎么配置。

## 一、它能干什么

Android 里一个页面通常就是一个 Activity（活动）。应用内的跳转链是固定的，比如启动顺序 A → B → C；如果你不想看到中间页 B，移花接木可以把"启动 B"的请求替换成"启动 C"，让你直接从 A 跳到 C。典型用途就是跳过某些应用一进来的中转页、引导页。

## 二、先认识页面标识

配置前要先会说"哪个页面"。每个活动页都有一个标识，格式类似网站的 URL 路径：

```java
"包名/活动名"
```

例如微信首页的标识是：

```java
"com.tencent.mm/com.tencent.mm.LauncherUI"
```

一条移花接木配置，本质就是把"页面 B 的标识"换成"页面 C 的标识"，所以你只需要拿到这两个字符串。

## 三、怎么拿到页面标识

Thanox 自带了查看工具，不用装别的东西：

1. 打开 Thanox 的 设置 → 开发者 → **显示当前活动**；
2. 开启后，你在手机上打开任何应用的任何页面，屏幕上都会以浮窗显示它当前的活动标识；
3. 点击浮窗即可复制这个标识。

操作顺序：先开浮窗 → 依次打开目标应用的 B 页面和 C 页面，各复制一次标识 → 回到移花接木功能，新增一条配置，把 B 的标识填为"原页面"、C 的标识填为"目标页面"。

## 四、配置后要注意什么

- 应用更新后活动页的名字可能变化，原有的替换会失效——重新用"显示当前活动"确认一遍标识即可；
- 替换只影响页面跳转本身；如果你发现配置后行为怪异（比如页面白屏、返回键异常），先删掉这条配置验证是不是替换目标不合适；
- "显示当前活动"这个开发者功能在写[情景模式入门教程](情景模式入门教程.md)里的 `activityResumed` 条件时同样用得上，可以留着不关。
