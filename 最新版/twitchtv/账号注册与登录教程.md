## 一、哪些功能需要账号

Twitch 不登录也能看：打开 App 就能浏览和观看直播，观众数里也包含未登录的观众。账号卡住的是「参与」这一层，下面这些动作都需要先登录：

- 发聊天、发悄悄话（私信）
- 关注频道、接收开播推送
- 攒频道点数并兑换奖励
- 订阅频道、送 Bits
- 领取掉宝活动的游戏内奖励
- 自己开播

账号免费注册；上面这些功能里只有订阅和 Bits 属于自愿付费，其余都不花钱。

## 二、注册账号

注册有两个入口，最终是同一个账号：

- **App 内注册**：打开 App，在登录页选「注册」。手机端默认以手机号为主，也可以切换成用邮箱注册。
- **网页注册**：打开 [twitch.tv/signup](https://www.twitch.tv/signup)，以邮箱为主要联系方式。

注册时按页面提示填写这几项：

1. **用户名**：4~25 个字符，只能用字母、数字、下划线。登录用户名注册后一般不支持修改，起名前想好；「显示名称」则是随时可以改的。
2. **密码**：至少 8 位；混入大小写字母、数字和符号（如 `@ # $ %`）更容易通过强度检查。
3. **出生日期**：按真实情况填，年龄不达标的部分功能会受限。
4. **人机验证**：按页面提示完成。

注册完成后，Twitch 会从 `noreply@twitch.tv` 发一封验证邮件到你填的邮箱。**这封邮件务必点开确认**：邮箱没验证之前，你没法改密码、也没法开启两步验证，账号出问题时会多不少麻烦。

## 三、开启两步验证（2FA）

两步验证开启后，新设备登录除了密码还要输入动态验证码，账号被盗的风险会小很多。另外它是开播的硬性前提：不开两步验证，开播功能会被直接挡住（打算用手机开播的话，这步绕不开，见 [手机开播教程.md](手机开播教程.md)）。

设置路径（网页与 App 大同小异，具体名称以你实际看到的为准）：

1. 进入 **设置 → 安全与隐私**。
2. 选择「设置两步验证」。
3. 先绑定手机号并完成短信验证（流程要求先验手机）。
4. 再绑定验证器应用：Google Authenticator、Microsoft Authenticator、Authy 等都支持。用验证器扫描二维码，输入 App 上显示的 6 位数字完成绑定。
5. **保存恢复码**：Twitch 会给一组一次性恢复码，务必存到可靠的地方。手机丢失、验证器重装时，这组码就是找回账号的钥匙。

## 四、验证码收不到怎么办

注册验证短信、两步验证的短信码都走运营商短信通道，而短信本身是「尽力而为」的投递，偶尔丢一两条很常见。收不到时按下面的顺序处理：

1. **先等几分钟，不要连续重发**：短时间内反复触发验证，可能被官方限流 —— 被限流后按官方说法要**等几天**才能再收，得不偿失。
2. **查手机侧**：确认信号正常、勿扰模式没开；把运营商网络选择改成「自动」（手动选网容易漏短信）；开关一次飞行模式刷新网络连接。
3. **核对号码格式**：填手机号用国际格式（如 `+86` 加 11 位号码），去掉空格与横线，格式不对是收不到的常见原因之一。
4. **根治办法：改用验证器 App**：两步验证绑定验证器应用（Google Authenticator、Microsoft Authenticator、Authy 等）后，动态码在本地生成，完全不依赖短信，短信通道的丢件、延迟、限流问题一并消失。已经在某个设备上登录着账号的话，随时可以到安全设置里补绑。
5. **彻底进不去账号**：以上都无效时，走官方帮助中心 [help.twitch.tv](https://help.twitch.tv) 联系支持，说明「收不到验证码」，必要时由支持重置两步验证设置。

## 五、登录与设备验证

- **新设备或新网络环境登录**时，Twitch 可能要求额外验证（比如邮箱验证码），这是正常的安全机制，按提示走完即可。
- **手机 App 登录**直接输账号密码（开了两步验证就再输动态码），不需要任何「设备激活码」。
- **智能电视、游戏主机**上的 Twitch 应用才走激活码流程：电视端显示激活码，再到 [twitch.tv/activate](https://www.twitch.tv/activate) 输码绑定账号。激活码几分钟就过期，过期了刷新出新码再输一次。

## 六、登录常见问题

| 问题 | 处理思路 |
| --- | --- |
| 收不到验证邮件 | 翻垃圾箱；搜发件人 `noreply@twitch.tv`；确认邮箱没填错，等几分钟再触发一次 |
| 两步验证码总不对 | 把手机时间改成「自动获取网络时间」再试；进不去就用恢复码 |
| 忘记用户名 | 在登录页用注册邮箱或手机号找回 |
| 忘记密码 | 走「忘记密码」重置，重置邮件发到已验证的邮箱 |
| 注册时提示密码不合格 | 补足 8 位并混入大小写、数字、符号，避开常见单词 |
