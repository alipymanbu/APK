## 一、先核对这份安装包的信息

动手装之前，先确认你拿到的是不是官方客户端、是哪个版本，免得装完才发现不对。本文涉及版本号、包名、体积的地方，一律以下面这份包为准：

| 项目 | 信息 |
| --- | --- |
| 应用名称 | Twitch（官方安卓客户端） |
| 包名 | `tv.twitch.android.app` |
| 版本 | 14.4.0_BETA（测试版） |
| 体积 | 121.38M |
| MD5 | `B3624495A88816AAE07FD8F41B646316` |
| 系统要求 | 安卓 5.2 及以上（安装包标注） |

几点说明：

- 包名 `tv.twitch.android.app` 是 Twitch 官方安卓客户端的固定包名，看到它就说明这份包出自官方应用本体。
- 版本号末尾的 `_BETA` 表示这是测试版构建：核心功能与正式版一致，个别功能可能不稳定。
- 应用商店里的最新版可能比这份更新，差多少以 [Google Play 的 Twitch 页面](https://play.google.com/store/apps/details?id=tv.twitch.android.app) 当时显示为准。
- 想核对下载到的文件是否完整，可以在电脑上对 APK 算一次 MD5，与上表的 `B3624495A88816AAE07FD8F41B646316` 比对，一致说明文件没坏。

## 二、从网盘拿到安装包

安装包通过夸克网盘分享，全程三步：

1. 打开 **[twitchtv 安装文件资源（夸克网盘）](https://pan.quark.cn/s/12abb7093c38)**。
2. 按页面提示把文件**转存到自己的夸克网盘**（分享文件需要先转存，才能在自己的网盘里操作）。
3. 在自己网盘里把 APK 下载到手机存储，完成后进入下一步。

手机上没装夸克网盘的话，先去应用商店搜「夸克」装一个；浏览器打开分享页也能转存和下载，只是 App 内操作更省事。

## 三、安装步骤

1. 用文件管理器找到刚下载的 `.apk` 文件（通常在 `Download` 目录），点按安装。
2. 如果系统提示「禁止安装未知来源应用」，按提示跳到系统设置，允许文件管理器（或浏览器）安装应用，再返回继续装。
3. 等待安装完成，点「打开」直接进入。

两个容易踩的点：

- 安装包有 120M 左右，安装前确认手机剩余存储充足，太满会装到一半失败。
- **如果手机上已经装了更高版本的 Twitch**，直接装这份 14.4.0 版本会被安卓系统拒绝（不允许「降级覆盖安装」），需要先卸载已装版本再装这份。

## 四、首次启动

1. 打开 App 后它会先联网加载内容，第一次进入可能要等几秒。
2. 界面语言跟随系统语言；登录入口在首次打开的引导页或侧边栏里。看直播、发聊天、关注频道、领奖励都需要登录账号，注册与登录的完整流程写在 [账号注册与登录教程.md](账号注册与登录教程.md)。
3. 不注册也能浏览和观看直播，但聊天、关注、订阅、掉宝这些「参与」性质的功能都用不了。

## 五、装不上时的排查

| 现象 | 常见原因与处理 |
| --- | --- |
| 解析包错误 | 下载不完整（重新下载一遍再装）；或手机系统版本低于安装包要求 |
| 安装到一半失败 | 存储空间不足，清理出足够空间后重试 |
| 提示「应用未安装」 | 手机里已有同包名的其他版本（尤其是更高版本），先卸载旧的再装 |
| 装好打不开、一直转圈 | 先确认网络能否正常访问 Twitch 服务，再按 [常见问题与卡顿排查.md](常见问题与卡顿排查.md) 逐条排查 |
