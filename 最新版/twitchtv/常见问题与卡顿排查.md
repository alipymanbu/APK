## 一、直播卡顿、一直缓冲

按顺序试：

1. **把清晰度调低**：直播间设置里把画质从「源」降到 720p 或 480p，这是见效最快的一招。
2. **换网络**：Wi-Fi 与移动数据互切，排除当前网络拥堵；Wi-Fi 信号弱就离路由器近一点。
3. **关掉画中画与后台应用**：后台挂太多应用时手机解码压力大，直播容易卡。
4. **确认能连上 Twitch 服务**：如果整个 App 首页都刷不出内容、所有直播都打不开，就不是单一直播间的问题了 —— Twitch 的服务器在部分地区的可访问性并不稳定，先确认当前网络环境能否正常访问 Twitch 服务，再考虑下一步。

## 二、收不到开播通知

通知走两层开关，缺一不可：

1. **App 内**：设置 → 通知，确认开播通知开着，且对应频道的通知没被关掉（关注频道时可以单独选「全部 / 部分 / 不提醒」）。
2. **系统侧**：手机系统设置里允许 Twitch 显示通知；国产安卓还要把省电策略改成允许后台运行，否则 App 进程被杀，推送收不到。

## 三、App 闪退、打不开

1. 先完全退出 App（从后台任务里划掉）再重新打开。
2. 清缓存：系统设置 → 应用管理 → Twitch → 清除缓存。别急着「清除数据」，那会退出登录。
3. 还不行就卸载重装。关注与订阅关系都存在账号里，重新登录不会丢。
4. 安装包本身损坏也会导致闪退，可以对照 [下载与安装教程.md](下载与安装教程.md) 里的 MD5 核对文件完整性，确认无误再重装。

## 四、聊天发不了

| 现象 | 原因与处理 |
| --- | --- |
| 输入框是灰的、点不了 | 没登录，或该频道开了「仅订阅者可聊天」 |
| 提示账号太新不能发言 | 部分频道限制新注册账号发言，先看一会儿，过几天再试 |
| 提示需要验证手机 | 个别频道开启「验证手机才能聊天」，去账号设置绑定手机号后回来 |
| 发出去立刻消失 | 被频道的机器人或房管删除，检查是否触犯该频道的聊天规则 |

## 五、账号与登录问题

登录、两步验证、邮箱验证相关的问题集中在 [账号注册与登录教程.md](账号注册与登录教程.md)，那里有逐条处理表。简版结论：收不到验证邮件先翻垃圾箱并搜发件人 `noreply@twitch.tv`；两步验证进不去用恢复码；新设备登录触发额外验证是正常安全流程，不用慌。

## 六、其他小问题

- **首页推荐流自动播放还带声音**：设置里可以关掉自动播放；流上也有静音按钮。
- **界面是英文想换中文**：App 界面语言跟随系统语言，把系统语言调到中文（或版本内提供的语言设置，视版本而定）即可；部分界面元素可能没有完整汉化。
- **订阅了还能看到广告**：无广告是「你订阅的那个频道」内无广告，不是全站去广告，别搞混范围。
- **想看的游戏找不到分类**：在「浏览」页用搜索直达游戏名，小众游戏分类不一定出现在首页推荐里。
- **自己开播总是卡**：开播端的卡顿是上行推流问题，与观看端思路不同，见 [手机开播教程.md](手机开播教程.md)。
- **付费相关的疑问**（订阅扣费、Bits 到账、退款）：先看 [订阅与打赏支持主播教程.md](订阅与打赏支持主播教程.md) 的说明，再对照官方条款。

上面都解决不了的问题，去官方帮助中心 [help.twitch.tv](https://help.twitch.tv) 按关键词搜具体报错，能对上大多数场景。
