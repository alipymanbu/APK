# K2er 激活步骤详解

> 激活是 K2er 用起来的第一道坎：没激活，映射不会生效。本篇把无线激活、电脑激活两条路都讲清，华为、荣耀等机型的特殊处理也单列出来。

## 一、为什么需要激活

K2er 要替你「按」屏幕上那个位置，也就是模拟触控，这个权限安卓不会直接给普通应用。所以首次打开 K2er 会停在激活引导页，激活的本质是借一次系统的开发者调试授权，让 K2er 拿到模拟触控的能力。激活只在装机时做一次，不是每次玩之前都要重来；但**USB 调试开关之后不能关**，关了激活会自动失效。

官方文档站把激活相关的问题单独放在 `https://doc.k2er.com/activation.html`，本篇内容与它口径一致。

## 二、先选路：你的机型走哪条激活路

| 你的情况 | 推荐方式 |
| --- | --- |
| Android 11 及以上的一般机型 | 无线激活（不用电脑、不用数据线） |
| 华为机型（无无线调试功能） | 电脑激活 |
| 荣耀机型（Android 12 才有无线调试） | Android 12 走无线激活；更早版本走电脑激活 |
| Android 11 以下的机型 | 电脑激活 |
| 已 Root 的设备 | Root 自动激活，按应用内提示操作 |

## 三、无线激活（Android 11 及以上）

前提：手机和路由器在同一局域网（激活过程要走一次本地网络，不耗流量；激活完成后 Wi-Fi 就不再必需）。

1. 打开手机的**开发者选项**（设置 → 关于手机 → 连点「版本号」7 次解锁）。
2. 在开发者选项里打开 **USB 调试**和**无线调试**。
3. 回到 K2er 的激活引导页，按提示进入配对流程。
4. 系统弹出**配对码**时注意：**不能离开无线调试界面去输码**——最小化后配对码会过期，必然配对失败。两个不离开的办法：
   - 用 K2er 的**悬浮窗**输入配对码；
   - 用**分屏**，一半无线调试、一半输码界面。
5. 引导里若有一项「允许显示设置悬浮层」你的机型上找不到，标记完成跳过，最后一步改用分屏配对（荣耀机型普遍如此）。
6. 配对码输入正确后等待激活完成。

卡住的两种典型情况（对应官方 FAQ）：

- **卡在 2/3**：进无线调试，删掉底部所有「已配对设备」，再到 USB 调试下点「撤销 USB 调试授权」，重启手机重来。
- **卡在 3/3**：卸载 K2er，重启手机后重装；还是不行且系统是 Android 11 的话，升级系统版本往往能解决。

## 四、电脑激活（华为、荣耀及 Android 11 以下）

1. 在电脑上下载 K2er 桌面端激活工具，入口在官网的电脑版页面 `https://k2er.wasd.plus/pc/`。这个桌面端除了激活，还能把电脑键鼠桥接给手机、把手机画面投到电脑，功能全貌见 [电脑版与投屏玩法](电脑版与投屏玩法.md)。
2. 手机端在激活界面底部选「使用电脑激活」。
3. 用**支持数据传输**的数据线连接手机与电脑（多数原装线都可以）。
4. 电脑需要装好对应品牌的 Android USB 驱动。驱动、线都没问题仍连不上时，多半是软件冲突：拔线、重启电脑、关掉其他手机助手类软件再连。
5. 按电脑端与手机端的提示完成激活。

**华为机型专属**：电脑端检测不到设备时，先在电脑装华为手机助手 HiSuite（`https://consumer.huawei.com/cn/support/hisuite/`），连上一次后**关闭助手**，再打开 K2er 桌面端；仍不行就电脑手机都重启。

**荣耀机型专属**：同理先装荣耀套件（`https://www.hihonor.com/cn/support/suite/`），连一次后关闭，再开 K2er 桌面端。

**华为/荣耀电脑激活后拔线掉激活**：官方给了几层补救，按顺序试——

1. 开发者选项里开启「仅充电模式下允许 ADB 调试」，之后用「仅充电」模式连线、拔线；
2. 改用 USB 的 MIDI 模式连接后拔线；
3. 关掉手机 Wi-Fi 再试；
4. 兜底：拔线后激活会丢，此时在 K2er 主界面点「立即激活」，等 30 秒看能否自动激活。

华为与荣耀在激活这件事上步骤最绕，官方原话是「请耐心多试几次」。

## 五、激活之后的维护

- **USB 调试保持开启**：这是激活有效的条件，关掉即失效，重开也不会自动恢复，要重新走一遍激活。
- **无线调试可以关**：激活完成后就不再需要，关掉不影响使用。
- **升级系统或重置手机后**：激活可能失效，重新跑一遍对应流程即可。
- **命令行激活**：需要先激活一个命令行工具（如 Brevent），再用它去激活 K2er，属于进阶玩法，普通用户不必走这条路。

激活完成后接着做的事：连外设看 [设备连接与外设支持](设备连接与外设支持.md)，配第一套键位看 [按键映射设置入门](按键映射设置入门.md)。
