## 一、游戏里看不到悬浮窗

按顺序核对：

1. 这个游戏加进 K2er 了吗？没加的界面不会出现悬浮窗；
2. 手机的「游戏模式 / 游戏空间」把游戏拦了：把游戏从系统游戏列表里移出去；
3. 拿一个非游戏应用加进 K2er 验证——非游戏能弹悬浮窗，问题就锁定在游戏模式上。

## 二、玩着玩着悬浮窗消失

这是 K2er 被 Android 从后台清掉了，官方给的保后台清单，逐项开启：

1. 给 K2er **通知权限**；
2. 在最近任务列表里把 K2er **锁定**；
3. 电池优化白名单里把 K2er 设为「无限制」；
4. 允许后台持续运行；
5. 允许自启动；
6. 游戏从系统「游戏模式 / 游戏空间」列表移除——游戏加速类功能会把后台的 K2er 当成优先清理对象；
7. 个别机型的游戏加速开关（如红魔的 Turbo 模式）在游戏内也会生效，关掉。

## 三、按键全都没反应（含鼠标）

1. **小米 / 红米 / 黑鲨 / POCO**：开发者选项里还有一个独立开关「**USB 调试（安全设置）**」，必须打开才能模拟触控，开完重启手机。这是这几款机型上最常见的原因；
2. K2er 手机端设置里点「重启激活服务」再试；
3. 重启手机；
4. 以上都无效，检查游戏是否在系统游戏模式里，移出去再试。

激活本身失效或想确认激活状态，流程与补救在 [激活步骤详解](激活步骤详解.md)。

## 四、个别按键或摇杆行为不对

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 右摇杆一动视角就往单方向漂 | 摇杆硬件中心值偏移 | 右摇杆详细设置里把**死区**调大 |
| 手柄像鼠标一样动指针 | 手柄处于鼠标模拟模式 | 切到 Android HID / Xbox PC / PS / NS 模式（见 [设备连接与外设支持](设备连接与外设支持.md)） |
| PS5 触控板不能当鼠标用 | K2er 接管了触控板 | 设备管理里取消勾选「DualSense Touchpad」 |
| 录快捷键时按键无反应 | 设备层或模式问题 | 桌面先验证输入 → 查设备管理 → 切模式 → 重启 |
| 单个映射点按了没反应 | 映射点没覆盖到游戏按钮区域，或没绑实体键 | 回 [按键映射设置入门](按键映射设置入门.md) 检查绑定与位置后重新保存 |
| 走位不跟手、移动轮盘漂移 | 轮盘映射的半径/偏移参数不合适，或映射点压在会动的界面上 | 调轮盘半径与偏移，映射点挪到固定 UI 上 |
| FPS 开镜/开火手感怪、偶发失效 | 一个键上叠了多重触发（组合键冲突、复杂宏） | 先撤掉宏与组合键，用最简映射确认稳定后再逐个加回 |

## 五、平板 / TV 模式的分辨率改不动

K2er 从 v0.2.141 起带 TV 模式，可改手机/平板的输出分辨率。OPPO、realme、一加机型上改了不生效的，去开发者选项打开「**禁止权限监控**」再试。

## 六、什么情况下该怀疑是映射而不是故障

- 只有某一个键失效、其他键正常 → 多半是键位配错位置或该键的映射类型选错，回 [按键映射设置入门](按键映射设置入门.md) 重配那一个键；
- 键位复杂（多场景、大量组合键）时偶发失效 → 先回最简单的一套基础键位验证，再逐层加回，定位是哪一层配置的问题；
- 换了游戏就全失效 → 新游戏没加进 K2er，或者又撞上了游戏模式拦截。
