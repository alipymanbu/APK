# K2er 电脑版与投屏玩法

> 手机版 K2er 之外还有一个 Windows 桌面端：能激活手机上的 K2er、把电脑的键鼠借给手机用、把手机画面投到显示器上。本篇讲它值不值得装、怎么装、三个功能各自怎么用。

## 一、电脑版能做的三件事

K2er 电脑版（官网叫 K2er 桌面版 / K2erDesktop）是装在 Windows 电脑上的配套程序，官方页面列的三大功能：

| 功能 | 做什么 | 什么时候用得上 |
| --- | --- | --- |
| 激活 K2er 服务 | USB 连上手机，一键完成激活 | 华为/荣耀机型、Android 11 以下，或无线激活反复失败时 |
| 桥接电脑键鼠 | 电脑的键盘鼠标直接控制手机游戏 | 手机旁有电脑、想要更稳的键鼠输入时 |
| 屏幕投屏 | 把手机画面投到电脑显示器上 | 想在大屏上玩、或录屏解说时 |

下载入口在官网电脑版页面 `https://k2er.wasd.plus/pc/`，官方标为免费，无捆绑软件。

## 二、安装要求与连接步骤

环境要求不高：Windows 10 或 11（64 位）、USB 2.0 及以上接口、支持 USB 调试的安卓手机，普通办公电脑即可。

1. 电脑上安装 K2er 桌面版；
2. 用数据线把手机连到电脑，手机弹出「允许 USB 调试」时勾选允许；
3. 电脑端点「激活」，手机上的 K2er 服务随即启用。

一个要点：**无线模式要先过一次有线**。桌面版支持无线使用，但必须先用数据线建立连接，之后才能切到无线；跳过有线直接无线是不行的。

## 三、桥接键鼠：电脑外设直接打手游

开启桥接后，你的电脑键盘鼠标就相当于插在手机上的键鼠：移动、点击、视角控制都走电脑端设备，手机端 K2er 的键位照常生效。对瞄准类游戏，鼠标在桌垫上的操作手感通常比接在手机扩展坞上更从容。

配合投屏一起用才是完整形态：手机只负责跑游戏，画面投到显示器，键鼠操作走电脑——手机游戏玩出端游的桌面体验。键位怎么配回到 [按键映射设置入门](按键映射设置入门.md)，具体游戏的键位实例见 [热门游戏键位配置参考](热门游戏键位配置参考.md)。

## 四、电脑端连不上设备怎么查

官方 FAQ 给的三项检查：

1. 手机上 **USB 调试**已打开；
2. 换一条**质量好的 USB 2.0 及以上数据线**（只能充电的线连不上）；
3. 电脑装了手机的 **USB 驱动**。

三项都对仍连不上，按 [激活步骤详解](激活步骤详解.md) 里「软件冲突」的处理来：拔线、重启电脑、关掉其他手机助手类软件再连。华为、荣耀机型额外要先装一次官方手机助手再关闭，步骤在该篇第四节。
