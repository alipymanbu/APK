## 一、先试公共配置，再手动微调

热门游戏不用从空白开始配：把这个游戏加进 K2er 后，点游戏图标进详情页，下滑找到**公共配置**，选一个对应你外设的方案（键盘适配 / 手柄适配）导入。导入后进游戏，从悬浮窗把映射按键拖到与游戏内按钮**逐一对齐**——配置给的按键位置是按常见分辨率做的，机型不同必然要挪。

两点提醒：

- 部分高级功能需要开通会员，以应用内提示为准；
- 导入的只是起点，个别角色手感不顺时按 [按键映射设置入门](按键映射设置入门.md) 的方法改键，或进「场景管理」复制一份配置改名，做你自己的专属方案。

## 二、王者荣耀·世界：手柄方案（2026-04 官方攻略）

| 操作 | 键位 |
| --- | --- |
| 移动 / 视角 | 左摇杆移动，右摇杆视角（细节设置里调「边界」和「归中模式」改手感） |
| 召唤精灵 | `X&A` 组合键，与 PC 版一致 |
| 绝招 | PC 默认 `L3+R3` 容易误触，官方建议改 `L1&R1` |
| 锁定目标 | 短按 `R3` 锁定；长按 `R3+L1` 切左侧目标，`R3+R1` 切右侧 |
| 虚拟鼠标 | 按「选择」键呼出：左摇杆控光标、`A` 点击；再按一次收起恢复行走 |
| 吃药 | 短按十字键右直接吃；长按十字键右弹出鼠标选药 |
| 坐骑 / 感应 / 地图 | 长按十字键下后：`+A` 驾驭游云板、`+X` 云流感应、`+L1` 开地图并带鼠标 |

「长按十字键下再叠加其他键」是这一款的核心思路——一个基键展开一整层功能，键位紧张的游戏都可以照这个思路套。

## 三、火影忍者手游：键鼠方案（2026-05 官方攻略）

- **导入配置**：游戏详情页 → 公共配置 → 选键盘适配方案；内置多套场景，对应不同角色，每套都要进游戏对齐；
- **改键**：点 K2er 图标找到对应按键 → 详情页 →「快捷键」，直接按目标键完成修改；
- **单角色专属**：场景管理里复制现有配置、重命名，即为某个忍者单独留一套方案。

官方攻略里几个可直接抄的角色键位：

| 角色 | 键位方案 |
| --- | --- |
| 青年长门 | 5 个忍术对应 `风/火/雷/土/水` 五个键，双轮盘无 CD 冲突 |
| 漂泊佩恩 | 长按 `H`，`1-4` 数字键快速切换道 |
| 长十郎 | `Tab` 一键切刀（单刀/双刀形态通用） |
| 秽土长门 | 长按 `J` 开盾，`H`/`Y` 触发子技能；也可不开盾直接按 `H`/`Y` |

## 四、其他游戏的要点摘录

- **燕云十六声**（键鼠）：`WASD` 移动、鼠标中键控视角、数字键放技能，整体照 PC 端 MMO 的习惯摆；
- **元气骑士**（手柄）：双摇杆方案——左摇杆走位、右摇杆瞄准射击，地牢类 Roguelike 通用；
- **洛克王国：世界**（手柄）：`L3` 切换跑步、十字键换精灵、长按 `R2` 瞄准，`Y`/`A` 长短按复用「召唤/交互」两件事，虚拟鼠标会自动弹出。

## 五、键位不对时：开指针调试

所有游戏通用的一招调试：K2er 悬浮窗 → 设置 → 右上角「更多」→ 开启**显示/隐藏指针**。之后每次按键都能看到模拟触控实际点在了哪里，键位错位、触发不到一眼定位。

## 六、官方教程还覆盖哪些游戏

官方视频与文章合集里出现过的还有：原神、鸣潮、绝区零、DNF 手游、永劫无间手游、英雄联盟手游、蛋仔派对、三角洲行动、荒野乱斗、宝可梦大集结、实况足球手游、极品飞车集结等（截至 2026 年 9 月；官方教程会持续新增，以官网文章页与官方视频合集当时列表为准）。思路都一致：先导公共配置、再对齐位置、最后按本篇第二节的组合键思路压缩键位。
