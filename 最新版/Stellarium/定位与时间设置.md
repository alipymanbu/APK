## 一、定位：GPS 和手动坐标

默认会用手机的 GPS 定位。在室内、想模拟别处星空、或 GPS 漂移时手动设：

1. 打开快捷栏 → 菜单（三横线图标）→ Location；
2. 取消勾选 Use GPS；
3. 三种填法任选其一：直接填经纬度；在地名列表里选城市；或在世界地图上直接点一个位置（官方指南注明这种方式精度较差，应急够用）。

换城市出差、旅游时记得把地点改回来，否则行星位置对不上——这是「画面和天上不一致」最常见的原因之一（其余排查项见 [常见问题与解决方法.md](常见问题与解决方法.md)）。卸载重装或换机后这些设置会清空，要重新给定位权限、重新确认地点，装回步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 二、时间：时间条与「拖天空就是拖时间」

- 点右下角的日期时间打开**时间条**：有倒退与快进按钮，可以跳到任何日期时刻，比如看明晚的月相、若干年后某天日食发生时太阳的方位；
- 时间条打开期间，**拖动天空不再是转视角，而是拨动时间**——往左往右拖就像手动转动地球，日出日落、星星东升西落都会跟着走；
- 再点一下天空任意处关闭时间条，恢复正常拖动；
- 菜单里的 Date and Time 还有一个选项：白天启动时是否自动把时间推到晚上；
- 时间除了用按钮拨，还能直接输入；公元前 30 年这样的日期填成 `-30`；官方 FAQ 注明可模拟的范围是公元前 4999 年到公元 4999 年。

## 三、几个影响观感的开关

| 设置项 | 什么时候动它 |
| --- | --- |
| Landscape（地景） | 想要无遮挡全景时关掉 |
| Atmosphere（大气） | 关掉后天空变纯黑、不再模拟大气折射，白天也能直接看星 |
| Cardinal Points（方位标） | 分不清东南西北时打开 |
| Light pollution（光污染，在 Advanced 里） | 按你所在环境的亮度调，影响画面里能看到的星数 |
| Milky Way brightness（银河亮度，在 Advanced 里） | 城市里看不清银河、想让它在图上更明显时调 |
| Starlore（星空文化） | 换不同文化的星座形象与命名（中国、希腊等） |
