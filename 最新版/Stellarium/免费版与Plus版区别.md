## 一、你手上这份是哪个版本

网盘里这份安装包的包名是 `com.noctuasoftware.stellarium_free`（1.15.0），对应免费版。免费版不是残缺版：认星、搜索、时间模拟、卫星追踪、夜间红光模式这些日常功能都在；Plus 是**同一个应用里的内购升级**，不装新应用、桌面也不加新图标，升级后功能直接解锁。

## 二、功能对照表

按官方页面的对照整理（截至检索时，以官方页面为准）：

| 功能 | 免费版 | Plus |
| --- | --- | --- |
| 恒星、行星、太阳系天体 | 有 | 有 |
| 星座连线与多种星空文化 | 有 | 有 |
| 深空天体图像（DSS） | 有 | 有 |
| 人造卫星（含 ISS） | 有 | 有 |
| 夜间红光模式 | 有 | 有 |
| 天体亮度下限 | 约 8 等 | 22 等 |
| 3D 行星视图 | 无 | 有 |
| 观测日历（天体可观测性预告） | 无 | 有 |
| 目镜模拟（按器材预览视野） | 无 | 有 |
| 望远镜控制（GOTO 协议） | 无 | 有 |

## 三、差别最大的两件事

1. **能看到的暗天体数量**：免费版显示到约 8 等，Plus 到 22 等。亮星、行星、梅西耶天体在免费版里都够看；想把星系星云一个个翻过去，免费版很快就到头。
2. **望远镜控制与观测规划**：这两项只在 Plus 里。没有 GOTO 望远镜、不做正式观测计划的话，这两项平时用不上。

## 四、怎么升级、什么时候升

升级在应用内完成，价格以你手机商店页面显示为准；官方不同时期可能提供买断或订阅两种形式，下单前看清楚是哪一种。换新手机后 Plus 没了：先确认登录的是原来那个购买账号（Google 账号）；恢复不了的话，官方 FAQ 的口径是联系官方支持并提供购买邮箱或 Google 订单号。一个省钱的判断顺序：先把免费版用熟（认星、搜天体、拨时间都试一遍），确认日常用法真的撞到上面那两条边界，再考虑升级。
