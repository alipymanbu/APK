## 一、要联网吗？会上传我的录音录像吗

不需要联网。官方说明写明「无需互联网连接」，Google Play 的数据安全页也标注「不会收集任何数据」「不与第三方分享任何数据」，官方仓库里另有一份[隐私政策文件](https://github.com/Myzel394/Alibi/blob/master/PRIVACY_POLICY.md)。录制全程在你的手机本地完成。

## 二、收费吗

免费，开源，许可证是 GPL-3.0，源代码公开在 GitHub（[github.com/Myzel394/Alibi](https://github.com/Myzel394/Alibi)）。没有内购、没有会员。

## 三、有中文界面吗

界面语言跟随系统语言；官方通过 Crowdin（[crowdin.com/project/alibi](https://crowdin.com/project/alibi)）众包维护多语言翻译。把系统语言设为中文后启动应用即可，具体某个词条翻没翻全，以你设备上的实际显示为准。

## 四、为什么我的版本和网上说的新功能对不上

网上资料多以官方最新版为准，而安装包通常是你获取当时的那一版。本文涉及的安装包是 0.5.0。0.5.x 系列各版本的主要变化：

| 版本 | 主要变化 |
| --- | --- |
| 0.5.0 | 长按保存 = 保存后继续录；捏合手势调麦克风灵敏度；界面与横屏改进 |
| 0.5.1 | 修复分段文件体积无限增长；改进文件夹访问检测 |
| 0.5.2 | 支持自定义保存文件名；修复自定义文件夹下保存崩溃 |
| 0.5.3 | 问题修复 |

想升到新版，覆盖安装即可，见[下载与安装教程.md](下载与安装教程.md)。

## 五、保存出来的文件是 0 字节 / 打不开

有用户反馈过保存后文件大小为 0 的情况，开发者回复已推送修复。处理顺序：先升级到新版重录一次；仍然复现，就到官方问题反馈页（`https://github.com/Myzel394/Alibi/issues`）说明机型与版本。这类异常相关的排查也可以看[后台被杀与自动停止排查.md](后台被杀与自动停止排查.md)。

## 六、耗电与发热正常吗

持续调用麦克风 / 相机本身就是高负载操作，耗电与发热是正常现象。长时间（比如车内挂一天）建议插着电源用。相比耗电，「后台被系统杀掉」才是更高频的故障，先把[后台被杀与自动停止排查.md](后台被杀与自动停止排查.md)里的电池优化做掉。

## 七、能当行车记录仪用吗

官方定位就是「把手机当行车记录仪用」，车内供电、固定机位是常见用法。要注意的是它只保留最近一段（默认 30 分钟），出事当时要点保存，否则旧内容会被覆盖；操作流程见[使用教程与录制设置.md](使用教程与录制设置.md)，供电与布置的专门建议见[行车记录仪设置与车内使用.md](行车记录仪设置与车内使用.md)。

## 八、iPhone 或电脑上能用吗

官方发布渠道（Google Play / F-Droid / GitHub Releases）提供的都是安卓版安装包，没有 iOS 或桌面版。

## 九、能录到通话对方的声音吗

录到的是麦克风收到的环境声。通话另一端的声音、系统内部播放的声音录不进来——安卓系统对通话音频有保护，官方 issue 区里「录制通话 / 系统内部声音」的请求也仍是开放状态（截至 2026-09）。需要留存通话内容时，用系统自带的通话录音或运营商提供的合规录音方案。
