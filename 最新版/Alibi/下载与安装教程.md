## 一、Alibi 是什么

Alibi 是一款开源的安卓后台录制应用，作者是独立开发者 Myzel394，采用 GPL-3.0 许可证发布。它的用法是：让手机在后台持续录制音频或视频，只保留最近一段（默认 30 分钟），平时不占存储，等你遇到事情需要证据时，点一下保存，这段录像才会落成文件。全程不需要联网。

这个思路来自行车记录仪：一直录、只留最近、出事再取。所以它常被当作手机版行车记录仪，也可以用来留录音凭证。

## 二、官方下载渠道

Alibi 的官方发布渠道有三个，都是免费：

| 渠道 | 地址 | 特点 |
| --- | --- | --- |
| Google Play | [play.google.com/store/apps/details?id=app.myzel394.alibi](https://play.google.com/store/apps/details?id=app.myzel394.alibi) | 有更新推送，安装最省事 |
| F-Droid | [f-droid.org/packages/app.myzel394.alibi](https://f-droid.org/packages/app.myzel394.alibi) | 开源应用仓库，自带更新通知 |
| GitHub Releases | [github.com/Myzel394/Alibi/releases](https://github.com/Myzel394/Alibi/releases) | 直接下 APK，能看到每版改动说明 |

三个渠道装的是同一个应用（包名相同），区别只在更新方式。如果在国内网络环境下 Google Play 无法访问，用 GitHub Releases 直接下 APK，或从安装包资源转存即可。

## 四、安装步骤

从 APK 安装（适用于网盘转存或 GitHub 下载的包）：

1. 把 APK 文件传到手机存储里，用系统文件管理器点开它。
2. 第一次装会提示「未知来源」或「禁止安装」，按提示允许你的文件管理器（或浏览器）安装应用。不同品牌的叫法不一样：有的在安装弹窗里直接给「仍要安装」，有的要去「设置 → 安全 → 更多设置」里开。
3. 回到安装界面，点安装，等它完成。
4. 装完先不要急着打开，下一节把权限的事看完再开，一次授权到位。

从 F-Droid 安装：先装 F-Droid 客户端，再在里面搜 Alibi 点安装；以后有更新它会在通知里提醒。

## 五、首次启动要给的权限

Alibi 靠前台服务在后台持续工作，第一次开录制时会逐个来要权限，各项的用途如下：

| 权限 | 用来做什么 |
| --- | --- |
| 麦克风 | 录音的基础权限，不给录不了声音 |
| 相机 | 录视频用；只打算录音的话可以不给 |
| 通知 | 后台录制必须挂一条常驻通知，这是安卓对前台服务的硬性要求 |
| 文件读写 | 保存录像时往你选的文件夹写文件 |
| 指纹 / 生物识别 | 可选，用来开应用锁（0.4.0 起支持），不让别人翻你的录制会话 |

建议按「录音用」还是「录像用」提前想清楚：只用录音的话，相机权限拒绝掉不影响使用；要当行车记录仪就都给。

## 六、关于版本：0.5.0 与更新的版本

官方 GitHub 上 0.5.x 系列的最新发布是 v0.5.3（2024 年 9 月），比 0.5.0 多了几轮修复：

- 0.5.1：修复分段文件无限变大、改进保存文件夹的访问检测。
- 0.5.2：支持自定义保存文件名；修复使用自定义文件夹时保存崩溃的问题。
- 0.5.3：问题修复。

如果你在 0.5.0 上碰到「保存时闪退」「存储占用一直涨」这类情况，升级到新版就能解决；不升级的话，临时办法见 [保存位置与文件导出.md](保存位置与文件导出.md) 里的说明。安装方式不变，用新版 APK 覆盖安装即可，不用先卸载。

装好之后怎么开第一段录制，见 [使用教程与录制设置.md](使用教程与录制设置.md)。
