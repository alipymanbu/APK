# Alibi 后台被杀与自动停止排查

> 录制切到后台就停、过一会儿自动停止、常驻通知消失——按可能性从高到低逐项排查。

## 一、先确认现象

打开 Alibi 看一眼状态栏：录制正常时应该有一条常驻通知（安卓对前台服务的要求，应用没法绕开）。

- 通知还在、只是你担心它停了 → 多半没停，点开通知能看到录制状态。
- 通知消失了、应用进程也没了 → 是被系统杀掉了，往下排查。

## 二、电池优化（最常见原因）

安卓系统的省电机制会把「后台长时间活动」的应用当成耗电大户处理掉，录制类应用首当其冲。通用做法（各家系统叫法略有差别）：

1. 系统设置 → 应用 → Alibi → 电池 → 把省电策略改成「无限制 / 不受限制」。
2. 关闭针对它的「电池优化」。
3. 部分系统支持在最近任务（多任务卡片）里下拉锁定应用，顺手锁上。

改完之后重新开始一段录制，锁屏放十来分钟验证它还活着。

## 三、厂商系统的额外管控

国产系统在原生省电之外通常还有一层管控，常见的有：

- **自启动 / 关联启动**：设为允许。
- **省电策略白名单**：把 Alibi 加进去。
- **深度睡眠 / 神隐模式**（部分老系统有）：把 Alibi 排除。

MIUI / HyperOS、EMUI / HarmonyOS、ColorOS、OriginOS 等各自的设置入口不同，以你手机的系统版本为准，搜「你的机型 + 应用后台运行设置」能找到对应路径。

## 四、通知权限被关

有的系统在应用通知被关闭后，会连带限制它的后台活动。Alibi 的常驻通知是它后台运行的一部分——保持通知权限开启，别在系统设置里把它禁了。

## 五、录出来没声音（排查输入侧）

录制没被杀、文件也保存出来了，但回放没有声音，查输入侧：

- Android 12 及以上系统在快捷面板里有「麦克风」隐私总开关，它关着时所有应用都录不到声音——先确认它是开的。
- 连着蓝牙耳机或车机时，录音输入可能被蓝牙麦克风接管，录到的全是它的声音；把蓝牙断开再录一段对照。

## 六、存储空间不足

暂存分段需要持续写盘，存储接近满时录制可能中断或保存失败。清出空间再试；也可以把保留时长调小、降低占用。

## 七、排查完还是不行

- 先把 Alibi 升级到新版再试——0.5.x 系列修过若干录制与保存相关的问题，升级方式见[下载与安装教程.md](下载与安装教程.md)。
- 有用户反馈过「保存出 0 字节文件」「更新后录制异常」等问题，开发者有跟进修复；如果你遇到的类似，到官方问题反馈页搜一下或提一条：`https://github.com/Myzel394/Alibi/issues`（附上手机型号、系统版本、Alibi 版本）。

排查思路总览：确认现象 → 放行电池优化 → 厂商管控白名单 → 通知保持开启 → 声音输入正常 → 存储留够 → 升级或反馈。更常见的用法问题也可以先翻[常见问题解答.md](常见问题解答.md)。
