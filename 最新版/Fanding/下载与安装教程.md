## 一、Fanding 是什么，这篇适合谁

Fanding 是开发者 Fanding 推出的创作者粉丝社区应用：YouTuber、直播主、网漫作者、播客等创作者在平台上开设官方粉丝社区，粉丝可以在社区里看只发给粉丝的内容、订会员、给创作者发私密讯息、参与内容投票。官方在 App Store 上有 iOS 版，安卓版可通过 Google Play 等渠道安装，商店页面以官方展示为准。

本篇适合：在应用商店里搜不到或装不上、想直接用网盘里这份安卓安装包完成安装的人。

## 三、从夸克网盘把安装文件取到手机

1. 在浏览器打开 [Fanding 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bc7c2a0d6223)。
2. 登录夸克账号，先把文件转存到自己网盘，再用手机端夸克 App 把它下载到本机（先转存再下载，比直接用浏览器下大文件更稳）。
3. 下载完成后，在通知栏或夸克 App 的下载列表里点开这个 `.apk` 文件，系统会直接进入安装流程。

## 四、允许安装来源与安装步骤

安卓默认不允许安装商店之外的应用，第一次点开 apk 时系统会拦一下，允许一次即可继续：

| 品牌 | 大致路径（不同系统版本菜单名略有差异） |
| --- | --- |
| 小米 / 红米 | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| 三星 | 设置 → 应用程序 → 特殊权限 → 安装未知应用 |
| 原生安卓 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

认准「安装未知应用 / 外部来源」这组关键词，找到你用来下载的那个应用（比如夸克或浏览器），勾选允许，然后回到下载记录重新点开 apk 完成安装。

## 五、首次启动

1. 打开 Fanding，会请求相机、存储等权限。官方对这两项的标注都是可选项：不授权也能用基本功能，需要发帖带图时再给。
2. 首次进入需要注册或登录，怎么注册、怎么把界面切到中文，见 [注册登录与中文界面设置.md](注册登录与中文界面设置.md)。
3. 装完打不开、闪退或卡在启动页，按 [常见问题排查.md](常见问题排查.md) 里的安装类条目处理。
