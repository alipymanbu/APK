## 一、收不到推送通知

按这个顺序查，多数在前两步就能解决：

| 步骤 | 查什么 | 怎么处理 |
| --- | --- | --- |
| 1 | 系统通知权限 | 安卓设置 → 应用 → GitHub → 通知，确认总开关和各分类都开着 |
| 2 | 应用内推送开关 | 应用里 Profile → 设置 → Configure Notifications，对应类型要开着 |
| 3 | Working Hours | 同一个设置页里看是不是正处在你设的免打扰时段 |
| 4 | 后台被杀 | 把应用加入电池/省电白名单，允许后台运行与自启动 |
| 5 | 事件类型本身 | 团队提及、团队审查请求本来就不推送（官方设计如此），去收件箱里看 |

另外提醒一句：推送只推「直接找上你」的事件（被 @、被请求审查、被指派、部署审批），仓库的一般性动静不推送。想确认推送链路通不通，让同事 @ 你一下是最快的测试方法。

这张表是入口级检查。如果每一条都对还是收不到，或者你的症状是「打开应用才补通知」「有通知没声音」这类，去 [收不到推送通知的排查步骤.md](收不到推送通知的排查步骤.md) 按症状逐层排。

## 二、登录失败或验证过不去

- **社交登录点不动/报错**：Google、Apple 社交登录只对当初就用该方式注册的账号开放，且仅限 GitHub Free 与 Enterprise Cloud 用户。后来才绑定社交账号的走账号密码登录；
- **密码对了还要验证码**：你的账号开过双重验证（2FA）或者正处于新设备验证流程。两种情况的方向相同：**登录页面上显示一个数字/验证码，你要把它输进手机上的 GitHub 应用里批准**（手机上必须已登录该账号），而不是反过来。代码一小时有效；手机不在手边时可以改用邮件验证码。手机丢失导致的 2FA 死局，去 GitHub 网页端用恢复码处理；
- **企业账号登不进**：依次核对——企业管理员是否开启了移动端支持、服务器版本是否 3.0 以上、你的客户端版本是否满足要求（Enterprise Server 需 1.4+，GHE.com 数据驻留需 Android 端 1.178.0+）；
- **公司要求 VPN 访问企业实例**：这种环境客户端可能就是用不了，先找管理员确认，别反复重装。

登录方式的选择与多账号操作细节在 [账号登录与多账号切换.md](账号登录与多账号切换.md)。

## 三、界面语言与主题

客户端内置 7 种语言：英语、西班牙语、日语、巴西葡萄牙语、简体中文、韩语、德语。默认跟随手机系统语言——系统是中文它就显示中文。

手动改语言：应用内 Profile → 设置 → 语言选项，选简体中文即可。列表里没有的语言（比如繁体中文）没有对应翻译，会回落到英语。

界面主题在设置里的外观（Appearance）相关选项里调，可以固定深色、浅色或跟随系统昼夜切换；不同版本菜单名和位置略有差异，找不到就在应用内设置页里找「外观/主题」字样。

## 四、Copilot Chat 用不了或没有入口

Copilot Chat 在客户端里能不能用、能用多少，跟你的账号计划挂钩：有的计划包含、有的要订阅，免费额度也随官方政策调整过几轮。应用里看不到 Copilot 入口时，先确认账号计划，再到官方定价页核对当前政策，以官方页面为准。给 Issue 指派给 Copilot 代理这类能力同样受计划限制。

## 五、安装包装不上

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示解析失败/包损坏 | 下载不完整 | 重新下载，并用 MD5 核对（1.242.0 版为 `ed8ea44d2290c945d423ea439cba97e2`，见 [下载与安装教程.md](下载与安装教程.md)） |
| 提示不兼容 | 系统低于 Android 8.0 | 客户端要求 Android 8.0+，低版本系统装不上 |
| 点安装没反应 | 未授权来源安装 | 在系统设置里给文件管理器打开「允许安装未知应用」 |
| 装完闪退 | 存储空间不足或系统过于老旧 | 清空间后重装；仍闪退到 [GitHub Community](https://github.com/orgs/community/discussions/categories/mobile) 搜同类反馈 |

处理完安装问题后，第一次启动要登录，路线见第二节；登录成功后先把通知按第一节调好，再开始处理仓库里的事（[手机上处理Issue与PR.md](手机上处理Issue与PR.md)）。
