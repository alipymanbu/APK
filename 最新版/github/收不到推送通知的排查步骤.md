# 收不到推送通知的排查步骤

> 应用内开关都开了还是收不到 GitHub 客户端的推送？本篇按「症状定位 → 系统层四处检查 → 重置推送通道」的顺序把安卓端的问题拆开排。

## 一、先看症状，别乱调

推送是「GitHub 服务器 → 谷歌推送通道 → 你手机的后台 → 系统通知」这条链路走下来的，断在哪一段，症状不一样：

| 症状 | 大概率断在哪 | 直接跳到 |
| --- | --- | --- |
| 完全没有任何通知 | 系统通知权限没给 | 第二节第 1 步 |
| 打开应用才看到通知（锁屏期间全静默） | 后台被系统限制 | 第二节第 3、4 步 |
| 有通知但没声音、不振动 | 通知分类被设成「静默」 | 第二节第 2 步 |
| 锁屏界面上不显示 | 锁屏通知设置 | 第二节第 2 步 |
| 只有一类事件不推（比如 PR 审查请求） | 应用内推送开关或事件类型本身 | [通知与收件箱管理.md](通知与收件箱管理.md) 第二节 |
| 别的事件都正常，就这个账号不推 | 企业账号的后台轮询机制 | 第五节 |

## 二、系统层四处检查（按命中率排序）

以下步骤是安卓通用的通知排查做法，多家独立来源的说法一致；不同品牌菜单名略有出入，找不到就在系统设置里搜关键词。

### 1. 通知总权限（Android 13 及以上必查）

Android 13 起应用要弹出权限申请才能发通知，装完时手滑点了「不允许」就全断了。路径：系统设置 → 应用 → GitHub → 通知，打开「允许通知」。

### 2. 逐个检查通知分类

应用的通知在系统里分成多个类别（如「活动」「Pull Requests」「系统」），**总开关开着不代表每个类别都开着**。在上面那个通知页面里把列表逐个过一遍，把你要的类别打开；某一类没声音的，检查它的「静默/默认/提醒」档位，锁屏不显示的看「锁屏上显示」开关。

### 3. 电池优化放行

这是国产系统上最常见的坑。系统省电策略杀后台后，推送只会在你打开应用时才「补」进来：

- **小米（MIUI/HyperOS）**：设置 → 省电与电池 → 应用智能省电，找到 GitHub 设为「无限制」。有用户反馈在 HyperOS 上正是这一步解决了 PR 推送消失的问题，还建议顺手打开锁屏通知、允许后台活动，并在最近任务里把应用卡片**锁定**；
- **三星**：设置 → 电池 → 后台使用限制，把 GitHub 从「睡眠应用 / 深度睡眠应用」列表里移出去；
- **原生类系统（Pixel 等）**：一般不需要动，设置 → 应用 → GitHub → 电池 → 选择「不受限制」即可。

### 4. 允许后台数据

设置 → 应用 → GitHub → 流量使用，打开「后台数据」；开了「流量节省程序」的，把该应用加入白名单。典型症状是 Wi-Fi 下正常、移动数据下收不到。

顺带一查：系统时间是否为「自动设置」。时间不准时通知可能乱序或延迟。

## 三、还不行：重置推送通道

上面都过了还是断断续续，多半是推送注册信息出了问题，按顺序做（每做一步测一次）：

1. **清缓存**：系统设置 → 应用 → GitHub → 存储 → 清除缓存（不是清除数据），然后重启手机；
2. **退出重登**：在应用里退出账号再登录，强制刷新推送注册；
3. **重装**：卸载后从 [GitHub 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b2022d65b796) 或 Google Play 重装——重装属于最后手段，前面两步通常就够。

## 四、和「消息免打扰」区分开

系统勿扰模式、专注模式开着时，通知其实**照常进通知栏**，只是不响不弹。如果你是「拉下通知栏能看到、就是不提醒」，问题在勿扰/专注模式的排程里，不在应用——检查这些模式的定时规则是不是全天生效。

## 五、企业账号的推送天生慢一点

GitHub Enterprise Server（公司自建服务器）的推送走后台轮询而非实时通道，到达延迟明显大于个人账号，这是官方文档写明的机制，不是你手机的问题。相关限制（VPN 环境等）见 [账号登录与多账号切换.md](账号登录与多账号切换.md) 第三节。

排查完通道问题后，想让收件箱本身清爽一点（过滤、批量分流），做法在 [通知与收件箱管理.md](通知与收件箱管理.md)；登录环节的疑难杂症回 [常见问题排查与解决办法.md](常见问题排查与解决办法.md)。
