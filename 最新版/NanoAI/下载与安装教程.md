## 二、从网盘拿安装包

1. 打开头部的 **NanoAI 安装文件资源（夸克网盘）** 链接：[https://pan.quark.cn/s/321ade7f2111](https://pan.quark.cn/s/321ade7f2111)
2. 如果直接下载提示需要先转存，就先点「保存到网盘」把它转存到自己账号，再进网盘下载。
3. 转存后在网盘里找到对应文件夹，里面是安装包 `NanoAI_v3.4.0.apk`（约 163.83 MB）和一份「先保存再下载避免失效」的说明文件。
4. 点安装包下载到手机，等进度条走完。

## 三、安装步骤

1. 在手机通知栏或「文件管理」的下载目录里点开下载完成的 `NanoAI_v3.4.0.apk`。
2. 系统若提示「禁止安装未知来源应用」，按弹窗指引去系统设置里允许这次安装（各品牌安卓的入口位置不同，一般点安装时系统会直接带你跳过去）。
3. 回到安装页点「安装」，等待完成。
4. 桌面出现 NanoAI 图标即安装成功，首次打开会申请权限（见第五节）。

## 四、安装前检查四件事

- **存储空间**：安装包本身 163.83 MB，安装展开和后续使用还要占额外空间，建议留出至少 2~3 倍的空余。
- **系统版本**：安装包标注的系统要求为「安卓 5.2 以上」，实际能否安装以安装时系统给出的提示为准；系统过老装不上时，只能升级系统或换设备。
- **设备类型**：小米商店标注支持手机与平板；以手机体验为主，平板上的界面布局以实际显示为准。
- **网络**：安装本身不联网，但打开后的生成类功能要联网才能用。

## 五、首次打开的权限说明

以下是应用商店公示的权限口径，装好后按需放行即可：

| 权限 | 用在哪 |
| --- | --- |
| 照片与视频读取 | 挑选要编辑的照片 |
| 照片与视频写入 | 把成品图保存进相册 |
| 相机 | 现拍照片作为素材 |
| 网络访问 | 上传素材、云端生成 |
| 通知 | 生成完成等提醒（可不授权，不影响修图） |

至少建议放行「读取」和「写入」两项：拒绝了读取你选不了图，拒绝了写入则保存不了成品。

## 六、装不上或装完打不开

- **提示「应用未安装」**：手机里可能残留同包名的旧版本或损坏文件，先卸载旧版再装。
- **提示解析包失败 / 安装中断**：多半是包没下载完整，重新下载后核对完整性——Windows 上执行 `certutil -hashfile NanoAI_v3.4.0.apk MD5`，结果与 `2EB9046F55D5B4EACAEF4F27EAC44501` 一致（大小写不敏感）才算完整。
- **空间不足**：清理出足够空间后再装。
- **装完闪退或打不开**：先重启手机再试；仍不行就清应用缓存或卸载重装，具体见 [生成失败与常见问题排查.md](生成失败与常见问题排查.md) 里的「应用打不开或闪退」一节。
- **装完发现界面和本文说的完全不是一回事**：可能装成了同名的另一个应用，对照 [同名应用怎么区分.md](同名应用怎么区分.md) 核对包名。

装好之后从哪个功能上手，看 [修图功能怎么用.md](修图功能怎么用.md)。
