## 二、安装步骤

1. 在手机浏览器打开 [Niagara Launcher 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6fcbed134d94)，下载 `niagara launcher_v1.16.27.apk`（转存到自己的网盘再下载也可以）。
2. 点击 APK 开始安装。若系统弹出「禁止安装未知来源应用」，按提示进入该来源的授权开关（通常在「设置 → 安装未知应用」里，给你的浏览器或文件管理器授权），返回继续安装。
3. 装完直接打开。首次启动会引导你把它设为默认桌面（见下一节）。

安装本身不需要 root，也不需要额外框架，就是一个普通应用包。装不上或更新失败（提示版本冲突、卸载后仍报错等）按报错场景排查，见 [安装与更新失败怎么办.md](安装与更新失败怎么办.md)。

## 三、设为默认桌面

不设为默认的话，每次按 Home 键都会跳回原桌面，Niagara 只能算「临时打开一下」。

**通常的做法**：首次启动时按引导选择 Niagara Launcher；若当时跳过了，进手机「设置 → 应用 → 默认应用 → 主屏幕应用（Home app）」，把默认桌面改成 Niagara Launcher。

**小米 HyperOS 2.0 及以上**：系统不允许直接把第三方启动器设为默认，有个变通路径——「设置 → 应用 → 应用管理 → 右上角三个点 → 其他设置 → 默认应用 → 桌面 → 恢复默认」，然后按 Home 键或用回桌面手势，系统会弹出选择默认桌面的对话框，在里面选 Niagara Launcher。

**通用兜底（adb）**：各品牌手机都能用这条命令强制设定，需要电脑装好 adb 并连上手机：

```bash
adb shell pm set-home-activity bitpit.launcher
```

**换回原桌面**：「设置 → 应用 → 默认应用 → 主屏幕应用」改回系统自带桌面即可，随时可逆。

## 四、装好后建议先给的权限

Niagara Launcher 把通知直接显示在桌面上，这类能力需要你手动授权，不给也能用，但会缺功能：

- **通知访问权限**：给它读取通知的权限，桌面上才会出现各应用的通知内容与通知点。
- **辅助功能（Accessibility）**：部分手势与快捷操作依赖它。
- **使用情况访问权限（Usage access）**：如果你要用 Usage Breaker（使用提醒）功能，需要这个权限。

Android 13 及以上如果是侧载安装（没走应用商店），系统可能在你授权时弹「受限设置」拦截，这个有明确解法，见 [常见问题与解决.md](常见问题与解决.md)。

## 五、用不惯怎么退出

它不会锁死你的桌面：

1. 在应用列表最底部进「Launcher Settings（桌面设置）→ Advanced（高级）→ Change default launcher（更改默认桌面）」，把默认改回原桌面；部分系统要点两次并选「始终」。
2. 之后想卸载，就和卸载普通应用一样（系统设置里卸载即可）。

想先留着试试、又怕换机丢配置，可以在换机前做一次备份，方法见 [免费版与Pro功能区别.md](免费版与Pro功能区别.md)。
