## 一、这条列表就是你的桌面

Niagara Launcher 没有图标网格。打开桌面，从上到下依次是：时钟与日期、你的收藏应用、（一段时间后出现的）常用建议、以及按字母分组的全部应用列表。右侧边缘是字母波浪条。

用它的核心就两件事：**拇指按住边缘的字母条上下滑**找到应用首字母，**松手**就停在那一组；或者直接在列表里往下滑着找。

## 二、波浪字母怎么操作

1. 手指按住屏幕右侧的字母条不放，上下移动，会浮出一个放大的字母预览，列表跟着跳到对应分组。
2. 松开手指，列表就停在该分组，手指再点列表里的应用即可打开。
3. 习惯左手的话，可以在设置里开启左手模式，字母条挪到左侧，操作逻辑相同。

应用默认按首字母分组，**组内按使用频率排序**——常用的应用排在组内靠前。如果你更想要纯字母序，进 Niagara 设置 → Productivity（效率）→ 关闭 Sort All Apps List by Usage（按使用情况排序全部应用列表）。

## 三、收藏与建议

- **加收藏**：在列表里长按一个应用 → 选 Favorite，它就固定到桌面收藏区。
- **整理收藏**：长按收藏区里任一应用 → Edit favorites，拖动应用旁的四个点调整上下顺序或移除。
- **建议应用**：用一段时间后，Niagara 会把高频应用钉在收藏区下方（收藏+建议总数一般不超过 8 个）。长按某条建议可以 Stop suggesting（不再推荐）；整个功能可以在设置 → Productivity 里关掉 Suggest Often-Used Apps。

不想手动维护收藏的人，可以直接清空收藏、只靠自动建议，桌面会自适应变化。

## 四、常用手势一览

| 操作 | 效果 |
| --- | --- |
| 右滑某个应用 | 展开它的通知与快捷方式（App shortcuts） |
| 左滑通知 | 清除该条通知 |
| 在桌面任意位置下滑 | 打开系统通知栏 |
| 长按应用 | 收藏 / 隐藏 / 应用信息等菜单 |
| 点顶部时钟或日期 | 打开时钟 / 日历 |
| 按住顶部时钟 | 可开关媒体小部件等选项 |

通知会直接显示在对应应用行上：右滑展开看全文，低优先级或不可清除的通知只出现在展开层里，不占列表行——这是它设计好的行为，不是故障（详见 [常见问题与解决.md](常见问题与解决.md)）。

## 五、搜索：最快的找应用方式

字母条适合「知道首字母」的场景，直接打字更快：**在主屏上滑调出应用搜索**，输入名字的首字母或片段，列表实时过滤，点结果即开。这个上滑手势可以在设置 → Features → Search 里开关与调整（如果你的上滑没反应，先来这里看是不是被关了）。

接了外接键盘（平板、折叠屏或桌面模式）时快捷键更省事：

| 按键 | 作用 |
| --- | --- |
| `A-Z` 任意字母 | 直接进入应用搜索 |
| `1-9` 数字 | 打开列表中第 n 个应用 |
| `Tab` | 展开全部应用列表 |
| `Esc` | 返回上一级（如从列表回主屏） |
| `Cmd + S` | 打开 Niagara 设置 |
| `Cmd + A` | 打开日程视图 |

搜索框还接受隐藏命令（以 `/` 开头的指令），比如截透明桌面图用的 `/screenshot`，用法见 [主题美化与图标定制.md](主题美化与图标定制.md)。

## 六、隐藏不常用的应用

预装应用、用不到的工具可以藏起来，让列表更干净：长按该应用 → 选择隐藏（Hide）。被隐藏的应用不出现在列表里，需要时仍可通过搜索或取消隐藏找回。想给隐藏的应用加一道锁（密码保护）是 Niagara Pro 的功能，见 [免费版与Pro功能区别.md](免费版与Pro功能区别.md)。

## 七、换机前把配置带走

Niagara 设置 → Advanced（高级）→ Backup & Restore → Create backup，会生成一个 `.nlb` 备份文件（含收藏、图标、弹窗文件夹、自定义名称与设置）存到下载目录。把它传到新手机，在同一路径 Restore backup 即可还原。壁纸、小组件内部配置、快捷方式受系统限制不在备份里，还原后按提示重配即可。
