## 一、桌面上看不到通知

Niagara 不用通知角标，而是把通知内容直接显示在桌面应用行上。一条都看不到时按顺序排查：

1. **先给通知访问权限**：没授权时它读不到任何通知。
2. **系统里打开通知点**：长按应用 → 应用信息 → 通知，确认「允许通知点」开着；进入每个通知类别，确认「显示通知点」也开着。只有一部分应用不显示，多半就卡在这一步。
3. **勿扰模式**会拦通知：检查「设置 → 声音 → 勿扰」。
4. **重启手机**后再看一次。
5. **Android Go（Go 版系统）不支持**第三方应用读取通知，这个功能在这类机型上用不了，无解。
6. **隐藏了状态栏**时，系统连带隐藏通知气泡，这是 Android 的既定行为；在 Niagara 里向上滚动即可临时唤出状态栏。

另外，低优先级通知、不可清除的通知只出现在右滑展开层里，不显示在应用行旁——这是设计如此。

## 二、权限弹「受限设置」，通知访问/辅助功能开不了

Android 13 及以上对**非应用商店安装**的应用默认限制敏感权限，侧载安装 Niagara 时容易撞上。解法：

1. 再次进入触发「受限设置」的授权页，这次点「我已阅读该文章」（不是「阅读文章」），跳到系统设置后尝试直接打开开关。
2. 若仍被拦：系统设置 → 应用 → 查看所有应用 → 搜索 Niagara Launcher 打开应用信息页。**必须从这条路径进入**——从 Niagara 设置里跳进去的应用信息页不会显示右上角三点菜单。
3. 点右上角三个点 → 允许受限设置（如果没看到三点菜单，说明你还没在第 1 步里触发过该弹窗，先回去触发一次）。
4. 再回到授权页，弹窗出现时点「我已阅读该文章」，即可完成授权。

## 三、设不了默认桌面

- **小米 HyperOS 2.0+**：系统屏蔽了第三方启动器的默认选项。变通路径：「设置 → 应用 → 应用管理 → 右上角三个点 → 其他设置 → 默认应用 → 桌面 → 恢复默认」，然后按 Home 键唤出选择框，选 Niagara Launcher。
- **通用办法（adb）**：电脑连手机执行 `adb shell pm set-home-activity bitpit.launcher`，各品牌都适用。
- 其他机型的常规入口：「设置 → 应用 → 默认应用 → 主屏幕应用」。

## 四、Usage Breaker（使用提醒）打不开，提示 App isn't available

这是 Niagara 没拿到「使用情况访问权限」。手动授予：

- **Pixel / 原生安卓**：设置 → 应用 → 特殊应用权限 → 使用情况访问权限 → Niagara Launcher → 打开开关。
- **三星**：设置 → 应用 → 右上角三个点 → 特殊访问权限 → 使用数据访问 → 找到 Niagara Launcher 打开开关。

授完再回去开启 Usage Breaker 即可。它需要 Android 9 及以上。

## 五、媒体小部件不显示或点了没反应

- **完全不出现**：先确认设置 → Features → Niagara widget → Show media widget 已打开；再确认音乐应用本身的通知权限开着；省电模式会拦截所需的媒体通知，把 Niagara 加入省电白名单或关掉省电。
- **点了没反应（小米 MIUI/HyperOS 常见）**：长按音乐应用 → 应用信息 → 其他权限 → 打开「后台弹出界面」，并确保该应用通知开启。
- **封面不显示/模糊**：播放器没提供封面图，或播放器开了「锁屏模糊」，去播放器设置里关。
- **音乐停了小部件还在**：只要系统通知栏里的播放器还在，它就保留；收起系统媒体卡即可。

## 六、系统版本不支持 / 更新停了

官方已调整支持范围：**Android 8 及以上完整支持并持续更新**；Android 5、6、7 自 2026-07-01 起停止接收更新，最后支持旧系统的版本是 **1.16.14**（官方会为其发布必要热修复），2027-01-01 起 Niagara Pro 及依赖联网的功能在这些系统上停止工作。装 1.16.27（本文档对应版本）前，先在「设置 → 关于手机」里确认你的安卓版本不低于 8。

若安装或使用中遇到本篇未覆盖的问题，可先对照官方帮助中心 [help.niagaralauncher.app](https://help.niagaralauncher.app/)；安装包来源见 [下载与安装教程.md](下载与安装教程.md)。
