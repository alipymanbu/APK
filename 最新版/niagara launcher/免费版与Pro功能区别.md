## 一、免费版能用到什么程度

核心体验不收费，免费版包含：

- 干净的列表式桌面与波浪字母快速找应用
- 桌面直接读通知、直接回复
- 无广告
- 持续更新
- 基础自定义（有限的主题、第三方图标包）

也就是说，把手机桌面换成 Niagara 并日常用下去，不付钱是完整的；Pro 解锁的是进阶美化与效率功能。

## 二、Pro 解锁了什么

| 功能 | 说明 |
| --- | --- |
| 全部主题 | 3 套免费之外的 18+ 套成品主题、社区主题导入 |
| Anycons | 给全部应用统一分配风格图标的内置图标家族 |
| 自定义字体 / 图标 / 时钟 | 深度外观定制 |
| 日历与天气小组件 | 桌面直接显示日程与天气 |
| 小组件堆叠 | 最多 4 个小组件叠在一起切换，不摊开占地方 |
| 弹窗文件夹（Pop-ups） | 能装应用、快捷方式、通知甚至小组件的加强版文件夹 |
| Usage Breaker | 对选定应用的使用时长做温和提醒（需 Android 9+） |
| 隐藏应用密码保护 | 给藏起来的应用加一道锁 |
| 双击熄屏、隐藏状态栏 | 少点几下、界面更干净 |

哪几项对你有用再决定买，纯美化需求和纯效率需求看到的功能集合并不一样。

## 三、价格与购买口径

官方定价页提供**按年订阅**与**终身买断**两种（页面显示 ¥49.98/年、¥159.98/终身，实际价格、币种与优惠以 [niagaralauncher.com](https://niagaralauncher.com/) 官方定价页当时显示为准）。购买在应用内完成，走 Google Play 结算。

几点注意：

- 购买与账号绑定，换手机时需要恢复购买（见下一节），不是「买了这台机器」。
- Android 5、6、7 上自 2026-06-11 起已不能新购 Pro，且 2027-01-01 起已购 Pro 在这些系统上停止工作；新装用户应确保系统在 Android 8 及以上。
- 本文档对应的 1.16.27 安装文件装完即可使用免费版全部功能；Pro 是应用内的升级项，不买不影响基本使用。

## 四、换机时保住 Pro 与配置

- **Pro 订阅**：新手机上装好 Niagara 后，在购买恢复入口执行恢复购买（同一 Google 账号）即可带回权益。
- **桌面配置**：设置 → Advanced → Backup & Restore → Create backup 生成 `.nlb` 文件，传到新机还原；收藏、图标、弹窗文件夹、自定义名称与设置都在其中，壁纸与小组件内部配置因系统限制需重配（详见 [基本用法与手势操作.md](基本用法与手势操作.md)）。
- 备份文件建议另外存一份到云盘或第二台设备，手机丢了也能还原。

不确定某功能是否属于 Pro 时，以官方功能清单 [niagaralauncher.com/niagara-pro-features](https://niagaralauncher.com/niagara-pro-features/) 为准。
