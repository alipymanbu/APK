## 一、先分清两种「加一台设备」

摄像头本身只连一个 WiFi，多处查看都是**软件侧**的事，两条路：

- **加另一部手机/平板**：把设备号加进第二部手机的 App，或走分享；
- **加 Windows 电脑**：装 PC 客户端，用设备号（UID/Gid）手动添加。

两条路都不用动摄像头的配网，前提是它已经在线（见 [摄像头连接WiFi教程.md](摄像头连接WiFi教程.md)）。

## 二、第二部手机 / 平板上添加

Neye3C 手册给的流程是按设备号手动加：

1. 在主手机的 App 里查看该设备的**设备 ID**（UID/Gid，设备详情里能看到）。
2. 第二部手机登录 App（可以是**不同的账号**），进添加设备页。
3. 点 **Add Manually（手动添加）** → **Add Device By Gid（按 Gid 添加）**。
4. 输入刚才记下的设备 ID，确认。
5. 添加成功，列表里出图。

要点：

- 记准设备 ID 这一串字符，它就是「地址」，输错加不上。
- 两部手机登录**同一账号**时，部分场景设备列表会自动同步——你看到列表里已经有了，就不用再手动加。
- 手册的界面是英文（Add Manually / Gid），中文版措辞可能是「手动添加 / 设备 ID」，按你界面上的实际按钮走。

不想给对方完整控制权的话，用 App 内的分享功能更合适；反悔收回的办法见 [常见问题与故障排查.md](常见问题与故障排查.md) 第四节。

## 三、Windows 电脑上看（PC 客户端）

Neye3C 系有 PC 客户端（常见发行名如 `Neye3C.PCNVR`；贴牌厂商会换成自家名字分发，比如手册里出现的 `CMS2000`），从**你买摄像头那家的官网/资源页**下载最稳。装好后手动添加设备的通用流程（出自 Neye3C 手册的 PC 章节）：

1. 双击桌面快捷方式打开客户端。
2. 进 **系统设置（System Settings）** → **监视器管理（Monitor Manager）**。
3. 切到 **P2P** 页，点 **Add（添加）**。
4. 逐项填：
   - **Device Name（设备名）**：随便起，或照抄 UID；
   - **Device Channel（通道）**：填 `1`；
   - **UID**：填摄像头的设备 ID（与手机上看到的同一串）；
   - **Password（密码）**：手册标注的出厂默认密码是 `12345678`。
5. 点保存，关闭窗口；在列表里**双击设备名**，状态变成 Connected（已连接）。
6. 再双击设备名 → 双击 **CH-1**，画面出来；双击画面可全屏。

两个提醒：

- 默认密码 `12345678` 是手册所载的出厂值，**连上之后尽快改掉**——默认密码等于没锁。
- 某一步的按钮名称对不上（不同贴牌客户端界面有差异），以「系统设置 → 设备/监视器管理 → P2P → 手动添加 UID」这条主线找。

## 四、接进第三方录像软件（RTSP，可选）

想把画面接进 VLC、自建录像系统这类第三方软件，摄像头通常开了 RTSP 流（默认端口 `554`）。社区整理的地址形如：

```text
rtsp://<摄像头IP>:554/live/ch00_0
rtsp://<摄像头IP>:554/h264_stream
```

使用前注意：

- 这两条是**社区众包整理的**，不同型号路径不同，**不保证在你的设备上可用**（来源明确标注信息可能过期或不准）。
- `<摄像头IP>` 是摄像头在**你家局域网**里的地址，路由器后台或扫描工具里查；账号密码用设备的登录凭据。
- 这条路是给你**自己的设备、自己家里用**的：局域网内看没问题，别把地址和凭据往外传。
- 接不上就回到 PC 客户端或手机 App，那两条路是官方支持的，稳得多。
