## 一、先想清楚：录像存 SD 卡还是云上

Neye3C 有两条存储路线，可以只用一条，也可以并用：

| | SD 卡（本地） | 云存储（付费） |
| --- | --- | --- |
| 费用 | 一次性买卡 | 按套餐周期付费 |
| 断网时 | 照常录 | 断网就断 |
| 查看方式 | App 内回放 | App 内云回放 |
| 卡坏了/被拿走 | 录像跟着没 | 云端保留 |

拿不准就先插 SD 卡——不花月费，回放功能齐全。

## 二、SD 卡：第一次用先格式化

- **首次使用先把卡插进摄像头并格式化**：官方安装注意事项里明确写了「首次使用请格式化 TF 卡」。没格式化的卡插上去，回放多半是空的或直接报错。
- App 内支持**远程格式化 SD 卡**：进设备参数设置里找存储/SD 卡相关项，按提示格式化。格式化会清空卡上全部录像，动手前先确认没有要留的片段。
- 卡的容量以摄像头说明书支持的上限为准，超大容量可能不识别。
- 卡接触不良、老化后会反复出现录像中断，第一反应是拔下来重新插紧，仍不行就换张卡格式化再试。

## 三、回放怎么看

1. 在摄像头预览画面上点 **回放（Playback）**。
2. 顶部或侧边选日期，拖动时间轴到你想看的时段。
3. 时间轴的颜色代表录像类型：

| 颜色 | 含义 |
| --- | --- |
| 绿色 | 计划录制（常录时段） |
| 橙色 | 报警录制（有事件触发） |
| 白色 | 该时段无录像 |

橙色段就是「出事那一刻」，找异常事件直接扫橙色段最快。回放不同步、拖不动时间轴这类问题见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、抓拍与手动录像

预览界面上有抓拍与录制按钮：抓拍截当前画面、录制手动开拍，产出的文件存手机本地，与卡上的录像互不覆盖，保存位置以应用内提示为准。这两个操作走云端转发，手机网络太差时按了没反应，先检查自己的网络再重按。

## 五、云存储怎么开

1. 预览界面点 **云存储 / cloud service** 入口。
2. 选套餐（常见分报警云存储、连续录制云存储，按月或按年）。
3. 按应用内提示完成支付，成功后设备会重启并重连，回到预览即可。
4. 之后在云存储页面的时间轴上按日期查云端录像；套餐还剩多久、要不要续，也在这个页面看和续（手册明确写了该页可查看与续费）。

注意这几点：

- **套餐种类、价格与支付方式一律以应用内当时显示为准**，不同地区、不同版本页面不一样。
- 用**报警类云存储**要先在摄像头设置里把报警功能打开，否则触发了报警也不产生云端录像。
- 有用户在应用商店评论里反馈购买时提示「余额不足」（支付环节的问题），遇到就换个支付方式重试，解决不了走 App 内反馈。
