## 一、收不到移动侦测通知

按命中率排序：

1. **手机系统通知权限没开**：系统设置 → 应用 → YBox → 通知，打开。安卓 13 及以上版本把这个做成显式开关，装 App 时手一滑点了「拒绝」，App 就永远安静——重装后弹窗时别再拒；
2. **省电策略把 App 杀了**：这是「打开 App 才看到推送、平时一条没有」的典型原因。把 YBox 的电池策略改成「无限制 / 不优化」；三星手机还要去「电池 → 后台使用限制 → 睡眠应用程序」里把 YBox 移出睡眠列表，一加、华为等深度定制的系统同理；
3. **后台数据被禁**：设置 → 应用 → YBox → 流量使用，允许后台数据；开了「省流量模式」的把 YBox 加入不受限名单；
4. **勿扰 / 专注模式在生效**：这类模式会静默吞掉推送而不留提示，检查有没有定时开启；
5. **位置权限被拒**：这类 App 的推送依赖位置权限读取网络状态，位置关了推送也会哑——这是最反直觉的一条；
6. **App 内通知开关被关**：设备设置里「告警通知 / Notification」单独有开关；
7. **设备端侦测没启用**：设备设置里把移动侦测 / 人形侦测打开，灵敏度别调到最低；
8. **设备在睡觉**：电池款休眠期间的事件要等唤醒后补报，个别场景会漏。

## 二、设备显示离线

先弄清设备此刻的供电与网络状态，再对症：

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 电池款离线 | 电量掉到临界值，设备主动断开 4G 保命 | 充电（太阳能款连续阴雨后常见），充一晚再刷新 |
| 4G 款反复离线 | 流量卡欠费 / 被休眠注销 / 当地无信号 | 按 [4G款离线与流量卡自检.md](4G款离线与流量卡自检.md) 的顺序查：先插手机测卡，再挪位置 |
| WiFi 款离线 | 家里断网、路由器重启后换了信道 | 重启路由器；仍不行就重新配网 |
| 换了宽带 / 换了路由器 | 设备还记着旧网络 | 必须重新配网，见 [添加设备与配网教程.md](添加设备与配网教程.md) |
| 有电量有信号但画面调不出 | 设备在休眠，唤醒命令卡住 | 等几秒再刷新；反复如此先更新设备固件 |
| 短暂离线后自己恢复 | 低功耗设备休眠唤醒的正常表现 | 无需处理 |

## 三、画面卡顿、转圈

1. 预览清晰度切回 SD（720P）——流量下看 HD 转圈是常态，见 [实时预览与双向对讲.md](实时预览与双向对讲.md) 的清晰度表；
2. 电池款点开后白等几秒属远程唤醒，别急着退出重进；
3. 家里 WiFi 看也卡：设备安装点离路由器太远，穿两堵墙后信号不够，挪路由器或加中继。

## 四、添加设备失败

完整步骤与失败分支都在 [添加设备与配网教程.md](添加设备与配网教程.md)，速记三条：设备必须处于待配网状态（蓝灯闪）、手机必须连 2.4G WiFi（5G 不行）、4G 设备必须蓝灯常亮且手机开蓝牙。反复失败先长按设备 reset 键重置再来。

## 五、验证邮件收不到、密码找不回

换 QQ / 163 等邮箱重新注册，Hotmail、Outlook 域有收不到验证信的已知情况；密码重置完全依赖注册邮箱，邮箱丢失没有申诉通道。详见 [注册登录与密码找回.md](注册登录与密码找回.md)。

## 六、设备状态灯怎么看

状态灯是判断设备死活的捷径，但**含义以你设备的说明书为准**，不同品牌型号定义有差异。常见规律：

- **蓝灯闪烁**：等待配网；
- **蓝灯常亮**：已连上网络（4G 款表示已注册运营商网络）；
- **红灯常亮 / 红灯闪**：没连上网，或硬件异常；
- **不亮**：没电或已休眠。

对不上号时，翻你设备的说明书 LED 一节，App 侧的问题再回到本篇前几节排查。

## 七、云存储买了没生效

App 内「云存储」页下拉刷新订单；确认登录的是**下单时的那个账号**（换账号登录会看不到已购套餐）；iOS 扣费成功但套餐没到账，等几分钟再重启 App。条款细节见 [云存储与TF卡录像选择.md](云存储与TF卡录像选择.md)。
