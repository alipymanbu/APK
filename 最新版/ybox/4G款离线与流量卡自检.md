# YBox 4G款离线与流量卡自检

> 4G 款设备（插流量卡的电池摄像机、行车款）离线是最难排查的一类——设备挂在室外，你够不着。本篇给一套从电量、流量卡到信号的自检顺序。

## 一、先想明白：4G 款为什么比 WiFi 款更容易「离线」

4G 款相当于一台常年待在室外的「手机」，电量、流量卡、信号任何一环断了，App 里就显示离线。而且它平时休眠省电，**「离线」有时只是「没醒」**——App 里还能看到电量和信号数字、只是画面调不出来，说明 4G 链路还通着，是唤醒命令卡住了，不是真离线。

判断技巧：在设备列表里看电量和信号格数。**数字还在刷新 = 设备活着**，去查唤醒；数字陈旧不动 = 真断线，按下面顺序查。

## 二、第一查：电量是不是掉到了临界值

电池电量掉到临界点（常见在 5%~10%）时，设备会**主动关掉 4G 模组保命**，表现就是离线。太阳能款连续阴雨、冬天日照短、太阳能板被树枝或电线**局部遮住一条缝**（局部遮挡能让发电量掉一半以上）都可能导致入不敷出。

处理：

1. 能摸到设备就取回来，用充电器**满充一次（给足一整晚）**再挂回去；
2. 太阳能板擦干净，检查正上方有没有新增的遮挡；
3. 冬季日照不足的地区，接受「定期取回充电」这个动作，这不是故障。

## 三、第二查：流量卡还活不活着（手机自检法）

最快的判定办法是把卡**从摄像机里取出来插进手机**：

1. 关掉手机的 WiFi；
2. 用流量打开任意网页；
3. 打不开 → 谜底揭晓：套餐用完、卡欠费停机，或卡被运营商**休眠注销**（物联网卡长期没流量就会这样）；
4. 手机能上网 → 卡没问题，继续往下查。

卡装回设备后仍提示无服务的，留意设备设置里有没有 **APN** 一项——运营商侧更新后 APN 可能丢失，按流量卡服务商给的 APN 名手动填一次。卡的方向、触点、卡槽类型（有的设备只认标准卡尺寸）也在这一步顺手核对。

## 四、第三查：信号「有格数」不等于「够用」

App 里显示两格信号，看录像依然会离线——**两格对稳定上传高清视频是不够的**，信号还会随天气、树叶生长、基站忙闲波动。另外设备装在金属杆上、金属棚顶下，会出现「信号弹跳」，看着有格其实时断时续。

处理：

1. 把设备挪 1~1.5 米（换到柱子另一侧、或抬高一点），常常就移出了死角；
2. **天线朝天竖直**，横着或朝下会明显削弱与基站的握手；
3. 长期反复离线且信号常年只有一两格的点位，换位置比换设备管用。

## 五、最后手段：硬重置

电量满、流量卡正常、信号也够，还是离线——长按设备 reset 键做一次硬重置（各设备时长不同，常见 5~10 秒，以说明书为准；通常在防水胶塞下面），强制 4G 模组清缓存、向最近的基站重新注册。这是「重启大法」，对莫名单独线往往有效。

重置后设备回到待配网状态，需要按 [添加设备与配网教程.md](添加设备与配网教程.md) 的 4G 流程重新绑定；绑好后在 [实时预览与双向对讲.md](实时预览与双向对讲.md) 确认画面恢复。仍反复离线，先更新设备固件（设备设置里检查更新），再不行就轮到找设备品牌的售后了——到这一步能试的你都试完了，其余通用问题回 [常见问题与故障排查.md](常见问题与故障排查.md)。
