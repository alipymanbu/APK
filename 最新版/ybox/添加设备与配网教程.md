# YBox 添加设备与配网教程

> 本篇讲把摄像机、门铃这类设备添加进 YBox 的两条配网路径——WiFi 设备扫二维码、4G 设备走蓝牙——以及每一步失败的排查点。

## 一、动手前先分清你的设备是哪类

配网路径完全取决于设备类型，先看说明书或机身标识：

| 设备类型 | 典型产品 | 配网方式 |
| --- | --- | --- |
| WiFi 电池摄像机 / 太阳能 WiFi 摄像机 | 户外电池款 | 扫二维码 / 声波配网，连你家 2.4G WiFi |
| WiFi 门铃 | 可视门铃 | 同上，走 WiFi |
| 4G 无线电池摄像机 | 插流量卡、无网线无 WiFi 的场景 | 蓝牙发现，不连你家 WiFi |
| 全景摄像机 | 360° 款 | 按 WiFi 流程 |

界面入口：App 首页点「添加设备」或右上角「+」，再按设备类型选对应项（4G 设备选「Setup 4G Device / 添加4G设备」一类）。

## 二、WiFi 设备：扫码配网

前提：手机连的是 **2.4G WiFi**（5G 频段连不上，双频合一的路由器如失败可试着把手机切到访客网络或单独的 2.4G 信号），设备已通电并处于待配网状态（通常蓝灯闪烁、有语音提示）。

1. 手机开定位和 WiFi，连上 2.4G 网络；
2. App 里选添加 WiFi 设备，给设备通电，等它的语音提示「等待配网」；
3. 界面上会生成一个二维码，**拿设备镜头对准手机屏幕扫**，距离 15 厘米左右；
4. 屏幕亮度保持中间值——太亮反光、太暗镜头读不出来都会失败；
5. 听到提示音后等配网进度走完，给设备起名、选安装位置，完成。

WiFi 名称在输入页**自动带出**才说明位置权限正常；要你手打 WiFi 名，多半是位置权限没给，回 [下载与安装教程.md](下载与安装教程.md) 的权限表补一遍。

## 三、4G 设备：蓝牙配网

前提：手机蓝牙已开；设备已装好可用的流量卡并通电，状态灯变**蓝灯常亮**（表示已连上运营商网络）。

1. App 里选「Setup 4G Device」；
2. 勾选「蓝灯常亮」后点下一步；
3. 等手机通过蓝牙发现设备，弹出确认窗点「好」；
4. 设置设备名称与位置，等待绑定完成。

蓝牙搜不到设备时，各品牌设备的兜底路径是**扫设备机身的二维码**（二维码纸上或机身贴纸），扫完按引导绑定。

添加时提示「SIM 卡未检测」「无可用网络服务」的，属于流量卡侧的问题（卡的方向与卡槽类型、卡已欠费或被休眠、当地无信号），自检顺序见 [4G款离线与流量卡自检.md](4G款离线与流量卡自检.md)。信号灯含义各品牌差别较大，以你设备说明书为准。

## 四、配网失败速查

进度走到 100% 后失败、或设备灯一直是红色，按这几条来：

1. **设备重置**：长按设备上的 reset 键 4~5 秒，听到「系统重置」语音后从头再来；
2. **距离拉近**：配网期间把设备放到路由器 1.5 米内，成功后再装到最终位置；
3. **路由器开 DHCP**：静态 IP 分配容易和这类设备冲突，改成动态分配再试；
4. **WiFi 密码报错**：注意大小写；密码里特殊字符多时，换 8~12 位纯字母数字的密码试；
5. **手机别连 5G 频段**：见第二节前提。

都试过仍失败的，翻 [常见问题与故障排查.md](常见问题与故障排查.md) 的设备离线一节；配网成功后先看一眼画面效果，见 [实时预览与双向对讲.md](实时预览与双向对讲.md)。
