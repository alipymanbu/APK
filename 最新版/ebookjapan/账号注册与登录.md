## 一、先分清：什么不用登录，什么必须登录

| 操作 | 不登录可以吗 |
| --- | --- |
| 浏览书城、搜索作品 | 可以 |
| 读免费作品、试读 | 可以（多数资料描述为可直接读，个别情况页面会要求登录，以页面提示为准） |
| 购买/租借作品 | 不行，需要 Yahoo! JAPAN ID |
| 书架同步（换设备接续读） | 不行，书架跟着账号走 |
| 离线下载 | 不行，要先登录 |

结论很直接：只是逛逛、试读，游客身份就够；打算花钱买书或在多个设备上接着读，先把账号准备好。

## 二、注册 Yahoo! JAPAN ID

ebookjapan 的账号体系就是 Yahoo! JAPAN ID（2018 年旧 eBookJapan 与 Yahoo! ブックストア整合后统一到这套体系），已经在用 Yahoo 邮箱、PayPay 等服务的话，直接拿现有 ID 登录即可，不用重新注册。

还没有 ID 的话：

1. 打开官网 [ebookjapan.yahoo.co.jp](https://ebookjapan.yahoo.co.jp/)，点页面上的「ログイン」（登录）。
2. 选择「新規取得」（新注册），按页面提示填写邮箱、密码等信息。
3. 完成邮箱或短信验证后，回到 ebookjapan 用这个 ID 登录。

两点提醒：

- 注册页面为日文，字段看不懂可对照翻译逐项填写；个别步骤可能要求可接收验证码的手机号或邮箱，以注册页实际提示为准。
- 注册过程与规则由 Yahoo! JAPAN 侧管理，遇到注册受阻（收不到验证、地区限制等），优先查 Yahoo! JAPAN ID 的官方帮助，而不是反复重试。

## 三、在应用里登录

1. 打开应用，进入「マイページ」（我的页面）或书架页，点登录入口。
2. 输入 Yahoo! JAPAN ID 与密码完成登录。
3. 登录后网页版与应用共用同一书架：在网页版买的书，应用里直接能读；应用里下载的书，换设备登录同一 ID 后重新下载即可。

## 四、登录常见问题

- **验证邮件收不到**：先查垃圾箱；注册时用的邮箱如果已停用，只能换邮箱重新走注册流程。
- **忘记密码**：走 Yahoo! JAPAN ID 的找回流程重置，重置后再回应用登录。
- **登录后书架是空的**：确认登录的是当初购书用的那个 ID；有多个 Yahoo ID 的话很容易串号，逐个核对。
- **账号方面的操作问题**（改资料、注销等）都在 Yahoo! JAPAN ID 侧完成，ebookjapan 应用内没有这些入口。
- **想彻底退出这个服务**：ebookjapan 没有独立的退会入口，路子是卸载应用后到 Yahoo! JAPAN ID 侧删除账号；账号一删，名下已购内容随之失效，动手前把书看完，具体以 Yahoo! JAPAN ID 官方说明为准。

登录好了打算买书的话，先看 [免费阅读与付费方式.md](免费阅读与付费方式.md)——应用里和网页版的优惠规则差别很大，买之前值得花两分钟弄清楚。
