## 一、离线阅读只有应用版支持

先明确边界：**离线是应用版独有的能力，网页版只能在线流式阅读**。飞机上、地铁隧道里这类没网的场景，必须提前在应用里把书下载好。应用版与网页版的能力对照：

| 项目 | 应用版（安卓 / iOS） | 网页版（浏览器） |
| --- | --- | --- |
| 离线阅读 | 支持（要先下载） | 不支持，全程联网 |
| 占用本地存储 | 是，随下载量增长 | 否 |
| 支付方式 | 走应用内硬币充值 | 方式最多（信用卡、PayPay、运营商合算、电子货币等） |
| 优惠券 | 不支持 | 支持 |
| 可用设备 | 手机、平板 | 手机、平板、电脑 |
| 适合场景 | 通勤、出行前囤书 | 电脑大屏看、随手购书 |

买书的优惠规则两边差别不小，下单前先看 [免费阅读与付费方式.md](免费阅读与付费方式.md)。

## 二、把书下载到设备（离线步骤）

前提：已登录 Yahoo! JAPAN ID，要下载的书已在书架里（在网页版或应用里购买的作品都会进书架）。

1. 打开应用，进「本棚」（书架）页。
2. 进入多选状态，勾选要离线的作品——书架里的书可以一次勾多本批量下载。
3. 确认下载，等待完成。下载完成后断网也能读。

两个实务建议：

- 尽量在 Wi-Fi 环境下载，一整卷漫画的数据量不小，用流量下很容易超套餐。
- 下载占用的是设备本地存储，长期囤书的话留意剩余空间，读完结的书及时删掉已下载数据（书架里对单本做删除下载操作即可，作品本身还在账号里，随时能重新下载）。

## 三、书架与背表纸显示

书架是 ebookjapan 比较有辨识度的一个设计：可以把收藏的书按书架视图排列，用「背表紙」（书脊）形式显示，像盯着实体书架看。实际用途有两层：

- **管理**：一个账号下所有购买记录都在这，网页版买的、应用里买的混在一起，按购买顺序或排列方式整理，找书比在列表里翻快。
- **核对**：怀疑买了没入库、书架缺书时，先到网页版登录同一账号对比书架，确认是同步问题还是买的时候没成功。

书架跟着 Yahoo! JAPAN ID 走，换手机、平板重装应用，登录后书架自动恢复，已下载到旧设备的离线数据不迁移、在新设备重新下载即可。账号方面的准备见 [账号注册与登录.md](账号注册与登录.md)。

## 四、下载读不了的快速自查

- 下载列表卡住不动：检查网络后从书架重新发起下载。
- 断网后打不开已下载的书：确认读的是应用而不是网页版。
- 下载报存储不足：清理空间后重试。
