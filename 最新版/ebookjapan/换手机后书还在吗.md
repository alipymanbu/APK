# ebookjapan 换手机后书还在吗

> 本篇回答换机（或卸载重装）之后已购漫画还能不能读：数据迁移的完整步骤、设备数量上限、书架缺书的处理。

## 一、先说结论

书不会丢。购买记录存在云端、挂在你的 Yahoo! JAPAN ID 下，换手机、换平板（包括安卓换苹果）之后，用同一个 ID 登录就能把书架整个恢复，已购作品重新下载即可，不额外收费。硬币余额这类账户资产也跟账号走，不受换机影响。

只有一样东西不迁移：已经下载到旧设备的离线数据。它只存在本地，新设备上要重新下载。

## 二、新设备上的完整步骤

1. 在新设备上安装 ebookjapan 应用，途径见 [下载与安装教程.md](下载与安装教程.md)。
2. 打开应用，用**当初购书的那个** Yahoo! JAPAN ID 登录（应用里点左上角头像图标进「マイページ」登录）。
3. 登录后书架自动同步，购买记录会出现在「本棚」里。
4. 把要离线看的作品重新勾选下载，完成后断网也能读，具体操作见 [离线下载与书架管理.md](离线下载与书架管理.md)。

安卓换苹果、苹果换安卓都没问题——书跟的是账号，不是设备系统。

## 三、书架里缺书时的处理

1. 在「本棚」的「購入済み」（已购）视图里下拉刷新一次，等同步完成。
2. 还是没有，就核对登录的 ID：有多个 Yahoo! JAPAN ID 的人最容易串号，书是跟着 ID 走的，换另一个 ID 登录试试。
3. 网页版和应用两边对比也能定位问题：网页版有、应用没有 → 同步或登录端的问题；两边都没有 → 当时购买没成功，去查支付记录。

## 四、设备数量有上限：最多 6 台

一个账号最多登记 6 台设备（多数资料标注此口径，以官方帮助页为准）。满 6 台再登新设备会失败，处理办法：在「マイページ」→「端末登録」（设备登记）里，把旧设备或不再用的设备删掉，再登记新设备。换机频繁的话，换完顺手删旧设备，避免攒满。

## 五、卸载应用算不算丢书

不算，但要分清两件事：

- **卸载应用**：已下载的离线数据被一并删除；书、硬币、优惠券都在账号里，重装登录后重新下载即可。
- **删除 Yahoo! JAPAN ID**：这才是真正的「销号」，账号下的已购内容会随账号失效。动手前想清楚，具体以 Yahoo! JAPAN ID 侧的官方说明为准。

## 六、换机前旧设备要不要做什么

没有必须做的步骤。旧设备上的离线数据不迁移，留着也用不上，删应用腾空间即可。稳妥的做法是反过来：先在新设备登录并确认书架完整，再清理旧设备。
