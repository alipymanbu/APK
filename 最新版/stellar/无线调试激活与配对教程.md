## 一、三种启动方式怎么选

| 启动方式 | 前提 | 适合谁 |
| --- | --- | --- |
| 无线调试 | Android 11 及以上，不用电脑 | 大多数人的默认选择 |
| 连接电脑（ADB） | 一台电脑 + 数据线 | Android 10 及以下，或无线配对一直不顺 |
| Root | 设备已 Root | 已解锁设备，想要开机自启等进阶能力 |

三种方式拉起的是同一个服务，启动之后的授权、命令等功能没有区别。配对（无线调试方式）只需做一次，之后每次重启手机重新启动服务即可。

## 二、无线调试激活（Android 11+，推荐）

整个流程分两段：先在系统里把开关打开，再回 Stellar 里配对。

### 1. 开启开发者选项和无线调试

1. 进入「设置 > 关于手机」，连续点击「版本号」数次（多数机型 5~7 下），提示「您已处于开发者模式」为止；
2. 回到设置，进入「开发者选项」（有的机型藏在「系统 > 开发者选项」或「更多设置」里）；
3. 打开「USB 调试」和「无线调试」。

### 2. 配对（只需一次）

1. 打开 Stellar，进入无线调试启动入口，选择配对；应用会请求通知权限——**要给**，配对码要填在通知里；
2. 到系统「开发者选项 > 无线调试」页面，点「使用配对码配对设备」，屏幕会显示一组 6 位配对码和端口；
3. 回到 Stellar 的通知，把配对码填进去提交；
4. 配对成功后回应用里点启动，状态从飘红变为「正在运行服务」即完成。

几点容易踩的：

- 配对码有时效，取码后尽快填；超时就回系统页面重新取一个；
- 手机要连着 Wi-Fi（或与电脑同一局域网），无线调试走的是本地网络；
- 小米、红米等 MIUI 系机型如果通知栏里没法输入配对码，把通知样式切到「原生样式」再试。

### 3. 启动服务

配对完成后点启动即可。如果启动失败，先把「无线调试」开关关掉再打开，然后重试一次——这是这类框架通用的有效做法。

## 三、连接电脑启动（Android 10 及以下）

没有无线调试配对的老设备走这条路：

1. 手机开启 USB 调试，用数据线连上电脑；
2. 电脑上装好 ADB 工具（Android 官方 platform-tools 里有）；
3. 在 Stellar 应用内的电脑启动指引里复制命令，到电脑终端执行（不同版本给的命令可能不同，**以应用内当时展示的为准**，不要照抄别处文章里的旧命令）；
4. 命令执行完，应用里状态变为正在运行即成功。

## 四、Root 启动与降权激活

设备已 Root 的话，在应用里直接选 Root 启动，同意管理器（Magisk 等）的授权请求即可。

Root 启动模式下有个「降权激活」开关（在设置里）：打开后服务以 Root 拉起，随即降到 Shell 用户（uid 2000）运行。好处是最小化特权暴露、更稳妥；代价是服务会失去 Root 特有的能力（比如写系统属性、访问受保护目录）。ADB 方式启动本身就是 Shell 权限，不存在降权一说。要不要开看你的用途：只跑普通 Shizuku 生态应用，开着更安心；要用 Root 级能力，就关掉。

## 五、重启手机之后

由于系统限制，**手机重启后服务一定会停**，这不是故障。重新打开 Stellar 点一次启动即可（无线调试配对不用重做），配对关系重启后一般仍然有效，恢复出厂设置才会清掉它。重启后所有依赖服务的高权限应用会暂时提示未授权或不可用，服务拉起后自动恢复。

几个减少重复操作的办法：

- **留意「停用 ADB 授权超时」选项**：部分系统的开发者选项里有这一项，打开后无线调试会话不那么容易被系统超时断开，以你的系统有没有这个选项为准；
- **Wi-Fi 保持稳定**：无线调试走本地网络，切换 Wi-Fi 或断网后服务可能需要重新拉起一次；
- **关注新版本的驻留选项**：1.0.13 之后的版本加入了开机启动（走开机广播、无障碍权限或 Root 权限几条路）与双进程互守（守护进程相互拉起），1.0.11 没有这些选项，只能每次手动拉起——要不要为这个升级看你自己权衡。

无 Root 设备另外两个常规手段：把 Stellar 加入电池优化白名单、在最近任务里锁定后台，能减少服务中途被杀，但不能根除（系统杀后台是常态）。排查方法见 [常见问题与故障排查.md](常见问题与故障排查.md)。
