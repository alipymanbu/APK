## 一、装之前先核对这份包

网盘里这份安装包的基本信息如下，装完可以用 MD5 对一下文件是否完整：

| 项目 | 数值 |
| --- | --- |
| 版本 | 1.0.11 |
| 包名 | `roro.stellar.manager` |
| 大小 | 4.37 MB |
| MD5 | `0B0FD8552008F03EA1C32D0626A55ACD` |

在 Windows 电脑上校验 MD5：

```powershell
certutil -hashfile "安装包文件名.apk" MD5
```

输出的哈希值与上表一致即文件完整。

系统要求方面，各渠道标注的口径不太一致（有标 Android 7.0 的，也有更低的），但真正的门槛其实不在安装，而在激活方式：**无线调试配对需要 Android 11 及以上**，更低版本要靠电脑 ADB 或 Root 才能启动服务，详见 [无线调试激活与配对教程.md](无线调试激活与配对教程.md)。

## 二、从哪获取

Stellar 是开源项目（GitHub 仓库 `https://github.com/roro2239/Stellar`），作者在仓库的 Releases 页发布各版本 APK，能正常访问 GitHub 的话直接从那里拿最新版即可。

两种情况适合取这份 Stellar 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/de2b6e452c72](https://pan.quark.cn/s/de2b6e452c72)

- 访问 GitHub 不方便，或者下载速度慢；
- 想把版本固定在 1.0.11，不想跟着 Releases 升级（本篇后面的步骤与截图说明都以这个版本为基准）。

网盘里拿到的是 APK 文件，把它传到手机存储里即可（数据线、局域网传输工具、网盘客户端都可以）。

## 三、安装步骤

1. 在手机上点开 APK 文件；
2. 系统弹出「未知来源 / 安装未知应用」提示时，按提示允许当前来源安装（各家系统的入口叫法略有差异，安装弹窗里会给跳转）；
3. 等安装完成，打开应用。

装完后建议到系统设置里把这个来源的「安装未知应用」授权收回，避免以后误装别的东西。

## 四、装完先做什么

打开应用，你会看到几个主要页面：启动（拉起服务）、授权应用、命令、设置。**先别急着点启动**——没有开发者选项里的无线调试配合，服务是起不来的。按这个顺序来：

1. 先去系统设置开启开发者选项和无线调试（一次性动作，之后每次重启手机只需重新拉起服务）；
2. 回到 Stellar 完成配对与启动，看到「正在运行服务」的状态才算就绪；
3. 再到授权应用页面给需要高权限的应用授权。

第 1、2 步的完整操作在 [无线调试激活与配对教程.md](无线调试激活与配对教程.md)，第 3 步在 [应用授权与快捷命令怎么用.md](应用授权与快捷命令怎么用.md)。

## 五、版本固定的注意点

网上渠道已经出现比 1.0.11 更新的版本（1.0.13、1.0.19 等），功能上有增量——比如后续版本加入了开机启动与双进程互守这类驻留选项。如果你决定固定用网盘这份 1.0.11，就不要在应用商店或应用内开自动更新；不同版本之间的能力差异见 [与Shizuku的区别和兼容性.md](与Shizuku的区别和兼容性.md)。
