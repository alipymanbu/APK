# Komi Store 是什么软件

> 一句话：Komi Store 是一个免费开源的第三方「应用商店」，专门用来浏览、安装和更新发布在 GitHub 等代码托管平台上的开源软件。本篇讲清它的定位、能装什么、和常见应用市场的区别。

## 一、它解决什么问题

大量开源软件（尤其是安卓应用）不在 Google Play 或国内应用市场上架，开发者只把安装包发布在自己项目的 GitHub Releases 页面。你过去想装这类应用，得自己打开项目主页、翻 Release 列表、在一堆文件名里分辨哪个才适合自己的设备，之后每次更新还得再来一遍。

Komi Store 把这一整套流程做成了应用商店的形态：你在里面浏览、搜索、点一下就完成下载安装，装过的应用出新版本时会收到提醒。相当于给「散装」的开源软件补了一个统一入口。

## 三、能装什么、不能装什么

**能装**：凡是发布页里带了可安装文件的开源项目——安卓的 `.apk`、Windows 的 `.exe` / `.msi`、macOS 的 `.dmg`、Linux 的 `.AppImage` / `.deb` 等。Komi Store 只列出这类「真的能装」的项目，纯源码、没有发布安装包的仓库不会出现在里面。

**能连的软件源**：默认是 GitHub，也支持 Codeberg、Forgejo、Gitea，以及你自己添加的自托管实例。也就是说你不一定非要绑在 GitHub 一家上。

**不能装**：Google Play、国内应用市场里的商业应用；那些应用才有的会员、内购体系在这里都不存在。

拿不准的项目，装之前可以在 Komi Store 里先看安装包的签名指纹、最低系统与权限清单（安卓端提供安装前检查），再决定装不装——用法见[安装GitHub应用步骤.md](安装GitHub应用步骤.md)第三节。

## 四、和 F-Droid 有什么区别

F-Droid 是另一个常见的非 Play 渠道，两者定位不同：

| 对比项 | Komi Store | F-Droid |
| --- | --- | --- |
| 软件来源 | GitHub 等平台的项目 Releases，安装包由原开发者发布 | F-Droid 官方仓库，从源码构建后打包 |
| 收录范围 | 任何带安装包的开源项目，范围大得多 | 通过 F-Droid 审核入库的项目 |
| 版本新旧 | 开发者一发新版就能看到 | 受构建与审核周期影响 |
| 安装包形式 | 原样分发开发者发布的文件 | F-Droid 重新构建的版本 |

两者不冲突，可以并存。Komi Store 还支持把已经在用的 F-Droid 应用关联到对应的代码仓库，这样更新提醒就能统一归口（操作见[安装GitHub应用步骤.md](安装GitHub应用步骤.md)）。

## 五、需要知道的安全边界

Komi Store 本身只是「浏览和分发」的渠道：它把第三方开发者发布在 Releases 里的文件送到你面前，但不替你审查这些文件的内容与安全性。你在安装任何一个应用之前，值得先看一眼该项目的 README、Star 数量和更新日志，再决定装不装——这一点和从任何非应用市场渠道获取软件时是一样的。
