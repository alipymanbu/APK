## 一、Windows（Windows 10 / 11，64 位）

先说明一点：页首网盘资源里放的是**安卓安装包**，电脑版请从官方 [Releases 页面](https://github.com/kurikomi-labs/komi-store/releases)或下文渠道获取。

按场景三选一：

| 方式 | 适合谁 | 操作 |
| --- | --- | --- |
| EXE 安装包 | 大多数人 | 从 Releases 下载 EXE 安装包双击安装（文件名以页面实际显示为准） |
| 包管理器 | 用惯命令行的你 | `winget install zed.rainxch.githubstore`（新版 ID 为 `KurikomiLabs.KomiStore`，搜得到哪个用哪个）；或 `scoop install komi-store` |
| MSI / 便携 ZIP | 企业部署 / 无管理员权限的机器 | MSI 适合组策略批量部署；ZIP 免安装、解压即用，不需要管理员权限 |

截至 2026-09，winget 里新旧两个 ID 都能搜到（旧 ID 沿用改名前的包名 `zed.rainxch.githubstore`），以 `winget search komi` 的实际结果为准。

## 二、macOS（macOS 12 及以上）

- **DMG**：Releases 页有 Apple Silicon（arm64）与 Intel（x64）两个包，下载后拖进「应用程序」文件夹。
- **Homebrew**：依次执行 `brew tap komi-store/komi-store` 和 `brew install --cask komi-store`。
- **首次打开会被拦**：该应用不在 Apple 公证名单里，Gatekeeper 会提示「无法验证开发者」。放行方法：**系统设置 → 隐私与安全性**，找到被拦的记录点**仍要打开**；或在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/Komi-Store.app
```

## 三、Linux（x86_64）

- **AppImage**（通用）：下载后 `chmod +x` 加执行权限直接运行；RPM 打包暂停期间，Fedora / openSUSE 用户就用它替代。
- **DEB**（Debian / Ubuntu / Mint）：官方提供通用版与 Debian 12 专版两个包，按自己的系统版本选。
- **Arch**：Releases 页直接提供 pacman 包（`.pkg.tar.zst`）。

## 四、桌面端与安卓端的差异

- 桌面端装 Windows / macOS / Linux 软件时，下载完成后由操作系统接手完成安装，没有安卓那套「未知来源」授权；
- GitHub 登录在桌面端走浏览器跳转。Windows 端 1.9.2 修复过「授权完成后回不到应用」的问题，遇到这个现象先升到最新版；登录方式与限流详见[GitHub登录与限流处理.md](GitHub登录与限流处理.md)；
- 安卓特有的 Shizuku 静默安装、应用内 README 翻译等选项在桌面端不适用或入口不同；
- 桌面端界面同样支持多语言与双栏布局，浏览、搜索、下载安装的用法与手机端一致（日常用法见[安装GitHub应用步骤.md](安装GitHub应用步骤.md)）。

渠道与文件名会随版本更新变化，以官方[下载页](https://komistore.app/download/)与 [Releases](https://github.com/kurikomi-labs/komi-store/releases)当前显示为准。
