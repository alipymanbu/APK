# Komi Store 配置 Shizuku 静默安装

> 每装一个应用都要跳一次系统确认弹窗？小米、OPPO、vivo、华为用户尤其烦这个。本篇讲怎么用 Shizuku 给 Komi Store 开静默安装，让「下载 → 安装 → 更新」全程免确认。

## 一、先想清楚要不要配

| 你的情况 | 建议 |
| --- | --- |
| 手机原生系统 / 安装弹窗不觉得烦 | 不用配，默认安装器够用 |
| 国产系统、频繁更新应用、嫌每次确认麻烦 | 值得配，十几分钟一次搞定 |
| 手机已 root | 更简单，Komi Store 直接支持 root 后端，不用装 Shizuku |

静默安装的实质：Shizuku 在后台以调试权限替你按「安装」，Komi Store 调用它完成安装与自动更新。这是 Shizuku 的正常用途，不改动系统，也不影响银行、支付类应用的使用。

## 二、准备：装 Shizuku 并启动

Shizuku 是另一个独立应用（开源，开发者 Rikka），从应用商店或其官方渠道获取。装好后要把它「启动」起来，Android 11 及以上可以全程在手机上完成：

1. **开启开发者选项**：一般是在「设置 → 关于手机」里连点「版本号」7 次（不同机型入口不同，搜一下自己机型）；
2. 在开发者选项里开启 **USB 调试**和**无线调试**；
3. 打开 Shizuku，点**配对**：通知栏会出现一条配对通知；
4. 进入系统的「无线调试」页面，点**使用配对码配对设备**；
5. 把屏幕上显示的配对码填进 Shizuku 的那条通知里（**配对只需做一次**）；
6. 回到 Shizuku 点**启动**，状态变成「运行中」即可。

两个官方手册里明确写过的坑：

- **手机重启后 Shizuku 会停**，需要重新点一次「启动」。所以「前几天还好好的，今天又要手动确认安装」，九成是这个原因——打开 Shizuku 重新启动一下就好；
- 配对时**一直显示「正在搜索配对服务」或填码后立刻失败**：把无线调试开关关掉再打开，重试一次（Shizuku 官方 FAQ 给出的处理方式）。

Android 10 及以下的设备没有手机端无线调试，需要连电脑用 ADB 启动 Shizuku，步骤见 [Shizuku 官方手册](https://shizuku.rikka.app/zh-hans/guide/setup/)。

## 三、在 Komi Store 里切换安装后端

1. 打开 Komi Store → **设置** → **安装**（Installation）；
2. 把安装后端从默认安装器切换为 **Shizuku**；
3. 弹出授权请求时点**允许**（Shizuku 会列出申请方的应用名，确认是 Komi Store 再允许）；
4. 之后在 Komi Store 里点安装，就不再弹系统确认窗了；应用更新同样走静默通道。

root 用户在第 2 步选 **root**（Magisk / KernelSU / APatch 均可），跳过第二节的全部步骤。

## 四、Dhizuku 是什么，要不要用

Komi Store 还支持第三种后端 **Dhizuku**：它通过「设备所有者」权限接管系统安装流程，主要面向被厂商限制得特别死的场景（如部分企业管控机型）。配置 Dhizuku 需要先把某应用设为设备所有者，门槛比 Shizuku 高得多——普通手机用 Shizuku 就够了，不必碰它。

## 五、安全提醒

Shizuku 的权限比普通应用高，**只给你信任的应用授权**：授权弹窗出现时看清应用名；已授权的应用可以在 Shizuku 的授权列表里随时撤销。Komi Store 是开源应用，装的时候从官方渠道（GitHub Releases、F-Droid 或本文网盘资源）获取即可。
