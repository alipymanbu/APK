## 一、安装时报错

**「解析包错误」/ 安装包损坏**

通常是下载没下完整。删掉 APK 重新下载；用网盘渠道就重新转存一次再下。也可以核对文件 MD5（本文网盘包为 `9f53245cdd5b7107d46418c5e413c40e`）确认完整性，核验方法见[下载与安装教程.md](下载与安装教程.md)。

**提示签名不一致 / 无法覆盖安装**

手机里已有一个同包名但不同来源的旧版本（比如之前从别的渠道装过）。两个选择：卸载旧版再装，或回原渠道更新。卸载会丢掉该应用的数据，先备份。

**安装按钮点了没反应（小米 / OPPO / vivo / 华为常见）**

这些系统对「第三方应用发起安装」管得最严。先确认给了 Komi Store「安装未知应用」权限；想彻底省事可以在 **设置 → 安装** 里配置 Shizuku 静默安装（要求 Android 11+），完整步骤见[Shizuku静默安装设置.md](Shizuku静默安装设置.md)。

## 二、列表加载不出来 / 下载转圈

**先想限流这件事。** GitHub 对未登录请求按 IP 限额（约 60 次/小时），几个人共用一个出口 IP 或刷得快一点就会触顶，表现为列表为空、详情打不开、下载失败。**登录 GitHub 账号**后限额提升到每小时数千次；三种登录方式（浏览器授权、设备码、个人访问令牌）的逐步操作与排查见[GitHub登录与限流处理.md](GitHub登录与限流处理.md)。

**登录了还是慢、或下载转圈**，用镜像：

- 下载走多源并行，与 GitHub 直连比速度，完成后按 GitHub 公布的 SHA-256 值校验完整性（官方仓库的说明）——换镜像不会换来内容被改过的包；
- 设置里可启用内置镜像（如 fastly.jsdelivr.net），镜像列表会随版本更新；自建了 gh-proxy 类服务的可以填**自定义镜像地址**；
- 长时间下载很慢时应用会主动弹出镜像建议，点一下就切换，不需要可以关掉这个提示。

## 三、更新提醒不响 / 自动更新没动静

- **通知权限**：系统设置里确认允许 Komi Store 发送通知；
- **后台保活**：国产系统常把后台服务杀掉，把 Komi Store 加入自启动与后台白名单（小米/OPPO/vivo/华为尤其需要）；
- **签名核对**：应用内更新前会校验签名一致性，更新包签名与已装版本不同时会被拒绝——回原渠道更新，或卸载重装；
- **在应用外更新过的应用**：更新判定按应用版本号比对，你在 F-Droid 或手动装的新版会被识别同步，不会反过来误报旧版本；
- **更新失败**：先查网络与存储空间；官方仓库 Issues 里有用户反馈过更新失败的情况，多数随版本更新修复，仍复现就带上版本号去搜；
- **单个应用不想更**：对该应用设置「跳过此版本」或「忽略更新」，也可以用正则只匹配特定命名的安装包。

## 四、其他

- **界面是英文**：设置里切换语言，有简体中文；英文 README 可用应用内翻译（需填自己的翻译服务 key）。
- **F-Droid 上的版本号比官方发布页旧**：正常现象，F-Droid 有构建与审核周期；急用新版就从 [GitHub Releases](https://github.com/kurikomi-labs/komi-store/releases) 获取。
- **想卸载 Komi Store**：直接卸载即可。它只是个管理与分发入口，你通过它装的其他应用不受影响，会照常保留在手机上（只是不再统一提醒更新）。
- **开着「始终开启的 VPN」且勾了「未连接 VPN 时阻断网络」就连不上**：社区反馈过的场景——这种模式下系统不给 Komi Store 联网。临时关掉该开关（或把 Komi Store 加入 VPN 的分应用白名单）即可恢复；
- **导出 Obtainium 失败**：有用户反馈导出功能偶发不成功（Issues 里有记录），可以先手动逐个关联应用，或等下一个版本；
- **闪退 / 界面弹窗遮挡**：先升级到最新版看是否已修；仍复现的，去 Issues 搜有没有同款，没有就带上机型与系统版本反馈；
- **电脑端的问题**：放行、安装、登录相关见[电脑版安装方法.md](电脑版安装方法.md)。

以上覆盖不了的问题，去官方渠道问：GitHub 仓库的 [Issues 页面](https://github.com/kurikomi-labs/komi-store/issues)，或从[官网](https://komistore.app/)进官方 Discord 社区。
