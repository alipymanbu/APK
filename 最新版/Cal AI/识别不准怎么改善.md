## 一、先对预期：两组数字并列看

官方 FAQ 写明识别准确率约 80%，并说明没有任何饮食记录应用能做到完美——热量与营养数值本身就有波动。

第三方评测给的是另一套分场景数字（2026 年一份 244 份参照餐的独立测试，口径为百分比误差）：

| 餐食类型 | 第三方实测误差 |
| --- | --- |
| 单一食物（三明治、一碗面） | 约 ±6~8% |
| 多样混合菜 | 约 ±10~14% |
| 食材叠放的杂乱餐盘 | 约 ±15~20% |
| 连锁餐厅餐品 | 约 ±12~15% |

两组口径不冲突，可以合起来用：官方的「80%」指多数情况不用修；第三方的数字告诉你**越乱越不准**。另有 2025 年发表在 Nutrients 期刊的研究测过「拍照估热量」这类方法的通用误差（114 份真实餐食、16 项营养素，平均误差约 26.9%）——该研究并非针对 Cal AI，但说明这个方法本身就有误差下限，指望精确到个位数不现实。

## 二、让识别更准的四个拍摄要点

官方给出的改善手段：

1. 光线充足：自然光或明亮房间，别在背光处拍。
2. 对焦清晰：食物要清楚合焦，糊了就重拍。
3. 食物占满画面：镜头凑近点，别让食物缩在角落。
4. 更新到新版本：识别能力随版本更新改进。

混合菜（一盘多菜）是识别最容易出错的地方，拍完后重点核对清单里每一项是不是真的在你盘子里。

## 三、识别错了怎么修

结果页里每一项都能动：认错的食物删掉、漏掉的加进去、分量按实际调，改完热量与营养会跟着重算。这比反复重拍省时间——尤其对家常菜，手动调一次分量往往比拍十张照片更接近真实值。

## 四、看不见的热量：AI 只认照片里的东西

照片里没有的，估算里就不会有。炒菜用的油、拌进去的酱、黄油、沙拉酱、勾芡，这些不显形或根本看不见的热量会被漏算；有第三方评测提示，一份沙拉的酱料就可能差出 200 大卡上下（单源口径，量级参考）。家常菜的两个对策：

- 用油、糖、酱按实际用量手动补一条进这餐；
- 常做的菜直接存成自定义食物，把油盐酱料折算进去，一次填好长期复用。

## 五、数据库偏北美：中餐场景的额外注意

多个第三方评测指出 Cal AI 的食物库与连锁餐厅数据以北美为主，对地区菜（国外评测举的例子是中东、南亚菜式）匹配更弱。对中文用户这意味着：家常中餐、地方小吃被认错或认不出的比例会更高，不是你手机的问题。省力的做法是把常吃的那几十样存成自定义食物，拍照只用来记新东西。

## 六、换一种记录方式更可靠的情况

| 情况 | 更可靠的方式 |
| --- | --- |
| 有包装的食品 | 条形码，其次数据库搜索品牌 |
| 包装背面的营养成分表 | 拍营养标签——官方 FAQ 单独提到标签要清晰合焦 |
| 自家配方（奶昔、便当） | 自定义食物或食谱，填一次以后复用 |
| 已经吃完、没法拍 | 文字描述，写清菜名与分量 |
| 拍了三四次还是离谱 | 手动添加，参考包装或常识数值 |

各方式的入口与操作流程见[拍照识别卡路里使用教程.md](拍照识别卡路里使用教程.md)。

## 七、修正也压不住的时候

更新版本、换光线之后仍然大面积识别失败，或个别餐食错得离谱且每次都错，可以带截图联系官方邮箱 support@calai.app（官方 FAQ 建议附上出错截图）。应用整体打不开、闪退这类问题则先走[闪退打不开问题排查.md](闪退打不开问题排查.md)的重装路径。
