# Smart Edge 侧边栏不显示怎么排查

> 划不出面板、手柄突然消失、后台重启后失效、通知区空白 —— 按这套顺序查，八成是权限或后台被杀。

## 一、先按顺序过三道闸

面板显示依赖服务活着，按出现频率从高到低查：

1. **「显示在其他应用之上」是否还开着**：系统更新、清理工具都可能把这个权限重置。去 设置 → 应用 → Smart Edge → 权限/悬浮窗 确认。
2. **无障碍服务是否还开着**：这是重灾区 —— 部分厂商在系统更新后会静默关闭第三方无障碍服务。去 设置 → 无障碍（辅助功能）里找到 Smart Edge，确认开关仍是打开的；如果显示「已开启」但面板没反应，关掉再开一次。
3. **服务是否被杀后台**：见下一节。

## 二、后台被系统杀掉（重启手机后、用一会儿后失效）

侧边栏是个常驻后台的服务，国产系统的省电策略很容易把它清掉。常规处理：

- **忽略电池优化**：Smart Edge 本身会申请「忽略电池优化」权限，在系统弹窗里同意；或到 设置 → 电池 → 更多电池设置里把 Smart Edge 加入不受限名单。
- **多任务锁定**：在最近任务列表里下拉 Smart Edge 卡片加锁，避免一键清理时被带走。
- **自启动与后台管理**：各品牌入口不同（MIUI/澎湃「自启动」、华为「应用启动管理」改手动并允许后台活动、OPPO/vivo「允许完全后台行为」），把 Smart Edge 设为允许。
- 检查是否开着系统的**省电模式 / 超级省电**：这类模式会限制一切后台服务，先关掉验证。

## 三、面板没消失，只是「划不出来」

- **划的位置不对**：要从手柄所在位置向内滑。手柄很细时容易划空 —— 临时把触发区高度、宽度调大试一次（设置里的位置区，见 [主题外观与手柄位置设置.md](主题外观与手柄位置设置.md)）。
- **与系统返回手势冲突**：全面屏手势下，屏幕边缘同时被系统的「返回」占用。把 Smart Edge 的手柄移到另一侧、或调垂直偏移错开，是最直接的解法；也可靠设置里的手势灵敏度提高触发优先级。
- **手柄被设进了隐藏名单**：1.3.4 起你可以手动勾选「在这些应用里隐藏手柄」。如果只在某个游戏/视频应用里消失，检查它是否在隐藏名单里（见 [侧边栏手势与分屏用法.md](侧边栏手势与分屏用法.md) 第五节）。

## 四、通知区是空的（生产力中心没内容）

面板能划出来、只有通知那一块空白时，按三层查：

1. **Smart Edge 自己的通知访问权限没开**：这是最常见的原因 —— 通知区依赖「通知访问」，去 设置 → 通知 → 设备和应用通知（各品牌叫法略有差异）里找到 Smart Edge，允许它读取通知。
2. **来源应用自己没通知**：通知区显示的是其他应用的活跃通知。先确认那些应用本身的系统通知开关是打开的；Android 13 以上还要求应用单独申请「通知权限」，误点了「不允许」就不会有任何通知产生。
3. **系统层把通知压住了**：勿扰模式、睡眠模式、以及厂商的「深度休眠应用清单」都会让通知不出现 —— 三星在 设置 → 电池 → 后台使用限制里有单独的休眠名单，把相关应用移出即可（各品牌以自己设置项为准）。

另外提醒：通知区需要 Smart Edge 本身也活着（见第二节），它被杀后台时面板可能还在、通知却是旧的。

## 五、其他已知情况

| 现象 | 说明 |
| --- | --- |
| 图标显示空白但仍可点 | 1.3.4 已修复（禁用了有问题的列表优化）。仍在旧版就升级 |
| 关掉服务后它又自己启动 | 1.3.4 已修复（阻止了服务被停用后的意外重启） |
| 手柄死活不出现，服务也开了 | 截至 1.3.6，新版在显示手柄前会强制检查引擎（无障碍或自动化至少一个可用）；确认二者没被禁用。以官方页面说明为准 |

## 六、还是不行怎么办

依次试：重启手机 → 在无障碍里关闭并重新打开服务 → 卸载重装（按 [下载与安装教程.md](下载与安装教程.md) 重走一遍权限）。用到自动化相关功能时，先确认进阶权限还有效（卸载重装会回收，见 [ADB与Shizuku进阶自动化.md](ADB与Shizuku进阶自动化.md)）。Smart Edge 是开源项目（MIT 协议），问题可以在官方仓库的 Issues 页反馈，渠道见 [版本更新与下载渠道.md](版本更新与下载渠道.md)。
