## 一、装之前先确认两件事

- **系统版本**：Smart Edge 要求 Android 8.0（API 26）或更高。低于 8.0 的老机型装不上。
- **效果预期**：玻璃模糊与 Material You 动态配色这两项视觉效果针对 Android 12+ 优化，8.0~11 的机器能正常用核心功能，但实时背景模糊效果出不来（官方说明如此）。

网盘里这份 Smart Edge 安装文件资源（夸克网盘）在：[https://pan.quark.cn/s/1c80b710f373](https://pan.quark.cn/s/1c80b710f373)，下载后是这样一个包：

## 三、安装

1. 把 APK 传到手机（数据线、局域网传输均可）。
2. 点击 APK 安装，系统若弹出「禁止安装未知来源应用」，按提示进入设置允许本次安装（各品牌入口通常在 设置 → 安全/隐私 → 安装未知应用）。
3. 装完先别急着打开，先把权限准备好（下一节）。

## 四、首次启动：按引导把三项权限开齐

打开 Smart Edge，首屏引导会让你逐项激活服务。三项权限各管一件事，缺一项对应功能就不好使：

1. **显示在其他应用之上（悬浮权限）**：让侧边面板能浮在别的应用上面。不开的话面板根本显示不出来。
2. **辅助功能服务（无障碍）**：核心交互与多窗口功能依赖它 —— 手势自动关闭面板、系统快捷动作都靠这个服务。系统会跳到无障碍设置页，在列表里找到 Smart Edge 并打开开关；部分品牌还会弹一个醒目二次确认，勾选「我已知晓」再确认。
3. **通知访问权限（可选）**：只服务于「生产力中心」（在侧边栏里看通知、从通知直接开小窗）。不需要这个功能可以先不开。

引导页往下滑有 `continue`，全部开完点 `test sidebar now` 即可当场验证侧边栏已启用。

## 五、它还申请了哪些系统权限（对照着看，别慌）

装的时候系统会列出一串权限，1.3.4 共 12 项。常见的几项与用途对照：

| 权限 | 用途 |
| --- | --- |
| 显示在其他应用之上 | 面板悬浮显示（核心） |
| 无障碍服务 | 手势交互与多窗口（核心） |
| 通知访问 | 生产力中心读通知（可选） |
| 忽略电池优化 | 防止后台被省电策略清掉 |
| 开机后启动 | 重启手机后把服务拉起来 |
| 振动 | 触觉反馈 |
| 查询已安装应用 | 生成面板里的应用列表 |

完整清单与最新版的差异以 [F-Droid 页面](https://f-droid.org/packages/com.imi.smartedge.sidebar.panel/)当时显示为准。其中 `WRITE_SECURE_SETTINGS`、Shizuku 两项属于进阶权限，普通用户在安装时碰不到，需要手动授予才生效 —— 不用管它，除非你要玩自动化（见 [ADB与Shizuku进阶自动化.md](ADB与Shizuku进阶自动化.md)）。
