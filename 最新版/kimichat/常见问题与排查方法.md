## 一、安装类

| 症状 | 先做什么 |
| --- | --- |
| 提示「禁止安装未知来源应用」 | 到系统设置里允许文件管理器/浏览器安装应用；小米/华为类机型再检查「纯净模式」是否开着 |
| 安装到一半失败 | 确认手机剩余空间够放安装包（包体 33.57M，留出数倍余量），删除旧包重新下载再装 |
| 怀疑包损坏 | 核对 MD5 是否为 BDEF1AA7622BD8150E66CABA3EA124EC，不一致就回网盘重下 |

**版本差异**：网盘里这一版是 2.1.0（信息核对于 2026-09-27），官方站上的最新版可能已经更新。功能入口随版本会有出入——如果你在[拍照解题与语音通话用法](拍照解题与语音通话用法.md)里找不到某个入口，先确认自己的版本，需要新版就从官方渠道或[Kimi 智能助手 安装文件资源（夸克网盘）](https://pan.quark.cn/s/abff1bfdbb43)获取。

## 二、登录类

| 症状 | 先做什么 |
| --- | --- |
| 验证码收不到 | 等满 60 秒再点重发；检查短信拦截/骚扰过滤；确认手机号没输错国别区号 |
| 第三方登录跳转失败 | 确认对应的第三方 App 已登录且未限制授权；换验证码方式登录兜底 |
| 换绑手机号被拒 | 目标手机号不能已注册过相关平台账号，换一个没用过的号码 |
| 新设备登录后记录不全 | 确认登录的是同一个账号；Work 模式的任务只留在创建它的电脑端，见[手机号登录与多设备同步](手机号登录与多设备同步.md) |

## 三、语音与权限类

| 症状 | 先做什么 |
| --- | --- |
| 语音通话没反应 | 系统设置 → 应用权限 → 麦克风，确认已允许；戴耳机时先摘掉试一次 |
| 收不到任务/回复提醒 | 检查通知权限是否开启，以及系统是否对该应用做了省电限制 |
| 拍照黑屏或保存失败 | 检查相机与存储权限 |

## 四、联网与响应类

- **联网异常**：切换 Wi-Fi 与移动数据再试，或彻底退出应用重开；部分第三方渠道的用户反馈也提到重启应用可解决偶发联网问题；
- **回答内容不准**：官方用户协议明确提示模型输出可能不准确、不能替代医疗/法律/金融等专业意见——涉及重要决策时自己再核一道，别把回答当唯一依据；
- **提示额度不足**：免费与会员额度都会耗尽；查看路径、刷新规则与套餐对比见[额度用完与套餐选择](额度用完与套餐选择.md)。

## 五、文件与上传类

| 症状 | 先做什么 |
| --- | --- |
| 文件传不上去 | 单文件超 100M、会话内超 50 个、格式不在支持列表（PDF/Word/Excel/PPT/TXT/图片/视频），三者逐一对——规格表在[长文档与多文件解读技巧](长文档与多文件解读技巧.md) |
| 大文件上传中断 | 换更稳的网络重传；把大文件拆分后再传 |
| 图片识别效果差 | 重拍让文字清晰、整题入框再传 |

## 六、一句话总结

绝大多数「用不了」都出在三层：**系统权限没给够 → 网络不稳 → 版本与资料对不上**。按这个顺序排查，解决不了的问题再去官方帮助中心（[kimi.com/help](https://www.kimi.com/help)）找对应条目。
