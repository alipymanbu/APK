## 一、先对规格：能传什么、上限多少

| 项目 | 规格 |
| --- | --- |
| 支持格式 | PDF、Word、Excel、PPT、TXT、图片、视频 |
| 单文件大小 | 不超过 100M |
| 单次会话文件数 | 最多 50 个 |

超了上限会直接传不上去，处理办法见文末「文件传不上去」一节。这一层信息官方帮助中心有明确说明，不用自己试错。

## 二、一次会话吃下多份资料的步骤

1. 进入对话，点输入框旁的附件/文件入口；
2. 从手机里逐个选中要处理的文件（或一次多选），等上传完成；
3. 用一句话说明你要对这批文件做什么，例如「对比这三份合同的违约条款差异」「从这批发票里整理出一份按月汇总的表格」；
4. 对结果继续追问，比如「第二份里关于交付时间的条款原文是什么」。

多文件的收益在于**跨文件提问**：单独读一份文档用任何工具都行，但「把 50 个文件放在同一个会话里互相对照」是这一类用法真正的价值点。

## 三、长文摘要、翻译与答疑的问法

同一个文件，问法不同得到的产出差别很大。几个可以直接抄的句式：

| 目的 | 提问句式 |
| --- | --- |
| 快速判断值不值得细读 | 「用 300 字概括这份文档的核心结论，并列出 3 个我最该注意的点」 |
| 章节级精读 | 「第 3 章在讲什么？把关键数据单独列出来」 |
| 定位信息 | 「这份合同里关于付款周期的条款在哪些段落，原文贴出来」 |
| 长文翻译 | 「把这份 PDF 翻译成中文，保留段落结构，术语第一次出现时附原文」 |
| 做笔记 | 「把整篇文档整理成分级要点的学习笔记，公式和图表描述保留」 |

翻译和写作辅助属于官方明确列出的精选功能；「是否联网搜索」由应用根据你的问题自动决定，不需要你手动开关。

回答太浅时，把思考强度调高一档再问往往更有效，模型档位见[模型选择与思考强度](模型选择与思考强度.md)。

## 四、资料整理场景

把杂乱输入变成结构化输出，是文件功能的另一类用法：

- **会议记录**：上传录音转写或速记文本，让它按「决议 / 待办 / 责任人」输出一张表；
- **票据与发票**：拍照或扫描件上传，汇总成「日期 / 项目 / 金额」表格；
- **调研材料**：多篇网页长文或报告混传，输出一份带出处的对比清单。

整理类任务建议在提问时**直接规定输出格式**（表格列名、分几栏、按什么排序），返工次数会明显变少。

## 五、文件传不上去

按顺序查：文件是否超过 100M、会话内文件数是否到 50 个、格式是否在支持列表里。超过 100M 的大文件先拆分或压缩；格式不支持的就先转成 PDF/TXT 再传。安装或版本问题导致的上传异常，转到[常见问题与排查方法](常见问题与排查方法.md)处理；拍照片解题这类图片输入的用法，见[拍照解题与语音通话用法](拍照解题与语音通话用法.md)。
