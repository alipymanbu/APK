## 一、先弄清额度怎么消耗

官方把各会员功能（Agent 任务、深度研究、PPT、文档表格、图片生成等）放进同一个额度池，按任务实际消耗的 token 扣减，你可以自由分配。免费层级也有基础额度，官方给了一个大致参考：

| 任务 | 大致消耗 |
| --- | --- |
| 生成一份简单 PPT | 1~2% |
| 一次深度研究 | 5~10% |
| 编写一段代码 | 0.5~2% |

会话入口的 K2.6 模型：中文帮助中心写的是「可供所有用户免费使用、不消耗额度」，英文帮助中心同一条则写会消耗额度——两处官方口径不一致，以你 App 内的实际提示为准。

## 二、额度去哪看

| 端 | 路径 |
| --- | --- |
| 手机 App | 我的 → 会员计划 → 订阅 |
| 网页端 | [kimi.com](https://www.kimi.com/) 左下角头像 → 设置 → 订阅 |

能看到剩余额度百分比、下次刷新时间和最近的使用明细。开发票也在网页端订阅页的账单入口。

## 三、用完了怎么办

- 正在跑的任务会正常跑完，新任务才会提示额度不足；
- 额度按订阅周期按月刷新，当期没用完的清零、不结转；
- 等不及刷新就升更高档套餐，或留意官方活动的赠送额度。

## 四、套餐怎么选（截至 2026-09，以官方页面为准）

| 套餐 | 连续包月 | 官方定位 |
| --- | --- | --- |
| Andante | ¥49/月 | 日常使用 |
| Moderato | ¥99/月 | 效率升级 |
| Allegretto | ¥199/月 | 专业优选 |
| Allegro | ¥699/月 | 全能尊享 |

连续包年比包月划算（官方页标注最高立省 ¥1,680）。和手机端直接相关的一条：要在安卓手机上部署 Kimi Claw Android，需要 Allegretto 及以上档位。价格与权益会调整，订阅前以[官方套餐页](https://www.kimi.com/zh-cn/help/membership/membership-pricing)当时显示为准。
