# IPTV Pro 组播频道与 UDP 代理（udpxy）设置

> 运营商列表里那些 `udp://@239.x.x.x` 开头的频道，在手机上直接点大多黑屏——组播流需要局域网里有一个 UDP 代理把它转成 HTTP。本篇讲为什么要这么做、代理装在哪、应用里怎么填。

## 一、为什么组播频道点不开

运营商的 IPTV 频道常用**组播（multicast）**分发，地址形如 `udp://@239.x.x.x:port`。组播是「只在本地网络里广播」的传输方式：

- 手机、电视盒子这些设备通常收不了组播流，点开就是黑屏或报错；
- 官方给出的方案是在**局域网里装一个 UDP 代理**（如 udpxy），把 `udp://` 流转成普通 HTTP 流，设备就能播了。

所以先判断自己是不是这种情况：列表里大部分普通 `http://` 频道能看、唯独 `udp://` 开头的黑屏——基本就是缺代理。普通频道也全黑的话，问题在别处，见[播放卡顿与常见问题处理.md](播放卡顿与常见问题处理.md)。

## 二、代理装在哪

按效果和省事程度排序：

| 方案 | 说明 |
| --- | --- |
| 路由器（推荐） | 在 OpenWrt、DD-WRT 固件的路由器上安装 udpxy 插件；部分厂商原厂固件也内置了 udpxy，先翻一遍路由器设置页 |
| Linux 主机 / NAS | 在局域网里常开的 Linux 设备上装 udpxy，项目地址：[http://udpxy.com/index-en.html](http://udpxy.com/index-en.html) |
| Windows 电脑 | 开发者在自己的站点提供 UDP-to-HTTP 代理程序（`UdpProxy.exe`，见 [http://borpas.info/download/UdpProxy.exe](http://borpas.info/download/UdpProxy.exe)），或在安装同作者的 IP-TV Player（[http://borpas.info/iptvplayer](http://borpas.info/iptvplayer)）时勾选代理组件 |

代理监听的**端口以你启动它时的参数为准**（不同的固件和教程习惯不同），记下「代理设备的 IP + 端口」两个数，下一步要用。

## 三、应用里怎么填

1. 打开 IPTV Pro 的**设置**，找到 UDP 代理（UDP proxy）选项（不同版本菜单位置略有差异，以应用内实际显示为准）。
2. 填入代理地址，形式一般是 `http://代理IP:端口/udp/`，例如代理在路由器上、IP 为 `192.168.1.1`，就填 `http://192.168.1.1:端口/udp/`。
3. 保存后回到频道列表，再点 `udp://@239.x.x.x` 开头的频道——应用会自动把这类频道转走代理，不需要逐个改频道地址。

填对没填对，可以先在手机或电脑浏览器里验证：访问 `http://代理IP:端口/udp/239.x.x.x:port`（换成你列表里某个真实频道的地址），浏览器能出画面或开始下载流，说明代理这一环是通的，再回应用里点频道。

udpxy 还自带一个状态页：浏览器打开 `http://代理IP:端口/status/`，能看到代理是否在运行、当前有几个连接。排查时先看这一页，能直接区分「代理没起来」和「频道源的问题」——前者去修代理，后者找提供方。

## 四、两个使用边界

- **只在家庭 / 运营商局域网内有效**：组播代理走的是局域网地址，你用手机流量、或在别的网络下访问不了家里的代理，这类频道自然看不了。在外面想看，得靠运营商提供的出网（单播）方式或回家里网络。
- **路由器性能**：组播转单播由路由器 CPU 承担，同时看多个频道、或路由器本身性能弱时可能出现卡顿，表现和源的问题类似——先关掉其他设备上的播放再对比。

普通网络频道、Xtream Codes 频道与这套机制无关，它们的添加方式见[添加直播源与播放列表.md](添加直播源与播放列表.md)。
