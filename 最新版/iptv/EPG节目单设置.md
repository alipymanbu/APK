## 一、节目单数据从哪来

EPG（Electronic Program Guide，电子节目单）不是应用自带的，数据来自两个地方：

| 来源 | 说明 |
| --- | --- |
| 播放列表自带 | M3U 里每个频道带有 `tvg-id`、`tvg-name` 等字段，并在文件头部或链接参数里附了节目单地址。这种情况下你不用额外操作 |
| 服务商单独提供 | 服务商另给一个节目单链接，通常是 **XMLTV** 格式（一个 `.xml` 或 `.xml.gz` 文件的网址） |

IPTV Pro 支持 **XMLTV** 与 **JTV** 两种节目单格式。XMLTV 是现在的主流；JTV 是老格式，新服务商基本不再提供，见到多半是老列表。

另一个省事的路径：用 Xtream 账号登录的列表，节目单通常由服务器直接下发，一般不用手动填地址——这也是 Xtream 方式相对 M3U 的优势之一，详见[Xtream账号与M3U链接的区别.md](Xtream账号与M3U链接的区别.md)。

## 二、怎么把节目单加进去

1. 如果你的播放列表自带节目单，先什么都不做，等列表加载完看看频道右侧有没有出现「正在播什么」。
2. 没有的话，进应用的**设置**，找到 EPG / 节目单相关选项，把服务商给的 XMLTV 地址填进去（不同版本菜单位置略有差异，以应用内实际显示为准）。
3. 保存后回到频道列表稍等——节目单文件往往有几 MB 到几十 MB，首次解析需要几分钟，之后才有内容出现。

## 三、节目单不显示，按这个顺序查

1. **先确认链接本身是活的**：用浏览器直接打开那个 XMLTV 地址，能看到 XML 内容（或触发下载）就是通的；打不开就找服务商要新地址。
2. **频道和节目对不上号**：节目单是按 `tvg-id` 或频道名匹配的。列表里的频道没写 `tvg-id`、或者名字和节目单里的写法对不上，这一台就会空白——这是最常见的原因，换播放列表或换节目单源才能解决，应用侧无解。
3. **没等解析完**：大节目单解析慢，等几分钟再刷新。
4. **时间不对**：节目都在，但时间整体偏移几个小时，检查设备的系统时间与时区设置是否正确。
5. **多个节目单源互相干扰**：如果填过不止一个源，先只保留一个再试。

## 四、个别频道有节目单、大多数没有

典型的匹配问题：个别频道名字恰好和节目单条目一致，所以显示了；其余频道 `tvg-id` 缺失或写法不同。处理思路只有两个方向：

- 换一个和你的播放列表配套的节目单源（最好向列表提供方要「配套」的节目单，而不是随便找公共源）；
- 换一个字段写法规范的播放列表。

节目单以外的播放问题（黑屏、卡顿、加载失败）不在本篇范围内，见[播放卡顿与常见问题处理.md](播放卡顿与常见问题处理.md)；列表本身没加上的，回[添加直播源与播放列表.md](添加直播源与播放列表.md)。
