# IPTV Pro 里 Xtream 账号与 M3U 链接的区别

## 一、两种方式的本质差别

| | M3U 链接 | Xtream Codes 账号 |
| --- | --- | --- |
| 本质 | 一份文本格式的频道清单 | 服务器接口（API）登录 |
| 需要填什么 | 一段完整 URL | 服务器地址 + 用户名 + 密码 |
| 拿到的内容 | 通常只有直播频道列表 | 直播频道 + 电影（VOD）+ 剧集目录 |
| 海报、季集结构 | 一般没有 | 通常有 |
| 换设备重新配置 | 要抄下整段链接 | 记住三样信息即可 |

M3U 是一份「频道清单」文本，应用把它读进来逐条播放；Xtream Codes 是一套登录接口，应用拿着你的账号去服务器查询，能取到的不只是频道，还有电影、剧集的目录和详情。所以订阅里含电影 / 剧集时，用 M3U 方式经常「看不到」这部分——不是没有，是 M3U 清单里根本没带。

## 二、在 IPTV Pro 里的表现差异

- **Xtream 登录**：列表按**直播 / 剧集 / 点播**三组显示——官方从 2024 年起完整支持了这套接口；剧集可以加收藏（2024 年 11 月版本更新日志提到），看一半的剧集有「继续观看」按钮（2024 年 8 月版本提到）。
- **节目单**：Xtream 登录的列表，节目单数据通常由服务器直接下发，一般不用再手动填 XMLTV 地址（个别服务商除外）。
- **M3U 方式**：只有链接里带的那些频道；节目单要按[EPG节目单设置.md](EPG节目单设置.md)单独配置。

## 三、怎么选

- 只有直播需求 → M3U 够用，配置最简单。
- 订阅含电影 / 剧集 → 用 Xtream 登录，否则这部分内容拿不到。
- 服务商只给其中一种 → 没得选，按给的来。
- 两种都给了 → 首选 Xtream，M3U 留作备用——服务器接口抽风时切 M3U 还能看直播。

## 四、填写时的两个常见坑

1. **服务器地址要带协议头和端口**：完整写法是 `http://服务器地址:端口`，漏掉 `http://` 或端口是最常见的登录失败原因。
2. **账号有在线数和有效期限制**：登录失败先确认没有超出服务商给的同时在线设备数，再去服务商后台核对账号是否到期。
