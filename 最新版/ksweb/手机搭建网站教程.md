## 一、先认清各分栏的分工

主界面按组件分栏，各管一摊：

| 分栏 | 作用 | 要不要开 |
| --- | --- | --- |
| 状态 | 总览：局域网 IP、各服务运行情况 | 只看不动 |
| LIGHTTPD ／ NGINX ／ APACHE | 三种 Web 服务器，功能同类 | 三选一开启 |
| MYSQL | 数据库服务（另可选 MariaDB） | 跑 PHP 程序就开 |
| PHP | PHP 解析，版本可切 | 跑 PHP 程序就开 |
| FTP | 文件传输服务 | 想从电脑传文件再开 |
| 计划任务 | 类似 cron 的定时执行 | 按需 |

不需要同时开三个 Web 服务器，选一个开着就行；每个分栏里都有自己的开关、主机条目、配置文件与日志入口，后面排错时会反复用到。

## 二、跑第一个页面（五步）

以 lighttpd 为例，nginx、apache 步骤完全一样：

1. 在 LIGHTTPD 分栏点「开启服务」，状态栏出现已运行的提示；
2. 分栏里有一条主机记录，地址形如 `http://localhost:8080`（没有就点加号新建一条），点它会自动跳到浏览器；
3. 能打开页面就说明服务通了。地址末尾那串数字是端口，想换就进主机设置改；
4. 把一个 `index.html` 放进站点根目录（默认在手机存储的 `htdocs` 文件夹，主机设置里可以改路径），刷新浏览器就能看到你自己的页面；
5. 再验证一下 PHP：在 `htdocs` 里新建 `info.php`，内容一行：

```php
<?php phpinfo();
```

浏览器访问 `http://localhost:8080/info.php`（端口按你的实际为准），能看到 PHP 信息页，整条链路就通了。

一台手机想跑多个站：再加几条主机记录、各指一个不同的根目录就行，彼此互不影响。

## 三、PHP 版本怎么选

PHP 分栏里可以切换版本，从 5.6 到 8.5 有多个可选（以你装的包实际提供的列表为准）。两条经验：

- 跑老项目遇到兼容报错，切到项目要求的版本——老程序在 5.6/7.x 下往往更稳；
- 跑 WordPress、Typecho 这类主流程序，选 7.4 以上。

切换后重启一下 Web 服务器再验证。有的版本首次选用时要按提示补装组件，装完才会出现在可选列表里。

## 四、装一套 WordPress 或 Typecho

前面只是静态页，真正「建站」一般要装一套现成的 PHP 程序。WordPress、Typecho 的完整四步、数据库参数与装完常见的坑，已单独成篇：见 [WordPress博客搭建步骤.md](WordPress博客搭建步骤.md)。WordPress、Joomla、Drupal、MODX、Yii2 这些主流程序官方都提到可以跑，流程同构：放文件 → 建库 → 走安装向导。

## 五、局域网里其他设备也能访问

手机上的站，同一 Wi-Fi 下的电脑、平板直接访问 `http://手机IP:端口` 就能看，手机 IP 在「状态」分栏里。想让不在同一网络的人也能访问，是另一套做法，见 [外网访问与内网穿透.md](外网访问与内网穿透.md)。

访问不了先确认两台设备在同一个 Wi-Fi 下、端口没写错；还不行就去 [常见问题与故障排查.md](常见问题与故障排查.md)。
