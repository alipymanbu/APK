## 一、它是什么，什么样的手机能装

KSWEB 是 KSLABS 出品的安卓应用，装上之后手机里就有了 lighttpd、nginx、apache 三种 Web 服务器，外加 PHP、MySQL/MariaDB 环境，你可以在本机跑 WordPress、Typecho 这类 PHP 程序，也可以拿它当随身开发测试环境。官方页标注的组件版本如下（以官方页面当时显示为准）：

- lighttpd 1.4.82 ／ nginx 1.29.2 ／ apache 2.4.65
- PHP 8.5.1（可切换 8.4.13、8.3.27、8.2.29、8.1.33、7.4.33、7.3.33、5.6.40）
- MySQL 5.7.34 ／ MariaDB 10.4.34
- Web 管理界面、FTP 服务、代码编辑器、计划任务

对设备的要求（官方下载页口径）：安卓 7.0 及以上，ARM 或 Intel x86 的 64 位处理器。安装包本身就不小，装完还会在本地释放上面这些运行组件，给手机留足存储空间再动手。

## 三、安装步骤

1. 把 APK 转存到自己的夸克网盘，下载到手机；
2. 点开 APK，系统会提示「未知来源应用」，在弹出的设置页里允许你的文件管理器或浏览器安装应用（不同品牌的入口叫法略有差别）；
3. 等安装结束。**首次打开时还要在本地释放服务器与 PHP、MySQL 组件，需要一点时间，别中途杀掉应用**；
4. 同意存储权限：后面你要把网站文件放进手机存储，没有这个权限服务器读不到文件。

装完打不开、闪退这类问题，先看 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、试用期与许可，装之前先弄清

KSWEB 有 5 天试用期，之后继续用需要许可证。官方在购买页（[kslabs.ru/buy](https://kslabs.ru/buy)）卖序列号，分两档：

| 档位 | 包含 |
| --- | --- |
| Standard | lighttpd + MySQL + PHP 基础环境 |
| PRO | 在 Standard 之上，另有 nginx、apache、计划任务、PHP 版本切换、composer 支持、带语法高亮的编辑器、端口转发管理 |

两档官方都按终身许可（lifetime）售卖，注册支持 v2.7 及以上、PRO 功能需要 v3.1 以上——上面这份 4.07 在支持的版本范围内。买的话有两条路：Google Play 版在应用内直接付费；用不了 Google Play 结算的，可以从官网购买页买序列号、付款后发到邮箱，但官方注明官网序列号只对从官网下载的版本有效，包来源与序列号的对应关系以官方购买页当时的说明为准。试用期结束后具体限制成什么样，官方没有逐条写明，以你设备上的实际表现为准——建议 5 天内把要用的功能全试一遍再决定。

## 五、装完先做这几件事

- 打开主界面，认识一下各分栏：状态、LIGHTTPD、NGINX、APACHE、MYSQL、PHP、FTP、计划任务；
- 在「状态」分栏记下手机在局域网里的 IP，后面局域网访问要用；
- 挑一个 Web 服务器（一般 lighttpd 或 nginx 就够），点「开启服务」，确认状态栏显示已运行；
- 跟着 [手机搭建网站教程.md](手机搭建网站教程.md) 把第一个页面跑起来。
