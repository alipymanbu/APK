## 一、把数据库服务开起来

MYSQL 分栏里点「开启服务」即可。程序包里同时带 MySQL 与 MariaDB 两套数据库（官方页标注版本为 MySQL 5.7.34、MariaDB 10.4.34，以你装的包实际为准），日常跑网站用哪套都行，装 PHP 程序时填的连接信息相同。

默认连接参数，装程序、连库时都会用到：

| 项目 | 默认值 |
| --- | --- |
| 主机 | `127.0.0.1`（或 `localhost`） |
| 端口 | `3306` |
| 用户名 | `root` |
| 密码 | 空 |

## 二、phpMyAdmin 从哪来

phpMyAdmin 没有直接打进安装包：在主界面点 phpMyAdmin 入口，第一次会提示在线下载安装，网速慢就多等一会儿或换个网络再试。装完它会问你要挂在哪个 Web 服务器下，选你已经开启的那个，对应分栏里就会多出一条 phpMyAdmin 的主机条目，点开就是管理界面。

在线安装一直失败的话，还有个手动路子：自己从 phpMyAdmin 官网（[www.phpmyadmin.net](https://www.phpmyadmin.net/)）下载压缩包，解压到站点根目录下的一个子文件夹，浏览器直接访问那个目录就能进登录页——这条路要自己核对配置文件里的数据库连接参数，比界面安装费事（老教程里的常见做法，版本不同细节有差异）。

## 三、登录与改密码

初始账号 `root`、密码为空，直接登录。**登录后第一件事就是给 root 设个密码**——尤其是打算开外网访问的话，空密码的数据库暴露在网络上等于门户大开。

改密码两个路子，效果一样：

- phpMyAdmin 里：顶部「用户账户」→ root → 编辑权限 → 改密码；
- 或在 phpMyAdmin 的「SQL」标签里执行：

```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY '你的新密码';
```

改完别忘了一件事：把已经装好的 PHP 程序的配置文件（比如 WordPress 的 `wp-config.php`）里的数据库密码同步改掉，不然网站立刻连不上库。

## 四、建站常用的几个操作

装程序、迁老站时在 phpMyAdmin 里的对应位置：

| 你要做的 | 在哪做 |
| --- | --- |
| 建空数据库（装程序前） | 首页「数据库」标签 → 输名字 → 创建 |
| 导入已有站点数据 | 对应库 →「导入」→ 选 SQL 文件 |
| 备份数据库 | 对应库 →「导出」→ 快速导出 SQL |
| 新建数据库用户 | 「用户账户」→ 新增 |

装一套新程序只需要「建空数据库」这一步，完整流程见 [手机搭建网站教程.md](手机搭建网站教程.md)；从电脑上把老站搬过来，靠的则是导入/导出这一对操作。

## 五、连不上数据库的几个高频原因

- PHP 程序配置里主机写 `localhost` 连不上时，换成 `127.0.0.1` 再试（反之亦然）；
- MYSQL 分栏根本没开——先确认服务在运行；
- 改过 root 密码，但程序配置文件没跟着改；
- 端口改过，配置里还写着 3306。

服务整体起不来这类更基础的问题，统一看 [常见问题与故障排查.md](常见问题与故障排查.md)。
