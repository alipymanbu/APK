## 一、服务开了但网站打不开

按顺序核一遍：

1. 分栏里的服务开关确实是开的，状态栏显示「已运行」；
2. 地址和端口没写错——端口以主机条目里显示的为准，别凭记忆敲；
3. 浏览器用 `http://` 而不是 `https://` 访问，本地服务默认没有配证书，HTTPS 会直接连接失败；
4. 换个浏览器再试，排除缓存与插件干扰；
5. 还不行，对照 [手机搭建网站教程.md](手机搭建网站教程.md) 的五步流程从头再走一遍。

## 二、提示端口被占用

同一台手机上还有别的应用（或本机另一个服务）占着端口时，当前服务会起不来。两个办法：

- 把主机设置里的端口换成一个没被占用的（比如 8080 换 8081），最省事；
- 或者关掉占端口的那个应用，再启动服务。

## 三、手机息屏或放一会儿网站就断了

这是安卓省电机制杀后台导致的，不是服务本身的问题。处理：

- 应用设置里勾上「保护服务器被非授权终止」「锁定 Wi-Fi」，有省电相关选项也一并处理；
- 在系统设置里把这个应用的电池策略改成「不限制」。入口各品牌不同：以小米/MIUI 为例，设置里搜「电池」→「电量和性能」→「应用配置」，找到本应用选「无限制」；华为在「启动管理」里关掉自动管理；其他品牌找「电池优化」或「自启动」；
- 长期跑服务的，插着电源最稳。

改完观察一晚再下结论——有的品牌除了电池优化还有「深度休眠」，也要一并放行。打算让外网访问的，这步尤其关键，见 [外网访问与内网穿透.md](外网访问与内网穿透.md)。

拿旧手机长期当服务器用的话，第三方教程里的共同建议是：2GB 以上内存更从容、长期插电、连稳定的 Wi-Fi、对它解除所有限制——这套组合做齐了，服务莫名中断的概率会小很多。

## 四、PHP 页面白屏或 500

- 先把错误显示打开定位问题：在脚本开头临时加一行 `ini_set('display_errors', '1');`，刷新看报什么错；
- 老程序跑在新版 PHP 上白屏是最常见的组合，去 PHP 分栏把版本切到程序要求的版本（老项目经常要 5.6 或 7.x）；
- 程序缺扩展（zip、gd 之类）也会 500，按 PHP 分栏里的提示补装对应组件；
- 顺带一提：如果你在 PHP 7.3.33 上报 zip 扩展错误，确认应用版本在 4.04 以上——4.04~4.07 的更新说明里明确修了这个问题（见 [下载与安装教程.md](下载与安装教程.md) 的版本信息）。

## 五、phpMyAdmin 装不上或打不开

第一次点 phpMyAdmin 入口时要在线下载安装包，卡住多半是网络到源站慢：换 Wi-Fi 或流量再试一次。装好后要在弹出的选择里挂到一个已开启的 Web 服务器下，才会出现可点的主机条目——选了个没开启的服务器，自然哪里都找不到入口。完整流程见 [phpMyAdmin与数据库管理.md](phpMyAdmin与数据库管理.md)。

## 六、想找的功能在哪

几个容易翻不到的地方：

| 你想做的 | 位置 |
| --- | --- |
| 改服务端口、站点根目录 | 对应服务器分栏 → 主机设置 |
| 改配置文件（nginx.conf 等） | 对应分栏的「配置」入口，改完保存并重启服务 |
| 端口转发 / 路由 | Tools（工具）菜单 |
| 开 Web 管理界面 | Tools（工具）菜单 |
| 定时执行任务 | 计划任务分栏 |

其中计划任务、端口转发管理在官方购买页被列为 PRO 功能，试用期里都可以先试用再决定，档位差异见 [下载与安装教程.md](下载与安装教程.md) 的许可说明。
