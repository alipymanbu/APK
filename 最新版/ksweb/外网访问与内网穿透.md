## 一、先分清三种访问范围

| 范围 | 地址形态 | 要做什么 |
| --- | --- | --- |
| 只在手机上 | `http://localhost:端口` | 什么都不用做 |
| 同一 Wi-Fi | `http://手机IP:端口` | 用「状态」分栏里的局域网 IP |
| 任何地方 | 域名或穿透服务给的地址 | 公网 IP + 端口转发，或走内网穿透 |

绝大多数家庭宽带没有公网 IP，所以「任何地方」这一档，现实的做法基本就是内网穿透。动手之前，手机上得先有个跑着的站，还没跑起来的先看 [手机搭建网站教程.md](手机搭建网站教程.md)。

## 二、内网穿透工具怎么选

原理都一样：在手机和公网之间架一个中转，外面访问中转地址，流量转进你手机。常见选择：

- **花生壳**：有安卓客户端，图形界面操作，注册后添加 HTTP 映射、填手机 IP 和 KSWEB 的服务端口即可，免费额度有限制；
- **cpolar**：同类穿透服务，常见用法是在 Termux 里装客户端做映射，免费版给的是会变化的临时地址，多见于第三方教程的推荐；
- **ngrok / Cloudflare Tunnel**：命令行工具，一般在 Termux 里跑，免费额度够临时演示用，适合愿意敲命令的人；
- **路由器端口转发 + DDNS**：前提是有公网 IPv4，在路由器上把外部端口指到手机 IP 与服务端口，再用 DDNS 解决动态 IP 问题。

临时给客户演示个原型、自己远程看下数据，选哪个都行；要长期对外提供服务，优先考虑带宽与稳定性，并把下一节的安全加固做完。

## 三、开放之前，把这几件事做完

1. **改掉所有默认密码**：Web 管理界面（Tools 菜单里开启，默认 admin/admin）、数据库 root（默认空密码）、PHP 程序后台，一个默认值都别留；
2. **不用 80 端口跑 Web 服务**：KSWEB 不用 root 也能正常工作，唯独 80 端口需要 root 权限；对外用高位端口就好，省事也更安全；
3. **能不开的服务不开**：FTP、phpMyAdmin 这类只在内网用的话，别映射到公网——FTP 还是明文协议；
4. **检查防杀设置**：设置里把「保护服务器被非授权终止」「锁定 Wi-Fi」这类选项勾上（不同版本叫法略有差异），不然手机息屏省电把服务杀了，外面访问直接断。

改密码的具体操作见 [phpMyAdmin与数据库管理.md](phpMyAdmin与数据库管理.md)；服务莫名中断的排查思路见 [常见问题与故障排查.md](常见问题与故障排查.md)。
