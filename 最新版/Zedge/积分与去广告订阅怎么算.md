## 一、先分清：积分和订阅不是一回事

这两样在界面上都会出现，但作用完全不同，付错地方的情况很常见：

| | Zedge 积分（Credits） | 订阅（去广告） |
| --- | --- | --- |
| 解决什么 | 解锁单件 Premium 内容 | 去掉免费内容区的广告 |
| 计费方式 | 按件消耗，可零散买、可免费攒 | 按周期付费（周/月/年，以应用内显示为准） |
| 影响范围 | 只影响你解锁的那一件内容 | 影响全应用的广告展示 |
| 能不能替代对方 | 不能——买了积分也不去广告 | 不能——订阅了，Premium 内容照样要积分或看广告解锁 |

**最关键的一条：订阅去掉的是广告，不等于"全部内容免费"。** Premium 里由专业作者提供、已获授权的内容是单独解锁的，这部分不在订阅范围内。

## 二、积分怎么免费攒

不看不知道——积分是能纯靠时间攒出来的，不急用的话没必要先花钱：

1. **看激励视频。** 在积分入口点绿色的 Go 按钮，看完一条视频得 **10 积分**。每天可看的条数有上限，达到上限后按钮会变成 "Earn more tomorrow"（明天再来），第二天恢复。
2. **做问卷。** 应用里接入的是第三方调研平台的问卷入口，积分多少取决于问卷长短——越长的问卷给得越多，选中前会提示大概耗时。**不是每份问卷都能做**：通常先问几道筛选题，不符合条件会很快告知你退出，不会浪费你时间。
3. **订阅用户每周可领一次积分。** 已经在付订阅费的，别忘了去领这一份，长期下来能抵掉一部分内容开销。

两条实际提醒：

- **问卷没给积分要找谁**：问卷是第三方平台运营的，出问题（做完没到账、提示未记录积分）只能在该模块内的帮助入口提交工单给那边的支持，Zedge 本身处理不了这类问题。做问卷前建议先确认自己愿意提供的信息范围。
- **攒积分只对 Premium 有用**。免费内容区的东西本来就不需要积分，别为了攒积分去做一堆问卷。

## 三、积分怎么买、怎么花

**买**：在积分入口或内容页点开积分包，选档位后通过 Google Play 或 Apple 的应用内购买完成。档位越大单价越低，这个折扣关系在各档位的价格对比里能直接看出来。具体价格随时可能调整，**以应用内当页显示为准**，这里不写死。

**花**：

- 在内容页遇到标着积分价格的条目，点它就会打开积分入口；也可以直接点右上角的积分钱包查看当前余额。
- 有些 Premium 条目不用积分，看一条广告就能解锁——**先看这条能不能用广告换，再看积分**，能省下来。
- 内置的 AI 壁纸生成（pAInt）消耗的是 **Energy**，Energy 用积分兑换，兑换入口在 pAInt 界面右上角的钱包里。生成一张要花多少 Energy、多少积分，以那里显示的额度为准，做法见 [壁纸怎么下载与设置.md](壁纸怎么下载与设置.md)。

**充了没到账怎么办**：扣款成功但积分没增加，先保留商店的订单号，再从应用内的积分/购买帮助入口找官方那篇专门说明（官方确实为此单列了一条）。因为钱是走应用商店收的，最终对账要靠商店的订单记录。

## 四、订阅怎么取消

**官方明确说过：订阅由应用商店管理，Zedge 自己既不能取消、也不能改你的订阅。** 所以取消必须去商店里操作：

- **安卓**：打开 Google Play → 点右上角头像 → 付款和订阅 → 订阅 → 找到 Zedge → 取消订阅。
- **iPhone / iPad**：设置 → 点最上方的 Apple ID → 订阅 → 选 Zedge → 取消订阅。如果列表里没有 Zedge，多半是当前登录的 Apple ID 不是当初购买时用的那个，换回正确的账号再看。

两个容易吃亏的细节：

- **带免费试用的订阅，必须在试用期结束前取消**，否则试用一结束就自动按周期扣费。取消后一般仍可用到当期结束。
- **取消后广告回来了是正常的**，这不代表取消没成功；确认取消是否生效，看商店的订阅列表里状态是不是"已取消/到期不续费"，而不是看应用里还弹不弹广告。

## 五、订阅之后还在被推销订阅？

有一部分用户遇到过：已经付了去广告订阅，应用里仍然弹出让你订阅的提示。官方为此单独写了一条说明——这类弹窗通常来自免费内容区的推广位，与该订阅覆盖的范围有关，不是扣费失败。判断自己到底有没有订阅成功，仍然只看商店订阅列表里的状态；状态正常就不用重复购买。

要不要买，取决于你用得多不多：只用免费壁纸和铃声，积分攒着解锁偶尔想用的 Premium 就够；长期高频使用、又受不了广告位，再考虑订阅。钱花在哪一边，先回到第一节那张表对一遍。
