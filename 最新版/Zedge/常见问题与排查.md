# Zedge 常见问题与排查

> 本篇按"现象"组织：打不开、加载慢、下载失败、设了没生效、安装包装不上、被要求强制更新，各自先试哪一步、再试哪一步。

## 一、打不开、闪退、卡在启动画面

官方给出的快修顺序就三步，先照做，能解决大部分偶发问题：

1. **确认版本不是太旧。** 旧版本有时会被服务端拒绝，表现就是打开后进不去。
2. **从最近任务里彻底关掉再打开**，不是切到后台再切回来。
3. **重启手机。**

三步无效，再往下查：

| 现象 | 先查什么 | 处理 |
| --- | --- | --- |
| 点开就退回桌面 | 存储剩余空间 | 空间不足时应用无法建立缓存，清出一些后重试 |
| 启动画面停住不动 | 网络 | 断网状态下首次启动会卡在加载；换 WiFi 或换流量试 |
| 更新系统后开始闪退 | 应用版本 | 装一份新版覆盖安装，不必先卸载 |
| 偶发闪退、无规律 | 应用缓存 | 设置 → 应用 → Zedge → 存储 → 清除缓存（**别点"清除数据"**，那会清掉收藏与下载记录） |

## 二、加载慢、内容刷不出来

- 内容库在境外，**网络状况不好时列表加载慢属正常**，不是应用坏了。优先用稳定的 WiFi，并避开所在网络的拥塞时段。
- **单张图本来就很大。** 官方帮助中心明确解释过：高清壁纸的体积可以到 10MB 以上，在屏幕上显示得越精细，加载越慢。缩略图刷得出来、点开大图要等几秒，属于正常现象，不是卡死。
- 列表空白可以下拉刷新，或切到别的分区再切回来触发重新拉取。
- 只有个别分类刷不出来、其它分类正常，多半是那个分类在按你的屏幕与设备能力筛选后可选内容本来就少，不一定是加载失败。
- 关掉后台的省电类、网络加速类应用再试一次，这类工具经常把图片请求截断。

### 提示"服务器连不上、请稍后再试"

这条提示的意思是**应用没能连上服务器**，与你的手机本身没关系。官方对这类连接问题的说明很简短：先确认网络通畅；如果确认是自己网络没问题，那就是服务端侧的原因，只能稍后再试。

按下面顺序走一遍，多数情况在第一、二步就恢复了：

1. **确认网络真的通**：用浏览器打开任意网页验证一次，别只看信号格。移动数据下注意流量是否已用尽、是否被限速。
2. **从最近任务里彻底清掉应用再打开**，不是切后台。
3. **关掉 VPN 或代理再试。** 代理会把请求绕到别的出口，是这类连接失败的高频原因；如果你平时必须挂着代理，把它对 Zedge 的分流规则单列出来再试。
4. **检查是不是所有内容都连不上**：只是某个分区刷不出来，多半不是连接问题，而是该分类在你的机型上可选内容少。
5. **清一次应用缓存**（设置 → 应用 → Zedge → 存储 → 清除缓存），清完重开。
6. **重启手机**，复位网络栈。
7. 以上都试完仍然连不上，就按官方说的等一会儿再试——服务端出问题时，本机做什么都改变不了结果，隔一段时间再来验证一次即可。

## 三、下载失败、进度条卡住

1. **先看存储空间。** 视频壁纸这类内容体积明显大于静态图，空间紧张时最容易失败在这里。
2. **切换网络重试一次。** 移动网络下大文件被运营商限速或切网时容易中断。
3. **下载后"列表里找不到"**：到应用菜单里的 **收藏（Saved）**，看**第三个标签页**（已下载内容），东西通常在那里，而不是在相册里。这点与壁纸的存放位置有关，详见 [壁纸怎么下载与设置.md](壁纸怎么下载与设置.md)。
4. **反复失败的那一件，换同类别的另一件试。** 个别素材本身有问题时会一直失败，换一件能下说明是素材问题，不是你的网络。

## 四、壁纸设了但桌面没变

- **确认设的位置。** 选的是锁屏，看桌面当然没变化；换个方向再设一次。
- **裁切时不要放大。** 下拉预览里放大后，边缘会被裁掉，看起来"和预览不一样"。
- **第三方桌面可能拦下来。** 装了非系统自带桌面的，到那套桌面的壁纸设置里再确认一次。
- **部分国产系统会截走"设壁纸"这个动作。** 有用户反馈，小米/红米/POCO 这类机型的系统会把第三方应用的设置请求转到自带的主题与壁纸应用里，表现就是点了应用内的按钮跳去了系统界面、或者干脆没反应。这属于系统层面的限制，不是应用坏了——同类教程站点给出一致说法，但各系统版本的严格程度不同，**以你自己机型的实际表现为准**。可以按这个顺序试：
  1. 先在系统里给 Zedge 打开"修改系统设置"这类权限（设置 → 应用 → Zedge → 权限），再回应用里点一次设置。
  2. 不用应用内的按钮，改成长按桌面空白处 → 壁纸 → 从本地/我的里挑，走系统自己的那条路。
  3. 第三方桌面在用时，先切回系统自带桌面设一次，设成功后再切回来。
  4. 上面都不行，说明这个系统版本不允许第三方直接设壁纸，把这张图设成**锁屏**试一次（部分机型只拦桌面、不锁屏这条路）；仍不行就只能等系统更新放行，或用系统截图存下画面再从相册设——截图会损失清晰度，只当最后手段。
- **动态效果类壁纸设不上**，处理方式不一样，见 [动态壁纸会不会耗电.md](动态壁纸会不会耗电.md) 第四节。

## 五、铃声设了但不响

先做三次判断，基本能定位到原因：

- **去系统里确认当前值**：设置 → 声音 → 电话铃声，看显示的到底是不是新铃声；还是旧的，说明那次设置没生效，重设一次。
- **换一台手机打进来试**，别用同一个联系人反复试——给某个联系人设过**专属铃声**的，默认铃声对他无效，他打进来还是原来那条。这是最高频的误判。
- **确认没设错分区**：设的是通知音，来电自然不响；反之亦然。音量归零、开着勿扰也属于"没响"而非"没设上"。

以上都不是，就是系统没把音频收录进媒体库，处理办法（把文件移到 `Ringtones` 目录）在 [铃声与通知音怎么设.md](铃声与通知音怎么设.md) 第四节末尾。

## 六、安装包丢了、或者装不上

- **安装包被清理掉了**，或者转存的文件在网盘里误删了：回到 [Zedge 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9bb2c5696feb) 重新取一份即可，这份包是固定的。已经转存到自己网盘的，用转存的那一份下。
- **安装时报"应用未安装"**：常见三个原因——存储空间不足；**同包名已装过一个签名不同的版本**（例如之前从别的渠道装过 Zedge，必须先卸掉旧的）；下载的 apk 不完整（重下一遍，必要时核一下 MD5，值见 [下载与安装教程.md](下载与安装教程.md)）。
- **提示"不允许安装未知来源应用"**：这是安卓对非商店渠道的常规限制，按 [下载与安装教程.md](下载与安装教程.md) 第三节放行一次即可，之后不会再反复问。
- **装完打不开、或提示与设备不兼容**：先确认系统版本满足要求，判断方式见 [下载与安装教程.md](下载与安装教程.md) 第一节。

## 七、被要求强制更新，但不想更新

应用里会弹更新提示，官方帮助中心专门解释过这个机制（包括"为什么我被要求强制更新"这一条），也就是旧版本确实可能被要求升级后才能继续使用。

处理方式：

- 想继续用就**覆盖安装新版**，不需要先卸载，收藏与下载记录一般能保留。
- **不想现在更新、又不想丢数据**：不要在提示里选"卸载"之类的操作，直接退出应用即可；只是后续可能无法继续取用内容。
- 更新后如果内容变得很不一样，先确认是不是被装成了同一包名的另一个应用——用包名 `net.zedge.android` 核对，方法见 [下载与安装教程.md](下载与安装教程.md) 第一节。

## 八、提醒不弹、自动换壁纸停摆

多数是后台被系统清掉了，而不是应用问题：

1. 到 设置 → 应用 → Zedge → 电池，把省电策略改成**无限制 / 不优化**（各品牌叫法不同）。
2. 在自启动管理里**允许 Zedge 自启动**，否则每次清后台后它都不会自己回来。
3. 开了"深度省电""超级省电"模式的，退出该模式再观察——这类模式会冻结除白名单外的所有应用。

处理完观察一天：限定内容的提醒、自动轮换的壁纸如果都恢复了，就说明确实是后台被限。
