# Zedge 铃声与通知音怎么设

## 一、先分清三类声音

Zedge 的音频内容按用途分成互不相同的分区，找错分区是"下了一堆结果一个都没用上"的最常见原因：

| 分区 | 对应系统里的位置 | 什么时候响 |
| --- | --- | --- |
| 铃声（Ringtones） | 设置 → 声音 → 电话铃声 | 有人打电话进来 |
| 通知音（Notification Sounds） | 设置 → 声音 → 默认通知音 | 收到短信、APP 推送等 |
| 闹钟音（Alarm） | 时钟应用 / 设置里的闹钟铃声 | 闹钟到点 |

一个具体差别：**铃声通常 15~30 秒**，库里的列表上会标出时长；**通知音往往只有 1~5 秒**，短促、重复不刺耳。把通知音当来电铃声设，来电时你会觉得"响一声就没了"，反之则会拖得很长。

## 二、设为来电铃声：两步

1. 在音频列表里点开一条，先**试听**，确认是你要的那条，再点下载。
2. 下载完成后点**设为铃声**。多数安卓机会弹出一个选择框，让你选用途：来电铃声 / 通知音 / 闹钟 / 指定联系人。

如果**点了没弹选择框、或者系统直接跳到了别的地方**，说明系统不认这套接口，改成手动指定更稳：

1. 打开"设置 → 声音与振动"（部分机型叫"声音"）。
2. 点"电话铃声"，在列表里往下翻到"我的声音""设备上的音频""本地"这一类分组。
3. 找到刚下载的那条选中即可。

**菜单名称各品牌不统一**（"声音与振动""声音和振动""声音"都有），但层级都一样：系统设置 → 声音 → 电话铃声。官方帮助中心也明确说了，设备型号太多，他们不逐机型提供设置指引，所以遇到菜单找不到时，直接在系统设置的搜索框里搜"铃声"最快。

## 三、给某个联系人单独设一条

指定联系人的专属铃声要在应用里选**设为联系人铃声**，再挑联系人。首次使用会向你要**通讯录权限**——这是它唯一需要通讯录的场景，不给就只是用不了这个功能，其它功能不受影响。

两个容易踩的坑：

- 专属铃声**优先于默认铃声**。给家人设过一条专属的，之后换默认铃声，他打进来还是原来那条。想统一，得回到那个联系人的详情页里把专属设置改掉或清掉。
- 通讯录同步进来的联系人如果有重复条目（同一个人存了两张卡），可能只改到其中一条。出现"这个号码还是旧铃声"时，先去通讯录合并重复联系人。

## 四、设完不生效，按这个顺序查

"下载了、也点了设置，来电还是老铃声"的原因基本就那几个，按下面顺序一个个排除，比反复重设快：

1. **看设置里到底写的是什么。** 打开"设置 → 声音 → 电话铃声"，确认当前值已经是新铃声。如果这里还是旧的，说明刚才那一下没设上，重设一次。
2. **确认没设错分区。** 你设的是"通知音"还是"电话铃声"？两者在系统里是两个独立项，音频列表里也容易混。
3. **检查联系人专属铃声。** 用另一台手机打进来试，而不是拿同一个联系人反复试——很可能是对方的专属铃声盖住了默认。
4. **看音量与勿扰。** 媒体音量为 0、开了勿扰/静音，来电一样没声。这不是铃声没设上，是根本没响。
5. **重启一次手机。** 安卓的媒体库偶尔没及时收录新音频，重启后系统会重新扫描，铃声列表里就出现了。

前四步走完还是不行，说明系统没把下载的音频收录进媒体库。最直接的处理是绕过应用自己找文件：用文件管理打开手机内部存储，把刚下载的音频移到 `Ringtones` 文件夹（通知音移进 `Notifications`），再回铃声列表刷新一次——放在 `Download` 目录里的音频，系统常常扫不到。连文件都找不到时，按 [常见问题与排查.md](常见问题与排查.md) 第三节确认是否根本没下成功。

## 五、下载的音频存在哪、会不会丢

- **存在哪**：音频下载后是落到手机存储里的，会被系统媒体库收录，所以能在系统的铃声列表里被选到——这一点和壁纸不同（壁纸只在 Zedge 应用内部可见）。
- **换机不会跟着走**：设到系统里的铃声是系统设置的一部分，换手机后新机是出厂默认铃声。要还原，得在新机上重新下载、重设一次；登录账号后能从"已下载"里快速找回来，步骤见 [账号登录与换机迁移.md](账号登录与换机迁移.md)。
- **清缓存会不会清掉铃声**：已经设为**系统当前铃声**的那条音频，系统自己会保留一份，清掉 Zedge 的缓存不会让来电变回默认。但列表里其它已下载的音频可能就找不回来了。
- **自制或别处来的音频**：这类文件不归 Zedge 管，系统认不认它，只看它有没有放在系统会扫描的那两个目录里，判断方式见第四节最后一段。
