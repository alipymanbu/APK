## 一、先确认这一份包是哪个版本

Zedge 是一个手机美化类应用：里面是壁纸、视频壁纸、铃声、通知音和闹钟音，找到喜欢的可以直接设到手机系统上。它本身不用付费就能下载使用，真正容易卡住的只有两处——包从哪来，以及权限给没给对。

动手之前，先对着下表核一遍你手上这一份：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | Zedge |
| 开发主体 | Zedge, Inc. |
| 包名 | net.zedge.android |
| 版本号 | 8.64.3 |
| 安装包大小 | 82.16 MB |
| 安装包 MD5 | D734BCC2C716C0EDB76AF77655A917FC |
| 适用设备 | 安卓手机、安卓平板 |
| 是否需要联网 | 浏览、预览、下载内容都要联网；已经下好并设定过的壁纸与铃声，断网后仍留在手机里生效 |

**版本号要对得上，但别拿别处的版本号来对。** 搜索出来的版本号基本都是官方当前最新版，和这一份未必是同一个；换个来源、隔几周再下，版本号也会变。判断"我装的对不对"只看两项：包名是不是 `net.zedge.android`，版本号是不是上面的 `8.64.3`。

**系统要求以官方页面为准。** 官方帮助中心的安卓常见问题写明：Zedge 需要 Android 5 Lollipop 或更高版本。这条是长期口径，而新版应用有时会把门槛抬高，所以最稳的确认方式是在手机上打开 [Google Play 上的 Zedge 页面](https://play.google.com/store/apps/details?id=net.zedge.android)：显示"此应用与你的设备不兼容"就是装不上，能点"安装"说明版本够。真不兼容时系统会当场拦下，不会装到一半坏掉。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享。相比在搜索结果里随手点一个"立即下载"，从网盘转存再下载的好处是这条链接固定、文件不会被中途替换成别的东西。

1. 在手机上打开 [Zedge 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9bb2c5696feb)。手机浏览器和夸克 App 都能打开，**建议用夸克 App**——浏览器下大文件容易被切到后台打断。
2. 点"保存到我的网盘"，把文件转存到自己账号下。转存之后，后续下载就不再依赖原分享链接还在不在。
3. 进自己的网盘找到这个文件，点下载，等它落到手机存储里。
4. 下完核对两件事：文件名结尾是不是 `.apk`（这一份形如 `Zedge_v8.64.3.apk`）；大小是不是 82.16 MB 左右。差得多的多半是没下完整，删掉重来。

习惯在电脑上操作也可以：电脑端网盘下载后，用数据线拷进手机的 `Download` 目录，再从手机"文件管理"里点它安装，效果一样。

手上有校验工具的话，可以顺手算一遍 MD5，和上表的 `D734BCC2C716C0EDB76AF77655A917FC` 比一比。一致说明传输没出错，不一致就重下一遍。不查也不影响安装，这只是多一层保险。

## 三、安装：系统会拦一次，放行即可

这一份是手动安装的，不是从手机自带商店点"安装"装的，所以点安装包时系统会拦一下，提示"不允许安装来自此来源的应用"之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开"文件管理"，进 `Download`（下载）目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的"设置"，打开**允许安装此来源的应用**开关。
   - 部分机型要去"设置 → 应用 → 特殊应用权限 → 安装未知应用"里，找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独给它放行。
3. 回到安装界面点"安装"，等进度条走完。
4. 出现"打开 / 完成"时先点"完成"，把权限一次性理顺再进应用，比进去之后反复弹窗省事。

装的时候如果停在"正在安装"很久、最后报"应用未安装"，先看是不是存储空间不够，另一个常见原因是**同包名已存在一个签名不同的版本**（例如之前装过别处来的 Zedge），这时只能先卸掉旧的再装。区分办法与更多情形见 [常见问题与排查.md](常见问题与排查.md)。

## 四、首次打开：权限与初始设置

第一次打开时系统会依次弹权限申请。哪些该给、为什么，对照下表：

| 权限 | 用途 | 建议 |
| --- | --- | --- |
| 存储 / 照片和媒体 / 文件 | 壁纸和铃声要落到手机里才能被系统用上，不给就存不下、也设不了 | 必须给。给过想收回，去"设置 → 应用 → Zedge → 权限" |
| 通讯录 | 只有给某个联系人单独设专属铃声时才需要读联系人 | 可给可不给。拒绝只影响"指定联系人铃声"，其它照常 |
| 系统设置（修改系统设置） | 把下载的音频设成默认来电铃声要用到 | 建议给，否则每次设默认铃声都可能跳回系统设置手动选 |
| 位置 | 按你所在地区推荐内容 | 可给可不给。纯浏览、下载不受影响 |
| 通知 | 通知栏提示、限定节日内容的提醒 | 建议给。不给只影响提醒，不影响取用内容 |

官方在应用说明里写明：不会导入或使用你媒体库、存储和通讯录里的个人信息与文件；存储权限存在的唯一理由是"壁纸和声音总得有地方放"。若你在意权限，可以只给存储、其余全部拒绝，应用的主要功能照样能用。

进到主界面后，左上角（部分版本是侧边菜单）是内容分区：壁纸、视频壁纸、铃声、通知音。可以**先不登录直接用**，当游客浏览和下载免费内容；但游客状态下收藏与已下载内容只在这台机器上，换机就没了，要不要登录见 [账号登录与换机迁移.md](账号登录与换机迁移.md)。

## 五、装完先做三步自检

不用急着挑壁纸，先花一分钟确认三件事，后面遇到问题也好定位：

1. **能打开、不闪退**：点图标能进主界面并看到内容列表。反复闪退先按 [常见问题与排查.md](常见问题与排查.md) 里的顺序试一遍。
2. **能搜到、能预览**：在搜索框里输入一个常见的英文关键词（例如 `cat`），能出图，点开能放大预览。这一步同时验了网络与权限是否正常。
3. **能下载并设上去**：选一张壁纸下载，再用应用里的设置入口把它设成桌面或锁屏，回桌面确认真的换了。这一步过了，说明存储权限和系统设置权限都通了。

三步都过就可以正常用了。壁纸怎么分类找、怎么设主屏和锁屏，见 [壁纸怎么下载与设置.md](壁纸怎么下载与设置.md)。

## 六、升级与卸载要注意的

- **升级**：新版本会换一个安装包文件名，直接装新包覆盖即可，一般不用先卸载。**先卸载再装反而会把应用内的收藏和已下载内容清掉**——安卓默认连应用私有目录一起删。
- **卸载**：卸载会清掉本地收藏与下载记录。要留着，先在应用里登录账号（见 [账号登录与换机迁移.md](账号登录与换机迁移.md)），别指望卸载重装后它们还在。
- **被要求强制更新**：官方帮助中心专门列了"为什么我被要求强制更新 Zedge"这一条，说明旧版本确实会被要求升级。遇到这种提示时，回到文首那条 Zedge 安装文件资源的链接取一份新的覆盖安装即可。
- **安装包删了**：任何时候都能用文首那条链接重新取一份；已经转存过的不受原分享是否还生效的影响。
