## 一、先分清两条路线

登录后你面前有两条路：一是去探索页挑现成角色，成本低、聊上就聊；二是自己创建一个，从外观到性格都按你的想法来。探索页的入口和挑法在 [怎么登录与开始聊天.md](怎么登录与开始聊天.md) 已讲过，这篇重点讲第二条路，以及 2D、3D 两种形象的区别。

## 二、2D 形象：划卡匹配，快

2D 路线的玩法接近刷卡片：

- 应用会给一批 2D 角色头像图库，你通过滑动浏览、匹配，看对眼就点开。
- 2D 角色同样支持对话和场景扮演，可以进入校园、工作之类的互动场景。
- 已经匹配到的 2D 角色还能再编辑，调整形象风格与核心特质。

适合想快点开始聊、对外观细节没有执念的人。整个流程几分钟内就能进入对话。

## 三、3D 形象：从外观捏到性格

创建 3D 角色时，你能动的维度多得多：

| 定制维度 | 你可以设置的 |
| --- | --- |
| 外观 | 发型、五官等外观参数 |
| 服饰 | 服装搭配，后续可换装 |
| 性格 | 性格标签，决定说话风格 |
| 互动场景 | 日常、奇幻等场景模板 |

第三方应用市场的介绍提到风格模板数量有数千种，实际可选数量以应用内为准。捏好之后，3D 角色会以立体形象出现在对话里，你还能给它换装、调整性格。

## 四、关系定位与性格随时可改

角色和你的关系不是定死的。在角色的设置里可以自定义关系定位（比如朋友或恋人方向），性格特质也能随时调整。聊了一阵觉得角色太冷淡或者话太多，直接去改性格标签，比重新捏一个省事。

## 五、用得越久越贴合

角色会记录你聊过的话题偏好和互动反馈，逐渐调整回应风格；第三方介绍还提到应用会记住你提过的重要日期，让对话前后连贯。日常互动中也可能逐步解锁新的服饰与动作，属于长期使用的额外收益。

另外，部分互动形式和内容可能需要会员才能使用（比如语音消息、图像消息一类特权），动手前先看 [会员与免费功能区别.md](会员与免费功能区别.md)，确认你要的玩法在免费范围内还是需要付费。
