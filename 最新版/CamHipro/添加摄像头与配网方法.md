# CamHipro 添加摄像头与配网方法

> 本篇讲把摄像头加进 CamHipro 的三种配网方式，以及添加已在用的设备、删除设备的操作。

## 一、三条路线先分清

打开 CamHipro 点「添加设备」，界面会按设备状态分成两条路：从没用过网络或刚恢复出厂设置的选「新设备」，已经联网的选「使用中的设备」。新设备又有三种配网路线——接网线（最稳，推荐）、AP 热点、声波配网。你的摄像头走哪条，取决于它有没有网口、是什么形态，下面对照着选。

## 二、开始前的准备

- 给摄像头上电，等约 30 秒再开始添加，听不到提示音就多等一会。
- 大多数配套摄像头只连 2.4GHz WiFi，连不上 5GHz；双频路由器先把手机连到 2.4G 那个频段再配。个别双频摄像头同时支持 5GHz，以你的摄像头说明书为准。
- WiFi 名称与密码里避开 `@ # % &` 和空格这类特殊字符，带特殊字符的名称配网容易失败。
- 设备默认密码是 `admin`，添加时被要求输密码就先输它。
- 走 AP 热点配网前，先把手机的 GPS（位置信息）打开，否则搜不到热点。

## 三、方式一：接网线添加（推荐）

1. 把摄像头用网线接到路由器，确认已通电。
2. 手机连上同一个路由器的 WiFi。
3. CamHipro 点「添加设备」→「新设备」→「已连接网线」，App 会自动搜出当前局域网里的设备 UID。
4. 选中要加的 UID，点「添加」。接下来 App 会进入无线配置界面，选中你家路由器的 WiFi、输密码，点「配置 WiFi 并添加」。
5. 配置成功后回到设备列表，等设备显示在线。

暂时不想给它配 WiFi 的，点「不配置，直接添加」也能先把设备加上，以后再到设备设置里补配网。

## 四、方式二：AP 热点配网

适合不接网线、支持 AP 配网的设备（盒式、球机、部分云台机等）：

1. 摄像头只接电源，确认手机 GPS 已开。
2. CamHipro 点「添加设备」→「新设备」→「未连接网线」，选 AP 配网。
3. App 会搜附近摄像头的热点，名字形如 `IPCAM-XXXXXX`，默认密码 `01234567`（部分老批次热点名与密码不同，以摄像头说明书为准）。
4. 选中自家摄像头的热点连接，连上后回到添加界面点「添加」，进入无线配置，选路由器 WiFi、输密码，点「配置 WiFi 并添加」。
5. 成功后设备列表里等它上线。

## 五、方式三：声波配网

适合卡片机、灯泡机、小飞碟这类没有网口的小设备：

1. 摄像头上电，进入等待状态，会间歇发出「嘀」的提示音。
2. CamHipro 点「添加设备」→「新设备」→「未连接网线」，选声波配网，按提示点下一步。
3. 用手机扫设备机身上的 UID 二维码；机身没有二维码就点跳过。
4. 输入要配的 WiFi 密码，点「开始声波配网」，手机会把 WiFi 信息用声音传给摄像头。
5. 听到语音提示即配置成功，设备列表等上线。

声波配网时手机音量开到最大、环境保持安静，成功率明显更高。

## 六、添加一台已经在用的设备

摄像头已经联网（比如换手机、家人也要看）时，不用再配一次网：

- **搜附近添加**：手机和设备在同一 WiFi 下，点「添加设备」→「使用中的设备」→ 搜索附近设备，选中 UID，输设备密码（默认 `admin`，改过就输改过的），点添加。
- **远程凭 UID 添加**：人不在设备旁边也能加，前提是你知道设备的 UID 和密码。UID 在设备信息页能看到，形如 `xxxxx-XXXXXX-XXXXX`。
- **扫码添加**：用工具把 UID 做成二维码，再用 App 扫码添加。

家里人想一起看画面，把 UID 和设备密码给对方，让对方按上面方式添加即可。

## 七、删除设备与换网之后

- 删除：在设备列表长按要删的摄像头，或进设备设置点「删除设备」。
- 换了路由器或改了 WiFi 密码，旧配网就失效了：设备会显示离线。设备还在线时可以直接进设置改 WiFi，已经离线就要重置后当新设备重来，完整步骤见 [摄像头重新连接WiFi步骤.md](摄像头重新连接WiFi步骤.md)。
- 恢复出厂设置的设备同样要删掉重新添加；加不上、反复离线时，按 [设备离线与连接失败排查.md](设备离线与连接失败排查.md) 的清单逐项查。
