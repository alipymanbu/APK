# CamHipro 摄像头重新连接WiFi步骤

> 换了路由器、改了 WiFi 密码或搬了家，摄像头就要重新连网——本篇按「设备还在线」和「已经离线」两种情况给步骤。

## 一、先判断设备还能不能连上

改了 WiFi 之后，设备列表里那台摄像头大概率显示离线——它还在用旧的网络配置，连不上新路由器。处理路径取决于它现在的状态：设备居然还在线（比如你只是提前改了密码、旧密码还没生效），直接进设置改 WiFi；已经离线的，走重置重新配。先试第一种，不行再第二种。

## 二、设备还在线：进设置里改 WiFi

设备列表里还能看到它在线时，这是最省事的路：

1. 点设备进设置，找「WiFi 设置」（或「网络设置」）。
2. 点 WiFi 管理，选中新路由器的 WiFi 名称，输入新密码。
3. 点确认（或 Apply），等设备自己连上新网络，列表里它保持在线就是成了。

这条路不需要碰摄像头本体，也不丢已设的报警、录像计划。

## 三、设备已离线：重置后当新设备配

连不上就改不了设置，只能重头配网，完整流程三步：

1. **重置摄像头**：长按尾线上的 RESET 键听到提示音，等约 1 分钟重启完成（细节见 [设备离线与连接失败排查.md](设备离线与连接失败排查.md) 第四节）。
2. **从 App 里删掉这台设备**：设备列表长按它，或进设置点删除设备。
3. **当新设备重新配网**：按 [添加摄像头与配网方法.md](添加摄像头与配网方法.md) 走一遍——有网口的接网线添加最稳，没有的走 AP 热点或声波配网。

重置会把设备密码也清回默认 `admin`，重新添加时记得设一个新密码。

## 四、新 WiFi 一次配过的几个前提

重连前把这几件事核对好，能省掉第二次重置：

- 新路由器开着 2.4GHz 频段——多数配套摄像头连不了 5GHz，双频路由器两个频段最好用不同名称。
- WiFi 名称与密码里没有 `@ # % &`、空格这类特殊字符。
- 配网时把摄像头放在路由器几米内，配成功再挂回安装点。
- 走 AP 热点配网时手机的位置信息（GPS）是打开的。

都核对过还是配不上，按 [设备离线与连接失败排查.md](设备离线与连接失败排查.md) 第三节逐项查。
