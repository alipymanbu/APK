## 一、装之前先看这段

CamHipro 是深圳市海芯威视科技有限公司的网络摄像机管理软件，配合采用海芯（Hichip）方案的网络摄像头使用，你在手机上看实时画面、回放录像、控制云台。本篇按安卓版 3.1.80 的安装包讲获取与安装：先核对安装包信息，再从网盘转存安装文件，最后装进手机并开好权限。iOS 端请在 App Store 搜索 CamHipro 安装，不在本篇展开。

## 二、安装包信息（先核对再装）

| 项目 | 内容 |
| --- | --- |
| 版本 | 3.1.80 |
| 包名 | `com.hichip.campro` |
| 安装包大小 | 73.49 MB |
| MD5 | `4C6F3A6637E92A9215729B740043B4F2` |
| 系统要求 | 安卓 5.2 及以上 |
| 开发者 | 深圳市海芯威视科技有限公司 |

官方渠道也能装到这个应用：安卓端有 [Google Play 上的 CamHipro 页面](https://play.google.com/store/apps/details?id=com.hichip.campro)（版本以页面当时显示为准），iOS 端在 [App Store 的 CamHipro 页面](https://apps.apple.com/cn/app/camhipro/id1420815722)。各渠道版本更新节奏不同，装哪个版本取决于你拿到手的是哪份安装包。

## 三、获取安装文件

1. 打开上面的 [CamHipro 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c71401706e6b)。
2. 把里面的 APK 文件转存到自己的夸克网盘，再用夸克客户端下载到手机，或先下到电脑再传给手机。
3. 下载完可以先核对一下文件大小是否约 73.49 MB，与上面表格对得上再安装。

## 四、安卓安装步骤

1. 在手机文件管理里找到下载好的 APK，点它开始安装。
2. 如果系统提示「禁止安装未知来源应用」，到系统设置里搜「安装未知应用」，给你用来打开 APK 的那个应用（文件管理或浏览器）授予权限，再回来继续。
3. 装完先别急着加摄像头，首次打开 CamHipro 时会弹权限申请，按下面这张表决定给不给：

| 权限 | 不给的后果 |
| --- | --- |
| 蜂窝数据与 WLAN | 搜不到、加不上摄像头 |
| 通知 | 摄像头侦测到移动时手机收不到报警推送 |
| 麦克风 | 用不了语音监听和对讲 |

## 五、装好之后

下一步是把摄像头加进 App：拿起摄像头的说明书看看它支持哪种配网方式，然后照着 [添加摄像头与配网方法.md](添加摄像头与配网方法.md) 操作即可。设备上线后，[实时画面与云台操作.md](实时画面与云台操作.md) 讲日常怎么看、怎么转。
