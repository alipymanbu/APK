## 一、先分清是环境还是设备

komoot 靠手机的 GPS 芯片定位。以下情况造成的短暂精度下降是**正常的**，别急着查设置：

- 恶劣天气；
- 高楼密集的城区；
- 隧道、岩壁、深谷；
- 密林遮挡。

另外不同手机的 GPS 芯片与传感器不一样，**同一段路两台手机录出来就是会有细微差别**——这也不是 bug。

测试定位时先去**开阔地**、抬头可见天空，给手机几秒锁星（多云天会更慢）。还有一类容易忽略的干扰源：**磁吸手机壳、支架、车把夹**——磁铁会影响定位与传感器，摘了再试。

## 二、定位获取不了 / 导航起不来

按顺序做，做到哪步好了哪步停：

1. 系统设置里，komoot 的**定位服务**是否开启、权限是否正确。
2. 有「高精度定位模式」就打开它。
3. 去开阔地等几秒，等 GPS 锁定。
4. 把 komoot 的**电池优化 / 省电限制**关掉。
5. 重启手机，重置 GPS 芯片。
6. 确认手机存储空间充足——空间不够，App 存不下记录数据。

安卓权限细节：设置 → 应用 → komoot → 权限 → 位置 → **始终允许**（没有就选「使用应用时」），并开 **使用精确位置**；位置服务里的 Google 精确定位（FUSE）也建议开着。

## 三、GPS 点不动 / 记录冻结 / 屏幕一关就停

这类问题多半出在系统的后台与省电策略上。挨个检查：

**通用安卓**

- 设置 → 应用 → komoot → 电池 → **不受限制（无限制）**，避开「优化」「受限」。
- 设置 → 应用 → komoot → 确认**后台活动**被允许。

**三星**

- 设置 → 设备维护 → 电池：确认 komoot 不在「闲置应用睡眠」与「深度睡眠应用」列表里。
- 关闭「自动优化 / 定时优化」，或设成不用 komoot 的时段跑。

**小米**

- 安全中心 → 应用管理 → komoot → 省电策略 → **无限制**。

**华为**

- 设置 → 应用 → 应用设置 → 特殊访问权限 → 忽略电池优化 → 允许 komoot。
- 设置 → 应用 → komoot → 电池 → 「手动管理」里全开。
- 关掉「电量消耗提示」（若有）。

改完重启 App 再录一段验证。若记录的轨迹在地图上看着歪、拐弯被切角，先**校准罗盘**：打开 Google Maps 或任意指南针 App，把手机按「8」字形挥几圈，再回 komoot 试。

## 四、轨迹在地图上不准 / 保存后看不到位置标记

- 轨迹形状怪 → 按上一节校准罗盘；带磁吸壳的先摘壳。
- 保存的活动里位置标记消失 → 先确认这台设备定位正常，再重新打开该活动；仍异常属个案，带截图找官方支持。
- 活动记录明显不合理（比如徒步跑出 150 km/h 的瞬时速度）是 GPS 抖动，官方在 2026 年的版本里加了速度平滑处理——把 App 升到最新版。

## 五、整个 App 都不对劲时的基础排查

定位之外的问题（打不开、不同步、界面异常）走这套通用流程：

1. 重启 App（从后台彻底划掉再开）。
2. 重启手机。
3. 换网络试试——Wi-Fi 与流量互切。
4. 关掉 VPN、代理、防火墙、广告拦截、自定义 DNS 或安全软件，或给 komoot 加例外。
5. 确认 App 与手机系统都更到最新版。
6. 退出登录再登回——**先确认记录已全部上传**：退出与重装都可能让未同步的活动**永久丢失**。在电脑上打开 [www.komoot.com](http://www.komoot.com) 看最新路线都在，再动登录。

登录本身出问题（邮箱拼错、登进了另一个账号、区域和路线突然不见），多半是账号对不上——先核对 个人资料 → 设置 → 里的邮箱与 komoot ID 是不是你原来那个，详见 [下载与安装教程.md](下载与安装教程.md) 第四节。

## 六、还没解决

以上做完仍复现，就该给官方支持递证据了：设备型号、系统版本、出问题的路线/活动、报错截图，以及你已经试过哪几步——一次性给全，省两个来回。
