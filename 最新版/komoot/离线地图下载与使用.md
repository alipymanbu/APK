# komoot 离线地图下载与使用

## 一、先记住这条总则

komoot **没有一个全局的「离线模式」开关**。所有离线内容都得你提前下好——要么单条路线，要么整块区域地图。没提前下，进山就是一张白图。官方建议用稳定的 Wi-Fi 下载，别在山上用流量补。

另外：区域与路线**只能在手机 App 里下载，网站下不了**。

## 二、下载单条路线

只跑固定一条线，下路线就够：

1. **个人资料 → 已保存路线**，选中要离线的那条。
2. 点 **下载（Download）** 或 **离线保存（Save offline）**。
3. **还在网上的时候**，把这条路线再打开一次，让 App 把没同步完的数据同步完、确认打开没有警告。
4. 断网再打开一次验证——能正常打开才算下成。

如果它提示「Offline data not synchronized」，说明同步没完成，回到有网环境重新走一遍第 3 步。

## 三、下载区域地图

想在没规划的区域随手记录、临时改线，光下一条路线不够，要把整块地图下下来：

1. **个人资料 → 地图（Maps）**。
2. 找到目标区域，点旁边的 **下载**。

你能下哪些区域，取决于你有什么权限：

| 你的账号 | 可下载范围 |
| --- | --- |
| Premium 或 World Pack | 「推荐」区域随便挑，也可搜索地球上任意可用区域 |
| 买了单区 / 区域包 | 在「已解锁」列表里下你买过的那些 |
| 只有免费单区 | 只有那一个区域 |

下之前把**起点到返回的整段**都框进去——只下中间一段，两头照样没图。

## 四、自定义区域（Premium / World Pack）

预设区域的边界不合用时，可以自己圈一块：

1. 入口二选一：打开地图点右上角**橙色离线按钮**（一朵带斜线的云）；或 **离线 → 区域 → 下载区域 → 下载自定义区域**。
2. 拖动缩放，让你要存的那块填满屏幕。
3. 起名 → **确认**。

已存过的区域会以紫色覆盖显示，方便你避开重复、把几块拼成一条长线的走廊。注意：自定义区域下载**需要 Premium 或 World Pack，且 App 得是最新版**；单区与区域包不含这个能力。

## 五、有些区域下不了——但不是没法用

部分区域在 App 里搜得到、却没有下载按钮，两个原因：应用商店在某些国家/地区限制了区域下载的售卖方式；或该区域根本没有预设下载包。检查方法：**个人资料 → 地图** 里搜那块地方，没有下载选项就是没有。

没有预设下载包时：有 Premium / World Pack 就用第四节的自定义区域兜底；什么都没有，你**仍然可以**在离线状态下用这块区域做定位定向与轨迹记录——只是没有完整离线导航那套。

## 六、离线了就用不了的东西

- 没提前下载的内容，离线时就是出不来。离线状态下保证的只有两件事：**已下载的路线能导航、已下载的区域有图**。
- 语音导航的前提不变：该路线**起点区域必须已解锁**（见 [下载与安装教程.md](下载与安装教程.md) 第五节）。
- 所以动作只有一个字：提前。用 Wi-Fi 下完、按第二节断网验证过，再出门。

## 七、安卓侧的三个保底设置

系统默认的省电策略会拦后台、拦定位、拦流量，出远门前把这三处设好（各品牌细化项见 [GPS定位与导航问题排查.md](GPS定位与导航问题排查.md)）：

1. **定位权限**：设置 → 应用 → komoot → 权限 → 位置 → 选 **始终允许**（没有「始终」就选「使用应用时」），并打开 **使用精确位置**。位置服务里把 Google 的精确定位（FUSE / Google Location Accuracy）也开着，能提升导航时的 GPS 精度。
2. **电池**：设置 → 应用 → komoot → 电池 → 选 **不受限制 / 无限制**，别用「优化」或「受限」；同时确认「后台活动」是允许的。
3. **移动数据**：设置 → 应用 → komoot 里允许用流量——否则你在外面点下载会毫无反应。App 内的数据偏好在 个人资料 → 设置 → App 设置 里调。

改完这三处，再回头把第二节的「断网验证」做一遍，出门才算稳妥。
