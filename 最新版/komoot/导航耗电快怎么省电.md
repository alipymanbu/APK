## 一、先把预期摆正

GPS 全程连着 + 屏幕常亮 + 实时算路，导航本来就是手机上最耗电的一类用途，**省不掉、只能压**。官方给的思路按收益排序是：先砍屏幕，再砍后台与网络，最后才调定位模式。下面每条都能单独做，按顺序来收益最大。

## 二、砍屏幕：最大的那一块

- **靠语音，不靠盯屏**。逐向语音导航开着，屏幕能黑就黑，别每分钟掏出来看一眼。
- **亮度压到能看清为止**，并把熄屏超时调短。
- **导航时别开别的**：后台应用、边听歌边导，都是在跟 GPS 抢电池。
- 安卓有个 **「唤醒屏幕（Wake up screen）」** 开关：导航中屏幕底部面板里打开——转向提示到来时屏幕自动亮一下，提示完就灭，不用一直亮着。iOS 没有这个功能。

## 三、砍后台与网络

- 把用不上的账号与 App 的**后台同步**关掉。
- 不需要实时更新的功能别开着——**Live Tracking 就是典型**：官方实测它比不开大约多耗 **1% / 小时**，不需要就关（它是干什么的见 [路线分享与组队活动.md](路线分享与组队活动.md) 第四节）。
- 不用网络时把**移动数据与 Wi-Fi 关掉**（前提是路线与地图已按 [离线地图下载与使用.md](离线地图下载与使用.md) 提前下好），流量模块的持续搜索很费电。

**关于系统省电模式，官方两篇口径要一起看**：省电建议一篇让你开手机的省电模式；但「记录中断」一篇明确交代 **iOS 在录制/导航期间别用低电量模式**——它会限制后台活动与 GPS。两篇并存，实操取舍是：**能不用低电量模式就不用**，优先靠砍屏幕、关网络这些不伤定位的手段；手机确实撑不住时，安卓侧用系统省电、iOS 侧宁可靠飞行模式与充电宝。

## 四、离线 + 飞行模式：一次全省

把路线与区域地图提前下好（步骤见 [离线地图下载与使用.md](离线地图下载与使用.md)），上路后直接开**飞行模式**——移动网络、Wi-Fi、蓝牙一起断，省电效果立竿见影。注意飞行模式下要确认 **GPS 仍处于激活状态**（飞行模式断的是通信，不是定位）。

代价是这些功能**在飞行模式下不可用**：

| 不可用 | 说明 |
| --- | --- |
| 自动重新规划 | 偏离路线后不会自动给你改线 |
| 规划新路线 | 出发前把线画完 |
| 编辑路线 | 同上 |
| Live Tracking | 需要联网，开了也推不出去 |

所以飞行模式适合「线已定好、只跟走」的场景；要边走边改线的，留着流量、改用其他几条省电招。

## 五、定位模式与 FUSE

- 系统定位模式如果可选，**「仅限设备（GPS）」**比持续调用 Wi-Fi + 流量的高精度模式更省电——代价是定位精度与搜索速度可能下降，市区高楼间尤其明显，郊野差别小。
- 安卓 App 内还有一项 **FUSE 定位源**：个人资料 → 设置 → 导航（Navigation）→ 打开 FUSE location source。它混合 GPS 与别的信号定位，通常比纯 GPS 略省，官方建议日常开着（iOS 无此选项）。
- 系统侧的 Google 精确定位（Google Location Accuracy）是另一回事，它影响的是**精度**——要精度就开着，见 [GPS定位与导航问题排查.md](GPS定位与导航问题排查.md) 第二节；两项不冲突，按「郊野求省、城区求准」自行取舍。

## 六、长线的兜底方案

再怎么省，连续导航几小时的多日行程也会把手机榨干——官方对长活动的建议就一条：**带充电宝**，别赌续航。出发前把电充到 100%、导航中尽量不边充边用（充电本身也发热），是比任何设置都实在的准备。

顺带一提：手机发烫时先摘壳、避免太阳直射、别捂在包里——发热会触发系统降频与高温保护，导航跟着卡。这些是手机的通用行为，不限于 komoot。
