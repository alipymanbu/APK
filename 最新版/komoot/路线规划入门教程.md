# komoot 路线规划入门教程

> 从零在手机 App 里规划一条能直接导航的路线：选运动类型、定起终点、加途经点、处理没路的地方。

## 一、从哪进入规划器

打开 App → 底部菜单选 **路线（Routes）** → 点 **+ 规划新路线（Plan new）**。安卓上这个按钮有时要先把顶部的绿色横幅往下拖才露出来。

进去后先设三件事：运动类型、配速、路线类型。这三项决定 komoot 给你选什么路，改一次全图重算。

## 二、运动类型：选错了路就不对

运动类型决定两件事：选路时偏好哪类路面，以及地图上显示哪些红色 Highlight 标记。可选项按官方口径：

| 类型 | 选路偏好 |
| --- | --- |
| 徒步 | 小径、自然步道 |
| 公路自行车 | 柏油路为主 |
| 山地自行车 | 单Track 林道、土路 |
| 砾石自行车 | 砾石路 |
| 跑步 | 适跑路面 |
| 旅行自行车 | 平稳铺装路 |
| 登山 | 登山路线 |

骑行类多一个 **E-Bike** 复选框：勾上后，时长与难度估算按电助力车算——同一段爬坡，勾与不勾的预计时间差很多，骑电助力就勾上。

## 三、配速与体能：只改时间，不改路线

- **配速（Pace）**：规划阶段设定你的预期速度，预计用时按它算；中途改配速会自动重算平均速度与到达时间。
- **体能（Fitness）**：五档里选一档，只调整预计时间与均速，**不会给你换一条路线**。

所以「预计 3 小时」不准的时候，先怀疑这两项设置，而不是怀疑路选错了。

## 四、单程还是往返

路线类型二选一：

- **单程（One way）**：A 到 B。适合分段走、或打算坐公共交通返回的行程。
- **往返（Round trip）**：从出发点原路规划回来。不想要原路返回，就用途经点把回程掰开。

## 五、定起终点

最少要两个点：起点和终点（它们是路线的前两个途经点，后面随时能移动、能调序）。设点的途径任选：

- 搜索地名或地址（放大镜按钮）；
- 用当前定位；
- 选你存的家庭地址；
- 选一个 Highlight（地图上红色标记的社区推荐点）或兴趣点（停车场、住宿、公交、泳池、公园等）；
- 直接点地图上的任意位置。

想快速画一条单程线：点地图上起点 → **从这里开始**；点终点 → **设为终点**。之后再点地图上的点，可以选「加入路线」或「设为新终点」。

## 六、用途经点掰路线

komoot 自动给的线往往不合心意，途经点就是你掰它的工具：

1. **加**：点地图上任意位置 → 选「作为途经点」；或在途经点列表里点「添加途经点」用搜索加。
2. **排**：打开途经点列表（菜单 ⋮ → 查看途经点列表），按住拖动手柄上下换序——顺序直接决定路线走向。
3. **删**：点中地图上的点，或点列表里它旁边的 ✕。

列表里能看见起点、编号途经点、终点的完整顺序，改完路线立即重算。

## 七、进阶两招

**按坐标定点**。手上有别处导来的 GPS 坐标，直接把坐标粘进搜索框，三种格式都认：十进制度（`52.520817, 13.409450`）、度分、度分秒。地图上没名字、没人标过的地方，只能这么放点。

**离网段（off-grid）**。komoot 默认只沿已有路网选线；点一个点 → 关闭 **跟随道路（Follow ways）**（安卓）或勾选 **设为离网段**（iOS/网页），这段就变成两点间的**直线虚线**，无视现有道路。适用场景：你知道有条没被地图收录的可通行小路，或者要过河、切开阔地、直上一个坡。

**注意**：离网段 komoot **不保证可通行也不保证安全**——地图数据可能不全，现场情况会变。用之前自己核对当地条件、带上基本导航能力，别把虚线当承诺。

## 八、保存与开始导航

规划完点保存、起个名字，这条路线就进你的已保存路线了。用它导航：

1. **个人资料** → **已保存路线** → 选中那条 → **导航（Navigate）**。
2. 前提：**路线起点所在区域必须已解锁**（见 [下载与安装教程.md](下载与安装教程.md) 第五节，注册送的那个免费区域就是干这个的）。
3. 你不在起点时，App 会视距离与网络给你指路到起点，或让你调外部地图 App 过去；没弹出来就手动用路线页的 **获取路线**。

导航中屏幕下方的面板可左右滑切换数据（下一点距离/速度/剩余时间/海拔/天气），下一条转向指令常驻顶部，点它或点数据区可以放大。熄屏前先确认定位与电池设置没被系统限制——出问题照 [GPS定位与导航问题排查.md](GPS定位与导航问题排查.md) 查，导航太吃电照 [导航耗电快怎么省电.md](导航耗电快怎么省电.md) 压。想拉上朋友跑同一条线，见 [路线分享与组队活动.md](路线分享与组队活动.md)。

## 九、不从零画：导入现成路线

手里已有 GPX 文件（别人给的、别的平台下的），不必重画：**个人资料 → 已保存路线 → 导入 GPS 文件**，选「导入为计划路线」，改完运动类型就能保存、能导航。格式与限制见 [GPX导入导出与设备同步.md](GPX导入导出与设备同步.md)。

要去没网的地方，保存后顺手把这条路线与覆盖它的地图下到手机——步骤见 [离线地图下载与使用.md](离线地图下载与使用.md)。
