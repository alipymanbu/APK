## 一、先确认你要装的是哪一个 SoulSync

同名应用非常多，Google Play 上叫 SoulSync 的就有日记、约会、冥想等十几个互不相干的应用；甚至还有一个叫 Soul Sync 的香港硬件公司网站。区分它们只看一条：**包名必须是 `live.moreshort.app.jp`**。

| 项目 | 值 |
| --- | --- |
| 应用名称 | SoulSync（部分下载站写作 Soul Sync、SoulSync AI，同一个应用） |
| 包名 | `live.moreshort.app.jp` |
| 版本号 | 2.5.1 |
| 安装包大小 | 70.55 MB |
| MD5 | `D9CA35DAA5A15D100D24AFFF5738E007` |
| 应用类型 | AI 角色聊天 / 虚拟陪伴，需联网使用，内含付费内容 |
| 厂商 | 多家下载站标注为 SeaArt，官网入口指向 [www.seaart.ai](http://www.seaart.ai)（以官方页面为准） |

上面这几项是网盘里那份安装包的实际信息。网上能搜到的最新版（截至 2026-09 有站点标注 2.5.5）与它不是同一个版本，装完在「设置—关于」里看到 2.5.1 是正常的。

## 二、从网盘拿到安装包

1. 打开 [SoulSync 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2ecdacba2862)，转存到你自己的网盘。
2. 进入应用文件夹，里面是 `SoulSync_v2.5.1.apk` 和一个说明文本。
3. 在手机上用文件管理器打开该 APK，按提示安装；或先传到手机再点开。

**建议校验一下 MD5**（防止传输中文件损坏，也能确认版本没错）：用手机上的文件管理器或 MD5 校验工具读取文件哈希，与上表的 `D9CA35DAA5A15D100D24AFFF5738E007` 比对，一致再装。

## 三、安装步骤与权限

1. 点开 APK 后系统会弹「是否安装此应用」，若提示「禁止安装未知来源应用」，按提示进入该来源（文件管理器或浏览器）的「安装未知应用」开关，允许一次即可。
2. 安装完成后打开，首次启动会请求网络、通知等常规权限；按自己的习惯选择允许或拒绝——拒绝通知不影响聊天，拒绝网络则无法使用。
3. 进入后按界面提示完成昵称、性别、年龄等基础设置，然后就能进首页挑角色了。

具体会弹出哪些权限取决于版本，以安装时系统列出的为准。

## 四、系统要求：各来源说法不一，按这个口径看

这一项网上没有统一口径，几处第三方下载站标注互相冲突，列出供你对照：

| 来源标注 | 写的系统要求 |
| --- | --- |
| 聚侠网（v2.5.1 页面） | 安卓 3.6 以上 |
| 七匣子（v2.5.1 页面） | 安卓 5.2 以上 |
| 游戏鸟（v2.3.9 页面） | 安卓 4.3 以上 / 正文另称 Android 7.0 及以上 |
| 第一手游（v2.5.1 页面） | 写的「iOS 9.0 或更高」，但同页提供的是安卓 APK，明显是模板错误 |

**实际判断以安装时的提示为准**：能装上、能进主界面，就是够格。装不上或装上闪退时再看 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、首次启动后的两件事

1. **确认版本**：进设置或关于页看版本号是否为 2.5.1，与网盘里那份对上。
2. **想好免费怎么玩**：这个应用的聊天按条消耗金币，金币可以靠首次进入赠送、福利中心领取、看广告免费拿，也能用充值的钻石换。第一次进应用别急着充值，先把免费渠道摸一遍，见 [金币与钻石获取及消耗说明.md](金币与钻石获取及消耗说明.md)。

装好之后，下一步通常是挑一个现成角色开聊，或者自己捏一个——见 [创建专属AI角色教程.md](创建专属AI角色教程.md)。
