## 一、记忆增强：让角色记得住前文

不开启时，角色对更早对话的把握会越来越淡，聊久了容易出现「忘了你说过什么」。记忆增强就是把这条链续上。

**开启位置**：进入与 AI 角色的对话界面 → 在输入框附近找到功能区域 → 点开**记忆增强**开关（以界面上实际的标注为准）。开完之后角色会留存更多对话信息，你不用再复述背景。

**什么时候开、什么时候不开**：

| 场景 | 建议 |
| --- | --- |
| 长期连载一个故事、固定人设 | 开，角色靠它保持前后一致 |
| 想让角色忘掉刚才的口误/跑偏 | 关掉并开一次新聊天，比重整段人设快 |
| 只是随手闲聊、聊完就散 | 不用开 |

记忆增强管的是对话连贯性，不等于内容会被备份到别处；对记录去留有要求的话，以应用内的隐私说明为准。

## 二、切换 AI：随时换人

在会话里点**切换 AI**按钮，就能重新挑一个角色继续，不用退回首页。切换后你面对的是另一个角色：它的性格、背景、语音都是独立的，记忆也不会跟着过去。

- 想保留原来的会话：切换前别删会话，回头还能从列表里回去。
- 想彻底换个开头：开新聊天（可勾选重置对话），见下节。

## 三、新聊天重置与全局人设

- **新聊天重置对话**：在设置或会话选项里打开它，之后每次开新对话都从干净状态开始，不会把上一段的上下文带过来。适合换题材、换心情的时候用。
- **全局对话人设**：你可以编辑一段全局的人设说明，作用于所有对话，用来统一「你」这个说话人的形象（昵称、自称、说话风格）。角色人设管「对方是谁」，全局人设管「你是谁」，两层不冲突。
- **个人资料**：昵称、性别、年龄等基础信息在个人设置里改；有些角色会根据这些字段称呼你，改完记得看新对话是否叫对了。

## 四、它没记住事的时候怎么排查

按这个顺序试，多数情况能解决：

1. 确认记忆增强开关**确实是开着**的（以界面实际显示为准）。
2. 关键信息再口头交代一次——记忆增强是概率性的，重要背景显式说一遍最稳。
3. 上一条回复明显串了人设 → 说明会话上下文已偏，开新聊天重置，再把背景补上。
4. 完全不进字、回复重复报错 → 走 [常见问题与故障排查.md](常见问题与故障排查.md) 的网络与服务一节。

聊天按条消耗金币，频繁开新聊天重置前，先看清自己的余额，见 [金币与钻石获取及消耗说明.md](金币与钻石获取及消耗说明.md)。
