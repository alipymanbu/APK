装完之后最先遇到的问题通常不是功能不会用，而是「我要的那个文件夹在哪」。XFolder 把入口分成两条路：从「图片 / 视频 / 音频 / 文档 / 安装包 / 压缩包」进是按类型，从「内部存储 / SD 卡」进是按位置。本篇讲清首页各区域管什么、目录里怎么挑文件、批量复制与移动怎么做，以及文件找不到时怎么翻出来。

## 一、首页三个区域各自管什么

| 区域 | 典型内容 | 什么时候用它 |
| --- | --- | --- |
| 按类型聚合 | 图片、视频、音频、文档、安装包、压缩包 | 只知道文件是什么类型，想快速筛一遍 |
| 存储位置 | 内部存储、SD 卡、U 盘等 | 明确知道文件在哪个盘、要按目录操作 |
| 云盘 / 网络 | 已登录的云盘、FTP 等入口 | 要处理不在本机的文件 |

分类聚合区给出的是**同一类型文件的汇总视图**，不是真实目录的镜像——你在分类里删掉一个文件，它在原目录里也一并消失。想弄清一个文件的真实位置，长按它看详情里的路径最直接。

## 二、在目录里怎么走

1. 点「内部存储」进入根目录，顶部会显示当前所在的完整路径；
2. 点任意文件夹进入下一层，点返回箭头或屏幕返回键退回上一层；
3. 右上角的更多按钮里有排序项，可以按名称、时间、大小排。注意**按大小排序只对文件生效**，文件夹不会跟着排——要让文件夹也显示大小，得先对所在目录做一次分析，具体做法见 [存储空间怎么清理.md](存储空间怎么清理.md)；
4. 常用目录可以加书签或收藏，下次直接从侧边栏进去，不用一层层点。

## 三、挑文件：单选与多选

- **单个文件**：单击打开（按类型用内置的图片查看器、视频播放器、音乐播放器打开）；要操作而不是打开，就**长按**；
- **多个文件**：长按第一个进入多选，继续点其它条目把它们一起选上；选中后菜单里会出现复制、移动、删除、压缩、分享这几项；
- **整批选择**：先全选、再取消掉不想动的几个，比一个个点着选快得多。

多选时注意选中的是文件还是文件夹：删除文件夹会连同里面全部内容一起删，这一步没有二次确认里的「清单」可看，选中后先数一下条目数再点删除。

## 四、复制、移动、重命名、新建

**复制 / 移动的完整动作是两步**：先在源目录选中文件、点复制（或移动），再进目标目录点粘贴。中间可以随意切换目录，选择不会丢。

- **同一存储位置内搬运**用「移动」更快，跨存储位置（比如手机存储 ↔ SD 卡）时两个都是实打实的拷贝，会占用双倍时间；
- **重命名**：选中后进菜单找重命名。改扩展名要慎重，把 `.jpg` 改成 `.txt` 这类操作只会让文件打不开，不会真的转换格式；
- **新建文件夹**：在当前目录的菜单里有新建文件夹项，建完立刻改名；
- **压缩 / 解压**：选中文件后可以打包成 ZIP 或 RAR，压缩包也能就地解压到当前目录。解压路径记得确认，很多压缩包解开后是套一层文件夹的结构。

## 五、文件找不到时怎么翻

1. **用搜索**：在首页或所在目录调出搜索，按文件名搜。搜索依赖应用对存储的索引，文件刚下载完就搜不到时，回目录里手动刷新一次再看；
2. **按来源找**：浏览器、微信、QQ 下载的文件散落在各自的目录里，常见位置是 `Download`、`Download/Weixin`、`Tencent` 这类系统或应用目录，先在「内部存储」里翻这几处；
3. **按类型找**：只记得是张图或一段录音，就从分类聚合区进去筛，比按目录找快；
4. **按体积找**：只记得文件很大，就走占用分析那条路，见 [存储空间怎么清理.md](存储空间怎么清理.md)。

## 六、看不见的文件去哪了

两类「看不见」要分开处理：

- **隐藏文件**：以点号开头的文件（如 `.nomedia`）默认不显示，需要在应用的设置里打开「显示隐藏文件」才会出现。关掉它之后这些文件会重新消失，属于正常现象；
- **应用数据目录**：`Android/data`、`Android/obb` 从 Android 11 起被单独保护，**授予「所有文件访问权限」也进不去别的应用在这些目录下的子目录**（Android 官方文档写明这条权限不覆盖其他应用的应用专用目录）。这是系统设计，不是应用的问题；要从那里取文件，回对应应用里用「导出 / 分享到下载目录」更省事。各目录分别属于谁、能不能删，见 [手机存储里那些文件夹都是干什么的.md](手机存储里那些文件夹都是干什么的.md)。

误删的文件不在这里找回，去回收站看：[回收站与私密文件夹.md](回收站与私密文件夹.md) 里写了回收站的位置、恢复方式和清空后会怎样。
