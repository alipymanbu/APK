XFolder 是安卓端的文件管理器，官方商店标题写作「File Manager - XFolder」，开发方是 InShot Inc.，官网在 [inshotapp.com/xfile](https://inshotapp.com/xfile/)。你在它里面干的无非是搬文件、清空间、用 FTP 让电脑直接读写手机目录。本篇只解决第一步：把网盘里这份包装进手机，并把首次打开要给的权限配齐。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本信息通常是当时的最新发布版，而网盘里这份是制作文档时核对过的版本，两者未必是同一个版本号。下表几项以网盘里这份为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | XFolder |
| 版本号 | 1.5.4.2 |
| 包名 | `files.fileexplorer.filemanager` |
| 安装包体积 | 14.56 MB |
| MD5 | `0EF02F974A044963B371AD22DB16FA45` |
| 系统要求 | Android 5.2 及以上 |

安装包本体在 [XFolder 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d6031c895527) 里，转存到自己网盘后再下载。

关于版本号：官方版本号形如 `1.5.4.2`，四段式递增，官方后续发布的版本号可能已经高于它，具体以官方渠道当时显示的为准。

关于系统要求：同一个应用在不同分发渠道标注的最低安卓版本并不一致（5.0、7.0 都出现过，通常对应不同的发布批次），本地记录里这份包标的是 Android 5.2 及以上。装的时候系统若提示「应用与你的设备不兼容」，基本就是这个原因，换一台系统版本更高的设备即可。

## 二、装之前要核对的两件事

**第一，认包名而不是认名字。** 应用商店里名字带 file manager 的应用很多，认人要认包名：本文这份是 `files.fileexplorer.filemanager`。包名不同的两个文件管理器在系统里是两个独立应用，不能互相覆盖安装，也各占一份数据空间。之前装过别的文件管理器不影响安装，但设置和书签不会带过来。

**第二，留出空余空间。** 安装包 14.56 MB，装完占用会更大一些。文件管理器本身不重，但它要扫描整机目录才能干活，存储接近满时扫描和列目录会明显变慢——装完先确认还有足够空余。

## 三、安装步骤

1. **转存并下载**：把上一节那个安装包转存到自己的网盘，再下载到手机或电脑。
2. **把包送到手机上**：手机端直接下载最省事；在电脑上下载的，用数据线或任意传输工具拷进手机存储即可。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统的这项开关常收在「安全」或「隐私」分类下面。
4. **点开 APK 完成安装**：系统提示「应用未经过安全检测」时选择继续安装，这是第三方渠道安装包的常规提示。
5. **回装低版本要先卸载**：安卓不允许用低版本安装包覆盖已装的高版本，会直接报「应用未安装」。你手上这份是 1.5.4.2，如果手机里已经有更高的版本，先卸载旧版再装；卸载会一并清掉应用内的设置与回收站里的内容。
6. **装完先别急着翻文件**：先按下一节把权限过一遍，否则首屏很可能是一排空目录。

## 四、首次启动要给的权限

第一次打开通常按顺序弹几项授权，逐项给全：

| 权限 / 设置 | 在哪里给 | 不给会怎样 |
| --- | --- | --- |
| 文件与媒体 / 存储 | 启动时的系统弹窗 | 看不到内部存储的内容，首页各分类都是空的 |
| 所有文件访问权限 | 系统设置里的应用详情页（Android 11 及以上叫这个名） | 只能处理媒体类文件，`.zip`、`.apk` 这类非媒体文件看不到、也改不了（注意：别的应用在 `Android/data` 下的数据目录，即使开了这一项也访问不到） |
| 通知 | 启动时的系统弹窗 | 复制、解压这类长任务的进度收不到，切到后台后不知道跑完没有 |

Android 11 之后系统对存储访问收得更紧：权限页里看到的往往不是笼统的「存储」，而是「照片和视频」「音乐和音频」分项。要整理全盘目录，你还需要分项之外的那项「所有文件访问权限」，跟着应用引导到系统设置里单独打开。入口名各厂商叫法不同，常见路径是「设置 → 应用 → XFolder → 权限」。

## 五、装完做一次最小验证

1. 打开 XFolder，按上一节把权限给全；
2. 回到首页，点进「内部存储」，能看到 `Download`、`Pictures` 这类系统自带目录，说明存储权限真正生效了；
3. 任选一个文件做一次复制、再粘贴到另一个目录，确认写入也正常；
4. 退出应用再重进一次，检查是否仍停在原来的目录。如果每次进来都要重新授权，去「设置 → 应用 → XFolder」确认权限没被系统的省电策略回收。
