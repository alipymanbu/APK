# XFolder 用FTP在电脑上访问手机文件

> 本篇讲怎么在 XFolder 里开启 FTP 服务，让同一个 Wi-Fi 下的电脑用资源管理器直接读写手机目录，以及连不上、传一半断掉时该看哪里。

插数据线传文件有两个老问题：线常不在手边，插上后还要等系统弹一次授权。同一个 Wi-Fi 下把手机当成一台小型 FTP 服务器更省事，电脑不用装任何手机助手就能进出手机目录。本篇讲怎么把服务开起来、电脑怎么连，以及连不上和传一半断掉时该查哪里。

## 一、这条路适合什么场景

| 场景 | 适不适合 | 说明 |
| --- | --- | --- |
| 电脑和手机在同一个 Wi-Fi | 适合 | 传几百 MB 到几个 GB 的照片、视频很顺手 |
| 一次要搬很多零散文件 | 适合 | 电脑端可以整目录拖拽，比在手机上一个个选快 |
| 想直接改手机里的文档 | 适合 | 电脑上编辑完保存，手机那边就是改后的版本 |
| 在外面用流量、和电脑不在同一网络 | 不适合 | FTP 走局域网，跨网络连不上 |
| 传输几百 GB 的整机备份 | 不适合 | 无线速率是瓶颈，这种量级还是走数据线 |

至于速度，先看量级就够判断该不该走这条路（下面几档是多方公开实测给出的常见区间，截至 2026 年，实际取决于路由器、机型与文件大小）：

| 通路 | 常见速度区间 |
| --- | --- |
| Wi-Fi 5 GHz（离路由器近） | 40~80 MB/s |
| Wi-Fi 5 GHz（隔墙，中等距离） | 20~40 MB/s |
| Wi-Fi 2.4 GHz | 5~15 MB/s |
| 数据线（插在 USB 2.0 口上） | 约 30~40 MB/s |
| 蓝牙 | 2~3 MB/s |

结论有两条：无线不一定比线慢，但这只在连 5 GHz 频段、离路由器近时成立；几十 GB 量级的整机备份仍然用数据线更稳，别用无线硬扛。

## 二、在手机上把服务开起来

1. 打开 XFolder，在首页或侧边栏的「网络 / FTP」分类里找到 FTP 功能入口；
2. 进入后开启 FTP 服务，界面会给出一个地址，形如 `ftp://192.168.1.23:端口`。**这个地址只在本次开启期间有效，关掉服务或换网络都会变**，每次用都要现看；
3. 界面会同时显示它是匿名可访问还是需要账号密码，具体以当时显示为准；
4. 保持这个界面在前台，别锁屏。

**用完记得关掉服务。** FTP 是不加密的明文协议：地址、账号密码、传的内容在网络里都不做加密。在自家 Wi-Fi 下用没问题，但在酒店、机场、公司访客网络这类共享环境里不要开——同一个网络里的其他人有机会看到传的东西。

## 三、在电脑上连进去

1. 确认电脑连的是和手机**同一个 Wi-Fi**（手机连 5G 频段、电脑连 2.4G 频段但属于同一路由器，也通常在同一网段）；
2. 打开「此电脑」，在顶部地址栏粘贴手机上给出的那个 `ftp://` 地址，回车；
3. 需要账号密码时按手机界面显示的填写，勾选记住凭据后下次省一步；
4. 连上后手机目录会像普通文件夹一样列出来，可以拖拽文件进出，也可以直接在电脑上打开手机里的文档。

Windows 资源管理器访问 FTP 时，双击远处的文件会先下载到临时目录再打开，改完保存不一定能同步回手机。**要就地编辑，建议用专用的 FTP 客户端**（如 FileZilla 这类），它的行为更接近本地目录。

## 四、传文件时手机端要注意什么

- **别让手机灭屏太久**。部分机型的省电策略会在息屏后掐断网络连接，表现是传到一半进度停住。稳妥做法是在系统设置里给 XFolder 打开「允许后台运行」，或传输期间把屏幕保持常亮；
- **别切到别的 Wi-Fi**。手机换到另一个网络，地址立刻失效，电脑那边的连接会掉线；
- **大文件传输期间别同时用手机看视频**。无线带宽是共享的，看视频会把传输速度拉下来。

## 五、连不上的排查顺序

1. **先看两台设备是不是同一个网络**。手机在 5G Wi-Fi、电脑连的是有线网口接的另一个路由，就不在同一网段；
2. **再核对地址里那串数字**。手机重连 Wi-Fi 后 IP 常常会变，用旧的地址当然连不上，回手机界面看一遍现成的地址；
3. **检查 Windows 的防火墙提示**。第一次用资源管理器访问 FTP 时系统可能弹出入站询问，选允许；企业网络或公共网络模式下系统会直接拦掉，把网络类型改成专用网络再试；
4. **看路由器有没有开 AP 隔离**。访客 Wi-Fi 或开了「无线设备隔离」的网络里，设备之间互相看不见，这是路由器设置的问题，不是应用的问题；
5. **换一个客户端试**。资源管理器连不上但专用客户端能连，问题多半在资源管理器的被动模式设置上，用客户端即可。

## 六、云盘入口和 FTP 不是一回事

XFolder 首页还有云盘入口，登录 Google Drive、OneDrive、Dropbox 这类账号后可以直接浏览和搬运云端文件。它和 FTP 的区别是：FTP 传的是**手机本地**的文件，云盘传的是**账号里**的文件。

需要注意的是，Google Drive 在境内网络环境下通常无法直接访问，要用它得先解决网络可达性，不要把它当成默认方案；OneDrive、Dropbox 的可用性也可能随网络环境变化。云盘登录状态存在账号授权里，换设备要重新登录一遍。

传完文件想做一次批量整理，做法见 [手机文件怎么浏览和整理.md](手机文件怎么浏览和整理.md)；地址、端口这些信息在哪看、开了服务却没人能连进来，对照 [常见问题与排查.md](常见问题与排查.md) 里 FTP 那几条。手机端要装的是哪一版，见 [下载与安装教程.md](下载与安装教程.md)。
