# XFolder 手机存储里那些文件夹都是干什么的

> 内部存储根目录里那一堆英文文件夹分别属于谁、装了什么、能不能删，本篇给一张对照表，并说明删错之后会发生什么。

打开「内部存储」，看到的大多是英文名目录，名字认不出来就不敢删——这是清理时最常见的卡点。其实它们分三类：系统建的、`Android` 目录下的、以及各个应用自己建的。认清楚归属，「能不能删」基本就有答案了。

## 一、系统建的目录

| 目录 | 属于谁 | 里面通常是什么 |
| --- | --- | --- |
| `DCIM` | 相机 | 手机拍的照片与视频；不少机型把截屏放在 `DCIM/Screenshots` |
| `Pictures` | 系统与各应用 | 非相机拍摄的图片，如截图、保存的网络图片、应用的配图 |
| `Movies` / `Music` | 系统与各应用 | 视频、音频的默认存放位置 |
| `Download` | 系统与浏览器 | 浏览器下载的文件；有的机型会多建一层 `Download/DLManager` |
| `Documents` | 系统与办公类应用 | 文档类文件 |
| `Alarms` / `Ringtones` / `Notifications` | 系统 | 自定义铃声要放在这里才会被系统识别，放别处不生效 |

这几个目录里的**内容**可以按需清理，目录本身留着即可。删掉目录后系统或应用下次用到时会重新建，但放在里面的自定义铃声要找回来就得重放一遍。

## 二、Android 目录里的三层

| 子目录 | 内容 | 能删吗 |
| --- | --- | --- |
| `Android/data` | 各应用在共享存储上的数据与缓存，子目录名就是应用的包名 | 不建议。删掉某个应用的子目录，等于清掉它的离线内容或存档 |
| `Android/obb` | 大型游戏的数据包 | 不建议。删了游戏要重新下载几百 MB 到几个 GB |
| `Android/media` | 少数应用（如通讯类）放媒体文件的公共位置 | 一般不用动 |

Android 11 及以上对 `Android/data` 和 `Android/obb` 做了单独保护：**即使授予文件管理器「所有文件访问权限」，也读不到别的应用在 `Android/data` 下的子目录**——Android 官方文档写明，这条权限本身不覆盖其他应用的应用专用目录。所以在手机上「进不去 `Android/data`」是系统的设计，不是应用的问题，也不用为它反复折腾权限。真要从那里取文件，回对应应用里用「导出 / 分享到下载目录」更省事；`adb`、Shizuku 这类偏技术的手段属于另一条路，普通使用没必要走。

## 三、应用建的目录

| 目录 | 属于谁 | 说明 |
| --- | --- | --- |
| `Tencent` | 腾讯系应用（微信、QQ） | 聊天里保存的图片、视频、文档，以及表情与头像缓存 |
| `BaiduNetdisk` / `baidu` | 百度系应用 | 网盘下载的文件、地图等应用的数据 |
| `weixin` / `QQ` 之类 | 单个应用自建 | 名字通常是应用名的拼音或英文，看到就能对上是哪个应用 |
| `LOST.DIR` | 系统 | 系统异常或应用崩溃时被挪进来的文件，文件名会被打乱 |

应用的目录删起来要留个心眼：把 `Tencent` 整个删掉之后，微信和 QQ 里那些聊天记录引用的图片、文件会打不开——**记录可能还在，但文件已经不在原位置了**。`LOST.DIR` 里是抢救出来的碎片，想恢复就把它重命名成带正确扩展名的名字，再移出来。

## 四、这套对照表什么时候用得上

1. **清理前**：先在 [存储空间怎么清理.md](存储空间怎么清理.md) 里对根目录做一次分析，看到哪个目录占地方，再回本篇查它属于谁、能不能动；
2. **找文件**：知道「照片在 `DCIM`、浏览器下载在 `Download`、聊天文件在 `Tencent`」之后，直接进目录或用搜索找，比在分类聚合里一页页翻快，做法见 [手机文件怎么浏览和整理.md](手机文件怎么浏览和整理.md)；
3. **不要拿「这个目录名我不认识」当删除理由**。不认识的先查一遍再动手；删文件有回收站兜底（见 [回收站与私密文件夹.md](回收站与私密文件夹.md)），但被别的应用引用的文件删掉后，应用那侧的表现通常是「记录在、文件没了」。

目录清单会随系统版本、厂商定制和已安装的应用变化，本篇列的是普遍存在的那一批，以你手机上实际存在的目录为准。
