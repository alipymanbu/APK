## 一、新建与保存

主界面点右下角的加号，选类型并起名：Markdown（.md）、纯文本（.txt）、todo.txt，也能建 Zim Wiki 文件和 csv、json、yaml 这类键值格式（App 里实际能选的类型以界面显示为准）。选完类型 App 会自动补扩展名。

保存不用你操心：离开 Markor 或关闭文件时会自动保存，顶部菜单里也有保存按钮兜底。写坏了可以撤销/重做。

## 二、编辑界面上用得上的东西

- **底部格式工具栏**：加粗、标题、插入图片、插入日期时间等常用动作都在这里，不熟 Markdown 语法也能按按钮生成。动作顺序可以在设置里调整，把最常用的放最顺手的位置。
- **行号**：顶部文件菜单里有开关，编辑和阅读模式都支持（代码块里也显示）。
- **编辑 / 阅读切换**：眼睛图标进阅读模式，笔图标回编辑模式。刚插入的图片在编辑模式只显示一行代码，切到阅读模式就能看到。
- **搜索**：当前文件内支持搜索与替换；整个笔记本按内容搜索也有入口，设置里可开关。
- **外观**：深色主题、自定义字体（选字体文件）都在设置里。
- **语音备注**：可以往文档里附带录音。录音权限只在你点"附带音频"按钮时才会用到，起止都由你手动控制。

## 三、预览模式能渲染什么

- Markdown 常规语法：标题、列表、表格、代码块高亮，遵循 CommonMark 规范。
- 数学公式：KaTeX 语法。
- 图表：流程图、时序图、饼图这类图示（以当前版本实际支持情况为准）。
- YAML front-matter：写在文件开头的元信息块。
- Markdown 里可以直接写 HTML，预览按网页的方式渲染。

## 四、导出与分享

- 顶部菜单里能把当前文档转成 **HTML 或 PDF**，也能把渲染结果直接分享到其他 App。
- 图片插入时是从相册选或现场拍，写进文本的是对图片文件的引用——所以把笔记文件单独传给别人时，记得连图片所在文件夹一起给，对方那边才能看到图。
- Markdown 还能当幻灯片放映，适合用笔记做个简单演示。
