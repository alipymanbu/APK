## 一、安装前先核对这些信息

Markor 是一款安卓端的纯文本编辑器，用 Markdown、todo.txt 这类标记格式记笔记、管待办，完全离线工作。装之前先确认手机满足下面的条件：

| 项目 | 信息 |
| --- | --- |
| 应用名称 | Markor（开发者 Gregor Santner，开源项目） |
| 安装包版本 | 2.16.0（网盘里这一份的版本，采集于 2026-09-27） |
| 包名 | `net.gsantner.markor` |
| 安装包大小 | 11.49M |
| MD5 | `4C2870A670AFC24BEC20D9156971371D` |
| 系统要求 | Android 4.3 及以上（以官方应用商店页面标注为准） |
| 许可证 | Apache 2.0（开源） |

版本号说明：官方项目一直在更新，网上搜到的可能是更新的版本号。网盘里这份以 2.16.0 为准，装好后如果提示更新，以官方渠道发布的版本信息为准。

## 二、从夸克网盘拿安装包（推荐步骤）

1. 打开 [Markor 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ba4e76fb6fb8)，把分享内容转存到自己的网盘（不转存的话链接可能失效）；
2. 在夸克网盘 App 里找到转存后的 `Markor_v2.16.0.apk`，下载到手机本地；
3. 下载完成后点开这个 APK 文件，系统会提示「是否允许安装」，确认即可；
4. 如果手机提示「禁止安装未知来源应用」，到 系统设置 → 安全（或应用管理）里，给本次安装授权后再重试。不同品牌手机的入口叫法不一样，OPPO/vivo/小米一般在「更多设置」或「隐私与安全」里能找到「未知来源安装」的开关。

如果你核对的安装包 MD5 与上表不一致，说明拿到的可能不是同一份文件，建议回网盘重新下载一遍。

## 三、官方渠道对照

Markor 是开源软件，官方发布渠道有两个，想跟随官方更新的读者可以用它们获取新版本：

- 官方项目页：[https://github.com/gsantner/markor](https://github.com/gsantner/markor)（README 与 Releases 页提供 APK）
- F-Droid 商店页：[https://f-droid.org/packages/net.gsantner.markor](https://f-droid.org/packages/net.gsantner.markor)（开源应用商店，可自动接收更新通知）

这两个渠道与网盘里的安装包来源不同，签名与版本号可能存在差异。已经装了 2.16.0 之后再从官方渠道装新版，属于覆盖升级，笔记文件不受影响（笔记都存在你选的文件夹里，与应用本体分离）。

## 四、首次启动要做的三件事

1. **授予存储权限**：Markor 不联网也能干活，但它要读写你手机里的文件，首次启动会请求存储权限，允许即可；
2. **确认 Notebook 目录**：Notebook 是你所有笔记的总文件夹，默认放在内置存储的 Documents 目录。你可以在 设置 → Notebook 里改成任何你有权限访问的位置（比如 SD 卡或同步软件的目录）；
3. **关掉欢迎页**：第一次打开会有几页使用引导，看完直接进入主界面，就能开始建笔记了。

装好之后怎么用，接着看 [使用教程.md](使用教程.md)；想直接开始记待办清单的，直接跳 [todo.txt待办清单用法.md](todo.txt待办清单用法.md)。
