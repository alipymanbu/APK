## 一、主界面三个入口

打开 Markor 后，底部有三个标签：

| 入口 | 用途 |
| --- | --- |
| 文件（Notebook） | 浏览笔记本根目录里的全部文件与文件夹 |
| 快速笔记（QuickNote） | 一个常驻的随手记文件，点开就能写 |
| 待办（To-Do） | 进入 todo.txt 任务清单，见 [todo.txt待办清单使用方法.md](todo.txt待办清单使用方法.md) |

## 二、新建一篇笔记

点右下角的加号：先输入文件名，再选文件类型（Markdown、纯文本、todo.txt 等），确认后按类型补上扩展名——Markdown 生成 `.md`，纯文本与 todo.txt 生成 `.txt`。

想分类管理，就先建文件夹：同样点加号，输入文件夹名后选「文件夹」，之后笔记按文件夹归置。

## 三、编辑页里能做什么

- **底部工具栏**：加粗、斜体、删除线、标题、列表、引用、插入链接、插入图片、插入日期时间等，点一下就把对应语法写进光标处；
- **自动保存**：不用手动点保存；误删可以撤销 / 重做；
- **语法高亮**：编辑时对标题、加粗、代码块等着色，方便核对写法。

## 四、常用语法对照

| 想要的效果 | 写法 | 示例 |
| --- | --- | --- |
| 标题 | 行首 `#` 到 `######` | `## 二级标题` |
| 加粗 | `**文字**` | `**重点**` |
| 斜体 | `*文字*` | `*强调*` |
| 无序列表 | 行首 `- ` | `- 第一项` |
| 有序列表 | 行首 `1. ` | `1. 第一步` |
| 引用 | 行首 `> ` | `> 引用内容` |
| 链接 | `[文字](网址)` | `[GitHub](https://github.com)` |
| 图片 | `![说明](路径)` | `![截图](shot.png)` |
| 行内代码 | 反引号包住 | `` `code` `` |
| 分隔线 | 单独一行 `---` | `---` |

代码块用三个反引号上下包住，起始行可标注语言（python、js 等），预览时会按语言着色。

## 五、插图与预览

1. 点工具栏的图片按钮（或手写 `![]()`），把图片路径写进括号；图片与笔记放在同一文件夹时，直接写文件名即可；
2. 编辑态里图片只是一行代码，这是正常现象；
3. 点顶部「眼睛」图标进入预览，图片与排版才会渲染出来；再点「笔」图标回到编辑。

## 六、行号与字体

顶部文件菜单里有「行号」开关，编辑器与预览（代码块部分）都会显示行号；字体与字号在设置里更换。
