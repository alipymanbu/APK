## 一、导出 PDF 与 HTML

在笔记编辑页的顶部菜单里找「分享 / 导出」类动作，可以把当前笔记转成：

- **PDF**：排版固定，适合打印、归档、发给别人看；
- **HTML**：保留标题、列表、表格等样式，适合贴进网页或邮件正文。

导出前先点预览（眼睛图标）确认效果——预览里什么样，导出物就是什么样。

CSV 这类表格文件走同一条路：预览会渲染成 HTML 表格，再从这里导出 PDF（官方说明）。

## 二、把文字从别的应用收进来

Markor 接系统的「分享到」：在浏览器、聊天或新闻应用里选中文字后点分享，选 Markor，之后可以：

- 存成一篇新笔记；
- 复制到剪贴板；
- 继续分享给别的应用；
- 直接打开文本里包含的链接。

## 三、安装类问题

| 现象 | 处理 |
| --- | --- |
| 提示「未知来源」装不了 | 在系统设置里允许「此来源安装应用」后重试 |
| 解析包错误 / 装不上 | 安装包多半没下完整，核对 MD5 后重新下载 |
| 装完点开没反应 | 先到系统设置确认存储权限已允许，再重新打开应用 |

安装包来源与 MD5 见 [下载与安装教程.md](下载与安装教程.md) 的核对表。

## 四、使用类问题

| 现象 | 处理 |
| --- | --- |
| 插的图片只显示一行代码 | 编辑态本来就不渲染，点顶部眼睛图标进预览看效果 |
| 图片在预览里也空白 | 图片路径写错了；图片与笔记同目录时直接写文件名 |
| 笔记列表是空的 | 多半是笔记本根目录被改过，或存储权限没给，回设置核对 |
| 界面是英文 | 设置里选语言，官方带简体中文 |
| 想要深色界面 | 设置里换深色主题 |
| 导出的 PDF 中文变方框 | 先看预览里是否正常；PDF 的字体显示与设备渲染有关，急用时改导出 HTML，用浏览器打开后再打印成 PDF |
| 换手机想带走全部笔记 | 把整个笔记本文件夹拷走、新机指回去，见 [文件夹存储与同步备份.md](文件夹存储与同步备份.md) |

## 五、版本与更新

网盘里这份是 2.16.0（2026-09 整理）。想用新功能可以到 F-Droid 或 GitHub 发布页看更新，覆盖安装后笔记仍在你设定的文件夹里，不会丢；求稳的话，更新前把笔记本文件夹备份一份（方法见 [文件夹存储与同步备份.md](文件夹存储与同步备份.md)）。
