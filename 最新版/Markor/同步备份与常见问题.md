# Markor 的同步、备份与常见问题

> Markor 自己不管同步和云备份，文件又是普通文本，这两件事交给专门的工具配合即可。本篇给出可行的组合，并列出新手最常撞上的几个问题。

## 一、文件都在哪

笔记本（Notebook）根目录默认是内部存储的 Documents 目录；QuickNote 和 todo.txt 这两个特殊文件的位置各自独立、可单独指定。知道这三个位置，备份就只是"把这几个文件夹纳入你的备份范围"。

## 二、跨设备同步怎么做

Markor 本体离线工作，同步交给专门的 App，两者配合。官方文档点名可搭配的同步客户端包括 Syncthing、Nextcloud、OwnCloud、Seafile、Dropbox、FolderSync、Syncopoli、BitTorrent Sync 等（截至 2026-09 的官方口径），其中项目自己推荐的是 Syncthing——设备之间点对点直传，不经过第三方服务器。

要点只有一条：让同步工具去同步"笔记本所在的文件夹"，Markor 不用做任何设置。手机和电脑之间的完整配置步骤（菜单路径、试跑验证、冲突副本合并）单独写在 [跨设备同步实操.md](跨设备同步实操.md) 里，照着做即可。

## 三、备份与恢复

- **文件备份**：把笔记本文件夹纳入网盘 / Syncthing / 系统备份即可，文本文件体积很小。
- **设置备份**：设置里有"备份与恢复"入口，能把应用内的设置导出成一个文件，换机时导入，不用一项项重配。

## 四、给笔记上锁

在设置的通用（General）分组里先设好"文件加密密码"，再打开加密开关，之后就可以把单个文本文件用 AES-256 加密；这一功能要求手机为 Android 6.0 及以上。注意两点：只加密文本本身，文件里引用的图片、音频附件不在加密范围；想在电脑上解密这类文件，需要配套的开源工具（如 [jpencconverter](https://gitlab.com/opensource21/jpencconverter)）。

## 五、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 文件名带删除线、改不了 SD 卡里的文件 | 还没拿到该目录的写授权。在 Markor 里浏览到 SD 卡的起始目录，按加号，按对话框指引授权一次即可 |
| 写的内容不见了 | 正常情况下离开 App 或关闭文件会自动保存，顶部也有保存按钮；若改过 Notebook 位置，去新位置找 |
| 找不到某个文件 | 确认是否在 Notebook 根目录下浏览；QuickNote 与待办文件的位置独立于笔记本 |
| 想全库搜一段话 | 用主界面的内容搜索（设置里可开关） |
| 同步之后多出一份带"冲突"标记的文件 | 两端同时改过同一个文件，两个版本都被保留了。合并内容、删掉多余副本，完整处理步骤见 [跨设备同步实操.md](跨设备同步实操.md) |
| 手机和电脑都想编辑 | 直接编辑即可，.md / .txt 都是普通文本，电脑上记事本、Vim 都能打开 |

安装与首次启动的问题在 [下载与安装教程.md](下载与安装教程.md) 里处理；编辑功能细节在 [Markdown编辑与导出.md](Markdown编辑与导出.md)；认真用待办看 [待办清单用法.md](待办清单用法.md)，轻量记录则在 [快速笔记与稍后阅读.md](快速笔记与稍后阅读.md)。
