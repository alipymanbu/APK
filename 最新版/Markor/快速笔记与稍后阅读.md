# Markor 快速笔记与稍后阅读

> QuickNote、LinkBox、分享进 Markor（Share-Into）这三样都为"少点几下"设计：随手记、存网页、转发文字。本篇讲各自的入口和适用场景。

## 一、QuickNote：一句话也值得记

QuickNote 本质是一个固定的 Markdown 文件。主界面**连续滑动两次**就能打开，想到什么写什么，不用先建文件、想文件名。它的位置同样可以在设置里单独指定。

和正式笔记的分工：正式笔记按主题建文件、放进不同文件夹；QuickNote 是一张草稿纸，攒多了定期整理到正式笔记里。建文件、预览这些通用操作见 [Markdown编辑与导出.md](Markdown编辑与导出.md)。

## 二、LinkBox：把网页先存下来

刷到一篇长文没时间看？用系统的分享菜单发给 Markor，链接会进 LinkBox 列表——它就是一个书签文件，支持 Markdown 格式，可以加一句备注说明为什么存它。之后从主界面进 LinkBox 逐条消化，看完删掉或留档都行。

## 三、Share-Into：任何 App 的文字都能发进来

在聊天、浏览器、阅读器里选中文字，走系统分享，Markor 会给你几个去处：

- 存进某条笔记；
- 存进 LinkBox 当书签；
- 复制到剪贴板（当中转站用）；
- 直接再分享给别的 App；
- 打开文字里包含的链接。

新版还会自动剥掉分享链接里的跟踪参数，转出去的网址不带多余尾巴。

## 四、桌面入口

设置里开启特殊文档启动器后，桌面除了 Markor 本体，还会出现 QuickNote 和待办的独立图标；也有对应的小组件，把这几样钉在桌面第一屏，少一层跳转。待办那条线的用法在 [待办清单用法.md](待办清单用法.md)。改完启动器开关记得重启手机，安装相关的问题回 [下载与安装教程.md](下载与安装教程.md)。
