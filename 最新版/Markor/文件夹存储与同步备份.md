## 一、笔记就是普通文件

Markor 没有私有数据库：你在里面写的每一篇笔记，都是笔记本根目录下的一个普通文本文件（`.md` / `.txt`）。默认根目录在内部存储的 `Documents/markor`。

这带来两个直接后果：

- 电脑上用记事本、Vim 或任意编辑器都能打开同一批文件；
- 备份、搬迁、同步，本质上都是「拷贝这个文件夹」。

## 二、换根目录

在设置里找到笔记本目录（Notebook）一项，指到任意有写权限的文件夹即可，文件列表会跟着换位置。

两点注意：

- 新版安卓对 SD 卡目录限制多，选内部存储路径更省事；
- 改完根目录如果列表空了，先回设置确认指的确实是放笔记的那个文件夹（排查详见 [导出分享与常见问题.md](导出分享与常见问题.md)）；
- 想把 Obsidian 的库目录直接当笔记本用，见 [与Obsidian共用一个笔记目录.md](与Obsidian共用一个笔记目录.md)。

## 三、与电脑互传

- **USB**：手机连电脑，把 `Documents/markor`（或你自定义的根目录）整个复制出来，写完再拷回去；文件名不变就能接着用；
- **网盘中转**：把文件夹打包成 zip 上传网盘，电脑端解压编辑后再放回；
- 文件是纯文本，拷贝过程中不会被转格式。

## 四、跨设备同步

云同步不归 Markor 管：把专门同步工具的目标指向笔记文件夹即可。官方说明已知可搭配的包括：

| 工具 | 适合的场景 |
| --- | --- |
| Syncthing | 设备间点对点直连，不经过第三方服务器 |
| Nextcloud / OwnCloud | 自建或托管网盘，用官方客户端同步目录 |
| FolderSync | 定时把指定文件夹与 Dropbox、OneDrive 等网盘对传 |
| Seafile、Dropbox、Syncopoli 等 | 装各自客户端、同步该文件夹即可 |

同步期间别在两台设备上同时编辑同一个文件；冲突后两份改动都会留下副本，需要你手动合并。

## 五、给文本加密（可选）

官方说明：在设置里设一个密码后，可以把文本文件加密存储（AES-256，安卓 6.0 及以上可用）。三条边界先知道：

- 只加密文本本身，同目录的图片、附件不加密；
- 电脑端要读这份密文，需要配套的开源工具（官方 README 提及 jpencconverter）；
- 密码忘了，文件也就解不开了。

## 六、备份节奏建议

- 低频省心的做法：把根目录放进第四节任一同步工具，历史版本交给同步工具兜底；
- 手动兜底：定期把整个文件夹打一个 zip，放进网盘或电脑；
- 单篇要紧笔记（比如马上要交的稿子）另存一份 PDF，方法见 [导出分享与常见问题.md](导出分享与常见问题.md)。
