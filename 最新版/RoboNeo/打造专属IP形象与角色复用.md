## 一、官方给的四步闭环

「一句话创造专属 IP」是 RoboNeo 的主打能力之一，官方把它设计成一个循环，而不是一次性的生成：

1. **创造 IP**：输入创意描述（也可以从零开始或基于已有素材），生成专属 IP 形象，从 0 到 1 拥有一个数字主角；
2. **剧本工作台**：脚本 Agent 引导你完成设定和生成，修改通过对话完成，内容实时同步到画布；
3. **用 IP 创作**：选定角色后挑产出形式——短剧、视频、贴纸、爆款复刻，AI 端到端做完；
4. **复用**：每个角色都有独立页面，你用它做过的所有东西都留存在角色名下，随时取用、接着做新的。

这个循环的意义在于第三、四步：角色立住之后，短剧、表情包、营销物料都从同一个形象出，不用每次重新描述「长什么样」。

## 二、让角色不「走样」的写法

AI 生成的老大难是角色一致性——第二次生成时发型变了、衣服换了。官方博客给过一套降低走样概率的做法，整理如下：

**第一步，把角色写成结构化描述。** 别用「一个可爱的女孩」这种模糊说法，按这张表逐项写全：

| 维度 | 要写的内容 |
| --- | --- |
| 身份 | 是谁、多大、什么气质（例如：20 岁左右、干练的职场女性） |
| 发型 | 长度、颜色、造型（例如：黑色齐肩短发、中分） |
| 五官/眼睛 | 眼型、辨识度特征 |
| 服装 | 具体到款式和颜色（例如：米白色高领毛衣） |
| 风格 | 写实、二次元、3D 卡通，选一个定死 |
| 景别/构图 | 特写还是全身、什么背景 |

**第二步，同一份描述先生成 3~5 版挑方向。** 从里面挑最接近构想的一版，记住是哪几个词起的作用。

**第三步，一次只改一个细节再重新生成。** 发型满意了再改服装；一次改五个地方，你不知道哪个改动带来了哪个结果。

立角色阶段的消耗是图片量级（见[算力萝卜与会员订阅.md](算力萝卜与会员订阅.md)），多试几版不心疼；角色一旦立住、进到视频阶段，换形象的代价就大了。

## 三、从静态形象到动态视频

角色定稿后，用「参考图生成视频」的思路把它带进动态内容：

1. 把定稿的角色图作为参考素材传入，而不是用文字重新描述一遍——图片锁脸比文字可靠；
2. 逐场景生成片段，每一段都检查脸和服装有没有和定稿对上；
3. 发现哪段走样，单独重生成那一段，确认无误后再组装成片。

这套「锁定形象 → 逐段生成 → 走样单段重做」的流程和短剧创作是衔接的：在 Agent 全自动模式里，角色素材确认环节就值得用上面第二节的写法先把好关，具体见[AI短剧与视频创作.md](AI短剧与视频创作.md)和[AI短剧提示词怎么写.md](AI短剧提示词怎么写.md)。

## 四、这个玩法适合谁

- **做系列内容的账号**：同一主角反复出现，观众才有「追剧感」，IP 页面正好充当素材档案；
- **做品牌吉祥物 / 虚拟主播的**：形象定稿后，短剧、贴纸、海报都用同一个角色出，视觉统一；
- **玩表情包的**：把自己的 IP 做成一套表情包发出去，比单张散图更有记忆点，表情包做法见[一句话修图与表情包制作.md](一句话修图与表情包制作.md)。

唯一要提醒的是额度：IP 闭环里的每一步生成都会扣算力萝卜，先把角色立准、再铺量做内容，是省额度的顺序。
