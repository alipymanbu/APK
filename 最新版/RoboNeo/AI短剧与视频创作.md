## 一、先选路线：全自动还是手动调优

视频创作在 RoboNeo 里有两条路，对应两种人：

| | Agent 全自动 | 画布手动创作 |
| --- | --- | --- |
| 适合谁 | 只有个想法，不想碰剪辑 | 对成片有明确要求，愿意逐镜头调 |
| 你要做的 | 输入一段剧情描述，等成片 | 在画布上拆镜头、选模型、改细节 |
| 可控性 | 低，基本靠「抽卡」后追加修改 | 高，镜头、模型、参数都能自己定 |
| 额度消耗 | 一整条流程跑下来消耗不小 | 按单次生成计，可控 |

拿不准就从全自动开始试一集，觉得某几帧不行再切到画布去精修，两条路并不冲突。

## 二、Agent 全自动：一句话出一集短剧

2026 年美图影像节给 RoboNeo 加上了「AI 短剧团队」，官方把它概括成「一句话组专业团队」：编剧、分镜导演、艺术总监等多个角色 Agent 分工协作。实际流程是这样的：

1. 在对话框输入剧情要求，写得越像「需求单」越好。可以参考这个结构：单集时长、画面比例（短剧常用竖屏 9:16）、题材、主角设定；
2. Agent 会先把任务拆解：编剧 Agent 出剧本，分镜导演 Agent 把剧情转成一条条镜头，艺术总监 Agent 生成角色、场景、道具等视觉素材；
3. 素材确认后进入视频生成阶段——它不是一次出整片，而是先分镜头生成多段视频，再剪辑组合成片；
4. 中途它会停下来让你确认关键节点（比如角色形象），你点确认或提出修改，流程继续。

几点实际体验上的提醒（来自公开测评）：

- 全自动模式下**不能指定用哪个模型**，想选模型得进画布手动创作；
- 生成的剧本冲突结构通常完整，但画面衔接、字幕、复杂场景的人物表现仍可能出问题，成片后逐段检查再发；
- 一集短剧从剧本到成片要生成的东西多，算力萝卜消耗远高于单张图片，额度紧张的话先从 30 秒的试播集开始。

提示词具体怎么写成「需求单」、生成途中在哪些节点插手，见[AI短剧提示词怎么写.md](AI短剧提示词怎么写.md)；想先立一个反复出现的角色再写剧本，看[打造专属IP形象与角色复用.md](打造专属IP形象与角色复用.md)。

## 三、画布手动创作：逐镜头精修

对成片有要求的用户走画布这条路。进入画布后，你能用到的关键能力：

- **模型选择**：可切换官方接入的多个视频模型（官方称接入 20+ 模型，名单持续在变——例如 2026 年 8 月前后接入过 Seedance 2.5 并在 PC 端配了限时五折，具体以 App 内当时显示为准，不同模型计费不同）；
- **文生视频 / 图生视频**：纯文字出片，或用一张图作为首帧；还有首尾帧生成，适合做转场；
- **运动控制与参考图**：控制画面里物体的运动方式，或用参考图约束风格；
- **导演台与多节点工作流**：把故事构思、镜头规划、生成修改拆成多个环节，你可以只重跑其中一环，不用整片重来；
- **画线标注与 Skills 风格库**：在画面上直接圈出要改的区域，或套用现成风格模板，减少「抽卡」次数；
- **清晰度**：支持 4K/2K 影视级超清输出，以及人像肤质优化。

手动模式生成每一段都是单独计次的，建议先拿 5 秒短片试模型和提示词，确定效果再铺开做完整镜头列表。

## 四、视频的清理与修复类需求

除了从零生成，视频方向还有一批「对已有素材动手」的功能，入口同样在对话或画布里：

- 视频高清修复（老视频提升清晰度）；
- 视频水印去除（只对你有权处理的素材使用）；
- 智能封面（从视频里挑并生成封面图）；
- 拆分图层（把视频主体和背景分层，方便单独替换）。

这类需求的单次消耗一般比从零生成低，适合先把存量素材翻新一遍再考虑做新片。
