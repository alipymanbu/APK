## 一、先把提示词写成「需求单」

在 Agent 全自动模式里，你给的不是一句台词，而是一份创作需求。RoboNeo 内置了短剧创作 Skills 和多套提示词模板，第一次用可以先套模板再改字段。一份够用的需求单包含这几个字段：

| 字段 | 写什么 | 例子 |
| --- | --- | --- |
| 项目目标 | 单集时长、画幅、画风、目标节奏 | 单集 1 分钟试播，竖屏 9:16，画风写实，面向短剧平台的爆款节奏 |
| 完成策略 | 先出试播还是直接连载 | 先完成这一集，满意后再规划连载 |
| 品类 | 短剧题材标签 | 职场打脸、甜宠、复仇、悬疑 |
| 主角设定 | 一两句人物反差描述 | 被裁员工看似小透明，实际核心系统是他一个人写的 |

「完成策略」这个字段最容易被漏，但它决定了 Agent 是收敛着做一集，还是摊开铺一个系列——额度有限时，永远先让它只出一集试播。

## 二、一个可以直接改的示例

下面这份是公开测评（2026 年 8 月）里实际跑通过整条流程的写法，你替换掉品类和主角设定就能用：

```text
创作一集1分钟的AI短剧试播集，要求如下：
【项目目标】单集1分钟试播，竖屏9:16，画风写实，面向短剧平台的爆款节奏。
先完成这一集，满意后再规划连载。
【品类】职场打脸
【主角设定】公司裁员，裁到了最不该裁的人头上。被裁的员工看起来是
普通工位上的小透明，实际上公司最核心的技术系统是他一个人写的，
连老板都要看他脸色。
```

这次生成里，Agent 把任务拆成了 4 个角色、3 个场景、2 个道具，再展开成 25 个镜头，从剧本一路走到成片，全程没有人工干预。写成「主角设定 + 反差」的形式，是因为短剧的钩子全在反差上——描述越具体，编剧 Agent 生成的冲突结构越接近你要的节奏。

## 三、生成途中你能在哪里插手

流程走到每个节点都会停下来等你确认，你可以全程不干预，也可以在任何一步插手：

1. **剧本节点**：编剧 Agent 出完剧本后，可以要求改冲突结构、加台词、调结局；
2. **分镜节点**：分镜导演 Agent 把剧情转成镜头语言后，可以砍掉多余的镜头；
3. **素材节点**：艺术总监 Agent 生成角色、场景、道具后，对某个角色形象不满意就让它重出——这是唯一后面改不动的东西，值得多花时间确认；
4. **成片后**：分段检查，哪段不行重生成哪段，不用整集重来。

只出一个「好角色」再往下走，比生成完一整集再换角色省得多。

## 四、写镜头的几个小技巧

- **用镜头语言而不是画面形容**：「切到办公室特写」「镜头拉远露出全景」这类指令，比「好看一点」「有电影感」更有效；
- **一次只改一处**：对结果提修改时逐条来——「先改发型，满意后再改服装」——一次塞进五个修改点，Agent 容易顾此失彼；
- **说明转场**：在提示词里直接写「切到」「镜头切换」，模型会自动保持主体、风格和环境的连贯；
- **竖屏优先**：发短剧平台就锁 9:16，别留横屏素材再裁。

## 五、写完之后算两笔账

**额度账**：一集短剧要生成剧本之外的大量视频片段，消耗远高于单张图片。公开测评给过一个量级：标准会员的 2000 算力萝卜配合当时限时五折的视频模型，大约够生成一分钟左右的成片；单价与折扣随时在变，以生成前界面显示的当次消耗为准，档位见[算力萝卜与会员订阅.md](算力萝卜与会员订阅.md)。

**返工账**：即便流程跑通，画面衔接、字幕、复杂场景里的人物细节仍是常见出问题的位置，成片后逐段检查再发布；生成中途掉线、任务丢失的处理见[登录注册与常见问题.md](登录注册与常见问题.md)。想先立一个反复出现的角色再写剧本，先看[打造专属IP形象与角色复用.md](打造专属IP形象与角色复用.md)。
