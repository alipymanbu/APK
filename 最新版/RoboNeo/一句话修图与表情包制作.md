## 一、对话式修图的基本节奏

和美图秀秀那种「找功能点按钮」的界面不一样，RoboNeo 打开后中间就是一个对话框。你上传一张照片，再用一句日常的话把要改的地方说出来，等一两分钟就能拿到改好的图。

一套完整动作是：

1. 在对话框里点「+」或图片按钮，从相册选一张照片发出去；
2. 紧接着用文字补一句需求，比如「把背景换成海边日落」「去掉画面右边的路人」；
3. 等待出图，期间不用一直盯着，但别把 App 切到后台太久——有用户反馈切走再回来任务会断；
4. 对结果不满意，直接在对话里追加一句「再改」，比如「表情更自然一点」，它会在原图基础上继续调。

这种「改到满意为止」的连续对话是它和传统修图软件最大的区别：你不用记功能在哪个菜单里，会描述就行。

## 二、一张照片能改什么

从官方介绍和实际体验汇总，图片方向的常见需求基本都覆盖：

| 你想做的事 | 在对话框里大概怎么说 |
| --- | --- |
| 换衣服 / 换发型 / 改姿势 | 「帮她换成白色连衣裙」「让他换个侧身站姿」 |
| 去路人 / 去杂物 | 「把左边的路人去掉，背景补自然」 |
| 换背景 | 「把背景换成纯白影棚背景」 |
| 扩图 | 「把这张图扩成 16:9，左右补全」 |
| 抠图 | 「把人物抠出来，导出透明底」 |
| 画质提升 | 「把这张老照片变清晰」 |
| 无痕改字 | 「把图里的日期改成 2026」 |
| 拆分图层 | 「把主体和背景拆成两层」 |
| AI 滤镜 | 「调成吉卜力动画风格」 |
| 水印清理 | 仅建议对你自己拥有或有权编辑的图片做清理 |

描述越具体，结果越接近预期。「修一下这张图」这种模糊指令，出图后大概率还要再返工一两轮。

## 三、表情包：它上线后最火的玩法

RoboNeo 2025 年 7 月上线一周就冲上中国区 App Store 图形与设计分类榜第一，社交平台上晒得最多的就是它生成的表情包——chibi 风格小人、动态 Emoji、卡通化头像都有人做。做法不难：

1. 上传一张人像照片（自拍、宠物照都行）；
2. 输入类似「在这张照片的右下角生成一个动态 Emoji 表情包」或「把这张照片做成 chibi 风格表情包」的话；
3. 出图后不满意就换风格词再试一轮，比如「圆润一点」「线条粗一点」「加上文字气泡」。

想做成能发的成套表情包，一次生成多张不同表情再手动挑，比一口气让 AI 生成九宫格更可控。生成完的图保存到手机相册后，微信里「添加单个表情」就能直接用。

## 四、修图时容易被问到的几件事

- **等待时间**：普通改图一般一两分钟；高峰期或复杂需求会更久，卡在生成中先别急着重发，重复提交会白耗额度。
- **原图会被覆盖吗**：对话里的每一轮结果都是新图，手机相册里的原图不受影响。
- **生成记录**：都在对话历史里，可以回翻；这也是不建议中途杀掉 App 的原因。
- **额度**：每次生成都会消耗当日免费额度或算力萝卜，图片类消耗低于视频，具体规则见[算力萝卜与会员订阅.md](算力萝卜与会员订阅.md)。

## 五、和美图秀秀怎么分工

两者都是美图公司的产品，但操作路数完全不同，按需求选即可：

| | 美图秀秀 | RoboNeo |
| --- | --- | --- |
| 操作方式 | 功能面板：找滤镜、点按钮 | 对话框：一句话描述需求 |
| 擅长 | 人像精修、日常快速修图、现成模板 | 复杂改图、设计物料、视频与短剧生成 |
| 官方定位 | 生活场景影像产品 | 生产力场景的 AI Agent |
| 出结果的路径 | 你自己动手，边点边看效果 | 你把需求说清楚，等它出图 |

简单的磨皮瘦脸，美图秀秀一步到位更快；「去路人、换背景、扩图、改字」这类没法点按钮完成的，或者压根不想学功能在哪的，RoboNeo 的对话式才省事。两者的修图思路差别，也正好是上文第一节说的「描述代替找功能」。

修图之外，它同样能一句话生成海报、商品图、LOGO 和物料图，玩法和修图一致；往视频方向走（短剧、图生视频、高清修复）则看[AI短剧与视频创作.md](AI短剧与视频创作.md)。还没装 App 的话，从[下载与安装教程.md](下载与安装教程.md)开始。
