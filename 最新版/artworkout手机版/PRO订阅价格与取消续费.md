## 一、免费版先用到什么程度

ArtWorkout 免费下载，装上就能画 —— 官网口径是「每天有免费绘画课程」，也就是说免费账号的可画内容是按天供给的，不是全库开放。免费版同时带广告。有第三方评测把免费版描述为「每天几节练习 + 广告，另有类似体力值的机制，用完要等或看广告」—— 这条来自单一评测来源，**实际以你应用内看到的为准**。

判断要不要订阅，就看两点：免费的每日额度够不够你每天画的量；锁住的课程（素描、透视、解剖这类成体系的内容）是不是你想学的。

## 二、PRO 给什么

官方应用说明列出的 PRO 权益是四条，没有更多：

1. 全部 3500+ 课程与课程库完整解锁；
2. 每周新课同步开放；
3. 多人绘画不限次（免费档的多人是受限的，见 [多人画画功能怎么玩.md](多人画画功能怎么玩.md)）；
4. 去掉广告。

## 三、价格是什么量级

订阅走应用商店的内购通道，**价格随地区与所选周期不同，一切以购买页面当时显示为准**。可以参考的两个口径：

- iOS 商店页面公示过的内购档位：**周订 6.99 美元、月订 7.99 美元、3 个月 29.99 美元、年订 41.99 / 59.99 / 69.99 美元**等多个档位并存；
- 第三方评测给出的常见口径是**年约 60 美元上下**。

换算下来周订与年订的单价差好几倍 —— 买之前先把周期看清楚，顺手算一下按你打算用多久哪种划算。另外留意首期是否有优惠价、续费恢复原价这类条款，都写在购买确认页里。

## 四、怎么取消自动续费

**在哪付的就在哪取消**，这是通用原则。按你当时的购买通道对号入座：

**Google Play（安卓常见）**
商店 → 右上角头像 → 付款和订阅 → 订阅 → 选中 ArtWorkout → 取消订阅。

**iPhone / iPad**
设置 → 顶部 Apple ID → 订阅 → ArtWorkout → 取消订阅。

**支付宝 / 微信代扣（国内渠道常见）**
支付宝：我的 → 设置 → 支付设置 → 免密支付 / 自动扣款 → 找到 ArtWorkout 关闭；
微信：我 → 服务 → 钱包 → 支付设置 → 扣费服务 → 选中后关闭。

**官方条款口径**：订阅默认按周期自动续费，你可以在应用内账户设置里取消，也可以用购买确认邮件里的管理链接取消；取消后**当期剩余时间仍然可用，到期才停止**，之后不再扣费。

## 五、扣错了、想退款

官方条款写的路径是：联系客服或通过购买确认邮件里的订阅管理链接申请，退款按原支付方式处理。客服邮箱 `support@artworkout.app`，邮件里附上扣费截图与账号信息。

如果是通过应用商店扣的款，商店侧通常也有独立退款入口（苹果走「报告问题」页面提交，谷歌 Play 在订阅记录里申请），两边走一条即可，同一件事别重复提交。退款政策以各渠道当时公布的规则为准。
