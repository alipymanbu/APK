## 一、多人模式是什么形态

一句话：**一张共享画布，几个人同时在上面画，笔触实时同步到彼此屏幕上**。官方对它的定位是既能和朋友约着画，也能直接匹配陌生玩家来一局快速对画。

和单人课程的关系是：多人并不另起一套内容，你照样是在课程的图与步骤框架下画，区别是同一时刻画布上不止你一个人。官方页面给出的典型玩法有两种：

- **约朋友**：把对方拉进你的画布，两人（或多人）画同一幅图，实时看到对方落笔；
- **匹配路人**：不约人时直接进快速匹配，和其他在线玩家随机配对对画。

## 二、怎么开一局

1. 打开应用，进到多人 / Multiplayer 入口（不同版本的入口名称与位置以应用内实际界面为准）。
2. 选「邀请好友」或「匹配」：邀请会给你一个可以发给对方的入口，匹配则由系统直接配人。
3. 进入共享画布后正常按步骤画 —— 对方的每一笔会实时出现在你屏幕上，你的也是。
4. 画完看双方的完成情况与评分，想再来一局就重复第 2 步。

前提条件只有两条：网络畅通（笔触同步全靠实时连接，网络不稳会表现为对方的笔画迟迟不出现）；账号状态允许你进多人（见下节）。

## 三、免费与 PRO 在多人上的差别

官方应用说明把「无限多人绘画」列在 PRO 权益里，也就是说**免费账号的多人次数 / 场次是受限的**，具体限制（每日场次还是功能整体加锁）以应用内实际显示为准；有第三方评测也把「免费版多人受限、PRO 完整开放」列为两档的主要差别。你不想订阅也能先试 —— 免费额度用完再决定要不要开，价格与判断标准见 [PRO订阅价格与取消续费.md](PRO订阅价格与取消续费.md)。

## 四、几个人用着最顺

按官方说明与公开报道的用法，这几类场景收益最明显：

| 场景 | 怎么用 |
| --- | --- |
| 家长带孩子画 | 一大一小进同一张画布，孩子照着大人的笔触画 |
| 远距离朋友 | 约个时间进同一节课，边画边聊 |
| 想看别人怎么下笔 | 匹配陌生人，观察对方处理同一根线的顺序与力度 |

反过来说，如果你只是想自己安静练画，单人课程就够了 —— 多人是附加玩法，不看它也不影响你把课程跟完（单人用法见 [新手从零开始怎么用.md](新手从零开始怎么用.md)）。

## 五、连不上、对方笔画不出来时

多人功能对网络的要求比单人课高，排查按这个顺序来：

1. 先切一次网络（Wi-Fi 与流量互换），确认不是当前网络整体不通；
2. 退出本局重进 —— 单局的房间连接坏了，重开一局比在里面等有效；
3. 确认不是账号侧的限制：免费额度用尽时多人会进不去或进去后没法开新局，对照 [PRO订阅价格与取消续费.md](PRO订阅价格与取消续费.md) 看自己是哪种情况；
4. 如果连单人课程都加载不出来，那是应用本身的网络 / 启动问题，见 [安装后打不开闪退怎么解决.md](安装后打不开闪退怎么解决.md)。
