## 一、多大的孩子能用

两个官方口径，都看一下：

- **应用商店年龄分级**：iOS 商店标的是 **4+**（全年龄），安卓侧第三方商店页面标的是 **PEGI-12**（12 岁以上）—— 两边标注不一致，内容本身是学画画、没有暴力或成人题材，实际按孩子年龄与理解力你来定。
- **条款要求**：使用条款写明，未达到所在地区「数字同意年龄」的孩子，只能在**家长或法定监护人陪同并明确同意**下使用；家长以孩子的账号同意条款，同时对孩子账号里的行为负责，**包括应用内购买**。

给孩子装之前，先自己过一遍应用（装法见 [下载与安装教程.md](下载与安装教程.md)），确认界面与课程内容符合你的预期，再交给他用。

## 二、应用会收集什么数据

官方隐私政策（最近更新于 2025-12-23）写的口径：

- **默认不收集个人身份信息**；
- 可能收集的你主动填的信息：**年龄、性别、邮箱、昵称**；
- 会自动收集：设备型号、设备与广告标识符（AdID、Firebase 实例 ID 等）、IP 地址、操作系统、使用数据与分析数据；
- 商店隐私标签还标明应用**用数据做追踪**（广告个性化那一类用途）。

给未成年人用时的三个动作：

1. **别填真实信息** —— 昵称用非真实姓名，邮箱用家长的而不是孩子的；
2. **在系统层关掉追踪**：安卓在 设置 → 隐私 → 广告（各品牌路径略有差异）里删除广告 ID / 关闭个性化广告；
3. **行使删除权**：想让孩子的数据被删除，隐私政策给的联系邮箱是 `privacy@artworkout.app`，写明要求行使访问、更正、删除（被遗忘）权利即可。

## 三、挡住误触付费

订阅与内购是应用里最容易被孩子点进去的东西，三道闸门：

| 闸门 | 怎么设 |
| --- | --- |
| 商店购买验证 | Google Play → 设置 → 认证 → 购买时需要密码 / 生物验证；苹果在 屏幕使用时间 里限制购买 |
| 支付工具侧 | 支付宝 / 微信里若有该应用的免密代扣，先关掉（路径见 [PRO订阅价格与取消续费.md](PRO订阅价格与取消续费.md)） |
| 事后核对 | 定期看商店订阅列表与账单，发现不明订阅立刻取消并按该篇第五节申诉 |

条款同时明确：**家长对孩子账号下的应用内购买负责** —— 也就是说买了再争议，主动权不在你这边，闸门设在前面最省事。

## 四、多人模式对孩子的额外注意

多人功能会和陌生人同画一张画布（玩法见 [多人画画功能怎么玩.md](多人画画功能怎么玩.md)）。条款把冒充他人、索取他人真实身份信息（全名、住址、邮箱、社交账号等）列为禁止行为，但**聊天内容的实时把关条款没有承诺**：

- 低龄孩子用多人模式时，家长尽量在场，或先只放开单人课程；
- 提醒孩子不在画布上写自己的真名、学校、住址这类信息；
- 作品要发到公开平台前，按 [画完的作品怎么保存与分享.md](画完的作品怎么保存与分享.md) 的口径处理，别带个人信息。

## 五、想清空重来

孩子用过一段时间后想抹掉重来：应用内的数据清除路径是 设置 → 应用 → ArtWorkout → 清除数据（**这会连画廊与练习记录一起清掉**，想留纪念先按 [画完的作品怎么保存与分享.md](画完的作品怎么保存与分享.md) 导出）；账号与服务端数据的删除，走本篇第二节给的隐私邮箱提出。
