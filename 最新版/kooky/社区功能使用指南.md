## 一、先弄清社区的范围划分

Kooky 的社区按艺人粉丝圈划分：注册时选了哪些艺人，就能浏览并发布哪些社区的内容；可以同时加入多个社区。你在某个社区发的帖子，只有这个社区里的人能看到，不会串到别的社区。

发帖点菜单中间的加号，先选目标社区，再写标题、正文或添加媒体。注册时选艺人的环节见 [注册登录与账号设置.md](注册登录与账号设置.md)。

## 二、能发什么内容

| 类型 | 说明 |
| --- | --- |
| 图片 | 上传照片（需要媒体权限） |
| GIF | 动图可直接发 |
| 纯文字 | 标题加正文 |
| 外部链接 | 贴其他平台的链接 |

## 三、四种信息流的区别

社区页里的信息流来源不同，各看各的：

| 信息流 | 显示什么 |
| --- | --- |
| My Feed | 你关注的人发的帖子 |
| Trending | 你所在社区的热门帖 |
| New | 你所在社区的最新帖 |
| HOT | 全部社区的热门帖 |

顶部有一排艺人按钮，不想看某个社区的内容时，把它对应的按钮关掉即可，不用退出社区。

## 四、互动与通知

- **关注**：在社区里看到合得来的人，进对方主页点关注；互关之后对方的帖子会出现在 My Feed。
- **点赞与评论**：别人点赞或回复你的帖子会有通知。注意每天点赞本身就是积分来源（用户帖子、投票页、杂志、KookyTV 都算），途径表见 [积分获取与使用攻略.md](积分获取与使用攻略.md)。
- **通知与屏蔽**：通知可以按偏好自定义，遇到不想交流的人可以拉黑。
- **与投票的联动**：你关注的艺人有正在进行的投票时，会自动出现在应用主页，直接点进去就能参与，规则见 [投票玩法与排名规则.md](投票玩法与排名规则.md)。

## 五、发帖要避开的红线

官方条款明确禁止的内容包括：针对个人或群体的诽谤骚扰、种族/性别/宗教等歧视、色情暴力内容、虚假诈骗信息、广告刷屏。违反会被官方处理，账号可能被限制；发现其他用户的违规行为可通过 `hello@kooky.io` 举报。

另外，成建制的粉丝组织（fanbase）可以申请把自家粉丝群注册为官方社区，入口是官方提供的[申请表单](https://forms.gle/tj51YVpiEKQrMzFk9)，审核通过后即拥有独立社区。
