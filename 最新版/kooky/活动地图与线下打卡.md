## 一、活动地图能看什么

应用底部右侧的 Map 标签（官网对应 Event 标签）是一张全球 K-Pop 活动地图，图上分四类事件，可用右侧四个图标分别开关：

| 类别 | 内容 |
| --- | --- |
| 官方活动 | 唱片公司与官方渠道举办的活动 |
| Kooky 活动 | Kooky 自己主办或赞助的活动 |
| 粉丝活动 | 粉丝自发的生日咖啡、应援等 |
| 广告 | 地铁站、灯箱这类应援广告位 |

地图可以按 My Artists 过滤，只看自己选的艺人；授权位置权限后会自动定位附近的活动，也可以拖动地图看其他地区，或在搜索页按艺人查。

## 二、现场打卡领积分

1. 到活动现场，打开 Map 点进该活动的页面。
2. 距离活动定位点 10 米以内时，打卡按钮才会激活。
3. 打卡成功得 50 Kooky，并生成一张打卡卡（Check-in Card）。

打卡卡存在 Profile → Check-ins 里，记录打卡时间与序号，有三个用途：留档你参加过的活动、某些按到场顺序排位的活动凭序号参与、可以保存到相册发到社交平台。

**打卡弹窗一直不消失怎么办**：先确认两件事——打卡日期与活动当天一致、自己确实在定位点 10 米内。都满足仍失败，点活动页里的 Having issues? 按钮上报官方处理。

打卡与提交活动拿到的积分，都归入免费积分的途径表，见 [积分获取与使用攻略.md](积分获取与使用攻略.md)。

## 三、自己提交活动拿 200 积分

入口在应用 Map 页的加号按钮，或网页 [kooky.io/event/new-event](https://www.kooky.io/event/new-event)。规则（截至 2026-09 的官方说明）：

| 规则 | 内容 |
| --- | --- |
| 奖励 | 常规活动 200 Kooky，大头贴（Photo Booth）类 50 |
| 审核时长 | 约 2~5 个工作日 |
| 提前量 | 活动开始前至少 1 周提交 |
| 每日上限 | 20 条 |
| 必填 | 准确的日期、时间、地址，并选择活动对应的艺人 |
| 标签 | 即使是成员个人活动，也必须带上组合名 |
| 禁止 | 把多日活动拆成 Day 1 / Day 2 分开提交 |
| 收录范围 | 只能提交 Kooky 已收录的艺人，艺人名对不上会被拒 |

需要准备的材料：活动日期时间地址、艺人与活动名、国家、活动类别（官方 Label 或粉丝 Fan）、封面图与说明图（封面用概念海报，说明页用活动指南海报），最好再附主办方社交账号或活动帖的链接，方便参与者查详情。

信息填错会被拒审、积分也拿不到，提交前逐项核对。

## 四、活动现场领周边的一般条件

粉丝活动的 freebies（小卡、杯套之类）通常不是到场就有，官方 FAQ 给出的一般性条件是：安装 Kooky、在应用社区里发过帖、关注官方 Instagram。这只是通用指引，具体以每场活动主办方公布的规则为准；社区发帖的方法见 [社区功能使用指南.md](社区功能使用指南.md)。反过来，想请 Kooky 赞助你办的活动，官方 FAQ 列的门槛是：落实场地（咖啡厅、商场、活动空间等），保证 30 人以上到场、30 次以上应用下载与 30 篇以上社区发帖，再发邮件到 `hello@kooky.io` 说明活动详情。

## 五、位置权限是前提

打卡与"找附近活动"都依赖定位。安装时拒绝了位置权限的话，这两项功能会受限，可以在系统设置里补开；各权限的用途见 [下载与安装教程.md](下载与安装教程.md)。
