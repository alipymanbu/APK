## 一、Kai 支持接哪些服务

Kai 是个「接口层」：模型跑在别人家的服务器上（或你本机的 Ollama 里），你把自己的账号凭证填进 Kai，它帮你把消息发过去、把回答收回来。v1.7.3 支持的服务就这几种：

| 服务 | 是什么 | 要不要花钱 | 你要准备什么 |
| --- | --- | --- | --- |
| 内置免费层 | 基于 Mistral AI 的免费通道 | 免费，免注册 | 什么都不用，打开就能聊 |
| Gemini | 谷歌的 Gemini（Google AI Studio 领 Key） | 有免费额度 | API Key |
| Groq | 主打高速推理的推理服务商 | 有免费额度 | API Key |
| xAI | Grok 系列模型 | 按其官方规则 | API Key |
| Ollama | 你自己电脑 / 局域网里跑的本地模型 | 免费 | 装好 Ollama，模型跑起来 |

查各服务的 Key 去哪领、免费额度多少，以对应官网当时显示为准；Kai 官方文档在 [https://kai9000.com/docs/](https://kai9000.com/docs/)。

## 二、添加一个服务（拿 Gemini 举例）

1. 打开 Kai，进**设置（Settings）**。
2. 选**添加服务（Add Service）**，在列表里挑一个服务商。
3. 把 API Key 粘进去。Kai 会校验连接，通过后自动把该账号可用的模型列表拉下来。
4. 在模型下拉框里选一个默认模型，之后聊天就用它。

Ollama 走的是另一条路：本机或局域网地址填进去即可，不需要 Key——前提是那台机器上 `ollama serve` 在跑、模型已经 pull 下来。

## 三、多个服务之间怎么切

- **聊天中途切**：v1.7.3 的主打能力就是服务间无缝切换（官方 README 原文 "seamless switch between services"）——同一个问题想换个模型再问一遍，切过去直接发就行。
- **免费层当兜底**：自己的 Key 用完额度或暂时没有，随时切回内置免费层继续聊。
- 切换入口在设置的服务列表里，把哪个设为当前服务，下一条消息就发给谁（具体交互以你装的版本界面为准）。

同一个问题在两个模型下答案不同是常态，拿不准就两边各问一遍再自己判断——Kai 只负责把你的消息送过去，不替模型打包票。

## 四、附件和朗读的限制（容易踩）

- **图片附件只有 Gemini 支持**：v1.7.3 的文件附件功能绑定 Gemini 服务，切到别的服务时附件入口不可用，不是按钮坏了。
- **语音朗读**是全局功能：回答出来后可以朗读，不挑服务。
- 想发图片，先切到 Gemini，再在输入框里加附件。

## 五、什么时候该接服务、什么时候免费层就够

- **随便聊、尝鲜**：免费层零配置，够用。
- **要发图片、要稳定上下文、要挑具体模型**：配一个 Gemini 或 Groq 的 Key。
- **隐私敏感的内容**：把 Ollama 装在自己机器上跑本地模型，全程不出网，见 [聊天记录加密与隐私说明.md](聊天记录加密与隐私说明.md)。

连不上、Key 校验失败、模型列表拉不下来，按 [常见问题与故障排查.md](常见问题与故障排查.md) 里对应的条目排查。
