## 一、消息发不出去 / 一直转圈

1. **先换服务试一下**：切到内置免费层发一条。免费层通了，说明是刚才那个服务的问题（Key、额度或网络）；免费层也不通，多半是网络本身出不去（试试切换 Wi-Fi / 流量，或确认是否需要代理）。
2. **看 Key 是否有效**：重新进设置校验一次该服务的连接，Key 填错、被服务商停用、额度耗尽都会失败。
3. **等一会儿再发**：服务商偶发超时很常见，隔几十秒重发一次即可。

## 二、内置免费层不能用了

免费层由官方按 Mistral AI 搭建，会有限流。v2.9.0 之后的官方版本在撞到限流时会主动给服务建议，但 v1.7.3 没有这个提示——**发不出去就当限流处理**：等几分钟，或临时切到自己的 Key（见 [添加AI服务与切换模型.md](添加AI服务与切换模型.md)）。

## 三、短信 / 日历 / 通知工具没反应

- **看开关**：设置 → 工具里那一个是否打开。
- **看权限**：安卓设置 → 应用 → Kai → 权限，确认对应权限已授予；曾经点了「拒绝」，工具就是静默失败。
- **看平台**：短信、日历、通知三个只在安卓版有，桌面 / 网页版看不到是正常的。
- 细节见 [短信与日历工具怎么用.md](短信与日历工具怎么用.md)。

## 四、发不了图片

v1.7.3 的图片附件**只在 Gemini 服务下可用**——先切到 Gemini 再发；其他服务下附件入口不可用是版本设计，不是故障。另外确认已授予存储/媒体权限。

## 五、装不上 / 打开就闪退

- **安装被系统拦**：非应用商店来源的 APK 需要临时允许「安装未知应用」，按提示开一次即可（详见 [下载与安装教程.md](下载与安装教程.md)）。
- **解析包错误**：文件没下完整，重新下载；核对 MD5 是否为 `CD743D3705FB2CD750DDD341ADDB1EBE`。
- **闪退**：先确认系统版本在安卓 5.2 以上；仍闪退就重启手机再开一次，不行则到 GitHub Releases 换个新版本装（见下节）。

## 六、要不要升级到新版

网盘这份是 v1.7.3（2026-02-21 发布）。官方后来加了不少功能——持久记忆、心跳自检、MCP 服务器、Linux 沙盒、互动界面等，应用名也改成了 Kai 9000。升级注意三点：

1. **升级入口认准官方**：[GitHub Releases](https://github.com/SimonSchubert/Kai/releases)、[Google Play](https://play.google.com/store/apps/details?id=com.inspiredandroid.kai) 或 [F-Droid](https://f-droid.org/en/packages/com.inspiredandroid.kai/)，具体最新版本号以页面当时显示为准。
2. **包名不变**（`com.inspiredandroid.kai`），直接装新包即可覆盖升级，聊天记录在本地。
3. **旧版能用就别强升**：只想用「多服务切换 + 短信日历工具」这些基础能力，v1.7.3 完全够；要新功能再升，升完按新版文档核对自己少看了哪些设置。
