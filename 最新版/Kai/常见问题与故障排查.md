# Kai 常见问题与故障排查

> 这篇按「症状 → 原因 → 怎么办」整理 Kai 安卓版最常见的坑：连不上服务、密钥失效、工具没反应、记录丢失、要不要更新到新版。

## 一、消息发不出去 / 一直转圈

1. **先换服务试一下**：切到内置免费层发一条。免费层通了，说明是刚才那个服务的问题（Key、额度或网络）；免费层也不通，多半是网络本身出不去（试试切换 Wi-Fi / 流量，或确认是否需要代理）。
2. **看 Key 是否有效**：重新进设置校验一次该服务的连接，Key 填错、被服务商停用、额度耗尽都会失败。
3. **等一会儿再发**：服务商偶发超时很常见，隔几十秒重发一次即可。
4. **网络要走代理的看这里**：Kai **没有应用内代理设置**——有用户在[官方仓库](https://github.com/SimonSchubert/Kai/issues/509)提需求（加 socks5 支持），截至 2026-09 官方还没做。所以代理/VPN 要在**系统层**配好（系统代理或 VPN 模式），让 Kai 的请求整体走过去，应用内没有开关可调。
5. **先变慢、后彻底没反应**：官方 issue 区有[用户反馈过这个症状](https://github.com/SimonSchubert/Kai/issues/505)——开始是回答越来越慢，然后完全不响应，换成官方内置通道也一样（2026-09 提出）。这种情况先杀掉应用重开；重开无效就按上面 1~4 条逐项排除，多半落在网络与服务商侧。

## 二、内置免费层不能用了

免费层由官方按 Mistral AI 搭建，会有限流。v2.9.0 之后的官方版本在撞到限流时会主动给服务建议，但 v1.7.3 没有这个提示——**发不出去就当限流处理**：等几分钟，或临时切到自己的 Key（见 [添加AI服务与切换模型.md](添加AI服务与切换模型.md)）。

## 三、短信 / 日历 / 通知工具没反应

- **看开关**：设置 → 工具里那一个是否打开。
- **看权限**：安卓设置 → 应用 → Kai → 权限，确认对应权限已授予；曾经点了「拒绝」，工具就是静默失败。
- **看平台**：短信、日历、通知三个只在安卓版有，桌面 / 网页版看不到是正常的。
- 细节见 [短信与日历工具怎么用.md](短信与日历工具怎么用.md)。

## 四、发不了图片

v1.7.3 的图片附件**只在 Gemini 服务下可用**——先切到 Gemini 再发；其他服务下附件入口不可用是版本设计，不是故障。另外确认已授予存储/媒体权限。

升级到新版后如果换用 Groq 发图，注意一条真实反馈：有用户在官方仓库报告[用 Groq 全部模型发图都报 "Image is too large"](https://github.com/SimonSchubert/Kai/issues/491)（安卓与桌面都复现，同一 Key 在别的客户端正常，2026-09 提出）。遇到这个报错先换 Gemini 发同一张图，能发就说明是 Groq 通道的问题，不是你的图片太大。

## 五、发完消息切后台，记录丢了 / 一直加载不出来

有中文用户在[官方仓库反馈](https://github.com/SimonSchubert/Kai/issues/483)：发送消息后把应用切到后台（切别的 App 或锁屏），再回来时聊天记录出现丢失或没加载出来的情况，反馈称**频繁出现、非偶发**（2026-09 提出，截至检查时仍在跟进）。实际应对：

1. **发完重要消息先等回包再切走**——返回后先等它把记录加载完，别一回来就连续操作。
2. **回来发现记录空**：等几秒让它加载、或杀掉重开一次；会话数据在本地，通常不是真丢，是没加载出来。
3. 重要答复**手动复制一份**再切后台，别赌它一定还在。
4. 这是官方仓库已收到的反馈（截至 2026-09 尚未看到修复版本）；在修复落地前，上面三条就是临时办法。

## 六、装不上 / 打开就闪退

- **安装被系统拦**：非应用商店来源的 APK 需要临时允许「安装未知应用」，按提示开一次即可（详见 [下载与安装教程.md](下载与安装教程.md)）。
- **解析包错误**：文件没下完整，重新下载；核对 MD5 是否为 `CD743D3705FB2CD750DDD341ADDB1EBE`。
- **闪退按这个顺序试**：重启手机 → 安卓设置 → 应用 → Kai → **清除缓存**（清缓存不丢会话数据）→ 再不行确认系统版本在安卓 5.2 以上。
- **发大图 / 大附件后闪退（升级到新版的用户注意）**：官方仓库有[安卓闪退的日志](https://github.com/SimonSchubert/Kai/issues/475)，指向单条消息过大撑爆本地存储；官方在 v3.2.0 的更新说明里写了对应修复（cap stored message size）。别往会话里塞超大附件；闪退了先删掉那条大消息，或升到带修复的版本。

## 七、要不要升级到新版

网盘这份是 v1.7.3（2026-02-21 发布）。官方后来加了不少功能——持久记忆、心跳自检、MCP 服务器、Linux 沙盒、互动界面等，应用名也改成了 Kai 9000。升级注意四点：

1. **升级入口认准官方**：[GitHub Releases](https://github.com/SimonSchubert/Kai/releases)、[Google Play](https://play.google.com/store/apps/details?id=com.inspiredandroid.kai) 或 [F-Droid](https://f-droid.org/en/packages/com.inspiredandroid.kai/)，具体最新版本号以页面当时显示为准。
2. **Play 商店版常常落后于 GitHub Releases**：有用户在[官方仓库催过 Play 的上架进度](https://github.com/SimonSchubert/Kai/issues/498)——同一个版本 GitHub 已经发了，Play 还没更新。想第一时间拿到新版就走 Releases 下 APK 手动装；不急就等商店自动更新。
3. **包名不变**（`com.inspiredandroid.kai`），直接装新包即可覆盖升级，聊天记录在本地。
4. **旧版能用就别强升**：只想用「多服务切换 + 短信日历工具」这些基础能力，v1.7.3 完全够；要新功能再升，升完按新版文档核对自己少看了哪些设置。
