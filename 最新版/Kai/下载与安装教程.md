## 一、先搞清楚：你装的可能是哪个版本

Kai 是德国开发者 Simon Schubert 写的开源 AI 聊天客户端，安卓、iOS、Windows、macOS、Linux、网页版都有，包名统一是 `com.inspiredandroid.kai`。它自己不带模型，而是把你手上的 AI 服务（Gemini、Groq、xAI、Ollama 本地模型，以及内置免费层）接到一个界面里聊。

这里要留意版本差异：

| 项目 | 网盘里的这份包 | 官方渠道最新版 |
| --- | --- | --- |
| 版本号 | 1.7.3（2026-02-21 在 GitHub 发布） | 持续更新中，以官方页面当时显示为准 |
| 安装包大小 | 4.46 MB | 数十 MB（功能加了很多） |
| 官方名称 | Kai | 后来改叫 Kai 9000 |

网盘里这份是 v1.7.3，本文余下内容都按这个版本讲；新版多出来的功能（比如记忆、心跳这类）装到新版才看得到，别在 1.7.3 里找不到就以为是坏了。

## 二、安装包从哪拿

**最省事的方式**是直接从网盘转存：打开 [Kai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/21dc679261a3)，把 `Kai_v1.7.3.apk` 转存到自己的网盘后下载到手机。转存的意义在于分享链接长期稳定——原文件更新换代后，你手里的入口照样能用。

想核对包没下错，可以看这几个事实（以本地记录为准）：

```text
版本：1.7.3
包名：com.inspiredandroid.kai
大小：4.46 MB
MD5：CD743D3705FB2CD750DDD341ADDB1EBE
```

官方渠道则有这些（想追新版从这里走）：

- GitHub Releases：[https://github.com/SimonSchubert/Kai/releases](https://github.com/SimonSchubert/Kai/releases) —— 各平台安装包都在这，APK 也在其中
- Google Play：[https://play.google.com/store/apps/details?id=com.inspiredandroid.kai](https://play.google.com/store/apps/details?id=com.inspiredandroid.kai)
- F-Droid：[https://f-droid.org/en/packages/com.inspiredandroid.kai/](https://f-droid.org/en/packages/com.inspiredandroid.kai/) —— 开源商店渠道
- 网页版：[https://simonschubert.github.io/Kai/](https://simonschubert.github.io/Kai/) —— 不装应用也能在浏览器里试

**追新版以 GitHub Releases 为准**：Play 商店的上架进度有时落后一拍（有用户在[官方仓库催过](https://github.com/SimonSchubert/Kai/issues/498)），同一版本 Releases 已经挂出来、Play 还没更新是发生过的；F-Droid 同理有自己的审核节奏，具体以各页面当时显示为准。

## 三、安装步骤

1. 把 APK 传到手机（下载到手机本地，或用数据线 / 互传工具从电脑拷过去）。
2. 点击 APK 安装。系统若弹出「禁止安装来自此来源的应用」，是安卓对非应用商店来源的默认拦截——到设置里允许本次安装即可（不同品牌菜单名略有差异，常见叫「安装未知应用」）。
3. 装完打开，首次启动是一屏带动画的欢迎聊天页。

整个包只有 4.46 MB，装完占用也很小，老一点的安卓机也能跑。

## 四、装完先干什么：不配密钥也能聊

Kai 内置了一个**免费层**（基于 Mistral AI 提供），首次打开**不需要填任何 API Key**，直接在输入框里发消息就能聊——你可以先这么体验一轮，觉得顺手再考虑接自己的服务。

想接自己的模型服务时，去设置里添加（Gemini、xAI、Groq、Ollama 都支持），步骤见 [添加AI服务与切换模型.md](添加AI服务与切换模型.md)。短信、日历这几个安卓专属工具要单独开权限，见 [短信与日历工具怎么用.md](短信与日历工具怎么用.md)。

## 五、系统要求

- 安卓 5.2 以上（按这份包的记录；实际以安装时的系统提示为准）
- 界面语言支持简体中文，装完在设置里可切
- 需要联网才能连 AI 服务；只有用 Ollama 本地模型时可以完全离线

装完打不开、连不上服务，直接翻 [常见问题与故障排查.md](常见问题与故障排查.md)。
