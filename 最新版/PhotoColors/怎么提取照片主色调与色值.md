# PhotoColors 怎么提取照片主色调与色值

想把某张照片、某张截图的配色记下来，对着屏幕手动吸色又慢又容易偏，用色盘模式会自动读出画面里的主色和对应的十六进制（HEX）色值。本篇按「找到入口 → 走流程 → 色值怎么用 → 结果不对怎么查」的顺序讲，适合做设计参考或者给 PPT 配色的场景。

## 一、先弄清入口在哪

模式不是每张照片单独设的：PhotoColors 把模式切换集中在**右上角的设置项**里，先选「琉璃色盘」，再挑要识别的图片。找不到入口时，先回主界面点右上角，不要在照片上长按找。

安装包本身在 [PhotoColors 安装文件资源（夸克网盘）](https://pan.quark.cn/s/061d2749fc1d) 里，还没装的先照 [下载与安装教程.md](下载与安装教程.md) 装好，再回来做这一步。

## 二、一步步提取色卡

1. 打开应用，点「加号」上传要分析的照片——日常随手拍、街景、穿搭图、设计稿截图都可以；
2. 需要的话先裁一下画面比例：只想要画面上某一块的配色时，先把无关部分裁掉，结果会干净得多；
3. 点右上角进设置，选「琉璃色盘」模式；
4. 选中这张图片，等它给出色卡；
5. 逐个看色卡上的颜色与色值，需要哪个就复制哪个。

静态图和实况（动态）照片都支持分析，色盘看的就是画面本身的配色。想验一验导出是否正常，做完直接保存一次，去系统相册确认。

## 三、色卡上的东西分别能拿去做什么

| 输出 | 形式 | 常见用法 |
| --- | --- | --- |
| 主色块 | 按画面占比排布的若干颜色 | 快速判断这张照片的整体色调，选配图时对照 |
| HEX 色值 | `#RRGGBB` 形式的字符串 | 粘贴进设计工具、PPT 主题色、网页 CSS 里直接用 |
| 色卡图 | 导出的 JPG / PNG | 存进素材库归档，或者直接发给一起做事的人 |

HEX 色值的好处是到处都认：它不依赖某一家软件，复制的是一段字符串，贴到哪都成立。做品牌或系列内容时，把同一批照片的色卡放一起对比，能很快看出配色是不是统一。

## 四、结果不满意时按这个顺序查

多数「提得不准」不是软件出错，而是照片本身的信息不够，按下面的顺序过一遍通常就清楚了：

1. **画面本身接近单一色调**——大面积同色、或者接近黑白灰的照片，能提炼出来的颜色本来就少，不是提取失败；
2. **照片被压缩或转发过**——聊天软件发的图、二次保存的截图，色彩层次已经被压掉，提出来会偏灰、偏平；
3. **要的是局部，识别的是整张**——先按第二节第 2 步裁剪，再重新识别；
4. **对照验证**——换一张同类场景的相机原图试一次，如果那张正常，说明问题出在前面那张照片上。

如果色卡能出来、但保存时提示失败或者相册里找不到文件，那是权限与存储的问题，不在这条链路里，按 [保存失败与定位不显示怎么办.md](保存失败与定位不显示怎么办.md) 处理。

## 五、色盘和卡片是两条不同的路

同一张照片，走琉璃色盘模式得到的是颜色清单，走灵动卡片模式得到的是带时间地点排版的成品图，两者入口不同、用途也不同。如果目标是发一条内容而不是记录配色，直接看 [灵动卡片怎么制作.md](灵动卡片怎么制作.md)，不用在色盘上反复调。
