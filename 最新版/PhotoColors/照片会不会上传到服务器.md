# PhotoColors 照片会不会上传到服务器

> 本篇说明 PhotoColors 的照片处理发生在哪一侧、哪些环节才真的需要联网，以及分享卡片前最容易忽略的一处隐私细节。

处理照片时会不会被传到别人的服务器，是选这类工具时最该先弄清的一件事。PhotoColors 的照片、色彩信息和卡片内容都在本机处理，不上传远端服务器——官方站点 [photocolors.app](https://photocolors.app/) 也写明了这一点。本篇讲清哪些环节在本机、哪些环节才需要联网。

## 一、处理在本机完成

读照片、算色盘、生成卡片这几步，都在手机上完成，不上传素材。这也带来一个你可以自己验证的结果：网络很差、甚至把移动数据关掉，色盘和卡片照样能出结果——如果中间要把原图传到服务器再传回来，弱网下是做不到的。

## 二、哪些环节才需要联网

| 环节 | 是否需要网络 | 说明 |
| --- | --- | --- |
| 打开应用、选照片、出色卡 | 不需要 | 图片读取与处理都在本机进行 |
| 生成卡片、导出保存 | 不需要 | 成品直接写回本机相册 |
| 转存或下载安装包（[PhotoColors 安装文件资源（夸克网盘）](https://pan.quark.cn/s/061d2749fc1d)） | 需要 | 网盘本身的转存、下载操作要走网络 |
| 装新版本 / 更新 | 需要 | 更新走应用商店或重新下载安装包 |

**自己验证一遍的办法**：把手机切成飞行模式，打开应用走一遍色盘流程。处理确实在本机的话，这一步能正常出结果；反过来，如果非要联网才能出图，那才需要怀疑素材被送走。这是判断同类工具时最直接的一招，不依赖任何口头承诺。

## 三、权限给到之后，应用能看到什么

相册权限决定它能读到哪些照片。授权之后它能读到被允许的那些照片，用于在本机生成色卡或卡片；被允许读取，不等于素材会被外发。

卡片上的地点和时间来自照片文件本身的拍摄记录，不是手机的实时定位。也就是说，它不需要持续获取你当前在哪，也读不到你没给它看的照片。

## 四、卡片上的地点是最容易忽略的一处

卡片模式会把照片自带的拍摄地点排到成品图上——它的用处就在这儿，但这也是最容易不小心公开的一处信息。发之前看一眼那张卡片：家里、公司、常去的店、孩子的学校这些位置要不要露出来。不确定就把地点那行文字删掉再导出——排版照样成立，只是少了一行字。

同理，如果你要把色卡或者卡片发给合作方，先确认画面里没有工牌、门牌、快递单这类顺带拍进去的信息。

## 五、网盘那份安装包和你的照片没有关系

从 [PhotoColors 安装文件资源（夸克网盘）](https://pan.quark.cn/s/061d2749fc1d) 拿到的只是安装文件，装到手机上之后照片处理仍然在本机完成，网盘账号里不会因此多出你的照片——那边放的是安装包，不是素材库。

还没装应用的话，先按 [下载与安装教程.md](下载与安装教程.md) 把包装上；想从照片里取出一组配色，具体操作看 [怎么提取照片主色调与色值.md](怎么提取照片主色调与色值.md)。如果保存或读地点时出了岔子，那不是隐私设置的问题，按 [保存失败与定位不显示怎么办.md](保存失败与定位不显示怎么办.md) 排查。
