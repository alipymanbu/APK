# PhotoColors 保存失败与定位不显示怎么办

> 本篇把「相册里选不到照片」「导出保存不了」「卡片上没有地点或时间」这几类问题按现象排一遍，每条都给出在手机上的具体处理位置。

这类工具用起来出问题，绝大多数不是应用坏了，而是权限没给全，或者照片本身缺少要读的那项信息。本篇按「先对现象找原因，再讲地点时间为什么读不到，最后是装不上打不开」的顺序过一遍，遇到问题直接跳到对应那一节。

## 一、按现象找原因

| 现象 | 最可能的原因 | 怎么处理 |
| --- | --- | --- |
| 点「加号」进来相册是空的 | 相册权限没给，或者只允许了部分照片 | 设置 → 应用 → PhotoColors → 权限，改成允许访问全部照片 |
| 相册有图但选不中某几张 | 同上，部分授权模式下未勾选的图不可读 | 同上，或先把那几张图挪进被允许的范围 |
| 导出后系统相册里找不到 | 写回相册的权限没给；或相册应用还没刷新 | 给存储 / 照片写入权限，用文件管理器看一眼相册目录，或重启相册应用 |
| 保存到一半失败 | 剩余空间不足 | 清出空间再试；安装包 250.16 MB，处理后的成品也要额外占空间 |
| 卡片上没有地点 | 原照片本身没有定位记录 | 见第二节 |
| 卡片上日期不对 | 照片的时间是转存、截图时生成的新时间 | 改标题里的文字，或者换相机原图重做一张 |
| 找不到模式切换入口 | 入口集中在右上角设置里，不在画面上 | 见第三节 |

## 二、地点和时间到底从哪里读

这两项读的是**照片文件自带的拍摄记录**，不是应用去查你当前在哪：

- 拍照时相机开着位置记录，照片里才会带上地点；关掉之后拍的照片，无论用什么模板都不会显示地点；
- 截图、聊天软件转发过的图、被二次压缩保存的图，这些信息通常已经被清掉了；
- 从别人那儿收藏来的图，即使画面里明明是个地标，文件里也未必留着定位。

所以卡片上没有地点，先回到「这张照片是怎么来的」这一步判断，而不是反复换模板试。要做出带地点的卡片，拿手机相机现拍一张、并确认相机的位置记录是开着的，是最稳的做法。

## 三、模式入口在哪

「琉璃色盘」「灵动卡片」这类模式集中在**右上角的设置项**里切换，不是在某一格画面上长按出来的。不同版本的界面细节可能略有出入，你装的是哪一版，以 [下载与安装教程.md](下载与安装教程.md) 里核对过的版本信息为准。

模式选好之后的具体流程，色盘看 [怎么提取照片主色调与色值.md](怎么提取照片主色调与色值.md)，卡片看 [灵动卡片怎么制作.md](灵动卡片怎么制作.md)。

## 四、装不上、点开就退

1. **安装包不完整**：重新下载一次，并按 [下载与安装教程.md](下载与安装教程.md) 表格里的 MD5 核对——对不上就是文件下坏了，换 [PhotoColors 安装文件资源（夸克网盘）](https://pan.quark.cn/s/061d2749fc1d) 里那份重下；
2. **系统版本过低**：安装时若提示「与你的设备不兼容」，说明手机系统版本低于这份包要求的基线，换台设备或升级系统再试；
3. **手机里已有更高版本**：安卓不允许低版本覆盖高版本，会直接报「应用未安装」，先卸载旧版再装（应用内的数据会一并清掉）；
4. **被安全软件或文件管理器拦下**：允许未知来源应用安装，或先关掉拦截提示再点安装包；
5. **点开就闪退**：先在设置里把相册权限给全再打开——首屏要读相册，权限没给时容易直接停在启动阶段。

## 五、还是不行，按这个顺序排除

1. 换一张**相机原图**再走一遍，确认问题出在照片本身还是应用上；
2. 从后台彻底关掉应用再重开，排除一次性的读取失败；
3. 看手机剩余空间，空间不足时保存类操作会失败；
4. 前面都试过仍不行，卸载重装一次（数据会清掉），安装包从 [PhotoColors 安装文件资源（夸克网盘）](https://pan.quark.cn/s/061d2749fc1d) 重取，别用手机上残留的旧包；
5. 记录手机型号与系统版本，连同出问题的照片来源（相机原图还是截图）一起反馈给开发者，比只说「保存不了」更容易被定位。

处理照片时到底联不联网、权限给出去之后应用能看到什么，见 [照片会不会上传到服务器.md](照片会不会上传到服务器.md)。
