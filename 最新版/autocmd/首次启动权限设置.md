## 一、为什么要先开权限

自动化工具要替你点屏幕、弹提示、定时干活，靠的都是系统级能力：模拟点击走无障碍服务，悬浮控制条走悬浮窗权限，定时与提醒走通知。权限没开全时，最直接的表现是脚本建不了、或者运行到某一步就停。首次启动时应用会自己弹授权引导，跟着开即可；漏掉的可以之后在系统设置里补。

## 二、必须开的三项

第一次进应用时按弹窗引导逐个授予，缺一项自动化就跑不全：

| 权限 | 系统设置里的入口（各品牌叫法略有差异） | 管什么 |
| --- | --- | --- |
| 无障碍服务 | 设置 → 更多设置 / 辅助功能 → 无障碍，找到 AutoCMD+ 开启 | 模拟点击、滑动、屏幕内容拾取，是所有屏幕类动作的基础 |
| 悬浮窗（显示在应用上层） | 设置 → 应用管理 → AutoCMD+ → 权限 | 运行时悬浮条、任务提示 |
| 通知权限 / 通知使用权 | 设置 → 通知管理，或授权管理里 | 推送运行通知、读取通知（「收到通知时」触发器也靠它） |

部分国产系统还会要求「允许自启动」「后台弹出界面」两项，跟着引导一起开掉，能减少后面很多「脚本不触发」的麻烦。

## 三、按需开的权限

下面这些对应具体动作，你用不到的动作可以不开对应权限。清单来自官方商店披露的敏感权限说明：

| 权限 | 对应的动作或触发器 |
| --- | --- |
| 存储权限 | 下载、读取、写入文件 |
| 短信权限 | 读取、发送短信；「收到短信时」触发器 |
| 位置权限 | 「到达指定位置时」触发器、获取当前位置 |
| 麦克风 | 录音、语音识别 |
| 传感器 | 「敲击屏幕」「敲击背部」触发器 |
| 系统设置修改 | 设置亮度 |
| 蓝牙 | 获取当前蓝牙状态 |

注意部分动作在较新版本才加入（如敲击类触发器），你手上的版本如果没有对应动作，相关权限也不用开。

## 四、权限会掉，脚本会停

用一段时间后如果发现「以前能跑的脚本不触发了」，先查权限再查脚本：

- **无障碍服务被关**：系统升级、安全软件「一键加速」、部分机型的省电策略都会把无障碍掐掉，重新到无障碍列表里开回来即可；
- **后台被清理**：把 AutoCMD+ 加入电池优化白名单（各品牌入口：设置 → 电池 / 省电 → 应用行为管理），并允许自启动；
- **锁屏后定时任务不触发**：在电池与权限管理里允许「锁屏运行」或「后台运行」。

排查不到原因时，把脚本的运行日志翻出来看停在哪一步，对照 [创建第一个自动化脚本.md](创建第一个自动化脚本.md) 的运行与日志一节继续查；更系统的排查路径见 [脚本不触发排查指南.md](脚本不触发排查指南.md)。

## 五、无障碍权限的安全边界

无障碍权限能读屏幕内容、能模拟点击，所以监管和安全软件都盯着它：据 2026 年 7 月的公开报道，一款自动化软件因用无障碍与通知权限自动化操作微信、抖音等第三方应用，被认定构成不正当竞争并处罚（背景见 [自动化仓库与社区用法.md](自动化仓库与社区用法.md) 第五节）；无障碍权限同时也是电信诈骗盯上的入口。落到你自己身上就三条：

- 只给你信任、且确实需要的应用开无障碍，不用了可以关；
- 任何陌生来电、短信、网页让你「开启无障碍服务」的，直接拒绝——正规业务不需要它；
- 开了无障碍之后，手机上的支付、聊天类应用对它就是可见的，装应用之前想清楚这一层。
