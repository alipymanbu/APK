## 一、给谁看这篇

你是服务器的频道主或管理员，手里有个几十人到几千人的社区，需要：把人分层、控制谁能进哪个频道、加个机器人自动签到抽奖。普通成员可以只看第二节，了解自己为什么进不去某个频道。

## 二、角色分层：管理上千人的基本功

Fanbook 的管理方式是**角色制**：给成员打上不同角色，每个角色配一组权限，成员的实际权限是其所有角色权限的叠加。典型分法：

| 角色 | 典型权限 |
| --- | --- |
| 频道主/管理员 | 全部权限，可改设置、踢人、封禁 |
| 版主/编辑 | 删除消息、置顶、管理某个分区 |
| 核心成员 | 只在部分受限频道发言 |
| 普通成员 | 公开频道发言、进语音房 |
| 访客/新人 | 只读，需完成验证后升级 |

先建角色、再往角色里加人，而不是逐个改成员 —— 人一多逐个改必然失控。角色之间可以设优先级，冲突时高优先级的说了算。

## 三、频道与可见性设置

- **公开频道 vs 私密频道**：私密频道只有指定角色能看到，用来放管理讨论、核心群内容。
- **只读频道**：公告、版本更新这类频道设成只有管理员能发言，普通成员只能看 —— 成员「发不出消息」多半是这个原因，不是故障。
- **频道分类**：把同用途的频道归到一个分类下，列表长了才不会乱。

改完设置建议用小号或让朋友截个图反馈，从普通成员视角确认一遍效果。

## 四、机器人（Bot）能干什么

Fanbook 内置机器人市场，加进服务器就能用，常见的一批能力：

- **签到、积分、积分兑换**：成员每日签到攒分，用积分换奖励，是最基础的活跃工具。
- **小游戏类**：成语接龙、俄罗斯方块、关卡编辑器等，用来做日常互动。
- **投票、抽奖、迎新**：活动运营常用，新人进服自动欢迎/验证也靠这类机器人。
- **管理类**：关键词过滤、不活跃清退、禁言、进服验证。

机器人的命令在聊天里通过 `@机器人` 触发，输入框上方会临时列出它支持的命令；管理员还可以把常用命令固定在输入框上方，成员点一下就能用。命令按可见性分级：所有人可见、仅私聊可见、仅机器人创建者可见三种 —— 看不到某个命令通常是权限级别设的，不是机器人坏了。

## 五、把机器人加进服务器

1. 在机器人市场（或机器人详情页）选中目标机器人。
2. 选择要加入的服务器 —— 你必须是该服务器的管理员，否则没资格添加。
3. 确认授权，机器人出现在成员列表里。
4. 回到频道 `@` 它发一条测试命令，有回复说明权限正常。

没有响应时的排查顺序：机器人是否真在这个服务器里 → 你是否有权限调用该命令 → 频道是否限制了机器人发言。更多对照见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 六、常见数量上限一览

官方开发者平台的接口错误表把这些上限写得最清楚（客户端提示文案可能不同，以界面实际显示为准）：

| 撞到的上限 | 界面可能给你的提示 |
| --- | --- |
| 可创建的服务器数量 | 你可创建的服务器已达上限 |
| 可创建的频道数量 | 创建频道数超出最大 |
| 一个证件能实名的账号数 | 你的证件号码可认证的账号数量已达上限 |
| 聊天群人数 | 聊天群超出最大人数限制 |
| 服务器里可设置的成员项 | 用户已经达到服务器可设置上限 |

撞到上限的通用处理：**删旧的、合并同类项，而不是反复重试** —— 重试多少次都一样。服务器实际能容纳的人规模很大（公开合作资料给过几万到上百万人的说法，属宣传口径），日常撞到的基本都是上面这几条，不是服务器装不下。

## 七、想自己开发机器人

官方开发者平台 [open.fanbook.mobi](https://open.fanbook.mobi/) 提供 Bot API 文档、机器人令牌与 SDK 接入说明，创建应用后即可拿到 clientID。这一层面向有开发能力的人，普通管理员用内置机器人市场就够了，不必碰 API。
