## 一、先归类，再动手

不同症状的起点不一样，别一上来就卸载重装：

| 症状 | 大概率原因 | 从哪节开始 |
| --- | --- | --- |
| 提示网络连接超时 / 一直转圈 | 网络或服务端 | 第二节 |
| 打开就闪退、播放中闪退 | 缓存异常、空间不足、版本旧 | 第三节 |
| 有声音没画面 / 后台老是断 | 权限没给 | 第四节 |
| 装不上 / 装完打不开 | 安装包或系统问题 | [下载与安装教程.md](下载与安装教程.md) |

## 二、网络类：超时、转圈、加载失败

按顺序试，一般走到第二三步就好：

1. **换网络**：Wi-Fi 和移动数据互切一次——很多「连不上」其实是当前这个 Wi-Fi 的问题。
2. **强停重开**：设置 → 应用管理 → 猫耳FM → 强行停止，再打开。
3. **换个时段**：热门剧集更新时段服务端压力大，隔十几分钟再试。
4. **清缓存**：缓存文件本身损坏也会表现为加载失败，长按图标 → 应用信息 → 存储 → 清除缓存（**清缓存不等于清除数据**，先只清缓存）。
5. **查代理/VPN**：挂着代理时反而容易超时，关掉再试。

> 曾有用户在应用商店评论里反馈反复提示「网络连接超时」（2021 年留言），这类问题多半要靠换网络或等版本更新解决——如果同时间别的人也连不上，那就是服务端的事，你这边做什么都没用。

## 三、闪退 / 无响应的排查顺序

每做一步就试一次，好了就停，不必全部做完：

1. **重启应用**：设置 → 应用管理 → 找到猫耳FM → 强行停止 → 重新打开。
2. **清缓存**：长按图标 → 应用信息 → 存储 → 清除缓存。还不好再考虑「清除数据」——**这会删掉本地登录状态与下载的音频**，账号本身不受影响，重新登录、重新下载即可。
3. **查权限**：被禁用的存储、通知等权限会导致异常，见下一节把该给的打开。
4. **升级**：应用商店或官方渠道更新到最新版；系统也顺手更到最新。
5. **清存储空间**：手机可用空间长期低于 10%~20% 时各类应用都会开始出毛病，先清出 1 GB 以上。特别是你要下载音频时，空间不够会直接让下载失败（管理见 [怎么下载音频到手机.md](怎么下载音频到手机.md)）。
6. **卸载重装**：前几步都试过还不行再来这一步。安装包用哪份、MD5 怎么校验，见 [下载与安装教程.md](下载与安装教程.md)。

**注意**：第 2 步的「清除数据」和第 6 步的「卸载重装」都会清掉本地数据，动手前想清楚——账号在服务器上，丢的只是本机缓存与登录态。

## 四、权限都是干什么的

在 设置 → 应用管理 → 猫耳FM → 应用权限 里逐项核对（各版本措辞略有差异，以应用内说明为准）：

| 权限 | 用在哪 | 不给会怎样 |
| --- | --- | --- |
| 存储 | 缓存文件、下载的音频 | 下载失败、缓存异常 |
| 通知 | 追更与活动提醒 | 收不到推送（不影响播放） |
| 麦克风 / 录音 | 你开直播、连麦时 | 直播连麦用不了，听剧不受影响 |
| 蓝牙 | 连蓝牙耳机 | 蓝牙耳机控制可能失灵 |
| 电话 | 一键登录 | 换用手动输手机号即可 |
| 系统设置（修改系统设置） | 减少退到后台后音频中断 | 后台播放更容易被系统杀掉 |
| 位置 | 商城收货地址定位 | 手动填地址即可 |

原则：**只给和你用的功能相关的权限**。纯听剧的人给存储 + 通知就够了；不开直播就别给麦克风。
