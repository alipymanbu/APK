## 一、登录方式

登录页提供这几条路（以你安装的版本实际显示为准）：

- **手机号 + 密码**，或手机号验证码；
- **邮箱 + 密码**（邮箱一般是在注册后于资料页绑定的）；
- **海外手机号**：登录页有单独入口，先选国家/地区再走验证码流程；
- **第三方授权登录**：哔哩哔哩、QQ、微信、微博。**首次用第三方方式登录时要绑定手机号**——绑定的手机号如果已注册过就直接进原账号，是新号才会让你设昵称和密码。

忘记密码走登录页的「忘记密码」，用手机号或邮箱收验证码重置；连验证码都收不到，可以走人工申诉。

## 二、不登录能用到什么

装完先不注册也基本能用：

| 操作 | 未登录 |
| --- | --- |
| 搜内容、听免费剧集、听直播 | 可以 |
| 下载 / 缓存、分享 | 可以 |
| 收藏、喜欢、关注、评论、发弹幕 | 要登录 |
| 购买剧集、投食、送礼 | 要登录 |

（据公开的产品分析整理，各版本可能有差异，以页面实际提示为准。）所以第一次点「收藏」弹出登录框是正常行为，不是应用坏了。

## 三、注销账号：先看条件再动手

注销入口在**客服或官方公示的流程里**（用户使用协议第 9.1 条：可通过联系客服申请注销），具体步骤以页面展示为准。动手之前先过一遍注销协议列的前置条件：

1. 是你本人通过官方渠道注册的账号；
2. 账号处于安全状态，没在换绑手机号、没有被盗风险；
3. 账号内交易与财产已结清，没有未处理完的订单或争议；
4. 与平台全部业务不存在合约关系（比如公会主播合约期内不行）；
5. 近期没有违规情形，没有处理中的投诉举报；
6. 其他页面/客服要求的前置流程已完成。

**处理时效：提交申请后 15 个自然日**。如果系统判定账号有安全风险，会要求你补资料核验身份，资料只用于核验。

### 注销会发生什么（不可恢复）

- 注销后**无法再用该账号登录**，即使拿同一个手机号重新注册，也不是原来那个账号了；
- 等级、积分、余额、钻石、优惠券、未到期的在线内容权益等**全部清除且无法恢复**；
- 与第三方平台（含第三方授权登录）的绑定关系解除；
- 个人资料、关注、收藏、交易记录等历史信息被删除或匿名化，粉丝将找不到你；
- 按法规要求，网络日志会保留不少于 6 个月，猫耳商城交易记录保留不少于 3 年（如有）；
- 账号 MID 会做匿名化处理后保留。

### 注销前的检查清单

- [ ] 关掉自动续费（路径见 [充值与取消自动续费方法.md](充值与取消自动续费方法.md)）
- [ ] 把钻石、优惠券、未到期会员处理掉——**这些注销后不退不清算**
- [ ] 想留的收藏内容提前记下来，协议明确建议注销前自行备份并清空账号数据
- [ ] 解除与第三方应用的绑定
- [ ] 确认没有处理中的订单或投诉

只想换设备登录，不要点注销——退出登录就够了，注销是把账号本身销掉。

## 四、注销不了怎么办

条件卡住时（合约期内、有未结交易、有投诉在处理），先把对应事项了结再提交。流程或资料要求有疑问，直接走官方反馈渠道，见 [闪退与加载失败解决办法.md](闪退与加载失败解决办法.md) 末尾的联系方式。
