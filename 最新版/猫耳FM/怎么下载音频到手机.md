## 一、四步把音频存下来

1. 在首页或列表里点开你要听的那条音频，进到播放页。
2. 播放页**中间位置**有下载图标，点它。
3. 屏幕底部会闪一条「已加入缓存队列」的提示，说明这条已经排进下载队列了。
4. 回到首页，点**右上角的下载箭头图标**；在打开的页面里选「音频」，就能看到刚下的内容（也可以从底部「我听」→「下载」进同一个入口）。

没网的时候打开这个下载页，里面的音频照样能放——离线听就是这么来的。

## 二、管理与删除

- 下载页里每条音频后面有**垃圾桶图标**，点它会弹「确定删除该项」的确认框，确认后这条音频从手机里清掉。
- 追的剧集多了以后定期来这里清一遍，缓存很占存储空间；手机存储紧张会直接导致下载失败，也容易引发应用闪退，排查见 [闪退与加载失败解决办法.md](闪退与加载失败解决办法.md)。

## 三、实际用起来会碰到的几件事

| 情况 | 怎么处理 |
| --- | --- |
| 没看到下载图标 | 先确认这条内容是不是需要单独购买的付费剧集——付费内容在详情页会标明，买了之后才谈得上下载 |
| 点了下载但列表里一直是 0 | 队列在后台跑，切回播放页等几秒；还不动就检查网络，或把应用强停后重开 |
| 想找下载好的文件 | 听和删都在 App 内的下载页解决；文件的实际保存目录在「我的」→ 设置里能查到，路径与注意事项见 [定时关闭与倍速设置.md](定时关闭与倍速设置.md) |
| 换了手机 | 缓存跟着设备走，新手机上重新下载一遍即可；账号里的收藏、关注跟着账号走，登录后就还在 |

## 四、下载前先把应用装好
