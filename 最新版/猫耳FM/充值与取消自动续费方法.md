## 一、先分清两种付费形态

站内花钱的东西分两类，别搞混：

- **钻石**：在钱包页按档位充值的虚拟币，用于站内消费（具体可用范围以页面显示为准）。
- **会员**：连续包月 / 连续包季的订阅服务，按周期自动扣款——**自动续费就出在这里**，也是本篇重点。

## 三、会员价格

苹果 App Store 的应用页写明：**连续包月 19 元/月，连续包季 53 元/季**（检索于 2026-09）。会员协议里也有一句关键约定——「会员价格可能因您使用软件的版本不同而产生差异，**以开通服务时显示的金额为准**」，所以安卓端、活动期看到的价格可能不一样，付钱前以当次页面为准。

## 四、取消自动续费（重点）

关掉续费要走**支付渠道**那一侧，App 里关不一定关得干净。按你当时用哪种方式付的款来选：

### 支付宝

打开支付宝 → 我 → 设置 → 支付设置 → 免密支付/自动扣费 → 找到「**猫耳FM会员自动续费服务**」→ 关闭服务。

### 微信

打开微信 → 我 → 服务（支付）→ 钱包 → 支付设置 → **扣费服务** → 找到猫耳FM → 关闭扣费服务并确认。部分旧版微信的路径是：我 → 支付 → 支付管理 → 扣费服务。

### iPhone（App 内购订阅）

设置 → 订阅 → 选中猫耳FM会员服务 → 取消订阅。（旧版 iOS 路径是：设置 → iTunes Store 与 App Store → Apple ID → 查看 Apple ID → 订阅。）

**注意**：苹果侧有条硬规则——**未在订阅期结束前至少 24 小时关闭，就视为同意继续授权，会自动续订一次**，想停就提前一两天操作。

### 关掉之后

- 关闭后不再产生新的扣款，会员权益结算到当期结束；当期已扣费用的处理以官方口径与客服答复为准。
- 关闭动作发生在支付渠道。会员协议约定官方会在到期前通过站内消息-系统通知提示你，**但别指望它一定提醒到你**——开通续费后顺手就把关闭路径试一遍，是更稳的做法。
- 如果没收到提醒却被扣款了：先保存扣费记录并联系客服说明情况；协商无果可拨打 12315 或通过全国消协智慧 315 平台反映（这是通用的消费维权路径，能不能退以协商结果为准）。

## 五、相关协议在哪

会员与续费规则的原文在官网协议页，条款有变以官方最新版为准：

- 会员服务协议（含自动续费规则）：`https://m.missevan.com/page/rule/vip-agreement`
- 用户使用协议：`https://m.missevan.com/page/rule/duty`

注销账号前记得先把续费关掉、把钻石花完——账号注销后这些权益不会退还，详见 [账号登录与注销方法.md](账号登录与注销方法.md)。
