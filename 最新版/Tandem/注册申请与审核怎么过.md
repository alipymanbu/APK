# Tandem 注册申请与审核怎么过

## 一、它和你用过的社交软件不一样在哪

Tandem 不是「装上就能加人聊天」的应用，它把注册做成了申请制：你要先提交一份资料，等社区团队审完放行，才会看到语伴列表。这样做是为了把非语言学习目的的人挡在外面。所以你第一次打开的流程会比一般社交软件长，等待期从几小时到几天都正常，个别国家还会排队。

**一个硬门槛先说在前面**：官方规定 16 岁以下不能使用。年龄填小于 16 会被直接拒。

## 二、注册时会问你什么

表单不长，但每一项都参与审核，别当成随手填的：

| 环节 | 要填的内容 | 审核方在看什么 |
| --- | --- | --- |
| 语言组合 | 你的母语、你会的语言、你想学的语言 | 是否构成一个合理的交换组合 |
| 基本资料 | 姓名、年龄、城市 | 姓名是否真实、年龄是否达标 |
| 学习目标 | 为什么学、想练到什么程度 | 回答是否具体，不是敷衍 |
| 头像 | 一张本人照片 | 是不是真人照、是不是本人 |
| 兴趣话题 | 你愿意聊什么 | 后续匹配语伴的依据 |

## 三、申请迟迟不通过，通常是这几个原因

官方客服页面对「审核慢、被拒」给出的原因集中在下面几点，按出现频率排：

| 原因 | 具体表现 | 怎么改 |
| --- | --- | --- |
| 资料不真实 | 头像不是本人、用网图、姓名是化名 | 换成本人清晰正面照，填真名 |
| 问答题写得太敷衍 | 目标、自我介绍只有几个字，或明显是为了过题随便填 | 每项写一到两句具体内容，说清你想学什么语言、为什么 |
| 年龄不满 16 岁 | 资料里年龄低于 16 | 只能等到符合年龄要求再用 |
| 所在国家/地区未开放 | 部分地区暂不支持注册 | 官方称会陆续开放，只能等 |
| 排队 | 该语言方向申请人多，用于维持社区平衡 | 保持资料可用，等通知即可 |

**如果你第一遍填坏了，不用新注册一个账号**：取消现有申请、重新填一份再提交就行。已经提交但还没通过的申请，满 7 天后可以自己在应用里点「取消我的申请」，资料会被清掉。

## 四、等待审核期间能做的事

1. **把登录方式定下来**，后面别乱换。注册方式有邮箱、Google、Facebook 三种，**登录时用的方式必须和注册时一致**（邮箱注册不等于 Google 登录）。用邮箱注册的，记住你填的是哪个邮箱。
2. **留意邮箱**：审核结果、被退回、排到号了，都会通过邮件通知，垃圾邮件箱也看一眼。
3. **先把头像和资料准备好**，别等通过了才开始想第一句话说什么。

## 五、通过之后的第一天

审核通过登录进去，默认落在 Community（社区）页。这里展示的是「说你想学的语言、同时想学你会说的语言」的人，也就是双向匹配的语伴。先在设置里核对三件事再开始加人：

- 语言组合对不对（母语 / 流利 / 在学，各能选一个）；
- 是否允许语音、视频通话（不想接视频就在这里关掉）；
- 纠错偏好，即你希望对方怎么改你的错（这个设置会展示给对方看）。

这几项和怎么找人的关系，接着看 [找语伴与筛选怎么设置.md](找语伴与筛选怎么设置.md)。

## 六、换设备或者换登录方式

- **换手机**：用原来的登录方式在新设备登录，语伴列表和聊天会一起同步过来，不需要重新申请。
- **忘记用哪个方式注册的**：先按注册时最可能的方式试一遍；都失败就联系官方客服，把姓名、Tandem ID 或邮箱、你记得的登录方式一并说清，让他们帮你核对。
- **账号被盗或被误封**：这类情况走客服申诉，具体入口和封禁规则见 [举报与账号安全怎么设置.md](举报与账号安全怎么设置.md)。
