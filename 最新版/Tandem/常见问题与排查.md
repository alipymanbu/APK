# Tandem 常见问题与排查

> 收拢使用中最容易卡住的几类问题：消息发出去没送达、登录不上、语伴不见了、通知不响、应用打不开，各自按步骤排查。

## 一、消息一直显示「已发送」，没有变成「已送达」

这条几乎每个人都会遇到，而且通常不是故障。先看懂三个状态分别代表什么，再看怎么处理。消息状态分三段：

| 状态 | 含义 |
| --- | --- |
| 已发送 | 消息已到服务器，但对方当前不在线 |
| 已送达 | 对方重新打开聊天列表，消息推到了他的设备 |
| 已读 | 对方看过了 |

所以「已发送」卡着，只说明对方此刻不在线、断网或者网络不稳。等对方回到聊天列表刷新一下，状态就会跳。**不需要反复重发，也不会丢。**

如果对方明确说自己一直在用却始终收不到，让他在应用里退出这条聊天重新进入，或者让对方换个网络再试。

## 二、登录不上去

九成是登录方式和注册时不一致。排查顺序：

1. **回忆注册方式**：邮箱、Google、Facebook 三种方式互不相通。用邮箱注册的账号，不等于 Google 登录。
2. **确认商店账号**：Google 和 Facebook 登录依赖设备上登录的是同一个账号，设备里登错号就会一直失败。
3. **邮箱账号直接填邮箱登录**，不要走 Google 按钮。
4. **Facebook 登录失败**：确认手机上的 Facebook 应用和手机浏览器里登的是同一个 Facebook 账号，再回来点 Facebook 登录。
5. 都试过不行，联系官方客服，提供姓名、Tandem ID 或邮箱、你记得的登录方式，以及报错原文。

## 三、找不到之前的语伴了

先分清是哪种情况：

- **对方注销了账号**：人从列表里消失，聊天记录也会一起没有，这种情况无法恢复；
- **对方把你删了或屏蔽了**：同样会看不到；
- **自己换了语言组合**：社区页推荐会变，但已经聊过的人仍在你自己的聊天列表里，不会丢；
- **换设备登录后列表变空**：确认登录方式和原来一致，登录错账号看到的是另一个账号的列表。

如果你确定对方没注销也没删你，用搜索栏直接搜对方的 Tandem ID 最快。

## 四、收不到消息通知

按顺序检查：

1. **系统通知权限**：设置里给到 Tandem 的通知权限是否开着；
2. **电池优化**：安卓上被系统「省电」限制后，应用在后台收不到推送。把 Tandem 加入不受限制的白名单；
3. **后台自启动**：部分国产系统需要单独允许自启动与后台运行；
4. **勿扰 / 专注模式**是否正开着；
5. **应用内通知开关**：应用自己的设置里也有各项通知的开关，别只在系统层面找。

## 五、应用打不开、卡在启动页

1. 先从后台划掉应用再重新打开，不要直接卸载重装——卸载会清掉本地聊天记录；
2. 重启手机；
3. 检查系统时间和时区是否正确，时间错乱会导致登录和推送失败；
4. 检查存储空间是否已满，空间不足时应用常停在启动页；
5. 确认网络能正常访问境外服务，部分网络环境下这类应用会一直连不上；
6. 如果只有通话或翻译功能异常，而不是整个应用打不开，按 [聊天翻译与纠错怎么用.md](聊天翻译与纠错怎么用.md) 里的通话排查走。

## 六、注册一直没通过

这是审核流程的正常表现，不是技术故障。被拒和延迟的原因集中在这几类：本人照片不清晰或不是本人、姓名不真实、问答题写得太短、年龄不满 16 岁、所在地区暂未开放、该语言方向排队。

处理方式：取消现有申请，改好资料重新提交。已经提交满 7 天的申请可以自己取消。逐项对照见 [注册申请与审核怎么过.md](注册申请与审核怎么过.md)。

## 七、收到警告或者被封了

收到警告说明有人举报并且社区安全团队核实了。**六个月内第二次警告会永久封号**，所以第一次警告要认真对待。认为处理有误可以申诉，把 Tandem ID 和相关记录一并提供。

## 八、翻译点了没反应、视频通话按钮是灰的

这两件事多半不是故障，是免费版的每日额度或权益限制：

- **翻译**：免费账号每天的翻译条数很少，用完当天就不再出结果，第二天重置。判断方法：换一条消息也翻不出来，就与网络无关。
- **语音、视频通话按钮变灰**：通话属于订阅权益，免费账号不开放。

各项额度和哪些功能属于订阅，对照表见 [会员订阅与退款怎么算.md](会员订阅与退款怎么算.md)。

## 九、以前有的「找老师上课」功能去哪了

官方在 2020 年下线了 Tandem Tutors，现在平台只做会员之间的一对一语言交换，不再提供预约付费课程。如果你需要的是结构化课程或批改作业，那属于另一类产品，Tandem 现在不覆盖这块。

## 十、还有别的问题找谁

官方支持渠道是对外开放的，通过官网 [tandem.net](https://tandem.net/) 可以找到支持入口。提交问题时把这几项一次说清，能省一轮来回：Tandem ID 或注册邮箱、设备型号与系统版本、应用版本号（6.0.6 这类）、问题现象与报错原文、能复现的操作步骤。
