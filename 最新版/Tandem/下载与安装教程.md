## 一、这份安装文件是什么

Tandem 是一个靠母语者互相练口语的语言交换应用，注册要经过社区审核，装上以后你要做的事是「找语伴、开口聊」。下面这份是安卓安装包，整理于 2026-09-23，对应版本 6.0.6。官方商店里现在挂的是更新的版本，两者不一定是同一版，所以版本号和包名请以这张表为准。

| 项目 | 值 |
| --- | --- |
| 软件名 | Tandem |
| 版本号 | 6.0.6 |
| 包名 | net.tandem.kbinstaller |
| 安装包大小 | 99.92 MB |
| MD5 | 6F9AB3B325D2AE87516CC1AC99746A4A |
| 整理时间 | 2026-09-23 |

补充一句：官方发布到 Google Play 的安卓版包名是 `net.tandem`。上面这份的包名多了后缀，属于另一条打包渠道的同名应用；如果你手机里已经装着商店版，两者可能无法共存（见第五节）。

## 二、安装前先确认三件事

1. **系统版本**：整理记录里标注的要求是安卓 5.2 以上。系统太旧的设备即使装上，通话类功能也容易表现异常，建议 Android 8 以上。
2. **存储空间**：安装包约 100 MB，装完还会写入聊天缓存和语音素材。留出至少 500 MB 空闲空间更稳。
3. **文件完整性**：下载后先用 MD5 校验一遍，对得上再装，能排除大半「解析包错误」。

Windows 上校验的命令（把路径换成你实际存放的位置）：

```powershell
certutil -hashfile "D:\Download\Tandem_v6.0.6.apk" MD5
```

输出结果去掉空格后应与 `6F9AB3B325D2AE87516CC1AC99746A4A` 完全一致，大小写不敏感。

## 三、安装步骤

1. 从 [Tandem 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b58b3a2d5138) 转存并下载安装包到手机或电脑。
2. 传到手机后，在文件管理器里点开这个 `.apk` 文件。
3. 系统会提示「未知来源应用」，进入提示里的设置项，把允许安装的权限给到当前正在用的那个 App（文件管理器或浏览器）。Android 8 以上是按应用逐个授权的，给错应用会一直装不上。
4. 回到安装界面，点「安装」，等待进度跑完。
5. 如果同时装着别的渠道的同名版本，系统会先问是否替换或提示无法安装，先把旧的卸载再装。

## 四、首次打开会看到什么

装完点开图标，第一屏不是登录页，而是注册与语言选择的引导流程：选你想学的语言、你想教的语言、填年龄与学习目标，最后上传一张本人照片、提交申请。

这里要提前知道一点：**提交完不等于马上能用**。申请是人工逐份审的，部分国家还有排队。审核通过后你才会看到社区里那些语伴。这一步怎么填才不容易被打回，见 [注册申请与审核怎么过.md](注册申请与审核怎么过.md)。

## 五、装不上或者装完打不开怎么办

| 现象 | 常见原因 | 处理办法 |
| --- | --- | --- |
| 解析包错误 | 下载不完整、传输中被截断 | 重新下载，按第二节的 MD5 命令核对 |
| 应用未安装 | 已存在同包名应用，或签名不同 | 先卸载旧版再装；注意卸载会清掉本地聊天记录 |
| 一直提示未知来源 | 权限给错了应用 | 在「设置 → 应用 → 特殊权限 → 安装未知应用」里核对授权对象 |
| 装上了但闪退 | 系统版本过低、权限被系统拦截 | 升级系统、重启设备后重试；仍闪退见 [常见问题与排查.md](常见问题与排查.md) |

## 六、装在电脑上（可选）

Tandem 官方除了 iOS、安卓端，还有网页版，入口在官网 [tandem.net](https://tandem.net/) 上。想在大屏幕上练，直接用浏览器打开网页版比在模拟器里跑安卓包省事，也不用担心模拟器的麦克风、摄像头权限问题。
