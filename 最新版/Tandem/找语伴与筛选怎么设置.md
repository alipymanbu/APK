## 一、先设语言组合，再谈找人

语言设置决定了社区页给你推谁，设错了推来的人基本都对不上。2025 年起，普通账号在同一时间只能挂 **一个母语、一个流利语言、一个在学语言**，每天可以改一次；Pro 账号能挂的更多（最多四个母语、四个流利语言、十个在学语言）。

对多数人来说，「在学语言」就填你当前最想练的那一门，别贪多。一次只挂一门，社区页给你的推荐会更准，稀有语种组合也不会被别人挤掉。

设置位置在「我的资料 → 语言」，改完当天生效，第二天才能再改。

可选语言范围很宽，**官方 FAQ 写的是 300 种**，官网语言交换介绍页则写成「180 多种语言，其中包含 12 种手语」。两个口径都出自官方，差别在于统计口径（是否计入方言与手语变体），按哪个理解都不影响使用：常见语种基本都在，冷门语种也能搜到语伴，只是候选人会少很多。

**语种越冷门，越要接受匹配慢这件事。** 学英语、西语、日语这类大语种，社区页一刷一大片；学芬兰语、挪威语这类组合，可能要等几天才有新面孔出现。这种情况下别频繁改语言设置——每改一次，推荐池要重新匹配。

## 二、在 Community 页筛人

社区页是主要入口，列表里默认就是和你语言组合互补的人。可用的筛选维度：

| 筛选维度 | 能筛出什么 | 什么时候用 |
| --- | --- | --- |
| 语言 | 只看说某门语言的人 | 语言组合里有多个候选时收窄 |
| 年龄 | 按年龄段过滤 | 想找同龄人 |
| 性别 | 按性别过滤 | 有明确偏好时 |
| 成员类型 | 新成员 / 有他人推荐的成员 | 想找「被别的用户认证过」的人时选后者 |
| 话题 | 按你想聊的主题匹配 | 想聊足球、动漫这类具体内容 |

列表顶部一般会先放当天推荐的人和近期活跃的人，往下才是全部。**优先挑最近上线过的**，活跃度比资料好看更重要，长期不上线的账号发过去也没回音。

## 三、用搜索栏直接找特定的人

搜索栏能吃两类关键词：

- **Tandem ID**：对方把 ID 告诉你了，直接搜 ID 最准；
- **话题词**：比如 `football`、`anime`，出来的是资料里提到这个话题的人。

搜到人之后，在对方资料页点关注，后面会更容易在列表里再遇到。

## 四、资料怎么写更容易被搭话

同一条推送里，资料写没写具体内容，被回信息率的差别很明显。可执行的做法：

1. **头像用清晰正面照**，别用风景、卡通、多人合照；
2. **自我介绍落到具体**：写明你在学什么语言、到什么程度、想练什么场景（日常口语 / 写作改错 / 面试），比「Hi, I'm friendly」有用得多；
3. **兴趣栏认真填**，它是搜索和话题匹配的依据；
4. **学习目标写一个字面目标**，例如「三个月内能用日语做自我介绍」，别人一看就知道该跟你聊什么。

资料写好了，第一条消息怎么发是另一件事，那部分单独写在 [第一次和语伴开口说什么.md](第一次和语伴开口说什么.md) 里。

## 五、收到太多私信怎么收口

有用户反馈，注册刚通过那几天收到的搭话信息会突然很多，其中一部分目的不是学语言。可以这样收：

- **收紧可联系方式**：在设置里关掉「视频通话」或「语音通话」，只留文字；
- **限制加人节奏**：免费账号每天能新建联系的人数是有限的，这本身也是一道缓冲；
- **不想聊的直接结束**：不需要解释，也不会通知对方你做了什么；
- **明显越界的直接举报**，别自己劝，流程见 [举报与账号安全怎么设置.md](举报与账号安全怎么设置.md)。

## 六、想找附近的人或者看谁在线

按地区、按「此刻在线」筛选属于 Pro 功能。如果你需要线下见面，或者想找能立刻回话的人，这两项是订阅里最直接相关的权益，完整对照见 [会员订阅与退款怎么算.md](会员订阅与退款怎么算.md)。

需要提醒的是，线下见面按社区准则属于个人行为，官方不做身份核验兜底；第一次见面选公共场所，这是基本操作。
