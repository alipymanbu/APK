## 一、流量从哪来：每日签到

加速流量靠每日签到领取，签到入口在应用内（以你打开应用时界面显示为准）。典型用法是：游戏已下单、但主机上下载要一整天，或者折扣快结束而 eShop 一直转圈打不开，这时用签到攒的流量给主机提速。

每天签到的量与规则以应用内当前显示为准。

## 二、能加速哪些场景

按官方介绍，签到流量可用于 Switch、PS4、PS5 的这几类场景：

| 场景 | 说明 |
| --- | --- |
| 游戏下载加速 | 主机上下载大体积游戏时提速 |
| 游戏更新加速 | 补丁与版本更新下载提速 |
| 系统更新加速 | 主机系统固件更新提速 |
| 商店访问 | 畅快访问主机游戏商店（如 eShop） |

联机对战的加速不在上表范围内，是否支持以应用内说明为准。

## 三、主机端怎么配合

应用内发起加速后，按指引把主机的网络配置改为指引给出的参数即可。以 Switch 为例，主机端的路径是通用的：

1. 主机主界面进「设置」；
2. 「互联网」→「互联网设置」；
3. 选中当前连接的 Wi-Fi，点「更改设置」；
4. 按应用内加速页面显示的参数填写对应项，保存并完成连接测试。

PS4 / PS5 的网络设置路径类似，都在系统设置的网络分类下。加速结束后记得把主机网络设置改回原样，避免影响日常联网。

不同版本应用里的加速引导界面可能不一样，操作以应用内当时显示的指引为准。

## 四、流量用完了怎么办

签到流量属于免费额度，用完只能等下一次签到，是否另有获取途径以应用内显示为准。大体积游戏下载前先看一眼剩余流量，别下到一半额度见底。

## 五、加速没效果的检查顺序

1. 确认主机与应用连的是同一网络环境；
2. 确认主机端参数填的是应用内当前显示的那组（改过路由器或换过网络后，旧参数会失效）；
3. 关掉主机上其他正在占带宽的下载；
4. 还是不行，回应用内加速页面重新发起一次，再无效走 [常见问题排查.md](常见问题排查.md) 的思路查应用本体问题。
