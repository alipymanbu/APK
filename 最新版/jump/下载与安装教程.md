## 一、先认准是哪一个 Jump

各应用市场里叫「Jump」的应用不少，有蹦床小游戏，也有海外社交应用，搜名字很容易装错。认准这两点就不会错：

| 核对项 | 正确值 |
| --- | --- |
| 开发者 | 北京矽岛科技有限公司 |
| 安卓包名 | `com.vgjump.jump` |

功能形态上它是一款游戏社区应用：覆盖 Switch、Steam、PS4、PS5、Xbox 平台的游戏比价与折扣信息，另有攻略、评测社区、点卡与 Switch 会员购买、主机下载加速等。iOS 端是否存在官方版本、叫什么名字，以官方页面为准，App Store 搜索时同样要按开发者甄别同名应用。

拿不准时可以去开发方官网 [www.jumpvg.com](https://www.jumpvg.com/) 看官方入口（官网、公众号、小程序，以官网当前展示为准），再用它给出的指引回到应用。

## 二、从网盘获取安装包

[Jump 安装文件资源（夸克网盘）](https://pan.quark.cn/s/105a2247d1d5)里是一份 `.apk` 安装包，适合不方便用应用市场的场景：

1. 打开上面的网盘链接，把文件转存到自己的网盘（夸克转存后才能下载）；
2. 在手机上用夸克 App（或网页端）把 `.apk` 下载到本机存储；
3. 从通知栏或文件管理器里点开下载完成的文件，进入安装。

如果你更习惯应用市场，也可以在应用宝等安卓市场搜「Jump」，同样按第一节的开发者信息核对后再装。市场里的版本以市场更新节奏为准，通常会比官方最新版滞后一些。

## 三、核对安装包（可选）

网盘里这份安装包的基本信息如下，拿到后可以对照：

| 项目 | 值 |
| --- | --- |
| 版本 | 3.30.6 |
| 大小 | 129.83M |
| MD5 | `8aac2a284d03896746e711385d6ef1c4` |

这个版本是网盘整理时的版本，官方此后还会继续发新版本（应用市场在架版本号会持续往前走）。网盘里的版本落后于官方最新版属正常情况，先装这一版、登录后再看应用内是否提示升级即可，不必刻意追求最新。

## 四、安装步骤

1. 点开下载好的 `.apk`；
2. 安卓系统首次安装会提示「是否允许此来源安装应用」，找到你用来下载的那个应用（浏览器或网盘 App），允许它安装；
3. 等安装进度走完，点「打开」。

安装包接近 130M，装完还会在首次启动时下载部分资源，开始前确认手机剩余空间比安装包大出数倍比较稳妥。

## 五、装不上时按顺序排查

| 现象 | 先做什么 |
| --- | --- |
| 提示「解析包出现问题」 | 安装包多半没下完整，重新从网盘下载一次再装 |
| 提示存储空间不足 | 清理出比安装包更大的空间再装 |
| 提示「存在冲突」或安装被中止 | 之前装过别的渠道同名版本时，先卸载旧版再装 |
| 安装按钮灰着不动 | 部分手机管家会拦截安装，去系统设置的权限里放行对应来源 |
| 装完点开闪退或白屏 | 见 [常见问题排查.md](常见问题排查.md) 的启动类条目 |

装好之后第一件事是注册登录并绑定你的游戏平台账号，流程见 [账号注册与登录.md](账号注册与登录.md)；想用它盯游戏折扣，见 [游戏折扣与史低提醒.md](游戏折扣与史低提醒.md)。
