## 一、先分清你要的是哪一版

BAVoice 是面向《蔚蓝档案》（Blue Archive）玩家的角色语音收集与二创工具，另有 BAVoiceOnline、bv社区两个叫法，指的都是同一个应用。官方页面 [bavoice.klicn.com](https://bavoice.klicn.com) 当前展示的已经是更新的版本，而下面这份安装文件是 **2.2.3 版**——两版的功能与界面会有差异，本文所有版本号、体积一律以 2.2.3 这份为准：

| 项目 | 数值 |
| --- | --- |
| 版本 | 2.2.3 |
| 包名 | com.klicn.onlinevoice |
| 安装包大小 | 25.52M |
| MD5 | 9630E1E12C23D4417AA726238AFF0794 |
| 系统要求 | 安卓（2.2.3 标注「安卓系统 5.2 以上」；官方页面对最新版标注 Android 8.0+，实际以安装时系统提示为准） |
| 语言 | 中文 |
| iOS 版 | 无，开发者未提供苹果端应用 |

如果你想在 iPhone / iPad 上用，可以直接放弃这个念头；具体原因见[常见问题汇总.md](常见问题汇总.md)。

## 二、获取 BAVoice 安装文件资源

安装文件放在夸克网盘分享里：[BAVoice 安装文件资源（夸克网盘）](https://pan.quark.cn/s/73d0adf637ef)。

1. 打开链接，把文件**转存到自己的夸克网盘**；
2. 在夸克网盘客户端里找到转存的 APK 文件，下载到手机存储；
3. 下载完成后直接从通知栏或「传输列表」里点开安装，也可以用文件管理器找到它再点。

想先核对拿到的文件对不对，见下面的第五节。

## 三、安装步骤

1. 点开下载好的 APK，系统会提示「不允许安装未知来源应用」；
2. 按提示跳到系统设置，允许**来自此来源的应用**安装（不同机型的入口在「设置 → 安全」或「设置 → 应用」里，名称略有差别）；
3. 回到安装界面，点「安装」，等进度走完；
4. 装完点「打开」，或者稍后在桌面点 BAVoice 图标进入。

存储空间不足会直接安装失败，装之前确认手机剩余空间比安装包大出几倍比较稳妥。

## 四、首次启动要过的三道坎

第一次打开 BAVoice，按顺序会碰到三件事，缺一步都进不了主界面：

1. **授权限**：允许存储等权限。这个应用要把语音资源写到手机存储的 `/BAVoice/` 目录，不给存储权限后面导出、离线都会出问题；
2. **同意协议**：点同意用户隐私政策；
3. **配置学院信息**：出现加载画面，等它配置完。这一步需要联网，卡住时先检查网络，别急着退出应用。

三步走完就进学院列表了，怎么找学生、怎么播放见[语音播放与收藏.md](语音播放与收藏.md)；如果首启之后碰到的不是这三步而是报错，去[语音下载失败怎么办.md](语音下载失败怎么办.md)对照排查。

## 五、核对安装包（MD5）

想确认手里的 APK 就是 2.2.3 这份原包，可以比对 MD5：

- 电脑上：右键文件 → 属性不一定显示 MD5，用系统自带命令最直接：

  ```powershell
  Get-FileHash "BAVoice_v2.2.3.apk" -Algorithm MD5
  ```

- 手机上：部分文件管理器（如 MT 管理器一类）在文件属性里直接显示 MD5。

比对目标值：`9630E1E12C23D4417AA726238AFF0794`（大小写不敏感，一致即可）。对不上说明文件在传输中损坏或根本不是这份包，重新下载一次再装。
