# 书架、收藏与进度怎么续接

talai 里的"资产"分三样：收藏过的剧本、正在聊的记录、没写完的草稿。三样都存在应用里，本篇讲它们各自放在哪、怎么找回来，以及哪些操作会把它们清掉。

## 一、收藏与书架：把想玩的先存起来

- **收藏栏目集中存放**：看到喜欢的剧本点一下收藏，之后从收藏入口直接进，不用再搜一遍。
- **适合收藏哪一类**：长篇、多分支的剧本值得收，反正一次跑不完；随手看两眼的短篇不收也行。
- **书架和收藏一起用**：两处入口的作用都是省掉下次再搜一遍的功夫，具体归类方式以应用内实际显示为准。

## 二、聊天记录：自动存档，可以分几次玩

- **记录是自动存的**：不用手动点保存，每推进一段就留在应用里。
- **中途退出再进来能接着写**：已开启的剧本不会因为你退出去就丢掉进度，下次从原来的位置继续。
- **想试另一条线**：回到关键节点重选，或者读之前的存档重来。多个存档的好处是选错了不用从第一句开始重跑。

## 三、草稿：没写完的剧本放哪

自己创建的剧本会自动存成草稿，而且支持同时留多份——写一段、放一放、过几天再回来接着写都可以，改坏了也能退回之前的版本。想给别人玩的时候，写完的那份发布或分享出去即可，做法见 [怎么创建自己的剧情和人物.md](怎么创建自己的剧情和人物.md)。

## 四、重装和换设备之前，先做这一步

- **记录默认保存在本机**：卸载应用、清理应用数据、换一台手机，本机上的聊天记录和草稿都会跟着没。
- **动手前先翻一遍导出入口**：应用内有没有导出或备份的功能，以你当前这一版实际显示为准；有就先用一遍，没有再考虑卸载。
- **清缓存和清数据是两回事**：清缓存只删临时文件，一般不影响记录；清数据等于把应用恢复成刚装好的样子，记录和草稿一起清空。系统存储管理里操作时看清是哪一项。
- **要换新手机**：旧机上先确认有没有可导出或可同步的入口，能导的先导；导不出来的，就先别急着卸载旧机上的应用。

## 五、记录或收藏不见了怎么找

| 情况 | 先确认什么 |
| --- | --- |
| 收藏夹空了 | 先确认现在登录的是不是原来那个账号；如果中途清过应用数据，收藏也会一起没 |
| 之前的剧本翻不到了 | 顶部搜索框直接用剧本名再搜一次；搜不到说明这份剧本可能已从平台上撤下 |
| 聊到一半的记录不见了 | 回忆一下之前有没有清过应用数据或卸载重装；这两项都会清掉本机记录 |
| 草稿没了 | 同上，先确认有没有换账号或清过数据 |
