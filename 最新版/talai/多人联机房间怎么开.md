# 多人联机房间怎么开

单人玩是一对一：你和 AI 角色推进一段剧情。联机玩是几个人进同一个场景，各自操控自己的角色，一边打字一边把同一个故事推下去。本篇讲后者怎么开起来。

## 一、单人玩和联机玩的区别

| 对比项 | 单人玩 | 联机房间 |
| --- | --- | --- |
| 参与者 | 你 + AI 角色 | 几个人各自扮演一个角色，AI 在场景里配合 |
| 谁定规则 | 剧本本身 | 房主 |
| 剧情怎么走 | 你自己打字 + 选分支 | 每个人都能改剧情，走向由参与的人共同推 |
| 进度快慢 | 自己说了算 | 要等其他人回应 |

## 二、开一个房间的步骤

1. **先选好剧本或背景**：房间要挂在一个故事设定上，用现成剧本，或者用你自己写的那份，做法见 [怎么创建自己的剧情和人物.md](怎么创建自己的剧情和人物.md)。
2. **点「创建房间」**：填房间名和故事题材这类基础信息。房间权限这里通常能选：**公开**（陌生玩家可以匹配进来）或**私密**（只有拿到你邀请入口的人能进）。只想和熟人玩就选私密。
3. **生成分享入口**：建好后一般会给出一个房间链接或邀请入口，把它发给好友。
4. **好友点开加入**：对方用自己的设备打开这个入口，进到同一个房间。
5. **各自认领角色、全员就位后开始**：每个人选一个角色（或自己填一个人设）。人都到齐、角色都认领完了再往下走，否则 AI 不知道该接谁的话。
6. **剧情由所有人一起推**：房间里的玩家都能影响走向，不只房主一个人说了算。

## 三、房主要提前定好的两件事

房间的规则由房主定，开房前先把这两项定下来，能省掉后面一半的口舌：

- **故事背景**：发生在哪、什么时间、有没有特殊规则。写清之后所有人都在同一套设定里演，不会有人各说各的。
- **剧情规则**：能不能中途加人物、结局由谁定、要不要按顺序发言。多人房间最容易乱的地方就是没人管节奏。

**角色别留空**：房间开好后每个人都该有明确身份。有人没认领角色就直接说话，AI 会不知道该怎么接。

## 四、进不去房间、联机卡顿怎么排查

按这个顺序试，一般前两步就能恢复：

1. **换个网络类型**：Wi-Fi 进不去就切移动数据，移动数据进不去就切 Wi-Fi。联机问题优先从这一项查。
2. **清后台再重启应用**：把后台不用的应用关掉，从后台彻底划掉 talai 再打开，重新点一次房间入口。
3. **确认双方进的是同一个房间**：让好友重新点一次你发的那条入口，别进了另一个同名房间。
4. **看是不是在等人**：全员没到位、或者有人还没认领角色时，房间不会正常往下走。
5. **看人数上限**：房间能容纳的人数是有限制的，具体上限以应用内显示为准；满了就先让一个人退出。

## 五、房间里常见的岔子

| 现象 | 先查什么 |
| --- | --- |
| 好友点链接进不来 | 先确认对方网络正常、应用已装好；再确认进的是同一个房间入口而不是另一个房间 |
| 进来了但看不到进度 | 让对方向下刷新一次对话；多人同时在打字时，最新的几条可能要等一会儿才同步 |
| 有人说话很久没回应 | 先看是不是在等他认领角色，或者是不是有人正在输入 |
| 房间卡住、点哪都没反应 | 按第四节的顺序走一遍，多数情况下切网络加重启就能恢复 |

## 六、什么时候不必开房间

- **只想安静跑一条线**：自己一个人玩，节奏完全由你控制，不用等别人。
- **想试一个剧本值不值得玩**：先单人跑个开头，觉得好再开房间拉人。
- **人凑不齐**：两个人就两个人开，房间不要求坐满；人少反而更好推剧情。
