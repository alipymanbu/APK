talai 是安卓端的 AI 文字剧情应用：首页是一批剧本，挑一个点进去、选好模型、给自己安一个身份，就能靠打字往下推剧情。本篇只做一件事——把网盘里这份安装包装进手机，并跑到能正常开局。

## 一、先认准网盘里这份包

| 项目 | 值 |
| --- | --- |
| 应用名 | talai |
| 版本号 | 1.0.3 |
| 包名 | `com.agtechltd.talai` |
| 安装包体积 | 40.52 MB |
| MD5 | `d586db3c5f72dddfb73f40c6387e615b` |
| 适用平台 | Android（手机端 APK） |
| 界面语言 | 简体中文 |

版本号、包名、体积三项以本表为准，别照下载站页面上的数字改——那些页面显示的是官方当时的最新版，跟网盘里这份常常不是同一个版本。

装之前先弄清三件事：

- **认包名，不要只认名字。** 搜「talai」能翻出一堆同名条目（`talai`、`Talai`、`TALAI`、`talai文游模拟器`），只有包名是 `com.agtechltd.talai` 的才是这份包。装好后在「设置 → 应用 → 应用管理 → talai」的应用信息页能看到包名，对不上的按 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 再核一遍。
- **这是安卓包，iPhone 和 iPad 装不了。** 网盘里这份是 APK，只能在安卓设备上侧载。
- **系统要求以本机与官方页面为准。** 这份包没有登记最低安卓版本，而第三方页面之间互相矛盾（有的写安卓 4.3，有的写 5.2，有的写 7.0 或 8.0），照哪个都可能装错。装机前在「设置 → 关于手机」看一眼系统版本，再对照官方渠道页面上登记的要求；版本过低的表现通常是装不上，或者装上打开就退。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [talai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a7bbb594ea69)，手机上装了夸克 App 的话会直接跳进去。
2. **先转存再下载**：选中安装包，转存到自己网盘的目录后再下载到本机。分享链接以后可能失效，转存过的那份不受影响。
3. **核对体积**：下载完成后看一眼文件大小，应当约 40.52 MB。中途断网重连导致体积偏小，安装时会直接报「解析包错误」。
4. **想校验完整性**：在电脑上对拿到的 APK 算一遍 MD5，结果应与上表一致（大小写不敏感）。

```cmd
certutil -hashfile talai_v1.0.3.apk MD5
```

文件名随版本变化，以实际拿到的那个为准。

## 三、安装步骤

1. **给打开 APK 的那个应用开「安装未知应用」权限**：进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把文件管理器（或浏览器）那一项的开关打开。国产定制系统这项常收在「安全」或「隐私」分类里。
2. **点击 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续，这是侧载安装包的常规提示。
3. **手机上已有更高版本时先卸载**：安卓不允许用低版本覆盖高版本，会直接报「应用未安装」。卸载会一并清掉本机上的聊天记录与草稿，动手前先在应用内翻一遍有没有导出或备份入口（是否提供以应用内为准，相关说明见 [书架收藏与进度续接.md](书架收藏与进度续接.md)）。
4. **报「签名不一致」说明包名撞了**：手机里已装过同包名、不同来源的版本，按本节第 3 步先卸载旧的，再装这份。
5. **留出安装空间**：安装过程中系统还要展开一份文件，建议预留 500 MB 以上可用空间。

## 四、第一次打开要确认的三件事

1. **能联网**：剧本内容与模型回复都要联网才能拿到，应用离线时基本用不了。打开后一直停在加载状态，先用浏览器确认手机能正常上网。
2. **能进到首页并登录**：首次进入会让你同意用户协议，注册入口在「我的」页里的「创建新账号」，按提示填账号信息完成注册后再登录。这一步卡住的处理见 [常见问题与排查.md](常见问题与排查.md) 第二节。
3. **能跑通一次完整开场**：首页刷得出剧本卡片说明数据侧通了；随便挑一个剧本，走到「开始阅读 → 选模型 → 填身份」能进对话页，就算装好了。四步路径的细节见 [怎么选剧本和开始一段故事.md](怎么选剧本和开始一段故事.md)。

## 五、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整 | 核对体积与 MD5，按第二节重新取一份 |
| 提示「应用未安装：签名不一致」 | 手机里已有同包名、不同来源的版本 | 先在应用管理里卸载旧包，再装这份 |
| 安装被安全中心拦下 | 侧载包被系统安全策略拦了 | 在安全中心的拦截记录里选「继续安装」 |
| 点安装没反应 | 「安装未知应用」权限没给 | 回到第三节第 1 步补上权限 |
| 装完打开就闪退 | 系统版本过低、存储不足或包残缺 | 见 [常见问题与排查.md](常见问题与排查.md) 第四节 |

以后换版本或者重装，按第二节的步骤重新取一份即可，安装动作与这次相同。
