# 游戏obb数据包安装教程（APK + OBB 完整流程）

> 本篇讲用 ZArchiver 装一个「带数据包」的游戏：压缩包怎么解、obb 文件放到哪个目录、文件夹名与文件名有什么讲究、启动报「需要下载额外资源」怎么处理。obb 目录进不去的先看[Androiddata与obb目录访问方法.md](Androiddata与obb目录访问方法.md)。

> [!IMPORTANT]
> **ZArchiver 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/0245ef29c7eb](https://pan.quark.cn/s/0245ef29c7eb)

## 一、先备齐三样东西

1. **游戏压缩包**（rar/zip/7z 都行），里面通常有 `xxx.apk` 和 `.obb` 数据文件，也可能解出后分开；
2. **ZArchiver**（还没有的话，用文首的 [ZArchiver 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0245ef29c7eb) 获取，安装见[下载与安装教程.md](下载与安装教程.md)）；
3. **足够的空间**：解压前后的双份占用 + 游戏本体，几个 G 很常见。

一个必须核对的前提：**APK 与 obb 必须是同一版本**。版本不配对时游戏启动会找不到数据或要你重新下载——这是装完打不开的第一大原因。

## 二、解压与放置步骤

1. 在 ZArchiver 里找到游戏压缩包，点开选「解压至当前文件夹」或「解压到…」；
2. 解压完成后你会看到 `.obb` 数据文件（常见文件名形如 `main.<版本号>.<游戏包名>.obb`）；
3. 把 obb 文件移动（长按 → 移动/剪切）到 `内部存储/Android/obb/<游戏包名>/` 目录：
   - 没有 `obb` 文件夹就手动新建一个；
   - `<游戏包名>` 文件夹**必须与游戏包名逐字一致**（如 `com.example.game`），包名一般能从 obb 文件名里看出来；没有这个子文件夹就按包名新建；
   - **obb 文件本身不要改名**，游戏启动时按原文件名核对；
4. 放好后回到安装包位置，安装 `xxx.apk`；
5. 装完先不要急着开游戏——先确认数据放对，再点开游戏图标，首次启动会校验数据包。

最终路径长这样：

```text
内部存储/Android/obb/com.example.game/main.123.com.example.game.obb
```

## 三、启动报错对照

| 启动时的表现 | 原因 | 处理 |
| --- | --- | --- |
| 提示「需要下载其他资源 / downloading additional resources」 | obb 没找到：目录不对、文件夹名与包名不一致、或文件被改过名 | 按第二节逐项核对路径与文件名 |
| 直接闪退或提示数据损坏 | APK 与 obb 版本不配对，或 obb 下载/解压不完整 | 换同一版本的 APK；obb 重新解压一次 |
| 进游戏后贴图/关卡缺失 | obb 只复制了一半（中途断开） | 删掉重解，确保进度走完 |

安卓 11 以上往 `Android/obb` 里移动文件会被系统拦，授权方法与替代方案（电脑复制）见[Androiddata与obb目录访问方法.md](Androiddata与obb目录访问方法.md)。

## 四、压缩包带密码时

从别人手里拿的游戏包经常带密码，解压时输入对方提供的密码即可，密码与手机锁屏无关；输错的表现与排查见[常见问题与解决方法.md](常见问题与解决方法.md)第一节。分卷的游戏包（`part1.rar` 等）必须全部卷在同一文件夹再解，缺一卷都会中途失败。
