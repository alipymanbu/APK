## 一、提示要密码 / 密码明明对的却说错

带密码的压缩包在解压时才要密码，先弹「输入密码」（报错原文 Invalid password）是正常流程，不是出错。密码来自发包方——官方说明的原话是：密码由压缩包作者提供，通常就写在发布这个包的页面附近。

输对了还报错时按顺序排查：

1. **大小写与全半角**：手机输入法常把首字母自动大写，密码里的 `a` 变 `A` 就错了；关闭输入法的自动大写再输一遍；
2. **手机锁屏密码不等于压缩包密码**：这是两回事，压缩包密码只有发包给你的人知道；
3. **同一个包多处下载**：不同地方拿到的同名包内容可能不同，向你发链接的人确认密码对应的是哪一份；
4. **密码带中文或特殊符号**：确认输入法没有把空格、全角字符混进去。

实在拿不到密码就找发包方重发，不存在绕过密码的办法，也不该去找。

## 二、解压出来的文件名是乱码

手机上解压 Windows 电脑打出来的包，文件名变成「瀹夊崜」这类乱码，原因是压缩时的文件名编码与解压时认定的不一致。

处理办法：进入 ZArchiver 的设置，找到文件名**编码**相关选项，把编码切换为中文环境常用的 GBK（或反过来切回 UTF-8）后重新解压。注意切换编码影响的是**显示与解出的名字**，先删掉已解出的乱码文件再重解一遍。

打包阶段避免乱码最稳的做法：你自己压包要发给中文用户时，压缩对话框里选 UTF-8 文件名（7z、zip 都支持）。

## 三、解压报错：按报错原文对照处理

应用给出的报错文字就是排查线索，逐条对照（报错原文来自官方错误说明，截至 2026-09）：

| 报错原文 / 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| Not enough disk space（空间不足） | 解压目标分区剩余空间小于包解压后的实际大小 | 清理目标分区，或「解压到…」换一个空间够的分区；压缩包解开后通常**比原包大不少**，按解开后的大小留余量 |
| Corrupt archive (CRC error)、Unexpected end of archive、Data error | 包损坏或数据缺失，多半是下载不完整 | 核对包文件的体积或 MD5（发包方给过就比一下）；对不上就重新下载原包再解 |
| Cannot find volume…（找不到卷） | 多分卷包缺了某一卷，或卷被改名 | 全部卷放**同一个文件夹**、保持原始文件名，从第一个卷重新解 |
| Cannot open file as archive、Unknown archive format | 这个文件根本不是压缩包（网页链接存成了 .zip、后缀被人乱改） | 找发包方确认文件来源，换个完整链接重新拿 |
| 「操作已完成，但有错误」 | 轻微损坏，部分文件解出来了 | 解出的文件能用就先用；包很重要就重新下载 |

修损坏包这件事 ZArchiver 本身做不了，官方也指明了这一点：rar 的恢复记录要用官方 WinRAR 修，7z 的修复方法见 7-Zip 官网的说明——多数情况下重新下载一次比修复快。

找不到已解出的文件：多半是解到了另一个分区/目录，用「解压到…」指定明确位置再解一遍。

## 四、安卓 11 以上：访问不了 Android/data 与 Android/obb

从安卓 11 开始，系统对 `Android/data`、`Android/obb` 这两个目录加了访问限制，普通方式进去看到的是空目录或写不进去，这不是 ZArchiver 的问题，所有第三方文件应用都受同样限制。装的「所有文件访问」权限**不覆盖**这两个目录。

基本处理顺序：

1. 系统设置 → 应用 → ZArchiver → 权限，确认「文件/所有文件访问权限」为允许；
2. 进入目标目录时按系统弹窗**逐个目录**授权（弹窗里点「使用此文件夹」）；安卓 13 以上 obb 还要额外给「安装未知应用」权限；
3. 2024 年 3 月之后安全补丁的设备，授权入口已被系统封掉，普通方法走不通，要走电脑复制或高级授权方案。

各版本的完整授权步骤、补丁影响的判断、ROOT/Shizuku 说明，单独整理在[Androiddata与obb目录访问方法.md](Androiddata与obb目录访问方法.md)；往 obb 放游戏数据的完整流程见[游戏obb数据包安装教程.md](游戏obb数据包安装教程.md)。

## 五、列表里看不到我的文件 / 无法写入存储

- 首次启动时拒绝了「所有文件访问」授权 → 按上一节第 1、2 步补开；
- 你在找的包在 SD 卡或 U 盘里 → 应用侧边栏切换存储位置；外接存储未挂载时不会出现；
- 手机存储路径不确定 → 用系统文件管理器先定位到文件，确认路径后回 ZArchiver 按同一层级进。
