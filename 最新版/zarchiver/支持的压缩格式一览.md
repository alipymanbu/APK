# ZArchiver 支持的压缩格式一览

> 本篇按「能创建 / 能解压 / 只能看」整理 ZArchiver 处理得动的压缩包格式，并说明密码、分卷、改写压缩包这几件事分别对哪些格式有效。具体怎么按、怎么压见[解压与压缩操作指南.md](解压与压缩操作指南.md)，解压出问题见[常见问题与解决方法.md](常见问题与解决方法.md)。

## 一、一张表看清三类能力

ZArchiver 对格式的支持分三档，拿到一个包先对号入座：

| 能力 | 格式 |
| --- | --- |
| 创建（压缩出这种包） | 7z、zip、tar、gzip（gz/tgz）、bzip2（bz2/tbz）、XZ、lz4、zst（zstd） |
| 解压 + 查看内容 | 上一行「创建」清单里的全部格式，另有 rar、rar5、iso、arj、cab、lzh/lha、lzma、xar、Z、deb、rpm、zipx、mtz、chm、dmg、cpio、cramfs、img（fat/ntfs/ubf）、wim、ecm、lzip、egg、alz |
| 不能创建、只能解压/查看 | 除「创建」清单之外的所有格式（含 rar、rar5） |

三档的具体含义：

- **创建**：你选中文件后可以压成这种包；
- **解压 + 查看**：能点开列内容、能解出来，也能只解压包里某几个文件；
- **deb / rpm / dmg / img / wim** 这类严格说是系统镜像或安装包格式，ZArchiver 把它们当压缩包列出内容、解出里面的文件——装系统、挂载镜像这类事别用它做。

## 二、RAR：解得开，压不出

rar 是被问得最多的一类。ZArchiver 解压 rar 与 rar5 都没问题，但**不能创建 rar 包**——rar 的压缩算法有专利授权，第三方实现只能做解压端。你需要压一个 rar 发给别人时，在这款应用里做不到，只能换成 zip 或 7z。

日常拿到的 rar 分卷（`part1.rar`、`part2.rar`…）可以解，注意事项见下面分卷一节。

## 三、带密码的压缩包

- 你压缩时可以给包设密码：在压缩对话框里填密码即可；
- 拿到带密码的包，解压时会弹框要密码——密码来自发这个包给你的人，不是你的手机锁屏密码；
- 7z、zip、rar 三种常见格式的加密包都能解。

密码相关的坑（大小写、输错表现）都汇总在[常见问题与解决方法.md](常见问题与解决方法.md)里。

## 四、分卷压缩包

- **解压**：把全部分卷放在**同一个文件夹**、文件名一个都不改，点开第一个分卷（`.7z.001`、`.zip.001`、`part1.rar` 或 `.z01` 这类序号最小的）选解压，其余分卷会被自动接上；缺任何一卷都会中途报错；
- **创建**：压缩时可以设分卷大小，压出一串 `xxx.7z.001`、`xxx.7z.002`，适合绕开单文件大小限制的传输场景。

## 五、改写压缩包内容（不用先解压）

对 **zip、7z、tar、apk、mtz** 这五种包，你可以直接在包里添加或删除文件，不必整包解出来再压回去。做法：点开压缩包进入内容列表，对包内文件用菜单添加/删除，改动会写回原包。

对 zip 和 7z 还可以只解压包里选中的那几个文件，不用整包全解——大包里只要一两个文件时省时间也省空间。

## 六、从压缩包里安装 APK 和游戏数据包

某些备份压缩包里同时含 `xxx.apk` 和 `obb` 数据文件，ZArchiver 支持从这类包里直接安装 APK 和对应 OBB。obb 文件放到哪个目录、文件夹名怎么写、启动报错怎么对，完整流程见[游戏obb数据包安装教程.md](游戏obb数据包安装教程.md)；安卓 11 以上写不进 `Android/obb` 的授权问题见[Androiddata与obb目录访问方法.md](Androiddata与obb目录访问方法.md)。

## 七、两个容易踩的判断误区

1. **改了后缀不等于换了格式**。把 `.zip` 改名成 `.7z` 打不开，格式由包内部结构决定，不由后缀决定；打不开时先确认真实格式再回[解压与压缩操作指南.md](解压与压缩操作指南.md)核对操作。
2. **iso、exe 之类的安装介质**。iso 能列出内容不等于能用它装系统；exe 根本不在支持列表里（那是 Windows 程序，不是压缩包）。

多线程、UTF-8/UTF-16 国际文件名这类能力属于官方捐赠版（Donate）的功能范围，是否随安装包版本提供以你装好的应用内说明为准。
