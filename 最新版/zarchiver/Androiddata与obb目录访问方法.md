# ZArchiver 访问 Android/data 与 obb 目录的方法

> 本篇讲安卓 11 以上为什么进不去 `Android/data`、`Android/obb`，以及各个系统版本下怎么把授权一步步点通。装应用与基础操作问题见[下载与安装教程.md](下载与安装教程.md)、[解压与压缩操作指南.md](解压与压缩操作指南.md)。

## 一、先分清：这不是应用坏了

从安卓 11 开始，系统出于隐私考虑限制所有第三方应用访问其他应用的专属目录（`Android/data`、`Android/obb`），装 ZArchiver 时给的「所有文件访问」权限**不覆盖**这两个目录。你点进去看到空目录、弹出「This folder has an Android access restriction」提示，都是系统限制的正常表现。

安卓各版本的限制程度不一样，先对号入座：

| 你的系统 | data/obb 能不能进 |
| --- | --- |
| 安卓 10 及以下 | 不受限，直接进 |
| 安卓 11、12 | 能进，但首次进入要**逐个目录**确认授权 |
| 安卓 13 及以上 | 更严：data 的每个子目录要单独授权，obb 还要额外给「安装未知应用」权限 |
| 安卓 11 以上、2024 年 3 月后的安全补丁 | 系统层面封掉了授权入口，普通方法进不去（见第四节） |

## 二、安卓 11/12：逐个目录确认授权

1. 在 ZArchiver 里进入 `Android/data`，系统弹文件选择器；
2. 核对弹窗顶部显示的路径就是你要的那个目录（弹错位置就授权了别处）；
3. 点「使用此文件夹」（Use this folder）→ 确认授权；
4. `Android/obb` 同样操作一遍。

授权只对你确认的那一个子目录生效，进入别的应用目录还要再确认一次。

## 三、安卓 13 及以上：两条不同的路

**进 `Android/data` 的子目录**（比如某个游戏的数据文件夹）：

1. 进入时系统直接弹授权窗口，同样核对路径后点「使用此文件夹」；
2. 授权后的子目录里，解压、粘贴、删除等操作都能做；
3. 但 `Android/data` 这一层本身仍有限制：不能随手新建任意名字的文件夹、不能把子文件夹改成任意名字——能建的只有「以已安装应用包名命名」的文件夹（装游戏数据包正好够用）。

**进 `Android/obb`**：除了文件授权，还需要给 ZArchiver 「安装未知应用」权限：系统设置 → 应用 → ZArchiver → 「安装未知应用」→ 允许。这是因为 obb 目录在系统看来与安装行为相关。

**安卓 TV 11/12**：设置 → 应用 → ZArchiver → 权限 → 「文件和媒体」→ 勾「始终允许」。

## 四、授权窗口不弹了：2024 年补丁之后的系统

两个时间点把事情变难了，来源均为官方说明（截至 2026-09，以官方页面为准）：

- **2023 年 9 月起**，Google 更新了系统「文件」（Files/DocumentsUI）组件，弹出的授权窗口会打开在错误位置，选不了 data/obb。部分设备可以在 系统设置 → 应用 → 文件（Files）→ **卸载更新** 后重试；
- **2024 年 3 月起**，安全补丁直接封掉了用「文件」应用授权 data/obb 的路径，且**不可回退**——如果你的安全补丁在这之后，「卸载更新」也救不回来。

碰到不可回退的情况，普通授权方法到此为止，剩下的出路：

- **换台电脑**：数据线连接后用电脑往这两个目录复制文件，不受安卓存储限制（装游戏数据包最常用这条）；
- **ROOT 或 Shizuku**：官方应用支持（设置 → ROOT → 勾选用于 data/obb；Shizuku 是免 root 的授权工具，配置以 [https://shizuku.rikka.app/](https://shizuku.rikka.app/) 官网说明为准）。这两条都涉及对系统的高权限操作，普通用户不必为此折腾，操作产生的影响自己把握。
