Sketchbook 是给手机和平板用的绘画应用，装好就能用手指或触控笔画画，图层、笔刷、调色这些都在应用里。本篇解决两件事：网盘里这份包是哪个版本，以及怎么把它顺利装进你的安卓设备。

## 一、先核对网盘里这份包是哪一版

各下载站登记的版本号与网盘里这份常常对不上。本文出现的版本、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Sketchbook |
| 版本号 | 6.2.6 |
| 包名 | `com.adsk.sketchbook` |
| 安装包体积 | 169.58 MB |
| MD5 | `4fb657ef60b3dfd270b05b80c73ecc29` |
| 形态 | 安卓 APK |
| 本文核对时间 | 2026-09-22 |

判断是不是同一个包，看**包名 + MD5**，不要看名字旁边的版本数字。两点容易混：

- 应用名统一写作 **Sketchbook**：首字母大写、后面的 b 小写。它 2021 年 6 月 30 日之前叫 Autodesk SketchBook，之后从 Autodesk 剥离、由 Sketchbook, Inc. 继续发布，名称也改成了现在的写法。
- 网上搜到的多是官方当时的最新版，与网盘里这份不一定是同一版；版本号不同属正常，本文只认上表。

## 二、装之前先确认这是安卓版

- **系统版本**：安卓版要求 **Android 9 及以上**。系统低于这个版本的设备装不上。
- **设备形态**：手机和平板都支持，两套界面布局不一样，见 [第一次画一张图.md](第一次画一张图.md)。
- **不是桌面版**：Windows 和 macOS 上那个叫 Sketchbook Pro，版本号是 9.x，和手机版不是同一个安装包，手机装不了。
- **触控笔**：官方在安卓上支持三星 S Pen，以及 Wacom MovinkPad 系列平板配的 Wacom Pro Pen 3；**外接数位板不支持**，第三方触控笔官方也已不再主动支持。细节见 [手写笔与压感设置.md](手写笔与压感设置.md)。

## 三、安卓：装网盘里这份 APK

1. **先转存再下载**。打开 [Sketchbook 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4bb4aa1d0c4b)，把 APK 转存到你自己的网盘再下载到手机。这一步别省：分享链接失效后，只有转过存的那份还在。
2. **允许安装未知来源应用**。在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，允许你要用来打开安装包的那个应用（文件管理器、浏览器或网盘客户端），再点这个 APK 安装。国产系统里这一项的名字略有差别，见下表。
3. **提示「应用未安装」就先卸载旧版**。手机里已有同包名但签名不同的版本时，覆盖安装会直接失败，先卸掉再装。
4. **同一包名无法共存**。装着旧版再装这份，旧版会被覆盖；想保留旧版就别装这一份。

几种常见的拦截与对应入口：

| 系统 | 允许安装的入口 |
| --- | --- |
| 原生 Android / 类原生 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |
| 小米 / 红米（HyperOS、MIUI） | 设置 → 应用设置 → 应用管理 → 右上角菜单 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 应用管理 → 特殊应用权限 → 安装未知应用 |
| vivo / iQOO | 设置 → 应用与权限 → 权限管理 → 安装未知应用 |

更愿意从官方渠道取包也可以：官网是 `https://www.sketchbook.com/`，帮助中心是 `https://help.sketchbook.com/`，Google Play 上的包名同为 `com.adsk.sketchbook`，包名对得上就是同一个应用。

用 iPhone 或 iPad 的话，网盘里这个 APK 装不了，需要到 App Store 搜索 Sketchbook 安装。

关于版本更新：走官方渠道装的版本由 Google Play 推送更新；本文这份是从网盘取回的，要换新版就取回新的安装包覆盖安装（同一个包名会覆盖旧版，作品文件不受影响）。

## 四、第一次打开要确认的几件事

1. **语言**。安卓版没有独立语言开关，界面语言**跟随系统设置**。简体中文在支持列表里；如果系统语言不在支持范围内，会回落到英文或系统里的第二语言。想用中文界面，先把系统语言设成简体中文再打开。
2. **权限**。首次保存或导入图片时，系统会要照片与媒体（部分机型叫「文件与媒体」）权限。三类权限各自对应一件事，给全了功能才完整：

    | 权限 | 用在哪 |
    | --- | --- |
    | 照片 | 从手机相册挑图导入到画布 |
    | 相机（媒体） | 扫描草图，见 [把纸上的草图扫进手机.md](把纸上的草图扫进手机.md) |
    | 文件 | 保存与读取作品，定位到你想存的位置 |

    拒掉之后不是报错，而是「导入点了没反应」「保存后 Gallery 找不到」这类沉默的失败，所以第一次装完先把这三项都放行。

3. **自动保存**。首次启动会弹一次与自动保存有关的提示；系统字体调得很大的话，这个提示可以滚动看完。默认的保存节奏偏保守，建议接着去「主菜单 → Preferences → Sketchbook Data → Automatically Save to Gallery」把间隔改成 15 或 30 分钟，原因见 [第一次画一张图.md](第一次画一张图.md)。
4. **确认版本**。装完在系统「设置 → 应用 → Sketchbook」里能看到版本号，与上表的 6.2.6 对上就对了。

## 五、装完做一次最小验证

开一张新画布，随便画两笔，然后**保存一次并退回 Gallery 看缩略图有没有更新**：

- 一打开就闪退、进不去 → 见 [常见问题与排查.md](常见问题与排查.md)；
- 能画但保存后 Gallery 里看不到 → 多半是媒体权限没给，回第四节第 2 条重开权限。

能正常保存，说明这份包在这台设备上可用；接下来怎么上手，见 [第一次画一张图.md](第一次画一张图.md)。
