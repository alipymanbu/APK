# Sketchbook 把纸上的草图扫进手机

> 用手机拍一张纸上画好的草图，直接扫进 Gallery 变成可继续画的画布，附各档处理的差别与报错处理。
> **相关文档**：[第一次画一张图.md](第一次画一张图.md) · [保存导出与备份.md](保存导出与备份.md) · [常见问题与排查.md](常见问题与排查.md)

在纸上勾好的线要变成能继续编辑的文件，除了重新描一遍，也可以直接拍下来让 Sketchbook 扫进 Gallery。这个扫描工具**只有手机和平板版有，桌面版没有**，而且它不只是拍照——会自动找边缘做透视校正、再把纸的背景清掉。

## 一、扫描入口

1. 主菜单 → **Gallery**；
2. Gallery 里点新建的图标 → **Add Scans to Gallery**；
3. 相机启动后会提示「Looking for sketch」，识别到画面里的纸张/画面时，会出现一个蓝色方框圈住它，然后自动完成扫描——包括自动做透视校正和清理背景。

三个手动补救的地方：

| 情况 | 怎么做 |
| --- | --- |
| 没自动框住 | 按快门按钮，把整个取景画面的内容都拍下来 |
| 不想要自动扫描 | 点右上角那个图标关掉自动扫描，图标会变样子 |
| 纸太暗 | 点闪光灯图标补光 |

注意一点：**画面内容如果是整张纸铺满取景框、塞不进去，会被从边缘裁掉**，拍之前留点余量。

## 二、扫完之后先处理，再落库

扫完不会立刻存进去，会停在扫描界面让你先调：

| 操作 | 作用 |
| --- | --- |
| **Rescan** | 这张不满意，重拍 |
| 旋转图标 | 逆时针转 90 度 |
| 背景图标 | 显示 / 隐藏背景（默认显示，点一下关掉） |
| 色彩处理 | 三档选一个，见下表 |
| **Done** | 存进 Gallery 并返回 |

三档色彩处理的差别，选择依据是「你接下来要在上面干嘛」：

| 档位 | 结果 | 适合 |
| --- | --- | --- |
| **B&W** | 转成黑白并把背景去掉，只剩线条 | 线稿要直接上色，不想被纸的底色和纸纹干扰 |
| **Color** | 保留画面的颜色，去掉背景 | 保留了彩色的草图，要接着在手机上调 |
| **Original** | 颜色和背景都原样保留 | 想把纸的质感一起留着，或者只是存档 |

## 三、扫进来的东西落在哪

扫完的图进 Gallery，就是一张普通作品。官方对它的定位是「**作为新画布的基础**」——可以直接在它上面新建图层描线、上色：

- 想分层接着画，见 [图层与混合模式怎么用.md](图层与混合模式怎么用.md)；
- 想把它导出到电脑继续做，见 [保存导出与备份.md](保存导出与备份.md)。

如果你只是想留个照片、不需要继续画，用系统相机拍完再「Add Image to Gallery」导入也一样，区别是**没有透视校正和背景清理**这两步。

## 四、扫描报错怎么处理

| 提示 | 原因 | 怎么办 |
| --- | --- | --- |
| Your device doesn't support this feature | 设备没有摄像头 | 这台设备用不了扫描，改用导入图片 |
| Unable to launch the camera / Sketchbook is Restricted from Camera Access | 应用的相机权限没开 | 到系统设置里给 Sketchbook 打开相机权限；不同安卓版本提示措辞不一样 |
| Sketchbook must use the full screen to scan sketches | 应用处在分屏状态 | 退出分屏，让 Sketchbook 全屏再扫 |

相机权限为什么必须给，和照片、文件两类权限是同一个道理，见 [下载与安装教程.md](下载与安装教程.md) 的权限一节。
