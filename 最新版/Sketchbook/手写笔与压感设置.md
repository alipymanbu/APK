压感是这条链路里最容易出错的地方：笔不对，画出来的线从头到尾一样粗；开关没设对，手指一搭上画布就留下笔迹。本篇把支持的笔、要改的开关、以及压感不生效时的判断顺序一次说清。

## 一、安卓端官方支持的笔

| 输入设备 | 支持情况 | 说明 |
| --- | --- | --- |
| 三星 **S Pen** | 支持 | 不用配对，直接就是真压感；笔的设置项在系统的 S Pen 设置里 |
| **Wacom Pro Pen 3**（Wacom MovinkPad 系列平板） | 支持 | 官方明确列入支持范围 |
| 外接数位板 | **不支持** | 手机/平板通过 USB 或蓝牙接的画板，不在这套支持范围内 |
| 其他第三方触控笔 | 不再主动支持 | 配对入口还在，但官方已无法验证其表现 |

结论很直接：**官方在安卓上的压感只覆盖 S Pen 与 Wacom Pro Pen 3 这两种笔**。其他笔能画，但拿不到官方支持的压力数据。

## 二、两个开关决定「谁能画」

在画布的主菜单里能打开 **Pen Mode**，另有一个多指手势开关：

| 开关 | 打开后 | 关掉后 |
| --- | --- | --- |
| Pen Mode | 只有笔能在画布上留下笔迹，手指仍可点按钮、开面板 | 手指和笔都能画 |
| Enable Multi-touch Gestures | 手指可以用于双指缩放、旋转、平移，以及三指手势 | 所有多指手势失效 |

常见配法：

- **有触控笔、画画时手掌容易碰到屏幕**：Pen Mode 打开、多指手势打开——笔负责画，手指负责转和缩放。
- **只用手指画**：Pen Mode 要关掉，开着的话手指在画布上留不下笔迹。
- **两只手同时用、经常误触**：先关多指手势，代价是缩放和旋转要改用界面按钮。

## 三、长按取色

「主菜单 → Preferences → Gestures」里有 **Tap-hold for Color Picker**。打开后，**长按画布**就能吸取当前显示的颜色——手指和笔都生效。

它的好处是取的是「屏幕上你看到的颜色」，而不是某一层原始的颜色，所以混合模式叠加后的效果也能直接吸走。

## 四、笔身按键可以自己定义

6.2.2 起，安卓端支持**自定义笔身按键的动作**。设好之后，按一下笔上的按键就能触发你指定的功能，不用再切回工具栏。

具体能绑哪些动作、绑定的入口叫什么，跟着你手机上的实际界面走——不同机型把 S Pen 的按键设置放在系统设置的不同位置。

## 五、压感没反应，按这个顺序查

1. **先确认笔是不是官方支持的那支**。第三方电容笔不在官方支持范围内，换开关也解决不了，见第一节。
2. **看笔刷属性里的压感项**。有些笔刷的压感相关参数会被调到接近恒定，这时无论怎么用力，线宽都不变——换一支默认笔刷试一笔，就能区分是笔的问题还是笔刷设置的问题。笔刷属性怎么调，见 [画笔与笔刷怎么调.md](画笔与笔刷怎么调.md) 的第二节。
3. **确认 Pen Mode 与手势开关的组合**是否合适，见第二节。
4. **低端机上还有一个独立开关**：「主菜单 → Preferences → Canvas → **High Precision Strokes**」（仅安卓，默认关）。打开后线条更精细，但**低配设备可能变卡**——它是精度开关，不改变压感有无，别把它当压感的解决办法。

## 六、ChromeOS / Chromebook 上的两点差别

大多数 Chromebook 和 ChromeOS 平板跑的是 Android 系统，可以从 Google Play 装 Sketchbook，但体验取决于具体设备：

- **系统版本与 Android 版本是两件事**。Chromebook 的系统更新到最新，底下的 Android 版本仍可能偏低，装不上或不满足系统要求时，先看 Android 版本。
- **很多 Chromebook 没有压感笔驱动**。带笔的 ChromeOS 平板更有可能支持压感；各家笔的技术方案不一样，能识别原厂笔不代表 Sketchbook 能拿到压感数据。

## 七、镜像到外接屏幕时的限制

把画面镜像到电视、显示器等外部设备时，**打开、保存、恢复文件这类功能可能不被支持**。需要认真画画或存盘的时候，别在镜像状态下做，回到设备本机上操作更稳。
