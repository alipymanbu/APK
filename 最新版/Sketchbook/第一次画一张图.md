手机版 Sketchbook 的界面元素比桌面版少，但该有的入口都在。本篇按「新建 → 落笔 → 手势 → 保存」的顺序走一遍，让你在一张图上把主要操作都碰一次。

## 一、先认清手机版界面上有什么

打开后你能看见的东西，取决于设备是手机还是平板：

| 元素 | 手机上 | 平板上 |
| --- | --- | --- |
| 工具栏 | 顶部，含主菜单、撤销重做、工具、笔刷库、颜色、图层、隐藏界面 | 顶部，工具项比手机全 |
| 笔刷面板 | 默认隐藏，可在偏好设置里打开 | 常驻 |
| 图层编辑器 | 默认收起，点图层图标打开，也可以钉住保持展开 | 默认在屏幕右侧常驻 |
| 标记菜单 | 有，一根手指长按呼出 | 有 |
| 双色环（Double Puck） | 点标记菜单时一并调出 | 常驻在笔刷面板一侧 |

三个入口值得先记住：

- **主菜单**：新建画布、Gallery、保存、导入、导出与分享、偏好设置都在这里。
- **标记菜单**：一根手指长按呼出，用来在笔刷与上一个笔刷之间切换、取屏幕上的颜色、翻转画布、调出双色环——界面藏起来时它照样能用。
- **角落工具**：**双击屏幕四角**触发，默认从左上是清空图层、右上是贴合视图、左下撤销、右下重做。这套映射可以在偏好设置里改成你顺手的工具。

## 二、新建一张画布

主菜单 → **New Sketch**，面板会展开：

1. 填像素宽高。默认带入你上次用的尺寸。
2. 不想锁比例，就点中间那个链接图标解开**纵横比**；画竖构图想改横构图，直接点预览中间的旋转图标。
3. 看右上角显示的图像大小。**别一上来就开很大**——画布越大越吃内存，能加的图层反而越少。
4. 点 **Create** 开始。

画布尺寸参考值：

| 用途 | 建议尺寸 | 说明 |
| --- | --- | --- |
| 随手速写 | 2000 × 2000 上下 | 手机上够清晰，图层能开得多 |
| 手机壁纸 | 1080 × 2400 左右 | 按屏幕比例填 |
| 打算打印 | 按印刷尺寸换算 | 版面上限见下一条 |

- **全平台画布上限是 100 百万像素（100 MPX）**。超过就创建不了，这条在手机上同样生效。
- 窗口右侧还有一个**预设**标签页，官方预设和自己存的预设都在那；自己加预设点 Add Preset，改预设名或删预设用条目右侧的齿轮与垃圾桶图标。
- **画布建好后想再改尺寸，需要先买过 Premium Bundle**，见 [免费版和付费版有什么区别.md](免费版和付费版有什么区别.md)。建之前想清楚尺寸更省事。

## 三、落下第一笔

1. 点工具栏的**笔刷库**图标选一支笔。默认那组基础笔刷可以直接开始画，换笔刷、导入笔刷是后面的事。
2. 调笔刷大小和不透明度：在笔刷面板里拖滑块，或者**点滑块上方的数字用键盘输入精确值**（6.2 起支持）。
3. 直接画。手指可以画，有 S Pen 的话压感会自动生效，见 [手写笔与压感设置.md](手写笔与压感设置.md)。
4. 想换颜色，点工具栏的颜色图标进颜色编辑器，或者长按画布用取色器吸当前颜色。
5. 画错了：左下角双击撤销、右下角双击重做；三根手指向左滑也是撤销、向右滑是重做。
6. 想擦：换成橡皮笔刷，或者把颜色切成**透明色**，这时任何一支笔刷都当橡皮用。

笔刷的选、调、导入导出另有一篇，见 [画笔与笔刷怎么调.md](画笔与笔刷怎么调.md)。

## 四、手势速查

| 手势 | 作用 |
| --- | --- |
| 两根手指旋转 | 转动画布 |
| 两根手指拖动 | 平移画布 |
| 两根手指开合 | 缩放画布 |
| 两根手指双击 | 默认贴合视图，可改 |
| 三根手指向左 / 向右滑 | 撤销 / 重做 |
| 三根手指向上 / 向下滑 | 打开颜色编辑器 / 笔刷库 |
| 三根手指单击 | 默认撤销，可改 |
| 三根手指双击 | 默认全屏，可改 |
| 双击屏幕四角 | 触发角落工具 |

三指手势容易失败的两个原因：手指并得太紧、横平竖直地滑。**手指稍微分开、带一点角度**会稳得多。所有手势映射都能在「偏好设置 → Gestures」里改。

另外两个和画布方向有关的开关，也在偏好设置里：

- **Rotate Canvas**（默认开）：允许两指旋转整个画布。
- **Lock Canvas Orientation**（仅平板）：开了之后转设备时画布和界面一起转，关掉就只转界面、画布不动。

## 五、画完立刻保存

主菜单 → **Save** 即可。如果这张图之前已经存进 Gallery 又改过，保存时会一并给你「**存为副本**」的选项——想留几个进度节点就选它。

从画布退回 Gallery 时（主菜单 → Gallery），会弹三选一：

- **Save current sketch**：更新原文件；
- **Save current sketch as a copy**：原文件不动，改动存进新文件；
- **Discard changes**：丢掉这次改动。

**自动保存建议现在就开**。路径是「主菜单 → Preferences → Sketchbook Data → Automatically Save to Gallery」，可选 15 / 30 / 60 分钟。默认不开定时保存的话，设备内存吃紧或突然关机时，没保存的部分只靠临时缓存兜底，而那个缓存并不可靠——原因与文件存放位置见 [保存导出与备份.md](保存导出与备份.md)。

## 六、接下来会经常碰到的几件事

- 想分层画（线稿一层、上色一层），去图层编辑器加图层，见 [图层与混合模式怎么用.md](图层与混合模式怎么用.md)。
- 想把纸上已经画好的草图搬进手机，用扫描工具，见 [把纸上的草图扫进手机.md](把纸上的草图扫进手机.md)。
- 想把作画过程录成视频发出去，开延时录制，见 [延时录制怎么用.md](延时录制怎么用.md)。
- 画到一半开始卡、或者发现图层加不上去，多半是内存而不是存储的问题，排查步骤见 [常见问题与排查.md](常见问题与排查.md)。
