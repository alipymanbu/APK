## 一、能同步的都有什么

Koodo Reader 的同步对象不止阅读进度：书库、阅读进度、书签、高亮和笔记都在同步范围内。只在一台设备上看书的话，这些数据全存在本地，不联网也能用；同步是可选项，需要你主动配置，不配置就不会往云上传任何东西。

## 二、可以接哪些云端通道

官方支持的云端通道覆盖面较宽，大致分三类：

- **国际网盘**：Dropbox、OneDrive、Google Drive 等；
- **国内网盘**：百度网盘、115、阿里云盘等；
- **自建与网关类**：WebDAV、SMB、FTP/SFTP、S3 兼容对象存储等，有 NAS 或自建服务的人走这类。

移动端各数据源的支持情况（截至 2026-09 摘自官方文档，以官方页面为准）：

| 数据源 | 移动端 |
| --- | --- |
| Dropbox / OneDrive / Google Drive / Box / pCloud / Yandex Disk | 支持 |
| 百度网盘 / 115 网盘 / 阿里云盘 | 支持 |
| WebDAV / FTP / SFTP / 对象存储 / Docker | 支持 |
| SMB | 支持 |
| MEGA | 不支持 |
| 本地文件夹 | 暂不支持（官方标注敬请期待） |

挑法很简单：手头已有哪个网盘就用哪个；都没有但想自己掌控数据，WebDAV 最通用，逐项填法见[WebDAV数据源配置步骤.md](WebDAV数据源配置步骤.md)。

## 三、在安卓上配置同步的大致步骤

官方同步文档给出的流程是三步（截至 2026-09，菜单措辞以你手上的版本为准）：

1. **登录账号**：安卓端去「设置 → 账户」登录。官方文档把这一步写作「登录 Koodo Reader 专业版」，即云端同步是跟着专业版账号走的；你手上 2.3.9 这个版本的口径可能不同，以应用内实际提示为准；
2. **绑定数据源**：登录后按应用引导添加，或稍后去「设置 → 同步选项 → 添加数据源」自己加，逐项填法见[WebDAV数据源配置步骤.md](WebDAV数据源配置步骤.md)；
3. **点同步按钮**：设备 A 导入新书后点顶部同步，设备 B 也点一次同步按钮，等数据拉下来两边就对上了。同步是增量的，传过的书不会重传。

另外有一个独立的「Koodo Sync」开关：开启后，阅读进度、笔记、高亮、书签、书架这类阅读数据走官方云端加密存储与同步（图书文件本体不走这条通道），官方说明该功能需手动开启，关闭后云端也会同步删除这部分数据。介意阅读数据经第三方云端的就不用开，只走自己的数据源。

注意：两台设备同时改同一本书可能出现冲突提示，处理方式以应用内提示为准；重要笔记建议先手动导出一份留底再做折腾性操作。

## 四、换手机怎么搬数据

思路一句话：旧手机先备份，新手机恢复。

1. 旧手机上把书库与笔记导出为备份文件（在设置的数据/备份选项里），或把云端同步完整跑一遍；
2. 新手机装好 Koodo Reader，安装方法见[下载与安装教程.md](下载与安装教程.md)；
3. 新手机登录同一账号，或配置同一个网盘/WebDAV 目录，选择从云端或本地备份恢复；
4. 恢复完抽查几本书：进度、高亮、书签都在，才算搬完。

书是用导入方式进的手机本地存储，备份和同步管的是数据记录，个别情况下书文件需要重新导入一次，属正常现象。

## 五、同步失败先查这几处

- **网盘授权过期**：去设置 → 同步选项，把这个数据源删除再重新添加；
- **WebDAV 信息填错**：地址、端口、目录缺一项都连不上，先在别的工具里验证这个地址能用，逐项填法见[WebDAV数据源配置步骤.md](WebDAV数据源配置步骤.md)；
- **115 网盘**：官方说明其最多同时授权两台设备，加新设备后旧设备凭证失效，需重新授权；
- **进度、书架各设备对不上**：确认各设备登录账号一致、绑的是同一个默认数据源；都排除后还不行，在「设置 → 同步 → 重置同步记录」后重新同步；
- **网络不通**：部分国际网盘在国内网络环境下连不上，换网络环境再试；
- 更多安卓端报错（书打不开、听书闪退、提示云端不存在图书）集中在[安卓打不开书与听书闪退怎么办.md](安卓打不开书与听书闪退怎么办.md)，通用排查见[常见问题与解决办法.md](常见问题与解决办法.md)。
