## 一、先确认是不是「天生不能克隆」

克隆会改变应用的签名证书，官方在首页明确写了两类后果（截至 2026-09 的官方页面）：

- **依赖证书的功能直接不可用**：Google 账号登录、Google Play 服务、Google Play Games、Google Drive 备份、应用内购买，这些在克隆里都不会工作。
- **自校验证书的应用克隆后可能拒绝运行**：带高级防拷贝、reCAPTCHA 校验的应用，克隆后可能闪退或报错。

这不是设置问题，是机制限制。官方列出的不能克隆名单（节选，实时名单以官方页面为准）：

| 应用 | 克隆情况 |
| --- | --- |
| 微信 WeChat | 不能克隆 |
| Snapchat、Viber、Trello | 不能克隆 |
| YouTube | 不能克隆 |
| OneDrive、Evernote、Kodi | 不能克隆 |
| Pokémon GO | 不能克隆 |
| AliExpress、Lazada 等部分地区应用 | 不能克隆 |
| 银行与支付类（GCash、Dana、OVO、paytm、Tokopedia、Grab 等） | 不能克隆 |
| 大多数 Google 应用 | 不能克隆（Chrome、Gmail 可用但有限制） |
| 大多数微软应用 | 不能克隆（Skype、LinkedIn 可用） |
| WhatsApp 及其衍生版 | 2.x 时代在不能克隆名单里；官方 2026-09 的 4.0 Beta 宣布重新支持，且要求 Ultra 版本 |

官方同时给了一批**可以克隆**的常见应用（节选）：Telegram、Instagram、Facebook、Facebook Lite、X（Twitter）、Skype、Spotify、Netflix、LINE、Pinterest、Tumblr、WordPress、Outlook、Yahoo Mail、Firefox、Opera、SwiftKey 键盘、Amazon Kindle、Dropbox、Flickr、Flipboard。动手前先对一眼名单，能省掉大半排查时间。

## 二、按现象排查

### 1. 生成克隆时弹出警告

克隆对话框里的警告要读完再点确认 —— 多数是提示某个选项与这个应用冲突，按提示把对应选项关掉或换掉，再重新生成。直接无视警告往下走，得到的多半是一个装上就坏的克隆。

### 2. 克隆装上就闪退 / 打开就报错

按官方建议的顺序逐项试（选项名称以你手上版本界面为准，2.x 与 3.x 有差异）：

```text
1. Cloning mode 改为 Skip native libraries，或改用 Manifest 模式重新生成
2. Cloning options 里打开 Increase compatibility
3. 仍失败再开 Ignore crashes
4. 进阶 workaround（逐个开，每改一次重新克隆测试）：
   Single process / Process name workaround / Package name check workaround /
   APK check workaround / Clone check workaround / User-Agent workaround
```

还有一个绕开思路：新版本克隆不了，就改用旧版本的 APK 克隆 —— 把旧版安装包加进 APKs 标签再走克隆流程（见[克隆应用完整步骤.md](克隆应用完整步骤.md)第四节）。

### 3. 安装克隆时被 Play Protect 拦截

弹「Unsafe app blocked」或杀毒类应用报毒，官方说明这是**误报**，来源有两个：克隆 APK 用的是非官方证书签名；生成的克隆 targetSdk 偏旧。处理：在拦截提示里点开详情，选择「仍然安装 / Install anyway」。官方博客有专文：[Unsafe app blocked message](https://appcloner.blog/2024/04/16/unsafe-app-blocked-message/)。确认安装包来源是你自己刚生成的克隆，就可以放心放行。

### 4. 换个设备环境试试都不行

官方明确不保证兼容的环境：安卓模拟器、x86 架构设备、已 root 的设备、装有 GameGuardian / LSPosed / LSPatch / EdXposed 的设备、自定义 ROM。这类环境下克隆失败，不一定是设置问题，调设置未必有解。

### 5. 克隆能跑，退到后台就收不到消息

这不属于克隆失败，是后台进程被系统省电策略杀掉了 —— 按官方给的电池白名单步骤处理即可，完整流程单独成篇：[克隆应用收不到通知怎么办.md](克隆应用收不到通知怎么办.md)。

## 三、还不行，怎么反馈

在 **Cloned apps** 标签对出问题的克隆用 **Report app issue** 提交反馈（在[克隆应用完整步骤.md](克隆应用完整步骤.md)第五节有入口说明）。官方会修复部分兼容问题 —— 一个今天克隆不动的应用，几个版本之后可能就能克隆了；反过来，应用自己升级也可能引入新的防克隆措施，更新克隆前先看[克隆应用更新与数据管理.md](克隆应用更新与数据管理.md)里的更新机制。
