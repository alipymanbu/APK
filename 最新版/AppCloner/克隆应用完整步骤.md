## 一、主界面五个标签

底部分成五块，克隆相关的操作都从这里进出：

| 标签 | 放什么 |
| --- | --- |
| Apps | 手机上已安装的应用，克隆的主要入口 |
| APKs | 你手动加进来的安装包，也能当克隆入口 |
| Cloned apps | 已经装上手机的克隆体，管理它们 |
| Cloned APKs | 每次生成的克隆安装包，相当于自动留底 |
| Store | 登录、购买与设备管理 |

克隆只能从 Apps 和 APKs 两个标签发起；Cloned apps 里的克隆不能再克隆一次。设置里可以打开「Show system apps」把系统应用也列出来，但官方明确不建议克隆系统应用。

## 二、克隆一个已安装的应用

1. 在 **Apps** 标签找到要克隆的应用，工具栏的搜索按钮可以按名字过滤。
2. 点应用进入它的克隆设置页。第一次克隆不用改任何设置，默认值直接用，先跑通再谈调整。
3. 点右下角的 **Clone** 按钮。
4. 等待生成：几秒到几分钟不等，取决于应用体积与手机性能；期间保持 App Cloner 在前台，别切走。
5. 生成完会弹出安装提示。第一次装克隆会要求给 App Cloner 本身授予「安装未知应用」权限，允许一次即可。
6. 装完点 **Launch** 打开克隆。克隆与原应用并行运行、互不干扰、数据不互通。

克隆过程中留意对话框里的警告文字 —— 很多「克隆起来能装、用起来不对劲」的问题，警告在这一步就已经提示了，对应的调整思路见[克隆失败与不兼容应用排查.md](克隆失败与不兼容应用排查.md)。

## 三、克隆编号：多开与更新共用一套机制

每个克隆带一个克隆编号（Clone number），这个编号决定你生成的是「新克隆」还是「更新旧克隆」：

- **不同编号** → 生成一个全新的、独立的克隆。同一个应用想登三个号，就编三个号。
- **相同编号** → 覆盖更新这个编号已有的克隆，**保留它现有的文件和登录数据**。想改克隆设置又不想丢数据，就用原编号重新克隆。
- **编号范围** → 批量克隆：把编号写成一段范围，一次生成多份，配合自动命名能一口气开出一批。部分 modding 选项支持占位符（运行时替换的变量），批量命名时让每个克隆自动带上自己的编号等差异，官方博客有专文：[Placeholders](https://appcloner.blog/2022/05/06/placeholders/)。

## 四、不装原版，直接克隆 APK

**APKs** 标签支持把安装包加进来再克隆，适合两种场景：原应用要保留最新版、但克隆想用旧版本；或者拿到一个来路将信将疑的 APK，想先套上隐私选项再装。

加 APK 的入口（不同版本叫法略有差异，以你手上界面为准）：

| 入口 | 用途 |
| --- | --- |
| From a file | 从手机存储选一个 APK 文件 |
| From a directory | 整个文件夹批量导入 |
| From an installed app | 把已装应用的 APK 复制进来 —— 之后就算卸载原应用，也还能从这份 APK 克隆 |
| From a web page / URL | 在线搜索或按网址获取 APK（第三方市场来源，注意甄别文件来源） |

从 APK 克隆的后续操作与第二节相同。

## 五、克隆生成之后去哪管

- **Cloned apps**：启动、卸载克隆，查看应用信息，把克隆另存为 APK 分享出去。克隆跑不正常时，菜单里的 **Report app issue** 可以把问题报给官方 —— 部分问题会在后续版本修复，也就是说同一个应用过几个版本可能就克隆得动了。
- **Cloned APKs**：每份克隆的安装包都在这里留底，同编号重新克隆会替换旧包。想省空间可以开「克隆安装成功后自动删包」，想留备份可以开「自动导出克隆包到外部存储」（设置项名称以你手上版本为准）。

克隆装好之后怎么更新、数据怎么备份迁移，见[克隆应用更新与数据管理.md](克隆应用更新与数据管理.md)。多开之后最常碰到的后续问题是「退到后台就收不到消息」，处理顺序见[克隆应用收不到通知怎么办.md](克隆应用收不到通知怎么办.md)。
