## 二、获取安装包

打开 [Calflow 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ee7155e7937b)，把分享内容转存到自己的网盘后再下载：

1. 手机装有夸克浏览器时，链接会直接唤起夸克，选「转存到我的网盘」；
2. 没有夸克就在浏览器里打开链接，登录或注册后转存；
3. 进入转存的文件夹，下载 `Calflow_v1.0.1.apk`；
4. 直接下到手机最省事；先下到电脑再传手机也行，文件内容不会变。

## 三、安卓安装步骤

1. 在文件管理器里点开下载好的 `Calflow_v1.0.1.apk`；
2. 若系统提示「禁止安装来自此来源的应用」，按弹窗跳转去授权：
   - 通用路径：设置 → 安全 / 隐私 → 安装未知应用，给文件管理器或浏览器授权；
   - 小米、华为、OPPO 等品牌的入口名称略有差异，跟着弹窗跳转最快；
3. 等安装完成，打开应用；
4. 核对包名：设置 → 应用管理 → Calflow → 应用信息，应为 `com.fcaw.vlf`。

## 四、安装前的检查

- **系统版本**：安卓 5.2 及以上，低于该版本安装会直接失败；
- **存储空间**：安装包 74.00M，安装后占用更大，建议预留 500MB 以上可用空间；
- **文件完整性（可选）**：把 APK 传到电脑后核对 MD5：

```powershell
certutil -hashfile Calflow_v1.0.1.apk MD5
```

输出与表格里的一致（不区分大小写）即文件完好；不一致说明传输中损坏，重新下载即可。

## 五、装不上时的三个常见原因

安装失败基本出在前面列过的三处：来源授权没给、手机系统低于安卓 5.2、安装包传输损坏。逐项对照第三、四节排查即可；装好后的功能认识见 [是什么软件.md](是什么软件.md)。
