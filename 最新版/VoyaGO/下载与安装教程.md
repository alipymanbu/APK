## 二、获取安装包

打开 [VoyaGO 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3ef231510534)，把分享内容转存到自己的夸克网盘后再下载：

1. 手机装有夸克的话，链接会直接唤起夸克 → 选「转存到我的网盘」；
2. 没有夸克就在浏览器里打开链接 → 登录/注册后转存；
3. 进入网盘里你转存的文件夹，下载 `VoyaGO_v1.1.2.apk`；
4. 只下到手机上是最省事的路径；先下到电脑再传手机也行，文件名与 MD5 不会变。

## 三、安卓安装步骤

1. 在文件管理器里点击下载好的 `VoyaGO_v1.1.2.apk`。
2. 若系统弹出「禁止安装来自此来源的应用」，按提示去允许该来源安装：
   - 通用路径：设置 → 安全 / 隐私 → 安装未知应用，给文件管理器或浏览器授权；
   - 部分品牌（小米、华为、OPPO 等）叫「安装未知应用」或在手机管家的安全设置里，按弹窗跳转最快。
3. 等安装完成，打开应用。
4. 核对装的是不是这份包：设置 → 应用管理 → VoyaGO → 应用信息，包名应为 `com.naxiemolv.tv.tv01`。

## 四、安装前的检查

- **系统版本**：安卓 5.2 及以上。低于它安装时会直接提示失败。
- **存储空间**：安装包 104.33M，安装后应用本体占用更大，建议预留 500MB 以上可用空间再装。
- **文件完整性（可选）**：在电脑上核对 MD5 与表格一致再传手机：

```powershell
certutil -hashfile VoyaGO_v1.1.2.apk MD5
```

输出应为 `c4f254962c84e98f0e772f67fdcc6465`（不区分大小写）。不一致说明文件在传输中损坏，重新下载即可。

## 五、装完之后：旧版怎么更新

网盘这份是 1.1.2，官方此后还在持续发版（版本历史见 App Store 的版本记录）。更新方式按平台分：

- **安卓**：用新 APK 覆盖安装（包名相同即为升级，不用先卸载）。可对照 [应用宝的 VoyaGO 页面](https://sj.qq.com/appdetail/com.naxiemolv.tv.tv01) 看当前渠道版本号。
- **iPhone / iPad**：直接在 App Store 里更新。

升级前若在意本地行程数据，先确认已登录账号（该应用支持手机号一键登录），再操作。

iOS 不走 APK：在 App Store 搜 `VoyaGO` 安装即可。系统要求 iOS 13.0 或更高（iPhone / iPad / iPod touch 通用，部分 Mac 需 macOS 11.0+ 且 Apple 芯片），商店页大小显示 153.8 MB，以官方页面为准。iOS 端的价格与订阅问题见 [会员Pro价格与常见问题.md](会员Pro价格与常见问题.md)。
