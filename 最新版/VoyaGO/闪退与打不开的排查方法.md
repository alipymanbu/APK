## 一、按代价从小到大排查

VoyaGO 打不开、点进去就退、卡在启动页，大概率是本地缓存、系统资源或版本问题，不必一上来就卸载。下面的步骤按「代价从小到大」排列——先试前面的，前面的没用再往走，每一步都标了会不会丢数据。步骤依据是 vivo、OPPO、Apple 三家官方支持页给出的通用排查顺序，对任何安卓/iOS 应用都适用。

| 步骤 | 操作 | 会丢数据吗 |
| --- | --- | --- |
| 1. 强制关闭重开 | 从后台划掉该应用，重新打开 | 不会 |
| 2. 重启手机 | 关机再开机，清掉临时故障 | 不会 |
| 3. 检查更新 | 应用是否有新版、系统是否有新版，都更到最新 | 不会 |
| 4. 清缓存 | 长按 VoyaGO 图标 → 应用信息 → 存储占用 → 清理缓存 | 不会（只清临时文件） |
| 5. 检查权限 | 应用信息 → 应用权限，把存储、相机、定位等该开的打开 | 不会 |
| 6. 清除数据 | 同一页面里的「清除数据」 | **会**：本地登录状态与未同步数据全没 |
| 7. 卸载重装 | 卸载后重新安装 APK | **会**：本地数据全没，装回后靠账号恢复 |

第 6、7 步之前，先确认你已登录账号、且行程照片在相册里有底（原因见 [打卡记录与旅行日志分享教程.md](打卡记录与旅行日志分享教程.md) 第五节）。没登录就清数据，行程找不回来。

## 二、先确认是不是「版本太旧」这个原因

网盘这份是 1.1.2，官方此后修过一批已知问题。对照官方版本记录，下面这些问题**在新版里已修**，旧版遇到属正常：

- 航班查询失败 —— 1.5.8 修复（1.5.7 修过一批已知问题）；
- 部分功能逻辑问题 —— 1.0.8、1.5.0 等多个版本均有「解决已知问题」记录。

所以排查顺序上，**「检查更新」要排在清数据之前**：先用新 APK 覆盖安装（不用卸载，包名相同即升级，见 [下载与安装教程.md](下载与安装教程.md) 第五节），升级后再看问题还在不在。反过来说，如果问题是在升级到某版之后才出现的，先回想上一版是否正常，再决定是等官方下个修复还是回退——回退安装旧包前要先登录账号保存行程。

## 三、启动就闪退的三个高频原因

1. **系统版本不够**：要求安卓 5.2 及以上，低于它安装或运行都会失败。查法：设置 → 关于手机 → Android 版本。
2. **安装包不完整**：传输中断过的 APK 会装上但启动即崩。用 MD5 核对（[下载与安装教程.md](下载与安装教程.md) 第四节的命令），不一致重新下载。
3. **存储空间不足**：安装包 104.33M，运行时还要空间写缓存与照片。剩余空间低于 1GB 先清理再试。

## 四、都试过了还不行：带什么信息反馈

按官方简介，应用内「我的 → 和开发者聊聊」可直接联系开发者。反馈时一次把这四样给全，省掉来回补充：

1. 手机品牌与系统版本（如「小米 14 / Android 15」）；
2. VoyaGO 版本号（应用内「我的」页面可查；网盘包是 1.1.2）；
3. 闪退发生在哪一步（打开就退 / 打卡时退 / 切地图时退）；
4. 复现录屏或截图。

清理缓存、清数据这类操作无法解决时，通常意味着是应用自身对该机型适配的问题，只能等官方版本修复——留意应用内的更新提示即可。
