## 一、先确认你要装的是哪一版

JayMe 是周杰伦官方粉丝社区应用，由杰威尔音乐授权、福建天音文化传媒有限公司运营，安卓与 iOS 都有客户端。在动手安装前，先分清两件事：

- **本文对应的安装包**：版本 5.0.3，包名 `com.nd.sdp.star`，体积 114.14M，以上为 2026-09-24 从安装包本身读到的信息，安装后可在「设置 - 关于」里核对版本号。这组数字在应用商店的历史版本列表里也能查到（5.0.3 对应 114.14MB），可以用来二次确认包没拿错。
- **应用商店里的最新版**：官方渠道会持续发新版本，商店页显示的版本号通常更新，而且新版对系统的要求也更高（新版历史页面标注安卓 8.0 以上）。以哪个版本为准看你的需求——从网盘装的是固定版本，从商店装的是当时的最新版，两者账号数据通用（同一个手机号登录）。

## 二、获取安装包

上面的夸克网盘链接就是 JayMe 安装文件资源的入口，转存到自己网盘后下载得到 APK 文件。下载完成后建议先校验一下文件完整性，再开始安装：

```powershell
certutil -hashfile "JayMe app_v5.0.3.apk" MD5
```

比对结果应为 `6CD3E697304066D064E0AED4B0AB2013`（不区分大小写）。如果对不上，说明下载过程出了问题，重新下载一遍再装，不要硬装。

## 三、安装步骤

1. 把 APK 传到手机存储里（网盘 App 直接下载、数据线、局域网传文件都行）。
2. 在手机文件管理器里点开这个 APK。系统会提示「是否允许从此来源安装应用」，选择允许——这是安卓对非商店安装的标准询问，只针对你当前使用的那个文件管理器。
3. 等安装进度走完，点「打开」或回到桌面点图标。
4. 如果安装到一半报「解析包错误」，多数是安装包没下完整，回到上一步重新下载并校验 MD5。

## 四、系统要求与空间

- 系统版本：安装包信息标注为「需要支持安卓系统 5.2 以上」（以实际安装时手机给出的提示为准）。近几年的安卓手机基本都能满足。
- 存储空间：安装包本身 114.14M，加上解压后的运行数据，建议预留至少 1GB 空间。空间不足时安装会直接失败或装完闪退。

## 五、安装后第一次启动会要哪些权限

按应用商店登记的权限清单，JayMe 会逐个向你申请这些权限，每个都有对应的功能：

| 权限 | 用在哪 |
| --- | --- |
| 位置 | 发动态时可选带地理位置、同城互动 |
| 存储 | 保存图片、聊天发文件、缓存资源 |
| 相机 | 拍照、拍视频、扫一扫 |
| 麦克风 | 语音消息、语音/视频聊天 |
| 通知 | 资讯推送、消息提醒 |

处理原则：按需授予。只想看资讯的话，位置、相机、麦克风都可以先拒绝，不影响主流程；用到对应功能时系统会再次请求。反过来，**存储权限被永久拒绝**可能导致发图、下载资源等功能异常，部分机型上甚至会引发闪退——遇到「功能用不了」先去系统设置里检查权限是不是被拒了。

## 六、装好之后：首次启动

第一次打开 JayMe 会要求登录，流程是手机号 + 验证码，没有账号就当场注册一个。登录进去之后先做两件事：

1. 在「我」或设置页把昵称、头像补齐——社区功能的入口大多与个人资料相关联。
2. 想了解这个应用里都有什么，直接看 [核心功能与使用入门.md](核心功能与使用入门.md)；打算参与演唱会门票活动的，先读 [会员体系与J币获取.md](会员体系与J币获取.md) 再决定要不要付费。

iOS 用户不走上面的 APK 流程：在 App Store 搜「JayMe」即可找到官方版本，开发者显示为 Just Me Co., Limited，与安卓版是同一个服务的两端。

## 七、装不上或装完打不开

按现象对号入座：

| 现象 | 先做什么 |
| --- | --- |
| 提示「解析包错误」 | 重新下载安装包并校验 MD5（见第二节） |
| 提示存储空间不足 | 清出 1GB 以上空间再装 |
| 点开就闪退 | 重启手机后再试；仍闪退看 [常见问题与客服渠道.md](常见问题与客服渠道.md) |
| 系统提示版本过低 | 手机的安卓版本低于安装包要求，需要先升级系统 |
