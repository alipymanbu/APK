## 一、它没有 Windows 原生版，iOS 版本官方说全是假的

HappyMod 的安装包是安卓 APK，没有 Windows 原生客户端；电脑上要跑，只能先装一个安卓模拟器，再把 APK 装进模拟器里。网上标着「Windows 版」「PC 版」的独立安装包，本质上多数也是「模拟器 + APK」的打包。

官方站点 [happymod.com](https://www.happymod.com/) 首页顶部用三行字写明：**HappyMod 只支持安卓系统，所有 iOS 版本都是假的，提醒用户不要下载以免受骗**。所以 iPhone / iPad 用户不用再找了，网上流传的「iPhone 版教程」与官方口径直接冲突，别照着装。

## 二、电脑上安装的完整步骤

1. **装一个安卓模拟器**：常见可选是 BlueStacks、夜神（NoxPlayer）、LDPlayer 等，Windows 与 Mac 都有对应版本。装好后先启动一次，完成初始化。
2. **确认模拟器环境**：模拟器自身的安卓版本建议不低于 7（越新越接近手机端表现），并给它分配 4G 以上内存、留足磁盘空间。
3. **拿 APK**：从 [happymod 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d82f24cb75ad) 下载到电脑，核对体积是否为 17.39M（详见 [下载与安装教程.md](下载与安装教程.md) 的核对表）。
4. **拖进去安装**：把 APK 文件直接拖进模拟器窗口，等它装完；或在模拟器里用自带浏览器打开该文件安装。
5. **首次启动**：在模拟器桌面点图标，绿色启动页走完即进入首页，界面与手机端一致。

## 三、电脑上用起来与手机的差异

| 项目 | 表现 |
| --- | --- |
| 界面与操作 | 与手机完全一致，只是用鼠标点击 |
| 点触类操作 | 模拟器自带按键映射，可把点击位置绑到键盘 |
| 下载位置 | 包下在模拟器的虚拟存储里，不占你 Windows 的下载目录 |
| 安装条目 | 下载的游戏/应用装进模拟器，手机上不会出现 |
| 性能 | 取决于电脑配置；模拟器本身比手机端更吃内存 |

一个实用点：电脑上下载好的 APK 也能传回手机装 —— 模拟器的共享文件夹功能可以把文件导出到 Windows 目录，再拷到手机，按手机端步骤装即可。

## 四、电脑上装不上、跑不动时

- **拖入 APK 没反应**：改用模拟器内部的「安装 APK」按钮选择文件，或换个模拟器。
- **提示 CPU 不支持虚拟化**：进 BIOS 打开 VT（Intel VT-x / AMD-V），否则模拟器会非常卡甚至起不来。
- **卡顿、闪退**：给模拟器加内存与 CPU 核数，关闭后台占用高的程序；模拟器安卓版本过旧时考虑升级模拟器。
- **应用装好但条目下载失败**：先查模拟器网络（能否打开网页），再看是不是下载通道被拦 —— 手机端同款问题的排查步骤在 [安装失败怎么办.md](安装失败怎么办.md) 第五节，同样适用。
