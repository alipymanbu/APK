## 一、先认三个底部标签

打开后屏幕最下方固定三个标签，所有操作都从这里进出：

| 标签 | 是什么 |
| --- | --- |
| 首页 | 主入口：搜索框、频道、快捷入口、热点条目都在这里 |
| 100%好用 | 已被用户验证「可用」的条目集合，中间那个绿色圆形图标就是它 |
| 小游戏 | 点开即玩的网页小游戏，**不需要下载安装** |

「小游戏」这一栏值得单说：里面的游戏直接在线玩，不占你手机空间，也没广告位干扰；想玩正式版、要存档的那种，还是回到首页搜。

## 二、首页顶部：搜索框与四个频道

- **搜索框**占满顶部一行，占位文字是 `HappyMod`，直接输入应用或游戏名回车即可 —— 找某个具体条目时这是最快的路径。
- 搜索框下方四个频道：**精选 / 游戏 / 应用 / Telegram**。「精选」是推荐位，「游戏」和「应用」按类型分开浏览，「Telegram」是官方频道入口。
- 顶部右上角两个图标：**下载图标**（进下载管理，看正在下和已下完的包）、**头像图标**（进「我」页面）。

## 三、快捷入口与「过去24小时热点」

频道下方一排 8 个图标，是预设筛选：

| 入口 | 作用 |
| --- | --- |
| Offline | 可离线玩的条目 |
| Single player | 单机条目 |
| Paid | 按「付费」标签筛出的条目 |
| Region locked | 受地区限制的条目 |
| Toca / Shooter game | 按题材聚合的两个入口 |
| Reviews | 看用户评测 |
| Categories | 全部分类总目录 |

再往下是**过去24小时热点**，横排展示当前被下得最多的条目，右侧「更多」可展开完整榜单。这一栏很适合「不知道玩什么，先看看别人在下什么」的场景。

## 四、条目页怎么看

点进任何一个条目，重点看三处：

1. **版本号与体积** —— 决定是不是你要的那一版。同一个游戏常有多个版本并存，历史版本也在这里选。
2. **改动说明标签** —— 条目名下方一排灰底标签，写清这个版本改了什么、适用于哪个系统版本（例如「此版本适用于 2.3 及…」这类适用范围提示）。有适用范围的先对一下自己的系统。
3. **验证标记** —— 条目带「100% 工作 / 已验证」这类标记，表示有用户实际跑通过；没标记的版本风险自担，装之前多看两眼评论区。

确认没问题就点下载，包会进右上角的下载管理；下完按 [下载与安装教程.md](下载与安装教程.md) 第四节的步骤安装（侧载需要先放行「未知来源」）。装上后提示「解析错误」或装不进去，转 [安装失败怎么办.md](安装失败怎么办.md)。

## 五、「我」页面：账号、设置与上传

点右上角头像进入「我」，默认是游客身份（显示 `Guest-` 加一串随机字符），右侧有绿色「登录」按钮。下面的菜单按用途分三类：

- **信息类**：官方网站（指向 [happymod.com](https://www.happymod.com/)）、在 Telegram 上关注我们、消息；
- **个人数据类**：愿望清单、我的评测、我的评论、「未审核」（你自己提交、还没通过验证的内容）；
- **操作类**：设置、管理、上传、请求 —— **上传**是把你自己做的 Mod 提交到平台的入口，**请求**是向平台提交「我想要某个条目」的诉求。

不登录也能搜、能下、能装；登录的作用是把愿望清单、评测和评论在多台设备间同步。想改语言、下载路径、通知开关，进「设置」。

## 六、日常最省事的三条路径

- **明确知道要什么**：顶部搜索框 → 条目页对版本 → 下载。
- **想挑一个能玩的**：底部「100%好用」→ 挑带验证标记的。
- **只想随手玩两局**：底部「小游戏」→ 点开即玩，不走安装流程。

想换台设备（电脑）接着用，按 [电脑版怎么装.md](电脑版怎么装.md) 走模拟器方案。
