# HappyMod 安装失败怎么办

> 把装不上、下不动、打开闪退这几类问题按现象分开，每种给可执行的排查步骤与判断依据。

## 一、先确认你手里这个包是对的

一半的「装不上」其实是拿到了不一样的文件。装之前花一分钟核对：

| 字段 | 本包应为 |
| --- | --- |
| 包名 | `com.happymod.apk` |
| 版本 | 3.1.5 |
| 大小 | 17.39M |
| MD5 | `7061C4586FF6AAB7352CC073AFC34734` |

包名不一致、体积差得离谱，就是下错了文件 —— 先回 [下载与安装教程.md](下载与安装教程.md) 重新拿包，别在错的文件上反复试。核对值以那一篇里的表格为准。

## 二、点开提示「未安装」或「解析包时出现问题」

按出现频率排序，逐条试：

1. **下载没走完** —— 文件不完整必然解析失败。看下载管理里的体积是否与 17.39M 一致，不一致就删掉重下。
2. **系统版本过低** —— 本包要求安卓 5.2 以上，系统低于它时安装程序会直接拒绝。查看路径：设置 → 关于手机 → Android 版本。
3. **安装包与已有版本冲突** —— 手机里残留的旧版本签名不同会装不进去。先卸载旧的（设置 → 应用 → 找到 HappyMod → 卸载），重启手机后再装一次。
4. **存储空间不足** —— 系统空间紧张时部分机型只提示「未安装」。清出 100M 以上再试。

## 三、安装按钮置灰，或找不到「未知来源」开关

这是安卓对侧载安装的默认限制，需要你手动放行一次：

- **Android 8.0 及以上**：点开 APK 时会直接弹出「安装未知应用」页，给发起安装的那个应用（浏览器或文件管理器）打开「允许来自此应用」，返回即可。
- **Android 7.0 及以下**：设置 → 安全 → 打开「未知来源」。
- **各厂商额外拦截**：MIUI/HyperOS 的「纯净模式」、ColorOS 的「安装监控」、华为的「外部来源应用检查」会再弹一次确认页，选「仍要安装 / 继续安装」。

按钮始终置灰、没有任何弹窗时，多半是第 2 条的系统版本问题，或是设备管理策略（公司管控机、学生模式）禁止了侧载 —— 后者在设置里搜「设备管理器」看有没有启用的管控项。

## 四、被杀毒软件或 Play Protect 拦下

侧载安装的商店类应用常被安全组件标记为「风险应用」，这是按来源判定的，不等于文件有问题。处理顺序：

1. 先完成第一步的包名、大小、MD5 核对，确认文件是本包；
2. 安装时弹出 Google Play Protect 扫描提示，选「仍要安装」；
3. 第三方杀毒 App 拦截时，在它的隔离区里找到该文件选择信任/恢复，再装一次；
4. 装完如果实时防护反复删除它，把安装目录加入白名单 —— 装不装由你自己决定，别在没核对来源的情况下盲目放行。

## 五、下载卡住、进度不动或一直失败

- **网络问题**：切换 Wi-Fi 与移动数据各试一次；公司/校园网常对大文件限速。
- **下载管理里任务堆积**：删掉失败的旧任务重新点下载，残留任务会占住文件名。
- **存储位置**：下载路径指向 SD 卡或已满的分区时会静默失败，改到内部存储。
- **电脑上下载再传过去**：手机网络怎么都不行时，用电脑下好 APK 用数据线拷进手机，再用文件管理器安装。

## 六、装上了但打不开、闪退或一直停在启动页

1. **停在绿色启动页**：那是初始化进度，一般十几秒内走完；超过一分钟无进度，杀掉进程重开。
2. **清缓存重开**：设置 → 应用 → HappyMod → 存储 → 清除缓存（清除数据会把登录态与下载记录一起清掉，可后做）。
3. **系统版本太老**：低版本安卓能装上但跑不动新界面，回第二条核对版本要求。
4. **与现有 Mod 冲突**：装了别的同类商店、或开过 Xposed 类框架的，先退出再试 —— 这类环境改动会干扰应用自检。
5. 还是闪退的话，卸载后按 [下载与安装教程.md](下载与安装教程.md) 重装一遍；电脑上出现同类问题，见 [电脑版怎么装.md](电脑版怎么装.md) 的模拟器侧说明。
