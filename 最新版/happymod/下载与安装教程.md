## 一、HappyMod 是什么

HappyMod 是一个安卓端的应用与游戏分发工具：它本身不是单个游戏，而是一个商店形态的应用，里面收录的条目分两类 —— 官方原版，以及社区上传、并经用户验证标注的修改版（Mod）。每个条目下会写清版本号、体积和改动说明，你按条目页的说明下载安装包，再装到手机上。

典型用法有三种：找某个游戏的特定版本（含历史版本）、看某个条目有哪几个改动版本可选、以及在「小游戏」标签里直接点开即玩的小游戏（这类不需要下载）。装好之后接着看 [新手使用指南.md](新手使用指南.md) 认界面。

## 二、装之前先看系统要求

| 项目 | 要求 |
| --- | --- |
| 系统下限（本安装包登记） | 安卓 5.2 以上 |
| 系统下限（第三方下载页的标注） | 各站写法不一，有写 5.0、也有写 7.0 或 11 |
| 安装包体积 | 17.39M |
| 是否需要 root | 不需要 |
| 是否上架 Google Play | 否，只能侧载安装 |

两处系统下限不一致时，以你的设备实际能否装成功为准：低于包内声明的版本，系统会在安装时直接拦下来。体积这条建议留出至少 100M 空闲空间，条目下载还要额外占地方。

## 四、安装步骤

1. 把 APK 从网盘下载到手机存储，用系统自带的「文件管理」找到它。
2. 点击 APK，系统会弹「禁止安装来自此来源的应用」—— 这是安卓对侧载安装的默认限制，不是病毒报警。
3. 按提示跳到设置，给你的浏览器或文件管理器打开「允许来自此来源的应用」，返回继续安装。
4. 部分厂商系统（MIUI、ColorOS、HarmonyOS 等）会再弹一次「纯净模式」或安全确认，选继续安装即可。
5. 装完打开，先看到绿色启动页（写着 HappyMod 与初始化进度），进度走完进入首页。

如果安装按钮始终置灰、或点开 APK 直接报错，按 [安装失败怎么办.md](安装失败怎么办.md) 逐条排查。

## 五、装完第一屏长什么样

启动页加载完会直接进首页：顶部是搜索框，下面是「精选 / 游戏 / 应用 / Telegram」四个频道，底部三个标签是「首页 / 100%好用 / 小游戏」。首次打开时它会以游客身份运行（「我」页面显示 `Guest-` 开头的随机名），不需要注册就能搜和下载。界面各处的用途在 [新手使用指南.md](新手使用指南.md) 里逐块讲；想在电脑上跑，见 [电脑版怎么装.md](电脑版怎么装.md)。
