# Enpass 从其他密码管理器迁移导入

> 换到 Enpass 不用逐条手抄。本篇讲把浏览器和其他密码管理器里的存量密码导入进来的完整路径，以及 passkey 这类搬不过去的东西怎么处理。

## 一、导入入口在桌面版

官方文档里的导入流程写在**电脑版 Enpass** 上（File 菜单 → Import），手机端没有对应入口（以你手上版本的菜单为准）。所以迁移的标准路径是：

1. 在电脑上装好 Enpass 桌面版（官网 [www.enpass.io/downloads](https://www.enpass.io/downloads) 有 Windows / macOS / Linux 版）。
2. 在桌面版里完成导入。
3. 手机端通过云盘同步或恢复备份拿到这批数据（搬法见[同步方式与数据存储.md](同步方式与数据存储.md)与[数据备份与恢复.md](数据备份与恢复.md)）。

只有手机没有电脑的话，导出 CSV 再逐条手输是唯一办法，这也是为什么建议迁移这一步尽量在电脑上做。

## 二、从浏览器导入（以 Chrome 为例）

**第一步，从 Chrome 导出：**

1. Chrome 设置 → 自动填充 → 密码管理器。
2. 已保存密码旁边的菜单里选「导出密码」，系统会要求验证你的电脑密码。
3. 存成一个**未加密的 .csv** 文件。

**第二步，导入 Enpass 桌面版：**

1. File 菜单 → Import → Browsers → Chrome Browser。
2. 点文件夹图标，选中刚导出的 .csv，继续。
3. 有多个保险库时选导入目标（默认主保险库），继续后完成。

导入完成后的分类按 CSV 里可用的数据自动判断，分不进去的条目会集中在侧边栏「分类 → 未分类」里，值得挨个看一眼补上归属。

其他浏览器（Edge、Firefox、Safari 等）和其他密码管理器（1Password、LastPass、Bitwarden、KeePass 等）的来源列表在 File → Import 菜单里都能看到，流程同样是「对端导出 → 这里选对应来源 → 指定文件」，以应用内当时列出的来源为准。

## 三、搬不过去的东西

- **passkey（通行密钥）**：按设计不能在密码管理器之间导入导出，换家后需要在各网站重新注册。迁移前可以先把存在旧管理器里的 passkey 对应网站记下来，逐个处理。
- **附件**：备份文件与附件不在 CSV 导出范围内，需要时在旧管理器里手动下载、再到 Enpass 里作为附件补上。

## 四、导入后的两件收尾事

1. **立刻删掉未加密的导出文件**，并清空回收站——CSV 是明文密码表，留在外面等于裸奔。
2. **核对条目数量**：拿导出来源里的条目数对一下导入后的数量，确认没有漏项；顺手把「未分类」清空。

## 五、离开 Enpass 时怎么办

导出同样在桌面版：File 菜单里有 Export，可导出为 CSV 或加密备份文件。导出的 CSV 同样是明文，用完即删。反向迁移的操作思路与本篇一致，只是方向相反。
