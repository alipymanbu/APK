## 一、先分清同步与备份

云盘同步解决的是「多设备一致」，不是「数据安全」——你在 A 设备上误删一条，删除动作会同步到所有设备。真正兜底的是**备份文件**：一个独立于应用、独立于同步的加密文件，放哪、存几份都由你定。两个都要有。

## 二、怎么备份

**安卓手动备份**（换机前、大版本升级前、隔一段时间）：

1. 设置 → 保险库，选中要备份的保险库。
2. 点该保险库右侧的三点菜单，选「备份」。
3. 备份文件存到手机存储后，建议转存一份到电脑或另一处存储，别和手机共存亡。

**桌面端**：

- 手动：File → Backup → Create Backup，选位置保存。
- 自动：设置 → Backup，勾选 Backup Automatically，每天自动备份一次，保留最近 60 份，位置可改；Previous Backups 里能看到历史列表。

备份文件是加密的，恢复时需要原主密码（主密码的分量见[主密码与保险库设置.md](主密码与保险库设置.md)）。

## 三、什么时候恢复、怎么恢复

| 场景 | 恢复方式 |
| --- | --- |
| 应用还在，想退回某次备份 | 设置 → 备份 → Previous Backups，选中一份点恢复 |
| 换新手机 / 重装系统 | 新装应用走到欢迎屏 → 恢复现有数据 → 备份文件 → 选中文件 → 输主密码 |
| 从云盘拉的保险库 | 不走备份文件，走「添加现有保险库」（见[同步方式与数据存储.md](同步方式与数据存储.md)） |
| 想用备份覆盖现有应用里的数据 | 见下一节的坑 |

## 四、v6 的恢复入口坑（官方团队口径）

Enpass 6 **没有**随时可用的「从备份恢复」按钮——恢复入口只在两种时刻出现：**全新安装后的欢迎屏**，和**新建保险库时**。

所以当你想用备份文件覆盖现有数据（比如误删了一批条目）时，官方给的路径是：

1. 先把现有数据备份一份（防止你要恢复的那份其实更旧）。
2. 设置 → 高级 → Erase Everything（清空本地全部数据）。
3. 应用回到欢迎屏，选「恢复现有数据」→ 备份文件 → 定位文件 → 输入原主密码。

Erase Everything 前确认云盘里的保险库还在（本地清掉不等于云端清掉），否则两头落空。

## 五、主密码丢了就是另一回事

备份文件解不开、云盘保险库也打不开——官方明确没有找回通道，Enpass 服务器上不存你的数据。这时唯一能做的是清空重来（Erase Everything → 当新用户重建），旧数据认了。预防手段只有两条：主密码提示 + 定期备份，都在前文。

## 六、推荐的备份节奏

- 日常：开着云盘同步，多设备互为副本。
- 每月或大改动后：手动出一份备份文件，存到与手机和云盘都不同的位置（比如电脑硬盘 + U 盘各一份）。
- 装有密钥文件的话：密钥文件单独存放，与备份文件**不在同一处**，两样同时丢失才致命，分开放就只丢一样。
