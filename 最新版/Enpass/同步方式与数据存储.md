# Enpass 同步方式与数据存储

> Enpass 不把你的数据放在它自己的服务器上。本篇讲三条存储路线（完全本地、个人云盘同步、Wi-Fi 同步）怎么选、怎么配，以及换手机怎么搬数据。

## 一、三条路线对比

Enpass 与多数密码管理器最大的差别在数据放哪：它没有中央保险库服务器，加密后的保险库文件要么只存在你设备上，要么放进你自己的云盘账号。三条路线的实际差别：

| 路线 | 数据放哪 | 需要什么 | 适合 |
| --- | --- | --- | --- |
| 完全本地 | 只在本机 | 无 | 只用一台设备、完全不想联网 |
| 个人云盘同步 | 你自己的云盘账号 | 任一支持的云盘 | 多设备、要换机迁移 |
| Wi-Fi 同步 | 局域网里一台当服务器的电脑 | 一台常开电脑 + 同一 Wi-Fi | 不想经过任何第三方云 |

支持的个人云盘包括 iCloud、Google Drive、OneDrive、Box、Dropbox、Nextcloud 与 WebDAV（以应用内当时显示的列表为准）。国内用户选 WebDAV 接自建网盘或 Nextcloud 也能走通。

同步过去的文件是加密后的保险库，云盘服务商拿到的只是密文，没有主密码解不开。

## 二、配置云盘同步

1. 打开 设置 → 保险库，选中要同步的保险库。
2. 选择同步方式，从列表里挑你的云盘。
3. 跳转到云盘官方登录页授权——授权走的是云盘自己的 OAuth 流程，Enpass 侧拿不到你的云盘密码。
4. 授权完成回到 Enpass，等第一次同步跑完。

另一台设备要拿到同一份数据：装好 Enpass 后选「添加现有保险库」，登录同一个云盘账号，选中那个保险库文件即可。

## 三、配置 Wi-Fi 同步

Wi-Fi 同步完全不经互联网，但架构上**必须有一台电脑当服务器**：

1. 电脑端 Enpass：设置 → Wi-Fi 同步 → 启动服务，并选中要通过 Wi-Fi 同步的保险库。
2. 手机端：设置 → 保险库 → 添加 → Wi-Fi 同步，电脑不在线时手机不会同步，这是最容易踩的坑。
3. 手机与电脑必须连**同一个局域网**。
4. 连接方式两种：扫电脑端显示的二维码，或在电脑端拿 Access Password 手动配对。
5. 服务器电脑关机后，各设备在本地照常用，等服务器再上线时补同步。

## 四、换手机怎么搬

两条路任选：

- **走云盘**：新手机装好 Enpass，添加现有保险库，登录原云盘账号拉取。
- **走备份文件**：旧手机在 设置 → 保险库 → 选中保险库 → 备份，把备份文件传到新手机，首次启动选「恢复」指向它。

两条路都需要**同一个主密码**。搬家前在旧手机上先手动同步或备份一次，确保最新改动都在。

## 五、常见坑

- **冲突副本**：两台设备离线时各改了同一条目，同步后会出现冲突副本，内容都在，手动比对后留一条删一条。
- **两套空保险库**：新设备上先创建了一个空保险库、又去云盘添加旧保险库，结果出现两个库。正确顺序是先「添加现有」，不要先「新建」。
- **免费版额度**：只有 1 个保险库的额度，多库需求见[免费版与付费版区别.md](免费版与付费版区别.md)。
- **主密码是唯一钥匙**：同步文件谁都能拷走，但没有主密码解不开；反过来你也一样，主密码的取舍见[主密码与保险库设置.md](主密码与保险库设置.md)。
- **同步不是备份**：误删、误改会原样同步到所有设备；云盘服务商一般保留文件的历史版本，能不能翻出来看具体服务商。真正兜底要靠独立的备份文件，做法见[数据备份与恢复.md](数据备份与恢复.md)。
