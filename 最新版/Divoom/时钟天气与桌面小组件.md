## 一、设一个表盘

1. 设备连上后，在应用里进「表盘 / 时钟」分类；
2. 图库里有大量用户上传的表盘，按风格筛选（像素风、极简、复古翻页等）；
3. 点选即推送到设备，时间会与手机同步。

表盘支持收藏，换季、换心情时不用重新翻找。表盘本质也是像素图案，部分表盘可以在应用里改配色后再用；想换成自己画的，方法在[像素创作与图案编辑.md](像素创作与图案编辑.md)。

## 二、天气显示

天气属于联网功能，只对带 Wi-Fi 的型号（Pixoo-64、Times Gate、Times Frame 等）有意义，纯蓝牙音箱型设备拿不到天气数据：

1. 先确认设备已完成 Wi-Fi 配置（在[连接设备与配对方法.md](连接设备与配对方法.md)里）；
2. 给应用定位权限，或在应用里手动设城市；
3. 在小组件列表里把天气组件加到设备屏幕上。

天气刷新需要设备保持联网，路由器重启后设备掉线，屏幕上的天气会停在上次数据 —— 这不是组件坏了，重连 Wi-Fi 即恢复。天气、日历一直刷不出来且重连也没用，按[常见问题与故障排除.md](常见问题与故障排除.md)查连接。

## 三、日历、提醒与小工具

应用的小组件区还提供这几类，按需往屏幕上加：

- **日历 / 倒计时**：盯截止日期、纪念日；
- **提醒闹钟**：应用内设的闹钟走设备喇叭，音色与手机闹钟不同，适合当独立闹铃用；
- **小游戏与工具类**：如计分器、白噪声等，型号不同清单不同。

加组件的通用路径：选中设备 → 组件 / 小工具页面 → 点选需要的 → 调整顺序。多个组件可以在屏幕上轮播，也可以固定只显示某一个。

一个容易忽略的前提：**通知镜像这类实时组件要求应用常驻后台**。官方支持口径是应用必须保持与设备的连接，镜像才能持续工作 —— 手机省电策略把应用杀掉后，屏幕上的通知会停在最后一条。处理办法是在系统设置里允许 Divoom 后台运行、取消对它的电池优化（入口位置随手机品牌不同，一般藏在「应用 → Divoom → 电池」里）；同时确认应用内该提醒功能的授权是打开的。

## 四、亮度与休眠

这两个设置决定设备晚上烦不烦人：

| 设置 | 建议场景 |
| --- | --- |
| 亮度 | 桌面白天用高档、卧室一律最低档 |
| 定时休眠 | 夜里固定时段自动黑屏或只留时钟，早上再亮 |

路径都在应用内该设备的设置页。纯蓝牙音箱型的亮度等级较少，屏类设备（Pixoo-64、Times Gate）可调范围更大。
