# Divoom 常见问题与故障排除

> App 搜不到设备、蓝牙配不上、Wi-Fi 配置失败、连上就掉线 —— 这几类是最常遇到的坑。本篇按症状给处理顺序，绝大多数问题两三分钟内能解决。

## 一、症状速查表

| 症状 | 多见机型 | 最可能原因 | 处理方向 |
| --- | --- | --- | --- |
| App 里搜不到设备 | 全部 | 没进配对状态 / 权限没给 | 见第二节 |
| 蓝牙配对失败 | Ditoo-Pro、MiniToo | 之前连过别的手机 | 见第三节 |
| Wi-Fi 配置总失败 | Pixoo-64、Times Gate | 手机在 5GHz 频段 | 见第四节 |
| 连接反复掉线 | Pixoo-64 | 信号弱 / 信道干扰 | 见第五节 |
| 配网卡在同一步（如 40%） | Pixoo-64 | 应用旧 / 密码 / 供电 | 见第七节 |
| 死机、重启循环、屏幕异常 | Pixoo-64 等屏类 | 供电不足 | 见第七节 |
| 小组件渲染错乱、功能缺失 | Wi-Fi 屏 | 固件旧 | 见第六节 |

## 二、App 里搜不到设备

按顺序做，多数在第 2 步就解决：

1. **让设备进配对状态**：长按电源键约 5 秒，直到屏幕闪烁。设备不在配对状态时，App 怎么搜都不会出现。
2. **补权限**：iPhone 检查「设置 → 隐私与安全性 → 蓝牙 / 本地网络」里 Divoom 是否允许；安卓检查「应用 → Divoom → 权限」里的「附近设备」。
3. **重启两端**：手机蓝牙关开一次、应用杀掉重开、设备断电重启，再搜。
4. **确认设备没被占用**：旁边另一台手机正连着它时，你这台搜不到。

## 三、蓝牙配对失败（Ditoo-Pro、MiniToo）

之前连过别的手机（或系统蓝牙里留着旧记录）是最常见原因：

1. 打开手机系统蓝牙设置，找到 Divoom / Ditoo-Pro / MiniToo 条目，选「忽略此设备」；
2. 设备长按电源键 5 秒重新进配对状态；
3. 回到 Divoom 应用内重新走配对流程，配好后系统蓝牙里的音频连接会跟着恢复。

再次强调：只连系统蓝牙只能听歌，屏幕功能必须从应用内配对（见[连接设备与配对方法.md](连接设备与配对方法.md)）。

## 四、Wi-Fi 配置失败（Pixoo-64、Times Gate 等）

- **检查频段**：老款 Pixoo-64、Times Gate、Times Frame 只认 2.4GHz Wi-Fi。家用路由器常把 2.4G 与 5G 合在一个名字下广播，手机显示连着的其实是 5G —— 到路由器设置里把两个频段拆成两个名字，或单开一个 2.4G 的名字再配。新款 Pixoo-64 II 已支持双频，不受此限（以官方产品页为准）。
- **检查网络环境**：公司网、宿舍网、带设备隔离的访客网络常拦这类设备的握手。密码没错也配不上时，先用手机热点试一次，能配上就说明是网络环境问题。
- **靠近路由器**：首次握手对信号要求高，配好之后设备可以放回远处。

## 五、连上就掉线

1. 看设备与路由器之间隔了几堵墙，先用近距离验证是否信号问题；
2. 路由器信道拥挤时（周围 Wi-Fi 多）换个信道；
3. 检查供电，插线板接触不良也会表现成「频繁掉线」。

## 六、固件与重置

设备功能异常、小组件渲染错乱时，先查固件更新：应用里选中设备 → 设置齿轮 → 设备信息 / 固件相关条目。升级过程中保持设备在线、别退出应用。重置（针孔硬件重置与应用内恢复出厂）的具体操作和注意点，单独写在[固件更新与设备重置.md](固件更新与设备重置.md)里。

## 七、供电不足与配网卡住（屏幕类）

Pixoo-64 这类插电屏幕有一套自己的「玄学故障」，官方支持口径把其中九成以上归因于同一件事：**供电不足**。死机、开机后反复重启循环、配网总卡在同一个进度（常见是 40%）、怎么都连不上网 —— 先怀疑电源，再怀疑别的。

**供电要达标：**

- Pixoo-64 需要 5V2A 起步的充电头，开了高亮模式则要 5V3A；
- 电脑 USB 口、电视上的 USB 口、老式苹果充电头多数达不到 5V2A；
- 多孔排插同时给几台设备供电时会分流，单孔输出也可能不达标；
- 换一个明确标着 5V2A 以上的充电头，是最便宜的排查动作。

**配网卡在 40% 的排查清单**（按官方支持页给的顺序）：

1. 确认应用已是最新版，必要时重装再试；
2. 切到蓝牙模式，看搜索列表里能不能找到设备；
3. 检查 Wi-Fi 密码 —— 大小写是区分的；
4. 别用需要网页登录认证的公共 Wi-Fi（机场、商场、校园网都属于这类）；
5. 用两部手机做热点测试：一部开热点，另一部装应用控制设备连这个热点。能配上就说明问题出在原来的路由器；
6. 换一个 Wi-Fi 源再试，部分路由器防火墙会拦新设备接入；
7. 回头确认供电达标（见上）；
8. 长按设备开关约 15 秒，重置网络模块后再走一遍配网。

**开机就死机、反复重启**：先换 5V2A 以上的充电头；仍不行，按官方建议换一张 TF 卡或把原卡格式化再试。这一类问题做固件升级和恢复出厂都没用，电源不达标，怎么重置都会复发。

装应用这步出问题的（商店装不上、网盘包无法安装），回[下载与安装教程.md](下载与安装教程.md)对一遍版本与权限；天气、日历组件刷不出来的，多数是 Wi-Fi 掉了，按第四节处理后回[时钟天气与桌面小组件.md](时钟天气与桌面小组件.md)重加组件。
