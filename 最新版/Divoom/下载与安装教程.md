## 一、安装前先对一遍基本信息

Divoom 应用只面向手机，官方目前没有 Windows 或 macOS 桌面版（截至 2026 年 7 月官方说明，以后是否推出以官方页面为准）。安卓与 iOS 都用同一个名字「Divoom」。

| 项目 | 内容 |
| --- | --- |
| 应用名 | Divoom（安卓商店显示名 Divoom: pixel art editor） |
| 安卓包名 | `com.divoom.Divoom` |
| 本篇收录的版本 | 3.7.04 |
| 安装包大小 | 51.77 MB |
| 安装包 MD5 | `A5915232D5E9301FF00D608C4CEC3C21` |
| 系统要求 | 安卓 5.2 以上（按安装包自带标注，具体以官方商店页面为准） |

版本号会随官方更新变化。你从网盘拿到的是上面标注的这一版，商店里的可能更新；日常使用建议优先用商店版，需要固定版本时再用网盘里的安装包。

## 二、两条获取路径

### 路径一：官方应用商店（推荐日常使用）

- 安卓：Google Play 商店搜「Divoom」，官方页面为 [https://play.google.com/store/apps/details?id=com.divoom.Divoom](https://play.google.com/store/apps/details?id=com.divoom.Divoom)
- iPhone：App Store 搜「Divoom」，官方页面为 [https://apps.apple.com/us/app/divoom-pixel-art-community/id1237452417](https://apps.apple.com/us/app/divoom-pixel-art-community/id1237452417)
- 官方下载页：[http://download.divoom.com/](http://download.divoom.com/)

在商店里安装前可以核对发布者、权限列表和更新记录。搜索结果里经常混着名字、图标相近的山寨应用和第三方 APK 站，不要从那里装。

### 路径二：从夸克网盘取安装包（安卓直装）

如果你要在不方便登录 Google Play 的手机上装，或者想要本文标注的这个版本，可以走 [Divoom 安装文件资源（夸克网盘）](https://pan.quark.cn/s/de8bc2ec0a15)：

1. 在网盘客户端里把安装包转存到自己的网盘后下载到手机；
2. 点开 APK，系统首次会提示「允许安装未知来源应用」，按提示允许这一次；
3. 装完打开，应用图标是 Divoom。

安卓 8 以上按「来源」授权，不是给全局开关；装完可以在系统设置里把该来源的授权收回。iOS 没有这种直装方式，只能走 App Store。

## 三、首次打开要给的权限

第一次启动会依次弹权限申请，逐个说明：

| 权限 | 用途 | 是否必须 |
| --- | --- | --- |
| 蓝牙 / 附近设备 | 搜索并连接你的像素设备 | 必须 |
| 本地存储 | 保存你画的图案、上传的照片 | 必须 |
| 定位（部分机型） | 天气小组件取当地天气 | 可选，不用天气就不给 |
| 通知读取 | 把手机通知镜像到像素屏上显示 | 可选 |

权限给错了也不用卸载重装，去系统设置的「应用 → Divoom → 权限」里逐项改就行。装好之后下一步是连上你的设备，步骤见[连接设备与配对方法.md](连接设备与配对方法.md)；如果商店版装完闪退、搜不到设备，先看[常见问题与故障排除.md](常见问题与故障排除.md)。
