# Divoom 像素创作与图案编辑

> Divoom 应用里最常被用的部分：从社区图库挑现成的像素图案、自己动手画、做滚动文字和动画。本篇按「找现成的 → 改一改 → 从零画」的顺序讲操作。

## 一、从社区图库挑现成的

应用内置一个由用户上传的像素图案库，按主题分类（节日、游戏、动物、天气等）。操作路径：

1. 设备连上后，进入对应设备的图案页面；
2. 在图库里按分类浏览或搜索关键词；
3. 看中哪个点一下，图案会直接推送到设备屏幕上。

图库内容是社区持续上传的，所以你看到的分类和热门图案会随时间变化。找到的图案大多可以「一键收藏」，下次不用再翻。

## 二、在现成图案上改

比从零画快得多的一条路：选中图库里的图案后进编辑，改几个像素、换配色再保存。适合想有点个人痕迹但不想从头做的场景。编辑器的具体按钮位置随设备型号和版本略有差异，常见的几个入口：

| 入口 | 干什么 |
| --- | --- |
| Design | 单帧像素图绘制 |
| Animation | 多帧动画，逐帧画后连播 |
| Text Editor | 滚动文字条，选字体颜色与速度 |
| Pixel Coloring | 给像素画上色、改色 |

## 三、从零画自己的图案

1. 进入 Design 或 Pixel Coloring，画布尺寸自动匹配你的设备屏幕（例如 16x16、32x32、64x64）；
2. 点格子逐个上色，或用填充工具整块刷；
3. 画完先在应用里预览，确认后发送到设备；
4. 保存后可在「我的作品」里随时再推送。

画多帧动画时建议先想好帧数再动手：帧数越多，逐帧绘制的工作量越大；简单的两三帧循环往往比十几帧的效果更耐看。滚动文字是给设备「加字」最省事的方式，输入内容、挑颜色就能用，不需要会画画。

## 四、把照片和视频放上屏幕

支持照片/视频播放的型号（如 Times Frame，以及 Pixoo-64 这类可传图的屏）可以走应用里的上传功能：

1. 在应用里选中对应设备，进入照片或上传页面；
2. 从手机相册选图，应用会自动缩放成屏幕分辨率并做像素化处理；
3. 发送后设备上即显示；具体能传静态图还是短视频取决于型号。

同一张照片在 16x16 的小屏上只能保留轮廓，在 64x64 的屏上才能看出细节 —— 传图前对效果有个预期，能省掉反复重传。

## 五、找不到入口时

各型号的功能菜单不完全一样，你手里的设备少了某个入口是正常的（屏幕硬件不同）。先确认设备已按[连接设备与配对方法.md](连接设备与配对方法.md)配对成功，再把应用更新到最新版试试。想给设备设上时间和天气显示，翻[时钟天气与桌面小组件.md](时钟天气与桌面小组件.md)。
