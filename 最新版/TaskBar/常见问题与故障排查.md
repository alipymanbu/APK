## 一、任务栏不显示 / 一闪就没

按顺序过一遍，走到哪步修好就停：

1. **应用内总开关**是不是开着（右上角，界面以实际版本为准）。
2. **「显示在其他应用上层」**有没有允许：系统 设置 → 应用 → Taskbar → 权限/特殊权限。这项不给，任务栏会被其他全屏应用盖住。
3. **开机自启**有没有允许，以及电池设置里有没有把它设成「严格限制/后台自动清理」——被系统杀掉后任务栏自然消失，需要手动再开一次。
4. 还不行就重启应用、再不行重启手机；装完第一次不显示时，先回 [下载与安装教程.md](下载与安装教程.md) 核对权限那张表。

## 二、遮挡与冲突（任务栏挡住了内容 / 和导航栏打架）

- 任务栏常驻屏幕顶部时会压住一行内容，改用「点一下收起」或干脆关掉，都在设置里（对照 [开始菜单与最近任务怎么用.md](开始菜单与最近任务怎么用.md) 的显隐表）。
- 有用户反馈：任务栏会和系统底部导航/全面屏手势互相挤占。两个处理方向 —— 系统侧把「全面屏手势」临时改成三键导航；或者干脆用 Taskbar 自带的导航三键（辅助功能服务开启后可用）替代系统那套。

## 三、小窗打不开 / 打开变成全屏

1. 最近任务**有没有清空** —— 目标应用必须处于未启动状态，从 Taskbar 点开才是小窗（这步最常被漏）。
2. 「Freeform window support」勾了没有，弹窗里的设置指引是否完整做完；Android 8.0/8.1/9 还差一条 adb 命令。
3. 系统版本与机型限制，见 [自由窗口小窗模式设置.md](自由窗口小窗模式设置.md) 第四节 —— 那类情况应用侧无解，别反复重装。

## 四、桌面模式没反应 / 外接屏黑着

核对三个条件：系统 ≥ Android 10、设备真的能视频输出、用了 USB 转 HDMI 适配器；再确认引导里的 adb 授权步骤做完了。逐条排查顺序在 [桌面模式开启与外接显示器教程.md](桌面模式开启与外接显示器教程.md) 第四节。

## 五、更新后出问题

有用户反馈不同版本各有各的 bug，其中一个稳妥做法：**当前版本用着正常时，先把这份安装包留存**，升级后出问题直接装回旧版。版本历史对照 [github.com/farmerbb/Taskbar/releases](https://github.com/farmerbb/Taskbar/releases)，本地这份 6.2.2 的信息见 [下载与安装教程.md](下载与安装教程.md)。

## 六、权限与联网情况一览

F-Droid 页面列出的该应用权限（截至该页面所示）：

| 权限 | 用途 |
| --- | --- |
| 开机后自动启动 | 重启后自动拉起任务栏 |
| 显示在其他应用上层 | 把任务栏盖在其他应用之上 |
| `START_STOP_TASKBAR` / `SEND_RECEIVE_SETTINGS` | 供其他应用启动/停止任务栏、传递设置 |
| Shizuku 相关权限（6.2 起） | 用于在不折腾 root 的情况下取到部分系统能力 |

隐私方面官方口径：该应用**未声明网络权限（无法联网）**、无广告；可选的辅助功能服务只用于模拟返回/Home/最近/电源键与展开通知面板。要是你在别处下的包宣称能联网或带推广，那就不是这个包了 —— 核对 MD5 的方法在 [下载与安装教程.md](下载与安装教程.md)。
