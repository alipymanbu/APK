# Struckd 停服前备份与导出游戏

> Struckd 已发布停服公告，导出是保住自己作品的唯一办法。这篇讲清楚备份窗口、导出到 Unity 编辑器的完整步骤，以及停服对账号和订阅的影响。

## 一、为什么现在就得备份

按官方《Struckd Shutdown FAQ》：应用定于 2026 年 8 月 1 日停止服务，此后无法登录、所有服务不可用，**那一天也是用导出工具保存游戏的最后期限**——过了这天，没导出的作品就无法再访问了。导出走的是官方的 Game Exporter（测试版）工具，方向是单向的：从手机端导出到电脑上的 Unity 编辑器，**导出后不能再导回手机应用**。

也就是说：手机里没导出的草稿，停服后等于丢失；导出到 Unity 编辑器的工程，之后随你在电脑上继续改。

## 二、备份前的准备

| 准备项 | 说明 |
| --- | --- |
| 一台电脑 | Windows/macOS 均可，需要装 Unity Hub 与指定版本的 Unity 编辑器 |
| Unity Player Account | 手机应用内注册（见第三节），导出时要用它登录 |
| 一个草稿 | 账号名下要有至少一个游戏草稿（自己建的或复制别人的都行） |
| 导出插件 | 官方页面提供的压缩包，解压后在编辑器里安装（见第五节） |

账号类型决定备份意义的大小：注册账号的草稿跟着账号走，匿名账号登出即失联——不确定自己状态的话，先看[账号与存档找回方法.md](账号与存档找回方法.md)。

## 三、手机端：确认账号与草稿

1. 打开应用，切到第三个标签页 Profile。
2. 底部找到 SIGN UP（绿色链接）注册 Unity Player Account；已有账号就用 Login with Unity 登录。
3. 确认账号名下有草稿：自己建一个，或把别人的游戏复制一份当模板。

## 四、电脑端：装 Unity Hub 与指定版本编辑器

1. 从 [unity.com/download](https://unity.com/download) 下载并安装 Unity Hub，首次打开会提示装编辑器，先跳过。
2. 在 Hub 的登录界面点 Create account 注册 **Unity ID**——注意这是另一套账号，和第三节的 Unity Player Account 不是一回事，注册完用 Unity ID 登录 Hub。
3. 点左侧 Installs → 右上角 Install Editor → 切到 Archive 标签 → download archive，浏览器会打开 [unity.com/releases/editor/archive](https://unity.com/releases/editor/archive)。
4. 在该页选 Unity 2021.X 标签，找到 **2021.3.22**（2023 年 3 月 29 日发布）这一版，点旁边的 Unity Hub 图标开始安装；等进度条走完再关 Hub。

版本要认准官方指南指定的 2021.3.22f1，其他版本可能导致插件不兼容。

## 五、装导出插件并导入游戏

1. 从官方导出页下载插件压缩包（Game Exporter），解压到本地任意位置，不必放进工程目录。
2. 打开 Unity 编辑器，菜单 Window → Package Manager，点左上角 + 号选 Add Package from disk，选中刚解压目录里的 `package.json`。装好后 Package Manager 里会出现 Struckd Game Exporter。
3. 编辑器顶部菜单点 Struckd → Game Exporter，弹窗里用第三节的 Unity Player Account 登录，等确认提示。
4. 窗口里会列出你账号下的草稿，选一个点 Import，再点 Import Game，等导入完成，按 Finish。
5. 点编辑器顶部的 Play 按钮试玩，确认游戏跑起来了。

卡在哪一步都可以去官方支持页提工单，支持只服务到停服日为止。

## 六、导入后的差异与订阅处理

- **游戏在 Unity 里可能长得不一样**：官方明确说明并非所有 Struckd 功能和素材都被支持，部分素材可能被替换成占位物，某些功能无法原样迁移。导出后先完整玩一遍核对。
- **订阅要自己手动退**：商店里的订阅入口会陆续关闭，已有订阅建议自行取消，避免继续扣费：
  - iPhone/iPad：设置 → 点你的名字 → 订阅 → 选 Struckd → 取消订阅。
  - Android：Google Play 商店 → 头像 → 付款和订阅 → 订阅 → 选 Struckd → 取消订阅。
- **账号数据的去向**：早期 Struckd 专用账号停服后数据全部删除；Unity Passport（UPL）账号只删 Struckd 相关数据，Unity 账号本身不受影响。
