## 一、开始前的两件事

- 装好应用，并想清楚第一个游戏做什么类型。还没装的话，先从 [Struckd 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c752caf4776e) 拿安装包，步骤见[下载与安装教程.md](下载与安装教程.md)。
- 建议开工前就登录账号：在应用第三个标签页 Profile 里注册或登录（Unity Player Account）。把草稿推到手机上试玩、以及之后导出备份，都依赖这个账号；账号类型的差别见[账号与存档找回方法.md](账号与存档找回方法.md)。

## 二、第一步：选玩法机制

新建草稿时先选一个核心玩法，玩法机制决定角色的默认动作与胜负判定方式。官方介绍里常见的类型有：

- 竞速
- 冒险 / 跳跑（jump'n'run）
- 物理解谜
- RPG
- 大逃杀
- 塔防

先定机制再摆素材，返工最少。机制也可以混搭（比如竞速加射击），混合玩法要在试玩环节多调几轮。

## 三、第二步：摆素材搭场景

- 素材库提供 1500 多个免费元素：角色、载具、建筑、平台、收集物、敌人、武器等。
- 操作是拖放：在素材面板点选元素，它会加到底部横条里，再从横条拖进场景。
- 点选素材后会出现绿色选中框，框选可以一次多选；选中状态下有四个基本操作：移动、旋转、缩放（改大小）、复制（可无限复制）。
- 场景不只是摆东西：地形（Terrain）与风格（Style）工具用来搭环境、调整体外观。

## 四、第三步：给素材定规则

摆好素材后，点选它会弹出属性面板。普通物件和角色的可调项不完全一样：

| 可调项 | 适用 | 能做什么 |
| --- | --- | --- |
| 数值（Stats） | 都可以 | 让角色更快、更强、跳更高、加大侦测距离；还能设为隐形、去掉碰撞体积、关闭物理、增加重量 |
| 生存与破坏 | 都可以 | 设为可被摧毁，加回血、生命数、血量、爆炸效果 |
| 队伍 | 都可以 | 点旗帜换颜色，一种颜色对应一支队伍 |
| 外观 | 都可以 | 有皮肤的话可以更换 |
| 对话 | 仅 NPC | 加台词与任务文本 |
| 行为 | 仅 NPC | 六选一：站在原地 / 跟随 / 防守 / 逃跑 / 巡逻 / 攻击 |
| 掉落（Loot） | 仅 NPC | 配置被击败后掉落的物品 |
| 可玩开关 | 角色 | 打开变绿色 = 玩家可操作；NPC 会标白色手柄图标 |

另外几个影响全局的设置：

- **摄像机**（仅可玩角色）：俯视（bird's eye）、第一人称、第三人称。
- **对战规则**：团队死斗（Team Deathmatch）模式开关、存档开关、友军伤害开关。
- **武器限制**（Loadout）：开启后所有角色只能用你放进 loadout 的武器；注意不是所有角色都能拿所有武器。
- **成长（Progression）**：角色在游戏里每收集一次点数就变强一点。
- **胜利条件**：可以加时限，也可以设成守住某处即获胜。
- **Muse Behavior**（进阶）：给素材加特定触发条件，做独特机制用。

## 五、第四步：试玩与发布

1. 点试玩按钮直接玩自己的草稿，发现不对的地方随时退出改——数值、摆位、行为都能即时调整。
2. 满意后点发布，填标题、描述、封面图；描述写得越具体，别人在社区里越容易搜到。发布时还可以选「允许复制」，别人就能把你的游戏当模板改。
3. 点 Publish Game 发布，其他玩家在手机端和网页端都能找到你的游戏；社区里的游玩与点赞数会显示在你的主页。
4. 想把自己作品长期保留的，按[停服前备份与导出游戏.md](停服前备份与导出游戏.md)导出到 Unity 编辑器。

## 六、新手最容易卡住的三处

- **试玩或发布点不动**：多半与未登录有关，回 Profile 页登录 Unity Player Account 再试。
- **NPC 不按预期行动**：行为逻辑块与数值是两层，先确认行为块选对了，再去调速度与血量。
- **改完没保存就退出**：设置菜单里有保存草稿的入口，重装应用或登出前务必先保存并确认登录的是注册账号。
