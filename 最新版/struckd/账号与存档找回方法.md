# Struckd 账号与存档找回方法

> 草稿和游戏「消失」多半是账号被登出，不是被删。这篇讲两种账号的区别、找回步骤和匿名账号的补救办法。

## 一、两种账号，命运完全不同

| | 匿名账号 | 注册账号 |
| --- | --- | --- |
| 怎么来的 | 不登录直接用，绑定当前设备 | 在 Profile 页注册用户名，或关联 Unity Player Account |
| 重装/登出后 | 无法自行找回 | 随时登录回来 |
| 官方态度 | 不建议长期用 | 明确建议使用 |

官方支持页的原话是：匿名账号一旦登出，你没有凭据可以登录回去。所以**只要你在意自己做的东西，第一步就是注册账号**。

## 二、草稿和游戏「消失」的常见原因

最常见的原因与账号有关：重装应用后账号会自动登出，新装的应用处于未登录状态，你做的草稿自然不显示。官方明确说明：官方与应用本身不会删除你的游戏。所以先别慌，按第三节的步骤登录回账号。

另外两种情况：

- 换了设备：草稿在账号里，登录同一账号即可；个别情况要等草稿同步完才会显示。
- 一直是匿名账号在用：见第四节的补救办法。

## 三、注册账号的找回步骤

1. 打开应用，切到第三个标签页 Profile。
2. 点底部的登录按钮。
3. 在弹出的页面点绿色文字 Forgot your password。
4. 填入注册邮箱，按邮件里的指引重设密码，然后登录。

登录回来后，你的游戏和草稿会重新出现。

## 四、匿名账号还有救吗

有，但要走人工渠道。给官方支持邮箱 `support@struckd.com` 发邮件或提工单（支持页入口见[下载与安装教程.md](下载与安装教程.md)），说明情况并提供以下信息（官方要求，尽量给全）：

1. 什么时候开始用 Struckd；
2. 发布过哪些游戏（附链接）；
3. 什么时候失去访问；
4. 有多少草稿；
5. 用的是什么手机；
6. 账号里的经验值大概多少；
7. 有没有新账号（官方会把旧匿名账号的游戏迁到你的新注册账号）；
8. 有没有内购记录（附凭证）。

注意：这些信息**不要发在公开场合，也不要告诉其他玩家**，只通过官方支持渠道提供。

## 五、停服对账号的影响

按官方《Struckd Shutdown FAQ》：

- 早期 Struckd 专用账号：停服后所有关联数据被永久删除。
- Unity Passport（UPL）账号：只删 Struckd 相关数据，Unity 账号本体不受影响。
- 支持渠道（工单、邮箱）只服务到停服日为止——匿名账号找回要在停服前办。

所以结论很直接：**用注册账号，尽早把要留的东西处理完**。创作与发布的流程见[怎么创建自己的游戏.md](怎么创建自己的游戏.md)；要把自己做过的游戏长期保住，按[停服前备份与导出游戏.md](停服前备份与导出游戏.md)导出到 Unity 编辑器。
