# 管理手机里的 APK 安装包（过滤、校验、批量操作）

> 手机里散落的安装包不用再开文件管理器翻：My APK 的「安装包」页签把它们集中列出，还能过滤、校验、批量改名删除。本篇讲怎么用。

## 一、它扫的是什么

切到「安装包」页签，My APK 会扫描你设备存储里的安装包文件，支持的扩展名包括：

- `.apk`（普通单文件安装包）
- 拆分包格式：`.apks`、`.aspk`、`.xapk`、`.apkm`

扫描范围可以自己定 —— 设置里能**选择要扫描的文件夹**。你如果只把安装包放在一两个固定目录（比如 `Download`），把扫描范围收窄，列表更干净、扫描也更快。

## 二、过滤与排序：从一堆文件里快速定位

**按时间过滤**：今天 / 昨天 / 过去 7 天 / 过去 14 天 / 过去 30 天。刚下的包选「今天」，一眼就出来。

**按扩展名过滤**：只看 `.apks`、`.aspk`、`.xapk` 或 `.apkm`，专门整理某一类拆分包时用。

**按版本状态过滤**：只看「较新版本」或「较旧版本」—— 同一个应用存了多个版本时，靠它快速挑出该留哪个。

**排序维度**：名称、所在文件夹、文件大小、修改日期、target SDK、版本号，均可升序/降序。查「哪个包体积最大」用大小倒序，查「谁的目标版本最老」用 target SDK 排序。

**搜索**：输入名称或包名直接过滤列表。

## 三、安装前先看详情

点开任意一个安装包，可以在装之前读到它的详细信息：版本、包名、权限列表、签名、target SDK 等。来源不明的包先看权限再决定装不装 —— 一个手电筒应用要短信权限，这就该停一下了。

## 四、Hash Checker：核对校验值

这是装之前确认「文件没被换过、没下残」的手段。选中安装包，用 Hash Checker 查它的 **MD5 / SHA-1 / SHA-256**，再和发布方公布的值比对：

1. 拿到发布方（或分享者）给出的校验值，注意它是哪种算法（MD5、SHA-1 还是 SHA-256）。
2. 在 My APK 里对同一文件算出同算法的值。
3. 逐字符一致 → 文件与你拿到的那份一致；不一致 → 文件不是同一份或已损坏，别装，重新下载再核。

举例：你从网盘下的 My APK 安装包，其 MD5 为 `2F122C6ECBEA8765C20709FC77E40A8A`（7.23M 那份，2026-09-23 记录），核对时以分享方给你的值为准。

## 五、批量重命名与批量删除

- **重命名**：多选后批量改名，支持高级选项（可自定义命名规则）。想让一目录安装包的命名统一成一种格式时用它，不必回电脑上一个个改。
- **删除**：多选后批量删除，清理重复或过期的安装包。

批量操作会直接改动存储里的文件，执行前先扫一眼选中的列表，别把还要用的包一起删了。

## 六、比较两个安装包的差异

选两个文件（或一个安装包与一个已装应用）做对比，能看出新旧版本之间改了什么 —— 你在决定「要不要升到这份新包」时，先比一遍比看更新日志更直接。

## 七、安装与签名

- **安装**：普通 `.apk` 与上文四种拆分格式都能从这里装。装失败时，My APK 会给出安装问题的识别提示，按 [常见问题排查.md](常见问题排查.md) 对照处理。
- **签名**：支持用 v1、v2 方案签名。这条只对你**自己打包**的安装包有意义（比如给测试包重签），从别处拿来的成品包不需要也别去重签 —— 改了签名就不是原来那份文件了。
