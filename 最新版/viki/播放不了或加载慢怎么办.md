# 播放不了或加载慢怎么办

> 一套按顺序做的排查动作，覆盖打不开、黑屏、缓冲转圈、提示更新、区域看不了这几种情况。

## 一、先分清是哪种「看不了」

四种症状对应四种原因，别一上来就重装：

| 症状 | 更可能的原因 | 从哪一节开始 |
| --- | --- | --- |
| 视频转圈、画质糊、卡顿 | 网络或当前清晰度设置 | 第二节 |
| 黑屏、点了没反应、进不去应用 | 缓存 / 登录态 / 应用状态 | 第三节 |
| 弹「请更新」或强制跳转商店 | 版本低于官方最低要求 | 第四节 |
| 提示该内容在你所在地区不可用 | 版权区域限制 | 第五节 |

## 二、网络与清晰度

1. **先重启网络**：官方排障第一步就是「针对视频播放问题，重新启动您的互联网连接」—— 路由器断电 10 秒再通电，比在 App 里反复重试有效。
2. **换网络对照**：Wi-Fi 和移动数据各播一次，只有其中一条路有问题就不是 App 的事。
3. **主动降清晰度**：免费版封顶 480p，网络一般时在播放器里把清晰度调到更低档，先保证不断流。
4. **别同时跑大流量任务**：下载、云备份、另一台设备看 4K 会把带宽吃满。

## 三、应用本身的四步排障

按官方「基本故障排除」的顺序做，做到哪步好了就停：

1. **登出再登入**：右下角「我」→ 右上角设置图标 → 向下滚动登出，然后重新登录。这一步能解决大部分「订阅没生效、收藏不同步、内容加载一半」的假故障。
2. **重启设备**：长按电源键重启手机。
3. **清缓存 / 重装**：设置 → 应用 → Viki → 存储 → 清除缓存；还不行就卸载重装，安装包可直接取 [Viki 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b7751db0074c) 里那份。重装前确认账号记得住（登录方式见 [下载与安装教程.md](下载与安装教程.md)），观看记录在账号里不会丢。
4. **确认是最新版**：设置 → 应用 → Viki → 应用信息里看版本号，对照官方要求。

顺带检查两项硬件条件：**存储空间**是否快满（接近上限会拖累整个系统性能），以及**应用权限**里是否给了网络与存储的访问权。

## 四、提示「请更新」但更新不了

这是版本门槛，不是故障。官方会公告最低可用版本（查询时 Android 要求 **26.5.0** 及以上，见 [Ceased Support for Older Viki App Versions](https://support.viki.com/hc/en-us/articles/4410143511443-Ceased-Support-for-Older-Viki-App-Versions)）。

- 能连 Google Play：商店里直接更新，最省事。
- 不能连商店：换用你手机能用的其他应用市场，拿**高于当前版本**的安装包覆盖安装；装之前核对包名是 `com.viki.android`，来源不明的包不要装。
- 设备系统升不到 Android 9.0：官方说法是现有版本还能继续看，但不会再收到应用更新 —— 也就是说这条路径有明确的终点，见 [下载与安装教程.md](下载与安装教程.md) 第五节。

## 五、提示该内容在当前地区不可用

这是版权发行区域限制，**订阅 Viki Pass 也不能解除**，官方对此有明确说明。可做的只有两件事：换一部在本地区有发行的作品看；或通过官方的内容请求入口提交你想看的节目（[提交请求](https://support.viki.com/hc/en-us/articles/360034633713)），是否补权由版权方决定。

顺带区分一个容易混淆的现象：**画面在播、字幕却不出来**，那不是播放故障，是字幕轨还没翻完，处理办法在 [中文字幕怎么设置.md](中文字幕怎么设置.md)。

## 六、还不行就找官方

官方排障总入口 [基本故障排除](https://support.viki.com/hc/zh-cn/articles/4408030816659) 覆盖各端；自助无效就到 [提交工单](https://support.viki.com/hc/en-us/requests/new) 描述问题，写清楚：设备型号与系统版本、应用版本号、出问题的剧集名、报错原文、是 Wi-Fi 还是移动数据 —— 这几项齐了，一轮就能定位。
