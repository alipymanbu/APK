# Threads 注册登录与账号设置

> Threads 没有独立的注册入口，账号来自 Instagram。本篇讲清登录时会带过来哪些东西（用户名、认证标识、屏蔽名单）、资料与用户名怎么改、多账号怎么切换，以及想离开时「停用」和「删除」的区别，还有哪些操作会反过来影响 Instagram。

## 一、账号从哪来

Threads 由 Instagram 团队开发，它不单独发账号，也没有「用手机号注册」这条路。你能进 Threads，是因为你有一个 Instagram 账号。所以：

- 想用 Threads，先要有 Instagram 账号；
- 登录 Threads 要输的是 Instagram 的账号与密码；
- Instagram 账号本身出问题（异设备登录被锁、密码忘了），Threads 这边也一起进不去。

## 二、第一次登录会带过来什么

| 项目 | 是否从 Instagram 带过来 |
| --- | --- |
| 用户名 | 带过来，且两边保持一致 |
| 认证标识（蓝勾） | 带过来 |
| 个人资料 | 带过基础信息，头像与简介可单独改 |
| 关注列表 | 不会自动全关注，会给你一屏可选，逐条决定 |
| 已屏蔽的账号 | 带过来，Instagram 上被你屏蔽的人在这里也被屏蔽 |

登录时你还能选要不要「用 Threads 专用资料」——如果你希望简介与头像跟 Instagram 不一样，就在资料页单独改，改这里不会同步回 Instagram。

## 三、资料与用户名怎么改

**改头像、简介、外链**：进自己的个人主页 → 右上角菜单 → 编辑资料，改完保存立即生效。

**改用户名**：也在这一路径下。注意两点：

1. 用户名在 Threads 与 Instagram 之间是**同一套**，在这里改会一起变；如果你只想让 Threads 显示得不一样，用户名这条路走不通。
2. 改完旧名字会被释放，别人可以抢注；改之前想清楚。

## 四、多账号与切换

你可以在同一台设备上挂多个账号：

1. 个人主页 → 右上角菜单 → 最上方能看到当前账号；
2. 选「添加账号」再登录另一个 Instagram 账号；
3. 之后从这个入口一键切换，不用反复输密码。

切换账号后，信息流、消息、通知都是各账号独立的，不会串。

## 五、停用与删除

这是最容易被误解的一块：**删 Threads 不会删 Instagram**。早期确实只能连 Instagram 一起删，后来官方把两者分开了。

| 操作 | 效果 | 反悔窗口 |
| --- | --- | --- |
| 停用资料 | 主页、帖子、回复、点赞对外全部隐藏，数据不删 | 随时登录即恢复；大致一周只能操作一次 |
| 删除资料 | 30 天后永久清空帖子、回复、点赞与关注关系 | 30 天内重新登录可取消 |

操作路径：个人主页 → 右上角菜单 → 账号 → 停用或删除资料，需要重新输一次 Instagram 密码确认。

三点要提醒：

- 删除生效后，**别人截图或转发过的内容不受你控制**，这部分不会跟着消失；
- 你与 Instagram 共享的那部分数据（比如登录信息）不随 Threads 删除而删除；
- **反过来的方向不一样**：停用 Instagram 账号会连带停用 Threads，而停用 Threads 不影响 Instagram。

## 六、导出自己的数据（换手机、留底、找旧帖）

Threads 没有「一键整机备份」，但官方提供数据导出，需要留底或换设备时用它：

1. 个人主页 → 右上角菜单 → 设置；
2. 进「账号」，拉到最下面的「导出你的信息」；
3. 会跳到 Meta 的隐私中心页面，选「下载或转移信息」；
4. 勾选要导出的账号（可以只勾 Threads），选「全部可用信息」或只选部分类别；
5. 选「下载到设备」（或转存到云端盘），再选通知方式与收件邮箱；
6. 提交后在「当前活动」里能看到进度，文件好了会发通知给你。

几个实际操作上的注意点：

- 导出的是 **ZIP 包**，里面一份 HTML 是方便直接浏览的版本，另有若干 JSON 是结构化数据；
- 下载链接**过几天会失效**，拿到之后尽快存到本地或自己的网盘；
- 全程在应用内与 Meta 官方页面里完成，**不需要把密码交给任何第三方**；
- 这条路径同样是**找回自己旧帖**的可靠办法：主页往下刷只加载有限条，刷不到底的时候，从导出包里按日期找比在应用里硬翻快得多；
- 导出包里能拿到你自己发过的帖子与互动记录，但**别人转发或截图出去的内容不在其中**。

## 七、和 Instagram 到底哪些是共享的

把两边的边界分清楚，很多「怎么改完那边也变了」的困惑就没了。

| 项目 | 是否共享 |
| --- | --- |
| 用户名、认证标识、登录密码 | 共享 |
| 屏蔽名单、隐藏词 | 共享 |
| 头像 / 简介（Threads 单独改过则不共享） | 基本共享，可单独覆盖 |
| 帖子、点赞、回复 | 各自独立 |
| 私信 | 各自独立，Threads 的消息不会进 Instagram 收件箱 |

关于「谁能回复你」「隐藏词」「联邦宇宙共享」这些偏隐私的开关，集中写在 [隐私设置与谁能回复你.md](隐私设置与谁能回复你.md)。
