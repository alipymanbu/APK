# Threads 隐私设置与谁能回复你

> 帖子发出去之后谁能看到、谁能接话、谁能提你的名字，这几项各由不同开关控制，配错很常见。本篇按「想达到什么效果」来组织：公开还是私密、谁能回复与提及、隐藏词、屏蔽与限制的差别，以及要不要打开联邦宇宙共享。

## 一、公开账号与私密账号

这是所有可见性的总闸门，先定这一项：

| 账号类型 | 谁能看到你的帖子 | 谁能关注你 |
| --- | --- | --- |
| 公开 | 任何人，包括没登录 Threads 的人 | 任何人，关注即生效 |
| 私密 | 只有你批准过的关注者 | 需要你逐条批准 |

切换路径：个人主页 → 右上角菜单 → 设置 → 隐私，里面的私密账号开关。切换**随时可逆，不影响已有内容**，这是它比「删号再建」实用得多的原因。

两点容易忽略：

1. 未满一定年龄的账号会被系统强制设为私密，开关是灰的，改不了；
2. 私密账号的帖子不会出现在话题标签页和搜索结果里 —— 想要曝光就别用私密，想要安稳就别指望被搜到，二者不可兼得。

## 二、谁能回复你、谁能提及你

这两项分开控制，改一个不影响另一个：

| 开关 | 管的是 | 可选项（以页面实际显示为准） |
| --- | --- | --- |
| 谁可以回复你 | 你的帖子底下能不能接话 | 任何人 / 你关注的人 / 被提及的人 |
| 谁可以提及你 | 别人能不能在帖子里 @ 你 | 同上 |

- 这里的**默认值是「任何人」**，所以不设就等于对所有人开放；
- 发帖时也能对单条帖子临时改「谁可以回复」，那条规则以发帖时的设置为准，不受全局设置覆盖；
- 已经发出的老帖子改了全局设置不会被追溯修改，想收紧要逐条去改。

想挡掉的是「不想看的词」而不是「不想看的人」，用下一节的隐藏词更对症。

## 三、隐藏词：按词过滤回复

路径：设置 → 隐私 → 隐藏词。写进去的词，只要出现在**别人给你的回复**里，那条回复就不显示（连同含这个词的整条回复一起隐去）。

用法上注意：

- 词是**按字面匹配**的，一个词一行，不要写整句话；
- 它只挡别人给你的回复，不影响你发的帖子和私信；
- **隐藏词与 Instagram 是共享的**：在任一边加的词，两边都会生效。

## 四、屏蔽、限制、静音、举报：四种力度

同一件事（不想看到某人），四种处理方式的后果差别很大：

| 操作 | 对方能看到你吗 | 你能看到对方吗 | 对方知道吗 |
| --- | --- | --- | --- |
| 静音 | 能 | 看不到（帖子不进你的信息流） | 不知道 |
| 限制 | 能看你的公开内容 | 对方的回复默认不展示，需你点开才看见 | 一般不知道 |
| 屏蔽 | 不能，互相看不见 | 不能 | 会察觉 |
| 举报 | 看平台处置 | 视处置而定 | 不会直接通知 |

**屏蔽名单与 Instagram 同步**：你在 Instagram 上屏蔽的人，在 Threads 里也自动屏蔽；在 Threads 里新屏蔽的人，同样会带到 Instagram。两边互为镜像，不用重复操作。

选择建议：只是烦不想看 → 静音；偶尔来骚扰但不严重 → 限制；明确要切割 → 屏蔽；涉及违法或恶意内容 → 举报并留证。

## 五、谁能看到你的点赞与收藏

点赞和收藏默认对他人可见，这一点经常被忽略：你以为只是自己记了一笔，别人翻你主页时能看到。

- 想收窄：设置 → 隐私里有对应的「点赞 / 收藏可见范围」开关，按页面提供的选项调整；
- 想留痕但不给别人看，更稳的做法是把内容收藏起来而不是点赞；
- 已经点过的赞，改成不可见后是对外不可见，不是删除记录。

## 六、联邦宇宙共享：要不要开

你可以把内容共享到联邦宇宙（fediverse）—— 一个由很多独立服务器组成的开放社交网络。这一项目前是可选开关，不是默认打开：

| 项目 | 说明 |
| --- | --- |
| 谁能开 | 通常要求成年用户且账号为公开状态 |
| 开了之后 | 其他服务器的用户能搜到你、关注你、和你的帖子互动 |
| 能互动的范围 | 能看到并点赞来自其他服务器的回复，但部分能力仍在逐步打通 |
| 不能共享的 | 带投票的帖子、以及设置了受限回复的帖子无法共享出去 |
| 关掉的后果 | 其他服务器上已经发生的互动不会因此回滚 |

路径在「设置 → 账号」附近，名为联邦宇宙共享（测试版）。它会改变你内容的可见边界，**不打算让内容跨平台流动就保持关闭**。

## 七、改完之后建议核对的三点

1. 用身边另一个账号（或退出登录后用浏览器）搜一下自己的用户名，看看陌生人视角下能翻到什么；
2. 发一条测试帖，让朋友尝试回复，确认回复范围设置真的生效；
3. 「屏蔽名单 / 隐藏词」在 Instagram 上做过的动作，来 Threads 这边确认一次是否已同步，避免两边认知不一致。
