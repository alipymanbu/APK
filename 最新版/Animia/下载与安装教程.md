Animia 是手机／平板上的追番应用，把每周新番放送时间表、多来源的剧集信息和讨论区放在一起，安卓与 iPhone 都有官方包。本篇只解决一件事：把网盘里这份包装进你的设备，并确认装的是哪一版。

## 一、先核对网盘里这份包是哪一版

各下载站挂的版本号是他们自己写的，而网盘里这份是制作文档时实际核对过的那一个，两者常常对不上。本文涉及的版本、包名、体积一律以这张表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Animia |
| 版本号 | 2.7.3 |
| 包名 | `com.animia.app` |
| 安装包体积 | 26.37 MB |
| MD5 | `1459D9C1C90411A3959C55A96EC64BB2` |
| 适用平台 | 安卓手机／平板 |
| 资料登记的系统要求 | 「安卓系统 5.2 以上」 |

三点提醒：

- **判断是不是同一个包，看包名 + MD5，不看名字旁边的数字。** 同一个 APK 在不同站点会被写成不同版本号，体积也常被四舍五入成「26.4M」。
- **「Animia」这个名字的近似应用不少。** 名字对上不算数，包名 `com.animia.app` 对上才算。
- **上面这份系统要求别当真。** 安卓并没有 5.2 这个正式版本号，这是资料登记的写法问题，不是准数。实际上装上能正常打开就说明你的设备可以；停在安卓 5 以下的老机器打不开的概率较高，没必要反复折腾。

## 二、安卓：装网盘里这份 APK

1. **先转存再下载**：打开 [Animia 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1cb644f7d996)，把 APK 转存到你自己的网盘，再下载到手机。转存这一步别省 —— 分享链接失效后，只有转过存的文件还能找回来。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器、浏览器或网盘客户端）打开开关，再点 APK 安装。
3. **签名冲突就先卸载旧的**：手机里若已装着同包名、但签名不同的版本，覆盖安装会直接失败并提示「应用未安装」。先把旧的卸掉再装这份。
4. **两个版本不能共存**：包名相同，系统只认一个。想保留旧版就别装这份，装了就会覆盖。

官方自己的安卓包挂在 Google Play 上，能正常访问商店的话也可以从那里装；网盘这份的好处是不依赖商店、随时可取。两条路的包名一致，装哪个都是同一个应用。

装好后想确认手里这份到底是哪一版，可以在应用内的设置或「关于」那一类页面里看版本号；这一版改了什么、要不要跟着升，见 [更新到2.7.3改了什么.md](更新到2.7.3改了什么.md)。

## 三、iPhone / iPad：走 App Store

**网盘里这份是安卓 APK，iPhone 装不了**，两个系统的安装包格式不同。苹果设备请到 App Store 搜 Animia 安装 —— 官方介绍页给出的商店条目属于台湾区，在台湾区商店能直接找到。若你的 Apple ID 不在该区，商店里可能搜不到，这属于商店分区问题，不是应用本身的问题。

## 四、第一次打开要做什么

打开后先看时间表页，通常是默认首页 —— 按星期排开当季新番，点了就能进详情页。第一次用建议按这个顺序走一遍：

1. 在**时间表**里找到一部你在追的番，点进去开始播放，确认能出画面；
2. 在详情页点一次**收藏**，再到收藏列表里确认它真的进去了；
3. 需要跨设备看的话，这时候再**登录**，让收藏与观看记录能跟着账号走。

游客状态也能看，区别在于收藏与观看记录只存在本机：换手机、清数据或重装之后这些记录就没了。要不要现在登录，看你是不是打算长期用，相关说明在 [时间表与追番收藏怎么用.md](时间表与追番收藏怎么用.md)。

## 五、装完做一次最小验证

挑一部常见番，走一遍「搜索 → 进详情页 → 播放」，能正常出画面并播起来就说明安装没问题。这一步卡住时按现象分头处理：

- 搜不出任何内容 → 见 [搜索找番与源怎么选.md](搜索找番与源怎么选.md)；
- 能搜到、点开一直转圈或播几秒就卡 → 见 [播放分流切换与卡顿排查.md](播放分流切换与卡顿排查.md)；
- 装不上、提示「解析包错误」、装上就闪退 → 直接翻 [常见问题与排查.md](常见问题与排查.md)。
