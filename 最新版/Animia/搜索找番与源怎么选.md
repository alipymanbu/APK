# Animia 搜索找番与源怎么选

Animia 自己不生产剧集，它做的是把多个来源的动画资讯与片源整合到一处。官方说明里点名的来源是 **Anime1、Myself 动漫、AGE 动漫** 三家。理解这一点，找番时的很多困惑就说得通了：搜出的结果取决于这几个来源各自收录了什么。

## 一、搜索能搜到，但结果不止一条

同一部番常常同时出现在两三个来源里，于是搜索列表里会出现重复条目 —— 这不算故障，是整合的来源多造成的。挑哪一条，按这个优先级：

1. **看集数**：集数更多的那条，通常是收录更完整的来源；
2. **看更新**：更新日期更近的那条优先，说明这个来源还在跟着更；
3. **看标注的来源名**：留意条目上标注的是哪一家。三家各自的收录与更新节奏不一样，记住哪条对应哪家，下次挑起来更快。

挑不出来的情况也有 —— 两条看着一模一样。这时随便进一条，播不动再换另一条，成本比纠结更低。

## 二、几个来源的差别在哪

官方说三个来源都整合进来了，但并没有承诺它们完全等价。实际用下来，三家的差别体现在这几处：

| 差别点 | 说明 |
| --- | --- |
| 收录范围 | 各家侧重不同，某部番只在一家能搜到是常事 |
| 更新节奏 | 同一部番在不同来源的更新时间可能差一两天 |
| 集数与进度 | 来源没跟上的话，某一集会缺，换一家就有 |
| 稳定性 | 各家自身会有波动，某家暂时搜不出来不等于番没了 |

**看时间表上标着更新、搜出来却还是旧一集，多半就是那家来源还没跟上** —— 这种情况换另一条条目，或晚些再看。

## 三、搜索被拦住、提示搜得太频繁

有用户反馈过 Myself 这一侧搜索有频率限制：**短时间内重复搜索会被提示操作太快**，需要隔一段时间（反馈中提到约 15 秒）再搜。这类提示更像是来源侧对搜索请求的限流，通常与本机网络、账号无关。处理办法很直接：

- 搜完之后等十几秒再搜下一个关键词，别连着快速敲；
- 关键词别太短、别只填一两个字，短词更容易被判定为无效请求；
- 用「时间表」和收藏列表代替一部分搜索：想找当季新番看时间表，想找看过的进收藏，都比反复搜更省事。

## 四、另外两条找番路径与讨论区

除了敲关键词，还有两条路值得记住：

- **按画面搜**。官方商店功能清单里有「以画面截图进行动画场景搜寻」—— 只记得画面、不记得片名时用它，具体怎么截、截什么命中率高，见 [截图找番怎么用.md](截图找番怎么用.md)；
- **按放送日找**。当季新番直接看时间表，比搜索更快，见 [时间表与追番收藏怎么用.md](时间表与追番收藏怎么用.md)。

讨论区方面，商店条目写的是「**Myself、Anime1、AGE 动漫讨论／留言区**」—— 也就是按来源各自有讨论／留言区，你在哪一条条目下留言，看到的人来自那一侧。它的定位是围绕一部番的讨论，不是求助客服的入口：播放失败、收藏丢失这类问题在讨论区问，别人多半也解决不了，直接按 [常见问题与排查.md](常见问题与排查.md) 处理更快。

## 五、搜不到番的排查顺序

1. **换关键词**。片名的别名、简繁写法、去掉季数后缀（如把「第二季」去掉）各试一次，来源里的条目名未必与你习惯的写法一致；
2. **看时间表**。当季新番在时间表里能点进去，说明库里有，只是搜索没命中；
3. **换用截图搜索**。片名实在想不起来时，拿一张画面截图去搜比瞎试关键词有效，见 [截图找番怎么用.md](截图找番怎么用.md)；
4. **过一会儿再搜**。尤其刚搜过好几个词，先等一下再试，避开限流；
5. **换一条结果**。同一个片名搜出多条时，换另一条进去；
6. 全都不行再考虑是这一部在这几个来源里都没收录 —— 这不属于应用故障。
