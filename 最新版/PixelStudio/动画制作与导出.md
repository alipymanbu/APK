## 一、逐帧动画的基本流程

1. 在项目里切到动画（帧）面板，新增一帧；
2. 新帧一般复制上一帧再改，角色整体位置不会跳；只有动的那几个部位需要重画；
3. 打开 Onion Skin（洋葱皮）：前一帧会半透明显示在当前帧下面，对齐动作变化全靠它；
4. 用预览窗口循环播放，看动起来的节奏对不对，再回去修帧。

逐帧动画就是每一帧自己画，应用不会帮你补中间动作：眨眼两三帧、走路循环四到八帧起步，是很正常的帧数，别觉得「怎么画了这么久才几帧」。

## 二、GIF 与精灵序列图怎么选

| 你要拿去做什么 | 导出哪种 |
| --- | --- |
| 发聊天群、社交动态直接动起来 | GIF |
| 给游戏引擎当角色动画素材 | 精灵序列图（sprite sheet） |
| 带音乐的小视频 | MP4（见下一节） |

导出精灵序列图时，所有帧会被拼进一张大图。拿去引擎里切帧前注意两点：帧与帧之间间距要一致；记录清楚一行排几帧，切帧设置就按这个来。

做完的动画也可以分享到应用内的 Pixel Network 社区，想发布作品的话在分享菜单里就能找到入口。

## 三、带音乐的 MP4

官方支持给动画配上音乐后导出 MP4 视频。注意官方清单里「无限导出 MP4」是 PRO 项目——也就是免费版的 MP4 导出有次数限制，碰到弹窗提示再处理就行，多数时候改导 GIF 也能满足分享需求。各项目差异对照见[免费版与PRO区别.md](免费版与PRO区别.md)。

## 四、导出结果不对时的处理

- **GIF 文件太大**：先缩画布、减帧数；像素画本身颜色很少，导出选项里别引入渐变之类的高色数元素；
- **颜色发糊变色**：GIF 上限 256 色；用你作画时那份调色板去导，比自己重新量化颜色更保真；
- **放大后边缘发虚**：要在别处把像素画放大显示，用应用内置的放大算法 Scale2x/AdvMAME2x、Scale3x/AdvMAME3x 处理，比拿图片工具硬拉干净得多；
- **需要旋转**：用应用里的 Fast RotSprite 旋转，普通旋转会把斜线像素打乱。

## 五、导出之前先把工程留住

GIF、MP4 都是把图层压平的成品。想保留继续修改的能力，把 PSP 工程文件一起存好，它保存图层与帧；格式明细在[支持的文件格式.md](支持的文件格式.md)。
