## 一、建第一块画布

1. 打开应用后新建项目，先定画布尺寸与背景——背景选透明，以后往游戏素材或头像框里合成就不用抠图；
2. 手机上用竖屏模式，平板和电脑上切横屏模式，两边的工具是一样的，只是布局不同；
3. 像素画里 1 个格子就是 1 个像素：画 32×32 的头像就把画布设成 32×32，画布宁小勿大，放大了格子才看得清。

画布上限方面，早期官方页面写过「最高 1024×1024」，现行官方描述是「画布尺寸无限」、PRO 再扩展最大工程体积——你装的那份能开多大，以应用里实际给出的上限为准。

## 二、常用工具对照

| 工具 | 你什么时候会用 |
| --- | --- |
| 画笔 / 橡皮 | 基础起稿与修图；较新版本里从橡皮状态取色会自动切回画笔，少一次手动切换 |
| 油漆桶 | 封闭区域一键填色，铺底色最快 |
| 形状工具 | 直接画圆、矩形这类规则图形，不用一格一格描 |
| 渐变工具 | 在选区里做颜色过渡 |
| 文字工具 | 往图里插不同字体的字 |
| Dot Pen | 带光标辅助的精确落点，放大修细节时比普通画笔稳 |
| 抖动笔 | 手工抖动排布做阴影和高光，像素画常用的上色质感 |
| 对称绘制 | 开 X、Y 或 X+Y 对称，画对称头像、图标一笔顶两笔 |
| 画笔平铺（Tile） | 把笔刷按平铺方式画，配合 PRO 的平铺模式做无缝贴图 |

工具栏支持自定义，把自己最常用的那几个挪到顺手的位置，比每次翻菜单快。

## 三、图层与颜色

- 图层的用法和电脑绘画软件一样：线稿一层、上色一层、背景一层，改哪层都不弄脏别的层；
- 拾色器有 RGBA 和 HSV 两种模式；想找「同一个色但更深一档」，用 HSV 拖亮度滑杆比在 RGBA 里瞎调快得多；
- 内置调色板收录了知名像素画师的配色，也可以自建调色板，或直接从 Lospec（[lospec.com](https://lospec.com)）下载现成的色板；想照着某张图重新画，还能直接从图片抓取调色板；
- 换配色不用重画：官方支持把调色板套用到图片上（apply palettes to images），整体换配色时先试这条路；
- 素材库（Sprite Library）用来存你反复用的小图案——云朵、砖块、装饰符号这类，存进去后随取随用，不用每次重画。

## 四、手势、手写笔与辅助视图

- 双指捏合缩放、滑动平移；不习惯双指也可以开虚拟摇杆来移动视图；
- 支持 Samsung S-Pen、HUAWEI M-pencil、Xiaomi Smart Pen 这类手写笔，普通电容笔同样能画；
- 开网格对齐格子，改背景色让深色线条看得清；
- 小地图（mini-map）和 Pixel Perfect 预览窗口用来看 1:1 缩放下画面实际是什么样——像素画放大画着好看、缩回去糊成一团是常事，靠这个窗口随时检查。

## 五、自动保存与下一步

不需要每画几步就手动存一次：应用自带自动保存与备份，默认存的是 PSP 工程格式，图层、帧都在里面，细节见[支持的文件格式.md](支持的文件格式.md)。单张图画顺了，想让它动起来就进入逐帧动画，流程在[动画制作与导出.md](动画制作与导出.md)。
