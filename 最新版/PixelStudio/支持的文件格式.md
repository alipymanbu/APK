## 一、PSP：Pixel Studio 的工程文件

PSP（Pixel Studio Project）是这个应用的工程格式，图层、帧、调色板都存在里面。所有还没「定稿成图片」的作品都建议留一份 PSP：

- 自动保存与备份写的就是 PSP 文件；
- 多设备同步（PRO 的 Google Drive 同步）同步的也是 PSP；
- 卸载重装、换机之前，先用文件管理器把 PSP 文件从应用数据目录整个拷出来；具体存放在哪个目录各机型不同，以应用内显示的保存位置为准，别凭记忆猜路径；
- 工程还在进行中的时候就养成节奏：隔一段时间把 PSP 拷一份到电脑或另一块盘——应用内的自动备份存在本机，设备本身出问题时它帮不上忙；
- 换机、重装时带「两份」：PSP 工程留给以后继续改，PNG 成品留着随时能看能发——只带走其中一份，总会在某个时刻后悔。

## 二、能导入的格式

下面是官方商店页（较新版本）列出的清单。这个清单随版本迭代在变宽，你装的那份能导入什么，以应用内导入菜单实际显示为准：

| 类别 | 格式 |
| --- | --- |
| 常见图片 | PNG、JPG、GIF、BMP、TGA |
| 工程 / 编辑软件 | PSP、PSD（Adobe Photoshop）、EXR |
| 像素软件工程 | Aseprite 文件（只能导入，不能导出） |
| 调色板 | JASC Palette（PAL）；也能直接从图片抓取调色板 |
| PRO 额外 | AI、EPS、HEIC、PDF、SVG、WEBP（云端读取）；PSD 云端读写 |

要注意方向性：手上有 Aseprite（.ase）文件可以导进来继续画，但 PSP 想转回 Aseprite 是没有导出通道的——以后换工具，先把作品导成 PNG / GIF 再走。

## 三、能导出的格式

| 用途 | 选什么 |
| --- | --- |
| 普通成品图 | PNG、JPG |
| 动画成品 | GIF |
| 游戏引擎素材 | 精灵序列图（sprite sheet） |
| 视频 | MP4（可带音乐；导出次数是 PRO 项目） |
| 放大输出 | 内置 Scale2x/AdvMAME2x、Scale3x/AdvMAME3x |
| 旋转输出 | Fast RotSprite |

导出参数怎么选、效果不对怎么补救，[动画制作与导出.md](动画制作与导出.md)里有更细的对照。

## 四、版本差异与几个注意点

- 网盘里那份是 5.45 版（来历与核对方式见[下载与安装教程.md](下载与安装教程.md)）。早期官方页面把格式标为「PNG、JPG、GIF、PSP、ASE」、画布标为 1024×1024；现行官方描述已经扩到上表那样、画布「无限」。版本越旧，缺某个格式的可能性越大；
- 在菜单里找不到某个格式时，分两步确认：先看版本够不够新，再看那一项是不是 PRO 专属；
- PSD、Aseprite 这类外部工程导入属于单向兼容，复杂图层效果导进来可能走样，重要的原始文件始终在原软件里留底。
