OPlayer 是安卓上的一款本地与局域网通用播放器，装机之后真正会卡住人的往往不是功能，而是权限、解码和网络这几处。这篇按「你看到什么」来分节，每节只给能动手的步骤，不讲原理，遇到问题时直接跳到对应那一节。

## 一、列表里扫不到本地视频

最常见的原因只有一个：存储权限没真正给到。

1. 进「设置 → 应用 → OPlayer → 权限」，确认媒体相关的项是「允许」而不是「仅在使用时允许」或「拒绝」；
2. Android 11 及以后，权限列表里可能分成「照片和视频」「音乐和音频」两项，缺一项就会少扫出一类文件；
3. 回到应用，进「设置 → 通用」，确认「自动重新扫描」是打开的，然后重启应用让它重扫一遍。

如果权限都给全了仍然少文件，检查文件所在位置：部分定制系统把「Android/data」等目录对新装应用完全隔离，放在那里的视频扫不到。把片子移到「下载」或自建的「Movies」目录下再重扫。

## 二、扫到了文件，点开却没反应

| 现象 | 先做什么 |
| --- | --- |
| 点击后一直转圈 | 确认文件没在传输中被拷一半，体积是不是 0 字节 |
| 只有个别文件打不开 | 换一部正常的片子试，正常的能播说明是这一个文件的问题 |
| 提示不支持该格式 | 对照 [支持哪些视频格式.md](支持哪些视频格式.md) 确认容器与编码 |

从压缩包里直接点开播放在部分机型上会失败，先把文件解压到本地目录再播。

## 三、高码率影片卡顿、4K 不流畅

按影响从大到小排：

1. **确认硬件解码是开着的**。同一部片子，硬解流畅、软解转圈，这是最常见的原因；把解码方式设成硬件优先甚至强制硬件，卡顿通常立刻缓解。
2. **看片源本身的规格**。4K 加高码率的原盘文件，中低端芯片就是扛不住，这类片子换播放器也救不回来。
3. **关掉同屏的其他负载**。悬浮小窗加后台下载一起跑，解码会抢不到资源。
4. **发热降频**。连续看半小时以上开始卡，多半是机身温度上去了被降频，摘掉厚手机壳、别边充边看能缓解。

## 四、有画面没声音

先换一条音轨，再考虑音频输出模式：AC3、DTS、EAC3 这类编码在部分机型上默认按直通输出，设备和耳机解不了就变成静音，把音频输出改成兼容（软解）模式即可。完整判断顺序在 [字幕加载与音轨切换.md](字幕加载与音轨切换.md) 里。

## 五、装不上、闪退

| 现象 | 处理 |
| --- | --- |
| 提示「应用未安装」 | 手机里已装了更高版本，或装了另一条包名线的版本；先卸载再装 |
| 提示与设备不兼容 | 系统版本低于这份包要求的基线，或安装包没下载完整，重新下一次 |
| 装完打开就闪退 | 卸载后重装一次，直接覆盖安装遗留的旧数据是常见诱因 |
| 安装界面反复弹出安全提示 | 这是第三方渠道安装包的常规提示，按提示继续即可 |
| 想要一份干净的安装包 | 从 [OPlayer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/96e8372920fa) 重新转存下载，装之前先卸载旧版 |

重装前记得本地播放记录会一并清空，介意的话先别急着重装，先把权限和后台限制这两项排除掉。

## 六、局域网主机连不上或播放中断

1. 确认手机和电脑在**同一个 Wi-Fi** 下，且不是访客网络（访客网络通常禁止设备互访）；
2. 换一台设备（另一部手机或电脑）访问同一个共享目录，能访问说明链路与共享权限都正常，问题出在播放器里填的地址、端口或账号密码上；
3. 播放到一半就断：多半是电脑进入休眠或账号注销，把电脑的睡眠改成「从不」；
4. 能连上但一直转圈：带宽不够，见 [局域网与NAS播放设置.md](局域网与NAS播放设置.md) 里关于频段与码率的那一节。

## 七、投屏到电视找不到设备

- 手机和电视要处于同一个局域网，电视端的投屏接收功能要先打开；
- 部分电视只认自己的投屏协议，不认通用的投放方式，这种情况下换用电视厂商自带的投屏应用更稳；
- 酒店、公共网络里通常会做设备隔离，投屏基本用不了，这属于网络限制而不是应用故障。

## 八、后台播放被系统掐断、耗电偏快

退出应用后声音就停，是系统的后台限制在起作用，不是播放器被关掉了：

1. 进「设置 → 应用 → OPlayer」，找到电池相关的选项；
2. 把省电策略改成「不受限制」或加进白名单；
3. 部分机型的手机管家里还有一层「后台运行管理」，同样要放行；
4. 别用第三方清理工具冻结它的后台进程，被冻结后表现就是加载失败、列表空掉。

耗电方面，硬解码通常比软解码省电得多，长时间看片优先保证硬解开启；听音频时把画面切到后台也比重在前台省。
