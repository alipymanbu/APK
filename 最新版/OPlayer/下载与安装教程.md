## 二、装之前要核对的两件事

**第一，包名别装混。** 官方在安卓上有两条并行的包名线：本文这份是 `com.olimsoft.android.oplayer`，另有一条以 `.pro` 结尾的包名线。两者包名不同，在系统里会被当成两个独立应用，**不能互相覆盖安装**，也各占一份数据空间。如果你之前装过别的包名版本，先确认想留哪一个。

**第二，留出足够的空间。** 安装包本身 71.70 MB，装完占用会比这更大一些；更要紧的是这个应用靠扫描本地存储来建立播放列表，存储太满时扫描本身就会变慢。装完先确认一下剩余空间够放你要看的片子。

## 三、安装步骤

1. **转存并下载**：从 [OPlayer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/96e8372920fa) 把 APK 转存到自己的网盘，再下载到手机或电脑。
2. **把包送到手机上**：手机端直接下载最省事；在电脑上下载的话，用数据线、文件传输助手或任意传输工具拷进手机存储均可。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统的这项开关通常收在「安全」或「隐私」分类下面。
4. **点击 APK 完成安装**：系统若提示「应用未经过安全检测」，选择继续安装即可，这是第三方渠道安装包的常规提示。
5. **回装低版本要先卸载**：安卓不允许用更低版本的安装包覆盖更高版本，会直接报「应用未安装」。如果你手上这份 5.00.42 比手机里已装的版本低，先卸载旧版再装，本地播放记录与设置会一并清掉。
6. **装完先别急着打开**：先把下一节的权限过一遍，否则首屏会停在扫描不到的空白列表上。

## 四、首次启动要给的权限

第一次打开时通常按顺序弹几项授权，逐项给全：

| 权限 / 设置 | 在哪里给 | 不给会怎样 |
| --- | --- | --- |
| 存储 / 文件与媒体 | 启动时的系统弹窗 | 扫不到本地视频与音乐，列表一直是空的 |
| 通知 | 启动时的系统弹窗 | 后台播放时通知栏没有控制条，切歌、暂停都不方便 |
| 后台运行 / 电池优化 | 系统设置里的应用详情页 | 切到别的应用或锁屏后，播放容易被系统掐断 |
| 悬浮窗 | 系统设置里的应用详情页 | 想用悬浮小窗边看边用别的应用时弹不出来 |

Android 11 之后系统对存储访问收得更紧，有的机型在权限页里看到的是「照片和视频」「音乐和音频」分项，而不是笼统的「存储」。把媒体相关的几项都允许即可；播放器不需要你额外开「管理所有文件」这类总开关。

## 五、装完做一次最小验证

1. 打开 OPlayer，按上一节把权限给全；
2. 回到主界面，让它扫一遍本地媒体。列表里能看到手机里已有的视频文件，就说明存储权限真正生效了；
3. 随便点一个文件播放几秒，确认画面、声音、字幕区都正常；
4. 退出应用再重进一次，检查列表还在——如果重进后又要重新扫，去 [播放手势与倍速设置.md](播放手势与倍速设置.md) 里看「自动重新扫描」这一项的设置。

卡在这里的话，先看 [常见问题与排查.md](常见问题与排查.md)，绝大多数情况是存储权限没真正给到，或者文件放在应用读不到的位置。想连电脑或 NAS 上的片库，接着看 [局域网与NAS播放设置.md](局域网与NAS播放设置.md)。
