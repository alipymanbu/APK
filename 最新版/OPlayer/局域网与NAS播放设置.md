# OPlayer 局域网与NAS播放设置

> 本篇讲怎么让 OPlayer 直接播电脑或 NAS 上的片子，不往手机里拷，以及连不上、卡顿时该看哪里。
> **相关文档**：[字幕加载与音轨切换.md](字幕加载与音轨切换.md) · [常见问题与排查.md](常见问题与排查.md) · [支持哪些视频格式.md](支持哪些视频格式.md)

手机存储放不下整套剧集，但电脑或 NAS 上已经有了片库 —— 这种情况下把文件拷来拷去没意义，让播放器直接读远处的文件更省事。OPlayer 内置了 SMB（也就是常说的 SAMBA）与 FTP 客户端，也能通过 UPnP / DLNA 发现自己网络里的媒体服务。

## 一、先想清楚走哪条路

| 方式 | 适合什么场景 | 你要做的准备 |
| --- | --- | --- |
| SMB / SAMBA | 电脑或 NAS 上有现成的共享文件夹 | 在电脑上共享目录，拿到主机地址与账号密码 |
| FTP | 已有一台常年开机的 FTP 服务 | 知道地址、端口、账号密码 |
| UPnP / DLNA | 家里有群晖等 NAS 或已运行媒体服务器 | 基本不用配，靠自动发现 |
| Wi-Fi 传输 | 只想把几个文件搬进手机 | 手机开接收端，电脑浏览器上传 |

只想把片子传进手机离线看，用最后一行的 Wi-Fi 传输；想让片库留在电脑上、手机随点随播，用前三行。

## 二、在电脑上准备一个共享文件夹（Windows）

1. 选中要共享的文件夹，右键 →「属性」→「共享」→「高级共享」；
2. 勾选「共享此文件夹」，点「权限」把读取权限给你的账户；
3. 记下这台电脑在局域网里的地址。在命令行里执行：

```bash
ipconfig
```

看无线网卡那一行的 IPv4 地址，形如 `192.168.1.23`。这个地址就是待会儿要填进播放器的主机地址。

共享电脑上的文件夹前，确认这台电脑没有休眠、也没退出账号 —— 电脑一睡，共享就断了，现象是播放器里能看到主机但点进去卡住。

## 三、在 OPlayer 里添加主机

1. 打开 OPlayer，点左上角菜单唤出侧边栏，进入「本地网络」或「网络」分类；
2. 点右下角的「+」新增主机；
3. 按提示填协议（选 SMB 或 FTP）、主机地址（第二步拿到的 IP）、端口与账号密码；
4. 保存后主机出现在列表里，点进去就能浏览共享目录，选中的视频直接开始播。

对同一台电脑，只需要填一次主机地址，之后每次打开应用直接进共享目录即可。共享目录里东西很多时，第一次进去会有一个列目录的等待时间，这是正常的。

要注意主机列表存在应用自己的数据里：卸载重装（安装包统一从 [OPlayer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/96e8372920fa) 取用）之后，地址和账号密码都要重新填一遍。

## 四、网络播放时字幕怎么办

和本地播放是同一套规则：**字幕文件要和视频文件放在同一个共享目录里、主名相同**。区别是字幕文件要放在电脑或 NAS 那一侧，而不是手机里 —— 放在手机上的字幕不会被远程视频认出来。

共享目录里只有视频没有字幕文件时，别把字幕单独拷进手机 —— 那样不会被远程视频认出来。正确做法是在电脑或 NAS 那边把字幕放进同一个目录，再回播放器刷新一次目录。字幕相关的细节见 [字幕加载与音轨切换.md](字幕加载与音轨切换.md)。

## 五、卡顿要看三件事

网络播放卡顿，原因大多不在播放器：

1. **频段**。优先连 5 GHz 频段的 Wi-Fi，2.4 GHz 在播放高码率影片时基本必卡。同一台手机在 5 GHz 上流畅、在 2.4 GHz 上转圈，就是这个原因。
2. **码率与文件体积**。一部 20 GB 的 4K 原盘，任何手机 Wi-Fi 都吃不下这个稳定的传输速率。这类片子要么降到 1080p 版本，要么先拷进手机本地播。
3. **无线信号中间有多少面墙**。路由器与手机之间的物理距离对吞吐影响很直接，隔一堵承重墙的衰减往往比换路由器更关键。

调这几项之前，可以先做个判断：同目录下的低码率小文件如果流畅，说明链路和账号密码都没问题，只是带宽不够。

## 六、Wi-Fi 传输：把手机当接收端

只想传几个文件到手机时，不用开共享目录，反过来做更省事：

1. 在 OPlayer 里找到 Wi-Fi 传输（或类似名称）的入口并开启；
2. 界面会给出一个局域网地址，形如 `http://192.168.1.x:端口`；
3. 在同一 Wi-Fi 下，用电脑浏览器打开这个地址；
4. 把文件拖进网页里的上传区，传完在手机的媒体列表里就能看到。

这条路适合「电脑上下了三集，想传到手机路上看」这种情况，不适合传整套片库 —— 无线传输的速率摆在那里。

连不上主机、能连上但播不动、或者局域网播放时字幕缺失，先看 [常见问题与排查.md](常见问题与排查.md)；某个文件到底能不能被远程播放，取决于格式与编码，对照 [支持哪些视频格式.md](支持哪些视频格式.md) 判断。
