# Nintendo Store 账号登录与游玩记录：绑定任天堂账号、查看 Switch 游玩数据

Nintendo Store 不登录也能浏览商品和新闻，但游玩记录、心愿单提醒、门店打卡这几块都要先登录任天堂账号。本篇把登录入口、能查到什么数据、查不到旧记录时缺哪一步，一次说清。

## 一、哪些功能必须登录

| 功能 | 不登录 |
| --- | --- |
| 浏览主机、配件、游戏、周边商品 | 可用 |
| 查看游戏与活动新闻 | 可用 |
| 完成购买（跳转商城结算） | 不可用，必须登录 |
| 游玩记录查看 | 不可用，必须登录 |
| 心愿单与降价推送 | 不可用，必须登录 |
| 门店与活动打卡 | 不可用，必须登录 |

如果你只想逛商城比价，可以不登录；但这款应用里最有「个人数据」味道的游玩记录和打卡，以及真正的下单环节，都建立在账号之上。

## 二、登录步骤

1. 打开应用，进入「我的页面」（My Page）一类的个人页签。
2. 点登录入口，会跳转到任天堂账号的授权页面。
3. 没有账号的话，在这个页面可以现注册一个：用邮箱注册即可，官网地址是 [accounts.nintendo.com](https://accounts.nintendo.com)。
4. 登录完成后回到应用，个人页会显示你的账号信息。

注意两点：

- 账号的「国家/地区」设置会影响你看到的商城区域和可用的支付方式，改地区的影响见 [界面语言与地区限制.md](界面语言与地区限制.md)；
- 如果卡在授权页转圈或报错，先看 [常见问题与故障排查.md](常见问题与故障排查.md) 的登录一条。

## 三、游玩记录能查到什么

登录后，在应用的游玩记录区域可以看到 Nintendo Switch 2 与 Nintendo Switch 的数据：

- **最近一周的每日游玩记录**：Recent Activity 区域按天列出你过去一周玩了什么；
- **累计时长排行**：哪些游戏玩得最久；
- **起始日期**：每个游戏你是什么时候开始玩的。

这些数据来自你主机上绑定的同一个任天堂账号，不需要在应用里再操作同步。

## 四、想看 3DS / Wii U 的旧记录

官方页面对这块有一个专门的说明：3DS 和 Wii U 的游玩记录只覆盖 **2020 年 2 月之前** 的数据，而且有一个前提——

- 你需要把 **Nintendo Network ID（NNID）关联到现在的任天堂账号**；
- 没关联 NNID 时，应用里看不到这两台老主机的任何记录，这属于正常现象，不是应用坏了。

关联 NNID 的入口在任天堂账号的网页设置里（账号设置 → 关联账号），关联完成后回到应用刷新即可。3DS/Wii U 时代之后的记录不会出现在这里，官方没有提供更晚时间段的合并查询。

## 五、登录之后做什么

- 想让心愿单降价时收到提醒，需要把推送通知打开，步骤见 [心愿单与降价提醒.md](心愿单与降价提醒.md)；
- 线下逛任天堂直营店（如 Nintendo NEW YORK、Nintendo SAN FRANCISCO）或参加官方活动时，可以在应用里打卡拿白金点数，打卡入口也在登录后的个人页；打卡拿到的点数和账号里积累的点数，都可以用来兑换 My Nintendo 奖励（限定壁纸、实物周边一类的兑换品，具体以官方奖励页面为准）；
- 登录遇到账号或地区相关的异常，对照 [常见问题与故障排查.md](常见问题与故障排查.md) 逐条排查。
