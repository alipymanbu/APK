## 一、不登录能用哪些功能

heibai弹幕对登录的要求是分功能的：

| 功能 | 要不要登录 |
| --- | --- |
| 浏览番剧、在线观看、试看 | 不需要 |
| 弹幕互动、播放设置 | 不需要 |
| 投屏到电视 | 不需要 |
| 离线缓存下载 | 需要 |
| 跨设备同步观看记录、更新提醒 | 需要 |

也就是说，只想在线看，装完直接用；想缓存到手机离线看，才需要先把账号注册好。

## 二、注册与登录步骤

1. 打开应用，点右下角**「我的」**；
2. 在个人信息页点**「登录/注册」**；
3. 在注册页填写相关信息，走完流程即完成注册；
4. 之后在同一入口登录即可。

注册入口在哪个版本里都是「我的 → 登录/注册」这条路径，照着找就行。

登录不上时先查这两处：一是账号或密码输错，用找回密码功能重置后再登；二是网络不稳，换一个网络环境（Wi-Fi 与流量互换）、重启应用后再试。都排除还登不上，就等一段时间再试，多为服务端临时问题。

## 三、收藏与更新提醒

登录后追番的主要动作是**收藏**：

1. 在[首页导览与找番方法.md](首页导览与找番方法.md)里找到想追的作品，进详情页；
2. 点**收藏**，作品进入你的追番列表；
3. 剧集更新后，应用会推送通知提醒你（部分版本需要在系统设置里允许该应用发通知，否则收不到）。

收藏列表同时会**自动记录观看进度**：看到第几集、看到哪个时间点，下次点开从进度处接着看，不用手动记。

## 四、观看记录与多设备

登录账号后，观看记录和收藏列表会同步到云端：换手机、平板上再装一个，登录同一账号，追番进度能接上。第三方介绍还提到应用支持多终端数据互通，具体覆盖哪些端以实际版本为准。

- 换机/重装前不用手动备份，登录状态本身就是备份；
- 重装后找不到记录时，先确认登录的是**同一个账号**；
- 没登录状态下看的内容，进度只存在本机，卸载就没了——想留进度就在卸载前登录并收藏。

## 五、登录后的下载功能

注册好账号之后，「下载」入口才会开放，缓存步骤在[投屏与离线缓存.md](投屏与离线缓存.md)。账号异常、收不到验证信息这类问题，先检查网络，再退出登录重新登录一次。
