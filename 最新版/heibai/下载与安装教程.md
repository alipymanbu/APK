## 一、先弄清你手里这版是什么

heibai弹幕（也常被叫作「黑白弹幕」）是一款面向安卓设备的动漫追番应用，聚合番剧资源并带弹幕互动。它的安装包通过网盘等渠道分发，装之前先确认手里这份包的信息。

本文涉及的安装包信息如下：

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.5.3.8 |
| 包名 | com.heibaitanmu.app |
| 安装包大小 | 37.75 MB |
| MD5 | 441d31fc4b12c3b643b488338303467c |

两点提醒：

- 网上各分发页显示的版本更新得快（截至 2026-09 已能看到 1.5.7.1 及更高的标注），与网盘里这份不一定是同一个版本。版本不同不影响本文的安装步骤；各版本都改了什么、要不要升级，见[版本更新日志与升级.md](版本更新日志与升级.md)。
- 不同分发页标注的包名并不一致（能见到 `com.heibaitanmu.app` 与 `com.mg.tool.p3` 两种标注）。包名不同意味着**无法互相覆盖升级**——如果手机上已经装过另一渠道的版本，遇到「签名冲突 / 无法安装」时，先卸载旧版再装。

## 二、从网盘获取安装文件

heibai弹幕 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/b113fd5e1512](https://pan.quark.cn/s/b113fd5e1512)

获取步骤：

1. 手机或电脑上打开上面的链接；
2. 选择「保存到我的网盘」（需要登录夸克账号，没有就现场注册一个）；
3. 转存完成后，在夸克网盘 App 里找到这个 APK 文件，点「下载」；
4. 下载完成后直接点文件即可拉起安装（部分机型会先让你选「用其他应用打开」）。

如果你想先核对文件完整性：安装包的 MD5 见第一节表格，可用「MD5 校验」类小工具比对本地的值。

## 三、安装步骤

1. 点开下载好的 APK 文件；
2. 系统弹出「不允许安装未知应用」提示时，点「设置」，给夸克网盘（或你用来打开文件的应用）勾选「允许安装未知应用」，返回继续；
3. 点「安装」，等待完成；
4. 安装完可以在桌面打开，首次启动会加载资源列表，稍等片刻进入首页。

各品牌手机允许未知来源安装的入口略有差异，找不到时可以直接在系统设置里搜「未知来源」或「安装未知应用」。

系统要求方面：这是一款安卓应用；各分发页对最低系统版本的标注并不统一（Android 4.x 到 5.x 都有出现），以你手机实际能否安装为准。

## 四、安装失败怎么处理

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「签名冲突」或无法覆盖安装 | 手机上已有另一个渠道的同名应用，包名/签名不同 | 卸载已有版本后重装 |
| 提示「解析包失败」 | 下载不完整、文件损坏 | 重新从网盘下载一次；必要时核对 MD5 |
| 提示存储空间不足 | 手机剩余空间小于安装包体积的数倍 | 清理空间后重试 |
| 安装按钮置灰 | 未授予「安装未知应用」权限 | 回到第三节第 2 步补授权 |
| 装上后闪退 | 系统版本过低或机型兼容问题 | 换更新的安卓系统版本再试；仍闪退可参考[换源与播放问题排查.md](换源与播放问题排查.md)的通用排查思路 |

装好之后从哪开始用，看[首页导览与找番方法.md](首页导览与找番方法.md)；发弹幕、调倍速这些播放里的设置见[弹幕与播放设置.md](弹幕与播放设置.md)。
