## 一、投屏：把手机画面放到电视上

投屏的前提只有一个：**手机和电视/电视盒子/投影仪连的是同一个 Wi-Fi**。

步骤：

1. 打开想看的作品，进入播放页并开始播放；
2. 点播放界面（右上角或右下角）的**投屏图标**（TV 字样图标）；
3. 等应用搜索同一网络下的设备，列表出来后点你的电视/投影；
4. 连接成功后画面同步到大屏，手机可以继续选集、调进度。

投屏功能**不需要注册登录**，装好就能用。

投屏搜不到设备时按顺序检查：

| 检查项 | 说明 |
| --- | --- |
| 是否同一 Wi-Fi | 手机用了流量、或连了访客网络都会搜不到 |
| 路由器是否开了 AP 隔离 | 部分路由器默认隔离设备间通信，关掉再试 |
| 电视端投屏服务是否开启 | 部分电视要在设置里手动打开「投屏/多屏互动」开关 |
| 设备是否太老 | 只支持特定协议的老电视可能搜不到，换支持 DLNA/乐播类协议的设备 |

## 二、离线缓存：下载到手机没网也能看

通勤、出门没网的场景用缓存功能。注意：**缓存下载需要先登录账号**（与投屏不同），注册登录的步骤见[注册登录与追番管理.md](注册登录与追番管理.md)。

缓存步骤：

1. 进入想下载的作品播放页；
2. 点播放界面下方的**下载**选项；
3. 勾选要缓存的集数（可单集，也可全选整季）；
4. 点「缓存」，任务自动排队下载。

部分版本在勾选集数这一步还能选缓存画质：高画质体积大、低画质省空间，按手机剩余空间取舍。

下载的内容在**下载列表**里管理：查看进度、看已完成的剧集都在这里；缓存文件保存在手机存储的应用目录下，在应用内播放，不占用网盘或外部播放器。

## 三、缓存占空间了怎么办

缓存是整包视频文件，一季下来体积不小：

- 看完的剧集及时在下载列表里删除，腾出空间；
- 批量缓存前先看一眼剩余存储空间，避免下到一半失败；
- 缓存损坏无法播放时，删掉对应剧集重新缓存一次即可。

## 四、投屏和缓存之外的播放问题

投屏卡顿多与网络带宽有关，缓存失败多与存储空间有关；如果是视频源本身加载失败、切换线路的问题，见[换源与播放问题排查.md](换源与播放问题排查.md)。
