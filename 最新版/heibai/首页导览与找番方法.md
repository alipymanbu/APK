## 一、首页上有什么

打开应用、等资源列表加载完，进入首页。首页大体是这么几块：

| 入口 | 用途 |
| --- | --- |
| 推荐位 | 当前热门作品的展示位，没目标时可以直接从这里挑 |
| 分类按钮（多在页面上方或右上角） | 按题材、地区、更新状态（连载中 / 已完结）等维度筛选 |
| 排行榜 | 实时更新的热门榜单，用来找「大家在看什么」 |
| 排期表 | 按日期列出当天更新的番剧，追连载时最常用 |
| 搜索框 | 知道名字时最快的入口 |

浏览方式就是普通的上下滑动；点任何一部作品都会进入详情页，详情页里可以直接开始播放。

## 二、用排期表追连载

追新番的关键入口是排期表：

1. 首页点开「排期表」（有的版本叫「今日更新」）；
2. 切到今天的日期，能看到当天有哪些番更新；
3. 点进对应作品直接看最新一集。

配合「收藏 + 更新提醒」使用效果最好——收藏之后剧集更新会推送通知，不用每天手动翻排期表，具体见[注册登录与追番管理.md](注册登录与追番管理.md)。

## 三、分类筛选的思路

不知道看什么、只知道「想看某种类型」时，走分类：

- 按**地区**分：日漫、国漫、美漫等，各分发页的介绍都提到收录范围覆盖这几类；
- 按**状态**分：连载中 / 已完结，补老番时选「已完结」可以一口气看完，不用等更；
- 按**题材**分：热血、恋爱、科幻、冒险、搞笑等；
- 另有「新番 / 高分 / 剧场版」这类独立栏目，剧场版（动画电影）单独归在一起，找起来更直接；「高分」栏则省去了自己甄别的功夫。

同一部作品往往在几个分类下都能出现，从哪个入口进去都一样。

## 四、搜索技巧

搜索框支持按作品名找：

- 输入**作品名的常用译名**更容易命中，一部作品常有多个译名，一个搜不到就换另一个；
- 名字记不全时，输入能想起的**关键字**片段即可；
- 搜出来如果结果太多，先看封面和更新状态（连载中/完结）再点进去。

## 五、进详情页之后

详情页能看到作品简介、剧集列表和播放入口，往下几件事也都在这里发生：

- 直接点剧集开始播放，播放中的弹幕和倍速设置见[弹幕与播放设置.md](弹幕与播放设置.md)；
- 播放页可以切线路、投屏、缓存，见[投屏与离线缓存.md](投屏与离线缓存.md)和[换源与播放问题排查.md](换源与播放问题排查.md)；
- 点收藏加入追番列表，之后有更新提醒。
