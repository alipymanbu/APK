# Fizzo 看小说拿金币与提现是怎么回事

> 网上流传「用 Fizzo 看小说能提现到电子钱包」。这件事部分属实，但边界很清楚：它是地区性运营活动、规则随时会调、收益量级很小。本篇把能确认的部分和不能确认的部分分开写清楚。

## 一、先弄清它是什么性质的东西

Fizzo 除了免费阅读和付费订阅之外，在**部分市场**还跑着一套阅读奖励机制：读得越久、做得越多，积累的虚拟金币越多，金币再折算成本地货币提到电子钱包里。

三条前提要说在前面：

- **地区性**：这套玩法明显集中在东南亚市场，尤其印尼，评测、用户晒单、提现截图基本都是印尼语内容。换一个市场，同样的界面里未必有这个入口。
- **非官方承诺**：Fizzo 的服务条款里写的是「部分服务免费、部分需要付费」，条款并没有承诺任何阅读返现。奖励属于运营活动，不属于产品功能承诺。
- **规则可变**：多个用户反馈单位时间给的金币在减少，说明这套规则一直在被调整。

## 二、金币从哪儿来

多个印尼本地评测给出的获取途径高度一致，可以放心作为「有哪些途径」来参考：

| 途径 | 说明 |
| --- | --- |
| 阅读时长 | 打开书页后累积，按分钟计 |
| 每日签到 | 每天登录领一次，通常有连续签到的加成 |
| 看广告 | 看完一段激励视频得金币 |
| 每日/每周任务 | 完成指定的阅读或互动任务 |
| 邀请好友 | 被邀请的人需要保持一段时间活跃才算有效 |
| 抽奖类玩法 | 用金币或免费次数参与 |

阅读页上那个转圈的圆形指示（通常带金币图标）就是按阅读时长累积用的，**它不是阅读进度条**。看到它一直转是正常的。

## 三、折算与提现

这一节的信息**确定度低于上一节**，请按下面的口径理解：

- 金币会折算成当地货币再提现，折算比例、每日上限、提现门槛由应用内规则决定，**不同时间、不同账号看到的不一样**；
- 有印尼评测给出过「10 金币折 1 印尼盾」的具体换算，但这是**单一来源**，没有第二个独立来源印证，只能当作量级参考；
- 提现通道是当地的电子钱包与银行转账（印尼常见的是 DANA、OVO、GoPay、ShopeePay 这一类），**中国大陆的支付渠道不在其中**；
- 有用户反馈首次提现门槛较低、后续会提高，同样属于单一来源的二手说法。

## 四、收益量级：把预期放低

把上面几节合起来看，实际收益的量级是这样的：

- 按多个印尼用户的晒单，「每天读一到两小时，一个月攒下来的钱够买话费或流量」是比较接近真实的描述；
- 同一批用户里也有人反馈单位时间给的金币从早期的 2500 降到 1500 甚至更低，也就是说**阅读越久不等于线性增长**；
- 邀请好友的收益高于自己读，但这属于拉新活动的常规设计，不是内容消费带来的。

一句话：**把它当阅读的附带小活动，别当收入来源。** 为了提现而增加阅读时长，性价比远不如把时间花在别处。

## 五、规则随时会变，以应用内为准

奖励机制的参数（每档给多少、折算比例、任务内容、提现上限）**会频繁调整**，任何写死数字的教程都会很快过时。要确认当前情况，只看两个地方：

1. 应用内的任务/奖励页面，那里的数值就是当前生效的值；
2. 官方服务条款与商店页面的说明，用来看有没有整体性的政策变化。

## 六、国内用户怎么判断自己用不用得上

按这个顺序看，不用去猜：

1. **入口在不在**：在应用里找不到任务、签到、金币这类入口，说明你这个地区没开这套活动，到此为止。
2. **提现通道对不对得上**：只支持当地电子钱包和当地银行转账，如果你没有对应的收款方式，金币再多也提不出来。
3. **账号年龄设置**：这类活动通常有年龄门槛，账号的年龄设置不满足时相关内容不显示。

前两条任一不满足，这套玩法对你就是无效的——这不影响你用 Fizzo 读小说，只是别为它花额外精力。

## 七、和「付费解锁章节」不是一回事

读者容易把两件事混起来：

| | 金币奖励 | 付费内容 |
| --- | --- | --- |
| 方向 | 应用给你 | 你给应用 |
| 目的 | 激励阅读与留存，属运营活动 | 获取未解锁的章节或订阅权益 |
| 依据 | 应用内的任务与奖励规则 | 官方服务条款里的 Premium Services |

关于付费与订阅的退订方式，见 [常见问题与排查.md](常见问题与排查.md) 第六节。两者互不抵扣，金币不能用来替代订阅。
