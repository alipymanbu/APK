# Fizzo 阅读设置与翻页模式怎么调

> 阅读页是 Fizzo 里停留时间最长的地方，字号、背景、亮度、翻页方式这些都在同一个菜单里。本篇讲菜单怎么唤出、每一项具体调什么、日间夜间主题怎么切，以及听书功能的用法与边界。

## 一、设置菜单怎么唤出来

进入任意一本书的阅读页之后，**轻点屏幕中央**（不要点到边缘，边缘通常留给翻页），正文上下会浮出控制层：顶部一般是返回、书名、目录和更多，底部是进度条与设置入口。设置入口的图标通常是齿轮或一个「Aa」字样，点它才展开下面这些项。

如果点了没反应，先确认不是在翻页动画进行中；再不行退到目录页重新进一次。这个菜单是浮层，**点正文空白处通常就能收起**，不需要按返回键退出阅读。

## 二、可以调的项一览

| 设置项 | 作用 | 什么情况下值得动 |
| --- | --- | --- |
| 字号 | 正文字号大小 | 小屏手机默认字号偏小，调大一到两档更省眼 |
| 字体 | 正文使用的字体 | 看习惯，衬线体读长文更稳，无衬线体在屏幕上更清晰 |
| 行距 / 段距 | 行与行、段与段之间的留白 | 长段落多的小说，加大行距能明显降低串行 |
| 页边距 | 正文距屏幕边缘的留白 | 曲面屏或窄边框手机容易误触，加大页边距 |
| 背景色 | 纸张底色 | 夜间或暗光环境下换成深色或暖色底 |
| 亮度 | 阅读页内的亮度 | 只想调阅读页、不想动整机亮度时用它 |
| 翻页方式 | 滑动 / 上下滚动等 | 追更类长文用滚动更顺，短篇用整页更整齐 |

不同版本里这些项的命名会有出入（有的写「排版」，有的写「阅读设置」），但能调的东西基本是这几类。改完不需要确认保存，退出菜单即生效。

另外，阅读页顶部某些版本会出现一个**带金币图标的圆形转圈指示**。它不是阅读进度条，而是按阅读时长累积奖励用的，盯着它没有意义。这套机制的说明见 [看小说拿金币与提现是怎么回事.md](看小说拿金币与提现是怎么回事.md)。

## 三、日间与夜间主题

阅读页有浅色与深色两套主题，切深色后正文变浅、底色变暗。有两点容易踩：

- **应用内主题和手机的深色模式不是同一件事。** 系统切到深色，阅读页未必跟着变；反过来也一样。想在夜间得到深色阅读页，建议直接在阅读设置里切，比依赖系统同步更稳。
- **深色底 + 高亮度最伤眼。** 切完深色主题后回头把阅读亮度降下来，效果才出来。

## 四、听书（朗读）怎么用

阅读页上有一个耳机形状的图标，点它会把当前内容念出来，官方把这个功能称为有声书（audiobook），也就是常说的听书或朗读。实际使用上有几条边界要知道：

- 它朗读的是**你正在打开的内容**，不是整本书的后台播放；想听后面的章节得先翻到、缓存到那部分。
- 语音是合成的，语速和音色按当地语言朗读；正文里混排的非该语言词句念出来会比较生硬。
- 需要联网才能拿到内容和语音资源。想彻底离线听，要先把对应章节下载下来，见 [离线下载与书架管理.md](离线下载与书架管理.md)。
- 蓝牙耳机、车机这类设备走的是系统音频通道，切歌键未必能控制朗读的暂停与继续，以你设备实际的表现为准。

## 五、几个实际取舍

- **滚动 vs 翻页**：上下滚动不会打断视线，适合长时间读连载；整页翻页能看清章节边界，适合一次读一章的短篇。
- **大字号 + 大行距**：两者一起加大，一屏能放的字会明显变少，翻页次数变多。别一次全拉满，先调字号、不够再加行距。
- **亮度别靠系统自动亮度**：自动亮度在夜间会来回跳，用阅读页里的独立亮度更稳定。
- **截图与分享**：正文截图是本机行为，不经过账号。

## 六、设置会不会跟着账号同步

阅读页的字号、背景、主题这类偏好，**通常在本地保存**，未必跟着账号走。这意味着：

- 换一台设备登录同一账号，书架和进度能回来，但排版设置一般要重新调一遍；
- 卸载重装也会把这些偏好清掉；
- 如果同一次安装里换了登录账号，排版设置不会互相影响。

书架与进度的同步规则是另一套机制，见 [账号登录与多设备同步.md](账号登录与多设备同步.md)。
