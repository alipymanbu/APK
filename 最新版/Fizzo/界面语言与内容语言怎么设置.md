# Fizzo 界面语言与内容语言怎么设置

> 装完 Fizzo 最先要解决的是「看不看得懂」这个问题。本篇分开讲两件容易被混为一谈的事：界面语言在哪里改，以及 Fizzo 的书库到底以什么语言为主——第二件事比第一件更影响你的实际体验。

## 一、界面语言和内容语言是两件事

先把概念分清楚，能省掉很多「改了也没用」的困惑：

| | 界面语言 | 内容语言 |
| --- | --- | --- |
| 指什么 | 菜单、按钮、设置项显示成哪种语言 | 小说正文本身是哪种语言 |
| 能不能改 | 能，应用内设置里可以选 | 不能「改」，只能通过筛选和搜索去找 |
| 改完的效果 | 你操作起来顺手了 | 不会平白多出中文小说 |

把界面切成英文或别的语言，**不会**让书库多出对应的语种内容。这两条要分开解决。

## 二、Fizzo 的内容语言是什么定位

这一点官方说得很直接。官方站点的原话是：**MyTopia 是英语阅读平台，Fizzo 是面向其他语言的阅读平台**，两者共用同一套作者后台。也就是说：

- 想看**英文**内容，官方指向的是另一个应用 MyTopia，而不是 Fizzo；
- Fizzo 的主体是**非英语市场**，覆盖印尼、泰国、越南、西班牙语、葡萄牙语、阿拉伯语等地区；
- 官方商店页面上，Fizzo 长期以「印尼排名第一的小说应用」作为自我描述，热门榜上大量书名是印尼语。

App Store 的语言列表也印证了这个范围：应用支持的语言为英语、西班牙语、印尼语、葡萄牙语。

关于书库到底有哪些语种，官方口径与第三方评测并不完全一致，两边都列出来，你自己判断：

- **官方口径**：英语内容归 MyTopia，Fizzo 服务其他语言；
- **第三方评测口径**：有印尼本地评测把「多语言」列为 Fizzo 的特点，具体点名的语种是**印尼语与英语**两种。

两者不冲突的部分是：**主战场是当地语言，不是中文。**

**对中文读者的现实结论**：Fizzo 不是中文书库，它的价值在于能直接看到这些语种的原创连载，而不是「换个壳子看国内网文」。你不能指望在这里搜到中文小说的完整书库；能不能搜到个别中文标题，以你在应用内实际搜索的结果为准，官方渠道没有把中文列为支持语言。

## 三、怎么改界面语言

Fizzo 从 2.3.5 版开始提供了应用内语言设置，5.2.6 也带着这个入口。路径上，先找到「我的 / 个人中心」这一栏，再进设置：

1. 打开 Fizzo，切到底部导航最右侧的个人中心页。
2. 找到设置入口（齿轮图标或 Settings 字样）。
3. 在设置里找语言项，名称一般是 Language 或语言，点进去选你要的语种。
4. 选完界面会即时刷新；个别页面的文案会等到下次启动才跟着变。

**如果界面已经是看不懂的语言怎么办**：选项列表里通常同时显示语言的自称（例如 Bahasa Indonesia、Português、Español、English），照这些词找就行，不需要先看懂当前界面。另一个办法是进手机系统设置里的「应用 > Fizzo > 语言」（Android 13 及以上支持单独给某个应用指定语言），从系统侧指定一次。

## 四、语言选完还是看不到想看的内容

判断顺序按下面走，别急着卸载重装：

1. **先确认你找的是哪一类内容。** 前面第二节说过，Fizzo 的定位是当地语言原创。如果目标本来就是中文内容，那不叫「设置不对」，而是这个应用不提供。
2. **用搜索而不是首页翻。** 首页推的是你所在地区的热门，未必合你口味；想找特定题材或书名，直接搜更快。
3. **确认账号所在区域。** 推荐位和可见书库跟地区有关，同一账号在不同地区看到的内容会有差异；这一条会随你的账号设置变化，具体以应用内显示为准。
4. **确认不是被内容分级挡住。** 涉及成人向题材的作品可能受年龄设置限制，见 [常见问题与排查.md](常见问题与排查.md) 第五节第 3 条。

## 五、短剧的语言是另一套

Fizzo 里除小说之外还有短剧，而短剧的语言问题比小说更麻烦：

- 短剧是**原声**，能不能看懂取决于该剧有没有配你要的语言的字幕；
- 界面语言换成英语，**不会**自动给短剧配上英语字幕；
- 部分剧字是硬字幕，直接印在画面上，关不掉。

所以选语言时要有预期：语言设置解决的是「菜单看不看得懂」，解决不了「剧听不听得懂」。短剧这块的完整说明见 [短剧怎么看.md](短剧怎么看.md)。

## 六、和国内版番茄小说的关系

两边的客户端、账号、书库都不是一套：

- 国内版番茄小说的账号登录不进去 Fizzo，反之亦然；
- 同一本书在两边可能上架、也可能不上架，进度和书架不互通；
- 主题和推荐算法逻辑相近，但内容供给是各自独立维护的。

把 Fizzo 当成一个平行的、面向海外市场的阅读应用来看，比较不容易踩「为什么我的书架是空的」这类坑——按 [账号登录与多设备同步.md](账号登录与多设备同步.md) 里的说明登录自己的 Fizzo 账号即可。
