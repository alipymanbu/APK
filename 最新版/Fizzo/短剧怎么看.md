## 一、Fizzo 里确实有短剧

这一点在官方渠道的自我描述里写得很清楚：商店介绍中提到应用内既有小说也有短剧，并且把阅读页形容为「小说与短剧的阅读页」。所以装完之后看不到小说之外的东西，通常不是装错了版本，而是入口没找到，或者你的地区没有这一块内容。

两者的差别大致是这样：

| | 小说 | 短剧 |
| --- | --- | --- |
| 形态 | 文字连载，篇幅长 | 竖屏视频，单集短、连续追 |
| 消费方式 | 读，或用朗读功能听 | 看 |
| 时间成本 | 一次读很久 | 单集几分钟，碎片时间 |
| 入口 | 首页、分类、搜索 | 首页/发现页的短剧类目，或搜索 |

## 二、短剧专区在哪

按 5.2.6 的常见布局，位置在两处：

1. **首页或发现页的类目栏**里会有一个专门的短剧分类，名称随应用语言变化（英文界面下一般是 Drama 或 Shorts 一类），横向滑动类目栏就能看到。
2. **搜索**：直接搜剧名或「drama」这类关键词，比在类目里翻更快找到。

如果两处都找不到，见第七节。

## 三、看短剧需要什么

| 条件 | 说明 |
| --- | --- |
| 网络 | 短剧是流媒体，**必须联网**；小说那套离线下载不能直接套到视频上 |
| 网速 | 竖屏短视频比读文字更吃带宽，网络不稳时会先卡后自动降清晰度 |
| 流量 | 消耗明显高于看小说，一集几分钟的量级，用移动数据看要留意套餐 |
| 账号 | 不登录也能看一部分；收藏、进度、追剧这类要跟着账号走 |

## 四、字幕和音轨跟语言设置有关

短剧的原声一般是内容本地区的语言。字幕是否出现、以哪种语言出现，跟你在应用里选的语言有关：

- 把界面语言换成英语，**不代表**所有短剧都配好了英语字幕，是否提供字幕取决于该剧本身；
- 部分剧集本身带硬字幕（直接烧在画面里），这类没法关；
- 没有字幕的剧，只能靠原声听——这也是为什么 Fizzo 的短剧对非当地语种用户的门槛比小说高。

语言设置怎么改，见 [界面语言与内容语言怎么设置.md](界面语言与内容语言怎么设置.md)。

## 五、短剧库比小说更挑地区

小说你还能靠搜索碰运气找到，短剧的版权和上架范围卡得更紧：同一账号在不同地区看到能看的剧集数量会有明显差异，一些剧可能只对特定市场开放。判断办法只有一个——在你自己的账号和网络环境下打开短剧类目看实际有多少可播，别照搬别人的截图。

## 六、别把它和 Melolo 混为一谈

字节在海外另有一款专门做短剧的应用 Melolo（2024 年底先在印尼、菲律宾上线）。两者容易出现混淆：

- **Fizzo** 是阅读平台，短剧是它内容的一部分，入口在 Fizzo 应用内部；
- **Melolo** 是独立的短剧应用，需要另行安装，账号体系与 Fizzo 不是一回事。

网上不少「Fizzo 短剧」的说法其实指的是 Melolo，看教程时留意对方说的是哪个应用。

## 七、找不到短剧入口怎么办

按顺序排：

1. **确认版本**：较早的版本可能还没有短剧模块，更新到较新版本再看。
2. **确认地区**：短剧显著受地区影响，这是最常见的原因，且没法靠设置绕过。
3. **换语言试一次**：个别情况下类目名称会随界面语言变化，改成英文更容易认出 Drama 入口。
4. **确认网络可达**：短剧列表本身就是联网拉取的，网络到不了服务时那里会是空的——这一点和小说加载失败是同一个原因，见 [常见问题与排查.md](常见问题与排查.md) 第一节。
