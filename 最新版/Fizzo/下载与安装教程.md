## 一、先认清楚要装的是哪一个 Fizzo

同名或近名的阅读类应用在应用市场里不止一个，装错版本最典型的后果是：登录进去发现书库对不上、或者干脆连不上服务。按下面两条认，比按图标认可靠。

| 认法 | 该对上的值 |
| --- | --- |
| 安卓包名 | `e.books.reading.apps` |
| 应用内显示的品牌名 | Fizzo |

关于这个名字本身，有几点值得先说明：

- Fizzo 是番茄小说的**海外版**，面向东南亚、拉美、中东等市场，运营主体是新加坡的 Poligon Pte. Ltd.，与国内版的番茄小说不是同一个客户端。
- 同一款应用在不同商店里的完整名称不一样：Google Play 上叫 **Fizzo - Novel & Drama**，App Store 上叫 **Fizzo - Read Good Novels**。名称差异不代表是两个软件，看包名最准。
- 官方有一个面向作者的站点 `https://fizzo.org`，用来说明投稿、合约与收益规则；它不是读者侧的下载页。

**这批安装文件的事实**（网上搜到的是官方最新版，与这里不是同一版，写文档一律以这一版为准）：

| 项目 | 值 |
| --- | --- |
| 版本号 | 5.2.6 |
| 包名 | `e.books.reading.apps` |
| 安装包大小 | 106.12 MB |
| MD5 | `2718D3D5179C1DD671EA761F34E8A911` |
| 以上信息核对于 | 2026-09-23 |

官方商店上的版本号一直在往前走，所以「你手机里装的 5.2.6」和「今天商店里的最新版」不是同一版是正常的。功能位置大体一致，但个别菜单的叫法可能不同，下面涉及界面路径的地方都以 5.2.6 为准来描述。

## 二、Fizzo 支持哪些设备

| 平台 | 有没有客户端 | 说明 |
| --- | --- | --- |
| Android 手机 / 平板 | 有 | 这批网盘资源就是安卓安装包 |
| iPhone / iPad | 有 | 要去 App Store 装，网盘里这份 APK 用不上 |
| Windows / macOS 桌面版 | 没有 | 想在电脑上用，只能装安卓模拟器，再把这份 APK 装进模拟器 |
| 浏览器网页版 | 没有 | 官方站点 `https://fizzo.org` 是给作者投稿用的，不提供在浏览器里看书的入口 |

安卓系统的版本要求，不同渠道标注并不一致（有的写 Android 6.0 及以上，有的写 7.0 及以上），以你打开商店页面时显示的为准。从实践角度，**系统越旧越容易在启动或播放音频时出问题**，如果你的手机还在 Android 6 附近，做好「装了但用不顺」的心理准备。

## 三、安装步骤（安卓手机）

先把安装包从网盘取到手机，再走本地安装：

1. 打开 [Fizzo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/892ded071a7c)，转存到自己网盘后下载 APK 到手机（建议下到「下载」目录，好找）。
2. 用手机自带的「文件管理」进到下载目录，找到这个 APK 文件，点它。
3. 系统第一次会拦一道，提示「出于安全考虑，禁止安装未知来源应用」。按提示进设置，把**当前这个应用**（文件管理器或浏览器）的「允许安装未知应用」打开，然后返回重试。
4. 核对一下文件对不对：文件大小应在 106 MB 左右。
5. 点「安装」，等进度条走完。
6. 装完先**不要**急着打开，先按下一节把网络准备好。

想更严谨一点，可以在电脑上核对文件的 MD5。Windows PowerShell 里对下载好的文件执行：

```powershell
Get-FileHash "Fizzo_v5.2.6.apk" -Algorithm MD5
```

输出的哈希值应当是 `2718D3D5179C1DD671EA761F34E8A911`。**不一致说明文件下载不完整或不是这份文件**，别装，重新下载一次。

## 四、第一次打开前要准备好的事

这一步比安装本身更容易卡住人。Fizzo 的服务面向海外市场，**在国内网络环境下直连，常见的结果是停在启动页转圈、或者一直登录不上**——这不是安装失败，也不是手机的问题，是服务可达性问题。

所以第一次打开之前：

- 确认你的网络能正常访问境外服务（是否有可用的网络环境，取决于你自己的上网条件）；
- 如果手机上装着代理类工具，确保它对 Fizzo 也生效，而不是只对浏览器生效；
- 别在「安装完成」页直接点打开就下结论，先给应用十来秒加载时间。

## 五、第一次打开会看到什么

按 5.2.6 的顺序，大致是这几步：

1. **服务条款与隐私政策弹窗**。要往下走就得先同意；不同意则无法使用，这是应用本身的机制。
2. **语言选择**。Fizzo 的界面语言可以自己选，也可以之后在设置里改——如果这一步选错了、界面变成了看不懂的语言，按 [界面语言与内容语言怎么设置.md](界面语言与内容语言怎么设置.md) 改回来。
3. **登录或跳过**。不登录也能先浏览和试读，但书架、阅读进度这些要跟着账号走，跳过登录就意味着换设备后这些东西带不走，详见 [账号登录与多设备同步.md](账号登录与多设备同步.md)。
4. **进入首页推荐流**。首页以推荐和榜单为主，想按类型找书走分类标签或搜索。

## 六、装不上、装完打不开的几种情况

| 现象 | 常见原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 安装包下载不完整 | 按第三节的 MD5 核对，重新下载 |
| 提示「应用未安装」 | 系统版本过低，或与已装的应用签名冲突 | 先卸载手机上已有的同包名应用，再重装 |
| 提示冲突、无法覆盖安装 | 已装过 Fizzo 的其他来源版本 | 卸载旧版后重装；卸载前留意进度是否会丢（见 [账号登录与多设备同步.md](账号登录与多设备同步.md)） |
| 装完点图标没反应 / 闪退 | 权限被安全软件拦、缓存异常 | 见 [常见问题与排查.md](常见问题与排查.md) 第二节 |
| 一直停在启动页转圈 | 网络到不了 Fizzo 的服务 | 见第四节，先解决网络可达性 |

系统的「纯净模式」「应用安全检测」这类功能在部分国产系统上默认开启，会阻止非应用商店来源的安装。遇到装到一半被拦，去手机设置里临时关掉再装，装完可以开回来。
