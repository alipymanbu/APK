# Ktown4u 下单购买流程

> 本篇讲在 Ktown4u 上把一件商品从加购走到付款的完整过程：下单五步、能用哪些支付方式、下单后哪些东西改不了、优惠券和积分怎么用。

## 一、下单前备好三样东西

| 要准备 | 说明 |
| --- | --- |
| 账号 | 邮箱注册即可，App 和官网账号通用；没装的先看[下载与安装教程.md](下载与安装教程.md) |
| 收货信息 | 收件人、电话、详细地址、邮编；转运用户填转运仓地址 |
| 支付方式 | 见本篇第三节，三种渠道按自己有的选 |

地址在**下单时就要填对**：发货后改不了，派件失败的包裹处理起来很折腾。

## 二、下单五步

官方给的流程就是这五步，App 和网站一致：

1. **加购**：把想要的商品加进购物车。想买多件一起发运的，必须在**同一个订单**里加齐——两个订单没法合并发货。
2. **结算**：确认商品和数量，进结账流程。
3. **填地址**：填写收货信息，点继续。
4. **选运输方式**：按目的地给出可选项（DHL、UPS、EMS、顺丰航空等），不同方式时效和费用差很多，见[物流跟踪与收货问题.md](物流跟踪与收货问题.md)。
5. **确认运输须知并付款**：最后有个 Shipping Notice 环节，把选项确认完再付钱。

运费在这一步就能看到确切数字：它按运输方式加包裹重量计算，你把地址填完，最终运费就会显示出来，不用自己估。

## 三、支付方式

官方支持的付款渠道有三种：

| 支付方式 | 适合谁 | 注意 |
| --- | --- | --- |
| PayPal | 有 PayPal 账号的人 | 退款只能原路退回 PayPal，不能改退到别的账户 |
| 信用卡 | 有 Visa / Mastercard 等国际卡组织标识的银行卡 | 大部分付款失败出在卡的状态上：确认卡没被冻结、额度够、开了境外线上支付 |
| 支付宝 | 国内用户最省事的选择 | 不用办国际卡 |

付款环节卡住时的处理顺序：换一个支付方式试 → 换浏览器或网络环境再试 → 还不行就截图找客服（网站右下角对话气泡 → CS 中心）。钱扣了但订单还是「待付款」状态的情况也有：这通常是发卡行还没放行扣款，拿 PayPal 里的交易 ID 去问发卡行。

付款成功却没收到确认邮件：先查垃圾邮件箱，再去「我的账户 → 订单记录」看，那边有记录就是付成功了。

## 四、下单后哪些改不了

这几条是官方规则里明确写死的，下单前想清楚：

- **数量不能改**：下单后想多买少买一件，只能整单取消再重新下。
- **Random 版不能挑版本**：标注 random 的专辑（随机版本发货），下单时挑不了具体款式，收到什么算什么；想挑版本就买标注了具体版本的商品。
- **付款方式不能中途换**：已经付完款的订单，只能取消后重新下单才能换支付方式。
- **状态过了就不能取消**：订单状态走到「发货中（On Shipping）」就取消不了了，能申请取消的状态只有待付款、备货中、待发货三种；取消窗口、退款到账时间的完整口径见[取消订单与退款规则.md](取消订单与退款规则.md)。
- **取消和修改要看状态**：商家缺货或厂家原因延迟发货的可能性是存在的，缺货会发邮件通知，也可以自己在网站上搜商品看状态。

## 五、优惠券与里程积分

**优惠券**：

- 领：官方常在活动页（Event）挂每月券包一类的活动，活动期内领取，规则以活动页为准；
- 查：自己手里有哪些券，在「我的页面 → Mileage/Coupon → Coupon」里看；
- 用：结账流程第 4 步（Shipping Notice 那一步）有 **Coupon 按钮**，点开选一张即可，付款前生效。

**里程积分（Mileage）**：

- 商品页标注的 Mileage 数值就是这笔订单能积的分数（以页面显示为准）；
- 积分可以抵货款，抵扣顺序是**先抵商品价、再抵运费**；
- 多笔积分并存时，**先到期的先用**，同一天到期则先攒的先用；
- 每笔订单能用多少积分有上限，个别商品或会员等级可能被限制使用，以结账页实际显示为准；
- 积分**不能换现金**，退款时也不会按现金退给你。

## 六、订单状态去哪看

「我的账户 → 订单记录」是唯一权威入口：付款是否成功、有没有含特典、发货没有、快递单号，全在这里查。等发货期间的状态变化也看这里，不用反复问客服。

下单只是第一步，货什么时候发、路上走多久，都在[物流跟踪与收货问题.md](物流跟踪与收货问题.md)里讲；蹲预售和特典的玩法在[预售与特典怎么玩.md](预售与特典怎么玩.md)。
