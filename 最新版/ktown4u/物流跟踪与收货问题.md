## 一、运输方式与时效

可选的运输方式取决于你的收货地区，结账时以实际显示为准。官方列出的常见渠道与参考时效：

| 运输方式 | 参考时效（发货后） |
| --- | --- |
| UPS / DHL | 3~10 个工作日 |
| EMS | 5~10 个工作日 |
| K-Packet / 挂号小包（Registered Small Packet） | 20~40 个工作日 |

中文站面向中国大陆用户提供的「韩国直邮包税」渠道，由圆通承运，发货后约 15 天到手；清关约一周。此外官方还接有 Aramex、DOORA、顺丰航空（SF EXPRESS AIR）、FedEx 等渠道。

三点先说在前面：

- 参考时效**只是参考**，官方明确不保证到达日期；
- 运费按运输方式 + 包裹实重计算，结账页显示的数字就是最终运费；按预估重量算出的运费和实际称重可能有差额，超出部分不补偿；
- EMS 有 30kg 上限，超重的包裹可能被拆成多件发，不会事先通知。

## 二、去哪查物流

1. **先在站内查**：「我的账户 → 订单记录 → 点订单号」，运送单号一栏出单号就说明已经交给快递。
2. **再拿单号查轨迹**：去承运快递的官网查，或者直接用聚合查询站 [https://www.17track.net/](https://www.17track.net/) 输单号。
3. **单号刚出查不到很正常**：揽收后要人工扫描上传系统，出单号后**过两天再查**；清关那一段也不会更新轨迹，卡在清关一周左右不用慌，放行后就是国内派送。

## 三、清关与关税

- 进口环节产生的**关税和清关费用由收件人承担**，因为拒缴税费导致派件失败，后续索赔不受理；
- 包裹入境后如果联系不上收件人（地址错、电话错、没人接），3 天左右就可能派送失败退回网点；包裹入境后**退不回韩国**，一直压在快递公司手里；
- 非邮政渠道（KOREA POST 之外）派件失败且责任在你时，包裹可能被直接丢弃、不退不赔——所以收货信息务必填对。

## 四、发货前改地址

路径：「我的账户」→ 订单记录 → 点订单号 → 页面最下方「修改地址」（英文界面为 Address modification）。

- **只有发货前能改**，开始打包或交给快递后按钮就没了；
- 改完保存后**再核对一遍**，跨国件改错一次代价很大；
- 发货后才想改地址，只能自己联系快递或客服协调，流程繁琐且不保证成功。

## 五、收货异常怎么处理

| 情况 | 怎么办 |
| --- | --- |
| 显示「已妥投」但没收到 | 先排查：地址是否填错、是否门卫/前台/家人代收。都没有就在工作时间找 CS 中心 |
| 包裹缺件 | **留好能体现问题的视频和照片**（快递面单、外箱、白色贴纸、商品问题本身），找 CS 中心，说明具体专辑版本和数量 |
| 订单里部分商品长期未入库 | 联系 CS 中心，可以申请去掉该商品、其余先发 |
| 包裹被退回 | 查明原因：责任在快递方的全额退款；因收件方原因被海关或本国邮政退回的，退款 = 已付总额（商品 + 运费）− 运费 − 退回费。官方示例：商品 45.02 美元 + 运费 20.81 美元 = 已付 65.83，退回费 2.5 美元，实退 42.52 美元；也可补运费和退回费要求重新寄出 |
| 商品本身有问题 | 同缺件处理：视频照片留证 → CS 中心，按官方调查结果定责 |

CS 中心的入口在网站/App 右下角的对话气泡里，进去先看 FAQ，右下角有蓝色 CS 中心按钮发人工咨询。咨询时一次把「专辑版本 + 数量 + 证据图」说全，来回追问很耗时。

### 开箱视频怎么拍才算数

官方对瑕疵受理有一条明确的证据标准，拍对了才容易过：

- **合格的开箱视频**：从商品还包着塑封时就开始拍，一口气拍完；视频里能看到全部构成品数量，以及确认瑕疵的过程本身；
- **不合格的**：拆开之后才开始拍、经过剪辑拼接、视频里看不出问题所在的；
- 拿不准时，把视频里能体现问题的段落截图，连同购买的商品、缺失的构成品和数量一起发给 CS 中心。

先分清两种情形再去申诉：**运输途中磕碰、缺件**（本篇讲的范围）走 CS 中心定责；**收到了不想要想退**走 14 天退换窗口，规则见[取消订单与退款规则.md](取消订单与退款规则.md)。外箱、外壳本身的轻微划痕压痕两边都不算瑕疵，不构成退换理由。

从下单到发货之间的状态疑问，先回[下单购买流程.md](下单购买流程.md)第六节对一下订单状态；等包裹期间想补特典的判断，在[预售与特典怎么玩.md](预售与特典怎么玩.md)第五节。
