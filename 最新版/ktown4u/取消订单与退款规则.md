# Ktown4u 取消订单与退款规则

> 本篇讲 Ktown4u 的取消与退款规则：订单到什么状态就取消不了了、退款走哪条路、多久到账、收到货后 14 天内怎么退换。

## 一、什么状态下还能取消

取消窗口跟着订单状态走，下单前先把这几条记住：

| 订单状态 | 能否取消 |
| --- | --- |
| 待付款（Payment required） | 可以 |
| 备货中（Preparing item） | 可以 |
| 待发货（Ready to ship） | 可以 |
| 开始打包 / 发货中（On Shipping） | 不行 |

活动类商品另有硬限制：**签名会、入场券类商品在活动期结束后不能取消**；粉丝团团购订单不能申请取消。所以参加[预售与特典怎么玩.md](预售与特典怎么玩.md)里的活动前，先想好再拍。

## 二、怎么申请取消

1. 登录后进「我的账户 → 订单记录」，点开要取消的订单；
2. 点页面下方的取消按钮（英文界面为 Cancel Request）；
3. 取消按申请顺序在**2 个营业日内**依次处理；
4. 取消一旦被批准**不能撤销**——手滑申请前想清楚。

两个订单没法合并，取消后重新下单是唯一「改数量 / 换支付方式」的办法（见[下单购买流程.md](下单购买流程.md)第四节）。

## 三、退款多久到账

- **原路退回是硬规则**：退款只能退回你付款时用的那条渠道，PayPal 付的不能改退到别的账户；
- 中文站口径：取消处理完后，退款在**3~7 个营业日**内处理（周末节假日除外）；英文 FAQ 的说法是 1~2 天内自动处理取消；
- 信用卡到账时间取决于发卡行和银行政策，超时直接问发卡行，平台侧给不了确切日期；
- 商品断货无法发货的情况，按用户协议自收款之日起 **3 个工作日内**退款；
- 申请退款时客服会让你提供**订单号（Order ID）和快递单号（Tracking number）**，提前备好。

## 四、没付款的订单会自己取消

下了单没付款，订单会被自动取消，不用手动操作。自动取消的时限两个渠道说法不一：英文 FAQ 写的是**24 小时**未付款取消，中文商品页对活动类商品标注的是**1 小时**。别赌这个时间差——想买就尽快付，想放弃就等它自己掉。自动取消后想再买只能重新下单，付款也无法恢复原订单。

## 五、收到货之后：14 天退换窗口

签收后 **14 天内**可以申请退货或换货，超出就不受理了。以下情况不退不换：

| 不予退换的情形 | 说明 |
| --- | --- |
| 超过 14 天 | 从签收日起算 |
| 可复制介质的封装被拆坏 | CD/LP、DVD/Blu-ray、软件、漫画书、杂志、写真集等，塑封一拆就没法退 |
| 自己弄坏的 | 购买者个人原因造成的商品损坏 |
| 外壳/外箱细微瑕疵 | 外壳、外箱本身就是保护用的，生产流通中的轻微划痕、压痕、变色不算瑕疵，不构成退换理由；CD/LP 盘面的细微划痕同样不行 |

费用怎么分担：

- **发错货、缺件、质量问题**：退换运费由平台承担；
- **单纯不想要了**：运费自己出，而且退款只退**商品价**，运费不退；
- **不要不打招呼直接寄回**：平台不受理。任何退换先通过 CS 中心（网站/App 右下角对话气泡）申请，问清流程再寄。

包裹在运输途中被退回韩国的退款算法（退回费扣除那条线）在[物流跟踪与收货问题.md](物流跟踪与收货问题.md)第五节，跟本篇是两套情形：那套是「没收到货」，本篇是「收到了想退」。
