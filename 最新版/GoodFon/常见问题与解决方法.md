## 一、先做这三件通用事

多数症状都能靠这三步收口，逐个做、别跳：

1. **确认网络**：图库全靠在线加载，先把页面打开试试 —— 网页都打不开就不是应用的问题。
2. **确认权限**：「设置 → 应用 → GoodFon → 权限」里，**网络（联网）、存储/照片、（若用自动更换）后台运行**这三项要给全。
3. **清缓存重开**：同一页里的「存储 → 清除缓存」（**别点清除数据**，那会把收藏等本地记录一起清掉），然后重开应用。

## 二、壁纸加载慢或显示不清晰

| 症状 | 处理 |
| --- | --- |
| 列表一直转圈 | 换个网络（Wi-Fi ↔ 流量）试；同一个网络下浏览器打开 [www.goodfon.com](http://www.goodfon.com) 验证是不是网络本身的问题 |
| 只有开了 VPN / 广告拦截才异常 | 临时关掉再试一次 —— 网络工具误拦图床域名是常见原因，关掉能开就是它的问题 |
| 图能看但发虚 | 双指放大看原图 —— 原图分辨率低于屏幕时必然发虚；换一张分辨率更高（Full HD 及以上）的再设 |
| 只有部分图糊 | 挑图时直接按分辨率筛选，见 [壁纸搜索与筛选技巧.md](壁纸搜索与筛选技巧.md) 的「挑分辨率」一节 |

## 三、保存失败 / 设为壁纸失败

按顺序查：

1. **存储权限**没给 —— 系统设置里开「照片/存储」权限，这是最常见的原因。
2. **空间不足** —— 清出至少 10% 可用空间再试（下载大图 + 缓存都吃空间）。
3. **权限给了还失败** —— 清缓存重开；仍失败则重启手机，重启能解决一部分系统壁纸服务卡住的情况。
4. 换一张图试：单张图损坏也会导致设置失败，能换图成功就说明不是应用的问题。

## 四、应用闪退或无响应

1. 先看是不是**版本太旧**：这份安装包是 2.1.3（包名 `com.goodfon.goodfon`），装好后在应用信息里核对；有更新提示就更新。
2. **缓存损坏**：清缓存后重开（同上，不清数据）。清缓存前可以先用「强制停止」结束进程再开（应用信息页有该按钮）—— 比直接划掉后台更彻底。
3. **手机过热**：机身发烫时系统会压性能，应用容易卡死或闪退 —— 先放下手机降温，再重开试。
4. **系统时间不对**：日期时间偏差过大会影响在线数据同步，检查「设置 → 系统 → 日期和时间」里的自动同步是否开着。
5. **安装包本身的问题**：若安装时就提示解析失败、或首次打开必闪，多半是下载的包不完整 —— 回 [下载与安装教程.md](下载与安装教程.md) 从网盘重新下载一遍再装（建议先保存到网盘再下载，避免下成半截文件）。
6. 以上都试过还闪：卸载重装。收藏若已同步到官网账号，重装后登录即可找回。

## 五、安装时提示「应用未安装」

不是运行问题，是系统在安装这一步拒了，四种原因与处理（含降级安装的完整步骤）都写在 [下载与安装教程.md](下载与安装教程.md) 的「安装失败的常见情形」一节，按那张表对号入座即可。

## 六、搜索与分类异常

- **搜中文没结果**：图库标签以英文为主，换英文关键词（`cat` 而不是「猫」），详见 [壁纸搜索与筛选技巧.md](壁纸搜索与筛选技巧.md)。
- **结果页空白**：先联网等数据同步完成；网络正常仍空白就清缓存重开。
- **点分类没反应**：退回首页重新进；持续失效清缓存。
- 个别图点开 404/裂图：是该张图的资源问题，跳过换下一张，不影响其他功能。

## 七、自动更换壁纸不生效

逐项对：

1. **功能开关**是否真的打开、**间隔**是否设得过短或没保存成功（回设置页再看一眼）。
2. **后台权限**：国产手机默认杀后台 —— 给 GoodFon 开「允许后台运行 / 自启动 / 省电策略设为无限制」（各品牌叫法不同），不开这个到点基本不会换。
3. **电池优化**：部分机型还要单独放行 ——「设置 → 电池 → 电池优化」（或「耗电管理」）里把 GoodFon 设为「不优化 / 允许后台运行」，否则系统到点会掐掉它的定时任务。
4. **网络**：换图时要联网下新图，离线状态会跳过这一轮。
5. **图源为空**：选了「用收藏」但收藏是空的，轮换无图可换 —— 先收藏几张再开。
6. **摇一摇（G-Shake）没反应**：检查系统「摇动/动作」类开关是否给到应用，见 [设为壁纸与自动更换.md](设为壁纸与自动更换.md)。
