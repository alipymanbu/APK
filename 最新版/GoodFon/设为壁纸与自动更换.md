## 一、预览页上的四个动作

点开任意一张图进预览页，页面上集成了全部常用操作：**下载保存、收藏、分享、设为壁纸**。顺序上建议先放大看清楚（双指缩放），满意了再动手 —— 设壁纸和下载都会真的占流量与空间。

## 二、设为主屏 / 锁屏壁纸

1. 预览页点「设为壁纸」（不同版本按钮文案可能是 Set wallpaper）。
2. 进入裁剪/调整画面：拖动框选要在屏幕上显示的区域。竖图对手机基本不用大动，横图（电脑风景图拿来当手机壁纸）要左右挪一下把主体框住。
3. 系统会问设到哪里 —— **主屏、锁屏、主屏+锁屏**三选一，按需点。
4. 确认后回到桌面看效果。若主体被图标挡住，回上一步重新框选，把主体偏上或偏下放。

设置失败弹「无法设置壁纸」时，一般是存储权限没给，按 [常见问题与解决方法.md](常见问题与解决方法.md) 的「保存失败 / 设为壁纸失败」一节开权限。

## 三、下载保存到手机

- 预览页的下载按钮会把原图存进相册/文件夹，**下载完的图离线也能看**，换壁纸不消耗流量。
- 下载速度取决于网络；官方描述里也提示过下载慢多半是网络问题，不是应用卡了。
- 存下来的图不会自动清理，占空间的地方在「相册 → 对应文件夹」里，定期删掉不再用的即可。

## 四、收藏与网站同步

- 预览页的星形/心形按钮把图收进「收藏」列表，下次翻自己的收藏就行，不用重新搜。
- GoodFon 的一个特点是**应用内收藏能与官网账户的收藏同步**（官方描述明确列了这条）：在网站 [www.goodfon.com](http://www.goodfon.com) 上登录同一账号收藏的图，会出现在应用的收藏里，反之亦然。跨设备找图时这条路比手动传图省事。
- 收藏列表里长按某张图可以删除（长按调出菜单是这类图库的通用操作）。

## 五、自动更换壁纸

这是「懒得每天换」的人最该开的功能：

1. 进应用的设置/壁纸轮换入口（不同版本位置略有差异，一般在侧边栏或「自动更换 / Auto-change」字样下）。
2. **选图源**：用收藏夹、或随机（从浏览过的/精选池里抽）。
3. **选间隔**：按自己习惯定，短则十几分钟，长到几小时都行 —— 设太短会频繁重下图、费流量也费电，日常一到几小时一换比较合适。
4. 保存后生效，到点自动切下一张。

注意两点：自动更换需要**后台可运行**（国产手机要在系统里给它允许后台/自启动，否则到点不换）；换了图源记得确认间隔设置真的保存了（见 [常见问题与解决方法.md](常见问题与解决方法.md) 的「自动更换壁纸不生效」一节）。

## 六、G-Shake：摇一摇换一张

官方叫 **G-Shake**：开着应用时摇晃手机，随机给你弹一张壁纸，顺手就能「设为壁纸」或收藏。适合没目标、就想来点惊喜的时候。摇不动先检查系统「动作与手势 / 摇动」权限有没有把传感器权限关给应用。

## 七、分享与流量控制

- 预览页的分享按钮走系统分享面板，发给聊天软件或社交平台都行。
- 省流量的关键动作就两个：**先放大预览再下载**、**列表别一次拉到底**。预览看的是小图，确认后才下大图，这是官方描述里也强调过的用法。

## 八、下载的图能怎么用

存进相册的图默认归你个人使用 —— 自己的桌面随便换。要拿去视频、封面、商品这类对外场景，先停一下核授权：免费下载不等于允许商用，判断顺序与场景归类见 [壁纸图片能商用吗.md](壁纸图片能商用吗.md)。
