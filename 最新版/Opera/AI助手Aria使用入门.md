## 一、入口在哪

底部菜单（红色的 O 图标）里有一项 **Aria 浏览器 AI**，点开即用。从 AI 对话里点开一个网页链接后，页面上会出现 Aria 图标，点它可以直接回到对话——查着网页还能接着问，不用来回切换。

## 二、需要账号吗

官方页面的说法前后有过变化：现在的功能页写「无需注册登录即可免费使用」，更早的常见问题页写的是「打开后可以选择登录或创建账号」。以你手机上实际弹出的界面为准：不登录先用，遇到提示需要登录的功能再登录；账号怎么注册见[账号同步与跨设备使用.md](账号同步与跨设备使用.md)。

## 三、它能做什么

按官方功能页的口径：

| 能力 | 具体表现 |
| --- | --- |
| 实时联网问答 | 回答基于当前网络信息，支持 50 种以上语言 |
| 生成图片 | 文字描述直接出图 |
| 看图、看文件 | 上传照片、截图、文档，让它总结、识别、提取信息 |
| 视频 | 结合字幕转写总结 YouTube 视频、翻译外文内容 |
| 语音 | 支持语音输入提问、朗读回答（以实际界面显示为准） |
| 划词 | 选中网页上的文字后让它解释或翻译 |
| 上下文 | 能理解你当前打开的标签页乃至整个标签岛的内容，比如让你对比组里的几个商品页 |

## 四、用不了、答不上来时

- Aria 要联网才能回答，网络本身不通时它也不通；所在网络对它有限制时，换一个网络（Wi-Fi ↔ 移动数据）再试；
- 问「刚刚发生的事」答不上来时，把时间点说清楚再问一遍；
- 某些能力在部分地区可能未开放，以官方说明与实际界面为准——这类情况不影响浏览器其他功能。
