# Opera 安卓版账号同步与跨设备使用

> 本篇讲要不要登 Opera 账号、登录后同步哪些东西、手机和电脑之间怎么共享数据，以及不想同步时怎么退出。

## 一、先说结论：不登录也能用

浏览、VPN、广告拦截、Aria 这些功能**不登录账号全都可用**。账号只在一种情况下才必要：你想把数据带到另一台设备上。

所以合理顺序是：先用一段时间，确认这浏览器你会留着用，再注册账号；中途注册也不损失任何已有数据，书签和记录还在本机，登录后才开始上传同步。

## 二、注册与登录

路径：**设置 → 同步（或点首屏的「同步并搜索」入口）→ 注册 / 登录**。

- 用邮箱即可注册，按提示收验证码完成验证；
- 登录页如果还提供 Google 等第三方登录选项，以当时页面显示为准；
- 登录成功后，同步默认就开始了，不需要手动触发。

## 三、同步的内容与范围

按官方页面的说法，安卓版与桌面版之间可同步的数据包括：

| 数据 | 同步后效果 |
| --- | --- |
| 标签页 | 手机上开的标签可以在电脑端看到（「在我的其他设备上打开的标签页」） |
| 快速拨号 | 首页九宫格里的常用网址两端一致 |
| 书签 | 一端添加，另一端出现 |
| 密码 | 已保存的站点密码跨设备可用 |

几点使用上的提醒：

- 同步是**双向**的：删掉一端的书签，另一端也会删，别把另一台设备当备份；
- 换新手机时，在新手机装好 Opera（安装见[下载与安装教程.md](下载与安装教程.md)），登录同一账号，等同步完成即可，不需要导出文件；
- 浏览历史本身不作为同步项使用，无痕标签页的内容不参与同步（见[标签岛与隐私浏览用法.md](标签岛与隐私浏览用法.md)）。

## 四、Flow：设备间传文件和链接

登录账号后，菜单里有 **Flow** 入口：它相当于你和自己设备之间的一条私聊通道，手机上选「分享到 Flow」，电脑端就能收到链接、图片、文件和笔记，反过来也行。传大文件仍建议走网盘或数据线，Flow 适合的是「这条链接发我自己」这类小东西。

## 五、退出与关闭同步

路径：设置 → 同步 → **断开 / 退出登录**。退出时可以选择是否同时清除本机上已同步的数据：

- 只退出、不清除 → 本地书签密码保留，之后不再与云端互通；
- 退出并清除 → 本机恢复到未登录状态，云端还留有最后一份（下次登录同一账号会拉回来）。

打算彻底弃用又介意云端留数据的，先在浏览器里手动删干净书签密码再退出。

## 六、同步提示密码错误时

按官方 FAQ 给的办法：浏览器打开 `sync.opera.com`，用注册邮箱登录账号，在页面下方找到同步数据的重置入口，重置后再回各设备重新登录同步。重置的是云端那份同步数据，各设备本地的书签、密码不会因此被删。

同步之外的其他使用问题，去[常见问题与解决办法.md](常见问题与解决办法.md)找。
