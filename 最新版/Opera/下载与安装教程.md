## 一、先确认你要装的是哪个 Opera

Opera 家族在安卓上不止一个应用，装错名字相似的会更难用。本篇讲的、也是上面这份安装包对应的是**标准版 Opera**，它的包信息如下：

| 项目 | 内容 |
| --- | --- |
| 应用名称 | Opera（安卓版） |
| 包名 | `com.opera.browser` |
| 版本 | 100.4.5122.89709 |
| 安装包大小 | 243.63M |
| MD5 | `0F21361E3D0B62355EAF8E29932571AA` |
| 系统要求 | 安卓 5.2 及以上（以安装包信息为准） |
| 开发者 | Opera Software ASA |

同一家族另外两个安卓应用，按需求对号入座：

| 应用 | 定位 | 适合谁 |
| --- | --- | --- |
| Opera | 标准全功能版 | 日常浏览，要用内置 VPN、广告拦截、Aria AI 这些完整功能 |
| Opera Mini | 极省流量版 | 网速慢、套餐流量紧、设备很老旧的场景 |
| Opera GX | 游戏风格定制版 | 喜欢游戏向界面、想手动限网页速度的人 |

装完之后想核对装的是哪个，可以到「设置 → 应用管理」里看包名：标准版是 `com.opera.browser`，Mini 是 `com.opera.mini.native`，GX 是 `com.opera.gx`。

## 二、获取安装包

1. 打开上面的 [Opera 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a2ba69060b3b)链接，把里面的 APK 文件转存到自己的网盘后下载到手机；
2. 下载完成后在通知栏或「下载」目录里点这个 APK，部分文件管理器会直接弹出「是否安装」。

243.63M 的包体不算小，建议在 Wi-Fi 环境下下载；如果中途断过网，最好重新下一次，下到一半的包是装不上的（见第四节）。

## 三、安装步骤

1. **点开 APK，首次会弹出「出于安全考虑，手机已禁止安装未知应用」**。点弹窗里的「设置」，把「允许从此来源安装」打开，返回后继续安装；
2. 不同品牌手机这个开关的路径不完全一样，都可以在系统设置里搜关键词「安装未知」找到；路径大致是：设置 → 应用 → 特殊权限（或更多设置）→ 安装未知应用；
3. 点「安装」，等进度条走完，点「打开」或回桌面点图标启动；
4. **首次启动**：会依次出现用户协议、数据统计选择，按需同意或跳过；账号登录这一步可以直接跳过，不登录也能正常浏览，之后想同步再登（见[账号同步与跨设备使用.md](账号同步与跨设备使用.md)）；
5. 进主界面后，建议先把两件事打开：广告拦截和免费 VPN，具体入口在[内置VPN与广告拦截设置.md](内置VPN与广告拦截设置.md)里。

## 四、装不上时的排查

| 提示 | 多半是 | 怎么办 |
| --- | --- | --- |
| 解析包时出现问题 | 下载不完整，或系统版本低于要求 | 重下并核对 MD5（见下）；确认系统版本满足第一节表格 |
| 已存在同名应用 / 安装失败（签名冲突） | 手机里装过其他渠道的 Opera | 先卸载旧版再装；数据（书签、密码）先登录账号同步，或用备份 |
| 存储空间不足 | 包体 243.63M，安装过程还要解压占用 | 清出至少 1G 余量再装；装完可以删掉下载的 APK |
| 点了没反应 | 文件管理器没有安装权限 | 换系统自带的「文件管理」打开 APK，或给当前文件管理器「安装未知应用」权限 |

**核对 MD5（可选但推荐）**：用支持校验的文件管理器（很多第三方文件管理器在文件「详情/属性」里就有 MD5 一项）查看下载到的 APK，应为 `0F21361E3D0B62355EAF8E29932571AA`。对不上就说明下载不完整，重新下载即可。

**确认版本与后续升级**：装好后到 **菜单 → 设置 → 底部「关于」** 能看到完整版本号；官方出了更高版本想升级时，直接用同包名的新 APK 覆盖安装，书签与数据保留（保险起见先登录账号同步一次，见[账号同步与跨设备使用.md](账号同步与跨设备使用.md)）。网上查到的「官方最新版」版本号一直在往前走，和本文写到的 100.4.5122.89709 不一致属正常，功能差异以官方更新日志为准。

装好之后如果遇到具体功能上的问题，去翻[常见问题与解决办法.md](常见问题与解决办法.md)；想先把浏览器里最常用的两个开关（VPN、广告拦截）调好，看[内置VPN与广告拦截设置.md](内置VPN与广告拦截设置.md)。
