## 一、定制入口与可开关的模块

起始页（新标签页）的定制有两处入口：起始页**右上角的定制按钮**，或 **菜单 → 设置 → 起始页**。能开关的模块包括：

| 模块 | 内容 |
| --- | --- |
| 快速拨号 | 常用网站的瓷砖图标 |
| 推荐站点 | 根据你的浏览历史推荐的相关网站 |
| 新闻 | 资讯流（里面有广告，见第四节） |
| 比分 | 体育赛事比分（部分版本提供） |
| 壁纸 | 换背景图 |

想让新标签页只留搜索框和快速拨号，把新闻、推荐站点、比分全关掉就行。

## 二、快速拨号：加、删、同步

- **加**：打开想收藏的网站 → 点地址栏右端的菜单 → 添加书签 / 添加到 → 选「快速拨号」；也可以直接点起始页空位上的「+」填网址；
- **删、调位置**：长按瓷砖进入编辑（不同版本手势略有差异）；
- **同步**：登录账号后快速拨号会跟着账号走，换手机不用一个个重新加，见[账号同步与跨设备使用.md](账号同步与跨设备使用.md)。

## 三、把网站放到手机桌面上

想不打开浏览器、从桌面图标直接进某个网站：打开该网站 → 地址栏右端菜单 → 添加到 → **添加到主屏幕**。生成的图标和普通 App 并排，点开就是那个网站。适合你用得最频繁的两三个站点，其余的留在快速拨号里就够了。

## 四、起始页新闻流里的广告

官方 FAQ 明确说过：起始页新闻流里会展示广告，用于支撑免费 VPN 这类服务的成本。介意就整块关掉：菜单 → 设置 → 起始页 → 关闭「新闻」——顺带新标签页也更清爽。

## 五、离线页面：没网也能看

遇到想留着慢慢看的长文，在地址栏右端菜单里选**离线保存**（老版本叫「保存页面」），之后在 **菜单 → 离线页面** 里找到它们。适合通勤路上补读；图片多的页面存下来占的空间也大，定期清理即可。
