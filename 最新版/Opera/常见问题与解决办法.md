## 一、怎么修改下载保存的位置

路径：**设置 → 下载 → 下载位置**。

- 首次修改时系统会要存储权限，允许后才能选到浏览器默认目录之外的文件夹；
- 安卓 10 及以上机型受系统「分区存储」限制，能选的位置可能只有公共下载目录一类，选项少是系统行为，不是浏览器坏了；
- 改完只对之后的下载生效，已下好的文件不会被挪动。

网页里下载没反应时，先看通知栏——大文件下载进度在通知里；被手动划掉通知不会中断下载，去浏览器的下载管理页看状态即可。

## 二、界面语言怎么变中文

浏览器界面语言**跟随系统语言**，没有单独的切换开关：系统是中文，界面就是中文。显示成英文时去系统「设置 → 系统 → 语言」里把简体中文调到第一位，重启浏览器生效。个别新增功能的文案可能暂缺翻译，等版本更新即可。

## 三、切到后台就被杀、回来自动刷新

这是系统省电策略在回收浏览器，处理办法：

1. 系统设置 → 应用 → Opera → 电池 → 改成「不受限制 / 无限制」；
2. 在最近任务界面把 Opera 的卡片**锁定**（下拉或长按，不同品牌手势不同），锁定的应用不会被一键清理；
3. 部分品牌（如小米、华为）有独立的「自启动 / 后台弹出」权限管理，把 Opera 允许上。

浏览器在后台主要是保标签页存活，锁了之后多任务切换回来就不用等页面重载。

## 四、占用空间越来越大

大头是缓存和离线数据，清理路径：**设置 → 隐私 → 清除浏览数据**，只勾「缓存的图片和文件」，时间范围选全部——这样历史记录和登录态都保留，只腾空间。各类数据该勾哪个见[标签岛与隐私浏览用法.md](标签岛与隐私浏览用法.md)的对照表。

安装包本身也会占一份：装完 Opera 后，下载目录里那个 243.63M 的 APK 就没用了，可以删掉。

## 五、装混了 Opera / Opera Mini / Opera GX 怎么认

三个应用图标和名字都像，认包名最准：系统设置 → 应用管理 → 找到对应应用 → 「应用详情」里看包名。

| 包名 | 应用 |
| --- | --- |
| `com.opera.browser` | 标准版 Opera（本套文档讲的就是它） |
| `com.opera.mini.native` | Opera Mini（省流量版） |
| `com.opera.gx` | Opera GX（游戏风格版） |

三个可以共存于同一部手机，互不覆盖；装错了不用纠结数据迁移，直接卸掉重装正确的那个即可。

## 六、起始页新闻流里有广告

官方 FAQ 说明过原因：新闻流里的广告用于支撑免费 VPN 这类服务的成本。不想看就整块关掉：菜单 → 设置 → 起始页 → 关闭「新闻」，新标签页顺带也更清爽；起始页上还有哪些模块可以关，见[起始页与快速拨号整理.md](起始页与快速拨号整理.md)。

## 七、其他常见疑问

- **VPN 连不上**：换服务器位置、关掉其他代理类应用再试，完整排查在[内置VPN与广告拦截设置.md](内置VPN与广告拦截设置.md)；
- **书签怎么带到新手机**：登录同一个 Opera 账号等同步完成即可，步骤在[账号同步与跨设备使用.md](账号同步与跨设备使用.md)；
- **某个网站广告还是很多**：先确认全局拦截已开（设置 → 广告拦截），个别站点被你放行过的，去地址栏盾牌图标里重新打开拦截；
- **打开网页整体偏慢**：先排除网络本身（换 Wi-Fi / 移动数据对比），再确认不是被 VPN 连到了很远的节点——点地址栏 VPN 徽标切回「自动」或就近节点；
- **网站推送通知关不掉**：菜单 → 设置 → 通知，里面能按网站单独清除；
- **想确认当前版本号**：菜单 → 设置 → 底部「关于」；
- **视频切后台或锁屏就停**：属于系统对后台画面的限制，小窗与后台播放的办法见[视频小窗与后台播放.md](视频小窗与后台播放.md)。

安装失败、「解析包出现问题」这类装都装不上的情况，对应表格在[下载与安装教程.md](下载与安装教程.md)第四节。
