## 一、这是个什么应用

Clipboard 是一款安卓剪贴板管理工具：把你复制过的文本留存成历史，把常用短语存成条目，之后点一下就能重新复制、到任意应用里粘贴。海外商店里它多记作「Clipboard - Copy Paste & Notes」，归类 productivity；国内分发页写作小写 clipboard，归类系统工具。本文统一写 Clipboard。

它要解决的是一件具体的小事：系统剪贴板一次只存一份内容，第二次复制就覆盖第一次；而「常用的收货地址、邮箱、话术、账号」这类内容，你其实会反复用。装好后的具体走法见 [常用文本与历史记录管理.md](常用文本与历史记录管理.md)，本篇只管安装。

## 二、安装包规格（以网盘里这份为准）

网上各处标注的版本经常不一致，下面这张表是**网盘里那份安装包**的信息，装完想核对「装的是不是同一份」时用得上：

| 项目 | 值 |
| --- | --- |
| 版本号 | 4.12.0 |
| 包名 | com.mason.ship.clipboard |
| 安装包大小 | 9.52M |
| MD5 | F1C1A89AEF7C1B9FDA1316FFF8493063 |
| 系统要求 | 分发页标注「安卓系统 5.2 以上」，以安装时的实际提示为准 |
| 界面语言 | 简体中文 |

核对包名的办法：装完后进手机「设置 → 应用管理」，找到 Clipboard 点进去，显示的包名应当是 `com.mason.ship.clipboard`。对不上说明你装的是别的来源的同名应用。

## 三、获取安装包

1. 打开 [Clipboard 安装文件资源（夸克网盘）](https://pan.quark.cn/s/02c745ebcdc5)；
2. 先转存到自己的网盘，再下载到手机，比直接在线下载稳；
3. 下载完成后确认文件大小 9.52M 左右（文件名类似 `clipboard_v4.12.0.apk`）再点安装。

也可以电脑上下载后传手机：数据线拷贝，或用微信、QQ 的文件传输助手发送 apk 文件。

## 四、安装步骤

1. 点击 apk 开始安装。系统若弹出「不允许安装未知来源的应用」之类的提示，按它给的入口进设置，把这个应用的安装权限打开（不同品牌的菜单路径略有差异，以你手机实际显示为准）；
2. 等安装进度走完，点「打开」；
3. 首次启动会请求若干权限，怎么给看用途：
   - **存储权限**：你要用备份导出功能就需要；
   - **无障碍服务（可选）**：只在你希望「复制完自动记录进历史」时才开，不开也能手动添加与使用，取舍见 [复制不被记录的排查方法.md](复制不被记录的排查方法.md)；
4. 进首页后先手动存一两条常用文本试一下复制粘贴，具体操作见 [常用文本与历史记录管理.md](常用文本与历史记录管理.md)。

## 五、装不上时先查这三项

- **提示「解析包时出现问题」**：apk 没下完整，基本都是下载中断造成的，回到第三节重新下载；
- **提示「未知来源」或「已阻止安装」**：按第四节第 1 步打开安装权限；
- **手机里已有同名应用、提示安装失败**：先看现有应用的包名。包名也是 `com.mason.ship.clipboard` → 是同一个应用，签名不同导致的冲突，先卸载旧版再装（卸载会连本地历史一起清掉，介意就先按 [备份恢复与换机迁移.md](备份恢复与换机迁移.md) 导出备份）；包名不同 → 那是另一个应用，互不影响，直接装这份即可。

## 六、以后更新版本怎么办

想换新版本时走**覆盖安装**，不要先卸载：

1. 回到第三节的网盘入口取安装包 —— 同名文件夹的分享链接不变，每次回原地取即可；
2. 直接安装新版，系统会原地升级，历史与常用文本保留；
3. 版本号以你获取安装包时页面显示的为准，本文表格只对网盘里这份 4.12.0 负责。

## 七、官方渠道与版本差异

这份应用的获取口子如下，前一个是本页资源，后两个是开发者官方渠道：

| 途径 | 说明 |
| --- | --- |
| 本页网盘资源 | 上面第二节的 4.12.0，本套文档写作时对应的版本，装法照本文走 |
| 官方站点 | [clipboardhistory.app](https://clipboardhistory.app/)，开发者 The 1 Studio 的官网，带下载页与隐私政策 |
| Google Play | [play.google.com/store/apps/details?id=com.mason.ship.clipboard](https://play.google.com/store/apps/details?id=com.mason.ship.clipboard) |

两个版本事实要留意（截至 2026-09，以官方页面当时标注为准）：

- **系统要求随版本抬高**：官方商店的较新版本已要求更高的安卓版本（8.x 系列页面标 Android 7.0 以上，9.0 商店标 11 以上）；网盘这份 4.12.0 按分发页标注是安卓 5.2 以上。老手机装不上最新版时，低版本包反而是能用的那份；
- **功能有差异**：文件夹、标签、跨设备同步是较新版本才有的（详见 [常用文本与历史记录管理.md](常用文本与历史记录管理.md) 第七节）；自动记录的权限机制两版一致，说明见 [复制不被记录的排查方法.md](复制不被记录的排查方法.md)。
