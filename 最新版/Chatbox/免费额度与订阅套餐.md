登录 Chatbox AI 账号后，用量按「计算点数」扣：对话、联网搜索、文档分析都在花点数，免费档与付费档的差别就是每天或每月给你多少点、能用哪些模型。本篇把各档的数字摆在一起，帮你判断要不要充、充哪档。

## 一、免费档能给多少

不订阅也有免费额度可用，截至本文整理时官方定价页显示的口径是：

- 每天 10,000 计算点数，次日重置；
- 可用「标准模型」对话；
- 每月 5 张 AI 绘图；
- 工作模式（Agent 执行任务）仅限试用。

每天一万点大致够轻度提问用，但撑不起长文档分析或高频联网搜索。具体以官方定价页（`https://chatboxai.app/zh/pricing`）当时显示为准。

## 二、付费三档对照

三档订阅的核心差异如下（价格为整理时的年付口径，月付更贵，以官网为准）：

| 项目 | Lite | Pro | Pro+ |
| --- | --- | --- | --- |
| 价格 | $3.5/月（月付 $3.99） | $16.7/月（月付 $19.99） | $33.33/月（月付 $39.99） |
| 计算点数 | 200 万/月 | 1200 万/月 | 3000 万/月 |
| 标准模型 | 有 | 有 | 有 |
| 高级模型 | 无 | 有 | 有 |
| AI 绘图 | 25 张/月 | 100 张/月 | 200 张/月 |
| 文档聊天 | 无 | 有 | 有 |
| MCP 服务 | 无 | 有 | 有 |
| 知识库 | 无 | 有 | 有 |
| 同时在线设备 | 最多 5 台 | 最多 5 台 | 最多 5 台 |

价格与包含项随官方调整会变，订阅前以定价页当时显示为准。模型清单里「标准 / 高级」各指哪些，见 [支持的模型与提供方.md](支持的模型与提供方.md)。

## 三、点数怎么耗的

同一个点数池覆盖三类动作：模型对话、联网搜索、文档分析。消耗速度主要取决于你选的模型 —— 官方文档给的换算例子是：同样的点数，DeepSeek 这类轻量模型能撑的 token 量是旗舰模型的数倍，旗舰模型几轮长对话就把点数吃掉一大截。

所以点数焦虑的第一解法不是升级，而是把日常问答换到便宜模型、只在需要时切旗舰。各模型的点数消耗倍率可在官网的模型定价页（`https://chatboxai.app/zh/model-pricing`）查到。

## 四、升降级与设备数规则

- **升级**立即生效；**降级**要到下一个计费周期生效；
- 一个订阅（License）最多 5 台设备同时在线，手机、平板、电脑都算；
- AI 绘图额度每月重置，当月用完只能等下月或升级。

不想订阅了，改走「自带 API Key」路线（见 [API密钥配置教程.md](API密钥配置教程.md)）之后，用量就跟各家模型平台结算，与 Chatbox 套餐无关。

## 五、按用量估一档

| 你的用法 | 合适的档位 |
| --- | --- |
| 每天几轮问答、偶尔搜一下 | 免费档大概率够用 |
| 每天高频对话、要发文档分析 | Lite |
| 要用旗舰模型、做编程或推理类任务 | Pro |
| 多人多设备、大量文档处理 | Pro+ |

拿不准就先用免费档跑一周，看设置页里的点数消耗速度，再决定充哪档 —— 套餐随时可升，先用着不亏；额度用尽的报错处理见 [常见问题与报错处理.md](常见问题与报错处理.md)。
