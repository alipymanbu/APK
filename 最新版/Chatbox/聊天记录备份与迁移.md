Chatbox 的聊天记录只存在你的设备本地，官方服务器上没有副本 —— 这意味着卸载、换机、恢复出厂都会把它带走，且事后无从找回。本篇把导出、导入、多设备搬移的操作写全，卸载或换机前先照做一遍。

## 一、记录存在哪、存了什么

安卓端的数据放在应用私有存储里，没有 root 就无法直接翻文件，所以要备份只能走应用内的导出功能。本地保存的内容包括：

- 所有对话历史；
- 应用设置与配置；
- 自定义 Prompt；
- 模型配置信息（含你填的 API Key）。

因为 Key 也存在本地，备份文件要当成敏感文件保管，别随手发到群里或公开网盘。

## 二、导出数据

安卓端操作路径：打开 Chatbox → 点左上角菜单进入「设置」→「数据管理」→「导出数据」→ 导出的文件保存在手机 `Documents/chatbox_ai_exports` 目录。

导出格式有两种，用途不同：

| 格式 | 内容 | 用途 |
| --- | --- | --- |
| JSON | 全量数据 | 备份与恢复（能再导回 Chatbox） |
| Markdown | 纯文本可读 | 存档、翻阅、分享给他人看 |

要恢复数据就用 JSON；只是想留一份能翻的记录，用 Markdown 更方便。

## 三、导入数据

在新设备或重装后的应用里恢复记录：

1. 在新设备上装好 Chatbox 并打开；
2. 进「设置」→「数据管理」→「导入数据」；
3. 选中之前导出的 JSON 文件；
4. 等导入完成，对话历史、设置、Prompt 会一起回来。

导入的是快照：旧设备之后新增的对话不会自动跟过来，需要时再导一次。

## 四、换手机、多设备之间搬数据

Chatbox 目前没有自动多设备同步，每台设备的数据各自独立。搬移只能手动走两步：

1. 在旧设备「导出数据」拿 JSON 文件；
2. 通过网盘、数据线或任意传输方式把文件送进新手机，再按第三节导入。

两台设备同时在用的话，记录不会互通 —— 各自聊各自存，想合在一起就定期从主力设备导出、往另一台导入。

## 五、防丢清单

官方文档明确说过：数据丢了没法从服务器恢复。照这几条做能把风险压到最低：

- **卸载前先导出**：卸载动作会带走应用私有存储里的全部记录；
- **定期导一份 JSON 放云盘**：手机丢失、损坏、恢复出厂时才有的救；
- **换机当天先迁移再清旧机**：确认新设备导入成功、记录完整，再处理旧手机；
- **借设备给别人用时**：聊天记录和 Key 都在本地，用完考虑清掉数据再还。
