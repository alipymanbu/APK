Chatbox 是一款跨平台的 AI 聊天客户端，支持 Windows、macOS、Linux、iOS、Android 与网页端，可以接入 GPT、Claude、Gemini、DeepSeek 等主流模型，也支持登录 Chatbox AI 账号直接使用。本篇面向安卓用户，讲清楚从拿到 APK 到打开应用这一段的每一步；装完之后怎么让它能正常对话，见 [API密钥配置教程.md](API密钥配置教程.md)。

## 一、安卓版有哪几种装法

官方给安卓用户提供了两条获取途径，装法不同，来源如下：

| 获取途径 | 说明 |
| --- | --- |
| 官方 APK 直接安装 | 从官网下载页拿到 APK 文件装进手机，不需要应用商店账号，也是官方推荐的方式 |
| Google Play | 在 Play 商店搜索 Chatbox 安装，适合已经登录 Play 账号、习惯商店更新的用户 |

两种途径装的都是同一个安卓客户端。Play 商店页面上的设备兼容性要求以官方标注为准，APK 直装则看下面这份本地安装包信息。

## 三、获取安装文件

从上方网盘块里的链接进入「Chatbox 安装文件资源（夸克网盘）」，转存到自己网盘后下载 APK 到手机存储即可。夸克网盘的转存操作：打开分享页 → 勾选文件 → 点「保存到网盘」→ 在自己的网盘里找到它并下载。

下载完成后，建议先按第六节的方法核对一次 MD5，再开始安装。

## 四、安装步骤

安卓手机默认只允许从应用商店安装应用，直装 APK 需要给一次「未知来源」授权：

1. 在手机上点开下载好的 APK 文件；
2. 系统弹出「是否允许安装未知应用」提示时，选择允许（不同厂商入口不同：部分手机在「设置 → 安全」里按应用单独授权，部分直接在弹窗里点「仍要安装」）；
3. 回到安装界面，等待进度走完，点「完成」或「打开」。

安装耗时主要看手机性能，这份包约 91 MB，中端机一般十几秒装完。如果提示「解析包错误」，通常是下载不完整，重新下载一次再装；其他安装阶段的问题见 [常见问题与报错处理.md](常见问题与报错处理.md)。

## 五、首次启动

打开 Chatbox 后会先看到欢迎界面，它提供两条路：

- **新手引导**：选「我是新手」这类入口，应用会一步步带你完成登录或配置；
- **跳过引导**：已经知道怎么填 API Key 的话直接跳过，之后从侧边栏进设置手动配。

移动端的设置入口在左上角的菜单按钮（三道横线图标）里：点开后从侧边栏进入「设置」。具体到模型与 Key 的填写，见 [API密钥配置教程.md](API密钥配置教程.md)。如果这是换机重装，旧手机里的聊天记录要先导出再迁移，见 [聊天记录备份与迁移.md](聊天记录备份与迁移.md)。

## 六、怎么核对 MD5

想确认手里的 APK 与分享时那份完全一致，可以在电脑或手机上算一次 MD5 再比对：

- **Windows（PowerShell）**：

```powershell
Get-FileHash "Chatbox_v1.67.13.apk" -Algorithm MD5
```

- **macOS / Linux**：

```bash
md5 Chatbox_v1.67.13.apk
```

算出的值与第二节表格里的 `863960CC34AE32840C50B9D2506FF07A` 一致，就说明文件没在传输中损坏。不一致就重新下载，不要硬装。
