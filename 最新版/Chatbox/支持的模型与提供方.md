Chatbox 本身不带模型，它是一个把各家模型装进同一个界面的客户端。你能用什么模型，取决于你在设置里连上了哪个提供方：要么登录 Chatbox AI 账号用官方套餐，要么用自己的 Key 接 GPT、Claude、Gemini、DeepSeek 等任一厂商，本篇按这两种口径把模型清单和选择思路列出来。

## 一、内置模型提供方

设置 →「模型提供方」列表里内置了主流厂商，各家的大致情况：

| 提供方 | 代表模型 | 计费口径 | 国内可用性 |
| --- | --- | --- | --- |
| OpenAI | GPT 系列、o 系列推理模型 | 美元按 Token 计费，需海外支付方式 | 直连通常不行，需处理网络 |
| Anthropic | Claude 系列 | 美元计费，需海外支付方式 | 同上 |
| Google | Gemini 系列 | 有免费额度档位，付费走美元 | 接口访问需要处理网络 |
| DeepSeek | DeepSeek 对话与推理模型 | 人民币充值，价格低 | 直连可用 |
| 其他 | Grok、Kimi、智谱等 | 各家不一 | 以各家官网为准 |

列表内容随版本更新会变，以你设置页里实际显示的为准。所有这些走的是「自己的 Key」路线，费用直接跟各家平台结算，与 Chatbox 无关。

## 二、Chatbox AI 套餐覆盖的模型

登录 Chatbox AI 账号（路线 A）则不需要自己找 Key，按套餐用量计费。截至本文整理时，官方文档列出的模型分组如下，具体以官方页面为准：

| 分组 | 覆盖 | 可用档位 |
| --- | --- | --- |
| 标准模型 | DeepSeek 系、Kimi、Gemini Flash、GPT mini 档、Claude Haiku 档等 | 免费档与所有付费档 |
| 高级模型 | GPT 旗舰、Claude Sonnet/Opus 旗舰、Gemini Pro 旗舰、Grok 旗舰等 | 仅 Pro / Pro+ |

免费档与付费档各自的点数额度、绘图张数见 [免费额度与订阅套餐.md](免费额度与订阅套餐.md)。两个套餐方向的实际差异（价格、每日额度、可用模型上限）以官网定价页（`https://chatboxai.app/zh/pricing`）当时显示为准，本文不写具体数字。

## 三、OpenAI 兼容的自定义接入

大量第三方服务与自建服务都提供「OpenAI API 兼容」接口，这类服务在 Chatbox 里统一按自定义提供方接入。核心配置就四个值：

| 配置项 | 示例值 | 备注 |
| --- | --- | --- |
| API 类型 | OpenAI API 兼容 | Gemini 原生接口的服务则选 Gemini 兼容 |
| API 主机 | 服务商给你的地址 | 不要拼错协议头与末尾斜杠 |
| API 密钥 | 服务商的 Key | 自建无鉴权服务可留空 |
| API 路径 | `/v1/chat/completions` | 默认即可，特殊服务按其文档改 |

接入步骤与各填项的详细说明在 [API密钥配置教程.md](API密钥配置教程.md) 第四节。要注意的是：第三方服务的模型名由服务商自己定义，添加模型时照服务商文档抄，别照官方模型名猜。

## 四、按场景选

- **不想折腾、马上能用**：登录 Chatbox AI 账号领免费额度，之后用量大了再考虑订阅；
- **已经有某家的 Key**：直接在模型提供方里配那一家，不花第二份钱；
- **在国内、没有海外支付方式**：DeepSeek 这类人民币计费、接口直连的提供方门槛最低；
- **想用某家中转/聚合服务**：走自定义提供方，按第三节四个值填。

选型拿不准时，先各配一个最便宜的模型试延迟与回复质量，再决定往哪家充值 —— 换提供方随时可以在设置里加，不用卸载重装。
