# Chatbox API 密钥配置教程

> 本篇讲装好 Chatbox 之后怎么让它真正能对话：登录 Chatbox AI 账号、或者填自己的 API Key，以及自定义提供方怎么配。安装步骤在 [下载与安装教程.md](下载与安装教程.md)。

Chatbox 装好还不能直接聊，你得先让它连上一个模型。连法有两种：登录 Chatbox AI 账号用官方套餐的额度，或者在设置里填自己的 API Key 调用各家模型服务。本篇把两条路线的步骤、自定义提供方的每个填项、以及配完怎么验证都写清楚。

## 一、两条路线怎么选

| 路线 | 适合谁 | 成本 | 前置条件 |
| --- | --- | --- | --- |
| 路线 A：登录 Chatbox AI 账号 | 不想自己找 Key、开箱就聊的人 | 新用户可领免费额度（每日刷新）；更高用量走付费套餐，以官网定价页为准 | 一个能注册的邮箱 |
| 路线 B：自带 API Key（BYOK） | 已经有 OpenAI、DeepSeek 等平台 Key 的人 | 按各家平台自己的计费走 | 对应平台的账号与 Key |

两条路线不互斥：可以先登录账号用免费额度，之后想换模型再在设置里加自己的 Key。

## 二、路线 A：登录 Chatbox AI 账号

1. 打开 Chatbox，在欢迎界面选新手引导，按提示点「登录」；已跳过引导的话，点左上角菜单（三道横线图标）→「设置」→ 第一项「Chatbox AI」；
2. 应用会拉起浏览器做授权，用邮箱登录你的 Chatbox 账号并确认授权；
3. 跳回应用后，设置页会显示登录状态与额度用量，回到首页点「新对话」即可开聊。

还没有账号的话，先去官网注册（`https://chatboxai.app`），新用户在用户页可以领取免费 License，领取后额度每日刷新；免费额度用尽后，要么订阅付费套餐，要么改走路线 B。

两点实用信息：一个账号（License）最多 5 台设备同时在线，手机平板电脑都算；登录状态与剩余额度在「Chatbox AI」设置页直接可见，觉得免费档不够用，先看看各档给的量再决定，对照见 [免费额度与订阅套餐.md](免费额度与订阅套餐.md)。

## 三、路线 B：填自己的 API Key

以 OpenAI 为例，其他提供方的操作骨架完全一样，只是 Key 的来源不同：

1. **拿到 Key**：登录对应平台的开放平台后台（如 `https://platform.openai.com`），在 API Keys 页面创建一个新 Key，复制保存 —— Key 只在创建时完整显示一次；
2. **打开设置**：手机上点左上角菜单（三道横线图标）→「设置」→「模型提供方」；
3. **添加提供方**：点「添加 Provider」，选择对应厂商（如 OpenAI），把 Key 粘进「API Key」字段；API 主机保持默认（OpenAI 为 `https://api.openai.com`）；
4. **选模型**：保存后回到对话界面，在模型列表里选一个该提供方下的模型。

各家 Key 的获取入口与计费方式不同：DeepSeek 等国内平台注册即用人民币充值，OpenAI 需要海外支付方式并建议在后台设置用量上限。哪家的模型适合你，见 [支持的模型与提供方.md](支持的模型与提供方.md)。

## 四、添加自定义提供方

设置列表里没有你要的服务商时，用底部的「添加」自己建一个。每个填项的含义如下：

| 填项 | 填什么 | 说明 |
| --- | --- | --- |
| 提供方名称 | 随意，用于自己辨认 | 如「我的中转」 |
| API 类型 | OpenAI API 兼容 / Google Gemini 兼容 | 按服务商接口类型选，GPT 系兼容接口选 OpenAI 兼容 |
| API 密钥 | 服务商给你的 Key | 有些自建服务不需要 Key，留空即可 |
| API 主机 | 服务商提供的接口地址 | 如 `https://api.xxx.com`，别带末尾斜杠 |
| API 路径 | 一般留默认 `/v1/chat/completions` | 服务商文档有特殊要求时才改 |
| 模型 | 至少添加一个模型 ID | 按服务商文档写模型名，并勾选对应能力（视觉、推理等），不勾视为纯文本模型 |

保存后点「检查」按钮，提示连接成功就说明配置可用；报错的话先核对 API 主机拼写与 Key 是否复制完整，排查思路见 [常见问题与报错处理.md](常见问题与报错处理.md)。

## 五、配完先测一句

配置验证最容易漏的一步是实际发一句话：回到首页，新建对话，选中刚配的模型，发一条短消息。能正常流式回复，说明 Key、网络、模型三环节都通了；只报错不出字时，把报错原文对照 [常见问题与报错处理.md](常见问题与报错处理.md) 里的场景逐条排查，比反复改配置有效。
