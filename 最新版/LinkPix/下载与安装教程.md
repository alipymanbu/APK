## 一、先分清你要装的是哪一个

LinkPix 是青虎AI（开发商：广州萌啦信息科技有限公司）旗下的电商 AI 视觉工具，负责 AI 生图和 AI 生视频；同一家还有云电脑、选品智能体等产品线。安卓端的安装包**名字不叫 LinkPix，叫「青虎云」**，包名为 `com.qinghu.cloud.mobile` —— 装好后手机桌面上显示的图标是「青虎云」，LinkPix 功能在 App 里面。别以为是下错了。

如果你主要在电脑前干活，也可以不装安卓包，直接用下一节的多端入口。

## 二、各端从哪下载

官方把所有端的入口集中在一个页面：[青虎AI 下载中心](https://www.iqinghu.com/download)，对应关系如下：

| 你用的设备 | 入口 | 说明 |
| --- | --- | --- |
| 安卓手机 | 本篇的网盘安装包，或下载中心的 Android 客户端 | 安装包名为「青虎云」 |
| iPhone / iPad | 下载中心扫码进 App Store | App 名称同样叫「青虎云」 |
| Windows 电脑 | 下载中心的 Windows 客户端 | 官方标注支持 Windows 10 及以上 |
| Mac（Apple 芯片） | 下载中心的 macOS 客户端 | 原生版本 |
| 不想装任何东西 | 下载中心的微信小程序，或网页端 | 扫码即用 |
| Chrome / Edge 用户 | 下载中心的网页插件 | 在电商网页上采集商品图用（见实操篇） |

渠道与系统要求以官方下载中心当时显示为准。

## 三、安卓安装包从哪拿

两个来源，按你的情况选：

1. **本篇提供的 LinkPix 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/b7358b6f0ff4](https://pan.quark.cn/s/b7358b6f0ff4) —— 转存到自己的网盘后把 APK 下到手机，适合想固定用某个版本的情况；
2. 官方下载中心的 Android 客户端 —— 拿到的总是官方当前最新版，版本号可能和网盘里的那份不一致。

版本差异怎么核对，见第五节。

## 四、安卓安装步骤

1. 把 APK 下载到手机存储；
2. 点开 APK，系统若提示「禁止安装未知来源应用」，按弹窗提示允许这次安装（不同品牌手机的开关位置略有差异，一般就在安装弹窗里给入口）；
3. 等安装完成，桌面出现「青虎云」图标；
4. 首次打开需要登录，注册方法见 [注册登录与免费算力.md](注册登录与免费算力.md)；存储等权限按需授予即可。
