## 一、先开权限（默认是关的）

应用内置服务沿用上游默认权限，**初始账号的 WebDAV 默认不开启**，客户端直连会被拒。开启位置在管理后台：

1. 管理 → 用户 → 编辑你要用的账号（默认是 admin）；
2. 只想看和播放：勾选「**WebDAV 读取**」；
3. 还要在客户端里上传、改名、删除：再勾「**WebDAV 管理**」，并且要同时勾上对应的文件系统权限（创建目录或上传、重命名、删除等）——只勾「WebDAV 管理」一项是不够的。

## 二、连接参数怎么填

| 配置项 | 填什么 |
| --- | --- |
| 地址 | `http://手机IP:5244/dav/`（配了外网访问就换成对应域名地址） |
| 路径 | `dav` |
| 端口 | 与网页端一致，默认 `5244` |
| 协议 | http 或 https（走外网时建议 https） |
| 用户名 / 密码 | 与网页端登录用的完全一致 |

三个易错点：结尾的 `/dav/` 不能漏；端口必须和访问网页用的端口一致；密码就是网页登录密码，不是什么单独的 WebDAV 密码。

## 三、各平台客户端

| 平台 | 文件管理 / 挂载 | 媒体播放（可直连播放） |
| --- | --- | --- |
| Android | Solid Explorer、MiXplorer、X-plore | nPlayer、Kodi、VLC |
| Windows | RaiDrive（挂成网络磁盘）、Mountain Duck、rclone | PotPlayer、Kodi |

选型建议：想把手机文件服务变成电脑上的一个盘符，用 RaiDrive 这类挂载工具；电视盒子上看电影，用 Kodi 或 nPlayer 直接添加 WebDAV 源最省事。

## 四、典型场景

- **电视看网盘电影**：电视装 Kodi → 添加视频源选 WebDAV → 填上面的参数 → 直接浏览播放挂载的网盘视频，不用先把文件下到本地；
- **同一台手机自挂**：不想到处传文件，就在手机的文件管理器（MiXplorer、X-plore 等）里添加 WebDAV，地址填 `http://127.0.0.1:5244/dav`（端口以应用内为准），再配 nPlayer/MX Player 播放，应用开着时即插即用；
- **电脑当本地盘用**：RaiDrive 填参数挂成 Z: 盘，在资源管理器里直接拖拽复制；
- **出门在外**：把地址换成外网访问那一套域名端口即可，路线见 [外网访问与DDNS设置.md](外网访问与DDNS设置.md)。

连不上时按顺序排查：权限开了没有 → 地址端口对不对 → 账号密码对不对 → 手机端服务还在不在后台跑，对应处理办法都收在 [常见报错与解决方法.md](常见报错与解决方法.md)。
