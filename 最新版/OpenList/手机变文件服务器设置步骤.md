## 一、开始前的准备

- 手机和要访问它的设备（电脑、平板、电视）连在**同一个 Wi-Fi** 下；
- 先做后台保活：进系统 设置 → 电池（或「耗电管理」「应用管理」），把 OpenList 设为允许后台运行 / 关闭电池优化。不同品牌路径不同，目标一致 —— 别让系统半夜把服务杀掉；
- 如果打算把它当长期文件服务器用，建议插着电放在信号好的位置。

## 二、启动内置服务

打开应用即自动启动内置的 OpenList 服务。应用有两套界面：直接加载的 Web 界面（安卓默认）和原生界面（目前 Linux 默认），日常在安卓上你看到的就是 Web 管理页。

页面拉到底部（或进入日志区域）能看到启动日志，服务正常起来之后才继续下一步；如果启动失败，多见于存储权限没给，回系统设置补权限再重开应用。

## 三、登录管理界面

1. 用户名填 `admin`；
2. 初始密码是服务端首次启动时随机生成的，在应用内的日志区域能找到（不同版本界面有差异，以你手机上实际显示为准）；
3. 登录后第一件事：进管理后台的用户页，编辑 admin，**把初始密码改成自己的强密码**；
4. 如果密码连输错 6 次，当前 IP 会被封 30 分钟，重启应用即可立刻解封。

## 四、确认本机访问地址

- 应用通知栏和日志里一般会显示当前的局域网地址；
- OpenList 服务端默认端口是 `5244`，局域网里其他设备的浏览器访问 `http://手机IP:5244` 就能打开同一个界面（具体地址和端口以应用内显示为准）；
- 在**同一台手机**上访问自己，不用查 IP，浏览器或文件管理器里直接用 `http://127.0.0.1:5244` 即可；
- 想在家里网络之外访问，走内置的 DDNS-GO 或 GATEWAY-GO，见 [外网访问与DDNS设置.md](外网访问与DDNS设置.md)；
- 如果家里已有部署好的 OpenList/AList 服务器，也可以把应用切换成纯客户端去连它，见 [连接远程服务器与切换地址.md](连接远程服务器与切换地址.md)。

## 五、挂上存储再开始用

新服务里没有任何存储，首页会提示找不到存储。到管理后台把手机目录或网盘账号挂进来才能浏览文件，具体操作见 [挂载网盘与本地存储.md](挂载网盘与本地存储.md)。挂好之后，在电脑浏览器里就能像操作本地文件夹一样上传、下载、预览。

## 六、长期运行的三个习惯

- **保活**：电池优化白名单 + 自启动权限（部分品牌还有「锁定后台」的多任务卡片锁定）；
- **插电**：长期对外提供文件服务时，掉电中断会直接断掉所有访问；
- **Wi-Fi 固定**：路由器里给手机绑一个固定内网 IP，局域网地址就不会隔三差五变，DDNS/局域网直连都省心。
