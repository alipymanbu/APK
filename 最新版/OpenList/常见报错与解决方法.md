## 一、打开页面提示找不到存储

报错形如 `failed get storage: can't find storage with rawPath: /`。

这不是故障 —— 是你还没添加任何存储。点页面底部登录进管理后台，到「存储」页添加一条，加完刷新首页即可，具体步骤见 [挂载网盘与本地存储.md](挂载网盘与本地存储.md)。

## 二、登录密码相关

| 现象 | 处理 |
| --- | --- |
| 不知道初始密码 | 服务端首次启动会随机生成初始密码，在应用内的日志区域查看 |
| 密码连错被锁 | 连续输错 6 次，当前 IP 封 30 分钟；重启应用立即解封，只封这一个 IP，其他设备不受影响 |
| 忘记密码 | 已改过密码的话，在管理后台改成新的；彻底忘了就走服务端的重置方式（OpenList 支持随机生成或手动设置），应用内以实际提供的入口为准 |

## 三、添加存储报错

| 报错 | 原因与处理 |
| --- | --- |
| `UNIQUE constraint failed: x_storages.mount_path` | 挂载路径和已有存储重复了，换一个没被占用的路径 |
| `Too Many Requests` | 同一 IP 请求过于频繁触发了网盘频控（阿里云盘等常见），等一段时间再操作；看视频、下载不算在这类次数里 |
| `ExceedCapacityForbidden` | 网盘容量超限被限制，扩容或删掉不用的文件释放空间 |
| 保存成功但浏览报错 | 多数网盘驱动要求挂载路径对应的真实目录已存在，先去网盘里建好目录再挂 |

## 四、视频、音频、文档预览不了

- **视频黑屏/不支持**：浏览器一般不支持 H.265 编码视频和 AC3 编码音频，编码不支持就换文件或换播放方式（走 WebDAV 用 nPlayer、Kodi 等本地播放器硬解）；
- **Office 文档打不开预览**：在线预览走的是微软在线查看器，要求有域名、80/443 端口、外网可达，Word/PowerPoint 不超过 10 MB、Excel 不超过 5 MB —— 手机本地 IP 直连的场景基本用不了它，直接下载文件再看；
- **PDF 打不开**：PDF 预览基于 pdf.js，需要 https 与跨域支持，本地 http 直连受此限制，同样建议下载后查看。

## 五、WebDAV 能连上，但上传/改名/删除报权限错误

客户端（如 RaiDrive 往挂载目录里扔文件时提示「你需要权限来执行此操作」）能浏览却不能写，几乎都是**服务端用户权限没配全**：回管理后台 → 用户 → 编辑该账号，确认「WebDAV 管理」已勾选，并且同时勾上了对应的具体权限（创建目录或上传、重命名、删除等）——只开「WebDAV 读取」或只开「WebDAV 管理」都不够，详见 [WebDAV连接参数与客户端.md](WebDAV连接参数与客户端.md) 第一节。

## 六、服务与网络问题

- **日志里报 `failed get aria2 version`**：设备上没装 aria2 或配置不对，不影响其他功能，可以无视；
- **服务隔一会儿就断**：系统把后台杀了。把电池优化关掉、给自启动权限，部分品牌还要在多任务里锁定卡片；服务被杀后重新打开应用即可恢复；
- **局域网其他设备连不上**：确认手机和访问设备在同一 Wi-Fi、地址端口填的对（默认 5244，以应用内显示为准）、手机端服务正在运行；
- **外网连不上**：按顺序查域名解析 → 端口转发 → https 配置，路线见 [外网访问与DDNS设置.md](外网访问与DDNS设置.md)。

上面这些解决不了，先确认安装包本身没问题（重新校验来源、必要时重装），再对照 [下载与安装教程.md](下载与安装教程.md) 从头走一遍。
