## 一、这是个什么应用

OpenList 是 AList / OpenList 文件列表服务的跨平台客户端，**应用内直接内置了 OpenList 服务端**：装到手机上就能跑一个本机文件服务，不需要另外部署服务器、不用 Root、也不用 Termux。项目开源在 `https://github.com/OpenListApp/OpenListApp`（MIT 许可，Flutter 编写），同一开发者在 Google Play 与苹果 App Store 上以 Yalist 的名义发布同款应用。

你能用它做两类事：

- 把阿里云盘、百度网盘、OneDrive 等多个网盘聚合到一个界面里浏览、上传、下载；
- 把手机里的目录变成局域网或远程可访问的文件服务（配合 WebDAV 还能在电视、电脑上直接播放）。

## 二、从哪里获取安装包

有三条路，装哪个版本取决于你想怎么用：

1. **夸克网盘**：直接取 [OpenList 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b7c4bac85570) 里现成的 APK，转存后下载到手机即可，省去自己挑架构的步骤。
2. **GitHub Releases**：到项目的 releases 页面 `https://github.com/OpenListApp/OpenListApp/releases` 下载通用包 `app-release.apk`；也提供按 CPU 架构拆分的包（arm64-v8a / armeabi-v7a / x86_64），不确定自己手机架构就用通用包。
3. **Google Play**：搜 Yalist，适合能正常访问 Play 商店的设备。

GitHub 版与应用商店版（Yalist）功能同源，但包名与发布主体不同：商店版由开发者的公司主体发布、商店页面的隐私信息栏标注不收集数据（以商店页面当时显示为准）；本文安装包信息对应的是 GitHub 侧的 com.github.openlist.openlist 包。两版核心能力一致（内置服务端 + 客户端），装哪个都行，别混装两份即可。

## 三、安装步骤

1. 把 APK 下载到手机存储；
2. 点开安装，系统提示「禁止安装未知来源应用」时，按提示允许浏览器或文件管理器安装应用（各品牌叫法略有差异，一般在 设置 → 安全 里）；
3. 装完打开应用，首次启动如果弹出存储、通知等权限请求，按需允许 —— 文件服务要读写手机目录，存储权限基本是必须的；
4. 打开后应用会自动启动内置服务并加载管理界面，接下来怎么登进去、怎么改密码，见 [手机变文件服务器设置步骤.md](手机变文件服务器设置步骤.md)。

## 四、打开之前先知道三件事

- **它不是一个纯客户端**：应用启动时会在本机拉起 OpenList 服务，界面里加载的就是本机的 Web 管理页，所以第一次进去需要登录（默认账号 admin，初始密码在日志里，下一篇细讲）。
- **WebDAV 默认是关的**：初始用户沿用上游默认权限，想用 WebDAV 要先在管理后台给账号开权限，见 [WebDAV连接参数与客户端.md](WebDAV连接参数与客户端.md)。
- **服务依赖本机进程**：后台服务被系统杀掉后服务就停了，装完建议顺手把电池优化放行，避免频繁断连，排查方法见 [常见报错与解决方法.md](常见报错与解决方法.md)。
