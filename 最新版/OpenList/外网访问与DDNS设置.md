# OpenList 外网访问与DDNS设置

> 人不在家也想访问手机上的文件服务：局域网直连之外，应用内置的 DDNS-GO 和 GATEWAY-GO 分别对应有/无公网 IP 两条路。

## 一、先分清三种访问方式

| 场景 | 用什么 | 访问地址长什么样 |
| --- | --- | --- |
| 同一 Wi-Fi 内 | 局域网直连 | `http://手机IP:5244` |
| 有公网 IP | 内置 DDNS-GO | `http://你的域名:端口` |
| 无公网 IP | 内置 GATEWAY-GO | 经网关中转的地址 |

先把局域网直连跑通（能在家里的电脑上打开页面）再折腾外网，出问题时才好定位是服务的问题还是网络的问题。

## 二、有公网 IP：DDNS-GO

应用内置了 DDNS-GO（MIT 协议的开源项目），作用是把运营商经常变的公网 IP 自动绑定到一个固定域名上：

1. 在应用内找到 DDNS-GO 的设置入口；
2. 选你的 DNS 服务商（阿里云、腾讯云、Cloudflare 等都支持），填 API 凭证；
3. 填要绑定的域名，保存后它会自动跟随公网 IP 变化更新解析。

配好之后，外网访问就用域名代替手机 IP。注意两件事：家宽公网 IP 需要向运营商申请（部分宽带默认不给）；路由器要把 5244 端口转发到手机，否则域名解析对了也进不来。

## 三、无公网 IP：GATEWAY-GO

大多数国内宽带拿不到公网 IP，这条路用应用内置的 GATEWAY-GO（同为 MIT 协议）：手机通过一台有公网访问能力的网关服务器中转流量，把手机变成可远程访问的服务器。思路与内网穿透一致 —— 需要你准备一台可被公网访问的中转（自己的云服务器，或自建网关），在应用内配置网关地址与密钥后，客户端访问网关地址即可到达家里的手机。具体参数界面以应用内版本为准。

## 四、安全与稳定清单

外网一开，服务就暴露在公网上了，这几条比配置本身更重要：

- **admin 换强密码**：默认密码+公网端口是最常见的入侵入口；连错 6 次密码 IP 会被封 30 分钟，重启服务立刻解封，但也说明有人在试你的端口；
- **挂了网盘要节制分享**：官方明确提醒过，网盘账号被公开分享、被多 IP 访问可能触发风控冻结（阿里云盘等），个人自用别把链接发到公开渠道；
- **手机保持在线**：插电、电池优化白名单、固定 Wi-Fi，三件事缺一，外网地址随时失联；
- **有条件上 https**：明文 http 走公网，密码和文件内容都是裸奔，域名配好后在服务端设置里启用 https（或套一层支持证书的反代）。

设置过程中撞上报错，先去 [常见报错与解决方法.md](常见报错与解决方法.md) 对照排查；WebDAV 客户端连不上外网地址时，多半是端口转发或 https 配置的问题，参数本身见 [WebDAV连接参数与客户端.md](WebDAV连接参数与客户端.md)。
