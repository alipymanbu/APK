## 一、模板特效在哪、怎么用

模板是官方做好的「一段效果 + 提示词」组合，你只需提供素材照片。入口在首页的「模板 / Templates」标签，数量有几百种且持续上新（截至 2026-09 官方口径 500+，以 App 内实际列表为准）。

通用操作就四步：

1. 打开「模板」标签，浏览或搜索效果名；
2. 点进想要的模板，上传指定数量的人像照片（多数模板要 1 张，双人效果要 2 张）；
3. 点生成，等 30~60 秒；
4. 满意就保存 / 分享，不满意换张照片重来 —— 模板玩法里**换照片比调参数有效**，因为参数根本不给你调。

热门模板大多是社交向的：亲吻、拥抱、牵手这类双人互动，以及变身、换装、肌肉化这类单人改造。节日前后会上应景的限定模板。

两个官方文档里的限制，遇到报错时先对号入座：一是**部分特效不支持高清晰度**，选 720p / 1080p 会直接被拒（官方错误码明确列了「该特效不支持 720p 或 1080p」），退回 480p 就能跑；二是**特效有每月激活次数上限**，用完要等下月或升档 —— 免费额度省着用的另一个理由。

## 二、什么样的照片出片率高

模板效果全看你的素材质量，这些经验在各类 AI 视频工具里普遍适用：

| 照片情况 | 出片效果 |
| --- | --- |
| 正面、光线均匀、脸部无遮挡 | 最好，五官还原准 |
| 侧脸或微微侧头 | 多数能用，个别模板会变形 |
| 戴口罩、墨镜、刘海遮眼 | 大概率翻车，面部结构靠猜 |
| 模糊、夜景、逆光 | 不建议，容易出鬼图 |
| 双人模板用了角度差异大的两张图 | 身高体型对不上，换同角度的图 |

人脸类模板对单人照要求高；宠物、卡通形象也有对应模板，但效果上限不如人像稳。

## 三、口型同步：让照片里的人「说话」

口型同步（Lip Sync）是另一类常用功能：上传人像照 + 一段音频（或输入文字转语音），生成人物开口说话的视频，常用于口播、虚拟形象、梗图。

操作路径：

1. 在创作页或功能列表里找「口型同步 / Lip Sync」；
2. 上传一张正面人像照；
3. 提供声音：直接录一段、上传音频文件，或用内置的文字转语音选音色；
4. 生成后检查嘴型与声音是否对齐，不对齐就换更正的脸部照片重试。

注意两点：音频里别有背景音乐和多人说话，口型识别会被干扰；照片的脸占画面比例越大，口型越准。

## 四、这些玩法消耗多少积分

模板与口型同步同样走积分体系：模板生成按普通生成计费（时长、清晰度定档），口型同步另有一套计价。免费每日额度玩几个模板绰绰有余，具体扣费规则与省积分技巧见[积分与免费额度怎么用.md](积分与免费额度怎么用.md)；生成卡住、效果异常的排查见[常见问题与生成失败排查.md](常见问题与生成失败排查.md)。
