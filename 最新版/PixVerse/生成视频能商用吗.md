## 一、官方条款的基线口径

PixVerse 的服务条款（见官网 [pixverse.ai](https://pixverse.ai/) 页脚的 Terms of Service，运营主体为新加坡 AIVORA PTE. LTD.）对生成内容的归属是这样写的：

- 在**非商用范围内**，你保留自己输入素材的权利，也保留生成结果的权利；
- 但输出内容的使用**仅限非商业用途**，除非你另外取得授权或商用许可。

换句话说，「生成的视频算不算你的」和「能不能拿去赚钱」是两件事：权利归你，商用资格要另看你的订阅档位。官方模型页的 FAQ 也明确说「商用权利取决于你的订阅档位（subscription tier）」，发布商业内容前先确认自己的套餐。

## 二、水印是商用资格的「标记」

免费档生成的视频带平台水印，付费档下载的就是无水印版本。这两件事连在一起看：

| 你的情况 | 能否商用 |
| --- | --- |
| 免费档、视频带水印 | 不能 —— 条款默认非商用 |
| 付费订阅、下载无水印版 | 可以，官方博客明确「付费计划可下载无水印版本，用于 Meta、TikTok、YouTube、Amazon 等广告平台」 |

所以判断标准很简单：**当前档位下载下来带不带水印，基本就代表这套规则允不允许你商用**。档位价格与权益随时间调整，下单前以 App 内订阅页为准（档位对比见[积分与免费额度怎么用.md](积分与免费额度怎么用.md)）。

## 三、平台不管的两类责任

商用资格解决的是「你和平台之间」的问题。视频发出去之后还有两层责任在你自己：

1. **输入素材的权利**：你上传的人像、产品图、背景音乐，必须是你有权使用的。拿别人的照片生成拥抱、亲吻类视频拿去变现，平台条款帮不了你，肖像权纠纷自己担（模板类玩法的边界见[特效模板与口型同步怎么用.md](特效模板与口型同步怎么用.md)）。
2. **生成内容本身的合规**：条款要求输出内容不得侵犯他人知识产权或隐私。AI 生成的画面如果撞脸名人、复刻了受版权保护的角色，商用风险同样在你。

商用前的自查清单：订阅档位允许商用吗 → 视频无水印吗 → 上传的素材都有授权吗 → 画面里没有未授权的名人与 IP 吗。四项都过，再发布。

## 四、几个容易误判的场景

- **挂橱窗、接商单的账号**：属于商用，别用免费档的带水印视频。
- **自己账号的日常分享**：非商用，免费档够用。
- **给客户做的投放素材**：商用，且客户方通常要求你确认素材授权链完整。
- **用 API 批量生成再倒卖**：平台条款明确禁止未经书面授权把 API 生成的视频直接用于广告牟利，这条是红线。
