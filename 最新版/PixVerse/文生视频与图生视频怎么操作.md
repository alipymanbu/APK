## 一、开工前：两条路的区别

| | 文生视频 | 图生视频 |
| --- | --- | --- |
| 输入 | 一段场景描述文字 | 一张图片（可配一句动作描述） |
| 适合 | 从零构思一个场景 | 让已有的照片、产品图、插画动起来 |
| 上手难度 | 需要练提示词 | 更容易出效果，推荐新手先玩这个 |
| 消耗 | 按时长和清晰度扣积分 | 同左，另加图片上传 |

两条路的参数面板基本一致，学会一个另一个就通了。

## 二、文生视频：五步出片

1. **进创作页**：打开 App，点底部的「创作 / Create」，选「文生视频 / Text to Video」。
2. **写描述**：在输入框里写场景。别只写「一只猫」，写成「一只橘猫跳上窗台，午后阳光洒在毛上，镜头缓慢推近」—— 描述越具体，画面越可控。提示词的完整写法见下文第四节。
3. **选模型与风格**：模型选当前主推的版本（截至 2026-09 是 V6 系列，以 App 内列表为准）；风格在写实、动漫、3D 等里选一个。
4. **定参数**：
   - **时长**：免费档建议 5 秒起步，够表达一个动作；
   - **画幅**：发抖音 / Reels 选 9:16 竖屏，发视频号横版选 16:9；
   - **清晰度**：草稿用 480p，终稿再上 720p / 1080p，积分消耗差很多（见[积分与免费额度怎么用.md](积分与免费额度怎么用.md)）。
5. **点生成**：等 30~60 秒出片。不满意就改描述重新生成；满意就点保存或直接分享。

## 三、图生视频：让照片动起来

1. 进创作页选「图生视频 / Image to Video」。
2. 从相册选图：人像照、宠物照、产品图都行。图里主体越清晰、背景越干净，动起来越自然 —— 模糊、逆光、多人重叠的图容易出错。上传规格上有硬限制：单张图片不超过 20MB、边长不超过 10000px，格式或尺寸不合规会直接被拒（官方错误码口径），截图长图记得先裁一下。
3. 补一句动作描述，比如「她转头微笑，头发被风轻轻吹起」；不写也行，App 会给默认动态。
4. 同样选风格、画幅、时长、清晰度，点生成。

**图生视频的三条经验**：第一，想要人物动作大就明说（转身、跳跃、挥手），默认动态往往只是轻微呼吸感；第二，发人物照前想好授权问题，商用边界见[生成视频能商用吗.md](生成视频能商用吗.md)；第三，一次不理想就换张图，改提示词的收益不如换图明显。

## 四、提示词怎么写才可控

一个通用的写法框架是：**主体 + 场景 + 动作 + 镜头 + 光线/氛围**。逐项填空：

- **主体**：谁或什么在画面里（一个穿红裙的女孩、一辆复古敞篷车）；
- **场景**：在哪（雨夜的便利店门口、清晨的山顶）；
- **动作**：做什么（撑伞走过水洼、缓慢爬坡）；
- **镜头**：怎么拍（推进、环绕、特写、俯拍）；
- **光线 / 氛围**：什么样（霓虹灯反光、黄昏暖光、赛博朋克风）。

英文描述的出片稳定性通常比中文好，不确定就中英各生成一次对比。另外，描述里**别堆太多动作** —— 5 秒的片子放三个动作，每个都做不完。

两个硬性限制（官方接口文档口径）：描述别太长 —— 官方建议 25~200 个词，超过 2048 个字符直接报错；反过来只写几个词（如「山湖日出」）又太省，画面没有可执行的信息。写完卡在两头都不好。

## 五、生成之后还能做什么

- **延长（Extend）**：对满意的片段续接生成，把 5 秒拉成更长，多段拼成一个完整故事；
- **多镜头**：较新的模型支持一次生成多个镜头切换的片段，适合叙事感内容；
- **重生成**：同一段描述反复生成，每次结果不同 —— 免费额度就是让你多试几次的，别怕浪费；
- **去编辑器细调**：成品可进编辑工具裁剪、配乐，模板与口型同步玩法见[特效模板与口型同步怎么用.md](特效模板与口型同步怎么用.md)。

生成排队卡住、出了片没声音这类问题，排查步骤见[常见问题与生成失败排查.md](常见问题与生成失败排查.md)。
