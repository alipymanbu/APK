## 一、这条路解决什么

手上已经有一张 GIF（别人发的、网上存的、自己之前做的），想删几帧、拼两张、配句话、或者压小一点再发 —— 都在编辑这条路径里。格式互转也放在一起：GIF 能转成视频，视频与图片也能反向转成 GIF，三者是同一套素材的三种形态。

## 二、编辑一帧一帧改

进入 GIF 编辑入口、选中目标动图后，你能做这些：

| 操作 | 说明 |
| --- | --- |
| 逐帧查看 | 预览时显示帧序号，空白处滑动即可切换帧 |
| 删除 / 复制 / 移动帧 | 把不要的画面删掉、把关键帧复制延长、调整先后顺序 |
| 调播放速度 | 整体快放或慢放 |
| 加文字 | 多字体、字号、颜色、样式；文字可旋转，还能设定只在选定的帧范围内出现 |
| 加贴纸 | 贴纸同样支持旋转与「所在帧范围」设置，可以只让它在后半段出现 |
| 裁剪 / 背景 | 裁剪画面区域，背景颜色与画面比例可调 |
| 旋转 / 镜像 | 画面翻转、水平镜像 |

**合并多张 GIF**：在编辑/合并入口把多个动图按顺序接成一张 —— 拼接前先统一各段的速度与尺寸，接缝处才不会忽快忽慢。

## 三、抽帧：把动图拆回图片

「GIF 抽帧」把一张动图拆成多张静态图，「视频抽帧」对视频做同样的事。典型用法：

- 从一段教程视频里取出关键步骤图，配文字说明；
- 把动图里最清晰的一帧截出来当封面；
- 取出喜欢的表情帧单独保存。

抽出的图片进相册，可以再单独编辑或直接发。反过来，多张静态图合成动图走 [图片转GIF与表情包制作.md](图片转GIF与表情包制作.md)。

## 四、GIF 转视频、视频转 GIF

- **GIF 转视频**：在主页「更多」里找到「GIF 转视频」，选中本地 GIF 直接转换保存 —— 生成的 MP4 能进剪辑软件继续加工，也方便发到只收视频的平台。
- **视频转 GIF**：方向相反，完整步骤与画质取舍见 [视频转GIF制作教程.md](视频转GIF制作教程.md)。
- **图片转视频 / 图片转 GIF**：同一批静态图的两种去向，选 GIF 得到循环动图，选视频得到可插入剪辑的片段。

## 五、压缩：分享前把体积降下来

成品太大发不出去、发出去加载慢，用内置的 GIF 压缩功能处理一版。压缩的原理无非三个方向，对应到应用里的选项：

| 你想保住什么 | 调什么 | 代价 |
| --- | --- | --- |
| 体积最小 | 降画质档位 | 画面出现色块 |
| 体积较小、还清晰 | 缩小输出尺寸 | 分辨率降低 |
| 动画流畅度 | 减少帧数/降帧率 | 动作略跳 |

三条一起用效果最明显。先压缩到能发出去为止，还不满意再逐项回调 —— 每次改完预览一遍，确认文字没糊再保存。压缩后如果画质崩得厉害，退回原图换个方向调，别在一条路上死磕。

**具体压到多少（体积、宽度、帧率的数值口径）**，按微信等聊天软件的实测限制走，见 [微信发表情包太大怎么压缩.md](微信发表情包太大怎么压缩.md)。
