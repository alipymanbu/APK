## 一、导入视频/GIF 时等很久，正常吗

正常。素材越长导入越慢，这段时间应用在读取并拆解每一帧。做法就一条：**等进度走完，别中途杀应用**。确有急事要切出去，回来接着等即可，一般不会前功尽弃。想从根上缩短等待，导入前先把视频裁到只留要用的那几秒。

## 二、做出来的 GIF 太大，发不出去 / 加载慢

聊天软件对动图体积有上限，超了会发不出去、要手动点开才播、或直接变静止图。完整口径（压到多少、宽度卡在哪、在 GIF Master 里按什么顺序压）见 [微信发表情包太大怎么压缩.md](微信发表情包太大怎么压缩.md)；三个压缩方向的取舍见 [GIF编辑压缩与格式互转.md](GIF编辑压缩与格式互转.md) 第五节。

**先试最省事的一步**：重新转换时选中等或更低画质、宽度压到 720px 以内 —— 多数情况一次就发得出去。

## 三、转换后找不到成品在哪

两个地方查：

- **应用内的作品列表/我的文件** —— 转换、编辑的成品先落在这里；
- **手机相册** —— 保存成功时会同时写入相册，按保存时间排序翻最新。

两处都没有，说明保存没成功：多半是存储权限被拒（见下一条），或转换中途被杀掉了应用。重新转一次并保持前台运行。

## 四、导入失败 / 保存失败：权限问题

到 **系统设置 → 应用 → GIF Master → 权限** 里，确认「存储 / 照片与视频」权限是允许状态。之前点了「拒绝」且勾了「不再询问」的，权限列表里会显示「已拒绝」，手动改成允许再回应用重试。装好后的首次配置见 [下载与安装教程.md](下载与安装教程.md)。

## 五、安装失败或装上就闪退

按 [下载与安装教程.md](下载与安装教程.md) 的步骤排查：

1. **提示「无法安装未知应用」** —— 给下载用的浏览器或文件管理器授予「安装未知应用」权限，返回重装。
2. **解析错误 / 版本不兼容** —— 系统版本低于应用要求（采集记录标注需要安卓 5.2 以上，以安装时实际提示为准），或安装包下载不完整 —— 重新下载一次，核对大小是否为 38.75M。
3. **装上打开就闪退** —— 先确认手机可用空间（安装包 38.75M，解压安装还要更多）；仍闪退就卸载后重装一遍，数据清零不影响相册里已保存的作品。

## 六、几个高频疑问

| 问题 | 答复 |
| --- | --- |
| 转换要不要联网 | 转换与编辑在手机本地完成；联网权限主要用于加载在线贴纸素材，断网也能做纯本地转换 |
| 做的东西会丢吗 | 成品存在手机本地（应用作品列表 + 相册），不主动上传；但**卸载应用会清掉应用内的作品**，重要的提前在相册留存 |
| 网盘那份是不是最新版 | 网盘里是存入当时的版本（1.16.8 / 38.75M，记录于 2026-09-23），官方后续可能发新版本，以商店页面当时显示为准 |
| 安卓和苹果是同一个吗 | 功能定位相同，iOS 在 App Store 也有同名应用；本篇系列讲的是安卓包（`com.nionco.gif_master`） |
| 动图上有横向条纹、渐变处一圈圈色块 | GIF 每帧最多 256 色，渐变过渡只能近似 —— 这是格式本身的限制，不是压坏或手机问题；减轻办法是缩小尺寸后重转，或改用「GIF 转视频」发 MP4，见 [GIF编辑压缩与格式互转.md](GIF编辑压缩与格式互转.md) 第四节 |
| 动图节奏忽快忽慢、动作发跳 | 帧率太低或删帧删多了；重转时选更高的画质/帧率档，或回编辑页把删过的帧补回几帧，见 [微信发表情包太大怎么压缩.md](微信发表情包太大怎么压缩.md) 第二节的帧率参考 |
