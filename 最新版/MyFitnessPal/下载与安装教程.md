## 一、动手前先对上这张表

MyFitnessPal 是一款饮食与运动记录应用：你吃了什么、吃了多少、做了什么运动，都记进当天的日记，应用把它换算成热量与营养素，再跟你自己设定的每日目标对照。它适合想控制体重、调整饮食结构，或者需要长期盯住蛋白质摄入的人——不需要器械，也不需要先加入什么计划，愿意每天花几分钟记一记就能用起来。

安装本身不难，容易出问题的是**拿到的是不对的包**：同一个应用在网上有多个来源的安装文件，版本号和体积都不一样。所以先核对事实。

| 项目 | 值 |
| --- | --- |
| 应用名称 | MyFitnessPal |
| 开发者 | MyFitnessPal, Inc. |
| 版本号 | 25.17.1 |
| 包名 | `com.myfitnesspal.android` |
| 安装包大小 | 76.85M |
| 文件校验值（MD5） | `B38E78DD05DFD9E80576EE8575DEE0CA` |
| 系统要求 | 官方帮助中心给出的要求是 Android 9.0 及以上 |

其中**包名**最该看：它是应用在系统里的身份，`com.myfitnesspal.android` 这一串对上了，才说明装的是同一个应用。**版本号**决定你看到的功能跟本文描述的是不是同一套——MyFitnessPal 的更新节奏很快，应用商店里通常已经是比 25.17.1 更高的号，两边的数字不要混着用，一切以你手上这份文件为准。

## 二、把安装包取到手机里

1. 在手机上打开 [MyFitnessPal 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c7a6c55b163c)，进入分享页。
2. 还没有网盘账号的先按提示注册或登录；已有账号的直接用「保存到网盘」把目录转存进自己的空间，再从自己的网盘里下载。转存之后下载比在分享页里直接打开稳，分享页刷新或网络波动都不会把下载打断。
3. 下载完的文件名形如 `MyFitnessPal_v25.17.1.apk`。**别在网盘里直接点「打开」**，那只会触发在线预览；要选「下载」，等文件完整落到手机的下载目录再动手。
4. 想确认文件有没有下坏，拿上一节那串 MD5 对一遍：`B38E78DD05DFD9E80576EE8575DEE0CA`。很多文件管理器自带校验入口，算出来的字符串与这串完全一致，说明文件是完整的。

如果这一步卡在「网盘打不开」或速度特别慢，先换手机流量、或者等网络空闲时段再试，这类情况跟安装包本身没关系。

## 三、允许从浏览器或网盘安装

Android 默认不允许安装来自浏览器、网盘这类来源的文件，第一次装通常会弹「已阻止安装」。开关位置按系统版本分两种：

| 系统版本 | 操作路径 |
| --- | --- |
| Android 8.0 及以上 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 → 选中你下载用的浏览器或网盘 App → 打开开关 |
| Android 7.x 及以下 | 设置 → 安全 → 打开「未知来源」 |

开关打开后回到文件管理器，点 `MyFitnessPal_v25.17.1.apk` 继续。装完建议把开关关回去，以后需要临时再开。

## 四、安装过程中可能出现的提示

| 提示 | 含义与处理 |
| --- | --- |
| 「解析软件包时出现问题」 | 文件没下完或已损坏。删掉重新下载，并按第二节的方法再校验一次 MD5 |
| 「应用未安装」 | 手机上已存在同一个包名的其他版本。先在设置里卸载旧的，再装这一份 |
| 「您的设备与此版本不兼容」 | 系统版本低于应用要求。对照第一节的系统要求，确认你的 Android 版本 |
| 安全软件提示风险 | 非应用商店来源的常规提醒。确认文件来自你信任的渠道后继续 |
| 装完桌面上找不到图标 | 部分启动器刷新慢，回桌面下拉一次，或在应用列表里搜索「MyFitnessPal」 |

## 五、第一次打开要做的几件事

1. **登录或注册账号**。MyFitnessPal 的日记、目标、运动记录全部挂在账号上，不登录就进不去主界面。注册环节的邮箱验证、密码规则等细节见 [注册登录与账号同步.md](注册登录与账号同步.md)。
2. **按提示授予权限**。相机权限是给条码扫描和拍照识别用的，通知权限用于提醒你记录，健康/活动权限用于读取步数。这些现在拒绝也不影响安装，之后随时能在系统设置里补开。
3. **填写基础资料与目标**。应用会依次问你性别、年龄、身高、当前体重、目标体重、每周想减或增多少、日常活动量，然后用这些算出你的每日热量目标。这部分资料后面还能改，目标是跟着变的，改法见 [热量目标与营养素怎么看.md](热量目标与营养素怎么看.md)。

走完这三步，首页就会出现当天的日记页。接下来怎么把吃的东西记进去，看 [怎么记录每天吃了什么.md](怎么记录每天吃了什么.md)。
