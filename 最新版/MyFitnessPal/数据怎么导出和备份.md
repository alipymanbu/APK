## 一、导出拿到的是什么

官方的做法是：**把文件发到你的注册邮箱，一封邮件带一个 ZIP 包，里面是三个 CSV 文件**。CSV 是纯文本表格，用 Excel、Google Sheets、Numbers 都能打开。

| 文件 | 里面有什么 |
| --- | --- |
| 按餐汇总的营养明细 | 你记过的食物带来的热量、宏量营养素、微量营养素，带时间戳，还包括你在食物条目里写过的备注 |
| 进度历史 | 记录过的身体数据，例如体重、颈围、腰围、臀围 |
| 运动历史 | 运动日记里的条目（项目、时长等） |

拿到的是数据和字段，不是图表、也不是应用界面——想还原成手机上的样子是做不了的，它的用途是自己存档、做表格分析、或者拿给教练和营养师看。

## 二、三个平台各自的入口

| 平台 | 路径 |
| --- | --- |
| Android | More 菜单 → 进 Progress 或 Nutrition 页 → 右上角的导出图标（像一张折角的纸）→ File Export → 确认收件邮箱与日期范围 → 导出 |
| iOS | More 菜单 → Nutrition → 右上角 Export → 点 Date Range 选日期范围 → Export My Information |
| 网页版 | 登录后点 Reports → 右侧的 Export → 选日期范围与邮箱 → Export |

三处都是**发到你注册账号用的那个邮箱**；网页端的导出页上可以直接改收件地址，注册邮箱已经不用了的话走网页版更省事。

## 三、提交之后要做什么

导出是异步处理的：请求提交完就可以离开，去邮箱等。官方没有给固定时长，**提交后半天内没收到，先翻垃圾邮件**；这封邮件来自系统发件地址，容易被拦。收到 ZIP 后建议先存到本地再解压，别在邮件里直接预览。

## 四、这条功能到底算不算会员功能

两种说法目前都在网上流传，先并列摆出来：

- 官方把「数据导出」这篇说明**放在会员功能分类下**，按官方口径它是随会员提供的；
- 也有第三方说明称所有账户都能导出，只是导出范围有差别。

**以你账号里实际能不能看到导出入口为准**——免费版打开 Reports 页面看一眼最快，看到 Export 按钮就是能用。功能归属会调整，不要拿别人的截图当准。

## 五、动手前先想清楚三件事

1. **顺序：先导出，再动账号。** 打算注销账号或退订的话，先把文件拿到手再操作。
2. **它是一份快照，不是持续同步。** 导出的是你请求那一刻之前的数据，之后新记的内容不会补进这份文件里，要新的就再导一次。
3. **文件里有个人健康数据，包括你自己写的备注。** 要转发给教练、医生或朋友之前，先打开看一眼有没有不想外传的内容。

## 六、什么时候需要导出，什么时候不需要

- **换手机、重装应用不需要导出**：记录挂在账号上，用同一个账号登录就回来了，流程见 [注册登录与账号同步.md](注册登录与账号同步.md)。
- **需要长期存档、或者要拿数据给别人看时才导出。** 只想留一份给别人过目的记录，官方列的免费功能里还有一条更省事的：网页版支持打印报告，不用等邮件。
- 导出属于把数据「拿出来」，不改变账号里的任何记录，也不会让日记变空——导完回手机上看，记录还是原样。
