## 一、动手前先做这三步

多数异常用这三步就能定位到方向，别一上来就折腾安装包：

1. **确认系统版本**：官方要求 Android 9.0 及以上，低于这个版本应用可能装得上但用不了。
2. **用同一个账号去网页版登一次**：网页版能登、只有应用不行，问题在应用端；两边都不行，问题在账号。
3. **卸载重装**：这是官方对多数异常的第一条建议。前提是数据已经同步上去了（网页版能看到你的日记），否则本地没上传的内容会一起没掉。

## 二、登录相关

| 现象 | 先做什么 |
| --- | --- |
| 提示 Invalid email or password | 先去网页版用同一组邮箱和密码登一次；还是不行就走登录页的忘记密码，重置后再登 |
| 收不到密码重置邮件 | 查垃圾邮件；把 `no-reply@myfitnesspal.com` 加进联系人；仍收不到就是账号绑的是另一个邮箱，换你注册时可能用过的邮箱重试 |
| 提示 Unable to connect to server | 先看官方公告页有没有在报故障；再用网页版验证账号是否正常；之后按第一节卸载重装 |
| 用 Facebook 登录一直卡在加载页 | 官方已确认的已知问题。改用邮箱（或用户名）加密码登录；需要密码就走忘记密码流程设置一个 |
| 从桌面小部件打开时被要求重新登录 | 官方已确认的已知问题。别从小部件进，直接打开应用登录 |

## 三、数据同步相关

| 现象 | 说明与处理 |
| --- | --- |
| 手机记了，网页版日记一片空白，好友也看不到 | 官方已确认的 Android 端同步问题，表现为记录传不到网页版、也传不给已连接的第三方服务，官方标注在 26.18.2 版本修复。版本比它低就先更新应用再判断 |
| 换了设备后记录不见 | 先确认登的是不是同一个账号；同一账号且联网时会自动同步 |
| 某天的消耗或摄入明显偏高 | 常见原因是重复记录：设备自动同步了一次，你又手动记了一次 |
| 修改网站上的目标后手机没变 | 手机需要联网同步一次才会显示新值 |

## 四、条形码扫描、拍照识别用不了

按这个顺序查，从最常见的开始：

1. **是不是免费版**。2022 年 10 月 1 日起扫描属于会员功能，免费版点了没反应或提示订阅是正常的，功能对照见 [免费版与会员有什么区别.md](免费版与会员有什么区别.md)。
2. **相机权限有没有给**。要去**系统设置**里给应用开相机权限，不是应用内部的设置。拒绝过一次之后，相机页会一直是黑的。
3. **设备有没有后置摄像头**。只有前置摄像头的设备用不了扫描。
4. **已订阅却仍被锁**。退出账号重新登一次，强制同步订阅状态；刚开通试用的等十几分钟再试。
5. **扫出来是别的食物**。可以手动改成正确的条目，保存后不影响已有的记录。

## 五、数字对不上

| 对不上的地方 | 先去核对什么 |
| --- | --- |
| 运动消耗 | 它是按项目、时长、体重估算的，不是实测；不同来源的数字本来就有差异。另外检查有没有重复记录 |
| 某样食物的热量 | 份量有没有填错；是不是选了其他品牌的同名条目 |
| 自建食物的热量 | 回 My Foods 里核对，最常见的是每 100 克和每份的数值填反 |
| 目标额度 | 有没有把运动消耗算进去了；目标是不是后来改过。算法说明见 [热量目标与营养素怎么看.md](热量目标与营养素怎么看.md) |

## 六、卸载重装会不会丢数据

不会丢，前提是数据已经同步到账号上——记录挂在账号下，不在这台手机里。做法是：卸载前先用网页版确认日记都在；重装后用同一个账号登录，数据会同步回来。还没同步上去的内容，卸载后找不回来。

重装用的安装包从手机上的 [MyFitnessPal 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c7a6c55b163c) 取，核对版本与包名的步骤见 [下载与安装教程.md](下载与安装教程.md)；注册、登录方式和同步机制的细节，见 [注册登录与账号同步.md](注册登录与账号同步.md)。

## 七、导出与食物库相关的三条

| 现象 | 说明与处理 |
| --- | --- |
| 导出的邮件一直没收到 | 导出是异步发送的，官方没给固定时长。先翻垃圾邮件；注册邮箱已经停用的话，去网页版走 Reports → Export，在导出页上把收件地址改成现在能收的。完整流程见 [数据怎么导出和备份.md](数据怎么导出和备份.md) |
| 网页版的「导入食谱」入口用不了 | 官方注明食谱导入功能目前只在设备或网页语言为英文时可用；语言不是英文时改用手动输入配料，配料多可以用批量导入，把一段配料文字贴进去让它自己匹配 |
| 找不到「我的食物」（My Foods）标签 | 官方说明：应用语言设为英文以外的语言时，Recent、Frequent、My Foods 三个标签可能被合并成一个叫「Recent」或「Food」的标签。内容还在，只是入口合到一处 |

## 八、还是要找官方时

- 帮助中心（英文）：[support.myfitnesspal.com](https://support.myfitnesspal.com/hc/en-us)，里面有公告页和已知问题清单，报障前值得先看一眼。
- 应用内的 FAQ / Feedback 页面底部有联系入口，也可以直接发邮件到 `support@myfitnesspal.com`。
- 提问题时把这几样一并说清楚，能省一轮来回：应用版本号、手机系统版本、具体看到什么提示、网页版能否正常使用。
