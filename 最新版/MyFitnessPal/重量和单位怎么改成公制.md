# MyFitnessPal 重量和单位怎么改成公制

> 本篇讲默认的美制单位怎么换成公制：体重从磅换成公斤、身高换厘米、距离换公里、能量在千卡和千焦之间怎么选，以及每一项改完哪些显示会跟着变。

## 一、为什么上来就该先改单位

单位是这个应用里最该在第一天就改完的一项设置——它决定你看到的每一个数字要不要在脑子里换算一遍。本篇讲清四类单位各在哪里改、改完哪些显示跟着变。

MyFitnessPal 是美区产品，新账号默认按英制显示。不改也能用，但会有两个具体的麻烦：称出来是公斤、要自己换算成磅再填；食物的份量单位是盎司、杯，跟中国食品标签上的克对不上。

官方帮助中心确认可以改的有四类：**体重、身高、距离、能量**。

## 二、手机端怎么改

菜单（或 More 页）→ Settings → Edit Profile（部分版本显示为 Profile）→ Units → 逐项选 → 保存。

| 项目 | 可选单位 |
| --- | --- |
| 体重 | 公斤（kg）/ 磅（lbs）/ 英石加磅（st lbs） |
| 身高 | 厘米 / 英尺英寸 |
| 距离 | 公里 / 英里 |
| 能量 | 千卡（kcal）/ 千焦（kJ） |

官方在那条说明里特意强调了一句：**所有更改都要保存**。改完看着没变化的，先回这一页确认是不是没点保存。

## 三、网页版怎么改

登录 [www.myfitnesspal.com](https://www.myfitnesspal.com/) → My Home → Settings → Change Units。网页和手机用的是同一套账号设置，改完联网同步一次，另一边也会变。

## 四、千卡和千焦别搞混

这一项最容易被忽略。应用里的「卡路里」实际指的是**千卡（kcal）**，就是日常说的「大卡」；而中国市售食品的营养成分表通常用**千焦（kJ）**标注。两者换算：

```
1 千卡 ≈ 4.184 千焦      1 千焦 ≈ 0.239 千卡
```

举个实际的例子：标签上写「能量 1000 kJ / 100 g」，要填进应用的数是 1000 ÷ 4.184 ≈ **239 千卡**。两者差 761 千卡——按 1000 填进去，这一条就比实际多算了七百多千卡。

反过来说，如果你的习惯是照着标签读千焦，把能量单位也切到千焦，读数就对得上了——应用会自动按你选的单位显示。

## 五、食物份量的单位不在这张表里改

第二节那张表管的是「体重 / 身高 / 距离 / 能量」这四项账号级显示设置，**食物份量的单位不在其中**——每条食物按它自己的计量方式显示，克、毫升、杯、盎司、个、片都可能出现。想换一种计量方式，要在**份量页**上切，不是回设置里找。

碰上只按盎司、杯标注的条目，这几个换算记住就够用：

| 常见单位 | 换算 |
| --- | --- |
| 1 盎司（oz） | ≈ 28.35 克 |
| 1 磅（lb） | ≈ 454 克 |
| 1 杯（cup） | ≈ 240 毫升 |
| 1 液量盎司（fl oz） | ≈ 30 毫升 |

比每次换算是更省事的做法：直接找一条用克标注的同类条目——同一个食物在库里常常有好几个计量版本。

## 六、改完体重单位，历史记录怎么算

官方那条说明只交代了「在哪里改」，没有说历史记录会怎么处理。最稳的做法是：**改之前先把当前体重数字记下来**，改完回进度页对一眼——数字是按新单位换算过、还是需要重新记一次，你自己账号上是哪种，一眼就看得出来。

## 七、改完还是不对，看这几处

| 现象 | 检查什么 |
| --- | --- |
| 手机上改了，网页还是旧单位 | 两边共用账号设置，联网同步一次；仍不生效就在网页端也改一次 |
| 只改了体重，食物份量还是盎司 | 食物份量的单位跟着每条食物自己的计量方式走，不受体重设置影响；在份量页切换计量方式 |
| 身高/距离没变 | 这三类要逐项改，改体重只影响体重 |
| 保存了没反应 | 回 Units 页确认保存是否生效，必要时退出账号重新登录一次 |

单位对上之后，记食物和记体重的操作本身没有变化，只是数字不用再心算了。
