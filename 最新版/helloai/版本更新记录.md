## 一、版本号怎么读、去哪核对

HelloAI 的安卓版与 iOS 版**各自独立编号**，同名不同号是正常的，别拿一边的版本去对另一边。核对方式：

- 安卓：装的这份包看 [下载与安装教程.md](下载与安装教程.md) 的安装包信息；商店页版本以页面当时显示为准。
- iOS：App Store 该应用的「版本历史记录」页。

## 二、安卓版

你手上的安装文件是 **1.7.2**，包名 `hello.ai`。应用商店里该版本的更新时间显示为 2026 年 1 月 11 日（以页面当时显示为准）。

各版本加了什么功能，官方更新说明里有迹可循。下表按功能加入的先后顺序归纳（版本号取自官方版本历史，功能在安卓各版本的落地时间以商店页为准）：

| 版本方向 | 加了什么 |
| --- | --- |
| 早期 1.x | AI 音乐、论文功能；首页联网搜索、写作、翻译；多文件上传与消息推送 |
| 1.x 中段 | 对话生成预览修复；智能体功能优化 |
| 1.7 前后 | AI 改图、思维导图调整，新增对话图表、改稿功能 |
| 1.8 ~ 1.9 | DeepSeek 线路、AI 数字人、DeepSeek 联网搜索 |
| 2.x 方向 | 新版智能体功能；首页改版并接入 veo3 视频；NanoBanana 视频生成；后续多次更新视频生成线路 |

上表是功能演进的脉络，**不等于你这版全有**——以你安装后界面上实际出现的入口为准。哪个功能是哪版进的，对照时以商店页更新说明为准。

## 三、iOS 版（App Store）

iOS 版走的是另一条版本线，版本历史如下（时间为 App Store 公示）：

| 版本 | 时间 | 更新说明 |
| --- | --- | --- |
| 2.5 | 5月21日 | 更新了新的线路，修复了一些未知问题 |
| 2.4 | 2025-11-04 | 修复了一些未知问题 |
| 2.3 | 2025-10-09 | 更新视频生成线路 |
| 2.2 | 2025-09-25 | 上新视频线路，添加 NanoBanana 视频生成 |
| 2.1 | 2025-08-28 | 首页改造升级，新增 veo3 视频功能 |
| 2.0 | 2025-04-12 | 上线新版智能体相关功能 |
| 1.9 | 2025-02-26 | 增加 DeepSeek 联网搜索 |
| 1.8 | 2025-02-07 | 新增 DeepSeek 线路，新增 AI 数字人 |
| 1.7 | 2025-01-17 | 调整 AI 改图、思维导图，新增对话图表、改稿功能 |
| 1.6 | 2024-11-22 | 优化了智能体功能 |
| 1.5 | 2024-11-06 | 修改文字大小，修复对话生成中无法预览的问题 |
| 1.4 | 2024-11-02 | 多模态可上传多文件；增加消息推送 |
| 1.3 | 2024-10-22 | 新增首页联网搜索、写作、翻译等功能 |

| 1.1 | 2024-09-02 | 增加 AI 音乐、论文等功能 |

从这个节奏能看出两件事：**视频线路是近两年的更新重点**（veo3、NanoBanana、多次线路更新都落在这一块）；小版本多为「修复未知问题」式的维护更新。想找某个视频能力在哪版出现，直接查上表即可。
