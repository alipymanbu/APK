## 一、搜的是「标签」，不是「关键词」

safebooru 这类图库（booru 体系）里的每张插画都由社区逐张打上英文标签，搜索框匹配的就是这些标签，而不是图片标题。这带来三个直接影响：

- **要用英文搜**。标签库以英文为主，输入中文几乎没有命中；想找「蓝头发」，输入的是 `blue_hair`；
- **词组中间用下划线**。标签内部不留空格，词与词之间用下划线连接，比如 `long_hair`；
- **标签越多，结果越少**。多个标签是「同时满足」的关系，先少后多更容易找到想要的内容。

## 二、标签的几种身份

按 safebooru 站点帮助页的说明，标签分几种类型，网页版里用颜色区分：

| 类型 | 含义 | 例子 |
| --- | --- | --- |
| 画师（artist） | 这张图是谁画的 | 具体画师名 |
| 角色（character） | 画的是哪个角色 | 具体角色名 |
| 作品（copyright） | 出自哪部动画、游戏、漫画 | 具体作品名 |
| 通用标签 | 发色、服装、动作、构图等画面内容 | blue_hair、long_hair、1girl |

角色名和作品名多用日文罗马音而非英文翻译（角色的名字直接按日语读音拼写），搜不到时先想想「这个词在标签库里叫什么」。

## 三、组合写法

搜索框里最常用的两种符号：

| 想要的效果 | 输入写法 | 说明 |
| --- | --- | --- |
| 同时满足多个条件 | `blue_hair 1girl` | 空格分隔，取交集 |
| 排除某个标签 | `touhou -1girl` | 减号紧跟标签，中间不能有空格 |

Gelbooru 系图库还支持「或者」与通配符写法（`{标签1 ~ 标签2}` 表示命中其一，`hakurei*` 匹配以此开头的标签）。这类写法在 safebooru 上能否生效、具体格式，以站点帮助页与实际搜索结果为准，拿不准就先用「交集 + 排除」这两种基本款。

## 四、元标签：按图片属性筛

除了内容标签，还有一类「元标签」（metatag）按图片本身的属性筛选。常用的几个：

| 写法 | 作用 |
| --- | --- |
| `width:1920` | 只看宽度 1920 的图（高度同理用 `height`） |
| `score:>=100` | 只看达到某个评分的图 |
| `sort:random` | 随机出图，适合不知道搜什么的时候闲逛 |

注意两点：不同站点对元标签的支持范围与具体格式有差别，完整清单以站点帮助页为准；客户端里的搜索框与网页版语法一致，但个别元标签在客户端能否生效，以实际搜索结果为准。

## 五、借用「相关标签」扩展条件

在网页版搜索时，页面侧栏的标签列表会列出与当前搜索相关的标签，点旁边的加号 / 减号就能把它加进或排除出当前搜索。想细化条件时，顺着相关标签走比凭空想词快得多；某个标签属于哪种身份，对照第二节表格里的说明即可。

## 六、搜不到结果时的排查顺序

1. **确认用的是英文**，中文关键词换成语义对应的英文标签；
2. **检查下划线**，`blue hair` 要写成 `blue_hair`；
3. **删掉几个标签再试**，条件太多交集为空，先保留最关键的一个；
4. **核对标签是否真的存在**，可以在 safebooru 网页版（[safebooru.org](https://safebooru.org)）里搜同一个标签确认，网页版的标签联想比客户端直观；
5. 还是不行，看 [常见问题与解决.md](常见问题与解决.md) 里的其他原因。

## 七、几个马上能用的搜索例子

| 目的 | 可以输入 |
| --- | --- |
| 找某部作品的角色图 | `touhou hakurei_reimu`（作品标签 + 角色标签） |
| 排除不想看的内容 | 作品标签后加 `-排除的标签` |
| 按分辨率找壁纸素材 | 描述标签 + `width:1920`（写法以站点帮助页为准） |
| 无目的闲逛 | `sort:random` |

找到图之后的浏览、看原图与保存操作，见 [浏览与下载插画.md](浏览与下载插画.md)。
