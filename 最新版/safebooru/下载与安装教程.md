## 一、安装前先核对这几点

safebooru 是一个面向二次元爱好者的插画搜索工具，安卓安装包体量很小。你拿到手的安装包应当与下面的信息一致（这是安装包文件本身的固定信息）：

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.0 |
| 安装包大小 | 3.37M |
| 包名 | com.safeboo.xxrjy |
| MD5 | 1BD9844E6D257557C81D1B90B796F7A1 |
| 系统要求 | 安卓 5.2 以上（以安装时的实际提示为准） |

网上能搜到 safebooru 的其他版本号，那些对应别的安装包；判断手里这份是哪一版，以上表为准。

## 二、从哪里获取安装包

安装文件资源放在夸克网盘里，取用路径是固定的三步：

1. 打开上方网盘提示块里的链接；
2. 把分享里的安装包转存到自己的夸克网盘（手机或电脑上都能操作）；
3. 在自己网盘里找到转存后的 `safebooru_v1.0.apk`，下载到手机本地。

转存这一步不能省：分享链接只保证你能看到文件，先转存再下载才稳定。

## 三、安装步骤（安卓手机）

1. 在文件管理器里点开下载好的 `.apk` 文件；
2. 系统提示「禁止安装未知来源应用」时，按提示允许该来源安装（不同品牌的入口不一样，一般在 设置 → 安全 / 应用管理 附近）；
3. 回到安装界面，点安装，等待完成；
4. 完成后桌面上会出现 safebooru 的图标。

安装包只有 3.37M，安装本身很快，存储空间紧张的手机也能装。

## 四、装好后的第一次打开

打开应用后你会看到插画列表和一个搜索框。有两点提前说清楚，能少走弯路：

- **搜索用英文标签**。这类图库的内容靠英文标签组织，中文关键词的命中率很低，具体写法见 [搜索技巧与标签用法.md](搜索技巧与标签用法.md)；
- **列表里的图是缩略图**。点进详情页才能看到大图与原图入口，操作细节见 [浏览与下载插画.md](浏览与下载插画.md)。

第一次打开如果遇到白屏、加载不出来，多半是网络问题，处理思路见 [常见问题与解决.md](常见问题与解决.md)。

只看图、不在乎个性化功能的话，也可以不装应用，直接用手机浏览器访问 [safebooru.org](https://safebooru.org)；收藏、屏蔽标签这类设置在网页版更齐全，见 [账号与屏蔽标签设置.md](账号与屏蔽标签设置.md)。

## 五、安装失败时的排查

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包出现问题」 | 安装包下载不完整或损坏 | 重新下载一次；较真一点的可以核对 MD5 |
| 提示存储空间不足 | 手机剩余空间太小 | 清出至少几百 MB 再装 |
| 点开安装包没反应 | 文件管理器没有安装权限 | 换系统自带的「文件管理」打开，或允许其「安装应用」权限 |

想核对安装包是否完整，可以在电脑上用命令行查看 MD5：

```bat
certutil -hashfile safebooru_v1.0.apk MD5
```

输出的哈希值与第一节表格里的 MD5 一致（不区分大小写），说明文件完整。
