# safebooru 账号与屏蔽标签设置

> 客户端之外，safebooru 网页版的账号能做收藏、屏蔽标签等个性化设置：本篇讲这些功能各管什么、在哪设。

## 一、什么时候才需要账号

在客户端里浏览、保存插画不需要任何账号。只有当你想在 safebooru 网页版做下面这些事时，注册一个免费账号才有意义：收藏图片、屏蔽不想看的标签、发帖交流（功能范围以站点当前政策为准）。

注册入口在 [safebooru.org](https://safebooru.org) 页面上方的登录区域，按提示创建即可。

## 二、账号能设置什么

登录后进入账号设置页（My Account → Settings），常用的几项如下：

| 设置项 | 作用 |
| --- | --- |
| Tag Blacklist（标签黑名单） | 命中黑名单标签的图在浏览时直接隐藏，标签、内容分级、上传者都可以设 |
| Comment Threshold（评论阈值） | 低于设定分数的评论不显示 |
| Post Threshold（图片阈值） | 低于设定分数的图不显示 |
| Safe Only Listing | 首页列表只显示标记为安全的图 |

这些设置都作用于网页版，与客户端互不相干。

## 三、标签黑名单怎么写

黑名单按行写规则，几条基本规则（以站点帮助页为准）：

- **一行一条规则**，多个规则各占一行；
- 一行内写多个标签（空格分隔）= 一张图**同时包含**这些标签才隐藏；
- 单独一个标签一行 = 只要包含就隐藏；
- 减号开头表示「不包含」。

举个不涉及内容的例子：想让含剧透标记的图默认隐藏，就单独写一行对应的标签；想给规则留例外（隐藏某标签、但图片还带另一个标签时不隐藏），在同一行末尾用减号写上例外标签。

设好黑名单后，浏览时被隐藏的图会在侧栏的黑名单框里显示数量，你可以按规则临时开或关。

## 四、网页版设置解决不了的问题怎么办

- **客户端里想避开某类内容**：网页版黑名单管不到客户端，搜索时直接加排除标签更直接（写法见 [搜索技巧与标签用法.md](搜索技巧与标签用法.md)）；
- **黑名单误伤了想看的图**：回设置页检查规则，一行多标签的规则是最容易误伤的写法；
- **图库范围本身没有的图**：换个标签或换个图库站，见 [同类图库站对照.md](同类图库站对照.md)。

保存插画与看原图的操作在客户端里就够用，步骤见 [浏览与下载插画.md](浏览与下载插画.md)。
