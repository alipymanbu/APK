# 登录一直转圈、启动就闪退的排查

> 这两个是安卓版 Viewer 最集中的两类故障：登录卡在加载页、一点图标就退出。本篇按官方团队在社区论坛给过的答复整理排查顺序。

## 一、登录一直转圈：先看 Chrome 在不在

官方团队在社区论坛答复过这个现象：安卓版 Viewer 的登录验证依赖设备上的 **Chrome 浏览器处于已安装并启用状态**——不必设为默认浏览器，但要有、且没被停用。很多手机出厂精简了 Chrome，或者你手动停用过它，登录就会一直卡在加载页。

动作：设置 → 应用 → 找到 Chrome → 启用（没有就去应用商店装一个），回到登录页再试。官方答复里提到登录成功后 Chrome 或许可以再卸载，这一步没有被广泛验证；而且这条答复年代较早，5.5.0 上是否仍然如此，以你设备实测为准。

其他登录问题（验证码收不到、第三方登录混用、密码规则）见 [注册登录与账号问题.md](注册登录与账号问题.md)。

## 二、启动就闪退：按这个顺序清

官方团队给过的通用排查顺序，多数启动闪退出在前两步：

1. 设置 → 应用 → SketchUp Viewer → 存储：先「清除缓存」，再「清除数据」——清数据会连登录状态一起清掉，重新登录即可；
2. 还闪退就「强制停止」后卸载，重新安装一遍再试；
3. 插着存储卡的机型，取下存储卡再开——官方论坛有过存储卡引起闪退的案例；
4. 把系统更新到最新；设备 root / 越狱状态不在官方支持范围内。

安装包本身有问题（下载不完整、MD5 对不上）也会一开就退，先回 [下载与安装教程.md](下载与安装教程.md) 第三节核对 MD5。

## 三、能打开但一操作就退出

这类多半是模型体量问题，不是应用坏了。官方团队给过的参考口径：移动端按 **10MB 上下的模型**设计，二三十 MB 就开始不稳、越大事越看设备运气；社区里也有用户反馈几十 MB 以上的模型频繁闪退。瘦身做法整理在 [常见问题与排查.md](常见问题与排查.md) 第六节，模型怎么传进手机见 [SKP模型怎么打开.md](SKP模型怎么打开.md)。
