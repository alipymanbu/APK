## 一、为什么要登录、用什么登录

Viewer 里的云端来源（3D Warehouse、Trimble Connect、Dropbox）都要先登录 Trimble ID 才能用。这个账号是 Trimble 家产品通用的：网页版 SketchUp、3D Warehouse、Extension Warehouse、官方论坛都用它，注册一次到处用。

登录方式两种二选一：邮箱注册的 Trimble ID，或者直接用 Google / Apple / Microsoft 账号登录。

## 二、注册一个 Trimble ID

在应用登录页或官网（[www.sketchup.com](https://www.sketchup.com/)）点 Sign In，再点 Create a Trimble ID：

1. 选所在地区；
2. 填名字和邮箱；
3. 同意条款，等验证码邮件（收不到先翻垃圾箱）；
4. 设密码——至少 8 位，必须含数字、大写字母、小写字母和特殊符号（如 `!@#`）；
5. 之后会引导设置多重验证（MFA）：可以创建 passkey（通行密钥），也可以先跳过。一个 MFA 方法都没设的话，每次登录会要求输入一次性验证码，这是官方的保护机制，不是账号出问题。

## 三、用 Google / Apple / Microsoft 登录的注意点

第三方登录省事，但官方文档里点明了两个坑：

- **选了就得一直用它**。账号由第三方托管，之后不能改成「邮箱 + 密码」登录；两种方式混着用可能报错，甚至把账号锁在门外。
- **Apple 的「隐藏邮箱」**。注册时如果开了 Hide My Email（用匿名中转地址），以后每次登录都得保持这个开关，中途关掉可能登不上、收不到邮件。

所以选哪种登录方式，先想清楚这个账号你打算长期怎么用。

## 四、登录不上先查这几条

按出现概率排：

1. **登录方式和注册时不一致**——注册用的 Google，现在拿邮箱 + 密码登（或反过来）；
2. **验证码邮件没到**——翻垃圾箱、查邮箱拦截规则，确认注册时选的地区和邮箱归属地没有明显冲突；
3. **密码规则没吃准**——四类字符缺一类都设不了密码，输错大小写也进不去；
4. **换设备后 passkey 用不了**——试试账号里设置的其他 MFA 方式，或用一次性验证码兜底；
5. **登录页一直转圈**——多半不是账号问题，是设备上的 Chrome 浏览器被停用或卸载了，见 [登录转圈与启动闪退.md](登录转圈与启动闪退.md)。

官方的账号问题排查页在 [help.sketchup.com/sign-and-account-issues](https://help.sketchup.com/sign-and-account-issues)，再往下的账号申诉要走官方支持渠道。

登录成功之后，模型怎么弄进手机看 [SKP模型怎么打开.md](SKP模型怎么打开.md)；云端列表刷不出来这类问题，翻 [常见问题与排查.md](常见问题与排查.md)。
