# SKP 模型传到手机并打开的几种方式

> 讲怎么把 `.skp` 模型弄进 SketchUp Viewer 安卓版：五条路线，按「模型现在在哪」「有没有电脑在旁边」选。

## 一、先选路线

| 你的情况 | 推荐路线 |
| --- | --- |
| 模型在电脑上，想长期在手机看 | 路线一：传到 Trimble Connect |
| 只想找现成模型看看 | 路线二：3D Warehouse 直接搜 |
| 模型本来就放在 Dropbox 里 | 路线三：应用内直连 Dropbox |
| 收到微信 / 邮件的 `.skp` 附件 | 路线四：下载到本地后用「打开方式」 |
| 模型在 Google Drive 或别的文件 App | 路线五：系统文件选择器 |

云端三条路线都要先登录 Trimble 账号，注册与登录见 [注册登录与账号问题.md](注册登录与账号问题.md)。

## 二、路线一：Trimble Connect（推荐）

Trimble Connect 是 Trimble 官方的云盘，用 SketchUp 账号（Trimble ID）就能用。

1. 电脑浏览器打开 [connect.trimble.com](https://connect.trimble.com/)，登录后新建一个 Project；
2. 把 `.skp` 拖进去上传；
3. 手机上打开 Viewer，主界面点 Cloud（云端来源菜单）选 Trimble Connect，找到文件点开。

以后模型改了，把同名文件再传一次覆盖，手机上重新打开就是新版——这是五条路线里最适合「反复改、反复看」的一条。

## 三、路线二：3D Warehouse

主界面 Cloud 菜单选 3D Warehouse，直接搜公开模型（家具、门窗、整套装机方案都有人传），点开就能看。想把自己电脑上的模型放进来给别人看，也是在 3D Warehouse 网页上传。

## 四、路线三：Dropbox 与其他网盘

Viewer 内置 Dropbox 登录入口，授权后直接列文件。Google Drive 没有专门入口，但走路线五同样能进。

## 五、路线四：附件「打开方式」

微信、QQ、邮件里收到的 `.skp` 文件：

1. 先在聊天工具/邮箱里把附件**另存到手机本地**（直接点聊天窗口里的预览经常失败）；
2. 在文件管理器里找到它，点「打开方式 / 其他应用打开」，选 SketchUp Viewer。

有的品牌手机第一次要手动选一次应用，之后会记住默认打开方式。

## 六、路线五：系统文件选择器

Viewer 支持安卓的存储访问框架（Storage Access Framework）：在应用内选「设备上的文件」一类入口，会弹出系统的文件选择器，从那里可以进 Google Drive、手机存储、或其他文件 App 里选 `.skp`。入口的具体名称以你手机上应用内的实际显示为准。

## 七、打不开时的排查

按出现概率排：

1. **文件没下完整**——聊天工具的缓存经常只有头几 MB，先确认另存出来的文件大小正常；
2. **后缀被传输工具改了**——有的工具会存成 `.skp.1` 或 `.bin`，改回 `.skp` 再开；
3. **模型版本比应用新**——个别用较新桌面版保存的 SKP 可能打不开，在电脑端用「另存为」存成较低版本再传；
4. **模型太大**——官方团队的参考口径是移动端按 10MB 上下的模型设计，二三十 MB 就开始不稳、几十 MB 就看设备运气；先在电脑端删掉用不到的组件、贴图瘦身再传，具体动作见 [常见问题与排查.md](常见问题与排查.md) 第六节。

这些动作做完还是不行，翻 [常见问题与排查.md](常见问题与排查.md) 的「模型打不开」一节对一遍清单。
