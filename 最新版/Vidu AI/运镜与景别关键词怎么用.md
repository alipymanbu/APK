## 一、为什么直接写关键词比写形容词有用

「电影感」「高级感」这类词太泛，落不到具体动作上。而**运镜、景别、动态幅度这些词是有明确对应的**——官方提示词指南里把它们列成了词典，写进去，视频的运动和机位会照着变。

下表的词是官方指南给出的触发词，中英文都认（同一行里的写法意思相同，挑一个写就行）。指南会随模型更新调整，**以官方提示词指南当页为准**。

## 二、动态幅度：控制动得多还是动得少

| 想要的效果 | 写这些词 |
| --- | --- |
| 运动幅度大 | 大动态、快速运动、超大动效 |
| 中等 | 中等动态、一般动效 |
| 幅度小、稳 | 小幅动态、小动态 |

这一组对文生视频、图生视频、参考生视频都有效。**人物特写、需要脸部稳定的镜头用小动态**；追逐、舞蹈、动作场面用大动态。同一个画面里既想要动作幅度大又想要脸不崩，通常做不到，得二选一。

## 三、基础运镜：机位怎么动

| 运镜 | 触发词（任选一种写法） |
| --- | --- |
| 左移 | 镜头向左移动、左移镜头、镜头 move left |
| 右移 | 镜头向右移动、右移镜头、镜头 move right |
| 升 | 镜头向上移动、升镜头、镜头 move up |
| 降 | 镜头向下移动、降镜头、镜头 move down |
| 推 | 镜头推进、推镜头、镜头 zoom in |
| 拉 | 镜头拉远、拉镜头、镜头 zoom out |
| 固定 | 镜头固定、固定镜头、Static shot |

**一次只用一种。** 同时写「一边推近一边环绕」，出来的画面通常是乱晃而不是两个运镜叠加。要连续变化，就拆成两条视频，分别写。

## 四、特殊拍摄手法

| 手法 | 触发词 |
| --- | --- |
| 延时 | 延时摄影、Time Lapse shot |
| 微距 | 微距镜头、Macro shot |
| 第一人称 | 第一人称视角、FPV shot |
| 航拍 | 航拍镜头、Aerial shot |

这一组对三类生成方式都适用。**航拍和微距对画面细节要求高**，配低分辨率容易糊，建议同一条视频里别把它们和低档位分辨率搭在一起。

## 五、景别与视角

| 维度 | 可选词 |
| --- | --- |
| 景别 | 远景、全景、中景、近景、特写 |
| 视角 | 低角度、高角度、平视镜头、鸟瞰镜头 |

景别决定观众离主体有多近。**同一个人物要在多个镜头之间保持一致，就把景别跨度控制住**——从大远景直接跳特写，人物特征最难稳住，中间用中景过渡一下更安全，做法见 [人物一致性怎么保持.md](人物一致性怎么保持.md)。

## 六、构图

| 构图 | 触发词 |
| --- | --- |
| 对角线 | 对角线构图 |
| 三分 | 三分构图 |
| 对称 | 对称构图 |
| 越肩 | 越肩镜头、Over shoulder shot |
| 荷兰角 | 荷兰角镜头、Dutch angle |

写「三分构图」比写「画面好看」有用得多，因为它对应的是主体该摆在哪。**要留出加字幕的位置，就用三分构图把主体放到一侧**，别让画面正中堆满元素。

## 七、画面风格

| 风格 | 触发词 |
| --- | --- |
| 2D 动漫 | 2D 动漫风格、2D anime style |
| 3D 渲染 | 3D Rendering style、3D cg style |
| 写实 | Realistic |
| 水墨 | 水墨风格、Ink Wash Painting style |
| 线稿 | 线稿风格、Line Art style |
| 像素 | 像素风格、Pixel Art style |
| 油画 | 油画风格、Oil Painting style |

一个来自官方指南的写法技巧：**同一种风格倾向，在句子开头、景物描述里、结尾各点一次**，出来的风格一致性比只在开头写一次更稳。注意是换着说法重复（「写实」「电影质感」「真实光影」），不是把同一个词机械地贴三遍。

**不要写具体在世创作者或真人的名字。** 这类内容在内容审核里是会被直接拦下的类别，写了不但不生效，还可能让整条任务失败，详见 [常见问题与排查.md](常见问题与排查.md) 第三节。

## 八、拼成一句：一个完整例子

把上面的词按「主体 → 动作 → 运镜/景别 → 光影 → 风格」装上：

```text
咖啡师在窗边把杯子放到桌上，动作缓慢；中景，镜头固定，小幅动态；
午后侧光穿过百叶窗落在桌面；写实风格，真实光影，电影质感。
```

对应关系一句话说清：`中景` 定景别、`镜头固定` 定机位、`小幅动态` 压住动作幅度、`写实风格` 定画面质感。**四个维度各取一个，别在同一维度里堆同义词**——写「推近、拉远」这种互相打架的组合，等于把选择权还给模型。

写句子的整体结构、以及三种生成方式下提示词的差别，见 [提示词怎么写才出片.md](提示词怎么写才出片.md)。
