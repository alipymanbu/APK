## 一、先确认你要装的是哪一份

Vidu AI 是北京生数科技有限公司（生数科技）推出的 AI 视频生成应用：输入一段文字、上传一张图，或者给几个参考主体，就能得到一段带运镜的视频。国内站点在 [www.vidu.cn](https://www.vidu.cn/)，国际站点在 [www.vidu.com](https://www.vidu.com/)。

网上叫「Vidu」的页面不止一个，判断你手上这份是不是同一份，看下面这张表最直接：

| 项目 | 本文档这份的实际值 |
| --- | --- |
| 应用名 | Vidu AI |
| 版本 | 3.6.2 |
| 包名 | `com.vidu.domestic` |
| 安装包大小 | 92.81M |
| MD5 | `787c6de1a8c49cb6fe65240d23394320` |

三件事要注意：

- **版本号不必追新**。应用商店里能搜到的版本可能比 3.6.2 更高，那是后来更新的一版。两版都是同一个应用、用同一个账号，装哪一份都能用，不存在「版本低就不能用」。
- **包名是最硬的判据**。名字叫 Vidu 的应用有好几个方向，包名里带 `domestic` 这个词，说明这是面向国内市场的版本。如果你搜到的包名对不上本文档这一列，那就是另一份东西，别看这篇的说明去装它。
- **显示的大小是估算值**：这份包体是 92.81M。下载页面若显示 90M 或 93M，是取整方式不同，不是文件有问题。

想核对文件是否完整：如果你先在电脑上下载再传进手机，可以在电脑上算一次 MD5，和上表一致就说明文件没坏、传输过程没被改动。

## 二、从网盘取回安装文件

1. 打开 [Vidu AI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c0ea9ba99fb9)；
2. 用夸克账号登录，把文件**转存到你自己的网盘**——文件夹名里的「先保存再下载」就是这个意思：分享链接会失效，转存之后这份文件才长期归你；
3. 在手机夸克 App 里下载到本机；也可以在电脑上下载，再用数据线或聊天工具传进手机；
4. 记住它落在手机存储的哪个目录（夸克一般放在「夸克下载」这类文件夹里），下一步要直接点它。

## 三、在安卓手机上装好

安卓默认不允许直接安装浏览器下载的 `.apk`，会先拦一次，这是系统机制，不是安装包有问题：

1. 打开手机「文件管理」，找到刚下载的 `.apk` 文件；
2. 点它，出现「禁止安装未知应用」时，点「设置」→ 找到对应的来源（浏览器或文件管理器）→ 打开「允许安装应用」这个开关；
3. 返回再点一次安装包，点「安装」；
4. 装好后在桌面找到 Vidu AI 图标。

安装出现的几种常见提示，对应处理方式：

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | 文件没下完或传输损坏 | 按第一节的 MD5 核对，重新下载 |
| 「未安装该应用」 | 手机里已有同包名但签名不同的版本 | 先在设置里卸载旧版 Vidu，再装这一份 |
| 「存储空间不足」 | 剩余空间小于安装包体积 | 清出空间；后面生成与导出视频还会继续占空间，留出富余 |
| 被手机管家拦截 | 系统把非商店来源当风险 | 在手机管家的「安装拦截」里放行一次 |

## 四、第一次打开要做的事

| 顺序 | 做什么 | 为什么 |
| --- | --- | --- |
| 1 | 登录账号 | 作品、积分、订阅都挂在账号上，不登录基本没法生成。具体支持哪些登录方式，以应用内当页显示为准 |
| 2 | 确认积分到账 | 账户页会显示当前可用积分；新账号有一段可用的免费额度，正式生成前先看一眼，免得做到一半提示不足（规则见 [积分和会员怎么算.md](积分和会员怎么算.md)） |
| 3 | 按需给权限 | 把成品存到相册需要存储／相册权限；用不到的功能可以不给 |
| 4 | 跑通一条最小流程 | 用一句话生成一条最短的视频，确认能生成、能预览、能保存到本地，再去做正式创作 |

第 4 步别跳过。审核不通过、上传的图不识别、导出没出现在相册，这几类问题都要等真正生成一次才会暴露，用最短的那条先踩一遍最省时间。生成方式之间怎么选，看 [三种生成方式怎么选.md](三种生成方式怎么选.md)。

## 五、打不开、闪退怎么处理

装完点不开或者一进去就退回桌面，按顺序试：

1. 在「设置 → 应用 → Vidu AI」里清一次缓存（不要清数据，清数据会退出登录）；
2. 检查手机系统版本是不是过低——版本过旧的系统装得上、跑不起来，这种情况只能换设备或换更适配的版本；
3. 确认手机剩余存储充足，系统空间见底时应用会在启动阶段被系统杀掉；
4. 还不行就卸载重装一次。

如果问题出现在生成阶段而不是启动阶段（一直转圈、报生成失败），那属于另一类问题，见 [常见问题与排查.md](常见问题与排查.md)。
