# 常见问题与排查

> 本篇按现象归类 Vidu AI 使用中最常遇到的一批问题——装不上、登录不了、生成失败、审核不通过、积分对不上、导出的视频找不到——每条给出先看什么、怎么处理。

## 一、装不上、打不开、退不出来

| 现象 | 先看什么 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 安装包是否下完整 | 拿电脑算一次 MD5 和 [下载与安装教程.md](下载与安装教程.md) 第一节的表对一下，不一致就重新下载 |
| 提示「未安装该应用」 | 是否装着同包名的旧版本 | 先在设置里卸载旧版，再装这一份 |
| 安装被拦 | 手机管家的安装拦截 | 在管家设置里放行一次 |
| 装完点开就闪退 | 缓存、系统版本、剩余存储 | 清缓存（别清数据）→ 查系统版本 → 清空间 → 卸载重装 |
| 启动就卡在开屏页 | 网络是否能通 | 换网络重试；公司网络或校园网有时会拦掉请求 |

清缓存和清数据是两回事：**清缓存通常不会退出登录，清数据会把登录状态和本地设置一起清掉**。排查时优先清缓存。

## 二、点了生成，一直失败

先分清是哪一类失败，处理方式完全不同：

| 提示方向 | 含义 | 处理 |
| --- | --- | --- |
| 提示内容不合规／审核未通过 | 输入或输出触发了内容审核 | 见本文第三节 |
| 提示积分不足 | 余额不够这次的消耗 | 见本文第六节 |
| 提示参数不合法、图片不可用 | 输入的图或参数不满足要求 | 见本文第四节 |
| 提示并发或请求过于频繁 | 同时跑的任务太多，或点得太快 | 等上一批跑完再提交，不要连点 |
| 提示服务端错误、稍后重试 | 平台侧的问题 | 隔几分钟重试，不必改设置 |

**先看提示文字指向哪一类，再动手。** 很多人一遇到失败就改提示词，结果改了半天发现是积分不够。

## 三、审核不通过是怎么判的

审核会同时看你输入的提示词、上传的图片和生成出来的画面。官方列出的会被拦截的内容类别包括：

- 裸露、色情或过度挑逗的内容；
- 暴力、血腥、内脏类画面；
- 侮辱性、冒犯性题材；
- 公众人物；
- 在世艺术家；
- 涉及未成年人保护的内容。

几个实际会踩到的点：

- **别写真实名人的名字**。想用一个「像某人」的角色，就描述特征，不要直接点名；
- **别反复提交同一条被拦的内容**。官方明确说了，反复提交被标记的输入可能导致账号被限制，换思路而不是重试；
- **触发点在图片上也会被拦**。提示词写得再干净，上传的图有问题一样过不去。

被拦之后改的方向：换主体设定、换场景、去掉敏感元素，然后重新生成。

## 四、上传的图片不被接受

对照这几条检查：

| 限制项 | 要求 |
| --- | --- |
| 格式 | JPG、JPEG、PNG、WebP |
| 单张体积 | 官方接口侧的上限是 50MB；App 端的实际限制以你那一版的上传提示为准，超了就先压缩 |
| 宽高比 | 比例过于极端的图不接受（细长条、超宽幅先裁成正常比例） |
| 人脸类操作 | 需要清晰正脸、单人、无遮挡，见 [人物一致性怎么保持.md](人物一致性怎么保持.md) 第四节 |

手机截图、聊天软件转发过的图往往已经被压缩或改过后缀，**改后缀名不等于改格式**。如果一张图怎么传都不过，用相册编辑另存为一张新的，通常就能解决。

## 五、生成出来了，但效果不对

这类不是故障，是设置与写法的匹配问题。按这个顺序回看：

1. **生成方式对不对**——图和参考都给了却效果不对，多半是走错了入口，见 [三种生成方式怎么选.md](三种生成方式怎么选.md)；
2. **提示词里有没有可执行的动作**——只写「一个女孩在走路」这类描述，结果随机性很大，见 [提示词怎么写才出片.md](提示词怎么写才出片.md)；
3. **时长塞不塞得下**——4 秒里放三个动作，必然赶；
4. **人物是不是换脸了**——那是参考没建好，见 [人物一致性怎么保持.md](人物一致性怎么保持.md)；
5. **上面都排除了就重生成**。同样的输入重跑得到不同结果是正常现象，多跑几条再挑。

想让画面动得可控（往哪推、推多快、什么景别），把运镜词按 [运镜与景别关键词怎么用.md](运镜与景别关键词怎么用.md) 写进提示词，比反复重生成有效。

## 六、积分对不上

| 现象 | 处理 |
| --- | --- |
| 明明有余额却提示不足 | 先退出重进刷新一次余额；还不行就对照账户页的扣分明细，看是不是被并发生成占用了 |
| 没生成成功也扣了分 | 参照 [积分和会员怎么算.md](积分和会员怎么算.md) 第三节的两种口径，以应用内明细为准 |
| 免费额度没到账 | 额度按周期发放，不是实时补；等到下个周期仍没有，从应用内的反馈入口提交 |
| 想退订 | 在账户页主动取消，取消后一般还能用到当前周期结束 |

## 七、生成的视频在哪、存不进相册

- 生成完成后先在应用内的作品列表里，长按或点开有保存／下载入口；
- **保存到相册需要存储权限**。第一次保存时被拒绝过，要去「设置 → 应用 → Vidu AI → 权限」里重新打开，只靠在应用内点保存通常不会再弹一次授权；
- 部分安卓系统里，应用保存的图片会落到一个独立的相册目录（如 `Pictures` 下的应用名文件夹），在图库的「相册」分组里翻一下；
- 下载卡在进度条不动，先切一次网络。大文件在弱网下断流很常见，重新点一次下载通常会续上。

装包、认包的另一类疑问（比如搜到了别家的 Vidu、不确定是不是同一份），回到 [下载与安装教程.md](下载与安装教程.md) 第一节的对照表核对包名即可。
