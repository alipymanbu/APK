## 一、一条能用的提示词包含五个要素

按这个顺序写，基本不会跑偏：

| 要素 | 回答的问题 | 例子 |
| --- | --- | --- |
| 主体 | 画面里是谁／是什么 | 一个穿深色风衣的男人 |
| 动作 | 它在做什么，动作要有先后 | 先低头看表，再抬头快步走 |
| 镜头 | 机位与运动 | 低角度跟拍，镜头缓慢推近 |
| 光影 | 什么光、什么时段 | 傍晚侧逆光，暖色 |
| 风格 | 写实、动画还是某类质感 | 写实电影质感，浅景深 |

官方提示词指南给的公式是「**主体/场景 + 场景描述 + 环境描述 + 艺术风格/媒介**」，和上面这张表是一回事，只是分得更粗。指南里同时给了四条写法禁忌，照着避基本不会踩空：

- **主体不要多、也不要分散**。一句话里塞三四个主体，画面会各占一块、谁也不突出；
- **不用模糊术语**。「氛围感拉满」「有质感的画面」这类词指代不清；
- **用口语化的流畅措辞，不要写成过度文学化的长句**。华丽修辞不会变成画面；
- **风格词要贯穿全句，不只在开头点一次**。开头、景物描述、收尾各带一次（换着说法），风格一致性更稳。

这五项拼起来就是一句完整的话，不必写成字段：

```text
一个穿深色风衣的男人站在雨夜的街口，先低头看表，再抬头快步走向镜头；
低角度跟拍，镜头缓慢推近；霓虹反光打在湿路面上，冷色调；写实电影质感，浅景深。
```

**动作要写顺序，不要写状态。** 「先……再……」能给模型一个时间轴；只写「在走路」它只能自己决定走哪个方向、走多快。要一段镜头里有变化，就把动作排成两到三步。

提示词支持中文，也可以中英混写。官方接口侧给的提示词上限是 5000 个字符；App 输入框自身的字数限制，以你那一版输入框的提示为准。

## 二、模糊 vs 具体，差别在这里

| 写法 | 问题 | 改成 |
| --- | --- | --- |
| 「一个女孩在走路」 | 不知道往哪走、快慢、什么环境 | 「女孩从画面右侧走进来，走向镜头，脚步放慢，身后是清晨的雾」 |
| 「镜头动一下」 | 什么方向、多快都没说 | 「镜头从人物背后缓慢升起，俯视整个街区」 |
| 「画面好看一点」 | 不是可执行的指令 | 「主体置于画面左侧三分之一，背景虚化」 |
| 「电影感、高级感、大片」 | 堆形容词，通常带不来可见的区别 | 换成「低角度仰拍 + 侧逆光 + 浅景深」这类具体描述 |
| 一口气写六七个动作 | 单条视频放不下 | 拆成多条分别生成 |

一个实用判据：**把你写的每句话问一遍「如果我是摄影师，我知道该怎么摆机位吗」**。答不上来的句子，就是模型也答不上来的句子。

## 三、镜头和运镜的常用说法

想要控制画面怎么动，直接用这些词：

- 机位：平视、低角度仰拍、高角度俯拍、过肩视角、第一人称视角；
- 运动：推近、拉远、横移、跟拍、环绕、升降；
- 景别：特写、近景、中景、全景、大远景；
- 节奏：缓慢、匀速、轻微手持晃动。

一次只用一种运镜更稳。同时写「一边环绕一边推近一边升降」，出来的往往是画面乱晃。

这几个方向只是常用的那批。官方提示词指南还给出了**动态幅度、特殊拍摄手法（延时／微距／第一人称／航拍）、构图、风格词**这几组触发词，完整的对照表与拼句示例见 [运镜与景别关键词怎么用.md](运镜与景别关键词怎么用.md)。

## 四、三种方式下，同一句话要改写

提示词不是通用模板，换个生成方式就要改：

| 方式 | 提示词该写什么 | 不该写什么 |
| --- | --- | --- |
| 文生视频 | 全套五要素都要写，画面长什么样由文字决定 | —— |
| 图生视频 | 只写动作、运镜、节奏，以及你没在图里体现的那部分氛围 | 不要重复描述图里已经有的长相、衣服、背景 |
| 参考生视频 | 用 `@参考名` 点名主体，再写它在做什么、镜头怎么走 | 不要再描述参考主体长什么样 |

参考生视频的写法在官方示例里是这样点名的：

```text
@牛仔 坐在吧台前，端起酒杯喝了一口；@酒吧 里灯光昏黄，镜头缓慢横移
```

**先给参考起名，再在提示词里用 `@` 调用**，这样多个主体同时出现时不会串。参考怎么建、一致性怎么保，见 [人物一致性怎么保持.md](人物一致性怎么保持.md)。

## 五、还不出效果时，按这个顺序改

1. **先看是不是方式选错了**：图和参考都给了却效果不对，先回到 [三种生成方式怎么选.md](三种生成方式怎么选.md) 确认入口；
2. **看提示词是不是只有主体没有动作**：补「先……再……」；
3. **再看动作数是不是太多**：一条一段，拆开生成；
4. **再调参数**：时长、分辨率、画幅这些设置会直接改变观感，见 [生成时长分辨率与模型怎么设置.md](生成时长分辨率与模型怎么设置.md)；
5. **最后重生成一次**：同样的提示词多跑几次本来就会得到不同结果，这一步之前别急着改词。

如果提示词看着没问题但任务直接失败，那不是写法问题，看 [常见问题与排查.md](常见问题与排查.md) 的审核与失败两节。
