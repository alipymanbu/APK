## 一、先说结论

OPatch 不是 LSPosed 官方出品——虽然它的包名带着 `org.lsposed` 前缀（沿用上游命名），但 LSPosed 官方仓库里没有这个项目。它是 **LSPatch 的第三方魔改版**，由社区维护，修掉了原版的两个最劝退的缺陷。你如果是新用户、手机没 root、不想折腾 Shizuku，直接用 OPatch 是社区目前的主流选择。

## 二、LSPatch 是什么，为什么会有这一家子

LSPatch 是 LSPosed 团队推出的免 root 框架：不解锁 Bootloader、不 root，把 Xposed 模块直接注入进目标应用的安装包，让模块在被修补的应用里跑起来。它和需要 root 的 LSPosed 是互补关系——LSPosed 覆盖系统级模块、功能完整，LSPatch 只求「无 root 也能挂模块」。

原版 LSPatch 的官方仓库已在 2023 年底归档停更，但免 root 挂模块这个需求一直存在，于是社区出现了几个维持分支，就是 npatch、OPatch、onpatch 这一家子。

## 三、四者对照表

社区教程里的口径整理如下（各自版本迭代很快，具体功能以各家发布说明为准）：

| 项目 | LSPatch（原版） | npatch | OPatch | onpatch |
| --- | --- | --- | --- | --- |
| 维护状态 | 已归档停更 | 第三方维护 | 第三方维护，社区使用最多 | 第三方维护 |
| 依赖 Shizuku | 快捷安装依赖 | 社区称与原版相近 | 不依赖 | 不依赖 |
| 修补后的应用需要管理器锁后台 | 需要 | 社区称与原版相近 | **不需要** | 不需要 |
| 启动动画 | 正常 | 正常 | 有「原神」主题启动动画 | 去掉了原神动画 |
| 与原版的差距 | —— | 改动不大，口碑一般 | 在原版基础上做了实质优化 | 基于 OPatch，仅去动画、微调界面 |

## 四、OPatch 相对原版改了什么

对使用体验影响最大的两点：

1. **免 Shizuku**。原版 LSPatch 的快捷安装要靠 Shizuku 提权，多一个要搭的环境；OPatch 直接用普通权限完成整套流程，装上就能用。
2. **修补后的应用不用锁后台**。原版本地模式下，被修补的应用要靠管理器常驻后台才能正常启动，很多人被系统杀后台折腾得够呛；OPatch 把这个依赖解决了，应用独立运行。

代价与注意点：

- **「原神」启动动画**：启动 OPatch 时会先播一段原神主题的开场动画。反感的话有两个选择：忍几秒，或者用 onpatch（去掉动画的再修改版）。
- **非官方渠道分发**：OPatch 没有官方 GitHub 仓库，安装包在社区渠道流转。下载时认准来源、核对包名（`org.lsposed.opatch`）与文件校验值，别装来路不明的「定制版」。

## 五、根据情况选工具

| 你的情况 | 建议 |
| --- | --- |
| 手机没 root，想给某个应用挂模块 | OPatch，流程见 [模块注入与修补教程.md](模块注入与修补教程.md) |
| 讨厌原神动画 | onpatch |
| 需要 LSPatch 特性或在做兼容性测试 | 原版 LSPatch（存档版本仍在） |
| 手机已 root，要系统级模块 | 不用这一家子，直接上 LSPosed |
| 模块加载范围怎么配 | [模式选择与设置说明.md](模式选择与设置说明.md) |

无论用哪一支，修补都会改变应用签名、商店更新会覆盖修补版，这些共同限制在 [常见问题与故障排除.md](常见问题与故障排除.md) 里集中说明。
