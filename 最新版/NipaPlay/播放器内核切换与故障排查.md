## 一、什么是播放器内核

同一个视频文件，可能被好几套解码方案播放 —— 这几套方案在 NipaPlay 里叫「内核」。它们对格式的覆盖、硬解的表现各不相同：A 内核放不了的片子，换 B 内核往往就正常了。所以遇到播放类问题，第一个该试的动作就是换内核，而不是重装应用。

## 二、切换路径与可选项

安卓版切换步骤：

1. 进入 **设置** 页；
2. 点 **播放器**；
3. 点 **播放器内核** 一栏右边的箭头；
4. 在选项里切换。

1.9.13 这一版可选 **MDK**、**Video Player**、**Libmpv** 三个内核（官方更新较快，新版本的可选项可能更多，以你装的那版设置页实际显示为准）。三个选项的差别：

| 内核 | 适合场景 | 注意事项 |
| --- | --- | --- |
| Libmpv（即 Media Kit，同一个内核的两种叫法） | 通用兼容性选择，格式覆盖广 | 复杂格式、长期用优先试它 |
| MDK | 需要跨平台硬解、或上一个内核行为不兼容时 | 不同机型的硬解表现可能有差异 |
| Video Player | 最小依赖的基础播放，也用于对照定位问题 | 能力最基础，复杂媒体不建议只用它 |

官方文档对「用哪个内核最好」的答复也是：Media Kit（Libmpv）是通用兼容性选择。各平台能力差异可参考 [官方文档](https://nipaplay.aimes-soft.com/docs.html) 的播放器内核章节。

## 三、常见症状排查顺序

官方故障文档给出的顺序，安卓上常用的是这几条：

1. **扫描不到本地视频**：先查存储权限 —— **设置 → 应用 → NipaPlay → 权限 → 存储** 允许；Android 11 及以上还要额外授予「所有文件访问」。权限给全了仍扫不到，再确认文件确实在手机存储里。
2. **播放黑屏、无声、卡顿**：先切内核（按上一节的顺序各试一遍，重点试 Libmpv 与 MDK），多数播放类异常在这一步就能分开是「文件不兼容」还是「应用问题」。
3. **能连服务器但某些片子放不了**：查服务器端的转码设置与网络带宽；详见 [连接Emby与Jellyfin媒体库.md](连接Emby与Jellyfin媒体库.md)。
4. **弹幕闪烁、不显示**：在 **设置 → 弹幕设置** 里把弹幕引擎切到 CPU 引擎再试，细节见 [弹幕与字幕设置教程.md](弹幕与字幕设置教程.md)。
5. **所有内核都失败**：问题多半出在文件本身或来源上 —— 换一个视频文件验证、确认容器与编码是否正常，而不是继续换内核。

排查时记下这几点，定位会快很多：手机型号与系统版本、应用版本（如 1.9.13）、出问题的视频编码与字幕格式、用的哪个内核、复现步骤。

## 四、导出日志再反馈

自查解决不了时，把日志带上再去社区反馈，效率高得多：

1. 进入 **设置 → 开发者选项 → 终端输出**；
2. 复制或导出日志（安卓支持导出为二维码，方便传到电脑）；
3. 反馈时附上平台、版本、重现步骤；不要把带账号凭据的服务器地址原样贴出去。

项目的问题反馈入口是 GitHub Issues（[github.com/AimesSoft/NipaPlay-Reload/issues](https://github.com/AimesSoft/NipaPlay-Reload/issues)），官方使用文档在 [nipaplay.aimes-soft.com](https://nipaplay.aimes-soft.com/)。

## 五、安装与启动阶段的几类问题

- **APK 装不上 / 提示解析错误**：下载不完整或架构不匹配，重新下载或换 Releases 页的另一种架构包，步骤见 [下载与安装教程.md](下载与安装教程.md)。
- **升级后播放历史或连接异常**：应用在大版本切换时偶有数据库迁移问题，官方在后续版本里修过同类缺陷 —— 先升级到最新版再判断，不要急着清数据。
- **应用改了设置没生效**：凡是选完媒体库、改完连接配置的，都要滑到设置页**最底部点「保存」**再退出。
