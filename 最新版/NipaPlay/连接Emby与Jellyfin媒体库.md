# 连接Emby与Jellyfin媒体库

> 讲怎么把 Emby / Jellyfin 服务器接进 NipaPlay 安卓版，以及连不上、报 403、选库不生效时怎么办。

## 一、先确认你有可用的服务器

NipaPlay 只是播放端，它自己不存片也不刮削元数据。你要先有一个能访问的 Emby 或 Jellyfin 服务器：

- 朋友或家人搭好的服务器，向你要一组账号密码 —— 最省事；
- 自己有 NAS 或常开的电脑，可以自己部署：Jellyfin 免费开源，官方文档见 [jellyfin.org/docs](https://jellyfin.org/docs/general/installation/)，支持 Windows / Linux / macOS / Docker；Emby 官方安装页见 [emby.media/download](https://emby.media/download.html)。Jellyfin 默认端口是 8096，服务器那头要放行防火墙。
- 只想看同一局域网里电脑上的文件，也可以不用装服务器：PC 端 NipaPlay 在**设置 → 远程访问**里启用 web 服务器，手机端在「共享媒体库」里点**扫描局域网**，或手动输 PC 的局域网地址（形如 `192.168.1.100`，默认端口 1180）。

## 二、连接步骤（安卓版）

1. 打开 NipaPlay，进入**设置 → 远程媒体库**；
2. 填服务器地址（`IP:端口` 或域名）、用户名、密码；
   - 服务器走 HTTPS 时，地址**必须以 `https://` 开头**，否则连不通；
3. 点保存，等连接验证通过；
4. 验证通过后选择要同步的媒体库；
5. 返回媒体库界面，服务器的影片列表就出来了。

注意：第 4 步选完媒体库后，**必须滑到设置页面最底部点「保存」**，否则这次修改不会生效 —— 这是最常见的「明明选了却没反应」的原因。

## 三、媒体库类型要求

NipaPlay 只支持两类标准媒体库：

| 服务器端的库类型 | 能否连接 |
| --- | --- |
| 电影（Movies） | 支持 |
| 剧集（TV Shows） | 支持 |
| 混合库（Mixed Content） | 不支持 |
| 文件夹类型的库 | 不支持 |

所以连接前，先在服务器后台把内容建成**独立的电影库和剧集库**，别混在一个库里；刮削信息（海报、简介）也要在服务器端做好 —— 这些元数据由服务器提供，应用只负责展示。

## 四、连不上或报错怎么查

- **连接失败**：核对地址与端口、确认手机和服务器网络互通（同一局域网，或公网地址可达）、账号密码是否打错、服务器进程是否在跑。
- **403 Forbidden**：这是服务器端配置了客户端访问限制，客户端这边改设置没用 —— 需要联系服务器管理员，把 NipaPlay 加进放行名单。
- **提示用户名或密码错误**：回服务器端确认账号信息、该账号是否有对应媒体库的访问权限，必要时在服务器端重置密码。
- **能连上但播放不了**：检查服务器的转码设置与网络带宽；SMB / WebDAV 还要确认服务器支持 Range 请求、账号有读取权限。内核层面的排查见 [播放器内核切换与故障排查.md](播放器内核切换与故障排查.md)。
- **局域网共享连不上**：确认两台设备在同一网段、检查手机与电脑的防火墙是否拦了访问、确认共享那台设备已开启远程访问。

## 五、大库初次加载慢是正常的

媒体库里有上万条内容时，第一次选择媒体库会明显偏慢 —— 服务器要把全量信息推过来。耐心等这一次加载完成，本地会生成缓存，之后打开就快了。中途退出重来反而会前功尽弃。

## 六、SMB 与 WebDAV 挂载

除 Emby / Jellyfin 外，NipaPlay 还支持 SMB 与 WebDAV 直接访问 NAS 或文件目录，适合只想按目录翻文件、不需要海报墙与转码的场景：

- **SMB**：在 NAS 上启用 SMB 并建一个只有媒体目录读取权限的账号，在应用里新增 SMB 连接填地址、共享名、账号密码；先打开少量文件验证路径和网速，再做全库扫描。
- **WebDAV**：用 HTTPS 地址，公网地址要证书有效；单独建一个低权限账号，不要复用管理员密码。

这两种方式的账号密码属于敏感信息，建议按最小权限原则配置。连接成功后，弹幕与字幕功能照常可用，见 [弹幕与字幕设置教程.md](弹幕与字幕设置教程.md)。
