## 一、连接前的三件事

1. **打印机装纸、开机**：热敏纸/标签纸按机型装法装好，通电开机，指示灯正常。
2. **先打一张自检页**，拿到打印机自己的蓝牙名称——这是本篇的关键一步，很多人连不上就是因为选错了蓝牙名。
3. **手机蓝牙已打开**，且这台手机没有同时连着一台别的标签打印机。

自检页是判断打印机状态的万能入口：它打印出蓝牙名称、固件版本、波特率等参数。**找不到蓝牙名时先打自检页，比反复重连快得多。**

## 二、打自检页：以 PT-280 为例

不同型号的组合键不同，下面是官方手册里 PT-280 便携打印机的做法，其他机型以你那台的说明书为准：

1. 打印机关机；
2. 同时按住 **FEED（走纸）键**和**电源键**；
3. 所有指示灯亮起后，松开**电源键**；
4. 蓝色状态灯熄灭后，松开 **FEED 键**，打印机会吐出一张自检页，上面有蓝牙名称（形如 `Printer_008B`）。

另一类常见做法是 **FEED 开机法**（如 iSH58 便携机；佳博官网 FAQ 也把它列为桌面机的通用做法）：关机状态下**按住 FEED 键再开机**，等 ERROR 灯灭后松手，同样打印自检页。你的具体机型用哪种组合，看说明书或[支持哪些打印机型号.md](支持哪些打印机型号.md)里的机型条目。

## 三、蓝牙连接（最常用）

1. **系统里配对**：安卓/iPhone 打开「设置 → 蓝牙」，等扫描出列表，点自检页上那个蓝牙名完成配对。
2. **打开 Gprinter**，进入 App 的设置/打印机管理界面，选中刚配对的打印机，确认状态为已连接。
3. **按纸型设置宽度**：官方手册给 PT-280 的例子是——纸张宽度设 58mm、打印宽度设 48mm。你的机型按自检页/说明书标注的数值设置，设错宽度会打出偏移或截断的标签。
4. 回到编辑界面打一张测试标签确认出纸正常。

第 1、2 步是先后关系，缺一不可：只做了系统配对、没在 App 里选机，就会出现「手机显示已配对、打印机却不出纸」的情况，排查见[搜不到打印机怎么办.md](搜不到打印机怎么办.md)第四节。

**权限提醒**：安卓 12 及以上系统，App 扫描蓝牙会请求「附近的设备」权限；安卓 11 及更早的系统要求位置权限。没给这个权限，App 里永远搜不到打印机——这是连接失败里最常见的一条。

## 四、Wi-Fi / 网络连接

佳博不少机型除了蓝牙还有 USB 与网络接口（网口/Wi-Fi），Gprinter 对应支持：

- **同一局域网**：把打印机和手机连到同一个路由器网络，在 App 的连接设置里按 IP/网络方式搜索连接；
- **接口组合**：App 支持蓝牙、USB、网络几类通道，桌面机型用网络接口时打印机插网线即可，不需要蓝牙。

用 Wi-Fi 连接的好处是不占蓝牙通道、多台手机可以共用一台打印机（比如店里几台收银机打同一台后厨打印机）。具体入口名称以你手上的 App 版本界面为准。

## 五、连不上？先查这几条

| 现象 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| App 里搜不到打印机 | 「附近的设备/位置」权限是否给了；打印机是否已被人连走 | 给权限；把别的手机与打印机的连接断开再搜 |
| 系统蓝牙配对失败 | 打印机是否已被其他设备占用；自检页蓝牙名是否照抄正确 | 打印机重启，重新打一张自检页核对名称 |
| 配对成功但打不出 | App 内是否选中了正确的打印机；纸宽/打印宽是否设置 | 回到设置确认打印机状态与宽度数值 |
| 内容打出来偏移、缺一截 | 标签尺寸与实际纸宽不一致 | 编辑界面里把标签宽度改成与纸一致，见[标签编辑与打印教程.md](标签编辑与打印教程.md) |
| 走纸正常但内容发白 | 浓度/速度设置不匹配（或纸装反） | 调整打印浓度档位；确认热敏面朝内/朝上（按机型） |
| 网络连接不上 | 打印机与手机是否同一网段 | 都连同一个 Wi-Fi；查打印机自检页上的 IP |
| 拒绝过权限后，再也不弹申请 | 部分手机系统拒绝一次后会默认挡掉后续申请 | 手机「设置 → 应用管理 → Gprinter → 权限」里手动改为允许 |

排查还卡住的话，把现象对号入座到[搜不到打印机怎么办.md](搜不到打印机怎么办.md)（搜不到 / 配对失败 / 已配对但打不出 / 断连）逐条过；同时先确认你的机型本身在 App 的适配范围内（见[支持哪些打印机型号.md](支持哪些打印机型号.md)），不在适配列表里的机型连得上也不会出纸正常。

连接成功后就可以去编辑标签了，步骤见[标签编辑与打印教程.md](标签编辑与打印教程.md)。
