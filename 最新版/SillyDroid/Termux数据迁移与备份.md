# SillyDroid Termux数据迁移与备份

> 之前在 Termux 里跑酒馆的，一条命令就能把整套数据搬进 SillyDroid；已在用的也能导出 ZIP 备份，换机不丢卡。

## 一、能搬走什么

迁移走的是**整套酒馆数据**：配置、角色卡与对话、插件和扩展配置。官方把迁移做成了产品能力 —— 一条命令打包，App 内一键导入，不用手动在目录之间拷文件。换机、重装、从 Termux 毕业到 SillyDroid，走的都是同一条路。

## 二、从 Termux 一键迁移

1. 在 Termux 里执行下面这条命令，把数据打包成 ZIP：

```bash
curl -fsSL https://raw.githubusercontent.com/jialmaster/SillyDroid/master/scripts/export-tavern-data.sh | bash
```

脚本会自动找到 SillyTavern 目录，打包结果存到手机下载目录；环境里缺 `zip` 命令时它会自己尝试安装。

2. 打开 SillyDroid，**等运行环境解压完成**（首次启动那一步）；
3. 点右上角进入导入入口；
4. 选中刚才生成的 ZIP，确认导入 —— App 会自动替换数据并重启服务，迁移完成。

做完直接进酒馆界面检查：角色卡、聊天记录应该原样都在。

## 三、不用 Termux 也能备份换机

已经在 SillyDroid 里用的，走 **宿主设置 → 数据迁移**：

- **导出**：数据 Tab → 「导出数据压缩包」，得到一份完整 ZIP（含 config、data、plugins、extensions 四个目录），比酒馆官方的用户备份范围更大 —— 官方格式只含用户数据；
- **导入**：三种 ZIP 都认得 —— 宿主完整备份、酒馆官方用户备份（`default-user-…` 这类文件名）、Termux / Linux 导出的数据包；导入前会弹确认提示，不会直接覆盖。

注意：宿主设置里的「清空数据」会删掉这四个目录并重置酒馆，**不可逆** —— 动它之前先导出。

## 四、搬完之后核对三样

1. **角色卡与对话**：进角色管理看卡在不在，点开旧对话确认记录完整，核对要点见[角色卡导入与创建.md](角色卡导入与创建.md)；
2. **扩展**：进宿主设置的扩展管理看一眼，扩展配置是跟着 ZIP 走的，缺的当场补装；
3. **模型连接**：API 密钥跟着配置走，如果连不上就重新填一遍密钥，步骤见[连接AI模型与首次对话.md](连接AI模型与首次对话.md)。

顺带说一句：迁移完成后，Termux 里那份旧数据不会被动到，确认新环境用着没问题再自己清理。
