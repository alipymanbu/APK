## 一、装之前先对一下机型和空间

- **系统版本**：Android 8.0 及以上（官方 Wiki 给出的最低要求）。
- **机型架构**：只支持 64 位（arm64-v8a）；32 位 ARM 与 x86 设备不支持，装不上别浪费时间试。
- **空间**：安装包约 306 MB（本文按 1.0.1.64 版写，MD5 `9C759EB481B260FDA0D7769670BEE0B5`），官方要求另有约 800 MB 可用空间存放运行环境 —— 装之前清出来。
- **最新版本号**：看[官方 Releases 页](https://github.com/jialmaster/SillyDroid/releases)当时显示。

## 二、从哪里拿安装包

正规来源有两个：

1. **官方 Releases**：[github.com/jialmaster/SillyDroid/releases](https://github.com/jialmaster/SillyDroid/releases)，作者发版的唯一渠道，认准文件名形如 `sillydroid-v…-release.apk` 的包；
2. **本文开头的 SillyDroid 安装文件资源（夸克网盘）**：撰写本文时保存的一份 1.0.1.64 安装包，访问 GitHub 不方便时，转存这一份即可安装。

两份的区别只在版本号：网盘里是 2026-09-27 保存的 1.0.1.64，官方页面此刻可能已经发了更新版。装哪份都行，界面与操作入口一致，写进文档的步骤两版通用。

## 三、安装步骤

1. 在文件管理器里点开下载好的 APK。系统会提示「来自未知来源」—— 这个包是自签名的，弹这个提示属正常现象；
2. 按系统指引给「你用来下载/打开安装包的那个应用」（浏览器或文件管理器）开「允许安装未知应用」权限，注意是给它开，不是给 SillyDroid 自己开；
3. 回到安装页点「安装」，等它装完。

## 四、第一次打开会发生什么

1. **解压运行环境**：启动后它先把内置的运行环境解压到手机存储，通常约 1 分钟；机型旧、存储慢会更久。这段时间别退出、别清后台，更别反复杀掉重开 —— 每次重开都从头来。
2. **进入酒馆界面**：解压完成后直接进 SillyTavern 界面，用的是内置 WebView，不需要再开浏览器。
3. **可选扩展提示**：首次启动会提示安装可选扩展（酒馆助手、小白X、提示词模板等）。装扩展需要手机能访问 GitHub，暂时连不上就先跳过，之后在宿主设置里补装，见[宿主设置与扩展管理.md](宿主设置与扩展管理.md)。
4. **先接模型再开聊**：界面进去了但没有东西可聊是正常的，模型接入见[连接AI模型与首次对话.md](连接AI模型与首次对话.md)。

## 五、装不上、打不开对症状查

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 安装中断，提示「未安装 / 解析失败」 | 包没下完整 | 重新下载，核对 MD5（第一节）后再装 |
| 反复弹「未知来源」提示 | 权限开错了对象 | 给下载/打开 APK 的那个应用开权限，不是给 SillyDroid 开 |
| 首次启动长时间停在解压 | 存储几乎占满，或机型太慢 | 清出空间后重试；期间不要杀后台 |
| 老机型打不开或秒退 | 32 位机型 | 见第一节位数说明，换 64 位设备 |
| 装好了但界面空白转圈 | 服务没起来或没解压完 | 先等首次解压结束；还不行按[服务启动失败与白屏排查.md](服务启动失败与白屏排查.md)逐条排查 |

## 六、更新到新版

- 官方更新节奏较快，宿主带自更新能力：检测到 GitHub Release 有新版本时会下载安装，前提是设备能访问 GitHub；
- 手动更新：去 [Releases 页](https://github.com/jialmaster/SillyDroid/releases)下载新 APK 直接安装升级。网盘里这份 1.0.1.64 是保存时点的版本，不追新版照常用；
- 已知场景：更新后启动失败 —— 先导出备份，再清空数据重启，见[服务启动失败与白屏排查.md](服务启动失败与白屏排查.md)第六节。
