## 一、先分清「酒馆」和「大脑」

SillyTavern 是前端：管界面、角色卡、对话记录、提示词排版；生成回复的是你接的后端模型。上游文档（[docs.sillytavern.app](https://docs.sillytavern.app/)）对它的定位就是「一个本地安装的界面」。所以第一次打开酒馆、发现没法聊，不是装坏了 —— 是还没接模型。

先区分两种「没连上」：页面白屏、或状态栏一直显示「未连接到 API!」，是手机本地的酒馆服务没起来，去[服务启动失败与白屏排查.md](服务启动失败与白屏排查.md)；服务正常、界面能开但发消息没回复，才是模型这一层的问题，往下看。

## 二、三种后端怎么选

| 类型 | 例子 | 什么时候选它 |
| --- | --- | --- |
| 免注册试水 | AI Horde | 手里没有任何 API，想先看看酒馆怎么玩 |
| 云端 API | OpenAI 兼容接口、Claude、OpenRouter 等 | 有密钥或愿意按量付费；手机党最省事 |
| 本地模型 | 电脑上的 Ollama、LM Studio、KoboldCpp 等 | 有显卡、在意隐私；手机连电脑的局域网地址 |

云端 API 的密钥从各家的开放平台获取，按用量计费；不同模型在角色扮演上的表现差异很大，建议先小额度试，顺口再充值。

## 三、连接步骤（以云端 API 为例）

1. 在酒馆界面点开 **API 连接**面板（插头样式的图标）；
2. API 类型选你手里那家的类型（OpenAI 兼容 / Claude / OpenRouter 等）；
3. 把密钥粘进对应输入框，然后在模型列表里选一个模型；
4. 点连接，等界面提示连接成功；
5. 回到聊天页，输入第一条消息发送，有回复就说明整条链路通了。

用本地模型的话，第 2 步选对应的本地 API 类型，地址填电脑的局域网 IP 加端口，并确认手机和电脑在同一个网络里。

## 四、开聊前的两个小设置

- **回复语言**：模型用什么语言回你，取决于模型本身和提示词。直接用中文提问，多数多语言模型就会用中文回；坚持回英文的，在系统提示里写一句「用中文回答」。
- **要不要角色卡**：不选卡也能聊，酒馆会用一张默认的 Assistant 卡。想用现成角色或自己捏一张，见[角色卡导入与创建.md](角色卡导入与创建.md)。

## 五、连不上的常见原因

| 现象 | 先检查什么 |
| --- | --- |
| 点连接一直失败 | 密钥是否粘全、API 类型是否选对；部分境外 API 需要网络能访问到服务本身 |
| 本地模型连不上 | 手机和电脑是否在同一网络；地址端口是否填对；电脑端服务是否真的在运行 |
| 连上了但回复很慢 | 多是模型或线路本身的速度，换一个模型对比就知道 |
| 报余额/权限类错误 | 去密钥所属平台查额度与权限，酒馆这边无法解决 |
