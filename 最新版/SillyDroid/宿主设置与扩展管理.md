## 一、宿主和酒馆是两层，别混

你平时聊天的界面是 SillyTavern（跑在内置 WebView 里）；宿主是包在它外面的安卓 App 本体，管运行环境、通知这些系统层的事。两层各有各的设置入口：改模型、角色、提示词在酒馆界面里；日志、通知、扩展、数据迁移在宿主这层。

## 二、宿主自带的四样能力

| 能力 | 什么时候用得上 |
| --- | --- |
| **实时日志** | 酒馆没响应、报错时点开看，运行日志当场可见，不用连电脑抓 |
| **新消息通知** | 来新消息发通知栏提醒；部分机型上不稳定，收不到不一定是设置问题 |
| **下拉刷新开关** | 下拉刷新容易和悬浮小手机、菜单图标误触冲突，冲突就关掉 |
| **刷新按钮** | 关了下拉刷新后，用按钮手动刷新页面 |

页面卡住的第一反应：先按刷新按钮重载，再不行看实时日志里的报错。

## 三、宿主设置页的三块

| 板块 | 能做什么 |
| --- | --- |
| **基础设置** | 可视化改酒馆的基础选项，例如端口、接口等，不用去改配置文件 |
| **扩展管理** | 安装、删除扩展，支持批量删除 |
| **数据迁移** | 整套导入导出：角色卡、对话、配置、扩展 |

## 四、扩展怎么装

1. 首次启动会弹可选扩展的安装提示，直接跟着装即可；当时跳过了，就从**宿主设置 → 扩展管理**补装；
2. 官方 README 里点名的常用扩展有三个：**酒馆助手**（让角色卡里带的脚本、互动界面能跑起来）、**小白X**、**提示词模板** —— 后两个装上后在扩展自己的设置页里看用法；
3. **装扩展需要手机能访问 GitHub**。扩展列表拉不出来时，先换一个网络环境再试，这不是 App 坏了；
4. 不想要的扩展在扩展管理里删，装多了的可以批量删。

## 六、换机或重装前

先把数据导出一份再动手机：宿主设置 → 数据迁移 → 导出，得到一个完整 ZIP，新环境直接导入恢复，细节见[Termux数据迁移与备份.md](Termux数据迁移与备份.md)。
