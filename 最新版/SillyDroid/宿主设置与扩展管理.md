## 一、宿主和酒馆是两层，别混

你平时聊天的界面是 SillyTavern（跑在内置 WebView 里）；宿主是包在它外面的安卓 App 本体，管运行环境、通知这些系统层的事。两层各有各的设置入口：改模型、角色、提示词在酒馆界面里；日志、通知、扩展、数据迁移在宿主这层。

## 二、宿主自带的四样能力

| 能力 | 什么时候用得上 |
| --- | --- |
| **实时日志（日志球）** | 设置 → 数据 Tab 打开「调试日志球」，主界面右下角出现悬浮按钮；酒馆没响应、报错时点开看，可导出日志文件，不用连电脑抓 |
| **新消息通知** | 来新消息发通知栏提醒；部分机型上不稳定，收不到不一定是设置问题 |
| **下拉刷新开关** | 下拉刷新容易和悬浮小手机、菜单图标误触冲突，冲突就关掉 |
| **刷新按钮** | 关了下拉刷新后，用按钮手动刷新页面 |

页面卡住的第一反应：先按刷新按钮重载，再不行看实时日志里的报错。

## 三、宿主设置页的三块

| 板块 | 能做什么 |
| --- | --- |
| **基础设置** | 可视化改酒馆的基础选项，不用改配置文件；「启动端口」默认 8000，宿主页面和本地服务共用，端口冲突才改 |
| **扩展管理** | 安装、删除扩展，支持批量删除 |
| **数据迁移** | 整套导入导出：角色卡、对话、配置、扩展；导入时自动识别宿主完整备份、酒馆官方用户备份与 Termux 导出的 ZIP |

改完任何 Tab 都要点底部的「保存并启动」才会生效 —— 只改不点等于没改。

## 四、扩展怎么装（两种入口）

| 方式 | 入口 | 特点 |
| --- | --- | --- |
| 酒馆内安装（标准） | 酒馆 Web 界面 → 扩展 → 安装 | 官方推荐路径；依赖酒馆页面正常加载 |
| 原生安装 | 宿主设置 → 扩展 Tab → 「安装扩展」（+） | 独立于酒馆页面，网络不稳时更可靠 |

原生安装的流程：粘贴扩展的 Git 仓库地址（GitHub、GitLab 或任何能 `git clone` 的镜像地址）→ 系统自动校验并显示扩展名称、版本、作者 → 确认安装 → 回酒馆页面刷新。四点注意：

1. 扩展装在持久目录，**更新 APK 不会覆盖已装的扩展**；
2. 官方 README 点名的常用扩展：**酒馆助手**（让角色卡里带的脚本、互动界面能跑起来）、**小白X**、**提示词模板** —— 后两个装上后在扩展自己的设置页里看用法；
3. **装扩展需要手机能访问 GitHub**；扩展列表拉不出来时先换网络环境，不是 App 坏了；
4. 不想要的扩展在扩展管理里删，支持批量删除；装之前确认扩展来源可信，有依赖的扩展要一起装。

## 六、换机或重装前

先把数据导出一份再动手机：宿主设置 → 数据迁移 → 导出，得到一个完整 ZIP，新环境直接导入恢复，细节见[Termux数据迁移与备份.md](Termux数据迁移与备份.md)。
