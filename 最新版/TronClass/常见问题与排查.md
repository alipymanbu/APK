# TronClass 常见问题与排查

> 本篇按「现象 → 原因 → 处理」整理 TronClass 使用中最常遇到的几类问题：装不上、登不进、找不到学校、签不上到、进度不动、作业交不上、通知收不到。

## 一、动手排查前先做两件事

遇到异常先确认这两条，能省掉大半折腾：

1. **版本对不对**。本套文档对应的是 2.3.10。TronClass 更新比较勤，很多故障是新版修掉的，也有一部分是旧版才有的。先在「我」页面最下面的「关于」里看一眼当前版本，必要时升级到较新版再复现一次。
2. **网络通不通**。课程内容、签到状态、测试作答都要连学校服务器。切换到稳定的 Wi-Fi 或流量，重启一次 App，再判断问题是不是还在。

## 二、安装相关

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 安装包没下完整 | 删掉本地文件重新下载，下完比对 MD5 是否为 `6AE744F42D44EE7D721B64FC83518FA5` |
| 提示「应用未安装」 | 手机里已装了签名不同的同名应用 | 先卸载旧的那个 TronClass，再装这一份 |
| 点了 apk 没反应 / 被系统拦下 | 没允许该来源安装应用 | 给正在打开文件的 App（文件管理或夸克）打开「允许安装未知应用」，见[下载与安装教程.md](下载与安装教程.md) |
| 提示系统版本过低 | 低于官方要求 | 官方标注安卓端需 Android 7.0 及以上，低于这个只能换设备或用较新的系统 |
| 装完发现界面不对 / 数据是别人的 | 从第三方站点下到了别的包 | 核对包名是否为 `com.wisdomgarden.trpc`，不对就卸载，改从本篇开头的「TronClass 安装文件资源」取 |

## 三、登不进去

**先分清是哪一类失败**，这三类的处理完全不同：

- **打开 App 就报错、进不去**：官方说明过，App 初始化会连一次服务器，网络不稳时这个连接会超时，导致启动失败。**换一个网络再重启 App**，登进去之后可以切回原来的网络继续用。
- **提示「服务器请求失败」**：这是学校服务器侧网络不稳，不是你账号的问题。**在手机后台把 App 彻底关掉再打开**；持续失败就联系学校的系统管理员。
- **能看到登录页，但账号密码被判错**：先确认大小写和数字没输错，退出重登一次。仍然不行，拿这套账号密码去**学校的统一身份认证页面**验证一次——那边能进，说明密码没错，问题出在 App 到学校这一段。

**忘记密码**按账号类型处理：统一身份认证的密码在认证页面找回；能看到「找回密码」入口的，按提示用邮箱找回；提示"用户信息不存在"说明没绑邮箱，只能找学校教务处或信息中心的老师后台改。官网自己注册的个人账号，在登录页点「忘记密码」，改密邮件可能落在垃圾邮件里。

**改密码**：网页端进首页点「个人设置」再点「修改」；App 端在「我」页面改。有些学校关掉了自助改密，界面上不会出现「修改」按钮，这种情况找学校老师。

## 四、搜不到学校 / 选了学校也进不去

- **搜校名搜不出选项**：换成学校官方全称或常用简称再搜。如果一直搜不出，可能是学校把课程放在了合作平台上，官方给过的例子是改在学校栏里输平台代号（如 `COOC` 这类）再选对应入口，具体代号以你学校的通知为准。
- **选对了学校还是登不进**：想想你用的是不是学校发的账号。学校账号走「学校/机构师生登录」，走官网那个登录入口是进不去的，两个入口不通用。
- **登录成功但看不到课**：课程没进你的列表，属于加课问题，见[找课与课程访问码.md](找课与课程访问码.md)。

## 五、签不上到

签到只能用 App，网页端没有入口。签不上时按顺序查：

1. **网络必须通**，签到状态要即时发回服务器，网络差就容易失败。
2. **雷达点名要同时开网络、GPS、蓝牙**，漏一个就判不出你在教室。
3. **课程列表里找不到正在签到的课**：下拉刷新页面再选。
4. **确认没签上，当场找老师**。老师能在「点名记录」里手动改出勤状态，下课前说比课后说有用得多。

签到是有时限的，老师结束点名后入口就关了，所以别拖。完整流程见[签到与课堂互动.md](签到与课堂互动.md)。

## 六、视频看完了进度还是零

三种原因，逐条对：

- **内容是跳着看的**。老师的完成指标要求「累计看够 90% 或 100% 的内容」，跳过去没看的段落不算，进度条自然到不了顶。倍速播放是算数的，跳段不算。
- **网络不稳，记录没回传**。看完保持联网，回「章节」页面**下拉刷新一次**。
- **视频被跳到外部平台播放了**。内嵌的第三方视频必须在平台里直接点播，跳出去看，记录不回传。

完整规则见[看视频与学习进度.md](看视频与学习进度.md)。

## 七、作业交不上 / 附件传不上去

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| iOS 手机传不了文档 | iOS 版 App 的作业附件只支持图片和视频 | 换安卓手机或电脑网页端提交；要传文档建议转成 PDF |
| 提示附件数量超限 | 安卓端上限是图片 8 个、视频 4 个、文档 2 个 | 减少数量，或改从网页端提交（网页端数量不限，单个附件最大 2 GB） |
| 交完进度条还是没满 | 该作业的完成口径不是「提交即完成」 | 如果是互评作业，还要完成互评那一步才算完成 |
| 想再交一次交不了 | 老师设了提交次数上限 | 联系老师说明情况，由老师侧调整 |

## 八、测试相关问题

- **交完看不到成绩和答案**：公布时机由老师设定，可以「不公布 / 交卷后立即公布 / 定时公布」，也可以只公布分数不公布答案。看不到是正常设置。
- **答题中途被强制交卷**：老师开了「离开窗口次数」限制，超过就自动交卷；上限设成 0 时，离开一次就交。答题时不要切到别的应用。
- **没参加上怎么办**：找授课老师申请补考，老师批准后系统会发补考提醒，流程与正常考试一样。

细节见[作业测试与成绩怎么看.md](作业测试与成绩怎么看.md)。

## 九、收不到通知、漏掉点名

TronClass 的课程更新、点名发起、待办提醒都靠系统通知推送，通知一断，最容易漏的就是签到。按平台查：

- **Android**：进系统「设置 → 应用 → TronClass → 通知」，把通知总开关和分类开关都打开。有些系统还会对长时间不用的应用自动收回权限，需要重新给一次。
- **iPhone / iPad**：系统「设置 → 通知 → TronClass」，打开允许通知。

只想在上课时不被打扰、别的时候照常提醒，用系统的「专注模式 / 勿扰模式」比关应用通知更稳，模式结束后提醒照旧。

## 十、App 和网页端能做的事有什么区别

两边是同一套数据、同一个账号，但能操作的范围不一样，别互相替代：

| 你想做的事 | App | 网页端 |
| --- | --- | --- |
| 签到、点名 | 只有 App 能做 | 无入口 |
| 课堂互动（抢答、选人、随堂测） | 只有 App 能做 | 无入口 |
| 交作业、做测试 | 能做（附件类型和数量受限） | 能做（附件限制更宽松） |
| 翻章节、看长课件、写讨论 | 能做，屏幕小 | 更适合 |
| 进直播、看回放 | 能做 | 能做 |
| 发讨论帖、完成互评 | 能做 | 更适合写长文 |
| 建课、建测验题目 | 不能 | 只有网页端能做 |

直播和录播的入口、以及讨论与互评的具体规则，分别在[直播课怎么进与看回放.md](直播课怎么进与看回放.md)和[讨论与互评怎么参与.md](讨论与互评怎么参与.md)里。

## 十一、还是解决不了，找官方

「我」页面里有**反馈**入口，可以就平台问题和意见直接提交，这里也能看到当前的版本号。提交时把「手机型号 + 系统版本 + TronClass 版本号 + 复现步骤」一起写清楚，比只描述现象有效得多。

官方还提供帮助中心，收录了登录、资源管理、作业、测试、课中互动、成绩、学习分析等分类的常见问题，遇到具体功能上的疑问可以直接在里面按关键词找：
[help.tronclass.com.cn（简体）](https://help.tronclass.com.cn/) · [support.tronclass.com（繁体）](https://support.tronclass.com/)

涉及账号、成绩这类跟学校数据直接相关的问题，走学校教务处或信息中心处理最快——平台侧通常改不了学校后台的账号与成绩设置。
