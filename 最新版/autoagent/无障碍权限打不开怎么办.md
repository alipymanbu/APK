# AutoAgent 无障碍权限打不开怎么办

> 本篇专讲开不了无障碍的三种表现与解法：弹「受限制的设置」、开关点了没反应、开好又自己关掉。

## 一、先对号入座：你碰到的是哪一种

| 表现 | 常见于 |
| --- | --- |
| 开关点不动，弹「受限制的设置（出于安全考虑，此设置目前不可用）」 | 从网盘等非应用商店渠道安装的包 |
| 没有提示，按钮能点但按下去没反应、立刻弹回 | 部分管控更严的国产品牌系统 |
| 开好了，用着用着自己关了 | 后台管理激进的机型（见第五节） |

三种表现的解法不同，先认准自己是哪一种再动手。

## 二、为什么会弹「受限制的设置」

这是 Android 13 起引入的安全机制：**非应用商店等可信来源安装的应用，默认不允许开启无障碍权限**。你从 [AutoAgent 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a6fb24c6b539) 转存装上的包属于「侧载」应用，正好撞上这一条 —— 和 AutoAgent 本身没关系，换成任何一个从网盘装的自动化工具都一样（机制说明基于截至 2026-09 的公开资料，菜单措辞以你系统实际显示为准）。

顺带给你一个官方口径：AutoAgent 的隐私政策写明无障碍权限「用于组合用户自定义的自动化操作，非必须，用户同意后才会申请」—— 也就是说只有你用到自定义自动化动作时它才会要这项权限。

## 三、标准解法：先解锁，再开无障碍

按顺序三步，顺序不能反：

1. 打开 AutoAgent 的**应用信息**页（设置 → 应用 → 找到 AutoAgent；或长按桌面图标 → 应用信息）。
2. 点右上角的菜单，选**允许受限制的设置**。
3. 回到系统的「无障碍」设置，找到 AutoAgent，重新把开关打开。

各品牌这个选项的位置不一样（多个公开资料汇总，以机型实际显示为准）：

| 系统 | 「允许受限制的设置」在哪 |
| --- | --- |
| 原生 Android | 应用信息 → 右上角菜单 |
| 小米 | 应用信息 → 高级设置 |
| 联想 moto | 应用信息 → 右上角三点 → 允许所有权限 |

解锁后仍提示不可用的，**重启手机**再试一次 —— 这一步能解决大部分残留状态问题。

## 四、菜单里根本没这个选项

按顺序往下试，到能开为止就停：

1. 重启手机后再看一眼菜单；
2. 用**系统自带的文件管理器**重新点 APK 覆盖安装一遍 —— 经系统安装器装的包可信判定更高；覆盖安装不卸载应用，本地任务数据不受影响（隐私政策写明卸载才会丢失本地任务数据）；
3. ColorOS / 一加这类管控更严的系统，公开资料还给出两条进阶路径：在开发者选项里关闭「禁止权限监控」后重试；或连电脑执行：

```bash
adb shell appops set com.sudian.sdautoagent ACCESS_RESTRICTED_SETTINGS allow
```

第 3 条要开 USB 调试，属于高级操作，做完建议把开发者选项关回去。

## 五、开好了又被系统自动关掉

表现为开关看着是开的，但任务不跑；或无障碍设置里显示「未运行」「此服务出现故障」。这是部分机型（小米、OPPO 等）的后台管理策略在停无障碍服务，不止 AutoAgent，同类自动化工具都有大量同类反馈。处理：

1. 进无障碍设置，把 AutoAgent 的开关**关一次再开**；
2. 允许 AutoAgent 自启动 —— 隐私政策也写明定时启动功能依赖自启动，取消/开启的入口在**手机设置 → 权限设置 → 自启动**；
3. 把应用卡片在最近任务里锁定，电池策略设为不优化；
4. 系统大版本更新后回来复查一次开关。

任务「到点了不执行」的整体排查顺序，见 [常见问题与解决方法.md](常见问题与解决方法.md) 第二节。

## 六、开权限之前值得知道的一件事

无障碍权限能读取屏幕内容并模拟点击，是手机上最高的一档权限。给它开权限前，先确认你装的包来源可靠、版本对得上（对照见 [下载与安装教程.md](下载与安装教程.md) 第二节），只对你自己确认可信的应用开启。
