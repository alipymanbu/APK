## 一、这是个什么应用

Clockology 是 Clockology, LLC 出品的表盘与小组件设计工具，在 Apple Watch 圈子里最有名，后来也出了安卓版。你要做的是一件事：往一块画布上叠「图层」，拼出一个自己看的时钟——数字时钟、倒数日、步数环、照片钟表都可以，做完放到手机屏幕上当桌面钟，或者做成小组件钉在桌面上。

它和「壁纸 App」的区别在于：壁纸是一张静态图，Clockology 的表盘里时间、天气、电量这些数据是活的，跟着系统实时变。

## 二、编辑器的核心概念：图层

Clockology 的编辑器是图层制的——每往画布上加一个元素，就是加一层；图层可以调位置、大小、颜色、字体，也能分层编组。官方给出的图层类型包括：

| 图层 | 放的是什么 | 典型用途 |
| --- | --- | --- |
| 日期和时间 | 时、分、秒、日期 | 数字时钟的骨架；可选字体、特效、内置指针样式 |
| 天气 | 图标、温度、日出日落、当天时段变化图 | 需要位置权限，拿的是定位地的天气 |
| 活动与健康 | 步数、目标进度 | 步数可画成圆环、条形或文字 |
| 设备 | 电量等本机信息 | 做桌面钟时顺手显示电量 |
| 视频 | 高速播放的视频 | 动态表盘；可设多种触发方式 |
| 声音 | 音效 | 整点报时、点击出声这类玩法 |
| 自定义形状 | 形状、线条、阴影 | 数字环、形状环、指针都在这类里 |
| 交互按钮 | 点击后切换显示的另一组图层 | 一块表盘里塞「白天版 / 夜间版」两套内容 |
| 图片条带 | 一条横排小图按数值滚动 | 做日期滚轮、星期滚轮这类效果 |

同一块画布上叠得越多，越吃性能。官方 FAQ 明确提过：图层太多或图片分辨率太高会让应用崩溃，设计复杂表盘时建议控制图层数、压缩图片再导入。

## 三、最快的起步方式：先改别人的

1. 打开应用，进社区库（Community Library），里面有数千个免费设计，按风格翻；
2. 挑一个接近你想要的样子，导入或预览；
3. 进编辑器改：换字体、换配色、把别人图里的照片换成你自己的；
4. 保存后从全屏预览看效果。

从零开始画一块表盘完全可行，但对第一次用的人来说，改模板能更快搞懂每个图层是干嘛的。

## 四、免费能用到什么、订阅解锁什么

下载与基础编辑是免费的；订阅版（Clockology+）解锁的部分高级设计素材与功能。订阅价格（按第三方市场收录信息，截至 2026-09）：月付约 1.99–2.99 美元，年付约 19.99–24.99 美元，以你设备应用内实际显示为准。

用免费版就够了的话，订阅弹窗直接关掉即可，不影响编辑器主体功能。

## 五、做完的东西去哪看

- **全屏时钟**：应用内直接全屏展示，配合充电支架当床头钟、桌面钟用；
- **桌面小组件**：把设计挂到安卓桌面长显，具体步骤见 [桌面时钟与小组件设置方法.md](桌面时钟与小组件设置方法.md)；
- **分享设计**：做完可以导出给别人，别人也能导入你的——社区库就是这么来的；设计以 `.clock` 文件的形式保存、怎么备份与导入，见 [表盘设计文件备份与导入方法.md](表盘设计文件备份与导入方法.md)。

天气图层不出数据、应用闪退这类问题，集中在 [常见问题与解决办法.md](常见问题与解决办法.md) 里讲。还没装的话，从 [下载与安装教程.md](下载与安装教程.md) 开始。
