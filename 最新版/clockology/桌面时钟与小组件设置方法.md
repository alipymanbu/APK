## 一、把时钟加到桌面（小组件）

安卓加小组件的通用路径是「长按桌面空白处 → 小组件 / 窗口小工具 → 找到应用 → 选样式拖出去」。各家叫法不同：

| 品牌 | 入口叫法 |
| --- | --- |
| 原生 / Pixel | 长按桌面 → Widgets |
| 小米 / 红米 | 长按桌面 → 添加工具 |
| 华为 / 荣耀 | 长按桌面 → 窗口小工具 |
| 三星 | 长按桌面 → Widgets |
| OPPO / vivo | 长按桌面 → 小组件 / 桌面插件 |

在列表里找到 Clockology，把小组件拖到桌面上，选一块你做好的表盘即可。放上去之后想换样式，重新长按这个小组件进入设置换绑就行。

小组件加不出来、加了不显示，多数是系统把应用的后台权限限制了，处理办法在 [常见问题与解决办法.md](常见问题与解决办法.md) 的小组件一节。

## 二、当床头钟 / 桌面钟用

应用内自带全屏展示模式，比小组件更大的画幅适合摆在床头、办公桌上：

1. 在应用里打开你要展示的表盘，进全屏预览；
2. 手机插上充电线立起来（一个十来块钱的充电支架就行）；
3. 想让它整晚亮着，把系统的「自动锁屏 / 息屏时间」调长，或开启系统的「屏幕保护（Daydream / 息屏显示）」里与时钟相关的选项。

数字时钟、倒数日、照片钟表都适合这么摆；配「视频」图层做的动态表盘摆桌面上效果最明显，也最费电，自己权衡。

## 三、用壁纸思路做整屏钟

除了小组件和全屏模式，你还可以把喜欢的图导进编辑器做成整屏钟表壁纸，再用系统「设为壁纸」的思路铺满屏幕。区别在于：

- **静态壁纸**：就是一张图，时间不会动；
- **Clockology 方案**：时间、电量这些数据是实时刷新的，但要在应用（或它的小组件）里展示，不能直接当系统壁纸用。

## 四、常亮与耗电的取舍

关于耗电有两套说法，都摆在这里：官方 FAQ 称应用前台运行本身占用很小，耗电主因是「常亮（Always-On）」与亮度设置——这话是对 Apple Watch 说的；第三方评测与部分用户反馈则是高动画、多实时数据的表盘会明显增加耗电，双方结论有分歧。不冲突的部分是：**亮多久、多亮、跑多少动画，这三样才决定耗电大头**，与应用是不是 Clockology 关系不大。落到安卓机上的取舍：

| 需求 | 建议 |
| --- | --- |
| 白天桌上当挂钟 | 静态图层为主，关掉视频类图层 |
| 夜里床头钟 | 调低亮度或开系统的夜间省电显示 |
| 整天常显 | 只保留时间 + 电量两个图层，别放天气轮播 |
| 平时放兜里 | 用小组件，别开常亮 |

另外记得在系统设置里给这个应用关掉电池优化（安装篇提过），不然摆着摆着被系统杀掉，时钟就停在最后一帧了。
