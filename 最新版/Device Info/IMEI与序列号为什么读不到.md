# Device Info IMEI 与序列号为什么读不到

> 本篇解释 Device Info 里 IMEI、序列号、MAC 地址这类标识信息显示 unknown 或空白的原因：多数是安卓系统级限制，不是应用坏了；以及这些号码该去哪里查。

## 一、先说结论：多数是系统限制

安卓官方开发者文档写明：从 Android 10 开始，IMEI、MEID、IMSI、序列号这类设备标识只允许「特权应用」读取——默认短信应用、系统预装的特权应用、拿到运营商授权的应用，或被设为设备所有者/资料所有者的应用。普通应用即使拿到了电话权限，去读这些标识时，系统要么抛安全异常，要么直接返回空值或占位数据。

所以你在 Device Info 的设备板块里看到 IMEI 或序列号一栏是空的、unknown，或是一串明显不对的占位值，在 Android 10 及以上的机器上属于正常现象。应用能读到什么，完全取决于系统放出了什么——这不是换个应用、多给权限就能解决的口子。官方口径下 root 后应用能以更高权限多读到一部分，但日常查看没必要为这个去 root。

## 二、受影响的不止 IMEI

同一份官方文档（[不可变的设备 ID](https://source.android.google.cn/docs/core/permissions/immutable-device-ids)）列出的受限标识还包括：

| 标识 | 什么情况下读不到 |
| --- | --- |
| IMEI / MEID / IMSI | Android 10 起普通应用一律受限 |
| 设备序列号（SN） | 同上 |
| SIM 卡序列号 | 同上 |
| USB 配件序列号 | Android 10 起默认不向普通应用开放 |
| Wi-Fi 出厂 MAC 地址 | Android 10 起默认改为随机 MAC，且每个 Wi-Fi 网络各分配一个不同的随机地址 |

最后一条解释了很多人在应用里看到的「MAC 地址怎么变来变去」：设置里和读取类应用里显示的默认都是随机 MAC，真实出厂 MAC 从 Android 10 起在系统设计上就不对普通应用开放。

## 三、这些号码去哪里查

- **IMEI**：拨号盘输入 `*#06#`，屏幕会直接弹出 IMEI——这是系统级功能，不需要给任何应用任何权限。包装盒、SIM 卡托、系统设置 → 关于手机里也能找到。
- **序列号**：系统设置 → 关于手机 → 状态信息（具体路径随品牌略有差异）。
- **当前网络的 MAC 地址**：设置里的 WLAN 详情页。
- 二手交易核验 IMEI，用拨号盘代码加包装盒标签比对最稳；第三方应用里读不到，不代表机器有问题。

## 四、和 Device Info 的关系

Device Info 在标识信息这块只是如实显示系统给的结果，字段空白时没有任何设置项能把它变出来。验机时把精力放在它真正擅长的地方——硬件测试与电池、屏幕读数，完整流程见 [验机与硬件测试步骤.md](验机与硬件测试步骤.md)；各类字段空白的其他原因（权限、机型差异）见 [常见问题与排查.md](常见问题与排查.md)。
