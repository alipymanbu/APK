> 本篇按 Device Info 的各个信息板块过一遍：每个板块里有哪些字段、关键数值怎么读、哪些地方容易误读。

## 一、先看仪表板

打开应用，首页仪表板把整机概况放在一屏里：内存占用、内部/外部存储、电池状态、CPU、可用传感器数量、已装应用数。它的定位是「一眼看整体」，想看某一项的完整参数要进对应板块。你装的 3.4.1.4 与官方最新版的板块划分略有出入，个别名称以你界面为准，位置基本一致。

## 二、设备与系统板块

**设备板块**回答「这台机器是谁」：设备名称、型号、品牌、制造商、主板、硬件、序列号、IMEI、SIM 序列、网络运营商与网络类型、出厂日期与设备年龄、build 指纹。

**系统板块**回答「它跑的什么系统」：Android 版本与代号、API 级别、安全补丁级别、内核版本、bootloader、基带、Java 虚拟机、Google Play 服务版本、Vulkan 与 OpenGL ES 支持、系统开机时长，以及是否检测到 root 管理应用。

读数时的几个要点：

- API 级别与 Android 版本一一对应（如 API 33 对应 Android 13），报修或查兼容性时报 API 级别更准确。
- **安全补丁级别**是二手机器容易被忽视的一项：它显示系统最后一次打安全更新的年月，日期太老说明系统长期没更新过。
- 「检测到 root 管理应用」指的是设备上装了这类管理工具，它只是如实报告检测结果。

## 三、CPU 与 GPU

这个板块列的是 SoC 与图形部分：处理器名称、CPU 架构、支持的 ABI、核心数、每颗核心的实时频率、governor，以及 GPU 渲染器、GPU 厂商与版本。

- 核心频率实时跳动是正常的——系统按负载在大小核之间调度，待机时低频、打开应用时蹿高。
- ABI 一栏主流机型显示 arm64-v8a（多数同时兼容 armeabi-v7a），它决定这台机器能装哪类编译产物的应用。

## 四、屏幕与内存

**显示板块**：分辨率、像素密度（DPI）、字体缩放、物理尺寸、支持的刷新率、HDR 支持与能力、亮度水平。买屏幕时最常核对的是分辨率与刷新率两项——高刷机型在这里能看到系统实际运行的刷新率档位。

**内存板块**：RAM 容量与实时占用、RAM 类型与频率（部分机型读不到这两项）、内部存储容量与占用、外部存储。

## 五、传感器与相机

**传感器板块**把手机里所有传感器逐个列出：名称、厂商、类型、功耗、是否唤醒型、动态传感器支持、最大量程。加速度计、陀螺仪、光线、接近这些常用件一目了然，缺了哪个（比如没有气压计）也在这里看出来。

**相机板块**把每个摄像头分开列参数：光圈、焦距、ISO 范围、RAW 支持、分辨率、裁切系数、对焦模式、闪光模式、图像格式、人脸检测模式。

官方特别说明过的一处坑：受安卓系统限制，应用显示的**百万像素值可能与厂商标称对不上**；相机的功能特性（对焦方式、RAW 等）是准确的。核对像素以厂商标称为准，见 [常见问题与排查.md](常见问题与排查.md) 第一节。

## 六、网络与连接

网络板块显示当前连接的细节：IP 地址、网关、子网掩码、DNS、租用期限、接口、Wi-Fi 频段频率、Wi-Fi 标准、安全类型与链路速度。连接板块列蓝牙、NFC、UWB、USB 的支持情况。一个常见的疑惑：MAC 地址一栏显示的不是厂商标签上的那个——Android 10 起系统默认对每个 Wi-Fi 网络使用随机 MAC，应用里看到随机地址属正常，详细解释见 [IMEI与序列号为什么读不到.md](IMEI与序列号为什么读不到.md)。

另外应用内带一个 Wi-Fi 分析工具，能扫描周边网络并列出信号强度、信道、Wi-Fi 标准、加密方式与估算距离——排查家里路由器信道拥堵时有用。

## 七、两个使用提醒

- 部分字段显示 unknown 或空白，多数不是应用坏了，而是系统没把这项数据放出来——新版安卓逐步收紧信息读取，部分厂商封得更多。哪些情况属正常、哪些能补救，见 [常见问题与排查.md](常见问题与排查.md)。
- 应用读数来自系统接口本身：机器在出厂信息上标错（工程机、翻新改标）时，它会把错误值如实显示出来。这也是它常被拿来做二手验机的原因，完整验机流程见 [验机与硬件测试步骤.md](验机与硬件测试步骤.md)。
