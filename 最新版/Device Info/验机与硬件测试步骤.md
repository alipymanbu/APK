## 一、什么场景用它验机

三个典型场景：二手交易收货当场核验、维修取机验收（换屏、换电池之后）、新机到手首次检查。

先建立一个预期：这组硬件测试是**交互式**的——应用给出操作提示，由你观察和判断结果，不是自动跑分。所以它的价值取决于你每一项是否认真做，官方也把「买手机时检查硬件」列为主要用途之一。

## 二、测试清单与确认要点

3.4.1.4 这一版可用的测试项与你要确认的东西如下（个别项目名称以你界面为准）：

| 测试项 | 操作 | 你要确认什么 |
| --- | --- | --- |
| 显示（Display） | 按提示切纯色画面 | 无坏点、无异常色斑；有争议就多换几个纯色反复看 |
| 多点触控（Multi-touch） | 多根手指同时画 | 每根手指都有独立轨迹，无断触、无漂移 |
| 手电筒（Flashlight） | 点亮 | 能亮、亮度正常 |
| 扬声器（Loudspeaker） | 播放测试音 | 有声、无破音；双扬声器机型两侧都出声 |
| 听筒（Ear Speaker） | 贴耳听 | 音量正常、无杂音 |
| 麦克风（Microphone） | 录音回放 | 回放清晰（需录音权限） |
| 接近传感器（Ear Proximity） | 遮挡/移开 | 读数随之变化 |
| 光线传感器（Light） | 遮挡/照亮 | 数值响应 |
| 加速度计（Accelerometer） | 各方向倾斜 | 轴数值跟随变化 |
| 充电（Charging） | 插电 | 功率/电流读数变化 |
| 耳机（Headset） | 插入耳机 | 识别正常、出声正常 |
| 振动（Vibration） | 触发 | 手感明显 |
| 蓝牙（Bluetooth） | 开关/扫描 | 正常开启与扫描 |
| 指纹（Fingerprint） | 录入指纹识别 | 能识别（需系统里先录过指纹） |
| 音量键（Volume up/down） | 逐个按压 | 每个按键都有响应 |

## 三、二手验机建议顺序

1. **先核对配置与描述是否一致**：设备板块看型号、内存、存储容量，系统板块看安全补丁级别——和卖家说的对不上就直接结束，没必要往下测（各板块字段见 [界面板块与参数解读.md](界面板块与参数解读.md)）。想核对 IMEI 的话，直接在拨号盘输 `*#06#` 最稳——应用在安卓 10 以上的机器上多半读不到 IMEI，这是系统限制，原因与替代查法见 [IMEI与序列号为什么读不到.md](IMEI与序列号为什么读不到.md)。
2. **跑硬件测试**：按第二节清单过一遍，重点花时间的是屏幕（坏点、断触）、扬声器、麦克风、充电这四项——它们是维修纠纷里最常见的争议点。
3. **看电池状况**：电池板块的健康度提示与充电功率读数，判断电池老化程度；较新的机型还能看循环次数，参考区间见 [电池健康与温度监控.md](电池健康与温度监控.md)。
4. **导出报告留档**：右上角三点菜单 → Export data，勾选内容后导出 PDF 或 TXT。收货当场导出一份存下来，之后出现纠纷时有原始记录可比对。

## 四、几个注意点

- **权限提前放行**：麦克风、相机、存储等测试依赖对应权限，被拒的测试会直接做不了。权限对照表见 [下载与安装教程.md](下载与安装教程.md) 第四节，建议验机前先开好。
- **别一口气快过**：交互测试跳着点容易漏掉间歇性问题，每项都按提示完整做。
- **一次正常不等于没问题**：间歇性断触、偶发破音这类故障单次测试未必复现，可疑项目多测几轮。
- 测试结果反映的是当下状态，导出的报告记得连日期一起留。
