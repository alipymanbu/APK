# Perplexity 设为手机默认助手与语音唤醒

## 一、先确认值不值得设

设成默认助手后，**长按侧键 / 喊唤醒词**会跳过桌面直接打开它，适合把「查一下」当成高频动作的人；代价是原本的系统语音助手入口被顶掉，想用回原来的得手动改回去。设置前先按 [下载与安装教程.md](下载与安装教程.md) 装好并登录。

## 二、安卓通用路径

不同品牌菜单名有出入，认这几个词：**默认应用 / 默认数字助理 / 数字助理应用**。常见走法：

1. **设置** → **应用**（或「应用管理」）→ **默认应用**；
2. 找到 **数字助理应用**（有的叫「默认助手应用」「默认数字助理」）；
3. 选 **Perplexity**；
4. 回到桌面，按机型对应的触发方式（长按 Home、长按侧键或电源键）验证能唤起。

厂商把它埋得比较深时，直接在**设置顶部的搜索框**里搜「默认」「助手」两个词最快。

## 三、以三星 Galaxy 为例（官方支持页口径）

三星公开支持文档里把这两条路径写得最清楚，其他品牌照此类推：

**长按侧键唤起**：

1. 设置 → **高级功能** → **侧键**；
2. 「长按」那一项点进去 → 点齿轮图标；
3. 在「默认数字助理应用」里选 **Perplexity**；
4. 之后长按侧键即唤起。

**语音唤醒（Hey Perplexity）**：

1. 设置 → **高级功能** → **语音唤醒**；
2. 打开 **Hey Perplexity 检测**；
3. 按提示**录一遍声纹**（若列表里没有这一项，先把系统的语音唤醒组件与 Perplexity 都更新到最新版再试）；
4. 录完说唤醒词即可，息屏状态下也能唤起（三星口径）。

**注意**：菜单路径、是否提供语音唤醒、可用语言，**随机型、系统版本与地区不同会有差异**；找不到某一项时以你手机上当时显示的为准，必要时先把系统与应用都升到最新。

## 四、唤起之后能做什么

- 直接说话提问，答案与你在应用里问的完全一致，历史照常进账号；
- 部分机型上它还能代为操作手机功能（如设闹钟）—— 这依赖厂商开放的接口，能不能用以实测为准，不保证每台机器都有；
- 语音唤醒常驻后台，耗电与隐私取舍自己权衡；介意的话只保留长按侧键这一种触发。

## 五、改回去 / 不灵了

- **换回原助手**：走与设置时**同一条路径**，把默认数字助理改回系统自带的那项即可；
- **长按没反应**：先确认默认助手已经显示为 Perplexity，再看侧键的「长按」动作有没有被别的功能占用（截屏、支付快捷键等）；
- **喊了没反应**：确认声纹录过、语音唤醒开关是开的、麦克风权限给了 Perplexity（设置 → 应用 → Perplexity → 权限 → 麦克风）；
- 应用本身打不开、连不上时，先按 [常见问题与故障排查.md](常见问题与故障排查.md) 处理，助手入口自然就好了。
