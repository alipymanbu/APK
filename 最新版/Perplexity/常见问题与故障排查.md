# Perplexity 打不开、连不上与闪退的排查方法

> 本篇按出现频率排：一直转圈连不上、提示请求过于频繁、闪退白屏、登录收不到邮件、引用点不开。

## 一、一直转圈 / 提示连接错误

按这个顺序试，通常第二步就能解决：

1. **换网络试一次**：Wi-Fi 与流量各试一遍，排除当前网络本身不通；
2. **关掉 VPN / 代理再试**：这是最高频的原因 —— 服务端挂着 Cloudflare 一类防护，容易把某些代理出口当成机器人流量直接拦掉，表现为「连接错误」「403」「Access Denied」。关掉后刷新；确实需要代理的话，换一个出口节点再试；
3. **强制停止后重开**：设置 → 应用 → Perplexity → 强制停止，再打开；
4. **确认不是全员故障**：网页端与手机端同时都打不开时，先查服务状态 —— 打开 [Perplexity 服务状态页](https://status.perplexity.com) 或官方社交账号看有没有正在进行的故障通告，是服务端的问题的话本地怎么折腾都没用，等恢复即可；
5. 以上都不行，按 [下载与安装教程.md](下载与安装教程.md) 重新下载安装包覆盖安装一次（包版本过旧与服务端不兼容，会表现为「搜了但什么都不返回」）。

## 二、提示 Too many requests / 429

这是**额度用尽**，不是故障：免费档对高级检索档位与单位时间内的请求量都有限制。处理办法：

- 等一会儿（通常十几分钟会放行一部分），或等次日额度重置；
- 期间改用标准搜索，它基本不限量；
- 天天见底就该考虑订阅了，档位与价格见 [Pro搜索与深度研究额度.md](Pro搜索与深度研究额度.md)。

**特别注意**：开 Pro 搜索的线程里**每一句追问都单独扣次数**，一路追问下去额度会掉得飞快 —— 这不是被限流，是自己用掉的。

## 三、闪退、白屏、卡在加载页

1. **强制停止再打开**：设置 → 应用 → Perplexity → 强制停止；
2. **清缓存（不清数据）**：设置 → 应用 → Perplexity → 存储 → **清除缓存**。⚠️ 别点「清除数据」，那会把登录状态一起清掉，得重新登录；
3. **检查更新**：应用版本落后服务端太久会出现「界面出来了但点哪都没反应」；
4. **看一眼存储空间**：手机可用空间见底时应用起不来；
5. **临时关掉安全类 / 加速类工具**再试一次，这类软件有时会拦截应用的网络请求；
6. 还不行就卸载重装 —— **历史存在账号里**，登回去就能看到，不用怕丢（没登录的记录才找不回来）。

## 四、登录收不到邮件 / 点了登不进去

- **先翻垃圾邮件箱**，验证邮件经常被判成垃圾；
- **链接会过期**：重新请求一次登录链接，然后打开**最新收到的那封**，翻旧邮件点开是无效的；
- 换个邮箱试 —— 部分邮箱服务商对这类自动邮件拦截较严；
- 走 Google 账号一键登录可以绕开邮件这一环；
- 订阅付了款却没生效：多半是**登录着另一个账号**，退出后登回付费用的那个，权益跟着账号走。

## 五、引用角标点不开 / 打开是 404

- **原文被删或改地址了**：网页失效很常见，不是应用坏了 —— 换下一个角标，或重新搜一次让它的检索层给你换来源；
- **引用数为零**：先看你是不是停在 Writing 这类不联网的模式上，切回 All / Academic 再问一次，模式的调法在 [Focus搜索模式怎么切换.md](Focus搜索模式怎么切换.md)；
- **答得像过期信息**：用搜索框旁的日历图标把时间范围限制到近一周 / 近一月，逼它去读新页面。

## 六、安装阶段就失败

装不上、提示「解析包时出现问题」「应用未安装」，属于安装环节而非应用本身：

- **系统版本低于 Android 8** 装不了（最低要求见 [下载与安装教程.md](下载与安装教程.md)）；
- **包没下完**：断点续传的包容易残缺，删掉重新下，下完核对一下大小是不是 64.85M；
- **空间不足**：清出 200MB 以上再装；
- **与已装版本冲突**：先卸载旧的（或确认包名一致是 `ai.perplexity.app.android` 的同签名包）再装。

## 七、还是解决不了

带上三样信息去找官方帮助中心：出问题的**具体提示原文**、**手机型号与安卓版本**、**第几步开始失败的**。多数「打不开」的工单，最后都落在网络环境与缓存两项上 —— 先把第一节的五步走完再提交，能省掉一轮来回。
