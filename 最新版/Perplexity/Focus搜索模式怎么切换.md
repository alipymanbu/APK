## 一、Focus 是干什么的

Focus 决定**它去哪儿找资料**。默认模式搜整个网页，好处是通用，坏处是搜论文时混进营销号、搜真实评价时全是厂商稿。把范围收窄到对应渠道，同样一句问题的来源质量会明显不一样 —— 这是这个功能唯一的作用，也不需要你改提问措辞。

## 二、手机上选择器在哪（默认是藏起来的）

安卓 / iOS 客户端为了把屏幕留给答案，**把 Focus 行收起来了**，很多人因此以为应用没有这个功能。调出来三步：

1. 点一下**输入框**（键盘弹出）；
2. 输入框正下方会出现一排小图标，默认亮着的是 `All`；
3. **在这排图标上向左划**，能看到被截在屏幕外的其余模式。

选中后，输入框旁会挂一个小标签显示当前模式。**一开始打字，这排图标就会收起来** —— 这是正常设计，不是坏了；想改就再点一次输入框调出来，提交之前选好即可。

## 三、各模式分别搜什么

选项随版本会有增减，下表是常见的几项，以你手机上当时列出的为准：

| 模式 | 搜什么 | 什么时候用 |
| --- | --- | --- |
| All / Web | 整个网页，默认范围 | 日常问题、时事、不确定该用哪个时 |
| Academic | 论文与学术库 | 写论文找文献、查研究结论 |
| Writing | 不联网，纯模型生成 | 起草、改写、翻译这类不需要出处的活 |
| Video / YouTube | 视频内容 | 想看某人的讲解视频、要时间点 |
| Social | 社交平台帖子 | 看近期讨论热度 |
| Reddit | Reddit 讨论 | 求真实用户经验、产品吐槽 |
| Math / Wolfram Alpha | 计算与数据 | 算题、单位换算、查数值 |

**用错模式的典型症状**：问了带引用的问题却一个角标都没有（多半落在 Writing 这种不联网的模式上），或者问技术问题却翻出一堆论坛碎碎念（该切 Academic 或者干脆回 All）。判断方法见 [Pro搜索与深度研究额度.md](Pro搜索与深度研究额度.md) 里对检索档位的说明。

## 四、把常用模式设成默认

每次开应用都要重选一遍很烦，可以一次性设好：

1. 点左上角**头像** → **Settings**（设置）；
2. 找到 **Search Defaults**（搜索默认值）；
3. 进入 **Focus**，挑一个你常用的模式。

之后每次新开搜索，选中的模式就已经挂好了，不用再点一遍。菜单项名字不同版本可能有出入，在设置里认「Focus」「Search Defaults」这几个词即可。

## 五、选了却没生效怎么办

按这个顺序查，多数问题在前三步就解决了：

1. 确认标签真的挂上了 —— 提交前看输入框旁有没有那个小标签；
2. 强行关闭应用再打开，界面状态会重置；
3. 还不行就清一次缓存：设置 → 应用 → Perplexity → 存储 → **清除缓存**（别点「清除数据」，那会把你登出）；
4. 清完仍不生效，连同其他异常一起看 [常见问题与故障排查.md](常见问题与故障排查.md)。
