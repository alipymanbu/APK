# 画面卡顿与白屏调优

> 连接正常但画面不对：白屏、卡顿、模糊、花屏，按现象对号入座来调。

## 一、先分清三种画面问题

| 现象 | 性质 | 去哪一节 |
| --- | --- | --- |
| 连上后全白，什么都没有 | 编解码器兼容问题 | 第二节 |
| 卡、模糊、不流畅 | 带宽或画质参数不匹配 | 第三、五节 |
| 一会清晰一会模糊、花屏、绿屏 | 硬件编码撞上网络抖动 | 第四节 |

本文参数多来自官方常见问题页的口径（如码率默认 3M、画质默认 1080P），会随版本变；设置入口与可选项以你手上客户端的实际界面为准，官方 FAQ 在 [desk.hsslive.cn/#/faq](https://desk.hsslive.cn/#/faq)。

## 二、白屏：逐个换视频编解码器

官方 FAQ 给的是排除法，在「高级设置 → 编解码器」里做：

1. 先取消勾选 H265、AV1，刷新重连；
2. 还白屏，再取消 H264，刷新重连；
3. 仍白屏，再取消 VP9，刷新重连。

每换一步都重连一次再判断，别一口气全关完才试，否则不知道是哪一档起了作用。

## 三、卡顿与模糊：先把带宽账算清

1. 主控、被控两端各测一次网速（官方 FAQ 用的是 [speedtest.cn](https://www.speedtest.cn)）。
2. 哪端实测低于 10 Mbps，码率就别设到高于它的值——码率超出带宽，画面只会更糊更卡。
3. 官方 FAQ 的推荐组合（以官方页面当前口径为准）：

   | 项 | 推荐 |
   | --- | --- |
   | 最高码率 | 能设的最大值（默认 3M） |
   | 最低码率 | 比最高码率低一档，或与其相同 |
   | 帧率 | 60 帧上下，过高未必更好 |
   | 画质 | 能设的最高档（默认 1080P） |

## 四、硬件编解码是双刃剑

「高级设置 → 基本设置」里有硬件编码、硬件解码（有的版本还有零拷贝）、降级模式、网络模式等开关，官方 FAQ 的口径：

- 网络好：开硬件编码 + 硬件解码，降级模式选保分辨率，网络模式选低延迟。
- 被控电脑是英伟达显卡（GTX 10 系列起）时：画面「一会清晰一会模糊、花屏、绿屏」多半是硬件编码撞上网络抖动，把硬件编码、硬件解码都关掉再试。
- N 卡硬编要生效，显卡得是十代以上（如 GTX 1050 / 1060 / 1650），驱动 570.0 或更高；「明明有 N 卡 CPU 占用还是高」先查这两项。

## 五、换中继服务器

打洞失败走中继时，中继的距离与拥堵直接决定流畅度：

1. 「高级设置 → 网络设置 → 中继服务器」里换一个离你近的。
2. 一次只选一个，不流畅再换下一个，逐个试出来。
3. 自建服务器的用户，中继地址填自己的，见[自建服务器与自定义接口配置.md](自建服务器与自定义接口配置.md)。

## 六、调不动了

画面这条线与连接那条线是两回事：连不上、频繁掉线按[连接不上排查.md](连接不上排查.md)走；画质参数怎么调都救不回来时，先确认两端版本一致（见排查篇第二节），再考虑升级。
