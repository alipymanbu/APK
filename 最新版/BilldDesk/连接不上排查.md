## 一、按卡住的位置对号入座

| 现象 | 先查什么 |
| --- | --- |
| 输入设备码提示找不到设备 | 被控端客户端是否还开着；两端是否连的同一个服务 |
| 提示密码错误 | 大小写、前后空格；被控端是不是刚改过密码 |
| 一直转圈连不上 | 网络环境；P2P 打洞失败会改走中继，中继不通就永远卡住 |
| 能连上但几秒就断 | 被控端进程被系统杀，安卓端看[安卓被控端权限设置.md](安卓被控端权限设置.md)里的保活部分 |
| 画面出来了但点不动 | 被控端权限没给全，安卓被控看[安卓被控端权限设置.md](安卓被控端权限设置.md) |
| 连得上但画面白屏 / 卡顿 | 不是连接问题，去[画面卡顿与白屏调优.md](画面卡顿与白屏调优.md) |

## 二、版本不一致是最常见的暗坑

官方在仓库里说过：项目没有稳定版，每次提交都可能带不兼容改动。落到日常使用就是三条经验：

1. 控制端和被控端版本差得远、行为又对不上时，先把两端都升到[官方下载页](https://desk.hsslive.cn/#/download)的当前版本再试。
2. 你要是自建了服务端，客户端版本还得跟服务端配套，见[自建服务器与自定义接口配置.md](自建服务器与自定义接口配置.md)。
3. 反过来，两端都是 0.58.0 且一直好好的，不必为了升级而升级；这类项目的「最新版」不等于「更稳」。

## 三、网络与中继

1. 两端各切一次网络（手机从 Wi-Fi 切到流量最方便），切完能连，说明原网络有限制——公司网、校园网常拦这类流量。
2. P2P 直连失败时流量走中继服务器，中继拥堵或不通时表现就是「永远在连接中」。客户端支持自定义接口（API、WebSocket、中继服务器地址），有服务器资源的可以把地址换成自己的，具体见[自建服务器与自定义接口配置.md](自建服务器与自定义接口配置.md)。
3. 电脑端被控时留意防火墙弹窗，拦下来就放行；Windows 上弹一次没理它，之后每次被控都可能失败。

## 四、被控电脑一侧的专属坑

被控端是电脑时，有几类官方常见问题页点名过的坑：

- **Windows 7 不支持**，装了也打不开。Windows 安装后闪退，先退出 360 杀毒再试；报缺 `MSVCP140.dll`、`VCRuntime140.dll` 这类文件，装一次 [VC++ 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe) 再重启。
- **被控端是 mac**：看不到画面或点不动，去「隐私与安全性」里给录屏与系统录音、辅助功能两项开权限；开关无效时，官方 FAQ 强调要把权限列表里的 BilldDesk **删掉重新添加**再开，不是关了再开。
- **游戏窗口里键鼠不生效**（其他界面正常）：游戏自身的风控在拦，官方暂未支持驱动级键鼠，别在游戏里白折腾。
- **提示风控**：官方口径是使用高峰期容易触发，等一会再连；官方同时称购买套餐的账号发起远程不触发风控——两条并列摆在这，等得起就等，等不起自己权衡。

## 五、还查不出来再找这三处

- 官方[常见问题页](https://desk.hsslive.cn/#/faq)收录已知问题，先搜一遍症状关键词。
- 官方在 B 站有视频频道（更新演示与教程）：[BilldDesk 远程控制](https://space.bilibili.com/381307133)。
- 确认像客户端本身的毛病，再去 GitHub 提 issue：主仓库 [billd-desk issues](https://github.com/galaxy-s10/billd-desk/issues)（网页端、电脑端）；安卓端对应 [billd-desk-flutter](https://github.com/galaxy-s10/billd-desk-flutter)。提之前把两端版本号、网络环境、卡在哪一步写清楚，来回追问最费时间。
