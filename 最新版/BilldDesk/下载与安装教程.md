## 一、装之前先核对这几点

BilldDesk 是一个开源远程桌面项目，电脑端、网页端、安卓端各自是独立的客户端。你手里这份是**安卓安装包（APK）**，装之前先核对下面的信息，确认它跟你预期拿的是同一份：

| 项目 | 值 |
| --- | --- |
| 安装包版本 | 0.58.0 |
| 安装包大小 | 约 49.82 MB |
| 包名 | `com.example.billd_desk_flutter_pro` |
| MD5 | `BC3467E29CAC2BABC1B13EE7EFD98D19` |

三点提醒：

1. 项目更新很快，官方下载页给出的安卓最新版可能已经不是 0.58.0（截至 2026-09 显示为 v0.600.0），以[官方下载页](https://desk.hsslive.cn/#/download)当时显示为准。
2. 官方仓库明确说明：项目至今没有发布过稳定版，版本之间可能存在不兼容的改动。后面遇到连接异常，先想到「两端版本不一致」这一层，排查思路见[连接不上排查.md](连接不上排查.md)。
3. 安卓端官方实测过的范围是 Android 11 至 Android 15；更早的安卓版本没有实测结论，能不能装、装上能不能用都不保证。

## 二、从哪里拿安装包

两条路，拿到的都是同一个项目的安卓客户端：

- **网盘获取**：[BilldDesk 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8197b6397538)，转存后下载这份 0.58.0 的 APK，可用上面表格里的 MD5 自行校验文件完整性。
- **官方渠道**：[官方下载页](https://desk.hsslive.cn/#/download) 提供 Windows / macOS / Android 各端安装包和多家网盘链接；[GitHub Releases](https://github.com/galaxy-s10/billd-desk/releases) 也有历史版本发布包。

## 三、安装步骤

1. 把 APK 传到手机：装了网盘 App 的直接在网盘里下载；也可以电脑下载后用数据线拷过去。
2. 在手机的文件管理器里点开这个 APK。首次安装会触发「未知来源应用」提示，按提示允许即可——不同品牌手机的叫法有差异，有的在安装弹窗里直接授权，有的要先去「设置 → 安全」里打开开关。
3. 等安装完成，打开 App。

## 四、装好之后

- 打开 App，首页能看到本机的设备码与连接密码（具体位置以你这版界面为准）——这是别的设备来连接这台手机时要用的凭据，官方支持自定义这两项。
- 想用手机去**控制电脑**：先在那台电脑上装好电脑端客户端（同一个官方下载页能下），操作流程见[手机控制电脑怎么操作.md](手机控制电脑怎么操作.md)。
- 想让手机**被控制**（比如用电脑操作手机）：先在手机上把权限给到位，见[安卓被控端权限设置.md](安卓被控端权限设置.md)。
