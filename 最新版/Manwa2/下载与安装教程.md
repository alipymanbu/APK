## 一、装之前先核对这几个信息

你拿到安装包后，先对一遍下面这张表，能避免装错包、装到别的应用。这份数据是安装包本身的事实，网上渠道页标称的版本与大小五花八门（从 3.x 到 5.x 都有），**一律以本表为准**：

| 项目 | 数值 |
| --- | --- |
| 应用名 | Manwa2（漫蛙2） |
| 版本 | 3.0.3 |
| 包名 | `com.zhuiman.yienna` |
| 大小 | 42.83M |
| MD5 | `54dee4f3d4129867bbbecd8b7153951a` |
| 记录时间 | 2026-09-21 |

包名是最可靠的核对项：你手机上装好后，在「设置 → 应用信息」里看到的包名应是 `com.zhuiman.yienna`。系统要求方面，各渠道页标注不一（有标安卓 5.2 以上、也有标安卓 4.0 以上），以官方页面当时显示为准；如果你的安卓版本过老，装不上时按 [常见问题与故障排查.md](常见问题与故障排查.md) 处理。

[Manwa2 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0f46cde6b81d)

打开分享链接 → 转存到你自己的网盘 → 在网盘里找到 `Manwa2_v3.0.3.apk`（所在文件夹名为 `Manwa2（先保存再下载）`）→ 下载到手机。先转存再下载，链接失效时你网盘里那份还在。

## 三、安装步骤（安卓）

1. 用手机浏览器或网盘 App 把 APK 下载到本地（下载完在「下载」或网盘的缓存目录里能找到）。
2. 点击这个 `.apk` 文件，系统会弹出安装界面。
3. 如果提示「禁止安装来自此来源的应用」，点提示里的去设置按钮，打开「允许来自此来源的应用」开关（不同品牌手机叫「未知来源」「安装未知应用」），授权后再返回安装。
4. 等进度走完点「完成」，回到桌面打开应用。
5. 打开后到「设置 → 应用信息」核对包名是不是 `com.zhuiman.yienna`，确认装对了。

第 3 步只是系统对非应用商店来源的例行拦截，不是安装包有问题；每换一个来源（比如浏览器、网盘）都要单独授权一次。

如果你手机上已经装过 Manwa2 的其它渠道包，**先卸载旧的再装这份，不要覆盖安装**——同名应用签名不一致时覆盖安装会直接失败（提示安装错误），卸干净后重装即可。安装包建议留在手机里备份一份：以后清缓存或换机时，不用重新去网盘取。
