## 一、阅读页能调什么

你进入阅读页后，点一下屏幕中央会呼出控制条，常见可调项有：

| 设置 | 什么时候调 |
| --- | --- |
| 字号 | 正文对话文字偏小或偏大时 |
| 背景色 / 阅读主题 | 夜里看嫌刺眼时，切深色主题；白天可切回浅色 |
| 横屏 / 竖屏 | 条漫竖着划顺手就竖屏；跨页大图想看清细节就横屏 |
| 翻页方式 | 滑动（一根手指上下划）与翻页（左右点按翻页）两种习惯，选顺手的那种 |
| 自动翻页 | 想腾出手时开启，速度按自己阅读节奏调 |

阅读主题的切换入口在阅读页的设置里（不同版本叫「主题」「背景」或「阅读设置」，以你装的版本界面为准）。建议你第一次进阅读页先把这四项按习惯调好——尤其是夜间场景把背景切深色，长章节看下来眼睛负担小很多。

## 二、把章节缓存到本地（离线看）

在有网络时，你可以把喜欢的漫画章节下载缓存到手机里，之后没网（地铁、飞机、信号差的地方）也能继续看：

1. 进入作品详情页或阅读页，找到**下载 / 缓存**入口。
2. 选要缓存的章节（一般支持多选或整部）。
3. 等下载完成，断网后从书架或缓存入口进，已缓存的章节照常翻页。

注意两点：缓存占的是手机存储，长篇整部缓存前先看看剩余空间；清理应用数据或卸载会把缓存一起清掉，重要章节重新缓存一次即可。

## 三、追更提醒怎么开

对收藏的作品，连载有新章节时应用会推送更新提醒。你需要保证两件事都成立：作品在**书架里是收藏状态**；系统层面**允许该应用发送通知**（设置 → 通知里打开）。通知被系统拦掉是提醒不弹的最常见原因，排查步骤见 [常见问题与故障排查.md](常见问题与故障排查.md)。

想把某部作品收进书架，见 [怎么搜索漫画与收藏书架.md](怎么搜索漫画与收藏书架.md)。
