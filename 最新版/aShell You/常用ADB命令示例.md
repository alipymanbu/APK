## 一、命令在哪里输、怎么执行

- 主界面就是命令行：输入一条命令，回车执行，输出直接显示在下方；
- 应用内置了**常用命令示例**，点开就能填进输入框，不用手打；
- 支持**连续输出**的命令（`logcat`、`top` 这类实时刷新的），输出区持续滚动，可随时在输出里搜索；
- 输出可以**保存为 txt** 或直接分享；
- 高频命令加进**书签**，下次一点就用。

注：内置命令示例的「增删改」是 v7.0.0 起加入的功能；本文对应的 v5.2.1 只能使用内置示例。

## 二、执行前先想清楚

命令是即时生效的，没有「撤销」按钮。官方 FAQ 也明确提醒：部分命令危害很大，后果需要你自己判断。拿不准的命令，先把参数查清再回车；对系统应用做改动前，先确认包名。

## 三、常用命令参考

下面都是 Android 通用的 ADB shell 命令，参数随系统版本略有差异，以 Android 官方文档为准：

| 你想做的事 | 命令 | 说明 |
| --- | --- | --- |
| 列出已装应用的包名 | `pm list packages` | 加关键词可过滤，如 `pm list packages \| grep todo` |
| 查看当前屏幕分辨率 | `wm size` | 配合 `wm size reset` 恢复默认 |
| 修改屏幕分辨率 | `wm size 1080x2400` | 数值改成你设备的目标值 |
| 查看或修改显示密度 | `wm density` / `wm density 420` | `wm density reset` 恢复 |
| 实时查看系统日志 | `logcat` | 连续输出，排查应用闪退时常用 |
| 读取一项系统设置 | `settings get global <名称>` | 名称先用 `settings list global` 查 |
| 修改一项系统设置 | `settings put global <名称> <值>` | 改错用对应 put 改回 |

预装应用的卸载属于高风险操作：包名认错、删了系统关键组件，可能要恢复出厂才能救回来。动手前把包名核对两遍；已经删了想救回来，见 [ADB卸载的应用怎么恢复](ADB卸载的应用怎么恢复.md)。

## 四、文件推送与提取

较新版本（v7.0.0 起）内置了基于 ADB push/pull 的文件管理器，可以在界面里直接推送（push）与提取（pull）文件。本文对应的 v5.2.1 还没有这个界面，需要搬文件时直接执行 `cp`、`mv` 一类的 shell 命令，效果等同。

本机之外还有两个入口：OTG 线连接，或同一网络下的无线 ADB，操作要点见 [OTG模式控制其他设备](OTG模式控制其他设备.md)。
