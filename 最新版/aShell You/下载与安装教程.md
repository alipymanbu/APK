## 一、这是个什么应用

aShell You 是一款开源的安卓 ADB shell 客户端：你在手机屏幕上直接输入 ADB 命令并立刻看到输出，不需要电脑。它由开发者 DP-Hridayan 维护，源码与发布都在 GitHub 仓库 [DP-Hridayan/aShellYou](https://github.com/DP-Hridayan/aShellYou)，许可证为 GPL-3.0。

你平时能用它做的事大致分三类：

- **本机执行**：在自己手机上跑 `pm`、`wm`、`logcat` 这类命令（需要先配好 [Shizuku](Shizuku配置教程.md) 或 root）；
- **OTG 控制**：用线把另一台安卓设备接到本机，对它执行命令；
- **无线控制**：对同一网络里开了无线调试的另一台设备执行命令。

每一类怎么操作，见本文的相关文档链接。顺带一提：它和 Termux 这类终端应用不是一回事，见 [和Termux有什么区别](和Termux有什么区别.md)。

## 二、先核对版本信息

搜索引擎给你的往往是官方最新版，而网盘里保存的是较早的一份。本文对应这份安装包的信息如下，**版本、包名、体积一律以它为准**：

| 项目 | 值 |
| --- | --- |
| 版本 | v5.2.1（2024-10-15 发布） |
| 包名 | `in.hridayan.ashell` |
| 大小 | 3.89 MB |
| MD5 | `566A7D6D088DE8E3BD56D3BD808F43C6` |
| 最低系统 | Android 8.0 |

aShell You 迭代很勤，官方仓库的版本号一直在往前走（整理本文时最新已到 v7.x），新版本对系统最低要求也可能上调。想用最新版就去 [Releases 页面](https://github.com/DP-Hridayan/aShellYou/releases/latest) 看；想用与本文对应的这一份，就走下面的安装步骤。

这份 v5.2.1 之后官方加了什么（均出自官方 [Releases 说明](https://github.com/DP-Hridayan/aShellYou/releases)）：

- v6.0.0（2025-03）：新增无线调试模式、应用内更新器；
- v7.0.0（2026-01）：界面重构，新增 ADB 文件管理器、二维码配对、设置与数据备份、自定义主题；
- v7.2.0：快捷设置磁贴、Google Drive 云备份（仅 GitHub 构建版提供）。

也就是说，网盘里这份 v5.2.1 **没有**文件管理器、二维码配对、备份这些能力；需要它们就得装更新版本。

## 三、官方获取渠道

官方 README 与官网只列了三个渠道：

| 渠道 | 地址 | 适合谁 |
| --- | --- | --- |
| GitHub Releases | [github.com/DP-Hridayan/aShellYou/releases](https://github.com/DP-Hridayan/aShellYou/releases) | 想挑任意历史版本 |
| F-Droid | [f-droid.org/packages/in.hridayan.ashell](https://f-droid.org/packages/in.hridayan.ashell) | 习惯用 F-Droid 客户端管理更新 |
| IzzyOnDroid | [apt.izzysoft.de/fdroid/index/apk/in.hridayan.ashell](https://apt.izzysoft.de/fdroid/index/apk/in.hridayan.ashell) | F-Droid 用户，拿到更新更快 |

应用商店里搜到的同名应用未必是这份开源项目，安装前认准包名 `in.hridayan.ashell`。

三个渠道拿到更新的速度也不一样：IzzyOnDroid 直接采用开发者发布的 APK，通常 24 小时内跟上；F-Droid 主仓库要自行编译，一般慢上几天（依据 IzzyOnDroid 官方 FAQ，截至整理本文时）。追新选 IzzyOnDroid 或 GitHub Releases；不急的话用哪个都可以。

## 四、安装步骤

如果你手上还没有安装包，可以从 [aShell You 安装文件资源（夸克网盘）](https://pan.quark.cn/s/60ba8c6c52c3) 取本文对应的 v5.2.1，然后：

1. 把 APK 下载到手机存储（网盘 App 内直接下载即可）；
2. 点开 APK，系统提示「禁止安装未知应用」时，允许对应来源安装；
3. 装完打开，首次启动会请求若干运行权限，按需允许。

不放心文件是否完整，可以核对 MD5：手机上用带校验功能的文件管理器，或把文件传到电脑后执行：

```powershell
Get-FileHash .\aShellYou.apk -Algorithm MD5
```

结果与第二节表格里的 MD5 一致，说明文件在传输中没有损坏。

## 五、装完第一件事

aShell You 打开后并不能立刻执行命令——它需要一条「以 shell 级权限运行」的通道，最常见的做法是配 Shizuku。装好 Shizuku 并完成授权后再回来，就能直接输命令了，具体步骤见 [Shizuku配置教程](Shizuku配置教程.md)。
