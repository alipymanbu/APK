# SubCat（字幕猫）字幕不显示与播放失败排查

> 本篇按现象排查 SubCat（字幕猫）最常见的四类故障：字幕不出字、网络视频打不开、字幕显示不合适、网址播放总失败。每条都给出先查什么、再做什么。

## 一、先对号入座

| 现象 | 大概率原因 | 先做什么 |
| --- | --- | --- |
| 视频能播、字幕一直不出 | 没登录 / 积分不够 / 目标语言没设 | 按第二节顺序查 |
| 网络视频打不开或一直缓冲 | 链接失效、来源限速 | 按第三节处理 |
| 字幕太小、挡画面、想要原文对照 | 字幕设置没调 | 按第四节调 |
| 粘贴的网址播不了 | 那不是可播放的直链 | 按第五节换路子 |

## 二、字幕不出字的排查顺序

按这个顺序查，通常一两步就能定位：

1. **登录了吗**——翻译功能要先登录，手机号验证码登录见 [注册登录与积分获取.md](注册登录与积分获取.md)；
2. **积分或会员**——免费用户积分不足时翻译不会开始，先看广告攒积分或开会员；
3. **目标语言**——设置 →「翻译字幕目标语言」是否已选好；
4. **网络**——实时识别与翻译全程要联网，断网或网络差时字幕出不来；
5. **版本**——官方在 2.2.187 的更新说明里写了「网络视频字幕缓冲时间减少」「解决字幕缓冲不够的问题」，旧版本遇到缓冲类问题先升级。

## 三、网络视频打不开或一直缓冲

- **链接会过期**：从视频源复制来的播放地址可能带时效，过期就失效——重新取一次新链接再试；
- **来源限速**：视频来源的下载速度慢，字幕缓冲就跟不上画面——最直接的办法是把视频下载到手机，走「文件视频」或「相册视频」播放，这也是官方 FAQ 给出的解法；
- **115 网页版**：播放异常的问题在 2.2.187 更新里标注已修复，还在旧版本的先升级。

## 四、字幕显示调整

| 想要的效果 | 去哪调 |
| --- | --- |
| 原文和译文同屏对照 | 设置 → 开「显示原文字幕」 |
| 暂时关字幕看原片 | 设置 → 关「显示字幕」 |
| 字太大或太小 | 设置 →「字幕大小」 |
| 字幕里语气词太多 | 2.2.187 新增了语气词过滤功能，升级后留意设置里的相关开关 |

## 五、网址播放总失败

不是所有网页链接都能直接播——「播放网址」入口要的是**可解析的视频直链**（http 地址）。页面里的普通网址、需要登录态才能看的链接，通常播不了。

稳的做法是改走本地：

1. 用该视频平台的官方下载功能，把视频存进手机相册或文件；
2. 回到 SubCat，用「相册视频」或「文件视频」导入；
3. 本地播放不依赖网络来源，字幕缓冲也更稳。

如果 [实时字幕翻译使用步骤.md](实时字幕翻译使用步骤.md) 里的流程都走对了还是不行，可以从 [下载与安装教程.md](下载与安装教程.md) 的渠道重装当前版本（2.2.187）再试。

## 六、都解决不了时找官方

官方给出的反馈通道有三条：

1. **App 内反馈功能**——官方介绍里写明的反馈入口，问题截图直接发过去；
2. **官网支持页**——[sdaigc.com](https://sdaigc.com/) 的「SubCat 在线支持和建议」页，有微信反馈交流群的入口；
3. **iOS 端的订阅与会员问题**——同时走 App Store 的账号渠道：订阅管理、恢复购买、退款申请都在系统订阅设置里，会员没生效的处理见 [会员订阅档位说明.md](会员订阅档位说明.md) 的「找回」一节。
