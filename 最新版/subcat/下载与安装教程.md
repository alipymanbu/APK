## 一、安装前先确认三件事

| 事项 | 说明 |
| --- | --- |
| 设备 | SubCat 是装在手机/平板上的视频播放器，官方同时上架了安卓与 iOS 两端。本篇讲安卓 APK 的安装；iPhone、iPad 直接在 App Store 搜「SubCat」安装 |
| 安装包体积 | 本篇对应的安卓版本为 2.2.187，安装包 296.25M。下载和安装都要占空间，建议给安装过程再留出一倍余量 |
| 系统版本 | 安装包适配信息为安卓 5.2 以上；安装器若提示不兼容，以应用商店页面标注的系统要求为准 |

## 二、安卓安装包的三个来源

| 来源 | 适合谁 | 注意 |
| --- | --- | --- |
| 手机应用商店 | 大多数人 | 官方已上架华为、小米、荣耀、OPPO、vivo 等商店，搜「SubCat」或「字幕猫」。其中小米商店页面当前显示「维护中」，能否正常下载以页面实际状态为准 |

如果你想固定用 2.2.187 这一版，直接用本篇顶部的 [SubCat 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e0b6c8e3d3ab)：先转存到自己的网盘，再把 APK 下载到手机，走下面第三节的 APK 安装步骤。

## 三、两条安装路径

### 走应用商店

1. 打开手机自带的应用商店，搜索「SubCat」或「字幕猫」；
2. 进入应用详情页，点安装；
3. 安装包近 300M，建议在 Wi-Fi 下等它下完，装完桌面会出现应用图标。

### 走 APK 文件

1. 从上面的网盘资源把 APK 下载到手机存储；
2. 在文件管理器里点开这个 APK；
3. 系统提示「未知来源应用」时，允许本次安装（不同品牌手机的入口名称略有差别，一般在设置的安全或隐私页里）；
4. 需要核对安装包的话，2.2.187 版 APK 的 MD5 为 `7BA46ED404E947342D49D04D04A63AA0`，可用校验工具比对；
5. 装完打开，按下一步骤走首启设置。

## 四、第一次打开会要哪些权限

按官方应用商店公示的权限清单，SubCat 会申请下面这些。不给哪个、影响什么，对照这张表：

| 权限 | 用在什么场景 |
| --- | --- |
| 网络访问 / 查看网络状态 | 实时识别与翻译全程要联网，不给网络权限字幕出不来 |
| 读取视频与文件 | 「文件视频」「相册视频」两个入口靠它才能扫到你手机里的视频 |
| 写入文件与文档 | 保存转录结果、导出的字幕文件 |
| 通知 / 前台服务 | 播放和后台处理时保持任务不被系统杀掉 |
| 防止休眠 | 看片过程中屏幕不会被中途锁掉 |
