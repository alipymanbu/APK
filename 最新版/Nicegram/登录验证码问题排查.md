## 一、先弄清验证码的送达机制

Nicegram 登录走的是 Telegram 的验证流程，验证码的送达顺序是固定的：

1. **优先发到你已登录 Telegram 的其他设备**——官方客户端的「Telegram」服务对话里会出现一条登录验证码消息，这条最可靠；
2. 该账号没有其他在线设备时，才发**短信**到你的手机号。

所以第一动作不是等短信，而是：打开你手机或电脑上还登着的官方 Telegram 客户端，翻「Telegram」官方对话，验证码多半已经在那里。

## 二、短信收不到的常见原因与对应动作

| 现象 | 原因 | 动作 |
| --- | --- | --- |
| 短信一直不来 | 验证码实际发到了别的已登录设备 | 去官方客户端的服务对话里找（见上节） |
| 号码格式不对 | 没用国际格式 | 国家区号要选对，号码前不带本地长途前缀，例如中国大陆号选 +86 后填纯手机号 |
| 运营商拦截 | 境外服务发的短信被手机或运营商当垃圾短信过滤（多地用户反馈这是最常见的拦截点） | 检查手机的骚扰拦截/垃圾短信文件夹；问运营商有无国际短信拦截开关 |
| 短时间反复请求 | 连续点「发送验证码」触发频控 | 隔几分钟再试，不要连续刷 |
| 网络不稳 | 请求本身没发出去 | 换 Wi-Fi/流量再试；重启应用 |

## 三、绕开短信的三条路

按可行性排序：

1. **用其他已登录设备接码**：任何一台还登着这个 Telegram 账号的设备（手机、电脑）都能收到验证码，这是零成本的路；
2. **用 Nicegram 的账号备份文件迁移**：如果旧手机上还装着 Nicegram（或官方 Telegram），可以先不做全新登录——在旧设备上用 Settings → Nicegram → Accounts → Export as File 导出会话文件，新设备 Import from File 导入，完全跳过验证码环节。操作细节见 [多账号与账号备份.md](多账号与账号备份.md)；
3. **付费语音验证**：登录页在短信多次无法送达时会出现付费验证选项（走电话报码）。有用户反馈这条路最终能登录成功，但是 Telegram 侧的收费项目，价格与是否出现以登录页当时显示为准，不是 Nicegram 的收费。

## 四、登录成功后先做两件事，下次不再卡验证码

- **绑定恢复邮箱 + 设置两步验证密码**：在官方 Telegram 客户端里设置（Settings → Privacy and Security → Two-Step Verification）。之后在新设备登录时除了验证码还要输这份密码，账号也更安全；
- **导出一份 Nicegram 会话备份文件**存好：换机、重装时直接导入，不用再走一遍验证码（文件等于登录凭证，放私密位置）。

## 五、什么时候该怀疑不是验证码的问题

- 输入验证码后提示错误：确认没有过期（验证码有时效，过期要重新获取），且没有把旧码重复使用；
- 登录成功但一直加载不出聊天：这已经不是验证码问题，是网络无法连通 Telegram 服务，见 [下载与安装教程.md](下载与安装教程.md) 的常见原因一节；
- 账号被风控提示无法登录：只能通过官方 Telegram 的申诉渠道处理，Nicegram 作为客户端帮不上。
