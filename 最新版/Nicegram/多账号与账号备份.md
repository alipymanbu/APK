## 一、无限多账号：和官方客户端的差别

官方 Telegram 客户端最多同时登录 3 个账号；Nicegram 把这个上限放开，可以添加几十个账号，切换时不用退出再登录。每个账号的数据仍由 Telegram 云端保存，Nicegram 只是多开了几个登录会话。

添加账号的入口：Settings（设置）→ Add Account（添加账号），输入另一个 Telegram 手机号并完成验证码验证即可。切换账号在侧边栏账号列表里完成。

适合的场景：把私人号、工作号、频道管理员号分开管理；需要同时在线的多个号不必在两台手机之间倒腾。

## 二、账号备份与恢复（Android 端只有文件导出一种）

Nicegram 支持把「登录会话」导出成文件，换机或重装后导入，免去每个号重新收验证码。注意两端平台的能力不同：

| 平台 | 备份方式 |
| --- | --- |
| iOS | iCloud 自动备份，或导出文件 |
| Android | 只有导出文件一种（没有云备份选项） |

Android 上的操作路径：

1. 导出：Settings → Nicegram → Accounts → Export as File，在手机上生成一个备份文件，你可以把它存到任何地方（网盘、电脑、传输工具都行）；
2. 恢复：在另一台设备装好 Nicegram 后，进 Settings → Nicegram → Accounts → Import from File，选中之前导出的文件，会话即恢复。

两点提醒：

- 备份文件等于账号的登录凭证，**谁拿到文件谁能登录你的号**，别放进公开分享的链接里；
- 建议至少存在一个稳定的位置（比如自己的网盘私密目录），换机时才找得到。

同一个入口里还有 Delete Sessions（删除会话），用来把已废弃设备的登录记录清掉。

顺带一提：备份文件导入也是「登录时收不到验证码」的最稳绕行路——旧设备上还有会话就能导出，新设备直接导入，不用碰短信。排查思路见 [登录验证码问题排查.md](登录验证码问题排查.md)。

## 三、Double Bottom：用两份密码切换两种界面

Double Bottom 是 Nicegram 的账号隐藏功能：给应用设两份密码，输入 A 密码只看到「主账号」，输入 B 密码才看到全部账号。它免费、不需要订阅 Premium。

前提条件：

1. 至少有 2 个 Telegram 账号；
2. 已开启 Telegram 的 Passcode Lock（密码锁）。

设置步骤：

1. 开密码锁：Settings → Privacy and Security → Passcode Lock → 启用并设置第一份密码；
2. 开 Double Bottom：Settings → Nicegram → Double Bottom → 打开开关，设置第二份密码；
3. 两份密码必须不同，这是切换界面的依据。

之后的日常用法：

- 开应用后输入**第二份密码**（Double Bottom 密码）→ 只显示你选定的那个主账号，其余账号和开关本身都被藏起来；
- 输入**第一份密码**（Telegram 密码锁）→ 显示全部账号。

也可以在聊天列表顶部点锁形图标随时切换。忘了第二份密码的处理方式：进 Settings → Nicegram → Double Bottom 关掉再重开，重新设一份新的。

注意：这是界面层面的隐藏，不是给聊天内容再加一层加密，消息本身仍然由 Telegram 的加密体系保管。

## 四、常见疑问

- 每个账号都要单独验证吗：是，每个手机号各走一遍验证码流程；之后用备份文件迁移就不用再收码；
- 多账号会互相串消息吗：不会，每个账号是独立的登录会话，通知也按账号区分；
- 一个账号能在官方客户端和 Nicegram 同时登录吗：能，Telegram 支持多客户端并存，Settings → Devices 里都能看到对方；
- 挂很多账号有什么代价：设备性能与 Telegram 自身的会话限制会影响实际可用数量，几十个号在低端机上切换会明显变卡。

账号都挂好之后，内置 AI 助手的用法见 [AI助手功能说明.md](AI助手功能说明.md)。
