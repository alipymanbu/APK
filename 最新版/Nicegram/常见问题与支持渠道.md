## 一、它和官方 Telegram 是什么关系

Nicegram 是独立开发者 Appvillis 出品的第三方客户端，基于 Telegram 的公开 API 构建，与 Telegram 官方没有任何隶属关系。含义拆开说：

- 账号、消息、云端存储全部还是 Telegram 的——你登录的是自己的 Telegram 账号，没有「Nicegram 账号」这一说；
- 换客户端不丢数据，聊天记录在 Telegram 云端，官方客户端和 Nicegram 可以并存并用同一个账号；
- 功能兼容性靠它自己跟进 Telegram 的版本更新，官方客户端上新功能后，第三方客户端通常会晚一段时间才支持。

## 二、用它登录，账号会不会被封

第三方客户端使用 Telegram 官方开放的 API 接口，登录行为本身是 Telegram 允许的。但和所有第三方客户端一样，最终的账号风控权在 Telegram 手里。稳妥的用法：从官方渠道拿安装包（见 [下载与安装教程.md](下载与安装教程.md)）、不在来路不明的修改版上登录你的主号。

## 三、内置钱包的钱包密钥归谁

Nicegram 内置了非托管的 Web3 钱包，支持 TON、BNB Smart Chain、Solana、Ethereum、Base 等多条链。密钥机制是账户抽象的 2/3 确认：你的 Telegram 账号 + 你设置的钱包密码 + 设备上的应用安装，三者有其二才能动钱。这意味着：

- 换手机后，只要 Telegram 账号还在、钱包密码还记得，就能恢复钱包访问；
- 三个凭证丢掉两个，钱就找不回来——钱包密码务必自己记牢，没有「忘记密码」可点。

链上操作产生的费用与风险由你自担，这部分属于加密资产操作，与聊天功能无关，不想用完全可以不碰。

## 四、敏感内容显示开关

官方 Telegram 在部分地区默认隐藏标记为敏感的频道与媒体，Nicegram 提供了对你自己账号的显示开关。官方的开通指引在 `https://my.nicegram.app`，按页面提示操作即可。这只影响你自己设备上的显示范围，不涉及任何内容修改。

## 五、收费与订阅

- 客户端本体免费，多账号、Double Bottom、快捷回复等常用功能不收费；
- Premium（订阅或应用内购买）覆盖完整版内置翻译、AI 完整额度、Mention All 等；
- AI 按量计费走 AI Tokens（旧称 Gems），换算与用法见 [AI助手功能说明.md](AI助手功能说明.md)。

价格与权益范围会调整，以应用内购买页当时的显示为准。

## 六、出问题了去哪找

| 事项 | 渠道 |
| --- | --- |
| 官方网站与功能介绍 | `https://nicegram.app`（新域名 `https://nicegram.me`） |
| 官方 Wiki / 使用文档 | `https://wiki.nicegram.app` |
| 反馈问题 | Telegram 联系 `@nicegram_support_manager`，或邮件 support@nicegram.app |
| 源代码 | `https://github.com/Nicegram`（Android 端 Releases 同时提供 APK） |
| 官方频道 / 群组 | 频道 `@nicegramapp`，英文交流群 `@nicegramchat` |

报问题时带上三样信息能少一轮来回：设备型号、系统版本、Nicegram 的版本号（设置里能看到）。

## 七、两个高频小问题

- **验证码收不到**：验证码优先发到你已登录的官方 Telegram 客户端里，先去那里翻消息，再看短信，详见 [下载与安装教程.md](下载与安装教程.md)；
- **换手机怎么迁账号**：Android 端用 Settings → Nicegram → Accounts 的文件导出/导入，完整步骤见 [多账号与账号备份.md](多账号与账号备份.md)。
