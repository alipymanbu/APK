# Nicegram 通知与稳定性排查

> 这篇处理两个最常见的使用故障：应用退到后台后收不到新消息通知，以及打开或使用中崩溃、卡顿。先讲安卓通知被系统拦下的原因，再讲崩溃的排查顺序。

## 一、收不到通知：九成是系统省电策略拦的

安卓手机为了省电，会限制后台应用联网与唤醒。消息型应用被系统杀掉后台后，通知自然不响。应用内通常没有专门的「通知开关」要调，重点在系统设置一侧：

1. **允许通知**：系统设置 → 应用 → Nicegram → 通知，确认总开关与各渠道开关都开着；
2. **关闭电池优化**：系统设置 → 应用 → Nicegram → 电池，从「优化/受限」改为「无限制/不优化」（国产系统里常叫「允许后台运行」「允许自启动」）；
3. **加锁后台**：部分系统在最近任务卡片上下拉或长按可以「锁定」，防止一键清理时被杀；
4. **保持 Telegram 服务可达**：通知依赖与 Telegram 服务器的长连接，网络断掉时通知先于消息失联——通知突然全停时先确认网络。

多账号用户注意：每个账号的通知在应用内按账号区分，怀疑「某个号没通知」时，先切到那个账号确认应用内通知设置，再查系统侧。

## 二、崩溃与卡顿：按这个顺序排查

| 顺序 | 动作 | 说明 |
| --- | --- | --- |
| 1 | 重启应用 | 从最近任务里彻底划掉再打开，能清掉大部分临时故障 |
| 2 | 更新版本 | 旧版对 Telegram 协议跟进不及时会出现打不开聊天、发不出消息等问题，去你拿安装包的渠道取新版 |
| 3 | 重启手机 | 系统层的资源异常只有重启能清 |
| 4 | 清理应用缓存 | 系统设置 → 应用 → Nicegram → 存储 → 清除缓存。清缓存不删聊天记录（记录在 Telegram 云端） |
| 5 | 卸载重装 | 最后手段；重装后用备份文件导入账号，免收验证码（见 [多账号与账号备份.md](多账号与账号备份.md)） |

## 三、用户反馈里出现过的稳定性问题

汇总自公开应用评论区的用户反馈（个例，未必人人遇到，供对照）：

- 大版本更新后一段时间内崩溃、白屏或掉通知较集中，等下一个版本或先退回旧版是用户常做的选择；
- 挂的账号特别多时，低端机上切换与加载明显变慢——账号数量控制在日常真正需要的范围；
- 个别用户反馈过加频道报错、发送消息失败，多见于版本刚发布阶段，随更新修复。

遇到上面这些情况，先按第二节顺序排查；仍不能解决，带着设备型号、系统版本、Nicegram 版本号去官方支持渠道反馈（联系方式见 [常见问题与支持渠道.md](常见问题与支持渠道.md)）。

## 四、重装前的一个提醒

重装不影响云端聊天记录，但会丢掉本地的登录会话。如果你挂着多个账号、又没导出过备份文件，重装意味着每个号重新走一遍验证码——先看 [登录验证码问题排查.md](登录验证码问题排查.md) 准备好接码路径，再动手重装。
