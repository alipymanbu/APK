## 一、注册流程：填完不等于能用

和大多数应用不同，HiWear 的账号注册要过一道**人工审批**，这是它区别于普通资源站的地方。步骤：

1. 打开应用，点**左上角的三横线菜单**。
2. 在菜单里选**注册**。
3. 按表单填写相关信息，点注册提交。
4. **等待管理员审批**，通过后账号才算注册成功。
5. 审批通过后再登录，就能进各板块发帖、回帖、进资源区下载了。

审批要多久没有公开的标准，提交后等通知即可；如果长时间没动静，可以换个时间段再登录看看状态，或参考[常见问题与推送排查](常见问题与推送排查.md)里的处理思路。

## 二、板块一览：每个区干什么用

社区按话题分了几个板块，发帖前先选对地方，求助才有人理：

| 板块 | 适合发什么 |
| --- | --- |
| 闲聊灌水 | 手表相关的日常闲聊，不限于具体问题 |
| 深水区 | 更深入的讨论区 |
| 互求互助 | 找资源、求帮助的主阵地：常见的求助有求改 dpi、找某个下不到的应用、求特定表盘 |
| 技巧教程 | 用户自己写的玩法教程、经验分享 |
| 基础玩法 | 入门向内容，新手从这里看起 |

新用户比较实际的路线：先去**基础玩法**和**技巧教程**把别人的帖子过一遍——你遇到的问题（表盘格式、推送失败、参数设置）大概率已经有人写过；实在没有再到**互求互助**发帖说明需求，等其他用户帮你。

## 三、发帖与互动

- 可以发帖、回帖、求资源、分享自己写的教程和评测。
- 支持打赏、发红包这类互动形式——别人帮了你忙，用这种方式回礼。
- 资源区里其他用户分享的表盘、手表应用、固件等资源可以自由下载使用。

## 四、审批等待期间可以先做的事

审批结果不归你控制，但下面这些可以先准备好，通过之后直接开工：

- 确认手机和手表的蓝牙连接正常——后面推表盘全靠这条路。
- 把想要的表盘风格、要找的资源先想好，进社区后先搜再问。
- 安装或连接还没弄顺的，回[下载与安装教程](下载与安装教程.md)补一遍；表盘操作提前看[表盘更换与自制教程](表盘更换与自制教程.md)。
