## 一、先确认你要装的是什么

HiWear 装在**手机**上，不在手表里。它是一个面向智能手表用户的社区应用：表盘壁纸、手表端小工具等资源在这里分享与下载，你选中后由手机推送到手表；另外还有闲聊、互助、教程等讨论板块。渠道介绍称全程无广告——这类说法听听即可，装上自己感受。

安装前先排除两个容易混的同名事物：

| 名称 | 是什么 | 和本篇的关系 |
| --- | --- | --- |
| **HiWear**（包名 `com.hiwear.beta`） | 手表资源社区平台，本文主角 | 就是你要装的 |
| Hiwear Plus（包名 `com.myled.HiwearPlus`） | 某些手环/手表的蓝牙配套应用，管来电短信推送、运动数据 | 不是同一个软件，别装错 |
| 华为开发者平台里的 "HiWear" | 华为 Wear Engine 的 API 入口，面向开发者 | 普通用户碰不到 |

认准包名 `com.hiwear.beta` 就不会错。

## 二、安装包从哪拿

主流应用市场里没有找到它的稳定上架页，网上下载站的版本也参差不齐。比较省心的做法是从网盘转存一份离线安装包，[HiWear 安装文件资源（夸克网盘）](https://pan.quark.cn/s/18801e98eaf6)里是 1.1.6 版（3.40 MB，2026-09 收集），转存到自己网盘后下载到手机就能装。

安装包这么小（约 3.4 MB）是正常的——它主要承担资源浏览与推送，表盘素材本身是联网按需取的，不打包在安装包里。

## 三、系统要求

- 手机端：安卓系统。各渠道标注的最低版本不一致（有标 5.x 的也有标 6.0 的），以你安装时系统给出的实际提示为准。
- 手表端：资源推送那部分功能需要一块能连上的智能手表。渠道介绍称覆盖二十余款主流型号、兼容 Wear OS 等系统，实际能不能识别以应用内检测结果为准（详见[常见问题与推送排查](常见问题与推送排查.md)）。

## 四、安装步骤

1. 从网盘把 APK 文件下载到手机存储里。
2. 在手机文件管理器里点开这个 APK。首次安装会提示「禁止安装未知来源应用」，按提示允许你的文件管理器（或浏览器）安装应用即可；装完建议把这个允许再关回去。
3. 等安装完成，点打开。

两个可选动作：

- **核对完整性**：如果你在意包有没有被调换过，可以核对 MD5。1.1.6 版的 MD5 是 `4D95E509637F86F8C1377928DDABF0C7`，用文件管理器的属性页或校验工具比对即可。
- **包名带 `beta` 是什么意思**：说明这版走的是测试通道，功能可能比正式版多也可能有小毛病，遇到奇怪问题先重启应用再说。

## 五、装完之后

第一次打开主要是熟悉界面。发帖、参与社区交流这类功能要等注册审批通过才能用（注册要等管理员审批，流程见[注册与社区板块指南](注册与社区板块指南.md)）；浏览和账号权限的具体边界，以应用内的实际表现为准。

想换表盘的，注册通过后看[表盘更换与自制教程](表盘更换与自制教程.md)；推送不上的问题都在[常见问题与推送排查](常见问题与推送排查.md)里。
