## 一、先分清两种形态

Swift Backup 在无 Root 与 Root 设备上能力差别很大，动手备份前先对照下表认清自己属于哪一种：

| 数据类型 | 无 Root | Root |
| --- | --- | --- |
| 应用（APK） | 可以（批量还原需 Shizuku） | 可以 |
| 短信 | 可以 | 可以 |
| 通话记录 | 可以 | 可以 |
| 已应用的壁纸 | 可以 | 可以 |
| 外部数据（Android/data/） | Android 10 及以下可以；11+ 需 Shizuku | 可以 |
| 应用私有数据（/data/data/） | 不行 | 可以 |
| 特殊应用数据（权限、电池优化设置等） | 不行 | 可以 |
| WiFi 网络配置 | 5.1.0 起 Android 11+ 可经 Shizuku | 可以 |

## 二、所有设备都能备份的内容

- **应用（APK）**：备份对象是安装在 /data/app/ 下的 base.apk 以及按语言、设备、功能拆分的分裂包（split APK），不是从商店拉清单；
- **短信**：系统短信库里的收发记录；
- **通话记录**；
- **已应用的壁纸**：备份的是你当时设置上的壁纸，还原时会重新应用；
- **文件夹**（5.1.0 新增）：对设备本地或云存储里的整个文件夹做备份与还原。

## 三、Root 之后多出来的三项

- **应用数据**：应用在 /data/data/ 里的私有数据（登录状态、账号进度、本地设置）。官方 FAQ 的说法是「把大部分应用还原到备份时的状态」；Shizuku/ADB 模式够不到这个目录，只有 Root 能备能还；
- **特殊应用数据**：已授予的运行权限、电池优化设置、应用的 SSAID、Magisk Hide 状态等；
- **WiFi 网络配置**：连过的 WiFi 与密码；5.1.0 起 Android 11+ 上经 Shizuku 也能备份还原，不必 Root。

无 Root 想备份应用私有数据没有绕开的办法。官方 FAQ 的答复是：任何应用都无法在无 Root 时读取另一个应用的私有数据，能替代的只有设备自带的备份功能，或 Google 的云备份（要求设备有 Google Play 服务）。

## 四、云端存储清单

应用内置支持这些云端存储（按官方说明整理，以应用内实际显示为准）：

| 云存储 | 备注 |
| --- | --- |
| Google Drive | 只能用登录账号对应的那份 Drive |
| Dropbox / OneDrive / Box | 通用网盘 |
| Mega.nz | 5.1.0 改进了支持 |
| pCloud / Yandex | 通用网盘 |
| Filen | 5.1.0 新增 |
| WebDAV | Nextcloud、ownCloud、群晖 NAS 等自建服务 |
| S3 | Amazon S3 或任何 S3 兼容存储 |
| SMB / SFTP / FTP | 局域网 NAS 与自建服务器常用 |
| CloudMail.Ru | 需要对方服务的付费套餐 |

「应用的云备份」在官方功能表里列在 Premium（应用内购解锁）之下，并且云备份与全部 Premium 功能都要求 Google 登录后才可用。

## 五、云备份的账号规则（容易踩坑）

1. 云备份和全部 Premium 功能都要求 Google 登录；没有 Google Play 服务的设备支持浏览器方式登录；
2. 备份文件与登录的 Google 账号绑定：只能用登录账号对应的那份 Google Drive，换账号读不到之前的云备份；
3. 匿名（离线）模式与 Google 登录模式互不通用，两种模式下的备份不能混用，选错就得重备；
4. Premium 资格跟购买账号走：换了登录账号，只要购买的那个 Google 账号在这台设备的 Play 商店上登录着，Premium 仍然生效。

## 六、本地备份放哪

备份存放在固定的标准位置：本地是内部存储里的 SwiftBackup 文件夹，云端在各个服务上也用统一位置。官方 FAQ 明确表示不支持自定义任意文件夹、也没有相关计划；但可以把 SwiftBackup 文件夹的位置从内部存储整体切换到 SD 卡或 U 盘（见 FAQ 的「SD 卡与 USB 存储」条目）：[www.swiftapps.org/faq](https://www.swiftapps.org/faq)。清机或刷机前记得把本地备份按原结构复制出来，操作见 [换机还原与数据迁移.md](换机还原与数据迁移.md)；放回去读不到时，先看 [读不到备份与还原失败排查.md](读不到备份与还原失败排查.md)。
