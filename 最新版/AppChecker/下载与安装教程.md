AppChecker 是一款跑在手机上的 Android 应用信息查看工具：装好之后，你能看到每个已安装应用的目标 API 级别、版本、包名、权限、组件与原生库，也能查看设备的 CPU、内存、屏幕和 DRM 状态。本篇只解决「装」这一步 —— 装在哪、怎么装、装完给哪些权限。

## 一、先确认装在哪类设备上

AppChecker 是 Android 手机应用，装在**你要检查的那台手机本身**上，不需要 Root，也不需要电脑配合。

| 设备 | 能不能装 | 说明 |
| --- | --- | --- |
| Android 手机 / 平板 | 可以 | 主要使用场景；它读的就是本机已安装应用的信息 |
| 安卓平板、Android 掌机等安卓设备 | 可以 | 只要系统版本达标，界面按横屏 / 大屏适配情况以实际显示为准 |
| iPhone / iPad | 不行 | 没有 iOS 版本 |
| Windows / macOS | 不行 | 电脑上要跑只能借第三方模拟器，不属于官方支持的用法 |

它检查的是「本机」，所以想查哪台手机的应用情况，就装在哪台手机上。

## 二、系统门槛

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 最低系统版本 | Android 5.0 及以上 | 版本迭代会调整，装前以应用商店页面当时标注的「需要 Android 版本」为准 |
| Root | 不需要 | 它读取的是系统本来就允许普通应用访问的信息 |
| 网络 | 非必需 | 查看本机应用与设备信息不需要联网；打开应用商店页或广告位时才用到网络 |
| 存储 | 很小 | 这份安装包不到 9 MB，见下面第五节的版本信息 |

如果你要确认自己手机的 Android 版本，进「设置 → 关于手机 → Android 版本」看一眼即可。

## 三、安装步骤

1. 打开上面的 **[AppChecker 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f539e764b2c6)**，把这个 APK 转存到自己网盘或直接下载到手机本地存储。
2. 在手机上点开下载好的 APK 文件。系统弹出「禁止安装未知应用」时，在弹窗里给**当前打开 APK 的那个应用**（文件管理器或浏览器）打开「允许安装未知应用」权限，再返回重装。
3. 按提示完成安装，装完可以从桌面图标进入。

给「打开 APK 的那个应用」授权、而不是给 AppChecker 授权，是这一步最容易搞错的地方 —— 装在后面的应用还没有权限可言。

## 四、装完第一次打开要做什么

AppChecker 要列出你手机里装了哪些应用，就得拿到系统的应用列表访问权限，这一步决定了它有没有内容可显示：

1. 首次启动时，按提示允许它读取已安装应用列表。Android 11 及以上，系统还会按「包可见性」策略限制一个应用能看到多少别的应用，AppChecker 需要在授权范围内被允许查询，才能把列表列全。
2. Android 6.0 及以上，如果列表是空的或只显示一部分，先去「设置 → 应用 → AppChecker → 权限」里确认应用列表权限是开着的。
3. 剩下没有额外要求：不需要登录账号，不需要 Root，也不需要开无障碍之类的特殊权限。

列表里看不到某个应用、或只看到一部分，属于另一类问题，按 [常见问题与排查.md](常见问题与排查.md) 里的顺序排查。

文档里凡涉及版本号、包名、体积，都以这份包为准（网上能搜到的通常是官方最新版，和这里的不是同一个）：

| 项目 | 值 |
| --- | --- |
| 应用版本 | 4.1.1 |

| 安装包大小 | 8.33M |

包名是认版本最可靠的一条：网上叫 AppChecker 的应用不止一个，装完进「设置 → 应用」看一眼包名是不是 `com.kroegerama.appchecker`，就能确认装的是这家的版本。想把文件核对一遍的话，在电脑上用任意 MD5 校验工具对 APK 算一次，与上表逐位比对即可。

## 六、装不上的几种情况

| 现象 | 原因方向 | 处理 |
| --- | --- | --- |
| 提示「解析软件包时出现问题」 | 文件没下完 / 传输中断 | 重新转存下载，并按上面表格核对 MD5 |
| 反复提示「禁止安装未知应用」 | 授权给了错误的对象 | 在弹窗入口给打开 APK 的那个应用授权，而不是给 AppChecker |
| 装完打开就退出 | 系统版本低于这份包的门槛 | 确认系统版本，必要时换更新版本的系统或设备 |
| 装完列表空白 | 应用列表权限没给 | 去系统设置里补上权限 |

装完能用起来之后，下一步通常是看懂列表里的信息，可以从 [怎么看应用适配到哪个安卓版本.md](怎么看应用适配到哪个安卓版本.md) 和 [怎么看应用是32位还是64位.md](怎么看应用是32位还是64位.md) 接着读。
