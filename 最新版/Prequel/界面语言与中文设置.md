# Prequel 界面语言与中文设置

> 本篇解决「进去全是英文」这个问题：给出应用内和设备设置两条切换路径，以及切完不生效、找不到语言选项时的处理办法。

## 一、默认是跟随系统的，不是应用里默认英文

Prequel 的界面语言默认取手机系统语言。中文系统进去却是英文，一般有三种情况：系统语言被设成了英文、系统用的是繁体中文而应用未覆盖该分支、或者之前手动改过应用级语言。先确认系统语言，再决定用下面哪条路径改。

顺带说一句：官方在应用商店页面把中文（ZH）列进了支持语言，那一页同时标注支持十余种语言，官方的帮助中心也有简体中文版本（`support.prequel.app` 上可切换语言）。也就是说中文界面本来就提供，进去是英文属于设置问题，不是这个版本没做中文。

## 二、路径 A：在应用内切换

1. 打开 Prequel，进到底部导航最右侧的个人页（头像图标）。
2. 点右上角的菜单图标（三条横线）。
3. 在菜单里找到语言相关的条目，点进去。
4. 从列表里选「简体中文」。

> [!NOTE]
> 不同版本里这个入口的位置和名称会略有出入：有的版本把语言放在「设置」下面的二级页面，菜单里的条目顺序也不完全一样。**如果当前界面是你看不懂的语言，就按位置找**：个人页右上角的菜单图标是固定的，进去后依次点开各条目，能打勾选中「中文 / Chinese / 简体中文」的那一项就是。

## 三、路径 B：从手机系统设置里改（应用内找不到时用这条）

这条路走的是系统给每个应用单独设语言的开关，安卓各品牌位置不同，常见的两条：

- **原生与类原生系统**：设置 → 应用 → 找到 Prequel → 语言 → 选中文。
- **国产定制系统**：设置 → 应用管理 → Prequel → 语言与地区（部分机型在「更多设置」里）。

改完之后按提示重启应用；如果列表里没有中文，先看下面第四节。

## 四、语言列表里没有中文 / 改了不生效

按顺序试：

1. **系统里补一个首选语言**：设置 → 系统 → 语言和输入法 → 语言，把「简体中文」加进首选语言列表，再回应用里看语言选项是否出现。
2. **强制关闭应用再开**：从最近任务里把 Prequel 划掉，重新启动。改语言后不重启，界面有时还是旧的文案。
3. **清一次缓存**：语言资源是随应用一起缓存的，缓存损坏时切换不生效。清除缓存的步骤见 [常见问题与排查.md](常见问题与排查.md)，注意选「清除缓存」而不是「清除数据」。
4. **确认版本**：较早的版本对中文的覆盖不完整，个别页面残留英文属于正常，不必反复切换。

## 五、几个容易被误解的地方

| 你看到的 | 实际情况 |
| --- | --- |
| 界面已经中文，但部分效果名称仍是英文 | 效果、模板的名字多为品牌化命名（如 D3D、Y2K 这类风格名），本身不翻译，不是没设置成功 |
| 换成中文后字体显示异常 | 多为机型自带字体与该语言字重不匹配，换回系统默认字体即可，与本篇设置无关 |
| 应用内改完，重启后又是英文 | 说明之前是从应用内临时切换的，改用路径 B 在系统层面固定一次 |
| 想只让这一个应用用中文，手机其余部分保持英文 | 路径 B 正是为这种场景准备的，系统级语言不用动 |

## 六、语言和「内容语言」是两回事

界面语言只决定按钮、菜单、提示这些文案。你在应用里能看到的效果风格、模板主题、推荐内容，是按地区与当前版本下发的，与界面语言无关 —— 切成中文不会让模板也跟着变中文。素材本身的语言（比如模板里自带的英文字幕）需要你在编辑时自己替换成中文文字，方法见 [滤镜特效怎么用.md](滤镜特效怎么用.md) 里关于文字工具的一节。
