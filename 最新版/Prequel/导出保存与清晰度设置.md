## 一、保存到相册的步骤

编辑完成后的收尾固定是这几步：

1. 点编辑页右上角的前进 / 导出按钮，进入导出页；
2. 在导出页确认输出参数（分辨率、帧率一类，视频素材才会出现帧率项）；
3. 点保存或导出，等待进度走完；
4. 提示保存成功后，去系统相册确认一下文件在不在。

**最后一步别省**。保存提示和实际写入是两件事，偶尔会因为相册权限或空间问题只完成一半，在相册里亲眼看到才稳。

## 二、导出时可以切出去做别的事

Prequel 在导出时使用前台服务，意思是导出任务不会被"应用切到后台"打断。所以长视频导出的时候，你可以直接退出应用去回消息，导出会继续跑完。这么用有两个前提：

- 不要从最近任务里把应用**强制划掉**，那会直接终止进程，导出也就断了；
- 别在导出过程中把手机断电关机。

导出大型视频（长时段、高分辨率）本来就慢，插着电慢慢等比反复重试划算。

## 三、清晰度和帧率怎么选

导出页的参数决定了成片最终有多大、多清楚，选择逻辑是**按用途定，不按"越高越好"定**：

| 用途 | 建议 |
| --- | --- |
| 发到社交平台 | 用平台默认上传档位即可，平台本身还会再压一次，导出 4K 到平台上往往看不出差别 |
| 存在手机里回看 | 中等偏上就够；超高分辨率会明显吃空间，一部短片就占几个 GB |
| 要留档、或还要在电脑上二次剪辑 | 选能选到的最高档，帧率跟拍摄时的原始帧率保持一致，不要中途改 |
| 做 GIF 或动态图 | 时间短、分辨率低一些，文件才发得出去 |

两个具体提醒：

- **帧率不要往上瞎提**。拍的时候是 30fps，导出选 60fps 不会让画面更流畅，只会让文件变大。
- **参数项以导出页实际显示为准**。不同版本、不同机型能选到的档位不完全一样，本文不写死具体档位名；遇到只有一档可选的机型，说明当前素材或机型只支持这一档。

## 四、导出后发现的几个问题

### 保存失败 / 保存按钮没反应

按顺序查三处：

1. **相册写入权限**：安装时如果对"照片与媒体"点了不允许，保存就会失败。补开权限的路径见 [常见问题与排查.md](常见问题与排查.md)。
2. **剩余空间**：导出过程要临时占用比成片更大的空间。空间不足时，先删掉几段无用视频再导。
3. **单次导出体积过大**：长视频一次性导出容易中途失败，把素材切短、分几次导出更稳。

### 导出的东西在相册里找不到

保存提示成功，回相册却没有，多半不是没保存成功，而是相册还没扫到。按顺序试：

1. **换到「所有照片」看**：部分手机的相册默认停在「照片」这个分类里，第三方应用新存进去的图要在「图集 → 所有照片」里才看得到，那个列表是按保存时间排序的。
2. **等一会儿再看**：新写入的文件要等系统的媒体库扫描一遍才会出现在相册里，图片通常很快，视频可能要等更久；刚存完立刻去找，找不到是正常的。
3. **去文件管理器里确认**：在文件管理的图片 / 视频分类里按时间排一下，能查到文件就说明确实写进去了。查到之后重启一次手机，相册就会刷新出来。
4. **检查有没有被隐藏**：有的系统带私密相册 / 隐藏相册功能，误触移进去的图不会出现在常规相册里。
5. **清一次相册应用的数据**：相册长期不刷新时，清相册自身的缓存数据能触发重新扫描。这一步不会删掉图片，但相册里的收藏分类会丢失，操作前心里有数。

真的哪一步都查不到文件，那就回到上面那三种原因（权限、空间、单次体积）重新排查一遍，而不是反复点保存。

### 导出的视频被裁掉了一部分

导入时如果原视频的画幅比例和当前项目画幅不一致，边缘会被裁掉。解决办法是在编辑页的画幅 / 比例设置里换成与原素材一致的比例，或者主动接受裁剪、把主体挪到画面中间。

### 导入的照片方向不对（躺着或倒着）

部分机型拍摄时把方向信息写在文件元数据里，导入后可能被按错误方向摆放。在编辑页用旋转工具转一次即可，旋转不损失画质。同一张图反复出现方向问题时，去系统相机的设置里把"保存方向信息"一类选项调整一下。

### 导出后整体变模糊

多数情况下不是导出参数的问题，而是：

- 原素材本身就没对上焦，效果再叠也补不回细节；
- 编辑时叠加了多层效果，每层都带一点压缩损失；
- 缩图上传到平台，被平台二次压缩。

所以导出前建议在手机相册里放大看一眼人物眼睛的位置，眼睛清楚，整体就没问题。
