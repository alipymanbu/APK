## 一、先核对这一版安装包的信息

安装之前对一下下面的信息，能避免装错版本、也方便判断文件有没有下全。

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.97.0 |
| 安装包大小 | 105.50M |
| 包名 | `com.prequel.app` |
| 文件校验值（MD5） | `A7CB82A6E9EEA02BF3C75771DC9446F1` |

几点说明：

- 官方应用商店里能搜到的通常是更新过的版本，本页对应的这份安装包是固定的一版，两者不是同一个；本文档里所有版本号、体积都以上表为准。
- 下载完成后，可以在文件管理器里看文件夹详情，体积在 105.50M 左右基本就是完整的；如果只有几 MB 或者打不开，多半是传输中断，重新下一遍即可。
- MD5 只在需要严格校验时用（比如电脑下载完再传到手机）。手机上一般看体积就够了，不必特意装校验工具。
- 部分中文应用商店里能搜到名称相近的其它应用，开发方并不是 Prequel Inc.。装之前认准上表的包名与开发者，区分方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 二、安装前要确认的两件事

### 1. 系统版本

Prequel 要求较新的安卓系统。如果手机是多年前的机型，先去「设置 → 关于手机」看一眼系统版本，再对照应用商店页面标注的最低要求；低于要求时即使装上了，也可能在启动或导出环节直接退出。

### 2. 剩余空间

安装包本身 105.50M，安装过程还要解压一份，加上后续编辑产生的缓存，建议安装前留出 500MB 以上的空闲空间。空间紧张时先清一下相册和微信缓存，别等装到一半失败。

## 三、安装步骤

1. 打开 [Prequel 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8b4459cae000)，先把安装包转存到你自己的网盘目录，再从网盘下载到手机 —— 比直接用临时链接可靠，中断了也能续。

2. 下载完成后在通知栏或文件管理器里点开这个 `.apk` 文件。
3. 系统会弹「出于安全考虑，你的手机不允许安装未知来源的应用」，按提示进入「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把当前用的浏览器或文件管理器允许一次。
4. 回到安装界面，确认应用名显示为 Prequel，点「安装」。
5. 装完先别急着实拍，按下面一节处理权限。

## 四、第一次打开的设置

### 权限怎么给

首次进入时应用会陆续问几项权限，按用途给就行：

| 权限 | 用途 | 不给的后果 |
| --- | --- | --- |
| 照片与媒体（读取） | 从相册导入要编辑的照片和视频 | 选不到素材 |
| 照片与媒体（写入）/ 存储 | 把编辑结果存回相册 | 能编辑但保存失败 |
| 相机 | 应用内直接拍摄 | 拍不了，只能用相册里的素材 |
| 麦克风 | 视频录制声音、外部音频 | 视频无声 |

其中「写入相册」这一项最容易被忽略：很多人编辑完整张图，点保存时报错，原因就在这里。如果当时点了「不允许」，去系统设置里补开即可，具体路径见 [常见问题与排查.md](常见问题与排查.md)。

### 界面语言

Prequel 默认跟随系统语言。如果你的手机是中文系统但进去还是英文，或者想手动指定中文，走 [界面语言与中文设置.md](界面语言与中文设置.md) 里的两条路径之一。

### 先分清「免费部分」和「订阅部分」

首先明确一点：**不订阅也能用**。官方帮助中心的答复是 Prequel 有免费版本、其中包含大量特效和滤镜可供选用，是否订阅取决于个人需求。也就是说导入素材、套用一部分滤镜与效果、做基础调整、导出保存这些都不受影响；需要订阅才能用的主要是成套的独家效果、部分模板与修图工具、以及 AI 类效果，界面里通常带有一个小标识。第一次用建议按下面顺序走一遍，先熟悉流程再决定要不要订阅：

1. 导入一张相册里的照片；
2. 在效果分类里挑一个免费效果套上去，拖动强度滑块看变化；
3. 点「保存」导出到相册，确认整条链路是通的；
4. 再决定是否订阅 —— 订阅与退款的口径见 [AI效果与金币怎么算.md](AI效果与金币怎么算.md)。

## 五、装不上、打不开怎么办

- **解析包错误**：安装包不完整，重新下载一遍；不要用第三方下载器做断点续传后再装。
- **提示「应用未安装」**：手机里已经有一个签名不同的同名应用，先卸载旧版再装。
- **装完闪退**：多数是系统版本过低或剩余内存不足，先重启手机再打开；仍不行见 [常见问题与排查.md](常见问题与排查.md)。
- **安装按钮点不动**：检查「安装未知应用」的授权是不是只给了另一个应用，换回当前打开安装包的那个应用再授权。
