## 一、先分清卡在哪一步

「没生效」分三种，处理完全不同：

| 现象 | 问题在哪 | 去哪查 |
| --- | --- | --- |
| 重启仍是原厂动画，一步没变 | 压根没写进系统（权限/路径没通） | 本篇第二节~第四节 |
| 动画播了但花屏、变形、黑边 | 包本身或分辨率不对 | [desc.txt写法与zip打包要求.md](desc.txt写法与zip打包要求.md)，再回看第五节 |
| 播了两秒退回默认 android 动画 | 包结构/压缩方式不被认 | [desc.txt写法与zip打包要求.md](desc.txt写法与zip打包要求.md)，再回看第五节 |

**动手前先备份**：替换前把系统里原来的 `bootanimation.zip` 原样拷一份出来（路径见下节）。没有备份，改砸了就没有后悔药 —— 这是最值得先做的一步。

## 二、root：绕不开的门槛

系统开机动画在系统分区里，**往里写文件基本都要 root 权限**。你没有 root，软件点得再顺也只会提示授权失败或重启后无效。少数例外：

- 部分机型允许把 `bootanimation.zip` 放到 **`/data/local`**，系统找不到系统分区那份时会用它（有的实现是它优先）；
- 但**很多新机型出于安全把这条通道封了** —— 放了不生效，不代表操作错，是机型不让。

所以第一步先确认：你的机器到底有没有 root（软件请求超级用户授权时有没有弹窗、能不能授）。确认之后选哪条替换路线，见[开机动画替换的几种方法.md](开机动画替换的几种方法.md) —— 本篇管的是「走哪条路都可能卡住的那几个点」。

## 三、路径：文件到底该放哪

系统会按固定位置找这个包，常见有：

| 路径 | 说明 |
| --- | --- |
| `/system/media/bootanimation.zip` | 最传统的默认位置 |
| `/product/media/` 或 `/system/product/media/` | 较新的系统（含 LineageOS 等）挪到这里 |
| `/data/local/bootanimation.zip` | 免 root 尝试位，能用与否看机型 |

- **两个目录都有文件时的优先级因系统而异**（常见是 `/system` 那份优先）。排查时建议：把**其他位置的旧包挪走**，只留一处，再重启看结果 —— 否则你改的可能根本不是系统在读的那份。
- 部分 ROM 还有 `bootanimation-dark.zip`（深色模式用的动画），只改主文件时深色模式下可能仍走另一个。
- 在 `/system` 里找不到该文件？有的机型压根没有这一层预置动画（直接用默认帧动画），有的换了路径 —— 用 root 文件管理器全盘搜 `bootanimation` 就能定位你这台的真实路径。

## 四、权限：最常被忽略的一项

文件放进去了不生效，多半是权限不对。要求：

- 属主和属组都是 **root**；
- 权限至少 **0644**（`rw-r--r--`），不少教程直接给 777 也能用 —— 关键是**别是 600 或属主是别的用户**。

命令行改法（有 root 的终端）：

```bash
su
mount -o remount,rw /system
cp /sdcard/bootanimation.zip /system/media/bootanimation.zip
chown root:root /system/media/bootanimation.zip
chmod 644 /system/media/bootanimation.zip
reboot
```

提示：有的机器 `mount -o remount,rw /system` 不认，换 `mount -o rw,remount /system` 试。用 root 文件管理器（如 MT 管理器）替换也一样 —— 替完长按文件看一眼权限和属主。

## 五、包本身：路径权限都对了还不播

逐条对照 [desc.txt写法与zip打包要求.md](desc.txt写法与zip打包要求.md)：

1. zip 是不是**存储方式**压的、包根部有没有直接躺着 `desc.txt`（没多包一层文件夹）；
2. 文件名是不是正好 `bootanimation.zip`；
3. `desc.txt` 里写的宽高和你屏幕是否匹配、帧率是否超过 30；
4. part 目录里的图片是否同尺寸、编号是否连续。

## 六、机型不兼容的硬情况

- **厂商用私有动画格式**：部分品牌的开机画面不是 zip，而是 `.qmg`、`.mrc` 之类专有格式 —— 这种机器怎么塞 bootanimation.zip 都不会播，得查你机型自己的方案（XDA 对应机型板块是常见去处）。
- **系统动画被别处覆盖**：有的 ROM 在线刷机包、主题引擎会二次管理开机画面，替换后被还原。判断方法：改完重启一次确认，若被还原则说明有更高优先级的机制在管，得从那个机制里改。
- **最坏情况的退路**：第二节说的备份此时用上 —— 把原包按原路径、原权限放回去即可恢复出厂动画。

拿安装包与包信息核对见[下载与安装教程.md](下载与安装教程.md)；动画本身怎么做见[制作开机动画的完整步骤.md](制作开机动画的完整步骤.md)。
