## 一、为什么需要懂一点这个结构

用 BootAnimation 导出的包已经按这个结构做好了（见[制作开机动画的完整步骤.md](制作开机动画的完整步骤.md)），你不必手写。但**导出的包替换后不播，十有八九是结构或打包方式不对** —— 知道规则才能自查。想手工改包（换几张图、调个帧率）时，也靠这一篇。

## 二、包内结构

解压 `bootanimation.zip`，里面应该直接是这些内容（**不能多一层文件夹**）：

```
bootanimation.zip
├── desc.txt        播放规则（必须有，且必须在包根部）
├── part0/          第一段：编号图片
│   ├── 01.png
│   ├── 02.png
│   └── ...
└── part1/          第二段（可选，段落数量不限于两个）
    ├── 01.png
    └── ...
```

- 图片用 **png 或 jpg**，命名连续编号（`01.png`、`02.png` 或 `0000.png`、`0001.png`），同一目录内**尺寸必须一致**。
- 常见分工：part0 放品牌 logo 这类只播一次的段，part1 放循环到开机结束的段。

## 三、desc.txt 逐行怎么读

一个典型内容（注意**要以回车换行结束**，最好用 Linux 环境或能保存纯文本的编辑器，别用会插入特殊字符的富文本编辑器）：

```
1080 1920 30
p 1 0 part0
p 0 0 part1
```

第一行三个数字：

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| 1080 | 动画宽度 | 建议与屏幕一致，取**偶数** |
| 1920 | 动画高度 | 同上 |
| 30 | 常见理解为每秒播放帧数 | 建议不超过 30 |

后面每个 `p` 开头的行管一个段落，四个字段：

```
p 循环次数 暂停帧数 目录名
```

| 字段 | 含义 | 例子 |
| --- | --- | --- |
| `p` | 段落开始标记 | 固定写 `p` |
| 循环次数 | 该段播几遍；**0 = 一直循环到开机结束** | `1` 播一次，`0` 无限循环 |
| 暂停帧数 | 播完本段后停多少帧再进下一段；0 = 不停 | 帧率 20 时填 40 就是停 2 秒 |
| 目录名 | 对应包内的文件夹名 | `part0` |

所以 `p 1 0 part0` = part0 播一遍不暂停就往下走，`p 0 0 part1` = part1 循环播到系统进桌面为止。

## 四、打包的四条硬要求

1. **压缩方式必须是「存储」（Store，不压缩）**：WinRAR、7-Zip、好压的压缩选项里都有。用了普通压缩（Deflate）部分机型直接不认。
2. **不能带上层目录**：进到内容目录里，把 `desc.txt` 和 `part0/`、`part1/` 全选后再压 —— 不是要压 `bootanimation` 这个文件夹本身。
3. **文件名必须就是 `bootanimation.zip`**：改名了系统找不到。
4. **desc.txt 为纯文本、UTF-8、末尾有换行**：格式不对时动画退回系统默认。

## 五、包合格了还得路径对

包本身没问题也只是「可以被播放」，能不能播取决于它被放进了哪个系统路径、权限对不对 —— 那部分的排查在[替换后不生效的排查.md](替换后不生效的排查.md)。软件安装包本身则在[下载与安装教程.md](下载与安装教程.md)。
