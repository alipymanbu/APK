## 一、连接前的三件事

| 条件 | 说明 |
| --- | --- |
| 同一个局域网 | 手机和电视连同一个 Wi-Fi；路由器把 2.4G 与 5G 分成两个名字时，两边要连同一个 |
| 电视开了 ADB 调试 | 就是下文的开发者选项设置，不开连不上 |
| 知道电视的 IP | 电视「设置 > 网络」里能看到，先记下来 |

## 二、电视端：解锁开发者选项并打开 ADB 调试

官方给出的通用路径是：

1. 电视进入「设置 > 设备偏好设置 > 关于」；
2. 对「版本号 / Build」连按遥控器确认键多次，直到提示已进入开发者模式；
3. 返回设置，进入「开发者选项」，打开「USB 调试」（有的系统叫「网络调试 / ADB 调试」）。

不同品牌的入口有差异：

- **Fire TV 系设备**：设置 > 我的 Fire TV > 开发者选项，打开「ADB 调试」；
- **Google TV**：设置 > 系统 > 关于，其余同上；
- 个别国产品牌把 ADB 开关藏在工程菜单里，需要用遥控器按特定按键组合才出现，直接搜「你的电视品牌 + ADB 调试」能找到对应做法。

## 三、手机端：发起连接

1. 打开 atvTools，等它扫描局域网里的设备，扫到了直接点；
2. 扫不到就手动添加：选输入 IP 的入口，填电视「设置 > 网络」里看到的 IP 地址；
3. 第一次连接时，电视屏幕会弹「允许 USB 调试吗？」的确认框，勾选「一律允许使用这台计算机进行调试」再点确定，之后重连就不会再弹。

## 四、连上之后

连接成功后，电视的应用列表、资源占用这些信息会直接出现在手机上。接下来你可以：

- 从手机往电视装应用、传文件：见[给电视安装应用与传文件.md](给电视安装应用与传文件.md)；
- 把手机当遥控器、鼠标、键盘用：见[怎么当遥控器用.md](怎么当遥控器用.md)；
- 清缓存、卸载或停用应用、看内存占用：见[清理缓存与卸载预装应用.md](清理缓存与卸载预装应用.md)；
- 扫不到、连不上、连上后功能异常：见[连接失败与功能异常排查.md](连接失败与功能异常排查.md)。
