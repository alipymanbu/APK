## 一、一键清理全部应用缓存

工具页里有一键清除所有应用缓存的按钮，不用挨个进电视设置。旧电视存储紧张、系统越来越卡时，先试这一步。注意清的是缓存，不是应用数据——看了一半的进度、登录状态一般不受影响，但个别应用的离线内容可能要重新加载。

## 二、管理已装的应用

应用列表里每个应用都能做这几件事：

| 操作 | 什么时候用 |
| --- | --- |
| 打开 | 在手机上直接启动电视里的应用，省得用遥控器翻 |
| 卸载 | 自己装的应用不要了 |
| 停用 / 启用 | 预装应用卸不掉，停用让它从桌面消失，随时可恢复 |
| 强制停止 | 某个应用卡死、占着后台不放 |
| 下载 APK | 把电视上某个应用的安装包拉回手机留存 |

## 三、预装应用：先停用，别急着重来

电视出厂自带的很多应用是卸不掉的，停用（禁用）是更稳妥的处理方式：停用后应用不再出现在桌面、也不在后台运行，存储与内存都能让出来，之后想恢复点启用就行。

动手前留个心眼：

- 不认识的包名先搜一下是什么，再决定停不停；
- 桌面启动器、应用商店、语音服务这类核心组件别停——停错了可能黑屏、遥控器部分按键失灵，恢复起来麻烦；
- 官方系统服务拿不准的一律不动，只处理你明确认得、明确不用的。

## 四、看资源占用，找吃内存的应用

资源页能看到设备的 CPU、内存、网络、存储占用，并列出正在运行的应用。使用思路：

1. 看内存占用是不是长期偏高；
2. 进运行中应用列表，找出占得多的那几个；
3. 确认不是系统组件后强制停止，或按第三节停用。

## 五、应用权限的授予与撤销

应用列表里可以直接授予或撤销某个应用的权限。典型场景：某个刚装的应用要麦克风或通知权限、而电视上的弹窗没注意到，直接在这里补授；反过来，不希望某个应用定位的，也可以在这里关掉。

## 六、进阶：shell 里直接执行命令

app 里有 shell 标签，可以直接对电视执行命令。上面几节的按钮覆盖不到时才用得着它，常用的几条：

```bash
# 列出所有已装应用的包名（配合关键词过滤）
pm list packages | grep -i 关键词

# 停用某个应用（比卸载安全，可恢复）
pm disable-user --user 0 包名

# 恢复停用的应用
pm enable 包名

# 强制停止某个应用
am force-stop 包名
```

三条安全习惯：

1. 停用前把包名和命令抄下来，恢复时照着敲 `pm enable`；
2. 只执行你看得懂、知道怎么撤销的命令，来源不明的命令一律不敲；
3. `disable-user` 与按钮里的「停用」是一回事，能点按钮就别敲命令。

清理完缓存、停完应用之后电视还是卡，或者某项操作点下去没反应，翻[连接失败与功能异常排查.md](连接失败与功能异常排查.md)对照处理。
