## 一、固件升级怎么做

应用的车辆设置里有固件升级入口（官方 Wiki 单独列了「访问升级页面」和「更新固件」两条说明），操作路径以你的应用版本内菜单为准。

升级前后的几条实操建议：

| 时机 | 要做的事 |
| --- | --- |
| 升级前 | 确认车辆电量充足、手机电量充足；确认手机与车辆距离足够近 |
| 升级中 | 保持应用在前台、蓝牙不断开；不要中途锁车或移动车辆 |
| 升级后 | 观察一次完整的锁车/解锁流程，确认功能正常 |

升级失败不要连续重试：先重启车辆（应用内有重启入口），确认电量后再试一次；连续失败的按第四节找官方客服，报上车辆 Virtual ID 能省一轮沟通。

## 二、高频问题速查

| 现象 | 先查什么 | 处理 |
| --- | --- | --- |
| 应用搜不到车辆 | 车辆开机、蓝牙与定位权限、距离 | 按[连接配对与手机钥匙](连接配对与手机钥匙.md)第四节的顺序排查 |
| 靠近不自动解锁 | 手机蓝牙是否常开、应用是否被后台清理 | 把应用加入后台白名单，确认 Phone Key 处于开启状态 |
| 电量读数异常或长期不变 | Smartpac 是否装到位 | 取下重新安装；仍异常联系客服 |
| 换了新手机 | —— | 新手机登录同一账号即可，车辆不用重新注册；Phone Key 需在新手机上重新激活 |
| 二手买的车还挂在原主人账号下 | —— | 让原主人在应用内解绑车辆与 Smartpac，你再用自己账号注册 |
| 收不到移动报警 | 通知权限、后台运行权限 | 系统设置里允许应用通知并常驻后台 |
| 车辆位置显示跟着手机走，与实际停车位置不符（有用户反馈） | 应用是否为商店最新版本 | 暂以 Smartpac 电池位置为主要参考，升级版本后仍复现就走应用内报修，详见[骑行数据与车辆定位](骑行数据与车辆定位.md) |
| 应用显示已关机，电池实际还在开机（有用户反馈） | 应用是否为商店最新版本 | 升级应用、在应用内重启车辆；仍复现走应用内报修 |

## 三、账号相关

- **删除账号**：应用内有删除账号入口，删除后账号下的车辆、Smartpac 绑定与历史数据一并处理，操作前想清楚；
- **一车一账号**：车辆注册到某个账号后，其他账号绑定不了它，转手前必须先解绑（见上表）；
- **换手机不用换账号**：车辆与账号绑定，与手机无关。

## 四、找官方客服

按官方服务页给的渠道，按响应速度排：

1. **应用内提交请求**：应用里直接报修，车辆信息会自动带上，官方推荐首选；
2. **在线客服**：欧洲中部时间周一至周五 08:00–24:00（换算成北京时间大约为 14:00 至次日 06:00，冬令时期间整体顺延一小时）；
3. **邮件**：`contact@lemmofuture.com`（官方称 24 小时内回复）；
4. **官网服务页**：[www.lemmofuture.com/pages/support](https://www.lemmofuture.com/pages/support)，上面还有欧洲 150 多个服务点的查询入口与图文/视频教程（Lemmo Wiki），很多操作问题在 Wiki 里就有现成答案。

客服沟通前备好三样：车辆 Virtual ID、Smartpac Virtual ID、应用版本号，能明显缩短来回。

## 五、还要动手解决不了的

绑定、数据、升级之外的问题（异响、刹车、机械部件），属于整车维修范畴，超出这款应用能处理的范围，直接走上面的服务点或应用内报修。应用侧的功能问题先回[骑行数据与车辆定位](骑行数据与车辆定位.md)和[连接配对与手机钥匙](连接配对与手机钥匙.md)核对操作步骤，确认不是设置问题再报修。
