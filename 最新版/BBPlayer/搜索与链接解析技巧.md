## 一、搜索框是个聚合入口

打开软件第一眼就是搜索框。它不是单纯的关键词搜索，而是会先猜你贴进来的内容想干什么 —— 识别不了链接时才退回关键词搜索。所以从 B 站复制的分享文本可以直接整段粘贴，链接前后的说明文字会被自动剥掉。

能识别的输入类型：

| 输入形式 | 识别结果 |
| --- | --- |
| `BV1GJ411x7h7` 或 `AV114514` | 直接跳到该视频详情页 |
| 短链 `b23.tv/xxxxxx` | 解析后按真实链接跳转 |
| `https://space.bilibili.com/...` | 按参数跳收藏夹页 / 合集页 / 用户主页（见下表） |
| 普通关键词 | 当作搜索词出结果 |

## 二、space 主页链接的细分规则

同是 `space.bilibili.com` 的链接，后面跟的参数不同，落点不同：

| 链接特征 | 跳转到 |
| --- | --- |
| 含 `ctype=21` | 合集页（如 `.../favlist?fid=xxx&ctype=21`） |
| 含 `ctype=11` 或不含 `ctype` | 收藏夹页（如 `.../favlist?fid=xxx`） |
| 含 `/lists/<id>` | 合集页 |
| 什么参数都没有 | 用户主页 |

看不懂参数没关系 —— 你只要知道：从 B 站个人空间、收藏夹、合集复制出来的链接，扔进搜索框都能到对的地方。

## 三、从 B 站 App 一键分享进来

在 Bilibili 手机端打开一个视频，点**分享**按钮，在弹出的菜单里右滑到底点**更多**，选择**分享到 BBPlayer**，系统会直接把视频详情页打开在 BBPlayer 里。前提是已经装好 BBPlayer（安装见 [下载与安装教程.md](下载与安装教程.md)）。

## 四、搜索结果里能做什么

- **搜 UP 主**：v2.5.0 起搜索页集成了 UP 主搜索，搜人也能出结果。
- **列表内搜索**：收藏夹和本地歌单里各有自己的搜索框，歌单曲目多了靠它定位。
- **搜到之后**：点曲目右侧**更多**菜单可以缓存音频（下载见 [歌曲缓存与导出m4a教程.md](歌曲缓存与导出m4a教程.md)）、查看分 P 详情（规则见 [歌单同步与本地歌单管理.md](歌单同步与本地歌单管理.md)）。

## 五、搜不到时的两个排查方向

1. **贴的链接不对**：确认是完整链接而不是被截断的半截 —— 短链要带完整的 `b23.tv/xxxxxx` 路径。
2. **结果为空但网页能打开**：B 站接口偶有变动，官方更新较勤，先到 [Releases 页面](https://github.com/bbplayer-app/BBPlayer/releases) 看最新版是否修了相关问题，再决定是否升级。
