## 一、先判断：是歌没了，还是应用坏了

点某首歌没反应、报错或直接跳过，先在 B 站网页或官方 App 里打开同一个视频确认它还在。按社区整理的 B 站接口常见错误，播不出来通常是这几种原因之一：

| 情况 | 表现 | 你能做的 |
| --- | --- | --- |
| 稿件被 UP 主删除或设为私密 | 所有客户端都打不开 | 换一首，或从歌单里删掉该条目 |
| 版权限制导致部分区域/账号不可播 | 网页端也放不了 | 没有绕行办法，放弃这首 |
| 登录态过期 | 收藏夹打不开、在线歌单空白 | 重新登录（扫码 / 手机号 / Cookie，见 [下载与安装教程.md](下载与安装教程.md)） |
| B 站接口风控偶发拦截 | 突然整批请求失败、稍后又恢复 | 等几分钟再试，或更新到最新版 |

**判断顺序永远是：先查视频本身 → 再查网络 → 最后才怀疑应用。** 大面积播不了（所有歌都失败）基本不是内容问题，按最后两行处理。

## 二、闪退或卡在启动页

按命中率从高到低依次试：

1. **清后台重开**：杀掉进程再进，多数偶发崩溃到此就好了；
2. **检查安装包架构**：装的架构与设备不匹配会表现为一点开就退。重新对照 [下载与安装教程.md](下载与安装教程.md) 里的架构表，arm64 设备装成 x86 包就是这种症状；
3. **清缓存**：系统设置 → 应用 → BBPlayer → 存储 → 清除缓存（清缓存不动你的歌单，清数据才会）；
4. **升级版本**：Releases 页面的逐版更新记录里常有「修复闪退」条目，看最新版是否已修；
5. **提交反馈**：仍复现就到 [GitHub Issues](https://github.com/bbplayer-app/BBPlayer/issues) 提 issue，附上机型、系统版本和复现步骤 —— 应用内置了崩溃上报（可在 设置 → 通用 关闭「分享数据」），开发者能看到堆栈。

## 三、通知栏控制与状态栏歌词不显示

BBPlayer 的锁屏控制、通知栏切歌、状态栏歌词都走**系统通知权限**，首次启动如果弹出通知申请时选了「不允许」，这些功能会整体失效。补救：系统设置 → 应用 → BBPlayer → 通知 → 允许通知，再回应用里重开对应开关。

状态栏歌词开了仍不显示，再按 [歌词匹配与桌面歌词设置.md](歌词匹配与桌面歌词设置.md) 第五节核对三件事：框架选对没有、插件在 LSPosed 里的作用域勾了 BBPlayer（词幕方案还要勾系统界面）没有、改完重启没有。**桌面歌词（悬浮窗）不显示**则是另一个权限：系统设置里的「显示在其他应用上层」没开。

## 四、登录相关

- **扫码没反应**：确认手机 B 站 App 是登录状态，扫的是 BBPlayer 应用内出的码，不是别的二维码；
- **登录后歌单空白**：等网络恢复再下拉同步；持续空白按第一节先确认登录态是否过期；
- **换登录方式**：三种方式（扫码 / 手机号 / Cookie）效果等同，Cookie 方式在前两种都被风控拦住时最稳。

## 五、几个「不是 bug」的现象

- **弹幕不见了**：弹幕功能在 v2.5.0 起废弃、后续版本已彻底移除，是主动下线不是坏了；
- **升级后共享歌单变成普通歌单**：v2.5.0 重构了共享系统，旧共享歌单自动转普通歌单，需重新发起共享（详见 [歌单同步与本地歌单管理.md](歌单同步与本地歌单管理.md)）；
- **旧备份导入失败**：v2.6.5 起备份格式升级到 v2，不再兼容更早版本的备份文件 —— 手里有旧备份就先在旧版本上恢复、再导出新格式；
- **歌单里部分曲目变灰**：无网络时只有已缓存的曲目可播，这是离线模式的正常表现。

## 六、实在解决不了时

先确认手里的版本：网盘这份是 2.6.4（安装包来源见 [下载与安装教程.md](下载与安装教程.md)），官方最新版以 [Releases 页面](https://github.com/bbplayer-app/BBPlayer/releases) 为准 —— 很多「怪问题」的修复就写在更新日志里。升级前记得在 设置 里导出一份备份。仍无解再去 [GitHub Issues](https://github.com/bbplayer-app/BBPlayer/issues) 搜一下同类问题，搜不到再提新的。
