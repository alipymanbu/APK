## 一、安装前先核对三件事

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 版本 | 0.1.7 | 网盘里这一份的版本号 |
| 安装包大小 | 78.12 MB | 下载完可以拿它对一眼 |
| 系统要求 | 安卓 5.2 及以上 | 安装包标注的最低版本 |

ZeroAI 是安卓应用，本篇只讲安卓端安装。手机存储建议预留安装包体积两倍以上的空闲空间，安装过程中还需要展开临时文件。

## 二、获取安装文件资源

安装包通过网盘分发：先转存 [ZeroAI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c5b3fc4fdfba) 到自己的夸克账号，再用夸克 App 把文件夹里的 apk 文件下载到手机本地。

下载时留意三点：

- 文件大小应约 78 MB，明显偏小说明没下完整；
- 不确定是否完整时，按第四节的 MD5 校验一遍；
- 打开链接提示「分享已取消」或已失效：网盘分享由资源方维护，这种情况只能等资源方重新发布，本篇无法自行处理。

## 三、安装步骤

1. 在手机上找到下载好的 apk 文件，点它；
2. 第一次安装会弹「不允许安装未知来源应用」——按弹窗提示跳到系统设置，允许你的文件管理器（或浏览器）「安装未知应用」，返回后再点一次 apk；
3. 等安装完成，打开应用。

各品牌手机的授权入口叫法不同：类原生系统在「设置 → 应用 → 特殊应用权限 → 安装未知应用」；小米、OPPO、vivo 等系统通常在弹窗里直接给「仍要安装」或「去授权」按钮，照着走即可。具体路径以你手机的系统为准。

## 四、装不上 / 提示安装包损坏

- **解析包出错、安装包损坏**：多半是下载不完整，重新下载一遍，下完先看大小是否约 78 MB；
- **想进一步确认完整性**：把 apk 传到电脑上算 MD5，正确值应为 `45FCA1693C944F71444D3429B248C533`。Windows 在命令行执行 `certutil -hashfile 文件名.apk MD5`，macOS 与 Linux 执行 `md5sum 文件名.apk`；
- **提示系统版本过低**：你的安卓版本低于安装包标注的 5.2，这种情况下装不了；
- **存储空间不足**：清理出足够空间后再装。

## 五、首次启动会经过哪些设置

按 0.1.7 的实际流程，第一次打开会依次经过：

1. **权限豁免（Request Exemption）**：申请电池优化豁免等权限。这是它后台常驻的前提，建议照常允许；
2. **设置 PIN（Set up a PIN）**：给应用加一道锁，之后每次打开要输 PIN，公开资料里没有找到找回方式，务必记牢；
3. **引导页**：点右下角 Next 依次过完说明页；
4. **选择大模型并填入 API 密钥**：这是最关键的一步，各模型的申请入口、填写位置与常见错误见 [API密钥获取与配置.md](API密钥获取与配置.md)；
5. 进入主界面后，从底部 Terminal 开始发第一条指令，日常用法见 [上手使用教程.md](上手使用教程.md)。

如果当时跳过了电池豁免，后面发现指令发出去没动静，去「设置 → 应用 → ZeroAI → 电池」里补开即可，更多排查见 [常见问题解答.md](常见问题解答.md)。
