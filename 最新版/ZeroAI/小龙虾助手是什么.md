## 一、「小龙虾助手」这个叫法从哪来

2026 年初，开源 AI 智能体项目 OpenClaw（曾用名 Clawdbot、Moltbot）在中文社区走红，大家按名字把它叫成「小龙虾」「龙虾」。之后一批「把智能体装进手机」的应用都被归进这一类，ZeroAI 也在其中——分发渠道里它常被标成「龙虾助手」，介绍它的资料里则多写作「小龙虾助手」。

有分发页说它是「给 clawdbot（小龙虾）准备的插件」，这个说法没有对应的官方说明可查。从 0.1.7 的实际形态看，它自己就是一套完整的手机端智能体：在应用内配置模型与密钥、在手机上常驻执行任务。

另外要注意：2026 年 3 月起，腾讯、字节等大厂也相继推出了各自的「龙虾」产品，这一类应用的名字越起越杂。认应用别只认名字——看包名更靠谱，ZeroAI 的包名是 `com.zeroclaw.android`。

## 二、它到底是干什么的

ZeroAI 是一款安卓端的 AI 智能体应用（包名 com.zeroclaw.android），核心用法是：

1. 你在应用里接入一个或几个大模型（DeepSeek、Qwen、OpenAI、Gemini、xAI 等，密钥自己申请）；
2. 在 Terminal 里用自然语言下达指令；
3. 它把指令拆成步骤，调用搜索、HTTP 请求、脚本等工具执行，最后给你结果。

与「打开聊天框问一句」不同，它强调把一件事做完：多步任务、跨应用协作、定时执行这类活是它的主战场。

## 三、和直接用 DeepSeek / ChatGPT 官方 App 的区别

| | 官方聊天 App | ZeroAI 这类智能体应用 |
| --- | --- | --- |
| 交互 | 一问一答 | 下达任务，AI 自己拆步骤执行 |
| 模型 | 固定一家 | 一个应用里切换多家 |
| 账号/密钥 | 用官方账号登录 | 需要自己申请各家的 API 密钥 |
| 费用 | 免费额度或订阅 | 按各供应商的 API 用量计费 |
| 后台 | 不在后台跑活 | 前台服务常驻，可执行定时任务 |

一句话：只想聊天问答，官方 App 更省事；想让 AI 替你跑流程、盯任务，才轮到这一类应用出场。

## 四、适合谁、不适合谁

**适合**：

- 愿意花十几分钟申请 API 密钥、想自己控制模型用量与成本的人；
- 有重复性任务要交出去（定时汇总、盯数据变化、批量整理）的人；
- 想在一个应用里对比多家模型效果的人。

**不适合**：

- 只想要一个开箱即用的聊天机器人——它不送模型额度，不配自己的密钥基本用不起来（以应用内实际提示为准）；
- 对后台常驻、通知栏常驻通知敏感的人。
