# ZeroAI 后台常驻与省电白名单设置

> 本篇解决「划掉应用、锁屏之后任务就断」的问题：给 ZeroAI 开后台白名单的系统设置，按品牌分开列。

## 一、为什么会被系统杀后台

ZeroAI 以前台服务的方式常驻（通知栏留一条常驻通知），这本身已经是安卓允许的最高优先级形态之一。但国产系统的省电策略普遍比原生激进，只靠前台服务常常不够——锁屏几分钟、或者从最近任务里划掉，进程仍可能被收掉。所以要手动把它加进各系统的「白名单」。

## 二、所有机型先做的四步

不同品牌叫法不同，但这四样都存在：

1. **电池优化豁免**：把 ZeroAI 设为「不受限制 / 不优化」。首次启动时的 Request Exemption 就是申请这个，当时跳过的现在补上；
2. **允许自启动**：多数国产系统有独立开关；
3. **保持通知权限**：通知被禁后，部分系统会连带清掉前台服务；
4. **最近任务里锁定**：在最近任务卡片上锁一下（有的系统是下拉卡片，有的是长按）。

做完用这个办法验证：让 AI 设一个十分钟后触发的定时任务，锁屏放一边，到点看它有没有执行、有没有回复。没动静就按第三节对着自己的品牌逐项检查。

## 三、各品牌的设置路径（示意）

| 系统 | 大致路径 |
| --- | --- |
| 类原生 Android | 设置 → 应用 → ZeroAI → 电池 → 不受限制；再到「特殊应用权限 → 电池优化」里确认对所有应用选了「不允许优化」 |
| 华为 HarmonyOS | 设置 → 应用和服务 → 应用启动管理 → ZeroAI → 关闭「自动管理」→ 手动允许自启动、关联启动、后台活动 |
| 小米 MIUI / 澎湃OS | 设置 → 应用设置 → 应用管理 → ZeroAI → 省电策略 → 无限制；「自启动」打开；最近任务下拉加锁 |
| OPPO / 一加 ColorOS | 设置 → 电池 → 应用耗电管理 → ZeroAI → 允许完全后台行为；自启动在「应用管理」里开 |
| vivo / iQOO OriginOS | 设置 → 电池 → 后台耗电管理 → 允许后台高耗电；自启动在「应用与权限 → 权限管理」里开 |
| 魅族 Flyme | 手机管家 → 应用管理 → ZeroAI → 后台权限放开 |

菜单名称随系统版本会变，找不到时在系统设置里直接搜「ZeroAI」或「电池优化」最快。

## 四、白名单全开了还断

- 检查是否开着省电模式或超级省电，先关掉再测；
- 长任务尽量放在充电、亮屏的场景跑，多数系统对这种状态下的后台最宽松；
- 换更省任务的写法：把一次性的大任务拆成几个到点执行的小任务，单次断掉的影响也小（指令写法见 [上手使用教程.md](上手使用教程.md)）；
- 以上都无效且系统刚更新过，等下一版系统或应用更新再试——这类「系统杀后台」的兼容问题通常双方都会修。

设置反复失效的，也可以先去 [常见问题解答.md](常见问题解答.md) 过一遍其它常见原因，排除掉密钥、网络这些问题再折腾系统设置。
