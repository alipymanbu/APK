## 一、先选供应商：对照表

ZeroAI 不自带模型额度，需要你自己申请 API 密钥接进去。0.1.7 支持的主流供应商如下（应用内实际列表为准）：

| 供应商 | 申请入口 | 计费方式 | 备注 |
| --- | --- | --- | --- |
| DeepSeek | [platform.deepseek.com](https://platform.deepseek.com) | 按用量计费 | 国内可直连 |
| Qwen（阿里云 DashScope） | [阿里云百炼控制台](https://bailian.console.aliyun.com) | 按用量计费，新用户额度以官方页面为准 | 国内可直连；分三个区域端点，见第四节 |
| OpenAI | [platform.openai.com](https://platform.openai.com) | 按用量计费 | 中国大陆网络环境无法直连 |
| Google Gemini | [aistudio.google.com](https://aistudio.google.com) | 有免费额度，超出按量计费 | 中国大陆网络环境无法直连 |
| xAI（Grok） | [console.x.ai](https://console.x.ai) | 按用量计费 | 中国大陆网络环境无法直连 |
| OpenRouter | [openrouter.ai](https://openrouter.ai) | 一个密钥转发多家模型，含免费模型 | 想用一个密钥试多家时选它 |
| Ollama（自建） | 自建的 Ollama 服务 | 免费 | 不申请密钥，填服务地址 |

价格、免费额度这类会变的信息以各供应商官方页面为准。只在国内网络环境直接使用的话，DeepSeek、Qwen、Ollama 是不用额外折腾网络的选择。

## 二、申请与填写的通用流程

1. 到供应商的开放平台注册账号（国内供应商手机号即可）；
2. 在控制台里找「API Keys」「密钥管理」之类的入口，创建一个新密钥；
3. 立刻复制密钥——多数平台只在创建时完整展示一次，关掉页面就得重新生成；
4. 回到 ZeroAI：首次启动在「选择模型」那一页，点中供应商后把密钥粘进输入框；已经过了引导的，从底部 **Agents** 页进入对应供应商的配置里补填或更换；
5. 保存后回到 Terminal 随手发一句话，能收到回复就配通了。

## 三、密钥长度校验：存不上的第一嫌疑

0.1.7 对密钥做最小长度校验：**DeepSeek 至少 35 个字符、Qwen 至少 20 个字符**。保存时提示长度不对，按这个顺序查：

1. 数一遍字符数是否达标——不够多半是复制时漏了头尾；
2. 检查有没有带进多余的空格或换行；
3. 确认密钥与供应商是配套的：Qwen 的密钥来自阿里云 DashScope，不能拿 OpenAI 的密钥填进 Qwen，反过来也不行。

其他供应商的密钥格式以各平台自己的说明为准。配好后仍然报认证错误，直接翻 [常见问题解答.md](常见问题解答.md) 的 401 一节。

## 四、Qwen 的区域端点怎么选

Qwen 走阿里云 DashScope，分**国际、中国、美国**三个区域端点，应用内有区域选择器；选中国区域时会提示数据驻留——你的请求会落在阿里云中国区。

选择原则：密钥是在哪个站点注册发放的，就选哪个区域。密钥与区域是绑定的，拿国际站的密钥选中国端点，容易直接认证失败。

## 五、多模型并存与切换

Agents 页可以同时配置多家供应商，之后：

- 新开聊天窗口时选不同模型，几条任务并行跑；
- 同一窗口内切换模型不需要重配密钥；
- 还没想好用哪家的，先用 OpenRouter 一个密钥在多家模型之间轮着试，定了再单独申请。

配好之后怎么把模型用起来，见 [上手使用教程.md](上手使用教程.md)。

## 六、费用怎么控

调用是按量花钱的，用量归你管：

- **预付费平台**（DeepSeek 等充值扣款型）：充多少用多少，余额扣完自动停，天然不会超额；
- **后付费平台**（OpenAI 等月账单型）：在控制台设置用量上限或月支出上限，多数平台支持，入口以平台为准；
- **定期看用量明细**：发现某天消耗突然翻倍，多半是某个长任务在反复调用，及时停掉；
- **拿不准先试便宜的**：Gemini 的 AI Studio 有免费额度，OpenRouter 有免费模型，先用它们把手感练出来，再决定主用哪家。各平台的额度政策随时会调，以官方页面为准。

## 七、密钥安全三条

- **密钥等于钱袋子**：不要截图发群里、不要把密钥原文发进任何聊天窗口去问别人；
- **怀疑泄露立刻吊销**：到对应平台的密钥管理页删掉旧密钥、生成新的，旧密钥即刻失效，几十秒就能止损；
- **开 PIN 锁**：首次启动时的 Set up a PIN 建议照做，手机借给别人时至少多一道门。
