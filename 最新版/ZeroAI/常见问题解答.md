## 一、密钥无效 / 401 认证错误

按命中概率从高到低排查：

1. **密钥填错了**：拼写错误、首尾空格、复制不全都会导致 401。0.1.7 有长度校验（DeepSeek 至少 35 字符、Qwen 至少 20 字符），长度不够先数一遍字符数；
2. **密钥已过期或被吊销**：到对应平台的密钥管理页看状态，失效就重新生成一个换上；
3. **密钥与供应商不匹配**：Qwen 的密钥来自阿里云 DashScope，OpenAI 的密钥填不进 Qwen，反过来也不行；
4. **缓存问题**：清一次应用缓存，重新进 API 设置页配置并保存。

填密钥的完整流程见 [API密钥获取与配置.md](API密钥获取与配置.md)。

## 二、429 请求限制 / 超出配额

429 是供应商侧的限流或配额问题，不是应用坏了：

- 把短时间内的指令频率降下来，避免同时发起多个任务；
- 到供应商控制台看剩余配额，免费额度用尽要么等重置、要么换付费计划；
- 多人共用一个密钥的，协调各自的使用时段，别挤在同一时间；
- 触发后等一段时间再试，多数限流会自动解除。

## 三、安装包装不上

- **解析包出错、安装包损坏**：重新下载，下完核对大小约 78 MB；需要更严格确认时用 MD5 `45FCA1693C944F71444D3429B248C533` 校验，方法见 [下载与安装教程.md](下载与安装教程.md)；
- **提示系统版本过低**：安装包标注需要安卓 5.2 及以上；
- **弹不出安装授权**：去「设置 → 应用 → 特殊应用权限 → 安装未知应用」里手动给你的文件管理器授权。

## 四、发指令没反应 / 后台被杀

手机省电策略把常驻服务收掉是最常见的原因。最快的处理顺序：

1. 在系统设置里给 ZeroAI 关掉电池优化——首次启动时的 Request Exemption 就是干这个的，当时跳过的话，去「设置 → 应用 → ZeroAI → 电池」补上；
2. 允许自启动、保持通知权限、在最近任务里锁定；
3. 还不行，按你的手机品牌逐项对照白名单路径：完整清单见 [后台常驻与省电白名单设置.md](后台常驻与省电白名单设置.md)。

排除后台问题之前，先确认不是密钥或网络的问题（见第一节和第五节）。

## 五、回复很慢或一直转圈

- 用的是海外供应商（OpenAI、Gemini、xAI）而当前网络到它们的接口不通——这是网络可达性问题，不是应用问题；国内网络环境下选 DeepSeek、Qwen 或自建 Ollama 更稳；
- 模型本身在高峰期响应慢，换个模型或过一会再试；
- 任务本身步骤太多，拆小一点分批发。

## 六、PIN 忘了怎么办

公开资料里没有找到找回入口。万不得已的兜底是卸载重装——应用内的全部配置（包括各家密钥）会被一起清掉，重装后要重新走一遍首次启动流程，所以动手前先把各供应商的密钥处理好（有的平台支持回看旧密钥，不支持的就重建一个，以各平台为准）。

## 七、版本与更新

网盘里这份是 0.1.7，更新以官方发布渠道为准。安卓覆盖安装通常保留应用数据与配置，但动手更新前把各家密钥自己备份一份更稳妥。

以上排查都试过仍无解的，回到 [上手使用教程.md](上手使用教程.md) 对照一遍基本用法，确认不是指令本身写法的问题。
