# ACGTI 角色库与原型一览

> 本篇整理 ACGTI 的角色库全貌：8 种人格原型各自是什么画像、匹配位里都有哪些作品与角色、隐藏角色是怎么回事。还不知道自己测出哪一档的，先看 [测试流程与答题技巧.md](测试流程与答题技巧.md) 与 [测试结果怎么看.md](测试结果怎么看.md)。

ACGTI 的匹配结果落在「原型 → 角色」两级上：你先被归入 8 种叙事原型之一，再匹配到该原型下的具体二次元角色。下文的角色名单整理自该项目公开的网页版角色图鉴，商店页面对数量的口径略有出入（见第三节），以你手机里的应用内实际显示为准。

## 一、8 种原型是什么

| 原型 | 画像 | 典型 MBTI 字母 |
| --- | --- | --- |
| 光芒主角 | 充满磁力的核心人物，在众目睽睽之下愈发耀眼 | ENFP / ESFP / ESFJ / ENFJ |
| 冰封观察者 | 冷静、理性，从边缘洞察全局 | ISTP / INTP |
| 誓约队长 | 责任驱动，冲在队伍最前，从不食言 | ESTJ / ENTJ |
| 诡谲游侠 | 混乱、机智，扰乱每一个进入的系统 | ENTP |
| 温柔治愈者 | 敏锐而温柔，仅凭存在就能抚平他人的伤害 | INFP / ISFJ / INFJ / ISFP |
| 暗影谋士 | 在幕后运筹帷幄，永远领先三步 | ENTJ / INTJ / INFJ |
| 混沌之火 | 活在当下，靠冲动驱动，点燃周围一切 | ESTP / ESFP / ENFP |
| 月光守护者 | 默默奉献的稳定存在，默默承担他人的重量 | INFP / ISTJ / ISFJ / INTP |

同一原型下的角色性格底色相近，但气质各有侧重：比如同在「月光守护者」，后藤一里是社恐内耗型，若叶睦则是安静钝感型。所以同原型测出不同角色很正常。

## 三、数量与隐藏角色：两种口径都摆在这

- 商店页面的介绍是「40 位常规角色 + 2 位隐藏角色」，隐藏角色需要测出后才解锁；
- 项目公开的角色图鉴页面则直接列出上表这 41 位。

两个数字对不上的部分大概率就在隐藏角色上——图鉴只展示常规匹配位，隐藏的那两位不列出来。你实际能匹配到谁，以应用内角色库为准。

## 四、怎么用这份名单

- **测之前**：扫一眼作品覆盖，心里有个预期——这份库偏 2020 年前后的热门番与虚拟歌手，冷门作品的角色少；
- **测之后**：先在 [测试结果怎么看.md](测试结果怎么看.md) 里读懂自己的原型，再回这张表看同原型的其他角色，理解「为什么是他而不是隔壁那位」；
- **和朋友对答案**：报角色代码或原型名都比报角色名快，具体含义见 [测试结果怎么看.md](测试结果怎么看.md)。

零散问题（隐私、重测、网页版入口）集中在 [常见问题解答.md](常见问题解答.md)；还没安装的从 [下载与安装教程.md](下载与安装教程.md) 开始。
