## 一、导出之前先确认三件事

这三条各自对应一类常见的「导完才发现」：

1. **时间轴上没有留下的标记**。标记只是给你自己看的，但留着多半意味着还有一段没改完。
2. **没有「缺失媒体」**。带红色条纹的片段表示源文件找不到了，先按 [常见问题与排查.md](常见问题与排查.md) 处理掉再导。
3. **画幅比和帧率与发布平台对得上**。要发竖屏短片，就别导成 16:9；导出这一步的帧率应该跟项目帧率一致，不该在这里改。

## 二、导出设置怎么选

导出时可以控制分辨率、质量和帧率，可选范围取决于素材与设备能力。

| 设置项 | 怎么定 |
| --- | --- |
| 分辨率 | 不超过原素材的分辨率；发布平台还会二次压缩时，1080p 通常就够 |
| 质量 | 先按默认导出看一遍，文件体积可以接受就不要往上加 |
| 帧率 | 与项目帧率保持一致，别在这里改 |
| 格式 | 直接发布用常规格式；需要拿到别的软件里再加工的，走第四节的项目迁移那条路 |

导出的去向不止一个：可以直接发到社交平台，也可以存到设备本地或云存储。选哪个按你后面拿它干什么来定 —— 要立刻发布就直发，要留底就先存本地再另存一份。

一条实用的判断：**导出耗时大致与片长、分辨率成正比**。一条十分钟的片子，高分辨率导出比 1080p 慢上数倍是正常的。别导到一半以为卡死了就强退 —— 中途退出通常要从头再导一次，等它跑完或让它继续在后台跑。

## 三、存一张单帧快照

成片里某一帧想要留作封面或分享，可以单独存成一张图片（快照）。存下来的就是普通图片文件，位置与导出文件一致，之后按普通图片使用即可。

## 四、换设备继续编辑，以及留底

官方列出的两条路用途不同，别混着用：

| 你的目的 | 用哪条 |
| --- | --- |
| 换一台设备接着剪同一个项目 | 把项目发到另一台设备 |
| 只想留一份底，防项目丢失 | 归档项目 |
| 想拿进桌面剪辑软件继续做 | 安卓版官方清单里没有列出来，需要以官方说明为准 |

这里有一个容易踩的点：**归档的是项目，不是素材**。项目文件记录的是「哪段素材、从哪一秒到哪一秒」，素材本身还在原来的位置。所以归档之后如果顺手把原素材删了，恢复回来也放不出画面。要真正留底，素材文件得另外备份一份，比如把整个素材文件夹拷到移动硬盘。项目、素材、成片这三样各自该怎么留，另开了一篇：[素材放在哪与误删了怎么办.md](素材放在哪与误删了怎么办.md)。

## 五、自动备份与误删恢复

项目有**自动的数据备份**。官方说明这份备份**只包含项目数据、不含素材**，项目被误删时可以从备份里恢复。它比手动留档省心，但别指望它连素材一起救回来。

即便如此，仍然建议：**每完成一个阶段的粗剪就归档一次**。手机上编辑到一半被系统清掉后台、或者误删了项目，归档过的损失会小很多。归档这件事不占空间太多，做起来也快。

## 六、导出失败或导出结果不对劲

三种现象，对应的原因通常不一样：

- **卡在某个进度不走** → 常见原因是时间轴引用了已经删掉的源文件，或有超大素材卡住了编码，先按第一节第二条第 2 点检查缺失媒体。
- **在别的设备上黑屏、或只有声音没有画面** → 多半是编码兼容问题，换一档导出设置（降分辨率或换格式）重导一次。
- **成片时长与预期对不上** → 检查时间轴末尾是不是残留了很短的片段。磁性时间轴的末尾本来就没有可见空隙，短片段容易看不出来。

逐条排查的做法见 [常见问题与排查.md](常见问题与排查.md) 的导出一节。
