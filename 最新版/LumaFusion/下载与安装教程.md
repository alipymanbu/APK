## 一、装之前先核对版本与设备门槛

LumaFusion 是 LumaTouch 出的移动端多轨视频剪辑应用。安卓与 ChromeOS 版是专门为这两个平台重做的独立版本（iOS 版是另一套），网盘里这份是安卓版，用来把手机或相机拍到的素材剪成成片。它适合剪什么、值不值得装，另有一篇专门讲：[适合剪什么样的片子.md](适合剪什么样的片子.md)。

照下面这张表对一遍。版本号、包名、安装包大小是这份安装文件本身的值，网上搜到的「最新版」通常已经是另一个版本号，不要拿它来核对。

| 项目 | 值 |
| --- | --- |
| 应用名 | LumaFusion（开发者 LumaTouch） |
| 包名 | `com.luma_touch.lumafusion` |
| 版本 | 1.0.68.4 |
| 安装包大小 | 55.07M |
| 安装包 MD5 | `FF650CAAEE0122A01FB5BA0398DAB605` |
| 系统要求 | 安卓 10 及以上，运行内存至少 3GB |
| 记录时间 | 2026-09-23 |

三条判断：

- **系统门槛是官方的硬限制，不是建议。** 官方对安卓版的要求是 Android 10 及以上、运行内存至少 3GB；低于这个门槛的设备在官方渠道里根本装不了。第三方的下载页面有时会写成「安卓 5.2 以上」这类更低的要求，那是页面模板，以官方页面的口径为准。
- **这是付费应用的安装文件。** LumaFusion 在官方渠道是一次性付费购买，网盘这份解决的是「把应用装进设备」这一步；应用内的可选付费组件仍按官方规则走，见 [安卓版和iOS版有什么区别.md](安卓版和iOS版有什么区别.md)。
- **存储要留出余量。** 安装包 55.07M，装完还会额外占用空间，再加上剪辑会用到的素材，建议至少留几个 GB 空闲。

## 二、从网盘把安装包取到手机

1. 打开 [LumaFusion 安装文件资源（夸克网盘）](https://pan.quark.cn/s/53aa9482ebf1)。
2. 先点「保存到我的网盘」，再从自己的网盘里下载。直接下载也能用，但转存之后，原分享链接哪天失效都不影响你。
3. 记下文件下载到了哪里，多数浏览器和网盘客户端会放在「下载」或「Download」目录。
4. 文件名以网盘里实际显示的为准，通常形如 `LumaFusion_v1.0.68.4.apk`。

打开链接提示失效、或要求提取码时，说明这条分享的当前状态变了，换最新的一条再试。

## 三、动手装之前校验一次安装包

大文件从网络传到手机，中途出问题就会在安装时报「解析包错误」。花半分钟验一次，比事后排查划算。

把 APK 拷到电脑上，在文件所在目录执行：

```powershell
certutil -hashfile "LumaFusion_v1.0.68.4.apk" MD5
```

输出的十六进制串去掉空格后，应当与第一节表里的 `FF650CAAEE0122A01FB5BA0398DAB605` 完全一致（大小写不敏感）。手机上用带 MD5 校验功能的文件管理器也能做同样的事。

对不上就重新下载一次，别将就着装。

## 四、先放行「安装未知应用」

网盘里的包不是从应用商店装的，安卓会默认拦一次。要先给「负责下载它的那个应用」开安装权限，各品牌路径不一样：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 权限管理 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装外部来源应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 生物识别和安全 → 安装未知应用 |
| 原生安卓 / 平板 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

路径记不住就在设置顶部的搜索框里搜「未知应用」或「外部来源」。关键是**找到下载这个 APK 的那个应用**（浏览器或网盘客户端），把它的开关打开。

## 五、安装与第一次启动

1. 从通知栏点刚下完的文件，或者打开文件管理器找到 `.apk` 点它。
2. 弹出安装界面点「安装」，等进度走完，桌面出现图标。
3. 首次启动会依次弹权限申请。这个应用要读写素材，真正影响功能的是这几项：

| 权限 | 不给会怎样 |
| --- | --- |
| 照片和视频 / 媒体（存储） | 选不到素材，导出的成片也存不出去 |
| 音乐和音频 | 导入音频、往时间轴上放音频会受影响 |
| 通知 | 只影响提醒，不影响剪辑 |
| 麦克风 | 只影响应用内的录音功能；不录旁白可以不签 |

具体弹哪几项、各自叫什么名字，以你手机上显示的为准，上表说的是它们各自的用途。

4. 第一次进去看到的是项目列表，此时还没有项目。下一步怎么建项目、怎么把素材导进来，见 [新建项目与导入素材.md](新建项目与导入素材.md)。

## 六、装不上、或者装完打不开

按顺序自查，比反复重装有效：

- 提示「解析包错误」「应用未安装」→ 回第三节重新校验 MD5，多半是文件没下完整。
- 提示「已被阻止安装」→ 第四节的权限没开，或者开给了错误的那个应用。
- 装好后点图标没反应、闪一下退回桌面 → 先确认系统满足安卓 10 与 3GB 运行内存，再按 [常见问题与排查.md](常见问题与排查.md) 的「闪退」一节排查。
- 提示空间不足 → 先腾出大于安装包的可用空间再试，安卓安装时会额外占一点余量。
- 装完打开是英文界面 → 界面语言跟随系统语言，把系统语言改成简体中文后再进一次即可。
