# LumaFusion 适合剪什么样的片子

> 本篇不讲操作，只回答一个判断问题：官方功能清单里有什么、没有什么，所以什么样的剪辑需求用它顺手、什么样的需求其实该换一类工具。

## 一、先看官方功能清单里有什么

把官方列出的功能按「你会做的动作」重排一遍，比读功能名更容易判断：

| 你常做的动作 | 对应的官方功能 |
| --- | --- |
| 把好几段素材按顺序排好、反复调 | 磁性时间轴 + 多轨（安卓版 6 条视频/图形轨 + 6 条音频轨） |
| 画面和声音分开处理 | 链接与断开、锁定、隐藏、静音 |
| 加转场、叠画面、抠绿幕 | 效果叠层、色度键与亮度键 |
| 调色、套 LUT | 调色工具、内置 LUT、导入 `.cube` / `.3dl`、示波器 |
| 让画面或参数随时间变 | 关键帧（贝塞尔缓动、速度斜坡属付费附加组件） |
| 让人声和音乐各就各位 | 音频轨、EQ、声像、自动闪避、画外音录制 |
| 做字幕和标题 | 多层标题、描边阴影、导入字体、标题预设 |
| 归档、换设备接着剪 | 项目归档、把项目发到另一台设备 |

这张清单的关键词是**手工决定**：剪哪一刀、哪段配什么效果、音量怎么走，都是你逐项定下来的。

## 二、清单里没有的东西

同样重要的是另一面。官方的功能清单里**没有**这几样：

- **没有模板市场，也没有「一键成片」**；
- **没有贴纸、素材包这类成品素材商店**（内容库只有 Storyblocks 的音乐、音效、视频素材订阅库）。

如果你的主要需求是「导入几段素材、套上现成模板、几分钟出一条竖屏短片」，那属于模板化工具的范畴，和这个应用的方向不是一条路 —— 它麻烦的地方恰好就是它要你自己做的那些决定。

## 三、按你的成片对一遍

| 你的成片主要是什么 | 用它的顺手程度 |
| --- | --- |
| 访谈、口播、教学、多机位活动记录 | 顺手：多轨、调色、混音、字幕这几块正好都用得上 |
| 旅行记录、Vlog 这类素材多、要精剪的 | 顺手：标记、多选、跨项目复制省掉大量重复操作 |
| 竖屏短片，但每一刀都想自己控 | 可以用：支持 9:16 项目，只是没有现成模板可套 |
| 竖屏短片，只求快，要模板和自动化 | 不顺手：这类需求用模板化工具更快 |
| 需要专业交付流程（多机位同步、拿到桌面软件里继续剪） | 覆盖不完全：安卓版官方清单里没有列出这些，以官方说明为准 |

## 四、动手前先接受两件事

- **它是付费应用的安装文件**，不是免费替代品。价格与可选内购见 [安卓版和iOS版有什么区别.md](安卓版和iOS版有什么区别.md)，装之前先按 [下载与安装教程.md](下载与安装教程.md) 核对设备门槛。
- **它有上手成本**。功能是按专业剪辑的思路组织的，官方清单里也没有模板和一键成片，所以第一次打开要自己从建项目、导素材开始做。官方提供了参考手册和教学视频，入口在 [常见问题与排查.md](常见问题与排查.md) 第七节。

判断完适不适合，具体操作从 [时间轴剪辑与轨道操作.md](时间轴剪辑与轨道操作.md) 开始往下走即可。
