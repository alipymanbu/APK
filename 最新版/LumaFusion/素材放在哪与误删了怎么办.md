# LumaFusion 素材放在哪与误删了怎么办

> 本篇讲一件容易被忽略的事：项目里存的是素材的「位置记录」而不是素材本身，所以删了源文件、清了应用数据、拔了外接盘之后各会发生什么，以及项目、素材、成片这三样分别该怎么留底。

## 一、项目里存的是「位置」，不是素材

导入素材时，应用记下的是**这份文件在设备上的位置**，而不是把文件复制进自己的目录。理解这一条，后面所有情况都好判断：

| 你做了什么 | 结果 |
| --- | --- |
| 素材留在原处不动 | 正常，随时能剪 |
| 在相册或文件管理器里删掉源文件 | 时间轴上对应片段变成「缺失媒体」（红色条纹） |
| 把源文件移到别的文件夹 | 官方说多数情况下仍能找到；偶尔找不到，就得放回原来那个文件夹 |
| 清空应用数据 / 卸载重装 | 项目列表和项目数据可能一并没了；素材本身在系统里不受影响 |

所以「保存项目」和「保住素材」是两件事，不能互相代替。

## 二、三样东西要分开留底

很多人以为归档一次就全都留住了，其实要分成三份看：

| 要留住的东西 | 谁在管 | 怎么留 |
| --- | --- | --- |
| 项目（剪辑点、效果、音频设置） | 应用自己，外加自动备份 | 定期归档；误删时从自动备份恢复 |
| 素材原文件 | 你的相册、文件管理器或外接盘 | 自己备份，应用不管 |
| 成片 | 你导出的那个文件 | 导出后自己另存一份 |

关键在第二行：**官方说明自动备份里只有项目数据，不含素材**。备份能帮你找回「剪到哪一步了」，但找不回已经被删掉的视频文件。

## 三、最常见的两种「丢」

**第一种：剪到一半，相册清理把源文件删了。** 手机上有些清理工具和"重复文件整理"功能动作很激进，剪一个项目期间随手清一次，第二天回来时间轴上全是红条纹。稳妥的做法只有一条：**项目没导出之前，别把用到的素材移出原位**。想省空间，先导出成片，再清理。

**第二种：换设备，以为新设备上能接着剪。** 发到另一台设备的只是剪辑信息；如果新设备上没有同一批素材文件，打开还是缺失状态。要跨设备接着剪，得把**项目和素材一起**弄过去，而且素材要放在新设备访问得到的位置。具体走法以官方说明为准。

## 四、外接盘上的素材要格外小心

外接盘上链接进来的文件夹，成立的前提是那块盘一直连着。拔盘、换线、换盘这类操作之后，时间轴上的片段通常马上就会变成缺失状态（官方描述这时库会出现提示条，片段带红色条纹）。

长期用外接盘剪同一个项目，把这几条当规矩：

- 每次用**同一块盘、同一根线**，官方恢复流程里也特意强调了「用正确的那根 USB-C 线」；
- 收工时先退出应用再拔盘，别在读取过程中断开；
- 换盘之前先导出一版成片，或者把这次要用的素材先复制到设备里。

## 五、留底这件事的最小做法

不用做得复杂，三条就够：

1. **项目一成型就归档一次**，不用等全部剪完；
2. **素材原文件在项目导出之前不删、不移位**；
3. **成片导出后另存一份**到与设备无关的地方（云盘或电脑）。

这三条做到，「手机丢了 / 相册被清了 / 手滑点删除」都不会让你彻底丢掉东西。
