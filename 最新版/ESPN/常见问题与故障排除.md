按「装 → 开 → 看 → 推」的顺序排：先安装阶段的问题，再启动与播放，最后是通知。逐条对号，不用从头读到尾。

## 一、安装类

**点 APK 没反应或提示「解析包失败」**

1. 先核对文件完整性：下载中断会得到一个残缺包，这是解析失败的头号原因。用下面的 MD5 命令核对，与 8.17.0 版安装包的 `1fcfa3bf7af5b7ce9ebfd954c62d3c48` 不一致就重新下载；
2. 存储空间不足也会报同样的错，清理出 500 MB 以上再试；
3. 安卓系统版本低于 8.0 时无法安装，只能先升系统（以官方应用商店标注的系统要求为准）。

**MD5 核对命令**（在 APK 文件所在目录执行）：

```powershell
# Windows（PowerShell）
certutil -hashfile "ESPN_v8.17.0.apk" MD5
```

```bash
# macOS / Linux
md5sum ESPN_v8.17.0.apk
```

**提示「不允许安装未知应用」后找不到继续安装的入口**：这是逐应用授权的机制，要给「打开这个包的应用」（文件管理器或夸克网盘）授权，各品牌的具体路径见[下载与安装教程](下载与安装教程.md)第三节。

## 二、启动与播放类

**打开就闪退**

1. 系统设置 → 应用 → ESPN → 存储 → 清除缓存后重试；
2. 仍闪退就清除数据（关注球队等本机设置会丢，登录账号的会保留）；
3. 你装的版本是 8.17.0（2026-09-23 采集口径）。故障依旧且官方已发布更高版本时，升级版本常能解决老版本的已知崩溃。

**直播黑屏、一直转圈**

1. 先确认授权状态：比分能看、直播看不了，多数是没走完授权。回[直播观看与账号登录](直播观看与账号登录.md)对照四条路径，确认自己该走哪条线；
2. 有订阅却被反复弹回登录页，优先怀疑走错了登录线（电视服务商线 vs Disney 账号线），换另一条重试，而不是反复输密码；
3. 部分赛事有地区限制，页面显示「此内容在你所在地区不可用」属版权限制，不是故障。

**视频加载慢**

- 直播画质可在播放器设置里手动调低，网络波动时先降画质保流畅；
- 集锦类短视频卡顿多与本机网络有关，切换 Wi-Fi / 移动数据对比一下。

**登录一直失败**

1. 把手机的日期与时间设成「自动」——系统时间不准会让授权校验失败，这是容易被忽略的一步；
2. 清缓存后完全退出应用（不是退到后台）再登录一次；
3. 走一遍完整刷新：退出登录 → 升级到最新版 → 重启手机 → 重新登录；
4. 仍失败就按[直播观看与账号登录](直播观看与账号登录.md)第三节核对登录线与登录态时效，确认没有开着 VPN、也没有多台设备在同时播放。

**电视上看不了、投屏没画面**

- 先确认手机与电视接收端连的是同一个 Wi-Fi、接收端在支持列表内，完整排查见[投屏与电视观看](投屏与电视观看.md)；
- 投屏图标不出现时，多数是接收端设备不被支持或不在同一网络，而不是应用坏了。

## 三、通知类

**收不到开赛/得分提醒**

1. 系统设置 → 应用 → ESPN → 通知：确认总开关是开的；
2. 应用内设置 → 通知：开赛提醒、得分提醒、新闻推送是分开的项，逐项核对；
3. 确认球队还处于「已关注」状态——清数据或重装后本机的关注会丢，重新关注即可；
4. 省电策略激进的品牌（华为、小米等）要把 ESPN 加入后台白名单，否则后台被杀掉推送就断了。

## 四、账号与数据类

**换机后关注列表丢了**：新旧手机用同一个 ESPN 账号登录，关注与订阅状态随账号走；之前一直没登录账号的话，关注只存在本机，换机前没有迁移通道。

**订阅了却看不到对应内容**：先退登再重登刷新授权状态；仍无效则按[直播观看与账号登录](直播观看与账号登录.md)第三节核对登录线是否走对。以上都试过仍不行，问题出在账号侧，需要联系官方客服核对订阅归属。
