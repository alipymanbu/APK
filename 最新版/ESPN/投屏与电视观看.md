手机屏幕看比赛终归局促，把画面放到电视上是多数人的用法。ESPN 支持从手机把画面投到电视设备，部分智能电视也能直接装应用。投出去播放的仍然是你账号授权范围内的内容，直播要先把[直播观看与账号登录](直播观看与账号登录.md)里的授权走完。

## 一、投屏前确认三件事

| 检查项 | 要求 |
| --- | --- |
| 网络 | 手机与电视接收端连**同一个 Wi-Fi** |
| 接收端 | Chromecast 二代及更新、Nest Hub / Nest Hub Max、内置投屏功能的 Android TV 设备（以官方支持列表为准） |
| 发送端 | 手机已装 ESPN（安装见[下载与安装教程](下载与安装教程.md)）并能正常播放 |

## 二、手机投屏步骤

按 ESPN 官方支持页的口径，操作是四步：

1. 打开 ESPN，选中想看的内容；
2. 点**播放**；
3. 点播放器顶部的**投屏图标**；
4. 在列表里选择你的电视设备。

投屏开始后手机就变成遥控器，暂停、切换内容都在手机上操作；要断开时回到投屏图标里选择断开即可。

## 三、电视上直接装 ESPN

不想每次投屏的话，主流电视与盒子平台的应用商店里可以直接找 ESPN 应用——Roku、Fire TV、Apple TV、Android TV、主流智能电视品牌与游戏主机都有覆盖（具体收录以你设备的应用商店为准）。电视端用**同一个账号登录**，关注球队、订阅状态与手机端通用。

电视应用商店里搜不到 ESPN 时，多半是机型太老、系统版本过旧——这时手机投屏就是可用的替代路径。

## 四、电视端才有的几个小功能

- **从开头看**：对正在直播的订阅内容，电视端在节目块上呼出菜单可以选「从开头看」，迟到也不错过开局（部分设备不支持，以实际菜单为准）；
- **防剧透（Spoiler Settings）**：打算晚点看回放、又怕比分被剧透，电视端在 设置 → 视频设置 → Spoiler Settings 里可以隐藏实时比分；
- **接着看（Continue Watching）**：点播内容看到一半退出，换台设备用同一账号登录，能从上次的位置继续。

这些功能的可用范围随版本调整，以应用内实际显示为准。手机端的画中画等播放小功能见[使用教程与常用功能](使用教程与常用功能.md)；投屏黑屏、找不到投屏图标这类问题，排查动作在[常见问题与故障排除](常见问题与故障排除.md)。
