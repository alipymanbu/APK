ESPN 是 ESPN Inc（迪士尼旗下）的体育应用，比分、新闻、赛程、视频集锦和赛事直播都在一个应用里。本篇按安卓手机的实际安装过程来讲，遇到装不上的情况直接翻[常见问题与故障排除](常见问题与故障排除.md)。

## 一、安装前先确认三件事

| 检查项 | 要求 | 说明 |
| --- | --- | --- |
| 系统版本 | Android 8.0 及以上（以官方应用商店页面为准） | 系统过老会在安装阶段直接解析失败 |
| 剩余空间 | 安装包约 100 MB，安装后占用更大 | 建议预留 500 MB 以上 |
| 网络 | 能正常联网 | 安装本身不需要，但首次启动要联网加载内容 |

安装包本身免费，比分和新闻功能不需要付费；直播和大部分点播视频则需要订阅或电视服务商授权，那部分内容见[直播观看与账号登录](直播观看与账号登录.md)。

## 三、允许安装未知来源应用

不是从应用商店装的包，安卓默认会拦一道。Android 8.0 之后权限不再按全局开关，而是**按来源应用逐个授权**：

1. 点开 APK 时系统弹窗提示「不允许安装未知应用」→ 点「设置」；
2. 找到你用来打开这个 APK 的应用（通常是**文件管理器**或**夸克网盘**）；
3. 打开它「允许安装未知应用」的开关，返回后继续安装。

各家手机入口略有差异，找不到弹窗入口时可以从系统设置进：

- **小米 / Redmi**：设置 → 隐私保护 → 特殊权限 → 安装未知应用；
- **华为 / 荣耀**：设置 → 安全 → 更多安全设置 → 安装外部来源应用；
- **OPPO / vivo / 一加**：设置 → 应用管理 → 特殊应用权限 → 安装未知应用；
- **三星**：设置 → 应用 → 右上角菜单 → 特殊权限 → 安装未知应用。

若手机还弹「外部来源应用安全检查」之类的二次确认，勾选已了解风险后放行即可——这是系统对所有非商店安装包的统一提醒，不代表这个包有问题。

## 四、首次启动

装好后第一次打开，应用会让你做两件事：

1. **选主队与联赛**：按你关注的运动（橄榄球 NFL、篮球 NBA、棒球 MLB、冰球 NHL、足球英超/欧冠等）勾选喜欢的球队，首页比分与新闻会按这个排；
2. **通知权限**：允许通知后，关注的球队开赛、得分、终场都会有提醒；跳过的话之后在系统设置 → 应用 → ESPN → 通知里也能补开。

此时不需要登录任何账号就能看比分、新闻和部分视频；想看直播再按[直播观看与账号登录](直播观看与账号登录.md)里的路径走。
