# 悬浮窗权限开启方法（各品牌手机路径对照）

> Stargate 的联机信息层和深空Aurora 的游戏内工具都靠悬浮窗显示，而悬浮窗权限是安卓的「特殊权限」，各品牌入口不一样。本篇给出逐品牌路径，以及权限开了却看不到悬浮窗的排查。

「游戏里看不到联机悬浮窗」这个现象，八成不是软件坏了，而是系统没给「显示在其他应用上层」的权限。这个权限不在应用的普通权限列表里，藏得深、名字多（悬浮窗 / 出现在顶部 / 显示在其他应用上层），下面按品牌对号入座。

## 一、各品牌手机的开启路径

| 手机系统 | 入口路径 |
| --- | --- |
| 通用安卓（多数机型适用） | 设置 → 应用 → 特殊应用权限 → 显示在其他应用上层 |
| OPPO / 一加 / 真我（ColorOS 13 及以上） | 设置 → 应用 → 特殊应用权限 → 悬浮窗 |
| OPPO / 一加 / 真我（ColorOS 12 ~ 12.1） | 设置 → 应用 → 悬浮窗 |
| OPPO / 一加 / 真我（ColorOS 7 ~ 11） | 设置 → 应用管理 → 悬浮窗管理 |
| 华为 / 荣耀（HarmonyOS / EMUI） | 设置 → 应用和服务 → 权限管理 → 在「应用」或「权限」页签里找到悬浮窗 → 把 Stargate（及深空Aurora）设为允许 |

菜单名称会随系统版本调整，上表截至 2026 年 9 月，以你手机实际显示为准。给权限时 Stargate 和深空Aurora 两个应用都要给——联机状态显示和游戏内工具分别走这两个应用。

## 二、找不到开关时的两个通用办法

1. **用系统设置里的搜索栏**，直接搜「悬浮窗」或「显示在其他应用上层」，搜到的开关页里找到 Stargate 打开。
2. **从应用信息进**：桌面长按 Stargate 图标 → 应用信息 → 权限（或「特殊访问权限」）→ 找悬浮窗相关开关。

## 三、权限开了还是看不到悬浮窗

按顺序核对：

1. **游戏版本**：悬浮窗要求《我的世界》基岩版 1.0 及以上，旧于 1.0 的版本不支持。
2. **应用内开关**：Stargate 个人页面里有悬浮窗开关，确认它没被关掉——这个开关的作用就是在游戏里停用悬浮窗。
3. **客户端版本**：悬浮窗功能只在完整客户端里提供；点开悬浮窗页面是一片空白的，多数是装了精简版，换完整客户端。
4. **刚授权没生效**：从后台彻底划掉应用再重新打开，让权限重新加载。

还看不到的话，回到 [联机失败常见问题排查.md](联机失败常见问题排查.md) 第四节继续排查，或直接走官方渠道求助。

## 四、为什么建议装完就开

Stargate 从房间启动游戏后，房间与玩家状态要叠加显示在游戏画面上；配合深空Aurora 悬浮窗使用的，游戏内操作工具也在这一层。先开好权限再进房间，比进到一半退出来补权限省事得多；安装阶段的具体步骤见 [下载与安装教程.md](下载与安装教程.md)，悬浮窗对游戏版本的要求见 [我的世界版本兼容说明.md](我的世界版本兼容说明.md)。
