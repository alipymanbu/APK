# Stargate 支持的我的世界版本与联机协议

> 本篇讲 Stargate 能配哪些版本的《我的世界》联机：基岩版与口袋版的覆盖范围、1.20.62 之后的协议变化、口袋版要手动填虚拟 IP 的特殊情况。

联机搜不到房间，多数时候不是操作错了，而是两边版本没对上。Stargate 对《我的世界》手机版的版本覆盖比大多数联机工具宽，但不同版本段的玩法有差别，本篇把它讲清楚。

## 一、覆盖范围：基岩版（BE）与口袋版（PE）

Stargate 面向《我的世界》手机版（基岩版 / 旧口袋版），不面向 Java 版。按官方说明：

| 版本段 | 支持情况 |
| --- | --- |
| 基岩版（Bedrock Edition，BE） | 支持多版本联机，含 1.20.62 及以上的新联机协议（见下节） |
| 旧口袋版（Pocket Edition，PE） | 理论支持 0.1.0 到 1.1.7（口袋版的最后一个版本） |
| Java 版 | 不支持 |

也就是说，不管你手机里是近年更新的基岩版，还是留着怀旧的老口袋版，都在可联机的范围内；但**房主和加入者的版本必须一致**，一边 1.21 一边 1.19 是连不到一起的。

## 二、1.20.62 及以上：新联机协议，一般不用你操心

官方在 1.20.62 及以上的基岩版里改用了新的联机协议。Stargate 会自行判断你游戏用的是哪套协议，正常情况下你感知不到差别。

唯一需要你动手的情况：游戏启动太慢导致找不到联机房间。此时**退出去，从 Stargate 的房间重新启动一次游戏**即可，多数一次就能解决。

## 三、口袋版（PE）：要手动复制房主虚拟 IP

口袋版的联机协议与基岩版改动较大，不能全靠自动发现，流程多一步：

1. 房主建好房间后，把**房主的虚拟 IP** 复制发给要加入的好友（房间信息里能看到）。
2. 好友在我的世界里用「添加服务器」的方式，把这个虚拟 IP 填进去连接。

好在新版已经解决了口袋版和早期基岩版房间无法广播的问题，多数 PE 房间现在也能在列表里一键点击加入；**手动加 IP 是广播不生效时的兜底做法**。

## 四、和深空Aurora 悬浮窗配合使用

- Stargate 兼容深空Aurora 的悬浮窗功能：游戏里那个叠加在画面上的操作层由 Aurora 侧提供，联机状态由 Stargate 提供，两个一起用互不冲突。
- 悬浮窗要求基岩版 1.0 及以上，并需要给应用「显示悬浮窗 / 在其他应用上层显示」权限。
- 不想看到悬浮窗的话，在个人页面有悬浮窗开关，可以选择在游戏里不启用。
- 用悬浮窗里会改动世界的功能（如速建、存档编辑）之前，先看悬浮窗界面里的「必看提示」：官方对速建的说明是效果不可撤回，使用前多备份存档。

## 五、装了多个我的世界（共存版）怎么办

共存版玩家（一台手机装多个我的世界）记得在 Stargate 设置里关掉「自动拉起游戏」，不然每次从房间启动，它都会打开默认那个，而你想玩的可能是另一个。关掉后你自己手动开游戏，联机状态照样生效。

版本对上了但房间还是进不去，转到 [联机失败常见问题排查.md](联机失败常见问题排查.md)；建房流程不熟的回 [创建房间与好友联机教程.md](创建房间与好友联机教程.md)。
