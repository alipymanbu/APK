联机失败的表现就那几种，但原因各不相同。先在下面的对照表里找到你的症状，再按对应小节逐项排查，多数问题两三分钟就能定位。

## 一、症状对照表

| 症状 | 最可能的原因 | 先看哪节 |
| --- | --- | --- |
| 房间列表里找不到好友的房间 | 版本不一致 / 房间没公开 / 启动迟滞 | 第二节 |
| 进房后频繁断线 | 网络不稳 / 后台占用 | 第三节 |
| 能玩但延迟很高 | 房间成员网络距离远 | 第三节 |
| 游戏里没有悬浮窗 / 开悬浮窗闪退 | 权限没给 / 游戏版本低于 1.0 / 精简版客户端 | 第四节 |
| 登录环节卡住 | 注册方式或账号问题 | 第五节 |

## 二、搜不到房间、好友进不来

按顺序核对：

1. **双方 Stargate 版本一致**。版本不同可能导致搜不到对方的房间，所有人和房主统一用同一个版本。
2. **双方游戏版本一致**。我的世界一边 1.21 一边 1.19 连不上；版本覆盖范围见 [我的世界版本兼容说明.md](我的世界版本兼容说明.md)。
3. **房间状态与密码**。房主确认房间是公开状态、密码没改过；加入方确认输入的密码正确。
4. **从房间重新启动游戏**。1.20.62 以上版本用了新联机协议，游戏启动太慢会找不到房间，退出去从 Stargate 的房间再启动一次。
5. **口袋版走手动 IP**。PE 房间广播不生效时，让房主把虚拟 IP 发给你，在我的世界里添加服务器连接。
6. **账号侧的多人权限**。微软官方帮助文档把「多人游戏权限」列为加入他人世界失败的检查项之一：受家庭组管理的儿童 / 青少年账号，需要家庭组织者在微软账号的家庭设置里允许其加入多人游戏。如果你用的账号是这类账号且怎么都进不了联机，先检查这一项（以微软账号的家庭设置页面实际显示为准）。

## 三、频繁断线、延迟高

这两类基本都是网络侧的问题，逐项试：

- **换稳定网络**：联机时连 WiFi，别用信号飘忽的移动数据；房主的网络质量决定全房间的下限。
- **清后台**：关掉抢带宽的应用（视频、下载类），断线次数会明显下降。
- **延迟高看房间构成**：你和房间内其他玩家的网络距离越远延迟越高，换一个成员地理上更近的房间，或干脆自己建房把好友拉进来。
- **房主重进**：房间里其他人正常、只有你断，退房重进一次；反复断就重启游戏再进。

## 四、游戏里看不到悬浮窗、或开悬浮窗就闪退

1. 确认给了 Stargate / 深空Aurora「显示悬浮窗 / 在其他应用上层显示」权限；各品牌手机的入口不一样，逐品牌路径见 [悬浮窗权限开启方法.md](悬浮窗权限开启方法.md)。
2. 悬浮窗要求基岩版 1.0 及以上，旧于 1.0 的游戏版本不支持。
3. 确认个人页面里的悬浮窗开关没有被关掉（这个开关就是用来在游戏里停用悬浮窗的）。
4. 悬浮窗页面打开是空白的，多数是因为用的是精简版客户端——悬浮窗只在完整客户端里提供，换完整客户端才有。
5. 授权后仍闪退的，先从后台彻底划掉应用重开一次；还是闪退，就核对自己的游戏版本与系统版本是否在支持范围内，然后走官方群反馈。
