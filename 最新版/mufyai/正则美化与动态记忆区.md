## 一、正则替换是干嘛的

官方文档给的定义一句话：**「当 AI 输出某段内容时，系统自动把它替换成你设定好的内容」**。它是建卡侧的功能，普通聊天用不到，但做角色卡的人绕不开。官方列的四个用途：

| 用途 | 你得到什么 |
| --- | --- |
| 美化输出 | 状态栏、地图组件、表情包、模拟小手机这类界面效果，不用让 AI 自己输出整段代码 |
| 过滤文本 | 拦截不想看到的思维链、设定泄露段落 |
| 省钱提速 | 代码预置在系统里，AI 只输出关键文本，输出 token 变少，等待时间同步变短 |
| 上手门槛低 | 官方提供「AI 一键生成指令」，把想要的效果描述出来让 AI 帮你写正则 |

第 3 条对普通用户也有意义：输出 token 变少，单轮消耗的额度就少——消耗口径见 [罐头消耗与会员订阅.md](罐头消耗与会员订阅.md)。

## 二、动态记忆区：官方给的现成方案

官方文档站有一篇「动态记忆区」案例，把记忆拆成三档自动维护：

- **关键里程碑**——重大事件单独记录；
- **短期记忆**——每轮对话总结一条；
- **长期记忆**——每五条短期记忆归纳成一条。

实现方式：建卡时用正则拦截 AI 输出的记忆字段（目标字符是 `<KeyMilestones>` / `<LongTermMemory>` / `<ShortTermMemory>` 这样的结构），替换成你自己的界面组件。官方文档附了完整的「目标字符 → 替换字符串」示例，照抄改配色就能用。实际效果是隔几天回来，角色能接着之前的话题与关系继续聊；有商店资料提到还支持跨角色引用同一事件、信息保持一致，以你自己的实测为准。

## 三、在哪学与常见坑

- 官方文档站 [docs.mufy.ai](https://docs.mufy.ai)，相关章节：「快速认识正则」「创建一条正则」「管理正则条目」「常见问题」「AI 一键生成指令」，2026 年仍在更新；
- 正则管「界面怎么显示」，记忆本身存什么还是要靠设定——固定人设写进世界书，自动沉淀交给记忆区，两者互补，世界书写法见 [角色创建与世界书设定.md](角色创建与世界书设定.md)；
- 正则条目在建卡侧创建与管理，改坏了会直接让输出格式错乱，先备份当前条目再动手。
