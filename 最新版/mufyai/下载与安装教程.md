## 一、装之前先确认三件事

| 检查项 | 说明 |
| --- | --- |
| 设备 | 安卓手机。各应用市场对系统版本标注不一（安卓 4.3 至 4.5 以上都有），以实际安装时的提示为准 |
| 存储空间 | 本地采集的安装包标注大小约 1.17M，安装后另占数据空间，留 1GB 以上余量比较稳妥 |
| 已装过同类变体 | 这个应用在不同市场存在包名不同的变体（如 `com.mufy.ai`、`com.chat.mufy.ai`）。之前装过其中任何一个，建议先卸载再装，避免签名冲突导致安装失败 |

本文涉及的版本信息：v4.1.9，包名 `com.mufy.ai`，安装包 MD5 为 `AFB0F8AB649FFE09E480FF62234B0DA6`。

## 二、获取安装文件

安装包不在应用商店走常规分发，而是放在网盘里，通过夸克网盘分享链接获取：

1. 打开上面头部的 **mufyai 安装文件资源（夸克网盘）** 链接；
2. 把分享里的安装包**转存到自己的网盘**，再从网盘客户端下载到手机；
3. 下载完成后在通知栏或文件管理器里找到 `.apk` 文件。

转存后下载比直接下载更稳，分享链接过期风险也更低——这是网盘分发的常规用法。

## 三、安装步骤

1. 点开下载好的 `.apk`，系统会提示「禁止安装未知来源应用」；
2. 按提示跳到设置页，允许**该来源**（浏览器或文件管理器）安装应用，不同品牌手机入口略有差异：小米在「特殊应用权限 → 安装未知应用」，华为在「更多安全设置 → 外部来源应用下载」，其余品牌一般弹窗里直接有「设置」入口；
3. 回到安装页点「安装」，等待完成；
4. 点「打开」进入应用。

## 四、第一次打开

1. 阅读并勾选用户协议与隐私条款（「同意事项」）；
2. 进入登录页：可以注册新账号、用谷歌账号登录，部分版本提供游客模式先试用；
3. 登录后即可进入角色列表挑角色开聊。注册方式、谷歌登录和账号管理的细节单独写在 [注册登录与账号管理.md](注册登录与账号管理.md)。

## 五、安装环节常见报错

| 现象 | 原因与处理 |
| --- | --- |
| 提示「解析包时出现问题」 | 多为下载不完整。回网盘重新下载一次，核对文件 MD5 是否为 `AFB0F8AB649FFE09E480FF62234B0DA6` |
| 「安装」按钮点不动 | 检查是否已允许未知来源；部分机型需关闭「纯净模式」或「应用行为记录」后再装 |
| 提示签名冲突 / 应用未安装 | 之前装过包名不同的旧变体，卸载后重装 |
| 装完打不开、闪退 | 系统版本过旧或内存不足，重启手机再试；仍闪退则确认系统是否满足最低要求 |

装好并且登录成功后，如果对话过程中遇到回复异常、记录不同步这类问题，翻 [常见问题与对话调试.md](常见问题与对话调试.md)；想先弄清聊多少要不要花钱，看 [罐头消耗与会员订阅.md](罐头消耗与会员订阅.md)。
