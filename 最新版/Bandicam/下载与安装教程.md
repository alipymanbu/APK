网盘里这份 Bandicam 是安卓端的手机录屏与视频编辑工具：点一下开始录，录完能在应用里裁剪、变速、加字幕。本篇只做一件事——把这份包装进手机、确认版本对得上，并让你录出第一段能正常保存的视频。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本信息通常是别处收录的最新版，而网盘里这份是制作文档时核对过的版本，两者未必同一个版本号。本文所有版本号、包名、体积都以下表为准：

| 应用名 | Bandicam |
| 版本号 | 1.1 |
| 包名 | `chen.ban.tam` |
| 安装包体积 | 68.74 MB |
| MD5 | `C6D5E7059F0CCAEAF10BBB9193D61C83` |
| 界面语言 | 中文 |
| 收费情况 | 免费，含应用内购买 |
| 系统要求 | 见下文说明 |

关于版本号：这一版编号是 `1.1`，属于该应用在安卓端的早期编号。别处页面上的版本号常常更高，有的干脆是把桌面版 Bandicam 的号段抄了过来——**认包不能看版本号，要看包名**，理由见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

关于系统要求：随包的应用信息页写的是「需要支持安卓系统 5.2 以上」。安卓的正式发行版本里并没有 5.2 这一档（5.0、5.1 之后直接跳到 6.0），这里按信息页原样照录，**实际能不能装，以手机能不能解析这个安装包为准**（判断方法见第三节第 4 步）。

## 二、装之前要核对的两件事

**第一，别和同名的包装混。** 这份包的包名是 `chen.ban.tam`。带 Bandicam 名字的安装包在网上来源很杂，包名未必相同；包名不同的两个包，系统会当成两个互不相干的应用，**不能互相覆盖安装**，录制的视频和设置也各算各的。如果你手机上已经装过一个，先看清它的包名再决定留哪一个——查看方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 第三节。

**第二，先留够空间。** 安装包本身 68.74 MB，装完还要占更多；录屏产生的视频也在这个空间里，长视频按分钟数累积。装之前确认剩余空间充足。

想顺手校验下载的包有没有传坏，可以在电脑上算一遍 MD5，结果应当与上表一致：

```cmd
certutil -hashfile Bandicam_v1.1.apk MD5
```

（文件名随版本变化，以网盘里你实际看到的名称为准。）

## 三、安装步骤

1. **转存并下载**：从 [Bandicam 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7da72b27c95a) 把 APK 转存到自己的网盘，再下载到手机或电脑。
2. **把包送到手机上**：手机端直接下载最省事；在电脑下载的话，用数据线或文件传输工具把 APK 拷进手机存储。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统这项开关常收在「安全」或「隐私」分类下。
4. **点击 APK 完成安装**：系统若提示「应用未经过安全检测」或「来自未知来源」，选择继续安装即可，这是侧载安装包的常规提示。如果提示的是「解析包错误」，多半是文件没下完整，回到第一步重新下载完整包。
5. **回装低版本要先卸载**：安卓不允许用更低的版本号覆盖已装的更高版本，会直接报「应用未安装」。手机里已有更高版本时，先卸载旧版再装。
6. **装完先别急着点开**：先把下一节的授权与权限过一遍，否则第一次录制容易白录。

## 四、第一次打开要过的三处

1. **授权录屏**：点录制按钮后，系统会弹一个「开始录制或投放」（不同系统措辞略有差别）的授权窗，必须点允许才能开始。多数系统每次重新开录都会再弹一次，有的新系统会给你「不再询问」的选项。
2. **给存储权限**：应用要读写手机存储才能把视频存进相册。第一次保存时如果被拦下，在「设置 → 应用 → Bandicam → 权限」里把存储权限打开。
3. **定好录制参数**：分辨率、帧率、比特率在录制前设置，录完再改只能重录。各项怎么选见 [录屏画质与录制参数怎么调.md](录屏画质与录制参数怎么调.md)。

## 五、装完做一次最小验证

1. 打开应用，点录制按钮，确认能通过系统的授权窗并进入录制状态；
2. 随便操作十几秒后停止录制，确认应用里能看到这段视频；
3. 点应用中间的「编辑」图标，选中刚录的视频，确认能进入编辑界面（裁剪、变速、字幕都在这里）；
4. 编辑完点右上角「确定」，确认视频能在手机相册里找到。

四步都通，说明安装与权限都到位了。中途卡在哪一步，对照 [录制没声音与常见问题排查.md](录制没声音与常见问题排查.md) 对应的小节处理。
