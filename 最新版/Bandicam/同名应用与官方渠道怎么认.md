# Bandicam 同名应用与官方渠道怎么认

「Bandicam」这个名字在两个平台上指的是两套不同的东西：一个是很多人熟悉的电脑端录屏软件，另一个是你手机上这份安卓录屏应用。两者不是同一款产品，界面、按钮和操作也对不上。这篇先帮你把身份认清楚，再给认包的三项硬指标。

## 一、同一个名字下其实是两套东西

| 对比项 | 电脑端 Bandicam | 手机端这一份 |
| --- | --- | --- |
| 形态 | Windows / macOS 桌面程序 | 安卓应用（APK） |
| 包名 | 桌面程序没有安卓包名一说 | `chen.ban.tam` |
| 界面 | 工作台式窗口，分屏幕录制 / 游戏录制 / 设备录制几种模式 | 一个主界面加一个录制按钮，中间是「编辑」入口 |
| 录制对象 | 电脑屏幕、PC 游戏、外接摄像头与采集卡 | 手机屏幕 |
| 版本号 | 按年份命名，如 Bandicam 2025、2027 | `1.1` |

电脑端 Bandicam 由开发 Bandicam 与 Bandicut 的 Bandicam Company 出品，其官网常见问题里明确写着：目前只提供 Windows 和 macOS 版本，**没有 Android 或 iOS 版本**，要在手机上录制，官方给的办法是把手机画面投到电脑上再录。也就是说，你手上这份安卓应用，和电脑端那款不是同一条产品线。

由此带来一个很实际的后果：**网上搜到的「Bandicam 教程」绝大多数讲的是电脑端**——里面会出现 DirectX / OpenGL / Vulkan 游戏录制、采集卡与 MHL 线、定时录制、设备录制模式这类内容，你在手机上按图索骥是找不到对应按钮的。反过来，电脑端用户也不该拿本套文档去操作桌面版。这套文档从头到尾只讲手机这一份。

## 二、认出这一份的三项硬指标

| 指标 | 值 | 能不能靠它认人 |
| --- | --- | --- |
| 包名 | `chen.ban.tam` | 能，唯一且不随版本变 |
| 安装包大小 | 68.74 MB | 只能辅助，换版本就变 |
| MD5 | `C6D5E7059F0CCAEAF10BBB9193D61C83` | 能，前提是和你手上这个文件对得上 |
| 版本号 | 1.1 | 只能辅助，别处标的常是另一个数 |

结论：**以包名为主**，大小和 MD5 对得上就基本确定是同一份文件；版本号是次要的，理由见第四节。

## 三、怎么查手机上装的那一份的包名

1. 打开「设置 → 应用 → 全部应用」（有的系统叫「应用管理」）。
2. 找到 Bandicam，点进「应用信息」。
3. 部分系统在应用信息页能直接看到包名；看不到的，用带包名查看功能的文件管理器或应用信息类工具查。

拿到的包名不是 `chen.ban.tam`，说明你装的是另一个同名的东西，往后遇到的所有问题都不是这套文档在讲的那个应用的问题。

## 四、版本号对不上不代表选错了

网盘里发出去的是 `1.1`，而你在别处可能看到「8.x」「最新版」这类标注，原因有三个：

- 分发页把电脑端的号段和手机端的号段写在了一起；
- 各站收录的版本本来就不一样；
- 应用内有更新提示，点了就会换成新版。

这三种情况版本号都会变，包名不会。看到「版本不一致」时先核对包名，再对一次大小和 MD5，别急着卸载重装。

**想保持在 `1.1` 这一版**，就别点应用内的更新提示——更新之后版本会变，本套文档里关于界面与操作步骤的描述也就未必还对得上。

## 五、入口与官方渠道分别在哪儿

- **手机这一份**：不在 Google Play 上架，属于要自备安装包侧载的应用。安装包从本篇开头给的 [Bandicam 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7da72b27c95a) 取，装完按 [下载与安装教程.md](下载与安装教程.md) 核对一遍包名与 MD5。
- **电脑端 Bandicam 的官网**：国际站 [www.bandicam.com](https://www.bandicam.com/)，中文站 [www.bandicam.cn](https://www.bandicam.cn/)（中文名「班迪录屏」）。这两个站点只提供电脑端软件与教程，**不提供手机安装包**，别去那里找安卓版。
- **手机自带录屏**：安卓 11 起系统内置了屏幕录制，通常在从屏幕顶部下拉的快捷设置面板里能找到「屏幕录制」磁贴。不想装第三方应用也能录，区别在于没有应用内的参数项和剪辑功能。
