# 签名会与抽签活动参与方法

> 本篇讲 WITHMUU 上粉丝签名会（FAN SIGNING）与抽签活动（LUCKY DRAW）怎么报名：买哪类商品才算报名、中签怎么公布、视频通话与线下签名各有什么规矩、报了名还能不能退款。

## 一、报名的本质是「在活动期内买指定商品」

签名会与抽签活动的报名入口不是单独的表单，而是**活动专用商品**：

1. 活动页（商品名常带 `[OFFLINE FANSIGN]` 或 `[FAN SIGNING]` 前缀）标明报名窗口，常见为 3~4 天，以「**支付完成时间**」为准；
2. 在窗口期内下单购买指定的专辑（通常规定「多版本中任选 1 种以上」）；
3. 活动结束后从购买者中**电脑随机抽签**，人数从几十人到一百多人不等，每场公告写明。

两个官方写明的坑：

- **必须买「报名专用」的那款商品**。官方公告明确说过：买成同专辑的普通商品不算报名，下单前核对商品名；
- 同一订单买多张能叠加的只有**报名者特典**（见第五节），中签与否与购买数量无关——名额是抽出来的，不是买出来的。

## 二、中签怎么公布

- 中签名单发布在官网「EVENT – 당첨자 발표（中签者发表）」公告板，公告时间写在中签者公告里（如报名结束次日下午）；
- 名单以「姓名打码 + 联系电话后四位 + 生日后四位」形式公示，核对自己那一条；
- 中签者的活动地点、入场时间等细节**单独通知**，走报名时填写的电话与邮箱——这也是报名信息必须填对的原因。

未中签没有补偿，官方公告也写明不接受未中签申诉。

## 三、视频通话签名会的规矩

部分签名会以视频通话形式进行（不出席现场），官方公告里的关键条款：

| 条款 | 内容 |
| --- | --- |
| 通话工具 | 以每场公告为准，常见是 KakaoTalk 视频通话，部分场次支持 WeChat（微信） |
| 账号要求 | 只能用报名时填写的 ID 拨打，**报名后不可更换**；填的 ID 必须能被好友搜索到（不是邮箱），且与手机号绑定一致 |
| 通话时长 | 每人约 1 分钟上下，具体以公告为准 |
| 接听纪律 | 叫号后**两次未接**即失去资格 |
| 签名范围 | 只能签在主办方指定页；签名专辑在通话结束后单独寄出 |
| 其他在场人 | 通话中出现非本人介入，工作人员有权强制结束 |

报名时就要装好对应 App 并确认账号可用——通话用的 ID 报名后改不了，临时换号等于弃权。

## 四、线下签名会的规矩

线下场（대면，面对面）的通用条款，同样以每场公告为准：

- **入场前 1 小时**开始核验身份、发号码牌（现场抽签定顺序），提前 30 分钟入场；
- **必须携带本人实名证件原件**：外国人用护照（或外国人登录证），且报名填写的姓名要与证件拼写完全一致；成年人的学生证不被认可；证件照片、复印件、App 电子证件都无效；
- 名额**不可转让**，代购报名可以，但到场必须是中签者本人；借他人名义入场会被直接请出；
- 信件与签名会小道具在身份核验时统一收取，活动后未领取的会丢弃，不支持转交；
- 只能签在**主办方现场提供的专辑**的指定页，自带物品一律不签；
- 现场禁止拍摄、录音，手机与蓝牙耳机、智能手表等要寄存在场外，私自携带被查出会要求删除记录后离场。

## 五、报名者特典与发货

- 报名期内在活动页购买，全员有**报名者特典**，通常是平台独占的自拍小卡（随机 1 种，按购买数量 1:1 追加，单张订单买到 6 张以上通常不重复），特典只在报名窗口内有效；
- 活动商品的发货**整体押后**：官方写明活动结束后统一发出，加上特典备货，工作日 10 天以上属正常预期，与普通预购的发货节奏不同；
- 想要特典但不想赌签名的，也可以只参加纯抽签活动（LUCKY DRAW）——机制相同（活动期内买指定商品 → 抽特典），但没有身份核验与到场环节。

## 六、退款规则：报名商品不是普通商品

这是报名前最该想清楚的一条，官方公告原文口径：

- 报名目的购买的商品，**报名截止后不接受单纯变心退款**——中签与否都不退；
- 报名截止前可以取消，但取消即**退出抽签**；
- 未中签不退款，钱换来的商品照常发货，外加全员特典。

所以参与签名会的正确姿势是：先确认活动当天的到场/接听条件（护照等证件是否齐备、通话时段自己能不能守在手机前），再下单。活动商品与普通商品在退换上的差异，也印证了[配送与退换货规则](配送与退换货规则.md)里「详情页标明不可退换的商品不予退换」那条。

## 七、报名前查什么

每场活动的条款都以**当次公告**为最终依据，报名前把这几项核对完：

1. 报名窗口与支付完成时点；
2. 指定商品与版本（是不是报名专用款）；
3. 中签者公告时间与活动日期（韩国时间）；
4. 视频/线下形式的账号与证件要求；
5. 报名者特典的发放期。

下单、支付环节的口径不变，见[专辑与周边购买流程](专辑与周边购买流程.md)；对报名资格或订单有疑问直接走客服（[常见问题解答](常见问题解答.md)第六节有联系方式），公告板也会集中回复活动相关问题。
