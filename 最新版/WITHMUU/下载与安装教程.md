## 一、你要装的是什么

WITHMUU（韩文写作 위드뮤）是韩国 Copan Global（㈜코팬글로벌）运营的 K-POP 追星商城，卖专辑、官方周边（MD）、应援棒，也办粉丝签名会与抽签活动。你在这里安装的是它的安卓客户端，装好后可以直接在手机上下单商城里的商品。App 默认是韩文界面，设置里可以切换成中文，中文用户用起来不需要先学韩文。

本次安装包的基本信息如下，涉及版本号的描述都以这一份为准：

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.1.2 |
| 安装包大小 | 4.17M |
| 包名 | `com.withmuu.mobileapp` |
| 系统要求 | 安装包信息标注为 Android 5.2 以上 |
| MD5 | `A85AD78C6A7DF6EC6B18C83031340415` |

官方后续会出新版本，本篇不会跟着更新，届时以你实际拿到的安装包为准。

## 二、获取安装包

安装包放在夸克网盘里：[WITHMUU 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e174f48e3284)。

取包的路径是固定的三步：

1. 打开上面的网盘链接；
2. 把文件转存到自己的网盘（夸克分享必须先转存才能下载）；
3. 从自己的网盘把安装包下载到手机存储里。

手机上还没装夸克 App 的话，先去应用商店装一个，登录后再操作上面三步会顺畅很多。

## 三、安装步骤

安卓手机默认不允许安装应用商店以外的安装包，所以装之前要先给浏览器或文件管理器开一次「未知来源」权限：

1. 在文件管理器里找到刚下载的 `.apk` 文件，点它；
2. 系统弹出「出于安全考虑，手机不允许安装未知来源应用」之类的提示时，按提示跳转到设置页，允许该应用安装；
3. 回到文件管理器再点一次 `.apk`，等待安装完成；
4. 完成后点「打开」，或从桌面图标进入。

不同品牌的手机（小米、华为、OPPO、vivo 等）这个开关的位置各不相同，但都发生在「点 apk → 被拦截 → 去授权 → 重试」这个循环里，跟着系统提示走即可。装不上、一直转圈的情况多半是下载不完整，重新下载一遍安装包通常就能解决，更多排查思路见[常见问题解答](常见问题解答.md)。

## 四、第一次打开：先把语言换成中文

首次打开 App，界面大概率是全韩文。先做这一件事，后面所有的菜单才看得懂：

1. 找到设置入口（一般在「我的页面」，图标或文字是 설정 / Settings）；
2. 进入语言（언어 / Language）选项；
3. 选择中文。

具体菜单层级可能因版本而异，认准「언어 / Language」这个关键词即可。语言之外，注册账号、登录以及界面里各个韩文选项的对照，都整理在[注册登录与中文界面设置](注册登录与中文界面设置.md)里。

如果你是为了买专辑来的，直接看[专辑与周边购买流程](专辑与周边购买流程.md)，里面有下单、支付方式与预购特典的完整说明；先不急着花钱的话，把语言切好、注册好账号，剩下的慢慢看也行。
