## 一、这是什么，适合谁装

bbspace（中文名哔哔空间）是一个开源的第三方B站安卓客户端，项目地址在 [github.com/naaammme/bbspace](https://github.com/naaammme/bbspace)，采用 GPL-3.0 协议，与哔哩哔哩官方没有关系。它不通过应用商店分发，需要你手动下载 APK 安装。

适合的情况：

- 手机上想要一个占用小、启动快的B站观看客户端（1.7.32 版安装包约 6.35M）；
- 不想要开屏广告、首页推广位，只想安静看视频；
- 需要在一台旧手机或备用机上单独登一个B站账号。

不适合的情况：它不是官方客户端的替代品，点赞、投币、收藏这类交互功能并不完整（截至本文核对时官方仍在补全，以官方仓库的功能列表为准）。

## 二、获取渠道

两个渠道任选其一：

1. **官方发布页**：项目在 GitHub 的 [Releases 页面](https://github.com/naaammme/bbspace/releases) 持续发布新版本 APK，想要最新版从这里拿。
2. **夸克网盘**：[bbspace 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9cc0d46f5620)，打开后转存到自己的网盘即可下载。网盘里保存的是 1.7.32 这一版，版本信息见下文第四节。

## 三、系统要求与安装步骤

系统要求为 Android 7.0 及以上（以官方仓库说明为准）。安装包是标准的 APK 文件，安装流程：

1. 从上面任一渠道把 APK 文件下载到手机；
2. 在文件管理器里点开这个 APK；
3. 系统会提示「禁止安装未知来源应用」，选择允许来自此来源的应用（不同品牌手机的入口叫法略有差异，一般在弹窗里直接给开关）；
4. 回到安装界面，点「安装」，等待完成；
5. 打开应用，第一次进去是未登录状态，登录方法见 [登录与账号同步.md](登录与账号同步.md)。

安装前后可以核对两点信息，确认拿到的是同一个包：

| 项目 | 值 |
| --- | --- |
| 包名 | `com.naaammme.bbspace` |
| MD5（1.7.32 版） | `6B8E203605FFA48EA47E4ACB577841B6` |

## 四、网盘这一版与官方最新版的差异

网盘资源里保存的是 **1.7.32** 版（版本信息整理于 2026-09），而官方仓库一直在更新，写作本文时官方已发布到 1.8.x 系列。两类内容值得留意：

- 1.7.32 这一版自身的更新内容：番剧、影视这类有「集」的内容支持选集切换（PGC 选集）、评论 shadowban 检查、收藏夹详情页面，以及对弹幕显示的优化；
- 1.7.32 之后官方陆续加入的能力（如搜索历史、性能设置里的网络选项、图片评论、主题调色板风格调整等）在这一版里没有，具体以官方 [Releases 页面](https://github.com/naaammme/bbspace/releases) 的版本说明为准。

也就是说：想体验新功能就去官方 Releases 拿最新版；只想稳定看视频，网盘里的 1.7.32 也够用。

## 五、升级与卸载

- **升级**：下载新版 APK 后直接覆盖安装即可，不需要先卸载。
- **卸载重装**：卸载后登录状态会清掉，重新登录即可；观看历史这类记录跟随B站账号的云端数据，登录同一账号后会同步回来（详见 [登录与账号同步.md](登录与账号同步.md)）。
- 装完之后遇到打不开、闪退等问题，先看 [常见问题与解决办法.md](常见问题与解决办法.md)。
