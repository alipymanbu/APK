## 一、找视频：推荐流、搜索、稍后再看

- **首页**是推荐视频流，登录你的B站账号后，推的内容和官方 APP 是一套体系；
- **顶部搜索框**按关键词搜，结果里既有视频也有用户卡片；
- 刷到想看但没空的，可以丢进**稍后再看**，列表跟着B站账号走，在官方 APP 里加的也能在这里看到。

## 二、播放页里能调什么

进入播放页后，常用的几样都在播放器界面上：

| 操作 | 怎么做 |
| --- | --- |
| 切清晰度 | 播放器设置里选，可选档位取决于该视频的源 |
| 倍速播放 | 播放器设置里调 |
| 弹幕开关 | 播放页里直接关掉或打开弹幕显示 |
| 后台播放 | 切到桌面或锁屏后声音继续 |
| 听视频 | 只放音频，当播客听 |
| 小窗播放 | 应用内小窗，边刷别的边看 |

「其他应用占用了声音、后台播放被打断」这类情况的处理办法见 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 三、番剧、影视的选集

从 1.7.32 起（网盘资源里这一版就带），番剧、纪录片、影视剧这类有「集」结构的内容（官方叫 PGC 内容）在播放页里可以直接选集切换，不用退出去重新点进下一集。收藏夹详情页也是这一版加上的，把收藏夹当追更列表用比较顺手。

## 四、缓存与导出

- 视频支持**应用内缓存**，缓存下来离线看；
- 除了应用内缓存，还支持把视频或音频**一键下载导出**成文件，导出后的文件按你自己的习惯管理；
- 首次使用缓存或导出功能时，系统会申请存储权限，允许一次即可；
- 弹幕能不能跟着缓存文件走、导出文件的命名规则，不同版本行为有差异，以你手上的版本实际表现为准。

## 五、直播与弹幕

- 直播内容在这个客户端里能看；发送直播弹幕是较新版本才加入的能力，老版本（含 1.7.32）只能看不能发；
- 普通视频的弹幕显示、密度等设置在播放页和设置里都能调，具体见 [设置与个性化调整.md](设置与个性化调整.md)。

## 六、倍速、字幕与互动的现状

用之前先知道边界，免得用时才发现：

- **倍速档位**：常规倍速档为主，没有 2.5 倍这种细档位（官方 issues 里已有用户提出这个需求），实际可选档位以播放页显示为准；
- **字幕**：字幕功能在官方计划里标注为「正在补全」，看无内嵌字幕的生肉视频、依赖 CC 字幕的内容前先有预期；
- **点赞、投币、收藏**：截至本文核对时仍在补全中，能不能操作取决于你的版本。需要完整互动时，回到官方 APP——两边登的是同一个账号；
- **番剧、电影的收藏夹**：有用户反馈点开这类收藏夹会打不开（官方 issues 里该问题截至核对时仍未关闭），遇到时先从搜索或首页重新进入视频本身绕过去，并留意 issues 的修复进展。
