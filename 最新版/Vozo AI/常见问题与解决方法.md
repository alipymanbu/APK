## 一、安装与启动

| 现象 | 先查什么 |
| --- | --- |
| 点 APK 没反应 / 提示未知来源 | 在安装弹窗里允许本次安装；部分品牌要到「设置 - 安全」里开 |
| 装完打不开、秒退 | 手机剩余存储太小先清一点；重启再试一次 |
| 系统版本装不上 | 不同第三方页面的口径不一致（有写 Android 5.0+ 的也有写 10+ 的），别纠结这个数 —— 装不上就升级系统，或换官方应用市场的包再试 |

安装步骤的完整说明在 [下载与安装教程.md](下载与安装教程.md)。

## 二、字幕识别不准

识别不准分好几种症状，各自的对策不一样：音源问题、歌词模式留空白段、专有名词全错，都集中在 [歌词模式与识别不准怎么办.md](歌词模式与识别不准怎么办.md) 里按症状对照处理。通用的两条：先降噪再识别（见 [字幕样式与AI剪辑技巧.md](字幕样式与AI剪辑技巧.md) 第四节）；改完别整条重新识别，会把你的修改冲掉。

## 三、翻译与语言

- **找不到目标语言**：先翻「语种（地区）」二级方言选项；3.8.1 的官方口径是 118 种语言与方言，实际覆盖以你手头版本的应用内列表为准；
- **翻译腔重**：机器翻译的稿子值得人工过一遍再发，尤其是要给真人看的视频；人名、术语第一遍就改对，后面才不会一路错下去。

## 四、导入与导出

| 现象 | 排查 |
| --- | --- |
| 粘贴链接导入失败 | 链接对应的视频是否为公开状态，私密或已删除的视频导不了；重新复制一次完整链接再试 |
| 导出卡住 | 关掉后台大应用再导；长时间无进度就取消重导 |
| 导出后应用闪退 | 有用户反馈过导出后崩溃的情况，重启应用再试，仍复现就带上机型反馈给官方邮箱 |
| 只要字幕不要成片 | 导出选项里选 SRT，给桌面剪辑软件接续用 |

## 五、账号与版本差异

- **多设备同步**：登录同一账号后项目可同步；官方还有网页端，同一账号在电脑上接着处理，入口以应用内设置为准；
- **免费版与内购**：官方口径是免费下载、含应用内购买；有用户反馈免费版会看到广告、部分能力要付费解锁，具体额度与价格以应用内当时显示为准；
- **3.8.1 与官方现行版的差异**：截至 2026-09，官方市场页面的现行版本已到 5.x，陆续加入了数字人头像、配音、一键生成等能力。**网盘里这份 3.8.1 没有的功能，应用里不会有对应入口，别按新版教程找按钮**；想用新功能就走官方应用市场更新（包名一致，覆盖安装即可）。
- **反馈与条款**：官方反馈邮箱 `app-support@vozo.ai`（旧版资料里也见过 `blink-support@vozo.ai`，都试得到）；服务条款与隐私政策见官网（[服务条款](https://www.vozo.ai/blinkcaptions/terms) / [隐私政策](https://www.vozo.ai/blinkcaptions/privacy_policy)）。
