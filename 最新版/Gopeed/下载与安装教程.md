## 一、安装前先弄清的几件事

Gopeed 是 GopeedLab 维护的开源下载器（GPL-3.0 协议），同一套代码覆盖 Windows、macOS、Linux、Android、iOS、Web、Docker 等平台。本篇只讲安卓版。

安卓安装包是 `.apk` 文件。Gopeed 官方发布页对每个版本都会给出四种 APK：`universal`（全架构通用包）、`armeabi-v7a`、`arm64-v8a`、`x86_64`。分不清自己手机架构的话，直接用 universal 包最省事，缺点只是体积比单架构包大。

本文涉及的这份安装包信息如下（以包上标注为准）：

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.9.3 |
| 安装包大小 | 约 57.48 MB |
| MD5 | `DB813D1634B50EE809EB5CE475110D70` |
| 系统要求 | Android 5.0 及以上 |

版本号会随官方发版推进，最新进度以 [GitHub Releases 页面](https://github.com/GopeedLab/gopeed/releases)显示为准。

## 二、从哪里拿安装包

三个常用入口，任选其一：

1. **本文开头的 Gopeed 安装文件资源（夸克网盘）**：已经把 1.9.3 版的安装包转存好了，点开头链接转存到自己网盘再下载即可，不用翻发布页找历史版本。
2. **官网**：打开 [https://gopeed.com](https://gopeed.com)，页面会按你的设备自动给出对应版本，Android 一栏选 `APK`。
3. **GitHub Releases**：打开 [https://github.com/GopeedLab/gopeed/releases](https://github.com/GopeedLab/gopeed/releases)，每个版本下挂有各平台安装包，安卓选 `apk` 后缀的文件。

官方安装文档明确提醒过：尽量从官网或 GitHub 官方仓库这类渠道获取安装包，避开来路不明的第三方站点。无论从哪个入口拿到的包，都可以用 MD5 校验工具核对上面表格里的 MD5 值，确认文件没有在传输中被改动。

## 三、安装步骤

1. 把 APK 文件下载到手机存储里。
2. 在文件管理器里点这个 APK。第一次装会弹「未知来源」或「允许安装未知应用」的提示，这是安卓对非应用商店安装的正常拦截：到系统设置里给**你用来打开 APK 的那个应用**（文件管理器或浏览器）授予权限，再返回重试。
3. 等安装进度走完，点「打开」或回桌面点图标启动。

几个常见的安装失败场景：

| 现象 | 原因与处理 |
| --- | --- |
| 提示「应用未安装」 | 之前装过别的签名的 Gopeed（比如从不同渠道拿的包），先卸载旧版再装 |
| 安装到一半中断 | 存储空间不足，清理后重试；57 MB 的包加上安装展开实际要留更多余量 |
| 下载后点不开 APK | 文件没下完整，重新下载并核对 MD5 |

安装环节卡死在其他报错上，可以到[常见问题与解决方法.md](常见问题与解决方法.md)对号入座。

## 四、首次启动建议动的地方

Gopeed 装完直接就能用，但有两处先设置一下，后面会少很多麻烦：

- **下载目录**：进设置里的下载配置，确认默认保存位置。放在你常用文件管理器能方便看到的位置（比如 `Download/Gopeed`），后面清文件、拷文件都方便。
- **同时下载任务数与连接数**：默认值对直链下载够用；如果你主要拿来下 BT，可以参考[BT磁力下载慢怎么提速.md](BT磁力下载慢怎么提速.md)再调。

界面语言默认跟随系统，设置里也可以手动切换，另有暗色主题可选。这几项都是个人偏好，不影响功能。

装完之后下一步就是加任务。能下什么类型的链接、每种链接怎么发起任务，看[支持哪些下载协议.md](支持哪些下载协议.md)；想让它接管浏览器里的下载，看[扩展安装与浏览器接管.md](扩展安装与浏览器接管.md)。
