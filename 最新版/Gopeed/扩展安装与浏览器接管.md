## 一、扩展解决什么问题

原生协议（HTTP、BT、磁力、ed2k）只能下「直链类」资源。而网盘分享链接、视频站页面这类地址，直接贴进新建任务是下不动的——真实文件地址藏在页面逻辑后面，需要先解析。

Gopeed 的扩展机制就是补这层的：每个扩展对应一类站点或服务，装上之后把相应链接贴进任务框，扩展会解析出可下载的文件清单。扩展用 JavaScript 编写、以去中心化方式分发，任何人都能为某类站点写一个。

扩展商店（[https://www.gopeed.com/store](https://www.gopeed.com/store)）里的典型品类（截至 2026 年 9 月）：

| 品类 | 代表扩展 | 说明 |
| --- | --- | --- |
| 视频站 | Youtube、哔哩哔哩、Twitter、TikTok | 下视频或合集，部分高清档需要配置账号 Cookie |
| AI 模型 | Huggingface 下载 | 模型与数据集文件，支持断点续传 |
| 代码托管 | GitHub Release、GitHub 仓库下载 | Releases 资产、仓库目录批量下载，可配 Token |
| 网盘 | 百度网盘、夸克网盘等 | 解析网盘链接或自己账号里的文件 |
| 文件床 | Gofile、Pixeldrain、MediaFire | 解析分享页拿到直链 |

商店里能装哪些、各扩展当前版本与用法，以商店页面实时显示为准——扩展更新很勤，旧教程里列的清单很快过时。

## 二、在应用里装扩展

1. 打开 Gopeed，进应用内的**扩展**页（安卓版在底部导航的「扩展」标签；桌面版在设置里的扩展中心）。
2. 从扩展商店或扩展的 GitHub 主页拿到安装地址（一般是 GitHub 仓库链接）。
3. 在扩展页粘贴地址安装；已装的扩展在这里升级、停用或卸载。
4. 装完回到主界面，贴对应站点的链接建任务，能解析出文件清单就说明扩展已生效。

两个使用注意：

- **按需装**。扩展只在你贴「它能处理的链接」时才介入，平时不碍事；但装太多会让任务解析变慢，留常用的几个就好。
- **看扩展自己的主页说明**。比如网盘类扩展通常要求先在扩展设置里登录对应账号 Cookie，视频类扩展的高清档位同样如此。每个扩展的主页（商店里能跳转 GitHub）都写了用法，装之前扫一眼能省掉大半疑问。

## 三、浏览器下载接管

Gopeed 另有一个**浏览器扩展**（区别于应用内的站点扩展），作用是接管浏览器自带的下载：在 Chrome、Edge、Firefox 里点任何下载链接，任务会转给 Gopeed 来下，走多线程下载并由统一的任务列表管理。

浏览器扩展的仓库与安装说明在 [https://github.com/GopeedLab/browser-extension](https://github.com/GopeedLab/browser-extension)，按页面指引从应用商店安装即可。

装好后有一个关键配置：打开浏览器扩展的设置页，启用 **Remote Download** 并指向本机运行的 Gopeed（桌面端默认本地地址即可），浏览器才会把任务递过去。官方在 Flathub 页面特意提醒过这一点——不设 Remote Download，接管不会生效。

安卓端用不上这条：浏览器扩展是桌面浏览器的东西，手机上你直接复制链接贴进 Gopeed app，效果等同。

## 四、扩展不生效的快速排查

- **贴了链接没反应**：确认装的是对应站点的扩展，且扩展处于启用状态；一个扩展只管一类站点。
- **解析失败**：部分扩展要求配置登录 Cookie（网盘、高清视频类常见），进扩展设置补配置。
- **扩展需要更新**：站点改版后旧扩展会集体失效，到扩展页升级到最新版，或到该扩展的 GitHub 页面确认是否还在维护。
- **装不上**：确认地址是扩展的 GitHub 仓库（或其发布的安装包）地址，别贴成别的东西。

排查到任务层面的失败（比如下载中途中断、速度为零），移步[常见问题与解决方法.md](常见问题与解决方法.md)；BT 类任务的提速是另一套思路，在[BT磁力下载慢怎么提速.md](BT磁力下载慢怎么提速.md)。
