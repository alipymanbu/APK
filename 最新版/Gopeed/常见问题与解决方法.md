## 一、安装类问题

**提示「应用未安装」或装到一半失败**

先卸载设备上已有的 Gopeed 再装。不同渠道拿到的包签名可能不一致，签名对不上时系统会直接拒绝覆盖安装。之后按[下载与安装教程.md](下载与安装教程.md)第三节的步骤重来，并用 MD5 核对安装包完整性（本文开头资源那份包的 MD5 为 `DB813D1634B50EE809EB5CE475110D70`）。

**安装时被系统拦「未知来源」**

这不是 Gopeed 的问题，是安卓对所有商店外安装包的统一拦截。到系统设置里给打开 APK 的那个应用（文件管理器/浏览器）授予「安装未知应用」权限。

**iPhone / iPad 能装吗**

iOS 版只有 `.ipa` 文件，官方说明需要自行签名安装（官方文档推荐的是 TrollStore 方案）。App Store 上没有——按官方说法，苹果审核不允许带 BitTorrent 功能的应用上架。iOS 用户装不上属于渠道限制，不是操作问题。

## 二、下载类问题

**磁力链接一直卡在「获取元数据」**

BT 网络里找不到活跃节点。处理顺序：确认 DHT 开启 → 删掉任务重新添加 → 补充 tracker（方法见[BT磁力下载慢怎么提速.md](BT磁力下载慢怎么提速.md)第二节）。都没用就是资源本身凉了，换源。

**下载速度为零或反复中断**

分两种：BT 任务先看可用节点数，直链任务先查连接数与代理设置。逐项排查的完整流程在[BT磁力下载慢怎么提速.md](BT磁力下载慢怎么提速.md)，直链类把连接数调小反而能解决「服务器拒绝高并发」导致的失败。

**切走一会儿任务就停了**

这是被系统从后台清理了，不是任务出错。按[后台下载被系统清理怎么办.md](后台下载被系统清理怎么办.md)把电池优化、后台限制逐项解除；重开应用后任务还在，点继续就接着下。

**任务文件名识别错了**

有用户反馈过这类情况：个别链接的文件名解析出来不对（乱码或与实际不符）。在任务创建页直接手动改名即可，下载内容不受影响。

**任务中断后要重来吗**

不用。直链任务支持断点续传，重新添加同一条链接会接着已下载的部分继续；BT 任务重新添加后也会校验已有数据。下载到一半手动暂停的任务，点继续即可。

**下载的文件去哪了**

任务详情里能看到保存路径；默认目录在设置的下载配置里改。找不到文件时优先在任务详情里看路径，别凭印象翻文件夹。

## 三、设置类问题

**界面是英文的怎么改**

设置里有语言选项，切到简体中文即可；不设置时默认跟随系统语言。暗色主题也在同一处设置里。

**代理怎么配**

设置里支持 HTTP 代理、SOCKS5 代理、跟随系统代理三种。需要让下载流量走特定网络环境时才配置；日常直连就保持关闭——代理对 BT 速度影响明显（原因见[BT磁力下载慢怎么提速.md](BT磁力下载慢怎么提速.md)第五节）。

**怎么彻底删掉一个任务**

任务列表长按（或右侧菜单）删除。删除时可选择是否同时删除已下载的文件——只清任务记录、保留文件是常用选项。

## 四、进阶用法速览

**远程管理下载任务**

Gopeed 对外提供 RESTful API 与 Web 界面。桌面/Web 版开启后，你可以在同一局域网的任何设备上用浏览器打开它的端口（默认 `http://localhost:9999`，Web 版部署时自行指定）管理任务。公网部署时官方明确要求开启身份认证，否则任何人都能控制你的下载。

**命令行调用**

除图形界面外还有命令行版本（依赖 Go 环境，`go install github.com/GopeedLab/gopeed/cmd/gopeed@latest`），适合在服务器或脚本里直接下载。日常手机用户用不到，知道有这条路即可。

**更多扩展玩法**

站点类资源（网盘、视频站）下不动时，先去[扩展安装与浏览器接管.md](扩展安装与浏览器接管.md)看有没有现成扩展——多数「下不了」的反馈，答案在那边而不是设置里。

软件本体还没装的，从[下载与安装教程.md](下载与安装教程.md)开始；协议与链接类型的对照在[支持哪些下载协议.md](支持哪些下载协议.md)。
