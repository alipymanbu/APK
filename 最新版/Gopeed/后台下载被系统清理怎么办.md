# Gopeed 后台下载被系统清理怎么办

> 下载到一半锁屏或切走、回来发现任务停了——这多半是手机系统把 Gopeed 从后台清掉了。本篇给出按品牌排查的系统设置清单。

## 一、先明确：这不是 Gopeed 的 bug

安卓从系统层面对后台应用做省电管控，国产厂商系统尤其激进——下载器、导航、音乐这类「需要持续后台联网」的应用是重点清理对象。专门收录这类问题的 [dontkillmyapp.com](https://dontkillmyapp.com/) 把三星、小米等品牌列为清理后台最激进的厂商之列；华为、荣耀的官方支持页也明确承认「应用无法在后台运行（播放、下载、更新等）」是省电优化策略所致，并给出了解除方法。

判断方法很简单：任务停在原地、通知也没了、重新打开应用后任务还在但需要手动继续——这就是被系统清理了，去按下面的设置解除限制。

## 二、所有品牌通用的两步

无论什么手机，先做这两步（菜单名在不同系统上略有差异，含义相同）：

1. **把 Gopeed 排除出电池优化**：系统设置 → 应用 → Gopeed → 电池，选「无限制」（部分系统叫「不优化」「允许后台活动」）。这是安卓官方给应用「持续后台运行」的正规通道，dontkillmyapp 的通用方案第一步就是它。
2. **多任务卡片加锁**：打开 Gopeed，进入多任务界面，把它的卡片下拉（部分品牌是长按）出现锁标志。加了锁的卡片在一键清理时会被跳过。

另外两个习惯性动作：省电模式/超级省电开着时后台联网会被大幅限制，挂机下载期间先关掉；别用「一键清理」顺手把 Gopeed 划掉。

## 三、按品牌补充设置

通用两步不够时，各品牌还有自己的一层（以下路径来自各厂商官方支持页与 dontkillmyapp，随系统版本可能变化）：

| 品牌 | 要动的地方 |
| --- | --- |
| 华为 / 荣耀 | 设置搜「应用启动管理」→ 关闭 Gopeed 的自动管理 → 勾选「允许后台活动」；设置搜「电池优化」→ 所有应用 → Gopeed 设为「不允许」（即不做优化）；电池 → 更多电池设置 → 开「休眠时始终保持网络连接」 |
| 小米 / Redmi / POCO | 应用信息 → 自启动打开；省电策略改为「无限制」 |
| 三星 | 设置 → 电池 → 后台使用限制，把 Gopeed 从「睡眠中」「深度睡眠」列表里移除 |
| OPPO / vivo / 一加 | 应用信息 → 电池 → 允许后台运行/不优化；部分系统有「应用速冻」，把 Gopeed 排除 |

找不到对应开关时，直接到 [dontkillmyapp.com](https://dontkillmyapp.com/) 选你的品牌，按它的图文说明走。

## 四、移动数据与休眠断网

后台下载还有两个容易被忽略的断点：

- **智能省流量 / 后台数据限制**：华为、荣耀的「智能省流量」会阻止应用在后台用移动数据，系统设置的流量管理里关闭它，或单独给 Gopeed 放行「后台数据」。只准 Wi-Fi 下载的话，睡前挂着 Wi-Fi 下即可。
- **休眠断网**：部分系统在灭屏一段时间后切断网络。华为/荣耀在「更多电池设置」里的「休眠时始终保持网络连接」就是管这个的；其他品牌在电池或 Wi-Fi 高级设置里找类似开关。

## 五、真被清掉了，损失多大

Gopeed 对任务进度做了持久化：应用被杀或重启后，重新打开它，任务列表还在，未完成的任务从已下载的部分继续，不会从头再来。所以后台被清的代价是「要手动点一下继续」，而不是数据全丢。

大文件挂机下载的稳妥姿势：按上面二、三节设置好之后，保持充电器插着、Wi-Fi 连着，锁屏挂机——这是下载器类应用在安卓上的标准用法。下载中的其他问题去[常见问题与解决方法.md](常见问题与解决方法.md)；速度本身上不去看[BT磁力下载慢怎么提速.md](BT磁力下载慢怎么提速.md)。
