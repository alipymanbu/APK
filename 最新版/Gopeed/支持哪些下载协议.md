## 一、协议总览

Gopeed 原生支持四类链接，点主界面右下角的「+」新建任务时，把链接贴进去它自己会识别类型：

| 协议 | 输入形式 | 典型用途 |
| --- | --- | --- |
| HTTP / HTTPS | `http://` 或 `https://` 开头的直链 | 软件安装包、压缩包、网盘导出的直链 |
| BitTorrent | `.torrent` 种子文件 | 大文件分发、资源合集 |
| Magnet（磁力） | `magnet:?xt=urn:btih:` 开头的链接 | 不用下种子文件，直接下 BT 资源 |
| ed2k | `ed2k://|file|...` 开头的链接 | 电骡资源网络 |

粘贴链接即可发起；BT 任务除了贴磁力串，也可以选择本地 `.torrent` 文件。ed2k 覆盖的是相对小众的场景，链接本身可用时流程与 HTTP 一样。协议支持清单以官方页面当前显示为准。

超出这个清单的站点（各类网盘、视频站等）不是协议问题，而是站点需要单独解析——这要靠扩展解决，见[扩展安装与浏览器接管.md](扩展安装与浏览器接管.md)。

## 二、HTTP / HTTPS 直链

直链下载是 Gopeed 用得最多的场景。新建任务时除了贴链接，还能改这些参数：

- **保存位置**：任务创建页可以单独指定这次存到哪。
- **连接数**：同一个文件开多少个并发连接分段下载。默认 16，上限 256，社区经验是按 2 的幂取值（16、32、64…）。服务器不限制的话，调大连接数经常能明显提速，但个别站点会对单 IP 的高并发限流甚至拒绝，遇到 403 或反复失败反而要调小。
- **HTTP 请求字段**：任务创建页还能改这次请求的头字段。有防盗链的直链（部分网盘导出链、图床外链）会校验 Referer 或 Cookie，缺了就返回 403——在这层把字段补上，往往就是「浏览器能下、下载器报错」的解法。
- **文件重命名**：任务创建页直接改文件名。

直链下载支持断点续传：任务中断后重新添加同一条链接，能从已下载的部分继续。这也是很多人把浏览器里下不动的大文件「复制链接→贴进 Gopeed」重下的原因。

## 三、BT 种子与磁力链接

BT 任务和直链的逻辑完全不同：速度不取决于你的连接数，而取决于**有多少人在给你上传**（做种数）、tracker 与 DHT 的连通情况。

Gopeed 的 BT 栈覆盖了这些环节，设置里对应可查：

| 机制 | 作用 | 对你的影响 |
| --- | --- | --- |
| DHT | 无 tracker 也能找到同行者 | 磁力链接能否动起来的关键，保持开启 |
| PEX | 已连接的节点互相交换同伴 | 冷门资源多一条找人的路 |
| uTP / WebTorrent | 兼容更多客户端类型 | 提高与对方连通的概率 |
| UPnP | 自动在路由器上开端口 | 家用网络下减少「端口不通」导致的低速 |
| tracker 列表自动更新 | 每天自动拉取最新的 tracker 列表 | 不用手动维护 tracker |

磁力链接刚开始会先「获取元数据」——这一步是在向其他节点询问资源信息，做种少的时候可能卡很久甚至一直不动，属于 BT 本身的特性，不是软件坏了。冷门资源的应对办法集中在[BT磁力下载慢怎么提速.md](BT磁力下载慢怎么提速.md)里。

任务创建页里 BT 任务可以勾选要下载的文件——种子合集里只要其中一两个文件时，把其余的取消勾选即可，不用整包都下。

## 四、ed2k 链接

ed2k 是电骡网络的链接格式，形如 `ed2k://|file|文件名|大小|哈希|/`。把整条链接贴进新建任务框即可。ed2k 资源的可用性完全取决于该文件在电骡网络里的来源数量，目前新资源越来越少，这个协议更多是用来接手历史收藏的老链接。

## 五、协议之外：站点类资源的下载

「能贴链接」和「能下某网站的资源」是两回事。网盘分享、视频站页面这类地址直接贴进去通常下不了——它们需要先解析出真实文件地址。Gopeed 把这层能力做成了扩展机制：装对应站点的扩展后，这类链接就能解析成可下载的文件清单。

哪些站点有现成扩展、怎么装，见[扩展安装与浏览器接管.md](扩展安装与浏览器接管.md)；安装包还没装的话，从[下载与安装教程.md](下载与安装教程.md)开始。
