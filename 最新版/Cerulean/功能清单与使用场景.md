## 一、先说清单的口径

Cerulean 的定位是把几十个平时用得着、又不值得单独装一个 App 的小工具收进一个应用里，界面就是工具入口的排列，点哪个进哪个。公开收录页对它的工具数量说法从「二十多项」到「五十多项」都有，因为不同版本收录的工具不一样——下面的清单按类别列出多个来源反复出现的工具，**你手机里那份的入口名称与数量以实际列表为准**。

部分工具藏在「工具箱」的二级目录里（即工具箱里面还有一层工具箱），主界面上找不到的工具先进那一层看看。

## 二、图片与文字类

| 工具 | 你会在什么场景用到 |
| --- | --- |
| 表情包制作 | 给现成图片加字、套热门表情模板，聊天斗图用 |
| 图片拼接 | 多张截图连成一张长图，比如聊天记录、攻略连载 |
| 九宫格切图 | 把一张图切成九份发朋友圈 |
| 图片打码 | 截图里要挡住头像、单号、金额时用 |
| 图片水印 | 给图加署名或标注，防止直接搬运 |
| 文字识别（OCR） | 把截图、拍照里的文字提出来变成可复制的文本 |
| 文字转语音 | 把一段文字读出来，做提示音、念稿 |
| 取色器 | 从一张图里取出具体色值 |
| 二维码生成 / 扫描 | 把一段文字或链接做成二维码给别人扫 |
| 网页长截图 | 把整个网页存成一张长图（部分版本提供） |
| 汉字数字大小写转换 | 填合同、报销单时要写「壹仟贰佰」这类大写金额 |

图片类工具（拼接、九宫格、表情包、网页长截图）的具体操作步骤单独写在 [图片拼接与表情包制作.md](图片拼接与表情包制作.md)。

## 三、测量与感知类

| 工具 | 你会在什么场景用到 |
| --- | --- |
| 直尺 | 手边没尺子，量个小物件的长度 |
| 量角器 | 量角度；这类工具通常会调用摄像头辅助对准 |
| 分贝仪 | 看看当前环境有多吵，给个参考数值 |
| 心率检测 | 用摄像头贴手指估测心率，数值只能当参考 |

测量类工具都依赖手机传感器，精度不能拿去和专用仪器比，量个大概够用就行；分贝仪没数值、心率测不出这类问题多半是权限没给，见 [常见问题排查.md](常见问题排查.md)。想给分贝仪的读数一个参照：有用户实测口径是普通办公环境约 58dB、音箱放歌时约 75dB，你的读数和场景对得上就说明工作正常。

## 四、时间与显示类

| 工具 | 你会在什么场景用到 |
| --- | --- |
| 全屏时钟 | 旧手机横过来当桌面钟，数字 / 模拟两种样式，可切 12 / 24 小时制 |
| 手持弹幕 | 全屏大字滚动，接机、演唱会应援、隔着桌子传话 |
| 倒计时 / 番茄时钟 | 厨房计时、学习计时 |

这两个显示类工具的参数设置与场景细节（钟面样式、旧手机当桌面钟、弹幕更醒目的调法）单独写在 [全屏时钟与手持弹幕怎么用.md](全屏时钟与手持弹幕怎么用.md)。

## 五、计算与查询类

| 工具 | 你会在什么场景用到 |
| --- | --- |
| 计算器 | 日常加减乘除 |
| 随机数 | 抽签、抽奖、选择困难时替你做决定 |
| BMI 计算器 | 算身体质量指数 |
| 日期计算 | 两个日期之间隔了多少天、倒数日 |
| 汇率换算 | 出境前大概换算一下物价（汇率数据是否实时以应用内显示为准） |
| 亲戚关系计算 | 过年遇到不认识的亲戚，算出该叫什么 |

## 六、网络与其他类

| 工具 | 你会在什么场景用到 |
| --- | --- |
| 网络测速 | 换了 Wi-Fi 或换了运营商套餐，测一下实际速率 |
| 来电模拟 | 定时弹出一个来电界面，聚会想脱身时给自己找台阶；接听后的界面与声音跟随系统设置，可提前录好「电话那头」的声音 |
| 翻译 | 简单的即时翻译，不用专门装词典应用 |
| 位置信息 | 看自己当前的经纬度、海拔、城市编码 |

来电模拟的完整设置流程与注意点（倒计时触发、预录语音、先演练一次）单独写在 [来电模拟怎么用.md](来电模拟怎么用.md)。

## 七、装好之后从哪进

安装包从 [下载与安装教程.md](下载与安装教程.md) 走网盘获取即可。第一次进应用建议先扫一遍工具列表，把常用的留着眼熟——用不上的入口不用管，不影响其他工具使用。某项工具的行为和预期不符时，先去 [常见问题排查.md](常见问题排查.md) 对照一遍再下结论。
