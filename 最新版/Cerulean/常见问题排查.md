## 一、权限类：工具打开没反应，先看权限

Cerulean 里的测量与保存类工具依赖手机传感器和存储，权限没给是最常见的「看起来坏了」。

| 症状 | 多半是哪个权限 | 处理 |
| --- | --- | --- |
| 分贝仪打开无数值、不动 | 麦克风 | 设置 → 应用 → Cerulean → 权限 → 允许麦克风 |
| 心率检测测不出 | 摄像头 | 允许摄像头；手指要完全盖住镜头与补光灯 |
| 量角器画面黑屏 | 摄像头 | 允许摄像头后重进工具 |
| 图片保存成功但相册看不到 | 存储 / 照片 | 允许存储权限后重新保存一次 |

安卓各品牌的权限入口叫法略有差异，有的在「应用管理 → 权限管理」，有的在「隐私 → 权限管理」，认准应用名即可。给完权限如果工具还是没反应，把它从后台划掉重开一次。

另外建议：量角器、心率这类会占用摄像头/麦克风的工具用完就从后台划掉，不让镜头保持占用，也避免下次打开时传感器状态异常。

## 二、识别类：文字识别不准怎么办

识别结果乱、漏字、整段丢失，按这个顺序调整：

1. 换更清晰的原图——截图优于拍照，拍照时对焦清楚、光线充足；
2. 把图先裁剪到只剩文字区域，去掉无关背景；
3. 避开艺术字体、手写体和低对比配色（浅灰字配白底），这类内容识别正确率天然低；
4. 分辨率过低的旧截图（比如被转发压缩多次的）直接重截原始页面，比反复识别强。

## 三、保存类：拼接、加字后的图去哪了

正常流程下成品保存在相册（部分机型在「Pictures」或应用同名子目录）。相册找不到时：

1. 先用文件管理器搜图片日期当天新增的图片文件，确认到底存没存上；
2. 存上了但相册不显示，是相册应用没刷新，重启手机或等一会儿再看；
3. 根本没存上，回到第一节的存储权限问题。

## 四、工具对不上号：找不到某个功能

- 不同版本收录的工具数量与名称有差异，主界面没有的先进「工具箱」二级目录；
- 确认自己那份的版本信息，与文档基准对照，方法见 [版本与包名差异说明.md](版本与包名差异说明.md)；
- 功能的对应场景参考 [功能清单与使用场景.md](功能清单与使用场景.md)。

## 五、安装与重装

安装环节的问题（未知来源拦截、风险提示框、空间不足）在 [下载与安装教程.md](下载与安装教程.md) 第三节都有对应处理。应用反复闪退、数据异常时，重装的顺序是：卸载 → 重启手机 → 重新从 Cerulean 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/ad2cf8905274](https://pan.quark.cn/s/ad2cf8905274) 下载 APK → 安装 → 按第一节把权限给齐。重启这一步别省，安卓清理残留的旧数据经常需要它。
