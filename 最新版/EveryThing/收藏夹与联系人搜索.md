## 一、收藏夹（底部第一个页签）

刚装好时这一页是空的，中间显示 `No favorite found`，说明你还没收过东西。

- **能收的不只文件**：官方功能清单里，文件、文件夹、应用、联系人都能标成收藏。
- **怎么加**：在搜索结果或列表里走长按 / 三点菜单里的「添加到收藏夹」；已装应用要在 Applications 页加，入口见 [应用备份与卸载.md](应用备份与卸载.md)。
- **怎么用**：以后打开应用直接停在这一页，不用把关键词再敲一遍。
- **怎么取消**：长按收藏列表里的条目看有没有移除项。不同版本入口不一样，实在找不到就回到原条目，把收藏标记去掉。

## 二、通讯录搜索（底部第四个页签）

官方列出的可搜字段：姓名、备注、邮箱、电话、邮寄地址、所属组织。

- 只记得邮箱后缀或公司名，也能把人搜出来，不必先翻通讯录列表。
- 搜到后可以直接查看联系人、拨号或发短信，不用切到系统通讯录再找一遍。
- 前提是给了通讯录权限；没给的话到 设置 → 应用 → EveryThing → 权限 里允许，否则这一页也是空的。

## 三、这两页什么时候派上用场

| 你的情况 | 用哪一页 |
| --- | --- |
| 同一个表格每周都要开 | 收藏那个文件夹，下次一点直达 |
| 装了一批同类工具，常用就两三个 | 把常用的收藏，其余留在 Applications 页 |
| 记不全名字，只记得公司或邮箱 | 通讯录页按字段搜 |
| 换了新手机 | 收藏不会跟过去，见 [常见问题排查.md](常见问题排查.md) 第五节 |
