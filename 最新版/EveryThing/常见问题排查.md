## 一、搜索结果是空的

按顺序排查，走到哪一步解决了就停：

1. **权限没给**（最常见）：设置 → 应用 → EveryThing → 权限，确认存储 / 文件访问是允许；改完把应用彻底退掉再重开。首次启动那次权限请求点了拒绝，就会是这个表现。
2. **筛选器还开着**：漏斗处于选中状态时只显示该类型，先把筛选取消。
3. **SD 卡没被识别**：插卡的手机先确认系统里能看到这张卡，卡没挂载时它自然搜不到。
4. **关键词打太长**：只打文件名里最有区分度的两三个字，或者改用后缀（如 `.mp4`）。

## 二、安装时被系统拦下

- 提示「禁止安装来自此来源的应用」→ 按 [下载与安装教程.md](下载与安装教程.md) 第三节允许该来源再装。
- 提示解析错误 / 包损坏 → 重新下载 APK 并核对：大小约 17.05 MB、MD5 `E26F8D1366380653BD3121C8A7E2C048`。
- 提示与已装版本冲突 → 先卸载旧版再装；注意旧版里的收藏会一起没，见本文件第五节。

## 三、搜到了但打不开

- 手机上没有能处理这类文件的应用 → 先装一个对应的阅读器或播放器，再在「打开方式」里选它。
- 目标文件在系统目录（`/system` 之类）里 → 没有 root 权限时只能看不能改，这是安卓本身的限制，换哪个文件管理都一样。

## 四、界面全是英文

见 [下载与安装教程.md](下载与安装教程.md) 第六节：先点顶部地球形状的图标找语言选项，再点齿轮进设置翻一遍。日常要认的就三个图标 —— 放大镜（搜索）、漏斗（筛选）、排序箭头，认全就能用。

## 五、换手机或重装后，收藏没了

应用内的收藏与设置存在本机，卸载、重装或换机后通常不会保留，需要重新收一遍；文件本身不受影响。新机上要装回这个应用，从 [EveryThing 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8c72091ea28a) 转存后安装即可，做法见 [下载与安装教程.md](下载与安装教程.md)。

## 六、它和电脑上的 Everything 是一回事吗

不是。电脑上那个是 voidtools 出品的 Windows 工具（官网 [voidtools.com](https://www.voidtools.com/)），只有文件名搜索一件事；本篇这套文档讲的是安卓端的 EveryThing，包名 `com.aljawad.sons.everything`，还带应用管理、联系人搜索这些手机上才用得着的功能。两边的设置与数据互不相通。
