## 一、从哪里开始搜

顶部工具栏第一个放大镜图标就是搜索入口，点开输入关键词，下面的列表就显示匹配结果。搜索范围是手机内部存储加 SD 卡，不需要你先翻到某个目录。

## 二、关键词怎么写更准

- 只记得文件名的一部分也能搜：打「发票」两个字，比憋完整文件名更快命中。
- 用后缀限定格式：`.mp4`、`.pdf`、`.apk`、`.docx`，适合「我要这类文件的全部」。
- 想缩小到一整类，别一个后缀一个后缀试，直接用下一节的漏斗。
- 官方描述写明支持对文件、联系人与已装应用做全文搜索；另有渠道资料提到 Word / PPT / Excel 的正文也能搜，实际覆盖范围以你装的版本为准。
- 换了新手机后**刚接收的文件搜不到**：那多半是它还躺在微信、QQ 的私有目录里，属于系统不让读的范围，不在关键词的问题上，见 [微信接收的文件搜不到.md](微信接收的文件搜不到.md)。

## 三、漏斗：把结果缩小到一类

点工具栏的漏斗图标，按类型过滤。官方列出的筛选项与各自的用途：

| 筛选项 | 缩到哪一类 | 典型用法 |
| --- | --- | --- |
| Picture | 图片 | 找某次截图、某张照片 |
| Video | 视频 | 找缓存或录制的片子 |
| Audio | 音频 | 找录音、下载的歌 |
| Documents | 文档 | 找 PDF、表格、笔记 |
| APK | 安卓安装包 | 找备份下来的应用包 |
| Compressed | 压缩包 | 找 zip / rar |
| Folder | 文件夹 | 只看目录、不看散文件 |
| Bookmarks | 已收藏条目 | 复看自己收过的东西 |

取消筛选的方式：再次点漏斗，或把已选中的类型取消掉（不同版本入口略有差异，以界面提示为准）。

## 四、排序：让目标自己浮上来

官方支持按 Name（名称）、Path（路径）、Size（大小）、Type（类型）、Last modified（最后修改时间）排序，方向可升可降。几个常用的组合：

| 你的目的 | 怎么排 |
| --- | --- |
| 找出最占空间的文件 | Size，降序 |
| 找昨天刚存的东西 | Last modified，降序 |
| 把散在各处的同类文件归到一起 | Type |
| 找记得开头的那一个 | Name |

## 五、搜到之后能对它做什么

在结果上长按（有的版本是点行尾的三点菜单）可做的操作，来自官方功能清单：

- 打开、查看；
- 分享、重命名、删除 —— 官方把删除列为即时操作，按下去之前先确认选中的是哪个文件；
- 剪切、复制、压缩、解压；
- 加入收藏，之后从底部 Favorites 页直达，见 [收藏夹与联系人搜索.md](收藏夹与联系人搜索.md)；
- 建桌面快捷方式，下次不必再搜一遍。

## 六、不搜索也能按类浏览

底部第三个页签 Folders 直接把内容按类别摆好了：Storage（存储）、IMAGES、VIDEOS、AUDIOS、DOCUMENTS、APKS，每一项行尾的三点菜单里有对应操作。官方描述里还提到 Downloads（下载）、Favorites（收藏）等类别。想找「东西大概在哪一类」而不是「叫什么名」时，先翻这一页往往比搜索更快。
