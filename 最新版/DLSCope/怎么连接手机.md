# DLscope 怎么连接手机

## 一、开始前确认两件事

1. **设备有电**：建议充满电再观测，低电量时画面容易卡顿、掉帧。这类设备充电时指示灯红灯常亮、充满后熄灭（不同批次略有差异，以设备说明书为准）。
2. **手机已装 App**：安卓装的是 1.10.092 一类的版本，iOS 装 App Store 里的版本，渠道见 [下载与安装教程.md](下载与安装教程.md)。

## 二、配对五步

**第 1 步：开机。** 长按设备上的电源键约 3 秒，看到蓝色指示灯常亮，就是开机完成。

**第 2 步：手机连设备热点。** 打开手机的「设置 → WLAN」，在列表里找设备发出的热点并连上。热点名以你手上这台设备的说明书为准，这一系设备常见的两种写法是 `Cam-XXXX` 和 `MKL_WIFI_xxxx`（XXXX 是每台设备各自的编号），热点一般**没有密码**。分不清哪个是自己设备的，可以开机前后各刷一次 WLAN 列表，新出现的那个就是。

**第 3 步：别让手机把连接切走。** 安卓连上后会弹「此 WLAN 无法访问互联网」一类的提示，要选**保持连接**（各品牌措辞略有差别）。点了「取消」或「切换」，手机会自动跳回家里的 WiFi，App 就连不上设备了——这是第一次用最容易踩的一步。

**第 4 步：App 里添加设备。** 打开 DLscope，点右上角的「+」，在设备列表里选中你的设备（名字形如 `W01A` 这类编号，以屏幕显示为准），确认连接。

**第 5 步：回预览对焦。** 连接完成后返回 App 进入实时画面，慢慢转动设备上的对焦轮，直到画面清晰。物体与镜头的距离、对焦轮的角度都会影响清晰度，慢慢找。

## 三、设备上的按键与接口

以同系设备说明书为准（不同批次细节略有差异）：

| 部件 | 作用 |
| --- | --- |
| 电源键 | 长按约 3 秒开机 / 关机 |
| 拍照/录像键 | 短按拍照；长按约 3 秒开始录像，再长按约 3 秒停止并保存 |
| 对焦轮 | 预览时转动对焦 |
| 灯光轮 | 调节 LED 补光灯亮度 |
| 复位孔 | 死机或关不了机时，用细针短按强制关机 |
| 充电口 | 常见为 Micro USB；充电中红灯常亮，充满后熄灭 |

拍照和录像存到哪、怎么导出分享，见 [拍照录像保存在哪里.md](拍照录像保存在哪里.md)。

## 四、连接期间手机没网，是正常的

设备热点本身不通互联网，所以观测期间微信、网页刷不动，这不是故障。要上网就在 WLAN 里切回自家 WiFi，切走后预览会中断，下次要看再连回来。更多类似情况的处理，翻 [常见问题排查.md](常见问题排查.md)；设备到底该配哪类热点，见 [适配哪些设备.md](适配哪些设备.md)。
