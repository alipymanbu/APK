## 一、它配哪类设备

DLscope 是配套 App，不独立工作。它出现在多个品牌的 WiFi 数字显微镜说明书里——例如 AmScope 的 HHD510-W 手持 WiFi 显微镜，官方手册就让 iOS 用户去 App Store 搜「DLscope」、安卓用户扫码或去应用商店下载。

判断你手上的设备该不该用它，看两条：

1. 设备说明书或商品详情页写明配套 App 是 DLscope；
2. 设备开机后会发出一个不加密的 WiFi 热点（`Cam-XXXX` / `MKL_WIFI_xxxx` 一类名字）。

两条都对得上，基本就是它；一条都对不上，就要翻你的设备说明书确认配套 App 叫什么，别硬连。热点怎么连见 [怎么连接手机.md](怎么连接手机.md)。

## 二、常见热点名对照

| 热点名样式 | 出处 | 密码 |
| --- | --- | --- |
| `Cam-XXXX` / `Cam_XXXX` | AmScope 等品牌的同系设备说明书 | 无 |
| `MKL_WIFI_xxxx` | 同系设备说明书示例 | 无 |

XXXX 是每台设备各自的编号，逐台不同。认不出哪个是自家设备时，开机前后各刷一次 WLAN 列表，新出现的那个就是。

## 三、电脑上不用装它

DLscope 只有手机/平板版（安卓与 iOS）。想在电脑上看同一台设备，普遍做法是用 USB 线直连：这类设备插上电脑后会被识别成通用摄像头，用系统自带的相机应用或任意拍照录像软件打开即可（不同批次设备的连接细节以设备说明书为准）。

也就是说，手机与电脑是两条并行路径：手机走 DLscope + WiFi 热点，电脑走 USB 线 + 通用摄像头，二选一都行。

另外，苹果芯片的 Mac（M1 及以上）通常可以直接运行 iPhone/iPad 版 App——App Store 页面也把它列为可运行环境之一，但开发者未针对 macOS 做过验证，能否正常连上设备以你实际测试为准；普通 Windows 电脑仍走 USB 线那条路。

## 四、这类组合常被用来做什么

「显微镜 + 手机看画面」的组合，常见用途包括：

- 电路板、元器件的焊点检查与维修观察；
- 纺织品、印刷品的细节核对；
- 皮肤、毛发、指甲的日常观察；
- 钱币、邮票等收藏品的品相核对；
- 给孩子做科学观察启蒙。

场景只取决于你把镜头对准什么；软件侧要做的就三件事——看画面、拍照、分享。前两件的流程与问题处理见 [怎么连接手机.md](怎么连接手机.md) 与 [常见问题排查.md](常见问题排查.md)，获取渠道见 [下载与安装教程.md](下载与安装教程.md)。
