# Hsteam 版本更新与HSteam2区别

> 本篇讲网盘这份 1.9.0 在版本脉络里的位置、各收录站可见的版本记录，以及 Hsteam 与 HSteam2 的关系和更新时的注意点。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [闪退与安装失败排查.md](闪退与安装失败排查.md) · [社区互动与云存档.md](社区互动与云存档.md)

---

Hsteam 的版本信息没有官方发布页可查，本篇只整理各第三方软件站公开可见的收录记录：哪些版本存在、HSteam2 是什么、更新时要注意什么。版本号与收录时间以各站当时显示为准。

## 一、为什么版本值得在意

盒子类应用的资源列表、社区与工坊功能随版本变化很快。你从 [Hsteam 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ded4fe8e0f40) 拿到的是固定在 1.9.0 的安装包（参数核对见 [下载与安装教程.md](下载与安装教程.md)），它不会自己升级；当某个功能「描述里有、应用里没有」时，先看版本差异，再下结论。

## 二、公开可见的版本记录

各第三方收录站上能查到的 Hsteam 版本条目（收录时间截至 2026-09）：

| 版本 | 备注 |
| --- | --- |
| 1.6.1 | 早期条目，包体约 17.7 MB |
| 1.8.5 | 包体约 18 MB |
| 1.8.15 | 2026-09 仍有收录站更新此条目 |
| 1.9.0 | 本文档对应的版本，包体约 19.18 MB，MD5 `2717DA3350359E0BDF565197CA0E366A` |

规律是常规的小版本迭代（1.6 → 1.8 → 1.9），没有大版本重编号的痕迹。各站条目的包体与描述互有出入，判断版本真伪以包名 `com.xp.hsteam` 加 MD5 为准，别只对名字。

## 三、HSteam2 是什么、和 Hsteam 什么关系

收录站上另有 **HSteam2**（包名 `com.newxp.hsteam`，可见条目到 v2.1.4，2026-02 更新），描述同样以游戏资源集合、下载与社区为主。两个应用的包名一脉相承（`com.xp.hsteam` → `com.newxp.hsteam`），从命名与功能描述看是同一产品线的后续版本，但公开资料里没有官方说明直接确认这一层关系，两种理解——「更名升级」或「另起的新应用」——都成立，以你实际使用时的判断为准。

有个旁证可供参考：部分软件站的「Hsteam」条目已经直接挂到了 2.1.4 与 `com.newxp.hsteam` 的安装包，也就是把两个名字收录到了同一份新包上——这更偏向「同一产品线改名延续」的理解，但依然不是官方口径。

2.x 一代的收录描述里出现了几处 1.x 条目里没有的功能点，可作为版本差异的参照：数千款 gal 系列游戏、离线下载、任务获取 G 币与积分兑换礼包、新游推送通知。1.9.0 里哪些具备、哪些没有，以实际界面为准（找入口的判据见 [怎么下载游戏.md](怎么下载游戏.md) 与 [社区互动与云存档.md](社区互动与云存档.md)）。

两者在安卓系统里的区别是实质性的：

| 对比项 | Hsteam | HSteam2 |
| --- | --- | --- |
| 包名 | `com.xp.hsteam` | `com.newxp.hsteam` |
| 版本号段 | 1.x | 2.x |
| 同设备共存 | 两包名不同，可以同时安装 | 同左 |

**包名不同意味着数据不互通**：游戏存档、收藏、账号记录都跟着各自的包走。从 Hsteam 换到 HSteam2 时，不能指望数据自动迁移，动手前先把有云存档的进度在旧应用里上传一遍。

## 四、更新时的三个注意点

1. **覆盖安装的前提是同包名**：Hsteam 的后续 1.x 版本可以覆盖安装到 1.9.0 上，本地数据保留；换成 HSteam2 则等于装一个新应用；
2. **应用内更新入口**：1.9.0 若有「检查更新」功能，以应用内提示为准；应用内没有更新入口的，就需要自己重新获取新版本安装包；
3. **认准包名再装**：搜索引擎里 Hsteam、HSteam2、Steam 官方应用的结果混在一起，安装前核对包名——`com.xp.hsteam` 是本文这份，`com.valvesoftware.*` 是 Valve 官方 Steam，别装错。

更新后遇到闪退或功能异常，按 [闪退与安装失败排查.md](闪退与安装失败排查.md) 排查；新版本里社区与工坊的入口变化，参考 [社区互动与云存档.md](社区互动与云存档.md) 的功能地图。
