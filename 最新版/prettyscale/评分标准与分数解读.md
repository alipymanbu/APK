## 一、分数由哪些维度构成

PrettyScale 没有公开的官方评分说明，下面这些维度来自第三方下载页的介绍，实际以 App 内展示为准：

| 维度 | 看什么 |
| --- | --- |
| 面部对称性 | 定位瞳孔、鼻尖、嘴角等关键点，计算左右脸的差值；差值越小，这项越高 |
| 黄金比例匹配度 | 眼睛间距与面部宽度、鼻长与下巴长度、唇宽与鼻翼宽度的比例 |
| 特征定位精度 | 你手动校准的面部标记点位置；标记点偏了，后面全都不准 |

## 二、分数怎么看

- 结果页是「综合分 + 分项分」：脸型、鼻子、眼睛、嘴巴各有一项，另有一个综合结果；
- 有第三方页面按百分制（1~100 分）介绍这款 App，也有页面提到普通用户分数多落在 60~80 分——两种说法都来自分发渠道，仅供参考；
- 看分项比只看综合分有用：哪一项明显低，通常对应照片里的具体问题（光线、角度、标记点没摆正），先排除照片因素再下结论。

## 三、哪些因素会让分数变化

| 因素 | 影响方式 |
| --- | --- |
| 光线 | 逆光、阴影会让关键点定位偏移，皮肤状态也会被误判 |
| 角度 | 侧脸、低头、仰头都会改变五官比例的测量值 |
| 表情 | 大笑、闭眼会改变嘴角与眼睛关键点的位置 |
| 妆容与滤镜 | 磨皮、瘦脸会直接改写被分析的像素 |
| 标记点位置 | 手动校准阶段的偏差会带进所有后续计算 |

有第三方页面提到，同一人不同照片的分数可能相差 10~15 分——这与上表的因素一致：分数波动大，先换照片再怀疑别的。每个因素的对策与固定测法见 [为什么每次测的分数不一样.md](为什么每次测的分数不一样.md)。

## 四、怎么看待这个分数

这类工具输出的是数学模型对一张静态照片的计算结果，审美因人与文化而异，分数不具备医学或专业美学上的效力。把它当娱乐参考没有问题；据此做医美决策、产生容貌焦虑，就超出这个工具能回答的范围了。想要一个相对稳定的对比记录，测试方法照 [颜值测试使用教程.md](颜值测试使用教程.md) 第二节固定下来即可。
