# Yandex Browser 账号登录与数据同步

> 本篇讲怎么登录 Yandex 账号、同步会带走哪些数据、换手机时怎么把书签和密码搬过去，以及不想同步时怎么关。

## 一、要不要登录

不登录，浏览、搜索、开隐身标签照常能用；登录的意义在两件事：**跨设备同步**和**账号级功能**。

- 同步必须登录：书签、密码这些数据存在 Yandex ID 账号里，没有账号就没有云端那份备份；
- Alice AI 的部分能力与账号挂钩，未登录时可能受限，以应用内实际提示为准；
- 不登录时，清一次应用数据或卸载重装，本地书签和记录就没了——这是最实际的差别。

## 二、登录入口与注册

1. 打开浏览器，点菜单里的头像 / 账号入口（找不到就按手机的菜单键）。
2. 选 **Settings**（设置）→ **Enable syncing**（开启同步），或直接点登录入口。
3. 输入已有的 Yandex 账号密码；没有账号就点 **Registration**（注册）现注册一个 Yandex ID，按页面填手机号或邮箱，验证码过了就能用。

登录这一步的入口在不同版本里位置略有出入，有的版本在欢迎页就提示登录——认准「登录 / Sign in」和「同步 / Syncing」字样即可。较新的版本还支持**免密码登录**：手机指纹、锁屏 PIN 直接进账号（官方要求浏览器 24.4.4 以上、Android 9 以上，以应用内实际显示为准）。登录遇到问题（收不到验证码、提示无法连接）先看[常见问题与故障排查.md](常见问题与故障排查.md)第三节。

## 三、同步会带走哪些数据

官方支持页写明的默认同步清单：**密码、Tableau 收藏站点、书签、自动填充表单、打开的标签页**。也就是说登录同一账号后，手机和电脑上的浏览器是同一套状态——手机上存个密码，电脑上登录页直接能自动填。

几个你需要知道的机制：

- 数据在 Yandex 服务器上是**加密暂存**的，传输走安全通道，密码和卡片信息单独加密；
- **密码库可以再加一层锁**：在密码设置里开启主密码，或用手势 / PIN / 指纹保护，开了之后自动填充前要先过这一关——手机借给别人用也不怕；另有备份加密密钥一说，重置时用得上，入口在密码管理设置里；
- 同步是**实时增量**的：手机加一个书签，服务器立刻收到，同时把其他设备在这期间的改动拉下来；
- **不能跨浏览器同步**：Yandex Browser 的同步只发生在 Yandex Browser 之间（手机版还和 Yandex 应用互通），和 Chrome、Firefox 之间不互通，从 Chrome 迁移要用浏览器的导入功能另走一遍；
- 想只同步一部分：设置 → **Syncing**（同步）里逐项勾选，比如只同步书签不同步密码。

## 四、换手机怎么搬数据

1. 新手机装好 Yandex Browser（安装包从哪拿见[下载与安装教程.md](下载与安装教程.md)）。
2. 登录**同一个** Yandex 账号，开启同步。
3. 等数据拉完，书签、密码、自动填充、标签页就都回来了；电脑上如果也装着，浏览器设置同样是同一套。

这套流程同样是数据救援的路径：旧手机摔了、丢了、进水了，只要同步开过，新设备登录就能恢复——前提是密码这类数据当时在同步清单里。所以换机前最好先在旧手机的 设置 → Syncing 里核对一遍清单。

## 五、关掉或调整同步

- 关闭：设置 → **Syncing** → **Disable syncing**（关闭同步）。关掉后云端数据不会消失，只是不再更新，重新开启会接着同步。
- 调整范围：同一页里逐项开关，密码、书签、表单、标签页可以分开控制。
- 隐身模式例外：隐身标签**不参与同步**，也不会被记录，见[标签页与手势操作技巧.md](标签页与手势操作技巧.md)第五节。
