## 一、装不上

按概率从上往下查：

1. **内部存储不足**：安装至少要 100MB 可用内部存储，SD 卡不算。清出空间再装；部分机型装完可以把应用移到 SD 卡，但安装时只看内部存储。
2. **未知来源没放行**：设置 → 应用 → 特殊权限 → 安装未知应用，给你打开 APK 的那个应用（文件管理器 / 网盘 / 浏览器）开允许。完整步骤见[下载与安装教程.md](下载与安装教程.md)第三节。
3. **系统版本过低**：官方支持页当前要求 Android 9.0 及以上（以官方页面为准）。系统升级不了又必须用，就找最低系统要求更低的旧版本包。
4. **包不完整**：下载中断出的包装到一半报错。删掉重下，下完核对 MD5：`FCA3860FCFE8B05B71AF5EBC3394D9F6`，对得上才是完整的那份 26.3.5.119。

## 二、打不开、闪退、卡在欢迎页

- **重启再开**：首次启动要联网初始化，网络不通会卡在欢迎页或转圈，先确认网络，再彻底关掉应用重开；
- **后台被杀**：用的时候被系统回收、切回来就重开，去系统设置把浏览器的电池策略放宽（允许后台运行 / 关掉对该应用的省电限制），锁屏后语音对话、下载才不会断；
- **清缓存**：设置里清浏览器缓存；连应用数据一起清会**丢本地书签和记录**，清之前确认同步开着（见[账号登录与数据同步.md](账号登录与数据同步.md)），数据在云端就丢不了；
- **重装**：以上都无效就卸载重装，同样先确认同步开着；
- **费电快**：浏览器自带的省电模式能压后台标签、切阅读模式、换硬件解码，触发阈值也能调，见[省电模式与Turbo加速怎么用.md](省电模式与Turbo加速怎么用.md)。

## 三、登录不上

1. **收不到验证码**：等一两分钟再重发；检查手机号 / 邮箱填错没有，邮箱方式翻一遍垃圾邮件箱；
2. **提示无法连接**：登录走 Yandex 的服务器，网络不通或被拦时连不上，换个网络环境再试；
3. **二次验证**：账号开过两步验证的，按提示输入验证方式，别把「验证失败」当成密码错了瞎试——试错次数多了账号会被临时锁；
4. 还不行就先在网页端登录 Yandex 账号验证账号本身没问题，再回浏览器登录。

## 四、同步不工作

- **核对账号**：两台设备必须登**同一个** Yandex ID，登成两个账号是最常见的原因；
- **核对开关**：设置 → **Syncing** 里确认同步是开的、想同步的数据项（密码、书签、标签页）是勾着的；
- **记住边界**：同步只在 Yandex Browser 之间发生，和 Chrome 不互通；隐身标签永远不在同步里；
- 手动触发一次：开关一次同步或等一次改动，看「其他设备」的标签页有没有刷新（见[标签页与手势操作技巧.md](标签页与手势操作技巧.md)第四节）。

## 五、翻译没反应

1. 页面是外语才会触发翻译提示，全中文页面不弹；
2. 提示没弹就从页面菜单里手动找**翻译（Translate）**入口；
3. 走线上服务，网络差时点了没动静，重试；
4. 视频翻译、总结这类新能力集中在较新的版本线上，老包没有就是没有，升级方式见[下载与安装教程.md](下载与安装教程.md)第四节；网页翻译的日常用法见[网页翻译与视频翻译怎么用.md](网页翻译与视频翻译怎么用.md)。

## 六、广告和跟踪器

广告拦截**默认就是开着的**，官方把三类广告算作「干扰性广告」：页面一加载就弹的全屏横幅、停留几秒后弹出的全屏横幅、自动播放带声音的视频广告——这三类不设置就会被拦。

日常用得到的几个操作：

- **给某个网站放行**：菜单 → **About the site**（关于本站）→ 关掉 **Ad blocking**，只对这个站生效；
- **举报漏网广告**：菜单 → **Ad blocking** → **Report ads**；同类举报多了，官方会把整个广告源对所有人拉黑；
- **全局关掉拦截**：设置 → **Content blocking**（内容拦截）→ **Ad blocking** → 关 **Intrusive ad blocking**；
- **跟踪器与 Cookie**：设置隐私部分里**拦截跟踪器**、**清除 Cookie** 是独立开关，和广告拦截互不影响。

拦不住的新式广告多半是换了投放形态，等过滤规则更新，或按下一节装个扩展兜底。

## 七、扩展：能装什么、在哪装

入口在菜单 → **Extensions**（扩展）→ 列表底部 **More extensions**（更多扩展）。官方从现有扩展里筛了一批「常用、有用、安全」的做内置精选，手机上直接开关就能用。

想装更多，从 **Chrome 应用商店**或 **Opera Add-ons** 目录装——安卓浏览器里能做到这点的没几个。外部装的扩展单独归在「**From other sources**（来自其他来源）」分组里，**也只有这个分组里的扩展能删除**；开关、配置都在扩展详情（**More information**）里，没有 Settings 按钮的扩展就是不可配置。

一条安全提醒值得单独写出来：官方曾**主动禁用过 SaveFrom.net、Frigate 等一批扩展**，原因是行为危险、涉及欺诈。装扩展前想一下这个先例——来路不明的「视频下载」「解锁」类扩展别碰，只从商店目录里挑、看评价和更新时间。
