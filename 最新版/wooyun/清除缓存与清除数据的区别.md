# 清除缓存与清除数据的区别

> 讲安卓「清除缓存」和「清除数据」差在哪、wooyun 出问题时该用哪个、各会丢什么，动手前先看这篇。

## 一、一句话分清

- **清除缓存**：只删临时文件（看片时的缓冲、封面图缓存），收藏、观看历史、设置都还在。
- **清除数据**：把应用恢复成刚装好的样子 —— 收藏、观看历史、离线缓存的片子、登录状态全部清空。

| 对比 | 清除缓存 | 清除数据 |
| --- | --- | --- |
| 看片缓冲、封面图等临时文件 | 清掉 | 清掉 |
| 收藏 | 保留 | 清空 |
| 观看历史 / 续播进度 | 保留 | 清空 |
| 已离线缓存的影片 | 多数保留（个别版本可能受影响） | 清空 |
| 登录状态（如你的版本有账号功能） | 保留 | 退出并清空 |
| 适合场景 | 界面卡、加载异常、闪退的常规处理 | 反复异常且清缓存无效时的最后手段 |

## 二、在哪操作

路径：**设置 → 应用管理 → wooyun → 存储**（个别机型叫「储存」，或要先点进「应用信息」）。

- 先试「清除缓存」，重开应用看是否恢复。
- 「清除数据」按钮通常和「清除缓存」挨在一起，容易误触 —— 点之前看清按钮文字。

## 三、什么时候用哪个

- **闪退、界面卡、内容加载异常** → 先清除缓存，多数情况够用。
- **清缓存后依然异常** → 再考虑清除数据。清除前想清楚：收藏与观看历史没有导出通道，清了就没了（数据归属详见 [收藏与观看历史管理.md](收藏与观看历史管理.md) 第三节）。
- **只是存储不够** → 这两个按钮都别动，去应用内删看过的离线缓存更安全，操作见 [离线缓存与播放设置.md](离线缓存与播放设置.md)。

## 四、清完之后

清除数据后应用回到首次安装状态，重新打开就是全新的。如果老毛病还在，多半不是数据的问题，按 [常见问题与故障排查.md](常见问题与故障排查.md) 的顺序查网络、线路与版本。
