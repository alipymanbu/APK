## 一、先看这张对照表

| 症状 | 大概率原因 | 处理 |
| --- | --- | --- |
| 打不开、点开就闪退 | 缓存出错 / 内存不足 | 重启手机；系统设置里给应用「清除缓存」再开 |
| 界面能进但内容加载失败 | 网络波动 / 线路失效 | 换网络（Wi-Fi 与流量互换）；换播放线路；稍后再试 |
| 黑屏有声音、或一直转圈 | 该条线路的片源失效 | 切别的线路；还不行等应用更新 |
| 搜不到某部片 | 内容池波动 / 关键词太偏 | 换关键词、去分类里翻、过几天再搜 |
| 投屏提示「暂无设备」 | 不在同一 Wi-Fi 等 | 逐项查 [投屏到电视怎么操作.md](投屏到电视怎么操作.md) 第三节 |
| 安装失败 / 解析包出错 | 包损坏或空间不足 | 按 [下载与安装教程.md](下载与安装教程.md) 第四节的表处理 |
| 应用内提示更新 | 出了新版本 | 覆盖安装新版即可，一般不用卸载 |
| 存储满、缓存下不动 | 剩余空间不足 | 清出空间再下；优先删应用内看完的离线缓存 |
| 收藏、历史想跨设备同步 | 同步类功能一般要登录 | 看应用内「我的」页是否出现登录入口；多份公开资料口径一致，基础使用无需登录 |

## 二、打不开、闪退的完整顺序

1. **重启手机** —— 清掉被占死的内存，能解决一大半偶发闪退。
2. **清除应用缓存**：设置 → 应用管理 → wooyun → 存储 → 清除缓存。注意别点成「清除数据」，那会把收藏和观看历史一起清空（两者区别见 [清除缓存与清除数据的区别.md](清除缓存与清除数据的区别.md)）。
3. **腾空间**：剩余存储不足时安卓会开始杀后台进程，表现就是各种闪退。
4. **重装**：卸载后重新安装。本地收藏与历史会丢，安装包从 [wooyun 安装文件资源（夸克网盘）](https://pan.quark.cn/s/423ee9dcb5c3) 拿（先转存再下载）。

## 三、关于内容源失效

聚合类应用的内容由应用内聚合的各条线路提供，线路失效、影片下架是常态，表现为搜不到、放不出来或播放中途断开。这类情况换线路、换个时间再看即可，不是设备坏了，也没有哪项设置能修 —— 等应用自己更新线路。

## 四、与账号、数据有关的问题

- 基础浏览与播放无需登录；收藏、观看历史的跨设备同步这类功能是否需要账号，多份公开资料的口径一致（建议注册），以应用内「我的」页实际入口为准。
- 收藏与观看历史是本地数据，卸载、清除数据、换机都会丢，且事前没有导出通道，细节见 [收藏与观看历史管理.md](收藏与观看历史管理.md)。
- 离线缓存的影片同样随清除数据 / 卸载消失，重新进应用下载即可，见 [离线缓存与播放设置.md](离线缓存与播放设置.md)。
