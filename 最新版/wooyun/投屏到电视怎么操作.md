## 一、投屏前先满足两个前提

1. **手机和电视连的是同一个 Wi-Fi**。这是搜不到设备最常见的原因：不在同一个网络里，设备列表就是空的。
2. **电视端开着接收能力**。智能电视或电视盒子保持开机联网；个别电视要在设置里打开 DLNA 或「多屏互动」之类的开关（各家叫法不同，翻一下你电视的设置）。

## 二、投屏步骤

1. 在应用里找到想看的剧或电影，进入播放详情页。
2. 点一下屏幕呼出控制条，找投屏图标（一般是台电视机模样的按钮）。
3. 点开后等设备列表刷出来，选中你家电视的名字。
4. 连上后画面切到电视，手机变成遥控。有资料提到投屏状态下支持熄屏播放省电，以实际界面为准。

## 三、提示「暂无设备」逐项排查

| 检查点 | 说明 |
| --- | --- |
| 是否同一 Wi-Fi | 手机用流量、电视用宽带是最常见的翻车组合；手机开热点给电视连也经常搜不到 |
| 路由器是否开了 AP 隔离 | 开了之后同一 Wi-Fi 下的设备互相不可见，进路由器后台关掉 |
| 双频路由器 | 2.4G 与 5G 两个频段在部分路由器上是隔离的，让手机和电视连同一个频段试试 |
| 电视端服务没开 | 智能电视的 DLNA / 多屏互动开关没打开，或盒子在休眠 |
| 应用版本太旧 | 旧版本对设备的发现能力可能有问题，覆盖装个新版再试 |

以上都查过还不行，把手机和电视都重启一遍再试 —— 设备发现卡死是个常见的小毛病。

## 四、投屏时的画质与卡顿

投屏对网络的要求比手机上看更高，卡顿优先检查路由器到电视这一段（信号格数、距离、有没有别的设备在下载大文件）。把清晰度降一档通常立竿见影，操作见 [离线缓存与播放设置.md](离线缓存与播放设置.md)。
