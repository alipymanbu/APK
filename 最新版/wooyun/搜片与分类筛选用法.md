## 一、找片走两条路

打开应用后，找片主要靠两个入口：

- **推荐流**：首页直接摆热门与最近更新的内容，适合没想好看什么时随便翻。
- **搜索框**：想好了片名、演员或关键词，直接搜最快。

不同资料对首页布局的描述不完全一致（有的截图里分类在底部导航，有的在频道页签），版本之间界面也可能调整过，以你手上这个版本的实际界面为准。

## 二、搜索怎么搜才不空手

1. 点搜索框，输入片名、演员名或关键词。
2. 在结果列表里找到目标影片，点进详情页。
3. 同一部片常有多个版本或播放源，选一条进入播放页。
4. 剧集在播放页用「选集」按钮切换集数。

搜不到想要的结果时，按这个顺序换姿势：

- **换关键词**：只记得别名、外文名或主演，就用那个搜；长片名只输最有辨识度的几个字。
- **去分类里翻**：搜索对冷门片经常漏，分类筛选反而能撞到（见下一节）。
- **过几天再搜**：这类聚合应用的内容池随时间变动，这次没有不代表下次也没有。

## 三、分类筛选有哪些维度

公开页面对它的筛选维度描述比较一致：**类型、地区、年份**三档，可以组合着筛。典型用法：

| 你想找 | 怎么筛 |
| --- | --- |
| 最近上线的剧 | 类型选「电视剧」，年份选最近一档 |
| 老电影 | 类型选「电影」，年份往早了调 |
| 某地区的综艺 | 类型选「综艺」，地区选对应档位 |
| 下饭短剧 | 走「短剧」频道（有的版本叫微短剧），按专题翻 |

筛出来的列表还可以继续配合搜索框缩小范围。

## 四、看完一集接着看

播放进度会自动记进观看历史，中途退出再进，通常能接着上次的位置继续；想主动追的片先收藏，操作与整理见 [收藏与观看历史管理.md](收藏与观看历史管理.md)。播放中要调清晰度、切线路或缓存到本地，见 [离线缓存与播放设置.md](离线缓存与播放设置.md)。
