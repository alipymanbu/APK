# AriaNg GUI 后台下载保活设置（分品牌）

> 手机锁屏或切走后下载就停，几乎都是系统省电策略把应用冻结了，不是应用本身的问题。本篇按品牌给出能让它在后台继续下载的设置路径，改完再挂机下大文件。任务本身没速度是另一类问题，见 [磁力与BT下载指南.md](磁力与BT下载指南.md)、[BT提速与tracker配置.md](BT提速与tracker配置.md)；其他异常汇总见 [常见问题排查.md](常见问题排查.md)。

## 一、所有品牌通用的四件事

不管什么手机，先把这四项做了，它们解决八成的情况：

| 设置 | 去哪找 | 目的 |
| --- | --- | --- |
| 忽略电池优化 | 系统设置搜「电池优化」，找到该应用选「不允许优化 / 不优化」 | 系统不再主动冻结它 |
| 允许后台活动 / 自启动 | 应用信息页或「启动管理」里，关闭「自动管理」，勾选允许后台活动、自启动 | 切后台、锁屏后进程不被掐 |
| 多任务卡片加锁 | 打开应用后进多任务界面，下拉卡片出现锁图标 | 一键清理时不被顺手杀掉 |
| 关闭省电模式 | 设置 → 电池 | 省电模式会连带限制后台联网与活动 |

另有一个容易被忽略的开关：部分品牌在电池设置里有「**休眠时始终保持网络连接**」，不开的话手机一锁屏 Wi-Fi 就休眠，下载自然停——挂机下载前记得检查。

下面分品牌给具体路径。各品牌菜单名称随系统版本变化，以下写的是常见叫法，以你手机实际设置里的搜索结果为准。

## 二、华为 / HarmonyOS

华为官方支持页给过针对「灭屏后应用停止下载」的排查步骤，逐条做：

1. 设置里搜「**应用启动管理**」，找到该应用，关闭「自动管理」，在弹框里勾选**允许自启动、允许关联启动、允许后台活动**；
2. 设置里搜「**电池优化**」，点三角形选「所有应用」，把该应用设为「**不允许**」（即忽略优化）；
3. 多任务界面下拉该应用卡片**加锁**；
4. 设置 → 电池，关闭省电模式；再到「更多电池设置」打开「**休眠时始终保持网络连接**」；
5. 若装了第三方管家类清理软件，卸载或把它加入白名单——这类软件会强制清后台。

## 三、小米 / Redmi（MIUI、HyperOS）

MIUI 系对后台的限制出了名地激进，三步缺一不可：

1. 应用信息页打开「**自启动**」开关（或在「应用权限」里允许后台自动启动）；
2. 应用信息页 →「**省电策略**」→ 选「**无限制**」；
3. 多任务界面下拉卡片加锁。

部分版本里还有一个「**暂停未被使用的应用**」类开关，在应用信息页里找到并关掉。

## 四、三星（One UI）

1. 设置 → 电池 → 电池优化 → 切到「所有应用」，把该应用设为「**不优化**」；
2. 设置 → 电池 → 后台使用限制，**关闭「让未使用的应用进入休眠」**与「自动禁用未使用的应用」——三星会把长期不点开的应用整体休眠，下载器正好是那种「不点开但要干活」的应用；
3. 多任务卡片加锁。

## 五、OPPO / vivo 及其他品牌

- OPPO（ColorOS）：应用管理里允许「**自启动**」；电池设置里对该应用选「**允许后台运行**」；有「安全中心」的机型再进「权限隐私 → 启动管理」里放开一次；
- vivo（OriginOS / Funtouch）：设置 → 电池 → 后台耗电管理，允许该应用后台高耗电；应用管理里开自启动；
- 其他品牌查不到对应设置时，直接看 `https://dontkillmyapp.com/`——这个站点按厂商汇总了各家杀后台的应对方法，专门收录这类问题。

## 六、设置完怎么验证

挂一个 BT 任务锁屏等 10 分钟，解锁后看进度有没有涨。仍然停就按顺序复查：省电模式是否真的关了、Wi-Fi 是否在锁屏后断开（可以发条消息测试）、有没有第三方清理软件在杀进程。任务本身不动（比如磁力一直取不到元数据）则是另一类问题，去 [磁力与BT下载指南.md](磁力与BT下载指南.md) 和 [BT提速与tracker配置.md](BT提速与tracker配置.md) 排查。

长时间挂机前还有一件事：确认下载目录空间够放完整任务，别下到 90% 才发现磁盘满了。
