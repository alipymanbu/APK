# AriaNg GUI 常见问题与排查方法

> 汇总 AriaNg GUI 使用中最常碰到的几个问题：未连接、后台被杀、文件去哪了、界面是英文。按现象对号入座；连接细节、BT 提速与后台保活的完整做法分别在 [RPC连接设置.md](RPC连接设置.md)、[BT提速与tracker配置.md](BT提速与tracker配置.md)、[后台下载保活设置.md](后台下载保活设置.md)。

## 一、界面显示「未连接」或一直转圈

含义是前端没连上 aria2 内核，不是应用损坏。

| 现象 | 先查什么 |
| --- | --- |
| 刚装完打开就未连接 | 完全退出应用重开一次，让内置内核启动；详见 [RPC连接设置.md](RPC连接设置.md) 第二节 |
| 提示认证失败（401） | RPC 密钥两边不一致，逐字重新填一遍 |
| 连远程电脑/NAS 时未连接 | 手机与设备是否同一 Wi-Fi、IP 是否填对、电脑防火墙是否放行 6800 端口 |
| 之前好好的突然连不上 | 局域网 IP 变了（路由器重启后常见），重新确认设备 IP |

## 二、手机锁屏后下载就停了

安卓各厂商对后台应用都有激进的省电策略，下载类应用被系统冻结是普遍现象，这是外因，得从系统设置侧解决。华为、小米、三星等主流品牌的具体设置路径在 [后台下载保活设置.md](后台下载保活设置.md) 里分品牌列了步骤，通用的三板斧：忽略电池优化、允许后台活动、多任务卡片加锁。

另外注意官方更新记录显示 1.3.0 版本加入了对后台运行的支持，但应用侧的支持代替不了系统白名单，锁屏即停时按上面顺序改设置通常就能解决。

## 三、下载的文件去哪了

任务的下载目录以**任务选项里显示的为准**：点开任务详情能看到完整路径；全局默认目录在 aria2 设置里改。

拿文件的两个建议：

- 下载前就把目录设到手机存储里你方便找的位置，避免事后在系统目录里翻；
- BT 任务建议下到应用有完整写权限的目录，个别目录位置受安卓存储权限限制会出现任务报错，报错信息里带「目录」「权限」字样时优先换目录重试。

需要把文件从手机里转出去，用文件管理器直接分享 / 拷贝即可，应用本身不需要参与。

## 四、界面是英文

这套界面自带多语言（官方特性列表里含简体与繁体中文）。切换位置：左侧「AriaNg 设置」→ 找语言（Language）选项 → 选「简体中文」，页面会自动刷新成中文。

## 五、任务报错或进度不动

| 报错/现象 | 最可能的原因 |
| --- | --- |
| 磁力任务长时间停在获取元数据 | 资源太冷门、无人做种，见 [BT提速与tracker配置.md](BT提速与tracker配置.md) 第二节 |
| 直链任务速度极低或 0 | 链接失效、服务器限单线程，开多连接试试 |
| 任务报「无法创建文件/目录」 | 下载目录无权限或空间不足，换目录 |
| 提示 401 / 认证失败 | RPC 密钥两边不一致，逐字重填一遍 |

## 六、装不上或装完闪退

- 装不上：系统版本低于要求，或安装包损坏——重新下载后用 [下载与安装教程.md](下载与安装教程.md) 第五节的方法校验 MD5；
- 打开就闪退：先重启手机排除内存紧张；仍闪退则说明该版本与你当前系统不兼容，这款应用最后一次官方更新在 2021 年，新版安卓上遇到不可用的情形时，应以官方仓库（`https://github.com/Xmader/aria-ng-gui-android`）的发布页信息为准。
