# AriaNg GUI 连接 aria2 的 RPC 设置指南

> 本篇讲 AriaNg GUI 里的 RPC 连接：默认连手机内置的下载内核为什么即开即用，以及怎么把手机变成电脑 / NAS 上 aria2 的遥控器。安装步骤见 [下载与安装教程.md](下载与安装教程.md)，连接好后加任务见 [磁力与BT下载指南.md](磁力与BT下载指南.md)。

## 一、RPC 是什么，为什么界面会显示「未连接」

AriaNg GUI 里你看到的那套界面（任务列表、新建任务、图表）是 AriaNg 前端，它自己不下载文件，而是通过一个叫 RPC 的接口去指挥真正的下载内核 aria2。界面右上角出现「未连接」或红色提示，意思是**前端还没连上内核**，不是应用坏了。

连接信息都在应用左侧的「AriaNg 设置」里，页面顶部会列出 RPC 连接条目，每一条对应一个 aria2。官方特性列表里写明支持配置多个 RPC，所以你可以同时保存「手机本机」「家里 NAS」「公司电脑」几条配置，在顶部随时切换。

## 二、本机模式：默认就应该能用

这款应用内置了 aria2 内核，正常情况下打开应用就自动连上本机内核，不需要任何设置。如果显示未连接，按这个顺序查：

1. 在设置里确认当前选中的 RPC 条目地址是不是本机（`127.0.0.1` 或 `localhost`），端口是否与内置内核一致；
2. 如果条目里填了 RPC 密钥（secret），确认它与内置内核要求的密钥一致——认证失败是「未连接」最常见的具体原因；
3. 完全退出应用重新打开，让内置内核重新启动；
4. 仍不行就到 [常见问题排查.md](常见问题排查.md) 对着现象逐条排。

## 三、遥控模式：连接电脑或 NAS 上的 aria2

另一种用法是手机只当遥控器，文件下到电脑或 NAS 里。前提是手机与那台设备在**同一个局域网**（或能通过其他方式互访）。

**第一步：让电脑上的 aria2 开启 RPC 并允许外部访问。** 命令行启动示例（Windows 下把 `aria2c.exe` 换成实际路径）：

```bash
aria2c --enable-rpc --rpc-listen-all=true --rpc-secret=你的密钥 --dir=D:\Downloads
```

参数含义：`--enable-rpc` 打开 RPC 接口；`--rpc-listen-all=true` 允许局域网里其他设备连入（不开这个手机连不上）；`--rpc-secret` 设置连接密钥；`--dir` 指定文件下到哪。NAS 用户一般在套件或 Docker 配置里做同样的事，端口保持默认的 `6800` 最省事。

**第二步：在手机应用的「AriaNg 设置」里新建或编辑一条 RPC：**

| 字段 | 填什么 | 说明 |
| --- | --- | --- |
| 协议 | `http` 或 `ws` | aria2 两种都支持；连不上时换另一种试试 |
| 主机 | 电脑 / NAS 的局域网 IP | 如 `192.168.1.100`，在设备上用 `ipconfig`（Windows）或路由器后台查 |
| 端口 | `6800` | aria2 默认端口，除非你改过 |
| 接口路径 | `jsonrpc` | 默认值，一般不用动 |
| 密钥 | 与 `--rpc-secret` 一致 | 没设密钥就留空，两边必须对得上 |

**第三步**：保存后界面应显示已连接，速度图表开始跳动。连不上时优先排查：IP 填错、手机和设备不在同一网段（比如手机走了流量或连了访客 Wi-Fi）、电脑防火墙拦了 6800 端口。

## 四、几个容易踩的坑

- **密钥不一致**：界面提示认证失败（401）时，十有八九是 RPC 密钥两边没对齐，重新复制粘贴一遍。
- **协议选错**：`http` 与 `ws`（WebSocket）指向同一个服务，一种连不上就换另一种，不必去改 aria2 配置。
- **IP 会变**：家用路由器给设备分配的 IP 可能重启后变化，遥控突然失灵时先确认 IP 还对不对；在路由器里给设备绑定固定 IP 可以一劳永逸。
- **离开局域网就断**：遥控模式依赖局域网互访，出门在外连不上家里的下载机属于正常现象，不在本篇讨论范围内。
- **换手机 / 重装不用重填**：AriaNg 设置页支持把全部配置（含 RPC 条目）**导出成文件**，新设备上导入即可还原；配置了好几条 RPC 的话，先导出一份留底比什么都稳。

设置完成后，去 [磁力与BT下载指南.md](磁力与BT下载指南.md) 加第一个任务试试；设置过程中遇到异常现象，[常见问题排查.md](常见问题排查.md) 第一节专门对「未连接」分了情形。
