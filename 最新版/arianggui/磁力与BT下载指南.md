# AriaNg GUI 磁力与 BT 下载指南

> 本篇讲在 AriaNg GUI 里添加磁力链接、种子与直链任务的完整操作。前提是界面已经连上内核，没连上的先看 [RPC连接设置.md](RPC连接设置.md)；任务加好了却没速度，直接去 [BT提速与tracker配置.md](BT提速与tracker配置.md)。

## 一、新建任务的三种入口

左侧「新建任务」按钮打开后，顶部有几个标签页，对应不同类型的任务：

| 任务类型 | 怎么加 | 适用 |
| --- | --- | --- |
| 链接（URI） | 粘贴 `magnet:?xt=urn:btih:…` 磁力链接，或 `http(s)://`、`ftp://` 直链 | 磁力、直链、FTP |
| 种子（Torrent） | 选择本地 `.torrent` 文件上传 | 手上有种子文件时 |
| Metalink | 选择 `.metalink` 文件 | 少数镜像站提供 |

多个链接可以一次粘贴多行，批量建任务。提交后任务出现在「正在下载」列表里，点进去能看每个文件的进度与连接节点情况。

**添加磁力任务前先想好下载目录**：新建任务面板的高级设置里可以改「下载到哪里」，BT 任务动辄几个 GB，别默认下到空间紧张的位置。

## 二、BT 任务：先选文件，再等连接

磁力任务刚建立时，应用需要先从网络获取种子元数据（文件列表），这一步在冷门资源上可能要等几十秒甚至更久，**列表里任务卡在获取元数据阶段是正常的**，不是卡死。

拿到文件列表后：

1. 在任务的文件页里**取消勾选不需要的文件**——BT 下载是你下得越多、上传负担越重的模式，只挑要的文件既省流量也省时间；
2. 多目录的种子会以树形显示，逐级勾选；
3. 确认后任务开始跑，进度页能看到健康度（availability）与各个连接节点（peer）的详情。

## 三、没速度时的自查顺序

BT 的速度取决于**有多少人在传给你**，应用本身能把连接做满，但变不出做种的人。按这个顺序查：

1. **资源本身冷门**：做种数为 0 的磁力链接，任何下载器都救不了，换源是唯一办法；
2. **DHT 还在握手**：新任务或刚开应用的前几分钟速度为 0 很常见，DHT 网络需要时间找到节点，等一会儿再看；
3. **补 tracker**：这是对「找不到节点」最有效的手段，列表来源与填法见 [BT提速与tracker配置.md](BT提速与tracker配置.md)，那里还讲了端口与网络环境这两个更深的门槛；
4. **网络环境限制**：部分宽带或校园网会限 P2P 流量，换个网络环境对比一下速度就知道是不是被限。

## 四、PT 用户注意

应用官方特性里写明支持 PT。PT 与公共 BT 的最大区别是**站点有严格的规则**，用的时候记住三条：

- passkey 等鉴权信息是站点针对你账号生成的，别把带 passkey 的种子或链接分享给别人；
- 不要为提速去做任何违反站点规则的改动，被 ban 账号的代价远大于省下的时间；
- 关注站点的分享率要求，下完记得按规则保种。

## 五、直链任务的提速与限速

- **多线程**：aria2 支持对单个 HTTP/FTP 直链开多连接（`-x` / `-s` 对应的选项），支持断点续传的服务器开了明显更快；新建任务的高级设置里可以按任务设置。
- **限速**：不想占满带宽时，在 AriaNg 设置或任务选项里设全局或单任务的下载速度上限；挂机下大文件前先限速是个好习惯。
- **断点续传**：任务中断后直接重试即可从断点继续，不需要删了重来。

直链下不动时先确认链接本身还有效（在电脑浏览器里开一次试试），再回到 [常见问题排查.md](常见问题排查.md) 对症处理。打算挂机下大文件的话，先按 [后台下载保活设置.md](后台下载保活设置.md) 把系统的省电策略调好，不然锁屏几分钟任务就停了。
