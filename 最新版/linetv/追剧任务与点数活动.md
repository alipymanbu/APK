## 一、活动入口在哪

LINE TV 会不定期上线「觀劇贈點」类活动，完成指定观看任务送 LINE POINTS：

- 手机 / 网页端：官网的[追劇任務](https://www.linetv.tw/feed/mission)页面，列出当期活动；
- 电视版 App 限定活动：入口在电视版 App 的开机图上，点「立即追劇」按钮完成报名（不点报名、光看片，不算参加）。

活动是分档上线的，打开页面没有进行中的任务就说明这一档结束了，等下一档即可。具体规则每档不同，参加前先读活动页的注意事项。

## 二、参与门槛

| 条件 | 说明 |
| --- | --- |
| 帐号 | 须用 LINE 帐号登录 LINE TV（见[注册登录方法](注册登录方法.md)） |
| VIP 限定奖励 | 只给「月费及以上」的付费订阅会员，免费试用不算；参加活动后退订，点数会被追回 |
| 每人次数 | 同一活动期间每位用户只能参加一次 |

## 三、哪些观看行为不算数

这是最容易白看一场的地方，官方活动页把「不算」的情况列得很细：

| 行为 | 结果 |
| --- | --- |
| 看预告、特辑、花絮、MV 等非正片 | 不计入观看纪录 |
| 调倍速、拉时间轴快进 | 判定失败，丧失得点资格 |
| 点「略過片頭」（跳过片头进入正剧）、跳片尾直接播下一集 | 跳过的部分不计入分钟数 |
| 把播放切到后台、切去别的分页 | 视为未完成观看 |
| 多台设备同时观看同一帐号 | 视为未完成观看 |
| 重复看同一部剧的同一集 | 不具得点资格（任务要求看不同集数） |
| 跨天看（每日任务） | 每日结算到 23:59:59，跨日部分不累计 |

简单说：**用 1 倍速、正片、不跳任何段落、前台一直挂着看完**，才是有效观看。

## 四、点数什么时候到

- 活动截止后 **15~20 个工作天**内发放，遇假日顺延；
- 到账通知在 LINE 钱包里查；
- 对点数有疑问，查询窗口是**活动结束后 30 天内**，过期不再受理。

## 五、电视版限定活动的参与步骤

1. 按[注册登录方法](注册登录方法.md)里的扫码方式，把电视版 App 登录好（扫 QR Code 或手动输入电视上显示的 6 位代码均可）；
2. 回到电视版 App 的开机图，点「立即追劇」完成报名；
3. 活动期间内，在电视版 App 上按活动要求「每天完整观看」指定剧集的正片集数。

注意两点：用手机投屏参与电视版活动**不符合资格**（必须是装在 Apple TV / Android TV 上的电视版 App 本体）；手机 App 或网页版看完的，也不计入电视版任务的进度。电视版 App 怎么装见[投屏电视观看方法](投屏电视观看方法.md)。

## 六、拿不到点数的常见原因汇总

按官方活动说明，被判定失败的高频原因集中在这几条：

1. 忘了先在电视版 App 开机图点「立即追劇」报名；
2. 看的是预告或花絮，不是正片；
3. 中途按了跳过片头 / 跳过片尾；
4. 开了倍速或拖动进度条；
5. 同一帐号多设备同时在播；
6. 同一集重复观看，集数没凑够「不同集数」的数量；
7. 用免费试用身份参加 VIP 限定奖励。

会员与免费的差别、VIP 方案价格见[会员方案与免费区别](会员方案与免费区别.md)。
