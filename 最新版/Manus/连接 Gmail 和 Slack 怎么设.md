# Manus 连接 Gmail 和 Slack 怎么设

Manus 默认只能看到你在对话里给它的东西。把 Gmail、Notion、Google 日历、Slack、GitHub 这类工具连上之后，它能自己进去取数据、也能把产出写到里面去 —— 一个提示词跨几个应用干活，靠的就是这一层。本篇讲清单里有哪些通道、内置连接器怎么连、邮箱那条路怎么用，以及权限怎么收回来。

## 一、连接通道有哪几种

| 通道 | 是什么 | 适合谁 |
| --- | --- | --- |
| 内置连接器 | 官方预置的集成，用 OAuth 授权，在各套餐里都可用 | 大多数人，接常用办公与开发工具 |
| Zapier | 借 Zapier 接上大量应用，按事件触发自动化 | 需要跨工具串流程的 |
| Slack 集成 | 把通知、更新、结果发进团队频道 | 团队用结果同步 |
| 自定义 MCP 服务器 | 接自建系统、内部接口 | 有内部工具的组织 |
| API | 用程序调用 | 要自己做应用的开发者 |
| 数据源 | 官方内置的第三方数据接口 | 市场研究、财务分析这类取数场景 |

内置连接器当前覆盖的常见服务包括 Gmail、Notion、Slack、Google 日历、Google Drive、GitHub、Stripe、HubSpot、Hugging Face 等；支持清单会增删，以官方文档与设置页当时显示的为准。

## 二、内置连接器怎么连（三步）

1. **选一个连接器**：在设置里找到集成入口，从列表里挑要连的服务。
2. **授权**：跳转到那个服务并登录，按页面提示同意授权。走的是 OAuth，页面会列出它申请的范围 —— 你能看到自己放出去的是什么权限。
3. **开始用**：连上之后在提示词里直接点名那个应用即可，例如「把这周的会议要点写进 Notion 的那一页」。它会自己挑对应的连接去读或写。

## 三、连上之后典型能做什么

- **Notion + Google 日历**：读一份活动安排文档 → 为每项写好说明 → 建日历条目 → 回写文档标记「已排期」。
- **Gmail + 文档分析**：翻出本周指定主题的邮件 → 下载并分析附件 → 产出一份汇总和问题清单。
- **Stripe + 表格数据**：取一段时间的交易数据 → 与上传的费用表合并 → 生成一份测算表。

这三个例子的共同点是：**单次提示词里跨了两个以上的应用**，而不是把信息复制来复制去。要让这条路走得通，提示词里得点名具体应用与要做的动作，写法见 [怎么提任务才不容易返工.md](怎么提任务才不容易返工.md)。

## 四、邮箱这条路：把任务直接发过去

不想开客户端也能派活 —— 每个账号会分到一个专属的机器人邮箱地址（在设置里能找到，形如 `your-name-abc123@mail.manus.ai`）：

1. **转发或抄送**邮件到这个地址，就触发了任务；
2. **它读邮件正文、附件和你在邮件里写的指令**；
3. **结果以邮件回复的形式回到你的收件箱**，需要时会带上附件；
4. **只有来自预先批准的发件人地址的邮件才能触发任务** —— 这道白名单是它安全的前提，别把这个地址当公开邮箱到处留。

反复处理同一类邮件（发票、报销、行程）时，可以建**工作流邮箱**：为不同用途各分一个地址，再用你自己邮箱里的过滤规则把对应邮件自动转发过去。这样一条常规流程就不需要每次手动转发了。

## 五、权限怎么放、怎么收

连接器给的是「能读、也能写」的权限，放出去之前先想一下：

- **授权时看清范围**，用不到的能力就不要同意；
- **不用了就断**：外部工具的连接、上传过的密钥，都留在任务与账号里，定期清一遍；
- **它申请的范围就是它的上限**：你在授权页面上没给的能力，它拿不到；
- **开协作会让连接失效**：任务一旦邀请协作者，已连接的外部工具会被自动禁用，这是官方的保护设计，别当成故障去反复重连。

从读取到写入这一步尤其要想清楚：连上 Slack 之后它是能往频道里发消息的，连上 Gmail 之后是能代你回信的。**先连只用得上的那几个**，比一次全接上要稳。

## 六、哪几种情况不适合走连接器

- **授权范围之外的东西读不到**：连接器只能用它拿到的授权，没给的读不到也写不进去；
- **只是偶尔用一次**：为一次性的事去授权一个长期连接，不如直接把文件上传给它；
- **材料本身敏感**：能不连就不连，改用上传 + 任务结束就断开的做法，边界更清楚。

任务里的文件会怎么留、分享链接会暴露什么，见 [任务文件和分享链接要注意什么.md](任务文件和分享链接要注意什么.md)。
