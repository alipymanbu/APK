## 一、三条路线对照

qBittorrent Controller 的连接设置里只有一个 Host 和一个端口，它不挑你人在哪——只要手机能访问到那台电脑就行。所以「在外面连家里」的本质是把两台设备放进同一个可达网络，而不是把应用换成什么远程模式。

| 路线 | 原理 | 前提 | 动的地方 |
| --- | --- | --- | --- |
| 端口映射 + DDNS | 路由器把公网端口转发到电脑的 Web UI 端口，DDNS 绑定变化的 IP | 家里宽带要有公网 IP（新装宽带常常没有） | 路由器 + 电脑防火墙 |
| 内网穿透 | 家里跑一个客户端主动连中转服务，外面经中转进来 | 无公网 IP 也能用 | 电脑（或路由器）上多跑一个服务 |
| VPN / 虚拟局域网 | 手机与家里设备组成一张虚拟内网，常见如 WireGuard、Tailscale、ZeroTier | 两端各装一个客户端，登同一账号或同一套密钥 | 手机 + 电脑各装一个 |

## 二、怎么选

- 家里**有公网 IP**、只有自己人用：端口映射最直接，配个 DDNS 绑域名；
- **没有公网 IP**：端口映射走不通，选内网穿透或 VPN 组网；
- **不想把 Web UI 暴露到公网**：VPN 组网是唯一一条入口不开在公网的路线——手机入网后就像坐在家里，应用里照旧填 `192.168.x.x` 或虚拟网段里的地址。

## 三、决定暴露到公网前，把四件事做完

1. **改掉默认账密**：老版本 qBittorrent 的默认 admin / adminadmin 全网都知道；
2. **开 HTTPS**：Web UI 设置里配证书与私钥路径；自签名证书在手机浏览器访问时要手动信任一次；
3. **配 IP 白名单**：Web UI 设置里可以按网段限制或免认证，公网方向不要整段放开；
4. **保持防爆破封禁开启**：连续登录失败封 IP 的机制别关，它替你挡住绝大多数扫端口的脚本。

前两项没做就开公网，等于把下载队列、下载路径乃至整台电脑的管理权敞开——Web UI 一旦被别人登录，对方能改下载目录、能看到你的文件路径。

## 四、配好了回到应用怎么填

Host 填你从外面够得着的那个地址：端口映射填 DDNS 域名（或公网 IP），VPN 组网填电脑在虚拟网里的地址，穿透服务给了域名就填域名。账号密码与家里内网连的时候是同一套。若外面走的 HTTPS 与家里不一致，应用设置里的 HTTPS 勾选和端口要跟实际对上——这种「同一个服务、两种入口」的错位，正是[WebUI安全设置与连接冲突.md](WebUI安全设置与连接冲突.md)里讲的常见拦截面。
