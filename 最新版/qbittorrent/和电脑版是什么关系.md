## 一、分工：电脑干活，手机遥控

| | qBittorrent（电脑端） | qBittorrent Controller（手机端） |
| --- | --- | --- |
| 跑在哪里 | Windows / macOS / Linux 电脑、NAS | Android 手机、平板 |
| 谁在下载 | 是，种子和文件都落在电脑上 | 不是。官方说明写得很直白：这个应用不会把种子下载到你的手机或平板 |
| 怎么连上 | 桌面程序本身 | 通过电脑端 Web UI 接口连过去 |

所以「手机上装了 qBittorrent 能不能单独下载」是个伪问题——手机上装的不是 qBittorrent 本体，脱离电脑什么都下不了；反过来，电脑上没跑 qBittorrent，这个遥控器也无处可连。

## 二、为什么不用浏览器直接开 Web UI

电脑端的 Web UI 本身就能在手机浏览器里打开使用。这个应用做的不是另一套下载服务，而是把这套操作换成了原生的方式：

| | 手机浏览器开 Web UI | qBittorrent Controller |
| --- | --- | --- |
| 界面 | 电脑版网页直接缩放，按钮很小 | 原生列表与抽屉菜单，按状态筛选 |
| 完成通知 | 没有 | 任务完成可推通知 |
| 服务器配置 | 每次手动输地址端口 | 填一次保存，之后直接进列表 |
| 平板 | 网页缩放 | 双栏布局 |

偶尔看一眼进度，浏览器完全够用；长期挂着管任务，完成通知和不用每次输地址这两点就是客户端与网页的实质差别。

## 三、免费版和 Pro 版差在哪

两个版本对应两个包名：免费版（Google Play 上叫 qBittorrent Client，包名 `com.lgallardo.qbittorrentclient`）和 Pro 版（qBittorrent Controller Pro，包名 `com.lgallardo.qbittorrentclientpro`）。官方给出的差异口径：

- 核心操作（添加、暂停、恢复、删除）两边功能一致，都能管自己的 qBittorrent 服务器；
- 界面更新与问题修复先到 Pro 版；
- 服务器配置位：免费版 1 个，Pro 版最多 3 个；
- Pro 版无广告。

应用抽屉里的 **Get Pro** 就是 Pro 版的入口。只有一台下载机要管的话，免费版的功能是够用的。

## 四、还在更新吗

v4.9.2 发布于 2021 年 2 月，是开发者仓库里的最后一次发布；2023 年 11 月仓库被归档为只读。也就是说这个应用已经停止更新——它现在能用、也还能连 qBittorrent 的 Web UI，但 qBittorrent 侧以后若有接口变动，不会再有适配跟进。网盘里这份 v4.9.2 就是最终版，与官方仓库的最后一次发布一致。
