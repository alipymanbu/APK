## 一、先确认要装的是哪个东西

你在应用商店或搜索引擎里搜「qbittorrent」，大概率会同时看到两个东西：

| 名称 | 是什么 | 装在哪 |
| --- | --- | --- |
| qBittorrent | 电脑端的 BT 下载软件本体 | Windows / macOS / Linux 电脑、NAS |
| qBittorrent Controller | 安卓端遥控客户端，管的是电脑上正在跑的 qBittorrent | Android 手机、平板 |

这一篇要装的是后者。它本身不会把种子下载到手机上——你用它远程操作电脑上的下载任务。还没弄清这两者分工的话，先看[和电脑版是什么关系.md](和电脑版是什么关系.md)。

## 三、安装步骤

1. 从夸克网盘把 APK 转存并下载到手机存储；
2. 点开 APK，系统第一次会提示「不允许安装未知来源应用」，按提示给这次安装放行（各品牌入口不同，一般在系统设置的「安装未知应用」权限页）；
3. 回到下载目录再点一次 APK，等安装完成；
4. 打开应用，你会看到英文的欢迎页，中间一个 qb 图标，下面几行使用说明。

## 四、装完第一件事：填服务器

欢迎页那几行英文的意思是：先去 Settings 里填 qBittorrent 服务器信息，再用菜单里的刷新按钮拉取任务列表。换句话说，**没有可连的服务器时，这个应用里什么都不会有**。

所以打开应用后直接点左上角菜单进 Settings，照着[服务器连接设置教程.md](服务器连接设置教程.md)把电脑端的地址、账号一项项填进去；填完刷新还是连不上，再去[连不上服务器怎么排查.md](连不上服务器怎么排查.md)对号入座。

## 五、对手机本身的要求

安装包只有 2.75 MB，v4.9.2 发布于 2021 年，近几年的安卓手机基本都装得上。真正决定能不能用起来的是电脑那一端：qBittorrent 要先开 Web UI，手机和电脑要能互相访问。这两件事分别在[服务器连接设置教程.md](服务器连接设置教程.md)和排查篇里有展开。
