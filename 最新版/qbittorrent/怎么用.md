## 一、先记住一件事：操作的都是电脑上的任务

你在这份列表里看到的每一个任务，实际都跑在电脑端的 qBittorrent 上，手机只是遥控器。暂停、恢复、删除的也都是电脑那边的任务——删除时如果选了连同已下载数据一起删，电脑硬盘上对应的文件会被一并删掉，这一步想清楚再按。

## 二、抽屉菜单与状态筛选

从左侧拉出抽屉，任务按状态分成几组：

| 菜单项 | 含义 |
| --- | --- |
| All | 全部任务 |
| Downloading | 正在下载 |
| Completed | 已完成 |
| Seeding | 做种中 |
| Paused | 已暂停 |
| Active | 当前有流量传输的任务 |
| Inactive | 当前没有流量的任务 |

顶部还有 **Servers** 一项（免费版只保存一个服务器，Pro 版才有多个配置可切换），抽屉底部是 Settings、Get Pro 和 Help。

## 三、对任务能做什么

选中任务后可以暂停、恢复或删除；对整个列表也能一键全部暂停或全部恢复。做完一个动作，列表会自动刷新（前提是 Settings 里开了自动刷新）。

- **暂停 / 恢复**：临时让出带宽，或把暂停的任务继续跑起来；
- **删除**：可选是否把电脑上已下载的文件一起删；
- **强制恢复**：v4.8.8 起加入的操作，用来处理普通恢复不起作用的任务；
- 任务详情里能看到文件列表等信息，v4.9.1 起详情里的路径等内容可以长按复制出来。

完成通知收不到时，先查系统侧：不少手机的省电策略会把这类通知拦在后台，把应用加入省电白名单或允许自启动后再试（各品牌叫法不同，属常见机型经验）。

## 四、往电脑添加新下载的三种方式

1. **直接加链接**：把种子页链接或磁力链接（`magnet:?xt=...` 开头的那种）粘进去，任务会出现在电脑端队列里；
2. **浏览器点链接**：在手机浏览器里点 .torrent 下载链接时，可以把它交给 qBittorrent Controller 处理；
3. **本地 .torrent 文件**：手机里存着的种子文件，从应用里选进去一样能加。

再强调一次口径：这三种方式加的都是**电脑端**的下载队列，下载发生在电脑上，手机不会下任何东西。

磁力链接加进去之后长时间没动静，多数不是加失败：磁力链接要先由服务器那边从 DHT 网络把种子元数据拿回来，冷门资源可能等很久。对照方法：电脑端 Web UI 里看同一个任务，状态一样就说明任务在正常排队，不是手机端的问题。

## 五、平板上的双栏布局

在平板上是双栏视图：一边任务列表、一边详情，同一屏看完；手机上则是列表和详情分屏跳转。

## 六、列表不动了怎么办

先确认电脑端 qBittorrent 还开着、手机和电脑还在同一个网络里，然后点刷新。反复连不上就按[连不上服务器怎么排查.md](连不上服务器怎么排查.md)排查；如果是设置项没填对，回到[服务器连接设置教程.md](服务器连接设置教程.md)逐项核对。
