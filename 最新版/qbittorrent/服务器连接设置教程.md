## 一、先在电脑端把 Web UI 打开

qBittorrent Controller 连的是 qBittorrent 的 Web UI 接口，电脑端不开这个开关就无从连起。在电脑上打开 qBittorrent：

1. 菜单栏 **Tools → Options**（中文界面是「工具 → 选项」）；
2. 左侧选 **Web UI**；
3. 勾选 **Enable the Web User Interface (Remote control)**；
4. 端口保持默认的 **8080**（被占用了才需要换）；
5. 设定用户名和密码。老版本 qBittorrent 的默认账号是 `admin`、默认密码是 `adminadmin`；较新版本首次启动会随机生成一个密码并在弹窗里显示，用它登录后再在 Web UI 设置里改成自己的；
6. 点 OK 保存。

qBittorrent 官网是 [https://www.qbittorrent.org](https://www.qbittorrent.org)，电脑端还没装的话先去那里拿安装包。

保存后可以先在电脑本机浏览器开 `http://127.0.0.1:8080` 试一下，能弹出登录框说明服务端这边已经就绪。

## 二、手机端每一项怎么填

手机上打开应用，点抽屉菜单里的 **Settings**。应用界面是英文的，下表按界面字段对照；免费版只有一个服务器配置位（Pro 版有三个），逐项填：

| 界面字段 | 填什么 | 说明 |
| --- | --- | --- |
| Host | 电脑的 IP 或主机名 | 不要带 `http://` 前缀，填 `192.168.1.124` 这样的裸地址或 `myserver.domain.com` |
| Username | Web UI 的用户名 | 电脑端 qBittorrent 里设的那个 |
| Password | Web UI 的密码 | 同上 |
| Port | 8080 | 在高级选项里，与电脑端 Web UI 端口一致 |
| 启用 HTTPS | 一般不勾 | 只有电脑端 Web UI 里开了 HTTPS 才勾 |
| 子文件夹 | 一般留空 | 只有 qBittorrent 发布在子路径下才填，如 `http://myserver.domain.com/torrents` 对应填 `/torrents` |
| 连接超时 | 5 秒 | 建立连接的最长等待 |
| 数据超时 | 8 秒 | 等数据返回的最长等待 |

填完保存，回到主界面点右上角的刷新按钮，任务列表应该就出来了。

## 三、值得顺手设置的几项

Settings 里还有几项不影响连接、但影响日常体验：

- **自动刷新**：勾上后每次操作（暂停、恢复、删除）列表会自动刷新，刷新间隔自己定；
- **完成通知**：勾上后任务下载完成会推通知；检查频率默认即可，嫌打扰可以调低；
- **深色主题**：勾上后应用转黑色主题，需要重启应用才生效；
- **在列表前显示速度和总数**：列表顶部会多一行总的上传/下载速度与任务数。

## 四、电脑端那几个安全开关，动之前先想连接

电脑端 Web UI 设置页里还有几个安全开关，改安全设置时可能顺手把客户端的连接弄断：

| 开关 | 作用 | 对连接的影响 |
| --- | --- | --- |
| Host header 校验 | 拒绝 Host 头对不上的请求 | 反代、面板场景下账号密码对也报未授权 |
| CSRF 防护 | 拦来源不一致的请求 | 来源与目标不一致时被拒 |
| 反向代理支持 | 按反代环境处理请求 | 走反代必须开，新版还要填受信任代理 |
| IP 白名单 | 名单内地址跳过认证 | 填错网段会影响预期中的免认证 |

这几项各自怎么处理，[WebUI安全设置与连接冲突.md](WebUI安全设置与连接冲突.md)里有逐项展开。

## 五、填完连不上先别乱改

填完刷新没反应是这一步最常见的结局，多数是 IP、端口、防火墙这类小问题，按[连不上服务器怎么排查.md](连不上服务器怎么排查.md)的顺序过一遍基本能定位。卡在更前面一步（比如安装包还没装上）就回[下载与安装教程.md](下载与安装教程.md)。
