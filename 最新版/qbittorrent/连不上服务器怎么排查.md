## 一、第一步永远是：用手机浏览器先开一次 Web UI

应用的开发者明确建议过：配好应用之前，先用浏览器确认 Web UI 本身是通的。在手机浏览器地址栏输入 `http://电脑IP:8080`（端口按你实际设的）：

- **能弹出 qBittorrent 登录框** → 服务端和网络都没问题，问题出在应用的设置上，跳到第三节逐项核对；
- **打不开 / 一直超时** → 问题在电脑端或网络层，看下一节。

## 二、浏览器也打不开：查电脑端和网络

按命中率从高到低：

1. **两个设备不在同一网络**：手机在用流量、电脑在内网，这是最常见的原因。让手机连上和电脑同一个 Wi-Fi 再试；
2. **Web UI 没开或端口不对**：电脑端 qBittorrent 的 Tools → Options → Web UI 里确认已勾选启用，端口与手机端填的一致；
3. **电脑防火墙拦了端口**：Windows 防火墙默认可能不放行入站连接，给 qBittorrent 或那个端口加一条放行规则；
4. **电脑休眠或关机**：合盖休眠后服务就停了；
5. **Web UI 监听地址被改过**：Web UI 设置里的监听地址如果被指定成了某个具体 IP，其他设备可能连不上，改回全部地址（`0.0.0.0`）。

## 三、浏览器能开、应用连不上：核对应用设置

应用的设置项怎么填见[服务器连接设置教程.md](服务器连接设置教程.md)，这里按现象对号入座：

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 一直转圈 / 超时 | Host 填了 `http://` 前缀；端口不一致；超时太短 | Host 只填裸地址；端口与电脑端一致；连接/数据超时改回 5 / 8 秒 |
| 提示认证失败 | 账号密码与 Web UI 不符；较新版本的 qBittorrent 首次启动会随机生成密码并弹窗显示 | 以 qBittorrent 里实际设置为准，忘了就在电脑端重设 |
| HTTPS 报错 | 电脑端没开 HTTPS 而应用勾了；或电脑端用了自签名证书 | 两边口径对齐；自签名证书连不上时，先关掉应用里的 HTTPS 验证一遍 |
| 挂了反向代理 / 子路径发布 | 子文件夹没填 | 服务发布在 `/torrents` 这类子路径时，应用里的子文件夹要填 `/torrents` |
| 账号密码正确仍提示未授权 | Host header 校验或 CSRF 防护在拦 | 逐项对照[WebUI安全设置与连接冲突.md](WebUI安全设置与连接冲突.md) |
| 之前输错过几次密码，现在对的也进不去 | 登录失败触发了 IP 封禁 | 等封禁时长过去，或重启电脑端 qBittorrent 立即解封 |

## 四、版本兼容的边界

官方描述里写明的兼容口径是 qBittorrent 服务器 4.1.x、4.2.x——这是 2021 年 v4.9.2 时代的说法。更新版本的 qBittorrent 上 Web UI 接口可能有变动，目前没有官方声明支持到哪个版本。遇到接口对不上的情况，以官方仓库 [https://github.com/lgallard/qBittorrent-Client](https://github.com/lgallard/qBittorrent-Client) 的说明为准，或先用手机浏览器直接开 Web UI 顶着用。

## 五、想在外面（流量）连家里电脑

前提是电脑端的服务能从外网到达。端口映射、内网穿透、VPN 组网三条路线怎么选、暴露前后要做哪些安全设置，单独写在[在外面连家里下载机的做法.md](在外面连家里下载机的做法.md)里，这里不重复。
