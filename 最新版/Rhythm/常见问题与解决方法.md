# Rhythm 常见问题与解决方法

> 汇总用户实测反馈里出现频率高的问题：均衡器打不开、播放出错、插件下载失败、在线源搜不到等，每条给出可先试的做法。

> 下列问题均来自用户实测反馈（覆盖 v3.0.810 ~ v3.0.858 一段时间），不是官方故障表；同一条在不同机型、不同版本上表现可能不同，按顺序试，无效就跳下一条。

## 一、均衡器打不开

有用户在荣耀 X10、荣耀 10 青春版（安卓 10）上从 v3.0.810 试到 v3.0.858，均衡器入口都点不开。可先试：

1. 重启应用、再重启手机，进设置确认音量没被静音后重试一次；
2. 清一次应用缓存（设置 → 应用 → Rhythm → 存储 → 清除缓存），重进再试；
3. 仍打不开就先用系统自带的音效 / 均衡器顶替（多数手机在 设置 → 声音 里有），等版本更新修复。

## 二、播放出错后，下一首要点两次才能播

播放报错后，第一次点「下一首」只有按钮反馈、不出声，再点一次才正常。临时绕法：出错后回列表重新点一首，或隔一两秒再点下一首，不必在同一秒里反复戳同一个按钮。这是反馈里存在一段时间的表现，是否已在新版本修复，以你装的版本实测为准。

## 三、下载插件显示过期 / 下载失败

- 打开下载插件提示「v7 / v8 过期」：插件包本身有有效期或已更新，**换新版本的插件包重装**（见 [扩展插件怎么安装.md](扩展插件怎么安装.md) 的手动添加步骤）；
- 百度相关的下载失败：同一反馈里与插件过期一起出现，先按上面换插件再试；
- 下载入口在播放页右上角三点菜单里，公开教程的口径是**装完扩展插件后才出现下载功能** —— 先确认相关插件已装好，再判断是不是坏了。

## 四、在线源搜不到内容 / 提示受限

1. 先点主页左上角按钮，确认该栏目的插件**已安装且没被勾掉** —— 装了不显示多半是这里；
2. 有用户反馈部分在线源用一阵会**短暂限制 IP**：换个时间段再试，或先切别的插件；
3. 换插件也搜不到：该插件的资源侧出了问题，等更新，本地音乐不受影响（见 [本地音乐与播放设置.md](本地音乐与播放设置.md)）。

## 五、本地歌曲搜不出来 / 专辑归类不对

- 搜不到：先查权限（存储 / 媒体），再确认格式 —— 有用户反馈 `MID` 等格式不支持，转成 MP3 / FLAC 再重扫；
- 某文件夹的歌没归进专辑：反馈里确认过存在，先把文件的专辑 / 艺术家标签补全，仍不行就用文件夹视图直接浏览该目录。

## 六、视频类播放问题（插件里的视频）

部分在线插件带视频内容，实测反馈的边界比较清楚：

- 百度网盘里的**长视频**（用户观察约一集动画长度以上）播不了；
- 视频播放**卡顿**、部分视频格式只能当音频播（有用户举例高清电影）；
- 这类内容更适合用网盘官方客户端看，Rhythm 里当音频听即可；换短视频源受影响较小。

## 七、网盘文件长按不能批量操作

有用户反馈网盘插件里长按文件**无法多选、无法批量加入播放**。当前只能逐个点播；把常用内容建成播放列表可以减少重复操作。同类批量功能的可用性以插件更新为准。

## 八、装错了 / 想换版本

- 页面上说的「Rhythm 打不开、要走一串引导」可能说的是 GitHub 上的同名播放器（包名 `chromahub.rhythm.app`）—— 认准 `com.rhythm.app`，见 [下载与安装教程.md](下载与安装教程.md)；
- 换版本前先卸载旧包再装（避免签名或数据残留），装完记得重新给权限；版本号怎么看也写在安装篇。
