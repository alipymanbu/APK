## 一、Rhythm 是什么

Rhythm 是一款安卓上的插件化音乐播放器：你手机里的本地音乐它直接播，想听在线内容（在线音源、听书、广播）或挂载网盘、媒体服务，则通过安装插件实现 —— 底子是个「空壳」，功能靠插件扩展。界面底部只有「主页」和「媒体库」两个标签，主页默认停在本地音乐页。

装之前先认准两件事，别装成同名的另一款：

- **包名是 `com.rhythm.app`**。这是本篇及整套文档唯一讨论的对象；
- 搜索引擎里还有好几个叫 Rhythm 的播放器，最容易混的是 GitHub 上 [cromaguy/Rhythm](https://github.com/cromaguy/Rhythm)（包名 `chromahub.rhythm.app`，在 F-Droid 上架的纯本地播放器），以及 [EncryptoCyphers/Rhythm](https://github.com/EncryptoCyphers/Rhythm)。**它们与本文这款是不同软件**，包名、安装包、界面都不一样；网上关于「Rhythm 打不开、要走引导设置」的说法多半指的是 GitHub 那款，不是这一款。

## 三、安装步骤

1. 把 APK 传到手机：在手机端打开网盘链接转存后直接下载，或电脑下载后用数据线 / 传输工具发过去。
2. 点击 APK 安装。若系统提示「禁止安装未知来源应用」，按提示为当前来源（浏览器、文件管理器或网盘应用）打开允许开关，再返回安装。
3. 装完打开，按下一节把权限给齐。

装完后可在 设置 → 应用 里查看应用信息，确认包名显示为 `com.rhythm.app`。

## 四、首次启动：语言与权限

按公开教程的常见顺序，首次启动会经过这几步（不同版本措辞可能略有差别）：

1. 开屏页点「开始」；
2. 界面不是中文时，在语言（language）选项里切到中文；
3. 把应用请求的权限打开 —— 至少要给**存储 / 媒体读取权限**，否则它扫不到你手机里的音乐；**通知权限**关系到锁屏控制与通知栏切歌，一并允许为好（拒绝了可在 设置 → 应用 → Rhythm → 权限 里补）；
4. 等它扫描本地音乐，扫完就能直接播。

装完是空的不代表出错 —— 这款应用本身不带在线曲库，在线内容要装插件才有，见 [扩展插件怎么安装.md](扩展插件怎么安装.md)；本地扫描的细节（有用户反馈部分歌曲搜不到）见 [本地音乐与播放设置.md](本地音乐与播放设置.md)。

## 五、版本号怎么看

公开渠道见到的版本号都形如 `v3.0.810` → `v3.0.832` → `v3.0.858`：前两段 `3.0` 稳定不变，末段往上递增，数字越大越新。你手上这份是 **v3.0.858**。版本会持续更新，具体最新版以你能访问到的下载页当时显示为准；升级前若想保住插件与设置，先看应用内有没有导出 / 备份入口再动手。
