## 一、插件是怎么回事

Rhythm 本体只负责播放与管理，**在线内容全部由插件提供**：一个插件接一类资源（在线音源、听书、网盘、媒体服务），装上它，主页和媒体库里就多出对应栏目。插件文件是 `rapk` 格式的扩展包，应用内的「扩展」入口负责安装与管理。

公开介绍页与用户汇总提到的内置插件有十几款，覆盖三类：

| 类别 | 公开资料列出的插件 |
| --- | --- |
| 音乐 / 广播类 | 爱听音乐、时代音乐、无名音乐、无忧音乐、DAB 音乐、全球广播、酷我畅听、酷狗、bilibili、油管音乐、HiFi Tidal 歌曲搜索 |
| 听书 / 有声类 | 云图有声、有声小说、爱听有声、无忧有声、博看有声、海洋听书 |
| 存储 / 服务类 | Alist、百度网盘、夸克网盘、UC 网盘、123 云盘、115 云盘、WebDAV、Jellyfin、Emby |

以上是各版本情况不一的清单（随插件增删变化），**以你安装的版本里实际显示的为准**。另据用户反馈，v3.0.858 这一版把在线音乐改成了外挂插件形式，装了对应插件才有在线栏目，不是本体自带。

插件是独立下载的，体积不小：有用户反馈**下载类扩展约 8～9M、油管插件约 3M** —— 装之前留意网络状况，装到一半失败就换网络重来。

## 二、装内置插件

1. 进入软件，在插件 / 扩展列表里上下滑动，找到想要的插件（按音乐、听书、网盘等分类排列）。
2. 点它安装。以在线音源类为例：点开插件 → 点安装，装完再点搜索框，就能搜到该插件提供的内容。
3. 装好后回到主页，**点左上角的按钮**，能看到全部已装扩展，勾选要显示的栏目。

装好插件后，主页顶部的栏目、底部「媒体库」的列表都会跟着变化 —— 只想看某一类时，还是用左上角那个按钮筛选。

## 三、手动添加扩展链接

插件除了应用内置列表，还能用链接手动添加：

1. 主页点右上角的**设置**按钮；
2. 找到「扩展」一项，点它右侧的 **+** 号；
3. 粘贴或输入扩展的链接，确认添加；
4. 回到主页点左上角按钮，即可看到新加入的扩展。

手动添加用的是你拿到的扩展链接，链接有效性由提供方决定 —— 打不开、装不上先换一个来源的链接试，再看是不是应用版本太旧。

## 四、装插件时会遇到的几个坑

以下都有用户实测反馈（截至 v3.0.858 前后，具体以你装到的版本为准）：

- **插件装上后删不掉**：有反馈装完的插件在管理界面无法卸载。目前没有确认的解法，装之前先想清楚要不要它；实在碍事，只能走 设置 → 应用 → Rhythm → 存储 → **清除应用数据** 重置（本地设置会一并清掉）。
- **下载类插件提示过期**：有用户反馈下载插件（v7/v8）打开显示「过期」、百度下载失败 —— 这是插件侧的版本问题，换更新的插件包或改用别的下载 / 网盘插件。
- **在线源短暂限制 IP**：部分在线插件用一阵会提示受限或搜不到结果，隔一段时间再试、或先切别的插件顶上。
- **插件装完不显示栏目**：回主页点左上角按钮确认它没被勾掉 —— 栏目是按已装扩展动态生成的，装了不等于显示。
