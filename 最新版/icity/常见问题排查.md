## 一、安装阶段

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点安装包没反应或提示解析失败 | 文件没下完整 | 对照 [下载与安装教程.md](下载与安装教程.md) 里的 MD5 重下 |
| 弹「禁止安装未知来源的应用」 | 系统拦了非商店来源 | 按提示给当前来源打开「安装未知应用」开关再装 |
| 提示空间不足 | 手机剩余空间太少 | 36.87M 的包，建议预留几百 MB 再装（含解压与缓存） |
| 装完提示与已有应用冲突 | 手机里有同名但不同包的应用 | 先卸掉旧的再装；装完核对包名是否为 `icity.com.riji.icityjishi.jishiben` |

系统要求 Android 6.0 及以上，低于这个版本装上也跑不起来。

## 二、注册与登录

- **收不到验证邮件**：先翻垃圾邮件文件夹；再核对邮箱有没有拼错。确认都没问题就回注册页重新触发一次。
- **收不到短信验证码**：看短信拦截列表，验证码多由 106 开头的号码发出；再确认手机号没输错、信号正常。
- **验证码填了说不对**：验证码有时效，超时就点「重新获取」，别拿旧码反复提交。
- **提示用户名已存在**：换一个，用户名全应用唯一。
- **忘记密码**：用注册时留的邮箱或手机号走找回流程，见 [注册与登录.md](注册与登录.md) 第五节。注册联系方式早就不用了的话，这次找回后顺手把它改掉。

## 三、应用打不开或用着用着退了

按成本从低到高试：

1. **杀掉进程重开**：上滑进多任务，划掉它再打开。
2. **重启手机**：很多偶发的卡死重启后就好了。
3. **清缓存**：设置 → 应用 → 该应用 → 存储 → 清除缓存。**清缓存不等于清数据**，先只清缓存；「清除数据」会把没同步的本地记录一起抹掉，轻易别点。
4. **确认系统版本**：Android 6.0 以下跑不了，见上表。
5. **重装**：以上都不行再卸载重装，装之前确认日记已经登录了账号或导出过，见下一节。

写日记中途应用被系统杀掉是最常见的丢稿原因 —— 改完就点保存、别攒着，见 [创建第一篇日记.md](创建第一篇日记.md) 第四节。

## 四、换手机 / 重装后内容还在不在

日记跟着账号走，顺序是：

1. 旧手机上先登录账号，并确认内容已经写完保存；
2. 新手机装好应用（[下载与安装教程.md](下载与安装教程.md)），登录**同一个账号**；
3. 进日记本核对内容，缺哪个本子就等它同步完再看。

若你从未注册过账号，记录只存在原手机本地 —— 换机前在旧手机上把内容导出或截屏留存。应用内是否有自动备份开关、备份到哪，以你那一版「设置」里实际出现的选项为准；界面上没有的项，本文不作承诺。

## 五、内容相关的问题

- **误删了一篇日记**：先去「设置」里找「回收站」，有教程称 30 天内可恢复，见 [删除与导出日记.md](删除与导出日记.md) 第二节。
- **想给日记留个备份**：走导出，路径是日记详情页 → 更多 → 导出，见 [删除与导出日记.md](删除与导出日记.md) 第三节。
- **日记内页字看着太小 / 太大**：有教程给的路径是「我的 → 左上角设置 → 日记内页字体」，在弹出的选项里挑一档（如「超大」）。设置里找不到这项就先确认版本。
- **换了账号**：我的页面 → 退出登录 → 用另一个账号登录，两个账号的内容互不相通，切换前先确认当前账号的日记已经保存。

## 六、功能找不到

- **没有日历 / 相册 / 图片版式入口**：这几个是 V4.0 加的，先核对版本，见 [日记本进阶功能.md](日记本进阶功能.md) 第一节。
- **找不到打印**：入口藏在日记或本子的「更多 / 分享」里，不同版本位置不同；确认版本后仍没有，说明该版本未提供，不作它想。
- **各处按钮跟我描述的不一样**：机型、版本、深色模式都会改布局，以你屏幕上实际显示为准，动作顺序（进记录页 → 选本子 → 新建）是不变的。
