## 一、为什么要先注册

你可以不注册直接写日记，但内容只存在这台手机上；注册之后日记跟账号绑定，换手机、重装应用时靠登录同一个账号把记录找回来。写第一篇之前先把账号建好，成本最低。

## 二、注册入口在哪

1. 打开应用，进入底部的「我的」页面。
2. 点「登录 / 注册」。
3. 在登录页里选「注册账号」。

如果你拿到的版本首屏直接给了「注册」按钮，点它也一样进到注册页。

## 三、要填哪些东西

按页面提示依次填：

| 填写项 | 要求 |
| --- | --- |
| 用户名 | 全局唯一，用来在应用里标识你 |
| 联系方式 | 有效的邮箱或手机号，用于收验证信息和以后找回密码 |
| 密码 | 自己设一个记得住的；两次输入要一致 |
| 服务协议 | 勾选同意《服务条款》与《隐私政策》，不勾选提交不了 |

提交后系统会发一封验证邮件或一条短信验证码，按提示点链接或输入验证码完成激活，账号才算正式可用。验证信息一般有有效期，收到就尽快用掉；过期了回注册页重新触发一次即可。

有用户反馈收不到验证邮件时先查垃圾邮件文件夹、再核对邮箱地址有没有拼错；收不到短信则看下拦截列表（多为 106 开头的号码）。更多排查见 [常见问题排查.md](常见问题排查.md)。

## 四、日常登录

回到「我的 → 登录 / 注册」，输入注册时用的用户名（或联系方式）和密码即可。登录成功后再去写日记，见 [创建第一篇日记.md](创建第一篇日记.md)。

## 五、忘记密码

用注册时留下的邮箱或手机号走「找回密码」流程：重置链接或验证码会发到那上面。正因为如此，注册用的联系方式要保证自己能长期收信 —— 换号、换邮箱之前先在账号设置里把绑定改掉，否则以后找回密码会很麻烦。

## 六、注册遇到问题

- **提示用户名已被占用**：换一个，用户名不允许重复。
- **验证码输错或过期**：点「重新获取」拿新码，连续失败就等一会再试。
- **提交后没反应**：先确认网络正常、必填项和协议勾选都完成，见 [常见问题排查.md](常见问题排查.md)。
