## 一、先确认这是哪一版

同一个名字在不同渠道的包并不一样，装之前先对着下表核一遍。下面这组数字是网盘里那份安装包的事实，不是网上各下载站标称的最新版：

| 项目 | 值 |
| --- | --- |
| 版本 | V4.0 |
| 包名 | `icity.com.riji.icityjishi.jishiben` |
| 安装包大小 | 36.87M |
| MD5 | `916c115a123ab8929f56c44c78371f55` |
| 最低系统 | Android 6.0 及以上 |
| 开发者 | 深圳市字符世界科技有限公司 |

网上还能看到体积 100 多 M、包名 `com.notesic.ity` 的同名应用，那是另一个包，别拿它的版本号来对这一份。以你在手机上核出来的包名为准。

## 二、下载安装包

从 [iCity 我的日记安装文件资源（夸克网盘）](https://pan.quark.cn/s/bc333f8cea44) 转存并下载到手机（或先下到电脑再传过去）。文件名形如 `icity_vV4.0.apk`，大小约 36.87M。

## 三、装到手机上

1. 用手机的文件管理器找到下载好的 `.apk`，点它。
2. 如果弹出「禁止安装来自此来源的应用」，按提示跳到设置里，给当前这个来源（文件管理器或浏览器）打开「安装未知应用 / 允许来自此来源」的开关，再返回继续装。各品牌路径不同，常见是「设置 → 安全 → 安装未知应用」。
3. 装完点「打开」。首次启动会先让你同意使用协议与隐私政策，不同意是进不去的。

装不上、装完打不开的情况，见 [常见问题排查.md](常见问题排查.md)。

## 四、核对装的是不是这份包

装好后到「设置 → 应用 → 应用管理 → 找到该应用」看包名是否为 `icity.com.riji.icityjishi.jishiben`（部分机型要在「查看高级信息」里才显示包名）。想进一步确认文件没下坏，可在电脑上打开命令行执行：

```powershell
certutil -hashfile icity_vV4.0.apk MD5
```

输出的 MD5 应与表格里的 `916c115a123ab8929f56c44c78371f55` 一致；不一致说明文件在传输中损坏了，重新下载一次即可。

## 五、装完之后

打开应用，按提示走完首次启动，然后去 [注册与登录.md](注册与登录.md) 把账号建起来 —— 日记内容跟着账号走，换设备时靠它。
