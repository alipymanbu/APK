## 一、先确认两个前提，缺一个都装了也不生效

LuckyTool 装上不会立刻生效——它是 **Xposed 模块**，要靠 Root 环境和 LSPosed 框架才能干活。开工前对照下面两条：

| 前提 | 说明 |
| --- | --- |
| 设备已 Root | Magisk、KernelSU、APatch 任一均可；没 Root 就先去搞 Root，本文后面全部步骤都建立在它之上 |
| 已装 LSPosed 框架 | 一般是 LSPosed 的 Zygisk 版：在 Magisk 里打开 Zygisk 后刷入 LSPosed，重启；KernelSU / APatch 装对应的 LSPosed 发行版 |

系统方面，官方推荐 **ColorOS 12 及以上**；ColorOS 之外的系统（原氧、Realme UI 等）不在官方适配口径内，能不能用要自己试。更细的版本与机型边界见 [支持的ColorOS版本与机型.md](支持的ColorOS版本与机型.md)。

## 二、拿到安装包

两条获取途径，按需选：

- **本页头部的 [LuckyTool 安装文件资源（夸克网盘）](https://pan.quark.cn/s/97e101b24ffe)**：转存后直接下载，适合国内网络环境；
- **官方 release 页面**：[https://github.com/Xposed-Modules-Repo/com.luckyzyx.luckytool/releases](https://github.com/Xposed-Modules-Repo/com.luckyzyx.luckytool/releases) ，官方文档的下载页也指向这里，版本始终以该页面当时显示为准。

官方在项目首页明确声明这个模块**永久免费**、并提醒「请勿上当受骗」——看到有人拿 LuckyTool 收费售卖，那是二道贩子，模块本身一分钱不要。

网盘里那份包的实测信息（以它为准，别拿网上搜到的版本号来对）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.2.8 |
| 包名 | `com.luckyzyx.luckytool` |
| 大小 | 8.33M |
| MD5 | `6F40E2CBCACA0EB8FF3CA15236EEE923` |

下载完可以校验一下 MD5 与上表一致，再往下装。官方最新版的版本号通常比 1.2.8 新，属正常现象——网盘存的是当时收录的那一版。

## 三、安装并启用模块（照官方流程走）

1. 安装 LuckyTool 的 APK（普通安装即可）。
2. 打开 **LSPosed 管理器** → 模块列表 → 找到 LuckyTool → **启用**，并按提示勾选它推荐的作用域应用（这一步漏掉，后面所有功能都不会生效）。
3. 打开 LuckyTool。首次启动如果弹出**获取 Root 权限**的对话框，点**允许**；如果你用的是 KernelSU，要先在 KSU 的超级用户列表里勾选 LuckyTool，再回到模块里操作。
4. 给 LuckyTool **所有文件访问权限**（系统设置 → 应用权限里开）。这个权限是给模块**导出日志**用的，不开以后排查问题会很被动。
5. 进功能页，把你要用的开关逐个勾上，然后**返回模块主页**（见 [状态栏时钟与控制中心设置.md](状态栏时钟与控制中心设置.md) 的具体开关位置）。
6. 点模块主页**右上角的重启按钮** → 选 **重启作用域**。这一步会强制停止除系统框架外的所有已勾选应用，并加载功能适配数据。
7. 有一部分功能的作用域是**系统框架**，这类功能光重启作用域不够，还必须**重启一次手机**。

## 四、怎么判断装成功了

按顺序核对，任何一条不满足都先回到对应步骤：

1. LSPosed 里 LuckyTool 显示为**已启用**、作用域已勾选；
2. 模块里 Root 授权已给、文件访问权限已给；
3. 功能开关已打开，且执行过一次 **重启作用域**；
4. 涉及系统框架的功能，重启过手机；
5. 打开对应界面（状态栏、锁屏、桌面……）能直接看到变化。

对不上号的话，别急着重装——直接按 [模块不生效排查方法.md](模块不生效排查方法.md) 的清单逐条排查，那篇把「重启作用域」和「重启系统」的区别、日志怎么保存都写清楚了。

## 五、升级与重装注意

- 官方明确提醒：**版本更新后强烈建议重启一次系统**，否则部分系统功能可能出现不生效的情况。
- 模块内置**检测更新**功能：打开 LuckyTool 时若有新版本会弹提示，可直接在弹窗里选安装（来源为官方 GitHub），装完照例重启一次系统。若你的版本里没弹过更新，也不影响手动去 release 页面下。
- 覆盖安装新版本后，如果原来好用的功能突然失效，先重复第三步的 6～7（重启作用域，再视情况重启手机），适配数据会重新加载；升级系统后出现「不报错但不生效」，排查篇还有一招「优化 Dex」。
- 想换别的来源的包时，先用 MD5 核对；不同来源的同一个版本，MD5 对不上就别混用。
