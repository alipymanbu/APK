# LuckyTool 模块不生效排查方法

> 开了开关但界面没变化、或改一半失效时，按这份清单从上往下查：先自查八步，再看日志，最后才是反馈。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [支持的ColorOS版本与机型.md](支持的ColorOS版本与机型.md)

---

> **LuckyTool 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/97e101b24ffe](https://pan.quark.cn/s/97e101b24ffe)

## 一、先分清三种「不生效」

排查前先给自己归类，三种情况的处理路径完全不同：

1. **所有功能都没反应** —— 多半是框架层问题：LSPosed 没启用模块、Root 没授权、作用域没勾。回头对照 [下载与安装教程.md](下载与安装教程.md) 第三节重走一遍。
2. **个别功能没反应** —— 多半是这一项的作用域或适配问题，走下面的八步自查。
3. **原来是好的，更新后坏了** —— 先执行一次「重启作用域」；官方明确提醒**版本更新后建议重启一次系统**，很多「更新后失灵」就是漏了这一步。

## 二、八步自查（官方复现流程，逐条做）

按顺序执行，做到哪条解决问题就停：

1. 确认装的是**最新版**模块；
2. 如果你在官方 TG 讨论群里，可换群文件里的最新 **beta** 版试试，部分问题 beta 已修；
3. 打开 LSPosed，确认 LuckyTool **已勾选对应的推荐作用域**；
4. 打开 LuckyTool，确认**对应功能的开关**确实开着；
5. 点模块主页**右上角的重启按钮** → 选 **重启作用域**（这会强制停止作用域应用并重新加载功能适配数据）；
6. 打开对应作用域的应用、**主动触发一次功能**（比如下拉控制中心看磁贴），此时应该生效、或在模块日志页打印报错；
7. 还不生效 → 走第 8 条；
8. **重启手机**。注意：作用域是**系统框架**的功能，必须用这一步，前七条对它无效。

一个容易搞混的点：**重启作用域 ≠ 重启系统**。重启作用域只重载被勾选的普通应用（系统界面、桌面、相机这些），系统框架类功能的改动只有整机重启才会加载。拿不准某功能属于哪类，就两种都来一遍。

### 升级系统后的专属一招：重新优化 Dex

如果你是**刚升级完系统**，出现的是「不报错、但就是不生效」，官方 README 给了另一条路：

- 用模块**主页右上角重启菜单里的「优化 Dex」**功能跑一遍；
- 或者到 LSPosed 里，**长按对应的作用域应用 → 点「重新优化」**。

官方给的例子：开发者选项通知怎么都移除不掉，重新优化「系统界面」后就恢复了。原理是系统升级后旧的优化缓存对不上新框架，重新优化即重建——所以这招只在**升级系统之后**的场景有意义，普通不生效先走上面八步。

## 三、日志怎么保存（自查无效时必须做）

日志是你判断「是没适配、还是自己配错」的唯一硬证据，三层依次来：

1. 打开 LuckyTool 的**日志页面**：有报错 → 点**右上角保存/分享按钮**导出日志文件；
2. 日志页没报错 → 把模块**留在后台**，按上面的流程复现一次问题，然后**立刻回日志页刷新**并保存；
3. 还是没有日志 → 打开 **LSPosed → 日志页面**，保存 LSPosed 日志文件。

配合「所有文件访问权限」（安装时给的那个）才能正常导出——权限没给的话先补上再试。

## 四、反馈前要备齐的材料

自己排查完仍无解，才轮到向官方反馈。官方对反馈有硬性材料清单，缺了会被警告甚至封禁，先备齐再发：

| 材料 | 是否必须 |
| --- | --- |
| 模块主页信息截图 | 必须 |
| 模块日志页面的报错文件 | 必须 |
| LSPosed 日志文件 | 模块日志无报错时必须 |
| 作用域 APK 文件 | 必须 |
| 问题复现录屏 / 截图 | 可选 |

**作用域 APK** 指出问题那个应用的安装包：按报错日志里的图标或标题确定是哪个应用，用 MT 管理器这类能提取 APK 的工具导出。如果日志显示是 **Android 系统框架**报错，则到根目录的 `/system/framework/` 下把这几个文件复制出来：

```text
framework.jar
oplus_framework.jar
services.jar
oplus_services.jar
oplus-service-jobscheduler.jar
```

官方反馈渠道是 TG 讨论群（`https://t.me/+F42pfv-c0h4zNDc9`），提交规则以官方文档的问题反馈页当时显示为准。

## 五、自查时最容易漏的三个点

- **只开了开关、没重启作用域** —— 开关改的是配置，重启作用域才把配置加载进去，这是最高频的「假故障」；
- **更新版本后没重启系统** —— 官方下载页专门强调过这一步；
- **把「不会用」当「没适配」** —— 官方反馈页原话：你不会用和模块没适配要分清。版本太旧、系统版本超出适配范围的情况见 [支持的ColorOS版本与机型.md](支持的ColorOS版本与机型.md)。
