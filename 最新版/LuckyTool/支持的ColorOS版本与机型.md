## 一、系统要求：官方口径只有一句话

官方模块介绍页对系统的要求是：**推荐 ColorOS 12 及以上**。

这句话的含义要拆开看：

- **ColorOS 12 以下**（ColorOS 11 及更早）不在推荐范围，功能适配从 12 起步，老系统上大概率部分功能失灵；
- **一加国行 / 国际的 ColorOS、氧 OS** 都是 ColorOS 血统，有用户在氧 OS 上跑通过部分功能，但官方测试口径以 ColorOS 为准，超出部分算自测；
- **非 ColorOS 系统**（MIUI、OriginOS 等）直接不用试，模块 hook 的全是 ColorOS 的系统应用。

除系统版本外，前置条件仍是 Root + LSPosed，见 [下载与安装教程.md](下载与安装教程.md)。

## 二、测试机型与开发者

- **官方测试机型**：OnePlus 9RT，模块介绍页标注的测试环境为 A14、C14 —— 官方是在这台机器上验证功能的，其他机型属于「同版本 ColorOS 大概率可用、细节自测」。
- **开发者**：忆清鸣（luckyzyx），GitHub 主页 `https://github.com/luckyzyx` ；模块在 LSPosed 官方模块仓库收录，地址为 [https://modules.lsposed.org/module/com.luckyzyx.luckytool](https://modules.lsposed.org/module/com.luckyzyx.luckytool) 。

## 三、模块会碰哪些系统组件（作用域一览）

功能生效的前提是 LSPosed 里勾上对应作用域。官方列出的作用域共 16 项：

| 类别 | 作用域 |
| --- | --- |
| 框架与服务 | 系统框架、系统服务、外部存储设备 |
| 系统界面 | 系统界面、时钟、设置 |
| 桌面与锁屏 | 系统桌面 |
| 系统应用 | 安全中心、电池、截屏、软件更新、相机、应用包安装程序、云服务、主题商店 |
| 厂商特色 | 游戏助手 |

两个实操含义：

1. **勾作用域按需勾**：装的时候 LSPosed 会提示推荐勾选，直接按推荐来最省事；手动挑的话，你要用的功能在哪个分区就勾哪个（对照 [状态栏时钟与控制中心设置.md](状态栏时钟与控制中心设置.md) 的分区表）。
2. **系统框架是特殊项**：勾了「系统框架」的功能，改完必须重启手机才生效，只重启作用域没用——排查时也最常卡在这，详见 [模块不生效排查方法.md](模块不生效排查方法.md) 第二节。

## 四、版本号怎么看

三个版本号来源，别混：

| 来源 | 版本 | 说明 |
| --- | --- | --- |
| 本页头部网盘里的安装包 | 1.2.8 | 网盘 2026-09-23 存入的那一版，包名 `com.luckyzyx.luckytool`、大小 8.33M |
| 官方 GitHub release | 以页面当时显示为准 | 截至 2026 年 9 月检索时最新为 1.3.4，晚于网盘那版属正常 |
| 官方更新日志页 | 记录 1.0.0 起全部版本 | 地址 [https://luckyzyx.gitlab.io/LuckyTool_Doc/changelog.html](https://luckyzyx.gitlab.io/LuckyTool_Doc/changelog.html) |

官方 release 的安装包文件名形如 `LuckyTool_v1.3.4.20950.apk` —— 前半段是版本号，后面那串数字是构建编号，两者一起才唯一对应一个包。

从更新日志能看出两点规律，判断「我的功能为什么不生效」时用得上：

- **适配跟着 ColorOS 版本走**：大量条目形如「适配 … C15.0.1」「… C16」——C14 / C15 / C16 指 ColorOS 大版本，系统升到新 ColorOS 后，旧版模块可能整体失灵，先把模块升到最新再排查；
- **小版本只做适配与修复**：像 1.3.x 系列基本是「适配新系统版本 + 修复」，跨大版本（比如 1.2.x → 1.3.x）才会有较多功能增减。

按官方惯例，**系统大版本升级后，模块也要跟着升级并重启系统**，否则旧适配数据对不上新系统。
