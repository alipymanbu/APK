## 一、通用操作模式：所有开关都按这一套来

LuckyTool 里改任何显示项，流程都一样，先记住这个骨架，下面各节不再重复：

1. 打开 LuckyTool → 进对应的功能分区（状态栏 / 锁屏 / 桌面 / 控制中心……）；
2. 勾选开关，或填自定义数值；
3. **返回模块主页** → 右上角重启按钮 → **重启作用域**；
4. 打开对应界面（下拉控制中心、锁屏、回桌面）触发一次，看效果。

改完没反应？先别改回去——按 [模块不生效排查方法.md](模块不生效排查方法.md) 走一遍，多数情况是忘了重启作用域，或该功能的作用域是系统框架、需要重启手机。

功能项会随版本增删，本文写的是官方文档列过的常用项；你手机上看到的分区名与条目以模块内实际显示为准（本地这份是 1.2.8，官方更新较快）。

## 二、状态栏时钟：格式、位置都能改

这是 LuckyTool 最早起家的功能——早期独立模块 KillRedOne（干掉状态栏红一）的功能后来并入了它。

- **换时钟样式**：在时钟分区里可以选**预设格式**，也可以用**自定义模式**自己拼年、月、日等格式，写好后状态栏时钟按你的格式显示。
- **时钟居中**：状态栏布局分区里有时钟居中对齐布局的开关，打开后时钟挪到状态栏中间。
- **控制中心时钟显秒**：控制中心分区里有单独开关，下拉后的时间精确到秒。
- **状态栏布局杂项**：同分区还有屏幕兼容模式等选项，按需开。

典型用法是「状态栏显示完整日期 + 控制中心显秒」，两个开关分别在状态栏与控制中心分区，开完一起重启作用域即可。

## 三、控制中心：磁贴行列数自己定

- **磁贴行列数**：控制中心分区里可以直接设置磁贴的行数与列数，想要更紧凑（一屏塞更多开关）就调大，想疏一点就调回默认。
- **移除「我的设备」**：控制中心里那个设备卡片有独立开关，不想要就关掉。

改磁贴布局后**必须重启作用域**才重排；如果重排后磁贴错位，先重启作用域一次，仍乱再重启手机。

## 四、锁屏：组件居中与按钮精简

锁屏分区里常见三项：

- **锁屏组件居中显示**：时钟、日期等组件挪到居中位置；
- **移除部分按钮**：锁屏底部用不到的快捷按钮可以去掉；
- **移除 72 小时密码验证**：ColorOS 有一项与锁屏密码相关的 72 小时验证限制，这个开关把它移除；具体限制的触发条件以你的系统版本实际表现为准。

锁屏属于系统界面作用域，改完先重启作用域；不生效再重启手机。

## 五、桌面：行列数与图标圆点

- **移除 APP 图标圆点**：有未读提醒的应用图标右上角小圆点，可以全局去掉；
- **桌面布局行列数**：自定义桌面每行每列的应用数，以及文件夹预览的行列显示。

桌面分区的改动触发方式是回到桌面看一眼即可；改完仍不生效，按排查篇的第 4～8 步走（桌面属于推荐作用域里的系统桌面，一般重启作用域就够）。

## 六、其余分区一句话索引

官方功能一览里除了上面几类，还有这些分区，读者按需自己翻：

| 分区 | 里面有什么（示例） |
| --- | --- |
| 应用相关 | 自定义小窗 / 暗色 / 分身支持列表，跳过 APK 扫描，允许降级安装，移除安装广告，移除 ADB 安装确认 |
| 游戏助手 | 移除游戏滤镜限制、启用开发者页面、Adreno GPU 控制器、赛事游戏模式等 |
| 其他 APP 功能 | 相机、电池、主题商店、云服务、截屏、软件更新等条目 |

这些条目默认全关，用哪个开哪个——一次性全开会让问题排查变得困难（出了异常你分不清是哪个开关引起的）。每个开关的作用分区在模块里都有中文描述，配合 [支持的ColorOS版本与机型.md](支持的ColorOS版本与机型.md) 里的作用域列表对照着看即可。

另外两处不在官方功能一览里单列、但有用户反馈能找到的条目：**解除应用自启动数量限制**（ColorOS 对能自启动的应用有数量上限）与**快速设置磁贴**（如提高触控采样率，见 [提高触控采样率磁贴怎么开.md](提高触控采样率磁贴怎么开.md)）。这类条目随版本增删，能不能看到一律以你模块内的实际列表为准。
