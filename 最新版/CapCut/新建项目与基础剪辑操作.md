## 一、新建项目与导入素材

在首页点「新建项目」（部分版本写作「开始创作」），从系统相册里勾选要用的视频和照片，进入编辑界面。素材会同时出现在底部的时间轴和最左侧的「媒体」区：

- **时间轴上的片段**：已经排好顺序、进入编辑的部分；
- **媒体区的素材**：还在素材池里，拖进时间轴才会出现在成片里。

导入之后再想补素材，点「媒体 → 添加」，不用退出项目重来。一段素材只用其中几秒时，先整段拖进来再裁，比事先裁剪更灵活。

## 二、先认识时间轴和三类轨道

时间轴是横着的那条带子，从上到下叠着不同用途的轨道。剪辑时判断「该选中哪一条」比记按钮位置更重要：

| 轨道 | 放什么 | 常见操作 |
| --- | --- | --- |
| 主视频轨（最下面一条） | 视频、图片，按时间首尾相接 | 切割、删除、拖动排序 |
| 叠加轨 | 画中画、贴纸、文字、特效 | 调节大小、位置、出现时长 |
| 音频轨 | 背景音乐、音效、配音 | 调音量、淡入淡出、卡点 |

**把时间轴放大（双指捏合）之后再做精细切割**，否则一帧只有几像素宽，手指按不准。

## 三、切割、裁剪、删除与排序

| 想做的事 | 操作 | 注意 |
| --- | --- | --- |
| 把一个片段切成两段 | 播放头移到位置，点「分割」 | 分割点尽量落在动作之间的静帧上，接缝更自然 |
| 删掉不要的一段 | 选中该段 → 删除 | 删中间一段后，后面的片段会自动前移补位 |
| 调整顺序 | 长按片段拖动 | 拖动时看插入线落在哪里松手 |
| 裁掉画面边缘 | 选中片段 → 「裁剪」 | 裁剪改的是画面取景，不改变时间长度 |
| 只保留一小段 | 拖动片段两端的白色把手 | 拖把手可以一次到位，不用反复分割 |

一句提醒：**「分割」和「裁剪」是两回事**——分割改时间长度，裁剪改画面范围。想「把竖屏视频两边裁掉一点」，用裁剪；想「把中间那段废话去掉」，用分割加删除。

除了上面五个动作，片段菜单里还常驻这几个：**定格**（把当前这一帧冻成一张图，用来做「停顿特写」）、**倒放**、**旋转**、**镜像**。它们都作用在你选中的那一段上，做完一样可以再拼接、再加效果。要抠背景或只露画面局部，见 [绿幕抠像与蒙版怎么用.md](绿幕抠像与蒙版怎么用.md)。

## 四、画布比例：导出前一定要回头确认

比例列表通常是 9:16（竖屏）、1:1（方图）、4:3、16:9（横屏）和「原始」。选定之后：

- 素材比例与画布不一致时，画面四周会留黑边。想填满就用「背景」加底色或模糊底图，或把主体放大到盖住黑边；
- **改比例会让已经摆好的文字与贴纸位置整体偏移**，所以比例尽量在开始剪辑时就定好，中途再改要回头逐个检查叠加元素；
- 成片要发到哪里，比例就跟那里对齐：短视频平台竖屏为 9:16，横屏平台多为 16:9。

## 五、变速与关键帧

**常规变速**：选中片段 → 「变速」，整段提速或减速。慢动作会拉长片段，时间轴上占的位置也跟着变长。

**曲线变速**：在变速里选「曲线」，让速度在一段素材内从慢到快或从快到慢，用来做节奏起伏。曲线变速后片段总时长会变化，卡点位置要重调。

**关键帧**：给片段的某个属性打两个或更多关键帧，中间的过程由应用自动补出来。

- 打第一个关键帧 → 把播放头往后移 → 再改一次缩放/位置/不透明度，第二个关键帧就出现了；
- 常见用法：画面缓慢放大、贴纸从左滑到右、画面淡出。

帧与时间的换算：时间轴是 30fps 时，一帧大约 33 毫秒；要精确到帧，先把时间轴放到最大。

## 六、声音：音量、淡入淡出与录音

- **音量**：选中音频片段，把音量拉低到能听清人声的程度。背景音乐盖过人声，是自动字幕识别不准的头号原因（见 [自动字幕与文字转语音.md](自动字幕与文字转语音.md)）；
- **淡入淡出**：在音频片段的头尾各留 0.5 秒左右做淡入淡出，切歌时不会「啪」一下；
- **录音**：用「音频 → 录音」录一段配音，录完会生成独立音频轨，可以单独裁剪和调音量；
- **降噪**：现场有空调声、风声时，用音频的降噪功能处理一遍，比事后硬压音量有效；
- **提取音频**：把某个视频里的声音单独抽成一条音频轨，用来复用别人的配乐或保留现场声；
- **卡点**：先在音乐轨上打出节奏标记，再把画面切割点对齐过去。具体做法见 [自动卡点与自动剪辑怎么用.md](自动卡点与自动剪辑怎么用.md)。

## 七、撤销、草稿与保存

- 右上角的撤销按钮可以逐步回退；桌面版还能在历史记录里跳回某一步；
- 草稿是自动保存的，退出项目不会丢。但**卸载应用会连草稿一起删掉**，重要项目先导出成片再动卸载；
- 草稿会占用不少空间。发现手机空间紧张时，优先清理已经导出过、确认不再改的旧草稿，而不是清应用缓存。

操作熟练之后，一条 1 分钟以内的短视频按「导入 → 排顺序 → 切掉废片 → 加音乐 → 调比例 → 导出」这条线走，不需要碰任何高级功能也能出片。
