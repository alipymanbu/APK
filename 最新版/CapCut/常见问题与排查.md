# CapCut 常见问题与排查

## 一、先按现象对号入座

| 现象 | 最可能的原因 | 先做这一步 |
| --- | --- | --- |
| 安装时提示「解析包失败」 | 安装包下载不完整 | 删掉重新下载 |
| 系统不让点安装 | 未放行「安装未知应用」 | 到系统设置里给来源应用放行 |
| 装完点开就退回桌面 | 系统版本过低或缓存异常 | 重启设备再试一次 |
| 模板、素材一直转圈 | 网络到不了在线服务 | 换网络，确认能打开官网 |
| 一打开就要登录、功能用不了 | 在线功能需要账号 | 见 [登录方式与云空间怎么用.md](登录方式与云空间怎么用.md) |
| 导出到一半失败 | 空间不足或参数过高 | 降一档分辨率或帧率后重试 |
| 剪到一半越来越卡 | 项目太大、后台应用抢资源 | 关后台、先导出一版存档 |
| 自动字幕识别不出来 | 未登录、网络不通或语言选错 | 核对语言并确认登录状态 |
| 项目或草稿找不到了 | 看错了「云 / 本地」视图或登错账号 | 切到本地视图并核对账号 |
| 点素材或导出参数弹出订阅提示 | 用了标 Pro 的素材或参数 | 换免费素材，或把分辨率降一档 |
| 手机提示存储不足 | 草稿与缓存堆积 | 清理已导出的旧草稿 |

## 二、装不上：四步走完再怀疑手机

四条固定顺序查下来：**先看包是不是完整，再看空间，再看系统版本，最后看安装权限**。

1. 核对安装包是否下载完整。在电脑上用 PowerShell 算一次 MD5，与 [下载与安装教程.md](下载与安装教程.md) 第一节表格里的值比对；
2. 清出至少三倍于安装包的剩余空间（这份包 287.91 MB，装完占用会更大）；
3. 系统版本低于要求时，应用商店里可能根本搜不到，或装到一半失败；
4. 没给「安装未知应用」放行会被系统挡住，放行路径见安装那篇第三节。

## 三、打开就闪退、界面黑屏

- **先重启设备**，不少临时性的异常重启一次就恢复；
- 仍然闪退，清一次应用缓存（设置 → 应用 → CapCut → 存储 → 清除缓存），**不要**点「清除数据」；
- 刚更新过版本就闪退，多半是新版本的兼容问题，等一次小版本更新，或退回上一版安装包；
- 只有打开某个特定项目才闪退，那是这个项目的素材或效果有问题，新建一个项目把素材分批导入，定位到具体是哪一段。

## 四、模板和素材加载不出来

这一类的根因大多在网络，不在应用，判断方法很简单：

1. 用系统浏览器打开 `https://www.capcut.com`。如果官网也打不开或极慢，问题在网络，应用怎么重装都没用；
2. 官网能正常打开，但素材库刷不出来，先**确认已登录**——未登录时不少素材只显示不能下载；
3. 登录正常仍然刷不出来，清一次应用缓存，再更新到较新版本；
4. 全部无效就转向「只剪本地素材」：导入自己的素材完成剪辑和导出，这条路不依赖在线素材库。

## 五、项目或草稿找不到了

先别急着重装。这里的「项目」在手机上就叫「草稿」，按下面四步走，多数情况当场就找回来：

1. **切视图**。桌面版项目库分「云」和「本地」两个视图，登着号默认停在云视图；没登录时建的项目可能只在「本地项目」里，切过去看；
2. **核对账号**。用 A 账号建的项目，登着 B 账号是看不到的，确认当前登的是当初那个；
3. **翻回收站**。官方帮助页提到删掉的项目会进回收站，可以从那里恢复；但另有一处官方说明称项目删除后无法恢复。两种口径并存，**别把回收站当保险**；
4. **还没备份就只能用数据恢复工具**。应用到这一步已经无能为力了，越早停止往这台设备写新文件，恢复的成功率越高。

要长期避免这类问题，做两件事就够：**重要项目先复制一份副本再改**；把成片导出到电脑或云盘留档。

如果丢的是「应用被人卸载了」，本地草稿会一起被清掉，这条没有补救办法——卸载之前确认过素材已经导出。

## 六、导出失败或导出特别慢

按代价从小到大试，每步之后重试一次：

1. 确认剩余空间足够（按成片体积两倍以上留）；
2. 把分辨率或帧率降一档，4K 加 60fps 是最容易失败也最慢的组合；
3. 关闭后台应用，释放内存；
4. 重启应用，重新打开项目再导；
5. 长项目分段导出后再合并；
6. 更新到较新版本后重试。

导出慢和导出失败经常是同一原因的两个程度，具体参数怎么选见 [导出设置与清晰度怎么选.md](导出设置与清晰度怎么选.md)；如果卡住你的是标着 Pro 的参数或素材，那一节也写了怎么退回免费档。

## 七、剪到一半明显卡顿

- **项目越剪越卡是正常的**。轨道越多、特效越多，实时预览的开销越大。桌面版可以给大素材开启代理（proxy）来提升预览流畅度；
- 手机上优先做两件事：关掉其他后台应用，把画中画和特效层的数量减下来；
- 需要继续做大工程时，**先把当前进度导出一版存档**，再删掉已经确定不用的轨道；
- 4K 素材在小屏手机上预览本身就吃力，这是设备算力问题，不是应用坏了。

## 八、自动字幕识别不出来

先核对三件事：**语言选对了吗、登录了吗、网络能连上在线服务吗**。三条都正常却不识别，把长素材拆成几段分开识别，再不行更新版本。识别原理与改错字的高效做法见 [自动字幕与文字转语音.md](自动字幕与文字转语音.md)。

## 九、手机存储被吃满怎么办

CapCut 占的空间分三块，清理的优先级不一样：

| 占空间的来源 | 怎么清 | 注意 |
| --- | --- | --- |
| 导出过的成片 | 把成片搬到电脑或云盘后删除 | 清之前确认已经备份 |
| 旧草稿 | 在草稿列表里删掉确定不再改的项目 | 删草稿不可恢复 |
| 应用缓存 | 设置 → 应用 → CapCut → 存储 → 清除缓存 | 只点清缓存，别点清数据 |

**先删成片和旧草稿，再清缓存**。缓存清掉之后模板和素材库要重新下载，属于次要手段。另外，长期项目建议定期把成片导出到电脑，手机只留正在剪的那一个。
