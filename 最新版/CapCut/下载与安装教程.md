## 一、先对准版本，再动手装

这份资源是 CapCut 的**国际版**（海外版），包名 `com.lemon.lvoverseas`。包名最后一段的 `overseas` 就是「海外」的意思，它是区分国际版与国内版剪映最快的办法——两个版本的包名不同，装完是两个可以并存的独立应用。

| 项目 | 这一份的值 |
| --- | --- |
| 应用名 | CapCut |
| 版本 | 17.7.0 |
| 包名 | com.lemon.lvoverseas |
| 安装包大小 | 287.91 MB |
| MD5 | `6a593d162c83f8baca645f5a3995c640` |
| 核对日期 | 2026-09-22 |

上面这几个字段只对**这一份包**成立。官方渠道上的最新版通常已经是别的版本号，两者不一定是同一版；写教程、报问题、对功能的时候，一律以这一份的版本号 17.7.0 为准。

## 二、装之前确认两件事

**第一，系统版本。** CapCut 对 Android 版本有最低要求，低于要求的设备会出现「应用商店里搜不到」「装到一半失败」。你的系统版本在「设置 → 关于手机」里看；具体最低要求以官方下载页或应用商店页当时标注的为准。

**第二，剩余空间。** 安装包本身 287.91 MB，但装完之后占用会明显变大，因为还要加上应用本体、运行缓存、以及你自己剪的草稿。手机上留出安装包体积三倍左右的空余，后面剪片子才不会因为空间不足中断。

## 三、从网盘取包并安装（安卓）

1. 在手机或电脑上打开 **CapCut 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/f2fc5c4edca0](https://pan.quark.cn/s/f2fc5c4edca0)，转存或直接下载其中的安装包；
2. 如果是在电脑上取的包，把 `.apk` 传到手机的「下载」目录（用数据线、聊天工具传文件都可以）；
3. 在手机的文件管理器里进入「下载」，点这个 `.apk` 文件开始安装；
4. 首次安装会被系统拦一下，提示「不允许从此来源安装应用」。到「设置 → 应用 → 特殊权限 → 安装未知应用」里，给你刚才点安装的那个应用（文件管理或浏览器）放行，然后回来重新点安装；
5. 安装完成后，桌面或应用列表里会出现 CapCut 图标。

两条经验：**不要**用「在线解压」「重命名改后缀」之类的办法处理安装包，那会让包直接损坏；安装过程中如果提示「解析包失败」，多数情况是包没下完整，删掉重新下一次即可，不用怀疑手机。

## 四、核对安装包是否完整

从网盘下载到电脑之后，建议先核对一次 MD5，确认文件在传输过程中没有损坏。Windows 上用 PowerShell：

```powershell
Get-FileHash -Algorithm MD5 ".\capcut_v17.7.0.apk"
```

输出的哈希值与本文第一节表格里的 MD5 一致，说明这一份包是完整的；不一致就重新从网盘取一次。这一步能省掉「装到一半报错、却不知道是包的问题还是手机的问题」的折腾。

## 五、第一次打开建议先做的几项

- **登录不强制**。首屏会引导你选语言、登录账号，直接跳过也能开始剪本地素材；但模板库、云空间和 AI 相关功能要登录之后才完整（见 [登录方式与云空间怎么用.md](登录方式与云空间怎么用.md)）。
- **权限按需给**。导入素材要「照片/媒体」权限，自己录配音要「麦克风」权限，导出保存要「存储」权限。用不到的权限可以先不给，功能触发时系统会再问一次。
- **界面语言**。语言可以在应用内设置里切换，是否包含简体中文取决于你装到的这个版本与所在地区，装完在设置里看一眼就知道。
- **导出的位置**。默认导出到系统相册或「Movies」目录；如果你希望成片直接进某个文件夹，在导出面板里改一次保存位置。

## 六、装不上、装完打不开

| 现象 | 常见原因 | 先做这一步 |
| --- | --- | --- |
| 提示「解析包失败」 | 安装包下载不完整 | 删掉重下，或按第四节核对 MD5 |
| 提示「应用未安装」 | 空间不足或与已装的同名应用冲突 | 清出空间；若已装有其他来源的同包名版本，先卸载再装 |
| 系统不让点安装 | 未放行「安装未知应用」 | 见第三节第 4 步 |
| 装完点开就退回桌面 | 系统版本过低或缓存异常 | 重启手机后再试，仍不行见 [常见问题与排查.md](常见问题与排查.md) |

安装环节的排查顺序统一是：**包完整 → 空间够 → 系统版本够 → 权限放行**。四步都过还装不上，再按排查那篇往下走。
