# CapCut 自动卡点与自动剪辑怎么用

> 把画面自动对上音乐节拍有两条路：自动剪辑（Auto Cut）直接给你剪好的时间轴，卡点（Beat Sync）只标出节奏点由你对齐。这篇讲两者分别在哪能用、怎么开、结果不对怎么改。

## 一、先分清两个名字

菜单里都带「自动」，但做的事完全不同，选错了会白折腾：

| 对比项 | 自动剪辑（Auto Cut） | 卡点（Beat Sync） |
| --- | --- | --- |
| 它做了什么 | 分析音频后**自动切分并排好**片段，直接在时间轴上生成一条序列 | 只在音乐轨上**标出节奏点**，切哪里由你自己决定 |
| 你需要做的 | 检查、微调、导出 | 把切割点和转场拖到标记上 |
| 可控程度 | 低，适合快速出草稿 | 高，适合成品 |

截至 2026 年初，自动剪辑在**手机版和桌面版有、网页版没有**；卡点在手机与桌面都能用。功能的上线范围与入口名称会随版本调整，以官方页面当时显示为准。

## 二、自动剪辑的三种触发方式

打开自动剪辑后，要先告诉它「按什么来切」：

- **音乐节拍**：从素材库或本机选一首歌，按鼓点切；
- **语音停顿**：用你录好的口播，按句子之间的自然停顿切，适合访谈、vlog；
- **文字指令**（部分版本逐步放开）：用一句话描述，比如「把这批片段做成 30 秒的快节奏旅行混剪」，让它先生成一版草稿。

触发方式决定切点从哪里来。同一批素材，选「音乐节拍」和选「语音停顿」，出来的结果几乎不会相似；这一步选错，后面的参数怎么调都救不回来。

## 三、桌面版的操作路径

1. 打开一个已经放了片段的项目；
2. 点顶部工具条上的 **AI** 按钮，或走「编辑 → AI 工具 → 自动剪辑」；
3. 选触发方式（节拍同步 / 语音停顿检测 / 脚本模式）；
4. 需要的话调灵敏度、最短片段时长、转场样式；
5. 点「应用」或「生成」，时间轴上出现自动排好的序列；
6. 逐段检查，不满意的段落手动改，再导出。

## 四、手机版的操作路径

1. 新建项目并导入片段；
2. 点编辑界面右上角的「模板」图标，往下翻到「AI 创作 / 智能剪辑」一栏；
3. 选「自动剪辑」——不同版本或地区可能叫裁切、节奏剪辑、智能裁剪；
4. 选触发源（音乐 / 语音 / 文字）；
5. 预览生成结果，逐段改完再导出。

## 五、卡点：手动对齐更可控

要出成品，卡点比自动剪辑更靠谱：

1. 先把音乐加到音频轨；
2. 点这条音乐轨 → 选「节拍」→ 打开「自动节拍」，时间轴上会出现一排节拍标记点；
3. 把每个切割点或转场**拖到标记点上**；
4. 转场时长控制在 0.3 至 0.8 秒之间，快歌用短转场，慢歌用淡入淡出这类柔和转场。

自动识别不准的时候（纯人声、古典乐尤其容易），改用「添加标记」手动打点，再对齐画面——比反复让应用重新识别快。

## 六、结果不满意，先动这三个地方

| 问题 | 调哪里 |
| --- | --- |
| 切得太碎，画面一闪一闪 | 降低灵敏度，或把「最短片段时长」调大 |
| 口播的呼吸停顿被当成切点 | 换成语音停顿模式，或给切点前后各留约 0.2 秒 |
| 整条看起来没节奏 | 多半是音乐本身节拍不明显，换一首鼓点清晰的 |

## 七、这些素材不适合自动卡点

- 长镜头风景、单机位访谈——本身没有密集的节奏可言；
- 配乐是清唱、古典乐或环境音——节拍弱，识别出来的点会很乱；
- 想**在网页版**直接做自动剪辑——目前不支持，只能先在手机或桌面版剪好，再把导出的成片传上去做协作与分享。
