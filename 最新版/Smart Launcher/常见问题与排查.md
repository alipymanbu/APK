## 一、设不了默认桌面 / 设了又被重置

先走通用路径（系统设置里搜「默认应用」→ 主屏幕应用）。设不上的，按品牌对号：

| 情况 | 处理 |
| --- | --- |
| OnePlus 系统更新后设不上 | 先把默认桌面切回 OnePlus 桌面，再重新切回 Smart Launcher，两次切换即可 |
| OPPO / Realme 找不到入口 | 路径在「应用管理（App management）→ 默认应用（Default App）→ 主屏幕（Homescreen）」，藏得深；个别老机型干脆不支持第三方桌面 |
| 华为 / 荣耀每次更新后被重置 | 这是固件行为：桌面应用每次更新，默认桌面的选择都会被系统重置。官方建议把不用的桌面应用都卸掉，减少重置概率；部分国行机型封锁第三方桌面选择，无解 |
| 弹出「手机刚刚因 Smart Launcher 出现严重错误已恢复」 | 忽略。这是系统劝退用户回自带桌面的提示，普通崩溃或冻结也会触发，不代表手机出问题 |

设好之后又被各种「手机管家」类应用改回去的，把 Smart Launcher 加进对应管家工具的白名单。

## 二、手势导航（全面屏手势）问题

- 提示「你所用的默认主屏幕应用不支持」：Smart Launcher 6 本身已适配手势导航，这个提示来自固件限制。部分厂商（如小米，Android 11 起）不给任何第三方桌面开放手势导航。
- 用手势后卡顿、闪屏、最近任务界面变样：同样是固件对第三方桌面的适配问题。能做的只有两件事：等系统更新，或改回三键导航。设置层面解决不了。

## 三、小米 / Redmi / POCO 专属

- **时钟显示一个没设过的闹钟时间**：MIUI 自带时钟应用向桌面传递了错误信息导致，Smart Launcher 侧修不了。换一个时钟应用（如 Google 时钟 `https://play.google.com/store/apps/details?id=com.google.android.deskclock`）即可解决。
- **小组件点不动**：MIUI 11 起的安全机制。给小组件对应的应用开「后台弹出界面」权限：系统设置 → 应用 → 权限 → 其他权限。每个要上桌面的第三方小组件应用都要开一次。

## 四、小组件不更新了

多数不是桌面的问题，而是系统电池限制砍掉了小组件应用的后台任务。按这个顺序处理：

1. 给 Smart Launcher 和小组件应用都关闭电池优化。
2. 允许小组件应用后台运行、开启自启动（有这个选项的话）。
3. 打开一次小组件应用，确认权限给全（定位、日历、通知等）。
4. 把小组件从桌面删掉重新加。
5. 重启手机。

处理后还反复出现的，说明你的固件后台限制激进，到 [dontkillmyapp.com](https://dontkillmyapp.com/) 按你的品牌查对应解法。

## 五、应用列表缺失或重复

自查清单：检查隐藏应用列表 → 重置应用页分类筛选 → 检查工作资料 → 检查厂商应用分身 → 重启重建索引。逐项说明见[分类与搜索用法.md](分类与搜索用法.md)第五节。

## 六、耗电与流畅度

官方口径：Smart Launcher 在后台几乎不执行任务，正常使用不会比自带桌面更耗电；支持 120Hz 的手机上会跟随系统刷新率跑满。

想进一步省电，按官方建议做这几件事：

1. 关掉用不到的页面（页面管理器）和小组件 —— 每一个常驻小组件都在后台刷新。
2. AMOLED 屏用深色或纯黑壁纸，尽量开深色模式。
3. 别用动态壁纸。
4. 避开刷新太频繁的小组件。
5. 降低壁纸轮换、资讯页（Your Feed）的刷新频率。

另外，系统电量统计对桌面类应用的估算普遍粗糙，看到异常数字先观察几天、一次只改一个变量再判断。

## 七、杀毒软件报毒

使用 Avast / AVG 病毒引擎的杀毒软件（含部分手机管家的「病毒扫描」）可能把 Smart Launcher 报成风险应用。官方明确说明这是误报，安装包来自官方渠道时可以放心忽略。

## 八、Google Discover（资讯页）不稳定

Smart Launcher 的 Google Discover 集成走的是非官方途径 —— Google 没有开放公开 API，所以这块本来就可能出现失效，而且 Google 侧一改版就可能坏，桌面侧修不了。

- Discover 出问题时，官方的建议是改用 Smart Launcher 自带的资讯面板（Your Feed），它专为桌面优化，稳定性不受 Google 改版影响（面板开关见[桌面设置入门.md](桌面设置入门.md)第二节）。
- 这类问题官方明确表示不接受 bug 反馈 —— 没有官方 API，报了也没法修。

## 九、想换回系统桌面

在默认应用设置里把主屏幕应用改回系统桌面即可，不用卸载。你在 Smart Launcher 里的布局和设置都留着，之后想用随时切回来；换新手机迁移布局的完整步骤见[桌面设置入门.md](桌面设置入门.md)第五节。
