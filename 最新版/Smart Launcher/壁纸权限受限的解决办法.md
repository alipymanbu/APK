# Smart Launcher 壁纸权限受限的解决办法

> 讲模糊背景、主屏截图、备份含壁纸这些功能提示没有权限时的手动授权方法（ADB，一次授予长期有效）。

## 一、哪些功能依赖这个权限

读壁纸的权限影响的是这几个功能，缺了它们会直接提示失败：

- 模糊背景（模糊效果类主题）；
- 主屏截图；
- 让备份文件里也包含当前壁纸。

普通换壁纸、壁纸自动取色（Ambient Theme）不在这条限制里，不受影响。

## 二、为什么不能在应用里直接点「允许」

新版本 Android 对「读取壁纸」加了一道特殊权限，而按 Google Play 商店的规则，Smart Launcher 不允许在应用内直接弹窗申请它 —— 所以只能由你在电脑上用 ADB（Android Debug Bridge，Google 官方的调试工具）手动授一次。授予之后长期有效，系统更新也不会丢；只有卸载重装才需要重新做。

## 三、手机端准备：打开 USB 调试

1. 数据线一根（电脑连手机用）。
2. 系统设置 → 关于手机 → 连点「版本号」7 次，开启开发者选项。
3. 系统设置 → 系统 → 开发者选项 → 打开「USB 调试」。
4. 连上电脑后手机弹窗询问是否允许 USB 调试，点「允许」。

## 四、电脑端操作

先在电脑上装好 ADB：Windows 从 [Android SDK Platform Tools 官方页](https://developer.android.com/studio/releases/platform-tools) 下载 ZIP 解压（如 `C:\adb`）；macOS 用 `brew install android-platform-tools`；Ubuntu/Debian 用 `sudo apt install android-tools-adb`。

连接确认（手机上若弹授权窗先点允许）：

```sh
adb devices
```

能看到设备编号（不是 `unauthorized`）就说明连上了。然后执行授予命令：

```sh
adb shell pm grant ginlemon.flowerfree android.permission.READ_EXTERNAL_STORAGE
```

`ginlemon.flowerfree` 是 Smart Launcher 免费版的包名，命令照抄即可；装的是 Pro 版的话把包名换成 Pro 的对应包名。

## 五、验证是否生效

1. 打开 Smart Launcher。
2. 重试刚才失败的功能（比如开模糊背景、做一次含壁纸的备份）。

还是不行就重启一次手机再试。备份里能不能带上壁纸，直接决定换机迁移时壁纸要不要重新设（迁移流程见[从其他桌面迁移的完整步骤.md](从其他桌面迁移的完整步骤.md)、[桌面设置入门.md](桌面设置入门.md)第五节）。
