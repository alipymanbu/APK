## 一、Ambient Theme：界面配色跟着壁纸走

换一张壁纸，桌面的界面配色（面板、文字）会自动跟着适配，这是 Smart Launcher 官方称为 Ambient Theme 的机制。你只管挑壁纸，配色不用自己调。

想手动控制的话：

- 用主题编辑器（Theme editor）逐项调整界面色调，不再依赖壁纸自动取色；
- 深色模式可以手动开，也能按条件自动切换（时间段 / 壁纸明暗 / 跟随系统设置）；
- AMOLED 纯黑模式属于 Feature Pack（包含在 Pro 里），免费版只有普通深浅两套。
- 模糊背景、主屏截图这类效果依赖「读取壁纸」权限，新版 Android 上系统会把这道权限拦下来，要在电脑上用 ADB 授一次（一次有效），步骤见[壁纸权限受限的解决办法.md](壁纸权限受限的解决办法.md)。

## 二、壁纸从哪来

- 内置精选壁纸，来源包括 Walli、Unsplash 等素材站，官方会不定期上架专门为 Smart Launcher 制作的壁纸。
- 换壁纸之前可以先备份当前壁纸，不满意随时换回来。
- 支持动态壁纸，但动态壁纸普遍更耗电，在意续航就别用（省电设置见[常见问题与排查.md](常见问题与排查.md)第六节）。

## 三、图标形状与图标包

- Android 8.0 起系统支持自适应图标，Smart Launcher 可以统一套用形状；免费版提供 5 种图标形状，装了 Feature Pack（含在 Pro 授权里）可用 30 种。
- 图标包兼容大多数第三方桌面通用的图标包格式，买过的图标包可以直接用。
- 想自己造图标包，官方另有一款应用 **Icon Pack Studio**（`https://www.iconpackstudio.com/`），它基于运行时生成图标的技术，做出来的包能套用到设备上所有应用，不受图标包覆盖数量限制。
- Kustom 家的 KLWP / KWGT（动态壁纸与小组件制作工具）与 Smart Launcher 有 API 配合，做出来的壁纸和小组件可以直接放进来。

个别图标想单独换而不整包换，长按该图标编辑即可（具体入口以你手上版本的菜单为准）。

## 四、字体

- 内置上千款 Google Fonts，换字体能整体改观桌面的气质，应用名、界面文字一起换。
- 6.x 起字体还能应用到小组件上，界面观感更统一。

## 五、Liquid Glass 主题（6.6 新增）

6.6 版本加了一套基于光影折射的 Liquid Glass 视觉风格，透明感和深度可调强度。你手上这份 6.7 build 002 的安装包包含这一版的能力，可以直接用。
