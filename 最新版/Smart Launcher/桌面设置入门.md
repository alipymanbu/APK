## 一、5 分钟上手流程

这是官方给新手的设置顺序，照着走最快见效：

1. 把 Smart Launcher 设为默认桌面（还没设的先看[下载与安装教程.md](下载与安装教程.md)第四节）。
2. 把最常用的几个应用放上主屏。
3. 加一个实用小组件，比如日历、天气或任务。
4. 在「首选项 → 主页（Home page）→ 通知」里开启角标。
5. 之后找应用优先用智能搜索，而不是在应用列表里翻。
6. 前几天保持简单布局，用顺了再逐步加东西。
7. 布局满意后立刻做一次备份（见第五节）。

官方推荐的第一版布局是：主屏 4~8 个图标，加 1 个小组件。宁可先少放，后面再补。

## 二、页面系统：桌面是模块化的

Smart Launcher 6 的主界面由若干「页面」组成，每一页可以单独开启、关闭或调整位置：

| 页面 | 放什么 |
| --- | --- |
| 主页（Home） | 图标、小组件、Dock |
| 应用页（App） | 全部应用，按分类自动分组 |
| 搜索页（Search） | 智能搜索入口 |
| 资讯页（Your Feed） | RSS / 资讯阅读，可自定义来源 |

在「首选项 → 页面管理器（Page manager）」里开关。只想要一个极简桌面，就把用不到的页面全关掉，只留主页和应用页。6.x 版本把主页和附加页统一了，还可以指定默认打开哪一页 —— 甚至把应用抽屉或搜索页设为主页面，适合「打开手机就想搜」的用法。

## 三、摆图标和小组件：Fluid Grid

- 主屏用流式网格（Fluid Grid）摆放，不同尺寸的小组件能自动对齐，不容易出现「歪一截」的尴尬布局。
- 小组件可以自由缩放、自由摆放；多个小组件还能叠在同一格上（Widget Stack），左右滑动切换。
- 6.6 版本起 Dock 支持多行多列、放小组件、以及多个 Dock 页面，底栏不再只放一排图标。
- 长按主屏图标选「双击」，可以给单个图标绑定一个弹出式小组件（Popup widgets，属 Pro 功能，见[免费版与Pro功能对照.md](免费版与Pro功能对照.md)）。

图标的形状、字体和配色定制单独写在[主题图标与字体定制.md](主题图标与字体定制.md)。

## 四、手势

- 在「首选项 → 手势」里给双击、滑动等动作绑定功能，比如打开通知栏、熄屏、启动某个应用。
- 熄屏、拉通知栏这类系统动作需要授予「无障碍」权限。这一步是可选的，不授就只用不需要权限的手势。
- 如果手势导航（全面屏手势）提示「当前默认桌面应用不支持」，或用了之后卡顿闪屏 —— 这通常是手机固件对第三方桌面的限制，不是设置问题，具体见[常见问题与排查.md](常见问题与排查.md)第二节。

## 五、备份与换机

备份文件是官方给的迁移方案，换机不重摆布局：

**旧手机上：**

1. 把 Smart Launcher 升级到当前可用的最新版。
2. 在 Smart Launcher 设置里创建备份。
3. 把备份文件传到新手机（网盘、数据线、本地传输都行）。

**新手机上：**

1. 安装 Smart Launcher（版本不要太旧，否则备份可能恢复不全）。
2. 打开后在设置里恢复/导入那份备份。
3. 设为默认桌面。

恢复的内容包括主屏布局、图标排布、分类和大部分偏好设置。注意两点：第三方小组件的数据可能要在各自应用里重新配置；应用本身的账号和内部数据不在桌面备份的范围内。想让备份文件把壁纸也带上，需要先授壁纸读取权限（见[壁纸权限受限的解决办法.md](壁纸权限受限的解决办法.md)）。

另外，6.6 版本起支持直接导入 Nova Launcher 的备份文件，主屏布局、图标和基础设置都能带过来 —— 从 Nova 迁移的用户不用从零摆。从其他桌面或旧版 SL3 换过来的完整步骤单独写在[从其他桌面迁移的完整步骤.md](从其他桌面迁移的完整步骤.md)。

备份做好之后，应用分类和搜索的用法见[分类与搜索用法.md](分类与搜索用法.md)。
