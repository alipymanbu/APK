## 一、先看能干什么

手表 QQ 是手机版的子集，下面这些是它实际提供的能力（以你手表上装的这一版为准）：

| 类别 | 能做的事 |
| --- | --- |
| 聊天 | 收发文字消息、发语音消息、发 QQ 表情、文字回复 |
| 语音转文字 | 把语音转成文字再发出去，开会、上课时不用出声 |
| 通话 | 与好友语音通话、视频通话 |
| 图片 | 查看好友发来的图片，可放大查看 |
| 好友与群 | 加好友、加群 |
| 动态 | 发布动态、查看好友动态、QQ 空间点赞与评论、相册、签到 |

## 二、聊天怎么操作

从消息列表点进会话就能回。手表上打字费劲，通常更顺手的是两条路：

- **语音消息**：会话里按住说话（或点语音入口）录一段发出去，对方收到的和手机版 QQ 发的语音一样；
- **语音转文字**：不想出声时用这个，说完自动转成文字，确认后再发送。

表情、图片这些入口都在输入区域附近，左右多滑一屏通常就能找到；具体按钮位置随版本与表盘形状（圆屏/方屏）有差异，以实际界面为准。需要语音或视频通话时，在会话里找通话按钮发起，手表要有麦克风和扬声器才能正常出声。

## 三、QQ空间与动态

除了聊，手表 QQ 保留了空间那一套轻量操作：

- **发动态**：在动态页面发布文字动态，分享当下在做的事；
- **看好友动态、点赞、评论**：刷到内容可以点赞和留言，这些互动都会记到 QQ 空间里；
- **相册与签到**：查看空间相册、每日签到也都在这一版里保留着。

涉及改资料、管文件、发红包这类复杂操作就别在小屏幕上折腾了，回手机 QQ 做更省事——手表端的定位是「随时能回消息」，不是把整个 QQ 搬过来。

## 四、用之前确认两件事

1. **已登录**：没登录看不到任何会话，先按 [扫码登录与登录异常处理.md](扫码登录与登录异常处理.md) 扫码进去；
2. **手表在线**：手表自己得有网（Wi-Fi 或移动数据），否则消息发不出去也收不到，网络排查见 [收不到消息与常见问题.md](收不到消息与常见问题.md)。

还没装的话，安装包从 [下载与安装教程.md](下载与安装教程.md) 里的入口拿。
