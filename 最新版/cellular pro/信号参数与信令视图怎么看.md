# Cellular Pro 信号参数与信令视图怎么看

> Cellular Pro 的 LTE 视图、Signal 信令视图、事件视图里全是缩写参数，新手不知道该盯哪个。本篇把常用参数讲成能直接对照的话。

## 一、打开先解决双卡问题

手机是双卡（尤其双 LTE）时，参数页左上角有 `1`、`2` 两个数字按钮，点它切换当前看的是哪个卡槽的数据。**看错了卡槽，后面所有参数都是另一张卡的** —— 这是新手最容易懵的地方，先切对再看。

不带 root 的情况下，你依然能看双卡网络信息：SIM 卡信息、服务小区信息、服务小区信号质量，部分机型还能获取邻小区信息。

## 二、LTE 视图：最常看的一页

LTE 视图显示当前物理层、RRC 层的部分参数，常用的有：

| 参数 | 含义 | 怎么用 |
| --- | --- | --- |
| 小区（ECI） | 当前驻留的小区标识 | 锁小区前先记下它，换没换小区一眼看出 |
| 带宽 | 当前载波带宽 | 同一地点带宽不同，速度上限不同 |
| 频点 | 当前频点（EARFCN） | 对应锁频点操作的填值 |
| 信号（RSRP） | 参考信号接收功率 | **数值越大（越接近 0）信号越好**，负值越小说明信号越弱 |
| 干扰（SINR） | 信噪比 | 越大越好；RSRP 不差但网速慢时先看它 |
| 调制方式 | 当前调制阶数 | 反映当前链路质量档次 |
| 传输模式 | 当前传输模式 | 一般不用管，对比场景时才有意义 |
| 循环前缀（CP） | CP 类型 | 一般不用管 |

判断顺序建议：**先 RSRP 看信号强度 → 再 SINR 看干扰 → 最后看频点/小区对不对**。锁了频段之后要验证有没有生效，也是回来对这几项（冲突规则见 [锁网锁频段功能怎么用.md](锁网锁频段功能怎么用.md) 第四节）。

WCDMA 视图、GSM 视图的功能和 LTE 视图性质类似，只是参数换成各自的制式（如 WCDMA 常看 RSCP、EC/IO，GSM 常看 RXLEV）。

## 三、Signal 视图：L3 信令

Signal 视图显示的是 L3 信令 —— L3 是相对于 L1、L2 的高层协议，通常用来配置和测量底层消息。你能看到消息时间、消息类型和详细解析内容。

两个操作：

- **左上角锁定图标**：锁定/解除当前消息显示状态（锁定后列表不跟着滚动，方便你慢慢读某条消息）。
- **右下角漏斗按钮**：筛选消息内容，比如只看某一类消息。

注意：**详细信令的查看与导出属于会员功能**（官方说明里它与锁网一样在「免费试用」之列），打开时若提示需要会员，按页面指引处理，以应用内当时显示为准。

## 四、事件视图：回溯发生了什么

事件视图记录网络切换、重选、呼叫、接通、掉话等关键事件，也记录业务相关节点（FTP 业务开始、连接建立、下载开始、下载结束等）。

排查「刚才卡了一下」「突然断了」这类问题时，这页比参数页有用：先按时间找到事件，再回头对那个时刻的参数与信令。

## 五、设备、WiFi、GPS 这些辅助页

除网络参数外，你还能查：双卡 SIM 与服务小区信息、已连接 WiFi 与附近 WiFi 列表（含 2.4GHz 与 5GHz 信道）、当前位置与 GPS 卫星图、设备信息（电池、硬件、系统）。

这些页面不涉及锁网，无需 root 也能看。想把「走到哪信号怎样」记录下来，用地图轨迹功能，见 [地图轨迹与网络测试怎么用.md](地图轨迹与网络测试怎么用.md)。
