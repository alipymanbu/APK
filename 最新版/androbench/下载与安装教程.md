## 一、你将装上的是一个什么应用

AndroBench 由韩国成均馆大学（SKKU）计算机系统实验室（CSL@SKKU）开发，最早在 2012 年就公开发布，作用是测出你手机的存储（闪存）读写速度——连续读写、随机读写，以及对 SQLite 数据库的插入、更新、删除操作性能。它免费、无广告，2017 年前后因多款机型被曝混用不同规格闪存，一度成为普通用户验机的主流工具。

它早已停止更新：最新版本就是 5.0.1（2016 年 11 月发布），开发者官网 `https://www.androbench.com/` 现在只剩下实验室的介绍页面。本文所有版本信息以网盘里这份安装包的登记信息为准：

| 项目 | 数值 |
| --- | --- |
| 版本 | 5.0.1 |
| 包名 | `com.andromeda.androbench2` |
| 安装包大小 | 2.80M |
| MD5 | `AD35A232666CA89990534A4C3CA3E4B7` |
| 信息核对日期 | 2026-09-23 |

安装包很小（不到 3M），装上不占什么空间。系统要求方面，安装包的描述信息标注为「安卓 5.2 以上」——这个版本号来自原始描述数据（实际上并不存在 Android 5.2 这个版本），实际能否安装以你设备安装时弹出的提示为准。

## 二、获取安装包

这款应用已不在官方网站分发，Google Play 等渠道的收录情况也随时间变化，最省事的方式是从下面的资源直接拿包：

[AndroBench 安装文件资源（夸克网盘）](https://pan.quark.cn/s/160f1d6a07ef)

下载后得到一个 `.apk` 文件，把它传到手机上（数据线、局域网传输、网盘转存均可），就可以开始安装。

## 三、安装步骤

1. 在手机上点开刚才传过去的 `.apk` 文件；
2. 系统会提示「未知来源应用」——在你手机弹出的安装确认页里选择允许安装（不同品牌的入口名称略有差异，一般在弹窗里直接给开关）；
3. 等待安装完成，通常几秒钟就好（安装包不到 3M）；
4. 完成后桌面会出现 AndroBench 图标。

如果你习惯先核对文件再安装：安装包 MD5 为 `AD35A232666CA89990534A4C3CA3E4B7`，用电脑端或手机端的 MD5 校验工具对一下即可确认文件完整。

## 四、安装时会用到哪些权限

按第三方应用库的收录记录，5.0.1 的安装包涉及这些权限：

- 读取 / 写入外部存储——测速本身就要往存储里写测试数据、再读出来计时，这条权限是必须的；
- 打开网络套接字——应用带这一权限，但它不强制联网也能完成测试；
- 清除所有已安装应用的缓存——用于测试前释放存储空间，你可以在弹窗里留意系统对该权限的说明。

装完后不需要注册账号，也没有任何广告与内购。

## 五、确认装好了

点开图标，你会看到主界面顶部有一个 **Run All Benchmarks**（运行全部测试）按钮——能看到它，就说明安装成功。接下来怎么跑分、跑分前要做哪些准备，见 [闪存速度测试教程.md](闪存速度测试教程.md)；测出来的分数怎么对照闪存类型，见 [结果解读与闪存类型判断.md](结果解读与闪存类型判断.md)。
