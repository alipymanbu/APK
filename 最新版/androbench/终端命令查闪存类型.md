# 用终端命令查手机闪存类型

> 不跑分、不拆机，直接用系统终端里的两条命令读出闪存是 eMMC 还是 UFS，可与 AndroBench 的成绩互相印证。

## 一、什么时候用得上这一招

跑分推断闪存类型要靠成绩区间去「猜」，这两条命令是直接问系统要答案。适合三种情况：

- AndroBench 成绩落在两档交界（比如 500~600 MB/s），单凭分数定不了性；
- 想知道闪存的具体品牌与型号，而不只是「哪一代」；
- 不想跑一分钟的分，只想要一个「是 / 不是」的结论。

办法来自 2017 年「闪存门」时期社区广泛验证的一套操作，多个独立来源（媒体评测与用户问答）结论一致。

## 二、准备：装一个终端模拟器

在应用市场搜索「终端模拟器」或 "Terminal"（常见的开源款是 jackpal 的 Terminal Emulator），装上、打开，你会看到一个类似电脑命令行的黑底窗口，直接在里面敲命令即可。

## 三、第一条命令：确认 eMMC 还是 UFS

在终端里输入（注意 `ls` 后面有一个空格）：

```bash
ls /proc/fs/*
```

看输出里 `/proc/fs/f2fs` 下面跟的设备名开头：

| 输出里出现 | 结论 |
| --- | --- |
| `sd` 开头（如 `sdd`） | UFS 闪存 |
| `mmcblk` 开头 | eMMC 闪存 |

一条命令就能拿到「是 / 不是」的结论，对大多数设备来说到这里就够了。

## 四、第二条命令：读出品牌与型号

想再进一步，输入：

```bash
cat /proc/scsi/scsi
```

- **UFS 设备**：会返回一段信息，`Vendor` 后面是闪存品牌，`Model` 后面是具体型号；
- **eMMC 设备**：这条命令没有输出——这本身也是一个判据，无输出即 eMMC。

拿到型号后，把它当关键词在浏览器里搜一下，就能查到这颗颗粒的具体版本。以三星为例，型号结尾 `B1` 对应 UFS 2.0、`C1` 对应 UFS 2.1（如 `KLUCG4J1EB-B0B1` 即 UFS 2.0）——这是社区总结的经验规律，不同品牌、不同年代的命名并不统一，结论以你搜到的资料为准。

## 五、连终端都不想装的土办法

还有一个零安装的社区偏方：一边往手机里拷一部大体积视频，一边同时从手机往电脑复制另一个文件——两件事能同时进行，基本可判定 UFS；其中一边直接报错，多半是 eMMC。它的依据是两类闪存能否同时读写的工作方式差异，方法糙，但胜在什么都不用装。

## 六、两条路结论对不上时

命令查出的类型和 AndroBench 成绩推断的档位不一致时：

1. 先确认命令真的执行成功了——个别系统版本会限制对这些目录的读取，无输出或提示无权限时，别硬猜，回到跑分推断；
2. 重跑一次 AndroBench（准备清单见[闪存速度测试教程.md](闪存速度测试教程.md)第二节），排除测量干扰；
3. 两条独立路径都指向同一结论，才最终定性——只有一边支持时，按[结果解读与闪存类型判断.md](结果解读与闪存类型判断.md)第四节再复核一轮。

还没装 AndroBench 的话，用这份[AndroBench 安装文件资源（夸克网盘）](https://pan.quark.cn/s/160f1d6a07ef)装上再跑，命令查「类型」、跑分看「快慢」，两边拼起来才是完整的答案。排查其他异常的方法汇总在[测试结果偏低与常见问题排查.md](测试结果偏低与常见问题排查.md)。
