## 一、先记住结论：记录挂在账号上

聊天记录跟着账号走，不跟设备走。同样的账号登回去，旧消息就能找回来；账号没了，就全没了。

| 你做了什么 | 旧记录还在吗 |
| --- | --- |
| 卸载应用后重装、同账号登录 | 在 |
| 换手机、同账号登录 | 在 |
| 订阅到期后重新订阅 | 在（要手动「载入历史对话」） |
| 删除聊天室 | 没了，官方明确不可恢复 |
| 取消订阅后又主动退出聊天室 | 没了，连同订阅天数一起清零 |
| 注销账号（退会） | 没了，任何方式都不可继承 |

## 二、到期后怎么把旧消息载回来

订阅中断一段时间再回来，聊天室默认是空的，旧消息要手动载入：

1. 进对应艺人的聊天室，点「:」按钮；
2. 点右下角的设置；
3. 在聊天室设置里选「载入历史对话」（Load Chat History，不同版本措辞略有差异，找带「历史」字样的入口）。

两个限制要提前知道：

- **空窗期的消息补不回来**：订阅中断期间艺人发的内容，不会因为你重新订阅就重新发给你；
- **前提是账号还在**：注销过账号，这条恢复通道整个作废。

## 三、哪些动作等于「永久删除」

这三个操作都在应用里一两下就能完成，但后果不可逆：

1. **删除聊天室**——记录当场清空，官方 FAQ 明确不可恢复；
2. **主动退出聊天室**——取消订阅后如果再点了「退出聊天室」，订阅天数和聊天记录一起没了；
3. **注销账号**——个人信息删除、已付费内容不再可用；重新注册是全新账号，旧记录不可继承。

所以「不想续费」和「想清记录」是两件事：只想停一段时间，走取消自动续费即可（步骤见[订阅收费与退订退款.md](订阅收费与退订退款.md)），别顺手删聊天室，更别走到注销那一步。

## 四、卸载重装会丢什么

卸载本身不动云端数据，重装后登录原账号就能回到原样：

1. 先确认账号邮箱还记得（想不起来的补救办法见[账号注册与昵称设置.md](账号注册与昵称设置.md)）；
2. 重装应用——安卓安装包可从 [bubble 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ec1bbe0c91e9) 获取；
3. 登录后按第二节的方法载入历史对话。

另外要知道：应用内没有官方的聊天记录导出入口（以当前版本为准）。想在断订后回看旧消息，靠的就是「载入历史对话」这一条路——所以账号和聊天室都留着，是唯一稳妥的选择。
