## 一、先把悬浮球调到顺手的位置

装好并给完权限（见 [下载与安装教程.md](下载与安装教程.md)）后，悬浮球会出现在屏幕上。你可以：

- **按住拖动**：把它拖到屏幕任意边缘，松手就停在那，不会自动回弹。
- **点一下**：展开快捷菜单；再点菜单以外的区域收起。
- 球的大小、透明度、图标样式、菜单背景颜色在应用的设置页里调（选项名称以实际版本界面为准），遮挡内容时把透明度调低即可。

## 二、菜单里的快捷项分别干什么

点开悬浮球得到一个快捷菜单，菜单里会出现下面这些项目（具体排布以实际版本界面为准）：

| 菜单项 | 点下去发生什么 | 前置条件 |
| --- | --- | --- |
| 主页（Home） | 回到桌面 | 无障碍服务已开 |
| 返回（Back） | 执行一次返回 | 无障碍服务已开 |
| 最近任务 | 打开多任务列表 | 无障碍服务已开 |
| 锁屏 / 关闭屏幕 | 立即锁屏 | 无障碍服务已开；关闭屏幕类动作另需设备管理员 |
| 音量加减 | 弹出音量条，直接调媒体音量与声音模式 | 无 |
| 铃声模式 | 在响铃 / 振动 / 静音之间切换 | 无 |
| WiFi、蓝牙、定位、飞行模式 | 直接开关对应开关 | 无 |
| 通知 | 展开通知面板 | 无障碍服务已开 |
| 电源弹窗 | 弹出关机/重启菜单 | 安卓 5.0 及以上 |
| 手电筒 | 打开闪光灯 | 无 |
| 全部应用 | 列出手机里所有应用，点哪个开哪个 | 无 |
| 设置 | 跳到系统设置各页 | 无 |

用不了的项基本都能回到权限上查：锁屏相关看 [无障碍与设备管理员权限说明.md](无障碍与设备管理员权限说明.md)，截屏与录屏看 [截屏与屏幕录制怎么用.md](截屏与屏幕录制怎么用.md)。

## 三、单击、双击、长按手势怎么设

悬浮球除了「点一下展开菜单」，还支持给**单击、双击、长按**各绑一个动作，让高频操作一步到位。设置路径：打开应用 → 手势设置（Gesture Setting）→ 分别选单击、双击、长按触发什么。

几个实用绑法：

- 单击 = 锁屏，双击 = 打开常用聊天应用，长按 = 手电筒 —— 实体键基本不用碰了。
- 绑定的动作列表与菜单项是同一套，所以凡是要给动作授权的（回主页、返回这类），先把无障碍开起来。
- 设错了想恢复：把三个手势都改回默认的「打开菜单」即可。

## 四、图标与颜色自定义

设置页里可以改这几项（选项名称以实际版本界面为准）：

- **悬浮图标**：换图标图案、调大小与透明度；
- **菜单背景**：换菜单底色，深色壁纸下把菜单背景调暗更清楚；
- 改完即时生效，不用重启应用。

自定义只是外观，不影响功能；改完如果球不见了（透明度拉太低容易误判成消失），按 [悬浮球不见了怎么办.md](悬浮球不见了怎么办.md) 的第一条查。
