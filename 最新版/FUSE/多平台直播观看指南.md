## 一、聚合了哪些平台

FUSE 把多个直播平台的内容放进同一个客户端，你在首页就能在平台之间切换，不用来回装一堆官方 App。各平台在 FUSE 里能用的功能不一样，下面是项目官方 README 给出的支持矩阵：

| 平台 | 直播 | 弹幕 | 画质 | 收藏 | 推送 | 搜索 |
| --- | --- | --- | --- | --- | --- | --- |
| 虎牙 | 有 | 有 | 有 | 有 | 有 | 有 |
| 哔哩哔哩 | 有 | 有 | 有 | 有 | 有 | 无 |
| 抖音 | 有 | 有 | 有 | 有 | 有 | 无 |
| 斗鱼 | 有 | 有 | 有 | 有 | 有 | 无 |
| 快手 | 有 | 无 | 有 | 无 | 无 | 无 |
| YY | 有 | 无 | 无 | 有 | 有 | 无 |
| Twitch | 有 | 无 | 有 | 有 | 有 | 无 |

几点说明：

- 目前只有虎牙平台提供搜索，想搜主播名字、房间号，切到虎牙板块再搜。
- 快手和 YY 在矩阵里没有弹幕，想看弹幕互动选别的平台。
- 网易CC 曾在聚合之列，官方更新日志显示 3.0.32 版本起移除。
- 功能可用性以你实际安装的版本为准——旧版可能还没有后来加入的板块，新版也可能调整了某个平台的接口。

## 二、切换平台与进入直播间

打开应用后，首页按平台分板块展示，选中想看的平台进入直播列表，再点进具体直播间。列表里一般能看到主播在播什么、热度如何。

播放页里换直播间有两种路子：一是返回列表重选；二是直接在播放页上下键切换上一个/下一个直播间（这个「刷直播」行为默认关闭，需要在设置里打开，详见 [画质弹幕与播放设置.md](画质弹幕与播放设置.md)）。

另外两类板块的播放方式不一样：tvlive、weblive 走的是网页方式，播的是各平台官方网页端的内容（官方更新日志原话是「均来自各官方网站的播放内容」），所以它们依赖系统 WebView，遇到加载异常先看 WebView 版本（见 [常见问题排查.md](常见问题排查.md) 第四节）。

## 三、收藏、历史与订阅

- **收藏夹**：在直播间里把主播加入收藏，之后从首页收藏夹直接进房。收藏列表可以做排序，3.0.18 起还支持在收藏夹里搜主播名（点开收藏夹后输入名字过滤）。
- **历史记录**：看过的直播间会留在历史里，方便回头找；老版本里历史记录有过「只显示 12 个」的限制，后续版本修复并支持继续加载。
- **订阅**：哔哩哔哩平台的订阅支持在 3.0.19 重构后加入，登录 B 站账号后可以订阅关注的主播。

## 四、一起看

「一起看」是虎牙、斗鱼都有的板块：进入后选择一部影视内容，会和同样在看它的观众（有时还有主播）匹配到同一个房间，边看边聊。斗鱼的一起看板块在 3.0.21 版本加入。如果你想把这个画面推到电视上看，参考 [投屏与第三方播放器.md](投屏与第三方播放器.md)。

## 五、看直播要不要登录

单纯看直播不需要登录任何账号。只有发弹幕、点赞、关注、订阅这类互动操作才需要登录对应平台——FUSE 里统一走扫码登录，在相应功能处弹出二维码，用平台自己的 App 扫码即可。

## 六、Live Pro 与功能解锁

装好后你会发现一部分功能点不动——多个第三方分享帖与评测提到的情况是一致的：未解锁 Live Pro 时，切换平台、进入设置等操作是受限的。解锁入口在应用内左上角的「Live Pro」：点开后选择「已诚信付款，解锁 LIVEPRO」。

这是作者内置的「诚信付款」机制——先解锁、之后付不付、付多少由你自己决定。假如你认可这个工具，回项目主页给作者捐一点是它持续维护的方式；各版本解锁后的可用范围以实际界面为准。

## 七、装的是旧版怎么办

网盘里这份是 3.0.6，属于 3.0.x 的早期版本：上面标注「3.0.18 起」「3.0.19 起」的功能（收藏夹搜索、B 站订阅、斗鱼一起看等）在它里面可能还没有。升级方法见 [下载与安装教程.md](下载与安装教程.md) 第六节；遇到某个平台看不了，先去 [常见问题排查.md](常见问题排查.md) 对一对症状。
