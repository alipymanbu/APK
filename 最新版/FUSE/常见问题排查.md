## 一、打开就闪退或装不上

按顺序查三件事：

1. **系统版本**：3.0.24 起的新版只适配 Android 6.0 以上；6.0 以下的老设备官方声明只保证老版本能正常播放。Android 4.4 的设备要用专门的旧版（2.1.25.x 系列，以官方发布页为准）。装新版闪退的旧设备，换对应的旧版 APK 即可。
2. **安装包完整性**：下载中断会得到损坏的包，典型表现是「解析包出现问题」。可以核对 MD5——网盘里这份 3.0.6 的 MD5 是 `53072E7AC6DE2A1A721A8FCEA58D73F4`，对不上就重新下载。
3. **设备类型选错**：首次启动选错设备类型可能导致界面异常，去设置里的「设备类型」改成当前设备（手机 / 平板 / 车机 / 电视）。

另外，安装时被手机管家拦截、或在第三方应用商店看到「可疑」标注，多数是第三方 APK 的通病而非安装失败的原因，判断与核对方法见 [安装报毒与权限说明.md](安装报毒与权限说明.md)。

## 二、某个平台看不了 / 直播间黑屏

聚合直播依赖各平台的网页接口，平台一改版，旧版 FUSE 对应的入口就会失效——这几乎每个版本都在修（例如 3.0.17 修斗鱼播放、3.0.18 修 Twitch、3.0.25~3.0.28 连续修抖音相关的问题）。所以：

1. **先升级到最新版**。官方发布页：[https://jayjd.github.io/thread/2025/04/25/FUSE3.0.0.html](https://jayjd.github.io/thread/2025/04/25/FUSE3.0.0.html)（版本号与更新内容以页面为准）。
2. 升级后仍黑屏的，换一个清晰度档位试试。
3. 再试切换解码器 / 渲染模式（方法见 [画质弹幕与播放设置.md](画质弹幕与播放设置.md) 第四节）。
4. 只是某一个直播间黑屏而列表里其他直播间正常，通常是主播端的问题，换房间即可判断。

## 三、弹幕不显示 / 弹幕停住

- 快手、YY 本身就没有弹幕（官方支持矩阵如此），不是故障。
- 虎牙弹幕「进房后一段时间不再滚动」的问题在 3.0.31 修复，旧版遇到就升级。
- 想发弹幕需要扫码登录对应平台账号；看弹幕本身不需要登录。

## 四、提示 WebView 版本过低

FUSE 的部分内容（网页直播、登录二维码等）走系统 WebView 渲染，WebView 太旧会给出提示并可能白屏。weblive、tvlive 这类板块整体走网页方式播放（见 [多平台直播观看指南.md](多平台直播观看指南.md) 第二节），受影响最明显。去系统设置里更新「Android System WebView」（或通过应用商店更新），更新完重启应用再试。老电视/盒子的系统停更、WebView 更不了新的，能做的有限——保持 FUSE 本身为新版可以缓解（新版本对 WebView 版本检测的提示做了优化）。

## 五、电视搜不到 / 手机扫码连不上

- DLNA 推送搜不到设备：确认同一网络、路由器没开 AP 隔离，详见 [投屏与第三方播放器.md](投屏与第三方播放器.md) 第一节的检查顺序。
- 手机控制电视扫码连不上：电视端和手机端必须在同一局域网；地址方式（浏览器输入）失败时换微信扫码再试。

## 六、功能点不动：切换平台、进设置是灰的

这不是故障，是 Live Pro 未解锁——未解锁状态下切换平台、进入设置等操作受限。解锁入口在应用内左上角「Live Pro」，机制说明见 [多平台直播观看指南.md](多平台直播观看指南.md) 第六节。

## 七、去哪反馈问题

闪退、某平台失效这类问题，反馈到开发者那里最有效。官方渠道有三个：

- 项目主页（GitHub）：[https://github.com/jayjd/HuYaTv](https://github.com/jayjd/HuYaTv)
- 官方发布页评论区：[https://jayjd.github.io/thread/2025/04/25/FUSE3.0.0.html](https://jayjd.github.io/thread/2025/04/25/FUSE3.0.0.html)
- 项目主页上的 QQ 频道与 Discord 入口（以页面当时展示的为准）

反馈时写清：设备类型（手机/电视/盒子）、安卓版本、FUSE 版本号、哪个平台什么症状，最好附上出现时间。
