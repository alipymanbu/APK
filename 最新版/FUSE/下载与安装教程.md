## 一、FUSE 是什么、装在什么设备上

FUSE 是一个开源的聚合直播客户端，前身叫 HuYaTv（虎牙TV），开发者是 GitHub 用户 jayjd。它把虎牙、哔哩哔哩、抖音、斗鱼、快手、YY、Twitch 这些直播平台的内容聚合到一个应用里观看，同一套程序适配手机、平板、车机、电视和电视盒子。

项目主页在 [https://github.com/jayjd/HuYaTv](https://github.com/jayjd/HuYaTv)，官方发布页（含各版本更新说明）在 [https://jayjd.github.io/thread/2025/04/25/FUSE3.0.0.html](https://jayjd.github.io/thread/2025/04/25/FUSE3.0.0.html)。按作者在项目主页的说明，这是一个个人兴趣开发的学习交流项目，内容来自各平台网页端，不收集个人信息。

GitHub 仓库的 Releases 页面主要放源码压缩包，APK 安装包作者通过网盘分发。你可以直接从下面的 FUSE 安装文件资源（夸克网盘）转存后下载：

[FUSE 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1ad56a78394a)

想找最新版本的话，也可以从项目主页「下载地址」一节进入作者提供的各网盘入口，以官方页面当时展示的为准。

## 三、安装步骤

手机上安装第三方 APK，默认会被系统拦下，需要先放行「未知来源应用」：

1. 下载 APK 到本机（网盘里这份约 27.42M）。
2. 点开安装时，系统会提示「不允许安装未知应用」——按提示进入设置，给你用来打开 APK 的那个应用（浏览器、文件管理器或网盘客户端）勾选「允许安装未知应用」。
3. 回到安装页点「安装」，等待完成。
4. 电视/盒子上类似：在设置里找到「安全」或「未知来源」开关允许安装，再用 U 盘或电视端文件管理器打开 APK。

核对装没装对，可以看包名：`com.ccc.huya`（沿用自前身 HuYaTv 时代的名字，与官方发布页标注一致）。

## 四、首次启动：选设备类型

第一次打开 FUSE 会让你选择当前设备类型（手机 / 平板 / 车机 / 电视或盒子），也可以选自动检测。这个选择影响界面缩放和焦点操作方式——电视上用遥控器方向键，手机上直接触摸。选错了不用重装，之后可以在设置里改（首选项 → 设备类型）。

## 六、关于升级

3.0.17 之前的版本带有强制自动更新提示，之后的版本改成了非强制——有新版本时在首页顶部 Tab 栏给出提示，由你决定是否升级。3.0.6 属于早期版本，打开后若弹出升级提示，建议照提示升级：聚合直播这类应用依赖各平台网页接口，接口一变旧版就会出现某个平台看不了的情况，新版本通常已经修复（具体见 [常见问题排查.md](常见问题排查.md)）。

各版本改了什么，作者维护了一份独立的更新日志页：[https://jayjd.github.io/update](https://jayjd.github.io/update)，升级前可以先去对一眼改动是否与你碰到的问题相关。
