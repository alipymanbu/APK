# Geekbench 5 跑分测试完整步骤

> 本篇讲在手机上把 Geekbench 5 的 CPU 跑分和 GPU（Compute）测试各跑一遍的完整流程，以及测完的结果页上都有什么。还没装上的先看 [下载与安装教程.md](下载与安装教程.md)，测出来的分数偏低先看 [跑分偏低与成绩波动处理.md](跑分偏低与成绩波动处理.md)。

## 一、跑分前一分钟准备

跑分是让处理器短时间全速运转的重负载测试，机身发热是正常现象。想让分数有参考价值，动手前做四件事：

1. **取下手机壳**，把手机放在硬质、通风的桌面上，别放在床上或沙发上。
2. **电量保持在 50% 以上**，但**不要边充电边跑**——充电本身发热，会叠加影响成绩。
3. **清掉后台应用**，关掉省电模式（省电模式会压频率）。
4. 如果手机刚充完电或刚打完游戏，先晾 10~15 分钟降到室温再跑。

这套准备对应的原理和波动判断写在 [跑分偏低与成绩波动处理.md](跑分偏低与成绩波动处理.md)，这里不重复。

## 二、CPU 跑分：RUN CPU BENCHMARK

1. 打开 Geekbench 5，主界面就是设备信息页（型号、CPU、内存等）。
2. 点 **RUN CPU BENCHMARK**，测试立即开始。
3. 测试期间屏幕会显示当前进度和正在跑的项目（图像处理、压缩、加密、机器学习等一串子项，逐个来），不需要任何操作，也**不要中途切出去用手机干别的事**。
4. 单核一组、多核一组，全部跑完一般几分钟。测完停在结果页。

CPU 测试的子项都是真实场景里常见的负载类型：网页渲染、拍照、PDF 渲染、语音识别这类都在其中，所以它测出来的数和「手机日常快不快」有对应关系，但也只是处理器的单一维度，整机体验还要看屏幕、系统调度这些跑分覆盖不到的部分。

## 三、GPU 测试：RUN COMPUTE BENCHMARK

1. 回到主界面，点 **RUN COMPUTE BENCHMARK**。
2. 安卓上这项测试走 Vulkan 接口，测的是 GPU 的通用计算能力（图像处理、计算机视觉这类负载），不是游戏帧率。
3. 同样几分钟跑完，得到一个 **Compute Score**。

要不要跑这项：关心游戏性能的直接看游戏帧率测试类工具更对症；Geekbench 的 Compute 分数更多用在「两台机器 GPU 通用计算谁强」这种横向比较上。只关心 CPU 的话，跳过它完全没问题。

Compute 测试起不来或中途闪退，先看版本：老版本在 Android 12 上有 OpenCL 跑不了、部分新 GPU 驱动下 Vulkan 起不来的已知问题，官方在 5.5.0 前后陆续修复，5.5.1 已包含这些修复。也就是说手头这份 5.5.1 已经是修过的版本，还失败的话先重启手机再试一次，仍不行就先跑 CPU 部分，GPU 测试换时间再跑。

## 四、结果页上都有什么

跑完的结果页从上到下大致是：

| 区块 | 内容 |
| --- | --- |
| 总分 | Single-Core Score（单核）和 Multi-Core Score（多核），CPU 跑分看这两个数 |
| 子项分数 | 往下滑能看到每个子项（加密、整数、浮点各一组）的单独得分 |
| 系统信息 | 型号、主板、操作系统版本、CPU 名称与核心拓扑、各核心频率、内存大小等 |
| 结果链接 | 每次成绩会生成一个 `browser.geekbench.com` 上的结果页链接，可以直接分享给别人 |

结果链接拿到之后怎么用（搜同机型成绩、看榜单、归档自己的历次成绩），见 [成绩查询与机型榜单.md](成绩查询与机型榜单.md)。

分数怎么算高算低、怎么拿去和别的机型对比，是 [成绩解读与机型对比.md](成绩解读与机型对比.md) 的主题；对分数有疑问（比如连续两次跑出来差很多）时，先按 [跑分偏低与成绩波动处理.md](跑分偏低与成绩波动处理.md) 排环境因素，再下结论。

## 五、几个跑分时常见的疑问

**测到一半屏幕锁了、切走了，会影响吗？**
会。测试需要 CPU 持续满载，中途切换应用或锁屏可能导致该子项成绩异常。中断了就重新跑一遍，Geekbench 每次测试都是独立完整的一轮。

**跑一次就够了吗？**
建议跑 2~3 次，每次间隔 15 分钟左右让手机冷却。取其中表现稳定的那次（或多次的中间值）作为参考；第一次和最后一次差得多，说明降频在起作用，判断方法见 [跑分偏低与成绩波动处理.md](跑分偏低与成绩波动处理.md)。

**测试对手机有伤害吗？**
高负载短时发热属于正常物理现象，手机的温控系统会自动保护。跑完如果机身烫，等它凉了再用大负载应用。

**成绩会不会自动上传？**
结果会上传到官方的 Geekbench Browser 并生成结果链接，这也是官方排行榜数据的来源。不想让这次成绩出现在公开页面上，就别点分享，成绩留在本地结果列表里一样能看。
