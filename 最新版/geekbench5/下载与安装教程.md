## 一、装哪个版本

本篇对应的是安卓手机版 Geekbench 5，版本 5.5.1，安装包约 281.83 MB，包名 `com.primatelabs.geekbench5`，开发者是 Primate Labs（Geekbench 系列的出品方）。这套安装包资源的获取入口就是上面网盘块里的链接。

官方桌面版（Windows / macOS / Linux）和 iOS 版是另外的安装包，别混着装；版本之间分数也不能互比，原因在 [与Geekbench6的区别.md](与Geekbench6的区别.md) 里展开。

系统要求方面，官方文档写的是 Android 7.0 及以上；手机系统太老的话装上也可能跑不起来，先确认自己的系统版本再动手。

## 二、获取安装文件资源

安装包通过夸克网盘分享：Geekbench 5 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/435b3ca8ed89](https://pan.quark.cn/s/435b3ca8ed89)。

转存或直接下载后，会得到一个 `.apk` 文件。装之前核对一下基本信息，避免拿到被改名过的文件：

| 项目 | 应该是 |
| --- | --- |
| 版本 | 5.5.1 |
| 包名 | com.primatelabs.geekbench5 |
| 安装包大小 | 约 281.83 MB |
| MD5 | ABB199C22A1F039F32BACDF0C4B010E2 |

MD5 可以用手机上的文件管理器或电脑端工具算一下，不一致就不要装。

另一个需要提前知道的预期：5.5.1 是官方更新日志里 Geekbench 5 的最后一版（2023 年 2 月发布，之后 5.x 再无更新）。装上后不会有功能更新推送，它就是以这份定稿状态被使用的，网上能查到的 Geekbench 5 口径成绩也都是这一版附近跑出来的。

## 三、安装步骤

1. 手机上打开刚下载的 `.apk` 文件。系统会提示「未知来源」或「不允许安装未知应用」，按提示允许对应来源（浏览器或文件管理器）安装即可，装完可以再把权限关回去。
2. 等待安装完成。安装包比较大（约 282 MB），建议手机剩余存储空间留出 1 GB 以上，不然中途可能报空间不足。
3. 装完在桌面出现 Geekbench 图标（一副眼镜样式）。没有的话去系统设置的权限管理里看看有没有被装成了仅限工作资料之类的受限模式。

国内手机（小米、华为、OPPO、vivo 等）安装第三方 APK 的提示各不相同，但流程一致：允许本次安装 → 等进度条走完。不需要 root，也不需要任何账号。

## 四、安装失败怎么办

点安装没反应或中途报错，按出现频率从高到低查：

| 现象 | 先查什么 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 安装包是否完整 | 重新下载一遍，再核一次第二节那张表里的 MD5；MD5 对不上 = 文件坏了 |
| 提示存储空间不足 | 剩余空间 | 清出 1 GB 以上再装（安装包约 282 MB，安装过程还要展开） |
| 装到一半卡住不动 | 后台与存储 | 清后台，等几分钟；还不行就重启手机再装 |
| 装完点开闪退 | 系统版本 | 确认系统是 Android 7.0 及以上；太老的系统跑不起来 |

装好后第一次启动的流程见下一节。

## 五、首次打开

第一次启动 Geekbench 5 会弹服务条款（Terms and Conditions），点 **Accept** 接受后进入主界面。主界面会列出当前手机的基本信息：品牌、型号、主板、操作系统、CPU 名称、核心数、频率、内存大小等，这一页本身就是一份不错的硬件信息核对页。

之后每次打开都直接停在这一页，两个按钮分别对应两项测试：

| 按钮 | 测什么 | 大概耗时 |
| --- | --- | --- |
| RUN CPU BENCHMARK | 处理器性能（单核 + 多核） | 几分钟 |
| RUN COMPUTE BENCHMARK | 图形/GPU 通用计算（安卓上走 Vulkan） | CPU 测完再来几分钟 |

具体每一步怎么跑、跑的时候注意什么，见 [跑分测试完整步骤.md](跑分测试完整步骤.md)；测出来的分数偏低、两次分数对不上，见 [跑分偏低与成绩波动处理.md](跑分偏低与成绩波动处理.md)。

## 六、界面是英文的，能调成中文吗

Geekbench 5 的客户端界面没有提供中文语言选项，菜单和按钮都是英文（以 5.5.1 这一版为准）。不过它平时要点的入口很少，认这几个词就够用：

- `RUN CPU BENCHMARK` —— 开始 CPU 跑分
- `RUN COMPUTE BENCHMARK` —— 开始 GPU 测试
- `Single-Core` / `Multi-Core` —— 单核 / 多核成绩
- `Compute Score` —— GPU 测试总分

跑分流程走一遍就会用了，语言不是障碍。
