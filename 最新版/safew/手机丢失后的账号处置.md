# SafeW 手机丢失后的账号处置

> 手机丢了或被盗时，SafeW 账号该怎么保：丢之前预防什么、丢之后按什么顺序处理、数据会不会被人看到。

## 一、丢之前：三件预防的事

手机丢失后账号安不安全，大半取决于丢之前做没做这几件事：

1. **开副密码锁或应用锁**：副密码进得去应用但看不到敏感聊天与文件（功能说明见 [隐私与安全设置.md](隐私与安全设置.md) 第三节）；你的版本若支持生物识别解锁（指纹 / Face ID 一类），一并打开；
2. **开两步验证**（如有）：设置里找「两步验证」或「登录验证」，让新设备登录多过一道关；
3. **定期备份 + 每月看一次设备列表**：备份是丢机后恢复记录的唯一指望；设备列表里留着不认识的设备，当场移除比丢机后再处理从容得多。

## 二、丢之后：按这个顺序做

越早做越有效，顺序别乱：

1. **先把账号密码改掉**：用还登录着的设备（电脑端）或找回入口改密码，让丢掉的那台设备上的登录态尽快失效；
2. **移除可疑设备**：在设备管理里把丢掉的设备踢出去；入口一般在「设置 → 安全 → 登录设备」一类位置，路径以实际版本为准；
3. **远程处理**：不同渠道对 SafeW 远程能力的说法不一（有称「远程退出登录」，也有称「远程销毁」本地数据），你的版本里有什么就用什么；
4. **新设备上恢复**：重新登录后，用丢机前做好的备份恢复记录，路径见 [注册登录与多端同步.md](注册登录与多端同步.md) 第三节。

SIM 卡也在手机里的话，联系运营商挂失补卡同样别拖——捡到手机的人能收到你手机号的短信验证码，这是账号防盗链条里最薄弱的一环。

## 三、数据会不会被别人看到

按官方渠道的一贯口径，SafeW 的本地聊天数据是加密存储的，应用还有锁；但「加密」不等于「捡到的人什么都拿不到」，实际边界取决于你丢之前开了几道锁。两点预期要摆正：

- **对方那边的记录不受影响**：你丢的是你的设备，聊天另一方的记录还在他自己手机上，处置动作只保护你的账号与本地数据；
- **借别人的设备登过号**：回想一遍，有用完退出登录的习惯，这一条在丢机事故里能救场。

## 四、预防成本与事故损失

这套预防（副密码、两步验证、月检设备列表、定期备份）加起来一年花不了你十分钟；丢机后的事故处理，轻则记录全失，重则账号被人拿去冒用。账怎么算，自己掂量。碰到的其他疑难，去 [常见问题解答.md](常见问题解答.md) 按现象找。
