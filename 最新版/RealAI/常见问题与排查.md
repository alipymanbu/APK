# RealAI 常见问题与排查

这篇按「先分类、再定位」来写。RealAI 的毛病看着花样多，其实大多落在四个圈里：网络链路、账号状态、本机环境、包本身有问题。**先判断属于哪一圈，能省掉大量反复重装的时间——重装对前三圈的问题基本无效。**

## 一、先分清是哪一圈的问题

| 症状 | 大概率是哪一圈 | 第一步做什么 |
| --- | --- | --- |
| 能打开、角色列表刷不出来 | 网络 | 切网络（Wi-Fi 与流量互换）重进 |
| 消息发出去，角色不回 | 网络或服务端 | 等十几秒，换一句短的再发 |
| 停在登录页、验证码收不到 | 账号 | 见第二节 |
| 语音点了没反应 | 权限 | 见第四节 |
| 图片发出去很久没出来 | 网络 | 见第五节 |
| 打开就闪退、界面卡死 | 本机环境或包 | 见第六节 |

判断网络是不是元凶，最快的办法是**同时开一个网页**：网页打得开、RealAI 不出内容，问题在应用或服务端；网页也打不开，先把网络修好再谈别的。

## 二、登录与验证码

| 情况 | 怎么办 |
| --- | --- |
| 收不到短信验证码 | 先看号码有没有填错；确认手机信号正常；等 60 秒再点一次重发；仍收不到就换一个网络重试（部分运营商对高频短信有限制） |
| 提示验证码错误 | 注意有效期，旧的一条验证码在重发之后通常作废；复制粘贴时别带上空格 |
| 换了手机号想继续用 | 看应用内是否提供换绑入口；没有换绑入口时，用新号重新登录，历史记录能否带过来取决于记录是否绑在账号上 |
| 一直停在登录页转圈 | 切网络重进一次；确认系统时间不是手动改过的（时间偏差会导致请求被判无效） |
| 用户协议点不下去 | 协议弹窗一般要滑到底才能确认，把内容翻到最后再点 |

**不要用访客态长期使用**：访客身份一旦失效（换设备、清应用数据、被挤下线），聊天记录大概率找不回来。长期要用就尽早注册登录，登录步骤见 [下载与安装教程.md](下载与安装教程.md) 第四节。

## 三、角色不回话或回得很慢

先区分「完全不回」和「回得慢」：

| 情况 | 可能原因 | 处理 |
| --- | --- | --- |
| 一直停在输入中、始终不出字 | 网络中断，或服务端排队 | 等 10~15 秒；仍不出就重新发送 |
| 要等很久才出字 | 网络延迟高，或当前是高峰时段 | 换网络或错开时段再聊 |
| 回了但内容明显跑题 | 会话太长、话题太杂 | 新开会话，把要聊的事说清楚 |
| 只在这一个角色上不回 | 该角色可能已下架或状态异常 | 换一个角色试，正常就说明问题在角色侧 |
| 群里某几个角色不出声 | 角色被动，或被别人的话盖住 | 单独点名提问，见 [多角色群聊与聊天记忆怎么用.md](多角色群聊与聊天记忆怎么用.md) 第二节 |

**别用连发多条催它的办法**，发一句短的探路更有效。同一句话反复没有回应、换一种说法就正常的情况，属于对话侧的处理差异，不是应用故障。

## 四、语音输入没反应、角色不出声

按顺序过一遍，绝大多数卡在前两项：

1. **麦克风权限**：进「设置 → 应用 → 应用管理 → RealAI → 权限」，确认麦克风是允许状态。国产系统还有单独的「录音」权限开关，一并打开。
2. **媒体音量与静音**：角色说话没声音时，先按一下音量键看媒体音量是不是被调到最低，再确认没开静音或免打扰。
3. **占用冲突**：后台有通话、录音、语音助手在跑时，麦克风会被占用，关掉那些应用再试。
4. **蓝牙耳机**：连着蓝牙但音频输出跑到了耳机上，听起来就是「没声音」，断开蓝牙或在系统里切回听筒。
5. **权限都给了还是没反应**：重启一次手机再试，之后仍不行就归到第六节的本机环境问题。

## 五、图片发不出去、加载不出来

- **你自己发图失败**：先确认选中的是本地相册里已有的图（部分系统对「最近删除」里的照片不给读）；存储权限没开会直接选不到图，去权限页补上。
- **角色发的图一直转圈**：多半是网络，切网络后重进这段对话。
- **图片糊或者显示不全**：与图片本身的分辨率和上传时的压缩有关，换一张清晰、正脸、不裁切的图。
- **群聊里发图别人不接话**：在单聊里试同一张图，能正常接话说明是群聊里没点名，加一句「你看这张图」再发。

## 六、打开就闪退、卡顿、发热

按影响面从大到小排：

1. **可用存储空间**：剩余空间过低（比如不足 1 GB）时，应用读写缓存容易失败，先清出空间。
2. **后台应用太多**：本机内存紧张时，长时间对话更容易被系统回收，表现为切回来要重新加载。
3. **系统版本偏旧**：这个包登记的系统要求是安卓 5.2 以上，长期不更新系统的设备更容易出问题。在「设置 → 关于手机」里对一眼版本号。
4. **应用版本偏旧**：官方更新说明里多次出现过修复类条目，把应用更到当前较新的版本是第一优先动作。
5. **边充边用**：高负载加充电会明显升温，聊天本身不算重负载，发热异常时先看是不是别的应用在跑。
6. **收不到通知 / 消息提醒延迟**：进「设置 → 应用 → RealAI → 通知」确认通知权限已打开；系统对后台应用的管束各不一样，长时间没打开应用时提醒延迟属于常见表现。
7. **清应用数据之前想清楚**：清除数据会连同本机的对话记录一起清掉，动手前先确认记录是否还需要（能不能导出见 [多角色群聊与聊天记忆怎么用.md](多角色群聊与聊天记忆怎么用.md) 第五节）。也**别指望手机厂商的备份功能兜底**——它一般只备份应用本身，不含应用内的聊天数据，以你这台手机的厂商说明为准。

## 七、安装、更新、卸载相关

装不上、提示解析包错误、签名不一致，这类属于安装环节，按 [下载与安装教程.md](下载与安装教程.md) 第五节逐条对。

- **更新**：应用内一般没有自动更新通道，新版本要自己去渠道取一份重新安装；安装前确认新包版本号不低于当前版本。
- **卸载**：在应用管理里正常卸载即可。**卸载会一并清掉本机对话记录**，卸载前先处理记录的事。
- **想退版本**：手上要留着旧包的安装文件，卸载新版再装旧版；旧包的对话记录不会跟着回来。

## 八、关于收费

- **安装包本身不收费**：网盘里这份 RealAI 安装文件取包、装包都不涉及费用。
- **应用内有没有付费项，以界面上当时显示的为准**：这类应用常见的是会员、角色解锁一类内购，也可能完全没有。装上之后在「我的」或「设置」里看有没有会员、充值、订阅这类入口，有再决定要不要买。
- **要退款找收款方，不在应用里**：如果确实发生了扣款，退款与取消的权限在收款渠道手上，先看账单上的收款方是谁，再去那一边走流程。
- **别为了解锁内容去找来路不明的版本**：换一个来路的安装包解决不了付费问题，反而会把账号和记录体系打乱，判断办法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 第一节。

## 九、怀疑装错了包

如果出现下面任何一种情况，先别继续排查应用问题，**很可能一开始装的就不是这一份**：

- 界面语言不是中文；
- 打开后是一个和聊天完全无关的产品（比如要你问房产问题的）；
- 应用管理里看到的包名不是 `com.realai.ai`；
- 界面里找不到角色列表，而是一个工具型界面。

核对方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 第一节，认对了再谈别的问题。
