# RealAI 怎么创建自己的AI角色

自己建角色是这类应用里最花时间、也最容易白花时间的一步：填了十几行设定，聊起来还是不对劲，问题通常不在设定太少，而在设定太虚。本篇按「填哪些项 → 每项填什么 → 怎么写背景故事 → 建完怎么管」的顺序说。

## 一、创建入口

通常在首页的角色列表旁边有一个「+」或「创建角色」按钮，点进去就是创建表单。表单一般一屏到两屏，填完预览、确认创建，角色会存进你自己的角色列表（有的版本叫「我的」「我创建的」），之后和自带角色一样点开就能聊。

## 二、表单里各填什么

| 字段 | 填什么 | 容易踩的坑 |
| --- | --- | --- |
| 角色名 | 一个具体的名字，最好带姓或称呼 | 别用「男友」「医生」这种通用词，搜的时候会跟别人撞 |
| 性别 | 按设定选 | 一般影响称谓与代称，后改会影响已开始的对话 |
| 性格标签 | 三五个具体词，别全挑好听的 | 全填「温柔善良」等于没填，掺一两个缺点反而更像人 |
| 头像 / 形象 | 上传一张正脸清晰的图 | 图太糊或非人脸时，角色列表里观感会差很多 |
| 音色 | 若版本支持，从音色列表里挑，或按需调 | 音色只影响朗读效果，不影响文字回复风格 |
| 背景故事 | 见第三节，这是决定聊天质量的一栏 | 写成长篇传记，结果关键信息被稀释 |
| 与你的关系 | 恋人 / 朋友 / 同事 / 陌生人等 | 关系设定和背景故事里的说法要一致 |

## 三、背景故事这一栏怎么写才有用

判断标准只有一条：**删掉这一句，角色聊起来会不会变样？** 不会，就别写。按下面四块凑，一段话就能写完，比堆几百字形容词有效得多：

1. **身份**：一句话说清他是谁。
   「28 岁，在市里一家独立书店做店员，学的历史，毕业后一直没换过工作。」
2. **和你的关系**：你们怎么认识的、认识多久。
   「你每周三下午来店里，已经连续来了两个月，他记住了你常坐的那张桌子。」
3. **说话习惯**：决定回复的语感，这是最容易见效的一句。
   「话不多，习惯先反问再回答，不用敬语，偶尔用书店打烊时间开玩笑。」
4. **边界**：明确写清不要什么。
   「不主动提起他大学的事；不用网络流行语。」

反例对照：

| 写法 | 结果 |
| --- | --- |
| 「温柔体贴、善解人意、很有魅力」 | 没有具体信息，回复会往最泛的方向走 |
| 「说话温柔，但你迟到会直接说，不哄人」 | 有场景、有反差，对话里能看出人味 |

想改设定时，**先只改一句话再聊几句试试**，一次全推翻很难判断是哪条起了作用。

## 四、形象和音色

- **形象**：上传的头图会用在角色列表、对话头像上。竖版正脸图效果最好；多人合照、风景图会看不出是谁。
- **音色**：在支持自定义音色的版本里，可以在角色设定里换音色。有用户反馈会自己反复调，试出偏低的男声一类效果；能选的音色种类和可调项以应用内当时提供的为准。
- **改形象不改设定**：换头像不会改变角色的说话方式，两者是分开的。

## 五、建好之后能改什么

| 想做的 | 在哪做 | 注意 |
| --- | --- | --- |
| 改名字、称呼、音色 | 角色的编辑页 | 一般即时生效 |
| 改性格与背景故事 | 角色的编辑页 | 已开始的对话会带上新设定，早期聊天记录里的说法不会跟着改 |
| 删除角色 | 角色列表里的管理项 | 先确认这段对话是否还需要，删了不一定能找到回收入口 |
| 复制一个改着用 | 部分版本支持再建一个 | 比在原角色上反复大改更省事 |

## 六、几个常见问题

- **建完找不到它**：先看角色列表是不是按「我创建的」筛过；创建时名字太通用也可能被自带角色压在下面，用搜索框搜角色名。
- **设定写了但它不照做**：设定越具体越好用，另外要看的那条有没有写进背景故事——只写在名字或标签里的，权重通常不如正文。
- **想让它记住的事**：重要的设定写进背景故事，而不是只在对话里说一遍；对话里说的内容会不会被长期保留，见 [多角色群聊与聊天记忆怎么用.md](多角色群聊与聊天记忆怎么用.md) 第三节。
