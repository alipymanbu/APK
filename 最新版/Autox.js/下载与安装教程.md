## 一、装之前先认清版本

Autox.js 的源头是开发者 hyb1996 的 Auto.js（2020 年起停止维护），社区在其 4.1 版基础上继续维护并改名为 Autox.js。你现在能下到的有两条主要分支：

| 分支 | 维护方 | 特点 |
| --- | --- | --- |
| 6.x 系列 | kkevsekk1 | 经典版本，资料和教程最多 |
| 7.x 系列（v7 分支） | aiselp | 较新的重构分支，界面换成 Material Design 3，引入 Node.js 引擎、支持 TypeScript 与 Vue3 界面 |

本篇对应的安装包属于 **7.x 系列**，关键信息如下（这一份的事实，与网上搜到的最新版可能不是同一个）：

| 项目 | 值 |
| --- | --- |
| 版本 | 7.0.5 |
| 包名 | `org.autojs.autoxjs.v7` |
| 安装包大小 | 126.65M |
| MD5 | 45FD52C5B524F3FE2C7EAEC17188CD52 |

两点提示：

- v7 分支的包名以 `.v7` 结尾，与 6.x 老版本的包名不同，**两个版本可以同时装在一部手机上**，不冲突。
- 官方 GitHub 仓库为 [github.com/aiselp/AutoX](https://github.com/aiselp/AutoX)，7.0.5 发布于 2024 年 11 月；官方之后可能又发了新版本，装哪个看你自己的取舍，功能差异以官方 [Releases 页面](https://github.com/aiselp/AutoX/releases) 的说明为准。

## 二、从哪里拿安装包

两个途径：

1. **GitHub Releases**（[github.com/aiselp/AutoX/releases](https://github.com/aiselp/AutoX/releases)）：官方渠道，但国内直连速度不稳定，页面里同一个版本会提供两种 APK：
   - `arm64-v8a`：64 位 ARM 设备用，主流机型选这个；
   - `mini-arm64-v8a`：精简掉部分非必要资源的版本，体积更小，缺的资源在使用时按需下载。
2. **[Autox.js 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0a66c77f074f)**：转存后直接下载 APK 安装，省去 GitHub 直连问题。

安装前可以用 MD5 核对一下文件完整性：在文件管理器里查看 APK 的 MD5（安卓上可用「文件管理器」自带的属性页，或装一个哈希校验类小工具），与第一节表格里的 `45FD52C5B524F3FE2C7EAEC17188CD52` 一致即说明文件没损坏、也没被调包。

## 三、安装步骤

1. 从上面任一途径拿到 APK 文件（本篇对应版本为 7.0.5，126.65M）。
2. 点开 APK，系统会提示「不允许安装未知来源应用」，按提示允许浏览器或文件管理器「安装未知应用」后继续。
3. 等待安装完成，打开应用。
4. 首次启动时应用会请求开启**无障碍服务**和**悬浮窗权限**——这两项是它干活的饭碗，具体开法见 [权限设置与无法运行排查.md](权限设置与无法运行排查.md)。
5. 装好后建议先跑一个最小脚本试试水，写法见 [脚本编写入门.md](脚本编写入门.md)。

安装过程里没有需要 Root 的环节；如果你的手机系统特别老、安装器直接拒绝，只能换新一些的系统版本再试（系统要求以安装时的实际提示为准）。

## 四、装完之后的建议动作

- **先开权限再写脚本**：无障碍、悬浮窗、电池白名单，一次开齐，能省掉之后一大半「脚本不动」的排查——排查顺序见 [常见问题与报错处理.md](常见问题与报错处理.md)。
- **确认脚本目录**：脚本默认放在手机内置存储的「脚本」文件夹里，重装应用前想保留脚本，先把它们备份出来。
- **别急着卸载旧版**：如果你之前装过 6.x，v7 可以共存，老脚本可以先在旧版跑通，再逐步迁过来验证（两代分支对个别 API 的行为有差异）。
