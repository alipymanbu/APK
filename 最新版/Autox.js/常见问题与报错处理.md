## 一、运行类问题

### 1. 点了运行没有任何反应

先查无障碍：开关显示开着不等于服务活着。把无障碍开关**关掉再打开**，立即再运行一次——大多数「点了没反应」到这一步就解决了。还不行就按 [权限设置与无法运行排查.md](权限设置与无法运行排查.md) 的排查表从上往下过一遍。

### 2. 脚本跑到一半自己停了

基本是被系统杀后台。做三件事：电池设置里设为不受优化、最近任务里给应用上锁、关掉厂商的极致省电/纯净模式。锁屏跑长任务的，再确认「后台弹出界面」权限已开。要定时跑的任务被杀更麻烦，定时场景的专门排查见 [定时运行与开机自启.md](定时运行与开机自启.md)。

### 3. 脚本停不下来，怎么按都没用

按顺序试：悬浮条的停止按钮 → 音量上键（多数版本默认开启此功能，没反应去设置里确认「音量上键停止」开关）→ 系统设置里强制停止 Autox.js。死循环 `while(true)` 的脚本要写好 `sleep` 和退出条件，否则只能靠强制停止兜底。

### 4. 手机重启后脚本全挂了

无障碍服务是易失的，重启后经常回到关闭状态。养成习惯：重启手机后第一件事是重开 Autox.js 的无障碍开关。

## 二、脚本报错类问题

### 5. `findOne` 卡住很久然后报错 / 脚本「卡死」

`findOne()` 不带参数会**无限等待**控件出现，页面压根不会出现这个控件时就是永久卡死。两个修正：

```javascript
// 写法一：限时等待，等不到返回 null，自己判断
let w = text("登录").findOne(5000);
if (!w) { toast("页面没加载出来"); exit(); }

// 写法二：waitFor 等待条件成立再继续
text("登录").waitFor();
```

### 6. 报控件存在但点不动

控件 `clickable` 属性为 false 时，直接对它 `.click()` 没有效果。用它的中心坐标来点：

```javascript
let w = desc("更多").findOne(5000);
click(w.bounds().centerX(), w.bounds().centerY());
```

### 7. 截图 / 找图函数报错

这类功能需要系统授予**屏幕录制（媒体投影）**权限，第一次运行时系统会弹窗，点「立即开始」后才有画面可截。弹窗错过或拒绝过，就会一直报错——把脚本里的截图请求再触发一次，重新授权即可。找色、找图、OCR 的完整用法与选型见 [找图找色与文字识别.md](找图找色与文字识别.md)。

### 8. 脚本在模拟器上行为异常

模拟器对无障碍、悬浮窗、截图的支持参差不齐（尤其游戏类模拟器）。同一段脚本真机跑不通、模拟器跑得通，或反过来，都很常见——排查时换一台设备对照，能快速区分「脚本问题」还是「设备问题」。

## 三、版本与生态问题

### 9. Autox.js 的 6.x 和 7.x 该用哪个

| 关注点 | 6.x（kkevsekk1 维护） | 7.x / v7（aiselp 维护） |
| --- | --- | --- |
| 教程与脚本兼容 | 网上老教程多，老的 4.1 时代脚本兼容好 | 较新，部分行为有差异 |
| 功能 | 经典功能齐全 | 新增 Node.js 引擎（npm 包）、TypeScript 类型提示、Vue3 界面、Shizuku 支持 |
| 界面 | 传统风格 | Material Design 3 重做 |

两分支包名不同，可以共存；本篇对应的安装文件资源是 7.0.5（v7 分支）。拿不准就先装一份跑通再说，切换成本不高。

### 10. 打包出来的 APK 装上不能跑

用 Autox.js 的打包功能把脚本做成独立应用后，**打包产物是一个新的应用**，它自己也要重新走一遍授权：无障碍、悬浮窗、存储、电池白名单，一个都不能少。打包产物的装不上、报毒、图片丢失等问题，逐条对照 [把脚本打包成独立应用.md](把脚本打包成独立应用.md) 的处理表。

### 11. 需要 Root 吗

绝大多数脚本不需要：无障碍通道就能完成点击、滑动、找控件、找图。个别需要更高系统权限的操作（部分 shell 命令、特殊设置项），可以用 Shizuku 授权来替代 Root，v7 分支已内置支持。只有非常底层的玩法才真的要 Root。

### 12. 哪里找脚本示例和官方文档

- 应用内置了示例脚本（主界面里能直接查看和运行）；
- 官方文档（v7 分支）：[autox-doc.vercel.app](https://autox-doc.vercel.app/)；
- 官方源码与发布页：[github.com/aiselp/AutoX](https://github.com/aiselp/AutoX)，更新日志里能看到每个版本改了什么。

安装包还没拿到的，从 [下载与安装教程.md](下载与安装教程.md) 开始；写第一个脚本见 [脚本编写入门.md](脚本编写入门.md)。
