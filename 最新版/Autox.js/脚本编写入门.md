# Autox.js 脚本编写入门：写出第一个自动化脚本

> Autox.js 用 JavaScript 写脚本，内置了编辑器，手机上就能完成「写—跑—停」的完整循环。本篇带你认识编辑器、跑通第一个脚本，并讲清控件与坐标两种写法的取舍。

## 一、编辑器界面与脚本存放位置

打开 Autox.js，主界面就是一个文件列表：上层是文件夹、下层是文件，右上角可以新建。它同时也是个带代码补全、格式化、查找替换的 JavaScript 编辑器。

脚本默认保存在手机内置存储的「脚本」文件夹下，用电脑或文件管理器都能直接看到这些 `.js` 文件——想备份、想在电脑上改，直接操作这个文件夹就行。

除了手写，悬浮窗上还有「录制」功能：点开始后你正常操作手机，点按、滑动会被记下来自动生成对应的脚本，回放也顺。录出来的代码通常要再手动整理一遍，但对新手来说，它是理解「一个操作对应哪行代码」的最直观入口。

## 二、第一个脚本：启动应用并弹个提示

新建一个 `main.js`，输入下面几行，点运行：

```javascript
// 弹出提示气泡
toast("脚本开始运行");

// 启动设置应用
launchApp("设置");

// 等待 2 秒（单位毫秒）
sleep(2000);

// 回到桌面
home();
```

你会在屏幕上看到「脚本开始运行」的气泡，然后设置应用被打开，2 秒后回到桌面。这五行覆盖了最常用的四类动作：提示（`toast`）、启动应用（`launchApp`）、等待（`sleep`）、按键（`home`）。

前提是无障碍服务已经开启——没开的话连 `toast` 都不会弹，先按 [权限设置与无法运行排查.md](权限设置与无法运行排查.md) 处理。

## 三、控件思路与坐标思路

写自动化脚本有两条路线，Autox.js 两条都支持：

**控件思路（推荐）**：按文字、ID、类型找屏幕上的控件，然后操作它。

```javascript
// 找到文字为「蓝牙」的开关并点击
let sw = text("蓝牙").findOne(5000);
if (sw) {
    sw.click();
} else {
    toast("没找到蓝牙开关");
}
```

**坐标思路**：直接按屏幕坐标点击或滑动。

```javascript
// 点击坐标 (540, 1200)
click(540, 1200);

// 从 (540, 1500) 滑动到 (540, 500)
swipe(540, 1500, 540, 500, 500);
```

两者的取舍一句话就能说清：控件写法在不同分辨率、不同机型上通用，坐标写法换个屏幕就全错。所以能用控件就用控件，坐标只留给画不出来的场景（游戏画面、自绘控件）——这些场面就得靠截图找图找色了，见 [找图找色与文字识别.md](找图找色与文字识别.md)。获取坐标可以用系统开发者选项里的「指针位置」，或 Autox.js 自带的界面分析工具。

一个常见组合是控件定位 + 坐标点击：有些控件本身不可点（`clickable` 为 false），这时先找到控件，再点它的中心：

```javascript
let w = desc("更多").findOne(5000);
if (w) {
    click(w.bounds().centerX(), w.bounds().centerY());
}
```

## 四、等待与停止

**等待**：页面加载需要时间，写死 `sleep` 是新手最常见的翻车点（网络慢一点就点空）。更好的写法是等条件成立再继续：

```javascript
// 最多等 10 秒，直到出现文字「完成」
text("完成").waitFor();
```

**停止**：脚本一旦跑飞，需要立刻停下来的办法有：

- 悬浮条上的停止按钮（悬浮窗权限要开着）；
- 大多数版本默认支持**按音量上键停止所有脚本**，没反应就去设置里找「音量上键停止」一类开关确认状态；
- 彻底不行就强制停止 Autox.js 应用本身。

## 五、语法支持与版本差异

- v7 分支的 Rhino 引擎升级到了 1.8.0，常见的 ES6 语法（箭头函数、模板字符串、`let/const`）都能用，写起来和网页 JavaScript 差别不大；进阶用法还能引入 npm 包，等你跑熟了再去官方文档研究。
- 网上很多教程基于 4.1 时代的老 Auto.js 或 6.x 分支写的，个别 API 行为有差异——脚本报错时，除了检查权限，也要把「版本差异」纳入怀疑范围。
- 手机上敲代码费劲，连上电脑的 VS Code 效率会高一截，见 [连接电脑开发调试.md](连接电脑开发调试.md)；跑不通先对着报错信息查 [常见问题与报错处理.md](常见问题与报错处理.md)。
