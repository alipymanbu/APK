# Autox.js 权限设置与无法运行排查

> Autox.js 的每一步自动化都建立在系统权限上：无障碍服务管「读屏与点击」，悬浮窗管「脚本控制条」，电池策略管「后台能不能活」。本篇按权限逐项讲怎么开，再给一张「点了没反应」的排查表。

## 一、权限清单：哪些必须开，哪些看用途

| 权限 | 是否必须 | 不开会怎样 | 开启位置（通用路径） |
| --- | --- | --- | --- |
| 无障碍服务 | 必须 | 脚本完全不动，运行直接报错 | 设置 → 无障碍/辅助功能 → 已下载的应用 → Autox.js |
| 悬浮窗 | 强烈建议 | 没有脚本控制条，录制和界面分析用不了 | 设置 → 应用 → Autox.js → 显示在其他应用上层 |
| 存储权限 | 必须 | 读不到、也保存不了脚本文件 | 设置 → 应用 → Autox.js → 权限 → 存储 |
| 电池优化白名单 / 自启动 | 建议 | 切后台或锁屏后脚本被系统杀掉 | 设置 → 电池 → 不受限制（各品牌叫法不同） |
| 屏幕录制（媒体投影） | 用到才开 | 截图、找图、找色类函数报错 | 首次调用截图功能时系统弹窗授权 |
| 后台弹出界面 | 部分机型 | 悬浮窗按钮点了没反应（小米常见） | 设置 → 应用 → Autox.js → 其他权限 |

具体菜单名称随品牌和系统版本不同，上面给的只是通用路径，找不到就多翻两层设置。

## 二、无障碍服务的开启与「假开启」

开启步骤：

1. 打开手机「设置」，搜索「无障碍」（老系统叫「辅助功能」）。
2. 找到「已下载的应用」分类里的 Autox.js，点进去打开开关。
3. 系统弹窗提示「该服务可以监控你的屏幕操作」之类的警示，点「允许」。

一个常见的坑是「假开启」：开关显示是开的，但服务实际已经死了。判断方法很简单——运行一个 `toast("test")` 的脚本，屏幕上连提示气泡都不弹，多半就是服务没真正连上。这时把无障碍开关**关掉再打开**，一次不行就重开两次，比反复重装应用有效得多。

部分国产系统（小米、华为、OPPO、vivo 等）会在锁屏、省电或重启后**自动关闭**无障碍服务，这是系统省电策略，不是应用坏了。对策：

- 把 Autox.js 加入电池优化白名单（或「受保护应用」列表）；
- 关闭「自动管理/省电模式」对该应用的限制；
- 每次重启手机后先检查一遍无障碍开关，再跑脚本。

## 三、悬浮窗与后台保活

悬浮窗权限开了之后，屏幕上会出现一个属于 Autox.js 的悬浮条，里面是运行、停止、录制等按钮。权限被系统拦下来的表现是：按钮点了没反应，或者悬浮条直接消失。

后台保活的核心动作：

1. 电池设置里把 Autox.js 设为「无限制/不受优化」（华为叫「手动管理」自启动，小米叫「无限制」）。
2. 最近任务卡片里给 Autox.js **上锁**（下拉卡片点锁图标），防止一键清理误杀。
3. 厂商自带的「纯净模式/极致省电」开启时，后台应用几乎必被杀，跑长任务前先关掉。

锁屏后脚本被杀、或切到别的应用脚本就停，九成以上是这一节没做全。

还有一层系统级限制要知道：从 Android 10 起，应用在后台无法自行拉起界面（部分国产系统收紧得更早），后台跑的脚本里 `launchApp`、请求截图授权这类动作会没反应。把「后台弹出界面」「自启动」权限开上能缓解大半；定时场景下这个问题的完整处理见 [定时运行与开机自启.md](定时运行与开机自启.md)。

## 四、v7 分支的 Shizuku 通道（可选）

v7 分支支持 [Shizuku](https://shizuku.rikka.app/introduction/)——一个通过 ADB 授予应用高级权限的中间件。不装 Shizuku，Autox.js 也能正常用（无障碍通道就够日常脚本）；装了之后，一些需要更高系统权限的操作可以走 Shizuku 通道，而不用真的 Root。这是可选项，初次使用可以完全不管它。

## 五、「点了没反应」排查表

按从上到下的顺序查，命中哪条就按对应动作处理：

| 症状 | 最可能原因 | 处理动作 |
| --- | --- | --- |
| 点运行，界面毫无动静 | 无障碍服务未开或假开启 | 重开无障碍开关，再试 |
| 提示「无障碍服务未启动」 | 同上，或服务被系统刚杀 | 关掉重开无障碍 |
| 脚本跑一半突然停了 | 被电池策略杀后台 | 做完第三节的保活三步 |
| 悬浮条不出现 | 悬浮窗权限没给 | 开「显示在其他应用上层」 |
| 悬浮条在但按钮没反应 | 后台弹出界面被禁（小米常见） | 开「后台弹出界面」权限 |
| 截图/找图函数报错 | 未授予屏幕录制 | 跑到截图代码时在弹窗里点「立即开始」 |
| 重启手机后全都不好使 | 无障碍被重启清掉 | 重新开一遍无障碍，形成习惯 |
| 所有权限都开了还是不行 | 应用版本与系统不兼容 | 换版本试试（6.x 与 7.x 行为有差异） |

排查到这里还解决不了的，去 [常见问题与报错处理.md](常见问题与报错处理.md) 对报错信息；权限都确认过之后，就该写脚本验证了，见 [脚本编写入门.md](脚本编写入门.md)。
