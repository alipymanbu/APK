# Shizuku 常见问题与故障排查

> 集中处理三类高频问题：配对付不起来、提示 adb 权限受限、服务运行中自己停掉。处理办法来自官方手册与各厂商系统的已知限制。

## 一、一直显示「正在搜索配对服务」

搜索配对服务需要访问本地网络，不少系统在应用退到后台后立刻切断它的网络，于是永远搜不到。

处理：允许 Shizuku 在后台运行。各系统入口不同，搜「你的机型 + 允许应用后台运行」；小米把「省电策略」改成无限制、华为把「应用启动管理」改成手动管理并全部允许，是两个最常见的入口。

## 二、输入配对码后立刻提示失败

| 系统 | 处理 |
| --- | --- |
| MIUI（小米、POCO） | 系统设置 → 通知管理 → 通知显示设置，把通知样式切换为「原生样式」 |

MIUI 的自定义通知样式会拦掉 Shizuku 用来接收配对码的通知输入框，这是官方手册点名的高频坑。切换样式后重新走一遍配对流程。

## 三、提示 adb 权限受限

| 系统 | 在开发者选项里 |
| --- | --- |
| MIUI（小米、POCO） | 开启「USB 调试（安全设置）」——注意它和「USB 调试」是两个独立选项 |
| ColorOS（OPPO、一加） | 关闭「权限监控」 |
| Flyme（魅族） | 关闭「Flyme 支付保护」 |

这些开关默认不开或默认开着拦截，官方手册把它们列为 adb 权限受限的直接原因。

## 四、运行中自己停掉（随机停止）

所有设备逐项检查：

1. 允许 Shizuku 后台运行，电池策略不设限制；
2. 不要关闭「USB 调试」和「开发者选项」——任一开关被关掉，服务就失去依据；
3. 开发者选项里把 USB 使用模式改成「仅充电」（安卓 8 上是「选择 USB 配置」→「仅充电」，安卓 9 及以上是「默认 USB 配置」→「不进行数据传输」）；
4. 安卓 11 及以上，开启「停用 adb 授权超时功能」。

厂商专属的额外开关：

| 系统 | 处理 |
| --- | --- |
| EMUI（华为） | 开启开发者选项里「"仅充电"模式下允许 ADB 调试」 |
| MIUI（小米、POCO） | 别用「手机管家」的扫描/优化功能，它会重置开发者选项 |
| Sony | 连接 USB 后弹出的对话框不要点，点了会改掉 USB 使用模式 |

把上面的设置全部做完，无 root 设备运行中仍可能偶发被杀——社区里不少用户反馈这一现象，这是系统省电机制决定的，重新点一次「启动」即可，不需要重新配对或重装。重启后想少做手动操作的，看 [重启后自动启动怎么做.md](重启后自动启动怎么做.md)。

## 五、root 启动后开机不自动启动

允许 Shizuku 在后台运行。已 root 的设备理论上可以开机自启（开关在 Shizuku 设置里），被拦下来基本是厂商的自启管理或省电策略在起作用，去自启动管理列表里给 Shizuku 放行；完整的对照与开关位置见 [重启后自动启动怎么做.md](重启后自动启动怎么做.md)。

## 六、其他两处容易被忽略的

- **GrapheneOS**：需要关闭系统设置 → 安全 → 「Secure app spawning」，否则 Shizuku 工作异常（官方手册提示）；
- **重启后非 root 启动方式都要重来**：无线调试、连电脑两种方式在重启后都要重新点一次「启动」，这是系统限制不是故障；已配对过的设备不需要重新配对。

排查完还是不行，先把 Shizuku 卸载重装一遍（安装包获取见 [下载与安装教程.md](下载与安装教程.md)）排除安装损坏，再按 [无线调试配对与启动方法.md](无线调试配对与启动方法.md) 从头走一遍流程。
