## 一、拿到安装文件

Shizuku 是安卓应用，以 APK 安装包的形式安装。从 [Shizuku 安装文件资源（夸克网盘）](https://pan.quark.cn/s/fd8f324df974) 转存后，把 APK 传到手机上就可以装。这份安装包的实际信息如下，装之前可以对照核对：

| 项目 | 信息 |
| --- | --- |
| 版本 | 13.7.0 |
| 包名 | com.yuanqi.shizuku |
| 安装包大小 | 28.65 MB |
| MD5 | A659C1FFBD4A14F4019CAE96B7D90726 |
| 信息整理日期 | 2026-09-27 |

两点说明：

1. 网上搜到的往往是官方最新版，版本号不一定和这份一致。涉及版本、包名、大小时，以你手上这份安装包为准；官方最新版本号与更新说明以官方页面为准。
2. Shizuku 官方项目在 GitHub 上开源（[github.com/RikkaApps/Shizuku](https://github.com/RikkaApps/Shizuku)，Apache 2.0 许可证），官方用户手册在 [shizuku.rikka.app](https://shizuku.rikka.app/)，拿不准的官方说法去这两处核对。

想核对拿到的文件与上表一致，可以算一遍 MD5：Windows 在命令行执行 `certutil -hashfile 文件路径 MD5`，把输出与上表比对；手机上部分文件管理器的「文件详情/属性」页也能直接看 MD5 值。

## 二、安装步骤

1. 把 APK 传到手机存储：手机端夸克网盘转存后直接打开，或用数据线、局域网传输都可以；
2. 在文件管理器里点开 APK，系统弹出「是否安装」；
3. 首次安装外部 APK 时，系统会要求允许「安装未知应用」——在弹出的页面里允许当前这个文件管理器安装应用，返回后继续；
4. 等待安装完成，打开 Shizuku。

部分系统的额外拦截：MIUI/HyperOS 可能开了「纯净模式」，需要先在设置里关掉才能装第三方 APK；个别品牌的「应用包安装程序」会在安装前再确认一次，选择继续安装即可。

## 三、装完之后先做什么

刚装好的 Shizuku 打开是「未运行」状态——它本身不直接干活，要先启动一个服务，其他应用才能借它调用系统接口。按你的设备情况选路：

| 设备情况 | 下一步 |
| --- | --- |
| 未 root，安卓 11 及以上 | 走无线调试，见 [无线调试配对与启动方法.md](无线调试配对与启动方法.md) |
| 未 root，安卓 10 及以下 | 连电脑启动，见 [连接电脑用ADB启动.md](连接电脑用ADB启动.md) |
| 已 root | 打开 Shizuku 直接点「启动」 |

启动环节或日常使用卡住了，先翻 [常见问题与故障排查.md](常见问题与故障排查.md)。
