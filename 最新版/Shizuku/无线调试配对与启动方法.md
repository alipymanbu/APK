# Shizuku 无线调试配对与启动方法

> 未 root 的安卓 11 及以上设备，用系统自带的「无线调试」就能启动 Shizuku，全程不用连电脑。本篇讲怎么选路、怎么配对、怎么启动、重启后要重做什么。

## 一、先确认这条路走得通

| 条件 | 说明 |
| --- | --- |
| 安卓版本 | 11 及以上（「无线调试」是系统功能，旧版本没有这一项） |
| 是否 root | 不需要 |
| 是否连电脑 | 不需要 |

安卓 10 及以下、或设置里找不到「无线调试」的机型（部分华为/鸿蒙系统没有这项），改走电脑方式，见 [连接电脑用ADB启动.md](连接电脑用ADB启动.md)；已 root 的设备打开 Shizuku 直接点「启动」即可，不用看本篇。

## 二、准备工作：开发者选项与无线调试

1. 打开系统「开发者选项」：大多数机型是 设置 → 关于手机 → 连点「版本号」7 次；各品牌入口不同（小米在「全部参数」里的 OS 版本），搜「你的机型 + 开发者选项」最稳；
2. 在开发者选项里打开「USB 调试」；
3. 在开发者选项里找到「无线调试」并打开（一般在「调试」分类下）。

「USB 调试」和「无线调试」两个开关在后面都要保持开启状态，关掉任何一个都可能要重新走流程。

## 三、配对（只需要一次）

配对依赖系统通知——配对码要填进 Shizuku 弹出的通知里，所以第一次进入配对流程时允许它的通知权限。

1. 打开 Shizuku，在「通过无线调试启动」下点「配对」；
2. 切回系统 设置 → 开发者选项 → 无线调试，点「使用配对码配对设备」；
3. 屏幕显示一个 6 位配对码，同时下拉通知栏，在 Shizuku 的通知输入框里填入这 6 位数字；
4. 提示配对成功后回到 Shizuku。

通知里没看到输入框时，手动下拉通知栏找 Shizuku 的那条通知，点「输入配对码」再填码；配对前记得先允许 Shizuku 的通知权限，否则这条通知根本不会出现。

注意顺序：先在 Shizuku 里点「配对」，再去系统里点「使用配对码配对设备」。配对码是当下生成的一次性数字，反过来操作配对码会过期，就要重来一遍。

## 四、启动与重启之后

配对成功后，在 Shizuku 主界面点「启动」，状态显示「Shizuku 正在运行」就算完成。之后给配套应用授权、正常使用，授权方法见 [配套应用授权与常见用途.md](配套应用授权与常见用途.md)。

两个必须知道的系统限制：

- **重启手机后服务会停**：这是系统机制，重启后打开 Shizuku 再点一次「启动」就行，不需要重新配对；
- **启动失败先重启开关**：官方手册给的第一招，就是把「无线调试」禁用再启用，然后重试启动。

重启后能不能自动恢复、哪些条件能省掉手动启动（root 的开关、官方 v13.6.0 起的受信任 WLAN 方案），单独整理在 [重启后自动启动怎么做.md](重启后自动启动怎么做.md)。

## 五、卡在这几步时

- 一直显示「正在搜索配对服务」→ 多半是 Shizuku 被系统切了后台网络，去允许它后台运行；
- 输入配对码后立刻提示失败 → 小米/POCO 用户把通知样式切换成「原生样式」再试；
- 启动成功但用一会儿就停 → 检查后台运行限制、USB 调试开关是否还开着。

这些问题的完整处理步骤都整理在 [常见问题与故障排查.md](常见问题与故障排查.md)。
