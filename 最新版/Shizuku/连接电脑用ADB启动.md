# Shizuku 连接电脑用 ADB 启动

> 未 root 且安卓 10 及以下的设备没有「无线调试」可用，需要电脑通过 ADB 来启动 Shizuku。本篇从装 ADB 工具讲到执行启动命令。
> **相关文档**：[无线调试配对与启动方法.md](无线调试配对与启动方法.md) · [常见问题与故障排查.md](常见问题与故障排查.md)

## 一、什么时候用这个方式

| 你的情况 | 用哪种启动 |
| --- | --- |
| 已 root | 打开 Shizuku 直接点「启动」，不用电脑 |
| 未 root，安卓 11 及以上 | 无线调试（见 [无线调试配对与启动方法.md](无线调试配对与启动方法.md)） |
| 未 root，安卓 10 及以下 | 连电脑 ADB（本篇） |

## 二、电脑装好 ADB 工具

1. 下载 Google 官方的「SDK 平台工具」（platform-tools），解压到任意一个文件夹；
2. 在解压出的文件夹里打开命令行窗口：Windows 10 按住 Shift 点右键，选「在此处打开 PowerShell 窗口」；Windows 7 选「在此处打开命令行窗口」；Mac/Linux 打开终端；
3. 输入 `adb` 回车，输出一长串用法说明而不是「找不到命令」，说明工具可用。

这个窗口不要关，后面的命令都在这里执行。如果用的是 PowerShell 或 Mac/Linux，所有 `adb` 要写成 `./adb`。

输入 `adb` 报「不是内部或外部命令」，说明当前窗口不在解压目录里：回到解压出的 platform-tools 文件夹重新开窗口；不想每次切目录，就把这个文件夹的完整路径加进系统 PATH 环境变量（搜「Windows 添加 PATH 环境变量」照做一次即可）。

## 三、手机端打开 USB 调试并连接

1. 手机进开发者选项（设置 → 关于手机 → 连点「版本号」7 次，具体入口以机型为准），打开「USB 调试」；
2. 用数据线连接手机与电脑；
3. 电脑命令行执行：

```bash
adb devices
```

4. 手机会弹出「是否允许 USB 调试」，勾选「总是允许」后确认；
5. 再执行一次 `adb devices`，列表里出现你的设备号和 `device` 字样，才算真正连上了。

两种常见的非正常状态：设备后面显示 `unauthorized`，说明授权没确认过——在开发者选项里点「撤销 USB 调试授权」，拔线重插，重新在弹窗里允许；列表是空的，先换一根数据线或换 USB 口（部分线只能充电、不能传数据），再确认手机上的 USB 连接方式不是「仅充电传输关闭」状态。

## 四、执行启动命令

设备连上后，执行适用于 Shizuku v11.2.0 及以上版本的官方启动命令：

```bash
adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
```

命令路径里的 `moe.shizuku.privileged.api` 是官方手册写法中的包名段。如果你安装的这份安装包包名不同（本文整理的那份包名为 `com.yuanqi.shizuku`，见 [下载与安装教程.md](下载与安装教程.md) 里的信息表），把路径中这一段替换成设备上实际的包名再执行，或者以官方手册页面为准。

执行成功后，手机上的 Shizuku 会显示「正在运行」，之后拔掉数据线即可正常使用。和无线调试方式一样，手机每次重启后服务都会停，需要重新连电脑执行一次这条命令；配对过的无线调试路线（安卓 11+）在这一点上要省事得多。

偶尔想在手机上直接执行命令、不想连电脑，可以用官方自带的 rish 工具，见 [rish终端命令怎么用.md](rish终端命令怎么用.md)。

启动命令报错、或服务中途停掉，对照 [常见问题与故障排查.md](常见问题与故障排查.md) 处理。
