## 一、把界面调成简体中文

1. 打开应用，进「我的」（右下角人物图标）。
2. 点右上角设置（齿轮）。
3. 往下滑找到语言设置（Language）。
4. 选简体中文，点保存。

个别版本菜单顺序略有不同，认准「设置 → Language」即可。

## 二、看不懂外语帖子，怎么翻

帖子与评论都带翻译按钮，点一下即可翻成你在语言设置里选的语种。翻译按钮找不到时，多半是该条内容本身不支持，回原帖看。更完整的板块说明在 [社区与直播功能入门.md](社区与直播功能入门.md)。

## 三、图片视频加载慢 / 转圈

按顺序试：

1. 切换 Wi-Fi 与移动数据，确认是不是当前网络的问题。
2. 清理应用缓存（手机系统设置 → 应用 → Weverse → 清除缓存；**不要点清除数据**，会退出登录）。
3. 完全退出应用后重开。
4. 高清视频（4K VOD）对带宽要求高，先切 480p/720p 确认内容本身能播。
5. 官方维护时段整个服务都会异常，等公告恢复。

## 四、应用闪退 / 白屏

- 确认手机剩余存储空间够用。
- 更新到最新版本；网盘这类固定版本的包会随时间落后于官方，更新不及时就从官方商店重新获取。
- 安卓端清缓存后重试；仍闪退就卸载重装（重装前确认记得自己的登录方式与密码，见 [注册与登录问题排查.md](注册与登录问题排查.md)）。

## 五、部分内容打不开 / 提示不可观看

四种最常见的原因：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| Only 栏内容点了没反应 | 未购买该艺人 Membership | 到对应艺人页面购买，见 [会员与支付说明.md](会员与支付说明.md) |
| 个别 VOD 提示不可购买/观看 | 版权按地区分发 | 该内容在你所在地区不提供，只能以官方调整为准 |
| 直播看到一半断开 | 网络波动或官方故障 | 到 LIVE 栏重进；付费场次结束后在已购媒体里重看 |
| 直播开始前一直缓冲 | 未到开播时间或网络不稳 | 到点重进；网络问题按第三节处理 |

## 六、找官方客服

- 通用问题：邮件 `support@weverse.io`（客服电话仅韩国境内可用）。
- 商品、订单问题：从「购买的地方」进客服 —— 应用内买的应用内问，Weverse Shop 网页买的在 Shop 的订单记录页。
- 官方公告账号：X [@weverseofficial](https://x.com/weverseofficial)，Instagram 与 YouTube 同名。
