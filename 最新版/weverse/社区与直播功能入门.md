# Weverse 社区与直播功能入门

> 本篇按板块讲 Weverse 的日常使用：加入社区、用自动翻译读各国粉丝的帖子、看 LIVE 直播、发粉丝信。付费相关板块（Only 内容、DM）只说明入口，价格与购买见会员与支付那篇。

## 一、先加入社区，其他一切都从这里开始

Weverse 按艺人分社区。用首页搜索框输入艺人名，进入对应社区点「加入」，就能看到该艺人的帖子、视频与公告。一个账号可以加入多个社区，各社区的内容与活动互不相通。

## 二、看帖与自动翻译

- 艺人发的帖子在 Artist 栏，粉丝之间的自由交流在 Feed 栏。
- 看不懂外语帖子时，点帖子里的翻译按钮，可把内容翻成你设置的语言；艺人的帖子与各国粉丝的评论都能翻。
- 翻译是机器翻译，意思大致不差，玩梗、缩写类内容仅供参考。

## 三、LIVE 直播

- 社区里的 LIVE 栏显示正在直播或已预告的场次。
- 直播中可以发文字消息、点「爱心」互动；部分场次结束后提供回放，能不能回放看该场次的说明。
- 开播时间以社区公告为准，开了通知权限会在开播前收到推送。

## 四、Media 与 Only

- Media 收录艺人的视频内容，带多语种字幕，部分免费看。
- Only 是会员专属内容，需要先购买对应艺人的 Membership 才能看，购买规则见 [会员与支付说明.md](会员与支付说明.md)。

## 五、粉丝信与收藏集

- 粉丝信：用模板与贴纸装扮一封写给艺人的信，发送后艺人端可见；生日、获奖等节点常有专门的粉丝信活动。
- 收藏集：完成社区活动任务可得徽章与 Collectible（带图片或视频的收藏品），在「更多 → 我的收藏」里查看。

## 六、Spot：线下活动专用

Spot 栏汇集演出、快闪店、展览等线下活动信息，常用功能：

| 功能 | 用途 |
| --- | --- |
| 远程排队 | 线上取号，不必到现场干等 |
| Stamp Rally | 集章活动 |
| Pickup | 现场提货（配合商品购买） |
| 二维码 | 入场核销 |

## 七、Weverse AI 搜索

首页右上方的 Weverse AI 入口可以直接提问，用来找公告、回放片段或商品信息，比在社区里翻帖快。

## 八、电脑端与电视端

- 电脑上用浏览器打开 `https://weverse.io`，可以看社区内容与已购视频；购买过的内容要与购买账号一致才能看。
- 手机端可用 Chromecast 或 AirPlay 投到电视上；播放窗口里可选画质，最高到 2160p（4K），实际画质受网络影响。

直播加载不动、视频转圈这类问题，处理步骤在 [常见问题与故障排查.md](常见问题与故障排查.md) 第三节。
