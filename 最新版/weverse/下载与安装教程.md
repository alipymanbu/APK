## 一、安装前先确认这几点

Weverse 是韩国 HYBE 旗下 WEVERSE COMPANY 运营的粉丝社区应用，安卓安装包体积不小（本文所附资源为 227.74M），动手前先过一遍：

| 检查项 | 说明 |
| --- | --- |
| 存储空间 | 建议剩余 1GB 以上，社区图片与视频缓存还会持续占空间 |
| 网络环境 | 注册登录、刷社区与直播都需要稳定的国际网络连接 |
| 系统版本 | 官方说明给出的最低要求为安卓 10.0 及以上（iPhone 为 iOS 17.0 及以上，截至 2026 年，以官方页面为准） |

本文所附的 weverse 安装文件资源是 3.18.0 版，拿到包之后可以按下面几项核对：

| 项目 | 值 |
| --- | --- |
| 版本 | 3.18.0 |
| 包名 | co.benx.weverse |
| 大小 | 227.74M |
| MD5 | 90d8dbaaf1d95d6f9de2d93ecec9b9e0 |

网盘里的版本是固定的，官方渠道的版本号通常已经往前走了，要装更新的版本以 [Google Play](https://play.google.com/store/apps/details?id=co.benx.weverse) 或 App Store 页面显示为准。

## 二、途径一：从夸克网盘获取 APK 直装

1. 打开上面的 weverse 安装文件资源（夸克网盘）链接，转存到自己的网盘后，把 APK 下载到手机。
2. 在手机上点开下载好的 APK。首次安装会提示「未知来源应用」，按弹窗指引允许本次安装即可（各品牌设置入口不同，多数机型在安装弹窗里直接给开关）。
3. 装完打开应用，先授权通知等权限（下一节说明），然后进入登录界面。

登录方式的选择、注册时要注意什么，直接看 [注册与登录问题排查.md](注册与登录问题排查.md)。

## 三、途径二：官方应用商店

- 安卓：[Google Play 商店](https://play.google.com/store/apps/details?id=co.benx.weverse)，认准开发者 WEVERSE COMPANY Inc.
- 苹果：App Store 搜 Weverse，同样认准开发者 WEVERSE COMPANY Inc.

商店版的优势是随官方更新自动升级；手机没有 Google 服务框架的话（部分国产机型），APK 直装反而是更现实的路子。

## 四、首次启动的权限说明

Weverse 会申请若干权限，必需与可选是两类：

| 权限 | 用途 | 可否拒绝 |
| --- | --- | --- |
| 设备与应用记录、设备 ID | 排查错误、识别设备 | 不可（必需） |
| 相机 | 发帖拍照、扫码 | 可拒绝 |
| 照片 / 媒体 / 文件 | 发帖、保存图片视频 | 可拒绝（拒绝后没法保存图片） |
| 位置 | 线下活动的远程排队、部分商品购买 | 可拒绝 |
| 通知 | 艺人更新与公告推送 | 可拒绝（建议开） |
| 麦克风 | 视频音频录制 | 可拒绝 |
| 本地网络 | 连接 Chromecast 等投屏设备 | 可拒绝 |

可选权限不同意也能正常用，只是对应功能受限。
