# Weverse 会员与支付说明

> 本篇讲 Weverse 上三类要花钱的东西怎么买：艺人的 Membership 会员、数字商品结算用的 Jelly、VOD 付费视频，以及 DM 订阅，并整理购买前该知道的退款与账号绑定规则。价格随时会调整，下单前以页面显示为准。

## 一、Membership：按艺人单独购买的会员

Membership 是各艺人官方粉丝俱乐部的会员，不是平台级会员。购买前先弄清这几条规则：

| 规则 | 说明 |
| --- | --- |
| 按艺人购买 | 这个艺人的 Membership 只管这个艺人，想加几个就买几个 |
| 有效期 | 购买日起 365 天，到期可续 |
| 价格因艺人而异 | 以各艺人 Membership 页面标价为准 |
| 账号要求 | Weverse 与 Weverse Shop 必须用同一个账号（同一邮箱），权益才能生效 |
| 一号一份 | 每个账号每期只能买一份，且不能转让 |
| 实名 | 购买时填写的姓名要与有效证件一致，具体证件要求以当期公告为准；填错不能改 |

会员权益通常包括会员专属内容（Only）、投票与优先购票资格等，具体以该艺人当期公告为准。

**退款**：付款后 7 天内、未使用任何会员权益，可在「更多 → 订单记录」里取消；用过权益就不能退了。续费后再退款，续费前那段剩余有效期是否保留，各店铺规则有差异，下单前看商品页的 Notes。

**自动续费**：Membership 支持自动续费，在 Weverse Shop 的 MY → 管理自动付款里查看与关闭。

## 二、Jelly：数字商品专用余额

Jelly 是 Weverse 官方的数字支付方式，用来购买：

- VOD 付费视频
- DM 订阅（艺人私信）
- 数字版 Membership
- 粉丝信等数字商品

**充值入口**：

- 手机：应用首页右下 More → Charge（充值）
- 电脑：weverse.io 页面左下角的黄色 J 图标
- 另有独立的 Jelly Shop 网页，分「普通充值」与「自动充值」两种；自动充值适合长期订阅 DM 的人，余额不足时按预设支付方式自动补足

**支付方式**（以 Weverse Shop 全球站为准，随地区与货币可能不同）：韩国发行的借记/信用卡、PayPal、Eximbay、PAYCO、Toss、Kakao Pay、Weverse Card；部分站点还支持 Apple Pay、Alipay+、微信支付。默认货币为美元、日元、人民币或墨西哥比索时，可选的支付方式以结算页列出的为准。

## 三、VOD：付费视频购买与观看

VOD 指单独售卖的演唱会录像、见面会、团综等视频。购买前这几点最容易被忽略：

1. **先试播**：买前用预告或试看片段确认设备能正常播放。
2. **看了就不退**：播放后一律不可取消；未播放且在购买后 7 天内，可申请退款。
3. **字幕**：一般提供韩、英、日、简中、繁中字幕，具体以商品页标注为准。
4. **画质**：播放窗口可选 144p 到 2160p（4K）。
5. **一端播放**：电脑与手机同时播放付费内容时，只允许其中一端。
6. **账号绑定**：必须在「购买时用的那个账号」下观看；注销 Weverse 账号后购买记录全部消失且无法恢复。
7. **地区**：个别 VOD 因授权原因不在某些地区销售（比如明确标注「韩国境内不可购买」的商品），以商品页提示为准。
8. **播放卡顿**：先彻底退出应用再重进；仍不行就降一档画质。移动网络下观看会产生流量费用，长视频建议 Wi-Fi。
9. **投屏**：用 Chromecast 或 AirPlay 在电视上看付费内容时，部分功能不可用，画质按网络状况自动调整。
10. **购买入口**：手机上买 Weverse Shop 的部分数字商品（如某些 VOD）要走手机浏览器打开 Shop 网页，应用底部 Shop 菜单里买不了。

## 四、DM：订阅艺人私信

DM 是按艺人订阅的私信服务，用 Jelly 结算、按月自动续费。订阅后可与艺人互发消息，支持图片、视频、语音消息与礼物消息。订阅入口在对应艺人社区里，价格以页面显示为准。

## 五、在线演唱会的票，规则和 VOD 不一样

演唱会、见面会的「直播票」（含只看延时场的那种）与 VOD 是两类商品，退款与观看规则差异很大：

| 事项 | VOD | 在线演唱会直播票 |
| --- | --- | --- |
| 退款 | 未观看且 7 天内可退 | 开演前 1 小时起不可退，没看也不退 |
| 观看入口 | 应用或网页版，进社区 Media 栏 | 部分场次走单独的流媒体页面，要用购票的 Weverse Shop 账号登录验证 |
| 重看 | 随时重看 | 有回放的场次结束后在已购媒体里重看；有的票只含延时场，没有直播权 |

下单前认准票种（LIVE / Delayed Streaming / VOD），别只比价格。

## 六、花钱前后的自保清单

- 购买 Membership 前确认 Weverse 与 Weverse Shop 用的是同一个邮箱账号。
- 大额消费（演唱会 VOD、会员）先看商品页的 Notes 与退款条款。
- 所有自动续费项集中记一份（订阅了什么、何时到期），防止无意续费。
- 扣款有问题时，通过「购买的地方」找客服：应用内买的应用内问，Weverse Shop 网页买的走 Shop 客服，通用问题邮件 `support@weverse.io`。

订单与购买记录跟账号的绑定关系，遇到「登录后看不到购买记录」时，先按 [注册与登录问题排查.md](注册与登录问题排查.md) 第二节排查账号混用。
