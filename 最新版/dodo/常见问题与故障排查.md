## 一、群里的排队工具不显示 / 排不上

排队（比如森友圈菜市场）是群内应用，列表异常按下面顺序查：

1. **你进对群了吗**——排队页面在对应的超级群内部，不在 App 首页；
2. **手动刷新**：排队页多数不会实时自动更新，在页面里**下拉刷新**一次；
3. **活动结束了**：岛主可能已关闭排队通道或删掉活动，列表自然为空——这不是故障，等群主重开；
4. **App 版本过旧**：群工具更新频繁，升级到最新版再试（升级方式见 [下载与安装教程.md](下载与安装教程.md)）；
5. 排队前先把**游戏护照**完善好，很多群的排队工具要求有完整档案才能提交。

## 二、打开就闪退 / 白屏

按命中成本从低到高试：

1. 清理后台、重启手机再开一次；
2. 手机 **设置 → 应用管理 → DoDo → 存储**，先「清缓存」；还不行再「清除数据」——**清数据会删本地记录**，重装登录后云端消息会重新拉取，但本地文件要重下；
3. 检查权限：存储、麦克风是否被系统默认关掉（部分国产系统会「自动回收」权限）；
4. 切换网络环境试开（Wi-Fi 换流量）；
5. 确认系统版本满足要求（安卓 5.0 以上，本包标注需 5.2 以上）、存储空间没满；
6. 以上都无效：卸载后重新安装。安装包重新下一份，可走 [DoDo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cb284619e7c0)。

## 三、登录失败 / 收不到验证码

- 先确认手机号输入没有多位、少位；验证码一般 60 秒内到，倒计时结束可重发；
- 收不到短信：检查手机是否欠费、是否装了拦截短信的软件，换个网络再试；
- 提示密码或账号异常：DoDo 主要走手机号验证码登录，确认你在用注册时那个手机号；换号后收不到验证码，说明账号绑的是旧号，需要联系官方客服处理；
- 网络本身不通时任何登录都会失败——先打开一个网页验证网络。

## 四、消息不刷新 / 群内容加载不出来

1. 看顶部连接状态，网络问题先切网；
2. 清缓存（设置 → 应用管理 → DoDo → 存储 → 清缓存）；
3. 退出群再进、或下拉消息列表强制刷新；
4. 只有某一个群异常时，可能是群主在调整群设置（改公开/私密、重整频道），等几分钟；
5. 版本过旧会导致协议对不上，升级后再试。

## 五、语音听不到 / 说话没声音

这属于语音面板状态问题，四个按钮含义与处理见 [语音开黑怎么用.md](语音开黑怎么用.md)。快速版：看麦克风图标是不是被你点了闭麦；语音设置里开「回音消除」；耳机用户确认输出设备是耳机。

## 六、收不到通知提醒（打开 App 才看到消息）

消息本身在，但锁屏、熄屏时没提醒——问题通常出在系统层，按这个顺序开：

1. **系统通知权限**：手机 **设置 → 通知 → 应用通知管理 → DoDo**，打开「允许通知」，并把横幅、锁屏、状态栏显示都勾上；只开总开关但关了横幅，熄屏时照样没提示。
2. **勿扰模式**：手机开了勿扰/免打扰时段，所有通知都会静音，检查时段设置。
3. **后台与省电**：国产系统默认会「冻结」后台应用——到 **应用启动管理** 里把 DoDo 改成手动管理（允许自启动、允许后台活动），再到电池设置里关掉对 DoDo 的省电优化。DoDo 被杀后台 = 收不到推送，进入应用才能拉到消息。
4. **联网权限**：确认 DoDo 的 Wi-Fi 与移动数据联网权限都没被关，也没被「智能省流量」模式拦截。
5. **电脑端同时在线**：部分聊天软件在电脑端登录后，手机端会静默接收而不响铃——如果你正开着 PC 客户端，先把它退了再测手机。
6. **重启后第一次**：手机刚重启、还没打开过 DoDo 时收不到推送是正常的，开一次 App 即恢复。

以上是通用安卓口径（与各手机厂商官方支持文档的排查一致）；若只有某一群不提醒，先查是不是群内开了免打扰。

## 七、账号被封 / 账号安全

**被封了先看通知**：封禁一般会附带原因说明与申诉渠道，先读通知、对照它说的行为自查。DoDo 官方《用户协议》里明确的高危行为有这几类：

- **发布违规内容**、传播垃圾信息、未经许可发广告——群内举报与平台巡查都会触发处罚；
- **冒用他人身份**、恶意注册账号误导其他用户；
- **转让、出租、售卖账号**——协议写明账号使用权仅属于初始注册人，禁止赠与、借用、租用、转让或售卖；
- **长期不登录**：协议保留对长期不活跃账号的回收权利，重要账号隔段时间登一次。

自查没问题就走 App 内反馈或官方站点 [www.imdodo.com](https://www.imdodo.com/) 的客服渠道申诉，提交时带上账号（手机号）、封禁通知截图、能说明情况的记录——要求对方给出具体依据是你的正当权利。

**日常防盗四条**（通用账号安全做法）：

1. 短信验证码就是你的登录凭证——任何自称客服、群主的人问你要验证码，都不要给；
2. 只从官方渠道拿安装包（见 [下载与安装教程.md](下载与安装教程.md)），来历不明的「特殊版本」可能内置窃取登录态的代码；
3. 手机号换号前先在 DoDo 里换绑，否则旧号停机后收不到验证码就找回困难；
4. 怀疑被盗时立即用当前手机号重新登录、改掉在其他平台复用的密码，并在群内声明防止骗子冒充你。

## 八、什么时候该找官方

上面各节都试过仍无解、或问题属于账号处置与付费争议（见第七节），就别自己耗着——走 App 内的反馈入口（设置 → 意见反馈）或官方站点 [www.imdodo.com](https://www.imdodo.com/) 上的客服渠道。反馈时带上有用信息：手机型号、系统版本、App 版本、问题截图——能省一轮来回。
