## 一、「超级群」到底是个什么单位

你在 DoDo 里的一切社交都发生在「超级群」里——它相当于一个自带频道划分的小型社区，而不是普通聊天软件里几十个人的群聊。几个要点：

- **人数不设上限**：官方口径是成员数无上限，几万人的群也照常运转；
- **多频道分区**：一个群里面分很多频道，文字帖区、语音频道、资料库各自独立，按话题分流，不会所有消息挤在一个屏里；
- **邀请或搜索加入**：公开群可以直接搜到加入，私密群靠群号或邀请链接；
- **多端同步**：手机、电脑、网页进的是同一个群，消息一致。

## 二、加入一个已有的群

1. 打开 App，点底部「**发现**」（放大镜入口）。
2. 在搜索框里输入群名或关键词，比如「动物森友会」「怪物猎人」「跑团」。
3. 在结果里点进群主页，确认是你要的那个，点「**立即加入**」。
4. 有的群开了入群验证，提交后等管理员放行；没开的直接进。
5. 进群后先看一眼「厅规」「群规」类置顶频道——大群一般都要求你先读规则再发言。

**通过链接或群号进群**：别人发给你邀请链接时，点开链接会跳转到 App 内的加入确认页；只有群号时，把群号填进发现页的搜索框也能定位到。私密群没被推荐、搜不到，只能走这两条路。

## 三、进群之后怎么看懂界面

- 左侧是**频道列表**：带 `#` 的是文字频道（发消息、看帖子），带耳机图标的是**语音频道**（点击进去就能说话）；
- 帖子类频道长得像论坛，可以看长内容、翻历史，比刷屏聊天适合沉淀攻略；
- 点群头像或群名可以进**群主页**，看群介绍、公告、成员，群主还会在主页挂自定义导航；
- 找不到某个频道时，用群内的搜索——搜索向全体成员开放，不设专门权限。

## 四、自己建一个超级群

1. 在消息列表或发现页找「**创建群聊 / 创建超级群**」入口（侧边 `+` 号里也有）。
2. 填群名称、群简介，选公开或私密：
   - **公开群**：会被收录进搜索与推荐，任何人都能搜到申请加入；
   - **私密群**：不公开收录，只能靠群号、邀请链接进人。
3. 建好后你就群主了，可以继续加频道：文字频道、语音频道、帖子频道、资料库频道等类型都有；频道与分组的管理在群设置里。
4. 邀请人：把群号或邀请链接发出去即可。
5. 想让群长期运转，再去群设置里配**角色权限**——把删帖、踢人、管频道的权限分给管理员，自己不用事事亲为。

## 五、群主与管理员常用的一些开关

| 想做的事 | 在哪操作 |
| --- | --- |
| 让群被搜索到 | 群设置 → 隐私（公开群 / 私密群） |
| 加新频道、改频道图标 | 群设置 → 频道管理 |
| 分权限给管理员 | 群设置 → 角色与权限 |
| 挂公告、改群主页 | 群主页编辑（部分能力需在 PC / Web 端操作） |
| 处理违规内容 | 帖子/消息长按举报、删除 |

部分高级编辑能力（比如资料库频道、群主页导航）官方注明需要在 PC 或 Web 端完成，手机端可以先规划内容、电脑上再配置。

## 六、围绕群的典型玩法

以最有名的「森友圈」为例：里面聚集了大量动森玩家，群内有菜市场排队工具、动森护照、图鉴收集进度这些群应用，新人进去一般先完善自己的游戏护照再参与排队。其他群各有各的工具——游戏招募频道喊人开黑、攻略频道问打法，进群后按公告走就行。

排不上队、群里工具打不开这类问题，见 [常见问题与故障排查.md](常见问题与故障排查.md)；语音频道怎么说话怎么闭麦，见 [语音开黑怎么用.md](语音开黑怎么用.md)。
