## 一、这是什么软件

DoDo 是一个游戏玩家与亚文化爱好者用的社群平台，把群聊、论坛发帖、语音开黑装进了一个 App 里。你既可以只当成员、加入别人的超级群聊游戏，也可以自己免费建一个超级群当群主。它从《集合啦！动物森友会》的玩家社群起家，现在也有原神、怪物猎人、Apex、跑团这类游戏与兴趣社区。

开发者是上海渡渡网络科技有限公司，官方站点是 [www.imdodo.com](https://www.imdodo.com/)（下载入口也可走 [dodo.link](https://dodo.link/)）。除了安卓 App，它还有 iOS、Windows 客户端、网页版和小程序，账号是同一个。

## 二、装之前先确认这几项

| 项目 | 要求 |
| --- | --- |
| 系统 | 安卓 5.0 及以上（本包采集记录标注需安卓 5.2 以上） |
| 包名 | `com.dodolive.app` |
| 安装包大小 | 75.81M（版本 5.1.0.09），装完建议再预留 200MB 以上空间 |
| 网络 | 首次登录要收短信验证码，需要能上网的 Wi-Fi 或数据流量 |

包名可以在下载前核对一下：文件名或文件信息里能看到 `com.dodolive.app` 就对了。装来历不明的同名包有风险，拿不准就用你手机自带的应用商店搜「DoDo」比对版本。

## 三、安装步骤

1. 从 [DoDo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cb284619e7c0) 把安装包转存到你的网盘，再在手机上下载 `.apk` 文件并点击安装；或从手机自带应用商店搜索安装。
2. 如果是浏览器下载的安装包，系统会提示「禁止安装来自此来源的应用」——这是正常的拦截。你到 **设置 → 允许安装未知来源**（不同品牌叫法略有差异，也可在安装提示弹窗上点「设置」进去）里对当前浏览器临时放行，装完建议关掉这个开关。
3. 安装完成打开，首次启动会请求**存储**与**麦克风**两项权限：存储用于收发文件与图片，麦克风用于语音频道说话。建议都允许；定位、通讯录这类用不到的可以拒绝。
4. 进入登录页。

## 四、登录与首次设置

1. DoDo 用**手机号 + 短信验证码**登录，按提示输入手机号、填验证码即可，首次登录会自动注册账号。
2. 登录后先起一个昵称——默认昵称是一串「Do友-数字」，进群后很多社群要求你改成好认的名字，可以在头像 → 个人资料里改。
3. 建议在设置里绑定好手机号，方便换设备后找回账号。
4. 底部导航的「发现」是找群入口，「消息」是你已加入的群与私信列表。

## 五、升级与卸载

- **升级**：应用内一般会在设置里提供版本检查；版本号以官方渠道当时显示为准。网盘里那份是 5.1.0.09，官方出新版本后以官方最新版为准。
- **卸载**：直接长按图标卸载即可。注意卸载会清掉本地缓存的聊天记录，重新安装登录同一手机号后，云端还在的群消息会重新拉下来，但本地已下载的文件需要重新下。
- 想在电脑上用，去官网下载 Windows 客户端或直接开网页版，同一个手机号登录，群列表是同步的。

装好之后的下一步通常是找一个群进去——见 [超级群怎么加入和创建.md](超级群怎么加入和创建.md)；进语音频道开黑见 [语音开黑怎么用.md](语音开黑怎么用.md)。
