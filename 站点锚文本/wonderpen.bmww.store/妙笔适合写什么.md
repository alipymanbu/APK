# 妙笔适合写什么：选型前先看这篇

> WonderPen（妙笔）是一款以文字为主的写作工具，但工具各有擅长。本篇按写作场景把它能干的活儿和不该指望的活儿分开摆，帮你在选型阶段少走弯路。
> **相关笔记**：[跨设备同步与防丢稿](跨设备同步与防丢稿.md) · [导出格式与成书流程](导出格式与成书流程.md)

## 它的底色：文档库 + 目录树 + 编辑器

WonderPen 由杭州同鸣科技开发，桌面端覆盖 Windows、macOS 与 Linux，手机端有 iOS 与 Android 版本。所有内容装在**文档库**里，库内按**树状目录**组织，层级没有上限——这个底色决定了它最适合「结构先行」的写作：先立骨架，再往每一节里填字。

编辑器是所见即所得的，不记语法也能排出粗体、列表、公式；懂 Markdown 的话，语法输入同样生效。写作中途冒出的想法可以记进**卡片列表**，人物设定、情节纲要这类全局素材放**白板**，需要参照时还能把卡片在编辑器里高亮显示。

## 五类放心交给它的活儿

1. **小说等长篇故事**：卷、章、场景层层往下拆，章节写乱了可以右键切分、合并；大纲视图把整部作品铺成表格，加自定义元数据（如 POV、状态）总览进度。
2. **技术书籍与论文**：按章、节、小节组织素材，每篇文档带专属备注，设定与文献线索记在正文旁边不占稿面。
3. **日记、博客与短文**：写完即走，专注模式、极简模式、打字机模式三档任选，干扰越少越好。
4. **灵感碎片**：一时不成文的点子先收进卡片，回头再长成文章。
5. **码字打卡**：设定目标字数盯进度，每日产出在统计里一目了然。

## 四件别勉强它的事

- **复杂的富文本排版**：小册子式的花哨版式不是强项，排版复杂就换专业排版工具。
- **多人协作**：暂不支持共写一份文档，团队场景另选工具。
- **把所有家当塞一个云端库**：免费档云端库有 1 个、条目与单篇字符数有额度，多部作品分库管理前先看额度。
- **超长单篇导出图片**：文档太长时导出图片可能失败，这类内容走 PDF 或 Word。

## 免费能用多久

基础版不是限时试用，可以一直用：树状目录、编辑器、卡片与白板、六种格式导出、整库备份都在免费范围内。会员档（Pro 与 Pro+）主要解锁主题外观、自定义 CSS、更高的云端库额度与更长的云端快照保留期——只在手机上写日记短文的话，免费档就够。
