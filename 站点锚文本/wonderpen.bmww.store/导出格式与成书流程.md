# 导出格式与成书流程：写完之后的事

> 在 WonderPen（妙笔）里写完只是上半场，本篇讲下半场：六种导出格式怎么选、几十个章节怎么合并成一部完整的书、手机端能导什么，以及两个容易踩的坑。
> **相关笔记**：[妙笔适合写什么](妙笔适合写什么.md) · [跨设备同步与防丢稿](跨设备同步与防丢稿.md)

## 六种格式，按去向选

导出格式覆盖 Word（docx）、PDF、Epub 电子书、网页（HTML）、纯文本（txt）、图片（PNG）六种，且**免费版与会员档的导出能力一致**，导出不设门槛：

| 格式 | 典型用途 |
| --- | --- |
| Word | 交稿给编辑、后续继续修改 |
| PDF | 打印、定稿存档 |
| Epub | 发布到阅读平台 |
| HTML | 自行发布、浏览器里直接看 |
| txt | 迁去其他写作工具、投稿系统 |
| PNG | 分享单篇内容 |

导出时内置排版会尽量保留编辑器里的常用效果，表格、代码块与代码高亮都能带出去。

## 从「一堆章节」到「一本书」

长篇最常见的需求是把几十个章节合成一个文件，三步完成：

1. 在左侧目录树里勾选要导出的多个文档或章节；
2. 选择导出为单个文件；
3. 挑章节间的连接方式——**分页**（每章另起一页，适合 Word、PDF 成书）或**空行**（用指定数量的空行衔接，适合纯文本）。

只想要某一卷时，选「导出当前节点及其所有子节点」整卷带出；选文本或网页格式时还能按文件夹导出，保持目录层级、一章一个文件。

## 两个容易踩的坑

- **超长文档别导出为图片**：帮助文档明确警告文档太长时导出图片可能失败，改走 PDF 或 Word。
- **PDF 想带背景要先开「打印背景」**：设了背景色、背景图的文档，导出设置里不开这一项，成品里不会出现。

## 手机端能导什么

移动端的导出能力跟版本挂钩：0.9.39 起可以在编辑器右上角的更多菜单里导出文本文件（.txt）或导出图片（长图、卡片两种样式，成品存进相册）；更早的版本没有这两个入口。在手机上写的稿子要排成书，稳妥的路子是先用云端库同步到桌面端再导出。

另外值得一提：即使哪天不再用 WonderPen，全部稿子也能按原有章节结构导出成文本迁去别的工具，整库还能打包 Zip 带走——换工具的成本极低。
