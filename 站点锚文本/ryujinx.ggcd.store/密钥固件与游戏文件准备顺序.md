# Ryujinx 密钥固件与游戏文件准备顺序

「装好了为什么玩不了」是 Ryujinx 安卓版最常见的问题，答案几乎都在三件套上：密钥（prod.keys）、系统固件（Firmware）、游戏文件（NSP/XCI）。模拟器本体只是运行环境，这三样因为版权原因都得玩家自行准备，且顺序不能乱。

## 一、三件套分别是什么

| 组件 | 形态 | 作用 |
| --- | --- | --- |
| 密钥 prod.keys | 从自己拥有的主机导出的文件 | 解密 Switch 游戏数据，没有它游戏文件读不开 |
| 系统固件 Firmware | zip 压缩包 | 让模拟器具备 Switch 系统环境，部分游戏强依赖 |
| 游戏文件 | .NSP 或 .XCI | 游戏本体，自行准备并放入手机目录 |

密钥的正规来源是玩家自己的 Switch 主机：社区常用 Lockpick_RCM 一类工具从自己拥有的设备中导出。模拟器项目本身不分发密钥，网上来路不明的密钥包既有版本错配风险，也有安全隐患，不建议碰。

## 二、为什么顺序必须是密钥 → 固件 → 游戏目录

这三步存在依赖关系，乱序的表现很有迷惑性：

1. **先导密钥**：固件安装过程要解密校验，密钥缺失时安装固件会直接报错——很多人卡在「固件装不上」，根因在这。
2. **再装固件**：在「设置 → 程序」里点「安装系统固件」，直接选中 zip 压缩包即可，**不要解压**；解压后散装文件反而不被识别。
3. **最后指目录**：在「设置 → 程序 → 游戏目录」选中放游戏文件的文件夹，回到主界面等扫描，游戏图标会自动出现。

密钥与固件版本不匹配是加载失败的另一高发原因：导出密钥的主机系统版本，尽量与固件包版本接近。

## 三、装好后的两个正常现象

- **首次进游戏很卡**：着色器缓存正在编译，等它跑完；保持「启用着色器缓存」开启，编译结果落盘复用，第二遍就顺了。
- **游戏列表空白**：先自查三件套次序，再确认文件格式确实是 NSP/XCI——rar、zip 压缩的游戏包要先解开成镜像文件本身。
