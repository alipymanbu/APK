# Ryujinx 手机配置要求与流畅度调优

Switch 模拟对手机并不算轻量：同样的 Ryujinx 安卓版，旗舰机上是「能玩且顺」，中端机上可能是「能进游戏但掉帧」。差别主要来自三处——CPU 翻译能力、GPU 后端选择、着色器缓存策略。这篇按真实设置面板逐项说清楚。

## 一、机型门槛在哪

- **处理器**：建议骁龙 8 系、天玑 9000 系或同等级芯片。Switch 的 CPU 侧需要实时做指令翻译，这是最吃性能的环节，中低端芯片很难靠设置弥补。
- **存储**：模拟器本体只有 61MB 出头，但单个游戏文件动辄数 GB，预留空间要按游戏库算。
- **系统版本**：保持较新的安卓版本，旧系统在图形驱动与内存管理上都吃亏。

## 二、决定帧率的四个开关

对照设置页逐项看（截图与入口见 [Ryujinx 安卓版介绍站](https://ryujinx.ggcd.store/)）：

1. **使用NCE**：受支持的机型保持开启，CPU 翻译开销显著下降；老机型若频繁闪退，关闭它做对比，再决定取舍。
2. **启用着色器缓存 / 缓存编译**：首次进图卡顿的元凶与解药。保持开启让编译结果落盘，第二次进同一场景直接复用；关掉它等于每次进图都重新编译。
3. **分辨率缩放比例**：1.0x 是原生档。画质与帧率冲突时先降它，比动纹理压缩更直接；「启用纹理重新压缩」在显存吃紧时再开。
4. **垂直同步**：防画面撕裂，帧率有余量时建议常开；追求极限帧数的老机型可以关掉换几帧。

## 三、操作方式怎么配

- **虚拟按键**：「显示虚拟按键」默认开，配合「使用NS控制器布局」还原主机手感；「控制器摇杆灵敏度」按个人习惯微调。
- **重力感应**：依赖体感的游戏（赛车、平衡类）打开「启用重力感应」，其余场景可关以省电。
- **蓝牙手柄**：Switch、PS、Xbox 布局的主流手柄即连即用，配合「主机映射」把按键按主机形态映射给游戏，体验远好于触屏。

## 四、两个容易被误解的现象

- **越玩越流畅是正常的**：着色器缓存在持续积累，前期卡不代表上限如此，给它几个小时的游戏时长再下结论。
- **掉帧不一定怪模拟器**：后台挂着网盘同步、录屏、分屏都会挤占性能，测试帧率时尽量清干净后台。
