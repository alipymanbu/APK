# 出图提示词速成

> 同一个应用，别人出的图精致、你出的图随机，差别多半不在运气而在描述的写法。本篇把手机端够用的提示词方法压成一篇速成：结构、例子、改错，看完就能用。还没跑通第一张图的，先看 [手机AI绘画从零上手](手机AI绘画从零上手.md)。

---

## 一、只记一条铁律：越靠前越重要

模型读描述时，排在前面的词权重更高。写的时候按「最重要的放最前」排：

```text
主体 → 主体细节 → 风格 → 构图 → 光线 → 质量词
```

对比一下：「一只白鹿，鹿角带花，唯美梦境风格，柔光」和「一张超级美丽的图片，有一只动物」——前者每一段都在给模型信息，后者只有形容词在空转。第一句出图的命中率远高于第二句。

## 二、六层结构，一张对照表

不必每次写满六层，但图不满意时，对照这张表看漏了哪层：

| 层 | 作用 | 例词 |
| --- | --- | --- |
| 主体 | 画面里是什么 | 一只白鹿 / 穿汉服的女孩 / 赛博朋克城市 |
| 主体细节 | 长相、动作、穿着 | 回头、长发、红白汉服、鹿角带花 |
| 风格 | 画成什么画风 | 水墨、动漫、油画、梦境感、未来感 |
| 构图 | 镜头怎么摆 | 半身特写、全身、俯视、仰视 |
| 光线 | 什么光 | 逆光、黄昏柔光、月光、霓虹灯光 |
| 质量词 | 拉高完成度 | 高清细节、精致画面、杰作质感 |

新手最容易缺的是「主体细节」和「光线」——前者决定画面准不准，后者决定氛围稳不稳。

## 三、让风格分区替你定方向

手机端的优势是不用背风格词：作品墙顶部的分区（古风、二次元、唯美梦境、梦境绘画、潮流插画）本质是预选好的画风方向。选分区时，描述就往同一个方向写，出图才不拧巴：

| 选的分区 | 描述往这个方向靠 |
| --- | --- |
| 古风 | 汉服、庭院、灯笼、月下、水墨晕染 |
| 二次元 | 动漫风格、赛璐璐上色、清透、高饱和 |
| 唯美梦境 | 梦幻、光斑、薄雾、柔焦、仙境 |

偷懒但有效的起点：作品墙卡片上的短词就是真实能出这套图的提示词，点「制作同款」后只替换主体词即可。

## 四、三个立刻能用的技巧

1. **一次只改一个词**。整句重写会让你不知道是哪个改动起了作用；只改主体或只改风格词，对比最快。
2. **把「不满意」翻译成具体描述**。觉得画面脏，就写「干净背景、简洁构图」；觉得脸糊，就加「五官端正，精致的面部细节」——「再好看一点」这种话模型读不懂。
3. **脸和手出问题，先降复杂度**。多人画面出问题的概率成倍上升；先画单人，镜头拉近到半身特写，稳定性立刻不同。更细的修法这里不展开，核心是把给手「安排具体动作」、让脸「占够像素」。

## 五、出不了图，那不是写法问题

描述写得再好，也绕不开流程层面的坎：高峰期排队、弱网超时、提交报错。碰到这些按这个顺序排：等几分钟再试 → 换网络对比 → 重开应用。把写法和流程两类问题分开，就不会在错误的环节反复用力。

顺带一提次数问题：这类应用通常有限免额度，规则以应用内显示为准。次数紧张时，先把提示词在别处打好草稿、用「制作同款」验证方向，确认对了再花自己的次数。
