# 手机串流玩电脑Steam游戏教程

> 手机屏幕小归小，电脑游戏照样能在掌心里跑——靠的是串流，不是把游戏装进手机。
> **相关文档**：[连接不上电脑的排查清单.md](连接不上电脑的排查清单.md) · [串流画面卡顿的优化方法.md](串流画面卡顿的优化方法.md)

---

## 一、思路先摆正：串流不是移植

Steam Link 走的路子和「手机版游戏」完全是两回事：游戏始终运行在你的电脑上，显卡与 CPU 干重活；手机那边只接收画面与声音，再把你的触控、手柄指令传回去。手机相当于一块带操控的远程屏幕。

这条路子带来两个直接结论：

- 电脑跑得动的游戏，手机上就能玩；电脑跑不动的，串过去也不会变快；
- 游戏不需要在手机上再下一次，手机只装一个串流应用。

## 二、要备齐的东西

| 角色 | 要求 |
| --- | --- |
| 手机 / 平板 | Android 5.0 及以上 |
| 电脑 | 装着 Steam、保持登录，游玩时别睡眠 |
| 网络 | 同一个路由器下最稳；建议 5 GHz 频段，电脑插网线 |

手柄不是必需品：没有手柄时应用会给出触屏虚拟按键，画面左上角的菜单里还能切鼠标模式、拖动按键位置；真要认真玩动作与赛车类，再接一只标准蓝牙手柄也不迟。

## 三、从安装到开玩的完整过程

1. **装应用**：安装包可以从 Steam Link 介绍站（[https://steam-link.qjxz.skin/](https://steam-link.qjxz.skin/)）的指引拿到，页面上把安装与配对拆成了分步骤说明；
2. **连网络**：手机与电脑连同一个 Wi-Fi，这是后面一切的前提；
3. **配对**：应用自动扫描同一网络里的电脑，点选后屏幕上会显示一串 PIN，在电脑弹出的确认框里输入即可——这一步要人在电脑跟前；
4. **开玩**：配对成功后，电脑里的整个 Steam 库会原样出现在手机上，点哪个就串哪个。

首次连接时应用还会给网络打个分，分数低说明环境有短板，照排障思路调一调即可（见 [串流画面卡顿的优化方法.md](串流画面卡顿的优化方法.md)）。

## 四、装好之后值得试的两个玩法

- **远程同乐**：本地合作、分屏对战类的游戏，好友通过互联网就能加入你这一局——游戏只在你的电脑上跑一份，好友不必拥有这个游戏，最多四人可立即加入；
- **出门连回家**：出门在外用流量也能连回家里那台电脑，只是延迟比局域网高，回合制、剧情向更合适。出发前记得让电脑保持开机与登录。
