# 连接不上电脑的排查清单

> 手机上一直转圈、电脑显示「离线」——别急着重装应用，九成是下面这些基础项没同时满足。
> **相关文档**：[手机串流玩电脑Steam游戏教程.md](手机串流玩电脑Steam游戏教程.md) · [串流画面卡顿的优化方法.md](串流画面卡顿的优化方法.md)

---

## 一、先确认三个前提

Steam Link 连不上电脑的情况，绝大多数出在这三条：

1. **同一个网络**：手机与电脑要连同一个路由器——电脑插网线、手机连这台路由器的 Wi-Fi 也算；一个走流量、一个连 Wi-Fi 就不是同一网络；
2. **Steam 开着且已登录**：电脑上的 Steam 退出登录或没启动，手机那边就会把电脑标成「离线」；
3. **电脑没有睡眠**：睡眠中的电脑无法被发现，远程唤醒不总管用。

## 二、逐项往下查（按命中率高到低）

1. **路由器开了「访客网络」或「AP 隔离」**：这两种设置会让设备之间互相看不见，需要进路由器后台把「接入点 / 客户端隔离」关掉；
2. **公共网络连不了**：公司、学校、酒店这类带门户登录或开了客户端隔离的网络不支持，换手机流量验证最快——流量能连上，说明是当前 Wi-Fi 的问题；
3. **端口被占**：首次发现电脑用的 27036 端口若被别的程序占用，电脑不会出现在列表里，重启 Steam 再试；
4. **防火墙重新开拦**：Steam 或游戏刚更新过时，Windows 防火墙可能重新拦截，放行规则里给 Steam 建好例外即可；远程畅玩相关端口为 UDP 27031、27036 与 TCP 27036、27037。

## 三、电脑端开关复核位置

| 位置 | 检查什么 |
| --- | --- |
| Steam 客户端 → 设置 → 远程畅玩 | 「启用远程畅玩」勾上；状态异常就取消再重新勾一次 |
| Windows 防火墙 | 允许 Steam 通过；更新后要重新确认一遍 |
| 网络类型 | 当前网络设为「家庭网络」，「公用网络」下连接容易不稳 |

## 四、能连上但体验差的另一回事

配对成功只是开始。画面卡、延迟大属于网络与设置问题，处理思路完全不同，见 [串流画面卡顿的优化方法.md](串流画面卡顿的优化方法.md)；从零开始装与配对的流程整理在 [手机串流玩电脑Steam游戏教程.md](手机串流玩电脑Steam游戏教程.md)，配套的安装与配对分步说明也可以直接看 [Steam Link 站点](https://steam-link.qjxz.skin/)上的安装页。
