# JuicyChat 角色创建与持久记忆玩法

> 讲 JuicyChat 里两类核心玩法：把一个角色从零搭出来，以及让对话跨会话延续的持久记忆系统。
> **相关文档**：[安卓端安装与首启设置.md](安卓端安装与首启设置.md) · [免费额度与订阅前须知.md](免费额度与订阅前须知.md)

## 一、先从角色库挑，还是直接自己搭

登录后进入 Characters 标签页就是角色库：现成角色按标签和内容分级排列，点开就能聊。多数人的实际路径是**先挑一个接近的**，发现某些设定不合口味，再进编辑器微调——完全从零搭一个的门槛比微调高不少。

想直接搭也行，编辑器里能填的字段不少，但开聊只需要其中三项：形象、性格、开场白。

## 二、角色编辑器里那些字段各管什么

| 字段 | 管什么 | 填写建议 |
| --- | --- | --- |
| 形象卡 | 角色的视觉呈现 | 可以先用图像生成产一张，之后随时换 |
| 性格 | 角色说话的脾气与方式 | 写具体场景反应，比堆形容词管用 |
| 开场白 | 角色先开口的第一句 | 决定对话起点，直接写你想要的情境 |
| 场景设定 | 对话的关系与情境背景 | 后补也不迟，不影响先开聊 |
| 标签 | 角色被检索的入口 | 填清楚才容易被对口的人搜到 |
| 内容分级 | 框住角色的话题范围 | 按真实意图填，这是分级开关生效的依据 |
| 底层模型 | 同一角色可切换对话模型 | 不确定就用默认，聊起来不顺再换 |

场景设定和开场白搭配起来最影响体验：同一个角色，场景写「刚认识的陌生人」和「认识多年的旧识」，第一句开场白之后走向完全不同。

## 三、记忆：聊过的下次还在

JuicyChat 的持久记忆保存的是跨会话的上下文要点，不是原文存档。你在对话里提过的偏好、剧情里发生过的关键事件、你惯用的表达方式，会沉淀进角色对你的理解，下次打开接着聊，不用复述前情。

界面顶部的 Memories 面板可以查看这些记忆内容。两点实用建议：

- 剧情跑偏、想重开一条线时，先清理相关记忆再继续，比直接新开对话更干净；
- 记忆是随对话累积的，介意留痕就定期清理，不影响正常使用。

这也是它和一次性聊天机器人的主要差别：积累的上下文越多，回应越贴合你，值得把时间花在一个角色上而不是每次换新。

## 四、打字之外的补充玩法

- **语音回复**：角色可以语音回话，配合场景设定用沉浸感更明显；
- **图像生成**：文字提示词出图，也能基于已有角色形象重绘，产出的图可以用作角色形象卡。
