# 深空-Stargate 介绍站 · 站点目录

这里收录围绕深空-Stargate（深空联机盒子）整理的几篇说明文章。深空-Stargate 是一款面向我的世界手机版玩家的房间制联机工具：登录深空账号后，房主点加号建房、玩家直接进房，最高 40 人同房，兼容基岩版与携带版多版本，游戏内可调出 Aurora 悬浮窗随时管理。

本站是第三方介绍站，从房间动线（登录 → 建房/进房 → 悬浮窗）出发讲清楚它的用法，并提供安装文件资源的获取入口：[深空-Stargate 介绍站](https://stargate.kook.yoga/)。
