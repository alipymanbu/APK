# 手机 AI 绘画和电脑部署怎么选

> 圈子里说的「SD」常常指两件事：手机上点选出图的应用，和电脑上自己部署的 WebUI。两者同源但体验完全不同，本篇帮你对号入座。提示词的写法两边相通，系统写法看 [AI绘画提示词六层写法.md](AI绘画提示词六层写法.md)；还没上手的先读 [手机AI绘画入门到第一张图.md](手机AI绘画入门到第一张图.md)。

## 一、先把名字理清楚

Stable Diffusion 原本是开源的文生图模型系列。因为开源，它衍生出两种典型用法：

- **电脑端**：把模型装进自己的电脑，配合 WebUI 界面出图，玩家口中的「本地部署」「跑 SD」指的就是这个；
- **手机端**：把同一套文生图能力做成「选风格、写一句描述、点生成」的轻量应用，出图放在云端完成，Stable Diffusion 手机版就是这种形态。

## 二、逐项对比

| 对比项 | 手机版 | 电脑本地部署 |
| --- | --- | --- |
| 安装 | 装个 APK 就能用 | 装 Python 环境、整合包，再下数 GB 模型 |
| 硬件 | 普通安卓手机 | 基本要独立显卡，显存越大越顺 |
| 出图在哪算 | 云端服务器 | 自己电脑的显卡 |
| 换模型 | 应用内风格模板，一般不能导外部模型 | 社区模型、LoRA 随便挂 |
| 参数 | 点选式 | 采样器、步数、CFG、分辨率全可调 |
| 上手 | 几分钟 | 几小时起步，还得会查报错 |

一句话：手机版买的是「省事」，电脑版买的是「控制权」。

## 三、选手机版的信号

- 做头像、壁纸、社交配图，质量够用就行；
- 电脑没有独立显卡，或压根不想碰命令行与报错；
- 灵感来了想马上出图，等不了装环境。

这类需求的安装入口见 [Stable Diffusion 手机版专题站](https://www.wrwq.fun/)，从取包到装好大概只要几分钟。

## 四、该上电脑版的信号

- 要精确控制构图与姿态（ControlNet 这类工具电脑端才有完整体验）；
- 要挂 LoRA 固定特定画风或角色、批量跑图；
- 出图要商用、对分辨率和细节有硬要求；
- 本身就把折腾环境当乐趣。

## 五、最划算的其实是两边都用

不少人手机上快速出小样、试风格，方向确定后把同样的提示词搬到电脑上精修大图。手机胜在随手，电脑胜在可控。提示词经验完全互通——在手机上用 [AI绘画提示词六层写法.md](AI绘画提示词六层写法.md) 练出的手感，搬到电脑上照样适用。
