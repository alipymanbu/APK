# AI 绘画提示词的六层写法

> 同一个应用，别人出图好看、自己出图随机，差别九成在提示词。本篇给一套能直接照抄的结构。还没装上应用的，先看 [手机AI绘画入门到第一张图.md](手机AI绘画入门到第一张图.md)；纠结该在手机上玩还是电脑上折腾的，看 [手机AI绘画和电脑部署怎么选.md](手机AI绘画和电脑部署怎么选.md)。

## 一、一条铁律：越靠前越重要

Stable Diffusion 这类文生图模型读提示词时，排在前面的词权重更高。所以别想到什么写什么，按固定的顺序排：

```text
主体 → 主体细节 → 风格 → 构图 → 光线 → 质量词
```

「一只白鹿，站在雾气弥漫的森林里，唯美梦幻，柔光」好过「一张超级美丽的图片，有一只动物」——前者每一段都在给模型信息，后者只有形容词在空转。

## 二、六层对照表

不用每次写满六层，但出图不满意时，对照这张表看漏了哪层：

| 层 | 作用 | 例词 |
| --- | --- | --- |
| 主体 | 画面里是什么 | 一只白色小鹿 / 穿汉服的女孩 |
| 主体细节 | 长相、动作、穿着 | 回头、长发、红白汉服 |
| 风格 | 画成什么画风 | 水墨、动漫、梦境感、未来感 |
| 构图 | 镜头怎么摆 | 半身特写、全身、俯视 |
| 光线 | 什么光 | 逆光、黄昏柔光、月光、霓虹 |
| 质量词 | 拉高完成度 | 高清细节、精致画面、杰作质感 |

## 三、三个立刻能用的技巧

1. **一次只改一个词。** 整句重写会让你不知道是哪个改动起了作用；只改主体或只改风格词，两相对比最快摸到规律。
2. **把「不满意」翻译成具体描述。** 觉得画面脏，就加「干净背景、简洁构图」；觉得脸崩，就加「精致五官」——「再好看一点」这种话模型读不懂。
3. **反向描述。** 创作页若提供「不希望出现」之类的输入框，把最怕出现的填进去：模糊、低质量、多余的手指、变形、文字水印。

## 四、用「制作同款」偷懒

手机版首页作品墙卡片上的短词就是能出这套图的真实提示词。点「制作同款」后只替换主体词，是验证方向最省次数的办法——思路通了再花自己的生成额度。

## 五、还是出不好图的几个去向

- 手或脸崩了：小崩直接重roll一张；大面积崩就减人数、镜头拉近、给手安排具体动作（如「单手捧着茶杯」）；
- 图能出但不满意：回到第二节对照表补层；
- 排队转圈不出图：那是高峰期的正常现象，等几分钟再试，别反复点。
