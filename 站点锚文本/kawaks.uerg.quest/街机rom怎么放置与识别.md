# 街机 rom 怎么放置与识别

> 「明明下载了游戏，列表里就是刷不出来」——街机模拟器的问题十有八九落在 rom 的放置方式上。这篇按「文件形态 → 目录路径 → 主板差异」的顺序，把识别失败的可能逐个排掉。

## 一、文件形态：zip 是唯一正确答案

街机 rom 的通行形态是一个 zip 对应一个游戏，模拟器读取的就是这个压缩包本身。三条铁律：

1. **不解压**。解压后的散文件反而识别不了，压回去即可；
2. **不改名**。同游戏常有世界版、日版、美版多个区域包，文件名里带着版本记号，动了它模拟器可能对不上主板定义；
3. **不拆包**。有些 zip 里文件不少，那不是多余，缺一个就报缺文件。

## 二、路径：中文目录是头号杀手

实测最常见的「文件在却扫不出」，根因都是路径里有中文——比如 `下载/游戏/拳皇` 这样的目录，读不到。推荐做法是在手机**内置存储**根目录建一个纯英文文件夹（`/roms` 或 `/kawaks/roms`），所有 zip 都放进去。另外两点经验：

- 优先放内置存储，别放外部 SD 卡——部分机型对外置存储的读取权限更麻烦；
- 游戏多了以后用列表里的搜索框按名字找，比逐个翻分类快得多。

放好之后，在模拟器的游戏列表界面找到「更改 rom 路径」入口，指到这个文件夹、触发一次扫描，游戏就会按「对打格斗 / 动作过关 / 飞行射击 / 益智休闲」分类列出来。

## 三、NeoGeo 游戏要多放一个系统文件

拳皇、合金弹头、侍魂这类 NeoGeo 主板的游戏，除游戏 zip 外还需要同目录放一个 `neogeo.zip`（系统 BIOS 性质的文件），否则启动即提示缺文件。CPS1、CPS2 的游戏不需要它——这两类扫不出来，就该回第二节查路径与形态了。

还有一类「提示缺少 xxx 文件」缺的是游戏自身的某个文件：同一个游戏的某些区域版依赖「世界版 / 主版本」才能启动，只放一个区域版可能就卡在这。处理办法是把世界版的 zip 放进去，或把同游戏的几个版本一起放好再扫一次。

## 四、还是识别不了的三步判定

1. 看主板：游戏属 CPS1 / CPS2 / NeoGeo 的，按上面三节走；三国战纪、西游释厄传这类 PGM 主板作品能否运行说法不一，放进实测最快；
2. 看文件：zip 原样、路径纯英文、NeoGeo 带 `neogeo.zip`；
3. 看提示：能进但缺文件按第三节补；黑屏闪退则多半是版本与权限问题。

安装与权限环节的问题，去 [kawaks 街机模拟器站](https://kawaks.uerg.quest/) 的下载安装页对着排；放好游戏想调手感，看 [触屏搓招与手柄键位设置](触屏搓招与手柄键位设置.md)；刚入门的先读 [手机上重温街机厅从哪开始](手机上重温街机厅从哪开始.md)。
