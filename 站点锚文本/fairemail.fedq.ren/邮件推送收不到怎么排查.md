# 邮件推送收不到怎么排查

> 手机上的邮件客户端突然不推新邮件了？本篇给一条从浅到深的排查路径：常驻通知 → 电池策略 → 同步条件 → 认证状态，多数「收不到」在前两步就能解决，FairEmail 用户尤其适用。
> **相关文档**：[开源邮件客户端怎么选](开源邮件客户端怎么选.md) · [README](README.md)

---

## 一、先看通知栏：常驻通知还在吗

FairEmail 这类靠长连接推送的客户端，会在通知栏挂一个低优先级的常驻通知——它对应维持推送的前台服务，是「推送还活着」的标志。它被划掉或被系统隐藏，新邮件提醒就失去了保障。先把它找回来，再谈后面的事。

## 二、电池策略：头号元凶

安卓厂商的电池管理对「要 7×24 小时活在后台」的邮件应用格外严厉，这是收不到推送的最常见原因：

| 位置 | 要做的事 |
| --- | --- |
| 系统设置 → 应用 → 邮件客户端 → 电池 | 改为「不受限制 / 允许后台运行」 |
| 手机管家 / 自启动管理 | 打开自启动放行 |
| 最近任务界面 | 把卡片加锁，防止一键清理 |

各品牌叫法略有差异：小米在「省电策略」里选无限制，华为在「应用启动管理」里改手动并开满三个开关，三星要把应用移出「深度休眠应用」名单。两个通杀动作：关掉省电模式再观察；部分系统（尤其 MIUI 系）重启或更新后会重置这些设置，复发时先回来复查。

## 三、同步条件与网络

- 账号设置里若开了「仅 Wi-Fi 同步」或「仅充电时同步」，移动网络下自然安静——按需调整；
- 安卓的「流量节省器」会限制后台流量，把邮件客户端加进不受限名单；
- 双开 / 工作资料里的应用受独立管理，别只改了主空间。

## 四、认证与账号侧

上面都正常还不来信，往账号侧查：开了两步验证的账号，第三方客户端要填的是「应用专用密码 / 授权码」而不是登录密码；QQ 邮箱、163 这类服务商对任何第三方客户端都要求授权码。改过主密码的（如 Apple 账号），旧的专用密码会被整体吊销，要重新生成。服务器连不上时逐字核对收发服务器主机名与端口。

## 五、一分钟验证法

下拉刷新确认能手动收信（排除服务器一侧问题）→ 回桌面等五分钟 → 让朋友发封测试邮件 → 通知到了就是修好了；打开应用才来信、退出去就断，说明推送仍被拦，回到第二节重来一遍。安装与配置上的其他问题，可以到 [FairEmail 介绍站](https://fairemail.fedq.ren/) 的下载安装页按步骤对照。
