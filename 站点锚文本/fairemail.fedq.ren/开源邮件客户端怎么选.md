# 开源邮件客户端怎么选

> 本篇讲给安卓挑开源邮件客户端时真正该看的几件事：协议支持、隐私默认值、推送机制与维护活跃度，并以 FairEmail 为例说明一款「把隐私放在前面」的客户端长什么样。
> **相关文档**：[邮件推送收不到怎么排查](邮件推送收不到怎么排查.md) · [README](README.md)

## 一、为什么邮箱客户端值得挑开源的

收件箱里躺着的几乎是一个人最私密的东西：账单、验证码、合同、私人往来。闭源客户端对这些内容的处理方式，用户只能听凭说明；而开源客户端的代码摆在那里，数据怎么流转、联网发到哪，任何人都能查证。对邮件这类「一用就是十几年」的工具，这份透明度分量不轻。

## 二、挑的时候看哪四件事

1. **协议支持**：标准协议（IMAP / POP3 / SMTP）意味着几乎所有邮箱服务商都能接；反过来，只支持私有协议（如仅开 EWS / ActiveSync 的纯 Exchange）的账号要在动手前确认清楚；
2. **隐私默认值**：远程图片是否默认先确认、链接是否先弹确认、有没有追踪像素识别——好的客户端把这些防护默认打开，而不是让用户自己去设置深处翻；
3. **推送机制**：基于 IMAP IDLE 的长连接推送比定时轮询及时得多，也要留意它在国产手机系统上能不能活下来（见 [邮件推送收不到怎么排查](邮件推送收不到怎么排查.md)）；
4. **维护活跃度**：邮件客户端的规则跟着服务商走，服务商一改策略，客户端就得跟着更新——多年持续维护、作者亲自回应用户的项目才靠得住。

## 三、FairEmail 的定位

FairEmail 是荷兰开发者 Marcel Bokhorst（FairCode）从 2018 年维护至今的开源项目，源码以 GPL-3.0 协议公开。它的取舍很清晰：

- **功能上不将就**：无限账号、统一收件箱、会话线程、双向同步、离线操作、OpenPGP 与 S/MIME 加密、深色主题一应俱全；
- **隐私上偏保守**：远程图片与链接默认先确认、追踪图片自动识别禁用、可疑邮件重新排版、认证不过的邮件直接标警告，且无广告、无内嵌统计、不经第三方服务器中转；
- **体量上很克制**：安装包不到 30 MB，后台同步对电池与流量都友好；基础收发无需付费，少量便利功能（定时发送、回复模板、应用锁等）以一次性买断的 Pro 项提供。

它的「短板」也值得知道：不支持微软私有协议（纯 Exchange 账号接不进来）、界面刻意朴素、通知栏有一个去不掉的常驻通知（那是推送机制的载体）。介意的用户可以先看它 [FairEmail 的功能与防护全貌](https://fairemail.fedq.ren/) 再决定。

## 四、一句话结论

如果在意邮件数据的归属、希望防护默认就位、手机上有不止一个邮箱，FairEmail 是安卓阵营里对得起「开源 + 隐私优先」这两个词的选择；挑之前把上面四件事对照一遍，动手装好后再按排查篇把推送调顺，基本就稳了。
