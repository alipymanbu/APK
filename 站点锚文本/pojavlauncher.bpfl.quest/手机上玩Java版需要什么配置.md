# 手机上玩 Java 版需要什么配置

> 想在安卓手机上跑 Minecraft Java 版，先看三个数：系统版本、内存大小、要玩的游戏版本。这篇把三者的对应关系与取舍讲清。
> **相关文档**：[模组和整合包怎么装](模组和整合包怎么装.md) · [闪退黑屏与联机报错排查](闪退黑屏与联机报错排查.md)

## 一、门槛其实分两层

第一层是**能不能装**：安装包可安装线普遍写在 Android 5.0 左右，近十年的机器基本都过线。真正的分水岭在第二层——**能玩哪个版本**。游戏版本越新，对内存、系统与图形接口的要求越高，同一台手机上新老版本的体验差距会非常大。

| 设备情况 | 建议起点 |
| --- | --- |
| 3 GB 内存及以下 | 1.8.9 / 1.12.2 等老版本 |
| 4 ~ 6 GB 内存 | 1.16 ~ 1.20 原版 |
| 8 GB 内存及以上 | 新版本或轻量模组包 |

老手机不必气馁：1.8.9 这类经典版本对硬件要求极低，玩起来的完整度与电脑版没有区别——世界机制、红石、命令方块都在，只是画面更新。

## 二、游戏版本与运行时的对应

Java 版按游戏版本对运行环境有硬性要求，启动器一般会自动选对，但手动改过设置之后就要自己核对：

| 游戏版本 | 所需运行时 |
| --- | --- |
| 1.16.5 及更早 | Java 8 |
| 1.17 ~ 1.20.4 | Java 17 |
| 1.20.5 / 1.21+ | Java 21 |

选错运行时的典型症状是进度条走完直接退回启动器——不是闪退报错，就是安安静静退回去。遇到这个现象先回来查这张表。

## 三、内存与渲染器怎么给

内存交给启动器的**自动分配**最省心；想手动调，给值别超过物理内存的一半，留出系统余量反而更稳。渲染器决定画面跑在哪种图形接口上：默认的 GL4ES 兼容面最广，老机型首选；新机型（较新的 Mali、Adreno 6xx/7xx）可以开基于 Vulkan 的 Zink；想玩 Sodium / Iris 光影就试 LTW。

卡顿的调整顺序也有讲究：先把游戏内渲染分辨率降一档（帧数回升最明显），再核对渲染器，最后才是开持续性能模式压制发热降频。三步都做完还不行的，基本就是版本与硬件不匹配，退一个游戏版本立竿见影。

具体到工具本身的功能盘点与获取方式，[PojavLauncher 介绍站](https://pojavlauncher.bpfl.quest/)里整理得更全；装好之后遇到启动问题，看[闪退黑屏与联机报错排查](闪退黑屏与联机报错排查.md)。
