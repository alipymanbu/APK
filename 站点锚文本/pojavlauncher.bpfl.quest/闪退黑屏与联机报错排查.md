# 闪退黑屏与联机报错排查

> 按症状对号入座：装不上、启动就退、进游戏黑屏、连不上服务器——先分层，再动手。
> **相关文档**：[手机上玩 Java 版需要什么配置](手机上玩Java版需要什么配置.md) · [模组和整合包怎么装](模组和整合包怎么装.md)

## 一、先分清是哪一层出的问题

排查前先定位层级，三层的处理方向完全不同：**安装层**（APK 装不上、点开就退）查安装包与系统版本；**启动器层**（能开启动器、下载或启动版本失败）查运行时、渲染器、内存与网络；**游戏层**（能进游戏、玩着玩着退）查内存、模组与发热。

## 二、启动与画面类

| 症状 | 多半是 | 处理 |
| --- | --- | --- |
| 进度条走完退回启动器 | 运行时与游戏版本不匹配 | 按版本对应表核对（1.17+ 要 Java 17、1.20.5+ 要 Java 21） |
| 新版本进去黑屏、有声音 | 渲染器不合适 | 换渲染器：GL4ES 黑屏就试 Zink / LTW，比反复重启有效 |
| 加载世界或生成地形时闪退 | 内存给少或给多 | 交给自动分配；手动值别超过物理内存一半 |
| 玩半小时越来越卡最后退出 | 发热降频 + 内存吃紧 | 开持续性能模式、调低游戏内分辨率、给手机散热 |
| 装模组后必闪退 | 版本不对齐或模组冲突 | 逐个移除定位问题；OptiFine 与 Sodium 不可共存 |

记住一条：闪退退回启动器不等于启动器崩了——游戏进程退出后本来就会回到启动器界面，要看的是报错关键词。另外渲染器、内存、运行时的改动，**重启该版本才生效**，原地重试没用。

## 三、账号与联机类

| 症状 | 多半是 | 处理 |
| --- | --- | --- |
| 登录报 404 | 账号未购买或未迁移 Java 版 | 换已购买的正版微软账号；本地账号只能单人与局域网 |
| 授权页成功却跳不回启动器 | 浏览器缓存或默认浏览器拦截 | 清缓存或换浏览器重试 |
| Invalid session / 验证失败 | 登录会话过期 | 删除账号重新登录再连 |
| 版本不匹配被拒 | 客户端与服务器版本不一致 | 回启动器换成服务器要求的版本 |
| 无法解析地址 | 地址或端口抄错 | 带/不带端口写法核对一遍，默认走 25565 |

进正版服务器只能用微软账号，本地（离线）账号会被校验挡在门外；反复验证失败还要核对一下系统时间是否自动同步。想玩更新的游戏版本而启动器层面确实跟不上时，可以去了解继任项目 Amethyst-Android。

## 四、彻底重来的一条路

版本反复坏掉时，不用重装整个启动器：删掉对应 Profile 的游戏目录（`games/PojavLauncher/.minecraft`）让它重新下载，往往更快。动手前记得把存档文件夹拷出来。

环境排查完了还慢的，回头把配置一档的思路再过一遍（见[手机上玩 Java 版需要什么配置](手机上玩Java版需要什么配置.md)）；工具本身的下载与安装步骤，[PojavLauncher 介绍站](https://pojavlauncher.bpfl.quest/)里写得直接。
