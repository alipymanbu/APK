# 模组和整合包怎么装

> 手机上装 Forge / Fabric 模组有两条路：内置安装器一键装，或者手动把 jar 文件放进 mods 文件夹。这篇把两条路和常见的坑一次讲完。
> **相关文档**：[手机上玩 Java 版需要什么配置](手机上玩Java版需要什么配置.md) · [闪退黑屏与联机报错排查](闪退黑屏与联机报错排查.md)

## 一、先看你的启动器支持哪条路

内置自动安装是 Edelweiss 及之后版本才有的能力：Forge / Fabric / Quilt / OptiFine 都能一键安装，整合包还能在启动器里直接搜索 CurseForge 和 Modrinth 的资源。更早的构建没有这套安装器，走手动方式即可，效果完全一样。

1.17 及以上的模组环境对运行环境与渲染器有额外要求：Sodium、Iris 这类优化与光影模组，建议用 Zink 或 LTW 渲染器跑；个别模组对 Java 版本敏感，装之前先核对游戏版本对应的运行时。

## 二、手动装模组（任何版本通用）

1. 先在启动器里选定目标游戏版本并**完整启动一次**，让游戏目录生成。
2. 用文件管理器打开游戏目录，默认在 `games/PojavLauncher/.minecraft`（给 Profile 单独设过目录的以 Profile 为准）。
3. 没有 `mods` 文件夹就新建一个，把模组 jar 文件直接拷进去。
4. 回到启动器重新启动该版本，加载时间明显变长属正常。
5. 进游戏看左下角版本标注或 Mods 列表，确认模组已加载。

Forge 手动装还需要先跑一遍 Forge 安装器（把安装包交给启动器执行），Fabric 装一个 loader 版本即可；安装器输出 `exited with code 0` 才算成功，之后版本列表里会多出带 Forge / Fabric 后缀的条目。

## 三、三个最容易踩的坑

- **三方版本要对齐**：模组版本、加载器版本、游戏版本必须一致，1.16.5 的模组放进 1.20.4 的 mods 文件夹，结果就是加载即退。
- **一次少加几个**：逐个添加再进游戏，出了问题才知道是哪一个；一把全塞进去，闪退了只能全拆重来。
- **OptiFine 与 Sodium 二选一**：两者同为优化模组，同时放必冲突；要光影就走 Sodium + Iris 组合，别混装。

整合包体积普遍不小，安装前先确认剩余空间；手动导入时把包里的 mods、resourcepacks、config 按同名文件夹对应摆放，CurseForge 包的实际文件多在 overrides 子目录里。装好模组后想检验成果，[PojavLauncher 介绍站](https://pojavlauncher.bpfl.quest/)有安装文件资源与功能盘点；进装了模组的服务器被踢出，先看[闪退黑屏与联机报错排查](闪退黑屏与联机报错排查.md)里的联机一节。
