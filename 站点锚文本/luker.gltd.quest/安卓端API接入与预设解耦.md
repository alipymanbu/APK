## 一、Luker 自己不带模型

它是一个聊天平台前端：你打的消息、角色卡的设定，由它组装成请求发给某个大语言模型服务，再把回复渲染成聊天界面。所以第一次用必须告诉它三件事——用哪家 API、地址是什么、密钥是什么。没有可用的连接，就没有对话，这一步绕不过去。

手里已有的东西决定走哪条路：

- 有 OpenAI / Claude / Gemini 的密钥，走「聊天补全」类连接，这是最常用的模式；
- 用各类中转站、聚合站，一般选「自定义 OpenAI 兼容 API」；
- 想省 API 费用，KoboldAI、Ollama 这类文本补全面向本地或自托管后端，让手机连它们的服务地址。

## 二、配一条能用的连接

操作路径很固定：点界面顶部的 API 连接图标 → 选 API 类型 → 填地址和密钥 → 测试连接 → 选一个具体模型。密钥的获取入口在各家自己的平台（如 OpenAI 平台、Anthropic 控制台、Google AI Studio、OpenRouter），注册后创建即可，各家计费口径以其页面为准。

还有一类容易被忽略的调用方：记忆图、多 Agent 编排这些内置工具自己也会调用模型，同样走连接配置。

## 三、连接管理器：把「日常」和「写长剧情」分开

连接管理器可以保存任意数量的配置，切换时在下拉列表里点一下就行，不用重新填地址和密钥。常见的分法：

- 日常闲聊挂一个便宜模型；
- 写长剧情时切到旗舰模型；
- 本地模型单独存一份；
- 给记忆图的写入与召回单独配一套便宜的，主聊天照常旗舰——长期跑剧情能省不少。

熟悉斜杠命令的话还有更快的写法：`/profile 名称` 直接切换，`/profile-list` 列出全部配置。

## 四、换模型，预设不动

这是相对原版酒馆使用习惯差别最大的地方：API 连接和聊天补全预设是分开的两套东西。连接决定「用哪个模型、走什么地址」，预设决定「提示词怎么写、采样参数是多少」。实际用起来意味着：

- 同一套调好的预设，可以在 OpenAI 和 Claude 之间来回切，对比同一剧情的输出差异；
- 同一个 API，配几套不同文风的预设，聊天里一键换风格。

两边自由组合，切换时不会再出现「换个模型，提示词配置被悄悄换掉」的情况。

## 五、连不上时的排查顺序

先看三处：密钥是否填错或多复制了空格、账户是否还有额度、模型名是否选对。还不行就打开内置的请求检查器，它能显示每次发给 API 的完整请求和返回内容，报错位置一目了然。至于从哪里拿安装包、怎么装上手机，[手机端酒馆替代方案.md](手机端酒馆替代方案.md) 里有完整的入口与步骤说明。
