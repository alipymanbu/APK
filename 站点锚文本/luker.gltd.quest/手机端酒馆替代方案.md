# 手机端酒馆替代方案：免 Termux 的 APK 一体化路线

> 想在安卓手机上玩 SillyTavern 生态的角色扮演聊天，过去绕不开 Termux。本篇把「为什么难」和「现在怎么装」一次讲清，并给出一条免终端的路线。
> **相关文档**：[SillyTavern数据迁移到手机.md](SillyTavern数据迁移到手机.md) · [安卓端API接入与预设解耦.md](安卓端API接入与预设解耦.md)

---

## 一、老路线到底麻烦在哪

SillyTavern 本体是一套跑在 Node.js 上的前端加后端，安卓上没有现成的安装包，社区常见的玩法是用 Termux 模拟一个 Linux 环境，再手动把服务拉起来。对不碰命令行的人来说，每一步都是坎：

1. 装 Termux，处理源与权限；
2. 在终端里 clone 仓库、等 npm install 跑完，Node 版本还得对得上；
3. 启动服务后用浏览器访问 localhost，端口转发一层套一层；
4. 手机一重启，整套服务重新拉起一遍。

这些步骤里没有一步和「聊天」本身有关，却决定了你能不能开始聊。

## 二、Luker 的解法：后端直接住进应用里

Luker 是基于 SillyTavern 深度重构的角色扮演聊天平台，它给安卓做了一个独立的 APK——后端整个跑在应用内部，一部手机同时充当服务端和界面。装上 APK、打开就是完整界面，不需要 Termux、不需要手动装 Node、不需要端口转发。

对这个项目做一次了解最快的入口是 [Luker 安卓版介绍站](https://luker.gltd.quest/)，上面有真实界面截图、与 SillyTavern 的兼容说明，以及从网盘分享拿安装包的安装步骤页。

几点使用前就该知道的事实：

- 它本身不带模型，聊天回复靠你接入的大语言模型 API（OpenAI、Claude、Gemini、OpenRouter 或本地 Ollama 都可以）；
- 软件本体按 AGPL-3.0 开源，费用来自模型 API 按量计费；
- 与 SillyTavern 的数据格式双向兼容，老数据能搬来也能搬回去。

## 三、装完之后的顺序

1. 首次启动的欢迎对话框里先把语言切到简体中文；
2. 老玩家在欢迎页走「Migrate from SillyTavern」，把角色卡、世界书、聊天记录搬进来，具体见 [SillyTavern数据迁移到手机.md](SillyTavern数据迁移到手机.md)；
3. 配一个能用的 API 连接，没有它发消息不会有任何回复，步骤见 [安卓端API接入与预设解耦.md](安卓端API接入与预设解耦.md)；
4. 选一张角色卡开聊，之后再用记忆图、多 Agent 编排这些进阶工具不迟。

从 Termux 折腾流换到 APK 一体化，省下来的不是十分钟安装时间，而是以后每一次「手机重启后服务没了」的重复劳动。
