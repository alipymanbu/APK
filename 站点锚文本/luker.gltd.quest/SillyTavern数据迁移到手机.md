# SillyTavern 数据迁移到手机：角色卡、世界书与聊天记录怎么搬

> 玩了几百楼攒下的角色卡、世界书和聊天记录，换到 Luker 要不要从头再来？不用。本篇讲清哪些数据能搬、从哪里搬、以及怎么给自己留退路。
> **相关文档**：[手机端酒馆替代方案.md](手机端酒馆替代方案.md) · [安卓端API接入与预设解耦.md](安卓端API接入与预设解耦.md)

---

## 一、先看兼容范围：是双向，不是单向导入

Luker 是 SillyTavern 的下游分支，保持数据格式层面的完全兼容。想清楚这一点，搬迁的心态会完全不同——这不是「搬家进新小区，旧钥匙作废」，而是两边随时可以来回走：

| 数据类型 | 兼容情况 |
| --- | --- |
| 角色卡（PNG / JSON） | 完全兼容，双向导入导出 |
| 世界书 / Lorebook | 完全兼容 |
| 聊天记录 | 完全兼容 |
| 聊天补全预设 | 完全兼容 |
| 第三方扩展 | 兼容 |
| 用户设置 | 完全兼容 |

Luker 新增的数据（记忆图节点、编排配置这类）放在独立的状态文件里，SillyTavern 会直接忽略它们——所以哪天想降级回去，核心数据不会被破坏。

## 二、从电脑或 Termux 搬过来

三个入口，按你的来路对号入座：

1. **备份 ZIP**：首次启动的欢迎页支持直接导入备份 ZIP，电脑上打包好的 `data/` 目录内容一次性进来，是最省事的一条路；
2. **欢迎页迁移入口**：欢迎对话框里的「Migrate from SillyTavern」区块负责引导迁移流程；
3. **Termux 特殊处理**：安卓沙箱互相隔离，Termux 目录下的数据没法被 APK 直接读，需要先经过共享存储（`/sdcard`）中转一次，再从应用里导入。

搬到手机后，记得配好 API 连接才算真正能用，见 [安卓端API接入与预设解耦.md](安卓端API接入与预设解耦.md)。

## 三、搬完之后的备份习惯

迁移完成不等于一劳永逸：

- 重装、换机之前，按数据类别导出备份，聊天记录和记忆图数据一起带走；
- 局域网同步可以把同一网络下的两台设备配对，聊天、角色卡、世界书、设置在两者之间保持一致，不需要把任何东西推到云上；
- 迁移动手前先备份一份原始数据——这条规矩在任何平台之间搬家都成立。

还在犹豫要不要换到手机端的，先看 [手机端酒馆替代方案.md](手机端酒馆替代方案.md)，那里把 Termux 路线和 APK 路线的差别摆在一起对比过了。
