# 想在手机上画像素画，App 怎么选

> 选触屏像素画应用，主要看四件事：像素级落笔、帧时间轴、洋葱皮、调色板。本篇把这四个标准讲清，再帮你把搜索结果里容易混的名字理顺。

## 一、触屏像素画的「四件套」

在手机小屏上做像素画，操作逻辑和平板、桌面完全不同，但核心工具是一样的小四套。挑应用时挨个对照：

| 标准 | 具体看什么 |
| --- | --- |
| 像素级落笔 | 能否放大到单格、手指或触控笔点下去是不是正好落在那一格 |
| 帧时间轴 | 多帧能不能平铺排列、复制帧、调整顺序 |
| 洋葱皮 | 画当前帧时，前后帧能不能以半透明影子显示 |
| 调色板 | 能不能先选出固定的一小把颜色再落笔，而不是随手取色 |

四个都占的应用不多。缺了时间轴就只能画静态图，缺了调色板画出来的颜色容易发散——如果你的目标是做游戏素材或表情包，前三个是硬门槛。

## 二、名字里的门道：别把两份「Aseprite」混成一谈

搜像素画应用，Aseprite 这个名字几乎绕不开。先说清楚：它最有名的是桌面版——Igara Studio 开发的付费桌面程序，装在 Windows、macOS、Linux 上，用键鼠操作。

而你想在**手机**上用的话，事情要分开讲：桌面版至今没有手机版，开发者公开表态过会优先维护桌面端；安卓上能装到的那份同名应用，是第三方针对触屏重做的版本，图层、逐帧动画、洋葱皮、调色板这些核心思路与桌面版同源，但界面和版本号各自独立。

动手之前先认清自己要装的是哪一份。这份安卓版的定位、版本情况与完整安装流程，在 [Aseprite 安卓版](https://aseprite.qhah.skin/) 里有一页式说明，先读它再决定装不装。

## 三、按需求对号入座

| 你的需求 | 先看什么 |
| --- | --- |
| 给独立游戏画角色和道具 | 帧时间轴 + 洋葱皮，缺一不可 |
| 做表情包、头像 | 像素级落笔 + 调色板，静态为主也够用 |
| 在通勤路上练手 | 手机端安装方便、打开就能画，安卓 5.2 以上的机子基本都能跑 |
| 认真学像素动画 | 手机练手感，桌面付费版补深度，两头不耽误 |

先想清楚自己画什么，再对照上表挑——比按「排行榜」下载一圈要省事得多。

装好之后从哪下手，看[洋葱皮逐帧动画入门.md](洋葱皮逐帧动画入门.md)；安装环节被系统拦住了，处理办法在[安卓APK安装被拦截怎么办.md](安卓APK安装被拦截怎么办.md)。
