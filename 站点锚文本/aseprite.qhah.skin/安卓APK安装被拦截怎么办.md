# APK 安装被拦截：先查未知来源授权

> 安卓装应用商店之外的 APK，十有八九卡在「未知来源」这道授权上。本篇按命中概率从高到低给排查路径，照着走一般两三分钟就能解决。
> **相关文档**：[手机上画像素画的App怎么选.md](手机上画像素画的App怎么选.md) · [洋葱皮逐帧动画入门.md](洋葱皮逐帧动画入门.md)

---

## 一、先明白拦截从哪来的

APK 直装不走应用商店，安卓默认不放行——系统要求你**手动给「负责下载的那个 App」授权**「安装未知应用」的资格，拦你的其实是这道门。授权对象不是文件本身，而是你用哪个 App 下载的 APK，就给哪个 App 开。

## 二、常见品牌的开关位置

各家设置入口埋得不一样，对号入座：

| 品牌 | 路径 |
| --- | --- |
| 小米 | 设置 → 更多设置 → 特殊权限 → 安装未知应用 |
| 华为 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| 其他品牌 | 设置里直接搜「未知来源」，一般都能搜到对应开关 |

给下载用的 App（浏览器或网盘 App）打开「允许安装」后，回到下载目录重新点 APK，就能正常进安装页了。

拿像素画应用来举例：装 [Aseprite 安卓版下载安装](https://aseprite.qhah.skin/) 这类 APK 直装的应用时，流程就是「网盘转存 → 下载 → 授权 → 安装」四步，其中卡住人的往往就是第三步的授权。

## 三、装上了却打不开，按这个顺序查

1. **提示「解析包时出现问题」**：文件没下完整，回网盘重新下载一遍再装；
2. **存储空间不足**：留意安装包本体之外还要留解压余量，给手机腾出 300 MB 以上比较稳；
3. **点开闪退**：先重启手机再试一次，再确认系统版本达到应用标注的要求（比如有的应用要求安卓 5.2 以上），最后卸载重装。

按顺序走完，绝大多数安装问题都能就地解决。装好之后画什么、怎么练，看[洋葱皮逐帧动画入门.md](洋葱皮逐帧动画入门.md)；还在挑应用的话，选型标准在[手机上画像素画的App怎么选.md](手机上画像素画的App怎么选.md)。
