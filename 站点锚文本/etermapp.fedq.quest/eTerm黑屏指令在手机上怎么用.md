# eTerm 黑屏指令在手机上怎么用

在桌面终端前干惯了出票的代理人，换到手机上最关心的不是界面好不好看，而是那套指令还在不在、怎么敲得快。这篇把这两件事说清楚，数据与功能口径以公开商店页和产品更新说明为准。

## 指令集没有因为屏幕变小而缩水

腾云（eTerm Clouds）的产品定位是「面向通用型代理人的移动版黑屏指令前端」，支持系统完整指令集——也就是查询、预订、出票用的还是桌面时代同一套语法。行业背景也印证了这个思路：据公开报道，中国航信已完成对境内 2600 余家代理人、超过 4 万台 Eterm 终端的关停切换，销售前端全面图形化，但图形化指的是前端形态，指令能力被保留进了新产品里。

常见的几类指令在手机上对应的用法：

- **AV 查航班**：语法与桌面端一致，后续版本还加了专门的 AV 快捷键，把最高频的一条查询压到一击；
- **SD 预订舱位**：图形界面里点选舱位时，后台执行的仍是这套指令逻辑；
- **NM / SSR 类**：录旅客姓名与证件信息，团队名单批量导入时会自动生成 SSR DOCS 等补充项，不用逐人手敲。

## 手机上敲得快，靠的是这几个输入辅助

按版本更新说明，App 在输入侧做的补偿主要有：

1. **快捷输入**：常用指令缩写，少敲字；
2. **自定义快捷指令**：把每天重复几十遍的指令存起来一键调出；
3. **历史指令记录**：翻回去重发，不用凭记忆重敲；
4. **黑屏引导操作**：对着界面学指令，新人也能逐步上手。

## 先确认权限，再谈效率

指令发出去提示无权限，多数不是敲错了，而是账号的权限组里没勾对应权限。腾云的账号分管理员与操作员两层：管理员建权限组并分配指令权限，操作员被审批后才能登录使用。所以换设备登录前，先确认账号状态与权限组配置，能省掉大半「登不上 / 发不出」的排查时间。

想系统了解这个工具的功能结构、订单模块与安装方式，可以看这个 [etermapp 介绍站](https://etermapp.fedq.quest/)，里面有按代理人工作动线整理的功能说明和安卓安装文件资源的获取入口。
