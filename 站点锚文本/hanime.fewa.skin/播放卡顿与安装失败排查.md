# 播放卡顿与安装失败排查

> 本篇汇总 Hanime 装不上、打不开、播放不顺这几类高频问题的排查顺序，多数情况从上往下照着试就能解决；安装的正常流程见 [安卓端安装与找番入口](安卓端安装与找番入口.md)，理顺之后想投屏或离线看，见 [投屏与离线缓存玩法](投屏与离线缓存玩法.md)。

## 一、装不上

| 现象 | 多半的原因 | 先做什么 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整 | 重新下载，核对体积约 23.84 MB |
| 提示「应用未安装」 | 存储不足或签名冲突 | 清出空间；装过同名应用先卸载旧的 |
| 点安装没反应 | 没开「安装未知应用」权限 | 给文件管理器或浏览器开权限再试 |

## 二、打不开或闪退

1. 从后台彻底划掉应用再打开，排除一次性的进程异常。
2. 到「设置 → 应用 → Hanime → 存储」清除缓存后再试。
3. 卸载后重新走一遍安装流程；旧版本可能有兼容问题。
4. 换一台安卓手机能正常用，基本就是原设备的兼容问题；系统太旧能升就升。

## 三、播放卡顿或加载慢

- **先换播放源**：详情页或播放页里换一条线路重新加载，比反复调画质更见效。
- **再降清晰度**：播放页里选低一档画质，加载明显变快，回到 Wi-Fi 再调上去。
- **腾出带宽**：关掉其他在下载、看视频的应用或设备。
- **清应用缓存**：缓存积多了也拖慢加载，按第二节第 2 条清一次。

## 四、搜得到但播不了

部分作品可能因版权因素无法播放或未收录，这不是故障：换一部能正常播的作品确认应用本身没问题即可，个别条目没字幕也是同理，不代表视频坏了。

## 五、都试过还没解决

把「做了什么操作、弹了什么提示、卡在哪一步」记下来，从安装环节完整重走一遍；涉及的版本判断以安装包实际登记为准，别拿网上搜到的其它版本当依据。整套用法的入口与找番路线，回 [安卓端安装与找番入口](安卓端安装与找番入口.md) 对照着看。
