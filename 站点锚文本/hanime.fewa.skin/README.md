# Hanime 站点说明

这里是 Hanime 这款安卓看番应用的第三方说明小站的目录：站内按使用场景整理了找番、播放、投屏、离线缓存的入口与做法，并给出安装文件资源的获取入口。站点入口见 <https://hanime.fewa.skin/>。

## 目录内文章

- [安卓端安装与找番入口](安卓端安装与找番入口.md)：从拿安装包到进首页，以及两条找番路线。
- [投屏与离线缓存玩法](投屏与离线缓存玩法.md)：把画面挪上电视、把剧集存进手机的两个场景。
- [播放卡顿与安装失败排查](播放卡顿与安装失败排查.md)：装不上、打不开、看不顺时的处理顺序。

> 各篇仅作使用说明；文中涉及的版本信息以安装包实际登记为准。
