# 加密聊天应用怎么选：五个可以量着看的维度

> 本篇不谈具体哪款"最好"，而是给一套挑选加密聊天应用的参考维度：加密口径、阅后即焚、多端同步、通话质量与上手门槛。并以 mchat 为例走一遍这些维度怎么对照。
> **相关文档**：[阅后即焚聊天怎么用.md](阅后即焚聊天怎么用.md)

## 一、五个维度，逐个对照

挑加密聊天应用，宣传语都差不多，差别藏在细节里。下面五个维度挨个问一遍，答案自然浮出来：

| 维度 | 该问的话 |
| --- | --- |
| 加密口径 | 是全量端到端加密，还是只有某个模式加密？密钥存在哪、服务器能不能解？ |
| 私密功能 | 有没有阅后即焚、防截屏这类细粒度控制？在普通会话里还是独立通道？ |
| 多端同步 | 手机之外能不能接着聊？加密会话参不参与同步（很多产品两者不可兼得）？ |
| 通话能力 | 语音视频走不走流量、弱网表现如何？通话内容在不在加密范围内？ |
| 上手门槛 | 对方也得装同一个应用吗？注册要不要手机号？界面是不是一看就会？ |

## 二、拿 mchat 走一遍

按上面五维对照 mchat，大致是这样一幅图：

- **加密口径**：私密聊天通道走端到端加密，密钥只在双方设备本地，服务器解不开；普通会话便于同步、不走这条通道；
- **私密功能**：阅后即焚、防截屏、禁止复制转发、头像打码，全部收在私密聊天通道里，从好友资料页发起；
- **多端同步**：普通会话支持多设备同步与离线消息补齐；私密会话不进云端——这是拿同步换保密的典型取舍；
- **通话能力**：语音视频通话走网络流量，不占运营商分钟数，公开介绍的口径是通话也在加密范围内；
- **上手门槛**：安卓 APK 安装包直接装，注册登录后即用；对方也得装同一应用，加密这条路才成立。

每一条的具体玩法与边界，[mchat 资料站](https://mchat.fwen.ren/)上有逐项展开的介绍页，配了真机截图，对照着看更直观。

## 三、两个常见误区

**误区一：加密 = 绝对保密。** 加密管的是传输路径上的第三方，管不住对面的人。对方截图、拍屏、转述，都不在任何加密的射程内；私密功能提高的是门槛，不是承诺。

**误区二：同步越全越好。** 云端同步方便，但意味着内容有副本在云端；纯本地加密保密性好，代价是换机即失。mchat 的做法是按会话类型分开处理——日常走同步、密聊走本地，两者各管各的场景，选型时想清楚自己更常发哪类内容就行。

## 四、落回一句话

没有"最好"的加密聊天应用，只有跟使用习惯对不对得上的。五个维度里挑你最在乎的两三条优先满足，其余接受取舍——这套办法比盯着单一卖点挑，踩坑少得多。选定了想先试试 mchat 的，从[阅后即焚聊天怎么用.md](阅后即焚聊天怎么用.md)看起最顺。
