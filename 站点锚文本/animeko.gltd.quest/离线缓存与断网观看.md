# Animeko 离线缓存与断网观看

> 缓存是 Animeko 里最实用也最容易踩坑的一项：能让你没网也照样看，但缓存在哪、什么时候会丢，值得提前弄清楚。
> **相关文章**：[安卓版怎么装.md](安卓版怎么装.md) · [弹幕不显示怎么排查.md](弹幕不显示怎么排查.md)

Animeko 的全部数据源都支持缓存——BT 源和在线源都能存到本地，断网后还能播放已缓存的剧集。通勤、出差、网络不稳的场景下，这是比「在线硬撑」靠谱得多的路子。

## 一、什么场景值得缓存

| 场景 | 建议 |
| --- | --- |
| 通勤、地铁上没有稳定网络 | 出门前把要看的集数缓存好 |
| 冷门老番、BT 做种少 | 能下就早点下，比播放时干等靠谱 |
| 在线源在你所在的网络里不稳定 | 缓存后不再依赖当时的连通性 |
| 只是随便看看 | 不必缓存，直接播更省空间 |

## 二、缓存时注意两点

1. **缓存的是当前选中的那条源**。源不同，画质与字幕组不同，缓存下来的东西也不同——选好源再缓。
2. **把弹幕一起缓存**。开着「自动缓存弹幕」，离线播放才有弹幕看；只缓视频的话，断网时画面是光秃秃的。

## 三、缓存放哪、会不会丢

缓存在本机存储里，属于应用数据，**不跟着账号走**：换设备、清除应用数据、卸载重装都会丢。空间上随缓存集数线性增长，长番整季缓下来占几个 GB 很常见，手机存储紧张时要提前取舍。

还有一条要提前知道的：**缓存引擎在 v5.3.1 做过重构，那次更新导致旧缓存失效**。所以升级版本前先想清楚手上有多少缓存，值不值得先看完再升；也不要把缓存当长期存档——想长期保留的片子，自己另存一份更稳妥。

## 四、断网后能做什么

- 已缓存的剧集可以正常播放，没缓存的播不了；
- 观看进度可能先留在本机，等有网了再对上 Bangumi 账号；
- 登录态过期需要联网刷新，离线状态下不会自动恢复。

空间不够时优先清已经看完的集数——清理是破坏性操作，冷门老番清掉之后可能很难再下回来，删之前确认这部还下得动。
