# 手机远程控制电脑任务怎么用

> 人离开工位后，用 Qoder CN 手机版接着盯电脑上正在跑的任务：扫码连接、审批放行、回答提问、追加指令，四件事的完整链路都在这篇。

---

## 一、先理解这条链路的分工

远程控制延伸的是**电脑上已经在跑的任务**：电脑端（Qoder CN 桌面应用或 CLI）开着任务，手机端登录同一账号后实时看进度，在需要确认的节点点批准或拒绝，产物文件仍然保存在电脑上。手机负责指挥，电脑负责干活。

三个前提，缺一条就连不上：

1. 电脑开机、任务进程活着（睡眠或关机，连接就断）；
2. 手机与电脑端登录**同一个账号**；
3. 两端都能正常访问网络（公司内网拦截时，最省事的判断是切手机流量对比）。

## 二、扫码连接的两种方式

**会话内连接**：电脑终端里正在运行的 `qodercn` 会话中输入 `/remote-control`，屏幕给出二维码和 URL，手机相机扫码或把 URL 复制到手机浏览器打开，会话列表里就会出现这个已连接的会话。断开用 `/remote-control stop`，查状态用 `/remote-control status`。

**守护模式**：打算让电脑挂着待命、人在外面随时派活时，在项目目录直接跑 `qodercn remote-control`，同样扫码连接。之后在手机上点「+」新建任务即可，不用等上一个任务做完，CLI 会顺序或并行处理，生成的文件都在跑 CLI 的那台电脑上。

## 三、手机上真正常用的四个动作

| 动作 | 什么时候用 |
|---|---|
| 看进度 | 智能体活动自动生成任务摘要，长任务不用翻记录 |
| 批准 / 拒绝 | 要改文件、要跑命令，任务停在等你点头的节点 |
| 回答提问 | 它向你确认细节，回一句它就继续 |
| 追加指令 | 跑到一半想改需求，直接补一句话 |

开着 Plan 模式时，执行前的方案也能先在手机上过一眼，确认方向没问题再放行。

## 四、连不上时先查什么

按命中率排序：账号不一致（两端登的不是同一个号）→ 产品系列装混（国内版与国际版数据互不相通，认准包名带 `cn` 的安装包）→ 电脑端没开远程监听 → 电脑睡眠或断网。审批点了没反应时，先下拉刷新再重进会话，仍停在旧状态就到电脑上看 CLI 的实际状态。

更多界面截图与安装包获取入口，见 [Qoder CN 手机版](https://www.fewz.tech/)；电脑不在身边时怎么让任务继续跑，看[云端任务怎么发起](云端任务怎么发起.md)。
