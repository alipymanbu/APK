# 自定义EQ与降噪设置

连上设备只是第一步，声音好不好听、降噪深不深，都在应用里调。本篇按设备类型把 EQ、HearID、降噪档位这几个最常用的设置项讲清楚，路径以 Android 端 3.8.4 版为基准，商店新版界面有重构但入口逻辑一致。

安卓端还没装好的，去 [soundcore 应用安装包获取站](https://soundcore.bmww.store/) 拿资源，装好回来接着调。

## 一、EQ 与音效

### 预设先试一遍

音箱与耳机类机型都内置预设，常见的几档：

| 预设 | 听感取向 |
| --- | --- |
| Signature | 标准均衡调音，不知道选什么先用它 |
| BassUp | 实时增强低频，电子乐、嘻哈听感更带劲 |
| Voice | 人声更突出，播客、脱口秀友好 |
| Treble Boost | 高频增强，弦乐与细节更亮 |
| Balance | 高低频都不动，原味输出 |

### 自定义曲线怎么画

进 应用内 Equalizer → Custom → Full-Band，点任意频点展开频段，长按拖动调整；改完的曲线就是该设备记录的调音。注意两点：

- 未登录账号时这份配置不随账号保存，换机即失，想保留就注册登录；
- EQ 只作用于音乐、视频、播客等媒体播放，通话音质不受它影响，通话问题去查降噪与网络。

### HearID：按你的耳朵生成曲线

部分耳机机型（P31i、R60i NC 等）带 HearID 听感测试：按提示听几组提示音，应用根据你的听感反馈生成专属曲线，不想手动拖频点的话这是最省事的路径。

## 二、降噪与环境音

耳机类机型的三档切换是主干功能：

- **降噪**：屏蔽环境低频噪声，通勤与办公常用；
- **普通**：不处理环境声，自然听感；
- **透明**：放大周围人声，戴机聊天、听报站不用摘耳机。

部分机型把降噪做成分场景调优（交通 / 户外 / 室内），自适应机型则会按眼镜、头发、佩戴密封度实时补偿。耳机本体按键默认只在档位间循环，想改映射进设备页的触控自定义里改。

## 三、LDAC 高音质模式（仅安卓）

支持机型（Motion X500/X600、AeroFit Pro 等）可以这样切：

1. 应用首页右上角进「设置」；
2. 选「声音模式（Sound mode）」；
3. 选「音质优先（Audio quality priority）」切到 LDAC。

三条限制：需要 Android 8.0 以上；切换耗时约十秒，旧固件会提示先升级；LDAC 更耗电，干扰少的环境下连接更稳。

## 四、几个实用小项

- 佩戴测试：入耳式机型在应用内运行，密封不良会直接拖累降噪和低频；
- 查找耳机：开启后丢失的耳机会发出较大声音；
- 游戏模式：Life P3 等机型可开，降低手游音画延迟；
- 双设备连接：设置 → 双连接开启后可同时挂两台手机。
