# 耳机扫不到设备排查思路

声阔的配套应用 soundcore 装好了，打开「添加设备」却怎么也扫不到耳机——这种十有八九不是设备坏了，而是下面几件事没按顺序做。本篇把卡点按出现频率排出来，逐条对号入座。

更完整的应用功能说明与安装包入口，见 [soundcore 应用整理站](https://soundcore.bmww.store/)。

## 一、先看位置权限

安卓 6.0 及以上系统，扫描蓝牙设备必须先开定位服务，这是平台机制而不是应用故障：

1. 首次进入应用时的位置权限弹窗要选「允许」；
2. 当时点了拒绝的，不用卸载重装，去 设置 → 应用管理 → 应用权限 → 位置，改成「仅在使用中允许」；
3. 改完重开应用再扫一次。

iOS 端路径：设置 → 隐私与安全性 → 对应应用 → 位置 → 使用 App 期间。

## 二、配对顺序别颠倒

正确顺序是「先系统蓝牙、后应用」：

1. 在系统蓝牙设置里把耳机/音箱与手机完成首次配对；
2. 确认蓝牙列表里这台设备处于已连接状态；
3. 再打开应用，点左侧页面的「添加设备」，等自动扫描认领；
4. 自动识别失败时走「手动设置」，按系列名 → 具体型号逐级选。

跳过第一步直接在应用里找设备，是新手最容易踩的坑。

## 三、干扰源清一清

- 手机上还连着其他蓝牙设备（手表、另一副耳机）时，先断开再扫描；
- iPhone 正在通话中，应用可能连不上设备，结束通话再试；
- 距离别太远，扫描时让设备贴近手机。

## 四、第一次连上了，之后连不上

这种「隔天失联」先查双连接状态：

- 设备的连接可能被另一台手机的后台应用占着——把那台手机上的应用彻底关掉，再用本机连；
- 只有手机一部的，重启设备再试，还是不行换一台设备连，用来区分是设备问题还是手机问题。

## 五、以上全做过还是不行

- 升级应用到商店最新版：较新的机型不在旧版本的设备列表里，3.8.4 这类老版本尤其明显；
- 手动添加列表里也找不到型号的，把「手动设置」页面截图，连同手机型号、应用版本一起发给售后核对；
- 系统区域设置会影响设备列表显示，海外渠道的说明建议切到 English (United States) 再试。

调音与降噪相关的设置项，另见 [自定义EQ与降噪设置](自定义EQ与降噪设置.md)；设备连上之后想更新固件，流程在 [固件更新与升级卸载](固件更新与升级卸载.md)。
