# 手机怎么把画面投到电视上

> 家里电视插着投屏接收器、手机也装好了应用，但打开一看入口不止一个——这篇按「你当下要做的事」把几条投屏路径拆开讲，看完就知道该点哪个。

## 先分清两条大路：镜像还是推送

手机画面上电视，本质只有两种玩法：

- **镜像**：电视上实时复刻手机屏幕，你看到什么电视放什么。适合演示操作、打游戏、看没有投屏按钮的应用。
- **推送（串流）**：手机只负责「下指令」，播放交给电视那头的设备。推送完成后手机可以锁屏、聊微信、干别的。适合放照片、追剧。

选错大路是很多人觉得「投屏不好用」的根源——想一边投屏一边用手机，却用了镜像；想放个视频找声音，却点了不带声音的镜像入口。

## 五条常见路径，按场景对号入座

| 你要做的事 | 走哪条 | 备注 |
| --- | --- | --- |
| 看视频、打游戏，要声音 | 手机控制中心的投屏开关（走 Miracast） | 点对点直连，投屏期间手机会暂时离开家里 Wi-Fi，属正常 |
| iPhone / iPad / Mac | 控制中心里的「屏幕镜像」 | 系统自带入口，与接收端连同一个 Wi-Fi 即可 |
| 演示某个应用怎么操作 | 投屏应用顶栏的镜像图标 | 最快的一条路，但这条路径传输的是无声画面 |
| 放手机里存的照片、视频 | 应用内的媒体入口 | 声音完整，投屏中手机照常可用 |
| 视频平台里追剧 | 播放器角落的「投电视」图标 | 需要 App 和接收端都支持 DLNA |

同一套设备之所以要留这么多入口，是因为各条路走的协议不同：Miracast、DLNA、EZAir（苹果专用）各管一段，应用内的镜像和串流又是两条独立通道。写法上一目了然的对照，可以看 [EZCast 投屏参考](https://ezcast.hfdk.space/) 整理的入口选择页。

## 三个容易踩的坑

1. **投出去没声音**：先回头看你点的入口——应用内镜像本身不带声音，换控制中心的投屏开关（Miracast）就有声音了。
2. **投屏时家里 Wi-Fi 掉了**：走 Miracast 镜像时手机与接收端点对点直连，会主动断开路由器，投完自动回来，不是故障。
3. **带 DRM 的内容投不出**：部分流媒体平台受版权保护限制，直接串流会被拒；换成镜像方式显示是可行的替代路径。
