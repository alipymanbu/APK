# 听书锁屏就停？这几类问题按现象自己排查

> 听书用着用着出了状况：锁屏后声音没了、书导不进去、手机和电脑进度对不上。本篇按现象给判断思路和操作步骤，多数情况不用求人。
> **相关文档**：[把EPUB和PDF变成有声书的听书工具.md](把EPUB和PDF变成有声书的听书工具.md)

---

## 一、锁屏或切后台后，朗读停了

这是被系统省电策略拦的，不是应用坏了。思路是把听书应用加入电池优化白名单、允许后台运行，各品牌手机的入口大致如下（系统更新后名称可能略有变化）：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / Redmi | 设置 → 应用设置 → 应用管理 → 找到应用 → 省电策略 → 无限制 |
| 华为 / 荣耀 | 设置 → 应用 → 应用启动管理 → 关闭「自动管理」，允许后台活动 |
| OPPO / 一加 | 设置 → 电池 → 应用耗电管理 → 允许完全后台行为 |
| vivo / iQOO | 设置 → 电池 → 后台功耗管理 → 允许后台高耗电 |
| 三星 | 设置 → 电池 → 后台使用限制，把应用移出休眠列表 |

另外两种"听起来不对劲"的情况顺手一起说：语速忽快忽慢先检查是不是手动调过倍率，再换音色对比；生僻词、人名读错是语音合成的常见局限，换音色效果差异最明显。

## 二、书导不进去

按顺序核对：

1. **格式在不在支持列表里**——EPUB、PDF、TXT、MOBI、DOCX 这类主流格式一般没问题，冷门格式先查说明；
2. **文件本身是否完好**——大小是否为零、电脑上能否正常打开，传输中损坏的文件重新传一遍；
3. **是不是版权保护的书**——从商店购买并绑定账号的文件通常无法被第三方阅读器处理，换没有保护的版本；
4. **扫描版 PDF**——本质是图片，能否读出文字取决于版本有没有文字识别能力，识别不出来就找文字版替代；
5. **大文件转换失败**——清理后台重试一次，仍失败就确认应用是不是该更新了。

## 三、手机和电脑进度对不上

- 两端必须登录**同一个账号**——只用手机单机听书的可以不登录，跨设备同步绕不开这一步；
- 同步不及时先手动刷新网页端，等十几秒再看；
- 手机端网络异常时同步会静默失败，确认联网状态后重试；
- 实在急用，手动翻到大体位置先接着听，偶发的延迟隔天再看多半已经对齐了。

## 四、装错了同名应用，越用越不对劲

应用市场上叫 Readify 的不止一款，专注训练类、PDF 工具类里都有同名的。判断装没装对，看包名就行：这款听书阅读器的包名是 `com.readin.app`，在系统设置的「应用管理」里能查到。

还没装、或者想了解它的收听场景和音色清单，可以看 [Readify 听书阅读器](https://readify.usea.quest/) 的介绍页；安装环节出问题的处理办法也整理在那里。
