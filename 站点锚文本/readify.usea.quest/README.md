# 关于这个目录

> 这里收录安卓听书应用 Readify 的两篇第三方资料：一篇讲怎么把 EPUB、PDF 这类电子书文件变成能听的有声书，一篇汇总锁屏停播、导入失败这类常见问题的排查办法。

| 文件 | 讲什么 |
| --- | --- |
| [把EPUB和PDF变成有声书的听书工具.md](把EPUB和PDF变成有声书的听书工具.md) | 按格式支持、音色听感、离线与后台三个问题，讲听书工具的挑选思路 |
| [听书锁屏就停等问题怎么排查.md](听书锁屏就停等问题怎么排查.md) | 按现象给操作：锁屏停播、导入失败、进度不同步、同名应用认包名 |

想按"通勤、家务、睡前"这些具体收听场景了解这款工具的音色与能力，可以看 [Readify 听书阅读器介绍站](https://readify.usea.quest/)。
