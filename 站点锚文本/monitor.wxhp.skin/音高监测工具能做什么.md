# 音高监测工具能做什么：把声音变成看得见的曲线

> 本篇讲音高监测（pitch monitor）这类工具的原理与用途：为什么把音高画成曲线就能帮到练唱、调音和声音训练，以及挑选时该看哪些能力。
> **相关文档**：[唱歌练音准怎么自我检查.md](唱歌练音准怎么自我检查.md) · [声音训练的实时反馈怎么用.md](声音训练的实时反馈怎么用.md)

---

## 一、它解决的根本问题：自己听自己不可靠

自己唱的时候，骨传导和听觉习惯会 masking 掉很多偏差——「感觉还行」和「真的唱准了」之间差着一整个八度的自我宽容。音高监测工具把这件事交给眼睛：麦克风收到什么音，屏幕上实时画出什么曲线，横轴是时间、纵轴是音阶，唱到哪个音、稳不稳、滑没滑，图上一目了然。

## 二、这类工具的四个典型用途

1. **唱歌练音准**：拖一个长音，看曲线是否接近水平直线；波动的幅度就是音准不稳的程度；
2. **滑音与转音检查**：曲线的走向就是滑音方向，斜得越陡滑得越快，转音有没有落在目标音上一眼可见；
3. **乐器单音核对**：当简易调音器用，对着麦克风给一个单音，读它判定的音名，怀疑不准就先给一个已知基准（如钢琴 A4 = 440Hz）校验；
4. **音域自测**：从最低音慢慢滑到最高音，曲线走过的上下两端就是当下的大致音域。

## 三、挑这类工具看什么

| 能力 | 为什么重要 |
| --- | --- |
| 实时性 | 曲线要跟着声音即时动，延迟高了反馈就没意义 |
| 音域范围 | 覆盖 C1~B7 七个八度，低音到高音都不出尺 |
| 单音检测的诚实说明 | 混着伴奏或多声部时判不准是原理限制，明说的更可信 |
| 录音回放 | 当场看不完的，录下来事后对照 |
| 校准选项 | A4 = 440Hz 可调，配合别的乐器不至于差半音 |

## 四、安卓上现成的选择

安卓平台常见的选择是 Vocal Pitch Monitor：黑底黄线的实时音高图，七个八度标尺、调音器、3 分钟录音回放、音阶与音符颜色自定义都有，体积极小、无需注册。想直接上手，可以从 [monitor 音高监测介绍站](https://monitor.wxhp.skin/) 看它的完整功能说明与安装入口；读图口径与练习方法在[唱歌练音准怎么自我检查](唱歌练音准怎么自我检查.md)一篇里展开。

## 五、先用起来再谈精度

初学阶段不必纠结半音级的误差——先把「曲线平不平」「落在哪一行」这两个读法练熟，音准概念就有了抓手。等能稳定读图，再考虑校准、换调标尺这些进阶设置。
