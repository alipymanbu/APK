# 安卓安装步骤与常见问题

> 本篇讲 SuperAI 安卓版怎么装：安装包参数、四步安装流程，以及装不上、闪退这几类问题怎么排查。
> **同目录其他文章**：[图生视频怎么把照片动起来.md](图生视频怎么把照片动起来.md) · [ai剧情带货视频怎么制作.md](ai剧情带货视频怎么制作.md)

## 一、装之前先核参数

第三方应用商店收录的安卓安装包信息如下（与 iOS 版本号不同步属常态，以安装包实际为准）：

| 项目 | 信息 |
| --- | --- |
| 版本 | 6.1.0 |
| 安装包大小 | 约 227MB |
| 系统要求 | 安卓 5.2 以上 |
| 界面语言 | 简体中文 |
| 包名 | `com.chatai.superai` |

同名应用很多，装完在「设置 → 应用管理」里搜上面这个包名，能对上才是本系列文章介绍的这一款。

## 二、四步装完

1. **拿安装包**：从网盘分享页把 APK 转存到自己的账号再下载，227MB 的大文件中途断流容易损坏，连 Wi-Fi 操作更稳；
2. **放行未知来源**：首次点开 APK 时系统会拦一道，按提示允许当前浏览器或文件管理器的「安装未知应用」权限，再返回重试；
3. **安装并核对**：点「安装」等它跑完，按第一节说的用包名核对一遍；
4. **首次启动**：同意用户协议与隐私政策，授予存储等必要权限，进首页后先去「灵感」页挑一条生成量高的模板试跑全流程。

用 iPhone 的不用走这一套：应用在 App Store 有上架，搜 SuperAI 安装即可，iOS 侧要求 iOS 13.0 以上、安装包约 201MB，功能随版本略有差异。

## 三、装不上 / 闪退怎么排查

- **安装失败**：九成是包不完整，回网盘重新下载；之前装过旧版的，先卸载再装，注意先备份应用内数据；
- **打开闪退**：依次确认系统版本达到 5.2 以上、剩余存储充足、存储与网络权限没被拒绝；都正常还闪退，多半是机型兼容问题，通过应用内「个人中心」的联系入口反馈，附上机型与系统版本；
- **界面和文章对不上**：功能入口随版本增减，用现有功能跑通「选模板 → 给素材 → 等成片」即可，不必纠结入口名称差异。
