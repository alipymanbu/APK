# 尺规作图在手机上预演：三组练习

> 本篇把三组常见的尺规类作图整理成手机上的预演练习：平行四边形骨架、内切圆、外接圆。先在画板上拖一遍再动笔，作图思路会清楚很多。入门路径与软件挑选见相关篇目。

## 一、为什么先在画板上练一遍

尺规作图题最怕的是「画到一半发现思路不对」。铅笔稿涂改麻烦，而画板上的对象都能撤销、能隐藏、能拖动——同一道题可以连试三种构造思路，挑顺手的那个落到作业本上。

开工前建议先把标注改成 New Points Only（做法见[动态几何画板入门](动态几何画板入门.md)第二节），否则辅助线一多，画面很难辨认。下述工具名以应用内显示为准，个别版本措辞略有出入；应用的下载入口见文末。

## 二、练习一：平行四边形骨架

构造思路：先画两条相邻边所在的直线，再分别过对面的点作这两条线的平行线，四条线围出的交点就是第四个顶点。

1. **直线工具**点两次，作出直线 AB；
2. 再用直线工具，先点已有的点 B、再点一下空白处生成点 C，作出直线 BC；
3. **平行线工具**：先点直线 AB，再点点 C——过 C 平行于 AB 的直线出现；
4. 重复平行线工具：点直线 BC，再点点 A；
5. **交点工具**点两条新平行线的交点，得到点 D；
6. **多边形工具**依次点 A、B、C、D，最后再点一次 A 封口。

注意第 3、4 步的顺序：**先选参照直线，再选通过的点**，反过来工具不响应。

收尾用「显示/隐藏对象」把四条辅助直线藏掉，再用角度工具点一下多边形，四个内角度数标出来——拖动任意顶点，对边始终等长、对角始终相等。

## 三、练习二：三角形的外接圆

1. **多边形工具**画一个三角形；
2. 展开**中垂线**工具，对三条边各作一条中垂线；
3. **交点工具**取三条中垂线的交点（外心）；
4. **圆工具**选「圆心与过圆上一点」：先点外心，再点任一顶点。

红圆应恰好穿过三个顶点。拖动顶点观察：三角形变成钝角三角形时，外心跑到三角形外面去了——这个现象纸上很难注意到，画板上一眼就看懂。

## 四、练习三：三角形的内切圆

1. 同样先画三角形；
2. 展开**角平分线**工具，作出任意两个角的平分线，取交点（内心）；
3. 过内心向任一边作**垂线**得垂足；
4. 以内心为圆心、内心到垂足的距离为半径画圆。

与练习二对照着拖：外心可能跑出三角形，内心永远在里面。两类「心」的位置规律，一次练习就记住了。

## 五、验证性质的两个小技巧

- **显示数值**：点选边，在属性里打开「显示值」，长度就标在图上，拖动时实时刷新；
- **构造步骤回放**：作图过程的每一步都被记录，可以逐步回放，检查哪一步出了问题，或者讲给别人听。
