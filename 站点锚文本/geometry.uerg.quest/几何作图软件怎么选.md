# 几何作图软件怎么选：Geometry、Graphing 与全家桶

> GeoGebra 按用途拆成了多款免费应用，第一次挑很容易装混。本篇按「想做什么」给出口径：只画平面几何选哪个、画函数选哪个、什么时候才需要全家桶。入门路径与作图练习在相关篇目。
> **相关文档**：[动态几何画板入门](动态几何画板入门.md) · [尺规作图手机练习](尺规作图手机练习.md)

## 一、家族一览

| 应用 | 强项 | 适合 |
| --- | --- | --- |
| Geometry | 几何构造：点线圆、多边形、变换、轨迹、圆锥曲线 | 平面几何学习与演示 |
| Graphing | 函数图像与方程 | 代数、函数学习 |
| Calculator Suite | 前两者加 3D、CAS、概率、电子表格 | 想一个应用全搞定 |
| 3D Calculator | 空间图形 | 立体几何 |
| Scientific / CAS | 数值计算 / 符号运算 | 对应的计算需求 |

各款都免费，包名互不相同，可以并存于同一部手机，装错款不冲突、按需补装即可。

## 二、按场景挑

- **初中、高中平面几何**（全等相似、圆、圆锥曲线）：选 **Geometry**。度量、变换、轨迹、构造步骤回放都是为这类场景准备的；
- **函数、不等式、图像分析**：选 **Graphing**，键入表达式立刻出图，特殊点（零点、极值、交点）直接读出；
- **既要几何又要函数，还想碰 3D**：直接上 **Calculator Suite**，代价是体积更大、界面项更多；
- **教材或老师指定了哪款**：按指定的装，交作业时界面一致省去很多解释。

拿不准就从 Geometry 开始——它的工具组最收敛，第一周最容易上手；缺什么再补对应款，本篇末尾给了 Geometry 的介绍站入口。

## 三、考试模式是怎么回事

各款应用内置考试模式（Exam Mode）：启动后锁定设备，不能切出去用其他应用或联网，同时保留作图与计算能力。它面向有监考要求的场景，是否允许使用、用哪一款，以当地考试规定与老师的要求为准；平时自己练习不需要碰它。
