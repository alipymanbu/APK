# 提取已装应用为APK的方法

> 想把手机里某个应用留一份安装包——商店下架前存底、发给别人、换机前带走，用的都是同一套操作。
> **相关文档**：[安卓应用管理工具能做什么](安卓应用管理工具能做什么.md) · [分体APKS安装包怎么装](分体APKS安装包怎么装.md)

安卓手机上「已装的应用」本身就是一份文件，只要有工具把它取出来就行。下面以 Skit 为例，讲具体怎么点、文件存在哪、批量怎么做。

## 一、提取单个应用的步骤

1. 打开工具，在应用列表里找到目标应用（用户应用与系统应用都支持，找系统记得切分类）；
2. 点进应用详情，再点右下角的功能按钮；
3. 选「提取」，文件会存进手机内部存储的 `Skit` 文件夹；选「分享」则直接调起系统分享面板；
4. 提取完用文件管理器打开对应文件夹确认文件在。

免费层级一次只能提取一个应用；批量提取与批量卸载属于 Premium（一次性买断的独立应用）。基础版与付费版的差异在 Skit 介绍站上有完整说明，见 [Skit 应用管理工具介绍](https://skit.fewf.click/)。

## 二、导出的是 .apk 还是 .apks

取决于目标应用的打包方式：

- 老式单包应用 → 导出 `.apk`，谁都能直接装；
- 用 App Bundle 分发的新应用（2021 年起商店新应用与更新的主流）→ 导出 `.apks` 分体包，系统自带安装器打不开。

拿到 `.apks` 不是出错了，只是格式不同；怎么装回手机在 [分体APKS安装包怎么装](分体APKS安装包怎么装.md) 里单独讲。

## 三、系统应用能不能提取

能，而且不需要 root。但要注意：导出的系统应用 APK 换到别的手机、别的系统版本上很可能装不上——系统应用常依赖所在系统的私有接口与预置环境。它只是「在本机可导出」，不等于「到哪都能装」，当本机备份看待最合适。

## 四、顺手导一份应用清单

除了逐个提取，还可以把「装了什么」整体记一笔：Apps List 功能一键生成 JSON 清单，除应用名与包名外还带体积、最后更新时间、SDK 版本等字段，文本编辑器直接能读。换机前先出清单再逐个提取，是最稳的顺序。

## 五、提取件的几个注意点

- 同一应用重复提取会再生成文件，旧的不会自动清，定期整理一下文件夹即可；
- APK 只有程序本体，聊天记录、账号登录这类应用内数据不在里面；
- 想跨机型搬运用户应用时，注意 CPU 架构与分片是否匹配，装不上多半是缺分片。
