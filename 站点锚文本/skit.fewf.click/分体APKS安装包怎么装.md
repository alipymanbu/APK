# 分体APKS安装包怎么装

> 从朋友那里或网上拿到一个 .apks / .apkm / .xapk 文件，点开装不上、提示解析错误——问题不在文件坏了，而是格式不认。
> **相关文档**：[提取已装应用为APK的方法](提取已装应用为APK的方法.md) · [安卓应用管理工具能做什么](安卓应用管理工具能做什么.md)

## 一、为什么系统装不了分体包

2018 年起安卓引入 App Bundle：开发者上传的不再是单个大 APK，而是「基础包 + 按屏幕密度、CPU 架构、语言拆开的分片」，商店下载时按你的设备挑分片拼装。这套东西在本地拼好后可以打包成单个文件分发，社区把它命名为 `.apks`；`.apkm`、`.xapk` 是类似的多分片打包格式。

它们不是损坏的 APK，只是「一袋 APK」。系统自带安装器只认单个 `.apk`，直接点开就报解析错误——这不是文件的问题，是格式的问题。

## 二、用 Skit 装回去

Skit 3.0 起内置分体包安装器，3.3 起还能从其他应用直接调起。两种进法：

**方式 A：从文件管理器调起**

1. 文件管理器里找到分体包文件；
2. 点开 → 选择用 Skit 打开；
3. 解析包内容后按提示确认安装。首次这样做，系统会要求允许「安装未知应用」，授权一次即可。

**方式 B：在应用内安装**

1. 打开 Skit，在工具入口里找到安装器；
2. 浏览到分体包所在目录（外部存储的下载目录都在列表里）；
3. 选中文件 → 确认安装，进度与结果跟着系统弹窗走。

Skit 的介绍与版本说明见 [Skit 应用管理工具介绍站](https://skit.fewf.click/)；自己提取出来的应用为什么是 .apks，见 [提取已装应用为APK的方法](提取已装应用为APK的方法.md)。

## 三、装不上时的排查

| 现象 | 处理 |
| --- | --- |
| 点开分体包提示「解析错误」 | 用支持分体包的安装器打开，别用系统安装器直接点 |
| 提示与已装应用签名不一致 | 两份包不是同一签名方，无法覆盖，只能卸载旧的再装（会丢该应用数据，先确认） |
| 安装到一半失败 | 多半是存储空间不足，或分片与本机架构不匹配——分体包通常按机型拆分，别机型导出的包本来就可能缺你这台的分片 |
| 一直转圈没反应 | 退出重试一次；仍卡住就换一份完整包再试 |

## 四、非要单个 .apk 也可以

有「强制导出单个 APK」的选项能把 App Bundle 应用也压成单包，代价是只保留基础分片的一套配置，换到不匹配的设备上可能装不上或功能缺失。优先用分体包原样搬运，只有目标设备确实只认单 APK 时再用这个选项。
