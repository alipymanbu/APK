# 大文件断点续传下载方法

> 安卓手机下载几个 GB 的大文件，中途断网、切后台、没电关机之后，如何接着传而不是从头来。相关文档：[手机磁力链接下载方法.md](手机磁力链接下载方法.md) · [无广告的安卓下载器怎么选.md](无广告的安卓下载器怎么选.md)

---

手机下载大文件的真正难点不在速度，而在"续"：固件包、游戏数据包、视频合集动辄几个 GB，用浏览器直下，中途任何一次断网都可能让进度归零。本篇给一套把大文件稳稳拿下来的做法。

## 一、为什么浏览器扛不住大文件

浏览器下载是单线程顺序传输，两个弱点恰好都卡在大文件上：

- **一断就废**：多数内置下载器对"断点"的支持形同虚设，重启后只能整包重来；
- **速度封顶**：单连接跑不满带宽，服务器限速时更是干等。

专用下载器的思路不同：把文件切成多段并行拉取，每段单独记录进度，哪段断了补哪段。Free Download Manager 安卓版就是这么工作的——这也是它的名字里带"断点续传"基因的原因，桌面版时代这套机制就已经成型。

## 二、实际操作顺序

1. 从 [FDM 安卓版介绍站](https://free-download-manager.wxhp.skin/) 的下载页拿到安装文件资源，先装好应用；
2. 把直链或磁力粘进"添加下载"，任务开跑后列表里能看到实时速度与剩余时间；
3. 进设置确认**"仅 Wi-Fi 下载"**按需开关：流量充足就关掉，晚上挂机不受路由器重启影响；
4. 中断后重新打开应用，任务会自动从断点继续，不需要任何手动操作；
5. 对速度敏感的场景，在任务详情里看各分段的连接状态，个别源慢就先暂停再恢复，重新握手往往更快。

## 三、限速与错峰

夜间路由器空闲，是拉大文件的好时段。FDM 支持全局与单任务两级限速：

- 白天挂着下，限速到总带宽的一小部分，刷视频、开会不受影响；
- 睡前放开限速，配合计划任务让传输集中在深夜；
- BT 任务还能按文件调优先级，先下完急用的，其余慢慢补。

## 四、任务"消失"了先别慌

以下三种情况看起来像任务丢了，其实都还在：

| 现象 | 实际状态 | 处理 |
| --- | --- | --- |
| 列表里找不到 | 任务被切到"已完成"标签页 | 顶部切到"已完成"查看 |
| 文件不见了 | 存储目录按类型分了文件夹 | 设置里查"已下载"路径 |
| 进度倒退 | 个别分段校验失败被重下 | 等它跑完，通常只回退一小截 |

传完的文件可以直接在应用内打开，或用系统文件管理器到"已下载"目录取。遇到的是"添加任务就失败"而不是"中途断"，那更多是链接与来源的问题，可先看 [手机磁力链接下载方法.md](手机磁力链接下载方法.md) 里对三种来源的区分。
