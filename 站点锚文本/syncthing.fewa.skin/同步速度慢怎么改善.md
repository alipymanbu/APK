# Syncthing 同步速度慢怎么改善

同步慢多数不是「软件不行」，而是连接走了兜底通道，或后台被系统停了。按下面的顺序查，大多数情况能明显改善。

**相关阅读**：[设备配对与第一个同步文件夹](设备配对与第一个同步文件夹.md) · [手机相册自动备份到电脑的设置](手机相册自动备份到电脑的设置.md)

## 一、先看是不是走了中继

电脑端管理页面里展开对应设备，「连接类型」以「中继 / Relay」开头，说明两端没能直连，流量正绕道公共中继服务器转发——数据依然加密，但速度受中继负载限制，通常远低于直连。

手机端同样能看：设备页展开对应设备；也可以用手机端的 Web 界面（左上角菜单 →「Web GUI」），界面和电脑端一致。

## 二、切回直连的四个办法

按优先级试：

1. **给一台设备做端口转发**：进路由器管理页，把 `22000/TCP` 和 `22000/UDP` 转发到那台设备的内网 IP。两端里有一台做了转发，通常就能建立直连，另一端不用动；路由器支持 UPnP/NAT-PMP 的话，也可以在连接设置里开 NAT 遍历让它自动映射；
2. **放行本机防火墙**：电脑防火墙放行入站 `22000/TCP`、`22000/UDP`，以及局域网设备发现用的 `21027/UDP`；
3. **手动指定对方地址**：同一家庭网络但本地发现失效（路由器隔离了广播、访客网络等）时，打开对方设备的编辑页，把「地址」从 `dynamic` 改成 `tcp://对方内网IP:22000`；给那台设备在路由器里绑定静态 IP 更稳；
4. **虚拟组网兜底**：两端都不方便动路由器时，可以用 Tailscale 这类虚拟组网工具让设备互相可达，Syncthing 会经由虚拟网络直连（非内置方案，是否使用自行取舍）。

改完回到设备详情确认：连接类型显示 `tcp://…` 或 `quic://…` 开头即为直连成功。

## 三、直连了还是慢，看瓶颈在哪

- **首次同步大文件夹**：瓶颈常在两端处理器的校验速度，低配置手机和 NAS 尤其明显，跑完这一轮就好了；
- **隔着互联网同步**：上限是两边的上行带宽，跟下载带宽无关；
- **锁屏就不动、亮屏又动了**：这不是速度问题，是后台被省电策略冻结——去系统电池设置里把它改为不优化，并核对应用内「运行条件」的勾选。

## 四、减少不必要的同步量

体积大但只此一份、传完就不再变的内容，同步完成后就让它保持「最新」状态即可；相册类场景记得排除缩略图缓存（`.thumbnails`）和回收站文件（`*trashed*`），能省掉大量无意义的扫描与传输，具体见[手机相册自动备份到电脑的设置](手机相册自动备份到电脑的设置.md)。
