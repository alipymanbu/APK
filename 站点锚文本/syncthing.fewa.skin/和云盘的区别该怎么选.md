# Syncthing 和云盘的区别该怎么选

「文件同步」和「存网盘」看起来都是让文件多端可得，实际是两套逻辑。把区别想清楚，才知道 Syncthing 适不适合自己。

**相关阅读**：[设备配对与第一个同步文件夹](设备配对与第一个同步文件夹.md) · [手机相册自动备份到电脑的设置](手机相册自动备份到电脑的设置.md)

## 一、文件放在哪，是根本区别

云盘是「文件存在厂商的服务器上，各设备从服务器存取」；Syncthing 是「文件只存在你自己的设备上，设备之间直接互传」，传输全程加密，没有中间服务器留存。

| | 云盘 | Syncthing |
| --- | --- | --- |
| 文件存放位置 | 厂商服务器 + 你的设备 | 只在你的设备 |
| 大容量成本 | 通常要会员 | 无此项支出 |
| 设备不同时在线 | 不影响，服务器中转 | 不同步，要同时在线 |
| 第三方可见性 | 厂商侧可处理扫描等 | 点对点加密，无中间存储 |

## 二、「同时在线才同步」意味着什么

这是它和云盘最实际的差距：手机和电脑得同时开着、连着网，文件才会流动。所以它替代不了「随时随地打开就有」的云盘，更适合这些场景：

- 家里设备之间的大批量搬运：相册备份、电影和安装包的中转，不占云盘容量也不限速；
- 对存放位置有要求的数据：只愿意让自己设备碰着的资料，设备间直传正合适；
- 局域网内的日常同步：同一 Wi-Fi 下速度按内网带宽算，大文件也快。

## 三、两条路也可以并存

不少人的用法是两者各管一摊：日常随手存的小文件放云盘图方便，大体积和私密的资料用 Syncthing 在设备间直传。安装包这类「下载一次、多设备要用」的东西，也可以先在自己的设备间流转，减少重复下载。

## 四、上手成本的真实评估

Syncthing 的配置比装个云盘客户端复杂：要配对设备、建文件夹、调后台运行条件，安卓端还得分清三种文件夹类型。换来的是完全自主的同步规则——什么条件跑、往哪台设备传、误删怎么找回，全由自己定。愿意花半小时摸一遍设置的，它的上限比网盘高得多。
