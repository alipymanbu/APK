# Syncthing 设备配对与第一个同步文件夹

Syncthing 没有账号体系，设备之间靠「设备 ID 互加」建立信任：两台设备各自把对方加进自己的设备列表，连接才算建立。本文把配对和第一个同步文件夹的完整流程一次讲清。

**相关阅读**：[手机相册自动备份到电脑的设置](手机相册自动备份到电脑的设置.md) · [同步速度慢怎么改善](同步速度慢怎么改善.md)

## 一、先找到自己的设备 ID

每台装了 Syncthing 的设备首次启动时会生成一个唯一的设备 ID，形如七段大写字母数字的组合：

- 手机端：打开 App → 左上角菜单 →「显示设备 ID」，会同时给出二维码；
- 电脑端：打开本机管理页面（默认 `http://127.0.0.1:8384`）→ 右上角「操作」→「显示 ID」。

手机端也有完整的 Web 界面（左上角菜单 →「Web GUI」），和电脑端长得一样，后面要调的设置两边都能操作。

## 二、互加对方（两边都要做）

1. 一端点「设备」页的「+」，扫描对方面前的二维码，或把对方 ID 粘贴进来；
2. 设备名只是本地显示用的备注，随意填，保存；
3. 到另一端，会弹出「新设备」提示，点确认添加——这一步就是「另一边也要加你」；
4. 两边设备名旁都出现在线状态圆点，配对完成。

顺序无所谓，哪边先加都行，但两边必须都完成。安全性也建立在这个机制上：光拿到设备 ID 并不能连上设备，对方不添加你，连接就不存在。

## 三、建立第一个同步文件夹

以「把手机相册同步到电脑」为例：

手机端（共享方）：

1. 「文件夹」页点「+」；
2. 标签随意（如「相机照片」），路径选到相机目录；
3. 在「共享给设备」里勾选刚配对的电脑，保存。

电脑端（接收方）：

1. 管理页面会弹出「文件夹共享请求」，点「添加」；
2. 把路径改成本地想存放的位置（如 `D:\照片备份`）；
3. 保存后等初始同步走完：文件夹状态显示「最新」即成。

**安卓 11 及以上的路径限制**：新版安卓收紧了对公共目录的写入，整个 DCIM 根目录等系统位置可能选不中。可以把要同步的内容挪进 `Documents/`、`Download/` 这类允许的目录，或用应用提示的私有目录。

## 四、文件夹类型怎么选

同一个文件夹在每台设备上可以各配各的类型：

| 类型 | 行为 | 适合 |
| --- | --- | --- |
| 发送和接收 | 双向同步，两边改动互传 | 都要增删改的资料夹 |
| 仅发送 | 只往外推，收不到对方的改动 | 手机相册 → 电脑备份 |
| 仅接收 | 只收不发，本机改动不外传 | 电脑往手机推电子书 |

单向类型比双向更防误操作：接收端误删的文件，下次同步会被原样推回来，不会真的丢。

## 五、别忘了后台条件

安卓会积极省电，锁屏后把「看起来不活跃」的应用停掉。装好后建议顺手做两件事：应用内「设置 → 运行条件」按需勾选（常见搭配是 Wi-Fi + 充电）；系统电池设置里把它改为「不优化」。不然「装好了却不同步」多半出在这层。
