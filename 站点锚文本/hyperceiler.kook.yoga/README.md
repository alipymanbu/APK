# HyperCeiler 站点导读（hyperceiler.kook.yoga）

这里是一个围绕 HyperCeiler 的第三方介绍站导读页：HyperCeiler 是挂在 LSPosed 上的小米 HyperOS / MIUI 系统增强模块，把状态栏、锁屏、相机、相册、桌面、通知等区域的细节聚成一个一个开关。站点按「上手前提 → 激活 → 开关速览 → 版本分支 → 常见问题」的顺序整理了它的用法与注意事项，并给出安卓版安装文件资源的获取入口，详见 [HyperCeiler 模块介绍](https://hyperceiler.kook.yoga/)。
