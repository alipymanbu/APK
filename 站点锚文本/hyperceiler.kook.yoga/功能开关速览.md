# HyperCeiler 功能开关速览

HyperCeiler 口号是「Make HyperOS Great Again!」——把系统不给的选项聚成一排排随手拨动的开关。这句口号背后，是它对状态栏、锁屏、相机、相册、桌面、通知等区域的细粒度改造能力。本篇按区域把值得先看的开关归堆列一遍；环境怎么备、模块怎么激活，见[激活前提与 LSPosed 步骤](激活前提与LSPosed步骤.md)。

## 状态栏与时钟

- **焦点歌词**：听歌时在息屏界面跟随显示歌词，还支持自定义息屏焦点布局与歌词翻译，是近期版本里最出圈的一项；
- **日期时钟格式 / 双排移动网络图标 / 网速指示器**：状态栏的信息密度自己定；
- **运营商名称自定义**：状态栏那几个字也能换。

## 锁屏与相机、相册

- **锁屏底部左侧按钮**：常用入口留在锁屏；
- **相机**：4K 60fps、超高照片质量、徕卡定制界面等拍摄档位的开关都在日志里出现过；
- **相册**：证件照、照片电影、生成 PDF 等能力可以直接打开。

## 桌面、通知与系统服务

- **最近任务卡片样式 / 小部件背景模糊**：桌面观感细节的主战场；
- **自动隐藏展开的通知 / 磁贴高级材质 / 全局弹幕通知**：通知块面的整齐度与控制中心手感；
- **验证码自动写入剪贴板 / 更多电池信息 / 晕车缓解 / 引导式访问**：杂项里的实用件，比如长按电源键就能退出引导式访问。

不同系统版本可用项有差异，以上以模块内实际列表为准。另外，这些开关只在支持的系统上可用——拿不准自己该用哪条产品线的话，先看[版本分支怎么选](版本分支怎么选.md)。

完整的分区介绍与应用内截图，可以参考 [HyperCeiler 介绍站](https://hyperceiler.kook.yoga/)，站点按「前提 → 激活 → 开关 → 分支」的顺序组织，读起来比零散翻日志省力。
