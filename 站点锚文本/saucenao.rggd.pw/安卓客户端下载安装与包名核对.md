# 安卓客户端下载安装与包名核对

> 在手机上用 SauceNAO，常见的是开发者 luk1337 的开源客户端。这篇讲从拿到安装文件到点开首搜的四步，以及怎么认出正身、避开同名仿冒。
> **相关文档**：[以图搜图结果相似度怎么读](以图搜图结果相似度怎么读.md) · [搜图次数限制与APIKey填法](搜图次数限制与APIKey填法.md)

## 装之前认两件事

第一件是身份：它的源码公开托管在 GitHub，也上架了 F-Droid 与 Google Play，认正身只看包名 `com.luk.saucenao`。第二件是门槛：安装包 3 MB 上下，要求 Android 5.0 及以上，近几年的机型基本都能跑。它只申请两条联网相关权限，相册、通讯录、位置都不碰——选图走的是系统照片选择器。

## 四步装好

1. **拿到安装文件**：进入分享页，把 APK 文件转存或下载到手机存储，确认文件以 `.apk` 结尾、大小 3 MB 上下。获取入口在 [SauceNAO 安卓版介绍站](https://saucenao.rggd.pw/)的下载页，进去点首屏按钮就到网盘分享页。
2. **放行「安装未知应用」**：首次安装系统会拦一道，按提示进「设置 → 安全（部分机型在「应用专用权限」里）→ 安装未知应用」，给提供文件的那个浏览器或网盘客户端打开开关。
3. **点开安装包**：回到文件管理器点开 APK，等进度跑完，桌面出现图标即装好；以后升级直接装新包覆盖，不用先卸载。
4. **试搜一张**：打开应用点「选择图片」搜一张试试；常搜图的话顺手把 API Key 填上，每日次数上限会高不少（不填也能正常搜）。

## 两个常遇到的坎

**点安装没反应、被系统拦截**：多半是「安装未知应用」的授权没给到位。注意授权对象不是这个客户端，而是提供安装文件的那个应用（浏览器或网盘客户端），开完开关回来重新点安装即可。

**装完闪退、打不开**：先看系统版本是否达到 Android 5.0；再看安装包是否完整，明显偏小就是没下完，删掉重新转存一份再装。

## 怎么核对不是仿冒品

安卓上同名、近名的搜图应用不少。核对办法：进入「设置 → 应用 → SauceNAO → 应用信息」，包名显示 `com.luk.saucenao` 的才是 luk1337 的开源客户端；名字再像，包名对不上就不是。
