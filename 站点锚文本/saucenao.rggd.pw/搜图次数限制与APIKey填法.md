# 搜图次数限制与APIKey填法

> 「服务器请求过多」是用 SauceNAO 搜图最常撞上的提示。它背后是短时与每日两档限制，恢复方式各不相同；API Key 则是抬高每日上限的唯一开关。这篇讲清两档怎么区分、密钥从哪来、往哪填。

## 两档限制，恢复方式不同

限制分两层，都和「有没有填 API Key」挂钩：

| 档位 | 触发表现 | 怎么恢复 |
| --- | --- | --- |
| 短时（约每 30 秒一档） | 提示「服务器请求过多」 | 停十几秒到半分钟再搜 |
| 每日（每 24 小时一档） | 同样的提示，但等几十秒也不会好 | 等次日额度刷新，或填 Key 抬高上限 |

区分办法很简单：停半分钟再搜就好了的是前者，一直不好的是后者。没填 Key 时的量级，多次被人引用的经验值是每 30 秒 4 次上下、每天一百次上下——这组数字会调整，以服务方页面当时显示为准。

## 密钥从哪来

1. 用浏览器打开 SauceNAO 的站点，注册一个账号；
2. 登录后进站内的 API 页面，生成或查看属于你的密钥——一串字母数字；
3. 整段复制下来。

客户端里没有「登录账号」这个入口，它只保存这一串密钥，不保存账号密码，所以流程是「在浏览器里拿密钥，回应用里粘贴」。

## 往哪填、该不该填

密钥的填入位置在客户端的菜单里，找到「API 密钥」一项整段粘贴即可。要不要填看用法：

- **偶尔用**（一天搜几张）：不填，够用，别折腾；
- **一天搜很多张**，或已经不止一次撞上「服务器请求过多」：填上，这是唯一能提高每日额度的办法。

## 撞上提示的现场处理

先停半分钟重搜一次：恢复了，就是短时档，慢一点就好；没恢复，就是当日额度用完了，填 Key 或次日再搜。顺带一提，搜不出结果不一定是限额——图的清晰度、裁剪和图库范围都有影响，先按[以图搜图结果相似度怎么读](以图搜图结果相似度怎么读.md)里说的换图重搜，再看次数。

三种搜法入口与安装流程，见 [SauceNAO 介绍站](https://saucenao.rggd.pw/)。
