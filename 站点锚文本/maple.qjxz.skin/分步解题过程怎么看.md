# 分步解题过程怎么看：从答案到每一步

> 只给最终答案的 App，对完数还是不知道自己错在哪。本篇讲 Maple计算器里怎么把解题过程一步步展开、哪些题型有分步，以及拿到图形之后还能怎么追问。

## 一、分步过程覆盖哪些题型

不是每道题都有长篇推导，常见有分步过程的大致是这几类：

| 题型 | 过程里能看到什么 |
| --- | --- |
| 方程与方程组 | 消元、移项到最终解，方程组还会先画图看交点 |
| 极限、导数、积分 | 按规则的拆解步骤，不定积分给原函数 |
| 矩阵计算 | 乘法、求逆、行列式、高斯消元的中间矩阵 |
| 表达式化简 | 配方、因式分解的结果与写法 |

简单算数题往往一步出结果，没有过程可展开——这属于正常现象，不是没找到入口。

## 二、怎么把步骤展开

解出来的结果默认收起，点开对应的条目就能看到逐步内容。一道题的界面里通常不止一个条目：解方程之外还有画图、求导、积分这些操作项，各自展开各自行数。

## 三、同一道题换个角度再算

这是它和普通计算器拉开距离的地方：同一个表达式，你可以挑画图（2D 曲线、3D 曲面，支持缩放、平移、旋转）、因式分解、积分等不同操作重算一遍。改动表达式，图形跟着变——验证自己对函数行为的直觉，比反复代数字直观。

## 四、过程还是看不懂的时候

结果是错的、或者过程里某步对不上，把手写的完整解题过程拍照传到 Maple Learn（在线工具）里逐步对照，找出错的那一行；也能在那里继续探索、把工作分享出去。与 Maple 桌面软件互传结果同理，适合已经在用桌面端做作业或项目的人。
