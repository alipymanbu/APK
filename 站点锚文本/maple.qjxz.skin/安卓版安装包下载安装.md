# 安卓版安装包下载安装：渠道与装不上的排错

> 想在安卓手机上装 Maple计算器，常见的获取渠道不止一个，装不上的原因也集中在几条上。本篇把渠道怎么选、安装四步、失败先查什么一次讲清。
> **相关文档**：[拍照识别手写数学题.md](拍照识别手写数学题.md) · [分步解题过程怎么看.md](分步解题过程怎么看.md)

## 一、从哪获取安装包

三条路，按自己手机的情况挑：

1. **应用商店**：Google Play 里搜得到；没有 Google 服务的国产手机，华为应用市场里也有这份 App。商店的版本随更新走，装最新的就用这条。
2. **网盘分享**：写作业的设备不方便登商店、或者想固定用某个版本时，从网盘把 APK 下到手机直接装，流程见下面第二节。
3. **介绍站指路**：[Maple计算器介绍站](https://maple.qjxz.skin/)的下载页把网盘获取和安装步骤放在同一页，照着走完四步就能打开，不用来回翻。

## 二、网盘获取后的安装四步

1. 打开分享链接，把文件**转存到自己账号**，再从网盘 App 下载 APK 到手机存储。
2. 在文件管理器里点开这个 APK。
3. 首次安装弹「未知来源」提示：进设置，允许当前这个文件管理器安装应用，返回继续。
4. 点「安装」等它完成，打开 App；首次进入选简体中文。

装好先在 Wi-Fi 环境拍一道手写题试识别——拍照功能要联网，先验证这条再出门，路上才不至于抓瞎。

## 三、装不上时先查这三条

| 现象 | 先查什么 |
| --- | --- |
| 提示解析包出现问题、装到一半失败 | 下载中断导致文件不完整，回网盘重新完整下载一遍；确认机身存储还有几百 MB 余量 |
| 系统拒绝覆盖安装 | 手机里已有一份同应用的版本且更新，同一包名只能留一个：想换先卸载现有的 |
| 打开就闪退 | 清应用缓存、重启手机再试；仍不行就换商店渠道的版本 |

## 四、装好之后

从拍照识题开始上手最顺，拍法与兜底技巧在[拍照识别手写数学题.md](拍照识别手写数学题.md)；拿到结果后怎么展开每一步，见[分步解题过程怎么看.md](分步解题过程怎么看.md)。它对题型覆盖到什么程度（从算数到常微分方程），介绍站里有一份按学段排列的能力清单，装之前可以[先看一眼](https://maple.qjxz.skin/)再决定。
