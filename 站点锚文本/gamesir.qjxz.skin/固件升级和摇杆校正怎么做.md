# 固件升级和摇杆校正怎么做

> 手柄出厂到到你手里隔着几个月的库存期，固件多半不是当前版本。本篇讲什么时候该升、怎么升、升级失败怎么办，以及为什么升级完必须校正摇杆。
> **相关文档**：[手柄连安卓手机玩手游怎么设置](手柄连安卓手机玩手游怎么设置.md)

## 一、什么时候该升

- **新手柄第一次连上时**：无论手感如何，先升再玩，后面省掉很多排查；
- **出现怪问题且软件侧查无原因时**：漂移、断连、个别按键失灵，固件旧版本是常见诱因；
- **App 提示有新固件时**：设备连上后 App 会自动检测并提醒。

顺带一提，App 本身也有版本更新（近期版本加入了宏编辑录制、配置分享这类新能力），固件与 App 两条线各自保持当前版本即可，介绍站入口见 [GameSir 配套 App 介绍站](https://gamesir.qjxz.skin/)。

## 二、升级四步

1. **连上手柄**：手机系统蓝牙配对后，进 App 的设备页连接目标手柄；
2. **进入固件升级**：在设备详情里找到固件升级入口，等 App 检测完当前版本；
3. **等待写入**：升级过程别锁屏、别切走 App、别让手柄断连——中途断电是变砖的主要来源，电量不足先充再升；
4. **完成校正**：升级结束后 App 会提示校正摇杆。

## 三、摇杆校正为什么必须做

固件刷新后，摇杆的物理中位与软件识别的中位需要重新对齐，跳过校正直接玩，大概率遇到两种情况：

- 角色原地缓慢漂移（中位偏了）；
- 推杆有死区或加速不线性（行程没对齐）。

校正操作就是跟着屏幕提示把摇杆转满几圈，几秒钟的事，做完手感立刻正常。

## 四、升级失败怎么救

| 现象 | 处理 |
| --- | --- |
| 检测不到新固件 | 确认手柄真的连进了 App 设备页（而不是只挂在系统蓝牙上） |
| 升级中断/卡住 | 重新连一次再试；手柄电量过低的先充电 |
| 升级后手柄异常 | 关机重开再连；仍不行就重走一遍升级流程覆盖写入 |
| 反复失败 | 换一台手机试一次，排除个别机型的蓝牙兼容问题 |

升级与连接的关系密不可分：设备页都进不去的话，先回 [手柄连安卓手机玩手游怎么设置](手柄连安卓手机玩手游怎么设置.md) 把连接链路走通。
