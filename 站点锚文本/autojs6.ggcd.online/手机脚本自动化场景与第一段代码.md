## 这些场景，脚本比人快

安卓自动化最常见的用法，是把"每天都要点几下的固定动作"交给脚本：

- **到点自动静音 / 恢复音量**：开会时段定时任务切换情景，不用记。
- **批量整理文件**：下载目录里的截图按日期归档、批量重命名，几行文件操作就够。
- **固定流程一键化**：打开某个应用、点进某个页面、截图保存——录一遍，以后悬浮窗里一键回放。
- **屏幕内容监控**：截图找色判断页面状态，出现特定内容就弹通知提醒。
- **读屏识别文字**：OCR 模块把屏幕上的字读出来，交给脚本做后续判断。

共同点很明确：**规则清晰、重复次数多**的事适合交给脚本；需要临场判断的事，人还是比脚本靠谱。

## 第一段代码：按控件点击

下面这段是最经典的入门脚本——找到屏幕上写着"开始"的按钮并点它：

```javascript
auto.waitFor();                          // 等无障碍服务连接好
let btn = text("开始").findOne(3000);    // 最多等 3 秒
if (btn) {
    btn.click();
    toast("点到了");
} else {
    toast("没找到按钮");
}
```

重点在 `text("开始")` 这种**选择器写法**：脚本按控件找目标，而不是死记屏幕坐标。好处是换手机、换分辨率，脚本照样能跑——这也是这类工具和按键精灵类坐标工具的本质区别。

## 动手前只差两件事

1. **开启无障碍服务**：首次打开应用按提示去系统设置里允许，这是模拟点击、读取控件的能力来源。
2. **跑一遍内置示例**：文件页里自带一套示例代码，从改示例开始，比从空文件开始快得多。
