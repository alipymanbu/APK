# vivo 手机真伪查询与维修报价查询方法

> 怀疑手机不是正品、维修前想知道价，都不用打电话来回问：一个 IMEI 就能验机，配件报价在应用里直接查。

vivo 手机的验机与维修报价都是公开口径，查询入口就在商城应用（vivo Space）与网页两端，动手之前先把数字查清楚，心里有底再送修。

## 一、先拿到识别码

不同产品用的码不一样：

- **手机**：拨号键盘输入 `*#06#`，屏幕直接显示 IMEI；
- **平板 / 手表 / 真无线耳机**：设置 → 系统管理 → 关于里看序列号 SN；
- **包装盒**：盒身标签印有 IMEI / SN / 防伪码，可与机身显示的对照。

## 二、在哪查真伪

把识别码输进查询页即可验证；查无此码或信息对不上，带购机凭证联系客服热线 95033 核实。商城应用的服务板块里也有同样的查询入口。

## 三、维修报价怎么查

- 应用内路径：**我的 → 维修价格**，选机型与配件看报价，手机、平板、蓝牙耳机、手表都支持；
- 口径要点：客户服务中心**只收配件费、不收手工费**，配件按指导价执行、均为原厂全新件；页面查不到的配件，直接问服务中心或打热线。

送修之后想看进度，应用内「我要维修 → 了解维修进度」就能跟踪，也可以用送修手机号验证查询。

## 四、三包与保修期

手机执行国家三包：**7 天包退、30 天包换、1 年保修**（凭有效发票与三包凭证）；商城购物的保修期从快递签收日起算，换机后三包从换机日重新计算。进水、摔坏等人为损坏不在保修范围内，可到服务中心付费换原厂件。

验机通过只是开始，机器到手后的贴膜、积分、新机福利都有时限，可以接着看[免费贴膜领取方法](免费贴膜领取方法.md)与[新机福利与国补攻略](新机福利与国补攻略.md)；积分的攒法和抵现比例写在[积分抵现与会员等级](积分抵现与会员等级.md)。
