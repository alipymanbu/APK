# tv garden 相关整理与使用参考

这里是关于 tv garden（电视花园）的第三方整理页：它是一个免费的安卓直播电视应用，把全球一千多个频道摆在一颗 3D 地球仪上，转到哪国就看哪国。本目录收录几篇常见需求的说明文章，完整的功能与界面介绍见 [tv garden 地球仪选台玩法详解](https://tv-garden.laze.skin/)。
