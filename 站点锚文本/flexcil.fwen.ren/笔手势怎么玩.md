# Flexcil 笔手势怎么玩

> Flexcil 把「选中、摘录、删除」这些批注动作全部做成了笔尖画出来的手势：不用先去工具栏点图标再拖动选择，笔一落纸动作就完成了。这篇按用途把手势整理成速查表，并说清楚两个新手最容易困惑的地方——阅读模式与笔手势模式的区别、扫描版 PDF 为什么选不了字。
> **相关文档**：[安卓版安装步骤](安卓版安装步骤.md) · [换手机备份搬家](换手机备份搬家.md) · [目录说明](README.md)

## 一、先分清两种模式

文档阅读器顶部有一个「阅读 / 笔手势」切换，这是所有手势的前提：

- **阅读模式**：手指和笔尖的滑动只负责翻页、缩放，不会误产生批注；
- **笔手势模式**：笔尖画出的轨迹被当作指令——下划线选字、画圈选词、方框截取，全靠它。

手势全部失灵时，第一件事就是看这里是不是停在阅读模式，这是新手反馈里最高频的一个原因。

## 二、常用手势速查

| 想做的事 | 画法 |
| --- | --- |
| 选一句话 | 在文字上画一条下划线 |
| 选一个词 | 围着词画一个小圈 |
| 选一整段 | 在段落两端画圆括号 |
| 精确选择 | 长按文字拖动扩展范围 |
| 截取图文块 | 画 L 形或方框框住区域 |
| 删除笔迹 | 在字迹上反复涂抹划掉 |
| 撤销 / 重做 | 两指双击撤销，三指双击重做 |
| 弹出 / 收起笔记本 | 三指上滑打开，三指下滑收起 |
| 移动弹出笔记本 | 三指按住笔记本上方拖动 |

截取下来的文字或图片，按住拖进弹出式笔记本即可完成摘录，出处会自动记成参考链接。

## 三、扫描版 PDF 选不了字，不是坏了

扫描件、拍照转成的 PDF 没有文字层，上面所有「选字」类手势（下划线、圈选、括号）对它都无效——这是官方支持文档里明确写过的正常现象。想对这些文档做文字摘录，需要先在别处完成 OCR 处理；而方框、L 形这类**截取手势不受影响**，把内容当图片截进笔记照常可用。

## 四、选完字之后能干什么

选中文字后弹出的菜单里，常用的有三类动作：

1. **高亮 / 下划线**：直接给原文加批注，颜色可换；
2. **复制到笔记**：拖进弹出式笔记本，摘录自带参考链接，之后点击能跳回原文位置；
3. **词典 / 网页搜索**：读外文文献时查词、搜原句都很顺手。

把手势练熟大约只需要几分钟，更完整的玩法图文（含截图演示）放在 [Flexcil 说明站](https://flexcil.fwen.ren/) 的手势速查一节。还没装好的话，先看[安卓版安装步骤](安卓版安装步骤.md)；装好后打算换机的，备份前记得读一遍[换手机备份搬家](换手机备份搬家.md)。
