# 演唱会购票流程与电子凭证入场须知

> 本篇讲在 BIGC 上买演出票的全流程：三类票的区别、开售前要做的准备、下单与支付，以及演出当天用电子凭证入场要注意什么。

## 一、TICKET 板块能买到什么

BIGC 的票务板块主要承载三类票，来源不同、买法也有差别：

| 票种 | 是什么 | 说明 |
| --- | --- | --- |
| 打歌节目现场观众票 | 进入 THE SHOW 等节目现场观众席的资格 | 以抽选（raffle）形式报名，不是先到先得 |
| 独家演唱会 / 见面会 | 仅在平台上架的演出与 FM 门票 | 常规票务平台买不到，只在平台内销售 |
| 线上直播观演券 | 在家观看演出直播的凭证 | 线下票售罄或人到场不了时的替代方案 |

前两类需要你人在韩国或另行安排出行，第三类没有地点限制。进场核验走应用内的 BIGC Pass（电子凭证），从核验到入场都在手机上完成，不需要兑换纸质票。

## 二、购票前的准备

购票拼的是下单速度，开售前把这几件事做完：

1. **账号先就位**：没注册的先完成注册登录，开售当场才注册基本来不及；
2. **支付方式提前确认**：确认你的支付渠道可用、余额或额度充足；
3. **分清开售时间用的是 KST**：韩国场次的预售时段通常按韩国时间标注，与北京时间恒定相差一小时（韩国不用夏令时），换算好再定闹钟；
4. **热门场次先浏览一遍购票页**：提前看清票档、限购数量与退票规则，开售后直接选票。

以线上直播观演券为例，预售期通常开在直播前数天、截止到开演前不久，开播后即无法再买——具体每场的时段以演出公告页为准，别照搬上一场的时间。

## 三、购票与入场流程

1. 在 TICKET 板块选中目标场次，进入详情页；
2. 选票档与数量，提交订单并完成支付；
3. 线下票：演出当天打开应用里的 BIGC Pass，工作人员扫码核验后入场；
4. 线上票：到开播时间在应用内进入直播页观看。

BIGC Pass 是电子凭证，入场时手机要能亮出应用页面，当天记得带充电宝；稳妥的做法是用原账号打开应用出示，不要只靠截图。购票后订单与凭证都能在「我的」的订单入口里回查，建议下单后立刻截图留底，出问题方便核对——演出门票的退改规则与普通商品不同，购票时先看场次页的退票说明。

## 四、看直播与回放

LIVE 板块除了独家直播，平时还免费转播 THE SHOW 与 THE K-POP 两档打歌节目——直播页带全球粉丝实时聊天与实时多语种字幕，直播结束后通常提供 VOD 回放。每周打歌时段可以一边看直播一边投票，一位公布的瞬间正好在直播间里。回放画质与保留时长以页面实际提供为准。

演出内容之外，后台花絮、候宠物料这类独家视频会不定期更新，追团日常可以顺手关注。想从投票这一头了解平台，见[THE SHOW 打歌投票全流程与免费攒票技巧](打歌节目投票全流程与免费攒票技巧.md)；这份 [BIGC 平台总览](https://bigc.uerg.quest/)把五个板块的玩法串成了一篇，适合刚上手时通读。
