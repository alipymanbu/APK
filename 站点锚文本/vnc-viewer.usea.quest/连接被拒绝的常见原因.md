# 连接被拒绝的常见原因：对号入座就能解决

> 手机连电脑报错，八成出在"地址那头"而不是手机上。本篇把 VNC 连接最常见的几类提示逐条拆开：它在说什么、先查哪里、改完怎么验证。
> **相关文档**：[手机远程控制电脑怎么开始.md](手机远程控制电脑怎么开始.md) · [触屏操作远端桌面的手势.md](触屏操作远端桌面的手势.md)

---

## 一、"Connection refused / 连接被拒绝"

这条提示的意思是：地址是对的，但那台电脑上没有东西在应答。逐项查：

1. **服务端没在运行**——被控电脑上的 VNC Server 类程序退出了或没设开机自启，先在电脑上把它打开；
2. **端口对不上**——默认端口是 5900，被控端若改过（比如为了多开多个桌面），地址里要带上端口号，写成 `192.168.1.10:5901` 这样的形式；
3. **防火墙拦截**——Windows 防火墙或安全软件把 5900 端口拦住了，在电脑上放行该端口或放行那个程序；
4. **跨网直连没人接**——公网直接连内网 IP 是连不上的，跨网要走云端中转或端口映射（见上一篇的场景表）。

验证方法：在被控电脑自己那台机器上，用 `127.0.0.1` 连一次能通，就说明服务端正常，问题出在网络链路上。

## 二、"连接被服务端拒接 / 等待确认"

这不是故障，是被控端开了"当面确认"：每次连接都要有人在电脑前点一下允许。处理方式按情况选：

- 有人在电脑旁 → 让他点同意即可；
- 电脑没人守 → 在被控端把验证方式改成纯密码，取消"用户必须确认"这类选项，但要确保连接密码足够强。

## 三、提示"未加密连接"

直连模式下，被控端若没启用加密，客户端会把这条提示摆出来让你决定。判断依据是链路在哪：

- **家里或办公室的内网**——链路不出门，风险有限，可以继续；
- **走公网的直连**——画面里若出现过聊天记录、登录状态，就值得先把被控端的加密打开，或改走云端中转（加密在链路里自动生效），再点接受。

拿不准时，宁可先去开加密，这条提示不会消失之前不要养成随手点"接受"的习惯。

## 四、"签名不匹配 / 会话不存在"

多见于连服务器或多用户场景：你想续上的那个会话已经被注销，旧地址自然失效。此时反复重试没有意义，在服务端重新开一个会话、拿新地址（新编号）再连。

## 五、连不上之外：连上了却黑屏

偶尔画面全黑但不断开，常见于被控端是无人登录的 Linux 主机，桌面会话没起来——在被控端重新登录一次桌面、或让服务端"跟随当前桌面"再试。

---

按上面顺序排查，绝大多数连接问题都能落地。这套"报错 → 先查哪里"的对照，也整理在 [VNC Viewer 安卓版介绍站](https://vnc-viewer.usea.quest/) 的首页"连不上排查"一节，手机上翻看起来更顺。若问题出在最开始的安装环节（未知来源被拦、转存后装不上），先回 [手机远程控制电脑怎么开始.md](手机远程控制电脑怎么开始.md) 把两侧装好，再看 [触屏操作远端桌面的手势.md](触屏操作远端桌面的手势.md) 练操作。
