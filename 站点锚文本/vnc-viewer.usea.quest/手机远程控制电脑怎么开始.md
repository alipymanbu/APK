# 手机远程控制电脑怎么开始：从被控端到第一条地址

> 想用手机操作家里或公司那台电脑，VNC 是门槛最低的一条路：跨系统、不用同账号。本篇按真实顺序讲清两侧各要做什么、第一条地址怎么填、第一次连上之前会碰到什么。
> **相关文档**：[连接被拒绝的常见原因.md](连接被拒绝的常见原因.md) · [触屏操作远端桌面的手势.md](触屏操作远端桌面的手势.md)

---

## 一、先弄清两端各是什么角色

VNC 这套远程方案里，被控的电脑要常驻一个"服务端"，负责把桌面画面发出去、接收输入指令；你手里的手机装的是"客户端"（Viewer），负责收画面、发指令。名字对上号，后面排错就不迷糊：

- **被控端（电脑）**：安装并运行 VNC Server 类程序，设置一个连接密码；
- **控制端（手机）**：安装 VNC Viewer，把电脑的地址存进列表。

两端装好之后，日常使用就只剩"点开一条地址"这一个动作。

## 二、被控端：打开门、设好密码

1. 在电脑上安装 VNC Server 并设置连接密码——这个密码就是之后手机连入的凭证，别用弱密码；
2. 记下电脑的地址：局域网内是 `192.168.x.x` 这类内网 IP（Windows 用 `ipconfig` 查，macOS 在网络设置里看），跨网则可能走云端中转的连接方式；
3. 留意防火墙：VNC 默认端口是 5900，首次启动时系统弹出的放行提示要点允许，否则手机这边会一直"连接被拒绝"。

## 三、手机端：装好 Viewer，填第一条地址

安卓版 VNC Viewer 的安装文件资源可以从 [VNC Viewer 安卓版介绍站](https://vnc-viewer.usea.quest/) 的下载页进入获取，装好后：

1. 打开应用，点右下角的加号；
2. 地址栏填电脑的 IP（跨网场景填对应的连接地址或编号），端口没改过就保持默认 5900；
3. 名称随手起——`homepc`、`work-mac` 这类名字比一串数字好认，机器一多就靠它分辨；
4. 保存后点这条地址发起连接，首次会提示输入被控端设置的密码。

## 四、第一次连接前，把场景想清楚

| 场景 | 手机和电脑的关系 | 要做的事 |
| --- | --- | --- |
| 同一 Wi-Fi | 同一个局域网 | 直接填内网 IP，最简单，先从这里练手 |
| 跨网络 | 手机在外、电脑在家/公司 | 两端登录同一云端账号走中转，或在路由器上做端口映射（有安全代价） |
| 电脑没人守 | 无人现场确认 | 被控端改成密码验证，别选"每次都要当面同意"，否则人不在就连不上 |

第一次连接若卡在某一步，多半不是安装的问题，而是地址、端口或防火墙这三处之一——具体报错可以对号入座：[连接被拒绝的常见原因.md](连接被拒绝的常见原因.md)。连上之后怎么用手机把桌面点准，看 [触屏操作远端桌面的手势.md](触屏操作远端桌面的手势.md)。
