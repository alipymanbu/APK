# Rhythm 插件怎么装与栏目管理

> Rhythm 装完打开只有「主页 / 媒体库」两个标签，看起来空空荡荡——这是设计如此，不是装错了。本篇讲插件从哪装、装完栏目不显示怎么查，以及插件侧几个已知的坑。

**相关文档**：[网盘与自建曲库挂载.md](网盘与自建曲库挂载.md) · [歌词与音效设置.md](歌词与音效设置.md) · [同名播放器分辨.md](同名播放器分辨.md)

## 一、为什么装完是空的

Rhythm 的本体只负责播放与管理本地文件，在线内容全部由插件提供。v3.0.858 这一版把在线音乐也改成了外挂插件形式——也就是说，不装任何插件时，你能用的只有本地音乐扫描与播放。首次启动把存储 / 媒体读取权限给上，扫完本地歌就能直接听；想听在线内容，从第二节的插件开始装。

## 二、装一个插件

1. 进入应用，在扩展列表里上下滑动，插件按音乐、听书、网盘等类别排列；
2. 点开想要的插件，点安装——插件是独立的 `rapk` 扩展包，需要单独下载：音乐下载类约 8～9M，油管插件约 3M，装之前留意网络状况，装到一半失败就换个网络重来；
3. 装好后回到主页，对应栏目会出现在顶部标签里；以在线音源类为例，装完再点搜索框，就能搜到这个插件提供的内容。

装完不显示栏目的情况见第四节。

## 三、栏目怎么筛选与手动加扩展

两个管理入口都在明面上：

- **筛选栏目**：主页点左上角的按钮，能看到全部已装扩展，勾掉的栏目在主页和媒体库里都不出现——找不到某个栏目先查这里；
- **手动添加扩展链接**：主页点右上角设置，找到「扩展」一项，点它右侧的 `+` 号，粘贴或输入扩展链接后确认。链接能否使用由提供方决定，打不开、装不上就换一个来源的链接试，再排查是不是版本太旧。

## 四、插件侧的几个坑

以下都来自用户实测反馈（覆盖 v3.0.810 前后到 v3.0.858），不同机型与版本表现可能不同：

| 现象 | 现状与可做的事 |
| --- | --- |
| 插件装上后删不掉 | 有反馈管理界面无法卸载，暂无确认解法；实在碍事只能走 设置 → 应用 → Rhythm → 存储 → 清除应用数据，本地设置会一并清掉 |
| 下载插件提示「v7 / v8 过期」 | 插件包自身有有效期，换更新的插件包重装，或改用别的下载 / 网盘插件 |
| 部分在线源短暂限制 IP | 用一阵提示受限或搜不到结果，隔段时间再试，或先切别的插件顶上 |
| 装完不显示栏目 | 回主页点左上角按钮确认没被勾掉——栏目按已装扩展动态生成，装了不等于显示 |

插件装好之后的用法（歌词、下载入口、在线歌加列表）写在 [歌词与音效设置.md](歌词与音效设置.md)；想把网盘和自建媒体服务挂进来，看 [网盘与自建曲库挂载.md](网盘与自建曲库挂载.md)。
