# Rhythm 同名播放器分辨：认准包名再装

> 搜索「Rhythm」至少能翻出三款不同的安卓音乐播放器：一款插件化空壳播放器、两款 GitHub 上的开源本地播放器。安装包、界面、包名都不一样，网上互相矛盾的说法多半是混到了不同软件头上。本篇给一张对照表，帮你分清。

**相关文档**：[插件怎么装与栏目管理.md](插件怎么装与栏目管理.md) · [歌词与音效设置.md](歌词与音效设置.md) · [网盘与自建曲库挂载.md](网盘与自建曲库挂载.md)

## 一、三款同名软件对照

| | 这款（插件化播放器） | [cromaguy/Rhythm](https://github.com/cromaguy/Rhythm) | [EncryptoCyphers/Rhythm](https://github.com/EncryptoCyphers/Rhythm) |
| --- | --- | --- | --- |
| 包名 | `com.rhythm.app` | `chromahub.rhythm.app` | 以其仓库发布为准 |
| 形态 | 空壳 + rapk 插件：本地直接播，在线音源 / 听书 / 网盘靠插件 | Material 3 风格的纯本地播放器，Media3 内核 | 开源音乐播放器与 MP3 播放器 |
| 渠道 | 经网盘分享获取安装文件资源 | GitHub / F-Droid | GitHub |
| 首次启动 | 语言切中文、给权限、等扫描 | 要跟着引导设置走一遍，不能跳过，扫描音频偏慢 | — |

本套资料讨论的对象只有第一款：包名 `com.rhythm.app`。它的插件生态、栏目管理写在 [插件怎么装与栏目管理.md](插件怎么装与栏目管理.md)。

## 二、最容易混的三处

1. **「Rhythm 打不开、要走一串引导」的说法**：多指 GitHub 那款 cromaguy 版——它首次打开必须走完引导设置。插件化这款没有强制引导，装完给权限就开始扫本地歌。
2. **「没有在线内容」的说法**：两款开源版都是纯本地播放器，本来就没有在线曲库；插件化这款的在线内容要自己装插件，装完是空的属正常（解释见 [插件怎么装与栏目管理.md](插件怎么装与栏目管理.md) 第一节）。
3. **挂名 Rhythm 的域名**：曾被认为是这款软件站点的 `https://www.rhythmplayer.com/`，2026 年 9 月起访问已是域名出售页，别从那儿拿安装包。

## 三、装完后怎么核对

装完打开 设置 → 应用，确认应用信息里包名显示为 `com.rhythm.app`。换版本或重装前先卸载旧包，避免签名或数据残留；装完记得重新给存储与通知权限。这款的形态速览与界面实拍，见 [Rhythm 插件化音乐播放器介绍](https://rhythm.gltd.quest/)。
