# Rhythm 资料索引：插件化安卓音乐播放器

> 这里整理 Rhythm（包名 com.rhythm.app）的中文使用资料。它是安卓上的一款插件化播放器：本体只管本地音乐，在线音源、有声书、网盘曲库都要靠装插件获得。四篇文章按「装插件 → 挂曲库 → 调听感 → 认准哪款」的顺序展开，都从读者实际会卡住的地方写起。

## 目录里有什么

- [插件怎么装与栏目管理.md](插件怎么装与栏目管理.md) —— 装完打开是空的怎么办、rapk 插件从哪装、栏目不显示怎么排查
- [网盘与自建曲库挂载.md](网盘与自建曲库挂载.md) —— Alist / WebDAV / Jellyfin / Emby 与各家网盘插件的用法与边界
- [歌词与音效设置.md](歌词与音效设置.md) —— 歌词不出来的固定排查顺序、均衡器打不开的机型反馈、倍速与无缝播放
- [同名播放器分辨.md](同名播放器分辨.md) —— 三款都叫 Rhythm 的安卓播放器，包名对照与混淆点澄清

想先看这款播放器的整体形态、插件地图与界面实拍，可以读 [Rhythm 插件化音乐播放器介绍](https://rhythm.gltd.quest/)，安装包的获取入口也在那里。
