# GBox 消息推送失败与闪退处理

> 本篇按现象归拢容器方案的高频故障：锁屏收不到 Gmail / WhatsApp 推送、打开就闪退、License 校验失败，逐条给出处理顺序。
> **相关文档**：[安卓版下载安装与首次配置步骤.md](安卓版下载安装与首次配置步骤.md) · [华为手机装谷歌服务的几种办法.md](华为手机装谷歌服务的几种办法.md)

## 一、先记一条通用原则

大部分异常的第一动作是**把 GBox 升到新版本**——旧版与新系统、与新版本应用不兼容，是闪退和各类怪问题的最大来源。升级走覆盖安装，沙箱内的应用与数据不会丢。

## 二、锁屏后收不到推送

本质是后台进程被系统省电策略回收了，三处一起开才算到位：

1. 「设置 → 应用 → 应用管理」搜 GBox，打开**自启动**；
2. 同一页面设为**忽略电池优化**（部分 EMUI 版本收在「应用启动管理」里，关掉自动管理后把允许自启动、关联启动、后台活动三项都勾上）；
3. 进 Gmail / WhatsApp 自己的设置，确认应用内通知权限已开。

三项都开过仍整段收不到，切一下网络再观察——推送链路同样依赖网络可达。

## 三、打开就闪退

1. 先升级到新版本；
2. 清缓存：「设置 → 应用 → 应用管理」→ GBox → 存储 → 清空缓存（不删沙箱内数据）；
3. 核对系统版本：EMUI 14+ 或 HarmonyOS 4.x，纯血鸿蒙 NEXT 不适用（见[华为手机装谷歌服务的几种办法.md](华为手机装谷歌服务的几种办法.md)）;
4. 重启设备再开。

四步走完还闪退，多半是机型兼容问题，等版本更新；别拿「卸载重装」碰运气——卸载会清空整个沙箱。

## 四、应用提示 License 校验失败

个别授权校验类应用启动报错时按顺序试：沙箱内退出谷歌账号重登 → 卸载该应用回商店重装 → 确认 GBox 为新版本。

## 五、其他容易忽略的点

- **登录报「与谷歌服务器通信失败」**：先直接重试；不行就点 GBox 首页右上角的清理图标清进程再试；仍不行，「设置 → 重置虚拟机」是最后手段——重置会清空沙箱，先备份；
- **附件一直「上传中」**：旧版问题，升级后重试；
- 界面入口对不上时，[GBox 介绍站](https://gbox.bmww.store/)的截图区可以看到设置与菜单的实际样子。

装好只是开始，推送稳不稳取决于后台权限那几步——装完就照第二节检查一遍，能省掉后面九成的「怎么收不到消息」。
