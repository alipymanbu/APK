# 在手机上做游戏这条路怎么走

> 用安卓手机跑 Godot 编辑器做游戏，到底靠不靠谱？这篇把可行范围、需要的装备与真实约束摆出来，再给一条能落地的路线。
> **相关文档**：[安卓下载引擎版本怎么选.md](安卓下载引擎版本怎么选.md) · [插件和素材资源怎么装进工程.md](插件和素材资源怎么装进工程.md)

---

## 一、可行性先说清

手机上跑 Godot 引擎是可行的，但要认清定位：引擎项目方把安卓编辑器标注为**实验阶段**，稳定度与效率都不如桌面版。它适合的场景是——

- 随时随地改场景、调脚本、跑小 demo；
- 学引擎时的碎片时间练习（跟着中文教程一步步走）；
- 已有桌面工程的补充管理：手机上看看、改改。

正经出活的重头戏，仍然建议回桌面端完成。

## 二、装备与工具

1. **一台像样的安卓手机**：OpenGL ES 3.0 或 Vulkan 兼容的机型即可，存储预留几个 GB（引擎版本单个数百 MB）；
2. **外接键盘鼠标**：编辑器 UI 未针对触屏适配，配一套键鼠（蓝牙或有线都行）才算可用的开发环境；
3. **平台应用**：装一个 GodotHub 这类社区工具 App，把引擎版本、工程管理、插件资源与中文教程收在一处，省去到处找下载源的功夫——它的安卓端情况可以看这份 [GodotHub 介绍页](https://godothub.gltd.quest/)。

## 三、能落地的路线

1. 装平台应用 → 在引擎模块下载一个 4.x 稳定版；
2. 新建 2D 或 3D 工程，选好引擎版本；渲染器选 **Mobile** 或 **Compatibility**（Forward+ 在部分手机上表现不佳）；
3. 跟着入门教程搭一个小场景，写几行 GDScript 跑起来；
4. 想装插件、找素材时按适配版本筛选（见 [插件和素材资源怎么装进工程.md](插件和素材资源怎么装进工程.md)）；
5. 做出成绩后要出安装包给别人试玩，用预设模板导出 APK 就行；走 Gradle 构建需要另装 GABE 配套应用。

## 四、三条会挡路的约束

- **C# / .NET 不可用**：安卓编辑器不含 C# 支持，C# 工程回桌面端；
- **键盘输入有坑**：部分手机键盘写脚本会随机插字符，换主流输入法（如 GBoard）可绕开；
- **后台恢复问题**：开发者选项开了「不保留活动」时，编辑器切后台可能无法正常恢复，改用默认设置更稳。

把这些边界记在心里，手机就是一台合格的「随身开发机」。想看平台应用的功能构成与界面，[GodotHub 介绍页](https://godothub.gltd.quest/) 里有截图与模块说明；下载引擎的版本选择细节则见 [安卓下载引擎版本怎么选.md](安卓下载引擎版本怎么选.md)。
