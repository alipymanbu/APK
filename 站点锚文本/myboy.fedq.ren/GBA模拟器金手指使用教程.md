# GBA 模拟器金手指使用教程

> 在安卓上重温 GBA 游戏时，金手指是老玩家最常翻出来的功能：本文按「建码 → 启用 → 排查」的顺序把 My Boy! 的金手指用法讲一遍，码不生效时对着排查表逐条对号。
> **相关文档**：[GBA游戏文件格式与放置方法.md](GBA游戏文件格式与放置方法.md) · [GBA模拟器即时存档与联机教程.md](GBA模拟器即时存档与联机教程.md)

GBA 时代流传下来的金手指码数量庞大，My Boy! 可以直接在游戏里加载使用。工具入口在模拟器安卓版的 [myboy 模拟器介绍页](https://myboy.fedq.ren/)有更完整的整理，本文聚焦金手指本身。

## 一、支持哪些码制

三类常见 GBA 金手指码都在支持范围内：GameShark、Action Replay、CodeBreaker。新建金手指时应用会按代码格式自动识别码制，玩家要做的只是选对「与手上这份游戏文件匹配的码」；一条金手指里还可以写多行代码。

## 二、新建并启用一条金手指

1. 运行游戏后打开模拟器菜单，进 Cheats（金手指）；
2. 新建，填一个自己认得出的名字，把代码粘贴进去；
3. 保存后回到金手指列表，勾选启用；
4. 回到游戏验证效果；游戏运行中随时可以回来开关某条码。

金手指跟着「游戏」记录，换一个游戏，列表互不串扰。

## 三、码不生效，按这个顺序查

| 现象 | 常见原因 |
| --- | --- |
| 勾选了但没效果 | 码的版本对不上：美版、日版、欧版 ROM 的码不通用，找码时先确认与游戏文件同版本 |
| 开码后死机、花屏 | 码本身有误，或与其他已启用的码冲突；全部关掉再逐条开，定位问题码 |
| 效果过一阵消失 | 部分码只在触发场景生效，或需要重启游戏才写入 |

## 四、动手前先落一个即时存档

任何一条码启用前，先存一个即时存档——坏码导致的死机、存档异常，读档就能全身而退，存档操作见 [GBA模拟器即时存档与联机教程.md](GBA模拟器即时存档与联机教程.md)。来源不明的码不要一次全开，逐条验证最省事；还没装模拟器的，先看 [GBA游戏文件格式与放置方法.md](GBA游戏文件格式与放置方法.md) 把运行环境搭起来。
