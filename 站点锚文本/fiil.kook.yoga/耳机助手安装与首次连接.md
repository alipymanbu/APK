# 耳机助手安装与首次连接

fiil+ 这类耳机配套 App 的安装过程比普通应用多两道弯：安装包来自网盘而非应用商店，需要放行「未知来源」；首次打开要授对权限，否则搜不到耳机。本篇按实际操作顺序整理，装好后的排查问题见 [耳机搜不到与连不上的排查.md](耳机搜不到与连不上的排查.md)，装之前想先了解这个 App 能做什么，可以看 [fiil+ 介绍站](https://fiil.kook.yoga/) 上的功能构成与界面速览。

## 一、拿到安装包

安装包经夸克网盘分享分发：打开分享页，把文件转存到自己的网盘空间，再用网盘 App 下载到手机本地存储。下载完成后在「文件管理」或通知栏里能找到这个 apk 文件。

## 二、放行未知来源安装

点开 apk 时系统会询问是否允许「来自此来源的应用」，选允许后继续。各品牌的入口叫法不同：

- 多数机型：安装弹窗里直接授权，一次有效
- 原生 Android：设置 → 应用 → 特殊应用权限 → 安装未知应用
- 华为 / 荣耀：设置 → 安全 → 更多安全设置；部分新机型要先关闭「纯净模式」
- 小米 / OPPO / vivo：多数在安装弹窗内授权即可

## 三、首次打开的权限取舍

fiil+ 会申请若干权限，每项对应一个具体功能。急着连耳机的话，先只给最关键的一项：

| 权限 | 干什么用 | 不给会怎样 |
| --- | --- | --- |
| 附近设备 / 位置 | 搜索、连接蓝牙耳机 | 多数手机上搜不到耳机 |
| 相机 | 扫序列号二维码注册产品 | 只能手输序列号 |
| 短信 | 注册时收验证码 | 验证码要切出去看 |
| 录音 | 语音搜歌 | 语音功能不可用 |

权限随时可以补：设置 → 应用 → fiil+ → 权限，用到哪项给哪项。

## 四、第一次连接耳机

1. 确认耳机电量充足（新耳机建议先充 10 分钟以上）。
2. 让耳机进入配对状态——注意「开机」不等于「可被搜索」，多数型号要长按功能键到指示灯闪烁。
3. 打开 fiil+，在型号列表里选择自己的耳机系列（如 Diva、FIIL、Carat），按提示完成连接。
4. 连上后 App 会显示电量与连接状态，之后就能进设置页调音效、定按键了。

连接失败不要急着重装 App，先按 [耳机搜不到与连不上的排查.md](耳机搜不到与连不上的排查.md) 逐项过一遍，大部分情况是配对状态或旧记录的问题。
