# 音效调节与固件升级笔记

耳机连上配套 App 之后，日常打交道最多的两件事：调出顺耳的声音、把固件升到最新。这两件事都有几个值得记住的细节——EQ 不是拉得越狠越好，固件升级中途断连比不升级更麻烦。本篇是使用习惯层面的整理，App 本身的安装与首次连接见 [耳机助手安装与首次连接.md](耳机助手安装与首次连接.md)，功能全景可以看 [fiil+ 介绍站](https://fiil.kook.yoga/)。

## 一、EQ：从预设起步，再考虑手动

fiil+ 里现成的选择就不少：3 组内置调音、12 种按曲风细分的预设，覆盖大多数人的听感需求；都不满意再进 5 段自定义手动拉频段。

两条实用思路：

- **人声闷、听不清歌词** → 抬中高频段
- **低音轰头、混成一片** → 压最低频段，别一味加低音

调 EQ 没有标准答案，边放自己最熟的那首歌边拉，变化立刻能听出来。

## 二、场景模式：按环境切换，别一个模式用到黑

带主动降噪的型号里，模式选择比 EQ 更影响日常体验：

| 场景 | 建议 |
| --- | --- |
| 地铁、公交（持续噪声） | 开降噪 |
| 过马路、等叫号（要听环境） | 切兼听 / 开放，别一直闷着 |
| 骑行、大风天（风噪明显） | 切风中模式，比调低音量管用 |
| 看视频、打游戏（声画不同步） | 开低延时模式，听完记得关（声音会变薄） |

还有一个总开关式的坑：这类设置「仅适用于蓝牙模式」，耳机不在蓝牙连接状态下，App 里怎么调都不会生效。

## 三、固件升级：规矩不多，条条要守

App 检测到新固件会弹窗提示，按「更新 → 立即升级」的提示走即可。过程中只有几条规矩：

1. **左右耳机保持在充电盒外面**——放回盒里升级会失败
2. **别离开升级页面**，等进度走到 100% 再退出
3. 升级前确认电量充足，手机别锁屏太狠（部分手机会限制后台活动）
4. 中途断连不用慌：重新连上耳机，App 会再次提示更新，从头来一遍就行

## 四、顺手可做的两件事

- **煲机**：App 内置煲机信号源，而且不挑品牌，别家的新耳机也能用它煲。做法是让耳机保持连接、放桌面上播放信号一段时间，期间别戴耳朵上，音量中等。
- **产品注册与序列号登记**：在 App 里扫码或手输序列号即可完成，后续查保修、验正品都用得上。
