# 我的世界基岩版 addons 怎么导入：从安装包到游戏里生效的完整路径

> 想在手机版《我的世界》里用上模组，卡点通常不在下载，而在「导进去了却没效果」。本篇按「取包 → 导入 → 激活」的顺序把整条路径走一遍，安卓与 iOS 的差异、常见失败点都在里面。
> **相关文档**：[mcpack和mcaddon有什么区别.md](mcpack和mcaddon有什么区别.md) · [手机版我的世界模组资源怎么选.md](手机版我的世界模组资源怎么选.md)

## 一、先确认版本：这套流程只服务基岩版

手机上的《我的世界》、Windows 基岩版、主机版都属于基岩版，模组以 Add-Ons 形式发行，用 `.mcpack` / `.mcaddon` 文件分发；Java 版（电脑原版）的 mod 体系完全不同，两者不可混用。按 Mojang 帮助文档的口径，Add-Ons 功能需要 PE v0.16.0 及以上——导入前先把游戏本体更新到能用的版本，避免白忙一场。

## 二、导入：两条设备两条路

| | 安卓 | iPhone / iPad |
| --- | --- | --- |
| 文件落地 | 下载到本地存储（下载目录好找） | Safari 下载后用「文件」App 找 |
| 打开方式 | 文件管理器里点开文件 | 点开后选「Copy to Minecraft」 |
| 游戏反应 | 自动拉起游戏，顶部出现导入提示 | 游戏自动启动并导入 |
| 成功标志 | 「Successfully imported」提示 | 同左 |

两种路径殊途同归：系统把文件交给游戏，游戏解包收进自己的资源库。看到成功提示就可以退出导入环节了——但注意，这只是「入库」。

## 三、激活：导入成功不等于已经启用

这是最常见的一步之差：资源已经在游戏里，世界里却什么都没变。原因是 Add-Ons 按「世界」启用，导入只完成了一半：

1. 回到主菜单的世界列表，选中目标世界，点铅笔图标进入编辑；
2. 往下翻到「资源包」与「行为包」两栏；
3. 在「可用」侧找到刚导入的包，点它移到「启用」侧；
4. 保存后进入世界，改动才会真正生效。

行为包（改生物、掉落、机制）与资源包（改外观、音效、材质）可以只开其一，按资源说明决定。给已有存档开行为包前建议备份世界——改动写进存档后，关掉包也可能留下痕迹。

## 四、导入失败对照表

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 点文件没有「用 Minecraft 打开」的选项 | 文件关联丢失 | 在游戏内资源导入入口重试，或改用分享菜单里的 Copy to Minecraft |
| 导入中途失败 / 报错 | 文件不完整或游戏版本过旧 | 重新取包；先更新游戏本体再导 |
| 导入成功但世界里没变化 | 没激活 | 回到第三节，把包在世界设置里启用 |
| 大版本更新后模组失效 | 旧包不兼容新版本 | 等资源作者更新包体，或先在旧版本存档里玩 |

## 五、省事的做法：用资源库应用一步到位

手动找包、手动导入的流程对新手偏繁琐。更顺的路子是装一个专门的资源库应用：在里面挑好资源点安装，导入游戏这一步它替你做掉，剩下的只有激活。安卓上这类应用以 APK 分发，挑一个资源全、更新勤的即可——选型时该看什么，见[手机版我的世界模组资源怎么选](手机版我的世界模组资源怎么选.md)；格式细节看[mcpack和mcaddon有什么区别](mcpack和mcaddon有什么区别.md)。想直接上手的话，这份基岩版 addons 资源库指南把应用安装与四步导入流程写成了操作页：[addons 使用指南](https://addons.gkhf.beer/)。
