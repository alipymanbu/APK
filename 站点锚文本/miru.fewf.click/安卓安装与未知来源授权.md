# Miru 安卓版安装与未知来源授权

> 讲安卓手机怎么拿到 Miru 的安装包、四步装上、被系统拦下时怎么放行，以及装不上时的排查顺序。加源与第一次观看的流程见 [扩展源添加与首次观看](扩展源添加与首次观看.md)，两个同名应用的区分见 [同名播放工具怎么区分](同名播放工具怎么区分.md)。

## 一、安装包从哪里拿

安卓端是一个 APK 安装包，经网盘分享获取：先把文件转存到自己的网盘账户，再从网盘取回本机。安装文件资源入口与图文步骤都整理在 [Miru 扩展源应用介绍站](https://miru.fewf.click/) 的下载页里，照着页面的顺序操作即可。

## 二、四步装完

1. 打开分享页，把 APK **转存到自己网盘**再下载——直接下分享里的文件容易中断；
2. 下载完成后从通知栏或文件管理器点开 APK；
3. 系统提示「禁止安装未知来源应用」时，按下一节的方法放行；
4. 安装进度走完点「打开」，进入浅色的主界面，底部是首页、搜索、扩展、设置四个入口。

## 三、未知来源授权怎么开

放行的对象不是 Miru 本身，而是**你用来打开 APK 的那个应用**（浏览器或文件管理器）：

1. 在安装被拦的弹窗里点「设置」，或在系统设置里搜「安装未知应用」；
2. 找到刚才下载 APK 所用的浏览器或文件管理器；
3. 打开「允许从此来源安装」开关，返回重试安装。

各品牌手机的菜单叫法略有差异，找不到时优先用系统设置里的搜索功能。

## 四、架构包怎么选

按手机处理器选对应的包，选错会装不上：

| 包名后缀 | 适用设备 |
| --- | --- |
| arm64-v8a | 近几年的绝大多数手机，不确定就选它 |
| armeabi-v7a | 年份较早的老设备 |
| x86_64 | 安卓模拟器、少数平板 |

## 五、装不上或打不开的排查顺序

1. 确认手机系统是 Android 5.0 或更高，低于这个版本无法运行；
2. 安装中断或提示解析失败，多半是包没下完整——回网盘重新下载一遍再装；
3. 授权后仍然被拦，重启一次手机再试；
4. 装完闪退，先检查是否选错了架构包，换包重装。

装好之后先别急着搜片名，Miru 的内容要靠扩展源接入，接着看 [扩展源添加与首次观看](扩展源添加与首次观看.md)。
