# Miru 扩展源添加与首次观看

> 讲 Miru 的内容从哪来：扩展源是什么、去扩展页怎么加、第一次搜索观看怎么做，以及 AniList 追踪这类设置的入口。安装步骤见 [安卓安装与未知来源授权](安卓安装与未知来源授权.md)，装之前想先认清同名应用见 [同名播放工具怎么区分](同名播放工具怎么区分.md)。

## 一、内容不在应用里，在扩展里

Miru 本身不内置任何片库：不同的站点与来源被封装成一个扩展，装上哪个扩展，应用里就多出哪类内容。视频、漫画、小说都是这样接入的，这也是它和普通播放器最大的差别——你想看什么，取决于你加了什么源。

扩展由 QuickJS 引擎运行，写一份 JS 扩展就能描述一个来源怎么搜索、怎么取内容；不想自己动手的话，自带的扩展仓库里已经有现成的视频源。

## 二、加源三步

1. 打开底部导航的「扩展」页（拼图图标）；
2. 从仓库里挑需要的源，想用别人整理的仓库，就在设置里填入自定义扩展仓库地址；
3. 启用后回到搜索页，新增的内容类型就会出现。

网络环境也可以自己调：设置里的「网络」支持配置代理与 User-Agent，扩展仓库地址同样能换成自己维护的那份。遇到某些源加载慢，先从这两处下手。

## 三、第一次观看与进度记录

源启用后，搜索一部想看的作品，点开就能在线播放。播放默认用内置播放器，设置里可以换成更顺手的；遇到 BT 种子类来源，由应用内的 BT Server 组件负责在线播放。看完退出，首页会记下条目与进度——下次直接从首页接着看，不用再翻一遍。

## 四、追踪与条目信息

- **AniList 追踪**：在设置页的「追踪」里登录 AniList 账号后，在看进度可以同步过去，不登录也不影响正常观看；
- **条目信息**：影视资料的封面与简介取自 TMDB，支持多语言，中文界面在设置里就能切换。

## 五、加不了源、搜不到东西的检查点

1. 扩展页里源是否处于启用状态；
2. 自定义仓库地址是否填对，仓库里是否真的包含你要的类型；
3. 代理设置是否与当前网络冲突，先关掉代理再试一次；
4. 换一个源交叉验证——只有某一个源搜不到，问题多半在那个源本身。
