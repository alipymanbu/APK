# 视频背景音怎么抽出来做成手机铃声

刷到一段视频，里面的 BGM 或配音特别对味，想留下来当铃声——这件事在手机上就能完成，不用开电脑。整条路分两段：先把声音从视频里抽出来，再把喜欢的片段剪成铃声。

## 第一段：把声音从视频里抽出来

先确认素材在哪。视频已经在手机相册里的话最省事；如果只是收藏了链接，先想办法把视频本体存到本地，后面才有东西可抽。

抽声音用「音频提取」类功能：选定视频，应用会把音轨原样抽出来，存成独立的音频文件。抽出来的就是完整的原声，时长和视频一致，画质无关、只听声音的话损失很小。

以安卓上的 medly 为例，它的功能主页里就有音频提取入口，选视频、等进度走完，音轨就躺在文件列表里了，后续的剪辑也在同一个应用里接着做（这款应用的整理介绍见 [medly安卓版下载](https://medly.boop.uno/)）。

## 第二段：剪出铃声那段

铃声不用长，来电铃声 30 到 40 秒足够。剪的时候几个细节决定成品好不好用：

- **开头直接进正题**。响铃的前两秒最关键，别留静音或前奏铺垫，掐在副歌进入的那一下最好；
- **手动输时间点更准**。拖起止点适合粗剪，看准波形后手动输入起始秒数，比来回拖更稳；
- **导出选 MP3**。几乎所有安卓手机的铃声列表都认它，省去再转格式的麻烦；
- **剪完先试听一遍**，确认没有半句被掐断、结尾收得干净。

## 第三段：设进系统

导出的音频文件要靠系统设置才能成为铃声，通用路径是「设置 → 声音与振动 → 来电铃声」，选择从本地音乐挑选刚才那段。几个常见变体：

| 想改什么 | 去哪设 |
| --- | --- |
| 来电铃声 | 设置 → 声音与振动 → 来电铃声 → 本地选择 |
| 通知 / 短信音 | 设置 → 声音与振动 → 通知铃声 |
| 闹钟 | 时钟应用内单独设置 |
| 某个人的专属铃声 | 通讯录 → 联系人详情 → 铃声 |

两个容易扑空的地方：微信、QQ 这类应用的消息音要在各自应用里改，动系统通知音不影响它们；部分品牌的「本地音乐」入口藏在铃声选择页的二级菜单里，找不到就先用文件管理器把音频挪进 Music 目录再选。
