# 一句话让 AI 做表格与清洗数据的方法

> 本篇讲 ChatExcel 手机版的核心用法：怎么把表格任务说给 AI、指令怎么写才一次到位、结果怎么核对。
> **本站相关文章**：[用聊天做表格的AI工具.md](用聊天做表格的AI工具.md) · [安卓版安装步骤与登录问题.md](安卓版安装步骤与登录问题.md)

ChatExcel 的用法不是自己拉公式，而是**把要求说给它听，它做完给你结果**。装好登录后（没装的先看 [安卓版安装步骤与登录问题.md](安卓版安装步骤与登录问题.md)），从菜单进「开始对话」，流程就四步：传表 → 说要求 → 等它跑 → 拿结果。

## 首页那些入口都是干嘛的

App 首页把高频操作做成了图标，点进去或直接在对话框里说同类要求都行：

| 入口 | 实际用途 |
| --- | --- |
| 数据清洗 | 删空白单元格、统一格式、批量补单位符号 |
| 智能运算 | 加总、求平均、按条件算提成，不写公式 |
| 智能数据分析 | 按维度汇总、找异常值、给分析结论 |
| 数据可视化 | 一句话生成柱状、折线、饼图等图表 |
| 交叉对比 | 两张表对差异、两组数据横向比 |
| 数据分类替换 | 批量把「北区/北方」统一成「华北」这类替换 |
| 智能判断 | 按条件整列打标：达标与不达标、优先级 |
| 自动纠错 | 揪出写错、格式不一致的单元格 |
| 多表分析 | 多个 Sheet、多个文件放一起处理 |

## 指令四要素：对象、动作、条件、输出

写指令把这四件事说清楚，命中率最高：

- 动哪列哪行（对象）；
- 做什么（动作）；
- 按什么规则（条件）；
- 要表格还是图表（输出）。

对比一下：

- 接不住的说法：「帮我处理一下这个表」—— 它不知道你要什么；
- 一次干对的说法：「把 A 列和 B 列相加，结果放在 C 列」「按地区分组算销售总和，用柱状图展示」「把所有日期统一成 2026-09-23 这种格式」。

几个实用技巧：

1. **一次说一件事**，多个要求分多轮逐条下，不容易漏；
2. **带上列名**，「销售额列」比「右边那列」稳；
3. **让它复述口径**，算完让它用一句话说明按什么规则算的，方便核对；
4. **结果不对就补条件**，比如「只统计 2026 年的数据」，不用推倒重来。

## 结果怎么核对与使用

处理结果在线查看、确认后可下载为 Excel 文件。建议抽查几行，确认计算口径和预期一致再拿去用 —— AI 理解的条件偶尔和你想的有出入，多轮对话里补一句就能修正。
