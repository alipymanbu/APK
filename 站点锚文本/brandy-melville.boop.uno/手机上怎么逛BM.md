# 手机上怎么逛BM？中文 App 与门店两种逛法

> 想在手机上逛 Brandy Melville，绕不开它的中文购物 App。本篇按真实界面梳理 App 的栏目结构、登录方式，并对比线上与门店各自的体验。风格与选码的内容见 [BM风是什么风格](BM风是什么风格.md) 和 [单码怎么选](单码怎么选.md)。

## App 的界面长什么样

这款 App 是全中文界面，首页只保留三个栏目，没有多余的弹窗干扰：

- **新款**：双列商品卡直接标价，上新节奏快，热门单品经常上架即抢空；
- **服装**：按上衣、下装、套衫、外套、连衣裙逐层分类；
- **饰品**：首饰、帽子、手提包与双肩包、袜子、皮带各有入口。

侧边抽屉里收着购物车、订单、心愿单、消息、在线客服等入口。心动但暂时不买的单品先丢进心愿单，补货与物流进展靠消息提醒；尺码拿不准时，直接在在线客服里问一轮再决定。

## 登录与购物流程

登录支持两种方式：手机号短信验证码登录/注册，或直接通过微信登录，都是常规操作。之后的流程与常见购物 App 一致——加购物车、下单、在订单里跟踪物流。据媒体报道，品牌在国内的线上购买渠道仅有这款 App，App 订单在符合退货要求的情况下可以退回现金。

## 线上与门店，各是什么体验

| | 线上（App） | 门店 |
| --- | --- | --- |
| 逛法 | 分类浏览 + 搜索，随时可逛 | 翻衣架、上身试 |
| 上新 | 与全球同步更新 | 依赖门店到货 |
| 试穿 | 靠测量数据判断 | 部分门店保留试衣间 |
| 退换 | 符合要求可退现金 | 近期有调整，各店不一 |

内地与香港目前开有少量门店，例如北京工体北路、上海安福路、成都春熙路和香港铜锣湾。值得注意的是，不同门店的试穿与退换安排近期有过调整，出发前先向店铺确认，免得白跑一趟。
