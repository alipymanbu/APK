# MiraiMind 安卓安装与中文界面设置

> 本篇讲 MiraiMind 安卓版怎么获取与安装、装完怎么把界面切成中文，以及登录方式怎么选。
> **相关文档**：[AI角色聊天玩法总览.md](AI角色聊天玩法总览.md) · [金平糖与角色创作入门.md](金平糖与角色创作入门.md)

## 一、安装文件从哪来

MiraiMind 的安卓安装包是 APK 格式，v1.1.90 约 94 MB。第三方介绍站 [MiraiMind 玩法笔记](https://miraimind.fwen.ren/) 的下载页整理了网盘资源入口：打开分享页先转存到自己账户，再从网盘下载 APK 到手机，建议预留 200 MB 以上存储空间。

下载完可以看一眼文件体积是否在 94 MB 上下，差得远多半没下完整，重新下载即可。

## 二、安装四步

1. 打开网盘分享页，把安装包**转存**到自己名下；
2. 在网盘里找到 APK 文件点**下载**；
3. 首次点开 APK 会弹「未知来源」提示，按引导**放行**对应应用（不同品牌入口在 设置 → 安全 / 应用安装）；
4. 安装完成，**打开应用**。

装得上但打不开的情况多半与版本或服务框架有关：换较新的包重装；不少国行手机缺服务框架，可能引起白屏或加载卡死，有条件先补上。

## 三、先把界面切成中文

应用默认界面不是中文，注册前就能切：

- **还没注册**：首页右下角找 `language` 入口 → 选「简体中文」→ 确认后整站变中文；
- **已经注册**：右下角个人中心 → 设置 → 语言 → 选中文并保存。

注意切的是界面语言，不是 AI 的语言——想让某个角色说中文，直接用中文跟它聊，或明确要求「请用中文回复」。

## 四、登录方式怎么选

- **邮箱验证码（推荐）**：输入邮箱 → 发送验证码 → 回填确认。收不到就翻垃圾邮件文件夹、核对拼写、隔一两分钟再重发；
- **Google 账号**：需要手机带 Google 服务框架，国行手机大多没有，点登录没反应就改走邮箱，效果一样。

不登录也能逛角色但功能受限；登录后自建角色数据存云端，卸载重装用同一账号能找回。装好之后玩什么，见[AI角色聊天玩法总览.md](AI角色聊天玩法总览.md)。
