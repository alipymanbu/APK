# 文生视频提示词怎么写

> 同一个工具，不同人写描述，成片差距能大到像换了个产品。这篇讲文生视频提示词的通用写法：结构怎么搭、哪些词真正影响画面、失败时怎么改。

---

## 一条能用的描述长什么样

文生视频的描述不需要文笔，需要的是**信息完整 + 顺序合理**。一条稳的描述通常按这个顺序组织：

```
主体 + 动作 + 环境 + 镜头 + 氛围
```

举例对比一下：

| 写法 | 描述 | 大概率结果 |
| --- | --- | --- |
| 太空 | 一只猫 | 随机场景里的猫，动作随机 |
| 太满 | 一只橘色的猫在黄昏的东京街头奔跑，霓虹灯反射在湿地面上，电影感运镜，浅景深，胶片颗粒，8K | 信息过载，渲染容易顾此失彼 |
| 合适 | 一只橘猫在雨后街头小跑，霓虹灯倒映在湿地面，镜头低角度跟拍 | 主体、动作、环境、镜头各就各位 |

「合适」那一档的核心：**一句话只说一个主镜头**，想要的多余细节宁可不写。

## 真正影响画面的几类词

不是所有词都值得写。经验上这几类最见效：

1. **镜头语言**：低角度跟拍、缓缓推进、环绕、俯拍——决定整条的观感基调。
2. **光线**：黄昏侧光、霓虹夜色、阴天漫射光——比任何滤镜词都管用。
3. **动作幅度**：小幅动作（转头、眨眼、风吹）远比大幅动作（奔跑打斗）稳定，幅度越大越容易崩。
4. **风格锚点**：电影感、纪录片、老录像带——一个词就够，别叠三个风格词互相打架。

「8K、超高清」这类画质词对生成质量帮助有限，分辨率是参数档位决定的，不是描述决定的。

## 出错了往哪改

描述本身没写错、成片却不理想时，按症状改：

- **主体变形** → 换动作幅度更小的描述；人脸特写最容易崩，先从半身镜头练。
- **画面乱** → 砍掉一半形容词，只留主体 + 动作 + 一处环境。
- **动作没跟上** → 把动作写具体（「小跑」「回头」），别写抽象状态（「开心的」「活泼的」）。

改描述是逐次收敛的过程：每次只改一处，跑一次看结果——这也是省免费额度的正确姿势，见[AI视频生成免费额度怎么用.md](AI视频生成免费额度怎么用.md)。

## 从文字到照片的下一步

描述练熟之后，文生视频和图生视频是相通的：图生视频相当于「用一张照片代替主体与环境，只描述动作」。两条路都想走通的话，可以看[照片动起来用什么App.md](照片动起来用什么App.md)。

工具选择上，文生视频能力集中在主流 AI 视频应用里，手机端够用。以 [PixVerse](https://pixverse.ggcd.online/) 为例，文生视频、图生视频、模板特效是三个并列入口，描述写法在这三个入口通用；它的介绍站把入口逻辑、出片速度和安装方式整理在了一起，动手前可以先过一遍。
