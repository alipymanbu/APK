> 想在安卓手机上离线听本地音乐，选播放器主要看哪几点？这篇把常见的坑列出来，再说说 Pulsar 为什么值得排在候选名单前面。

## 一、先想清楚自己的用法

本地播放器的取舍其实很集中，挑之前先问自己三个问题：

1. **手机里有没有现成的音乐文件**。歌曲都存在手机或 SD 卡里，才谈得上本地播放器；只听在线曲库的话，这类工具帮不上忙。
2. **在不在乎广告**。不少免费播放器靠开屏广告和播放页横幅变现，歌单越长广告越多；也有像 Pulsar 这样走无广告路线的，定位就是安静放歌。
3. **要不要"重功能"**。均衡器、音效插件这类高级功能往往锁在付费版里；如果日常就是放歌、看歌词、建歌单，轻量播放器的免费版已经够用。

## 二、挑播放器时值得核对的五点

| 核对点 | 为什么重要 |
| --- | --- |
| 支持的格式 | mp3、aac、flac、ogg、wav 是基本盘，flac 无损党的刚需 |
| 无缝播放 | 现场专辑、古典组曲中间不留空隙，听感完整 |
| 歌词显示 | 最好同时支持内嵌歌词和 .lrc 文件，老歌才有歌词可看 |
| 标签编辑 | 曲库乱多半是文件标签的锅，播放器里能直接改最省事 |
| 后台稳定性 | 被系统省电策略杀后台的播放器，听几首歌就得重新打开 |

## 三、Pulsar 在这份名单里的位置

Pulsar 是 Rhythm Software 出品的安卓本地播放器，安装包只有十几 MB，免费版无广告。它的强项正是上面那张表里的大部分条目：格式跟随系统解码、有无缝播放和交叉淡入淡出、歌词支持内嵌与 .lrc、内置标签编辑器，还有 Chromecast 投屏和 Android Auto 车载支持。它的功能取舍也很坦诚——免费版没有均衡器，五段均衡器、低音增强、混响都在付费的 Pro 版里，不用装完才发现。

它把 36 种语言、百万级下载量的体量做在一个轻量包体里，对"手机里存了一堆歌、只想有个清爽工具放歌"的用户来说，是比较典型的优选。
