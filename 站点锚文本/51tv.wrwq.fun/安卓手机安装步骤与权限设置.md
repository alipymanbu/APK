# 51TV 安卓手机安装步骤与权限设置

> 本篇讲把 51TV 装进安卓手机的完整过程：从网盘取包、放行未知来源、完成安装到首次打开，以及每一步容易卡住的地方。
> **相关文档**：[看剧卡顿换源与清晰度调整.md](看剧卡顿换源与清晰度调整.md) · [投屏电视观看条件与排查.md](投屏电视观看条件与排查.md)

装之前先对一眼硬指标：这一份 51TV 的包名为 `app.kanju.app`，分享版本 5.3.2、安装包约 55.79M，系统要求安卓 5.2 及以上。搜这个名字会混出不少同名的别的软件，名字和图标都靠不住，认包名最稳。

## 一、从网盘取安装包

安装包通过夸克网盘分享，入口在 [51TV 安卓看剧应用介绍站](https://51tv.wrwq.fun/) 的下载页。打开分享后建议先「保存到我的网盘」再下载：转存进自己账号后，原分享日后失效也不影响已经留下的这份。下载完成的通知栏里能直接点开文件，多数手机会把它放进「下载 / Download」目录。

## 二、放行「安装未知应用」

不是从应用商店装的包，安卓默认拦一次，要先给**负责下载它的那个应用**（浏览器或夸克）开安装权限：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 权限管理 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装外部来源应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 生物识别和安全 → 安装未知应用 |

记不住路径没关系，在设置顶部搜索框里搜「未知应用」或「外部来源」基本都能跳到同一页。常见错误是开关开给了这个影视应用自己——放行对象是下载工具，开错了到安装时还是会被拦。

## 三、点开 APK 完成安装

1. 从通知栏或文件管理器点开刚下载的 APK。
2. 安装界面点「安装」，等进度走完，桌面出现图标。
3. 首次启动会依次申请权限：存储（缓存与播放记录要用）、网络（打开内容的前提）、附近的设备（投屏搜电视要用），建议逐项允许；通知权限只影响推送，不给也不影响观看。

## 四、装不上时对号入座

- **被系统阻止安装** → 第二节的权限开错了对象，回头改给下载工具。
- **提示解析包错误** → 文件多半没下完整，回网盘重新下载，下载前核对文件名与大小。
- **装完点图标闪退** → 先确认系统不低于安卓 5.2；满足的话给应用清一次缓存再试，仍不行就卸载重装。
- **桌面没有图标** → 部分启动器把它收进了应用抽屉，去抽屉里翻一遍，实在没有就重装。

装好后想核对包名，到「设置 → 应用 → 全部应用」里找到它的应用信息页即可。更多日常使用中的播放、投屏问题，见[看剧卡顿换源与清晰度调整.md](看剧卡顿换源与清晰度调整.md)与[投屏电视观看条件与排查.md](投屏电视观看条件与排查.md)。
