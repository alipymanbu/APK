# 51TV 看剧卡顿换源与清晰度调整

> 本篇讲 51TV 播放不顺畅时怎么处理：为什么换播放源是最有效的一招、清晰度怎么选、倍速字幕弹幕在哪调，以及一串容易误判的情况。
> **相关文档**：[安卓手机安装步骤与权限设置.md](安卓手机安装步骤与权限设置.md) · [投屏电视观看条件与排查.md](投屏电视观看条件与排查.md)

这类影视应用的片库里，同一部片子往往挂着多条来源。由此有个很实际的结论：**卡顿、黑屏、只有声音、集数不全，绝大多数靠换一条源就能解决**，不用清缓存、更不用重装。

## 一、什么时候该换源，怎么换

换源入口在播放界面里，一般叫「换源」或「线路」，也可能就是几条并列的标签。出现下面这些情况就别等了：

- 缓冲圈转超过 10 秒不动；
- 某一集点开是黑的，同剧其他集正常（只换这一集的源）；
- 能播但清晰度明显偏低，另一条源同集有高清。

两个注意点：换源后如果回到片头，手动拖回进度即可；**别一次连点好几条源**，每条源都有连接时间，连点反而更容易卡。

## 二、清晰度不是越高越好

清晰度档位跟着源走：某条源本身没有高清，档位列表里就不会出现。经验是——

- **手机上看**：高清档足够，超清档在小屏上观感差别不大，对网络要求却高很多；
- **投到电视上**：反过来，大屏低清晰度的噪点很显眼，电视走家里宽带，调高一档更划算。

一直转圈、播一会儿才出画的，先降一档清晰度再观察。

## 三、倍速、字幕、弹幕

| 功能 | 位置 | 实际影响 |
| --- | --- | --- |
| 倍速 | 播放界面，通常与进度条同层 | 1.5 倍以上时部分源的字幕会对不齐 |
| 字幕 | 播放界面或右上角菜单 | 能否显示取决于这条源是否自带字幕文件 |
| 弹幕 | 播放界面的开关 | 想清静就一键关掉；发弹幕需登录，内容公开可见 |
| 亮度 | 播放界面边缘上下滑 | 调的是播放器内亮度，不改系统亮度 |

## 四、按现象快速排查

| 现象 | 先做这一步 |
| --- | --- |
| 一直缓冲、转圈 | 换源 |
| 黑屏但进度条在走 | 换源 |
| 只有声音没画面 | 换源 |
| 所有片子都打不开 | 换网络——这是网络问题，不是片子问题 |
| 掉帧、发烫 | 关省电模式、降一档清晰度 |
| 昨天能看今天不能 | 源会失效，过段时间再试，也可能有新源补上 |

晚上高峰特别卡与片子无关，是时段性的网络拥堵；缓存过的集数正常、新集数卡，也属正常——前者读本地、后者走网络。
