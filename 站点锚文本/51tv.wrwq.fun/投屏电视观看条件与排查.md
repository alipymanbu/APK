# 51TV 投屏电视观看条件与排查

> 本篇讲把手机上正在看的剧投到电视上：两个前提、具体点法、搜不到设备时查哪几条，以及投屏中途断开的处理。
> **相关文档**：[看剧卡顿换源与清晰度调整.md](看剧卡顿换源与清晰度调整.md) · [安卓手机安装步骤与权限设置.md](安卓手机安装步骤与权限设置.md)

小屏追剧不过瘾时，投屏是最省事的放大方案：手机当遥控器，画面走电视。51TV 的播放页里自带 TV 按钮，投屏本身不额外消耗流量，但它对网络稳定性的要求比手机本地播放高——手机播着不卡，不代表投出去也不卡。

## 一、先满足两个前提

缺一条，后面怎么点都不会成功：

1. **手机和电视连的是同一个网络。** 判断标准就一条：两台设备挂在同一个路由器下。手机开着热点、电视连家里 WiFi，或电视连的是光猫自带的另一路 WiFi，都不算同网。
2. **电视那头能收投屏。** 2016 年之后的智能电视多数自带（协议上叫 DLNA 或 Miracast，各品牌叫法不同）；老电视接个安卓盒子也行。拿不准就直接问电视品牌的客服，别在手机上反复试。

## 二、具体点法

1. 电视上打开投屏入口（海信、创维、TCL 等一般在「我的应用」里叫「无线投屏」「多屏互动」），停在等待连接界面。
2. 手机连上与电视相同的 WiFi。
3. 在播放页点画面上方或右上角的 **TV** 图标。
4. 设备列表里选中电视名称，等两三秒连上。
5. 连上后手机就是遥控器：拖进度、暂停、调音量、选集都在手机上操作。

如果电视上只是镜像了手机屏幕、画质模糊，说明走的是「屏幕镜像」而非应用内投屏——退出重连，从播放页的 TV 按钮进，那条路更省电也更清晰。

## 三、搜不到设备，按顺序查五条

| 顺序 | 查什么 | 怎么做 |
| --- | --- | --- |
| 1 | 是否同一 WiFi | 手机关掉移动数据，核对 WiFi 名与电视上一致 |
| 2 | 电视端入口开了没 | 让电视停在等待连接的界面 |
| 3 | 路由器 AP 隔离 | 登录路由器后台关掉「AP 隔离 / 客户端隔离」 |
| 4 | 局域网权限 | 手机的应用权限里给到「附近的设备 / 局域网」 |
| 5 | 重启一遍 | 电视盒子断电重开，手机 WiFi 重连再搜 |

五条走完仍搜不到，问题基本在电视那一端。想快速判断问题在哪端，用手机热点试：让电视连上手机热点再投一次，能投上说明是路由器的问题（多为双频或 AP 隔离）。

## 四、投屏中途断开、卡顿

| 现象 | 先查这个 |
| --- | --- |
| 画面不断缓冲 | 路由器旁别同时挂大文件下载；清晰度降一档 |
| 播一会儿自己断 | 手机锁屏后被深度省电冻结，把应用的省电策略放宽 |
| 有声音没画面 | 换一条播放源再投 |
| 画面有黑边、比例不对 | 电视遥控器上按「画面比例」切自适应 |

投屏时手机的「WLAN+ / 智能网络切换」最好关掉：信号一弱它自动切流量，投屏随即断开，而这个开关名字里不带「投屏」两个字，最容易被漏掉。

播放本身的卡顿换源思路见[看剧卡顿换源与清晰度调整.md](看剧卡顿换源与清晰度调整.md)；还没安装的，先看[安卓手机安装步骤与权限设置.md](安卓手机安装步骤与权限设置.md)，或到 [51TV 安卓看剧应用介绍站](https://51tv.wrwq.fun/) 看整理好的玩法一览。
