# 插件地址怎么找与怎么装

MusicFree 把「播放器」和「内容来源」拆开了：本体只管播放，能搜到什么全看装了哪些插件。所以拿到它之后的第一件事，就是给找一个可用的插件地址装上。

## 插件地址长什么样

插件地址就是一个普通的网址，通常以 `.json` 或 `.js` 结尾。`.json` 的一般是插件清单（里面列了若干个插件），`.js` 的则是单个插件本体。

## 去哪里找

几个常见的找法：

1. **项目自带的示例仓库**：开发者在 GitHub 上维护着 `maotoumao/MusicFreePlugins` 示例插件仓库，里面的插件基于公开接口封装，会过滤 VIP / 仅供试听的内容；
2. **社区聚合清单**：搜索「MusicFree 插件」「MusicFree 音源」能找到不少第三方维护的聚合清单页，一页列出多个地址，逐个试装即可；
3. **社区讨论区**：项目的 issue 区和相关话题帖里，常有用户分享自己验证过能用的地址。

注意：第三方插件请自己把关安全性，看见网络请求奇怪的、来路不明的地址就不要装；插件与其产生的数据和播放器本身无关。

## 装的四个动作

1. 打开首页左上角的侧边栏，进「插件设置」；
2. 点右下角的 **+** 号；
3. 选「**从网络安装插件**」；
4. 粘贴地址确认，列表里出现新插件就成功了。

装好后在插件设置页可以逐个开关，在线更新也在这一页完成。

更直观的分步图文版（含每一步的界面截图），可以看 <https://musicfree.gkhf.beer/> 首页的「四步把插件装上」一节。
