# 歌单整份搬家与歌词关联玩法

装好插件、能正常搜歌之后，MusicFree 还有几个不那么显眼、但用过就回不去的能力。这一篇挑两个最实用的说：歌单搬家和歌词关联。

## 歌单整份搬家

在原来的音乐应用里攒了几百首收藏，换播放器最舍不得的就是这份歌单。MusicFree 的做法是把它交给插件处理：

1. 在原来的应用里打开歌单，用「分享」复制一条歌单链接；
2. 回到 MusicFree，进「插件设置」；
3. 找到对应平台的插件，点开选「导入歌单」；
4. 把链接粘贴进去确认，歌曲就整份进来了。

不同插件支持的导入能力有差别（有的插件暂时只支持搜歌和播放），遇到「目标歌单为空」的提示，通常是那条分享链接的类型插件不认，换一种分享方式或换同平台的另一个插件试试。

## 歌词关联

冷门歌、翻唱、remix 版经常配不上歌词，MusicFree 给了个巧办法：手动把两首歌的歌词「关联」起来。比如把 A 歌的歌词挂到 B 歌上，之后 A、B 两首都会显示 B 的歌词，还能串起来挂（A→B→C，三首都显示 C 的）。在歌曲详情里就能操作，中文歌配 instrumental 版特别好用。

## 主题也值得一调

深色浅色两套模式之外，背景图、模糊度、透明度都能自己改——把播放页调成自己喜欢的样子，只需要几分钟。榜单浏览页也是常用的入口，按最近一天 / 一周 / 一月 / 全部切换着看趋势。

这两处能力在 <https://musicfree.gkhf.beer/> 的首页里都有带截图的展示，比文字更好对上号。
