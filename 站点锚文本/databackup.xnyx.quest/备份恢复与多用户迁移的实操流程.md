# 备份恢复与多用户迁移的实操流程

> 从指定目录、勾选应用，到恢复回本机、另一台手机甚至另一个用户——把一条完整链路拆成可核对的步骤，每一步做完都有明确的验收点。

**相关阅读**：[安卓应用数据备份工具怎么选](安卓应用数据备份工具怎么选.md) · [刷机换机前怎么备份应用数据](刷机换机前怎么备份应用数据.md)

---

## 一、备份：三步走完

以开源工具 DataBackup 为例（它的界面截图与安装入口见 [DataBackup 介绍站](https://databackup.xnyx.quest/)）：

1. **指定备份目录**：内置存储或自定义路径都行。先看剩余空间——几十个应用的完整备份上 GB 很正常；目录定下后就别再挪动改名，恢复时要指回同一位置；
2. **勾选应用**：列表里逐个或批量勾。游戏存档、聊天工具、要登录态的优先；系统应用大多重装就有，不备也行。支持多用户的设备可以在列表里切换用户，把分身里的应用一并纳入；
3. **开跑、核对**：完成后界面会给出备了多少个应用，点开逐个确认，有失败的单独重试那一个，不必整批重来。

## 二、恢复到本机（刷机、重置之后）

前提：设备重新 Root、工具重新装好、授权通过。然后按顺序：

1. 把备份目录放回手机（刷机没清掉内置存储就还在原位）；
2. 在应用里把备份目录指到这个路径；
3. 列表会读出已备份的应用，勾选要恢复的，执行恢复；
4. 恢复完去桌面核对：应用在不在、登录态和存档有没有跟着回来。

## 三、恢复到另一台手机

比本机恢复多两步搬运：旧机把整个备份目录拷出到电脑或 U 盘，新机拷入存储后指向该目录。**两台设备都要 Root**——备份动作发生在旧机那边，只 Root 新机做不了迁移。

## 四、恢复到另一个用户

多用户是这类工具的独门能力：备份时可以备任意用户的应用，恢复时也能把 A 用户的数据还原给 B 用户。工作资料、手机分身这类第二空间的迁移就靠它——在列表里切换用户视角，分别勾选恢复即可。

## 五、恢复后的验收清单

| 检查点 | 说明 |
| --- | --- |
| 应用能打开 | 闪退的多是架构变体装错，换对应变体重装 |
| 数据跟着回来了 | 聊天记录、存档逐个翻一眼，别只看图标在不在 |
| 登录态 | 强绑定设备的应用会要求重新验证，重登一次属正常，不是恢复失败 |
| 备份目录原样保留 | 恢复完先别删，全部核对无误再清理 |
