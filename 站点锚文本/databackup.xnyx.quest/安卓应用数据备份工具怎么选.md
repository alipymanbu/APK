# 安卓应用数据备份工具怎么选

> 想把聊天记录、游戏存档、应用登录态一起搬到新手机或熬过一次刷机，先把「备份的到底是什么」弄清楚，再挑工具才不会白忙。

**相关阅读**：[刷机换机前怎么备份应用数据](刷机换机前怎么备份应用数据.md) · [备份恢复与多用户迁移的实操流程](备份恢复与多用户迁移的实操流程.md)

---

## 一、先分清两种「备份」

安卓上的备份其实分两层：

- **应用本身**：APK 安装包，丢了随时能重装；
- **应用数据**：每个应用私有目录里的数据库、配置、登录态——聊天记录、游戏进度、账号会话都住在这里。

系统自带的备份方案大多只覆盖第一层，或者对第二层「看厂商实现」。真正让人心疼的恰恰是第二层：应用重装容易，数据回不来。

## 二、按设备条件挑方案

| 设备状态 | 适合的路线 |
| --- | --- |
| 未 Root，只想保常用数据 | 各家云服务 + 厂商自带备份，覆盖不到的私有数据只能放弃 |
| 已 Root（Magisk / KernelSU / APatch） | 直读私有目录的开源工具，应用连数据整体打包 |
| 只想临时搬一两个应用 | 部分应用自带的「聊天记录迁移」功能，逐个操作 |

已 Root 的设备里，DataBackup 是目前社区活跃度比较高的选择：开源（GPL-3.0）、无广告，备份产物用 zstd 压缩，还支持 WebDAV、FTP、SMB 三种云协议，它的功能说明与界面截图整理在 [DataBackup 介绍站](https://databackup.xnyx.quest/)。

## 三、挑工具时看这四点

1. **覆盖范围**：能不能连应用私有数据一起备，而不是只搬 APK；
2. **恢复路径**：备份目录是否自明、恢复时能不能指回同一位置；
3. **多用户**：手机分身、工作资料这类第二空间能不能一并纳入；
4. **产物归属**：备份文件落在谁手里——落在自己能拿到的目录或自建云上，比锁在某个服务里更稳。

## 四、选定之后

无论选哪条路线，都建议先拿一两个不重要的应用试跑一遍完整流程（备份 → 恢复 → 核对），确认方案真的能走通，再对聊天工具、游戏这些要紧应用下手。实操细节见 [备份恢复与多用户迁移的实操流程](备份恢复与多用户迁移的实操流程.md)。
