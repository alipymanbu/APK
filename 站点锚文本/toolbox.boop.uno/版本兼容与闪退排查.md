# 版本兼容与闪退排查

**本篇讲什么**：Toolbox 与《我的世界》携带版之间的版本配对问题——为什么旧版配新游戏会闪退、更新到哪个版本、装好以后还有哪些常见坑。相关阅读：[悬浮窗权限与M按钮设置](悬浮窗权限与M按钮设置.md)、[游戏内速调菜单功能详解](游戏内速调菜单功能详解.md)。

---

## 为什么版本要配对

Toolbox 的工作方式决定了它对游戏版本敏感：它要叠加在 Minecraft 本体上修改游戏内容，游戏每次更新都可能改动内部结构，Toolbox 必须跟着出新版才能对上。所以"旧版 Toolbox + 新版游戏"是最容易出问题的组合，典型表现就是点开闪退、黑屏，或者能进游戏但菜单点不动。

以实际更新记录为例：5.4.57 起支持游戏 1.20.80，5.4.58 以兼容修复为主。保持两边都新，是最省事的配对策略。

## 闪退了按什么顺序处理

1. **核对游戏版本**：设置 → 档案里能看到当前游戏版本号；
2. **更新 Toolbox**：换成最新收录版本再试，旧版配新游戏是闪退的最大来源；
3. **清缓存重启**：系统设置 → 应用 → Toolbox → 清除缓存，然后重新从 Toolbox 启动游戏；
4. **检查设备存储**：空间不足也会造成加载中途退出，留出至少 1~2 GB 余量更稳；
5. **重装兜底**：以上都无效时，先备份游戏世界存档，再重装游戏本体与 Toolbox。

## 装好后的两个高频小坑

- **菜单是空的**：几乎都是没装游戏本体或没从 Toolbox 启动，按 [悬浮窗权限与M按钮设置](悬浮窗权限与M按钮设置.md) 的顺序排查；
- **功能时灵时不灵**：多半是版本"擦边"——游戏刚更新而 Toolbox 还停在上一版。等新适配发布并更新即可，不必反复重装。

## 版本之外的话

Toolbox 由社区开发者 MCMrARM 维护，与 Minecraft、Mojang、Microsoft 无从属关系；它是一个需要配合游戏本体使用的修改层，不是独立游戏。获取最新安卓版安装文件，走 [Toolbox 专题站](https://toolbox.boop.uno/) 的资源入口即可。
