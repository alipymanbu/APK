# Toolbox 专题站收录页

这里是 Toolbox 安卓版的第三方介绍站收录页。Toolbox 是配合《我的世界》携带版（MCPE）使用的游戏内启动器与速调菜单：生存缺装备直接给物品、附魔一键拉满、X-Ray 照出矿脉、时间天气点两下切换。专题站按"一局游戏的进程"整理了它的功能场景、悬浮窗设置与版本兼容注意事项，入口在 [Toolbox 功能与安装指引](https://toolbox.boop.uno/)。
