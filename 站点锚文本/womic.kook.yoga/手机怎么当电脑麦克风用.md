# 手机怎么当电脑麦克风用

本篇讲清楚把安卓手机当电脑麦克风使用的整体思路：需要哪些组件、四种连接通道各自适合什么场合、连上之后怎么让系统里的软件认到这只「话筒」。想看图文并茂的版本，可到 [womic 图文介绍站](https://womic.kook.yoga/) 浏览。

---

## 先认识这套方案的组成

以 WO Mic 为例，它由三个部分配合：手机端 App 负责拾音并发送声音数据；电脑端客户端负责接收；再由一只虚拟设备驱动在 Windows 里模拟出名为 WO Mic Device 的标准录音设备。三件都就位后，会议、直播、录音软件都能把它当真麦克风来选。音频规格为 48000 Hz 采样率、16 bit、单声道，日常语音场景完全够用。

## 四种连接方式怎么选

| 方式 | 适合场合 | 前提条件 |
| --- | --- | --- |
| Wi-Fi | 日常语音、临时开会，最省事 | 手机和电脑连同一个路由器 |
| USB 数据线 | 直播、录音等在意延迟的场合 | 数据线 + 电脑装好手机驱动 + 手机开 USB 调试 |
| 蓝牙 | 没有路由器、又不想拉线的短距场景 | 两端先完成蓝牙配对 |
| Wi-Fi 直连 | 户外、完全没有路由器的环境 | 手机开出热点，电脑连这个热点 |

拿不定主意就先从 Wi-Fi 开始：手机 App 启动后面板会显示 IP 地址，电脑客户端填入这个 IP 即可连接；之后对延迟不满意再升级到 USB——它是四种通道里延迟最低、码率最高的一种。

## 连上之后的关键一步

不少人说「连上了但软件里没有麦克风」，多数是没把输入设备指过去：

1. 打开 Windows 设置 → 系统 → 声音，在输入设备列表里找到 WO Mic Device；
2. 把它设为默认录音设备，对着手机说话看电平条有没有反应；
3. Zoom、Discord、OBS 等软件的音频设置里，把输入设备也选成 WO Mic Device。

想直接验证拾音效果，客户端里有个本地回放选项（Play in speaker），勾上就能听到手机传来的声音。
