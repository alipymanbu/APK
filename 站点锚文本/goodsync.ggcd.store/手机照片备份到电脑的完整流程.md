# 手机照片备份到电脑的完整流程

> 本篇讲怎么把手机相册里的照片和视频，用 GoodSync 从安卓手机备份到电脑或 NAS：从手机端账户接入、建第一个单向备份任务，到之后让它自动跑起来。备份与同步的概念差异，见[双向同步和单向备份怎么选](双向同步和单向备份怎么选.md)；手机端还没装好的，先看[安卓版安装与电脑配对方法](安卓版安装与电脑配对方法.md)。

---

## 为什么照片备份要挑「单向」

照片的特点是只增不改：拍一张存一张，很少回头修改。这种内容用单向备份（Backup）最合适——手机端做源，电脑或 NAS 做目标，文件只从手机流向备份端。这样即使某天在手机上误删了一张照片，备份端那份还原样躺在那里，恢复有依据。

GoodSync 处理这件事的方式和其他工具不太一样：点执行之前，它会先做一次分析，把「哪几张是新增、哪张更新过、哪张已经不存在」逐条列成清单，确认没问题再动手。第一次跑是全量比对，之后每次只看变化的部分，几百张照片的差异几秒钟就能算完。

## 手机端要做的事

1. **接入存储**。打开应用里的 Accounts 页，把备份目标加进来：电脑走 Windows 共享（SMB），填电脑的地址、共享名和登录信息；NAS 一般也走 SMB 或 FTP；想备份进网盘，就把对应的账户接上。
2. **建任务**。新建一个任务，类型选 Backup（单向），左侧选手机里的 DCIM/Camera 这类相册目录，右侧选刚加的存储目标。
3. **先分析，再执行**。第一次分析会列出全部待传文件，确认清单符合预期再执行；中途发现某个目录不该备份，回任务设置里排除掉。

## 让它自己跑

手动备份的问题在于靠记性。GoodSync 的任务可以挂触发条件：

- **接入即动（On Connect）**：适合备份到移动硬盘的场景，盘一插上就自动开跑；
- **定期计划（Periodically）**：每天或每周固定时间执行，把大传输放在夜里不占白天的带宽；
- **文件变化即动（On File Change）**：照片一落盘就触发，适合常拍的机器，但备份到远端存储时要注意流量与电量。

搭配建议：家里的固定备份用「接入即动」或「定期计划」，出门在外的增量备份交给「文件变化即动」。

## 几个容易踩的点

- **删除要不要传播**：单向备份默认会把源端的删除动作带过去（目标端同步删掉）。照片这种不可再生的内容，建议在任务选项里关掉「传播删除」，宁可目标端多留冗余。
- **相册目录的位置**：不同品牌的手机相册路径不一定叫 DCIM/Camera，截图、微信图片各有各的目录，建任务前先在文件管理器里确认一遍。
- **第一次执行的等待**：几百 GB 的照片第一次全量备份耗时正常，之后每次只传增量，几分钟内能结束。
