# 安卓版安装与电脑配对方法

> 本篇讲 GoodSync 安卓端从安装包下载、权限授权，到与电脑端 GoodSync Connect 配对的全过程；配对成功后手机目录就能被电脑直接读写。装好之后建什么任务，见[手机照片备份到电脑的完整流程](手机照片备份到电脑的完整流程.md)；备份与同步的模式选择，见[双向同步和单向备份怎么选](双向同步和单向备份怎么选.md)。

---

## 安装前的准备

安卓端安装包以 APK 形式分发，从网盘拿到安装包后直接安装即可，设备要求 Android 5.2 及以上。安装时如果系统提示「禁止安装未知来源应用」，到系统设置的「安装未知应用」里，给下载时用的浏览器或文件管理器放行，再返回继续。

首次打开会申请「文件与媒体」权限，这项必须给——GoodSync 要读写本地目录才能做同步；部分系统的「照片和视频」权限只给读不给写，会导致同步单边失败，所以按「所有文件访问」授权更稳妥。

## 与电脑端配对（GoodSync Connect）

配对的价值在于：手机不再是「插线拷贝」的外设，而是同步链上的一台正式设备。步骤如下：

1. **两端都装好 GoodSync**。电脑端在 Windows、macOS 或 Linux 上装桌面版；手机端装好安卓版。
2. **登录同一账号**。两端各自的设置里登录同一个 GoodSync Connect 账号，账号起到「认亲」作用。
3. **手机端打开 Server**。切到 Server 标签页登录，开启「把本地文件分享给其他设备」——这个开关打开后，手机上指定的目录就对配对设备可见了。
4. **电脑端添加设备**。在电脑端浏览文件系统时选择 GoodSync Connect，找到这台手机，就能像浏览本地磁盘一样浏览手机目录。

配对建立后，电脑端建任务时可以直接把「手机上的文件夹」选为一侧，另一侧选电脑目录、NAS 或网盘，同步和备份都随任务类型决定。

## 不配对也能用

只想把手机照片备份进网盘、不涉及电脑的话，可以跳过配对：在手机端的 Accounts 页直接接入存储（SMB、Google Drive、S3、iCloud 等逐个添加），手机本地目录对远端存储建单向备份任务即可。局域网里的 Windows 共享和 NAS 走 SMB 直连，同样不需要电脑端参与。

## 配对后常见的小状况

- **设备列表里找不到手机**：确认两端登录的是同一账号，且手机端 Server 处于开启状态；息屏后系统杀后台也会导致设备掉线，把 GoodSync 加入电池白名单。
- **传输速度慢**：同一局域网内走内网直连，速度由路由器决定；跨网络则取决于两端带宽，大文件建议留在 Wi-Fi 环境。
- **权限弹窗反复出现**：检查系统是否处于省电模式，部分品牌的省电策略会拦截后台权限。
