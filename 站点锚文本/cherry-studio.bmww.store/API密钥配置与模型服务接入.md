# Cherry Studio API 密钥配置与模型服务接入

> 本篇解决「装完发不出第一条消息」：客户端为什么不带额度、API 密钥从哪来、两条接入路线怎么选、怎么验证配通了。
> **相关文档**：[安卓手机版下载安装方法.md](安卓手机版下载安装方法.md) · [手机版与电脑版配对同步.md](手机版与电脑版配对同步.md)

---

## 一、为什么装完还不能聊

Cherry Studio 是客户端，本身不附带模型额度：每个回答都是它拿着你的 API 密钥去对应平台请求回来的。所以第一次打开要先接入至少一个模型服务。两个常踩的认知坑：

- **别把平台登录密码当密钥**。密钥是在平台的开放接口页单独创建的一串字符，不是账号密码。
- **普通聊天会员不一定含接口额度**。充了会员不代表 API 能随便调，去对应平台确认额度规则；调用费用由平台按量结算，明细也在平台侧查，客户端里看不到账单。

## 二、两条接入路线，先选一条

| 你的情况 | 走哪条 |
| --- | --- |
| 电脑上已在用桌面版，服务商都配好了 | 扫码配对，把服务商配置与模型导入手机（见 [手机版与电脑版配对同步.md](手机版与电脑版配对同步.md)） |
| 第一次用，或电脑上没配过 | 在手机上直接添加服务商，按第三节走 |

## 三、在手机上添加服务商

1. 首次使用向导里直接选服务商；错过了向导，就打开「设置 → 模型服务 → 添加服务商」。
2. 内置列表覆盖了 DeepSeek、智谱、硅基流动这类常用平台，连接设置都预填好了；列表里没有的平台选「自定义服务商」，按平台说明填基础地址。
3. 粘贴平台给你的 API 密钥，保存。部分渠道会提供免配置密钥的试用模型，随活动调整，适合先体验。
4. 同步模型列表，选一个常用模型并确认；列表拉取失败不代表不能用，把平台文档里的准确模型 ID 手动添加即可。
5. 回头确认服务商处于启用状态，再从对话顶部选好模型。

配好后的界面长什么样、入口在哪一屏，[Cherry Studio 手机版介绍站](https://cherry-studio.bmww.store/)的界面一览里有一张设置页截图，可以对位找入口。

## 四、发第一条消息验证

1. 用初始的 Cherry 智能体，在对话顶部选好刚启用的模型。
2. 发一句「用三句话介绍你能帮我做什么」。
3. 收到回复，配置就通了。没回复的话先换一条**不带附件的短消息**重试，再核对服务商与模型是否都已启用、密钥有没有多余的空格。

## 五、配好之后值得先试的三件事

- 给写作、翻译这类固定任务各存一个智能体，任务说明写一次就够。
- 把照片或文件丢进对话，让模型看图、读文档。
- 在设置里把字号、主题调成顺手的样子，日历与提醒等设备能力第一次用到时会单独弹授权，不同意只关那一项。
