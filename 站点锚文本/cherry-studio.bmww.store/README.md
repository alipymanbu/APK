这里是 Cherry Studio 移动版（安卓 APK）的介绍小站导航。移动版目前处于 Beta 阶段，客户端本身不带模型额度，装好后的头两件事——装上它、接上模型服务——下面的三篇正好各讲一件。想直接看整理好的图文版，可以逛逛 [Cherry Studio 手机版介绍站](https://cherry-studio.bmww.store/)，功能亮点、界面截图与安装入口都在那里。

## 一句话背景

Cherry Studio 是 CherryHQ 开源的多模型 AI 客户端，桌面端覆盖 Windows / macOS / Linux；移动版把多模型对话、智能体与 MCP 工具搬到了手机上，模型额度由使用者自备（各自的平台密钥）。名称与商标归其权利人所有，本目录内容整理自公开资料，仅供参考。
