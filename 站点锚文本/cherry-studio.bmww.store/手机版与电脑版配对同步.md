# Cherry Studio 手机版与电脑版配对同步方法

> 电脑上已经把桌面版的服务商配好了？本篇讲怎么扫码配对把配置带进手机：哪些带得走、哪些带不走、同步失败按什么顺序查。
> **相关文档**：[API密钥配置与模型服务接入.md](API密钥配置与模型服务接入.md) · [安卓手机版下载安装方法.md](安卓手机版下载安装方法.md)

---

## 一、这个功能能带过来什么

先把边界说清楚：导入范围是**模型服务商配置与已启用的模型**。聊天记录、插件账号授权都不在导入范围里，它也不是远程控制电脑的方式。配对成功后不会持续自动同步——以后改了配置想更新手机，要再手动同步一次。电脑上的本地模型服务（Ollama、LM Studio 这类跑在本机的东西）同样导不过来。

## 二、配对步骤

1. 手机与电脑连**同一个局域网**（比如同一个家庭 Wi-Fi），电脑上保持桌面版运行。
2. 桌面端打开「设备互联」，屏幕上出现配对二维码。
3. 手机端打开「设置 → 设备互联 → 扫描二维码」；第一次用会要相机权限与局域网访问权限，都允许。
4. 扫完按页面提示继续，勾选要同步的服务商。手机没有相机时，用页面提供的手动输入方式，把二维码里的**配对内容**（不是普通网址）粘进去。

不想折腾配对的话，在手机上直接添加服务商也完全可以，两条路线见 [API密钥配置与模型服务接入.md](API密钥配置与模型服务接入.md)。

## 三、导入时会发生什么

| 情况 | 结果 |
| --- | --- |
| 勾选的服务商 | 覆盖为电脑上的地址和密钥，并在手机启用 |
| 电脑启用、手机还没有的模型 | 加到手机 |
| 手机已有的同名模型 | 保留手机现有设置，不重复加 |
| 手机独有的服务商或模型 | 保留 |
| 电脑上已停用的服务商或模型 | 不导入 |
| 聊天记录、插件授权 | 不导入 |

最要留意第一行：就算没有新模型，把已有服务商再同步一次，也会把手机上的地址和密钥替换成电脑那份——手机和电脑用不同密钥的话，想清楚再点同步。

## 四、扫码成功、同步却失败

按顺序查：

1. 桌面端还开着吗；
2. 两台设备还在不在同一局域网（路由器的访客网络隔离会把两台设备隔开）；
3. 电脑防火墙或代理有没有拦；
4. 之前拒绝过局域网权限的话，去系统设置里给应用打开；
5. 页面提示「需要重新配对」就重扫一次二维码。

## 五、换手机与解除配对

手机端「移除设备」只删掉这台手机里存的连接凭据；要真正撤销授权，还得在电脑端「设备互联」里把这台移动设备移除。导入配置不是备份——重要对话换机前用导出功能（Markdown、HTML 或图片）另行保存。

装好移动版还没配模型的话，先看 [API密钥配置与模型服务接入.md](API密钥配置与模型服务接入.md)；想先看看移动版整体长什么样，[Cherry Studio 手机版介绍站](https://cherry-studio.bmww.store/)上有界面一览与功能亮点。
