# Cherry Studio 安卓手机版下载安装方法

> 本篇讲怎么把 Cherry Studio 移动版（安卓 APK）装进手机：安装包从哪来、四个步骤怎么走、被系统拦下或报「解析包错误」时怎么处理。
> **相关文档**：[API密钥配置与模型服务接入.md](API密钥配置与模型服务接入.md) · [手机版与电脑版配对同步.md](手机版与电脑版配对同步.md)

---

## 一、装之前先弄清楚三件事

1. **版本形态**：移动版以 APK 形式发布，目前处于 Beta 阶段，界面随版本调整较快，教程截图对不上时先更新再找入口。
2. **设备要求**：安装包面向 ARM64 设备，近几年出的安卓手机基本都符合；32 位老机型装不了。收录版本 0.1.7 约 89 MB，给手机留出足够的存储空间。
3. **渠道要对**：从可靠的资源页拿安装包，别用来路不明的「镜像站」；之前装过同名应用的话，先卸掉再装，避免签名冲突报「未安装」。

想边看图边操作的话，[Cherry Studio 手机版介绍站](https://cherry-studio.bmww.store/)的安装页把这几步做成了图文流程，和本篇讲的是同一件事。

## 二、四步装进手机

1. **打开资源页，转存到自己的网盘**：进入安装文件资源页后先登录网盘账号，把安装包转存到名下再下载，这样即使原分享链接日后失效，自己网盘里那份还在。
2. **把 APK 下载到手机**：在网盘里找到 APK 直接下载，用手机浏览器操作即可；下完在通知栏或浏览器的下载记录里能找到它。
3. **点开安装，允许「安装未知应用」**：系统默认拦「来源不明」的安装包，按弹窗提示给当前打开 APK 的那个应用（浏览器或文件管理器）临时勾选允许。注意这是按应用授权的：用浏览器下载、却用文件管理器打开安装，两个都要允许；装完建议把授权关回去。
4. **打开应用，接入模型服务**：首次启动可以选「从桌面版导入」，把电脑里配好的服务商直接带过来；没有桌面版就在「设置 → 模型服务」里添加平台、填入密钥。具体做法见 [API密钥配置与模型服务接入.md](API密钥配置与模型服务接入.md)。

## 三、装不上时的对号入座

- **点安装被拦或没反应**：九成是「安装未知应用」授权没给到当前打开 APK 的那个应用，按弹窗提示去设置里勾选即可。
- **提示「解析包错误」**：先看文件大小是否明显偏小（没下完就重新下载）；再看存储空间与安卓版本是否过低。
- **报「App 未安装」**：手机里如果有来路不明的同名应用，签名对不上会装不进去，先卸载旧的再装。
- **装好了发消息没回复**：这不是安装问题，是还没接模型服务，回 [API密钥配置与模型服务接入.md](API密钥配置与模型服务接入.md) 第二节。

## 四、升级与卸载

- **升级**：拿到新版本 APK 直接覆盖安装，聊天数据一般会保留；Beta 阶段界面变动快，升级前看一眼版本说明。
- **卸载**：长按图标卸载即可；里面有要留的对话就先导出（支持 Markdown、HTML 或图片格式），再动手删。
