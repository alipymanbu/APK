# mifun 播放设置与离线缓存使用说明

> 本篇整理 mifun 播放页里清晰度、倍速、弹幕这些开关的用法，以及离线缓存和投屏的操作路径。
> **相关文档**：[追番时间表与找番方法.md](追番时间表与找番方法.md) · [安卓版安装步骤与装不上排查.md](安卓版安装步骤与装不上排查.md)

---

## 一、开关都在哪：播放页一条控制条

点一下画面呼出控制条，清晰度、倍速、弹幕、字幕、来源切换、投屏、缓存都在这一条上；清理缓存这类全局设置在「我的 → 设置」里。按钮排序随版本略有差异，认图标即可。

## 二、清晰度与倍速怎么选

| 网络环境 | 建议档位 |
| --- | --- |
| 稳定 WiFi | 超清 / 高清 |
| 一般 WiFi | 高清 |
| 移动数据 | 流畅 / 标清 |
| 一直转圈 | 直接降到流畅 |

切换即时生效、不打断进度。补旧番、赶进度开 1.25~1.5 倍比较合适，战斗作画和配乐重要的段落记得调回原速。

播放卡顿先换线路（控制条上的来源/线路）、再降画质、最后查网络——别的应用也卡就是网络问题，只有它卡就切一条线路，通常切一次就顺。

## 三、弹幕与字幕

- **弹幕**：播放页点气泡图标开关；不想露脸也可以只看不发。部分版本设置里有「默认关闭弹幕」，设一次全局生效。
- **字幕**：有的番带字幕轨，播放页里有字幕入口就能切；没入口说明这部没有，不是操作问题。

## 四、离线缓存：先把剧下到手机

1. 进到想看的番的播放页，点下载/缓存图标（向下箭头）。
2. 勾选要下的集数（可多选），点开始下载。
3. 进度在「查看下载列表」里看，下载在后台跑，退出页面不影响。
4. 下好的在「我的 → 离线缓存」，直接播放或删除。

三点提醒：缓存文件存在应用私有目录，外部文件管理器翻不到，管理只走「我的 → 离线缓存」这一条路；删了找不回，清理前看一眼有没有没看的；缓存不跟账号走，换手机要重新下。

## 五、投屏电视

手机和电视连**同一个 WiFi**，播放页右上角点 TV/投屏按钮，等列表出现设备点一下就连上。列表一直空着时按顺序查：同一网络 → 电视投屏开关已打开 → 往路由器靠近或改 5GHz → 暂停同网络里的大流量下载。投屏画面断续多是带宽问题，把画质调低一档再投。

## 六、越用越卡时

先清缓存：「我的 → 设置 → 清除缓存」，清的是临时文件、不影响账号数据，也别担心动到你下载的剧集。还不见好就从后台彻底划掉重开，或重启手机。

应用的获取与安装入口在 [mifun 追番应用介绍](https://mifun.wrwq.fun/) 的下载页；找番与追番排期见 [追番时间表与找番方法.md](追番时间表与找番方法.md)。
