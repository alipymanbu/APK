# mifun 安卓版安装步骤与装不上排查

> 本篇讲 mifun 安卓安装包从拿到手到装进手机的全过程，以及「解析包出错」「应用冲突」这类装不上情况的排查顺序。
> **相关文档**：[追番时间表与找番方法.md](追番时间表与找番方法.md) · [播放设置与离线缓存使用说明.md](播放设置与离线缓存使用说明.md)

## 一、动手前对一遍环境

| 项目 | 口径 |
| --- | --- |
| 系统要求 | 安卓 5.2 及以上 |
| 安装包大小 | 64.82M（建议留出三倍以上的可用空间） |
| 版本 | 以安装后「设置 → 应用」里显示的为准 |

## 二、安装四步

1. **拿到安装包**：打开 [mifun 追番应用介绍站](https://mifun.wrwq.fun/)，下载页里的大按钮直达夸克网盘分享页，把 apk 转存或直接下载到手机——用手机浏览器或网盘 App 完成，别用聊天工具从电脑传（传输中容易被截断，装时必报「解析包出错」）。
2. **放开未知来源拦截**：首次点开 apk 会弹「不允许安装来自此来源的应用」，点提示里的设置打开对应开关；Android 8.0 起按应用授权，在哪个应用里点的安装包就给哪个开。
3. **安装并等待完成**：返回点安装，进度条走完再退出，中途退出容易留下半截包。
4. **打开核对**：完成后点打开或回桌面点图标；想确认版本，到「设置 → 应用 → mifun」里看一眼。

## 三、装不上的三种常见情况

- **解析包出错**：基本都是下载不完整，核对文件大小后删掉重下一次。
- **与已有应用冲突**：手机里装过另一个签名不同的同名应用，同包名装不上去——先卸载旧的再装；之前登录过账号的话，装好登录同一账号收藏能回来。
- **空间不足或系统太低**：安装时系统要临时解压，空间留足；系统低于安卓 5.2 则装不了，先在「关于手机」里确认。

按顺序排查基本都能解决；装好之后怎么找番、怎么把追番表用起来，见 [追番时间表与找番方法.md](追番时间表与找番方法.md)。
