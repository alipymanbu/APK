# VideoFk 支持哪些平台与内容边界

> 本篇讲 VideoFk 能解析哪些平台的视频、怎么快速验证某个站行不行，以及哪些内容类型注定解析不了。
> **相关文章**：[粘贴链接提取视频的操作步骤](粘贴链接提取视频的操作步骤.md) · [解析失败与下载中断的排查思路](解析失败与下载中断的排查思路.md)

「VideoFk 支持哪些平台」没有一劳永逸的固定答案：解析覆盖面由内置的 yt-dlp 引擎决定，引擎每次更新都可能修复或新增某些站点，也可能因为平台改版暂时失效某个站。这篇给一份确认可用的起点清单，以及一套一分钟自测任何站点的办法。工具整体介绍见 [videofk 介绍站](https://videofk.xnyx.quest/)。

## 一、商店介绍页列出的平台

| 平台 | 备注 |
| --- | --- |
| 抖音 | 口令式分享长链接可直接解析，不用清理成纯网址 |
| 快手 | 分享面板复制链接即可 |
| 哔哩哔哩 | 单视频页地址直接解析 |
| YouTube | 部分视频有地区或年龄限制，属平台侧限制 |
| Instagram | 仅公开帖子有效 |

另有介绍页宣称覆盖上百个平台，这个数字无从核实，当参考即可：实际覆盖范围以手里的链接能不能解析出来为准。某条链接解析失败时，按 [解析失败与下载中断的排查思路](解析失败与下载中断的排查思路.md) 的顺序走一遍再下结论。

## 二、一分钟验证某个站行不行

三步出结论：

1. **先验公开性**：把链接粘到浏览器无痕窗口打开，能正常播放才有解析的可能；
2. **粘进应用试解析**：复制链接 → 粘贴 → 看能否解析出视频信息；
3. **区分「单站失效」与「整体故障」**：拿另一家平台的公开链接再试一次。另一家能成，多半是那个站改了页面，等一次引擎更新就会恢复；另一家也不成，问题在应用或网络侧，回排查篇逐项过。

## 三、单视频链接与播放列表链接要分清

这是粘贴环节最常见的「粘错了对象」：

| 粘的内容 | 会发生什么 | 该怎么做 |
| --- | --- | --- |
| 单条视频页地址 | 解析出这一条视频 | 正常下载 |
| 播放列表 / 合集链接（带 `list=` 参数、合集口令） | 按整个列表解析，一口气列出几十上百条任务 | 只想要其中一条时，改粘单条视频页地址 |

想要整个列表就让它整列解析，只想留单条就换成单视频地址，两种意图都合理，区别只在粘之前想清楚。完整的粘贴与下载操作见 [粘贴链接提取视频的操作步骤](粘贴链接提取视频的操作步骤.md)。

## 四、这些内容不在能力范围内

无论粘多少次都解析不出来，属于能力边界而不是故障：

- 私密视频（仅作者可见）；
- 需要登录才能观看的内容；
- 有年龄限制、需要账号验证的视频；
- 平台加了版权保护的内容；
- 限定地区播放、所在地区访问不到的内容。

无痕窗口测试正是基于这条边界：浏览器不登录都看不了的内容，解析工具同样拿不到。
