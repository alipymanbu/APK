# VideoFk 解析失败与下载中断的排查思路

> 本篇汇总 VideoFk 最常见的几类故障：粘贴后解析不出、下载到一半停了、昨天还能用今天不行，每类都给可操作的排查顺序。
> **相关文章**：[粘贴链接提取视频的操作步骤](粘贴链接提取视频的操作步骤.md) · [支持哪些平台与内容边界](支持哪些平台与内容边界.md)

VideoFk 的解析下载能力来自内置的 yt-dlp 引擎，出的问题大多有规律：要么链接本身有边界，要么系统把后台下载杀了，要么引擎版本追不上平台改动。先按下面的速查表对号入座，再进对应小节处理。正常操作流程（从复制链接到保存）见 [粘贴链接提取视频的操作步骤](粘贴链接提取视频的操作步骤.md)。

## 一、症状速查表

| 症状 | 最可能的原因 | 先做什么 |
| --- | --- | --- |
| 切后台后下载就停了 | 系统电池策略杀了进程 | 电池管理设为「无限制」（见第二节） |
| 粘贴后一直解析不出 | 链接不完整，或内容有访问限制 | 核对链接、确认公开性（见第三节） |
| 昨天还能用、今天突然不行 | 平台改了接口，引擎过旧 | 更新 yt-dlp 引擎（见第四节） |
| 解析出一大堆不想要的任务 | 粘的是播放列表 / 合集链接 | 换单视频页地址，见 [支持哪些平台与内容边界](支持哪些平台与内容边界.md) |
| 下载速度异常慢 | 平台限速或网络波动 | 换网络环境再试 |
| 提示存储空间不足 | 手机空间满了 | 清空间或删旧记录 |

## 二、下载到一半停了：电池管理设为「无限制」

安卓的省电策略会主动杀后台应用，下载任务一进后台就可能被掐断，表现就是「切出去回个消息，回来发现下载停了」。设置路径（不同品牌叫法略有差异）：

1. 系统设置 → 应用管理 → 找到 VideoFk；
2. 进「电池 / 电池优化」；
3. 选「无限制 / 不受限制 / 允许后台运行」。

设完之后跑批量任务才踏实——多链接批处理耗时长，被系统盯上的概率也高。

## 三、解析不出来：先分清链接问题还是能力边界

按顺序做两步确认：

1. **核对链接完整性**：口令式长链接中间缺一段就解析不了，回平台重新复制一遍再粘。还有一种「链接没错但粘错了对象」：粘成播放列表或合集链接会被按整个列表解析，只要单条视频就换单视频页地址。
2. **确认内容是公开可访问的**：私密视频、需要登录才能看的、有年龄限制需账号验证的、平台加了版权保护的、限定地区播放的——这几类无论用什么工具都拿不到，属于能力边界而不是故障。完整边界清单见 [支持哪些平台与内容边界](支持哪些平台与内容边界.md)。

一个快速判别办法：把链接粘到浏览器无痕窗口里打开，无痕窗口里都看不了的内容，解析不出来是正常现象，不是应用坏了。

## 四、引擎更新是长期有效的「修复手段」

视频平台隔三差五改自己的接口，旧引擎对新页面就会失灵，「昨天还好好的今天不行了」基本都是这一类。操作上：

1. 在应用设置里找「更新 yt-dlp / 更新引擎」入口，更到最新；
2. 更新后重试刚才失败的链接；
3. 某个平台整体失效、其他平台正常时，通常等一次引擎更新就会恢复，期间先用其他来源。

更新前先确认手机能正常联网，网络不通时引擎更新本身也会失败。

## 五、更新之后还不行的兜底检查

- **换网络试试**：移动数据和 Wi-Fi 各试一次，个别平台对特定网段有限制；
- **重启应用**：清掉后台重新打开，排除应用状态异常；
- **重发链接**：删掉记录里失败的那条，重新复制粘贴，排除剪贴板残留；
- **换一条链接验证**：拿另一条公开视频试，能成说明问题在那条视频本身，不是应用整体坏了；
- **重装排查**：装完就各种异常的，卸载后重新转存安装包再装一遍，排除安装过程损坏。

安装环节本身出问题（解析包出错、版本不兼容、杀毒拦截），处理办法见 [videofk 介绍站](https://videofk.xnyx.quest/) 的安装步骤页。
