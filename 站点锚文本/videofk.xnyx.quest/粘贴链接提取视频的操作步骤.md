# VideoFk 粘贴链接提取视频的操作步骤

> 本篇讲 VideoFk 提取视频的完整操作顺序：从哪里拿链接、怎么粘贴解析、下载前能调什么，以及提取完的文件在哪里。
> **相关文章**：[解析失败与下载中断的排查思路](解析失败与下载中断的排查思路.md) · [支持哪些平台与内容边界](支持哪些平台与内容边界.md)

VideoFk 是一款安卓端的视频解析下载工具，主线操作只有一条：复制视频链接 → 粘贴进应用 → 自动解析 → 选格式保存。整条链路不需要登录任何视频平台账号，处理的对象是公开可访问的视频内容。工具的功能总览与安装文件资源入口，见 [videofk 介绍站](https://videofk.xnyx.quest/)；某一步卡住出不来，按 [解析失败与下载中断的排查思路](解析失败与下载中断的排查思路.md) 对症处理。

## 一、整个流程长什么样

| 步骤 | 要做的事 | 发生在哪 |
| --- | --- | --- |
| 1 | 在视频平台应用里复制视频链接 | 抖音 / 快手 / B 站 / YouTube 等平台 |
| 2 | 切回 VideoFk，点粘贴按钮读入链接 | VideoFk 首页 |
| 3 | 应用自动识别来源平台并解析 | 自动完成，无需手动操作 |
| 4 | 预览确认，选画质与格式后开始下载 | VideoFk 下载设置 |
| 5 | 在下载记录里查看，视频进系统相册 | VideoFk 记录页 / 系统相册 |

## 二、先把链接复制完整

在平台应用里找到目标视频，用「分享 → 复制链接」放进剪贴板：

- **抖音**：视频右侧分享按钮 → 复制链接；
- **快手 / B 站**：分享面板里选「复制链接」；
- **YouTube**：分享 → Copy link；
- **Instagram**：帖子右上角菜单 → 复制链接（仅公开帖子有效）。

带中文和特殊符号的口令式长链接（比如抖音那种一长串文案加网址的形式）可以直接解析，不用先手动清理成纯网址。解析失败最常见的起点是「链接没复制全」，中间缺一段就出不来，排查顺序见 [解析失败与下载中断的排查思路](解析失败与下载中断的排查思路.md)。

## 三、粘贴解析与下载设置

第一次解析前，应用会先要两笔授权：**存储权限**（保存下载的文件要用）和**后台运行权限**（下载切后台不被系统掐断），给上再往下走。之后每次都是同一套操作：

1. 打开 VideoFk，在首页点**粘贴按钮**，应用从剪贴板读入链接；
2. 链接读入后自动识别来源平台并开始解析；
3. 解析完成后先**预览**，确认是想要的那条内容再动手；
4. **在开始下载前修改本次设置**：画质 / 分辨率按解析结果选，输出格式视频常用 MP4、想保留字幕与多音轨选 MKV；只要声音的话，把输出类型切成音频、格式选 MP3。

每条任务都可以单独决定参数，这是它和「点一下就直接下」类工具的主要区别。想一次处理一批链接，把多个链接一次性导入即可，应用会按列表逐个解析下载；批量任务跑得久，先到系统电池管理里把该应用设为「无限制」，避免中途被杀后台。

## 四、提取完的文件在哪里

下载完成后视频保存到手机相册，系统相册里直接可见；音频文件在应用指定的音频下载目录里。应用内的**下载记录页**按视频与音频分列历史记录，可以回看每条任务的完成状态、管理已下载的文件。相册里找不到时，先去记录页核对任务状态，再看文件管理器的 Download 目录。

## 五、两个容易踩的点

- **粘错对象**：粘成播放列表或合集链接（带 `list=` 参数的地址）会被按整个列表解析，一口气列出几十上百条任务；只想要单条时，改粘单视频页地址，详见 [支持哪些平台与内容边界](支持哪些平台与内容边界.md)；
- **引擎过旧**：「昨天还能用今天不行了」大多是平台改了接口、内置引擎没跟上，到设置里更新 yt-dlp 引擎通常就能恢复。
