# 主机游戏下载加速怎么弄

> 本篇讲 Switch、PS4、PS5 下载游戏和更新时速度慢的常见原因，以及用加速流量提速的完整做法。

## 一、主机下载为什么慢

Switch、PlayStation 下载大作时速度上不去，多数时候不是主机的问题，而是到游戏商店服务器的线路绕了远路。表现为：下载进度龟速前进、商店页面转圈打不开、补丁更到一半卡住不动。游戏体积动辄十几 GB，这个速度等一晚上也未必下得完。

## 二、常见的几条提速路子

玩家常用的办法有这么几种：改主机 DNS、路由器开加速插件、或者直接用带加速功能的应用。前两种折腾门槛高，改不好还会影响日常上网；对多数人来说，在手机上用应用一键发起加速是最省事的一条——应用给出参数，主机照着填就行。

## 三、用加速流量的完整流程

以玩家圈子里常用的 [Jump 比价社区](https://jump.bpfl.quest/)应用为例，它的加速流量靠每日签到领取，用法是：

1. **手机上签到攒流量**：每天在应用里签到领免费加速流量，攒着等下载大作时用；
2. **应用内发起加速**：选对应场景——游戏下载、游戏更新、系统更新或商店访问，应用会给出网络参数；
3. **主机端照着填**：以 Switch 为例，主机「设置 → 互联网 → 互联网设置」里选中当前 Wi-Fi，点「更改设置」，按应用显示的参数填好并保存，跑一次连接测试；
4. **用完改回去**：加速结束后把主机网络设置改回原样，避免影响日常联网。

PS4 / PS5 的操作路径类似，都在系统设置的网络分类下。

## 四、加速没效果时先查这几处

- 主机和应用是否连在同一个网络环境；
- 主机上填的参数是不是应用**当前显示**的那组——换过网络或改过路由器后旧参数会失效；
- 主机上有没有其他下载在占带宽，先停掉；
- 都没问题就回应用里重新发起一次加速。

## 五、小结

主机下载慢不必硬等，签到攒的免费加速流量足够应付游戏下载、更新与商店访问这些场景。顺带一提，这类应用多数也带比价功能，买游戏前先比一遍各区价格更划算，做法见 [Switch游戏比价与史低提醒.md](Switch游戏比价与史低提醒.md)；工具的安装方式可以从 [Jump 比价社区](https://jump.bpfl.quest/)介绍页了解。
