# MultiTTS 站点收录

MultiTTS 是安卓系统上的文字转语音引擎前端：本身不带阅读界面，装好后由听书、朗读类应用调用发声；语音包另行导入，一个包里可以有上百个发音人，离线音源不耗流量也能照常朗读。

围绕它的使用整理了下面几篇，站点入口：[MultiTTS 语音引擎说明](https://multitts.fwen.ren/)。
