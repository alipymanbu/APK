# keymapper.yoan.quest · Key Mapper 介绍站

Key Mapper（常被写作 keymapper）是一款按 GPL-3.0 协议开源的安卓按键映射工具：把音量键、耳机线控、蓝牙键盘、手柄按键等硬件按键拦截下来，替换成你自己安排的动作。本站整理它的玩法模型、按键支持边界与上手设置，安装文件资源的获取入口也放在站内。

- 站点首页：<https://keymapper.yoan.quest/>
- 功能与玩法：<https://keymapper.yoan.quest/index.html>
- 下载与安装：<https://keymapper.yoan.quest/download.html>
