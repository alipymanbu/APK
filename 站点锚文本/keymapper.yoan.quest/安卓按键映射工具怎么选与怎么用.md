# 安卓按键映射工具怎么选与怎么用

> 想把手机上按了没用的键、或用途定死的键改成别的功能，是很多人搜索「keymapper」的起点。本篇从需求出发，聊聊按键映射适合哪些场景、核心玩法长什么样，以及上手前要有什么心理预期。

## 一、哪些需求适合用按键映射解决

按键映射解决的是一类很具体的问题：**某个硬件按键的默认用途你不满意**。常见的几类：

- 音量键位置顺手，却只能调音量——想让它兼职干别的：长按开手电筒、双击截屏；
- 蓝牙键盘、手柄上有一些用不上的键，想让它们一键打开某个应用；
- 耳机线控只有播放键，想让它也能唤起付款码、语音助手；
- 某些机型侧边的按键误触率高，想让它「按了什么都不做」也行。

注意另一类需求不在此列：触屏手势改键、虚拟导航键改造、自动连点——这些不是硬件按键的范畴，别选错工具方向。

## 二、keymapper 的玩法模型

Key Mapper（包名里带 keymapper 的那个开源项目，GitHub 上搜 keymapperorg 可以找到源码）把每条映射拆成三块：

1. **触发器**：你按下什么。可以是单键，也可以是多键同时按、按顺序依次按；同一个键还能按短按、长按、双击分别定义，互不干扰。
2. **动作**：系统替你做什么。内置动作有上百项——开关手电筒、截屏、打开应用、媒体控制、调亮度、锁屏、输入一段文本、点按屏幕指定坐标，一条映射还能串多个动作。
3. **约束**：什么情况下才生效。限定只在某个应用里生效、播放媒体时生效、连上某台蓝牙设备时生效、充电时生效，新版还加了时间段约束。

约束是最容易被忽略、也最出效果的一块：给映射加一个「前台应用 = 浏览器」，键盘 B 键就只在浏览器里变成直达某个网站的快捷键，在其他应用里照常输字母。

## 三、上手前要有的一条心理预期

这类工具的工作原理，决定了它必须常驻一个无障碍服务来监听按键。所以装完不是「开箱即用」——要先开启无障碍服务，再把应用加进电池优化白名单，防止后台被系统清掉。国产系统（小米、华为、OPPO、vivo 等）的后台管理分好几层，每一层都要放行，否则就会出现「设置完好好的，过一夜就失灵」。

这些设置不复杂，但值得一次做齐，具体按序排查的思路见 [按键映射失灵的排查思路](按键映射失灵的排查思路.md)；想直接动手配两条最常用的映射，看 [音量键改成手电筒或截屏的设置方法](音量键改成手电筒或截屏的设置方法.md)。

## 四、工具本身的情况

按 GPL-3.0 协议完整开源，代码在 GitHub 公开可查；对安卓版本的要求比较宽松，多数近年机型都能装。功能边界也说得出：电源键、Bixby 键这类改不了；免 root 状态下息屏检测不到按键；手柄的摇杆和扳机不在支持范围。这些边界在它的功能介绍页都有明示，选型前先对照一遍自己的需求。

一份整理了触发器、动作、约束三大玩法与按键支持清单的中文介绍，可以看 [keymapper.yoan.quest](https://keymapper.yoan.quest/)，站内也带了安装文件资源的获取入口。
