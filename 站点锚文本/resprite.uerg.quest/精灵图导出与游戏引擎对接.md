# 精灵图导出与游戏引擎对接

> 本篇讲像素作品画完之后怎么交出去：GIF、APNG、精灵表、PSD、原生项目包分别适合什么场合，交给游戏引擎或合作者时各要注意什么。
> **相关文档**：[手机上画像素画的第一步.md](手机上画像素画的第一步.md) · [像素动画帧与洋葱皮入门.md](像素动画帧与洋葱皮入门.md)

---

## 一、先想清楚「交给谁」

导出格式没有万能答案，先看接方是谁：

| 接方 | 用哪种格式 |
| --- | --- |
| 社交平台（发动态、发教程） | GIF 或 APNG |
| 游戏引擎（Unity、Godot 等） | 精灵表（无损 PNG 按网格排帧） |
| Photoshop / Krita 等修图软件 | PSD（保留图层） |
| 其他像素画工具的用户 | 对方支持的项目格式（如 Aseprite） |
| 三个月后的自己 | 原生项目包（保留帧、图层、调色板） |

## 二、精灵表：引擎最认的形态

游戏引擎读动画，认的是「一张大图 + 帧坐标」。导出精灵表时按网格排帧，设置好每行帧数与边距，再在引擎里按同样网格切开播放即可。导出面板里的放大倍数按项目分辨率定——引擎里有像素完美（pixel perfect）设置时，素材一倍导出、引擎内缩放更稳。

以安卓端工具为例，Resprite 的导出面板可以调帧范围、每行帧数、边距与放大倍数，具体界面可以看[它的介绍站](https://resprite.uerg.quest/)；Tiled 地图与瓦片集也能打包导出，做横版关卡地图时用得上。

## 三、PSD 与原生包的区别

PSD 适合把作品递给 Photoshop、Krita、Clip Studio 这类软件继续加工：图层组、剪贴蒙版、混合模式都能保留。但要注意——**PSD 通常只捕捉当前帧**，动画要逐帧导出，或者干脆改用 GIF、精灵表。

原生项目包（如 Resprite 的 `.resprite` 文件）才是真正意义的「工程文件」：帧、图层、调色板、元数据都在里面。换设备继续画、交接给别人改、做备份，都应该用它。PNG、GIF 这些成品替代不了工程文件——图层数据不在里面。

## 四、交接前的小清单

1. 确认接方要的格式与尺寸倍数；
2. 动画素材核对帧率与帧范围；
3. 长期保存或远程交接，一律带上原生项目包；
4. 文件名带上日期，避免下一次导出把旧版覆盖掉。

静态画还没画完的话，回[手机上画像素画的第一步.md](手机上画像素画的第一步.md)补基础；想让画面动起来，看[像素动画帧与洋葱皮入门.md](像素动画帧与洋葱皮入门.md)。
