# v380pro 摄像头配网步骤

> 本篇讲怎么把 V380 系列摄像机添加进 v380pro：先认清该用哪种配网方式，再按语音提示一步步来，末尾是反复失败时的排查顺序。
> **相关文档**：[手机端下载安装流程](手机端下载安装流程.md) · [移动侦测报警与回放设置](移动侦测报警与回放设置.md)

## 一、配网前必须知道的三件事

1. **摄像机只支持 2.4GHz Wi-Fi**。双频路由器如果发两个名字（2.4GHz 和 5GHz 各一个），配网时一定选 2.4GHz 那个；名字合一时多数路由器会自动分配，个别需要在路由器后台把 2.4GHz 单独拆出来。
2. **Wi-Fi 必须设密码**，加密用 WPA2-PSK 或更低级别；Wi-Fi 名字里带中文、空格或特殊符号时部分机型会失败，先临时改成纯英文数字。
3. **配网只需要做一次**。成功后摄像机记住这个 Wi-Fi，换网络或重置才需要重来。

开始前把摄像机放在路由器旁边一两米内，信号越强配网越快，成功后再装到想装的位置。

## 二、先重置，听语音定方式

接通电源等开机提示说完，**长按机身上的 reset 键几秒**，听到「恢复出厂设置」「等待 Wi-Fi 智能配网」之类的语音后松手。接下来听它说什么：

| 语音提示 | 该用的方式 |
| --- | --- |
| 「等待 Wi-Fi 智能配网」 | Wi-Fi 智能配网（快配） |
| 「热点已建立」 | AP 热点连接 |
| 「蓝牙准备就绪」 | 蓝牙配对 |
| 「请扫描机身上的二维码」 | 二维码配网 |

一种试不过关就重置换下一种，互不冲突，这是最省时间的路子。

## 三、四种方式各自怎么走

- **快配**：手机先连上家里 2.4GHz Wi-Fi，进 App 点「+」选快配，确认界面显示的 Wi-Fi 名就是手机正在用的，输密码下一步，把手机拿到摄像机旁边等它播报「Wi-Fi 已连接」。安卓 10 以上可能要求连一下设备热点（名字形如 MV+数字），按提示允许。
- **AP 热点**：长按 reset 听到「热点已建立」后，进 App 点「+」选 AP 连接，选好要给摄像机配的 Wi-Fi 并输密码，再去手机系统设置连摄像机的热点（MV 开头），弹「无法访问互联网仍要连接吗」选仍然连接，返回 App 等提示音。
- **蓝牙配对**：开机语音说蓝牙就绪的机型，开手机蓝牙、进 App 选蓝牙方式，搜到设备后选 Wi-Fi 输密码即可。不依赖 Wi-Fi 信号强弱，快配失败时值得一试。
- **二维码配网**：手机连上 2.4GHz 后扫机身贴的二维码，选 Wi-Fi 输密码，App 会生成动态二维码，举到镜头前 15~25 厘米等它连接。

二手摄像机、贴纸磨损的机器用手动添加：设备 ID 印在机身底部标签上，MV 开头加一串数字，手动输入即可。4G 款不走 Wi-Fi 配网——装好 nano SIM 卡开机，指示灯变黄就是联网成功，直接扫码或输 ID 添加。

## 四、反复失败按这个顺序查

1. 手机和摄像机是不是都站在 2.4GHz 上——手机连着 5GHz 时，快配会把错误频段喊给摄像机。
2. 密码输错是最常见的低级失误，重新输一遍。
3. 摄像机离路由器太远，挪到路由器旁边再试。
4. 上面都正常还失败：重置后换一种配网方式再来一遍。

配好网别急着收工——让摄像机在有人动的时候主动提醒，还要把报警两段链路打开，见 [移动侦测报警与回放设置](移动侦测报警与回放设置.md)。App 本身还没装好的，先看 [手机端下载安装流程](手机端下载安装流程.md)；更多用法整理在 [v380pro 看家手记](https://v380pro.qhah.skin/)。
