# kikoeru 登录不上与加载失败排查

> 按现象对号入座：登录界面进不去、仓库刷不出来、锁屏就断、闪退卡顿，一条一条来。
> 这些现象多数与账号本身无关，环境与设置占大头。应用的整体功能背景，见 [kikoeru 功能与睡前收听介绍](https://kikoeru.fewf.click/)。

## 一、登录界面登不上

按出现频率排：

1. **服务器选错**：登录前先确认选的是教程普遍建议的 **200**，这是首次使用最容易漏的一步；
2. **网络环境**：换一个 Wi-Fi 或切数据网络再试，是最省事的排除法；
3. **账号密码**：确认是注册过的账号；密码不对就在登录界面走找回或重新注册。

登录的完整顺序（先选服务器、再输账号）在 [从登录到播放的完整流程.md](从登录到播放的完整流程.md) 第一节。

## 二、仓库或作品加载不出来

- **单个作品失败**：多是这条内容的临时问题，退出重进或换一集；
- **整个仓库刷不出来**：回登录页确认服务器选项，切换网络重连；高峰时段响应会慢，加载页多等几秒；
- **锁屏后就断、通知栏播不了**：把应用加入系统的后台保护或白名单，别让省电策略断它的网（路径因品牌而异）；闹钟不响也先查这条。

## 三、闪退或卡顿：先清缓存

闪退、界面卡住时，先用系统自带清理而不是直接卸载：

1. 手机**设置 → 应用管理 → kikoeru → 存储**；
2. 点**清空缓存**——注意不是「清除数据」，清数据会把登录状态和本地记录一起抹掉；
3. 重新打开应用。

清完仍闪退，重启一次手机再试；个别老旧系统版本带不动新应用，属于环境限制。

## 四、下载的音频找不到

保存位置随机型与版本变化：打开应用的**设置**，找「下载设置 / 存储路径 / 音声库路径」一类的选项，当前路径显示在那里，也可以直接改，改完重启应用生效。

## 五、搜到的资料对不上号

「kikoeru」这个名字下至少有两套东西：一套是需要自己架设的服务端项目（Docker 镜像、网页版教程那一类），另一套才是手机上直接装的安卓应用。看教程时先分清对方讲的是哪套——桌面端的操作描述（空格键暂停之类）对触屏手机并不适用。界面与功能的全貌对照，见 [kikoeru 功能与睡前收听介绍](https://kikoeru.fewf.click/)；播放相关的设置（字幕、倍速、定时）在 [悬浮字幕与歌词设置.md](悬浮字幕与歌词设置.md) 与 [从登录到播放的完整流程.md](从登录到播放的完整流程.md) 里分别有展开。
