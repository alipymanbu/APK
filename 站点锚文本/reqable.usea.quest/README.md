Reqable 把抓包调试和 REST 接口测试放在同一个应用里：手机端靠本机 VPN 接管流量，浏览器与 App 的请求逐条进列表；装上它生成的 CA 根证书，HTTPS 内容也能解析成明文。上面几篇按「入门 → 证书 → 协同」的顺序各讲一面，遇到安装问题可以直接看介绍站里的[安卓版安装步骤](https://reqable.usea.quest/download.html)。
