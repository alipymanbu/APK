# 安卓预装应用怎么安全冻结

> 本篇讲清「冻结」到底动了什么、没 root 的手机权限从哪来、以及冻结前后的稳妥顺序。
> **相关文档**：[安卓应用管理器怎么挑.md](安卓应用管理器怎么挑.md)

---

## 一、先弄清冻结到底做了什么

冻结在系统层面的效果等于「停用」：应用图标从桌面消失、后台彻底停止、不再自启，但安装文件和数据都原样留在原处，随时可以解冻还原。它和卸载的区别就在这条退路上——卸载把应用真正移除，冻结只是让它闭嘴。

对预装应用来说，这条退路很重要：有些预装组件你不确定别的功能会不会依赖它，先冻结观察几天，手机没出现异常再考虑进一步处理；万一出了问题，解冻一次就回到原样。

## 二、动系统应用的前提：权限从哪来

用户应用自己就能冻结；要动系统预装的那部分，管理工具得先拿到越过应用沙箱的权限。常见的引擎有三种，按手机状态对号入座：

| 引擎 | 权限从哪来 | 重启手机后 |
| --- | --- | --- |
| Root | 手机已 root，在授权管理里放行 | 仍然有效 |
| Shizuku | Android 11 及以上用无线调试启动服务（配对一次），10 及以下连电脑 ADB | 服务停止，需重新启动一次 |
| Dhizuku | 把 Dhizuku 设为设备所有者 | 仍然有效 |

没 root 的机型大多走 Shizuku 这条路：在开发者选项里打开无线调试，到 Shizuku 里用配对码配对（只需要一次），点启动后再回管理工具授权。要注意的是没 root 时 Shizuku 服务在每次重启后都会停，重新点一次启动即可，不必重新配对。

具体到 Thor 这款管理器，三种模式在设置里切换， [Thor 应用管理器介绍站](https://thor.fewa.skin/) 把三种引擎的能力差异整理成了一张对照表，选型前可以先看一眼。

## 三、冻结的稳妥顺序

1. **从明显安全的下手**：自己装过又不再用的用户应用、确定用不上的预装（比如重复的浏览器、推广类应用），先冻结这批。
2. **每批少冻几个**：一次冻结两三个，用半天到一天，确认输入法、相机、支付这些日常功能都正常，再继续下一批。
3. **拿不准的先查证**：对不认识的进程名，先搜一下它在系统里的角色，再决定冻不冻。少数关键组件被停用可能导致桌面、通话或支付异常。
4. **留好记录**：冻了哪些、什么时候冻的，简单记一笔。还原时心里有数。

## 四、冻结之后怎么还原

解冻就是反向操作：在管理工具里找到状态为已停用的应用，点解冻，图标和数据都会回来。有一个细节容易踩：如果冻结和还原两次操作用了不同的引擎（比如冻结时用的是 Root，还原时 Shizuku 服务已经停了），解冻可能报错——切回当初冻结时用的那个模式再操作就能解开。

换新手机或系统大更新后，预装应用可能被重新装回，把冻结流程再走一遍就行。挑工具时看重哪几条，可以接着读 [安卓应用管理器怎么挑.md](安卓应用管理器怎么挑.md)。
