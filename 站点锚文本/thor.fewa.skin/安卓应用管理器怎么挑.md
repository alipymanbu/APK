# 安卓应用管理器怎么挑

> 本篇按真实使用场景把安卓应用管理器的能力拆开对照，帮你对号入座选出趁手的那款。
> **相关文档**：[安卓预装应用怎么安全冻结.md](安卓预装应用怎么安全冻结.md)

---

## 一、先想清楚你要它做什么

这类工具的名义都叫「应用管理」，实际能力差别很大。挑之前先把自己的需求排个序：

- **只是想看清手机里有什么**：清单、搜索、按体积或来源排序；
- **想清理预装**：冻结、卸载，以及动系统应用所需的权限通道；
- **会换机或折腾刷机**：把已装应用提取成安装包留存；
- **装了 XAPK、分割包装不上**：从文件直接安装各类包体。

需求越靠后，对工具能力的要求越高，值得花时间挑；只是想看清单的话，随手装一个都够用。

## 二、按能力对照

把 Thor 这类管理器的常见能力摆在一起，挑的时候逐项对：

| 能力 | 用来做什么 |
| --- | --- |
| 高级筛选 | 按安装来源区分商店应用与侧载应用，快速定位来路不明的包 |
| 冻结与解冻 | 停用预装应用且保留数据，随时可逆 |
| 批量操作 | 勾选多个应用一次完成重装、卸载或终止进程 |
| 提取与分享安装包 | 把已装应用导出成 APK 文件，换机留存用 |
| 从文件安装 | APK 之外还能接 XAPK、APKS 与分割包，多 APK 结构有单独标记 |
| 状态标记 | 列表里直接标注哪些已停用、哪些是分割包 |

Thor 在这几项上都有对应实现，界面用 Material 3 写成，浅色、深色与 AMOLED 纯黑三种主题，动态色彩会跟着系统壁纸走。它是开源项目，代码以 GPLv3 发布、不含统计与跟踪组件，对隐私敏感的人这点可以自己读源码验证；安装包本身也很轻。

## 三、权限通道决定了能力上限

清单、筛选、提取安装包这些普通权限就能做；冻结系统应用、批量卸载这类深层操作，取决于工具接的权限引擎——Root、Shizuku 还是 Dhizuku，各家工具的接法大同小异，能力覆盖却有差别。挑的时候注意两点：一是没 root 的机型 Shizuku 通道是否顺畅（Android 11 及以上无线调试最省事）；二是重启手机后权限还在不在、要不要重新启动服务。

## 四、装上之后的第一个动作

装好后别急着清理，先进设置把权限模式接通，再从冻结而不是卸载开始试手。另外，应用市场里同名的管理工具不少，认准包名（Thor 是 `com.valhalla.thor`）能避免装混。能力与选型的更完整对照，可以看[安卓应用管理器 Thor 的介绍站](https://thor.fewa.skin/)；冻结具体怎么动手、出错怎么还原，见 [安卓预装应用怎么安全冻结.md](安卓预装应用怎么安全冻结.md)。
