# 在手机上把追番列表管起来

> 查到作品只是第一步：状态、打分、收藏都记下来，才是「追番」。本篇讲手机端怎么维护这份列表，以及它和网页端的关系。
> **相关文档**：[俄文追番客户端上手.md](俄文追番客户端上手.md) · [换手机追番记录不丢.md](换手机追番记录不丢.md)

---

把作品加进列表、收藏角色、发评论这些动作都要先登录——账号在 Shikimori 网页端注册，手机客户端登录同一套。登录之后你标记的每个状态都会存进网站账号，网页端打开看到的是同一份数据。

## 一、六种状态，对应追番的每个阶段

在作品详情页找到加入列表的按钮，选一个状态：

| 状态 | 含义 |
|---|---|
| Запланировано | 计划看 |
| Смотрю | 在看 |
| Просмотрено | 已看完 |
| Пересматриваю | 重看中 |
| Отложено | 搁置 |
| Брошено | 弃了 |

选完状态还能打分、填已看集数。个人资料页里可以按状态过滤查看，一列下来就是当季的追番进度。

## 二、收藏分两条线，别混着找

作品的收藏跟着列表走；**角色和人物有单独的收藏入口**。喜欢某位声优、想把 TA 的作品攒起来时，先进人物页再收藏，回头在个人资料里能单独翻出来。

## 三、放送日历配合状态用

侧边菜单里的放送日历按星期列出当季每集的更新时间。计划看的作品一多，靠记忆很容易漏——每天扫一眼日历，看完就把状态改成「已看完」，列表才不会越积越乱。

手机上改起来最顺手，这也是它和网页版最大的分工差异：查资料哪边都行，**记录进度在手机上最快**。上面提到的界面词汇，[Shiki 介绍站](https://shiki.usea.quest/)里有一份按截图标注的中俄对照，动手前值得花两分钟过一遍。登录环节遇到问题（昵称、大小写、输入法布局），见 [换手机追番记录不丢.md](换手机追番记录不丢.md)。
