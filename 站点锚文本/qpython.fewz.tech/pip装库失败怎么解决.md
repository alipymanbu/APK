# pip装库失败怎么解决

> 在安卓端的 Python 环境里装第三方库，装不上、超时、编译失败是最常撞到的问题。按「先选路线、再配镜像、最后按报错类型排查」的顺序走一遍，大部分库都能装上。
> **相关文档**：[手机Python环境怎么选](手机Python环境怎么选.md) · [手机跑本地大模型入门](手机跑本地大模型入门.md)

---

## 一、先选对装库路线

以 QPython 为例，装第三方库有两条路，先走对路能省掉一半麻烦：

| 路线 | 入口 | 适合装什么 |
| --- | --- | --- |
| QPYPI（预编译包） | 应用内的「扩展 / QPYPI」 | 按安卓环境预编译好的常用包，点选即装，不用敲命令 |
| pip 命令 | 终端里 `pip3 install ...` | QPYPI 上没有的包、需要锁版本的包 |

优先从 QPYPI 找——那里的包是针对安卓环境准备好的；QPYPI 没有再走 pip。

## 二、pip 装不上，第一反应是换镜像源

默认源在境外，国内网络下超时是装库失败的头号原因。给 pip 指定国内镜像：

```bash
pip3 install requests -i https://pypi.tuna.tsinghua.edu.cn/simple
```

锁版本照抄教程里的版本号，避免新版接口变了报错：

```bash
pip3 install requests==2.25.1
```

装完在同一个终端里验证：

```python
import requests
print(requests.__version__)
```

能打印出版本号，这个库就算装好了。更多装库姿势与整站介绍，见[QPython 介绍站](https://qpython.fewz.tech/)。

## 三、按报错类型排查

### 1. 超时 / 连接类报错（`ReadTimeout`、`Connection timed out`）

网络问题。带上镜像源重试；手机在 Wi-Fi 与流量之间切换也会挂起请求，切回稳定网络再装。

### 2. 编译类报错（`Failed building wheel`、找不到 `gcc`）

这个包带 C 扩展，需要在手机上现场编译，而手机上没有完整工具链。**这不是命令敲错了**，别反复重试同一个包：换 QPYPI 里的预编译版本，或找纯 Python 的替代品。部分科学计算、数据库驱动类库在手机上本来就受限。

### 3. 依赖冲突

先只装你直接要用的那个包，让 pip 自己解依赖；仍冲突就锁一个较旧、彼此兼容的版本。

### 4. 明明装了却 `ModuleNotFoundError`

`pip3 list` 确认包在不在；再检查是不是用两条路线装过同名包——QPYPI 装过又用 pip 装一遍，可能让解释器加载到旧的那份。先 `pip3 uninstall 包名` 清干净，再走单一路线重装。

### 5. SSL / 权限类报错

SSL 握手类异常（如 `NO_CIPHERS_AVAILABLE`）属于环境层兼容问题，先确认同一地址在系统浏览器打得开，再针对自己脚本调整请求；读写文件报 `EACCES` 是权限没开，到系统设置的应用权限页里允许文件访问，或把文件挪到应用自己的目录下。

## 四、装完的库放哪了

pip 装的库落在应用自己的目录下的 site-packages，终端和编辑器里 `import` 都能拿到，不需要配 `PYTHONPATH`。查看与卸载：

```bash
pip3 list
pip3 uninstall 包名
```

库和脚本是两回事：库在应用目录里，脚本存在你保存时选的文件夹。常用的库装齐之后，可以试试更进阶的玩法——在本机跑开源模型，见 [手机跑本地大模型入门](手机跑本地大模型入门.md)。
