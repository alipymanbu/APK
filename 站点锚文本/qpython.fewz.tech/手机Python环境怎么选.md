# 手机Python环境怎么选

> 搜索结果里同名或近名的应用不止一个，讲清 QPython 两条分支的定位、包名核对方法，以及它与 Termux、Pydroid 各自适合什么人。

## 一、先分清：名字相近的不一定是同一个应用

在手机上搜「Python」，会同时看到好几个名字相近的应用。判断它们是不是同一个，**别看图标和标题，看包名**——包名才是最可靠的同一性依据。

以 QPython 为例，市面上能搜到的相关应用大致分三类：

| 你看到的 | 包名 | 说明 |
| --- | --- | --- |
| QPython（现行版本） | `org.qpython.qpy` | 本文讨论的对象，两条分支的现行版本都归这里 |
| QPython3（历史分支的商店页） | `org.qpython.qpy3` | 与上面不是同一个包，老教程里常见 |
| 各类历史安装包 | 视分支与版本而定 | 多来自开源项目的 release 页，版本较旧 |

装之前到商店页或安装信息里核对一眼包名，比装完再纠结要省事得多。

## 二、QPython 自己分了两条线

QPython 按使用场景分两个分支，这是项目说明里写明的划分：

| 分支 | 面向谁 | 适合的场景 |
| --- | --- | --- |
| QPython Ox | 编程学习者 | 界面与功能对新手更友好，第一次在手机上写 Python、想快点跑起来看结果 |
| QPython 3x | 有经验的 Python 用户 | 提供更进阶的技术特性，要调更底层的能力、跑更复杂的项目 |

两个包可以装在同一台手机上（包名不同，系统当成两个应用），但**脚本与已装的第三方库互不共享**——在一个里装的库，另一个里 import 不到。除非确实要对比两条线，装一个就够。

分不清要装的版本时，可以从[QPython 安卓版介绍站](https://qpython.fewz.tech/)入手，那里把功能入口、真实界面与获取方式整理在了一起。

## 三、和 Termux、Pydroid 的取舍

手机上跑 Python 并非只有一种形态，常见的三类各有侧重：

| 你要做的事 | 更合适的选择 |
| --- | --- |
| 边学边练、写短脚本、让脚本调手机硬件 | QPython 这类现成界面 + 系统调用能力的环境 |
| 要 git、要完整命令行、要后台常驻服务 | Termux 这类类 Linux 终端环境 |
| 只想要个带补全的编辑器写纯 Python | Pydroid 这类 IDE 形态应用 |

这张表按用途给方向，不是排名。QPython 的差异化在于**用 Python 驱动安卓设备**：弹提示、读传感器、调相机这些系统能力有专门接口，这是它区别于纯终端或纯编辑器的地方。

## 四、选定之后的两个注意点

1. **系统版本门槛**：不同版本对安卓系统版本的要求会随发布变化，下载前以商店页当时标注为准。手机系统低于门槛时，往往装得上但没法更新。
2. **装完核对一遍**：到 设置 → 应用管理 里确认包名与版本，对得上再开始写代码。之后装库遇到问题，排查思路见 [pip装库失败怎么解决](pip装库失败怎么解决.md)；想在手机上跑大模型的，看 [手机跑本地大模型入门](手机跑本地大模型入门.md)。
