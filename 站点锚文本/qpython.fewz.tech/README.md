# QPython 安卓版 · 介绍站导读（qpython.fewz.tech）

这里是 QPython 的第三方介绍与使用说明目录：QPython 是装在安卓手机上的 Python 环境，内置解释器、编辑器、Notebook 与 QPYPI 包管理，还集成了 Ollama 框架，可以在本机运行 Llama 3.3、DeepSeek-R1 等大语言模型。

站点入口：[QPython 安卓版介绍站](https://qpython.fewz.tech/)，上面有完整的功能梳理、真实界面截图与安装文件资源获取方式。
