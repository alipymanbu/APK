# 图源配置与换源技巧

> 聚合漫画阅读器装完是空的，能不能用起来全看图源。本篇整理 Cimoc 的图源添加方式、启停管理、失效判断与换线路的实操思路。
> **相关文档**：[安卓聚合漫画阅读器使用答疑](安卓聚合漫画阅读器使用答疑.md)

## 一、图源从哪来

Cimoc 本身不带任何漫画内容，它只是一个聚合阅读器：所有能看的漫画都来自你导入的图源（各家漫画网站的接口配置）。图源地址通常由社区整理分享，常见形态是一段 JSON 列表链接；项目自己的发布页与频道会随版本说明当前可用的获取途径，别长期收藏任何一个「固定地址」——列表地址会过期，这是这类工具的常态。

## 二、三种添加方式

1. **批量导入（推荐）**：侧边栏进「图源」页 → 右上角菜单 → 导入图源 → 粘贴 JSON 列表地址确认，一次进来一整批站点条目；
2. **手动单个添加**：同一菜单选手动添加，依次填图源 ID、名称、网址保存，适合手里只有一个接口地址的情况；
3. **扫码添加**：新版本支持二维码识别，别人发来源码图直接扫。

导入后按需勾选启用。搜索只在你启用的源里进行，**启用的源越多，单次搜索越慢**，留几个常用的就好。

## 三、失效了怎么判断、怎么换

- **个别源搜不出**：先换关键词再试一次（同一部作品常有不同译名），仍没有就把这个源停用或删除，避免每次搜索都白等它超时；
- **大面积搜不到**：多半是列表整体过期或版本太旧，先更新源列表，再升级版本——图源解析逻辑随站点改版走，老版本对改版后的站点会失效；
- **阅读中加载失败**：同一部漫画常被多个源收录，阅读界面里直接唤出菜单换一条线路，这是最直接的解法；
- **下载失败**：检查存储空间与文件访问权限，批量下载时把应用留在后台，别从最近任务里划掉。

## 四、别忘做备份

图源配好了、书架攒起来了，记得做一次备份：收藏、历史与设置支持本地备份，也能走 WebDAV 推到网盘，换机恢复只需一分钟。图源是否会随备份恢复各方说法不一，稳妥预期是恢复后重新导入一遍列表。
