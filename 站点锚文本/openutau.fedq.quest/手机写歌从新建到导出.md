# 手机写歌从新建到导出

> 装好应用、导好声库之后，这篇走一遍从新建工程到导出音频的最小完整流程：创建分片、写音符、填歌词、调参数，以及几个新手最容易卡住的点。
> **相关文档**：[声库去哪找与怎么导入.md](声库去哪找与怎么导入.md) · [手机版歌声合成编辑器怎么选.md](手机版歌声合成编辑器怎么选.md)

## 开工前确认两件事

- 至少导入了一个声库（还没装的先看[声库去哪找与怎么导入.md](声库去哪找与怎么导入.md)），否则后面选不到歌手；
- 界面还是英文的话，先花一分钟换成中文：右上角 options → settings → language 选简体中文，重启应用生效。

## 完整流程

社区教程里通行的操作顺序如下：

1. 主页点 `New` 新建工程，进入编辑界面；
2. 点右上角图标**创建分片**——一段可以放音符的区域；
3. 在分片上**选择歌手**（你导入的声库角色）；
4. 在钢琴卷帘上点对应位置**创建音符**，拖动音符边缘的手柄调时值长短；
5. **双击音符**进入歌词编辑：日文声库填假名或对应读音，中文声库填汉字或拼音，以声库说明为准；
6. 点音符侧边的曲线图标，进入**音高 / 动态参数**微调；
7. 点左上角箭头修改整个工程的 **BPM**。

应用内置合成引擎，编辑过程中随时能试听，不用等整首渲染完。

两个新手共同的坑：

- **忘了改歌词**：1.1.3 起新建音符的默认歌词是 `a`，不填词它就一直唱 a——这是"有声音但不对"，不是没声音；
- **找不到下笔的地方**：编排区右侧有个铅笔按钮切换只读 / 编辑模式，要先切到编辑模式在空白处滑动划出分片，再进钢琴卷帘写音符。

## 值得记住的几个操作

- **磁铁按钮**：点按开关网格吸附，长按调网格密度（量化精度）——写快歌调细、慢歌调粗；
- **轨道管理**：轨道头上点彩色标签静音、点头像换歌手、拉滑杆调音量声像，底部 `+` 号加轨；
- **AI 悬浮按钮**：用 DiffSinger 这类支持自动音高的渲染器时会出现，一键加载自动音高结果；
- **哼旋律变音符**：1.1.7 起可以把一段音频识别成音符草稿，搭主歌结构时很省事。

## 导出与保存

- 导出格式以软件内导出菜单实际可选的为准（多篇资料提到 WAV，也有来源提到 MP3、OGG）；导出的是干声，加伴奏要在其他音频软件里合成；
- 有用户反馈导出时锁屏会中断导出——导出前把屏幕常亮打开，过程中别切后台；
- **最重要的一条：勤保存**。项目仓库说明里写明软件目前还不够稳定、可能出现内存管理问题；每写完一段就点一次保存，万一闪退，到工程目录找 `.autosave.ustx` 结尾的恢复文件能找回大部分内容。
