# 手机版歌声合成编辑器怎么选

> 想在安卓手机上让虚拟歌手开口唱，绕不开 OpenUtau 这个名字。这篇把 OpenUtau 与它的移动端分支 OpenUtau Mobile 分清楚，讲明白后者能在手机上干什么、干不了什么，帮你判断它是不是你要找的那个工具。
> **相关文档**：[声库去哪找与怎么导入.md](声库去哪找与怎么导入.md) · [手机写歌从新建到导出.md](手机写歌从新建到导出.md)

## 先分清两个名字

| 名字 | 是什么 |
| --- | --- |
| OpenUtau | 电脑端的开源歌声合成编辑器，UTAU 社区的现代化替代品，支持 Windows、macOS、Linux |
| OpenUtau Mobile | 社区开发者 vocoder712 基于 OpenUtau 内核改造的**移动端编辑器**，Apache 2.0 协议开源，装在安卓手机上 |

两者是"内核同源、两端分工"的关系：手机端直接基于 OpenUtau Core 构建，所以桌面版的 `.ustx` 工程文件在手机上完整可用——电脑上做一半的歌拷进手机接着写，手机上记的灵感草稿回电脑打开还是同一份工程。

## 它能在手机上做什么

- **完整的钢琴卷帘编辑**：点按创建音符、拖动改时值、双击填歌词，底部扩展区还能画音高、颤音、音量包络这些表情参数；
- **多轨编排**：主唱、和声分轨管理，每条轨可以指定不同歌手，做合唱不用来回切工程；
- **三类声库**：DiffSinger（AI 神经网络合成，出声自然）、UTAU（传统采样拼接，调音空间大）、Vogen（中文 AI）都能装；
- **离线合成**：AI 推理全部在本机完成，不联网也能出声；
- **中文界面**：options → settings → language 选简体中文，重启生效。

1.1.7 版本还补上了音符多选、复制、粘贴、轨道导入，以及"把一段音频识别成音符"——哼一段旋律就能生成音符草稿。

## 它干不了什么

- **追求绝对稳定的生产环境**：项目仓库首页写明软件目前仍不够稳定，内存管理问题可能频繁出现，建议只有一条——勤保存（闪退后可以到工程目录找 `.autosave.ustx` 恢复文件）；
- **重度精细调音**：小屏上画参数曲线效率有限，社区通行的分工是手机出草稿、电脑做精修；
- **iOS 直接安装**：iOS 版没有现成安装包，需要自己在 macOS 上编译，普通用户可忽略。

## 系统要求与安装

项目仓库给出口径为 Android 5.0 及以上（部分渠道另称 8.0+），安装包 1.1.7 版约 238MB，安装流程与常见拦路问题（未知来源授权、跨版本签名的坑）已单独整理在 [OpenUtau Mobile 口袋合成站](https://openutau.fedq.quest/) 的下载安装页里。

装好之后第一件事是给它一个声库——没有声库它就只是一架不出声的钢琴卷帘，去哪找、怎么装见 [声库去哪找与怎么导入.md](声库去哪找与怎么导入.md)。
