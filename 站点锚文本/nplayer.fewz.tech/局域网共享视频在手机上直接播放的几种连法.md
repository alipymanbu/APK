# 局域网共享视频在手机上直接播放的几种连法

> NAS、盒子、电视硬盘里的视频想用手机直接看，路子就那几条：SMB、WebDAV、FTP/SFTP、UPnP/DLNA——这篇按协议分开说，各自适合什么情况、要填什么。

## 连之前确认两件事

- **手机和 NAS 在同一个局域网里**（连的同一个路由器 Wi-Fi）；人不在家要看，得先在 NAS 那头把服务映射到外网或走内网穿透，这是网络配置的事，跟播放器无关。
- **你手里有对应设备的地址和账号**：NAS 的 IP 或主机名、共享目录的登录用户名密码。

## 按协议分：各自适合什么

**SMB/CIFS——家庭共享的默认选项。** Windows 电脑的共享文件夹、群晖/威联通之类 NAS 的文件共享，走的基本都是它。播放器里选新建 SMB 连接，填地址、用户名、密码三样，目录列表就出来了。

**WebDAV——盒子和自建服务常用。** 很多电视盒子、网关服务对外开的是 WebDAV 口，地址通常长成一个 http(s) 链接加路径，连同账号填进播放器即可。公开到外网看片，WebDAV 也是最常见的承载方式。

**FTP / SFTP——老设备与命令行爱好者。** 老 NAS、路由器挂载的硬盘常年开着 FTP；有 SSH 在手的设备可以直接走 SFTP。速度不占优，胜在哪儿都开得出。

**UPnP/DLNA——不用填地址的一条。** 局域网里的媒体服务（电视、盒子、NAS 的 DLNA 功能）会自动冒出来，「扫描网络」扫一遍就能看到，适合不想碰任何设置的场合。缺点是只能看对方共享出来的媒体库，不如 SMB 那样整个目录随便翻。

## 云盘是同一套逻辑的延伸

Box、Dropbox、Google Drive、OneDrive、Yandex.Disk、Amazon Cloud Drive 这类云盘，在支持它们的播放器里登录后，目录会和局域网共享并列出现在同一个列表里，点开也是直接流播——「文件在哪都直接播」这件事是连着的：局域网一层，云盘一层。

## 推荐的连法组合

手机装一个协议覆盖面全的直读型播放器，把家里常用的两三种协议各建一个连接存着，之后打开应用就是目录列表，点开即播。nPlayer 就是按这个思路设计的播放器——SMB/CIFS、WebDAV、FTP、SFTP、UPnP/DLNA 全覆盖，云盘也在同一面板登录，具体的功能与协议清单整理在 [nPlayer 介绍站](https://nplayer.fewz.tech/)。
