## 一、先分清两类方案：云端中转 vs 局域网直连

在电脑上管理安卓手机，市面上能搜到的工具分两条技术路线，体验差别很大：

| 对照项 | 云端中转型 | 局域网直连型 |
| --- | --- | --- |
| 数据走向 | 手机 → 厂商服务器 → 电脑 | 手机 ↔ 电脑，同一条 Wi-Fi |
| 账号 | 必须注册登录 | 通常不需要 |
| 免费档限制 | 常见单文件 30MB、每月 200MB 流量 | 无此限制，速度就是 Wi-Fi 速度 |
| 人在外网 | 天然可用 | 不内置，需自建 VPN 或开热点凑同一网络 |

一句话判断：在意「人在公司也能碰家里手机」选云端型；在意「照片短信不出家门」选局域网型。本文主角 PlainApp 属于后者——开源（AGPL 3.0）、免账号、无广告，Google Play 安装量 1.3M+，GitHub 星标 6.5K+。

## 二、局域网直连是怎么工作的

原理一句话：手机上跑一个 Web 服务，电脑浏览器访问它。

1. 手机安装应用后点「启动」，应用在你手机上开一个本地网页服务；
2. 屏幕上列出形如 `http://192.168.1.50:8080` 的地址（HTTPS 一般是 `:8443`）；
3. 同一 Wi-Fi 下，电脑任意浏览器（Chrome、Edge、Firefox、Safari 都行）打开这个地址；
4. 你看到的就是一个完整的手机管理面板。

不需要给电脑装任何客户端，浏览器就是全部。用得勤的话，还可以用 Chrome/Brave 把这个网页「安装」成 PWA，变成一个独立窗口，观感接近原生应用。

## 三、以 PlainApp 为例：完整连接流程

1. **启动服务**：打开应用，主界面点「启动服务」，按钮变成红色「停止服务」即已上线；
2. **读地址**：界面上会列出多个地址，明文 `http://IP:8080` 与加密 `https://IP:8443` 都可以试；
3. **电脑打开**：浏览器输入地址，**末尾的端口不能漏**——只输 IP 是打不开的；
4. **按项授权**：网页端能碰哪些能力（文件、联系人、短信……）在手机端逐项开关，默认最小化。

首次连接的两个正常现象，别当成坏了：

- **「您的连接不是私密的」警告**：加密证书由手机本地自签，浏览器无法向公共机构核验，点「高级 → 继续访问」即可，或改用 `http://` 地址；连接建立后数据仍有加密保护。
- **地址打不开**：先确认两台设备连的是同一个 Wi-Fi；个别路由器开了「AP 隔离」会挡住互访；重启路由器后手机 IP 可能变化，以应用界面当时显示为准。

## 四、浏览器面板里通常有哪些能力

以 PlainApp 为例，局域网面板的典型能力覆盖面已经超过多数云端工具的免费档：

- **文件**：内部存储、SD 卡、U 盘浏览，上传下载、改名、移动、删除全在网页上做；
- **照片 / 视频 / 音乐**：浏览器直接翻相册、播放，不用先把文件拷出来；
- **短信与通话记录**：电脑键盘回短信，通话记录可搜索筛选（注意：Google Play 商店版因政策少了短信相关能力，直装包完整）；
- **屏幕镜像**：把手机画面实时投进浏览器，见 [手机屏幕镜像到浏览器.md](手机屏幕镜像到浏览器.md)；
- **通知同步**：手机通知实时出现在网页上，忙电脑时不漏消息；
- **应用管理**：列出已装应用，支持导出 APK 备份。

## 五、人在外面，还能连上家里的手机吗

局域网方案的设计场景就是同一网络，跨网访问不内置。两个现成思路：

1. **手机开个人热点，电脑连这个热点**——两台设备进了同一网络，原样能用，适合「人在车上/酒店想倒文件」的场景；
2. **自建 VPN 回家**——能打通但属于网络工程，折腾成本自己掂量，工具本身不提供现成通道。

## 六、怎么判断一个管理工具靠不靠谱

不替你下结论，只给三个可以自己核实的检查点：

- **源码是否公开**：开源许可（如 AGPL 3.0）意味着代码可审计，`https://github.com/plainhub/plain-app` 这类仓库地址可以直接翻；
- **数据走不走第三方**：抓包或看文档说明，确认传输是否只在局域网内完成；
- **免费档的真实边界**：把「单文件大小、月流量、必需账号」逐条问清，云端型工具的差异全在这里。

把这三条套到任何一款工具上都成立，选型前花五分钟核实，比事后发现传输被限流划算得多。
