## 一句话认识 PlainApp

开源（AGPL 3.0）的安卓应用：手机上点「启动服务」，同一 Wi-Fi 下的电脑浏览器打开界面显示的地址，就能管文件、看相册、回短信、投屏、同步通知——免账号、无广告、传输不设体积上限，数据全程不离开局域网。
