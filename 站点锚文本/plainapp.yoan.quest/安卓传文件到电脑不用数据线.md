# 安卓传文件到电脑不用数据线：Wi-Fi 直连的几种做法

> 数据线找不到、蓝牙慢到着急、微信传给自己又压画质——本文对比几种无线传文件的常见做法，重点讲局域网直连方案（以 PlainApp 为例）：怎么连、速度预期、以及大文件到底有没有限制。

## 一、先对齐需求：你传的是照片还是几十 GB 的视频

传文件方案没有万能答案，量级决定选择：

| 场景 | 合适的路子 | 原因 |
| --- | --- | --- |
| 一两张截图随手倒 | 聊天工具「文件传输助手」、云剪贴板 | 快，但画质常被压缩 |
| 每次几百张照片 | 局域网直连工具 | 批量、原画质、速度取决于 Wi-Fi |
| 几 GB 到几十 GB 视频 | 局域网直连工具 | 云端免费档普遍限流，数据线又容易找不到 |

本文讲的就是中间那一格：手机和电脑在同一 Wi-Fi 下，把手机当成一台局域网里的存储来访问。

## 二、局域网直连的原理与速度预期

手机上跑一个本地 Web 服务，电脑浏览器打开它给出的局域网地址（形如 `http://192.168.x.x:8080`），之后：

- **下载**：在网页里选中文件，浏览器直接拉取，速度就是 Wi-Fi 的真实速度；
- **上传**：把电脑里的文件拖进网页，落到手机存储指定的目录；
- **在线看**：照片、视频、音乐可以不落地直接在浏览器里播放，有些场景根本不用「传」。

实测速度主要由路由器决定：Wi-Fi 5 环境跑几十 MB/s 很常见，比蓝牙快两个数量级，比走云端的方案通常快 5~10 倍（云端要把数据先传上服务器再下回来）。

## 三、以 PlainApp 为例的操作步骤

1. **手机端启动**：打开应用点「启动服务」，界面出现 `http://IP:8080` 这样的地址（HTTPS 是 `:8443`）；
2. **电脑浏览器打开地址**：端口别漏；首次 HTTPS 会弹「连接不是私密的」，点「高级 → 继续访问」即可，这是本地自签证书的正常表现；
3. **进文件面板**：内部存储、SD 卡、U 盘都能浏览，支持上传、下载、重命名、移动、删除；
4. **大文件随意传**：这一类工具一般**不设单文件体积与月度流量上限**——几十 GB 的录屏直接拉，不用拆包。

两个容易忽略的点：

- 手机和电脑必须**连同一个 Wi-Fi**；人不在家时，让电脑连手机的个人热点，就凑成了同一网络；
- 重启路由器后手机 IP 可能变，地址以应用界面当时显示的为准，别背旧地址。

工具本身的开源情况与功能全貌，可以看这篇 [PlainApp 介绍站](https://plainapp.yoan.quest/)，文件、相册、短信、投屏各板块都有截图对照。

## 四、常见卡点与处理

- **网页打不开**：先查端口；再查两台设备是不是同一 Wi-Fi（访客网络经常互相隔离）；最后查路由器「AP 隔离」设置。
- **传到一半断了**：多为手机省电策略杀后台，到电池设置里给应用「不限制后台」；锁屏必断的，把该应用加入电池优化白名单。
- **HEVC (H.265) 视频在线播放没画面**：浏览器解码支持问题，下载下来用本地播放器看，或把拍摄格式改成 H.264。

更多连接类问题（证书警告、地址失效、热点组网）在 [电脑浏览器管理安卓手机.md](电脑浏览器管理安卓手机.md) 里按步骤排过一遍，建议先读那篇再动手。

## 五、什么情况下仍建议数据线

- 需要刷机、 adb 调试这类系统级操作；
- 路由器老旧、Wi-Fi 挤满设备，速率反而不如 USB 2.0；
- 一次性迁移整机数据——用厂商自家的换机工具更省心。

日常「照片倒电脑、视频拉回手机」这类高频动作，局域网方案连上一次之后，基本就再也想不起来数据线放哪儿了。
