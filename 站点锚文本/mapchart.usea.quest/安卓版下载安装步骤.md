# MapChart 安卓版怎么下载安装

> 本篇回答一个高频问题：想在一台安卓手机上装 MapChart，安装包从哪拿、装之前确认什么、装完第一次打开是什么样，以及装不上时的三个常见原因。玩法层面的内容在 [地图填色上手教程.md](地图填色上手教程.md)。

## 一、装之前先看三件事

| 项目 | 说明 |
| --- | --- |
| 系统版本 | 商店页面对较新版本标注 Android 11 及以上，旧机型先确认系统 |
| 存储空间 | 安装包约 92.55 MB，装完连同地图数据与缓存建议预留 300 MB 以上 |
| 应用来源 | 认准开发者 whidev、包名 com.whidev.mapchart，别装来路不明的改包 |

## 二、获取与安装的完整路径

1. 打开 [MapChart 地图填色手册](https://mapchart.usea.quest/)，从下载页进入安装文件资源的网盘分享页；
2. 把分享里的安装包转存到自己网盘账户，再用网盘客户端下载到手机存储；
3. 在文件管理器里点开 APK，首次安装按提示允许「安装未知来源应用」；
4. 点安装，进度走完后选择打开，看到地图列表即成功。

## 三、装不上时的排查

| 现象 | 原因与处理 |
| --- | --- |
| 解析包出现问题 | 安装包没下完整，重下再装；或系统低于版本要求 |
| 存储空间不足 | 清出一部分空间后重试 |
| 与已安装应用冲突 | 先卸载旧渠道的同包名版本再装 |

## 四、装完先干什么

不需要注册账号，打开就是地图列表。想直接动手画一张，按 [地图填色上手教程.md](地图填色上手教程.md) 的三步走；拿不准挑哪张底图的，先翻 [底图分类与选用思路.md](底图分类与选用思路.md)。
