# MapChart 怎么用：从选图到导出

> MapChart 的核心玩法可以概括成三步：点国家或州填色、填图例、导出图片。本篇按手机上的实际操作顺序展开，每一步给足细节，读完就能画出第一张完整的填色地图。

## 一、认识两个功能按钮

| 按钮 | 位置 | 管什么 |
| --- | --- | --- |
| Customize | 左下角 | 背景色、边界线、图例样式等整体外观 |
| Actions | 右下角 | 下载地图、保存工程等收尾动作 |

不同版本按钮位置可能略有差异，以应用内实际为准。

## 二、三步画出第一张图

1. **选底图**：点 Create Map，在 Select map 列表按分组翻，选定后双指缩放、拖动查看；
2. **涂色 + 图例**：调色板选色后点区域上色，小区域先放大再点避免误触；在图例编辑区给每种颜色写一句说明，组数控制在四五个以内；
3. **导出**：Preview Map 预览整体效果，确认后 Actions → Download map 导出图片，可直接发社交平台或贴进报告、博客。

## 三、让成图更耐看的几个细节

- 与主题无关的国家或州直接隐藏，画面会干净很多；
- 优先用内置配色方案，发给不特定读者时选色盲友好调色板；
- 一块区域同属两组时，用图案填充（点、条纹）叠在颜色上表达重叠归属；
- 图例不要留空——没有说明的填色图，读者看不出颜色代表什么。

## 四、保存与导出是两件事

存成工程（以后能接着改）和导出成图片（拿去用）走的是不同入口，都在 Actions 菜单里。做一半的图记得先存工程；换手机时可用 6 位迁移码接力，或导出备份文件整体搬家。

工具本身还没装的话，先看 [安卓版下载安装步骤.md](安卓版下载安装步骤.md)；更多实机画面与功能盘点，见 [MapChart 地图填色手册](https://mapchart.usea.quest/)。
