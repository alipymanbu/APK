# 挑底图的思路：七类地图各适合画什么

> 用 MapChart 画图，一半的成败在动笔前：底图挑对了，后面只是填色；挑错了，怎么涂都不对味。本篇把一百多种底图按七大类拆开，说清每类适合的场景，帮你对号入座。

## 一、七类底图对应七种用途

| 分组 | 里面有什么 | 适合画什么 |
| --- | --- | --- |
| 世界与大洲 | 世界地图与各大洲 | 数据分布、环球主题的概览图 |
| 单个国家 | 英、法、德、意、西等 20 多国 | 一国范围的专题统计 |
| 行政细分 | 美国州 / 县 / 国会选区、各国省级 | 精度要求高的数据图 |
| 历史地图 | 1815、1880、1914、1938、一战、二战 | 历史推演、年代格局复盘 |
| 游戏地图 | 钢铁雄心 IV、维多利亚 3、欧陆风云 IV | 游戏战局复盘、架空战史 |
| 奇幻地图 | 维斯特洛、泰姆瑞尔 | 同人设定、虚构世界疆域 |
| 区域专题 | 中东、加勒比等跨国家区域 | 地区局势、区域专题 |

## 二、三条挑选经验

1. **先定用途再翻分组**：数据展示选国家或行政细分，架空推演选历史或游戏，纯娱乐去奇幻分组；
2. **数据图优先细颗粒度**：能拆到州、省一级就不要用整国一张，信息量立得住；
3. **关注版本更新**：底图数据随版本迭代，近期就有亚洲地图重制、微型国家拆分、阿尔及利亚新省补入这类改动，画某张图前留意所用底图的更新状态。
