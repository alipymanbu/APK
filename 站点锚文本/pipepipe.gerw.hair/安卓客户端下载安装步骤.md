# PipePipe 安卓客户端下载安装步骤

> PipePipe 没有上架 Google Play，安装包要走网盘或发布页渠道。这篇按顺序讲清从拿包到装好能用的每一步，以及卡住时先查什么。
> **相关文章**：[和NewPipe哪个好](和NewPipe哪个好.md) · [赞助片段跳过与直播弹幕设置](赞助片段跳过与直播弹幕设置.md)

## 一、先拿安装包

常见的获取路径有三条：项目的 GitHub Releases 页、F-Droid 类应用商店，以及网盘分享。前两条适合能顺畅访问国际网络的环境；图省事的话，直接从 [PipePipe 安卓客户端介绍站](https://pipepipe.gerw.hair/) 进入下载页，按指引把网盘分享里的安装包转存到自己的账号，再用网盘 App 下载到手机即可，不用注册任何商店账号。

## 二、安装四步

1. **转存并下载**：打开网盘分享页，把安装包转存到自己账号后下载到手机存储。
2. **点开 APK**：在通知栏或文件管理器里点开刚下载的文件；系统弹「允许安装未知应用」时，按提示给对应应用（浏览器或文件管理器）打开开关。
3. **确认安装**：点「安装」等进度走完，期间别清后台。
4. **首次启动**：按默认设置走完引导页就能用，登录不是必需的。

## 三、卡住了先查这三处

- **点安装没反应 / 被阻止**：安装未知应用的授权没给到位，部分机型还要在纯净模式或安装守护里放行。
- **解析包出错**：安装包多半没下载完整，删掉重下；老设备也可能是处理器架构不匹配，换个架构的包再装。
- **覆盖安装失败、提示签名冲突**：先后两个包不是同一来源签发的，沿用原渠道更新最稳；真要换渠道，先在应用内导出数据备份，卸载重装后再导入。

## 四、装完建议做的两件事

- 在设置里过一遍播放器与下载目录，把下载位置指到空间够的分区；
- 想跳过视频里的推广口播、看直播弹幕的，把对应开关调校好再日常使用。

功能调校的具体做法在 [赞助片段跳过与直播弹幕设置](赞助片段跳过与直播弹幕设置.md) 里展开；还在犹豫装不装的，先看 [和NewPipe哪个好](和NewPipe哪个好.md) 再决定。
