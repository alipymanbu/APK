# PipePipe 和 NewPipe 哪个好

> 两个都是免广告的开源安卓视频客户端，名字像、界面像，却已经各自独立开发多年。这篇用一张对照表讲清差别，看完就知道装哪个（或者都装）。

## 一句话讲清关系

PipePipe 在 2022 年初从 NewPipe 分叉出来，之后两边不再互相同步改动：一边修好的问题不会自动出现在另一边。所以严格说它不是 NewPipe 的「新版」，而是同一棵树上长出的另一棵树。两者的包名不同，装在同一台手机里互不冲突，完全可以并存各试几天。

## 功能对照

| 对比项 | NewPipe | PipePipe |
| --- | --- | --- |
| 内容平台 | YouTube、SoundCloud、Bandcamp、PeerTube 等 | YouTube、BiliBili、NicoNico、SoundCloud、Bandcamp 等 |
| 跳过赞助片段 | 无 | 有（YouTube 与 B 站都可用） |
| 显示点踩数 | 无 | 有 |
| 直播弹幕聊天 | 无 | 有（B 站 / NicoNico 直播评论弹幕滚动） |
| 登录账号 | 不支持 | 支持（可看账号权限内的内容） |
| 播放列表内搜索与排序 | 无 | 有 |
| 音乐播放器模式 / 睡眠定时器 | 无 | 有 |

功能边界随版本变化，装之前可以再对照一遍两边的发布页。

## 怎么选

- **主要刷 B 站或 NicoNico**：选 PipePipe，本土化能力都是它分叉后主攻的方向。
- **只想看 YouTube，还听 SoundCloud、Bandcamp**：选 NewPipe 也够用；但想跳赞助片段、看点踩数的话，PipePipe 体验更全。
- **拿不定主意**：两个都装，不冲突。想先试 PipePipe 的，从 [PipePipe 安卓客户端介绍站](https://pipepipe.gerw.hair/) 的下载页按指引拿安装包即可，安装流程见 [安卓客户端下载安装步骤](安卓客户端下载安装步骤.md)。

装好之后把招牌功能调顺手的做法，见 [赞助片段跳过与直播弹幕设置](赞助片段跳过与直播弹幕设置.md)。
