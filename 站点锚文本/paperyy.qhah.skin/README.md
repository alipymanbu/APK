# PaperYY 说明站（paperyy.qhah.skin）

这里是 PaperYY 说明站的文档目录。PaperYY 是一款围绕论文查重的移动端工具：免费版每天可提交 1 篇初稿检测，一次检测能出多版本报告，再往下降重、提纲、班级组队各有一条线。站点从第三方视角按写作阶段把这些环节拆开整理，安装文件的获取入口也集中在站点里。

- 站点地址：[PaperYY 查重参考站](https://paperyy.qhah.skin/)
