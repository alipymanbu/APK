# 连不上和 PIN 输错的排查顺序

手机遥控端打不开局面，八成卡在两处：装好了一直停在「输入 PIN 码」的界面，或者 PIN 填进去提示无效。这类问题几乎没有玄学，按下面的顺序排查，通常两三分钟内能定位。

## 先确认三个硬前提

遥控端是「寄生」在电脑端上的，三个前提缺一个都连不上：

1. **同一个 WiFi**。手机挂着流量、或者连了路由器的访客网络（很多路由器把访客网络和主网络隔离开），配对都会失败。先看两台设备的网络名是不是同一个。
2. **电脑端开着并登录了账号**。遥控功能绑定在带 Pro 订阅的账号上，免费账号登录手机端也无法使用；电脑端一旦关闭，手机上立刻断开。
3. **Windows 防火墙放行**。电脑端第一次联网时 Windows 会弹「是否允许」，当初手滑点了取消的，去控制面板的「允许应用通过 Windows 防火墙」里补上勾选。

## PIN 相关的两种情况

- **提示 PIN 无效**：多半是取号和填号之间隔太久、或电脑端换过会话——回电脑端再点一次 Connect，用**新弹出的那串**填。PIN 每次连接现给，填旧的必然失败。
- **输错还想改**：直接在输入框里改就行，圆圈填满之前都能删掉重输；真卡死了就强制退出应用重开。

## 强退重连是万能起手式

上面都查过还连不上，就把两端都彻底关掉再来一次：电脑端从系统托盘或任务管理器退出，手机端按系统的办法强制停止，然后先开电脑端、再开手机端重新配对。这个动作能清掉绝大多数「状态卡住」的情况。
