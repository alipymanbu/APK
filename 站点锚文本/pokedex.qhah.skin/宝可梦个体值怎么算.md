# 宝可梦个体值怎么算

游戏里看不到个体值的数字，想知道手里这只宝可梦是不是好苗子，要么按游戏内的评价措辞估档次，要么用工具反推。这篇讲反推的思路和读结果的方法，配合口袋图鉴（PokeDex）里的个体值计算器使用。

## 先弄清六围是几层东西叠出来的

面板上的 HP、攻击、防御、特攻、特防、速度，是四层因素合成的结果：

- **种族值**：整个种族的固定底子，图鉴里能直接查；
- **个体值**：这一只的天赋，每项 0–31，出生时就随机定死；
- **努力值**：后天训练加的，初始为 0，单项最多 252、六项合计最多 510；
- **性格**：一对能力的 ±10% 修正，共 25 种；HP 不受性格影响。

个体值计算器做的事，就是从面板数值里把第二层逆推出来。

## 反推的操作与要点

1. 选定宝可梦——种族值它自己知道，不用填；
2. 输入等级、性格，以及当前面板的各项能力值；
3. 努力值一栏按实际填：刚孵出或刚抓的按 0 填，这是最准的测量状态；已经练过的必须按真实情况填，否则结果不可信；
4. 得到每项个体值的候选区间。

三个直接影响成败的点：

- **结果是区间不是单值**。公式取整会让相邻几个个体值算出同一个面板数字，这是正常的，不是工具坏了；
- **等级越高越准**。1 级的宝可梦经常测出来「0–31 都有可能」；把它升几级再录一次新数值，区间会明显收窄；
- **提示无解或测不出，是输入错了**。最常见的三种：性格选错、种族值按错形态（有地区形态或变身形态的要注意）、努力值没按实际填。

## 算出来之后怎么判

- 31 就是玩家常说的「V」，六项全满叫「6V」；能遗传满个体的胚子，通用性最好，留；
- 故意的 0 个体也有用：空间队要速度个体为 0（越慢越先出手），靠对手攻击力打人的宝可梦要攻击个体为 0（打得越轻越好）——这类「废苗」恰恰是好胚子；
- 测出来 26–30 的高数值，对要求不高的场合完全够用，追求极限再去孵。

另外提醒一句：用了王冠类道具「锻炼到最棒」的宝可梦，对战能力按满个体算，但孵蛋遗传时仍按原来的个体值——想遗传满个体，还得父母本身是满的。查种族值、配队这些前置步骤，见 [PokeDex 口袋图鉴介绍站](https://pokedex.qhah.skin/)；队伍层面的搭配思路在[宝可梦配队和伤害计算用什么工具](宝可梦配队和伤害计算用什么工具.md)里。
