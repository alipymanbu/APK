# Cemu 卡顿与闪退排查：图形设置调对，多数问题自己就能解决

> 本篇按现象整理 Cemu 安卓版的高频问题：卡顿掉帧、画面发暗、进游戏黑屏或闪退，每条给出先查什么、再做什么。

## 先用默认设置跑一次

装好应用、导完游戏，先拿一个轻量级游戏用默认设置完整跑一段。Wii U 模拟本身对手机性能有要求，默认设置已经是比较稳妥的起点——大多数游戏不需要额外调整。先有一个基准，后面再逐项改，出了问题你才知道是哪一项引起的。机型够不够格先看[安卓版手机配置要求.md](安卓版手机配置要求.md)。

## 两项推荐配置先打开

- **图形 API 选 Vulkan**：设置 → 图形（Graphics）→ 图形 API。多数设备上它更快、卡顿也更少；只有很旧的机型跑 Vulkan 不稳时，再退回 OpenGL 试。切换后重进游戏生效。
- **打开异步着色器编译**：第一次玩某个游戏时，画面偶尔会在特定场景定住一瞬——那是模拟器在现编译着色器，不是故障。把「异步着色器编译」（Async shader compile）打开，编译挪到后台进行，这种顿卡会明显减少。

## 卡顿掉帧的排查顺序

跑起来掉帧、间歇性卡住，按这个顺序逐条试，每改一项重进游戏确认：

1. **关掉图形包**：增强类图形包全部关掉，回到裸跑状态——很多卡顿是图形包叠加出来的。
2. **降分辨率**：图形设置里把分辨率倍率降回 1x，2x / 3x 只留给性能富余的机型。
3. **确认 Vulkan 和异步着色器都开着**：两项推荐配置缺一个都可能白丢性能。
4. **看温度**：连跑半小时后机身烫得厉害，卡顿多半是降频引起——摘掉手机壳、别边充边玩。
5. **换游戏验证**：拿另一个游戏跑一段，若只有单个游戏卡，去查该游戏的图形包或兼容性，而不是全局设置。
6. **进阶：换社区驱动**：骁龙 / Adreno 机型可以试社区开源驱动（Turnip），部分实测用它拿到了更高帧率。版本要和移植版对上，动手前先记下当前能正常玩的版本。

## 图形包（Graphic Packs）怎么用

图形包是社区做的增强 / 修改包，作用远不止改画面：有提高分辨率的、有解锁帧率的（比如《塞尔达传说：旷野之息》社区常见的 FPS++），也有针对单个游戏优化性能的。

使用步骤：

1. 设置里打开图形包（Graphic packs）窗口。
2. 点「下载最新社区图形包」，等列表拉下来。
3. 按游戏找到对应条目，勾选启用，按提示配置。

两个注意点：一次别开太多，开得越多性能负担越重、出问题越难定位；某些图形包是按游戏版本做的，游戏文件换了版本后原包可能不兼容，届时更新图形包即可。

## 画面发暗 / 对比度异常

个别版本里出现过整体画面偏暗、对比度不对的问题。社区的做法是先更新移植版到新版——历史上这类偏暗问题就是靠版本更新修复的；更新后仍偏暗的，检查该游戏启用的图形包，把增强类条目关掉再对比。

## 进游戏黑屏或闪退

1. **先排除文件问题**：换另一个游戏试——只有一个游戏崩，是该游戏文件或对应图形包的问题；个个都崩，才是设置或性能问题。
2. **关图形包**：进得了设置就把图形包全部关掉再试，个别图形包与游戏版本不兼容会直接崩。
3. **图形 API 换一下**：Vulkan 不稳的机型换 OpenGL 试（反之亦然），改完重进游戏。
4. **清后台重进**：长时间挂后台内存被占满，闪退概率明显升高，清掉后台重开。
5. **点游戏就报 Encrypted Title**：这不是性能问题，是加密镜像缺密钥文件，换 WUA 格式的游戏文件最省事，见[游戏文件格式与导入方法.md](游戏文件格式与导入方法.md)。
6. **还崩就重装**：卸载重装，重装后存储权限要重新给。

装好游戏列表是空的、导入扫不出来这类「还没进游戏」的问题，在[游戏文件格式与导入方法.md](游戏文件格式与导入方法.md)里按清单对；安装包的获取与安装步骤见 [Cemu 安卓版介绍站](https://cemu.djnf.quest/)。
