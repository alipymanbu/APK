## 先认识它

Cemu 是 PC 平台上最成熟的 Wii U 模拟器，2015 年首次发布、2022 年开源。它本没有安卓版本的开发计划，现在手机上能用的是社区移植版本：基于同一套开源代码的 ARM64 分支，以实验性名义公开测试，版本迭代很勤，兼容性几乎每个新版本都在往上走。

也正因为是社区移植、不走应用商店分发，你在商店里搜不到它，网上能查到的资料也散落在各种论坛和视频里。这个目录把中文玩家最常问的几件事整理成篇：

## 动手前的三个提醒

1. **先核对机型再看别的**：Wii U 模拟对手机性能有硬要求，机型不够，后面所有设置都救不回来。配置门槛与各档实测表现见[安卓版手机配置要求.md](安卓版手机配置要求.md)。
2. **游戏文件要单独准备**：模拟器本体不附带任何游戏，装完打开是空列表属于正常现象。文件从哪来、什么格式能省事，见[游戏文件格式与导入方法.md](游戏文件格式与导入方法.md)。
3. **默认设置已经是好起点**：图形 API 用 Vulkan、打开异步着色器编译，这两项调完先玩一段，别一上来就大改。出问题再按[画面卡顿与闪退排查.md](画面卡顿与闪退排查.md)逐条对。
