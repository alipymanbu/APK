# 智能电视怎么看直播频道

> 本篇面向刚买了智能电视或安卓盒子、想在上面看央视卫视直播的人：讲清装直播应用的完整路线、
> 装好之后怎么按分类选台，以及电视端和手机端操作上的差别。
> **相关文档**：[安卓盒子装电视直播应用步骤.md](安卓盒子装电视直播应用步骤.md) · [直播画面卡顿与黑屏换源排查.md](直播画面卡顿与黑屏换源排查.md)

## 一、电视端看直播的两条路线

智能电视和盒子出厂不带直播频道，想看直播通常走两条路：一是有线电视 / 运营商的机顶盒，二是在电视上装一个直播类应用。第二条路不用额外接线，装完就多出几十个可选频道，是现在不少人选的方式。

以 MeTV 这类直播应用为例，它的做法比较直接：装好后点开就是直播画面，不用注册登录，频道按央视、卫视、地方台、高清、体育、少儿分好类，选台和用遥控器换电视一个手感。功能的详细介绍与获取入口，见 [MeTV 直播应用介绍站](https://metv.uerg.quest/)。

## 二、装到电视上的主线流程

1. **在电脑或手机上取安装包**：电视自带的浏览器不好操作，安装包建议先在电脑或手机上下好。
2. **放行未知来源**：电视的「设置 → 安全」里允许安装商店之外的应用。
3. **U 盘送进电视**：安装包拷进 U 盘根目录（格式用 FAT32，很多电视不认 NTFS），插上电视，在文件管理器里点开安装。
4. **打开验证**：桌面出现图标，点开能直接进直播画面即装好。

每一步容易卡住的点（解析包错误、安装被拦、U 盘不识别），在 [安卓盒子装电视直播应用步骤.md](安卓盒子装电视直播应用步骤.md) 里按现象拆开讲了。

## 三、装好之后怎么选台

直播应用的频道列表动辄上百个台，一个个翻效率很低，正确姿势是先选分类再看台：

| 想看什么 | 去哪一档 |
| --- | --- |
| 新闻、综艺、纪录片 | 央视 |
| 热播剧、晚会 | 卫视 |
| 家乡新闻、本地节目 | 地方台 |
| 大屏看清晰画质 | 高清 |
| 赛事直播 | 体育 |
| 动画、少儿节目 | 少儿 |

手机端与电视端的操作差别只在换台：手机靠触摸唤出选台菜单，电视用遥控器方向键移光标、OK 键确认。换台之后等一两秒出画是正常现象，别连着按。

## 四、看的时候遇到问题

- **个别台黑屏或转圈**：先换一路信号源，多数直播应用给同一个频道备了多条线路；
- **所有台都不行**：用手机热点对照一下，区分是宽带的问题还是应用的问题；
- **高清台卡、标清台顺**：网络带宽吃紧，降一档清晰度或给电视插网线。

这几类问题的完整排查顺序整理在 [直播画面卡顿与黑屏换源排查.md](直播画面卡顿与黑屏换源排查.md)。
