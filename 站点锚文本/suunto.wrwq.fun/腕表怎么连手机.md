# Suunto 腕表怎么连手机

> 本篇讲 Suunto（颂拓）腕表与潜水电脑连接手机端 Suunto App 的完整流程：配对前的三项检查、标准蓝牙配对四步、Suunto 7 的 Wear OS 特例，以及老款 Ambit 走 SuuntoLink 的路径。配套的图文版在 [Suunto 腕表连手机：Suunto App 配对、路线与训练数据](https://suunto.wrwq.fun/) 一站里，可以对照着操作。

---

## 一、配对前先检查三件事

1. 腕表蓝牙开着、飞行模式关着——飞行模式开启时无法配对任何设备（腕表路径一般是 设置 → 连接 → 飞行模式）；
2. 腕表的「发现 / Discovery」开关打开，否则应用搜不到它；
3. 腕表没有进入省电休眠——部分表型闲置几分钟后会关蓝牙，按键唤醒再配。

另外，手机上如果还装着老 Movescount 应用，先卸载并重启手机再配：两个应用并存会引起连接与通知异常。

## 二、标准蓝牙配对四步

适用于 Suunto 3 / 5 / 9 系列、Vertical、Race、Spartan 系列、Traverse、Ambit3，以及 D5、EON Core、EON Steel、Ocean 等潜水设备：

1. 手机打开 Suunto App，注册或登录 Suunto 账号（账号只能在手机应用里注册）；
2. 点应用主界面**左上角的腕表图标**；
3. 点「配对 / PAIR」；
4. 腕表屏幕显示一组配对码，输入手机确认，配对完成。

配对成功后同步自动进行：手机与腕表蓝牙都开着、彼此在有效范围内时，打开应用就开始同步；点应用顶部的腕表图标可以看进度。每次同步还会顺带更新腕表的 GPS 优化数据，户外定位更快。

配对码没出现：安卓上配对请求可能以通知形式出现在状态栏，重新发起后下拉通知栏看；勿扰模式开着时腕表不出配对码，先关掉。

## 三、Suunto 7 要先走 Wear OS

Suunto 7 是 Wear OS 腕表，顺序和其他表相反：

1. 先用手机上的 **Wear OS by Google** 应用把腕表配对好；
2. 再打开 Suunto App，点左上角腕表图标，看到腕表后点「连接」；
3. 它的通知走 Wear OS 自己的机制，不在应用的「腕表上的通知」权限里设置。

## 四、老款 Ambit / Ambit2：走 SuuntoLink 数据线

Ambit（1、2）两代没有蓝牙通道，只能用电脑：

1. 在电脑上装 SuuntoLink；
2. 用随附 USB 线把腕表连到电脑；
3. SuuntoLink 识别设备后要求提供 Suunto App 的账号凭据（它里面不能注册新账号）；
4. 登录后数据自动同步进应用日记。Ambit3 与 Traverse 还能经 SuuntoLink 管理腕表设置、自定义运动模式与同步路线。

## 五、换表与多台设备

应用一次只保持一台设备连接。换新表：先在应用里取消旧设备配对，再按第二节流程连新表。手机蓝牙设置里的旧配对记录也删掉，能少踩很多坑。

装好应用是第一步，安卓安装包的获取与安装在这套站点的下载页里；路线规划与热图选线的用法见 [运动路线规划与热图选线.md](运动路线规划与热图选线.md)。
