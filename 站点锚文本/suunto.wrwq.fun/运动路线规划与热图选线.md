# Suunto 运动路线规划与热图选线

> 本篇讲 Suunto App 的地图与路线能力：运动热图怎么读、路线怎么建并同步进腕表、兴趣点 POI 的两种存法，以及 2D / 3D 与路面筛选这几个实用工具。腕表先连上手机才有意义，配对流程见 [腕表怎么连手机.md](腕表怎么连手机.md)；图文版在 [Suunto 腕表连手机：Suunto App 配对、路线与训练数据](https://suunto.wrwq.fun/) 一站的路线路板块。

## 一、地图页的工具箱

| 工具 | 用途 |
| --- | --- |
| 2D / 3D 切换 | 出发前用 3D 看地形起伏，比平面图直观 |
| 多种地图风格 | 换底图风格，提前熟悉目的地 |
| 运动热图 | 15 种运动类型的热门路线分布，看别人常在哪跑、哪骑 |
| 路面筛选 | 区分铺装、未铺装、崎岖路面，可单开也可全开（骑行选线用得多） |
| 我的轨迹 | 回看自己走过的线：本周、本月、今年、近 30 天或自定义时段，能叠在任何底图上 |

想看清更细的路况，用平板等大屏设备登录同一账号再规划；手机上则随手看、随手改。

## 二、建线、改线、存进腕表

流程三步：在应用里规划路线 → 确认无误 → 保存到腕表，出发后腕表按线导航。几个实用点：

- 在地图上选中一片区域，可以搜「热门路线」和热门起点；看中的线重命名、改运动类型后存进路线库；
- 长按沿途某一点可以加路点（waypoint）并改名；
- 给自建路线开启「转弯提示 / Turn-by-turn」后，腕表会在该拐弯时提醒你；
- 热图的价值在选线：可以沿用别人踩熟的成熟线，也可以刻意避开热门、另辟蹊径。

## 三、兴趣点（POI）

兴趣点是存下来用于导航的位置，两种建法：

1. 在应用里把位置添加为 POI，再同步到腕表；
2. 戴着腕表时把当前位置直接存为 POI（Suunto 9 系列支持在腕上操作）。

导航到 POI 时，腕表显示方向和距离，跟着走就行。

## 四、两个容易踩的点

1. **Suunto 3 没有内置 GPS**：靠「手机互连 GPS」拿定位——腕表连着应用、手机在身边，才能记录速度、距离和轨迹；不带手机时只能用腕部步频估算；
2. **旧版应用的地图功能可能不全**：3D 地图、路面筛选这类是后来加的，版本越旧缺得越多，日常使用建议保持应用更新。

选好的路线导出成 GPX 发给同伴的办法，见 [训练数据分析与数据导出.md](训练数据分析与数据导出.md)。
