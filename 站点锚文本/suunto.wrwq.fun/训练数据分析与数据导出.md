# Suunto 训练数据分析与数据导出

> 本篇讲腕表数据同步进 Suunto App 之后能看什么：锻炼日记与长期趋势、SuuntoPlus 小功能、第三方服务绑定，以及把记录导出成 GPX / FIT 文件带走的方法。应用的获取与安装在这套站点的下载页里，图文版总览在 [Suunto 腕表连手机：Suunto App 配对、路线与训练数据](https://suunto.wrwq.fun/)。

---

## 一、同步进来的是什么

腕表连上应用后，这些数据自动进入 Suunto App：

| 类别 | 内容 |
| --- | --- |
| 锻炼与潜水记录 | 每次的详情数据与轨迹，配活动图表；可补照片、视频和文字描述 |
| 日常活动 | 步数、卡路里、睡眠跟踪 |
| 长期趋势 | 训练负荷、活动与训练的长期曲线 |

点开日记里的任意一条记录能看完整详情：配速、心率、功率、海拔的逐段曲线都在里面；主页视图把日常关键活动放在最上层，活动水平与睡眠习惯从这里看。

## 二、SuuntoPlus 小功能

SuuntoPlus 是一组可选的小功能，常见的有：

- **Burner**：锻炼期间显示脂肪与碳水的燃烧速度；
- **Ghost Runner**：虚拟领跑者，用来练配速；
- **Variometer**：垂直速度跟踪，徒步与飞行场景用；
- **通勤标记**：把骑行、跑步、步行标为「通勤」，看相比机动车出行的 CO2e 排放差；
- **音乐控制**：运动中用腕表控制手机播放。

哪些能用取决于腕表型号与软件版本，以应用与腕表里实际出现的为准。

## 三、绑定第三方运动服务

伙伴服务网络有两百多个，常见的有 Strava、TrainingPeaks、komoot 等。绑定路径：应用「个人资料 / Profile」标签 → 「连接其他服务 / Connect to other services」→ 选服务按提示授权。绑定后活动自动同步到对应平台，不用手动导出。

## 四、导出 GPX / FIT 带走数据

三种导出，先选对格式：

| 导出 | 内容 | 适合 |
| --- | --- | --- |
| 锻炼 → GPX | 位置 + 时间（有心率时也带上） | 导进其他平台看轨迹 |
| 路线 → GPX | 只有位置线 | 给别的服务当导航线；也能把别人分享的 GPX 导入应用变自己的路线 |
| 锻炼 → FIT | 位置、时间、心率、功率、步频等全部 | 兼容面最广的推荐格式 |

操作：打开任意一条锻炼记录 → 右上角三个点 → 选格式 → 存手机或用兼容应用打开。注意：**没有 GPS 的记录导不了 GPX**，只能导 FIT。

路线规划与热图选线的完整玩法见 [运动路线规划与热图选线.md](运动路线规划与热图选线.md)；配对连表遇到问题先看 [腕表怎么连手机.md](腕表怎么连手机.md)。
