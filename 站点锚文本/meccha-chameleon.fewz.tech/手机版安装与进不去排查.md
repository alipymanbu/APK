## 一、安装速查

1. 从站点给出的网盘入口拿到安卓安装包（约 285MB，建议 Wi-Fi 下载）。
2. 在系统 设置 → 安全 / 隐私 → 安装未知应用 里，给下载所用的浏览器或文件管理器授权。
3. 点开 APK 等待安装完成；包不小，别中途退出。
4. 打开游戏需要联网，没有单机模式。

## 二、进不了对局：按症状排查

| 现象 | 优先处理 |
| --- | --- |
| 点按钮弹提示、卡在加载 | 切换一次 Wi-Fi 与移动数据；开网络加速工具后完全退出重进 |
| 对局里别人涂的颜色半天才显示 | 房主网络慢或同屏人数多，换一局通常就好 |
| 滑动不跟手、越玩越卡 | 关省电模式、调低画质、清后台，这不是网络问题 |
| 装到一半失败 | 下载中断会留下残缺文件，重新下载，别反复点坏文件 |
| 装完闪退 | 确认存储空间充足、系统版本达到安装提示要求 |

联机类游戏的服务器波动常有时间性，隔半小时再试恢复的情况不少见；反复失败时把「卡在哪一步、最后一句提示、用的什么网络」记下来再逐项换。

## 三、联机开房要点

- **开局两条路**：主界面点 Play 随机匹配；或走组队入口创建房间，自己选地图与模式。
- **创建房间**填四项：玩家名、房间名、密码（建议必填）、最大人数——不设密码的房间任何人都能进出。
- **朋友进场**：把房间码或密码发给对方，从加入界面输入即可；英文界面走 PLAY → Host / Join，含义相同。
- **语音**：对局内置通话，队友听不到你多半是麦克风权限被拒，去系统设置里把该游戏的麦克风权限改为允许。
- **人数**：房间上限通常 8 人，实际体验与房主网络关系很大，开黑前先有预期。

## 四、开黑前的最后一步

装好、进得去之后，先花两分钟过一遍躲藏与搜寻的思路再认真开打——胜负多半在开画前就定了。
