# meccha chameleon 躲藏伪装与搜寻技巧

> 躲藏方怎么画才不像人、搜寻方按什么顺序找人才快——可直接照做的判断标准。
> **相关文章**：[玩法规则与对局流程.md](玩法规则与对局流程.md) · [手机版安装与进不去排查.md](手机版安装与进不去排查.md)

这游戏的胜负多半在开画之前就定了：时间怎么分、点位怎么选，比画工本身更关键。把下面这套思路过一遍，第一局就能少走弯路；规则还不熟的先看 [玩法规则与对局流程.md](玩法规则与对局流程.md)。站点里还整理了对局实录画面，可对照着理解 [meccha chameleon](https://meccha-chameleon.fewz.tech/) 的伪装效果到底长什么样。

## 一、躲藏方：先选点，再动笔

最常见的失误是一进图就原地开涂，涂完才发现这个位置根本藏不住。180 秒的正确分配是「前十几秒跑图选点，剩下的时间画」。选点看三条：

- **背景够简单**：大面积纯色墙面、空白地砖、深色阴影角落，涂起来省事、破绽少。
- **有东西能挡住身体**：画框、柜子、雕塑能削弱人形轮廓，是天然队友。
- **避开高对比区**：纯白墙、亮黄色区域、过道正中、灯光正下方——任何一点色差都会被放大。

## 二、涂装四要领

1. **用取色工具拿颜色**，别凭眼睛估。同一种灰在亮处和阴影里差得很远，估出来的几乎一定对不上。
2. **先大笔刷铺满全身**，再换小笔刷修边缘；时间不够时铺底完成度优先于细节。
3. **有明暗的区域分层画**：亮处取一色、暗处取一色，按块铺上去。单一色调在光影墙前会显得异常平整。
4. **画完退远检查**：把镜头拉远看有没有比周围亮一档的色块、有没有露出的肢体边缘，发现问题马上改。

## 三、姿势：把人形轮廓拆掉

颜色只是伪装的一半，另一半是形状：

- 贴墙选侧身、贴地选匍匐、塞家具缝选蜷缩——原则是让外轮廓不再像一个站着的人。
- 身体边缘尽量压在墙缝、砖线、地板接缝上，让轮廓线「消失」在背景线条里。
- 手臂、腿别横向探进走廊或空地，这是最容易被一眼看穿的破绽。
- 定好姿势后保持静止：倒计时前的任何移动，都会把「背景的一部分」变回「会动的目标」。

## 四、搜寻方：按顺序排查

1. **先看形状**：人眼对人形极其敏感，画框里多出的一块、墙角多出的轮廓，多半就是玩家。
2. **再看明暗**：比周围亮或暗一档的色块、方向不对的阴影，值得走过去确认。
3. **扫高发点位**：油画内部、墙面缝隙、吊顶、桌椅底部、阴影角落，抬头低头都要看。
4. **靠近确认再出手**：误击不扣分，但浪费的是自己的搜查时间。

## 五、新手五个常见错误速查

| 错误 | 改法 |
| --- | --- |
| 先涂色再找位置 | 进图先跑十几秒选点 |
| 全身只用一个色调 | 亮处暗处各取一色分层铺 |
| 摆舒展的站姿 | 用靠墙、趴地、蜷缩收窄外形 |
| 忽略光源方向 | 顺着环境的明暗画，别逆光 |
| 最后几秒还在改 | 倒计时结束前就定好不动 |

装好进不了对局、房间里混进陌生人这类问题，见 [手机版安装与进不去排查.md](手机版安装与进不去排查.md)。
