# meccha chameleon 玩法规则与对局流程

> 一场对局分几段、躲藏方与搜寻方各自的目标、常见的模式差异，一篇讲清楚。
> **相关文章**：[躲藏伪装与搜寻技巧.md](躲藏伪装与搜寻技巧.md) · [手机版安装与进不去排查.md](手机版安装与进不去排查.md)

meccha chameleon 是一款多人涂色躲猫猫游戏：开局人人都是一个纯白小人，用画笔吸走环境颜色把自己涂成场景的一部分，倒计时结束后互相搜寻。对局节奏快，输了马上能开下一局。完整的对局实录与获取入口整理在 [meccha chameleon 介绍站](https://meccha-chameleon.fewz.tech/)。

## 一、一局的三段流程

1. **进图分阵营**：所有玩家进入同一张地图，按所选模式分成躲藏方与搜寻方。随机匹配由系统凑人，也可以自己开房约朋友。
2. **180 秒涂色时间**：躲藏方用取色工具从墙面、地板、家具上吸取颜色涂满全身，再摆一个姿势贴进场景。这段时间搜寻方还不能行动。
3. **倒计时结束开搜**：躲藏方定格不能再动，搜寻方开始在地图里逐个排查。躲藏方活到最后即胜；搜寻方要在时限内把人找完。

单局通常五到八分钟，节奏紧凑，出局的人下一局照常参战。

## 二、躲藏方与搜寻方的目标

| 阵营 | 胜利条件 | 核心能力 |
| --- | --- | --- |
| 躲藏方 | 倒计时结束仍未被找出 | 取色、涂装、摆姿势伪装 |
| 搜寻方 | 时限内找出全部躲藏者 | 观察：形状 → 明暗 → 点位 |

两边拼的不是手速而是脑子：躲藏方要「让自己不像人」，搜寻方要按顺序排查而不是乱扫一气。具体的画法与找法见 [躲藏伪装与搜寻技巧.md](躲藏伪装与搜寻技巧.md)。

## 三、模式与地图

不同版本里出现的模式名称略有出入，常见的有经典躲猫猫、感染模式（被找出的人就地转为搜寻方）与全员转搜寻几类；具体有哪几种，以创建房间时的模式列表为准。地图方面，洗衣房、画廊、砖墙陈列室这类老房间是主要舞台——墙面纹理越复杂，颜色越难对齐，选点时要跟着换思路。

## 四、基本操作对照

| 想做的事 | 操作 |
| --- | --- |
| 移动 | 屏幕一侧的虚拟摇杆 |
| 观察四周 | 滑动屏幕调整视角 |
| 吸取环境颜色 | 涂色面板里的取色工具 |
| 换笔刷与粗细 | 涂色面板切换，先大笔铺底再小笔修边 |
| 换姿势 | 姿势面板选站立、趴下、蜷缩等 |

第一次进主界面可以先点头像换个形象，再去匹配或开房。联机开房、房间密码与语音的说明，见 [手机版安装与进不去排查.md](手机版安装与进不去排查.md) 的联机一节。
