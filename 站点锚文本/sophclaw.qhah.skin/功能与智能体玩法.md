# Sophclaw 功能与智能体玩法

> 本篇回答两个问题：Sophclaw 能替你干哪些活、它和普通 AI 聊天应用的差别在哪。装机问题见 [安卓下载与安装流程.md](安卓下载与安装流程.md)；想把它挂进工作群，见 [接入飞书钉钉Telegram.md](接入飞书钉钉Telegram.md)。

## 一、定位：会动手，不止会答

Sophclaw 是 Sophnet 云算力平台推出的「龙虾」智能体，产品自述是 7×24 小时在线的数字员工。与普通聊天应用最大的差别在「执行力」：接到指令先拆解成步骤，再逐步执行，需要授权的关键动作会先停下来向你确认。推理全部发生在云端，手机端只负责下指令、看进度、收结果——中途关掉屏幕，任务照跑。

## 二、值得交给它的几类活

| 类型 | 典型用法 |
| --- | --- |
| 文案与文档 | 工作总结、会议纪要、商务邮件、润色改写；字数、口吻、受众一次说全，成品更接近能直接交差 |
| 定时与提醒 | 挂一个 Cron 定时任务，到点往指定会话发提醒（每天几点吃药、周几交周报） |
| 任务拆解执行 | 复杂的事拆成步骤按序跑，这是它与普通聊天机器人拉开差距的地方 |
| 学习与检索 | 知识点梳理、灵感构思、信息查询，把「查资料再整理」一次交出去 |
| 文件与图片 | 加装技能包后能生成 Word、读写多维表格、做图片编辑 |

## 三、指令怎么下才省事

- **一次说全**：「写一封请假邮件」能用，但格式口吻靠它猜；「写一封请假邮件，收件人是直属领导，事由家中有事请一天，正式语气，200 字内」一次到位。
- **可以追着改**：带长效记忆，同一轮对话里直接说「按刚才那份改」就行，不用重发背景。
- **语音也行**：不方便打字时口述需求，走同一条链路。
- **别一次塞太多**：多步骤任务耗时随步骤涨，着急的结果先单独发。

## 四、开局三步

1. 验证码登录（登录即注册）；
2. 首页点「即刻体验」，等实例创建完成——没创建完对话框是不响应的，别误会是卡死；
3. 进对话页发第一条指令，建议从小事开始，先熟悉它的输出风格再上复杂任务。

## 五、用之前心里有数

- **权限按需给**：弹权限申请时想一层「这条指令用得上吗」，事后可在系统设置里逐条改；
- **技能只从平台内装**：安全机构演示过恶意技能包伪装登录页的钓鱼路径，装技能认准应用内安装器列出的清单；
- **凭证不进对话框**：账号密码别让它代填，确需登录网页时让它打开页面、自己动手输。
