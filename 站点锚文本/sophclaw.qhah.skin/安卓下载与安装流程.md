# Sophclaw 安卓下载与安装流程

> 本篇讲怎么把 Sophclaw 装到安卓手机上：安装包从哪来、每一步点哪里、装完第一屏见什么。装好之后的玩法与计费规则，见同目录的 [功能与智能体玩法.md](功能与智能体玩法.md) 与 [计费方式与省钱要点.md](计费方式与省钱要点.md)。

## 一、装机前的三个前提

1. **系统版本**：安卓 5.2 及以上，近几年的主流机型都能满足；
2. **剩余空间**：安装包 118M 左右，加上安装与首次运行的占用，建议预留 500M；
3. **网络**：首次启动要联网初始化，Wi-Fi 环境下操作更稳。

## 二、四步装好

1. **取安装包**：Sophclaw 的安装包以网盘分享的形式提供，打开 [Sophclaw 介绍站的下载页](https://sophclaw.qhah.skin/download.html)，页首的按钮直接指向安装文件资源；进到网盘页后转存到自己账户或直接下载到手机都可以。
2. **允许安装**：在文件管理器里点开 `.apk`。系统弹「禁止安装来自此来源的应用」是安卓对未知来源的默认拦截，到 设置 → 安全/隐私 → 安装未知应用，给本次用的文件管理器授权后回来重装即可。
3. **验证码登录**：装完打开应用，手机号或邮箱收验证码填入——登录即注册，没有单独的注册流程。
4. **创建实例**：回到首页点「即刻体验」，等云端把专属实例拉起来（首屏会显示「正在连接服务」的进度弹窗，属正常流程），完成后就能在对话框派活了。

## 三、装完第一屏会看到什么

- **功能侧栏**：文件管理、使用教程、训练营、福利中心、邀请奖励与客服入口都在左侧抽屉里；
- **内置教程**：从快速入门到飞书、钉钉、Telegram 接入，教程一页页内置在应用里，不用去别处找；
- **订阅与认证页**：工作套餐与邀请认证在这一屏，填了邀请码双方都能拿体验金。

## 四、装不上时的排查顺序

| 现象 | 先查什么 |
| --- | --- |
| 解析包时出现问题 | 文件大小是否明显小于 118M（多半没下完整）；系统是否 ≥ 安卓 5.2 |
| 装到一半中断 | 剩余空间是否够；存储权限是否被拒 |
| 打开就闪退 | 清缓存 → 查权限 → 清数据重开 → 卸载重装，逐级来 |

再往深的问题（收不到验证码、任务转圈等）属于使用环节，同目录的 [功能与智能体玩法.md](功能与智能体玩法.md) 里有对应的处理思路；页面的完整图文版在 [Sophclaw 介绍站](https://sophclaw.qhah.skin/)，配了真机截图对照着点更直观。
