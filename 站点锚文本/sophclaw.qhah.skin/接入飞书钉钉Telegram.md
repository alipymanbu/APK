# Sophclaw 接入飞书钉钉Telegram

> 本篇讲怎么把 Sophclaw 变成工作群里的机器人：飞书、钉钉、Telegram 三条通道各自怎么接、定时提醒怎么挂、哪里最容易翻车。还没装上的先看 [安卓下载与安装流程.md](安卓下载与安装流程.md)。

## 一、为什么要接入聊天软件

手机 App 之外，Sophclaw 支持把机器人挂进既有工作会话：群里 @它 一句就能派活，回话直接落在会话里，不用在应用之间切来切去。对已经在用飞书或钉钉协作的团队来说，这是它最顺手的打开方式之一。

## 二、三条通道的接法概览

| 通道 | 前置动作 | 关键配置 |
| --- | --- | --- |
| 飞书 | 在飞书开放平台创建应用并开通云文档等权限 | 拿到 appId/appSecret 填进实例通道配置；群聊场景把连接模式设为 dual（即时消息走 WebSocket，定时任务走 HTTP） |
| 钉钉 | 在钉钉后台创建应用 | 按内置教程逐字段填入凭证 |
| Telegram | 找 BotFather 建一个 Bot | 拿 Bot Token 配到实例上 |

应用的内置教程对三条通道都给了逐字段的图文说明，跟着填即可，不需要自己写代码。

## 三、定时提醒：最常见的翻车点

智能体自带 Cron 功能，可以挂定时任务，比如「每天 23:10 提醒我吃药」并发送到飞书的指定会话。实测里最容易翻车的地方是**会话 ID**：

1. 会话 ID 在飞书客户端：点开目标会话 → 右上角「···」→ 设置页底部那串；
2. 下指令时把会话 ID 一并给到，任务才算真正挂上；
3. 创建完回智能体的定时任务列表确认一眼——列表里有它才是成功，没有就补上会话 ID 重新创建。

用药提醒、健身打卡这类事表达得越具体（时间、会话、内容），一次创建成功的概率越高。

## 四、接入后的权限与安全

- 机器人进群后能看到会话内的消息，**拉进哪个群、给什么权限**是个决策点，按最小需要来；
- 飞书侧的联系人读取等权限在开放平台逐项勾选，用不上的不开；
- 敏感操作（发消息、删文件、付款类）执行前会弹确认，别闭眼同意；
- 群里来了自称机器人的陌生账号，先核对是不是自己配置的那一只。

接好之后回到玩法层面，能派什么活见 [功能与智能体玩法.md](功能与智能体玩法.md)；往群里挂机器人省下的时间多了，额度消耗也会跟着涨，幅度可以对照 [计费方式与省钱要点.md](计费方式与省钱要点.md) 估一估。带真机截图的完整图文版在 [Sophclaw 介绍站](https://sophclaw.qhah.skin/)。
