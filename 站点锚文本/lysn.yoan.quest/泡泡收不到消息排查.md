# 泡泡收不到消息的排查顺序

> 订了泡泡却迟迟不响，先别急着怀疑手机坏了——两种「假故障」和三层「真问题」按顺序过一遍，多数几分钟就能定位。
> **相关文章**：[泡泡私信订阅与回复规则](bubble泡泡私信订阅与回复规则.md) · [安卓安装与首次使用](安卓安装与首次使用.md)

## 一、先确认是不是「真收不到」

两种情况根本不是故障，别白折腾：

- **没订阅**：bubble 是付费订阅制，没买某位艺人的利用券就收不到他的消息，订阅前也看不到历史消息。
- **艺人本来就不定期发**：服务条款写明不保证消息数量和频率，几天没动静属于正常，尤其艺人在巡演、军训或休息期。

排除这两种后，再往下面三层查。

## 二、应用内：通知设置逐项过

1. 打开应用右下角「更多」，进「设置」。
2. 找到「聊天通知设置」，检查三项：消息到达通知是否开启、通知栏显示内容、锁屏是否弹通知。
3. **单个聊天室被静音**：进入那个聊天室，点右上角菜单，检查铃铛图标状态——很多人只是单独关了一个房间的通知。

## 三、系统层：安卓杀后台是头号元凶

安卓机把应用的后台进程清掉，推送自然就断：

- **电池优化白名单**：设置 → 应用 → Lysn → 电池 → 选「无限制 / 不优化」。
- 装了省电类、清理类工具的，把 Lysn 加进它们的白名单。
- 部分机型会常驻一条「正在后台运行」的系统提示，那是系统自己的通知，关掉提示不影响推送。

改完后锁屏等几分钟观察推送是否恢复；没有测试条件就等艺人下次上线。

## 四、图片、语音打不开

| 现象 | 处理 |
| --- | --- |
| 图片 / 视频不显示 | 多为网络波动，切 Wi-Fi 与流量后重进聊天室；还不行就退出重登 |
| 语音没声音 | 查媒体音量与蓝牙连接，再重进聊天室播放 |
| 回复发不出 | 先重启应用；再对照回复额度确认是不是发满了 3/5 条 |
| 想保存内容 | 照片视频可存到手机，常用消息收进 OUR BOX 集中回看 |

## 五、还不行就找服务方

高峰期（新艺人开放日）全平台拥挤，加载与支付都可能延迟，等高峰过去再试；仍无解决就通过应用内「咨询」入口或邮件联系服务方，附上账号邮箱与问题描述。付款没生效导致收不到消息的情况，处理口径见应用内帮助与订阅渠道的客服。

排查归排查，工具得先在手——还没装好的先去 [安卓安装与首次使用](安卓安装与首次使用.md) 把应用装上；订阅规则、回复额度这些口径在 [泡泡私信订阅与回复规则](bubble泡泡私信订阅与回复规则.md) 里都有。
