# 修复幅度怎么调才自然

> 修出来不像本人，还是细节总是不够？本篇讲 codeformer 修复幅度滑块的取舍逻辑，以及不同素材该往哪端调。
> **相关文档**：[手机修模糊人脸照片的步骤.md](手机修模糊人脸照片的步骤.md) · [老照片修复与上色方法.md](老照片修复与上色方法.md)

用 codeformer 修照片，决定成片观感的就是那一个修复幅度滑块。很多「修出来不像本人」「修了跟没修一样」的问题，根源都在没理解这个滑块在控制什么。

## 一、滑块两端各是什么

- **往激进端拉（细节多）**：画面更干净、细节补得足，但五官可能与原来有出入——适合糊到认不出人的照片。
- **往保守端拉（保原样）**：五官纹理基本不动，清晰度提升有限——适合想保住本人特征的近照。

它对应的是上游开源模型里的「保真度」参数：那一端追求更好看，另一端追求更像本人。手机版把数值简化成了滑块，方向逻辑完全一致。

## 二、照素材类型选档

| 处理的内容 | 建议档位 | 理由 |
| --- | --- | --- |
| 带背景的整张照片 | 中间偏保守 | 背景占比大，动多了容易假 |
| 只有人脸的特写 | 中间 | 多数照片从这里开始试最省事 |
| 老照片修补 | 中间偏保守 | 颗粒感是岁月的一部分，磨太干净反而假 |
| 视频片段 | 最靠保守端 | 连续帧之间保脸优先，稳字当头 |

## 三、实操顺序

1. 先从中间档跑一次，看默认效果。
2. 修出来不像本人 → 往保守端拉一档，重跑。
3. 脸还是糊、噪点多 → 往激进端拉一档，重跑。
4. 两头都不满意 → 多半是原图质量太差，重拍或重新扫描再试；这类情况的排查思路在[手机修模糊人脸照片的步骤.md](手机修模糊人脸照片的步骤.md)第三节。

同一张照片多试两档再定稿，比反复纠结一档更省时间。

## 四、哪些「不自然」不是档位问题

- **脸上出现奇怪纹理**：原图压缩太狠或分辨率太低，先重拍重扫再修。
- **清晰照片被修出塑料感**：这类工具面向有退化的照片，本来清晰的图不需要过这一遍。
- **破损区补出不存在的东西**：补全属于推断，没法保证与真实一致，这是工具边界，不是操作失误。
