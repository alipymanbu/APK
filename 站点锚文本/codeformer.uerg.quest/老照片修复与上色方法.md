# 老照片修复与上色方法

> 本篇讲老照片翻新的两条线：破损划痕怎么补、黑白褪色照怎么上色，以及翻拍质量和结果预期这两件最容易翻车的事。
> **相关文档**：[手机修模糊人脸照片的步骤.md](手机修模糊人脸照片的步骤.md) · [修复幅度怎么调才自然.md](修复幅度怎么调才自然.md)

家里的纸质老照片大多同时带着三种伤：岁月磨出来的划痕折痕、褪色发黄的色彩、还有本身就糊掉的人脸。用 codeformer 这款手机修复工具，这几类问题对应不同入口，顺序对了效果会稳很多。

## 一、先按伤情分好类

- 人脸糊到五官分不清 → 走人脸修复入口，流程见[手机修模糊人脸照片的步骤.md](手机修模糊人脸照片的步骤.md)。
- 相纸有折痕、划痕、缺角 → 走修补类入口。
- 黑白照、褪色发黄 → 走上色入口。

一本相册往往要「先修补、再上色」跑两遍，别指望一个入口包治所有问题。

## 二、纸质照片先翻拍好，修复就成了一半

修复应用处理的是电子版，翻拍质量直接决定上限：

1. 靠窗的自然光下拍，别开闪光灯——相纸反光会盖掉细节。
2. 手机正对照片，别斜着拍，避免透视把脸拉变形。
3. 照片撑满取景框，四周留一点边，拍完裁掉多余背景。
4. 带玻璃相框的先把照片取出来，玻璃的反光和倒影会被当成画面内容修进去。

已经拍歪拍暗的电子版也能修，但重拍一遍往往比后期补救更快更省事。

## 三、上色与修补的操作要点

1. 导入翻拍好的照片，先修补破损，再跑上色。
2. 修补时幅度别拉太激进：老照片的颗粒感本身是岁月的一部分，磨得太干净反而假。
3. 上色结果不满意可以多跑一两次，算法每次推断的颜色会有差别，挑最顺眼的一版。
4. 成片保存后按日期在相册里找；个别鸿蒙机型图库不显示第三方应用保存的图，去文件管理的「图片」分类里翻。

## 四、对结果的合理预期

| 期望 | 实际情况 |
| --- | --- |
| 划痕折痕消失 | 大部分能修掉，跨越人脸的大面积破损可能留痕迹 |
| 黑白照变彩色 | 颜色是算法推断的，肤色通常接近常理，衣服背景未必与现实一致 |
| 认不出的人修到能认 | 信息量够时效果明显，损坏到只剩轮廓时补出的是「合理想象」 |
| 五官和本人一致 | 幅度往保守端调会更像，清晰度提升相应变小，取舍见[修复幅度怎么调才自然.md](修复幅度怎么调才自然.md) |
