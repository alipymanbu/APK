# 情侣位置共享要双方同意吗

> 「装个定位是不是等于被监控」是这类应用绕不开的疑问。本篇按 Lookus 的实际机制讲清：开启靠什么、看到什么、怎么关。
> **相关文档**：[异地恋怎么自动报备行程.md](异地恋怎么自动报备行程.md) · [收不到报备通知怎么排查.md](收不到报备通知怎么排查.md)

---

## 结论先说：开启必须两人各自同意

按应用商店页面的说明，Lookus 所有位置共享与状态同步功能，都需要**双方在知情前提下分别授权**才能启用。绑定情侣关系时，一方发起邀请（扫码或手机号），另一方在自己手机上确认，链条才算接通——不存在单方面装一个就能看对方位置的情况。

## 授权之后，对方能看到哪些东西

把边界列清楚，比笼统说「保护隐私」更有用：

| 信息 | 呈现方式 |
| --- | --- |
| 实时位置 | 地图头像，附带移动速度、App 内/外状态、电量 |
| 历史轨迹 | 按日期回看，含到达时间与停留时长 |
| 设备动态 | 充电、连网、通话结束、屏幕使用汇总 |
| 紧急呼叫 | 对方静音也会响提示音（走专门通道） |

范围就是这些：应用内聊天、通讯录、相册都不在共享之列。介意轨迹被长期留存的话，绑定前两个人先商量好看哪些、哪些不看。

## 反悔了怎么关

双向授权的另一面是双向可退出：任一方解除绑定或关闭位置共享，对面立刻看不到更新。所以这套机制更适合「商量好了再用」——它防的是偷偷监控，不是防分手。

## 一个更实际的用法建议

把自动报备当成「减少追问」的工具，而不是「随时查岗」的工具：标好常去地点，让到达离开自动通知；剩下的时刻互不打扰。关心有边界，应用才用得久。

各功能的具体界面与操作细节，整理在 [Lookus 功能介绍站](https://lookus.wxhp.skin/)，设置时遇到提醒不响、定位不更新的情况，直接按[收不到报备通知怎么排查](收不到报备通知怎么排查.md)处理。
