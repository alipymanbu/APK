# 韩漫、日漫、国漫，在同一个书架里找

> 想在某一个 app 里同时读到韩国条漫、日本漫画与国产漫画，先分清三种叫法，再用题材缩小范围。本篇讲这两步怎么走。

## 一、先分清三种叫法

找书之前，先把产地对应的叫法捋顺：韩国作品常被叫做 manhwa 或 webtoon，日本作品叫 manga，国产作品叫 manhua。你在搜索或者跟人讨论的时候，换着用这几个词，能翻出来的结果比只用「漫画」两个字多得多。

MangaToon 在应用商店里的介绍，就是把这三类放在一处讲的：既有韩国的 manhwa 与 webtoon 故事，也有日本漫画系列，再加上国产作品。对读者来说实际的好处是书架不分家——不用装三个应用、来回切换着追更。

## 二、题材清单过一遍

按商店介绍里列出的题材，少女漫方向有恋爱、校园、霸道总裁、都市、穿越；少年漫方向有热血、冒险、玄幻；另外幻想、动作、恐怖、BL 这几类也常年在架。

挑的时候可以先问自己两个问题：

| 你想要 | 大概率去 |
|---|---|
| 轻松的恋爱日常 | 恋爱、校园、霸道总裁 |
| 一口气读完的爽感 | 热血、动作、玄幻 |
| 睡前不敢多读的 | 恐怖 |
| 换个世界透口气 | 幻想、穿越、冒险 |

## 三、两步缩小范围

实际操作建议按「产地 → 题材」两步走：先想清楚今天想读韩国条漫还是国产玄幻，再进对应题材的分类页里翻封面。分类页的封面就是最快的筛选器，看到顺眼的点进详情页，先看更新时刻表和读者评分，再决定要不要开第一话。

把产地和题材都摆在一起的入口，可以到 [MangaToon 条漫馆](https://mangatoon.ggcd.uno/) 的介绍页里看一遍，那里按韩漫、日漫、国漫三个方向把题材讲开，配合找书入口的使用思路正好接上。

找书入口的具体玩法（排行榜、日签这些）在本系列另一篇里：[漫画排行榜找书荒自救.md](漫画排行榜找书荒自救.md)；找到书之后的读法，见 [上下滑动的条漫阅读体验.md](上下滑动的条漫阅读体验.md)。
