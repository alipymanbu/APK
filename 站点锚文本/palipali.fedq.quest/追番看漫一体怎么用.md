# palipali 追番看漫一体怎么用

> 本篇讲 palipali 从打开到开始追一部番的完整路径：首页有什么、怎么搜、播放页怎么操作、收藏和追更怎么用。
> **相关文档**：[安装不上怎么排查](安装不上怎么排查.md) · [缓存番剧离线看的方法](缓存番剧离线看的方法.md)

palipali（帕哩啪哩，启动页的 P² 标识很好认）把番剧和漫画放在同一个应用里处理，界面以粉色为主。装好后不用登录就能直接逛，下面按实际使用顺序过一遍。

## 一、首页能干什么

打开后默认是推荐流，按热门程度排当前的动漫作品，点封面就进详情页；往下翻会按热血、恋爱、搞笑这类题材分组陈列，想漫无目的找番就往这里翻。

除了推荐流，首页还有两个常用入口：

- **搜索框**：在页面顶部，明确知道要看什么时用它最快；
- **榜单入口**：顶部附近一个火苗样式的图标，点进去是热播榜，片荒时扫一眼就有方向。

## 二、搜一部想看的

点搜索框输入番剧名称，支持中文原名，部分版本也认别名或拼音缩写；记不清全名就输入最有辨识度的两三个字。结果列表里按封面和年份认准要的那部——同名翻拍不少，别点错。

搜不到先别认定应用坏了：全名搜不到换简称、别名再试；换了几个说法还是没有，那部作品可能就是不收录，属于内容覆盖的问题，不是操作错了。

## 三、播放页的操作

进入播放页后点一下屏幕中央呼出控制栏，常用操作都在这里：

| 想做的事 | 怎么做 |
| --- | --- |
| 快进快退 | 拖动底部进度条 |
| 换一集 | 控制栏里点「选集」，点集数即切换 |
| 调清晰度 | 画质选项里切「流畅」或「高清」，卡顿先降档 |
| 看评论 | 播放画面滚动显示其他观众的评论，部分版本能发弹幕 |
| 全屏 | 点全屏按钮或旋转手机自动切换 |

## 四、收藏与追更

追番主要靠三个机制配合：

- **收藏**：播放页或详情页点收藏按钮，之后从「我的收藏」（或追番列表）进入，不用再搜；
- **进度记忆**：看过的每一集自动记进度，下次打开从上次位置继续；
- **更新跟进**：连载中的番更新后，重新进详情页或收藏列表就能看到新一集。
