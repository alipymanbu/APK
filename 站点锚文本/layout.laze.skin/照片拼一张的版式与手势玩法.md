# 照片拼一张的版式与手势玩法

> 本篇讲把多张照片拼成一张图的实操：版式怎么挑、格子怎么调、连拍怎么用、成图存到哪。以拼图应用 Layout 的玩法为骨架，思路对其他拼图工具同样适用。
> **相关文档**：[商店下架的拼图应用怎么装回手机](商店下架的拼图应用怎么装回手机.md) · [独立拼图应用和快拍内置拼图怎么选](独立拼图应用和快拍内置拼图怎么选.md)

## 一、先定张数，再定版式

拼图的第一步不是挑照片，是**想清楚拼几张**——张数决定了可选的版式范围：

| 张数 | 适合的画面 |
| --- | --- |
| 2 张 | 前后对比、左右呼应（去程与返程、素颜与妆后） |
| 3 张 | 一张全景横片切三段，或一组连续动作 |
| 4 张（2×2） | 四宫格合集：一天四景、四季同框 |
| 6～9 张 | 大汇总：一周记录、同主题批量图、合影墙 |

Layout 的做法是选图时自动给出对应张数的版式，选的越多可选组合越少——这个「先选图、后出版式」的顺序本身就省了一次返工。

## 二、手势编辑：预览图上直接完成

好用的拼图工具不需要你在菜单里翻找。以 Layout 为例，所有调整都在预览图上手势完成：

- **点按**某张照片 → 左右镜像翻转；
- **长按拖动** → 和其他格子的照片换位置；
- **双指捏合或张开** → 缩放这张照片在格子里的取景范围；
- **拖动蓝色分隔条** → 重新分配相邻两格的面积，想让主角占大画面就往旁边拖。

这四套动作练熟之后，拼一张九宫格合集通常一分钟内搞定。这些界面的实际样子可以在 [Layout 拼图介绍站](https://layout.laze.skin/) 的界面一览里看到。

## 三、连拍模式：当场拍一组

拼图应用有个容易被忽略的场景：**照片还没拍**。Layout 的 Photo Booth 提供倒计时连拍，一次自动拍 4 张，拍完直接进版式——适合表情包式的连续表情、宠物的连贯动作。先拍后拼，素材和版式一步到位。

## 四、保存与后续

拼完点保存，成图直接进系统相册。之后的事情交给下一环：想加滤镜、文字、贴纸，用相册里的任意修图应用打开这张成图继续处理。拼图应用只负责「把几张排进一张」，分工清楚反而干净。
