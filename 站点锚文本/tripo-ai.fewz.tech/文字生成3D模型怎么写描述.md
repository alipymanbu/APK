# 文字生成3D模型怎么写描述

> 本篇讲文字变 3D 模型时描述怎么组织：写什么、避开什么、出错了怎么改。
> **相关文档**：[手机上把照片变成3D模型的方法](手机上把照片变成3D模型的方法.md) · [3D模型导出格式怎么选](3D模型导出格式怎么选.md)

文字生成 3D 的门槛不在软件，在描述。[Tripo AI](https://tripo-ai.fewz.tech/) 这类工具吃的是具体、有结构的短句，堆形容词不如堆名词。下面是实测总结的几条写法。

## 一、基本公式：名词 + 结构 + 量级

- **名词具体**：「一只穿盔甲的柴犬坐像」比「超酷的狗」可用得多；「黄铜蒸汽朋克风护目镜」比「护目镜」出细节；
- **结构说清**：坐姿、站姿、带底座、拿着什么——模型对「一个 X」的理解最稳定，一对或带场景要明确写；
- **量级给足**：单个物件、一对、还是一套，别让工具猜。

## 二、几个实用经验

1. **角色想后面做动画，姿势写 T-Pose 或 A-Pose**——这是角色建模的通用经验，自动绑骨功能吃这一套；
2. **中文可以直接用**，描述不清楚时换成英文短句往往更稳；
3. **一次生成一个主体**，场景类需求等单件都稳了再试；
4. **风格词放最后**：低多边形、像素风、手办感这类修饰，加在具体描述之后。

## 三、出错了怎么改

- **形状跑偏** → 把模糊词全部换成具体名词，重新生成；
- **细节糊** → 积分允许的话换更高质量的生成档位；
- **总是不像** → 放弃文字，找一张接近的照片走图片输入，路子见 [手机上把照片变成3D模型的方法](手机上把照片变成3D模型的方法.md)。

## 四、别忘了额度

生成是积分消耗的大头，档位越高扣得越多，免费额度按月发放。想清楚再点，比生成完再心疼有用；做出来的模型要进 Blender、Unity 或拿去打印的话，格式选择见 [3D模型导出格式怎么选](3D模型导出格式怎么选.md)。
