# 3D模型导出格式怎么选

> 本篇讲 AI 建模工具产出的模型怎么选导出格式：六种常见格式各进什么软件、导入时注意什么。
> **相关文档**：[文字生成3D模型怎么写描述](文字生成3D模型怎么写描述.md) · [手机上把照片变成3D模型的方法](手机上把照片变成3D模型的方法.md)

用 [Tripo AI](https://tripo-ai.fewz.tech/) 做出的模型，最终都要落地到别的软件里：进引擎、进建模器、或进切片器。格式选对，后面少走弯路。

## 一、六种格式对号入座

| 格式 | 适用场景 |
| --- | --- |
| GLB | Web、AR/VR、游戏引擎；纹理内嵌，单文件即可 |
| FBX | 游戏与 3D 动画行业标准，Maya、3ds Max、Unity 常用 |
| OBJ | 通用 3D 编辑与基础 3D 打印兼容 |
| STL | 3D 打印标准格式，只含几何体、不含贴图 |
| 3MF | 较新的 3D 打印格式，带切片信息 |
| USD | 影视特效、动画与协作工作流 |

拿不准就先选 GLB（带贴图、单文件），要打印则选 STL 或 3MF。

## 二、进 Blender

- GLB 直接拖进视口就能用，贴图随文件一起进来，不用重新指定路径；
- 导入后先看面数：AI 做出的原始模型面数极高（有实测一次约 190 万面），先减面再编辑，否则视口都转不动。

## 三、进 Unity / Unreal

- Unity 用 FBX 或 GLB 都行，Unreal 走 FBX 更省事；
- 别把原始结果直接丢进场景：先在生成平台里用重拓扑把面数降下来（滑块范围约 500~50000 面），降到一万面上下的量级再导出；
- 可行的流程参考：图生 3D → 重拓扑到 10000 面 → 导出 GLB/FBX → 进引擎。

## 四、拿去 3D 打印

1. 导出 STL 或 3MF；
2. 进切片软件（Cura、PrusaSlicer 等主流切片器都认）；
3. AI 做出的网格不保证封闭（水密），切片报「非流形 / 有孔洞」时先用修复工具处理；
4. STL 不含颜色，想彩色打印改导 3MF 或带贴图的格式，看打印机支持。

## 五、手机上导还是电脑上导

手机端适合随时生成、随手看；重导出、重编辑的活儿更适合在网页工作台做，能力更全。入口与工具介绍见 [Tripo AI 介绍站](https://tripo-ai.fewz.tech/)，描述写法见 [文字生成3D模型怎么写描述](文字生成3D模型怎么写描述.md)。
