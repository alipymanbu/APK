# Tripo AI 资源与使用说明

这里整理安卓版 Tripo AI 的介绍与上手资料：它是一款把文字描述或照片变成 3D 模型的手机应用，适合想做游戏素材、3D 打印或纯粹好奇 AI 建模的人。站点入口：[Tripo AI 介绍站](https://tripo-ai.fewz.tech/)。

- [手机上把照片变成3D模型的方法](手机上把照片变成3D模型的方法.md)：图片输入怎么选图、怎么提高出模成功率。
- [文字生成3D模型怎么写描述](文字生成3D模型怎么写描述.md)：提示词的组织方式与常见误区。

## 使用边界

生成、下载、导出等动作按积分计费，新账户每月有一定免费额度；免费档做出的模型默认公开且限非商业用途，商用需求需要在付费档下完成。具体规则随版本调整，以应用内实时显示为准。
