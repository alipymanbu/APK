# 哪些灯能用手机控制

> 装了 Nilight App 却扫不到灯，多半不是 App 的问题，而是灯本身不归它管。本篇讲怎么在买灯、装灯之前判断一套灯能不能用手机控。
> **相关文档**：[蓝牙连不上排查步骤.md](蓝牙连不上排查步骤.md) · [音乐与麦克风声控设置.md](音乐与麦克风声控设置.md)

## 一、先看灯是不是「控制款」

同一品牌下的产品线很宽，但只有带蓝牙控制盒的 RGB 彩光款才用手机控制。拿到一套灯，三条里中一条就基本能确定：

1. **看包装与说明书**：印着 App Control、Bluetooth、Music Mode 字样的，才是手机控制款。
2. **看供电结构**：几颗灯的线汇进一个小控制盒、盒子再接电源的，就是它管的范围。
3. **App 里直接查**：装好后翻一遍应用内的设备支持列表，手上这套在不在一目了然。

反过来，纯白光的大灯、灯条、工作灯走物理线控开关，跟手机控制无缘，装了应用也扫不到。

## 二、有手机控制款的产品线对照

| 产品线 | 典型用法 |
| --- | --- |
| 底盘灯（4 灯、6 灯、8 灯套件） | 轮眉、底盘的氛围与越野照明 |
| 鞭灯（3FT、4FT 螺旋天线款） | 越野旗杆灯，部分款带刹车、转向、倒车联动 |
| 内饰灯条（48 / 72 LED） | 车内脚底、出风口的氛围灯，USB 或点烟器供电 |
| 底盘霓虹灯条（256 LED，RGB / RGBIC） | 车底大面积光毯 |

这类套件多为 9–32V 宽压、灯体 IP68 防水（以各款商品页标注为准），皮卡、SUV、ATV / UTV 是主流用法。接线时控制盒先串一个摇臂开关再接电瓶，别直连常电，否则熄火后控制盒仍带电，长时间停放会把电瓶亏掉。

## 三、老款套件的坑：配的可能是别的应用

一个容易踩的坑：部分老款 RGB 底盘灯套件，随附说明书标注的控制应用是 HappyLighting 这类通用蓝牙灯控 App（系统要求 Android 4.3 以上），而不是 Nilight 这款应用。典型表现是灯能被通用 App 连上、Nilight App 里却怎么都扫不到。

判断方法很简单：以灯具随附说明书为准——说明书里的二维码或文字指到哪个应用就用哪个。老款套件没有定时开关、声控这些新特性属于正常现象，不是灯坏了；它们的模式与灵敏度调节多半在随附的遥控器上。

买二手或翻新套件时尤其要留这一眼：先确认应用，再谈功能。
