# VLIVE 老直播回放在哪里还能找到

> 平台关了，当年守过的直播回放去哪了？迁去 Weverse 的、没迁移的、某一场具体直播的回放——找旧 VLIVE 视频的几条路都在这。
> **相关文章**：[停服时间线与平台始末.md](停服时间线与平台始末.md) · [V币兑换与会员迁移窗口.md](V币兑换与会员迁移窗口.md)

## 一、先分清要找的内容属于哪类

| 你要找的 | 去哪找 |
| --- | --- |
| 已迁入 Weverse 的艺人的直播与视频 | Weverse |
| 未迁入 Weverse 的艺人的内容 | 平台渠道已无，可以试粉丝存档站 |
| 某一场具体直播的回放 | 先拿到视频编号，再去存档站按编号查（见第三节） |

关于「未迁入」的那部分：当年的公告只承诺对已入驻 Weverse 的艺人做内容迁移，据英文媒体报道的平台口径约有 60 位艺人完成迁移；12 月 31 日前未入驻的艺人，其内容库随平台关闭失效。这部分内容平台渠道确实没有了，能不能找回，取决于有没有人存档过。

## 二、第一路：Weverse

迁入艺人的旧直播与视频在 Weverse 里看。当年关注的艺人是否在迁移名单里，直接在 Weverse 搜艺人名最快；Weverse 现在自带直播功能（Weverse Live），实时聊天、翻译聊天、多机位这些都在，等于接过了 VLIVE 的班。

## 三、第二路：粉丝存档站，按视频编号查

社区有一个爱好者自发维护的存档项目 vlivearchive.com，保存了大量 VLIVE 时期的视频。用法不难，关键是拿到**视频编号**：

- 旧 VLIVE 的视频链接形如 `vlive.tv/video/138613`，末尾那串数字就是视频编号；
- 旧帖子、相册截图里翻出来的任何一条 VLIVE 链接，编号都能拿来在存档站检索。

找到编号后在站内查询，可能遇到几种状态（其公开文档所载）：

| 状态 | 意思 |
| --- | --- |
| Available | 立即可看、可下载 |
| Available to request | 视频在库但不在热存储，提交请求后取回 |
| Pending / Queued / In Progress | 请求已提交 / 已排队 / 取回中（带进度） |
| Failed | 取回出错，可重试 |
| Video not found | 只存了条目信息、没存到视频文件 |

两点预期管理：

- **冷存储与等待**：自 2024 年 11 月起，大部分视频放在冷存储，取回要等 1~5 分钟——15 分钟内的短视频通常 1 分钟内，1 小时左右的约 3~4 分钟；超过 2GB 的大视频可能超时，需按其文档走人工申请；
- **社区项目、不保证永远在**：可用性以站点当时状态为准；遇到「未收录」，手上恰好有当年的缓存视频，存档站也接受投稿补档。

## 四、都找不到时

Weverse 没有、存档站显示未收录——那这段内容大概率没有被任何人保存下来，基本无解，这不是检索方式的问题。
