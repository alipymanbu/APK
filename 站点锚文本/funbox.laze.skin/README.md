# FunBox 模块导航页

这里是 FunBox 聊天增强模块的第三方资料目录：它是跑在 LSPosed 框架里的模块，给微信、QQ、TIM 的聊天窗口加上表情面板和语音面板。目录下几篇文章分别讲装好之后怎么用、装之前要备齐什么、两块面板里有哪些玩法。完整的功能介绍与界面一览，见 [FunBox 模块介绍站](https://funbox.laze.skin/)。
