# FunBox 表情包与语音包玩法

> 面板呼出来之后能玩什么：表情怎么存怎么发、在线表情库什么路数、语音怎么录怎么导、Telegram 贴纸包怎么整包搬进来。
> **相关文档**：[模块用法与面板呼出.md](模块用法与面板呼出.md) · [安装前提与免Root疑问.md](安装前提与免Root疑问.md)

FunBox 的两块面板——表情面板和语音面板——是它区别于普通表情工具的地方：它们直接长在微信、QQ 的聊天窗口里，长按就能呼出。呼出方式与入口位置见 [模块用法与面板呼出.md](模块用法与面板呼出.md)；想先看功能全貌与设置页截图，逛 [FunBox 模块介绍站](https://funbox.laze.skin/)。

## 一、表情面板：存与发

- **存**：聊天里收到的好图可以直接保存进面板；在线表情库里也能直接下载收藏。
- **发**：点面板里的表情直接发送，发送方式自选「以图片发」或「以表情发」——以表情发体积小、动图能播，以图片发兼容性好，按对方端能不能正常显示来选。
- **管理**：最近发送的表情支持长按查看大图、删除；一个表情包里的表情可以复制到另一个包里重新归类；最近列表还能调最大保存数量，或让某些表情发送后不进最近列表。
- **在线库**：按沙雕、萌系、二次元等风格分类，联网获取；**已下载到本地的可以离线用**。

## 二、从 Telegram 搬贴纸包

想把 Telegram 上收藏的贴纸包整包搬进面板，社区常用的路子是借转换机器人：

1. 在 Telegram 里找到转换用的 Bot（多篇教程提到 `@QToolHelperBot`，是否仍在服务以实际可用性为准）；
2. 把想要的贴纸包发给 Bot，选「转换到 FunBox」，拿到返回的 ID；
3. 打开表情面板的导入入口，填入 ID 完成导入。

一次转一包，转完永久留在面板里。导入失败先看：Bot 是否还在服务、ID 是否复制完整、模块版本是否太旧。转不动的退回手动路线，逐张保存进面板，稳但费时。

## 三、语音面板：选、录、导、转

| 你想做的 | 做法 |
| --- | --- |
| 用现成的语音包 | 按分类选（DJ、恶搞、铃声等），先试听再发送 |
| 录一段自己的 | 面板里点录音，说完保存；保存路径和文件名自定 |
| 导入已有音频 | 语音包面板右上角的分享 / 导入入口，从手机存储选文件 |
| 文字转语音 | 输入文字生成个性化语音再发送 |

QQ 语音常见的 silk 格式音频支持转成 mp3，方便在别的设备回放。保存的语音文件会落到设置里指定的存储路径；遇到「转换的语音只进临时目录」「存储路径设不动」这类现象，先升级模块版本再试。

## 四、聊天辅助小开关

- **消息翻译**：内置翻译接口，目标语言以模块内实际提供的选项为准；
- **减少无效推荐**：长按不匹配的推荐表情选「不再推荐此类」，用一阵后同类内容明显减少；
- **发图行为**：微信里发支持尺寸的图片会按表情方式发送、可自动勾选原图、支持回复带图（QQ），不合习惯的都能在设置里关。

在线表情加载不出时先确认网络——在线资源要联网，只有已下载的能离线用；环境受限导致一直转圈，换个网络再试。模块环境与安装前提没备齐的，先回 [安装前提与免Root疑问.md](安装前提与免Root疑问.md) 把基础打好。
