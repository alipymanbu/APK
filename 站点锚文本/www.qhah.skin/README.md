# MoePal 说明站（www.qhah.skin）

这里是 MoePal 说明站的文档目录。MoePal 是一款安卓端的网盘链接解析与下载工具：把夸克、百度网盘、阿里云盘等平台的分享链接粘进同一个输入框，解析后勾选文件加入下载列表。站点从第三方视角整理了它的功能、界面与上手流程，安装文件的获取入口也集中在站点里。
