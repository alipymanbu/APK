# MoePal 解析失败常见问题

> 本篇按现象归类：解析没结果、下载中断、闪退卡顿、预览异常，各给一组「先查什么、再做什么」的排查动作。
> **相关文档**：[分享链接怎么解析下载.md](分享链接怎么解析下载.md) · [安卓版安装步骤.md](安卓版安装步骤.md)

## 一、点「开始解析」没结果

按出现概率从高到低逐条过：

1. **复制的内容不是链接本身**。从聊天软件整段复制的文字可能混入表情、空格或换行，先只复制 `https://` 开头那一小段再试；
2. **提取码漏了或错了**。设有提取码的分享必须填对提取码，跟分享者核对原始消息；
3. **链接已失效**。分享者取消分享、或平台屏蔽了内容，解析自然为空——把链接发给分享者确认状态，或让对方重新分享一份；
4. **平台不在支持范围**。长尾平台的兼容情况没有保证，换该平台自己的客户端处理这条链接；
5. **同一平台的链接整批失败**。第三方版本更新日志里提到过某些平台接口因风控做过调整——一家集中失效、别的平台都正常时，问题多半出在接口层，等应用更新后重试；
6. **应用版本过旧**。分享页格式更新后，旧版本可能识别不了新格式，更新到当前可用的版本再试。

## 二、解析成功但下载不动

| 现象 | 先查 | 再做 |
| --- | --- | --- |
| 进度一直 0 | 网络是否可用；剩余存储够不够 | 切到稳定的 Wi-Fi；清理存储后重新发起 |
| 下载到一半中断 | 是否切过网络、锁屏后被杀后台 | 给 MoePal 关闭电池优化 / 允许后台运行，再重新发起；已下部分一般可续传 |
| 速度明显变慢 | 是否处于网络高峰 | 换时段或换网络再试 |
| 任务列表堆积卡住 | 是否同时挂了过多任务 | 先暂停不急的任务，留一两个在跑 |

下载文件的保存位置可以在应用内设置里自定义，找不到已下文件时先到这里确认目录，再用系统文件管理器按文件名搜。

## 三、应用闪退或卡顿

1. 到系统设置的**存储权限**里确认 MoePal 拿到了读写权限——解析、下载、预览都依赖它；
2. 看剩余存储：安装包本身约 74.43M，加上下载缓存，低于 1G 剩余时容易出现各种异常，清理后再试；
3. 从后台划掉应用重新打开；仍闪退就重启手机；
4. 以上都无效时，卸载重装一遍（先记下账号密码，重装后要重新登录），安装包的取法见 [安卓版安装步骤.md](安卓版安装步骤.md)。

## 四、在线预览打不开

- 先确认文件类型：冷门格式没有对应预览能力，直接下载后用专门的 App 打开；预览支持哪些格式跟版本有关；
- 视频、大图预览对网络要求高，切到稳定 Wi-Fi 再试；
- 预览与登录状态相关，退出重新登录一次再试。

排查完仍然无解的情况，多半出在分享链接本身的状态或版本兼容上——回到 [分享链接怎么解析下载.md](分享链接怎么解析下载.md) 的坑位表对一遍现象，或者换一条新链接验证工具本身是否正常。日常使用中想对照界面操作，也可以打开 [MoePal 说明站](https://www.qhah.skin/) 边看边做。
