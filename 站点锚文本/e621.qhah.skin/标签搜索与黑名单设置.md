# 标签搜索与黑名单设置：把刷图范围调成自己的

> e621 的标签系统是它区别于一般图站的地方：搜什么、屏蔽什么，都由标签决定。这篇整理常用搜索写法与黑名单的配置思路。

## 标签先分五类

点开任何一张图，标签自动归成五组：artist（画师）、species（物种）、character（角色）、copyright（作品版权）、general（通用描述）。想找"某画师画的某角色"，把两个标签一起输进搜索框就行，不用翻相册。安卓客户端会保留这套分组并在详情页分类展示，点击任何一个标签都能直接跳搜索。

## 常用搜索写法

| 写法 | 作用 |
| --- | --- |
| `artist:画师名` | 只看某位画师 |
| `rating:safe` | 只看分级安全的内容 |
| `order:score` | 按评分从高到低 |
| `fav:用户名` | 看某账号收藏过的帖子 |
| `-标签名` | 从结果里排除某个标签 |

组合着用更有效：一行 `artist:某画师 rating:safe order:score` 就能筛出"某画师评分最高的安全分级内容"。客户端还带搜索历史、撤销与重做，连输错标签都能一步退回。

## 黑名单：不喜欢的直接不见

黑名单按标签生效——把不想看到的标签加进列表，对应帖子从浏览流里整体消失，连缩略图都不留。配合站点级分级切换（客户端可在 e621 与过滤更严的 e926 之间切换），看到什么完全由自己决定。配置入口在应用的 Blacklist 设置项，改动即时生效。

想长期追某位画师或某部连载，订阅标签比定期搜索省事：有新帖会直接推送通知。以上功能在手机上的实现方式与界面截图，统一收在 [e621 安卓客户端介绍站](https://e621.qhah.skin/)；途径选择与安装步骤分别见 [手机上浏览的几种途径](手机上浏览的几种途径.md) 和 [安卓客户端怎么装](安卓客户端怎么装.md)。
