# KWGT 小组件制作入门：桌面空白块到第一块卡片

> KWGT（Kustom Widget Maker）是安卓上的小组件制作工具：把时钟、天气、音乐、电池这些信息做成完全按自己想法排版的小部件。本篇讲它的工作方式、能做什么，以及从安装到桌面出现第一块卡片的完整路径。
> **相关文档**：[预设怎么导入与备份.md](预设怎么导入与备份.md) · [小组件不刷新怎么排查.md](小组件不刷新怎么排查.md)

## 一、它的工作方式

KWGT 不是打开来看的主题应用，装完之后桌面不会有任何变化。它的全部产出都走同一条流程：在桌面放一块空白小部件，点开这块空白区域进入编辑器，往里装内容，保存后空白块就变成做好的卡片。桌面上可以放多块 KWGT 小部件，各自装不同的内容，互不影响。

它也不替代桌面（启动器）、不改系统主题——系统自带的桌面基本都能配合使用，想要更细的尺寸控制（半格步进）可以搭配 Nova 一类第三方桌面。

## 二、能做出什么

| 卡片类型 | 桌面上的样子 |
| --- | --- |
| 时钟与日期 | 自己排版的时钟，字号、字体、时区、格式随定 |
| 天气卡片 | 温度、天气状况、未来几小时预报 |
| 音乐控制 | 曲名、封面，带上一首 / 暂停 / 下一首按钮 |
| 电池与系统 | 电量百分比、充电状态、内存存储占用 |
| 日历日程 | 下一个日程、当月日期、倒计时 |
| 快捷启动 | 一张图或一个按钮，点击打开指定应用 |

编辑器是一套图层式设计工具：文本、形状、图片、图标、进度条逐层往上摆，支持 SVG 与自定义字体；每个对象都能绑触摸动作。内容框里可以直接写公式（比如 `$df(hh:mm)$` 显示当前时间），电量、天气都有对应函数；主色、字号这类反复用的值定义成全局变量，换主题只改一处。

## 三、从安装到第一块卡片

1. 准备好安装包（安卓 5.2 及以上可装，获取入口见 [KWGT 介绍站](https://kwgt.wxhp.skin/)）；
2. 装好后桌面空白处长按，在"小组件 / 添加插件"列表里找到 KWGT，挑一个尺寸拖到桌面——第一次建议 4×4，空间大好操作；
3. 点这块空白区域打开编辑器，在预设列表里选一个内置成品，点右上角保存；
4. 回到桌面，空白块已经变成卡片；尺寸不合适就长按小部件用桌面的"调整大小"改。

免费版自带一套覆盖时钟、天气、电量、日历的基础包主题，编辑功能也全部开放，先把它用起来再考虑要不要进阶。
