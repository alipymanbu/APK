# KWGT 预设怎么导入与备份：.kwgt 文件的来龙去脉

> KWGT 的每个小组件内容都存成一个 .kwgt 预设文件——从别人那里拿成品、装预设包、换机迁移，全都围绕这个文件。本篇讲它存在哪、怎么进手机、怎么导出，以及最容易踩的"文件变 0 字节"坑。
> **相关文档**：[小组件制作工具入门.md](小组件制作工具入门.md) · [小组件不刷新怎么排查.md](小组件不刷新怎么排查.md)

## 一、预设文件放在哪

KWGT 在手机内部存储建一个 `Kustom` 文件夹，小组件预设都放在其中的 `widgets` 子目录。把 `.kwgt` 文件放进这个目录，编辑器预设列表里就能看到它；删掉文件，列表里就没了。同一家族的应用各管各的目录：KLWP 动态壁纸在 `Kustom/wallpapers`，KLCK 锁屏在 `Kustom/lockscreens`，别放混。

## 二、把预设装进手机的两种方式（二选一）

**方式一：文件管理器直接拷**——把 `.kwgt` 文件复制到 `Kustom/widgets`，打开编辑器在列表里选中、保存。

**方式二：编辑器内导入**——打开编辑器点"导入"，从 Kustom 文件夹之外的任意位置（比如 Download 目录）选中文件，导入后同样出现在列表里。

两种方式做的是同一件事。注意一个固定行为：文件已经拷进 `Kustom/widgets` 之后，再对它点一次"导入"，等于让程序把文件复制到它自己身上——原文件会被一个 0 字节空文件覆盖，列表里显示损坏（Corrupted）。这是社区里最经典的翻车原因，预防只有一条：**已在 widgets 目录里的文件别再点导入**。

## 三、后缀不对怎么办

| 拿到的文件 | 处理 |
| --- | --- |
| `xxx.kwgt` | 直接用 |
| `xxx.kwgt.zip` / `xxx.zip` | 先改名去掉 `.zip` 试试；仍被当损坏就解压取出里面的 `.kwgt` |
| 其他后缀 | 大概率不是预设文件，别硬导 |

## 四、导出与换机

编辑器里可以对当前预设执行导出，生成 `.kwgt` 文件。换机迁移的完整动作：

1. 导出预设，或直接把整个 `Kustom/widgets` 文件夹打包备份（更稳妥）；
2. 传到新手机，放回 `Kustom/widgets`；
3. 新手机桌面放一块 KWGT 空白块，选中对应预设、保存。

预设里用到的图片、字体如果放在 Kustom 文件夹之外的自定义路径，换机时要一并搬过去，否则卡片会缺素材。顺带一提："恢复预设"（Recover preset）是 Pro 解锁项，免费版的兜底手段就是文件备份——把整个 widgets 目录打包的习惯值得养成。

## 五、成品从哪找

应用商店搜 KWGT 能找到大量预设包应用（装好后预设直接进编辑器列表）；Reddit 的 r/kustom 版块、酷安等社区常年有单文件分享与教程。装好预设后套不上、显示损坏，先按上文核对文件本身。

还没装的话，安装包与完整介绍见 [KWGT 介绍站](https://kwgt.wxhp.skin/)；装好后小组件不刷新，去[小组件不刷新怎么排查.md](小组件不刷新怎么排查.md)。
