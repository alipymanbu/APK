# HyperCeiler 装完没效果的排查思路

> 模块装了、开关也拨了，界面却纹丝不动——别急着反复重装，这类问题九成出在框架接管链路上。按下面的顺序查，多数人在前三步就能找到原因。

## 一、五步顺序查，别跳步

| 顺序 | 检查什么 | 怎么确认 |
| --- | --- | --- |
| 1 | LSPosed 里模块开关开了没 | LSPosed → 模块 → HyperCeiler 开关为打开状态 |
| 2 | 作用域勾了没 | 模块详情页作用域列表非空，且勾的是被改的那项（状态栏锁屏类勾「系统界面」） |
| 3 | 重启了没 | 勾完作用域、开完功能后有没有按提示重启作用域或整机 |
| 4 | 应用内功能开了没 | HyperCeiler 应用里对应开关确实是打开状态 |
| 5 | 分支对得上系统吗 | 包名前缀与系统大版本的对应关系见[版本分支与系统对应关系](版本分支与系统对应关系.md) |

中招最多的是第 2、3 步。LSPosed 类模块的一切改动都要等重启才生效，这是框架的通用规则，不是模块本身的问题。

## 二、前四步都过了还是没反应

- **系统刚升级完才失效**：大版本升级后旧模块可能不再匹配，先停用，等对应分支的适配版再装回来；
- **系统本身不在支持范围**：深度修改过的第三方系统、部分国际版系统天生不生效，这不是设置能解决的；
- **个别功能没效果、其他正常**：多半是作用域漏勾——回到应用里看那个功能标注需要的作用域，补勾后重启再试。

## 三、还没解决的话

去项目在 GitHub 仓库的 Issues 区搜相同反馈，开源项目的已知问题通常有人报过；要自己提，先确认没有重复帖。确认链路本身没问题之后，再考虑从头走一遍[下载安装与启用全过程](下载安装与启用全过程.md)，或者干脆停用恢复原状。

功能都正常之后，从锁屏显秒、状态栏时钟这类小定制开始玩起最顺手，入口与玩法整理在 [HyperCeiler 介绍站](https://hyperceiler.hfdk.space/)里。
