# HyperCeiler 下载安装与启用全过程

> HyperCeiler 是挂在 LSPosed 框架下运行的 HyperOS 系统增强模块，装它比装普通应用多几道工序：装包只是开始，真正的开关在 LSPosed 里。这篇把从拿安装包到界面生效的完整顺序一次走完。

## 一、先对前提，再谈安装

模块靠框架接管系统界面，所以这三样缺一不可：

| 前提 | 怎么确认 |
| --- | --- |
| 小米 / 红米机型，系统为 MIUI 或 HyperOS | 深度修改过的第三方系统、部分国际版系统不在支持范围 |
| 已解锁 Bootloader 并取得 Root | 刷入 Magisk 或 KernelSU，能正常授予权限 |
| LSPosed 显示「已激活」 | 在 Root 方案里刷入 LSPosed 模块，重启后打开管理器确认 |

三样都齐了再往下走，顺序反过来只会白折腾。

## 二、拿到安装包

安装包从 [HyperCeiler 介绍站](https://hyperceiler.hfdk.space/)的下载页进入网盘分享页，转存到自己的网盘后即可下载到手机（或先下到电脑再用数据线传过去）。

拿包之前先确认版本分支跟自己的系统对得上——这是装完「没反应」的第一大原因，判断方法单独写在[版本分支与系统对应关系](版本分支与系统对应关系.md)里。

## 三、装包与启用

1. 在文件管理里点开 APK 完成安装，系统询问「是否允许安装未知应用」时允许；
2. 装完**先不打开**——此时模块还没被框架接管；
3. 打开 LSPosed → 模块页 → 找到 HyperCeiler，打开启用开关；
4. 进入模块详情页勾作用域：拿不准就先勾「系统界面」和「设置」，覆盖大部分入门功能，其余按需补勾；
5. 重启手机，再打开 HyperCeiler 应用开具体功能。

之后每改一批开关，都按应用底部提示重启对应作用域或整机，改动才真正落地。

## 四、装完之后

- 功能分布与搜索定位：打开应用直接搜「锁屏」「状态栏」这类词最快；
- 开了没变化：按[装完没效果的排查思路](装完没效果的排查思路.md)从作用域查起；
- 想干净地卸掉：先在 LSPosed 里停用并重启，确认界面回到默认后再卸应用。
