# 新手进群建群与机器人配置

> 这篇讲怎么找到圈子并加入、想当群主怎么从零建超级群，以及把机器人接进频道的完整流程。
> **相关文档**：[超级群游戏社区玩法全解.md](超级群游戏社区玩法全解.md) · [语音开黑与频道使用技巧.md](语音开黑与频道使用技巧.md)

---

## 一、加入一个已有的群

1. 打开 App，点底部「发现」的放大镜入口；
2. 搜游戏名或兴趣关键词，比如「怪物猎人」「跑团」；
3. 点进群主页，看群介绍与群规，点「立即加入」；开了入群验证的群，提交后等管理员放行；
4. 别人发你邀请链接时，点开直接跳到加入确认页；只有群号就把它填进发现页搜索框。

进群先看置顶的群规频道，大群普遍要求读完规则再发言。搜不到的群是私密群，只能走群号或邀请链接。如果想先看看各类群子里都玩什么，第三方整理的 [DoDo 玩法索引站](https://dodo.fewa.skin/) 上有按主题拆开的介绍，挑兴趣对口的再进。

## 二、自己建一个超级群

1. 在消息列表或发现页找「创建群聊 / 创建超级群」入口；
2. 填群名与简介，选公开或私密：公开群进搜索与推荐，私密群只靠群号、链接进人；
3. 建好后按需加频道——文字、帖子、语音、资料库类型都有，管理入口在群设置；
4. 把群号或邀请链接发出去拉人；
5. 长期运转记得配角色权限，把删帖、踢人、管频道分给管理员。

| 想做的事 | 在哪操作 |
| --- | --- |
| 让群被搜到 | 群设置 → 隐私 |
| 加频道、改图标 | 群设置 → 频道管理 |
| 分权给管理员 | 群设置 → 角色与权限 |
| 挂公告、改主页 | 群主页编辑（部分能力需在电脑端完成） |

## 三、把机器人接进群

群自带的自动欢迎、禁言、置顶在群设置里就有，先确认这些够不够用；真正的机器人程序（骰子、签到、图鉴查询）走开放平台接入：

1. 注册开放平台的个人开发者身份；
2. 「创建应用」拿到应用卡片；
3. 在「凭证和基础信息」里取 `Client ID` 与 `Bot Token`——等同于机器人账号密码，不要贴进公开群；
4. **勾选要监听的事件**——不勾，机器人收不到消息，这是最常见的坑；
5. 到「机器人管理」勾权限、生成邀请链接；
6. 浏览器打开链接，选目标群确认加入；
7. 到需要它的子频道里启用，没反应就再点一次。

权限口诀：给多了有风险、给少了会报错。机器人发不出消息多半是权限不足，重新生成一条权限更全的邀请链接即可，不是一次定死。

## 四、常见坑

- **机器人不回话**：按顺序查——事件开关没勾？权限给少了？频道里没启用？
- **搜不到自己的群**：检查群设置里是不是选了私密；
- **手机端编辑不了一些高级配置**：资料库频道、群主页导航这类，先在手机上规划，电脑端完成编辑。
