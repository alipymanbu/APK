# 手机 SSH 连接 Linux 服务器的步骤，从零到第一条连接

第一次用手机连 Linux 服务器，卡住的地方通常不是 SSH 本身，而是几个前置条件：端口、认证方式、以及第一次连接时的指纹确认。这篇文章把完整步骤拆开写一遍，用 ServerBox 演示——它是一款开源的跨平台服务器管理工具，手机端的连接流程比较有代表性。

---

## 准备：确认服务器端的三件事

动手前先核对：

1. **SSH 服务在跑**：绝大多数 Linux 发行版默认开启 `sshd`，不确定就在服务器控制台跑 `systemctl status sshd` 看一眼；
2. **端口放行**：云主机要在厂商控制台的安全组里放行 SSH 端口（默认 22，改过就放行改后的那个）；本机或内网机器检查防火墙规则；
3. **账号可用**：用户名加密码，或者提前做好密钥认证（把公钥写进服务器的 `authorized_keys`）。

## 第一步：安装 App 并选语言

安装 ServerBox 后首次打开会让你选界面语言，列表里有简体中文；选完进入主页，此时还是一张空列表。

## 第二步：添加主机

点右下角的「+」，逐项填写：

- **名称**：随便起，方便自己认机器，比如「家里 NAS」；
- **主机**：IP 地址或域名；
- **端口**：默认 22，改过就填实际值；
- **用户名与密码**：或者切换成密钥认证，选择本地密钥文件。

App 会自动发现手机上已有的 SSH 密钥，也能从 `~/.ssh/config` 导入主机配置，旧终端用户迁移过来不用重填一遍。

## 第三步：确认 host key

第一次连接会弹出服务器指纹，核对无误后确认。这个指纹之后每次连接都会复验，一旦对不上（比如服务器重装过系统），App 会明确提示而不是静默继续——这正是 SSH 协议设计里防中间人的那道检查。

## 第四步：看状态面板

连上后进入机器详情：CPU、内存、磁盘、网络的实时图表直接铺开，顶部还能进 SSH 终端、文件管理、Docker 等分区。到这里，「手机连服务器」的闭环就走通了。

## 连不上时的排查顺序

- 安全组 / 防火墙没放行端口（云主机最常见）；
- 端口号填错（改过默认端口的机器特别容易忘）；
- 密码输错或密钥没选对；
- 服务器端 `sshd` 挂了或被改了配置。

按这个顺序查，基本能覆盖绝大多数情况。更多工具背景可以看 [手机管理 Linux 服务器的开源工具](手机管理Linux服务器的开源工具.md)；连上之后想管容器，接着读 [手机端 Docker 容器管理实操](手机端Docker容器管理实操.md)。工具的功能全景与安装资源见 [ServerBox 介绍站](https://serverbox.kook.yoga/)。
