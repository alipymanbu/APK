# 手机端 Docker 容器管理实操：看状态、翻日志、重启容器

容器化之后，服务器上的服务多了，日常操作反而变得碎片化：看看哪个容器在跑、翻两行日志、重启一个抽风的服务。这些活儿每次只需要十几秒，专门开电脑却要几分钟。这篇写怎么用手机把这些碎片操作做掉，演示工具是开源的 ServerBox——它的容器管理走 SSH 直连，手机 App 上就能完成。

---

## 前提：容器管理为什么不用装东西

ServerBox 的 Docker 管理没有自己的 agent，它连上服务器后调用 Docker/Podman 的标准接口读数据。这意味着：只要手机能 SSH 到机器、机器上装着 Docker 或 Podman，容器列表就能直接刷出来，服务器端零改动。

进入某台机器的详情页，点「容器」分区即可。

## 看状态：谁在跑、占了多少

容器列表里能看到每个容器的运行状态，配合实时资源占用数据，一眼分辨「活着但很闲」和「活着但快炸了」的容器。镜像与卷的清单也在同一分区里，清理磁盘前先来翻一遍很方便。

## 翻日志：不敲 `docker logs`

点开某个容器直接跟它的输出日志，支持按严重程度过滤、实时滚动。半夜服务异常时，这个动作的完整终端版是「解锁电脑 → 开终端 → SSH → 敲命令 → 翻屏」，手机版把它压成了三秒内的两次点击。

## 重启与启停：把命令变成按钮

启动、停止、重启都是列表里的按钮操作。配合 ServerBox 的代码片段（Snippet）功能，连「重启之后顺便看一眼日志」这种组合动作也能做成一条自定义流程——片段支持参数占位，跨机器复用。

## Compose 项目自动归组

用 Docker Compose 编排的服务会被自动识别成项目分组，服务之间的依赖关系、环境变量与扩缩操作都在项目维度呈现，不用在十几个容器里翻找谁属于哪个应用。

## 小结

手机端管容器的边界很清楚：适合「看、翻、重启」这类轻操作；镜像构建、大规模编排调整这类重活，还是留给工作台。两者不冲突——重活一年没几次，轻操作每天都要做。
