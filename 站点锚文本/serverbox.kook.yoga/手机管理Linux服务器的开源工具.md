# 手机管理 Linux 服务器的开源工具，有哪些值得留意

想用手机管服务器，早些年能选的路子不多：装个终端类 App 敲命令，或者在浏览器里开网页面板。现在这条路上多了一个开源选项——ServerBox，一款基于 Flutter 开发的跨平台应用，把状态监控、SSH 终端、文件管理和容器操作收进同一个界面。这篇文章从选型角度把这几种路线捋一遍，帮对工具挑花眼的人省点时间。

本文是介绍性质的文章；想看它的功能演示与安装步骤，可以到 [ServerBox 介绍站](https://serverbox.kook.yoga/) 继续阅读。

---

## 路线一：纯终端 SSH 客户端

各种 SSH 客户端解决的是「连上去」这件事：保存主机与密钥、多会话切换、终端模拟。它们的强项是命令行体验，弱项是所有信息都要靠敲命令换取——想看一眼 CPU 占用，得连上去跑 `top`；想知道磁盘还剩多少，得 `df -h`。

适合人群是重度命令行用户：反正一天到晚都泡在 shell 里，多一步图形界面反而累赘。

## 路线二：网页监控面板

在服务器上装一个面板程序，浏览器里看图表。优点是可视化做得足，缺点也明显：服务器端要常驻一个服务，占用资源且多一个暴露在外的入口；手机浏览器里的操作体验也谈不上好，图表缩放、按钮点击都别扭。

适合有大屏看板需求、机器数量多的场景。

## 路线三：原生 App 直连 SSH

第三条路线就是 ServerBox 走的路：手机上装一个原生应用，直接跟服务器的 SSH 服务对话。

- **服务器端零依赖**：监控图表、文件管理、容器操作全部通过标准 SSH 完成，机器上不用装任何常驻组件；
- **监控不打扰**：CPU、内存、磁盘、网络、传感器温度实时成图，还有 GPU 与 S.M.A.R.T. 磁盘健康数据；
- **操作有界面但不丢终端**：SFTP 文件浏览与在线编辑、Docker/Podman 容器启停、systemd 服务管理都是点选完成，完整 SSH 终端依然内置，想敲命令时随时可切；
- **开源可查**：项目以 AGPL-3.0 协议开源，GitHub 上有 8k+ Stars，Android、iOS、Windows、macOS、Linux 五端都能用。

它的定位更像是「把终端里常做的那些事翻译成点按操作」：找出吃 CPU 的进程、重启一个容器、改一行配置文件——这些动作在终端里各是一条命令，在这里各是一次点击。

## 怎么选

给个简单的判断方法：

1. 命令行为主、图形只是辅助 → 终端客户端足够；
2. 机器多、要看大盘 → 网页面板；
3. 机器不多、以「随手看一眼、随手处理一下」为主 → 原生 App 直连 SSH 的路线最省事，ServerBox 是这条路线里值得试的开源选择。
