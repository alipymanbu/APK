# icity 心情日记本站点目录

icity 是一款手机日记记录应用，围绕记录做了三条线：心情转盘记当天情绪、目标打卡追每日计划、日记本收下想多写几句的时刻。这里整理围绕它常见的使用问题与玩法说明，安装文件资源的获取入口见 [icity 心情日记本](https://icity.wrwq.fun/)。

## 本目录的文章

- [日记本app心情转盘怎么用](心情转盘日记本怎么用.md)——不想写长文的日子里，成本最低的记录方式
- [目标打卡养成坚持习惯](目标打卡养成坚持习惯.md)——把计划拆成每天一次点击的打卡玩法
- [换手机日记怎么迁移](换手机日记怎么迁移.md)——账号、导出与换机前该做的几件事
