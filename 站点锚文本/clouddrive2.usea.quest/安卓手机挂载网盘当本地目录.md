# CloudDrive2 安卓手机挂载网盘当本地目录

> 想让网盘出现在手机文件管理器里、像操作本地文件夹一样翻云端的文件，是很多人装多云盘工具的第一个动机。本篇讲挂载这件事在安卓手机上需要什么条件、挂载点怎么建、没有 Root 时走哪几条效果接近的替代路径。

## 一、先说清一个前提：手机挂载需要 Root

安卓系统没有向普通应用开放本地文件系统的挂载能力。CloudDrive2 在未获取 Root 的手机上会直接提示「未获得Root权限，不能本地挂载」——这不是故障，是系统限制；多云盘管理、跨盘传输、相册备份、WebDAV 这些其余功能都不受影响。

手机已经 Root 的话，跳到第二节照步骤建挂载点；没 Root 的直接看第三节，两条替代路径能覆盖大多数需求。

## 二、有 Root 的挂载步骤

1. 打开应用时允许 Root 权限；
2. 管理界面进「挂载点」页，点「添加挂载点」；
3. 填四项：
   - **挂载名称**：随意，显示用；
   - **源目录**：要挂出去的目录，可以是某家网盘的根目录或下面任意一层，填 `/` 则把所有已连接的云盘一起挂出去；
   - **挂载点**：一个空目录；
   - **选项**：勾「只读」防误删误改，勾「启动时自动挂载」让它跟着服务一起起来；
4. 挂好后用文件管理器进那个目录，网盘文件就在里面，其他应用也能直接打开其中的文件。

两件容易忽略的事：在挂载目录里删除文件删的是网盘上的真实文件，没有回收站可捞；在网盘自己的应用或网页上做的改动，挂载目录要刷新一次才反映出来。

## 三、没有 Root 的替代路径

- **WebDAV 连接**：CloudDrive2 自带 WebDAV 服务，手机、平板上的播放器和文件管理器都能通过协议连上来读写，效果与挂载接近。服务器地址、账号、密码三项在应用「WebDAV」页能直接看到；
- **SAF 直读**：安卓的存储访问框架（SAF）是另一条不需要 Root 的路——在支持 SAF 的文件管理器里把 CloudDrive2 当作文档提供方选中，即可直接读写其中的文件，应用设置里有专门的开关。

## 四、挂载点的额度

基础账户能建 1 个本地挂载点，会员不限数量；挂载点数量与云盘连接数量分开计算，互不影响。各档权益以产品方定价页为准。

## 五、从哪里开始

整套流程的起点是把 CloudDrive2 装到手机上并接入网盘账户。安装来源、四步安装过程与首次配置，整理在 [CloudDrive2 手记](https://clouddrive2.usea.quest/) 的下载与安装页里，照着做即可；装好后添加云盘的步骤、授权掉线的处理，与本篇互为补充。
