# 多家网盘之间互拷文件不落地的做法

> 从百度网盘搬几个 G 的资料到另一家网盘，老办法是先下载到电脑再上传，费时还占盘。本篇讲用 CloudDrive2 做跨网盘复制的操作路径、「秒传」与「慢传」的差别在哪，以及不花钱的账户能用到哪一步。

## 一、操作路径

1. 管理界面进「我的文件」，勾中要复制的文件或文件夹——这里的文件视图是跨云盘的，两家的目录并排可见；
2. 点「移动 / 复制到...」；
3. 在目录树里选好目标网盘里的位置，点「复制」；
4. 任务在后台运行，不必守着界面，进度到「任务」页的「复制任务」标签下查看。

上传、下载、移动、重命名、删除、新建文件夹，同样是跨云盘操作，不只在单个盘内生效。

## 二、快与慢的差别在哪

复制开始时先从源网盘取文件哈希：

- 目标网盘用同一套哈希算法并且命中了 → 服务端直接建一条指向已有数据的记录，数据根本不搬，这就是「秒传」，几乎瞬时完成；
- 算法不同或没命中 → 在两个网盘之间边下边传，不经过本地磁盘，速度受两端带宽限制。

慢的那一种不是出了故障，只是目标网盘没有可命中的现成数据。

## 三、不花钱的账户能用到哪一步

- 云盘 A 直接复制到云盘 B 的快速复制是会员功能；
- 不付费也有一条能跑通的路径：只要复制的一端是「本地文件夹」（云盘 → 本地、本地 → 云盘）就正常可用——把网盘资料拉到电脑，或把本地文件推上云盘都不受限，把「本地文件夹」当一端添加进来即可，这一端不占云盘连接名额；
- 基础账户同时可连 2 个云盘，想换第三家时先在「云存储」页移除一个再加。各档权益以产品方定价页为准。

## 四、动手前的两个提醒

- 复制是往目标位置写文件，批量搬之前先小批量试一次，确认目标目录选对了；
- 复制不等于备份：源端删了、目标还在的持续同步要用「备份」页的任务来做，两者别混用。
