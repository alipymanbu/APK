# LeviLauncher 是什么

> LeviLauncher 是面向《Minecraft》基岩版（国际服）玩家的安卓第三方启动器：把导入的基岩版安装包按版本分目录管理，免安装代运行，并支持 Xbox 多账号切换、存档备份与 .mcpack 模组导入。这里收录两篇围绕真实使用问题写的短文。

- [同一部手机并存多个基岩版的方法.md](同一部手机并存多个基岩版的方法.md) —— 从「更新后老模组失效」这个常见场景说起，讲清楚多实例并行的思路。
- [模组光影导入后不生效怎么办.md](模组光影导入后不生效怎么办.md) —— 按现象给排查顺序：从启用状态查到版本兼容。

想先整体了解这款启动器的界面、功能与获取方式，可以看 [LeviLauncher 介绍站](https://levilauncher.wrwq.fun/)。
