# 离线地图下载与赴俄出行准备

> 本篇讲去俄罗斯旅行时怎么把 Yandex Maps 的离线地图提前下好：下载入口在哪、跨地区行程怎么分段下、入境初期网络受限时离线包能顶上什么用。
> **相关文章**：[安卓版安装步骤与故障处理](安卓版安装步骤与故障处理.md) · [界面语言设置与公交查询技巧](界面语言设置与公交查询技巧.md)

## 一、为什么离线包是赴俄行程的刚需

多份旅行指南与游客反馈都指向同一件事：入境俄罗斯后头一天常有一段「网络静默期」——漫游数据与短信受限、信号偏弱。这段时间想查地址、找路，靠的就是出发前下好的离线地图。离线状态下搜地址、规划驾车/公交/骑行/滑板车/步行路线都能用，只是没有实时路况。

## 二、下载步骤

1. 打开应用，点左下角**头像**进入个人页（不登录也能操作）；
2. 点 **Offline maps**；
3. 在搜索框输入国家、城市或地区名，从候选里选中；
4. 点下载图标开始下载，下载中别把应用从后台划掉。

注意两点：部分国家不支持整国下载，只能按城市/地区分块；一条路线跨多个地区时，**途经的每个地区都要下**，缺一段那段就查不了。给没下图的目的地规划路线时，界面会出现「Plan download」按钮，点一下，回到有网的环境会自动补下。

## 三、体积与更新

以应用商店给出的参考值，莫斯科的离线包约 187 MB，大城市普遍上百 MB，出发前建议预留 2 GB 以上空闲空间。更新方式二选一：**Auto update**（联网自动更新）或 **Download via Wi-Fi only**（只在 Wi-Fi 下更新，省流量），赴俄前推荐后者。

## 四、途中怎么用

- 把 Wi-Fi 和移动数据都关掉，应用自动进入离线模式，不需要手动开关；
- 开始导航后，路线信息栏上方出现 **Route built offline** 字样，说明当前走的是离线路线；
- 途中断网时已开始的导航会继续，中途改路线则按离线数据重算，联网后自动切回在线模式。

另外提醒：换 SIM 卡、改系统语言、拔插 SD 卡都可能导致已下载地图丢失，落地后如果发现地图不见了，重装应用或清空搜索与路线历史后重新下载即可（操作细节见 [安卓版安装步骤与故障处理](安卓版安装步骤与故障处理.md)）。

想按出行场景逐个功能过一遍（公交实时位置、室内路线、路况分值这些），可以到 [Yandexmaps 出行参考](https://yandexmaps.gltd.quest/) 看图文整理版。
