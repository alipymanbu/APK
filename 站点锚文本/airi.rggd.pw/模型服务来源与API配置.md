# AIRI 模型服务来源与API配置

AIRI 不绑定任何一家的模型，第一次打开时的「选择服务来源」页面就是给她接大脑的地方。本篇把常见问题一次说清：有哪些服务来源可选、本地模型怎么接、语音相关的服务去哪配。还没装好的先看[安卓版下载安装步骤](安卓版下载安装步骤.md)。

## 第一次打开：选服务来源

欢迎页会引导你设置第一个服务来源，列表里能看到 OpenAI、Azure OpenAI、Anthropic、Amazon Bedrock、Google Gemini、Groq、OpenRouter、Ollama 等选项。选一个你有账号（或打算注册）的，按提示填入密钥即可；以后想换，随时可以在设置页的「服务来源」分区里改。

一个形象的比喻：服务来源决定她「用什么脑子思考」，角色卡决定她「是什么性格」，两者互相独立、可以分别调整。

## 云端还是本地

**云端服务**（OpenAI、Gemini、OpenRouter 等）开箱即用、模型能力强，按服务商的计费规则付费；密钥只保存在你自己的设备上，由应用直接调用。

**本地模型**（Ollama）不把对话交给外部云端处理，推理发生在你自己的设备上，适合在意隐私或想零成本试玩的场景；代价是对设备性能有一定要求，效果也比不上最大的云端模型。

两种方式可以并存：日常用云端模型，偶尔切到本地玩。

## 语音相关配置

AIRI 的语音链路分三段：语音识别（听你说话）、语音合成（她开口回答）、说话检测（判断你说完没有）。识别在客户端完成；合成支持接入 ElevenLabs 等多家 TTS 服务，这些同样在设置页的「服务来源」分区里逐项配置。

配好之后，和她的交互就从打字变成了自然对话：你开口、她听完、再回答。

## 记忆与模块

设置页里还有两块值得认识：

- **记忆体**：存放记忆的内容与策略，聊过的偏好可以跨会话延续；
- **机体模块**：思维、视觉、言语综合、游戏等能力按需启用，只留聊天桌宠还是配成完整伙伴，由你决定。

配上游戏模块之后她就不只是聊天了，具体玩法见[一起玩我的世界](一起玩我的世界.md)；整体功能概览可以回 [AIRI 安卓版介绍站](https://airi.rggd.pw/)看介绍页。
