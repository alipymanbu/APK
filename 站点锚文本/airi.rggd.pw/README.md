# AIRI：安卓手机上的 AI 虚拟角色伙伴

这里是 AIRI 的第三方介绍与指引区。AIRI 是一个开源的 AI 虚拟角色桌宠应用，支持 Live2D 与 VRM 形象、实时语音对话、长期记忆，还能作为游戏智能体陪你玩《我的世界》《异星工厂》。想直接上手的话，可以看 [AIRI 安卓版介绍站](https://airi.rggd.pw/)，安装包的网盘获取入口也放在那里。

## 一句话认识她

打开应用，选一个 AI 服务来源，挑一个 Live2D 或 VRM 形象，她就会以桌宠的样子住在你的手机屏幕上：会眨眼、会跟着你的手指看、会开口回答，也记得住你们聊过的事。更多介绍见 [AIRI 安卓版介绍站](https://airi.rggd.pw/)。
