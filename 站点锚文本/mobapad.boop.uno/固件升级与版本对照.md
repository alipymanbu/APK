# 手柄固件升级与 App 版本对照：新机型搜不到先看这里

> 魔派手柄搜不到、设置项缺失，多数不是故障，而是版本没到：新机型要等 App 更新才被识别，部分功能还要求手柄固件达到下限。这篇给一张对照表和升级失败的处理办法。
> **相关文档**：[魔派手柄怎么连手机.md](魔派手柄怎么连手机.md) · [背键宏毫秒编辑玩法.md](背键宏毫秒编辑玩法.md)

## 一、手柄型号 → 起始支持的 App 版本

按应用商店版本历史整理（截至 2026-09，之后以各页面当时显示为准）：

| 手柄型号 | 起始支持版本 | 时间 |
| --- | --- | --- |
| N1-HD、N1s | 1.4.0 | 2024-11 |
| S1 | 1.4.3 | 2024-12 |
| ML35（虎贲 2） | 2.2.0 | 2025-05 |
| Pro2-HD（赤兔 2） | 2.6.0 | 2025-12 |
| 赤兔 2 静音版 | 2.6.4 | 2026-03 |
| 双子星 3-HD | 2.7.0 | 2026-05 |
| 双子星 3-S | 2.8.0 | 2026-05 |
| 赤兔 2 Lite | 2.8.5 | 2026-08 |

读法：手柄是赤兔 2 Lite、装的却是 2.8.2，连接列表里不会出现它——换新版即可；老型号（N1 / S1 / 虎贲 2 / 赤兔 2 系列 / M6 系列）在 2.8.x 里都已覆盖。

## 二、部分功能还看手柄固件

App 版本够了、设置项还是不出现，是手柄固件没到下限，几个例子：

| 功能 | 手柄 | 所需固件 |
| --- | --- | --- |
| 马达振动强度调节 | 双子星 M6-HD | 1.26 及以上 |
| 按键映射键鼠设置 | 虎贲 2 | 0.41 及以上 |
| 按键测试实时反馈 | 虎贲 2 | 0.51 及以上 |
| 死区 / 体感 / 连击 / 振动 | 双子星三代 HD | 0.32 及以上（配 App 2.8.3+） |
| 摇杆曲线 / 死区、连击 | 双子星三代 S | 1.18 及以上（配 App 2.8.3+） |

## 三、固件怎么升

1. 手机连上手柄，进 App 的**固件升级**页（有新版时入口会挂红点）；
2. 升级过程**别断网、别退出 App、别让手柄没电**——这三样是升级失败的主因；
3. 误升了新版也不用慌，升级页支持**刷回旧版**；
4. 例外：M9-HD 走电脑端升级器，不经手机 App；
5. Switch 2 兼容固件同样通过 App 推送到手柄。

升级成功后重新配对一次，再到按键测试里确认，然后按[背键宏毫秒编辑玩法.md](背键宏毫秒编辑玩法.md)把之前的配置补回来。连接排查见[魔派手柄怎么连手机.md](魔派手柄怎么连手机.md)；App 下载与安装方式在 [Mobapad](https://mobapad.boop.uno/) 有整页说明。
