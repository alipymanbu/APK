# Mobapad：围绕魔派手柄配套 App 的实用短文

> 这里是几篇写给魔派（MOBAPAD）手柄玩家的短文：连手机、编背键宏、升固件这些高频问题，每篇只讲透一件事。App 本身的功能全景与安装方式，见 [Mobapad](https://mobapad.boop.uno/)。

## 本目录有什么

- [魔派手柄怎么连手机.md](魔派手柄怎么连手机.md) —— 蓝牙配对、权限、被主机占用等连不上的逐项排查。
- [背键宏毫秒编辑玩法.md](背键宏毫秒编辑玩法.md) —— M1 宏的按下/持续/弹起逐段毫秒编辑思路。
- [固件升级与版本对照.md](固件升级与版本对照.md) —— 哪款手柄从哪个 App 版本开始被识别，升级失败的三大主因。

三篇按「先连上 → 再调键 → 出问题查版本与固件」的顺序排布，也可以单篇跳读。
