# Lyricify 四个版本怎么选

Lyricify 这个名字下其实有好几个版本：4、Fusion、Mobile，还有一个已停更的 3。它们都出自同一位开发者（WXRIW），但平台和定位差得不小，装错平台是最常见的第一坑。这篇把它们摆在一起对比，按设备对号入座。

## 一、一张表看清

| | Lyricify 4 | Lyricify Fusion | Lyricify Mobile | Lyricify 3 |
| --- | --- | --- | --- | --- |
| 平台 | Windows | Windows | Android / iOS / iPadOS / macOS | Windows |
| 面向谁 | 主要用 Spotify 听歌的人 | 用 Apple Music、QQ 音乐等带 SMTC 播放器的人 | 想在手机、平板、Mac 上看词的人 | 历史版本 |
| 定位 | 功能最全的桌面端 | 多播放器适配 | 随身看词 | 已停更 |

3 已于 2024 年 6 月停止功能更新与维护，只作历史保留，新装不用考虑它。

## 二、各自能做什么

**Lyricify 4（桌面全功能）**：逐字歌词（精确到音节）、桌面歌词、多套界面（含 1:1 还原的 Apple Music 样式）、歌词管理与导入修改。依赖 .NET Desktop Runtime 6.0，装它之前先把这个运行时装上。

**Lyricify Fusion（多播放器适配）**：不走 Spotify 接口，而是读取系统 SMTC 信息，所以苹果音乐、QQ 音乐、网易云等客户端都能挂上。形态上偏「桌面部件」：动态歌词岛、任务栏歌词、桌面歌词都在这一版里。

**Lyricify Mobile（随身看词）**：只有 Apple Music 风格一套界面，整行滚动歌词加翻译，能顺手切歌；与 4 共用同一份歌词库。它明确没有的东西也别找：桌面歌词、逐字歌词、多套主题都没有，开发者也没有加入计划——这些需求只能回桌面端满足。

## 三、几个常被一起问的问题

- **两个都装冲突吗？** 不冲突。电脑装 4、手机装 Mobile，登录同一个 Spotify 账号即可，歌词库自动互通；
- **免费账号能用吗？** 看歌词这个核心功能没有订阅门槛；但 Mobile 撞上 429 想配自定义 API Client、以及 4 的部分控制类功能，需要 Premium 订阅；
- **iPhone / iPad 怎么装？** Mobile 的 iOS 端没有上架 App Store，要按项目文档的「Apple 设备自签教程」自行安装，装前先有这个预期。

## 四、结论

- 只在 Windows 用 Spotify、想要完整体验 → Lyricify 4；
- 用的是其他音乐客户端 → Lyricify Fusion；
- 主要在手机上看词 → Lyricify Mobile，安卓获取入口见[安卓版下载安装与授权步骤.md](安卓版下载安装与授权步骤.md)；
- 装完用着出问题 → 看[歌词不显示与429怎么处理.md](歌词不显示与429怎么处理.md)。
