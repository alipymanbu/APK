# 离线翻译怎么弄：出发前把语言包放进手机

> 本篇讲翻译应用的离线翻译怎么设置、离线模式下能干什么不能干什么，以及出发前应该做的一次实测。

## 一、为什么非离线不可

出境头两个小时是最容易抓瞎的时段：飞机落地、排队过境、机场找车，漫游套餐往往还没生效，当地电话卡还没插上，公共 Wi-Fi 又连不稳。这段时间恰恰要跟人沟通。离线翻译解决的就是这个空窗——语言包早就存在手机里，翻译全程在本地完成，一张 SIM 卡都不用。

另一个理由是钱。漫游流量按 MB 计费，翻译应用虽不算流量大户，但架不住使用频率高；离线模式开着，这笔钱直接省掉。

## 二、设置步骤（以 iTranslate 为例）

1. **连上 Wi-Fi**：语言包几十 MB 到上百 MB 不等，别用流量下；
2. **打开 Offline Mode**：在设置里把离线模式开关拨到开启，图标是一架小飞机；
3. **下载目的地语言包**：在语言列表里找到要去的国家，点下载，等进度走完；
4. **开飞行模式试一遍**：出发前实测是关键一步——打一句常用语看看能不能翻，能翻说明包是全的。

这一套在 [iTranslate 的介绍站](https://itranslate.fewf.ren/)里有对应截图和更细的说明，装应用之前可以先去对照着看一遍界面长什么样。

## 三、离线模式的能力边界

离线不是万能，心里有数才不会在关键时刻误事：

- **文本翻译**：离线支持的主阵地，热门语言覆盖普遍在几十种的量级，iTranslate 官方口径是 40 多种语言可离线；
- **语音对话**：离线语音要本地跑识别与合成，支持的语言比文本少得多，只有少数几种语言做得到；
- **镜头识别类功能**：这类功能对算力要求高，部分情况下仍需要联网，别默认它断网可用；
- **翻译质量**：离线模型为了塞进手机做过精简，长句和生僻表达的准确率不如联网档，重要的正式沟通尽量找网用在线翻译。

## 四、出发前的三分钟清单

- [ ] 目的地语言包已下载完成
- [ ] 飞行模式下打字翻译实测通过
- [ ] 常用关键句（地名、酒店名）已经存在短语收藏里
- [ ] 知道哪些功能断网用不了，心里有替代方案

做完这四条，落地那一刻就不慌了。
