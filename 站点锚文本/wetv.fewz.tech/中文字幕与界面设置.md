# WeTV 中文字幕与界面设置：两条语言线分开调

> 首次打开 WeTV 默认是英文界面，很多人卡在这一步。实际上它有两条独立的语言线：界面语言在个人中心里改，字幕语言在播放器里改。本篇把两条线都写清楚，顺带列几种改不动的情况。

## 一、界面换成简体中文

界面语言不跟随手机系统，要手动改一次，路径固定：

1. 点右下角 `ME`（个人中心，图标是小人像）；
2. 点 `Settings`（设置）；
3. 点 `Language`（语言）；
4. 在列表里选「简体中文」，界面立即切换，不用重启应用。

可选项通常还有繁体中文、英文、泰文、印尼文等，选错了随时回同一入口再改。

## 二、播放时开中文字幕

界面换了中文，字幕仍可能默认是英文或泰文，要单独设：

1. 播放任意一集，点一下屏幕唤出控制栏；
2. 找到 `CC` 字样的字幕图标点开；
3. 选「中文（简体）」或「中文（繁体）」，播放器立即加载。

之后播放其他剧集一般会沿用这次的选择，个别片源会重置，重选一次即可。国产剧大多是中文原声、字幕多语；泰剧韩剧保留原声靠字幕，部分热门剧另有泰语、印尼语配音，在播放器的音轨入口里换。

## 三、选项点不动时的几种情况

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 字幕列表里没有中文 | 该片源未制作中文字幕 | 只能选其他语言；热门新剧的字幕一般陆续补齐 |
| `CC` 图标是灰的 | 正片未开始或无字幕 | 先点播放让进度走起来再点 |
| 设置里找不到 `Language` | 版本过旧或入口调整 | 换较新版本再看 |
| 改了没生效 | 页面缓存未刷新 | 退出应用重新打开 |
