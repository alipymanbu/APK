# 一个应用看四家直播靠谱吗

> 虎牙、斗鱼、哔哩哔哩、抖音各装一个客户端太占地方，聚合播放器是不是更省事？这篇以 Simple Live 为例，把「聚合看直播」这条路的真实体验讲清楚：能干什么、不能干什么、适合谁。
> **相关文档**：[手机电视同步看直播的方法.md](手机电视同步看直播的方法.md)

---

## 一、聚合播放器是什么形态

Simple Live 是一个开源的聚合直播播放器（GPL-3.0 协议，项目在 GitHub 上），做的事情很专注：把四家平台的直播间整合到一个列表里。打开应用就是首页，顶部四家平台的名字一字排开，左右滑动或点名字就切换，每个平台下面是按人气排序的直播间，封面上带实时观看人数。

它不是哪一家的客户端，也不要求你注册新账号——应用本身没有账号体系，虎牙、斗鱼、抖音的内容打开就能看，只有 B 站多数内容需要登录一次你自己的哔哩哔哩账号。

## 二、实际用下来怎么样

**省事的地方：**

- 一个列表看完四家，搜索框输主播名、房间号或「LOL」这类关键词，结果覆盖全部平台并标明来源；
- 弹幕可控：字号、透明度、速度、显示区域都能调，屏蔽词一加，刷屏口令整条消失；
- 画质档位照搬平台提供的，流畅到原画都有，B 站高档位需登录后解锁；
- 小窗悬浮播放、定时关闭、夜间模式这些常用件都齐。

**要有预期的两点：**

1. **发弹幕、送礼这类互动是弱项。** 它以观看为主，发送类互动按平台和登录状态而定，重度粉丝团用户还是会回到各家的客户端。
2. **依赖平台接口。** 平台一调整，某个平台临时看不了是这类工具的常态，历史上多数靠版本更新修复——问题集中在一家、以前好好突然不行，多半就是这种情况。

## 三、安装包从哪来

项目在 GitHub 上已声明不再随版本提供现成安装包，应用商店里也未必搜得到，一般走 APK 安装包的路子。[Simple Live 介绍站](https://simple-live.bmww.store/)整理了它的功能清单、界面截图和安装文件资源的网盘入口，安卓版要求 5.2 及以上，安装包只有 17MB 出头，老手机也不挑。

装法不复杂：网盘转存后下载 APK，允许一次「安装未知应用」就能装完，具体的分步操作站点下载页里写得很细。

## 四、结论

只想「看」直播的人——同时追两三家主播、烦开屏广告、手机存储紧张——聚合播放器是对路的解法；要送礼、上粉丝团、追平台活动，还是得装那家的客户端。两边不冲突，很多人是各留一个。
