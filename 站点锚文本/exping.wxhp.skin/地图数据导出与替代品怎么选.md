# exping 停服后地图数据怎么办：导出与替代思路

> exping 曾把「数据自由」写进产品理念，支持 GeoJSON、KML、Excel、HTML、Markdown 五种导出格式；但服务器关闭后，云端那条路已经断了。本篇按数据存在哪、还剩哪些通道、替代品怎么挑三段讲清现状。
> 相关文章：[是一款什么样的应用](是一款什么样的应用.md) · [停服后还能下载安装吗](停服后还能下载安装吗.md)

## 一、数据在哪，决定还有没有机会

**存在云端（多数人的情况）**：地图随账号保存在服务器上，2024-12-31 停服后服务器已关，云端数据随之不可访问。开发团队在停服前开放过全量导出，但那扇门已经关了——现在没有其他任何通道能再取回云端那份。

**留在旧手机里（窄路，但值得一试）**：如果停服前装过 exping 且一直没卸载，本地可能还留着缓存或数据库副本。做法：

1. 先别更新、更别卸载，保持原状；
2. 打开旧版本，看能否凭残留登录态进入地图列表；
3. 能进就立刻试客户端内的导出，优先 **GeoJSON**——坐标、路线、属性齐全，换任何仍在维护的工具都能接上；其次 KML；
4. 进不去就基本没有办法了，导出入口本身也在登录之后。

顺带一提：它当年有「误删 72 小时内可恢复」的删除保护，但该机制依赖账号服务，如今只在第 2 步能走通的前提下才有意义。

## 二、五种导出格式分别适合什么

停服前版本的导出口径，留作格式选择的参考：

| 格式 | 适合拿去做什么 |
| --- | --- |
| GeoJSON | 标准地理数据格式，迁移首选 |
| KML | Google 地图系工具通用，也方便归档 |
| Excel | 表格化整理地点清单，做行程表、台账 |
| HTML | 保留网页样式，浏览器双击即可回看 |
| Markdown | 转进笔记软件继续编辑 |

## 三、替代品怎么挑

带着格式去挑，比带着感情去挑靠谱：

1. **先定格式底线**：手头有 GeoJSON / KML 的，替代品必须支持导入这两个格式之一，否则数据接不上；
2. **再核服务存续**：exping 的教训在于「好用但没撑住」。挑替代品时看团队规模、更新频率与商业模式，单人格子间里的小团队产品可以欣赏，但别把重要数据只存在一处；
3. **按场景对功能**：探店收藏看重标记与点评、旅行规划看重路线与分组、团队协作看重多人编辑与位置共享——按自己最主要的场景核对，不必追求全能；
4. **保留导出习惯**：无论选哪家，定期导出一份 GeoJSON 存在自己手里。工具会谢幕，通用格式不会。

当年它的一系列界面与玩法截图，仍在 [exping 存档站](https://exping.wxhp.skin/) 留档，评估「同类工具该长什么样」时可以对照参考。

## 四、关于社区流传的「精神续作」

停服后有用户提到一款玩法相近的新应用，称其支持导入 exping 的分享链接，并猜测与原团队有关。这只是个别用户的观察，没有任何确认说法，下判断前先自行核实。更稳的路子仍然是本文第三节：格式先行，逐家核对。
