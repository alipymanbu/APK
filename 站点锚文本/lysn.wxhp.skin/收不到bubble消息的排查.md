# Lysn 收不到 bubble 消息的排查

订阅了却等不到消息、通知不响、图片语音打不开——按本篇顺序从「是不是真收不到」查到「系统层为什么拦了」。还没装应用的话，先去 [Lysn 安卓版下载安装](https://lysn.wxhp.skin/) 拿安装包。

## 一、先确认是不是「真收不到」

两种情况不是故障，别白折腾：

- **没订阅**：bubble 是付费订阅制，没买某位艺人的利用券就收不到他的消息。
- **艺人本来就不定期发**：消息按艺人个人安排非定期发出，巡演、休息期几天没动静属于正常。

## 二、应用内通知设置

1. 打开右下角「更多」→ 设置 → 聊天通知设置，检查消息到达通知、通知栏显示、锁屏弹通知三项。
2. 单个聊天室可能被单独静音：进那间房点右上角菜单，检查铃铛状态——很多人是被单独关了一个房间。

## 三、安卓系统层

- 到 设置 → 应用 → Lysn → 电池，选「无限制/不优化」，别让电池优化把后台杀掉、推送就断。
- 装了省电类、清理类工具的，把 Lysn 加进它们的白名单。
- 改完锁屏等几分钟，让推送恢复后再观察。

## 四、图片、视频、语音打不开

| 现象 | 处理 |
| --- | --- |
| 图片/视频不显示 | 多为网络波动，切换 Wi-Fi 与流量后重进聊天室 |
| 语音没声音 | 检查媒体音量与蓝牙连接，重进聊天室再播 |
| 回复发不出 | 先重启应用，再对照回复额度确认是否发满 |

换机或重装后聊天列表为空，先检查登录的是不是原账号——邮箱拼错一个字母就是另一个新账号。
