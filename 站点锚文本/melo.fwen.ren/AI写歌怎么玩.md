# MELO 是什么：一款把写歌变成聊天的 AI 应用

MELO 是北京灵犀深智科技推出的 AI 音乐创作应用：你用一句话、一张照片、一段哼唱描述想法，它补齐作词、谱曲、演唱与编曲，几十秒内给出一首带完整人声的成品歌。它覆盖安卓、iPhone、微信小程序与网页四个入口，账号打通、作品云端同步，换设备登录同一账号就能接着用。

相关阅读：[写歌提示词怎么写.md](写歌提示词怎么写.md) · [安卓版安装与上手路线.md](安卓版安装与上手路线.md)

## 对话式创作：没有参数面板

MELO 的交互里没有 BPM 滑块、没有调式下拉，也没有编曲模板九宫格。你像发消息一样描述想要的歌曲——「毕业季的粤语民谣，女声，前奏用吉他，3 分钟左右」——它就去生成。成品不满意，就在对话里接着说「副歌再高一点」「鼓别这么满」，模型会按你的反馈继续调，不必从头重写。

有用户实测普通短曲几十秒出结果，而且常一次给两个版本：先在两版里挑，再往下改，试错成本不高。

## 七种输入起点

随手有什么，就从哪里开始：

| 你给它的 | 你得到的 |
| --- | --- |
| 一句心情 | 自动作词、谱曲、演唱的完整歌 |
| 完整歌词 | 直接谱曲演唱 |
| 一段哼唱 | 旋律片段被扩成完整歌曲 |
| 一张照片 | 按画面色调与氛围成曲 |
| 视频 / vlog 片段 | 按画面节奏做卡点配乐 |
| 参考音频 | 解析风格后按那个路数重做 |
| 现成伴奏 | 自动填词、配人声 |

## 曲风、方言与人声

曲风覆盖流行、民谣、古风、R&B、说唱、摇滚、电子、Lo-fi、史诗配乐等，国风里的古筝、唢呐、二胡、马头琴音色做得比较细。中文咬字是主打，方言唱腔是它相对同类产品的强项——粤语、闽南语、藏语、蒙语、维吾尔语、客家话都有专门优化，外语支持英、日、韩、西、印地、越南等。人声质感可选烟嗓、童声、御姐、气泡音，也能排男女对唱、大合唱；上传一段自己的录音做音色克隆后，任何一首歌都能指定用你的声音唱。

单首最长可到 8 分钟，装得下完整的前奏、主副歌、桥段与尾奏。

## 写完之后：二创与归属

拿到成品还能继续折腾：原曲换音色翻唱、把人声和伴奏拆开单独用、词不变换曲、从成品里抽动机当下一首的起点。导出方面，日常用 MP3 就够；48kHz 无损 WAV、最多 12 条分轨以及 MIDI、简谱乐谱属于会员向权益。版权口径：会员生成的作品所有权归用户、可自由商用发行，免费生成的作品可通过购买创作存证获取所有权——细则以应用内页面为准。
