# AI 写歌提示词怎么写：让 MELO 一次出对味的歌

在 MELO 这类对话式写歌应用里，「给我写首好听的歌」等于让 AI 猜你的口味——猜错不是它能力差，是你没给信息。一条把画面说清楚的提示词，能让成品的贴合度完全不同。

相关阅读：[AI写歌怎么玩.md](AI写歌怎么玩.md) · 安装与上手见 [安卓版安装与上手路线.md](安卓版安装与上手路线.md)

## 一个通用公式

**语种 + 曲风 + 人声风格 + 情绪氛围 + 小细节**

- 反面：`给我写首悲伤的歌`
- 正面：`国语女声，emo 流行，烟嗓，凌晨三点刷朋友圈的丧感，钢琴打底，带点下雨的白噪音，旋律别太吵，适合深夜循环`

差别只有一处：后者每个词都在缩小选择范围。写提示词的本质，是把「你脑子里那个画面」拆成 AI 能执行的约束。

## 五个要素各写什么

| 要素 | 写得具体一点的样子 |
| --- | --- |
| 语种 / 方言 | 国语、粤语男声、闽南语、英语、日语 |
| 曲风 | 别只写「电子」，写 lo-fi、City Pop、90 年代港风摇滚 |
| 人声 | 男声 / 女声 + 质感（烟嗓、气声、清甜）+ 唱法（慵懒、高亢、带哭腔） |
| 情绪 / 场景 | 用画面替代形容词：「凌晨三点的出租屋，窗外下雨」比「伤感」准 |
| 小细节 | 主乐器、速度、用途（适合深夜循环、当 vlog 配乐） |

三条避坑：别堆乐器（列七八样会互相打架，挑 3~5 样核心的）；别自相矛盾（「又炸又安静的纯音乐」只能二选一）；关键定位放开头，别埋在句尾。

## 结构标签：让歌有完整骨架

不想只得到一段副歌循环，就在提示词或歌词里标出段落：

```
[前奏] 古筝泛音 + 流水声，静谧悠远
[主歌] 竹笛打底，人声轻柔叙事，鼓点弱进
[副歌] 大鼓 + 弦乐齐奏，人声高亢有力量
[桥段] 节奏抽空，只剩人声和钢琴
[尾奏] 渐弱收尾
```

通用标签对应：`[Intro]` 前奏、`[Verse]` 主歌、`[Chorus]` 副歌、`[Bridge]` 桥段、`[Outro]` 尾奏。分段描述每一段的配器与情绪，成品的层次感会明显不同。

## 排除法与符号技巧

结果里老混进不想要的元素时，直接声明排除项：国风抒情曲补一句「避免电子鼓、合成器音色」；轻柔纯音乐补「无打击乐」；只要伴奏就明确写「纯音乐，无人声」。「不要什么」和「要什么」同等重要。

歌词层面还有几个实测有效的写法：把字拆开写制造拖长音（`快 - 乐 -`）；把要和声的词塞进括号出双声部（`摸鱼的快乐（快乐）`）；句末用标点引导力度（感叹号走高亢，问号走心虚低语）。

## 生成之后怎么迭代

一次会出多个版本，先挑再改；在对话里指出具体问题（「副歌再高一点」）比重做整首省；先让副歌达标再扩展成完整曲；脑子里有旋律就录哼唱、有氛围就丢照片，比纯文字更不跑偏。应用与输入方式的全部玩法见 [AI写歌怎么玩.md](AI写歌怎么玩.md)；还没装的话，[安卓版安装与上手路线.md](安卓版安装与上手路线.md) 从获取安装包一路讲到第一首歌，也可以先去 [MELO 安卓版介绍站](https://melo.fwen.ren/) 看界面截图与功能梳理。
