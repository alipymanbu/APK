# 手机看自家影音库的准备清单

「在家 NAS 上存了一堆电影剧集，怎么在手机上随时看？」——这条链路其实只差三个环节：一台跑着影音服务器的设备、一个能连上它的手机客户端、以及两端之间可达的网络。这篇按顺序把准备工作列清楚。

## 一、服务端：先有一台常开的设备

影音库的「家」得先安顿好：

- **设备**：NAS、家里的台式机、甚至一台旧笔记本都行，关键是看片时段它得开着；
- **服务端软件**：Emby、Jellyfin、Plex 都是常见选择，装好后把电影、剧集的文件夹加进媒体库，让它刮削好海报与元数据；
- **账号**：在服务端建一个自己的账号，记下**服务器地址 + 用户名 + 密码**这三样——手机端连接时用的就是它们。

## 二、网络：分清「家里看」和「外面看」

- **局域网内**（连家里 Wi-Fi）：最简单，直接用内网 IP 加端口访问，比如 `192.168.1.10:8096`；
- **外网访问**：需要服务器侧具备公网可达的条件——端口转发、DDoS 防护或内网穿透方案任选其一，手机端填的地址也要换成对应的公网形式。

判断服务端通没通，最直接的办法是拿另一台设备开浏览器访问 `http://服务器地址:端口`，能打开登录页就说明服务端就绪了。

## 三、客户端：按设备挑一个装上

服务端就绪后，手机上装一个对应的客户端。挑法在 [第三方Emby客户端怎么挑](第三方Emby客户端怎么挑.md) 里展开过，不重复；只提醒一句：**客户端装哪个都行，账号是通用的**，连的都是同一台服务器。

安卓手机走 APK 安装包装不上商店应用时，注意安装前要在系统设置里允许「安装未知应用」的权限。以 Yamby 这类轻量客户端为例，装好后首次打开点右下角加号、填上面记下的三样信息就能进媒体库，具体的界面与功能介绍可以看 [Yamby 介绍站](https://yamby.fewa.skin/)。

## 四、核对清单

动手前对照一遍：

- [ ] 一台看片时段常开、装好影音服务端的设备
- [ ] 媒体库已建好，海报与信息刮削正常
- [ ] 服务器地址、端口、账号密码记录在案
- [ ] 手机与服务器在同一网络（或外网访问已打通）
- [ ] 手机上已装好客户端

五项都打勾，打开客户端连上服务器，海报墙出来就算大功告成。连不上时先查服务端是否存活、端口协议是否配对，多数问题出在这两处；装好之后播放体验的调法，见 [Emby安卓端弹幕与字幕调节](Emby安卓端弹幕与字幕调节.md)。
