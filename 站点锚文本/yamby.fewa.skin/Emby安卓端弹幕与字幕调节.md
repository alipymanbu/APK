# Emby安卓端弹幕与字幕调节

装好客户端、连上服务器之后，真正决定「看得舒不舒服」的是播放体验的细节：弹幕有没有、字幕对不对得上、音轨能不能随手切。这篇把这些高频调节项集中讲一遍，均以安卓端客户端的常见实现为准。

## 一、弹幕：先弄懂匹配机制

安卓端支持弹幕的客户端不多，而且实现路径基本一致：**基于 dandanplay 匹配当前播放的剧集，仅限中文弹幕**。由此带来三条「特性」：

1. 匹配不上就没有弹幕——小众片源、刚出的资源常见，这是机制限制，不是开关没开；
2. 匹配依赖文件名与剧集信息，文件命名越规整，匹配成功率越高；
3. 弹幕内容只覆盖中文，外语内容的弹幕本来就少。

追番用户挑客户端时可以把「弹幕支持」当硬指标，比如 Yamby 就把中文弹幕做进了播放器；具体效果还是得以实际匹配为准。

## 二、字幕：四个高频调节项

| 调节项 | 什么时候动它 |
| --- | --- |
| 字幕轨选择 | 文件内嵌多条字幕、或外挂了 srt/ass 时，播放中直接切 |
| 字幕缩放 | 字幕太小看不清、或太大挡画面时调 |
| 时间偏移 | 字幕比台词快/慢几秒时微调：正值延后、负值提前 |
| 自定义字体 | 中文显示异常或样式不合口味时换字体文件 |

时间偏移是最常用的救急项—— 不同版本的视频与字幕时间轴常有几秒错位，往一个方向试几次就能对上。多数客户端（包括 Yamby 这类）都支持播放中即时调整、不用退出重进。

## 三、音轨与播放参数

- **多音轨切换**：剧集带双音轨（如国语/粤语）时，播放中直接换，不用重新加载；
- **倍速播放**：看访谈、听课程类内容常用，倍速不影响服务器上的原文件；
- **缓存大小**：网络抖动导致频繁缓冲时调大；设备内存紧张就别开太大。

## 四、画面外的两件事

- **画中画**：切出去回消息时，播放画面缩成小窗继续播；需要在系统设置里给客户端开「画中画」权限；
- **手势操作**：滑动调节音量、亮度、进度。不少客户端的手势默认关闭（Yamby 就要在设置里手动打开），画面上滑没反应时先去设置里找开关，别误以为功能缺失。

这些调节项没有「一次设对」的通用值，按自己的习惯调到顺眼就行。还没装客户端的，先看 [手机看自家影音库的准备清单](手机看自家影音库的准备清单.md)；挑客户端的思路则见 [第三方Emby客户端怎么挑](第三方Emby客户端怎么挑.md)，或直接到 [Yamby 介绍站](https://yamby.fewa.skin/) 看一款轻量客户端的功能与界面实拍。
