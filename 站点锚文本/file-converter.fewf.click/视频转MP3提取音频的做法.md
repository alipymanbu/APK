# 视频转 MP3：在手机上把视频里的声音提出来

## 动手前先分清两种情况

手机上提音频的工具不少，思路分两类：

| 方式 | 文件去向 | 适合 |
| --- | --- | --- |
| 在线转换网站 | 上传到网站、转完再下载 | 小文件、偶尔用一次 |
| 手机上的转换应用 | 本地完成，文件不出手机 | 大视频、经常要转、在乎隐私 |

两小时以上的长视频，走在线网站上传这一步就很煎熬；本地的做法是把 File Converter（安卓应用）装在手机上直接转，装法在 [File Converter 格式规格单](https://file-converter.fewf.click/) 里有完整说明。

## 在应用里怎么操作

1. 打开应用，主页点「视频转换器」这一类；
2. 右下角「+」从相册或文件目录里选视频，可以一次多选；
3. 输出格式选 MP3（想换别的看下一节）；
4. 展开高级设置可以调比特率、采样频率，或者做裁剪（trim）——只要视频里某一段声音时用它；
5. 点转换提交。音频类走的是本地转换，不需要联网，转完在侧栏「已转换」里取文件。

转换期间别把应用从后台清掉：本地编码占 CPU，进程被杀任务就得重来。大视频转得慢是正常现象，插着电转更稳妥。

## 输出格式怎么挑

| 你的用途 | 选这个 | 理由 |
| --- | --- | --- |
| 车机、老播放器、通用场景 | MP3 | 兼容面最广 |
| 语音内容、要体积小 | OPUS | 同等听感下文件更小，新设备支持好 |
| iPhone 铃声 | M4A | 苹果生态顺手 |
| 音乐、要保音质 | FLAC | 无损，文件也大 |
| 存档、不在乎体积 | WAV | 无压缩 |

想给手机直接当铃声用，转成 M4A 或 MP3 后再到系统设置里指认它；转出来的文件也能当场通过系统分享发给微信、邮箱等。

## 转不动时的检查点

- 视频本身带了数字版权保护（比如某些平台下载的加密内容）——这类文件转不了；
- 输出文件播不出来，先确认播放器支持那个容器格式，换个 MP3 再验一遍；
- 应用里任务出现在「失败的」分组，多见于手机存储不足或转换中途进程被清，清理后重试。
