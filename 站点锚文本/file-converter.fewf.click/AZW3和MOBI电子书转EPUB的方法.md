## 先确认书是不是能转的

电子书是格式转换里"边界感"最强的类别，动手前先排查两件事：

- **带 DRM 保护的书转不了**。从商店购入、需要账号授权才能打开的电子书，大多带了数字版权保护，任何格式工具都不该去碰它；
- **自己导入的文件（网上下载的 AZW3/MOBI、自己做的 EPUB）**一般没这层限制，可以放心转。

判断方法很朴素：用阅读器打开不需要登录授权、能在设备间随便拷贝的，基本就是无保护文件。

## 转换步骤

以 AZW3 转 EPUB 为例，安卓手机上用 File Converter 操作：

1. 主页点「电子书转换器」——这一类里能看到 AZW3、CBZ、DJVU、DOCX、EPUB、FB2、HTML 等一整列输出方向；
2. 右下角「+」选入书文件；
3. 点选 EPUB 作为输出格式；
4. 展开高级设置可以补两件事：改书名等元数据、按目标阅读器选配置（Kindle、Kobo、Nook 等都有对应档案）；从 MOBI 往 EPUB 转时顺手核对一遍书名，老文件元数据经常是空的；
5. 提交转换。电子书走云端处理，需要网络畅通——公司 Wi-Fi 或校园网拦外网请求时，切手机流量再试。

转完在侧栏「已转换」里取书，直接分享给手机上的阅读应用即可。

## 反方向：EPUB 转回 AZW3/MOBI

给 Kindle 传书的场景同样在这套流程里：选入 EPUB、输出方向改成 AZW 或 MOBI 即可。两边走的是同一个转换入口，差异只在输出格式的选择。

| 去向 | 输出选 | 备注 |
| --- | --- | --- |
| 手机阅读器（微信读书、静读天下等） | EPUB | 主流阅读器都认 |
| Kindle 设备 / Send to Kindle | AZW、MOBI | 老设备以 MOBI 兼容性好 |
| 存档、排版不动的版本 | PDF | 页面固定，适合打印或归档 |

## 转完怎么核对

- 章节目录还在不在——AZW3 转 EPUB 最容易丢的是章节书签；
- 封面与元数据有没有错位，不对就在应用里补一遍书名再转；
- 排版复杂的扫描版 PDF 转 EPUB 会散架，这类文件直接存 PDF 更合理。
