# nealfun 是什么应用？里面的游戏一次列清楚

经常有人在群里发一张花花绿绿的卡片截图，问「这个在哪玩」。那些卡片多半出自 neal.fun——美国独立开发者 Neal Agarwal 从 2017 年起陆续发布的个人项目合集，如今公开可见的项目已有 35 个以上。而 nealfun 就是把这面「项目卡片墙」整体搬进手机的安卓应用：打开后是中文的项目列表，点哪张卡进哪个项目，不用自己记网址。

## 应用本体是什么

nealfun 本身不做游戏，它更像一个「桌面快捷方式合集」：安装包只有 1MB 出头，里面装的是项目列表和网页容器。项目本体来自 neal.fun 网页端，所以点开任何一张卡都需要联网加载，断网时列表还能翻、项目会一直转圈。

界面语言也值得一说：应用里的列表是中文，好挑好找；点进项目之后，内容基本保持英文原样。好在绝大多数项目的操作只有点、拖、滚动三样，语言基本不构成门槛。

## 值得先点开的卡片

按上手动作来分，比背名字好使：

| 上手动作 | 代表项目 | 一句话说明 |
| --- | --- | --- |
| 拖两下合成 | Infinite Craft | 水、火、风、土两两组合，AI 现场给结果，合出新组合会被记「首次发现」 |
| 一直往下滚 | The Deep Sea / The Size of Space | 从阳光带滚到深渊海沟，或从人类滚到可观测宇宙 |
| 规则越叠越多 | The Password Game / Stimulation Clicker | 密码规则一路加到 35 条；点击器把屏幕堆满为止 |
| 自己动手拼 | Design the Next iPhone / Asteroid Launcher | 给空白手机模具加配件自动估价；自定义小行星看损害评估 |
| 点开即完 | Draw a Perfect Circle / Absurd Trolley Problems | 画圆打分；从经典电车难题一路荒诞下去 |

列表底部还有 Sun vs Moon、Rocks、Dark Patterns、Life Checklist 这些新面孔，名单会随网页端更新而变化，以打开应用时实际看到的为准。

## 装一个要花什么

应用本身不设付费门槛，也没有订阅环节；对机型的要求很低，老安卓机也能装。流程与注意点集中在[安卓包获取与安装步骤](安卓包获取与安装步骤.md)里；想先弄懂招牌玩法，可以从[无限合成玩法入门](无限合成玩法入门.md)看起。至于整面卡片墙长什么样、按时间怎么挑项目，[nealfun](https://nealfun.fewf.ren/) 介绍站上有完整的导览。
