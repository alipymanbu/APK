# 无Root自动化脚本入门

想让安卓手机自动签到、自动整理文件，又不想折腾 Root？Autox.js 是目前最顺手的一条路：它用 JavaScript 写脚本，靠系统无障碍服务读屏与点击，手机上装一个应用就能开工。本文把入门路径一次讲清，安装包可以从 [Autox.js 指南站](https://autox-js.hfdk.space/) 提到的网盘资源获取。

## 一、为什么它不需要 Root

Autox.js 的自动化建立在系统无障碍服务上——这是安卓为视障用户提供的读屏与操作接口，权限足够完成点击、滑动、找控件，所以绝大多数脚本用不到 Root。个别需要更高系统权限的操作，可以用 Shizuku 授权来替代，7.x 分支已经内置支持。

## 二、第一个脚本长什么样

打开应用新建 main.js，五行就能看到效果：

```javascript
toast("脚本开始运行");   // 弹出提示气泡
launchApp("设置");       // 打开设置
sleep(2000);             // 等 2 秒
home();                  // 回到桌面
```

前提是无障碍服务已经开启。气泡弹出来、设置被打开，自动化这条线就算通了。

## 三、控件思路与坐标思路

写自动化脚本有两条路线：

- **控件思路（推荐）**：按文字、ID 找屏幕上的控件再操作，比如 `text("蓝牙").findOne(5000)`。不同分辨率、不同机型通用，换手机脚本照跑。
- **坐标思路**：直接 `click(540, 1200)` 按坐标点。适合游戏画面、自绘控件这类找不到控件的场景，缺点是换个屏幕就全错。

能用控件就用控件，坐标只留给画不出来的场面。

## 四、新手最容易卡住的地方

不是语法，是权限：无障碍没真正生效（开关亮着但服务已死）时，连 toast 都不弹，把开关关掉重开即可；国产系统还会用电池策略杀后台，把应用加进电池白名单再跑长任务。这两关过了，剩下的就是慢慢把 JavaScript 学起来——内置示例和离线文档足够起步。
