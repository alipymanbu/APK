# 给装机与救援准备镜像：仓库直取与空白镜像两条路

> 手机启动盘好不好用，取决于镜像备得对不对。本篇按"你要干什么"反推该备哪种镜像，并讲清两条取镜像的路。
> **相关文档**：[手机当启动盘的完整教程.md](手机当启动盘的完整教程.md) · [引导失败的排查清单.md](引导失败的排查清单.md)

---

镜像就是启动盘里的"系统或工具本体"。装 Windows、试 Linux、救一台起不来的电脑，对应的镜像各不相同；DriveDroid 的镜像来源有两条路——内置仓库直接取，或者自己造空白镜像回电脑写入，按需求选即可。

## 一、先想清楚你要哪种盘

| 目的 | 适合的镜像 |
| --- | --- |
| 给电脑装系统 | Windows 安装镜像，或 Ubuntu、Fedora、Arch、Debian 等 Linux 发行版的安装 ISO |
| 应急救援维护 | GParted（分区调整）、Clonezilla（整盘克隆）、维护工具合集类镜像 |
| 随身 live 系统 | Kali 这类支持持久化的发行版，改动能保存、换机接着用 |

三类可以并存：手机存储够的话，装机盘和救援盘同时备一套，用哪个挂哪个。

## 二、内置镜像仓库直取

应用内置了持续更新的镜像列表，主流 Linux 发行版和常用工具盘不用自己找资源：Ubuntu、Fedora、Arch Linux、Debian、Kali Linux、Linux Mint、openSUSE、GParted、Clonezilla、FreeDOS、ophcrack、Grml 等都能在仓库里直接下载到手机，主界面点加号即可添加。

这也是它比传统 U 盘省事的地方——换发行版试玩，仓库里点一下，不用回电脑重新烧录。

## 三、空白镜像自己造

仓库里没有的（最典型是 Windows 安装镜像），两条路任选：

1. **现成 ISO 直接放**：把手上已有的 ISO/IMG 文件放进镜像目录，回主界面添加；
2. **空白镜像 + 写入**：在应用里新建一个指定大小的空白 `.img`，回电脑用 Rufus、Windows 安装媒体创建工具这类软件把内容写进去。

工具和镜像的获取入口都整理在 [DriveDroid 使用指南](https://drivedroid.wxhp.skin/) 的下载页，需要的话从那里进。

## 四、放镜像前的两个注意

- **目录认准向导里指定的那个**：第二步选定的文件夹才是应用扫描的范围，镜像放别处主界面看不到；
- **分区格式决定单文件上限**：FAT32 分区上单个镜像不能超过 4GB（建空白镜像时界面会提示约 3999 MB），大镜像放进内部存储或 exFAT/NTFS 分区更稳。

镜像备好了却引导不出来？去 [引导失败的排查清单.md](引导失败的排查清单.md) 对照排查；还没跑通首次设置的话，先看 [手机当启动盘的完整教程.md](手机当启动盘的完整教程.md)。
