# 电脑启动时看不到手机挂的盘？按这张清单查

> 手机端挂载正常、电脑端就是找不到，或者引导到一半失败——本篇把这类问题按"手机端 → 电脑端 → 机型内核"的顺序列成清单，逐项对照即可定位。
> **相关文档**：[手机当启动盘的完整教程.md](手机当启动盘的完整教程.md) · [装系统与应急盘的镜像准备.md](装系统与应急盘的镜像准备.md)

---

引导失败的原因集中在少数几处：授权被拦、镜像没挂上、启动顺序不对、内核不支持。别急着刷机重装，按下面的顺序查，多数几分钟就能定位。

## 一、先看手机端

1. **授权真的拿到了吗？** 打开 SuperSU / Superuser 这类授权管理，看请求记录里有没有被拒绝的条目。向导停在第一步、或提示拿不到 Root 权限，基本都是授权管理"默默拒绝"造成的，把应用设为允许后重跑向导。
2. **镜像挂上了吗？** 主界面顶部会显示当前托管状态；还没挂载任何镜像时，电脑端自然什么都看不到。先在主界面把目标镜像挂载起来，再插线。
3. **挂载模式选对了吗？** 同一镜像可能提供 U 盘 / 光驱两种挂载方式，电脑端认哪种取决于机型内核，换一种模式再试是成本最低的排查动作。

## 二、再看电脑端

- **启动顺序**：进 BIOS/UEFI 把 USB 设备启动调到硬盘前面，保存重启；
- **插对接口**：部分机型的 USB 口直连关系不同，换一个口再试；
- **认盘不认引导**：电脑能识别到这块"U 盘"但启动菜单不出它，多半是镜像本身不可引导或模式不匹配，回到手机端换挂载模式。

每一步对应的界面与按钮位置，[DriveDroid 上手指南](https://drivedroid.wxhp.skin/) 里都有截图对照，排查时开着比对更直观。

## 三、机型与内核这一层

如果上面全部排除，问题大概率落在内核支持上：

- 仿真依赖内核的 Mass Storage gadget 支持，个别系统默认不编译这个模块（LineageOS 是常被提到的例子）；
- 能不能模拟 U 盘、能不能模拟光驱，随机型而定——设置向导的"检测 USB 系统"一步就是干这个的；
- 确实缺支持的，出路是刷带补丁的内核，或换集成了补丁的自定义 ROM，这一层操作风险高，动手前先备份。

## 四、两个已知的正常现象

- **拔线后手机 USB 异常**：部分机型退出仿真后 USB 功能要重启手机才恢复，属已知现象，操作结束前先在应用里正常卸载镜像能减少发生；
- **旧版本的识别问题**：识别失败在若干机型上有过集中反馈，新版本陆续修复过，版本太旧先升级再排查。

排查中确认手机端根本没跑通设置的，回 [手机当启动盘的完整教程.md](手机当启动盘的完整教程.md) 从头走一遍向导；怀疑镜像本身有问题的，看 [装系统与应急盘的镜像准备.md](装系统与应急盘的镜像准备.md) 的第四节。
