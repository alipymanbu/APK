# Flexcil 笔手势速查：划线、画圈、框选都是怎么用的

> 本篇把 Flexcil 的笔手势整理成一张速查表：想选中一段文字该画什么、想摘一张图该画什么、
> 笔迹画错了怎么删，对照着画一遍就熟。安装与导入 PDF 的部分见[安卓版下载安装步骤](安卓版下载安装步骤.md)；
> 摘抄进笔记之后怎么溯源，见[摘抄与参考链接用法](摘抄与参考链接用法.md)。

---

Flexcil 和一般 PDF 阅读工具最大的区别，就是把「选中」这件事从菜单里搬到了笔尖上：
先在笔工具栏最左侧切到**手势模式**，然后按下面的画法出手即可。

## 手势对照表

| 手势 | 怎么画 | 能做什么 |
| --- | --- | --- |
| 划线 | 在文字下面划一条线 | 选中划过的文字，弹出操作菜单 |
| 括号 | 把要选段落的起止两端连成括号 | 选中整段文字 |
| 小圈 | 围着单词画一个小圈 | 选中单个词 |
| 大圈 | 画一个大圈圈住目标区域 | 选中多行文字或图片；区域内已有批注时改为选中批注 |
| L 形 / 方框 | 画出 L 或矩形 | 框选一块区域，用来截图或摘抄，边缘可拖动微调 |
| 长按拖动 | 按住页面空白处拖动 | 同样能框选捕捉，手势、手写两种模式下都可用 |
| 折线 | 在要删的笔迹上来回画折线 | 删除折线范围内的批注与笔迹 |
| 两指滑动 | 左右或上下滑动 | 翻页；在设置里开启「单指滑动」后一根手指也行 |
| 双指开合 | 两指收拢或张开 | 缩放页面，安卓端最高能放到 1000% |
| 三指上划 | 三指从下往上推 | 呼出弹窗笔记；三指下滑关闭，开合调整弹窗大小 |
| 两指双击 | 两指同时双击页面 | 撤销；三指双击是重做 |

## 两个容易踩的点

- **画了没反应**：多半还在笔模式。批注和手势分属两种模式，点笔工具栏最左侧的图标切换后再画。
- **长按是万能兜底**：长按文字可选中并拖动扩展范围，按住空白处拖动能框图，两种模式下都生效，
  记不住手势时先用长按顶上。

手势练熟之后，配合弹窗笔记与拖拽摘抄，整条「读到记」的动线会顺很多，
完整用法梳理在 [Flexcil 使用介绍](https://flexcil.ggcd.store/) 里。
