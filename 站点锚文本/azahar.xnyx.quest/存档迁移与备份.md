# Azahar 存档迁移与备份

> 本篇讲 Azahar 的两套存档机制在哪、换机重装前怎么备份、以及从 Citra / Lime3DS 旧目录搬家的做法。安装相关见[安卓版下载安装步骤](安卓版下载安装步骤.md)。

## 两套存档，各自独立

- **游戏内存档**：游戏自己写的进度，落在模拟器数据目录的对应子文件夹里。
- **即时存档（save state）**：模拟器菜单里的存档点，把整个运行状态拍下来，与游戏内存档互不覆盖。

备份原则就一条：**重要进度两边各存一份**，只依赖任何一边都有翻车先例。

## 换机、重装、换形态前先备份

卸载应用可能把两套存档一起清掉，所以这几类操作之前，先备份整个数据目录：

1. Android 11 及以上系统的 `Android/data` 目录受系统限制，部分文件管理器看不到；用数据线连电脑（MTP 模式）能直接访问，整个拖出来一份即可。
2. 备份的不是某个文件，而是**整个数据目录**——存档、金手指、高清纹理、着色器缓存都在里面。
3. 商店版与直装包签名不同、不能覆盖安装，换形态就是「卸载重装」一趟，备份更要先行（原因见[安卓版下载安装步骤](安卓版下载安装步骤.md)）。

## 从 Citra / Lime3DS 搬旧存档

Azahar 沿用 Citra 系的数据结构，搬家就是搬文件夹：

| 文件夹 | 装着什么 |
| --- | --- |
| `sdmc` | 游戏存档（装过的游戏更新 / DLC 也在里面） |
| `cheats` | 金手指 |
| `load` | 高清纹理 |

把旧数据目录里的这几个文件夹原样复制进 Azahar 的数据目录，重启后存档就在。桌面版可以从菜单「File → Open Azahar Folder」直达；安卓版思路相同。搬之前把旧目录整个再备一份，搬错了随时退得回来。

## 搬完验证

重启应用（最好连后台一起划掉）后进游戏读一次档确认。游戏本身打不开的，先按[黑屏卡顿与性能设置](黑屏卡顿与性能设置.md)排查文件形态——存档没问题但游戏跑不起来，多半是转储未解密，与迁移无关。联机玩家换机后还要注意版本一致问题，见[安卓联机房间怎么开](安卓联机房间怎么开.md)。
