# Azahar 游戏文件格式与添加方法

> 本篇讲 Azahar 认哪些游戏文件格式、怎么把游戏加进列表，以及「扫不出来 / 打不开」时先查什么。安装环节的问题见[安卓版下载安装步骤](安卓版下载安装步骤.md)。

## 常见格式对照

| 扩展名 | 是什么 | 备注 |
| --- | --- | --- |
| `.cci` / `.3ds` | 卡带镜像 | 同一格式的两个名字；2120 起不再认 `.3ds` 后缀，改名 `.cci` 即可 |
| `.cia` | 安装型内容包 | 数字版游戏、DLC、系统内容常用 |
| `.cxi` / `.app` | 可执行内容 | 多见于系统程序或拆出的模块 |
| `.3dsx` / `.elf` | 自制程序 | 玩 homebrew 才会碰到 |

普通游戏不是 `.cci` 就是 `.cia`，放进游戏目录都能被扫到。

## 关键前提：文件要「已解密」

2120 起 Azahar 不再支持加密转储——这是它区别于旧 Citra 时代的最大口径变化：

- 没解密的游戏文件**扫不出来、进去黑屏或报解密错误**，都不是文件损坏；
- 放密钥文件救不了它，解密要在导出环节完成：从自己的卡带导出时选解密导出（dump decrypted）；
- 密钥与系统文件现在只服务另一摊事（系统内容、商店相关功能），需要时用 Artic 工具从自己的真机提取，放进数据目录的 `sysdata/`。

一句话：**转储本身就是解密好的，Azahar 才认。**

## 把游戏加进列表

1. 在手机存储里建一个固定文件夹（比如 `3DSgames`），游戏文件都放进去，别散落在下载目录各处——目录乱是「列表里找不到游戏」最常见的起因。
2. 首次启动时会提示选游戏文件夹；跳过了也没关系，之后在列表界面再添加。
3. 等扫描完成，游戏逐个以图标和名称出现在列表里。
4. 点游戏即运行；第一次进某个游戏时着色器在编译，开头卡顿属正常（卡顿对策见[黑屏卡顿与性能设置](黑屏卡顿与性能设置.md)）。

## 先查兼容性，再折腾设置

每个游戏在模拟器上的状态不一样，上游项目维护着一份兼容性列表，搜游戏名能看到别人报告的运行情况。列表里标着「崩溃 / 无法运行」的游戏，怎么调设置都救不回来，别浪费时间反复重装。
