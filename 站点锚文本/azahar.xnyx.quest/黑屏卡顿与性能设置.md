# Azahar 黑屏卡顿与性能设置

> 本篇讲 Azahar 安卓端两类高频问题的排查：游戏黑屏打不开、玩起来卡顿掉帧，以及设置里真正有用的几个旋钮。文件格式问题先看[游戏文件格式与添加方法](游戏文件格式与添加方法.md)。

## 黑屏先分两层查

**第一层：文件形态。** 2120 起不再支持加密转储，未解密的文件扫不出来或进去黑屏，怎么调设置都救不了——重新解密导出才是正路。`.3ds` 后缀的老文件改成 `.cci` 再扫一次。系统内容、商店相关功能报错的，才轮到密钥文件（放数据目录 `sysdata/`）。

**第二层：图形后端。** 排除文件问题后仍黑屏、闪退的，在设置里把图形 API 在 Vulkan 与 OpenGL ES 之间切一次对照——不少崩溃只发生在其中一种后端上。

还有一层兜底：上游维护着兼容性列表，个别游戏本身就跑不起来，先查状态再动手，别在不兼容的作品上反复重装。

## 卡顿按这个顺序调

1. **降内部分辨率**。3DS 原生上屏只有 400×240，倍数越高画面越锐、GPU 负担越重；卡顿先降，流畅有余再加，加到掉帧临界点为止。超出手机物理像素的倍数没有收益。
2. **换图形 API**。Vulkan 与 OpenGL ES 来回试，同一游戏在两种后端下表现可能差很多，逐游戏定。
3. **开省力开关**。异步着色器编译能明显减少游戏中途「突然卡一下」；ASTC 解码加速在支持的设备上建议常开；「禁用右眼渲染」按更新说明部分游戏性能提升可达 50%，代价是个别画面异常，逐游戏试。
4. **防发热降频**。越玩越卡多半是机身热了：摘壳、别边充边玩、清后台。

两个常见误判：**开局卡 ≠ 全程卡**（着色器编译，缓存建立后就顺了）；**换设置后开局场景顺 ≠ 全程顺**（进一段战斗或剧情再下结论）。
