# Azahar 安卓联机房间怎么开

> 本篇讲 Azahar 的多人联机：哪个版本才有安卓房间、公开房间与私密房间的差别、公开房间列表为什么要自己配地址、联机前要确认什么。装机步骤见[安卓版下载安装步骤](安卓版下载安装步骤.md)。

## 先对版本：安卓房间是 2126 起的功能

安卓版的多人房间系统从 **2126.0** 开始加入，与桌面版对齐。更早的版本线上（如 2122-alpha）没有这个功能，想联机先升级到 2126 及以上。桌面版的多人房间则是 Citra 血统里一直延续下来的老功能。

## 房间怎么用

进入多人菜单后有三条路：

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| 搜公开房间 | 浏览列表选一个加入 | 蹭陌生人的局 |
| 建私密房间 | 自己开房，把房间信息发给朋友 | 固定队友开黑 |
| 直连 | 直接填主机 IP 与端口进入 | 有自建服务器 |

房间内自带文字聊天。硬限制有两条：连不上真实的 3DS 主机（模拟器之间互连而已），也不支持附近设备无线直连；网络条件只有一种——**同一房间的所有人连同一个 Wi-Fi 或热点**。

## 公开房间列表要自己配地址

时至今日仍没有公共的房间列表服务，想看到公开房间得在配置里填一个第三方 web API 地址。社区流传的地址多是个人或小团体搭的，意味着：

- **不要在任何这类服务里输入账号、密码或任何凭据**；
- 这些地址多为明文 HTTP，可用性随时归零，失效了不是你的问题；
- 流传渠道以论坛帖子为主，用前自行甄别。

最稳的做法是绕开公开列表：朋友里一个人建私密房间，把直连信息发出去，全程不经过第三方。

## 联机前确认两件事

1. **游戏本身支持无线联机**才有后面的事，先到兼容性列表查状态（查法见[游戏文件格式与添加方法](游戏文件格式与添加方法.md)）。
2. **同一房间用同一版本的游戏**，版本或区域不一致会有人进不了房。

进房后游戏异常的，先看[黑屏卡顿与性能设置](黑屏卡顿与性能设置.md)排除本机问题，再怀疑网络。还没装模拟器的，[azahar 安卓版介绍站](https://azahar.xnyx.quest/)有安装全流程；存档怎么带去新设备见[存档迁移与备份](存档迁移与备份.md)。
