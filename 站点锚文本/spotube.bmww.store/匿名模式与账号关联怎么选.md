# Spotube 匿名模式与账号关联怎么选？两种用法对比

> 首次启动 Spotube 时引导页会让二选一：匿名浏览，还是关联 Spotify 账号。这篇短文把两种方式各自能做什么、什么时候该换，摆在一起讲清楚。

---

Spotube 不强制登录，这是它和多数音乐应用不一样的地方。启动引导页给的两条路，对应的是两种完全不同的数据存放逻辑：匿名模式的一切记录只存在本机，账号模式则把歌单与收藏托管给 Spotify 账号。无论选哪条路开始，都可以在 [Spotube 介绍站](https://spotube.bmww.store/)先看看界面实拍与功能清单，再决定怎么配置。

## 两种方式对照

| | 匿名浏览 | 关联 Spotify 账号 |
| --- | --- | --- |
| 需要注册 | 不需要 | 要有一个 Spotify 账号 |
| 能做什么 | 搜索、播放、收藏、下载全部可用 | 在基本功能之上，同步歌单与关注内容 |
| 数据存哪 | 只在本机 | 跟随 Spotify 账号 |
| 换设备后 | 本地记录不会跟过去 | 歌单与收藏自动恢复 |

## 选法建议

- **暂时注册不了 Spotify、或不想绑账号**：直接匿名进，日常听歌完全够用；
- **本来就有 Spotify 账号、歌单攒了不少**：走关联，歌单免于重新手工建一遍；
- **拿不准**：先匿名用着，等确认要长期留收藏了再在设置里关联，随时可切。

关联走的是 Spotify 的授权流程：应用跳到授权页，登录并同意后跳回，歌单就会加载进来。普通账号即可，不需要 Premium 订阅。有一点要注意——授权页所在的账号服务在部分网络环境下不是直连可达，打不开时先换网络再试，这不是应用本身的问题。

## 匿名模式的边界

匿名用得越久，攒下的收藏、自建歌单就越多，而这些数据只在本机：卸载重装或换手机，它们不会跟过去。所以比较稳妥的节奏是——匿名期把工具摸熟，确认合口味后尽早关联账号，把收藏的「存档位置」从单机挪到账号上。

装好后的插件配置与语言设置属于另一条线，与登录方式互不影响，具体见 [搜索无结果与插件安装配置](搜索无结果与插件安装配置.md)；还没安装的读者从 [安卓安装包下载与安装步骤](安卓安装包下载与安装步骤.md)开始即可。
