# Spotube 搜索没结果？插件安装与数据源配置方法

> 装好 Spotube 后搜索一片空白，多数情况不是故障，而是 5.0 版本起曲库数据改由插件提供、还没装插件。这篇短文讲清插件机制与配置步骤。

---

从旧版升到 5.0 或全新安装 Spotube 的用户，几乎都会在同一件事上愣一下：搜索框输入歌名，结果空空如也。原因写在 5.0 的架构调整里——曲目搜索、歌手专辑、歌单这些元数据不再内置固定来源，改由你自己安装的插件提供，项目对此的说法是「自带音乐元数据」。想了解这个应用本身的定位与获取方式，可以先看 [Spotube 介绍站](https://spotube.bmww.store/)，本篇只解决「装好之后搜不到」这一件事。

## 先装项目自带的 MusicBrainz 插件

MusicBrainz 是社区维护的开放音乐元数据库，Spotube 5.0 发布时同步提供的两个插件之一。安装路径：

1. 打开设置，进入 Plugins（插件）区域；
2. 浏览已收录的插件仓库，找到 MusicBrainz；
3. 安装并启用，回到搜索页再试。

装好后搜索、曲库浏览就有数据来源了。另一个同场提供的插件是 ListenBrainz，功能是把你的播放记录同步到开放的听歌统计服务，属于可选增强，不装不影响听歌。插件仓库托管在 GitHub 与 Codeberg 上，列表加载不出来通常是网络可达性问题，不是应用坏了。

## 插件与登录是两条独立的线

账号关联解决「你的歌单收藏从哪来」，插件解决「曲库信息从哪来」，两者互不依赖：匿名访客一样可以装插件，关联了账号也照样要装插件才有搜索结果。把这两件事分开理解，配置时就不会互相等来等去。

## 装了插件还是搜不到

按这个顺序排查：

- **确认版本**：设置里看版本号，4.x 及更早版本已整体不可用，换 5.x 的安装包再来；
- **确认插件已启用**：插件列表里 MusicBrainz 应处于启用状态，停用状态等于没装；
- **换网络再试**：搜索请求要到达数据源，部分网络环境访问受限；
- **停用第三方插件对照**：装过其他来源的插件时，先只留 MusicBrainz，判断问题是出在插件还是网络。

搜索恢复之后，日常播放、歌词、下载这些主线操作就可以慢慢摸了；首次启动时在匿名与账号之间的选择还没想好的，参考 [匿名模式与账号关联怎么选](匿名模式与账号关联怎么选.md)。需要重装或还没装上的，从 [安卓安装包下载与安装步骤](安卓安装包下载与安装步骤.md)开始。
