# Mixkit 安卓手机下载安装流程与问题处理

> 安装包从哪拿、怎么装进手机、权限怎么给、装不上怎么对号入座——把 Mixkit（MIX滤镜大师）「装上、装对」一件事讲完。

## 一、安装包从哪拿

推荐路径是走网盘：打开 [Mixkit 介绍站](https://mixkit.wxhp.skin/)的下载页，点「获取安装文件资源」进入夸克网盘分享，**转存到自己名下再下载**——转存后链接长期有效，随取随下。

安装包约 115 MB（收录版本 4.9.63），建议 Wi-Fi 环境下载。这款应用本身由成都品果科技开发、2014 年起公开上架，不建议下来路不明的改包：多一层风险，还可能因签名不同和已装版本互相冲突。

## 二、四步装进手机

1. **打开网盘链接**：进入分享页，把安装文件资源转存到自己网盘；
2. **下载到手机**：在夸克网盘客户端里找到文件，下载到手机存储；
3. **点开安装**：在下载列表点 APK 开始安装。系统提示「禁止安装未知来源应用」时，按提示去「设置 → 安全 / 隐私 → 安装未知应用」里给网盘客户端放开允许，再回来继续（不同品牌手机入口略有差异）；
4. **打开应用**：安装完成点打开，从相册选一张照片进入编辑。桌面图标显示 **MIX** 就说明装对了。

## 三、首次打开的权限

- **照片 / 存储权限——必须给**：不给读不到相册。当时拒绝了可事后去「设置 → 应用 → MIX → 权限」补开，设为「始终允许」最省事；
- **网络权限——按需给**：云备份自定义滤镜、逛社区和学苑要用；只想本地修图的话，不给网也能用。

## 四、装不上？对号这三件事

**提示「应用未安装」**：按可能性从高到低查——① 存储不足，解包安装要占更多空间，先清几 GB 余量；② 包没下完整，删掉重新下载；③ 系统版本太低，老机型安卓版本不够会直接装不上。

**提示签名冲突，或要求先卸载再装**：手机里已有一个别的来源装过的同包名版本，安卓不允许两个不同签名的同包名应用共存——先卸旧再装新。卸载前留意：本地自定义滤镜卸载即丢，只有登录过、云备份生效过的才能在重装后用同一账号找回。

**装好了但相册是空的**：存储或照片权限没给，去「设置 → 应用 → MIX → 权限」把「存储 / 照片和视频」设为允许即可。

## 五、换版本的两个提醒

- 同一路径升级最稳：商店装的就从商店更新，数据与滤镜都在；
- 跨来源换版本（网盘装的换商店的，或反过来）可能遇到签名冲突，得先卸载——卸载前把自定义滤镜的云备份确认好。
