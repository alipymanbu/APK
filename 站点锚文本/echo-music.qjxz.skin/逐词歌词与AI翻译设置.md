# 逐词歌词与AI翻译设置

> Echo Music 的歌词能跟着旋律逐词点亮，外语歌还能翻出中文对照。这篇讲清动效怎么换、歌词源怎么挑、翻译接口怎么配。
> **相关文章**：[离线下载与后台播放](离线下载与后台播放.md) · [安卓版安装与常见拦截处理](安卓版安装与常见拦截处理.md)

## 一、进入全屏歌词

播放任意一首歌时，在播放页点歌词区域（或上滑）就能进入全屏歌词视图。这里是它观感最突出的地方：唱到哪个词，哪个词就亮，一行之内按字推进。

几个可调的地方：

- **动画样式**：滚动、渐变等几套歌词动效可以切换，菜单名字随版本略有出入，找不到就在设置页顶部的搜索框里输关键词定位。
- **逐词与逐行**：不是每首歌都带逐词时间轴，没有时间轴的歌会自动退回逐行滚动——这是正常表现，不是故障。
- **Lyrics+ 歌词源**：覆盖面比早先的来源更全。整屏没有歌词、或歌词和演唱对不上拍时，先换到这个源试试。

## 二、外语歌词翻成中文

听非中文歌时，可以给歌词加一栏中文翻译。这是个可选能力，需要先在 **设置 → AI Settings** 里配置翻译接口：

| 配置项 | 填法 |
| --- | --- |
| Provider（提供方） | 默认 OpenRouter，也可换 ChatGPT、Gemini 或 Custom |
| API Key | 到所选服务商处注册生成后粘进来 |
| Base URL | 仅 Provider 选 Custom 时填写 |

几点提醒：

- 翻译要联网调用接口，多数服务有入门额度，用完需要自行处理；不配置翻译不影响其它任何功能，歌词照常显示原文。
- Key 是自己的账号凭据，不要截图发到公开场合。
- 翻译栏是空的时，先回这一节确认接口配置没漏项。

## 三、歌词相关的其它表现

- 歌词与「一起听」互不影响：一起听同步的是双方播放进度，歌词仍各自按自己的屏幕滚动。
- 本地音乐文件的歌词同样走这套显示逻辑，前提是能匹配到对应的歌词数据。

功能全貌与安装包的获取入口，见 [Echo Music 介绍站](https://echo-music.qjxz.skin/)；装好后遇到播放类问题，先看[离线下载与后台播放](离线下载与后台播放.md)里的权限部分。
