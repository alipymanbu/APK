# astrbot 手机上怎么部署

> AstrBot 本体是个部署在电脑或服务器上的开源聊天机器人框架，手机上想玩就得靠社区封装的安卓 App。本篇讲清这条「手机部署」路线的完整链路：装什么、初始化时发生什么、装完怎么让它开口。
> 相关文章：[astrbot 初始化失败怎么办](astrbot初始化失败怎么办.md) · [astrbot 接入哪家大模型](astrbot接入哪家大模型.md)

## 一、手机部署的是什么

安卓 App 把三样东西打进一个安装包（约 87 MB）：AstrBot 框架核心、NapCatQQ 协议适配器、一套 Ubuntu 容器运行环境。装好后，手机就是机器人的运行主机——QQ 号变成能自动回消息的机器人账号，全程不需要电脑、不碰命令行。

要接受两个前提：

- **只支持 QQ 个人账号**：微信、Telegram、钉钉这些平台接不了，那是电脑/服务器部署原版框架才有的能力；
- **账号有风控可能**：第三方协议接入会被 QQ 运营方按「外挂软件」监测，别拿主力号，用备用小号。

## 二、五个环节

1. **拿到安装包**：安装包放在网盘分享里，转存到自己账户再下载，[astrbot 安卓 App 介绍站](https://astrbot.yoan.quest/) 的下载页有现成入口与逐步说明；
2. **允许安装**：点开 APK，系统提示「未知来源」时允许该来源安装；
3. **自动初始化**：首次启动自动下载运行环境并部署，点屏幕可切到日志页看进度；用家用 Wi-Fi 或流量，别锁屏太久；
4. **给通知权限**：机器人靠一条常驻通知保活，权限必须给，装好后这条通知也不能手动清；
5. **扫码配模型**：初始化完弹出 QQ 登录二维码，手机 QQ 扫码登录；进管理面板填一把大模型 API 密钥、重启，机器人开始接活。

## 三、装完验证通没通

用另一个 QQ 号给机器人发条消息，能自动回就是整条链路都通了。不回先按三件事排查：常驻通知还在不在、这个号是不是刚在电脑 QQ 登录过（会互挤下线）、管理面板日志页有没有报错。更细的症状对照见 [astrbot 初始化失败怎么办](astrbot初始化失败怎么办.md)。

## 四、什么时候该换电脑部署

要接多平台、跑代码沙箱、让机器人长期服务一个群——这些是服务器原版的能力，App 版默认给不了。两条路线的取舍在站内有对照表，玩熟 App 之后想迁移，模型、插件、人设这些概念完全通用。
