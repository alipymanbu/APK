# astrbot 初始化失败怎么办

> AstrBot 安卓 App 的初始化（下载容器环境、部署核心、装协议适配器）是全自动的，也因此「看不见发生了什么」。本篇按症状给排查顺序，多数情况不用重装就能解决。
> 相关文章：[astrbot 手机上怎么部署](astrbot手机上怎么部署.md) · [astrbot 接入哪家大模型](astrbot接入哪家大模型.md)

## 一、总原则：先切到日志页

所有排查从同一个动作开始：**点一下屏幕**，从白色进度条切到模拟终端日志页，看它到底卡在哪一行——下载不动、报错、还是在慢慢装。对症才好下药。

## 二、症状对照

| 症状 | 多半是 | 处理 |
| --- | --- | --- |
| 白色进度条长时间不动 | 下载被网络卡住 | 换家用 Wi-Fi 或手机流量；切日志页确认卡点 |
| napcat 一步卡住或报错 | 耗时长、对网络敏感 | 关掉 App 重开，会从断点继续装 |
| 反复重启仍失败 | 本地环境包损坏 | 清除应用数据，重新初始化 |
| 终端出现 `dpkg was interrupted` | 系统软件包安装被中断 | 别照提示修，清数据重来最干净 |
| 初始化完成但 QQ 二维码不弹 | 协议组件没装利索 | 重启 App 多数自愈，反复出现就清数据 |
| 装好了突然不回消息 | 常驻通知被清 / 号在电脑端被登录 | 重开 App；电脑 QQ 退出该号再重扫 |

## 三、四条预防

- **网络**：初始化只用家用 Wi-Fi 或手机流量，校园网、公司内网、公共 Wi-Fi 拦大文件下载，是卡进度条的头号原因；
- **别锁屏**：初始化期间保持屏幕常亮盯着日志，完成后就没这么多讲究；
- **通知权限**：点过拒绝的去系统设置 → 应用管理 → AstrBot → 通知，手动打开；
- **别让系统杀后台**：把 App 加进电池白名单 / 允许后台运行，不然息屏久了服务可能被掐。

## 四、清数据的代价

「清除应用数据」会把容器环境和配置全部清空，相当于重新初始化：填过的 API 密钥、改过的密码、装过的插件都要重配。所以它是多次重启无效后的最终手段，不是第一反应。

## 五、还不行

把日志页的报错截图记下来（关键词盯 `error`、`failed`、`timeout` 出现的位置），到项目的社区群或文档里对照排查。装机环节没走完的，先回 [astrbot 手机上怎么部署](astrbot手机上怎么部署.md) 把五个环节过一遍；[astrbot 安卓 App 介绍站](https://astrbot.yoan.quest/download.html) 的下载页也整理了同样一份排查清单。
