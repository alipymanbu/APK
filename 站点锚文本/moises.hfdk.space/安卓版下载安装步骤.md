# Moises 安卓版下载安装步骤与装不上的处理

> 本篇整理 Moises 安卓端从拿到安装包到装好登录的全过程：怎么转存下载、安装权限在哪给、装不上时按哪几条排查。
> **相关文档**：[人声分离伴奏提取教程.md](人声分离伴奏提取教程.md) · [变速变调与和弦识别练习法.md](变速变调与和弦识别练习法.md)

## 一、安装前确认两件事

1. **系统版本**：建议安卓 9 及以上。查法：设置 → 关于手机 → Android 版本。
2. **存储空间**：安装包 57 MB 上下，留出几百 MB 空间比较稳妥，后续处理生成的音轨文件还会额外占用。

安装包走网盘分发，入口在 [Moises 安卓版下载与安装](https://moises.hfdk.space/download.html) 页面，打开后按按钮进分享页即可。

## 二、安装步骤

1. **转存**：打开分享页，点「保存到网盘」把安装包转到自己账号下（不转存直接下载可能受限）；
2. **下载**：打开夸克网盘 App，找到刚转存的 APK，点下载等进度走完；
3. **给权限**：点开 APK，系统提示「未知来源应用」，在弹窗里给本次授权。部分品牌要对下载工具开「允许安装应用」：小米在设置 → 更多设置 → 开发者选项；华为 / OPPO / vivo 一般安装弹窗里直接给；
4. **安装**：点「安装」等几十秒，完成后点「打开」。

## 三、第一次打开：登录别踩坑

首次启动要注册或登录，Google、Apple 或邮箱任选。**关键只有一条：以后每次都用同一种方式登录。** 邮箱和第三方登录会被认成两个账号，换设备时曲目「消失」多半是这个原因，换回原来的登录方式一般能找回来。

登录后应用会请求存储权限，建议允许 —— 不给的话，后续导入本地音频会受限。

## 四、装不上按这三条排查

- **提示安装被阻止 / 点安装没反应**：到系统设置里找到网盘 App，打开「允许安装未知应用」，回通知栏重新点开 APK；
- **解析包错误 / 装到一半失败**：安装包八成没下完整，删掉重下再装；
- **打开就提示不支持**：系统版本低于要求，见第一节，升级系统或换设备。

## 五、装好之后

先拿免费额度把流程走一遍：导一首歌 → 拆轨 → 调推子 → 导出，确认分离效果符合预期。具体玩法见 [人声分离伴奏提取教程.md](人声分离伴奏提取教程.md)；变速、变调、节拍器这些练习向功能见 [变速变调与和弦识别练习法.md](变速变调与和弦识别练习法.md)。
