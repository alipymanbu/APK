# Okta Verify 换手机后如何重新绑定

换新手机、卸载重装、还原备份数据之后，很多人发现 Okta Verify 里的账户消失了、登录时验证不通过。本篇讲清楚为什么会这样，以及重新绑定的两条路径。

还没装应用的话，可以先看 [Okta Verify 使用说明站](https://okta-verify.ggcd.uno/)的安装与扫码注册部分。

## 为什么绑定会失效

Okta Verify 的账户绑定跟着设备走，而不只是跟着账号走。以下几种常见操作都可能断开绑定：

- 卸载后重新安装应用；
- 换新手机（旧机数据未提前迁移验证器）；
- 用系统自带或第三方工具做数据迁移、还原；
- 手机恢复出厂设置；
- 部分手机清理类工具清掉了应用数据。

绑定一旦断开，应用里的账户条目就不存在了，登录组织账号时自然无法完成验证。

## 路径一：自助重置（账号还登得进去时）

如果还能用密码加其他验证方式登录组织账号：

1. 登录后进入账号的「设置 / Settings」页，选择「编辑个人资料」；
2. 按提示完成密码与已有验证方式的确认；
3. 在「额外验证 / Extra Verification」区找到 Okta Verify，先「移除」；
4. 再点「设置 / Set up」，按页面提示用新手机重新扫码注册。

## 路径二：联系组织 IT 管理员（登不进去时）

新手机上没有任何可用的验证方式、登录页走不下去时，唯一稳妥的出路是联系所在组织或学校的 IT 服务台：

- 说明情况，请管理员重置多因素验证；
- 重置后下次登录会重新出现设置向导，用新手机扫码完成注册；
- 手机丢失的情况也应走这条路，并提醒管理员及时重置，避免他人用你的设备验证。

## 重绑之后

重新扫码注册完成后，应用里会出现账户条目并恢复六位码显示。建议顺手确认两件事：推送通知权限已打开；知道自己还可以用离线六位码应对没网的场合。
