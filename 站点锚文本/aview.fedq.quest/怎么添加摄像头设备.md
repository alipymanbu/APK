# aview 怎么添加摄像头设备

> 本篇讲把摄像头、录像机加进 aview 手机端的各种方式：扫码、手动输入设备 ID、局域网搜索、热点直连，以及 NVR 录像机的接入。设备加好后的画面操作见 [远程看画面的日常用法](远程看画面的日常用法.md)；还没装 App 的先看 [安卓手机端怎么装](安卓手机端怎么装.md)。

## 加设备前先做两件事

1. **给设备通电**：网线 / PoE 款通电后等约 5 分钟（等远程连接就绪）；纯 WiFi 款等约 1 分钟（等设备热点出现）。
2. **手机连上 WiFi**：首次添加要求手机与设备处于同一个局域网。多数摄像头只认 2.4GHz 频段，双频路由器先把手机切到 2.4GHz 那一路。

另外，配网过程要扫二维码、要切 WiFi，记得把 App 的**相机**与**位置/WiFi**权限都给到，权限被拒是「扫不出、搜不到」的常见原因。

## 方式一：扫码添加（最常用)

1. 打开 App，进「设备」页，点右上角「+」。
2. 把摄像头底座或机身上的设备二维码放进取景框。
3. 读出设备信息后按提示继续，给设备起个名字（「客厅」「店门口」）。
4. 等连接完成的提示，画面出来即成功。

## 方式二：手动输入设备 ID

二维码磨损、贴纸脱落、二手购入的设备走这条：扫码界面里选「找不到二维码」的手动入口，填机身上那条 **37 位设备 ID**（用任意扫码工具扫原二维码也能读出来；带网页管理端的设备可在「配置 → 基本设置」里查到），再按引导让设备进入配对状态——一般是断电再通电，或长按复位键听提示音。

## 方式三：局域网搜索

设备与手机在同一 WiFi 下时，添加页会提供局域网/自动搜索：点「+」后选搜索方式，App 列出当前网段内处于配对状态的设备，选中绑定即可。设备多的时候按昵称过滤，能快速定位刚加的那台。

## 方式四：热点直连（无网也能看）

对支持的热点枪机类设备，可以不看路由器直接看画面：

1. 手机 WiFi 设置里连接设备发出的热点（名称形如 `HSIPC-XXXXXX`，默认密码常见为 `12345678`，以机身标注为准）。
2. 回到 App 即可看到这台设备的实时画面。
3. 直连模式下手机断了原来的 WiFi，**不能同时上外网**；要远程观看还得把设备接回路由器。

注意两点：设备通电后约 **15 分钟**内要完成配对，超时就断电重启重新计时；这个模式适合新装没布网线时先验货、或临时在无网环境查看。

## NVR 录像机怎么加

1. 用网线把录像机网口与路由器直连，确保已接入外网。
2. App 登录账号，添加设备时选 NVR，扫描或手动录入机身上的设备信息。
3. 录像机侧完成通道对码（套装出厂一般已配好），按说明书操作。
4. 添加成功后逐通道看画面，也支持多画面同看。

## 配不上时的快速排查

按顺序过一遍，多数问题在前两步就能定位：

1. 指示灯不亮 → 电源没插好，插好等一分钟。
2. 刚换过路由器 / 改过 WiFi 密码 → 设备还揣着旧网络凭据，需要复位重新配网。
3. 手机连的是访客网络或 5GHz → 切回与设备同频段的 WiFi 再试。
4. 路由器开了 AP 隔离 → 关掉后再搜。
5. 以上都排过仍失败 → 断电 10 秒重启设备，重新走一遍扫码流程。
