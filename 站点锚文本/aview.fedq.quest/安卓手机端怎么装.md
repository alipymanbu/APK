# aview 安卓手机端怎么装

> 本篇讲安卓手机从拿到安装包到登录出画面的完整步骤，以及安装环节真会挡路的几个问题。装好之后先去 [怎么添加摄像头设备](怎么添加摄像头设备.md) 把摄像头加进来；功能速览在 [远程看画面的日常用法](远程看画面的日常用法.md)。

## 装之前确认三件事

| 检查项 | 要求 |
| --- | --- |
| 手机系统 | 安卓 5.2 及以上（以安装时实际校验为准） |
| 存储空间 | 至少留 300MB（安装包约 121MB，装完还要写数据） |
| 网络 | WiFi 或流量均可，注册登录需要联网 |

## 安装四步

1. **打开分享入口**：到 [aview 随身看](https://aview.fedq.quest/) 站点的下载页，点开网盘资源入口（站内网盘链接集中在一处，照着点即可）。
2. **转存并下载**：把安装包转存到自己网盘，再用手机网盘客户端下载到本机存储。
3. **允许安装**：点开 APK，系统提示「未知来源」时，在弹窗里允许该来源安装（不同品牌叫法略有差异，一般在安装弹窗里直接授权），再点安装等进度走完。
4. **登录加设备**：注册或登录账号，首次会请求存储、通知等权限，建议都允许——通知权限关了，报警推送就收不到。

## 安装路上的三个坎

### 解析包出现错误

多半是安装包没下载完整：删掉重下，核对体积约 121MB 再装。存储空间不足也会以同样报错中断，先清空间。

### 系统拦截不让装

这是安卓对非应用市场安装包的常规确认：到设置里找到「安装未知应用」，给下载时用的那个 App（网盘客户端或浏览器）授权即可。

### 提示与已有版本冲突

先卸载旧版再装。卸载不会丢设备——设备绑定在账号上，用同一账号登录后列表会自动回来。

## 装完第一件事

账号就绪后把摄像头加进来，不加设备主界面是空的。配网四条路径（扫码 / 手动 ID / 局域网搜索 / 热点直连）的完整流程见 [怎么添加摄像头设备](怎么添加摄像头设备.md)，加好就能看实时画面了。
