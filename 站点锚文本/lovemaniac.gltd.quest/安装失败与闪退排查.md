# LoveManiac 安装失败与闪退排查

> 本篇收集 LoveManiac 装不上、打不开、玩着玩着卡死这类高频问题的排查顺序，按「先试什么」排列。
> **相关文档**：[玩法分支与弹幕躲避要点](玩法分支与弹幕躲避要点.md) · [版本更新与存档注意事项](版本更新与存档注意事项.md)

---

## 一、装不上：权限与包完整性

按顺序排查：

1. **没给安装权限**：设置 → 安全（或「隐私保护 / 应用安装」）→ 允许「安装未知应用」；小米、华为等机型会在点 APK 时弹窗单独询问，当场允许即可；
2. **包不完整**：提示「解析错误 / 应用未安装」多半是下载中断导致的，删掉重新下载一次；
3. **后缀被改**：确认文件名以 `.apk` 结尾，有的下载通道会在文件名后面带一串参数；
4. **空间不足**：安装需要临时空间，89MB 的包建议预留 500MB 以上。

安装界面的包名应为 `com.teamnebula.lovemaniac`，对不上就取消安装——来路不明的同名包常被换了内容。同理，别碰来源不明的「汉化版」：那类第三方改动包可能被植入额外代码，介意就先用原版英文。

## 二、装上了但打不开 / 闪退

- **系统版本过低**：最低要求 Android 7.0，再低的机型大概率跑不起来；
- **权限没给全**：存储权限被拒会读不到资源直接退出，去应用信息里把权限打开再进；
- **首次启动慢**：首启要加载大量资源，等十几秒再操作，别连点退出；
- **架构不匹配**：极少数老 32 位机型装 64 位包会闪退，需要换对应构建。

## 三、玩着玩着卡住 / 报错

- **某场剧情走不动**：走到树旁拿到蛋后走不动不是死机，按一次确认键（手机上对应确认按钮）就继续；
- **战斗中不能移动**：0.3.3 的已知 bug，0.3.4_2 才修，只能升级解决；
- **「Array buffer allocation failed」类报错**：内存分配失败，关掉后台应用释放内存再进；
- **弹幕关过不去**：这不是故障，是难度本身——换用摇杆控件、贴着方框边缘走会好一些（见 [玩法分支与弹幕躲避要点](玩法分支与弹幕躲避要点.md)）。

## 四、虚拟按键失灵

先点一下屏幕空白处让控件重新获得焦点；不行就在设置里把方向键切成摇杆（或反过来）；再不行重启游戏，临时性失灵基本都能恢复。对话推进尽量点对话框或选项本身，别点画面空白处——点画面可能直接结束当前场景。

---

这些排查都做完仍卡住的话，多半是版本本身的问题——对照 [版本更新与存档注意事项](版本更新与存档注意事项.md) 换个版本试试；游戏的实机画面与安装步骤，也可以到 [lovemaniac 介绍站](https://lovemaniac.gltd.quest/) 直接查看。
