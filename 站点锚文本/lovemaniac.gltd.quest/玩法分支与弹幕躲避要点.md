# LoveManiac 玩法分支与弹幕躲避要点

> 本篇讲 LoveManiac 的玩法结构：剧情与战斗两条线怎么交替、分支从哪来、手机和电脑分别怎么操作。
> **相关文档**：[安装失败与闪退排查](安装失败与闪退排查.md) · [版本更新与存档注意事项](版本更新与存档注意事项.md)

## 一、两条线交替推进

LoveManiac 的推进方式是剧情与战斗交替：

1. **剧情线**：在像素场景里走动、与角色交谈，用点按推进对白；不同的对话与 ACT 选项会把路线引向不同方向；
2. **战斗线**：进入回合制战斗后，屏幕中央方框里的红心就是你。敌方回合拖动红心躲避飞刀、骨头类弹幕，轮到你再决定攻击还是 ACT。

它不是吃数值的游戏——弹幕段输赢几乎全看走位。新手在前几场战斗里多死几次很正常，把「贴着方框边缘走、预判弹幕缝隙」练熟就顺了。

## 二、分支与多周目

开发者给这款游戏准备了多条路线，项目简介的说法是「很多条路线最后是同一个结果，Chara 要跟你做个交易」。也就是说：

- 一周目基本看不全内容，ACT 与对话的不同选择会导向不同分支；
- 二周目有变体场景，重入时留意与第一轮不一样的细节；
- 游戏没有难度选项（玩家在评论区求过多次，截至 0.3.5 仍未加入），遇到难的弹幕关只能硬练。

想先看实机画面再决定要不要上手，可以逛逛 [lovemaniac 介绍站](https://lovemaniac.gltd.quest/)，那里把四张实机截图和玩法要点摆在了一页里。

## 三、手机端操作

安卓版提供两套触屏控件（据玩家反馈整理）：

- **虚拟方向键 / 摇杆**：可在设置里切换，摇杆在部分弹幕段更顺手；
- **点按**：对白与菜单用点按推进，战斗里部分场景直接用手指拖动红心。

虚拟按键偶尔会「失灵不动」，按顺序试：点一下屏幕空白处让控件重新获得焦点 → 换一套控件 → 重启游戏。另外对话中点画面空白处可能直接跳过当前场景，推进对白尽量点对话框或选项本身。

## 四、电脑端操作

Windows / Linux 版是键盘操作：方向键移动，`Z` / `Enter` 确认，`X` / `Shift` 取消——这是 Undertale 系同人最通用的键位惯例。键位暂不支持自定义；个别键没反应时，先确认输入法处于英文状态。

## 五、两个与版本有关的体验点

- **过场动画**：0.3.3 里跳不过，0.3.4 起才支持跳过——反复刷开场时会比较磨人；
- **战斗中失去移动控制**：这个 bug 在 0.3.4_2 才修复，0.3.3 里遇到只能升级解决。

装不上、闪退之类的故障不在本篇范围内，去 [安装失败与闪退排查](安装失败与闪退排查.md) 对照处理；发版节奏与各版差异见 [版本更新与存档注意事项](版本更新与存档注意事项.md)。
