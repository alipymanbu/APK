# LoveManiac 版本更新与存档注意事项

> 本篇讲 Team Nebula 的发版节奏、0.2 到 0.3.5 各版大致变化，以及跨版本更新时存档可能出的问题。
> **相关文档**：[玩法分支与弹幕躲避要点](玩法分支与弹幕躲避要点.md) · [安装失败与闪退排查](安装失败与闪退排查.md)

## 一、发版节奏：先赞助者、后公开

Team Nebula 的固定做法是：新版本先放赞助渠道（Patreon 档位提前 2~4 周拿到），到公开日再在 itch.io 发布页放出公开版。所以搜索时你会遇到两种「最新」：赞助版的编号更靠前，发布页上的公开版才是多数人能直接拿到的。

各平台每版通常发三个包（以发布页当时显示为准）：

| 平台 | 文件形态 | 说明 |
| --- | --- | --- |
| Android | `xxx android.rar` | 压缩包内是 APK，需先解压再装 |
| Windows | `xxx windows.zip` | 解压后直接运行 |
| Linux | `xxx linux.zip` | 0.3.3 起提供 |

网盘里拿到的多是已解压好的 APK，直接装即可。

## 二、公开版本时间线（据开发者 devlog）

| 版本 | 公开日期 | 主要变化 |
| --- | --- | --- |
| 0.2 | 2026-02-04 | 首个大规模公开版 |
| 0.3.2 | 2026-04-24 | Chara 重做（含全部动画）等 |
| 0.3.3 | 2026-05-03 | 新主菜单、新开场；新增西班牙语与俄语；新增 Linux 版 |
| 0.3.4 | 2026-06-16 | 过场动画可跳过；新增 6 个场景、9 个二周目变体、2 套皮肤；Mac 测试版 |
| 0.3.4_2 | 2026-06-18 | 修复战斗中失去移动控制、开场重进等 |
| 0.3.4_3 | 2026-07-06 | 以修复为主，附带易用性改动与一个新道具 |
| 0.3.5 | 2026-08-19 | 加入配音；ACT 新增限时选择；同日发布独立外传 LoveManiac: Scarlet Lust |

0.3.5 之后仍在继续发小补丁，最新编号以开发者 devlog 为准。想看各版实机画面的变化，[lovemaniac 介绍站](https://lovemaniac.gltd.quest/) 的玩法页按当前版本整理了一轮。

## 三、选包建议

- **就想正常玩**：0.3.3 内容完整可玩，主菜单与开场都是这版更新的，不必追最新；
- **想要配音、更多场景**：得升到 0.3.5 及以上；
- **想要中文**：语言列表截至 0.3.5 为英语、西班牙语、俄语，没有中文，换版本解决不了，别去找来源不明的汉化包；
- **宣发有、包里没有**：公告提到的后续内容会分批补，没进当前公开版就是没有，以实际打开游戏看到的为准。

## 四、存档：跨版本更新最大的坑

玩家反馈最集中的一条：

- **跨版本更新会丢进度**：版本跨度越大风险越高，游戏目前没有存档导出 / 导入功能；
- **长期闲置也可能丢档**：有玩家反馈一段时间没打开后进度消失；
- **能做的**：大版本更新前别指望自动保留；想要保险，更新前用文件管理器把应用数据目录整目录备份一份（普通机型权限有限，不一定完整）；
- **从头开始**：应用信息里「清除数据」即可重置（存档一并清掉）。

玩法层面各版的差异见 [玩法分支与弹幕躲避要点](玩法分支与弹幕躲避要点.md)；装新版遇到问题去 [安装失败与闪退排查](安装失败与闪退排查.md)。
