# 口语跟读与听力训练怎么练更有效

> 本篇讲移动端外语学习里口语跟读自动评分、听力任务这两类练习的练法：评分引擎怎么用、什么环境练分更高、听力任务按什么顺序做。课程激活与成绩口径见相关篇目。

---

## 一、口语跟读：机器评分怎么用

现在不少外语学习应用内置了跟读自动评分引擎，WE Learn 随行课堂是学生里用得较多的一款：选到口语跟读类练习后，屏幕上逐句显示对话文本，戴上耳机逐句朗读，系统即时给出分数。不需要搭子、不需要老师在旁边，自己一个人就能反复练，分数变化直接反映熟练度。

想刷高分，三个细节比多练十遍更管用：

- **环境安静**：背景噪音会直接拉低识别质量，图书馆或宿舍安静时段练最合适；
- **语速正常**：追快反而咬字含糊，按日常说话的节奏读；
- **先听后读**：先把原音听一两遍摸清连读与重音，再开口跟读，比盯着文本硬读准得多。

除了跟读，部分版本还提供 Freestyle 口语与作文专项训练，作文提交后能拿到实时评分、逐句点评与切题分析，写作薄弱的同学可以拿来当日常自测。

## 二、听力任务：按层级推进

每单元的听力板块通常按「听力策略 → 前置任务 → 会话/短文听力 → 视频课 → 单元测验」的层级排布，这个顺序不要跳：

1. 先看**听力策略**，半分钟到一分钟的技巧讲解，告诉你这一单元听的时候该抓什么；
2. 做**前置任务**热身，把生词混个脸熟；
3. 正式听会话与短文，第一遍盲听抓大意，第二遍看题精听；
4. 视频课当放松收尾，最后做单元测验验收。

手机适合磨耳朵，电脑网页端适合做需要打字的题目——两端登录同一账号进度互通，教室电脑和寝室电脑之间交替使用也不用手动迁移。

## 三、录音录不上、耳机没声音

口语练习最常见的拦路虎不是发音，是设备：应用拿不到麦克风权限、蓝牙耳机延迟导致评分异常，都会让跟读分低得离谱。练口语前先在系统设置里确认麦克风权限已授予应用；蓝牙耳机评分不稳时改用有线耳机或手机外放。这些故障的处理思路在介绍站里有更细的排查清单，[we learn 随行课堂站点](https://we-learn.wrwq.fun/)整理了从安装到常见故障的完整入口。
