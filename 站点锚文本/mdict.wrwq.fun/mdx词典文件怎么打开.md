# mdx 词典文件怎么打开

手头拿到一份 `.mdx` 文件，双击打不开、拖进 Word 全是乱码——这是很多人第一次接触 mdx 的共同经历。其实它不是文档，而是一种**词典数据封装格式**，得用专门的词典阅读器来开。

## 一、mdx 是什么格式

mdx 是 MDict 词典阅读器所使用的词典文件格式，里面打包了词头和释义。它有几个鲜明的特点：

- **释义按网页方式排版**：支持加粗、变色、音标、插图，甚至嵌入朗读按钮，做得到和纸面词典几乎一样的阅读体验；
- **常伴一个同名 `.mdd` 资源包**：真人发音、例句音频、插图都装在 mdd 里，两者主文件名一致、只差扩展名；
- **跨设备通用**：同一份 mdx，手机和电脑上的阅读器都能读，词典是"搬得走"的。

所以"打开 mdx"的正确姿势是两步：装一个词典阅读器，再把文件放进它的词典目录。

## 二、用 MDict 打开（安卓手机）

安卓上最通用的做法是用 MDict：

1. 安装 MDict，首次运行会在内部存储生成 `mdict/doc` 目录；
2. 把 mdx（以及同名的 mdd，如果有的话）拷进这个目录，压缩包要先解压；
3. 回到应用的"词库"页刷新，新词典出现后即可查词。

安卓 11 以上的系统对目录访问管得严，拷完在列表里看不到的话，去 设置 → 词库 里指定一个"额外词库目录"，把文件放进那里再刷新。装应用、授权、放词库的完整过程，可以看这份 [MDict 安卓版下载与安装说明](https://mdict.wrwq.fun/)，写得比这里细。

## 三、电脑上怎么开

Windows 电脑版是绿色软件，解压即用：把 mdx/mdd 放进程序目录下的 `doc` 文件夹，启动时自动扫描导入；词典放在别的盘符时，也可以走菜单 Library → Library Manager → Import Library 选择文件夹导入。

想顺手在电脑上预览内容也可以用 GoldenDict 这类开源词典工具，它同样支持 mdx——不过排版还原度因词典而异，讲究的词条还是 MDict 读起来最原汁原味。

## 四、打不开的几种常见原因

- **只拷了 mdx，正文空白**：资源在同名的 mdd 里，缺了它图和发音都不显示，把 mdd 一起放进同目录即可；
- **改了文件名**：mdx 与 mdd 要求同名配对，单独改名会拆散这对搭档；
- **压缩包没解压直接拷**：很多词库下载下来是 zip/7z，要先解出 mdx（和 mdd）再放进词典目录；
- **文件本身损坏**：下载中断的包重新下一遍。

确认不了文件是否完整时，可以先拿一本几 MB 的小词典试水，排除了文件因素再折腾目录。

## 五、词库去哪里找

围绕 mdx 有一个沉淀多年的社区：有爱好者整理的各类学习词典、专业辞典，也有开发者提供的 Wordnet、CC-CEDict 这类开源样例词库，数量以千计。挑词库时留意两点：一是看词条排版质量，好的 mdx 打开赏心悦目；二是留意版权——很多词典是用户自行转换的，自己学习用没问题，别拿去二次分发。

先装好阅读器，再往书架上一本本添词典——这就是打开 mdx 的全部秘密。
