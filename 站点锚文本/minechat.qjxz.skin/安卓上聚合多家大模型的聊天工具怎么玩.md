# 安卓上聚合多家大模型的聊天工具怎么玩

> 讲一类「多模型聚合」安卓聊天工具的通用玩法，以 MineChat 为例：模型怎么切、人设怎么配、记录存在哪。

## 一、这类工具解决什么问题

各家大模型各有擅长：有的写长文稳、有的响应快、有的角色扮演味道足。装一堆单一模型的 App 换来换去太折腾，聚合型客户端的思路是**一个窗口接多家服务商**，聊天中途点一下就换模型，上下文还在。

MineChat 是这类工具里的轻量代表：安装包约 2.78M，安卓 5.2 及以上就能装，免登录，打开就能用。内置 OpenAI、Google Gemini、Claude、OpenRouter、Grok（xAI）等主流服务商，也支持手动接入兼容 OpenAI 协议的第三方模型。

## 二、核心操作只有三个位置

| 位置 | 干什么 |
| --- | --- |
| 首页左下角方块 | 选 / 切当前模型，下一条消息就走新模型 |
| 右上角头像 | 进设置：提供商、预设、助手、外观都在这 |
| 助手入口 | 切换、创建 AI 角色，单人 / 多人模式从这里发起 |

先在「提供商」里确认有可用模型（内置的选一个，或自己新建填接口地址与密钥），回首页左下角选中，就能发第一条消息 —— 全程没有注册环节。

## 三、让它更像「自己的」工具

模型只是底座，体验差异来自上面三层可自定义的配置：

- **助手（角色）**：写名字、人设、开场白，AI 按这套说话；
- **预设**：场景描述 + 角色设定 + 输出要求打包，开聊前选好即生效；
- **世界书与正则**：长线剧情用世界书按关键词带入设定；正则规则清洗回复排版。

这四样互相独立：同一个模型可以配不同角色，同一个角色也能随时换模型。卡片文件网上到处都有，导入方法见[酒馆角色卡导入手机教程.md](酒馆角色卡导入手机教程.md)。

## 四、记录与输入体验

历史会话保存在本地，关掉应用、重启手机都在，找旧内容直接翻记录；输入支持全屏模式，写长 prompt、粘贴整段文稿不憋屈。界面走深色简洁路线，对话框透明度、字体颜色、聊天背景图都能调。
