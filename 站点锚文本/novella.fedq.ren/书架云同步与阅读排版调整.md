## 换机不丢书架：同步怎么用

同步的中间站是 GitHub 账号，整条链路是三步：

1. 在旧手机上登录 GitHub 账号，书签与阅读进度会存到云端。
2. 新手机装好应用后登录**同一个账号**。
3. 等一次同步跑完，书架、进度与设置自动还原。

两个容易踩的点：

- **两台设备必须指向同一个账号**——换机后书架是空的，九成是这里没对上，其次才是授权失效，重新登录一次再看。
- **卸载重装前先同步**——覆盖升级不动本地数据，但卸载会把本地书架清掉，云端有同步才能还原。

社区讨论区也是登录后才开放的，进去之后动画、漫画分区分开聊，今日新增和在线人数在页首就能看到。

## 读长章不累：排版可调项

阅读页的排版全部可调，几百章的大部头也按自己的习惯来：

- **字号、字体与段落间距**：字体大小、字体类型、排版间距都能改，找到不跳行、不费眼的组合再开始读。
- **三种显示模式**：浅色、深色、纯黑各一套配色，夜间追更切纯黑不刺眼；切换模式与翻页方式都不影响阅读进度，切回来还在原处。
- **动态取色**：界面配色会从当前书籍封面提取主色，每本书的氛围略有不同。
- **大屏双页**：平板或横屏时切到 Expanded / Split 双页排版，一屏两页像翻纸书，这项能力从 v1.6.0 起提供。
