## 怎么用这些文章

- 还没注册账号 → 从 [外国观众购票准备清单.md](外国观众购票准备清单.md) 开始，账号、实名、支付三件事都有时间要求；
- 场次已经定好 → 直接看 [抢票当天时间线怎么排.md](抢票当天时间线怎么排.md)，把当天每个时间点排进日历；
- 找不到原来的入口 → [NOL更名后入口怎么找.md](NOL更名后入口怎么找.md) 里有两轮更名的完整时间线。

想按界面一步步把「发现场次到扫码入场」的路径走一遍，可以参考 [Interpark 观演参考](https://interpark.fedq.quest/)。
