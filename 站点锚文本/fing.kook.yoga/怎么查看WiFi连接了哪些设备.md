# 怎么查看WiFi连接了哪些设备

> 本篇讲的是：不登录路由器后台，用手机把一个 WiFi 里所有已连接设备列出来的做法，以及列表里每台设备该怎么读。相关内容见[新设备上线提醒怎么设置](新设备上线提醒怎么设置.md)。

---

想知道"这个 WiFi 上到底连了谁"，最直接的办法是做一次局域网扫描。手机装上 Fing 这类网络扫描工具后，连上要查的 WiFi，点一次扫描，几十秒内就能拿到一份设备清单——不需要路由器管理员密码，也不需要在电脑上敲命令。

## 清单里能看到什么

扫描结果不只是 IP 地址列表。每台设备通常会标注：

- **设备类型**：手机、电脑、打印机、摄像头、智能音箱、传感器等；
- **品牌与型号**：比如 "HP Color LaserJet M283fdw" 这种能对上号的程度；
- **IP 与 MAC 地址**：定位设备、排查冲突时用得上；
- **在线状态**：当前是否在线、最近什么时候上线过。

同一个网络里的设备，还能按家人、办公设备、媒体设备这类维度归类，设备多的时候不至于一屏糊满。

## 识别是怎么做到的

设备肯暴露在网络上的特征其实不少：MAC 地址段对应哪个厂商、DHCP 请求里带了什么指纹、HTTP 标识与主机名长什么样。扫描工具把这些特征拿去和一套持续更新的识别库比对，就能得出"这是一台什么设备"。识别库积累得越久，冷门 IoT 设备认出来的概率越高——这也是 Fing 这类工具的看家本事，它的识别引擎持续训练超过十年，部分路由器厂商甚至直接把这套识别能力集成进了自家固件。

## 常见的几种结果

- **全部眼熟**：家里的设备都对得上号，顺手把每台标上归属，以后一眼就能发现异常；
- **有陌生设备**：先别急着下结论，可能是自己忘了的旧设备（智能插座、旧手机）；把 MAC 地址和家里实物对一遍，对不上的再处理；
- **有设备认不出型号**：通常是无牌 IoT 小硬件，不影响排查，看 IP 和在线时段也能判断。

## 从清单到行动

看清单只是第一步：怀疑被蹭网，就把陌生设备标出来盯住；测速发现带宽不对劲，用工具箱里的测速和排障功能继续查。相关的操作细节，可以到 [Fing 设备扫描](https://fing.kook.yoga/) 站点进一步了解，那里整理了设备清单、识别原理和安装文件资源的获取方式。
