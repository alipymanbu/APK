# LoveManiac 安卓版下载与安装步骤

这篇只解决一件事：怎么把 LoveManiac 的安卓包装进手机。全程用手机完成，不用连电脑，前后大约五分钟。装完之后怎么玩、触屏怎么操作，另见 [手机触屏操作与上手答疑](手机触屏操作与上手答疑.md)。

## 装之前：开一次「安装未知应用」权限

安卓默认只让从应用商店装应用，直接点 APK 会被拦。先进「设置 → 安全（或隐私保护）→ 安装未知应用」，把接下来要用的那个应用（浏览器、文件管理器或网盘客户端）设为允许。小米、华为等品牌会在点开安装包时单独弹窗询问，当场点允许也行，不必提前翻设置。

## 四步装完

1. **打开分享入口**：LoveManiac 玩法与安装指南（<https://lovemaniac.wxhp.skin/>）的下载页里有夸克网盘分享入口，点进去先把文件转存到自己的网盘；
2. **下载到手机本地**：从自己的网盘把 APK 下到本地，等进度走完再动手，别在预览页里直接点「打开」；
3. **点包安装**：用文件管理器进下载目录，点 APK 文件，在弹出的安装界面里点「安装」。文件名应以 .apk 结尾，后缀被改是装不上最常见的理由；
4. **打开并给权限**：装完点「打开」，首次启动会申请存储权限（读写存档用），允许即可。首启加载较慢属正常，等进度走完再操作。

## 装不上时按顺序排查

- **解析错误 / 应用未安装**：基本是包没下完整或后缀被改，删掉重下一次；
- **装上了打不开、闪退**：先确认系统是 Android 7.0 以上，再去应用信息里看存储权限是否被拒；
- **空间不足**：包体约 89 MB，安装需要临时空间，建议预留 500 MB 以上。

另提醒一句：这是 18+ 成人向同人作品，首次进入会有内容提示，未成年设备请不要安装。想先了解游戏本身值不值得装，看 [弹幕战斗与对话分支玩法拆解](弹幕战斗与对话分支玩法拆解.md)。
