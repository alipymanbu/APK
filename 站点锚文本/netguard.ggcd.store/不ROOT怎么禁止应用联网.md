# 不 ROOT 怎么禁止应用联网（安卓无 root 拦截方案整理）

> 搜「不 root 怎么禁止应用联网」「怎么不让某个 App 连网」的读者要的答案：安卓不解锁、不刷机的前提下，靠系统自带的 VPN 接口就能在本机建一道过滤闸口。本篇讲清这条路为什么可行、怎么一步步设好，以及装完怎么验证真的拦住了。

## 一、不 ROOT 能拦到什么程度

先说结论：**按应用、按网络类型（Wi-Fi / 移动数据）逐个禁止联网，不 root 完全做得到**；做不到的是 deeper 的东西——比如篡改某个应用的行为、强行断掉系统级连接通道。

不 root 方案能覆盖的：

| 能力 | 说明 |
| --- | --- |
| 按应用禁网 | 指定某个应用完全断网，或只断移动数据、Wi-Fi 照常 |
| 按网络类型区分 | 同一个应用，家里 Wi-Fi 放行、出门流量拦住 |
| 系统应用纳入管理 | 预装应用一样能进清单（部分方案里是可选项） |
| 按地址拦截 | 进阶玩法：只挡某个应用的回传地址，其余联网保留 |

实现载体几乎都一样：借助安卓系统提供的 VPN 接口，在本机建一张虚拟网卡，所有应用的联网请求先经过它，再按规则放行或拦下。**过滤动作发生在手机本地，流量不会绕到别处的服务器**——这一点是判断这类工具靠不靠谱的关键。

## 二、用 NetGuard 建这道闸

老牌的开源选择是 NetGuard（开发者 FairCode B.V.，GPL v3 许可证，源码在 `github.com/M66B/NetGuard`），支持安卓 5.1 及以上，不内置广告、不做追踪。上手四步：

1. **装好后打开应用**，拨动顶部的总开关；
2. **系统弹出「VPN 连接请求」**，点确定——这一步是安卓对这类工具的固定要求，弹一次、之后不再问；
3. **回到应用列表**，每个应用右侧有两列开关，分别对应 Wi-Fi 与移动数据，把不想让它联网的应用对应开关关掉即可；
4. **即时生效**：被拦的应用立刻拿不到网络，正在用的应用不受影响。

界面上的状态靠图标区分：绿色三角是已放行，红叉是已阻止，橙色锁形是按流量计费网络下的锁定。应用内自带图例页，认不全的时候翻一下就明白。

想核对细节、看真机界面长什么样，可以逛逛这份 [NetGuard 闸口原理与玩法整理](https://netguard.ggcd.store/)，截图和规则语义都对得上。

## 三、装完怎么验证真的拦住了

- **最直接**：把某个应用的 Wi-Fi 和移动数据两列都关掉，打开它试试刷新——转圈加载不出内容就是拦住了；
- **看图标**：应用列表里该应用行会变成红叉标记，对应「已阻止」；
- **看通知**：通知栏有一条常驻通知是正常的——安卓对 VPN 类前台服务的强制要求，应用内没有隐藏它的开关。它还在，就说明闸口在值守。

## 四、两个使用前提

1. **别让系统把它杀了**：进各品牌手机的电池优化设置，把 NetGuard 设为不受限制 / 加入白名单，否则锁屏一段时间后防火墙可能被冻结、规则失效；
2. **和其他 VPN 二选一**：安卓同时只允许一个应用占用 VPN 通道，两者都要用时只能切换着来，具体的冲突表现与处理见 [开了防火墙 VPN 连不上怎么办](开了防火墙VPN连不上怎么办.md)。
