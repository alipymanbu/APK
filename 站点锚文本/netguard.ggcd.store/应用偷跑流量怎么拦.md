# 应用偷跑流量怎么拦（先定位、再动手的完整流程）

> 搜「手机应用偷跑流量怎么办」「后台流量谁在用」的读者，多数是月底一看流量账单傻眼。本篇给一条可复现的路：先用系统自带工具把耗流大户揪出来，再按应用精准拦住，最后讲两个容易忽略的补充开关。
> **本目录其他文章**：[不 ROOT 怎么禁止应用联网](不ROOT怎么禁止应用联网.md) · [开了防火墙 VPN 连不上怎么办](开了防火墙VPN连不上怎么办.md)

---

## 一、先定位：谁在偷跑

动手拦之前先花两分钟定位，免得拦错人：

1. 打开系统设置 → **流量使用情况**（各品牌叫法略有差异，小米叫「流量管理」，华为叫「流量管理」/「应用联网管理」）；
2. 切到「本月」，按用量从高到低排序；
3. 重点看两类异常：
   - **前台没怎么用、后台用量却很高**的应用——典型偷跑嫌疑；
   - **明明很少打开、流量却蹭蹭涨**的应用——多半在驻后台刷新或上报。

系统流量排行只到「应用」这一级，想看它连了哪些地址，得靠防火墙类工具的日志功能（下文第三节会提）。

## 二、再拦截：按应用断粮

定位到目标后，用 NetGuard 这类无 root 防火墙动手。装好后（取包与安装步骤见 [不 ROOT 怎么禁止应用联网](不ROOT怎么禁止应用联网.md)），打开总开关、同意一次 VPN 连接，然后在应用列表里找到嫌疑对象：

| 想要的效果 | 操作 |
| --- | --- |
| 彻底断网 | Wi-Fi 与移动数据两列开关都关掉 |
| 只拦流量、家里 Wi-Fi 随便用 | 只关移动数据那列 |
| 保持能用、但不许后台乱来 | 开「屏幕亮起时才放行」类的可选规则 |
| 出境漫游时全部收紧 | 开「漫游时拦截」类开关 |

这些可选规则在设置里都能找到，不用逐个应用去点——先立全局规则，再对例外应用单独放行，是最省事的用法。

改动即时生效，回到系统流量排行观察一两天，用量曲线掉下来就说明拦对了。

## 三、进阶：只挡回传地址，保留正常功能

有些应用被完全断网后会闹脾气（收不到推送、登录失效）。更细的做法是**按地址过滤**：在 NetGuard 的过滤模式（属专业版功能）里，把某个应用的特定域名 / 地址拦下，其余联网照常——比如只挡掉它的统计上报地址，应用本体功能不受影响。

配合流量日志（同样属专业版，可导出 PCAP 格式、用 Wireshark 打开）能看清每个应用连过哪些地址，定位「回传大户」会精准很多。这类进阶玩法不必一开始就用，先用基础拦截把大头拦住，有进一步需求再上。

整套规则体系长什么样、图标语义怎么认，[NetGuard 介绍站](https://netguard.ggcd.store/)里有真机截图对照，上手会更快。

## 四、顺手补两个漏

- **系统应用也要管**：部分预装应用的流量不在普通排行榜前排，但积少成多。防火墙设置里允许管理系统应用后，把它们一并纳入清单；
- **漫游开关常备**：平时用不上，出境前顺手把「漫游时拦截」打开，能省掉很多意外账单。

拦完之后如果发现别的 VPN 连不上了，不是坏了——安卓只留一个 VPN 通道，处理办法见 [开了防火墙 VPN 连不上怎么办](开了防火墙VPN连不上怎么办.md)。
