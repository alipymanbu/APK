# PojavLauncher 停更后的替代选择

> 本篇写给 PojavLauncher 的老用户：项目停更归档之后，想在手机上继续玩 Java 版有哪些路可走，换启动器要注意什么。
>
> 相关文档：[手机玩我的世界 Java 版完整流程](手机玩我的世界Java版完整流程.md)、[手机模组与光影安装思路](手机模组与光影安装思路.md)

---

PojavLauncher 曾是安卓上玩 Minecraft: Java 版事实上的标准答案，但它已经停止更新并归档。对老用户来说，问题不是「能不能玩」，而是「还能不能跟上版本」。

## 停更意味着什么

启动器不是装完就完事的软件：游戏每次更新版本，启动器都可能需要跟进适配；崩溃与兼容性问题也需要持续修复。项目归档意味着这些更新停了——新版本支持、稳定性修复、界面改进都会停滞。老版本凑合能玩，想跟进游戏更新就会越来越难受。

## 接棒的方案长什么样

社区接过了这一棒。Amethyst 由与 PojavLauncher 一脉相承的开发者组成 AngelAuraMC 继续维护，技术积累同源，方向却更激进：

- **版本覆盖拉满。** 从 2009 年的 rd-132211 原型版到最新快照都在支持范围里，项目状态清单里连 1.17+ 的新渲染管线支持都列得明明白白。
- **Java 运行时内置。** OpenJDK 8 / 17 / 21 的移动版按架构（ARM32 / ARM64 / x86）打包好，装机即用。
- **渲染栈持续演进。** GL4ES、MobileGlues 等移植方案负责把 OpenGL 调用转到手机 GPU，画质与功耗的平衡比早年好了不少。
- **控制系统重写。** 虚拟按键、画面缩放、外设映射都按移动端原生重做。

## 换启动器，注意三件事

**账号照旧。** 无论哪个启动器，登录拥有 Java 版的微软账号这一步不会变，游戏文件跟着账号与版本走。

**配置可以延续思路，不必硬搬。** 不同启动器的配置目录结构有差异，JVM 参数、内存分配这类设置按新工具的口径重设一遍更稳妥。

**安装包来源要干净。** 启动器涉及账号登录，来源务必可靠——认准项目仓库或可信的指引站。Amethyst 的安装包获取入口与安装步骤可以看 [Amethyst 安卓启动器](https://amethyst.ggcd.online/)。

## 老存档怎么办

Java 版的存档格式跨版本兼容性不错，把旧世界的文件夹拷到新启动器对应的游戏目录里，通常就能认出来。跨大版本（比如很老的版本跳到 1.20+）前，建议先把存档备份一份。
