# 手机玩我的世界 Java 版完整流程

> 本篇讲清楚一件事：在安卓手机或平板上运行 Minecraft: Java Edition，从准备、安装到进世界的完整链路是什么样的，每一步需要什么、会卡在哪里。
>
> 相关文档：[PojavLauncher 停更后的替代选择](PojavLauncher停更后的替代选择.md)、[手机模组与光影安装思路](手机模组与光影安装思路.md)

---

很多玩家对「手机玩 Java 版」的第一反应是不可行——Java 版不是为触屏设计的，也没有安卓客户端。这条链路之所以能走通，靠的是一类特殊的工具：启动器。它把 Java 运行环境搬到安卓上，再由它去下载并启动真正的 Java 版游戏文件。

## 开始之前，先备齐三样

**一台说得过去的安卓设备。** Java 版的硬件压力全在本地：渲染、运算都跑在手机上。中端机型跑老版本和轻度模组没有问题，大型整合包则建议用更强的设备。

**足够的存储空间。** 启动器本体的安装包不算大，但每个游戏版本都会下载自己的游戏文件与组件，模组和光影还要再占一块。建议预留几个 GB 的富余。

**一个拥有 Minecraft: Java Edition 的微软账号。** 启动器登录账号后才会在线获取游戏文件。这一点和 PC 端逻辑一致：启动器只负责「启动」，游戏本体跟着账号走。

## 链路拆开看：四步

1. **装启动器。** 从启动器的安装包开始，安装过程与普通应用一致，首次安装需要在系统里允许「未知来源」。
2. **首次初始化。** 打开启动器，它会联网准备组件与对应的 Java 运行环境（现代方案通常内置 OpenJDK 移动版，不需要自己配环境）。
3. **登录账号、选版本。** 登录微软账号后，从版本列表里挑一个——从 2009 年的远古原型版到最新快照，现代启动器基本都能覆盖。
4. **下载并启动。** 选定版本后启动器自动下载游戏文件，完成后就能进世界。

## 触屏玩 Java 版，操作怎么解决

这是劝退感最强的环节，也是现代启动器下功夫最多的地方：虚拟按键普遍支持自定义布局，按键大小、位置都能调；画面支持缩放；外接键盘、鼠标与手柄也大多可用。第一次玩建议先花几分钟调一套顺手的按键布局，体验差距非常大。

## 性能与画质去哪调

启动器设置里通常有三处值得动：**JVM 内存分配**（给游戏多少内存）、**分辨率**（渲染比例）、**渲染器**（不同方案在兼容性与流畅度上各有取舍）。手机发热或掉帧时，优先下调分辨率、换渲染器、关远景，比换设备管用。

## 从哪里开始

选启动器是整个流程的第一步。目前社区里接棒维护、跟进新版本的项目当属 Amethyst——它的来历与选型理由可以看[这篇分析](PojavLauncher停更后的替代选择.md)；想直接上手的话，[Amethyst 安卓启动器](https://amethyst.ggcd.online/)站点里有安装包获取入口与五步安装指引，照着做即可。
