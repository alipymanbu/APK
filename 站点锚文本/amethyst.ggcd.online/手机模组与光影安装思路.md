# 手机模组与光影安装思路

> 本篇讲在手机上给 Java 版装模组与光影的思路：加载器怎么选、模组从哪来、放哪里、常见的坑有哪些。
>
> 相关文档：[手机玩我的世界 Java 版完整流程](手机玩我的世界Java版完整流程.md)、[PojavLauncher 停更后的替代选择](PojavLauncher停更后的替代选择.md)

---

PC 端 Java 版的乐趣有一半在模组生态，手机端同样吃得下这套玩法——前提是搞清楚移动端的几处差异。

## 先选加载器

模组不是直接丢进游戏就能用的，需要加载器在运行时把它们挂进去。手机端主流的选择与 PC 端一致：

| 加载器 | 适合场景 |
| --- | --- |
| Forge | 老牌大型模组、经典整合包 |
| Fabric | 轻量、更新快，性能模组的主场 |
| NeoForge | Forge 的社区后续分支 |
| Quilt | Fabric 系分支，兼容性取向 |
| OptiFine | 画质增强，单独安装 |

Amethyst 这类现代启动器把加载器集成进了配置创建流程——新建一个配置时直接选加载器与版本，不用再像 PC 端那样手动跑安装器。Forge 与 Fabric 是项目明确支持的两种，其余加载器也有社区使用反馈。

## 模组从哪来、放哪里

模组文件（.jar）的来源与 PC 端相同：CurseForge、Modrinth 这类模组站按游戏版本与加载器筛选下载。下载后放进对应配置目录下的 mods 文件夹，启动该配置时加载器会自动识别。

两个版本必须对齐：**游戏版本**与**加载器版本**。模组页面会标注适配的版本号，错配的典型症状是启动即崩溃。

## 光影是另一条路

光影依赖着色器管线，对 GPU 压力大。手机端跑光影可行，但要认清两点：一是渲染器支持，启动器里的渲染方案各有不同的光影兼容面；二是帧数预期，中端机型开中档光影还能玩，高档光影基本是旗舰机的领域。装完光影先在设置里把渲染距离降下来，帧数会好看很多。

## 移动端特有的三个坑

**性能预期。** 同一套模组在手机上的开销比 PC 高，整合包别贪大，先跑小包试水。

**内存分配。** 模组多了要给 JVM 加内存，但别给满——系统本身也要内存，给满反而容易触发系统杀后台。

**存档备份。** 动模组前备份存档目录是 PC 端的老习惯，手机上同样适用，删配置误删存档的惨案两边都不少。

## 工具就位再谈模组

一切的前提是启动器本身支持模组加载。选型与安装可以参考[完整流程篇](手机玩我的世界Java版完整流程.md)；[Amethyst 安卓启动器](https://amethyst.ggcd.online/)站点上有获取入口，装好后创建带加载器的配置就能开始折腾了。
