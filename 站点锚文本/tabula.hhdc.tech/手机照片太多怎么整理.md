# 手机照片太多怎么整理

照片越攒越多，找个截图要翻半天，旅行照和表情包混在一起——很多人卡在这一步，不是不想整理，是缺一个顺手的方式。安卓上有一款叫 Tabula 的小工具，把"删除"和"归类"都做成了滑动卡片的形态，顺手又解压。这篇从整理的角度讲讲它的图集与归档机制，玩法细节在[像刷卡片一样清理手机相册](./像刷卡片一样清理手机相册.md)里有更完整的介绍。

## 从"清理工具"升级成"整理工具"

Tabula 早期版本主打清理，之后的更新里加入了图集功能：在图库里可以按旅行、美食、家人这些主题创建图集，挑照片时往下滑，就归入对应图集，归档动画带着 macOS 般的缩放质感。定位也从"把不要的删掉"扩展成了"把要留的放好"。

## 归档的照片去了哪里

在系统相册的路径下，Tabula 会自动生成一个同名文件夹，归档的照片就分类放在这下面，所以整理成果在别的相册应用里也看得到。归档方式有两种：

- **复制**：原图不动，副本进图集；
- **移动**：直接搬进对应分类。

选择权在使用者手里，原有相册结构不会被强行改动。

## 让整理变成可持续的小习惯

- **推荐模式可换**：随机推荐带"冷却池"机制，刷过的照片 7 天 / 14 天 / 24 天内不会重复出现；也可以按相似度成组挑，连拍、同场景一次处理完。
- **整理统计**：总体进度、累计清理数量一页看清，坚持了多久一目了然。
- **桌面小组件**：把"今天整理了几张"摆在桌面上，顺手瞄一眼就有接着滑的动力。

## 只在手机里进行

整个整理过程全程离线：读取、标记、归档都发生在本机，没有账号体系，也不用联网上传。源代码在 GitHub 公开，介意隐私的话可以自行查验。准备装一个试试的话，[Tabula 介绍站](https://tabula.hhdc.tech/)整理了它的安装文件资源获取方式与玩法说明；装好后的第一步怎么做，见[安卓手机上怎么安装使用](./安卓手机上怎么安装使用.md)。
