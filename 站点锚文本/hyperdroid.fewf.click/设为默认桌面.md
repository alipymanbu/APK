# 设为默认桌面：开机直进 Windows 风格界面，以及怎么切回去

> HyperDroid 刚装完还只是一个普通应用，按 Home 键仍会回到原来的桌面。要让它真正「接管」设备，得设成默认主屏幕应用；这篇把这个设置讲清楚，附上切回原桌面的办法——随时可逆，不用担心回不去。背景知识见[手机变电脑桌面](手机变电脑桌面.md)，装好后的用法见[平板多窗口玩法](平板多窗口玩法.md)。

## 一、装完先打开一次

安装完成后先打开应用：屏幕切到横屏，Windows 风格的桌面、任务栏和开始菜单就会加载出来。确认一切正常再往下走默认桌面的设置，出问题也好排查。

## 二、在应用自己的设置里设默认（推荐路径）

HyperDroid 自带设置入口，几步搞定：

1. 点任务栏面板上的齿轮图标，打开 Settings 窗口；
2. 确认在 **System** 分区，点 **Default Launcher**；
3. 打开 **Enable as launcher** 开关；
4. 点 **Choose as Default**，在系统弹出的「主屏幕应用」列表里选 HyperDroid。

设好之后，按 Home 键或解锁屏幕就直接进入 Windows 风格桌面。

## 三、应用里找不到入口？走系统设置

不同版本的菜单位置可能不同，系统设置这条路永远通用：

**系统设置 → 应用 → 默认应用 → 主屏幕应用（Home app）→ 选 HyperDroid**

## 四、想切回原来的桌面

- **临时切回**：同一个路径（系统设置 → 应用 → 默认应用 → 主屏幕应用）选回原来的桌面即可，HyperDroid 的设置不会被清掉，随时能再切回来。
- **彻底卸载**：先切回原桌面，再像卸载普通应用一样卸载 HyperDroid。不先切回去直接卸载，个别机型会出现桌面临时无主的情况，按提示选一个桌面就好。

## 五、顺手把桌面调到舒服

设为默认之后，值得一调的还有：显示缩放（小屏建议调小）、隐藏状态栏与导航栏（观感更接近整块电脑屏幕，从 Display 分区开关）、壁纸与主题色（Personalize 分区）。这些调整的完整整理见 [HyperDroid 桌面启动器站](https://hyperdroid.fewf.click/)。
