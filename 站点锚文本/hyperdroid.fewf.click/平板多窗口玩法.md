# 平板多窗口玩法：任务栏、开始菜单与窗口拖拽实操

> HyperDroid 装好之后，平板（或横屏手机）就是一个「小电脑桌面」。这篇按实际使用的顺序过一遍它的桌面逻辑：任务栏怎么用、应用怎么开成窗口、文件怎么管理，以及哪些细节值得先知道。还没装好的，先看[手机变电脑桌面](手机变电脑桌面.md)和[设为默认桌面](设为默认桌面.md)。

## 一、任务栏：桌面的控制中心

屏幕底部常驻一条任务栏，布局与 Windows 11 基本一致：

- 左侧开始菜单图标，点开是固定应用；菜单里的下拉框选 **All**，能看到设备上装的全部安卓应用。
- 右侧系统托盘显示 Wi-Fi、音量、电量和时钟，点开还有快捷设置面板，常用开关一触即达。
- 常用应用可以长按图标 **Pin to Taskbar**（固定到任务栏），之后任何时候一点即开。

## 二、窗口：和手机全屏逻辑最大的不同

应用不再是铺满全屏，而是以独立窗口打开：

1. 窗口可以拖动、缩放，多个窗口同时留在桌面上；
2. 切换靠任务栏，和电脑上点图标切窗口一个道理；
3. 接上蓝牙键鼠后，拖窗口、打字就是电脑上的操作手感。

据第三方评测，窗口还支持置顶、分屏组合等进阶玩法，具体以你手上的版本实际提供的控件为准。窗口开太多后台会卡，这一点和电脑也像。

## 三、文件管理器：按电脑的习惯找文件

内置一个 Windows 风格的文件管理器，左侧栏是 **This PC**、**Documents**、**Downloads**、**Pictures** 这些熟悉的位置。它管理的正是设备里的真实存储，不是另存了一份；第一次使用会请求存储权限，允许后才能看到内容。看图、播视频、移动删除文件都在这里完成。

## 四、浏览器：桌面式的工作方式

内置浏览器支持装扩展，平时在电脑浏览器上用的部分扩展可以照常启用；还能把 YouTube、Instagram 这类网站固定成桌面快捷方式，点开就是一个独立窗口的站点——平板上追网页应用，这条路径比手机版体验顺手得多。

## 五、两个先知道的小毛病

- **小组件抽风**：新加的小组件可能提示无网络或显示错乱，彻底杀掉应用重开就好，可能每加一个都要重启一次。
- **设置页有广告**：免费应用，广告存在感因版本而异，介意的话把常用设置一次调完、少频繁进设置。

整体而言，这套桌面逻辑的上手成本很低：会用 Windows 就会用它。功能全貌与真机截图见 [HyperDroid 介绍站](https://hyperdroid.fewf.click/)，桌面个性化（壁纸、主题色、模糊效果）的调整入口也在同一站的整理里。
