# 手机电脑互相同步文件的做法

数据线找不着、聊天工具传文件被压缩、云盘传大文件要会员——在同一个 Wi-Fi 里，这些事其实有一条更直接的路：让两台设备自己握手传文件。本文以开源同步工具 Syncthing 的安卓端为例，讲清这套「设备直连」的同步是怎么跑起来的，以及第一次配对要做的几步。

## 一、先弄懂配对逻辑

这套工具不设账号体系。每台装了它的设备，首次启动都会生成一串专属的设备 ID（七段大写字母数字，形如 `ABCDE12-FGHIJK3-…`）。所谓配对，就是**两台设备各自把对方的 ID 加进自己的设备列表**——只加一边是连不上的，这个「双向确认」也正是它的安全边界：光知道你的 ID，别人连不上你的设备。

手机端的 ID 在「侧边菜单 → 显示设备 ID」里，带二维码；电脑端装好后会打开一个本地管理页面（默认 `127.0.0.1:8384`），右上角「操作 → 显示 ID」同样能看到。

## 二、配对三步走

1. 一边点「+」添加远程设备：扫对方二维码，或把那串 ID 复制粘贴过来；
2. 保存后，另一边会弹出「新设备」确认提示，点添加——这一步就是双向确认的第二半；
3. 两边设备名旁亮起状态点，即配对完成。

## 三、共享一个文件夹，同步就开始了

配对只是「认识」，真正传文件靠共享文件夹：

- 发起方在「文件夹」页点「+」，选好本地目录，在「共享给设备」里勾选刚配对的对方；
- 接受方会收到共享请求，确认时可以改本地存放路径，也可以把类型改成「仅接收」做成单向；
- 初次同步对每个文件做内容校验，大文件夹第一次会慢一些，之后只传增量改动。

文件夹有三种类型可以按需选：「发送和接收」做双向同步；「仅发送」适合把手机相册往外推；「仅接收」适合电脑往手机放电子书、安装包。每种文件夹里会出现 `.stfolder` 标记目录，它是「归同步管理」的记号，别手动删。

## 四、什么时候会真正开始传

两台设备**同时在线**才会互传：都连同一个家庭 Wi-Fi 最稳，隔着互联网也能通过加密连接补齐，速度看两边上行带宽。手机端默认受运行条件约束（比如只在 Wi-Fi 下运行），装完先到设置里把运行条件和电池优化交代清楚，锁屏后才能继续干活。
