# 大文件怎么从手机传到电脑不压缩

> 手机里录的视频、拍的原片想搬进电脑，又怕画质被压、文件被改——本篇讲清楚各条传输路线对「原样」的保障程度，以及传大文件时的实操要点。
> **相关文档**：[手机电脑互传文件的几种方法.md](手机电脑互传文件的几种方法.md) · [手机FTP传文件电脑连不上怎么办.md](手机FTP传文件电脑连不上怎么办.md)

---

## 一、先分清：哪些路线会动你的文件

传输本身分两类：

- **原样搬运**：文件按字节复制，内容一个比特都不变。数据线、局域网 FTP、蓝牙都属于这类——它们只管搬运，不碰内容。
- **经过中转加工**：文件先上传到第三方服务器再下载下来。聊天工具传视频常常二次压缩、云盘相册可能转码，画质和元数据都可能变化。

想保住原始画质和文件完整性，优先走第一类。其中蓝牙速度太慢，大文件实际可选的就是**数据线**和**局域网 FTP**两条：有线适合整机搬迁这类一次性大工程；手边没线时，用 Filetransfer 这类 FTP 工具走 WiFi 直传是更顺手的替代——它在 [Filetransfer 介绍站](https://filetransfer.yoan.quest/) 有按功能整理的说明，装好后手机开服务、电脑输地址即可开始，传输的文件只在你自己的两台设备之间流动。

## 二、局域网直传的实操要点

### 1. 速度取决于 WiFi 这一段

- 连 **5 GHz 频段**（有的路由器用 `_5G` 后缀区分网络名），速度比 2.4 GHz 高一档；
- 离路由器近一点，隔一堵墙速度就可能掉一半；
- 同一网络里有设备在看视频、下载，带宽会被分走，传大文件时让它们先歇一歇；
- 路由器老旧时，手机直接开热点让电脑连上，跳过路由器往往反而更快。

### 2. 没有断点续传，稳住环境再开传

FTP 协议没有断点续传——连接断开，没传完的大文件要整个重来。传几个 G 的视频前：

1. 给传输工具关掉电池优化、允许后台运行；
2. 传输期间尽量别锁屏、别切走太远；
3. 传完先在电脑端核对文件大小再删手机上的原件。

### 3. 特别说说视频

手机录的 4K 视频单个动辄几个 G，是最考验传输路线的文件类型。原样搬运（数据线 / 局域网 FTP）不会动它的编码和码率；经聊天工具中转则大概率被压缩成「流畅画质」，细节损失不可逆。在乎原片的话，从一开始就别走中转。

| 关注点 | 数据线 | 局域网 FTP | 聊天工具 / 云盘中转 |

| 文件是否原样 | 是 | 是 | 常被压缩 |
| 速度量级 | 最快 | 快（看 WiFi） | 受上传带宽限制 |
