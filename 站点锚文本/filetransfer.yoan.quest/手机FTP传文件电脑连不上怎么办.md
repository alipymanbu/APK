# 手机FTP传文件电脑连不上怎么办

> 手机端 FTP 服务开了、地址也输进电脑了，却一直连不上或报「无法访问」——本篇按出现频率从高到低列出排查点，从上往下过一遍，绝大多数情况都能定位。

---

## 一、排查清单总表

| 顺序 | 检查点 | 典型症状 |
| --- | --- | --- |
| 1 | 两台设备不在同一个网络 | 地址完全打不开 |
| 2 | 地址或端口输错 | 报「无法访问此网站」 |
| 3 | 电脑防火墙拦截 | 手机端有请求、电脑端无反应 |
| 4 | 路由器开了设备隔离 | 都能上网但互相够不着 |
| 5 | VPN / 虚拟机网卡捣乱 | 电脑 IP 不是 192.168 开头 |
| 6 | 手机端服务掉了 | 之前连得上，中途断开 |

## 二、逐项展开

### 1. 先确认真的在同一个网络

这是出现最多的一种。典型情况：电脑插在光猫上而手机连的是光猫下面路由器的 WiFi，两层网络互相够不着；或者一台连了访客 WiFi——访客网络通常做了设备隔离。最快的验证方法：电脑按 `Win+R` 输入 `cmd` 运行 `ipconfig`，看 IPv4 地址与手机 WiFi 详情里显示的 IP 前三段是否一致。

### 2. 地址要照屏幕原样输

三个容易错的地方：开头是 `ftp://` 不是 `http://`，浏览器自动补 https 会直接打不开；端口号不能漏，`ftp://192.168.1.5:2121` 里的 `:2121` 漏了就会去连默认 21 端口；IP 换过网络后会变，以手机屏幕**当前显示**的为准。

另外部分 Windows 11 会把 `ftp://` 交给浏览器处理，而浏览器打不开 FTP 站点——遇到这种不必折腾系统，换 FileZilla 这类专门的客户端连，或者用支持 FTP 的资源管理器窗口打开。

### 3. 放行电脑防火墙

「控制面板 → 系统和安全 → Windows Defender 防火墙 → 允许应用或功能通过防火墙」，找到资源管理器或你用的 FTP 客户端，把「专用」「公用」都勾上。拿不准是不是防火墙的事，可以临时关闭测试一次，能连上就说明是它拦的。

### 4. 关掉路由器的 AP 隔离

浏览器打开路由器管理地址（常见 `192.168.1.1`，具体看路由器底部标签），在无线设置或安全设置里找「AP 隔离 / 访客隔离」，关掉并重启路由器。公司、学校、酒店的公共网络由管理员强制隔离，改不了就用手机热点替代。

### 5. 断开 VPN、退出虚拟机

VPN 改走流量路径，VMware、VirtualBox 会给电脑加虚拟网卡，导致 FTP 工具显示的地址对不上号。断开 VPN、完全退出虚拟机软件后再看一次 IP。

### 6. 手机端服务状态

FTP 服务只在应用前台运行期间有效，锁屏断网、被系统清后台都会断线。可以在系统设置里关掉对该应用的电池优化；重连前重新读一遍屏幕上的地址，它可能已经变了。

## 三、连上了但很慢

速度只有几百 KB/s 时问题通常出在 WiFi 这段路：换连 5 GHz 频段、离路由器近一点、避开同网络下正在看视频的设备。顺带记住 FTP 的固有特性——没有断点续传，连接断开没传完的文件要整个重来。
