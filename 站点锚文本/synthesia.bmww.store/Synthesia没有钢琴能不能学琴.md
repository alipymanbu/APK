# Synthesia 没有钢琴能不能学琴：触屏、MIDI 键盘与取舍

想用 Synthesia 练琴，但手边没有电钢琴或 MIDI 键盘，只有一部手机 —— 能不能学？结论先给：**能开始，走不远；想认真练，迟早要加一台入门键盘**。安卓版安装文件资源的获取入口整理在 [Synthesia 玩法与获取指引站](https://synthesia.bmww.store/)，下面把三种硬件条件下的体验差别讲清楚。

## 一、纯触屏：能跟弹，但练不到手上功夫

安卓版在手机、平板的触屏上直接显示虚拟琴键，下落音符落到哪个键就按哪个，零成本就能体验完整的跟弹流程 —— 认识键位走向、感受旋律练习「弹对才往下走」的节奏，这些都行。

但触屏有两个绕不过去的短板：

- **没有力度**：真钢琴的强弱是靠按键力度控制的，触屏只有「按到 / 没按到」，练不出触键
- **没有手感**：琴键的下沉阻力和玻璃屏幕完全是两种东西，肌肉记忆迁移不过去

把它当「听歌识曲式的音乐启蒙」没问题；当正式学琴的替代品，练出来的习惯放到真琴上会水土不服。

## 二、接一台 MIDI 键盘：这套玩法的完全体

Synthesia 对硬件的要求其实很低：一台带 MIDI 输出的键盘 + 一根 OTG 转接线 + 一根数据线。几百块的入门 61 键就够用很久。

连接要点（安卓设备）：

1. 看键盘的输出口：常见 USB-B 方口；老设备是 5 针 DIN 口，需要经 MIDI 转 USB 线
2. OTG 转接线（设备接口转 USB-A）+ 数据线，把键盘接到手机或平板
3. 打开应用，在设置的输入设备里选到你的键盘
4. 按一个键，界面有反应就是通了

接上之后体验质变：力度反馈回来了、真琴键的手感开始积累、旋律练习时键上的提示圆点直接落在实物上。带灯键盘还有额外加成 —— 即将要弹的键会在键盘上亮起来，找和弦位置更容易。蓝牙 MIDI 也能用（安卓 6.0 起系统支持 BLE MIDI），但延迟普遍高于有线，认真练优先 USB 直连。

## 三、接不上 / 没声音，多半是线的问题

- OTG 转接线是最大嫌疑：不少转接线只能充电不能传数据，换一根确认支持数据的
- 部分USB 线只供电不传数据，同样要换
- 接线顺序有讲究：键盘开机 → 插 OTG → 插设备 → 再打开应用
- 安卓 6.0 以下对 MIDI 支持不完善，设备太老也会认不到

## 四、怎么选

- **只想试试跟弹好不好玩**：触屏够用，装上就能玩
- **想认真学琴**：触屏玩几天确认兴趣后，就安排一台入门 MIDI 键盘，这钱省不掉
- **已经有电钢琴**：一根 OTG 线的事，接上就是完全体
