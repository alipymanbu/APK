# 怎么把歌词调成逐词卡拉OK，外语歌顺便翻译着看

> 搜「歌词逐词高亮」「歌词翻译怎么开」的人，多半是刚装上 Echo Music、在播放页没找到入口。本篇按「进歌词页 → 调样式 → 开翻译」的顺序讲，两分钟搞定。

## 一、先说结论

Echo Music 的歌词默认就在，只是入口藏得浅：播放任意一首歌，点播放页的歌词区域（或把播放页往上滑）就能进全屏歌词。逐词高亮、动画样式、外语翻译三件事都在歌词相关设置里调。

## 二、进入歌词页的两种方式

1. 播放任意一首歌，在播放页点一下歌词区域；
2. 或者直接把播放页向上滑，进入全屏歌词视图。

进了全屏歌词，唱到哪一行滚到哪一行；支持逐词同步的曲目，一行里唱到哪个词、哪个词就单独点亮，效果接近卡拉OK机。

## 三、样式怎么调

歌词页提供多种显示形态，常见的是这几类：

- **逐行滚动**：整行跟随进度移动，最省电的基础形态；
- **逐词高亮**：行内按唱到的词逐个点亮，节奏感强的歌尤其明显；
- **动画风格切换**：滚动、渐变等动画可以换着挑，选自己看着最舒服的。

不同版本的菜单名字和层级略有出入，找不到某个选项时，去设置页顶部的搜索框直接输「歌词」两个字，能一步定位到相关设置项；还找不到，多半是手上这版没带这个选项。

歌词对不上或干脆不显示时，先换歌词源——Echo Music 提供 Lyrics+ 这类歌词来源，覆盖面和准确率比早期来源更好，多数「歌词错位」换个源就能解决。

## 四、外语歌词翻译成中文

听非中文歌时，翻译是独立开关，不配置也不影响歌词原文显示：

1. 进 **设置 → AI Settings（AI 设置）**；
2. 打开歌词翻译；
3. 界面上有现成翻译开关的直接开；需要接翻译服务的，按界面提示填 Provider 与 API Key（可选 OpenRouter、ChatGPT、Gemini 或自定义服务）。

三点提醒：

- 翻译要联网调用接口，第三方翻译服务一般有免费额度，超出后按该服务的规则付费，用不用自己权衡；
- 只想看原文的话，把翻译开关关掉即可，其余功能不受影响；
- API Key 是你自己的账号凭据，别截图发到公开场合。
