# 免费额度和 API Key 怎么配，两种用法一次讲清

> 一句话：Chatbox 接模型有两条路——登录账号吃免费额度，或者填自己的 API Key。这篇讲清两条路各适合谁、点数怎么个扣法、Key 在哪填，帮你一次选对。
> **相关文档**：[安卓版安装与首次启动.md](安卓版安装与首次启动.md) · [多模型客户端和网页版AI的区别.md](多模型客户端和网页版AI的区别.md)

## 先搞懂"计算点数"这把尺子

登录账号用法下，对话、联网搜索、文件解析这些能力统一按"计算点数"扣。三件事决定你的点数撑多久：

| 因素 | 影响 |
| --- | --- |
| 用的模型 | 不同模型消耗不同点数，选低成本模型明显更耐用 |
| 用什么功能 | 文件解析、联网搜索这类加重活，消耗高于纯对话 |
| 订阅档位 | 免费档每日重置一笔小额点数；付费档月给一大笔 |

付费档位（Lite / Pro / Pro+）的定价和点数配比会调整，动手前以应用内或定价页当时的显示为准，这里不写死数字。判断口径很简单：先白用免费档，天天顶到上限再考虑订阅。

## 路 A：登录账号，领额度就用

适合"先试试"的人：注册、登录、领免费额度，然后直接开聊。没有 Key、没有配置，手机上从打开应用到发出第一条消息也就一两分钟。额度用尽当天就等次日重置，或者升级档位。

## 路 B：自带 API Key（BYOK）

适合已经在模型平台有 Key、想自己管用量和账单的人。配置路径：

1. 打开侧边栏（手机端点左上角 ☰），进**设置**；
2. 选**模型提供方**，挑你的平台（OpenAI、DeepSeek 等）；
3. 填入 **API Key** 和 **API 主机**——API 路径一般留默认即可；
4. 保存，回到对话界面选模型开聊。

这条路上应用本身不产生费用，开销发生在你的模型平台账号里。各家平台的计费规则差异不小，选型前先看一遍平台的定价页，别只看对话单价。

## 常见的三个疑问

- **没 Key 能长期用吗？** 能，路 A 就是为此设计的；免费档对轻度用户够撑，重度再谈订阅。
- **两条路能混用吗？** 能。同一个设置页随时切换，很多人日常吃额度、赶工时切自己的 Key。
- **Key 会被上传吗？** Key 存在你设备上的应用配置里，这条应用的设计取向是"本地优先"——聊天记录同样默认存本地。
