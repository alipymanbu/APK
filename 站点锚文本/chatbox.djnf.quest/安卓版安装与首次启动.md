# 安卓版安装与首次启动，从下载到能对话

> 一句话：安卓端装 Chatbox 走"拿到 APK → 允许一次未知来源 → 装完启动登录"三段，全程五分钟内。这篇把每一步会弹什么、点什么写清楚，装完第一次打开的两种起步方式也一并交代。

## 装之前，先确认两件事

1. **手机留够空间**：安卓安装包在百兆上下，别在存储告警的状态下硬装。
2. **想好获取渠道**：常见两条路——Google Play 商店直接搜（适合习惯商店更新的用户），或者直装 APK（不用商店账号）。无论哪条路，装的都是同一个安卓客户端。

走 APK 直装的话，[Chatbox 安卓版下载安装](https://chatbox.djnf.quest/)这个页面上备好了安装文件资源的获取入口和逐步说明，转存到自己网盘再下载，比到处找安装包稳。

## 安装四步

1. **下载 APK 到手机**：从网盘转存后下载，或从你选定的渠道拿到安装包。
2. **点开安装包**：系统提示"禁止安装未知来源应用"时，按弹窗里的"设置"进去，给下载时用的那个应用（浏览器或文件管理器）勾选"允许安装未知应用"。
3. **回来点安装**：进度条走完即装好。不同品牌文案略有出入，含义一致。
4. **打开应用**：首次启动会看到欢迎界面和登录提醒，见下一节。

## 第一次打开，两条路二选一

启动后的选择和"你要怎么用"直接挂钩：

- **图省事**：按欢迎界面提示注册并登录，领取免费额度就能直接开聊，什么都不用配。
- **自带 Key**：已经有模型平台的 Key 的话，点左上角菜单（☰）展开侧边栏 → 设置 → 模型提供方，选你的提供方、填入 Key 和 API 主机，保存后回到对话界面就能用。具体每种提供方怎么填，见 [免费额度和APIKey怎么配.md](免费额度和APIKey怎么配.md)。

两条路随时可换：先用免费额度试手感，之后想换自己的 Key，同一个设置页里改就行。

## 卡住了往哪看

- 安装按钮点了没反应 → 回看第二步，九成是未知来源授权没给到下载用的那个应用。
- 启动后要求登录/许可 → 领免费额度那条路没走通，可以先切自带 Key 顶上，再慢慢排查账号问题。
- 想先了解这个应用本身值不值得装 → [多模型客户端和网页版AI的区别.md](多模型客户端和网页版AI的区别.md) 里把客户端和网页版的差异摊开比过了。
