# 收不到新邮件的排查办法：从电池策略查到同步条件

> FairEmail 收不到新邮件，头号原因不是账号而是系统把后台同步杀了。本篇按出现概率排排查顺序：电池策略 → 自启动 → 同步条件 → 账号本身。

---

装好 FairEmail 后「邮件不进来」，九成出在安卓系统一侧：它靠常驻前台服务与服务器保持长连接推送新邮件，正好撞在各家电池管理的枪口上。按下面的顺序查，绝大多数在第一、二步就解决。

## 第一步：确认常驻通知还在

通知栏找那条低优先级的常驻通知——它是前台服务的标志。被你划掉、或被系统按「不重要通知」隐藏，推送机制就没了保障。找不到就进系统设置把它的通知重新打开。

## 第二步：电池策略与自启动放行

系统设置 → 应用 → FairEmail → 电池，改为「不受限制 / 允许后台运行」；国产 ROM 还要到手机管家的「自启动管理」里放行。各品牌叫法不同：

| 品牌 | 关键路径 |
| --- | --- |
| 小米 / Redmi | 应用管理 → 省电策略 → 无限制；自启动管理打开 |
| 华为 / 荣耀 | 应用启动管理 → 手动管理，三个开关全开 |
| 三星 | 后台使用限制 → 移出「深度休眠应用」 |
| OPPO / 一加 / vivo | 耗电管理 → 允许后台运行；自启动放行 |

两个通杀动作：关掉省电模式再观察；最近任务界面把卡片加锁防一键清理。注意部分系统（尤其 MIUI 系）会在重启或系统更新后重置这些设置，复发时先回来复查。

## 第三步：看同步条件有没有被改过

账号设置里的同步选项若限定「仅 Wi-Fi」或「仅充电时同步」，换到流量环境或拔掉充电线邮件就停了。安卓的「数据节省器」也会限后台流量，把应用加进不受限名单。

## 第四步：排除账号一侧

下拉刷新收件箱手动收一次：能收到说明服务器连接正常，问题确实在后台；收不到则回到账号配置检查服务器信息与授权码是否失效。改过邮箱密码的，回账户设置里更新密码即可，不必删账号重配。

## 判断口诀

- 开着应用才来邮件、退出去就断 = 后台被杀，回第二步；
- 常驻通知在、邮件也不进 = 查同步条件，回第三步；
- 手动刷新也收不到 = 账号一侧，回第四步。
