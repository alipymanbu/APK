# 邮箱账号配置方法：OAuth 一键授权与手动 IMAP 的分界

> 本篇讲把各种邮箱账号接入 FairEmail 的三条路径：Gmail / Outlook / Yahoo 走 OAuth 授权，其他服务商手动填 IMAP / SMTP，开了两步验证的账号用应用专用密码（授权码）。

---

FairEmail 只是客户端、不提供邮箱地址，配置账号前先确认自己在某个邮箱服务商那里有账号。它接入几乎所有服务商，但配置方式分三条路，先对号入座再动手能省一半时间。

## 一、先判断走哪条路

| 你用的邮箱 | 配置方式 |
| --- | --- |
| Gmail / Google Workspace | 向导里选 Gmail (OAuth) |
| Outlook / Live / Hotmail / Office 365 | 向导里选 Outlook (OAuth) |
| Yahoo / AOL / Sky | 对应的 OAuth 入口 |
| QQ 邮箱、163、企业自建服务器 | 「其他提供商 (IMAP)」手动填 |
| 纯 Exchange（只开 EWS） | 配不了，换支持的客户端 |

POP3 也支持，但多设备场景下邮件被一台设备拉走后其他设备就看不到了，能用 IMAP 就别用 POP3。

## 二、OAuth 授权：三步走完

1. 首次启动同意许可协议后进入快速设置向导；
2. 选带 (OAuth) 字样的入口，输入邮箱地址后跳到服务商授权页登录并允许；
3. 回到应用，服务器地址、端口、加密方式已全部自动填好，保存完成。

两个容易卡的点：向导里若同时出现 Gmail (Android) 与 Gmail (OAuth)，前者只能用手机上已登录的 Google 账号，想单独配一个账号选后者；Google「高级保护计划」开着时不允许第三方邮件客户端接入。

## 三、手动 IMAP：备齐四样东西

向导里没有你的服务商时选「其他提供商 (IMAP)」，填入地址和密码点「检查」，能查到自动配置就直接保存；查不到进手动设置，需要准备：

- IMAP 收信服务器地址与端口（常见 993，SSL/TLS）；
- SMTP 发信服务器地址与端口（常见 465 配 SSL/TLS，或 587 配 STARTTLS）；
- 用户名（多数服务商就是完整邮箱地址）；
- 密码或应用专用密码。

收信（账户）与发信（身份）是两个独立配置项，都要填——漏掉发信那半边就只会收不会发。具体参数在服务商帮助页搜「IMAP」基本都能找到。

报「无法连接」时先逐字核对服务器主机名，再检查 SSL/TLS 与 STARTTLS 有没有选反；个别服务商过不了证书透明度校验，可在账户选项里关掉这项校验再试。

## 四、两步验证账号：先生成授权码

QQ 邮箱、163 等国内服务商对任何第三方客户端都要求「授权码」而不是登录密码；Gmail 走 OAuth 不受此限；Apple iCloud 一律要求 App 专用密码（需先开两步验证，在 account.apple.com 生成；改过 Apple 主密码后所有专用密码自动吊销，要重新生成）。

生成入口一般在服务商网页版的「账户安全 / 授权管理 / POP3-IMAP 服务」里。粘贴时注意别带上首尾空格；报认证失败时先人工核对输入框内容，密码管理器偶尔会自动填成旧密码。

---

配置好的账号默认双向同步并保留离线副本。装应用、拿安装包的入口与安装步骤在 [FairEmail 介绍站](https://fairemail.wxhp.skin/)；配好后收不到新邮件的场景翻 [收不到新邮件的排查办法.md](收不到新邮件的排查办法.md)，整体使用感受参考 [开源邮件客户端使用体验.md](开源邮件客户端使用体验.md)。
