# 开源邮件客户端使用体验：一个把隐私当默认值的安卓选择

> 本篇整理 FairEmail 这款开源安卓邮件客户端的实际使用角度：协议支持、默认隐私设计、同步机制与付费边界，帮正在挑选邮件应用的人判断它是否对味。

---

在安卓上挑邮件客户端，多数人先看界面好不好看，用一段时间才开始在意后台耗电、广告推送和隐私泄露。FairEmail 属于反过来的那一类：界面朴素克制，但把协议支持与隐私防护做到了很深的程度。

## 协议面：几乎所有邮箱都能接

它走标准协议——IMAP / POP3 收信、SMTP 发信，Gmail、Outlook、Yahoo 提供一键授权向导，QQ 邮箱、163、企业自建服务器走手动 IMAP。明确的例外是微软私有的 Exchange Web Services 与 ActiveSync：纯 Exchange 账号接不了，这一点在动手前就该知道。

多账号场景处理得体面：几个收件箱合成一个统一列表，发信时点一下就能切换身份；草稿、已发送、垃圾箱都对应服务器上的真实文件夹，手机上删掉的信服务器同步进垃圾箱，不会本地另造一套。

## 隐私面：默认值偏保守，但讲得清道理

远程图片默认不直接加载（防追踪像素）、邮件里的链接先弹确认（防钓鱼）、可疑邮件重排排版让伪装链接现形、发件人认证失败的邮件带警告标识。这些防护每一条都能按需放宽——对信任的发件人可以选「始终显示图片」——但默认状态是防着的。

应用本身无广告、无统计埋点，邮件数据不经第三方服务器中转，只落在设备和邮箱服务商两端。权限要求也少：收发邮件只靠网络权限，通讯录和通知权限不给不影响主功能。

## 同步面：推送而非轮询

靠 IMAP IDLE 保持长连接，新邮件推着到，不是隔几分钟问一次。代价是它需要常驻后台——通知栏那条低优先级常驻通知就是前台服务的标志。国产 ROM 的电池管理容易把它当后台滥用杀掉，装完第一件事应该是把电池策略放行，否则「收不到新邮件」几乎必然出现，排查思路见 [收不到新邮件的排查办法.md](收不到新邮件的排查办法.md)。

## 付费边界

收发邮件的全部基础功能不收费；独立通知声音、定时发送、回复模板、按规则自动归类、应用锁属于付费 Pro 项。建议先拿基础功能跑顺日常收发，确认自己真缺哪样再补，多数人停在基础层就够用。

## 小结

看重开放协议、隐私默认值与同步及时性的用户，FairEmail 在安卓端是值得认真考虑的选择；想要花哨界面或内置日历套件的人则会觉得它寡淡。功能与界面的完整介绍、安装文件资源的获取入口，见 [FairEmail 介绍站](https://fairemail.wxhp.skin/)；第一次装的话，账号配置跟着 [邮箱账号配置方法.md](邮箱账号配置方法.md) 走一遍即可。
