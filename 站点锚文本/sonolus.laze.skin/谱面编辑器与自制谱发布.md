# Sonolus 谱面编辑器与自制谱发布

> 想在 Sonolus 里做自己的谱：工具在网页端、发布走服务器审核制，本篇讲从制作到上架的整条链路。

Sonolus 的创作生态分两层：手机客户端负责玩与提交入口，**谱面本身在网页编辑器里做**——手机、电脑浏览器都能打开，不用装任何东西。

## 一、三个常用网页工具

| 工具 | 地址 | 用途 |
| --- | --- | --- |
| Horizon Editor | horizon-editor.sonolus.com | 通用谱面编辑器，支持实时预览 |
| Next SEKAI Editor | next-sekai-editor.sonolus.com | 针对 PJSK 类玩法，可直接打开 `.sus`、`.usc` 老谱文件 |
| Sonolus Studio | studio.sonolus.com | 制作皮肤、背景、音效、粒子等素材 |

这些地址可在 Sonolus 服务器的置顶指南与社区百科里核对，以页面当时显示为准。

## 二、制作阶段

1. 导入音频后先定 **BPM** 与起始偏移——这两项错了整张谱都会漂，后面很难救。
2. 摆音符、调速度变化曲线，随时用实时预览检查手感。
3. 完成后点编辑器的 **Save** 导出关卡数据文件，这就是发布用的东西。
4. 手里有 `.sus`、`.usc` 格式旧谱的，用 Next SEKAI Editor 直接转过来，不必重做。

## 三、发布是审核制

1. 登录目标服务器，在关卡（Level）区点 **Create**，按表单填标题、作者、难度等。
2. 新建关卡先是**草稿**：可以把草稿链接发给朋友试玩收意见，继续修改。
3. 改完点 **提交审核**，等服务器审核员过目，**通过后才会公开出现**在曲库里。
4. 被拒时意见里会写明原因，改完再次提交即可。

## 四、投稿前对着规范过一遍

各服务器规范不完全相同，但社区服务器公开的通用要求大致是：

- **音频**用 mp3 恒定比特率（变码率在部分设备会出播放问题），另配约 30 秒带淡入淡出的试听；
- **封面**约 400×400、清晰不糊；
- **元数据**填全：BPM 与同步必须正确，标题、作者、关键词、标签补上别名与异写，别人才搜得到；
- **可玩性**：谱面要能正常通关，避免会互相误触的堆叠音符；
- **素材版权**：不放露骨内容，不直接搬运商业音游素材（自己重绘的可以）。

谱还没打熟的话，先把服务器接起来练手感——步骤见 [自定义服务器怎么添加.md](自定义服务器怎么添加.md)；做出来的谱手感怪，多半是偏移与流速的问题，调法在 [判定偏移与流速调节.md](判定偏移与流速调节.md)。

还没装客户端的玩家，[Sonolus 玩法介绍站](https://sonolus.laze.skin/)里有引擎机制讲解与安卓端安装文件资源的入口。
