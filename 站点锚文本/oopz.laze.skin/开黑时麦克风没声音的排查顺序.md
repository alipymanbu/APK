# 开黑时麦克风没声音的排查顺序

> 队友听不见你、试麦没反应、电流声、回声——本篇按现象给排查顺序，均对照电脑客户端操作。
> **相关文档**：[开黑语音域与频道搭建思路](开黑语音域与频道搭建思路.md)

---

语音没声音的原因无非四类：麦克风被关、模式不对、设备选错、硬件或驱动问题。先按第一节五步走，大部分情况当场解决。

## 一、队友听不见你：五步速查

1. **麦克风开着吗**：看客户端左上角调音台的麦克风图标，关着就点开。
2. **音量是 0 吗**：鼠标悬浮到麦克风图标上会出现音量条，确认没被拉到 0。
3. **是不是按键说话**：调音台上显示键盘图标 = 按键说话模式，必须按住快捷键麦克风才采集；右键调音台可切换为自由发言。
4. **设备选对了吗**：右键调音台 → 「语音设置」，检查麦克风下拉框选的是不是正在用的设备；客户端启动后才插拔过设备的，重启客户端再试。
5. **试麦**：语音设置 → 「麦克风测试」 → 「开始试麦」，对着麦克风说话，看音量条动不动。

## 二、试麦音量条完全不动：输入断了

- 在语音设置里换其他输入设备试；
- 重新插拔麦克风，或换一个接口；
- 关闭 Windows 麦克风独占模式：控制面板 → 硬件和声音 → 声音 → 「录制」选项卡 → 双击麦克风 → 「高级」 → 取消「独占模式」；
- 去 Windows「开始 → 设置 → 声音」的输入设备里点「开始测试」，系统层面就收不到声音的话，问题在驱动或硬件，不在语音软件。

## 三、试麦有波动但队友听不到：输出断了

采集正常、播放有问题，按顺序查：输出设备别选错扬声器 / 耳机 → 重新插拔或换接口 → Windows「设置 → 声音」里对输出设备点「测试」→ 换一副耳机排除硬件问题。

## 四、电流声、声音糊

1. **先确认 AI 智能降噪开着**：右键调音台菜单里勾选；用声卡的用户注意，部分声卡自带降噪，和 AI 降噪叠加会让声音发糊，二选一关掉一个再听。
2. **把麦克风采样率降到 48000 Hz**：声卡或高端麦克风常默认更高采样率，超出软件支持范围就会出电流声。路径：系统「设置 → 声音 → 更多声音设置」，「录制」选项卡双击麦克风 → 「高级」 → 采样率选「2 通道，16 位，48000 Hz」，然后重启客户端。
3. 还不行，让对方检查**扬声器**采样率，方法相同，调低后同样重启客户端。

## 五、有回声

1. 右键调音台，确认「回声消除」是开启状态；
2. 检查频道里是否有人用**音响外放**——外放声会被他的麦克风再收一遍传回来，开黑全员用耳麦是最稳的做法。

## 六、还没解决

网页端用户先确认浏览器麦克风权限已允许（进语音频道时浏览器弹窗选「允许」，之前点过拒绝的要去地址栏站点设置里改回来），再重复第一节五步。网页版权限、调音台开关这类设置的图文说明，见 [Oopz 开黑语音介绍](https://oopz.laze.skin/)；域和频道的搭建思路反过来见[开黑语音域与频道搭建思路](开黑语音域与频道搭建思路.md)。
