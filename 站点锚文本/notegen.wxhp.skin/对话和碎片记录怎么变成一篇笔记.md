# 对话和碎片记录怎么变成一篇笔记

> 这篇写清它的核心工作流：对话页聊出来的内容、记录面板攒下的碎片，怎么一步步落到一篇完整的 Markdown 笔记里。

## 一、三个入口是一条产线

打开应用后，手机底部摆着三个常驻入口：**对话、记录、写作**。它们不是三个独立功能，而是同一条产线的三道工序——素材从对话和记录进来，在写作里成型，共用同一份数据。理解了这一点，界面就不用背了。

## 二、对话：先开口说，别急着排版

在对话页直接说「帮我写一篇笔记」，它会先调用工具弄清楚你想要的主题和内容，再动手生成——聊天里能看到「模型选择工具」「模型响应」这类调用痕迹，说明它不是简单地把你的话丢给模型。问答、生成、改稿都在同一个会话里完成。

Agent 的能力更进一步：授权后它可以读取和修改你的笔记、文件夹、标签与记录，配合长期记忆和知识库，问「我上周记的那件事」这类基于自己笔记的问题也能答上来。担心隐私的话，可以先只体验对话，不授读写权限。

## 三、记录：碎片先进收件箱

点「快捷」面板，能往同一处丢的东西比想象中多：

- 文本、截图、图片
- 链接、文件
- 录音、待办

素材攒着不用管结构，之后可以用**标签、搜索、时间和类型筛选**翻查。这个设计的好处是「记」的门槛极低——课堂上一句话、一条链接、一段会议录音，两秒丢进去就走，回头再处理。

## 四、整理与写作：落到 Markdown

素材够了，用**整理**功能按模板生成一篇 Markdown 初稿，然后进写作页慢慢磨。写作页是一个功能完整的 Markdown 编辑器：

| 能力 | 说明 |
| --- | --- |
| 基础排版 | 表格、任务列表、代码块、数学公式、图片 |
| 图表 | Mermaid 语法，画流程图不用外接工具 |
| 长文辅助 | 文档大纲、搜索替换、多格式导出 |
| AI 协作 | 补全、润色、精简、扩写、翻译 |

AI 能力可以直接用内置的免费模型体验基础功能，也可以在「设置 → 模型配置」里接入自己的 OpenAI 兼容服务，用哪个模型自己说了算。
