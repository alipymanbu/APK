# 换手机和跨设备同步怎么安排

> 笔记这种东西一用就是几年，换手机、换电脑时数据能不能完整带走的答案，这篇一次写清：默认存在哪、同步怎么配、不配会怎样。

## 一、默认是纯本地的

和多数云笔记不同，它**不要求注册登录**，装上就能用，没有订阅，核心功能免费。笔记和附件默认保存在手机本地，留下的是**标准 Markdown 文件和普通附件**——这意味着哪怕哪天不用了，用任何编辑器都能打开这些文件，知识不会被锁在专有格式里。

不配置同步的用法完全成立：单机用户、注重隐私的用户，可以直接当一本本地笔记用下去。

## 二、需要跨设备时的选择

在「设置 → 同步配置」里，可选的方式覆盖面不小：

| 方式 | 适合谁 |
| --- | --- |
| GitHub / Gitee / GitLab / Gitea | 有 Git 使用习惯的人，版本历史天然可追溯 |
| S3 对象存储 | 想自己掌控存储桶、按用量付费的进阶用户 |
| WebDAV | 手上有 NAS 或支持该协议的网盘，配置门槛最低 |

再往前一步，还可以自托管同步服务，让数据链路完全跑在自己的设备上——这是开源应用才给得到的选项。

## 三、换新手机的操作顺序

1. 旧手机上确认同步已配置且完成（或手动把本地文件夹整个备份）；
2. 新手机装好应用，安装相关的问题见 [安卓APK安装步骤与架构要求](安卓APK安装步骤与架构要求.md)；
3. 新手机上配置同一套同步方式，等待数据拉取完成。

因为底层是普通文件，这个迁移过程没有私有格式的转换环节——最坏情况就是手动把文件夹拷过去，笔记一条都不会丢。

## 四、桌面端与手机端的配合

五端覆盖意味着手机上随口记的碎片，回家可以在电脑上接着写。工作流怎么串、对话内容怎么沉淀成文，在 [对话和碎片记录怎么变成一篇笔记](对话和碎片记录怎么变成一篇笔记.md) 里有完整拆解。想先看看它的界面和功能全貌再决定装不装，[NoteGen 笔记应用介绍站](https://notegen.wxhp.skin/) 里有按真实截图的逐屏展示。
