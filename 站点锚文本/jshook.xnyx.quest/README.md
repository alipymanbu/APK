# jshook 站点导航

jshook（JsHook）是一款安卓上的注入框架工具：用 JavaScript 写脚本，由它把脚本注入目标应用，Java 层和 native 层都能挂上钩子。这里围绕它的两个高频搜索疑问各整理了一篇说明。

- [免root激活路线怎么选.md](免root激活路线怎么选.md)：没 root 的设备走哪条路、LSPatch 修补流程与四类环境对照；
- [脚本不生效怎么排查.md](脚本不生效怎么排查.md)：注入框架怎么选、脚本改了没反应的五步排查顺序。

想看它的能力构成、界面实拍与安装包获取入口，去 [JsHook 介绍站](https://jshook.xnyx.quest/) 即可。

*本目录为第三方整理的资料页，与工具开发者无隶属关系。*
