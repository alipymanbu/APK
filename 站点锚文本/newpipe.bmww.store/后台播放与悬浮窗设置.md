# 后台播放与悬浮窗设置：锁屏不断音的正确姿势

> 用 NewPipe 听歌、听播客时一锁屏就没声、通知栏没有控制条，多半是权限没给对。本篇把后台播放与悬浮窗两种形态的设置一次讲清。
> **本目录其他篇**：[不用Google服务怎么看视频.md](不用Google服务怎么看视频.md) · [视频离线保存目录怎么选.md](视频离线保存目录怎么选.md)

## 一、三种形态，一个按钮切

NewPipe 的播放页控制栏上有三个形态按钮，随时互切、进度不丢：

| 形态 | 画面在哪 | 典型用法 |
| --- | --- | --- |
| 全屏 / 普通 | 应用内 | 正常看视频 |
| 后台播放 | 只剩通知栏控制条 | 锁屏听歌、听播客 |
| 悬浮小窗 | 浮在其他应用上 | 一边聊天一边看 |

切后台后声音继续，此时只拉音频流，比挂着画面省一大截流量和电。

## 二、后台播放的两个前提权限

1. **通知权限**：后台控制条是一条常驻通知。首次启动弹的「允许通知」要点允许；已经拒绝的到 `设置 → 应用 → NewPipe → 通知` 补开。锁屏没声九成是它没给。
2. **后台运行放行**：部分国产 ROM 的省电策略会杀后台服务。把 NewPipe 加进电池优化白名单（EMUI 路径：`设置 → 应用 → 高级 → 忽略电池优化`），其他品牌搜「自启动」或「后台运行」找同类开关。

MIUI 还有一个已知坑：`设置 → 通知 → 锁屏通知格式` 要设成显示内容一类，否则锁屏后控制条不出现。改完重启应用生效。

## 三、悬浮窗的开关与用法

- 权限入口：`设置 → 应用 → NewPipe → 显示在其他应用上层`；没给权限时切小窗会被系统静默拦下，表现为「点了没反应」。
- 小窗拖边缘缩放、拖标题栏挪位置，点小窗回应用、点关闭结束播放。
- 所有 Android 版本都能用悬浮窗，系统弹「允许绘制在其他应用上」时允许即可。

## 四、顺手开的无缝切换

设置里打开「最小化到后台」后，看视频时按 Home 切走，画面停、音频无缝续上，切回来黑屏一两秒画面恢复——适合边听边刷别的应用。个别很老的视频不支持这种切换，会有短暂停顿，属正常现象。

客户端还没装的话，先到 [NewPipe 介绍站](https://newpipe.bmww.store/)拿安装文件资源，装好再回来对着设置。
