# 视频离线保存目录怎么选：一次授权、下载不失败的设置法

> NewPipe 里点下载就失败、下完找不到文件，问题几乎都出在保存目录的授权上。本篇按系统版本讲清目录怎么选、失败按什么顺序排查。
> **本目录其他篇**：[不用Google服务怎么看视频.md](不用Google服务怎么看视频.md) · [后台播放与悬浮窗设置.md](后台播放与悬浮窗设置.md)

## 一、下载入口与可选内容

播放页的下载按钮（向下箭头）点开，可以分别选：

- **内容类型**：视频 / 音频 / 字幕，三者独立，只勾音频时体积小很多；
- **格式与分辨率**：144p 到 4K 档，取决于源视频提供哪些档位；
- **字幕**：有字幕的视频可单独存。

## 二、保存目录按系统版本选（最关键的一步）

NewPipe 走系统的存储访问框架（SAF）授权目录，规则按版本分：

- **Android 11 及以上**：不能选 `Download` 目录本身，也不能选内部存储 / SD 卡的根目录。正确做法是**新建一个专属空文件夹**，在文件选择器底部点「使用此文件夹」完成授权。
- **Android 10 及以下**：选 `Download` 下的子目录一般没问题，同样建议单独建一个，方便找文件。

路径在 `设置 → 下载` 里分别给视频和音频指定，视频音频可以指到同一个文件夹省事。每次改动都会弹一次系统文件选择器，授权一次即可。

## 三、下载失败与找不到文件，按五步查

1. 目录是不是按第二节选的（Android 11+ 选了 `Download` 本身必失败）；
2. 文件选择器底部的「使用此文件夹」点了没有——没点等于没授权；
3. `设置 → 下载` 里的「使用 SAF」开关状态（SD 卡老出问题的设备可以反过来关掉 SAF 走传统方式）；
4. 应用权限里有没有给「存储 / 媒体」；
5. 内部存储和 SD 卡互换试一次，能立刻分清是卡的问题还是目录的问题。

精简 ROM 还可能缺处理文件选择的系统组件（DocumentsUI），这种场景需要先补系统组件。

## 四、两个容易误解的点

- **应用内不播放已下载的文件**：离线保存出来的是普通媒体文件，用手机自带的视频 / 音乐播放器打开即可，这是设计取舍不是故障；
- **重装不影响已下载的文件**：媒体文件在普通目录里，卸载应用还在；但订阅、播放列表、设置存在应用数据库里，卸载即丢，重装前先在「设置 → 备份和还原」里导出。

客户端版本与获取方式见 [NewPipe 介绍站](https://newpipe.bmww.store/)，装好后按本篇设好目录，第一次下载就能成。
