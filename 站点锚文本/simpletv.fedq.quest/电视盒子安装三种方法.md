# SimpleTV 装到电视盒子的三种方法

> SimpleTV 是一个打开即看的安卓电视直播应用，手机、平板、电视盒子装的是同一个安装包。电视上没法直接用浏览器下载 APK，所以这篇按设备情况把三种安装路子一步步说清楚，选一种照做就行。
> **相关文章**：[频道打不开怎么排查.md](频道打不开怎么排查.md) · [打开即看型直播应用使用心得.md](打开即看型直播应用使用心得.md)

## 一、先选路子

| 方式 | 前提 | 适合谁 |
| --- | --- | --- |
| U 盘安装 | 一个 U 盘 + 一台能拷文件的电脑或手机 | 绝大多数盒子与电视，最通用 |
| 当贝市场远程推送 | 盒子和手机都装了当贝市场 | 不想拔插 U 盘、家里已有当贝市场 |
| ADB 安装 | 电脑 + 会用命令行 | 手边没 U 盘、愿意折腾的开发型用户 |

电视端的系统要求同样是安卓 6.0 及以上。安装包从哪里拿、手机上怎么装，[SimpleTV 介绍站](https://simpletv.fedq.quest/)的下载安装页有完整步骤。

## 二、U 盘安装（最通用）

1. 先在电脑或手机上把安装包下载下来，拷进 U 盘；
2. U 盘插到盒子或电视的 USB 口；
3. 在电视上打开自带的「文件管理」「媒体中心」这类应用，找到 U 盘里的 APK 文件，选中安装；
4. 弹出「禁止安装未知来源应用」提示时，进「设置 → 安全」把「未知来源」打开，再回来装一次。

**TCL 电视的特例**：TCL 的系统会把 U 盘里的 APK 文件藏起来，普通文件管理器里根本看不到它。处理办法是改用 TCL 自带的电视卫士类应用进入 U 盘安装，具体入口名称以你的系统版本显示为准。

## 三、当贝市场远程推送（免 U 盘）

当贝市场的「远程推送」能把手机里的安装包直接发到电视上：

1. 盒子和手机都装好当贝市场；
2. 在盒子上的当贝市场里进「管理」，找到「远程推送」；
3. 手机扫码登录推送页面，点上传文件，把提前下载好的 APK 传上去；
4. 电视端会提示安装，确认即可；同样可能需要先允许未知来源。

推送连不上时先查一件事：**手机和电视必须连同一个 WiFi**。除了扫码，电视端还会显示一个网址，用电脑浏览器打开它走「上传文件」流程，效果一样——家里没 U 盘时这条路很顺手。

## 四、ADB 安装（进阶）

前提：电视打开开发者模式并允许 USB / 网络调试（通常在「设置 → 关于」里连按「版本号」几次解锁），电视和电脑连同一个网络。

```bash
# 1. 让电脑连上电视（IP 在电视的网络设置里能看到）
adb connect 192.168.1.100:5555

# 2. 安装（路径换成你电脑上安装包的实际位置）
adb install SimpleTV_v1.0.3.apk
```

出现 `Success` 就装完了，在电视的应用列表里找得到。不同品牌的调试端口可能不是 5555，以设备说明为准。

## 五、装完之后

打开应用等频道列表初始化完成，就能直接选台。如果多数频道转圈、报「播放失败」，大概率不是装错了，而是网络条件不满足——部分频道只在 IPv6 网络下提供播放，排查步骤看[频道打不开怎么排查.md](频道打不开怎么排查.md)。
