# 命令格子玩法与常用命令

ShizukuRunner 的主界面就是一面「命令格子墙」：每个格子存一条命令，点格子上的运行键就执行。这篇把格子的用法和社区里最常存进去的命令整理成一份速查，命令都来自公开的安卓调试文档，免 root 设备借助 Shizuku 的 adb 权限通道就能跑。

想直接装一个试试，可以到 [shizukurunner 命令盒子](https://shizukurunner.qjxz.skin/) 拿安装文件资源；前置的 Shizuku 链路见 [Shizuku激活与授权步骤](Shizuku激活与授权步骤.md)。

## 一、格子怎么用

- **存命令**：选中一个格子点「更改命令」，把命令本体贴进去。网上抄来的命令带着 `adb shell` 前缀的，要去掉前缀只留后面的部分——Runner 本身就是替你发 shell 的那一层，带着前缀反而会报错。
- **起标题**：长按格子可以改标题，给命令起个「半速动画」「锁90Hz」这类一眼能认的名字。
- **执行与读结果**：点格子右侧的运行键。没有红色提示就是执行成功了——`settings put` 这类命令成功时本来就静默完成；有红字先查 Shizuku 链路，再核对拼写。
- **格子数量**：v17 起格子数目可以自定义，命令多就多排几行。
- **备份**：v17 起支持把全部命令卡片导出成备份文件，换手机、重装后一键导入复原。

## 二、屏幕与显示

| 想做什么 | 查看当前值 | 修改 | 恢复默认 |
| --- | --- | --- | --- |
| 改屏幕密度 | `wm density` | `wm density 420` | `wm density reset` |
| 改分辨率 | `wm size` | `wm size 1080x2400` | `wm size reset` |

动手前先跑一遍查看命令记下原值，改激进界面乱了也有退路。这两个场景的完整操作在 [免root改屏幕密度和动画速度](免root改屏幕密度和动画速度.md) 里展开。

## 三、动画速度

把三个动画缩放都调小，界面切换会明显变快：

```sh
settings put global window_animation_scale 0.5
settings put global transition_animation_scale 0.5
settings put global animator_duration_scale 0.5
```

`0.5` 是半速，`1` 是系统默认。恢复就是把三条的值改回 `1`。这组键是 AOSP 通用的，绝大多数品牌都认。

## 四、应用管理

| 想做什么 | 命令 |
| --- | --- |
| 列出第三方应用 | `pm list packages -3` |
| 卸载某个应用（当前用户） | `pm uninstall --user 0 包名` |
| 找回刚卸载的系统应用 | `pm install-existing 包名` |
| 清除某应用数据 | `pm clear 包名` |

系统应用卸载不可乱来：桌面、系统界面这类被卸了可能黑屏。优先用 `pm uninstall --user 0`（只对当前用户隐藏，还能救回来），拿不准的包别碰。

## 五、两个保护机制

- **输出超 1000 字符会被掐断**，返回值 141——这是防卡死的保护，不是填错了。想看长输出，把结果重定向到文件再看。
- **`logcat` 这类停不下来的命令别在格子里跑**，它会一直占着进程；真踩到了重启手机解决。
