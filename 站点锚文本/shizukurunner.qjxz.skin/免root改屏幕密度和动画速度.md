# 免root改屏幕密度和动画速度

改屏幕密度（dpi）和动画速度是免 root 玩机里最高频的两个需求：前者让屏幕显示内容变多变大，后者让系统观感变快。借助 Shizuku 提供的 adb 权限，ShizukuRunner 可以在手机上直接完成这两件事，不用连电脑。这篇把两条操作从头到尾走一遍，包含查值、修改与恢复。

操作前确认 Shizuku 服务在跑、Runner 已授权；没做过的先看 [Shizuku激活与授权步骤](Shizuku激活与授权步骤.md)。安装包从 [shizukurunner 命令盒子](https://shizukurunner.qjxz.skin/) 获取。

## 一、改屏幕密度

### 1. 先查当前值

在 Runner 的一个格子里填（记得网上抄的命令要去掉 `adb shell` 前缀）：

```sh
wm density
```

点运行，输出类似 `Physical density: 440`——把 `440` 记下来，这是恢复的退路。

### 2. 修改

再存一条：

```sh
wm density 400
```

数值越小界面元素越小、一屏显示越多；想字大就往上调。没有红色提示即生效，多数机型界面会立刻重排。

### 3. 恢复

改过头界面挤成一团、按钮点不到时，用系统设置里的「显示大小」先把可读性调回来，再跑：

```sh
wm density reset
```

实在点不到 Runner 图标，让手机保持解锁，用任一能执行命令的方式（比如连电脑跑同一条 reset）也能救回来。

## 二、改动画速度

动画缩放由三个系统键控制，一起改才有完整观感。在 Runner 里存三条命令：

```sh
settings put global window_animation_scale 0.5
settings put global transition_animation_scale 0.5
settings put global animator_duration_scale 0.5
```

- `1` 是系统默认，`0.5` 是半速（更快），追求「秒开」可以试更低的值；
- 三条都跑完且无红字提示即生效，切几个应用感受一下；
- 恢复默认就把三条的值改回 `1` 再各跑一遍。

这组键是 AOSP 通用的，绝大多数品牌都认；改坏了也不伤系统，填回原值即可。

## 三、改完顺手做的两件事

1. **把命令存成带标题的卡片**：长按格子起名「密度400」「半速动画」，下次一键切换；换手机前用 v17 的导出备份带走，新机导入即复原。
2. **重启手机后命令「失效」了**：不是命令没了，是 Shizuku 服务掉了。进无线调试页面回 Shizuku 点一次启动，格子里的命令照常能跑。

更多能存进格子的命令（分辨率、锁刷新率、卸载预装等）见 [命令格子玩法与常用命令](命令格子玩法与常用命令.md)。
