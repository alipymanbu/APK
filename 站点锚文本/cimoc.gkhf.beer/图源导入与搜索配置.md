# Cimoc 图源导入与搜索配置

> 本篇讲 Cimoc 最关键的一步：把图源配起来。包括手动添加图源、导入 JSON 配置、聚合搜索怎么用，以及搜不到漫画时的排查思路。离线缓存与备份见 [离线缓存与备份迁移](离线缓存与备份迁移.md)。

---

装好 Cimoc 第一次打开，很多人会愣住：主界面四个标签页都是空的，搜索也什么都没有。这不是装坏了——Cimoc 定位是阅读器框架，本身不收录任何漫画，内容这层由你自己导入的图源决定。图源配置因此成了装完后唯一必做的一步。

## 手动添加一个图源

1. 打开 Cimoc，点左上角三横图标拉出侧边菜单；
2. 选择「图源」进入管理页；
3. 点右上角三点菜单，选「手动添加图源」；
4. 依次填写**图源 ID、图源名称、图源网址**三项，点右上角对钩保存。

保存后图源列表里就会出现这个源，长按或勾选可以控制启用与停用。

## 导入 JSON 配置

图源地址通常是社区维护的一份 JSON 配置链接，一次能带进一批源：

1. 同样在「图源」页，点右上角三点菜单选「导入图源」；
2. 把图源配置链接粘贴进弹窗，点确定；
3. 底部提示导入成功后，图源列表会多出一批站点，逐个勾选启用即可。

建议多启用几个源：单一源加载失败时有备选，聚合搜索的覆盖面也更大。

## 聚合搜索与线路切换

图源配好，搜索才算真正开始：

- 回主界面点右上角放大镜，输入书名或关键词；
- 结果会按已启用的图源聚合返回，右上角能看到来源信息；
- 同一部漫画常来自多个源，选一条线路进入详情页即可开读；
- 阅读页里点菜单（倒三横图标）可以随时换线路——某条线路加载慢或失效时，切一条就能接着看，不用中断阅读。

## 搜不到时的排查

- **对应源没启用**：回「图源」页检查勾选状态，Cimoc 的搜索范围完全取决于启用的图源；
- **图源地址失效**：社区配置会不定期更新地址，重新导入一份新的 JSON 再试；
- **书名关键词问题**：换个更短的书名核心词搜，聚合结果比想象中准。
