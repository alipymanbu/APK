# yoki 安卓端下载安装步骤

> 本篇讲怎么把 yoki（yoki星球）的安卓安装包拿到手并装进手机：从网盘转存、下载，到放行安装权限、完成安装，五步走完，附常见安装问题的处理。
> **相关文档**：[语音派对与游戏陪玩玩法盘点.md](语音派对与游戏陪玩玩法盘点.md) · [新手安全使用注意事项.md](新手安全使用注意事项.md)

---

## 一、装之前先确认

| 项目 | 要求 |
| --- | --- |
| 系统 | 安卓系统，近几年的主流机型都满足 |
| 空间 | 建议预留 1GB 以上（安装包约 217 MB，解压还要额外空间） |
| 网络 | 建议连 Wi-Fi 操作 |

## 二、五步装好

1. **打开分享页**：从 [yoki 星球介绍站](https://yoki.qhah.skin/)进入安装文件资源的获取入口，没登录网盘就先用手机号登录；
2. **转存**：勾选分享里的安装包，点「转存」，放进自己网盘——先转存再下载，文件跟着自己的账号走，之后随时能重新下载；
3. **下载**：在自己网盘里找到转存的文件，点「下载」到手机本地，记住保存位置（一般在「下载」目录）；
4. **放行权限**：安卓默认拦商店之外的安装包。在系统设置搜「未知」，给你用来打开安装包的浏览器或文件管理器允许「来自此来源的应用」；
5. **安装登录**：点安装包一路「继续」，装好后打开应用，同意协议，用手机号收验证码登录，填好兴趣标签就能开始用了。

## 三、装不上时的对照

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 点安装包没反应 | 没给「安装未知应用」权限 | 回到第四步放行 |
| 解析包出现问题 | 文件没下完整 | 删掉重新转存、重新下载 |
| 空间不足 | 剩余空间不够 | 清出 1GB 以上再装 |
| 安装被拦截 | 系统来源保护 | 按提示跳到设置页放行，不是文件坏了 |

## 四、装好之后

登录进去第一件事是把兴趣标签填准，系统推给你的人才对味；玩法入口怎么挑，见[语音派对与游戏陪玩玩法盘点](语音派对与游戏陪玩玩法盘点.md)。开聊之前，建议先花两分钟过一遍[新手安全使用注意事项](新手安全使用注意事项.md)。
