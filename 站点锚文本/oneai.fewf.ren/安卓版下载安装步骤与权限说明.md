# 安卓版下载安装步骤与权限说明

> 本篇讲把 OneAI 装到安卓手机上的完整流程：从哪拿安装包、安装时要注意什么、首次启动会要哪些权限。装好之后怎么用出效果，见 [AI提问怎么写效果更好.md](AI提问怎么写效果更好.md)；功能盘点见 [手机AI聊天助手功能与板块盘点.md](手机AI聊天助手功能与板块盘点.md)。

---

## 一、装之前核对三件事

| 项目 | 这份安装包的情况 |
| --- | --- |
| 版本 | 1.0.20（商店渠道后来还发过 1.0.21，更新内容是创作界面改版） |
| 体积 | 约 90 MB，建议预留两倍空间给安装解包 |
| 系统要求 | Android 5.0 以上（应用商店标注；部分渠道建议 6.0 以上更稳） |

应用商店对它标注了「年满 18 周岁」的适龄提示，介意的话先确认再用。

## 二、下载与安装四步

1. **进网盘分享页**：OneAI 的安装文件资源放在夸克网盘，入口整理在 [OneAI 介绍站](https://oneai.fewf.ren/)的下载页里；
2. **转存再下载**：网盘分享内容需要先转存到自己账号，然后在网盘 App 或网页版里把文件下载到手机存储；
3. **点开 APK 允许安装**：在文件管理里找到下载好的 APK（文件名以 OneAI 开头），系统提示「不允许安装未知来源应用」时选仍要安装——小米在弹窗里直接给开关，华为/荣耀进「更多安全设置」，OPPO/vivo 在弹窗里点「设置」后允许；
4. **打开并注册**：装完点开，用手机号收验证码注册登录就能用了。

电脑上操作的话，可以先下到电脑再用数据线传进手机「下载」目录；也可以在电脑上跑安卓环境直接装这份 APK。

## 三、首次启动的权限清单

| 权限 | 用途 | 不给会怎样 |
| --- | --- | --- |
| 存储读写 | 保存与读取生成的图片、音频等素材 | 无法保存生成的内容 |
| 麦克风 | 录音，作为语音类功能的输入 | 语音输入相关功能不可用 |
| 摄像头 | 扫码 | 扫码不可用，其余不受影响 |
| 电话 | 读取短信验证码用于核验身份 | 收验证码时要手动切出去看 |
| 通知 | 接收消息提醒 | 收不到推送，不影响主功能 |

验证码短信到了之后切回应用手动输入即可，「读取短信」权限不是非给不可。

## 四、装不上或打开异常

- **解析失败/安装中断**：确认包完整（大小应接近 90 MB）、系统版本达标，残缺的包重新下载；
- **打开闪退**：重启手机再试，还不行就卸载重装，并确认安装包来自介绍站给的同一入口；
- **空间不足**：清出至少 200 MB 再装。
