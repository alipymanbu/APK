# 安卓客户端装到手机的步骤

本篇讲 9xbuddy 安卓客户端的安装路径与装好后的使用要点：安装文件从哪来、系统会拦在哪一步、装完有哪些网页版没有的顺手功能。

相关文档：[在线视频链接怎么保存到手机](在线视频链接怎么保存到手机.md)

---

偶尔存一条视频，浏览器里打开网页版就够了；但经常收集素材的话，安卓客户端会把「复制 → 切换 → 粘贴」这套动作省掉一大半。安装方式与商店应用略有不同，按下面的步骤走即可。

## 安装四步

1. **取安装文件**：从公开整理的介绍站拿到网盘入口，把安装文件资源转存到自己的网盘账号，再经网盘客户端下载到手机本机。
2. **允许未知来源**：首次点开 APK 时，系统会提示安全确认。按弹窗指引允许对应客户端（网盘或浏览器）安装应用；部分机型入口在「设置 → 应用 → 特殊权限 → 安装未知应用」里，一次性授权即可。
3. **完成安装**：桌面出现 9xbuddy 图标即装好，当前整理到的版本为 v1.7.7，体积约 41MB，要求 Android 5.2 及以上。
4. **首次打开**：若出现「正在使用试用版」的提示属正常现象，页面上有「添加更多时间」「获取桌面应用程序」等入口，按自己的需要选择即可。

## 装好后多出来什么

- **分享菜单直接呼出**：在任意应用里点视频的「分享」，选 9xbuddy，它接手这条链接并列出可选版本，不用手动复制粘贴。
- **后台下载队列**：任务在后台排队推进，状态栏可见进度；Wi-Fi 与流量切换时可以暂停续传，大文件也不怕中断。
- **内置下载管理器**：进行中与已完成的任务分栏管理，文件默认落在系统 Download 目录，保存路径、下载格式、界面语言都能在设置页调整。

## 版本渠道的小差异

受商店政策影响，不同发布渠道对部分站点来源的解析能力有所限制，以 APK 形式直接安装的版本功能更完整。无论哪个渠道，解析结果的格式与清晰度口径是一致的。
