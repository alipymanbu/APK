# BetterVia 站点导航（bettervia.bmww.store）

这里是 BetterVia —— 一枚给安卓 Via 浏览器用的增强模块 —— 的第三方介绍站导航页。模块安装包只有 0.39MB，装上之后能把名单限制解除、主题换装、脚本大全、广告规则、Cookie 管理和一组隐私开关收进同一个面板。站点里整理了它的功能清单、运行条件与完整的安装流程。

站点入口：[bettervia 模块介绍站](https://bettervia.bmww.store/)
