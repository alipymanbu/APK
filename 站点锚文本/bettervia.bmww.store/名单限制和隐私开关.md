# BetterVia 名单限制和隐私开关

BetterVia 面板里的开关不少，其中问得最多的是「解除名单限制」到底解了什么，以及隐私那组开关各自管什么。本文把三组名单列清楚，再过一遍隐私防护相关的设置。

**相关文档**：[怎么装到Via浏览器.md](怎么装到Via浏览器.md) · [脚本和广告规则怎么补.md](脚本和广告规则怎么补.md)

## Via 的三组名单

Via 在一批视频、音频站点上限制了自带功能，三组名单是分开的：

| 被限制的功能 | 名单内的站点 |
| --- | --- |
| 资源嗅探 | v.qq.com、youku.com、iqiyi.com、mgtv.com、bilibili.com、ximalaya.com、film.qq.com |
| 广告拦截 | youku.com、iqiyi.com、mgtv.com、qq.com |
| 浏览器脚本 | v.qq.com、film.qq.com |

模块里的「解除名单限制」开关打开后，变化是：这些站点上用户脚本恢复执行、过滤规则重新参与过滤、页面里的音视频资源能重新被嗅探到。要说明白的是，这只是浏览器自带功能恢复工作，不改变站点自身的账号、会员与授权规则——能看什么仍由账号状态决定，也不要拿它去绕站点的付费与授权。

开关改完打开对应站点就能看到变化，通常不用重启浏览器；想恢复原状关掉即可。

## 隐私类开关

| 开关 | 大致作用 |
| --- | --- |
| 隐私锁 | 给进入浏览器加一道验证 |
| 超级隐身 | 阻止收集用户隐私数据的一组设置 |
| 截屏防护 | 禁止第三方应用截屏或录屏 |

这三个开关的具体行为随版本可能调整过，锁的对象、验证方式、防护范围以面板里那一页的说明为准，用之前先看一眼。

## Cookie 管理器

- 按站点列出已保存的 Cookie，可单删也可整批清理，较新版本里加了全选；
- 典型用法是把某个站点的登录态清掉（等于在该站点退出登录），其它站点不受影响；
- Cookie 里带着登录凭证，清掉就要重新登录，也别随手导出发给别人；
- 管理器页面适配不了所有机型，显示不全时退回用 Via 自带的数据清理功能。

## 护眼与界面类

护眼模式支持色温与纸质纹理调节，改前能实时预览；屏蔽组件可以把不想看的界面元素逐项勾掉；较新版本还支持对指定网址屏蔽长按菜单栏。这些外观改动都是随时可改、随时可退的，试错成本很低。各开关的面板实拍与运行条件，见 [bettervia 介绍站](https://bettervia.bmww.store/)。
