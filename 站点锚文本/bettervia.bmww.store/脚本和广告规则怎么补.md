# BetterVia 脚本和广告规则怎么补

Via 本身能跑用户脚本、能拦截广告，缺的往往是「去哪找脚本、去哪找规则」。BetterVia 模块里的脚本大全和广告规则两个入口，就是把这一步搬进面板：一个挑脚本，一个补过滤规则。本文讲两处怎么用，以及「装了没反应」时的排查顺序。

**相关文档**：[怎么装到Via浏览器.md](怎么装到Via浏览器.md) · [名单限制和隐私开关.md](名单限制和隐私开关.md)

## 脚本大全

- 入口在模块面板里，是一个脚本列表页，挑中装上即可。
- 装上的脚本会出现在 Via 自己的脚本列表里，能随时停用或删除；排查页面异常时先停用，别急着删。
- 脚本只对它头部声明的网址范围生效，访问别的站点时它不参与，属正常现象。
- 脚本资源联网加载，模块里可选 Gitee 源或 GitHub 源，一个源加载不出来就换另一个。

## 广告规则

- 作用对象是 Via 的广告拦截功能，模块负责规则的下载与更新。
- 规则是一份列表，站点页面结构一变旧规则就可能失效，定期更新一次比较省事。
- 某个站点拦得不干净，通常不是模块坏了，而是规则没覆盖那种广告位。

## 装了没反应，按这个顺序查

1. 确认脚本声明的网址范围包含当前站点；
2. 把其余脚本停用，只留这一个再试，排除相互干扰；
3. 查当前站点是否在 Via 的内置名单里——名单站点上脚本本来就会被跳过，见[名单限制和隐私开关.md](名单限制和隐私开关.md)；
4. 打开 Via 的脚本页确认脚本处于启用状态，必要时重启一次浏览器。

四步都走完还不行，多半是模块没有被正确加载，回[怎么装到Via浏览器.md](怎么装到Via浏览器.md)核对作用域与重启那两步。

## 挑脚本前留意三句

- 脚本由社区用户编写，不属于模块自带内容，装之前先看清它要做什么；
- 来源不明、索要账号密码或额外权限的脚本先放一放；
- 只在自己的设备、自己的账号上用，并遵守所访问站点的服务协议。
