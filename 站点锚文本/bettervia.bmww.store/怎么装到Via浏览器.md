# BetterVia 怎么装到 Via 浏览器

BetterVia 是一枚挂在 Via 浏览器上的功能模块，靠框架加载运行，所以安装分「装模块本体」和「挂框架激活」两段。本文把有 root 与没有 root 两条路线各走一遍，并列出装机前要对一遍的条件。

**相关文档**：[脚本和广告规则怎么补.md](脚本和广告规则怎么补.md) · [名单限制和隐私开关.md](名单限制和隐私开关.md)

## 装之前先对条件

- Via 本体需要 V6.6.0 及以后版本，国内版包名 `mark.via`、谷歌版 `mark.via.gp`，改过包名的版本也能对应勾选；
- 系统在 Android 10 到 16 之间测试通过，版本过低或过高都可能跑不起来；
- 模块安装包约 0.39MB，版本 1.1.0，装完几乎不占空间。

## 已 root：LSPosed 路线

1. 确认 LSPosed 已装好且可用（它本身需要 Magisk、KernelSU 之类的 root 方案配合）。
2. 安装 BetterVia 安装包。
3. 打开 LSPosed 进模块列表，启用 BetterVia，作用域勾选 Via。
4. 按提示重启作用域应用，或整机重启一次。
5. 打开 Via 进设置页，看到模块入口即激活成功。

## 没有 root：LSPatch 修补路线

1. 装一个免 root 框架（LSPatch 或其衍生版本），按提示给足权限。
2. 在框架里选中 Via 开始修补，本地模式与集成模式里选本地——之后改作用域不用重新修补。
3. 安装修补出来的 Via（可能需要 Shizuku 服务，或先卸载原版再手动装）。
4. 回框架的模块页启用 BetterVia，作用域勾修补后的 Via。
5. 重启修补版 Via，到设置页确认入口。

修补会改掉 Via 的签名，之后 Via 更新都要重新修补一遍，这是这条路线的主要代价。

## 装完没入口怎么排查

先核对三件事：模块在框架里是否启用；作用域勾的是不是当前在用的那个 Via；勾完是否重启过。三项都对仍没有入口，多半是框架本身没正常工作，先单独验证框架再回头查模块。更完整的排查顺序整理在 [bettervia 模块介绍站](https://bettervia.bmww.store/) 的安装步骤页里，对照着走一遍能省掉大部分瞎试。

## 装完之后

- 模块面板可以独立打开，全部设置项都在里面，第一次打开有一段启动动画；
- 激活后 Via 的设置页里也会出现模块入口；
- 想撤掉时：有 root 在 LSPosed 里停用即可；无 root 要先卸载修补版 Via 再装回原版，卸载前记得用 Via 自带的备份功能导出书签和历史。
