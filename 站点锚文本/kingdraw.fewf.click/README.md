# KingDraw 介绍站 · 锚文本目录

这里是 KingDraw（清笔，一款化学结构式编辑器）相关文章的汇总页。KingDraw 把结构式绘制、AI 图像识别、手势输入、3D 分子模型与名称互转集成在手机画板上， Android、iOS、Windows 多端通过账号同步文件；目录里的文章围绕它的实际使用场景展开：

- [手机画结构式的快捷技巧.md](手机画结构式的快捷技巧.md)——手势绘制、环模板、一键美化等小屏绘制技巧；
- [与ChemDraw等格式互通.md](与ChemDraw等格式互通.md)——cdx、mol、SMILES 文件的打开、导出与协作做法。

功能的完整概览与安卓安装文件的获取入口，见 [KingDraw 介绍站](https://kingdraw.fewf.click/)。
