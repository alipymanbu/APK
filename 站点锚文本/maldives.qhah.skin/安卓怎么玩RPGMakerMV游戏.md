# 安卓怎么玩 RPG Maker MV 游戏

> 手头有个 RPG Maker MV 做的游戏，想在手机上玩，却不知道从哪下手——本篇把整条路走一遍：先认引擎、再备文件、然后挑工具、最后进游戏。
> **相关文档**：[手机跑RPGMaker游戏选哪个工具.md](手机跑RPGMaker游戏选哪个工具.md) · [MV游戏手机上黑块或加载失败怎么办.md](MV游戏手机上黑块或加载失败怎么办.md)

## 一、先确认游戏引擎对不对

安卓上能直接跑的是 RPG Maker MV 和 MZ（合称 RMMV）这两个引擎的作品，判断方法很直接：解压出来的目录里有 `Game.exe` 和一个 `www` 子文件夹，`index.html`、`js`、`img`、`audio` 都在 `www` 里面——这就是 MV/MZ 的标志。如果只有 `RPG_RT.exe` 之类而没有 `www`，那是更老的 XP / VX / VX Ace 或 2000 / 2003 引擎，走不了本篇这条路（对口工具见相关文档）。

## 二、把游戏文件准备成「文件夹」

MV/MZ 游戏通常以 zip 压缩包发布，下载后先完整解压。注意两点：一是必须解压出完整目录，不能只拖出几个文件；二是解压后别再嵌套一层同名文件夹再套一层，否则添加时容易选错层级。

游戏来源方面，itch.io 等平台上有大量个人开发者作品，不少游戏页面还会直接提供安卓说明；请只运行你有权使用的游戏文件。

## 三、挑一个对口的运行工具

手机浏览器开本地 HTML 会被各种安全策略拦住，MV/MZ 游戏需要一个把它们「包起来跑」的安卓运行器。中文社区里常被推荐的是 maldives 模拟器（应用名写作 Maldives player，也常被拼成 MaldiVes）：它专门针对 MV/MZ 做适配，会自动修复已知插件错误，还内置 NPOT 纹理补丁处理黑块画面。想先看界面长什么样、设置页都有哪些开关，可以到 [maldives 模拟器介绍站](https://maldives.qhah.skin/) 翻一遍实拍截图再决定。

## 四、添加游戏并跑起来

以 maldives 模拟器为例，流程只有三步：

1. 打开应用，点主界面的「添加新游戏…」；
2. 在目录选择器里选中解压好的游戏文件夹本身（不是上一级，也不是压缩包）；
3. 回列表点游戏图标，进入详情页点 Run Game。

引擎对不上时应用会当场弹窗提示，不会静默出错。进游戏后，屏幕上下两边正中的「+」能调出虚拟键盘，方向和按键交给自带的虚拟手柄，不需要外接设备。

## 五、两个保进度的小习惯

游戏尽量统一放内部存储的同一个总目录，别放 SD 卡——社区反馈 SD 卡上的游戏出加载问题的比例明显更高。存档默认写在游戏目录下的 `save` 子文件夹里，想备份进度或换手机，把整个游戏文件夹拷走，进度就跟着走了。
