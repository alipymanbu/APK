# 账号注册与登录要点：通道为什么时开时关

> 想下载 .torrent 文件就必须有账号，而注册通道并不是常开的。本篇讲清开放的规律、注册时的注意点，以及登录后能多做哪些事。

## 一、先分清：什么操作需要账号

不是每个动作都要求登录。按公开规则，权限大致分成两层：

| 操作 | 是否需要登录 |
| --- | --- |
| 使用磁力链接（magnet:?xt= 开头） | 不需要 |
| 站内搜索 | 需要 |
| 下载 .torrent 文件 | 需要（受每日限额约束） |
| 评论、参与社区讨论 | 需要 |

只用磁力的人可以完全不碰注册；但搜索不方便、想按板块精确定位的人，账号是绕不开的。安卓端的 RUTRACKER 应用同样遵循这套逻辑——[介绍站的手上手指引](https://rutracker.djnf.quest/)里把这两层的差别画成了四步流程，装之前值得看一眼。

## 二、注册通道：周期性开放

为应对机器人注册，站点会周期性关闭注册入口，隔一段时间再开放。这个节奏没法预测，操作建议只有三条：

1. **看到注册入口就别犹豫**：开放时首页会出现明显的注册链接，填用户名、密码、邮箱并完成页面验证即可；
2. **关闭时不要反复尝试**：入口不在就是这轮没开，等下一轮比反复碰运气省事；
3. **密码单独设一个**：任何社区都不该复用你在别处的密码，这里也不例外。

## 三、登录之后注意两件事

- **每日限额**：登录账号每天最多取 1000 个 .torrent 文件（公开资料显示，群组成员上限更高），正常使用很难触顶，但批量抓取时心里要有数；
- **无分享率压力**：站内没有强制分享率考核，上传下载统计只作参考，不会因为"下多了没做种"被限制——这和很多要求 ratio 的站点不同。

## 四、账号之外的路

如果暂时没有账号，手机上依然有完整的玩法：磁力链接配合一款 BT 下载器就能开工。具体步骤、做种数怎么挑，见 [手机端上手与磁力下载.md](手机端上手与磁力下载.md)；站点背景与域名问题则整理在 [俄语资源社区是什么与域名由来.md](俄语资源社区是什么与域名由来.md) 里。
