# FurryBar 安卓版下载安装流程与首次注册

> 本篇讲 FurryBar 安卓端从取安装包到登录进主界面的完整流程，以及几处容易卡住的地方怎么处理。

## 一、取安装包：走网盘分享

FurryBar 的安卓安装包一般通过网盘分享传递：打开分享链接，登录夸克账号后把文件「保存到我的网盘」，再从网盘客户端里下载 APK。手机端直接下，电脑端下完传到手机也可以。

获取入口整理在 [FurryBar 安卓版下载安装](https://furrybar.fewf.ren/download.html) 这页里，按页面上的步骤走即可，这里不重复贴地址。

## 二、安装四步

1. 点开下载好的 APK；首次安装弹「是否允许安装未知应用」时，在对应的下载来源（浏览器或夸克）一栏勾选允许；
2. 部分国产手机的「纯净模式」会先拦一步，按提示选「继续安装」或临时关闭该模式；
3. 等待安装完成——安装包约 77 MB，手机留出 200 MB 以上空闲更稳；
4. 桌面出现兽人爪印图标，点开即用。

## 三、第一次打开：注册与登录

1. 主界面点「立即注册」，填入邮箱地址；
2. 点「获取验证码」，去邮箱收信（垃圾箱也翻一下）；
3. 填验证码、设密码、再确认一次，提交注册；
4. 按引导挑性别、起昵称、写一句简介，就能进主界面挑角色了。

已有账号的直接用同一个邮箱登录；换新手机也是同一套账号，介绍里提到安卓、iOS、网页端数据同步。

## 四、装不上时的三件事

- **提示「有风险」**：非应用商店来源的安装包都会触发这类提示，确认来源可信后继续安装即可；
- **验证码收不到**：先翻垃圾邮件，等一两分钟再点一次，还不行就换个邮箱重新注册；
- **反复安装失败**：删掉旧安装包重新下载一遍再装，传输损坏是最常见的原因；存储不足也会失败。
