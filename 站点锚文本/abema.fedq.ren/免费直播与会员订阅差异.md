# ABEMA 免费能看什么？直播频道与会员订阅的边界

经常看到有人问：ABEMA 到底是不是免费的？为什么有的节目点开就要订阅？
答案藏在它的产品形态里——这是一个「直播频道免费、增值功能订阅」的平台，两条线分得很清楚。
这篇把免费能享用的部分、订阅后多出来的部分，以及两者最容易混淆的地方一次讲清。

## 一、免费的部分：直播频道随便看

ABEMA 的核心形态是网络电视：二十多个专业频道全天候编排、到点开播。
这些直播频道对所有用户开放，而且**不注册也能看**——装好应用打开，切到「テレビ」一栏就能换台，
这是它和多数视频平台差别最大的一点。

免费范围内包含：

- 全部直播频道：新闻、动画、剧集综艺、麻将格斗、音乐等按表播出；
- 节目表（番組表）完整可查，能提前看到一周编排；
- 部分点播作品（ビデオ区）带广告观看，不用付钱；
- 评论区、节目提醒这类基础功能。

代价是广告：免费观看会插入广告，直播与点播都有，这是内容方的主要收入来源。

## 二、订阅的部分：ABEMA Premium 多了什么

付费档叫 ABEMAプレミアム，按月订阅（日币计价，应用内或网页端都可办理），多出来的东西集中在四块：

1. **去广告**：点播与直播的广告大幅减少，追长篇综艺时体感最明显；
2. **离线下载**：会员可以提前把节目存到手机（最多同时保存 25 个），通勤路上不耗流量；
   注意下载件必须在「节目可看期」内且会员状态有效才能播，解约后没看完的会失效；
3. **会员专属作品**：部分电影、原创内容与提前看的话数只在付费档开放；
4. **画质与投屏**：更高画质档位与更完整的投屏支持。

## 三、最容易混淆的三件事

**免费 ≠ 会员少个「跳过广告按钮」**：两档的内容集合不同。免费档看不到某些作品，
不是广告在挡，而是那部作品本身属于会员库。

**订阅与地区是两个独立维度**：付了钱也可能有看不了的节目——单档内容的授权范围由版权分区决定，
与会员状态无关。判断顺序永远是先看报错类型，再怀疑账号。

**退订有时限**：按月自动续费，退订要在下次扣款日 24 小时前操作；
解约后离线下载件随之失效，想清理缓存腾空间的重装党尤其要注意。

## 四、怎么判断自己需不需要订阅

一个实用的判断法：先免费看两周。

- 主要看直播频道、对广告不敏感 → 免费档够用，连账号都可以不绑；
- 通勤路上追特定剧集、想提前下好 → 离线下载就是为这个场景设计的，值得订；
- 只为一部会员独占作品订阅 → 先确认它的可看期，短篇内容按月订反而划算。
