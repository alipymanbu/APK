# 手机上开超市的游戏，到底在玩什么

> 搜"supermarket"找手机游戏的人，多半是被那段第一人称逛超市的短视频勾起来的。这里把这类超市经营模拟游戏的真实玩法拆开讲清楚：它模拟的不是"购物"，而是"开一家店"。

在超市题材的模拟游戏里，玩家的身份被整个翻转过来——不再推着购物车逛，而是站到了货架的另一边。以 Supermarket Simulator（超市模拟器）这类作品为代表，手机屏幕里呈现的是一间空荡荡的小铺面和一台能下订单的电脑，剩下的一切都靠玩家自己动手。

## 核心循环：一天五件事

这类游戏的基本节奏可以概括成一个营业日：

1. **进货**：在游戏内的电脑上向供应商下单，货物送到后去门口搬箱子，在储藏室里拆包理货；
2. **上架**：把商品摆上货架、冰箱和冰柜，陈列位置、过道动线都由自己规划；
3. **定价**：对准货架上的价签就能改价格，参照系是会波动的市场价——定高了顾客嫌贵，定低了利润被吃掉；
4. **营业**：把门口的牌子从 CLOSED 切到 OPEN，顾客陆续进店，站上收银台扫码结账，现金要找零、刷卡走 POS 机；
5. **算账**：一天结束看流水，决定明天的钱花在补货还是扩建上。

五件事环环相扣：货架空了客流会掉，价签乱贴会压利润，收银排队太久顾客扭头就走。所谓"经营"，就是在这几件事之间来回救火，再一点点腾出手做规划。

## 为什么这么"琐碎"却让人上头

它把平时完全接触不到的超市后台，拆成了一件件有反馈的具体活儿：箱子拆开有货、价签贴上有人买、扫码枪响有钱进账。碎片时间收几单也行，周末闲下来扩建一层卖场也行——进度随存档累积，没有"一局"的压力。很多玩家形容，这游戏最解压的地方是"看货架一点点满起来"。
