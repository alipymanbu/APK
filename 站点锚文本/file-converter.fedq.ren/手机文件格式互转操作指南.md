# 手机文件格式互转操作指南：从选文件到取结果

> 本篇把安卓手机上的格式转换流程拆成可照做的步骤，以 File Converter 为操作对象，顺带讲批量转换、从网址转换和几个关键参数。

## 一、开工前的两件事

第一次打开应用，先确认两件事，能省掉大半「转不了」的困惑：

1. **网络**：音频和视频在手机本地离线转换；其余类别（文档、电子书、图片、表格、3D、CAD 等）都要上传云端处理，先用浏览器随便开个网页确认能上网。公司、校园 Wi-Fi 拦外部请求的情况不少，失败先切手机流量。
2. **存储权限**：转换要读手机里的文件、把结果存回去，权限弹窗出来就允许，否则连文件都选不了。

还没安装的话，[file converter 工具站](https://file-converter.fedq.ren/) 的下载页有安装包获取入口和四步安装说明。

## 二、一次基本转换的五步

以「DOCX 转 PDF」为例，其它格式的路径完全一样：

1. **进类别**：主页按类别列着转换器入口——图像、音频、视频、电子书、文件、演示、电子表格；顶部有「转换成 PDF / JPG / MP4」快捷组合，正好要转这几种就直接点；
2. **加文件**：点右下角「+」从手机里选文件，支持多选；
3. **选格式调参数**：页面往下翻找到目标格式点选。要调细节就展开高级设置——文档与表格有 OCR 开关；图片有输出质量与尺寸；音频有比特率、采样频率和裁剪；视频有编码器、旋转、裁剪、防抖；电子书能指定目标阅读器型号（Kindle、Kobo、Nook 等）；
4. **提交**：点转换，任务进后台跑，切出去干别的没问题；
5. **取结果**：回侧栏「已转换」组取文件，可存回手机目录，也能直接分享给微信、邮箱。

进度与结果全在侧栏（主页左上角三条横线）里：「忙」是进行中、「已转换」是成功、「失败的」是没转成的。常用组合长按一下收进主页收藏夹，下次免翻列表。

## 三、批量转换

一堆文件转同一个格式不用一个个来：选文件那一步用多选把要转的文件一次勾上（可跨目录），选共同的目标格式批量提交，任务排队依次处理。20.1.12 版更新说明里专门提到「更高的批量转换上限」；文件特别多时（比如上百张图片）分几批提交更稳妥。

## 四、从网址转换

「从网址转换」这个入口有两种用法：

- **转换网上的文件**：粘贴指向具体文件的直链（比如某个 PDF 的下载地址），应用抓下来走正常转换流程。注意要的是文件直链，不是随便一个网页地址；
- **把网页转成文件**：把一个普通网页转成图片或电子书，存一份离线可看的版本。

## 五、几个常用交叉组合

| 想做的事 | 路径 |
| --- | --- |
| 视频转 GIF 动图 | 视频类源文件 → GIF 输出 |
| 提取视频里的音频 | 视频类源文件 → MP3（音频输出） |
| 扫描件转可编辑 Word | 图片类源文件 → DOCX，高级设置勾 OCR |
| 文字转语音 | 文本 / 电子书源文件 → 音频输出 |
| 照片拼成 PDF | 多选图片 → PDF 输出 |

## 六、转完之后

结果文件默认存在应用自己的目录，安卓 11 以上系统限制文件管理器直接访问，从应用内分享出去是最省事的取法。历史任务是本地数据，卸载应用就清空——卸载重装前，把还要的结果先分享或复制出来。

发图前想去掉拍摄位置信息，用元数据工具把 EXIF（含 GPS）整条清掉；PDF 加密码、文件修复（针对损坏的 PDF / RAR / ZIP / 音视频）也都在独立入口里。
