## 一、格式对不上的日常场景

下面这些场景大概率碰过其中几个：

- 收到一份 EPUB 电子书，手机阅读器只认 TXT；
- 录了一段 FLAC 无损音频，车机读不了；
- 相机拍出来的是 RAW，发群别人打不开；
- 拿到一张 DWG 图纸，手机上没有任何应用能直接看；
- 扫描出来的 PDF 想改成 Word，手机上似乎无从下手。

桌面时代的答案是一堆各管一段的小工具：转 PDF 的、转音频的、转图纸的，各装一个。安卓上这套思路走不通——一个应用占一份内存，装七八个转换工具既占空间又来回切换。于是就有了「万能转换」这个品类：一个应用，把尽可能多的格式互转收进同一个入口。

几个能说明「广度」的例子：

- 电子书方向能给 Kindle 出 AZW / MOBI，给手机阅读器出 EPUB；
- 3D 与 CAD 这种桌面软件的地盘，它也能做 STL / OBJ / FBX 与 DWG / DXF / PDF 之间的转换；
- 甚至字幕（SRT / SUB / LRC）和 Gerber 板图（GBR）都有对应入口。

同类工具里做到这个覆盖面的不多。另一个特点是转换方式分两条线：音频视频在手机本地离线完成，文件不出设备；其余类别传到云端服务器转换再传回，速度通常比手机算力直接跑快。

## 三、边界也要心里有数

「万能」不等于无所不能，两条硬边界提前知道：

1. **加密文件转不了**——带打开密码的 PDF / ZIP，转换前先解密；
2. **DRM 保护的内容转不了**——部分商店购入的电子书、音乐带版权保护，任何工具都绕不过去。

另外每个类别只有固定的输出方向，列表里没有的组合就是不支持。挑工具之前先想清楚自己最常用的两三个转换路线，对照清单确认支持再装，比装完再失望划算。
