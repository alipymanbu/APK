# 免 Root 隐藏应用的工具怎么选

不想 Root 手机，又想把某些应用从桌面上藏起来，是隐私需求里最常见的一种。这篇把免 Root 隐藏应用的几条路线摆出来，各适合什么样的人，最后给一个省事的选择建议。

相关文章：[手机相册和视频怎么隐藏](手机相册和视频怎么隐藏.md)

## 一、免 Root 隐藏应用的原理

安卓的"停用"（disable）是系统级操作，普通应用没有这个权限，所以免 Root 方案的思路都一样：**向别的途径借权限**。借到权限之后，工具就能把选中的应用停用——图标从桌面消失、抽屉里搜不到，看起来就像被卸载了；恢复时再启用回来。

## 二、三条常见路线

| 路线 | 借谁的权限 | 特点 |
| --- | --- | --- |
| Shizuku | ADB 权限 | 配置快，几分钟搞定；缺点是每次重启手机后要重新激活服务 |
| Dhizuku | 设备所有者（Device Owner） | 配置麻烦（要用电脑激活、登出全部账号），但重启后依然生效，一劳永逸 |
| DSM（冰箱/小黑屋） | 设备管理员 | 依赖的项目已停止维护，出错概率高，不建议新配 |

已 Root 的设备不用纠结，直接走 Root 模式最省事。

## 三、拿什么工具来隐藏

路线选定后，需要一个把这些模式整合好的前端工具。开源的 [Amarok](https://amarok.fewa.skin/) 是目前口碑较好的一个：上面三种免 Root 路线它都支持，外加 Root 模式共四种，在"更多设置 → 应用隐藏模式"里配一种即可；文件隐藏则完全不需要配置，装完就能用。它的[介绍站](https://amarok.fewa.skin/)把每种模式的激活步骤和报错对照都整理过一遍，配模式卡住时可以按图索骥。

除了隐藏应用，它同样能隐藏文件——原理是混淆文件名和文件签名（不是加密），几个 GB 的视频也是秒级完成。装它一个，"藏应用"和"藏文件"两件事都覆盖了。

## 四、选择建议

- **怕麻烦**：选 Shizuku，Android 11 及以上全程手机上就能激活，代价是重启后要点一次"重新启动服务"；
- **怕重启**：选 Dhizuku，激活一次管到底，代价是首次激活要用电脑、还得先登出设备上的所有账号；
- **已 Root**：直接 Root 模式；
- **DSM 路线**：除非手头已经有激活好的冰箱/小黑屋，否则不再推荐。

配好模式之后记住一条铁律：**卸载隐藏工具之前，先把应用和文件全部取消隐藏**——这是所有停用类工具共同的软肋，工具不在了，被藏的应用就没人帮你恢复。
