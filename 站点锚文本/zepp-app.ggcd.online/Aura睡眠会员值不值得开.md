# Aura 睡眠会员值不值得开

> 应用免费装、数据免费看，但里面确实藏着几处要掏钱的地方。本篇把免费与订阅的分界列清楚，你再决定要不要为睡眠服务买单。
> **相关文档**：[PAI活力值是什么意思.md](PAI活力值是什么意思.md) · [Amazfit手表要装哪个App.md](Amazfit手表要装哪个App.md)

---

先说结论的前半句：**手表同步回来的睡眠数据，不订阅也一直在**。得分、时长、阶段、周趋势，全都不收费；订阅服务是在这些原始数据之上加的「解读与陪伴」，属可选，不订不影响看数据。

## 免费与付费的分界

| 内容 | 是否收费 |
| --- | --- |
| 睡眠 / 消耗 / 心脏健康分数与周趋势 | 免费 |
| 设备配对、固件升级、表盘更换 | 免费（个别社区开发的表盘与小应用一次性买断，非订阅） |
| 地图与轨迹文件导入 | 免费 |
| Aura：个性化睡眠音乐、冥想辅助 | 免费 |
| Aura：每天向 AI 睡眠助手提问 | 免费 1 条 |
| Aura：周报月报式睡眠报告、AI 助手无限提问 | Premium 订阅 |
| Zepp Fitness：训练周报月报、训练问答 | 会员订阅 |

## 什么人适合开 Aura

- **长期睡不好、想看趋势的人**：免费版能看到每晚分数，但「这周比上周退步在哪」要靠订阅里的周期报告来归纳；
- **需要入睡辅助的人**：免费的音乐与冥想若已经够用，就没必要升级；
- **戴 Helio Ring 的用户**：这类订阅对你是免费提供的，直接用即可。

反过来说，如果你只是想确认「昨晚睡得怎么样」，免费部分已经完整覆盖，不用为没会用到的功能付钱。

决定开了之后想先装应用体验几天，[Zepp App](https://zepp-app.ggcd.online/) 介绍站有安装与配对的完整路径；PAI 那张卡的含义见 [PAI活力值是什么意思.md](PAI活力值是什么意思.md)。
