# 影视聚合播放器的订阅机制详解

> 装完打开首页一片空白？九成不是故障。这类播放器的内容全部来自「订阅」，这篇讲清楚订阅到底是什么、怎么添加、为什么会失效、失效了怎么判断和更换。
> **相关文档**：[电视盒子怎么安装第三方应用.md](电视盒子怎么安装第三方应用.md) · [手机投屏电视看剧的方法.md](手机投屏电视看剧的方法.md)

---

## 一、订阅到底是什么

TVBox 体系的播放应用（包名带 `tvbox.osc` 的都是同一血统，NewBox 也属于这一系）本身只做三件事：界面、搜索、播放。至于「有哪些片、分什么类、每部片走哪条线路」，全由一个叫「订阅 / 接口 / 配置」的文本文件决定 —— 通常是一段 JSON 或 TXT 格式的网络地址，应用打开时整个拉下来解析。

所以装完看到的现象可以这样对号入座：

| 现象 | 原因 |
| --- | --- |
| 首页没有分类、没有影片 | 还没配订阅 |
| 有分类但点开是空的、一直转圈 | 订阅里的部分线路失效了 |
| 换了订阅后内容完全变了 | 订阅就是内容入口，换订阅等于换了一套片源目录 |

订阅源由第三方个人维护，应用本身不附带长期有效的片源，地址需要自己从影视社区找 —— 本文不代找、不推荐具体地址。

## 二、添加订阅的步骤

以手机竖屏布局为例（电视版路径相同，用方向键 + OK 键操作）：

1. 进底部「我的」页，点「订阅管理」；
2. 按界面提示新增订阅，把订阅地址（`https://` 开头的一条链接）粘贴进去，确认；
3. 回到首页等加载，出现电影 / 剧集 / 综艺等分类即表示生效。

三条实操建议：

- **地址复制粘贴，不要手打**。订阅链接通常很长，少一个字符就加载失败；电视上输入可以在手机端先把地址发给自己，用时粘贴，或者外接 USB 键盘；
- **一次只配一条常用的**。多条订阅混在一起展示，找片反而乱；先跑通一条，不够再加；
- **配完不生效先刷新或重启应用**。订阅是打开时拉取的，改完不刷新会维持旧状态。

## 三、失效的判断与更换

出现下面任一信号，基本可以判定当前订阅出了问题：

1. 首页分类还在，但点开任何分类都是空的或一直转圈；
2. 搜什么片名都没有结果；
3. 影片详情能打开，但所有播放线路都报错。

处理顺序：先确认家里其他应用能上网（排除网络原因）→ 回「订阅管理」删掉或禁用旧订阅 → 换一条新地址 → 回首页重新加载。换了订阅后内容目录会整个换掉，之前收藏的影片如果挂的是旧订阅的线路，可能播不出来 —— 重新在当前订阅里找同一部片即可，这不是记录丢了。

判断一条订阅地址死活最直接的办法：手机浏览器里打开它。能看到一大段文本就是活的，404 或超时就是死的。社区里的普遍经验是「用的人越多死得越快」，订阅一批批换属于常态维护，不是应用坏了。

## 四、不配订阅能干什么

「本地视频」和「播放链接」两个功能不依赖订阅：前者直接播设备存储或 U 盘里的视频文件，后者粘贴一条视频直链就能起播。也就是说，订阅还没着落的阶段，完全可以先把它当本地播放器用。等订阅配好，直播板块（频道列表同样来自订阅里的直播源）和聚合点播才全部点亮。

以 NewBox 的界面为参照，底部四个板块的分工与实机截图，见 [NewBox 介绍站](https://newbox.uerg.quest/)；订阅配好后想在电视上看，把手机画面投过去的操作见[手机投屏电视看剧的方法.md](手机投屏电视看剧的方法.md)。
