# HyperOS 状态栏与锁屏定制玩法

装完模块、重启生效之后，大多数人最先动的就是状态栏和锁屏这两块——改动肉眼可见、风险低，成就感来得最快。这篇把常改的几项和它们的位置捋一遍。

## 状态栏：一寸土地一寸金

状态栏区域的开关都收在「状态栏」分类里，常见的玩法：

| 想改什么 | 说明 |
| --- | --- |
| 时钟显秒 | 状态栏时间精确到秒，刷机圈的经典需求 |
| 双排时钟 | 一行显示时间、一行显示日期或其他信息 |
| 网速显示 | 实时上下行速率常驻状态栏 |
| 电池样式 | 图标形态与百分比显示方式可调 |
| 运营商名称 | 自定义文字，改掉千篇一律的「中国移动」 |

不同机型的可选项不完全一致：项目按主流机型适配，个别选项在你的机器上不出现属于正常的机型差异。

## 锁屏：从看时间到看信息

锁屏分类里最热门的是时钟显示秒数；再往深一点，息屏显示支持自定义布局，音乐播放时的焦点歌词还能调整息屏样式并显示歌词翻译。经常戴耳机听歌的用户可以先把这一项玩明白。

## 改完没生效？就一个原因居多

LSPosed 类模块的改动不即时生效：开关打开后，留意应用底部的提示——它会要求重启对应作用域或直接重启手机。漏掉重启，是「开关开了界面没变」的头号原因。

个别选项打开后界面显示异常的，把那个开关关掉再重启即可恢复原状；想系统性排查，到 [hyperceiler 介绍站](https://hyperceiler.wxhp.skin/) 的常见问题区按顺序过一遍即可。
