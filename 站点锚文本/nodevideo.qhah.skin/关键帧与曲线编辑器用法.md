# 关键帧与曲线编辑器用法

> 本篇讲 NodeVideo 里做动画的基本功：关键帧怎么打、曲线编辑器怎么让过渡不生硬，以及参数跟着音频跳的音频反应玩法。
> **相关文档**：[光流补帧慢动作教程.md](光流补帧慢动作教程.md) · [安卓版下载与安装步骤.md](安卓版下载与安装步骤.md)

## 一、打关键帧：点参数名称，不是数值

这个应用里几乎所有参数都能做动画，入口统一得很：

1. 点一下**参数名称**，展开关键帧栏；
2. 游标移到起始位置，改参数值——当前游标位置自动记录一个关键帧；
3. 游标移到结束位置，再改一次数值，第二个关键帧自动生成；
4. 播放预览，参数就在两个值之间过渡。

常见的几种用法：

| 想要的效果 | 动哪个参数 |
| --- | --- |
| 镜头推近拉远 | 缩放 |
| 画面平移 | 位置 |
| 淡入淡出 | 透明度 |
| 旋转出场 | 旋转 |

## 二、曲线编辑器：把「机械感」调成「顺滑感」

线性过渡看起来发硬。改曲线的做法：点参数左侧菜单 → 选「曲线编辑器」→ 调动画曲线形状，过渡速度就跟着变了。缓入缓出、先快后慢，全在这条线上调，这是手机端动画做出顺滑感的关键一步。

## 三、音频反应：参数跟着鼓点跳

频谱可以映射到视觉参数上，做音乐可视化和卡点特效很顺手：

1. 给图层加上想被驱动的属性（缩放、透明度或某个特效参数）；
2. 在添加属性时搜「音频」，找到音频反应类设置；
3. 绑定后播放，参数随频谱实时变化。

建议从透明度、缩放这类简单参数开始试，熟了再把特效数值绑上去。
