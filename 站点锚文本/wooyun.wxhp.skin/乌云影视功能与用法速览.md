# 乌云影视功能与用法速览

> 讲乌云影视（wooyun）这款安卓影视聚合播放应用能做什么：内容覆盖哪些频道、找片走哪两条路、播放卡顿时怎么救，以及缓存与投屏这类日常功能怎么用。

## 一、它是一款什么应用

乌云影视（应用名显示为 wooyun）是一款安卓端的影视聚合播放应用，把电影、电视剧、综艺、动漫、短剧这些频道收进同一个播放器里。它的定位不复杂：不生产内容，负责把各条播放线路聚起来，让找片和看片这两件事在一个应用里完成。公开页面对它的介绍普遍提到「界面简洁」「免登录直看」——基础浏览与播放确实不需要注册账号，装上就能用。

几个常被问到的事实：

- 内容频道：电影、电视剧、综艺、动漫、短剧，部分版本还有纪录片板块；
- 筛选方式：类型、地区、年份三档组合筛，配关键词搜索；
- 播放能力：多播放线路、多档清晰度，支持离线缓存与电视投屏；
- 平台：目前只有安卓侧装包，iPhone 一直没见着正式版。

## 二、找片的两条路

**想好了看什么**，搜索框直接输：片名、演员名、关键词都行。长片名只输最有辨识度的几个字命中率更高；搜不到就换别名或主演名再试一轮。

**没想好看什么**，走分类筛选：先选频道（电视剧 / 电影 / 综艺 / 动漫），再叠类型、地区、年份。「最近上线的剧」「二十年前的老电影」「某地区的综艺」这类需求各有一条最快的筛法。搜索对冷门内容经常漏，分类里反而容易撞到。

## 三、播放与卡顿

同一部片常有不止一条播放线路，这是聚合应用的常态，也是它抗风险的方式：某条线路失效或转圈，退回详情页换一条即可，不用干等。清晰度同理——网络稳就往上选，转圈就往下选。

黑屏有声音、播放中途断开这类情况，九成是单条线路的片源问题，换线路、换个时间再看即可，不是设备坏了，也没有哪项设置能修。

## 四、缓存与投屏

**离线缓存**：播放详情页里选集缓存到本机，断网也能看，通勤出差用得上。缓存前看两件事：剩余空间（一集高清剧几百 MB 很正常）和清晰度（缓存时选的就是之后看的档位）。看完及时删，缓存列表支持逐条删除。

**投屏电视**：手机和电视连同一个 Wi-Fi，播放页点屏幕呼出控制条，找台电视机模样的投屏图标，选中设备即可，连上后手机变遥控。提示「暂无设备」时按顺序查：是否同一网络、路由器是否开了 AP 隔离、电视端 DLNA / 多屏互动开关有没有打开。
