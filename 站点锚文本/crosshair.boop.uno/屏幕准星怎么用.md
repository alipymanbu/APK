# Crosshair 屏幕准星怎么用：五步设置流程

本篇面向第一次上手屏幕准星类工具的读者，按应用内的真实界面把流程拆成五步：挑样式、调形状、定颜色、对中心、挂屏开打。相关的安装与权限问题单独整理在[安卓版下载安装与悬浮窗权限](安卓版下载安装与悬浮窗权限.md)一篇里；至于什么场景下这类工具能派上用场，可以先看[手游对枪的瞄准参照点](手游对枪的瞄准参照点.md)。

## 整体思路

Crosshair 的工作方式是在所有窗口之上叠加一层图形，所以它不需要"进入"任何游戏，也不用改游戏里的任何设置。使用节奏很简单：先在应用里把准星调到满意，点 Start 让它挂到屏幕上，然后切进游戏正常开玩；一局结束点 Stop 就能摘掉。

## 第一步：挑一个基础样式

打开应用进入样式选择页，列表里分**简单**与**动态**两类：

- 简单款是静态图形——圆圈、点、括号、十字、叉形等，适合喜欢干净画面的玩家；
- 动态款会缓慢自转或呼吸闪烁，视觉上更容易和游戏画面区分开。

每个样式下面都有 Select 按钮，点一下就应用。先随便选一个顺眼的，后面随时可以换。

## 第二步：调大小、透明度和角度

回到主界面的 Adjust UI 区域，三个控件对应三个参数：

1. **Rotate**：转动圆盘微调十字的倾角；
2. **Size**：滑杆控制整体大小，建议小到"能看清但不挡目标"；
3. **Transparency**：透明度调低一点，长时间盯着也不突兀。

## 第三步：定颜色，或换成自己的图片

Tap to select 区域有两个入口：

- **Pick Color**：取色器里任意选色。荧光绿、亮黄这类高饱和颜色在多数游戏画面里辨识度最高；
- **Pick Image**：从手机相册选一张图片当准星，适合用惯了某种特殊图形的玩家。

两者可以叠加使用：先换图片，再微调颜色与透明度。

## 第四步：把准星对准屏幕中心

Adjust Position 提供上下左右四个方向键，按一下挪一点，把参照点挪到当前游戏画面弹道的汇聚处；按 **Reset** 可以一键回到默认坐标。不同游戏的画面裁切不同，换游戏后往往要重调一次。

## 第五步：Start 挂屏，进游戏验证

回到主界面点 **Start**，屏幕上应该立即出现准星；如果系统弹出"显示在其他应用上层"的授权请求，允许后返回再点一次即可。切进游戏检查两点：参照点是否在弹道中心、转动视角时是否始终固定不动。没对准就回第四步微调。

## 一句话收尾

整套流程两三分钟就能走完，之后每次使用只需要 Start / Stop 两个按钮。更多细节与安装文件资源入口见 [Crosshair 屏幕准星介绍站](https://crosshair.boop.uno/)。
