# Crosshair 安卓版下载安装与悬浮窗权限处理

本篇记录 Crosshair 在安卓手机上从获取安装包到挂屏成功的完整路径，重点是两个最容易卡住的环节：系统对未知来源应用的拦截，以及"显示在其他应用上层"（悬浮窗）授权。装好之后怎么调样式，见[屏幕准星怎么用](屏幕准星怎么用.md)；它适合哪些对局场景，见[手游对枪的瞄准参照点](手游对枪的瞄准参照点.md)。

---

## 获取安装文件资源

Crosshair 的安卓版安装包通过网盘分享，打开 [Crosshair 屏幕准星介绍站](https://crosshair.boop.uno/) 的下载页即可进入分享入口。安装包原样放在网盘里，先**转存到自己的网盘账号**，再从网盘下载到手机——这一步不做二次打包，拿到手的就是原始 APK 文件（v1.0.22，约 11.3MB）。

## 安装：四个动作

1. 在手机上点开下载完成的 APK；
2. 系统弹出"出于安全考虑，手机已拦截这次安装"时，点**仍然安装**（或"允许此次来源"）；
3. 等待安装完成，桌面出现应用图标；
4. 打开应用，进入主界面。

### 安装被拦怎么办

部分系统的拦截提示只有"已拦截"没有"仍然安装"按钮，这时去**设置 → 应用 → 特殊权限 → 安装未知应用**，找到下载来源（浏览器或网盘客户端），勾选"允许安装应用"，再回到 APK 重新点一次。

## 悬浮窗权限：准星显示的前提

点 Start 时如果没有反应，或者系统提示需要"显示在其他应用上层"，就是叠加层权限没给：

1. 按提示进入授权页（或手动走"设置 → 应用 → Crosshair → 显示在其他应用上层"）；
2. 打开开关，返回应用；
3. 重新点 Start，屏幕中心出现准星即成功。

个别省电策略激进的机型会在锁屏或清理后台后冻结叠加层，表现为"准星消失"。把应用加入电池白名单、允许后台运行即可。

## 装完之后的两个小提醒

- **位置不居中**：不同游戏画面裁切不同，用 Adjust Position 微调，Reset 可回默认坐标；
- **换游戏后重看一眼**：切到分辨率或横竖屏不同的游戏时，中心点可能偏移，重调一次就好。
