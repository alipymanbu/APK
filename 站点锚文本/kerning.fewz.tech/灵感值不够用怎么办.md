# 灵感值不够用怎么办

> 可灵AI按灵感值扣费，新账号的第一笔额度来自登录领取；不够用的时候，省值比充值更值得先做。
> **相关文档**：[文生视频提示词怎么写.md](文生视频提示词怎么写.md) · [生成的视频太短怎么办.md](生成的视频太短怎么办.md)

## 一、消耗跟着四个变量走

点生成前，页面会亮出本次要扣的数量。同一个输入框，扣多少由四件事决定：

| 变量 | 影响方向 |
| --- | --- |
| 模型版本 | 越新的模型单价越高，旧模型会随更新降价 |
| 时长 | 5 秒与 10 秒不是一倍之差，长档位单价更贵 |
| 分辨率 | 高画质档按更高标准扣 |
| 是否带音频 | 带台词或音效的生成另加 |

举例：给一段 5 秒的视频对口型扣 5 灵感值，10 秒的扣 10——这类按秒计费的功能，时长直接换算成支出。

## 二、先做这三件免费的事

1. **每天登录领一次**。应用首页右上角有「登录领灵感值」入口，新账号注册本身就送一笔，日常靠签到也能攒出试错量。
2. **用低档位磨稿**。提示词没调顺之前，一律 5 秒、默认画质先出草稿；构图和动作对了，再升时长与分辨率出成品。草稿期的消耗能压到成片的零头。
3. **别重复排队**。生成高峰期偶尔排队失败，重试前先看资产页——有些失败任务不扣值，反复手动重发反而多扣，以扣费记录为准。

## 三、订阅之前先分清两套体系

国际站按美元订阅，分 Standard / Pro / Premier / Ultra 四档，另有年付与一次性灵感值加油包；国内版的档位与价格在应用内订阅页查看，与国外那套不通用。**两个版本的账号、资产、会员权益互不互通**，订阅前先确认自己常用的是哪一版，别在一边注册、去另一边充值。

充值之外的省钱路径其实就一条：把上面第二节的习惯养成。同样的额度，会磨稿的人能多出三四条可用成片。想看从起稿到发布的完整操作顺序，[kerning](https://kerning.fewz.tech/) 上有一份按导演工位拆开的流程介绍，对照着做能少走弯路。
