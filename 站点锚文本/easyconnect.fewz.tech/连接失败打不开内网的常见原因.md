# EasyConnect 连接失败打不开内网的常见原因

> 按现象对号入座：连接没反应、登录成功却打不开资源、VPN 图标不出现。地址和账号还没搞定的，先看 [服务器地址和登录账号从哪里拿.md](服务器地址和登录账号从哪里拿.md)。

## 一、点「连接」没反应 / 提示连接失败

1. **地址格式**：必须是 `https://域名或IP:端口` 的完整写法，漏端口是最常见错误（默认接入端口 4430）。先在手机浏览器直接输这个地址，能打开登录页说明地址没问题；
2. **对照电脑端**：连同一 WiFi，电脑浏览器能不能打开同一个地址。电脑能、手机不能，问题在手机侧；两边都不能，是网络或设备侧的问题，只能等或报管理员；
3. **手机网络**：客户端自己也要联网；关掉手机上其他 VPN 类软件再试——两个 VPN 抢通道会互相干扰；
4. **系统太新**：单位设备版本较老时可能不支持最新手机系统，个人端无解，报给 IT。

## 二、登录成功但打不开内网资源

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 资源列表是空的 | 管理员没给账号配资源 | 问管理员 |
| 隧道类资源全打不开 | 弹「连接请求」时点了拒绝 | 重新登录，弹窗时点确定 |
| 有 VPN 图标但某系统打不开 | 对该系统没有权限 | 问管理员加权限 |
| 网页能开但 App 连不上内网 | 只有网页类权限，没有隧道权限 | 问管理员确认资源类型 |

## 三、VPN 图标不出现

登录后状态栏应有钥匙形图标，没有就等于隧道没建立：

- 回想登录时是否弹过「连接请求」且被拒绝或忽略；
- 在系统设置的 VPN 权限里确认没有被禁用；
- 卸载重装一次，重装后第一次登录的弹窗别再点错。

## 四、连上了但很慢

流量绕行单位服务器中转，速度上限取决于线路负载，这不是故障：用完及时**注销**（列表页右滑）；访问公网视频、下载时先断开 VPN，需要内网再连。

安装环节的问题（未安装 / 不兼容 / 被拦截）整理在 [安卓手机版怎么下载安装.md](安卓手机版怎么下载安装.md)；更多功能介绍与界面一览见 [EasyConnect 安卓版介绍与安装包入口](https://easyconnect.fewz.tech/)。
