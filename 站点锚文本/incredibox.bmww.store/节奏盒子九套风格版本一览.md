# 节奏盒子九套风格版本一览

> 本篇是选版本用的对照：Incredibox 九套风格各是什么曲风、想听什么感觉从哪套下手、系统版本怎么限制列表长度。
> **相关文档**：[节奏盒子玩法入门.md](节奏盒子玩法入门.md) · [节奏盒子录制与导出混音.md](节奏盒子录制与导出混音.md)

---

## 一、「版本」不是更新号

Incredibox 里的版本是**九套并列的风格包**：每套有自己的画面主题、自己的 20 个声音、自己的 3 段奖励动画。换一套等于换一个乐队，不是升级。

## 二、九套对照表

| 版本 | 首发年份 | 曲风关键词 | 想要什么感觉从它开始 |
| --- | --- | --- | --- |
| V1 Alpha | 2009（2018 重制） | 老派 beatbox、爵士味 | 最原始的纯人声打拍子 |
| V2 Little Miss | 2012 | 纽约嘻哈、切分鼓点 | 纯正 B-Boy 底子 |
| V3 Sunrise | 2013 | 电子流行、明亮轻快 | 顺耳、适合循环的入门款 |
| V4 The Love | 2014 | 法式 House | 能当派对背景的电子乐 |
| V5 Brazil | 2016 | 桑巴、巴图卡、嘉年华 | 热带打击乐的热闹感 |
| V6 Alive | 2018 | 二次元 × 嘻哈 × 日系电音 | 低音重、带迷幻感 |
| V7 Jeevan | 2019 | 印度风、宝莱坞律动 | 神秘、转音多的异域节奏 |
| V8 Dystopia | 2020 | 赛博朋克、暗色电子 | 冷、暗、带失真的科幻氛围 |
| V9 Wekiddy | 2023 | 90 年代复古嘻哈 | 怀旧、色彩跳脱的复古派对 |

## 三、按口味挑的三条捷径

- **第一次玩**：V1 Alpha 或 V3 Sunrise。Alpha 声音结构最直白，Sunrise 层次分明，适合先用它建立耳朵；
- **想要戏剧性**：V8 Dystopia 与 V6 Alive 的层次最厚，适合录长作品；
- **想换心情**：V5 Brazil 管热闹、V7 Jeevan 管神秘、V9 Wekiddy 管怀旧——这三版彼此反差最大。

每套都是 7 个站位、20 个声音，够录完整一首；风格不合口味就换下一套，不用在一套里挖到底。

## 四、系统版本决定列表长度

系统版本直接决定你能看到几套：

| 系统 | 能拿到的版本 |
| --- | --- |
| Android 7.0 及以上 | 全部 9 套 |
| Android 7.0 以下 | V1 Alpha 到 V8 Dystopia |
| iOS 15.6 及以上 | 全部 9 套 |
| iOS 15.6 以下 | V1 Alpha 到 V8 Dystopia |

版本列表「缺斤少两」多半是系统版本卡的，不是被隐藏——升级系统才是正解。选好版本之后怎么编曲，见 [节奏盒子玩法入门.md](节奏盒子玩法入门.md)；各版本的图文展示收在 [Incredibox 节奏盒子专题站](https://incredibox.bmww.store/)。
