# 手机测游戏帧率怎么看曲线

想知道一局游戏到底掉没掉帧，过去得把手机接上电脑跑采集工具；现在装个工具箱、激活免 ROOT 的 ADB 模式，手机自己就能把整局数据记下来。本篇讲怎么记录、曲线怎么读。三种工作模式的取舍见[三种工作模式与root取舍](三种工作模式与root取舍.md)，激活步骤见[免root激活adb模式的步骤](免root激活adb模式的步骤.md)。

---

## 为什么手机本机就能测

安卓系统的帧率数据本来就在系统层生成，只是没有界面给你看。Scene 这类工具箱在 ADB 模式下拿到系统级读取权限后，可以一边跑游戏一边把帧率、处理器负载、温度逐秒落盘——整套采集在手机本机完成，不用数据线，也不用电脑端软件。

这也是它和电脑端采集工具（Perfdog 一类）最大的差别：电脑端方案数据更全，但每次都要接线、装驱动；手机本机方案对普通玩家来说随手就能开一局测一局。

## 记录一局游戏的流程

1. **激活 ADB 模式**：按[免root激活adb模式的步骤](免root激活adb模式的步骤.md)完成无线调试授权，帧率记录功能在这一层才开放；
2. **打开监视器**：进入工具箱的功能页点「帧率记录」，首次会请求悬浮窗权限，把悬浮窗缩到屏幕角落；
3. **正常游玩**：跑你想测的那一局，悬浮窗上的实时数字就是当前帧率，后台同时在记完整曲线；
4. **回看记录**：打完回「帧率记录」页，选刚才那次的记录，完整曲线与负载数据都在里面。

## 曲线怎么读

| 看什么 | 说明 |
| --- | --- |
| 帧率曲线 | 平直代表稳，锯齿状起伏就是掉帧；结合时间点能定位到具体场景（团战、加载、切场景） |
| CPU / GPU 负载 | 与帧率同屏对照：帧率下坠而负载顶满，多半是性能不够；负载不高却掉帧，另找原因 |
| 温度曲线 | 温度爬升后帧率跟着跌，是典型的温控降频；这类掉帧靠关画质解决不了 |
| 耗电数据 | 配合耗电统计看单局耗电，判断是性能压力还是后台应用在抢电 |

读图时先看帧率再看温度，最后对照负载——顺序反了容易被单条曲线带偏。悬浮窗别开太大，遮住操作区域反而影响发挥。
