# 免root激活adb模式的步骤

ADB 模式是 Scene 的主力层：帧率记录、应用冻结这些常用功能都要在这一层才开放，而它不需要 ROOT。安卓 11 起系统支持无线调试，激活全程可以在手机上完成。本篇按准备、配对、执行三段讲清步骤；还装着应用的话先看[手机测游戏帧率怎么看曲线](手机测游戏帧率怎么看曲线.md)了解激活后能干什么。

---

## 激活前的准备

- **开启开发者选项**：设置 → 关于手机 → 连续点击版本号，直到提示已处于开发者模式；
- **打开无线调试**：在开发者选项里同时开启 `USB 调试` 与 `无线调试` 两项；
- **同意使用协议**：首次进入 ADB 模式时应用会弹出协议与风险说明，看清后同意才能继续。

不同品牌入口命名有差异，部分机型的开发者选项藏在「系统管理」「特殊权限」里；找不到就用设置里的搜索框搜「开发者」。

## 配对授权

无线调试需要一次配对码授权：

1. 进入系统的「无线调试」页面，点「使用配对码配对设备」，会显示一组一次性配对码与端口；
2. 在配对工具里输入这组配对码完成连接——身边有电脑可以用 adb 命令配对；没有电脑时，社区常用方案是借助黑阈（另一款工具）完成配对，它同样走无线调试通道；
3. 配对码是一次性的，过期或用错就重新取一组再试。

部分机型还需要在开发者选项里开启「禁止权限监控」，否则配对工具可能报权限不足。

## 执行激活脚本

配对成功后，把开发者提供的激活脚本下载到手机存储的 Download 目录，在配对工具的「执行指令」里运行：

```bash
sh /storage/emulated/0/Download/scene_adb_init.sh
```

看到 `Scene-Daemon OK` 提示即激活成功。脚本文件名要与指令里的路径逐字对应——下载后被重命名或换了目录，指令就找不到文件，这是激活失败最常见的原因。

## 激活失败排查

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 提示权限不足 | 「禁止权限监控」没开 | 开发者选项里开启后重新配对 |
| 配对码总提示错误 | 配对码过期或端口输错 | 重新点「使用配对码配对设备」取新码 |
| 脚本执行报找不到文件 | 路径与实际文件名不一致 | 确认脚本在 Download 目录、文件名与指令逐字相同 |
| 激活成功但功能仍灰着 | 没有重启应用 | 彻底退出 Scene 再打开，或重启手机 |

大版本更新后偶发激活失效，重启一次手机通常就恢复；还不行时检查登录账号与积分状态，这部分在[三种工作模式与root取舍](三种工作模式与root取舍.md)里有说明。
