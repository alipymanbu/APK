# 监控设备怎么添加到手机？三种常用方式逐一演示

装好手机客户端只是第一步，画面能不能出来，关键在设备添加这一步。以天视通方案的 Seetong 客户端为例，摄像头、录像机（NVR）进列表常见有三种方式，按现场条件任选其一即可。

## 方式一：同一 WiFi 下搜索添加（最省事）

前提：手机与设备接在同一路由器的网络里。

1. 确认摄像头或录像机已经接好网线并通电，路由器本身能上网；
2. 手机连上同一路由器的 WiFi；
3. 打开客户端，点设备列表右上角的「+」，进入搜索添加；
4. 搜到设备后点添加，按提示输入设备密码完成绑定。

这种方式适合装机当天就在现场的情况，搜出来的设备直接进列表，不用手输任何编号。

## 方式二：云 ID + 密码手动添加（人不在现场也能加）

设备云 ID 一般印在机身标签上，录像机则在接了显示屏的画面里能看到。

1. 先在设备端找到云 ID（如 6729718 这类纯数字编号）；
2. 客户端里点「+」选手动添加，输入设备 ID；
3. 用户名默认 admin，密码填设备激活时设置的云密码；
4. 信息核对无误后点添加，设备就挂到账号下了。

远程接手别人的安装项目、或者给老设备补绑账号，走这条路径最稳。

## 方式三：直连添加（热点与网线两种）

- **手机直连设备热点**：部分摄像机自带热点，手机在 WiFi 列表里连上它，客户端会自动识别并引导添加；
- **网线直连**：客户端里选「网线直连添加」，按引导把手机与设备拉到同一链路完成配置。

新款 WiFi 摄像机还支持蓝牙配网（如 TD53W 等机型）：打开手机蓝牙，客户端点添加设备后按引导连接 2.4G WiFi，搜索绑定即可。注意这类配网只支持 2.4G 频段，5G WiFi 连不上属正常。

## 搜不到设备时，先查这三样

- 手机与设备是否真的在同一网段——连了访客网络或不同路由器就会搜不到；
- 设备是否通电、网线两端是否插紧；
- 设备密码是否被改过——密码对不上也会表现为添加失败，找回或重置密码后再试。
