# 监控设备离线、画面加载不出来？按这四层排查

客户端里设备变成灰色、通道掉线、点开画面一直转圈——这类问题八成出在通电、网线、网段、密码四样上。别急着恢复出厂，先按层级定位，多数几分钟就能恢复。

## 第一层：分清是「设备离线」还是「通道离线」

监控链路是「摄像机 → 录像机 → 云端 → 手机」，两层断点表现不同：

- **设备整体离线**：客户端列表里整台录像机灰色，下面所有通道都看不了；
- **通道离线**：录像机本身在线，只是某几路摄像头灰色。

先在客户端里看清提示属于哪种，再往下对号入座。

## 第二层：设备整体离线，查供电与外网

- 查录像机电源与指示灯，断电重启一次；
- 查录像机到路由器的网线两端是否插紧，路由器本身要能上网；
- 设备端密码改过也会导致整台掉线，重输新密码后等两三分钟看状态。

## 第三层：通道离线，看录像机上的提示

在录像机接显示屏的界面里打开视频管理，看掉线通道报什么：

**报「网络断开」**：

1. 对比掉线摄像头与录像机的 IP：第三位不一致就是网段不同，开启多址模式把网段对齐，应用后等两分钟左右；
2. 网段一致还掉线，用通道旁的诊断按钮跑一次网络检测——丢包 0%、回应 10ms 以内算线路良好，出现 Timeout 就是线路不通；
3. 丢包高或时通时断，重点查水晶头和交换机端口，换个网口或换根线再试。

**报「用户名或者密码错误」**：

- 摄像机密码被改过就在视频管理里双击该提示，输入新密码重新连接；
- 第三方协议（onvif）的摄像机密码要找对应厂商确认；
- 实在找不回密码，恢复出厂会回到初始密码，再重新搜索添加。

## 第四层：设备在线，但手机端画面出不来

- 先切一次网络（WiFi 与流量互换），排除手机侧波动；
- 只有某一路出不来就回到第三层单独查那条通道；
- 全部通道都黑屏而设备显示在线，重启录像机再试。

客户端一直装不上、设备加不进列表的，先把前一步走通：方法都写在[监控设备怎么添加到手机](监控设备怎么添加到手机.md)这篇里。
