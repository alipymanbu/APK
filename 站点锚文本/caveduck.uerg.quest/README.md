# Caveduck（鸭答鸭答）角色扮演聊天入门

Caveduck，中文圈常叫「鸭答鸭答」，是一款实时 AI 角色扮演聊天应用：从 30 万以上的角色库里挑一个入戏，用文字、语音和图片把故事聊出来，也可以自建角色公开给社区。这个目录收录围绕它的入门内容：怎么装到手机、怎么挑角色、点数机制怎么运转。

想直接看整理好的介绍与安卓安装文件资源入口，移步 [Caveduck 介绍站](https://caveduck.uerg.quest/)。
