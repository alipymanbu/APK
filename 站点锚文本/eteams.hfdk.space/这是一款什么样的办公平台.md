# eteams 是一款什么样的办公平台

> 想搞清楚 eteams 是做什么的、能管公司里哪些事、跟传统装在服务器上的办公软件差别在哪，看这一篇就够。

## 一、一句话定位

eteams 是泛微网络（2017 年上交所主板上市，代码 603039）旗下面向企业团队的一体化移动办公云平台。它走 SaaS 路线：不用买服务器、不用安排实施人员进场，用一个手机号注册就能把团队开起来，当天就能开始处理审批、写日报、打考勤。

按产品公开页面的口径，它的规模数据是：注册用户 90 万以上，覆盖 80 多个细分行业，沉淀了 1000 多个岗位场景的成熟应用模板，随开随用的云应用有 30 多个。

## 二、它管的是公司日常运转的哪几段

eteams 的模块围绕「人和事」铺开，挑使用频率最高的几块说：

| 模块 | 干什么用 |
| --- | --- |
| 审批流程 | 请假、报销、用章、采购这类流程全部电子化，手机上发起、手机上批完 |
| 移动考勤 | 基于位置的上下班签到签退，自动形成考勤轨迹；外勤签到还能关联客户留痕 |
| 工作日报 | 每天的成果随手记，系统自动提炼成周报、月报，管理层能往下钻到具体事项 |
| 任务与项目 | 任务互相分派、随时反馈进展；跨团队项目用甘特图盯进度 |
| 客户管理 CRM | 线索、客户、商机、报价、订单合同沿销售漏斗一条线管到底 |
| 知识文档 | 团队统一的知识网盘，多人在线编辑、按权限下载 |
| 人事 HRM | 人事档案、招聘、绩效、考勤统计、工资单发放统一处理 |

这些模块不是全都要开：按需启用、用不到的可以先不开，管理员还能用零代码、低代码方式搭自己的个性化应用。

## 三、和装在服务器上的办公软件差在哪

传统部署型办公软件要先买服务器、装环境、做实施，上线周期按月算；eteams 这种云端平台把这一段全免了——注册即用，功能更新由平台侧统一做，组织规模变了也不用重新规划硬件。代价是数据存在云端、深度定制能力不如部署型产品强，所以大中型组织如果要做平台级定制，通常选部署型产品线；中小团队、异地协作多的团队，云端的注册即用反而更划算。

两类的账号体系并不互通，装手机端之前先确认公司在用哪条线，分辨方法写在 [和e-cology怎么分辨.md](和e-cology怎么分辨.md) 里。

建议路径是：手机装上 App → 注册账号 → 加入公司团队（或自己建一个）→ 把考勤、审批先跑起来。手机端的安装过程和登录注意事项在 [手机端从安装到登录团队.md](手机端从安装到登录团队.md) 逐步讲；7 天全功能试用结束后哪些能用哪些要付费，看 [免费试用和收费的边界.md](免费试用和收费的边界.md)。
