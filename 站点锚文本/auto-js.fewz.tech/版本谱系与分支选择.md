# Auto.js、AutoX、AutoJs6 到底是什么关系

> 搜 Auto.js 时结果里混着免费版、Pro、AutoX、AutoJs6，名字像、包名不同，装错一份教程就对不上。这篇按社区整理的年表把脉络讲清，再给一个按需选择的路标。
> **相关文档**：[安卓版下载与安装步骤.md](安卓版下载与安装步骤.md) · [无障碍服务开启与被拦处理.md](无障碍服务开启与被拦处理.md)

## 一、一张年表看懂脉络

按社区年表的口径（具体日期以各项目仓库为准）：

| 时间 | 事件 |
| --- | --- |
| 2017 年 1 月 | 开发者 hyb1996 开源 Auto.js，MPL 2.0 授权，「免 Root + JavaScript」的玩法就此立住 |
| 2020 年 3 月 | 免费版停在 4.1.1 Alpha2 不再更新，作者转做付费的 Auto.js Pro |
| 2020 年 7 月 | 社区从 4.1.1 的源码接续出 AutoX，界面与 API 一脉相承 |
| 2021 年 12 月 | 另一条社区分支 AutoJs6 起步，继续对新版安卓做适配 |

也就是说，「Auto.js」这个词底下至少有三条活着的线：停在 2020 年的免费开源版、作者渠道的付费 Pro、以及两条社区接续的免费分支。

## 二、认版本别靠图标，靠包名

这几支应用名字与图标都长得像，包名才是身份证：

- `org.autojs.autojs` —— 免费开源版 4.1.1，也就是多数老教程对应的那份
- AutoX、AutoJs6、Pro 的包名各不相同

包名不同意味着它们能同时装在同一台手机上互不干扰，想对比着用是可行的。装完在系统「应用信息」里核对一眼，比靠名字猜可靠得多。安装与授权的完整步骤在[安卓版下载与安装步骤](安卓版下载与安装步骤.md)里单独写过。

## 三、按需求选

| 你的情况 | 更合适的方向 |
| --- | --- |
| 手机系统不新，或就想用 4.1.1 那份 | 免费开源版，教程最多、API 资料最全 |
| 系统很新（尤其 Android 13+），老版本权限被拦 | 看 AutoX、AutoJs6，对新系统的适配更勤 |
| 手上有旧脚本要接着跑 | 三条线同源，核心的 `text()` / `click()` / `findOne()` 通用，老脚本基本能跑 |
| 需要 OCR、代码加密这类扩展能力 | 各分支的边缘模块不同，先查对应分支的文档再定 |

换分支时有两点要知道：脚本与配置不互通，迁移要把脚本文件拷过去；查 API 资料时认准对应分支的文档版本，混着查会看到手里这份没有的函数。

## 四、给个省事的起点

不想在版本里绕的，从免费开源版 4.1.1 入手最直接：体积小、资料全，跑通第一段脚本后再决定要不要迁去社区分支。从原理到示例脚本的入门整理见 [Auto.js 介绍与入门站](https://auto-js.fewz.tech/)，权限被拦的处理则看[无障碍服务开启与被拦处理](无障碍服务开启与被拦处理.md)。
