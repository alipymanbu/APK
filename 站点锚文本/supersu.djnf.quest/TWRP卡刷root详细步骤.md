# TWRP 卡刷 root 详细步骤：从备份到验证的全流程

> 本篇整理用 TWRP 卡刷获取 root 的完整操作链：刷前要备齐什么、八步刷入怎么走、首次开机为什么慢，以及刷完怎么验证 root 真的到位。
> **相关文档**：[Root 授权管理器怎么选](Root授权管理器怎么选.md) · [SU 二进制报错处理](SU二进制报错处理.md)

---

## 一、刷前准备：四样东西缺一不可

卡刷 root 动的是系统层，翻车成本高，这几样先备齐：

1. **解锁 bootloader**——这是前提中的前提，没解锁连 TWRP 都进不去，按机型教程处理；
2. **刷入 TWRP**（或 CWM 等 recovery）——同样按机型来，本篇不展开；
3. **整机备份**——解锁与刷入都可能清空数据：相册、聊天记录先导出；会玩 TWRP 的再做一份 Nandroid 备份（Backup → 勾 System、Data、Boot → 滑块确认），这是刷坏时的退路；
4. **电量五成以上**——别在 10% 电量的时候动 recovery。

root 方案本身按设备年代选：老设备用 SuperSU 的卡刷 ZIP，新设备走 Magisk 的 boot 修补，选择的依据见 [Root 授权管理器怎么选](Root授权管理器怎么选.md)。

## 二、八步刷入

1. 把卡刷 ZIP 放进手机**内置存储**的 `Download` 目录就行，路径别太深；
2. 关机，按住「电源 + 音量上」（组合键因机型而异）进入 TWRP；
3. 首次刷 root 前先备份：**Backup** → 勾选 System、Data、Boot → 滑动确认（做过 Nandroid 的可跳过）；
4. 回主界面选 **Install**，找到 ZIP 文件；
5. 选中后**滑动滑块确认刷入**（Swipe to Confirm Flash）；
6. 等底部日志出现 **Successful**——通常几十秒，中途别强制重启；
7. 可顺手 **Wipe cache/dalvik**（可选，不清也行）；
8. 选 **Reboot System**。

ZIP 在电脑上不方便拷进手机时，还有 ADB Sideload 这条路：TWRP → Advanced → ADB Sideload → 滑动开始，电脑端在 adb 同目录执行 `adb sideload 文件名.zip`。

## 三、首次开机：慢是正常的

刷完后的第一次开机会明显比平时慢——系统在重建 dalvik 缓存、安置新增的部件，等三五分钟很常见，**别急着强制重启**。超过十分钟还卡在第一屏才需要处理：回 TWRP 用刷机前做的备份还原。个别 TWRP 版本会在刷完时问"要不要顺便安装管理器应用"，选不装，之后单独装 APK 即可。

## 四、刷完验证一分钟

随便挑一个需要 root 的工具（文件管理器、卸载器都行），做一次会触发 root 的操作：

- 弹出授权确认窗口 → 点允许 → 工具正常干活，root 与管理器都就位；
- 工具直接报"没有 root / 无 SU 二进制" → 只装了管理界面、root 本体没进去，把卡刷包重刷一遍。

授权弹窗之后怎么拍板、日志在哪看，属于日常使用层面，介绍站上有成篇的整理，入口：[SuperSU 介绍站](https://supersu.djnf.quest/)。

## 五、刷入中断怎么排查

刷入过程报 Error 1、或开机后各种异常，多数都能归到三类成因：ZIP 文件损坏（重取一份干净的）、boot 镜像与固件版本不匹配（重刷对应的原版 boot 再试）、recovery 太旧（升级 TWRP）。具体的报错对照与处理，见 [SU 二进制报错处理](SU二进制报错处理.md)。
