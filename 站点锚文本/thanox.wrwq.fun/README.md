# Thanox：围绕息屏链路的安卓系统管理工具

> 本目录收录 Thanox 的几篇实用短文，回答装之前最常见的三个问题：激活方式怎么选、智能冻结怎么用、没有 Root 能用到什么程度。想先整体了解这款工具，可看 [Thanox 介绍站](https://thanox.wrwq.fun/)，那里按「启动时拦截、息屏即冻、息屏后清理」这条息屏链路把功能串起来讲。

## 目录里有什么

- [激活方式怎么选.md](激活方式怎么选.md) —— Xposed、Magisk、Shizuku 三条路线的门槛与取舍，以及更新后失效的处理
