# Thanox 无 Root 能用吗：Shizuku 路线的能与不能

> Thanox 常被当成 Root 设备专属的工具，其实不刷框架、不 Root 也能用——走 Shizuku 授权。本篇讲清这条路线能打开哪些功能、牺牲了什么、怎么激活，帮你判断要不要为此刷框架。激活步骤的完整版见[激活方式怎么选.md](激活方式怎么选.md)。

---

## 先说结论

没有 Root 也能用 Thanox：装好 APK 后启动 Shizuku，再在应用内切换到 Shizuku 授权即可，首次打开时的「等 Shizuku 就绪」提示就是在引导这一步。代价是功能面比 Xposed 模式窄一截。

## Shizuku 路线怎么激活

1. 安装并打开 Shizuku，按它的引导把服务进程启动起来（无线调试或连接电脑都可以）；
2. 打开 Thanox，切到 Shizuku 模式并授权；
3. 回主面板确认功能可用。

之后注意一点：Shizuku 服务重启后（比如手机重启了），要重新启动一次服务，Thanox 才能继续拿到授权。

## 与 Xposed 模式的差别在哪

Xposed 模式是给系统打补丁，很多动作在系统进程里完成，所以能管得深：隐匿这类能力、以及更完整的后台管控，都建立在补丁之上。Shizuku 路线没有这个层面，能做的集中在 Shizuku 权限够得着的范围内。

实际取舍可以这么定：

- 只想拦自启、管冻结、清理后台——Shizuku 基本够用；
- 要用隐匿、情景模式里执行 su 命令这类更深的动作——需要框架路线；
- 设备本来就有 Xposed 类框架——直接走 Xposed 模式，不必绕 Shizuku。

## 几个不用 Root 也适用的事实

- 不需要给 Thanox 保活或自启动，只有情景模式里用到 su 命令时才要允许它后台启动；
- 各功能的配置存放在系统目录，清掉应用数据不会丢功能配置，只清掉界面层的设置；
- 它与 X-APM 这类工具不能同时开，二选一；
- 从 Shizuku 切换到 Xposed 模式不需要重装，补丁状态确认的入口在 设置 → 关于 → 补丁状态。

拿不定主意就先走 Shizuku 用几天，缺什么再决定刷不刷框架——框架路线的门槛与步骤都在[激活方式怎么选.md](激活方式怎么选.md)。装好后第一个值得配的功能是智能冻结，操作见[智能冻结怎么用.md](智能冻结怎么用.md)；这款工具的完整功能排布，[Thanox 介绍站](https://thanox.wrwq.fun/)里按息屏链路有一份走读。
