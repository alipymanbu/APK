# Thanox 激活方式怎么选：Xposed、Magisk、Shizuku 三条路线

> 装完 Thanox 的 APK 只是第一步，功能要在激活之后才会亮起来。本篇按设备条件把三条激活路线的门槛、操作步骤和取舍讲清楚，并处理最常出现的「更新后提示未激活」问题。三条路线的功能差异，另见[无Root能用吗.md](无Root能用吗.md)。

---

## 先判断：你的设备适合哪条路线

| 路线 | 系统门槛 | 前置条件 | 特点 |
| --- | --- | --- | --- |
| Xposed 模式 | Android 6+ | 已装好 Xposed 类框架 | 功能最全，每次更新后要重新勾选模块 |
| Magisk 模式 | Android 11+ | 已装 Magisk，且装了 Riru 或开启 Zygisk | 实验性，功能目前相对较少；更新要同步刷补丁 |
| Shizuku 路线 | 无硬性门槛 | 能启动 Shizuku 服务即可 | 不刷框架、上手最快，功能比 Xposed 模式少 |

三选一即可，不要叠加。拿不准就从 Shizuku 开始，缺什么再换框架路线。

## Xposed 模式：最常规的一条路

1. 确认设备上已经有正常工作的 Xposed 框架（或兼容其 API 的同类框架）。
2. 打开框架管理器，在模块列表里勾选 Thanox。
3. 支持作用域的框架里，作用域至少勾选「Android 系统」；之后要对某个应用启用隐匿类功能，再把那个应用也勾上。
4. 重启设备。

每次更新 Thanox 之后，回到框架管理器重新勾选一遍模块再重启，这是最容易漏的一步。

## Magisk 模式：实验性，补丁要跟着更新走

1. 设备已装 Magisk，且安装了 Riru（Magisk v23+）或开启了 Zygisk（Magisk v24+）。
2. 打开 Thanox 的 设置 → 关于 → 补丁状态，导出 Magisk 补丁；也可以直接把 Thanox 的 APK 改名成 .zip 当补丁用。
3. 把补丁刷进 Magisk，重启。

注意：Thanox 每次更新，补丁都要重新导出、重新刷，两边的版本要始终对齐。

## Shizuku 路线：不动框架的选择

先启动 Shizuku 服务，再到 Thanox 里切换到 Shizuku 授权即可。首次打开应用时也会有「等 Shizuku 就绪」的提示，跟着装好并授权就行。代价是功能面比 Xposed 模式窄，具体差别见[无Root能用吗.md](无Root能用吗.md)。

## 更新后提示未激活，怎么办

这是被问得最多的问题，原因几乎只有一个：更新冲掉了之前的激活动作。

- Xposed 模式：框架管理器里重新勾选 Thanox，重启；如果重新勾选后仍然识别失败，检查一下是否限制了框架管理器的广播权限。
- Magisk 模式：重新导出补丁（或用新 APK 改名 .zip）刷入。

另外两点提醒：更新这类给系统打补丁的工具之前先做好备份，万一卡在开机，从框架侧的安全模式或模块开关临时停用 Thanox 就能回到系统；它与 X-APM 这类工具不能同时开，二选一。

激活完成后回到主面板，各功能板块就会亮起。接下来配置息屏行为，看[智能冻结怎么用.md](智能冻结怎么用.md)。想先完整了解这款工具的功能排布，可以浏览 [Thanox 介绍站](https://thanox.wrwq.fun/)，它按息屏链路的顺序把功能串成一条线讲。
