# PlainApp 站点资料索引

这里是 PlainApp 相关介绍文章的汇总页。PlainApp 是一款开源的安卓应用，把手机变成局域网里的一台小型 Web 服务器，电脑或平板的浏览器输入屏幕上的地址，就能传文件、看照片、收发短信和投屏。

想快速了解它的上手路径、权限开关与横向对比，可以看 [PlainApp 介绍站](https://plainapp.ggcd.store/)，安装文件资源的获取入口也集中在这一个入口页里。
