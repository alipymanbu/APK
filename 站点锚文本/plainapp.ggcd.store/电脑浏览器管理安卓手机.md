# 用电脑浏览器管理安卓手机，现在是一件很轻的事

想在电脑上处理手机里的东西，很多人的第一反应还是数据线加手机助手，或者装一个带云端账号的同步软件。前者插拔麻烦，后者要注册账号、数据还得绕一圈第三方服务器。PlainApp 提供了第三种思路：它把手机本身变成一台局域网里的小型 Web 服务器，电脑浏览器输入地址就直接访问。

## 浏览器面板里都有什么

在手机上按下启动服务，屏幕会给出形如 `http://km.local:8080` 的地址，同一 Wi-Fi 下的电脑浏览器打开它，能看到一个完整的网页面板：

- **文件管理**：内部存储、SD 卡、U 盘都能浏览，上传、下载、重命名、移动、删除在网页里完成；
- **照片与视频**：相册按时间线浏览，视频和音乐直接串流播放，不用先拷出来；
- **短信与通话记录**：电脑键盘上读短信、回短信，通话历史支持搜索筛选，验证码不用再拿手机；
- **Markdown 笔记**：内置笔记工具，手机与浏览器编辑的是同一份数据；
- **屏幕镜像**：通过 WebRTC 把手机画面实时投到浏览器，最高 30 帧并带声音；
- **RSS 阅读器**：无算法推荐的订阅工具，阅读也能留在浏览器里。

这些能力不需要在电脑上装任何客户端，Chrome、Edge、Firefox、Safari 都可以，平板和另一部手机同样能访问。

## 权限是逐项开关的

比较讲究的一点是权限设计：网页设置里把「管理文件、联系人、短信」拆成独立开关，只想传文件就只打开文件权限，其余保持关闭，面板里也不会出现对应入口。会话列表、安全选项、排查问题集中在同一页，访问地址的 HTTP 与 HTTPS 也可以自行切换。

## 适合什么样的人

如果你不放心把照片和聊天记录交给云端中转，或者只是嫌装桌面客户端太重，这种方式值得试一次。项目按 AGPL-3.0 开源，手机端要求 Android 9.0 以上，安装包不到 100 MB。更多上手细节与安装入口，见 [PlainApp 介绍站](https://plainapp.ggcd.store/)。
