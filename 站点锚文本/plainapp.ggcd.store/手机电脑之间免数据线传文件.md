# 手机和电脑互传文件，可以不插线也不走云

拍照当天想把照片交给电脑修图、出门前把课件拖进手机、聊天记录里的文件要在桌面端归档——这些高频动作靠数据线和聊天窗口来回转发，效率都不高。局域网直传是更顺的一条路：两台设备在同一 Wi-Fi 下，浏览器之间直接传。

## 为什么局域网直传更省事

常见的替代方案各有负担：云盘方案要先上传再下载，大文件受速度和容量限制；带云端账号的手机助手要把数据交给第三方服务器中转，还要注册登录。局域网直传的逻辑是数据只在内网两端之间流动，速度取决于路由器，隐私也在自己手里。

## 用 PlainApp 做文件互传的步骤

1. 手机端装好应用后点「启动服务」，屏幕上会显示形如 `http://192.168.x.x:8080` 的地址；
2. 电脑浏览器打开这个地址，进入文件面板，内部存储、SD 卡、U 盘的目录结构都在左侧可见；
3. **电脑到手机**：把文件拖进浏览器窗口，或用上传按钮选择，文件直接落到手机对应目录；
4. **手机到电脑**：在面板里选中文件或文件夹点下载，照片、视频、APK 都能批量取回；
5. 用完在手机端点「停止服务」，访问通道即关闭。

整个过程没有账号环节，也没有传输大小的限制，照片原样传输不压缩。

## 两个实用细节

- **权限最小化**：网页设置里的访问权限是逐项开关的，只想传文件就只开「管理文件」，短信、联系人保持关闭；
- **HTTPS 可选**：地址支持 HTTP 与 HTTPS 切换，在公司等公共内网里建议用 HTTPS，连接本身也是加密的。

这款应用按 AGPL-3.0 开源，手机端要求 Android 9.0 以上，安装包不到 100 MB，功能面板的完整介绍见 [PlainApp 介绍站](https://plainapp.ggcd.store/)。

文件之外，浏览器面板还能管短信、看相册、投屏，相关玩法见[电脑浏览器管理安卓手机](电脑浏览器管理安卓手机.md)与[安卓手机投屏到电脑浏览器](安卓手机投屏到电脑浏览器.md)。
