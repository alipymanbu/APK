# 安卓版下载安装步骤

HandShaker 手机端是一个体积很小的安卓应用（v1.2.0 版约 5.5 MB），出自锤子科技（北京）有限公司，装在手机上用于与电脑客户端配对。本篇记录从下载 APK 到打开应用的完整流程。想了解它能为电脑端带来什么，可以先看 [HandShaker 介绍站](https://handshaker.ggcd.store/)。

---

## 安装前的环境确认

- 手机为安卓系统，留存空间至少留出几十 MB；
- 电脑端建议一并准备好（Windows 或 macOS 版客户端），装完手机端就能直接连。

## 下载与安装流程

1. **获取安装包**：从网盘分享页把 `HandShaker_v1.2.0.apk` 转存到自己的网盘账号，再下载到手机存储；
2. **允许安装**：首次安装时系统会提示「未知来源应用」，在弹出的设置页允许该来源安装，返回安装页继续；
3. **完成安装并打开**：装好后打开 HandShaker，按提示授予文件访问等权限；在「设置 → 检查更新」里可以看到当前版本号；
4. **连接电脑**：手机与电脑接入同一个 Wi-Fi 后两端同时打开应用，或直接插上 USB 数据线，在电脑端选中这台手机即可。具体操作见 [手机端连接电脑教程.md](手机端连接电脑教程.md)。

## 常见安装问题

**点开 APK 提示「无法解析安装包」？**
多半是下载不完整或传输中断，回到网盘重新下载完整的 APK 再装；反复出现时，换一台设备先验证安装包本身没问题。

**安装按钮置灰或被拦截？**
这是系统对未知来源应用的常规限制：按弹窗提示允许该来源安装即可；部分机型的开关在「设置 → 安全」里，装完可以收回权限。

**装好了但电脑端搜不到手机？**
先确认电脑端也装了客户端、两端在同一 Wi-Fi、手机亮屏解锁；仍不行就按 [连接搜不到手机的排查方法.md](连接搜不到手机的排查方法.md) 逐项排查，重点是各品牌的后台运行权限。
