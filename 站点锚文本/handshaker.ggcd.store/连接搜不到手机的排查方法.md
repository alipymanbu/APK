# 连接搜不到手机的排查方法

电脑端搜不到手机、点了连接没反应、连上几分钟后又断开——是 HandShaker 用户反馈最多的一类问题。本篇把散落在各处的处理办法整理成一份按顺序走的排查清单。连接方式本身还没跑通的，先看 [手机端连接电脑教程.md](手机端连接电脑教程.md)。

---

## 第一步：把最简单的先排除

- 手机端 HandShaker 已安装且处于**打开状态**，手机**亮屏解锁**；
- 电脑端客户端也已安装（两端缺一不可，手机端是电脑端工作的前提）；
- 手机弹出「允许连接」时选择了允许，而不是随手点了拒绝。

## 第二步：无线场景的重点检查

1. **两端必须在同一个 Wi-Fi**：手机用流量、电脑用有线这种组合搜不到是正常的；
2. **网络本身可用**：公司网络、酒店网络常做客户端隔离或要求二次认证，搜不到就换个手机热点验证；
3. **路由器设置**：部分路由器（如思科）默认关闭「组播模式」，设备发现会失效，需要联系网络管理员放开；
4. **重启两端应用**再搜一次——大量「搜不到」到这一步就解决了。

## 第三步：USB 场景的重点检查

- 把 USB 连接方式切换为「**仅充电**」或「**PTP（查看图片）**」，再重新插拔；
- 换一根数据线（有些线只能充电、不能传数据），或换电脑上其他 USB 接口；
- 重启电脑端客户端。

## 第四步：连接总断开 → 放开后台权限

无线连接建立后几分钟就断，多半是系统把手机端的后台活动限制了。HandShaker 手机端服务是保持连接的前提，需要按机型放开：

| 机型 | 设置路径 |
| --- | --- |
| 华为 | 设置 → 权限管理 → HandShaker → 设置单项权限 → 打开「信任此应用」 |
| 小米 | 授权管理 → 自启动管理打开开关；「神隐模式」中把应用配置选为「无限制」 |
| 魅族 | 手机管家 → 自启动管理 → 勾选允许后台启动 |
| 三星 | 智能管理器 → 内存 → 自动运行应用程序 → 打开 HandShaker（7 天未使用会被自动关闭，需再开） |
| 乐视 | 设置 → 隐私授权 → 自动启动列表 → 添加 HandShaker |

实在复杂的无线环境（信号干扰、公共网络限制），换 USB 有线连接是最稳的兜底。
