# 两步验证器怎么选：先把「数据放在哪」想清楚

> 本篇把常见的几类两步验证（2FA）工具放在一起，比较它们在数据存放、备份方式与迁移上的取舍，帮你在挑选时想清楚自己要哪一种。

---

验证器这个工具平时存在感很低，可一旦换手机或手机丢失，它就是「能不能登上自己账号」的分水岭。市面上的验证器大致分两类，分歧点只有一个：**你的密钥放在谁手里**。

## 一、两类验证器的核心分歧

**云同步型**：登录同一个账号，验证码自动出现在所有设备上。省心，代价是密钥存在服务端，账号体系本身成了单点——账号被盗，密钥就跟着暴露；服务商停止某项同步服务时，用户也只能被动接受。

**本地保管型**：密钥存在手机本地的一个加密文件里，不设账号、不联网同步。Aegis 属于这一类，它的保险库用 AES-256 加密，备份文件由你自己导出、自己存放。代价是备份这件事从服务商手里接了过来，变成你自己的责任。

两类没有绝对优劣，看的是使用者对「方便」和「掌控」的权重分配。

## 二、选本地保管型时看什么

以 Aegis 为例，这类工具值得逐项对照的能力有：

| 能力 | 为什么重要 |
| --- | --- |
| 加密存储 | 保险库文件丢了、被人拿到，没有密码也解不开 |
| 生物识别解锁 | 日常打开不用反复输长密码，密码留作退路 |
| 导入能力 | 能整批接收其他验证器的存量条目，换工具不用逐条重录 |
| 导出能力 | 随时能把数据完整带走，不被锁在某一款里 |
| 离线 | 应用没有网络权限，密钥不会因应用自身行为外传 |

这几项里，**导入与导出**最容易被忽视，却在换工具的那天最致命——只能进不能出的验证器，等于把你的第二道门锁焊死在别人家墙上。

## 三、别忽略的平台边界

验证器是跟着系统走的。以 Aegis 来说它只有安卓版，没有 iOS、桌面端或浏览器扩展的计划；同时在用 iPhone 的话，要么另配一个跨平台方案，要么接受两台设备各管各的。选型前先确认自己所有设备能不能被一款工具覆盖，再谈其他。
