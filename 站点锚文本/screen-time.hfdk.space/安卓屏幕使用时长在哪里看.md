# 安卓屏幕使用时长在哪里看

> 想知道今天手机亮了多久屏、时间花在哪个应用上——先把各家的入口位置找出来。
> **相关文档**：[屏幕时间统计工具怎么选.md](屏幕时间统计工具怎么选.md) · [想少玩手机先看清使用数据.md](想少玩手机先看清使用数据.md)

想看「今天玩了多久手机」，入口藏得比想象中深，而且各家叫法不一样。这篇把常见的几个位置一次列全，顺带说清系统自带统计能看什么、看不到什么。

## 一、各品牌系统的入口

不同品牌的入口与叫法差异不小，路径随系统版本可能变动，以实际显示为准：

| 品牌 | 常见路径 |
| --- | --- |
| 原生安卓 / Pixel | 设置 → 数字健康与健康连接（Digital Wellbeing） |
| 小米 MIUI | 设置 → 屏幕时间管理 |
| 华为 / 荣耀 EMUI | 设置 → 健康使用设备 |
| OPPO / realme | 设置 → 应用使用时间（或「数字健康」） |
| vivo OriginOS | 设置 → 屏幕使用时间 |

进去之后通常能看到：当天总亮屏时长、分应用时长排行、解锁次数等。多数品牌还带限额与停用时段功能。

## 二、系统统计的两个盲区

系统自带的统计对多数人够用，但有两处常被提到：

1. **换机不连续**：各品牌界面与口径不同，换了手机之后旧数据、旧习惯都要重新适应一遍；
2. **图表维度有限**：想按周对比、按小时拆分看某天的时间分布时，部分系统的图表比较粗。

## 三、用第三方工具补齐

想要一份界面统一、能按天/周/小时拆解的统计视图，可以装一个专门做统计的应用，比如 Screen Time（开源应用，只做统计、不申请联网权限）。它的界面与图表读法，在 [Screen Time 介绍站](https://screen-time.hfdk.space/) 有完整的整理，包括周视图、小时分布和分应用排行三种视角的用法。

装好之后的使用路径很简单：给一项「使用情况访问」权限，打开就是当天的时长数字。选型时该对比什么，见 [屏幕时间统计工具怎么选.md](屏幕时间统计工具怎么选.md)。
