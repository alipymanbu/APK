# 屏幕时间统计工具怎么选

> 系统自带、开源应用、带家长控制的服务——三类「屏幕时间」工具能力差别很大，一篇对齐再挑。
> **相关文档**：[安卓屏幕使用时长在哪里看.md](安卓屏幕使用时长在哪里看.md) · [想少玩手机先看清使用数据.md](想少玩手机先看清使用数据.md)

搜「屏幕时间」的人，想找的东西其实不一样：有人只要看数字，有人想管孩子的设备，有人在乎数据别出手机。先把三类工具分开，选择就简单了。

## 一、先分清三类工具

**第一类：系统自带统计。** 各品牌手机设置里都有，强项是能跟系统功能联动（限额、停用时段），弱项是界面与口径随品牌变，换机要重新熟悉。

**第二类：纯统计的开源应用。** 代表如 Atharok 开发的 Screen Time（安卓，GPL-3.0 许可证）：只做时长统计与图表，不做任何限制；不申请联网权限，数据留在本机。各机型界面一致，1.78M 的体积几乎不占空间。

**第三类：同名但完全不同的服务。** 苹果系统设置里的「屏幕使用时间」（Screen Time）是 iOS 的系统功能；另有一家商业亲子控制产品也叫 Screen Time，带远程管理与过滤。搜这个词时留意分辨，别把三类混为一谈。

## 二、按需求对号入座

| 你的需求 | 更合适的选择 |
| --- | --- |
| 偶尔看一眼今天用了多久 | 系统自带统计足够 |
| 要给应用限额、到点拦截 | 系统自带的管理功能 |
| 想要按周/按小时的细粒度图表 | 纯统计类应用（图表维度更细） |
| 在乎隐私、希望数据不出设备 | 开源、无联网权限的那一类 |
| 管理孩子的设备使用 | 带家长控制的服务（与本文统计类不是一回事） |

## 三、装纯统计工具前核三件事

1. **权限清单**：统计类应用只需要「使用情况访问」这类读取权限；如果一份「只看数字」的工具还要网络与通讯录权限，就值得警惕；
2. **包名与开发者**：同名应用多，安装前核对包名（如 Atharok 版是 `com.atharok.screentime`）与开发者署名；
3. **统计口径**：多数工具只统计亮屏使用，熄屏挂后台的时间不计入——对不上直觉时先核对口径再怀疑故障。

选定了之后，从哪里装、装完怎么授权，可以参考 [Screen Time 介绍站](https://screen-time.hfdk.space/) 下载页的四步流程；想先看看它界面长什么样，从[安卓屏幕使用时长在哪里看.md](安卓屏幕使用时长在哪里看.md)进入也很顺。
