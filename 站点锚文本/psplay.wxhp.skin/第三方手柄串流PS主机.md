# 在安卓手机上用第三方手柄串流 PS 主机

> 触屏玩主机游戏总觉得隔着一层？手柄才是串流的正确打开方式。本篇讲哪些手柄能直接用、按键认歪了怎么修、手边没手柄时怎么把手机本身变成一副手柄。

---

## 一、先看你手头这把能不能用

判断标准很简单：**能被安卓系统认出来的手柄，基本都能用**。具体到常见型号：

| 手柄 | 连接方式 | 说明 |
| --- | --- | --- |
| DualSense（PS5 原装） | 蓝牙 / USB | 直接可用；震感反馈与自适应扳机走 USB 有线时才生效 |
| DualShock 4（PS4 原装） | 蓝牙 / USB | 直接可用 |
| Xbox 系列手柄 | 蓝牙 / USB | 蓝牙或 OTG 有线均可 |
| 其他第三方手柄 | 蓝牙 / USB / OTG | 只要安卓 5.0 以上系统本身能识别，就能用 |

一个来自开发者手册的实用建议：蓝牙手柄在不少安卓设备上存在输入延迟，这是硬件层面的限制，不是串流客户端能修的——竞技类游戏尽量把游戏柄换成 **USB 有线连接**，延迟改善立竿见影。

## 二、按键认歪了：做一个映射档案

杂牌手柄常见的问题是按键错位：按 A 出来的是 B，摇杆触发的是十字键。这种情况不用换手柄，做一份按键映射档案即可——在侧边栏里打开"Button mapping"，按提示逐个按下你手柄上的键，让客户端记住每个物理键对应主机上的哪个键。注意：如果某个键被系统识别为 Home 键，任何应用都无法改写它的行为，映射时可以改用"双键组合"功能绕过去。

## 三、手边没手柄：把手机当手柄用

客户端内置 Gamepad Mode（主界面右上角三个点里开）：手机变成一台虚拟 DualShock，屏幕上显示摇杆与按键，只把操作指令传给主机、不回传画面和声音。两个用途：

1. **给朋友腾手柄**：真手柄挂在另一条 PS5 / PS4 游客档案上，手机虚拟手柄用主档案，两人同屏开玩；
2. **应急替代**：手柄没电或不在手边时先用触屏顶上，虚拟按键的位置、大小、透明度都能改。

## 四、装上客户端再谈手柄

手柄只是输入端，还得先有串流客户端。还没装的话，流程在 [手机串流玩PS5主机](手机串流玩PS5主机.md)；对这款客户端的手柄兼容范围想看更系统的说明，可以读 [PSPlay 功能介绍](https://psplay.wxhp.skin/)；出门后连回家里的主机继续用手柄玩，见[在外面远程玩家里主机](在外面远程玩家里主机.md)。
