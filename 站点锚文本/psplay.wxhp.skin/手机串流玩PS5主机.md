# 手机串流玩 PS5 / PS4 主机的完整流程

> 想躺床上或出差路上用手机接着玩主机游戏，需要一台安卓设备、一台开了远程游玩的主机，外加一次同网注册。本篇按首次使用的顺序把每一步讲清。

---

## 一、先确认手机和主机都够格

门槛不高，但缺一样就会卡在半路：

| 环节 | 要求 |
| --- | --- |
| 手机系统 | Android 5.0 或更高 |
| 手机硬件 | 双核处理器、2 GB 内存为佳；屏幕分辨率 1024 × 768 以上 |
| 手机联网 | 建议连 5 GHz Wi-Fi，延迟比 2.4 GHz 低一截 |
| 主机 | PS5 或 PS4，强烈建议用网线接进路由器 |
| 带宽 | 上传、下载各 15 Mbps 起步 |

配置一般的手机也能跑，做法是把串流设置里的分辨率和帧率调低，用画质换流畅。

## 二、在主机上打开远程游玩开关

注册前，主机侧要先亮出"身份码"：

- **PS5**：`设置` → `系统` → `远程游玩`，勾选启用，再进 `关联设备` 页面，屏幕上会出现一个 8 位数字。
- **PS4**：`设置` → `远程游玩连接设置`，勾选启用远程游玩，再进 `添加设备`，同样能看到 8 位数字。

这串数字就是待会儿要输进手机的注册码。注意它是会刷新的——如果放着太久没输，回到该页面拿当前显示的那组。

## 三、完成注册（关键的一次同网）

出于安全考虑，首次注册只能在**同一个网络**里完成，异地注册不支持。流程：

1. 手机连上与主机同一 Wi-Fi（主机插网线则连同一台路由器）；
2. 打开客户端，点"Register PS"，选择要注册 PS5 还是 PS4；
3. 输入主机上显示的 8 位注册码；
4. 按提示完成一次 PSN 登录——从 PS4 固件 7.0 起，注册必须携带与账号绑定的 Account-ID，登录页面是索尼自己的站点，账号密码不经过串流客户端，最终也只有账号 ID 存在手机本地；
5. 成功后回到主界面，就能选 Local Connect 直接连上开玩。

## 四、日常连接与画面调整

注册是一次性的，之后每次打开选 Local Connect 即可。串流中可以随时调分辨率、帧率和码率；带宽紧张时开启 FSR 超分，低分辨率画面的锐度也能补回来。想用手柄而不是触屏操作的，接着看[第三方手柄串流PS主机](第三方手柄串流PS主机.md)；人在外面想连回家里的主机，跳到[在外面远程玩家里主机](在外面远程玩家里主机.md)。

这款客户端相对原版远程游玩应用的具体差异（第三方手柄、流量串流、多主机档案、录屏等），在 [PSPlay 介绍站](https://psplay.wxhp.skin/) 里有逐条对照，安装文件资源的获取入口也放在那里。
