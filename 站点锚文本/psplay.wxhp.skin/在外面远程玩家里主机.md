# 人在外面，怎么远程连回家里的 PS5 / PS4

> 出门想接着玩家里主机的游戏，光装好客户端还不够——你得让外网的手机"找得到"家里的主机。本篇讲两条路：自动远程连接和手动端口转发，各自的条件与失败原因。

---

## 一、先想清楚走哪条路

| 方案 | 前提 | 适合谁 |
| --- | --- | --- |
| 自动远程连接 | 注册时完成过 PSN 登录；主机连着 PSN 且系统较新；客户端 5.0.0 起 | 不想动路由器设置的人 |
| 手动端口转发 | 能登录家里路由器后台 | 自动连接失败、或不想登录 PSN 的人 |

两条路都不通时，多半是运营商的问题，文末有排查思路。

## 二、省事的路：自动远程连接

在串流设置里打开"自动远程连接"，之后点 Remote Connect 选 Automatic，客户端会自己穿过外网找到主机，不需要在路由器上做任何设置。几个硬条件：

- 注册 PSPlay 时完成过 PSN 登录（这是它拿到连接凭据的唯一途径）；
- 主机处于联网状态、系统更新到新版本；
- 家有多台 PS4 时，只能连被设为主机的那台（索尼的限制，PS5 无此问题）。

这是实验性功能：主机 NAT 类型为 3 时可能连不上，常见原因是运营商没给路由器分配真正的公网 IP——这种情况只能打电话给运营商要公网 IP，或者改走下面的手动路线。

## 三、手动路线：端口转发

在路由器后台把以下端口指到主机的内网 IP（PS5 与 PS4 的端口不同，别照抄）：

| 端口 | 协议 | 适用 |
| --- | --- | --- |
| 9295 | UDP + TCP 都要 | PS5 / PS4 通用 |
| 9296 | UDP | PS5 / PS4 通用 |
| 9297 | UDP | PS5 / PS4 通用 |
| 9302 | UDP | 仅 PS5 |
| 987 | UDP | 仅 PS4 |

配好后还要做两件事：

1. 查出家里宽带的公网 IP（随便搜"my ip"就能看到），在外面连接时把这个公网 IP 填进 Remote Connect 的手动对话框——填主机的内网 IP 是连不上的；
2. 给主机在内网里配一个固定 IP，否则主机一重启换了地址，转发规则就指空了。

公网 IP 是运营商动态分配的，哪天突然连不上，先回头查公网 IP 是不是变了。

## 四、连不上时的三个检查点

1. **手机用了移动流量吗**——测试远程连接时，手机要断开家里 Wi-Fi 走流量，否则不算真的"在外网"；
2. **端口协议对不对**——9295 必须同时转发 UDP 和 TCP，只转一个会时通时不通；
3. **运营商给的是不是公网 IP**——路由器 WAN 口地址若是 100.64.x.x 或 192.168.x.x 开头，说明前面还有一层运营商 NAT，端口转发做了也无效，先找运营商要公网 IP。
