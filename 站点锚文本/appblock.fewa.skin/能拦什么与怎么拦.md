# AppBlock 能拦什么与怎么拦

> 本篇讲 AppBlock 的两条屏蔽路径（Quick Block 与 Schedules）、五种自动触发条件，以及「只封短视频板块、不卸载整个应用」的玩法。
> **相关文档**：[拦截不生效怎么排查.md](拦截不生效怎么排查.md) · [值得装吗与适合谁.md](值得装吗与适合谁.md)

## 两条路径，两种场景

AppBlock 的屏蔽入口都在底部的 Blocking 标签下，分两条路：

- **Quick Block**：解决「现在就要清净」。选好要拦的应用、网站或关键词，点 Start 立刻生效，结束时手动停用。付费版还能按 25 分钟 / 1 小时 / 24 小时定时，或按番茄钟节奏走。
- **Schedules**：解决「到点自动拦，不靠每天下决心」。建一条计划，设定触发条件，之后按规律反复自动生效。

## 五种触发条件

| 条件 | 生效逻辑 |
| --- | --- |
| Time（时间） | 选定时段内自动生效，可按星期几组合 |
| Usage limit（用量上限） | 当日或每小时累计使用到设定时长后开始拦 |
| Location（位置） | 进入（或离开）某区域的半径范围后生效 |
| Launch count（打开次数） | 当日或每小时打开次数达到上限后开始拦 |
| Wi-Fi | 连上指定 Wi-Fi（比如公司网络）时生效 |

建计划时还有两个必选项：拦启动（应用直接打不开）或拦通知（收不到通知），至少勾一个；名单类型分黑名单（拦名单内的）与白名单（拦所有、只放行名单内的，属付费功能）。

## 只封应用里最刷不停的那一块

从 7.5.0 版起，Instagram Reels、YouTube Shorts、Snapchat 的 Spotlight/Stories 这些板块可以单独拦截：应用本身照常打开，聊天、搜索不受影响，只有最耗时间的信息流消失。做法是在计划的 Blocklists 里选中应用后，再勾选具体板块。

## 网站与关键词

网站拦截依赖无障碍权限，并且只在受支持的浏览器里生效（Chrome、Firefox、Edge、Opera 等二十多款）。添加规则时既可以给具体网址，也可以用关键词批量匹配：按域名匹配还是按整个网址匹配，口径要在设置里选清楚。
