# 修补应用的完整步骤与模式选择

> 本篇讲从材料备齐到装上修补产物的整条链路，以及本地、便携两种模式怎么选——这是使用 LSPatch 的核心操作。
> **相关文档**：[免Root使用Xposed模块的方法.md](免Root使用Xposed模块的方法.md) · [修补版应用的更新与数据备份.md](修补版应用的更新与数据备份.md)

## 一、材料备齐再开工

| 材料 | 说明 |
| --- | --- |
| LSPatch 管理器 | 已安装并能正常打开 |
| 目标应用 | 已安装的应用或一个 APK 文件，两种来源都行 |
| 模块（便携模式需要） | 先装到手机上待命；新一些的版本也支持修补时直接从存储选模块文件 |
| 输出目录 | 首次修补会要求选一个文件夹存产物，提前建好省事 |

## 二、六个步骤走完一条链

1. 打开管理器，切到「管理」页，点右下角的加号新建修补；
2. 首次会提示选存储目录：选准备好的文件夹，按提示授予存储权限；
3. 选目标：「从存储目录选择 APK」或「选择已安装的应用程序」，效果一致；
4. 选修补模式（本地 / 便携），差别见下节；
5. 便携模式在此点「嵌入模块」，勾选要带的模块后确认；本地模式没有这一步；
6. 点「开始修补」等日志跑完——耗时与应用体积成正比，几秒到几分钟都正常，期间别清后台。

看到日志出现 done 与带 `lspatched` 字样的文件名，就是修补成功，产物落在第 2 步选的目录里。

## 三、本地模式与便携模式怎么选

| 对比项 | 便携模式 | 本地模式 |
| --- | --- | --- |
| 模块位置 | 直接嵌入产物 APK | 留在管理器里，不进包 |
| 运行依赖 | 独立运行，不依赖管理器 | 管理器须保活，被杀模块失效 |
| 发给别人 | 可以，对方装上就能用 | 仅限这台手机 |
| 事后调整 | 要重新修补 | 管理器里长按应用改「模块作用域」 |

选择思路一句话：搭配固定、想省心、要分发，选便携；还在试模块、经常调整，选本地。不少教程把便携写作「集成模式」，指的是同一件事。

## 四、装产物与售后两件事

- **安装产物**：有 Shizuku 时可在应用内直接点安装；没有就走手动路——文件管理器进输出目录，装那个带 `lspatched` 字样的包。无论哪条路，都要先卸载原版（签名不同，不能共存），卸载前的数据备份见 [修补版应用的更新与数据备份.md](修补版应用的更新与数据备份.md)；
- **修不好的应用**：个别应用做了完整性校验或加壳，修补后打不开。先换另一种模式重修一次，再换目标应用的版本试；反复失败就接受它修不了——免 Root 框架的能力边界摆在那里，不是所有应用都能覆盖。

## 五、从哪里拿管理器

管理器本体是一个普通 APK，安卓 9 以上可装。获取入口与安装步骤已整理在 [LSPatch 免 Root 修补工具介绍站](https://lspatch.fewf.click/) 的下载安装页；装好后的第一次修补，就按本篇第二节的六步走。
