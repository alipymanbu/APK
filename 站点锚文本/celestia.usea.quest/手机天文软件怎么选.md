# 手机天文软件怎么选：星图应用与宇宙模拟器的分工

想在手机上看星星，商店里能搜到两大类应用：一类是**星图 / 电子天文馆**，举起手机对着天空，屏幕上标出那颗星叫什么；另一类是**宇宙模拟器**，代表就是 Celestia——它不做「对照天空认星」这件事，而是把整个太阳系和银河系做成一个可以漫游的三维模型。

两类工具回答的是两个不同的问题：

| | 星图应用 | Celestia 这类模拟器 |
| --- | --- | --- |
| 回答的问题 | 「我现在头顶这颗亮星是什么」 | 「土星环从这个角度看是什么样」 |
| 视角 | 固定在地球表面 | 整个宇宙任意移动、绕行、降落 |
| 时间 | 显示当前天空 | 可加速、放慢、倒流重放 |
| 适合场景 | 户外观星现场对照 | 平时学习、演示、预习天象 |

## 什么时候该装模拟器

- 想看的不是「今晚的 sky」而是行星、卫星、星系本体的三维外观；
- 想理解轨道、尺度、公转周期这些抽象概念——把时间流速调快，木星的几颗伽利略卫星几分钟就绕出一圈；
- 想提前「实地」预习一场天象，比如下一次日食时月亮影子扫过地面的过程。

## 什么时候星图更合适

准备出门观星、想现场对照星座，星图应用的增强现实模式是模拟器替代不了的。两者并不冲突，很多爱好者两个都装：户外认星用星图，回家钻研用模拟器。

如果想先试试模拟器这条路，可以从开源的 [Celestia](https://celestia.usea.quest/) 入手——它以 GPL 许可证开源发布，安卓安装包约 400MB，内置超过 60 万颗恒星的星表，上面那个介绍页整理了它的功能细节与安装文件的获取方式。
