# noyacg 是什么？功能与界面一览

> 这篇回答「noyacg 是什么软件」：它是一款安卓端的 ACG 漫画应用，阅读之外还带一片同好社区。下面按界面与功能两条线把它讲清。
> **相关文档**：[注册与邀请码获取.md](注册与邀请码获取.md) · [漫画加载慢与线路切换.md](漫画加载慢与线路切换.md)

## 一、一句话定位

noyacg 把「找漫画、看漫画、聊漫画」装进了同一个深色界面：首页是榜单与题材标签，底栏五个入口（主页、最新、社区、收藏、用户），第一眼就能摸清结构。它主要通过各类分享页面分发安卓安装包，第一次打开需要注册账号才能正常使用。

手上这份安装包的信息：版本 2.4.9，安装包约 21.7MB，安卓 5.2 及以上可装。

## 二、四块屏幕看懂界面

| 界面 | 里面有什么 |
| --- | --- |
| 主页 | 题材标签（热血、恋爱、悬疑、治愈等一排）+ 今日阅读榜、今日收藏榜 |
| 收藏排序页 | 最新 / 最多浏览 / 最多收藏 / 最高评分 / 最近上架几种排法，配星级与收藏数 |
| 最新页 | 连载中的新话按时间排，追更就在这里 |
| 社区 | 贴文时间线，最新与精选分栏，规则帖置顶 |

四屏截图与更细的讲解，可以看 [noyacg 应用速览站](https://noyacg.laze.skin/)，那里按「找书 → 阅读 → 社区」的顺序把界面走了一遍。

## 三、功能上值得留意的几处

- **找书两条路**：榜单管「当下热门」，标签管「按口味筛」；搜索以关键词匹配为主，冷门作品换个更短的词或直接翻分类更容易命中。
- **三条分流线路**：图片与章节各走各的线路，其中一条走地域级 CDN、速度通常最快；图片加载不顺时切线路最直接，见 [漫画加载慢与线路切换.md](漫画加载慢与线路切换.md)。
- **阅读设置够细**：单页、横向翻页、连续滚动可选，夜间护眼背景、亮度字号可调，2.4.9 版起还能按音量键翻页。
- **章节可离线**：缓存到本地后通勤无网也能续看，占用在存储设置里可见。
- **账号跟着服务器走**：书架、收藏、积分都存在服务器上，换手机登录即恢复；登录页可切服务器分区，选错分区会发现「收藏不见了」。

## 四、注册这道门槛

应用不开放免注册浏览，账号是第一道门槛。注册表单要名称、邮箱、密码，邀请码一栏在较新版本里可以留空直接提交。具体步骤与被卡住的处理，见 [注册与邀请码获取.md](注册与邀请码获取.md)。

## 五、装之前的小提醒

同一款应用在网上能搜到包名不同的两支安装包，它们不能互相覆盖升级，装完出现两个图标就是混装了——删掉多余的那个，只留自己的一份。
