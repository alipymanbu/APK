# 注册与邀请码获取

> 这篇整理 noyacg 的注册流程：表单要填什么、邀请码从哪来、注册被卡住时先查哪一步。
> **相关文档**：[应用功能与界面速览.md](应用功能与界面速览.md) · [漫画加载慢与线路切换.md](漫画加载慢与线路切换.md)

## 一、注册要用什么

noyacg 不开放免注册浏览，账号是第一道门槛。注册走应用内表单，需要准备：

| 字段 | 说明 |
| --- | --- |
| 名称（用户名） | 社区里显示的名字，之后可在资料页改 |
| 邮箱 | 登录用的账号标识，填收得到信的地址 |
| 密码 | 自己设一个，两次输入要一致 |
| 邀请码 | 较新版本可留空直接提交，见下文 |

提交时会有一道拖动图片的滑块验证，把图块拖对位才算通过。

## 二、注册步骤

1. 打开应用，停在登录页时点「立即注册」（有的版本写作「无账号，即刻注册」）。
2. 按表单填名称、邮箱、密码、重复密码。
3. 邀请码栏：有码就填，没有先留空提交，被拒再去找码。
4. 拖动滑块完成图片验证，点「注册」。
5. 提示成功后回到登录页，用邮箱与密码登录。

注册和登录是两个界面，注册完要手动回登录页再进一次，别以为注册完就自动进去了。

## 三、邀请码从哪来

邀请码是控制新增账号数量的手段，有效性随时间变化，旧码大概率被拒。靠谱的来源只有几处：

- **应用内公告与社区置顶帖**：当期公布的码优先从这里拿；
- **社区与群组现分享的码**：ACG 相关论坛里其他用户刚分享的，越新越好；
- **直接留空**：近年多份说明都写着「目前注册无需邀请码」，先留空提交一次，被拒再找。

网上不少页面罗列着一串「长期有效邀请码」，那些码被用过之后就失效了，照抄基本过不了。

## 四、注册被卡住的两种情况

**提示「今日已达注册上限」**：这是每天新注册数的上限，不是网络问题。等次日零点重置后再试（间隔 24 小时）；急用就换一个没用过的邀请码再提交。

**点了注册没反应、一直转圈**：这套服务端链路对网络环境敏感，先换一条网络（Wi-Fi 与流量互换）再试，往往就过了；仍不行可按 [漫画加载慢与线路切换.md](漫画加载慢与线路切换.md) 的排查顺序走一遍。

## 五、登录与服务器分区

登录页左上角有「服务器」按钮，用来切换账号所在的服务器分区：

- 书架、收藏、社区数据**跟着所选服务器走**，选错了会发现「我的收藏全没了」——先切回原来的服务器再看；
- 不确定当初注册在哪，就逐个试一遍，能登进去、书架还在的那个就是。

账号注册好之后做什么，可以看 [应用功能与界面速览.md](应用功能与界面速览.md)，从书架到社区的功能都整理在那篇里；安装环节的问题则可在 [noyacg 应用速览站](https://noyacg.laze.skin/) 的下载安装页找到对应处理。
