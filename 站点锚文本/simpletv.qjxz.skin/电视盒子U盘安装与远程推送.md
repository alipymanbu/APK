# 电视盒子U盘安装与远程推送

> SimpleTV 在电视端与手机端是同一份安装包，但电视上没法直接用浏览器下载 APK，得先把文件弄进电视。本篇把 U 盘、当贝市场远程推送、ADB 三条安装路讲清楚，按手头设备选一条即可。
> **相关文档**：[下载安装步骤与首次设置.md](下载安装步骤与首次设置.md) · [频道构成与部分频道看不了的排查.md](频道构成与部分频道看不了的排查.md)

## 一、三条路怎么选

| 方式 | 前提 | 适合谁 |
| --- | --- | --- |
| U 盘安装 | 一只 U 盘 + 一台能拷文件的电脑或手机 | 绝大多数盒子与电视，最通用 |
| 当贝市场远程推送 | 盒子和手机都装了当贝市场 | 家里已有当贝市场、不想拔插 U 盘 |
| ADB 安装 | 电脑 + 会用命令行 | 手边没有 U 盘的开发型用户 |

三种方式装完效果没有区别，电视端的系统要求同样是安卓 6.0 及以上。

## 二、U 盘安装（推荐先走这条）

1. 在电脑或手机上打开 [SimpleTV 介绍站](https://simpletv.qjxz.skin/)，通过「获取安装文件资源」按钮进网盘分享页，把安装包下载下来，拷进 U 盘；
2. U 盘插到盒子或智能电视的 USB 口；
3. 在电视上打开自带的「文件管理」「媒体中心」类应用，找到 U 盘里的 APK，选中安装；
4. 弹出「禁止安装未知来源应用」时，进「设置 → 安全」打开「未知来源」开关，回来再装一次。

**TCL 电视的特例**：TCL 系统会屏蔽 U 盘里的 APK 文件，普通文件管理器里看不到它。处理办法是用 TCL 系统自带的电视卫士类应用进 U 盘安装，入口名称以系统版本显示为准。

## 三、当贝市场远程推送（没有 U 盘时）

当贝市场的「远程推送」能把手机里的安装包直接发到电视上：

1. 盒子和手机都安装当贝市场；
2. 在电视端当贝市场的「管理」界面找到「远程推送」；
3. 用手机扫码登录推送页面，上传提前下载好的 SimpleTV APK；
4. 传输完成后电视端提示安装，确认即可，同样可能需要先允许未知来源。

**推不上的第一个检查点**：手机和电视必须连同一个 WiFi，这是远程推送能工作的前提。除了扫码，电视端还会显示一个网址，用电脑浏览器打开走「上传文件」流程，效果一样。

## 四、ADB 安装（会命令行再选）

前提：电视打开开发者模式并允许网络调试（通常在「设置 → 关于」里连按「版本号」几次解锁），电视与电脑在同一网络。

```bash
adb connect 192.168.1.100:5555   # IP 在电视的网络设置里看
adb install SimpleTV_v1.0.3.apk  # 换成你电脑上 APK 的实际路径
```

出现 `Success` 即装完，不同品牌调试端口可能不是 5555。

## 五、装完先做两件事

1. 打开 SimpleTV，等频道列表初始化完成，遥控器方向键选台；
2. 如果多数频道转圈，大概率不是装错了，而是网络条件不满足——部分频道只有 IPv6 网络能看，排查步骤见 [频道构成与部分频道看不了的排查.md](频道构成与部分频道看不了的排查.md)；手机端的安装与首次设置则见 [下载安装步骤与首次设置.md](下载安装步骤与首次设置.md)。
