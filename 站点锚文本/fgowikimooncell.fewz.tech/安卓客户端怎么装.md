# fgowikimooncell 安卓客户端怎么装

> 这篇讲 fgowikimooncell 客户端从拿包到装进手机的全过程：资源从哪转存、安装被拦怎么放行、装完打不开先查什么。查资料用法见 [英灵图鉴怎么查.md](英灵图鉴怎么查.md)，装完有问题先翻 [打不开白屏怎么办.md](打不开白屏怎么办.md)。

## 一、手上这份包是什么

fgowikimooncell 是 Mooncell——玩家共同维护的 FGO 中文资料站——的安卓壳客户端，装上它，英灵图鉴、素材掉落、活动排期这些查询就不用每次开浏览器输地址了。安装包只有 3.43 MB，对手机存储几乎没负担。

需要留意的是版本线：Mooncell 有新旧两代客户端，应用名都叫 Mooncell，最省事的辨认方法是点右上角三个点——带悬浮窗切换的是新客户端（Kotlin 编写，包名 wiki.fgo.app），不带的是旧客户端（Lua 编写，包名 wiki.mooncell.app）。两者包名不同，可以在同一部手机上共存。

## 二、从哪拿安装包

获取入口是 [fgowikimooncell 安卓版下载页](https://fgowikimooncell.fewz.tech/)，资源放在夸克网盘：打开分享页 → 转存到自己的网盘账户 → 从网盘下载 apk 到手机。转存一份再下载，比直接依赖别人的分享稳得多——分享链接可能被取消，自己账户里的文件不受影响。

## 三、安装步骤

1. 在手机文件管理里点开下载好的 apk；
2. 系统弹出「禁止安装来自此来源的应用」时，点进设置允许本次安装——这是安卓对应用商店之外安装的常规拦截，放行即可；
3. 等待安装完成，点开图标；
4. 首次启动需要联网加载 Mooncell 的页面内容，稍等首页出来就算装好了。

之前装过旧版 Mooncell 的不必先卸载，两者共存，装完自己挑一个顺手的用。

## 四、装不上先看这两条

- **解析包出错**：多半是设备安卓版本低于 6.0（先升级系统），或者下载中途断了导致包损坏（重新下载一份）；
- **反复装失败**：核对一下手机剩余存储，空间见底时安装阶段也容易失败。

更多运行中的问题（白屏、闪退、页面加载不出来）统一收在 [打不开白屏怎么办.md](打不开白屏怎么办.md)。
