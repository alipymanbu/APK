# fgowikimooncell 英灵图鉴怎么查

> 这篇讲装好 fgowikimooncell 之后怎么把 Mooncell 的图鉴用起来：栏目怎么分、从者怎么筛、素材掉落去哪查。还没装上的先看 [安卓客户端怎么装.md](安卓客户端怎么装.md)，打不开先翻 [打不开白屏怎么办.md](打不开白屏怎么办.md)。

## 一、先认栏目的分布

客户端里加载的就是 Mooncell 站点内容，首页按栏目排布，常用的几块：

| 栏目 | 查什么 |
| --- | --- |
| 英灵图鉴 | 从者数值、配卡、宝具、技能，以及灵基再临与技能强化的素材需求 |
| 礼装 / 纹章图鉴 | 概念礼装属性、命令纹章效果 |
| 道具一览 | 素材的分类、用途与掉落去向 |
| 关卡配置 / 敌人一览 | 各关卡敌人配置、AP 消耗，刷本前先看清 |
| 活动一览 / 卡池一览 | 日服国服活动与召唤卡池的时间线 |

界面随网站改版可能调整，栏目名称以你打开时看到的为准。

## 二、查一个从者的完整路径

以规划养成素材为例：

1. 打开英灵图鉴，在筛选框按名字搜，或勾星级、职阶标签组合筛选；
2. 点开目标从者页，「基础数值」「宝具」「技能」几节看战斗数据；
3. 「素材需求」一节把灵基再临与技能强化分开列，末行有两项合计——养成一个从者总共要多少素材，看这一张表；
4. 页面往下翻还有成长曲线、牵绊等级与各阶段立绘，按需翻阅。

## 三、查素材掉落与刷本路线

「道具一览」里找到目标素材，页面会链到掉落它的关卡；再到「关卡配置」核对敌人的职阶与血量，决定带什么队去刷。掉落率是玩家实测汇总的统计值，游戏调整掉落后页面会跟着更新，读的时候留意页面标注的统计口径。

## 四、查活动排期，规划圣晶石

「活动一览」与「卡池一览」按时间线分列日服与国服。国服进度落后日服，页面分别标注了服别，别把日服时间直接当国服用。规划抽卡时顺手用站内的抽卡模拟器过过手瘾——不过它的概率与保底是玩家推测的，结果仅供娱乐，别当策略依据。

## 五、数据对不上游戏内实况怎么办

Mooncell 是 wiki，每页右上角有编辑入口，注册登录后人人能改；不想动手也可以在讨论区指出问题。判断数据对不对时，永远以游戏内实况为最终标准。伤害与 NP 的具体计算，配合站内指令卡计算器使用更顺手。
