# 大模型接入与插件玩法

> 机器人上线只是第一步，真正决定「它好不好聊」的是两件事：接哪个大模型、装哪些插件。本篇把安卓端上这两件事的选法与填法一次说清。
> **相关文档**：[手机上把QQ号变成AI机器人.md](手机上把QQ号变成AI机器人.md) · [安卓端初始化失败排查.md](安卓端初始化失败排查.md)

---

## 一、能接哪些大模型

AstrBot 框架同时兼容 OpenAI、Google、Anthropic 三种原生 API 接口，外加一切「OpenAI 兼容」的第三方接口。落到实际选择上：

| 你的情况 | 可选的接法 |
| --- | --- |
| 手里有国外大平台账号 | OpenAI（GPT 系列）、Google Gemini、Anthropic（Claude）原生接口 |
| 想用国产模型 | DeepSeek、智谱（GLM）、Kimi、MiniMax 等，多走 OpenAI 兼容接口 |
| 不想花 API 钱 | Ollama、LM Studio 里部署的开源模型，填本机或局域网地址即可 |
| 已有现成智能体 | Dify、Coze、阿里云百炼等平台的应用可以直接接入 |

各家模型的价格、免费额度、可用性随时会变，接入前以对应平台当时的页面为准。

## 二、Key 怎么填

1. 在管理面板进入「模型提供商」（Provider）页面；
2. 新增一个提供商，选对应类型（OpenAI 兼容接口是最常用的万能选项）；
3. 粘贴该平台发给你的 API Key，填对 base 地址，保存并获取模型列表；
4. 选一个默认模型，保存后按提示**重启机器人**，配置才生效。

两个省成本的实践经验：

- **聚合平台一个 Key 调多家**：硅基流动这类聚合平台走 OpenAI 兼容接口，一个 Key 可切换多家开源模型，部分模型还有免费额度，适合开发测试；
- **本地模型零成本**：手机和电脑在同一局域网时，安卓端可以直接填电脑上 Ollama 的局域网地址，调用不花钱，代价是电脑得开着。

## 三、模型切换与对话管理指令

指令以唤醒前缀开头（默认斜杠 `/`，可在面板里改）。日常最常用的几条：

| 指令 | 作用 | 权限 |
| --- | --- | --- |
| `/help` | 查看当前实际可用的指令清单 | 所有人 |
| `/new`、`/reset` | 开一个全新对话 | 所有人 |
| `/stop` | 停掉当前正在跑的任务 | 所有人 |
| `/stats` | 看当前会话 Token 用量 | 所有人 |
| `/provider` | 查看 / 切换大模型提供商 | 管理员 |
| `/sid` | 查看会话来源与用户 ID（设管理员要用） | 所有人 |

把自己设成管理员的路径：先发 `/sid` 拿到用户 ID，再到面板「配置 → 其他配置 → 管理员 ID」里填进去。换过人设或提示词之后，记得发 `/reset` 让新设定从干净的上下文生效。

## 四、插件怎么装、装哪些

插件在管理面板（WebUI）的插件页安装，一键装、一键卸，生态里有上千个可选。按用途挑几个方向：

- **信息增强**：网页搜索、翻译——让机器人能查实时信息、跨语言对话；
- **记忆与人设**：长期记忆、人设（persona）、亲和度系统——对话更像「一个固定的角色」，越聊越贴合；
- **群务运营**：入群欢迎、关键词触发、娱乐互动——群里用得多；
- **效率工具**：定时任务、摘要总结——把机器人当轻量助理用。

装之前看一眼插件页的说明与依赖；装完发 `/help`，新指令才会出现在清单里。插件的完整列表也可以在浏览器里打开插件市场浏览。

## 五、手机端的能力边界

安卓端为了开箱即用做了聚焦，下面几点与电脑/服务器部署不同：

| 能力 | 安卓端 |
| --- | --- |
| QQ 个人号变机器人 | 支持 |
| 微信 / Telegram / 钉钉等平台 | 不支持，需自行部署完整版框架 |
| 代码执行器（沙箱） | 默认不可用（依赖 Docker） |
| 插件、人设、知识库 | 支持 |
| 图形化配置 | 支持（内置 WebView 面板） |

也就是说：只想要一个 QQ 上的 AI 机器人，安卓端足够；要接多平台、跑代码沙箱，就得往服务器走。想动手装的话，流程见[手机上把QQ号变成AI机器人.md](手机上把QQ号变成AI机器人.md)；功能与实拍可以看 [AstrBot 安卓端介绍](https://astrbot.fedq.ren/)这个整理站。

初始化或运行中出了问题，先翻[安卓端初始化失败排查.md](安卓端初始化失败排查.md)，多数情况重启 App 或清一次数据就能解决。
