# 手机上把 QQ 号变成 AI 机器人的完整流程

> 本篇讲一条不碰电脑的路线：用 AstrBot 安卓端，把自己名下的一个 QQ 号变成能自动回消息、能调用大模型的机器人账号。从安装到上线大约十几分钟，难点不在操作、在首次启动那一段等待。
> **相关文档**：[大模型接入与插件玩法.md](大模型接入与插件玩法.md) · [安卓端初始化失败排查.md](安卓端初始化失败排查.md)

---

## 一、为什么选手机端这条路

把 QQ 号变成机器人，常见路线有两类：一类是在电脑或服务器上部署 AstrBot 框架本体，能力强、平台广，但需要 Python 或 Docker 环境；另一类就是本文的路线——社区开发者把 AstrBot 核心、NapCatQQ 协议适配器和 Ubuntu 容器环境打包成了一个安卓 APK，装上就能跑。

对「只想在 QQ 里挂一个 AI 机器人」的需求来说，手机端的优势很直接：

- **零环境搭建**：不用装 Python、不用开 Docker，一部 Android 手机就是全部家当；
- **初始化全自动**：首次启动自动部署容器环境与协议组件，进度实时滚动，断点续装；
- **管理不出手机**：内置 WebUI 管理面板，配置、日志、插件都在手机浏览器里点选完成。

代价也有：安卓端当前只支持 QQ 个人账号这一种消息平台，依赖 Docker 的代码沙箱在手机容器里默认不可用。要接微信、Telegram 等更多平台，仍需按框架文档自行部署完整版。

## 二、动手前准备三样东西

1. **一个备用 QQ 号**。机器人走的是电脑端协议，社区资料普遍提醒别用主力号——第三方协议接入在账号层面有被风控的可能。同时记住：同一个号别再登录电脑 QQ，两边互挤会把机器人挤下线。
2. **手机剩余空间**。安装包约 87 MB，但首次启动还会联网下载容器环境与依赖，实际占用明显更大，建议留出 1 GB 以上余量。
3. **一把大模型 API Key**。DeepSeek、智谱、Kimi 等国产模型的 Key 在各自开放平台申请；本地党也可以用 Ollama 填局域网地址，零调用成本。模型选择的细节见[大模型接入与插件玩法.md](大模型接入与插件玩法.md)。

## 三、流程总览

整个过程四步：

1. **获取安装包**：从网盘分享页把 APK 转存到自己的账号再下载（[AstrBot 手机端介绍站](https://astrbot.fedq.ren/)的安装页整理了获取入口与安装步骤）；
2. **安装放行**：点开 APK，系统提示「未知来源应用」时允许对应来源安装；
3. **首次启动初始化**：连家用 Wi-Fi 或手机流量，保持屏幕常亮；点按屏幕任意位置可切到日志页，看它部署容器、拉取核心、安装协议组件——napcat 这一步最慢，卡住别慌，关掉 App 重开会接着装；
4. **扫码配 Key**：初始化完成会弹出 QQ 登录二维码，用手机 QQ 扫码；随后进管理面板（默认账号密码均为 astrbot，登录后立即修改），在「模型提供商」里填入 API Key 并重启机器人。

全部就绪的标志：通知栏出现一条「正在运行」的常驻通知。它是机器人的命脉，清掉服务就停；只要它在，息屏、锁屏、切后台都不影响收发消息。

## 四、上线之后能聊成什么样

- **私聊**：直接说话它就接；
- **群聊**：靠唤醒前缀（默认斜杠 `/`）或 @ 触发，先用 `/help` 验证链路是否通；
- **指令管理**：`/new` 开新对话、`/stop` 停任务、`/stats` 看 Token 用量、`/provider` 切换模型（管理员）；
- **人设养成**：在管理面板里编辑人格设定，配合长期记忆、亲和度类插件，聊得越久越像「一个固定的人」。

装完插件之后用 `/help` 看到的清单，才是真正可用的全部——主程序刻意保持轻量，扩展能力大多在插件里。

## 五、风险与边界，装前再看一眼

- 第三方协议接入被 QQ 侧视为「外挂软件」的类似物，存在警告、限制直至冻结账号的可能，规则随时会变，以腾讯侧当时口径为准；
- 机器人号若被冻结，项目方帮不上忙也不承担后果，重要社交关系与支付绑定不要放在这个号上；
- 别拿机器人做群发广告、批量加好友这类事——那是封号之外还可能直接违规的红线。

卡在初始化、二维码不弹、莫名掉线，按症状对照处理即可，多数不用重装，见[安卓端初始化失败排查.md](安卓端初始化失败排查.md)。
