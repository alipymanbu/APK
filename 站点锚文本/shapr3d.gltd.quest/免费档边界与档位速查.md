# 免费档边界与档位速查：Shapr3D 不花钱能走多远

> 本篇把 Shapr3D 的免费档（Basic）能力边界列成清单：哪些功能完全不设限、哪些卡在数量与精度上、什么信号出现时才值得升档。价格与档位结构会随时间调整，付款前以定价页当时展示为准。

## 一、免费档不是试用版

先把最容易误会的一点说清：Shapr3D 的免费档**不限时间**，不是「14 天试用」。注册后一直用下去没问题，另有 14 天的付费版试用通道，试用结束账号落回免费档继续用。

免费档下，这些能力**完全不设限**：

- 建模核心全开放：2D 草图与约束、直接建模、参数化历史、布尔运算；
- 导入 STEP、IGES、X_T、DWG/DXF、STL 与图片底图；
- 离线建模，联网后项目云同步，一个账号跨平台最多 3 台设备。

## 二、卡住你的是这两条

| 项目 | 免费（Basic） | 付费（Pro / Solo 档） |
| --- | --- | --- |
| 项目数 | 2 个 | 无限 |
| 导出 STL / 3MF | 仅低精度 | 高精度 |
| 导出 STEP / IGES / X_T | 不行 | 可以 |
| 2D 技术图纸（DXF / DWG / PDF） | 没有 | 有 |
| 导出 USDZ / GLB / OBJ | 不行 | 可以 |
| 项目版本历史（误删回退） | 没有 | 有（档位不同保留期不同） |
| 实时渲染 + 材质库 | 没有 | 有（100+ 材质） |
| iPad 上的 AR 查看 | 没有 | 有 |

**判定口诀**：卡在「2 个项目」——删旧项目腾槽还能凑合；卡在「导出精度与格式」——说明你的下游已经进入真实制造（送 CNC、出正式图纸、打高精度件），这就是升档的信号。学软件、画概念、打玩具件，免费档走完全程没有问题。

## 三、升档前的三个省钱事实

1. **一份订阅覆盖全平台**。订阅不按平台收钱，iPad / Mac / Windows / Vision Pro 通用，模型云同步——不用为「多平台」单独付费。
2. **学生与教师免费**。教育许可在定价页的「free for Students and Educators」入口，用教育邮箱申请。
3. **别为没定稿的模型升级**。先用免费档的低精度 STL 把形状验证到位，设计成立再为高精度导出付钱；形状都不对时，高精度没有意义。

## 四、免费档之内再压榨一点空间

两个项目槽的管理有小技巧：把已定稿的模型导出低精度 STL 存档后删项目腾槽，需要时再以参考体的方式导回来照着重画——麻烦，但确实能多撑一阵。真到频繁这么折腾的程度，说明该升档了。
