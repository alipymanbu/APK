# DramaBox 观剧手册：短剧应用的题材、中文设置与安装入口

DramaBox 是一款主打竖屏短剧的手机应用，单集 1~3 分钟、整部 70~150 集，题材覆盖闪婚豪门、替身新娘、重生复仇等。这里整理了它的剧库构成、界面调中文的方法、付费模式的拆解，以及安卓手机安装的完整步骤，整理内容见 [DramaBox 观剧手册](https://dramabox.gkhf.beer/)。
