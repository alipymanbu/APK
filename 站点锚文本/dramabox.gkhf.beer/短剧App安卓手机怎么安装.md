# 短剧App安卓手机怎么安装

DramaBox 主要面向海外市场发行，国内的应用商店通常搜不到，安卓手机上常见的做法是通过安装文件资源（APK）安装。这篇把从转存到打开的完整流程写清楚，并附上三个最常拦路的问题的处理办法。

## 四步装好

1. **打开分享页并转存**：进入安装文件资源的网盘分享页，选择"保存到网盘"，把它转存到自己的网盘账号；
2. **下载安装包**：在自己网盘的"我的资源"里找到 APK 文件，下载到手机存储；
3. **允许安装未知应用**：首次安装时系统会提示"禁止安装未知来源应用"，按提示给下载时所用的应用（浏览器或网盘）授予权限；
4. **完成安装并打开**：装好后在桌面点开应用，建议先按[短剧App怎么切换中文](短剧App怎么切换中文.md)里的步骤把界面切成简体中文。

安装前留意两个参数：它适配 Android 5.2 及以上系统，安装包约 110 MB，手机剩余存储留够再动手。

## 三个最常见的拦路问题

**点"安装"没反应，提示被阻止**：小米、华为等品牌需要在"设置 → 更多设置/安全和隐私 → 安装未知应用"里给下载时所用的应用授权；部分企业设备被安全策略锁定，这种情况装不了。

**提示"解析包错误"或安装失败**：多半是安装包没下载完整，删掉重新下载一次再装；下载过程中别让手机断网。

**装好了但打开就闪退**：先确认系统版本达到要求，重启手机再试一次；仍不行就换一台机型验证，排除兼容问题。

## 装好之后看什么

题材从闪婚豪门到重生复仇，单集 1~3 分钟，适合碎片时间追更。剧库构成、付费模式和更完整的介绍，见 [DramaBox 观剧手册](https://dramabox.gkhf.beer/)。
