# 真机界面一览：Gloom 里逛 GitHub 的四步动线

> 用四块真实界面的顺序讲清这款安卓 GitHub 客户端的日常用法：从个人主页出发，翻仓库、看组织、回到收藏。
> **相关文档**：[动态取色与主题设置.md](动态取色与主题设置.md) · [安卓版安装步骤与登录.md](安卓版安装步骤与登录.md)

---

## 一、先明确它的形态

Gloom 是一个装在安卓手机上的 GitHub 客户端，用 Kotlin 编写、以 GPLv3 许可证开源，上游项目是 `https://github.com/MateriiApps/Gloom`。它不追求把 GitHub 的全部功能搬进手机，重点放在最常逛的几类页面上——看别人主页、翻仓库、跟组织、回访 Star 过的项目。

想先看界面再决定装不装的话，[Gloom 介绍站](https://gloom.ggcd.online/)上按同样顺序放了四张实拍图，配合文字对着看更直观。

## 二、第一站：个人主页

个人主页一屏给齐了三样东西：头像与简介、置顶仓库、关注数据（粉丝 / 关注 / 仓库数 / 组织数）。置顶仓库以卡片形式排列，名字、描述、语言、Star 数都在卡上，往下翻还有仓库、组织、收藏的分组入口。

这一页适合的场景很具体：刷提交记录时看到一个陌生的贡献者，想了解这个人，直接进主页看置顶作品就能建立第一印象。

## 三、第二站：仓库列表

仓库页是使用频率最高的界面，每行展示：

| 信息 | 用途 |
| --- | --- |
| 仓库名与一句话描述 | 判断是不是要找的东西 |
| 语言色点 + 语言名 | 快速过滤技术栈 |
| Star 数 | 看项目的受关注程度 |
| Fork 来源标记 | 识别派生仓库 |

列表默认按最近更新排序，往上滑持续加载。点进单个仓库后可以继续看 README 与提交内容，日常「找东西—确认—收藏」的动作在这里闭环。

## 四、第三站：组织

组织页列出你加入或关注的组织，每条带组织头像与一句话介绍。对同时在几个开源团队里活动的人来说，这一页相当于组织维度的收藏夹，比在网页上来回切账号省事。

## 五、第四站：收藏（Starred）

Starred 页按时间倒序排列 Star 过的仓库，每条同样带描述、语言与 Star 数。它的定位是「回逛」：记得看过某个项目但忘了名字时，按时间翻一下通常几屏内就能找到。

## 六、四站连起来是什么体验

四块界面共同构成一条动线：主页认识人 → 仓库找代码 → 组织看团队 → 收藏做回访。整套流程在手机上不需要来回开浏览器标签页，配色还跟随系统壁纸（前提见[动态取色与主题设置.md](动态取色与主题设置.md)）。装好后想走一遍这条动线，先按[安卓版安装步骤与登录.md](安卓版安装步骤与登录.md)把应用装上并登录 GitHub 账号即可。
