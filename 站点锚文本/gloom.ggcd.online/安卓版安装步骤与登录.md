# 安卓版安装步骤与登录：从安装包到进入 Gloom

> 讲清装这款安卓 GitHub 客户端的完整路径：拿到安装包、放行未知来源、完成安装、授权登录，以及两条最常卡住的弯路。
> **相关文档**：[真机界面一览.md](真机界面一览.md) · [动态取色与主题设置.md](动态取色与主题设置.md)

---

## 一、开始前确认两件事

1. **系统版本**：安卓 5.0 及以上才能安装；想体验壁纸取色，需要安卓 12+（详见[动态取色与主题设置.md](动态取色与主题设置.md)）。
2. **安装包来源**：安装文件资源通过网盘分享分发，[Gloom 介绍站](https://gloom.ggcd.online/)的下载页集中放了入口，先转存再下载，文件名以网盘内实际显示为准。

## 二、四步装完

### 第一步：转存并下载

进入网盘分享页，把安装文件转存到自己的网盘账号，再在手机网盘客户端里把 APK 下载到本机。转存这一步别省——分享内容更新时不影响你自己空间里的那份。

### 第二步：放行「安装未知来源应用」

点开 APK 时若系统提示禁止安装，按提示跳到设置，给下载来源（一般是网盘客户端或文件管理器）勾选允许。这是安卓对应用商店之外安装的标准限制，开一次即可。

### 第三步：完成安装

回到 APK 点安装，等待完成。若提示「应用未安装」，见下面第四节第一条。

### 第四步：用 GitHub 账号登录

打开应用，在登录入口完成 GitHub 授权。授权成功后，个人主页、仓库、组织与收藏四个板块就能按[真机界面一览.md](真机界面一览.md)里那条动线逛起来了。

## 三、登录相关的注意点

- **一个客户端对应一个 GitHub 身份**：日常一个账号够用；想换账号，最稳妥的路径是先在应用内退出、再重新走一遍授权，而不是指望账号间随时切换。
- **多包共存时登录互不干扰**：若手机上同时装着不同包名的构建，它们的登录状态各自独立，退出一个不影响另一个。

## 四、两条最常卡住的弯路

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「应用未安装」 | 同包名旧版本签名不一致，或未知来源权限没给 | 先卸旧版再装；确认权限已勾选 |
| 装完点图标没反应 | 系统版本过低，或安装过程被打断 | 确认安卓 5.0+，卸载后重新装一次 |

装完之后的界面颜色问题（没跟随壁纸）不属于安装问题，去翻[动态取色与主题设置.md](动态取色与主题设置.md)的排查清单。
