# 安卓开源电子书前端是什么：读懂 Olib 的定位与来路

> 一句话：讲清 Olib 这个安卓应用的定位——独立开源的电子书前端，书与账号都在外部。
> **相关文档**：[登录不上与线路切换排查.md](登录不上与线路切换排查.md) · [电子书格式导入与离线阅读.md](电子书格式导入与离线阅读.md)

---

在搜索结果里看到 Olib 这个名字的人，第一个疑问通常是「它到底是不是一个读书应用」。准确的说法是：它是一个安卓上的电子书**前端**——界面、书架、阅读器由它负责，而书的数据来自外部书源，账号也是书源侧的。这个设定决定了它所有与众不同的使用方式。

## 三个先记住的事实

1. **开源且独立**。源码托管在 GitHub（`https://github.com/shiyi-0x7f/olib-mobile`），采用 MIT 许可证；项目自述是独立的第三方客户端，与任何书源服务没有隶属关系。
2. **书不归它管**。搜索、下载的数据全部来自外部书源，书源怎么注册、可用性如何，以项目页面与应用内提示为准。
3. **技术上很轻**。用 Flutter 构建，本地数据保存在设备上；界面内置 16 种以上语言，中文开箱即用。

## 它能做什么

按项目自己的说明，功能集中在这些点上：

| 能力 | 说明 |
| --- | --- |
| 检索 | 按书名、作者、ISBN 或关键词搜书 |
| 离线阅读 | 下载后的书不看网络也能读 |
| 多线路 | 连接书源的服务器入口有多条，可切换 |
| 多账号 | 保存多个账号互相切换 |
| 阅读体验 | 深色模式、多主题、排版可调 |
| 费用立场 | 项目自述无广告、无订阅、无隐藏收费 |

## 为什么「前端」这个定位重要

因为所有让你困惑的环节——打开就要登录、登录失败要先换线路、搜不到书要换检索词——根源都在「书与账号在外部」这一点上。把定位想明白，后面的问题排查就有方向了：界面问题看应用设置，连不上、登不进多半是线路或书源侧的事，排查思路见 [登录不上与线路切换排查.md](登录不上与线路切换排查.md)；手里已有电子书文件的，直接走本地导入，见 [电子书格式导入与离线阅读.md](电子书格式导入与离线阅读.md)。

想按页面快速了解它的线路机制、登录流程与安装步骤，可以逛逛 [Olib 介绍站](https://olib.fedq.ren/)，两页内容按真实上手动线组织，比零散翻评论省时间。
