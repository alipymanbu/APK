# 登录不上与线路切换排查：Olib 打开后的第一道坎

> 一句话：解释为什么打开 Olib 就要登录、登录用的是哪个账号，以及登不上时按什么顺序排查。
> **相关文档**：[安卓开源电子书前端是什么.md](安卓开源电子书前端是什么.md) · [电子书格式导入与离线阅读.md](电子书格式导入与离线阅读.md)

---

点开 Olib，迎接你的不是书架而是登录框——不少人在这一步就退出去给差评了。先说结论：这一步要输的不是「Olib 账号」，而是外部书源侧注册的邮箱和密码；登不上，多数时候也不是密码错了，而是线路不通。

## 账号到底是谁发的

Olib 是一个只做前端的客户端，本身不发账号。登录框里的邮箱密码，对应的是外部书源侧注册的账号；注册入口不在应用里，要去所选书源的网站完成。书源的可用性随时间和地区变化较大，具体以项目页面与应用内提示为准。

顺带一提：旧版本（1.0.x 这一代）启动后必须过登录这一关，没有「跳过登录」入口；新版本加入了跳过登录，可以直进主界面做本地导入。手里已经有电子书文件、不想折腾账号的，直接看 [电子书格式导入与离线阅读.md](电子书格式导入与离线阅读.md)。

## 线路是什么，怎么换

「线路」是客户端连接书源用的不同服务器入口，同一个账号在哪条线路上都能登录。应用内置多条线路，还在线路选择器里留了自定义域名入口，为的就是某条线路不通时随时换。

换线的顺序没有玄学：

1. 默认线路先试一次；
2. 登录超时、搜索转圈，换一条线路再登录；
3. 换线路后要**重新搜一次**——原来的搜索结果不会自动刷新。

## 排查对照表

| 现象 | 先做什么 |
| --- | --- |
| 一直转圈不出结果 | 换一条线路；确认手机本身能上网 |
| 提示密码错误 | 确认登的是书源账号，不是把应用当成有独立账号的软件 |
| 账号密码都对仍失败 | 书源侧可能限制登录频率，隔一段时间再试；或换线路 |
| 报错笼统看不出原因 | 旧版本的报错信息比较笼统，只能逐条换线路试 |
| 之前能用现在不行 | 书源侧入口可能变化，留意项目页面的说明 |
