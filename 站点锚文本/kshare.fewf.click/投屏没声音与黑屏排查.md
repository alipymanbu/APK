# KShare 投屏没声音、黑屏卡顿怎么排查

> 画面投上去了，大屏却没声；或者能投但一卡一卡、两侧留黑边——这些是投屏最高频的几类故障，绝大多数不用重装应用，按本篇顺序逐条查就能解决。
> **相关文档**：[是什么与核心功能.md](是什么与核心功能.md) · [手机连接电视投屏方法.md](手机连接电视投屏方法.md)

## 一、投不上或黑屏：先回到三条基础

1. 手机/电脑与接收端是否在**同一个网络**（同一 Wi-Fi 或同一有线网）；
2. 接收端是否停在**待机投屏页**，而不是主页或别的应用里；
3. 网络通但设备被隔离（访客网络常见）——改用**投屏码**或**扫码**连接。

三条都对还黑屏：重启接收端上的接收程序、再重连一次；仍不行时两端都升级到新版本。

## 二、卡顿、延迟、花屏：网络质量问题

画面能出但一动就糊、声音对不上嘴、局部出马赛克，几乎都出在网络：

- **切 5GHz 频段或改有线**：2.4GHz 干扰多、带宽挤，投屏首推 5GHz；接收端支持网线的，插网线最稳；
- **减少同网设备**：路由器下挂太多设备、有人在下载大文件都会抢带宽，活动前先摘掉无关设备；
- **缩短距离**：手机离路由器太远信号弱，往中间挪一步往往立竿见影。

改完重连再看。持续花屏且网络没问题，重启接收端再连。

## 三、画面比例不对：两侧黑边或画面被裁

竖着的手机投到横屏大屏，两边留白不是故障，按场景处理：

| 场景 | 处理 |
| --- | --- |
| 手机竖屏投上去两边有黑边 | 把手机横过来，画面自动横满 |
| 接收端是电子白板类设备 | 在接收端显示设置里开「填满屏幕」（会拉伸内容） |
| 个别应用画面怎么都铺不满 | 应用本身的限制，换文件推送方式放内容 |
| 多画面同显时区域不匹配 | 升级到新版，会按设备尺寸自动调整显示区域 |

## 四、投屏没声音：四步快查

先分清声音的去向：是留在手机上（连着蓝牙耳机/音箱）、到了电视但外接设备关着，还是压根没往大屏送。然后按顺序做：

1. **两边音量都调一遍**：镜像开始后音频输出权通常已交给大屏，用**电视遥控器**调音量，别只按手机音量键；
2. **断开蓝牙**：临时关掉手机蓝牙，排除声音被耳机/音箱截走；
3. **电视声音输出切回「电视扬声器」**：遥控器进 设置 → 声音 → 声音输出，选电视扬声器；
4. **暂停重播、断开重连**：重新点一次播放让应用把声音挂到新输出上，还不行就断开投屏等 10 秒重连。

两类情况属于正常现象，不用修：来了电话、闹钟响时声音从手机出（非媒体音走手机）；某些在线视频应用出于版权保护限制镜像输出（表现为无声或黑屏），换个普通视频文件对照测试即可确认。

## 五、中途自己断开

- **断开前先卡了一下**：网络波动，按第二节处理网络；
- **手机锁屏一会儿后断的**：系统省电策略杀后台——给应用开后台运行/自启动权限，加进电池优化白名单；部分接收端在手机熄屏约 30 分钟后会主动断开，重连即可；
- **一投屏就和其他功能打架**：无线投屏与华为分享、多设备协同、VPN 等功能共用传输信道，投屏时先关掉这类功能。

投屏期间别清后台：系统内存紧张时会先杀投屏应用，投着投着回到待机页就是这么来的。连接本身还没搞定的话，先看 [手机连接电视投屏方法.md](手机连接电视投屏方法.md)；想了解镜像之外的推送、反控等能力，见 [是什么与核心功能.md](是什么与核心功能.md)，也可以到 [KShare 投屏介绍站](https://kshare.fewf.click/) 翻功能对照。
