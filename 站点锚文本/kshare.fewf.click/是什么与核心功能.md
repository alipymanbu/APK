# KShare 是什么？多屏互动投屏工具的核心功能速览

> 在会议室里见过别人把手机画面"甩"上大屏、还想用手机反过来操作电视？KShare 做的就是这件事。本篇讲清它的定位与核心能力，帮判断是否适合自己的设备。
> **相关文档**：[手机连接电视投屏方法.md](手机连接电视投屏方法.md) · [投屏没声音与黑屏排查.md](投屏没声音与黑屏排查.md)

KShare 是深圳皓丽软件推出的多屏互动（投屏）应用，装在手机或电脑上，把画面、文档、音视频推到电视、投影仪、会议平板这类大屏上，也能反过来用手机操控大屏。它有安卓、iOS、Windows、macOS 多个版本，发送端（手机/电脑）与接收端（大屏/投屏器）各装一份配对使用。

## 一、它的定位：大屏的"多功能遥控底座"

很多投屏方案只解决"画面上去"这一件事，KShare 围绕大屏做了一整圈能力：投画面、推文件、反向触控、语音与摄像头转发、网页直投，基本覆盖"人围着一块大屏开会/上课/看片"的所有动作。接收端通常预装在会议平板、电子白板这类设备上，普通电视也可以搭配配套投屏器补上接收能力。

## 二、核心功能逐条看

| 功能 | 做什么 |
| --- | --- |
| 镜像投屏 | 手机画面实时同步到大屏，横竖屏自动跟随 |
| 文件推送 | 视频、照片、文档交给大屏独立播放，手机可锁屏 |
| 反向控制 | 触控回传，手机点按等同于操作大屏，翻页标注不用跑上台 |
| 手机变遥控器 | 无线鼠标、键盘、遥控器三合一 |
| WebCast 网页直投 | 浏览器打开地址、输访问码即投，访客电脑免装客户端 |
| 多画面分屏 | 接收端最多 9 个画面同显，多屏编组可同步更多屏幕 |
| NFC 一碰投 | 支持的安卓手机碰一碰发起投屏 |
| AES 加密传输 | 投屏链路加密，会议内容多一层保护 |

其中"镜像"与"推送"是两条不同的路：镜像是大屏实时跟着手机走；推送是把文件交给大屏自己播放，更稳也不怕中途来消息。看片、放资料优先用推送。

## 三、适合谁用

- **会议室常客**：多台设备轮流上屏，访客用网页直投不用装软件；
- **老师与培训讲师**：摄像头画面和麦克风声音实时上屏，讲题演示看得清；
- **家庭用户**：把电影相册推给电视独立播放，手机锁屏不误事；
- **演示与直播场景**：镜像低延迟跟手，横屏自动铺满。

## 四、从哪一步开始

先确认手上的大屏有 KShare 接收端（或配了投屏器），手机端装好发送端应用，连同一个 Wi-Fi 就能开投。连接的详细步骤见 [手机连接电视投屏方法.md](手机连接电视投屏方法.md)；装好之后遇到画面或声音问题，按 [投屏没声音与黑屏排查.md](投屏没声音与黑屏排查.md) 逐条排查。这款工具的功能与界面一览，也整理在了 [KShare 投屏介绍站](https://kshare.fewf.click/)，可以先去翻一遍再决定要不要装。
