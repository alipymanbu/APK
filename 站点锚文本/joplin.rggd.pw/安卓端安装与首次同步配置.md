# 安卓端安装与首次同步配置

本篇讲 Joplin 手机端从拿到安装包到完成第一次同步的全过程：安装环节容易卡住的两个地方、第一次打开先做什么、同步目标怎么挑、端到端加密什么时候开。应用的介绍与安装文件资源的获取入口，见 [Joplin 中文介绍站](https://joplin.rggd.pw/)。

---

Joplin 的安卓端在手机上就是一个完整的笔记库：所有笔记默认存在本机，没网也能全部打开。把装好之后那几步配置做对，后面换设备、跨平台都不会折腾。

## 安装环节容易卡住的两个地方

- **提示「安装被阻止」**：这是系统没放开「安装未知应用」的权限。到系统设置里找到你用来下载的那个应用（浏览器或网盘客户端），允许它安装应用，再回到安装包继续即可；
- **提示「解析包出现问题」**：多半是安装包没下载完整，中途断网或暂停续传都会导致。把旧文件删掉重新完整下载一次，基本都能解决。

装好第一次打开，应用里只有几篇欢迎笔记，这是正常的——它不带任何预置内容，你的笔记库从这一刻开始自己长。

## 第一次打开建议先做两件事

1. **过一遍「配置」页**：语言、日期格式、主题这些按习惯调；顺手看一眼「附件下载行为」，默认的「手动」模式只在点开附件时才下载，流量紧张的话很省心；
2. **把同步目标定下来**：进「配置 → 同步」，选一个你已有账号的服务。这一步做完再开始大量记笔记，后面多设备才顺。

## 同步目标怎么挑

| 你手上有什么 | 适合选的同步目标 |
| --- | --- |
| 已有 Dropbox 或 OneDrive 账号 | 直接选它，登录授权就能用 |
| 自建了 Nextcloud / 群晖这类私有云 | WebDAV 或 Nextcloud，数据留在自己的盘里 |
| 有对象存储（S3 兼容） | S3，适合折腾党与大库 |
| 什么都不想管 | Joplin Cloud，Joplin 团队运营的付费托管服务 |

同步目标以后随时能换，在配置里改一下就行；换之前让各个设备先各自完成一次同步，能少踩坑。

## 端到端加密什么时候开

建议同步跑通之后就开：打开后笔记在离开设备前就已加密，云上存的只是密文。要留意的是主密码——它丢了没有找回渠道，务必记在别的地方。细节在 [笔记加密与数据归属](笔记加密与数据归属.md) 里有展开。

如果是从印象笔记搬过来的，先别急着手动重录，看看 [和印象笔记比有哪些不同](和印象笔记比有哪些不同.md)，ENEX 导入能省掉绝大部分搬运工作。
