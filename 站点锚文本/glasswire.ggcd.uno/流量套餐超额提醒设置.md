# 流量套餐超额提醒设置：让手机在扣费前先喊你

> 运营商的超额短信总是事后才到。本篇讲怎么在安卓上按自己的套餐建一条数据计划，让提醒赶在扣费之前——包括"无限量"套餐被降速的那种提醒。
> **相关文档**：[手机流量去哪了.md](手机流量去哪了.md) · [免root防火墙怎么开.md](免root防火墙怎么开.md)

## 一条计划要填哪些项

GlassWire（安卓版）的数据计划在底部秒表图标里新建，字段不多，照着套餐填就行：

| 字段 | 怎么填 |
| --- | --- |
| 名称 | 随手取，比如用运营商的名字，方便多计划区分 |
| 上限 | 套餐总量，如 3 GB |
| 周期 | 按月或按周循环，起始日不必是 1 号 |
| 已用量 | 月中才开始统计就补录一笔，剩余量才准 |
| 零流量应用 | 运营商不计费的免流应用排除在外，不占额度 |

套餐带流量结转或者出境漫游的，"附加选项"里各有对应开关；WiFi 也能单独建计划——按流量计费的宽带、卫星网络同样适用。

## 两级提醒，贴着上限卡

计划建好后有三道闸：**到达上限**即提醒、**用到 90%** 再催一次（截图里能看到这个开关），再加上周期内的持续监控。提醒走系统通知，不用打开应用也能看见。

## "无限量"也要设一条

不少无限量套餐的真实规则是：超过某个用量就把你降速。与其等网变卡了再猜，不如把计划的阈值直接设在降速点上（比如 15 GB）——被限速的第一时间，通知就到了。

计划、曲线、警报是三件配套的事：先建计划，回头再用曲线核对"是谁把量用掉的"，对应做法在 [手机流量去哪了.md](手机流量去哪了.md)；真怕某些应用不受控，就把它们交防火墙管，见 [免root防火墙怎么开.md](免root防火墙怎么开.md)。

工具本身在安卓端不收费，[GlassWire 介绍站](https://glasswire.ggcd.uno/)有两页式速览：首页讲三步用法，下载页讲安装授权，照着走一遍就能把计划建起来。

## 顺带两句

- 常驻通知可以自定义显示内容，把实时网速表放上去，随时能看出"现在有没有东西在跑"；
- 提醒嫌吵的话，设置里可以只保留移动数据相关的警报，或全部关掉。
