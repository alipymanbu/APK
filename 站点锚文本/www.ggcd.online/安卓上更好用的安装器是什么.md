# 安卓上更好用的安装器：InstallerX 是什么、能解决什么

> 本篇介绍 InstallerX 的定位与能解决的问题：它是一款开源的安卓安装器，用来接管定制系统里体验平平的默认安装流程。相关阅读：[XAPK 文件怎么安装到手机](XAPK文件怎么安装到手机.md)、[免 root 静默安装怎么设置](免root静默安装怎么设置.md)。

---

不少玩机的人都遇到过类似的场景：下载到的是 `.xapk` 或 `.apks` 分发包，系统自带的安装程序直接不认；或者系统安装界面夹带推广、装完还不给清理安装包。InstallerX 就是为这些情况准备的开源工具（GPL v3 协议，社区维护版叫 InstallerX Revived），把「解析安装包 → 授权 → 安装 → 装后清理」整条链路重新做了一遍。

它的能力可以概括成三块：

- **格式全**：APK、APKS、APKM、XAPK、压缩包里的 APK、批量多选都能解析，分包自动挑最合适的组合，同包名多版本会去重并智能选包；
- **授权灵活**：Shizuku（推荐，无线调试或 ADB 激活）、Dhizuku（设备管理员模式）、Root 三条路径任选，没有 root 也能用；
- **方式多样**：对话框安装、通知栏安装、自动安装三种方式，配合装后自动删包、允许降级、声明安装者等细粒度选项。

它不执行任何 shell 命令，全部走系统原生接口，完整适配 Android 14~16，老机型从 Android 8.0 起也能用。

如果想上手，可以先看[InstallerX 的功能介绍页](https://www.ggcd.online/)了解格式支持与授权配置，再按后面的教程一步步设置。已经装好的读者，建议从[免 root 静默安装怎么设置](免root静默安装怎么设置.md)开始配置。
