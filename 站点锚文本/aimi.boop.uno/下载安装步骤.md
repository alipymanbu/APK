# Aimi 下载安装步骤：安卓手机四步装好

> 这篇只管一件事：把这款 AI 角色聊天应用装进安卓手机。装完想学怎么用，去看[角色聊天怎么玩.md](角色聊天怎么玩.md)。
> **相关文档**：[是什么应用与同名区分.md](是什么应用与同名区分.md) · [角色聊天怎么玩.md](角色聊天怎么玩.md)

## 装之前

- 手机留出 **300M 以上**可用空间：安装包 95.67M，装好后占用更大。
- 确认装的是对的那一款：包名 `com.ai.aimi.android.prod`（为什么强调这个，见[是什么应用与同名区分.md](是什么应用与同名区分.md)）。

## 四步装好

1. **打开安装文件资源页**——进入 [aimi.boop.uno](https://aimi.boop.uno/)，点页面上的获取按钮到网盘分享页，登录后把文件转存到自己的网盘账号。
2. **下载到手机**——转存后在网盘里把 APK 下到手机本地；也可以先下到电脑再传手机。
3. **安装并放行未知来源**——点 APK 安装时若提示「禁止安装来自此来源的应用」，到 设置 → 安全/隐私 → 安装未知应用，给浏览器或文件管理器授权一次，返回继续；装完可以把权限关回去。
4. **打开并登录**——首次启动需要联网，同意权限与隐私政策后用邮箱登录（未注册的邮箱会引导创建账号），然后就能进角色大厅了。

## 卡住了怎么办

- **安装被拦**：回到第 3 步，把「安装未知应用」的授权给到对应工具再试。
- **装到一半失败**：先清空间、删旧包，重新下载完整包再装。
- **打开就退出**：确认手机联网；系统太旧也会这样（下载页标注需要 Android 5.2 以上），升级系统后重试。
