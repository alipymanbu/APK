# Structured 提醒不响与小组件不刷新排查

Structured 用起来最常碰到的两类故障：设了提醒到点不响、桌面小组件空白或不刷新。这篇按排查顺序整理处理办法，多数情况两分钟内能解决。

## 提醒不响，按顺序查

1. **系统通知权限**：系统设置 → 应用 → Structured → 通知，确认允许通知，锁屏、角标、弹窗都勾上；
2. **应用内开关**：应用设置 → Notifications & Alerts，确认通知已启用；
3. **闹钟授权（Android 13 及以上）**：Notifications & Alerts → Allow Alarms，跳到系统「闹钟和提醒」页，把 Structured 的开关打开。这一步漏掉是「设了不响」的最常见原因；
4. **勿扰模式**：开着勿扰或专注模式时提醒会被拦下；
5. **通知上限**：这类应用最多安排约 100 条通知，日程排得特别密时，排在后面的任务可能分不到提醒，删几条旧提醒腾名额。

另外，从外部日历导入的事件默认可能不带提醒，要到 Notifications & Alerts → Imported Tasks 里单独打开 Calendar Events。

## 小组件空白或不刷新

1. 先把小组件删掉，**重启手机，重新添加**——多数情况到这步就好；
2. 在应用里随便改动一个任务（勾掉再取消），触发小组件刷新；
3. 检查省电策略：系统设置 → 应用 → Structured → 电池，选「不受限制」；省电模式开着时小组件常会停更，关掉再试；
4. 还不行就先备份数据（设置 → Advanced → Backups → Backup now），再删除重装。

顺带确认显示规则：Timeline 小组件只列出**正在进行和即将开始**的任务，早些时候已结束的任务不会出现，这不是故障。

## 同步转不完也一起说了

多设备同步卡住时，确认所有设备登录的是**同一个邮箱**，每台设备都单独收一次验证码，再点 Sync now 手动推一次；验证码邮件先翻垃圾箱。

日常的排程方法见[时间线日程规划怎么用](时间线日程规划怎么用.md)；还没安装的先看[安卓版下载安装步骤](安卓版下载安装步骤.md)，或到 [Structured 介绍站](https://structured.fewz.tech/)看两页图文介绍。
