# 绘画笔刷导入与自定义方法

> 这篇讲移动绘画应用里笔刷的进阶玩法：.hbr 笔刷文件怎么导入 HiPaint、笔刷工作室里哪几个参数最影响手感、调好的笔刷怎么分享出去。
> **相关文档**：[手机画画软件怎么选.md](手机画画软件怎么选.md) · [安卓平板画画从装应用到第一笔.md](安卓平板画画从装应用到第一笔.md)

## 一、内置笔刷先盘一遍再谈导入

HiPaint 内置的笔刷按组分好：素描铅笔、炭笔、气笔、喷枪、油画棒、水彩晕染、漫画 G 笔尖、像素笔、材质与噪点纹理等，上百种摆在一起，很多新手的问题不是笔不够，是没翻到底。画笔、橡皮擦、涂抹三支基础工具常驻工具栏，不占笔刷库的位置。

两条管理规则先知道：默认笔刷删不掉，能删的只有自己新建或导入的；笔刷参数支持压感与倾斜，笔尖轻重带来的线条变化要在带压感的笔或手绘板上才体现得出来。

## 二、把 .hbr 笔刷文件导进来

HiPaint 的笔刷文件后缀是 .hbr，社区里画友分享的自制笔刷多是这个格式。导入走系统的「打开方式」链路：

1. 先把 .hbr 文件存到手机存储（聊天工具、网盘、浏览器下载来的都行）；
2. 在文件管理器里点它 → 「打开方式」→「其他应用」→ 选 HiPaint；
3. 导入成功后笔刷出现在笔刷库，可再拖进自己的笔刷组整理。

常见卡点：部分手机的文件管理器不认 .hbr 后缀，列表里根本看不到文件——换一个能显示全部文件的文件管理器再试。想搬别人一整套笔刷的，笔刷组支持整组导入导出，不用一支支来。

## 三、笔刷工作室：先动这四个参数

笔刷工作室里可调的参数有九十多项，全调一遍不现实，先动最影响手感的四个：

| 参数 | 调了会怎样 |
| --- | --- |
| 大小 / 硬度 | 线条粗细与边缘虚实 |
| 透明度 | 叠色时的通透程度 |
| 平滑 / 稳定器 | 手抖修正，勾线时开高一点线条更顺 |
| 快速滑块 | 画布上直接拖，随手改粗细与不透明度 |

调好后导出成 .hbr 文件就能发给别人；换机前把笔刷组整套导出、新机上再导入，配置原样带走。

## 四、更多笔刷资源去哪找

应用的设置里有社区资源入口，能翻到用户自制的笔刷；从第三方渠道拿笔刷文件时，先确认是 .hbr 格式再往里导，避免白下一趟。笔刷配好了还没装应用的，可以先去 [HiPaint 功能总览](https://hipaint.hfdk.space/)看安装与上手路径，回来再慢慢攒自己的笔刷库。
