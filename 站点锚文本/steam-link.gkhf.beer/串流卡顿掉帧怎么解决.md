# 串流卡顿掉帧怎么解决

Steam Link 连上了，画面也出来了，但玩两分钟卡三秒——这是最常见的问题。好消息是：串流体验的瓶颈几乎总在网络而不是电脑，按本文的顺序排查，多数情况十分钟内能定位。

## 第一步：先让问题"现形"

别凭感觉猜。在设备的流式传输设置里打开**性能叠加层**（性能图表），串流时屏幕上会出现实时曲线。重点盯那条青色的网络时间线：

- 曲线平缓 → 网络没问题，卡顿可能是电脑端编码掉链子，去查后台程序；
- 曲线频繁飙峰 → 网络时间抖动严重，问题就在链路上，往下看。

Steam 客服文档把这个工具列为排障第一动作，因为它能直接告诉你该修网络还是修电脑。

## 第二步：修网络拓扑

网络类卡顿多半源于下面几条，命中率从高到低：

1. **电脑走无线是头号杀手**。视频流要先进电脑、再出路由器、然后无线发给手机——电脑和设备都走无线时，两条信号在空中对撞，Steam 明确说这种拓扑"几乎必然表现糟糕"。让电脑插一根网线连路由器，体验立竿见影。
2. **手机连 5GHz 频段**。2.4GHz 拥挤且干扰多，5GHz 干净得多；路由器支持 802.11ac 最佳，11n 的 5GHz 次之。频宽设置从 40MHz 起步，稳定后再试 80MHz。
3. **路由器关闭「客户端隔离 / AP 隔离」**。这个选项开了之后设备间互相隔离，不仅扫描不到电脑，连上了也会不稳。
4. **玩的时候让出带宽**。有人同时挂着 BT 下载、往电视投屏、看在线视频，串流就会时好时坏。串流和这些应用抢同一条出口，让谁先来一目了然。

VR 串流对网络的要求更苛刻：需要 5GHz Wi-Fi 5 起步的路由器，且电脑必须有线连路由器，头显仅支持本地网络串流。

## 第三步：调带宽限制

设置 → 流式传输 → 高级客户端选项 → **带宽限制**。操作口诀是从最低档起步，逐步上调，一旦出现问题就退回上一个稳定档位——那个档位就是你家网络的甜点值。想恢复默认行为选「自动」即可。

## 第四步：清理电脑后台

Valve 的客服文档里点名过一批会干扰串流的程序，包括帧数显示类的 MSI Afterburner、RivaTuner，外设管理类的 Razer Synapse，以及录屏软件、云同步工具和 BT 下载器。串流前把它们关掉，能给视频编码和上行带宽腾出空间。

## 端口被拦也会卡

防火墙没放行串流端口时，表现不只是连不上，还可能频繁掉线：UDP 27031、27036，TCP 27036、27037（VR 串流另需 UDP 10400、10401）。Steam 或游戏更新之后，即使以前正常，防火墙也可能重新拦截，值得复查一遍。
