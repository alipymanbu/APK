# AionClaw 是什么？一款把任务说出去、结果交回来的 AI 助手

> 本篇讲 AionClaw 的定位与产品思路：它和常见聊天 AI 的差别、都能接什么活、靠什么把活干完。
> 上手与派活流程见相关文档：[AionClaw 怎么用](AionClaw怎么用.md)。

---

AionClaw 是杭州趣猿人工智能推出的 AI Agent 助手，宣传语叫"真正能做事的 AI 龙虾"。它基于开源框架 OpenClaw 深度升级，覆盖安卓、Windows、macOS 等多端，思路和"问答式 AI"有明显区别：大多数 AI 应用停在"给建议"——问它怎么写周报，它回十条要点；问它怎么做起短剧，它给三个方向；真正动手的部分，仍然留给用户。AionClaw 主打的就是补上这最后一段：把任务交代出去，由它调用大模型与工具执行，最后把结果交回来。

## 它能接的活，长什么样

按产品方公开的场景介绍，交代出去的任务大致是这样的：

| 交代出去 | 交回来 |
| --- | --- |
| 散在各个聊天记录里的周报素材 | 一份有条理的周报初稿 |
| 脑子里的短剧点子 | 能直接开拍的剧本和分镜 |
| 用大白话描述的小程序需求 | 跑得起来的成品 |
| 开网店做跨境的想法 | 选品建议、商品文案、竞品动态跟踪 |
| 堆成山的行业资料 | 梳理好、能直接用的结论 |

能看出它的定位偏"干活的同事"而不是"聊天的对象"：开发、视频/短剧、电商、股票、内容运营、设计、学术、营销增长、法律这些方向都有对口的专家智能体，开口不用先解释一遍行业背景。

## 靠什么把活干完

- **自动调度大模型**：DeepSeek、Qwen、Kimi、智谱 GLM 等主流模型随任务切换，遇到难啃的任务会自动换更擅长深度思考的模型，用户不用懂模型、也不用配 API Key。
- **移动桌面协作**：手机上交代一句，电脑端开工，成果推送回手机；也能把微信、飞书、钉钉、QQ 这些常驻聊天工具接上，在消息窗口里直接派活。
- **持久记忆**：记住文档格式、称呼习惯和常用标准，用得越久越省交代。
- **技能市场**：社区提供 5000 多个技能，写作、翻译、PPT、数据处理即装即用，也可以让 AI 自己给自己装技能。
- **本地运行**：记录与配置保存在本地设备，本地部署模式下数据不经外部服务器。
