# 格式转换常见问题解答：转不动、找不到结果、没有目标格式怎么办

> 本篇按症状整理格式转换的常见问题：提交就报错、转完了文件不对劲、列表里没有要的格式，各自怎么排查。相关阅读：[手机上转换文件格式的方法.md](手机上转换文件格式的方法.md)、[万能格式转换器哪个好用.md](万能格式转换器哪个好用.md)

---

用 file converter 这类转换工具，大多数顺利，出问题的一般集中在下面这几种情况。按症状对号入座。

## 一、提交转换就报错，或一直转不完

按出现概率从高到低排：

1. **网络问题**：文档、图片、电子书这些类别的转换要经过服务器，先确认能正常上网；公司和校园网常拦外部请求，切手机流量再试一次是最快的验证办法；
2. **文件加了密**：带密码的 PDF、ZIP 不支持直接转换，先解密另存一份无密码的版本；
3. **内容带版权保护**：部分商店购入的电子书、音乐有 DRM 保护，这类必然失败，也没有绕开的办法；
4. **文件太大**：云端转换对单文件体积有上限，超大文件先压缩（比如视频降分辨率）再转；
5. **服务端临时故障**：网络正常、文件也没问题却反复失败，多半是转换服务当时不可用，隔段时间重试。

## 二、转换完成了，但找不到结果文件

别先去文件管理器里翻。这类应用的转换任务都收在侧栏里，一般分「进行中 / 已完成 / 失败」三组：点「已完成」组里的对应条目就能取回或分享；点开失败组看看是不是它躺在了那里。安卓新系统限制了应用数据目录的直接访问，从应用内分享出去是最省事的取法。

## 三、格式列表里没有我要的那个

- 每个类别只有固定的输出方向，不存在「任意格式互转」：视频类输出就是 MP4、MKV、WebM 那几样，想「音频输出成视频」这类反向需求它不做；
- 同一个文件有时能归进不同类别（带文字的截图既是图片也是扫描件），换个入口进，输出列表可能就不一样；
- 挑工具前先看格式覆盖清单——像 [File Converter](https://file-converter.wrwq.fun/) 的介绍站里就把各类别的输出方向列全了，先对清单再动手能省很多时间。

## 四、转出来的东西不对劲

| 症状 | 多半是 |
| --- | --- |
| 扫描件转出来还是图片、选不了字 | 没勾 OCR，重新转并在高级设置里打开 |
| 视频转完方向不对 | 高级设置里有旋转选项，转之前设好 |
| 音频音质明显变差 | 输出比特率设太低，调高再转 |
| GIF 大到发不出去 | 先裁短时长、降尺寸，GIF 没有压缩率可言 |
| 电子书在阅读器里排版乱 | 高级设置里指定目标阅读器型号再转 |

## 五、用得顺手的两个前提

一是**网络**：云端转换全靠它，Wi-Fi 优先；二是**权限**：存储权限不给，选文件的列表是空的。这两点在[手机上转换文件格式的方法](手机上转换文件格式的方法.md)的安装一步里有提。都排除了还不行的，参考[万能格式转换器哪个好用](万能格式转换器哪个好用.md)里说的「服务端故障」那种情况，换个时段再试往往就好了。
