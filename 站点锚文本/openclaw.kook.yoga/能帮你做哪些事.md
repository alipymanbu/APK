# OpenClaw 能帮你做哪些事

这篇按「它到底是什么 → 能接什么活 → 在哪干活」的顺序，把 OpenClaw 的能力盘一遍。它的名字在 2026 年初频繁出现在科技媒体和社区讨论里，很多人是被「数字员工」这个叫法吸引来的，这篇就从这里讲起。

## 它是什么来头

OpenClaw 是一个开源的个人 AI 智能体框架，最初跑在电脑上。科技日报对它的描述是：能调用大模型、自动化操控本地环境与任务流程，被用户称为「能指挥电脑的数字员工」。和普通聊天机器人的差别在于：它不只会回答问题，还会真的动手——读写文件、执行命令、操作浏览器，把一句话指令拆成一系列动作做完。

## 能接的活

- **消息入口接指令**：通过 Telegram、WhatsApp、Discord 等聊天软件给它发消息，人在外面也能指挥家里的 AI 干活；
- **工具执行**：浏览器自动化、终端命令、联网搜索，把「说」变成「做」；
- **定时与触发**：Cron 定时任务、Webhook 触发器，适合盯盘提醒、定时汇总这类重复流程；
- **技能扩展**：社区 Skills 生态，按需装技能包，国内云厂商也在往里上架自己的 Skills；
- **多模型接入**：Anthropic、OpenAI、Google 之外的模型也能接，国内常见的 DeepSeek、Kimi、GLM 等在百度系的部署服务里可以直接选配。

## 手机上怎么用

OpenClaw 本体跑在电脑端，但 2026 年 3 月起手机端的路子陆续铺开：红手指 Operator 把它预置进云端虚拟手机，DuClaw 提供网页端零部署服务，百度 App 也能一键唤醒。这几条路子的取舍在[手机端使用方法与入口对比](手机端使用方法与入口对比.md)里展开。

如果想在手机上直接管理支撑它运转的云资源（云服务器、账单、工单），配套的安卓客户端是个顺手的工具，安装过程见[安卓客户端安装步骤与首次使用](安卓客户端安装步骤与首次使用.md)；图文版介绍与界面截图在 [OpenClaw 手机端介绍](https://openclaw.kook.yoga/) 。

## 动手前的提醒

智能体能执行真实操作，权限给得越足，能干的事越多，出岔子的空间也越大。社区文档反复强调的几条：先在受控环境里试、给敏感操作加审批、别把 API Key 随手塞进公开配置。这些习惯比任何技巧都重要。
