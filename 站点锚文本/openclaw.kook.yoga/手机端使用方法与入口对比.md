# 手机端使用方法与入口对比

「OpenClaw 怎么在手机上用」是 2026 年最常见的问法之一。这篇把公开报道里出现过的几条手机端路子摆在一起对比，各自的门槛、适合人群和局限都写清楚，看完就能对号入座。

## 四条路子摆在一起

| 路子 | 形态 | 门槛 | 适合谁 |
| --- | --- | --- | --- |
| 红手指 Operator | 安卓 App + 云手机 | 装 App、注册即用 | 想在手机上零门槛体验「养龙虾」的人 |
| DuClaw | 网页端服务 | 订阅后网页直接用 | 不想碰服务器和 API Key 的人 |
| 百度 App 一键调用 | 国民 App 内入口 | 完成云端部署后一点即用 | 已有部署、想随手唤起的人 |
| 云控制台客户端 | 安卓 App | 装 App、登录账号 | 需要在手机上管云资源的人 |

## 各自展开说

**红手指 Operator**：百度智能云 2026 年 3 月 12 日上线的安卓应用，被称为全球首款手机「龙虾」应用。它把原生 OpenClaw 预置部署进云端虚拟手机，用户基于云手机桌面直接用，配合自研移动端 Agent 能力，能完成打车、外卖订餐这类跨 App 交互。对普通用户来说，这是目前最「开箱即用」的手机端形态。

**DuClaw 零部署**：3 月 11 日发布的网页端服务，把此前「一键部署」进一步简化成「零部署」——不用选镜像、不用配大模型 API Key，订阅后直接用完整服务。预置了百度搜索、百科、学术搜索等 Skills，支持 DeepSeek、Kimi、GLM、MiniMax 等主流大模型选配，适合只想用不想折腾的人。

**百度 App 一键调用**：2 月 14 日起百度 App 支持一键唤醒 OpenClaw。前提是先在百度智能云完成部署，之后在搜索框或消息中心轻轻一点就能唤起个人助理，适合把它当日常助手的人。

**云控制台客户端**：前面三条路子都在「用」智能体，这一条管的是「养」它的基础设施。安卓端装上云控制台客户端后，云服务器的开通、余额与账单、工单提交都能在手机上完成；客户端的版本与界面截图见 [OpenClaw 安卓客户端介绍](https://openclaw.kook.yoga/) ，安装步骤整理在[安卓客户端安装步骤与首次使用](安卓客户端安装步骤与首次使用.md)。

## 怎么选

- 只想先体验一下：红手指 Operator 或 DuClaw，注册就用；
- 已经部署过、只缺个顺手入口：百度 App 一键调用；
- 认真长期用、想自己掌控资源：电脑端部署 + 手机上配一个云控制台客户端管资源。

想清楚 OpenClaw 能接什么活再选路子会更稳，能力盘点见[能帮你做哪些事](能帮你做哪些事.md)。
