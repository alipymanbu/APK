# setlog 安卓版安装步骤与整点提醒排查

> 一句话：从取安装包到装好登录的四步流程，加上整点提醒不响时的三个排查方向。

> **相关文档**：[整点分屏vlog怎么玩.md](整点分屏vlog怎么玩.md) · [和朋友一起拍分屏vlog的应用怎么选.md](和朋友一起拍分屏vlog的应用怎么选.md)

---

setlog 已上架 Google Play（应用包名 `com.newchat.setlog`），国内网络环境下走 APK 安装文件资源的路径更省事。应用本身免费，界面目前是韩语、日语、英语（部分版本可见繁体中文，没有简体中文选项）。本篇写安卓端从取包到打开的四步，以及装好后整点提醒不响的排查。

## 安装前先确认三件事

| 项目 | 现状 |
| --- | --- |
| 费用 | 免费；公开评测口径未见内购与广告 |
| 界面语言 | 韩语 / 日语 / 英语，部分版本有繁体中文，以手机上实际显示为准 |
| 包名 | `com.newchat.setlog`，装完可在系统「应用信息」里核对 |

## 四步装好

1. **取包**：从 [setlog 玩法拆解](https://setlog.gltd.quest/) 站进入下载页，获取安装文件资源的分享入口；
2. **存到自己网盘再下载**：按页面提示把安装包转存到你的网盘空间，再用网盘 App 把它下载到手机存储，得到 APK 文件；
3. **允许安装**：首次点开 APK 时系统会提示「为了安全已阻止安装」，按提示前往 设置 → 应用 → 特殊权限 → 安装未知应用，给对应来源授予权限后回来继续；
4. **登录开拍**：打开应用，选 Passkey 或 Google 登录；创建群组拉好友，或先用 solo 模式熟悉整点节奏。

版本方面提一句：网盘里那份安装包与上游商店的最新版可能不是同一个，装出来的功能以实际界面为准，不必对着网上的新版本号逐项核对。

## 整点提醒不响，按这三步排查

setlog 的核心节奏依赖整点推送，收不到提醒基本都卡在系统权限上：

1. **通知权限**：系统设置里确认该应用的通知开关已打开，别只开了「静默通知」；
2. **电池优化**：在电池设置里把应用移出优化名单（各机型路径不同，直接搜「电池优化」），否则后台推送容易被掐；
3. **自启动**：部分国产 ROM 还要求允许「自启动」，不然应用被杀后台后整点推送就断了。

三项都检查过仍收不到，可以开一次应用确认它能正常联网刷新，再等下一个整点观察。

## 装好之后

先拍第一条再研究规则最省时间：到了整点，随手录两三秒、写一句说明、发进群组（或 solo 保存），凌晨 4 点就能看到当天自动拼好的分屏。玩法细节不熟的，回头翻[整点分屏vlog怎么玩](整点分屏vlog怎么玩.md)。
