# 安卓手机运行 XP 系统的完整流程：从镜像到开机

> 想在安卓手机上看到 Windows XP 的启动画面，需要一台模拟器加一个系统镜像。这篇按顺序讲清每一步做什么、哪里最容易卡住。
> **相关文档**：[手机x86模拟器怎么选.md](手机x86模拟器怎么选.md)

---

## 一、开工前要备齐的两样东西

1. **一台 x86 模拟器**：手机上常见的是 Bochs 的安卓移植版，它把整台 x86 电脑（CPU、芯片组、显卡、BIOS）用软件模拟出来，属于"模拟得实、跑得不快"的类型——跑 XP 这类老系统，慢是常态，先接受这一点再开工。
2. **一个 XP 的磁盘镜像（.img 文件）**：模拟器只是"裸机"，没有镜像它永远停在 BIOS 自检画面。镜像动辄几百 MB 到几 GB，手机存储要留足富余，因为系统运行时还会持续往镜像里写数据。

另外提一句：如果你只是想先验证流程、手头还没有 XP 镜像，可以先用模拟器内置下载的 FreeDOS 或 muLinux 这类小系统练一遍手，再换正式镜像。

## 二、四步流程

按下面的顺序做，每一步都别省：

1. **装好模拟器并完成首次启动**。第一次打开时它会复制 BIOS 等运行文件到应用目录，保持前台等它跑完，见到 BIOS 相关画面再退出。
2. **挂载镜像**。在"存储"标签页，把 .img 文件指定给 ata0-master（主通道主盘），底部选好启动盘。文件选择器一般有 System（新）与 In-App（旧）两种入口，选其一即可。
3. **检查基础配置**。"配置"页里内存建议给到 256 MB 以上（XP 的常见下限）；"其它"页确认 rom 镜像（默认 BIOS-bochs-latest）、VGA 刷新频率与扬声器开关。
4. **按 Start 通电**。先看到 BIOS 自检文字，然后就是熟悉的 XP 启动画面——进系统可能要几分钟，这段等待属于指令级模拟的正常速度，不是卡死。

## 三、最常卡的三个地方

- **卡在启动画面不动**：XP 上最常见。先关掉手机后台应用把内存让出来，再把模拟器里的内存设置调到镜像用得了的范围（不是越大越好），仍不行就换更精简的 XP 镜像。
- **没有声音**：模拟器里有声卡选项，但要镜像里装了对应驱动才会出声，很多现成镜像没带驱动，属正常现象。
- **进系统后连不上网**：安卓端的移植版按"不能联网"预期比较稳妥，把它当单机用；文件要传进虚拟机的话，试试共享文件夹方式挂载手机目录。

## 四、预期与替代方案

跑 XP 更像"让一台旧电脑复活"，不是"手机变电脑"：点菜单要等、窗口切换要等，适合怀旧与折腾，不适合当生产力。如果只想跑某个老软件而它恰好有 DOS 版，FreeDOS 加 DOS 版软件的组合体验会比 XP 顺畅得多。

选好模拟器、备齐镜像之后，具体怎么装、每一步在哪个界面，可以照着 [Bochs 安卓版介绍站](https://bochs.fwen.ren/) 的装机流程页一步步来，里面连下载与安装的常见问题都整理好了。
