# Mineradio 安卓版安装步骤与问题排查

> 本篇讲 Mineradio 安卓版怎么装进手机：从哪拿到安装包、安装时系统会拦什么、装不上先查哪几项。

## 一、装机前知道三件事

- 版本：安卓存量版 1.1.5，安装包约 40.85 MB，要求安卓 5.2 及以上；
- 来源：安装包放在夸克网盘分享里，转存到自己网盘后下载到手机，得到 `Mineradio_v1.1.5.apk`；
- 性质：项目按 GPL-3.0 开源，免费、无广告、无内购。

## 二、安装步骤

1. 打开网盘分享页，把安装包转存到自己的网盘账号，再下载到手机存储；下完核对大小在 40.85 MB 上下；
2. 在文件管理器里点开安装包，系统弹「是否允许安装」时选允许；若提示先开启「安装未知来源应用」，跳到系统设置把权限授给这次打开安装包的入口，再返回重试；
3. 等安装进度走完，点「打开」或回桌面点星球图标启动；
4. 首次启动允许「读取本地音频」权限，等扫描完成即可开始用。

## 三、装不上先查这几项

| 现象 | 先查什么 |
| --- | --- |
| 点安装包没反应 / 提示解析失败 | 安装包多半没下完整，重下并核对大小 |
| 大小正常仍报「解析包出现错误」 | 关掉系统的「纯净模式」再装；确认存储空间充足 |
| 提示与已有应用冲突 | 装过同包名旧版，先卸载再装这份 |
| 提示系统版本过低 | 确认安卓版本不低于 5.2 |

## 四、装好之后

本地文件导入与平台歌单同步的操作，见[歌单同步与本地导入方法](歌单同步与本地导入方法.md)；功能全貌、界面截图与视觉效果的展开介绍，看 [Mineradio 安卓版介绍站](https://mineradio.qhah.skin/)。
