# we learn 随行课堂怎么加入班级

> 本篇讲 we learn（随行课堂）里加入班级的完整流程：班级码从哪里来、在 App 的哪个位置输入，以及加错班级、看不到班级任务时的排查思路。

## 一、为什么要加入班级

we learn 的课程内容可以靠教材封底的激活码自行解锁，但老师布置的作业、阶段测试、公告和学习资料都挂在班级下面，平时分相关的形成性评价也按班级统计。想让平台上的学习行为真正计入成绩，开学第一周就把班级加好。

## 二、班级码从哪里来

班级码由任课老师生成：老师在网页端的「我的班级」里建班后，每门课程下都会生成一个对应的班级码，通常在第一堂课或课程通知里公布。同一个教学班如果同时学多门课程，老师会分别建班，每门课的班级码并不通用。

## 三、在 App 里加入班级的步骤

1. 打开 we learn App，登录自己的账号。
2. 点击底部导航的「学习」。
3. 找到「加入课程班级」入口。
4. 输入老师公布的班级码或课程码，确认后即加入成功。

加入后回到「学习」页刷新，就能看到班级课程、老师发布的作业与测试了。

## 四、常见问题

- **输入班级码提示不存在**：先核对有没有把数字 0 与字母 O 认混；再确认这门课的班级码有没有用错到另一门课上。仍不成功就联系任课老师核对建班信息。
- **加了班级但看不到作业**：确认登录的账号与老师登记的账号是否为同一个。平台存在个人注册账号与学校导入账号两种来源，混用后课程与任务会对不上。
- **加错了班级**：自行退出后重新输入正确班级码即可；若退出入口不可用，请任课老师在班级管理面板里把你移出。
