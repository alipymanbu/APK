# we learn 激活码无效怎么办

> 本篇讲 we learn（随行课堂）教材激活码的常见问题：提示已被使用或无效时先查哪里、激活码与课程的关系，以及何时需要联系客服处理。

## 一、激活码是怎么工作的

we learn 的移动课程与纸质教材一一对应。买了新教材后，封底印着一串激活码，它是解锁线上配套内容的钥匙：在 App 里找到「添加课程」或「课程激活」入口，输入激活码确认，配套的音视频、练习、测试就会进入课程列表。一串激活码对应一门课程，同时使用多本教材时需要分别输入。

## 二、提示无效时，先自查这四项

1. **字符认混**：最容易踩的坑是数字 0 与字母 O、数字 1 与字母 I。逐位对照封底印刷，不要凭印象输入。
2. **涂层刮花**：激活码区域刮得太用力会让个别字符缺失，对照包装内的说明页或教材前言里的备用标注确认。
3. **输入位置**：激活码要输在「添加课程 / 课程激活」入口里，与加入班级用的班级码是两回事，输错了自然提示无效。
4. **重复激活**：同一串激活码只能解锁一次，换设备后登录原账号即可，不需要也不应该再次输入。

## 三、确认无误仍失败怎么办

以上四项都排查过仍提示已被使用或无效，说明激活码本身可能出了问题（例如被提前注册）。这时联系平台客服处理最直接：提供教材条码、激活码截图与购买凭证，说明情况后等待客服核对。教材是二手购买的，出现激活码已被使用的情况较多，购买时尽量选择全新教材。

## 四、激活成功后的下一步

课程激活只是第一半，老师布置的作业与测试都挂在班级下面，还需要输入班级码归队，具体见本目录的 [随行课堂怎么加入班级.md](随行课堂怎么加入班级.md)。图文版的完整上手路径（含安装文件资源入口）整理在 [we learn 随行课堂介绍站](https://we-learn.kook.yoga/)，可以按步骤对照操作。
