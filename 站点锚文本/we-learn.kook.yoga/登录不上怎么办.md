# we learn 登录不上怎么办

> 本篇讲 we learn（随行课堂）登录环节的高频问题：学号账号与手机号账号怎么区分、忘记密码的正确处理方式，以及「重新登录后课程不见了」的排查思路。

## 一、先分清账号的两种来源

we learn 的账号有两个独立来源：

- **个人注册账号**：自己用手机号注册，适合没有学校统一安排的使用者。
- **学校导入账号**：账号是学号，初始密码由学校下发，具体以学校通知为准。

两种账号相互独立，课程和班级任务只跟着「你登录的那个账号」走。登录提示账号不存在或密码错误时，第一件事就是确认自己该用哪一种。拿不准就问任课老师或班委。

## 二、忘记密码的正确做法

在登录页点「忘记密码」，用注册时的手机号接收验证码，按流程重置后重新登录即可。不要因为密码忘了就重新注册一个新号——新账号是空的，原账号里加入的课程、做过的练习记录全都不在里面。

## 三、「重新登录后课程不见了」

常见原因有两个：

- **手里有多个账号**：手机号注册的账号和学校导入的学号账号可能同时存在，课程在哪个账号里就固定用哪个登录，逐个排查一遍。
- **误触注册**：登录时点成了「注册」，系统新建了一个空账号。退出登录，回到登录页改用原来的手机号登录即可。

两种情况都排除后课程仍不显示，通过 App 或网页版的客服入口反馈，提供注册手机号让客服核对账号下的课程记录。

## 四、登录之后的建议

登录成功后建议在账号设置里绑定可用的手机号，后面找回密码会省事很多。接下来按「激活课程 → 加入班级」的顺序把课备齐，图文版步骤整理在 [we learn 随行课堂介绍站](https://we-learn.kook.yoga/)，加班级的细节见本目录的 [随行课堂怎么加入班级.md](随行课堂怎么加入班级.md)。
