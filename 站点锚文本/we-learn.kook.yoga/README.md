# we learn（随行课堂）学习资源导航

这里是 we learn（随行课堂）的上手资料汇总页。we learn 是上海外语教育出版社推出、与高校外语教材配套使用的移动学习应用，本目录的文章围绕新生最常问的三件事整理：怎么加入班级、激活码无效怎么处理、登录不上如何排查。

## 本目录文章

- [随行课堂怎么加入班级.md](随行课堂怎么加入班级.md)：班级码从哪来、在哪输入，以及加错班级的处理。
- [激活码无效怎么办.md](激活码无效怎么办.md)：教材封底激活码的常见输入坑与申诉渠道。
- [登录不上怎么办.md](登录不上怎么办.md)：学号账号与手机号账号的区分、忘记密码的正确做法。

## 快速上手一览

完整的图文版上手指南（含安装文件资源入口）见 [we learn 随行课堂介绍站](https://we-learn.kook.yoga/)，按「登录 → 激活课程 → 加入班级 → 日常练习」的顺序一步步带着做。
