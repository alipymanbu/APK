# BT 下载速度慢的原因排查：按命中率从高到低

> 手机 BT 速度上不去，八成不是客户端"不行"，而是资源、网络或设置里某一环卡住了。这篇按实际命中率从高到低给一份可照做的排查清单。

## 一、先看资源热度，别的都是其次

打开任务详情里的节点页签，数一数连上了几个人（peers）、有多少在做种（seeders）：

| 现象 | 含义 | 能做什么 |
| --- | --- | --- |
| 做种个位数 | 资源冷门，供给就这么多 | 换时段再试，或换资源 |
| 节点有但速度趋近零 | 连上了但对方不给你传 | 等待，或换资源 |
| 节点几十上百 | 资源没问题，问题在你这边 | 继续往下排查 |

冷门资源下载慢基本无解——BT 的速度来自"有多少人同时在做种"，客户端再好也变不出节点。

## 二、客户端这边：五个最常见的自伤设置

按出现频率排：

1. **仅 Wi-Fi 开着，人却在用移动数据**。任务全部暂停、状态停在排队（Queued），看起来像"卡死"。要么连上 Wi-Fi，要么在设置里放开这个开关。
2. **系统省电策略杀后台**。锁屏几分钟后传输中断，亮屏又恢复。把客户端加入电池白名单 / 允许后台运行，很多机型默认会限制它。
3. **上传带宽被占满**。BT 传输需要持续交换确认信息，上传跑满会拖垮下载。把上传速度上限设到总带宽的七八成，整体反而更快。
4. **顺序下载一直开着**。它按顺序取块，对做种不友好，部分节点会优先服务别人。看完视频记得关掉。
5. **存储位置空间不足或不可写**。剩余空间小于种子体积、或外置卡是 FAT32 且单文件超 4GB，任务会停在半路。换到内置存储是最快的验证方式。

## 三、网络这边：节点发现与端口

- **追踪器全红不等于没救**：tracker 失效很常见，DHT 与 PeX 会继续帮你发现节点，确认这两项（加上局域网的 LSD）处于开启状态即可。
- **端口映射**：路由器支持的话让 UPnP 或 NAT-PMP 自动映射监听端口，能显著提高"可被连上"的概率——能被主动连接的节点，总是更容易排上队。
- **运营商对 BT 流量限速**：部分宽带在高峰时段对 P2P 做 QoS，协议加密能绕开最粗暴的识别，换个时段测试往往立竿见影。

## 四、一条省时间的排查顺序

先看做种数 → 再确认仅 Wi-Fi 与后台策略 → 然后限上传、关顺序下载 → 最后动端口与加密。前三步解决绝大多数"莫名慢"，需要更完整的操作背景（比如任务怎么加、文件怎么挑），[Flud 安卓版的功能与安装说明](https://flud.usea.quest/)里有分步展开；工具本身的选型问题回看 [安卓BT下载器怎么选.md](安卓BT下载器怎么选.md)。
