# 从配对到跑通第一个脚本的完整流程

> 本篇讲一台普通安卓手机从零接入 Hamibot 的完整链路：装客户端、配对控制台、开权限、装第一个脚本、看到运行结果。想先了解这个工具能做什么、界面长什么样，看 [hamibot 安卓自动化介绍站](https://hamibot.hfdk.space/) 的整理即可。
> **相关文档**：[免root实现自动签到打卡的思路.md](免root实现自动签到打卡的思路.md) · [脚本市场与多设备批量管理的玩法.md](脚本市场与多设备批量管理的玩法.md)

## 一、整条链路只有五步

Hamibot 的运行模型是「网页控制台下发指令、手机本地执行」，所以接入过程围绕一件事展开：把手机和账号关联起来。完整走一遍大约十几分钟：

1. 手机装上 Hamibot 客户端（APK 安装，允许一次「未知来源」即可）；
2. 手机号注册并登录；
3. 在控制台「设备」页拿到配对码，填进手机 App 完成配对；
4. 开启无障碍服务等必要权限；
5. 从脚本市场装一个现成脚本，选定这台设备运行。

装完的客户端界面很朴素：配对入口、权限开关、脚本列表，几件核心事都收在侧边栏里。

## 二、配对这一步的细节

- 配对码在控制台的「添加设备」页显示，输入一次即可，之后设备会一直挂在账号下；
- 1.6.1 版起的客户端还支持本地配对文件方式，不用手输配对码，入口在 App 的配对界面；
- 免费额度可配对 1 台设备，接入前先想好用哪部手机；要绑更多设备需要订阅扩容；
- 配对码输完没反应：先确认手机能上网、App 处于登录状态，再重输；仍不行就重启手机换个网络验证。

## 三、权限是最容易翻车的环节

「脚本运行几秒就自动结束」十有八九是权限没开全。三项都要给到：

| 权限 | 用途 |
| --- | --- |
| 无障碍服务 | 脚本找控件、点按钮全靠它 |
| 后台弹出界面 | Hamibot 在后台时才能拉起其他应用 |
| 屏幕截图 | 坐标类操作需要截屏授权，弹窗里勾「记住选择」 |

国产系统对后台的限制普遍很严，想让设备长期在线，还要把自启动、省电策略（设为无限制）、前台服务、悬浮窗这几项开齐；华为机型另有关掉「锁屏断网」。无障碍服务被系统悄悄结束后，最快的恢复办法是重启手机。

## 四、跑通第一个脚本

从脚本市场挑一个免费的签到类脚本，点「安装脚本」后它会出现在账号里；打开控制台的脚本控制台，选中脚本、挑一台在线设备执行即可。运行后等几秒到几十秒是正常的（启动要加载），没动静就看手机 App 右上角的日志图标找线索。

想改行为：控制台里选中脚本点「源码」进在线编辑器，改完 Ctrl+S 保存，下一次运行即生效。脚本语言是 JavaScript 加 JSON，与开源项目 Auto.js 的语法一脉相承，最小示例三行就能动起来：

```javascript
app.launchApp('计算器');   // 按应用名启动
sleep(1000);               // 等一秒
toast('已打开');           // 弹个提示
```
