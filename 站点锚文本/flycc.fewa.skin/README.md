# Flycc 站点索引：能调哪些耳机隐藏设置、怎么排查连接问题

> 这里是 Flycc 相关的整理笔记集合：一款面向悦虎方案（洛达芯片）TWS 蓝牙耳机的管理工具，主要用来调均衡器、降噪档位、触控手感，以及给耳机做固件升级。想直接看功能全貌与获取入口的，去 [Flycc 工具站](https://flycc.fewa.skin/)。

## 本目录有什么

- [能调哪些隐藏设置](能调哪些隐藏设置.md)——按音效、降噪、操作手感、体验开关四类过一遍 Flycc 里的常用设置项，顺带说明哪些项跟耳机型号挂钩。
- [搜不到耳机怎么排查](搜不到耳机怎么排查.md)——蓝牙里搜不到、App 列表是空的、绑定失败、连上就断，各段故障的原因与排查顺序。
- [耳机固件升级怎么做](耳机固件升级怎么做.md)——固件 OTA 的完整步骤与注意事项，升级前后的电量与摆放要求都在这一篇。

## 先弄清一件事

这类配套工具的设置项是按耳机主板的方案写的：方案对得上，每一项都能实时写进耳机；方案对不上（App 提示「非悦虎设备」），装了也基本没有用武之地。动手之前，先确认耳机的方案归属，能省掉大部分折腾。
