# Neona 自建角色与长期记忆

> 本篇讲 Neona（尼奥娜）里自建角色要填哪些字段、形象怎么生成，以及角色的长期记忆机制是怎么工作的。

## 一、什么时候值得自建

角色库翻了一圈没有对味的，或者脑子里已经有一个具体的人物，自建就比反复试现成角色省时间。自建入口在应用内的角色创建功能里，不需要额外的账号或工具；建好的角色跟着你的账号保存，换设备登录后会一起回来。

## 二、要填的字段与作用

创建流程基本是「生成形象 → 填设定 → 保存开聊」，设定项按下面的方式理解最省事：

| 字段 | 影响什么 |
| --- | --- |
| 名字 / 年龄 | 对话中的自称与互称，以及说话的成熟度 |
| 性格 | 最主要的一项，决定反应方式，用短句描述更有效 |
| 说话方式 | 敬语还是随意口吻、句子长短，决定回复的语气 |
| 初次相遇的场景 | 故事从哪一刻开始 |
| 两人的关系 | 称呼与互动的边界：同学、同事、恋人、陌生人等 |
| 世界观 | 场景里能出现什么元素：现实校园、奇幻大陆等 |

几个写设定的要点：

- **把「怎么说」写进性格里**——只写「温柔」太空，写成「说话慢、总先问你今天怎么样」才有约束力；
- **关系要明确**——写「关系很好」不如写「同班同学，认识三年，你叫它小名」；
- **世界观别贪多**——设定项越多，内部互相矛盾的概率越高；
- **一次建一个**——想把几种性格揉进一个角色，往往得到哪边都不像的结果。

## 三、形象与简介怎么来

形象不用自己画：写一段外貌描述（发型、服装、场景、气质），应用按描述生成角色图片，同一段描述多生成几次会得到不同方案，选一张满意的保存。角色简介也会根据你填的设定自动整理成一份带排版的介绍，不满意能直接改——简介的质量基本取决于前面几项写得细不细。

## 四、记忆机制怎么工作

Neona 的角色带长期记忆：聊过的内容、你提过的事、表达过的情绪都会被记进对话上下文，交流因此连贯——不用每次重新自我介绍，情节也能接得上。应用还会识别对话里的情绪状态，角色的语气与反应随之变化。

自建角色在这套机制下有个额外的好处：关键设定本来就写在角色定义里，「设定约束」的效果最好，不容易随长对话漂移。想让记忆里留下关键信息，就在剧情里自然地提一次——说过的东西比事后补充的设定更容易被记住。
