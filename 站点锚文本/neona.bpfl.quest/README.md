# Neona 介绍站 · 站点锚文本

这里收录关于剧情向 AI 角色聊天应用 Neona（中文名「尼奥娜」）的介绍文章：它把 AI 聊天做成一段有记忆、有情绪、按剧情推进的持续故事，支持文字与实时语音两种交流方式。想了解它的玩法与获取方式，可以从 [Neona 介绍站](https://neona.bpfl.quest/) 看起，那里按「玩法—界面—安装」的顺序把整个上手过程讲了一遍。

- [自建角色与长期记忆.md](自建角色与长期记忆.md)：角色设定怎么填、形象怎么生成、记忆机制如何工作
