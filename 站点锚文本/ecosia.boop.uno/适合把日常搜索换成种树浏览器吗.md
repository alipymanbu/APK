# 适合把日常搜索换成种树浏览器吗？先看这四个问题

> 本篇不吹不黑，从结果质量、隐私需求、参与感和设备适配四个角度，帮读者判断要不要把日常搜索迁移过去。机制背景见[种树搜索引擎是什么原理](种树搜索引擎是什么原理.md)，功能清单见[安卓浏览器功能与隐私详解](安卓浏览器功能与隐私详解.md)。

换默认搜索引擎是个习惯问题，值不值得换，取决于它能不能在不添麻烦的前提下给出额外价值。下面按读者最关心的顺序逐条过。

## 一、结果质量够不够用

它的网页结果由 Bing 索引提供，日常导航、查资料、购物比价都在水准线上；个别冷门 query 的精度可能不如主力引擎。务实的用法是：当作主力日常使用，遇到特别冷门的问题再交叉验证——大多数人对搜索引擎的依赖集中在高频简单查询上，这部分它完全接得住。

## 二、隐私需求有多重

对「不想被画像、不想被卖数据」的用户，它是比主流引擎更省心的选择：不建个人画像、搜索与 IP 数据 7 天内匿名化、传输全程 SSL 加密、无痕模式不存本地记录。当然，它不是匿名工具，搜索仍会经过服务端处理——诉求是「少被追踪」而非「彻底隐身」的话，这套默认配置已经够用。

## 三、参与感值不值

这是它最独特的部分：每次搜索都会推进社区种树计数，登录账号后还能攒种子、升等级、看个人影响统计。对喜欢「顺手做点小事」的用户，这种零成本的参与感是普通搜索引擎给不了的；社区累计 1.8 亿+ 棵树、2000 万+ 用户的规模也说明这不是小圈子玩具。

## 四、设备与习惯适配

- **安卓用户**：体验最完整，浏览器 + 搜索 + 计数一体，装完即用。
- **多设备用户**：账号体系让影响数据跟着人走，手机与电脑的行为可以合并计算。
- **重度依赖 Chrome 插件的用户**：浏览器本体基于 Chromium，常见使用习惯都能平移。
