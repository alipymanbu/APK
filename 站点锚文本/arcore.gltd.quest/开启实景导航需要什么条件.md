# 实景导航开启条件与常见原因：按钮找不到、定位转圈怎么办

> 谷歌地图步行导航里的实景模式（Live View）能把转向箭头直接叠在真实街道上，但不少人卡在「按钮不出现」或「一直在寻找位置」。这篇把开启条件和对应处理一次列清。

## 一、实景导航靠什么工作

实景模式打开后，屏幕上是摄像头实时画面，转向箭头「钉」在街道的正确位置上——这背后是底层的 AR 服务在实时定位手机的位置与朝向。所以实景导航进不去时，先别急着折腾地图应用，底层服务才是排查起点。

## 二、开启条件逐项核对

按这条清单从上往下过，绝大多数问题卡在前三行：

| 核对项 | 要求 |
| --- | --- |
| 导航模式 | 只有**步行**路线才有实景入口，驾车模式没有 |
| 机型认证 | 型号需在谷歌的认证设备名单里，名单页 Ctrl+F 搜型号最快 |
| 系统版本 | Android 7.0 及以上（个别机型另有单独要求） |
| 底层服务 | 应用管理里能搜到 Google Play Services for AR，且版本较新 |
| 相机权限 | 「设置 → 应用 → 地图 → 权限」里放行相机 |
| 应用版本 | 地图应用保持较新，旧版入口位置不同 |
| 所在地区 | 实景导航并非所有地区开放，开关与覆盖以谷歌说明为准 |

底层服务这一项如果搜不到，可以先去 [ARCore 说明站](https://arcore.gltd.quest/) 看看它的安装与验证步骤；机型与系统两关的详细排查，另一篇 [手机AR功能用不了怎么排查](手机AR功能用不了怎么排查.md) 写得更细。

## 三、症状对号入座

| 症状 | 通常原因 | 处理办法 |
| --- | --- | --- |
| 步行导航里没有「实景」按钮 | 机型不在名单 / 服务未装或太旧 / 地区未开放 | 先过完第二节清单；都满足仍没有，多半是地区未开放 |
| 一直转圈，「正在寻找位置」不结束 | 环境定位不成功 | 换到开阔、光线好的地方，按画面引导把镜头对准周围建筑扫一遍 |
| 箭头与实际朝向对不上、乱跳 | 校准不足或干扰多 | 远离玻璃幕墙和强反光表面，重新校准；收起手机再举起重新进入 |
| 用一会儿自动退回普通地图 | 定位长时间不稳 / 手机发烫 | 先退回普通地图走路，隔一会儿再试 |

## 四、用得顺的环境细节

- **光线充足**：夜晚、逆光、镜头被挡都会拖慢定位；
- **避开反光**：大面积玻璃幕墙、雨后湿路面会「骗」过画面识别；
- **有参照物**：有楼、有招牌的街道比空旷平地更容易定位；
- **认真校准**：进画面前按提示扫动周围一圈，校准越充分箭头越稳。

## 五、装好之后的小提醒

这套 AR 服务平时待命、不主动运行，只有实景导航或 AR 应用打开时才工作，日常不必为耗电担心。真遇到「装完应用还是不认」的情况，重启一次手机再试——系统级服务装完后，部分应用需要重启才能识别到它。

按清单过完，实景导航大概率能开起来；仍卡住的，回到机型名单那一关再确认一次。
