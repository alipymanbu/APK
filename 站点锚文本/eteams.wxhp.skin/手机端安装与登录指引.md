# eteams 手机端安装与登录指引

> 讲 eteams 安卓手机版从哪装、怎么装、装完登录时最容易卡住的几个提示怎么处理。
> **相关文章**：[移动考勤打卡设置全流程.md](移动考勤打卡设置全流程.md) · [和部署型OA怎么区分.md](和部署型OA怎么区分.md)

eteams 的安卓手机端和电脑网页版、企业微信端共用同一套账号数据，装好手机版把账号跑通，其余端口随时能用浏览器或工作台进入。这篇按「装 → 登 → 排障」的顺序讲。

## 一、安装包从哪来

安装包在 [eteams 移动办公平台介绍站](https://eteams.wxhp.skin/) 的下载页有获取入口，走网盘转存后下载到手机即可。安装包接近 180M，建议在 Wi-Fi 环境下载，避免下到半截文件装不上。

装好后想追新版本，可以在手机应用市场搜索「eteams」直接升级，不必反复转存安装包。

## 二、安装四步

1. 从网盘把 `.apk` 文件下载到手机存储；
2. 在文件管理器里点开它；系统提示「禁止安装未知来源应用」时，按引导去「设置 → 应用 → 特殊应用权限 → 安装未知应用」给对应应用授权，再回来继续；
3. 装完桌面出现 eteams 图标；之前装过同包名版本的会覆盖升级，登录数据保留；
4. 打开 App，用手机号注册或直接登录，加入公司团队——让管理员邀请你是最省事的路。

## 三、登录环节的三个常见提示

**「该账户未授权此手机，不能登录」**：这是设备授权机制，不是账号被盗。先在已授权的旧设备或电脑网页端登录，进「个人资料 → 设备管理」把这台手机加入授权设备，再回 App 登录。

**验证码收不到**：先确认没开骚扰拦截，换网络重发；仍收不到多半是手机号停用或换号，联系团队管理员协助处理。旧号还能收码时，尽早去「个人资料 → 基本信息」换绑。

**密码忘记**：从登录页找回密码入口走重置流程，用绑定手机号收验证码完成重置；手机号已停用的找管理员协助。

## 四、装完第一件事

eteams 按「账号 + 团队」组织内容：个人注册只能进 demo 环境，真正的协作要加入公司团队或自己创建一个。账号跑通后，最先用起来的通常是考勤打卡——记得先把定位权限给足，具体设置见 [移动考勤打卡设置全流程.md](移动考勤打卡设置全流程.md)。

另外提醒一句：如果你登录的是公司自有域名或内网地址，装的这份手机端可能进不了公司系统，先看 [和部署型OA怎么区分.md](和部署型OA怎么区分.md) 确认产品线再动手。
