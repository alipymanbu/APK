# eteams 移动考勤打卡设置全流程

> 讲 eteams 手机端怎么把考勤用起来：定位权限、打卡规则类型、外勤签到、异常申诉与请假联动，一次理清。
> **相关文章**：[手机端安装与登录指引.md](手机端安装与登录指引.md) · [和部署型OA怎么区分.md](和部署型OA怎么区分.md)

eteams 是泛微网络旗下面向团队的云端协同办公平台，考勤是它最常被先用起来的模块：手机定位打卡自动形成考勤轨迹，管理员按人员维度配规则，月底的报表不用再靠人工统计。这篇文章按实际使用顺序，把每一步的要点讲清楚。

## 一、打卡前：先把定位权限给足

eteams 的移动考勤基于地理位置。第一次打卡前，进手机「设置 → 应用 → eteams → 权限」，把位置信息设为「仅使用期间允许」或「始终允许」。权限没给足时，打卡页面会一直转圈定位或提示失败——这是新用户最常见的卡点。

打卡尽量在开阔位置操作：室内、电梯、地下车库里定位漂移，容易让打卡点偏离公司范围。除了 App，微信服务号和企业微信里同样能打上下班卡，数据进的是同一套考勤，手机不在手边时可以顶上。

## 二、考勤规则：不是只有朝九晚六一种

管理员在后台按人员维度配置规则，常见的几类：

| 规则类型 | 适合谁 |
| --- | --- |
| 固定时间考勤 | 朝九晚六的行政、财务类岗位 |
| 弹性考勤 | 只卡总时长、不卡到岗点的岗位 |
| 自由考勤 | 不按固定班制考核的岗位 |
| 倒班考勤 | 轮班制的一线岗位 |
| 单双周考勤 | 单双周班制交替的团队 |

规则可以按地域、职位、职级、部门、具体员工分别设置。出差多的销售岗和坐班的职能岗各用各的规则，不用一刀切；申诉次数、超时自动处理这类人性化选项也在管理员配置里。

## 三、外勤签到：拜访客户记得关联客户信息

销售、巡检、售后的外勤场景用外勤签到：到客户现场后打开签到、**选关联客户**、提交。关联这一步别省——它决定这次外勤记录能不能挂到对应客户名下，事后对账和复盘都靠它。外勤轨迹实时上报，管理者在后台能看全团队的外勤数据。

## 四、考勤日历与一键申诉

系统按规则和实际打卡情况自动生成考勤报表，每月每天的状态都能查，包括迟到、未签到、未签退这类异常。对结果有异议不用找人事对纸质单，直接在异常记录上**一键申诉**，领导线上审批处理。

自己的月度打卡轨迹上级同样看得到，代打卡这类操作在系统里是留痕的，别试。

## 五、请假审批和考勤是联动的

考勤模块可以和审批表单关联：外勤、请假这类单据批完后，数据自动计入考勤，剩余假期额度随之更新，年假、事假额度支持管理员批量导入。也就是说，请假走完流程，考勤日历和假期余额自己就变了，不需要再手工报备。

## 六、还没装 App 的先补上这一步

以上所有操作都建立在手机端已经装好的前提下。安装包从哪拿、未知来源权限怎么开、登录时设备授权提示怎么处理，见 [手机端安装与登录指引.md](手机端安装与登录指引.md)；如果发现手机上装的不是这条产品线，先看 [和部署型OA怎么区分.md](和部署型OA怎么区分.md) 再决定装哪份包。

想直接上手的，可以从 [eteams 移动办公云平台](https://eteams.wxhp.skin/) 进入站点，里面整理了功能模块速览与安装入口。
