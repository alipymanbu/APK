# 不登录看Twitch直播的安卓客户端

> 很多人只是想在手机上安安静静看一场 Twitch 直播：不想注册账号、不想被推荐流牵着走，更不想在进直播间前后看一段插播广告。这款叫 Twire 的开源安卓客户端就是冲着这个需求来的。本篇讲清它不登录能干什么、登录又多得到什么，以及「本地关注」这个容易踩坑的点。

## 一、为什么一个第三方客户端值得装

Twire 是开源项目（GPL-3.0 协议），代码公开、免费，安装包只有 9.3MB 左右，Android 5.0 及以上的手机都能跑。它只做「看直播」这一半事：浏览、播放、聊天、回放，没有首页推荐流和活动页，看播途中也不插广告。

对只想看播的人来说，这些取舍全是加分项——打开应用就是直播间列表，点进去就是画面。

## 二、不登录，这些都能用

| 功能 | 未登录可用 |
| --- | --- |
| 热门直播、热门游戏浏览 | 可用 |
| 搜索主播、游戏、频道 | 可用 |
| 看直播回放（VOD） | 可用 |
| 看频道里的剪辑（Clips） | 可用 |
| 进直播间聊天室 | 不可用 |

也就是说，装完直接跳过登录引导，切到「热门直播」就能看；错过的直播从频道页进回放列表接着看，支持拖进度和续播。

## 三、登录后多得到什么

- **进聊天室**：未登录时聊天面板是空的（不是故障，是没连上）；登录后才能发言，也才能看到 BTTV、FFZ、7TV 这三套社区表情的完整效果。
- **同步关注列表**：登录后应用会把你 Twitch 账号上的关注读进来，谁在开播一目了然。
- **订阅、礼物等聊天通知**：登录后才会出现。

登录走的是 Twitch 的授权页面，账号密码只输给 Twitch，应用拿到的是一个授权令牌；改密码或在平台侧撤销授权后需要重新登录，本地数据不会因此丢失。

## 四、最容易踩的点：本地关注

在 Twire 里点关注，默认**只写在本机**，不会同步到 Twitch 账号的关注列表。想搬运到另一台手机，用「导出全部关注」导出文件、新机上「导入关注」读回即可，导入不会反向写回账号。

换版本或卸载重装前，记得先导出——本地关注存在应用数据里，卸载即清空。
