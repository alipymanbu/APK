# 聊天表情与画质怎么调

> 装好 Twire 只是开始。这款开源的 Twitch 安卓客户端里藏着不少值得调一调的设置：三套社区表情怎么开、画质档位怎么选、锁屏和后台播放怎么才不会断。本篇把高频的几处设置按场景整理成取舍建议。

## 一、聊天室：先登录，再开表情

聊天室需要登录 Twitch 账号才会连接，未登录时聊天面板是空的——不是加载失败。登录方法见[不登录看Twitch直播的安卓客户端.md](不登录看Twitch直播的安卓客户端.md)，装包流程见[装到手机上的完整步骤.md](装到手机上的完整步骤.md)。

三套社区表情在「设置 → Twitch 聊天室」里各有独立开关：

| 表情集 | 特点 |
| --- | --- |
| BetterTTV（BTTV） | 社区覆盖最广，大量频道自定义表情 |
| FrankerFaceZ（FFZ） | 频道自定义表情与徽章 |
| 7TV | 带动画表情 |

三套可以同时打开，互不冲突；全开后聊天首次加载会略慢，网络不好就只留常用的那套。表情由应用自身解析，不用装任何浏览器扩展——这点和桌面端靠扩展注入的做法完全不同。输入框里打一个 `:` 会弹出表情补全，不用背代码。

## 二、画质：按网络环境选，别迷信「自动」

进直播间轻点画面调出控制条，画质菜单里「自动」和一串具体档位并列。档位多少由主播推流时开的转码决定，小主播可能只有「源」一档，看不到想要的档位不是应用故障。

| 场景 | 建议 |
| --- | --- |
| 移动流量 | 手动锁 480p 或 720p，流量好控（480p 一小时约 450MB） |
| 家用 Wi-Fi | 想看细节选「源」，那是主播推出来的原始档 |
| 频繁缓冲 | 手动降一档，比「自动」来回跳更稳 |
| 只想听声音 | 选最低档，有纯音频档更好 |

遇到「昨天还好好的、今天所有频道都不行」，先别反复卸载重装：用浏览器开 Twitch 网页确认是不是平台侧或线路的问题，这类整体性故障往往等平台接口稳定或更新客户端即可。

## 三、锁屏与后台播放

锁屏继续播放依赖前台服务：开始播放后通知栏会出现一条播放控制条，锁屏断播、后台无声多数是这条通知被系统拦了，或者电池优化把应用限制住了——把 Twire 的电池策略设为「不受限制」、允许通知，锁屏播放才能稳定跑。

画中画有个前提：暂停状态下不会进小窗，先让画面在播再切后台。睡前听播用播放菜单里的「定时停止播放」，到点自动停，比让屏幕亮一整晚省电。

## 四、两个互不相同的「代理」

设置里有两处带「代理」字样的开关，别混淆：

- **图像代理**（设置 → 一般）：管封面与头像的加载，封面大面积灰掉时启用它通常能救回来；
- **流代理**（设置 → 播放器）：管直播视频流本身，直连播不动时才用。

两者各管一条通道，视频卡顿时调图像代理没有用，反过来也一样。
