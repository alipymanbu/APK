# AI 虚拟世界八大玩法一览

Cybox Life 把 AI 角色对话和模拟经营放进了同一座虚拟城市：八个板块共享同一套 NPC 与城市状态，板块之间能互相联动——你让角色去某座城市演出，转头就能在娱乐头条里看到它的新闻。本文把八个板块一次讲清，想看完整图文版与安卓安装文件资源，可移步 [cyboxlife 玩法专题站](https://cyboxlife.uerg.quest/)。

## 八个板块分别做什么

| 板块 | 你在里面做什么 |
| --- | --- |
| AI 角色对话 | 自定义角色背景与性格，在微信风格的界面里展开多轮剧情对话 |
| 虚拟陪伴养成 | 与角色建立恋人、朋友、陌生人等关系，随互动加深发现其另一面 |
| 宠物养成 | 领养 6 个品种的像素宠物，喂食、玩耍、洗澡三类日常互动 |
| 公司创业模拟 | 从初创团队做到上市企业，招聘员工、与 AI 谈判 |
| 选秀造星 | 赛季制选秀：报名、初舞台、公演、顺位淘汰，把素人捧成顶流 |
| 证券交易 | 在 AI 驱动的虚拟市场里看实时行情，做投资决策 |
| 世界探索 | 在 8 座城市地图上查看角色活动轨迹，找演出场馆与工作地点 |
| 娱乐头条 | 虚拟世界的新闻中心，AI 写出的头条与热搜榜追踪角色动态 |

## 为什么建议先聊再做别的

AI 角色有三套底层机制，决定了对话是这个世界的地基：

- **长期记忆**：角色记得聊过的内容和你的行为，情绪与态度随时间变化，不用每次从头建立关系；
- **独立社交圈**：每个角色有自己的好友关系和聊天记录，可以翻看其社交动态；
- **日程与轨迹**：角色的手机日程、位置轨迹、日记都能查看，配合城市地图能看到它「现在在哪、在干什么」。

理解这套机制之后，再开公司、选秀这类经营板块会顺很多——那些玩法的对手盘和员工都是这些 NPC。

## 上手顺序建议

1. 注册进入世界（邮箱注册，存档进云端）；
2. 建 1~2 个角色先聊几轮，确认记忆与性格在按设定走；
3. 领养一只宠物当日常挂机项（见 [像素宠物养成与点数消耗规则](像素宠物养成与点数消耗规则.md)）；
4. 再铺开公司或选秀的经营线；
5. 期间用头条和城市地图追踪角色动态。
