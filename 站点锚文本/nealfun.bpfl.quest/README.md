# nealfun 介绍站：一座装进口袋的脑洞游乐场

> 独立开发者 Neal Agarwal 从 2017 年起在自己的个人网站上陆续发布互动小游戏、数据可视化和各种实验项目，这个安卓合集把其中 35+ 个项目收进了手机——安装包只有 1.15M，列表是中文的，点开哪个玩哪个。这里把这些项目的来龙去脉捋一捋。
> **本目录文章**：[值得先玩的十个项目.md](值得先玩的十个项目.md) · [密码游戏35条规则通关思路.md](密码游戏35条规则通关思路.md)

## 这个合集里装的是什么

neal.fun 是 Neal Agarwal 的个人项目合集，横跨小游戏、模拟器与滚动式科普：四个元素无限合成的沙盒、规则层层加码的密码关、一路下潜到万米深海的长卷、把首富额度花光的购物清单……据第三方资料，其中出圈的几款被各大媒体报道过、合计被玩过千万次级别。

安卓上的 nealfun 应用是这些内容在手机端的入口：主界面是中文的项目列表，点进任何一个项目才真正加载内容（内容来自网页，联网是前提）。项目内部保留网页原样、基本是英文，但多数项目看图标、拖元素、点数字就能玩。

想直接在手机上翻这座游乐场，可以去 [nealfun 口袋游乐场介绍站](https://nealfun.bpfl.quest/) 看项目精选与上手说明，再从那边拿到安装文件资源的获取入口。
