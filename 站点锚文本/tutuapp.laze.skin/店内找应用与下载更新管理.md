# 店内找应用与下载更新管理

> 本篇讲 tutuapp 装好之后的事：怎么在店里搜到想要的应用、下载任务卡住怎么排查、已装应用怎么更新、想退回旧版怎么办。

## 一、找应用的三条路

还没有明确目标时，从首页往下翻：精选流 → 热门榜单 → 分类。分类层效率最高，很多国内市场上没有的海外内容，按分类翻反而更容易撞见。

有明确目标时用顶部搜索框，库里很多条目用的是原始外文名，搜不到依次试：

1. **换原始外文名**：中文译名搜不到的，用条目的原始外文名（通常就是英文名）再搜一次；
2. **缩短关键词**：长名字截取开头几个字符，命中率比完整输入更高；
3. **搜包名片段**：重名太多时，用包名里特征明显的一段搜，能绕开一堆同名条目。

点进详情页后先看四行再下载：版本号、体积、更新时间、截图与介绍——名字相近的条目就靠这些区分。完整的界面布局与截图对照，在 [tutuapp 商店导览站](https://tutuapp.laze.skin/) 里有整页展示。

## 二、下载任务卡住的排查顺序

1. **存储权限**：首次下载被拒的话任务会一直停在队列里，去「设置 → 应用 → TutuApp → 权限」把存储权限打开再重试；
2. **网络**：换 Wi-Fi / 流量各试一次，大包务必 Wi-Fi（流量下大包中途切换基站容易断）；挂了代理的先断开再试；
3. **空间**：目标应用比商店本体大得多，空间见底的手机会下到一半失败；
4. **重试与重下**：失败任务先点重试，反复失败就删掉任务重新发起。进度停在 99% 先等两三分钟——那是下载完成后的安装处理，看起来像卡住。

## 三、更新与历史版本

通过 tutuapp 装出去的应用不会出现在系统市场的更新列表里，更新提醒只来自商店本身。已装应用有新版时商店会给更新入口，部分版本支持一键批量更新；更新前看一眼版本号与更新时间，同一应用在店里可能同时挂着多个版本条目。更新列表不刷新就下拉刷新，再不行清一次商店缓存重进。

当前版本出问题（新版闪退、改版不适应）时，部分条目在详情页保留「历史版本」入口，可以往回退：先卸载当前版本，再从历史版本列表里选目标版本重新下载安装。卸载会带走应用数据，有本地数据要留的先备份。

## 四、换机或重装前

商店不提供账号体系（游客身份），换机等于重新找一遍应用，所以换机前把「装过哪些」记一下是值得的。需要保留的安装包从手机下载目录拷出来；商店本体没了就重新取一份，入口在 [安卓版下载安装步骤与常见拦路问题](安卓版下载安装步骤与常见拦路问题.md) 里，收录与定位的背景见 [是什么商店与收录构成](是什么商店与收录构成.md)。
