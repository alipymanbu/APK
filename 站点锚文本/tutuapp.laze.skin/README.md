# tutuapp 商店导览（站点锚文本目录）

这里是 tutuapp（TutuApp，中文名兔兔助手）的第三方介绍与使用说明合集：tutuapp 是一款面向安卓的第三方应用商店，以 APK 安装包直装分发，收录游戏与应用两大板块，条目里带大量 MOD 版与海外内容，免 Root、免注册，游客身份即可浏览，界面支持多语言。
