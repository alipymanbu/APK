# 扫不到歌与后台被杀排查：Pulsar 高频故障处理

> 新歌扫不出来、播放几分钟自动停、投屏中途断开——这三类是本地播放器被反馈最多的问题，多数不需要重装，按下面的顺序排查即可。
> 相关阅读：[歌词显示与标签整理.md](歌词显示与标签整理.md) · [均衡器与音效怎么调.md](均衡器与音效怎么调.md)

还装着应用的话，先到 [Pulsar 安卓版介绍站](https://pulsar.djnf.quest/)确认手里的版本与安装步骤，排查动作都要在正确安装的前提下做。

## 一、新歌或整批音乐扫不出来

按顺序做三件事：

1. **手动重扫**：工具栏点「重新扫描媒体库」，可以切到后台挂着慢慢扫。注意扫描只负责发现新增文件，不会更新已有歌曲的信息——改了标签不显示，也是重扫无用的原因之一。
2. **确认格式受支持**：Pulsar 的播放能力跟随安卓系统本身，某些 ape、dsf 等小众格式系统不支持就放不了，这不是播放器的锅。
3. **重建系统媒体库**：曲库条目重复、信息张冠李戴时值得试——设置 → 应用 → 右上角三点 → 显示系统应用，找到「媒体存储（Media Storage）」清除数据，重启手机等几分钟重建，再回 Pulsar 重扫。这步不动音乐文件本身。

扫出来一堆铃声、通话录音？不用删文件，把所在目录加入排除列表，做法见 [歌词显示与标签整理.md](歌词显示与标签整理.md) 第三节末尾。

## 二、播放几分钟自动停

最常见根源是系统电池优化杀后台。三步处理：

1. 系统设置 → 电池 → 电池优化，找到 Pulsar 选「不允许优化」；
2. 机型没有这一项时：设置 → 应用 → Pulsar → 电池，改成「不受限制」；
3. 设置 → 应用 → Pulsar → 通知，打开「显示通知」和「媒体播放」。

省电策略激进的国产定制系统可能还要把 Pulsar 加入后台白名单、锁定后台，路径因机型而异，方向一致：别让系统杀它。

## 三、投屏与车载不稳

| 现象 | 处理 |
| --- | --- |
| 找不到投屏设备 | 手机与投屏设备必须在同一 Wi-Fi，且手机用的是 Wi-Fi 而非蜂窝网络 |
| 投几分钟就断 | 设置 → Wi-Fi → 高级 → 休眠时保持 Wi-Fi 连接 → 选「始终」 |
| 反复中断 | 投屏期间保持手机屏幕常亮 |
| 车机不显示 | Android Auto 应用 → 「自定义启动器」里确认 Pulsar 已勾选，电池同样设为不受限 |

曲库特别大时老版本在车机上加载会报错，把 Pulsar 升级到较新的版本再连能避开一批已知问题。

## 四、随机播放停不下来

直接点列表里的第一首歌就是顺序播放，悬浮的大圆随机按钮才是乱序入口。点了单曲仍进随机模式，到设置的播放选项里关掉「保持随机播放模式」即可。

## 五、以上都无效时

先确认安装包完整：安装中断、下载不完整会带来各种诡异行为，重新走一遍安装流程（入口见 [Pulsar 安卓版介绍站](https://pulsar.djnf.quest/)）往往比反复调试省时间。日常想少遇到这类问题，可以把 [均衡器与音效怎么调.md](均衡器与音效怎么调.md) 里的播放引擎切换记下来——多数卡顿换引擎就能解决。
