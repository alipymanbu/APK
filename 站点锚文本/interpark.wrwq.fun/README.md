## 一句话背景

interpark 是韩国老牌演出票务平台（1998 年起家，现属 NOL 体系），演唱会、音乐剧、体育与展览的门票都在这里开售；海外观众走国际版，邮箱注册加外卡支付就能买票。

所有文章均为第三方整理的观演信息，票务规则以购票页面实时显示为准。
