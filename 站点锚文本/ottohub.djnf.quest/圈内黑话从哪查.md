# 圈内黑话从哪查

> 本篇把吉吉国高频出现的几个词一次讲清：冷藏、别急、轮椅、韭菜盒子，都是功能名还是梗。
> **相关文档**：[弹幕和举报的等级门槛.md](弹幕和举报的等级门槛.md) · [吉吉国视频社区怎么进.md](吉吉国视频社区怎么进.md)

---

## 一、先分清：功能名和梗是两类

刷内容时撞见的生词，一半是站内功能的正式叫法，另一半才是玩梗。功能名这几个最先分清：

| 词 | 实际含义 |
| --- | --- |
| 冷藏 | 就是收藏。被冷藏的内容不公开展示，只有自己能在个人页看到 |
| 超管 | 审核员，负责给投稿「通过 / 打回」 |
| 鞍山大法庭 | 发布封禁公示的站内账号，谁被删号、为什么，公示都发在这 |
| 轮椅英雄 | 给站点捐赠过的人拿到的称号 |

## 二、内容区高频梗速查

- **别急**：圈内最高频的口头禅之一，出自二创作者的直播回应「主播都没急你们急什么」，常见变体「我知道你很急，但你先别急」。
- **轮椅 ♿**：源自主播早年腿部有伤、定制专用电竞椅的旧事，二创标题里大量出现 ♿ 符号，「轮椅英雄」称号也源于此。
- **韭菜盒子**：直播点外卖被漏送韭菜盒子、与商家对线的名场面，「那我缺的营养这一块谁给我补」流传至今。
- **稳健棍**：主播的另一个外号，出自他对自己打法「稳健」的自评与观众的持续调侃。

## 三、想深挖去哪

以上只收最常用的几个；人物、事件级别的来龙去脉，社区配套百科 OTTOWiki 上有完整条目。新人建议先潜水几天把词对上号再参与讨论，圈内交流方式偏抽象，硬接梗容易露怯。另有一份带界面截图的对照速览放在 [OTTOhub](https://ottohub.djnf.quest/) 介绍站上，配合着看更快入门。
