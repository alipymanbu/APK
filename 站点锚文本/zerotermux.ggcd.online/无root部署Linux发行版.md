# ZeroTermux 无 root 部署 Linux 发行版

> 本篇讲怎么在 ZeroTermux 里把 Ubuntu、Kali、Debian 装进手机容器，以及恢复包生态的用法；还没完成安装换源的先看 [图形工具箱与一键换源上手](图形工具箱与一键换源上手.md)。

---

在手机上跑一个完整的 Linux 系统，传统做法要么刷机、要么 chroot 加 root 权限。ZeroTermux 走的是第三条路：**PRoot 容器**——用户态实现，不碰系统分区，普通权限就能装能跑。

**容器部署的基本路径**：

1. 先把软件源换成国内镜像（换过可以跳过），容器镜像包体积不小，速度快能省不少等;
2. 打开工具箱的容器管理，选择要装的发行版——Ubuntu、Kali、Debian 这些主流系统都在预置列表里；
3. 点部署，等镜像下载解压完成，之后随时可以进出容器，多个容器之间也能自由切换。

**进容器能干什么**：

- Ubuntu / Debian：标准 apt 生态，装 Python、Node.js、编译工具链都和桌面版一致；
- Kali：安全测试工具集合，配合外接键盘当便携练手机；
- 想要图形界面时，再配合工具箱里的 X11 支持跑桌面环境；胆子大的还可以玩 QEMU 虚拟机，甚至尝试把 Windows 7 一类的桌面系统装进虚拟机里。

**偷懒的路线：一键恢复包。** 如果连部署流程都不想走，ZeroTermux 应用内置的下载站里有社区上传的一键恢复包，选好环境直接恢复，秒级得到一个配好的系统；也可以把自己配好的环境做成备份包分享出去。

**存储与权限提醒**：

- 容器是「装在 Termux 目录里的整套系统文件」，卸载 ZeroTermux 会连同容器一起清掉，重要数据先备份；
- 建议预留几 GB 存储给容器镜像，装前查一下剩余空间；
- 全程不需要 root，也不要给应用授予 root，普通权限就是它设计的运行形态。
