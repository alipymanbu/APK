# ZeroTermux 图形工具箱与一键换源上手

> 本篇按第一次打开 ZeroTermux 的顺序，把双指单击、侧滑菜单、一键换源这几步讲清楚；背景知识见 [与 Termux 区别和怎么选](与Termux区别与怎么选.md)。

---

装好 ZeroTermux、首次启动同意协议并授予存储权限之后，先别急着敲命令，它真正的便利都在面板里。

**第一步：调出工具箱。** 首屏会有引导提示——**双指单击屏幕**即可打开图形工具箱；屏幕左侧向内滑是菜单（含内置文件浏览器），右侧向内滑是常用工具区。三组手势对应三个入口，记住"双指 = 工具箱"这一条就够起步了。

**第二步：一键换源（强烈建议最先做）。** 在工具箱里点「一键更换软件源」，面板里直接列出了清华、北京等国内镜像，选中即生效，全程不用碰 `sources.list`，也不用跑 `termux-change-repo` 的字符界面。换完之后 `pkg install` 的速度会从几十 KB/s 上到正常宽带水平，这是国内网络环境下最立竿见影的一步。

**第三步：认识工具箱里的常客。**

- **备份 / 恢复**：把当前环境整体打包，折腾坏了随时回滚；换手机时还能跨设备还原。
- **定时执行**：把重复动作（定时备份、定时更新）交给计划任务，不用配置 crontab。
- **优化设置**：字体、配色、提示样式在这里调，还有一批社区在线脚本可选装。
- **文件管理**：图形化浏览 Termux 目录，支持在指定目录克隆仓库、wget 下载。

**几点提醒**：

- 自定义源有风险时先做一次备份再动手，出问题可以整包还原；
- 想把命令学回来也不冲突——面板背后还是标准 Linux 工具链，终端随时可用；
- 界面截图与版本信息（0.119.1 / 约 107 MB / Arm64 Android 7.0+）可以在 [ZeroTermux 介绍站](https://zerotermux.ggcd.online/) 对照着看。

工具箱顺手之后，下一步就是给它装一个完整的 Linux 桌面环境，见 [无 root 部署 Linux 发行版](无root部署Linux发行版.md)。
