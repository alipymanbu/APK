# ZeroTermux 与 Termux 的区别和怎么选

> 本篇说清 ZeroTermux 和 Termux 的渊源、差异点，以及什么情况下选哪个更顺手；上手后再看 [图形工具箱与一键换源上手](图形工具箱与一键换源上手.md)。

---

很多第一次找安卓终端工具的人都会在这两个名字之间犯迷糊：名字几乎一样，打开后的主界面也几乎一样——这是有原因的。

**渊源**：ZeroTermux 是在 Termux 基础上二次开发的开源分支（fork），项目页里写着"站在 Termux 的肩膀上，向其致敬"。它没有另起炉灶重写终端，而是在原版的底子上加了一层图形化能力，并把界面默认做成简体中文。

**实际差异主要在四处**：

| 对比点 | Termux 原版 | ZeroTermux |
| --- | --- | --- |
| 界面语言 | 英文为主 | 默认简体中文 |
| 软件源 | 默认境外源，换源要自己跑 `termux-change-repo` | 内置清华、北京等国内镜像，面板点选即换 |
| 高频操作 | 全靠命令行（换源 / 备份 / 定时任务 / 装发行版） | 侧滑工具箱逐项图形化 |
| 附加能力 | X11、QEMU 需自己配置 | 原生集成管理面板 |

**怎么选**：

- 想学 Linux 命令本身、追求原汁原味、习惯英文界面——原版 Termux 够用，生态也最正统；
- 设备在国内网络环境、不想一开始就卡在换源和报错上、希望备份恢复和装发行版点点手指就完成——ZeroTermux 的图形面板省时间，入门曲线平缓很多；
- 两者包名相同（com.termux），**不要同时装在一只手机上**，会互相顶替。

一句话概括：ZeroTermux 不是替代品，而是给 Termux 补了一层"国内网络 + 图形化"的现成答案。想先看看它整体长什么样，可以到 [ZeroTermux 图形终端介绍站](https://zerotermux.ggcd.online/) 逛一圈，里面有界面截图和版本信息。
