# Kali Linux 学习路线与入门命令

> 一条可执行的四步路线，外加新手最先混眼熟的高频命令与报错初判。
> **相关文档**：[新手入门先弄懂的三件事](新手入门先弄懂的三件事.md) · [安卓手机上能学到什么](安卓手机上能学到什么.md)

## 一、四步路线

1. **读基础章**：搞清 Kali 是 Debian 系发行版、终端与桌面的关系。这一步在手机上读教程即可，通勤、排队的时间都够用。
2. **过命令章**：高频命令先混个眼熟，不求背下，见过后面就不慌。
3. **按需挑工具章**：网络类、漏洞分析类按兴趣跳读，不必从头通读。
4. **配图放到电脑练**：教程配图多是电脑桌面的截图，读懂步骤后，在自己搭建的虚拟机练习环境里照着敲一遍。每章读完用三条判据自测：能复述工具解决什么问题、能敲通一条核心命令、报错时能读出原因层次。

## 二、最先混眼熟的几条命令

```text
ls        # 列出当前目录内容
cd        # 切换目录
cat       # 查看文件内容
sudo      # 以管理员权限执行
apt update && apt full-upgrade -y   # 更新系统与软件包
```

这几条在教程的工具章里会反复出现，先在练习环境里把它们敲通，后面读任何一章都不会卡在「命令怎么输」这一层。

## 三、报错先分三层

照着敲命令，最常见的三类报错各有各的原因：

- **command not found**：命令没装或敲错了。先核对拼写，再用包管理器搜索安装对应的包；
- **Permission denied**：权限不够。系统目录相关的操作前面加 `sudo`；输入密码时屏幕不会显示任何字符，输完直接回车；
- **解析失败 / 404**：网络或软件源的问题。先测网络连通，再刷新包索引重试。

分不清层次时，把报错最后一行原样复制去搜索，通常直接命中原因。练习始终放在自己的设备与自己搭建的环境里，这条边界与 [新手入门先弄懂的三件事](新手入门先弄懂的三件事.md) 里说的一致。
