# Kali Linux 新手入门先弄懂的三件事

> 打算在手机上认识 Kali Linux 之前，先把三件事想明白：它是什么、学了能干什么、边界在哪里。
> **相关文档**：[安卓手机上能学到什么](安卓手机上能学到什么.md) · [学习路线与入门命令](学习路线与入门命令.md)

## 一、先分清「教程」和「系统」

很多新手的第一个误会：以为手机上装一个 Kali 相关的应用，手机就变成了 Kali 系统。实际上，安卓平台上的 Learn Kali Linux 是一款**图文教程应用**——18M 出头的体积里装的是分章讲解的概念、命令与工具介绍，它本身不带系统、没有终端，也不能运行任何安全工具。

真正的 Kali Linux 是基于 Debian 的发行版，预装了六百多个安全测试工具，通常装在电脑或虚拟机里；想在安卓手机上真跑这些工具，Kali 项目方面向安卓的方案叫 NetHunter。三者的位置摆对了，后面每一步才不会走歪。

## 二、入门阶段真正能拿到的东西

从教程里能带走的是「认知」：Kali 是什么、终端和桌面是什么关系、ls 与 cd 这些高频命令长什么样、漏洞分析类的工具各自解决什么问题。这些内容读起来不需要联网，也不需要 Root，通勤路上翻几章正合适。

但「认得」和「会用」之间隔着动手练习——教程里的配图多是电脑桌面的截图，读懂步骤后，需要在自己搭建的练习环境里照着敲一遍才算数。具体怎么安排，见 [学习路线与入门命令](学习路线与入门命令.md)。

## 三、边界比工具更重要

安全工具只应该出现在自己的设备与自己搭建的环境里：自己的虚拟机、自己架的靶场。对不属于己的系统与网络使用这些工具，超出学习范畴，也不被允许——这条边界不随工具换到手机上而改变。

想先看看这款教程应用本身的内容结构与获取方式，可以到 [kali linux 安卓图文教程站](https://kali-linux.wrwq.fun/) 了解；手机端能学到什么程度，见 [安卓手机上能学到什么](安卓手机上能学到什么.md)。
