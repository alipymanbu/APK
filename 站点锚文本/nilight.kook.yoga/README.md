# Nilight 控灯应用介绍（nilight.kook.yoga）

这里是 [Nilight](https://nilight.kook.yoga/) 控灯应用的介绍站——Nilight 是配套 Nilight 蓝牙控款车灯使用的安卓应用，扫描连接岩石灯、底盘灯条、鞭灯、内饰灯条后，可以在手机上完成调色、亮度、音乐随动、模式设定与定时分组。站点按「连上 → 调色 → 随动 → 存模式」的控灯顺序整理了功能说明与安装文件资源获取入口。
