# 手机动态壁纸怎么和电脑配对传输

> 讲 Wallpaper Engine 手机端与电脑端的配对连接方法：PIN 在哪生成、手机怎么发起连接、传输出问题先查什么。
> **相关文档**：[创意工坊壁纸怎么弄到手机上.md](创意工坊壁纸怎么弄到手机上.md) · [动态壁纸费电吗省电设置.md](动态壁纸费电吗省电设置.md)

---

## 一、先满足两个前提

配对走的是局域网直传，开工前确认两件事：

| 前提 | 说明 |
| --- | --- |
| 电脑端已装 Wallpaper Engine | Windows 版本体，且正在运行；手机传壁纸靠它 |
| 手机与电脑在同一网络 | 连同一个路由器的 Wi-Fi 最稳；区分"访客网络"或开了 AP 隔离的路由器可能互相搜不到 |

手机端的应用本体是免费的伴侣应用，需要 Android 10 及以上系统，还没装的话可以先看[壁纸引擎手机版介绍站](https://wallpaperengine.yoan.quest/)了解装法与入口。

## 二、四步完成配对

1. **电脑端生成 PIN**：打开 Windows 版 Wallpaper Engine，点界面右上角的"移动设备"按钮，选"连接新设备"，窗口会显示一个 4 位 PIN 码。
2. **手机端发起连接**：打开手机应用，点"与计算机配对"。
3. **选中你的电脑**：应用会在局域网里搜索正在运行的 Wallpaper Engine，几秒后电脑名称出现在列表里，点它。
4. **输入 4 位 PIN**：输完回车，手机应用顶部状态栏变绿、显示"已连接"，配对即完成。

连上之后，电脑里已经订阅的壁纸合集会无线同步到手机，之后在手机上像换本地壁纸一样切换。

## 三、连不上时按顺序排查

- **搜不到电脑**：先看电脑端 Wallpaper Engine 是否开着（最小化到托盘也算运行）；再确认两端是否真的在同一网段，公网 Wi-Fi 下的机顶盒热点、访客网络经常是坑。
- **搜到了但连不上**：回电脑端重新生成一次 PIN 再试，PIN 每次连接都会刷新，不要用记在纸上的旧码。
- **传一半中断**：大体积视频壁纸传输时间偏长，保持两端别锁屏休眠；不行就先传一张小壁纸验证链路。
- **实在配不上**：退而求其次走"备份方案"——在电脑端把壁纸导出成视频文件，发到手机后用"导入文件"入口加载，效果打折但能用。

## 四、配对成功后能做什么

- 壁纸合集自动出现在手机应用的库列表里，点选即用；
- 可以建播放列表让多张壁纸轮换；
- 想控制耗电，去设置页调帧率与省电策略，具体见[动态壁纸费电吗省电设置](动态壁纸费电吗省电设置.md)；
- 工坊里还没订阅的内容，先在电脑端订阅再传，原因见[创意工坊壁纸怎么弄到手机上](创意工坊壁纸怎么弄到手机上.md)。
