# 创意工坊壁纸怎么弄到手机上

> 解释为什么手机应用里搜不到创意工坊内容，以及把工坊壁纸搬到安卓手机的两条可行路径。
> **相关文档**：[手机动态壁纸怎么和电脑配对传输.md](手机动态壁纸怎么和电脑配对传输.md) · [动态壁纸费电吗省电设置.md](动态壁纸费电吗省电设置.md)

---

## 一、先说清原因：不是没装对，是链路就不通

不少人在手机上装好 Wallpaper Engine 后，翻遍菜单也找不到工坊入口。这不是安装出了问题：受技术与授权两方面的限制，安卓端无法直接连接 Steam 创意工坊，工坊里的社区壁纸绑定在电脑版的订阅体系里。所以"手机直接搜壁纸下壁纸"这条路本来就不存在，得换条路走。

想先把应用装上，可以去[壁纸引擎手机版介绍站](https://wallpaperengine.yoan.quest/)看安装文件资源的获取方式。

## 二、路线一：电脑订阅，配对无线传（正路）

这是保留完整玩法的方式：

1. 电脑上打开 Windows 版 Wallpaper Engine，在创意工坊里浏览、订阅想要的壁纸；
2. 按"移动设备 → 连接新设备"生成 4 位 PIN；
3. 手机端点"与计算机配对"，连上同一 Wi-Fi 后选中电脑、输入 PIN；
4. 状态栏变绿即完成，订阅好的合集随后无线同步进手机。

之后电脑里新增订阅，手机端同步也跟得上，手机始终是电脑壁纸库的"随身镜像"。配对细节卡住了看[手机动态壁纸怎么和电脑配对传输](手机动态壁纸怎么和电脑配对传输.md)。

## 三、路线二：本地导入，绕开订阅

手头没有电脑版、或者只想要某一张特定的动态图，可以直接导入本地文件：

1. 把视频、GIF 或导出的壁纸文件放进手机存储（文件传输、聊天工具发给自己都行）；
2. 打开手机应用，点主界面的"导入文件"；
3. 选中文件，它就会作为动态壁纸出现在库里。

这条路线拿不到工坊里那些带交互参数的完整作品（可调色的部分会变成固定画面），但零依赖、随时可用，临时体验足够。

## 四、两条路线怎么选

| 情况 | 选择 |
| --- | --- |
| 已有 Windows 版，想长期玩 | 路线一，配对一次长期同步 |
| 没有电脑版，只想先试试 | 路线二，导入几张本地动图先跑起来 |
| 只想给手机省点电地挂着壁纸 | 先看[动态壁纸费电吗省电设置](动态壁纸费电吗省电设置.md)再决定装不装 |
