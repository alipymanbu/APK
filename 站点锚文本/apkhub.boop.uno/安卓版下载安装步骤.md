# apkhub 安卓版下载安装步骤

> 本篇讲怎么把 apkhub 装到安卓手机上：从夸克网盘转存安装文件、传到手机、授权「安装未知应用」，到装完打开，四步走完。装的过程中被系统拦下来，按第三节的办法处理。
> **相关文档**：[打不开与闪退处理.md](打不开与闪退处理.md) · [五大栏目与社区玩法.md](五大栏目与社区玩法.md)

---

## 一、先拿到安装文件

apkhub 不在系统自带的应用商店里分发，安装包走网盘渠道：打开 [apkhub 资料站](https://apkhub.boop.uno/)，首页和下载页的「获取安装文件资源」按钮会带你去夸克网盘的分享页。

到网盘分享页后，先把 `apkhub_v4.1.2.apk`（约 29.4 MB）**转存到自己的网盘账号**——转存之后这份文件就在自己账号里了，后面随时能重新下载，不怕原分享失效。

## 二、装到手机上的四步

1. **下载 APK**：手机端在夸克 App 里直接下载刚转存的文件；电脑端下载后，用数据线或局域网共享把 APK 传到手机存储。
2. **点开 APK**：在手机的文件管理器里找到 `apkhub_v4.1.2.apk`，点它。首次安装会弹出「禁止安装未知应用」的提示，进入下一步。
3. **授权「安装未知应用」**：按提示去 `设置 → 应用 → 特殊权限 → 安装未知应用`，把开关开给**用来打开 APK 的那个应用**（夸克、浏览器或文件管理器）。注意这个授权是按应用给的——开给夸克后，从夸克里点开文件才有效。小米、华为、OPPO、vivo 的菜单路径略有差异，在设置里搜「安装未知」最快。
4. **完成安装并打开**：回到文件位置再点一次 APK → 安装 → 打开。第一次启动会看到「全球 APK 下载分享社区」的启动页，进去就是五大栏目的首页。

装完想确认版本：`设置 → 应用` 里找到 apkhub，应显示 4.1.2；系统要求 Android 5.2 及以上，老系统装新版会直接闪退。

## 三、安装被拦、点不动怎么办

- **点安装没反应**：九成是授权给错了对象——「允许安装未知应用」要开给正在打开文件的那个应用，不是开给 apkhub 自己。重新核对第 3 步。
- **提示解析失败**：多半是包不完整（下载中断过）。回网盘重新下载一份再装。
- **想确认文件是不是原样**：在电脑上对 APK 算一次 MD5，与 `6CD9B75E62D8AF58D589ADEEE21FBE2D` 比对，一致即文件完整。
- **装好了但打不开**：按 [打不开与闪退处理.md](打不开与闪退处理.md) 的顺序排查。
