## 一、首页五条动线

apkhub 的首页把内容拆成五个栏目，找东西各走各的路：

| 栏目 | 适合什么时候用 |
| --- | --- |
| 推荐 | 没有目标随便逛，混排编辑挑选与热门内容 |
| 新游 | 想尝鲜——已上线和即将上线的分开列 |
| 排行 | 想跟风——按热门、总下载、下载时间几个口径排 |
| 分类 | 目标明确——工具、社交、娱乐这类大类里翻 |
| 专辑 | 选择困难——别人整理好的成套主题合集 |

顶部搜索框带实时热搜，词会跟着全站热度更新，想不起应用全名时顺着热搜找往往更快。

## 二、榜单与地区切换

商店页顶部可以**切换地区**，推荐、预约、下载榜、收入榜几个分栏跟着地区一起换。下载榜反映的是真实安装热度，跟着排行动手比看宣传靠谱；想找海外应用、独立游戏或冷门应用时，多换几个地区翻榜单，命中率比死磕搜索高。

## 三、预约上新与更新提醒

这是 apkhub 和普通安装包站点拉开差距的两件事：

- **预约下载**：还没上线的游戏先点预约，连上 WiFi 后自动开下，不耗流量也不用蹲点守着；
- **更新提醒**：装过的应用出了新版本会及时提醒，不用隔三差五挨个翻；
- **集中管理**：更新、卸载、打开收在一处，下载任务支持断点续传，网不稳也能接着下。

## 四、广场社区

底部标签栏的「广场」是社区入口：发帖聊使用体验、逛别人整理的专辑；个人中心里有关注、粉丝这些社交关系，下载过的应用会归进「本地」，也能上传分享给社区。想参与这些只需要一个邮箱——「个人中心 → 去绑定」，邮箱加验证码就完成了。

更多玩法细节和在线入口见 [apkhub 资料站](https://apkhub.boop.uno/)。
