# Noteshelf 使用短文收录页

> 围绕安卓手写笔记应用 Noteshelf 的几篇短文：写过的字怎么搜回来、录音怎么贴着笔记记、以及它适合什么人。功能介绍与安卓版安装文件资源的获取入口，见 [Noteshelf 安卓版手写笔记介绍](https://noteshelf.fewa.skin/)。

## 目录

- [手写笔记怎么搜索和转文字.md](手写笔记怎么搜索和转文字.md) —— 开启识别、按关键词定位页面、把手写整段转成文本。
- [上课录音和笔记怎么对上.md](上课录音和笔记怎么对上.md) —— 边写边录、按页回放，课后复盘不用拖进度条。
- [适合什么样的人用.md](适合什么样的人用.md) —— 从课堂、手账、PDF 批注三类场景判断它是否合手。
