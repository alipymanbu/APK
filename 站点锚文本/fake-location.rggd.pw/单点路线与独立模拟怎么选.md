# 单点路线与独立模拟怎么选

授权配好之后，Fake Location 的侧边栏里并排摆着好几个入口：位置模拟、路线模拟、WIFI 模拟、独立模拟。它们不是重复功能，而是各管一层——这篇按真实使用场景把它们拆开，帮你对号入座。

相关文档：[模拟位置授权设置全流程](模拟位置授权设置全流程.md)、[启动转圈与位置跳回排查笔记](启动转圈与位置跳回排查笔记.md)

---

## 单点位置模拟：把定位钉在一个坐标上

最基础也最常用的模式。地图上搜索地名、点选位置或直接输入坐标，确认后启动模拟，设备上报的位置就固定在那个点上。

适合的场景：

- 社交应用里分享一个不在当前位置的地点；
- 测试一个只对特定城市生效的功能；
- 把定位固定在某个固定地点，一挂一整天。

历史位置会自动留存，常用的点可以快速调用，不用每次重新搜。

## 路线模拟：让位置「走」起来

单点是不动的，但有些应用会看轨迹的连续性——速度恒定、路线笔直反而露馅。路线模式沿多个路径点移动，速度可以按步行、骑行、驾车等档位调整，模拟出真实的移动节奏。

适合的场景：

- 运动轨迹类功能的测试；
- 需要位置随时间平滑变化、而不是瞬移的场合。

配合设置页里的「位置更新频率」调低间隔，轨迹会更顺滑。

## WIFI 模拟：补上位置之外的周边环境

有些应用不只看 GPS 坐标，还会核对周边的 WiFi 环境。WIFI 模拟可以把指定 WiFi 网络添加进环境信息里，与模拟位置配套使用。它的角色是「辅助」——单纯换坐标不够用时，把它加进组合里。

## 独立模拟：不同应用各在各的位置

默认情况下，虚拟位置对整机生效；独立模拟则可以给不同应用分配不同的虚拟位置，互不干扰。比如一个应用定位在 A 城、另一个定位在 B 城，同时成立。有多应用并行测试需求的用户，这个模式能省掉反复切换位置的时间。

## 怎么组合

一个简单的决策顺序：

1. 只需要固定位置 → **单点**；
2. 需要位置动起来 → **路线**；
3. 应用会核对 WiFi 环境 → 单点/路线 之外加 **WIFI 模拟**；
4. 多个应用要不同位置 → **独立模拟**。
