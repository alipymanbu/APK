# EasyClaw 和 OpenClaw 什么区别

> 搜「Claw」会同时撞上一堆名字相近的项目。本篇讲清 EasyClaw 与开源框架 OpenClaw 的关系，以及怎么认准你要装的那一个。
> **相关文档**：[安卓端安装与登录.md](安卓端安装与登录.md) · [手机怎么遥控电脑.md](手机怎么遥控电脑.md)

---

## 一、一句话说清两者关系

OpenClaw 是开源社区里的 AI 助手框架，能力强，但要自己部署、自己配置；EasyClaw 是在它基础上做的一键安装版本——把部署和配置都收进安装包，普通人装上就能用。可以理解成：OpenClaw 负责「能干」，EasyClaw 负责「人人会用」。

## 二、具体差别在哪

| | OpenClaw（开源框架） | EasyClaw（一键安装版） |
| --- | --- | --- |
| 获取方式 | 社区渠道自行获取部署 | 安装包直接装（安卓端入口见[EasyClaw 介绍站](https://easyclaw.fwen.ren/)） |
| 部署配置 | 自己找教程、配环境 | 开箱即用，无需部署 |
| API 密钥 | 需要自己准备 | 不需要 |
| 上手门槛 | 偏技术向，适合愿意折腾的人 | 一句话上手，无专业知识要求 |
| 控制入口 | 终端、桌面 | 手机端对话框，或飞书 / QQ / 企业微信 |

如果你愿意折腾、想完全自主定制，社区原版是条路；如果只想「手机上说句话，电脑把活干了」，一键安装版省掉的就是前面那几天的折腾。

## 三、「Claw」家族再大，认这两点就不会装错

搜「EasyClaw」时，结果里常混着其它「Claw」项目和同名应用，它们未必是同一个客户端。核对两点：

1. **安卓包名**：`com.cf.easyclaw`——装好后进「设置 → 应用 → 应用管理」能查到；
2. **开发者**：北京灵豹智能科技有限公司。

装混了最常见的后果是「登录后互相看不见」——两端账号体系对不上。装之前先把[安卓端安装与登录.md](安卓端安装与登录.md)里的核对步骤过一遍，装完要连电脑端的活，见[手机怎么遥控电脑.md](手机怎么遥控电脑.md)。
