# javdb 找片与播放技巧：搜索、画质、倍速与换源一次讲清

> 本篇讲 javdb 的日常使用：找片的两条路、播放页里最常用的画质 / 倍速 / 换源三项操作，以及追剧记录怎么留。

## 一、找片的两条路

javdb 是一款安卓端的移动观影应用，打开后进首页，找片按手头信息多少选路：

- **知道名字** → 顶部搜索框直接敲片名、演员名或关键词，一敲就出结果；同名内容多时，用年份、地区、类型对一遍再点。全名搜不到就换更短的词，去掉空格和标点，搜核心词命中率更高。
- **不知道看什么** → 沿着分类和榜单逐层逛：先挑栏目（推荐、电影、电视剧这类分区），再翻海报列表，感兴趣的点进详情页，剧集列表与播放按钮都在那一层。

详情页点某一集就进播放页，后面要讲的画质、倍速、换源入口都集中在播放页的控制条里——点一下画面就唤出。

## 二、画质切换：按网络选档

播放中点一下画面，控制条里找清晰度 / 画质入口：

1. Wi-Fi 稳定就往高了选，画质细节更足；
2. 走流量或信号一般就降一档，画面略糊但不卡，比卡成幻灯片强；
3. 切换会重新加载几秒，属正常现象。

具体有哪几档（流畅 / 高清之类）以界面实际显示为准，不同内容提供的档位也可能不同——某个档位点不亮，通常是这部片没挂那一档。

## 三、倍速播放：节奏自己定

控制条里找「倍速」，在 0.5~2.0 之间挑一档（档位以界面为准），选完立即生效，调回 1.0 恢复原速。倍速只影响本机的播放速度，不会改变内容本身。看节奏慢的剧想快点过剧情，2.0 档；想细看镜头就回到 1.0。

## 四、换源播放：对付卡顿黑屏的第一手段

一部片往往有多条播放线路（源），**这是这类应用对付「打不开、黑屏、一直转圈」最见效的一招**：

1. 播放页控制条或「···」菜单里找「源 / 线路 / 换源」入口；
2. 当前源播不动就换下一个，一般换一两个就能继续；
3. 判断技巧：同一部片不同集数表现不一样（有的能播有的不能），基本是源的问题，换源就是正解；整部片每条源都播不了，才轮到查网络和设备。

## 五、追剧与记录：进度都记在本机

- **观看记录**：看到第几集应用会记在本机，首页的历史入口翻到就接着看；
- **收藏 / 追剧**：详情页或播放页的收藏按钮把想追的存进「我的收藏」，更新了回来看；
- **离线缓存**：详情页若挂「缓存 / 下载」按钮，就能把片子存到本地没网时看；缓存占空间，到应用内的「缓存管理」里删才干净。

记录与收藏都存在本机：清缓存不影响它们；清「数据」或卸载重装会一并清掉，换机前把想续看的片名记下来。
