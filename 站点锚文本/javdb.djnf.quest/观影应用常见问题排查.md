# 观影应用常见问题排查：装不上、闪退、黑屏与记录丢失

> 本篇按症状分型：装不上、打不开 / 闪退、播放失败黑屏、记录丢失，每种给一套可执行的处理顺序。
> **相关文档**：[观影找片与播放技巧](观影找片与播放技巧.md) · [手机看电视直播与投屏的方法](手机看电视直播与投屏的方法.md)

---

## 一、装不上：按报错分型处理

javdb 属于侧载安装的安卓应用（不在应用商店上架），装不上时按报错文案对号入座：

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| 禁止安装来自此来源的应用 | 安卓标准安全拦截，不是文件问题 | 按提示进设置允许该来源，返回继续 |
| 解析包出问题 / 安装包损坏 | 包没下完整 | 回网盘重新下载，文件明显偏小就重下 |
| 应用未安装 | 空间不足或与旧版冲突 | 清出几百 MB 空间；装过旧版先卸载再装 |
| 安全扫描拦截（Play Protect 之类） | 侧载应用常被扫一道 | 包是自己转存来的，选「仍然安装」放行 |

安装包约 12.6 MB，下载后看大小是否接近，明显偏小说明没下完整。装机四步的完整流程在介绍页里有逐步说明：[javdb](https://javdb.djnf.quest/)。

## 二、打不开、闪退、白屏

按顺序试，走到哪步好了就停：

1. **重启应用**：上滑关掉再进，一次性进程卡死最常见；
2. **清缓存**：系统设置 → 应用 → javdb → 存储占用 → **只清缓存**（别清数据，记录不丢）；
3. **确认网络**：首页列表要联网加载，Wi-Fi 与流量互切试一次；
4. **查存储与内存**：剩余空间不足几百 MB、后台挂着一堆应用时，这类应用容易起不来；
5. **卸载重装**：以上都不行再走这步——卸载会清掉本机观看记录，介意就先记下片名。

新装就闪退、或系统刚升级后开始闪退的，多半是包与系统不兼容，重新拿一份覆盖装（同包名覆盖不丢记录）。

## 三、播放失败、黑屏、一直转圈

这类问题九成出在**源和网络**上，与设备无关：

1. **换源**：播放页找「源 / 线路」换一条，一部片的某条源挂了很常见，换一两个就能播；
2. **降画质**：清晰度切到低一档，先保证能播；
3. **验网络**：开个网页确认网是通的；只有某类内容播不了、网页都正常，说明是源的问题；
4. **清缓存**：还是只清缓存，不动数据；
5. **换时间段**：晚高峰热门内容拥堵，隔一阵再试。

直播整区没画面的，换线路那套见 [手机看电视直播与投屏的方法](手机看电视直播与投屏的方法.md) 第三节。

## 四、记录丢了、收藏不见了

观看记录与收藏存在**本机**，以下操作会清掉它们：清「数据」（不是清缓存）、卸载重装、恢复出厂。所以：

- 只想解决卡顿 / 闪退 → 清缓存就够，别点清数据；
- 必须卸载重装 → 先接受记录会没，重装后回应用里重新搜片即可。

换机也一样：记录不会跟着账号走，把想续看的片名记下来，新机装好后直接搜。

## 五、缓存与存储：清理的边界

- **清除缓存**：清临时文件与缩略图，什么都不丢，卡顿的第一选择；
- **清除数据**：缓存 + 设置 + 记录 + 收藏全没，只在应用彻底起不来时用；
- **离线缓存的片子**：到应用内的「缓存管理」里删才干净；应用私有目录里的分段文件别用文件管理器手删，手删容易让应用下次启动异常。
