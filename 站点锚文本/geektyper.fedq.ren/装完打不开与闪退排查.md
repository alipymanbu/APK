# 装完打不开与闪退排查

> GeekTyper 装完点图标没反应、打开就闪退、动画卡顿——三种症状三种病因。本篇按"先便宜后贵"的顺序给排查路径，每做一步就开一次应用试，多数在前两步就好。

## 一、先分清是哪一种"打不开"

| 症状 | 更可能的原因 |
| --- | --- |
| 点图标没任何反应 | 后台被系统清了、省电策略拦着，或包没装完整 |
| 打开就闪退回桌面 | 缓存数据异常，或与当前系统版本不兼容 |
| 能开但滚动卡顿 | 老机型图形负载吃紧，多窗口特效叠太多 |
| 提示"不兼容"装不上 | 系统版本低于要求（这一份标注 Android 5.2+） |

## 二、通用排查顺序

1. **重启应用**：最近任务里划掉，或「设置 → 应用 → 强制停止」再开。多数偶发无响应到这步就好了；
2. **清缓存**：长按图标 → 应用信息 → 存储 → **清除缓存**。这类小工具打不开的常见原因就是缓存异常；它不存任何进度，清数据也不亏；
3. **查后台与省电策略**：高频诱因是"它早被系统杀了"。应用信息 → 省电策略 → 选「允许后台运行」；录长视频前尤其做一遍；
4. **换网络试一次**：核心画面不联网，但个别页面资源请求失败会拖慢启动，Wi-Fi 与流量切一下排除变量；
5. **卸载重装**：前三步无效就重装一遍，重装零成本——没有账号体系。

五步之后仍打不开，换一台设备试一次即可确诊是不是与该机型安卓版本不合。

## 三、卡顿专项

代码滚动偶尔顿一下，先做减法：

- 关掉 Show Folders 与大特效窗口——多窗口叠加最吃性能；
- 清一遍后台腾内存；
- 换最素的黑底纯文字主题（CMD）对比：明显变顺就是图形负载问题，不是应用坏了；
- 还卡就接受——包只有 3.12MB，动画上限摆在那里。

## 四、什么时候该怀疑装错了

同时出现「版本对不上 + 界面跟教程完全不像」再核对：包名 `com.blumont.geektyper2`、版本 `1.0.1`。对不上就重新取一份安装包；对得上而主题列表跟网上说法不一样，只是口径差异（不同页面描述的版本与平台本来就不同步），换个主题就能继续用。
