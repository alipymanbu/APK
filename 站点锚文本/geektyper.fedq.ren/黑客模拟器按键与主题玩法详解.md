# 黑客模拟器按键与主题玩法详解

> 本篇讲 GeekTyper 进去之后到底按什么：让代码滚起来的几个键、弹窗特效藏在哪、文件夹系统怎么开，以及 CMD / SCP / Avira 这些主题从哪里切。看完就能上手演。

## 一、先过那道英文确认页

启动后第一屏是整页红色警告，底部一个 **I will use responsibly!** 按钮——点它就进代码界面。这不是登录、不收集任何东西，只是提醒一句"这是玩笑，别乱用"。

## 二、让屏幕滚起来的三个层次

**第一层：手动出码。** 进界面后在屏幕键盘上随便点字母键，每按一下铺一段预设代码，连按就是"狂敲"效果。字母和滚出的内容没有任何对应——按 A 出来的不是 A 的效果，按键只负责往屏幕上"放料"。

**第二层：自动滚码。** 点 **AUTO** 进入持续滚屏，画面立刻变成电影里的默认形态；再点同位置的 **STOP** 定格。录视频前先用这两键排练起停时机。

**第三层：剧情窗口。** 数字键弹出进度条、扫描、结果框这类"剧情窗"；**P** 键的红色警报窗持续闪烁，是全场最抢眼的效果；**TR** 切另一套成串大招；敲到一段的末尾按 **Enter** 或 **Alt**，弹出"拒绝访问 / 允许访问"给整场戏收个尾。

## 三、文件夹系统与画面控制

- 开 **Show Folders** 后右上角多出一排文件夹，还能展开子文件夹，点进去触发不同弹窗——画面从"一整屏代码"升级成"多窗口作业现场"，截静态图时信息密度立刻上来；
- 右下角 **min** 收起键盘得到纯画面，同位置的 **+** 号唤回；
- **Reset Input** 把滚过的一切清空归零，上一段演砸了不用退出重进；
- 按 **TAB** 看当前主题的热键提示——某个键没反应先看它，有的主题没开某些特效，换个主题再试。

## 四、主题从哪里切、差在哪

入口只有主界面右上角的**三横图标**，点开选风格即时切换，按键逻辑不变。被提起最多的三套：

| 主题 | 观感 | 一句话点评 |
| --- | --- | --- |
| CMD | 黑底白字命令行 | 最素的一套，也是唯一不带 logo 的主题 |
| SCP | 绿色荧光终端 | 仿基金会机密界面，"越权查看"氛围拉满 |
| Avira | 红色系扫描 | 配警报窗最出戏，像系统正在被攻破 |

设置菜单里还能调字体（资料称五种）与界面、按钮颜色；调坏了换一次主题即恢复默认配色。至于"一共几套主题"，网上从"六种"到"二十七种"说法都有——以装完后菜单里实际列出的为准，数量对不上不代表装错。
