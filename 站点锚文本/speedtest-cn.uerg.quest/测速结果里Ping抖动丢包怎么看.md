# 测速结果里Ping抖动丢包怎么看

测速跑完，大多数人只盯着那个最大的速度数字，Ping、抖动、丢包三个小数被直接划走。可当「网速很快但打电话一顿一顿」「游戏延迟忽高忽低」这类问题出现时，答案恰恰藏在这三个小数里。这一篇把它们逐个说清。

相关文章：[测速前的准备清单](测速前的准备清单.md) · [千兆宽带测不出千兆的原因](千兆宽带测不出千兆的原因.md)

## 一、三个数各在回答什么问题

| 指标 | 单位 | 回答的问题 |
| --- | --- | --- |
| Ping | ms | 一来一回要多久，越低越「跟手」 |
| 抖动 | ms | Ping 稳不稳，波动大不大 |
| 丢包 | % | 发出去的数据有多少没到 |

速度数字回答「快不快」，这三个数回答「稳不稳」。刷视频只需要快，而视频通话、网游、实时语音对「稳」更敏感——这就不难解释为什么有人下载飞起、通话却一卡一卡。

## 二、Ping 为什么要测三次

常见的测速流程里，Ping 会在三个阶段各取一次：空闲时、满速下载中、满速上传中。

- **空闲 Ping 低**：网络「裸奔」时的底子；
- **下载/上传中的 Ping 飙升**：说明一大流量就挤占响应时间——家里有人下游戏你打游戏变卡，就是这个数在变难看；
- **三个数都低**：这条网络在满负荷时依然跟手，才是真的稳。

## 三、多少算能用

参考区间，具体以实际体验为准：

| 场景 | 大致要求 |
| --- | --- |
| 网页、视频 | Ping 宽松，速度够就行 |
| 网游 | Ping 50ms 以内为佳，超 100ms 能感到迟滞 |
| 视频通话 | 抖动小比速度高重要 |
| 丢包 | 大于 0 就要留意，持续出现就该排查 |

抖动和丢包没有「高一点没事」的说法：通话一卡一卡、游戏角色瞬移，多半是这两个数在作怪。

## 四、数字难看时，换个测速点再下结论

Ping 高、抖动大，先别急着怪线路：测速服务器远、忙，结果同样难看。手动换一两个同城节点再测，对比多数结果——同一网络在不同服务器上差百分之十几很常见。多轮数字稳定难看，再按[千兆宽带测不出千兆的原因](千兆宽带测不出千兆的原因.md)的顺序查链路；准备阶段的干扰因素见[测速前的准备清单](测速前的准备清单.md)。

工具可以从 [speedtest.cn 网速测试](https://speedtest-cn.uerg.quest/) 获取安装文件资源，装好后一轮测速里这三项与速度同屏出现，换测速点也在同一个界面里完成。
