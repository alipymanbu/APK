# 不注册能看什么与会员差别

> 「先随便看看再决定」在 Niconico 是成立的，但访客的边界在哪、注册之后还要不要掏月费，公开资料里散得很。本篇把这三档（访客 / 一般会员 / 月费会员）的差别拢到一起。

## 一、访客能干什么

安卓应用欢迎页明确给了「ゲストとして始める」（以访客身份开始）的入口，点了直接进站，不用先绑邮箱。对访客开放的部分：

- 视频常规观看，弹幕照常飘过（只是自己不能发）；
- 部分直播（ニコニコ生放送）的公开频道，不登录也能进；
- 竖屏短视频板块照样能滑。

被挡在外面的是「参与」：发评论、发弹幕、投稿这些互动动作要注册ニコニコ账号（免费）才能做。

## 二、注册之后的两档

免费的一般会员解锁参与权。再往上是月费制的 Premium 会员，综合公开评测的口径，差别主要落在体验上：

| 对比项 | 一般会员 | Premium 会员 |
| --- | --- | --- |
| 广告 | 播放前与页面内会展示 | 基本不显示 |
| 倍速播放 | 上限较低（评测口径 1.25 倍） | 最高 2 倍速 |
| 高峰期画质 | 可能被降到省流档 | 画质有保障，上限更高 |
| 发弹幕 / 投稿 | 可以 | 可以 |

「高峰期画质」这条值得单独说：免费档在晚间高峰可能被整体下调到「エコノミー（经济）画质」，老用户叫它经济画质时代——想追新番首播的人感受最明显。具体权益与价格随时会调，下单前以平台会员页当时显示的为准。

## 三、怎么选

| 使用情况 | 建议 |
| --- | --- |
| 只想看看弹幕文化长什么样 | 访客就够，不用注册 |
| 想发弹幕、参与直播聊天 | 注册一般会员即可 |
| 常在高峰期追新番、受不了画质跳水 | 再考虑月费会员 |

先把访客身份用起来再决定进阶哪一档，是最不亏的路径。装应用的第一步写在[安卓版安装步骤与访客模式.md](安卓版安装步骤与访客模式.md)；装好之后弹幕的调法与黑话速查在[弹幕评论怎么玩.md](弹幕评论怎么玩.md)，更多功能说明可以在 [Niconico 介绍站](https://niconico.hfdk.space/)继续翻。
