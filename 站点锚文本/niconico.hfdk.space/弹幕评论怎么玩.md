# 弹幕评论怎么玩

> 刚点开 Niconico 的视频，画面上飞过一串「888888」先看不懂？本篇把弹幕的走法、能调的参数和社区里的常见说法一次讲清，看完就能跟上节奏。

## 一、评论不从下面排队

Niconico（ニコニコ動画）的评论不走「评论区从上往下排」的路子，而是叠在画面上、从右往左流过——你看到视频的那一刻，别的观众的弹幕正同时掠过画面，名场面一来就是一整批同时飘过。这套玩法 2006 年随平台上线，后来中文圈的弹幕网站也沿用了这个模式。

除了默认的「流过」，评论还可以选两种停法：固定在画面顶部、或固定在画面底部。挑哪种取决于内容——说明类、计分类的信息常固定，玩梗的照旧让它流过去。

## 二、发之前能调什么

发评论的输入框旁边有几样可调的，都是明面上的：

| 可调项 | 能做什么 |
| --- | --- |
| 出现时机 | 评论在视频的哪个时间点出现，由你发送时决定 |
| 位置 | 流过 / 顶部固定 / 底部固定 三种走法 |
| 大小 | 大、中、小几档 |
| 颜色 | 默认白之外有几种可选色 |

能把这四样用到极致的人，社区里叫「コメント職人」（评论职人）：对准节拍盖一句话、给画面补一个注解，做出来的评论本身就有人专门回看。

## 三、看懂几个常见说法

- **888888**：一串 8 像拍手声，用来庆祝、起哄，最常出现在结局和名场面；
- **草**：日文语境里的「笑」，等于「哈哈哈哈」，密度高说明这段真的有节目效果；
- **うぽつ**：对投稿人的问候语，视频刚出时常刷；
- **ニコる**：给某条神评论「盖章」，被盖得多的评论带徽章显示——评论区自己也在被打分。

## 四、弹幕挡画面怎么办

看得入神但弹幕太密，把画面糊住了是常见抱怨。两条路：直接关掉评论显示（播放器里有开关，随时切回）；或在安卓应用里更精细地处理——评论列表里可以直接把某条评论或某个用户设为 NG，之后这个人的弹幕不再出现，比整体关闭更有针对性。
