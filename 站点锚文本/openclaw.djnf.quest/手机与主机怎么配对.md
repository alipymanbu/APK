# 手机与主机怎么配对

> 本篇讲 OpenClaw 安卓端与后台主机的配对步骤：两端怎么连到一起、连不上时按什么顺序排查。
> **相关文档**：[聊天软件里使唤AI助手是什么体验](聊天软件里使唤AI助手是什么体验.md) · [上手前要准备什么](上手前要准备什么.md)

OpenClaw 的安卓端装好后只是个「配套节点」，要跟跑着 Gateway 服务的主机配上对，整套系统才算转起来。配对这件事不难，卡住的人多半栽在网络环境上。

## 一、配对前的两个前提

- **主机端服务已在跑**：主机上启动 Gateway 后它会监听一个端口（社区常用 18789），手动填地址时用的就是它；
- **两端网络能互相够到**：最省事的是同一 Wi-Fi 局域网；人在外面、主机在家里时，常见做法是用 Tailscale 之类的组网工具把两端拉进同一虚拟网络再连接。

## 二、配对四步

1. 打开手机应用，进入网关（Gateway）设置页；
2. 同一局域网里它会自动发现主机，直接选择；发现不到就手动填主机地址和端口；
3. 按提示完成配对，首次配对可能需要主机端确认；
4. 回到主机状态页，能看到这台手机节点即告成功。

跨网络接入时建议走加密地址（`wss://`），明文连接只留给局域网、localhost 这类私有环境，安全取舍要多留意。

## 三、连不上，按这个顺序查

- **网络**：两端是否真在同一网络？路由器的访客网络、AP 隔离会把两端隔开，Wi-Fi 名字一样也不行；
- **服务**：主机上的 Gateway 是否在跑，状态命令看一眼是否正常监听；
- **后台**：手机端是否被系统杀了后台——常驻通知别划掉，电池优化里设为不限制；
- **记录**：之前配过、后来失联的，删掉手机里的网关记录重新走一遍配对。
