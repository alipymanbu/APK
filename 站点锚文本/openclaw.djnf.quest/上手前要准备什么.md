# 上手前要准备什么

> 本篇列 OpenClaw 开工前的三样准备：安卓手机、模型密钥、常开主机，以及只有一部手机时的折中路线。
> **相关文档**：[手机与主机怎么配对](手机与主机怎么配对.md) · [聊天软件里使唤AI助手是什么体验](聊天软件里使唤AI助手是什么体验.md)

不少人的第一印象是「装个 App 就能用」，结果装完对着空荡荡的界面发懵。OpenClaw 是一套分工明确的系统，开工前先把三样东西备齐，能少走绝大多数弯路。

## 一、三样准备

**一部安卓手机**。装配套的安卓端应用，角色是随身传话：把你的聊天消息递给主机、把通知和设备能力回传出去。安装文件的获取入口在 [OpenClaw 介绍站](https://openclaw.djnf.quest/)的安装步骤页。

**一个模型密钥**。助手的大脑是大模型，没有可用的 API 密钥，装好也答不了话。费用方面心里有个数：项目 FAQ 给的个人用量量级是每月 5~20 美元（截至 2026 年，随版本可能变化），心跳与定时任务是常见的隐形消耗，不需要就关掉。

**一台常开的主机**。真正读文件、跑命令、调模型的是主机上常驻的 Gateway 服务。家里一台旧笔记本、便宜的云服务器都行；主机不开机，助手就等于下班。

## 二、只有一部手机，行不行

社区里确实有人把服务端直接跑在手机上：用 Termux 装环境再装 OpenClaw，手机自己当主机。走这条路前先掂量三条：

- 安卓对后台进程卡得严，灭屏、省电一介入就可能断线，得手动锁保活；
- 内存与存储要求不低，老机器会很吃力；
- 这是社区路线，出了问题主要靠自己查。

对多数人来说，一台闲置笔记本或月付几十块的云服务器，比折腾手机省心得多。设备备齐后，两端怎么连到一起，见[手机与主机怎么配对](手机与主机怎么配对.md)。

## 三、给你的上手顺序

备齐三样后，推荐按「配对 → 接渠道 → 收紧权限 → 发第一条消息」的顺序走：先让手机认到主机，再把某个聊天软件接上，配好白名单，最后从一句「现在几点」开始，把这套系统玩明白。
