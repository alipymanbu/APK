# OpenClaw 介绍站导航

这里是 OpenClaw 的第三方介绍站导航页。OpenClaw 是一个开源的个人 AI 助手项目：把它接进 WhatsApp、Telegram 这类聊天软件，随口发消息就能让它跑命令、管文件、盯日程——真正干活的是一台主机上常驻的 Gateway 服务，安卓端负责随身传话。

想直接看完整介绍，可前往 [OpenClaw 介绍站](https://openclaw.djnf.quest/)，站内有工作方式图解、功能清单、界面截图与安装文件资源的获取入口。
