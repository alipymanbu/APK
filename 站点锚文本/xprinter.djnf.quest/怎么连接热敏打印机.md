# XPrinter 怎么连接热敏打印机

XPrinter 这款安卓应用主要靠三种通道把手机和打印机连起来：蓝牙、USB、Wi-Fi。柜台和库房里用得最多的是蓝牙——方便、不用布线，一台手机也能随时给几台机器轮流发打印任务。这篇把连接的完整过程和卡住时的排查思路整理成笔记，供对不上号的人参考。

## 连接前先备好两样东西

1. **自检页**：绝大多数芯烨系热敏机都能自己打一张自检页——不带屏幕的机器按住走纸键开机，约两秒后状态灯闪一下就松手；带屏幕的机器在设置菜单里选「打印自检页」。这张纸上有蓝牙名称和 PIN 码，配对时要用。
2. **打印机电量与纸**：电量太低时蓝牙广播不稳定；纸仓没装好有些机型会直接拒绝响应，先确认出纸口能正常走纸。

## 蓝牙配对的完整顺序

1. 打开手机系统蓝牙（应用内搜索一般也要求系统蓝牙先开）。
2. 进入应用首页，点右上角的连接状态入口（默认显示「未连接」）。
3. 选蓝牙连接，等待应用搜出附近的设备。
4. 在列表里点自己打印机的蓝牙名称——拿不准就对照自检页上的名称。
5. 首次连接会要求输入 PIN 码，照自检页上的填，确认后配对完成。

配对成功后，设备页会显示类似「Printer001-XXXX 已连接」的状态，这里可以直接开始打印了。

## Wi-Fi 与 USB 的适用场合

- **Wi-Fi**：适合固定位置的多台手机共用一台打印机，比如吧台、收银台。机器和应用要处在同一局域网段，在网络连接里填打印机地址即可。
- **USB**：安卓手机通过 OTG 线直连，适合蓝牙环境拥挤的仓库现场，插上线就能识别，不走无线信道。

## 连不上时的排查顺序

按出现频率排，多数人在前两步就解决了：

1. **重启大法**：把打印机和 App 都重启一次再试；蓝牙当前若显示已连接，先断开再重新配对。
2. **核对机器**：自检页能正常打出来，说明机器本身没坏；打不出来先解决机器的问题。
3. **查 MAC 地址**：应用显示打印成功、机器却没动静时，多半是连到了另一台同型号机器——自检页上的 MAC 地址后四位要与应用右上角已连接设备的后四位一致。
4. **权限**：安卓系统没有给应用定位/附近设备权限时，蓝牙搜索列表可能是空的，到系统设置里补授权。
