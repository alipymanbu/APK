# XPrinter 标签模板编辑与 Excel 批量打印

打一张标签不难，难的是打一批。XPrinter 这款应用真正省时间的部分在于模板加批量数据：先挑一张现成模板或自己建一张，把文本、条码、二维码这些元素摆好位置，再用 Excel 把整批数据灌进去，一次打出几十上百张。这篇笔记按实际编辑顺序整理。

## 模板从哪里来

应用里的模板分两类：**内置模板**（按行业分好——商超便利、小票、数码家电等，直接取用改内容）和**云模板**（云端储存，手机、网页、电脑端实时同步，换设备不用重做）。同事之间还可以用模板批量分享功能，把做好的版式直接分发下去复用。

## 新建标签时的关键参数

不套模板、从空白开始建时，新建标签页会问这几个问题，每一个都影响出纸效果：

| 参数 | 怎么定 |
| --- | --- |
| 标签宽度 / 高度 | 按实际纸卷尺寸填，比如 40mm × 30mm |
| 标签缝隙 | 间隙纸按实际缝隙填（常见 2.0mm），连续纸填 0 |
| 打印方向 | 0° / 90° / 180° / 270°，竖版价签常用 90° |
| 纸张类型 | 间隙纸、连续纸、黑标纸三选一 |
| 机器类型与打印模式 | 标签 / 票据 / 76 针打；TSC 指令或 ZPL 指令 |

其中**纸张类型与打印机模式的对应关系**最容易出错：标签模式对应间隙纸，票据模式对应连续纸，选错是乱码的头号原因。

## 可用的元素与素材

编辑器支持文本、一维条码、二维码、线条、矩形、图片、表格七类元素；语音识别、图像识别、扫码识别几种输入方式可以减少手打。图标不用自己找——应用内置了按行业分类的 Logo 素材库，石油、银行、运营商、快递、母婴、生活、电商、电网、美妆、警示都有现成的。

## Excel 批量导入：一次生成整批

这是批量作业的核心能力，流程大致是：

1. 把商品名、价格、编号等字段整理进 Excel 表格，第一行是字段名。
2. 在模板里把元素绑定到对应字段，同一个字段可以选择渲染成文本、一维码或二维码。
3. 导入后应用按行批量生成，直接整批打印。

商品信息库还能存会员价、等级这类扩展字段，导入模板里有现成的表格文件可以下载对照格式填写。商超改价、仓库贴标这类活，用这套流程比一张一张改快得多。
