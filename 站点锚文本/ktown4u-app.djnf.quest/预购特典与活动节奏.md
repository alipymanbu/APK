# Ktown4u 预购特典怎么看：报数日、时区与付款时效

> 本篇讲 Ktown4u 买专辑最容易踩坑的预购环节：商品页的字段怎么读、特典资格什么时候算数、截止时间为什么要换算时区，以及付款环节的两个时效。

## 一、先把商品页的几个字段读懂

K-POP 专辑普遍走「预购 → 报数 → 发货」的节奏，这些字段看懂能避免大量误会：

| 字段 | 含义 |
| --- | --- |
| Pre-Order / 预购 | 在报数日之前下单，通常附带预购特典（POB） |
| 预购特典 / POB | 报数日前下单额外赠送的海报、小卡等，随单寄出 |
| Ktown4u Special Gift | 平台自己加赠的特典，与厂牌特典是两回事 |
| 报数日 | 平台把预购数量报给厂牌的截止点，决定首印量 |
| 预计发货日 | 报数后生产、到仓、发出的估算时间，可能浮动 |

同一张专辑常有多个版本与特典组合，先确认选中的是想要的那个组合再加购物车。活动页通常会写清「报数日」「预计发货日」，以及报数后是否继续开放链接——不少活动在首批报数后若有余量会继续卖到售罄，售罄前下的单都算首批，具体以当期活动页标注为准。

在手机上逛预购活动、比价加车，用客户端会顺手很多——它把商城活动区固定成了桌面入口，整理好的介绍见 [Ktown4u app 客户端说明](https://ktown4u-app.djnf.quest/)。

## 二、时区上的坑：截止时间多为韩国时间

活动与特典的截止时间按页面标注多为**韩国时间（KST）**，比北京时间快一小时。有用户在北京时间深夜付款，结果错过了当日 KST 的特典截止。把截止时间换算成北京时间，再决定什么时候付款。

## 三、付款环节的两个时效

- **未付款订单有时效**：站内活动页有「超时自动取消」的提示（有的写 2 小时，以页面为准）。别把下单拖到特典截止的最后一刻，给自己留出付款时间。
- **一起发运要同一单**：想把几件商品一起发运，必须放进同一个订单，分开下的单不合并；运费按预估重量计算，与实重算出的费用可能有差异。

结算页按所在地区展示可用支付方式，常见有信用卡、PayPal、支付宝；有优惠券的话，在结算的 Shipping Notice 一步点「Coupon」按钮选用。

## 四、特典没随单，先自查两处

1. 核对下单时间是否在预购期内——活动期结束后，标题里再写特典也不补发；
2. 「我的订单」里点开订单号，看特典条目在不在订单详情里：下单时选了特典会随单发，没选就真没有，售罄时选项会显示「售罄」。

都对得上却没给，走站内客服咨询并附订单号。发货后多久能到、清关要等几天，是另一段流程；参与签售活动的完整路径见[视频签售报名与通话流程](视频签售报名与通话流程.md)。
