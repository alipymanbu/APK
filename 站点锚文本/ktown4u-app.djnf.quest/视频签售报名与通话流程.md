# Ktown4u 视频签售怎么报名：从买对条目到一分钟通话

> 本篇讲 Ktown4u 上签名会与视频签售（video call）活动怎么参与：资格怎么来、中选名单在哪看、接到来电前后各要做什么、哪些细节会让人白买专辑。

## 一、先分清两种活动

| | 线下签名会 | 视频签售（video call） |
| --- | --- | --- |
| 地点 | 韩国现场 | 你在哪儿都行 |
| 形式 | 当面签你带来的专辑 | 主办方按名单顺序给你打视频电话 |
| 中选后 | 到场参加 | 通话限时，签名专辑事后邮寄 |

对身在韩国以外的粉丝来说，视频签售是不需要机票酒店的那种：一部手机加稳定的网络就能参加。两类活动在商城里是**不同的商品条目**，商品标题里会标注线下（offline）或视频通话（video call / 영상통화），买之前看清，买错了不能互相顶替。

## 二、资格怎么来

一场活动的通用节奏：

1. 发布活动公告，写明绑定哪张专辑、购买窗口与中选公布日；
2. 在窗口期内购买活动绑定的专辑（在 Ktown4u 上通常就是下单活动商品本身）；
3. 等中选名单公布。

有的活动购买后自动获得资格，有的要求额外提交订单号报名——**下单前把活动页与公告逐行读完**，只买不报等于没报名的情况真实存在。中选名额通常远少于参与人数，热门艺人的中选线可能要几十张专辑，把它当抽奖对待，预算量力而行。购买窗口的截止时间多为韩国时间（KST），比北京时间快一小时，报名前先换算清楚。

## 三、中选名单在哪看、看什么

- **站内公告板**：中选名单按艺人与活动场次分帖公布；
- **邮件**：中选的详细说明以邮件为准，活动规则里明确写了「不查邮件导致的损失自负」——中选公布日前后每天查一次邮箱，包括垃圾箱。

名单帖里除了中选者编号，还会写通话时间与注意事项，重点确认三件事：通话时间、联系渠道（用哪个应用打给你）、以及报名渠道的「允许被搜索」是否已打开。商城活动入口与客户端使用说明，见 [Ktown4u app 客户端介绍](https://ktown4u-app.djnf.quest/)。

## 四、接到来电之前

1. **开启「允许被搜索」**：通话通常通过 KakaoTalk、LINE、WeChat 这类应用呼叫，要求中选者把报名渠道的 ID 搜索权限打开；因为关着权限而联系不上，会被视为无法参加。
2. **核对实名信息**：报名填的名字、生日、电话要与证件一致，拼写对不上可能在核验环节被取消资格。
3. **网络与环境**：网络问题可能影响参加，提前确认手机网络稳定；找个安静、光线好的位置。
4. **想好要说的话**：单人通话时间普遍只有一分钟左右，包括打招呼和你想问的问题；提前准备一句最想说的，比临场组织语言高效得多。

## 五、通话进行时与之后

- 按名单顺序来电，**保持手机在手边等电话**；
- 规则口径：**连续两次不接听，顺位自动让给下一位**；
- 通话限时，超时可能被强制结束；
- 说完及时挂断，把线路让给下一位；
- 签名专辑不当场给，活动结束后按安排另行邮寄，留意邮件通知与订单物流。

活动绑定的专辑下单时，预购与特典的规则细节见[预购特典与活动节奏](预购特典与活动节奏.md)；还没装客户端的，安装步骤见[安卓客户端安装步骤](安卓客户端安装步骤.md)。
