# WonderPen 妙笔适合什么样的写作者

评价一款写作工具合不合手，看的不是功能多不多，而是它的结构设计是不是对准你的写作类型。这篇从几个典型的写作人群出发，说说 WonderPen（妙笔）在谁手里能发挥最大价值，以及什么情况下它不是最优选。

## 先看它的底层设计

妙笔的所有内容都围绕两个东西组织：

- **树状目录**：一篇文档下面还能再挂文档，层级不限；
- **卡片与白板**：正文之外的地方，随手记人物、设定、灵感。

这个组合决定了它的天然主场是「篇幅长、结构强」的写作——因为层级够深，再厚的稿子也拆得开；因为卡片在手边，写几百章也不至于把设定忘干净。

## 很适合的几类人

**长篇小说作者**。最对口的人群。卷、章、节挂在目录树上随点随跳，人物卡、地点卡、时间线放在卡片列表或白板里，写到后面对照着写；每章字数统计和大纲视图让进度一目了然。网页端产品页展示的示例作品，本身就是一部按章节拆好的小说。

**论文与长文写作者**。论文的「章—节—小节」结构天然适合树状目录；引用资料可以记成卡片，正文里高亮标注；写完导出 Word 或 PDF 交差。

**连载作者与日更党**。写作目标可以设每日字数，码字统计记录每天的产出；专注模式、打字机模式屏蔽手机上的干扰，通勤路上掏出手机也能推进几千字。

**日记与随笔爱好者**。虽然是「轻量场景」，但目录树当日记本用（一年一个分支、一月一篇）也很顺手；夜间模式和自定义字体行距让睡前写作舒服一些。

## 不太适合的场景

- **复杂排版**：它走的是 Markdown 式纯文本路线，所见即所得编辑器能处理粗体、列表、公式，但别指望它做画册式的复杂版式；
- **多人协作**：目前没有面向团队的协同编辑能力，多人共写一份稿子不是它的菜；
- **只想随手记便签**：如果只是零散记事，它这套「文档库」结构反而显得重，轻量笔记工具更合适。

## 免费够不够用

基础版免费，文档编辑、白板、备份、快照、夜间模式、导出（图片 / PDF / Word / Epub / 网页 / txt）都在免费范围内，写小说、写论文的核心需求基本覆盖。差异主要在云端额度与高级自定义上：Pro / Pro+ 解锁无限模板、自定义 CSS、更大的云文档库等，属于「用得深了再考虑」的部分。

一句话总结：写长东西的人，它的结构优势能完全兑现；写短东西的人，它也不碍手，只是未必用得到全部家当。
