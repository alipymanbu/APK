## 一句话了解 Adblock Plus

Adblock Plus 在网页发出请求的瞬间逐条对照过滤规则，广告与跟踪请求被直接取消——没下载，就没流量。它以 GPLv3 协议开源，过滤列表由全球社区持续维护。
