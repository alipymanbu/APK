## 一、先分清：功能名还是梗

OTTOhub 的界面文字里混着两类词：一类是**功能的正式叫法**，一类是**圈子里的梗**。第一次见容易混，先给功能名对上号：

| 词 | 实际含义 |
| --- | --- |
| 冷藏 | 就是收藏。被冷藏的内容不公开展示，只有自己个人页能看到 |
| 超管 | 审核员，负责给投稿「通过 / 打回」，由资深用户申请而来 |
| 鞍山大法庭 | 发布封禁公示的站内账号，谁被删号、为什么，公示都发在这里 |
| 轮椅英雄 | 给站点捐赠过的用户拿到的称号 |

## 二、高频梗速查

| 梗 | 一句话解释 |
| --- | --- |
| 吉吉国王 / 吉吉国民 | 前者是对主播 otto（电棍）的调侃外号，直播平台认证的也是它；后者是粉丝自称，注册 OTTOhub 后第一个称号就是它 |
| 稳健棍 | otto 的另一个外号，出自他职业生涯的对局与采访里「打法稳健」的自评，被观众调侃至今 |
| 轮椅 / ♿ | otto 早年腿部有伤、定制过专用电竞椅，被观众戏称坐轮椅；二创标题里的 ♿ 符号与「轮椅英雄」称号都源于此 |
| 韭菜盒子 | 直播点外卖被漏送韭菜盒子、与商家对线的名场面，「那我缺的营养这一块谁给我补」成了流传语录 |
| 别急 | 出自圈内二创作者的直播回应「主播都没急你们急什么」，如今是最高频的口头禅，常见变体「我知道你很急，但你先别急」 |
| 德州之夜 | otto 职业生涯早期打德州扑克一夜输掉大额现金的旧事，常被拿来玩梗 |

## 三、动物园与圈层

电棍与炫神、山泥若等主播的粉丝圈子交集密切，这几个圈子被合称「动物园」，相关创作文化也叫「动物园文化」。OTTOhub 的内容基本都从这条文化线里长出来；人物与事件级别的来龙去脉，社区百科 OTTOWiki 上有完整条目。
