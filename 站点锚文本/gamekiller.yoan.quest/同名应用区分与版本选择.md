# GameKiller 同名应用区分与版本选择

> 搜「Game Killer」能翻出好几个完全不同的东西，这篇讲清楚怎么认准沙箱游戏工具箱这一款，以及手上的版本新不新、要不要升级。
> **相关文档**：[变速连点与多开玩法详解.md](变速连点与多开玩法详解.md) · [安装失败排查与解决.md](安装失败排查与解决.md)

---

## 一、这个名字下面至少有三个应用

搜「Game Killer」「GameKiller」，结果里混着三类东西，功能毫无关系：

| 它是什么 | 怎么认 | 要不要装 |
| --- | --- | --- |
| 沙箱游戏工具箱（本系列讲的这款） | 免 root、深色界面、底部 Mod / Box / Category 三个标签，游戏克隆进沙箱后出悬浮球 | 看需求 |
| Play 商店里的拼图休闲游戏 | 用手机里已装应用的图标做谜面，纯猜谜 | 与工具无关 |
| 早年的内存修改工具 | 多年前就停更，流传版本来源混杂，需要 root | 不建议 |

**认包名是最可靠的区分办法**——不同应用包名必然不同，名字可以随便起，包名不会撞。安装前在安装包信息里核对一眼，装错名字相同的东西是最常见的弯路。

## 二、版本信息怎么查

两种查法任选：

- 系统设置 → 应用管理 → 找到 Game Killer → 看「版本号」；
- 部分版本可在应用内右上角三个点的菜单里找到「关于 / 设置」入口查看。

以 5.3.5 为例：沙箱 Box 升级、适配性更好，存档下载效率优化，本地存档与变速工具匹配。完整的获取与安装流程在 [GameKiller 介绍站](https://gamekiller.yoan.quest/)。

## 三、5.3.x 各版本变化速览

从更新记录里能看出这条主线：**几乎每一版都在修沙箱兼容性**。

| 版本 | 主要变化 |

| 5.3.0 | Core2 变速选项；沙箱支持 Google 登录；多开最多 10 个分身 |
| 5.3.2.2 | 存档编辑器与云存档备份；降低广告弹窗频率 |
| 5.3.3 | 会员福利；Box 兼容性再提升；新增反馈渠道 |
| 5.3.4 | 下载与沙盒启动提速；变速新增简易模式；连点器改进 |
| 5.3.4.2 | 修复存档导入问题；修复部分游戏悬浮球不显示 |
| 5.3.5 | 沙箱 Box 升级适配性更好；存档下载提效 |
| 5.4.0 起 | 沙箱内直接安装 APK/APKs；广告策略调整；AI 实时翻译（测试） |

## 四、要不要升级

分三种情况：

- **只想把工具用起来**：5.3.5 已覆盖沙箱、变速、连点、多开、存档备份整套核心能力，够用；
- **碰到兼容性问题**（某游戏闪退、悬浮球不出）：优先升级，5.2.3 以来每版都在处理这类问题，你踩的坑大概率已修；
- **在意广告与会员策略**：5.3.3 之后策略有调整，升级前先看当版更新记录，确认接受再动。

升级前记得先把沙箱里的重要存档备份一份，动作再去[变速连点与多开玩法详解](变速连点与多开玩法详解.md)里对照；装不上是另一类问题，转[安装失败排查与解决](安装失败排查与解决.md)。
