# 支持哪些网站与输出格式

> 「我想下的那个站它能不能下」「下出来是什么格式」——装之前人人都会问这两句。这篇把 iTubeGo 安卓版的站点范围、输出规格，以及手机版容易和桌面版搞混的地方整理在一起。

## 一、站点范围：数字之外看具体站名

产品方页面对安卓版给出的说法是支持 1000+ 个站点，首页也出现过更大的数字——计数口径不一，与其纠结总数，不如看常被提起的那些是否在列：

| 类别 | 站点 |
|---|---|
| 综合视频 | YouTube、Dailymotion、Vimeo、TikTok |
| 社交平台 | Facebook、Instagram、Twitter、VK |
| 音乐音频 | SoundCloud、MixCloud、Vevo、Bandcamp、niconico |
| 其他 | OK.RU、Coub、U-NEXT |

三条使用规律值得记住：

- **YouTube 只有 APK 安装包版支持**。应用商店上架的那版受政策限制不含这条能力，装错版本怎么试都失败，不是操作问题；
- 没列出来的站**不代表不能下**——智能链接检测认得媒体流就能解析，最快的验证办法是实际送一次链接；
- 站点改版或加防护会导致个别解析临时失效，属于常态，换送链接的方式（内置浏览器、复制链接、分享进来三条路）常能绕开。

## 二、输出规格一览

**视频**（类型选 Video，存 MP4）：

- 档位 360p / 720p / 1080p / 1440p / 2160p，按源视频实际提供的可选；
- 转换过程保持源质量，不做二次压缩。

**音频**（类型选 Audio）：

- 容器格式 MP3、AAC、M4A 三种；
- 码率 70 / 128 / 320kbps 三档，320k 是铃声和有声书的最优档；
- ID3 标签完整保留，歌名封面不用手补。

## 三、手机版与桌面版别搞混

同一名字的工具有安卓版和 Windows / macOS 桌面版，宣传页上不少数字（8K、万级站点数、字幕下载、剪辑）说的是**桌面版**。手机上找这些功能找不到，先对照这张表：

| 能力 | 安卓版 | 桌面版 |
|---|---|---|
| 分辨率档位 | 官方安卓页列到 2160p | 标到 8K |
| 站点数量宣称 | 1000+ | 10000+ |
| 字幕 / 剪辑 | 未提供 | 有 |

判断某个功能手机上有没有，以应用内实际选项为准。桌面版是独立的安装包与授权，两者互不相干。

## 四、格式定错了能补救吗

不能在应用内改格式——输出类型在点下载那一刻就锁死了。要换只能重新下一次。所以批量任务开工前，先拿一两条试出对的档位，再回来全选整份列表。
