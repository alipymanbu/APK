# Wispr 注册流程详解：从手机号到 Matrix ID

注册 Wispr 的体验和常见聊天软件接近，但走完流程后你会发现一个关键差异：别人认识的不再是你的手机号码，而是一串代号。本篇按顺序拆开注册的每一步，说明 Matrix ID 是什么、为什么这样设计。安装环节还没完成的，可以先看介绍站上的[加密通讯应用 Wispr 功能与获取指引](https://wispr.ggcd.store/)。

## 注册只需要一个手机号

打开应用后按提示输入手机号，收到验证码填入，账号即告创建。整个过程不要求填写姓名、邮箱等额外信息，可选的头像与昵称也属于个人资料范畴。

值得留意的是这串号码的去向：Wispr 会把你的手机号换算成一串 Matrix ID 代号，形式类似 `xae38s25c56c2883e34esab`。之后别人在会话列表里看到并用来找到你的，主要是这串代号，而非号码本身。

## Matrix ID 在组织场景里的用法

除了个人注册，Wispr 还支持由组织统一发放 Matrix ID：成员无需绑定个人手机号，用组织分配的专属标识登录，在组织划定的范围内通讯。对不想把私人号码带入工作沟通的人来说，这是一条干净的路径。

## 注册完成后的第一件事

账号就绪后，建议先做两件事：

1. **把 Matrix ID 发给要联系的人**——对方发起会话时需要能定位到你；
2. **理解「接受」这一步**——给新联系人发出第一条消息时，对方需要先接受你的会话请求。这不是社交确认，而是两台设备在交换公钥：接受之后，端到端加密的会话才正式建立。

想弄清这套密钥机制为什么值得信任，可以延伸阅读[加密机制与 VOBP 协议](加密机制与VOBP协议.md)；如果注册或首次使用时遇到连不上、握手失败等情况，[连接失败与常见问题](连接失败与常见问题.md)一篇有排查路径。

## 小结

注册环节的简洁是有意为之：手机号只是入口，代号才是身份。需要获取安卓安装文件资源的，可以从本目录开头给出的介绍站入口进入。
