# Castro 怎么看手机硬件信息

> 想知道自己的手机 CPU 什么水平、电池还健康吗、屏幕密度多少，用 Castro 打开就是一屏实时读数。这篇按「仪表盘 → 信息页 → 读数注意事项」的顺序，讲每个数字该在哪看、怎么看。

**相关文档**：[安卓版下载安装步骤](安卓版下载安装步骤.md) · [二手手机验机流程](二手手机验机流程.md)

## 一、先看仪表盘：一屏知道手机现在的状态

Castro 打开后的第一屏就是仪表盘，把最常看的几组数字放在同一屏：

| 卡片 | 能看到什么 | 什么时候用得上 |
| --- | --- | --- |
| CPU | 各核心的实时频率，新版还会叠加使用率百分比 | 怀疑降频、玩游戏卡顿时 |
| 电池 | 电量、温度，新版本直接显示实时功率 | 感觉耗电异常时先看这里 |
| 网络 | Wi-Fi 与移动数据的实时上下行速率 | 查有没有应用在偷跑流量 |
| 内存 | RAM 总量与当前占用 | 多任务卡顿时判断负载 |

数字都是实时刷新的：切回桌面再进来，数值已经换了一轮。桌面小部件还能常驻一块 CPU 温度读数，不进应用也能瞄一眼。

## 二、信息页：按硬件分类的完整档案

往下翻是信息页，按硬件分门别类，常用的几块：

- **处理器**：核心数、每颗核心的频率，以及 GPU 的型号与状态；
- **电池**：温度、电压、健康状态，支持的机型还显示循环次数；
- **内存与存储**：RAM 与机身存储的占用分布，用来定位「谁吃掉了空间」；
- **网络**：Wi-Fi 与移动网络的用量统计，Wi-Fi 页还能看到当前网络的安全类型；
- **传感器**：加速度计、陀螺仪、光线等读数带实时曲线，点进单个传感器能看详情图、直接调整采样频率；
- **摄像头**：前后镜头的分辨率、光圈、对焦与防抖（OIS）参数；
- **编解码器**：设备支持的音视频格式完整清单，装播放器前先来查一眼。

信息项太多时，用搜索页直接输关键词（比如 "refresh"、"battery"）跳过去，比逐层翻菜单快。

## 三、读数怎么解读，几个常见疑问

- **频率、温度一直在跳，是不是不准？** 波动本身正常：手机一空闲 CPU 就降频，一跑应用又拉上去。判断问题要看趋势，别凭单次数值下结论。
- **个别条目是空的？** 多数是权限没给全，或机型本身不上报该传感器；把相机、电话等权限补上再重启应用，仍为空的条目多半是硬件没有。
- **想保存或分享这份数据？** 工具页的「数据导出」能把设备信息以合适的格式导出，具体流程见[二手手机验机流程](二手手机验机流程.md)。

温度、频率之外，电池相关的读数误区更多，装好前先看[安卓版下载安装步骤](安卓版下载安装步骤.md)把权限配对，读数才完整。

按「卡顿发热、流量耗电、二手验机」三个疑问组织的读数方法，见 [Castro 介绍站](https://castro.djnf.quest/)。
