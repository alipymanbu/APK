# Castro 安卓版下载安装步骤

> 从哪拿安装包、怎么装上、装完怎么确认能用，这篇按顺序讲清。全程只有「转存 → 下载 → 安装」三段，卡住的点集中在未知来源授权和权限分配，都有对应解法。

**相关文档**：[怎么看手机硬件信息](怎么看手机硬件信息.md) · [二手手机验机流程](二手手机验机流程.md)

## 一、安装前知道三件事

- **系统要求**：最低 Android 6.0，再老的机型装不上，不必勉强试；
- **版本差异**：开发者把 Castro 分 Basic 与 Premium 两个独立应用（包名不同），拿到哪份以安装包实际显示为准；
- **版本号出入**：开发者的正式版迭代较快，不同时间拿到的包版本号可能不一致，属正常现象，不影响读数功能。

## 二、下载与安装五步

1. **打开分享页**：进入安装文件资源的夸克网盘分享页，把安装包转存到自己的网盘账号；
2. **下载 APK**：从自己的网盘把安装包下载到手机存储；
3. **点开安装**：首次安装系统会拦一道「禁止安装未知来源应用」，按提示跳到授权页，给这次用的浏览器或文件管理器勾上「允许安装」，返回后继续；
4. **按需给权限**：装完首次启动会请求相机、电话等权限——按需授予，不给权限时大部分读数照常显示，只有对应条目会空着；
5. **确认装好**：进入主界面看仪表盘，CPU 各核频率、电池、网络三块卡片在实时跳动，就说明已经就位。

装好之后各页读数怎么解读，见[怎么看手机硬件信息](怎么看手机硬件信息.md)。

## 三、装不上或打开异常，按这个顺序查

| 现象 | 处理 |
| --- | --- |
| 点安装提示未知来源被拦 | 到 设置 → 应用 → 特殊应用权限 → 安装未知应用，给下载所用的应用授权；装完可收回 |
| 安装到一半失败 | 先删掉已下载的 APK 重新下载一份，排除下载损坏；存储空间不足也会导致 |
| 打开后部分条目空白 | 多数是权限没给全，补授后重启应用；个别传感器硬件本身没有，读数就是空的 |

装好只是第一步，拿它验二手手机、导出设备底账的完整玩法，见[二手手机验机流程](二手手机验机流程.md)。

功能全景与安装文件资源入口见 [Castro 介绍站](https://castro.djnf.quest/)。
