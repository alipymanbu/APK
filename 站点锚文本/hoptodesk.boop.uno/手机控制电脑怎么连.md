## 一、先分清你坐在哪一端

HopToDesk 的连接模型是双向的：装在电脑上是主控端也是被控端，装在手机上同样如此。你想「拿手机控制电脑」，那么电脑是被控端、手机是主控端；反过来想让电脑看到手机屏幕，角色就调换。两端都要装好 HopToDesk，缺一边连不了。

安装包从哪来、装完怎么初始化，见介绍站的[下载与安装页](https://hoptodesk.boop.uno/download.html)；本篇只讲装好之后的连接。

## 二、三步发起第一次连接

1. **读出凭据**：在被控端（电脑）打开 HopToDesk，窗口顶部会显示这台设备的 ID 和密码，这两个值就是本次连接的凭据。
2. **输入远程 ID**：在手机端「连接」页签顶部找到「远程 ID」输入框，填入电脑显示的 ID，点箭头发起。
3. **确认密码**：电脑端会收到连接请求，输入（或确认）密码后会话即建立，电脑桌面出现在手机屏幕上，可看可操作。

之后的连接不用再翻凭据：最近的会话会留在手机端列表里，常用设备还可以加收藏夹，一翻就到。

## 三、按你的用法给权限

不同用法要给的权限不一样，给少了才是「连上了却控制不了」的根源：

| 你想做什么 | 需要的动作 |
| --- | --- |
| 拿手机控制电脑 | 装完即可，无需额外系统权限 |
| 让电脑反过来操作这台手机 | 在系统「无障碍」设置里给 HopToDesk 开启无障碍服务 |
| 让电脑看到手机屏幕 | 在「共享屏幕」页签启动服务，按弹窗确认屏幕录制等权限 |
| 会话留档 | 到「设置」页签打开自动录制传入/传出会话 |

无障碍服务是安卓上实现远程触控的正规途径，不开它，电脑那头就只有画面、点不动你的手机。

## 四、连接之外的沟通与安全

会话中要传一句口令、确认一个文件名，不必中断画面——「聊天消息」页签提供与远程画面并行的即时聊天，同样走端到端加密。账号层面，担心设备被陌生会话打扰，可以到设置里启用双重认证（2FA）；手机屏幕交出去之前，逐项确认「共享屏幕」页里的权限开关，用完随手关。
