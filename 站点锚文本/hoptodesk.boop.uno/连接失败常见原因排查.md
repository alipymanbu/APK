# 连接失败常见原因排查

> 连不上、连上了却控制不了、提示服务没有启动——按「凭据 → 服务与权限 → 网络环境」三层从易到难排查。
> **相关文档**：[手机控制电脑怎么连.md](手机控制电脑怎么连.md) · [和TeamViewer哪个好用.md](和TeamViewer哪个好用.md)

---

## 一、先核对凭据：ID 与密码

最常见的失败其实最简单：远程 ID 输错（多一位、少一位、把本机 ID 当成了对方 ID），或者密码过期。被控端重新打开一次 HopToDesk，核对窗口顶部当前的 ID 与密码，再在主控端逐位重填。设备多的人建议直接用收藏夹存常用设备，避免手输。

## 二、被控侧没就绪：服务与权限

凭据没错还连不上，看被控端这三处：

- **服务没有启动**：手机被控时，「共享屏幕」页签顶部提示「服务没有启动」，就点 Start Screen Share 把屏幕共享服务跑起来。
- **权限开关没给**：同一页里的屏幕录制、文件传输、音频录制逐项确认；电脑端留意系统弹窗，别让确认框挂在后台没人点。
- **无障碍没开**：「电脑连上了手机却点不动」，几乎都是手机端无障碍服务没给——到系统设置的无障碍列表里找到 HopToDesk 打开。

## 三、版本与渠道差别

一个容易被忽略的点：应用商店版和 APK 安装包的能力并不一样——按项目帮助文档的说明，商店版只保留主控功能（拿它去连别人），APK 包才同时带被控能力。如果你指望「电脑反过来控制这台手机」，装的却是商店版，怎么排都排不通；换成 APK 这一脉的包再试。

APK 从哪拿、装的时候要注意什么，[HopToDesk 远程桌面介绍站](https://hoptodesk.boop.uno/) 的下载与安装页有一份按顺序走的安装指引。

## 四、网络环境：通常不用动路由器

HopToDesk 不需要端口转发，也不要求在防火墙上开洞，家庭网络下装上就能连——所以「连不上」先别怀疑路由器。真遇到一直握不上手，可以先做两个排除法：

1. 把两台设备换到另一个网络（比如手机开热点）再试，能连上就说明是原网络的限制，公司网络里常见这类管控；
2. 核对两端时间是否正常，时间偏差过大可能影响握手。

排查到这一步仍然失败，把两端的现象（报错文案、卡在哪一步）记下来再逐条对照上文的层级，多半能定位到具体是哪层的问题。装好之后想一次走通完整流程，回到[手机控制电脑怎么连](手机控制电脑怎么连.md)按步骤来即可。
