## 一、户外看天和日常看天不是一回事

城市里看天气，温度和晴雨差不多就够了；一到山里、雪线以上或天上，真正决定安不安全的是另外几个变量：

| 变量 | 为什么关键 |
| --- | --- |
| 阵风 | 山脊与垭口的阵风峰值远大于城区平均风速，直接影响行进安全 |
| 霜线 | 涉水路段夜里结不结霜，决定清晨路面湿滑程度 |
| 降雪线 | 下雨还是下雪，以这条线为界，雪线之上装备完全不同 |
| 热气流 | 航拍与滑翔看升力窗口，静稳天和大风天都不适合 |

日常预报页不会把这些摆在明面上，需要专用图。

## 二、按活动对工具

- **徒步登山**：All-in-One 气象图 + 逐小时降水概率，出发前把阵风和霜线对一遍路线海拔；
- **滑雪**：降雪线高度 + 山区专用预报，判断当天是新粉还是冻壳；
- **飞行**：热气流预报 + 大气稳定度图，先确认当天有没有可用的升力窗口；
- **农业**：土壤湿度 + 喷洒天气窗口，安排打药和灌溉不再靠经验猜。

[meteoblue 的介绍站](https://meteoblue.hfdk.space/)把这些场景对应的图层一一列了出来：多模型气象图管趋势判断，实时雨雷达管临场一两小时，where2go 负责在地图上圈出周边的晴朗区域，四类活动都能找到自己要看的那张图。

## 三、信号不好的时候怎么保底

山区没信号是常态，办法只有一个：出发前把数据带在身上。有的应用会自动留存最近查过的地点数据，离线照常翻图——meteoblue 就是这样处理的，进山前查一次，全程有底。另外把桌面小组件提前加好，信号时好时坏时，开屏即读，不用专门点进应用刷新。
