# 告警误报太多怎么调

> 「有人经过要提醒」由三层拼起来：手机放行通知、摄像头认对事件、消息留得下来。
> 任一层没配好，都会表现为「明明有人走过，手机却没响」或者反过来「猫走一下推三条」。
> **相关文章**：[摄像头怎么添加与配网](摄像头怎么添加与配网.md) · [手机远程看家的正确用法](手机远程看家的正确用法.md)

本文的排查思路同样适用于 iCam365 系列机型的看家设置；完整的图文版与安装入口见
[iCam365 看家手册](https://icam365.hfdk.space/)。

## 一、第一层：先把通知权限放行

完全收不到推送时，先查两处：

1. 手机系统设置里，iCam365 的「消息通知」权限有没有被关掉——系统管家与省电模式经常顺手关它；
2. 应用内这台摄像头的设置里，推送开关有没有关。

另有一个容易误判的点：正开着实时画面看这台设备时不会再另外推送，画面就在眼前、它判定没必要。这不是故障。

## 二、第二层：让摄像头认对「什么算事件」

在设备的侦测设置里，几项分工如下：

| 设置项 | 作用 | 调法建议 |
| --- | --- | --- |
| 侦测开关 | 总闸 | 关了什么都不产生 |
| 灵敏度 | 多大的动静才触发 | 对着马路的往低调，安静院子可往高调 |
| 侦测区域 | 只盯画面某块区域 | 把马路、树枝、邻家窗户排除掉，减误报最有效 |
| 人形检测 | 只把「人」当目标 | 过滤小动物与光影变化 |
| 智能追踪 | 人动镜头跟着转 | 云台机型才有；常开明显耗电 |

**误报太多的调整顺序**：先缩侦测区域 → 再开人形检测 → 最后降灵敏度。反着调往往把该报的也一起压掉了。

两个和机型直接相关的点：

- 宠物、车辆这类非人目标的识别，部分型号要求开通云存储才可用——选项是灰的或找不到，多半不是设置问题而是套餐问题；
- 户外电池与太阳能机型通常是「人体感应先唤醒 + AI 再判断」两层配合，感应范围以机身说明为准；部分户外机型内置警报器，可在检出后联动声光报警。

## 三、第三层：消息留得下来

告警消息在应用里**最多保留 7 天**，过期自动消失。要靠某条告警做凭据的，当天就用录屏把对应片段存进手机（做法见 [手机远程看家的正确用法](手机远程看家的正确用法.md)）；要长期留存事件录像，靠云存储套餐或机身存储卡。

## 四、快速自查表

| 现象 | 先查 | 再查 |
| --- | --- | --- |
| 完全收不到推送 | 系统里应用的通知权限 | 应用内该设备的推送开关 |
| 白天推、晚上不推 | 手机是否进了免打扰或省电模式 | 夜视切换时事件是否被判为噪音 |
| 有人走却不推 | 侦测区域是否正好排除了那一块 | 灵敏度是否过低 |
| 猫走过也推 | 是否开了人形检测 | 灵敏度是否过高 |
| 只在看实时画面时不推 | 正常行为，不用改 | —— |

排查下来发现是设备本身连不上网络、频繁离线，先回 [摄像头怎么添加与配网](摄像头怎么添加与配网.md) 把链路理顺，再回来调这些开关。
