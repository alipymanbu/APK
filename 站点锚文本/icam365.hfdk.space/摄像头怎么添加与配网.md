# 摄像头怎么添加与配网

> 家用摄像头是**先通电、再由手机端带着它连进家里 WiFi** 的，这一步做完它才会出现在应用首页。
> 这一篇把扫码、热点、网线三种添加方式拆开讲，并附上配网卡住时按层排查的顺序。
> **相关文章**：[手机远程看家的正确用法](手机远程看家的正确用法.md) · [告警误报太多怎么调](告警误报太多怎么调.md)

iCam365 是家用摄像头的手机端应用，摄像头本体负责驻守，添加与配网都要在这块小屏幕上完成。
完整的图文版（含安装包获取入口）在 [iCam365 看家手册](https://icam365.hfdk.space/)，下面先把关键路径说清。

## 一、动手前先确认四件事

1. **摄像头已通电并等够时间**：接上电源约 1 分钟，听到开机提示音再操作；一直没声音先长按机身 Reset 键重置。
2. **手机已登录账号**：添加设备会绑定到当前登录的账号，没账号先注册。
3. **WiFi 是 2.4GHz 且没被隐藏**：摄像头只认 2.4GHz，5GHz 它扫不到；双频合一的路由器建议先在后台拆成两个名字。WiFi 名称与密码尽量只用字母数字，别带特殊符号。
4. **安卓手机打开定位服务**：添加设备要用到定位权限，当时拒绝了可能出现一直添加不成功的情况。

## 二、三种方式怎么选

| 方式 | 原理 | 适合情况 |
| --- | --- | --- |
| 扫码添加（推荐） | 手机先连家里 WiFi，再把屏幕上的二维码给摄像头看 | 机身二维码清晰可识别的绝大多数情况 |
| 快速添加（AP 热点） | 手机先连摄像头自己发出的热点，再把 WiFi 信息交给它 | 二维码破损、识别失败 |
| 有线添加 | 摄像头直接用网线接路由器 | 摄像头旁有网口，或无线环境复杂 |

扫码的完整动作：应用里点「+」扫机身底部或背面的二维码 → 选家里 2.4GHz 的 WiFi 并输入密码 → 把屏幕上的二维码对着镜头（距离 10~30 厘米）→ 听到「扫码成功」后等它自动联网，整个过程约半分钟到一分钟。

## 三、卡住了，按提示音排查

摄像头是「用嘴报进度」的，听它说到哪一句：

- 没听到「请配置摄像头」这类开场提示 → 设备没进配网模式，先重置再来；
- 停在「正在连接 WiFi」→ 核对密码是否填错、路由器距离是否太远、WiFi 是否隐藏；
- 停在「正在连接网络」→ 连上了路由器但连不上服务器，看家里宽带是否正常、下挂设备是否过多；
- 说了「网络已连接」但首页没画面 → 回应用里刷新设备列表，仍不见就重启摄像头再试。

## 四、挪位置、换网络、换账号

- 换 WiFi：进设备设置里的网络选项重新选网填密码；接网线的机型拔线后要重新上电才会去连 WiFi。
- 挪到别的房子：通电后首页会显示设备断开，从故障排查入口重新走一遍配网。
- 换路由器或改了 WiFi 密码：摄像头不会自己跟着变，先重置再重新配一次。
- 换账号：摄像头与账号一对一绑定，先在当前账号里解绑，新账号才加得进来；家人想一起看，走设备分享而不是共用账号，详见 [手机远程看家的正确用法](手机远程看家的正确用法.md)。
