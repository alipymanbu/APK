# 手机远程看家的正确用法

> 摄像头连上网之后，日常就剩两件事：看现在的画面、回找刚才的录像。
> 这一篇把首页实时操作、时间轴回放的两种来源、片段保存与家人共享一次说清。
> **相关文章**：[摄像头怎么添加与配网](摄像头怎么添加与配网.md) · [告警误报太多怎么调](告警误报太多怎么调.md)

用 iCam365 看家的完整图文（含安卓安装包入口）整理在 [iCam365 看家手册](https://icam365.hfdk.space/)，
这篇把手机端的日常操作摊开讲。

## 一、首页与实时画面

登录后首页就是设备列表，一台摄像头一张卡片，当前画面与在线状态直接铺在卡片上。点进单台设备，常用动作都在大画面里：

| 想做的事 | 在哪操作 | 留意点 |
| --- | --- | --- |
| 换清晰度 | 画面的清晰度入口 | 用流量看时先降一档 |
| 横屏大图 | 右下角全屏按钮 | 系统横屏锁定要先解开 |
| 听现场声音 | 声音开关 | 默认常是关的，听不到先开它 |
| 对讲 | 麦克风按钮 | 按住说话松开送出，一般同时只能一方说 |
| 转动镜头 | 方向方向盘 | 仅云台机型有，固定机型没有 |
| 截图 | 截图按钮 | 直接进手机相册，留证据最省事 |
| 多路同看 | 多宫格预览 | 路数越多对网络压力越大 |

有个容易误判的点：正开着实时画面看这台设备时，应用不会再额外推一条通知——画面就在眼前，它判定没必要。所以「盯着看的时候不推」是正常行为，不是故障。

## 二、回放：按时间轴找那一段

回放页是一条可拖动的时间轴，页面上有「卡录像 / 云录像」的切换：

- **卡录像**：存在摄像头机身的存储卡上，能翻多久取决于卡的容量与清晰度；
- **云录像**：开了云存储套餐才有，按套餐保留最近若干天。

时间轴是空的或只有一小段，常见原因就四类：设备刚装还没录上；存储卡没插好没被识别；云服务到期而机身又没有可用卡；这段时间断电或断网。

## 三、把片段带走

看到要留的那一段，用回放画面的**录屏**按钮：开始、停止，文件就进了手机相册或应用本地文件。
只要一帧证据用**截图**更快。本地卡和云端都是给回看用的，要长期保留、要发给别人的，一律先截图或录屏存出来——告警消息在应用里最多只保留 7 天，过期的通知会消失。

## 四、家人一起看，走分享不走共号

一台摄像头最多分享给 10 个账号：对方装好应用登录后，由设备主人发起分享，家人在自己的账号里就能看。同一账号同一时间只能在一台手机登录，所以共用账号会互相顶下线——正确姿势始终是分享而不是把密码发出去。

想收回分享、或要把摄像头挪到别人账号下，前者在分享管理里移除即可，后者必须先解绑再重新添加（配网相关的坑见 [摄像头怎么添加与配网](摄像头怎么添加与配网.md)）。

## 五、画面转圈加载不出来

转圈是还在加载，不是卡死，按这个顺序判断：

1. 换个网络再看，或换一台手机比对——别的手机流畅，问题就在原来那台的网络；
2. 降一档清晰度，流量看先切回 WiFi；
3. 看家里宽带是否被占满；
4. 时间轴能拖但画面黑，多是云端与网络一侧的问题；连时间轴都拉不动，回到 [摄像头怎么添加与配网](摄像头怎么添加与配网.md) 查设备在线状态。

看完画面别忘了把告警也调顺：有人走过却不提醒、猫经过乱推，处理思路见 [告警误报太多怎么调](告警误报太多怎么调.md)。
