# 视频通话活动购票流程

> 在应用里和偶像真人视频通话是这款平台最抢手的活动形式，本篇按活动页的通行规则整理购票、入场与通话当天的注意事项，帮第一次报名的粉丝避开常见失误。
> **相关文档**：[人气歌谣预投票怎么投](人气歌谣预投票怎么投.md) · [粉丝积分攒分途径一览](粉丝积分攒分途径一览.md)

## 一、活动有哪几种形态

艺人间接互动主要有两类：1:1 视频通话（Meet & Call / Relay Call）和双人合影（Two-Shot，与艺人同框拍照留念）。两类活动都在应用内的活动房间（Event Room）进行，票从活动页购买。

## 二、购票规则

下表是活动页列出的通行规则，个别场次可能有差异，报名前以活动页说明为准：

| 项目 | 规则 |
| --- | --- |
| 单张票 | 1 分 30 秒通话时长 |
| 单账号上限 | 8 张（8 张 = 12 分钟） |
| 时长累加 | 2 张 3 分钟、4 张 6 分钟，以此类推 |
| 取消/退款 | 开演前 72 小时内不可取消；退改找客服 |
| 入场方式 | 售票截止后，含入场码的参与邮件发到注册邮箱 |
| 通话地点 | 应用内的活动房间 |

**购票前先把昵称设好**——通话时艺人按昵称称呼你；购票截止后再改昵称，可能会无法参加活动。

## 三、通话当天注意什么

- 提前进入应用内的活动房间，留意现场公告；
- 保证网络稳定，提前在系统设置里允许相机与麦克风权限；
- 参与邮件在售票截止后才发出，收不到先确认登录的还是当初购票的那个账号——每种登录方式各算一个独立账号，换方式登录看到的是另一个空账号；
- 通话顺序与开始时间可能按进度调整，人不在就可能错过自己那一场；
- 没接通时系统会重拨，最多 3 次；3 次都未到场按取消处理、不退款；
- 聊天消息看不懂：去 Settings → Language → Translation 设置翻译语言。

## 四、常见失误清单

| 失误 | 后果 |
| --- | --- |
| 购票截止后才改昵称 | 可能无法参加活动 |
| 错过通话时间 | 重拨 3 次未到场按取消处理，不退款 |
| 没给相机/麦克风权限 | 通话画面或声音异常 |
| 网络不稳 | 掉线，白白消耗有限的通话时长 |
| 没留意参与邮件 | 找不到入场码，进不了活动房间 |

热门场次经常直接售罄，可以留意后续场次，或转向私信订阅这类长期通道。

## 五、从哪里开始

还没装应用的，先看 [LiNC 粉丝互动平台介绍与安卓安装包资源](https://linc.qhah.skin/)，装好注册完再回来报名活动；活动里拿到的签名卡、小卡想长期保存，可以了解同厂牌的数字小卡应用 tin，日常投票消耗的积分则见 [粉丝积分攒分途径一览](粉丝积分攒分途径一览.md)。
