## 一句话定位

Agora 是一款开源的安卓 LLM 客户端，走的是 **BYOK（Bring Your Own Key，自带密钥）** 路线：它本身不带任何模型，
你填入哪家的 API 密钥，它就直连哪家的服务。对话记录保存在手机本地，请求由设备直接发给你选择的服务商，
中间没有中转服务器。

由独立开发者 Newo Ether 用 Kotlin 编写，界面基于 Material 3，在 F-Droid、Google Play 与 GitHub Releases
这些公开发布渠道都能找到它。

## 核心功能一览

- **多服务商直连**：内置 OpenAI、Anthropic（Claude）、Google Gemini、DeepSeek、通义千问（DashScope）、
  OpenRouter、OpenCode Go、Groq、Ollama、本地 llama.cpp 十类提供商，另支持 OpenAI 兼容 / Google /
  Anthropic 三种协议的自定义端点；
- **树状对话**：编辑或重新生成任意一条更早的消息，旧回答保留在另一条分支上，方便对照不同问法的结果；
- **上下文压缩（Context Compact）**：4K 到 1M token 的预算自定，压缩不破坏原文、最近的对话逐字保留；
- **智能体工具**：联网搜索（Brave / Serper / Tavily / SearXNG）、长期记忆、历史对话语义检索、图像生成、
  MCP 服务器接入、远程 Shell 与文件操作、Tasks/Loops 定时任务、Alpine 沙盒；
- **本地推理**：通过 llama.cpp 在手机上运行 GGUF 格式开源模型，embeddings 也在本机完成，断网可用；
- **数据可搬**：`.agora` 版本化 ZIP 归档导入导出、支持从 ChatGPT / Claude 迁移历史记录、定时自动备份；
- **界面本地化**：12 种界面语言（含中文），主题、字体、触感反馈可调。

## 适合谁用

- 手里已经有多家模型账号或 API 密钥，想在同一部手机上集中切换的人；
- 在意对话数据留在本机、不想经过第三方中转的人；
- 想在没网的环境下继续用开源模型干活的用户。

## 与常见 AI 助手应用的区别

常见助手应用把模型服务包在自家账号体系里，按订阅收费；Agora 不碰模型本身，只做客户端——模型能力来自你
自己的密钥或本地模型文件，用量与费用跟着各家服务商走。这也是它开源的意义：代码可查，数据边界写在明面上。
