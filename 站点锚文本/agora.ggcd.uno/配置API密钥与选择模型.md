# Agora 配置API密钥与选择模型的方法

> 本篇面向第一次启动 Agora 的用户，讲清楚从拿到密钥到发出第一条消息的完整链路。
> 相关阅读：[是什么软件与核心功能](是什么软件与核心功能.md)、[离线使用本地模型](离线使用本地模型.md)。
> 更多细节见 [Agora 介绍站](https://agora.ggcd.uno/)。

---

## 前提：准备密钥

Agora 是 BYOK 客户端，调用云端模型前需要先在各家服务商那里拿到 API 密钥：
OpenAI、Anthropic、Google Gemini、DeepSeek、通义千问、OpenRouter、Groq 都在各自的控制台页面生成。
只打算用本地模型的话，这一步可以整个跳过。

## 第一步：进入设置添加提供商

打开应用左侧抽屉 → **设置** → **Providers**，选择服务商类型后把密钥填进去。Agora 内置了十类提供商，
如果你的服务商不在列表里，选自定义端点并挑对应协议（OpenAI 兼容 / Google / Anthropic），
中转站与私有部署的服务也能接。

## 第二步：同步并启用模型

进入 **Models** 页同步该服务商下的可用模型，把要用的勾选启用。不同服务商的模型会集中出现在
同一个选择器里，切换时不用来回退出。

## 第三步：回到底部选模型，发第一条消息

回到对话界面，在输入框下方的模型选择器里挑一个，直接开聊。树状对话在这一步就能用上：
任何一条消息都可以编辑后重新生成，旧回答留在另一条分支里。

## 常见问题

- **密钥保存在哪里？** 密钥由 Android Keystore 以 AES-GCM 加密保管，不随对话导出。
- **要不要注册 Agora 自己的账号？** 不需要，它没有账号体系，密钥直接对接各家服务商。
- **怎么换成中文界面？** 设置 → 语言，内置 12 种界面语言，见
  [离线使用本地模型](离线使用本地模型.md) 末尾的说明。
