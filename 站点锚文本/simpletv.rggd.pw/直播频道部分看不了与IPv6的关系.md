# 直播频道部分看不了与IPv6的关系

> 本篇回答一个高频问题：直播应用装好了，为什么有的台能看、有的台永远转圈？多数情况下答案是 IPv6。应用本身的介绍与获取入口见[电视盒子装直播应用从哪里下](电视盒子装直播应用从哪里下.md)，先弄清这类应用的价值可以读[内置频道源的直播应用怎么样](内置频道源的直播应用怎么样.md)。

---

一个很典型的场景：直播应用装好后，央视几个台播得顺顺当当，换到某几个台就一直"播放失败，网络连接超时"。换个台又好了，重启应用也没用。这时候问题多半不在应用，而在网络——那几个台只有 IPv6 的流，而当前的网络走不了 IPv6。

## 为什么偏偏是 IPv6

直播频道的流来源不一，有的频道源同时提供 IPv4 和 IPv6 两条路，有的只保留了 IPv6 一条。以 SimpleTV 这类内置源的应用为例，部分频道就只提供 IPv6 流：普通宽带下大部分台正常，少数台在纯 IPv4 网络里永远连不上。这不是个别应用的怪癖，而是国内 IPv6 普及过程中的常见现象。

好消息是，移动网络侧的普及度已经很高：2019 年起新入网的手机默认开启 IPv4/IPv6 双栈，近年来的安卓、iOS 系统也原生支持，所以用流量看基本不用操心。真正需要留意的，是家里的宽带、光猫和路由器这一段。

## 两分钟自测

用一台连着家里 Wi-Fi 的手机或电脑，浏览器打开 `test-ipv6.com`，页面会自动跑一轮测试：

- 结果 10/10，或提示已接入 IPv6 → 宽带侧没问题，个别台看不了与网络无关，属于线路波动，换个时间再看；
- 结果显示不支持、只有 IPv4 → 问题大概率出在光猫或路由器，往下看。

## 光猫与路由器怎么处理

测试不通过时，按这个顺序查：

1. **路由器**：登录管理页（地址通常印在机身标签上），在 IPv6 设置里把模式打开（常见选项是"自动"或"DHCPv6"），保存后重连 Wi-Fi 再测；
2. **光猫**：路由器开完还不行，可能是光猫没下发放行 IPv6。部分运营商的光猫支持用户自行开启，搞不定就打运营商客服，报"家里需要开通 IPv6"即可；
3. **复查**：改完再跑一遍 `test-ipv6.com`，通过后回到应用里，把刚才转圈的台重新加载一遍。

## 一个判断口诀

- **多数台正常、少数台转圈** → 那几个台是纯 IPv6 源，按上面的流程开 IPv6；
- **多数台都转圈** → 与 IPv6 无关，先看宽带本身是否连通、应用是否需要更新；
- **全都报播放失败** → 先换网络（比如手机热点）验证是应用问题还是网络问题。
