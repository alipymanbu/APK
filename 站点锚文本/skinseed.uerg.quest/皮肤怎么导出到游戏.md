# 皮肤怎么导出到游戏：基岩版与 Java 版各一条路

> 本篇讲画好的自定义皮肤怎么穿到《我的世界》角色身上：手机基岩 / PE 版的直接导出、电脑 Java 版的手动上传，以及网易国服为什么走不通、失败时常见的原因。
> **相关文档**：[我的世界皮肤怎么做.md](我的世界皮肤怎么做.md) · [皮肤编辑器哪个好用.md](皮肤编辑器哪个好用.md)

## 一、先分清玩的是哪个版本

皮肤能不能"一键进游戏"，取决于版本而不是工具：

| 版本 | 皮肤入口 | 自定义皮肤方式 |
| --- | --- | --- |
| 手机基岩版 / PE | 更衣室 | 编辑器导出后直接生效 |
| 电脑 Java 版 | 启动器与官网的换肤页 | 上传皮肤图片文件 |
| 网易国服 | 游戏内装扮系统 | 独立体系，外部皮肤进不去 |

## 二、手机基岩版 / PE：直接导出

在编辑器里画完（或从库里改完）皮肤后，用导出功能把皮肤送进游戏，回到更衣室就能看到新造型。这是最短的一条路。

导出前两个习惯值得养：

1. **先转 3D 预览**：正、背、侧、顶扫一圈，头顶和脚底是最容易漏看错格的角度；
2. **命名或收藏**：同一个人做多套造型时，随手整理，之后换装不翻找。

## 三、电脑 Java 版：借道相册

Java 版吃的是皮肤图片文件，走法是绕一下：

1. 在皮肤详情里选「保存至照片」，皮肤以图片形式存进手机相册；
2. 把这张图传到电脑（数据线、云盘、聊天工具传文件均可）；
3. 在 Java 版的换肤入口上传这张图，进游戏确认生效。

注意别对图片二次裁剪或压缩——展开图的格子位置是精确对齐的，裁掉一条边，穿到角色身上就会错位。

## 四、国服玩家怎么办

网易代理的国服有一套独立的皮肤与装扮体系，外部工具导出的皮肤对国服不适用，这不是某个编辑器的缺陷，而是两套系统的差别。国服玩家可以在游戏内的装扮渠道里挑选造型，或在国际服里体验自定义皮肤。

## 五、导出没生效，常见三个原因

- **模型对不上**：皮肤按经典手臂画，角色却用的 Slim 模型（或反过来），手臂区域会显示错乱——导出前确认两者一致；
- **图片被改动**：相册同步、二次裁剪改变了展开图尺寸，重新导出一份原始图即可；
- **版本没刷新**：游戏还在跑旧造型时，退回更衣室重进一次一般就好。
