# Prisma 照片变油画完整玩法

> 本篇讲用 Prisma 把普通照片变成油画、插画一类画面效果的完整路子：选什么样的照片、每一步点什么、出了不满意的结果怎么补救。强度滑杆的具体调法见 [风格强度调节技巧.md](风格强度调节技巧.md)。

Prisma 是安卓上的一款照片艺术化应用，开发者是 Prisma Labs。它和常规修图工具的思路不同：不是调亮度、加贴纸，而是把相册里的整张照片重新「画」一遍——按应用商店介绍的口径，风格库有五百种以上，覆盖油画笔触、插画描边、波普色块、马赛克拼接等大类，并且每天会放出一款新风格。注意它不做「输入一段文字生成一张图」那类创作，操作对象始终是你提供的照片。

## 一、什么样的照片容易出效果

效果好坏，一半在照片本身。被多方教程反复验证的规律有四条：

- **原图清晰、对焦准**——糊图经过重绘只会更糊；
- **光线均匀**——大背光、大逆光的照片，重绘后暗部细节基本没了；
- **主体占比大**——画面里主体越大越完整，风格越有地方「落笔」；
- **背景别太乱**——杂乱背景配浓重风格容易整团糊，适当留白反而出效果。

## 二、从选图到出图的步骤

1. 打开应用，在首页点「+」从相册选图，也可以当场拍一张（用系统相机拍好再导入，成片质量通常更好）；
2. 需要的话先裁剪、旋转——导出按 1:1 方图处理，主动按方形预裁比被动裁留得住重点；
3. 点「下一步」进入风格选择页，底部横排点一个风格，等几秒到十几秒出预览；
4. 不满意就换风格，或按 [风格强度调节技巧.md](风格强度调节技巧.md) 里的滑杆收一收浓度；
5. 满意后点保存，成品直接进系统相册，发社交平台时勾「原图」少被二次压缩。

整个处理和保存的流程不依赖注册账号，社区功能的登录需求以应用内提示为准。

## 三、效果不理想时的三步补救

1. **先降强度**——大多数「翻车」是风格太浓，收回 50% 以下再看；
2. **再换风格**——同一张图至少试三个风格再下结论；
3. **最后换图**——原图太糊、太暗、主体太小，怎么调都救不回来。
