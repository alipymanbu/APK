# 手机上浏览 GitHub 的开源客户端

> 这篇梳理安卓端浏览 GitHub 内容的第三方开源选择 Gloom：它能把哪些内容读顺、哪些操作要回网页端，以及和 GitHub 自家客户端怎么分工。
> **相关文档**：[壁纸取色界面怎么玩.md](壁纸取色界面怎么玩.md)

## 它解决什么问题

在手机上点开一个 `github.com` 链接，网页端往往要先加载一整套桌面布局，翻目录、读 Issue 都费劲。Gloom 是 MateriiApps 出品的开源客户端（GPL-3.0 许可），把这些内容重新排进原生界面：仓库文件树、代码高亮、Markdown 渲染、Issue 与 PR 的完整讨论串、Release 记录，全部按移动端的节奏铺开。

它的定位是「浏览型」：看得全、翻得顺，但不动键盘改代码。能替你完成的写操作只有三类——Star / 取消 Star、关注 / 取关、给 Issue 和 PR 加表情回应；新建 Issue、写评论、合并 PR 这类协作动作都交回网页端。边界摆得清楚，用起来反而不会别扭。

## 和 GitHub 自家客户端怎么分工

两者装在同一台手机上互不冲突，按场景分工即可：

| 场景 | 更顺手的工具 |
| --- | --- |
| 通勤时读仓库、追 Issue、翻 Release | Gloom |
| 收 Issue / PR / 构建状态的推送通知 | GitHub 自家客户端 |
| 需要评论、审核、合并等协作操作 | 网页端或自家客户端 |
| 收藏项目、跟进作者动态 | Gloom（Star 与关注跟着账号走） |

Gloom 没有通知中心，盯某个仓库的动静要回来手动刷；反过来说，它也没有常驻后台的推送，不打开就不跑流量。

## 上手需要准备什么

- **系统**：安卓 5.0 及以上；完整的壁纸取色体验要安卓 12 以上。
- **账号**：走 GitHub 的 OAuth 授权登录，密码只输在 GitHub 自己的页面，客户端拿到的是授权凭证。
- **网络**：登录与内容都走 `github.com`，网络到不了的话装上了也走不到第二步。
- **体积**：安装包 25M 上下，装完占用大致相当。

想看完整的功能盘点与界面细节，可以逛逛这篇第三方整理：[Gloom 安卓客户端介绍站](https://gloom.laze.skin/)，里面把取色玩法、功能边界与安装步骤分开讲清楚了。

## 上手后的两个小习惯

1. **把 Star 当收藏夹**：想到什么就 Star 一下，列表跟着 GitHub 账号走，换设备也在；找同类项目时翻自己的 Star 列表往往比再搜一遍快。
2. **关注作者而不是只 Star 仓库**：关注能持续收到作者的新动作，只 Star 仓库的话，信息流里只有那个仓库自己的动静。

装的过程中遇到「解析包错误」「应用未安装」这类拦截，多数是下载不完整或权限没放行，介绍站的安装页把这几步拆开讲过一遍，对着处理即可。
