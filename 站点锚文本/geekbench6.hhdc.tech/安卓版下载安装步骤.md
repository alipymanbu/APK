# Geekbench6 安卓版下载安装步骤：从网盘到第一次跑分

装一个跑分工具不需要任何技术背景，整个过程可以概括成四步：取资源、下载、安装、开跑。
下面按顺序拆开讲，每一步可能遇到的小状况也一并说明。

## 第一步：把安装文件资源转到自己名下

资源放在夸克网盘里，打开 [Geekbench6 跑分解读站](https://geekbench6.hhdc.tech/) 的下载页，
点「获取安装文件资源」会跳到网盘分享页：登录网盘账号，先把资源**转存**到自己的网盘，
再从自己的网盘列表下载到手机。转存这一步别省——分享链接可能变动，转存到自己账号后
资源就长期稳了。

## 第二步：在手机上打开安装包

下载完成后，从通知栏或文件管理的下载目录里找到 APK 文件点开。安装包约 443 MB，
开始前确认手机存储空间充足；中途中断的下载包容易导致安装失败或打开闪退，
遇到异常就重新下载一遍。

## 第三步：放行「未知来源」提示

安卓系统默认只允许从应用商店安装，第一次装会弹出「禁止安装未知来源应用」的提示。
在弹窗里选择允许来自此来源的应用即可继续；部分机型入口在
「设置 → 安全 → 更多设置」里，按应用单独放行。装完建议把开关收回，不影响已装好的应用。

## 第四步：打开 app，跑第一次分

同意使用条款进入主页，先核对机型、系统与 CPU 信息识别是否正确，然后点
**Run CPU Benchmark**。测试全自动，通常几分钟到十几分钟；跑之前清空后台、
别插充电器，成绩更接近真实水平。跑完除了单核与多核分数，往下滑还有整套
System Information 可核对。

## 装不上时的三条快查

- **点安装没反应 / 安装被阻止**：系统在拦未知来源，按第三步放行后重新打开安装包；
- **打开就闪退**：确认系统为 Android 10 及以上、安装包完整（重新下载一次最省事）；
- **网盘页打不开 / 转存失败**：先登录网盘账号，或换个浏览器稍后再试。

装好之后怎么读分、怎么和别的机型比，见
[手机跑分成绩怎么看](手机跑分成绩怎么看.md)；想知道它和安兔兔的分工，
见 [和安兔兔跑分有什么区别](和安兔兔跑分有什么区别.md)。
