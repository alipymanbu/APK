## 先认清三大板块

打开客户端，顶栏三个标签页就是它的骨架：

- **图片模型**：模型广场。按爆款 Top、新热 Top、摄影写真等栏目组织，模型卡上直接给「使用模型」按钮。写实、动漫、国风、电商海报各有专属模型，Qwen-Image-Edit、F.1 Kontext 这类编辑型模型也能在手机上一键调用；
- **视频特效**：把热门玩法做成打开即用的一键模板——节日舞蹈、商品揭秘登场、镜像万花筒之类，挑一张照片或一段素材，点「使用」就等出片；
- **发现灵感**：作品流。看中哪张点「创作」或「做同款」，提示词与参数一并复用，改几个词就是自己的版本。

## 创作链路：四步一条线

1. **选模型或模板**：讲究风格就在模型广场挑大模型，再叠加风格模型；想快就去特效页拿现成模板；
2. **写画面描述**：主体、场景、风格、画质逐段写清楚。Seedream 一类模型对中文友好，要让画面里出现文字时，把文案用双引号括起来识别更准；
3. **一键生成**：出图消耗算力，用量与模型、参数相关。结果有随机性，不满意就换个措辞多跑两三次；
4. **保存与分享**：成品收进资产页，按生成方式与日期检索、批量下载；分享出去的作品，别人可以一键复刻参数。

## 六条立刻能用的提示词技巧

| 场景 | 做法 |
| --- | --- |
| 强调重点 | 想突出的词用 `(词:1.3)` 括号加系数，数值越高越突出 |
| 排除干扰 | 不想要的元素写进负向提示词（多余手指、模糊、水印） |
| 精细度 | 迭代步数取 20–30，越高越精致但越耗时 |
| 服从度 | 引导系数取 7–12，低了跑偏、高了画面僵 |
| 风格叠加 | Qwen-Image / F.1 支持同时叠 3 种风格，打架时把强度各调 0.2–0.3 |
| 带字海报 | 用支持文字渲染的模型，需要出现的文案用双引号括住 |

## 新手第一周怎么练

- 前两天只玩「发现灵感」的做同款，先建立「描述 ↔ 画面」的对应感；
- 第三四天换成自己在模型广场选模型、从零写提示词，对照灵感页的成品找差距；
- 周末试一次视频特效模板，感受一下照片变短片的效果。
