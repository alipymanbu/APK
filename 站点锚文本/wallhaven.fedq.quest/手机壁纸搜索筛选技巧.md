# 手机壁纸搜索筛选技巧

> 本篇讲在 wallhaven 客户端里怎么快速找到适配手机屏幕的图：分类、分级、排序、分辨率与搜索框写法。
> **相关文章**：[安卓壁纸客户端安装步骤](安卓壁纸客户端安装步骤.md) · [桌面锁屏壁纸设置方法](桌面锁屏壁纸设置方法.md)

## 一、先认识筛选体系

客户端接的是壁纸社区 wallhaven.cc 的公开接口，筛选逻辑与网页端同一套：

- **分类**三个：General（综合：风景、建筑、抽象、太空）、Anime（动漫绘画）、People（人物摄影与绘画）。
- **级别**：默认展示适合公开场合的两级；第三级要在 wallhaven.cc 注册账号、生成 API 密钥填进应用后才会出现。
- **排序**：最新（默认）、热门榜（可选近 1 天到近 1 年六档范围）、随机、按浏览量、按收藏量。

## 二、按屏幕挑图

壁纸库里横版桌面尺寸占大头，手机直接用会被裁掉两侧。两个做法：

- **按比例筛**：手机用户在比例选项里选竖版方向（9x16 一类），列表方向就和屏幕一致。
- **按分辨率筛**：知道自己屏幕参数（如 1080x2400）就填精确值；只想排除太小的图，用「最小分辨率」选项。

每页 24 张，翻到底自动加载下一页；先收紧比例再收紧分辨率，能少翻很多页。

## 三、搜索框里能写什么

| 写法 | 作用 | 示例 |
| --- | --- | --- |
| `关键词` | 模糊匹配标签 | `mountains` |
| `-标签` | 排除某标签 | `landscape -snow` |
| `+A +B` | 两个条件都要有 | `+sunset +sea` |
| `@用户名` | 只看某人的上传 | `@username` |
| `type:png` | 指定文件类型 | `type:png` |
| `like:ID` | 找标签相似的其他图 | `like:94x38z` |

几个实用提示：

- 标签以英文为主，搜中文大概率无结果，「星空」用 night sky 或 stars。
- 点开任何一张图的标签，就是按它重搜一遍——从一张好图挖出一串同类图的捷径。
- 每张图自带主色板标注，想配桌面图标主题时先定主色再筛。
- 没有明确目标时不用搜索：直接切最新流、热门榜或随机刷。这些玩法的入口与机制，在 [wallhaven 安卓客户端](https://wallhaven.fedq.quest/)介绍站里有更完整的整理。
