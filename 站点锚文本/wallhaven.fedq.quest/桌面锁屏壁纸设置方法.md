# 桌面锁屏壁纸设置方法

> 本篇讲挑好图之后怎么落地：下载、裁剪、分别设为桌面或锁屏，以及设完又被改回去这类小麻烦。
> **相关文章**：[手机壁纸搜索筛选技巧](手机壁纸搜索筛选技巧.md) · [安卓壁纸客户端安装步骤](安卓壁纸客户端安装步骤.md)

## 一、从找到图到上屏

1. 浏览或搜索找到目标图（精准找图的方法见[手机壁纸搜索筛选技巧](手机壁纸搜索筛选技巧.md)）。
2. 点开大图下载；下载界面支持编辑、裁剪、缩放，可以按自己屏幕裁好再保存。
3. 到下载列表里找到刚保存的图，点「设置壁纸」。
4. 选择应用目标：桌面或锁屏，两者分开设置、互不影响。

全程不需要登录账号——API 密钥只影响能看到哪些内容级别。

## 二、裁剪与尺寸

- 保存的是原图文件，不做二次压缩；原图什么分辨率，存下来就是什么分辨率。
- 横版图直接设为竖屏壁纸会裁掉两侧，人物图容易把主体裁出画面。两个办法：设置前手动裁剪把主体框进竖版区域；或者挑图时就按竖版比例筛，从源头少裁。

## 三、设完又被改回去

| 原因 | 现象 | 处理 |
| --- | --- | --- |
| 系统主题自带轮换 | 隔天或重启后变回默认 | 关闭系统壁纸轮换 |
| 装了其他壁纸类工具 | 不定时被换 | 找到对应工具关掉自动更换 |
| 深色模式联动 | 切深色模式时被换 | 在显示设置里解除联动 |
| 分辨率不符被缩放 | 上屏后模糊或裁切异常 | 换更贴近屏幕分辨率的图 |

## 四、图删了还能找回

本地误删的图，记得壁纸 ID 就能重新搜出来再下一遍；不记得 ID 就用标签或相似搜索找回同类。还没装客户端的，从 [wallhaven 安卓客户端](https://wallhaven.fedq.quest/)介绍站的下载页拿安装包，装法见[安卓壁纸客户端安装步骤](安卓壁纸客户端安装步骤.md)。
