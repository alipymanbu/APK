# 安卓壁纸客户端安装步骤

> 本篇讲把 wallhaven 安卓客户端装到手机上的完整流程：从夸克网盘拿安装包、允许未知来源、装完首次打开会看到什么。
> **相关文章**：[手机壁纸搜索筛选技巧](手机壁纸搜索筛选技巧.md) · [桌面锁屏壁纸设置方法](桌面锁屏壁纸设置方法.md)

## 一、装之前

- 系统版本：安卓 5.2 及以上，低于这个版本装不上。
- 存储空间：安装包不到 8 MB，但之后保存的壁纸原图（2K、4K 居多）会持续占空间，建议预留几百 MB。
- 这个客户端不在应用商店里分发，安装时系统会拦一道，属于正常现象，下面第二步会处理。

## 二、四步装好

1. 打开 [wallhaven 安卓客户端](https://wallhaven.fedq.quest/)介绍站的下载页，点「获取安装文件资源」进入夸克网盘分享页。
2. 把安装包转存到自己的网盘，再用夸克 App 把 APK 下载到手机存储。
3. 点开 APK，系统首次会询问「来自此来源的应用」，选择允许；如果直接被挡，去系统设置搜「安装未知应用」，给浏览器或文件管理器授权后再点一次。
4. 等待安装完成，点「打开」——不要求注册登录，直接落在壁纸大厅，上下滑动就能刷图。

## 三、装完之后

- 想解锁更多内容级别，去 wallhaven.cc 注册账号生成 API 密钥，应用内「设置 → API 密钥」粘贴后重启生效；不填也不影响刷图和下载。
- 挑图、筛图的门道看[手机壁纸搜索筛选技巧](手机壁纸搜索筛选技巧.md)；把图设成桌面或锁屏的步骤看[桌面锁屏壁纸设置方法](桌面锁屏壁纸设置方法.md)。
- 装完打不开或闪退：重启手机、清缓存、清数据、卸载重装，按这个顺序走，多数到重装一步就解决。另外同名客户端不止一个，如果之前装过别家的版本，建议先卸载再装，避免互相干扰。
