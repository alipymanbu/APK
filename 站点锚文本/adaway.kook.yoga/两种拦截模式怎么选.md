# 本地 VPN 和系统 hosts，两种拦截模式怎么选

同一个安卓广告拦截工具，AdAway 给了两条运行路线：免 Root 的本地 VPN 模式，和已 Root 的系统 hosts 模式。装的是同一个安装包，区别在拦截发生的位置和各自的代价。

## 本地 VPN 模式：为不 Root 的设备准备

工具在手机上建一条**只在本机工作**的 VPN 通道，所有出站连接先经过它：目标域名在广告名单里的，连接直接断开；不在名单里的，原样放行。

- 优点：不解锁、不刷机，装上就能用；关掉工具通道即撤，系统恢复原样；
- 代价一：通道被占用——安卓同一时间只允许一条 VPN，再开别的 VPN 应用前得先停掉它；
- 代价二：过滤层常驻后台，耗电略增（幅度看机型和使用强度）。

## 系统 hosts 模式：为已 Root 的设备准备

设备已经解锁并刷了 Root 方案（比如 Magisk 的 Systemless Hosts），可以把名单直接写进系统 hosts 文件。解析在系统层就被改写，广告域名指向本地地址，请求根本发不出去。

- 优点：不占 VPN 通道、可与其它 VPN 共存；没有常驻过滤层，开销接近零；
- 前提：引导解锁与 Root 本身有门槛，也可能影响保修，折腾成本在前头。

## 一句话的选择标准

- 日常主力机：别为去广告专门 Root，本地 VPN 模式足够；
- 手上有现成 Root 的备用机或老机型：hosts 模式更省电、更彻底。

两种模式的原理展开和界面里的具体设置，可以到这个[AdAway 免 Root 拦广告的介绍站](https://adaway.kook.yoga/)看，页面上有一张双路对比和一张拦截流程示意。
