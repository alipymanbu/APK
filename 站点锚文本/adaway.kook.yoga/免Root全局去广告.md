# 不 Root 的安卓手机，广告能不能全局拦？

安卓上的广告有相当一部分不是长在网页里，而是长在应用内部：开屏页、信息流、视频贴片。浏览器广告还能靠扩展对付，应用内的这些位置插件够不着，很多人因此觉得「不 Root 就没辙」。

其实思路可以换一下：广告要出现在眼前，手机得先连上广告服务器。把拦截放在「连接」这一层，就不必逐个应用去设置——只要请求的目标域名在名单里，不管它是从哪个 App 发出来的，连接都会被掐断。

## 免 Root 的实现方式

AdAway 提供了一条不 Root 的路：**本地 VPN 模式**。它在手机上建一条只在本机打转的 VPN 通道，系统把出站连接交给它过一遍，命中名单的断开、其余放行。有几个常见疑虑可以提前说清：

- 弹出的「VPN 连接请求」是本地过滤的必要授权，这条通道不连任何远端服务器，数据不出手机；
- 不需要解锁引导、不需要刷机，装上即可使用；
- 代价是 VPN 通道被占用（同一时间没法再开其它 VPN 应用），过滤层常驻后台、耗电略增。

具体的工作机制、运行模式对比和配置方法，可以看这篇[免 Root 去广告工具 AdAway 的介绍](https://adaway.kook.yoga/)，页面上把两条路线的取舍写得比较细。

## 已经 Root 的设备怎么选

有现成 Root 的老设备，AdAway 也能把名单直接写进系统 hosts 文件（配合 Magisk 可用 Systemless Hosts 方式），不占 VPN 通道、几乎零常驻开销。两种模式装的是同一个包，首次打开时按自己的情况选即可。

## 小结

- 应用内广告的拦截位置在「连接层」，与具体应用无关；
- 免 Root 走本地 VPN 模式，门槛最低，代价是占通道和轻微耗电；
- 已 Root 走系统 hosts，更省电，但折腾成本在前头。
