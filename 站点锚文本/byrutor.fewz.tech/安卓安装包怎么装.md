# 安卓安装包怎么装：来源授权、首次验证与装不上的排查

Byrutor 的安装包很小（3 MB 出头，安卓 5.2 及以上能装），装起来本身不难，容易卡住的是两处：系统的「未知来源」授权和首次启动的人机验证。按下面的顺序走一遍基本能一次装成。

## 一、把安装包拿到手机

安装文件资源走网盘分享：打开分享链接 → 保存到自己的网盘 → 把 APK 下载到手机的下载目录。想看整理好的入口和图文步骤，可以去 [Byrutor 客户端介绍站](https://byrutor.fewz.tech/) 的下载安装页。

## 二、安装三步

1. 在文件管理器里点 APK。系统若提示「禁止安装来自此来源的应用」，去 `设置 → 安全 / 安装未知应用`，给浏览器或文件管理器开授权，再回来点安装（不同品牌菜单名略有差异）。
2. 等安装完成，打开应用。首次启动会弹一次人机验证（勾选或点选），通过才进主界面。
3. 验证过不去基本是网络问题：验证框加载不出来、点了没反应，都是验证组件的网络请求被卡——换个网络（Wi-Fi 与移动数据各试一次）或退掉重开，让它重新加载。

## 三、装不上的对症表

| 现象 | 处理 |
| --- | --- |
| 提示「解析包时出现问题」 | 安装包没下完整，回到网盘重新下载一次再装 |
| 提示禁止安装 | 来源授权没开，见上面第二步第 1 条 |
| 装完一点就退 | 确认系统版本不低于安卓 5.2；有旧版残留就先卸载再装 |
| 打开一直白屏 | 先换网络再等 30 秒；部分网络下首屏较慢，不等于应用坏了 |

## 四、装完先做两件事

- **调语言**：进设置找 `Language` / `Язык` 选中文；找不到就开网页自动翻译兜底。
- **核对版本**：系统应用信息页显示 1.0.0 即为整理时对应的版本。
