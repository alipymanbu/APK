# Geometry 锚文本目录

围绕「Geometry」这个关键词整理的三篇实用短文，均以第三方口吻介绍 GeoGebra 家族的动态几何应用 Geometry 在手机上的用法：从基础构造到具体作图任务，再到课堂演示场景。各篇的站点入口与截图对照见 [Geometry 动态几何画板介绍站](https://geometry.gerw.hair/)。

- [手机上怎么画几何图形.md](手机上怎么画几何图形.md) —— 徒手画与构造画的区别，以及动态几何画板的基本构造动作；
- [内切圆与外接圆的画法.md](内切圆与外接圆的画法.md) —— 两个高频作图任务的标准步骤与拖动验证；
- [勾股定理动态演示.md](勾股定理动态演示.md) —— 把定理变成「拖不烂的事实」的课堂演示思路。
