# 手机屏幕使用时长在哪里看？安卓查每天亮屏时间的方法

> 想知道自己每天在手机上花了多少时间、时间都花在哪些应用上？这篇把安卓上查屏幕使用时长的几种途径摆在一起说，并介绍一款专做统计的开源小工具 Screen Time。

## 一、系统自带的入口

现在主流安卓系统基本都内置了使用时长统计，入口名称各不相同：

| 系统 | 入口 |
| --- | --- |
| 原生安卓 / 部分国际机型 | 设置 → 数字健康与家长控制 |
| 华为 / 荣耀 | 设置 → 健康使用设备 |
| 小米 MIUI | 设置 → 屏幕时间管理 |
| OPPO / realme | 设置 → 应用使用时间 |

进去后能看到当天总时长、各应用耗时排行，部分系统还支持给应用设限额。日常粗略了解，这些入口已经够用。

## 二、系统统计的两个局限

1. **界面与数据随品牌走**：换一个牌子的手机，入口、图表样式、数据留存时长都会变，历史记录通常也带不走；
2. **功能常常和「管控」绑在一起**：限额、停用时段这些管控项占了大半个界面，单纯想看数字的人反而要翻找。

## 三、想要一份干净的统计：Screen Time

如果只想要一份**纯粹的时长统计**，可以试试 Screen Time——开发者 Atharok 做的开源安卓应用，界面遵循 Material 3，开箱即简体中文：

- 按天、按周、按小时三张对比柱状图，回答「今天用了多久 / 一周哪天最重 / 哪个钟点亮屏最勤」；
- 分应用排行榜从多到少排好，点进去还能看单个应用的独立图表；
- 无广告、无内购、**没有联网权限**，统计数据全程留在手机里；
- 安装包只有约 1.78M，老机型也能轻装运行。

更完整的功能介绍与界面截图，见 [Screen Time](https://screen-time.fewf.ren/) 介绍页；安装包的获取与首次授权步骤，介绍页的下载分区里也按顺序写清楚了。

## 四、小结

随手查一查，用系统自带入口就行；想要一份开源、不联网、各机型界面统一的统计视图，Screen Time 值得装一个。两类工具并不冲突，可以并存着用。
