# FluxDown 安卓版怎么装：从安装包到打开应用的完整流程

> 讲安卓手机上装 FluxDown 的完整过程：安装包从哪来、系统拦不拦、装完第一步做什么，以及两类最常见的安装报错怎么处理。

## 一、装之前先确认两件事

1. **机型与安装包**：FluxDown 的安卓包按 CPU 架构分（arm64-v8a / armeabi-v7a / x86_64），另有通用版——不确定自己机型就选通用版，体积大一点但都能装。
2. **来源要干净**：这个应用是开源的（AGPL-3.0 协议），但搜索结果里混着不少高仿站，发过带木马的假安装包。安装包只从可信网盘或可信发布渠道取，动手装之前先看一眼文件名与版本号是否对得上。

想先了解这个工具长什么样、引擎怎么跑，可以看 [FluxDown 介绍站](https://fluxdown.boop.uno/)，里面有真机界面截图和下载安装的入口。

## 二、四步装完

1. **把 APK 放进手机**：从网盘转存或下载到手机存储，完成后在通知栏点开，或去文件管理器找到这个 APK 再点开。
2. **允许这次安装**：第一次装会弹「未知来源 / 来源不受信任」的提示——这不是应用有问题，是系统按来源放行。按提示去设置里允许「浏览器」或「文件管理器」安装应用，再返回重新点开。
3. **等待安装完成**：几秒到一分钟，过程不需要任何账号。
4. **打开应用贴第一批链接**：首页点右下角的加号进「新建下载」，直链、`magnet:` 磁力、`m3u8` 地址可以混着多行贴进同一个框。

## 三、装不上时的两类报错

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 与已安装的应用冲突 | 手机里有同包名、签名不同的旧版本 | 先卸载旧的再装；卸载会清掉任务记录，还在跑的任务先跑完 |
| 装好了但打不开 / 一闪就退 | 存储权限没给到，或这版包与机型不匹配 | 重新授存储权限、重启手机；仍不行就换一个发布渠道的新版包 |

装完第一次用，磁力任务怎么加、种子怎么挑文件，见[磁力链接怎么用.md](磁力链接怎么用.md)；网页视频的抓取见[网页视频m3u8怎么下.md](网页视频m3u8怎么下.md)。
