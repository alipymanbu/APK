# FluxDown 介绍与使用指引

> FluxDown 是一款以 AGPL-3.0 协议开源的多协议下载器，支持 HTTP、FTP、BitTorrent、HLS、DASH、eD2K。这里收录安卓端的实用指引：安装、磁力任务、网页视频抓取与提速排查。

**目录**

- [安卓版怎么装.md](安卓版怎么装.md) —— 安装包获取与四步安装流程
- [磁力链接怎么用.md](磁力链接怎么用.md) —— 磁力 / BT 任务的添加与文件勾选
- [网页视频m3u8怎么下.md](网页视频m3u8怎么下.md) —— m3u8 流媒体任务的完整流程
- [下载速度慢怎么办.md](下载速度慢怎么办.md) —— 从设置到源头的排查顺序

安卓端的下载安装入口与引擎拆解见 [fluxdown 介绍站](https://fluxdown.boop.uno/)。
