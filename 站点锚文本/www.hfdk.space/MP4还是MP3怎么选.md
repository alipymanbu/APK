# MP4还是MP3怎么选

> 点下下载按钮后的那个弹窗，决定了文件最后长什么样。本篇把类型（Video / Audio）、分辨率档位、音质档位和输出格式一次讲清，顺带说清「下完才发现选错了」该怎么补救。
> **相关文档**：[把网页视频存进手机的几种方式.md](把网页视频存进手机的几种方式.md) · [下载失败与文件去哪了.md](下载失败与文件去哪了.md)

下载弹窗里真正要动的只有两项：Type（类型）和 Quality（质量）。选完点 OK，文件先转换格式再落盘，中途能在下载区看到进度。

## 一、Type：要画面还是要声音

- 选 **Video**：出来的是画面加声音的 MP4，适合收藏、转发、离线观看；
- 选 **Audio**：只留声音，按所选音质存成 MP3（也可输出 AAC、M4A），适合听歌、有声书、当铃声。

## 二、视频的分辨率档位

档位按源视频实际提供的分辨率列出，常见这几档：

| 档位 | 适合场景 |
|---|---|
| 360p / 720p | 体积小，手机上随手看 |
| 1080p | 全高清，多数视频的默认选择 |
| 1440p / 2160p | 2K 与 4K，仅当源视频本身有该分辨率时才会出现 |

弹窗里没列出高档位，说明这条视频的源头就没有——这不是应用的限制，换条高清源就有了。

## 三、音频的音质档位

音频是 70kbps / 128kbps / 320kbps 三档：

- **70kbps**：体积最小，语音类内容够用；
- **128kbps**：常规音质，日常听歌的性价比之选；
- **320kbps**：最高档，打算当铃声、长期存有声书就选它。

下载的音乐会保留 ID3 标签（标题、封面、艺术家、专辑等），进了音乐播放器之后歌名和封面通常不用手动补。

## 四、下完才发现选错了，怎么办

已下载的文件**不能在应用内改格式**——格式在下载那一刻就定死了。想换格式只能重新下一条：点开那条视频重走下载流程，在弹窗里改 Type / Quality。

所以下大批量之前，先下一两条把档位试对，再全选批量，能省不少回头功夫。

## 五、两个常见疑问

- **这条视频最高能下到几 K？** 以弹窗里实际列出的档位为准，源头给多少就有多少；宣传口径里的 4K 指的是「源支持时可到 2160p」，不是任何视频都能拉到 4K。
- **为什么有的站下不了？** 站点改版或加防护会让解析暂时失效，属常态；先换一种送链接的方式试（方式见 [把网页视频存进手机的几种方式.md](把网页视频存进手机的几种方式.md)），仍不行再按 [下载失败与文件去哪了.md](下载失败与文件去哪了.md) 排查。
