# 把网页视频存进手机的几种方式

> 刷到一条视频想存下来，从哪一步开始？本篇把链接送进 iTubeGo 的三种方式、播放列表批量下载、以及下载任务在应用内怎么管，一次讲完。
> **相关文档**：[MP4还是MP3怎么选.md](MP4还是MP3怎么选.md) · [下载失败与文件去哪了.md](下载失败与文件去哪了.md)

iTubeGo 是一款安卓上的视频与音乐下载器，内置浏览器加链接识别，大部分操作在应用内就能闭环。还没装好的话，先到 [iTubeGo 安卓版下载安装](https://www.hfdk.space/) 拿安装包。

## 一、方式一：内置浏览器，边看边存

打开应用，主页上已经预加载了 YouTube、Facebook、Instagram、Dailymotion 等常用站点的图标，点进去就像用普通浏览器一样浏览。播到想存的那条视频，点屏幕右下角的红色下载按钮，下载就开始了。

这是路径最短的一种方式——全程不用复制任何链接。主页没列出的站点也能去：在「Other Sites」区域点 Add，把常去的站加到主页，下次一步直达。

## 二、方式二：复制链接，自动识别

在任意浏览器或其他应用里复制视频链接，再切回 iTubeGo，它会自动识别剪贴板里的地址并弹出下载提示框，点 Download 就行，不用手动粘贴。

这个方式适合视频不在 iTubeGo 主页站点清单里的情况：哪里刷到，就在哪里复制，剩下的交给应用自己认。

## 三、方式三：从其他应用分享进来

比如在社交应用里刷到一条视频，点「分享」，在分享列表里选「Download with iTubeGo」，应用会拉起并自动解析下载。

三种方式最终都落到同一个下载设置弹窗，类型（Video / Audio）与质量在那一弹窗里选，具体档位见 [MP4还是MP3怎么选.md](MP4还是MP3怎么选.md)。

## 四、播放列表怎么一次下完

单条视频好办，整份播放列表也能一次排队：

1. 用内置浏览器打开目标频道，切到 Playlists 标签，进入其中一个播放列表；
2. 点红色下载按钮，先设好输出类型与质量；
3. 弹出的下载清单里点 Select All 全选（也可以只勾其中几条）；
4. 点 Start Download 开始，进度在下载区里逐条看。

多条任务排队时，先转换完的先落盘，完成顺序不完全等于勾选顺序，以下载区的实际状态为准。

## 五、下载中和下载完，去哪里看

- **下载区管「正在下的」**：每条任务都能暂停、恢复、停止；中途网络断了或手动停了，下次打开应用会自动恢复未完成的任务。
- **已下载区管「下载完的」**：所有完成的视频和音乐都在这里，能搜索、播放、排序、删除。注意应用内下载的文件默认不进系统相册，从这一区进是唯一入口——下载完了相册里刷不出来不是丢了，去那里找。

下载按钮点了没反应、或某条视频解析不出来，按 [下载失败与文件去哪了.md](下载失败与文件去哪了.md) 的顺序逐条排。
