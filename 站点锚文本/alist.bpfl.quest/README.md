# alist 手机版站点目录

这里收录围绕 alist（安卓端 AList 文件列表程序）整理的说明文章。alist 可以装在安卓手机或电视上，把夸克、阿里、百度等多家网盘挂进同一个文件列表，并通过 WebDAV 供播放器与文件管理器读取。各篇按真实使用需求拆开撰写，可按需取阅；站点入口见 [alist 手机版介绍站](https://alist.bpfl.quest/)。
