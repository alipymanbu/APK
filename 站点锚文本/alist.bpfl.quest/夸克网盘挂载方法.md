# alist 夸克网盘挂载方法

> 本篇讲在 alist（安卓端文件列表程序）的管理后台里把夸克网盘挂进来：抓 Cookie、找根目录 ID、添加存储、确认挂载成功，以及几个高频翻车点。
> **相关文档**：[手机版下载安装步骤.md](手机版下载安装步骤.md) · [WebDAV播放器接入教程.md](WebDAV播放器接入教程.md)

---

## 一、为什么夸克的挂载要单独写

alist 支持的存储驱动很多，多数网盘扫码授权即可，夸克比较特殊：它认的凭证是**网页版 Cookie** 加**根目录 ID**，两样都要手动取。这篇把两样东西怎么拿、怎么填、填完怎么验证，按顺序走一遍。前提：应用已装好且服务处于运行状态（还没装的先看 [手机版下载安装步骤.md](手机版下载安装步骤.md)）。

## 二、抓 Cookie（电脑浏览器最省事）

Cookie 要从夸克网盘网页版的请求里抄，手机浏览器上不好操作，建议用电脑：

1. 电脑浏览器打开夸克网盘并登录。
2. 按 `F12` 打开开发者工具，切到「网络（Network）」页签，点一下清除按钮清掉旧记录。
3. 在网盘页面里重新点进「全部文件」，让页面发出新请求。
4. 在网络列表里找 `list` 或 `sort` 开头的请求，点开它的「标头（Headers）」，向下滚动找到 `Cookie`，把整串值完整复制出来。

这串 Cookie 等同于账号的登录凭证：不要发给任何人、不要贴到公开场合；怀疑泄露时在夸克网页版退出登录即可让它立即失效。

## 三、找根目录 ID

根目录 ID 决定挂载的范围：

- 想挂整个网盘，就取「全部文件」根文件夹的 ID；进入目标文件夹后，浏览器地址栏里 `folder/` 之后的那串长字符就是文件夹 ID（页面版本不同地址格式略有差异，以当时地址栏实际显示为准）。
- 只想挂某个子目录，就填那个文件夹的 ID；不限定范围则留空或用默认。

## 四、在管理后台添加存储

1. 应用里点左下角「网页」，用 `admin` 和自己设的密码登录管理后台。
2. 底部点「管理」→ 左上角菜单 →「存储」→ 顶部「添加」。
3. 驱动选**夸克（quark）**，表单里只动这几项：
   - **挂载路径**：填 `/quark`（以 `/` 开头、不与已有路径重名即可）；
   - **Cookie**：粘贴第二节抓到的整串；
   - **根目录 ID**：按第三节取到的填；
   - 其余保持默认，移除方式按需选择。
4. 保存成功会回到存储列表，新条目显示为正常状态；回到主页就能看到 `/quark` 下的目录树，视频、图片可以点开在线看。

## 五、高频翻车点

- **粘贴时带上 `Cookie:` 前缀**：复制的必须是纯值，开头留着 `Cookie:` 字样会直接报格式错误——这是被提得最多的一个坑。抓完先看一眼开头是不是 `__kps=` 这类字段名。
- **Cookie 过期**：重新登录、改密码、长时间不用都可能失效，症状是存储列表报错、主页目录变空。照第二节重新抓一份覆盖保存即可，有经验的做法是隔一两个月主动换一次。
- **夸克下载必须走代理中转**：受夸克侧限制，下载要经 alist 的代理功能携带 Cookie 中转，表现为在线播放正常、下载或部分播放器拉流失败时先确认 WebDAV 策略没有被改错（策略说明见 [WebDAV播放器接入教程.md](WebDAV播放器接入教程.md)）。
- **挂载路径重复**：提示路径已存在，把旧条目删掉或换个路径名。

挂好夸克之后，阿里、百度等其他存储的凭证拿法各自不同，按后台对应驱动的要求填写；接入播放器观看则交给 [WebDAV播放器接入教程.md](WebDAV播放器接入教程.md)。
