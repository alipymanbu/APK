# alist 的 WebDAV 播放器接入教程

> 本篇讲把 alist（安卓端文件列表程序）的 WebDAV 地址接进电视、电脑、手机上的播放器与文件管理器：地址怎么写、账号密码用哪组、常见客户端在哪填、播放卡顿或报错时改哪一项。
> **相关文档**：[夸克网盘挂载方法.md](夸克网盘挂载方法.md) · [手机版下载安装步骤.md](手机版下载安装步骤.md)

---

## 一、WebDAV 是用来干什么的

在 alist 的网页里看文件是「自己看自己」；WebDAV 是它对外的另一个口子——局域网里任何支持 WebDAV 的应用，填一个地址加账号密码，就能把挂好的网盘当成自己的目录来浏览和播放。典型场景：手机上跑着 alist，电视里的 Kodi、电脑上的 PotPlayer 直接播夸克网盘里的电影。前提是网盘已挂好（见 [夸克网盘挂载方法.md](夸克网盘挂载方法.md)）且服务在运行。

## 二、三样连接信息

| 项 | 值 |
| --- | --- |
| 地址 | `http://手机IP:5244/dav/` |
| 账号 | `admin`（或后台新建的用户名） |
| 密码 | 后台里设置的密码 |

- **手机 IP**：手机 WLAN 设置里能看到（如 `192.168.1.23`）；用别的设备访问必须填这个 IP，本机自测才用 `127.0.0.1`。
- **端口**默认 `5244`，改过就换新端口；地址末尾的 `/dav/` 不能省。
- 后台还有两处开关决定能否连上：WebDAV 服务总开关，以及 `admin` 用户的「WebDAV 读取」权限。地址密码都对却连不上，多半是这两处漏了。

先在同一个 WLAN 下用手机浏览器开 `http://手机IP:5244` 验证服务通不通，再进各应用填 WebDAV。

## 三、常见客户端在哪填

- **nPlayer（手机 / 电视）**：侧栏 → 网络 → 添加 → WebDAV，填上面三项。
- **Kodi（安卓电视）**：文件 → 添加视频 → 浏览 → WebDAV server。
- **PotPlayer（Windows）**：打开 → 打开文件夹 → 添加收藏，协议选 WebDAV。
- **RaiDrive（Windows）**：新建连接选 WebDAV，地址拆成主机与端口两项填，连上后是「此电脑」里的一个盘符。
- **MT 管理器等安卓文件管理器**：侧栏 → 添加网络存储 → WebDAV。

各客户端菜单名随版本会变，认准「WebDAV」协议选项即可。

## 四、播放卡顿或报错，改策略

每个存储都有「WebDAV 策略」选项：

- **302 重定向**：请求被直接导向网盘真实下载地址，速度最快，但要求客户端能处理带凭证的跳转；
- **本地代理**：流量经手机转发，兼容性最好，夸克这类必须带 Cookie 的存储只能走它，代价是占手机性能与上行。

通用判断：播放器报 403、无法播放或下载失败，切到**本地代理**再试；播放流畅但带宽吃紧，切 302。

## 五、装好第一步从哪开始

如果应用还没装，先看 [手机版下载安装步骤.md](手机版下载安装步骤.md)；站点里还有各功能的界面截图与场景说明，可移步 [alist 手机版介绍站](https://alist.bpfl.quest/) 查看。接入过程中遇到地址连不上、播放器报错，先回第二节核对三样连接信息与两处开关，多数问题都出在那里。
