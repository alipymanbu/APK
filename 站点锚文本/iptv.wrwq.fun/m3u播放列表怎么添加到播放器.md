# m3u 播放列表怎么添加到播放器

> 手里拿到一段 m3u 链接或一个 .m3u 文件，不知道往哪儿填、怎么填——本篇按步骤讲完添加全过程，以及添加后常见现象的判断。

---

## 一、先认清 m3u 是什么

m3u 本质是一份文本格式的频道清单：里面一行一条，记录频道名字和流的地址。播放器读进这份清单，频道才会一个个列出来。所以要注意：

- m3u 链接不是网页地址，别把它当普通网址塞进浏览器就以为完事；
- 清单由提供方维护，链接失效、频道减少都属常见现象，与播放器无关；
- 带用户名密码参数的链接等于账号凭证，不要转发给别人。

## 二、添加步骤（以 IPTV Pro 为例）

1. 打开播放器，在主界面找到「添加播放列表」入口；
2. 选择 URL 方式，把 m3u 链接完整粘贴进去；
3. 起个名字，方便以后在多个列表之间切换；
4. 确认后应用开始下载并解析——几千个频道的列表首次加载需要等一会，别急着关。

如果拿到的是 `.m3u` / `.m3u8` / `.xspf` 文件（存在手机或 U 盘里），就用「文件」方式导入：电视盒子上不方便打长链接时，这种方式最省事。

## 三、添加后的三种常见现象

| 现象 | 判断 |
| --- | --- |
| 一直转圈不出频道 | 用浏览器直接打开那条链接，能下载到一串文本说明链接是通的、问题在应用侧；打不开就是链接过期，找提供方要新的 |
| 频道数量明显变少 | 大列表部分失效属正常，先刷新列表再判断 |
| 频道有了但不知道在播什么 | 节目单（EPG）没配，需要单独填 XMLTV 地址或改用服务器下发的方式 |

## 四、接着配什么

列表加载出来只是第一步：想让频道旁显示「正在播什么」要配节目单；列表里 `udp://@` 开头的频道点开黑屏的，需要局域网代理配合，这些在此前的播放器说明里都有展开，推荐到 [iptv.wrwq.fun](https://iptv.wrwq.fun/) 看整理好的完整配置思路（IPTV 播放器与播放列表）。
