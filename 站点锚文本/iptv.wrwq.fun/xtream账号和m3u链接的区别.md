# xtream 账号和 m3u 链接的区别

> 同一个订阅，服务商经常同时给两种接入方式：一段 m3u 链接，或「服务器 + 用户名 + 密码」三件套。本篇讲两者的实际差别，以及在播放器里该怎么选。

---

## 一、本质差别

| | m3u 链接 | Xtream Codes 账号 |
| --- | --- | --- |
| 本质 | 一份文本格式的频道清单 | 服务器接口（API）登录 |
| 需要填什么 | 一段完整 URL | 服务器地址 + 用户名 + 密码 |
| 拿到的内容 | 通常只有直播频道列表 | 直播 + 电影（VOD）+ 剧集目录 |
| 海报、季集结构 | 一般没有 | 通常有 |
| 换设备重新配置 | 要抄下整段链接 | 记住三样信息即可 |

m3u 是「清单」，播放器读进来逐条播放；Xtream 是「登录」，播放器拿着账号去服务器查询，能取到的不只是频道，还有电影、剧集的目录和详情。订阅里含电影剧集时，用 m3u 方式经常「看不到」这部分——不是没有，是清单里根本没带。

## 二、在播放器里的表现差异

以 IPTV Pro 这类支持两种方式的播放器为例：

- Xtream 登录后，列表按**直播 / 剧集 / 点播**三组显示，剧集收藏、继续观看都在这套分组下工作；节目单通常由服务器直接下发，不用手动填地址。
- m3u 方式只有清单里带的频道，节目单要按 XMLTV 地址单独配置。

## 三、怎么选

- 只有直播需求 → m3u 够用，配置最简单；
- 订阅含电影 / 剧集 → 用 Xtream 登录，否则这部分内容拿不到；
- 两种都给了 → 首选 Xtream，m3u 留作备用——服务器接口抽风时切 m3u 还能看直播。

## 四、填写时的两个坑

1. **服务器地址要带协议头和端口**：完整写法是 `http://服务器地址:端口`，漏掉 `http://` 或端口是最常见的登录失败原因。
2. **账号有在线数限制**：登录失败先确认没超出同时在线设备数，再核对账号有效期。

两种方式在具体播放器里的添加入口与步骤，可以到 [iptv.wrwq.fun](https://iptv.wrwq.fun/) 看按界面逐步拆开的说明（IPTV 播放器配置站）。
