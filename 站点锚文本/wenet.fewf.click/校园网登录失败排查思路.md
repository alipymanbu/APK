# 校园网登录失败排查思路

> 这篇讲 wenet（闪讯手机端）登录失败、连上 WiFi 却上不了网、反复掉线时，按什么顺序定位问题。
> **相关文档**：[闪讯校园网客户端是什么](闪讯校园网客户端是什么.md) · [宿舍多设备共享校园网](宿舍多设备共享校园网.md)

## 先分清是哪一种"连不上"

三种症状的原因完全不同，先对号入座再动手：

| 症状 | 大概率原因 |
| --- | --- |
| 应用里登录就报错 | 账号格式、密码、地区、欠费 |
| 登录显示成功，网页打不开 | 手机偷切流量、认证没真正完成 |
| 用一会儿就断、反复登录 | 顶号、信号弱、无数据自动下线 |

## 登录报错：按这四条排

1. **地区设置**：进入「我的」→「地区设置」，确认选的是学校所在省份（有的学校通知会指定省份）；改完**完全退出应用再打开**才生效。这是最容易被忽略的一条。
2. **账号格式**：是否漏了前缀（如要求 `edu` 就必须带上）、是否混入空格、大小写是否正确。
3. **密码状态**：初始密码多为身份证后六位（末位 X 注意大写）或身份证后八位；改过密码后所有设备都会掉线，要用新密码重登。密码忘了按学校通知的方式重置。
4. **账号状态**：欠费或套餐到期会直接拒绝登录，缴清后退出重登；账号已在别的设备在线时，先在旧设备退出（处理思路见[宿舍多设备共享校园网](宿舍多设备共享校园网.md)）。

## 登录"成功"却上不了网

- **关掉 WLAN 助理类开关**：系统的"WLAN 助理 / WLAN+"会在认证完成前判定"这个网没互联网"，自动切回流量把认证打断——先去 WLAN 设置里关掉它；
- **关闭移动数据再试**：排除偷切流量的干扰；
- **随机 MAC 改设备 MAC**：认证系统靠 MAC 认设备，在 WLAN 详情里改用"设备 MAC"，把网络"忘记"后重连重登；
- **关代理与 VPN**：不少认证系统检测到代理会只放行部分流量，表现为聊天能用、网页打不开。

## 认证页不弹出

连上校园 WiFi 却什么都没弹时，用浏览器随便访问一个网址手动触发；用 wenet 的话直接在应用里登录，通常能跳过"等弹页"这一步。

## 报错提示速查

| 你看到的提示 | 先做什么 |
| --- | --- |
| 账号或密码错误 | 核对前缀与大小写；改过密码就用新密码 |
| 已达到同时在线用户数 | 有设备没退出，先下线旧设备 |
| 欠费 / 账号已停用 | 缴费后退出重登 |
| 地区不能使用本服务 | 改地区设置，重启应用 |
| 认证失败 / 服务器超时 | 确认连的是学校信号、没开代理；等半分钟重试 |

各校提示文案不统一，最终以学校实际显示的原文为准。排完仍不行，先看学校信息化中心有没有维护公告，再走校内报修——反馈时说清账号形式（别发密码）、报错原文和已排除的原因。

## 装好应用但配置没做对

不少"连不上"其实是首次配置没做完：地区没选、WiFi 没连学校信号就开始登录。从安装到登录的完整顺序，可以对照 [wenet 校园网客户端介绍站](https://wenet.fewf.click/)下载页的安装步骤走一遍。
