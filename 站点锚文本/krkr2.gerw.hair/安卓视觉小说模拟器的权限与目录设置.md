# 安卓视觉小说模拟器的权限与目录设置

用手机跑吉里吉里游戏的模拟器（如 krkr2 / Kirikiroid2），逻辑上是"你指到哪、它读哪"，对目录位置并不挑剔。真正让人头疼的是安卓系统这一侧：权限开关层层叠叠，新版本还把 `Android/data` 目录锁了起来。这篇把权限、目录、SD 卡三个变量一次理清，看完就知道你的"看不到文件"卡在哪一层。

## 一、先对症：你是哪种"看不到"

| 症状 | 大概率原因 |
| --- | --- |
| 模拟器里整个列表空白 | 存储权限没给够 |
| 能看到别的文件夹，唯独没有你放游戏的那层 | 位置被系统限制（如 Android/data） |
| SD 卡里的游戏看不见 / 卡在加载 | 机型对外置卡读取不稳定 |
| 权限给够了还是空白 | 系统抽风，重启一次手机再试 |

## 二、权限分两级，缺一不可

1. **文件与媒体**：长按桌面图标 → 应用信息 → 权限 → 允许「文件与媒体」。只给这一级，很多机型上模拟器还是空列表。
2. **管理所有文件**：安卓 11 及以上，还要打开这个总开关——设置 → 应用 → 对应模拟器 → 权限，或 设置 → 应用 → 特殊应用权限 → 所有文件访问权限。

老玩家口中的"打开什么都没有"，十有八九是只给了第一级、没给第二级。

## 三、Android/data 为什么进不去

从安卓 11 起，系统逐步收紧对 `内部存储/Android/data` 的访问；到安卓 13、14，大多数文件管理器打开这个目录只会得到"拒绝访问"或一片空白。这是系统层面的安全设计，不是手机坏了。

麻烦在于，部分模拟器的专属数据目录恰好也在这个受限区域下面（例如 krkr2 的 `Android/data/org.github.krkr2/files/`）。要在新系统上用这条路径，需要一个支持该目录授权的文件管理器：

1. 用 MT 管理器这类工具进入 `内部存储/Android/data`；
2. 弹出系统授权窗口时选择同意——这是安卓系统自带的目录授权机制，同意后该工具即可长期读写；
3. 把整个游戏文件夹移动或粘贴到 `<模拟器包名>/files/` 下；
4. 回到模拟器，在内置浏览器里切换到这个路径，点 `data.xp3` 启动。

个别机型（如部分三星 One UI 6.x 以上）对这套授权限制更严，成功率明显低，只能改走普通目录方案。

## 四、更省事的替代：普通目录

把游戏放在普通内置存储目录（`Download`、自建的游戏文件夹等）完全不受 `Android/data` 限制——权限给够就能读，读写速度也有保障。除非遇到特殊需要，否则没必要往受限目录里挤。这也是为什么多数教程会建议：**优先内置存储、普通目录、别用外置 SD 卡**。

## 五、权限与目录都对了，还差什么

剩下的问题多半出在游戏文件本身：压缩包没解压完整、后缀被改名、缺对应补丁。这些属于"文件怎么打开"的范畴，处理办法见 [xp3文件怎么打开与运行](xp3文件怎么打开与运行.md)；播放器本身还没装的，先补 [吉里吉里2模拟器手机版怎么下载安装](吉里吉里2模拟器手机版怎么下载安装.md) 这一课。想看真机各设置页长什么样，[krkr2 介绍站](https://krkr2.gerw.hair/)的四张实拍截图可以逐项对照。
