# 吉里吉里2模拟器手机版怎么下载安装

想用手机玩那些经典的吉里吉里文字冒险游戏，第一步就是把 krkr2（Kirikiroid2，中文圈常叫"吉里吉里2模拟器"）装进安卓手机。这篇按真实操作顺序讲清楚：从哪里拿安装包、怎么装、装完先做什么，以及安装环节最容易卡住的三件事。

想先了解这个播放器本身能干什么、什么游戏能跑，可以看 [krkr2 介绍站](https://krkr2.gerw.hair/)，那里有真机界面与手势映射的完整整理；本文只管"装好"这一段。

## 一、安装包从哪来

krkr2 是开源项目的安卓打包版，安装包体积不大（约 69 MB），常见获取方式是通过网盘分享链接：打开分享页，先把资源转存到自己的网盘账号，再把 APK 下载到手机本地存储。转存这一步不能省——分享链接可能失效，转存到自己账号里的那份才真正属于你。

注意两点：

- 安装包只是"播放器"，里面没有任何游戏内容；
- 版本号各打包版规则不一，能正常安装使用即可，不必纠结追新。

## 二、安装步骤

1. **打开 APK**：用系统自带安装器或文件管理器点开下载好的安装包。
2. **允许未知来源**：系统若提示"禁止安装未知来源应用"，按提示进入允许列表，勾选本次用来打开 APK 的应用（浏览器或文件管理器），返回后重试。
3. **等待安装完成**：全程几十秒，完成后桌面会出现 krkr2 图标。
4. **先别急着进游戏**：第一次打开还有一步权限设置，见下一节。

## 三、装完第一件事：给存储权限

krkr2 要读取你放在手机里的游戏文件夹，权限不足时内置文件浏览器会一片空白——这是"打开什么都没有"的头号原因：

1. 长按桌面 krkr2 图标 → 应用信息 → 权限；
2. 允许「文件与媒体」；
3. 安卓 11 及以上的机型，把「管理所有文件」总开关一并打开；
4. 重新打开 krkr2，主界面应能看到手机存储里的目录。

打开时若弹出"SDK 版本较低"之类的提示，属正常现象，直接忽略。

## 四、装好之后

下一步是把吉里吉里游戏放进手机并启动：解压压缩包、找到 data.xp3、点开即玩，完整流程见 [xp3文件怎么打开与运行](xp3文件怎么打开与运行.md)。权限给了还是看不到文件夹、或者你的系统是新安卓版本，多半是 Android/data 目录限制在挡路，单独一篇讲透：[安卓视觉小说模拟器的权限与目录设置](安卓视觉小说模拟器的权限与目录设置.md)。

## 五、安装环节常见问题

- **安装按钮点不动、被拦截**：全是"未知来源"限制，按第二节第 2 步放行即可；部分机型入口在 设置 → 应用 → 特殊应用权限 → 安装未知应用。
- **提示解析包出现问题**：多为 APK 下载不完整，重新下载一遍再装；网盘在线下载中断后接着下的包容易残缺，建议删掉重下。
- **装好了但打开就闪退**：清后台重进一次；仍闪退则确认手机安卓版本与安装包架构匹配，换个打包版本来装。

## 六、写在最后

播放器装好只是开始，吉里吉里游戏的乐趣在于故事本身。把krkr2与你的游戏数据都准备好之后，手机就是一台随身的文字冒险机。安装过程卡住时，回到 [krkr2 资源与介绍站](https://krkr2.gerw.hair/) 对照真机截图逐步排查，比凭记忆翻教程省事得多。
