# xp3文件怎么打开与运行

下载到一个文件夹，里面躺着一个 `data.xp3`，双击打不开、手机也不认识——这是很多玩家第一次接触吉里吉里（Kirikiri）引擎游戏时共同的记忆。xp3 不是损坏的压缩包，而是吉里吉里游戏的资源封包，装着脚本、立绘、语音与剧情文本；要打开它，需要一个能读懂这个引擎的"播放器"。安卓手机上，这个播放器通常就是 krkr2（Kirikiroid2）。

## 一、先确认它真是吉里吉里游戏

xp3 封包是吉里吉里引擎的标志性产物，但拿到资源时仍建议核对两点：

- 资源说明里有没有标注「krkr / 吉里吉里 / Kirikiroid2 版」之类的字样；
- 解压后的文件夹里是否存在 `.xp3` 后缀的文件（`data.xp3` 最常见，汉化包有时会提供 `启动游戏.xp3` 之类的替代入口）。

两条都满足，基本就能在手机上跑。Ren'Py、Unity 或普通 Windows 程序不是这套体系，换什么播放器都打不开。

## 二、在手机上运行 xp3 的完整流程

1. **解压压缩包**：用 ZArchiver、RAR 这类工具把游戏压缩包解压到内置存储。注意三个坑——后缀被改过的压缩包先改回 `.7z` / `.rar` / `.zip` 再解；解压出来还是压缩包就再解一层；分卷压缩（`.z01`、`.part1.rar`）只对第一个分卷执行解压。
2. **放入内置存储**：位置不挑，任意能找到的文件夹都行；优先内置存储而非外置 SD 卡——读卡速度慢会直接拖累加载。
3. **打开播放器**：启动 krkr2，首次进入会有一条使用说明浮层，关掉后就是文件浏览器。
4. **点选启动文件**：逐级进入游戏目录，按优先级点——绝大多数游戏点 `data.xp3` 就能进；目录里同时有 `data.xp3` 和 `.exe` 时，`.exe` 通常也能直接点开；极少数游戏按资源附带的说明选其它 xp3。
5. **开始阅读**：加载出游戏画面即成功。目录里的 `patch.xp3`、`savedata` 不用手动处理，播放器会自己读。

运行起来之后，鼠标操作怎么用手指替代、黑边区域上滑调菜单这些手势细节，[krkr2 介绍站](https://krkr2.gerw.hair/)用一张对照表讲得很直观，值得先看一遍再开玩。

## 三、点开就报错？多半是缺补丁

xp3 封包有的带加密，播放器读取时需要这款游戏**对应的补丁文件**才能解开：

- 标注「krkr2 版 / Kirikiroid2 版」的资源一般已随包带好补丁（目录里常见 `patch.xp3`），不用额外处理；
- 普通日文原版或汉化版点开就报错的，去社区整理的 Kirikiroid2 补丁列表按游戏名找对应补丁，把 `xp3filter.tjs`、`patch.tjs` 等文件放进**游戏根目录**（与 data.xp3 同级）再启动；
- 放错层级（进了上层文件夹或子文件夹）是"放了补丁还报错"的第一原因；
- 报错九成以上其实是游戏文件本身损坏——下载不完整、解压中断都会这样，先重新解压一遍再下结论。

## 四、存档与游戏目录

吉里吉里游戏的进度存档全部写在**游戏目录下的 savedata 文件夹**里：`.ksd` 是存档本体，`.bmp` 是节点缩略图——缩略图在相册里看着像垃圾小图，删了对应节点的存档就读不出来，清理软件白名单记得把游戏目录加进去。想换手机时，整个游戏文件夹（连同 savedata）复制过去，进度原样带走。
