# 安卓版下载安装步骤

> WalkColor 在苹果端先火起来，后来才出的安卓版本。安卓安装包通过网盘分享获取，转存、下载、安装一共四步，最常卡住的是"未知来源"授权这一关，这篇单独拆开讲。

## 装之前

它是一款创意图片编辑工具，安装包体积不大，近几年的安卓机型都能流畅运行。安装文件放在夸克网盘的分享里，所以流程比应用商店多一步"转存"——这一步的意义是文件进你自己的账号，之后随时能重新下载，不依赖原分享的状态。

从哪里进分享页：站点的 [WalkColor 安卓版下载安装](https://walkcolor.bpfl.quest/) 页面顶部就是获取入口，进去后按下面的步骤走。

## 第一步：转存安装文件

打开分享页，登录网盘账号，把分享内容转存到自己网盘。转存后文件夹里除了 APK 文件，一般还附带一个说明文件。

## 第二步：下载到手机

手机上打开网盘客户端（用同一个账号），找到刚转存的 APK 选择下载；也可以先在电脑上下载，再用数据线、局域网或聊天工具传到手机。

## 第三步：允许安装未知应用

安卓默认拦截应用商店之外的安装包，点开 APK 提示"禁止安装"是正常现象，不是文件坏了：

1. 进「设置 → 应用管理 → 特殊权限（或更多设置）→ 安装未知应用」；
2. 找到你用来打开安装文件的那个应用（文件管理器或浏览器）；
3. 打开"允许安装此来源的应用"；
4. 回到下载目录，重新点 APK 继续安装。

各品牌手机的菜单名称略有出入，在设置里直接搜"未知来源"或"安装未知应用"就能定位。授权装完后可以再关掉，不影响已装好的应用。

## 第四步：授予相册权限，开始第一张

安装完成首次打开时，应用会申请相册 / 存储权限——读取用来导入照片，写入用来把成品存回相册。拒绝的话既选不了图也存不了结果，建议允许。

点"新制作"导入一张照片，就能按玩法流程开始第一张波点拼贴了，具体怎么玩见[波点拼贴玩法解析](波点拼贴玩法解析.md)。

## 装不上的三种常见情况

**提示"解析包出错"**：多半是 APK 没下载完整或下载被中断，回网盘重新下载一遍再装。

**安装到一半卡住**：先清一下手机存储空间，空间紧张时安装容易中途失败。

**装好了却选不了照片**：相册权限被拒过，到「设置 → 应用」里找到它，把存储 / 照片权限改成允许即可。
