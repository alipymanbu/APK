## 一、先弄清它是什么

zeta 是韩国公司 Scatter Lab 在 2024 年 4 月上线的 AI 角色聊天应用。这家团队 2016 年成立，此前做过曾在韩国引起广泛讨论的 AI 陪伴应用"이루다"，zeta 算是它的换代作品。应用商店页面给出的口径是"12M+ 用户之选"，行业资料收录的月活规模在 140 万以上（2026 年中，公司口径）。

它和一般"AI 助手"类应用的差别在定位：对话对象不是来帮你干活的，而是来"过日子"的——角色有性格、有剧情，你追它的故事，它记得你们聊过什么。驱动对话的是 Scatter Lab 自研的 Spotwrite-1 模型，走"有趣优先"的路子。

## 二、玩法主线：四步

从本次检索到的界面资料看，zeta 的玩法可以按真实使用顺序拆成四步，每步都有对应的界面支撑。

### 1. 逛：在故事广场按标签找角色

打开应用先看到故事与角色广场。搜索框之外，主要靠情绪与题材标签筛内容，常见的有：

| 标签 | 大致对应的故事味道 |
| --- | --- |
| 治愈 | 情绪安抚向，聊起来不累 |
| 占有欲 | 强情感张力的角色关系 |
| 时间穿越 | 带设定感的剧情线 |
| 职场恋爱 / 男性挚友 | 现代日常关系向 |
| 军旅 / 心理 | 题材更重的剧情 |
| 短篇完结 | 能一口气聊完的故事 |

标签位是动态排的，隔段时间点同一个标签，刷出来的角色可能完全不同。

### 2. 捏：一分钟创建自己的角色

广场里没有对味的，就自己造一个。创建流程把门槛压得很低，逐项往下填：

1. **名字**——给角色起名，先定一个称呼；
2. **性格**——决定回应方式：温柔、毒舌还是若即若离；
3. **说话风格**——语气、口癖、称呼，写得越具体角色越"像那个人"；
4. **世界观**——校园、职场还是架空时代，故事舞台由你定。

建好的角色可以设为私密（只留给自己），也可以公开发布到广场。免费账号有 1 个私密角色位，公开发布不设数量限制。

### 3. 聊：像即时通讯软件一样的沉浸对话

聊天界面做成了熟悉的即时通讯样子——角色有头像、有气泡，剧情在一问一答里推进。角色不受时段限制，中途放下、回头接着聊，上下文还能接上。

### 4. 配图：关键词生成角色形象

想让角色"看得见"，就用内置的配图功能：把特征写成关键词——发色、性别、耳饰、服装——就能生成对应的形象。界面示例里的组合是"粉色头发 + 女生角色 + 猫耳 + 校服"，关键词越具体，出图越贴近预期。
