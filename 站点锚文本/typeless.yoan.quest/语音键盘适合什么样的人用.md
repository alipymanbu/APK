# 语音键盘适合什么样的人用

> 本篇不聊参数，只聊场景：哪些人把输入方式从打字换成开口之后，是真的省时间；哪些情况键盘仍然是更顺手的选择。
> **相关文档**：[说话变文字的键盘怎么装到手机](说话变文字的键盘怎么装到手机.md) · [语音听写能替你写什么](语音听写能替你写什么.md)

## 一、拇指追不上思路的人

手机打字的真实速度大约每分钟三四十个词，而人正常说话的语速折算下来能到它的几倍。想法在脑子里已经成型、拇指还在一个字一个字敲——这种「嘴比手快」的落差，是语音键盘存在的理由。

Typeless 走的是「说 + 整理」这条路：你在它的键盘上按一下 Speak 开口讲，讲完再按一下，落进输入框的不是逐字记录，而是去掉了语气词、修掉了中途改口、排好了标点分段的成稿。产品方公布的对比口径是语音 220 wpm 对键盘打字 36 wpm，实际因语言和个人语速有差异，但差距的方向不会变。

## 二、对号入座：这些场景很合适

| 你是谁 | 换成开口之后的差别 |
| --- | --- |
| 消息回得多的人 | 一段话说完直接成稿，省掉打字和删改口头语的两轮功夫 |
| 邮件要写体面的人 | 称呼、分段、落款自动排好，口语讲完就是能发的版本 |
| 开会做记录的人 | 边听边说要点，单次最长 9 分钟，长内容分段讲完进历史 |
| 清单爱好者 | 念一串采购项，自动排成带项目符号的列表 |
| 要用外语回消息的人 | 长按 Speak 上滑是翻译：说中文，出来整理好的外语成稿 |

## 三、这些情况，键盘还是快

- **一两个字的修改**：补个标点、改个错字，切回打字键盘更快——在 Typeless 键盘上左右滑动就能来回切，两块键盘不冲突。
- **安静程度不允许开口的场合**：地铁早高峰、合租的深夜。它有低语模式可以压低音量说，但周围喧闹到麦克风分不清人声时，效率照样打折。
- **涉及隐私的内容**：转写在云端完成，不希望音频离开手机的场景，这块键盘并不适合。

## 四、一句话结论

日常消息、邮件、记录类的高频输入，换成「说」的收益最直接；精确修改和不宜开口的场合，留回给打字。两者是搭配，不是替代。
