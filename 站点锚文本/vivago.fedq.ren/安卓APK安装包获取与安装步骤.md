# 安卓 APK 安装包的获取与安装步骤

> 这类应用多数不在国内应用商店上架，安装包要从网盘分享获取。这篇讲从网盘转存、开启安装权限到装进手机、完成首次启动的全过程，以及三个最常见的安装障碍怎么处理。

## 一、从网盘分享拿安装包

以 VIVAGO 为例（安卓版约 81 MB 的 APK），获取入口整理在 [VIVAGO 安卓版介绍](https://vivago.fedq.ren/) 这一页，进去就能看到网盘分享地址。流程是固定的三步：

1. 打开分享页，选中文件点「转存」，存进自己的网盘账号——转存后的文件长期有效，不怕原分享失效；
2. 在自己的网盘里找到这个 APK，点「下载」到手机本地存储；
3. 下载完成后在通知栏或文件管理器里能看到它（文件名通常带版本号，以页面当时显示为准）。

安装前看一眼剩余空间：安装包约 81 MB，加上运行缓存，预留 500 MB 以上比较稳妥。

## 二、允许安装外部来源应用

第一次安装 APK 时，系统会弹「禁止安装未知来源应用」。这不是文件有问题，是安卓的默认保护——需要把你用来打开安装包的那个应用（文件管理器或浏览器）放行：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装未知应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 |
| 三星 | 设置 → 应用 → 特殊权限 → 安装未知应用 |

系统版本不同菜单名略有差异，最稳的办法是在系统设置里直接搜「未知」。

## 三、安装并完成首次启动

1. 在文件管理器里点刚下载的 APK，等待安装完成，点「打开」；
2. 应用图标会出现在桌面或应用列表里；
3. 首次启动需要联网加载资源，弱网下可能停在加载页，换个网络重进即可；
4. 按提示登录：邮箱收验证码，或用 Google、Discord 账号直接进；
5. 生成或保存作品时会请求存储权限，按需允许——拒绝的话，成品存不进相册。

## 四、三个最常见的安装障碍

- **提示「解析包出错」**：多半是安装包没下载完整，重新下载一遍再装；
- **点安装没反应或被阻止**：回到设置，把「安装未知应用」权限授给刚才打开 APK 的那个应用，再回来重试；
- **装完打不开或闪退**：先重启手机；仍闪退就卸载后重装，存储不足也会导致这类异常。
