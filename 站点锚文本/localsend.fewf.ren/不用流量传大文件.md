# LocalSend 不用流量传大文件

> 几个 GB 的视频想从手机挪到电脑，网盘要开会员才有速度，聊天工具压画质又限大小——其实只要两台设备在同一个网络里，用 LocalSend 局域网直连：不消耗流量、不压缩文件、速度跑满 Wi-Fi。本篇讲清「为什么不算流量」、没有路由器怎么组网，以及让速度再快一点的几个要点。操作流程见[手机电脑互传文件](手机电脑互传文件.md)。

## 为什么它不走流量

手机套餐的流量只统计「经过运营商网络」的数据。LocalSend 的传输发生在局域网这一层：文件从一台设备直接进另一台设备，根本不出门，自然没有流量费。家里的宽带断了、欠费了都不影响——它要的只是「两台设备连在同一个路由器（或热点）下」这个条件。

也正因为不经过服务器：没有会员加速这回事，速度上限就是 Wi-Fi 的实际带宽；文件原图原样到达，不压缩、无大小限制；内容端到端加密，不出局域网。

## 没有路由器：热点直连

在外面、会议室、甚至飞机高铁上，都能自己组网：

1. 任意一台手机在系统设置里打开「个人热点」；
2. 另一台把它当普通 Wi-Fi 连上；
3. 两端打开 LocalSend，照常发送接收。

三个要点：

- **热点不需要有外网**——开热点只是把设备接到一起，停机了、套餐用尽了，只要热点开得出来，文件照样通；
- **不消耗流量**，传几十 GB 也没有费用；
- **想快**：热点设置里若有 2.4GHz / 5GHz 选项就选 5GHz，两台设备放近一点，传大文件时给开热点的手机插上电。

## 公共 Wi-Fi 搜不到人？也是热点的用武之地

咖啡厅、酒店、公司访客网普遍开着「客户端隔离」：同一网络里的设备互相看不见，而你多半没有路由器的管理权限去改它。这时切成热点直连，等于自建一个只有自己人的小网络，隔离规则够不着它——这是搜不到设备时最干脆的绕行方案。

## 让速度再快一截

| 要点 | 说明 |
| --- | --- |
| 频段 | 5GHz Wi-Fi 近距离明显快于 2.4GHz |
| 距离 | 设备靠近路由器，信号弱会反复重传拖慢整体 |
| 有线 | 电脑插千兆网线最稳，无线掉速时的备选 |
| 打包 | 几百张照片打成一个压缩包再传，只走一次确认流程 |
| 让路 | 传输期间停掉网盘同步、视频下载这类抢带宽的任务 |

## 它做不到的事

LocalSend 只在**同一局域网内**工作：两台设备不在一个网络里（比如人在两个城市），就互相看不见——跨城市传文件该交给网盘。另外它没有账号体系，「发给某个指定的人」也做不到，对方必须和你在同一个网络里。

工具本身免费开源，安卓安装包与逐步的安装说明都在 [LocalSend 介绍站](https://localsend.fewf.ren/)；先装好两端，再照着上面的要点挑一个顺手的网络开始传。
