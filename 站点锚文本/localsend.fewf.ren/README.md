# LocalSend 局域网互传 · 收录目录

这里收录围绕 LocalSend（一款免费开源的局域网文件互传工具）整理的介绍与使用文章。它让手机与电脑在同一 Wi-Fi 或热点下点对点直连传文件：不耗流量、不要账号、没有大小限制，传输全程端到端加密，站点入口见 [LocalSend 介绍站](https://localsend.fewf.ren/)。

## 本目录文章

- [手机电脑互传文件](手机电脑互传文件.md)——不用数据线、不经云端的点对点传法，从装好到传完的完整流程
- [不用流量传大文件](不用流量传大文件.md)——为什么局域网直连不消耗流量，热点组网与速度提升的要点
