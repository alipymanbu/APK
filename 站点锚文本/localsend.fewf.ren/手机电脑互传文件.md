# LocalSend 手机电脑互传文件

> 手机里的照片、视频想挪进电脑，数据线不在手边、聊天工具又压缩画质还限速？LocalSend 给的是另一条路：两台设备连同一个网络，点对点直连，传完即走。本篇把从安装到传完的完整流程走一遍，另一篇[不用流量传大文件](不用流量传大文件.md)专门讲流量与组网的事。

## 先认识它

LocalSend 是一款在 GitHub 上开源（7 万多星标）的跨平台互传工具，Windows、macOS、Linux、安卓、iOS 都能装，媒体常把它称作「开源的 AirDrop 替代品」。它的几个底子决定了用起来的感受：

- **直连不绕路**：文件在两台设备之间直接传输，不经过任何中转服务器，也就没有上传等待；
- **端到端加密**：传输内容只有收发两端能读，公共 Wi-Fi 里也放心；
- **零配置**：不用注册登录，装上打开，「附近的设备」列表会自动列出同网络里的其他设备。

想先看功能全貌与界面截图，可以逛逛 [LocalSend 介绍站](https://localsend.fewf.ren/)；本篇直接进入操作。

## 第一步：两端都装上

互传是两台设备之间的事，缺一不可：

- **安卓手机**：安装包约 16.7MB，装法在介绍站的下载页有逐步说明；
- **电脑 / iPhone**：从项目在 GitHub 的开源仓库（github.com/localsend/localsend）按平台取，也可用 `winget install LocalSend.LocalSend` 这类包管理器安装。

## 第二步：连同一个网络

两台设备连同一个 Wi-Fi 即可；没有路由器的场合，一台开热点另一台连上照样能用（细节见[不用流量传大文件](不用流量传大文件.md)）。注意两点：路由器的「访客网络」和主网默认互相看不见；公司、咖啡厅的网络常开客户端隔离——这两种情况搜不到对方，换热点直连最稳。

安卓端首次启动记得把「附近设备 / Wi-Fi 访问」和通知权限给全，拒掉任何一项，列表就会一直空着。

## 第三步：发送与接收

1. 发送端切到「发送」页，按类型选内容：文件、媒体、剪贴板、文本都行；长按进入多选，新版本还支持滑动连选照片。
2. 点「附近的设备」里对方的名字。
3. 接收端弹出确认框，点「接受」，进度走完文件就落进了「下载」目录（安卓常见为 `Download/LocalSend`）。

几个顺手的功能：发送页选「文本」可以直接把一段文字或链接推给对面；点「附近的设备」旁的齿轮能开启多设备同发；对方没装 LocalSend 时，齿轮里还能生成二维码，用浏览器扫码就能取文件。

## 传不动、搜不到人时

- **速度上不去**：换 5GHz Wi-Fi、靠近路由器；大量小文件先打成一个压缩包再传，能省掉逐个确认的时间；
- **列表是空的**：按「同一网络 → 权限 → 两端都开着」的顺序排查，电脑端再看防火墙是否放行了 53317 端口的 TCP 与 UDP；
- **传一半断了**：把手机省电策略对它放开、传输期间别锁屏。

这些场景的处理细节，介绍站与相关文章里都有逐步的拆解。
