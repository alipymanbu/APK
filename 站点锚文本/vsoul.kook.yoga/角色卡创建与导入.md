# 角色卡创建与导入

> 本篇讲在 vsoul（微灵AI）里怎么得到一个「对味」的角色：广场现成角色怎么找、创意工坊自建的各项参数怎么填、PNG 角色卡怎么导入，以及角色跑偏之后怎么修。模型与参数的部分见 [模型与参数调校.md](模型与参数调校.md)，首次上手见 [玩法入门与首次对话.md](玩法入门与首次对话.md)；完整版在 [vsoul 调校笔记](https://vsoul.kook.yoga/)。

---

## 先找现成的，再考虑自建

角色广场的现成角色能覆盖大部分需求：顶部关键词搜索、热搜榜、排行榜（按点赞、收藏、对话量排）和标签筛选都能用，你的浏览偏好还会影响推荐。这几条路都翻过确实没有想要的人设，再去创意工坊自己动手——自建不依赖付费功能。

## 自建角色的步骤

1. 点底部的「创意工坊」；
2. 找到「创建角色」入口；
3. 选择是否导入一张图片作为角色卡底图（支持 PNG 角色卡一键导入，导入后自动生成设定；从零写就跳过这步）；
4. 逐项填写：姓名、显示名、性别、性格、衣着外貌、背景、对话场景，并选择这个角色用哪个模型；
5. 保存后角色卡就是你的了，保持私有或公开分享由发布设置决定。

## 每一项该填什么

写得越具体，聊天时越不容易跑人设。几个维度的参考：

| 维度 | 填什么 |
| --- | --- |
| 关系设定 | 朋友 / 恋人 / 知己 / 树洞等，决定对方用什么口吻说话 |
| 开场白 | 你发起聊天时对方的第一句话，定下第一句的氛围 |
| 性格 | 脾气、说话习惯、口头禅、边界感 |
| 背景故事 | 人设的来龙去脉，给模型提供语境 |
| 对话场景 | 常聊的话题范围与情境 |

**关系设定与开场白是最影响体验的两项。** 另有一个容易被忽略的技巧：与其堆形容词，不如在角色设定里补几段**对话示例**——给几个你期望的问答样本，比「温柔」「高冷」这类词管用得多。有剧情需求的，剧情节点里写清楚触发条件与走向，注意别让逻辑互相矛盾。

## 角色跑偏了怎么修

1. 在对话里用明确指令当场纠正，比如「请用平静一点的语气回应」；
2. 不奏效就回角色编辑页，补更详细的性格描述和对话示例；
3. 涉及剧情节点的，检查关键词是否打错、条件有没有冲突；部分复杂剧情要**保存后重新加载角色**才生效；
4. 还不对，回头查模型贴合度——不同模型对人设的稳定程度差别很大，见 [模型与参数调校.md](模型与参数调校.md)。

**改完设定记得重开对话**：新设定要重新进入聊天才完全生效，接着旧对话聊很可能还是原来的表现。

## 两个实用提醒

- 退出角色编辑或对话界面前点一下保存，有用户反馈过内容偶发丢失；
- 角色卡支持 PNG 一键导入，网上分享的角色卡多是这个格式，导入后逐项核对一遍再开聊，比手动重输省事。
