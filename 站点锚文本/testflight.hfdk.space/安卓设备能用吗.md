# 安卓设备能用吗

> 本篇回答「TestFlight 有没有安卓版」：安卓设备的现状、网上流传的 testflight APK 是什么，以及安卓项目的替代方案。
> **相关文档**：[怎么加入Beta测试.md](怎么加入Beta测试.md) · [90天有效期规则.md](90天有效期规则.md)

## 一、直接给答案：没有安卓版

TestFlight 在 2014 年被苹果收购后，安卓支持于当年终止，此后再没有苹果渠道的安卓版本。它只经 App Store 分发，覆盖 iPhone、iPad、Mac、Apple TV、Apple Watch 与 Vision Pro；邀请链接在安卓手机上打开也不会进入安装流程，这是渠道本身决定的。

## 二、网上流传的 testflight APK 是什么

- 全部出自第三方打包，与苹果没有从属关系。以流传较广的一份为例：版本 3.2、约 26.63MB——这类包的实际内容没有任何渠道背书，可能只是个空壳，也可能与名称完全无关。
- 非要安装的话，风险自行评估：看清索要的权限，装完发现内容对不上直接卸载。安装步骤与常见问题整理在 [TestFlight 测试笔记](https://testflight.hfdk.space/) 一站的下载页。
- 想参加真正的 Beta 测试只有一条正路：一台苹果设备 + App Store 版 TestFlight + 开发者邀请，路径见 [怎么加入Beta测试.md](怎么加入Beta测试.md)。

## 三、安卓项目的 Beta 测试用什么

如果你是开发者，想给安卓应用做类似的事，常见选择：

| 方案 | 适合场景 |
| --- | --- |
| Google Play 测试轨道 | 走商店的正式测试流程，分内部 / 封闭 / 开放式三种轨道 |
| Firebase App Distribution | 不经过商店，快速把构建发给指定的一批测试员 |
| 直接发安装包 | 小范围、临时给少数人试用 |

各方案的入口与名额规则会随时间调整，以各家页面当时显示为准。测试期限、到期处理这类规则只存在于 TestFlight 平台，安卓侧的安装包不适用，见 [90天有效期规则.md](90天有效期规则.md)。
