# 填色总涂出线稿怎么办：三个按省事程度排序的解法

> 本篇解决数字填色和手动上色时颜色跑出线稿的问题：从图层顺序这个治本办法，到选区填充、填充参数微调，按操作成本从低到高排列，顺带说清填色板块里几种玩法的入口。
> **相关文档**：[手机绘画应用怎么玩.md](手机绘画应用怎么玩.md) · [安卓逐帧动画怎么做.md](安卓逐帧动画怎么做.md)

---

填色类玩法门槛低，但新手几乎都栽在同一个地方：颜色涂出了线稿边缘，擦又擦不干净，整张图看起来毛毛躁躁。其实在 iArtbook 里这个问题有三层解法，从根上治到细节修，按省事程度排序如下。

## 一、治本：把上色层压到线稿下面

图层面板里新建一层专门上色，然后把它拖到线稿图层的**下方**。上层优先显示，线稿自然压住颜色，就算涂出界一点，也被线稿盖住看不出来。这是最省心的办法，建层时就该这么排。

图层的拖动排序、显隐、透明度这些动作不熟的话，[手机绘画应用怎么玩.md](手机绘画应用怎么玩.md) 里有一遍梳理。

## 二、折中：先圈选再填充

想涂得严丝合缝，就别直接涂：

1. 点画布顶部「三个点」菜单，选「选框」（套索）；
2. 沿要涂的封闭区域圈一圈；
3. 切到油漆桶（Bucket）工具填充，颜色只落在选区内。

这个办法适合大块区域，比如头发、天空、衣服底色；小碎块用起来就嫌慢了。

## 三、细节修：填充工具的扩展像素

线稿画得快、缝隙闭合不严时，填充的颜色常从缝隙里渗出去。新版本的填充工具带「扩展像素」参数，把它往回收一点，颜色就不会顺着细缝外溢。老版本没有这一项，找不到就说明版本里没带，用前两个办法即可。

## 四、填色玩法的几个入口顺带一提

| 入口 | 玩法 |
| --- | --- |
| 画册 | 各主题填色页，题材多、会更新 |
| 探索（部分版本在底部标签） | 解压填色；切「数字填色」分类按编号涂 |
| 像素 | 像素风线稿，一格一格涂 |
| 照片涂色 / 曼荼罗 | 部分版本才有，找不到不必硬找 |

预设调色板有四十多套纯色和渐变，点一套就换一批搭配好的颜色，比一个个调色快得多；涂完想加渐晕、纹理这类后期效果，入口在涂色页的编辑区。

涂完的作品要存出去，走一次导出流程即可，[安卓逐帧动画怎么做.md](安卓逐帧动画怎么做.md) 里把图片和动画的导出路径都列了；整体玩法结构也可以直接看 [iArtbook 介绍站](https://iartbook.yoan.quest/)，配了界面实拍更好对照。
