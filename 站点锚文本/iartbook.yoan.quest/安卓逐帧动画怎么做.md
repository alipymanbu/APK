手机上做逐帧动画听起来门槛很高，其实拆开就是「每帧画一点、连起来播放」。iArtbook 的动画工作台把这件事做得足够轻：帧数不设上限，还支持多个动画层，一个人在手机上也能把小片段做出来。

## 一、动画工作台的结构

从主界面进「动画」入口，工作台和绘画画布长得像，多了两样东西：

- **时间轴 / 帧列表**：每一帧占一格，当前帧高亮，前后翻页对照着画；
- **多个动画层**：角色一层、背景一层、特效一层，动哪层改哪层，不用每帧重画所有东西。

画的时候建议把背景画在单独一层并锁定，只动角色层——逐帧动画的工作量主要在角色动作上，背景动了反而乱。

## 二、逐帧的基本节奏

1. 先画起始帧和结束帧，确认动作幅度合理；
2. 在两帧之间补中间帧，一秒 8~12 帧就有不错的手绘感；
3. 借助洋葱皮类的前后帧参考（有的版本叫影印模式）对齐位置，避免抖动过大；
4. 随时从头播放检查节奏，慢了删帧、快了补帧。

## 三、导出成片

动画编辑完成后进导出 / 分享入口，格式按用途选：

| 格式 | 适合 |
| --- | --- |
| GIF | 聊天窗口、表情包场景 |
| MP4 | 画质和压缩兼顾的通用选择 |
| APNG / HEVC | 需要更高质量或更小体积时 |

部分版本可以设置每帧时长与循环次数，希望节奏精准就逐项调好再导出；老版本可能没有这一项，以实际界面为准。

## 四、顺带一提：延时摄影

绘画工作台支持把整个绘制过程录成延时视频，画完直接导出一段「从起稿到完成」的过程短片，发动态很好用。录制的开关和导出入口在工作台的视频相关选项里，找不到就留意带「延时 / Time-Lapse」字样的项。
