# Keepsafe 忘了密码怎么找回

> 主 PIN、相册密码忘了分别怎么走找回流程，哪些情况走不通，这篇按顺序讲清。
> **相关文档**：[照片保险箱玩法与设置要点](照片保险箱玩法与设置要点.md) · [换新手机怎么迁移照片](换新手机怎么迁移照片.md)

---

## 一、找回只有一条通道：恢复邮箱

Keepsafe 的找回路径就一条 —— 往当初填的恢复邮箱发验证码或重置链接。所以先确认两件事：设 PIN 时填过邮箱；那个邮箱现在还能登录。两件里缺一件，下面的流程都走不通。这也解释了为什么第一次设置时「填恢复邮箱」这步不能跳。

## 二、忘了主 PIN

1. 在锁屏界面找 **Forgot PIN / 忘记密码** 入口（一般输错几次后出现）；
2. 去恢复邮箱收重置邮件，按邮件指引重设；
3. 重设后进保险箱，先确认照片都在再继续用。

邮件迟迟不来，先翻垃圾箱、查发件人有没有被拉黑、确认收件箱没满，再点重发。**别用「卸载重装赌它清空密码」**—— 重装确实可能清掉 PIN，但也会把没同步的照片一起清掉，代价完全不对等。

## 三、忘了相册密码

相册密码（Album Lock，Premium 功能）不走主 PIN 那条路，步骤是：设置 → **Album Passwords** → **Remove all Passwords** → 邮箱收 4 位字母验证码 → 填回应用 → 再点一次移除，全部相册解锁。注意这会清掉**所有**相册密码（包括诱饵相册的），验证码 24 小时有效、以最后收到的那个为准。

## 四、什么情况走不通

| 情况 | 结果 |
| --- | --- |
| 留了邮箱、邮箱能登录 | 按上面两节走，能找回 |
| 跳过了邮箱、或邮箱已注销 | 找回通道走不通，只能联系支持邮箱说明情况 |
| 没开同步、本地数据又清了 | 密码找回来也只是个空保险箱 |

**找回密码和找回照片是两件事**：前者靠邮箱，后者取决于有没有开同步或另留副本。

## 五、防再次卡住

- 设完 PIN 当天填恢复邮箱，并记下用的是哪个邮箱；
- 开了 Fake Pin（诱饵密码）的话，真假两套码都要记 —— 「照片全不见了」的求助里相当一部分是输错了码、进了空诱饵保险箱；
- 验证码收不到的完整排查顺序，以及界面里的其余开关说明，见 [照片保险箱玩法与设置要点](照片保险箱玩法与设置要点.md)；Keepsafe 的站点入口在 [keepsafe.wxhp.skin](https://keepsafe.wxhp.skin/)。
