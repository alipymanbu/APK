# Susan 视频链接解析工具入门

> Susan 是一款开源的安卓视频解析播放工具：把视频平台剧集的分享链接粘进它的输入框，就能在应用里直接播放；也可以不走链接、直接搜片名找片。这篇先把它的定位和玩法讲清楚，判断它是不是你想要的那个工具。

## 它解决什么问题

在手机上看视频平台的剧，常常被开屏广告、非会员清晰度限制、客户端体积这类事搅得没有耐心。Susan 的思路很直接：你在视频 App 里点「分享 → 复制链接」，回到 Susan 粘贴这条链接，它解析出可用的播放源后直接开播——一条链接对应一次解析，播下一集再复制一集。

它的界面也贯彻了这种极简：打开就是标题、一个「请输入视频链接」的输入框和一个播放按钮，没有别的干扰。长辈拿到手也能一眼看懂怎么用。

## 两条找片路径

- **链接解析**：主流视频平台（腾讯视频、爱奇艺、优酷、芒果 TV、哔哩哔哩）的播放页分享链接都能粘，注意要拿「分享 → 复制链接」生成的播放页地址，聊天里转发的口令文本可能识别不了。
- **站内搜片**：点右上角放大镜输入片名，内置资源库里有的直接选集播放；首页还有影视库信息流，点封面就开看。两条路资源不重合，一条搜不到换另一条。

## 一些基本的盘子信息

 Susan 免费开放使用，没有账号体系，装完即用；应用无内购，也没有弹窗广告；源码在 GitHub 公开，平台改版导致解析失效时，社区通常会较快跟进出新版。手头常见的安装包在 9MB 上下，对老手机很友好。
