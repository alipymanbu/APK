# 认识一款装在口袋里的安全学习工具

> 学习 Kali Linux 不一定非要先有电脑环境：这款叫 Learn Kali Linux 的安卓应用把整套图文教程装进了手机。它是什么、讲什么、怎么用，一篇说清。

## 一、它是什么

Learn Kali Linux 是一个教学类安卓应用：内置一套按主题分章的 Kali Linux 图文教程，覆盖基础概念、常用命令、网络与脚本、安全工具主题章。v2.1 版本体积 18.10M，要求安卓 5.2 及以上，无需 Root。

要说清的第一件事是：**它是教程，不是系统**。装上它不等于手机里有了 Kali——没有终端可敲、没有工具可运行，它的角色更像一本口袋教材。

## 二、内容与界面

打开应用就是深色卡片式菜单，六个入口一目了然：Let's Start（进入章节目录，学习从这里开始）、Tool Box、Our Apps、Share、Feed Back、No Ads。日常使用只认 Let's Start 就够。

章节按主题组织，比如漏洞分析（Vulnerability Analyses）类章节会逐个介绍工具的用途，配图是 Kali 桌面环境的实操截图。正文为英文，配合手机自带的划词翻译读起来并不吃力；教程内容随安装包离线内置，读章节不需要联网。

想先看真机界面再决定装不装，[kali linux 安卓版介绍站](https://kali-linux.qjxz.skin/) 里放了实拍截图与内容板块说明。

## 三、怎么用效率高

单靠手机硬读，效率一般。更顺的节奏是四步循环：

1. 手机上读一章基础或命令主题；
2. 合上手机，把这一章「讲了什么」复述给自己听；
3. 回到电脑虚拟机里，把章里的命令逐条敲通；
4. 报错自己查原因，查完再进下一章。

配套的虚拟机搭建思路（VirtualBox + 预建镜像 + 快照）不难，半小时内能就位。

## 四、获取方式

安装包通过网盘分享分发：打开介绍站的[下载与安装页](https://kali-linux.qjxz.skin/download.html)，转存到自己网盘后下载 APK，允许「安装未知来源应用」后按引导装完即可。版本、体积与系统要求在下载页都标注了，装前先核对手机系统版本。
