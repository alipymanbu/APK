# 不刷机不Root在手机上练Linux命令

> 手机不想刷机、不想 Root，又想把 Linux 命令练起来——有哪些不折腾设备的做法，各适合什么阶段，这篇讲清。

## 一、先想清楚：练「读」还是练「敲」

练 Linux 命令分两个层次：

- **读得懂**：知道一条命令是干什么的、参数大概什么含义；
- **敲得通**：在真实终端里把命令跑起来、看懂输出与报错。

不刷机不 Root 的手机，两样都能练，只是「敲」要借助专门的环境，别拿系统自带的东西硬来。

## 二、「读」这一层：装个离线教程最省事

应用商店之外，还有一种常见的获取方式是网盘分享的安装包。以 [kali linux 手机版图文教程](https://kali-linux.qjxz.skin/download.html) 为例：转存到自己的网盘账号后下载安装，打开就是分章图文——基础概念、`ls`/`cd`/`sudo`/`apt` 这类高频命令、网络与脚本主题，离线可读，地铁上也能翻。

这个阶段的目标很朴素：把命令「混熟」。看到一条命令，能说出它解决什么问题，就算过关。

## 三、「敲」这一层：两条不用 Root 的路

**路线 A：Termux（轻量起步）**

Termux 是安卓上的终端模拟器，不用 Root 就能装。`pkg` 装软件、`ls`/`cd`/`grep` 这些核心命令都能真实跑起来，日常练手完全够用。局限是它不是完整的 Kali 环境，渗透类工具装不全。

**路线 B：Kali NetHunter Rootless（更接近真 Kali）**

Kali 面向安卓的方案叫 NetHunter，其中 Rootless 档位明确支持未 Root、未改机的手机：基于 Termux 拉起一个 Kali 命令行环境，配合 KeX 还能开图形桌面。代价是镜像体积大（预留十几 GB 存储）、部分依赖内核的能力用不了——作为学习环境已经足够。

两条路的共同点：**都跑在手机里的隔离环境中**，不动系统、不碰保修；出了问题删掉重装就是。

## 四、配一台电脑虚拟机，效果翻倍

手机负责碎片时间「读」，电脑虚拟机负责整块时间「敲」：

1. VirtualBox 免费好用，Kali 有官方预建镜像，导入即用；
2. 每次实验前拍快照，命令玩崩了一键还原；
3. 手机教程里的配图多是桌面环境截图，与虚拟机里的画面能直接对上。

这套「手机读 + 电脑敲」的组合，是投入最低、走弯路最少的练法。
