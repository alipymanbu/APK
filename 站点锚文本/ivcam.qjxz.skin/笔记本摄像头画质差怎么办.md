# 笔记本摄像头画质差，用手机顶上最省事的办法

笔记本自带的 720p 摄像头在视频会议里常年被人吐槽：逆光发灰、暗光糊成一片、色彩发黄。换外接摄像头要花钱，画质提升也有限；其实更好的镜头你已经有——手机的主摄。把它变成电脑能用的摄像头，画质直接上一个档次。

## 为什么手机的镜头更适合开会

手机主摄的传感器尺寸、防抖和夜景能力都远超笔记本那颗小摄像头，直播平台和会议软件的清晰度上限也吃得到。用 iVCam 这类工具，手机画面会以虚拟摄像头的身份出现在电脑里，Zoom、Teams、OBS 都能直接选中，不需要在会议软件里做任何特殊配置。

## 具体怎么弄

1. 手机装 iVCam App，电脑装它的 Windows 客户端（客户端会一并装好虚拟摄像头驱动）。
2. 手机和电脑连同一个 Wi-Fi，App 打开后自动发现电脑、完成配对；被路由器拦住时可以手动输 IP 或改用 USB 线。
3. 在会议软件的摄像头列表里选 e2eSoft iVCam，画质档位可在手机端从 360p 一直调到 4K。
4. 手机麦克风还能顺手变成电脑的无线麦克风，台式机不用另接耳麦。

免费版即可完成上面全部流程，画面左上角带水印，介意的话购买授权即可去除（手机 App 内购或电脑端许可证，任选一边）。完整的介绍与画质档位说明见这篇[手机当电脑摄像头](https://ivcam.qjxz.skin/)的介绍页。

## 两个小提醒

- 想跑高分辨率，优先用 USB 线直连，稳定性比 Wi-Fi 好，也不受同屋别人刷视频的干扰。
- 会议前先在 App 设置里把分辨率和帧率定好，进了会议再切档位容易闪断。
