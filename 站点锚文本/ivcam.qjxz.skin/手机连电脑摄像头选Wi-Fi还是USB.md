# 手机连电脑摄像头，选 Wi-Fi 还是 USB 线

把手机当电脑摄像头用，连接方式只有两条路：Wi-Fi 无线，或 USB 有线。两条路 iVCam 都支持，但体验差异不小——选错了不是不能用，而是画质和稳定性都打了折扣。

## Wi-Fi：方便，但看网络环境脸色

Wi-Fi 方式只要手机和电脑在同一台路由器下就能自动配对，App 打开后雷达界面里搜到即连，全程不用接线，手机想放哪儿放哪儿，这是它最大的好处。

代价是稳定性交给网络环境决定：

- 同屋有人看视频、下载，画面帧数立刻波动；
- 路由器开了 AP 隔离，手机和电脑直接互相看不见，只能手动输 IP 绕一下；
- 穿一堵墙信号衰减，延迟肉眼可见地变大。

家用会议、网课这类对稳定性要求不极端的场景，Wi-Fi 完全够用；1080p 在像样的路由器下跑得很从容。

## USB：稳、快，还能顺便充电

USB 直连的带宽和延迟都远好于无线，1080p 高帧率跑起来更稳，直播推流、长时间录制这类场景优先选它。安卓手机需要在开发者选项里打开 USB 调试、连接模式选传文件（MTP），必要时装厂商驱动；iPhone 则要装桌面版 iTunes 让系统认出设备。设置一次之后，以后插线即连。

还有一个容易被忽略的好处：边用边充电。一场两小时的直播下来手机不会掉电。

## 结论

| 场景 | 建议 |
| --- | --- |
| 日常视频会议、网课 | Wi-Fi，省事优先 |
| 直播推流、录课、长录制 | USB，稳定优先 |
| Wi-Fi 被路由器设置挡住 | 手动输 IP 或直接换 USB |

两条连接方式的具体设置步骤与画质档位，[手机当电脑摄像头](https://ivcam.qjxz.skin/)的介绍页里按「发现—连上—调画质—插进软件」四步整理过，照着做即可。
