# Wplace 安卓版下载与安装步骤

想在手机上随时补两笔像素，安卓版的安装并不复杂：全程不需要连电脑，几个步骤就能装好。本文按实际操作顺序整理，并附上安装途中最常见的几种拦截情况。

## 安装前的两件小事

- 确认手机剩余空间足够——软件本体体量很小，十几 MB 量级，但要留出缓存与系统余量；
- 准备好网络环境——安装完成后首次打开需要登录账号并加载地图数据，网络不稳会白屏或转圈。

## 四步装好

1. **获取安装文件资源**：进入 [Wplace](https://wplace.qhah.skin/) 下载页，点击按钮打开夸克网盘分享页，把安装文件转存到自己的网盘账号下；
2. **下载到手机本地**：在网盘客户端或网页里把文件下载下来，通常落在「下载」目录，也可以在通知栏里直接点开；
3. **放行「安装未知应用」**：安卓默认拦截应用商店之外的安装来源。到系统设置里，找到你用来下载的浏览器或文件管理器，允许它「安装未知应用」——授权完成后再重新点开 APK；
4. **安装并登录**：按屏幕提示确认安装，完成后打开软件登录账号，把地图放大到网格出现，选色点一下就是你的第一格。

## 安装途中容易卡住的地方

| 现象 | 处理思路 |
| --- | --- |
| 点按钮后网盘页打不开 | 多为网络波动或浏览器拦截跳转，换系统浏览器或换网络再试 |
| 提示「来源不明」被拦 | 这是系统保护而非文件问题，按第 3 步授权后重新安装 |
| 装好却白屏、一直转圈 | 高峰时段服务端压力大，等几分钟再进，或换个网络环境 |
