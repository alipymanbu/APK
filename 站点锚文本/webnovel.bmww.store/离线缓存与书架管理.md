# 离线缓存与书架管理

> 这篇讲 WebNovel 的章节怎么缓存到本地、书架怎么整理、阅读界面哪些设置值得先调。
> **相关篇目**：[不充值的解锁与追更玩法.md](不充值的解锁与追更玩法.md) · [安卓版下载安装步骤.md](安卓版下载安装步骤.md)

## 一、章节离线缓存

通勤、飞行模式或网络不稳时的用法：

1. 打开书籍目录页点右上角下载图标，或在阅读界面菜单里选 Download。
2. 选择缓存范围（最近几章 / 自定义区间），确认后开始缓存。
3. 缓存完成的章节在无网络时也能从书架直接打开。

两点注意：已解锁的付费章节才能缓存离线，未解锁的不会进离线包；文字章节占不了多少空间，缓存漫画时体积明显变大，空间紧张就在设置里清掉已读缓存，不影响云端进度。

## 二、书架怎么整理

- 书架页按更新时间排列，长按书封可以置顶、移出。
- 追更超过十几本时，把不更新的完本书移出去，新章红点提示才有意义。
- 书架挂在账号下云端同步，换设备登录同一账号自动恢复；只有离线章节不跨设备，新手机上要重新点一次下载。

找新书别只靠搜索：书单广场里按题材、梗、完结状态归拢的读者合集，一份几十本，比关键词挨个试效率高，看中再逐本收进书架。

## 三、阅读界面值得先调的五项

| 设置 | 建议 |
| --- | --- |
| 字号 | 长篇阅读 18pt 以上更省眼 |
| 背景色 | 深色界面夜间用，米黄底白天用 |
| 翻页方式 | 滚动模式适合网文长章 |
| 亮度 | 应用内独立调节，不改系统亮度 |
| 自动滚屏 | 速度可调，快节奏扫文时解放双手 |

设置全局记忆，调一次对书架里所有书生效。

## 四、换个设备接着读

阅读进度、书架、已解锁章节都随账号走；书单、投票记录也在同一账号下。想看这个应用完整的图文介绍与界面实拍，见 [webnovel 追更手册](https://webnovel.bmww.store/)。还没装的话，先从 [安卓版下载安装步骤.md](安卓版下载安装步骤.md) 开始。
