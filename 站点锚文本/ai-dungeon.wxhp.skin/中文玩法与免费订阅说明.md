## 一、中文可以直接输入

你打中文的行动与台词，AI 能读懂并接着写，这是很多中文玩家的常规玩法。但要注意：中文续写的流畅度比英文场景波动更大，想稳定用中文，靠下面几个做法，而不是指望某个开关：

1. **全程只用一种语言**——设定、行动、台词都写中文，混着写会让 AI 在两种语言间摇摆；
2. **开局就定基调**——第一轮直接用中文开场，或在 AI Instructions 里写一句「全程使用简体中文」，这样每轮生成都会带上这条要求；
3. **开局多 Retry**——中文开局最容易出现半中半英的句子，连点几次从候选里挑一条纯中文的，后面会顺着这条的风格写；
4. **换个模型试试**——不同模型的多语言表现差别很大，同一段剧情换模型各试一轮，看谁的中文最顺。

## 二、界面是英文怎么办

界面本身没有中文选项，但高频入口就那几个，对照着记很快：

| 英文 | 含义 |
| --- | --- |
| `Do` / `Say` / `Story` / `See` | 行动 / 说话 / 旁白 / 生图 |
| `Retry` / `Edit` / `Erase` | 重写 / 修改 / 删除 |
| `Undo` / `Redo` / `Continue` | 撤销 / 重做 / 续写 |
| `My Stuff` | 我的内容（冒险与场景） |
| `Discover` | 发现（社区场景） |
| `Quick Start` | 快速开始 |

## 三、免费档能玩到什么程度

不订阅也能一直玩：免费档用免费模型时**不限次数、也没有广告**，开冒险、走剧情、玩社区场景都行。

订阅买的是四样东西——更强的模型、更长的上下文、更多的记忆位、每月发放的 Credits（点数，主要用于 `See` 模式生图）。档位从每月 14.99 美元到 99.99 美元分多档，上下文从 8k 一路到 32k；价格与额度时有调整，以应用内当时显示为准。

判断标准很实际：偶尔开几局短故事，免费档完全够用；一条冒险写到几十轮以上、开始觉得 AI 记不住前面的人物设定，才是订阅能解决的问题。

## 四、AI 忘设定怎么补

上下文装不下的早期内容会被截掉，所以「治健忘」的核心是把关键设定放进每次都带上的区域：铁律写进 Plot Essentials、人物地点做成关键词触发的 Story Cards、世界状态的变化记进 Memory。每条写短、写具体、写事实，比大段描写有用得多。
