# 安卓端下载安装步骤

> 从哪拿安装包、怎么装、装完怎么登录，按顺序走一遍只要几分钟。
> **相关文档**：[文字冒险游戏怎么玩](文字冒险游戏怎么玩.md) · [中文玩法与免费订阅说明](中文玩法与免费订阅说明.md)

AI Dungeon 的安卓端是一个约 35.6M 的安装包，要求安卓 5.2 以上。这篇只讲获取与安装；装完怎么开第一局，见[文字冒险游戏怎么玩](文字冒险游戏怎么玩.md)。

## 一、拿到安装包

安装包通过夸克网盘分享获取，入口整理在 [AI Dungeon 介绍站](https://ai-dungeon.wxhp.skin/)的下载页：打开站点后进入「下载与安装」页，点按钮跳到网盘分享，先转存到自己的网盘账号，再下载到手机。文件名为 `AI Dungeon_v1.3.6.apk`。

下载完成后看一眼文件名与大小（约 35.6M）对不对得上，残缺包是后面「解析包错误」最常见的原因。

## 二、安装四步

1. **转存并下载**：按上面的入口把安装包转到自己网盘，下载到手机；
2. **点开 APK 安装**：在文件管理器里点开安装包；系统弹出「是否允许安装来自此来源的应用」时，去系统设置对该来源授权一次——这是安卓对未知来源安装包的常规拦截，装完可以关掉；
3. **联网打开**：故事在云端进行，必须联网才能进入；离线状态下停在加载是正常表现；
4. **注册登录**：用邮箱注册并完成验证，登录后冒险与场景都存在云端账号里，换设备不丢。

## 三、装不上时的三种情况

| 症状 | 处理 |
| --- | --- |
| 解析包错误 / 装不上 | 确认系统为安卓 5.2 以上；删掉旧包重新下载一次再装 |
| 装完打开就闪退 | 核对包名为 `com.aidungeon`（别装成仿冒包）；清一次应用缓存再启动 |
| 打开一直转圈、要求登录 | 转圈先换网络环境；要求登录是正常流程，存档在云端必须登录 |

## 四、装好之后

第一次进入会有英文界面，高频按钮记住 Do / Say / Story / See（行动 / 说话 / 旁白 / 生图）和 Retry / Edit / Undo（重写 / 修改 / 回退）就够用了；中文输入与界面的更多细节，见[中文玩法与免费订阅说明](中文玩法与免费订阅说明.md)。
