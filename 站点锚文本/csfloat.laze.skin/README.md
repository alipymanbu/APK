## 一句话认识 CSFloat

CSFloat 是 CS2（Counter-Strike 2）饰品圈的 P2P 交易市场：饰品不经平台库存、由买卖双方在 Steam 里直接互发交易报价，平台负责验证与结算；同名浮点数据库收录超 11.7 亿件饰品，销售手续费 2%、买家侧零手续费。安卓客户端的获取入口与安装步骤，见 [CSFloat 手机端介绍站](https://csfloat.laze.skin/)。
