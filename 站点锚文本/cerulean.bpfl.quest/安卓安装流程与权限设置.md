# Cerulean 安卓安装流程与权限设置

> Cerulean 的安卓安装包（APK）走的是安装文件资源获取的方式：先把网盘里的包转存到自己账号、再下载安装。这篇把从拿到包到装好能用的流程写全，权限怎么给也一并说明。

## 一、装之前确认两件事

1. 这是**安卓安装包**，需要一台能正常联网的安卓手机；iPhone 是另一条发布线，不适用这套流程。
2. 手机剩余空间建议留出安装包体积的两倍以上——安装过程中会产生临时文件，空间太紧容易中途失败。

## 二、安装流程（四步）

1. **先转存，再下载。** 打开安装文件资源（夸克网盘）分享页，先「保存到网盘」转存到自己的账号，再从转存后的目录下载原文件。转存这一步不建议省：分享链接存在失效的可能，转存之后你自己的副本随时能再下。
2. **下到手机。** 手机端直接下载最省事；电脑上下载的话，用数据线或传输工具把 APK 传进手机存储。下完核对一下文件大小，与来源页标注的体积相差太多就说明拿到的不是这份包。
3. **点开安装，允许未知来源。** 在文件管理器里点 APK 文件；系统若提示「禁止安装未知来源应用」，按提示到设置里允许你正在用的文件管理器（或浏览器）安装应用。这只是针对这一次安装动作的常规拦截，不需要长期放开。小米、华为等机型还会多弹一次「风险应用」确认框，勾「仍要安装」即可。
4. **完成安装并核对版本。** 装完点「打开」，先到「设置 → 应用管理」里确认版本号与包名，再去应用信息页核对是否与来源页标注一致——这一步能避免「装到别的版本」的疑惑。

## 三、权限怎么给

装好后有几类工具依赖系统权限，没给就是最常见的「看起来坏了」：

| 症状 | 缺的权限 |
| --- | --- |
| 分贝仪打开无数值 | 麦克风 |
| 心率检测、量角器黑屏 | 摄像头 |
| 图片保存后相册看不到 | 存储 / 照片 |

入口一般在「设置 → 应用管理 → 应用权限」里（各品牌叫法略有差异），把对应权限允许后，把应用从后台划掉重开一次即可。另外量角器、心率这类占用摄像头 / 麦克风的工具，用完就从后台划掉，别让镜头一直保持占用。

## 四、装完认认工具

第一次进应用建议先扫一遍工具列表，把常用的留着眼熟。每个工具的用途与典型场景整理在 [小工具清单与用途分类](小工具清单与用途分类.md)；名字与版本号之间的渊源见 [一个木函改名了吗](一个木函改名了吗.md)。
