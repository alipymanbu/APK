# listen1 资料站：安装、歌单搬家与使用答疑

这里是关于 listen1 的第三方资料目录，收录安卓安装、歌单导入、播放排查与数据备份四篇实用说明。

listen1 是开源的多平台音乐聚合播放器：一个搜索框按平台出结果，旧歌单发一条链接就能整单导入，收藏跨平台归拢，数据本地自管。功能总览、界面速览与安装包获取入口见 [listen1 介绍站](https://listen1.fewf.ren/)。
