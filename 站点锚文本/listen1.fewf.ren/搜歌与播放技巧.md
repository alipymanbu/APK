# listen1 搜歌与播放技巧：搜不到、放不出来怎么办

> 本篇讲 listen1 的搜索入口与省时间的搜法、播放页控制项，以及「搜到了却放不出来」的按序排查。

## 一、搜索：一次输入，按平台出结果

打开 listen1，首页就是搜索栏。歌名、歌手名、专辑名输进去，命中结果**按来源平台**分列——同一首歌可能同时存在于多个平台曲库。点顶部平台标签可以只看单一平台的命中。

三个省时间的搜法：

- 记得歌名忘了歌手 → 直接搜歌名，用结果里的歌手字段核对；
- 同名歌太多 → 搜「歌手名 + 歌名」，一步到位；
- 找某平台的独家内容 → 搜完切到对应平台标签，别在聚合列表里翻。

## 二、播放页有什么

| 位置 | 作用 |
| --- | --- |
| 底部一排 | 播放 / 暂停、上一首、下一首 |
| 左下角 | 循环模式，点一下切一种（顺序、单曲循环等） |
| 进度条 | 拖动定位任意位置 |
| 右上角 | 收藏到指定歌单等操作 |

底部常驻一条迷你播放栏，浏览别的页面也能切歌、暂停，点它回到完整播放页。

## 三、放不出来，按这个顺序查

1. **换平台同曲**：一个平台侧资源异常，另一个平台可能正常——聚合播放器最大的好处就在这；
2. **查网络**：在线播放依赖网络，切 Wi-Fi 或换个环境再试；
3. **判断是不是来源整体失效**：在该平台搜一首大热歌曲，热的也放不出来，基本是该来源停服或接口失效（典型如虾米音乐 2021 年初关停），不是你的问题；
4. **确认版本**：安卓手机版当前最新为 0.8.1，旧版本对平台接口的适配停留在当年，装新版可到项目发布页查看（安装路径见[安卓安装方法.md](安卓安装方法.md)）。

都试过还不行的个别歌曲，多半是平台侧当时不可用，过几天再搜同一首看看。

## 四、两个使用习惯提醒

- **流量**：在线播放每首歌都走流量，长听建议连 Wi-Fi；手机版没有「下载成文件」的入口，要离线听的歌在自己有权限的平台 App 里下载；
- **后台播放**：息屏后是否续播取决于系统后台策略，被杀后台就在系统设置里给它关掉电池优化、允许后台运行。

搜到歌、建好歌单之后，记得定期备份——方法见[换机迁移与备份.md](换机迁移与备份.md)。功能总览与安装包获取入口在 [listen1 介绍站](https://listen1.fewf.ren/)。
