# PDFelement 安卓版实用笔记

> 关于手机端 PDF 处理的几篇实用笔记：直接编辑文字图片、扫描件转可编辑文本、合并与页面整理。PDFelement 是万兴科技（Wondershare）旗下的 PDF 编辑应用，安卓版把这几类高频操作收进了同一个应用。

## 目录

- [手机上怎么编辑PDF文字和图片.md](手机上怎么编辑PDF文字和图片.md) —— 哪些 PDF 能直接改、改文字与图片的最短路径
- [扫描件怎么转成可编辑文字.md](扫描件怎么转成可编辑文字.md) —— 整页是图的扫描件，先 OCR 再编辑
- [PDF合并与页面整理怎么做.md](PDF合并与页面整理怎么做.md) —— 拼文件、调页序、转方向、抽单页

三篇笔记按「拿到一份 PDF 之后最常做的事」组织，互相有链接，从哪篇开始读都行。应用的获取入口与整体功能主线，见 [PDFelement 安卓版](https://pdfelement.bmww.store/)。
