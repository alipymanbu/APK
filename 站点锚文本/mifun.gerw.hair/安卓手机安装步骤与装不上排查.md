# mifun 安卓手机安装步骤与装不上排查

> 把 [mifun](https://mifun.gerw.hair/) 的安装包装进安卓手机，完整走一遍从取包到打开的流程；装不上时的几类提示也按频率排了序。
> **相关文档**：[番剧表与追更时间怎么看.md](番剧表与追更时间怎么看.md)

## 一、装之前对三件事

| 项目 | 这份安装包的情况 |
| --- | --- |
| 系统要求 | 安卓 5.2 及以上 |
| 版本 | v5.1.7（网盘固定版本） |
| 安装包大小 | 约 64.82M（建议留三倍空间给安装解压） |

网盘里是固定版本，应用内后续升级以手机上实际收到的为准；想固定用某个跑得稳的版本，就别急着升。

## 二、安装四步

1. 从分享页把 `mifun_v5.1.7.apk` 下载到手机，「下载」目录或通知栏里能找到；
2. 在文件管理器里点开这份 APK，弹出安装确认框；
3. 遇到「不允许安装来自此来源的应用」，点提示里的**设置**，给下载时用的那个浏览器或文件管理器开「允许安装未知应用」，返回再点安装——安卓 8.0 以后这个权限按应用授权，换个入口下载就要重开一次，属正常现象；
4. 进度条走完点**打开**，桌面会出现粉色播放键样式的图标。

下载尽量在手机上一次完成：电脑下载后用聊天工具转传，容易截断文件或改掉 `.apk` 后缀，装的时候就会报解析包出错。

## 三、装不上按频率排查

1. **解析包出错 / 打开闪退**：多半是文件不完整，核对大小对不对得上 64.82M，不对就删掉重下；
2. **提示与已有应用冲突**：手机里装过签名不同的同名应用，先卸载旧的再装（卸载会清掉它的本机数据，绑了账号的收藏登录后可找回）；
3. **系统版本太低**：安卓 5.2 以下装不了，到「设置 → 关于手机」确认；
4. **点安装没反应**：部分机型要在「安全设置」里临时放开安装权限，装完可再关掉。

## 四、装好后的第一眼

进应用不注册也能直接看；想认准装的是对的应用，到「设置 → 应用」里看包名，与资料里标注的一致就没拿错。界面怎么用、更新时间表在哪，[mifun](https://mifun.gerw.hair/) 介绍站的功能板块里有更顺的阅读顺序，装完不妨先逛一遍。
