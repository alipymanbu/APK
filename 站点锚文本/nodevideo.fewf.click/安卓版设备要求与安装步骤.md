# 安卓版设备要求与安装步骤：装之前先对一遍门槛

> 本篇整理 NodeVideo 安卓版的设备门槛、安装包获取路径与四步安装流程，并附覆盖安装、安装被拦截等实际会挡路的问题的处理办法。

## 一、设备门槛先核对

| 项目 | 要求 |
| --- | --- |
| 系统 | Android 7.0 及以上 |
| CPU | 64 位 |
| 运存 | 建议 4GB 及以上 |

再多说两句实在的：这类节点式合成工具吃的是**运存与存储**——多层特效、光流补帧都是重负载操作，运存紧张时预览会先变卡，导出阶段压力最大。安装包约 145 MB，加上工程缓存，建议给应用预留 2GB 以上空间。

## 二、安装包怎么拿

它的分发渠道不少（各品牌应用商店里也能搜到），这里记录的是**网盘获取**这条路径：安装包放在夸克网盘分享里，转存到自己的网盘后下载 APK 安装，步骤如下。

## 三、四步安装

1. **转存**：打开网盘分享链接，把安装包转存到自己夸克网盘（分享链接可能失效，转存到手才稳妥）；
2. **下载**：在夸克网盘 App 里把 APK 下载到手机，建议连 Wi-Fi；
3. **授权**：点开 APK，系统提示「禁止安装未知来源应用」时选择允许——各品牌入口叫法不同，有的在 `设置 → 应用 → 特殊应用权限`，有的在 `安全` 设置里，给下载时用的浏览器或文件管理器授权即可；
4. **安装**：回到安装界面点「安装」，完成后打开。工程会自动保存在首页草稿列表，之后从这里继续剪辑。

**覆盖安装提示**：装过旧版本时，直接安装新版本覆盖即可保留已有工程，不用先卸载；大版本更新前，先把重要工程导出成视频成品留底。

## 四、两个常见安装问题

- **点安装没反应 / 被拦截**：基本是「未知来源」授权没给到位，按第三步的路径重新授权对应 App 再试；
- **装完打开就闪退**：多数是运存不足——清掉后台应用再开；进入后在项目设置里把预览分辨率、预览帧率调低，长工程拆成几段做。

## 五、装好之后从哪开始

熟悉三段式界面（预览窗 / 属性面板 / 时间线）是第一步，然后按「导入素材 → 搭图层 → 关键帧动效 → 导出」的顺序走一遍完整流程。这款工具的功能清单、界面实拍与工作流讲解，可以看这个 [NodeVideo 节点式剪辑站](https://nodevideo.fewf.click/)，比应用商店的截图全面得多。
