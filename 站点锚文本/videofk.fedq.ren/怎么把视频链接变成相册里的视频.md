# 怎么把视频链接变成相册里的视频

> 本篇讲 VideoFk 的完整操作流程：从哪里复制链接、怎么粘贴解析、下载前要定哪些参数、成品最后存在哪。
> **相关文档**：[解析失败是什么原因](解析失败是什么原因.md) · [安卓版在哪下载安装](安卓版在哪下载安装.md)

---

VideoFk 是一款安卓端的多平台视频解析工具，主线操作只有四步：复制链接 → 粘贴 → 选参数 → 保存。整个链路不需要登录任何视频平台账号，解析对象是公开可访问的视频。下面按顺序拆开讲，每一步容易卡住的地方都标了处理办法。

## 一、流程总览

| 步骤 | 要做的事 | 发生在哪 |
| --- | --- | --- |
| 1 | 在视频平台 App 里复制视频链接 | 抖音 / 快手 / B 站 / YouTube 等 |
| 2 | 切回 VideoFk，点粘贴按钮读入链接 | VideoFk 首页 |
| 3 | 应用自动识别平台并解析 | 自动，无需手动操作 |
| 4 | 预览确认，选好画质与格式再下载 | VideoFk 下载设置 |
| 5 | 视频保存进系统相册，记录页可查 | 系统相册 / 下载记录页 |

## 二、先把链接复制完整

在平台 App 里找到目标视频，用「分享 → 复制链接」把链接放进剪贴板：

- **抖音**：视频右侧分享按钮 → 复制链接；
- **快手 / B 站**：分享面板里选「复制链接」；
- **YouTube**：分享 → Copy link；
- **Instagram**：帖子右上角菜单 → 复制链接（仅公开帖子有效）。

带中文和特殊符号的口令式分享链接（比如抖音那种一长串文案加网址）可以直接粘，不用先手动清理成纯网址。解析失败最常见的原因就是「没复制全」，出问题先回这一步核对，排查思路见[解析失败是什么原因](解析失败是什么原因.md)。

## 三、粘贴并解析

第一次使用前，应用会先要两笔授权：**存储权限**（保存文件用）和**后台运行权限**（下载切后台不被系统掐断），给一次即可。之后每次操作都一样：

1. 打开 VideoFk，点首页的**粘贴按钮**，从剪贴板读入链接；
2. 应用自动识别来源平台并开始解析；
3. 解析完成后显示视频信息，可以先**预览**，确认是想要的那条再下载。

要处理一整批视频（整个合集、多条分享链接）时，把多个链接一次性导入，应用按列表逐个解析下载；批量任务里还可以按需把弹幕、字幕、音乐等相关内容一起带上。

## 四、画质与格式在下载前定

开始下载前可以修改本次任务的设置，这是它和「一点就下」类工具的主要区别：

- **分辨率**：解析结果提供什么清晰度就选什么，档位越高体积越大；
- **输出格式**：视频常用 MP4，也支持 MKV 等；只要声音时把输出类型切成音频、格式选 MP3；
- 解析结果保留原始画质、不额外叠加平台水印，实际以解析的那条链接为准。

## 五、成品在哪、下载记录在哪

下载完成后视频进**系统相册**，音频归入应用内的**下载记录页**。记录页负责回看每条任务的完成状态、管理历史文件。相册里找不到时，先去记录页核对任务状态，再看文件管理器的 Download 目录。

保存目录不是只有默认一种：设置里可以分别给视频与音频指定下载文件夹，跑批量任务前先指一个专门的目录，事后整理省事很多。
