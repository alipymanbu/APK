# 解析失败是什么原因

> 本篇汇总 VideoFk 常见的几类故障：粘贴后解析不出来、下载到一半停了、昨天能用今天突然不行，每类都给可操作的排查顺序。
> **相关文档**：[怎么把视频链接变成相册里的视频](怎么把视频链接变成相册里的视频.md) · [安卓版在哪下载安装](安卓版在哪下载安装.md)

---

VideoFk 的解析下载能力来自内置的 yt-dlp 引擎，出的问题大多有规律：要么链接本身有边界，要么系统把后台下载杀了，要么引擎版本追不上平台改动。先按下面的速查表对号入座，再进对应小节处理。

## 一、症状速查表

| 症状 | 最可能的原因 | 先做什么 |
| --- | --- | --- |
| 粘贴后一直解析不出 | 链接不完整，或视频有访问限制 | 核对链接；确认视频公开（见第二节） |
| 切后台后下载就停了 | 系统电池策略杀了进程 | 电池管理设为「无限制」（见第三节） |
| 昨天能用、今天突然不行 | 平台改了接口，引擎过旧 | 更新 yt-dlp 引擎（见第四节） |
| 解析出一大堆不想要的任务 | 粘的是播放列表 / 合集链接 | 改粘单条视频页地址（见第五节） |
| 下载速度异常慢 | 平台限速或网络波动 | 换网络环境再试 |
| 提示存储空间不足 | 手机空间满了 | 清空间或删旧记录 |

## 二、解析不出来：先分清链接问题还是能力边界

两步确认，再怀疑应用本身：

1. **核对链接完整性**：口令式长链接中间缺一段就解析不了；带中文和特殊符号本身不是问题，问题多半出在「没复制全」。完整流程见[怎么把视频链接变成相册里的视频](怎么把视频链接变成相册里的视频.md)。
2. **确认视频公开可访问**：以下几类无论用什么工具都拿不到——私密视频（仅作者可见）、需要登录才能看的、有年龄限制需要验证的、平台加了版权保护的、限定地区播放的。

一个快速判别办法：把链接粘到浏览器**无痕窗口**里打开——无痕窗口里都看不了的视频，解析不了是正常现象，不是应用坏了。

链接没问题、视频也公开，还是解析不出来，大概率是平台改了页面结构，进下一节更新引擎。

## 三、下载到一半停了：把电池管理设为「无限制」

安卓的省电策略会主动杀后台应用，下载任务一进后台就可能被掐断，表现就是「切出去回个消息，回来发现下载停了」。设置路径（不同品牌叫法略有差异）：

1. 系统设置 → 应用管理 → 找到 VideoFk；
2. 进「电池 / 电池优化」；
3. 选「无限制 / 不受限制 / 允许后台运行」。

跑批量任务前尤其要先设这一项——任务列表越长、跑的时间越久，被系统盯上的概率越高。

## 四、某个平台突然集体失效：更新引擎

视频平台隔三差五改自己的接口，旧引擎对新页面就会失灵，「昨天还好好的今天不行」基本都是这一类。操作：

1. 应用设置里找「更新 yt-dlp / 更新引擎」入口，更到最新；
2. 更新后重试刚才失败的链接；
3. 单个平台失效、其他平台正常时，通常等一次引擎更新就会恢复，期间先用其他来源。

更新前确认手机能正常联网，网络不通时引擎更新本身也会失败。

## 五、粘错对象：播放列表链接会被整列解析

YouTube 带 `list=` 参数的播放列表链接、其他平台的「合集」链接，会被按整个列表解析，一口气列出几十上百条任务。只想要其中一条时，换成单条视频页地址再粘；想整列归档就让它整列解析，两种意图都合理，区别只在粘之前想清楚。

## 六、兜底检查

- 换网络试试：移动数据和 Wi-Fi 各来一次，个别平台对特定网段有限制；
- 重启应用：清掉后台重开，排除应用状态异常；
- 重发链接：删掉失败记录，重新复制粘贴，排除剪贴板残留；
- 拿另一条公开视频验证：能成说明问题在那条视频上，不是应用整体坏了。
