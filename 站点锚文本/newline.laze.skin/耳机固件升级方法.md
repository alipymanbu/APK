# 耳机固件升级方法

> 这篇讲怎么给 NewBuds 耳机做 OTA 升级：在哪看版本号、升级的正确姿势、卡住或失败的常见处理。
> **相关文档**：[耳机降噪怎么开.md](耳机降噪怎么开.md) · [耳机连不上手机怎么办.md](耳机连不上手机怎么办.md)

## 一、版本号在哪儿看

连上耳机后，打开配套 App 下滑进入「关于本机」，两段信息：

- **设备信息**：耳机名称、型号（NewBuds 为 NB-T2101）、SN 号——找售后报修时用的就是型号加 SN；
- **版本信息**：「当前耳机版本」是耳机正在跑的固件；「耳机版本更新」后面带红点，说明服务端有新固件可升。

固件是分批推送的，今天没红点不代表没有新版本，隔几天再看。查看 App 各功能入口与获取方式，见 [Newline 耳机介绍站](https://newline.laze.skin/)。

## 二、升级步骤

1. 两只耳机都放进充电盒、保持开盖并连上 App，耳机与充电盒电量最好都过半；
2. 进「关于本机」，点带红点的「耳机版本更新」开始下载；
3. 下载会申请存储权限，不给就下不动，按提示授权；
4. 安装阶段耳机会自动重启——**别合盖、别退出 App、别让手机离开蓝牙范围**，等进度走完；
5. 完成后回到页面刷新，「当前耳机版本」变成新版本号即成功。

## 三、卡住或失败的处理

| 现象 | 处理 |
| --- | --- |
| 一直停在下载中 | 查网络；确认存储权限已给 |
| 安装到一半中断 | 耳机放回盒内充电，重新开盖连接，多数会自动续装 |
| 报传输失败、反复中止 | 耳机电量低于三成就先充满；断开手机上其它蓝牙设备；关掉省电模式再试 |
| 怎么都不成 | 耳机贴到手机 50cm 内、离开路由器与微波炉等干扰源，退出 App 重进再升 |

升级期间的三条纪律：不切后台、不放音乐、不把耳机带出蓝牙范围。固件包要在蓝牙链路上传完整，中途断连就得从头再来。

## 四、升完顺手做两件事

- 看一眼三格电量是否都正常显示，左右耳都能出声；
- 到降噪与手势设置里各试一下，确认新固件没有改动默认行为；若发现手势变了，进手势页重新分配即可。
