网店上新一次要处理几十张图：逐张抠图、逐张换白底、逐张改尺寸，重复劳动量很大。快咔的批处理把这几步合并成一次操作，一次最多处理 50 张（网页端批量编辑的上限，应用内入口随版本调整）。

## 批处理能一次做什么

| 批量动作 | 用途 |
| --- | --- |
| 批量去背景 | 整组商品图一次抠掉背景 |
| 批量换背景 | 统一套白底、纯色或同一张场景图 |
| 批量调尺寸 | 按预设尺寸出图，适配不同平台规格 |
| 批量导出 | png / jpg 自选，可控制导出大小 |

## 操作思路

批量的价值在于「同一组设置打一批图」，所以先把单张流程跑通，再整批套用：

1. 用一张图确认抠图效果、背景选择、目标尺寸都对，单张步骤见[AI抠图换背景教程.md](AI抠图换背景教程.md)；
2. 在批量入口选中整组商品图；
3. 一次性套用去背景 + 目标背景 + 目标尺寸；
4. 预览整组结果，个别边缘有问题的图再单独修；
5. 统一导出 png 或 jpg。

## 两个影响质感的细节

- **阴影与倒影**：商品贴上白底后加阴影或倒影，是「贴纸感」和「实拍感」的主要差别；先用一张测试图调到满意，再整批套用同样参数。
- **平台规格会变**：各电商平台对主图尺寸、白底、留白的规定不一样且会调整，做图前去平台规则页核对一遍，避免整批返工。
