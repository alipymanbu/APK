# Cherry Studio 助手市场与MCP工具上手

本篇讲 Cherry Studio 移动版里两块最能提升日常效率的能力：预置助手的挑选与改造成自己的版本，以及内置 MCP 工具的开启方法。还没装上的先看[手机版怎么下载安装](手机版怎么下载安装.md)。

---

## 助手市场：按角色挑，而不是按功能猜

打开助手市场，应用按「职业、商业、工具」这类标签把预置角色铺开：产品经理、策略产品经理、社群运营、内容运营……每个角色自带一套写好的系统提示词，选中就能用。

几个实用习惯：

- **先搜后逛**：有明确需求直接搜「周报」「复盘」这类词，比翻分类快；
- **别怕改**：任何预置助手都能改提示词，把它的口吻、输出格式调成自己的模板，下次直接调用；
- **多模型同问**：同一个问题让几个模型一起答，横向比较谁的结论更靠谱，切模型不用退出话题。

## MCP 工具：让模型动手，不只动嘴

在 MCP 市场里，移动版内置了四个开箱即用的工具，拨动开关就挂进对话：

| 工具 | 能干什么 |
| --- | --- |
| @cherry/fetch | 抓取网页内容，让模型基于正文做总结 |
| @cherry/time | 获取当前时间，回答不再凭感觉编 |
| @cherry/calendar | 读取系统日历、添加日程 |
| @cherry/reminder | 获取、添加、修改、删除提醒事项 |

实际组合起来很好用：一句「把这篇网页的核心观点总结成五条，设个明天上午的提醒」——抓网页、读时间、加提醒一次完成，全程在对话里。

桌面端还能接入更多第三方 MCP 服务，手机上这四个则是零配置直接可用。装好工具后跟哪些模型搭配更顺，见[没有密钥能用吗](没有密钥能用吗.md)。

## 顺带一提：话题管理

每个助手的对话自动按话题归档，全局搜索能跨话题找历史记录——用得越久，这个索引越值钱。想了解应用全貌，去 [Cherry Studio 手机版介绍](https://cherry-studio.ggcd.store/) 站点逛一圈即可。
