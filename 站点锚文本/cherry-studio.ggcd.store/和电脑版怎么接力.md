# Cherry Studio 和电脑版怎么接力

Cherry Studio 有桌面端（Windows、macOS、Linux）和移动体验版两端。本篇讲两端的分工、配置怎么从电脑搬到手机、以及哪些数据值得备份。还没装的先看[手机版怎么下载安装](手机版怎么下载安装.md)。

---

## 两端各干什么活

- **电脑端是主力**：重度工作流放这里——本地知识库（RAG）、接 Ollama 或 LM Studio 跑本地模型、接更多第三方 MCP 服务，屏幕也装得下多模型对比；
- **手机端是延伸**：核心的对话、助手市场、内置 MCP 工具都在，通勤路上接着聊，碎片时间处理零碎任务。

两端是同一个开源项目的不同形态，不是两个产品。

## 配置怎么搬过去

手机版首次打开时，欢迎页就提供了「从 Cherry Studio 导入」的入口：电脑端配好的模型服务商、密钥、助手偏好，一次导入到位，不用在手机上逐项重填。

导入之外，日常两端的对话记录各自独立保存——手机上的话题不会自动出现在电脑上，反之亦然。需要跨设备带走的东西，走 WebDAV 备份。

## 建议的接力姿势

1. 电脑端当配置中心：服务商、密钥、自定义助手都在这里维护；
2. 大改动后重导一次：手机上重新走导入，保持两端一致；
3. 重要对话定期备份：WebDAV 挂上，数据留在自己掌控的存储里。

密钥和开销的细节在[没有密钥能用吗](没有密钥能用吗.md)里展开过；装好之后先把[助手市场与MCP工具上手](助手市场与MCP工具上手.md)里的工具挂起来，接力的感觉立刻就有了。应用的两端长什么样，去 [Cherry Studio 移动版介绍](https://cherry-studio.ggcd.store/) 站点看实机截图即可。
