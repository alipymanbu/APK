# Cherry Studio 没有密钥能用吗

「还没决定订阅哪家模型服务，装了是不是白装？」这是上手前最常见的顾虑。本篇把密钥、用量开销、数据走向三件事一次说清。安装过程本身见[手机版怎么下载安装](手机版怎么下载安装.md)。

---

## 不配密钥，也能先聊起来

Cherry Studio 内置了免密钥的零门槛模型通道（如 Qwen3-8B、GLM-4.5-Air 等），装好直接就能发起对话，不用注册、不用填任何 Key。想体验多模型对比、助手市场、MCP 工具，这条通道足够把流程走通。

之后想换更强的模型，再到「设置 → 模型服务商」里添加对应服务的密钥。它支持的服务商覆盖面很宽：DeepSeek、OpenAI、Claude、Gemini、Kimi、智谱、通义、文心、硅基流动，也兼容自定义 API 地址，桌面端还能接 Ollama、LM Studio 这类本地模型。

## 开销怎么算

- **客户端本身**：以 AGPL-3.0 协议开源，免费使用；
- **模型用量**：按所选服务商自己的计费规则走，用哪家、花多少都由自己挑；选免密钥通道则不产生这笔开销。

一句话：应用不收钱，花销只在模型侧，且完全可选。

## 数据放在哪

对话记录、助手配置默认保存在设备本地；只有配置了某家模型服务或 WebDAV 备份时，相关数据才会发往对应地址。跨设备同步靠 WebDAV 自行备份，走向清楚，随时可以导出查看。

这套「本地优先」的思路和它的开源属性是一体的：代码公开、协议透明，社区更新也勤快（GitHub 星标截至 2026 年 10 月已过五万二）。应用的全貌可以在 [Cherry Studio 介绍站](https://cherry-studio.ggcd.store/) 看到；已经装好的，下一步可以研究[助手市场与MCP工具上手](助手市场与MCP工具上手.md)，或者看看[和电脑版怎么接力](和电脑版怎么接力.md)。
