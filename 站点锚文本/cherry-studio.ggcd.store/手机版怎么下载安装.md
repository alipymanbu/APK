# Cherry Studio 手机版怎么下载安装

本篇整理 Cherry Studio 手机体验版从取包到装好的完整过程：装之前要准备什么、四步装到位、以及两个最容易卡住的环节。想先了解这个应用本身，可读[助手市场与MCP工具上手](助手市场与MCP工具上手.md)；装好之后对密钥有疑问的，看[没有密钥能用吗](没有密钥能用吗.md)。

---

## 装之前，先确认三件小事

- 手机留出至少 200 MB 空间：体验版安装包约 89 MB，安装过程还需要一点余量；
- 系统是较新的安卓版本，主流机型都能直接装；
- 手边有网盘应用：安装包通过网盘分享的方式获取，手机上装好网盘客户端会方便很多。

安装文件资源的获取入口在 [Cherry Studio 安卓版下载](https://cherry-studio.ggcd.store/) 这个介绍站里，先转存到自己的网盘，再取到手机。

## 四步装到位

1. **转存资源**：打开分享页，把整个应用文件夹存进自己的网盘账号，这样以后不怕原分享失效；
2. **下载安装包**：在手机网盘客户端里找到 APK 文件，下载到本机存储；
3. **允许安装**：首次点开 APK 时系统会拦一道，按提示给下载来源（浏览器或网盘应用）授予「安装未知应用」权限，再继续；
4. **打开应用**：装完在桌面点开樱桃图标的 Cherry Studio。

## 两个最容易卡住的环节

**点了安装没反应。** 多半是权限没给到——安卓对外部来源应用一律先拦，去系统设置里找到刚才下载用的应用，打开「允许安装未知应用」再试。

**下载到一半断了。** 移动网络下 89 MB 的包容易中断，切 Wi-Fi 重下即可；网盘客户端支持断点续传，重新点下载会接着上次的进度。

## 装好后的第一步

新用户直接在对话框里发条消息试试——内置了免密钥的零门槛模型，不需要任何配置就能开聊。电脑端已经在用的老用户，回到欢迎页选「从 Cherry Studio 导入」，把服务商配置一步搬进手机。两种用法各自的细节，见[和电脑版怎么接力](和电脑版怎么接力.md)。
