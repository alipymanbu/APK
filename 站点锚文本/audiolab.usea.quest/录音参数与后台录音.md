## 录音弹窗：六项一次定好

主界面点「录制音频」，允许麦克风权限后先看到参数弹窗，而不是直接开录。六项分别是：

| 字段 | 常见取值 | 怎么选 |
| --- | --- | --- |
| 输入文件名 | 按日期时间自动生成 | 录前改成自己看得懂的名字，存完才找得到 |
| 使用为 | 音乐 等 | 要当铃声 / 音乐素材就保持「音乐」 |
| 源 | DEFAULT | 一般不动；蓝牙耳机断连后重开弹窗再选一次 |
| 通道 | 立体 / 单 | 纯人声、会议记录选「单」，体积小一半 |
| 采样率 | HZ_44100 | CD 级采样率，常规录音保持默认 |
| 音频格式 | WAVE / MP3 / AAC / M4A | 见下表 |

## 采样率与比特率：两条就够

- **人声、会议、语音备忘** → MP3 + 128 kbps：体积小，语音听清绰绰有余；
- **音乐、要反复剪辑的素材** → WAVE，或把比特率调高一档：留足余量，多次编辑不掉质。

比特率越高文件越大，这是硬币两面；采样率则要**全程保持一致**——录音、剪辑、转换一路换采样率，只会白增体积或丢细节。设置页里可以定「输出默认音频格式」与默认比特率，定好之后每次导出不用再逐次挑。

## 录一半自己停了：治电池优化

被当成 bug 报得最多的现象：锁屏或切后台，录音停了，切回来后半段没有输出。原因应用设置页里自己写明了——电池优化会让它在后台停止工作。改法：

1. **设置 → 让 AudioLab 在后台运行**，按页面提示走 **电池 → 管理电池使用 → 无限制**（各品牌机型路径略有差异，有的在「电池优化」列表里改成「不允许优化」）；
2. 录音期间别手动清后台、别开省电模式，双保险；
3. 改完录一段长的验证：锁屏放两分钟，回来看波形连不连续。

## 录出来一片静音的另一种可能

「全程波形一条直线」和「录一半断了」不是一回事：直线基本是**麦克风权限**没给，或者麦克风被通话、会议类应用占着——清掉它们的后台再录，输入源保持 DEFAULT。排完仍静音，换系统自带的录音机试一下，录音机也静音就是硬件或系统层的问题了。

录好的文件下一步通常就是掐头去尾，做法见 [波形剪辑与铃声制作.md](波形剪辑与铃声制作.md)；装应用、给权限的完整流程与更多界面细节，在 [AudioLab 剪辑台笔记](https://audiolab.usea.quest/) 有按真机截图整理的版本。
