# 支持哪些文件格式转换

> 手里的文件能不能转，装之前先对一遍清单。这篇按类别列 ZenConverter 的支持范围与几条容易踩的边界，功能全貌见[本地格式转换工具功能盘点](本地格式转换工具功能盘点.md)。

## 各类格式支持一览

| 类别 | 输入 | 输出 / 动作 |
| --- | --- | --- |
| 视频 | MP4、MKV、MOV、WEBM、AVI、3GP、TS、MTS | MP4 / MKV / MOV / WEBM、GIF、概览拼图、合并、裁剪 |
| 音频 | MP3、M4A、AAC、FLAC、WAV、WMA、OGG、OPUS，或视频音轨 | MP3 / M4A / WAV / FLAC / WMA / OPUS 互转 |
| 图片 | JPG、PNG、WEBP、GIF、HEIC/HEIF、ICO | JPG / PNG / WEBP / ICO、PDF、AI 超分 |
| PDF | PDF | JPG / PNG / WEBP、TXT / Markdown、合并、压缩、加解密 |
| Office | DOCX、PPTX、XLSX | PDF / TXT / Markdown（Beta） |
| 字体 | TTF、OTF、WOFF、WOFF2 | 互转 |
| 字幕 | SRT、VTT、LRC、ASS | 四格式互转 |

## 几条容易踩的边界

- **字幕轨、内嵌封面不保留**：视频转码只留第一条视频轨和重编码后的音频，字幕、附件、多余音轨会丢——带字幕的片子转完字幕没了不是 bug。
- **扫描版 PDF 出不来文字**：PDF 导出文字靠文字层，扫描件是图片，这类文件会明确失败，工具不做文字识别。
- **HEIC 看机型**：iPhone 的 HEIC 照片走手机芯片解码，近几年的主流安卓机基本能转，老机型或冷门芯片可能真不行。
- **AI 放大不留透明**：Real-ESRGAN 放大后的图片没有透明通道，带透明的 PNG 先想清楚再用。
- **GIF 只取前 30 秒**：视频转 GIF 默认最多 30 秒、900 帧，想要的那段先用裁剪范围圈出来。
- **转出的 MP3 没有封面**：封面属于附件流，转换不复制，播放器里显示无封面是设计如此。

确认格式在清单里之后，操作路径看[手机上转视频格式的操作步骤](手机上转视频格式的操作步骤.md)；工具的整体情况与安装文件资源入口见 [zenconverter 介绍站](https://zenconverter.fewa.skin/)。
