# 本地格式转换工具功能盘点

> 想在手机上转文件格式，又不想把文件传到陌生网站？这篇盘点 ZenConverter 这类本地转换工具能接住的活儿，以及它与在线转换网站的差别。支持范围细看[支持哪些文件格式转换](支持哪些文件格式转换.md)。

## 它是什么来头

ZenConverter 是一款开源的安卓文件格式转换工具，用 Kotlin 和 Jetpack Compose 原生写成，源码以 AGPL-3.0 协议公开在 GitHub 上。它的核心主张只有一条：**转换在手机本地完成，文件不上传任何服务器**。

安装包约 49 MB，适配 64 位（arm64）、Android 8.0 以上的机型。无广告、无内购，功能不做会员墙。

## 能接住哪些活儿

| 类别 | 典型用途 |
| --- | --- |
| 视频 | MP4 / MKV / MOV / WEBM 互转、压缩体积、转 GIF、多段裁剪 |
| 音频 | 从视频抽音轨、MP3 / FLAC / OPUS 等格式互转、降噪与淡入淡出 |
| 图片 | JPG / PNG / WEBP / ICO 互转、AI 放大 2×–4×、GIF 拆帧 |
| PDF | 合并、逐页转图片、导出文字、压缩、加解密 |
| Office | DOCX / PPTX / XLSX 本地转 PDF / TXT / Markdown |
| 字体与字幕 | TTF / OTF / WOFF 互转；SRT / VTT / LRC / ASS 字幕歌词互转 |
| 隐私 | 照片视频的拍摄位置、设备型号等元数据查看与清理 |

## 和在线转换网站的差别

- **隐私**：在线网站要把文件先传到它的服务器；本地工具的转换不出手机，合同、证件照这类敏感文件不用先掂量一遍。
- **断网可用**：转换不依赖网络，地铁上、飞机上照样干活。应用只在检查更新、按需下载 AI 模型或字体时联网。
- **没有排队与限速**：在线网站免费档常卡在队列里；本地跑只吃自己的手机性能，转多大文件都看存储和电量。
- **代价**：超大视频受手机性能限制，转之前留足空间；批量重活不如电脑顺手。

它的功能介绍站整理了界面截图、各功能的边界说明与安装文件资源入口，见 [zenconverter 介绍站](https://zenconverter.fewa.skin/)。

## 适合谁用

- 经常在手机上收发文件，偶尔要转个格式的人：视频压小、图片转 PNG、语音转 MP3。
- 在意隐私、不想把文件交给第三方服务器的人。
- 喜欢开源软件、想看源码用得放心的人。

具体某个格式能不能转、有什么限制，看[支持哪些文件格式转换](支持哪些文件格式转换.md)；想上手操作直接看[手机上转视频格式的操作步骤](手机上转视频格式的操作步骤.md)。
