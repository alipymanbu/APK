# Pixcall 手机和电脑怎么同步素材

> 本篇讲清两端各自能管什么、文件在手机与电脑之间怎么走、为什么手机上会少一部分文件，以及离线出门的正确姿势。

---

Pixcall 的两端不是简单互为镜像：手机端和电脑端各管一摊，文件走哪条路取决于放进哪个库。分清这点，"手机上怎么少了一块文件"这类疑惑基本都能自己解开。

## 一、两端各管什么

| 客户端 | 能管理的库 | 能看到的内容 |
| --- | --- | --- |
| 电脑端（Windows 10+ / macOS 12.0+） | 本地资源库 + 同步资源库 | 两类库的全部文件 |
| 手机端（Android / iOS） | 只能管理同步资源库 | 只看到已同步到云端的文件 |
| 网页版 | 只能管理同步资源库 | 同手机端，功能是桌面端的子集 |

一句话判据：**电脑端是唯一能建本地资源库的端**。本地资源库里的文件不经过云端，手机端永远看不到——这不是同步坏了，是它压根不上云。涉及隐私又不需要跨设备的素材，放本地资源库反而更合适。

## 二、文件在两端之间怎么走

1. 手机上传 → 先进云端空间 → 电脑端在线时取回；
2. 电脑端往**同步资源库**加文件 → 推上云端 → 手机端收到；
3. 电脑端**本地资源库**里的文件 → 只留本机，手机看不到。

两个容易误解的点：

- **电脑端不在线，手机传的东西不会凭空出现在电脑文件夹里**——要等电脑端客户端（或常驻后台的 mini 程序）在线时去云端取；
- **手机端没有「读电脑磁盘」这条路**，两端能共享的只有同步资源库这一份。

## 三、手机上少了文件，按概率排查

1. 那些文件在电脑端的**本地资源库**里——本来就不上云；
2. **云端空间满了**——新文件传不上去，手机端自然没有新的可看（空间与废纸篓的关系见文末）；
3. **桌面端没在运行**——电脑上改的还没推上云端；
4. **还在传**——一次动的文件多就要多等一会。

## 四、离线出门前先缓存

手机端访问的是云端库，文件默认不整份存在手机里，保存到本地的只是元信息数据库（文件列表、标签这类索引）。要离线看素材，**出门前在应用里把目标文件或文件夹缓存到本地**，文件本体打开时按需取，缓存过的离线也能看。

## 五、顺手记三条容量口径

- 普通会员起步 **2GB** 云端空间，容量按账号算，手机传多了三端一起计数；
- 云端**单个文件上限 10GB**，视频、压缩包这类大块头放得下；
- 删除的文件先进**废纸篓**，废纸篓里的照样占容量——想腾空间得清空它，而不是只删一次。
