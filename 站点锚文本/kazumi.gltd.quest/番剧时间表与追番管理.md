# 番剧时间表与追番管理

> 这篇讲用开源应用 Kazumi 把追番这件事管起来：按周看新番排期、五档状态标记、历史记录与多设备同步。
> **相关文章**：[追番规则导入与更换方法](追番规则导入与更换方法.md) · [弹幕超分与播放设置](弹幕超分与播放设置.md)

## 时间表：这周哪天更新什么

主页切到 `时间表`，新番按星期排列，上方一排日期切换到具体某天；左上角可以切换放送季度，追旧季度的番或提前看新季度排期都行。右上角的排序与筛选支持按热度、评分排列，还能「隐藏看过」「保留正在追的」，把列表过滤成只属于你的那批。

## 搜索与筛选

首页左上角放大镜输入番名回车即可搜索。结果页可以按热度、排名、评分、匹配程度排序，也能按题材标签与放送时间筛选。注意搜索依赖已启用的规则——结果为空时先去检查规则，再怀疑别的事，排查思路见 [追番规则导入与更换方法](追番规则导入与更换方法.md)。

## 追番状态：五档标记

在番剧详情页可以打标记，一共五档：

| 状态 | 用在哪 |
| --- | --- |
| 在看 | 正在追、还没完结的 |
| 想看 | 加进清单等完结的 |
| 看过 | 补完的 |
| 搁置 | 暂时不想追又不舍得的 |
| 抛弃 | 看了几集不合适的 |

详情页的番剧资料（简介、标签、评分、角色）由 Bangumi 提供，挑番先看这里，比只看封面准。打完标记，主页的 `追番` 页就是你的清单，卡片上可以直接改状态，不用点进详情。

## 历史记录与统计

`我的` → `历史记录` 是续播的入口，记着你看到哪；「我的」页顶部还有看过番剧数与观看集数两个数字，看个概览。追番、历史、统计默认全部存在本地设备，不需要登录任何账号。

## 换手机怎么办：WebDAV 同步

同步走 WebDAV 而不是账号体系：自己填一个 WebDAV 服务器（Nextcloud 或任何兼容服务都行），两台设备填同一个地址与账号，打开观看记录与收藏的同步开关，进度就合并到同一份数据上。换新手机也是这条路——旧机开同步，新机连同一个服务器，数据自动接过来。偏好设置里另有 Bangumi 同步开关，用 Bangumi 记录的人可以一并打开。

安装这个应用的过程，可以参考 [Kazumi 介绍站](https://kazumi.gltd.quest/) 的安装说明页，安卓端的步骤与常见拦截问题都写清楚了。
