## 一、先说底数：二十多个台，全天轮播

ABEMA 的「テレビ」区是典型的电视形态：约 25 个以上频道按时刻表编排、24 小时不间断播出，运营方帮助中心给的上限口径是「约 30 个」。全部电视频道免费开放——它家没有付费电视频道，收费部分是会员作品池和按次购票的直播，不占频道。

## 二、主要频道一览

| 频道 | 内容方向 |
| --- | --- |
| Abema NEWS | 24 小时新闻速报，原创直播编排，突发新闻上得快 |
| アニメ（动漫） | 动画剧集与动漫相关企划，会员池里还有先行放送 |
| バラエティ（综艺） | 原创综艺的大本营，招牌节目常驻榜首 |
| ドラマ（剧集） | 原创剧与日剧内容 |
| スポーツ（体育） | 棒球、格斗、足球等；J 联赛每轮有精选场次免费放送 |
| 音楽（音乐） | 音乐节目与 live 相关内容 |
| 麻雀（麻将） | 职业麻将对局，日本网络电视里相当有特色的一路 |
| 競輪・競馬 | 竞轮与赛马赛事 |
| SPECIAL | 特别企划与限时编成 |

还有些频道是「到点才出现」的：临近开播才在列表里露面，比如 SPORTS LIVE、AbemaDELUXE 这类为单场赛事或特别节目临时开的台，平时看不到属于正常现象。

## 三、按电视的方式看：节目表与预约

两点小技巧让体验更接近看电视：

1. **换台**：应用首页左右滑动即可切频道，前一次看的台会被记住；
2. **番組表（节目表）**：从「テレビ放送中」旁的入口进，能看全天时刻表；点节目旁的加号收进「マイリスト」，开播前会收到提醒，错过的节目部分支持回看。

## 四、一句话总结频道之外的补充

频道是直播形态，点播区（ビデオ）负责「错过再看」：免费作品带广告可看，会员作品池更大。两者配合着用——直播追实时，点播补存量。
