# MagicPlan连接激光测距仪量房

MagicPlan 在安卓端没有房间扫描功能，尺寸全靠手动输入——这正是蓝牙测距仪发挥价值的地方。它的 PrecisionLink 功能支持连接蓝牙激光测距仪与数字卷尺，在墙上点一下要改的尺寸，设备量出的数值直接进图，「量、记、输」三步并成一步。

## 哪些型号能用

开发者对清单内的型号逐一做过兼容测试，主流品牌覆盖情况大致如下：

- **Bosch**：GLM 50 C、GLM 100 C、PLR 40 C、PLR 50 C 等多个 C 系型号；
- **Leica 徕卡**：DISTO D1、D2、D110、X3、X4、E7500i 等；
- **DeWalt 得伟 / Stabila / Stanley**：LD 250 BT、TLM 99s、Fatmax TLM 165s 等；
- **Mileseey**：S50C、S50R（联名版）。

清单外的型号不保证能用——有用户反馈某些型号能被发现、也能连上，但被识别错了、数据传不过来。动手买之前先对一遍清单。

## 应用内连接步骤

1. 打开测距仪电源，进入项目与楼层平面；
2. 点进房间，选中一面墙或一个对象；
3. 点平面上蓝色的尺寸数字，弹出 Change Measurement 窗口；
4. 点 **Laser**，在 Nearby Devices 列表里点你的型号旁的 Connect；
5. 用设备量出距离，回应用里点 Done，数值落在对应墙段上。

## 连不上？按这个顺序排查

1. 确认型号在兼容清单里；
2. 手机蓝牙设置里「忽略/取消配对」这台设备，清掉旧配对；
3. 测距仪关机，手机蓝牙也关掉；先开手机蓝牙，再开测距仪；
4. 回到应用重新搜索连接。

还连不上时，重点检查安卓的两个隐藏开关：**系统定位权限必须开着**（安卓的蓝牙扫描依赖定位权限，这是最常见的翻车点）；部分测距仪有蓝牙可见时间窗口，超时后搜不到，把可见超时调长再试。另一个通用原则：测距仪一次只服务一个应用，连之前确认它没被其他测量类应用占着。

连上之后量出的数据直接落在对应墙段；数字不对就先核对设备与应用的单位设置是否一致（公制/英制）。量房画图的完整流程，见[安卓端画户型图的四种方法](安卓端画户型图的四种方法.md)；工具本身的界面与获取入口，可看[MagicPlan 户型图工具介绍站](https://magicplan.bmww.store/)。
