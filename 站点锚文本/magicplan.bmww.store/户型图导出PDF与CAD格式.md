# 户型图导出PDF与CAD格式

在 MagicPlan 里把户型图画完只是前半程，交接给业主、施工方或设计师时，选对导出格式比画图本身更能决定对方的体验。这篇把导出入口、格式取舍和两个最容易踩的坑整理在一起。

## 导出入口在哪

应用内：进入项目面板 → 点进楼层 → 点右上角 **Export** 图标 → 选格式 → 右侧齿轮可先配参数。导出完成后文件自动归档到项目的 **Files 区**，从那里保存到手机本地。

电脑端：浏览器登录 magicplan Cloud，打开项目进楼层，点 **Send** → **Export Floor Plans**；所有导出文件在云端都取得到，比数据线传文件省事。

## 按交接对象选格式

| 交给谁 | 选什么 |
| --- | --- |
| 业主汇报、走流程存档 | Report PDF（图纸 + 照片 + 备注 + 明细） |
| 只需看图 | Sketch PDF（带尺寸标注的图纸） |
| CAD 深化 | DXF 或 SVG（DXF 兼容 AutoCAD，注意不含尺寸标注） |
| 三维建模 | IFC / OBJ / USDZ（USDZ 是唯一带家具对象的 3D 格式） |
| 预算与报价 | 统计导出（PDF/CSV）、估价导出（PDF/XLS） |

导出前点右侧 **Settings** 能调纸张、比例、尺寸标注、照片排版、页脚声明与抬头栏——「每间一张图加照片单独成页」和「全部拼一张大图」是完全不同的交付观感，交正式报告前值得花两分钟过一遍。

## 两个最容易踩的坑

1. **同类型文件默认被覆盖**。再次导出同一种格式时，新文件默认覆盖上一次。想每次都留档，在 Cloud 的 Settings → Export → Export File Versioning 里改为按新版本创建。
2. **改了图，PDF 不会自己更新**。应用不会自动重导 PDF，每次修改完图纸，记得重新生成需要的导出文件——发给对方的还是旧版，是最容易漏的一步。

另外导出内容多时生成需要时间，期间不要退出应用；反复中断就分楼层、分类型多次导出。
