# MagicPlan 介绍与资源索引

这里是 MagicPlan（开发者 Sensopia）的第三方介绍目录：一款在手机与平板上画户型图的应用，装修自装、验房记录、带看讲解都用得上。目录里的文章围绕安卓端的实际用法整理——从手动添加房间的四种方式，到蓝牙测距仪直连量尺寸，再到画完之后导出 PDF、CAD 与三维模型。

想直接上手的朋友，可以先看 [MagicPlan 户型图工具介绍站](https://magicplan.bmww.store/)，里面有功能速览、界面截图与安装文件资源的获取入口。
