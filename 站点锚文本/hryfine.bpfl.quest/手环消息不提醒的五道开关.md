# 手环消息不提醒的五道开关

> 手环收不到来电、短信、微信提醒时，按本篇把消息从手机到手环要过的五道开关逐个过一遍；任何一道关着都收不到。
> 相关文档：[连接不上手环的排查顺序.md](连接不上手环的排查顺序.md) · [表盘更换与照片壁纸设置.md](表盘更换与照片壁纸设置.md)

---

## 先确认通道是通的

推送的前提是手环和应用之间那条 BLE 数据通道在线。最快验证：在手表上点「找手机」，手机响铃说明通道是通的；不响就先按 [连接不上手环的排查顺序.md](连接不上手环的排查顺序.md) 把连接修好——通道断着，权限全给对也推不过来。

## 五道开关逐个过

| 开关 | 在哪查 | 常见坑 |
| --- | --- | --- |
| 1. 通知使用权 | 系统设置里搜「通知使用权」/「读取应用通知」，勾选该应用 | 装完没给、或系统升级后被重置 |
| 2. 应用通知权限 | 系统设置 → 应用 → 对应应用 → 通知，允许 | 被一键清理工具顺手关掉 |
| 3. 应用内提醒开关 | 应用里的消息提醒设置区，把「来电」等逐个打开 | 装完没进去开，来电只震不响 |
| 4. 发消息应用的通知 | 系统设置 → 通知 → 微信/QQ/短信，允许 | 应用内也有关通知的开关 |
| 5. 勿扰时段 | 应用端和手环端的勿扰设置都看一眼 | 设了勿扰时间段，到点手环就不震 |

## 后台被清理是最大原因

「应用一关推送就停」是这类伴侣应用被反馈最多的问题：数据通道靠应用在后台活着。按这个顺序设置（各家系统叫法不同，在设置里搜关键词）：

1. **自启动**：允许应用自启动。
2. **后台不受限**：电池/省电设置里设为「无限制」，或移出省电优化名单。
3. **锁定后台**：多任务界面里给应用加锁，避免一键清理杀掉。
4. **蓝牙后台权限**：部分系统要求单独允许应用在后台使用蓝牙。

设置完重启一次手机再测。

## iOS 上的差异

应用侧开关同样要给：系统设置 → 通知里允许，蓝牙权限允许。部分 iOS 版本默认不推送短信内容到手环，遇到「短信不推、应用消息照推」先想到这一层；腕上通话的音频通道同样在系统蓝牙里配对。

## 五道都对还是不推

按成本从低到高试：重开手机蓝牙再测一条 → 重启手机 → 卸载重装并逐项重新授权 → 手环恢复出厂后重新配对（先同步一次数据）。仍不行多半是机型适配问题，可留意应用更新说明里的设备适配修复。

功能速览、表盘玩法等更多内容见 [hryfine](https://hryfine.bpfl.quest/) 介绍站。
