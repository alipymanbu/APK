# 手机上做 Godot 游戏要装哪些东西

> 想在安卓手机上跑通一个 Godot 工程需要什么：应用本体、引擎版本、存储余量与外设，一篇对齐清单。

想在手机上试试 Godot 引擎的人不少，但真正动手前容易卡在「到底要装几样东西」。按从零到能建工程的顺序过一遍，看完就知道自己缺哪块。

## 一、先装一个管理端：GodotHub

手机上不直接下引擎，而是先装一个社区做的管理应用。以 GodotHub 为例，它把引擎下载、工程管理、插件素材与中文教程收在同一个安卓应用里，安装包只有 25 MB 上下，具体的功能构成可以看这篇[手机开发工作台介绍](https://godothub.qjxz.skin/)，这里不展开。

装好后第一次打开会停在首页，显示项目数、已安装引擎数和最新引擎版本，此时两栏都是 0，属于正常状态。

## 二、再装一个引擎版本

进「引擎」页，Godot 3.x 与 4.x 的版本按分栏列出，每个版本标了体积（4.6 正式版 GDScript 约 628 MB）。挑一个点下载，走国内镜像通道，速度比直连顺畅。

这里有个新手常踩的点：**引擎本体比应用大一个量级**。应用 25 MB，引擎 600 MB 起，后续工程文件还要再吃空间——开工前给手机留几个 GB 余量是底线。

## 三、版本选哪个

- 新开项目：直接选 4.x 的最新稳定版，资源与教程的适配也以 4.x 为主；
- 接手老工程：看工程原本用的版本，应用支持多版本并存，切到匹配版本打开即可。

选版本的细节展开在[安卓端Godot引擎版本怎么选](安卓端Godot引擎版本怎么选.md)。

## 四、可选但强烈建议：外接键鼠

Godot 的安卓编辑器界面还没针对触屏适配，纯触屏写脚本、拖节点的效率很低。一套蓝牙键鼠能让体验接近桌面端，成本几十到一百出头。渲染器记得选 Mobile 或 Compatibility，Forward+ 在部分机型上表现不佳。

## 五、对一遍开工清单

1. 管理应用已装好并能正常打开；
2. 至少一个引擎版本下载安装完成；
3. 存储余量几个 GB 起步；
4. （可选）蓝牙键鼠已配对。

四条齐了就能在「项目」页新建 2D 或 3D 工程开工。做出来的东西想变成能安装的 APK，路线见[Godot安卓端导出APK的路线与准备](Godot安卓端导出APK的路线与准备.md)。
