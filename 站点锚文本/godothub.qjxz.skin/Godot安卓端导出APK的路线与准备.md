# Godot 安卓端导出 APK 的路线与准备

> 在手机上把做好的 Godot 工程变成能安装的 APK：两条导出路线、各自要准备什么、出包之后怎么用。

工程在手机上做完，最后一步是变成能装进手机的 APK。这一步有两条路线，准备事项差别不小，先对清楚再动手。

## 一、导出前先备齐三样

- 应用本体与匹配的引擎版本都已就位（版本怎么挑见[安卓端Godot引擎版本怎么选](安卓端Godot引擎版本怎么选.md)）；
- 一个能正常打开的工程；
- 第一次导出前，按编辑器提示装好对应版本的导出模板。

## 二、路线一：预设模板导出（大多数人的选择）

用引擎自带的预编译模板直接出包，**零额外准备**，适合快速出包装机自测或发给朋友试玩。没特殊需求就选这条，几分钟出结果。

## 三、路线二：Gradle 构建（有定制需求再上）

要自定义构建配置、接安卓插件时才需要走这条：另装上游提供的 GABE（Godot Android Build Environment）配套应用，首次使用联网下载构建组件。准备成本明显更高，纯自测用不着。

顺带一条硬限制：C# / .NET 工程不能在安卓编辑器上导出，这类工程回桌面端出包。

## 四、出包之后

- **APK**：传到手机直接安装（允许「未知来源」），自测、分享都靠它；
- **AAB**：上架 Google Play 用的格式，**不能**直接装手机，别拿它本地安装；
- 签名：只是自己测试，调试签名就够；要正式上架再配自己的 keystore。

## 五、从装应用到出包的完整链路

把全流程串一遍：装管理应用 → 装引擎版本 → 建工程 → 开发 → 按本文导出 APK。前三步的清单在这篇[手机上做Godot游戏要装哪些东西](手机上做Godot游戏要装哪些东西.md)；应用本身的功能与界面，[手机开发工作台介绍](https://godothub.qjxz.skin/)里整理得更细。
