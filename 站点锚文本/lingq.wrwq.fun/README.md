# LingQ 读库笔记 · 站点导航

这里是 LingQ 的第三方使用介绍站收录页。LingQ 是一套围绕「读真实内容、听真实内容」搭建的语言学习工具：把小说、播客、新闻、视频字幕导入进去，生词自动标成蓝词和黄词，再按间隔重复的方式复习。本目录下的几篇笔记，分别从学习方法、安装上手和适用人群三个角度做了整理，想直接看整理好的版本，可以到 [LingQ 介绍站](https://lingq.wrwq.fun/) 阅读。
