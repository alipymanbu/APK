# FairEmail 介绍站

FairEmail 是一个 100% 开源（GPLv3）、隐私导向的安卓邮件客户端：自带邮箱地址即可接入，支持任意 IMAP/SMTP 服务商，把防追踪、加密与推送的控制细节全部开放给使用者。这里围绕它的隐私机制、多账户管理与无谷歌环境下的使用整理了几篇说明。

- [FairEmail 介绍站](https://fairemail.ggcd.store/)：功能拆解、真实界面截图与安装文件资源获取入口。
