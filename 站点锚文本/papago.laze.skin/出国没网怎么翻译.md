# 出国没网怎么翻译

> 本篇讲出境途中没网、漫游又贵时的翻译应对办法：哪些翻译能离线做、语言包怎么提前下载、哪些操作必须等有网再补。

## 一、离线翻译能干什么、不能干什么

先把预期摆正：离线翻译是「把翻译引擎和语言数据装进手机」，省流量但也缩水。以 Papago 为例，离线状态下：

| 功能 | 离线可用 |
| --- | --- |
| 打字翻译（文本） | 可用，限部分语言对 |
| 语音翻译 | 安卓可另下语音语言包，部分机型不支持 |
| 对话、拍照、网站翻译 | 不可用，需联网 |

所以离线包解决的是「打字查词、翻简单句子」这个最基本的场景；菜单、路牌这类靠镜头的翻译，没网时翻不了。

## 二、出发前把语言包下好

以 Papago 为例的操作路径：

1. 打开应用，进侧边菜单 → 设置 → 离线翻译；
2. 找到需要的语言对（如中文简体 ↔ 韩语）点下载，单个包在一百多 MB 量级；
3. 安卓想离线用语音翻译，同一界面再单独下语音语言包；
4. 下载完会出现已下载标记，到这一步才算就绪。

两点提醒：离线文本翻译对手机运行内存有要求（官方口径 4GB 以上），老手机可能看不到语言包条目；不用的语言包及时删掉腾空间，删了随时能重下。

## 三、没网时的实用技巧

- **高频句提前翻好**：问路、点菜、退房、过敏提示这类句子，出发前在线翻好并加星收藏，落地直接从翻译记录里调出来给对方看；
- **重要沟通等有网**：离线结果偏生硬，看病、签合同这类场合务必联网再确认一遍；
- **蹭稳定的 Wi-Fi**：酒店、机场、咖啡馆一般有免费网络，拍照翻译、对话翻译可以攒到这些场合再做；
- **截图兜底**：没网时把要翻的画面拍下来存着，有网了用相册导入功能补翻。
