# 无广告的开源闹钟，可以从这几处找起

> 受够了开屏广告和"会员去广告"的闹钟应用？开源世界里有不少干净的选择。这篇讲去哪找、怎么判断一只闹钟靠不靠谱，以及装非商店应用要注意什么。
> **相关文档**：[睡眠提醒怎么开启.md](睡眠提醒怎么开启.md) · [AMOLED纯黑主题值不值得开.md](AMOLED纯黑主题值不值得开.md)

## 一、为什么闹钟这个品类特别值得换开源的

闹钟是全天候驻留后台的应用，广告 SDK 在它身上的代价也最大：更费电、更容易被系统判定为后台活动而遭清理，半夜弹一条推送也不稀奇。开源的闹钟应用没有广告位、没有内购，代码公开可查，这类问题从根上就不存在。

## 二、去哪里找

- **IzzyOnDroid 仓库**：面向安卓开源应用的 F-Droid 软件源，用 Neo Store、Droid-ify 这类客户端添加后，能直接浏览和更新里面的应用；
- **GitHub Releases**：很多独立开发的应用直接把 APK 挂在 GitHub 的发布页，比如 Chronos（`https://github.com/meenbeese/Chronos`），每次更新都在那里；
- **Obtainium**：一个盯 GitHub 发布页的应用，配好之后新版本出了会提醒你，省去手动查。

## 三、怎么判断一只开源闹钟值不值得装

看三样东西就够了：

1. **权限清单**：一只闹钟真正需要的是响铃、振动、开机重排闹钟、通知这几种权限。像 Chronos 申请的读取音频、读取图片这类权限，都对应"换自定义铃声""设背景图"这种用到才需要的功能，申请理由写得明白；
2. **更新频率**：发布页隔三差五有动静，说明还活着；
3. **功能密度**：闹钟、计时器、世界时钟、睡眠提醒，这些是时钟应用常见的几大件，够用就好，不必贪多。

Chronos 本身值得单独一看：深色、浅色、AMOLED 三种主题，铃声可以用手机里的音乐，界面横竖屏和平板都有对应布局。它的功能细节与获取方式，看 [Chronos 的介绍站](https://chronos.gkhf.beer/) 更直观。

## 四、装非商店 APK 前的三件事

1. **来源要正**：只从上面列的渠道拿安装包，随手在群里、网盘搜来的文件别装；
2. **未知来源授权**：第一次安装时系统会拦一次，到设置里允许"来自此来源的应用"即可，装完可以收回；
3. **装完给权限**：通知权限（Android 13 及以上必需）和电池白名单，直接决定闹钟到点响不响，装完就检查一遍。
