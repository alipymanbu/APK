# 导入Word文档自动做PPT的方法

手里已经有 Word 底稿、思维导图或者一份 PDF 资料，不想再手动搬运到幻灯片里——这条路线 AiPPT 支持得比较完整。这篇把导入生成的细节一次说清：支持哪些格式、字数和层级怎么算、导入之后流程怎么走。

相关文档：[手机一键生成PPT的五个步骤](手机一键生成PPT的五个步骤.md)、[安卓版安装与首次使用问题](安卓版安装与首次使用问题.md)。

---

## 支持的格式

| 手里的材料 | 能否直接导入 |
| --- | --- |
| doc / docx | 支持 |
| PDF | 支持 |
| TXT | 支持 |
| Markdown(.md) | 支持 |
| XMind / FreeMind(.mm) | 支持（思维导图式文件） |

思维导图类文件注意一点：AiPPT 最多读取 5 个层级的内容，第 6 层及以下会被自动忽略，导出前先把结构收一收。

## Word 底稿怎么准备最稳

识别效果最稳的是**纯文字文档**：

- 建议 4500 字以内；
- 只保留文字内容，图片、表格这类元素不参与识别；
- 标题层级清楚（哪几行是章、哪几行是节），生成的大纲会更贴合原意。

## 导入之后的流程

导入只是换了一种「喂料」方式，后面的链路和手动输入主题完全一样：

1. AI 读完材料，先产出章节大纲；
2. 大纲逐条可编辑，确认结构合理再往下走；
3. 挑一个契合内容的版式，AI 负责填充、配图与排版；
4. 进编辑器微调文字与图片，导出源文件即可。
