# AiPPT 介绍站：安卓 App 使用与安装指引

这里是 AiPPT 安卓 App 的第三方介绍站收录页。AiPPT 是一款把「一句话主题 → 可编辑大纲 → 成套幻灯片」压缩进一条链路的 AI 做 PPT 工具，支持输入主题对话式生成，也支持把 Word、PDF、TXT、Markdown、XMind 等文档丢给它当底稿，合成一份通常 3 分钟以内，手机上就能改字换图，账号云端同步到网页版与桌面端接力。

- [导入Word文档自动做PPT的方法](导入Word文档自动做PPT的方法.md) —— 文档导入的格式、字数与层级细节
