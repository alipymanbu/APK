## 先确认前提

ZOZOTOWN 面向日本国内市场运营，收货地址以日本地址为前提，运营方不提供海外直邮——这是海外用户绕不开的第一道门槛。界面只有日语，搜索也要用日文关键词，不熟日语可以配合系统自带的屏幕翻译。

注册本身免费，需要这几样：一个邮箱（同时作为账号 ID，一个邮箱只能注册一个账号）、密码、性别、生日，以及日本邮编。浏览与部分下单操作不登录也能做，但收货地址无论是否登录都必须是日本地址。

## 转运仓补上哪一环

海外用户常见的路径是转运：先在转运服务商处取得一个日本收货地址（通常附带入库编号），下单时把这个地址填进收货信息；包裹到达转运仓后，由转运商完成入库、合箱、国际段运输与清关派送。

几个实操层面的注意点：

| 事项 | 说明 |
| --- | --- |
| 收件人姓名 | 转运商一般要求写成片假名，注册转运账号时会给出建议写法，按转运商的规则填 |
| 商品与承运限制 | 服饰类通常无碍，但转运商对品牌真伪、液体化妆品等品类各有承运清单，下单前核对 |
| 运费与合箱 | 多单合箱能摊薄国际运费，合箱规则以转运商说明为准 |
| 时效预期 | 比日本国内配送多出国际段与清关，整体周期以转运商承诺为准 |

选哪家转运商、走不走这一段，属于你自己的安排，平台侧对这类订单的售后以结算与配送完成为界，转运段的争议要找转运商处理。

## 支付与下单

站内支付方式以日本市场常见渠道为主，部分卡种能否直付以结算页实际给出的选项为准；结算金额含日本国内消费税处理规则，跨境段的税费由进口环节产生，按收货地海关与承运方规则缴纳。

下单流程与日本用户一致：选规格 → 加入购物袋 → 结算。商品页的尺码是实测数据，配合页内评价使用更稳；平台整体的功能与量级介绍在 [ZOZOTOWN 平台介绍站](https://zozotown.fedq.quest/)，古着区的逛法见[古着区怎么逛](古着区怎么逛.md)。
