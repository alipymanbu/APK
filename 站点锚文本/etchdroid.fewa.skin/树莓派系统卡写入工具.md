# 树莓派系统卡写入工具

> 给树莓派装系统的第一步是把系统镜像写进 SD 卡。没有读卡器能插电脑、或者手边只有手机时，这件事照样能办——这篇讲清楚工具和步骤。

## 用手机写卡：EtchDroid

**EtchDroid** 是一款安卓端开源应用，把「USB 读卡器 + SD 卡」插到手机上，就能直接把树莓派镜像写进卡里，全程不需要电脑参与，也不用 root。应用的介绍与获取入口见 [EtchDroid 手机写盘指南](https://etchdroid.fewa.skin/)。

写卡步骤：

1. 把树莓派镜像下载到手机存储。
2. USB 读卡器装上 SD 卡，通过 OTG 线插到手机。
3. 打开应用，选中镜像文件，再选列表里的读卡器设备，确认写入。
4. 等进度走完，把卡插回树莓派开机。

## 镜像形态的坑：先解压再写

树莓派提供的系统镜像多数是 `.img.xz` 压缩包，**直接选压缩包会写入失败**。先用手机上的解压应用解出 `.img` 文件，再拿去写。树莓派官方提供的 Imager 工具会在电脑端自动处理解压，手机端这一步要自己动手。

## 为什么不能用手机自带的 SD 卡槽

给手机写卡的用户常问：能不能把 SD 卡插进手机的卡槽直接写？**不行**——安卓系统不允许应用向内部 SD 卡槽做这种整盘写入，这是系统层面的限制，EtchDroid 也明确不靠 root 去绕。所以「USB 读卡器 + SD 卡」是手机写卡的固定组合，一个几块钱的 OTG 读卡器就能解决。

## 供电与速度的注意事项

- 手机 USB 口输出的电流有限，读卡器加普通 SD 卡一般够用；如果中途掉盘，多半是供电或读卡器质量问题，换一个再试。
- 写入速度取决于 SD 卡本身的读写性能，十几分钟到半小时都在正常范围。
- 写完后手机可能提示 SD 卡「有问题 / 不受支持」，这是正常现象，卡没坏，直接插树莓派用。这类提示的原理在[启动盘写完电脑识别不了](启动盘写完电脑识别不了.md)里有展开。

## 手机写卡之外的选择

手边有电脑时，树莓派 Imager 是最省事的方案（自动解压、可选系统）；手机方案的价值在于「没有电脑」的时刻——EtchDroid 把写卡能力装进了口袋，应急时不用到处借电脑。
