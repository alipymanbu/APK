## 一句话介绍

EtchDroid 是一款 GPL v3 开源的安卓应用，手机通过 OTG 插上 U 盘或读卡器，就能把 Linux 发行版 ISO、树莓派镜像直接写入，全程免 root、无广告，适合当「口袋刻录机」应急使用。
