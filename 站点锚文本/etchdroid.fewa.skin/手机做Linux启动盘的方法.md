# 手机做 Linux 启动盘的方法

> 笔记本坏了、被占着、或者干脆不在手边，但明天就要给另一台电脑装系统——这篇讲怎么只用一部安卓手机和一根 OTG 线，把 Linux 启动盘做出来。

## 思路

传统做法是「电脑 + 刻录软件 + U 盘」，三个条件缺一不可。手机做启动盘的思路是把刻录这一步搬到安卓上：用 **EtchDroid** 这款开源应用，手机通过 OTG 直接把镜像写进 U 盘，写完的 U 盘插到目标电脑上就是一枚正常的系统安装盘。

它的几个前提条件：

| 条件 | 要求 |
| --- | --- |
| 手机 | 安卓 5.0 以上，支持 USB OTG（现在绝大多数 Type-C 机型都支持） |
| U 盘 | 容量不小于镜像文件，里面的数据会被整盘清空 |
| 连接件 | OTG 转接头（双头 Type-C U 盘可以直接插） |
| 镜像 | 提前下载到手机存储的 ISO / IMG 文件 |

## 操作流程

1. 在手机上装好 EtchDroid，获取与安装方式见 [EtchDroid 手机写盘指南](https://etchdroid.fewa.skin/)。
2. 把发行版镜像下载到手机。Ubuntu、Debian、Fedora 等都有手机浏览器可直接访问的下载页，2 GB 左右的镜像注意留够存储。
3. 插上 U 盘，系统弹出「允许应用访问 USB 设备」时点允许。
4. 打开应用 → 选「写原始镜像」→ 文件选择器里选中 ISO → 列表里点选 U 盘 → 确认覆盖。
5. 等进度走完。几 GB 的镜像写十几分钟属正常速度，期间别拔盘、别把应用从后台划掉。

写完拔下 U 盘，插进要装系统的电脑，开机按启动菜单键（常见 F12 / F9 / Esc / Del）把启动顺序切到 U 盘，看到发行版的启动菜单就成功了。

## 两个容易卡住的点

- **树莓派镜像要先解压**：`.img.xz` 压缩包直接选会失败，先用解压应用解出 `.img` 文件。更多设备与镜像的支持情况见[树莓派系统卡写入工具](树莓派系统卡写入工具.md)。
- **写完的 U 盘「打不开」**：手机和电脑大概率都提示 U 盘异常或无法读取——这是正常现象，镜像用的文件系统本来就不面向日常读写，不影响装机。详细原因见[启动盘写完电脑识别不了](启动盘写完电脑识别不了.md)。

## 小结

手机做启动盘不是替代方案，而是应急场景里最快的那条路：不用等电脑、不用装任何桌面软件，一部手机加一根 OTG 线，十几分钟就能交出一枚能开机的安装盘。
