# 安卓手机玩怀旧游戏从哪开始

> 本篇讲在安卓手机上重拾 FC、SFC、GBA、PS1 这些老游戏的第一步怎么走：模拟器、模拟器前端、核心、游戏文件各自扮演什么角色，先装什么、后装什么。

## 一、先把几个词分清

刚接触怀旧游戏圈，容易被几个词绕晕，先捋清层次：

- **模拟器**：让手机「假装」是某台老主机的程序，比如跑 SFC 游戏的 Snes9x、跑 GBA 的 mGBA。一台主机对应一个模拟器，各装各的、界面各异。
- **模拟器前端**：把这些模拟器收拢到同一个界面下统一管理的「壳」。装一个前端，就等于同时拥有几十台主机的启动台。
- **核心**：前端里真正干模拟活的插件。前端的玩法是「本体 + 按需下载核心」，玩哪台主机就下哪个核心。
- **游戏文件（ROM）**：模拟器读的游戏数据，来自自己备份的卡带与光盘。前端和核心都不附带游戏。

安卓上最流行的前端就是 RetroArch——由 Libretro 团队维护、免费开源，社区口碑多年不衰。想看它的界面与功能全貌，可以逛逛这个 [RetroArch 中文介绍站](https://retroarch.xnyx.quest/)，再把本文读完动手。

## 二、为什么推荐从前端入门，而不是单装模拟器

单装模拟器不是不行，但玩的主机一多就露馅：三四个模拟器三四种界面，存档格式各管各的，手柄键位每个都要配一遍。前端把这些统一了：

1. **一个界面管全部主机**：游戏库按主机分列表，找游戏不用在桌面翻应用图标。
2. **存档、快进、按键映射全站统一**：学会一次，所有主机通用。
3. **即时存档是标配**：任何画面瞬间存档，老游戏的高难关卡再也不用一命通关。
4. **手柄一次配置全局生效**：蓝牙手柄自动识别键位，换游戏不用重设。

代价是第一步比单装模拟器多绕一个弯——要理解「核心」这个概念。也就十分钟的功课，见下一节。

## 三、动手路线：装好之后的两件事

先把前端安装包装进手机（侧载安装，允许一次「未知来源」即可），首次启动记得给存储权限。接下来按顺序做两件事：

1. **下核心**：在前端的核心列表里按主机挑选，SFC 选 Snes9x、GBA 选 mGBA、PS1 选 PCSX-ReARMed，点一下自动下载安装。具体哪台主机配哪个核心口碑最好，[模拟器核心怎么选](模拟器核心怎么选.md) 有整张对照表。
2. **导游戏**：把游戏文件按主机分文件夹放进手机存储（zip、7z 压缩包不用解压），用扫描功能自动建游戏库。文件名尽量保留原始命名，扫描靠它识别。

两步做完，主菜单就会出现一台台「虚拟主机」，点游戏即玩。

## 四、老手机能带得动吗

按主机年代分档估：FC、SFC、GBA 这类 8/16 位主机对性能要求极低，市面上能正常使用的手机几乎都行；N64、PS1 开始要求芯片性能，中端机流畅无压力；PSP、Dreamcast 往上就要看具体机型了。卡顿先换高速核心、关画面滤镜，比反复调设置管用——排查思路写在[模拟器游戏黑屏闪退怎么办](模拟器游戏黑屏闪退怎么办.md)里。

一句话总结：入门的顺序是「装前端 → 下核心 → 导游戏」，三步走完，口袋里就揣下了一整个童年的机厅。
