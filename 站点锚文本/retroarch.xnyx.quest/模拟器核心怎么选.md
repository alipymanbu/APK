# 模拟器核心怎么选

> 本篇讲模拟器前端的「核心」到底怎么挑：同一台主机常有多个核心，性能与兼容差别不小，这里按主机给出社区口碑较好的组合，顺带说清核心的更新、删除与常见误区。

## 一、先明白一件事：核心没有唯一答案

核心是前端里真正负责模拟的插件。同一台主机往往并列着好几个核心——有的追求精确还原（吃性能）、有的主打速度（牺牲一点细节）、有的擅长玩花活（高清化、宽屏）。选核心就是在这三者间挑一个合口味的。

以 RetroArch 为例，核心都在主菜单的 Load Core → Download a Core 里按主机分组列出，点一下即下载；不同主机可以各装一个，同一主机也能并存几个备选。还没装前端的话，[RetroArch 介绍站](https://retroarch.xnyx.quest/) 里有完整的界面展示与获取入口，可先行一步。

## 二、各主机口碑核心对照表

手机上跑得动的优先，星标为多数人的首选：

| 主机 | 可选核心 | 一句话点评 |
| --- | --- | --- |
| FC / NES | **Nestopia UE**、FCEUmm、Mesen | Nestopia 均衡省电；Mesen 最准但吃性能 |
| 超任 / SNES | **Snes9x**、bsnes-hd | Snes9x 速度快，手机首选；bsnes-hd 玩宽屏高清化 |
| GB / GBC | **Gambatte**、SameBoy | 画面还原扎实，随便挑不踩坑 |
| GBA | **mGBA** | 手机上的默认答案，兼容与速度兼顾 |
| 世嘉 MD / GG / SMS | **Genesis Plus GX** | 世嘉 16 位时代全家桶一把抓 |
| 世嘉 32X | **PicoDrive** | 几乎唯一稳妥选择 |
| PS1 | **PCSX-ReARMed** | 手机端最成熟，多数游戏免 BIOS |
| N64 | **Mupen64Plus Next** | 部分游戏需逐个调插件，耐心活 |
| 土星 | YabaSanshiro、Beetle Saturn | 土星本身就难模拟，中低端机型慎入 |

## 三、三条实用原则

1. **先快后准**：手机性能有限，先用高速核心玩起来；画面有瑕疵再换精确型核心对比，别一上来就追「最准」。
2. **核心可并存**：同一主机装两三个核心不冲突，游戏加载时可以指定用哪个；某款游戏在一个核心上表现差，换另一个常有奇效。
3. **老机器别硬攀高画质主机**：N64、土星、Dreamcast 这类对芯片要求陡增，中低端机型跑不动属正常，量力而行。

## 四、更新与删除

- **一键更新**：主菜单 → Online Updater → Update Installed Cores，把已装核心整体升到最新。
- **卸载**：Load Core → Installed Core List 里选中核心卸载即可，删错了重新下载，没有连带损失。
- 注意核心大版本更新后，旧的**即时存档**可能失效（绑定核心版本），游戏内存档不受影响——重要进度别只依赖即时存档。
