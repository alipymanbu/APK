# 模拟器游戏黑屏闪退怎么办

> 本篇按症状给排查顺序：游戏黑屏或秒退、扫描不出游戏、存档丢失、画面拉伸与卡顿——多数毛病五分钟内能定位，先从最常见的原因查起。
> **相关文档**：[安卓手机玩怀旧游戏从哪开始](安卓手机玩怀旧游戏从哪开始.md) · [模拟器核心怎么选](模拟器核心怎么选.md)

---

## 一、黑屏 / 秒退：按这个顺序查

用 RetroArch 这类前端加载游戏黑屏或直接退出时，九成出在下面四项里，从上往下过：

1. **核心装了吗**：前端本体不带模拟器，对应主机的核心没装，游戏起不来。主菜单 Load Core 里确认已装并选中。
2. **这台主机要 BIOS 吗**：带光驱、带开机画面的主机（PS1 部分游戏、世嘉 CD、Dreamcast、土星、3DO）缺 BIOS 文件就黑屏。FC、SFC、GBA 这类卡带机一般不需要。BIOS 要放进前端的系统目录（Settings → Directory → System/BIOS 显示的路径），文件名与校验值以核心文档为准。
3. **游戏文件完整吗**：解压到一半的压缩包、来源不明的文件是黑屏大户，换一个确认完好的文件对比测试。
4. **换核心再试**：同主机换一个核心加载一次，排除核心本身的兼容问题（核心取舍见[模拟器核心怎么选](模拟器核心怎么选.md)）。

## 二、扫描不出游戏 / 列表缺斤少两

- 先在前端的 Online Updater 里把数据库更新一遍再扫——扫描识别游戏靠这份库。
- 严格扫描模式下，对不上号的游戏不会进列表：改用手动扫描（Manual Scan）放宽匹配，或用 Scan File 逐个指定；没匹配上的游戏也会以「未识别内容」出现在列表里，不影响游玩。
- 游戏文件名尽量保留原始命名，乱改名会让识别对不上号；zip、7z 压缩包可以直接扫，不必解压。

## 三、存档丢了 / 读不出来

- **游戏内存档丢了**：先回想是不是用清理工具清过应用数据——存档目录会被一并清掉。换手机迁移时把存档目录整个拷走。
- **即时存档读不出**：即时存档与核心版本绑定较紧，核心大版本更新后旧档可能失效；游戏内存档不受影响，重要进度两种都存。
- 存档目录位置在前端 Settings → Directory 里查看，备份整个目录最稳妥。

## 四、卡顿与画面问题

- **卡顿**：换该主机公认的高速核心 → 快速菜单把内部分辨率类选项调回默认 → 关掉着色器滤镜 → 手机开性能模式。中低端机型跑 N64、土星、Dreamcast 吃力属正常，换核心比调设置管用。
- **画面拉伸变形**：快速菜单 → Video 里按主机原始比例（多为 4:3 或 10:9）设置，再考虑整数缩放。
- **按键错乱**：外接手柄先跑自动配置；只有个别游戏不对就用按游戏重映射单独修。

都试过仍无解时，把「核心名 + 症状」当关键词去搜社区讨论，命中率最高。如果连前端本身还没装好，先回[RetroArch 中文介绍站](https://retroarch.xnyx.quest/)看安装与界面总览，再回头逐项排查。
