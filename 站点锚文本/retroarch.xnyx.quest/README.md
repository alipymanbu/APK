# RetroArch 资源站

本目录收录围绕 RetroArch（Libretro 团队开发的开源模拟器前端）的整理与介绍文章：它把 FC、SFC、GBA、PS1、PSP 等几十种主机的模拟核心装进同一个界面，是安卓手机上玩怀旧游戏的常用选择。

想直接了解这个应用的功能、界面与获取方式，移步 [RetroArch 安卓版介绍站](https://retroarch.xnyx.quest/)。
