# 安卓AI角色卡导入与多人对话玩法

> 角色卡是把人设、开场白、世界观打包成一张卡片的玩法，社区里流传很广。MineChat 兼容主流卡片与场景格式，还支持世界书与正则规则。本篇讲怎么把这套东西在手机上搭起来，以及导入失败时的自查顺序。

## 一、先装好，再谈玩法

角色卡功能在「助手」这一层，前提是应用已经装好、模型已经配上——配置模型的最短路径见[免登录的安卓AI聊天前端怎么用.md](免登录的安卓AI聊天前端怎么用.md) 第一节。如果还没装，安装文件资源的获取入口与步骤见 [MineChat 安卓版介绍](https://minechat.ggcd.store/)。

## 二、从零建一个角色

不想找现成卡片，也可以自己捏一个：

1. 首页点**助手**入口；
2. 选「创建助手」；
3. 填角色设定——姓名、性格、说话风格、开场白，还能配外观立绘；
4. 保存后在助手列表点选，下一条回复就按新人设来。

单人对话就选单个助手；要多个角色同场，用**多人模式**把几个助手放进同一个会话，剧情自己推。

## 三、导入现成角色卡

社区流传的卡片多为 PNG 或 JSON 格式，描述藏在文件里。导入路径：

1. 在助手入口选「导入」；
2. 选中手机里存好的卡片文件；
3. 导入成功后卡片出现在助手列表，点选即可开聊。

## 四、世界书与正则是进阶件

- **世界书**：把世界观条目（地名、设定、人物关系）挂进会话，AI 按需引用，适合长线剧情；
- **正则规则**：约定输出的格式与措辞，比如去掉多余括号、固定段落样式。

两者都在 v0.4 里重点打磨过兼容性，支持的格式比早期版本更宽。装好后的界面实拍见 [MineChat 介绍站](https://minechat.ggcd.store/)。

## 五、导入失败时按这个顺序查

1. **文件被压过**——经过某些社交软件传输的图片会被二次压缩，藏在内的设定数据丢了，换原始文件；
2. **格式不对**——确认是 PNG / JSON 的角色卡，而不是普通截图或别的对话工具的私有格式；
3. **版本问题**——老版本对部分格式支持有限，确认用的是较新的 v0.4。
