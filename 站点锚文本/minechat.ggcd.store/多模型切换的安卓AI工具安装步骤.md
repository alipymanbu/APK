# 多模型切换的安卓AI工具安装步骤

> MineChat 是安卓端 2.78M 的轻量 AI 对话前端，聚合 OpenAI、Gemini、Claude、OpenRouter、Grok 等服务商，免登录。本篇讲安装环节：装前确认什么、怎么装、装不上时按哪三条查。
> **相关文档**：[免登录的安卓AI聊天前端怎么用.md](免登录的安卓AI聊天前端怎么用.md) · [安卓AI角色卡导入与多人对话玩法.md](安卓AI角色卡导入与多人对话玩法.md)

## 一、装前三件事

| 项目 | 说明 |
| --- | --- |
| 系统版本 | 安卓 5.2 及以上，低了装不上，先到「设置 → 关于手机」看一眼 |
| 存储空间 | 安装包只有 2.78M，几乎不占地方，老旧机型也无压力 |
| 联网条件 | 聊天需要联网，模型都在云端，离线只能进界面 |

另外提醒一句：应用市场上存在与它同名的其它应用，安装前认准包名 `com.mine.minechat`，避免装错。工具的定位与界面实拍见 [MineChat 介绍站](https://minechat.ggcd.store/)。

## 二、从安装文件到桌面图标

1. 打开介绍站标注的安装文件资源分享页，把文件**先转存到自己的网盘**，再下载到手机——转存一次，日后链接失效也不影响；
2. 在下载列表或文件管理里点开 `MineChat_v0.4.apk`，进入安装；
3. 若系统提示「禁止安装未知来源应用」，按提示进 设置 → 安全/隐私，给这次用的来源（浏览器或网盘 App）打开允许开关，再回安装界面继续；
4. 进度走完，桌面出现图标，点开即用——没有注册环节，打开就是可用状态。

装完第一件事是配模型，最短路径见[免登录的安卓AI聊天前端怎么用.md](免登录的安卓AI聊天前端怎么用.md) 第一节。

## 三、装不上时的三种情况

- **提示「解析包时出现错误」**：多半是系统低于安卓 5.2，或安装包没下载完整——重新下载一遍再装；
- **安装按钮是灰的**：未知来源权限没给到位，按第二节第 3 步补开关；
- **打开就闪退**：先确认系统版本达标，再确认网络可用；仍不行就卸掉重装一次。
