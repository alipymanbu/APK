# Poweramp 支持哪些无损格式：清单与输出边界

> 「这个文件它能不能播」「DSD 会不会白存了」——这篇把 Poweramp 的格式支持列成清单，
> 再说清输出规格的边界：文件能播和规格跑满是两件事，后者取决于手机。

## 一、格式清单

| 类别 | 格式 |
| --- | --- |
| 常见有损 | MP3、AAC（MP4/M4A）、OGG、OPUS、WMA |
| 常见无损 | FLAC、WAV、ALAC、AIFF |
| 冷门无损 | APE、WV（WavPack）、TTA、MPC、TAK、MKA |
| 高解析 | DSD（.dsf / .dff） |
| 其他 | 模块音乐（IT、S3M、XM 等）、FLV 音轨、MPGA |

自带解码器意味着绝大多数文件**不需要转码**，直接丢进手机就能播。

## 二、整轨专辑与 .cue

一张整轨 FLAC 配一个 .cue 文件是最容易出问题的形态，处理方式：

- 两个文件放同一目录（或 cue 内嵌进 flac），播放器会按 cue 里的时间点把整轨切成一首一首；
- cue 里的曲目名来自 cue 文件本身的文本，名字显示不对要去改 cue，改播放器设置没用；
- m3u / m3u8 播放列表可导入导出，pls / wpl 可导入；列表里带 http 地址的网络流也能直接播。

## 三、哪些文件播不了

- **流媒体应用的离线缓存**：那些是平台加密格式，不是普通音频文件，丢进来不会播，也不应该绕——想听还是回到正规渠道；
- **格式在表里却播不了**：先查文件是否下完整、扩展名有没有标错（比如 flac 被改成了 mp3 后缀）；
- **文件没问题但列表里看不到**：那是文件夹没勾选的问题，见 [扫描不到歌曲的排查思路](扫描不到歌曲的排查思路.md)。

## 四、Hi-Res 输出的真实边界

文件规格高，不代表输出规格一定跑满：

- 手机内部输出与 USB DAC 输出的最高采样率、位深由**芯片与系统**决定，播放器标称支持到 384kHz 级别，实际可选档位以设备为准；
- 设备不支持时播放器会内部降采样——文件照样播，只是没跑满；播放页的音频信息里能看到当前曲目实际走的输出规格；
- 外接 USB DAC 时可以绕过系统混音直通解码器；蓝牙侧的上限由编码决定（LDAC 这类高码率编码两端都支持才生效）。

## 五、三个影响听感的播放开关

位置都在 设置 → 音频：

1. **无缝播放（gapless）**：现场录音、专辑连续曲目不留白；
2. **交叉淡化**：曲间淡入淡出，与无缝互斥，二选一；
3. **回放增益**：按专辑或曲目标签统一响度，适合标签规范的整库。
