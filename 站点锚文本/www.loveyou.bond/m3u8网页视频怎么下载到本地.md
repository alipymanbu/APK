# m3u8 网页视频怎么下载到本地

> 网页视频大多不是单个文件，而是一堆小分片按清单排列——这正是浏览器「另存为」存不下它们的原因。
> 本篇讲清什么样的视频链接能下、链接从哪拿、哪些视频注定下不了，以及下完怎么播。

## 一、先分清三种视频链接

| 类型 | 地址长什么样 | 能否当普通文件下载 |
|---|---|---|
| 视频直链 | 以 `.mp4`、`.mkv`、`.webm` 等结尾 | 能，直接下 |
| HLS 流 | `.m3u8` 清单，背后是一堆小分片 | 不能直接下，要按清单抓分片再合并 |
| DASH 流 | `.mpd` 清单，音轨视频轨常分开 | 不能直接下，要按清单抓分片再合并 |

现在的视频站普遍用 HLS/DASH 出流，浏览器里能播、右键却存不下来，就是这两类清单在起作用。

## 二、把链接拿到的几条路子

1. **长按复制**：部分安卓浏览器（如 Via）长按视频或链接会出现「复制链接地址」，拿到后粘进下载器的新建任务；
2. **分享或推送**：一些浏览器支持把链接分享给其他应用，选下载器即可；
3. **桌面端扩展嗅探**：FluxDown 的 Chrome/Edge/Firefox 扩展能自动嗅探网页里的流媒体清单并列出来让你挑，视频量大时在电脑上下完再传回手机反而省事；
4. **开发者工具抓包**：手机上拿不到地址时，用电脑浏览器打开该网页，F12 网络面板里筛 `m3u8` 或 `mpd`，把清单地址复制出来——麻烦，但最通用。

清单地址经常是限时生成的，复制后尽快粘进去，放几分钟就可能失效。

## 三、粘贴之后会发生什么

以 FluxDown 为例：粘进 `.m3u8` 地址后它会自动按流媒体任务处理——有多档画质时先让你选一档（会标注带宽与分辨率），然后并行下载分片、边下边解密（AES-128 加密流也能处理），最后按清单顺序合并成一个完整的本地视频文件。分片下载默认有并发上限，可在设置里调；单个分片失败会自动重试几次再判失败。

## 四、哪些视频注定下不了

- **DRM 加密的付费内容**：视频平台的会员内容普遍有 DRM 保护，任何下载器都下不了，不用浪费时间；
- **带登录态或防盗链的地址**：浏览器里能播、复制出来却 403/404 的直链，多半校验 Referer 或 Cookie，裸链接拿不到数据——用扩展接管（带上会话信息）比手动粘链接成功率高；
- **限时生成的清单**：每次播放都换新地址的站点，复制慢一步就过期；
- **个别站点的防护机制**：接口有风控的没有通用办法。

## 五、下完播不了怎么办

合并完成的文件就是普通本地视频，任何本地播放器都能放。两种常见异常：

- **只有画面没有声音**：这条流的音视频是分开的两轨（DASH 常见）。FluxDown 在系统装有 ffmpeg 时会自动合并两轨；没有 ffmpeg 时会存成两个文件（如 `video.mp4` 和 `video.audio.m4a`），装上 ffmpeg 后重新下载即可自动合并，已有文件也可以手动 `ffmpeg -i video.mp4 -i video.audio.m4a -c copy output.mp4` 合一下；
- **画质比预期的低**：清单里 advertised 的就是全部可选档位，站点没给高清晰度，下载器变不出来。

还没装 FluxDown 的话，安装包信息与获取指引整理在 [FluxDown 中文介绍站](https://www.loveyou.bond/)。视频分片多、下载慢时，排查思路见[BT磁力下载没速度怎么办.md](BT磁力下载没速度怎么办.md)；各种下载器在流媒体支持上的差异见[多协议下载器怎么选.md](多协议下载器怎么选.md)。
