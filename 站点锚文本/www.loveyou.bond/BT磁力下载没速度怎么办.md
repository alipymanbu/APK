## 一、先理解 BT 的速度从哪来

BT 下载的本质是「从其他正在下载或已下载完的人那里拿数据」：你的速度不取决于带宽有多宽，而取决于这条资源**有没有人在做种、你能不能连上他们**。所以同一个种子白天没速度、深夜跑满很正常——在线的人变了。

磁力链接（`magnet:?xt=urn:btih:…`）和 .torrent 种子文件效果一样，只是形式不同；种子里还带文件结构信息，支持逐个勾选要下的文件。

## 二、对号入座：你的情况是哪一种

| 现象 | 原因 | 能做的事 |
|---|---|---|
| 长时间 0%，连元数据都拿不到 | 在线做种的人太少或为 0 | 换一条热门资源验证流程；这条资源无解 |
| 开始很慢，几分钟后起来 | DHT 网络找节点需要暖机时间 | 等一等，别急着删任务重加 |
| 速度忽高忽低 | 各个源的上线时间不一致 | 挂着，BT 任务靠时间熬 |
| 完全连不上 | 运营商或网络环境限制了 BT 流量 | 换 WiFi 与移动数据对比测试 |
| 能看到 peer 数但速度一直是 0 | 路由器没做端口映射，别人连不进你的 NAT | 见下文第三节的端口打通 |

## 三、几个能提高连速的抓手

1. **补充公共 Tracker**：Tracker 是帮 BT 客户端互相认识的介绍人。FluxDown 内置了一批公共 Tracker，也支持在设置里手动添加；多加几条常用公共 Tracker（如 `udp://tracker.opentrackr.org:1337/announce` 这类）能明显提高找到节点的几率——这类地址时效性强，会失效，以网上维护中的公共 Tracker 列表为准；
2. **打通端口**：BT 建连的规律是双方至少有一方端口可达。路由器开着 UPnP 时客户端能自动映射端口；无公网 IP 的网络环境对 BT 的限制所有客户端都一样，社区常见的反馈是 IPv6 网络下能连的资源更多、速度更好；
3. **保持应用在线**：安卓的后台清理会掐断 BT 连接——把 FluxDown 加进电池白名单或后台保护名单，下载期间别用一键清理；
4. **先拿热门资源试**：想验证流程是否走通，用一条做种数多的热门资源比冷门资源靠谱得多。

## 四、PT 站的规矩要先看

私有 Tracker（PT 站）只允许指定客户端接入，用别的客户端下载可能没速度、甚至违反站点规则导致封号——下 PT 资源前先看站点的客户端白名单规定。

直链任务慢是另一套排查思路：先看线程数有没有被调小、软件里的全局限速有没有开启，再考虑换镜像源或错峰下载。安装包信息与获取指引整理在 [FluxDown 中文介绍站](https://www.loveyou.bond/)；网页视频的下载方法见[m3u8网页视频怎么下载到本地.md](m3u8网页视频怎么下载到本地.md)，各下载器的横向对比见[多协议下载器怎么选.md](多协议下载器怎么选.md)。
