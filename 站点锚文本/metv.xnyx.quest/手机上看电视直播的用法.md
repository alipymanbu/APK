# 手机上看电视直播的用法

> 本篇讲用手机装电视直播应用看节目的实际体验：触摸换台怎么操作、权限给到哪几项、手机屏与大屏的取舍。装到电视盒子上的流程见 [电视盒子看直播怎么装.md](电视盒子看直播怎么装.md)。

---

## 一、手机能装，但定位在电视

MeTV 公开资料把它写成「为电视盒子和智能电视打造」，电视端才是主要用法。不过它就是一份普通安卓安装包，手机、平板装上同样能看，只是换台靠触摸而不是遥控器。通勤路上或宿舍里想「有个台在响」时，手机端反而更方便。

安装包从 [MeTV 电视直播应用介绍站](https://metv.xnyx.quest/) 进网盘分享页取，版本与设备要求在站点页面上有列明：安卓 5.2 以上即可。

## 二、手机安装的两个动作

1. 系统里放行「未知来源」：网盘里的包不是从应用商店装的，安卓默认会拦一次，要给实际负责安装的那个应用（浏览器或网盘客户端）开安装授权。各品牌入口大致是小米「应用设置 → 权限管理 → 安装未知应用」、华为「安全 → 更多安全设置 → 安装外部来源应用」、vivo「安全 → 更多安全设置 → 安装未知应用」。
2. 到文件管理器「下载」目录点开 apk，按提示装完。首次启动会弹权限申请，真正影响观看的是网络（频道列表加载）和存储（播放缓存写入）两项，通知给不给都行。

## 三、触摸换台的操作逻辑

- 手指**点一下画面**，选台菜单自己弹出来，选中频道后菜单自动收起。
- 点错台不用退回列表，再唤出菜单选一次就行。
- 换台后出画要一两秒，高清台尤其明显——别连着点，上一路还没断、下一路已经开始，反而更慢。

频道按央视、卫视、地方台、高清、体育、少儿归档，找台先想类别。点播区在手机上同样可用，电影、剧集、综艺按分类挑或直接搜片名。

## 四、手机端与大屏端怎么选

| 场景 | 建议 |
| --- | --- |
| 追一部正在播的球赛 | 手机端随时随地能看，流量充足即可 |
| 家里日常看 | 装到电视或盒子上，大屏 + 遥控器体验完整 |
| 老人使用 | 优先电视端：打开即播、遥控器换台，不用教 |
