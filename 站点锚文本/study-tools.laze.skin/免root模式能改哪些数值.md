# studytool 修改器免 Root 模式能改哪些数值

> 首次打开 Study Tools 会弹「工作模式」：Root、无Root、退出。不少人在这一步犯嘀咕——不 Root 到底还能不能改？本篇把免 Root 模式的能力范围一次列清，顺带说说 Root 模式多出来的那部分值不值得折腾。
> **相关文档**：[修改不生效怎么排查](修改不生效怎么排查.md) · [配置保存与恢复注意事项](配置保存与恢复注意事项.md)

## 一、免 Root 模式的能力清单

无Root 模式是给没解锁、也不想折腾的手机准备的，覆盖日常使用的绝大部分场景：

| 能做的事 | 免 Root 可用性 |
| --- | --- |
| 自动检测已装游戏、过滤系统应用 | 可用 |
| 调整金币、属性等本地数值 | 可用 |
| 调整画质、速度、灵敏度等参数 | 可用 |
| 保存、恢复配置 | 可用 |
| 深度修改、完整功能 | 受限 |

一句话：**存在手机本地的数值，免 Root 基本都够用**；深度修改才需要 Root 环境。

## 二、哪些情况免 Root 改不动

三类常见场景要提前有预期：

1. **走服务器校验的数值**：充值货币、排行榜分数这类存在服务器端的值，本地改了也会被服务器改回去，Root 了也一样改不动——这是游戏设计决定的，跟模式无关。
2. **带反作弊的联网游戏**：数值刚改出去就可能被比对发现，轻则回档、重则封号，免 Root 和 Root 都有这个风险。
3. **刚更新过的游戏**：内部数据结构和旧配置对不上，改法可能整体失效，等配置跟进再试。

## 三、Root 模式多出来的部分，值不值得

Root 模式包含免 Root 的全部能力，另加深度修改与完整功能。但解锁 bootloader 大多会清空手机全部数据，保修可能失效，银行支付类应用还会检测 Root 环境直接拒绝运行。

建议的路径是：**先用免 Root 模式跑一遍你玩的那款游戏**，确认这工具确实对它有效，再评估要不要为它走 Root——别倒过来。

工具的两种模式在[功能与模式说明站](https://study-tools.laze.skin/)里有更直观的对照，安装步骤也在那一并整理了。

## 四、选错了模式怎么办

不用重装。重启应用就会回到「工作模式」选择界面，重新选一次即可；日常用无Root，需要深度修改且设备已解锁时再切 Root。
