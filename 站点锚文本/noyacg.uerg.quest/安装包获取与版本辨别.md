# NoyAcg 安装包获取与版本辨别

> 这篇讲怎么把 NoyAcg 的安卓安装包拿到手、装之前怎么核对，以及为什么网上搜到的两支包不能互相覆盖。
> **相关文档**：[注册邀请码与服务器分区](注册邀请码与服务器分区.md) · [阅读设置与线路切换](阅读设置与线路切换.md)

## 先认准这一支包

NoyAcg 是一个安卓端的 ACG 漫画阅读应用，漫画阅读之外还带一个社区讨论区。网上能搜到的安装资料里，它的包名有两种登记：`asia.noy.now` 与 `asia.noy.th`。对安卓来说，包名不同就是两个不同的应用——不能互相覆盖升级，装完可能出现两个图标，账号数据也不保证互通。

整理时手里这份安装包的情况：

| 项目 | 情况 |
| --- | --- |
| 版本 | 2.4.9 |
| 包名 | `asia.noy.now` |
| 大小 | 约 21.73M |
| 系统要求 | 安卓 5.2 及以上 |

另一支 `asia.noy.th` 的版本号虽然更高（3.x），但它的更新日志、资费口径与这一支并不通用，别拿它当「新版本」去升级手上的应用。判断某个下载页属于哪一支，看它登记的包名就行。

## 怎么拿到安装包

安装包通过网盘分享的方式获取：在介绍站的[下载页](https://noyacg.uerg.quest/download.html)点「获取安装文件资源」，进入网盘资源页后把 APK 转存到自己的网盘或直接下载到手机。下完核对一下文件名与大小（约 21.73M），对得上就是完整的一份。

介绍站首页还有按界面整理的功能说明，不熟悉这个应用的话可以先看 [NoyAcg 介绍站](https://noyacg.uerg.quest/) 的功能与截图部分再决定装不装。

## 装的过程里会碰到的拦截

1. 点开 APK 时提示「不允许安装来自此来源的应用」——安卓对侧载安装的常规拦截，在提示里进设置打开允许开关即可；
2. 提示「解析包时出现问题」——多半是下载不完整，删掉重下一次；
3. 提示「应用未安装」——手机里残留了旧版本，先卸载干净再装；
4. 装完有两个图标——装了两个不同包名的包，留一个、删掉多余的那个。

## 装完之后

第一次打开会停在登录页，这个应用不支持免注册浏览，注册要填用户名、邮箱和密码，具体字段与容易卡住的环节写在 [注册邀请码与服务器分区](注册邀请码与服务器分区.md) 里；装好想直接看阅读玩法，转到 [阅读设置与线路切换](阅读设置与线路切换.md)。
