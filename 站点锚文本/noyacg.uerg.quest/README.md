# NoyAcg 介绍站目录

这是一个围绕安卓端 ACG 漫画应用 NoyAcg 整理的第三方介绍小站，收录了它的功能构成、界面表现、注册要点与安装过程里实际会碰到的问题。想直接看整理好的内容，可以从 [NoyAcg 介绍站](https://noyacg.uerg.quest/) 读起。

## 本目录的文章

- [安装包获取与版本辨别](安装包获取与版本辨别.md)：怎么把安卓安装包拿到手，两支不同包名的包为什么不能混装。
- [注册邀请码与服务器分区](注册邀请码与服务器分区.md)：第一次打开后的账号门槛，邀请码留空、滑块验证、分区选错书架不见了怎么办。
- [阅读设置与线路切换](阅读设置与线路切换.md)：翻页方式、夜间模式、音量键翻页这些设置在哪，图片卡住时怎么换线路。
