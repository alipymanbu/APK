# 自定义字体导入与 emoji 更换

> 内置字体库挑不到心仪的字形？导入自己的 TTF/OTF 字体文件全局使用；顺带把系统 emoji 换成 iOS 等风格。

## 一、导入入口在哪

导入入口在应用的 **Downloads（下载）** 标签页。把字体文件放进手机存储后，在这个页面里浏览选中即可导入。能识别的容器不止 TTF/OTF 裸文件：

- `.ttf` / `.otf` 字体文件本体；
- 装着字体文件的 `.zip` 压缩包；
- 其他应用的主题文件（`.apk`、主题包）里嵌的字体。

也就是说，拿到的是主题包或压缩包时，不用先解包提取字体，直接丢进 Downloads 页让应用自己找。

## 二、字体文件从哪来

两个常用的字体站点：Google Fonts（fonts.google.com，思源黑体、Noto 系列等支持中文的开源字体都在这里，按语言筛「Chinese」能快速定位）与 DaFont（www.dafont.com，英文艺术字体居多，适合标题与个性排版）。

下载字体时注意两件事：一是确认字体的授权条款允许你的用途（多数个人使用没问题，商用前要看授权页）；二是中文用户要确认字体**包含中文字形**——只含英文的字体应用到系统后，中文会回落到默认字体，效果是「英文变了、汉字没变」。应用后中文没变化，几乎都是这个原因，换一个含中文字形的字体包即可。

## 三、导入后怎么应用

导入的字体和内置字体走同一套应用流程：Downloads 页选中 → 预览 → 应用 → 按机型提示在系统字体设置里确认（或重启）。完整步骤与机型差异见[免root换字体方法](免root换字体方法.md)；小米、华为等机型记得先配好文件处理器（见[机型兼容与文件处理器配置](机型兼容与文件处理器配置.md)）。

已 Root 的设备还可以点 Create Module 生成字体模块（Magisk / KernelSU / APatch 均可刷入）。自己做模块时有一条关键规则：字体映射必须**四种字重配齐**（Regular / Bold / Italic / BoldItalic 分别映射到对应的 Roboto 系列文件），只映射 Regular 不会全局生效；中文等其他语言要映射到对应的系统字体族，具体族名到系统字体目录里核对。

## 四、emoji 风格更换

1. 在 Home 页点 **emoji** 入口；
2. 点 See All 浏览全部表情包，常见的有 iOS 风格、Twitter（Twemoji）风格等，选一个点开；
3. 下载后按提示应用，部分机型需要重启后全局生效。

emoji 与字体走同一套主题写入机制，机型兼容、文件处理器的要求完全一致。

**为什么微信、WhatsApp 里的 emoji 没变？** Instagram、TikTok、WhatsApp、Facebook 这类应用自带一套 emoji 图标，不读取系统 emoji，所以系统级更换对它们无效——这不是故障。受影响的是「读系统 emoji」的应用：系统自带短信、浏览器、备忘录，以及多数直接调用系统键盘表情的应用。

## 五、恢复与清理

- Settings 标签页里的 Reset Font 同时负责恢复字体与 emoji 的原厂状态；
- Downloads 页里长按（或字体详情内）可删除已下载项，释放存储空间；
- 字体和 emoji 能同时换，两者独立写入互不影响；先换字体确认生效后再换 emoji，更容易定位问题。

工具的功能清单、界面截图与获取入口见 [zFont3](https://zfont3.bmww.store/) 介绍站。
