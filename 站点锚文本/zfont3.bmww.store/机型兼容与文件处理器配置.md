# 机型兼容情况与文件处理器配置

> 免 Root 换字体能不能成，先看品牌和系统版本；Android 11 以上的小米、华为等机型还要先配一个文件处理器。

## 一、各品牌支持范围一览

免 Root 换字体依赖各厂商主题系统的开放接口，支持情况由「品牌 + 系统版本」共同决定：

| 品牌 / 系统 | 免 Root 支持情况 |
| --- | --- |
| 小米 / POCO / Redmi（MIUI、HyperOS） | 全版本支持 |
| 华为（EMUI、HarmonyOS） / 荣耀（Magic UI） | 全版本支持 |
| LG（LG UX） | 全版本支持 |
| Tecno / Infinix（hiOS、XOS） | 需系统设置里提供「字体」选项 |
| 三星（One UI） | 2026 年 3 月安全补丁起，免 Root 字体通道被系统签名校验拦下；补丁较旧的机型不受影响（查补丁级别：设置 → 软件信息 → Android 安全补丁级别） |
| vivo / iQOO（Funtouch OS、OriginOS） | Android 12 及以下直接可用；13 起要走专门流程，兼容性因机型而异 |
| OPPO / realme（ColorOS） | Android 10 起需设备提供「切换地区到缅甸」的选项才能放开主题字体接口 |
| 一加（OxygenOS） | 需带主题商店且设置里能切换地区 |
| ASUS | 兼容性不定，需实测 |

机型不在上表或标记不确定时，可以先装上用内置字体试一次：应用失败通常只会有提示，不会损坏系统。已 Root 设备不受品牌限制，走 Magisk / KernelSU / APatch 模块路线即可；Root 有失保与变砖风险，不熟悉的话不要轻易尝试。

## 二、为什么需要文件处理器

小米（MIUI、HyperOS）、华为、荣耀、Tecno、Infinix 这几家的主题系统把字体文件存在 `Android/data` 目录下。从 Android 11 开始，系统限制普通应用直接读写这个目录，所以应用字体会失败。文件处理器就是替 zFont 3 拿到这个目录访问权限的一层代理。三星、LG、OPPO、vivo 等走主题商店接口的机型不涉及此目录，装完即用。

方式怎么选：

| 方式 | 配置难度 | 适用范围 |
| --- | --- | --- |
| Legacy（旧版直连） | 简单 | Android 10 及以下，什么都不用配 |
| SAF（存储访问框架） | 简单 | Android 11–12 可靠，13 起基本失效 |
| Shizuku | 中等 | 全部设备、全部版本，首选 |
| Root | 高 | 全部设备可用，但仍建议用 Shizuku |

## 三、Shizuku 配置步骤

Shizuku 是一个独立的授权工具应用，先装好它，然后打开手机的开发者选项（华为/荣耀及多数机型：关于手机 → 连续点「版本号」7 次；小米 MIUI：连续点「MIUI 版本」7 次；HyperOS：连续点「OS 版本」7 次）。

用无线调试配对（Android 11 及以上，无需电脑）：

1. 打开 Shizuku，允许它发的权限请求，点 Pairing（配对）并开启通知权限；
2. 到开发者选项打开「USB 调试」，再打开「无线调试」；
3. 点「使用配对码配对设备」，通知栏会弹出 Shizuku 的配对输入框，把屏幕上的配对码填进去；
4. 回到 Shizuku 点 Start（启动），看到「Shizuku is running」即成功。

然后在 zFont 3 里：Settings → File Handler（文件处理器）→ 选 Shizuku → 在授权框里允许，回到字体页正常应用即可。Shizuku 启动后会一直保持运行，直到手机重启；重启后重新点一次 Start，配对不用重做。

## 四、排错对照

| 现象 | 处理方法 |
| --- | --- |
| 配对成功但点 Start 没反应 | 开发者选项里把「无线调试」关掉再打开，回 Shizuku 重新点 Start |
| 提示 Service Start Failed | 打开 Shizuku 的「应用管理」，把 zFont 开关关掉，重开 zFont 再试 |
| 手机重启后失效 | 正常现象，重新点一次 Start 即可 |
| SAF 一进来就提示 Unsupported | 点 Ignore 忽略，勾选 Use bypass 后再试一次；仍不行换 Shizuku |
| 系统更新后 SAF 突然失效 | 回 File Handler 重新授权一次；反复失效就换 Shizuku |
| 字体应用卡在写入那一步 | 确认文件处理器处于运行状态，再重走一遍应用流程 |

配好之后回到[免root换字体方法](免root换字体方法.md)继续应用字体；想导入自己的字体文件或更换 emoji 风格，见[自定义字体与emoji更换](自定义字体与emoji更换.md)。完整的机型适配说明与获取入口见 [zFont3](https://zfont3.bmww.store/) 介绍站。
