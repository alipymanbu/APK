# 免 Root 换字体的完整方法

> 不获取 Root 权限也能给安卓机换全局字体：前提条件、选字体、应用生效与恢复原字体的完整流程。

换字体前先确认三件事：zFont 3 已装好并能正常打开；机型在免 Root 支持范围内（各品牌差异见[机型兼容与文件处理器配置](机型兼容与文件处理器配置.md)）；小米、华为、荣耀、Tecno、Infinix 机型已配好文件处理器，否则字体会卡在最后写入那一步。

## 一、选字体并应用

1. 打开应用，在 Home 页按风格浏览字体。应用会按你的机型与系统版本自动给出可用项，比如小米机型会标注对应的 MIUI 版本。
2. 点一款字体进详情页，先用预览看实际效果，确认喜欢再下载。
3. 点下载，完成后点 Apply（应用）。这一步应用会把字体文件放进系统主题目录，然后弹出指引。
4. 按指引操作：多数机型是回到桌面，打开系统「设置 → 显示 → 字体」（各品牌路径略有差异），在字体列表里选刚出现的字体项。
5. 部分机型需要重启一次才能全局生效，按提示重启即可。

小米机型的典型路径：应用字体后打开系统「设置 → 字体」，切到「系统字体」页，列表里会出现刚应用的字体，选中并重启手机。华为/荣耀则在「设置 → 显示与亮度 → 字体样式」里选。

## 二、换完后验证这几处

- 打开系统设置页，看菜单文字是否已变成新字体；
- 打开任一社交应用发一条消息，看聊天文字；
- 看锁屏时间与通知栏字体。

有任意一处没变化，通常是写入没成功：重新走一遍应用流程，确认文件处理器（如 Shizuku）处于运行状态再试。

## 三、恢复原字体

换完不满意或出现显示异常时：打开应用 → 进 Settings（设置）标签页 → 点 Reset Font（重置字体），按提示完成，部分机型需要重启。恢复后系统回到出厂默认字体。如果你是在系统字体设置里手动选了别的字体项，也可以直接在系统设置里选回默认，效果相同。

## 四、容易踩的坑

- **字体只改了一半**：某些系统在「省电模式」或「性能模式」下会限制主题刷新，重启后仍未生效就把省电模式关掉再应用一次。
- **三星机型提示「字体不受支持」**：2026 年 3 月补丁后免 Root 字体通道被系统签名校验拦下，属于系统限制而非操作失误，受影响机型与现状见[机型兼容与文件处理器配置](机型兼容与文件处理器配置.md)。
- **应用后部分应用里没变化**：个别应用自带字体渲染引擎、不读系统字体，这类应用不在全局字体的影响范围内，属于正常现象。
- **下载字体时一直转圈**：字体库在境外服务器，网络不畅时换个时间段再试。
- **想用自己的字体文件**：不用在内置库里找相似款，直接导入 TTF/OTF 即可，做法见[自定义字体与emoji更换](自定义字体与emoji更换.md)。

工具的界面预览、机型适配说明与获取入口，见 [zFont3](https://zfont3.bmww.store/) 介绍站。
