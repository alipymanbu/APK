# 怎么查看蹭我家wifi

> 网速莫名变慢、路由器指示灯狂闪，第一反应就是「是不是有人蹭网」。这篇把「查清楚 → 认出来 → 处理掉」三步讲完整，用的工具是手机上的网络扫描应用 Fing，全程不用登录路由器后台。

## 一、先扫一遍，拿到设备清单

手机连上自家 Wi-Fi（注意是主网络，不是访客网络），打开 Fing 点一次扫描，几秒钟后会列出当前网络里的全部联网设备：手机、电视、摄像头、打印机、智能音箱，每台都带着 IP 地址、厂商、型号。

- 没装应用的可先看[功能与界面介绍](https://fing.fewf.click/)，安卓安装文件资源也在那里获取；
- 扫描需要位置权限，这是安卓系统把 Wi-Fi 名称归为位置信息导致的，授权后重扫一次才生效。

## 二、把自家设备逐个「认领」

拿到清单后，按这个顺序过一遍：

1. **对自家设备**：手机、电脑、电视、平板、智能音箱、摄像头挨个对上号。认得出的点进详情改成「客厅电视」「老妈手机」这类名字，下次扫描一眼可辨；
2. **看厂商**：清单里冒出一个你从没买过该品牌产品的条目，基本就是外来设备；
3. **看新旧**：第二次扫描才出现的新条目，比一直躺着的旧条目更值得怀疑。

## 三、这些「陌生设备」其实是误判

别急着下结论，以下几种情况都会让清单比你数出来的多：

- 路由器自身、网络打印机这类基础设施本来就挂在网上；
- 访客手机连过一次留下的记录；
- IoT 设备用随机 MAC 地址，同一台设备看起来像两台；
- 机顶盒、智能电视自带摄像头是明装的，不算偷拍设备。

拿不准的，去路由器后台的设备列表交叉核对一遍，两边对照比单信一边可靠。

## 四、确认被蹭网后怎么处理

按成本从低到高：

1. **改 Wi-Fi 密码**：进路由器后台（地址多为 `192.168.1.1` 或 `192.168.0.1`，账号密码看路由器背面标签），换成 12 位以上、大小写数字符号混排的新密码。这一招不依赖任何付费功能，效果也最彻底；
2. **加密方式选 WPA2 或 WPA3**，淘汰掉 WEP；
3. **给外人发访客网络**：朋友来家里要网，发访客密码，别发主网密码；
4. **改了密码还扫出陌生设备**：检查是不是有自家设备把密码存进了 WiFi 共享类工具，或者路由器管理后台被入侵——重置路由器重新配置最省心。
