# 住酒店民宿怎么检测隐藏摄像头

> 出差、旅游住进陌生房间，越来越多人在入住后会做一遍「网络体检」。这篇讲清一个关键事实：联网型偷拍设备必须挂在 Wi-Fi 上回传画面，所以用 Fing 扫一遍房间网络就能让它现形；同时也讲清扫描查不到什么，免得自己吓自己。

## 一、原理：为什么扫网络能找到摄像头

带直播回传功能的偷拍设备（IP 摄像头）要把画面传出去，就必须连上房间里的某个网络。你连上房间 Wi-Fi 后用 Fing 扫一次，它会以一台普通网络设备的身份出现在列表里，设备类型往往直接标着 Camera，厂商可能是海康威视、大华、TP-Link、萤石这类安防品牌。

安卓安装包与功能介绍见 [Fing 介绍站](https://fing.fewf.click/)，装好后连上房间 Wi-Fi 扫描即可。

## 二、扫描与甄别步骤

1. 入住后先连上房间提供的 Wi-Fi（扫的就是你连的这个网络，务必连对）；
2. 打开 Fing 执行一次扫描，等设备列表出来；
3. 重点看三类条目：类型标着 Camera / IPC / Surveillance 的、厂商是安防品牌的、以及任何你叫不出名字的；
4. 对可疑条目点进详情，拿到型号字符串直接去搜索——是商用摄像头还是别的设备，一搜便知。

## 三、扫描查不到的形态，靠物理检查补

按「能不能联网」划线：

| 摄像头形态 | 网络扫描 | 原因 |
| --- | --- | --- |
| 联网 IP 摄像头（Wi-Fi 直连） | 查得到 | 就在你扫的网络里 |
| 走另一路 Wi-Fi / 热点回传 | 查不到 | 不在你扫的网络 |
| 只录内存卡、不联网 | 查不到 | 不发射任何网络信号 |
| 有线连到录像机 | 查不到 | 同上 |

物理检查两个低成本动作：

1. **关灯看反光**：全屋拉黑，用手机手电筒扫可疑物件（烟感器、闹钟、插座、电视机），镜头会反出一个亮点；
2. **重点位**：正对床和浴室的位置，以及「位置不合常理的东西」——没有电线却插着的充电头、朝向床的烟感器。

网络扫描与物理检查互为兜底，两边都做过才算查过。

## 四、真发现可疑设备怎么办

1. **别拆别动手**，先拍照录视频留存证据；
2. **断开该 Wi-Fi**，改用移动数据继续操作；
3. **报警**：把扫描结果（设备名、IP、厂商、型号）作为线索提供；
4. **联系预订平台**举报房源，平台有义务处理。

隐私检查只应在本人入住的空间内进行，扫描也只针对已获准使用的网络。日常在家查蹭网的方法，见[怎么查看蹭我家wifi](怎么查看蹭我家wifi.md)。
