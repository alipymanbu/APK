# 跑步骑行时怎么在手机上看实时心率

跑步机上没地方放手环配套的屏幕、骑行台上想隔两米也能看清数字、拳击课中间歇休息才想起来看一眼心率——这些场景的共同点是：需要一块**大字号、能一直亮着的心率表**。手机本来就能干这件事，缺的只是一个能把蓝牙心率数据读出来的应用。

## 前提：你的心率来源得会「广播」

手机上的应用自己测不了心率，它读的是**蓝牙低功耗（BLE）广播出来的心率数值**。常见的两类来源：

- **心率带 / 臂带**：胸带沾水贴身戴好，天生就是广播式输出，连上最稳；
- **手表 / 手环**：多数需要先在表上打开「心率广播」（有的叫 Heart Rate Push），部分型号还要求先进入一次运动记录，具体步骤见[手表手环的心率广播模式怎么打开](手表手环的心率广播模式怎么打开.md)。

## 四步把手机变成心率表

1. 在安卓手机上装一个接收端应用，这类工具里 HypeRate 用得最多，它的安卓版可以从 [HypeRate 实时心率工具的介绍页](https://hyperate.bmww.store/)进入安装文件资源入口；
2. 打开手机蓝牙，首次启动时把应用要的蓝牙、「附近的设备」权限都放行；
3. 戴好心率设备，点应用里的搜索按钮，几秒内主屏会跳出实时的 BPM 大数字；
4. 手机往支架上一架——数字用的等宽字体足够大，跑步机显示面板的位置、骑行把立的距离都看得清。

## 训练之外还能做什么

- **课后复盘**：应用会给每场会话生成统计和一条分享链接，训练完发给教练或朋友，打开就能看到这一场的心率曲线概况；
- **顺势开播**：哪天想把训练过程播出去，同一条会话链接加进 OBS 就能变成画面里的心跳挂件，户外场景还能带上速度、地图等信息，写法在[户外直播把心跳速度和地图一起挂上画面](户外直播把心跳速度和地图一起挂上画面.md)里。

## 两个容易踩的点

- **数字一直是「-」**：说明没有设备连上，不是应用坏了。先确认手表端真的在广播心率、胸带电极是湿的，再重新搜索；
- **搜不到设备**：优先检查「附近的设备 / 位置」权限有没有给。安卓扫描 BLE 设备依赖这类权限，缺了就会一直空转。
