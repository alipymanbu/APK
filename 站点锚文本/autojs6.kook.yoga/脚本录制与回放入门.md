# AutoJs6 脚本录制与回放入门

> 完全不会 JavaScript 也能先用起来：把操作录一遍、回放一遍，就是第一个自动化脚本。本篇讲录制回放的入口、录制结果怎么改，以及从哪里继续往深走。
> **相关文档**：[无障碍服务开启与保活.md](无障碍服务开启与保活.md) · [脚本打包成独立APK.md](脚本打包成独立APK.md)

## 先用录制找手感

AutoJs6 的主战场是 JavaScript，但入门不必从语法开始。它内置了录制功能：你在屏幕上的点击、滑动会被记下来，生成对应的脚本，回放一次就等于自动做了一遍同样的事。对没写过代码的人，这是最平滑的起步方式；对会写的人，录制结果也是现成的坐标与控件参考。

## 录制入口在哪

装好后主界面能看到一个浮动按钮，它是 AutoJs6 的快捷操作中心，录制、运行、查看包名与活动、布局分析都收在这里面：

1. 点浮动按钮，选录制；
2. 去目标应用里做一遍想自动化的操作；
3. 回到浮动按钮停止录制，会得到一段生成的脚本；
4. 直接回放验证效果，不满意就重录或微调。

前提只有一个：无障碍服务要先接好，不然录不到东西。卡在这一步就先看 [无障碍服务开启与保活.md](无障碍服务开启与保活.md)。

## 录出来的脚本值得看一眼

打开录制生成的文件，会看到 `click`、`swipe` 这类函数调用。这正好是熟悉 API 的捷径——你做过什么，代码里就写着什么。改一改参数再回放，比看十篇教程记得牢。

## 从回放到自己写

想写复杂逻辑时，注意两件事：

- 脚本引擎是 Rhino，ES5 全部支持、ES6 部分支持，个别新语法用不了很正常；
- 比起坐标定位，控件选择器（`text()`、`id()` 这类）更抗界面变化，能用就优先用；实在要按坐标点，部分操作要求安卓 7.0 以上甚至 Root 权限。

编辑器里就有代码补全和格式化，应用内文档离线可查，写到一半忘了 API 不用跳出应用去搜。这些能力凑在一起，一台手机就能把「录、改、写、跑」走完一轮——完整的功能盘点可以看这篇 [AutoJs6 手机脚本工作台](https://autojs6.kook.yoga/)。
