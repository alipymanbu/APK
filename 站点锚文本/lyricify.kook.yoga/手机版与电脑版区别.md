# Lyricify 手机版与电脑版区别：别装错，也别指望错功能

> 本篇讲清楚 Lyricify 系列里"手机版"和"电脑版"各管什么：能做什么、不能做什么、词库怎么共享。装之前花两分钟看完，能省掉大部分"怎么没有这个功能"的困惑。

Lyricify 不是一个单一应用，而是一套系列：Windows 上的主力叫 Lyricify 4，手机端叫 Lyricify Mobile，此外还有已停止维护的 Lyricify 3。两个现役成员名字很像、图标相近，但分工完全不同。

## 一句话概括分工

- **手机版（Lyricify Mobile）**：听歌时看词。跟着 Spotify 的播放进度滚动显示歌词，带中文翻译，仅此而已——项目文档里说得直白："目标就是显示歌词，现在目标已经达成。"
- **电脑版（Lyricify 4）**：完整体验。逐字歌词动画、桌面歌词、多种歌词界面、歌词导入与管理，全在电脑端。

## 功能对照

| 对比项 | 手机版 | 电脑版 |
| --- | --- | --- |
| 运行平台 | Android、iOS 等 | Windows |
| 配合的播放端 | Spotify | Spotify |
| 歌词界面 | Apple Music 风格（唯一界面） | 多种界面可切换 |
| 逐字歌词 | 不支持，且没有加入计划 | 支持 |
| 桌面悬浮歌词 | 不支持（可用系统小窗近似） | 支持 |
| 导入歌词、管理词库 | 不支持，交给电脑版 | 支持 |
| 共享歌词库 | 是 | 是 |
| 歌词显示延迟 | ±2 秒内属正常范围 | 更实时 |

## 两个最常见的误解

**"手机版怎么没有桌面歌词？"**——开发者文档明确说明原因：Lyricify Mobile 是跨平台开发，iOS 上无法实现传统桌面歌词，所以 Android 端也统一不提供。安卓用户可以用系统的小窗模式近似替代。

**"手机上能显示逐字发光的那种歌词吗？"**——不能。逐字歌词是 Lyricify 4 的功能，手机端只做逐行滚动。

## 词库是打通的

两端共享同一套歌词库。手机上某首歌没搜到词时，可以在电脑版里为该曲目导入歌词并标记，手机端重新打开就能看到；反过来，电脑上标记过的翻译也会同步到手机。

## 按需选择

只用手机听歌，装手机版就够了；想要逐字歌词、桌面歌词或者参与歌词管理，再上电脑版。安卓安装包的获取步骤见本目录的[安卓版下载安装步骤](安卓版下载安装步骤.md)，装好后的界面与体验细节可以看 [Lyricify 安卓版介绍](https://lyricify.kook.yoga/)。
