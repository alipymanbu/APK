# Lyricify 不显示歌词怎么办：按这四种情况排查

> 手机版 Lyricify 打开后一片空白、歌词不出来、或者报 429 错误——这篇按现象分四种情况，逐条给出处理思路。大多数"用不了"其实不是软件坏了，而是它的工作方式和你以为的不一样。

---

先建立一个预期：Lyricify Mobile 是歌词软件，不是播放器。它自己不放歌，只在 Spotify 正在播放时把歌词滚出来。理解了这一点，下面四种情况就都好解释了。

## 情况一：打开后什么都不显示

**先看 Spotify 是否在播放。** 没有正在播放的曲目，它就无事可做——此时点应用里的播放按钮也不会出声，这是设计如此，不是故障。

如果 Spotify 确实在放，依次检查：

1. 手机和 Spotify 的网络连接是否正常，必要时重启 Spotify 客户端；
2. 授权是否过期，退出后重新走一遍浏览器授权；
3. 该曲目是否真的在播放信息里（个别客户端版本偶发不上报播放状态）。

## 情况二：某首歌搜不到歌词

提示"没有找到歌词"时，说明共享词库里暂时没有这首的词条，和手机端本身无关。处理路径在电脑端：用 Windows 版 Lyricify 4 打开曲目管理，手动导入歌词文件并标记，手机端重新打开即可看到。歌词有而翻译没有，也是同样的补法。

## 情况三：总是提示 429 错误

429 是"请求过多"，来自 Spotify 服务端的限流，不是软件本身的错误。三个缓解办法：

- 按项目文档配置**自定义 API Client**，把请求分散开；
- **不听歌时关掉后台**——没有播放却长期挂着会持续发请求，连用十几个小时后更容易触发超长等待的 429；
- 多设备重度使用的话，给每台设备单独建一个 Client。

## 情况四：歌词比歌快或慢几秒

播放进度要经 Spotify 服务端中转，客户端上报、应用轮询两端都有误差，±2 秒内的偏移属于正常范围，不必反复重启。对延迟零容忍的话，电脑版的体验更实时。
