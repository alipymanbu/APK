# NetShare 手机当WiFi中继的用法

本篇讲的是 NetShare 的另一种打开方式：让手机一边连着已有的 Wi-Fi，一边把网络转发出去，给信号覆盖不到的房间续一段网。一台退役的旧手机就能干这件事，省下一台中继器的开销。

热点共享与故障处理分别见[连接电脑共享网络的方法](连接电脑共享网络的方法.md)与[连上热点没有网络的解决办法](连上热点没有网络的解决办法.md)。

---

## 中继模式解决什么问题

家里的路由器放在客厅，卧室隔着两堵墙信号只剩一两格；或者住的屋子太大，阳台、楼上是信号死角。这种时候不一定要买中继器——找一台能正常连 Wi-Fi 的安卓手机（退役旧机最合适），把它摆放在「信号还行」和「信号差」的中间位置，就能把网络接力过去。

NetShare 的特别之处在于不需要 Root：它生成一个以 `DIRECT-` 开头的加密热点，把手机当前连接的 Wi-Fi 网络经由这个热点转发出去，接收设备照常连接。

## 摆位是成败关键

中继效果好不好，八成取决于手机摆在哪：

- 手机所在位置必须**还能收到稳定的源 Wi-Fi**（至少两三格）——中继不能凭空造网，它只是接力；
- 尽量放在信号「还行」区域的边缘，而不是已经没信号的角落；
- 高处、开阔处优于地面、柜子里；
- 离微波炉、蓝牙设备远一点，减少干扰。

## 接入步骤

1. 在旧手机上安装 NetShare 并打开；
2. 确认这台手机已连上家里的 Wi-Fi；
3. 勾选 **Start WiFi Hotspot**，记下屏幕显示的热点名、密码和代理参数；
4. 需要上网的设备连接这个热点，并按屏幕参数配置 HTTP 代理（安卓设备可以直接装 NetShare 点 CONNECT，免配代理）。

## 接入后的两个细节

- **电源要接**：中继需要手机长时间亮机运行，插上充电线，并在电池设置里把 NetShare 设为「无限制」，避免系统后台限制导致断流；
- **用完记得恢复**：接收设备的 Wi-Fi 代理设置在共享结束后改回「无 / 关闭」，否则设备换到别的网络时可能上不了网。

## 合理的预期

用手机当中继，胜在零成本、随取随用，但它替代不了专业设备：带宽经过一次转发会有损耗，覆盖范围也有限，适合救急与轻度使用。信号极差的大户型，还是Mesh 路由或专业中继器更可靠。
