# NetShare 连上热点没有网络的解决办法

本篇集中处理 NetShare 最常见的一类问题：设备已经连上了它生成的热点，却提示「无网络」，或只有个别应用能上网。连不上往往是代理没配对，而不是软件坏了——先对照下表对号入座。

连接流程本身还没走通的，先看[连接电脑共享网络的方法](连接电脑共享网络的方法.md)。

---

## 快速对照表

| 现象 | 常见原因 | 处理方法 |
| --- | --- | --- |
| 连上热点，提示「无网络」 | 代理地址或端口没填、填错 | 回到 NetShare 主屏幕核对地址与端口，填进接收设备的 Wi-Fi 代理设置 |
| 浏览器能上网，个别应用不行 | 部分应用不读取系统 HTTP 代理 | 接收端是安卓：装 NetShare 点 CONNECT；电脑端改用对应的连接方式 |
| 共享几分钟后自动断开 | 系统电池优化限制了后台 | 把 NetShare 的电池策略改为「无限制」，允许后台运行 |
| 熄屏后连接就断 | 后台被冻结或省电策略拦截 | 把 NetShare 加入省电白名单，锁屏前确认通知栏还在显示运行状态 |
| 热点列表里找不到网络 | 热点创建失败或 Wi-Fi Direct 异常 | 两端 Wi-Fi 都关一次再开，重新勾选 Start WiFi Hotspot |
| 用完后手机本身上不了网 | 手动代理设置残留 | 把接收设备的 Wi-Fi 代理改回「无 / 关闭」即可恢复 |

## 为什么必须配代理

NetShare 不走系统自带热点的通道，而是把接收设备的流量经由手机转发。受安卓系统限制，不 Root 的情况下流量需要通过本机代理或隧道中转——所以接收设备连接热点后，还必须把 HTTP 代理指向 NetShare 屏幕上显示的地址和端口（常见为 `192.168.49.1 : 8282`，不同版本可能不同，以屏幕实际显示为准）。

这也是排查的总原则：**连上没网，先查代理**。

## 「浏览器能通、应用不通」的原理

填在系统 Wi-Fi 设置里的是 HTTP 代理，浏览器会遵守它，但有些应用（部分聊天工具、游戏、桌面客户端）使用自己的网络通道，不读取系统代理。遇到这种情况：

1. 接收端是安卓设备：安装 NetShare 后点 CONNECT，走应用内的接入方式；
2. 电脑端：按 NetShare 提供的电脑端连接方式设置。

## 断流问题的两个开关

- **电池优化**：进入系统设置，把 NetShare 的电池策略设为「无限制 / 不优化」，这是「几分钟后就断」的最常见原因；
- **熄屏断线**：部分机型的省电机制会在锁屏后冻结后台应用，把 NetShare 加入省电白名单或允许后台运行即可。

## 排查完还是不通

把两端设备都重启一遍、重新开启热点再连，多数环境类问题在这一步就消失了。更多用法与安装文件资源入口，见 [NetShare 介绍站](https://netshare.boop.uno/)；想了解把手机当中继扩展 Wi-Fi 的玩法，见[手机当WiFi中继的用法](手机当WiFi中继的用法.md)。
