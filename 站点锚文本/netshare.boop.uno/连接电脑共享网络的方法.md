# NetShare 连接电脑共享网络的方法

本篇讲的是用 NetShare 把手机网络分享给电脑的完整流程：从热点开启到电脑端接入，四步走完就能让笔记本用上手机的流量或 Wi-Fi。相关故障处理见[连上热点没有网络的解决办法](连上热点没有网络的解决办法.md)。

---

NetShare 是一款不用 Root 的安卓网络共享工具，工作原理与系统自带热点不同：开启后它会生成一个以 `DIRECT-` 开头的加密热点，接收设备的流量经由手机转发出去。也正因为这个机制，接收端除了连 Wi-Fi，还多一步代理设置——很多「连上了却没网」的情况都是漏了这一步。

## 第一步：在手机上开启热点

1. 在拥有网络来源的手机上打开 NetShare（手机插着流量卡，或已连上 Wi-Fi 的旧手机都可以）；
2. 勾选 **Start WiFi Hotspot**，这是应用里唯一的主开关；
3. 首次运行按提示允许相关权限；
4. 开启后屏幕上会出现三样东西：热点名称（通常形如 `DIRECT-NS-Hotspot`）、连接密码、代理地址和端口（常见为 `192.168.49.1 : 8282`，以屏幕实际显示为准）。

## 第二步：电脑连接这个热点

在电脑的 Wi-Fi 列表里找到屏幕上显示的热点名称，像连接普通 Wi-Fi 一样输入密码。Windows、macOS、Linux 都可以按这个方式接入。

## 第三步：配置代理（关键一步）

电脑连上热点后网络不会立刻可用，需要在 Wi-Fi 详情里手动配置 HTTP 代理：

- **Windows 10/11**：设置 → 网络和 Internet → WLAN → 点击已连接的热点 → 代理 → 手动设置代理，填入应用屏幕显示的地址和端口；
- **macOS**：系统设置 → Wi-Fi → 详细信息 → 代理 → 网页代理（HTTP），填入同样的地址和端口；
- **Linux**：网络设置里对应连接的代理项，填法相同。

填好保存后，浏览器能打开网页就说明通了。

## 第四步：安卓接收端的省事做法

接收设备如果也是安卓手机，可以不填代理：在接收端同样安装 NetShare，打开后直接点 **CONNECT**，应用会自动完成接入。

## 收尾提醒

用完共享后，建议把接收设备 Wi-Fi 详情里的手动代理改回「无 / 关闭」，否则设备回到其它网络时可能因为代理残留而上不了网。

更完整的用法说明与安装文件资源入口，见 [NetShare 介绍站](https://netshare.boop.uno/)；热点开启后扩展覆盖范围的玩法，见[手机当WiFi中继的用法](手机当WiFi中继的用法.md)。
