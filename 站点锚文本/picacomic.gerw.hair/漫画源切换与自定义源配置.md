# PicaComic 漫画源切换与自定义源配置

> PicaComic 是一款开源的多源漫画聚合阅读应用，本篇讲它最核心的「源」怎么用：内置了哪些漫画源、浏览时怎么切换、哪些源要登录账号、自定义源怎么导入，以及源打不开时的排查顺序。

---

## 一、内置了哪些漫画源

按项目仓库的说明，PicaComic 内置了这些漫画源：

- picacg
- E-Hentai / ExHentai
- JM Comic
- Hitomi
- 绅士漫画
- nhentai

不同版本内置的源可能有增减，以应用内实际列表为准。每个源对应不同的漫画网站，内容范围、语言、账号规则都不一样——切换源之后，分类、排行、搜索结果会整套换掉。

## 二、切换当前源的两个入口

1. **浏览时切源**：首页、探索或分类页顶部的源切换下拉列表，换源后列表内容立刻换成新源的数据；
2. **设置里管理**：设置中有漫画源管理项，可以控制源的启用状态、查看已配置的源（入口名称随版本略有差异）。

一个实用习惯：想清楚自己常看哪类内容，固定用一两个源并把它们排在顺手位置——每次把全部源挨个切一遍是多源应用最低效的用法。

## 三、哪些源要登录账号

部分源要求先注册登录，典型的是 picacg：未登录时浏览受限或直接提示登录。注意三点：

- 登录状态**按源分开**——在 picacg 登录了，不代表别的源也登录了；
- 登录之后才能用「网络收藏」这类跟随账号的功能；
- 注册、找回密码只能在对应漫画网站自己的体系里完成，应用本身不代管账号。

## 四、自定义源：从 3.0.0 起的进阶玩法

自定义源解决两个现实问题：内置源配置过期后没有更新渠道；想接入应用不认识的源。

- **源文件形态**：一份 JavaScript 配置文件（`.js`），由对应站点或社区提供，也可以自己写；
- **导入入口**：设置 → 漫画源管理 → 添加自定义源，支持选本地文件或粘贴指向文件的链接；
- **兼容性是最大的坑**：3.1.0 对自定义源机制做过大改造，3.0 时代的老格式文件在 4.x 上很可能直接失效；
- **调试入口**：加载失败的日志在「设置 → App → Logs」里看，源脚本执行出错、请求失败通常都有记录。

安全提醒：源文件能以你的身份在应用内发起网络请求，来历不明的源文件不要导入。

## 五、源打不开，按这个顺序查

1. **先区分范围**：切到别的源试试——只有单个源不行是源站的问题；全都打不开先查手机网络；
2. **查账号状态**：需要登录的源，密码失效、被顶号都会表现成「加载失败」，重新登录一次；
3. **换个时段**：源站维护、限流期间应用侧无解，等恢复；
4. **补自定义源**：项目仓库已标注不再积极维护，内置源配置只会越来越旧，自定义源是唯一的更新手段。
