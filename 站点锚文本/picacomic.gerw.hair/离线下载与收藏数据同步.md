# PicaComic 离线下载与收藏数据同步

> 本篇讲 PicaComic 的数据怎么管：把漫画按章节下到本地离线看、本地收藏与网络收藏的区别、WebDAV 同步怎么配，以及换手机或重装前的动作清单。

---

## 一、把漫画下到本地

在漫画详情页发起下载，基本流程：

1. 搜索或浏览找到目标漫画，点进详情页；
2. 找到下载按钮，选择要下载的章节（整本全选或只挑部分章节）；
3. 确认后在下载管理里看进度。

几点实际情况：

- **下载内容跟源走**：只能下载当前源里的漫画，下完存在本机，断网也能看；
- **体积别小看**：长篇全本下载可能到几百 MB 甚至更多，空间紧张就按章节挑着下；
- **速度取决于源站**：源站限流时快不起来，换时段或换源重试，不是应用坏了。

## 二、管理已下载与导出 PDF

下载管理入口里能看到进行中和已完成的任务；已下载的漫画从「已下载 / 本地」列表直接打开，不需要联网。腾空间就从同一处删除本地文件，删错了一般还能重新下载。

应用还支持把漫画导出为 PDF 文件——想把某几话存成单个文件、传到别的设备上看，比搬图片文件夹方便得多（功能入口以应用内实际显示为准）。

## 三、两种收藏，别搞混

| 对比 | 本地收藏 | 网络收藏 |
| --- | --- | --- |
| 存在哪 | 只存在这台设备的应用数据里 | 存在漫画源网站的账号下 |
| 换手机 / 重装 | 不做备份就没了 | 登录账号就能拉回来 |
| 前提 | 无 | 对应源已登录账号 |

加收藏的入口都在漫画详情页，它进哪一类取决于当前源与登录状态。整理收藏时先把两类分开看，免得以为「都收藏了」，换机时却只找回了网络那部分。

## 四、WebDAV 同步怎么配

本地收藏、阅读历史这类数据可以同步到自己的 WebDAV 空间（坚果云或任何支持 WebDAV 的网盘都行）：

1. 在设置里找到数据同步 / WebDAV 相关项；
2. 填服务地址、账号与应用密码（部分服务要用单独生成的应用密码，不是登录密码）；
3. 先手动推一次，确认方向没搞反——多数「同步后数据不对」是上传 / 下载方向弄反了；
4. 之后养成「加了新收藏就顺手同步一次」的习惯，成本一次点击，收益是任何时候设备出问题都能恢复到最近状态。

## 五、换机或重装前的动作清单

1. 对照上面表格，想清楚多少收藏只存在本机；
2. 登录各源账号，让网络收藏先落上去；
3. WebDAV 推一次同步；
4. 已下载的漫画不在同步范围，需要保留就手动传输或导出 PDF 后带走。

漫画源层面的切换、登录与自定义源配置，见[漫画源切换与自定义源配置.md](漫画源切换与自定义源配置.md)；阅读设置的调优技巧，见[阅读设置与使用技巧.md](阅读设置与使用技巧.md)。
