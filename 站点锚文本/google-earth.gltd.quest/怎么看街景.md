# Google Earth 手机版怎么看街景

> 本篇讲在手机上的 Google Earth 里怎么进街景、进去之后怎么走怎么逛，以及翻历史街景的方法。还没装好的，先看介绍站把应用装上；想了解它和谷歌地图的分工，见[和谷歌地图有什么区别](和谷歌地图有什么区别.md)。

---

## 一、街景的入口藏在地点信息卡里

手机版里没有独立的街景按钮，要先有一个地点：

1. 搜索一个地点，或把地球拖到目标位置后点一下；
2. 弹出的信息卡或底部栏里找**街景小人**（黄色小人图标）；
3. 地图上出现**蓝色高亮**的线条或区域——蓝色画到哪，实景就拍到哪；
4. 点一段蓝色区域，直接「站」到地面上。

## 二、站在路中央怎么动

| 想做什么 | 做法 |
| --- | --- |
| 环顾四周 | 拖动屏幕 |
| 沿路前进 | 点屏幕上的白色箭头顺路走 |
| 缩放 | 右下角放大 / 缩小按钮 |
| 回正北 | 右下角罗盘 |
| 退出 | 左上角返回 |

看完想看平面的，退出街景回到地球视角，之前搜的地点还保留着。

## 三、翻历史街景：看这条街几年前什么样

同一个地点往往拍过多轮：

1. 按上面的步骤进街景；
2. 找**「查看更多日期」**入口，打开时间轴；
3. 拖动滑块或点缩略图切换年份；
4. 看完点「返回最新图像」回到当下。

只有被重拍过的路段才翻得出历史；翻不出来，就是那个位置只拍过一轮。另外，能翻「卫星影像年代」的历史影像滑块是电脑版才有的工具，手机上可翻时间的只有街景这一层。

## 四、这里怎么是灰的

- **覆盖不均**：全球只有部分地区拍了街景，乡村、小岛、部分国家整片没有蓝色线条，就是没拍过；
- **影像糊**：放大超过当地影像分辨率上限图就糊，缩小一档反而清楚；
- **加载卡住**：影像全部在线拉取，网络不通时街景也进不去。
