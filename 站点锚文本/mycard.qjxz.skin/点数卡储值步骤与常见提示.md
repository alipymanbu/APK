# MyCard 点数卡储值步骤与常见提示

> 手里的 MyCard 点数卡怎么充进会员账号：三条路（网页储值、会员中心、App 贴卡储值）逐步走，外加充不进去时的几条排查。
> **本目录其他篇章**：[游戏储值扣点与扫码快速付款.md](游戏储值扣点与扫码快速付款.md) · [安卓客户端安装步骤.md](安卓客户端安装步骤.md)

## 先弄清一件事：卡 ≠ 余额

点数卡只是一串「卡号 + 密码」凭证，直接充给某个游戏就只能一次性用在那一个游戏里。先充进 MyCard 会员账号，它就变成账户余额，可以分次扣给不同游戏，也能统一查账。

## 卡从哪来

便利商店、e-Play 实体门市、购物网站都能买到，不同通路售价略有差异。买卡时确认卡面完好，热感应纸材质的卡别弄湿弄花，否则卡号密码可能读不出来。

## 路线一：App 贴卡储值（手机上最顺）

前提：App 已装好并登录（安装步骤见 [安卓客户端安装步骤.md](安卓客户端安装步骤.md)）。

1. 点 App 底部菜单的**贴卡储值**。
2. 输入卡号与密码；卡面印有二维码的，直接用扫码功能读取，省去逐位输入。
3. 确认储值结果页显示成功即可。

## 路线二：网页储值

1. 打开 MyCard 站点，点上方**点数储值**。
2. 输入卡号与密码，点「进行充值」。
3. 选择「**MyCard 会员点数**」（这一项才是充进会员账户），继续。
4. 按提示登录会员账号，确认账号无误。
5. 出现交易成功画面即完成。

## 路线三：会员中心储值

已经登着会员、只想快速充一笔时走这条路：会员中心登录 → 左侧**点卡储值** → 输入卡号密码 → 交易完成。

## 充不进去的几种情况

| 现象 | 处理 |
| --- | --- |
| 提示「未开通 / 无法正常使用」 | 卡自购买起一年内没用过会触发保护机制，不是卡坏了，联络客服解除即可 |
| 卡号密码报错 | 先核对有没有把 0/O、1/l 看混；卡面模糊就别反复试，直接找客服 |
| 充到了别的账号 | 点数无法直接转移，充值前务必核对账号；详情见下一篇的说明 |

充完想看余额、查交易纪录，打开 App 的会员中心就有；点数怎么在游戏里花出去，接续看 [游戏储值扣点与扫码快速付款.md](游戏储值扣点与扫码快速付款.md)。App 的功能总览与实机画面，也可以先看 [mycard.qjxz.skin](https://mycard.qjxz.skin/) 的整理。
