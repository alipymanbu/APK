## 一句话了解 AdAway

AdAway 靠 hosts 表在域名解析阶段断掉广告与跟踪请求：有 Root 写系统 hosts，无 Root 走本地 VPN，两条路都能对全局应用生效。它以 GPLv3+ 协议开源，由社区自 2011 年维护至今。
