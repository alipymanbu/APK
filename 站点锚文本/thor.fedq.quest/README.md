# Thor 应用管理器 · 资料整理

这里是围绕安卓应用管理器 Thor（包名 `com.valhalla.thor`）整理的一组短文：它是一款 GPLv3 开源工具，用 Kotlin 构建，支持按来源与状态筛选应用、批量冻结与卸载、导出与分享安装包，可通过 Root、Shizuku 或 Dhizuku 三种权限引擎工作。功能介绍、界面截图与安装文件获取入口见 [Thor 应用管理器介绍站](https://thor.fedq.quest/)。
