# 出门在外连回家里的电脑

> 本篇讲人不在家时怎么连回家里那台 Windows 电脑：路由器端口转发与 VPN 两条路各要什么条件，以及暴露远程端口的风险与对策。
> **相关文档**：[手机远程控制电脑怎么弄.md](手机远程控制电脑怎么弄.md)

## 一、先想清楚你要哪条路

手机和电脑在同一个 Wi-Fi 里，填内网 IP 直连就够了，什么都不用配。只有人在外面、电脑留在家里内网时，才需要额外打通一条路。常见的两条：**路由器端口转发**和 **VPN**，二选一。

## 二、路一：路由器端口转发

把路由器公网 IP 上的 3389 端口映射到家里那台电脑。动手前备齐：电脑内网 IP、路由器公网 IP、端口号（默认 3389）、路由器管理员权限。进路由器管理界面加一条转发规则后，手机端连接的 PC name 改填**公网 IP**。

三个会咬人的后续问题：

- **公网 IP 会变**：运营商随时换 IP，一变就连不上——用动态 DNS（DDNS）绑定一个固定域名可解；
- **内网 IP 也会变**：在路由器里给电脑绑定静态内网 IP，避免转发规则指空；
- **口子别开给所有人**：多数路由器支持限制来源网段，只放行你常在的网络。

## 三、路二：先连 VPN 再连电脑（更稳）

手机先连上家里的 VPN，就等于回到了家里局域网——远程桌面客户端的用法与在家时完全一样，电脑**不需要**对公网开任何端口。从安全角度这是更稳妥的一条路：判断标准就一条，**3389 端口有没有直接暴露在公网上**。

## 四、不管走哪条路，先做两件安全的事

- **远程账户用强密码**：公网可达的 3389 端口会被全天候扫描，弱口令账户面临爆破；
- **保持 NLA（网络级别身份验证）开启**：它要求先完成身份验证才建立会话，是廉价有效的一层防护。排查连接问题时临时关闭可以，验完记得开回去。

顺带一提：微软的安卓客户端 Windows App 对这条链路是全程支持的，端口转发后填公网 IP、VPN 场景下填内网 IP，其余步骤完全一致——完整的设置流程见 [手机远程控制电脑怎么弄.md](手机远程控制电脑怎么弄.md)。

工具就绪、链路打通之后，剩下的就是在手机上点开那张连接卡片。[Windows 远程桌面手册](https://windows.fedq.ren/) 把安装与连接的每一步都整理成了页面，卡住时按图索骥即可。
