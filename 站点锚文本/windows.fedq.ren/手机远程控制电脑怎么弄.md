# 手机远程控制电脑怎么弄

> 本篇讲在安卓手机上控制一台 Windows 电脑的完整路径：电脑端要开什么、手机端装什么、连上之后怎么操作。
> **相关文档**：[出门在外连回家里的电脑.md](出门在外连回家里的电脑.md)

## 一、先在电脑那头做好三件事

手机只是「遥控器」，真正决定能不能连上的是被控那台电脑：

1. **系统版本够格**：Windows 家庭版（Home）不能被远程连接，需要专业版、企业版或教育版——在「设置 → 系统 → 关于」里确认；
2. **打开远程桌面开关**：「设置 → 系统 → 远程桌面」打开并确认，记下这一页显示的电脑名称；
3. **账户设过密码**：无密码账户不允许远程登录；默认只有管理员组账户能连，其他账户要加进「远程桌面用户」组。

## 二、手机端装一个远程桌面客户端

安卓上常见的选择是微软的 Windows App（包名 `com.microsoft.rdc.androidx`，早年叫 RD Client / Microsoft Remote Desktop），免费、专门干这件事。它的功能与安装入口可以看这份 [Windows 远程桌面手册](https://windows.fedq.ren/)，那里把界面、步骤和常见坑整理得很全。

## 三、添加连接，填对凭据

1. 打开应用进入连接中心，点 **+** 选 **Desktop**；
2. PC name 填电脑名或 IP 地址（同一 Wi-Fi 下填 IP 最稳，IP 在电脑的「设置 → 网络和 Internet」里看）；
3. 账户建议选「添加用户账户」存进应用，免得每次输；
4. 密码填电脑账户的**真实登录密码**——锁屏上用的 PIN 在这里无效；微软账户就填完整邮箱地址。

首次连接会弹证书确认，点 Connect 继续；连上后屏幕上出现的就是电脑的完整桌面。

## 四、连上之后的操作逻辑

手机屏幕变成了 Windows 桌面，鼠标动作用手势代替：单指轻点等于左键、长按等于右键；也可以切到「鼠标指针」模式，按住拖动一根可见指针，点小按钮更准。双指捏合能缩放远程画面，字太小就看这一招。

连不上时按顺序排查：两台设备是否同一网络、电脑是否休眠、防火墙是否放行 3389 端口、IP 是否填对。人不在家里网络时，还需要先打通外网链路——具体见 [出门在外连回家里的电脑.md](出门在外连回家里的电脑.md)。
