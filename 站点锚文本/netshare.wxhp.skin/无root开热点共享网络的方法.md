# NetShare 无 root 开热点共享网络的方法

> 本篇讲不获取系统最高权限也能把手机网络共享出去的思路：为什么普通热点会被锁、NetShare 走的是什么通道、从开启到接通的四步流程。
> **相关文档**：[热点共享连上没网怎么办.md](热点共享连上没网怎么办.md) · [电脑怎么连这台热点上网.md](电脑怎么连这台热点上网.md)

---

不少套餐的热点开关被运营商锁着，或者开共享要另外加钱；也有人只是想给信号差的房间补一层 Wi-Fi 中继。这类需求用一个不足 1M 的小工具就能解决——它不改动系统任何配置，装上就能用。

## 一、为什么它可以不 root

安卓对普通应用的最大限制，是不允许未取得系统权限的应用直接转发网络流量——这是大多数共享工具绕不开的坎。NetShare 的做法是换个思路：它在手机本机起一个代理服务，热点本身照常建立（走 WiFi Direct 通道，名称常带 DIRECT- 前缀），接入设备的流量统一经由这个代理出去。系统转发权限没被碰，共享照样成立。

副产品也有两个：一是卸载干净不留痕，二是热点自带 WPA2 密码，接入方需要密码才能连。

## 二、从开启到接通的四步

1. 在有网的手机上勾选 Start WiFi Hotspot，屏幕给出网络名、密码和代理地址；
2. 第二台设备连上这个热点（此时显示已连接但上不了网，属正常）；
3. 把该网络的 HTTP 代理指向手机屏幕显示的地址（默认 192.168.49.1，端口 8282）；
4. 打开任意网页能刷出来，链路就算通了。

第 3 步是最容易漏的一步，也是「连着但没网」的唯一常见原因——具体的排查顺序与症状对照，见 [热点共享连上没网怎么办.md](热点共享连上没网怎么办.md)；Windows、macOS 等桌面系统去哪里填代理，见 [电脑怎么连这台热点上网.md](电脑怎么连这台热点上网.md)。

另一台安卓设备当接收端时最省事：装上同一款应用点 CONNECT，代理自动配好，不用手动填。

## 三、分出去的是哪种网络

没有单独的「中继开关」：手机连着 Wi-Fi 时，分出去的就是这条 Wi-Fi 的网络；用流量时就分流量。想让房间角落蹭上客厅宽带，就把手机放在信号尚可的位置连家里 Wi-Fi 再开共享。

## 四、在哪里获取

工具的安装文件资源与完整的安装步骤，都整理在 [NetShare 无 root 热点共享说明站](https://netshare.wxhp.skin/)里，从获取到装好一共四步，几分钟的事。
