# NetShare 热点共享连上没网怎么办

> 设备连上热点却刷不出网页，是这套用法里最常见的一道坎。本篇按出现频率从高到低给出核对顺序与症状对照表。
> **相关文档**：[无root开热点共享网络的方法.md](无root开热点共享网络的方法.md) · [电脑怎么连这台热点上网.md](电脑怎么连这台热点上网.md)

---

先说结论：九成的「连上没网」都卡在同一处——代理没配或配错。热点只负责让两台设备见面，流量真正出去靠的是手机上的代理服务，这一步不完成，状态栏的「已连接」只是假象。

## 一、先核对三件最基本的事

1. 手机端共享在跑：Start Hotspot 勾着、应用没被从后台划掉；
2. 设备连的是这个热点本身，不是附近同名的 Wi-Fi（热点名可能带 DIRECT- 前缀）；
3. 代理已配置，地址和端口与手机屏幕当前显示的一致（默认 192.168.49.1，端口 8282）。

三条都对仍不通，再按下面的症状对表。

## 二、按症状对表

| 症状 | 先查什么 | 再查什么 |
| --- | --- | --- |
| 搜不到热点 | 手机端开关是否勾上 | 按 DIRECT- 前缀找；两端开关一次 Wi-Fi 再扫 |
| 连上但没网 | 代理没配或端口填错 | 照手机屏幕显示的地址端口重新填 |
| 浏览器能开，个别软件没网 | 那个软件不走系统代理 | 该软件内单独设代理，或换支持代理的版本 |
| 游戏和语音连不上 | 不走系统代理的应用属方式边界 | 这类应用接不进来，属正常现象而非故障 |
| 换回原来的 Wi-Fi 反而没网 | 手动代理忘了关 | 把该网络的代理设回「无」 |
| 共享用着用着断 | 省电策略杀后台 | 给应用关电池优化、允许后台活动 |
| 之前能用，突然不行 | 屏幕显示的 IP 或端口变过 | 代理处同步改成当前显示值 |

## 三、两个高频疑问

**为什么一定要配代理？** 安卓不允许未取得系统权限的应用直接转发流量，代理是这套方案接通流量的唯一通路，跳过它热点就是「连着但没网」。

**用完之后要注意什么？** 手动配过代理的设备，回原网络前把代理设回「无」——代理留着，设备连家里 Wi-Fi 时还会去找 192.168.49.1，结果就是「换了网络反而没网」。

## 四、工具从哪来

还没装的读者，安装文件资源与安装步骤都整理在 [NetShare 热点共享说明站](https://netshare.wxhp.skin/)，装好后回到本文第一节的三条核对，一般几分钟内就能跑通。
