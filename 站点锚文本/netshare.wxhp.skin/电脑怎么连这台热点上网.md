# NetShare 电脑怎么连这台热点上网

> 笔记本想借手机的网络，Windows 与 macOS 的代理入口藏得深。本篇按系统给出完整路径与收尾动作。
> **相关文档**：[无root开热点共享网络的方法.md](无root开热点共享网络的方法.md) · [热点共享连上没网怎么办.md](热点共享连上没网怎么办.md)

---

电脑连热点这一步和平常连 Wi-Fi 没区别，差别全在「连上之后要配一次 HTTP 代理」。代理地址以手机应用屏幕显示为准，默认 192.168.49.1、端口 8282。

## 一、Windows

1. 任务栏 Wi-Fi 列表找到热点（名称常带 DIRECT- 前缀），输密码连接；
2. 控制面板 → Internet 选项 → 连接 → 局域网设置，勾「为 LAN 使用代理服务器」，填地址与端口；
3. 打开网页验证；用完回到局域网设置，取消勾选——代理留着，回家连路由器时会找不到网。

## 二、macOS

1. 系统设置 → 网络 → Wi-Fi，连上热点后点「详细信息」；
2. 「代理」页签里勾选网页代理（HTTP），填地址与端口，好确定；
3. 验证后记得回来把代理关掉，否则离开热点后浏览器会一直指向一个不存在的地址。

## 三、平板与另一台手机

- iPhone / iPad：设置 → Wi-Fi → 点开该热点网络 → HTTP 代理 → 手动，填地址端口；
- 另一台安卓：装上同一款应用，打开点 CONNECT（首次请求 VPN 权限，允许即可），应用内自动完成，不用手动填——最省事的接法。

## 四、接通之后

浏览器能开网页即链路已通。游戏、语音通话这类不走系统代理的应用多半接不进来，属于方式本身的边界；用着用着断线则先查手机省电策略。获取方式与安装步骤见 [NetShare 热点共享说明站](https://netshare.wxhp.skin/)。
