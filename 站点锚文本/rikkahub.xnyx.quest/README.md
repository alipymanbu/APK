# RikkaHub 介绍站

RikkaHub 是一款开源的安卓 AI 聊天客户端：它本身不带模型，而是把 OpenAI、Gemini、Claude 与各种 OpenAI 兼容接口收进同一个对话界面，密钥自备、对话数据留在手机本地。本目录收集围绕它的使用整理，从密钥配置到进阶玩法。

- [API密钥配置与模型接入](API密钥配置与模型接入.md)：各家服务商的密钥从哪申请、怎么填进 RikkaHub。
- [免费模型与低成本用法](免费模型与低成本用法.md)：不花钱先跑起来的三条路。
- [消息分支与MCP工具玩法](消息分支与MCP工具玩法.md)：让聊天客户端变成能干活的工具台。

更多功能清单与界面预览，见 [RikkaHub 介绍站](https://rikkahub.xnyx.quest/)。
