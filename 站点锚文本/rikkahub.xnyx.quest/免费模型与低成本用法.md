# 不花钱先用上 RikkaHub 的三条路

> RikkaHub 是「自带密钥」的聊天客户端，但这不等于必须先掏钱：从内置免费模型到本机模型，三条路按成本从低到高排。
> **相关文档**：[API密钥配置与模型接入](API密钥配置与模型接入.md) · [消息分支与MCP工具玩法](消息分支与MCP工具玩法.md)

## 一、零配置：内置的免费小模型

从 1.4.8 版本起，RikkaHub 与硅基流动合作，应用内默认内置了免费小模型（名单里出现过 Qwen3-8B、GLM-4.1V-9B 等，随版本可能变化）——不需要注册、不需要 API Key，装好就能在对话页左下角的模型选择器里直接切换。

这条路适合刚装完试手感、验界面；小模型能力有限，复杂任务还得往下面两条路走。

## 二、免费额度：从 Gemini 的 key 开始

各家服务商里最典型的免费起点是 Google AI Studio：注册后有免费额度，拿到的 key 填进 RikkaHub 就能正常用，配置步骤见 [API密钥配置与模型接入](API密钥配置与模型接入.md)。

要注意：免费额度、限速与可用模型随政策调整，别把「现在免费」当成永久承诺，申请前以各家页面当时显示为准。

## 三、零账单：电脑跑模型，手机来连

电脑上用 Ollama 或 LM Studio 跑开源模型，手机与电脑连同一个网络，RikkaHub 新建一个 OpenAI 兼容服务商，Base URL 填局域网地址（形如 `http://192.168.x.x:11434/v1`），密钥按工具要求填（Ollama 通常留空）。

这条路的账单是零，但回答质量取决于电脑跑得动的模型，出门不在同一网络就连不上。

## 四、走付费 API 时的省法

决定按量付费后，成本大头在聊天模型。RikkaHub 的默认模型设置按功能分模块，把小任务分给小模型是通用省法：

| 功能 | 建议 |
| --- | --- |
| 聊天模型 | 按需选主力，这里决定回答质量 |
| 标题生成模型 | 选参数量小、稳定的，别用推理类大模型 |
| 聊天建议模型 | 不需要就直接关掉，不再产生调用 |
| 翻译模型 | 常用量不大，小模型即可 |

装好应用是第一步，安装包与安装过程整理在 [RikkaHub 介绍站](https://rikkahub.xnyx.quest/)；配好之后的进阶玩法见 [消息分支与MCP工具玩法](消息分支与MCP工具玩法.md)。
