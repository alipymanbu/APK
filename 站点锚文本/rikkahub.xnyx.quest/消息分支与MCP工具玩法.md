# 消息分支、助手定制与 MCP 工具的实战玩法

> 密钥配好只是起点。RikkaHub 真正拉开差距的是这几个功能：消息分支、自定义助手、记忆与 MCP 工具——这份整理按使用场景把它们串起来。
> **相关文档**：[API密钥配置与模型接入](API密钥配置与模型接入.md) · [免费模型与低成本用法](免费模型与低成本用法.md)

## 一、消息分支：一个问题试多种问法

对任意一条回复创建分支，对话就从那个节点岔出一条新走向，原对话保持不动。两类典型场景：

- 同一个问题想比较两种问法，看哪种得到的答案更好；
- 在同一个上下文里对比两个模型的回复——先切模型再开分支，两家的答案并排留着。

## 二、助手：把常用场景做成「人格」

每个助手可以配自己的系统提示词、默认模型与人格，聊天页一键切换；不同助手之间的对话互相隔离，工作与生活分成两个助手，记录互不掺和。

几个可抄的模板：

- **翻译助手**：提示词写明「中译英/英译中，只输出译文」；
- **周报助手**：固定输出格式与语气；
- **代码审查助手**：绑定一个擅长代码的模型，提示词里写清审查重点。

系统提示词支持变量（当前模型名、当前时间等），写模板时能自动填充。应用还支持导入 SillyTavern 角色卡，玩角色扮演的可以把现成卡片直接带进来。

## 三、记忆：跨对话记住偏好

记忆入口在助手配置里：进「记忆」页签可以开关、查看、手动编辑它记住的内容。两点须知：

- 记忆是模型主动记录的，要求所用模型支持工具调用——换不支持工具调用的模型，记忆可能不工作；
- 不想被记住的隐私内容，聊完记得进这个页签手动清。

## 四、MCP 与联网搜索：让它能干活

- **MCP 工具**：设置里配置 MCP 服务器（地址、请求头），给模型挂上外部能力，让它查数据、调服务；连不上时先核对地址与请求头取值，确认服务本身在线。
- **联网搜索**：接上 Exa、Tavily、Brave 等搜索服务的 key——注意搜索用的是搜索服务自己的密钥，与模型密钥无关，没配搜索 key 时「联网」不会有反应。

## 五、输入与渲染的细节

输入栏可以附带图片、文本文件、PDF、Docx 一起提问；回复按 Markdown 渲染，代码高亮、LaTeX 公式、表格、Mermaid 流程图都正常显示。顺带一提：别拿「你是哪个模型」去考它——默认不给模型注入身份提示词，模型自我认知本来就不准，在意就在系统提示词里写明。
