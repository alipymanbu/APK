# RikkaHub 的 API 密钥怎么配置，各家模型怎么接

> RikkaHub 装好后的第一道门槛就是密钥：这份整理把主流服务商的申请入口、填写的位置、容易填错的字段一次说清。
> **相关文档**：[免费模型与低成本用法](免费模型与低成本用法.md) · [消息分支与MCP工具玩法](消息分支与MCP工具玩法.md)

## 一、先理解它的接入方式

RikkaHub 是「自带密钥」型的聊天客户端：应用里每个服务商对应一份配置，填入密钥与接口地址后即可在对话里切换使用。它兼容三类写法：

- **OpenAI 兼容接口**：OpenAI、DeepSeek、硅基流动、OpenRouter、本地 Ollama 都走这一类，Base URL 形如 `https://xxx/v1`；
- **Google Gemini**：独立类型，从 Google AI Studio 拿 key；
- **Anthropic Claude**：独立类型，从 Claude 控制台拿 key。

## 二、配置的落点在哪

设置 → 「提供商」→ 右下角加号新建。以 OpenAI 兼容类型为例，关键字段四个：

| 字段 | 填什么 | 易错点 |
| --- | --- | --- |
| 名称 | 随意起，方便自己认 | —— |
| API Key | 服务商后台生成的密钥 | 前后别带空格，粘贴后先保存再测 |
| API Base URL | 服务商给的接口地址 | 结尾带不带 `/v1` 按服务商文档来，拼错是最常见的报错原因 |
| API 路径 | 一般留默认 `/chat/completions` | 用 Response API 的才需要另说 |

保存后进「模型」页签拉取模型列表，勾选要用的即可回到对话页切换。

## 三、密钥从哪里申请

- **DeepSeek / 硅基流动 / OpenRouter**：各自开放平台注册后即可生成 key，按量计费，部分有新户赠送额度；
- **Google Gemini**：Google AI Studio 的免费额度最友好，适合第一把钥匙；
- **本地模型**：电脑上跑 Ollama（默认端口 11434）或 LM Studio，手机与电脑连同一网络，Base URL 填局域网地址，这条路零 API 账单。

各家的免费额度、限速政策随时可能调整，申请前以服务商页面当时显示为准。

## 四、换机迁移：二维码导入导出

服务商配置支持导出成二维码、新机扫码导入，免得逐个重敲密钥。注意二维码里是完整密钥，导出后别随手截图乱放；密钥弄丢了只能去服务商后台重建。
