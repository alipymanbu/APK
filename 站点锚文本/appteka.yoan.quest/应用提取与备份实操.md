# 不用 Root 把已装应用提成 APK：提取与备份的做法

> 本篇讲怎么把手机上已装的应用提取成 APK 文件：备份到本机、分享给别人、发布上架，三种去向各是什么做法。

---

「把手机里的应用变成文件带走」是这类工具最早的本职——这个市场的客户端前身就叫 AppSend，应用提取才是它起步的功能，商店反而是后来长出来的。换机前攒一份安装包、把某个应用传给别的设备，用的都是这一套，而且全程不需要 Root。

## 三种去向

| 你想做的事 | 怎么实现 | 要不要登录 |
| --- | --- | --- |
| 备份自己手机的应用 | 提取成 APK，存在本机或转存到电脑 | 不需要 |
| 把应用传给别人 | 提取后走系统分享面板发出 | 不需要 |
| 把应用发布给所有人 | 客户端内走上传流程，过审后上架 | 需要 |

## 提取时要知道的几件事

- 提取入口在已装应用列表与应用详情里，不同版本位置略有差异，以实际界面为准；
- 绝大多数应用都能提，包括大部分系统应用；个别受系统保护的会失败，属正常现象；
- 产物是标准 APK 文件，可以用文件管理器继续复制到 SD 卡或电脑。

**一个容易误会的边界**：APK 只含应用本体，不含应用数据。聊天记录、游戏进度这类东西不会跟着 APK 走，备份它们要用应用自带的备份功能——换机前两样都做，才不会丢东西。

## 备份的完整建议

1. 提取后把 APK 复制一份到电脑或自己的网盘，只存在手机里等于没备份；
2. 装回时签名一致的应用可以直接覆盖安装升级；想回退旧版本得先卸载，卸载会连本地数据一起清掉，先备份再动手；
3. 定期整理一次，删掉已经不用的，留下的按用途归档。
