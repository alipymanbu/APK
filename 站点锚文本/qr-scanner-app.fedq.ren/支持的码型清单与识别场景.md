# 支持的码型清单与识别场景

> QR Scanner app 认得哪些码：二维码与条形码的完整清单、每类码的常见用途、扫码后能直接执行的动作，以及它和手机系统相机的分工。

## 一、先看结论

日常遇到的码，绝大多数它都认得：QR 码自不必说，商品条码（EAN / UPC）、物流面单（Code 128）、外箱码（ITF）、火车票证件上的 PDF417 都在覆盖范围内。识别分两条路：摄像头对着扫，或把相册里的图片交给它识别——朋友发来的截图、拍下来的海报码，不用再对着屏幕翻拍。

## 二、码型全清单

**二维码（2D）：** QR Code（可承载网址、文本、联系人 MeCard / vCard / vcf、日历事件、WiFi 接入信息、地理位置、电话、邮箱、短信）、Data Matrix（零部件小码）、Aztec Code（登机牌、电子票）、PDF417（火车票、证件上的堆叠式码）。

**一维条形码（1D）：**

| 类型 | 常见用途 |
| --- | --- |
| EAN-13 / EAN-8、UPC-A / UPC-E、JAN、GTIN、ISBN | 商品条码、书号 |
| Code 39 / Code 93 / Code 128 | 物流与工业标签 |
| Codabar | 图书馆、血库标签 |
| Interleaved 2 of 5（ITF） | 包装箱外箱条码 |
| GS1 DataBar（RSS-14） | 生鲜与优惠券条码 |

## 三、扫码之后能直接做什么

识别只是第一步，它会按内容类型给出对应的动作，少一次手动中转：网址在内置标签页打开并接入 Google Safe Browsing 检查；WiFi 码弹出名称密码确认后直接连入；名片码一键存通讯录；日历事件直接添加；地理位置打开地图；电话号码直接拨打；商品条码可查商品与价格信息。

这些动作的界面演示与逐屏说明，整理在 [QR Scanner app 介绍站](https://qr-scanner-app.fedq.ren/)的功能区。

## 四、和系统相机怎么分工

系统相机解决「偶尔扫一下」：餐厅菜单、WiFi 连网这种一次性 QR 码。下面这些场景，装一个专用扫码器更顺手：

- 扫商品条码查价、做盘点台账——多数机型相机不支持条码，且历史与导出是刚需；
- 暗光、褪色、倾斜的小码——手电筒补光加双指缩放，成功率明显高于裸相机；
- 断网环境（仓库、地下室）——它的识别在本机完成，离线照样工作；
- 扫完要找回记录——历史自动留档，可搜索、可备注、可导出表格，用法见[扫码历史导出表格做台账.md](扫码历史导出表格做台账.md)。

偶尔才扫一次的话，系统相机确实够了，不必多装一个。

## 五、识别不出来的几种可能

反复扫不出时，先对照三点：一是距离——条码贴太近反而难对焦，离 10~20 厘米更容易成功；二是光线——暗处开手电筒补光，反光塑封码稍斜一点角度避开反光；三是码型本身——超出了第二节清单范围的码（如被加密或自定义格式的码），换什么工具都读不出。安装与权限类的问题整理在[安卓安装步骤与常见拦截处理.md](安卓安装步骤与常见拦截处理.md)。
