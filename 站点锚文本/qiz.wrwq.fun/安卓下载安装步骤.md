# Qiz 安卓下载安装步骤：从网盘转存到装好打开

> 本篇讲怎么把 Qiz 的安卓安装包装进手机：网盘转存与下载、允许未知来源的设置路径、五步完成安装，以及装不上时的三种处理。
> **相关文档**：[兴趣匹配与交友玩法.md](兴趣匹配与交友玩法.md)

---

Qiz 是一款以兴趣标签为核心的交友应用，安卓端走 APK 安装包路线，需要自己装进手机。整包流程是：网盘转存 → 下载 → 允许未知来源 → 安装 → 注册。网盘里这份为 1.0.1 版安装包，约 57 MB，要求 Android 7.0 及以上。

## 一、取安装包：先转存再下载

1. **打开分享页**：进入 [Qiz 介绍站](https://qiz.wrwq.fun/)，页面上「获取安装文件资源」按钮指向夸克网盘分享页，手机上用夸克 App 打开最省事。
2. **先转存**：选中安装包转存到自己的网盘目录。转存过的那份不受原分享后续状态影响，这一步别省。
3. **再下载**：转存完成后下载到手机。下载完看一眼体积是否约 57 MB——明显偏小说明没下完整，装的时候会报「解析包错误」，重新下载一次即可。

## 二、安装五步

1. **给文件管理器开安装权限**：「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，把用来打开 APK 的那个应用（文件管理器或浏览器）的开关打开。国产定制系统这项常收在「安全」或「隐私」分类下。
2. **点开 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续，这是侧载安装的常规提示，不代表文件有问题。
3. **安全中心再拦就看拦截记录**：在拦截记录里选「继续安装」；还不行就换一个文件管理器重新打开安装包。
4. **等安装完成**：出现「应用未安装」提示多半是手机里已有同包名的另一个渠道版本（签名不一致），先卸载旧的再装；安卓不允许用低版本覆盖高版本，回装旧版同样要先卸载。
5. **打开并完成注册**：手机号验证码登录，按引导填好兴趣标签、给通知与麦克风权限，就能开始匹配了。首次进入需要联网加载，卡在加载页先确认手机能正常上网。

## 三、装完先做两件事

- **把标签填具体**：「独立游戏」「冷门番」这类具体词比「游戏」这种大词更容易匹配到同频的人，标签是这套匹配逻辑的地基。
- **把权限给到位**：麦克风管语音匹配、定位管同城与附近，没给到对应入口就用不起来；都在系统设置的应用权限里随时可调。

## 四、玩法入口

装好之后从哪玩起？兴趣匹配有语音、快速、同城三种方式，交友墙可以按距离与在线状态筛人，兴趣广场发图文视频参与话题。具体的玩法思路、标签填写建议与常见问题排查，见[兴趣匹配与交友玩法](兴趣匹配与交友玩法.md)一篇，或在 [Qiz 兴趣交友介绍站](https://qiz.wrwq.fun/) 里看带界面的完整版本。
