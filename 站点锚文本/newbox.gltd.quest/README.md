NewBox 是 TVBox 体系的安卓播放应用，装完不自带片库，内容全靠订阅源加载——所以围绕它的问题大多集中在三件事上：源从哪接、盒子怎么装、频道卡了怎么换。三篇文章各对应一件事；想按使用顺序系统过一遍的，可以从 [NewBox 使用参考站](https://newbox.gltd.quest/) 读起，那里配了界面截图对照。
