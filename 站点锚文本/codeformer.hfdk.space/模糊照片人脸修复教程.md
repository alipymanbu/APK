# codeformer 模糊照片人脸修复教程

> 手里有一张模糊、看不清脸的照片？这篇把 codeformer 手机应用修复一张人脸照片的完整流程走一遍：导入、处理、调滑块、保存成片，以及修不满意时往哪调。

## 一、开始前准备

- 手机相册里有一张要处理的照片：模糊、低分辨率、噪点多、脸部看不清都行。
- 应用已拿到照片/存储权限。没给的话导入列表会是空的，去系统「设置 → 应用 → codeformer → 权限」把照片权限改成允许。

## 二、完整操作流程

1. 打开应用，在首页选照片修复 / 人脸修复类的功能入口。
2. 从相册导入照片，支持一次勾选多张批量导入。
3. 点开始修复，等进度跑完。单张通常几十秒内完成，取决于手机性能和照片尺寸。
4. 处理完出现预览，对比原图与修复结果。
5. 满意就保存到系统相册，也可以直接分享出去；不满意按下一节调滑块重跑。

## 三、修复幅度滑块怎么调

应用里那根滑块控制 AI 对画面改动的大小，一端是更激进的修复（细节补得多、画面干净，但五官可能与原来有出入），另一端更保守（尽量保留原样，清晰度提升有限）。

| 处理的内容 | 建议滑块位置 |
| --- | --- |
| 带背景的整张照片 | 中间偏保守 |
| 只有人脸的特写照 | 中间（从这里起步） |
| 视频 | 最靠保守一端 |

实操顺序：先从中间档跑一次看默认效果；修出来不像本人 → 往保守端拉一档重跑；脸还是糊、噪点多 → 往激进端拉一档重跑；两头都不满意 → 多半是原图质量太差，重拍或重新扫描一张再试。同一张照片多试两档再定稿，比反复纠结一档更省时间。

## 四、批量处理与保存

- 一次勾选多张照片批量导入后逐张处理，适合一整套旧照片集中翻新。
- 保存后在系统相册按最近日期就能找到；华为鸿蒙新系统上若图库里没显示，去文件管理的「图片」分类找，成片并没有丢。

## 五、对结果的合理预期

- 破损过于严重的照片无法百分之百复原，AI 补出来的部分属于合理推断。
- 本来就清晰的照片没必要再过一遍修复，反而可能被改出奇怪细节。
- 人脸在画面里只占几十个像素时，补出来的长相参考价值有限。
