# codeformer 安卓版下载安装步骤

> 这篇只讲一件事：把 codeformer 的安卓安装包装进手机并顺利打开。每一步都标了系统会怎么提示、该怎么应对。
> **同站相关文档**：[模糊照片人脸修复教程.md](模糊照片人脸修复教程.md) · [手机应用与开源模型的区别.md](手机应用与开源模型的区别.md)

---

## 一、安装前知道三件事

- 安装包为 v1.6，体积 78.21 MB，中文界面。
- 手机剩余空间最好保持在安装包体积的 3 倍以上。
- 近几年的安卓手机一般都能装，系统要求以安装时手机给出的提示为准。

## 二、下载与安装四步

1. **拿到安装包**：打开 [codeformer 安卓版下载与介绍](https://codeformer.hfdk.space/)，点「获取安装文件资源」进入分享页，把 codeformer_v1.6.apk 保存后下载到手机。
2. **核对文件**：下载完在文件管理器里查看大小，应在 78.21 MB 上下；对不上说明没下完整，删掉重下。
3. **允许安装**：点开 APK，系统提示「不允许安装未知来源应用」时，按提示允许文件管理器（或你用来打开它的应用）安装应用，装完可以把开关关回去。
4. **打开并授权**：安装完点「打开」，首次使用会申请照片与文件权限——必给，否则读不到相册。

## 三、装不上时的对号入座

| 现象 | 处理办法 |
| --- | --- |
| 提示「解析包出错」 | 安装包多半没下完整，重新下载并核对大小 |
| 安装中途失败 | 清一下存储空间，留足安装包 3 倍以上的空间再装 |
| 点开就闪退 | 先重启手机再试；仍闪退多为旧包兼容问题，换最新可用安装包覆盖安装 |
| 装好了但读不到照片 | 存储权限没给全：设置 → 应用 → codeformer → 权限，改成允许 |
