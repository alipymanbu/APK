# codeformer 手机应用与开源模型的区别

> 搜 codeformer 这个词时会同时撞见三样东西：安卓修图应用、开源人脸修复项目、网页在线演示。这篇讲清它们各是什么、分别适合谁，免得装错、用错。

## 一、同一个名字，三个东西

| | 手机应用 | 开源项目 | 在线演示 |
| --- | --- | --- | --- |
| 是什么 | 基于 CodeFormer 模型做的安卓修图工具 | 南洋理工大学 S-Lab 团队发布的原始研究（NeurIPS 2022） | 挂在网上的演示页面，传图即试 |
| 怎么用 | 装 APK 即用，中文界面 | 要配 Python 环境，参数靠命令行 | 打开网页就能用，结果限时保存 |
| 可调的东西 | 一根修复幅度滑块 + 常规编辑工具 | 保真度数值、背景增强、人脸放大、批量文件夹、视频逐帧 | 保真度数值滑杆、背景增强等开关 |
| 适合谁 | 想在手机上直接修相册照片的人 | 要批量处理、处理视频、精细调参的人 | 只想先试一两张效果的人 |

开源项目的源码在 github.com/sczhou/CodeFormer，手机应用正是基于同源思路做的移动端产品，但由第三方团队打包，两者不是一回事。

## 二、修复能力的共同逻辑

三种形态背后是同一套修复逻辑：把人脸恢复转化为代码序列的预测问题，对严重退化的照片（模糊、破损、噪点重）尤其有效。核心的可调参数是「保真度」：0 追求更好看，1 追求更像本人。手机应用把这根参数简化成了一根滑块，不显示数值，方向逻辑完全一致。

## 三、各自适合谁

- **手机应用**：相册里存着模糊老照片、拍糊的人像，想直接在手机上修好，不想折腾电脑环境。
- **开源项目**：要批量处理整个文件夹、处理视频，或者想把背景增强这类开关也调上；速度依赖显卡，没有 N 卡用 CPU 跑会非常慢。
- **在线演示**：只想先试一两张看看效果。处理完要尽快把结果下载下来，演示页的结果是限时保存的。

## 四、选定手机版之后

确定在手机上用，从 [codeformer 安卓版下载与介绍](https://codeformer.hfdk.space/) 进安装文件资源入口，装好以后的操作流程见[模糊照片人脸修复教程.md](模糊照片人脸修复教程.md)；安装被系统拦下时的处理办法写在[安卓版下载安装步骤.md](安卓版下载安装步骤.md)。
