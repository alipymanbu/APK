# 手机搜不到电脑怎么办

> reWASD 手机端搜索列表里找不到电脑、或连上又频繁掉线，几乎都出在网络环境和电脑端设置这两类原因上。本篇按出现概率从高到低列排查项，每条都能当场验证。
> **相关文章**：[手机当电脑手柄怎么弄.md](手机当电脑手柄怎么弄.md) · [陀螺仪体感瞄准怎么设置.md](陀螺仪体感瞄准怎么设置.md)

## 一、按概率排查清单

| 排查项 | 怎么验证 | 怎么处理 |
| --- | --- | --- |
| 电脑端共享没开 | 电脑端 Preferences → Servers，看 Enable sharing via local network 是否勾选 | 勾上后点 Apply（最常见原因） |
| 不在同一局域网 | 手机和电脑是否连同一台路由器；手机是否在用流量 | 两端连同一 Wi-Fi；电脑插网线也算 |
| 访客网络 AP 隔离 | 手机连的是不是访客 Wi-Fi；两台设备互相 ping 不通 | 关掉 AP 隔离或换主网络 |
| 防火墙拦截 | 电脑能上外网，但手机端列表为空 | 给 reWASD 放行 Windows 防火墙（见下节） |
| 网卡接口选错 | 电脑同时有有线 + 无线 + 虚拟网卡 | Servers 页把 Network interface 改成 ANY |
| VPN / 加速器干扰 | 电脑或手机正开着 VPN、游戏加速器 | 断开再试，虚拟网卡会干扰局域网发现 |
| 版本过旧 | 两端版本是否都比较老 | 都升到较新版本再试 |
| 偶发状态错乱 | 以上都对还是连不上 | 两端都重启：电脑端重开 reWASD，手机端杀掉应用重进 |

## 二、给 reWASD 放行 Windows 防火墙

手机端列表为空、网络又确认没问题，多数是防火墙拦掉了默认端口 `35474` 上的连接：

1. 打开「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」。
2. 点「更改设置」，在列表里找到 reWASD（没有就点「允许其他应用」手动添加）。
3. 「专用」和「公用」都勾上，确定保存后回手机端重新搜索。

## 三、连上了但频繁掉线

- **信号**：手机离路由器太远时，持续输入流最容易断，先缩短距离验证。
- **频段**：手机连路由器的 5GHz 频段。2.4GHz 和蓝牙、智能家居挤在同一片频率，卡的表现是一阵一阵「吞输入」式的尖峰。
- **电量**：手机电量过低时发射功率会下降，当手柄玩之前先充上电。
- **Transfer 参数**：把手机当手柄时，General settings 里的 Transfer 调低一档，能明显缓解高负载下的断连。
- **省电策略**：部分安卓机会冻结后台应用，把 reWASD 加入省电白名单、允许后台运行，锁屏就掉线多出在这里。

## 四、还不行就重置连接状态

两端的连接状态是记住的，改完设置有时旧状态会碍事：电脑端确认 PC 名称和端口没被改过，手机端回首页重新走一遍连接流程，别依赖上次记住的旧连接；再把电脑端完全退出重开一次。

排查完还连不上，最后剩下的可能就是两端版本兼容问题，都升级后再试。安装包从哪来、装完怎么配，见 [reWASD 手机端介绍站](https://rewasd.fewa.skin/) 下载页与首页的配对三步。
