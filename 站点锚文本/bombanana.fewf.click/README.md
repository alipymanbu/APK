# BOMBANANA! 三人拆弹简报站

这里是 [bombanana.fewf.click](https://bombanana.fewf.click/) 的配套资料目录。BOMBANANA! 是 Lefto Studio 开发、TARK 发行的三人在线合作拆弹游戏：盲猴动手、聋猴传话、哑猴比划，三个各缺一感的猴子要在倒计时归零前把信息一环环传对，才能拆掉炸弹。

站点里整理了角色分工、信息链、四类模块的打法要点、手势暗号约定清单，以及安卓版的下载安装步骤；本目录收录两篇展开说明：

- [三人合作拆弹玩法.md](三人合作拆弹玩法.md)——为什么恰好三个人、一条拆弹指令怎么流动；
- [手机版安装与联机.md](手机版安装与联机.md)——安卓包获取、安装排查与联机前提。

本目录为第三方整理的介绍资料，与开发及发行团队无隶属关系；安装文件资源的获取入口统一放在上述站点内。
