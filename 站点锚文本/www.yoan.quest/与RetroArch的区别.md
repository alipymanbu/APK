# 与RetroArch的区别

搜 Lemuroid 的人几乎都会顺带看到 RetroArch，然后陷入「到底装哪个」。两者其实是近亲——都建立在同一套 Libretro 模拟内核生态上，模拟能力同源；差别在于 Lemuroid 把常用的事做成了开箱即用，RetroArch 把可调的东西几乎全摆了出来。这篇把差别摊开讲，再按需求给结论。

## 一、一句话分清

- **Lemuroid**：自动扫描游戏、自动配好按键、界面只有常用项，免费、无广告、支持 Android TV，上手几乎零配置；
- **RetroArch**：同样免费，但设置项极多——画面着色器、输入延迟优化（Run-Ahead）、逐游戏换内核、联网对战等高级能力都在里面，代价是术语密集、上手成本高。

## 二、逐项对照

| 维度 | Lemuroid | RetroArch |
| --- | --- | --- |
| 上手难度 | 引导式，几乎零配置 | 术语多，要折腾一阵 |
| 游戏库 | 自动扫描、自动封面 | 需要自己整理播放列表 |
| 平台覆盖 | 23 类主机 | 数十种，更广 |
| 逐游戏换内核 | 不暴露该选项 | 支持 |
| 画面 / 性能微调 | 常用项为主 | 深度可调 |
| Android TV | 开箱即用 | 可用，配置较繁 |
| 存档 | 应用托管（saves/states 目录） | 同为目录托管，路径不同 |

表格里的「更广」「深度可调」是相对说法。就日常 8/16 位与 PSX、PSP 游戏而言，两者在同一台手机上的实际运行效果差别不大——毕竟内核同源，跑的是同一批模拟核心。

## 三、按需求选

- **只想把童年的几款游戏跑起来**：选 Lemuroid，从下载到开玩十分钟内走完；
- **要逐帧调画面、追低输入延迟、玩联网对战或冷门平台**：RetroArch 给得动这些空间；
- **手机 + 平板 / 电视换着玩**：Lemuroid 的云同步存档和 TV 支持对这种用法更省事；
- **已经用惯 RetroArch**：不必迁移，两边的游戏存档可以互相搬。

## 四、两个都装行不行

行。两个是不同的应用，包名不同、互不覆盖、也不冲突，同一台手机可以并存。常见的实际搭配：日常用 Lemuroid 图省事，偶尔需要某个高级功能时再开 RetroArch。

要注意的是**存档各自独立**：在 Lemuroid 里的进度不会自动出现在 RetroArch 里，需要手动搬。搬档前先在接收方关掉自动保存，避免旧档覆盖新档；存档目录的路径与备份方法，[Lemuroid 介绍站](https://www.yoan.quest/)的功能页有详细说明。还没装的用户，安装流程见[模拟器下载安装步骤](模拟器下载安装步骤.md)。
