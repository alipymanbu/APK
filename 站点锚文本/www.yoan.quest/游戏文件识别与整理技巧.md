# 游戏文件识别与整理技巧

Lemuroid 装好后列表空空、或者某个游戏死活扫不出来，是新手最常碰到的坎。原因几乎都能归结到「文件不符合识别规则」——它扫描时会拿文件和内置数据库对照（CRC 校验、序列号、文件名都参与匹配），对不上又没有归类线索的文件会被直接无视。这篇按见效程度把整理和排查方法排好序。

## 一、第一招：按主机建文件夹

把游戏放进以主机命名的文件夹（一个文件夹一类主机），再让 Lemuroid 扫描这些目录。常用文件夹名（小写）与主机的对应关系：

| 文件夹名 | 主机 |
| --- | --- |
| `nes` | 红白机 |
| `snes` | 超级任天堂 |
| `gb` / `gbc` / `gba` | Game Boy / Color / Advance |
| `n64` | Nintendo 64 |
| `psx` | PlayStation |
| `psp` | PSP |
| `sms` / `genesis` / `gg` | 世嘉 Master System / Mega Drive / Game Gear |
| `atari2600` | 雅达利 2600 |
| `fbneo` | 街机（FinalBurn Neo） |

放在这类文件夹**直接子层**的文件，即使数据库查不到，只要扩展名属于该主机也会被归进去。这一步做完，绝大多数「扫不出来」就解决了。

## 二、压缩包的规矩

- 只认 **zip**，且**一个包里只能有一个游戏文件**；rar、7z 一律不认；
- 一个 zip 里塞了多个文件会被整个跳过；
- 最稳的做法：不压缩，直接放原始文件。

## 三、文件名别乱改

扫描靠文件名、CRC 与数据库对照。`游戏123.bin` 这种面目全非的名字既对不上数据库、又没在主机文件夹里，基本必被无视。尽量保持下载时的原始文件名。

## 四、三个特例

1. **FBNeo 街机只认非整合（non-merged）romset**，且 CRC 必须与数据库一致——这是街机游戏扫不出来的头号原因；
2. **PSX 多碟游戏**要配 `.m3u` 播放列表：新建文本文件改扩展名为 `.m3u`，每行写一个碟的 `.cue` 文件名，和碟文件放同一目录，扫描时认这个 m3u；
3. **Sega CD 需要额外的 BIOS 固件文件**才能运行，其余主机基本放好即玩。

## 五、逐条排查清单

按顺序过，命中哪条改哪条：

1. 存储权限给过吗？（首次启动拒绝过就一个游戏都扫不到，去系统设置补）
2. 扫描指定的目录对吗？文件真的在那里？
3. 是不是 rar/7z？解压再试；
4. zip 里是不是不止一个文件？拆开再试；
5. 文件名改得面目全非？改回原名再试；
6. 没按主机分文件夹？按第一节归类再扫；
7. 以上全对还认不出？把应用更新到新版本再试——内核与数据库的更新常会修好识别不准的老游戏。

游戏都认出来之后，建议先弄清存档放在哪再开玩，免得换机时丢档。主机性能预期与手柄、电视玩法，可以在 [Lemuroid 介绍站](https://www.yoan.quest/)里找到对应章节；安装环节的问题看[模拟器下载安装步骤](模拟器下载安装步骤.md)。
