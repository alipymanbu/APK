# 降水雷达颜色怎么看

打开天气应用的雷达地图，最先让人犯迷糊的就是那堆彩色斑块：青色、蓝色、紫色、橙色各代表多大雨？动画时间轴上的 1h、3h、24h 又分别该在什么时候用？这篇按"认色、看轴、定行程"三步讲清楚。

## 第一步：认色标

雷达图例基本遵循一套从冷到暖的强度分级，以常见的分级为例：

| 颜色 | 强度 | 直观感受 |
| --- | --- | --- |
| 青 | 毛毛雨 / 小雨 | 地面刚湿，不必带伞 |
| 蓝 | 小到中雨 | 淋一会就难受 |
| 紫 | 大雨 | 伞基本挡不住 |
| 橙 | 特大降水 | 路面汇水，别出门 |
| 黄 | 冰雹等级 | 最强级别，注意预警 |

规律很简单：**颜色越暖，雨越猛**。看雷达时先扫一眼有没有橙、黄色斑块，有的话直接改行程。

## 第二步：看时间轴

雷达动画的价值在于"推移"：

- **1h / 3h**：出门前用。看当前雨带边缘离你还有多远，判断半小时内会不会被压到。
- **6h / 12h**：安排下午活动用。看雨带是发展还是消散。
- **24h**：回看整天，判断这次降水是系统性大范围降雨，还是局地对流——前者要改全天计划，后者等两小时就行。

把动画从头到尾播完，雨带的来去方向一目了然，这比任何百分比概率都直观。

## 第三步：和别的图层叠着用

雷达管"现在和最近几小时"，管不到未来两周。定长途行程时，先用趋势图表挑窗口（读法见 [meteogram气象图怎么读](meteogram气象图怎么读.md)），出发当天再用雷达做最后确认，两层叠起来才完整。
