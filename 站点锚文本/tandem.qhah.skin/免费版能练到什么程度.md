# 免费版能练到什么程度

> 结论先说：找语伴、文字语音聊天、让对方改错这条主路径，免费版完全走得通；次数上限集中在翻译、新对话这类辅助功能上。本篇把两边每天的差距摆出来，帮你判断要不要升级。

## 免费版每天的真实配额

注册通过审核后，免费账号能用的核心功能没有缩水：

- **找人**：社区列表按语言组合推荐，筛选器按语言、等级、地区收窄，都能用。
- **聊天**：文字消息、语音消息、图片随便发；对方帮你改错（红色划掉原句、给出修正）这个核心交互也是免费的。
- **翻译**：每天 3 次，用来读懂卡壳的那条消息够用，但别指望全程靠它对话。
- **新对话**：每天能主动发起 10 个，已建立的对话不受限，想聊多长聊多长。

换句话说，"每天固定跟一两个语伴深聊"这个最常见的学习方式，免费版没有任何障碍。

## 升级 Pro 换来的是什么

Pro 按 1 / 3 / 12 个月订阅（价格以应用商店按地区显示为准），主要把上限拆掉、把进阶工具打开：

| 每天能用什么 | 免费版 | Pro |
| --- | --- | --- |
| 消息翻译 | 3 次 | 无限 |
| 主动发起新对话 | 10 个 | 30 个 |
| 语音消息转文字 | 无 | 无限转写 |
| 音视频通话 | 无 | 解锁 |
| 按附近 / 地图找语伴 | 无 | 支持 |
| 查看主页访客与在线成员 | 无 | 可看 |
| 保存生词与表达 | 每日上限 | 无限收藏 |
| 同时学的语言数 | 1 门 | 最多 10 门 |
| 广告 | 有 | 无 |

其中「按地图找语伴」值得单独说：出行前把地图钉在目的地城市，先认识当地的人，是很多用户订阅的实际理由——这已经从练口语延伸到交朋友了。

## 怎么决定升不升

给一个务实的顺序：先用免费版把审核、筛选、改错这条路径完整跑一遍，确认自己真的会每天打开聊天窗，再考虑升级。如果发现瓶颈恰恰是"翻译次数不够用"或"想跟语伴打语音电话"，那 Pro 花得值；如果连免费额度都用不完，就没必要先掏钱。

两条路径各自长什么样，可以参考 [Tandem 免费版与 Pro 的边界对照](https://tandem.qhah.skin/)，那里按"每天能用什么"逐项列了差距。

还在等审核结果的，先看 [注册审核被拒的常见原因.md](注册审核被拒的常见原因.md) 排查资料问题；已进社区打算开口的，直接跳 [第一次找语伴怎么开口.md](第一次找语伴怎么开口.md)。
