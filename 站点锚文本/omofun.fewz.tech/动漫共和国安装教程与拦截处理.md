# 动漫共和国安装教程与拦截处理

## 装之前知道两件事

其一，安装文件是 apk 格式，安卓手机直接装；iOS 端走签名安装，不上架 App Store，签名有有效期，介意折腾的话留在安卓上用最省心。

其二，安装文件的获取入口、图文步骤都在这个 [OmoFun 安装说明页](https://omofun.fewz.tech/download.html)里，按钮点开就是网盘分享，下面的文字步骤和它一一对应。

## 四步装完

1. **转存**：打开网盘分享页，登录自己的网盘账号，把安装文件转存进自己账号——文件进了自己网盘，之后随时能重新下载，不依赖原分享的状态；
2. **放行未知来源**：进入「设置 → 应用 → 特殊访问权限 → 安装未知应用」，对你用来打开安装包的那个应用（浏览器或文件管理器）打开允许开关；
3. **安装**：在「文件管理 → Download」里点开 apk，确认安装，等进度走完；
4. **开权限**：首次启动允许存储、网络权限——离线缓存依赖存储权限，不给全后面缓存会一直失败。

各品牌菜单叫法不一样，华为、小米、OPPO、vivo 在设置里直接搜「未知来源」或「安装未知」最快。

## 两个最常见的坎

**安装到一半被系统拦下**：基本是第二步没对上。安卓 8.0 起「未知来源」改成按应用授权，要放行的是「打开安装包的那个应用」，不是应用本身。回到设置确认开关已开，再重新点安装包继续。

**装完打不开或缓存失败**：先查存储权限——长按应用图标进「应用信息 → 权限」，把存储设为允许。还不行就重启一次手机再试；安装文件一直躺在自己网盘里，重装也不用重新找资源。

装好之后先别急着注册，不登录也能搜索、看番、加本地收藏。日常播放里的弹幕、倍速、换线路这些操作，看这篇：[弹幕倍速换源与离线缓存用法](弹幕倍速换源与离线缓存用法.md)。
