# Blurrr.fwen.ren：Blurrr 剪辑工具介绍与安装指引

> 本目录围绕视频剪辑工具 Blurrr 整理中文介绍：它把关键帧曲线、图层混排与四百余款特效装进手机，常被二创圈拿来做 Mad、动漫与游戏剪辑。完整盘点见 [Blurrr 介绍站](https://blurrr.fwen.ren/)。

## 这个目录里有什么

- [关键帧曲线怎么用.md](关键帧曲线怎么用.md) —— 哪些参数能打点、缓动曲线怎么选、预设之外怎么手画；
- [特效与粒子怎么加.md](特效与粒子怎么加.md) —— 特效分类、滤镜定调、3D 粒子铺氛围的思路；
- [安卓安装包怎么获取.md](安卓安装包怎么获取.md) —— 获取安装文件资源、放开安装权限与常见卡点处理。

## 怎么用这个目录

第一次接触建议从安装篇读起，装好后按「关键帧 → 特效」的顺序过一遍功能篇；每篇末尾的互链可以按需跳转。工具能力随版本更新变化，涉及具体参数以运行时的实际界面为准。
