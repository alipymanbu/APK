# 不写代码把网站变成手机应用的方法

> 你已经有一个能正常打开的网站（或者一个 Vue / React 项目编译出的 dist 目录），想让它以独立 App 的样子出现在手机桌面上，又不想从零学安卓开发——本篇讲这条零代码路径怎么走，中间有哪些要提前想清楚的事。
> **相关文档**：[网页打包成安卓应用要装什么环境.md](网页打包成安卓应用要装什么环境.md) · [云端打包和本地打包怎么选.md](云端打包和本地打包怎么选.md)

---

## 一、思路：不重写，只包一层壳

把网站变成 App，不是把网页代码翻译成安卓代码，而是给现有页面套一个能独立安装的客户端壳。页面还是原来那个页面，改版也照常改网站即可；壳负责的是图标、独立窗口、全屏体验这些"像一个正经 App"的部分。

这条思路在圈子里常被叫做"网页打包"，做这件事的工具不少，思路大同小异：填入网址（或静态文件目录），工具负责产出安装包。本文以开源打包工具 PakePlus 为例展开，它的完整介绍在 [PakePlus 介绍站](https://pakeplus.yoan.quest/) 上有整理。

## 二、动手前的三样准备

1. **一个能访问的网址**。这就是打包的原料；如果做的是 Vue / React 项目，就准备好编译后的 dist 目录。
2. **想好应用叫什么名字**。支持中文应用名，起名时按"手机桌面上想显示什么"来定。
3. **想好打给谁用**。给自己日常用、给内网同事用、还是发给网站访客，会影响后面选哪条打包路线。

## 三、流程长什么样

以手机端操作为例，整个过程大致是：

1. 打开打包工具，新建一个项目；
2. 填入网址（或选择本地 dist 目录），起好名字；
3. 等待编译，参考用时以分钟计；
4. 拿到 APK，装进手机，桌面上出现独立图标。

整条流程不需要写一行代码，也不需要碰安卓开发工具。选哪条路线（云端还是本地）编译，见 [云端打包和本地打包怎么选.md](云端打包和本地打包怎么选.md)。

## 四、几个常见的疑问

- **打包之后网站还能改吗？** 能。壳里加载的就是你的网页，网站照常更新，App 下次打开就是新内容。
- **打出来的包有多大？** 这类方式的卖点就是轻——以 PakePlus 公开文档的口径，产物安装包小于 5M，比 Electron 包小约 20 倍。数字细节可看 [网页打包成安卓应用要装什么环境.md](网页打包成安卓应用要装什么环境.md) 里整理的部分。
- **iOS 也能出包吗？** 桌面三系统与安卓、iOS 都在支持列表里，但各端安装包相互独立，一份配置不等于一份包到处能用。

## 五、走之前要接受的边界

打包工具不做软件签名，打出来的安装包按项目说明仅限自己使用，别拿它冒充正经上架应用，也不要拿去分发别人的付费内容。把用途框在"自己装、自己用、发给特定的人用"，这条路会很顺。
