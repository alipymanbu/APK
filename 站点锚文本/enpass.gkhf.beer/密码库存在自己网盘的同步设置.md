# 密码库存在自己网盘的同步设置思路

本篇讲 Enpass 这类本地自持密码工具的同步玩法：密码库其实就是一个加密文件，把它放进你已经有的网盘账号，多台设备就能自然接力——不需要为工具本身再注册一个账户。

## 原理：一个加密文件的旅行

用主密码派生的钥匙加密之后，整个密码库就是一份文件。手机上改了一条记录 → 文件内容变化 → 网盘把新版本推到你其他设备 → 那边读到新版本。全程传的都是密文，网盘服务商看到的只是"一个文件变了"。

## 支持哪些存放位置

常见的几类都覆盖：iCloud、Google Drive、OneDrive、Dropbox、Box、NextCloud，以及更通用的 WebDAV。不想折腾云端的，还有两条替代路：

- **纯本机**：什么都不配，库就待在设备里，适合只用一台设备的人；
- **局域网直连**：手机与电脑在同一 Wi-Fi 下互相发现、直接同步，数据不出内网。

## 配置时的四个注意点

1. **所有设备指向同一个库文件**——同步出错最常见的原因就是"两份库各改各的"；
2. **网盘的"按需下载/占位文件"功能**建议对库文件关闭，避免离线时读不到；
3. **换机场景**：新设备先配好网盘、找到库文件再登录，顺序反了容易新建出空库；
4. **定期导出备份**放在库之外的位置，防的是误删与网盘账号出问题这两种小概率事件。

## 主密码没有找回，务必记牢

数据完全自持意味着服务商帮不了你：主密码遗忘没有重置后门。设置时建议同时抄一份纸质备忘收进抽屉，这是这类工具最被反复提醒的一条。
