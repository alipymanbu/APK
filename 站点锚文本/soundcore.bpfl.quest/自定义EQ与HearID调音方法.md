# 自定义EQ与HearID调音方法

> 同一副耳机，有人觉得低音闷、有人觉得人声远——差别大多不在耳机，在调音。这篇把 soundcore 应用里的两条调音路线讲清楚：一条是省事的 HearID 听感测试，一条是自己动手的全频段 EQ。
> **相关阅读**：[耳机连不上手机的排查思路](耳机连不上手机的排查思路.md) · [降噪模式切换与场景选择](降噪模式切换与场景选择.md)

## 一、先试试 HearID：让应用替你调

HearID 的思路是先测后调：应用播放一组测试音，根据你的听感反馈与音乐偏好生成一条专属曲线。测完之后，这条曲线就是这台设备在这个应用里的默认调音，切换歌单时不用再手动改。

入口一般在设备页的音效区域，按提示做完几分钟的听感测试即可。每个人的听阈不同，同一副耳机测出来的曲线也不一样——这正是它比预设更贴耳的原因。

## 二、预设 EQ：快档选择

不想做测试的话，预设也能应付大多数场景。应用里常见的几组：

| 预设 | 听感取向 |
| --- | --- |
| soundcore Signature | 标准均衡调音 |
| Voice | 人声更突出，适合播客与通话回放 |
| Balance | 高低频均不增强，忠实还原 |
| Treble Boost | 增强高频，弦乐与齿音更亮 |
| BassUp | 实时低频增强，电音与摇滚更带感 |

应用商店页提到的口径是 22 组预设音效，不同机型能看到的组合略有差异。

## 三、自定义 EQ：逐频段动手

想精确控制就进自定义模式：**Equalizer → Custom → Full-Band**，点任意频点展开对应频段，长按拖动调整。几个实用建议：

- 人声发闷，把 1kHz~3kHz 段抬一点；
- 低音浑浊，收 100Hz 以下；
- 觉得刺耳，压 3kHz~6kHz。

改完的曲线自动记录在该设备名下。注意一点：未登录账号时这些配置不随账号保存，换手机或卸载重装就没了，需要跨机保留就先登录。

## 四、两个容易踩的坑

1. **EQ 只影响媒体播放**，不改变通话音质。打电话觉得声音差，去调 EQ 是没用的，问题多半在通话降噪或网络。
2. **LDAC 与 EQ 是两条线**。支持 LDAC 的机型想要更高音质，路径是 设置 → 声音模式 → 音质优先，需要 Android 8.0 以上，iOS 端不支持。

## 五、调音之外

调音只是应用功能的一角。设备连接不顺先看[耳机连不上手机的排查思路](耳机连不上手机的排查思路.md)；想按地铁、街道、办公室这些场景切换降噪档位，看[降噪模式切换与场景选择](降噪模式切换与场景选择.md)。

应用的获取入口与安装步骤，见 [soundcore 介绍站](https://soundcore.bpfl.quest/)。
