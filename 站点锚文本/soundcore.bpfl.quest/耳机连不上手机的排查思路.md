# 耳机连不上手机的排查思路

> soundcore 耳机第一次连手机时容易卡住：蓝牙里搜不到、应用里扫不到、连上又掉。这篇文章把常见的几种情况按顺序拆开讲，多数卡点其实是位置权限和配对顺序这两件小事。
> **相关阅读**：[自定义EQ与HearID调音方法](自定义EQ与HearID调音方法.md) · [降噪模式切换与场景选择](降噪模式切换与场景选择.md)

## 一、先分清两个环节

很多人把「蓝牙配对」和「应用添加」混在一起，其实它们是两步：

1. **系统蓝牙配对**：在手机的蓝牙设置里找到耳机并连上，这一步与 App 无关；
2. **应用内添加设备**：打开 soundcore 应用，点 Add Device，让设备出现在「我的设备」里。

顺序反了（先开应用再配对）经常表现为「应用扫不到任何设备」。正确做法是先把耳机与手机在系统蓝牙里连上，再进应用添加。

## 二、位置权限不是可选项

安卓 6.0 及以上系统，扫描蓝牙设备需要定位服务配合。首次打开应用时如果拒绝了位置权限，扫描列表永远是空的——这不是故障，是平台机制。

处理方式：系统设置 → 应用管理 → soundcore → 权限 → 允许位置权限。给「仅在使用中允许」就够了，不用给「始终允许」。iOS 端在 设置 → 隐私与安全性 里同样有这个开关。

## 三、扫到了但连不上

按这几条从上往下试，多数在第三条就解决：

| 顺序 | 动作 | 说明 |
| --- | --- | --- |
| 1 | 断开手机上其他蓝牙设备 | 手机正忙着连别的耳机音箱时，扫描容易失败 |
| 2 | 确认应用是可用版本 | 版本太旧可能不带新机型的设备信息 |
| 3 | 走手动添加 | Add Device → Set Up Manually，按系列 → 型号逐级选 |
| 4 | 检查双连接占用 | 另一台手机的后台应用占着设备时，这台就连不上；把它彻底关掉再试 |
| 5 | 重启设备再试 | 用来区分是设备问题还是手机问题 |

还有两个容易忽略的场景：手机正在通话时应用可能连不上，先挂断再试；系统区域设置会影响设备列表能否显示，连不上时切换一下区域语言有时有效。

## 四、手动添加里也找不到型号

较新的机型需要较新的应用版本才能识别；如果手动设置页面里翻遍系列也找不到自己的型号，把这个页面截图，连同手机型号与应用版本一起发给品牌客服核对，比反复重试更省时间。

## 五、连上之后的下一步

设备出现在「我的设备」里只是开始，调音、降噪、固件这些功能入口都在设备页里。想了解怎么把声音调成自己喜欢的样子，看[自定义EQ与HearID调音方法](自定义EQ与HearID调音方法.md)；想按场景切换降噪档位，看[降噪模式切换与场景选择](降噪模式切换与场景选择.md)。

关于应用本身的安装与配置要点，[soundcore 介绍站](https://soundcore.bpfl.quest/)整理得更系统一些。
