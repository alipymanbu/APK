# 从浏览器导出密码并导入新库：换密码管理器不手抄

> 决定换密码管理器后，最劝退的一步是几百条账号怎么办。其实不用一条条抄：先把旧工具导出成 CSV，再用桌面版一次性导入。本篇以 SafeInCloud 为例，讲导出入口、导入位置和搬完后的收尾。

---

## 一、先在旧工具里导出 CSV

常见来源的导出入口：

| 旧工具 | 导出位置 |
| --- | --- |
| Chrome / Edge（电脑版） | 地址栏进密码管理器设置，找「导出密码」，验证电脑开机密码后存为 CSV |
| Firefox | 设置 → 隐私与安全 → 已保存的登录信息 → 导出登录信息 |
| LastPass | 网页保险库 → 高级选项 → 导出（会发确认邮件） |
| 1Password / Bitwarden / Dashlane / KeePass | 各自的网页版或桌面版设置里有导出条目，选 CSV 格式 |

各家界面随版本变化，找不到入口就以对应工具的帮助页为准。导出时要输入一次原工具的主密码或电脑密码，这是正常验证。

## 二、在哪一步导入 SafeInCloud

导入主力是**桌面版**（Windows / mac，免费）：

1. 电脑上装好并打开桌面应用。
2. 用导入功能选择来源——它支持自动从 Chrome、Edge、Firefox、LastPass、1Password、Bitwarden、Dashlane、KeePass 等几十种工具读数据（以应用内实际列表为准），也可以直接选中你刚导出的 CSV。
3. 等导入完成。

为什么优先桌面版而不是手机：电脑上核对、改错、批量整理都方便。导完再配上云同步，手机端就能直接拿到全部数据，不用在手机上再导一次。

## 三、导入后核对三件事

1. **条数**：旧工具里的条目数和导入后的大致对得上（同名去重后可能略少）。
2. **抽查**：挑两三个不常用的账号手动登录一次，确认账号密码没有变形（特殊字符、首尾空格最容易出问题）。
3. **字段**：自动填充靠「用户名 / 密码 / 网址」三个字段起作用——导入条目如果网址字段是空的，填充不会弹，补上即可。

## 四、收尾：把 CSV 删干净

CSV 是**明文**文件——所有账号密码裸写在里面。搬完家做三件事：

1. 立刻删除电脑里的 CSV，回收站也清掉。
2. 导出时用过 U 盘或聊天工具中转的，把中转副本一并删除。
3. 旧工具不再用了的话，从浏览器里移除已保存的密码，避免两处存密码、日后不知道哪份是新的。

搬完之后，新增密码都记进新库，旧的密码管理器就可以卸载了。SafeInCloud 的存储模型与获取指引见[这里](https://safeincloud.gltd.quest/)的介绍页。
