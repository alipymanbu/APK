# 密码库云同步与换机恢复：SafeInCloud 的「存自己云盘」方案

> 换新手机、新电脑时，密码库怎么完整跟过去？SafeInCloud 的答案是：数据库加密后放进你自己的云盘账号，新设备连同一朵云就能整体接回来。本篇讲支持哪些云、手机和电脑分别在哪开启、换机三步走。

---

## 一、先弄清数据存在哪

SafeInCloud 的同步模型和很多密码管理器不一样：**数据库文件存在你自己的云账号里**，开发者服务器上没有你的密码。手机上改一条记录，应用把加密后的数据库推到云盘，其他设备从同一朵云拉下来解密。

两个实际后果：

- 你的云账号就是你的备份。手机丢了，只要记得主密码，任何新设备都能完整恢复。
- 云账号被盗也读不出密码——数据库用主密码加密，云服务商拿到的只是密文。代价是主密码忘不了。

## 二、支持哪些云

| 云服务 | 说明 |
| --- | --- |
| Google Drive | 安卓手机上最省事，登录 Google 账号即可 |
| Dropbox | 各平台都能用 |
| OneDrive | Windows 用户顺手 |
| iCloud | iPhone 端可走系统 iCloud |
| WebDAV（「其他云」） | 任何支持 WebDAV 的云都能接，包括群晖等 NAS |

选哪个的原则：**选你已经登录、其他设备也能访问的那个**。所有设备必须指向同一朵云，数据才会互通。

## 三、手机端怎么开

两条路任选：

- **横幅入口**：还没配过云同步时，主界面顶部有一条横幅，点它跟着向导走。
- **菜单入口**：进「工具 → 设置 → 数据库」，选主数据库，点「配置云」，选云服务、登录账号。

想用 NAS 就选「其他云」，填 WebDAV 地址和账号密码，填之前先在 NAS 端把 WebDAV 服务打开。配好后不用再管——改动会在几秒内自动推到云里。

## 四、电脑端怎么开

Windows 或 mac 版里走「选项 → 数据库 → 操作 → 配置云」，登录与手机相同的云账号即可。两边连同一朵云，就会自动合到同一个数据库上。

## 五、换新设备三步走

1. 新设备上安装应用。
2. 首次启动时选「**连接已有的云数据库**」，登录同一朵云的同一账号。
3. 输入主密码，整个库原样落回新设备。

不需要导出导入文件，也不需要旧设备在场。这也是为什么装机建议里总把「配云同步」放在第一位——它是唯一的灾备手段。

## 六、家人共用一个密码库

不用买家庭授权也有办法：注册一个**专用的**云账号（别用任何人的私人邮箱），把要共享的密码放进一个数据库、云配置到这个账号，每个成员的设备都连它。注意免费版 Dropbox 单账号最多连 3 台设备；Google Drive 和 OneDrive 的免费空间对一个小小的数据库文件绰绰有余。

## 七、容易疑惑的点

- **两台设备同时改会怎样**：按改动时间同步，一般不用干预；出问题看应用里的同步日志。
- **云盘里那个文件能删吗**：不能，那是加密的数据库本体，删了等于删备份。
- **换云服务怎么办**：新云上重新配置一次同步；动手前把旧云里的数据完整保留。
