# Nebula 图标包 · 站点锚文本

这个目录收录与 Nebula 图标包相关的两篇文章。Nebula 是一套面向安卓桌面的手绘矢量图标包：5460+ 枚图标按 192×192px 绘制，附带 20 张设计师壁纸，需要配合支持图标包的自定义桌面使用。两篇文章分别回答「怎么把图标主题套用到桌面」和「装完桌面没变化怎么排查」两个最常见的搜索需求，换装路径与桌面兼容清单见 [Nebula 图标包](https://nebula.xnyx.quest/)。
