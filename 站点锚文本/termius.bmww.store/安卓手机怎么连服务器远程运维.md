# 安卓手机怎么连服务器？用 Termius 把运维装进口袋

> 本篇从零走一遍手机远程运维的路：备齐连接信息、把服务器登记进 Termius、连上去确认指纹、在触屏上把命令敲利索。密钥免密登录单独放在[SSH 密钥免密登录与 SFTP 传文件](SSH密钥免密登录与SFTP传文件.md)里讲。

## 一、连接前备齐四样信息

无论用什么客户端，SSH 连接都需要这几样，先在服务器提供商的后台确认好：

| 信息 | 说明 | 常见值 |
| --- | --- | --- |
| 地址（Address） | 服务器的 IP 或域名 | `123.45.67.89`、`vps.example.com` |
| 端口（Port） | SSH 服务监听的端口 | 默认 `22`，有些商家改过 |
| 用户名（Username） | 登录账号 | 云主机常是 `root` |
| 认证方式 | 密码，或 SSH 密钥 | 密钥更省心，见文末相关文档 |

## 二、把服务器登记成主机

1. 打开 Termius，进 **Hosts** 页，点 **+** 新增主机；
2. 填备注名（Label）、地址、端口、用户名；认证选 Password 就填密码，选 Key 则先去 Keychain 建好密钥再回来选；
3. 保存后主机出现在列表里。服务器多就按用途分组（Group），「生产」「测试」各归各，列表长了也好找。

应用没要求登录账号——单机使用跳过登录引导即可，主机和密钥都存在本机；想在手机和电脑之间同步才需要账号与订阅档。

## 三、连上去并确认主机指纹

1. 在 Hosts 里点一下主机条目，开始连接；
2. 第一次连接会弹出主机指纹（host key fingerprint）让确认——这是服务器出示的身份凭证，确认后记进已知主机，下次不再问。在意安全可以先在服务器上执行 `ssh-keygen -l -f /etc/ssh/ssh_host_ed25519_key.pub` 比对再确认；
3. 出现 `root@vps:~#` 这样的提示符就是连上了。

指纹对不上会报「host key changed」并拒绝连接，多半是服务器重装系统导致，在已知主机里删掉旧记录、确认新指纹即可。

## 四、触屏上把命令敲利索

手机没实体键盘，Termius 的补偿手段都在终端界面里：

- **快捷键条**：终端下方一排常用键（Esc、Tab、方向、Ctrl、`-`、`/`），可换成最常用的组合；
- **手势**：长按屏幕拖动即发送方向键，按住空格拖动只移光标，越拖越快；
- **双指捏合**调字号，长按选择文字复制粘贴；
- **长命令**：存成 Snippet 片段，点一下整条发送（`df -h`、`systemctl restart nginx` 这类）；
- **蓝牙键盘**：连上即用，Esc / Ctrl / Tab 都正常，体验接近电脑。

## 五、两个让它更顶用的进阶项

- **启动命令**：主机编辑页里加一条 `tmux attach -t work || tmux new -s work`，一连上就进 tmux 会话——手机断线、锁屏都不影响服务器上跑的任务，重连原样恢复；
- **Mosh**：地铁、基站切换这种网络频繁变动的环境，普通 SSH 会频繁掉线；服务器装好 mosh 包后在主机详情里启用，会话跟着网络切换自动续上。

## 六、装一个先试起来

还没装的，可以从 [Termius 安卓终端介绍站](https://termius.bmww.store/)了解功能清单和安装步骤，装好照着第二节的步骤把服务器加进来。连不上时先分清断在哪一段：超时查防火墙与安全组、被拒绝查端口与服务、认证失败查密码与密钥，一台台排除比瞎猜快。
