# 手机管理群晖 NAS 与树莓派：家用设备的远程打开方式

> 本篇讲两类最常见的家用 SSH 设备——群晖 NAS 和树莓派——怎么先在设备端把 SSH 打开、再用手机上的 Termius 连上去管理。设备的型号与系统版本不同，菜单名可能略有出入，以实际界面为准。
> **相关文档**：[安卓手机怎么连服务器远程运维.md](安卓手机怎么连服务器远程运维.md) · [SSH密钥免密登录与SFTP传文件.md](SSH密钥免密登录与SFTP传文件.md)

---

## 一、共同的前置：设备端先开 SSH

家用设备和云服务器不一样：**很多设备出厂默认关闭 SSH**，手机这边配置得再对也连不上。流程永远是「先在设备端开启 SSH 服务 → 再回 Termius 添加主机」。连不上时第一件事就是回头确认设备端服务状态。

## 二、连接群晖 NAS

### 设备端：在 DSM 里开启 SSH

以 DSM 7 为例：

1. 用管理员账号登录 DSM 网页界面；
2. 打开 **控制面板 → 终端机和 SNMP → 终端机**；
3. 勾选 **启用 SSH 功能**，端口默认 `22`，点应用。改过端口的话，Termius 主机里的 Port 也要跟着改。

### 三条硬规则

- **不是所有账号都能 SSH 登录**：DSM 只允许属于 administrators（本地管理员）群组的账户登录，普通共享账号连不上是正常现象；
- **默认没有 root 直登**：先用管理员账号连上，再执行 `sudo -i` 切换；
- **密码不能为空**：空密码账户一律拒绝。

### 一个容易踩的坑

在 DSM「高级设置」里把 SSH 加密算法安全等级调到最高后，部分客户端会因算法不兼容而握手失败。手机上连群晖报握手类错误时，先把安全等级调回默认再试。

### 传文件顺带解决

群晖的 SFTP 在 **控制面板 → 文件服务 → FTP** 里启用（端口同为 22），开启后就能用 Termius 的双栏界面直接浏览共享文件夹，用法见[SSH密钥免密登录与SFTP传文件](SSH密钥免密登录与SFTP传文件.md)的 SFTP 一节。

## 三、连接树莓派

### 第一步：把 SSH 打开

官方系统的 SSH 默认关闭，按手头条件选一种：

- **有屏幕键盘**：桌面菜单 → Raspberry Pi 配置 → 接口 → 启用 SSH；或执行 `sudo raspi-config` 在 Interface Options 里启用；
- **纯命令行**：`sudo systemctl enable ssh` 后 `sudo systemctl start ssh`；
- **无屏无键盘（最常见）**：把烧好系统的 SD 卡插回电脑，在 boot 分区根目录新建一个名为 `ssh` 的**空文件**（全小写、无扩展名），插回树上电，首次启动检测到该文件就自动开启并删除它。

### 第二步：找到它的 IP

- 手机和树莓派连**同一个局域网**，这是一切的前提；
- 路由器管理页设备列表里找 `raspberrypi`；或在任何能跑命令的设备上 `ping raspberrypi.local`（新版系统自带 mDNS）；
- 接了屏幕的话直接执行 `hostname -I`。

### 第三步：账号密码

旧版系统默认 `pi` / `raspberry`（官方早已建议首登改密）；新版 Raspberry Pi OS 已取消默认账户，刷系统时要用官方 Imager 预先设置用户名密码，没设进不了系统。连上后第一件事改成自己的强密码——家用设备暴露在内网被扫的情况并不少。

## 四、连上之后玩什么

- **免密登录**：给 NAS 或树莓派部署公钥的流程和普通服务器完全一样，见[SSH密钥免密登录与SFTP传文件](SSH密钥免密登录与SFTP传文件.md)；
- **传文件**：往 NAS 的共享目录丢片子、从树莓派拉日志，SFTP 双栏直接拖；
- **看内网页面**：树莓派上 Home Assistant 的 `8123`、下载工具的 WebUI，都能按 Local 端口转发映射到手机浏览器；
- **长任务挂着跑**：套在 tmux 里，手机锁屏也不影响。
