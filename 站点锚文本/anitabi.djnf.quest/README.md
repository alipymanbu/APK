# anitabi.djnf.quest 站点说明

这是一个面向动画圣地巡礼爱好者的第三方介绍站，介绍对象是动画巡礼地图工具 anitabi：它把动画、漫画、游戏、小说里的场景坐标标进真实地图，每个点位配着巡礼人贡献的原作截图。站点整理了它的找点方法、网页版与手机 App 的分工、安装文件资源的获取入口，以及现场巡礼的实操建议。

- 站点入口：[anitabi 动画巡礼地图介绍站](https://anitabi.djnf.quest/)
- 本目录其余几篇围绕真实使用需求展开：怎么找取景地、到现场怎么对截图、这份数据从哪来。
