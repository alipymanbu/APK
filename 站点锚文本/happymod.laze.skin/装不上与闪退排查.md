# 装不上与闪退排查

> 按现象分四类：装不上、被安全组件拦、下载卡住、打开闪退。每类给可执行的排查顺序。
> **相关文档**：[下载安装全流程.md](下载安装全流程.md) · [条目怎么挑才靠谱.md](条目怎么挑才靠谱.md)

## 一、点开提示「未安装」或「解析包出现问题」

按出现频率逐条试：

1. **文件不完整**：下载中断是最常见原因。核对文件管理器里的体积是否与说明的 17.39M 一致，不一致就删掉重新下载。
2. **系统版本过低**：安装包要求安卓 5.2 以上，低于它系统会直接拒绝。查看路径：设置 → 关于手机 → Android 版本。
3. **旧版本冲突**：手机里残留签名不同的旧版会装不进去。先卸载旧的（设置 → 应用 → HappyMod → 卸载），重启后再装。
4. **空间不足**：部分机型空间紧张时只提示「未安装」，清出 100M 以上再试。

## 二、被 Play Protect 或杀毒应用拦下

侧载安装的商店类应用常被按「来源」标记风险，这与文件本身好坏是两回事。处理顺序：先核对下载体积与版本说明无误 → 弹出扫描提示时选「仍要安装」→ 第三方杀毒应用拦截时在其隔离区选择信任后重装。反复被实时防护删除的，把安装目录加入白名单——放行与否由自己判断，没核对过的文件不要盲目放行。

## 三、下载卡住或进度不动

- Wi-Fi 与移动数据各试一次；公司与校园网常对大文件限速。
- 应用内下载管理里任务堆积时，删掉失败的旧任务重新点，残留任务会占住文件名。
- 下载路径指向 SD 卡或已满分区会静默失败，改到内部存储。
- 手机端始终不行的，用电脑下载后数据线拷进手机再装。

## 四、装上了但打不开

1. **停在绿色启动页**：那是初始化进度，十几秒内走完；超过一分钟无进度就杀掉进程重开。
2. **清缓存重开**：设置 → 应用 → HappyMod → 存储 → 清除缓存（清除数据会连带清掉登录态与下载记录，放后面做）。
3. **条目闪退**：先回条目页核对改动说明里的适用系统版本，不匹配就换一版——挑选方法见[条目怎么挑才靠谱.md](条目怎么挑才靠谱.md)。
4. **环境干扰**：装了多个同类商店、或开过 Xposed 类框架的设备，退出相关工具再试。
5. 还不行就卸载重装一遍：安装包获取与完整流程见[happymod 介绍站](https://happymod.laze.skin/)与[下载安装全流程.md](下载安装全流程.md)。
