# MChat 加好友与聊天方式

新装一个聊天应用，第一件事是把要说的人加进来，第二件事是挑对说话的方式。这篇把 MChat 这两步拆开讲。

## 加上人的三条路

**靠 MChat ID 精确找人。** 每个账号的资料页都有一串专属 ID，这是最稳的定位方式：把自己的 ID 发到微信、QQ 或者当面给对方，对方在应用里搜索这串字符就能直接找到你。资料页的头像、昵称和所在地可以顺手核对一遍，确认加的是本人。

**进兴趣群组认识同好。** 除了一对一，MChat 里有按兴趣聚起来的群组，进群后聊得来的可以单独加好友私聊。群组是开放入口，只想安静用的人不点开即可。

**从动态里自然认识。** 动态页的图文时间线相当于一个公共客厅：别人发的生活片段下面可以点赞、评论，一来二去聊投机了，点进资料页就能发出好友申请。

## 聊天方式怎么挑

MChat 的沟通通道不少，挑的原则只有一条：看这件事急不急、说不说得清。

- 文字消息适合不急的事，发出去就留在会话里，对方晚点看也行；
- 语音条适合打字说不清的事，按住说完，对方点开听，不用两人同时在线；
- 语音通话适合要当场答复的事，实时往返最快；
- 视频通话适合要看表情、看现场的场合——第一次用之前记得把相机和麦克风权限给到位，不然对方看不到也听不到；
- 图片、视频、文档这类资料直接在会话里传，比邮箱来回发附件省事。

语音和视频通话都走网络流量，不占运营商分钟；信号差的地方（电梯、地库）视频容易卡，优先连 Wi-Fi。
