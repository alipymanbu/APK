# 演唱会现场取货和签名会报名：两件最「现场」的事

在 WITHMUU（위드뮤）上追星，最有现场感的两件事：一件是演唱会当天在场馆扫码领周边，一件是报名签名会赌一次和艺人视频通话。这两件事的规则都和普通网购不一样，值得先看明白再动手。

## PICK UP：场馆里扫码即取

商品页标注 PICK UP 的商品可选现场取货，流程是：

1. 下单时选现场取货，确认商品页标注的取货时段（常见为演唱会前后数天）；
2. App 内生成取货二维码，页面标明编号与时段；
3. 到场馆后把二维码出示给工作人员，扫码核销；
4. 商品当场交接，不经过国际物流。

两个细节：二维码可以提前保存到手机相册，进场前人挤人信号差也不慌；现场取货类商品不支持积分抵扣，下单页会单独标注。

## 签名会：报名就是买对商品

签名会（FAN SIGNING）没有报名表单，报名凭证就是「报名专用商品」的支付完成记录：

- 商品名带 [FAN SIGNING] 一类前缀的才是活动款，买成同专辑普通款不算报名；
- 报名窗口常见 3~4 天，以支付完成时间为准；
- 活动结束后电脑随机抽签，名额从几十人到一百多人不等，以每场公告为准；
- 中签名单在公告板以「姓名打码 + 电话后四位」形式公示，细节单独通知到报名时填写的电话与邮箱。

## 视频通话场与线下场的规矩

视频通话场常见用 KakaoTalk，部分场次支持微信：只能用报名时填写的 ID 拨打且不可更换，填的账号必须能被好友搜索到并与手机号绑定一致；每人通话约 1 分钟，叫号两次未接即失去资格。

线下场要求更严：入场前 1 小时核验身份发号码牌，必须携带本人实名证件原件（外国人用护照），报名填写的姓名要与证件拼写完全一致；名额不可转让；手机要寄存，现场禁止拍摄录音，只能签在主办方提供专辑的指定页。

## 退款与特典，下单前算清楚

报名截止后不接受单纯变心退款，中签与否都不退；截止前取消可以，但等于退出抽签。窗口期内下单全员有报名者特典（多为平台独占自拍小卡，按购买数量 1:1 追加），活动商品在活动结束后统一发货。只想抽特典不赌签名的，可以参加纯抽签活动（Lucky Draw），机制相同但没有到场环节。
