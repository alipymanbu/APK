# APKHUB 下载与安装：从拿包到装好的完整步骤

> 本篇按顺序过一遍 APKHUB 的获取与安装全过程。还不太了解这个应用的，先看 [社区型应用市场功能一览](社区型应用市场功能一览.md)。

APKHUB 不通过系统自带的应用商店分发，安装时 Android 会拦一道「安装未知应用」的授权——这是整个流程里唯一需要动设置的环节，其余基本是点点下一步。本篇对应的安装包为 4.1.2 版、约 29.41M，装完建议留出 100M 以上剩余空间。

## 一、获取安装文件

安装文件资源放在 [APKHUB 介绍站](https://apkhub.fewa.skin/) 的获取入口里（夸克网盘）：

- **手机端**：打开站点、进入网盘页面转存后，在夸克 App 里直接点开 APK；
- **电脑端**：下载后用数据线或局域网共享把 APK 传到手机存储，再到文件管理器里点开。

## 二、给对应应用开授权

安卓 8.0 起「安装未知应用」不再是全局开关，而是**按应用授权**——要给「用来打开 APK 的那个应用」开允许，而不是给 APKHUB 自己。入口一般在「设置 → 应用 → 特殊权限 → 安装未知应用」，个别品牌藏得深一点：

| 品牌 | 常见入口（以手机实际菜单为准） |
| --- | --- |
| 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 | 设置 → 安全 → 安装未知应用 |
| vivo | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 应用 → 特殊访问权限 → 安装未知应用 |

## 三、安装并核对

1. 在文件管理器里点开 APK，系统弹「是否安装此应用」时点「安装」；
2. 装完点「打开」，或回到桌面点图标；
3. 首次启动的网络、存储权限按需允许——**网络权限必须给**，否则内容加载不出来；
4. 到「设置 → 应用」里找到 APKHUB，核对版本显示 4.1.2。版本号与网上介绍页对不上很常见，判断手上是哪一版以手机里的实际显示为准。

装好后怎么用、各栏目是干什么的，见 [社区型应用市场功能一览](社区型应用市场功能一览.md)；安装环节卡住了，直接按 [解析包出错或装不上的排查](解析包出错或装不上的排查.md) 处理。
