# Kai 免密钥能用哪些模型

> 这篇回答一个高频问题：不申请任何 API 密钥，装完能直接用什么；以及之后想换更强的模型，分别要准备什么。
> **同站其他说明**：[安卓版怎么装到手机.md](安卓版怎么装到手机.md) · [短信和日历工具怎么授权.md](短信和日历工具怎么授权.md)

---

## 一、不填密钥：内置免费通道

Kai 内置了一条**零配置的免费通道**（由 Mistral 的模型能力提供）：装完打开，在输入框里发消息就能聊，不需要注册、不需要绑定任何账号。日常问答、翻译、写段子这类需求，先用它体验一轮完全够用。

有两点边界提前知道：免费通道会有限流，发不出去时等几分钟再试；走它就等于把消息发给了提供能力的第三方，对隐私敏感的内容可以换本地模型（见下文）。

## 二、想换更强的模型：填密钥即用

到「设置 → 服务 → 添加服务」里选一个服务商，把 API 密钥粘进去，应用会自动校验连接并拉取该账号可用的模型列表：

| 服务 | 特点 | 准备什么 |
| --- | --- | --- |
| Gemini | 有免费额度；图片附件只在它下面可用 | API 密钥 |
| xAI | Grok 系列模型 | API 密钥 |
| Groq | 出字速度快，有免费额度 | API 密钥 |
| OpenRouter | 一个密钥转接多家模型 | API 密钥 |
| Ollama | 本机或局域网跑本地模型，**完全离线** | 装好 Ollama 并拉好模型 |

密钥只填在应用的设置里；求助时贴截图记得把密钥输入框遮住，泄露了谁都能烧你的额度。

## 三、切换的日常用法

- 同一个问题想换个模型对比：聊天中途切到另一条通道，再发一遍即可；
- 自己的密钥额度用完时，随时切回内置免费通道兜底；
- Ollama 走本地地址、不需要密钥，前提是那台机器上的模型服务在运行。

## 四、开始用

还没装的话，从第三方介绍站进入即可：打开 [Kai 客户端介绍页](https://kai.wxhp.skin/)，按页面指引先把安卓安装包拿到手（步骤见 [安卓版怎么装到手机.md](安卓版怎么装到手机.md)），装完按本文第二节逐个添加服务。
