# Kai 短信和日历工具怎么授权

> 这篇讲 Kai 在安卓上的「工具」能力：短信、日历、通知这些动作分别读什么数据、权限怎么给、给了以后怎么用自然语言触发。
> **同站其他说明**：[免密钥能用哪些模型.md](免密钥能用哪些模型.md) · [安卓版怎么装到手机.md](安卓版怎么装到手机.md)

## 一、工具是干什么的

普通聊天里模型只能「动嘴」，Kai 的工具（Tools）是给模型开的一组真实动作：模型判断该用时就调用，结果直接回到对话里。安卓版共有 6 个，全部在「设置 → 工具」里逐个开关：

| 工具 | 干什么 | 平台 |
| --- | --- | --- |
| 查看短信 | 读取最近短信会话 | 仅安卓 |
| 回复短信 | 回复已有会话 | 仅安卓 |
| 创建日历事件 | 在系统日历里建日程 | 仅安卓 |
| 发送通知 | 状态栏推一条提醒 | 仅安卓 |
| 获取本地时间 | 让回答里的「今天」不再靠猜 | 全平台 |
| 获取位置 | 按 IP 估到城市级 | 全平台 |

## 二、权限怎么给

1. 进「设置 → 工具」，把需要的开关打开；
2. 第一次触发时安卓会弹权限请求——**短信、日历、通知是三个独立权限**，按需给；
3. 曾点过「拒绝」的工具会静默失效：到「系统设置 → 应用 → Kai → 权限」里补授予即可。

敏感权限只开用得到的：不用短信就只关短信那一个，日历照常能用。**用不到的权限完全可以不给**，开关关着模型根本调不到。

## 三、开了之后怎么用

权限给完，回到对话里用自然语言直接说：

- 「看下刚才那条验证码短信」→ 调用查看短信；
- 「回复他：稍后到」→ 调用回复短信；
- 「明天下午三点提醒我交材料」→ 建日历事件，落到系统日历里，用惯用的日历应用就能改；
- 「给我发条通知：到了喊我」→ 状态栏即时提醒（一次性，不是定时器）。

位置按 IP 估算、只到城市级，导航还是用手机自带的地图。

## 四、权限之外的边界

- 用哪条模型通道不影响工具——工具跑在应用这一侧，内置免费通道、Gemini、Groq 都能触发（前提是开关打开、权限给过）；
- 聊天记录在设备上**加密保存**，短信、日历这类被读取的数据也只用于当场完成动作，不会另外上云同步。
