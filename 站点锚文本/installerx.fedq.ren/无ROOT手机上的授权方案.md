# 无ROOT手机上的授权方案

> InstallerX 调系统安装接口需要特权，授权器就是给它供权限的通道。手机没有 ROOT 也不是死路——本篇把 ROOT / Shizuku / Dhizuku 三条通道的前提、激活步骤与取舍讲清，没 ROOT 的机型重点看 Shizuku。
> **相关文档**：[接管默认安装器的设置流程.md](接管默认安装器的设置流程.md) · [安装失败与报错的排查思路.md](安装失败与报错的排查思路.md)

## 一、三条通道怎么选

| 通道 | 前提 | 特点 |
| --- | --- | --- |
| ROOT 超级用户 | 手机已 ROOT | 最直接，授权一次长期有效 |
| Shizuku | 无需 ROOT，Android 11+ 可无线调试激活 | 无 ROOT 用户的主流选择，功能完整 |
| Dhizuku | 无需 ROOT，走设备管理员机制 | 激活门槛高、权限相对弱，部分高级操作做不到 |

已 ROOT 就直接选 ROOT 超级用户；没 ROOT 优先装 Shizuku 再回来授权；两条路都不通再考虑 Dhizuku。

## 二、激活 Shizuku（Android 11 及以上）

前提：手机连着 Wi-Fi，开发者选项已打开。

1. 进系统「设置 → 开发者选项」，开启**无线调试**；
2. 打开 Shizuku，点**通过无线调试启动**，进**配对**页面；
3. 回到系统的无线调试界面，选**使用配对码配对设备**，屏幕显示一组 6 位配对码；
4. 下拉通知栏，把 Shizuku 发来的配对通知展开，在超时前把 6 位码填进去；
5. 回到 Shizuku 主界面，显示「正在运行」即激活成功。

三个容易卡住的点：一直「正在搜索配对服务」就把系统无线调试关掉重开再试；配对码超时作废，重新生成后第一时间填；点启动没反应，同样先重开无线调试。

## 三、老系统用电脑 ADB 激活

Android 11 以下没有无线调试配对入口，需要电脑连一次：装好 ADB 工具（platform-tools）、手机开 USB 调试后，在电脑执行 Shizuku 应用内显示的启动命令（不同版本略有差异）。手机上显示正在运行即可拔线；手机重启后需要重新执行一次。

## 四、把权限授给 InstallerX

1. 打开 Shizuku，进「使用 Shizuku 的应用」（有的版本叫已授权应用）；
2. 找到 InstallerX，打开授权开关；
3. 列表里没有它的话，先回 InstallerX 随便发起一次授权请求（比如进设置点授权器），它就会出现在候选里。

之后回 InstallerX 的设置确认授权器已选为 Shizuku，就可以进行锁定了，见 [接管默认安装器的设置流程.md](接管默认安装器的设置流程.md)。

## 五、重启后失效是机制不是故障

无线调试激活的 Shizuku 在手机重启后会停，重新点一次「通过无线调试启动」即可（一般不用重新配对）。两个减负办法：

- 把 Shizuku 加入电池白名单 / 后台无限制，减少被杀；
- 嫌反复激活麻烦，改用重启后依然有效的 Dhizuku，代价是权限弱一档、部分安装场景做不到。

授权或安装环节还有别的报错，去 [安装失败与报错的排查思路.md](安装失败与报错的排查思路.md) 查。
