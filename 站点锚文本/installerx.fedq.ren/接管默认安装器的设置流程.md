# 接管默认安装器的设置流程

> 装完 InstallerX 只是第一步——不经过授权与锁定，点 APK 时弹出来的仍然是系统安装器。本篇按顺序走完「选授权器 → 锁定 → 试装」三步，并处理锁定后被系统弹回去的情况。
> **相关文档**：[无ROOT手机上的授权方案.md](无ROOT手机上的授权方案.md) · [安装失败与报错的排查思路.md](安装失败与报错的排查思路.md)

## 一、为什么装完不生效

InstallerX 的工作方式是替换系统的默认安装器角色，而「改默认安装器」这个动作本身需要特权。特权来自授权器（ROOT / Shizuku / Dhizuku 三选一），所以顺序是死的：

1. 先进设置，把**授权器**选好并确认可用；
2. 再回来点**锁定为默认安装器**；
3. 找一个 APK 试装验证。

顺序反了或授权器还没生效就去点锁定，要么按钮没反应，要么直接提示没有权限——这是第一次设置失败最常见的原因。

## 二、三步的具体操作

**第一步：选授权器。** 打开 InstallerX 进设置页，在授权器一项里选择 ROOT 超级用户、Shizuku 或 Dhizuku。已 ROOT 的机型直接选 ROOT；没 ROOT 的主流路线是 Shizuku，激活与授权的完整步骤见 [无ROOT手机上的授权方案.md](无ROOT手机上的授权方案.md)。

**第二步：锁定。** 授权器就位后，点设置里的「锁定为默认安装器」，弹出确认时再确认一次。锁完可以顺手看一眼安装方式（对话框 / 通知栏 / 自动）是否符合自己的使用习惯。

**第三步：试装。** 在文件管理器里随便点开一个 APK：弹出来的是 InstallerX 的安装卡片（显示应用名、版本、包名）就说明接管成功；还是老样子的系统安装页，就去 [安装失败与报错的排查思路.md](安装失败与报错的排查思路.md) 对号入座。

## 三、锁定又被系统弹回去

部分定制系统会在系统更新、重启或自家安全策略触发时，把默认安装器重置回自带的那一个。表现为：明明锁过，过几天点 APK 又走回系统流程。处理办法：

- 重新进 InstallerX 再锁一次，一分钟的事；
- 版本太旧的先升级——1.7 版的更新说明里就有「修复锁定默认安装器」一条；
- 小米 HyperOS、ColorOS、OriginOS 这类系统重置更勤，属于系统侧策略，InstallerX 本身解决不了厂商的限制，能做的就是把重锁变成习惯。

## 四、不想锁定也能用

偶尔装一个包、不想改系统默认行为的，可以在文件管理器里用「打开方式」手动选 InstallerX 来装单个 APK，只是每次都要选一遍。经常装包、想让所有 APK 自动走它的，还是锁上省事。

更多功能说明与安装包获取入口，见 [InstallerX 介绍站](https://installerx.fedq.ren/)。
