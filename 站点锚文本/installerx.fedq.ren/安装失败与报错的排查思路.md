# 安装失败与报错的排查思路

> 点了安装没反应、还是弹系统安装器、授权失败、装到一半报错——失败基本分三类，断点不同修法完全不同。本篇按「断在哪一步」对号入座。
> **相关文档**：[接管默认安装器的设置流程.md](接管默认安装器的设置流程.md) · [无ROOT手机上的授权方案.md](无ROOT手机上的授权方案.md)

## 一、先判断断在哪一步

| 现象 | 断点 | 处理 |
| --- | --- | --- |
| 点 APK 弹出的还是系统安装器 | 接管没生效 | 本文第二节 |
| 弹授权请求 / 提示授权器不可用 | 权限没到手 | 本文第三节 |
| InstallerX 弹出来了，但安装报错 | 安装环节出错 | 本文第四节 |

## 二、还是弹系统安装器

按顺序检查四件事：

1. **锁定过没有**：进 InstallerX 设置，确认「锁定为默认安装器」处于已锁状态，没有就先锁；
2. **顺序对不对**：必须先选好授权器再锁定，顺序错了锁定不生效；
3. **被系统重置了**：小米 / ColorOS / OriginOS 这类系统可能把默认安装器弹回去，重新锁一次；
4. **锁不上**：个别系统对安装入口管控极严，纯靠 InstallerX 接管不了，这是系统侧限制，报错信息明确的先对照下文第四节。

完整的三步流程见 [接管默认安装器的设置流程.md](接管默认安装器的设置流程.md)。

## 三、授权失败

**Shizuku 相关**：

- 提示 Shizuku 未运行：它重启手机后会停，重新「通过无线调试启动」一次，配对细节见 [无ROOT手机上的授权方案.md](无ROOT手机上的授权方案.md)；
- 授权列表里找不到 InstallerX：先在 InstallerX 里发起一次授权请求，让它出现在候选里；
- 无线调试配对不上：确认手机与配对时连的是同一 Wi-Fi，配对码要在通知弹出后尽快输入，超时就重新生成。

**ROOT 相关**：先确认 ROOT 管理器本身工作正常，再回 InstallerX 重试授权。

**Dhizuku 相关**：它走设备管理员机制，权限弱于 Shizuku，部分高级操作做不到；授权总是不顺畅就换 Shizuku，是更省事的路线。

## 四、安装环节报错

| 报错 / 表现 | 原因 | 处理 |
| --- | --- | --- |
| 版本类错误，装不上旧版 | 没开允许降级 | 在安装选项里勾「允许版本降级」，建议直接在配置里预设 |
| 提示需申明有效安装者 | 系统校验安装来源 | 调整「声明安装者」设置，个别机型把声明者设为系统安装器包名后可通过，以机型实际为准 |
| 解析失败 | 包没被正确识别 | APK、XAPK、APKS 及含 APK 的 ZIP 都能直接装，无需手动解压；反复失败先换一份包 |
| 装到一半卡住 | 后台被系统冻结 | 把 InstallerX 加进电池白名单 / 后台无限制，重新发起 |
| 点安装闪退 | 通知权限被禁 | 通知栏安装依赖通知通道，去系统设置打开它的通知权限 |
| 装完打不开 / 提示缺数据 | 分包容器的 OBB 没就位或架构不匹配 | OBB 放进 `Android/obb/<应用包名>/`（目录名与包名逐字一致）；或换对应架构的包 |
| 签名冲突 | 已有同名应用但签名不同 | 先卸载旧版再装，卸载会清数据，先备份 |

## 五、排除安装包本身的问题

以上都正常还失败，就换一个 APK 试：换一个能装，说明问题在那个包本身（损坏、架构不匹配），不是安装器的问题。分包格式（XAPK 等）解析时自动按设备匹配，单个 APK 则可能只含特定架构，换对应架构的包即可。
