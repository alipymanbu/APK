# MyComic 离线缓存与书架追更

> 通勤没网想看漫画、追更不想天天手动翻查——这两件事分别对应 MyComic 的离线缓存与书架提醒。本篇把这两条日常路径讲清楚。
> **相关文档**：[聚合阅读应用功能一览.md](聚合阅读应用功能一览.md) · [搜不到作品时怎么换数据源.md](搜不到作品时怎么换数据源.md)

## 一、离线缓存：先把章节囤下来

MyComic 支持离线下载，把想看的章节先缓存到本地，通勤、没网时也能继续看。据公开收录页的更新记录，v1.11.4 起小说章节也支持缓存了，漫画与小说都能做本地储备；缓存与在线内容在阅读时会自动衔接，不用手动切换。

缓存后看不到已下载章节的常见原因有两个：一是存储空间不足导致缓存中断，清理后再缓存；二是换了数据源后章节对应关系变了，切回缓存时使用的源就能看到。

## 二、书架与追更：收藏之后交给提醒

- **收藏进书架**：追更的作品都收进书架，进度与更新提醒都围绕书架转；
- **继续阅读**：应用会记录阅读进度，下次打开从上次停下的地方接着看，不用自己记章节号；
- **更新提醒**：收藏的作品更新后会提醒，不用天天手动翻查；收藏与删除在书架页长按或通过菜单操作。

## 三、阅读界面里顺手调几项

阅读过程中可调的项目集中在阅读界面里呼出：

| 可调项 | 说明 |
| --- | --- |
| 阅读模式 | 翻页方式可切换，看漫画像翻书一样顺手 |
| 字体大小 | 长篇阅读时调大更省眼 |
| 背景色 | 换深浅背景，夜间看更舒适 |
| 深色模式（小说） | 小说阅读支持深色模式，自 v1.11.4 起 |

具体入口的位置随版本可能有小变动，以实际界面为准。

## 四、书单分享：把整理好的推荐给别人

v1.11.3 起支持书单分享与导入，入口在收藏页右上角的菜单选项里：可以把整理好的书单分享出去，也能导入别人分享的书单。导入分享书单遇到问题时，多数是版本过旧，更新后即可。

## 五、遇到加载不出来的情况

图片转圈、章节打不开时，先按 [搜不到作品时怎么换数据源.md](搜不到作品时怎么换数据源.md) 换个源，再依次试换网络、重启应用、重新进章节。想了解应用的整体功能，回 [聚合阅读应用功能一览.md](聚合阅读应用功能一览.md)，或直接到 [MyComic 介绍站](https://mycomic.fedq.quest/) 看界面速览。
