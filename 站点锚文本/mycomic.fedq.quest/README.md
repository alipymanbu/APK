# MyComic 介绍站：聚合漫画阅读的第三方说明页

本目录整理围绕安卓聚合阅读应用 MyComic 的介绍文章：它把漫画、小说、番剧装进同一个应用，内置多个数据源，搜不到就换源再搜，还支持离线缓存与书架追更。界面速览、安装文件资源入口与换源技巧见 [MyComic 介绍站](https://mycomic.fedq.quest/)。
