# MyComic 搜不到作品时怎么换数据源

> 在 MyComic 里搜某部作品没有结果、详情页一直转圈，多数时候不是应用坏了，而是当前数据源没收录。本篇讲换源的具体路径与换源时机。
> **相关文档**：[聚合阅读应用功能一览.md](聚合阅读应用功能一览.md) · [离线缓存与书架追更.md](离线缓存与书架追更.md)

## 一、先弄清「源」和「内容」的关系

MyComic 的漫画、小说、番剧都来自内置数据源，搜索结果跟随当前选中的源。所以同一个关键词，在不同源里给出的结果是不一样的一批——反复换关键词不如直接换源有效。

## 二、切换数据源的路径

1. 打开应用，进入左下角的「我的书架」；
2. 点页面左上角的切换按钮；
3. 在弹出的小窗口里选择想用的数据源；
4. 返回搜索页，用关键词重新搜索。

换源之后，搜索与排行榜都按新源给出；书架里已收藏的作品不受切换影响。

## 三、什么情况该换源

| 情况 | 建议 |
| --- | --- |
| 搜某部作品没有结果 | 换一个源再搜，不同源收录范围不同 |
| 详情页或正文图片一直转圈 | 换源，或把应用从后台划掉重开再试 |
| 某个源整体响应很慢 | 先换到快的源看内容，稍后再回来试 |
| 想对比章节进度 | 在两个源里分别搜同一作品，看各自更新到哪一话 |

## 四、换源之外的两条路

- **关掉不想要的源**：较新版本可以在「个人中心 → 数据源配置」里选择关闭数据源，搜索页也会把不同源的结果分类展示；手上的版本没有这两个入口属正常，不是坏了；
- **本地导入**：某部作品在任何源里都找不到、或手里本来就有文件时，可以把本地漫画文件导入应用直接阅读，不再依赖数据源。

想先看看这个应用的整体功能与装机门槛，可以移步 [MyComic 介绍站](https://mycomic.fedq.quest/)；日常的缓存与追更操作则整理在 [离线缓存与书架追更.md](离线缓存与书架追更.md) 里。
