# 安卓版安装步骤与问题排查

本篇讲怎么把 Sekai 的安卓版装进手机：从哪里进网盘分享页、转存与下载的顺序、未知来源怎么放行，以及装不上时的排查顺序。装好之后的玩法动线见 [兴趣标签与推荐流玩法解析](兴趣标签与推荐流玩法解析.md)。

---

Sekai 的安卓安装包不走应用商店分发渠道也能拿到，全程在手机上即可完成。整体思路是：先把安装包转到自己的网盘名下，再下载到本机安装。

## 安装五步

1. **打开资源入口**：进入 [Sekai 中文玩法站](https://sekai.rggd.pw/)，点页面上的下载按钮打开网盘分享页，登录自己的网盘账号；
2. **转存**：把分享页里的安装包保存到自己名下，转存后再下载比直接在分享页下载更稳；
3. **下载 APK**：用网盘客户端把安装包下载到手机存储，包体不大，流量也能下；
4. **放行未知来源**：首次点开安装包时系统会提示禁止安装，按弹窗引导进入设置，允许刚才用来下载的那个应用（网盘客户端或浏览器）安装应用，返回重试；
5. **首次启动**：装好打开，选称呼、挑至少 3 个兴趣标签，点 Next 就能进推荐流。

## 装不上时的排查顺序

- **提示无法解析安装包**：多半是下载不完整，回网盘重新下载一次，下载完成前不要急着点安装；
- **点安装没反应或被拦截**：回到「设置 → 应用 → 特殊权限 → 安装未知应用」，确认给对了应用授权，再从文件管理器或通知栏重新点安装包；
- **下载很慢或中断**：确认已经转存到自己的网盘再下，客户端走专用通道，比浏览器直接拉分享页稳定；中断后可从断点续传；
- **装好但打开一直转圈**：Sekai 的对话由在线模型完成，需要联网才能用，先确认手机能正常上网，彻底退出重开；仍异常就卸载后重装一次。

装完别急着划走，首屏那几个兴趣标签决定了你之后看到的推荐内容——选法与读卡的细节都写在 [兴趣标签与推荐流玩法解析](兴趣标签与推荐流玩法解析.md) 里。
