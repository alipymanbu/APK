# 无线调试配对激活教程

> 本篇讲让 ShizukuRunner 真正能跑命令的前提：把 Shizuku 服务激活起来。三种激活方式按机型与条件选其一即可。激活之后的格子用法另见[自定义命令面板怎么用](自定义命令面板怎么用.md)；图文版全流程在 [ShizukuRunner 安卓版介绍与获取入口](https://shizukurunner.gkhf.beer/download.html)。

---

## 为什么装完还是「未授权」

ShizukuRunner 本体只是个命令面板，权限全部来自 Shizuku 提供的服务。服务没启动时打开面板，自然提示未授权——这不是安装失败，顺序问题而已：**先激活 Shizuku，再授权给 Runner**。

## 方式一：无线调试（Android 11+，推荐）

手机自己就能完成，全程不用电脑：

1. 进入系统设置，打开开发者选项里的「无线调试」；
2. 选择「使用配对码配对设备」，屏幕会显示一组六位配对码与端口；
3. 打开 Shizuku，进入配对流程，填入配对码；
4. 配对成功后回到 Shizuku 主页点「启动」，服务跑起来即完成。

配对一般只需做一次；手机重启后服务会停，重新点一次「启动」即可，不用重新配对。

## 方式二：电脑 ADB（Android 7~10 可用）

老系统没有无线调试，需要电脑帮一次忙：

1. 电脑安装 Google 官方的 SDK Platform Tools；
2. 手机开启 USB 调试并连接电脑；
3. 在 Shizuku 里点「查看命令」，把显示的启动命令复制到电脑终端执行；
4. 终端出现服务启动的提示后，手机上的状态就会变成运行中。

缺点明显：每次重启手机都要再连一次电脑。所以老设备用户往往在重启前想清楚要不要重启。

## 方式三：root 设备直接启动

已经 root 的设备在 Shizuku 里直接点启动即可，还能在设置里勾选开机自启，重启后服务自动回来，最省心。

## 激活之后：把权限发给 Runner

服务跑起来后，打开 ShizukuRunner，会弹出「允许使用 Shizuku」的确认框，选允许。面板顶部显示激活状态，就绪后就可以填命令了——具体见[自定义命令面板怎么用](自定义命令面板怎么用.md)。

顺带说清权限边界：Shizuku 以 ADB（含无线调试）方式启动时，命令以 shell 权限执行；以 root 方式启动时才是 root 权限。不想跑太高的权限，可以在设置里勾选「降权至 shell 身份执行」。
