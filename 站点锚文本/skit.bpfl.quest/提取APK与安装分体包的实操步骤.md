# 提取APK与安装分体包的实操步骤

> 把手机里的应用导出成文件、再把外面的分体包装回手机，是 Skit 用得最多的两个方向。这篇只写操作：从哪点进去、文件存到哪、装不上时先查什么。
> **相关文档**：[应用管理工具为什么值得单独装一个](应用管理工具为什么值得单独装一个.md) · [看穿应用权限组件与换机留档](看穿应用权限组件与换机留档.md)

## 方向一：把应用提取出来

1. 打开 Skit，在列表里找到目标应用——侧边栏能切「用户应用 / 系统应用」，别在用户列表里翻半天找不到系统预装；
2. 点进应用详情，再点右下角的功能按钮；
3. 选「提取」，文件会存进内部存储的 `Skit` 文件夹；选「分享」则直接调起系统分享面板发出去；
4. 提取完到文件管理器里确认文件在，再决定拷走还是留着。

两个先知道的事：Basic 版一次只能提取一个应用，批量提取要多装一份 Premium；系统应用虽然能提取，但导出的包离开原机型大概率装不上，当本机留档看就好。

## 提取出来的为什么是 .apks

取决于目标应用的打包方式。2021 年起商店新应用基本走 App Bundle 分发，提取出来就是「一袋分片」的 .apks 格式——它不是损坏文件，只是系统安装器不认。Skit 设置里有强制导出单个 APK 的选项，但缺了机型分片的单包换设备可能装不上，优先原样搬运。

## 方向二：把分体包装回手机

- **从文件管理器进**：点开 .apks / .apkm / .xapk 文件 → 选「用 Skit 打开」→ 按提示确认安装，首次会要求授权「安装未知应用」；
- **从 Skit 里进**：工具入口 → 安装器 → 浏览到文件所在目录 → 选中确认。

安装过程会逐分片拉起系统安装会话，进度跟着系统弹窗走。

## 装不上时先查这三样

| 现象 | 先查什么 |
| --- | --- |
| 提示解析错误 | 是不是在用系统安装器直接点分体包——改用 Skit 的安装器打开 |
| 中途安装失败 | 存储空间够不够；分体包是按机型拆的，别人机型的包可能缺你这台的分片 |
| 提示签名不一致 | 新旧两份不是同一签名方，只能卸旧的再装，注意先留数据 |

工具本身的获取与安装步骤，[Skit 介绍站](https://skit.bpfl.quest/)的下载页写得最细；清单、组件这些「提取之外」的能力，见 [看穿应用权限组件与换机留档](看穿应用权限组件与换机留档.md)。
