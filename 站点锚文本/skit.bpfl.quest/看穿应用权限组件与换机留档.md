# 看穿应用权限组件与换机留档

> 装完一个新应用，它的权限要得对不对、有没有可疑的后台组件；换新手机前，装过的应用和它们的版本怎么留底。这两件事都属于「把应用的底细摸清」，这篇一起讲。
> **相关文档**：[应用管理工具为什么值得单独装一个](应用管理工具为什么值得单独装一个.md) · [提取APK与安装分体包的实操步骤](提取APK与安装分体包的实操步骤.md)

## 详情页：一个应用的基本盘

在 Skit 的列表里点开任意应用，能看到的信息比系统设置里细得多：

- **安装时间**——排查「这是什么时候混进来的」最有用的一栏；
- **最后更新 / 最后使用**——版本停在多老、多久没打开过，清理时心里有数；
- **本机实测体积**——应用本体和数据各占多少；
- **包名与 SDK 版本**——判断能不能装到旧手机、能不能覆盖升级。

列表页本身也能增强：给每行加第三行显示体积、给系统应用挂识别徽标，扫一眼就能筛掉大半疑问。

## 组件页：它后台到底在干什么

详情页里的组件视图把 APK 的 Manifest 拆开：Activities（界面入口）、Services（后台干活）、Receivers（监听广播，开机自启常在这）、Providers（对外供数据），外加权限清单。装完一个应用觉得它「管得有点宽」，来这里对着看，比在系统设置里翻设置项直观得多。

要看「这个包是谁签的」，证书页也有入口——同一包名能不能覆盖安装，就看签名是否一致。证书只是身份信息，别当成安全背书。

## 换机前的两份留档

真到换手机那天，Skit 能帮你留下两样东西：

1. **应用本体**——按 [提取APK与安装分体包的实操步骤](提取APK与安装分体包的实操步骤.md) 把在意的应用逐个导出，拷到电脑或网盘；
2. **整机清单**——功能入口里的 Apps List 会生成一份 JSON 文件（包名、体积、更新时间、SDK 都在），新机装完照单查漏。

要说清边界：应用里的聊天记录、登录状态不在 APK 里，云端数据登录即回，只存在本地的得靠应用自己的导出功能或系统迁移工具。「程序」和「数据」是两条线，别指望一份 APK 全带走。
