# LumaFusion 安卓版：资源与阅读指引

这是一个围绕移动端多轨视频剪辑整理的资料小站目录。主角是 LumaFusion——LumaTouch 推出的移动端剪辑应用，安卓与 ChromeOS 版按平台重做，2023 年 2 月正式发布。

软件的获取入口、功能清单与安装步骤整理在介绍站里：[LumaFusion 安卓版介绍站](https://lumafusion.hfdk.space/)。

## 本目录有什么

- [手机多轨视频剪辑.md](手机多轨视频剪辑.md)——手机上做多轨剪辑需要什么、思路怎么转
- [手机绿幕抠像.md](手机绿幕抠像.md)——绿幕拍摄与色度键操作的要点
- [手机视频调色.md](手机视频调色.md)——LUT、Log 素材与示波器怎么看

三篇按「先搭工作流、再解决具体画面问题」的顺序排，建议从第一篇读起。
