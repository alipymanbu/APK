# 手机绿幕抠像：拍对了一半就成功了

绿幕抠像（色度键）是把纯色背景整块去掉、换上别的画面，手机上就能做。但它有个铁律：**拍摄决定上限**。后期只能放大拍摄时留下的瑕疵，救不回没拍对的东西。这篇按「先拍、再抠、后修」的顺序讲。

## 一、拍摄阶段的四条底线

抠像干不干净，七八成在拍的时候已经定了：

1. **绿布平整**：褶皱会产生深浅不一的绿色，后期容差很难兼顾；
2. **光线均匀**：布上有阴影、亮斑，抠完必留残影；
3. **主体离布远一点**：人贴着绿布站，身上会打出绿色的反弹光，边缘发绿就是这么来的；
4. **主体别穿绿色**：衣物颜色接近背景色会被一起抠掉。

## 二、色度键还是亮度键

两种键控按背景选：

- **色度键（chroma key）**：按颜色抠，绿幕、蓝幕都用它；
- **亮度键（luma key）**：按明暗抠，适合黑底、白底的素材，比如黑色背景拍的访谈剪影。

手机剪辑工具里这两样都有，LumaFusion 把它们和模糊、扭曲等一起放在效果列表里，选中片段直接挂载，效果还能多层叠加、调好存成预设。

## 三、抠像三步：取色、容差、柔化

操作顺序别乱，反着调容易越调越脏：

1. **取色**：吸管点绿幕最标准的那块颜色；
2. **调容差**：慢慢加大范围，直到绿色基本消失；
3. **柔化边缘**：最后处理主体轮廓，让边缘自然融入新背景。

三个常见坑：

- **边缘发绿**：这是颜色溢出不是没抠干净，加柔化或溢出抑制，反复改容差只会更糟；
- **主体被啃掉一块**：容差开太大了，往回收一点；
- **画面整体变色**：检查是不是把调色放在了抠像之前，效果叠层有顺序，先抠后调还是先调后抠结果不同。

## 四、手机上的实操路径

以 LumaFusion 安卓版为例：素材上时间轴 → 选中绿幕片段 → 效果列表里挂色度键 → 取色调容差 → 边缘柔化 → 播一遍看动态边缘稳不稳。静态看很干净还不够，人物一动边缘闪烁才是最容易翻车的地方，有问题回容差微调。
