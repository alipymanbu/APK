# 手机视频调色：LUT 与示波器的实用入门

调色分两件事：**还原**（把素材调回正常颜色）和**风格化**（定调性）。很多人跳过还原直接套滤镜，出来的颜色总差点意思。这篇讲手机上把调色做对的基础：LUT 怎么用、Log 素材怎么还原、示波器怎么看。

## 一、LUT 是什么，怎么用

LUT（查找表）是一份「颜色换算规则」：输入一个颜色值，按表输出另一个颜色值。用途有两个：

- **技术还原**：把 Log 模式拍的灰片换算回正常对比与颜色；
- **风格化**：给画面套电影感、复古感之类的预设调性。

用的时候注意来源匹配：Log 素材要套对应机型的还原 LUT，套错了颜色就是不对。手机剪辑工具普遍内置一批 LUT，也支持导入自己的 `.cube` 或 `.3dl` 文件——LumaFusion 就两者都支持，媒体库里点导入选中文件即可，内置列表里还能选 FiLMiC deLog 这类常用的。

## 二、Log 素材为什么要还原

用 Log 模式拍回来的画面是灰的、对比很低——这不是拍坏了，是刻意保留了更多亮度与色彩信息。还原 LUT 把它拉回正常状态之后，再做风格化微调，可塑空间比直接拍的大得多。

顺序记住：**先还原，后风格**。还原是起点不是终点。

## 三、别只信手机屏幕

手机屏幕会骗人：色偏、环境光、亮度设置都会让同一段画面看起来是两个样子。所以调色工具里带了示波器——用数据说话：

| 示波器 | 看什么 | 什么时候用 |
| --- | --- | --- |
| 波形图 | 亮度分布 | 触顶是过曝，堆底是死黑 |
| 矢量图 | 色相与饱和度 | 颜色跑出安全范围说明饱和过头 |
| 直方图 | 各亮度区间的像素量 | 判断整体偏亮还是偏暗 |

不用三块都盯，对应当前问题看一块就够：担心高光看波形，怀疑颜色太妖看矢量，拿不准整体明暗看直方图。

## 四、手机调色的实操顺序

1. 导入素材上时间轴，选中片段；
2. 有 Log 先套还原 LUT；
3. 按曝光 → 色温 → 饱和度的顺序粗调；
4. 需要风格化再叠一层 LUT 或微调色轮；
5. 定了的一套调法存成预设，同系列素材整体套用，多段之间风格才统一。

工具层面，LumaFusion 安卓版把色轮、LUT、三块示波器都放在调色面板里，功能清单与安装入口见 [LumaFusion 安卓版介绍站](https://lumafusion.hfdk.space/)。

调完颜色如果发现画面边缘有绿边或残留，多半是绿幕素材的问题，处理办法见[手机绿幕抠像](手机绿幕抠像.md)；时间轴和轨道的基础操作在[手机多轨视频剪辑](手机多轨视频剪辑.md)里。
