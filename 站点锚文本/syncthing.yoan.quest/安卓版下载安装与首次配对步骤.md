# 安卓版下载安装与首次配对步骤

> 已经决定在手机上装 Syncthing 了？本篇把安卓端从下载安装包到首次配对、开始第一轮同步的完整路径走一遍，顺带提两个最容易卡住的新手坑。

## 一、先把安装包拿到手

安卓端是一个独立的 App。需要留意的是：它在 2024 年底随 1.28.x 系列停止了维护，此后由社区分支接续更新；1.28.x 本身同步功能完整，普通使用没有问题。

安装包的获取入口整理在 [Syncthing 介绍站](https://syncthing.yoan.quest/)的下载页里，按页面提示把 APK 转存到自己的网盘再下载即可；用电脑转存后传到手机也可以。

## 二、安装四步

1. **打开 APK 前先放行**：国产系统常默认拦截侧载安装，在「设置 → 应用」里给文件管理器或浏览器允许「未知来源应用」；
2. **完成安装**：点开 APK，进度走完后打开应用；
3. **给足权限**：存储权限决定能不能读你要同步的文件夹，通知权限对应那条常驻的同步状态通知，电池优化务必豁免——这是「装好了却不同步」的头号原因；
4. **别删常驻通知**：部分系统在通知被禁后会连后台服务一起限制，保留它反而更稳。

## 三、首次配对：两边都要加对方

Syncthing 不用注册账号，配对靠交换设备 ID：

1. 手机端左上角菜单 →「显示设备 ID」，会出现一串七段式的 ID 和二维码；
2. 电脑端打开管理页面（浏览器访问 `127.0.0.1:8384`），添加远程设备时扫手机上的二维码，或把手机 ID 粘贴过去；
3. 关键的一步：电脑端会弹出「新设备」确认提示，点添加——**只加一边是连不上的**；
4. 两边设备名旁都亮起在线状态，配对完成。

## 四、共享第一个文件夹

以手机照片进电脑为例：手机端「文件夹」页点加号，路径选相册目录，类型选「仅发送」，共享给刚配对的电脑；电脑端接受时把类型改成「仅接收」，路径指向存放照片的位置。保存后等第一轮初始同步走完（几千张照片建议插电过夜跑），之后新照片就会在联网时自动补进电脑。

## 五、装好却不同步，先查两处

- 应用内「设置 → 运行条件」：是否勾了 Wi-Fi、当前是否满足自己设的条件；
- 系统电池设置：是否已把它的电池优化关掉。

这两处处理完，绝大多数「看起来不动」的情况都会恢复正常。
