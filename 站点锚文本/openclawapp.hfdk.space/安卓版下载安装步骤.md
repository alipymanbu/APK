# openclawapp 安卓版下载安装步骤

> 本篇讲 openclawapp 安卓端从拿到安装包到装进手机的完整步骤，以及装完之后还差哪一步才能真正用起来。
> **相关文档**：[手机端配对与语音用法](手机端配对与语音用法.md) · [连不上网关的排查思路](连不上网关的排查思路.md)

## 先弄清这份安装包的角色

openclawapp 是开源自托管 AI 助手 OpenClaw 的安卓随行端（伴生节点）。它本身不运行助手——助手本体是跑在电脑上的 Gateway，手机端负责聊天、语音、审批与按授权开放手机能力。所以"装完"只是半程，装完再连上 Gateway 才算能用了。

本文对应的安装包约 6.7 MB（10.0 版），获取入口见 [openclawapp 安卓随行站](https://openclawapp.hfdk.space/) 的下载页。

## 安装四步

1. **取安装包**：从网盘分享页把 `openclawapp_v10.0.apk` 转存到自己的网盘，再用手机客户端下载到本机；
2. **允许安装**：首次安装会被"未知来源应用"拦一下，按弹窗指引给下载入口（浏览器或文件管理器）开一次允许；
3. **完成安装**：点开 apk 装完，桌面出现龙虾图标；打开后通知栏会挂一条常驻通知，那是它的前台服务在保活，别随手关；
4. **连上 Gateway**：这一步在电脑上配合——`openclaw qr` 生成配对码，手机 app 的 Connect 页扫码或手动填电脑 IP + 18789 端口，然后电脑端 `openclaw devices approve <requestId>` 批准设备。

前三步装完只花几分钟；第四步的前提是电脑端 Gateway 已经跑起来（`openclaw gateway status` 能看到监听 18789）。

## 装完之后看什么

- Connect 页能列出同一局域网里的 Gateway，说明网络这层通了；
- 批准后 `openclaw nodes status` 里出现手机节点，聊天页就能选会话发消息了；
- 想用语音、想让助手读通知或拍照，去设置里逐项开授权，用不到的保持关闭。

装好了但一直连不上，别急着重装——多半是网络或批准环节的问题，处理顺序整理在 [连不上网关的排查思路](连不上网关的排查思路.md)；配对与语音的具体玩法见 [手机端配对与语音用法](手机端配对与语音用法.md)。
