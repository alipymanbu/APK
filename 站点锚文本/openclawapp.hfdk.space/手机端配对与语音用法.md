# openclawapp 手机端配对与语音用法

> 本篇讲 openclawapp 与电脑端 Gateway 的配对方式、设备批准，以及 Mic / Talk 两种语音档位的差别。
> **相关文档**：[安卓版下载安装步骤](安卓版下载安装步骤.md) · [连不上网关的排查思路](连不上网关的排查思路.md)

## 三种连接方式，按场景挑

app 的 Connect 标签页里给了两条手动路径，同网段下还有一条自动的：

| 方式 | 适用场景 | 做法 |
|---|---|---|
| 自动发现 | 手机和电脑在同一局域网 | Settings 的 Discovered Gateways 里选中网关直接连 |
| Setup Code / 二维码 | 跨网段组网后也适用，最省事 | 电脑端 `openclaw qr` 生成，app 里扫码或粘贴 |
| 手动填写 | 发现被路由器 AP 隔离挡住时 | Advanced controls 里填主机 + 端口（默认 18789） |

私有网段地址用 `ws://` 填；跨网络远程访问建议走 Tailscale Serve 这类能提供 `wss://` 加密的路线，别把端口直接暴露到公网。

## 在电脑上批准这台设备

首次连接会在 Gateway 侧生成一条设备配对请求，要批准才生效：

```bash
openclaw devices list
openclaw devices approve <requestId>
openclaw nodes status    # 确认手机节点已连上
```

批准之后，app 以后启动会自动重连上次的 Gateway，不用每次重新配。认证信息变过的话，app 可能再发一条新请求——批准最新的那条就行。

## 语音两档位怎么选

- **Mic（说完再发）**：按住说话、松开送出，一句话一句话来，安静场合合适；
- **Talk（连续对话）**：像打电话一样连续听你说，中途可打断，戴耳机或出门走路时顺手。

回复的语音从哪来：电脑端配了语音服务（如 ElevenLabs 这类）就用它，没配的话 app 兜底走安卓系统的 TTS，嗓音一般但能用。真正的语音合成跑在 Gateway 侧，手机只负责放音。

## 手机上还有这些可开的口子

能力是逐项授权的：相机、照片、联系人、日历、通话记录、短信搜索、运动、已装应用、指定通知事件。取舍原则简单——让助手帮你看什么才开什么。另有几件容易忽略的：

- **命令审批**：Gateway 有需要批准的命令时，手机上能看脱敏预览与到期时间，直接批或驳；
- **多网关切换**：家里一台、公司一台都能配对，凭据与离线队列互相隔离；
- **Wear OS 手表**：走配对手机的连接，能选会话、语音回复、中止任务、发起 Talk。
