# 手机bt下载器挂机技巧：让长任务安静跑完

> 用手机当下载机，最怕的是熄屏变慢、流量超标、下到一半存储出问题。本篇把挂机下载的三处设置与速度排查思路一次理清，以 tTorrent 为例。

---

BT 下载的特点是任务长、连接多，这对手机的后台策略、网络条件与存储都提出了要求。想让它整夜稳定挂机，下面几处设置比任何「加速秘籍」都管用。

## 一、熄屏就停？先处理电池优化

典型表现：熄屏几分钟后速度归零或任务不动，亮屏解锁又马上恢复。这不是应用坏了，而是系统的电池优化在限制后台——安卓会在熄屏或内存紧张时回收长时间联网的应用。

通用处理路径（安卓 6+，各品牌菜单略有差异）：

1. 设置 → 应用 → tTorrent → 电池 → 电池优化 → 切到「所有应用」→ 找到 tTorrent → 选「不允许优化」；
2. 顺手检查应用信息里「后台限制」「后台运行权限」有没有被关；
3. 挂机期间关掉省电模式，让应用的通知留在通知栏——划掉通知或强制停止都会中断任务。

各品牌手机的后台策略差异很大，实在找不到入口，直接在系统设置里搜「电池优化」最快。

## 二、流量红线：仅 WiFi 模式

大文件挂机走移动网络非常烧流量。tTorrent 的设置里提供仅 WiFi 模式，出门挂机前确认它开着；版本更新后新增的下载默认也走 WiFi，保险起见定期看一眼这个开关。

## 三、存储别拖后腿

- 首次启动务必授予存储权限；标题栏出现 `Free space: 0 B` 就是权限丢了，到保存路径设置里重新选择同一文件夹即可恢复；
- 默认目录在 `/sdcard/torrent`，外置 SD 卡从安卓 5.0 起支持，但要手动授权一次，换卡后需重做；
- FAT32 分区单个文件上限 4GB，大文件建议存 exFAT 分区或内置存储；
- 1.8.5 起有「先下载到应用私有目录」的选项，SD 卡写入慢或存储框架出问题时可以试它。

## 四、速度慢的排查顺序

BT 速度的决定因素是有多少人在做种，这一条任何设置都替代不了。排查建议按这个顺序：

1. **换任务对比**：冷门种子做种 0~1 人，慢是正常的；换个热门任务就知道是种子问题还是设置问题；
2. **看时段**：部分运营商高峰期对 P2P 流量限速，换个时段对比；
3. **核对应用内设置**：下载/上传上限是否被设小、最大同时下载数是否排了队、仅 WiFi 是否开着；
4. **代理与加密**：走代理通常明显更慢，排查时先关掉；
5. **端口与 NAT**：应用支持 UPnP 与 NAT-PMP 自动映射，长期连不上 peer 时检查监听端口（默认 6890）。
