# tTorrent：安卓磁力链接下载工具的稳妥之选

> 本篇聊的是在安卓手机上跑磁力链接与种子任务这件事：一款迭代多年的 BT 客户端 tTorrent 能把手机变成什么样的下载工具，哪些功能值得注意，以及从哪里看它的详细介绍。

---

手机上下载大文件，HTTP 直链经常断、速度看源站脸色，而 BitTorrent 协议的思路完全不同：同一份文件的人越多、来源越多，速度反而越有保障。要在安卓设备上稳定承接这类任务，挑一个成熟的客户端是第一步。

## 为什么值得看 tTorrent

在安卓端的 BT 下载器里，[tTorrent](https://ttorrent.laze.skin/) 是迭代时间相当长的一个，由 tagsoft 开发，Lite 与无广告两个版本功能一致，只差广告的有无。它把手机当成一台下载机来设计，几类能力比较有代表性：

- **磁力链接直接开下**：复制 `magnet:` 链接粘贴新建任务即可；DHT 支持让没有 tracker 的任务也能连上来源；
- **多文件种子挑着下**：几十个文件的种子可以按文件优先级只取部分，0 不下载、3 最先完成；
- **顺序下载边下边看**：按片顺序取数据，视频类任务开头部分先就绪；
- **RSS 订阅自动入队**：订阅源更新出的新种子自动进下载队列，配合标签（每个标签可指定保存路径）自动分目录落位；
- **Web 界面远程遥控**：默认端口 1080，同一局域网里用浏览器看进度、加任务，还兼容 Transdroid / Transdrone；
- **网络选项齐全**：加密连接、SOCKS / HTTP 代理、IP 过滤、UPnP 与 NAT-PMP 端口自动映射。

## 界面与上手难度

tTorrent 用 Material 风格的中文界面，左侧抽屉承担状态筛选（正在下载 / 已完成 / 已暂停）与 RSS、标签、设置入口；添加磁力链接的对话框里可以改保存路径、勾选顺序下载与添加即启动。对没用过 BT 客户端的人而言，需要理解的只有两个概念：任务来自种子文件或磁力链接，文件默认落在 `/sdcard/torrent`。

## 挂机下载前的准备

长任务挂机有三件事值得先做：授予存储权限（否则标题栏会出现 `Free space: 0 B`）、打开仅 WiFi 模式（大流量不烧套餐）、把应用移出电池优化（否则熄屏后任务会被系统后台限制掐掉）。这几条的展开说明在[手机bt下载器挂机技巧](手机bt下载器挂机技巧.md)里单独整理了。
