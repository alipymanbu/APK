# 清理工具要哪些权限：Gator 的授权单与隐私现状盘点

> 清理类应用的授权单普遍偏长，本篇把 Gator 权限单里影响大的几项逐个讲清用途，顺带交代它的联网行为与隐私政策现状，给授权前一个判断依据。
> **相关文章**：[安卓清理工具怎么样](安卓清理工具怎么样.md) · [七件清理工具怎么用](七件清理工具怎么用.md)

---

清理工具的工作方式决定了它必然碰文件、碰应用列表，权限申请单因此不会短。判断的落脚点不是它申请了多少项，而是每一项是否都能对上你用得到的功能。本篇按这个思路拆 Gator 的授权单；功能层面的取舍见[安卓清理工具怎么样](安卓清理工具怎么样.md)。

## 影响大的几项权限

| 权限 | 干什么用 | 不给会怎样 |
| --- | --- | --- |
| 所有文件访问 | 扫描与清理都要读文件系统 | 核心功能基本用不了 |
| 清除应用缓存 | 缓存清理与自动清缓存都靠它 | 按应用清缓存不可用 |
| 使用情况访问 | 应用占用统计的数据来源 | 应用管理页是空的 |
| 查询全部应用 | 应用管理列出设备上全部应用 | 列表不全 |
| 无障碍服务 | 自动清理的缓存代执行 | 只影响自动清理，手动不受影响 |

前四项在首次扫描与进入应用管理时系统会逐个弹窗，按提示去设置里打开再回来重试；无障碍服务是可选项，开启路径、被系统自动关闭后的恢复办法展开在[七件清理工具怎么用](七件清理工具怎么用.md)的自动化一节。完整清单以安装时系统弹出的为准，装完想逐项复核的，到权限分析平台的公开报告页搜它的包名 `com.mitigator.gator` 即可。

## 联网行为与账号

第三方隐私分析的口径显示，较新版本只检出崩溃统计一个追踪器，更早的版本曾检出两个；应用本身没有登录账号体系，也就不存在账号注销的问题。它隐私政策的原文发布在开发者的 GitHub 页面，授权前想先读条款的可以从那里进。

## 给不给的判断法

三个问题问自己：

1. **我要用它的核心清理吗？** 要用，「所有文件访问」躲不开；
2. **我只做手动清理吗？** 是的话，无障碍服务可以不开，权限面收窄一大截；
3. **装的包来源可靠吗？** 授权级别高的工具，安装包来源比权限本身更重要，拿到安装包后先核对指纹再装。

用不到自动清理的时段，随手把无障碍开关关掉也无妨，下次要用再开——这类工具的权限应当跟着使用频率走，而不是一次给满。决定装了之后，从[七件清理工具怎么用](七件清理工具怎么用.md)的第一步开始配起；整体评价与适用人群见[安卓清理工具怎么样](安卓清理工具怎么样.md)，界面与功能细节可参考 [Gator 清理工具箱](https://gator.wrwq.fun/)。
