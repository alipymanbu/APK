# Gator 七件清理工具怎么用：从装好到跑完第一次扫描

> 本篇按「装完第一次该点哪个」的顺序，把 Gator 的权限配置、七件工具的操作路径与注意点串成一条线上手流程。
> **相关文章**：[安卓清理工具怎么样](安卓清理工具怎么样.md) · [清理工具要哪些权限](清理工具要哪些权限.md)

---

Gator 的界面是英文的，第一次打开容易在术语上卡住。本篇不逐个功能平均用力，而是按日常使用顺序把它串起来：先配权限，再跑主清理，然后按需取用单项工具，最后才是自动化。装之前想先了解它的整体口碑与长短板，见[安卓清理工具怎么样](安卓清理工具怎么样.md)。

## 第一步：把权限配齐再扫描

装好后直接点 System Cleaner 右下角的 scan，系统会接连弹出授权窗：

1. **所有文件访问**：扫描与清理的基础，按提示跳到系统设置里打开；
2. **使用情况访问**：应用占用统计的数据来源，点允许后回到应用；
3. 授权完成后回 Gator 再点一次 scan，能列出可清理项就说明配到位了。

第三类权限——无障碍服务——只有「自动清理」用得到，只做手动清理可以不开；它的取舍与开启路径单独写在[清理工具要哪些权限](清理工具要哪些权限.md)里。

## 第二步：跑一遍系统清理

扫描结果出来后，点条目左侧的眼睛图标能展开看到具体是哪些文件，勾选要删的项，点右下角的清理按钮执行。有一类条目要留意：临时 root 数据只对已 root 的设备生效，没 root 时它扫不出来或执行不了，跳过即可。

## 按需取用的五件工具

- **缓存清理（Cache Cleaner）**：按单个应用清缓存，适合「就那几个应用占得多」的场景。设置里可调最小缓存体积、是否扫系统应用，都能缩短扫描时间；
- **重复文件查找（Duplicate Finder）**：只列出不主动删，同一场景连拍留哪张自己判断，删前逐组展开核对——文件删了找不回；
- **文件搬运（Exporter）**：把选中的媒体、文档转移到 SD 卡等外置存储，没插卡用不上；提示无权限就先确认存储写入已打开；
- **存储分析（Storage Analyzer）**：按占用列出文件与应用，定位大头后再决定是删、是搬还是卸载；
- **应用管理（App Manager）**：卸载不用的应用、把安装包备份出来留存；换机或恢复出厂前记得先把备份文件挪出手机。

## 最后才碰：自动清理

Automated Cleaning 设好定时计划后到点自动执行，缓存部分靠无障碍服务代执行。它的常见失效原因是权限被省电策略收回——把 Gator 加入电池优化白名单、在手机管家里设为不清理能缓解；个别系统上权限确实保持不住，遇到就先回 System Cleaner 手动清，别反复折腾。

## 一条主线记住它

配权限 → 扫描 → 勾选清理，这条主线每天花不了一分钟；其余五件工具按需取用，自动清理留给权限稳定的设备。工具本身的定位与适用人群见[安卓清理工具怎么样](安卓清理工具怎么样.md)，授权单的逐项拆解见[清理工具要哪些权限](清理工具要哪些权限.md)；想看界面截图与更细的功能拆解，可以逛逛 [Gator 清理工具箱](https://gator.wrwq.fun/)。
