# Photoroom 抠图换背景怎么做

> 从一张普通照片到换好背景的完整路径：自动抠图、换纯色或场景背景、补阴影、导出，每一步都有省时间的做法。

## 一、主线只有四步

准备一张照片，剩下的主线是：选图 → 自动抠图 → 换背景或加效果 → 导出。手机上打开应用，在首页选相册照片或直接拍摄，应用会自动把主体从背景里抠出来，通常一两秒完成，不需要手动圈选。

识别得比较准的题材：人物、商品、宠物、家具这类轮廓清晰的物体。头发丝、玻璃杯、网纱蕾丝是共同的难点边缘，抠坏的地方用擦除 / 恢复笔刷手工补。

## 二、背景的几种换法

| 想要的效果 | 怎么做 | 适合 |
| --- | --- | --- |
| 白底 / 纯色底 | 选白色或任意颜色 | 电商主图、证件类照片 |
| 现成场景图 | 从图库挑一张 | 快速出图 |
| 自己的照片当背景 | 上传一张图 | 个性化场景 |
| 按描述搭背景 | 输入一句场景描述，自动生成 | 想要特定氛围又没素材 |

补一个 AI 阴影能让主体在新背景上"落地"，做商品图尤其有用；画面光线的方向和强度也能调，补救拍摄时光线不理想的原图。

## 三、原图决定上限

主体与背景有颜色或明暗差、光线均匀、主体完整不入杂物的照片，成功率高得多。深色头发配深色背景、聊天工具反复转发过的强压缩图、逆光照片，修起来事倍功半，直接重拍更划算。
