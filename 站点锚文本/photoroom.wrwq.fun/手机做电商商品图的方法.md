# 手机做电商商品图的方法

> 没有影棚和相机也能出图：一部手机从拍摄到上架的完整链路，白底主图、场景图、模特上身图分别怎么做。

## 一、一条链路走完

拍一张商品照 → 自动抠图 → 套白底或影棚图 → 按平台导出尺寸。拍摄环节的几条通用经验（不是某个应用的要求，但直接影响出图质量）：

- 光线均匀，宁可阴天散射光也不要直射强光，强反光的商品后面很难修；
- 背景尽量干净纯色，给抠图留余量；
- 商品摆正、占画面主体，四周留一点边。

## 二、需求对照功能

| 需求 | 用什么功能 |
| --- | --- |
| 白底、干净的主图 | 影棚图 / 白底背景 |
| 商品有立体感、不"飘" | AI 阴影 |
| 生活场景图（没条件实拍） | 按场景描述自动搭背景 |
| 服装上身效果展示 | AI 时装模特 |
| 服装平铺、无模特展示 | 隐形人台、平铺图 |
| 衣服照片有褶皱 | 熨烫 |
| 同款商品出多个配色 | 改色 |
| 图片适配上架平台 | 电商尺寸调整 |

平台预设覆盖 Shopify、Amazon、Etsy、Instagram、TikTok 等常见目标，导出时选平台即出对应尺寸，不用逐个查像素要求。

## 三、批量与额度

同款商品目录要统一风格时，把同一套处理（抠图、背景、尺寸、阴影）一次套到多张图上；批量导出按张数计入额度，30 个商品各出 4 个版本的图就是 120 次，先核对自己的套餐再批量跑。生成类功能（场景、模特）单独消耗 AI 额度，不同套餐解锁程度不同。

上架前花十秒逐张比对原图：颜色、材质、徽标有没有被改动——生成类功能对商品细节的保真度有限，吊牌小字这类位置重点看。
