# 手机上免 root 跑 adb 命令的工具怎么选

> 想改屏幕密度、调动画速度、卸载预装应用，搜到的教程却都是 `adb shell` 开头、要连电脑开终端？这一篇讲清楚免 root 的另一条路。

## 为什么 adb 命令非要连电脑

adb（Android 调试桥）的权限高于普通应用，系统默认只把这条通道开放给「通过 USB 连接的电脑」或「无线调试配对过的源」。所以论坛里抄来的命令，传统跑法是：电脑装 platform-tools → 手机开 USB 调试 → 敲命令。对只是想改几个设置的人来说，这套流程太重了。

免 root 的折中方案是借 Shizuku：它用「无线调试」这条系统自带通道，在手机本地把一个高权限进程跑起来（安卓 11 及以上全程不碰电脑）。之后凡是接入 Shizuku 的应用，都能借这条通道干活。

## ShizukuRunner 在这里面扮演什么角色

Shizuku 解决「权限从哪来」，还得有人解决「命令从哪发」。ShizukuRunner 就是一个纯粹的命令发送端：

- 界面是一面命令格子墙，默认 10 格，每格存一条命令，点运行键即执行；
- 从教程里抄来的命令去掉 `adb shell` 前缀填进去就能跑，无红字即成功；
- 长按卡片给命令起名（比如「锁 90Hz」「半速动画」），命令多时格子数可自定义；
- v17 起支持把整份命令列表导出备份，换机后一键导入。

它还有两条防误操作的底线：Shizuku 没激活时直接禁止执行，避免「以为跑成功了其实什么都没发生」；单条输出超 1000 字符会被掐断（返回值 141），防止 `logcat` 这类命令把应用卡死。

## 适合谁用

- 想「即抄即跑」：命令是社区抄来的，只差一个不用连电脑的执行入口；
- 不想 root：解锁、保修、支付环境的代价犯不上，shell 权限已经够改绝大多数设置；
- 折腾党：改 dpi、锁刷新率、充电常亮这类小调整，装一次工具长期复用。
