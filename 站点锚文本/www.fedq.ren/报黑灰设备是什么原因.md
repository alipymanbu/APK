# 报黑灰设备是什么原因

> Hunter 弹出「黑灰产设备」「当前设备环境异常」一类提示时，六类触发原因逐条对照，以及在手机上能做的排查动作。
> **相关文档**：[检测报告红项怎么看](检测报告红项怎么看.md) · [与Momo和Ruru哪个准](与Momo和Ruru哪个准.md)

「黑灰产设备」这个词看着吓人，其实它是报告里对「这台设备的环境存在异常特征」的汇总性说法——列的是机器上能查到的**客观痕迹**，不是对使用者的定性。要做的只有一件事：对照下面的清单，确认每条提示指向的改动是否发生在自己的机器上。

## 一、六类提示逐条对照

| 提示原文 | 通常指向 | 排查方向 |
| --- | --- | --- |
| 不支持 Attestation 或 AndroidKeyStore 服务被破坏 | 设备不提供密钥证明服务 | 老机型、精简过的系统常见，先确认系统是不是完整版 |
| 当前手机可能是模拟器 / 云手机 | 设备参数与真机不符 | 确认真的跑在实体手机上；分身、多开工具也会造出这种环境 |
| 检测到当前环境处于模拟器中 | 运行环境被容器包了一层 | 关掉分身/多开类工具后复测 |
| 当前设备机型 ROM 可能被修改 | 系统分区与厂商原版镜像不一致 | 回想是否刷过第三方系统、动过系统分区 |
| 查找 rwx 条目 | 存在可读写执行的挂载项 | 通常与 Root 方案残留有关 |
| 当前设备指纹可能被修改 | Android ID、MAC 等标识参数异常 | 检查是否用过改机类工具；没动过则考虑机型误报 |

除这六条外，首页偶尔还会弹「电池异常：充电功率过高」之类的单条提示。这类报的是**状态**而不是环境痕迹，单独出现不构成判定——换个充电器复测一次即可排除，两次一致就当机器固有状态记下，不影响其余项。

## 二、按情况分三种处理

**确实改过系统的**（Root、刷机、装过框架）：提示是如实记录，属于预期结果。想让相关项回到绿色，标准做法是回到厂商原厂固件——未解锁的用厂商方式恢复，已解锁的重刷原厂镜像（先备份个人数据），刷完复测。

**什么都没改过但提示仍在的**：先确认工具是同一版本（不同版本项数不同），换个时间复测排除偶发；再查机型是不是精简系统、二手收来时就带改动——这类改动不随恢复出厂设置消失；单项仍存疑的，顺着报告给的可疑路径去文件管理器里亲自核对。

**在模拟器或云手机里跑的**：前两条提示属于正常结果，不是故障。要测真机环境，把安装包装到实体手机上再跑。

## 三、别只信一个工具的判词

同一条提示，拿 Momo、Ruru 这类同类工具各跑一遍做交叉验证：两个以上工具都指向同一项，基本可以确认；只有一个报的，优先按误报处理。工具怎么搭配，见[与Momo和Ruru哪个准](与Momo和Ruru哪个准.md)。
