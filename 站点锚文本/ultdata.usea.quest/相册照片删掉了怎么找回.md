# 相册照片删掉了怎么找回

手机相册里的照片被误删，先别急着放弃——大多数情况下，照片并不是在按下删除的那一刻就消失了。本篇按「先免费、后工具」的顺序，把几种找回路径理一遍。

## 一、先翻相册自带的「最近删除」

安卓与 iOS 的相册基本都带「最近删除」或「回收站」入口，一般保留 30 天左右（以机型为准）。刚删的照片大概率还在这里，点恢复就能回到原相册，一分钱不用花、一分钟搞定。

用谷歌相册的，其回收站逻辑相同；部分品牌云相册也有各自的暂存区，都值得先翻一遍。

## 二、暂存区里没有，考虑恢复工具

过了保留期、或删除时直接跳过了暂存区，就要靠恢复工具去翻存储里残留的已删除文件。这类工具的原理是：被删文件只是被标记为「可覆盖」，在新数据写进去之前，区块内容还在。

以安卓平台的 UltData 为例，它装在手机上直接扫描，不需要 root，也不用连电脑：选图片入口 → 等扫描跑完 → 开「仅显示已删除项」筛选 → 预览确认后导出。工具介绍与获取入口可以看 [UltData 手机版介绍站](https://ultdata.usea.quest/)。

这一步有两件事决定成败：

1. **时间**：删除后每多拍一张照片、多下一个视频，可恢复的区块就少一片。想找回就立刻停手，先扫再说。
2. **预期**：删得久的可能只剩缓存缩略图，有的工具提供画质增强能改善观感，但被覆盖的原图是真正回不来了。

## 三、云端备份是最后的兜底

如果开通过厂商云服务或谷歌相册备份，登录网页版相册翻一遍——很多人开了备份却不知道去网页端看。照片类数据是最常被自动备份的类型，找回概率不低。

## 四、顺序总结

1. 相册「最近删除」→ 2. 恢复工具扫描 → 3. 云端备份翻底。三条路都空手，说明原图区块确实已被覆盖，坦然接受即可；下次删除重要照片前，先确认备份开着。

删掉的是聊天记录而不是照片的话，处理思路不一样，见 [WhatsApp聊天记录删了怎么恢复](WhatsApp聊天记录删了怎么恢复.md)；想了解免 root 恢复的边界，见 [免root恢复误删数据的方法](免root恢复误删数据的方法.md)。
