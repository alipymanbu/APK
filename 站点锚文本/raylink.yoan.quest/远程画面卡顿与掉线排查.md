# 远程画面卡顿与掉线排查

远程控制的体验九成取决于网络。手机控制电脑时遇到画面卡、操作延迟大、频繁掉线，多数能按现象对号入座。本篇按常见症状整理排查思路，工具以 RayLink 这类带连接指标显示的远控为例。

## 一、按现象对号入座

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示密码错误 | 被控端临时密码已刷新 | 回被控端主界面重读一次再连 |
| 一直转圈连不上 | 一方网络受限 | 公司/校园网常拦远程端口，手机换流量、电脑换热点再试 |
| 能连但很快掉线 | 被控端息屏、省电策略杀后台 | 给远控应用关电池优化、允许后台，被控电脑关闭睡眠 |
| 画面卡、延迟大 | 带宽不足或网络抖动 | 两端改 5GHz Wi-Fi 或有线；清晰度降到流畅档 |
| 画面黑屏或静止 | 被控端权限被系统回收 | 回系统设置补录屏/悬浮窗授权，重新连接 |

还没走通连接这一步的，先看[手机远程控制电脑的连接方法](手机远程控制电脑的连接方法.md)把基础流程跑顺。

## 二、网络层面的四个动作

1. **先测基础网络**：任一端刷视频都卡，先解决网络本身，别急着调软件；
2. **看连接指标**：连上后功能栏会显示延迟、带宽、帧率与连接方式，判断卡顿出在带宽还是画质设置，这是第一手依据；
3. **同网段走直连**：手机和电脑连同一路由器时，点对点直连通常更稳、延迟更低，传文件也快；
4. **避开受限网络**：部分办公网禁止设备互连，软件设置绕不开，换网络最直接。

## 三、画质设置与流畅的取舍

帧率与清晰度档位越高，对带宽的要求也越高。普通文档操作选流畅档完全够用；看视频、玩游戏再上高帧率档位。4:4:4 这类真彩模式建议在显卡支持、带宽富余时开启，否则反而拖累流畅度——普通远程办公保持默认档即可。

## 四、还解决不了

- 两端都升到新版本再试，版本差异有时就是问题来源；
- 被控端是安卓手机且黑屏的，先检查是不是开了防窥模式，关掉再连；
- 需要长期稳定连一台没人值守的电脑，把固定密码与自启动配好，见[无人值守连接的设置思路](无人值守连接的设置思路.md)。

更多安卓端的使用资料与界面说明，见 [RayLink 安卓端参考站](https://raylink.yoan.quest/)。
