# 手机远程控制电脑的连接方法

出门在外想操作家里或公司的电脑，手机装一款远程控制工具就能办到。RayLink 的安卓端支持双向远控：手机可以当控制端操作电脑，也能反过来被电脑接管。本篇按真实的使用顺序，把从安装到连上的完整路径理一遍。

## 一、先备齐两端

远程控制是两端的事：

- **电脑（被控端）**：安装桌面版并保持运行，主界面会直接显示本机设备码和访问密码；
- **手机（控制端）**：安装安卓版，[这里整理了安卓端的安装资源与界面速览](https://raylink.yoan.quest/)，可以先看再做。

两端都能上网即可，不要求同一网络；不过手机和电脑挂同一路由器时，通常会走点对点直连，延迟和传输速度都更好。

## 二、登录账号

安卓端打开后用手机验证码登录，新版本还提供微信、邮箱等入口，以界面实际显示为准。两端登录同一账号的好处：常用设备自动进设备列表，之后从列表里点一下就能发起连接，不用反复抄设备码。

## 三、发起连接

1. 在电脑端读下**设备码**与**访问密码**（临时密码会定期刷新，连之前看一眼最新值）；
2. 手机端填入这两项，点「远程连接」；
3. 网络正常时几秒内接通，手机屏幕上出现电脑桌面。

如果连的是一台没人守着的电脑，临时密码这条路走不通——需要提前在电脑端设自定义密码、开自启动，具体见[无人值守连接的设置思路](无人值守连接的设置思路.md)。

## 四、连上之后的常用操作

| 想做的事 | 手机上的操作 |
| --- | --- |
| 移动光标、点按 | 直接点屏幕，或切鼠标模式 |
| 打字 | 调出虚拟键盘，支持中英文输入法 |
| 滚动与缩放 | 单指滑动，双指捏合缩放画面 |
| 传文件 | 悬浮工具栏的文件传输入口，两端互传 |
| 调画质 | 工具栏里切清晰度与帧率档位，网络差先降档 |
| 防旁人围观 | 开启防窥模式，被控端屏幕停在黑幕 |

连接后的顶部工具栏还提供色彩模式切换：普通办公用默认档就够，对色彩还原有要求的设计场景再开更高档位，部分增强档位与账号权益相关，以软件内实际显示为准。

## 五、用完收尾

两个习惯值得保持：控制结束在工具栏里断开连接，别只是切走应用；临时帮别人修电脑，用完请对方改一下访问密码。

连不上、频繁掉线这类问题，按[远程画面卡顿与掉线排查](远程画面卡顿与掉线排查.md)逐条对照处理。
