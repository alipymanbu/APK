# NodeVideo 光流补帧与慢动作怎么做

> 本篇讲 NodeVideo 里做慢动作的完整链路：三个变速入口的方向、光流补帧怎么开、素材有重复帧时怎么处理。

## 一、先变速：三个入口记清方向

NodeVideo 的变速有三个入口，方向定义并不一致，先记清再动手：

| 入口 | 在哪找 | 方向 |
| --- | --- | --- |
| 伸缩 | 选中图层 → 打开时间线 → 改「伸缩」值 | 大于 1（如 3.0~5.0）是慢动作，小于 1 是加速 |
| Speed 变速 | 添加属性 → 时间 → Speed变速 | 大于 1 变快，小于 1 变慢 |
| 时间重映射 | 添加属性 → 时间 → 时间重映射 | 在时间轴上自由加时间关键点，做局部加减速与变速曲线 |

注意两点：「伸缩」改的是播放速度不是裁剪，内容不会丢；它与 Speed 变速的方向定义相反，混用时以画面实际效果为准。

## 二、慢放要丝滑：开光流补帧

慢放卡顿是因为原帧数不够用，光流补帧的作用是在原有帧之间生成中间帧：

1. 在时间轴上选中视频素材图层；
2. 点图层上部的图层菜单；
3. 选【补帧】→【光流】，参数大多数情况保持默认；
4. 返回时间轴对该图层变速，放到 0.1x~0.5x 区间慢放效果最明显。

只想给某一段做慢动作：先用剪刀把那一段切出来，再单独给这个片段开补帧，不用整条素材一起算。

## 三、两个实用选项

- **用途切换**：补帧界面可把用途设为「补帧」或「运动模糊」——后者会让快速运动出现动态模糊，跳舞、运动类视频常用；
- **去重复帧**：慢放后卡顿、跳帧、感觉补帧没效果，直接原因通常是素材里有重复帧（常见于用其他应用变速后再导出的素材），打开「去重复帧」即可。

素材选择上优先用相机/手机直拍的原文件，重复帧最少；清晰度、帧率、光线稳定度越高，补帧效果越好。

## 四、三个预期管理

- **预览不等于成品**：时间轴预览时补帧质量会被故意调低，可能出现果冻感、模糊或伪影——判断效果以导出后的文件为准；
- **耗性能**：补帧逐帧计算量大，复杂工程或长视频建议分段处理；
- **机型差异**：一部分安卓机型开光流会闪退或画面出噪点，遇到就放弃插帧、改用普通变速。

变速后原音频出现爆音或怪声：把该图层音量调到 0（静音）或直接删除音频属性，另配一条音轨。
