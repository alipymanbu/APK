# NodeVideo 节点式合成与上手路径

> 本篇解释 NodeVideo 的「节点 + 效果器」组织方式与传统轨道式剪辑的分野，并给出第一次打开后的上手路线。

## 一、节点式合成是什么意思

常见手机剪辑应用把素材一条条铺在轨道上，处理复杂画面时轨道会越堆越多、来源去向越来越含糊。NodeVideo 换了条路：图层与属性以节点方式连接，谁接到谁、参数由谁驱动，都摆在明面上——这也是它敢把调色、3D、补帧这些桌面级工具塞进手机的结构基础。

它的强项在「合成」而不是快速出片：愿意花时间调参数的人，能拿到非常细的控制权；只想简单拼接的话，用更轻量的应用反而更省事。没用过 PR、AE 这类桌面软件的话会有一段学习期，属于正常成本。

## 二、界面三块区域

打开工程后，屏幕从上到下分成三块：

| 区域 | 作用 |
| --- | --- |
| 上部：预览窗口 | 实时看画面效果，拖中间蓝色条调整大小 |
| 中部：属性面板 | 当前选中图层/参数的可调项，大部分编辑在这 |
| 下部：时间线 | 管理各图层的时间块、剪切开刀的地方 |

## 三、第一次打开按这条线走

1. **导入素材**：新建图层 → 媒体文件 → 视频，从相册选一段；拖时间轴底部移动游标，点播放预览；
2. **加属性**：点属性窗口里的加号继续叠加，大多数特效在应用内资源商店里找；数值拖蓝色条快调，点数字精确键入；
3. **打关键帧**：点参数名称展开关键帧栏，改变量自动记录关键帧；再到曲线编辑器修缓入缓出，动画立刻顺滑；
4. **理时间线、导出**：建议直接在根节点上操作，剪刀图标一分为二、长按拖动改图层顺序；导出等进度走完，工程自动存在草稿列表。

## 四、两个新手常疑惑的点

- **第一次播放特别卡**：是在等预览渲染，预览区下方绿条走完，第二遍就流畅了，不是手机出了问题；
- **预览发糊**：默认预览质量只有 50%，为了编辑流畅；导出成品用完整质量渲染，清晰度不受影响。
