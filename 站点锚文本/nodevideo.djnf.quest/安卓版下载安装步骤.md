# NodeVideo 安卓版下载安装步骤

> 本篇讲 NodeVideo 安卓版安装包怎么取、安装时怎么授权，以及覆盖安装升级、安装被拦截这几件常遇到的事。

## 一、装之前对一遍门槛

NodeVideo 对安卓设备有明确要求：Android 7.0 及以上、64 位 CPU，运存建议 4GB 起步。它做的是视频合成，多层特效与高分辨率导出都吃性能，运存紧张的机器编辑时最好清掉后台。

安装包大约 145 MB，走网盘分发：先把分享页里的 APK 转存到自己的网盘账号，再用网盘 App 下载到手机。安装包与获取入口在 [NodeVideo 介绍站](https://nodevideo.djnf.quest/) 上有完整整理，这里不重复贴。

## 二、安装四步

1. 进入网盘分享页，把 APK **转存到自己的网盘**；
2. 打开网盘 App，把 APK 下载到手机存储；
3. 点开 APK，系统提示「禁止安装未知来源应用」时选择允许——各品牌入口不同：有的在「设置 → 应用 → 特殊应用权限」，有的在「安全」设置里，给下载时用的浏览器或文件管理器授权即可；
4. 回到安装界面点安装，装完直接打开，无需联网验证。

## 三、升级与覆盖安装

NodeVideo 大约一至两周更新一版，**直接覆盖安装即可保留原有工程**，不需要先卸载。稳妥起见，升级前把重要工程先导出成视频成品——版本间的工程兼容性没有逐条说明，成品在手就不怕万一。

## 四、安装路上的坎

- **安装被拦截 / 按钮点不动**：基本是未知来源授权没给到。回想 APK 是用哪个应用下载的，去系统设置里给那个应用授权「安装未知应用」，再回安装界面重试；
- **装完打开就闪退**：多数是运存不够。清后台再开；进项目设置或性能选项把预览分辨率、预览帧率调低；
- **怀疑文件下坏了**：重新下载一次即可，损坏多发生在传输途中。
