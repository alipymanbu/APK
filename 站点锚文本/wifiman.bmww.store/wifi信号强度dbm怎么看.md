# WiFi 信号强度 dBm 怎么看

> 判断无线环境好坏，最省事的办法是学会读那一个数字。本篇讲 dBm 的读法、通用参考区间，以及几处容易误读的地方。

## 一、dBm 是个什么数

dBm 是功率的绝对值表示，在手机上看到的 WiFi 信号读数都是负数，比如 -50、-67、-78。判断方向只有一条：**越接近 0 越好**。-50 比 -70 强得多，-90 基本等于断线边缘。

很多人以为"数字大 = 信号好"，看到 -30 以为是弱信号——恰好相反，-30 属于贴着路由器的顶级读数。

## 二、通用参考区间

不同环境会有些出入，下面这套区间是广泛使用的经验值，够用来做日常判断：

| dBm 区间 | 含义 | 日常体验 |
| --- | --- | --- |
| ≥ -50 | 极佳 | 满格，速率跑满 |
| -50 ~ -60 | 很好 | 刷视频、视频通话都稳 |
| -60 ~ -70 | 够用 | 正常使用，高峰期可能卡 |
| -70 ~ -80 | 边缘 | 加载明显变慢，容易掉线 |
| ≤ -80 | 不可用 | 基本连不上 |

记录读数时顺带看一眼频段：同样的位置，2.4 GHz 往往比 5 GHz 高出 10 dBm 上下——这不是信号变好了，是穿墙能力不同。

## 三、去哪里看这个数字

安卓系统自带的 WiFi 列表只给大概的格数，想看连续变化还得用专门工具。安卓上可以试试 [WiFiman 读数指南](https://wifiman.bmww.store/) 里介绍的免费工具：它的信号页会实时画出 dBm 曲线，走动时曲线怎么起伏一目了然，页面还会按"非常好 / 一般"给出口径提示。

看曲线比看瞬时数字有用得多：站定三秒读一个数，不如观察曲线在哪个房间开始下滑。

## 四、三处常见误读

1. **把信号当速度**。-55 只说明无线链路质量好，实际网速还取决于宽带套餐、网关负载和信道拥挤程度，两件事要分开看（链路怎么拆，见[wifi测速慢是路由器还是宽带.md](wifi测速慢是路由器还是宽带.md)）。
2. **隔着墙读数就沮丧**。混凝土承重墙衰减 15~20 dBm 很正常，读数低先想位置，别急着换设备。
3. **只在一个房间测**。单点读数说明不了覆盖，要按房间逐个记录才有结论（方法见[家里wifi信号死角怎么排查.md](家里wifi信号死角怎么排查.md)）。
