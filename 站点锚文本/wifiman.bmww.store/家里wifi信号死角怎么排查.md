# 家里 WiFi 信号死角怎么排查

> 房间一多，总有一两个位置刷不出网页。本篇给一套十分钟就能走完的排查流程：逐个房间记录读数、圈出死角、再决定是挪路由器还是补节点。
> **相关文档**：[wifi信号强度dbm怎么看.md](wifi信号强度dbm怎么看.md) · [wifi测速慢是路由器还是宽带.md](wifi测速慢是路由器还是宽带.md)

---

## 一、死角长什么样

死角不是"完全没信号"才算。真正影响使用的是读数落在 -70 dBm 以下的位置：格数看着还有两三格，视频已经开始转圈。排查的目标就是把这类位置找出来，而不是等它彻底断网。

## 二、十分钟排查流程

1. **定基准**。站在路由器旁半米处记一次读数，这个数是全屋的"天花板"（通常在 -30 ~ -40 之间）。
2. **按房间走一圈**。每个房间选常坐的位置（沙发、书桌、床头），站定后等读数稳定再记录。用能画实时曲线的工具会快很多——安卓上 [WiFiman 读数指南](https://wifiman.bmww.store/) 介绍的信号页就是做这件事的，曲线在哪个门口开始下坠，当场就能看见。
3. **顺手记下频段**。2.4 GHz 与 5 GHz 分别记一遍，别混在一张表里。
4. **圈出 -70 以下的位置**，连成一片的就是死角区。

记录可以用手机备忘录，格式越简单越好：

```
客厅沙发      -48  ✓
主卧床头      -66  ✓
书房书桌      -74  ✗
厨房          -81  ✗
```

## 三、对着结果做处置

| 排查结果 | 优先动作 |
| --- | --- |
| 只有死角房间差 | 挪路由器：往屋子中心、离地 1~1.5 米、别塞进弱电箱 |
| 承重墙另一侧差 | 5 GHz 穿不过混凝土，给那侧补一个节点或改连 2.4 GHz |
| 全屋普遍偏低 | 查路由器摆位与天线角度；仍低再考虑设备能力 |
| 单一频段差 | 该频段信道拥挤，进路由器后台换信道 |

## 四、两个提醒

- 安卓 9 及以上系统对应用的 WiFi 扫描做了节流（每两分钟最多四次），扫描类页面不会秒刷，等一个周期再看，别当成手机坏了。
- 挪完路由器或加了节点，把第二节的流程重走一遍，用前后两组读数确认改善幅度——比"感觉快了"可靠得多。
