# WiFi 测速慢：路由器问题还是宽带问题

> 网速一慢就怪运营商，未必冤枉。本篇把"家里这条链路"拆成三段，给一套逐段判定的思路，顺带讲两个最常被忽略的无线侧瓶颈。
> **相关文档**：[wifi信号强度dbm怎么看.md](wifi信号强度dbm怎么看.md) · [家里wifi信号死角怎么排查.md](家里wifi信号死角怎么排查.md)

---

## 一、先把链路想清楚

你家手机到互联网，实际走的是三段：

```
手机 ──无线──> 路由器/网关 ──线路──> 运营商网络 ──> 目标网站
```

慢可能出在任何一段。测速慢先分段，再动手，别一上来就打电话报修。

## 二、分段判定表

| 现象 | 大概率在哪一段 | 怎么验证 |
| --- | --- | --- |
| 网线直连电脑跑满速，手机就是慢 | 无线段 | 看下面第三节 |
| 所有设备（含网线）都慢 | 运营商段 | 避开晚高峰再测一次；仍慢报修 |
| 个别时段慢，其余正常 | 运营商段或网关过热 | 记录时段，重启网关对比 |
| 内网传文件都慢 | 无线段或路由器本身 | 见下面的设备对测 |

## 三、无线段最常见的两个瓶颈

**信号强度。** 手机在 -70 dBm 以下时，速率下降是物理规律，换什么测速软件都一样。先按[家里wifi信号死角怎么排查.md](家里wifi信号死角怎么排查.md)把读数摸一遍，确认手机所在位置的信号底子。

**信道宽度。** 这是隐藏最深的一项：路由器明明支持高速率，实际却只协商在 20 MHz 信道宽度上，速度因子直接被打成"一般"。专业一点的测速工具会把这项摆出来——[WiFiman 读数指南](https://wifiman.bmww.store/)里介绍的测速页就会同时给出信号、信道宽度与综合速度因子，并直接建议"增加信道宽度"。遇到这种情况，进路由器后台把 5 GHz 的信道宽度调到 80 MHz，往往立竿见影。

## 四、用设备对测跳过宽带段

怀疑路由器本身慢、又不想被宽带套餐干扰判断时，可以做内网对测：两台设备连同一个接入点互测吞吐。这样测出来的是"无线 + 路由器"的净能力，与宽带上下行完全无关。这个结果如果都不理想，报修解决不了问题，重点该放在无线侧。
