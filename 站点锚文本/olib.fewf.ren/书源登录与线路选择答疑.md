# Olib 书源登录与线路选择答疑

> 本篇集中回答 Olib 用起来最容易卡住的几个问题：为什么打开就要登录、线路是什么、搜不到书与下载打不开怎么办。安装流程见 [安卓版获取与安装步骤](安卓版获取与安装步骤.md)，导入本地书见 [本地书导入与阅读排版](本地书导入与阅读排版.md)；功能总览可到 [Olib 安卓阅读客户端介绍站](https://olib.fewf.ren/) 查看。

## 一、为什么打开就要求登录

Olib 是第三方阅读客户端：项目方只做了界面与阅读功能，在线搜书、下载书的数据全部来自外部书源。因此：

- 应用本身不发账号，登录用的是外部书源侧注册的邮箱和密码；
- 1.0.6 这一版启动后要先过登录这一关，「跳过登录」入口是后续版本才加入的；
- 不想注册书源账号也能用：把电子书文件拷进手机做本地阅读，全程不依赖账号（做法见 [本地书导入与阅读排版](本地书导入与阅读排版.md)）。

## 二、线路是什么、怎么选

「线路」指连接书源用的不同服务器入口，同一个账号在不同线路上都能登录。应用内置 Line 1–4（CN）与 Global 多条线路，还支持填自定义域名。选择没有玄学，按这个顺序试：

1. 默认线路先试一次；
2. 登录超时或搜索一直转圈 → 换一条线路再登录；
3. 换线路后要重新搜一次，原来的搜索结果不会自动刷新。

## 三、搜书与下载的排查

**搜不到想要的书**，按这个顺序换检索方式：

1. 核对关键词拼写，外文书优先用原名而不是译名；
2. 换「作者名 + 书名」组合，或直接用 ISBN 检索；
3. 换一条线路重搜，结果可能随线路不同；
4. 冷门书长期搜不到，就自己找文件走本地导入。

**下载下来的书打不开**：先确认文件完整（中途断网容易产出半截文件），删掉重下；仍不行就转成 epub 或 txt 再导入，兼容性最好。

## 四、登录失败速查表

| 现象 | 先检查什么 |
| --- | --- |
| 一直转圈不出结果 | 换一条线路；确认手机能正常上网 |
| 提示密码错误 | 确认登录的是书源账号，不是把应用当成有独立账号的软件 |
| 账号密码正确仍失败 | 书源侧可能限制登录频率，隔一段时间再试或换线路 |
| 之前能用现在不行 | 书源侧入口会变化，关注项目页的说明 |

## 五、更新与版本差异

1.0.6 没有应用内「一键更新」（后续版本才加入），要手动下载新 APK 覆盖安装；覆盖前把重要的本地书文件在电脑上留一份。寻书、无线传书、扫码登录等都是更新版本才有的功能，装哪一版按自己的需求决定——新版本的获取方式见 [安卓版获取与安装步骤](安卓版获取与安装步骤.md)。
