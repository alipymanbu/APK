# Material You 客户端盘点：把流行应用重画一遍的开源项目

Material You（Material 3）是安卓 12 起普及的设计语言，最有辨识度的能力是**从壁纸取色**：主色不是写死的品牌色，而是从你当前的壁纸里取出来，按钮、卡片、选中态都变成同一色系的不同深浅。系统给了能力，应用愿不愿意接是另一回事——大部分主流应用并不接。

于是有一批开源项目专门干这件事：把热门 Web 应用按 Material You 的规范在安卓上重画一遍。

## Materii 家族

这个团队（GitHub 上的 MateriiApps 组织）的思路很统一，每做一个就盯准一个流行平台：

| 项目 | 对标平台 | 一句话定位 |
| --- | --- | --- |
| OpenCord | Discord | 开源的 Material You 实现，社区里知名度最高 |
| Upvote | Reddit | 可自定义的第三方客户端 |
| Gloom | GitHub | 把仓库、讨论、用户主页按阅读器的路数重排 |
| Dimett | Mastodon / Akkoma / Pleroma | 轻量的长毛象系客户端 |

全部 Kotlin + Jetpack Compose 写成，GPL-3.0 开源，翻译走 Crowdin 社区渠道。

## 取色这件事的实际体验

以其中的 Gloom 为例：装上后界面主色会跟你的壁纸走，换一张壁纸、整屏配色跟着换；深浅色则跟随系统的显示设置开关，两件事独立生效，「深色模式 + 壁纸取色」是最常见的组合。在安卓 11 及以下的旧系统上没有取色能力，只能用自带固定配色——旧机型能用，只是少了这一层。([Gloom 的界面实拍](https://gloom.kook.yoga/)可以直观感受这套配色逻辑。)

这类客户端还有一个容易被忽略的细节：内置多套启动图标。经典、风格化线条、Catppuccin 主题色这类社区流行配色都有，在桌面长按图标就能换——能不能换成取决于你的启动器给不给这个入口。

## 盘点背后的趋势

这批项目证明了一件事：设计语言不是大厂的专利。Material You 的规范是公开的，社区完全有能力把「官方没跟上」的个性化体验补齐，而且以开源协议发布、代码可查。对壁纸取色这类系统级特性有执念的安卓用户，值得把这几个项目都翻一遍。
