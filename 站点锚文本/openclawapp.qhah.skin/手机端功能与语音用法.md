# 手机端功能与语音用法

> 本篇盘点 openclawapp 连上 Gateway 之后能在手机上做的事：聊天、连续语音、命令审批、手机能力授权，以及手表上的用法。
> **相关文档**：[是什么与上手前提.md](是什么与上手前提.md) · [安卓端安装与配对连接.md](安卓端安装与配对连接.md)

---

## 聊天：会话跟着你走

app 里可以选会话、翻历史记录，发文字、图片、语音。断网时发出的消息会按 Gateway 排队，重连后按顺序送达，不会丢。除了在 app 里聊，助手还能住进 Telegram、WhatsApp、Discord、Slack、飞书等二十多种聊天渠道——在常用工具里发消息就能派活，app 反而更像一个总控台。

## 语音：两种模式

- **Mic（说完再发）**：按住说、松开送出，适合一条条下指令；
- **Talk（连续对话）**：像打电话一样连续说，适合边做事边指挥。

回复的语音用电脑端配置的语音合成服务生成，没配的话回落到安卓系统自带的合成，一样能用。

## 命令审批：敏感操作你说了算

Gateway 配置了命令审批后，助手要执行敏感命令会先发请求到手机：app 里能看到脱敏后的命令预览和有效期，直接批准或驳回。人不在电脑前也敢让它干活，靠的就是这道闸。

## 手机能力：逐项授权、逐项可关

你允许助手用手机上的什么，它才能用什么：

- 相机与照片
- 联系人与日历
- 通话记录、短信搜索
- 运动、已装应用
- 指定通知事件

原则很简单：让助手帮你看什么才开什么，用不到的当场关掉。多台 Gateway 混用时，同一时间只有「焦点」网关能调用手机能力，避免两边的助手同时指挥一部手机。

## 还有这些

- **工作区文件**：只读浏览助手的工作区，预览文本或图片，能通过系统分享导出；
- **多网关切换**：家里一台、公司一台都能配对，Settings → Gateway 里切换，凭据与离线队列互相隔离；
- **Wear OS 手表**：手表不存网关凭据、走配对手机的连接，可以选会话、语音回复、中止正在跑的任务、发起实时 Talk。
