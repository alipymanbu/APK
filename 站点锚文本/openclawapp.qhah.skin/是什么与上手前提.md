# openclawapp 是什么与上手前提

> 本篇讲 openclawapp 的定位：它是开源个人 AI 助手 OpenClaw 的安卓端节点，本身不独立运行助手。弄清架构再动手，能少走大部分弯路。

## 一句话定位

OpenClaw 是一款按 MIT 协议开源的自托管个人 AI 助手：Gateway 跑在你自己的电脑上，接你选的 AI 模型，能真正执行任务——整理文件、读写内容、跑脚本、控制浏览器完成检索。项目在 GitHub 上有 59K+ Stars、309 位以上贡献者，可接入的平台与技能超过 50 种。

openclawapp（包名 com.openclaw.ai）就是这套系统的安卓端应用。它的角色是「随身节点」：在 WhatsApp、Telegram 这类常用聊天工具里给助手派活，也能在 app 里直接对话、发语音、审批助手要执行的命令。

## 架构：两端分工

| 部分 | 跑在哪 | 负责什么 |
|---|---|---|
| Gateway | 电脑：macOS / Linux / Windows | 接 AI 模型、执行任务、管理会话与渠道 |
| 安卓端 app | 手机 | 聊天与语音入口、命令审批、把手机能力按授权开放给助手 |

动手型的活都由电脑端完成，手机端负责「随时使唤 + 批准」。这个分工决定了它的上手顺序：先电脑后手机。

## 三个上手前提

1. **一台能常开的电脑**：Gateway 要在后台跑着，手机端才有可连的对象。安装是一条命令的事，向导会带着选模型服务商、填 API Key。
2. **一个模型 API Key**：助手的能力来自你接的模型——Anthropic、OpenAI、Google、DeepSeek 都可以，也能用 Ollama 接本地模型。软件本身无订阅，费用取决于模型用量。
3. **网络互通**：手机和电脑最好在同一局域网；出门在外用 Tailscale 这类组网工具连回来，不要把 Gateway 端口直接暴露到公网。

## 适合谁用

愿意自己维护一台「永远在线」的电脑、对隐私和可控性在意、想让自己的助手住进日常聊天工具的人。如果你只想装一个 app 就开箱即用，这套架构会显得麻烦——它确实需要一点动手意愿。
