# 安卓端安装与配对连接

> 本篇讲 openclawapp 从安装包到连上电脑端 Gateway 的完整流程：装 apk、放行未知来源、配对批准，以及连不上时的排查顺序。
> **相关文档**：[是什么与上手前提.md](是什么与上手前提.md) · [手机端功能与语音用法.md](手机端功能与语音用法.md)

---

## 安装前确认两件事

- 电脑端 Gateway 已经装好并在运行：`openclaw gateway status` 能看到 18789 端口在监听；
- 手机系统为 Android 5.2 及以上。

安卓端的安装包是一个 apk 文件（10.0 版、约 6.7MB），安装文件资源的获取入口在 [openclawapp 介绍站](https://openclawapp.qhah.skin/)的下载页，从网盘转存后即可取出。

## 四步装好

1. **转存并下载**：打开网盘分享页，把 `openclawapp_v10.0.apk` 转存到自己的网盘空间，再下载到手机存储。
2. **放行未知来源**：首次点开 apk，系统会提示「禁止安装未知应用」。在弹窗里选「仍要安装」，或到 设置 → 应用 → 特殊权限 → 安装未知应用，给浏览器或文件管理器放行。
3. **完成安装**：装完后桌面出现龙虾图标的 app。
4. **连接并批准**：确认电脑端在跑，然后按下面的方式连接；首次连接要在电脑端批准设备。

## 三种连接方式

| 方式 | 适用场景 | 怎么做 |
|---|---|---|
| 自动发现 | 手机和电脑在同一局域网 | 打开 app 的 Connect 标签页，在 Discovered Gateways 里选中网关 |
| Setup Code / 二维码 | 跨网段、组网后最省事 | 电脑端 `openclaw qr` 生成，app 里扫码或粘贴 |
| 手动填写 | 路由器开了 AP 隔离等情况 | Advanced controls 里填电脑 IP + 端口（默认 18789，私有网段用 ws://） |

首次连接会在 Gateway 侧生成一条设备配对请求，需要批准才生效：

```bash
openclaw devices list
openclaw devices approve <requestId>
openclaw nodes status    # 确认手机节点已连上
```

批准之后 app 以后启动会自动重连，不用每次重新配。

## 连不上时的排查顺序

自动发现失败 → 先确认两端在同一网段（访客网络、手机流量都不行）→ 不行就手动填电脑 IP + 18789 → 跨网络就让两端进同一 Tailscale 网络再连。

两个高频细节：

- **连上又频繁掉线**：app 靠一条前台服务保活，通知栏的常驻通知别关；把 app 加入电池白名单、允许自启动，各厂商安卓的后台策略一般就掐不断它了。
- **扫了配对码没反应**：先看电脑端有没有待批准的设备请求（`openclaw devices list`），凭据变过的话 app 会重新发起一条，批准最新的那条即可。

装好连上之后能玩什么，见 [手机端功能与语音用法.md](手机端功能与语音用法.md)；架构与前提的背景说明见 [是什么与上手前提.md](是什么与上手前提.md)。
