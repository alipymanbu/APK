# 脚本进阶：打包独立应用与电脑联调

> 脚本在手机上跑顺之后，通常会走两条进阶路：把脚本打包成独立 APK 分给别人，或用电脑的
> VSCode 写代码、手机同步运行。这篇把两条路的步骤与坑一次讲完。

## 一、把脚本打包成 APK

Auto.js 免费版自带打包功能，能把写好的脚本变成独立安装包，别人不装 Auto.js 也能运行：

1. 在主界面**长按**脚本（或脚本所在文件夹），弹出菜单里选「打包」；
2. 填应用名称、包名、版本号，按需勾选权限（截图、网络等用到什么勾什么）；
3. 等打包完成，生成的 APK 路径会出现在通知里，装到任意安卓手机即可。

几个实际会碰到的事：

- 打包出的应用第一次启动同样要开**无障碍服务**，且不会自动跳转设置页，别忘了交代；
- 免费版打包**没有代码加密**，脚本内容可以被还原，别把带账号密码的代码打给不熟的人；
- 脚本不止一个、或要带图片等资源时，用「项目」方式：主界面「+」→ 新建项目，把脚本和资源
  都放进项目目录再对整个项目打包，界面里引用同目录图片写相对路径即可。

## 二、用 VSCode 在电脑上写、手机上跑

脚本稍长就会发现手机小屏改代码很折磨。思路是：电脑装插件起服务，手机连过来，代码在电脑上
写、一键推到手机运行。

1. **电脑端**：安装 Visual Studio Code，扩展市场搜 `Auto.js-VSCodeExt`，装好后按
   `Ctrl+Shift+P` 执行「Start Server」；
2. **手机端**：打开 Auto.js → 侧边栏 →「连接电脑」，输入电脑的局域网 IPv4 地址
   （电脑上 `ipconfig` 可查）；
3. 之后在 VSCode 里打开 `.js` 文件，命令面板搜 Auto.js 命令：「Run」在手机上运行当前脚本，
   「Save」把文件保存到手机。

两端必须在同一局域网；公司或校园网常做设备隔离，连不上时开手机热点最快。调试期把
`console.log` 打满，日志会在 VSCode 输出面板实时滚动，比在手机上看舒服得多。

## 三、场景分工建议

| 场景 | 建议做法 |
| --- | --- |
| 短脚本、临时改几行 | 直接手机编辑器改，够用 |
| 写完整项目 | VSCode 写 + 保存即推送，代码留在电脑好备份 |
| 给别人用 | 打包 APK，按第一节清单交代权限与环境 |

还没跑通第一段脚本的话，先回 [手机自动化脚本入门](手机自动化脚本入门.md)；
打包应用要开的无障碍等权限，细节在 [无障碍服务与权限设置](无障碍服务与权限设置.md)；
工具的版本辨析与安装入口，见 [auto.js 专题介绍站](https://auto-js.gerw.hair/)。
