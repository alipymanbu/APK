# 手机自动化脚本入门：安卓上是怎么做到「自己会动」的

> 想让手机自动签到、自动整理文件、自动重复某串点击操作，绕不开「手机自动化脚本」这个圈子。
> 这篇先把原理和选型讲清楚，再看具体工具怎么上手。

## 一、手机自动化的两条技术路线

安卓系统上的自动化，常见有两条路线：

1. **Root 后注入**——拿到系统最高权限，直接注入点击事件。自由度最高，但 Root 本身门槛高、
   会破坏保修与银行类应用的运行环境，普通用户基本不会选。
2. **无障碍能力**——系统为视障用户提供的一套「读屏幕 + 操作屏幕」接口，自动化工具借用它来
   读取界面上的控件、执行点击与滑动。**不需要 Root**，系统也允许用户随时开关，是目前社区
   主流的做法。

Auto.js 走的就是第二条路线：它是 2017 年开源的一款安卓应用，内置 JavaScript 编辑器与运行引擎，
脚本里写 `text("蓝牙").findOne(5000).click()` 这样的代码，背后是无障碍服务在替你查看屏幕、执行点击。

## 二、这类脚本适合做什么

从社区里大量被反复提及的场景看，集中在三类：

- **重复操作代劳**：每天固定顺序点开的签到、打卡、领取类按钮，写一次脚本天天省事；
- **批量整理**：批量重命名文件、按规则归档下载目录、定期清理缓存；
- **界面联动的效率工具**：比如连接电脑后把通知转发到桌面、定时截屏记录等。

反过来，有两类需求并不适合：违反应用服务条款的批量操作（账号风险自担，工具本身也保证不了稳定性），
以及依赖游戏内自绘界面精细操作的场景——自绘界面读不出控件，只能退化为坐标点击，稳定性会明显下降。

## 三、上手路径长什么样

以 Auto.js 4.1.1 开源版为例，从装好到跑通第一段脚本通常是三步：

1. 开启无障碍服务与悬浮窗权限；
2. 用悬浮窗里的「布局分析」查看目标控件的文字、ID 属性；
3. 新建脚本，把属性填进选择器，点运行。

应用内自带「示例」文件夹和入门教程，覆盖启动应用、找控件、截图找图等常见场景，每个都能直接
运行看到效果。完整的图文步骤与常见卡点，整理在 [auto.js 专题介绍站](https://auto-js.gerw.hair/)
里，配合 [无障碍服务与权限设置](无障碍服务与权限设置.md) 一篇操作最顺。

## 四、选哪个版本

搜「Auto.js」会同时看到免费开源版、付费 Pro 版，以及社区接续的 AutoX、AutoJs6 等分支。简单说：
免费开源版停在 4.1.1（2020 年），胜在无广告、不注册；社区分支对新版安卓适配更勤；付费版多了
OCR、代码加密等能力。它们的包名互不相同，装之前在系统「应用信息」里核对一眼就能分辨。

进阶玩法（打包独立应用、电脑上写代码手机跑）见 [脚本进阶：打包与电脑联调](脚本进阶打包与电脑联调.md)。
