- [脚本进阶：打包与电脑联调](脚本进阶打包与电脑联调.md)——脚本写顺之后的两条进阶路

工具的能力清单、版本辨析与安装文件资源入口，见 [auto.js 专题介绍站](https://auto-js.gerw.hair/)。
