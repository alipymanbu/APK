# 音高监测器怎么用：从装好到看懂那条曲线

> 本篇讲 Monitor 这类音高监测工具的用法：界面怎么读、三步上手、常用设置怎么调，以及练多久能看出变化。
> **相关文档**：[唱歌音准怎么练](唱歌音准怎么练.md) · [伪声练习的音高反馈工具](伪声练习的音高反馈工具.md)

音高监测器（pitch monitor）做的事情很简单：把麦克风收到的声音，实时画成一条随音高起伏的曲线。横轴是时间，纵轴是音阶刻度，你在哪个音上，曲线就停在哪一行。它不修音、不评分，只负责让你「看见」自己的音高——而这恰恰是练声最缺的一块反馈屏。

## 一、界面只需要认识四个部位

| 部位 | 含义 |
| --- | --- |
| 横轴 | 时间，越靠右越是刚刚发出的声音 |
| 纵轴 | 音阶，从 C1 覆盖到 B7 共七个八度 |
| 顶部大字 | 当前判到的音名（如 A4），扫一眼就知道落在哪 |
| HOLD 键 | 定格画面细看，再点一次恢复实时 |

读懂这四处，就足够开始练了。剩余的按钮（录音、回放、设置）用到再看，不构成上手门槛。

## 二、三步上手

1. **给麦克风权限**：装好后第一次打开会请求麦克风，允许它——没有输入，一切都画不出来；
2. **哼一个长音**：随便哼一个舒服的音，保持两三秒，看曲线稳定停在哪个音名上；
3. **对照目标音**：用钢琴或参考音源给一个音，哼同样的音，看两条线是否落在同一行。

第三步对上了，说明检测链路没问题，之后就可以进入正式练习。

## 三、常用设置只动两处

- **音阶标尺（Scale）**：默认 C 大调。练其他调的曲子时换成对应调式，目标行的位置会更好认；
- **Hz 显示**：勾上之后除了音名还能读出频率数值，做声音训练、对照参考区间时更直观。

每个音符还可以单独设颜色，把练习的目标音标成醒目色，练习时扫一眼就能确认到位没有。

## 四、练多久能看到变化

以长音为例：第一天大多数人的曲线都是「波浪线」，坚持每天录一段、回放对照，一到两周就能看到曲线明显变平——这不是天赋问题，是反馈频次问题。把每次的录音存下来隔几天对比，进步看得见。
