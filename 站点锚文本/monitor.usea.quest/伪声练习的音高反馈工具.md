# 伪声练习的音高反馈工具：盯着曲线找位置

> 声音女性化（MTF）练习里，音高只是其中一个维度，却是最先能「看见」的一个。本篇整理流传较广的练习配置、参考区间与日常流程。
> **相关文档**：[音高监测器怎么用](音高监测器怎么用.md) · [唱歌音准怎么练](唱歌音准怎么练.md)

## 一、为什么练伪声要先盯音高

自己听自己的声音不可靠：骨传导与多年习惯会让「自我感觉」严重失真。实时曲线的价值在于把说话音高变成看得见的读数——你现在落在哪个区间、往上抬了多少、句尾掉没掉回去，屏幕不撒谎。

社区里被反复推荐的一款工具就是 Monitor（安卓端），不少用户在商店评价里提到拿它做伪声练习。工具的安装与界面读法见 [Monitor 音高监测器介绍页](https://monitor.usea.quest/)。

## 二、流传较广的配置（两步）

1. **音阶（Scale）设为 F 大调**：F2、F3 等参考线会出现，说话音高落在哪一目了然；
2. **勾选以 Hz 显示频率**：除音名外直接读出频率数值，方便对照区间练习。

配置来自流传较广的英文声音训练笔记，两项设置在应用的设置菜单里都能找到。

## 三、参考区间（仅供定位，不是标准）

| 参考 | 数值 |
| --- | --- |
| 偏男性说话音高 | 约 85~155 Hz |
| 偏女性说话音高 | 约 165~255 Hz |
| 部分社区指南建议的练习下限 | 不低于 G3（约 196 Hz） |

人与人差异很大，这些数值只用来定位起点，别硬凑。

## 四、日常流程

1. **记基线**：用平常的声音录一段短文朗读，看曲线自然停留的区间，这就是起点；
2. **抬音**：把整段说话位置往上移，目标是稳定停在一个更高、且发着不累的位置——注意是整段上移，不是用假声顶上去；
3. **句尾上扬**：读句子时刻意让句尾比句首高一点、下句开头再落回，图上应出现一个个起伏的小弧线，而不是一条死平的线；
4. **定期对比**：每天固定录一小段，隔几天加载旧录音对比区间有没有整体移动。

单段录音上限 3 分钟，读短文足够；录音可通过系统分享导出存档。

## 五、音高之外的维度

音高到位但听感不对，是练习初期的正常阶段——共振位置、气息声、说话节奏同样影响「听感」，而这些在音高图上看不出来。把音高当第一个抓手，别当唯一目标。

另外它只判单音，练习时别开伴奏或电视，否则曲线乱跳会影响判断。基础用法与界面读法见 [音高监测器怎么用](音高监测器怎么用.md)，唱歌向的练习思路见 [唱歌音准怎么练](唱歌音准怎么练.md)。
