# KsuWebUI 资料目录

> 围绕 KsuWebUI（打开 Root 模块网页界面的独立宿主应用）整理的第三方资料：Magisk 下界面打不开的处理、找不到界面宿主提示的应对，以及模块网页界面自身的工作原理。

这个应用做的事很简单：KernelSU 模块可以自带一套网页界面，而这份界面需要一个应用来加载，KsuWebUI 就是那个加载器，适配 KernelSU、Magisk、APatch 三类环境。想了解它的入口机制、适用场景与安装过程，见 [KsuWebUI 介绍站](https://ksuwebui.wrwq.fun/)。
