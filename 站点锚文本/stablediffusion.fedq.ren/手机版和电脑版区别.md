# stablediffusion 手机版和电脑版区别

> 搜「stablediffusion」的人，想找的往往是两种完全不同的东西：手机上点选出图的 App，和电脑圈常说的本地部署「跑 SD」。同名不同形，这篇帮你判断该用哪个。决定装手机版的话，步骤在 [手机上怎么下载安装](手机上怎么下载安装.md)；装好后出第一张图看 [出图提示词怎么写](出图提示词怎么写.md)。

## 一、先把名字理清楚

「Stable Diffusion」原本是一套开源的文生图模型。因为开源，它衍生出两种典型用法：

- **手机版**：把模型做成云端服务，App 只负责「选风格、写描述、点生成」，适合随手创作；
- **电脑版**：把模型装进自己的电脑，配 WebUI 界面跑图，就是玩家口中的「本地部署」。

两者用的是同源的文生图技术，提示词写法也相通，但使用门槛和自由度完全是两回事。

## 二、逐项对比

| 对比项 | 手机版 | 电脑版（本地部署） |
| --- | --- | --- |
| 安装 | 装个 APK 就能用 | 配 Python 环境、下数 GB 模型 |
| 硬件 | 普通安卓手机即可 | 基本要独立显卡，显存越大越顺 |
| 出图在哪算 | 云端服务器 | 自己的显卡 |
| 参数控制 | 点选式，简单 | 采样器、步数、CFG、分辨率全可调 |
| 模型 | 内置风格分区，不能随意换 | 社区模型、LoRA 随便挂 |
| 上手时间 | 几分钟 | 几小时起步，还得会查报错 |

一句话：**手机版买的是省事，电脑版买的是控制权。**

## 三、怎么选

- 做头像、壁纸、朋友圈配图，或没有独立显卡、不想碰命令行——手机版足够；
- 要精确控制构图姿态、挂 LoRA 固定画风、批量跑图，或把折腾环境当乐趣——值得上电脑版；
- 更多人的真实用法是两边都用：手机上快速出小样、试风格，方向定了再搬到电脑上用同样的提示词精修。

手机版的界面、风格分区和获取入口整理在 [stablediffusion 手机版介绍站](https://stablediffusion.fedq.ren/)，可以先去看看界面截图再决定装不装。
