# stablediffusion 手机上怎么下载安装

> 想在安卓手机上用 stablediffusion 出图，第一步就是把 APK 装进去。这篇按「安装包从哪来 → 怎么装 → 装不上怎么排查」的顺序整理，出图之后的事见 [出图提示词怎么写](出图提示词怎么写.md)；还在犹豫装不装的，先看 [手机版和电脑版区别](手机版和电脑版区别.md)。

## 一、安装包从哪来

stablediffusion 手机版不在应用商店上架，以 APK 安装包形式分发。比较省心的做法是从 [stablediffusion 介绍站的下载页](https://stablediffusion.fedq.ren/download.html) 进网盘获取：打开分享链接 → 「保存到网盘」转存到自己账户 → 把文件夹里的 APK 下载到手机本地存储。

也可以在电脑上完成转存和下载，再用数据线、微信文件传输助手之类的途径把 APK 传到手机，效果一样。

## 二、四步装好

1. 手机文件管理里点开下载好的 APK；
2. 系统提示「禁止安装未知来源应用」时，点「设置」→ 打开「允许安装未知来源应用」→ 返回继续（小米的入口叫「允许安装未知应用」，华为在「更多安全设置」里）；
3. 等安装进度走完；
4. 点「打开」或回桌面点图标。

装完如果近期没有别的安装需求，建议把「允许安装未知来源」的开关关回去，减少误装来路不明软件的风险。这份安装包约 20.3 MB，安卓 5.2 以上机型可装，v5.3 已兼容更多 Android 12+ 机型。

## 三、装不上的三种常见情况

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 提示「解析包错误」或点了没反应 | 下载不完整 | 删掉安装包，重新转存下载，核对大小与 20.3 MB 差得不多再装 |
| 提示「应用未安装」 | 手机里有同包名旧版本 | 先卸载旧版再装（会清应用内数据，图片先导出） |
| 装到一半退出或开了就闪退 | 存储不足或系统太旧 | 清出 1 GB 以上空间；反复闪退就换系统更新的手机验证 |

## 四、装好之后

第一次打开会看到按风格分区的作品墙（古风、二次元、唯美梦境等）。想直接抄作业，就在作品墙挑一张点「制作同款」；想自己写描述，先过一遍 [出图提示词怎么写](出图提示词怎么写.md) 里的三段式公式。更多界面说明与功能整理，都在 [stablediffusion 安卓介绍站](https://stablediffusion.fedq.ren/) 首页。
