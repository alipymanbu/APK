# 正浩户外电源 App 连接与配网指南

> 本篇讲正浩（EcoFlow）户外电源配套手机应用的连接方式选型与配网实操，覆盖 IoT / 直连 / 蓝牙三种方式的取舍、五步配网流程和连不上时的排查思路。相关文档：[DELTA 与 RIVER 户外电源怎么选](DELTA与RIVER户外电源怎么选.md)、[太阳能板充电搭配使用经验](太阳能板充电搭配使用经验.md)。

把户外电源用顺手的第一步，就是把它连进手机 App。很多人在「连接方式」这一步就卡住，其实理清思路后并不复杂。

## 三种连接方式，先选对再连

正浩电源在 App 里支持三种连接方式，差别主要在「要不要经过路由器」：

- **IoT 模式（首选）**：设备接入家庭 Wi-Fi 后常驻互联网，人在外面也能远程看电量、改设置。缺点是依赖家庭网络的可用性，断网时设备会显示离线。要接收固件升级推送，也必须走这条路。
- **直连模式（户外）**：手机直接连接设备发出的热点（以 EcoFlow_ 开头命名），没有互联网也能实时查看和控制，适合山里、营地等没有 Wi-Fi 的场景。代价是手机这个阶段上不了网，设备列表里也只显示这一台机器。
- **蓝牙模式（近场）**：支持蓝牙的机型可以在近场直控，打开手机蓝牙进 App 首页，弹窗发现设备后点添加即可。蓝牙连上后还能继续完成配网，升级到 IoT 模式。

一个原则：**家里用就配 IoT，户外用就切直连，临时看一眼用蓝牙**。

## 五步完成配网

以最常用的 IoT 模式为例：

1. 设备开机，确认屏幕亮起、电量充足；
2. 打开 App，在设备列表页点右上角「+」，选择对应型号；
3. 按 App 提示长按机身的 IOT RESET 键约三秒，听到蜂鸣声、屏幕 Wi-Fi 图标开始闪烁后回到 App 勾选确认；
4. 切到手机的 Wi-Fi 设置，找到以 EcoFlow_ 开头的热点并连接，成功后返回 App；
5. 在互联网接入配置页选中家庭 Wi-Fi、输入密码，等待提示「设备已连接」。

过程中手机会断网一两分钟，属正常现象。

## 连不上时的三个排查方向

- **搜不到家庭 Wi-Fi**：设备目前只认 2.4GHz 频段，5GHz 是搜不到的。双频合一的路由器建议到后台把 2.4GHz 单独分出来再配。
- **蓝牙搜不到设备**：确认设备已开机、手机蓝牙已打开，靠近一点再试；不行就长按 IOT RESET 重置后再来一遍。
- **设备突然离线**：多半是所连 Wi-Fi 断网或路由器把设备踢下线，网络恢复后会自动重新上线，期间可用蓝牙或直连就近控制。

另外提醒一句：一台设备同时只能绑定一个账号，一个账号则可以添加多台设备。接手二手设备或想换绑时，记得先在原账号里解除绑定。
