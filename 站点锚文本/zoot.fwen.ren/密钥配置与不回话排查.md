# ZOOT 的 DeepSeek 密钥配置与不回话排查

> 这款应用开箱聊不了——必须填一枚 DeepSeek API 密钥才能生成干员回复。这篇讲密钥从哪来、三步配进应用，以及配完还是不回话时按什么顺序查。
> **相关文档**：[干员聊天玩法一览](干员聊天玩法一览.md) · [下载安装步骤与安装问题](下载安装步骤与安装问题.md)

---

## 一、为什么必须先配密钥

ZOOT 本体里放的是干员角色卡、人设逻辑与界面，真正生成对话的是 DeepSeek 大模型——应用把消息和人设一起发给 DeepSeek 的服务，拿回回复再以干员口吻显示出来。这意味着：

- 没有密钥，首次设置向导走不完，进不了联系人列表；
- 密钥是自己的 DeepSeek 账号凭据，对话的 token 费用记在这个账号上，与应用无关；
- 密钥别发给别人——拿到它的人可以用这个额度聊天。

## 二、获取一枚 DeepSeek API 密钥

1. 打开 DeepSeek 开放平台（platform.deepseek.com），用手机号注册并登录；
2. 进入 API keys 页面，点「创建 API key」；
3. 给密钥起个名字（比如 `zoot`，方便辨认用途），确认创建；
4. 页面会显示一次完整的密钥——**只显示这一次，当场复制保存**，关掉就再也看不全，只能删掉重建。

费用按 token 用量计费，价格与充值方式以平台当时显示为准，实际消耗可在用量明细页核对。聊得越多花得越多，心里有数再用；账户额度用尽时对话会失败。

## 三、三步配进 ZOOT

打开应用，首次启动会直接进入设置向导：

1. **选择 AI 模型**：列表里选 DeepSeek，不需要手动填接口地址；
2. **粘贴 API 密钥**：把创建好的密钥完整粘进输入框——常见翻车是粘贴时带上空格或少了头尾字符，粘完从头到尾目视检查一遍；
3. **填写博士姓名**：这是干员称呼博士的名字，会出现在对话里，随意起但建议别用真实姓名。

保存后进入首页，能看到联系人页面就说明配置生效了。后续换密钥、改名字都在设置入口操作。更多玩法从这里继续：[干员聊天玩法一览](干员聊天玩法一览.md)。

想按截图对照操作界面的，[ZOOT 介绍站](https://zoot.fwen.ren/)的上手一节把这三步配了图说明。

## 四、配完还是不回话，按这个顺序查

| 现象 | 多半的原因 | 处理 |
| --- | --- | --- |
| 发消息转圈后没有任何回复 | 密钥无效或被删 | 回 DeepSeek 平台重建一枚新 key，重新粘贴 |
| 前几天还能聊，今天突然全哑 | 账户 token 额度用尽 | 去平台看余额，充值或等额度恢复（规则以平台页面为准） |
| 一直显示加载空白 | 网络不通或接口超时 | 换 Wi-Fi / 流量，重启应用再试 |
| 只有个别干员不回 | 该角色卡数据异常 | 换别的干员验证；单角色异常就清这个干员的记忆重置 |

一个实用的判断技巧：先换一位干员发消息——全体都哑是密钥、额度或网络问题；只有一个哑是角色数据问题。

聊天越久越容易「不像 TA」：上下文积累太长把人设带偏了。进该干员的档案设置，清空中期记忆（保留初始人设）或清空全部记忆（完全重置）即可恢复；清空全部会丢掉与这位干员的历史对话，想留的内容先存档。

## 五、提醒

- ZOOT 是玩家社区的同人作品，与《明日方舟》开发商鹰角网络无隶属关系，游戏本体的问题（充值、账号、封号）要找游戏客服，同人应用解决不了；
- 聊天记录与存档保存在手机本地，卸载或清除数据会一起清掉，换机不同步——换设备前先把要留的对话存成命名存档或自行导出；
- 还没装应用的从 [下载安装步骤与安装问题](下载安装步骤与安装问题.md) 开始。
