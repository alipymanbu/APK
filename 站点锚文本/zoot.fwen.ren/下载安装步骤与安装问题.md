# ZOOT 下载安装步骤与安装问题

> 这篇讲把这款明日方舟同人 AI 聊天应用装上安卓手机的完整流程：从哪里拿安装文件资源、四步装好、安装环节卡住的几种处理办法。
> **相关文档**：[干员聊天玩法一览](干员聊天玩法一览.md) · [密钥配置与不回话排查](密钥配置与不回话排查.md)

---

## 一、装之前先认识它

ZOOT 是玩家社区制作的《明日方舟》同人 AI 聊天应用，圈内也叫它「罗德岛通讯端」：内置数十位干员的角色卡，接 DeepSeek 大模型生成对话，能私聊、拉群、收干员的主动消息、逛动态广场，还带养成计算与理智提醒等游戏工具。它与游戏开发商鹰角网络没有隶属关系，角色名称与设定的版权归原作方。

两件事先知道：一是安装包接近 180MB，解压还需要额外空间，手机最好留出 1GB 以上余量；二是它必须配一枚 DeepSeek API 密钥才能聊起来（见 [密钥配置与不回话排查](密钥配置与不回话排查.md)）。

## 二、从哪里拿安装文件资源

这款应用的安装文件资源放在夸克网盘，入口在 [ZOOT 介绍站](https://zoot.fwen.ren/)的下载页，路径是：打开介绍站 → 点「下载安装」→ 页面中间的大按钮直达网盘分享。拿到后先把分享文件**转存到自己的夸克网盘**（分享文件可能随时失效，转存后才是自己的），再从网盘下载 APK 到手机本地存储。

## 三、四步装好

安卓安装非商店来源的安装包，系统默认会拦一道，流程如下（不同品牌菜单名称略有差异）：

1. **转存并下载**：按上面的路径把 APK 下载到手机本地存储；
2. **放行未知来源**：首次点开 APK 会弹「禁止安装来自此来源的应用」——按提示进系统设置，给文件管理器（或浏览器）开「安装未知应用」权限；
3. **点安装等完成**：返回继续点安装，包体大、解压时间长，等进度走完再退出；
4. **打开并完成首次配置**：首次启动进设置向导——选 DeepSeek、粘贴密钥、填写博士称呼，保存后进通讯录挑干员开聊。

## 四、安装环节卡住了

- **点安装没反应或提示解析包出错**：多半是安装包下载不完整，删掉重新从网盘下载一遍再装；
- **提示「应用未安装」**：常见原因是手机里已有签名不同的旧版本，先卸载旧的再装（卸载会清掉本地聊天记录与存档，要留的先保存好）；存储不足也会导致，清理出 1GB 以上余量再试；
- **装完点开就闪退**：重启手机试一次；仍闪退就清应用缓存（别点「清除数据」，那等于恢复出厂）。装好后 AI 不回话是另一类问题，去 [密钥配置与不回话排查](密钥配置与不回话排查.md) 对表排查。

装好之后从 [干员聊天玩法一览](干员聊天玩法一览.md) 开始挑第一位干员。
