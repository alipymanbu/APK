# 声库获取与导入要点

没有声库，歌声合成编辑器就只是一架不出声的钢琴。这篇按「手机上装声库」的实际流程，把类型、来源和导入时容易卡住的点一次讲清。

## 一、先认类型

OpenUtau Mobile 的项目仓库列出三类可用的歌手类型，装之前先确认手里的包属于其中之一：

- **DiffSinger**：神经网络合成路线，出声自然度高，是社区当下的主流方向，也是移动端主打支持的一类；
- **UTAU**：传统采样拼接，历史声库存量最大，手动调音空间最大；
- **Vogen**：面向中文的 AI 合成声库体系，中文歌姬资源可以直接导入。

仓库同时注明：其他未经测试的类型不保证正常工作。来历不明装不上的包，先核对类型再排查。

## 二、去哪里找

两条社区通行路径：

1. **DiffSinger 自制声库分享渠道**：OpenUtau Mobile 仓库首页的 Quick Start 一节给了集中登记社区自制 DiffSinger 声库的入口；
2. **UTAU 声库百科**：各类 UTAU 歌手的介绍页通常会给出发布页链接，按歌手名搜索即可；重音 Teto、足立レイ等经典声库都有维护良好的发布页。

声库一般打成 ZIP 包，体积从几十 MB 到上 GB 不等，下载前留意手机剩余空间。

## 三、导入六步

1. 把 ZIP 包放进手机内置存储——**别提前手动解压**，也别放在嵌套很深的目录里；
2. 打开应用，主页点「歌手」进入歌手列表；
3. 点右下角加号，应用申请「查看所有文件」权限时选择允许；
4. 选中声库 ZIP，选择压缩包解码方式（一般用默认项，歌手名变乱码时再换）；
5. 按提示确认歌手类型（CV、CVVC、VCCV 等，不确定先用默认）；
6. 等解压安装完成，回到歌手列表确认新歌手出现，回主页新建工程就能选它演唱。

## 四、卡住时的三个自查点

- **导入没反应**：多半是压缩包被提前解压了，整包重新导入；
- **歌手名乱码**：换一种解码方式重试，日文声库常见；
- **工程里选不到歌手**：确认导入时类型选对，或回歌手列表刷新。

装好应用是第一步，安装流程见站点下载页的完整五步：[openutau 手机版安装指引](https://openutau.hhdc.tech/)。装好之后工程怎么在手机与电脑之间往返，见[手机端工程互通与上手路径](手机端工程互通与上手路径.md)。
