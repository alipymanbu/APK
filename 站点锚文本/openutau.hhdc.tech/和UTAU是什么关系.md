# OpenUtau 和 UTAU 是什么关系

分清两个名字，是入坑歌声合成的第一课。**UTAU** 是 2008 年问世的日语歌声合成软件，靠「采样拼接」的方式让声库唱歌，二十年下来积累了庞大的爱好者生态与海量自制声库。**OpenUtau** 则是 UTAU 社区为自己打造的现代化开源替代品：由开发者杉田朗（stakira）发起、大量志愿者参与，2021 年 8 月放出公开测试版，以 MIT 协议开源。

两者不是竞争关系，更像是「老宅子」与「新装修」：

| 维度 | UTAU | OpenUtau |
| --- | --- | --- |
| 界面与操作 | 老式单窗口，体验多年未变 | 多轨编辑、鼠标滚轮与快捷键现代操作 |
| 渲染 | 手动重采样，改动后要等 | 后台预渲染，播放即试听 |
| 歌词拆音 | 手工拆解、按后缀标记 | 音素器自动拆音（VCV / CVVC / Arpasing 等） |
| 系统区域 | 历史上常被非日语系统坑 | 无需改系统区域设置 |
| 平台 | 仅 Windows | Windows、macOS、Linux，还有社区移动端分支 |

关键在于**声库生态的延续**：OpenUtau 沿用 UTAU 的声库格式约定，character.txt、oto.ini、prefix.map 这些文件照常识别，历史声库可以直接装进新编辑器继续用。对调音师来说，换编辑器不等于换声音资产。

手机端也有一条分支：社区开发者 vocoder712 基于 OpenUtau Core 改造的安卓版，把多轨钢琴卷帘、声库管理和 .ustx 工程读写搬到了手机上。想快速看它的真机界面与功能梳理，可以逛逛 [openutau 手机版介绍站](https://openutau.hhdc.tech/)。
