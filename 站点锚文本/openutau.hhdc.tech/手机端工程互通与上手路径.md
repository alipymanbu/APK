# 手机端工程互通与上手路径

歌声合成调音最费时间，灵感却总在通勤路上、排队间隙冒出来。OpenUtau Mobile 的价值正在这里：它基于 OpenUtau Core 打造，工程格式与电脑端同源，手机上改的东西回电脑接着改，不用推倒重来。

## 一、.ustx：两端通用的工程文件

.ustx 是 OpenUtau 体系的工程格式，手机版保存工程时默认落到手机存储（文件名以 .ustx 结尾）。这个文件是**两端通用的**：

- 电脑端 OpenUtau 开的工程，拷进手机直接打开继续编辑；
- 手机上写了一半的工程，拷回电脑端接着细调。

拷贝方式随意：数据线、局域网传输、云盘中转都行——工程文件本身不大（声库才是大头），来去很快。

## 二、手机端保留了什么

移动端没有照搬桌面全部功能，挑出来的是「路上真正用得起来」的部分：

- **多轨钢琴卷帘**：工程按 120 BPM、4/4 拍组织，音符块的增删拖动都为触控重做；
- **音素拆音**：歌词填进音符后自动转成音素，不用手工拆解；
- **表情面板**：音量、flags、声部颜色这些参数用滑块调，不用像老 UTAU 那样手动敲 flag 字符串；
- **预渲染试听**：编辑时后台渲染人声，改完就听，不等整轨重算。

混音与导出成品这类重活，仍建议留给电脑端完成——这也是两端的合理分工。

## 三、最短上手路径

1. 装好应用并授权文件访问权限；
2. 主页点「歌手」导入一位歌手（声库）；
3. 回主页点「新建」，选中歌手进入钢琴卷帘；
4. 放音符、填歌词，听预渲染效果；
5. 存成 .ustx，回电脑端继续精修。

应用怎么装、权限在哪一步弹，站点里按真机界面逐步写过：[openutau 手机版介绍站](https://openutau.hhdc.tech/)。声库从哪来，见[声库获取与导入要点](声库获取与导入要点.md)；它与 UTAU 的渊源，见[和UTAU是什么关系](和UTAU是什么关系.md)。
