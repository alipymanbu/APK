# 手机怎么给照片做弧形文字

本篇记录在手机上把文字排成弧线、圆环的做法与踩坑点，以安卓图片加字工具 Phonto 为例展开，另外一篇 [图片加字怎么弄才好看](图片加字怎么弄才好看.md) 整理了字体选择与间距思路，可以搭配着看。

---

## 弧形文字适合什么场景

- **环形徽章**：文字绕着人像、Logo 排一圈，社团头像、社群徽标常用；
- **弧形标语**：一行字微微上弯，跟着地平线、屋檐的弧度走；
- **贴着主体绕排**：让文字像丝带一样绕在照片中的物体旁边。

## 通用做法（以 Phonto 为例）

1. **先放底图、再放文字**：选好照片，点画布任意位置写下文字内容；
2. **点文字唤出菜单**，在尺寸/倾斜一栏附近找到弯曲（倾斜与弧度）调节，拖动数值，文字就会沿弧线弯曲，弧度正负对应向上弯还是向下弯；
3. **配合旋转微调**：弧形排完再看整体角度，稍作旋转让弧线的走向呼应照片里的曲线；
4. **逐字渐变加分**：弧形 + 逐字渐变是经典组合，文字沿着弧线换色，视觉上更有流动感。

## 弧形排版的三个细节

- **弧度别太猛**：除了做徽章，日常配图的弧度小一点更耐看，微微上弯就有"动感"了；
- **字距跟着弧走**：弧线外侧的字自然散开、内侧挤在一起，排环形文字时把字距略收紧，整圈会更均匀；
- **分行做双层**：徽章式排版常做上下两层弧形，上层向上弯、下层向下弯，中间放主图案。

## 常见问题

**弯曲后描边变形怎么办？** 描边宽度过大时弧形转角处容易糊，把描边调细一档，或改用阴影拉开层次。

**中文字体能弯吗？** 能。字体只影响字形，弯曲是排版属性；如果内置中文字体不合意，先导入自己的 .ttf / .otf 中文字体再排弧形。

**保存后弧度变了？** 多半是缩放图层时把文字当成了普通图片拉伸。回到文字图层重新调弧度，或排好后少做整体拉伸。
