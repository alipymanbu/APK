# 手机和电脑互传文件不压缩的省事办法

手机拍一段 4K 视频，想拷到电脑上剪辑，结果发现：微信发过去画质被压得一塌糊涂，QQ 大文件动不动就限速，数据线又懒得翻。其实只要手机和电脑在同一个 Wi-Fi 下，这事有个更直接的思路——**走局域网，文件从一台设备直达另一台，中间不经过任何服务器**。

## 为什么画质会被压

聊天工具传文件时普遍会转码压缩：照片重新编码、视频降码率，好处是省流量，代价是画质和体积双双缩水。云盘中转则是另一条路——先上传、对方再下载，大文件两头都要等，还吃宽带。

局域网传输绕开了这两件事：文件原样打包、原样落地，不重新编码；速度取决于路由器和网卡，跟宽带上限无关。

## 局域网互传是怎么运作的

以 LANDrop 这类工具为例，它的做法接近"隔空投送"的通用版：

1. 两端都装上工具，连同一个 Wi-Fi（或一方开热点）；
2. 设备自动互相发现，不用输 IP、不用搭服务器；
3. 选文件、点对方设备，接收端确认一下就开始传；
4. 全程加密认证，局域网里的其他设备看不到内容。

对"手机给电脑发原图、电脑给手机丢安装包"这类高频场景，这套流程基本是零门槛的。更完整的介绍与界面截图，可以看这份 [LANDrop 局域网隔空投送整理](https://landrop.hhdc.tech/)。

## 几个容易踩的坑

- **搜不到设备**：先确认两端连的是同一路由器；路由器开了"AP 隔离"或访客网络时，设备之间是互相看不见的。
- **公司/校园网传不了**：这类网络常开客户端隔离，开个手机热点验证最快。
- **传到一半断**：手机别切后台太深，部分系统会杀掉后台应用的网络。

## 小结

图片要原图、视频要原画质，就走局域网；随手发个截图给同事，聊天工具仍然最方便。两条路各干各的活，互不耽误。
