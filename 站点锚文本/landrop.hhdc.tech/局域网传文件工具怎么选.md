# 局域网传文件工具怎么选

"传文件"这三个字，在不同设备组合下答案完全不同。先把常见路线摆一摆，再聊什么样的场景适合走局域网。

## 常见的几条路线

| 路线 | 适合 | 不适合 |
| --- | --- | --- |
| 聊天工具文件传输助手 | 随手发截图、小文档 | 大视频、原图，会被压缩或限速 |
| 数据线 / SD 卡 | 一次性大批量搬运 | 临时传一张图还要翻线，麻烦 |
| 云盘中转 | 跨城市、跨网络共享 | 同一屋檐下还要绕一圈公网，两头都吃带宽 |
| 局域网直传 | 同一 Wi-Fi 下的设备之间 | 设备不在一个网络里就没辙 |

局域网直传的核心优势就两条：**原样不压缩**、**不占公网带宽**。速度上限由路由器和网卡决定，跟宽带快慢无关。

## 挑局域网工具时看什么

- **平台覆盖**：家里设备杂——iPhone 加 Windows 台式机，再加一台安卓电视，就得挑各平台都有的工具，否则永远缺一环。
- **是否压缩**：有些工具号称直传，实际会转码。照片传过去体积变了，就是被压了。
- **要不要账号**：注册、扫码、加好友这类前置步骤越多，临时用一次的成本越高。
- **安全性**：文件在局域网里裸奔还是加密传输，差别很大，尤其在公司网络里。

## LANDrop 的落点

拿 LANDrop 来说，它的位置比较清晰：iOS、安卓、Windows、macOS、Linux、Android TV 都有客户端，同一 Wi-Fi 下自动发现设备，无需输 IP、无需账号；传输走加密认证，照片视频不做压缩；手机开热点时也能继续传，不消耗流量。这套特性基本把上面四条挑选标准都占住了，具体可以看这份 [LANDrop 介绍与使用整理](https://landrop.hhdc.tech/)。

## 结论

同一网络内的设备互传，局域网直传是体验上限最高的一条路；跨网络、跨城市的场景，云盘和聊天工具仍有它们的位子。工具本身没有万能的，对上场景就是好工具。
