# facetune 磨皮怎么修才自然

> 本篇讲 facetune 皮肤工具组（Heal / Smooth / Patch / Texture / Conceal）的分工与顺序，核心是一个判断：磨皮的终点是"看不出修过"。相关阅读：[美白牙齿与五官微调技巧](美白牙齿与五官微调技巧.md)、[安卓版下载安装步骤](安卓版下载安装步骤.md)。

磨皮是最容易翻车的一步：力度一大，皮肤就变"塑料"。facetune 的解法不是一支万能磨皮刷，而是把皮肤修饰拆成了几件各管一段的工具——用对组合，才能既干净又保得住质感。

## 先记住一个原则

开发方在自己的使用指南里反复提过一句话：**smooth 和 too smooth 是两回事**。磨皮的目标是"气色更好"，不是"换一层皮"。实际操作里，宁可先加小幅度、再逐步叠，也别一上来就把滑杆拉满。

## 各工具的分工

**Heal（点掉瑕疵）**：对着痘痘、印子点一下即可，适合零星的小问题。偶尔冒头的一两颗痘没必要陪照片过一辈子。

**Patch（修补）**：要盖的面积大时用它。选一块想盖掉的皮肤，再选一块想拿来覆盖的皮肤——用自己的健康皮肤补自己，颜色和质感天然对得上，效果比硬遮自然得多。

**Smooth（磨皮）**：主力度工具，强度自己控。顺带两个变体：出油反光走 Matte 压掉，想要好气色走 Glow 叠一层日晒光泽。

**Texture（补纹理）**：磨皮之后把细腻的皮肤质感加回去。这是"看不出修过"的关键一步，很多人跳过了它才翻的车。

**Conceal（遮眼袋）**：熬夜后的眼下暗沉用滑杆提亮。加一点是"休息好了"，加多了就是"熬夜被抓包"，幅度同理宁小勿大。

## 推荐顺序

1. Heal 清掉零星瑕疵；
2. Patch 处理成片的泛红或印记；
3. Smooth 小幅度磨一遍；
4. Texture 补回质感；
5. Conceal 提亮眼周收尾。

每一步之间把照片放大到 100% 看一眼局部——手机屏幕缩小看什么都好看，放大才见真章。
