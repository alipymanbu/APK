# 不用电脑给手表安装第三方应用

> 给 Wear OS 手表装个新表盘、装个离线音乐播放器，传统路子是把表接到电脑上敲命令。本篇讲更省事的路：一只手机完成侧载，不用数据线、不用电脑。
> **相关文档**：[手表预装应用清理与冻结方法](手表预装应用清理与冻结方法.md)

## 为什么装个应用这么折腾

国内发行的 Wear OS 手表大多没有可用的应用商店——系统里那个商店入口要么空空如也，要么点了没反应。谷歌的开发文档也写明了这个现状，并建议开发者改用 ADB 方式侧载安装。所以「给手表装应用」这件事，目前主流做法就是走 ADB 通道。

老教程会让你：手表接电脑、装 ADB 驱动、敲 `adb install` 命令。能成，但对不碰命令行的人来说门槛不低。

## 手机直装的路子

现在有一类手机端的手表管理工具（例如 [WearOS 工具箱介绍站](https://wearos.wxhp.skin/) 里整理的这款），把 ADB 通道包进了图形界面：手机和手表连同一个 Wi-Fi，手表打开调试开关，手机上选中 APK 点安装，文件就直接推进手表完成安装。

大致流程：

1. 手表进「设置 → 系统 → 关于」，连点版本号 7 次打开开发者模式；
2. 在开发者选项里开启「ADB 调试」和「无线调试」；
3. 手机装好工具箱，填入手表屏幕上显示的 IP 和端口（新版可以自动扫描发现设备）；
4. 在「安装 APK」功能里选中手机里存好的安装包，确认推送。

部分工具还内置了应用商店（挑选后直接装进手表），以及一次推多个安装包的批量模式。

## 三个注意点

- **包要适配手表**：手表的处理器架构和屏幕与手机不同，拿手机版的 APK 硬装，轻则安装失败、重则装上闪退。找表盘、手表工具类资源时认准 Wear OS 版本。
- **装完没图标**：安装成功但手表列表里找不到，重启一次手表再看，多数会出现。
- **调试开关会自己关**：部分系统息屏一段时间后自动关掉无线调试，装到一半失败先回开发者选项看一眼开关。

## 装完之后

装应用只是开始——预装的那堆用不上的应用同样能管起来，思路写在[手表预装应用清理与冻结方法](手表预装应用清理与冻结方法.md)里，配合使用体验更完整。
