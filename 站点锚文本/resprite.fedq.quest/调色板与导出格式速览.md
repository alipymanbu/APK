# Resprite 调色板与导出格式速览

> 本篇讲 Resprite 的调色板玩法（生成、插值、导入现成色板）和各种导出格式分别适合什么场合。
> **相关文档**：[像素动画与时间轴入门](像素动画与时间轴入门.md) · [安卓版下载与安装步骤](安卓版下载与安装步骤.md)

## 一、调色板：像素画的全部颜料

像素画通常要限定用色数量，调色板就是全部家底。Resprite 的调色板支持几件很实用的事：

- **从画布或参考图直接生成**：看到配色喜欢的图，提出来就是一套现成色板；
- **颜色插值**：给两个端点色，自动补出中间阶梯，做明暗过渡不用手调；
- **排序与分组**：色板按规则整理，找色快；
- **导入现成预设**：支持 GPL、RPL 这类通用调色板文件。

还有个「材质颜色球」：按光照方向推演高光、中间调与阴影，把推出来的阶梯色直接加进调色板——画球体、发光物、金属感这类需要明暗阶梯的对象时，先用它定基础色阶再逐格画，省很多试错。

取色时注意：长按画布快速吸色会出现放大镜，确认落点在哪颗像素上——像素画错一格，颜色就错位。

## 二、导出格式按用途选

在打开的作品里进菜单 ▸ 导出，常用格式对号入座：

| 想做什么 | 用哪种格式 | 要点 |
| --- | --- | --- |
| 发社交平台 | GIF / APNG | 帧范围、边距、放大倍数可调；APNG 支持 24 位全彩与透明 |
| 交游戏引擎 | 精灵表 PNG | 无损，可设每行帧数、边距与放大倍数 |
| 给 Photoshop 等深加工 | PSD | 保留图层组、剪贴蒙版与混合模式；只有当前帧，动画要逐帧导 |
| 与 Aseprite 用户协作 | Aseprite 格式 | 剪贴蒙版等特性没有对应表达，复杂文件先看兼容说明 |
| 与 Tiled 工具链互通 | Tiled 打包 | 导出 zip，内含 .tmx、.tsx 与 PNG |
| 手工拼豆 | 拼豆图纸 | 粗细两种网格，可显示颜色名 |
| 展示动画成果 | 视频 | 安卓端可选编码器 |

往 Resprite 里导入的东西也很宽：`.resprite` 包、GIF / APNG（逐帧拆开）、精灵表（按帧宽高切分）、Aseprite 1.3+ 项目、Tiled 地图与瓦片集。导入后保存的都是 `.resprite` 项目，想回 GIF、PSD 走导出即可。

## 三、备份的正品是 .resprite 副本

PNG、GIF、PSD 这些导出文件替代不了备份——图层数据不在里面。重要节点手动保存后，在美术馆选中作品导出 `.resprite` 副本，存到应用数据目录以外，文件名带上日期；恢复时用美术馆的导入菜单载回来，确认图层、帧都在才算备份成功。
