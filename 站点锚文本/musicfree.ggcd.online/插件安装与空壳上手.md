## 先接受一个设定：装完就是空壳

MusicFree 是一款以 GPL 协议开源、基于 React Native 构建的播放器。它的安装包里没有任何内置音源——这一点在它的公开介绍里写得非常直白。也就是说，刚装完打开时搜索页空空荡荡，不是下载出了问题，也不是版本不对，而是这款应用的设计就是如此：**内容从哪来，由你自己装的插件决定**。

这个设定带来的好处其实不少：应用本身无广告、不强制登录账号，所有数据都保存在本地，不会把使用记录上传到谁的云端。接受这个设定之后，剩下的问题只有一个——把插件装上。

## 插件从哪里来

插件由社区维护，常见的获取方式有两类：

1. **从网络安装**：拿到一个以 `.json` 或 `.js` 结尾的插件合集地址，粘贴进应用即可批量装好。开源项目的 README 里通常给了合集入口。
2. **从本地安装**：如果你下载到了插件文件（单个 `.js` 文件或 `.json` 描述文件），直接从手机存储里选中导入。

两种方式走的是同一个入口，下面是完整路径。

## 安装插件的五个步骤

1. **打开侧边栏**：在主界面点左上角，基本设置、主题设置、插件设置等入口都在这里；
2. **进入「插件设置」**：这一页管理所有已装插件；
3. **点右下角的 + 号**：弹出安装方式选择；
4. **选择「从网络安装」并粘贴链接**：粘贴时留意首尾不要带上空格，确认后应用会拉取合集并逐个装好；从本地安装则在此时选中插件文件；
5. **回到搜索页试一下**：装好后直接搜歌名或歌手，结果会按插件来源分列展示。

装好后如果想查看或调整，回到「插件设置」页即可：每个插件都能单独启停、更新，不需要的也可以直接卸载，应用本体不受影响。

## 插件失效了怎么办

插件是社区作品，单个插件偶尔会因为来源平台调整而短暂不可用。处理思路很简单：在插件设置里先更新试试；更新后仍不行，就换一个社区合集重新导入。这也是插件化设计的好处之一——**换源不动应用**，你收藏的歌单、播放记录都还在本地。

更多日常用法（搜索、收藏、导入歌单、歌词设置）可以继续阅读[多源搜索与歌单导入](多源搜索与歌单导入.md)；还没装上的话，先看[安卓安装与首次启动](安卓安装与首次启动.md)把本体装好。
