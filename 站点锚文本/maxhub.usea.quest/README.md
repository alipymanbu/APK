# MAXHUB 传屏助手 · 使用介绍

本目录围绕 MAXHUB 会议平板的无线投屏整理了几篇实用内容：怎么把手机或电脑画面连上大屏、连上之后能做什么，以及连不上时怎么排查。安卓端配套的传屏助手安装包信息与获取入口见 [MAXHUB 传屏助手介绍站](https://maxhub.usea.quest/)。
