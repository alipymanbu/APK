# 反应时间多少算快？

> 用公开统计的 273ms 中位数做标尺，把常见成绩区间摆在一起对照，并讲清哪些因素在悄悄影响你的数字。

---

测反应时间的人，最想知道的不是怎么测，而是测出来那个数到底算快算慢。下面这些参考区间来自项目公开的统计页——超过 8100 万次点击记录汇总出的分布，比朋友圈里流传的「正常值」可靠得多。

## 一、273ms：全体样本的中位数

公开统计里，反应时间的中位数是 **273ms**，平均值 284ms。中位数比平均值更能代表「普通人」——它不受少数极快或极慢成绩的拉动。你的成绩落在哪里，可以对照这张表：

| 成绩区间 | 参考位置 |
| --- | --- |
| 150–180 ms | 电竞玩家的常见区间 |
| 180–200 ms | 进入人群前 5%（第三方统计） |
| 200–230 ms | 进入人群前 25%（第三方统计） |
| 273 ms | 全体中位数，一半人在你之下 |
| 300 ms 以上 | 慢于大多数人，先检查设备再说 |

百分位会随样本量浮动，把上面的数字当标尺用就好，不必抠到个位数。

## 二、100ms：比它还快反而「犯规」

人类反应速度有生理下限。田径比赛的抢跑判定线就定在 100ms——发令枪响后 100ms 内起跑的运动员，会被认定不是「听到」而是「猜到」，直接判罚。你在测试里如果打出 100ms 以下的成绩，多半是预判撞了大运，并不代表超越了人类极限。

## 三、三个悄悄拉高数字的变量

同一台手机，昨天 240ms、今天 290ms，大概率不是状态问题，而是这三个变量在动：

1. **设备链路**。从屏幕到手指的整条链路都有延迟：普通桌面或笔记本的输入延迟约 30ms，接电视可能加到 150ms；高刷新率屏幕加游戏鼠标，对比触控板或旧手机，同一个人能差出 20–40ms。对比成绩前，先确认设备在同一档。
2. **预判**。抢点会被判定无效并重置该轮，整轮平均反而更差。盯住屏幕中心，等颜色真正变化再动。
3. **睡眠**。有第三方统计称，把睡眠从 6 小时补到 8 小时，反应时间能在一到两周内改善 50–80ms。缺觉对反应速度的影响比多数人以为的大。

## 四、怎么测，数字才作数

- 热身两三轮再正式测；
- 同一台设备、同一只手，连测 5 次取平均；
- 换了屏幕、鼠标或手指，成绩要重新基准——旧数字不作数。

测完想看自己的成绩落在人群分布的哪一段，可以去 [Human Benchmark 测试站](https://human-benchmark.qjxz.skin/) 把八项测试挨个过一遍，页面上有完整的成绩对照表。反应时间只是入口，记忆类的成绩对照同样值得一看。
