# 智能灯泡配网全流程

> 这篇讲把 Yeelight 的灯从「刚拆封」变成「手机里能控的设备」的完整流程：动手前的三个条件、不同灯型的重置手法、App 里每一步点哪里、加完别忘了哪个开关。
> **相关文档**：[灯光跟随音乐节奏的设置方法](灯光跟随音乐节奏的设置方法.md) · [控灯应用与米家生态怎么选](控灯应用与米家生态怎么选.md)

## 一、动手前先满足三个条件

| 条件 | 为什么 | 怎么确认 |
| --- | --- | --- |
| 路由器有可用的 2.4GHz 网络 | 这类灯只连 2.4GHz，不认 5GHz | 手机 Wi-Fi 列表里能看到的那个名字，2.4G 与 5G 通常两个名字 |
| 路由器开着 DHCP | 灯要自动拿到一个内网 IP | 路由器后台「DHCP 服务」开启，多数机型默认就是开的 |
| 手机、路由器、灯三者靠近 | 配网时要让灯临时发出一个热点 | 同一个房间，中间别隔承重墙 |

路由器把两个频段合并成一个名字（双频合一）时，灯可能被分到 5G 那一侧而连不上。稳妥做法是在后台给 2.4GHz 单独设一个网络名，配网时手机也连这个名字。

## 二、把灯恢复到待配网状态

新拆封的灯可以直接配；配过网、换过路由器、从别人手上接过来的灯，要先重置：

| 灯型 | 手法 | 成功标志 |
| --- | --- | --- |
| 灯泡、吸顶灯、吊灯（靠墙上开关供电） | 实体开关连续开关 5 次，每次开约 2 秒、关约 2 秒 | 彩光循环或呼吸效果，几秒后自动重启回白光 |
| 灯带（自带电源适配器） | 按住开关键的同时重新接电，保持 5 秒再松手 | 红绿蓝闪烁，指示灯转黄 |
| 带按键或遥控的灯具 | 长按对应按键若干秒 | 以随灯说明书为准 |

前两条的顺序和节奏都不能错：数满 5 次、快慢适中；灯带必须先按住键再插电，反了不生效。

## 三、在 App 里添加

1. 登录后进「设备」页，点右上角「+」；
2. 在列表里选中设备型号；
3. 按屏幕指引完成重置（还没重置的话）；
4. 选择 2.4GHz 网络并输入密码；
5. 跳到手机 Wi-Fi 设置，连上 `yeelink-light-` 开头的热点，然后**手动切回 App**；
6. 保持手机与灯靠近，等进度走完；
7. 成功后改名、选房间。

第 5 步是唯一要离开 App 的地方，也是最多人漏掉的一步——它不会自动跳回去。

## 四、加完记得开「局域网控制」

路径：「设备」页 → 点进那盏灯 → 右下角「更多」→「局域网控制」→ 打开。开启后同一网络下走本地直连，响应更快；要用 Google Home 的本地执行，也必须开它。

## 五、常见卡点速查

| 现象 | 大概率原因 |
| --- | --- |
| Wi-Fi 列表里没有 `yeelink-light-` 热点 | 灯没进配网状态，重置手法没做对 |
| 热点连上了、进度停在中途 | Wi-Fi 密码里有特殊字符，改成纯字母数字再试 |
| 提示添加成功、马上变离线 | 灯拿到了 IP 但没连上服务器，查路由器往外那一段 |

按上面排完还是不行，用手机热点绕开路由器验证一次：能加上就是家里路由器的事，加不上就回头查重置和型号选择。
