# 控灯应用与米家生态怎么选

> 这篇讲清 Yeelight 控制端、米家 App、Yeelight Pro、Yeelight Station 四个名字各管什么，登录用哪个账号，以及同一批灯该定在哪一个入口上。
> **相关文档**：[智能灯泡配网全流程](智能灯泡配网全流程.md) · [灯光跟随音乐节奏的设置方法](灯光跟随音乐节奏的设置方法.md)

## 一、先分清四个名字

| 名字 | 是什么 | 管什么设备 |
| --- | --- | --- |
| Yeelight 控制端 | 易来的手机控灯应用，安卓包名 `com.yeelight.cherry` | 易来消费级智能灯：灯泡、灯带、吸顶灯、台灯、氛围灯 |
| 米家 App | 小米的智能家居总入口 | 米家生态下各类设备，Yeelight 的灯是其中一类 |
| Yeelight Pro | 面向易来 Pro 全屋灯光系统的另一套应用 | Pro 系列的网关、灯具、开关、传感器 |
| Yeelight Station | 电脑端程序（Windows 8 及以上，暂不支持 macOS） | 以支持型号清单为准 |

四个不是同一个软件的不同版本，装错了打不开自己的设备很正常。

## 二、账号：都是小米账号

Yeelight 控制端只能通过小米账号登录，没有的话登录流程里会先引导注册一个；账号注册与关联的个人信息都在小米那侧完成。这也解释了为什么接入 Google Home、Amazon Alexa、IFTTT 时，绑定设备走的都是「关联小米账号」这一步。

想家里人也控灯：让家人用同一个小米账号登录，是最省事的做法；设备分享入口以应用内设备设置页实际显示的为准。

## 三、两套添加流程都支持，但别来回切

指向 Yeelight 控制端的添加流程和指向米家 App 的添加流程是分开的两套，步骤几乎一样：重置设备、选 2.4GHz 网络、连 `yeelink-light-` 开头的热点。

同一盏灯在两边是不是随时都认得，各方说法并不一致，遇到时以设备在应用里的实际表现为准。稳妥做法：**定一个应用，从配网到日常控制都用它**；真要换，就按换应用的流程重新配一次网（见 [智能灯泡配网全流程](智能灯泡配网全流程.md)）。

## 四、怎么选

| 你的情况 | 建议 |
| --- | --- |
| 手上主要是易来的灯，想调光调色、玩灯光效果与音乐律动 | 用 Yeelight 控制端，灯光玩法更全 |
| 家里还有一堆别的米家设备，想让灯和它们联动 | 用米家 App |
| 装的是易来 Pro 系列网关与灯具 | 用 Yeelight Pro |
| 想在电脑上控灯 | 先对照 Yeelight Station 的支持型号清单 |

不管用哪个，都建议把设备的「局域网控制」打开：同一网络下走本地直连，响应更快。

还没定用哪个的话，可以去 [Yeelight 光控站](https://yeelight.bmww.store/) 看一遍真机界面与功能清单再决定；定了想玩灯光跟音乐，见 [灯光跟随音乐节奏的设置方法](灯光跟随音乐节奏的设置方法.md)。
