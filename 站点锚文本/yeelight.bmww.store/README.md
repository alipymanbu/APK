## 一句话认识 Yeelight

Yeelight（易来）是 2012 年从青岛起步的智能照明品牌，灯泡、灯带、吸顶灯、台灯都装了 Wi-Fi 模块，拧上就能联网；手机装上它的控制端后，亮度、色温、1600 万色随手调，还能让灯跟着音乐动。想看完整的界面截图与功能清单，去 [Yeelight 光控站](https://yeelight.bmww.store/) 翻一遍即可。
