# 无损音乐格式怎么选

> FLAC、ALAC、WAV、DSD、APE……无损标签一大堆，哪种值得存手机、哪种纯属浪费空间？
> 这篇按「来源—体积—兼容」三个维度把常见音频格式捋一遍，并给出在 Poweramp 里的播放建议。

## 一、先分清两大类

- **有损**（MP3、AAC、OGG、Opus）：压缩时丢弃人耳不敏感的信息，体积小；320kbps 的 MP3 与无损在通勤场景里多数人听不出差别；
- **无损**（FLAC、ALAC、WAV、APE、WavPack）：完整还原原始录音，体积大（一首歌 20~60MB 起）。

**结论先行**：手机本地收藏选 FLAC（安卓生态兼容最好）；苹果设备间流转选 ALAC；只是随手听，高码率有损完全够用。

## 二、常见格式速查

| 格式 | 类型 | 一句话点评 |
| --- | --- | --- |
| FLAC | 无损 | 开源、标签支持好，安卓首选 |
| ALAC | 无损 | 苹果系无损，常装在 M4A 壳里 |
| WAV | 无损 | 兼容性最好但没有标签体系，歌名靠文件名 |
| APE | 无损 | 压缩率略高，老资源多，解码更吃性能 |
| WavPack (WV) | 无损 | 小众，个别老合集在用 |
| DSD (.dsf/.dff) | 高解析 | SACD 抓轨形态，文件巨大、设备要求高 |
| MP3 / AAC / Opus | 有损 | 日常听够用，Opus 同码率素质最好 |

## 三、DSD 和 Hi-Res：值不值得追

DSD 文件动辄一首 100MB 以上，而且**能不能按原规格出声由手机决定**：芯片和 ROM 的音频通路不支持时，播放器会内部转换成 PCM 再输出——文件照样能播，只是没跑满规格。24bit/192kHz 的 FLAC 同理。与其囤规格，不如先确认自己的耳机和手机到底能走多高。

在 Poweramp 里播放这类文件不用装任何插件：它自带解码器，DSD、APE、模块音乐（IT/XM/S3M）都是原生支持；整轨 FLAC 配一个 .cue 文件放同目录，会自动按曲目切开。播放页的解码信息里能看到当前实际输出的采样率，用来核对有没有跑满。

## 四、播放不了的只有一种

各流媒体应用加密的**离线缓存文件**——那不是普通音频格式，放进来不会播。除此之外，扩展名标错（`.flac` 实为 MP3）或文件没下完整，才是「格式表里明明有却播不了」的真实原因。

整理好的曲库配上像样的解码器才有意义。Poweramp 的格式支持与功能介绍见 [Poweramp 介绍站](https://poweramp.bmww.store/)，安装文件获取入口也在那里。
