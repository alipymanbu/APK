# 空库与扫描不到歌曲排查

> 装好 Poweramp 打开一片空白、新下的歌不出现、扫到一半卡住——这些几乎都不是播放器坏了，
> 而是它的曲库机制和别的播放器不一样。按这篇从上到下走一遍，九成能在第二步就解决。

## 一、先理解它的曲库逻辑

Poweramp 的媒体库是**独立的**：它不读系统音乐 App 里有什么，只扫你在它自己设置里**勾选过的文件夹**。
所以「系统播放器里有歌、它里面没有」大概率不是故障——是文件夹没勾。这是新用户撞到的第一堵墙。

## 二、按顺序排查

### 1. 音乐文件夹没勾（最常见）

进 设置 → 文件夹 / 媒体库 → 音乐文件夹：

- 看存歌目录在不在列表里、有没有打勾；
- 后来新建的目录（比如 `Download/Music`、SD 卡新文件夹）**要手动进来再勾一次**；
- 勾完回列表页触发一次扫描。

### 2. 权限没给足

系统设置 → 应用 → Poweramp → 权限，确认存储 / 音乐与音频权限是「允许」。安卓 13 及以上对媒体权限卡得严，首次启动随手拒了，表现就是空库。

### 3. 触发完整重扫

歌确实在勾过的文件夹里却不出现：列表页菜单里执行「重新扫描」；还不行就在应用信息里「强行停止」再打开，让它重建索引。

### 4. 扫描慢或扫到一半卡住

这一条多半是 **SD 卡的问题**（部分损坏或速度过慢）：拔卡在电脑上查错，或换张卡试。只在某个特定文件夹卡住，通常是那个文件夹里堆了大量非音频文件，取消勾选它再扫。

### 5. 不想让某些文件进来

游戏音效、录音、通知音混进歌单：同样在「音乐文件夹」里取消勾选对应目录即可，不用删文件。

## 三、两个衍生问题

- **中文歌名乱码**：标签编码问题，不是文件坏了。老版本在扫描器设置里切 GBK/GB2312 再重扫；新下载的资源多是 UTF-8 标签，编码没错时别乱切，切错反而全乱。个别歌名不对直接在播放器里改标签。
- **封面不显示**：先完整重扫一遍（多数是没读到内嵌封面）；个别文件本身没带封面图，把图片放进同目录或在标签编辑器里补。

## 四、还是不行

按「文件夹勾选 → 权限 → 完整重扫 → SD 卡」的顺序走完仍无解，就把范围缩小：只有一个文件夹缺歌 = 那个文件夹的问题；所有歌都缺 = 权限或索引的问题。功能介绍与安装文件获取入口见 [Poweramp 介绍站](https://poweramp.bmww.store/)。
