# 手机上提取 Unity 游戏资源的完整流程

> 想在安卓手机上把一款 Unity 手游的贴图、音频、模型翻出来，不用电脑能做到哪一步？这篇把「找文件 → 加载 → 提取 → 导出」整条流程一次讲清，工具侧以 AssetStudio 手机版为例（它的界面与操作思路整理在 [assetstudio.fedq.ren](https://assetstudio.fedq.ren/) 这 个介绍站里）。
> **相关文档**：[AssetBundle怎么看和导出.md](AssetBundle怎么看和导出.md) · [安卓手机拆包工具怎么选.md](安卓手机拆包工具怎么选.md)

## 一、先把三类目标文件找到

Unity 游戏的资源散落在三个地方，先按下面的表对号入座：

| 文件 | 常见位置 | 特征 |
| --- | --- | --- |
| 安装包 APK | 下载目录、应用管理里的「安装包」 | 资源藏在内部的 `assets`、`bin/Data` 目录 |
| 扩展包 OBB | `Android/obb/<包名>/` | `main.<数字>.<包名>.obb` 命名，体积几百 MB 起步 |
| 热更资源包 | `Android/data/<包名>/` 缓存目录 | 一堆带 hash、版本号的文件，没有统一命名 |

查包名的办法：系统「设置 - 应用管理」里进目标游戏的应用信息页，包名（形如 `com.xxx.yyy`）一般直接显示。安卓 11 以后 `Android/data`、`Android/obb` 对第三方文件管理器加了锁，绕行路子有三条：系统自带文件管理器的授权入口、USB 连电脑走 MTP、Shizuku 授权给支持的文件管理器。找到后统统复制到一个方便访问的目录（比如 Download），后面加载时少绕路。

两个前置处理：XAPK 本质是压缩壳，先当 zip 解开、取出里面的 APK 和 OBB；APK 内部资源不用安装游戏，用支持解压的文件管理器把 APK 当 zip 解开，取出 `assets`、`bin/Data` 即可。

## 二、加载与浏览

打开 AssetStudio 手机版，走 **File - Load file**（单文件）或 **File - Load folder**（整个目录）。加载完主界面出现两个面板：

- **Scene Hierarchy**：按场景结构组织，适合顺着「场景里摆了什么」往下翻；
- **Asset List**：按类型平铺，顶部筛选栏勾 Texture2D、AudioClip 等类型，找东西更快。

⚠️ 一个几乎所有新手都会撞上的坑：**直接加载 AssetBundle 时文件是在内存里解压读取的**，包一大就卡顿、发热、闪退。省内存的做法是先走 **File - Extract 文件/文件夹** 把包解压成本地普通文件，再从提取后的目录加载——大包也能稳稳读。

## 三、按需导出

在列表里选中资源（支持多选），从 Export 菜单导出，常见类型的去向：

- 贴图与精灵图 → PNG 等位图格式；
- 音频 → MP3 / OGG / WAV；
- 字体 → TTF / OTF；
- 模型 → OBJ；带动画的角色模型走 Model 菜单导出 FBX；
- 脚本挂载数据（MonoBehaviour）→ JSON。

批量导出的小技巧：先按类型筛选，再配合全选一次导一整类；导出目录建议按「游戏名 + 资源类型」建文件夹，回头找图找音频不乱。

## 四、边界提醒

提取出来的贴图、音频、模型版权归原作品权利方——自己学习、研究资源结构没问题，公开传播或二次分发有实际风险。工具与具体操作里的更多细节（比如模型导出时怎么把动画一起带上、导出的 FBX 在 Blender 里尺寸不对怎么修），可以到 [assetstudio.fedq.ren](https://assetstudio.fedq.ren/) 翻对应的专题整理。
