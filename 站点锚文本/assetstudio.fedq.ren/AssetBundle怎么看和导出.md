# AssetBundle 怎么看和导出

> 拿到一个 `.bundle`、`.assets` 或 OBB 文件，想在手机上看看里面装了什么、把有用的东西导出来——这篇按「辨认 → 加载 → 排错 → 导出」四步讲清楚，操作示例基于 AssetStudio 手机版（界面截图与更多角度的介绍见 [assetstudio.fedq.ren](https://assetstudio.fedq.ren/)）。
> **相关文档**：[手机上提取Unity游戏资源的完整流程.md](手机上提取Unity游戏资源的完整流程.md) · [安卓手机拆包工具怎么选.md](安卓手机拆包工具怎么选.md)

## 一、先认出手里的是什么文件

| 文件长相 | 它是什么 |
| --- | --- |
| `*.bundle`、`*.assetbundle`、带 hash 的无后缀文件 | 典型 AssetBundle，热更资源最常见的形态 |
| `*.assets`、`*.resource` | Unity 序列化资源，常在 APK 的 `bin/Data` 里 |
| `main.x.xxx.obb` | OBB 主资源包，本质是大号资源合集 |
| `*.unity3d` | 旧版 Unity 打包格式，同样能读 |

这些文件都没法直接打开看，得靠解析工具读出内部的贴图、音频、模型条目。

## 二、两种加载姿势，选对能省一半内存

**姿势一：直接 Load**——File - Load file / Load folder，省事，但 AssetBundle 会在内存里解压读取，包一大内存峰值就上去了。

**姿势二：先 Extract 再 Load**——File - Extract 文件/文件夹，把包解压到本地目录再加载。提取后的文件是普通文件，读取不再整包占内存。经验法则：几十 MB 以内的小包姿势一无所谓；上百 MB 的包一律姿势二，4GB 内存以下的旧机型更是必须。

加载成功的标志：主界面出现 **Scene Hierarchy**（场景结构）与 **Asset List**（按类型平铺）两个面板。列表是空的就按三步排查。

## 三、列表为空的三种常见原因

1. **喂错文件**：工具只认 Unity 体系产物，普通 zip、图片目录、视频文件都不认；
2. **文件不完整**：从 `Android/data` 里拷出来时断了，比对一下源文件与目标文件的大小；
3. **类型被筛掉**：Asset List 顶部的类型筛选栏只勾了某一类，全选后刷新。

## 四、导出：单件与批量

- **单件**：选中条目 → Export 菜单 → 选导出目录；
- **批量**：按类型筛选（比如只看 Texture2D）→ 全选 → 一次导出，落点建议按「项目名 + 类型」建目录；
- **图集类资源**优先看 Sprite 条目而不是 Texture2D——Sprite 是裁好的成品小图，Texture2D 是整张大图，多数场景你要的是前者。

导出格式的对应关系（贴图 → PNG、音频 → MP3/WAV、模型 → OBJ、动画 → FBX 等）与操作细节，[assetstudio.fedq.ren](https://assetstudio.fedq.ren/) 的站点内容里有逐类整理，这里不重复展开。资源版权归原作品权利方，学习研究就好，别拿去传播。
