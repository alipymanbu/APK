# 安卓手机拆包工具怎么选

> 「拆包」在安卓圈里通常指：把一个安装包里的资源、配置、素材翻出来看。需求不同，趁手的工具完全不同——这篇按目标分门别类，帮你对号入座；其中「看 Unity 资源」这一类，重点介绍 AssetStudio 手机版（入口与功能总览见 [assetstudio.fedq.ren](https://assetstudio.fedq.ren/)）。
> **相关文档**：[手机上提取Unity游戏资源的完整流程.md](手机上提取Unity游戏资源的完整流程.md) · [AssetBundle怎么看和导出.md](AssetBundle怎么看和导出.md)

## 一、先想清楚要拆出什么

| 你想要的东西 | 该用的工具类型 | 说明 |
| --- | --- | --- |
| Unity 游戏的贴图、音频、模型、动画 | Unity 资源解析工具 | 本文主角，见下文 |
| 安装包里的清单、权限、签名信息 | APK 信息查看器 | 应用商店类工具普遍自带 |
| 代码与逻辑（smali / dex） | 反编译套件 | 学习研究为主，门槛高，不在本文范围 |
| 普通压缩包内的文件 | 通用解压工具 | APK、XAPK 本质都是 zip |

工具选对，一半的问题就消失了：想让 Unity 游戏的美术资源现出原形，解压工具是无能为力的，必须用懂 Unity 序列化格式的解析器。

## 二、拆 Unity 资源：为什么推荐 AssetStudio 手机版

Unity 系手游占了市场大头，而 AssetStudio 是这个领域知名度很高的开源解析工具。它的手机移植版有几个实打实的优点：

1. **全流程在手机上闭环**：找到文件 → 加载 → 浏览 → 导出，不用来回传电脑；
2. **类型覆盖全**：贴图、精灵图、音频、字体、网格、动画、文本资源等 11 类都能解析导出，且导出的都是 PNG、MP3、OBJ、FBX 这类通用格式；
3. **中文界面、原版布局**：电脑端用户迁移过来几乎零学习成本；
4. **自带附加工作台**：内置上千个 Material 矢量图标，能转成 VectorDrawable 并生成工程代码，安卓开发顺手用。

使用上唯一要记住的习惯：大包先 Extract 再 Load（直接加载会在内存里解压，包大就崩）。完整流程在 [手机上提取Unity游戏资源的完整流程.md](手机上提取Unity游戏资源的完整流程.md) 里逐步讲过。

## 三、选购与使用的三条经验

- **看文件支持范围再下工具**：手里是 OBB、AssetBundle 就找 Unity 系解析器；是普通 APK 想看权限信息，轻量查看器就够了；
- **小内存机型注意操作姿势**：几百 MB 的资源包先解压再加载，比「加载就闪退再重启」省时间得多；
- **守住版权边界**：拆包产物（贴图、模型、音频等）的权利属于原作品方，学习、研究、备份自己有权的项目都行，公开传播或商用有实际风险。
