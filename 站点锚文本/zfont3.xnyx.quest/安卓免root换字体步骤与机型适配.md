# 安卓免 root 换字体步骤与机型适配

> 本篇讲不获取 root 权限给安卓手机换系统字体的通用步骤，以及各品牌机型的支持差异；换完部分应用里没变化的，见[换字体后部分应用没变化的原因.md](换字体后部分应用没变化的原因.md)。

---

想给手机换一套字体，多数人卡在两个地方：一是以为必须 root，二是不知道自己的机型支不支持。实际上用 zFont3 这类工具，[zfont3.xnyx.quest](https://zfont3.xnyx.quest/) 上有完整的介绍与真机截图，大部分热门机型不 root 就能完成更换。下面按顺序说明。

## 一、先确认机型在支持范围里

免 root 换字体依赖各品牌主题系统的开放程度，先对号入座：

| 品牌 / 系统 | 免 root 情况 |
| --- | --- |
| 小米 / POCO / Redmi（MIUI、HyperOS） | 全版本可用 |
| 华为 / 荣耀（EMUI、HarmonyOS、Magic UI） | 全版本可用 |
| LG | 全版本可用 |
| 三星（One UI） | 范围广，但 2026 年 3 月补丁后免 root 通道被签名校验拦下，新补丁机型基本走不通 |
| vivo / iQOO | Android 12 及以下可直接用；13 起要按专门方法操作 |
| OPPO / realme | Android 9 及以下可直接用；10 起需要把地区切到缅甸才能放开主题字体接口 |
| 一加 / Tecno / Infinix / ASUS | 视系统选项而定，装上实测最稳妥 |

三星用户要特别注意：已经用上第三方字体的，不要随意切换到别的字体——切走就回不来了。

## 二、通用操作步骤

1. 装好工具并完成首次启动的权限授予（存储权限在后面对字体写入时还会用到）。
2. 在 Home 页按风格浏览字体，点进详情先预览，确认效果再下载。
3. 下载完成后点应用（Apply），工具会把字体文件写进系统主题目录。
4. 按界面提示到系统设置里确认：多数机型在「设置 → 显示 → 字体」里选中刚出现的字体项；小米在「设置 → 字体 → 系统字体」里选。
5. 部分机型需要重启一次才全局生效，按提示操作即可。

## 三、Android 11 以上要多做的一步

小米、华为、荣耀、Tecno、Infinix 这几个品牌把主题字体文件放在 `Android/data` 目录里，Android 11 起普通应用写不进去，需要先配一个「文件处理器」。推荐用 Shizuku：手机上装好 Shizuku、打开开发者选项里的无线调试完成配对，再回到工具的 Settings → File Handler 里选 Shizuku 授权即可。配好一次，后续换字体、换 emoji 都走这条路。

三星、LG、OPPO、vivo 等走主题商店接口的机型没有这一步，装完直接用。

## 四、验证与恢复

- **验证**：换完后看三处——系统设置页的菜单文字、任一社交应用的聊天界面、锁屏时间与通知栏。三处里最直观的是系统设置页。
- **恢复**：Settings 标签页里的 Reset Font 一键回到出厂默认字体，部分机型需要重启；换坏了不用担心。

## 五、root 设备的额外选项

已 root 的设备不受品牌表限制：工具能生成 Magisk / KernelSU / APatch 的 systemless 模块，刷入后字体和 emoji 全局覆盖，连自带 emoji 的应用也能换掉。root 有失去保修与变砖风险，普通用户走上面的免 root 路线就够用。

更多功能清单、界面截图与安装包获取入口，见 [zFont3 介绍站](https://zfont3.xnyx.quest/)；相关疑问先看[换字体后部分应用没变化的原因.md](换字体后部分应用没变化的原因.md)。
