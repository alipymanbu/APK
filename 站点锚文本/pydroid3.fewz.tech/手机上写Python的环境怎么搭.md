# 手机上写 Python 的环境怎么搭

> 想在安卓设备上写 Python，不必折腾 Termux 配环境，也不需要刷机：pydroid3 把解释器、编辑器、终端和 pip 打包成了一个应用，装上就能用。本篇讲它的定位、能力边界与安装思路。
> **相关文档**：[pip装库与镜像源配置.md](pip装库与镜像源配置.md) · [常见报错与解决办法.md](常见报错与解决办法.md)

## 一、pydroid3 是什么定位

pydroid3（开发者 IIEC，包名 `ru.iiec.pydroid3`）是一款面向安卓设备的 Python IDE。它最大的特点是**离线可用**——解释器内置在应用里，没有网络也能跑代码、试语法；对新手来说省掉了在手机上手动配环境的全部折腾。

它的能力清单：

- 离线 Python 解释器，打开即写即跑；
- pip 包管理 + 预编译库仓库，numpy、scipy、matplotlib、scikit-learn、jupyter 这类含原生代码的重型库免编译直装；
- PDB 断点调试、支持 readline 的完整终端模拟器；
- Tkinter 开箱即用，Kivy、PySide6、pygame 各有适配；
- 内置 C / C++ / Fortran 编译器，支持 Cython，pip 里没有现成包的库还能试着从源码构建；
- `#Pydroid run` 魔法注释控制运行方式（终端模式 / 各类 GUI 模式）。

代码预测、自动缩进、实时代码分析，以及 OpenCV、TensorFlow、PyTorch 这几个机器学习库属于付费的 Premium 部分；日常学语法、写脚本、常规画图用不到它们。

## 二、安装前想清楚两件事

**架构**：安卓的 APK 按 CPU 架构分开打包，版本号后面的后缀就是架构（如 `8.22_x86_64`）。实体手机多为 arm64，安卓模拟器与 Intel / AMD 处理器的设备则是 x86_64——装错架构系统会直接拒绝，先用 CPU 信息类工具看一下设备的 ABI。

**空间**：应用本身装完之外，装库很吃空间，建议至少预留 250 MB，scipy、jupyter 这类大库要更多。

功能与界面的完整说明，看 [pydroid3 介绍站](https://pydroid3.fewz.tech/)整理得更细；安装步骤与装不上的排查在[常见报错与解决办法.md](常见报错与解决办法.md)里。

## 三、装好之后从哪开始

应用自带一套开箱示例：先跑通一份现成代码，再一点点换成自己的逻辑，比空着写快。想装第三方库看[pip装库与镜像源配置.md](pip装库与镜像源配置.md)，想画图、写窗口应用看[图形界面与matplotlib画图.md](图形界面与matplotlib画图.md)。
