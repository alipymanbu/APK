# M3U 直播源添加与排查：格式、三种载入方式与播放问题处理

## 一、为什么要自己加源

这类聚合播放器内置的频道来自开放网络，优点是即开即用，缺点是源随时可能变动。如果手里已经有合法可用的直播列表或直链，把它们加进应用的 Personal 分区（有的应用叫「My IPTV」），就会和内置频道出现在同一个目录里，照常收藏、搜索，不用再切别的播放器。

以 Orbitv 为例，Personal 分区接受下面这些类型，[orbitv 安装与分区说明](https://orbitv.loveyou.bond/)在介绍站里有整理。

## 二、支持哪些格式

| 类型 | 说明 |
| --- | --- |
| M3U 播放列表 | 一份列表带多个频道，适合批量加入 |
| m3u8 直链 | 常见的 HLS 流媒体地址 |
| mpd 直链 | DASH 流媒体地址 |
| mp4 直链 | 直接的视频文件地址 |

## 三、三种载入方式怎么选

先判断手上的源属于哪一种：

| 你的源 | 用哪种方式 |
| --- | --- |
| 手机里已存好的 `.m3u` 列表文件 | 从文件加载 |
| 一条 M3U 列表地址（URL，一批频道） | 从列表地址加载 |
| 单个 m3u8 / mpd / mp4 直链 | 直接贴地址 |

通用流程（入口与按钮名称随版本可能略有差异，以设备上 Personal 页面实际显示为准）：

1. 准备好上面任意一种源；
2. 进入 Personal 分区，点添加；
3. 按源类型选「文件 / 列表地址 / 单条地址」对应的入口，粘贴或选取；
4. 保存后回到频道目录，加进来的条目会与内置频道一起出现，可照常收藏、搜索。

## 四、来源与合法使用

这类应用只索引开放网络上的公开流，不提供付费频道或订阅频道；自行添加的源，合法性由添加者自己负责——只添加有权使用的来源。这既是应用条款的要求，也是这类应用唯一稳妥的用法。

## 五、加了但不显示或播不动

按顺序检查：

1. **地址粘对没有**：地址要以 `http(s)://` 开头，前后多余的空格会导致识别失败；
2. **格式对不上**：列表内容要是 M3U 结构，普通网页地址播不了；
3. **源本身失效**：把同一个地址丢到别的播放器里验证——能播说明源没问题，是添加方式的问题；不能播就是源已经失效；
4. **源服务器限流或有地区限制**：这种情况下配置再正确也播不了，只能换源。

## 六、画面能出来但不稳

- **卡顿、缓冲多**：通行的参考值是下行 10 Mbps 以上体验较稳；移动流量下信号波动比 Wi-Fi 明显，播放时先停掉后台的大流量活动；
- **频道黑屏**：先换两个别的台区分是单台失效还是整体网络问题，再做「宽带 vs 移动流量」对照测试定位；
- **长期想要某个台**：往 Personal 里添加自己合法持有的源，是最稳的办法。
