# IMVU 是什么：3D 化身社交玩法入门

> 本篇讲 IMVU 这款 3D 化身社交平台的玩法骨架：先捏人、再换装、然后进聊天室交朋友，四大分区各自管什么、新手第一步该做什么。

IMVU 从 2004 年做到现在，是全球规模最大的化身社交平台之一：每月有超过 700 万人来访，用户平均每天在里面待 55 分钟，虚拟商品货架上挂着 4000 多万件玩家自制的衣服、家具与配饰。它和普通社交软件的区别在于——你发的不是照片，而是一个活的 3D 形象。

## 一、先捏人，再谈社交

注册的第一步就是挑初始化身。这只是起点：肤色、脸型、下颚骨、发型、眼睛全部可以后天细调，穿搭配上是另一整套系统。老玩家的经验是「先换头模再买衣服」——同样一身行头，换了头模辨识度立刻不同。

形象立起来之后可以随时摆姿势拍照，加滤镜、发动态流，甚至做成动态表情在聊天里用。

## 二、四大分区就是四件事

手机版主界面分成四块，找任何功能都从这里下手：

| 分区 | 干什么 |
| --- | --- |
| 装扮 | 换装、逛商店、发动态、管积分 |
| 交友 | 聊天室、匹配开聊、找人、送礼 |
| 约会 | 约向聊天室与直播房 |
| 奖励 | 每日转盘、登录奖励、赚积分任务 |

## 三、聊天室是核心场景

交友分区里点开房间列表，可以按语言、人数、分级三个维度筛选——想练口语筛英语房，想安静聊天避开几百人的大房。进房后化身出现在 3D 场景里，点自己选动作（挥手、跳舞、坐下），走到别人化身附近还能触发握手、拥抱这类互动。

认识人之后的路径也顺：点头像加好友、用匹配功能随机找人开聊、看对方愿望清单再送礼，比瞎挑命中率高得多。

## 四、不花钱能玩，花钱有讲究

注册送 150 个推广积分，每天转转盘、做任务能继续攒；但主线时装基本要充值积分。建议先免费玩一周，确认自己会长期玩再决定投入，花钱前把三种货币（充值积分、推广积分、VCOIN）的区别弄清楚。
