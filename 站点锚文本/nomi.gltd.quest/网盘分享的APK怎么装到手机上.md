# 网盘分享的APK怎么装到手机上

> 安卓应用不在商店里时，常见的分发方式是网盘分享：先转存、再下载、再安装。这篇以 Nomi 为例把整个流程讲一遍，重点说清最常卡住人的「未知来源」一步。

## 为什么会多一步「转存」

夸克网盘的分享页默认要先把文件转存到自己的网盘账号，之后才能下载。这一步不是多余的：文件转进自己账号后，随时能重新下载，不再依赖原分享链接的状态——原分享哪天失效了，你手里的副本还在。

## 四步装完

1. **转存**：打开安装包的分享页，登录网盘账号，把文件转存到自己名下；
2. **下载**：手机上打开网盘 App，在「我的转存」里找到安装包，下载到本机存储；
3. **允许安装**：在文件管理器里点开 APK，系统问「是否允许安装未知来源应用」时允许一次。如果被拦，去「设置 → 应用管理 → 特殊权限（不同品牌叫法略有出入）→ 安装未知应用」，给用来打开安装文件的那个应用（文件管理器或浏览器）勾上允许；
4. **打开**：装完点开应用，按首次引导登录就能用。

安装包本身不大，移动网络下也下得动；全程大约五分钟。

## 装完先核对两件事

- **包名对不对**：Nomi 对应的安卓包名是 `ai.nomi.twa`，在系统设置 → 应用里能看到；
- **开发者对不对**：认准 Glimpse.ai 旗下的 Nomi——应用商店里叫 Nomi 的应用不止一款，装错了卸掉重装即可。

安装入口、分步截图与常见问题（打开停在加载页这类）都整理在 [Nomi 安装步骤与资源入口](https://nomi.gltd.quest/)，按页面顺序走就行。
