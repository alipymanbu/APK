# 电竞椅承重身高与保修年限对照：逐夜桌椅的硬判据

挑电竞椅最怕只看外观。逐夜（Blacklyte）的椅子和升降桌各有几条可以直接拿来做判断的硬指标，这篇按「买前挑参数、买后查保修」两段整理。

## 一、买前：承重、身高、面料、椅轮

品牌产品页 FAQ 给出的参考判据：

| 判据 | 参考值 |
| --- | --- |
| 适用体重 | 椅子建议承重不超过 330 磅（约 150 kg） |
| 适用身高 | 建议 165–190 cm，超出区间支撑位置对不准 |
| 布面选项 | Athena 系列有布面可选；Kraken 系列仅皮面 |
| 椅轮 | 各型号轮子通用；仅 Athena X 的刀轮带锁定，其余不能锁 |

型号怎么挑：**Athena Pro** 顶级支撑、**Athena** 均衡、**Kraken Pro** 升级材质；升降桌里 **Atlas** 带灯控、面向带灯效的桌面搭建，**Atlas Lite** 是双电机 + 记忆档位的实用向。这些条目在配套 App 的产品百科里有实拍、规格与演示视频，买前先翻一遍。

## 二、买后：各部件保修多久

保修按部件拆分，不是一个数包全场（分区域条款有差异，以购买地区页面当时显示为准）：

| 产品 | 部件 | 保修期 |
| --- | --- | --- |
| 电竞椅 | 钢制框架 | 终身（部分区域页面口径） |
| 电竞椅 | 机构、轮子、椅座底盘、扶手、气压杆 | 3 年 |
| 电竞椅 | 坐垫海绵与靠背 | 2 年 |
| 电竞椅 | 头枕、腰枕、脚轮及随椅附件 | 1 年 |
| 升降桌 | 框架、桌面、电机、控制器、灯控 | 3 年 |
| 升降桌 | 桌垫 | 1 年 |

几条容易踩的口径：保修从**送达日**起算；发现问题 **14 天内**提交申请，审批通过后换件约 **10 个工作日**发出；保修只对**原始购买者**有效，二手受让按现状处理；**商用场景**（出租、办公、电竞馆）不在范围；部分区域参加晒单活动可把部件保修延到 5 年。

## 三、期限怎么查最省事

不用翻纸质凭证：逐夜 App 从 2.0.7 版本起支持用包装内附带的 NFC 卡片绑定产品，贴卡绑定后保修期限直接显示在产品详情里。具体绑定步骤和「贴卡没反应」的排查，看 [NFC卡片绑定查保修流程.md](NFC卡片绑定查保修流程.md)；品牌和产品线的基本盘，见 [逐夜是什么牌子.md](逐夜是什么牌子.md)。App 的功能全貌（赛事资讯、签到积分、产品百科）也可以先逛逛 [Blacklyte 逐夜介绍站](https://blacklyte.ggcd.online/)，心里有个数再装。
