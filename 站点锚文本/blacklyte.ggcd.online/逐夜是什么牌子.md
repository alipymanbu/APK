# 逐夜是什么牌子：从 CES 亮相的桌面灯到一整套桌面装备

逐夜（Blacklyte）是杭州智华家居科技有限公司旗下的电竞生活品牌，产品线覆盖**桌面灯、智能落地灯、电竞椅与升降桌**。2025 年 CES 上，它的桌面灯靠双面发光设计和铝合金氧化工艺刷过一波存在感——光线扩散均匀、亮度给足同时压住眩光，还支持音乐、屏幕、游戏三种同步光效；同一批亮相的智能落地灯则内置锂电池，不插线也能搬着用。

## 产品线速览

| 品类 | 代表型号 | 一句话定位 |
| --- | --- | --- |
| 桌面灯 | Desktop Lamp | 双面发光 + 三种同步光效，桌面搭建的视觉主角 |
| 落地灯 | Smart Floor Lamp | 内置锂电池，随处可搬 |
| 电竞椅 | Athena / Athena Pro / Athena X、Kraken / Kraken Pro | 从均衡到顶级支撑分档 |
| 升降桌 | Atlas / Atlas Lite | Atlas 带灯控，Atlas Lite 是双电机 + 记忆档位的实用向 |

这个牌子有个特点：硬件只是起点，它给全套装备配了一个 App 当数字入口——赛事资讯、产品百科、签到积分、会员任务，连保修查询都收在里面。想快速了解这个 App 都装了什么，可以看 [Blacklyte 逐夜介绍站](https://blacklyte.ggcd.online/)，四个核心板块挨个拆开讲过。

## 桌椅怎么挑

- 要顶级支撑看 **Athena Pro**，要均衡看 **Athena**，要升级材质看 **Kraken Pro**；
- 品牌产品页的 FAQ 给过两条硬判据：椅子建议承重不超过 330 磅（约 150 kg），适用身高 165–190 cm；
- 面料上 Athena 系列有布面可选，Kraken 系列只有皮面；各型号椅轮通用，只有 Athena X 的刀轮带锁定；
- 桌面向选 **Atlas**（带灯控、配灯效桌面），实用向选 **Atlas Lite**。

具体参数在逐夜 App 的产品百科里有图文、教程和视频，买前把条目翻一遍比看二手经验可靠。装好 App 之后，包装里附带的 NFC 卡片还能用来绑定产品查保修——这部分的操作细节，另见 [NFC卡片绑定查保修流程.md](NFC卡片绑定查保修流程.md)。
