# 文字转语音配音更自然的技巧

> 本篇讲怎么让合成出来的配音少一点机器味：先看问题出在文案层还是参数层，再按标点、用词、种子与背景乐逐层调整。示例以 ChatTTS 安卓版为例，思路对同类工具同样适用。

## 一、先定位：机器味从哪来

配音听着发僵，原因大多不在工具而在喂进去的文本。对照下面几种症状找方向：

| 症状 | 多半的原因 | 先做什么 |
| --- | --- | --- |
| 念得又快又赶 | 长句连排、缺标点 | 拆短句、补逗号句号 |
| 全程一个调 | 整段同长度陈述句 | 长短句交替，插一个问句 |
| 人名、数字念错 | 数字与缩写没展开 | 数字写汉字、缩写换全称 |
| 该停没停 | 只用逗号 | 句号、省略号分级控停顿 |

## 二、文案层的四个写法

1. **标点就是停顿**。逗号短停、句号中停、省略号带犹豫感；长句在换气处补逗号，想强停直接拆成两句。
2. **数字写成汉字**。「2026」改成「二〇二六」，金额、序号同理，误读率立刻下降；念不准的字词换个写法，比反复重生成省事。
3. **书面语换口语**。「进行查看」改「看一下」，「如下图所示」这类只活在纸面上的说法直接删；一句只装一个意思，自己念着不换气才适合整句喂进去。
4. **列表别用顿号连到底**。条目之间给个句号或直接换行，念出来的节奏马上稳住。

## 三、参数层的三个抓手

文案改顺了还不满意，再动界面上的滑杆（以 ChatTTS 安卓版的参数区为例）：

- **temperature（背景噪声强度）**：默认 0.7。念教程、说明类内容调低一点更稳；广告、宣传类调高一点语气更活。
- **top_P / top_K**：听到怪音先降它们，让每一步发音更保守。
- **文本种子**：返工某段时把种子记下来，同文本同种子，韵律接近可复现，不用每次从零试。

另外勾上「符号文本优化」，标点杂的长文案会先被整理一遍再合成，能减少把括号、符号念出声的尴尬。

## 四、最后一步：垫背景乐

导出的干声直接用，生硬感会全露出来。进剪辑软件后铺一层 5%~10% 音量的背景乐或环境音，加到刚能察觉为止——低音量氛围声能盖住细微的合成感，这一步的听感改善比反复重生成划算得多。
