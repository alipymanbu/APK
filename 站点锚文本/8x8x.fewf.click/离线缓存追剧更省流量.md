# 离线缓存追剧更省流量

> 本篇讲用播放应用的离线缓存功能追剧时，怎么选画质、怎么管空间、缓存失败怎么排查，让流量和存储都花在刀刃上。

追剧族月底流量超标的常见原因，是把在线播放当成了唯一看片方式。带离线缓存的应用（以 8x8x 为例）用得好，流量能省下一大截：Wi-Fi 环境下把片子提前缓存好，路上断网看，流量一点不烧。

## 一、缓存前先定画质

同一部片，不同画质的体积差得很远，缓存前按用途选：

| 用途 | 建议画质 |
| --- | --- |
| 通勤路上、流量环境 | 720P，省空间够清晰 |
| 家里 Wi-Fi 追剧 | 1080P，画质与体积平衡 |
| 存高画质片源、空间充裕 | 4K（单部体积明显更大，先确认剩余空间） |

## 二、缓存的正确姿势

1. 找到目标影片，进入详情 / 播放页；
2. 点「缓存」或「下载」，选好画质开始；
3. 多部影片可以排队同时下，进度在下载列表里看；
4. 缓存完成后在缓存列表直接播，断网也能看。

配套习惯：晚上睡前把第二天要看的排上队，早出门即点即看；追长剧时一次多缓存几集，路上不用来回折腾。

## 三、空间管理三条

- 缓存的影片和普通视频一样占存储，看完就在缓存管理里删掉，别等系统弹「空间不足」；
- 首次启动授予的存储权限别关，关了缓存功能会失效；
- 下载前选好画质，比事后清理省事得多。

## 四、缓存失败排查

部分冷门资源缓存失败，多数是片源线路的问题，不是手机坏了：

- 换一条线路再缓存，同一部片不同线路可用性不一样；
- 换个时段重试，线路繁忙时容易失败；
- 分不清是网络还是片源：Wi-Fi 和流量互换着试同一部片，两边都失败才更像片源问题；
- 在线播放正常、缓存始终不动的，直接在线看或投屏；
- 提示空间不足，先清已看完的缓存再试。

画质档位怎么和自家带宽匹配，[8x8x 观影速览站](https://8x8x.fewf.click/)里有一份按网络环境给的对照建议，缓存前可以先看一眼再定档。

把「Wi-Fi 缓存、离线播放」变成习惯，流量账单和观影体验会同时改善——这是追剧应用里最值得学的一个用法。
