# 手机看剧投屏电视方法

> 本篇讲把手机里正在播的剧投到电视上的通用方法：三个前提、五个步骤，以及投上去了但不理想的几种处理。
> **相关文档**：[追剧播放器功能盘点](追剧播放器功能盘点.md) · [离线缓存追剧更省流量](离线缓存追剧更省流量.md)

---

手机屏幕再大也不如客厅电视舒服。以 8x8x 这类带投屏功能的播放应用为例，把投屏这件事拆成前提、步骤和排障三段说清。

## 一、先满足三个前提

| 前提 | 怎么确认 |
| --- | --- |
| 手机和电视在同一 Wi-Fi | 手机设置里看的 Wi-Fi 名，要和电视网络设置里的一致 |
| 电视开了投屏服务 | 智能电视一般在「设置 → 网络」或「我的应用 → 无线投屏」里；老电视可以接一个支持 DLNA 的盒子 |
| 播放应用装好、能正常播 | 在手机上先确认片子能播，再谈投屏 |

## 二、五步投上去

1. 手机和电视连同一个 Wi-Fi；
2. 电视端打开 DLNA / 无线投屏服务（小米电视：我的应用 → 无线投屏）；
3. 打开播放应用，搜到想看的片，进入播放页；
4. 点播放页里的「投屏」按钮；
5. 在设备列表里选中你的电视，连上即播。

投屏成功后手机就是遥控器：进度、清晰度、音量、选集都在手机上操作，退出播放页去回消息、刷网页，电视上的播放不受影响。

## 三、投上去了但不理想

- **画面卡顿**：把清晰度从 4K 降到 1080P，并关掉家里其他占带宽的下载任务；
- **有声音没画面**：多为该路片源格式特殊，换一条线路或换一部影片验证；
- **设备列表搜不到电视**：先查路由器是否开了「AP 隔离」（开了设备之间互相看不见），再确认手机没离路由器太远；
- **看一半断开**：依次重启路由器、电视、手机再重连，多数是网络临时波动；手机 Wi-Fi 省电策略有时会掐后台连接，投屏时先关掉。

想了解 8x8x 本身的画质档位和播放设置，[8x8x 观影速览站](https://8x8x.fewf.click/)里有按网络环境给的清晰度选择建议，可以直接对照着调。

## 四、设备差异一句话

- 小米 / Redmi 电视：记得在「我的应用」里手动启用「无线投屏」；
- 支持 AirPlay 的电视：从控制中心走「屏幕镜像」更省事；
- 老电视：接个电视盒子当投屏目标，兼容性通常比电视自带服务更稳。

把三个前提核对好，绝大多数投屏问题都出在 Wi-Fi 这一层——先查网络，再查设置，最后才考虑换设备。
