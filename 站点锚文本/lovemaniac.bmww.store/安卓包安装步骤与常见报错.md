# LoveManiac 安卓包安装步骤与常见报错

这篇把 LoveManiac 的安卓安装从头到尾走一遍：包从哪儿来、装之前要开什么权限、四步怎么装，以及解析错误、安装被拦、打开闪退这三个最常见的拦路问题。玩法部分另见 [玩法路线与弹幕躲避入门.md](玩法路线与弹幕躲避入门.md)。

## 一、装之前先知道三件事

- **这是 18+ 成人向同人作品**：含成人情节与用语，未成年设备请不要安装；
- **它是同人作品**：与《Undertale》原作及作者 Toby Fox 无关联，属于粉丝自制；
- **手上的包是哪一版**：分享渠道流传的安卓包版本不一，安装界面显示的包名应为 `com.teamnebula.lovemaniac`，对不上就取消安装。

## 二、四步装进手机

1. **拿到分享地址并转存**：在[lovemaniac 玩法与安装指引站](https://lovemaniac.bmww.store/)的下载页有现成的网盘入口，打开后先把整个分享转存到自己的网盘账号，再从自己账号下载；
2. **APK 下到手机本地**：别在网盘预览页里直接点"打开"，等文件完整下到本地存储再操作；
3. **允许未知来源安装**：首次点 APK 时系统会弹窗询问，允许"来自此来源的应用"即可；小米、华为等品牌直接在弹窗里点允许，不必提前去设置里翻；
4. **安装并首次打开**：进度走完点打开，首启申请存储权限（读写存档用）允许即可；首次加载偏慢是正常的，别连点。

安装完成后，虚拟按键怎么用、弹幕怎么躲，接着看 [玩法路线与弹幕躲避入门.md](玩法路线与弹幕躲避入门.md)；版本与语言问题见 [版本更迭与语言现状.md](版本更迭与语言现状.md)。

## 三、三个高频报错的处理

- **「解析错误 / 应用未安装」**：基本是包没下完整——删掉重下，下完确认文件以 `.apk` 结尾；安装要临时空间，建议预留 500M 以上；
- **点安装被拦「禁止安装」**：未知来源权限没开。弹窗里点"设置"打开"允许来自此来源"再返回继续装；
- **装上了打不开 / 闪退**：先确认系统不低于 Android 7.0；存储权限被拒会读不到资源直接退出，去应用信息里补权限；首启慢，等十几秒再动；清后台释放内存后再进一次。
