# LoveManiac 玩法路线与弹幕躲避入门

这篇讲 LoveManiac 的玩法骨架：剧情线怎么选路线、战斗线怎么躲弹幕、手机和电脑分别怎么操作，给准备上手或刚上手的玩家一个底。安装环节卡住了先去 [安卓包安装步骤与常见报错.md](安卓包安装步骤与常见报错.md)；版本差异见 [版本更迭与语言现状.md](版本更迭与语言现状.md)。

先交代背景：这是 Team Nebula 开发中的 2D 像素风 Undertale 同人恶搞 RPG，18+ 成人向、未成年勿入；与原作及 Toby Fox 无关联。想整体了解这款游戏，可以看 [lovemaniac 安卓版玩法与安装](https://lovemaniac.bmww.store/) 介绍站。

## 一、玩法两条线

1. **剧情与对话**：在像素场景里走动、交谈，不同的对话与 ACT 选择会把路线带向不同分支——作者简介那句"很多条路线最后是同一个结果，Chara 要跟你做个交易"已经点明它是多周目结构；
2. **弹幕战斗**：进入战斗后屏幕中央出现小方框，里面的红心就是你。敌方回合拖动红心躲刀刃类弹幕，轮到你再选 FIGHT / ACT / ITEM / MERCY。数值不是重点，走位才是。

## 二、上手前半小时怎么玩

- 先跟着开场熟悉移动与对话点按；
- 第一场战斗别急着赢，练"把红心移进弹幕缝隙"——躲得住就赢一半；
- 游戏没有难度选项（玩家求了很久也没加），弹幕关死几次属正常，换摇杆控件、红心贴方框边缘走会好一些；
- 某段剧情走不动时先按一次确认键再判断是不是卡死，别急着退出重开。

## 三、操作速查

**安卓触屏**：虚拟方向键 / 摇杆移动（设置里可切换，部分场景摇杆更顺手）；点按推进对话与菜单；战斗部分场景直接手指拖红心。虚拟按键偶尔失灵，点一下屏幕空白处或换一套控件即可恢复；对话推进尽量点对话框本身，点画面空白处可能直接跳过场景。

**Windows / Linux 键盘**：方向键移动，`Z` / `Enter` 确认，`X` / `Shift` 取消——Undertale 系同人最通用的键位。键位暂不能自定义；个别键没反应先确认输入法在英文状态。

## 四、新手常见疑问

- **进度会丢吗**：有玩家反馈跨大版本更新会丢存档，且当前版本没有存档导出/导入功能，大版本更新前心里有数；
- **过场动画能跳吗**：0.3.3 不行，0.3.4 起支持跳过（对照 [版本更迭与语言现状.md](版本更迭与语言现状.md)）；
- **某场战斗里动不了**：若是 0.3.3，"战斗中失去移动控制"这个 bug 要到 0.3.4_2 才修，只能升版本解决。
