# Pydroid 3 安卓版下载与安装入口

本篇讲 Pydroid 3 安卓版从哪里获取、装到手机上分几步，以及安装前后各要注意什么。功能与库生态的完整盘点见[手机上跑Python的几种方式](手机上跑Python的几种方式.md)。

---

Pydroid 3 是安卓设备上的 Python 3 开发环境，内置离线 CPython 解释器，写代码、跑脚本、调试都不依赖网络。想直接拿安装文件资源的，可以走 [Pydroid 3 安卓版介绍站](https://pydroid3.ggcd.uno/)，站点里的获取入口指向网盘分享，先转存再下载，比到处找安装包稳得多。

## 安装步骤概览

1. 打开获取入口，把资源转存到自己的网盘账号；
2. 从网盘把安装包下载到手机本地；
3. 系统提示"禁止安装未知应用"时，按提示给对应应用授权；
4. 完成安装，首次启动联网初始化环境，之后就能离线使用。

## 安装前后的注意点

- **存储空间**：应用加基础环境建议预留 250MB 以上，装 SciPy、PyTorch 这类大库还要更多；
- **首次初始化**：需要联网等它准备完，建议在 Wi-Fi 下做；
- **装库口径**：在 Pip 界面勾上"使用预编译库"，多数科学计算库能直接装现成的，具体思路见[科学计算库手机安装思路](科学计算库手机安装思路.md)。

安装被拦截、初始化卡住这类问题，站点的安装页里按现象给了解法，对照处理即可。
