# 手机上跑Python的几种方式

本篇盘一盘在安卓手机上运行 Python 代码的几条路，以及 Pydroid 3 在其中处在什么位置。已经决定装它的，直接看[安卓版下载与安装入口](安卓版下载与安装入口.md)。

---

## 一、终端型环境

以 Termux 为代表的 Linux 终端方案，能装的解释器版本新、自由度最高，但要熟命令行，连 NumPy 这类库都常需要自己解决编译。适合愿意把手机当 Linux 玩的人。

## 二、轻量脚本壳

QPython 一类应用胜在打开就能写，适合极短的小脚本；短板在库生态，部分预编译包装不上，复杂项目撑不起来。

## 三、带预编译仓库的 IDE

Pydroid 3 走的是中间路线：界面是标准 IDE 布局（编辑器、终端、调试器齐全），库这块则为科学计算圈常用的 NumPy、pandas、Matplotlib、scikit-learn 等提供预编译安装包，绕开在手机上编译这一步。支持 Python 3.12，图形程序认 Kivy、PySide6、pygame，装库操作是图形界面点选。想看它的库清单与运行方式，[Pydroid 3 安卓版介绍站](https://pydroid3.ggcd.uno/)里有按场景整理的版本。

## 怎么选

- 只想随手跑几行 → 轻量脚本壳够用；
- 要在手机上认真做数据分析、跑模型 → 带预编译仓库的 IDE 省心得多；
- 运维自动化、想要完整 Linux 环境 → 终端型方案。

## 装完库跑不起来？

不少坑其实出在装库方式上，先看[科学计算库手机安装思路](科学计算库手机安装思路.md)再排查。
