# 科学计算库手机安装思路

在手机上装 NumPy、Matplotlib 这类库，失败的原因大多不是"库太大"，而是走了编译这条路。本篇讲为什么预编译是关键，以及装库失败时从哪里排查。还不清楚基础装法的话，先过一遍[安卓版下载与安装入口](安卓版下载与安装入口.md)。

---

## 为什么手机上装库容易失败

桌面环境装 Python 库，pip 找不到现成的二进制包时可以现场编译。手机不是：编译工具链不完整、存储与内存都紧，源码安装动辄几十分钟还以失败告终。所以在安卓上装科学计算库，思路和电脑上不一样——**优先找预编译好的安装包**。

## Pydroid 3 的处理方式

它为科学计算方向的常用库维护了预编译仓库：NumPy、SciPy、SymPy、pandas 负责数据与计算，Matplotlib、Seaborn 负责画图，scikit-learn、TensorFlow Lite、PyTorch 覆盖机器学习，OpenCV 在支持 Camera2 API 的设备上也可用。操作上不敲命令行，在 Pip 界面搜索库名、勾上"使用预编译库"再装即可，装好的库在 LIBRARIES 页统一管理。

各个方向的库分别有哪些、图形界面库（Tkinter、Kivy、PySide6、pygame）怎么跑，[Pydroid 3 安卓版介绍站](https://pydroid3.ggcd.uno/)按用途做了分类整理。

## 装库失败排查顺序

1. **勾了预编译选项没有**——这是最常见的坑，图形界面里装库时记得勾选；
2. **存储够不够**——基础环境之外，大库还要留出解包与缓存的空间；
3. **网络稳不稳**——首次初始化与装库都需要联网，移动网络不稳时换 Wi-Fi；
4. **库本身有没有设备要求**——个别库（如 OpenCV）对硬件接口有要求，机型太旧装不上属正常。

## 装好了之后

交互 Shell 里 import 一下不报错就是成了。Tkinter 程序没窗口这类运行端的问题，看[手机上跑Python的几种方式](手机上跑Python的几种方式.md)里的运行方式对照。
