# Qiz 安卓安装包下载安装步骤

> 本篇讲这款兴趣社交应用的安卓安装包怎么获取、怎么装进手机，以及装不上时的三种常见处理。安装包统一从夸克网盘分享获取，入口在文末的介绍站里。玩法层面的内容见 [兴趣标签交友怎么玩.md](兴趣标签交友怎么玩.md)。

Qiz 是一款以兴趣标签做匹配的社交应用，安卓端走安装包侧载路线——应用商店在线的版本通常更新，而网盘分享里留存的这一版信息如下（以实际拿到的包为准）：

- 版本：1.0.1
- 体积：约 57.12 MB
- 系统要求：Android 7.0 及以上
- 包名：`com.yueai.fori`

## 一、获取安装包

1. 打开文末介绍站，进入安装获取页，点「获取安装文件资源」会跳到夸克网盘的分享页。
2. 手机上装了夸克 App 的直接打开最省事；选中安装包，**先转存到自己的网盘、再下载**——转存过的那份不受分享链接后续变动影响。
3. 下载完成后核对体积是否约 57 MB，体积差太多说明没下完整，装的时候会直接报「解析包错误」。

## 二、安装四步

1. **给文件管理器开安装权限**：进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把用来打开安装包的那个应用（文件管理器或浏览器）的开关打开。国产定制系统里这项常收在「安全」或「隐私」分类下。
2. **点开安装包**：系统提示「来自未知来源」或「未经安全检测」时选择继续——这是侧载安装包的常规提示，不代表文件有问题。
3. **处理旧版本冲突**：安卓不允许用低版本覆盖高版本；如果手机里已经装过同包名的更高版本，先卸载再装。同包名不同渠道的包签名不一致，也会报「应用未安装」，同样先卸载旧的。注意卸载会一并清掉仅存在本机的聊天与数据。
4. **首次进入**：确认手机能联网；第一次进入需要注册或登录（一般是手机号加短信验证码）；进入主界面后按提示把通知、麦克风、定位几项权限给到，语音匹配和「附近的人」才用得起来。

## 三、装不上的三种常见情况

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 解析包错误 | 安装包下载不完整 | 删掉残缺包，从网盘重新下载，核对体积再装 |
| 应用未安装 / 签名不一致 | 已装同包名的另一个渠道版本，或回装了更低版本号 | 先卸载旧包再装这份 |
| 安装被安全中心拦截 | 侧载包被系统安全策略拦下 | 在安全中心的拦截记录里选「继续安装」 |

装好之后别急着刷匹配，先把兴趣标签填具体——标签是这类应用推荐与匹配的底层依据，填得越准，遇到同频的人越快。应用的玩法与功能细节，在 [Qiz 介绍站](https://qiz.fewf.ren/) 里有整理。
