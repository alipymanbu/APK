# 电子会员卡怎么出示与扫码进门

> 本篇讲 Priority Pass 真正「用出去」的那一步：到贵宾室门口，怎么把电子会员卡调出来、前台怎么扫、哪些情况会被拒。出发前花两分钟读完，能省掉现场最尴尬的排队折返。
> **相关文档**：[贵宾室会籍从哪里来怎么激活.md](贵宾室会籍从哪里来怎么激活.md) · [到访次数与随行宾客怎么算.md](到访次数与随行宾客怎么算.md)

---

整套贵宾室权益，最后都落在门口那一次扫码上。电子会员卡做成了 App 内的一张二维码/条码卡片，几乎所有贵宾室的前台设备都认它——这也是它比实体卡更常被推荐的原因。

## 一、门口的操作就三步

1. 进厅前打开 App，切到「卡」选项卡；
2. 把电子会员卡的二维码/条码出示给前台；
3. 前台扫码登记，屏幕上会核对持卡人与随行人数，确认后放行。

全程无接触，手机锁屏状态下也能快速调出（支持指纹或面部识别直接解锁进卡面）。

## 二、出发前先做这三个确认

- **卡能显示**：登录后「卡」选项卡里能看到带二维码的电子卡。显示不出来通常不是网络问题，而是会籍类型或激活状态没到位，先回激活环节排查；
- **厅认不认电子卡**：个别贵宾室的读卡设备只收实体卡，或对电子卡有单独规定——在 App 的贵宾室详情里翻「设施」说明就能确认；
- **手机有电**：电子卡依赖手机工作，手机没电就什么都调不出来。长途出行建议实体卡随身带，这是最省事的兜底。

## 三、被拒入场的几种常见原因

遇到前台说「进不了」，多半是下面几条之一：

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 查不到有效会籍 | 账户激活未完成、登录了错误账户 | 回激活页核对会员编号后重新登录 |
| 随行人数超限 | 该厅限定每位持卡人可携人数（常见 1～2 位） | 超出部分按人次付费，或分批进入 |
| 方案不含该厅 | 个别贵宾室不参与该会籍档位 | 换同机场其他参与厅，详情页可筛 |
| 逗留超时 | 各厅有最长逗留时间（常见 3 小时） | 超时部分按厅内规定结算 |

规则逐厅不同，拿不准就进门前翻一眼该厅详情页。整套查厅到扫码的流程演示，[Priority Pass 贵宾室使用指南](https://priority-pass.ggcd.store/)站内按真实界面逐步走了一遍，可以对照着操作。

## 四、进门之后

扫码成功，这次到访就开始记账了：App 里会先出现「处理中」，离厅后结算完成、剩余次数随之更新。账目规则（次数怎么扣、随行怎么收费）在 [到访次数与随行宾客怎么算.md](到访次数与随行宾客怎么算.md) 里单独讲。
