# 按应用锁定屏幕方向的方法

「进视频应用就横屏、回微信就竖屏」——这种跟着应用走的方向规则，靠系统开关和手动切换都实现不了，得给每个应用单独定规则。这篇讲这类规则的配置思路和注意点。

## 一、规则长什么样

按应用的定向规则通常是这个结构：**指定某个应用 + 指定一个方向模式**。之后每次该应用切到前台，规则自动生效；切走后交还给全局设置。常见的配法：

| 应用类型 | 建议方向 |
| --- | --- |
| 视频、横版游戏 | 强制横屏 |
| 阅读、小说、新闻 | 强制竖屏 |
| 地图、导航 | 传感器自动 |
| 银行、政务类 | 自动旋转关（锁竖屏防误触） |

## 二、实现路径

安卓原生没有这个能力，需要借助方向管理工具。[rotation 屏幕方向管理工具](https://rotation.wxhp.skin/) 的做法是：主界面先定全局默认模式，再单独给个别应用加「应用方向」规则覆盖全局，只给真正需要的应用定制。它的条件系统里还有通话、锁屏、耳机、充电、底座这些事件维度，可以和按应用规则叠加使用。

因为「识别当前前台是哪个应用」依赖系统的使用情况访问授权，配置按应用规则前，先把「使用情况访问」「悬浮窗」两项权限批掉，否则规则不命中。

## 三、优先级：多个规则撞车时谁说了算

充电时插着耳机、前台又是视频应用——三个条件同时成立是常事。这类工具内部给条件排了优先级，撞车时优先级高的生效。配置建议：

1. 全局默认模式定一个基底（比如传感器自动）；
2. 只给少数真正在意的应用加定向规则，别全量铺；
3. 把「最不能接受被打破的场景」的优先级顶上去——最烦充电乱转就把充电条件排前，最在意视频横屏就把应用方向排前。

出了「不该转却转」的情况，也按这三层倒着查：全局模式、单应用规则、条件优先级，一层一层排除。

## 四、个别应用显示错乱怎么办

少数应用被强制到特定方向后界面会错乱，尤其是那些自己写死了方向的。处理办法是对这类应用单独放行：把它的规则设成「自动旋转开 / 关」，让它走系统默认逻辑，其余应用继续享受规则。
