## 先搞清楚规则

这款应用走点数制，不是月费订阅：充值只买点数包，每发一条消息按模型档位扣点。免费部分靠注册奖励与每日签到攒（以下为 2026 年公开资料口径，以应用内实际显示为准）：

| 项目 | 点数（约） |
| --- | --- |
| 注册奖励 | 500（一次性） |
| 每日签到 | 300/天 |
| 故事模式 · 最高档模型 | 195/条 |
| 故事模式 · 中档模型 | 90/条 |
| 故事模式 · 基础档模型 | 30/条 |
| 角色模式 · 基础模型 | 免费不限量 |

## 四个省点习惯

1. **故事模式降档**：把最高档留给关键剧情，日常推进用中档或基础档，同样的签到点数能多推好几幕。
2. **短会话摊开用**：与其一次聊到见底，不如早晚各推一段，把当天签到点数摊满一整天。
3. **行动写具体**：每条输入都是钱。「继续」「？」这类低信息量消息等于白烧点数；一次把行动与意图写清楚，一条顶三条。
4. **角色模式兜底**：点数烧完就切到角色模式用基础模型聊，官方口径是免费不限量——剧情线暂停，陪伴线不断。

另外留意活动：应用内加了兑换码（coupon）功能，运营方会不定期在社区渠道放码，能白拿一笔点数。
