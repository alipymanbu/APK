# DramaBox 免费看剧与解锁规则

> 本篇讲 DramaBox 的解锁体系：免费额度有多少、金币怎么赚怎么花、订阅值不值、不想续费去哪取消，帮你在追剧前把账算明白。
> **相关文档**：[内容形态与题材盘点.md](内容形态与题材盘点.md) · [安卓安装步骤与常见问题.md](安卓安装步骤与常见问题.md)

## 一、先搞清免费额度

大多数剧是「前几集免费、后面按集解锁」的结构。第三方整理的口径：每部剧开头 5~10 集免费，另有每日免费集（当日有效），看广告也能解锁部分后续集（有每日上限）。各剧额度不完全一样，判断方法很直接——从第一集往下翻，第一次出现锁的地方，就是这部戏免费额度的终点。

## 二、金币：两种币别混了

- **付费金币**：充值所得，不过期；
- **奖励金币**：签到、看广告、做任务拿的，会过期（多为当日或短期内失效），当天领的当天用。

签到与任务入口在主界面右上角的礼盒或奖励图标里，连续签到奖励递增、断签重置；任务还包括累计观看时长、看激励视频等，以应用内实际显示为准。看广告解锁必须完整看完才发奖励，且有每日上限（随版本与地区浮动）。

**一个省金币的习惯**：不打算花钱的话先把自动连播关掉——遇到付费集它会直接扣金币，余额就是这么被悄悄耗光的。解锁前先看一眼剩余集数，算完账再点。

## 三、订阅：按周算钱，全站可看

订阅期内解锁全站剧集，也免掉广告打断。第三方整理的价格口径（截至 2026-09，以应用内实际显示为准，各地区差价很大）：周订阅约 $5.99/周（新用户首周常有约 $3.99 促销价），年费约 $49.99/年。

订阅前避开两个最常见的误会：

1. 周订阅不是月费——约 $5.99 是一周的价格，一个月会扣四次；
2. 卸载应用不等于取消订阅——费用照扣，取消必须回到商店账户设置里操作。

## 四、取消续费去哪操作

订阅走应用商店扣款，取消也在商店里：

- **安卓**：Google Play → 头像 → 付款与订阅 → 订阅 → 选中 DramaBox → 取消；
- **iPhone**：设置 → Apple ID → 订阅 → 选中 DramaBox → 取消。

取消后，当期已付的时段一般还能用到到期日。扣款争议走商店渠道申请退款，走不通再联系应用内的客服邮箱。

## 五、三条路怎么选

碎片时间偶尔看两集，免费额度加签到基本够用；集中追一两部长剧，奖励金币撑得住前半段；长期重度观看，订阅才是每集成本最低的方式。想把应用先装上试试的，安装步骤见[安卓安装步骤与常见问题.md](安卓安装步骤与常见问题.md)；这款应用整体什么样的，[DramaBox 短剧介绍站](https://dramabox.fewa.skin/)里有完整介绍。
