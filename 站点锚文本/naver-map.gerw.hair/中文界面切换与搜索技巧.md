# 中文界面切换与搜索技巧

> 本篇讲 NAVER Map 的中文界面怎么开、开完之后搜地点用什么输入最准——这是新用户最常碰壁的两步。
> **相关文章**：[韩国出行为什么用本地地图](韩国出行为什么用本地地图.md) · [公交地铁实时查询与驾车导航](公交地铁实时查询与驾车导航.md)

## 一、切到简体中文的路径

界面默认韩文。按 NAVER 帮助中心给的路径（安卓）：

1. 打开应用，点搜索框右侧的 **MY 图标**（头像 / 人形图标）；
2. 点右上角的**齿轮设置**；
3. 找到 **언어 / Language** 一项；
4. 从韩语 / 英语 / 简体中文 / 日语四种里选「简体中文」；
5. 切换会自动重启应用，重开即中文界面。

两点提醒：只有简体、没有繁体；部分老教程写「左上角三条杠 → 设置」是旧版界面入口，找不到时两个入口都点一遍。

## 二、版本门槛

语言设置功能从 5.1.3 版本起提供；5.0 及以上版本只能装在 Android 8.0 及以上系统。装了更老的版本、设置里没有语言一项时，先升级再切。

## 三、中文界面 ≠ 中文搜得到一切

界面语言管的是按钮与菜单，搜地点另有门道，按命中率排：

1. **韩文名最准**：出发前把店家的韩文名复制好，粘进搜索框基本不失手；
2. **简体中文可用，繁体搜不到**：同一个地点用简体写才匹配得上；
3. **电话号码是捷径**：商家在 NAVER 登记过电话的，直接搜号码就能定位到店；
4. **英文与罗马拼音也行**：输入 `Gangnam Station` 这类罗马字写法可以直接命中韩文站名；
5. 公交线路号、地铁站名用数字与站名搜，与界面语言无关。

## 四、地图标注与评价的翻译

- 界面切了中文，地图上的韩文地名标注是否跟着变，随版本与地区不同，以实际界面为准；
- 商家详情页里有翻译入口，可以把用户评价翻成设置的语言；
- 导航语音的语言与界面语言是两回事，中文语音有没有、在哪开，以当时版本的设置项为准。
