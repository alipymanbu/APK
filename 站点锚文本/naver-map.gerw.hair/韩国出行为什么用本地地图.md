# 韩国出行为什么用本地地图

> 本篇回答一个出发前最常搜的问题：去韩国到底该装哪个地图App，为什么大家都在推荐 NAVER Map 这类本地应用。
> **相关文章**：[中文界面切换与搜索技巧](中文界面切换与搜索技巧.md) · [公交地铁实时查询与驾车导航](公交地铁实时查询与驾车导航.md)

## 一、境外地图在韩国的真实表现

不少习惯用境外地图App的旅行者，落地首尔后发现导航不好使：能打开、能搜到地点，但完整的步行、驾车、公交导航给不出来。原因不在网络也不在账号——韩国限制高精度地理数据出境，境外服务的地图数据处理在境外服务器，拿不到本地应用用的那套细粒度路网。2026 年 2 月韩国政府对数据出口给出有条件批准后，情况有松动，但截至 2026 年年中，境外地图在韩国仍未上线完整的逐步导航。

实际表现集中在几处：步行路线只画到街区边缘；公交线路缺项或不准；实时公交到站缺失；小巷与支路绕不过去。

## 二、本地应用之间的分工

韩国本土常用的两款地图是 NAVER Map 与 KakaoMap，多份 2026 年攻略给的分工建议一致：

| 场景 | 更合适的选择 |
| --- | --- |
| 公交换乘、地铁出口号、实时到站 | NAVER Map |
| 驾车导航、通行费预估、车道级引导 | NAVER Map |
| 查餐厅、看评价 | NAVER Map |
| 离线地图下载 | KakaoMap |
| 打车（接 Kakao T） | KakaoMap |

两个应用都装、互相印证是常见做法；只挑一个的话，多数行程 NAVER Map 够用。它的搜索也吃得下多语言输入：英文、罗马拼音、简体中文、商家电话号都能命中，中文界面同样可以在设置里切换，具体路径见 [中文界面切换与搜索技巧](中文界面切换与搜索技巧.md)。

## 三、用之前要知道的两件事

- **交通卡照样要带**：地图应用只给车费预估与路线，上车刷卡仍要刷 T-money 这类交通卡；
- **流量是刚需**：路线与实时到站都在线拉取，落地前备好当地 SIM / eSIM，没网时地图明显变慢。
