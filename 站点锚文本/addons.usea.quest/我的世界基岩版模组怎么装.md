# 我的世界基岩版模组怎么装：从下载到激活的完整流程

> 本篇讲《我的世界》基岩版（PE / 手机版）安装 Add-Ons 模组的完整链路：文件从哪来、怎么进游戏、怎么在世界里激活，以及每一步最常撞上的坑。
> **本目录其他文章**：[模组地图皮肤资源类型一览.md](模组地图皮肤资源类型一览.md) · [安卓版安装步骤与常见问题.md](安卓版安装步骤与常见问题.md)

## 一、先分清：Add-Ons 是什么、和普通 mod 差在哪

基岩版（手机 PE、Windows 版、主机版）不兼容电脑 Java 版的 .jar 模组，它有自己的扩展体系——Add-Ons。一个 Add-On 通常由两部分组成：**资源包**负责外观与音效，**行为包**负责生物习性与游戏规则。两者可以分开用，但大多数玩法类模组两包齐装才完整。

文件后缀认三种就够：

| 后缀 | 是什么 | 导入后的动作 |
| --- | --- | --- |
| `.mcpack` | 单个资源包或行为包 | 提示导入成功，去世界设置里激活 |
| `.mcaddon` | 多包合集 | 一次导入多份，同样去激活 |
| `.mcworld` | 整张带模组的地图 | 直接进入该世界，无需再激活 |

看到 `.jar` 就说明拿的是 Java 版资源，基岩版永远用不了。

## 二、资源从哪来

Add-Ons 散落在社区各处，手动收集要自己辨版本、自己放文件。更省事的做法是用现成的资源库应用，比如 [addons 模组库](https://addons.usea.quest/)介绍的这款工具：资源按分类陈列、上架前经过测试打包，应用内点两下就能完成下载和导入，安卓与 iOS 的按钮略有差异但流程一致。

## 三、导入：两个平台各一句话

- **安卓**：在应用里点 DOWNLOAD 下载，完成后点 INSTALL，出现安装成功提示后**彻底退出并重启游戏**，包才会出现。
- **iOS**：下载完成后底部菜单选 Copy to Minecraft，游戏自动启动并弹导入提示；`.mcworld` 直接进世界，`.mcpack` 提示成功导入。

补充两条：文件最好放在手机内部存储（SD 卡或纯网盘目录游戏有时扫不到）；点文件没反应时走游戏内万能入口——设置 → 存储 → Import，手动选文件。

## 四、激活：最容易漏的一步

导入 ≠ 生效，还要在世界设置里激活：

1. 主界面 Play → 点世界旁的铅笔图标进编辑页（新世界则在创建页直接设置）；
2. 左侧找到 **Resource Pack** 与 **Behavior Pack** 两个标签，在 **Available** 列表里找到刚导入的包 → 点 **Activate**；
3. 包挪进 **Active** 列表才算装上；确认弹窗里注意别点到"不添加"那一侧——绿色按钮常常是"取消"，点下面那颗才对。

**激活按世界生效**：在 A 世界开过，新建的世界要重新开。只开资源包，新生物会站着不动；只开行为包，它会显示成白盒或缺材质——两边都进 Active 才算完整。

## 五、装了没效果怎么排查

按顺序查，多数在前两步解决：

1. 两个包标签都激活了吗（见上节）；
2. 提示 Duplicate pack detected → 进游戏设置 → 存储，删掉旧版本包，彻底关游戏后重装；
3. 游戏是不是最新版——大版本更新后旧包会失效；
4. 脚本类模组需要在世界设置的 Experiments 里打开 Beta APIs（注意：开启后该世界成就被禁用且关不掉，重要存档先复制一份）。
