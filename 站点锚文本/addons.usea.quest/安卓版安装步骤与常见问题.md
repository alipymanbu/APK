# addons 安卓版怎么装：下载、安装与打不开的对策

> 本篇只讲安装这一段：安装文件从哪拿、安卓手机怎么装、装完打不开或闪退怎么办。模组导入与激活是另一段流程，见 [我的世界基岩版模组怎么装.md](我的世界基岩版模组怎么装.md)。
> **本目录其他文章**：[我的世界基岩版模组怎么装.md](我的世界基岩版模组怎么装.md) · [模组地图皮肤资源类型一览.md](模组地图皮肤资源类型一览.md)

## 一、这是个什么应用，装它干什么

Addons for Minecraft 是 Kayen Works 开发的基岩版资源库应用：模组、地图、皮肤、材质集中陈列，测试打包后一键导入游戏。它本身不是游戏——手机上得先有《我的世界》基岩版（0.16.0 以上），它的价值才体现得出来。应用免费可用，订阅只用于去广告，不订不影响下载与导入。

## 二、安装文件从哪拿

两个常规渠道：有 Google Play 的设备直接在商店搜索安装；商店不可用或想留存安装包时，走夸克网盘分享的安装文件资源——[addons 安卓版下载安装](https://addons.usea.quest/)页面上有直达入口和分步说明。网盘里的包先转存到自己的账号再下载，文件约 17 MB，下完若体积明显不对，多半是下载中断，重下即可。

## 三、安卓安装四步

1. 点开下载好的 APK；系统弹"禁止安装未知来源应用"时，按提示允许该来源后重试；
2. 等待安装完成，别中途返回杀进程；
3. 打开应用，首次启动需联网加载资源列表；
4. 在设置里把界面切到中文，然后就可以挑资源了。

iOS 设备不走这条路：直接在 App Store 获取即可，导入游戏的按钮是 Copy to Minecraft，与安卓的 INSTALL 不同。

## 四、装不上、打不开的对策

- **点安装没反应**：先确认未知来源权限已给到"文件管理器"这个应用本身（它才是发起安装的入口）；还不行就换系统自带的文件管理器再试。
- **打开就闪退**：确认装的是 Kayen Works 的 Addons for Minecraft——商店里同名模组工具不止一个，装错会闪退；确认无误仍闪退，卸载重装一次。
- **资源列表一直加载不出来**：检查网络；部分资源按创作者要求挂了广告门槛，等几秒出现关闭按钮再操作即可。
- **导入模组后游戏里没效果**：这不是安装问题，是游戏内的激活步骤没做，处理顺序见 [我的世界基岩版模组怎么装.md](我的世界基岩版模组怎么装.md) 第五节。

装好之后，资源怎么挑、各类包能改什么，翻翻 [模组地图皮肤资源类型一览.md](模组地图皮肤资源类型一览.md) 再下手能少走弯路。
