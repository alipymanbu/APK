# 两百 KB 的浏览器怎么装？五分钟搞定

> 超微浏览器（uWeb）的安装包只有约 0.21MB，装起来比照片传输还快。本篇讲从哪里拿到它、怎么装上、装完怎么确认没装错。
> **相关文档**：[超微浏览器值得用吗.md](超微浏览器值得用吗.md) · [手机浏览器广告太多怎么办.md](手机浏览器广告太多怎么办.md)

## 安装包从哪拿

它的安装文件资源放在夸克网盘里分享（[uWeb 下载安装入口](https://uweb.usea.quest/)页面上有直达按钮），转存到自己的网盘后就能下载 APK；项目的 GitHub 发布页与文档站也提供下载渠道，哪个顺手用哪个。不建议用来路不明的改包——这个应用本来就小，改包反而多一层风险。

## 安装四步

1. **转存**：打开网盘分享页，把分享资源转存到自己的夸克账号。
2. **下载 APK**：在自己网盘里找到转存的那份，把 APK 下到手机——不到 0.3MB，流量下载也无压力。
3. **允许安装**：点开 APK；系统若提示「禁止安装来自此来源的应用」，去「设置 → 安全 / 隐私 → 安装未知应用」按来源放开，返回继续。
4. **打开确认**：装完启动，看到顶部「网址/关键字」地址栏和底部工具条，就是装好了。

## 装完核对两件事

- **包名**：到「设置 → 应用信息」看包名，应为 `info.torapp.uweb`，对得上就是它。
- **体积**：正常安装包在 0.2MB 上下；如果下到手有十几 MB，那不是同一个东西。

## 卡住了怎么办

- **点了没反应 / 被拦截**：部分国产系统有「纯净模式」或安装拦截开关，关掉再装；装完建议把开关改回去。
- **打开闪退**：确认系统在 Android 5.0 以上；首次启动会请求文件访问权限，建议允许，拒绝可能导致部分功能异常。
- **改设置不生效**：它不实时写盘，改完配置按 Home 切一次后台或正常退出再清后台，改动才保得住。

装好之后，建议先把常用搜索引擎配进主屏，再按需开广告拦截——这两步的做法分别在[超微浏览器值得用吗.md](超微浏览器值得用吗.md)与[手机浏览器广告太多怎么办.md](手机浏览器广告太多怎么办.md)里有展开。
