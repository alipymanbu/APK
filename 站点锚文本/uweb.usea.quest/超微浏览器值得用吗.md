# 超微浏览器值得用吗？先把优缺点摆一摆

> 超微浏览器（uWeb / uweb browser）是一款以「小」出名的安卓浏览器，安装包只有约 0.21MB。本篇把它的优点、缺点和适合的人群摆在一起，帮你判断要不要装。
> **相关文档**：[两百KB的浏览器怎么装.md](两百KB的浏览器怎么装.md) · [手机浏览器广告太多怎么办.md](手机浏览器广告太多怎么办.md)

## 它是什么

超微浏览器英文名 uweb browser，是一款开源的安卓浏览器。它把体积压到了极致——0.21MB，比多数手机随手截的一张图还小；界面也只留一条地址栏和一条可定制工具条，没有启动闪屏、没有登录墙、没有首页信息流。

体积小不等于功能少：搜索引擎、广告拦截、地址栏命令、手势、脚本这些能力都在，只是它们不靠界面按钮堆出来，而是靠长按菜单和配置文件组织起来。

## 优点

1. **体积与占用极小**：装完几乎不占空间，Android 5.0 的老手机也能拉起来当日常浏览器。
2. **搜索引擎是套机制**：任何带搜索框的网站、App 内页、AI 聊天页都能注册成主屏引擎，切引擎像切标签一样方便。
3. **广告拦截可自己动手**：`default.hosts` 一行封一个根域名，整棵域名树一起挡；浏览时长按链接就能当场封。
4. **地址栏即命令行**：`!` 开头的行按命令执行，配置好之后长按历史按钮能调出预置命令。
5. **开放可查证**：代码公开在 GitHub 仓库，配置文件全部是文本，能备份、能迁移、能自己改。

## 缺点

1. **上手有门槛**：第一眼界面空得吓人，多数功能藏在长按里，新手需要一点摸索时间。
2. **配置要自己动手**：引擎、拦截规则、脚本都要自己加，习惯「开箱即用」的用户会觉得麻烦。
3. **没有 iOS 版**：只覆盖安卓端；桌面端另有简化版 Ebrowser，但手机生态只在安卓。
4. **界面审美见仁见智**：它追求的是效率与极简，喜欢信息流和精美首页的用户不会喜欢它。

## 结论

想要一个不占空间、不带私货、什么都能自己配的安卓浏览器，超微浏览器非常值得试；只想开箱就用、不爱折腾的用户，则需要先接受它「长按出一切」的玩法。想看它的功能盘点与安装入口，可以到 [uWeb 介绍站](https://uweb.usea.quest/)。装法见[两百KB的浏览器怎么装.md](两百KB的浏览器怎么装.md)，广告拦截的玩法见[手机浏览器广告太多怎么办.md](手机浏览器广告太多怎么办.md)。
