## 一句话认识 GitMind

GitMind（中文名「思乎」）是 Apowersoft 旗下的一款云端绘图工具：思维导图、流程图、组织架构图、鱼骨图在同一个编辑器里切换，文件存在云端账号里，手机、平板、电脑登录同一账号自动同步，还能多人同时编辑一张图。想先看界面与功能清单，去 [GitMind 思乎介绍站](https://gitmind.bmww.store/) 翻一遍即可。
