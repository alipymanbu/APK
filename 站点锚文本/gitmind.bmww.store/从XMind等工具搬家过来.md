# 从XMind等工具搬家过来

> 本篇讲怎么把 XMind、FreeMind、MindMaster 等工具里攒下的旧导图搬进 GitMind：哪些格式能直接读、导入入口在哪、搬进来之后怎么拆分合并，以及两个容易踩的坑。
> **相关文档**：[怎么把碎片资料理成导图.md](怎么把碎片资料理成导图.md) · [免费版能用到什么程度.md](免费版能用到什么程度.md)

## 一、能直接读的格式

按 2026 年的产品更新口径，截至 2026-09 支持导入的格式包括：

| 来源 | 格式 |
| --- | --- |
| GitMind 自己的文件 | `.gmind` |
| XMind | `.xmind` 工作簿 |
| FreeMind | FreeMind 格式 |
| MindMaster / EdrawMax | MindMaster 格式 |
| MindManager、MindMeister | 各自的导出格式 |
| 纯文本类 | Markdown、OPML、HTML |
| 流程图 | Visio（导入后转成可编辑流程图，也能再导回 Visio） |

从 XMind、MindMaster 换过来的旧图大概率能直接搬，不用重画。个别版本格式互不认的，先回原软件里「另存为」上面的通用格式再导。

## 二、导入步骤（以网页版为准）

1. 登录后进「我的文件」页面；
2. 在「更多」菜单里找「本地导入」；
3. 选择本地文件直接添加，或把文件拖进窗口；
4. Markdown 文件导入后会自动生成一张导图。

手机 App 的入口以设备上实际显示为准；网页版能力最全，找不到导入入口时优先去网页版操作。

## 三、搬进来之后的整理

- **拆分**：一张大图想拆成两张，选中要拆出去的分支，右键选「分解」，该分支自动生成一张新导图；
- **合并**：在导图空白处右键选「引入心智图」，选中要并进来的文件，把内容拖到目标节点下；
- **调层级**：拖 A 节点到 B 节点上，A 变成 B 的子节点；外接键盘可用 `Alt + ↑/↓` 上下调位置。

## 四、两个容易踩的坑

1. **样式不会跟着搬**。导入只搬结构，原来的主题、配色要重新套——编辑页右上角魔法棒图标一键换整套主题，比逐个节点调快得多。
2. **导入的图计入账户额度**。和手画的图一样：免费账号总共 3 个文件、单张 60 节点。图多的话先想清楚搬哪几张，额度口径见[免费版能用到什么程度.md](免费版能用到什么程度.md)。
