# 免费版能用到什么程度

> 本篇把 GitMind 免费账号的额度边界逐项说清：能建几个文件、一张图能有多少节点、导出受什么限制、删掉的东西留多久，以及撞到额度时的几条实用出路。

## 一、先说结论

免费版能正常画图、正常协作，限制集中在**文件数量、节点数、导出清晰度**三处。下表是截至 2026-09 产品页面的口径，权益可能随版本调整，以登录后账户内显示为准。

## 二、额度逐项对照

| 项目 | 免费版口径 |
| --- | --- |
| 可建文件数 | 3 个 |
| 每张导图节点数 | 60 个 |
| 每张导图可插图片 | 2 张 |
| 云空间 | 100 MB |
| 导出 | 标准清晰度图片（无 PDF、无高清） |
| 版本历史 | 7 天 |
| 回收站保留 | 7 天 |
| 白板可插图片 | 10 张 |

两条容易被误读的：

- **建满 3 个文件不等于锁死**。产品说明里明确：免费账号建满后只是不能再新建或保存新文档，**已建的 3 个文档仍然可以继续编辑**。撞墙时把不常用的旧图导出留档后删掉一个，就能腾出位置。
- **节点加到 60 个加不动不是故障**。是单图上限，把一个分支「分解」出去另成一张图即可。

## 三、什么情况才值得考虑会员

按用法倒推，别按功能清单倒推：

- 只是偶尔画一张、导张普通图发群里——免费版够用，一个文件数都碰不到顶；
- 图要打印、要放进报告、要发客户——高清导出与 PDF 是硬差异，免费版过不去这关，这时再考虑；
- 要长期囤图、常误删文件——免费版回收站只留 7 天，会员不限时长，看自己的手滑频率。

AI 功能按「算粒」另行计费，各会员档每月赠送的额度不同，算粒也可以单独购买，购买后永久有效。

## 四、删错东西的补救窗口

- **误删的导图**：底栏「我的」进回收站恢复，免费版保留 7 天，过期清空——删错东西要在这个窗口内处理；
- **改坏了想退回**：免费版有 7 天版本历史，在文件的历史版本里回退；
- **换手机后文件不见了**：先确认登录的是不是同一个账号，文件全在云端，同账号登录会自动同步出来。
