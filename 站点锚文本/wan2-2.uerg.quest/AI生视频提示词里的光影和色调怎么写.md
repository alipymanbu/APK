# AI生视频提示词里的光影和色调怎么写

同样是生一条 5 秒的视频，有人得到的是"随便一段动画"，有人得到的却是海报级画面——差别多半不在运气，而在提示词里有没有把光影、色调、镜头这些"摄影语言"写进去。Wan2.2 恰好是这类写法收益最大的模型：它的训练数据带上了光线、构图、色调、色彩等维度的精细标注，这些词在它那里是"听得懂"的。

## 一、为什么这类模型"认"摄影词汇

Wan2.2 开源时着重强调的一点，就是把电影工业的美学标准做进了训练环节：画面按光线、时段、色调、构图、镜头等维度打过标签。所以提示词里出现 golden hour（柔金光）、teal-and-orange（蓝橙调）这样的词时，模型不是靠字面猜，而是有对应的审美先验可用。社区里流传的各类提示词合集，核心也是这套词汇。

## 二、一组可以直接抄的标签

按"光线 → 时段 → 色调 → 镜头 → 景别"的顺序往提示词里填：

| 维度 | 常用词 | 效果倾向 |
| --- | --- | --- |
| 光线 | golden hour / rim light / neon / soft light | 氛围感、人物轮廓 |
| 时段 | dusk 薄暮 / harsh noon 正午硬光 | 情绪基调 |
| 色调 | teal-and-orange / 低饱和 / 暖棕 | 电影海报感 |
| 镜头 | 35mm / anamorphic 变形宽银幕 / 16mm grain | 质感与"胶片味" |
| 景别 | 特写 / 中景 / 航拍大远景 | 信息量控制 |

一条 5 秒的短视频，交代一个景别就够，别贪多。

## 三、组合示例

文生视频可以这样组织一句话：

> 薄暮时分的海边公路，golden hour 柔金逆光，teal-and-orange 调色，35mm 镜头，人物中景回望镜头，风吹动发丝。

图生视频则把重点放在"怎么动"上：

> 旧照片里的人缓缓抬头，rim light 勾出侧脸轮廓，低饱和暖棕色调，镜头缓慢推近至特写。

反向提示词可以补"静态、模糊、过曝"之类的词来收窄结果；不过多试几轮往往比堆词更有用，最终以实际生成效果为准。
