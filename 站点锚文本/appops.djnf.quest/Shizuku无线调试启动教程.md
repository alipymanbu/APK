# Shizuku 无线调试启动教程（免电脑）

> App Ops 免 root 使用的前提是接通 Shizuku。安卓 11 及以上可以用「无线调试」在手机上直接完成配对与启动，不用连电脑。本篇给完整步骤与常见报错处理。

## 一、什么情况走这条路

- 手机没 root、手边没电脑、系统是安卓 11 及以上——这是最省事的启动方式；
- 安卓 10 及以下用不了无线调试，只能连电脑走 adb（见第三节）；
- 配对只需要做一次；之后每次重启手机都要重新点一次「启动」（系统限制），但不用重新配对。

## 二、无线调试启动（安卓 11 及以上）

1. 打开开发者选项：设置 - 关于手机，连续点击「版本号」数次，直到提示已进入开发者模式（不同机型入口可能不同）。
2. 在开发者选项里打开「USB 调试」，再进入「无线调试」并启用。
3. 打开 Shizuku，点「配对」开始配对。
4. 在系统的「无线调试」页面点「使用配对码配对设备」，屏幕上会显示一组配对码。
5. 把配对码填进 Shizuku 的通知里（弹不出通知就先允许 Shizuku 的全部通知）。
6. 配对成功后回到 Shizuku 首页点「启动」，看到「Shizuku 正在运行」即完成。
7. 打开 App Ops，在 设置 - 工作模式 里选 Shizuku，弹出授权时允许；回到应用列表能列出各应用的操作开关，就接通了。

## 三、连电脑启动（安卓 10 及以下，或有电脑时）

1. 电脑下载 Google 提供的「SDK 平台工具」并解压；
2. 手机开启「USB 调试」后连电脑，在解压目录打开终端执行 `adb devices`，手机上弹出的「是否允许调试」勾选「总是允许」；
3. 执行启动命令（Shizuku v11.2.0 及以上）：

```powershell
adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
```

在 PowerShell 或 Mac / Linux 终端里，要把 `adb` 换成 `./adb`。

## 四、报错对照

| 现象 | 处理 |
| --- | --- |
| 一直「正在搜索配对服务」 | 允许 Shizuku 在后台运行——搜索配对服务需要访问本地网络，不少厂商会在应用切后台后立刻掐断它的网络 |
| 点「输入配对码」后立刻失败 | MIUI / POCO：系统设置的「通知管理 - 通知显示设置」里，把通知样式切换为「原生样式」 |
| 提示 adb 权限受限 | MIUI / POCO：开发者选项里开启「USB 调试（安全设置）」；ColorOS（OPPO、一加）：关闭「权限监控」；Flyme（魅族）：关闭「Flyme 支付保护」 |
| Shizuku 随机停止 | 允许后台运行；不要关「USB 调试」与开发者选项；把 USB 使用模式改为「仅充电」；安卓 11 及以上开启「停用 adb 授权超时功能」 |
| 华为 EMUI 随机停止 | 开发者选项里开启「'仅充电'模式下允许 ADB 调试选项」 |
| 小米用「手机管家」扫描后失效 | 不要用手机管家的扫描功能，它会禁用开发者选项 |

无线调试怎么都启动不了时，还有一个通用招：把「无线调试」开关关掉再打开，回 Shizuku 重试一次。

## 五、启动之后

- 每次**重启手机**后 Shizuku 服务都会消失，重新点一次「启动」即可（配对不用重来）；已经改好的设置照常生效，只是那段时间不能继续管理。
- 启动成功但 App Ops 还是连不上时，排查思路见 [改了权限不生效的原因与排查.md](改了权限不生效的原因与排查.md)。
- 还没装 App Ops 的，工具介绍与安装文件资源入口在 [App Ops 功能与获取页](https://appops.djnf.quest/)；它管什么、拒绝方式为何特别，见 [免root拨动隐藏权限开关.md](免root拨动隐藏权限开关.md)。
