# 静默拒绝和系统权限面板的区别

> 系统设置里的权限开关与 App Ops 看起来都在管「权限」，实际管的东西、拒绝的方式、能改的范围都不一样。本篇用一张对照表说清，再给选用建议。

## 一、两者管的不是同一层

系统权限面板管的是「运行时权限」（相机、麦克风、定位这类），档位就是允许 / 拒绝，以及安卓 10 以后的「仅在使用期间允许」。

App Ops 管的是系统里另一套 appops「应用操作」：其中一部分与运行时权限对应，另一部分是面板里**根本没有开关**的操作——读取剪贴板、后台行为，以及安卓 10 及以上的传感器类。你能看到哪些操作，以你手机的系统为准，在工具内的 设置 - 行为 - 全部权限 里看全。

## 二、对照表

| | 系统权限面板 | App Ops |
| --- | --- | --- |
| 可管范围 | 运行时权限 | 对应的操作 + 面板没有的操作（剪贴板、后台行为、传感器等） |
| 拒绝后的表现 | 应用调用时收到错误 | 应用不报错，只拿到空白数据 |
| 应用能否察觉 | 能，拒绝是明确的 | 多数察觉不到；主动检查的应用仍能发现 |
| 批量能力 | 无 | 按操作反查全部应用、模板套用、备份恢复 |
| 设置的持久性 | 系统自己维护 | 安卓 11 及以上会在个别时点被系统重置 |
| 使用门槛 | 系统自带，打开就能用 | 需先接上工作模式（Shizuku） |

「静默拒绝」是两边最本质的差别：普通面板一拒，应用立刻收到错误；App Ops 的拒绝对应系统内部的「忽略」，应用只会拿到空数据——定位被拒就拿空位置，读剪贴板被拒就拿空内容，多数应用根本意识不到自己被拒了。

## 三、什么场景用哪个

- **只想关掉某个应用的定位、麦克风**：系统面板就够，不用折腾；
- **想管住剪贴板、后台行为，或想知道「谁在偷偷干这事」**：面板没有这些开关，用 App Ops 的「按操作看」视角；
- **想管加速度计这类传感器的使用**：传感器不需要权限，面板连入口都没有，App Ops 里可以控制；
- **不想让应用知道「我被拒了」**：面板一拒应用就报错，静默拒绝让应用只拿到空数据；
- **换机或刷机后想快速恢复一整套配置**：导出备份再按文件恢复，比逐个应用重设省事。

## 四、两处细节

1. App Ops 不能直接改「权限」本身（开发者在用语说明里写得很清楚）：要彻底开关某个运行时权限，仍以系统面板为准；
2. 两边对同一项的设置会互相影响——系统写入的是高优先级设置，会压过 App Ops 的修改，纠结时两边设成一致。设置冲突的具体表现与排查见 [改了权限不生效的原因与排查.md](改了权限不生效的原因与排查.md)。

工具的功能盘点与安装文件资源入口整理在 [App Ops 功能与获取页](https://appops.djnf.quest/)；它到底管什么，见 [免root拨动隐藏权限开关.md](免root拨动隐藏权限开关.md)。
