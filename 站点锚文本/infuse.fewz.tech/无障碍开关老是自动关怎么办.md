# 无障碍开关老是自动关怎么办

> 刚打开就被系统弹回、锁屏一次回来就关了——这是厂商省电机制在杀后台，不是应用坏了。按品牌对症修，几步就能稳住。
> **相关文档**：[触发字符用法与误触发处理.md](触发字符用法与误触发处理.md) · [安卓AI助手是什么应用.md](安卓AI助手是什么应用.md)

---

## 一、先确认是这个问题

症状对上这几条，就是系统把后台服务掐了，与应用本身无关：

- 无障碍里刚把开关打开，**立马自动弹回关闭**；
- 明明开着，锁屏一次或重启手机后**自己关了**；
- 用着用着突然读不到屏幕文字，回去一看开关是关的。

原因：安卓的省电机制会把长期驻留后台的应用当成多余进程停掉，而无障碍服务恰恰必须一直活着。厂商的后台管理越激进（MIUI、ColorOS 最典型），越容易出现。

## 二、通用修法（所有品牌先做这三步）

1. **关掉电池优化**：设置 → 应用 → Infuse → 电池 → 选「无限制」/「不优化」/「允许后台活动」（各叫法不同）；
2. **允许自启动**：同一页面打开自启动开关，或在「应用启动管理」里改成手动允许；
3. **最近任务里加锁**：呼出最近任务卡片，长按或点锁形图标把它锁定，防止一键清理把它扫掉。

改完回无障碍重新打开开关，锁屏再解锁验证一次——还掉就是品牌特有的限制，往下对号入座。

## 三、小米 / Redmi（MIUI、澎湃 OS）

- 应用信息页 → **省电策略** 改「无限制」（默认的「智能限制后台运行」就是元凶）；
- 打开**自启动**；
- 安全中心 → 电池 → 设置里把「锁屏后清除缓存」设为**从不**；
- 应用信息 → 权限 → 关闭「闲置时删除权限或释放空间」（有的版本叫「暂停非活跃应用」）；
- 系统更新后权限可能被重置，升级完回无障碍复查一眼。

## 四、OPPO / 一加 / realme（ColorOS、realme UI）

ColorOS 有「权限监控」，部分版本开了无障碍会当场弹回：

1. 设置 → 关于手机 → 版本信息 → 连点「版本号」多次开启开发者模式；
2. 系统设置 → 开发者选项 → 打开「**禁用权限监控**」；
3. 回无障碍再开一次；还不行就先卸载，用自带文件管理器重装，**装完别先打开应用**，直接去无障碍里开启，再启动应用。

无障碍入口按版本不同：ColorOS 14.1-15 在「设置 → 辅助功能 → 无障碍」，ColorOS 13-14.0 在「设置 → 其他设置 → 无障碍」，ColorOS 12 在「设置 → 系统设置 → 无障碍」；找不到直接在设置里搜「无障碍」。

## 五、三星及其他品牌

- 三星：设置 → 电池 → 后台用量限制里确认 Infuse 不在受限名单，「设备维护 → 电池」里同样设为不优化；
- 通用排查：设置里搜「电池优化」，切到「全部应用」，把它排除掉；再检查「睡眠应用 / 深度休眠」名单，从中移除。

## 六、验证修好了没有

四步都过才算修好：打开无障碍确认开关是开的 → 锁屏解锁回来看一眼 → 重启手机回来看一眼 → 隔半天再看一眼。系统大版本更新会重置部分权限，升级后照这套复查一遍即可。

还没装上的，先去 [Infuse 安卓 AI 助手介绍站](https://infuse.fewz.tech/)的下载页拿安装文件资源；装好想玩转触发字符的，看 [触发字符用法与误触发处理.md](触发字符用法与误触发处理.md)。
