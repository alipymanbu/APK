# Turrit 消息翻译与多账号设置：把中文体验调出来

> 本篇讲 Turrit 最常用的三类设置：界面切成中文、聊天与频道的消息翻译（含发送前先译）、同一应用里挂多个 Telegram 账号，顺带提一下隐私检测与关键词屏蔽的入口。
> **相关文档**：[与Telegram原版有什么不同.md](与Telegram原版有什么不同.md) · [安卓版下载安装步骤.md](安卓版下载安装步骤.md)

## 一、界面切中文

Turrit 内置简体、繁体语言包，不用额外下载：

1. 打开 Turrit，点左上角三条横线进 **Settings**；
2. 找到 **Language**；
3. 选「中文（简体）」或「繁體中文」，立即生效，不用重启。

## 二、消息翻译

进设置里认准 **Translation / 翻译** 字样的入口（不同版本名称略有差异）：

1. 打开翻译开关，选好目标语言（比如简体中文）；
2. 聊天里遇到外语消息，长按选翻译，或开自动翻译直接显示译文；
3. 群聊、频道同样适用，频道内容能整篇翻译，应用内打开的网页链接也有翻译入口。

**发送前先译**：在输入框写好原文，点输入框上方的翻译图标先看译文，长按图标还能指定对方语言，确认没问题再发——发出去的就是译文，对方读起来更顺。

两个小提醒：翻译要读取消息内容才能工作，介意的话关掉自动翻译改手动；专有名词和俚语的译文仅供参考，重要内容对照原文。

## 三、多账号并行

Telegram 原版客户端在一台设备上最多登 3 个账号，Turrit 开发方页面宣称最多 10 个（具体上限以手上版本界面为准）：

1. 进设置，找「添加账户 / Add Account」入口；
2. 输入另一个 Telegram 账号的手机号并完成验证码验证，流程和首次登录一样；
3. 添加后点侧栏顶部头像即可在账号间切换，不用重新输验证码。

每个账号的界面设置、通知偏好分开保存；不想被某个账号打扰，单独静音它就行。账号多了容易发错窗口，发消息前瞄一眼输入框上方当前账号名。

## 四、顺手调的两处

- **隐私检测**：设置 → 工具 → 隐私检测，一键给账号隐私打分，手机号是否容易被搜到、陌生人能否直接私信，逐项按提示修复；
- **关键词屏蔽**：设置 → 工具 → 阻断消息，把常见推广词加进列表，含词消息自动过滤；看到广告直接长按选屏蔽该词更省事。

这些功能都建立在同一个 Telegram 账号之上，账号关系与换用取舍见 [与Telegram原版有什么不同.md](与Telegram原版有什么不同.md)；还没装的话，安装包获取与安装步骤见 [安卓版下载安装步骤.md](安卓版下载安装步骤.md)，功能总览与界面截图看 [Turrit 中文图文介绍](https://turrit.fewf.ren/)。
