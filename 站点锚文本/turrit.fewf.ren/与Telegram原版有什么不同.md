# Turrit 与 Telegram 原版有什么不同：同一个账号的两套客户端

> 本篇讲 Turrit 和 Telegram 原版客户端的关系与差别：账号为什么不互通也不冲突、功能对照差在哪几处、什么情况下值得换用它、换用前要知道哪些事。
> **相关文档**：[安卓版下载安装步骤.md](安卓版下载安装步骤.md) · [消息翻译与多账号设置.md](消息翻译与多账号设置.md)

## 一、先说清关系

Turrit 不是另一款聊天软件，而是基于 Telegram 开源代码与 API 构建的第三方客户端，开发者是 SEASTAR FUTURE HOLDING PTE. LTD.。登录的就是你原来的 Telegram 账号：

- 在 Telegram 原版或其他客户端注册的账号，都能直接登录 Turrit，反过来也一样；
- 两边同时在线不冲突，消息走 Telegram 云端，会话记录自动同步；
- 群、频道、机器人、联系人都是同一套——换客户端不等于换圈子。

所以「区别」不在账号和数据上，而在客户端本身提供的功能与操作方式。

## 二、功能对照

| 方面 | Telegram 原版客户端 | Turrit |
| --- | --- | --- |
| 账号 | Telegram 账号 | 同一个账号，两边通用 |
| 同时登录账号数 | 3 个 | 开发方宣称最多 10 个 |
| 界面语言 | 语言列表不含中文，需装汉化包 | 内置简繁中文语言包，安装后直接选 |
| 消息翻译 | 内置翻译，部分语言组合要手动开 | 聊天、频道、网页全场景翻译，发送前也可先译 |
| 下载速度 | 免费账号有速度上限 | 速度多档可调，宣称最高 20 倍（实际看网络） |
| 频道浏览 | 按会话进入 | 另有时间线方式浏览频道内容 |
| 群聊显示 | 按原群名显示 | 可给群聊加仅自己可见的备注名 |
| 隐私设置 | 手动逐项调 | 内置隐私检测，一键评分并按提示修复 |
| 消息过滤 | 无关键词屏蔽 | 关键词屏蔽、频道广告过滤、屏蔽特定用户 |

各功能随版本更新会有增减，以你手上客户端的实际界面为准。

## 三、什么情况下值得换

不替你下结论，只列两类典型场景：

- **经常读外文群或频道**：全场景翻译省去逐条复制去翻的动作，发送前先译对跨语言沟通尤其顺手，这是 Turrit 与原版差异最大的地方；
- **手里有几个 Telegram 账号**：同时登录数放宽到 10 个，切换不用反复退出登录，通知还能按账号分开管。

反过来，如果你只用一两个账号、聊天对象都用中文，原版客户端可能已经够用。

## 四、换用前要知道的事

- **第三方构建**：Turrit 由第三方团队开发，不是 Telegram 原班出品；装不装自行权衡，账号安全功能（两步验证、登录设备管理）照常可用，建议把两步验证开上；
- **更新节奏**：Turrit 更新比较频繁，版本号与原版客户端不一一对应，功能以实际界面为准；
- **收费口径**：开发方站点宣称免费无限制，第三方应用商店信息则标注含广告与内购，装之前可到商店页面确认当前口径。
