# Shizuku 授权与免 Root 管理应用

> 本篇讲免 Root 设备怎么借 Shizuku 把应用管理权限打通：Shizuku 是什么、两种激活方式怎么选、授权完成后能多做哪些事。
> **相关文档**：[冻结预装应用与批量整理手机](冻结预装应用与批量整理手机.md) · [XAPK 与分割包安装方法](XAPK与分割包安装方法.md)

## 一、为什么管理应用需要权限

安卓对「管别的应用」这件事卡得很严：卸载、冻结系统预装、批量终止后台，这些动作背后都是系统级权限。传统做法是 Root——解锁 Bootloader、刷入管理框架，一步不到位就全盘卡住。而 Shizuku 提供了另一条路：让应用以 shell 权限执行特权操作，不解锁、不刷机、不动系统分区。

Thor 这款开源应用管理器对两种模式都支持：有 Root 的设备直接授权即解锁全部功能（底层走 libsu 改造的 suCore 模块执行特权命令）；没 Root 的就走 Shizuku。

## 二、激活 Shizuku 的两种方式

| 方式 | 适合谁 | 做法 |
| --- | --- | --- |
| 无线调试 | Android 11 及以上，一个人一台手机就能搞定 | 开发者选项里打开无线调试 → 在 Shizuku 里点配对 → 输入配对码 → 启动 |
| 电脑 adb | 任何版本，手边有电脑更稳 | 手机开 USB 调试连电脑 → 执行 Shizuku 给出的启动命令 |

两种方式殊途同归：Shizuku 跑起来之后，手机重启需要重新启动一次服务，其余时间常驻后台待命。

## 三、在 Thor 里完成授权

Shizuku 处于运行状态后，打开 Thor 会检测到它，点一次授权即可。之后这些原本需要 Root 的操作都能用了：

- 冻结与解冻系统预装应用；
- 卸载顽固的内置应用；
- 批量终止进程、清除数据。

界面上被限制的按钮会随之解锁；哪天 Shizuku 服务没在跑，重新激活一次就好，应用数据不受影响。

## 四、激活前后值得知道的三件事

1. **不解锁 Bootloader、不影响保修**——Shizuku 走的是开发者选项里的正规调试通道，系统完整性不变；
2. **冻结比强行停止更彻底**——冻结会把图标一并藏起来、停掉后台活动，解冻即恢复原样，具体用法见 [冻结预装应用与批量整理手机](冻结预装应用与批量整理手机.md)；
3. **权限只用于管理动作**——Thor 按 GPLv3 协议开源、无广告无追踪，授权给它的权限只花在冻结、卸载这类管理操作上。

还没装这款工具的，可以先到 [Thor 应用管理器介绍站](https://thor.ggcd.uno/)了解它的完整功能，再从站内的网盘入口拿安装包。
