# 冻结预装应用与批量整理手机

> 本篇讲拿到新手机后怎么把应用整理干净：冻结和卸载各适合什么场景、批量操作怎么一次处理几十个应用、冻结页的状态过滤怎么看。
> **相关文档**：[Shizuku 授权与免 Root 管理应用](Shizuku授权与免Root管理应用.md) · [XAPK 与分割包安装方法](XAPK与分割包安装方法.md)

## 一、冻结和卸载，先分清再动手

| 动作 | 效果 | 适合场景 |
| --- | --- | --- |
| 冻结 | 图标隐藏 + 后台禁用，数据保留，随时解冻 | 预装但偶尔要用的（银行类、厂商服务）、暂时不想看到的应用 |
| 卸载 | 彻底移除，数据一并清掉 | 确定不再需要的应用 |

冻结的优势在「可逆」：比强行停止更彻底——强行停止只是按住后台，冻结连入口都收走了；而哪天要用，进冻结列表点一下解冻，应用原样回来。对系统预装应用来说，这几乎是唯一稳妥的处理方式：直接卸载可能影响系统功能，冻结则留了后路。

## 二、批量操作：几十个应用一次搞定

一个个点卸载是整理手机最劝退的环节。Thor 支持在列表里多选之后一次性执行：

- 批量卸载 / 批量冻结 / 批量解冻；
- 批量终止进程；
- 批量清除数据。

新机开箱把厂商预装过一遍、旧机换季清理闲置应用，都适合用批量模式，一轮勾选一轮执行，几分钟收工。

## 三、用筛选和标识认准目标

动手前先看清每个应用是什么、从哪来：

1. **按安装来源筛选**——分清厂商预装、应用商店安装、浏览器侧载，来源不明的先重点关注；
2. **按状态过滤**——应用冻结页提供 All / Active / Frozen / Suspended 四个状态，一眼分清哪些在跑、哪些已经冻着；
3. **拆分应用专属标识**——用分割包安装的应用带专属标识，处理时不会认错。

列表还支持直接启动应用、查看应用信息，整理和日常使用两不误。

## 四、整理完顺手做的两件事

- **把常用应用提取一份 APK 备着**——应用详情页一键分享 APK，换机、刷机后不用满世界重新找包，具体见 [XAPK 与分割包安装方法](XAPK与分割包安装方法.md)；
- **给管理工具本身上把锁**——Thor 支持指纹锁，避免别人拿到手机误动应用配置。

权限还没打通的先看 [Shizuku 授权与免 Root 管理应用](Shizuku授权与免Root管理应用.md)，装好工具后到 [Thor 应用管理器介绍站](https://thor.ggcd.uno/)可以对照界面截图熟悉各个页面的用法。
