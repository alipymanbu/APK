# XAPK 与分割包安装方法

> 本篇讲系统安装器装不了的包怎么处理：XAPK、APKS 这类分割包是什么、为什么直接点开装不上、怎么用 Thor 的「从文件安装」把它们装进手机。
> **相关文档**：[冻结预装应用与批量整理手机](冻结预装应用与批量整理手机.md) · [Shizuku 授权与免 Root 管理应用](Shizuku授权与免Root管理应用.md)

## 一、先弄明白：为什么这些包点开装不上

传统的 `.apk` 是单文件安装包，点开就能装。但随着应用体积越来越大，安卓生态里出现了两类「拆开卖」的格式：

| 格式 | 长什么样 | 系统安装器的态度 |
| --- | --- | --- |
| APK | 单个 `.apk` 文件 | 直接支持 |
| XAPK | 把主包 + 语言包 + 各分辨率资源打成一个 `.xapk` 归档 | 多数系统不认，点开无反应或报解析错误 |
| APKS / 分割包 | 一组按需拆分的 `.apk` 组合 | 系统安装器缺少合并安装会话，通常装不上 |

这些格式本身没问题——应用商店分发的就是拆分后的形态；问题出在侧载路径上：系统自带的安装器只处理单文件 APK，遇到归档或分割组合就无能为力。

## 二、用 Thor 的「从文件安装」装分割包

Thor 主页有一个显眼的「从文件安装」入口，支持 APK、XAPK、APKS 以及分割包：

1. 把下载好的包文件放到手机存储（下载目录、文件管理器能找到的地方即可）；
2. 打开 Thor，点主页的「从文件安装」；
3. 选中目标文件，Thor 会解析包内容并走安装会话，分割包在这一步被合并成完整应用装进系统；
4. 装完即可在应用列表里看到它。

整个过程不需要电脑、不需要解压工具，也不要手动去改文件后缀——那只会把包弄坏。

## 三、反向操作：把已装的应用提取成 APK

装包之外还有一类需求是「备包」：换机前把应用安装包导出来。Thor 在应用详情页提供一键分享 APK——把当前安装的应用提取成安装包文件，存本地或发给别人都行。

配合多选批量操作，常用应用一轮勾选就能全部提取完毕；换机、刷机之后用上面的「从文件安装」把包装回去，形成一个小闭环。

## 四、两个常见卡点

- **XAPK 解析失败**：先确认文件完整（下载中断的包会解析报错），再确认用的是「从文件安装」入口而不是系统安装器；
- **装好了但管理按钮是灰的**：那是特权功能还没授权，与包格式无关，去 [Shizuku 授权与免 Root 管理应用](Shizuku授权与免Root管理应用.md) 把权限打通。

工具本身从 [Thor 应用管理器介绍站](https://thor.ggcd.uno/)的网盘入口获取；装好之后，冻结预装、批量整理的玩法见 [冻结预装应用与批量整理手机](冻结预装应用与批量整理手机.md)。
