# VMOS Pro 介绍站：安卓本地虚拟机的安装与玩法

这里整理 VMOS Pro（安卓设备上的本地虚拟机工具）的功能介绍与获取指引：一部手机里再运行一个独立的安卓系统，小号多开、息屏挂机、虚拟机内开启超级用户，真机系统保持原样。

想直接上手，可以从 [VMOS Pro](https://vmos-pro.rggd.pw/) 介绍站进入，站点里有两页内容：功能与场景介绍、下载与安装步骤。
