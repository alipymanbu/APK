# 息屏挂机设置与开机卡99处理：VMOS 挂机党实用记录

把应用放进虚拟机长时间运行，最关心两件事：真机息屏后它还在不在跑、开机卡在 99% 怎么救。本篇汇总这两条路上的实操要点。相关阅读：[安卓双开与小号多开方法](安卓双开与小号多开方法.md)、[虚拟机开启Root与谷歌服务](虚拟机开启Root与谷歌服务.md)。

---

## 一、息屏挂机怎么开

以 VMOS Pro 为例，挂机依赖的是虚拟系统的后台运行能力，而不是真机的分身机制：

1. 把要挂的应用装进虚拟机并登录好；
2. 在虚拟机设置里确认后台运行保护类开关已打开；
3. 真机直接息屏即可，虚拟机内的应用继续运行；
4. 需要看进度时，用悬浮窗小窗查看，不用切回全屏。

官方展示里把这条场景叫"息屏持续运行"——手机锁屏放进兜里，虚拟机里的自动任务照样推进。放置类游戏的定时收菜、需要保持在线的小号，都用得上这套玩法。

## 二、省电与流畅的两个小调整

- 适当调低虚拟机分辨率（设置 → 分辨率 → 添加自定义参数），运行压力会小不少；
- 挂机期间尽量别同时开多台虚拟机，性能吃紧时系统更容易杀后台。

## 三、开机卡在 99% 的处理路径

一个高频故障：虚拟机开机进度停在 99% 不动。社区反馈的有效做法是**不要关机**，按下面顺序处理：

1. 切回 VMOS Pro 主界面，进入设置；
2. 点「虚拟机无法启动？」；
3. 选「修复虚拟机文件」，等待修复进度提示成功；
4. 切回虚拟机开机页面，等待它正常开机。

如果修复后仍然进不去，把重要数据先导出来，再删除这台虚拟机重建。这个故障多出现在非首次开机的场景，养成定期导出数据的习惯能少很多损失。

## 四、安卓 12 及以上机型的一次性激活

新系统对后台进程的限制会让虚拟机跑不稳，首次使用需要按应用内引导完成一次激活：连接 Wi-Fi → 打开开发者选项 → 开启无线调试 → 把通知栏里 VMOS 助手显示的配对码输入进去 → 激活完成。之后就正常使用了。

功能与安装方式请看 [VMOS Pro 功能介绍站](https://vmos-pro.rggd.pw/)，里面有完整的场景说明与安装步骤。
