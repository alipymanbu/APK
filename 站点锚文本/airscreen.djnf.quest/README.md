# AirScreen 投屏接收站

AirScreen 是装在安卓电视、盒子、旧手机这类接收端设备上的无线投屏接收应用：一套收齐 AirPlay、Cast、DLNA、Miracast 四种协议，iPhone、iPad、Mac、安卓手机与 Windows 电脑都能往同一块大屏投，发送端不用装任何东西。

本目录是这个介绍站的文章存档，按真实使用场景整理：

- [安卓电视怎么接收iPhone投屏](安卓电视怎么接收iPhone投屏.md) —— 补上 AirPlay 接收端这块缺口，装好后 iPhone 怎么投。
- [手机投屏搜不到设备怎么解决](手机投屏搜不到设备怎么解决.md) —— 搜不到、连不上、画面不对，按命中率排的排查清单。
