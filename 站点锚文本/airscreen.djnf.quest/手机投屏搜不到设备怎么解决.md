# 手机投屏搜不到设备怎么解决

> 按命中率从高到低排的排查清单：发送端列表里看不到接收设备、看到了连不上、连上了画面不对，三种情况各自的判断依据与动作。
> **相关文档**：[安卓电视怎么接收iPhone投屏](安卓电视怎么接收iPhone投屏.md)

---

## 一、列表里根本看不到接收设备

投屏本质是两台设备在局域网里互相发现，发现不了十有八九卡在网络环境上。按下面的顺序逐条试，每做一条就回去刷新一次列表：

1. **确认同一个 Wi-Fi**。手机连了蜂窝数据、或连了另一个 SSID（很多路由器 5GHz 和访客网络是两个名字），列表里就不会出现对方。
2. **检查路由器的 AP 隔离 / 访客网络**。这个开关的作用就是禁止连在同一台路由下的设备互相通信，开着就一定搜不到，先关掉。
3. **关掉 VPN / 代理**。发送端开着 VPN 时局域网发现包发不出去，手机上尤其常见。
4. **拉齐频段**。双频合一的路由有时把两台设备分到不同频段，部分设备间会互相发现不了——临时把两端都手动连到同一个频段验证。
5. **接收端要停在就绪状态**。接收应用开着、主界面能看到设备名（形如 AS-xxxx）且没有弹窗挡着，才算真的在「等连接」。
6. **重启三件套**。局域网发现依赖组播，路由长期不重启后经常失灵：先杀掉接收应用重开，再重启电视 / 盒子，最后重启路由器。

## 二、看到了，但一直连不上

- **配对码输错**：走 AirPlay 镜像时电视上会弹一串配对码，输错直接退回列表，重选设备重新输一次。
- **接收端权限没给全**：首次启动时若拒绝了网络或后台权限，应用会表现得像「开着但连不上」。到系统设置 → 应用里，把网络、后台运行补齐，电池优化选「不限制」。
- **版本太旧**：发送端系统已升到最新、接收端的应用还停留在很老的版本时，握手协议可能对不上，先升级接收端应用再试。
- **防火墙拦截**（发送端是 Windows 电脑时）：系统弹过「已阻止此应用访问网络」并点了阻止的话，去「Windows 安全中心 → 防火墙 → 允许应用通过防火墙」把它勾上。

## 三、连上了，但画面 / 声音不对

| 症状 | 多半是 | 先做什么 |
| --- | --- | --- |
| 连上就黑屏 | 版权保护内容在拦截，或清晰度超出网络承载 | 换一个普通视频试：能放说明是版权机制，都黑屏就往下调清晰度 |
| 画面一顿一顿 | Wi-Fi 带宽不够或信道拥挤 | 接收端设置里清晰度降一档，发送端离路由近一点 |
| 声音比画面慢半拍 | 镜像链路延迟累积 | 打开硬件加速，或改用投内容的方式（Cast / DLNA）代替整屏镜像 |
| 投一会儿自动断 | 接收端被系统杀后台 | 电池优化选「不限制」、应用里的后台服务开关打开 |
| 有画面没声音 | 音量 / 蓝牙占用 / 输出设备没切过去 | 先查接收端音量与发送端的蓝牙连接，再重连一次 |

## 四、还没解决时的两个取舍

- **换协议试一遍**。镜像不通试投内容，投内容不通换支持 DLNA 的播放器投——同一台接收设备往往同时挂着好几路协议，一路堵了换一路。
- **换发送端试一遍**。iPhone 搜不到就换安卓手机试：哪台设备都搜不到，问题在网络；只有某一台搜不到，问题在那台设备的设置。

接收端本身的安装与就绪状态怎么确认，见 [安卓电视怎么接收iPhone投屏](安卓电视怎么接收iPhone投屏.md)；完整的接收端功能与安装入口，在 [AirScreen 投屏接收站](https://airscreen.djnf.quest/)。
