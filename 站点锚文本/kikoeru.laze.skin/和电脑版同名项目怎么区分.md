# 和电脑版同名项目怎么区分

> 搜「kikoeru」会同时撞到两套东西：手机上的安卓应用，和 GitHub 上一套需要自己架设的同名服务端。教程对不上号、操作照着做却找不到入口，多半是混了这两套。
> **相关文档**：[从登录到睡前收听.md](从登录到睡前收听.md) · [登录不上与加载失败怎么办.md](登录不上与加载失败怎么办.md) · [字幕怎么调与定时播放.md](字幕怎么调与定时播放.md)

## 一、两套东西对照

| 你搜到的内容 | 实际是什么 |
| --- | --- |
| Docker 镜像、Windows 服务端包、网页版部署教程、自建仓库的说明 | 一套**需要自己架设**的同名服务端项目，内容要自己导入，和手机上装的这份不是一回事 |
| 打开就是登录界面、选服务器后进【仓库】的那种 | 包名 `com.cnl.kikoeru` 的**安卓应用**，装好登录直接用 |

认包名最稳：手机上这份的包名是 `com.cnl.kikoeru`。

## 二、怎么判断手里的教程在讲哪套

- 教程里出现 **Docker、部署、端口、反向代理、导入元数据**这类词 → 讲的是服务端项目；
- 教程里出现 **选服务器 200、仓库主页、歌词设置、定时停止**这类词 → 讲的才是手机上这份安卓应用；
- 出现「空格键暂停、拖拽播放列表」之类桌面端操作的描述 → 那是对着别的软件写的套话，手机触屏上没有这些入口，别照着找。

## 三、两边的用法没法互相套

服务端项目要自己准备内容、自己维护；安卓应用装好就能登录用。想在手机上直接听，就走安卓应用的路子：装包 → 选服务器 → 登录仓库，完整步骤见 [从登录到睡前收听.md](从登录到睡前收听.md) 第一节。
