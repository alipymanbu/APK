# 登录不上与加载失败怎么办

> kikoeru 进不去、作品加载不出来、锁屏后播放就断、下载的文件找不到——按现象逐条对号排查。
> **相关文档**：[从登录到睡前收听.md](从登录到睡前收听.md) · [字幕怎么调与定时播放.md](字幕怎么调与定时播放.md) · [和电脑版同名项目怎么区分.md](和电脑版同名项目怎么区分.md)

## 一、登录界面进不去或账号登不上

按出现频率排：

1. **服务器选错**：登录前先确认选的是 **200**（首次使用最容易漏这一步，顺序是先选服务器、再输账号）；
2. **网络环境问题**：换个 Wi-Fi 或数据网络先试，最省事；
3. **账号密码**：确认是注册过的账号；密码不对就在登录界面走找回或重新注册。

登录的完整顺序见 [从登录到睡前收听.md](从登录到睡前收听.md) 第一节。

## 二、仓库或作品一直加载失败

- **单个作品加载失败**：多是这条内容的临时问题，退出重进或换一集试试；
- **整个仓库列表都不出来**：回登录页确认服务器选项、切换网络重连；高峰时段响应会慢，加载页多等几秒；
- **反复失败**：清一次缓存——手机「设置 → 应用管理 → kikoeru → 存储」里点**清空缓存**（注意不是「清除数据」，清数据会把登录状态和本地记录一起抹掉），重新打开。

## 三、锁屏后就断、通知栏播不了

这是省电策略把后台掐了。在系统设置里把 kikoeru 加入**后台保护 / 白名单**（路径因手机品牌而异），别让省电逻辑断它的网。音乐闹钟到点不响，也先查这一条。

## 四、下载的音频存在哪个文件夹

默认路径不固定，随机型与版本变化。查法：

1. 打开应用的**设置**；
2. 找**「下载设置 / 存储路径」**一类的选项，当前路径就显示在那里；
3. 那里也能直接改保存位置，改完重启应用生效。

## 五、搜到的教程对不上号

「kikoeru」这个名字下有两套东西——手机上装的这份安卓应用，和 GitHub 上一套需要自己架设的同名服务端项目。教程对不上号时先分清是哪一套，见 [和电脑版同名项目怎么区分.md](和电脑版同名项目怎么区分.md)。
