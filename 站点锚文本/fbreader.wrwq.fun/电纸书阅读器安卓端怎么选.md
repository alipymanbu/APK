# 电纸书阅读器安卓端怎么选

> 不少电纸书设备跑的是安卓系统，装什么阅读器直接影响翻页残影和续航。本篇从电纸书用户的实际使用习惯出发，讲清挑选要点与 FBReader 的适配情况。
> **相关文档**：[mobi文件在手机上怎么打开.md](mobi文件在手机上怎么打开.md)

---

## 一、电纸书用户挑阅读器，多看三件事

同样一款阅读器，在彩色手机屏和 e-ink 屏上是两种体验。电纸书场景下值得多看的：

- **排版可调深度**：e-ink 屏幕刷新慢，字号、边距、行距一次调对，比反复翻设置省心；
- **动画开关**：翻页动画在 e-ink 上是负担，阅读器得允许整体关掉；
- **格式广度**：电纸书常被用来读扫描件和旧藏书，PDF、DjVu 这类图片型格式能不能开很关键。

## 二、FBReader 的 e-ink 适配情况

FBReader 的设置清单里有一项专门的「e-ink 屏幕选项」，为电纸书设备优化刷新表现；字体、边距、进度条样式、翻页方式都在同一层设置里逐项可调，CSS 规则还能选择应用或忽略书籍自带样式。

格式方面：epub、fb2、mobi、RTF、HTML、纯文本由主程序直开；PDF 走插件模块（免费版需单独安装），DjVu 与漫画压缩包同样以模块方式加载。各版本的分支差异与安装入口，[FBReader 资料站](https://fbreader.wrwq.fun/)有按稳定版 / 测试版分开的说明。

## 三、手机与电纸书之间的进度同步

这是电纸书读者容易忽略的一点：通勤路上用手机读几章，回到电纸书接着读，进度得对得上。FBReader 登录账号后，书籍列表、书签与阅读位置在设备之间同步，书签还带颜色标记，回找重点段落不必翻全书。

没有网络书库习惯的读者，也可以只用 OPDS 目录浏览在线书源，把书下载到本地再读，进度同样记录在阅读器内。

## 四、小结

| 关注点 | 建议核对的功能 |
| --- | --- |
| 屏幕体验 | e-ink 专属选项、动画能否关闭 |
| 藏书格式 | mobi / fb2 / PDF / DjVu 的支持方式 |
| 多设备 | 账号同步覆盖书籍、书签、阅读位置 |

先在手机上装好试读一周，再决定要不要装进电纸书，是最省事的验证路径——两边的安装文件是同一份，mobi 等旧格式的导入方法见 [mobi文件在手机上怎么打开.md](mobi文件在手机上怎么打开.md)。
