# 洛雪音乐是什么软件值不值得装

洛雪音乐（LXMusic，也常被叫作洛雪音乐助手）是一款开源的音乐播放器，由开发者落雪无痕发起，代码在 GitHub 上公开，协议为 Apache 2.0，Star 数累计超过五万。

## 它的几个标签

- **开源透明**：桌面版基于 Electron 与 Vue 构建，移动端是独立的 React Native 项目，代码可查；
- **四端覆盖**：Windows、macOS、Linux 加安卓，其中移动端只做了安卓（Android 5.0+），没有 iOS 与 HarmonyOS NEXT 的开发计划；
- **界面干净**：无广告、不催登录、没有账号体系，装上就是一台安静的听歌机器；
- **找歌有章法**：榜单侧栏加三层标签墙，具体路子见[洛雪音乐榜单和标签找歌玩法](洛雪音乐榜单和标签找歌玩法.md)。

## 适合谁

- 厌倦了开机推广告、听歌先看直播的普通听众；
- 喜欢翻排行榜、按心情挑歌单的人；
- 想要一款界面清爽、可以自己调主题（绿意盎然 / 蓝田生玉 / 热情似火）的安卓用户。

## 不适合谁

- 苹果手机用户——移动端暂无 iOS 版本；
- 指望它替代流媒体大平台完整生态的人——它更像一把趁手的「找歌 + 整理」工具。

## 怎么装

安卓用户从 [洛雪音乐介绍站](https://lxmusic.laze.skin/) 的下载页进入网盘即可拿到 APK，具体步骤见[洛雪音乐安卓版下载安装步骤](洛雪音乐安卓版下载安装步骤.md)，两分钟装完就能用。
