# 洛雪音乐安卓版下载安装步骤

洛雪音乐（LXMusic）的移动端只提供 APK 安装包，不走应用商店。整个过程大约两分钟：拿到安装包、放开安装权限、点开装好、首次设置一遍即可。

## 装之前先确认两件事

- 手机系统是 Android 5.0 及以上，手机与平板都可以装；
- 移动端没有 iOS 版本，苹果手机暂时装不了，桌面用户可以选 Windows、macOS 或 Linux 版。

## 安装四步

1. **拿到 APK 文件**：从 [洛雪音乐介绍站](https://lxmusic.laze.skin/) 的下载页进入网盘分享页，把安装包转存到自己的夸克账号，再下载到手机存储里；
2. **放开安装权限**：在文件管理器里点开 APK，系统首次会提示「禁止安装未知来源应用」，按弹窗指引允许当前文件管理器（或浏览器）安装应用；
3. **确认安装**：核对权限弹窗后点安装，等进度条走完；遇到「解析包出现问题」多半是包没下完整，重新下载一次即可；
4. **首次打开**：先到设置里选主题颜色（绿意盎然 / 蓝田生玉 / 热情似火）和界面语言，再去「自定义源管理」导入并启用音源，搜索就有结果了。

## 装完之后

刚上手建议先翻一遍它的榜单侧栏和标签墙，熟悉「先挑榜单、再筛标签」的找歌路子，具体玩法见[洛雪音乐榜单和标签找歌玩法](洛雪音乐榜单和标签找歌玩法.md)。想先弄清这款软件的底细，可以读[洛雪音乐是什么软件值不值得装](洛雪音乐是什么软件值不值得装.md)。
