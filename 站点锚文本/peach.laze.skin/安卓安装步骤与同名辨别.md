# 安卓安装步骤与同名辨别

> 拿「Peach」当关键词去搜，撞到的一多半是别的产品。这篇讲两件事：怎么认出真正由凹凸有致科技开发的 Peach陪趣，以及装到安卓手机上的完整步骤。
> **相关文档**：[语音派对玩法入门.md](语音派对玩法入门.md) · [每晚九点的邂逅速配.md](每晚九点的邂逅速配.md)

---

装错同名应用不只是连不上人的问题——另一款语音社交产品与 Peach陪趣 形态相近，账号、充值互不相通，充进去的钱也跟着装错的地方走。所以这篇把「认对」放在「装上」前面讲。

## 一、三条核对线

| 核对项 | 应该是 | 说明 |
| --- | --- | --- |
| 包名 | `com.peach.app` | 装完可用「包名查看器」类工具复核 |
| 开发者 | 北京凹凸有致科技有限公司 | 应用内「关于」页或商店详情里能看到；这家公司 2015 年成立，2018 年底有过一轮 Pre-A 融资报道 |
| 名称沿革 | 桃趣 → 陪趣 | 2017 年前后的报道多写「桃趣」，2018 年底起用「陪趣」，商店在架名称为「Peach陪趣-恋爱交友处CP」 |

容易撞名的还有：一款名为「Peach - 這裡藏了一個可愛的你」的语音派对应用（开发者与反馈邮箱都不同）、日本的廉航 Peach Aviation，以及若干同类社交软件。核对完这三条再动手，基本不会装错。

## 二、安装四步

1. 从 [Peach陪趣安卓版下载安装](https://peach.laze.skin/) 这篇站点指引进入，先浏览一遍步骤与常见问题，再从页面按钮打开安装文件资源的网盘分享页；
2. 把文件转存到自己的夸克网盘账号，下载到手机存储，点开 apk——安卓 8 以上系统会弹「是否允许此应用安装」，选允许；部分机型入口在「设置 → 安全 → 更多安全设置 → 安装未知应用」，按应用单独授权；
3. 首次启动依次申请麦克风、存储、通知权限，麦克风是连麦必需项，拒绝就连不了麦；
4. 手机号加验证码注册登录，补上头像昵称，进「广场」挑个派对房试麦——上手路径见 [语音派对玩法入门.md](语音派对玩法入门.md)。

## 三、装不上时按现象排查

| 现象 | 先查什么 |
| --- | --- |
| 「解析包出现错误」 | 安装包没下完整或后缀被改，重新下载，确认文件以 `.apk` 结尾 |
| 安装按钮点了没反应 | 手机管家的「未知来源拦截」开着，按厂商说明放行一次 |
| 装上了但打不开 | 存储空间至少留几百 MB；手机里有同包名旧版本且签名不一致的，先卸载再装 |

渠道收录的 2.8.4 版本更新记录写着「紧急修复微博用户登录问题」，说明那一版对微博登录敏感——登录卡住时先用手机号验证码顶上。装好之后每晚 9 点的匹配入口怎么用，见 [每晚九点的邂逅速配.md](每晚九点的邂逅速配.md)。
