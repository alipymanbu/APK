# Gradient 名人撞脸测试怎么玩：照片要求、出图格式与翻车处理

> Gradient 最出圈的玩法就是「测你和哪位明星最像」：AI 把你的自拍和明星脸做成四格渐变过渡拼图。本篇把测试入口、照片怎么选、结果怎么导出一次讲清。
> **同站其他篇**：[AI滤镜与美颜工具盘点.md](AI滤镜与美颜工具盘点.md) · [订阅价格与免费功能边界.md](订阅价格与免费功能边界.md)

## 一、测试入口在哪

装好应用打开主界面，是一列功能入口，AI 测试类入口排在显眼位置（不同版本名称略有差异，比如名人相似这项在部分版本里叫「Who's Your Twin」）。流程统一是三步：选照片 → 等处理 → 保存或分享。

还没装的应用的，可以先看 [Gradient 玩法速览站](https://gradient.yoan.quest/) 的界面实拍与获取说明。

## 二、照片怎么选（决定成败的一步）

- **单人正脸**，不戴墨镜、口罩，脸在画面里占比别太小；
- **画面里别出现第二张脸**：合照里检测到的可能不是你；
- **光线均匀**、别逆光；侧脸、低头、运动模糊的照片容易测不出，或结果飘忽；
- 别用别人的照片去测，一是没意义，二是涉及他人肖像。

## 三、结果长什么样

名人相似的结果是一张「你 → 明星」的四格拼图：你的照片开头、明星照片收尾，中间两张过渡画面；底部可以切换方形 / 长条两种版式（Post A / Post B）。对结果不满意，直接点「Next」看下一位匹配对象，不用重选照片。右上角的分享按钮可以把图存到相册或直接发出去。

## 四、常见翻车与处理

| 现象 | 先做什么 |
| --- | --- |
| 一直「处理中」或中途报错 | 换一个稳定的 Wi-Fi / 流量重试，再不行清应用缓存重开 |
| 提示「未检测到人脸」 | 换正脸、清晰、光线好的照片 |
| 点进去直接弹价格页 | 这项属于订阅范围，边界说明见 [订阅价格与免费功能边界.md](订阅价格与免费功能边界.md) |
| 结果没保存就没了 | 生成后没点保存就只能重跑，养成出图先导出的习惯 |

同一个人换不同照片，撞脸结果可能不一样，这属于这类功能的正常现象，不用反复重测较真。除了撞脸，卡通化、动物相似、古典肖像这些测试的玩法与照片要求基本相同，功能全貌见 [AI滤镜与美颜工具盘点.md](AI滤镜与美颜工具盘点.md)。
