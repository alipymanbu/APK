# 怎么查看视频文件的编码信息

> 手机里存了一个视频，想知道它到底是什么编码、多少码率、有没有多音轨——系统自带的「属性」只给个文件大小，播放器又不显示这些细节。这篇讲清楚媒体文件内部有哪些信息值得看，以及在安卓上用什么方式读出来。
> 相关阅读：[视频有画面没声音怎么排查.md](视频有画面没声音怎么排查.md) · [转码前需要确认哪些参数.md](转码前需要确认哪些参数.md)

工具与安装入口见 [MediaInfo 安卓版介绍站](https://mediainfo.bpfl.quest/)，这里只讲怎么读、怎么理解。

## 一、媒体文件内部的信息分五组

一个视频文件并不是「一段画面」这么简单，它是一个容器，里面装着好几条流和一堆元数据，按组来读才不乱：

| 分组 | 典型字段 | 用来看什么 |
| --- | --- | --- |
| 常规 | 封装格式、时长、总体码率、写入程序 | 文件整体是什么规格 |
| 视频 | 编码、分辨率、帧率、位深、色彩空间 | 画面部分怎么压缩的 |
| 音频 | 编码、采样率、声道数、语言 | 每条音轨的底细 |
| 文本 | 字幕格式、语言 | 内挂了几条字幕 |
| 章节 | 章节数量与时间点 | 长视频怎么分段 |

「写入程序 / 写入库」这一项经常被忽略，其实很有用：它能告诉你这个文件当初是哪个软件压出来的，遇到奇怪的参数组合时，往往能从这里找到线索。

## 二、在安卓上读这些字段

桌面端这类工具很多，手机上比较方便的是 MediaInfo：把文件加进列表，点开就能看到按组展开的报告，编码、帧率、码率一目了然，报告还能导出成文本或 JSON 留档。安装入口见前文链接。

操作上只有三步：

1. 打开应用，点右下角添加按钮，从文件选择器里挑要看的视频；
2. 点开条目，按「概览 → 视频 → 音频」逐段读；
3. 需要发给别人讨论时，把视图切到文本格式再复制，比截图清楚得多。

## 三、字段怎么理解才不踩坑

- **码率**：总体码率是容器层面的平均值，视频轨、音频轨各有自己的码率，两者加起来才对得上总账；
- **帧率**：存在标称与实际两种口径，手机拍摄的视频常出现「标称 30、平均 29.x」，属于正常波动；
- **编码与封装是两回事**：MP4 是封装、AVC 是编码——「换个 MP4 就能播」的判断方式并不可靠，播放器认的是里面的编码。

## 四、读不出字段怎么办

先怀疑文件本身：下载中断、传输截断的文件，末尾索引丢失，时长与码率会大面积读不出来；换一个同类文件对比，别的正常就说明问题在源文件。编码太新也是常见原因，把工具升到新版本再读一次，往往就出来了。
