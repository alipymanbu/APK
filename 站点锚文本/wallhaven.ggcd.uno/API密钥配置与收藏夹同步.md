# API密钥配置与收藏夹同步

wallhaven 客户端不用登录也能正常找图、下载、设壁纸，但有一个功能值得多花两分钟：在应用里填入 API 密钥，把账号的线上收藏夹接进来。这样一来，在网页图库里攒下的好图，手机上翻开就有。这篇讲清楚密钥从哪来、填到哪去、填完能多干什么，应用本体的安装入口见 [wallhaven](https://wallhaven.ggcd.uno/) 站点。

---

## API 密钥是干什么的

图库站给注册用户每人发一把 API 密钥，相当于「这是我的账号」的通行证。客户端拿到这把钥匙，才能替你读取账号维度的数据：

- 查看并浏览账号的收藏夹；
- 同步书签与收藏记录；
- 使用账号权限内的完整图库功能（不同账号等级对应的接口范围不同）。

不填密钥，公共区域的浏览、筛选、下载一样能用；填了密钥，多的是「我的那一部分」。

## 密钥从哪里拿

1. 到图库站的网页端注册并登录账号；
2. 进入账号设置里的 API 区，页面会给出属于你的密钥串；
3. 复制这串字符。应用设置页的「API 密钥」项里也内置了获取方法的说明，忘了步骤随时回应用里看。

## 填进应用的三步

1. 打开应用，进入「功能设置」；
2. 点第一项「API 密钥」，粘贴刚复制的密钥串；
3. 保存后回到侧栏，底部会多出「查看用户收藏夹」一类的入口，点开就是自己账号里的收藏。

## 填完之后值得做的事

- **把网页端收藏翻一遍**：在手机上把这些图逐一设为壁纸或下载，图库账号真正变成了随身素材库；
- **书签两边共用**：手机上刷到的好图先收藏，回电脑前再细看，两头看到的是同一份清单；
- **密钥保管**：密钥等同于账号凭证，不要发给别人；换机重装后重新填一遍即可。

## 常见问题

- **填了密钥还是看不到收藏**：检查密钥有没有复制完整、前后有没有带空格；账号收藏设为私密时，客户端需要有对应权限才能读取；
- **密钥失效提示**：到网页端重新生成一把，旧密钥作废，应用里换上新串即可；
- **不想填密钥了**：把密钥清空保存，应用退回公共浏览模式，其余功能不受影响。
