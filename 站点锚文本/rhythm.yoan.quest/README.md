# Rhythm 安卓播放器介绍站（rhythm.yoan.quest）

这里是 Rhythm 音乐播放器的第三方介绍站导航页。Rhythm 是一款插件化的安卓播放器：本体只负责本地音乐播放与媒体管理，在线音乐、有声书、广播、网盘挂载都靠扩展插件逐个点亮。站点 [rhythm.yoan.quest](https://rhythm.yoan.quest/) 整理了它的「空壳 + 插件」运作方式、三类插件生态、音效设置与安装文件资源的获取入口。

## 本目录的文章

- [怎么下载安装.md](怎么下载安装.md) —— 从网盘转存到手机安装的完整流程，含安装被阻止、首次启动权限的处理；
- [插件怎么装.md](插件怎么装.md) —— 内置扩展清单与安装、手动添加扩展链接、装完不显示栏目的排查；
- [听不了歌怎么办.md](听不了歌怎么办.md) —— 本地扫描不出歌、在线源搜不到、歌词不显示的逐条排查思路。
