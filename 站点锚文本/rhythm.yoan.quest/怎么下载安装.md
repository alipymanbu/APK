# Rhythm 怎么下载安装

> 讲 Rhythm 安卓端从拿到安装包到装好打开的全流程：装前认版本、四步安装、首次启动的权限给取，以及两个最容易卡住的点。
> **相关文档**：[插件怎么装.md](插件怎么装.md) · [听不了歌怎么办.md](听不了歌怎么办.md)

## 装之前：先认准是哪一款 Rhythm

搜索引擎里叫 Rhythm 的播放器不止一款，最容易混的是 GitHub 上另两款同名开源播放器——它们与这里说的不是同一个软件。认准两条就不会装错：

- **包名是 `com.rhythm.app`**，装完可在系统「设置 → 应用」里核对；
- 版本号是三段式（如 v3.0.810、v3.0.858），前两段 3.0 稳定不变，末段递增。

系统要求有两个口径：采集页标注安卓 5.2 以上，长期用户的实测口径是安卓 7 起可用。拿不准机型，以装上后能否正常启动为准。

## 从哪拿安装包

安装包通过夸克网盘分发：打开 [Rhythm 介绍站](https://rhythm.yoan.quest/)，首页与下载页的「获取安装文件资源」按钮会带你去网盘分享页，转存到自己账户后，手机端就能下载。这个入口的链接集中写在站点的 links.js 一处，站点只做获取指引，安装包本体不在网页上。

## 四步装好

1. **转存**：打开网盘分享页，把资源转存到自己的网盘账户；
2. **下载**：手机网盘客户端里找到转存的文件下载到本机，或电脑下载后用数据线传过去；
3. **允许安装**：点开 APK，系统提示「禁止安装未知来源应用」时，按提示为当前来源（浏览器 / 文件管理器 / 网盘应用）打开允许开关，返回继续；
4. **首次启动**：开屏页点「开始」；界面不是中文就在语言（language）选项里切到中文；存储 / 媒体读取权限务必允许（不然扫不到本地歌），通知权限关系到锁屏切歌，建议一并允许。

拒绝过权限也能补救：系统「设置 → 应用 → Rhythm → 权限」里随时可以改回允许。

## 装完的正常形态

打开后底部只有「主页」「媒体库」两个标签，主页默认停在本地音乐页，且只有扫到的本地歌曲——**装完即空属正常**，这款播放器的在线内容全部靠插件提供，装完第一件事往往是去扩展面板挑插件，流程见 [插件怎么装.md](插件怎么装.md)。

## 两个常见卡点

- **点了安装没反应**：基本是未知来源限制没放开，去「设置 → 应用 → 特殊权限 → 安装未知应用」为下载用的应用开允许；
- **装上打不开或秒退**：先核对系统版本是否达到上述口径，再卸载重装一遍，装之前别改 APK 文件名。

更多播放层面的排查（扫不出歌、在线源搜不到）整理在 [听不了歌怎么办.md](听不了歌怎么办.md)。
