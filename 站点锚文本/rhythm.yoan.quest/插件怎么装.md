# Rhythm 插件怎么装

> 讲 Rhythm 的扩展机制：内置插件有哪些、怎么装一个新插件、扩展链接怎么手动添加，以及「装了却不显示栏目」这类小坑。
> **相关文档**：[怎么下载安装.md](怎么下载安装.md) · [听不了歌怎么办.md](听不了歌怎么办.md)

## 插件是怎么回事

Rhythm 本体只负责播放与管理，**在线内容全部由插件提供**：一个插件接一类资源，装上它，主页和媒体库就多出对应栏目。插件是 `rapk` 格式的独立扩展包，应用内的「扩展」入口负责安装与管理。据公开介绍与用户汇总，各版本的内置插件覆盖三类（清单随版本增删，以你装到的版本里实际显示为准）：

| 类别 | 常见插件 |
| --- | --- |
| 音乐 / 广播 | 爱听音乐、时代音乐、无名音乐、无忧音乐、DAB 音乐、全球广播、酷我畅听、酷狗、bilibili、油管音乐等 |
| 听书 / 有声 | 云图有声、有声小说、爱听有声、无忧有声、博看有声、海洋听书 |
| 存储 / 服务 | Alist、夸克网盘、UC 网盘、百度网盘、123 云盘、115 云盘、WebDAV、Jellyfin、Emby |

插件体积不小：有用户反馈下载类扩展约 8～9M、油管插件约 3M，安装前留意网络状况。

## 装内置插件

1. 进入扩展列表（按音乐、听书、网盘等分类排列），上下滑动找到想要的插件；
2. 点开插件 → 点安装；以音源类为例，装完再点搜索框，就能搜到该插件提供的内容；
3. 回主页点**左上角按钮**，能看到全部已装扩展，勾选要显示的栏目。

## 手动添加扩展链接

插件除内置列表外还能用链接添加：主页点右上角**设置** → 找到「扩展」一项点右侧 **+** 号 → 粘贴扩展链接确认 → 回主页点左上角按钮查看。手动链接的有效性由提供方决定，装不上先换来源再判断是不是版本太旧。

## 三个常见坑

- **装完不显示栏目**：先回主页点左上角按钮，确认它没被勾掉——栏目是按已装扩展动态生成的，装了不等于显示；
- **插件删不掉**：有反馈装完的插件无法卸载，目前只能用「设置 → 应用 → Rhythm → 存储 → 清除应用数据」重置（本地设置会一并清掉），装之前想清楚要不要它；
- **下载类插件提示过期**：插件包自身有有效期，换更新的插件包重装，或改用别的同类插件。

装好插件后在线歌加列表、歌词展开、下载入口这些操作的细节，见[听不了歌怎么办.md](听不了歌怎么办.md)；还没装上 Rhythm 的话，从[怎么下载安装.md](怎么下载安装.md)开始，或直接去 [Rhythm 介绍站](https://rhythm.yoan.quest/)看整站整理。
