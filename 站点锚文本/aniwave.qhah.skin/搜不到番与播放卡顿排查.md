# 搜不到番与播放卡顿排查

> 装好追番应用之后，最高频的两类故障是「搜不到想看的番」和「播放转圈不出画面」。这篇按「现象 → 先试什么 → 再试什么」的顺序整理，多数情况一两分钟就能定位。
> **相关文档**：[动漫追番应用怎么挑](动漫追番应用怎么挑.md) · [追番站更名与停运始末](追番站更名与停运始末.md)

## 一、排查前先做一件事

第三方追番应用的资源条目会随更新变动，很多「故障」其实是内容库在变化。动手排查前先接受一个前提：**条目时有时无是常态，先排除操作层面的原因，再怀疑应用本身。**

## 二、搜不到番：三轮排查法

1. **换写法**：全称、简称、英文、罗马音各试一次。第三方资料库的条目名写法不统一，同一部片可能挂在中文名下也可能挂在日文罗马音下；
2. **减字数**：只搜片名的核心词，把「第一季」「剧场版」「完整版」这类后缀去掉再试；
3. **换时段**：确认网络可用后，隔几个小时或第二天再搜——内容库更新期间条目会短暂消失。

三轮之后仍然搜不到，大概率是资源端暂时没有这个条目，不是你操作错了，也不用反复重装应用。

## 三、播放卡顿：先分清是网络还是源

用同一个网络打开另一个视频应用或网站做对照：

- **别的也慢** → 问题在你的网络：换 Wi-Fi / 流量对比一次，或等网络恢复；
- **只有追番应用异常** → 大概率是资源端波动：把清晰度降到最低一档重进播放页，多数立刻见效；仍不行就退出播放页换一集对比，排除单个条目的问题。

另外注意时段效应：晚间高峰段的缓冲会明显变多，多个第三方资料都把「高峰拥塞」列为在线播放卡顿的首要原因。错开时段观看，往往比反复刷新有效。

## 四、设备侧还能做的三件事

1. **清应用缓存**：系统设置 → 应用管理 → 对应应用 → 存储 → 清除缓存（只清缓存不动数据，观看设置不受影响）；
2. **对带宽有个数**：在线视频流畅播放的参考带宽约为 5 Mbps，实际低于这个水平时先解决网络再谈清晰度；
3. **重启大法**：应用完全退出重开、手机重启，听起来土但对「界面卡住、加载不出」类问题命中率不低。

## 五、什么情况不用再折腾

- 反复重装、换网络、换时段结果都一样 → 这份包在当前时点可能就是不可用状态，过几天再看；
- 不要为了「修好它」去安装来路不明的「修复补丁」「加速器配置」「解码器」——这类说辞是第三方分发里最常见的坑。
