# 手机离线缓存追剧方法

> 本篇讲把在线视频缓存到手机本地看的通用方法：入口在哪、权限怎么给、空间不够时怎么清，适合通勤与信号不稳的环境。

## 一、为什么先缓存再看

在线播放的质量取决于当下网络：地铁进隧道、高铁过山区、租房 Wi-Fi 拥挤，都会让视频转圈。缓存到本地后播放走的是存储读取，断网也能流畅播，还省流量——长剧集提前缓存，一个月能省下不少流量账单。

## 二、缓存的通用步骤

不同播放器入口名称略有差异，流程基本一致：

1. 在片库或搜索结果里找到想存的片子；
2. 点条目旁的**下载 / 缓存**按钮（有的应用收在播放页里）；
3. 弹出清晰度选择时按需选：标清省空间、超清观感好，通勤看选中间档最平衡；
4. 缓存完成后到**我的 → 下载管理 / 离线缓存**里找到并播放。

以 lutube 为例，缓存入口在视频条目旁，缓存记录在「下载管理」里分「已下载」和「正在下载」两栏，进度一目了然。它的功能与安装说明见 [lutube 资料站](https://lutube.gltd.quest/)。

## 三、权限与常见状况

- **点下载没反应**：先去系统设置确认应用的**存储权限**已开启，这是缓存成立的前提；
- **缓存的中途取消**：在下载列表里逐条暂停或删除，重新点缓存即可；
- **换播放器打不开**：应用缓存的内容通常只在应用内可播，拷出去别的播放器不一定认得，别白折腾。

## 四、空间不够时的清理顺序

1. 应用设置里的**清理缓存**入口：清的是临时数据，一般不动特意存的片子；
2. 下载管理里逐条删看完的剧集：两个入口常常相邻，删之前看清名字；
3. 还不够就删整季里已经看完的部分——缓存跟着账号走的前提是已登录，未登录的记录卸载即清零。

## 五、缓存之外的补充姿势

- 投屏：家里电视支持 DLNA 的，手机找到片源直接投大屏；
- 倍速：赶进度把倍速调到 1.25 或 1.5，长剧省时间；
- 播放异常：所有片子都放不出来时先查网络环境，个别片子放不出来换线路或换片源。
