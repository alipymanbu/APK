# MeTV 电视直播怎么看与频道分类

> 本篇讲打开 MeTV 之后看到什么、频道按什么分类、手机和电视分别怎么换台，以及点播区在哪。
> **相关文章**：[装到智能电视与盒子上的方法](装到智能电视与盒子上的方法.md) · [直播卡顿与黑屏的处理办法](直播卡顿与黑屏的处理办法.md)

## 一、打开就是直播画面

多数点播类应用打开先给首页和登录框，MeTV 不是这个路子：装好点开，直接进的就是电视直播画面，不用注册也不用登录。对只想「打开电视有个台在响」的人来说，这一步省得很实在。

打开后的内容大致分两块：

| 区域 | 里面是什么 |
| --- | --- |
| 直播 | 央视、卫视、地方台、高清、体育、少儿等类型的频道 |
| 点播 | 电影、电视剧、综艺这类自己挑着看的片子 |

看腻了直播切到点播搜一部片子，是比较常见的用法；两块内容在同一个应用里，不用另外装一个影音应用。

## 二、换台的两种操作

**手机上**：手指点一下屏幕唤出选台菜单，选中想看的频道即可，菜单会自己收回去。点错台不用回列表重找，再点一次屏幕重选就行。

**电视和盒子上**：手上只有遥控器，方向键把光标移到想看的频道，按 OK／确定键进去；返回键用来退出选台菜单或回到上一个界面。各品牌遥控器按键命名不一，能不能唤出面板以设备实际为准。

换台的几条经验：

- 换台之后出画需要一两秒，高清台更明显，别连着按——几路连接叠在一起抢带宽，反而更慢；
- 某些台在列表里看得到、点开是黑的，那是这一路信号此刻不通，不是操作错了；
- 频道列表会随版本和数据更新变动，以应用内实际显示为准。

## 三、按类型找台，别一个个翻

找台先想清楚要看哪一类，再去对应分类里挑，比从头翻到底快得多：

| 分类 | 大致包含 |
| --- | --- |
| 央视 | 中央台各频道，新闻、综艺、纪录等 |
| 卫视 | 各省上星频道，热播剧和综艺多 |
| 地方台 | 各省市本地频道，想看家乡节目从这里找 |
| 高清 | 单独归到高清一档的频道 |
| 体育 | 赛事直播与体育资讯 |
| 少儿 | 动画与少儿节目 |

同一类里频道多的时候，结合选台菜单里的排序或搜索入口更快；搜索对点播那块用处更明显，直接输片名比翻分类省事。

## 四、找不到想看的频道时

| 现象 | 多半原因 | 怎么办 |
| --- | --- | --- |
| 整个选台列表是空的 | 频道数据没拉下来，多半是网络问题 | 退出重进；仍为空就换个网络再试 |
| 列表正常，但就是没有那个台 | 应用没收录该频道 | 换同类型其他台，别指望收全 |
| 点开是黑的或一直转圈 | 这一路信号此刻不通 | 换台验证，处理思路见 [直播卡顿与黑屏的处理办法](直播卡顿与黑屏的处理办法.md) |

还没装的，可以先到 [MeTV 资料站](https://metv.qjxz.skin/) 把功能与画面看一遍，再决定要不要装。
