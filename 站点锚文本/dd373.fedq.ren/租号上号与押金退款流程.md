# 租号上号与押金退款流程

> 租号和买号是两条完全不同的业务线：租的是一段时间内的使用权，账号密码不经手，靠上号器自动登录。这篇讲清楚从选号到退押金的每一步，以及哪些行为会让押金直接扣光。
> **相关阅读**：[担保交易与找回包赔规则.md](担保交易与找回包赔规则.md) · [买卖游戏账号的防坑清单.md](买卖游戏账号的防坑清单.md)

## 一、租号为什么「多一套工具」

DD373 上的租号，账号密码不交给你，而是由 PC 端的上号器自动帮你输入登录。所以租号比买号多出两个专属问题：上号器装不上或报错，以及押金的退还规则。租号入口在租号大厅，与商品交易并列。

## 二、完整流程五步

1. **选号**：租号大厅先选游戏，再用筛选条件缩小范围，看商品详情；
2. **下单支付**：点「立即租号」，支持银行卡、支付宝、花呗、微信，部分订单可用余额兑钻支付；
3. **复制登录码**：支付成功后进「我租到的帐号 → 订单详情」，复制登录订单号；
4. **上号器登录**：录入用户名与登录码，选普通登录，等它自动把账密输进游戏 —— 自动输入过程中别碰鼠标键盘，一动就可能失败；
5. **到期失效**：租期内不改密码、不切号，租期到点使用权自动结束。

登录码忘了就去个人中心的「我租到的帐号」里查；上号器自动更新失败时，重新下载最新版再试。

## 三、押金什么情况退、退多少

| 情形 | 结果 |
| --- | --- |
| 正常租用无违规 | 押金 48 小时内返还平台账户 |
| 卖家侧问题（密码错误、被顶号） | 核实后退全部租金 |
| 账号本身进不去（异地限制、需令牌） | 核实后退全部租金 |
| 自己中途撤单 | 15 分钟内全退，之后按小时计 |
| 自己违规、卖家维权成立 | 从押金里扣钱赔付卖家 |

## 四、这些行为直接进黑名单

上号器会检测运行环境，租号期间开着下面这些工具会被判环境异常，订单即刻终止、押金扣光并纳入全网黑名单（换号重新注册也租不了）：

- 卡屏器、连招工具、按键精灵、语音脚本工具；
- 无限视距、换肤、画质美化、鼠标宏；
- 各类第三方盒子、网吧特权软件，以及一切游戏外挂。

后果更重的两条：租号期间违反游戏行为准则导致账号被裁决、禁赛，扣全部押金补偿卖家，三次以上冻结平台账户；试图开外挂或脚本的，平台保留追责权利。

对判定有异议，可以按复核渠道提交登录码与用户名申诉。

## 五、装客户端与延伸阅读

只想短租体验的话，网页端就能下单；打算长期买卖的，装个手机客户端更方便 —— [DD373 交易观察](https://dd373.fedq.ren/)整理了安卓端安装文件资源的获取入口和安装步骤。买号押钱的机制差别，见 [担保交易与找回包赔规则.md](担保交易与找回包赔规则.md)。
