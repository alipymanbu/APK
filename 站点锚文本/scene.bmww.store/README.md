# scene.bmww.store · 站点说明

本站是一个第三方软件介绍页，围绕安卓系统工具箱 Scene 整理：它把帧率记录、充电与耗电统计、应用冻结、屏幕测试这些系统级能力收进一个应用，按「基础 / ADB / ROOT」三档权限分层开放。站点提供功能构成说明、三种工作模式的对照，以及安装文件资源的获取入口（夸克网盘转存）。

从这里进入：[Scene 工具箱数据台](https://scene.bmww.store/)。
