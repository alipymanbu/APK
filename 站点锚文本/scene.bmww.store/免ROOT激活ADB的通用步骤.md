# 免ROOT激活ADB的通用步骤

> 很多系统级小能力 —— 帧率记录、应用冻结、卸载预装 —— 都卡在权限上：普通应用拿不到，ROOT 又太重。ADB 级权限正好卡在中间：能力够用、不动系统底层、还不用解锁手机。本篇整理目前主流的几条免 ROOT 激活路线。

## 一、为什么「无线调试」改变了局面

Android 11 起系统自带「无线调试」：手机自己就能完成 adb 配对，不再必须连电脑。绝大多数免 ROOT 工具（各类工具箱、冻结器、权限管理器）都改走这条路 —— 用一个「授权器」应用完成配对，再把权限转交给目标工具。

开工前先把开发者选项打开：设置 → 关于手机 → 连续点「版本号」约 7 次。

## 二、路线一：Shizuku + 无线调试（Android 11+，推荐）

Shizuku 是目前最常用的授权器，思路是「一次配对，多工具共享」：

1. 装好 Shizuku，首次打开允许它发通知（配对码要从通知栏输入）；
2. 开发者选项里同时打开「USB 调试」和「无线调试」，手机连着 WLAN；
3. 进系统的「无线调试」页面，点「使用配对码配对设备」，记下 6 位配对码和端口；
4. 下拉通知栏，在 Shizuku 通知里输入配对码，确认配对；
5. 回 Shizuku 主页点「启动」，状态变成「正在运行」即成；
6. 打开要用权限的工具（以 Scene 工具箱为例，在模式选择页选 ADB 模式），弹出授权框时选「始终允许」。

两个系统层面的限制提前知道：**配对只需一次，但每次重启手机后 Shizuku 要重新点一次「启动」**；无线调试依赖同一 WLAN 环境，换网络可能要重来。

## 三、路线二：电脑 adb（Android 10 及以下或无线调试不可用）

1. 电脑下载 Google 官方的 platform-tools（SDK 平台工具）并解压；
2. 手机开 USB 调试，数据线连电脑，首次连接在手机上点「允许调试」；
3. 电脑在解压目录打开终端，执行 `adb devices` 确认设备已列出；
4. 目标工具的激活页会显示需要在电脑上执行的命令，照抄执行 —— 不同工具、不同版本命令不同，以应用内显示为准。

## 四、激活失败的排查清单

| 现象 | 先检查什么 |
| --- | --- |
| 一直「正在搜索配对服务」 | 手机是否在同一 WLAN；无线调试关掉重开再试 |
| 输配对码立刻失败 | 配对码是一次性的，弹窗关掉或超时就失效，重新取一组 |
| 配对成功但工具弹不出授权框 | 授权器状态是否「正在运行」；给工具关掉省电限制、允许后台运行 |
| 提示权限不足 | 部分机型要在开发者选项里开「禁止权限监控」 |
| 重启后功能又失效 | 正常现象：重启 Shizuku 即可，不用重新配对 |

## 五、权限拿到之后

ADB 模式能解锁什么取决于工具本身。以系统工具箱类的 Scene 为例：帧率记录、充电与耗电统计、应用冻结、系统应用卸载都在这一档开放；更深的 CPU 调度、刷写镜像才需要 ROOT。功能全貌可以看这个 [Scene 工具箱介绍页](https://scene.bmww.store/)。一条安全线提醒：这一层级已经能卸载系统应用，列表里看不懂用途的组件（尤其 `com.android` 开头的）不要动手，卸错关键组件可能无法开机。
