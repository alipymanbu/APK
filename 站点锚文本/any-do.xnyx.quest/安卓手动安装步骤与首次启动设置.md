# 安卓手动安装步骤与首次启动设置

> 本篇讲手机上没有应用商店（或商店里装不了）时，手动安装 Any.do 安卓版的完整步骤，以及首次启动要处理的注册、权限和界面语言；装完想先弄清楚免费能用到什么程度，见[免费版与付费档的功能边界.md](免费版与付费档的功能边界.md)。

---

手动安装听起来麻烦，其实就是「拿到 APK → 给一次权限 → 装完配置」三段事。Any.do 是待办、日历与提醒三合一的应用，安卓 5.0 及以上的手机都能装，整个过程五分钟内能走完。安装包可以从[Any.do 安卓版下载安装](https://any-do.xnyx.quest/)这个介绍页的网盘入口拿到，下面按顺序说明。

## 一、动手前确认三件事

| 检查项 | 要求 | 不满足的后果 |
| --- | --- | --- |
| 系统版本 | 安卓 5.0 及以上 | 装不上或闪退 |
| 剩余存储 | 安装包约 81 MB，装完占用更大 | 安装中途失败 |
| 安装包来源 | 从介绍页的网盘入口获取 | 来源不明的包有风险 |

不同渠道给出的版本号可能不一样，装哪一版自己定；只想先体验核心功能的话，差异影响不大。

## 二、安装四步

1. 把 APK 文件下到手机存储（网盘里先转存到自己账号，再从网盘客户端下载）。
2. 在文件管理器里点开 APK。系统第一次会拦一下，弹窗里选「设置」，允许这个文件管理器「安装未知应用」，不同机型的入口略有差异，一般在 设置 → 安全 附近。
3. 回到安装界面点「安装」，等进度走完。
4. 点「打开」，或者回桌面从图标进。

## 三、首次启动要处理的三件事

- **注册或登录**：启动后直接进登录页，没有「先逛逛」的入口——数据全挂在账号上，这是它多设备同步的前提。注册方式四选一：邮箱、Google、Facebook、Apple。选了哪种，以后就得一直用哪种登录，换方式登录会变成另一个空账号。
- **通知权限**：安装完系统会弹通知授权，建议直接给。提醒功能是这个应用的核心，权限没给，后面设了提醒也收不到。
- **界面语言**：安卓版自带简体和繁体中文，不用另找语言包。入口在 Settings → Language，选简体中文即可。

## 四、装完先验证两件事

1. **提醒能不能推**：随手建一条一分钟后的任务提醒，锁屏等它响。能弹通知，说明通知链路是通的。
2. **日历能不能显示**：在设置里打开日历集成，看系统日历里的事件有没有出现在应用里。这一步不通一般是日历权限没给。
