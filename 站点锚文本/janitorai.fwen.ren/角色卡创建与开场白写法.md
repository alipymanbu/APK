# JanitorAI 角色卡怎么写：字段含义与开场白技巧

> 本篇讲 JanitorAI 角色卡的每个字段填什么、开场白怎么写才稳、发布前怎么自己测一轮。
> **相关文档**：[安卓客户端安装步骤.md](安卓客户端安装步骤.md) · [中文对话设置方法.md](中文对话设置方法.md) · [角色健忘与消息限制处理.md](角色健忘与消息限制处理.md)

---

JanitorAI 的角色库由社区贡献，量很大，按标签（动漫、历史、游戏、恋爱向……）筛比按推荐翻快。多数人前几次聊天挑现成的就行；想自己写一个，从主菜单进 Create Character（手机端在头像菜单里），下面按字段拆解。

## 先会挑，再学写

挑现成角色的要领是看**简介和开场白**：开场白写得细的角色，后面回复质量通常也稳；只有三行简介配张图的，进去往往没话聊。想快速感受这个平台的玩法，可以从整理了界面与玩法说明的 [JanitorAI 介绍站](https://janitorai.fwen.ren/) 看起，再决定自己写还是先聊现成的。

## 角色卡字段逐个说

| 字段 | 必填 | 填什么 |
| --- | --- | --- |
| 角色图片 | 是 | 卡片封面，需符合社区规范 |
| Character Name | 是 | 显示在卡片顶部的名字 |
| Character Chat Name | 否 | 聊天时角色的自称，比上面短 |
| Character Bio | 建议填 | 给读者看的简介，不参与对话 |
| Tags | 至少一个 | 决定能否被搜到，最多 10 个 |
| Personality | 是 | **真正喂给模型的部分**：性格、背景、说话方式、示例对话都写这里 |
| Scenario | 否 | 场景、时代、角色与你的关系 |
| Initial Message | 是 | 开场白，同时给回复定文风基调 |

几条实操经验：

- **Personality 是权重最高的框**，示例对话也放这里。但别堆太厚——常驻内容每条消息都要占同一块空间，堆得越高，聊天本身可用的空间越小，角色反而更容易忘事，成因见[角色健忘与消息限制处理](角色健忘与消息限制处理.md)。
- **开场白用第三人称写**，能明显减少模型替你说话（把你的台词也写了）的毛病。
- **Bio 和 Personality 别混**：Bio 是门面，写给路过的人看；Personality 是角色的行为说明书。
- **想钉死中文**，在 Personality 开头加一句语言声明，具体见[中文对话设置方法](中文对话设置方法.md)。

## 发布前先私有测一轮

保存时选可见性：Private 只有自己能用，Public 进公开库被所有人搜到。建议先私有测几轮——用 Test Chat 开一局，发几条不同风格的消息，看角色是否自称设定的名字、开场白文风有没有保持住、长句多人场景接不接得住。满意再转公开，公开后别反复上下架，别人收藏过的引用会失效。

写角色之前得先有账号：注册登录的入口与三种方式的取舍，整理在[安卓客户端安装步骤](安卓客户端安装步骤.md)的登录一节。
