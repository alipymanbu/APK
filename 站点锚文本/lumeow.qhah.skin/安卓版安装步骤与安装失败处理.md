# lumeow 安卓版安装步骤与安装失败处理

> 本篇讲 lumeow 安卓安装包从获取到装进手机的全流程：转存、下载、放开安装权限、登录，以及三件最常挡路的事怎么处理。

## 一、装之前先核对两件事

- **系统版本**：安装包要求安卓 5.2 及以上（设置 → 关于手机里看），低于这个版本会提示解析失败；
- **存储空间**：包体约 25 MB，加上安装后的运行数据，预留 200 MB 以上空闲更稳。

安装包从网盘资源获取，装完后首次启动需要注册登录。步骤整理得细一点，是为了让第一次装的人不走弯路。

## 二、四步装完

1. **打开资源页并转存**：进入分享页后先把安装包转存到自己网盘账号名下，再从网盘客户端下载到手机——建议别跳过转存，也别去别处搜安装包，来源不明的包风险高；
2. **下载 APK 到手机**：在网盘里选中 APK 文件下载，通知栏看进度，下完点开文件；
3. **放开「安装未知应用」**：系统会拦一次——到 设置 → 安全 / 隐私 → 安装未知应用，给你用来打开 APK 的那个应用（浏览器或文件管理器）单独授权，回来再点「安装」；
4. **装完打开并登录**：点「打开」进入应用，右上角「登录 / 注册」，用邮箱号 + 验证码 + 两遍密码完成注册；验证码约 5 分钟内有效，先备好一个能收信的邮箱。

四步里具体的按钮位置，图文版可以对着 [lumeow 安卓版下载页](https://lumeow.qhah.skin/download.html) 一步步来，两页内容是一致的。

## 三、三件最常挡路的事

| 现象 | 多半的原因 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 下载不完整，或系统低于安卓 5.2 | 回网盘重新下载一次；再不行核对系统版本 |
| 「安装」按钮置灰 | 来源权限没放开 | 按第 3 步给打开 APK 的应用授权后重试 |
| 装完点开就闪退 | 网络问题或机型兼容 | 先换网重启（AI 对话必须联网）；仍闪退记录机型，重装前确认包是最新转存的 |
