# easyconnect 连不上常见原因

> 按现象对号入座：点连接没反应、安装报不兼容、登录成功却打不开资源。地址格式怎么写见 [服务器地址怎么填](服务器地址怎么填.md)，产品本身的定位见 [是干什么的软件](是干什么的软件.md)。

## 现象一：点连接没反应 / 提示连接失败

按命中率从高到低查：

1. **地址格式**：必须是 `https://域名或IP:端口` 的完整写法。只填 IP 不带端口时，客户端会去连 80 端口，而设备默认接入端口多为 4430——这是「别人都能连就你连不上」的最常见原因。用手机浏览器直接输这个地址，能打开登录页说明地址本身没问题；
2. **对照电脑端**：连同一 WiFi，电脑浏览器能不能打开同一个 VPN 地址。电脑能、手机不能，问题在手机侧；两边都不能，是网络或设备侧的问题（设备维护、线路不通），只能等或报管理员；
3. **手机网络**：客户端自己也要联网，切一下 WiFi / 流量再试；手机上装了其他 VPN 类软件的，先关掉——两个 VPN 抢通道会互相干扰；
4. **手机系统太新**：单位设备版本较老时，可能不支持最新一两年出厂的手机系统，表现为所有设置都对但一登录就断。这要管理员升级设备侧，个人端无解。

## 现象二：安装时提示「应用未安装 / 不兼容」

- 包没下完整是最常见的假性不兼容，重新下载一遍再装；
- 个别折叠屏机型与手机版安装包确实不合，找管理员要适配机型的包；
- 平板用户直接换平板版安装包，别硬装手机版。

## 现象三：登录成功但打不开内网资源

登录这一步过了，问题出在资源层：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 资源列表是空的 | 管理员没给账号配资源 | 问管理员 |
| 隧道类资源全打不开 | 弹「连接请求」时点了拒绝 | 断开后重新登录，弹窗时点确定，确认状态栏出现 VPN 钥匙图标 |
| 状态栏有图标但某系统打不开 | 对该系统没有访问权限 | 问管理员加权限 |
| 内网网页能开、App 连不上内网 | 只有 WEB 资源权限，没有隧道权限 | 问管理员确认资源类型 |

## 现象四：连上了但一切都很慢

VPN 工作时流量要绕道单位服务器中转，速度上限就是服务器和线路的负载，这不是故障。两条缓解：用完及时**注销**（资源列表页右滑选注销，别只划掉 App）；访问公网网站时先断开，需要内网时再连。

## 都排除了还不行

那就只剩设备侧配置一种可能，把现象（地址、报错截图、手机型号与系统版本）整理好发给单位管理员，比一句「连不上」更快拿到答案。客户端的获取与安装流程见 [EasyConnect 使用说明站](https://easyconnect.wxhp.skin/)。
