# MCPEDL 资源站导航

MCPEDL 是 Minecraft 基岩版玩家手机上找模组的常用安卓应用，这里收录它的介绍站与使用要点，安装文件资源的获取入口也在里面。

## 从哪里开始

- 想了解这个应用能做什么：看 [安卓应用下载安装步骤](安卓应用下载安装步骤.md)，从获取安装包一路写到装完确认；
- 装完之后怎么用：看 [基岩版模组导入与激活方法](基岩版模组导入与激活方法.md)，附加包、地图、皮肤分别怎么启用都有；
- 挑内容时犯难：看 [材质包光影与地图怎么选](材质包光影与地图怎么选.md)，按玩法需求对号入座。

应用介绍与安装文件资源的获取入口见 [MCPEDL 安卓应用介绍站](https://mcpedl.bpfl.quest/)。
