# MCPEDL 模组导入与激活方法

> 从应用里下载的内容要经过「应用内下载 → 导入 Minecraft → 在世界里启用」三步才真正生效。本篇按附加包、地图、皮肤、材质分别写清每一步怎么点，末尾附 zip 手动导入兜底。
> **相关文档**：[安卓应用下载安装步骤.md](安卓应用下载安装步骤.md) · [材质包光影与地图怎么选.md](材质包光影与地图怎么选.md)

## 一、导入前的准备

- 手机上已装 Minecraft 基岩版（手机版），且能正常进游戏；
- MCPEDL 与 Minecraft 装在同一部手机上——导入是靠系统把文件「交给」游戏完成的；
- 网络可用：浏览目录和下载内容都需要联网。

## 二、在应用里下载内容

1. 按分类浏览或用搜索框找到想要的内容，点开详情页；
2. 点下载按钮，等进度走完；
3. 下载完成的条目会出现在应用的下载（Downloads）页，后面的导入从这里点。

连续下载多个内容时下载按钮可能卡住：重启应用可以缓解，之后一个条目下载完成再点下一个。

## 三、把文件导入 Minecraft

1. 在下载页点已完成条目旁的下载图标；
2. 系统弹出「选择打开方式」，点 **Minecraft**；
3. 游戏自动拉起并开始导入，屏幕上方出现 `Import started...`，伴随一声提示音；
4. 导入完成显示 `Successfully imported`——此时文件已进游戏，但**还没生效**，接着看下一节。

这一步常见的三种英文报错：

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `Duplicate Pack Detected` | 同一个包已导入过，新旧冲突 | 游戏「设置 → 存储」删掉旧版再导 |
| `Failed to import` | 常见是包缺清单文件 | 先重启游戏再导一次，仍失败找内容作者 |
| `Not a Valid Zip Archive` | 下载损坏或打包不规范 | 重新下载；不行改手动解压导入 |

## 四、在游戏里启用（按类型）

**附加包 / 模组（.mcaddon）**

1. 创建新世界或编辑现有世界；
2. 世界设置里点「资源包」和「行为包」，切到「可用」标签激活；
3. 附加包通常**两边都要激活**，只开一边功能会缺；
4. 部分附加包要求打开「实验性玩法」开关（包说明里会写）。注意：开了实验玩法或模组的世界，成就不可解锁——在意成就的话，留一个干净的原版生存世界专刷成就。

**地图 / 世界（.mcworld）**：导入完成后直接出现在主菜单的世界列表里。

**皮肤**：主界面「更衣室」（Dressing Room）→「经典皮肤」里找。

**材质 / 光影**：单个世界在世界设置的资源包里激活；想全局生效，在「设置 → 全局资源」里激活。

## 五、zip 手动导入兜底

下载到的是 `.zip` / `.rar`，或自动导入一直失败时：

1. 把 `.mcpack` / `.mcaddon` 改名为 `.zip` 解压；
2. 按内容类型把文件夹放进 Minecraft 数据目录 `games/com.mojang/` 下的对应位置：

| 内容类型 | 放到哪 |
| --- | --- |
| 世界 / 地图 | `games/com.mojang/minecraftWorlds/` |
| 资源包（材质、光影） | `games/com.mojang/resource_packs/` |
| 行为包（模组逻辑） | `games/com.mojang/behavior_packs/` |

3. 重启 Minecraft，再按第四节启用。

目录放错是「导入显示成功、游戏里却找不到」最常见的原因，逐层核对上面三个路径。

## 六、还没装应用？

先从安装开始：获取入口与安装步骤见 [安卓应用下载安装步骤.md](安卓应用下载安装步骤.md)；挑哪类内容先下手，见 [材质包光影与地图怎么选.md](材质包光影与地图怎么选.md)。应用的整体介绍与获取入口也在 [MCPEDL 安卓应用介绍站](https://mcpedl.bpfl.quest/)。
