# MCPEDL 材质包光影与地图怎么选

> 应用里的内容按模组、材质包、光影、地图、皮肤五类分开，下载下来对应 `.mcpack`、`.mcaddon`、`.mcworld` 这类专用格式。本篇讲每类内容适合什么场景、挑选时看哪几项，帮你少下废包。
> **相关文档**：[基岩版模组导入与激活方法.md](基岩版模组导入与激活方法.md) · [安卓应用下载安装步骤.md](安卓应用下载安装步骤.md)

## 一、先想清楚要改什么

| 类型 | 改变什么 | 适合场景 |
| --- | --- | --- |
| 模组 / 附加包（Add-Ons） | 游戏行为：新生物、新物品、新机制 | 玩腻原版玩法，想要新目标 |
| 材质包（Texture Packs） | 方块与物品的贴图外观 | 画面看腻，玩法不想动 |
| 光影（Shaders） | 光照、阴影、水面效果 | 配合材质包一起换画面 |
| 地图 / 世界（Maps） | 整张世界：存档、玩法、建筑 | 想直接玩别人做好的关卡 |
| 皮肤包（Skin Packs） | 角色外观 | 纯装饰，随时换 |

手机性能一般的话，光影优先选「轻量 / 性能版」：重光影在手机上掉帧明显，先用轻量版试水再逐步加码。

## 二、挑内容时看详情页的哪几项

详情页会标注作者、更新日期、适用版本要求与评论区，四项按重要性排：

1. **适用版本**：包要求的最低游戏版本高于你手机上的 Minecraft 版本时，导入后可能不生效或报错——这是「装了没效果」的头号原因；
2. **评分与评论**：社区内容质量参差，评分过低或评论区集中报「导入失败」的直接跳过；
3. **更新日期**：长期没更新的包在新版游戏上容易出兼容问题，玩法类尤其明显；
4. **作者说明**：要不要开「实验性玩法」、成就是否受影响，说明里都会写，装前看一眼。

顺带一提：不少附加包会标注「Achievement Friendly（成就友好）」，想要一边玩模组一边刷成就的话，优先挑这类。

## 三、下载下来是什么文件

- `.mcpack`：单个资源包（材质、光影、皮肤包），导入后进世界设置的「资源包」；
- `.mcaddon`：成套附加包（行为包 + 资源包），两边都要激活；
- `.mcworld`：完整世界（地图），导入后直接出现在世界列表；
- `.zip` / `.rar`：老式打包，要手动解压放进游戏数据目录。

这些格式只适用于**基岩版**（手机版 / Win10 版），Java 版电脑客户端用不了。导入的点击步骤见 [基岩版模组导入与激活方法.md](基岩版模组导入与激活方法.md)。
