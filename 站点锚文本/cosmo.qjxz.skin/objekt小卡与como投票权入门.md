# Objekt 小卡与 COMO 投票权入门

> 刚接触 tripleS / ARTMS / idntt 的粉丝平台，最先要弄懂的两个词就是 Objekt 和 COMO：前者是你收藏的数字小卡，后者是卡片掉落的投票权。这篇把两者讲清楚。
> **相关文档**：[gravity投票如何参与.md](gravity投票如何参与.md) · [grid合成与spin开卡规则.md](grid合成与spin开卡规则.md)

## 一、Objekt 是什么

Objekt 是 Cosmo : the Gate 里的数字小卡，以 NFT 形式发行，每一张都绑定成员、季与等级。你在 App 里翻卡、合成、参加活动，围绕的都是这套卡片体系。

来源分两条线：

- **线上数字卡**：Spin 开卡、商店购入、活动奖励，直接进你的收藏；
- **线下实体卡**：随专辑、季节问候（Season Greeting）等周边发行，和线上是同一套体系、互相对应。

收藏列表可以按成员、季、等级筛选，卡片右上角那条彩色竖条就是等级标识——你在截图里看到的 01Z、10Z 这类字样就是卡号。

## 二、COMO：卡片掉落的投票权

每张 Objekt 都会掉落 COMO，不同等级掉落的数量不同。COMO 的去向只有一个：Gravity 投票。攒在手里不投只是数字，投出去才会变成对艺人活动的实际影响。

点开 App 里显示 COMO 数量的位置，能看到收支明细与参与历史——哪张卡掉了多少、哪次 Gravity 用了多少，都查得到。

## 三、从收藏到投票的最短路径

1. 进 App，选好要关注的艺人频道（tripleS / ARTMS / idntt 都在）；
2. 在 Collect 里翻自己的卡，或在 Spin、商店补卡；
3. 用卡片掉落的 COMO 去参加正在进行的 Gravity。

卡片既是收藏品，也是选票来源。想一次看全这条链路，可以逛逛这个 [Cosmo : the Gate 玩法介绍站](https://cosmo.qjxz.skin/)，三个板块按链路顺序排的。

## 四、新手常见的小疑问

**实体卡和数字卡什么关系？**
实体 Objekt 随专辑、季节问候等线下渠道发行，线上数字卡与线下活动互相对应，收藏的是同一套体系。

**新人先攒卡还是先投票？**
先看当前有没有进行中的 Gravity：有就看活动规则再决定补不补卡；没有就按喜欢的成员慢慢攒，等下一次投票开桌。
