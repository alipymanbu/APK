# Kali Linux 教程的安卓手机离线阅读方案

> 手边没有电脑、流量又不想浪费：怎么在安卓手机上离线读完一套 kali linux 图文教程，这篇讲清形态、装法与注意点。
> **相关文档**：[初学者入门学习路径](初学者入门学习路径.md) · [工具概念速览与练习边界](工具概念速览与练习边界.md)

---

## 一、离线阅读为什么可行

kali linux 的入门内容以图文为主——概念讲解、界面介绍、命令说明、工具用途，配桌面实操截图。这类内容一旦随安装包内置，阅读就不再依赖网络：地铁上、排队时掏出手机翻两章，正是概念积累阶段最合适的碎片用法。

有一款叫 Learn Kali Linux 的教学应用就是这个形态：教程按主题分章内置，装完打开即读，全程不联网、无账号体系。它不改变手机系统，也不提供终端——定位就是「读」。

## 二、装到手机上的路径

流程与普通安卓应用一致：

1. 拿到安装包（网盘分享是常见渠道）；
2. 点开 APK，对「安装未知来源应用」按提示放行；
3. 装完打开，从首屏主入口进章节目录。

配置门槛很低：体积约 18 MB，安卓 5.2 及以上即可。装不上时先怀疑文件没下完整，重新下载一遍再试。站内把每个步骤连同放行方法写得更细，见 [kali linux 安卓版安装说明](https://kali-linux.fedq.quest/)。

## 三、两个使用注意

- **界面是英文的**：顶栏、菜单、正文全英文。配合系统划词翻译读并不费劲，高频入口认几个单词就够（如 Let's Start = 从这里开始）。
- **别指望在它里面敲命令**：它是教程不是系统，没有终端。命令练习回到电脑上的虚拟机环境做，两边怎么分工见 [初学者入门学习路径](初学者入门学习路径.md)。

## 四、什么人适合这个方案

适合两种情况：一是还没有可用的电脑环境，想先在手机上把概念过完一遍；二是已有环境，但想把碎片时间用在复习概念与工具用途上。要动手做工具实验时，边界在哪里见 [工具概念速览与练习边界](工具概念速览与练习边界.md)。
