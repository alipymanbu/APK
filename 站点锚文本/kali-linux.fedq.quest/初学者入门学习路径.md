# Kali Linux 初学者入门学习路径

> 想入门 kali linux 但不知道从哪下手：先学什么、后学什么、哪些内容要放到电脑上练，这篇按顺序讲清。

## 一、先建立整体认识，再谈动手

很多初学者一上来就想把工具跑起来，结果卡在环境搭建上直接劝退。更稳的顺序是反过来的：先弄清 kali linux 是什么——一个基于 Debian 的安全发行版，桌面与终端各是什么角色——再去记命令，最后才挑工具章深入。概念层没建立之前，任何工具操作都只是照抄。

碎片时间里能做的事恰恰是第一步：读图文、认界面、记住每类工具解决什么问题。这一层不需要终端环境，手机上就能完成。

## 二、三段式学习顺序

1. **基础章打底**：系统的定位、桌面与终端的关系、基本操作方式。读完能给别人讲清「它和普通桌面 Linux 差在哪」就算过关。
2. **命令章混眼熟**：`ls`、`cd`、`cat`、`sudo`、`apt` 这类高频命令先过一遍，不求背熟，见到能想起用途即可——后面工具章的每一步操作几乎都在用它们。
3. **按需挑工具章**：网络类、漏洞分析类按兴趣与需要跳读，不必通读。每读完一章给自己三条判据：能说出这章的工具解决什么问题、能在自己环境里敲通至少一条核心命令、报错时能读出原因层次（命令没装 / 权限 / 网络）。

## 三、手机端在整条路径里的位置

前两段（概念 + 命令认知）完全可以放在手机上利用碎片时间完成；第三段的「敲」留给电脑上的虚拟机环境。具体怎么在安卓上离线读教程，见 [安卓手机离线阅读方案](安卓手机离线阅读方案.md)；工具章会讲哪些内容、练到哪里为止，见 [工具概念速览与练习边界](工具概念速览与练习边界.md)。

市面上有一类教学应用把整套 kali linux 图文教程装进了安装包，按章节离线阅读，适合承担「手机端读概念」这一段——站点里有它的板块划分、首屏入口与学习路线整理，见 [kali linux 手机端介绍站](https://kali-linux.fedq.quest/)。

## 四、别跳过的两个提醒

- 教程类内容只解决「认识」；动手练习只在自己的设备或自行搭建的靶场环境里做。
- 别拿「背命令」当目标。命令是手段，能复述「这一章解决什么问题」才是学会的标志。
