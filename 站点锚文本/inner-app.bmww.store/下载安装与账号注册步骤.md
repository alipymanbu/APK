# inner 下载安装与账号注册步骤

> 安卓端怎么装、注册要填什么、注销入口在哪一步——把账号从无到有的过程一次讲清。
> **相关文档**：[创作者社区功能与玩法全解.md](创作者社区功能与玩法全解.md) · [发布作品与连载要点.md](发布作品与连载要点.md)

## 一、安卓端安装四步

inner 的安卓端安装包是 .apk 格式，安装入口放在 [inner app 介绍站](https://inner-app.bmww.store/)的下载页里（首页底部与下载页都有获取按钮）。拿到安装包后：

1. **转存**：打开获取入口，把安装包转存到自己的网盘账号下；
2. **下载**：手机网盘里点这个 .apk 下载，下完核对一眼文件大小是否正常；
3. **放行未知来源**：首次安装时系统提示「禁止安装未知应用」，到系统设置里允许当前浏览器或文件管理器安装，再返回重新点开安装包；
4. **安装并打开**：确认应用名与图标后点安装，完成后桌面出现 inner 图标。

装完首次打开先随便滑两页，确认图片能正常加载——加载不出来多数是网络问题：Wi-Fi 与流量互切、关掉系统的省流量模式、关 VPN，再不行清缓存重开。

## 二、注册要填什么

注册与登录需要四项基本信息：

| 必填项 | 用途 |
| --- | --- |
| 手机号码 | 收验证码 |
| 验证码 | 短信校验 |
| 密码 | 注册时自行创建 |
| 昵称 | 展示用 |

头像、出生年月、个性签名是可选补充项，不填不影响基本功能，可以先跳过。日常浏览与发布都用不到身份证件——只有申请「账号认证 / 账号找回」时才需要实名信息，政策原文也提醒这类敏感信息要谨慎提供。

## 三、注销账号在哪

想退出时，注销入口在应用内：

```
【我的】→ 右上角【…】→【设置】→【账号管理】→ 账号注销
```

注销前想清楚两件事：发过的作品与专辑是否还要保留（注销后账号不可再登录找回）、有没有绑定记录需要先处理。

- 两个都读完了，直接去 [inner app 介绍站](https://inner-app.bmww.store/)把安装包拿到手。
