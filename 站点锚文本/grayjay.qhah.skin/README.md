# Grayjay 介绍站（grayjay.qhah.skin）

这里是 Grayjay 介绍站的文档目录。Grayjay 是 FUTO 推出的安卓视频聚合播放器：用插件把 YouTube、BiliBili、Twitch、Patreon 等平台接进同一个应用，所有订阅汇成一条按时间排序的通用信息流，数据存在手机本地。站点从第三方视角整理了它的功能、插件生态与上手路径，安装文件资源的入口也集中在站点里。

- 站点地址：[Grayjay 聚合播放器介绍站](https://grayjay.qhah.skin/)
