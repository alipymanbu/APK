# 从NewPipe迁移订阅的方法

> 两个都是「不装平台客户端也能看视频」的安卓应用，经常被放在一起比较。本篇摆一摆两边差异，再把 NewPipe 的订阅搬到 Grayjay 的完整步骤走一遍。
> **相关文档**：[多平台订阅汇成一条信息流.md](多平台订阅汇成一条信息流.md) · [插件视频源怎么加.md](插件视频源怎么加.md) · [安卓版下载安装与更新.md](安卓版下载安装与更新.md)

## 一、先分清两边定位

| 维度 | Grayjay | NewPipe |
| --- | --- | --- |
| 平台范围 | 插件制：YouTube、BiliBili（CN）、Twitch、Patreon、Nebula 等十多个源可选 | 内置 YouTube、PeerTube、SoundCloud 等少数平台 |
| 账号登录 | 支持，登录后有个性化推荐、可看已付费的会员内容 | 不支持登录，一切数据本地化 |
| 订阅管理 | 多平台订阅汇成一条通用信息流，存手机本地 | 单平台订阅，存手机本地 |
| 设备间迁移 | 备份文件整包搬 + 局域网设备同步 | 手动备份与恢复 |
| 安装包体积 | 一百六十多兆 | 小得多 |

怎么选，看使用方式：

- 只看 YouTube、SoundCloud 这几个站，想要轻量 → NewPipe 就够；
- 订阅分散在多个平台（比如 YouTube 加 Twitch 加 BiliBili），想一条信息流刷完 → Grayjay 的聚合就是为这个场景；
- 要登录账号看 Patreon / Nebula 已付费内容、要 B 站高画质 → 只有 Grayjay 能做；
- 在意开源许可、只接受 OSI 认证 → NewPipe（Grayjay 源码公开但用的是 FUTO 自有许可）。

两边不互斥，常见做法是先装着 Grayjay 过渡，订阅搬过去用一阵再决定去留。

## 二、订阅搬家：两条路

**路子 A：从 NewPipe 导出 JSON（不登录平台账号也能搬）**

1. 在 NewPipe 里把订阅导出成 JSON 文件；
2. 用手机文件浏览器打开这个 JSON（系统自带或第三方都行）；
3. 选择用 Grayjay 处理，订阅名单就进来了。

**路子 B：登录平台账号直接导入**

1. 到 Grayjay 的「来源（Sources）」页点开对应平台；
2. 登录账号；
3. 登录后出现「Import Subscriptions」按钮（该插件支持才有），点它把订阅搬进来；播放列表同理，入口是「Import Playlists」。

## 三、过渡期注意两件事

- 两个应用可以并存，确认订阅和列表都搬全了再卸旧的；
- 搬完后按平台逐个核对一遍：个别平台的插件对订阅导入支持有限，缺的部分用路子 B 补齐。
