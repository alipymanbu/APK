# 插件视频源怎么加

> Grayjay 装完打开首页是空的——它不托管任何视频，内容全靠「源」：各平台的插件。本篇讲插件从哪来、怎么装、成熟度标记怎么看，以及个别源失效时怎么处理。

## 一、插件目录里有什么

插件集中收录在 plugins.grayjay.app，由社区维护、持续新增。截至 2026 年下半年，目录里收录的主要有：

| 类别 | 插件 |
| --- | --- |
| 主流视频 | YouTube、BiliBili（CN）、Dailymotion（Beta）、BitChute（Beta） |
| 直播 | Twitch（Beta）、Kick（Beta），直播与聊天都支持 |
| 去中心化 | Rumble、Odysee、PeerTube |
| 音频 | SoundCloud、Mixcloud（Alpha）、Apple Podcasts、Radio Browser（Alpha） |
| 会员制 | Patreon、Nebula（登录后免费与付费内容并排可见） |
| 纪录片与讲座 | TED Talks（Alpha）、Curiosity Stream（Alpha）、NASA+、FOSDEM（Alpha）、Internet Archive（Alpha） |

BiliBili（CN）插件登录后才能用更高画质、字幕与会员内容；想接入某个特定的 PeerTube 实例，要到插件宿主页填实例地址单独装。

## 二、两种装法

1. **扫码**：在应用的「来源（Sources）」页用内置扫码器，扫插件页上的二维码；
2. **点链接**：用手机浏览器打开插件页，点「Open in Grayjay」，跳回应用完成安装。

装好的插件在「来源」页统一管理：顶部的为主要来源，不用的随手禁用，插件有新版时页面会提示更新（Update available）。

## 三、成熟度标记与失效处理

插件页上的标记是成熟度口径：

- **无标注**：最稳；
- **Beta**：次之，功能可能不全；
- **Alpha**：最早期，缺功能或失效的概率也最高。

个别源质量参差、平台一改版就短期失效，是插件制应用的常态。遇到某个源出问题，先看「来源」页有没有插件更新，更新一轮再试；还不行就换同类源顶上，或在对应渠道反馈。订阅与历史数据存在手机本地，换源、禁用源都不会动它们。
