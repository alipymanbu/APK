# 手机怎么遥控电脑上的快捷面板

> 人不在键盘前，电脑还在放片子、跑演示、等一条指令——这篇讲怎么用手机把电脑上那块快捷面板"拿"到手里，以及这套玩法需要提前备齐什么。
> **相关文档**：[安卓版安装与悬浮窗权限设置.md](安卓版安装与悬浮窗权限设置.md) · [手机扫码配对连不上电脑怎么办.md](手机扫码配对连不上电脑怎么办.md)

---

## 一、先认清这套组合的分工

Quicker 的主体装在 Windows 电脑上：鼠标中键呼出快捷面板，按钮点下去执行对应动作。而手机上装的那个安卓应用只干一件事——把这块面板以悬浮形式常驻在手机屏幕上，你点手机按钮，动作在电脑上执行。

分工很明确：电脑端负责"配面板"，手机端负责"隔着几米点按钮"。手机端自己不产生新功能，电脑端没配的动作，手机上也变不出来。

所以判断这套玩法对你有没有意义，先过两个前提：

| 前提 | 自查方法 |
| --- | --- |
| 电脑上已经在用 Quicker，且面板里配了常用动作 | 任务栏有它的图标，中键呼出能看到自己的按钮 |
| 有"人离开键盘、操作还得跟上"的时刻 | 开会讲解、窝在沙发上看片、录入手忙不过来 |

两个前提都不占，手机应用装上只会是一块连不上任何东西的空面板。

## 二、备齐四个条件再配对

| 条件 | 细节 |
| --- | --- |
| 同一个局域网 | 手机和电脑连同一个 Wi-Fi；连接全程在局域网内完成，不走外网服务器 |
| 电脑端正在运行 | 电脑端没开，手机端没有可连的对象 |
| 电脑端开启 APP 连接 | 默认关闭，进设置窗口的「手机APP / WebSocket 设置」页启用 |
| 端口与验证码 | 端口默认 666，验证码用于防止连错同一网络里的其他电脑 |

## 三、配对就三步

1. 电脑端点面板头像，菜单里选「连接手机APP」，弹出二维码窗口。电脑有多个网卡时，选与手机同网段的那个 IP（一般是 192.168 开头、前三段与手机 IP 一致）。
2. 手机打开应用，扫码对准二维码；二维码不好对焦就在手机端手动填三项——电脑局域网 IP、端口、验证码，填完点连接。
3. 提示连接成功，面板出现在手机屏幕上并常驻，之后点按即触发。

电脑端还没装的话，从[安卓版安装与悬浮窗权限设置.md](安卓版安装与悬浮窗权限设置.md)把两端的包都备齐；配对这步卡住，直接翻[手机扫码配对连不上电脑怎么办.md](手机扫码配对连不上电脑怎么办.md)。

## 四、遥控真正顺手的几个时刻

- **讲台另一头**：电脑接着投影，人站远了，手机点按钮翻页、触发讲解动作，不用每次跑回键盘前。
- **沙发上**：电脑在放音乐或视频，手机面板做暂停、切换这类轻操作。
- **录入间隙**：一只手在键盘打字，另一只手拿手机点辅助动作，把高频操作分摊出去。

手机端的能力上限就是电脑端的面板配置——想让遥控顺手，功夫在电脑端的按钮编排上。想先整体了解这个安卓应用是什么、能干什么，可以看这篇 [Quicker 安卓端介绍](https://quicker.rggd.pw/)，配对步骤和适用场景都整理在同一个站里。
