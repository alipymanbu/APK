# 手机扫码配对连不上电脑怎么办

> 二维码扫上了、转圈半天没反应，或者直接报连接超时——按这篇的顺序查，绝大多数失败出在网络互通和 Windows 防火墙这两处。

## 一、先看报错长什么样

| 现象 | 大概率原因 | 对应章节 |
| --- | --- | --- |
| 提示 Connection timed out / 连接超时 | 网络不通或防火墙拦端口 | 二、三 |
| 扫码后提示连上但面板是空的 | 电脑端 APP 连接没真正启用 | 二 |
| 手动填 IP 连不上 | IP 填错网段或端口对不上 | 四 |
| 连上用一会儿就失灵 | 兼容性问题，见第五节说明 | 五 |

## 二、四个条件逐项过

配对能成立只有四个前提，缺一个都连不上：

1. **同一局域网**：手机和电脑连同一个路由器；电脑插网线时，网线也得接在同一台路由器下。部分 Wi-Fi 会开启"设备互联隔离"，这类网络里两台设备互相看不见，换网络或进路由器设置打开互联。
2. **电脑端在运行**：任务栏里有 Quicker 图标。
3. **APP 连接已启用**：电脑端设置窗口 →「手机APP / WebSocket 设置」页，服务开关处于启用状态。
4. **防火墙放行监听端口**：默认 666，这是连不上的头号嫌疑，下一节单独讲。

## 三、Windows 防火墙：最常见的拦路虎

电脑端第一次开启 APP 连接时，Windows 防火墙通常会弹询问框，当时点了"取消"的话，手机就连不进去。处理：

1. 打开 Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙；
2. 在列表里找到 Quicker，确认"专用"网络一列已勾选；
3. 列表里没有就手动新建入站规则，放行 TCP 666 端口（或电脑端设置里改过的那个端口）；
4. 改完在手机上重新连接。

## 四、手动填参数时的三个对法

扫码总失败（摄像头对焦、屏幕反光都会导致）就改手填，三项都要对得上：

- **IP**：电脑上 `Win + R` → 输 `cmd` 回车 → 输 `ipconfig`，找"IPv4 地址"那一行；电脑有多个网卡时，要填与手机同网段的那个（前三段与手机 IP 一致，如手机是 192.168.31.x，就填 192.168.31 开头的那个）。
- **端口**：与电脑端设置页显示的一致，默认 666，改过就填新值。
- **验证码**：与电脑端设置页一致。它的存在就是防止连错同一网络里的其他电脑，别按记忆填。

填完点连接还超时，回到第二节把四个条件再过一遍，重点查防火墙。

## 五、能连上但反复失灵的情况

有一种问题不在这篇的解决范围里：连上之后用一阵子失灵、面板点不动。这与手机端的维护现状有关——作者 2025 年 9 月在项目讨论区说明手机应用已停止维护，源代码开放在 GitHub，这类兼容性问题不会再有新的修复版本，重开应用重连是最现实的处理方式。

如果你还在评估要不要装，可以先看 [Quicker 安卓遥控面板介绍](https://quicker.rggd.pw/)这个整理站，把现状与边界看完再决定；配对流程本身在[手机怎么遥控电脑上的快捷面板.md](手机怎么遥控电脑上的快捷面板.md)里，安装环节的问题在[安卓版安装与悬浮窗权限设置.md](安卓版安装与悬浮窗权限设置.md)。
