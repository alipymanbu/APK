# 安卓版安装与悬浮窗权限设置

> 这篇只讲两件事：安装包从哪来、装的过程中哪两个权限必须放行。装完连不上电脑的，直接看文末指的排查篇。
> **相关文档**：[手机怎么遥控电脑上的快捷面板.md](手机怎么遥控电脑上的快捷面板.md) · [手机扫码配对连不上电脑怎么办.md](手机扫码配对连不上电脑怎么办.md)

---

## 一、装之前核对三件事

1. **系统版本**：安卓 7.0 及以上，更老的系统不保证能用。
2. **它不是独立工具**：这个应用是电脑快捷面板的手机遥控器，电脑端没装 Quicker 的话，装它没有意义，先去把电脑端装好。
3. **没有 iOS 版**：项目文档口径是长期内都不会有，苹果设备不用找了。

## 二、安装包从哪来

安卓客户端的源代码开放在 GitHub 上，发布渠道也就两条路：

- 网盘分享渠道：适合访问 GitHub 不顺畅的网络环境，转存到自己网盘后下载 APK。整理好的获取入口与安装步骤看这篇 [Quicker 手机版下载安装](https://quicker.rggd.pw/)，按页面指引走即可。
- 仓库发布页：在 GitHub 搜该安卓客户端的仓库，从 Releases 页取安装包。

两条路拿到的都是同一份应用的安装文件资源，选顺手的就行。安装包体积不大，35 MB 上下，具体以当时拿到的文件为准。

## 三、安装四步

| 步骤 | 操作 | 注意 |
| --- | --- | --- |
| 1 | 转存并下载 APK | 先转存到自己网盘再下载，比直接下稳；文件名以 .apk 结尾 |
| 2 | 点开 APK 安装 | 弹「不允许安装未知来源应用」时，按引导允许来自当前来源的安装 |
| 3 | 打开应用 | 各品牌"允许安装未知应用"的入口措辞略有差异，多在应用详情或安全设置里 |
| 4 | 装完先别急着用 | 面板此刻还是空的，要先连上电脑端（见配对篇） |

## 四、悬浮窗权限，最容易被拦的一道

配对面板要以悬浮形式常驻在手机屏幕上，这依赖「显示悬浮窗 / 显示在其他应用上层」权限。装完面板弹不出来、按钮不常驻，第一反应就查这里：

1. 系统设置 → 应用管理 → 找到该应用；
2. 进入权限页，放行「显示在其他应用上层」；
3. 回到应用重新连接电脑端，面板应能常驻显示。

## 五、语音输入的引擎选择

应用内置语音转文字输入能力，装「讯飞语记」作为语音引擎后可用。若引擎选错，到系统设置 → 应用程序管理里执行「重置应用偏好设置」再重选——注意这个操作会重置所有应用的偏好，不只是这一个。
