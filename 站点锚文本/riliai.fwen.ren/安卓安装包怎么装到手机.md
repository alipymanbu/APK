# RiliAI 安卓安装包怎么装到手机

> 本篇讲怎么把 RiliAI 的安卓安装包装进手机：从安装包资源入口、下载，到允许未知来源、完成安装与首次打开。
> **相关文档**：[游客模式能玩什么](游客模式能玩什么.md) · [怎么切换AI模型](怎么切换AI模型.md) · [积分获取与奖励规则](积分获取与奖励规则.md)

## 一、装机前的三件小事

1. **确认机型**：RiliAI 目前主流渠道只有安卓版，建议系统 Android 5.2 及以上；iPhone 用户在常见渠道拿不到可用入口。
2. **清出空间**：安装包约 177 MB，解包安装后占用更大，建议预留 2 GB 存储。
3. **认准资源入口**：安装包经夸克网盘分发，转存到自己网盘后下载，安装前不用做任何校验步骤。

[RiliAI 玩法站](https://riliai.fwen.ren/)整理了完整的下载与安装步骤，配套的安装文件资源入口也在那里。

## 二、安装四步

1. 打开资源分享页，登录夸克账号，把资源转存到自己的网盘；
2. 在夸克网盘 App 里把安装包下载到手机存储（建议 Wi-Fi 环境）；
3. 在文件管理里点开 APK 安装；系统若提示「禁止安装未知来源应用」，按弹窗指引允许本次安装即可，不同品牌的入口名称略有差异；
4. 装完打开，首次启动会加载资源，等进度走完（可按提示跳过）就能进首页。

## 三、装不上时的排查

| 现象 | 处理 |
| --- | --- |
| 解析包失败 | 多为下载不完整，回网盘重新下载一遍再装 |
| 安装被拦 / 卡住 | 安全软件弹窗选「允许本次安装」；关掉后台大应用再试 |
| 打开闪退 | 确认系统版本达标后重启手机；仍闪退多半是存储不足 |

装好之后先别急着注册：游客身份就能试聊基础对话，试完再决定要不要建账号，见 [游客模式能玩什么](游客模式能玩什么.md)。
