# RiliAI 游客模式能玩什么

> 本篇讲 RiliAI 游客模式与注册账号的能力差别：哪些功能游客直接能用、哪些要注册后才解锁，以及先试后注册的顺序怎么走最省事。
> **相关文档**：[安卓安装包怎么装到手机](安卓安装包怎么装到手机.md) · [怎么切换AI模型](怎么切换AI模型.md) · [模组与世界书入门](模组与世界书入门.md)

## 一、能力对照

应用把这两者的差别直接写在了注册弹窗里：游客试用仅支持基础流式聊天，注册后即可使用模型、设置、模组和上传功能。落到具体功能上：

| 功能 | 游客 | 注册后 |
| --- | --- | --- |
| 基础流式聊天 | 可以 | 可以 |
| 切换 / 自定义模型 | 不可以 | 可以 |
| 对话与界面设置 | 不可以 | 可以 |
| 模组、世界书 | 不可以 | 可以 |
| 上传（发图片等） | 不可以 | 可以 |

## 二、游客阶段建议这么玩

1. **从排行榜挑角色**：首页卡片流顶部有每日 / 每周 / 每月切换，热度榜是最省事的起点；
2. **看评价再开聊**：卡片列表直接展示热度与详情信息，点进卡片还有评论区与评分，先扫一眼再决定；
3. **试对话手感**：回复是逐段流式输出的，输入框会显示字数，聊几轮就能感受它记不记得住上文；
4. **留意标记**：部分卡片带 NSFW 标记表示内容偏成人向，介意的话避开即可。

想动手试试的朋友，[RiliAI 玩法站](https://riliai.fwen.ren/)上有安装文件资源的获取入口和更完整的玩法说明。

## 三、什么时候值得注册

想认真玩剧情、调设定，注册基本绕不开：换模型、开世界书、用模组、发图片都挂在注册之后。注册入口在左侧功能栏最底部的账号位置，第一次用点「立即注册」按提示填完资料即可。

注册后涉及的积分与奖励规则单独成篇，见 [积分获取与奖励规则](积分获取与奖励规则.md)；想自己搭剧情的，先看 [模组与世界书入门](模组与世界书入门.md)。
