# UniFans 创作者分成与提现规则

> 创作者最关心的数字都在这里：分成比例、处理期、提现节奏、渠道与大陆银联入账的硬性条件。
> **相关文章**：[平台核心玩法与适用人群.md](平台核心玩法与适用人群.md) · [引力币充值与订阅支付详解.md](引力币充值与订阅支付详解.md)

## 一、能拿到多少

引力圈（UniFans）的平台费按发布内容的类别**起步 5%**，内容跨多个类别时按最高的那档费率计算。也就是说创作者最高可获得 **95% 的赞助收入**，费率结构在同类订阅平台里属于对创作者相当友好的一档。粉丝订阅付款的那一刻平台费就扣掉了，剩余部分进入待结算金额。

成为创作者的前提是注册账号并在主页提交「创作主页设置」，注册与开店本身不收费，流程参考 [平台核心玩法与适用人群.md](平台核心玩法与适用人群.md)。

## 二、钱什么时候能提

| 环节 | 规则 |
| --- | --- |
| 新订阅收入处理期 | 7 天，期满自动进入可提现总额 |
| 提现频率 | 每 7 天可提交一次 |
| 单次金额区间 | 30 ~ 2,200 美元 |
| 到账时长 | 3 ~ 7 个工作日 |
| 提现信息修改 | 每 7 天可改一次 |

入口路径：创作中心 → 工作台 → 提现。可提现余额以美元显示，支持美元与人民币两种提现币种，各自填写对应收款信息。

## 三、提现渠道与费用

渠道覆盖 **PayPal、Wise、USDT 稳定币**，中国大陆创作者支持**银联卡人民币入账**（走银联全球速汇）。平台在提现环节不另收手续费，第三方支付服务商或银行侧产生的费用视账户类型、地区与金额而定；汇率方面 Wise 按中间价计算，想估算到账金额可用其货币换算工具先试算。

## 四、银联入账的硬性条件

大陆创作者走银联卡，逐条核对再提交，改信息要再等一个 7 天周期：

1. 第三方支付账户、收款银行卡、创作者认证三处**姓名必须完全一致**，提交后不可改；
2. 只收**借记卡**，不收信用卡；只汇**个人账户**，不对公；
3. 收款人须持中华人民共和国居民身份证开户；
4. 招商、民生、兴业、浦发、南京这几家银行不接收境外汇款，换别的银行卡收款；
5. 银联提现占用每年 5 万美元的结售汇便利化额度，单笔低于 5,000 美元默认免申报。

## 五、提现失败先查什么

- 姓名不一致、卡种不对、银行在不收汇名单里——这三种直接失败，先改信息等下个周期；
- 提交后过了 3~7 个工作日仍无通知，带提现单据找平台内客服；
- 账号本身登不上、被锁的处理，与充值侧的注意事项互相关联：粉丝付不出钱多半出在购币环节（见 [引力币充值与订阅支付详解.md](引力币充值与订阅支付详解.md)）。
