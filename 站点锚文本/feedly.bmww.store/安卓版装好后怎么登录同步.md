# Feedly 安卓版装好后怎么登录同步

> 本篇讲 Feedly 的账号机制：为什么必须登录、注册与登录方式怎么选、多端同步怎么工作，以及「订阅列表空了」这类问题的排查顺序。
> **相关文档**：[RSS 时间线阅读怎么上手](RSS时间线阅读怎么上手.md) · [免费版够用吗](免费版够用吗.md)

## 一、没有账号，应用里什么都做不了

Feedly 不是本地阅读器：订阅列表、已读状态、Board 全部存在 Feedly 服务端，跟着账号走。所以装完打开应用，第一屏就是注册或登录，跳不过去。应用内可以直接注册，也可以先在电脑网页版注册，手机端再用同一账号登录。

## 二、一个最容易踩的坑：登错账号

**用不同方式注册会生成两个互不相通的账号。** 在手机上用邮箱注册、在电脑上误用了另一种方式登录，会看到「订阅全没了」的假象——其实只是登进了另一个空账号。确认两台设备的登录方式完全一致，列表就回来了。

## 三、多端同步怎么工作

| 场景 | 行为 |
| --- | --- |
| 手机读了几篇 | 已读状态同步到服务端，网页版打开不再显示 |
| 电脑上加了新订阅源 | 手机的订阅列表自动多出这一条 |
| 换新手机 / 重装应用 | 登录同一账号，订阅与未读状态整体回来 |

同步在联网时进行。读到一半要切设备时，把文章存进 Board 或稍后读，另一端登录同一账号就能看到。

## 四、登录不上按这个顺序查

1. **网络可用性**：订阅与已读全在服务端，断网时登录环节必然卡住。
2. **登录方式是否与注册时一致**：见第二节的坑，现象和「密码错误」很像。
3. **应用版本太旧**：产品持续发小版本修复，异常持续可核对应用商店里的最新版本。
