# Feedly 免费版够用吗

> 本篇讲 Feedly 三个个人档位（Free / Pro / Pro+）各自的上限与差异，以及出现哪些信号说明免费档开始碍事、该考虑升级。
> **相关文档**：[RSS 时间线阅读怎么上手](RSS时间线阅读怎么上手.md) · [安卓版装好后怎么登录同步](安卓版装好后怎么登录同步.md)

## 一、三个档位一张表

Feedly 个人版分 Free、Pro、Pro+ 三档，价格与上限会随调整变动，下表是 2026 年多家第三方评测汇总的口径，以定价页当时显示为准：

| 项目 | Free | Pro | Pro+ |
| --- | --- | --- | --- |
| 价格（月付） | 0 | 约 $6.99/月 | 约 $12.99/月 |
| 内容源上限 | 100 | 1,000 | 更高（有来源写 2,500） |
| 文件夹数 | 3 | 更多 | 更多 |
| 站内搜索（找回读过的文章） | 无 | 有 | 有 |
| 笔记与高亮 | 无 | 有 | 有 |
| AI 助手 Leo | 无 | 无 | 有 |
| 静音过滤（屏蔽不想看的词/源） | 无 | 无 | 有 |

三个档位用同一份安装包装出来，差别只在登录后的账号档位；安卓安装包的获取入口与安装步骤，见 [Feedly 安卓版介绍站](https://feedly.bmww.store/)。

## 二、免费档够用的场景

- 订阅来源在 100 个以内、读完即走、不需要回头搜旧文章。
- 文件夹只有 3 个：按「必读 / 偶尔看 / 消遣」这种粗分法用，比按主题细分实用得多。
- 能接受内容流里夹杂的赞助条目（付费档没有）。

## 三、三个信号说明该升级了

1. **删源换源成了常规动作**——为了凑 100 以内的名额，开始删掉其实还想留的源。
2. **想找回一篇读过的文章找不着**——站内搜索是 Pro 起步的功能，免费档只能翻历史或自己存 Board。
3. **想在文章上写笔记、划重点**——同样是 Pro 起步。

## 四、Pro 与 Pro+ 之间怎么选

核心差别是一件事：**AI 助手 Leo 只在 Pro+**。Leo 按你指定的主题、公司、关键词把相关文章顶到前面、把重复报道合并成一条、给长文写摘要，还支持静音过滤。每天阅读量在「扫标题」级别，Pro 够用；要从大量来源里做信息筛选、靠它跟进行业动态，多花的钱买的就是 Leo 这一层。

升级与否都不影响已订阅的内容：订阅列表跟着账号走，升档即解锁，降档后超出上限的源不会被删，只是不能再添加新的。
