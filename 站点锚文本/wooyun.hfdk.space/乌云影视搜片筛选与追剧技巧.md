乌云影视的片池按频道铺开：电影、电视剧、综艺、动漫、短剧各管一摊。找片走两条路——想好了名字直接搜，没想好看什么就去分类里翻。

## 一、搜索怎么搜不空手

1. 点顶部搜索框，输片名、演员名或关键词。
2. 在结果列表里找到目标影片，进详情页。
3. 同一部片常有多个播放源，选一条进播放页。
4. 剧集在播放页用「选集」切换集数。

搜不到时按这个顺序换姿势：换关键词（别名、主演名、片名里最有辨识度的几个字）→ 去分类里翻（搜索对冷门片经常漏，筛选反而能撞到）→ 过几天再搜（片池随时间变动，这次没有不代表下次没有）。

## 二、三档筛选的组合用法

筛选挂类型、地区、年份三档，可以叠加：

| 你想找 | 怎么筛 |
| --- | --- |
| 最近上线的剧 | 电视剧频道 + 年份选最近一档 |
| 老电影 | 电影频道 + 年份往早了调 |
| 某地综艺 | 综艺频道 + 地区选对应档位 |
| 下饭短剧 | 短剧频道按专题翻 |

综艺频道还有个彩蛋：常驻嘉宾的名字直接挂在签上，点一下就是整个片单，追某位演员的综艺特别好用。

## 三、收藏与历史配合追剧

- **收藏**：播放详情页里点收藏，想追的片子集中放，更新了从收藏夹进。
- **观看历史**：进度自动记录，中途退出再进能接着上次的位置继续，不用手动拖进度条。
