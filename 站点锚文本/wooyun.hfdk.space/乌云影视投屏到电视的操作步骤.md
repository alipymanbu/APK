# 乌云影视投屏到电视的操作步骤

> 讲乌云影视（wooyun）怎么把正在播的片子投到电视上，以及搜不到设备时先查哪几处。
> **相关文档**：[乌云影视下载安装与侧装注意事项.md](乌云影视下载安装与侧装注意事项.md) · [乌云影视搜片筛选与追剧技巧.md](乌云影视搜片筛选与追剧技巧.md)

手机屏幕看剧费眼，客厅电视才是正位。乌云影视自带投屏能力，播放页里呼出控制条就能找设备，前提只有一个：手机和电视得在同一个局域网里。

## 一、投屏前两个前提

1. **同一个 Wi-Fi**：手机用流量、电视用宽带是最常见的翻车组合；手机开热点给电视连也经常搜不到设备。
2. **电视端开着接收能力**：智能电视或盒子保持开机联网，个别电视要在设置里打开 DLNA 或「多屏互动」开关，各家叫法不同，翻一下自家电视的设置。

## 二、投屏操作

1. 找到想看的片，进入播放详情页开始播放。
2. 点一下屏幕呼出控制条，找投屏图标（一般是台电视机模样）。
3. 等设备列表刷出来，选中自家电视的名字。
4. 连上后画面切到电视，手机变成遥控器，熄屏也能继续放。

## 三、搜不到设备逐项查

| 检查点 | 说明 |
| --- | --- |
| 是否同一 Wi-Fi | 按上面第一条再核一遍，这是最高频原因 |
| 路由器 AP 隔离 | 开了之后同一网络下的设备互相不可见，进路由器后台关掉 |
| 双频路由器 | 2.4G 与 5G 频段可能隔离，让手机和电视连同一个频段 |
| 电视端服务没开 | DLNA / 多屏互动开关没打开，或盒子在休眠 |
| 应用版本太旧 | 覆盖装个新版再试，旧版对设备发现的支持可能有问题 |

以上都查过还不行，把手机和电视都重启一遍再试——设备发现卡死是个常见小毛病。投屏对网络要求比手机上看更高，卡顿时把清晰度降一档通常立竿见影。还没装应用的，先看 [乌云影视下载安装与侧装注意事项.md](乌云影视下载安装与侧装注意事项.md)；装好后入口在 [wooyun 放映室](https://wooyun.hfdk.space/) 有整理，搜片姿势见 [乌云影视搜片筛选与追剧技巧.md](乌云影视搜片筛选与追剧技巧.md)。
