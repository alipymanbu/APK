# 唱歌修音五大基础效果怎么用：听感、场景与踩坑

> 不订阅也一直能用的五个基础效果，是大多数人和修音应用的第一次接触。本篇按听感逐个讲它们适合什么唱法、什么时候该换，以及两个最容易踩的坑。

## 一、先分清修音和声码器

打开效果列表，五件套里其实只有两种本质不同的东西：

- **修音（Hard Tune、Natural Tune）**：检测你唱出的音高，拉回当前调式里最近的音。差别在动作幅度——Hard Tune 是"听得出来的修音"，电子感明显；Natural Tune 动作轻，追求"修了但听不出修了"。
- **声码器（Super Vocoder）**：把人声特征喂给合成器音色，出来的是机器人声，已经不在乎你唱得准不准了。

剩下两个是辅助位：Big Chorus 按调式复制多声部做合唱，Clean 不加工只滤波降噪。

## 二、按唱法对号入座

| 你在唱什么 | 建议起点 |
| --- | --- |
| 说唱、陷阱 | Hard Tune，重拍段落电子感立得住 |
| 流行、R&B、抒情 | Natural Tune，圆润不机械 |
| 电子、创意段落 | Super Vocoder，一句点睛就够 |
| 副歌要大场面 | Big Chorus，一轨铺出合唱 |
| 环境吵 / 只想收干声 | Clean，配安静环境更好 |

拿不准就录 30 秒同一句，五预设挨个过一遍——效果随时能换，录完的作品也可以在编辑视图里对选中的段落单独换预设做 A/B，不用重录。

## 三、修音跑调的两个真凶

1. **调式没对上**：修音效果跟着项目的调式设置走，换了伴奏没换设置，声音就会"跑到别的调上"。先去工程的调性设置里核对，多数"修音很怪"的问题到这里就解决了；
2. **对 Clean 期望过高**：Clean 只是滤波降噪，不隔音——麦克风收进来的底噪和漏进来的伴奏它救不干净，安静环境和插耳机比任何预设都管用。

## 四、五件套之外的进阶路线

免费预设用顺了，订阅的主题包按风格继续细分：说唱、爵士、Talkbox、8-bit、异星声码器各有成包的预设；压缩、均衡、回声、混响四个通道条工具也各有即用预设，想把人声做得更"成品"就从这里下手。参数级的自定义和保存个人预设属于订阅能力，先在免费预设里确认自己喜欢的方向再考虑。
