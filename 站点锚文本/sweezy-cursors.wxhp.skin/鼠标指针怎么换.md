# 鼠标指针怎么换：浏览器、Windows 桌面与 Roblox 三条路线

> 同一座光标库，三种换法各走各的文件格式：浏览器里点一下就换，桌面要指文件，Roblox 替换两张图片。这篇把三条路线一次讲清。

Sweezy Cursors 的光标库按用途拆成三条用法线，动手前先分清要换哪一层：只换网页里的指针，走浏览器扩展；想连桌面、文件夹窗口一起换，走 Windows 系统指针；玩 Roblox 想换游戏里的箭头，走单独的 PNG 替换。三条线互不冲突，都做好就是「网页、桌面、游戏」全套风格统一。

## 一、浏览器扩展路线（最常用）

1. 在 Chrome 网上应用店或 Edge 加载项里获取 Sweezy Cursors 扩展（Brave、Opera、Vivaldi 等 Chromium 内核浏览器走 Chrome 商店入口）；
2. 确认安装后，点浏览器右上角拼图图标，把扩展固定到工具栏；
3. 点扩展图标打开光标面板，在对应分类里点选一个光标，网页指针立即切换；
4. 面板里还能调光标大小，用开/关开关随时切回默认指针。

在光标站浏览时，卡片上的「Add Cursor」按钮会把该光标存进扩展库，之后在面板对应分类里就能找到；添加前可以先看预览。装完没反应的情况多半是页面没刷新，排查思路见[光标不生效的排查与自制方法](光标不生效的排查与自制方法.md)。

## 二、Windows 系统指针路线

扩展只管浏览器窗口，桌面和本地软件要靠系统指针文件：

1. 在光标详情页下载 `.cur`（静态）或 `.ani`（动态）文件，放进固定目录——建议在「文档」下建一个专门的文件夹，Windows 可能因源文件被挪动而丢失自定义指针；
2. 打开「设置 → 鼠标 → 其他鼠标设置」（Windows 11 在「蓝牙和其他设备 → 鼠标」里），切到「指针」选项卡；
3. 先换「正常选择」（主箭头）与「链接选择」（手型）这两个角色，就能覆盖绝大多数场景，需要的话再逐个替换其余角色；
4. 点「应用」立即生效。

想还原时，回到「指针」选项卡把方案换回系统默认即可一次性复原。更多取舍见[动态光标主题盘点](动态光标主题盘点.md)。

## 三、Roblox 光标路线

每个光标的详情页都单独提供 `Roblox Cursor.png` 与 `Roblox Pointer.png` 两张图，尺寸已按 Roblox 要求做好，下载后不需要再裁剪：

1. 右键桌面上的 Roblox 快捷方式，选「打开文件所在位置」，进入 `content\textures\cursors\keyboardmouse` 文件夹；
2. 先把原有的 `ArrowCursor.png` 与 `ArrowFarCursor.png` 改名备份（比如加 `.bak` 后缀）；
3. 把下载的两张图改名为这两个文件名放进去，完全退出 Roblox 再重开即生效。

整个过程只动两张图片，不碰游戏本体；备份的原文件改回原名就能随时还原。

## 四、换回默认的三种情况

- 浏览器里：扩展面板用开关切回，或点选默认光标；
- Windows 里：指针方案选回系统默认；
- Roblox 里：备份的原文件改回原名覆盖回去，重启游戏。

三条路线的获取入口、界面截图与资源说明，见 [Sweezy Cursors 介绍站](https://sweezy-cursors.wxhp.skin/)。
