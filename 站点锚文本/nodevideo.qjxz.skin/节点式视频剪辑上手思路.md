# 节点式视频剪辑上手思路

## 一、它和普通手机剪辑应用差在哪

常见的手机剪辑应用走「时间轴轨道」思路，按轨道铺素材；NodeVideo 走的是桌面合成软件的思路——一切围绕**图层与属性**展开。新加的图层自动叠在所有层之上，天然形成画中画；长按拖动可以改渲染顺序（谁盖住谁）；想加特效、遮罩、变速，都是在图层的属性面板里继续往上叠。

也正因为这套思路，它的强项在「合成」而不是快速出片：只想拼接几段视频的话，更轻量的应用反而更省事；但要做推拉镜头、卡点特效、音乐可视化，它能做到的深度明显不同。

## 二、先认清三块区域

打开工程后，屏幕从上到下分成三块：

| 区域 | 作用 |
| --- | --- |
| 预览窗口 | 实时看画面效果，拖动中间的蓝色条可调整窗口大小 |
| 属性面板 | 显示当前选中图层/参数的可调项，大部分编辑在这里进行 |
| 时间线 | 管理各图层的时间块，剪刀图标把片段一分为二 |

选中根节点（主时间线）时，属性面板会切换成项目设置，帧率、分辨率这类全局参数在这里改。

## 三、上手四步

1. **导入素材**：新建图层 → 媒体文件 → 视频，从相册选一段；拖动预览区里的控件可以直接改位置；
2. **打关键帧**：点参数**名称**（不是数值）展开关键帧栏，移动游标后修改数值，关键帧自动生成；推拉镜头改缩放、淡入淡出改透明度；
3. **曲线调顺滑**：点参数左侧菜单进曲线编辑器，调缓入缓出——线性过渡看着机械，这是做出顺滑感的关键一步；
4. **导出**：左下角导出图标进导出界面，点绿色三角形开始渲染；工程自动存在首页草稿列表，导出中途退出也不丢。

两个新手容易疑惑的点：进入工程后屏幕方向会锁定，是设计行为；预览默认只有 50% 质量，画面偏糊不影响导出成品。

## 四、边学边练的路径

建议拿一段十几秒的素材，把「关键帧 → 曲线 → 导出」整条链路走两遍，再去看慢放与音频驱动这类进阶玩法。完整的功能整理与安装文件资源入口，见 [NodeVideo 介绍站](https://nodevideo.qjxz.skin/)。
