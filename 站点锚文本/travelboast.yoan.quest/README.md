## 几个先说清的事实

- TravelBoast 同时有 iOS 版与安卓版，路线动画的生成逻辑两端一致。
- 手动打点之外，它认 GPX 轨迹文件，也接受从 Google Maps 规划好的路线导入。
- 免费版能完整跑通「做动画、导出视频」，但画面带水印；订阅解锁全部交通工具模型与无水印导出，订阅与单个模型买断在应用商店里是两套并行的付费项，价格以商店当时显示为准。
