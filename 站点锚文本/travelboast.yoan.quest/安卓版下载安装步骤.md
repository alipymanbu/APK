# TravelBoast 安卓版下载安装步骤与拦截处理

> 这篇按「拿到安装包 → 授权 → 装好 → 打开」的顺序写，安卓端每一步会弹什么、卡住怎么处理，一次说清。

## 一、装之前先核对三件事

| 检查项 | 建议线 |
| --- | --- |
| 手机剩余存储 | 留足 1 GB（安装包约 487 MB，解压安装还要占空间） |
| 网络环境 | 安装包体积不小，建议连 Wi-Fi |
| 下载来源 | 走网盘分享页转存后再下，别用聊天工具收到的中转文件 |

图文版的下载入口与每步截图，整理在 [TravelBoast 安卓版下载安装](https://travelboast.yoan.quest/)，需要对着界面操作的可以打开它并排看。

## 二、五步装好

1. **转存分享文件**：从分享页把安装包「保存到我的网盘」，转存到自己名下再下载，完整度更有保障。
2. **下载到手机**：在网盘应用里找到已转存的安装包，选下载到本机，等进度条走完。
3. **允许未知来源安装**：首次从网盘或浏览器安装时系统会拦一道，按弹窗指引进入设置，允许对应来源安装应用。各机型入口多在「设置 → 安全」或「设置 → 应用管理」。
4. **完成安装**：点开下载好的安装包，等安装进度走完选「打开」，桌面出现图标即成功。
5. **跑第一条路线**：进应用选「开始新路线」，钉一个起点一个终点，点播放就能看到第一支动画。

## 三、三种最常见的拦截与处理

- **点安装没反应或被拦**：「未知来源应用安装」没放开。按提示进设置允许；部分机型每次安装都会重新询问，选「仍要安装」。
- **提示解析失败 / 安装包损坏**：基本是下载不完整。把中断过的包删掉，回网盘重新转存、完整下载一遍再装。
- **装完打不开或闪退**：先确认剩余存储与系统版本达标，清理后台重开一次；仍然闪退就重启手机再试。

## 四、装好之后

安装只是第一步，真正出片的关键在路线与座驾的搭配，流程见 [怎么把旅行路线做成地图动画.md](怎么把旅行路线做成地图动画.md)；如果你是徒步或骑行用户，先把已有的轨迹文件用起来更省事，参考 [GPX轨迹导入方法.md](GPX轨迹导入方法.md)。
