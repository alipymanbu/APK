# GPX 轨迹导入 TravelBoast 的三种方式

> 徒步、骑行记录下来的 GPX 文件不用重画——这篇把三条导入路径、各自的适用场景和导入失败的处理写全。

## 一、三条导入路径

### 方式一：文件管理器直接打开

在手机文件管理器里找到 `.gpx` 文件，点开时选择用 TravelBoast 打开。最快的一条路，适合单条轨迹的处理。

### 方式二：从记录 App 的分享菜单转发

徒步或骑行记录应用里一般都有「分享 / 导出」功能，分享目标里选 TravelBoast，整条轨迹原样搬进地图。适合刚跑完一段行程、顺手就做的场景。

### 方式三：应用内文件浏览器

在 TravelBoast 里点「+」新增点，或从主菜单选「开始新路线」；在地点输入页找到用内置文件浏览器选择 GPX 文件的入口，按路径选中即可。适合一次性整理多条历史轨迹的时候。

## 二、三种方式怎么选

| 场景 | 建议路径 |
| --- | --- |
| 文件已经躺在下载目录里 | 方式一 |
| 刚结束一段记录，App 还开着 | 方式二 |
| 要批量翻旧轨迹挑一条 | 方式三 |

## 三、导入之后

轨迹进来的是一条真实走过的线，接下来和手动画的路线一样处理：换交通工具模型、拉视频长度、叠照片，最终导出成片——后半段流程见 [怎么把旅行路线做成地图动画.md](怎么把旅行路线做成地图动画.md)。

对界面位置拿不准的话，[TravelBoast 介绍站](https://travelboast.yoan.quest/) 的路线来源一节配了截图说明，三种导入方式在页面上都有对应入口描述。

## 四、导入失败或轨迹不对的处理

- **分享菜单里找不到 TravelBoast**：先确认应用已装好，缺的就是安装环节，步骤见 [安卓版下载安装步骤.md](安卓版下载安装步骤.md)。
- **导入后路线缺段或变形**：记录时卫星信号中断会出现这种断点，先在原记录 App 里检查轨迹完整性，再重新导一次。
- **文件点开没反应**：确认扩展名是 `.gpx` 而不是改过名的其他格式；个别压缩包里解出来的文件要先解压再导入。
