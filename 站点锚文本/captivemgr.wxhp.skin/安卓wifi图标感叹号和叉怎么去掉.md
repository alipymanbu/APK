# 安卓 WiFi 图标上的感叹号和叉怎么去掉

WiFi 能正常刷视频、聊微信，状态栏上却一直挂着个感叹号或者小叉——不少刷过原生系统、类原生 ROM 的安卓用户都遇到过。这个标记不是网络坏了的提示，绝大多数时候恰恰相反：网是通的，是系统自己判断错了。

## 标记为什么会挂上去

安卓从 5.0 版本起内置了「Captive Portal 检测」：系统在后台向一个固定的探测地址发请求，期待返回 HTTP 204，以此确认设备真的能上网。原生系统默认的探测地址指向谷歌服务器，大陆环境直连不上，探测就一直失败——于是系统在 WiFi 和信号图标下方画上一个叉（安卓 7 起）或感叹号（更早的版本），哪怕你正在正常上网。

要分清的是：信号图标**上方**的叉是安卓 7 加入的移动数据状态提示，跟联网检测无关，去掉它不在这个话题范围内。

## 三种处理路径

- **换探测服务器**：把系统设置里的探测地址换成大陆可达的服务器，比如小米的 `connect.rom.miui.com/generate_204`，探测通了图标自然干净。这是最推荐的路线，不牺牲任何功能。
- **直接关闭检测**：图标立刻不挂了，但在校园网、企业 WiFi 这类要网页登录的网络里，得手动打开一个非 HTTPS 网站触发登录页。
- **改 hosts 指定 IP**：不推荐。IP 需要频繁更换、不稳定，还会干扰谷歌服务的 DNS 智能解析。

手工改可以用 ADB 命令写 settings 参数；不想敲命令的话，CaptiveMgr 这类小工具把这些开关和服务器列表做成了图形界面，root 和 Shizuku 两种授权方式都支持。它把探测原理、三条路径的取舍和实机操作截图整理在 [CaptiveMgr 介绍页](https://captivemgr.wxhp.skin/)，对照着做不容易漏步骤。

## 换完服务器还要做一件事

改完参数记得让系统重新探测一次：工具里的「刷新图标」靠重启 WiFi 和数据网络实现，也可以手动开关一次飞行模式。生效可能有几分钟延迟，一直没变化就重启设备。另外，如果图标过段时间又挂回去，先检查网络本身——那个标记本来就有提示断网的作用，不能全当成误判。
