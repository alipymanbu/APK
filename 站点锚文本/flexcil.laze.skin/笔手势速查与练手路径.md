# Flexcil 笔手势速查与练手路径

> Flexcil 把选字、截取、删除这类动作都做成了笔手势：不用先点工具栏再拖选，笔尖一画就出结果。本篇把手势按用途整理成表，附一条三分钟练手路径和两个常见误区。
> **相关文档**：[同屏笔记玩法一文讲清](同屏笔记玩法一文讲清.md) · [新旧两版怎么选与备份迁移](新旧两版怎么选与备份迁移.md)

## 先分清两种模式

文档阅读器顶部有「阅读」和「笔手势」两个模式：

- **阅读模式**：手指滑动就是翻页、缩放，笔尖划过去不产生批注；
- **笔手势模式**：笔尖（或手指）划出的轨迹被当成指令，用来选字、截取、删除。

手势全部失灵时，第一件事就是看是不是停在阅读模式——这是新手最常撞上的「假故障」。

## 手势对照表

| 想做的事 | 手势画法 | 说明 |
| --- | --- | --- |
| 加高亮 / 下划线 | 在文字上画一条下划线 | 选中后可换高亮色 |
| 选一段文字 | 圈出文字 | 小圈选字，大圈跨行 |
| 选一整段 | 段落两侧画圆括号 | 适合整段摘取 |
| 精确选择 | 长按文字 | 弹出选择菜单 |
| 截取一块内容 | 画 L 形 / 方框 | 文字或图表整块拖进笔记 |
| 删除手写内容 | 在字迹上涂抹划掉 | 也可用橡皮工具 |
| 撤销 / 重做 | 两指左滑 / 右滑 | 不同设备略有差异 |
| 打开弹出式笔记 | 三指上滑 | 边看边记的入口 |

## 选字之后能干什么

- **高亮 / 下划线**：直接给原文加批注；
- **复制到笔记**：拖进浮层，复制内容自动带参考链接，之后能一键跳回原文；
- **词典 / 网页搜索**：读外文文献查词义、搜句子都顺手。

截取的图块同样能拖进笔记，来源链接保留。摘录之后的整条工作流，见 [同屏笔记玩法一文讲清](同屏笔记玩法一文讲清.md)。

## 三分钟练手路径

新装好的话，按这个顺序过一遍就能上手：

1. 打开任意 PDF，确认处于笔手势模式；
2. 用下划线手势划一句话，再两指左滑撤销；
3. 用方框手势截一小段，三指上滑打开笔记浮层，把它拖进去；
4. 点笔记里刚拖进来的内容，确认能跳回 PDF 原文。

四步走完，「划、截、收、回」这条主链路就通了。

## 两个常见误区

- **扫描版 / 图片版 PDF 选不了字**：这类文档没有文字层，下划线、圈选、括号这些选字手势本来就无效，需要先做文字识别；方框、L 形截取不受影响，照常用。
- **圈选画得太小**：手势要有明显的轨迹形态，闭合的圈、清楚的 L 形才被认出来，轻轻一点是不会有反应的。

想直接装一个照着练，从 [Flexcil 介绍站](https://flexcil.laze.skin/) 进安装文件资源入口即可；换设备时怎么把笔记完整带走，见 [新旧两版怎么选与备份迁移](新旧两版怎么选与备份迁移.md)。
