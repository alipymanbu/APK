# lumen5 与同名网页工具的区别

> 搜 lumen5 这个词，结果里常同时出现两款产品：一款安卓手机应用，和一个海外团队的在线网页工具。两者不是同一家出品，功能也不通用。本篇给你一套两分钟就能做完的分辨方法。安卓应用的装法看[下载安装步骤](下载安装步骤.md)，装好后的玩法看[文字图片变成视频的玩法](文字图片变成视频的玩法.md)。

---

名字撞在一起，是搜 lumen5 时最容易踩的坑。一款是本文讲的安卓应用（上架名「lumen5视频制作」，包名 `com.crlyechuhong.spzu`，开发者深圳市顺林祥科技有限公司），装在手机上、界面全中文；另一款是 `lumen5.com` 上的在线视频工具，开浏览器用、界面以英文为主，主打把博客文章批量转成视频。两个账号互不相通，订阅也各算各的。

## 一、两个问题定去留

1. **你打算在哪用？** 手机上随手做条短视频 → 安卓应用；电脑浏览器里批量把长文转视频 → 网页工具；
2. **你手里拿到的是哪个？** 一个 APK 安装包 → 安卓应用；一个要注册账号的网址 → 网页工具。

## 二、对比一览

| 对比项 | 安卓应用 lumen5 | lumen5.com 网页工具 |
| --- | --- | --- |
| 形态 | 手机应用，装完即用 | 浏览器里的在线服务 |
| 出品方 | 深圳市顺林祥科技有限公司 | 海外 Lumen5 团队 |
| 界面语言 | 全中文 | 英文为主 |
| 典型用法 | 文生视频、图生视频、模板剪同款 | 把文章、脚本批量转成视频 |
| 成片去向 | 存进手机相册或应用内作品列表 | 在线导出 |
| 网络 | 生成时联网，成片在本机 | 全程在线 |

网页工具的收费档位与限制会随时间调整，以 `lumen5.com` 页面当时的说明为准；安卓应用的安装文件资源从 [lumen5 视频制作介绍站](https://lumen5.xnyx.quest/)获取，不涉及订阅。

## 三、几个容易混淆的场景

- **在应用商店搜「lumen5」**：两类产品可能一起出现，认包名 `com.crlyechuhong.spzu` 和开发者「深圳市顺林祥科技有限公司」就能锁定安卓应用这一个；
- **搜索引擎混排**：讲网页工具的教程和讲手机应用的教程会混在一起，照做之前先看清讲的是哪一个；
- **别人发你一个安装包**：核对包名与开发者信息，对不上就不要装，获取途径见[下载安装步骤](下载安装步骤.md)。

要在手机上做短视频，走安卓应用这条路；要批量处理长文章，网页工具更对路。两边的玩法细节，见[文字图片变成视频的玩法](文字图片变成视频的玩法.md)。
