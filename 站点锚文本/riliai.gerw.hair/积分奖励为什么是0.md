# RiliAI 积分奖励为什么是0：三类积分的混扣逻辑

对话和生图都要扣积分，而 RiliAI 把积分分成三类、混在一起扣——很多人「奖励怎么是 0」的困惑就出在这。本篇讲清三类的来源、奖励只认哪一段，以及哪些动作会让奖励缩水。

## 三类积分，来源各不相同

公开渠道收录的问答把积分分成三类：

| 积分类型 | 来源 |
| --- | --- |
| 免费积分 | 系统赠送，不花钱 |
| 普通积分 | 通过充值获取 |
| 奖励积分 | 通过邀请好友或创作内容获取 |

关键细节是：**三类积分在消耗时会混在一起扣**。

## 奖励是怎么算的

计算口径：**只有当次成功扣取的正常积分，才参与奖励计算**。一次消耗里如果同时扣了免费积分和普通积分，只有普通积分那一部分算进奖励。

由此推出奖励变少的两种情形：

1. **当次消耗里含免费积分**——免费积分被优先扣掉，参与奖励计算的基数就小了；
2. **正常积分余额不足**——扣取失败或扣得少，奖励相应缩水。

对照这两条，「部分内容奖励积分很低或为 0」就有了直接解释。

## 两个高频疑问

**玩自己创建的卡片能拿奖励积分吗？**

不能。问答里明确了这一点：游玩自己的卡片无法获取奖励积分。奖励积分只通过邀请好友或创作内容获取。

**怎么把奖励做起来？**

先保证账户里有足够余额的普通积分，让每次消耗都能成功扣到普通积分，再去看奖励数字。

## 积分从哪来

- **充值**：左侧栏「充值」入口；应用内含付费项目，充不充、充多少自己决定；
- **任务**：完成应用内任务领取；
- **邀请好友**：通过邀请链接拉新获得奖励积分；
- **创作内容**：通过创作获取奖励积分；
- **邮箱验证**：有第三方渠道提到验证邮箱后可领一笔积分（口径 10000），以应用内「奖励」页当时显示为准。

左侧栏的「奖励」「充值」两个入口分别对应领积分和买积分；各类积分的结算规则以应用内当时显示为准。
