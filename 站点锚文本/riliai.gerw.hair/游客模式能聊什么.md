# RiliAI 游客模式能做什么：试聊边界与注册解锁对照

游客不用注册就能直接开聊，这是 RiliAI 上手成本最低的一段路；但模型切换、模组、上传这些真正改变体验的功能，都压在注册之后。本篇把两边的边界一次对清楚，帮你决定要不要走注册那一步。

---

## 打开应用就是游客

装好后首次启动会加载资源，等进度走完，左侧功能栏最底部显示的账号身份就是「游客」。此时点进首页任何一张角色卡片都能直接进入对话，回复逐段流出——不需要邮箱、不需要验证。

游客阶段能做的事：

- 浏览角色卡片流，按题材标签（都市、历史、科幻、同人、游戏、幻想等）筛选；
- 切换每日 / 每周 / 每月排行看热度；
- 以游客身份进入对话，体验基础流式聊天。

## 「注册以解锁工具」弹窗在说什么

试聊过程中点击模型、设置之类的具体功能，会弹出「注册以解锁工具」的提示：游客试用仅支持基础流式聊天，注册后即可使用模型、设置、模组和上传功能。这不是故障，是产品把免费边界划在了这里。

对照关系如下：

| 功能 | 游客 | 注册后 |
| --- | --- | --- |
| 基础流式聊天 | 可以 | 可以 |
| 切换 / 自定义模型 | 不可以 | 可以 |
| 对话与界面设置 | 不可以 | 可以 |
| 模组、世界书 | 不可以 | 可以 |
| 上传（聊天发图片等） | 不可以 | 可以 |

## 注册入口在哪、怎么走

1. 左侧功能栏拉到最底部，点「游客」；
2. 已有账号直接输账号密码登录；
3. 第一次用就点「立即注册」，按提示填完资料；
4. 登录后回到首页，角色与故事内容会陆续解锁。

注册邮箱建议选一个长期使用的，后续验证、找回都靠它。有第三方渠道提到完成邮箱验证后可领一笔积分（口径 10000，以应用内「奖励」页当时显示为准），积分的算法另见[积分奖励为什么是0](积分奖励为什么是0.md)。

## 建议的上手顺序

先以游客身份把聊天体验跑通——试试流式回复顺不顺手、角色对不对口味；觉得值得深入，再注册解锁模型与模组。想把设定玩出花（触发条件、自定义样式）之前，可以先读[世界书与自建剧情怎么玩](世界书与自建剧情怎么玩.md)，那篇把创作侧的几块积木拆开讲了。

两边的边界、功能对照与玩法主线，也可以在 [RiliAI 介绍站](https://riliai.gerw.hair/) 里按板块速查。
