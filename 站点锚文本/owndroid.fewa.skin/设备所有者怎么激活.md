# 设备所有者怎么激活

> 本篇讲 OwnDroid 从「空壳」变「能用」的关键一步：激活前的设备清理、四条路线怎么选，以及常见报错的处理。
> **相关文档**：[设备管控能做哪些事](设备管控能做哪些事.md) · [装完想停用或卸载怎么办](装完想停用或卸载怎么办.md)

---

安卓给「设备所有者」这个身份的权限远高于普通应用：冻结与隐藏应用、禁止卸载、管控相机与截屏、限制短信电话、管理多用户，全都建立在这个身份上。所以装完 OwnDroid 后功能点不动是正常现象——先激活，再谈使用。

## 一、激活前先做三件清理

安卓规定：设备上还挂着账号、还有多个用户、或已有别的设备所有者时，拒绝设置新的设备所有者。激活命令报错，九成出在这里。

1. **清理带账号的应用**：进「设置 → 账号」，把同步着账号的应用（邮箱、云服务、游戏渠道服）删掉账号或先冻结，激活完再加回来；
2. **删掉次要用户**：工作资料、私密空间、应用分身（微信/QQ 分身常挂在「分身」入口下）全部删除，主用户之外一个不留；
3. **停用旧的管理工具**：之前激活过类似管理工具（含公司配机管理、防丢类应用）的，先在那个工具里解除它的设备所有者身份。

## 二、四条路线按条件选

| 路线 | 前提 | 特点 |
| --- | --- | --- |
| ADB 命令 | 一台电脑 + 数据线 | 没 root 的普通手机最稳，连一次即可 |
| Shizuku | Android 11+、稳定 Wi-Fi | 无线调试配对，全程在手机上完成，多数人走这条 |
| Dhizuku | 设备已在用 Dhizuku | 已有托管环境时直接授权，不必专门为它折腾 |
| Root | 已 root | 应用内点一下即完成 |

ADB 路线的完整命令是一条 `adb shell dpm set-device-owner com.bintianqi.owndroid/.Receiver`——先开开发者选项与 USB 调试、`adb devices` 确认连上，再执行；看到成功提示后，数据线随时可拔，激活是一次性的。Shizuku 路线的配对细节（6 位配对码、重启后重按「启动」）在配套介绍站里有逐步说明。

## 三、报错对号入座

- **already some accounts on the device**：设备上还挂着账号，回第一节第 1 条；
- **already several users on the device**：还有次要用户没删干净；
- **device owner (xxx) is already set**：已有别的设备所有者，一台设备只允许一个；
- **MIUI/HyperOS 的 SecurityException**：开发者选项里打开「USB 调试（安全设置）」再试；
- **ColorOS 的 Unexpected @ProvisioningPreCondition**：系统签名校验拦截，换用项目发布页的 testkey 版本即可，功能没有区别；
- **三星机型的 user limit reached**：系统层限制，这类机型暂走不通这条路。
