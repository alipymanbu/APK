# OwnDroid · 资料整理

这里是围绕安卓设备策略管理工具 OwnDroid（包名 `com.bintianqi.owndroid`）整理的一组短文：它是一款 GPL-3.0 开源工具，用 Kotlin 与 Jetpack Compose 构建，通过设备所有者（Device Owner）等身份调用系统自带的管理接口，覆盖冻结预装、权限收紧、多用户拆分、Wi-Fi 批量配置等能力，可经 ADB、Shizuku、Dhizuku 或 Root 激活。功能介绍、界面截图与安装文件获取入口见 [OwnDroid 介绍站](https://owndroid.fewa.skin/)。
