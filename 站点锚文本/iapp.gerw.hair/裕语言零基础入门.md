# 裕语言零基础入门：几行指令就能跑起来

> 本篇整理裕语言（iyu）的最小入门路径：第一条指令怎么写、常用的几个指令是哪些、卡住了去哪查。
> **相关文档**：[手机上写代码做App的工具.md](手机上写代码做App的工具.md)

裕语言是 iApp 里的主力开发语言，特点是指令短、反馈快——写一行就能看到效果。这篇带你把最小的一圈跑通。

## 第一段代码：弹出一句话

在按钮的点击事件里写：

```iyu
tw("你好，这是我的第一个程序")
```

`tw` 是"弹出提示"指令。保存后点运行，点一下按钮，屏幕上就会出现这句话。第一次运行如果弹出权限提示，按提示放行。

## 高频指令先记这几个

| 指令 | 用途 | 示例 |
| --- | --- | --- |
| `s` | 赋值 / 定义变量 | `s a="123"` |
| `tw` | 弹出提示 | `tw("你好")` |
| `syso` | 打印调试信息 | `syso(a)` |
| `f` | 判断 | `f(a=="123"){ }else{ }` |
| `for` / `w` | 遍历循环 / 条件循环 | 写法见软件内手册 |
| `t` | 开线程，包住耗时动作 | `t(){ }` |
| `us` | 设置控件属性 | `us(1,"text","点我")` |

新手阶段记住一条搭配就够用：**耗时的动作（比如取网页源码 `hs`）包进 `t` 线程，结果出来再用 `tw` 提示**。直接在事件里做网络请求，界面会顿住。

## 几个新手最容易踩的坑

- **中文标点**：逗号、括号、引号打成了中文全角，是报错的第一大来源，报错行附近先查它；
- **版本差异**：新建项目时选的版本线（V3 / V5 / V7）决定指令集，导入别人的源码时版本要对得上，否则可能打不开；
- **权限被拒**：项目存不上，多数是存储权限没给，到系统设置的应用管理里放行即可。

## 卡住了去哪查

- **软件内手册**：安装目录自带几份 txt 帮助手册（V3.0、V5.0 各有对应文件），是最不容易出错的一手资料；
- **内置课程**：打开 iApp，在"互动"区有从零基础到进阶的系列视频课程，覆盖变量、控件、网络、数据库、动画等几十课；
- **对照例子学**：共享空间里有别人分享的源码项目，导入后把界面和代码摆在一起看，比凭空想快得多。
