# 安卓手机连电脑传文件，试试 HandShaker 这条路

> 安卓手机和 Windows / Mac 之间传文件，原生方案一直不算顺手。本篇从实际场景出发，聊聊 HandShaker 的定位：它把手机在电脑上打开成一个整洁的窗口，照片、视频、音乐按类型分好，拖拽即传。
> **相关文档**：[无线与扫码连接方法.md](无线与扫码连接方法.md) · [手机照片批量导到电脑.md](手机照片批量导到电脑.md)

## 一、老问题：手机一连电脑就是一堆天书目录

用数据线把安卓手机插上电脑，DCIM、Download、Android 这些文件夹一层套一层，找张前几天拍的照片得来回点半天。Mac 用户更尴尬——macOS 压根没有顺手的安卓文件窗口，早年靠 Google 的传输工具撑着，那款工具如今也已停止提供和维护。

HandShaker 是锤子科技针对这件事做的工具：手机端装一个应用，电脑端装一个客户端，两者连上之后，电脑窗口里直接出现按类型整理好的手机内容，拖进去是存入，拖出来是导出。

## 二、它在哪些场景里顺手

- **零散互传**：几张图、一个文档，无线连接下拖拽完成，不用插线；
- **大文件搬运**：视频、大压缩包改走数据线，电脑端 2.0 起换用自研的 SSP 传输协议，1GB 上下的影片从五六分钟压到约一分钟；
- **整批照片导出**：把整个相册文件夹一键导到电脑指定位置，比单选拖拽省事得多；
- **Mac + 安卓组合**：这正是它起家的场景，原名 SmartFinder，2016 年更名后同时覆盖 Windows 与 macOS。

## 三、上手前的两件事

第一，两端都要装：手机端负责提供文件访问，电脑端负责发现设备与执行传输，缺了哪头都连不起来。第二，准备好网络或数据线：无线方式要求手机和电脑连同一个路由器，USB 方式优先用原装线。

具体的连接操作步骤（无线、数据线、扫码三条路）见[无线与扫码连接方法.md](无线与扫码连接方法.md)；想把手机里的照片整批搬进电脑的，直接看[手机照片批量导到电脑.md](手机照片批量导到电脑.md)。
