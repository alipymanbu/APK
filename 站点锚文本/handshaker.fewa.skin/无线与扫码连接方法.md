# HandShaker 无线与扫码连接方法

> 连接是使用 HandShaker 的第一步，共三条路：同一 WiFi 的无线连接、USB 数据线，以及电脑端 v2.5.6 起支持的扫码连接。本篇按场景讲每条路怎么走、走不通时先查什么。
> **相关文档**：[安卓手机连电脑传文件工具.md](安卓手机连电脑传文件工具.md) · [手机照片批量导到电脑.md](手机照片批量导到电脑.md)

## 一、连接前的总前提

不管走哪条路，先满足这一条：连接时手机处于**解锁**状态，且手机端 HandShaker 正在**打开**着。锁屏或没开应用的情况下，电脑端发现不了手机——这是最容易踩的坑，没有之一。

## 二、无线连接（日常推荐）

1. 手机和电脑连**同一个路由器**——两个 WiFi 名字看着像、实际是两个网络的情况非常常见；
2. 解锁手机，打开手机端 HandShaker；
3. 打开电脑端，稍等片刻等它搜索到设备，点击连接；
4. 第一次连接时手机上会弹授权提示，点「信任」；
5. 两端都显示已连接，就可以拖拽传文件了。

无线的好处是不插线、随处可用；传大文件时改走数据线更稳更快。

## 三、USB 数据线连接（大文件首选)

优先用手机原装数据线（杂牌线可能只充电不传数据），解锁手机、打开手机端应用，电脑端会自动识别。如果插上没反应，试试切换手机上的 USB 连接方式（传输文件 / 仅充电 / 查看图片三种都试一遍），再检查是否需要打开 USB 调试。

## 四、扫码连接（搜不到设备时的备用路）

电脑端 v2.5.6 之后，手机端可以扫描电脑端显示的二维码直接建立连接，绕开设备发现环节。无线搜索一直无果时，先走这条路把连接立起来。

有个容易混淆的名字要提醒：搜索时可能出现一款叫 AirHandshaker 的应用，那是别家团队的工具，与锤子科技无关，手机端包名 com.smartisanos.smartfolder.aoa 才是正主。

## 五、连不上时的排查顺序

按顺序过：① 确认手机已解锁、手机端应用开着；② 确认两端在同一网络、网络本身可用（电脑刷个网页验证）；③ 完全退出两端应用重开；④ 部分路由器关闭组播会导致设备发现失效，换网络或改用数据线；⑤ 手机系统把后台服务杀掉也会频繁掉线，把 HandShaker 加进自启动白名单。

工具本身的获取与两端安装，整理在 HandShaker 资源站：[https://handshaker.fewa.skin/](https://handshaker.fewa.skin/)。连上之后想整批导出照片的，接着看[手机照片批量导到电脑.md](手机照片批量导到电脑.md)。
