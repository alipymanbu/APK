# NekoAnime 追番时间表与离线缓存用法

> 本篇讲 NekoAnime 装好之后的日常用法：用时间表追每日更新、把想长期看的番收进追番列表、离线缓存的适用场景，以及四个单手手势的速记。
> 相关文档：[安卓版下载与安装流程.md](安卓版下载与安装流程.md)

## 一、先认全三个找番入口

打开 App 后找内容主要走三条路：

- **知道名字**：直接搜索框输关键词，试试中文名或圈子里的常用简称。
- **只记得类型**：进分类页按类型逐级逛，适合没想好看什么的时候。
- **追新番**：用时间表，新番一般在你想到去搜它之前就出现在当天的更新栏里。

## 二、时间表：按星期追每日更新

时间表按星期一到星期日分栏，点对应日期就能看到当天更新的番和更新到的集数。日常动线很简单：晚上打开 → 切到今天 → 把追的那几部点开看完，全程不用出这一个页面。

## 三、追番列表与进度记忆

- 在番剧详情页点「追番」，它就进「我的」里的列表；列表支持排序（v0.5.1 专门优化过），番多了按自己的观看顺序排一遍。
- 看过的每一集自动进观看历史，中途退出再打开会从上次停的位置继续放，不用手动拖进度条。
- 「我的」页面里还有几个实用开关：禁用横屏模式（侧躺看番时用）、允许在竖屏状态下全屏播放（折叠屏/平板显示异常时的解法）、清除番剧数据缓存（页面数据错乱时用）。

## 四、离线缓存：通勤与流量紧张时的解法

离线缓存是 v0.5.0 加入的功能（当前版本 v0.5.2 功能齐全，并包含 v0.5.1 对缓存偶尔失效问题的修复）。三个典型场景：

1. **通勤路上**：地铁隧道信号断续，出门前在 Wi-Fi 下把要看的几集存好，路上离线播。
2. **月底流量见底**：回家连 Wi-Fi 缓存第二天的量，比用流量临时加载省得多。
3. **周末连看**：把当前更新到的几集一次性存下来，比每集临时加载稳。

缓存状态下的播放进度同样会被记忆，接着看不会从头开始。两点预期要提前有：缓存只能在应用内看，没有导出成普通视频文件的入口；内容来自互联网公开渠道，源侧变动可能让已缓存的条目失效，重要进度别只依赖缓存。

## 五、播放手势速记

播放界面的常用操作都有手势，不用中途找按钮：

| 手势 | 效果 |
| --- | --- |
| 长按屏幕 | 按住期间 2 倍速，松手恢复原速 |
| 水平滑动 | 快进 / 快退 |
| 左半边上下滑 | 调亮度 |
| 右半边上下滑 | 调音量 |

左右分区是 v0.5.0 才有的（横屏时左手管亮度、右手管音量的思路），手势没反应先确认版本；倍速目前只有长按 2x 一档，多档倍速菜单还在开发计划里没上线。

## 六、两个合理的预期

- **内容源单一**：目前只接了一个内容源，源侧临时出问题时全站番剧都可能放不出来——这是这类工具的共性，等恢复即可，反复卸载重装解决不了反而可能丢数据。
- **更新节奏偏慢**：这是个人业余维护的开源项目，版本迭代不快，不要因为「迟迟不更新」怀疑装了假包；以应用内自动检查更新的提示为准。
