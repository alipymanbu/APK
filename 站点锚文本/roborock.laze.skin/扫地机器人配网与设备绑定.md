# 扫地机器人配网与设备绑定

> 本篇讲石头扫地机器人第一次连 Wi-Fi、绑定到 Roborock App 的完整流程：配网前要满足的四个前提、扫码与搜索两种添加方式、Wi-Fi 指示灯怎么看。
> **相关文档**：[清扫地图编辑与禁区设置.md](清扫地图编辑与禁区设置.md) · [设备离线与指示灯排查.md](设备离线与指示灯排查.md)

配网要做的事一句话就能说清：让机器人连上家里的 Wi-Fi，再把它绑到你的账号下。入口在 App 首页右上角的「+」号，顺利的话几分钟走完。装 App、注册账号这些前置步骤，见 [roborock 安卓版下载与安装方法](https://roborock.laze.skin/download.html)。

## 一、配网前的四个前提

差一条，配网多半卡在半路：

1. **机器人电量充足**——先放回充电座充一会儿再配；
2. **手机已连上家里的 Wi-Fi**——注意是 Wi-Fi，不是流量；
3. **家里 Wi-Fi 是 2.4GHz 频段**——多数机型只支持 2.4GHz、不支持 5GHz。路由器双频分开命名的，配网时选 2.4G 那个；两个频段共用一个名字的直接选它试，连不上就去路由器后台把频段分开；
4. **手机给 App 开了位置权限**——添加设备时 App 会索要，安卓搜不到设备多半是这条没给。

另外两点提醒：App 没有针对平板做适配，用手机操作，别用 iPad 或安卓平板；充电座放在硬质平整的地面、靠墙摆，前方留 0.7 米、上方留 0.5 米空档，太挤会影响回充和日常使用。

## 二、支持扫码的机型

Q7 Max、Q7、Q5、S8 系列、Q Revo、Q5 Pro、Q8 Max 等系列支持扫二维码添加（以机型实际为准）：

1. 打开机器人上盖（部分机型的二维码贴在尘盒上或机身顶部），找到二维码；
2. 打开 App，点首页右上角「+」添加设备，按提示扫码；
3. 选家里 2.4GHz 的 Wi-Fi 名称，输入密码；
4. 过程中开着上盖观察 Wi-Fi 指示灯，等 App 提示配网完成。

## 三、没有二维码的机型

1. 打开机器人上盖，找到 Wi-Fi 指示灯；
2. App 首页点「+」→「搜索设备」，界面里点「未找到二维码」继续；
3. **重置 Wi-Fi 让机器人进入等待配网状态**：按住「局部/定点清扫」和「回充/充电座」两个按键，听到 Resetting WiFi 语音、指示灯转**慢闪**即成功（不同机型按键位置有差异，以说明书为准）；
4. 回到 App 按引导继续：选 2.4GHz Wi-Fi、输密码，等配网走完。

iPhone 流程多一步：中途会切到系统 Wi-Fi 列表，选中名字以 `roborock-vacuum` 开头的机器人热点，选完回 App 继续。

## 四、看懂 Wi-Fi 指示灯

| 状态 | 含义与处理 |
| --- | --- |
| 慢闪 | 已重置、正在等待配网，正常状态 |
| 一直快闪 | 可能在连网；反复快闪下不去，多半是密码输错，重置再来一次 |
| 复位后仍慢闪不动 | 检查 App 的 Wi-Fi/位置权限是否给全，再重试 |

配网成功后回 App 首页点进设备，等初始化进度到 100% 就能开始用了。配好了接着做的是建图和地图编辑，见 [清扫地图编辑与禁区设置.md](清扫地图编辑与禁区设置.md)；反复失败、设备一直离线的，翻 [设备离线与指示灯排查.md](设备离线与指示灯排查.md)。
