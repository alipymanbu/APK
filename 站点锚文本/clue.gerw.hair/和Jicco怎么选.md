# Clue 和 Jicco 怎么选？同门两款社交应用的分野

> 本篇回答一个高频困惑：Clue 与 Jicco 都出自武汉吉格斯科技，名字风格也像，到底是不是同一款、该怎么选。
> **相关文档**：[地图社交玩法与真人认证详解.md](地图社交玩法与真人认证详解.md) · [彩虹据点与同城组局.md](彩虹据点与同城组局.md)

## 一、先说结论：不是同一款

两款应用出自同一家开发方，但产品方向不同：

| 对比项 | Clue | Jicco |
| --- | --- | --- |
| 定位 | 彩虹圈层地图社交 | 兴趣圈子交友 |
| 主界面 | 实时地图（人、动态、据点全在图上） | 圈子与兴趣匹配 |
| 包名 | com.jiccos.clue | 与 Clue 不同（以应用商店页为准） |
| 特色玩法 | 彩虹据点、以图换图、新人推送 | 兴趣圈层、话题互动 |

装错方向就白注册了——下载前先核对包名，Clue 的包名是 `com.jiccos.clue`，这是最可靠的分辨办法。

## 二、按需求选：你要的是哪种社交

- **想按位置找人、关心「谁在我附近」**：选 Clue。它的地图把距离做成了透明的信息，附近新面孔、同城动态、线下据点都围绕位置组织，适合想把线上关系走到线下的人。
- **想按兴趣找人、关心「聊得来」**：选 Jicco。它按兴趣圈子聚合人，先聊共同话题再考虑见面。

两者都要真人资料与实名向的审核，注册时都用真实资料，账号才活得长久。

## 三、Clue 的使用体验要点

选了 Clue 之后，有几件事提前知道会更顺：

1. **认证是第一道关**：头像人工审核，正脸、清晰、无遮挡最容易过；认证通过前核心玩法是锁着的。
2. **位置权限必须给**：地图社交的一切都建立在定位上，「使用期间允许」是常见的给法。
3. **先调隐私再社交**：距离展示范围、位置可见性都能在设置里收紧，介意曝光的话先调再玩。
4. **安装包走网盘**：安卓安装包可以从夸克网盘资源获取，入口与安装步骤见 [clue 玩法拆解站](https://clue.gerw.hair/)，转存后就能装。

## 四、装完之后的路

装好 Clue 后建议按这个顺序上手：完成头像认证 → 收紧隐私设置 → 看附近的人 → 发第一条带定位的动态。玩法细节在 [地图社交玩法与真人认证详解.md](地图社交玩法与真人认证详解.md)，线下探店与组局的玩法在 [彩虹据点与同城组局.md](彩虹据点与同城组局.md)。
