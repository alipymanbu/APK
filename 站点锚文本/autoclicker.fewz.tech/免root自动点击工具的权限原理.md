# 免root自动点击工具的权限原理

> 免 Root 的自动点击工具不碰系统底层，却能替你在屏幕上点来点去——靠的是两项系统权限的配合。本篇把原理讲清楚，配置时心里有数。

## 为什么不需要 Root

安卓设计上不允许普通应用替用户操作屏幕，模拟触摸这类操作只对无障碍服务开放。免 Root 连点工具正是走这条路：申请成为一项无障碍服务，借用系统给无障碍的合法通道生成点击与滑动。Auto Clicker 就是这类工具的典型代表，全程不修改系统、不申请超级用户权限。

## 两项权限各管一件事

| 权限 | 管什么 | 缺了它是什么表现 |
| --- | --- | --- |
| 无障碍服务 | 在屏幕上生成模拟点击、模拟滑动 | 面板能出来，按播放却一下都没点 |
| 悬浮窗权限 | 把控制面板叠显示在其他应用上层 | 应用里点开始没动静，屏幕上看不到面板 |

一个当「手」，一个当「遥控器」。两项都在系统设置里手动开启：无障碍服务在「设置 → 无障碍 → 已下载的应用」里找；悬浮窗在「应用 → 权限 → 显示在其他应用的上层」里给。

## 无障碍权限会读到屏幕内容吗

会——这是它完成「替你看、替你点」的基础，对任何持有这项权限的应用都成立，不是某个连点工具特有。开发者在商店页面说明不通过该权限收集个人数据；如果仍然介意，记住这个自查方法：打开「设置 → 无障碍 → 已下载的应用」，列表里就是当前所有持有这项权限的应用，见到不认识、不使用的条目随手关掉。

## 为什么这类工具普遍要求 Android 7.0 以上

无障碍服务的接口在历代系统里变化不小，新版接口才提供了稳定的坐标点击与手势分发能力。以 Auto Clicker 为例，它的系统要求就是 Android 7.0 起，太老的系统装上也跑不稳。
