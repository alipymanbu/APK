# 无障碍服务总被自动关闭怎么办

> 连点工具点着点着自己停了，十有八九是无障碍服务被系统关掉了。本篇把常见原因和对应的保活做法一次列全。

## 先判断是不是服务掉了

无障碍服务掉线有个典型表现：控制面板还在，按了播放却一下都不点，或者点两下就停。遇到这种情况先别卸载重装，去系统设置里把无障碍服务关掉再重新打开，多数时候立刻恢复。

## 四种常见的掉线原因

| 原因 | 典型表现 |
| --- | --- |
| 省电策略杀掉了服务 | 跑一会儿就停，面板可能一并消失 |
| 一键清理或加速球清了后台 | 切到别的应用再回来就不点了 |
| 应用更新后服务被系统重置 | 更新完一打开就是没开权限的状态 |
| 部分系统对无障碍应用有使用确认 | 状态栏出现提示，服务被暂停 |

其中省电策略是最高发的。三星、小米、一加这类省电激进的品牌上，「跑一会儿就被关」的反馈最集中，重点检查下一节的白名单设置。

## 让服务稳定驻留的做法

下面是安卓通用的保活做法，入口名称各品牌略有差异：

1. 电池策略里把连点工具设为「不受限制」或「无限制」；
2. 允许它自启动，有的系统叫「后台弹出界面」，也要一并允许；
3. 在最近任务界面把它的卡片锁定，避免一键清理误伤；
4. 挂机时让屏幕保持常亮，或插着电并在开发者选项里开「充电时屏幕不休眠」——屏幕一灭，自动点击就没有作用对象了。

## 找不到服务条目怎么办

刚装完或刚更新完应用时，无障碍服务列表有时要等一会儿才刷出它的条目，找不到就退出去重进一次设置。实在定位不到入口，在设置页顶部的搜索框里直接搜「无障碍」。
