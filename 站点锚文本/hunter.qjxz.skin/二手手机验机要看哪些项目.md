# 二手手机验机要看哪些项目

> 收二手机、接手家人朋友的旧手机之前，值得花十分钟核查的项目清单：硬件之外，系统环境才是容易踩坑的部分。
> **相关文档**：[刷机后怎么自查手机环境](刷机后怎么自查手机环境.md) · [安卓 Root 检测工具怎么选](安卓Root检测工具怎么选.md)

## 一、为什么系统环境比外观更值得查

二手交易的常见验机动作是看外观、查 imei、试功能，但这些查不出「系统被动过什么」。前任机主 Root 过、刷过第三方系统、装过框架、用过分身多开——这些改动不会写在商品描述里，却直接影响你之后的使用：系统稳定性、某些应用的运行环境、甚至二手价是否符合「无拆无修无 ROOT」的说法。

十分钟的环境核查，补的就是这块信息差。

## 二、验机清单

**先查常规项（交易前大家都会做的）：**

- 外观成色、屏幕是否原装；
- imei 与包装、系统信息是否一致；
- 电池健康度、充电是否正常；
- 摄像头、听筒、指纹、面部识别逐个试。

**再查系统环境（容易被漏掉的）：**

1. **系统版本与内核信息**：进设置看系统版本，是不是第三方 ROM 一眼能看出；内核安全补丁等级与机型出厂状态差得远，说明刷过机。
2. **是否有 Root 管理器**：应用列表里翻有没有 Magisk、KernelSU 一类；没有也不代表干净，残留可能藏在系统层。
3. **环境检测跑一遍**：拿检测工具把 Root 痕迹、框架残留、沙箱环境、设备指纹、模拟器特征逐项扫一遍，这是常规手段查不到的部分。
4. **指纹与标识参数**：Android ID、MAC 这类参数被改过，往往意味着用过改机工具——这类机器来路要多问一句。

## 三、第 3 步具体怎么做

环境检测工具的选择逻辑见 [安卓 Root 检测工具怎么选](安卓Root检测工具怎么选.md)，操作上记住三点：

- **用覆盖面宽的工具扫全量**，第一次要的是完整清单。Hunter 属于这一类：Root、框架、沙箱、调试工具、指纹、模拟器特征一次扫完，报告列风险项并附可疑文件路径，做验机记录很合适——截图留档，与卖家描述对照。它的界面与检测项演示在 [Hunter 环境检测站](https://hunter.qjxz.skin/) 可以先看一眼。
- **报告带路径的，顺着路径核对**。可疑文件给了路径，就在文件管理器里看一眼是否真的存在，比只信一句结论可靠。
- **存疑项换工具交叉验证**。只有一家报的项目优先按误报对待；两家以上报同一项，谈判时才拿得出手。

## 四、查出来问题，怎么定性

| 检测发现 | 定性 | 处理建议 |
| --- | --- | --- |
| Root 痕迹、框架残留 | 前任机主主动改动 | 不一定是坏事，但与「原装无 ROOT」的描述不符，可作议价依据 |
| ROM 被修改 / 第三方系统 | 刷过机 | 稳定性与保修都受影响，谨慎对待 |
| 指纹参数异常 | 可能用过改机工具 | 来路存疑，建议放弃或大幅压价 |
| 模拟器特征 | 极少见，警惕「翻新机刷系统」 | 要求卖家解释或放弃交易 |

一句话原则：**检测结果不改好坏判断，改的是「描述与实物是否一致」**。环境干净就按原计划走；查出与描述不符的项目，主动权就在你手里了。

## 五、收尾动作

验机通过、决定收下之后，建议做三件事：退出前任机主登录的所有账号、恢复一次出厂设置、再跑一遍环境检测留底。恢复出厂不会清掉系统层的改动（Root 残留、框架文件还在），所以「恢复出厂 = 干净」是误区——留一份检测记录，之后出问题才有对照的基准。
