# 核心怎么选与主机对照：给怀旧游戏新手的核心指南

> 本篇讲 RetroArch 的「核心」是什么、怎么下载更新，以及 FC、SFC、GBA、PS1、PSP 等常见主机各自口碑最好的核心叫什么名字。
> **相关文档**：[安卓上装怀旧游戏前端.md](安卓上装怀旧游戏前端.md) · [ROM导入与扫描建列表.md](ROM导入与扫描建列表.md)

## 一、核心是什么

RetroArch 本体只是统一的「壳」，真正执行模拟的是一个个叫核心（Core）的插件。刚装好的它一个核心都没有，所以列表是空的；想玩哪台主机，就装哪个主机的核心，同一台主机还能并排装几个备选。

## 二、下载与更新

- **下载**：主菜单 → Load Core → Download a Core，列表按主机英文名分组，例如 `Nintendo - Game Boy Advance` 分组下就是 GBA 核心，点一下自动下载安装。
- **批量更新**：主菜单 → Online Updater → Update Installed Cores，一次把所有已装核心升到最新。
- **卸载**：Load Core → Installed Core List 里选中卸载，删错了重下即可，没有连带影响。

下载核心要访问 Libretro 的构建服务器，一直转圈多半是网络到服务器不稳，换个网络环境再试；核心列表本身只有几十条的，说明装的是受平台政策限制的渠道版本，换独立分发的安装包重装（安装流程见[安卓怀旧游戏前端安装整理](https://retroarch.djnf.quest/download.html)）。

## 三、常见主机口碑核心对照

| 主机 | 推荐核心 | 备注 |
| --- | --- | --- |
| FC / NES | Nestopia UE、Mesen | Mesen 精准但吃性能 |
| 超任 / SNES | Snes9x | 速度快，手机首选 |
| GB / GBC | Gambatte、SameBoy | 老掌机零门槛 |
| GBA | mGBA | 手机上的默认选择 |
| 世嘉 MD / GG / SMS | Genesis Plus GX | MD 世代通吃 |
| 世嘉 32X | PicoDrive | 小众但稳定 |
| PS1 | PCSX-ReARMed | 多数游戏免 BIOS |
| N64 | Mupen64Plus Next | 部分游戏需逐个调插件 |
| 土星 | YabaSanshiro | 本身难模拟，中低端机慎入 |
| Dreamcast | Flycast | 性能要求较高 |
| PSP | PPSSPP | 新机型体验出色 |
| 街机 | MAME 2003 Plus、FBNeo | 按游戏年代选 |
| NDS | melonDS、DeSmuME | 双屏依赖触屏或手柄 |

高画质主机（N64 及以后）对手机芯片要求直线上升，老手机卡顿先换同主机的高速核心，再考虑调设置。

## 四、核心与游戏的配合

核心版本与个别游戏的兼容性偶有牵连：某个游戏在核心更新后异常，可去 Online Updater 看有没有单独更新该核心的选项，或在 Load Core 里换同主机的另一个核心交叉验证。核心就位后，把游戏文件导入并建立列表的步骤见 [ROM导入与扫描建列表.md](ROM导入与扫描建列表.md)。
