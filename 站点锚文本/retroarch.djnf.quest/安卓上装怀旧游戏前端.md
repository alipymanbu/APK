# 安卓上装怀旧游戏前端：RetroArch 完整流程

> 本篇讲怎么在安卓手机上装好 RetroArch：认准 64 位安装包、侧载安装的两处系统拦截怎么放行、首次启动要给哪些权限，以及装完第一件事做什么。
> **相关文档**：[核心怎么选与主机对照.md](核心怎么选与主机对照.md) · [ROM导入与扫描建列表.md](ROM导入与扫描建列表.md)

## 一、先认准版本

RetroArch 由 Libretro 社区开发，同一部手机上能找到好几个发行渠道，但功能完整度差别很大：应用商店里挂在货架上的版本受平台政策限制，内置的核心下载器连不上构建服务器，能装的核心屈指可数；独立分发的 64 位安装包（当前稳定版 v1.22.2，包名 `com.retroarch.aarch64`）才是社区推荐的形态，核心列表最全、更新也最快。

近几年的安卓手机基本都是 64 位设备，直接用 64 位包即可；只有特别老的 32 位机器才需要找 `ra32` 构建。

## 二、侧载安装四步

1. **转存安装包**：通过[怀旧主机模拟前端介绍站](https://retroarch.djnf.quest/)提供的夸克网盘入口把 APK 转存到自己账号，再从网盘下载到手机。
2. **放行未知来源**：用文件管理器点开 APK，系统弹「已阻止安装」时点提示里的设置按钮，打开「允许安装未知应用」开关，返回继续。
3. **放行 Play Protect**：弹出红色警告页时选「更多详情 → 仍要安装」；老系统上反复拦截的，可临时关闭 Play 保护机制的扫描开关，装完再打开。
4. **首次启动**：打开应用立刻会请求存储权限，选允许——扫描游戏、写存档全靠它；界面空空如也是正常的，它出厂不带任何核心。

## 三、装完第一件事

进主菜单 → Load Core → Download a Core，把目标主机的核心装上，才有第一批能玩的内容。选哪个核心口碑好，见 [核心怎么选与主机对照.md](核心怎么选与主机对照.md)；核心装好后把 ROM 放进手机存储扫描建列表，见 [ROM导入与扫描建列表.md](ROM导入与扫描建列表.md)。

## 四、覆盖升级与回退

新版安装包直接覆盖安装，数据与存档保留；覆盖后个别核心行为变化导致游戏异常的，可以在在线更新器里把核心单独降级，或去设置里核对存档目录是否还指向原来的位置。
