# ROM 导入与扫描建列表：让游戏架自己长出来

> 本篇讲游戏 ROM 放到手机哪个目录、怎么用扫描功能按主机生成游戏列表、扫描不出结果时怎么放宽匹配，以及给列表补上封面图。
> **相关文档**：[安卓上装怀旧游戏前端.md](安卓上装怀旧游戏前端.md) · [核心怎么选与主机对照.md](核心怎么选与主机对照.md)

## 一、ROM 放在哪

RetroArch 不提供游戏本体，ROM 要自己放进手机存储。两条原则：

- **放在应用看得到的地方**。安卓 11 之后 `Android/data` 一类目录在部分机型上无法用普通文件管理器浏览，最省事的做法是在内部存储根目录自建文件夹，例如 `RetroArch/roms/`，再按主机分子目录：`roms/GBA/`、`roms/SNES/`、`roms/PS1/`。
- **文件名保留游戏原名**。扫描靠文件名与校验值去数据库对号入座，乱改名的游戏容易匹配失败。

常见的 `.zip`、`.7z` 压缩包不必解压，可直接扫描加载；PS1 游戏优先找 `.chd` 整盘镜像，省空间也免换盘。

## 二、扫描前的准备

1. 先装好对应主机的核心（对照表见 [核心怎么选与主机对照.md](核心怎么选与主机对照.md)），没核心扫出来也玩不了。
2. 主菜单 → Online Updater → Update Databases，顺手把 Update Core Info Files 也点了——这份数据库是识别游戏的依据，不更新可能扫不出新游戏。

## 三、扫描与手动导入

**自动扫描**：主菜单 → Playlists → Import Content → Scan Directory，选中放 ROM 的文件夹确认即可，大合集要等几分钟，扫完主菜单会按主机出现一个个列表。

扫描默认是严格模式：文件必须在数据库里精确对上号才会进列表。扫完发现缺了不少游戏时，用 Import Content 里的手动扫描（Manual Scan）放宽匹配再扫一遍，或用 Scan File 逐个指定；没匹配上的游戏也会以「未识别内容」出现在列表里。

**手动加载**：偶尔玩一次、懒得建列表的，主菜单 → Load Content → 选文件 → 选核心，直接开玩，不生成条目。

**多盘游戏**：PS1 一拆两三张盘的，合并成单个 `.chd` 当一张盘最省心；没合并的逐盘扫描，玩到换盘时在快速菜单 → Disc Control 里弹出并插入下一张。

扫完的游戏打不开，先怀疑缺 BIOS 文件——光驱类主机（PS1 部分游戏、世嘉 CD、Dreamcast、土星）缺 BIOS 就黑屏。

## 四、补封面图

主菜单 → Online Updater → Playlist Thumbnails Updater，选中要补图的主机列表联网下载封面与标题画面。图包不小，网络慢就只挑自己在玩的几个列表。手动扫描生成的列表，条目名要与缩略图站命名一致才配得上图，配不上的游戏一直是灰格子，不影响游玩。

## 五、从列表到开玩

列表、核心、BIOS 都齐了，点游戏直接进。装好本体的完整流程回顾见[安卓怀旧游戏前端介绍站](https://retroarch.djnf.quest/)，按键手感不合适再去快速菜单里调输入映射。
