# RetroArch 怀旧主机资料站

这里整理 RetroArch 这个开源模拟器前端的介绍与上手资料：它能把 FC、SFC、GBA、PS1、PSP 等几十种老主机的模拟核心装进同一个界面，是怀旧游戏玩家在安卓手机上最常被提起的方案之一。

- 站点入口：[https://retroarch.djnf.quest/](https://retroarch.djnf.quest/)
