# GameKiller 沙盒免 Root 玩法与数值搜索教程

本篇讲 GameKiller（玩家常叫它八门神器）当前版本的两条使用路线：沙盒路线解决「怎么免 Root 跑起来」，搜索路线解决「数值怎么定位准」。安装入口见[GameKiller 怎么用](https://gamekiller.boop.uno/)，装好之后照下面的顺序走即可。

---

## 先弄清楚它靠什么运行

早期的同类工具要读游戏内存，很多机型得先 Root。到了 v5.3.x，GameKiller 把修改器搬进了「沙盒（Box）」：游戏被克隆进一个隔离环境，工具和游戏待在同一个空间里运行，整机不再需要 Root 权限。悬浮窗、暂停游戏、按数据类型搜索这些老功能都还在，只是入口挪到了沙盒里。

所以上手前只需要确认两件事：

1. 手机是 Android 5.2 以上（v5.3.5 安装包约 41 MB）；
2. 想改的游戏已经装在本机，而且是单机或模拟器游戏（边界见文末链接的那一篇）。

## 路线 A：沙盒免 Root（对应 Box 标签）

1. 打开 GameKiller，切到底部 **Box** 标签，点 **Add Game**，把装在本机的游戏加进初始沙盒；
2. 需要多开或试改时，新建一个沙盒再把游戏克隆过去——不同进度各占一个沙盒，互不干扰；
3. 从沙盒里启动游戏，修改功能随游戏一起运行，改完直接在沙盒里继续玩。

注意克隆的先后顺序：**先把游戏加进初始沙盒，再谈克隆到别的沙盒**。顺序反了会找不到可克隆的对象——界面上那句「To clone an app, first add it to the initial sandbox」说的就是这件事。

## 路线 B：数值搜索四步定位（经典玩法）

1. **记下屏幕数值**：金币、生命、属性点都行，在搜索框输入这个数，并选好数据类型（整型、浮点都能搜，负数也支持）；
2. **回游戏让数值变化**：花掉一点、赚回一点都可以，变化量越明确，收敛越快；
3. **切回工具再搜**：输入变化后的新数值再搜一轮，候选地址会明显变少；
4. **改、存、锁**：剩少数几个结果时尝试修改、存储或锁定，回游戏确认效果。

第一轮结果通常一大把，别急着动手；多让数值变一两轮，收敛到一两个地址再改，成功率高得多。搜索期间可以在工具里暂停游戏，方便记数和输入。

## 两条路线怎么选

- 只想快点看到效果：走沙盒路线，配合内置榜单里的现成修改版；
- 想自己动手、改自己指定的数值：走搜索路线，四步定位；
- 两者不冲突：同一个游戏可以沙盒里克隆一份练手，原版留着正式进度。
