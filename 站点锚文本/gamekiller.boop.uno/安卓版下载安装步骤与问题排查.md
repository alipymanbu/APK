# GameKiller 安卓版下载安装步骤与问题排查

本篇按顺序讲 GameKiller v5.3.5 在安卓手机上从取包到打开的全过程，以及安装被拦、解析失败、打开闪退这几件最常挡路的事。安装文件资源的入口在[GameKiller 安卓版](https://gamekiller.boop.uno/)，打开分享页转存到自己网盘就能取原包。

---

## 装之前确认三件事

1. 机型是 Android 5.2 以上，存储空间留出至少 100 MB；
2. 安装包 v5.3.5、约 41 MB，从分享页转存后下载到手机；
3. 想改的游戏已经装在本机（沙盒要把游戏克隆进 Box 才能运行）。

## 安装四步

1. **转存并下载**：打开分享页，先「保存到我的网盘」再下载 APK——转存一份之后随时能重新取，不怕分享失效；
2. **放行未知来源**：首次安装系统会拦一下，选「仍要安装」，或在设置里把「安装未知应用」权限授给下载用的浏览器或文件管理器；
3. **完成安装并首次打开**：授予存储权限，沙盒要把游戏文件复制进 Box，这一步跳不过；
4. **加游戏开改**：切到底部 Box 标签，点 Add Game 把想改的单机游戏加进初始沙盒，从沙盒里启动它。

## 三个常见问题

### 点安装被拦截、提示未知来源

各品牌入口不一样，但思路相同：把「安装未知应用」权限授给**下载用的那个应用**（浏览器或文件管理器），而不是去开全局开关。小米部分机型还要关「MIUI 优化」或刷开发版才能正常授权，授权反复失败多半是这类机型限制。

### 提示解析失败或包损坏

多半是下载不完整。回网盘把 APK 删掉重新下载一遍，确认文件完整（约 41 MB）再装；下载中途中断过的包，别省这一步。

### 装好了却打不开、或游戏加不进沙盒

Android 5.2 以下装不上属于版本问题。能装但闪退，先清后台腾出可用内存再试；游戏加进 Box 失败，检查是不是还没加进初始沙盒——克隆副本的前提是先有初始沙盒里的那一份，顺序别反。
