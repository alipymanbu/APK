# FanFiction.Net 离线书库与听书用法

> 本篇讲怎么把故事缓存进 FanFiction.Net 应用断网读、书架怎么跨设备同步，以及把文当有声书听的几项设置。
> **相关文档**：[安卓版怎么下载安装.md](安卓版怎么下载安装.md) · [和AO3怎么选.md](和AO3怎么选.md)

---

这个应用相对网页版最大的优势就在离线：下载下来的文断网能读，坐地铁、出差都不受影响；再配上内置的文字转语音，通勤路上可以直接「听」完一章。

## 一、哪些内容能离线、走哪条正路

- 站方提供的正式功能就是把故事**免费下载进书库离线读**，数量没有限制；网页端没有下载功能，站方条款也不允许用自动化工具批量抓站内内容——想在规则内离线读，就用应用自带的下载。
- 顺带一提：AO3 每篇作品支持一键导出 EPUB / MOBI / PDF，FFN 没有对应的导出途径，两站在离线上的取舍见[和AO3怎么选.md](和AO3怎么选.md)。

## 二、下载与查看

1. 打开故事页，点下载（Download）按钮，整部作品的章节会缓存到本机。
2. 在书库里切到已下载（Downloaded）分区查看，断网也能打开。
3. 章节多的长文建议在 Wi-Fi 下下载，下载走的是应用流量，不接管系统下载管理。

一个被老读者反复验证的细节：**已经下载进应用的故事，即使站方后来把原文删除，在你这台设备上仍然能读**；反过来，这个「备份」只存在于应用里，卸载应用就一起没了。

## 三、书架与进度的跨设备同步

- 书库、追更、收藏与阅读进度挂账号同步，手机和平板登录同一账号即可互通。
- 已下载到本机的故事**不参与同步**，换设备要重新点下载。
- 遇到书架不同步、个别章节消失时先别清数据——清数据可能把本地已下载的文一起清掉，先等站方更新修复。

## 四、听书（TTS）怎么配

1. 在阅读界面找朗读/耳机图标启动文字转语音。
2. 音色在朗读设置里选；后续版本加入了高清英文音色，手上的版本能不能用，以应用内实际显示为准。
3. **发音生硬或卡顿时**，把朗读引擎从手机自带的本地引擎换成网络语音引擎，流畅度通常更好——入口在系统设置的「文字转语音」选项。
4. 朗读支持来电自动暂停，这项依赖电话状态权限，装完没给的要在系统设置里补开。
5. 车上有 Android Auto 的话，应用也支持在车机界面里继续听。

## 五、下载或播放失败的常见原因

| 现象 | 先查什么 |
| --- | --- |
| 下载按钮点了没反应 | 网络是否可用；部分操作需要登录状态 |
| 下载中断或文件损坏 | 存储空间是否已满；删掉重下一遍 |
| 已下载的文打不开 | 是否最近清过应用数据、或处于未登录状态 |
| TTS 没声音 | 系统音量与媒体音量；引擎是否被省电策略限制 |
