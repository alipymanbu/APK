## 一、先说结论：是一场演出，不是出了事

归零那一刻，屏幕会剧烈跳动、闪白，配合音效把「时间到了」按恐怖片的路子演一遍。闪光灯自己开合、音乐音量突然拉高、机身一阵阵震动——这些都是内置特效，界面还在、功能还在就都不是故障。商店里的一星评论，大多数其实是**被特效吓到**，而不是应用坏了。

## 二、几个会被误会的时刻

| 你看到的现象 | 属于什么 |
| --- | --- |
| 闪光灯开合、屏幕闪白、音乐突然变大 | 内置恐怖特效，不用处理 |
| 数字变红 | 接近归零的设计，越近越扎眼 |
| 点界面某处突然闪屏、出怪声 | 点数字本身也会触发效果，想安静别乱点 |
| 弹 `User Agreement Broken`、界面错乱 | 改了系统时间触发的整蛊，恢复自动对时即可 |
| 点某个入口先播广告、之后时长变了 | 「改变命运」机制：看广告换一个随机时长 |

关于最后一条多说一句：剩余时长**本来就不是固定的**——有人拿到几十年，有人拿到几小时，卸载重装还可能变。它给的数是娱乐设定，没有可核验的算法，也别按它安排心情。

## 三、想把动静调小，可以动哪些地方

- **嫌吵**：音量键压低，或直接给它静音；
- **嫌震**：系统设置里对这一应用单独关震动；
- **嫌闪**：拒绝闪光灯权限，背面灯就不闪了（屏幕闪白没有单独开关）；
- **接受不了**：直接杀后台或卸载，卸载没有任何副作用。

**光敏与场合提醒**：应用含突发音效与强闪光，光敏感人群与低龄儿童不建议接触；别在深夜独自打开，更别在驾驶、骑行时开，也别对着不知情的人突然放。

## 四、归零之后还能再玩吗

能。重新打开应用会重新给出一段随机时长，读秒从头开始——它没有「存档」，也没有「结局记录」，每一轮都是一段独立演出。想完整体验归零又不等太久，可以多开几次碰一个短的时长，或者用「改变命运」入口碰运气。
