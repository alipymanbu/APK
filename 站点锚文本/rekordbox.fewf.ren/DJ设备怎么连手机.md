# DJ设备怎么连手机

> 手机版 rekordbox 能接两类硬件：家里的 DDJ 控制器（练手法）和俱乐部的 CDJ/XDJ 播放器（上台放歌）。本篇讲两种连接的准备条件、接法和连不上的排查顺序。
> **相关文档**：[手机上怎么打碟.md](手机上怎么打碟.md) · [免费版和订阅怎么选.md](免费版和订阅怎么选.md)

---

## 一、连之前的三件事

1. **登录账号**：连接 DJ 硬件属于需要登录 AlphaTheta 账号的功能，不登录时设备连上也用不了；
2. **核对型号**：手机版只认适配清单内的型号，不在清单里的设备连上不会被识别；
3. **备好线材**：控制器走 USB 线或蓝牙；接播放器则要按型号备线，很多「只能充电」的线是连接失败的元凶。

安装与首次授权的流程见 [rekordbox 安卓版介绍站](https://rekordbox.fewf.ren/) 下载页，这里不再展开。

## 二、在家：连 DDJ 控制器

手机版适配四款控制器：**DDJ-200、DDJ-FLX2、DDJ-FLX4、DDJ-GRV6**，USB 线或蓝牙均可（具体到某个型号支持哪种接法、要不要供电转接头，以该型号的说明页为准）。连接步骤：

1. 打开控制器电源，USB 线连手机（或先在蓝牙设置里配对）；
2. 打开 rekordbox 并登录账号；
3. 在应用的硬件连接入口选中控制器，等识别完成；
4. 识别成功后，推子、转盘、打击垫直接控制手机界面。

两个提醒：耳机预监听（公放前用耳机听下一轨）受订阅状态影响，免费版不可用，详见 [免费版和订阅怎么选.md](免费版和订阅怎么选.md)；部分手机没有 USB 口或供电不足，需要带供电的 OTG 转接。

## 三、上台：手机直连 CDJ/XDJ

俱乐部场景下，手机就相当于一个 U 盘，播放器直接浏览手机曲库。两种接法：

**Wi-Fi（PRO DJ LINK）**：播放器用网线接路由器，手机连同一台路由器的 Wi-Fi，应用里选 PRO DJ LINK 入口识别设备。现场路由器不可控时，自带一个随身路由器比碰运气稳；手机流量热点不适合这种接法（不在同一网段）。

**USB 线直连**：按播放器端口备线——Type-B 口的机型（CDJ-3000、XDJ-XZ、XDJ-RX3 等）用 A 转 B 数据线，Type-C 口的机型（CDJ-3000X、XDJ-AZ、OPUS-QUAD 等）用 C 对 C 线，手机侧视接口加 OTG 转接。**切换有线前先关手机 Wi-Fi**，否则连接不生效。

注意三个机型特例：XDJ-RR / RX3 / RX2 没有 Wi-Fi、只能线连；XDJ-AN 与 OMNIS-DUO 只有 Wi-Fi、没有有线口；完整机型表在应用的说明页里，出门前按自己的设备核对一遍。

## 四、连不上的排查顺序

| 现象 | 按顺序查 |
| --- | --- |
| 控制器识别不到 | 型号是否在四款清单内 → 换一根数据线 → USB 不行改蓝牙 |
| 连上但推子不动 | 是否已登录账号（未登录硬件功能不开放） |
| 播放器读不到手机 | 换线换口 → 手机 USB 模式设为文件传输 → 有线先关 Wi-Fi → 不行改 Wi-Fi 接法 |
| PRO DJ LINK 搜不到设备 | 手机与播放器是否同一网段 → 路由器 AP 隔离是否关闭 |

## 五、出发前的最后检查

- 灰色标题的歌 = 只有曲库信息、文件本体不在手机上，提前用 Mobile Library Sync 传全；
- 串流曲目依赖网络，现场的关键曲目换成本地文件；
- 手机版不能把歌「导出」到 U 盘——这个能力只有电脑版有，别在出发当晚才发现；
- 带齐：数据线、OTG 转接、（可选）随身路由器。
