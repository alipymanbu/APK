# komoot 路线规划技巧与选路逻辑

> 从运动类型的选择讲到途经点的排布，把"画一条能直接导航的路线"这件事拆开讲清。
> **相关文档**：[离线地图与省电技巧.md](离线地图与省电技巧.md) · [码表手表与账号同步.md](码表手表与账号同步.md)

## 为什么同一对起终点，画出来的线不一样

komoot 的选路不是单纯求最短或最快，而是先看你是什么运动方式。规划器里先定三件事：运动类型、配速、路线类型（单程或往返）。运动类型决定选路偏好，也决定地图上显示哪些红色 Highlight 推荐点：

| 运动类型 | 选路偏好 |
| --- | --- |
| 徒步 | 小径、自然步道 |
| 公路自行车 | 柏油路为主 |
| 山地自行车 | 单 Track 林道、土路 |
| 砾石自行车 | 砾石路 |
| 跑步 | 适跑路面 |
| 旅行自行车 | 平稳铺装路 |
| 登山 | 登山路线 |

两个容易忽略的细节：骑行类有独立的 E-Bike 复选框，勾上后时长与难度按电助力车估算，同一段爬坡的预计时间差很多；配速与体能档位只影响预计用时，不会替你换路线——"预计 3 小时"不准时，先查这两项设置。

## 途经点：把自动生成的线掰成你想要的形状

自动规划的线往往不合心意，途经点是修正它的工具：

1. **加**：点地图任意位置选"作为途经点"，或在途经点列表里用搜索添加；
2. **排**：打开途经点列表，按住拖动手柄换序——顺序直接决定路线走向；
3. **删**：点中地图上的点，或点列表里它旁边的 ✕。

改完路线立即重算，所见即所得。两个进阶玩法：

- **按坐标定点**：把十进制度、度分或度分秒格式的 GPS 坐标直接粘进搜索框。地图上没名字、没人标过的地方，只能这么放点；
- **离网段**：关闭"跟随道路"后，两点间变成直线虚线，无视现有道路。适合你知道某条没被地图收录的可通行小路的场合——注意这段路线不保证可通行也不保证安全，出发前自己核对现场条件。

## 从画完到开始走

保存路线后，从"已保存路线"里选中它发起导航。前提只有一个：路线起点所在区域已解锁。注册时赠送的免费区域建议留给常住地，随时能练手；语音导航开启后，转向提示通过耳机播报，屏幕可以一直黑着，安卓端还有"转向时点亮屏幕"的开关可选。

想看这款应用的界面与完整功能盘点，[komoot 介绍站](https://komoot.fewf.ren/) 有更直观的图文整理。要去没信号的地方，出发前照 [离线地图与省电技巧.md](离线地图与省电技巧.md) 把地图先下好。
