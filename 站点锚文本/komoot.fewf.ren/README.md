## 一句话认识 komoot

komoot 诞生于 2010 年的德国波茨坦，全球注册用户超过五千万。它与开车导航最根本的不同在于选路目标：徒步给小径、公路车给柏油、山地车给林道，坡度与路面都参与计算，导航靠逐向语音完成，手不离把也能走完全程。
