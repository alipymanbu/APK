# Blurrr 安卓版怎么下载安装

> 安卓端安装包约 248MB，要求 Android 11 及以上。整条链路是：找到分享资源 → 转存 → 下载 → 允许安装 → 打开。

## 安装前先核对两件事

- **系统版本**：安卓端要求 Android 11 起步，老一些的机型需要先升级系统；
- **存储空间**：安装包约 248MB，解压安装阶段占用更大，建议预留 2GB 以上空间。

## 下载安装流程

1. **进入分享页先转存**。安装文件资源以网盘分享的形式提供，打开分享页后登录自己的网盘账号，把安装包转存进自己的空间——这样即使原分享后续变动，文件也不会丢。
2. **在网盘客户端里下载**。找到转存好的安装包点下载，体积不小，建议走 Wi-Fi。
3. **允许安装未知来源应用**。首次点开安装包时系统会拦一道，在弹出的设置页里给提供安装包的应用（网盘或文件管理器）打开「允许安装未知应用」，返回后继续装。
4. **装完直接打开**。桌面出现图标后，首次启动会有权限申请与素材库初始化，稍等片刻就能进入剪辑界面。

## 装不上的几种情况

- **提示「禁止安装」**：就是未知来源权限没给到，按第 3 步再检查一遍；部分机型入口在 设置 → 安全 → 更多安全设置 → 安装未知应用。
- **提示版本过低**：系统没到 Android 11，先升系统再装。
- **装完闪退**：清理后台重开，或清一次应用数据；仍然不行就卸掉重装一遍。
