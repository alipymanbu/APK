# 界面是英文？改成中文的设置方法

> 本篇讲 DreamFace 界面显示成英文时怎么换成中文：应用内切换、系统级按应用设置，以及常用界面的中文对照。
> **相关文档**：[是什么软件怎么用.md](是什么软件怎么用.md) · [照片跳舞唱歌怎么弄.md](照片跳舞唱歌怎么弄.md)

---

## 一、先试应用内的语言入口

1. 打开 DreamFace，进入探索（Explore）主界面。
2. 点左上角的语言选项。
3. 在语言列表里选「简体中文」。
4. 返回主界面，显示语言即已切换。

左上角找不到语言入口的话，说明这份版本的入口位置不同或功能有变动，接着用下面的系统级办法。

## 二、系统级：只给这一个应用换语言

Android 13 与 iOS 13 之后的系统都支持「只改某一个应用的语言」，不影响手机整体：

| 系统 | 路径 |
| --- | --- |
| Android 13+ | 设置 → 应用 → DreamFace → 语言 → 简体中文 |
| iOS 13+ | 设置 → 应用列表 → DreamFace → 语言 → 简体中文 |

两个前提：系统语言列表里要先有简体中文；应用本身支持中文（不支持时这一项是灰色或不出现）。改完退出应用重开一次再看效果。

## 三、界面还是英文时的对照表

赶时间生成的话，先按这张表找到功能入口：

| 界面英文 | 对应功能 |
| --- | --- |
| Explore | 探索页，各功能入口都在这 |
| Video / Avatar Video | 数字人说话、照片动起来 |
| Photo / Image | 做图、滤镜 |
| Templates | 模板列表 |
| Upload | 上传照片或素材 |
| Generate / Create | 开始生成 |
| My Works / History | 作品记录，成片在这找 |
| Settings | 设置 |
| Subscribe / Upgrade | 订阅与会员页 |

## 四、装好第一件事

还没安装的，从 [DreamFace 玩法介绍站](https://dreamface.wrwq.fun/) 拿到安卓安装文件资源并装好；第一次打开趁还没开始用，先把语言调好，再去看 [照片跳舞唱歌怎么弄.md](照片跳舞唱歌怎么弄.md) 出第一条片子。
