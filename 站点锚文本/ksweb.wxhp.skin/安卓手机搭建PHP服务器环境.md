# 安卓手机搭建 PHP 服务器环境，从装 KSWEB 到页面跑通

想在安卓手机上跑 PHP 网站不需要刷机，也不用连电脑敲命令。一套叫 KSWEB 的安卓应用把 Lighttpd、Nginx、Apache 三种 Web 服务器和 PHP、MySQL 打包在一起，装上就能把手机当一台小型主机用，普通手机即可运行，不要求 root 权限。

## 一套应用里有什么

KSWEB 的组件是完整的建站技术栈：

- **三种 Web 服务器可切换**：Lighttpd 默认监听 8080 端口，开箱即跑；Apache 默认 8000 端口，.htaccess 伪静态规则原样生效；Nginx 供进阶配置，端口自定。
- **PHP 多版本**：从 5.6 到 8.x 可选，新框架和老系统都能对上号。
- **数据库**：MySQL 5.7 或 MariaDB 10.4，默认监听 3306。
- **配套工具**：FTP 服务、代码高亮编辑器、cron 风格计划任务、phpMyAdmin 和 Adminer 数据库管理。

各组件在应用里单独启停、单独改配置，顶部标签页之间切换。

## 从零跑通一个站点

1. 安装并打开 KSWEB，首次启动会完成组件初始化。
2. 进入 LIGHTTPD 标签页打开"开启服务"开关，状态页显示"运行中"。
3. 手机浏览器访问 `http://localhost:8080`，看到页面即环境就绪。
4. 把网站源码放进存储卡的 `htdocs` 目录（默认站点根目录），刷新浏览器就是你的站点。
5. 同一 Wi-Fi 下的电脑用状态页显示的内网 IP 加端口访问，可以直接在电脑上调手机上的站点。

## 安卓手机做服务器的两个注意点

**省电策略是头号敌人。** 手机休眠后系统可能杀掉后台服务，KSWEB 设置页里提供"关闭省电""锁定 Wi-Fi""保护服务器被非授权终止"三个选项，长期挂机建议全部开启并保持充电。

**80 端口才涉及 root。** 日常使用 8080、8000 这类高位端口功能完全一样；只有想直接绑 80 端口时才需要 root，保持默认设置即可避开。
