# 手机运行 WordPress 的方法：KSWEB 加 MySQL 就够了

WordPress 对运行环境的要求是 PHP 加 MySQL，这两样 KSWEB 都内置了，所以在安卓手机上跑 WordPress 只是"放文件、建数据库、走安装向导"三件事，不需要 root，也不需要额外装别的应用。

## 环境准备

手机上先装好 KSWEB 并启动服务：打开 LIGHTTPD 开关，状态页显示"运行中"后，`http://localhost:8080` 能访问即说明 Web 服务就绪。数据库这边，MySQL 默认监听 3306，账号 root、密码为空，装完 WordPress 后建议尽快改掉默认密码。

PHP 版本建议选 7.4 或更高的 8.x，在应用的 PHP 标签页里切换；WordPress 新版本对 PHP 8 的兼容已经很好。

## 部署步骤

1. **放源码**：把 WordPress 解压后的文件放进存储卡的 `htdocs` 目录。可以用手机文件管理器直接操作，也可以开 KSWEB 的 FTP 服务，在电脑上用 FTP 客户端整包上传。
2. **建数据库**：工具页里打开 phpMyAdmin（或 Adminer），新建一个库，比如 `wordpress`，排序规则选 `utf8mb4`。
3. **走安装向导**：浏览器访问 `http://localhost:8080`，WordPress 会自动检测出需要配置数据库，填库名、root 账号即可，主机填 `localhost`。
4. **日常访问**：同一 Wi-Fi 下的电脑或手机用内网 IP 加端口访问站点；想让公网也能打开，用设置页里的 No-IP 动态域名或配合端口路由做映射。

## 遇到问题先查这两处

- **安装向导连不上数据库**：确认状态页里 MySQL 显示"运行中"，主机名用 `localhost` 或 `127.0.0.1`，端口 3306。
- **手机锁屏后站点打不开**：到设置页开启"关闭省电""锁定 Wi-Fi""保护服务器被非授权终止"，避免系统省电策略杀掉后台服务。

手机跑 WordPress 更多用于学习、调试和小流量展示场景，写文章、改主题、试插件都顺手。KSWEB 的组件清单和其他玩法，见[安卓手机搭建 PHP 服务器环境](安卓手机搭建PHP服务器环境.md)；也可以直接到 [KSWEB 专题页](https://ksweb.wxhp.skin/) 按目录查阅。
