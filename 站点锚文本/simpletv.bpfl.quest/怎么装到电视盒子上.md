# SimpleTV 怎么装到电视盒子上

> SimpleTV 是手机、平板、电视盒子通用的安卓直播应用，但电视上没法直接用浏览器下载安装包，需要借助 U 盘、当贝市场远程推送或 ADB。本篇按设备情况帮你选一种方式，并给出每种的步骤。
> **相关文章**：[直播频道看不了怎么解决.md](直播频道看不了怎么解决.md) · [README.md](README.md)

## 一、装之前先确认两件事

1. **设备系统是安卓 6.0 及以上**：电视盒子和智能电视的安卓版本一般在「设置 → 关于」里能看到，低于 6.0 装不上。
2. **手机、平板、电视盒子用的是同一个安装包**：不需要找单独的「电视版」，应用会按设备类型适配操作方式（遥控器方向键选台或触屏滑动选台）。

安装文件的获取入口在 [SimpleTV 介绍站](https://simpletv.bpfl.quest/) 的下载页，转存下载后按下面的方式装。

## 二、U 盘安装（最通用）

1. 在电脑或手机上把安装包下载下来，拷进 U 盘；
2. U 盘插到盒子或电视的 USB 口；
3. 在电视上打开自带的「文件管理」「媒体中心」类应用，找到 U 盘里的 APK 文件，选中安装；
4. 弹出「禁止安装未知来源应用」提示时，进「设置 → 安全」打开「允许安装未知来源应用」，再回来装一次。

**TCL 电视的特例**：TCL 的系统会在普通文件管理器里屏蔽 U 盘中的 APK 文件，根本看不到它。处理办法是改用 TCL 系统自带的电视卫士类应用，它提供 U 盘安装入口，具体名称以你的 TCL 系统版本显示为准。

## 三、当贝市场远程推送（免 U 盘）

家里盒子和手机都装了当贝市场的话，可以不用拔插 U 盘：

1. 在盒子上的当贝市场进「管理」界面，找到「远程推送」；
2. 用手机扫码登录推送页面，上传提前下载好的 APK；
3. 传输完成后电视端会提示安装，确认即可，同样可能要先允许未知来源。

两个前提容易踩坑：**手机和电视必须连同一个 WiFi**；除了扫码，电视端还会显示一个网址，用电脑浏览器打开它走「上传文件」流程，效果一样——没有 U 盘时用电脑推送也很顺手。

## 四、ADB 安装（开发型用户）

手边没有 U 盘、电脑上装了 ADB 工具时可以用命令行。前提：电视开启开发者模式并允许 USB / 网络调试（通常在「设置 → 关于」里连按「版本号」几次解锁），电视和电脑连同一网络。

```bash
# 让电脑连上电视（IP 在电视的网络设置里能看到）
adb connect 192.168.1.100:5555

# 安装（路径换成电脑上 APK 的实际位置）
adb install SimpleTV_v1.0.3.apk
```

出现 `Success` 就是装完了，在电视的应用列表里找得到。不同品牌盒子的调试端口可能不是 5555，以设备说明为准。

## 五、装完第一次打开

首次启动会先初始化频道列表，随后直接进入直播画面，中间没有注册登录、也没有要填的源地址。遥控器方向键选分类、确认键呼出频道列表；手机上则是滑动选台。

如果打开后提示「初始化频道列表失败」，或多数频道转圈播不了，基本是频道源或网络条件的问题，处理顺序见 [直播频道看不了怎么解决.md](直播频道看不了怎么解决.md)。
