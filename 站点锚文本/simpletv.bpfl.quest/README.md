# SimpleTV 介绍站

SimpleTV 是一款把「看直播」做简单的安卓电视直播应用：不注册、不填源，装好打开就选台，手机与电视盒子通用同一个安装包。

本目录收录围绕 SimpleTV 的使用说明与排查文章：

- [怎么装到电视盒子上.md](怎么装到电视盒子上.md)：U 盘、当贝市场远程推送、TCL 特例，装完第一次打开会遇到什么。
- [直播频道看不了怎么解决.md](直播频道看不了怎么解决.md)：手动更新频道源、IPv6 自测与路由器设置、频道源失效的分辨。

应用的完整介绍、界面速览与安装文件资源的获取入口，见 [SimpleTV 介绍站](https://simpletv.bpfl.quest/)。
