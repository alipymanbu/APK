# 安卓小组件样式分类与改法

> 桌面装饰类应用最常见的问题是「不知道挑哪块」——这篇把五类组件各自的用途、尺寸档位和能改的项捋一遍，挑样式不再靠一个个点。

装饰类小组件的应用大多按用途分类陈列，以 Widgetsmith 安卓版为例，样式库分五类，顶部按热门 / 最新 / 分类切换，也能直接搜索。

## 一、五类样式各自适合什么

| 分类 | 适合做什么 |
| --- | --- |
| 时钟组件 | 桌面主时钟、翻页钟、指针钟这类时间显示 |
| 倒数日 | 距离某个日子还有多少天，比如考试、纪念日 |
| 唯美文字 | 放一句话、座右铭之类的纯文字组件 |
| 节日 | 节气、节日主题的应景组件 |
| 累计日 | 从某天起累计了多少天，比如在一起多少天、坚持多少天 |

想快点找到合适的样式，先翻热门是最省事的路子；风格定了再按分类细挑。

## 二、尺寸与数据源

- 组件分**小、中、大**三档，对应桌面不同的格子数，应用里添加按钮会标明档位；
- 数据源包括时间、日期、天气、日历、步数、照片相册、自定义文本，选的样式决定显示哪几项；
- 天气、日历、步数这类数据要对应权限，权限没给对应栏目会空白或停在旧数据。

## 三、能改哪些项

- **外观**：字体样式、颜色、背景色调，在具体样式的编辑页里调；
- **照片类组件**：可以选自己的照片做背景；
- **点击动作**：部分组件支持点一下启动某个应用、发短信、播放音乐，适合当快捷入口。

编辑页里没有的选项就是该样式不支持，换个样式再试；要是想要的改动超出了样式给的范围，说明该走「自己搭组件」的编辑器路线（如 KWGT），两条路线的取舍按需求定：快、零学习成本选现成样式，要完全自由再啃编辑器。

## 四、按时段换着用

可以给同一块桌面位置准备几个样式，按需要换着放：上班挂日历组件、下班换回时钟。设置完成后留意组件是否按预期变化。

样式挑好了怎么放上桌面，见 [安卓小组件上桌面的方法](安卓小组件上桌面的方法.md)；放上去不更新，见 [小组件不刷新怎么排查](小组件不刷新怎么排查.md)；配一块会动的背景，见 [动态壁纸怎么设置才省电](动态壁纸怎么设置才省电.md)。
