# 安卓小组件上桌面的方法

> 挑好了样式却卡在「怎么摆上桌面」——这篇按挑样式、登记、放置三段讲完整个流程，顺带把各家桌面入口的名字差异列清楚。

安卓桌面的小组件（窗口小工具）都走系统的组件入口，以 Widgetsmith 安卓版为例，整个流程是：先在应用里挑样式登记，再从桌面的组件列表里拖出来。

## 一、先在应用里登记样式

1. 打开应用，顶部停在「小组件」标签；
2. 按分类（时钟组件、倒数日、唯美文字、节日、累计日）或搜索找到想要的样式，点开看预览；
3. 确认后点「+ 添加小号组件」这类按钮——按钮上标的是尺寸档位，中号、大号各有对应按钮。

登记完组件就挂在这个应用名下了，接下来只是摆放。

## 二、从桌面把组件拖出来

1. 桌面空白处**长按**，出现编辑菜单；
2. 点「添加工具 / 窗口小工具 / 小组件」（叫法因桌面而异）；
3. 在列表里找到 Widgetsmith，会列出小、中、大三档尺寸；
4. 按住想要的尺寸，拖到目标位置松手；
5. 组件让你选样式时，选刚登记的那一个。

常见桌面的入口对照：

| 桌面 | 长按空白后找的入口 |
| --- | --- |
| 小米（MIUI / 澎湃 OS） | 添加工具 |
| 华为 / 荣耀 | 窗口小工具 |
| OPPO / 一加 | 小组件（或叫「插件」） |
| vivo | 原子组件（或叫「小组件」） |
| 原生安卓（Pixel 一类） | Widgets |

系统版本不同菜单名会调整，找不到就在桌面编辑模式里翻一遍带「小组件 / 小工具 / 插件」字样的选项。

## 三、放置之后

- **换样式**：长按组件进编辑，换成应用里登记过的另一个样式；
- **挪位置**：长按直接拖动；
- **移除**：长按拖到「移除」，只是拿离桌面，不影响应用里登记的样式。

更多样式挑选与改色的思路，见 [安卓小组件样式分类与改法](安卓小组件样式分类与改法.md)；放上去之后不刷新、显示旧数据，见 [小组件不刷新怎么排查](小组件不刷新怎么排查.md)。
