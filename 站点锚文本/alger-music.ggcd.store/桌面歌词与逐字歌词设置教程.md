## 全屏歌词的入口

播放任意一首歌时，**点击播放页左下角的封面**就能进入全屏歌词。整个页面只剩下歌词和底部一条进度条，前奏阶段也不会空着——即将开始的第一句会提前显示出来，跟着唱不容易接不上。

进入全屏歌词后，右上角的设置按钮可以调出**页面设置面板**，这是歌词样式的主控台。

## 逐字歌词与逐句歌词

歌词同步有两种精度可选：

- **逐字模式**：唱到哪个字，哪个字亮起来，适合想跟唱或者练歌的场景。
- **逐句模式**：一整句同时高亮，阅读感更接近传统歌词滚动，安静看词时更舒服。

如果发现歌词比歌声快了或慢了半拍，在歌词页里可以**校准同步精度**，微调几毫秒就能对上。

## 桌面歌词的三种显示模式

电脑端（Windows / macOS / Linux 版本）的桌面歌词是一个独立悬浮窗，显示模式有三种：

1. **单行**：一行歌词贴在屏幕边缘，占用空间最小，适合边工作边听。
2. **双行**：当前句和下一句同时显示，双行分组还带淡出动画，切换不生硬。
3. **滚动**：歌词像字幕一样连续滚动，看长句不容易断。

悬浮窗**双击歌词区域就能拖动位置**，不挡其他窗口的操作；翻译开关打开后，外语歌会带对照译文，内置的繁体中文翻译模块也支持直接切繁体。

## 样式细节都能调什么

打开页面设置面板，可以改的项包括：

| 设置项 | 说明 |
| --- | --- |
| 字体大小 | 滑杆调节，从小号到大号自由取值 |
| 文字间距 | 紧凑、默认、宽松三档可选 |
| 行高 | 控制多行歌词的疏密 |
| 字体粗细 | 细体看词、粗体跟唱，按习惯选 |
| 背景与宽度 | 桌面歌词窗口的底色与窗口宽度 |

手机横屏时歌词页会**自动重新排版**，控件位置跟着转过来，放在车载支架或桌面支架上看都很合适。
