# Emoke 情绪纸卷使用整理

这一组文章围绕「用一包纸卷安放情绪」这款安卓小工具整理。Emoke 把心情记录做成一分钟的仪式：选贴纸、写几句、点燃纸卷、跟着呼吸看它燃尽——没有账号，记录只留在手机里。功能演示与安装文件资源入口见 [emoke 情绪纸卷介绍站](https://emoke.uerg.quest/)。

本目录文章：

- [情绪纸卷点燃仪式怎么玩.md](情绪纸卷点燃仪式怎么玩.md) —— 从选贴纸到点燃呼吸的完整流程，以及燃烧速度、自定义标签这些小调节
- [记录只存在手机里怎么防丢.md](记录只存在手机里怎么防丢.md) —— 哪些操作会让记录消失、换机前该做什么准备
- [烟盒隐喻和戒烟传言.md](烟盒隐喻和戒烟传言.md) —— 名字里的 smoke 从哪来，「戒烟App」的分类误会怎么分辨
