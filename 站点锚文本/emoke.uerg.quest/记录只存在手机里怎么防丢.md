# 记录只存在手机里怎么防丢

> Emoke 的纸卷记录保存在哪、哪些操作会让它消失、换机时怎么把它带过去。
> **相关文档**：[情绪纸卷点燃仪式怎么玩.md](情绪纸卷点燃仪式怎么玩.md) · [烟盒隐喻和戒烟传言.md](烟盒隐喻和戒烟传言.md)

---

Emoke 没有账号体系，写下的情绪纸卷**只保存在设备本地**。这意味着两件事：别人从外部翻不到你写了什么；但手机出状况时，记录也不会自动有备份。本文把「什么时候会丢、现在能做什么」一次讲清，站内对它隐私设计的整理见 [emoke 情绪纸卷介绍站](https://emoke.uerg.quest/)。

## 一、哪些操作会丢记录

| 操作 | 记录还在吗 | 说明 |
| --- | --- | --- |
| 正常退出、重启手机 | 在 | 数据在本地库，不依赖应用前台运行 |
| 卸载 Emoke | 没了 | 卸载会清掉应用私有数据 |
| 「设置 → 应用 → 清除数据」 | 没了 | 「清缓存」一般没事，两个按钮别按错 |
| 换新手机 | 不会自动跟过去 | 没有账号、没有云同步 |
| 换机时整机迁移 | 通常在 | 走厂商换机助手这类系统级备份有机会带上，以实际迁移结果为准 |

## 二、现在就能做的四件事

1. **把 Emoke 移出清理名单**：手机提示「清理不常用应用」时，别让它一键清掉 Emoke 的数据。
2. **换机当天做一次整机备份**：用手机自带的换机 / 备份功能，在换机前再操作一次，别等新手机激活完才想起来。
3. **特别在意的纸片留个底**：在回看里翻到后自行截图或抄录——应用不提供导出，截图是最直接的兜底。
4. **闪退先排查再重装**：「卸载重装」是记录的最后杀手，能靠清后台、重开应用解决的，别走到卸载那一步。

## 三、隐私这一面怎么理解

- 记录不经过云端，配合应用内的密码锁，拿到手机的人也难以翻看。
- 想确认数据去向时，以你设备上应用的实际表现与隐私说明为准，版本之间可能存在差异。

装好之后第一次使用前，建议先把玩一遍 [情绪纸卷点燃仪式怎么玩.md](情绪纸卷点燃仪式怎么玩.md) 里的流程——知道哪些操作会动本地数据，比丢了再补救省心得多。
