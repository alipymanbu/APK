# DeepAI智能助手 生成失败与找不到作品怎么办

> 点了生成一直转圈、提示失败，或者做完的作品在相册里翻不到——这几个是用 AI 创作类应用最先撞上的墙。本篇按命中率给排查顺序。

## 点了生成没反应 / 一直转圈

按命中率从高到低排查：

| 现象 | 先查什么 |
| --- | --- |
| 全部功能都失败 | 网络是否正常；换个 Wi-Fi / 流量试一次 |
| 只有视频、音乐失败 | 这类生成耗时长，退出重进会丢任务——先等满一次，再去作品区看是否其实已生成 |
| 提示次数用完 / 需要付费 | 不是故障，是计费触发。生成类操作很可能单独计次，开跑之前先看一眼余额提示（详见 [会员收费与次数限制.md](会员收费与次数限制.md)） |
| 刚装完就各种失败 | 是否拒绝了存储 / 相机权限；或安装包与手机系统不兼容，重新覆盖安装一次再试 |
| 装完点不开、闪退 | 先看手机剩余存储（安装包 61.59M，解压运行还要占更多，留出几百 MB 余量），再覆盖安装一次；仍不行建议换渠道版本试 |

**反复失败时的止损动作**：截图（含报错文字与时间）→ 记下任务名 → 找客服反馈。生成类服务多按次扣费，失败了要留证据，方便主张返还对应次数。

## 找不到历史作品

生成结果（图、视频、音乐、PPT）都落在应用内的**个人 / 作品区**，不是系统相册——这是最容易误会的地方：

1. 进个人区按时间翻一遍；
2. 换过账号登录的，作品跟账号走，确认当前登录的是生成时那个账号；
3. 已经点过下载的，去手机相册 / 文件管理器的下载目录找；
4. 都没有且当时任务是失败中断的，作品可能从未生成成功，按上一节的排查顺序走。

**涉及人脸的写真作品**用完记得去作品区删除——应用隐私政策写明用户可随时查看、管理或删除包含面部数据的照片，这一步要自己动手，别只留着不管。另外，上传他人照片做写真前先取得本人同意，尤其成品打算发到公开平台的话。

## 两个降低失败率的习惯

- **文字类先出大纲再扩写**：写日报、总结、报告这类长文，一次要全文容易因为方向不对反复重跑，先让 AI 出大纲、改完再扩写，成功率更高；
- **视频 / 音乐每次换描述**：同一段描述连着生成，出来的内容差别不大（公开评论区有用户反馈曲词雷同），换一组完全不同的风格与主题描述再试。
