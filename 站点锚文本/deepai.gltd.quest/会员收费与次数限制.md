# DeepAI智能助手 会员收费与次数限制

> 「终身会员」买完还要再充点数？这是公开投诉里针对这款应用最高频的一类意见。本篇把计费的两层结构、开通前该做的动作和取消自动续费的路径一次讲清。

## 计费是两层，别只看第一层

第一层是**会员档位**：苹果内购说明里列过周卡、月卡、年卡、终身大会员，以及按次数的体验卡（示例价：体验卡 38 元给 15 次、终身 198 元，各渠道各时期价格可能不同，以支付页面当时显示为准）。

第二层是**点数类消耗**：公开投诉平台上有用户反馈，买了「终身大会员」之后，生成视频、绘画等操作仍会按次扣金币，金币耗尽要再充值。两层的规则都会写在应用内的购买页与协议里。

**支付前把「本档位含多少次 / 多少金币、用完之后怎么算」看清并截图**——这是后续所有争议里最有用的一张证据。

## 开通前的三个动作

1. **分清「单次」和「连续包月」**：支付按钮旁写着「自动续费」的，到期会自动扣款；只想买一个月，就选不带续费字样的选项。
2. **取消默认勾选**：页面把「自动续费」预勾上时手动去掉，确认最终按钮显示的是你打算买的档位再付款。
3. **截图留证**：把购买页（含价格、周期、续费字样）连同支付记录一起存好。

## 怎么取消自动续费

按当时的支付渠道关，关完**当场验证**（回订阅页看状态变成「已取消」才算数）：

- **iOS**：设置 → 顶部 Apple ID → 订阅 → 选中该应用 → 取消订阅（到期前 24 小时内操作要留余量）；
- **微信**：我 → 服务 → 钱包 → 支付设置 → 自动续费 / 扣费服务 → 关闭对应项目；
- **支付宝**：我的 → 设置 → 支付设置 → 免密支付/自动扣款 → 关闭该签约；
- **应用内**：「我的」里的会员 / 订阅入口也有取消开关，找不到就走支付渠道那条路，一样有效。

取消只停**未来**的扣款，当期已付的周期照常可用完。

## 被扣款了怎么主张

消费者权益相关的法规要求经营者在自动续费前**五日以显著方式提醒**用户。如果你的扣款通知并没有真正送到手上（翻一遍通知记录、站内信、短信），这就是主张时最有分量的一条依据。通用顺序：先联系客服说明「未获显著提醒」要求退款；协商无果拨 12345 或通过全国消协智慧 315 平台在线反映；全程保留扣款记录、协议截图与沟通记录。

## 付费前的一句话建议

生成类功能的输出质量波动较大，公开渠道的高频反馈集中在「会员之外仍限制次数」「生成结果与预期不符」这类意见上。**先用最低成本档位验证它能不能干你要的活**，能干再考虑长期档；别被「终身」两个字带着直接买最高档。
