# 安卓手机安装直播应用的完整步骤

> 本篇讲把 twitchtv（Twitch 安卓客户端）装进安卓手机的完整过程：从网盘分享页转存、下载 APK、放行未知来源安装，到装不上时的三类常见现象处理。
> **相关文档**：[看直播领游戏道具的掉宝玩法入门](看直播领游戏道具的掉宝玩法入门.md) · [用一部手机开播游戏实况的入门条件](用一部手机开播游戏实况的入门条件.md)

## 一、动手前先核对两件事

- **存储空间**：安装包约 120M，建议手机剩余存储留足 2G 以上，太满会装到一半失败。
- **系统版本**：安装包标注安卓 5.2 及以上可装；版本太老的设备会报解析包错误。

## 二、安装四步

1. **打开分享页，转存到自己网盘**：安装包通过夸克网盘分享，按页面提示把文件转存到自己的网盘账户——分享文件需要先转存，才能在自己网盘里下载。
2. **把 APK 下载到手机**：在自己网盘里找到转存好的安装包，下载到手机存储（通常落在 Download 目录）。
3. **点按安装，放行未知来源**：用文件管理器点按刚下载的 .apk；系统提示「禁止安装未知来源应用」时，按提示跳到设置里允许文件管理器安装应用，再返回继续装。
4. **打开应用**：装完点「打开」，首次进入会联网加载几秒。界面语言跟随系统语言，系统是中文界面就是中文。

不登录也能浏览和观看直播；发弹幕、关注频道、攒点数、领掉宝这些参与性质的功能，登录账号后才会解锁。

## 三、装不上的三类现象

| 现象 | 原因与处理 |
| --- | --- |
| 解析包错误 | 多半是下载不完整，删掉重新下载再装；再核对系统版本是否达标 |
| 安装到一半失败 | 存储空间不足，清出空间后重试 |
| 应用未安装 | 手机里已有更高版本的同包名应用，系统不允许降级覆盖，先卸载再装 |

装好之后，先去 [twitchtv 介绍站](https://twitchtv.bmww.store/) 把功能与玩法过一遍，再看掉宝篇学领游戏道具，或开播篇学用手机开一场直播。
