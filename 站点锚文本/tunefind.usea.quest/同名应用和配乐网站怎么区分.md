# 同名应用和配乐网站怎么区分

在搜索框输入 tunefind，排在前面的结果其实来自两个不相干的东西：一个是查影视剧配乐的国外网站，一个是安卓端的音频剪辑应用。名字一模一样，找错了就会一头雾水——想剪铃声的人点进一个「查歌」网站，想查歌的人下了一个剪辑 App。

## 一、两个分别是什么

**tunefind.com**：2005 年就上线的国外网站，收录影视剧、游戏里出现过的歌曲——「刚才那集美剧片尾曲是什么」这类问题去那里查。它是纯网页服务，自己也说明过目前没有推出 App。有人打着它的旗号发安装包，那些来路不明的包反而要当心。

**tunefind 音乐剪辑（安卓应用）**：装在手机上的音频编辑工具，中文语境里常写作「tunefind音乐」「tunefind音乐剪辑」。功能围绕波形编辑展开：剪切、淡入淡出、拼接、混音、MP3/WAV/FLAC 转换、人声伴奏分离，剪好的片段能直接按铃声用途导出。

## 二、三秒分清的办法

| | 配乐网站 tunefind.com | 安卓应用 tunefind |
| --- | --- | --- |
| 形态 | 网页，浏览器直接访问 | 安装到手机的应用 |
| 用途 | 查「这部剧的歌单」 | 剪音频、做铃声、拆人声 |
| 判据 | 域名以 .com 结尾 | 安卓安装包，包名 com.tunefind.ljhsafa |

最稳的判据是包名：`com.tunefind.ljhsafa` 对上的才是这里说的音频剪辑应用。

## 三、想剪铃声的去哪动手

如果是冲着「把自己歌单里的歌剪成铃声」来的，要的是后者。[tunefind 介绍站](https://tunefind.usea.quest/)整理了它的功能细节、界面实拍与安卓安装文件的获取方式；具体的剪铃声流程可以接着看[手机剪音乐做铃声的完整流程](手机剪音乐做铃声的完整流程.md)，剪完想给翻唱垫伴奏的再看[手机上怎么把人声和伴奏分开](手机上怎么把人声和伴奏分开.md)。

至于查配乐，直接浏览器访问那个 .com 网站就行，不需要装任何东西。
