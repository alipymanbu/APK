# 线下应援活动怎么参与

> 本篇讲 kooky 的 Kooky Map 活动地图怎么用：怎么按城市找生日咖啡应援和快闪、自己办的活动怎么提交、以及活动与积分体系的联动。投票与积分的完整规则分别见[打榜投票从攒票到正赛](打榜投票从攒票到正赛.md)和[签到积分和社区玩法速查](签到积分和社区玩法速查.md)。

---

## 活动信息终于有了一个集中地

K-pop 的线下应援——生日咖啡应援、快闪店、观影会、应援棒分发——信息长期散落在各个社交平台的角落里，错过了就只能看别人晒图。kooky 把这些信息汇进了同一张地图：打开应用里的 Map 页（网页端在 Event 标签），就能按位置浏览附近正在发生的活动。

地图页很直观：每个城市用气泡标注活动数量，点开就能看活动详情，比如某个生日应援咖啡店的档期、打卡规则和现场布置照片。

## 自己办活动：提交规则要记牢

在地图页点提交按钮就能登记活动，有 Kooky 奖励：

- **通用活动**：提交审核通过得 200 Kooky；
- **照片墙类活动**（Photo Booth）：得 50 Kooky。

提交前注意几条硬规则，不然会被拒：

1. **带上组合名**：哪怕是单个成员的活动，也要写明所属组合的标签；
2. **提前至少一周提交**：审核要 2–5 个工作日，临时抱佛脚来不及；
3. **不要按天拆分**：「Day 1 / Day 2」要作为同一场活动提交，别拆成两条；
4. **只提交已在库的艺人**：艺人信息对不上会被拒。

## 活动与积分、投票的联动

活动体系不是孤立的：提交活动拿的 Kooky 可以直接投进正赛；平台还有应援赞助机制，粉丝为偶像办的咖啡应援若在站内投票中胜出，有机会拿到平台的赞助支持。线下露出的天花板更高——Ranking 的胜者奖励包括首尔地铁广告和海外线下电子屏，这些在[打榜投票从攒票到正赛](打榜投票从攒票到正赛.md)里有完整说明。

对经常跑线下活动的粉丝来说，惯用的组合是：地图上找活动 → 现场打卡拍照 → 回社区发帖记录 → 用攒下的 Kooky 继续投票，一整套参与感拉满。
