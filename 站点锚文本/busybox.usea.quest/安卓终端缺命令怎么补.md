# 安卓终端缺命令怎么补

在安卓的终端模拟器里敲命令，撞到 `awk: not found`、`wget: not found` 是家常便饭——不是手机坏了，而是安卓自带的 shell 只带最基础的几条命令，文字处理、下载、归档这类 Unix 工具一概没随系统出厂。想补齐这套命令，最省事的路子就是装 [BusyBox](https://busybox.usea.quest/)，一篇讲清它的来历和机制的文章见 [瑞士军刀式的命令工具是怎么回事](瑞士军刀式的命令工具是怎么回事.md)。

## 一个文件变出几百条命令

这类工具的实现思路和"把一堆命令逐个塞进手机"完全不同：磁盘上只放一份体积一兆上下的可执行文件，其余的 awk、sed、gzip、ps，全部是指向这份文件的符号链接。程序启动时看自己被叫成了什么名字，就表现得像哪条命令——所以同一份文件，既能当 awk 解析文本，也能当 wget 下载网页。这套机制有个专门的说法，叫多调用二进制（multi-call binary）。

对使用者来说，感受就是"装了一个东西，终端里多了几百条命令"。装进系统的路径通常是 /system/xbin 这类分区，装完后命令可以带前缀敲（`busybox awk`），也可以直接敲短名字（`awk`），后者依赖安装时建好的链接。

## 补上命令之后能干什么

- 终端里处理文本：日志取列、批量替换、按条件筛行，awk 加 sed 基本全覆盖；
- 直接在手机上下载和传输：wget、tftp 这类网络小工具随取随用；
- 归档与解包：tar、gzip、unzip 处理压缩包不用再倒腾电脑；
- 更重要的是让别人的脚本能跑起来：不少 root 应用和刷机脚本默认环境里有这套命令，缺了就报错。

## 动手前的一个前提

往系统分区写文件这件事，绕不开 root 授权。没 root 的机器装不上、也用不了，这是这类工具和其他安卓应用最大的区别。确认手机已有 root 之后，从哪里拿安装文件、装完怎么验证，下方的介绍站把步骤拆得很细。

装完最好在终端里敲一次 `busybox`：回显开头出现版本号加一长串命令名，就说明链接都建好了；如果回的是 `command not found`，通常是安装路径没进终端的搜索路径，换个常用路径重装一遍即可。
