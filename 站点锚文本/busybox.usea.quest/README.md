# BusyBox 锚文本文章 @ busybox.usea.quest

这里收录围绕 BusyBox（安卓终端命令补全工具）整理的介绍文章。内容面向想在手机终端里补齐 awk、sed、wget 等 Unix 命令的 root 用户：工具的单文件多命令原理、安卓上的实际用途、脚本环境的准备，都整理成了独立成篇的短文。

- [安卓终端缺命令怎么补](安卓终端缺命令怎么补.md)：从 `awk: not found` 这类报错说起，讲清这类工具靠一个文件变出几百条命令的机制。
- [root 手机跑脚本前要补的命令环境](root手机跑脚本前要补的命令环境.md)：脚本依赖哪些命令、root 方案自带的那份和你装的这份是什么关系。
- [瑞士军刀式的命令工具是怎么回事](瑞士军刀式的命令工具是怎么回事.md)：从 1996 年的一张软盘讲到今天路由器和手机里的常驻组件。
