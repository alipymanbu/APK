# 绘画描述四要素写法

> 一句话概括：在 GammaAI 里写文生图描述，把一句话拆成主体、细节、风格、氛围四块来组织，出图方向会稳定很多——本篇给拆法、改写对照和出图不对时的排查顺序。

## 一、一句话拆成四块

写描述前先按顺序想四个问题：

| 要素 | 回答的问题 | 举例 |
| --- | --- | --- |
| 主体 | 画的是什么 | 一只圆脸橘猫 |
| 细节 | 在做什么、什么姿态 | 蜷在藤椅上打盹 |
| 风格 | 用什么画法呈现 | 3D 渲染 |
| 氛围 | 什么光线、色调 | 傍晚暖光 |

四块拼起来就是一句可用描述：`一只圆脸橘猫蜷在藤椅上打盹，3D 渲染，傍晚暖光`。只写「一只猫」也能出图，但结果基本靠运气。

## 二、从弱到强的改写对照

同样一个念头，两种写法拿到的东西差别很大：

| 弱写法 | 强写法 |
| --- | --- |
| 一个机器人 | 蹲在雨里检修天线的小型巡检机器人，外壳有掉漆，写实机械风，冷色夜光 |
| 一片森林 | 雾气未散的针叶林，晨光从树缝斜切下来，横构图，油画质感 |
| 一张海报 | 复古网球赛海报，米黄底色，大字标题居中，扁平插画风格 |

规律只有一条：把抽象的形容词换成看得见的画面。想要「高级感」，就写材质、配色和构图；想要「可爱」，就写圆脸、大眼睛这类具体特征。

## 三、图生图与相似图生成的描述重点

这两种方式不用重新介绍画面，写法各有侧重：

- **图生图**：重点写「要改成什么」——「保留原图构图，把照片改成手绘动画风格」「背景换成雪天，人物不动」；
- **相似图生成**：描述可以更短，只想控制方向时补一句风格说明，比如「再暗一点、偏冷色调」。

比例、数量这类选项以应用内页面提示为准，思路不变：说清保留什么、改变什么。

## 四、出图不对时的排查顺序

1. **描述太短**：不到十个字，先补齐四要素再重试；
2. **主体太多**：一句话塞五六个东西出图会乱，一张图聚焦一个主体，要多个就写清位置（左边、右边、前景）；
3. **一次改太多**：退回上一版，每次只动一处，才知道是哪句话起的作用；
4. **风格词打架**：又写「写实」又写「卡通」会两边不靠，留一个主风格。

按顺序排完还不满意，切到「应用」标签用绘画提示词润色工具把草稿扩写一遍再试。生成一直失败或卡住是另一类问题，多与网络和高峰排队有关，换个时段往往就好了。
