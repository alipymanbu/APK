# 追番记录客户端怎么选

> bgm.tv（番组计划）的账号体系是开放的，围绕它出现的安卓客户端也不止一个。这篇把常见的几款摆在一起，说清差别与分辨办法，给搜「追番记录 app」的读者一个对号入座的依据。

## 先分清平台与客户端

很多新朋友容易把两件事混在一起：**bgm.tv 是一个资料库与社区网站**，收录动画、书籍、音乐、游戏的条目，用户在上面标记想看、在看、看过，给作品打分写评论；而**客户端**只是连接这个社区的工具，装在手机上用起来更顺手。账号只有一个（注册在 bgm.tv），客户端可以换着用，数据都不会丢。

## 常见的两个开源安卓客户端

社区里活跃维护的开源客户端主要有两支，定位不太一样：

- **czy0729 开发的 Bangumi 客户端**（包名 `com.czy0729.bangumi`）：用 React Native 写成，把网站的 100 多个页面按移动端重新排版，除了进度管理、每日放送、超展开这些基本盘，还补了封面 CDN 加速、bilibili 与豆瓣的有限同步、词云、AI 推荐这类网页端没有的加强，自定义选项也多。功能分区与获取渠道可以看 [Bangumi 安卓客户端介绍](https://bangumi.fewf.click/)。
- **xiaoYv 维护的 Bangumi App**（包名 `com.xiaoyv.bangumi`）：另一位开发者的作品，界面与交互是另一套思路，整体更轻量，同样开源。

两个客户端连的都是同一个 bgm.tv 账号，收藏、评分、进度实时互通；但**安装包完全不通用**，签名不同，也没法互相覆盖升级。本地设置（主题、缓存这类）也不会跟着账号走，换客户端要重新调一遍。

## 装错版本是新人最常见的坑

由于这类开源作品不进国内应用商店，商店里能搜到的同名安装包多是第三方转载，版本滞后不说，还经常和别的客户端混在一个搜索结果里。装之前花几秒核对**包名**最稳妥：

| 包名 | 对应作品 |
| --- | --- |
| com.czy0729.bangumi | czy0729 的 React Native 客户端 |
| com.xiaoyv.bangumi | xiaoYv 的轻量客户端 |

拿不准自己适合哪支，就看使用侧重：想把网页端的完整体验搬到手机上、喜欢折腾自定义的，选前者；只求快速点格子记进度的，后者够用。两者切换成本都低——登录同一个账号，数据原样都在。
