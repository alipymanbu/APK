# 手机配网与连接排查

> 本篇汇总正浩 EcoFlow 电源连进手机应用的三种方式（IoT、直连、蓝牙）怎么选、配网失败的
> 常见原因与设备离线的处理思路。
> **相关文档**：[户外电源怎么用手机控制](户外电源怎么用手机控制.md)

## 一、三种连法先选对

| 方式 | 连接原理 | 适合场景 | 主要限制 |
| --- | --- | --- | --- |
| IoT 模式 | 设备连家庭 Wi-Fi 联网 | 远程控制、固件升级 | 只支持 2.4 GHz；断网就离线 |
| 直连模式 | 手机连设备自己的热点 | 户外无 Wi-Fi | 不能升级固件、不能解绑 |
| 蓝牙模式 | 手机与设备蓝牙配对 | 近距离快控 | 距离远了会断 |

应用没装好的先去把应用装上，获取入口见 [ecoflow 应用站](https://ecoflow.fewa.skin/)，装好后再回来照着配。

## 二、IoT 配网五步

1. 设备列表页点右上角「+」，选你的机型；
2. 按提示长按设备上的 IOT 键，直到屏幕 Wi-Fi 图标闪烁，回应用勾选确认；
3. 手机 Wi-Fi 设置里连接名称以 EcoFlow 开头的热点；
4. 回到应用，在联网配置页选中家里的 Wi-Fi 并输入密码；
5. 等设备联网成功，列表里出现它就是配好了。

## 三、配网一直失败，查这四条

- **频段**：设备只认 2.4 GHz Wi-Fi，5 GHz 搜不到；双频路由器常拆成两个名字，认准不带 5G 字样的那个；
- **密码**：输错设备就上不了网，删掉重输；
- **图标没闪**：长按 IOT 键后 Wi-Fi 图标必须闪烁才算进了配网状态，没闪就重按；
- **Wi-Fi 本身**：拿手机连同一个 Wi-Fi 验证能不能上网，断网的 Wi-Fi 配了也白配。

## 四、设备显示离线

IoT 模式下离线基本是设备端断网：路由器重启过、离路由器太远、家里停电都会导致；设备重新联网后应用不一定立刻恢复，重开设备列表等刷新。户外改用直连或蓝牙时注意：直连模式下手机自己连回了家庭 Wi-Fi，设备就会从列表消失——这是正常的。

二手买来的设备搜不到、绑不上，多半还绑在原主人的账号下：一台设备只属于一个账号，让原账号解绑后才能绑到自己名下。

## 五、升级固件的前提

固件升级只在 IoT 模式（设备联网）下能做，直连和蓝牙没有升级入口；升级时电量充足或接着市电、手机别锁屏、人守在旁边。升级卡住或失败的处理顺序：按页面提示重试 → 试应用里的「离线升级」→ 仍不行就带着设备型号与版本号找售后。
