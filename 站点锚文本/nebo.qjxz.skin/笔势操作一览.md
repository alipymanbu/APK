# Nebo 笔势操作一览

> 本篇收 Nebo 常用的笔尖动作：删除、强调、图形成形、选择、高亮，以及四种笔记页面各自怎么触发转换。
> **相关文档**：[手写转文字准确率提升](手写转文字准确率提升.md) · [安卓版安装步骤与首次设置](安卓版安装步骤与首次设置.md)

---

## 五个笔势，顺手就记住

| 动作 | 做法 |
| --- | --- |
| 删除 | 在文字上横向划掉 |
| 强调 | 在文字下方画下划线 |
| 图形成形 | 画完直线、圆、箭头后笔尖停住不抬，自动变标准形 |
| 选择 | 用套索圈住内容，可整体移动、复制、改色、转文字 |
| 高亮 | 换马克笔书写，或用马克笔涂抹 |

不用翻菜单，笔尖动作本身就是操作。转换后的图形粘到 PowerPoint 里仍保持可编辑。

## 四种页面，转换的触发方式不一样

| 类型 | 版面 | 转换触发 |
| --- | --- | --- |
| 笔记本 | 固定尺寸页，页数不限 | 套索圈选后转换 |
| 文档 | 无限纵排、自动重排 | 双击整段转换 |
| 白板 | 无限画布，可缩放平移 | 套索圈选后转换 |
| PDF | 导入的文件逐页批注 | 套索圈选后转换 |

创建任一类型都要先选「书写语言」，选定后这一篇不能改；英语始终被同时识别，不用单独装。

## 误删与卡顿的两条冷知识

- 删掉的笔记、文件夹和集锦会先进应用内的**回收站**，可以恢复，清空之前先扫一眼；
- 笔记很长、PDF 很大时翻页会变卡：把长笔记拆成短篇，导入的 PDF 先精简页数再导入。
