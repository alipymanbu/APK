# 安卓手机安装步骤与常见拦路问题

> 本篇讲 reccloud（录咖）安卓版从网盘转存到装进手机的完整步骤，以及安装被阻止、解析包出错、装完闪退三种最常见的拦路情况的处理办法。
> **相关文章**：[录音转文字从录音到成稿.md](录音转文字从录音到成稿.md) · [视频字幕与多语翻译实操.md](视频字幕与多语翻译实操.md)

reccloud（录咖）的安卓安装包通过夸克网盘分发，不依赖任何应用商店。整个过程手机上就能完成，装好的应用长什么样、有哪些功能，可以先去 [reccloud（录咖）介绍站](https://reccloud.fewf.ren/) 过一眼再决定装不装。

## 一、四步装好

1. **转存**：从[介绍站的下载页](https://reccloud.fewf.ren/download.html)进入网盘分享页，登录夸克账号，把安装包转存到自己网盘——转存后这份资源就长期跟着你的账号了；
2. **下载**：在网盘里选中 `reccloud_v1.5.7.apk`（约 102M）下载到手机，建议连 Wi-Fi；
3. **授权**：首次点开安装包，系统会要求先给「点开文件的那个应用」（网盘客户端或文件管理器）开「安装未知应用」权限，按提示跳到设置打开开关，返回再点一次安装包；
4. **安装**：点「安装」等十几秒，装完打开应用；首次用实时录音时授予麦克风权限，读视频、导文稿需要存储权限。

## 二、三种最常见的拦路情况

**点安装包提示「禁止安装」**
授权对象没选对。安卓的「安装未知应用」是按应用单独授的：用夸克客户端下的就授权夸克，用文件管理器点的就授权那个管理器。路径：设置 → 应用 → 特殊访问权限 → 安装未知应用。这个授权只需做一次。

**提示「解析包时出现问题」**
多半是文件没下完整。先确认网盘任务显示下载完成，删掉安装包重新下一次；反复出现就换一下网络（Wi-Fi 与流量互切）再下。

**装好了一点开就闪退**
按顺序来：重启手机 → 检查剩余存储（安装包 102M，装完再留几百兆余量给缓存）→ 系统设置里清一遍应用缓存。仍闪退通常是机型兼容问题，等应用版本更新修复。
