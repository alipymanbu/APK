> 这里整理了几篇围绕 OCAT 的使用思路文章：为什么背句子比背单词更接近真实口语、想说什么就问什么的查询方式、以及磨耳朵与跟读的日常安排。

OCAT 是一款通过与 AI 对话练口语的应用：用母语把想说的句子问出来，得到带平假名注音、可点读的地道说法，摘进收藏夹反复听。它的名字源自日语「おしえて（oshiete）」，意思是「请教教我」——每遇到一句不会说的话，就问一句、收一句。

想快速了解它的一条完整学习循环（问句子 → 收藏 → 循环播放 → 跟读验证），可以看这篇第三方介绍站：[OCAT](https://ocat.boop.uno/)，里面有按循环展开的图文说明，也整理了安卓安装文件资源的获取入口。
