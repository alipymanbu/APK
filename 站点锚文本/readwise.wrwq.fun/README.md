# Readwise 导览：划线收集、每日回顾与导出笔记的索引

这里是 Readwise（阅读划线回顾工具，含其阅读器 Readwise Reader）的第三方介绍索引：它把 Kindle、Apple Books、纸书拍照、Pocket、Instapaper、Goodreads 等来源的划线摘录收进同一条信息流，再用间隔重复的「每日回顾」帮你记住读过的内容。功能与安装介绍站见 <https://readwise.wrwq.fun/>。

## 一句话背景

Readwise 自 2017 年运营至今，靠订阅制维持：主应用负责划线的回顾与导出，Readwise Reader 负责稍后读、RSS、PDF、EPUB 等内容的阅读与标注，两端共用同一套账号。30 天试用、注册无需填信用卡。

更多机制讲解、两套应用的分工与安卓安装文件资源获取方式，见 [Readwise 划线回顾站](https://readwise.wrwq.fun/)。
