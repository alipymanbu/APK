# UTAU 手机版歌声合成入门

UTAU 圈的老玩家对「排音符 → 调参数 → 导出」这套流程再熟不过，但过去这一切基本拴在电脑上。随着 OpenUtau 项目的移动端落地，手机也能完整走完这条线了。这篇把入门要弄懂的三件事捋一遍：它是什么、和桌面版什么关系、以及从哪里开始。

## 它和 UTAU 是什么关系

OpenUtau 是 UTAU 社区的开源后继项目：兼容 UTAU 声库与重采样器，编辑器换成了现代化的钢琴卷帘，支持颤音编辑、音素扩展与实时预览。桌面版覆盖 Windows、macOS 与 Linux；而安卓端以 OpenUtau Mobile 的形态出现，把核心编辑能力压缩进了触屏。

简单说：声库资产是同一批，工程格式能对上，编辑思路一致，只是操作从鼠标键盘换成了点按与手势。

## 手机端能做什么

- 导入带 oto.ini 配置的标准 UTAU 声库，中日英等多语言音源都能认；
- 触控钢琴卷帘上排音符：点按放置、长按改时长、双指缩放工程；
- 拖锚点调音高与动态曲线，颤音按段微调，另有 AI 音高校正辅助对齐；
- 多轨编排，主唱之外可叠和声，每轨指定不同歌手；
- 实时试听，成曲导出 WAV 或 MP3。

各项能力的实操细节，另见[声库导入与歌手设置要点](声库导入与歌手设置要点.md)与[ustx 工程手机与电脑互通](ustx工程手机与电脑互通.md)两篇。

## 从哪里开始

建议的路径是：先把介绍与功能主线过一遍，建立整体印象——[OpenUtau Mobile](https://openutau.ggcd.store/) 整理了安卓版的安装文件资源入口，页面里的工作流四步正好可以当作第一首试试水的歌的路线图。

装好后别急着追求成品，先拿一段熟悉的旋律排八个小节，把「放音符 → 指定歌词 → 试听」这条最小循环跑顺，剩下的参数打磨都是时间问题。
