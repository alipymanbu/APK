# IGXE 安卓版怎么下载安装

> 本篇讲怎么把 IGXE 安卓客户端装到手机上：安装包从哪里拿、安装步骤、装不上的常见处理，以及装好后的第一件事。
> **相关文章**：[手机端怎么交易饰品.md](手机端怎么交易饰品.md) · [平台是做什么的.md](平台是做什么的.md)

IGXE 的安卓客户端体积不小（约九十兆），装好后手机号注册即可登录。安装包与界面介绍都整理在 [IGXE 安卓客户端介绍站](https://igxe.fwen.ren/)，站内的下载按钮直接指向网盘分享，本篇把流程拆开讲一遍。

## 一、安装包从哪里来

安装包放在网盘分享里：打开介绍站的下载按钮，登录网盘账号后先转存到自己的网盘，再从网盘下载到手机存储——网盘分享文件需要先转存再下载，这是常规流程。转存到自己账号还有个好处：文件一直留着，换手机重装时不用再找一次。

## 二、安装步骤

1. 把 APK 下载到手机存储后，用文件管理器点开它。
2. 首次安装会提示「不允许安装未知来源应用」，按手机品牌去设置里放行：
   - 小米 / Redmi：设置 → 隐私保护 → 特殊权限 → 安装未知应用；
   - 华为 / 荣耀：设置 → 安全 → 更多安全设置 → 安装外部来源应用；
   - OPPO / vivo / 一加：设置 → 安全（或「其他设置」）→ 安装未知应用。
   放行对象选你用来打开 APK 的那个应用（浏览器或文件管理器），不必全局放开。
3. 回到文件管理器重新点开 APK，点「安装」，等进度走完。
4. 桌面出现 IGXE 图标，打开后用手机号注册或直接登录。

## 三、装不上？按这三条排查

- **提示「解析包出现问题」**：多半是下载不完整，删掉 APK 回网盘重新下载；反复失败再确认手机系统版本是否过低。
- **点开没反应**：部分机型的文件管理器要先长按 APK 选「安装」，直接点开只是预览。
- **装好但打不开**：重启一次手机；仍不行就卸载重装，并检查剩余存储空间。

## 四、装好后的第一件事

登录后先别急着下单：进「账号安全」设置支付密码，然后按 [手机端怎么交易饰品.md](手机端怎么交易饰品.md) 第一节把 Steam 绑定四件事补齐——库存公开、交易链接、API Key、加速器，一样都不能少。平台本身的定位与玩法可以看 [平台是做什么的.md](平台是做什么的.md)，租赁玩家直接翻 [饰品租赁玩法与规则.md](饰品租赁玩法与规则.md)。
