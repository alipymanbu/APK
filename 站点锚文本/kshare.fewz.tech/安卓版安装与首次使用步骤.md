# KShare 安卓版安装与首次使用步骤

> 想让手机当投屏发送端，先把安卓客户端装上。本篇从拿安装包讲到连上第一块大屏，四步走完即可开投。
> **相关文档**：[手机投屏到会议大屏的连接方法.md](手机投屏到会议大屏的连接方法.md) · [手机变遥控器反向控制大屏.md](手机变遥控器反向控制大屏.md)

---

KShare 的安卓客户端负责发送端这一侧：镜像投屏、推送音视频与文档、反向控制大屏都从这里发起。装它不需要折腾，唯一要留意的是安卓系统的未知来源拦截——按下面四步走一遍就清楚了。

## 一、拿到安装包

安装文件资源的获取入口整理在 [KShare 安卓版下载安装](https://kshare.fewz.tech/) 页面，从那里进入网盘分享页，把安装包**先转存到自己的网盘账号、再下载到手机本地**。转存这一步别省，直接下载大文件偶尔会中途失败，转存后文件在自己网盘里长期有效。

## 二、允许未知来源安装

点开下载好的安装包，系统大概率会弹"禁止安装未知来源应用"的提示。处理路径是固定的：

1. 进「设置 → 安全」（部分品牌在「设置 → 应用管理 → 特殊权限」）；
2. 找到「安装未知应用」；
3. 给浏览器或网盘客户端允许安装权限；
4. 回到下载位置，重新点安装包继续。

不同品牌手机路径叫法略有差异，认准"安装未知应用"这个关键词即可。

## 三、首次运行授权

装完打开 KShare，首次运行会陆续申请几项权限，都与投屏直接相关：

- **本地网络 / WLAN 信息**：用于发现同一 WiFi 下的接收端设备；
- **照片与媒体访问**：投照片、投视频时要读取媒体文件；
- **弹窗与悬浮窗类提示**：镜像投屏期间可能用到，按需允许即可。

权限给少了功能会受限制，后续在系统设置里随时可以补授。

## 四、连上第一块大屏

授权完成后就是连接环节：让手机与接收端连同一个 WiFi，设备列表里点「连接」；列表为空就手动输入大屏显示的 IP 地址或投屏码。连上之后先试镜像投屏，再用遥控器页翻翻大屏界面，整套流程就通了。连接细节与反控玩法见本目录相关文档。

版本方面，应用商店与网盘渠道的更新节奏不同，装哪个版本以获取页面当时显示为准；若后续要换设备或重装，把安装包留在自己网盘里最省事。
