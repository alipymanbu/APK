# CS2 饰品浮点值查询方法

> 想知道自己那把 AK 到底「新」到什么程度，靠游戏里五档磨损等级远远不够——同样是久经沙场，两件的实际磨损可能差出好几倍，价格也一样。本篇讲浮点值、图案编号分别是什么，以及用 CSFloat 手机客户端怎么查到小数点后十几位。

## 浮点值与磨损等级

每件 CS2 饰品在生成那一刻会被写上一个 0.000 到 1.000 之间的小数，代表磨损程度，生成后终身不变。五个磨损等级对应的区间全游戏统一：

| 等级 | 缩写 | 浮点区间 |
| --- | --- | --- |
| 崭新出厂 | FN | 0.00 – 0.07 |
| 略有磨损 | MW | 0.07 – 0.15 |
| 久经沙场 | FT | 0.15 – 0.38 |
| 破损不堪 | WW | 0.38 – 0.45 |
| 战痕累累 | BS | 0.45 – 1.00 |

注意：不是每件饰品都能取遍 0 到 1，部分皮肤天生开不出崭新出厂。所以挑饰品看精确浮点，比只看等级更细。

## 图案编号（paint seed）

浮点之外还有一个 0 到 999 的整数，决定纹理贴图在模型上的位置。多数皮肤不同编号肉眼看不出差别，但对 Case Hardened、Fade、Crimson Web 这类涂装差异巨大——AK-47 | Case Hardened 的 661 号（俗称 Blue Gem）就是被收藏者追捧的例子，同款其他编号价格可能差出几十上百倍。

## 在手机上查

CSFloat 的手机客户端内置饰品数据库，收录十亿量级的皮肤记录：浏览市场时每件 listing 直接标出精确浮点；查具体某一件，把 CS2 库存里右键复制的检视链接（`steam://` 开头）粘进浮点查询页，返回精确浮点、图案编号、贴纸磨损等明细。

手机上装 CSFloat 客户端的方式，见 [CSFloat 手机版介绍站](https://csfloat.xnyx.quest/)，安装文件资源的获取入口也在那里。
