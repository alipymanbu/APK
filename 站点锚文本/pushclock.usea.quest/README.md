# PushClock 介绍站 · 文档目录

本目录收录围绕 PushClock（一款用任务关闹钟的强力闹钟 App）整理的介绍与使用文章。PushClock 没有贪睡键：闹钟响后要做完俯卧撑、拍照验证或脑力题才能停铃，适合被「再睡五分钟」反复折磨的起床困难户。功能总览、界面与安卓版安装包获取入口见 [PushClock 任务闹钟介绍站](https://pushclock.usea.quest/)。
