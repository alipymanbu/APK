# aria2 移动端与参数资料索引

> 这个目录收录围绕 aria2 下载引擎的第三方整理资料：它是什么、在安卓手机上怎么跑、常用参数怎么配。

---

aria2 是一个支持 HTTP/HTTPS、FTP、SFTP、BitTorrent 与 Metalink 的命令行下载引擎，靠 JSON-RPC 接口被各类图形前端控制。目录里的几篇各自独立成篇，按需取阅：

- [多协议下载引擎是什么.md](多协议下载引擎是什么.md) —— 协议面、控制方式与常见使用场景；
- [手机端下载与远程遥控用法.md](手机端下载与远程遥控用法.md) —— 安卓两条路径：内置引擎本机下载、远程遥控服务器；
- [BT磁力下载与断点续传参数.md](BT磁力下载与断点续传参数.md) —— `-x`、`-s`、`-j`、`-c` 等参数对照与 BT 预期管理。

想按界面截图一步步对照操作，可看整理好的 [aria2 移动指南](https://aria2.rggd.pw/)，两页覆盖介绍与安装。
