# 手机端下载与远程遥控用法

> 在安卓上跑 aria2 有两条路径：引擎内置在应用里本机下载，或者把手机当作远程服务器的遥控器。
> **相关文档**：[多协议下载引擎是什么.md](多协议下载引擎是什么.md) · [BT磁力下载与断点续传参数.md](BT磁力下载与断点续传参数.md)

---

手机上既没有命令行习惯，也不总开着电脑，aria2 这类命令行引擎在安卓上因此演化出两种用法：要么把引擎装进应用里直接本机下载，要么远程连接常驻在 NAS、服务器上的引擎。两条路径用的是同一套 RPC 接口，区别只在引擎跑在哪台设备上。

## 两条路径对照

| | 路径一：内置引擎 | 路径二：远程遥控 |
| --- | --- | --- |
| 引擎在哪 | 手机本机（应用自带） | NAS / 服务器 / VPS |
| 需要服务器吗 | 不需要 | 需要，地址要可达 |
| 适合场景 | 临时抓文件、直接落到手机存储 | 挂机下载大文件、BT 做种 |
| 网络要求 | 无特殊要求 | 公网可达或同一局域网 |

## 路径一：内置引擎本机下载

安卓上的代表应用是 Aria2App（GitHub 上开源、GPL-3.0 许可，仓库地址 `https://github.com/devgianlu/Aria2App`）。它把 aria2 引擎直接编进了安装包：

1. 首次打开新建一个配置文件——启动页的加号就是干这个的；
2. 给配置启用通知服务，下载进度会常驻通知栏；
3. 按需设置连接条件：总是可用、或仅无线网络时工作，避免偷跑流量；
4. 之后添加任务即可，全程不需要 root，也不需要任何服务器。

## 路径二：远程遥控服务器

在配置文件里填服务器的地址、端口与 `/jsonrpc` 端点，WebSocket 或 HTTP 二选一，确认 TLS/SSL 开关与服务器侧一致：

- 服务器侧建议先设置 `rpc-secret` 令牌，手机端填同样的密钥；
- 外网遥控的常见前提是 DDNS 加端口转发，或走内网穿透；
- 连上之后，远程任务队列、进度、限速都能在手机上改。

Aria2App 还有一个「直接下载」功能：启用后可以从 aria2 服务器经 WEB、FTP 或 SFTP 把已完成的文件回传到手机存储，需要给应用授予文件读写权限。配置过程如果卡住，[aria2 安卓版](https://aria2.rggd.pw/) 把两种路径的界面步骤拆开写了，可以对照操作。

## 该选哪条

只在一个设备上用、任务量不大——内置引擎最省事；家里有常开的 NAS、习惯挂机下载——把引擎留在服务器上、手机当遥控器更合适。两者并不冲突，Aria2App 里可以并存多个配置文件，切换即可。
