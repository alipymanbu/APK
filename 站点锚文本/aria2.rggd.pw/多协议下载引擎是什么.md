# 多协议下载引擎是什么

> 把「aria2 到底是个什么东西」讲清楚：它支持哪些协议、靠什么被控制、常见在哪些场景出现。
> **相关文档**：[手机端下载与远程遥控用法.md](手机端下载与远程遥控用法.md) · [BT磁力下载与断点续传参数.md](BT磁力下载与断点续传参数.md)

---

aria2 是一个以轻量著称的命令行下载工具，一个文件不大、资源占用不高的可执行程序，却同时支持 HTTP/HTTPS、FTP、SFTP、BitTorrent、Metalink 这些协议，还能从多个地址同时取同一个文件的数据块。本篇讲它的定位、控制方式与常见使用场景；想直接看安卓手机上怎么用，可以跳到[手机端下载与远程遥控用法](手机端下载与远程遥控用法.md)。

## 支持的协议面

同一个引擎，吃下这几类任务：

| 协议 | 典型用途 |
| --- | --- |
| HTTP / HTTPS | 普通网页直链、软件安装包 |
| FTP / SFTP | 服务器之间的文件传输 |
| BitTorrent | 种子与磁力链接 |
| Metalink | 一份元数据里带多个镜像源的下载清单 |

「多来源」是它区别于普通下载器的一点：同一个文件可以同时从几个 URI 拉不同分段，最后拼成完整文件，对慢速镜像尤其有用。

## 命令行工具，谁在操作它

aria2 本体没有图形界面，它开放 JSON-RPC（可走 HTTP 或 WebSocket）与 XML-RPC 接口，谁连上接口谁就能指挥它：添加任务、暂停、限速、查进度。日常见到的「aria2 图形界面」其实都是前端——比如浏览器里的 Web 面板 AriaNg，或者安卓上的 Aria2App，本质都是通过 `jsonrpc` 接口跟引擎说话。

## 常见出现的地方

- **NAS 与服务器挂机下载**：让引擎常驻在设备上，手机或电脑只负责远程下发任务；
- **安卓 Termux**：在手机终端里装引擎本体，配合脚本运行；
- **批量与自动化**：命令行天然适合写进脚本，配合参数控制并发与续传（见 [BT磁力下载与断点续传参数](BT磁力下载与断点续传参数.md)）。

## 和图形下载器是什么关系

把 aria2 理解成「引擎」、图形程序理解成「遥控器」就不会混：引擎负责真正的传输，遥控器负责把你的操作翻译成 RPC 调用。所以换前端不用换引擎，引擎的参数也不随前端变化。如果想了解手机端的两种跑法（内置引擎与远程遥控），[aria2 中文介绍与安卓用法](https://aria2.rggd.pw/) 里有按场景整理的对照。
