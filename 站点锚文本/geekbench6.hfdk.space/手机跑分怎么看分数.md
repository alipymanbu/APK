# 手机跑分怎么看分数

> 用 Geekbench6 给手机跑完分，屏幕上留下一堆数字：单核、多核、外加一长串逐项成绩。本篇讲这些数怎么读、跟谁比才有意义。
> **相关文章**：[怎么跑分才准](怎么跑分才准.md) · [和安兔兔跑分差多少](和安兔兔跑分差多少.md)

## 一、先看两个总分

结果页顶上是两个数：

- **Single-Core（单核）**：只用一个核心时的整体表现，影响日常单线程操作的响应速度——开应用、刷页面、日常操作的跟手程度都跟它相关；
- **Multi-Core（多核）**：所有核心一起上的表现，影响多任务、视频导出这类并行负载。

读数规则只有一条要记住：**分数越高越好，翻倍就是性能翻倍**。这是整套量尺的标定口径——Geekbench 6 以 2500 分对齐一台搭载 Core i7-12700 的工作站，以此为刻度起点。

具体某台手机该跑多少分不用背数字。Geekbench Browser 的安卓榜单按用户提交数据实时更新，分单核、多核、OpenCL、Vulkan 四张榜，比自己记区间准得多。想先看一眼工具界面和测试构成，可以逛逛这个 [Geekbench6 实测介绍站](https://geekbench6.hfdk.space/)。

## 二、逐项分比总分更有信息量

总分下面是逐项成绩，每项自带真实单位：

| 举例任务 | 单位 | 对应场景 |
| --- | --- | --- |
| File Compression | MB/秒 | 打包、传输大文件 |
| Photo Library | 张/秒 | 相册整理、修图 |
| HTML5 Browser | 页/秒 | 浏览器渲染 |
| PDF Renderer | 百万像素/秒 | 看文档、导出文档 |
| Object Detection | 张/秒 | 相机识别、AI 功能 |

读法是**按自己的用法找行**：经常修图就看照片那几行，经常传文件就看压缩那行。总分落后的一方在某一项上反超很正常，只有逐项分能看出这种差别。

## 三、GPU Compute 单独看

GPU Compute 的成绩与 CPU 分开，分 **OpenCL** 与 **Vulkan** 两套。同一块 GPU 在两个 API 下可以差出不少，对比时必须用同一套 API 的数。它量的是图像处理、视觉与机器学习这类运算负载，不直接等于游戏帧率。

## 四、只能同版本互比

Geekbench 6 的分数只能跟 6 的分数比。每换代一次，量尺就重新标定一次：5 代以 1000 分对齐 Core i3-8100，6 代以 2500 分对齐 Core i7-12700——数字看着差不多，含义完全不同，两代之间也不存在换算关系。网上流传的跨版本换算系数不要采信。

拿别人的分数来比之前，先问一句对方用的哪个版本；版本对不上，要么找同版本的结果，要么两边用同一版本各跑一次。

## 五、一个容易踩的坑

单核与多核差几倍都正常——多核本来就是把所有核心加在一起。别拿一台手机的多核分去比另一台的单核分，也别拿跑分工具的总分去质疑别人手机「卡不卡」：日常流畅度还取决于存储、内存与系统调度，跑分只是其中一个维度。
