# 解锁画质帧率没生效怎么办

> 本篇按现象汇总 pubgtool（PUBG Tool 画质助手）解锁不生效的高频原因与处理办法，先对号入座，再按步骤排查。
> **相关文档**：[和平精英120帧怎么开.md](和平精英120帧怎么开.md)

「点了解锁没效果」通常落在四类原因里：权限没给够、读写方式与机型不匹配、操作顺序不对、游戏或系统刚更新导致暂时不兼容。下面按现象逐条给处理办法。

## 一、提示「开启失败，请运行游戏后重试」

两条路，按顺序试：

1. 到「设置 → 应用 → PUBG Tool → 权限」里手动给存储权限，然后重启应用；
2. 仍不行就先手动运行游戏、进入一次大厅，再切回来点解锁。

## 二、点「保存并启动游戏」一直转圈

这是部分系统补丁较新机型才会遇到的情况。处理思路分两步：

1. **先换读写方式**：1.0.8.8 起应用右上角提供「无需 Shizuku / Shizuku / 原生」三种读写方式，先换一种再试，多数情况不用折腾额外授权；
2. **确实需要 Shizuku 的机型**：Shizuku 是独立的开源小工具，需要单独安装并激活——Android 11 及以上走「无线调试」配对（全程不用电脑），Android 10 及以下要连一次电脑。激活后保持它在后台运行，回到 PUBG Tool 完成授权。注意手机每次重启后 Shizuku 服务要重新点一次「启动」，这是系统限制，属正常现象。

## 三、解锁成功但游戏闪退

长按「解锁画质帧率」取消解锁，游戏即可恢复正常启动。之后想再试，换一种读写方式再解锁；不要与 GFX Tool 等其他画质工具叠加使用，两类工具同时改配置会互相顶掉，要用哪个就先长按取消另一个。

## 四、帧数选项整个消失

先检查和平营地里的「画质提升」功能是否开着——把它关掉，再回游戏看选项是否恢复。这与画质助手无关，是营地侧的功能冲突。

## 五、画面异常或键位错乱

- **改了分辨率后键位错乱**：把分辨率调回默认，或进游戏重新调整键位位置；分辨率调高还容易卡顿，拿不准就保持默认；
- **画面显示异常**：依次尝试「画面修复」的各个选项直到画面正常，或把保存模式从 EC 改成 UC（UC 方式会在启动游戏时自动清理旧配置文件，避开读取冲突）；
- **部分小米机型分辨率不生效**：把游戏切到小窗再还原全屏。

## 六、以上都试过仍不行

先确认游戏本体是否刚更新了大版本——工具的适配通常滞后几天，等一版更新比反复折腾旧版更省事。另外提醒一句：**生效位置在对局内，不在大厅**，大厅锁定 30 帧属正常现象，别把它当成「没生效」的依据。帧数档位与画质组合的关系，见[和平精英120帧怎么开](和平精英120帧怎么开.md)一篇，这里不再展开。

安装文件、功能盘面与完整的上手顺序，都整理在 [pubgtool 画质助手参考站](https://pubgtool.fedq.quest/)，从站内的下载页进即可。
