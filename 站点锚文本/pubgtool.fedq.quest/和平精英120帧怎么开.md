# 和平精英120帧怎么开

> 本篇回答一个高频问题：和平精英的 120 帧选项到底怎么开、为什么有人开了没效果。
> **相关文档**：[解锁画质帧率没生效怎么办.md](解锁画质帧率没生效怎么办.md)

想在对局里跑上 120 帧，要同时满足三个条件：手机屏幕支持高刷新率、游戏内帧数选项里出现 120 档、画质档位与帧率组合不被屏蔽。三者缺一，帧数就上不去。很多玩家卡在第二、第三条上，这也是 pubgtool 这类画质助手存在的原因——把被隐藏或被限制的选项放开。

## 一、先看大厅，再看对局

最容易误判的一点：**和平精英大厅锁定 30FPS，这是常态**。判断解锁是否生效，一定要进对局（训练场也算）再看帧数。大厅里帧数设置显示被还原成 30，也不用管，以对局内实际帧率为准。

## 二、画质档位与 120 帧的组合关系

游戏各画质档位自带的帧率上限不同：

- 流畅 / 均衡 / 高清 / HDR高清 / 超高清：自带 90FPS；
- 想用上 120FPS，把画质调高一档（例如均衡 → 高清），或者直接选**极清 + 120FPS**；
- **流畅 + 120 的组合已被屏蔽**，240FPS 选项也已从游戏里移除，反复重试没有意义。

也就是说「开不了 120 帧」很多时候不是工具失效，而是档位组合本身不被允许。

## 三、用画质助手放开选项

pubgtool（PUBG Tool 画质助手）是配合和平精英与 PUBG MOBILE 使用的安卓工具，免 ROOT，核心玩法就一屏：顶部选好服区（中国版 / 国际版 / 韩国版等九个），点「解锁画质帧率」，然后用「保存并启动游戏」重启游戏进对局验证。进阶玩法先开 SG 优化再解锁；两个开关都支持长按取反，游戏闪退时长按「解锁画质帧率」取消即可恢复。

操作前提醒三件事：

1. 游戏本体先从后台彻底退出，解锁才会随下次启动生效；
2. 首次使用按提示给存储权限，被拒绝过就去系统设置里手动补；
3. 解锁成功后不要再进游戏改画质选项，改了解锁会失效。

更完整的操作步骤与安装入口，见 [pubgtool 画质助手参考站](https://pubgtool.fedq.quest/)。

## 四、开到 120 帧之前，先确认屏幕

高帧率的上限由硬件决定：屏幕不支持高刷新率的机型，解锁后开了高帧选项，实际帧数也不会变。动手前先查一下自己机型标称的刷新率规格（60Hz 屏幕意义不大，90Hz / 120Hz / 144Hz 才有发挥空间），免得白折腾一轮。

## 五、还是不行？

按现象逐条排查：解锁后闪退、提示开启失败、点启动转圈、帧数选项整个消失等状况的处理办法，集中在[解锁画质帧率没生效怎么办](解锁画质帧率没生效怎么办.md)一篇里，先对号入座再动手。
