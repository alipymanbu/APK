# LocalSend 使用指引导读

这里是围绕 LocalSend 整理的第三方使用指引。LocalSend 是一款免费开源的局域网互传工具，手机、电脑、平板连到同一个网络里就能直接互发文件与文字，全程不走云端，Windows、macOS、Linux、安卓、iOS 都有对应版本。

本目录的文章挑了三个新手最常碰到的场景来写：装好之后怎么发出第一个文件、没有路由器或断网时怎么组网、以及传输速度上不去时从哪里下手。工具的功能拆解、界面实拍与安卓安装包的获取入口，都放在 [LocalSend 介绍站](https://localsend.wxhp.skin/)。
