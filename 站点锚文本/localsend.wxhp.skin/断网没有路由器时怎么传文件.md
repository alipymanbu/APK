# 断网没有路由器时怎么传文件

> 宽带断了、在外面、甚至完全没外网，两台设备之间照样能传。这篇分清三种离线场景各自怎么组网，热点直连的四个步骤与三条要点，以及它做不到的事。

## 一、先分清：靠的是局域网，不是互联网

路由器给的「上网」和「局域网」是两层东西，LocalSend 只用底下那层。所以外网断了、欠费了、没信号，都不影响互传——只要两台设备在同一个小网络里。对号入座：

| 场景 | 怎么组网 |
| --- | --- |
| 家里或办公室，宽带断了 | 两端继续连原来的 Wi-Fi，路由器不用动 |
| 没有路由器（路上、会场） | 一台开热点，另一台连上 |
| 公共 Wi-Fi 搜不到人 | 放弃那个网络，改热点直连 |

## 二、热点直连四步

1. 任意一台（通常是手机）在系统设置里打开「个人热点」；
2. 另一台把它当普通 Wi-Fi 连上去；
3. 两端都打开 LocalSend（还没装的话，[LocalSend 介绍站](https://localsend.wxhp.skin/)有各平台的获取方式）；
4. 照常发送与接收，动作和有路由器时完全一样。

三条要点：

- **热点不需要有外网**。开热点只是把两台设备接到一起，手机停机、套餐用尽，只要热点开得出来，文件照样通；
- **这条链路不耗流量**。数据只在两台设备之间走，不经过运营商，传几十 GB 也没有流量费；
- **想快一点**：热点设置里如有 2.4GHz / 5GHz 选项就选 5GHz，两台设备靠近些，传大文件时给开热点的手机插上电。

## 三、公共 Wi-Fi 搜不到人，切热点是最快的绕法

咖啡厅、公司访客网普遍开了「客户端隔离」，同一网络里的设备互相看不见，而你多半没有路由器管理权限。热点直连等于自建一个只有你们几台的封闭网络，隔离规则够不着——权限、防火墙都查过仍无解时，换热点基本立竿见影。

## 四、它做不到的事：跨城市

LocalSend 只在**同一个局域网内**工作。文件在你手机、人在另一个城市，是互相看不见的——跨网络的需求要交给网盘或协作工具。它也没有账号体系，不存在「发给指定的人」，对方必须和你站在同一个网络里。
