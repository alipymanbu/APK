# 多账号切换与界面自定义

> 这篇讲 Chuckle 日常使用里最常动手的两件事：多个 X 账号的添加与切换，以及时间线、主题、推文样式的自定义入口，顺带整理登录不上的快速排查。
> **相关文档**：[X第三方客户端怎么选.md](X第三方客户端怎么选.md) · [订阅价格与设备规则.md](订阅价格与设备规则.md)

---

## 一、登录用的还是你自己的 X 账号

Chuckle 本身不发账号：登录页输入的手机号或邮箱，对应的就是你的 X（推特）账号。还没有 X 账号的话，先用手机号或邮箱注册一个；登录遇到验证码或密码报错，先用浏览器登录一次 X 确认账号本身没问题，再回到客户端重试。

## 二、多账号的添加与切换

1. 在应用内找到账号管理入口（通常在侧边栏或「我的」页面，具体位置以当前版本界面为准）；
2. 选择添加账号，输入另一个 X 账号的手机号或邮箱完成登录；
3. 之后在账号列表里点选头像即可切换，切换后看到的内容直接跟着换成对应账号的。

切换不需要反复退出登录；通知按账号区分，后台未读通知也能在不打开应用的情况下收到提醒。

## 三、时间线按自己的口味调

1.0.2 版本起可用的几组开关（入口名称以应用内实际显示为准）：

| 你想做的事 | 对应设置 |
| --- | --- |
| 首页只看原创推文 | 时间线 → 筛选原创推文 |
| 不想反复刷到同一条内容 | 布局样式 → 首页过滤重复推文 |
| 不想看到推荐关注/订阅 | 布局样式 → 隐藏推荐关注/订阅 |
| 换一种滑动浏览手感 | 阅读习惯 → 首页滑动模式 |
| 推文卡片直接带翻译按钮 | 布局样式 → 推文预览显示翻译按钮 |

## 四、主题与推文样式

- **主题**：提供深色、深蓝等夜间主题，都带低对比度选项；颜色可自定义；
- **推文样式**：推文字体大小、行距、布局样式都能调，调完时间线的观感完全不同；
- **翻译引擎**：支持 DeepL 与 AI 大模型，1.0.2 起还能用 Grok 对推文或用户提问。

## 五、登录不上的快速排查

按出现频率排：

1. 确认账号密码正确——先用浏览器登录一次 X 验证；
2. Wi-Fi 与移动数据互相切换一次再试；
3. 核对手机系统时间是否准确，时间偏差会直接导致登录验证失败；
4. 都试过仍失败，多与所处网络环境有关，换个网络环境再试。
