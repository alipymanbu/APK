# 订阅价格与设备规则

> 这篇讲 Chuckle 的订阅收费模式：一年多少钱、新用户的免费试用怎么用与怎么取消、支付宝渠道订阅的差别，以及一份订阅最多几台设备、多设备激活有哪些前提。

## 一、收费模式：订阅制

Chuckle 是付费订阅制应用。商店介绍页标注的价格为 20 美元/年，Google Play 新用户一般有 7 天免费试用，试用期内取消不扣费。价格与试用政策会随版本调整，以应用内订阅页实时显示为准。

iOS 端的订阅项目名为 Chuckle Premium，走 App Store 内购，不同区商店显示的价格不同（港区页面曾显示 HK$148，以你所在区实时显示为准）。

## 二、免费试用与取消的实际操作

1. 在应用内发起订阅，走 Google Play 支付；订阅页会直接标出新用户能否享受 7 天试用；
2. 不想续费时，打开 Play 商店 → 「付款与订阅」，找到 Chuckle 取消即可；
3. 取消后当前周期仍可用到期满，不会立刻失效。

试用期内记得取消，就不会产生扣费；订阅记录随时可以在 Play 商店 / App Store 里查到，找不到取消入口时去那里最直接。

## 三、支付宝渠道订阅的差别

安卓端另有支付宝渠道订阅。按商店介绍页的说法，通过支付宝订阅的用户，应用后续仍可在 Play 商店正常更新——付款渠道只影响支付方式，不影响更新。差别在于多设备使用的规则（见下一节）。

## 四、一份订阅最多 3 台设备

| 规则 | 内容 |
| --- | --- |
| 设备上限 | 一份订阅最多 3 台设备 |
| 支付宝订阅多设备 | 各设备激活订阅时的 IP 归属地必须一致，否则其他设备会失效 |
| 共用 | 不允许合租，不允许多人共用一份订阅 |
| 反复换地激活 | 反复用不同归属地的 IP 去激活，可能导致订阅失效且无法再激活 |
| 恢复订阅 | 多台设备使用时恢复订阅，恢复期间不要开代理 |

最容易踩的坑在支付宝订阅这一档：自己在手机上激活成功，家人在另一台设备登录时，因为激活时的 IP 归属地不同，第二台设备被判失效。避免的办法是多台设备在同一网络环境下完成激活。

## 五、订阅了但功能没解锁

1. 彻底退出应用（从后台划掉）再打开，让订阅状态刷新；
2. 确认设备数没超 3 台上限，超了会有一台被判失效；
3. 支付宝订阅的，回想最近是否换过网络环境激活别的设备；
4. 仍不行就保留订单信息，通过应用内入口向开发者反馈。
