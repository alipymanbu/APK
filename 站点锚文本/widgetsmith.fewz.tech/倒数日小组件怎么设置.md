# 倒数日小组件怎么设置

考试倒计时、项目截止、纪念日还剩几天——这类「盯着日子过」的需求，放到桌面最直观。安卓端这款小组件应用里，倒数日和节日是两类现成的组件，配上之后桌面直接显示剩余天数，不用打开任何应用。

设置路径大致三步：

1. 打开应用，在小组件类型里选倒数日（或节日风格），挑一个顺眼的样式；
2. 设定目标日期与显示文案，比如「距离考研」加日期；
3. 点「添加小组件」，回桌面长按空白处，从小组件列表里把对应尺寸摆上桌面。

摆好之后还有两个细节值得调：

- **颜色跟壁纸走**。深色壁纸配深红、墨绿这类深底组件更沉稳；浅色壁纸就选奶油、白底款，别让组件和壁纸糊在一起。
- **位置留给视线动线**。倒数日这种一天看几次的组件，放桌面右上或第二屏开头最合适；配合点击直达，有的样式点一下还能直接进编辑，改日期不用翻菜单。

如果想把日子提醒和照片墙拼在一起，参考[桌面照片小组件怎么弄](桌面照片小组件怎么弄.md)；组件样式的整体效果与安装入口，见 [Widgetsmith 安卓版站点](https://widgetsmith.fewz.tech/)的组件玩法一节。
