# Threads 注册登录与账号共用规则

> Threads 没有独立注册入口，进门全靠 Instagram 账号。这篇讲清登录时什么会带过来、哪些设置两边共享、停用与删除的差别，以及「怎么改完那边也变了」的几处常见困惑。
> **相关阅读**：[安装步骤与装不上的排查.md](安装步骤与装不上的排查.md) · [信息流推荐与发帖玩法速查.md](信息流推荐与发帖玩法速查.md)

## 一、账号从哪来

能进 Threads，是因为有一个 Instagram 账号：登录输的是 Instagram 的账号密码，找回密码、收验证码这些安全操作也都在 Instagram 那一侧完成。账号本身出问题，这边跟着进不去。

## 二、第一次登录会带过来什么

| 项目 | 是否从 Instagram 带过来 |
| --- | --- |
| 用户名 | 带过来，两边保持一致 |
| 认证标识（蓝勾） | 带过来 |
| 已屏蔽的账号 | 带过来，两边互为镜像 |
| 关注列表 | 不自动全关注，给一屏可选，逐条决定 |
| 头像与简介 | 带基础信息，可在 Threads 单独改 |

想只让 Threads 显示得不一样，走「Threads 专用资料」这条路，改简介头像不会同步回 Instagram；但用户名没有单独改的空间，改名两边一起变。

## 三、哪些共享，哪些独立

- **共享**：用户名、认证标识、登录密码、屏蔽名单、隐藏词；
- **可单独覆盖**：头像、简介、外链；
- **各自独立**：帖子、点赞、回复、私信收件箱 —— Threads 的消息不会进 Instagram 收件箱，找消息别翻错地方。

## 四、停用与删除的差别

| 操作 | 效果 | 反悔窗口 |
| --- | --- | --- |
| 停用资料 | 主页、帖子、回复、点赞对外全部隐藏，数据不删 | 随时登录即恢复，约一周限一次 |
| 删除资料 | 30 天后永久清空帖子、回复、点赞与关注关系 | 30 天内重新登录可取消 |

删 Threads **不会**删 Instagram（早期连删的问题后来分开了）；反过来停用 Instagram 会连带停用 Threads。删除生效后，别人截图或转发过的内容不受控制，重要的东西先导出留底。

## 五、换手机与数据留底

没有一键整机备份，但可以走应用内的「导出你的信息」：路径在个人主页 → 右上角菜单 → 设置 → 账号，提交后拿到的是 ZIP 包（一份 HTML 方便浏览 + 若干 JSON 结构化数据）。下载链接过几天会失效，拿到尽快存本地；顺便这也是翻找自己旧帖最快的一条路，比在主页里无限下拉靠谱。

关于登录后能看到什么、谁可以回复你这些可见性开关，在 [信息流推荐与发帖玩法速查.md](信息流推荐与发帖玩法速查.md) 里有一节速查；安装环节的问题则回到 [Threads 说明站](https://threads.gltd.quest/)的获取页对表处理。
