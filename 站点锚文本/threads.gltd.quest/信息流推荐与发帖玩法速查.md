# Threads 信息流推荐与发帖玩法速查

> 同一个应用，两个人的首页可以完全不同。这篇按「想干什么 → 怎么动手」组织：发帖的限制与玩法、回复引用转发的分工、两条信息流的区别，以及把推荐拧向自己口味的三种手段。
> **相关阅读**：[注册登录与账号共用规则.md](注册登录与账号共用规则.md) · [安装步骤与装不上的排查.md](安装步骤与装不上的排查.md)

## 一、发帖：能放什么

| 能放什么 | 限制 |
| --- | --- |
| 文字 | 最多 500 个字符，支持换行分段 |
| 图片 | 可放多张，上限随版本调整，以编辑页显示为准 |
| 视频 | 最长 5 分钟 |
| 链接 | 直接粘进正文 |

发帖前有一个「谁可以回复」的下拉项：所有人 / 你关注的人 / 被提及的人，事后还能改。想被接话就保持默认，想清净就收窄。

## 二、回复、引用、转发的分工

- **回复**：把话挂在同一条对话链上，是长讨论的主要形态；
- **引用**：把对方的帖子嵌进自己的新帖再说几句，适合「我要就这条内容讲两句」；
- **转发**：不带评论，把值得看的东西推给关注你的人。

发出去之后还有三个小动作：删除（已被人引用的那条不会跟着消失）、短暂窗口内的编辑、以及主页置顶。

## 三、两条信息流不是一回事

| 信息流 | 里面是什么 | 什么时候刷 |
| --- | --- | --- |
| 已关注 | 只显示你关注的人的帖子 | 安静看完熟人动态 |
| 为你推荐 | 关注的人 + 系统推荐的陌生账号 | 发现新账号、追热点 |

推荐流里混进陌生内容是设计如此，不是关注列表出了问题；不想看某类内容，直接对那条帖子操作即可。

## 四、把推荐拧向自己的口味

按力度从小到大：

1. **对单条帖子表态**：帖子菜单里选「不感兴趣」或减少此类内容，见效最快；
2. **用自然语言告诉算法**：写下想多看什么、少看什么，选一天 / 三天 / 七天生效，请求仅自己可见（分地区逐步开放）；
3. **三档降噪**：隐藏词（挡词）、静音账号（不取关但看不见）、屏蔽账号（互相不可见，名单与 Instagram 同步）。

调完不会立刻翻天覆地，刷几条才开始变化，这是正常节奏。

## 五、可见性开关与搜索收录

想收紧可见范围，去「设置 → 隐私」：公开 / 私密总闸门、谁能回复你、谁能提及你都在那里，默认值是「任何人」，不设等于全开放。注意私密账号的帖子不会进话题页和搜索结果，想要曝光就别开私密。

关于「搜不到人、搜不到帖子」：多数不是故障，而是索引延迟（新帖几分钟到一两天才被收录）或对方是私密账号。反复删除重发反而可能触发频率限制，等一等比折腾更快。
