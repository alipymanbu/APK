# 换密码管理器怎么搬数据

下决心换密码管理器的人，十有八九卡在同一个问题上：几百条记录，难道要一条条重录？当然不用。以 Enpass 为例，迁移有一条标准路径，多数情况半小时内能跑完。

## 迁移的标准路径

各家密码管理器几乎都提供导出功能，通用的中间格式是 CSV；不少产品之间还支持直接读取对方的导出文件。Enpass 的导入入口放在**桌面端**：打开电脑版的 File 菜单 → Import，选择来源格式（CSV 或对应管理器的导出文件），导入后数据就进了本地保险库。

手机端没有导入入口，这不是缺陷而是分工：保险库文件同步到云盘之后，手机端挂上同一个保险库，数据自然就到了——所以迁移的正确顺序是：

1. 在旧工具里把数据导出（CSV 或它支持的格式）；
2. 桌面端 Enpass 走 File → Import 导入；
3. 保险库文件放进你选的网盘；
4. 手机端 Enpass 打开这个保险库，齐活。

## 迁移时值得留意的三件事

- **导入后抽查**：CSV 对字段的理解各家略有差异，导入完抽几条看备注、网址、验证器字段有没有串位；
- **验证器条目**：TOTP 密钥如果旧工具支持导出，别落下——丢了它，两步验证就得逐个站点重新绑定；
- **导出文件即用即删**：明文 CSV 是迁移期最大的风险点，导入确认无误后立刻删除，回收站也清一遍。
