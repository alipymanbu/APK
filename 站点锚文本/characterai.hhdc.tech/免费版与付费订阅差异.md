# 免费版与付费订阅差异

> 一句话：免费版就能正常聊，c.ai+（$9.99/月或 $94.99/年）买的是更快响应、更强记忆和新功能尝鲜——差距在体验，不在"能不能用"。
> **相关文档**：[角色语音通话与群组同框玩法.md](角色语音通话与群组同框玩法.md) · [自建角色从人设到发布的流程.md](自建角色从人设到发布的流程.md)

---

常被问到"Character AI 是不是要充钱才能聊"——不是。免费注册后就能和角色发消息，应用商店的介绍里写得明白："Unlimited free messages (and no ads)"，消息免费发、中途不插广告。语音通话、群组、自建角色这些玩法也都在免费范围内。

## 两档差在哪

| | 免费版 | c.ai+ |
| --- | --- | --- |
| 价格 | $0 | $9.99/月，或 $94.99/年 |
| 聊天 | 无限免费消息 | 同样无限 |
| 高峰期 | 可能排队等回复 | 优先队列，响应更快 |
| 记忆 | 长度有限，长对话易丢前文 | 更强的长期记忆 |
| 新功能 | 随正常节奏开放 | 抢先体验，附专属徽章 |

一句话概括：免费版覆盖全部核心玩法；聊得浅完全够用。

## 什么人会考虑订阅

- **长故事玩家**：一次跑几百条消息的沉浸式文字冒险，免费版记忆长度容易"断片"，订阅后前文丢得少。
- **重度用户**：每天高频开聊，高峰期的排队等待积累起来很可观。
- **喜欢尝鲜**：新玩法通常先给订阅用户开。

反过来，如果只是偶尔找角色闲聊两句，免费版没有哪个地方会"卡住"你，不用为用不上权益付费。

## 登录与账号

无论哪一档，登录都是 Apple、Google 账号或邮箱三选一；聊天记录跟账号走，换设备重新登录后还在。装应用、挑角色这些前置步骤，见 [characterai 玩法动线介绍](https://characterai.hhdc.tech/)；造一个自己的角色则见 [自建角色从人设到发布的流程.md](自建角色从人设到发布的流程.md)。
