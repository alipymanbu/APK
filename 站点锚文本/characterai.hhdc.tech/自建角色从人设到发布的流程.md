# 自建角色从人设到发布的流程

> 一句话：把 Create a Character 表单从上到下填一遍——名称、头像、开场白、人设描述、示例对话、可见性，填完就是一个能聊的角色。
> **相关文档**：[角色语音通话与群组同框玩法.md](角色语音通话与群组同框玩法.md) · [免费版与付费订阅差异.md](免费版与付费订阅差异.md)

---

在 Character AI（c.ai）里造角色不需要会写代码，整个过程就是填一张表单：主界面点 Create → Create a Character，然后从上往下逐项过。

## 表单逐项怎么填

1. **名称**：角色的公开名字。名字最好直接透出身份，"面试教练老周"就比"老周"更容易被搜到、也更让人知道该找它聊什么。
2. **头像**：上传一张图，或按一句描述生成一张，风格贴近角色设定即可。
3. **开场白（Greeting）**：角色被点开时说的第一句话。把它写成"已经进入情境"的样子——比如学习搭子直接说"今天先从哪一科开始？"，比干巴巴的"你好"更容易接。
4. **人设描述**：短描述一句话定位；长描述展开写背景、性格、说话习惯，类比给剧本角色写人物小传。
5. **示例对话（Example Dialogues）**：给两三段你期望的问答样本，角色会模仿这种语气。这是让"聊起来像不像"拉开差距的一项。
6. **可见性**：公开（所有人可用、可搜到）、不公开（拿链接的人可用）、私有（只有你能聊）。

填到哪一步都能先保存试聊，语气不对就回来改描述、加示例，反复几轮，贴合度会明显上升。

## 造完之后

- **先私有试聊**再决定公开，避免人设漏洞被陌生人带偏。
- **放进群组**看它和别的角色怎么互动，是检验性格是否立得住的快捷办法，群组玩法见 [角色语音通话与群组同框玩法.md](角色语音通话与群组同框玩法.md)。
- 想给角色更长的"记性"，涉及订阅对记忆长度的影响，见 [免费版与付费订阅差异.md](免费版与付费订阅差异.md)。

还没装应用的，可以从 [characterai 介绍站](https://characterai.hhdc.tech/) 看起，那里按"装好后的第一个晚上"把挑选角色、文字、语音的动线串成了一篇。
