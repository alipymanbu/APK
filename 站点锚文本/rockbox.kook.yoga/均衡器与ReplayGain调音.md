# 均衡器与ReplayGain调音

> Rockbox 的声音部分不靠三五个预设打发：本篇按你会真正用到的顺序讲参量均衡器、ReplayGain 响度统一，以及几个和听感直接相关的播放行为选项。

## 为什么预设不够用

手机自带播放器的音效页通常是「流行 / 古典 / 摇滚」三选一，加上一个拉不动的图形均衡器。问题在于每个人的耳机、听音习惯都不一样，预设盖不住。Rockbox 安卓端给的是逐频段的参量均衡器（EQ）：每个频段的增益、中心频率都能单独拧，由它自己的 DSP 音频管线处理，调出来的曲线贴的是你的耳朵，不是某个「大多数用户」。

## 参量均衡器怎么下手

第一次拧 EQ 不用贪多，按这个顺序来：

1. 进声音设置，打开均衡器（EQ），先只动增益；
2. 从 60Hz 一类的低频段开始小幅抬升或压低，每段变化控制在 2~3dB，听一两天再决定去留；
3. 低频轰头就压低频、人声发闷就抬中高频——一次只动一段，动完记下参数；
4. 觉得声音发毛时把增益整体拉回，宁平勿炸。

## ReplayGain：把响度拉平

现场版比录音室版响、老专辑整体偏轻、不同专辑之间音量忽大忽小——这些是响度不一致，不是音质问题。ReplayGain 的思路是给每条音轨或每张专辑算一个统一的响度基准，播放时按基准补偿，你只需要选按单曲还是按专辑：

- **按单曲（per track）**：每首歌都拉到同一响度，适合随机乱序听歌；
- **按专辑（per album）**：保持专辑内部的强弱关系，只拉平专辑与专辑之间的差异，适合按张听。

## 顺手该一起设的几个播放选项

| 选项 | 建议口径 |
| --- | --- |
| 重复（repeat） | 单曲循环 / 全列表循环 / 关闭，按听歌习惯选 |
| 乱序播放（shuffle） | 配 ReplayGain 按单曲口径最合适 |
| 快进快退步长 | 默认太快或太慢都可在播放设置里改 |
| 停止 / 暂停时淡出 | 开了以后按暂停不会「啪」一声切断 |
| 聚会模式（party mode） | 防误触的长时间连续播放场景用 |
| 淡入淡出（crossfade） | 前后两轨叠着过渡，接歌揉歌的效果 |
