# uWeb 站点导航（uweb.hfdk.space）

这里收录围绕安卓极简浏览器 uWeb（中文常叫「超微浏览器」）整理的第三方介绍页与使用笔记。它用一个不到 250KB 的安装包，把多引擎搜索、地址栏命令、根域名广告拦截和全局脚本样式全部带齐，是安卓圈子里出了名的「小体积、深定制」浏览器。

完整的功能介绍与安装文件资源获取入口，见 [uWeb 超微浏览器介绍站](https://uweb.hfdk.space/)。
