# 提词器蓝牙遥控器配对与失灵排查

> 遥控器搜索不到、配对失败、连上了按键没反应——大多数情况出在电池、定位服务和配对路径上。
> 台本与参数的准备另见 [手机提词器怎么用](手机提词器怎么用.md)。

---

## 一、先看指示灯

以 RT113 的口径为例，遥控器用指示灯区分两种状态：

| 指示灯 | 含义 |
| --- | --- |
| 蓝灯闪烁 | 正在配对模式，可以被搜到 |
| 蓝灯常亮 | 已经连上 |

搜不到时先确认它还在闪——长按电源键重新开机让它回到闪烁状态。完全不亮基本是电池问题，RT111 / RT113 换新 AAA 电池，注意正负极。

## 二、搜不到设备：四步走

1. **电池**：装对、电量足。
2. **蓝牙**：系统设置里确认已开。
3. **定位服务**：把位置信息也打开——部分机型的蓝牙扫描依赖它，这是最容易漏的一步。
4. **重启两端**：遥控器关机重开，手机蓝牙开关一次或直接重启。

周围蓝牙设备多的时候（耳机、手表都连着），先把其他连接断开再搜，减少干扰。

## 三、配对路径不对：换一条路重试

遥控器有两条常用配对路径，不同型号批次推荐的还不一样：

- **应用内连接**：打开应用，在设备连接入口搜「NEEWER RT…」点选连接；
- **系统蓝牙配对**：系统设置 → 蓝牙里配对，再回应用里用。

卡住时的有效动作是：先在系统蓝牙里对这个遥控器「取消配对 / 忽略此设备」，然后换**另一条路径**重来。连上后进播放界面按一下播放键验证。

## 四、连上了但按键没反应

- 确认手机里装的是配套的 NEEWER Teleprompter 应用，第三方套壳收不到遥控指令；
- 完全退出应用再重开（是杀掉重进，不是切后台）；
- 应用能更新就更新到新版本。

按键分工记一句话：**上下键管快慢（播放中）或翻页（暂停时），A+/A− 管字号**。拍摄中最常用的就是播放中按上下键微调滚动速度。

## 五、还没解决

把遥控器拿到离手机更近的地方再连；换一组新电池再试；另外这类遥控器不面向 Windows 电脑，在电脑上试不算故障。怀疑硬件损坏就走售后渠道，不要自行拆修。

应用还没装好的，先去 [Teleprompter 安卓提词应用介绍](https://teleprompter.gltd.quest/) 看获取方式，装完回到 [手机提词器怎么用](手机提词器怎么用.md) 把参数调顺。
