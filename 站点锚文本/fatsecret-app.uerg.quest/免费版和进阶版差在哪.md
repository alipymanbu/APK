# 免费版和进阶版差在哪

> 「先免费用着，会不会关键功能都锁着？」这篇把免费版能做的事与进阶版多出的工具摆在一起对照，看完就知道要不要花钱。

## 一、结论先行

把每天吃的东西记下来、看营养分解、追体重趋势——这条主线在免费版里是完整走得通的。进阶版解决的是「记得更快、分得更细」的效率问题，不是「不做就没法用」的门槛问题。

## 二、免费版里有什么

- **宏量营养素追踪**：脂肪、碳水、蛋白质与 %RDA，按餐次拆开看；
- **条码扫描**：包装食品即扫即录；
- **四类餐次**：早餐、午餐、晚餐、小食及其他；
- **体重记录与趋势报告**：长期曲线配合每周称重复盘；
- **社区、徽章与连续打卡**：正反馈的那一套；
- **健康应用同步**：可连接 Apple Health、Google Health、Fitbit、Samsung Health、Garmin，步数、卡路里、体重自动同步。

## 三、进阶版多出什么

| 进阶版工具 | 对应的场景 |
| --- | --- |
| 餐食规划 | 提前排好一周吃什么，照单执行 |
| 一键复制 | 常吃的餐食一键抄到今天 |
| 自定义餐食 | 自家配方存成模板，营养自动核算 |
| 更多餐次（最多 10 类） | 加餐、补剂分得比四类更细 |
| 饮水记录 | 每天喝水量顺手一并记 |

一句话概括：免费版记「吃了什么」，进阶版帮你省「记的时间」。

## 四、怎么选

- **刚开始记录**：直接用免费版，跑满两三周再说——多数人卡住的是习惯，不是功能。
- **记录已成习惯、开始嫌步骤烦**：再考虑进阶版，用它的时间省出来巩固习惯。
- **只想先看看长什么样**：[FatSecret app 介绍页](https://fatsecret-app.uerg.quest/) 有中文界面实拍与功能说明，先看再装不吃亏。

功能取舍的判断标准从来是自己的记录场景，不是清单长短——这也是 [食物数据查不准怎么办](食物数据查不准怎么办.md) 里反复强调的：先让记录跑起来。
