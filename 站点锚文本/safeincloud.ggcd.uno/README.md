# SafeInCloud 介绍站文档索引

SafeInCloud 是一款跨平台密码管理器：账号密码、银行卡与私密笔记存进 AES-256 加密数据库，数据同步到使用者自己的云盘账户。本目录收录几篇第三方视角的介绍文章，覆盖安装设置、云同步方式与授权选择三个常见需求。

安装文件资源的获取入口与真机界面一览，见 [SafeInCloud 介绍站](https://safeincloud.ggcd.uno/)。

- [数据同步到自己的云盘](数据同步到自己的云盘.md) —— 同步机制与各家云账户的配置思路
