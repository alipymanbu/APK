# 卡顿与掉帧优化设置：让 3DS 模拟在手机上跑顺

> 本篇讲安卓端真正影响流畅度的几组设置：图形 API、内部分辨率、着色器编译，以及卡顿时的排查顺序。
> 相关文章：[安卓3ds模拟器上手指南.md](安卓3ds模拟器上手指南.md) · [游戏文件格式与解密.md](游戏文件格式与解密.md)

---

3DS 模拟的重头在**单核 CPU 性能和 GPU**，核数堆再多也帮不上忙。机型达到骁龙 835 这条线之后，按本文调一般能稳住大多数游戏；达不到的，下面的设置只能缓和、救不回来。

Azahar 的安装文件资源与基础安装，见 [Azahar 橙花手册](https://azahar.gltd.quest/)，本篇直接从设置讲起。

## 一、图形 API：Vulkan 还是 OpenGL ES

两个后端都支持，选哪个看设备驱动表现：

- 较新的芯片、驱动较新 → 先试 **Vulkan**，不少设备上帧数上限更高；
- Vulkan 下花屏、闪退、黑屏 → 切回 **OpenGL ES** 对照；
- 同一游戏两种 API 表现差异大 → 以实际游戏为准，逐游戏定。

路径不用背：设置里的图形区块找"图形 API"下拉项，切换后重新进游戏生效。

## 二、内部分辨率：清晰与流畅的主旋钮

3DS 原生分辨率很小（上屏 400×240），模拟器按倍数放大内部渲染，这就是"内部分辨率"：

- 倍数越高画面越锐利，GPU 负担也越大；
- 卡顿先**降倍数**，流畅有余再往上加，加到掉帧临界点为止；
- 别无脑拉满——超过手机屏幕物理像素后没有额外收益；
- 开局场景不代表全程负载，跑一段剧情再下结论。

## 三、其他值得动的开关

1. **硬件着色器**：保持开启（默认开），关掉只会更差；
2. **异步 / 后台着色器编译**：打开后新画面在后台编译，能明显减少游戏中"突然卡一下"；
3. **ASTC 解码加速**：部分贴图用 ASTC 压缩，支持的设备上开着；
4. **禁用右眼渲染**：2120 版本加入的性能开关——3DS 即使关掉裸眼 3D 也在渲染左右两份画面，把它省掉后部分游戏性能提升接近一半（项目更新说明给的数字）；个别游戏会出画面异常，逐游戏开着试；
5. **音频缓冲**：爆音、断续时调大；它不是性能开关，别为帧数动它。

## 四、帧数不稳时的排查顺序

1. 降内部分辨率；
2. 换图形 API；
3. 逐个关掉放大相关的附加效果，对照帧数；
4. 清后台、留意发热降频——"越玩越卡"多是降频，摘掉壳、别边充边玩。

按顺序做完还不稳的，多半是设备档次或该游戏的兼容性问题：先查兼容性列表，再回 [安卓3ds模拟器上手指南.md](安卓3ds模拟器上手指南.md) 核对基础设置。
