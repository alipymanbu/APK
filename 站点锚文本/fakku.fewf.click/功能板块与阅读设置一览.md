# fakku 是什么应用：功能板块与阅读设置一览

> fakku 是一款安卓端的漫画阅读应用，漫画与小说装在同一个应用里。这一篇按板块拆开讲它有什么、阅读器里哪些设置值得先调。
> **相关文章**：[下载安装步骤与装不上的处理.md](下载安装步骤与装不上的处理.md) · [离线缓存与账号同步技巧.md](离线缓存与账号同步技巧.md)

## 一、四个板块，各管一段阅读生活

- **漫画主线**：题材覆盖热血冒险、搞笑幽默、浪漫爱情等，页面为高清全彩，长条漫与分镜页漫都有；
- **小说副线**：从底部「精选」顶部一键切换，通勤路上想换文字看时用得上；
- **社区**：关注、热门、最新、插画几个分栏，漫画作者会发更新动态，读者在作品下方留言聊剧情；
- **我的**：书架、下载管理、账号设置都收在这里。

底部导航「首页 / 书架 / 精选 / 社区 / 我」贯穿全部板块，[fakku 应用介绍站](https://fakku.fewf.click/) 上有四张实拍截图，布局一眼能看明白。

## 二、找书的四条路径

刚装好打开首页，推荐位和畅销榜是最快的入口；想看指定的书就用右上角放大镜搜索，搜不到时换同义关键词、少打几个字再试。分类入口里，热血冒险、搞笑幽默、浪漫爱情这类大题材下还有细分，按口味筛即可。

## 三、书架与追更

看到想追的书先进详情页点「收藏」，书架里就能集中管理；连载更新有提醒，阅读记录会记住上次看到的位置，从书架重新打开接着看。收藏建议在登录状态下使用，换手机、重装后收藏才跟着账号走。

## 四、阅读器里值得先调的几项

进阅读页后点一下屏幕中间唤出设置菜单，第一次正式开读前把这几项过一遍：

| 设置 | 作用与建议 |
| --- | --- |
| 阅读模式 | 条漫用卷纸（上下滚动），页漫用分图（按分镜翻页） |
| 智能定位分镜 | 翻页时自动定位到下一格，看页漫更顺手 |
| 竖屏智能修剪 | 看竖版长图时自动裁掉多余留白 |
| 亮度 / 背景 | 阅读页单独调亮度与底色，夜里调暗些 |
| 夜间模式 | 整体换深色，睡前追更不刺眼 |
| 翻页方向 / 横竖屏 | 跨页大图可以试试横屏 |

设置项名称以手机里实际显示为准，不同版本叫法可能略有差别。

## 五、两个使用前提

- 渠道把这款应用标注为「年满十六周岁以上」使用，给未成年人安装前请留意；
- 渠道信息里标注应用含内购项目，哪些内容要解锁以应用内实际显示为准。
