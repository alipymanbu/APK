# Turrit 介绍站：一款主打全场景翻译的 Telegram 客户端

Turrit 是基于 Telegram 开源代码与 API 构建的第三方客户端，登录的就是原来的 Telegram 账号。它把翻译做进了聊天气泡、频道长文和外部网页链接，另有多账号同开、下载加速、隐私检测等原版没有的扩展。

功能与体验的完整介绍见 [Turrit 介绍站](https://turrit.bmww.store/)，安卓安装包的获取指引与安装步骤也在那里。
