# GBA金手指使用与排查

> GBA 时代流传下来的大量金手指码，在安卓模拟器上照样能用。本篇讲码制怎么认、一条码怎么建到游戏里、不生效时按什么顺序排查。
> **相关文档**：[安卓上重温GBA游戏](安卓上重温GBA游戏.md) · [GBA联机对战怎么连](GBA联机对战怎么连.md) · [GBA存档备份与换机](GBA存档备份与换机.md)

My Boy! 这类安卓 GBA 模拟器把金手指菜单直接做进了游戏运行界面：不用外挂工具，游戏中随时开随时关。想先装上模拟器再试码，安装步骤见 [myboy 模拟器介绍站](https://myboy.qhah.skin/)。

## 一、认码制：三类常见码

| 码制 | 说明 |
| --- | --- |
| GameShark | 老牌码制，流传的 GBA 码里占比很高 |
| Action Replay | 同样常见，不少合集码以它为主 |
| CodeBreaker | 第三类，个别游戏圈的码只用它 |

新建金手指时应用会按代码格式自动识别码制；你要做的是选对"跟你这份游戏文件匹配的码"——找码时认准「游戏名 + 版本 + 码制」三个都对得上再粘进来。

## 二、新建并启用一条码

1. 运行游戏后打开模拟器菜单，进 Cheats（金手指）；
2. 新建，填一个自己认得出的名字，粘贴代码；
3. 保存后回到列表勾选启用；
4. 回游戏验证效果；运行中可以随时回来开关某条码。

金手指跟着"游戏"记，换一个游戏，列表互不串。

## 三、码不生效，按这个顺序查

| 现象 | 常见原因 |
| --- | --- |
| 勾选了但没效果 | 码的版本对不上：美版、日版、欧版 ROM 的码不通用 |
| 开码后死机、花屏 | 码本身有误，或与其他已启用的码冲突；全部关掉再逐条开，定位问题码 |
| 效果过一阵消失 | 部分码只在触发场景生效，或需要重启游戏才写入 |

来源不明的码不要一次全开，逐条验证最省事。

## 四、动手前先落一个即时存档

任何一条码启用前，先存一个即时存档——坏码导致的死机、存档异常，读档就能全身而退。存档体系分哪几套、怎么随存随读，见 [GBA存档备份与换机](GBA存档备份与换机.md)；装模拟器与开机三步回 [安卓上重温GBA游戏](安卓上重温GBA游戏.md)；想联机交换的玩法在 [GBA联机对战怎么连](GBA联机对战怎么连.md)。
