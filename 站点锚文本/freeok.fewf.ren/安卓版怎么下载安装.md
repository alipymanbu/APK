# freeok 安卓版怎么下载安装

> 本篇回答一个高频问题：安卓手机想装 freeok，安装包从哪来、装的过程会卡在哪、装完第一次打开要确认什么。
> **相关文档**：[搜片播放与投屏到电视.md](搜片播放与投屏到电视.md) · [离线缓存与观影记录.md](离线缓存与观影记录.md)

## 一、安装前先确认两件事

1. **系统版本**：安卓 5.2 以上即可，安装包只有约 3.4MB，中低端机型也能装。
2. **认准包名**：叫「freeok」的安装包在网上不止一份，版本号、体积、包名各不相同。下载来的这份包名是 `com.zjyhj.android.yf80.apk`，装好后可在系统「应用信息」里核对——装错同名包最常见的表现就是怎么都跑不起来。

## 二、从哪里拿到安装包

推荐先转存再安装：把整理好的安装文件资源转存到自己的网盘账号，再下载到手机存储，原件留了备份，重装也不用重新找。

[freeok 追剧应用介绍站](https://freeok.fewf.ren/)的下载页里放了现成的资源入口和逐步安装说明，按页面按钮走就能拿到。

## 三、安装步骤

1. 在手机的下载列表里点开下载好的 APK。
2. 系统首次会提示「禁止安装来自此来源的应用」：按提示进入「设置 → 应用 → 特殊应用权限 → 安装未知应用」，给浏览器或网盘应用放行，再回来点安装。
3. 等进度走完（包小，几十秒即可），部分机型会再弹一次安全扫描，允许即可。
4. 装完点「打开」进入首页：顶部是搜索框，首页排着热播与推荐内容。

## 四、装完第一次打开要确认什么

- 界面顶部应能看到「首页 / 电影 / 剧集 / 动漫 / 综艺」这一排分类——对上了说明装的是网盘里这份；
- 首次启动会申请网络、存储等权限，看片离不开的是前两项，定位权限拒绝也不影响使用；
- 想验证播放是否正常，直接搜一部剧点开即可，操作细节见 [搜片播放与投屏到电视.md](搜片播放与投屏到电视.md)。
