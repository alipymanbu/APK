# freeok 离线缓存与观影记录

> 没网也要看、换了手机怕丢进度——这一篇讲 freeok 的离线缓存怎么用、观影记录存在哪、什么情况会丢。
> **相关文档**：[安卓版怎么下载安装.md](安卓版怎么下载安装.md) · [搜片播放与投屏到电视.md](搜片播放与投屏到电视.md)

## 一、离线缓存怎么用

1. 在详情页或播放页找到「下载」入口，勾选要缓存的集数（可多选）。
2. 在 WiFi 环境下下载，进度在「我的下载」或缓存管理页里能看到。
3. 下载完在离线状态下从同一入口进入即可播放，通勤、出差不怕没信号。

两点注意：

- 缓存文件持续占存储，下载前看一眼剩余空间；
- 缓存存在应用私有目录里（路径带包名），新版安卓的文件管理器直接打不开——要找、要清都从应用内的「我的下载 / 缓存管理」走，应用没提供导出就导不出来。

## 二、想腾空间时怎么清

路径：系统「设置 → 应用 → freeok → 存储」。

- **清缓存**：只删临时文件，播放记录和下载列表都还在——拿不准就先用它；
- **清数据**：等同重置，播放记录和缓存一起清空——动手前想清楚。

卸载应用时私有目录一并删除，缓存不会残留在手机里。

## 三、观影记录在哪、会不会丢

首页右上角的**时钟图标**就是「我的观影记录」，按时间倒序排列最近看过的内容，带上次的集数与进度，点任意一条直接续播。

记录的存续情况：

| 情况 | 记录状态 |
| --- | --- |
| 正常使用 | 保留，随时间累积 |
| 清除应用数据 | 被清空，无法找回 |
| 卸载重装 | 随卸载一起清空 |
| 换新手机 | 不会自动带过去 |

部分版本登录账号后支持记录同步，是否生效以手上版本的实际表现为准——别把它当唯一备份，追到关键集数先手动记一下。

## 四、缓存失败或记录不见了

- 缓存失败先查存储权限是否被关：系统「设置 → 应用 → freeok → 权限」里把存储打开再试；
- 记录列表空白，多半是清过数据或装的是另一份同名包——核对包名最快的入口见 [安卓版怎么下载安装.md](安卓版怎么下载安装.md)。

功能盘点与安装文件资源入口见 [freeok 追剧应用介绍站](https://freeok.fewf.ren/)。
