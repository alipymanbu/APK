# 手机 Python 编程入门：从装环境到跑通第一行代码

想在安卓手机上学 Python、写点小脚本，桌面电脑并不是必需品。这篇讲清楚手机上写 Python 需要什么、Pydroid 3 在里面扮演什么角色，以及一条走得通的学习路径。

## 一、手机上写 Python，缺的是什么

Python 本身是解释型语言，跑起来不需要编译环境；真正缺的是三样：

1. **解释器**——安卓系统不自带 Python，得有一个应用把它装进来；
2. **编辑器**——能高亮、能缩进、能快速插入 Python 符号的输入环境；
3. **装库通道**——第三方库要能装得上，最好不用自己在手机上折腾编译。

Pydroid 3 把这三样收进了同一个应用：离线解释器、带扩展键盘条的编辑器、pip 加预编译库仓库，装一次全解决。它的功能划分与真机界面，可以看 [pydroid3 整理站](https://pydroid3.gerw.hair/) 上的速览。

## 二、第一步不是学语法，是跑通一个示例

应用内置了一套开箱即用的示例，覆盖基础语法和常用库。建议的起步动作：

1. 打开示例列表，挑一个最短的跑起来，确认环境没问题；
2. 改一行输出，再跑，确认改动生效；
3. 从这一行开始，逐步把示例换成自己想写的东西。

「先跑通、再修改」比对着教程空敲快得多，报错也更具体。

## 三、装第三方库的正确时机

语法过一遍就可以开始装库了。requests、beautifulsoup4 这类纯工具库随手就能装；numpy、matplotlib 这类科学计算库在 Pydroid 3 里走预编译仓库，也不需要漫长的等待。装库的细节与排错见[pip 装库与环境配置](pip装库与环境配置.md)。

## 四、写代码之外，还要会看报错

手机小屏读报错有技巧：红色的那一行是关键，定位不到就往红色行上面多看一两行，调用链通常在前面。更系统的调试手段（断点、单步、监视变量）见[运行与调试技巧](运行与调试技巧.md)。

## 五、设备的边界要提前知道

- Android 对后台限制严格，长任务可能被省电机制回收；
- 存储权限没给到位时，文件打不开、保存失败；
- 可移动存储（SD 卡、U 盘）访问不了，文件先复制进内置存储。

这些坑都能绕过，提前知道比撞上再查省时间。环境装好之后，剩下的就是坚持写——手机碎片时间足够把 Python 入门走完。
