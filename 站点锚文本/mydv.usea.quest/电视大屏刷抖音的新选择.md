# 电视大屏刷抖音的新选择

在电视上看手机里的短视频，过去基本只有投屏一条路。这篇文章聊聊投屏的老毛病、电视端客户端的新玩法，以及一个值得先试再说的开源项目。

## 投屏的麻烦，用过都懂

手机投屏看抖音，流程是这样的：掏出手机 → 找到投屏开关 → 等两台设备连上 → 手机变成遥控器兼播放器，屏幕还被占着。想回个微信，电视上的画面就断了；家人想换条视频，还得把手机递来递去。

更根本的问题是：抖音没有电视版应用，手机版硬装进电视又对不上横屏，遥控器基本派不上用场。这个空位，被一个开源项目补上了。

## myDV 是个什么东西

myDV 是 GitHub 上的开源项目（GPL-3.0 协议），作者是把它当「AI 写代码」的演示作品做出来的，README 里还写着「卡是正常的，保持深呼吸」这种自嘲——但它在电视用户社区里被反复讨论，版本一路更到了 1.5.x。

它的价值不在功能多，而在**全部操作都长在遥控器上**：

- 上下键切换视频，就是刷抖音那个手感；
- OK 键暂停、继续；
- 左键调出相关视频推荐面板，右键调进度条快进快退；
- 长按菜单键改画质、倍速、弹幕；
- 连按两次返回键退出应用。

安装包不到 9MB，Android 6.0 以上的电视和盒子都能装。打开就是推荐流，**不登录账号也能直接刷**。

## 要不要配 Cookie

想看关注流、自己的喜欢和收藏，才需要登录。myDV 的做法是在电脑浏览器上登录抖音网页版，用 Cookie 管理插件把登录后的 Cookie 整串导出，粘进电视端设置里。两个要点：一要整串导出，只抠一个字段会登录不上；二别用浏览器控制台去取，敏感字段拿不到。

Cookie 过段时间会失效，表现是关注流突然打不开，重新导一份覆盖填上就好。

## 实话实说的短处

- 个人开源项目，更新节奏跟着作者走，接口一变功能可能临时失灵；
- 个别版本的搜索时灵时不灵，部分视频加载会卡；
- Cookie 登录对不折腾的用户有门槛。

介意这些，把它当一个好玩的实验；不介意，它就是遥控器手感最好的大屏抖音方案之一。[myDV 电视端介绍站](https://mydv.usea.quest/)整理了它的界面实拍、按键对照和安装步骤，装之前可以先过一遍。
