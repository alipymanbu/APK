# PDF 文献批注从导入到导出

> 把文献装进平板逐页批注，是手写笔记应用最常用的场景之一。这篇按「导入 → 腾地方 → 边读边记 → 整理 → 导出」的顺序，把每一步的关键设置讲清楚。
> **相关阅读**：[安卓平板手写笔记应用怎么选](安卓平板手写笔记应用怎么选.md) · [手写笔记备份与换机迁移](手写笔记备份与换机迁移.md)

---

## 一、导入：格式比想象中宽

以 StarNote 为例，除了 PDF，PPT 课件、DOC 讲义、EPUB 与 MOBI 电子书、TXT 都能直接导入，拍照或选图片可以把纸质资料收进来批注；知网下载的 CAJ 文献也在支持之列，这一点对常查文献的人相当实用——不少安卓批注应用不认这个格式。

导入路径：进入一本笔记后用「导入」选择设备里的文件，每一页都可以直接书写。

## 二、页面留白：给密排文档腾出写字的地方

期刊论文和教材的排版通常很满，直接批注没有落脚处。用「页面留白」把文档往一侧缩，空出的白边专门用来写笔记：

- 给整本教材留出固定的批注位；
- 给试卷留出演算位；
- 原文件排版不动，导出时批注跟着页面一起走。

## 三、双开：一边读一边记

开启双开后屏幕分成两块，左边放 PDF、右边写笔记。上课「课件在左、笔记在右」，读文献时把摘录写在旁边。看视频网课还能配合画中画，课程视频浮成小窗，笔记接着写。

## 四、整理：让批注能被找回来

批注写了一堆找不着，等于没写。几件值得做的事：

1. **摘录互联**：把文档里的一段文字或一处图摘出来、引用到另一本笔记，两处内容互相链接，复习时顺着链接跳回原文；
2. **标签体系**：给笔记打标签、搭知识框架，零散的知识点按主题归拢；
3. **OCR 搜索**：导入的 PDF 与手写内容都能按关键词全文搜索，外文文献配合划词翻译阅读更快。

工具层面，图层把原稿和批注分开；套索圈选后整体移动缩放；放大镜适合在密排行间写小字。

## 五、导出：交作业、存档、分享

| 导出格式 | 用在哪 |
| --- | --- |
| PDF | 打印、提交、长期存档（可带手写批注） |
| PNG / JPEG | 单页取用、插到别处、发社交平台 |

导出入口在笔记的分享 / 导出菜单，带不带批注可以在导出选项里选；不用整本导出时，可以只挑部分页面。
