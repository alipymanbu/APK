# AstrBot 相关资源与使用指引（astrbot.bmww.store）

这里是围绕 AstrBot 安卓版的第三方整理页入口：AstrBot 是一个开源的 Agentic 聊天机器人框架，而它的安卓 App 封装把框架、QQ 协议适配和容器环境装进了一个安装包，让「手机上把 QQ 号变成 AI 机器人」成为零命令行的操作。 astrbot.bmww.store 整理了它的功能盘点、上手路线与注意事项，并附安装包的获取入口。

- [支持哪些大模型怎么接.md](支持哪些大模型怎么接.md) —— 能接哪些模型、密钥从哪申请、在面板里怎么填

## 一句话了解它

安卓 App = AstrBot 框架 + NapCatQQ 协议适配 + Ubuntu 容器环境，三合一 APK。安装后首次启动全自动初始化，弹出 QQ 登录二维码扫码即接入，模型密钥在内置管理面板里填，支持 OpenAI、Gemini、Claude、DeepSeek、智谱、Ollama 本地模型等。功能与安装细节见 [astrbot.bmww.store](https://astrbot.bmww.store/)。
