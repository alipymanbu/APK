# AstrBot 支持哪些大模型，密钥怎么填

> 本篇回答两个高频问题：这套机器人能接哪些大模型、API Key 从哪申请往哪填。口径以框架当前版本为准，各平台的价格与免费额度随时会变，接入前以对应平台当时的页面为准。
> **相关文档**：[手机上部署QQ机器人.md](手机上部署QQ机器人.md) · [封号风险与日常保活.md](封号风险与日常保活.md)

## 一、支持的模型一览

AstrBot 框架同时兼容 OpenAI、Google、Anthropic 三种原生接口，外加一切「OpenAI 兼容」的第三方服务。落到实际选择上：

| 你的情况 | 可选的接法 |
| --- | --- |
| 有国外大平台账号 | OpenAI（GPT 系列）、Google Gemini、Anthropic Claude 原生接口 |
| 用国产模型 | DeepSeek、智谱（GLM）、Kimi、MiniMax 等，多走 OpenAI 兼容接口 |
| 想零成本跑本地模型 | Ollama、LM Studio 里部署的开源模型，填本机或局域网地址即可 |
| 有现成的智能体应用 | Dify 等应用可直接作为提供商接入 |

聚合平台如硅基流动也支持：一个 Key 可调多家开源模型，适合想同时试几个模型的场景。

## 二、API Key 从哪申请

| 平台 | 申请入口 | 备注 |
| --- | --- | --- |
| DeepSeek | platform.deepseek.com | OpenAI 兼容，base_url 为 api.deepseek.com |
| 硅基流动 | siliconflow.cn | 聚合多家开源模型，新用户通常有免费额度 |
| Ollama / LM Studio | 不需要 Key | 跑在自己设备上，填地址就行 |
| OpenAI / Gemini / Claude | 各自的开放平台 | 需要相应账号与网络条件 |

## 三、在手机面板里怎么填（安卓 App）

1. QQ 扫码登录后，App 会自动打开内置管理面板；
2. 进入「模型提供商」（Provider）页面，点新增；
3. 选择服务商类型（如 DeepSeek / OpenAI 兼容），粘贴平台发给你的 API Key，确认 base_url；
4. 保存后获取模型列表，选一个设为默认对话模型；
5. 按提示**重启机器人**，配置才生效。

验证方法：在 QQ 里给机器人发一条消息，能回就说明模型接通了。

## 四、插件装上之后能力更宽

框架核心保持轻量，翻译、联网搜索、长期记忆、群管理这些能力大多由插件提供，在面板的插件页一键装卸，生态里有上千个可选。装完插件记得用 `/help` 看一眼新指令清单。

模型与插件都就位后，剩下的就是日常使用与保活了，相关注意点见 [封号风险与日常保活.md](封号风险与日常保活.md)；还没装好的先回 [手机上部署QQ机器人.md](手机上部署QQ机器人.md) 走完部署流程。安装包与更多整理见 [astrbot.bmww.store](https://astrbot.bmww.store/)。
