# 手机上部署QQ机器人：不开电脑的完整路线

> 本篇讲怎么只靠一台安卓手机，把一个 QQ 号变成能自动回消息、会调用大模型的机器人——用的是 AstrBot 框架的安卓 App 封装，全程不碰命令行。
> **相关文档**：[支持哪些大模型怎么接.md](支持哪些大模型怎么接.md) · [封号风险与日常保活.md](封号风险与日常保活.md)

---

## 一、为什么手机就能部署

在服务器上部署聊天机器人框架，通常要装 Python 或 Docker、配协议端、改配置文件。而 AstrBot 的安卓 App 把三样东西打成了一个安装包：

| 组件 | 作用 | 需要你动手吗 |
| --- | --- | --- |
| AstrBot 框架 | 大模型接入、插件、人设、知识库 | 不需要，自动装 |
| NapCatQQ 协议适配 | 与 QQ 收发消息 | 不需要，自动装 |
| Ubuntu 容器环境 | 承载前两者的运行环境 | 不需要，自动装 |

三样都装在同一部手机里，手机就是机器人的主机。

## 二、部署全过程（五步）

1. **拿安装包**：从 astrbot.bmww.store 的获取入口把 APK 转存下载到手机；
2. **安装**：点开 APK，系统提示「未知来源应用」时选择允许；
3. **首次启动初始化**：全自动下载容器环境与组件，屏幕是一条紫色进度条，点一下屏幕可切到终端日志页看进度。建议连家用 Wi-Fi、屏幕保持常亮；中途卡住就关掉 App 重开，会从断点继续；
4. **QQ 扫码**：初始化完成的标志是屏幕弹出 QQ 登录二维码，用手机 QQ 扫一下即接入；
5. **填模型密钥**：扫码后自动进入内置管理面板（默认账号密码都是 astrbot，记得改），在「模型提供商」里新增一家、粘贴 API Key、保存并重启。

给机器人发条消息能收到自动回复，整条链路就算通了。

## 三、装完之后的两件小事

- **保活**：机器人靠一条常驻通知维持后台，这条通知别手动清；再把 App 加进电池白名单，避免息屏久了被系统杀掉；
- **别混登**：机器人走的是 QQ 电脑端协议，同一个号别再在电脑 QQ 上登录，两边互挤会掉线。

## 四、手机路线的边界

当前版本的安卓 App 只支持 QQ 个人账号，微信、Telegram、钉钉等平台接不了，代码沙箱这类依赖完整容器能力的功能也默认不可用。想接多平台、跑完整功能，就要走电脑或服务器部署完整版框架——配置概念（提供商、插件、人设）与手机版一致，迁移不难。

动手前建议先看一眼 [封号风险与日常保活.md](封号风险与日常保活.md)，第三方协议接入对账号意味着什么，先了解再决定用哪个号。
