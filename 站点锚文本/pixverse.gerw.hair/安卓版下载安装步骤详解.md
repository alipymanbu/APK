# PixVerse 安卓版下载安装步骤详解

PixVerse 的安卓安装包不能靠应用商店以外的散装链接乱碰，比较稳妥的路径是先拿到安装包文件，再按安卓的流程装。本文按顺序讲：怎么拿到包、怎么过「未知应用」这道坎、装完第一步做什么。想先了解这款工具能干什么，可以看[提示词怎么写出好片子](提示词怎么写出好片子.md)和[积分免费额度与水印答疑](积分免费额度与水印答疑.md)。

完整的介绍页与获取入口在 [PixVerse 站点](https://pixverse.gerw.hair/)，那里把功能玩法、出片样例和安装包入口放在了一起。

## 一、装之前的三个条件

- **系统版本**：安卓 5.2 以上，低于这个版本装上也会闪退；
- **存储空间**：安装包 205MB 上下，加上安装展开与缓存，建议预留 1GB；
- **一个能收验证码的邮箱或手机号**：注册要用，也支持 Google、Apple、Discord 账号直接登录。

## 二、下载安装包

从上面给的站点入口进介绍页，页面上「获取安装文件资源」按钮指向夸克网盘的分享页：先**转存**到自己网盘，再下载 APK 到手机。手机端直接操作最省事；电脑下载的话，用数据线把文件传到手机的「下载」目录即可。

## 三、安装四步

1. 在文件管理器里点下载好的 APK；
2. 首次安装会弹「禁止安装未知应用」——点「设置」，允许你的文件管理器安装应用，返回后重试；
3. 等进度条走完（中低端手机约一两分钟，别中途取消），点「打开」；
4. 同意用户协议，选一种方式注册登录。

## 四、装完第一小时

- **先玩模板**：「模板」标签里有几百个现成效果，上传照片就能出片，最快见效；
- **再试图生视频**：挑一张光线均匀的正面照，配一句动作描述；
- **积分当日有效**：注册送一笔、每天登录再送一笔，当天用不完会清零，别攒着。

## 五、装不上怎么办

- **解析包错误**：多半是下载不完整，核对文件约 205MB，删掉重下；
- **安装按钮灰着**：存储不足，清出空间再试；
- **点开闪退**：确认系统版本达标，重启或重装——作品存在云端账号里，重装不丢。
