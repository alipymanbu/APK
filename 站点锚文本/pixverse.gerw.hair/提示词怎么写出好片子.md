# PixVerse 提示词怎么写出好片子

同样的工具，有人出的片能直接发账号，有人出的片五官乱飞——差距基本都在提示词上。本文给一套能直接照抄的写法框架，再讲文生视频与图生视频各自的侧重。安装与注册流程见[安卓版下载安装步骤详解](安卓版下载安装步骤详解.md)。

玩法全景与出片样例收录在 [PixVerse 介绍站](https://pixverse.gerw.hair/)，本文只聚焦「怎么把一句话写到位」。

## 一、五个格子填空法

一个稳定的写法框架是：**主体 + 场景 + 动作 + 镜头 + 光线/氛围**。

| 格子 | 回答的问题 | 示例 |
| --- | --- | --- |
| 主体 | 谁在画面里 | 一只橘猫 / 一辆复古敞篷车 |
| 场景 | 在哪里 | 雨夜的便利店门口 |
| 动作 | 做什么 | 撑伞走过水洼 |
| 镜头 | 怎么拍 | 缓慢推进 / 环绕 / 俯拍 |
| 光线氛围 | 什么调子 | 霓虹反光 / 黄昏暖光 |

照着填：「一只橘猫（主体）在午后窗台（场景）跳上书堆（动作），镜头缓慢推近（镜头），暖黄阳光洒在毛上（氛围）」。

## 二、三条硬规矩

1. **长度卡在 25~200 个词**：超过 2048 个字符接口直接报错；只写「山湖日出」四个字又太省，画面没有可执行的信息。
2. **5 秒别塞三个动作**：时长装不下，每个动作都做不完，画面会闪变、主体变形。想讲完整故事用「延长」功能把 5 秒续成更长。
3. **英文通常更稳**：不确定就中英各生成一次对比；新模型对原生音频与多镜头的支持也在持续更新，以 App 内实际可选为准。

## 三、图生视频的侧重

图生视频吃的是**素材质量**：主体清晰、背景干净、光线均匀的图最容易出效果；模糊、逆光、多人重叠的图容易出错。动作描述要写明确的动词——「转身」「跳跃」「挥手」，默认动态往往只是轻微呼吸感。一次不理想，换图的收益通常大于改提示词。

规格上有两条硬限制：单张图不超过 20MB、边长不超过 10000px，超了直接被拒，长截图先裁。

## 四、不想写提示词就走模板

「模板」标签里有几百个现成的「效果 + 提示词」组合，上传照片点生成就行：亲吻、拥抱这类双人效果要 2 张照片，变身、换装单人即可。两个限制提前知道：部分特效不支持 720p/1080p（退回 480p 就能跑），且特效每月有激活次数上限。
