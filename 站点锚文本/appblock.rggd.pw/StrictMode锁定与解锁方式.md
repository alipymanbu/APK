# StrictMode 锁定与解锁方式

本篇讲 AppBlock 区别于同类工具的核心：Strict Mode。它解决的是所有拦截工具共同的悖论——定规则的人也是能撤销规则的人。锁定了什么、五种解锁方式各自适合谁、防卸载要不要开，一篇说清。还没装应用的先看[安卓版安装步骤与权限配置](安卓版安装步骤与权限配置.md)。

---

## Strict Mode 锁住什么

普通拦截状态下，你随时能进应用改规则、关拦截。Strict Mode 激活后，三件事同时被锁：

- **规则改不动**——Schedules 和 Quick Block 的设置进不去也改不了；
- **设备设置进不去**——可选项里能把系统设置入口一并锁掉，堵住「去系统里停用它」的路；
- **应用删不掉**——勾选防卸载后，锁定期内连 AppBlock 本身都无法卸载。

应用公开的问卷口径显示，55% 的用户表示离不开这个模式，开启后首月屏幕时间平均下降 63%。数字是自报口径，但逻辑很实在：把「再等 15 分钟」的按钮从自己手里拿走，提醒才能真正起作用。

## 五种解锁方式怎么选

激活 Strict Mode 前要先选一种解锁方式，决定锁定期结束后（或紧急情况下）你怎么出来：

| 方式 | 机制 | 适合谁 |
| --- | --- | --- |
| PIN 码 | 输码解锁，码别设生日 | 需要应急通道的人 |
| 充电器 | 插上充电器才能解 | 睡前锁机，起床才解锁 |
| 定时器（Timer） | 设定时长，到期自动解锁 | 考试周、项目冲刺这类有明确终点的 |
| 倒计时冷却（Cooldown） | 申请解锁后等一段冷静期 | 怕冲动解锁的，等的过程会劝退大部分念头 |
| 同伴批准（Approval） | 由被授权的另一个人批准 | 两个人互相监督，最硬的一条 |

前置条件注意：Strict Mode 必须先有 Quick Block 或 Schedules 规则才能启用——它锁的是已有规则，空转没有意义。

## 三个务实建议

1. **第一次用选 Cooldown，别选 PIN。** 冲动之下 PIN 是能输的，而冷却期给出的延迟足够让大部分念头过去；PIN 留给真正需要应急通道的场景；
2. **锁定范围从窄开始。** 先只锁一两个最耗时间的应用和固定时段，跑一周再加码——锁太狠的结果往往是「一气之下全清空」，那正是防卸载选项想防的事；
3. **锁定规则前先验证规则本身。** 用 Quick Block 试拦一次确认权限都给齐了，再上 Strict Mode，否则锁住的是一套失灵的配置。
