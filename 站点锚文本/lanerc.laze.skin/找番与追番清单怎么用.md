# Lanerc 找番与追番清单怎么用

> 讲在 Lanerc 里定位想看作品的三条路：搜索、分类筛选与首页推荐，以及收藏追番清单、登录后能解锁哪些功能。
> **相关文档**：[每周排期表怎么看](每周排期表怎么看.md) · [安装后常见问题排查](安装后常见问题排查.md)

Lanerc 的内容以日本动画为主，TV 动画、剧场版动画电影和 OVA 都在收录范围，热血、恋爱、奇幻、冒险等题材各自成区。东西多了，「怎么找到想看的」就成了第一个要解决的问题——界面的完整拆解见 [Lanerc 找番玩法笔记](https://lanerc.laze.skin/)，本篇讲路径。

## 一、按手头的信息选路径

| 场景 | 走哪条路 |
| --- | --- |
| 知道作品名字 | 直接用搜索框输入名称，最快 |
| 只记得题材或画风 | 按分类筛：题材、年份、地区可以组合着缩小范围 |
| 想看电影版 | 进剧场版专区，那里把剧场版单独归拢 |
| 没有明确目标 | 翻首页推荐和更新列表，新番与经典作品分开展示 |

搜索有个常见坑：同一部日本动画往往有不止一个译名，中文名搜不到时，换另一个译名、简称或日文原名再试；还找不到就走分类筛选，可能只是名字对不上。

## 二、进详情页确认三样东西

点封面或标题进入作品详情页：剧情概述（决定看不看）、分集列表（决定从哪集开始）、更新状态（连载中标到第几集，完结标总集数）。追连载时这个页面就是进度参照。

## 三、收藏与追番清单

看到想追但暂时没空看的作品，加入收藏或追番清单，之后在「我的」页面集中查看并继续播放。几点说明：

- **登录后清单功能才完整可用**，评论区、弹幕这些互动同样需要登录状态；注册之后还有一道「入站问答」，答够题目数量才能参与社区互动；
- 部分作品支持更新提醒，订阅后有新内容会上通知，入口以手上的版本实际界面为准；
- 离线缓存的用法与播放器里能调的东西（清晰度、倍速、弹幕开关），装好应用后按界面提示操作即可，遇到问题先看[安装后常见问题排查](安装后常见问题排查.md)。

## 四、没装应用的先补课

Lanerc（原 Omofun 更名后的版本）是安卓端应用，获取方式与安装步骤都整理在 [Lanerc 排期表笔记站](https://lanerc.laze.skin/)的下载页里，装好再回来照本篇找番。
