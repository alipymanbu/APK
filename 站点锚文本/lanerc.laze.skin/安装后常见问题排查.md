# Lanerc 安装后常见问题排查

> 覆盖 Lanerc 装好之后最容易碰到的几类问题：首次打开的权限请求、打不开或闪退的通用排查、播放卡顿的处理顺序。
> **相关文档**：[每周排期表怎么看](每周排期表怎么看.md) · [找番与追番清单怎么用](找番与追番清单怎么用.md)

安装环节的问题（放行未知来源、包损坏重下这类）在获取安装包的页面上有专门整理，入口见文末；本篇从「装好了但用不顺」讲起。应用的界面速览与功能盘点，可以参考 [Lanerc 使用笔记站](https://lanerc.laze.skin/)，此处不再重复。

## 一、首次打开的权限请求

第一次打开 Lanerc 通常会请求存储权限——离线缓存要用到它，打算缓存剧集的话就允许；只在线看、不缓存，拒绝也不影响浏览和播放。

## 二、打不开、点开就退，按顺序做

1. **强制停止后重开**：设置 → 应用管理 → Lanerc → 强制停止，再点开；
2. **清缓存**：应用信息 → 存储 → 清除缓存，缓存数据损坏是闪退的常见原因；
3. **查存储空间**：剩余空间过少会让应用运行异常，离线缓存塞满时先清掉看完的旧包；
4. **查权限**：把被拒的关键权限逐个放开试，不需要无脑全开；
5. **重启手机**：长时间没重启的设备，这一步偶尔直接解决；
6. **卸载重装**：最后才做——卸载会清掉本地数据，已缓存的剧集和登录状态都会丢。

还有一种情况值得先查：**版本本身**。这支应用的历史版本出过需要紧急修复的状况（第三方渠道收录的更新日志里，1.0.7 曾因安全隐患被紧急替换），莫名闪退时可以考虑换新版安装包重装。

## 三、能打开但播放卡顿

按这个顺序处理，多数走到前两步就好：

1. 确认手机网络本身可用，切一下 Wi-Fi / 流量；
2. 把清晰度调低一档，卡顿大多出在带宽跟不上当前档位；
3. 同一集有其他线路就换一条（播放页里的「换源」入口），换源不换进度；
4. 停掉后台占带宽的下载、同步任务。

按顺序走完还不行，多半是内容源临时出问题，过一阵再试。

## 四、获取安装包

需要重装或换新版本时，从 [Lanerc 排期表笔记站](https://lanerc.laze.skin/)进下载页：那里有安装包的网盘入口和完整的安装步骤，装完回到[每周排期表怎么看](每周排期表怎么看.md)开始追番。
