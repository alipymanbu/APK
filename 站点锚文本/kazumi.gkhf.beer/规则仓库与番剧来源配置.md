# Kazumi 规则怎么加：仓库导入与来源切换

> 装好 Kazumi 后列表是空的，多半是规则还没就位。本篇讲规则从哪来、怎么导入、来源失效时怎么换。
> **相关文档**：[新番时间表与追番管理.md](新番时间表与追番管理.md) · [和好友一起看新番的步骤.md](和好友一起看新番的步骤.md)

---

Kazumi 与常见播放器最大的不同，在于它本身不带任何视频内容——你搜到的每一部番，都来自「规则」对接的资源。所以打开 app 看到空列表，不是装坏了，而是还没把规则配好。本篇按实际操作顺序，讲清规则的添加与更换。

## 一、先弄明白规则是什么

一份规则就是一段配置，它告诉 Kazumi 从哪个平台取番剧列表、分集信息和播放地址。规则通常以 JSON 或 XPath 的形式存在，由社区维护、互相分享。你不需要看懂它，只需要会导入。

## 二、四个入口，走第一个就够

进入底部「我的」页，点「规则管理」，再点右上角的加号，会看到几种添加方式：

| 方式 | 适合谁 | 说明 |
| --- | --- | --- |
| 从规则仓库导入 | 绝大多数人 | 规则仓库建在 GitHub 上，选一条安装即可，最省事 |
| 从剪贴板导入 | 拿到别人分享的规则串 | 复制后粘贴进来就能用 |
| 导入 JSON 文件 | 手上有规则文件的 | 从本地存储选择文件导入 |
| 手动创建 | 想自己写规则的 | 需要了解 XPath 写法，新手不必碰 |

从仓库导入时，列表里通常同一天内有好几条同类规则。先装一两条试试加载速度，不满意再换，不必全装。

## 三、导入之后：切换来源

规则装好不代表完事。回到浏览页，顶部可以切换当前使用的来源；同一条规则在不同番剧上的表现也不一样。习惯的做法是：配两三条规则，哪条对当下这部番响应快就用哪条。

## 四、规则失效了怎么办

来源平台改版后，个别规则会暂时失效，表现为列表加载不出或播放报错。处理顺序：

1. 先换一条已装的规则，确认是规则问题还是网络问题；
2. 都不行时，回规则仓库重新导入新版本；
3. 仓库里也没有可用的新版，就等社区更新，期间不影响其他番剧观看。

装好后想按星期追新番，可以接着看[新番时间表与追番管理](新番时间表与追番管理.md)；规则配好之后，[和好友一起看新番的步骤](和好友一起看新番的步骤.md)也值得顺手学会。整条流程的完整梳理，见 [Kazumi 追番手册](https://kazumi.gkhf.beer/)。
