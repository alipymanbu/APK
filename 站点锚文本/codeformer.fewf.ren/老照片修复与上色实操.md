# 老照片修复与上色实操：翻拍、修补、上色一条龙

> 本篇专讲用 codeformer 翻新老照片：纸质照片怎么翻拍才好修、修补和上色按什么顺序跑、以及对结果的合理预期。
> **相关文档**：[人脸修复怎么用.md](人脸修复怎么用.md) · [AI人脸修复应用是什么.md](AI人脸修复应用是什么.md)

---

## 一、哪些老照片值得交给它

- 人脸模糊到五官分不清、只剩轮廓的；
- 相纸有折痕、划痕、缺角的；
- 黑白照、褪色发黄想还原色彩的。

三种问题对应的功能不一样：模糊靠人脸增强，破损靠修补，黑白上色是单独的入口，导入前先在首页选对功能。

## 二、翻拍质量决定修复上限

修图应用处理的是电子版，纸质照片翻拍这一步做对了，修复就成功了一半：

1. 找光线均匀的地方，靠窗的自然光最好，别用闪光灯——相纸会反光；
2. 手机正对照片拍摄，别斜着拍，避免透视变形；
3. 照片撑满取景框，四周留一点边即可，拍完裁掉多余背景；
4. 带玻璃相框的先把照片取出来拍，玻璃的反光和倒影会被当成画面内容。

已经拍歪、拍暗的电子版也能修，但先重拍一遍往往比后期补救更快。

## 三、修补与上色的顺序

1. 打开应用，导入翻拍好的照片；
2. 破损划痕先选修补类功能跑第一遍，把画面「物理」上补完整；
3. 再选上色入口跑第二遍，先修补后上色比反过来稳得多——上色算法不必再跟划痕较劲；
4. 修复幅度滑块按[人脸修复怎么用.md](人脸修复怎么用.md)第三节的心法调：不像本人往保守拉，细节不够往激进拉；
5. 每一遍出预览都对比一下原图，满意再进入下一步，最后统一保存到相册。

## 四、对结果的合理预期

| 期望 | 实际情况 |
| --- | --- |
| 划痕折痕消失 | 大部分能修掉，跨越人脸的大面积破损可能留痕迹 |
| 黑白照变彩色 | 颜色是算法推断的，衣服背景未必与现实一致，肤色通常更接近常理 |
| 认不出的人修到能认 | 信息量够时效果明显；损坏到只剩轮廓时，补出的长相属于「合理想象」 |
| 五官与本人一致 | 滑块往保留原样方向调会更像，清晰度提升相应变小 |

补出来的部分是推断，不是复原——这是这类工具的边界。修完的照片配上翻拍前后的对比，家庭相册数字化已经足够体面。工具的背景与形态区别见[AI人脸修复应用是什么.md](AI人脸修复应用是什么.md)，功能演示与安卓安装文件入口整理在[codeformer 人脸修复站](https://codeformer.fewf.ren/)。
