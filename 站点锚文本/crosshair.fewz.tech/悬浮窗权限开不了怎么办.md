# 悬浮窗权限开不了怎么办

> 屏幕准星类工具全靠「显示在其他应用上层」这一项权限吃饭，权限没给到位，准星就叠不到游戏画面上。本篇集中处理授权环节的三种卡壳：入口找不到、开关是灰的、授权时弹「屏幕叠加层已检测到」。工具本身的安装与使用见[手机射击游戏怎么加准星](手机射击游戏怎么加准星.md)，装完想对准弹道看[准星位置对不准弹道怎么调](准星位置对不准弹道怎么调.md)。

---

## 一、先确认你遇到的是哪一种

| 现象 | 对应小节 |
| --- | --- |
| 第一次点 Start 没弹授权页，准星不出现 | 第二节 |
| 悬浮窗开关是灰的、点不动，或提示「受限」 | 第三节 |
| 授权时弹「检测到屏幕叠加层」，按钮点不了 | 第四节 |

## 二、手动补开权限

第一次点 Start 时如果没弹出授权页（或当时点了拒绝），手动去系统设置开：设置 → 应用 → Crosshair → 权限 → 「显示在其他应用上层」。部分品牌还有一道独立的「悬浮窗管理」（常在手机管家里），也要一并放行。找不到入口就在设置顶部搜索「悬浮窗」。开好后把应用从最近任务划掉重开，再点 Start。

另外注意省电策略：有些手机会在锁屏或切游戏后清理后台，把应用加入电池白名单 / 自启动名单（小米叫「省电策略无限制」，华为叫「电池优化不受限」），准星才稳定。

## 三、开关是灰的：允许受限设置

安卓 13 起对商店外安装的应用收紧了权限，悬浮窗开关可能灰置或提示「受限」。处理顺序：

1. 设置 → 应用 → Crosshair → 右上角三点菜单 → 点「**允许受限设置**」，多数情况点了就解；
2. 没有这一项时，先把系统更新装到最新再回来找；
3. 登录了公司账户或开了工作资料的，先退出工作资料再授权；
4. 仍无效就卸载后用系统自带文件管理器重新安装一遍再授权——安装来源会影响系统的信任判定。三星机型还多一道「自动拦截器（Auto Blocker）」，位置在 设置 → 安全和隐私 → 更多安全设置，临时关掉装完再开。

## 四、弹「屏幕叠加层已检测到」

这个弹窗的意思是：此刻屏幕上（或后台里）还有**另一个**应用开着悬浮窗，系统要求先清屏再授权——从安卓 6.0 起的既有安全机制，与准星工具本身无关。处理三步：

1. 点弹窗里的「打开设置」跳到悬浮窗权限列表；
2. 找嫌疑应用临时关掉它的悬浮窗开关，高频元凶按命中概率排：聊天工具的气泡悬浮回复、蓝光过滤 / 护眼滤镜、录屏投屏工具、清理提速类应用、游戏加速器、其他悬浮球侧边栏；
3. 回授权页重试，成功后把刚才关掉的开关恢复。

一次只关一个再试，比全关再逐个恢复省事。列表里实在看不出谁在捣乱，就重启进安全模式（长按关机选项直到弹出安全模式提示），在安全模式里把权限授好，再正常重启——权限会保留。

权限开好、准星叠上屏幕后，下一步就是把它对准游戏里的真实弹道，方法见[准星位置对不准弹道怎么调](准星位置对不准弹道怎么调.md)。
