# BeautyPlus 一键美颜怎么用

> 本篇按「拍照 → 一键美颜 → 五官皮肤精修 → 上妆 → 调身材」的顺序过一遍 BeautyPlus 的人像功能，每一步都写清入口和实操建议。刚装好想快速出片的，照这个顺序走一遍就够。

## 一、先分清两个入口

- **相机**：首页的拍摄入口，直接取景，拍完自动进编辑流程；
- **编辑**：从相册导入已拍好的照片再修，适合处理旧照片。

美颜分两层：**一键美颜（HD Retouch）**负责整体效果，只调强度；**手动工具**按部位逐项调，人像调整工具有 22 项以上。日常自拍用一键的就够，想精修再进手动。

## 二、一键美颜（HD Retouch）

1. 选照片（或拍完一张）进入编辑；
2. 找到 HD Retouch，应用后面部轮廓和皮肤会自动处理一遍；
3. 滑杆控制强度：拉到 60%~70% 通常最自然，拉满容易出现「塑料感」。

一键结果不满意时不要反复叠加，直接转手动工具修具体部位。

## 三、手动精修：按部位分组调

| 部位 | 能调什么 |
| --- | --- |
| 眼睛 | 放大、提亮、去黑眼圈和眼袋 |
| 鼻子 | 大小、缩窄、鼻梁挺直、鼻尖形状 |
| 嘴唇 | 丰满度、位置、微笑弧度上扬 |
| 皮肤 | 祛痘、去油光、平滑毛孔、提亮 |
| 牙齿 | 矫正（含戴牙套的情况）、美白 |
| 脸型 | 瘦脸、下颌与下巴重塑、发际线 |

两条经验：一次只调一两个部位、调完看整体；皮肤类工具先用低强度涂一遍，不够再补。

## 四、妆容与身材

- **妆容（Makeup）**：先选一套接近目标的完整妆，再单独微调口红或眉毛；直接逐个单项叠加容易显脏；
- **身材（Body Editor）**：用「推拉」方式收腰、调肩颈线条、拉长身高——先把画面放大到要改的部位，小幅度推多次，人物边缘有直线参照物（门框、墙线）时格外注意，推拉会把直线一起带弯。

## 五、胶片相机（Film Cam）

不想后期的话，相机里切到 Film Cam 模式：6 款复古机型各自带色调风格，可叠加滤镜与贴纸，拍照拍视频都支持，直出「老照片」氛围。

## 六、保存与水印

修好的图一般落在系统相册的 BeautyPlus 文件夹；应用内设置里可以关掉导出图上的角标水印。照片只保存在手机本机，重要的成品记得及时备份。工具玩熟之后，去路人、老照片修复这类 AI 玩法见[去路人与老照片修复.md](去路人与老照片修复.md)；还没装好的先看[安卓版怎么下载安装.md](安卓版怎么下载安装.md)。
