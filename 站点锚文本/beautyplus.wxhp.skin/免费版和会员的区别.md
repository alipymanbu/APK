# BeautyPlus 免费版和会员的区别

> 本篇讲 BeautyPlus 免费档能用什么、哪些内容锁在会员后面、订阅怎么取消、换手机后怎么找回会员，帮你决定要不要付费。

## 一、免费版能干什么

拍摄、一键美颜、基础的五官与皮肤调整、基础滤镜和保存导出都可用——日常自拍出图够用。代价两个：使用中会看到广告；一部分滤镜、妆容、贴纸、模板和 AI 类选项带会员标识，点了提示升级。

识别方式统一：素材图标上带「钻石」角标的就是会员内容。免费与会员的边界随版本调整，以应用内显示为准。

一个容易踩的坑：拍摄或编辑时用了会员效果，结果可能保存不了——换免费素材或撤销效果再保存即可。

## 二、会员包含什么

订阅后的宣传口径：全程无广告、解锁 50 多项会员功能、上千款专属滤镜妆容模板贴纸。定价页把档位分成 Free / Pro / Max 三档，主要差异在 AI 额度与导出规格：

| 档位 | 要点 |
| --- | --- |
| Free | 基础素材与有限 AI 功能；导出带水印 |
| Pro | 每月 200 积分；照片增强不限量；HD 导出无水印；3 天试用 |
| Max | 每月 500 积分；UHD 增强不限量；4K/HD 导出无水印 |

积分是消除路人、AI 头像、视频增强这类功能的「燃料」，每月刷新。要不要订阅，最直接的办法是先用免费版修几张常拍类型的照片，看锁住的功能是不是真会用到。

## 三、怎么取消订阅、关闭自动续费

取消入口不在应用里，在付款用的商店：

| 渠道 | 路径 |
| --- | --- |
| Google Play（安卓） | Play 商店 → 付款与订阅 → 订阅 → 找到 BeautyPlus → 取消 |
| App Store（iOS） | 设置 → Apple ID → 订阅 → 找到 BeautyPlus → 取消 |

取消后权益用到当前计费周期结束，不按天退款；不想续就尽早取消。

## 四、换手机后找回会员

新手机登录与购买时相同的账号（Google 或 Apple ID），进应用会员页点「恢复购买」（Restore Purchases）。恢复不了先核对是不是登了另一个账号——这是最常见的原因。
