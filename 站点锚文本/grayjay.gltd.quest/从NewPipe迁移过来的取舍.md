# 从 NewPipe 迁移到 Grayjay 的取舍

两个应用解决的是同一个问题——不装各家客户端也能舒服地看视频，所以经常被放在一起比较。这篇只摆差异和适合的情况，结论因人而异；还没装的朋友，安装包入口在 [Grayjay 介绍站](https://grayjay.gltd.quest/)。

## 差异摆在这

| 维度 | Grayjay | NewPipe |
| --- | --- | --- |
| 平台范围 | 插件制：YouTube、Twitch、PeerTube、Rumble、Odysee、BiliBili、Patreon、Nebula 等十多个源 | 内置 YouTube、PeerTube、SoundCloud、Bandcamp、media.ccc.de 等 |
| 平台账号登录 | 支持，登录后拿个性化推荐、可看已付费会员内容 | 不支持登录，一切数据本地化 |
| 设备间同步 | 局域网设备同步，另有备份文件整包迁移 | 无 |
| 桌面版 | 有 Windows / macOS / Linux 版 | 只有安卓版 |
| 安装包体积 | 约 165 MB | 小得多，轻量是它的卖点 |

源码许可上也有差别：Grayjay 源码公开但不是 OSI 认证开源（FUTO 自有许可），NewPipe 是标准开源——在意许可口径的话这是决定性的一条。

## 按使用方式对号入座

- **只看 YouTube、SoundCloud 这几个站**，想装个轻量的 → NewPipe 就够；
- **订阅分散在多个平台**，想一条信息流全看完 → 聚合器就是为这个场景而生；
- **要登录平台账号**——看 Patreon / Nebula 已付费内容、解锁 BiliBili 高画质 → 只有前者支持；
- **手机和电脑想用同一个应用** → 它有桌面版可用。

两边不互斥：常见做法是先装着过渡，把订阅搬过去用一阵再决定去留。

## 迁移动作只要一步

订阅不用手抄：NewPipe 里把订阅导出成 JSON 文件 → 手机文件浏览器打开这个 JSON → 选 Grayjay 处理，订阅名单就进来了。过渡期两个应用可以并存，确认订阅和列表都搬全了再卸旧的。

搬过去之后的使用要点：订阅流的搭法见 [多平台订阅一条流看完](多平台订阅一条流看完.md)，离线缓存与投屏的设置见 [离线缓存与投屏设置](离线缓存与投屏设置.md)。
