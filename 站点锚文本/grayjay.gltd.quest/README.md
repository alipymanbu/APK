# Grayjay · grayjay.gltd.quest

关于 Grayjay（FUTO 出品的安卓视频聚合播放器）的介绍与使用整理：它用插件把 YouTube、BiliBili、Twitch、Patreon 等平台接进同一个应用，订阅汇成一条信息流，支持离线下载、后台播放与投屏。本目录收录三篇使用向整理，应用的安装文件资源获取入口见 [Grayjay 介绍站](https://grayjay.gltd.quest/)。
