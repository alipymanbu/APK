# Grayjay 订阅聚合：把各平台的更新收进一条信息流

装聚合播放器的动机大多一样：订阅的频道散在好几个平台，每个都要单独打开翻。Grayjay 的解法是把平台做成插件接进来，订阅汇成一条按时间倒序的通用信息流，直播和已预约的直播置顶。这篇整理它的聚合思路和上手路径，安装包的获取入口见 [Grayjay 介绍站](https://grayjay.gltd.quest/)。

## 插件制的聚合器长什么样

Grayjay 本身不带任何内容，视频全靠「源」——也就是各平台的插件。插件目录收录的有 YouTube、BiliBili、Twitch、Kick、Rumble、Odysee、PeerTube、SoundCloud、Patreon、Nebula、Apple Podcasts、TED Talks 等，覆盖视频、直播、播客和会员制平台。

加源两种方式：在应用的「Sources」页用内置扫码器扫插件页二维码，或用手机浏览器打开插件页点「Open in Grayjay」跳回应用安装。带 Alpha / Beta 标注的是成熟度标记，没标注的最稳，个别源质量参差属插件制应用的常态。

## 订阅怎么搬进来

两种路子，按有没有平台账号选：

1. **登录平台直接导入**：到「Sources」页点开对应平台、登录账号，出现「Import Subscriptions」按钮后一键搬入（插件支持才有）；
2. **从 NewPipe 迁移**：NewPipe 里把订阅导出成 JSON 文件，用手机文件浏览器打开、选 Grayjay 处理即可。

导入完成后所有平台的订阅汇进同一条流，按时间倒序排列；订阅创作者存的是频道元数据，位置在手机本地。播放列表同理，登录后在同一入口点「Import Playlists」。

## 几个容易疑惑的现象

- **底栏没有「订阅」标签**：订阅至少一个创作者之前它不显示；也可能被调进了「More」，到设置的 Manage Tabs 拖回来；
- **首页全是随机视频**：默认不跟踪、不登录时没有个性化推荐，登录某平台后该平台的推荐才恢复；
- **搜索搜不到某个视频**：搜索只覆盖已启用的源，先确认对应插件装了没、有没有在筛选里被关掉。

## 上手顺序建议

先装应用 → 加两三个最常用的源 → 登录账号导入订阅 → 信息流跑起来后再按需补源。延伸阅读：[离线缓存与投屏设置](离线缓存与投屏设置.md)、[从 NewPipe 迁移过来的取舍](从NewPipe迁移过来的取舍.md)。
