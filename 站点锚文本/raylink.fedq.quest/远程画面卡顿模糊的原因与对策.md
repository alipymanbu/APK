# 远程画面卡顿模糊的原因与对策

> 远程控制的体验九成落在网络上：卡顿、模糊、掉帧，多数不是软件「不行了」，而是某一段出了问题。这篇以 RayLink 为例，把远程画面变差的原因按出现频率排一遍，每条都给出对应的处理动作。
> **相关文档**：[手机远程控制电脑的连接方法](手机远程控制电脑的连接方法.md) · [无人值守远程连接的设置方法](无人值守远程连接的设置方法.md)

---

## 一、先读功能栏，再动手

连接建立后，功能栏会实时显示四项指标：延迟、带宽、帧率、连接方式。这四项是判断问题出在哪一段的第一手依据，比凭感觉猜有效得多：

- 延迟高 → 两端之间的链路绕远或拥堵；
- 带宽低 → 某一端的网络本身慢；
- 帧率低 → 带宽不足，或画质档位被压到了流畅档；
- 连接方式是「转发」而不是「直连」→ 传输经过了服务器中转，速度上限被压低。

## 二、按现象对号入座

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 画面模糊、色彩发灰 | 画质档位在省流档，或色彩模式是 4:2:0 | 工具栏切回高清档；对色彩敏感的调色、看图场景切 4:4:4 真彩模式 |
| 操作跟手但画面拖影 | 帧率被压低 | 提高帧率上限，网络允许时开高帧率模式 |
| 一切都卡、鼠标都飘 | 带宽不足或网络抖动 | 两端都改 5GHz Wi-Fi，电脑尽量走有线 |
| 能连但频繁掉线 | 被控端息屏、省电策略杀后台 | 给 RayLink 关电池优化、允许后台运行，被控电脑关闭睡眠 |
| 突然完全黑屏 | 被控端录屏或悬浮窗权限被系统回收 | 回系统设置补授权后重新连接 |

## 三、网络层面的四个动作

远程画质的上限由网络决定，按顺序做四件事：

1. **测基础网络**：任一端刷视频都卡，先解决网络本身，别急着调软件；
2. **争取直连**：手机和电脑连同一个路由器，同网段点对点直连延迟最低、画质上限最高，文件传输速度也跟着上去；
3. **避开受限网络**：一部分办公网禁止设备互连，这不是软件设置能绕开的，换网络最直接；
4. **给大文件让路**：远程的同时还在网盘同步、系统更新，画面自然卡，错峰使用。

## 四、画质档位怎么选

RayLink 的画质选项按场景选，不必一路拉满：

- **普通办公**（文档、网页、终端）：默认档即可，省带宽、延迟更低；
- **看图、改稿、调色**：开 4:4:4 色彩模式，全色域还原不偏色；
- **视频预览、游戏**：高帧率模式优先，清晰度其次。

需要说明的是，部分画质增强选项与账号版本权益有关，以软件内实际显示为准。

装好软件还没跑通连接的，先看[手机远程控制电脑的连接方法](手机远程控制电脑的连接方法.md)；想连一台没人守着的电脑，[无人值守远程连接的设置方法](无人值守远程连接的设置方法.md)里有固定密码与自启动的完整做法。
