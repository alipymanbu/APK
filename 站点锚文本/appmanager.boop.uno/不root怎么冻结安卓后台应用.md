# 不 root 怎么冻结安卓后台应用

> 想让一个应用彻底安静下来，又不想卸载它，有三条路径：系统自带的停用、配一次 ADB 的冻结、以及 root 档的全量管理。各要什么条件、能管多宽，这篇一次说清。
> **相关文档**：[安卓应用追踪器扫描结果怎么看.md](安卓应用追踪器扫描结果怎么看.md) · [查安卓应用包名与签名的方法.md](查安卓应用包名与签名的方法.md)

---

## 一、先分清：停用、冻结、卸载

- **卸载**：彻底移除，数据一并消失。
- **停用**：系统对预装应用提供的开关，效果接近卸载但可随时恢复，普通用户应用多半没有这个按钮。
- **冻结**：由管理工具实现的状态，应用从桌面消失、不能自启、不能被拉起，数据原样保留，解冻即恢复原状——这是"暂时不想见到它"的标准答案。

无 root 的设备走不了 root 工具的冻结，但仍有下面两条路。

## 二、系统自带：设置里停用

设置 → 应用管理 → 选中目标应用，若出现"停用"按钮即可直接点。这条路不需要任何工具，但只对部分预装应用可用；对第三方应用，多数系统不给这个入口。

## 三、ADB 档：配一次无线调试，之后全程在手机上

Android 11 及以上的系统支持无线调试，配对完成后管理工具就能代你执行"改系统"级别的操作：

1. 开发者选项里打开 USB 调试，再进入"无线调试"。
2. 选择"使用配对码配对设备"，记下弹出的六位配对码与端口。
3. 打开管理工具（例如 App Manager，开源、GPLv3+），在设置里选运行模式为 ADB，输入配对码完成配对。
4. 配对成功后回到应用详情，冻结/解冻按钮即可用；之后每次连的是同一个网络环境，一般重连即可，不必重新配对。

ADB 档能覆盖冻结、撤销权限、清除数据、强行停止这一批操作，对"管住后台"来说足够。各档位的完整能力差异，[App Manager 中文介绍站](https://appmanager.boop.uno/)按"看得全、看得透、管得住"分了级，可对照着自己走到哪一档。

## 四、root 档：给已 root 设备的全量管理

设备本身已 root（Magisk、KernelSU 等方案）的话，在 root 管理器里授权即可解锁最后一档：组件拦截、共享偏好编辑、含数据的完整备份这些能力都在这一档，冻结也从"应用级"细到"组件级"。

## 五、冻结前想清楚的事

- 冻结期间它的桌面小组件、闹钟、后台同步全部失效，依赖它推送的消息收不到。
- 输入法、启动器、系统关键组件不要冻结，冻错可能导致部分功能异常。
- 拿不准某个组件是干什么的，先看[安卓应用追踪器扫描结果怎么看.md](安卓应用追踪器扫描结果怎么看.md)里名单的读法，再决定动不动它。
