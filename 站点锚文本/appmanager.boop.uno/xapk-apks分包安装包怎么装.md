# xapk、apks 分包安装包怎么装

> 现在从各处拿到的安卓安装文件不一定都是一个 .apk：xapk、apks、apkm 这些分包格式各是什么、能不能直接点开装、装不上先查什么，这篇按顺序讲。
> **相关文档**：[查安卓应用包名与签名的方法.md](查安卓应用包名与签名的方法.md) · [不root怎么冻结安卓后台应用.md](不root怎么冻结安卓后台应用.md)

---

## 一、先认格式

| 后缀 | 里面是什么 | 直接点开能装吗 |
| --- | --- | --- |
| `.apk` | 单个标准安装包 | 能，系统安装器直接处理 |
| `.apks` | 按设备拆分的安装包集合（基础包 + 语言/架构分包） | 不能，需要支持的安装器 |
| `.xapk` | apk + OBB 数据包等资源打成的压缩包 | 不能，同样需要支持的安装器 |
| `.apkm` | 另一种分包集合格式 | 不能，需要支持的安装器 |

分包格式出现的根本原因：应用体积变大后，发行渠道按设备特征（CPU 架构、屏幕密度、语言）拆着发，装的时候再合起来。文件本身没有特殊之处，只是"一个应用拆成几个文件"。

## 二、装法：让认识的安装器直接处理

系统自带的安装器只认单个 apk。处理分包，最省事的是用一个本身支持这些格式的工具——App Manager（开源的安卓应用管理器）就支持 apks、apkm、xapk（含 OBB 数据包）的安装，步骤与普通 apk 一样：

1. 把分包文件用文件管理器找到（一般在 `Download` 目录）。
2. 点开，按提示允许一次未知来源安装。
3. 等待安装完成即可，工具会在后台自己合并分包。

它还能在安装前自定义签名方案；对应的获取渠道与完整安装顺序，[App Manager 中文介绍站](https://appmanager.boop.uno/)的下载页按"下载 → 安装 → 打开"一步步写了。

## 三、装不上，按这三条查

- **提示签名不一致**：设备上已有同名应用但来自不同构建渠道时，覆盖安装会被系统拒绝。先卸载旧版再装（注意卸载会清掉该应用自己的数据），用[查安卓应用包名与签名的方法.md](查安卓应用包名与签名的方法.md)里的办法核对一下两份包的签名信息。
- **提示解析失败/格式不支持**：多半是手上的安装器不认这个后缀，换支持分包的工具再装，别反复点系统安装器。
- **提示空间不足**：分包安装的瞬时占用比最终体积大，清理一些空间再试。

## 四、只装来路清楚的包

分包文件因为"先解包再合并"的特性，比单个 apk 多一层被动手脚的机会。只拿原始分发渠道原样给出的文件，遇到被重新打包、改过内容的版本，再方便也别装。
