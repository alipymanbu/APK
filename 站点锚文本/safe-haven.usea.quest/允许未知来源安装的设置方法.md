# 允许未知来源安装的设置方法

从商店以外装任何 APK——不管是直接下载的安装包，还是商店类应用本身——安卓都会拦一道「未知来源」提示。这不是包有问题，是系统层的权限门槛。这篇把这道门槛怎么过、不同系统路径差在哪、拦住了怎么排查，一次说清。

## 一、为什么会被拦

安卓默认只信任从应用商店发起的安装。其它来源（浏览器、文件管理器、聊天工具）打开 APK 时，系统会先确认「你授权了这个中间应用去装包」。所以要放行的对象不是某个全局开关，而是**你用来打开 APK 的那个应用**。

## 二、通用设置路径

1. 双击打开下载好的 APK，弹出「出于安全考虑，已禁止安装未知来源应用」之类的提示；
2. 点提示里的「设置」，系统会直接跳到对应权限页；
3. 打开「允许从此来源安装应用」的开关；
4. 返回安装界面，点「安装」，等进度走完。

跳转页找不到时，手动走的通用路径是：**设置 → 应用 → 特殊应用权限 → 安装未知应用**，在列表里找到刚才打开 APK 用的那个应用（浏览器或文件管理器），打开它的开关。

各家 ROM 措辞略有差别：有的叫「安装未知应用」，有的藏在「安全」或「更多设置」里，认「未知来源 / 未知应用」这两个词即可。

## 三、拦住了怎么排查

- **点了安装没反应**：十有八九是第 2 步的开关没真正打开，或者开了之后没有返回安装界面，重新进一遍；
- **提示「解析包出现问题」**：文件在下载环节损坏了，重新下载一遍再装；
- **开关打开后又弹回提示**：部分 ROM 对每次安装都会再确认一次，属于正常设计，点「仍要安装」放行；
- **装商店类应用后，在里面装别的应用又拦一次**：同理——这次要授权的对象换成那个商店应用，开一次即可。

## 四、装好之后

权限只放行一次，之后该来源再装包不会再拦。装好商店类应用后想弄清楚它靠不靠谱，可以看它的验证与扫描标志怎么读——[Safe Haven（SafeHaven）商店介绍](https://safe-haven.usea.quest/)里按它的五层机制做过拆解；缺 Play 商店的设备怎么挑到合适的商店，见[没有GooglePlay的手机怎么装应用.md](没有GooglePlay的手机怎么装应用.md)；两个开源商店混装时的签名坑，见[开源应用商店和F-Droid有什么不一样.md](开源应用商店和F-Droid有什么不一样.md)。
