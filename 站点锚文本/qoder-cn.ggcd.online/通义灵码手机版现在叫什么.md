# 通义灵码手机版现在叫什么

> 搜「通义灵码手机版」找到这里来的，大概率是老用户。这篇把更名的前因后果和两条产品线讲清楚，帮你确认现在该装的是哪一个。
> **相关文档**：[手机上审批AI编程任务的工作流.md](手机上审批AI编程任务的工作流.md) · [云端任务和远程控制怎么选.md](云端任务和远程控制怎么选.md)

## 一、一句话结论

通义灵码的公有云版本已经在 2026 年 5 月正式升级更名为 **Qoder CN**，手机端随之叫 Qoder CN 手机端。你在旧文章里看到的「通义灵码」，说的就是现在这条产品线——名字换了，账号和定位一脉相承。

## 二、为什么会有两条产品线

阿里云在这个品牌上实际布局了两条线：

| | Qoder CN（国内线） | Qoder（国际线） |
|---|---|---|
| 前身 | 通义灵码（公有云版） | 无，直接以新品牌面向海外 |
| 开发方 | 通义云启（杭州）信息技术有限公司 | 同一集团，面向海外市场 |
| 手机端 | Qoder CN 手机端 | Qoder Mobile |
| 安卓包名 | `com.qoder.mobile.cn` | `com.qoder.mobile` |
| 配套电脑端 | Qoder CN IDE / Qoder CN CLI | Qoder IDE / Qoder CLI |
| 模型与服务 | 国产大模型，部署在境内 | 海外渠道服务 |

两套体系**账号、任务、数据互不相通**：电脑上用 Qoder CN 的，手机必须装 Qoder CN 手机端；反过来也一样。装混了最典型的症状就是「登录成功，但列表空空如也」——不是坏了，是任务在另一条线上。

## 三、老用户要做什么

其实什么都不用做：

- 电脑端已经在用通义灵码的，升级后就是 Qoder CN，账号直接沿用；
- 手机端装的时候认准包名带 `cn` 的那一个；
- 各大安卓应用商店（小米、vivo、OPPO、荣耀、华为）和 App Store 中国区搜新名字都能搜到。

## 四、国内线换名字之外换了什么

更名不只是改个牌子，能力也跟着升级了一轮：模型选择器可以在 GLM、DeepSeek、Kimi、MiniMax 这些国产大模型之间切换；Quest 模式升级到能自动拆解复杂开发任务、端到端交付项目级成果；面向企业还有专属版和私有化部署的选项。手机端也在这波升级里从「通知接收器」变成了真正的任务指挥位置——方案预审、编辑审批、云端任务跟进都能在手机上完成。
