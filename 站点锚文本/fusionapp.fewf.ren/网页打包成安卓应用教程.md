# 用 FusionApp 把网页打包成安卓应用：完整教程

> 本篇从新建工程讲到打包安装，把「网页变应用」的主线流程一次走完；安装工具本身的步骤见 [安卓版下载与安装.md](安卓版下载与安装.md)，界面外壳怎么调见 [模板选择与图标定制.md](模板选择与图标定制.md)。

---

## 一、FusionApp 是干什么的

FusionApp 是安卓上的网页转应用工具：把一个网址套进可定制的界面壳子里，生成一个独立安装包，装到桌面上点开就用。它由酷安开发者寒歌开发（「一个木函」同作者），要求安卓 5.2 及以上，没有 iOS 版。

适合的场景很具体：常去的论坛、常查的工具页、自己的博客——凡是你会反复打开的网址，都值得钉在桌面上。工具的定位与安装文件资源的获取入口，见 [FusionApp 介绍站](https://fusionapp.fewf.ren/)。

## 二、开工前备好三样

- **一个能正常打开的网址**：先在浏览器里确认它能访问，别把分享短链当成站点地址；
- **应用名**：显示在桌面图标下面；
- **包名**：形如 `com.xxx.yyy` 的唯一标识，创建后就不要再改——换包名等于做一个全新应用。

## 三、主线五步

1. **选模板建工程**：打开应用点右下角加号，从顶栏、标签栏、底栏、纯底栏、空白五种模板里选一个（拿不准先选空白或顶栏），填应用名与包名后创建；
2. **填启动网页**：把网址照抄进「启动网页」一栏，这是应用打开时加载的页面。新手建议先把应用栏相关选项全部关掉，跑通了再逐个开回来，避免按钮重复、遮住网页内容；
3. **预览**：点右上角的预览按钮，网页会在工程里渲染出来——看加载是否正常、滑动是否顺手、有没有多余工具条挡内容，有问题回配置页改；
4. **清单里配图标**：左上角菜单打开「清单」，导入应用图标（从内置图标仓库挑、用设计器画、或导入自己的方形图片都可以）；
5. **打包安装**：菜单底部点「打包」，生成 APK 直接装进手机，桌面出现你设的图标与名字。

不同版本的按钮叫法略有差异，认不准就按「右上角预览、左上角菜单出清单与打包」这个相对位置找；应用自带的数据库手册入口也在左上角菜单里。

## 四、打包之后要知道的几件事

- **网页内容更新不用重新打包**：应用加载的是在线地址，站点内容更新自动到达；只有改图标、模板、启动图这类工程项才需要重打一次；
- **自己打包的应用安装时可能弹风险提示**：非应用市场分发的安装包都会被系统例行提示一遍，来源可靠即可继续安装，分发给别人时提前说明能省掉解释；
- **想让它更像原生应用**：组件装卸、点击事件、脚本注入（支持 JavaScript 与 alua）都在工程里逐项可调，玩法见 [模板选择与图标定制.md](模板选择与图标定制.md)。
