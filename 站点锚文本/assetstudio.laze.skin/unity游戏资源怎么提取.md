# Unity 游戏资源怎么提取

> 本篇讲在手机上从 Unity 游戏包里取出贴图、音频、模型这类资源的完整路径：文件从哪来、用什么工具打开、怎么按类型筛出来并导出。
> **相关文档**：[安卓上拆游戏包用什么工具.md](安卓上拆游戏包用什么工具.md) · [游戏贴图音频导出格式详解.md](游戏贴图音频导出格式详解.md)

想看某个手游里的角色立绘、UI 图标或者听一段背景音乐，这些内容都封在 Unity 引擎打包出的资源文件里，文件管理器直接点开是看不动的。要在手机上完成这件事，思路是固定的三段：找到文件 → 用工具加载 → 按类型导出。

## 一、先找到资源文件在哪

Unity 游戏的资源常见落在三个位置：

| 文件 | 常见位置 | 说明 |
| --- | --- | --- |
| 安装包本体（APK） | 下载目录 | 资源藏在其内部的 `assets`、`bin/Data` 目录里 |
| 扩展资源包（OBB） | `Android/obb/<包名>/` | 大型游戏的主资源包，几百 MB 起步 |
| 热更新缓存 | `Android/data/<包名>/` 下 | 一堆带 hash、版本号的文件，命名不统一 |

安卓 11 以后 `Android/data` 和 `Android/obb` 对第三方文件管理器上了锁，进不去时可以试三条路：机型自带文件管理器的授权入口、USB 连电脑走 MTP 复制、或者用 Shizuku 给支持的文件管理器授权。XAPK 则是个压缩壳，先当 zip 解开取出里面的 APK 和 OBB 再处理。

## 二、用工具加载

手机上趁手的加载工具可以选 [AssetStudio 安卓版介绍站](https://assetstudio.laze.skin/) 里介绍的这款 AssetStudio 手机版——它把桌面端同名的 Unity 资源浏览能力搬到了安卓上，加载方式分两种：

- **Load file**：喂单个 AssetBundle、单个 OBB；
- **Load folder**：喂整个目录，比如把 APK 当 zip 解开后取出的 `bin/Data` 文件夹，一次全进来。

加载完会看到两个面板：Scene Hierarchy 按场景结构组织，Asset List 按资源类型平铺，配合顶部的类型筛选栏（Texture2D、AudioClip、Mesh……）能很快锁定目标。

## 三、导出拿走

在列表里选中资源（可多选）走 Export 菜单。贴图出 PNG、音频出 WAV 或 MP3、模型出 OBJ、动画器连同动画片段出 FBX，具体对应关系在 [游戏贴图音频导出格式详解.md](游戏贴图音频导出格式详解.md) 里逐类列过。

两个实操建议：

1. **大包先提取再加载**：直接加载是整包读进内存，包大会卡顿甚至闪退；先走 File → Extract 解压到本地目录，再 Load folder 加载解压结果。
2. **导出按「游戏名 + 资源类型」建目录**：整批导出的文件不少，分类存放回头才找得到。

最后提一句边界：提取出来的素材版权归原作品权利方，自己学习、研究资源组织方式没问题，公开传播或商用请自觉避开。
