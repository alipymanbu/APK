# 游戏贴图音频导出格式详解

> 本篇按资源类型过一遍 Unity 游戏资源导出时的格式选择：每类资源能出什么、什么时候该选哪个、导出结果不对劲时先查哪里。
> **相关文档**：[unity游戏资源怎么提取.md](unity游戏资源怎么提取.md) · [安卓上拆游戏包用什么工具.md](安卓上拆游戏包用什么工具.md)

用 [AssetStudio 安卓版介绍站](https://assetstudio.laze.skin/) 介绍的手机版工具把资源筛出来之后，导出那一刻会弹格式选择。对着类型表选，基本不会拿错。

## 一、按类型对号

| 资源类型 | 可导出格式 | 选择建议 |
| --- | --- | --- |
| Texture2D（贴图） | PNG、TGA、JPEG、BMP | 带透明通道的选 PNG；仅看效果 JPEG 就够 |
| Sprite（精灵图） | 从图集裁切后出 PNG 等 | UI 小图优先看 Sprite 而不是整张 Texture2D |
| AudioClip（音频） | MP3、OGG、WAV | 要无损编辑选 WAV；FSB 封装的转 WAV 最稳 |
| Font（字体） | TTF、OTF | 出来就是可安装的字体文件 |
| Mesh（网格） | OBJ | 通用交换格式，建模软件都认 |
| Animator（动画器） | FBX | 可连同绑定的动画片段一起导出 |
| TextAsset（文本） | 原样导出 | 配表、剧情文本之类直接拿 |
| MonoBehaviour | JSON | 需要对应程序集才能还原成可读结构 |
| Shader（着色器） | 文本形式 | 用来看渲染思路，不能直接复用 |

具体某一版支持哪些格式，以应用内导出菜单实际显示为准。

## 二、导出结果不对劲时先查这里

- **PNG 黑底或发灰**：贴图带 alpha 通道，部分看图软件不认，换支持透明的查看器确认，别急着重导；
- **贴图是马赛克**：包里存的本来就是低分辨率缩略图（mipmap 或占位），不是导出坏了，找同名高清变体；
- **模型没带动画**：导出时没勾上 AnimationClip，重新导出时把动画一并选上；
- **找不到导出的文件**：先回忆导出时选的目录，再看应用的私有目录（`Android/data/coyamo.assetstudio/` 下），那里面的文件安卓 11 以后要绕权限才能拿到。

## 三、批量导出的效率做法

在 Asset List 里按类型筛选后配合多选，一次导空一整类（比如全部贴图）；导出目标按「游戏名 + 资源类型」建目录，图集类优先从 Sprite 条目里拿裁好的成品，而不是抱着整张大图自己裁。

格式选对了只是第一步，文件从哪来、怎么加载，见 [unity游戏资源怎么提取.md](unity游戏资源怎么提取.md)。
