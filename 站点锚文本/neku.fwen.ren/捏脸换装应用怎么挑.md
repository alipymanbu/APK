# 捏脸换装应用怎么挑：先分清三种形态

> 搜「捏脸」「捏人」的人常把几款工具混在一起比较，其实它们根本不是一类东西。这篇先分形态，再按你的需求给选择建议。
> **相关文档**：[OC头像从模板到成品.md](OC头像从模板到成品.md) · [安卓装不上与闪退排查.md](安卓装不上与闪退排查.md)

---

## 一、三种形态，对应三种用法

**部件拼装类应用**（以 Neku 为代表，安卓与 iOS 都有上架版本，第三方商店统计装机量在千万级）：美术资源是一整套统一画风，你在现成模板上把脸型、眼睛、发型、服装一层层换掉。学习成本最低，手机上就能反复改。

**生成器平台**（以网页端为主）：平台本身不出美术，上万个生成器由不同创作者各自上传，风格跨度极大。同一个平台里，这个生成器可能允许改色、那个不能；商用授权也是逐个生成器自己规定，用之前得逐条看说明。

**捏人游戏**：捏角色只是玩法的一环，重点在姿势、场景和游戏内容。角色能摆出动作，这是前两类普遍做不到的；代价是画风固定为游戏自带的那套，界面上游戏入口多。

## 二、按需求对号入座

| 你的情况 | 更合适的形态 |
| --- | --- |
| 手机上快速出一张头像，以后还能改 | 部件拼装类应用 |
| 心里有很小众的画风，愿意花时间找 | 生成器平台 |
| 想让角色摆动作、搭场景 | 捏人游戏 |
| 图要用于商业用途 | 先看条款：平台类逐个生成器确认，应用类看使用条款说明 |

## 三、挑部件拼装类应用时看什么

- **画风是否统一**：部件出自同一批美术资源，混搭才不会风格打架；
- **能不能存草稿**：做一半能存、回头接着改，比一次成型的体验实用得多；
- **注不强制注册**：不建账号就能开做的应用，上手门槛低一截；
- **免费内容量**：免费部件够不够拼出完整头像，付费包属于可选还是必需。

拿 Neku 举例的话，它在这四条上的表现、以及编辑界面实际长什么样，[Neku 捏人介绍页](https://neku.fwen.ren/)里有按玩法主线整理的图文说明，配合[OC头像从模板到成品.md](OC头像从模板到成品.md)的流程篇看更直观。

## 四、选定之后

确定形态再装应用，能省掉不少反复试错的时间。装的过程中遇到拦截或闪退，直接翻[安卓装不上与闪退排查.md](安卓装不上与闪退排查.md)，两条最常见的卡点都在里面。
