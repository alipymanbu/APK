# 安卓免 root 抓包怎么做：原理边界与上手路径

> 想看清一台安卓手机上各应用的联网行为，不再需要刷机或连电脑挂代理：借系统自带的本地 VPN 接口，普通应用就能在本机完成流量捕获。本篇讲清这条路的原理、边界与最短上手步骤。
> **相关文档**：[手机抓的包怎么导出Wireshark分析.md](手机抓的包怎么导出Wireshark分析.md)

---

## 先说清楚：以前为什么要 root

在安卓上抓流量，卡点在"收包权限"：系统把网络数据交给内核处理后，普通应用拿不到别的应用产生的包。老办法要么给设备刷入 root 权限直接跑 tcpdump，要么在电脑上架代理、手机手动指过去——前者动系统分区、门槛高，后者要配代理、且不少应用会拒绝走代理。

安卓系统其实留了一条正路：**VpnService 接口**。应用可以创建一个"本地 VPN"，把设备上的流量引到自己这里处理。注意这里没有任何远程 VPN 服务器参与——数据被引到手机内部就地分析，不出设备。免 root 抓包应用走的都是这条路。

## 免 root 路线的三个边界

动手前先知道能抓什么、抓不到什么，免得白忙：

| 边界 | 具体表现 |
| --- | --- |
| 只抓本机 | 只能捕获这台设备上应用的流量；蹭你热点的其他设备的包不在范围内 |
| HTTPS 默认是密文 | 域名、IP 这些元信息可以直接提取；要看 TLS 里面的明文内容，多数应用需要 root 设备配合解密代理才行 |
| 靠 VPN 授权 | 不点掉系统弹出的"VPN 连接请求"，捕获不会开始；这是机制要求，不是应用在要网络权限 |

## 以 PCAPdroid 为例的上手路径

这类工具里用得较多的是 [PCAPdroid](https://pcapdroid.boop.uno/)，开源、免费，介绍页把工作方式与安装步骤整理得很细。装好之后，跑通第一次捕获只要五步：

1. 打开应用，认准主界面的三角形播放键；
2. 系统弹"VPN 连接请求"，点确定——通知栏出现钥匙图标即开始捕获；
3. 切出去正常使用手机几分钟，随便刷几个应用；
4. 回来切到"连接"标签，列表里已经一行行滚出记录：发起应用、协议、远端地址、收发字节；
5. 点任意一行看详情，想逐字节确认就切"载荷"标签。
