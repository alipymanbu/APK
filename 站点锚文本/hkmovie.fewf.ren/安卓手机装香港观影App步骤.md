# 安卓手机装香港观影App步骤

> 本篇整理在安卓手机上装好 HKMovie 的完整流程：从哪里拿安装文件、怎么装、装完登录后先做什么，以及几条卡住时的处理办法。
> **相关文档**：[香港戏院场次查询与座位表使用心得](香港戏院场次查询与座位表使用心得.md) · [香港影迷评分讨论区怎么玩](香港影迷评分讨论区怎么玩.md)

## 装之前先确认两件事

- 手机系统版本别太旧，新版应用对 Android 版本有要求，太旧的系统可能装不上或打不开；
- 存储空间留出几百 MB，安装文件本身不大，但下载加安装的余量要够。

安装文件的获取入口放在 [hkmovie](https://hkmovie.fewf.ren/) 介绍站里，首页和下载页的按钮都能直达，下文以从那里拿到文件为起点。

## 四步装好

1. **转存**：点介绍站上的「获取安装文件资源」，进入网盘分享页后登录，把文件先转存到自己的网盘账号——这一步不占手机空间，也避免直接下载中途断掉；
2. **下载**：在自己网盘里选中该安装文件下载到手机，等进度条走完，文件一般出现在通知栏或「文件管理 → 下载」里；
3. **安装**：点按安装文件。系统若提示「禁止安装未知来源应用」，按指引给下载时用的那个应用（浏览器或文件管理器）授予权限，再回来重新点装；
4. **打开登录**：装好后打开应用，注册并登录账号，查场次、看座位表、写影评的功能就都解锁了。

## 卡住了怎么办

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 点安装没反应 | 未授「安装未知应用」权限 | 设置 → 应用 → 特殊权限 → 安装未知应用，给对应应用授权后重试 |
| 提示「解析包时出现问题」 | 文件没下载完整或被改名 | 回网盘重新下载，确认是 .apk 且大小正常再装 |
| 装完打不开或闪退 | 空间不足或系统太旧 | 清出空间重试；把系统更新到较新的 Android 版本 |
