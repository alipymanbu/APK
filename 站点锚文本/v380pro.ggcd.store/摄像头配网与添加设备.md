# 给摄像头连上网：V380 Pro 的配网与添加步骤

> 新摄像头要先用手机「认识」它，后面的一切功能才谈得上。这篇按真实操作顺序讲清 V380 Pro 的配网与添加路径：连哪个 WiFi、从哪里进添加页、扫二维码和手输设备 ID 怎么选，以及第一次添加失败时先查哪几样。相关文档：[设备离线排查.md](设备离线排查.md) · [录像回放与存储.md](录像回放与存储.md)

---

## 一、开箱后先确认三件事

1. **摄像头通电**：接上电源，等自检完成——指示灯进入稳定状态再动手，别在启动中途就配。
2. **手机连 2.4GHz WiFi**：配网走 2.4GHz 频段。很多路由器 2.4GHz 与 5GHz 共用一个名字，添加失败时优先怀疑这一条。
3. **WiFi 密码别凭记忆输**：大小写、特殊字符输错一次，后面每一步都会卡住。

## 二、添加设备的完整路径

1. 打开 V380 Pro，进入设备列表页；
2. 点右上角的「+」号；
3. 扫机身上的二维码——通常贴在机身或底座标签上；
4. 等待提示「添加成功」，列表里出现这台摄像头。

机身上找不到二维码也没关系：添加页里有**手动输入**入口，把设备 ID 敲进去效果相同；也有**局域网连接**选项，手机与摄像头连同一个 WiFi 时可以直接搜到。

## 三、第一次添加失败的常见原因

| 现象 | 先查这里 |
| --- | --- |
| 一直搜索不到设备 | 手机是否连着 2.4GHz 频段；摄像头是否已完成启动 |
| 提示密码错误 | 重新核对 WiFi 密码，注意大小写与符号 |
| 扫码后无响应 | 换手动输入设备 ID 试一次 |
| 局域网里也搜不到 | 关闭路由器的 AP 隔离功能后再试 |

## 四、加好之后从哪里看状态

设备列表里能看到每台摄像头的画面缩略图与布防状态；点进预览界面，下方一排是云台、截图、录制、对讲、报警这些常用操作。如果列表里的设备显示离线或干脆连不上，按[设备离线排查](设备离线排查.md)里的顺序逐项过一遍。

想先看看这个 App 实际长什么样、每一步在界面的哪个位置，可以对照这份带截图的 [V380 Pro 图文使用站](https://v380pro.ggcd.store/)，按「配网 → 实时画面 → 报警 → 回放」的真实使用顺序排的，和这篇的操作路径一一对应。
