# 模糊人脸照片怎么变清晰

> 本篇讲模糊人脸照片变清晰的几条路子：什么照片值得修、手机端怎么修、修复幅度怎么取舍，以及修出来不像本人时的调整办法。
> **相关文章**：[老照片修复上色与翻拍技巧.md](老照片修复上色与翻拍技巧.md) · [手机视频画质增强方法.md](手机视频画质增强方法.md)

## 一、先判断照片有没有救

- 模糊但五官轮廓还在：信息量够，修复后通常认得出是谁，值得修。
- 像素低、噪点多：能拉回一层清晰度，但细节属于算法推断。
- 糊到只剩一团轮廓：补出来的长相是"合理想象"，与真人可能对不上，预期要放低。

本来就清晰的照片没必要过一遍修复，反而可能被改出奇怪纹理。

## 二、手机端最省事的一条路

电脑端的开源模型效果好，但要配 Python 环境、参数全靠命令行；网页演示能快速试效果，结果页却是限时保存。想在手机相册里直接翻新照片，装一个基于 CodeFormer 模型的安卓应用最省事，比如 [codeformer 介绍站](https://codeformer.laze.skin/)里整理的这款：导入照片、选人脸修复、点开始，几十秒出结果，不满意再换个档位重跑。

它的核心是一个"修复幅度"滑块，对应开源模型里的保真度参数——一端追求细节多、画面干净，一端追求像本人、改动小。不同素材的参考档位：

| 处理的内容 | 建议档位 |
| --- | --- |
| 带背景的整张照片 | 中间偏保守 |
| 人脸特写照 | 中间档起步 |
| 模糊到认不出的老照片 | 偏激进修复 |

## 三、修出来不像本人怎么调

- 五官变了：滑块太靠激进端，往保留原样的方向拉一档重跑。
- 脸上有奇怪纹理：原图压缩太狠或分辨率太低，先重拍、重扫一遍再修。
- 照片本来清楚却被修出塑料感：这类工具面向"有退化的照片"，清晰照片不必过这一遍。

同一张照片多试两档再定稿，比反复纠结一档更省时间。

## 四、修完保存的小提醒

成片会存进系统相册，按最近日期就能找到。部分鸿蒙设备上第三方应用保存的图片可能不显示在图库里，去文件管理的「图片」分类按日期找，成片并没有丢。

照片是老照片、还带划痕褪色的，接着看[老照片修复上色与翻拍技巧.md](老照片修复上色与翻拍技巧.md)；视频素材的处理见[手机视频画质增强方法.md](手机视频画质增强方法.md)。
