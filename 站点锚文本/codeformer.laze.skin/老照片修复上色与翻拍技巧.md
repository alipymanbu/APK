# 老照片修复上色与翻拍技巧

> 本篇专讲老照片：纸质照片怎么翻拍才好修、破损划痕怎么补、黑白照怎么上色，以及对修复结果的合理预期。

## 一、翻拍质量决定修复上限

修图应用处理的是电子版，老照片翻拍这一步做对了，修复就成功了一半：

1. 找光线均匀的地方，靠窗的自然光最好，别用闪光灯（相纸会反光）。
2. 手机正对照片拍摄，别斜着拍，避免透视变形。
3. 照片撑满取景框，四周留一点边，拍完裁掉多余背景。
4. 带玻璃相框的先取出来拍，玻璃反光会被当成画面内容。

已经拍歪、拍暗的电子版也能修，但先重拍一遍往往比后期补救更快。

## 二、修复与上色的顺序

1. 把翻拍好的照片导入修复应用，破损划痕选修补类功能，黑白照选上色类，单纯模糊选人脸修复。
2. 先修破损、再跑上色，两遍分开跑比一步到位更稳。
3. 用滑块控制改动幅度：不像本人就往保守端拉，细节不够就往激进端拉。
4. 满意后保存到相册；一整本相册可以批量导入逐张处理。

手机上操作以 [codeformer 安卓版](https://codeformer.laze.skin/) 这类基于 CodeFormer 模型的应用为代表，人脸清晰化、上色、去杂物在同一个应用里就能完成。

## 三、对结果的合理预期

| 期望 | 实际情况 |
| --- | --- |
| 划痕折痕消失 | 大部分能修掉，跨越人脸的大面积破损可能留痕迹 |
| 黑白照变彩色 | 颜色是算法推断的，衣服背景未必与现实一致，肤色通常更接近常理 |
| 认不出的人修到能认 | 信息量够时效果明显；损坏到只剩轮廓时是"合理想象" |
| 五官与本人一致 | 滑块往保守方向调会更像，清晰度提升相应变小 |

补全的部分属于推断，没法保证与真实一致，这是这类工具的边界，不是操作失误。

## 四、修完去哪儿找成片

成片默认进系统相册，按最近日期排列就能看到。鸿蒙 HarmonyOS 5 及以上设备有个已知现象：第三方应用保存的图片可能不进图库，去文件管理的「图片」分类按日期找即可。
