# 安卓版怎么下载安装

> 整理乌云影视（wooyun）安卓安装包的获取途径、侧装 APK 的完整步骤，以及安装环节最容易卡住的几个点。
> **相关阅读**：[片库分区与找片方法](片库分区与找片方法.md) · [离线缓存与投屏玩法](离线缓存与投屏玩法.md)

乌云影视（wooyun）目前只面向安卓设备：社区讨论里开发者提过 iOS 仍在适配中，公开渠道见到的都是 APK 安装包，所以安装方式属于典型的「侧装」——不走应用商店，直接装安装包。动手之前，先弄清楚安装包从哪来、怎么装、卡住了怎么办。

## 安装包从哪来

常见途径有两类：

1. **网盘分享**：把别人整理好的安装包转存到自己的网盘账号再下载。这是最稳的一条路——安装包放在网盘里不会因为某个下载站下架而失效，版本信息也往往连同说明一起整理好。
2. **第三方下载站**：各大安卓下载站多有收录，页面信息齐（版本号、体积、截图），但页面广告多，容易点到误导按钮，下载前要认清真正的安装包文件。

无论走哪条路，拿到手后都建议核对一下文件体积是否正常（1.0.x 线的安装包在 64MB 上下，明显偏小就要当心），再决定装不装。

## 侧装 APK 的四步

1. 用文件管理器点开下载好的 APK；系统提示「不允许安装来自此来源的应用」时，确认来源是自己刚用的文件管理器或浏览器，允许这一次。
2. 等安装进度走完，点打开。
3. 首次打开若询问存储权限，允许后才能正常使用离线缓存功能。
4. 到「设置 → 应用管理」里核对一下包名与版本号，确认装的是自己要的那份。

装之前手机存储最好留出 1GB 以上余量——安装包本身 64MB 左右，装完还有缓存与离线文件要占地方。

## 卡住了按什么顺序排查

| 现象 | 先做什么 |
| --- | --- |
| 「解析包出现问题」/ 装到一半失败 | 多半是包没下完整，回网盘重新下载一遍再装 |
| 点开 APK 没反应 | 换一个文件管理器再试，个别机型自带管理器对 APK 兼容差 |
| 覆盖安装提示「签名不一致」 | 手机上已装的旧版与这份包不是同一签名来源，先卸载再装（本机收藏与历史会被清掉，先记下收藏清单） |
| 装上打不开、闪退 | 清一次应用缓存再试；仍闪退说明机型兼容有问题，等待新版本 |

## 装好之后

第一次打开先别急着搜片，花两分钟把频道页签和筛选标签翻一遍，心里有张地图，之后找片快得多——具体见[片库分区与找片方法](片库分区与找片方法.md)；想在电视上看，路径在[离线缓存与投屏玩法](离线缓存与投屏玩法.md)里。

应用的界面布局、频道划分与常见疑问，也可以先到乌云影视介绍站（<https://wooyun.ggcd.uno/>）过一遍再决定装不装。
