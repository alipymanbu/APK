# Chuckle 多账号切换与账号管理

> 本篇讲第三方 X 客户端 Chuckle 的多账号用法：同时登录几个账号、怎么切换、以及账号安全上值得留意的几点。

---

## 一、同时登录多个 X 账号

Chuckle 支持在同一台手机上登录多个 X（Twitter）账号，适合把工作号与个人号分开使用的人。添加的方法：

1. 打开应用内的账号管理入口（一般在侧边栏或「我的」页面，具体位置以当前版本界面为准）；
2. 选择添加账号，输入另一个 X 账号的手机号或邮箱完成登录；
3. 之后在账号列表里点选头像即可切换，时间线与关注关系会直接跟着换成对应账号。

切换不需要反复退出登录，这也是很多人从网页版换到第三方客户端的主要理由之一。

## 二、登录用的还是你自己的 X 账号

Chuckle 本身不发账号：登录页输入的手机号或邮箱，对应的就是你自己的 X 账号。还没有 X 账号的话，先用手机号或邮箱注册一个，再回到客户端登录。

按应用介绍，装好即可直接登录使用；如果你所在的网络长时间连不上，排查思路见[登录不上与连不上的排查.md](登录不上与连不上的排查.md)。

## 三、账号安全的三点提醒

- 只从可信渠道获取安装包，装之前核对来源；
- 出现异地登录提醒或怀疑账号异常时，先到 X 网页版改密码，再回到客户端重新登录；
- 多个账号切换使用时，留意别把工作号的发帖入口当成个人号用——发出去的内容删了也可能被截图。
