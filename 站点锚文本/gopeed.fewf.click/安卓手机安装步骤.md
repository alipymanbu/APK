# Gopeed 安卓手机安装步骤

> 从拿到 APK 到完成安装全流程：怎么放行"未知来源"、装到一半失败怎么办、第一次打开建议动哪两处设置。
> **相关文章**：[磁力没速度怎么办](磁力没速度怎么办.md) · [扩展与浏览器接管用法](扩展与浏览器接管用法.md)

## 一、安装前知道的几件事

Gopeed 是 GopeedLab 维护的开源下载器（GPL-3.0 协议），同一套代码覆盖 Windows、macOS、Linux、Android、iOS、Web 与 Docker。安卓安装包是 `.apk` 文件，发布页每个版本都会给出 universal（全架构通用包）与 armeabi-v7a、arm64-v8a、x86_64 四种，分不清手机架构就选 universal，代价只是体积略大。安卓版要求 Android 5.0 及以上。

## 二、安装步骤

1. **把 APK 下到手机存储**。安装包从夸克网盘获取：打开[Gopeed 安卓版下载安装介绍页](https://gopeed.fewf.click/)，点"获取安装文件资源"按钮，转存到自己的网盘账号后下载到手机。
2. **放行"未知来源"**。在文件管理器里点开 APK，系统会提示禁止安装——这是安卓对商店外安装包的统一拦截。到系统设置里给你用来打开 APK 的那个应用（文件管理器或浏览器）授予"安装未知应用"权限，返回重试。
3. **等进度走完，点打开**。桌面出现图标即安装成功。

## 三、装不上时的三种常见原因

| 现象 | 原因与处理 |
| --- | --- |
| 提示「应用未安装」 | 设备上已有签名不同的旧版（比如从别的渠道装的），先卸载再装 |
| 安装到一半中断 | 存储空间不足：约 57 MB 的包安装展开还要占更多余量，清理后重试 |
| 下载后点不开 APK | 文件没下完整，重新下载一遍；转存到自己网盘再下更稳 |

## 四、首次启动建议动的两处

- **下载目录**：进设置的下载配置，确认默认保存位置放在文件管理器方便看到的地方（比如 `Download/Gopeed`），以后清文件、拷文件都省事。
- **语言与主题**：界面默认跟随系统语言，可手动切简体中文；暗色主题在同一处设置里。

装好之后，直链、磁力、种子、ed2k 四类链接都能贴进任务框直接下；磁力速度上不去看[磁力没速度怎么办](磁力没速度怎么办.md)，网盘与视频站这类需要解析的资源则看[扩展与浏览器接管用法](扩展与浏览器接管用法.md)。
