# Gopeed 磁力下载没速度怎么办

> BT 与磁力任务速度上不去时，按"判断慢在哪 → tracker → 端口 → DHT → 代理"的顺序逐项排查，多数卡顿都能对号入座。
> **相关文章**：[安卓手机安装步骤](安卓手机安装步骤.md) · [扩展与浏览器接管用法](扩展与浏览器接管用法.md)

## 一、先分清是哪种慢

BT 速度本质上取决于"有多少人愿意给你传"，动手调设置前先对号入座：

| 现象 | 大概率原因 |
| --- | --- |
| 磁力卡在「获取元数据」不动 | 这条资源几乎没有活跃节点 |
| 有速度但离带宽差得远 | tracker 连通差或端口不通 |
| 直链慢（非 BT） | 连接数或代理设置问题 |
| 所有任务都慢 | 网络环境本身或代理配置 |

判断资源凉不凉有个简单办法：任务详情里看可用节点（peers/seeds）数量，个位数基本没救，换资源或换时段再来。冷门种子的做种人在线时间集中在晚间，深夜与白天结果可能完全不同。

## 二、补充 tracker 列表

tracker 是帮你找到其他下载者的"介绍人"。Gopeed 内置的 tracker 列表每天自动更新，正常情况不用管；但对冷门资源，手动追加一批公共 tracker 依然是最见效的一招——到公开的 tracker 列表项目复制最新地址，一行一个粘进设置的 BT 配置框。

两层入口别搞混：设置里改的是全局默认，对之后所有任务生效；单个任务的创建页也有 tracker 栏，只影响这一单。某个任务怎么都找不到人时，可以在任务级单独喂它一批新鲜 tracker。注意时效性，半年前的旧列表基本失效。

## 三、端口与防火墙

BT 是双向的：别人也要能连到你。端口连不进来时只能"你连别人"，速度通常只剩零头。按顺序检查：

1. **确认 UPnP 开着**——家用路由器会自动开端口，设置里保持开启；
2. **路由器手动映射**——UPnP 被禁用时，到路由器管理页把 BT 监听端口映射到设备 IP（手机在运营商 NAT 下尽力而为）；
3. **换非标准端口**——部分网络会对常见 BT 端口限速，换一个有时立竿见影。

## 四、DHT 与代理

DHT 是没有 tracker 时的兜底网络，磁力几乎完全依赖它：设置里保持开启；卡在元数据阶段时，删掉任务重新添加让它重新入网也是常用手段。

代理则是另一个隐形拖累——它对直链影响不大，但经过中转后其他节点更难直连你。BT 慢而直链正常时，先想想是不是近期开了代理（或系统级代理应用），关掉再试一轮。

## 五、还没装这款下载器

以上设置都在安卓版的设置页里能找到。如果手机上还没有它，先看这篇[安卓手机安装步骤](安卓手机安装步骤.md)，或直接到 Gopeed 安卓版下载安装的[介绍页](https://gopeed.fewf.click/)了解功能与获取方式。站点类资源（网盘、视频页）下不动属于另一类问题，去[扩展与浏览器接管用法](扩展与浏览器接管用法.md)找答案。
