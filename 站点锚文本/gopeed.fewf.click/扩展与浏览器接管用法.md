# Gopeed 扩展与浏览器接管用法

> 网盘分享、视频页这类链接贴进任务框下不动？这层解析能力靠扩展补齐；桌面端还能让浏览器把下载任务直接转交给 Gopeed。
> **相关文章**：[安卓手机安装步骤](安卓手机安装步骤.md) · [磁力没速度怎么办](磁力没速度怎么办.md)

## 一、扩展解决什么问题

原生协议（HTTP、BT、磁力、ed2k）只能下"直链类"资源。网盘分享链接、视频站页面这类地址，真实文件地址藏在页面逻辑后面，直接贴进任务是下不动的。Gopeed 把这层解析做成了扩展机制：每个扩展对应一类站点或服务，装上之后贴相应链接，它会解析出可下载的文件清单。扩展用 JavaScript 编写、以去中心化方式分发，任何人都能为某类站点写一个。

应用内扩展商店里的典型品类（以商店页面实时显示为准，扩展更新很勤）：

| 品类 | 代表扩展 |
| --- | --- |
| 视频站 | Youtube、哔哩哔哩、Twitter、TikTok |
| AI 模型 | Huggingface 下载 |
| 代码托管 | GitHub Release、GitHub 仓库下载 |
| 网盘 | 百度网盘、夸克网盘等 |
| 文件床 | Gofile、Pixeldrain、MediaFire |

## 二、在应用里装扩展

1. 打开 Gopeed，进应用内的**扩展**页（安卓版在底部导航的「扩展」标签）；
2. 从扩展商店或扩展的 GitHub 主页拿到安装地址；
3. 在扩展页粘贴地址安装，装完可升级、停用或卸载；
4. 回到主界面贴对应站点的链接，能解析出文件清单就说明生效了。

两个使用提醒：**按需装**——装太多会让任务解析变慢，留常用的几个就好；**看扩展自己的主页说明**——网盘类通常要求先配置账号 Cookie，视频类的高清档位同样如此。

## 三、浏览器下载接管（桌面端）

Gopeed 另有一个浏览器扩展（区别于应用内的站点扩展），作用是接管浏览器自带的下载：Chrome、Edge、Firefox 里点任何下载链接，任务都会转给 Gopeed 走多线程下载，由统一的任务列表管理。

装好后有一个关键配置别漏：打开浏览器扩展的设置页，启用 **Remote Download** 并指向本机运行的 Gopeed，浏览器才会把任务递过去——不设这一项，接管不会生效。

安卓端用不上这条：手机浏览器里复制链接直接贴进 Gopeed，效果等同。

## 四、扩展不生效的快速排查

- **贴链接没反应**：确认装的是对应站点的扩展且处于启用状态，一个扩展只管一类站点；
- **解析失败**：部分扩展要求配置登录 Cookie，进扩展设置补配置；
- **集体失效**：站点改版后旧扩展会失灵，去扩展页升级，或到该扩展的 GitHub 页面确认维护状态。
