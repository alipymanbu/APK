# 怎么把实时心跳挂进直播间

在直播间里挂一个实时跳动的 BPM 读数，是恐怖游戏、健身实况和竞技对局主播常用的节目效果。本文按实际操作顺序，讲清从设备到直播画面之间的整条链路：手机装好 HypeRate、连上心率设备、拿到会话链接，再把它加进 OBS 一类的直播软件。

## 第一步：手机端接好心率设备

HypeRate 的角色是"心率广播站"：它通过蓝牙接收心率设备的数据，再实时转发出去。

- 智能手表路线：Apple Watch（Series 4 及以上）、Wear OS 手表、Garmin、Fitbit 等，先在手表端装好对应的表盘或配套应用；
- 胸带路线：Polar H10、Wahoo TICKR、CooSpo H808S 这类标准蓝牙胸带，穿上之后设备会自动广播心率；
- 没有手表也没有胸带时，还可以用电脑浏览器直接连接蓝牙胸带（Web Bluetooth 方案），全程不用手机。

设备就位后，打开 HypeRate，点主屏下方的 Search for Device，连上后屏幕中央会立刻出现实时 BPM。

## 第二步：拿到会话链接

连接成功后，主屏会显示一个简短的会话链接（形如 `app.hyperate.io/你的ID`）。这个链接就是观众端看到的心率小组件入口，也是后面挂进直播软件的钥匙。

## 第三步：挂进直播软件

以 OBS Studio 为例：

1. 来源区域右键 → 添加 → 浏览器源；
2. 粘贴上一步的会话链接；
3. 宽高给到 300×150 以上，确定后画面里就出现 BPM 小组件。

Streamlabs、Meld Studio 等同样支持浏览器源，Twitch、YouTube、Kick 等平台对这条链路没有额外限制。进阶玩法还可以给摄像头边框、Logo 加"Heartbeat"滤镜，让画面元素跟着真实心跳律动，甚至用 BPM 阈值自动切换场景、控制灯光。
