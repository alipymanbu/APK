# ReelShort 怎么下载安装到安卓手机

> 商店里搜不到 ReelShort、或者账号区域不合适？这篇写安卓手机用安装包安装的完整路线：从哪拿包、怎么授权、装完做什么，五步搞定。

## 一、动手前确认两件事

- **空间**：安装包 110 MB 左右，装完连同缓存更大，建议预留 1 GB 以上空闲空间；
- **来源**：安装包路线与商店路线装出来是同一个应用（包名一致），进度与金币都在账号体系里，不因为安装来源分开。商店能直接搜到的话，走商店最省事。

## 二、五步安装

1. **拿安装包**：安装包通过夸克网盘分享获取，整理好的入口在 [ReelShort 竖屏短剧站](https://reelshort.wrwq.fun/) 的下载页，点「获取安装文件资源」就能打开分享页；
2. **转存**：登录夸克账号，把安装包转存到自己的网盘——只预览不转存，手机端是下载不了的；
3. **手机下载**：手机装好夸克 App、登录同一账号，在我的网盘里找到这份 APK，下载到本机存储；
4. **授权并安装**：首次从夸克安装时，系统会要求「允许从此来源安装应用」，按提示授权后点开 APK 安装。授权对象是「夸克」这个来源，装完可以在系统设置里关掉；
5. **打开登录**：用邮箱、Google 或 Facebook 任一方式注册登录，进度、金币、订阅都跟账号走。登录后先领新人金币，再开免费集。

## 三、装不上怎么办

- **点安装没反应 / 被取消**：系统设置 → 应用 → 特殊权限 → 安装未知应用，给「夸克」打开允许安装，回头重试；
- **提示「应用未安装」或解析失败**：多为下载不完整，删掉 APK 重新下载；也检查一下剩余空间；
- **装完闪退**：先卸载重装一次；仍闪退则核对安卓版本是否过低。首启加载慢的话换 Wi-Fi / 流量再试，应用需要联网验证。
