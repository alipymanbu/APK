Cemu 安卓版是社区把 PC 端 Wii U 模拟器移植到手机的实验性作品，上游项目并没有把安卓排进计划，所以它对硬件的挑剔程度比一般安卓应用高。你的手机能不能跑、能跑多顺，本篇帮你按档位先做个判断；安装与导入的完整流程，[Cemu 安卓版介绍站](https://cemu.gkhf.beer/)按"三道门"整理成了一份操作单，可以配合着看。

## 先对最低门槛

社区发布页给的要求是：

- 系统：Android 11 及以上
- 处理器：八核 1.5GHz 以上
- 运存：4GB 以上
- GPU：Adreno（骁龙系）优先

这条线只是"能装能开"的门槛，不等于"玩得爽"的标准——Wii U 游戏里的大块头（比如《塞尔达传说：旷野之息》）对性能的要求远高于此。另外大型游戏吃内存凶，8GB 运存的机器后台也别挂太多应用。

## GPU 的差别比 CPU 大

移植版主要围绕骁龙的 Adreno GPU 调优，社区驱动、兼容性报告也以骁龙系为主。Mali（天玑、Exynos 系）是后期版本才加入支持的，可玩的游戏清单更短、报错概率更高：有用户反馈 Exynos 机型跑《旷野之息》默认设置只有约 10fps（2026 年，社区反馈）。在几台机器之间挑，优先选骁龙（Adreno）的那台；天玑机型遇到问题，先怀疑 GPU 兼容性，别急着怪设置。

## 各档机型实测参考

## 两条进阶路径

- **社区驱动（Turnip）**：骁龙 / Adreno 机型可以换第三方开源 GPU 驱动换帧率，多个实测视频用它拿到了更高帧率。版本必须与移植版对上，弄不好直接闪退——动手前先记下当前能正常玩的版本，出问题随时退回去。
- **安卓游戏掌机**：AYN Odin 2 这类骁龙旗舰配置的掌机是社区实测的主力设备，物理手柄免映射、散热比手机好，配置判断逻辑与上表一致——先看 SoC 档次和 GPU 阵营。

## 判断流程

1. 看 SoC 与 GPU 阵营：骁龙 Adreno 有戏；天玑 / Exynos 能装，游戏清单要打折。
2. 对照上表找同档实测：有同档跑同游戏的记录，按它的表现预期。
3. 先用轻量游戏验证流程（导入、按键、画面），再挑战大作。
4. 大作跑不动先按[wiiu模拟器安卓版画面设置.md](wiiu模拟器安卓版画面设置.md)的顺序调，仍不行就是档位到了。
5. 报错对照[wiiu模拟器游戏文件格式与导入.md](wiiu模拟器游戏文件格式与导入.md)——多数"进不去游戏"是密钥 / 格式问题，不是性能问题。
