# 下载安装到手机的完整步骤

> 本篇讲把 Quickstep 装进安卓手机或模拟器的全流程：取安装包、授权未知来源、安装、设为默认桌面，以及桌面已经空白时的两条替代路线。
> **相关文档**：[安卓原生桌面是什么能卸载吗](安卓原生桌面是什么能卸载吗.md) · [桌面空白和停止运行的应急处理](桌面空白和停止运行的应急处理.md)

---

## 安装前确认两件事

一确认你真的需要装：桌面一切正常的话，Quickstep 已经在你的系统里跑着，不用重复安装。二确认授权：进 `设置 → 应用 → 特殊应用权限 → 安装未知应用`，给你用来打开安装包的那个应用（文件管理器或浏览器）授予「允许安装」，装完可以再把权限关掉。

## 四步装完

1. **取包**：从夸克网盘分享页把安装包转存到自己网盘，再下载到手机存储；
2. **安装**：用文件管理器找到 APK 点开，在系统弹窗里点「安装」，十几秒完成；
3. **选桌面**：装完按 Home 键（或做上滑手势），系统弹出「选择桌面」框时选 Quickstep 并勾选「始终」；
4. **没弹框就手动指定**：进 `设置 → 应用 → 默认应用 → 主屏幕应用`，在列表里点选 Quickstep，再按一次 Home 键验证。

安装包是 v3.0.12、约 5 MB，包名 `com.android.launcher3`，手机和模拟器通用。

## 桌面已经空白时的两条路线

系统还在、只是没有桌面可显示时，图标打不开、文件管理器也点不了，按顺序试：

**路线一：从通知栏绕进设置。** 在空白桌面下拉通知栏，点右上角齿轮进系统设置，搜索「文件」打开自带文件管理器，在里面找到已下载的 APK 安装；通知栏进不去设置的话，试试长按齿轮图标。

**路线二：电脑 ADB 侧载。** 手机开启 USB 调试并连接电脑，在 Android 调试工具 platform-tools 目录执行 `adb install -r Quickstep_v3.0.12.apk`，装完按 Home 键选择桌面。

## 装完怎么核对

不用到处试，系统设置里有四个页面能直接说明它已就位：应用信息页确认已安装、默认主屏幕应用列表里选中它、默认打开页保持默认、通知页管好角标开关。

[Quickstep 桌面安装与设置说明](https://quickstep.rggd.pw/)给这四页各配了一张真机设置页截图，装完逐页对照，两分钟就能确认桌面切换到位。
