# 桌面空白和停止运行的应急处理

> 本篇讲两种桌面故障的应急次序：桌面彻底空白（组件被删或被停用）怎么一步步装回来，「Quickstep 已停止运行」反复弹窗该怎么处理。
> **相关文档**：[安卓原生桌面是什么能卸载吗](安卓原生桌面是什么能卸载吗.md) · [下载安装到手机的完整步骤](下载安装到手机的完整步骤.md)

---

## 先分清是哪种故障

**桌面空白**：重启后屏幕只剩状态栏和壁纸，图标全部打不开、设置也进不去——这是当前没有可用的桌面，多半是清理工具或误操作把桌面组件删了、停用了。

**反复弹「已停止运行」**：桌面还在闪退边缘，Home 键偶尔能回——这是组件在运行但崩溃，处理方向是修复而不是重装系统。

两者的共同点：先保证系统里**有另一个能用的桌面**，再谈修和换。

## 桌面空白的恢复次序

1. **通知栏绕行**：空白桌面上下拉通知栏，点右上角齿轮进系统设置，搜索「文件」打开自带文件管理器；通知栏进不去设置时，试试长按齿轮图标；
2. **补装桌面**：在文件管理器里找到已下载的 Quickstep 安装包，点开安装；装包前记得给对应应用授「安装未知应用」权限；
3. **设为默认**：装完按 Home 键，在弹出的选择框里选 Quickstep 并点「始终」；没弹框就去 `设置 → 应用 → 默认应用 → 主屏幕应用` 手动指定；
4. **ADB 兜底**：手机连不上任何图形入口时，开启 USB 调试连电脑，执行 `adb install -r Quickstep_v3.0.12.apk` 从命令行把桌面装回去。

## 反复停止运行的处理

按代价从小到大依次试：`设置 → 应用 → Quickstep → 存储` 里**清除缓存**后重进桌面；无效就**覆盖安装**一遍安装包；仍然崩溃的话，先切到系统里另一个桌面顶住，再排查是不是最近装的应用与桌面组件冲突。

## 事后预防

桌面属于「坏了才知道它重要」的组件。日常两个习惯能避开大部分窘境：一是清理类工具别对系统桌面组件做「停用 / 卸载」操作；二是装一个备用桌面留在机器里，当前桌面出问题时随时能顶上，也不会出现按 Home 键无处可回的死局。

从取安装包到四页核对设置的完整流程，都整理在 [Quickstep 桌面安装与设置说明](https://quickstep.rggd.pw/)，照着走一遍基本十分钟内能恢复。
