# Pixel 风格安卓桌面怎么换

不少人在用了几年厂商定制系统后，开始想念 Pixel 那种干净利落的桌面：整齐的网格、克制的配色、顶部一瞥小组件、底部一根搜索条。这篇文章讲清楚"换桌面"这件事的本质与完整路径，并以开源启动器 Lawnchair 为例走一遍全流程。

## 一、先弄清：桌面 = 一个应用

安卓的"桌面"（启动器 / Launcher）本质是一个普通应用，只是被系统赋予了接管主屏幕的职责。所以"换桌面"不需要刷机、不需要 root，就是三步：

1. 装一个启动器应用；
2. 在系统设置里把"主屏幕应用"从厂商桌面切到它；
3. 在它自己的设置里慢慢调到顺手。

任何时候切回原来的桌面，都只是把默认应用换回去，数据与布局不会丢。

## 二、选启动器：两条路线

- **原生增强路线**：以 Pixel 桌面同源的 Launcher3 为底子，外观贴近原生，把原生不给调的地方（图标包、网格、手势、搜索）补出来。Lawnchair 是这一派的代表——开源（Apache 2.0）、免费无内购、由社区志愿者维护，新系统的 Pixel 特性（Material You 取色、At a Glance）也跟得快。
- **全能定制路线**：自有一套可调体系，设置条目极多、手势极细，代表是 Nova Launcher，完整功能靠内购解锁。

路线没有高下，看你要"像原生但更能调"还是"彻底重定义桌面"。从 Nova 迁移的人还有个加分项：Lawnchair 支持直接读取 `.novabackup` 备份，图标位置与文件夹能一并带入，不用从头摆。

## 三、以 Lawnchair 为例的换桌流程

1. **拿安装包**：它有三个发布渠道——项目发布页定期出的稳定版、跟随代码每日构建的 Nightly、以及 Play 商店版。侧载安装前记得在系统设置里给文件管理器放行"安装未知应用"。
2. **设为默认桌面**：装完先别急着调，长按桌面空白处 → 主屏幕设置，按提示把默认桌面切过去。
3. **解锁受限权限**：Android 13 及以上，侧载应用的通知、无障碍等敏感权限需要手动"允许受限设置"一次，路径在应用信息页的右上角菜单。
4. **按喜好调整**：图标包与单色主题图标、强调色取自壁纸、应用抽屉的全局搜索（应用 / 联系人 / 文件 / 系统设置一起搜）、双击与滑动手势，都在"主屏幕设置"一层里。
5. **做一次备份**：调好后立刻在 更多 → 创建备份 存一份 `.lawnchairbackup`，之后换机或改乱都能一键恢复。

各项设置的细调方法，[Lawnchair 介绍站](https://lawnchair.gltd.quest/)上有按主题整理的图文，配合安装步骤说明一起看更顺。

## 四、换完之后的两件小事

- **手势导航打折是正常现象**：部分厂商在系统层面限制第三方桌面的手势动画，接近原生的机型（Pixel、Nothing、AOSP 类 ROM）表现更好，深度定制机型问题多一些——这是系统限制，换哪个第三方桌面都一样。
- **留意电池优化**：双击熄屏这类依赖无障碍服务的手势，被系统省电策略杀掉后台后会失灵，给启动器关掉电池优化即可。
