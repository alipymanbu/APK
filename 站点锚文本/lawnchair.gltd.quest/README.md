# Lawnchair 站点资料区

这里收录与 Lawnchair——一款基于 AOSP Launcher3 的开源安卓桌面启动器——相关的整理文章。它把 Pixel 风格的桌面体验带到各种安卓机型上，图标包、取色、全局搜索与手势都能自由调整，全程不需要 root。

- [Pixel风格安卓桌面怎么换.md](Pixel风格安卓桌面怎么换.md)：从认清"桌面=启动器"开始，到装包、设默认、迁移布局的完整路径。
- [安卓启动器怎么选.md](安卓启动器怎么选.md)：开源与闭源、原生增强与全能定制两条路线的取舍思路。

想直接看功能介绍与安装文件资源的获取方式，可以去 [Lawnchair 介绍站](https://lawnchair.gltd.quest/)。
