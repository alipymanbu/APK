## 一、为什么像素画特别适合在手机上画

像素画的基本单元是「格」，一笔就是一两个像素，不需要大面积运笔，对设备的要求天然就低——
不需要压感笔、不需要大屏幕，通勤路上掏出手机就能推进几个图标。真正决定体验的是工具够不够专业：
图层、精确到像素的线条控制、方便整理的调色板，这些在桌面软件里理所当然的东西，手机端并不多见。

resprite 是把桌面级像素工作台完整搬到移动端的那一类：安卓、iOS、Windows、macOS 共用同一套
界面逻辑，工具栏、图层、时间轴面板一样不缺，触控与手写笔都做了适配。获取方式见
[resprite 功能介绍与安卓安装包获取](https://resprite.fewz.tech/)，装好就能跟着下面的步骤开画。

## 二、画布开多大合适

新手最容易在尺寸上栽跟头。像素画的「分辨率」就是格数，尺寸翻倍，工作量翻的不止一倍：

| 用途 | 建议起步尺寸 |
| --- | --- |
| 图标、头像练手 | 32×32、48×48 |
| 角色或场景小图 | 64×64、128×128 |
| 精细插画 | 160×160 以上 |

两点经验：

- 画布越大，图层与帧数一多，设备负担上升得很快，手机上宁可从小的开始；
- 新建对话框会记住用过的自定义尺寸，常用的几个存下来，不用每次重输。

## 三、认识几件趁手的工具

| 工具 | 分工 |
| --- | --- |
| 画笔 | 主力，支持完美像素线条，笔刷尺寸在工具控件上拖动调节 |
| 油漆桶 | 区域填色，铺底色最快 |
| 取色器 | 长按画布直接吸色，放大镜帮你确认落点 |
| 选区与变换 | 框选后移动、缩放、旋转，改构图不重画 |
| 抖动纹理 | 不是独立工具——画笔、油漆桶、渐变都能套用抖动图案，做复古颗粒感 |

画错了别急着找橡皮：两指轻点撤销、三指轻点重做，这个手势用顺了效率翻倍；外接键盘的话
还有整套快捷键可用。

## 四、调色板：限定颜色反而更好画

像素画的经典做法是限定用色数量。从一张喜欢的图里提取一套色板，或者用颜色插值给两个端点色
自动补出中间阶梯——明暗过渡就有了。画球体、金属这类需要光照的对象时，材质颜色球能按
光照方向把高光、中间调、阴影的阶梯色一次推出来，直接加进色板备用。

## 五、画完存好，再谈下一步

作品默认存在应用内部存储，安卓端可以在设置里切换到外部存储，文件管理器直接访问。
重要节点导出一份原生格式备份，换设备、防丢失都靠它。画好的静态图发社交平台前，
建议先放大导出（倍数在导出设置里调），小图直接发出去容易被平台压缩糊掉。

想让图动起来，就进入下一阶段——时间轴与逐帧，见[像素动画制作技巧](像素动画制作技巧.md)。
