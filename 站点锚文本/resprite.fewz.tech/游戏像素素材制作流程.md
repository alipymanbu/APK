# 游戏像素素材制作流程：从手机到游戏引擎

> 本篇站在游戏开发的角度讲素材流水线：角色帧动画怎么排成精灵表、地图瓦片怎么画、
> 与 Tiled 等工具怎么接力，以及跨软件协作时各自的格式边界。
> **相关文档**：[手机像素画入门指南](手机像素画入门指南.md) · [像素动画制作技巧](像素动画制作技巧.md)

## 一、独立开发为什么值得在手机上画素材

独立游戏素材有个特点：单件不大，但数量多、碎片化——图标几十个、角色四方向、瓦片一套十几块。
这类活儿最吃「碎片时间」，手机端的专业像素工具正好补这个位置。resprite 的瓦片与导出能力
是按完整游戏工作流设计的，手机上画的部分可以直接进引擎，不需要绕道桌面软件中转。

工具的功能全貌与获取入口见
[resprite 功能介绍与安卓安装包获取](https://resprite.fewz.tech/)，本篇只讲流程。

## 二、角色动画 → 精灵表

引擎（Unity、Godot、Cocos 等）吃的是精灵表：把角色的每个动作帧按网格排进一张大图。
制作侧的要点：

1. 先定帧宽帧高（如 32×32 或 64×64），所有动作统一尺寸；
2. 在时间轴里把一个动作画成一串帧（洋葱皮对齐动作，见
   [像素动画制作技巧](像素动画制作技巧.md)）；
3. 导出时选精灵表，设置每行帧数与边距，引擎里按同样参数切分即可。

一次可以导多个动作，也可以按动画片段分别导出，后者在引擎里更好管理。

## 三、地图瓦片与 Tiled 接力

2D 地图的标准做法是瓦片拼接：画一套可复用的瓦片（草地、路、墙、水岸），再在地图编辑器里
拼装。resprite 直接内建了这条工作流：

- 瓦片图层支持矩形、等距菱形、六边形三种形态，2D 顶视角和战棋类地图都覆盖；
- 地形规则可以先定义「角、边」关系，画地面时边缘与转角瓦片自动匹配，不用手挑；
- 平铺模式能在绘制时实时预览无缝重复效果，做循环背景尤其顺手；
- 与 Tiled 互通：.tmx / .tsx 地图与瓦片集可以导出成 zip 交给 Tiled 用户，也能把 Tiled 的
  地图包（建议带 .tmx、.tsx 与图片资源的 zip）导入进来继续画。

## 四、和桌面软件协作的格式边界

素材难免要在不同软件之间过手，各格式的边界心里有数能少走弯路：

| 交接对象 | 用什么格式 | 注意 |
| --- | --- | --- |
| Photoshop / Krita 等继续精修 | PSD | 保留图层组与混合模式；只含当前帧，动画逐帧导或改用精灵表 |
| Aseprite 用户协作 | Aseprite 格式 | 剪贴蒙版等特性没有对应表达，交接前先确认兼容范围 |
| 引擎与地图编辑器 | 精灵表 / Tiled zip | 引擎按网格切分，参数对齐 |
| 存档与换设备 | 原生工程包 | 帧、图层、调色板完整保留，是唯一「可继续编辑」的备份 |

导入侧同样宽松：GIF、精灵表、Aseprite 项目都能进，进来的东西统一存成工程格式，
想要回去再导出即可。

## 五、一条可复用的手机素材流水线

把上面的内容串起来，独立开发者的移动素材线可以是这样：

1. 通勤或碎片时间在手机上画单件素材（图标、角色帧、瓦片）；
2. 每收工一段就导出原生工程包备份，防止进度只躺在手机里；
3. 需要精修的场合导 PSD 回桌面，动画类导精灵表；
4. 地图类素材走 Tiled 互通，拼装完的地图连同瓦片集一起归档；
5. 引擎里统一按网格参数接入，版本迭代只替换对应精灵表。

素材库是攒出来的，流程顺手了，产出速度比想象中快得多。
