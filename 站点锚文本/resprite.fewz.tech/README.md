# resprite 资料索引（resprite.fewz.tech）

这个目录收录围绕 resprite——一款覆盖安卓、iOS 与桌面端的像素画与像素动画编辑器——整理的中文资料，
内容偏第三视角的功能梳理与上手经验：它能把整套像素创作流程（起稿、调色、分层、逐帧动画、
导出素材）装进手机里完成。配套的介绍站在 [resprite 功能介绍与安卓安装包获取](https://resprite.fewz.tech/)。

## 目录里的文章

- [手机像素画入门指南](手机像素画入门指南.md)——从画布尺寸、工具选择到调色板，第一张像素图怎么落地
- [像素动画制作技巧](像素动画制作技巧.md)——时间轴、洋葱皮与帧率的配合，让图动起来
- [游戏像素素材制作流程](游戏像素素材制作流程.md)——精灵表、瓦片地图与 Tiled 互通，素材怎么交进游戏项目

三篇按「先画图 → 再做动画 → 最后进游戏工作流」的顺序排列，也可以单独翻阅。
