# HanimeViewer 搜索筛选与播放功能速览

> 打开 HanimeViewer 之后怎么找片、播放时能调什么、下载管理有哪些实用设定——本篇把日常最常用的功能串一遍。
> **相关文章**：[下载安装与版本分支说明.md](下载安装与版本分支说明.md) · [首页加载失败与网络设置.md](首页加载失败与网络设置.md)

## 一、首页布局与搜索

进首页主要看两个位置：主内容区放着推荐、最新上传与分类入口；点左上角三条横线呼出侧边栏，设置、收藏、历史、下载入口都从这里进。搜索在右上角放大镜里，输入作品名、系列名或作者名即可——支持中文关键词检索，但冷门作品用日文原名命中率更高；搜过的词留在搜索历史里，复搜一键直达，结果多时往下滑会自动分页。

## 二、高级筛选：四维组合着用

点筛选图标展开高级搜索后，主要条件有四类：视频类型（先勾上直接砍掉大半结果）、排序方式（找新片用最新排、找口碑片按好评排）、标签（可叠加，按题材画风组合定位）、发布日期（锁定老番新番的时间范围）。另外还有影片时长筛选。先定类型，再加标签，最后用日期和时长收口，三步下来基本只剩目标作品。

## 三、播放控制

| 控制 | 说明 |
| --- | --- |
| 倍速 | 可调快可调慢，档位以你的版本播放菜单为准 |
| 画质 | 卡顿先降一档；网络好转再升回去 |
| 播放内核 | 一种内核播不了的片子换另一种常能解决 |
| 画中画 | 退出应用后以小窗继续播 |
| 本地播放 | 直接播下载到本地的视频文件 |

看一半退出的位置一般会被记住，下次从详情页续播即可。

## 四、下载管理与本地导入

把视频加入下载后，任务进下载管理：后台下载让任务排上后可以退出界面干别的；下系列作品时按系列名自动建分组；下载目录可以自定义到存储卡；开「下载后播放」的话，下完的任务点开直接进播放。流量有限的场景先找「仅 WiFi 下下载」一类的开关。下载管理里还有导入本地文件的入口，手机里已有的视频能导进来统一管理。

## 五、延伸阅读

隐私方面还有应用锁与启动器图标伪装可用；网络加载不顺的解法见[首页加载失败与网络设置](首页加载失败与网络设置.md)。整套功能布局的图文版放在 [HanimeViewer 介绍站](https://hanimeviewer.yoan.quest/)，找片之外想先把应用装上的，从[下载安装与版本分支说明](下载安装与版本分支说明.md)开始。
