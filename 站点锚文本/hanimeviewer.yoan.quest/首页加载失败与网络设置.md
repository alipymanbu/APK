# HanimeViewer 首页加载失败与网络设置

> 首页转圈、搜索出不来、提示网站被加固——这类问题九成出在网络链路上。本篇按现象给出排查顺序，所有开关都在应用内的网络设置页里。
> **相关文章**：[下载安装与版本分支说明.md](下载安装与版本分支说明.md) · [搜索筛选与播放功能速览.md](搜索筛选与播放功能速览.md)

## 一、先分清是哪种失败

| 现象 | 大概率原因 | 先做哪一步 |
| --- | --- | --- |
| 首页、搜索一直转圈 | 访问链路不通 | 开应用内置 Hosts |
| 提示「网站被加固」或跳验证页 | 目标站点开了防护 | 换备用域名 |
| 能刷列表，一点播放就卡死 | 播放链路不稳 | 查代理与出口 IP，再降画质 |
| 昨天还好好的，今天全挂 | 内容源改版或换域名 | 换域名不行就升级版本 |

所有开关都在同一个地方：**首页左上角三条横线 → 设置 → 网络设置**。

## 二、两个最值得先试的开关

**应用内置 Hosts**：打开后按提示确认并重启应用。开启后部分地区可以不借助任何其他工具直接访问，但它不是对所有地区、所有运营商都有效，开了没变化属正常，往下走。

**备用域名**：同页下方的备用网站列表里换一个域名。有的版本会显示各域名延迟，选延迟低、能连通的那个，换完同样重启生效。内容源会不定期更换可用域名，哪个能用以当次实测为准。

## 三、代理与出口地区

- 手上本来就有可用代理的，在网络设置里选手动填代理，输入地址和端口后重启应用；代理生效后不必再叠加开内置 Hosts；
- 出口 IP 归属地有讲究：有用户反馈日本 IP 会被内容源拦截，切到非日区后恢复正常；
- 部分版本检测到需要代理时会直接提示开启，照提示做即可；反过来直连能用的环境就别叠加代理，多一层链路多一层卡的可能。

## 四、都试过还不行

按顺序收尾：重启路由器、换网络（WiFi 与流量互换）排除本地波动；仍不行就用新安装包覆盖升级——内容源改版后旧版本的解析逻辑会整体失效，同包名覆盖安装能保留收藏与下载。版本分支的注意事项见[下载安装与版本分支说明](下载安装与版本分支说明.md)。

网络通了之后，从[搜索筛选与播放功能速览](搜索筛选与播放功能速览.md)把界面用起来；想看图文并茂的功能整理，也可以逛逛 [HanimeViewer 介绍站](https://hanimeviewer.yoan.quest/)。
