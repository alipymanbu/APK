# T2S 介绍与获取指引

T2S 是一款安卓端的文字转语音（TTS）工具，能把网页文章、ePub 电子书、PDF 与纯文本文档朗读出来，也支持复制即读、输入即读，还可以把文字导出成音频文件随时回听。它的声音来自系统的朗读引擎，配合 Google 语音服务使用兼容性最好，适合通勤听长文、睡前听书、用耳朵校对文稿这类「眼睛忙、耳朵闲」的场景。

整理了它的功能说明、朗读入口、常见故障排查与安装获取方式，见介绍站：<https://t2s.fewf.click/>
