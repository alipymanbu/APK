# 无损音乐社区搜歌与在线试听方法

> HiFiNi app 的内容以帖子为单位：一首歌或一张专辑对应一个帖子，帖子里带歌词、试听和资源入口。本篇讲在里面搜歌、进帖试听的方法，以及试听前要知道的几件事。

## 先弄清形态：论坛，不是点歌台

在里面找音乐，本质上是「搜帖子」，逛法和论坛接近：搜索结果以帖子列表呈现，同一首歌常有多个帖子（不同版本、不同音质各占一帖）；点进去就是帖子页，试听和资源入口都在帖子里。

## 搜歌的几种姿势

1. **按歌名搜**：输入完整歌名，带书名号能减少歧义，比如搜《海阔天空》比只输「海阔天空」更准；
2. **按歌手搜**：列出该歌手相关的全部帖子，适合整体翻找；
3. **按专辑搜**：歌名想不起来、只记得专辑时用；
4. **翻板块**：华语、日韩、欧美、纯音乐等板块直接逛，适合没目标随便听。

结果太杂时，优先挑标题带音质标注（FLAC、Hi-Res 之类）且发帖时间较新的帖子。

## 进帖试听

列表点开帖子 → 页内点播放即可在线试听，不需要登录，也不用先把文件下到本地。试听是流式加载，对网络有要求：加载慢或点播放没反应，多半是网络波动或该帖音源暂时失效，换个帖子就能验证是哪边的问题。

流量提醒：无损音源一首常在 20~60MB 量级（MP3 320K 约 8~12MB），用流量试听前先掂量套餐，下载留到 Wi-Fi 再做。
