# 帖子回复后提取码在哪看

> 在 HiFiNi app（音乐磁场）里试听免登录，但想拿走文件，得登录并回复帖子后才会显示网盘链接与提取码。本篇讲这一步怎么走、卡住时怎么办。
> **相关文档**：[无损音乐社区搜歌与在线试听方法](无损音乐社区搜歌与在线试听方法.md) · [音乐磁场安卓客户端怎么装到手机](音乐磁场安卓客户端怎么装到手机.md)

## 前提：哪些操作需要账号

| 操作 | 需要登录吗 |
| --- | --- |
| 浏览帖子、搜索 | 不需要 |
| 在线试听 | 不需要 |
| 回复帖子（看提取码的前提） | 需要 |
| 每日签到 | 需要 |

最常见的需求就是第三条：想拿提取码，必须先有账号并在该帖评论区回复。

## 从帖子到手机的完整链路

1. **回复帖子**：登录后在目标帖子的评论区回复任意内容，底部资源区的网盘链接与提取码就会显示出来；
2. **完整复制**：把网盘地址和提取码一起复制，少一位都打不开——注意形近字符（0 与 O、1 与 l），从原帖复制而不是手抄；
3. **网盘里打开链接**：粘贴跳转后输入提取码；
4. **先转存再下载**：把文件转进自己网盘空间，再下载到手机本地，后续不受原帖变动影响；
5. **用本地播放器播放**：FLAC、WAV 多数安卓播放器直接支持；放不出声音先换播放器再下结论，别急着怀疑文件坏了。

## 卡住时的对照

- **回复后提取码仍不显示**：个别帖子另设金币门槛（签到、回帖可攒金币），换个同曲目的帖子最快；
- **链接打不开**：检查末尾是否带上了多余空格；仍不行多半是原帖链接已失效，换帖；
- **转存失败**：多为网盘空间不足，删些旧文件再转。
