# iCity 记录手账 · 安卓安装文件资源与用法整理

一个第三方整理的小站：iCity 我的日记是一款把「写日记」拆成三种轻量记法的安卓应用——日记本收纳生活、心情转盘几秒记状态、目标打卡每天点一下。V4.0 之后每个日记本还配了独立日历与相册，日记可导出成 PDF 留档。

这里沉淀的是围绕它的用法拆解：

- [心情转盘与目标打卡玩法.md](心情转盘与目标打卡玩法.md) —— 两条轻记录线怎么配合；
- [日记本进阶用法与导出备份.md](日记本进阶用法与导出备份.md) —— 日历、相册、版式与导出；
- [换手机与账号的那些事.md](换手机与账号的那些事.md) —— 注册、迁移与误删找回。

应用的获取入口与界面一览，见 [iCity 记录手账](https://icity.gltd.quest/)。
