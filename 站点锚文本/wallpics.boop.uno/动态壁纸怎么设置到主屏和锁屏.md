# 动态壁纸怎么设置到主屏和锁屏：路径与常见卡点

> 动态壁纸的设置动作本身只要十几秒，真正让人卡住的是三件事：来源授权、设完不动、锁屏和主屏想用不同的图。这篇把路径和卡点一次讲清。

不管是哪款壁纸应用，设置路径大同小异，差异在授权与机型行为上。

## 一、标准设置路径

1. 装好应用并授予权限，进图库按分类或榜单挑图；
2. 点开目标图进入全屏预览，确认动效效果；
3. 选「设置 / 应用」，按需选主屏、锁屏或两张都设；
4. 回桌面看效果，不合适就换下一张——动态壁纸试错成本几乎为零。

挑图环节如果想按屏幕类型和动效强度缩小范围，可以看 [Wallpics 挑选思路页](https://wallpics.boop.uno/)，里面有按 AMOLED、LCD 和电量预算整理的选图顺序。

## 二、卡点一：apk 手装被拦

从网盘拿到安装包时，系统会弹「不允许安装来自此来源的应用」，这是所有 apk 手装都会遇到的提示，不是包有问题。处理路径：设置 → 应用 → 特殊权限 → 安装未知应用，给下载所用的浏览器或文件管理器开一次授权；若提示「解析包错误」，多半是下载不完整，重新下载一次再装。

## 三、卡点二：设完不动了

两个常见原因：

- **预览在动、桌面不动**：个别第三方桌面与动态壁纸服务冲突，先换回系统静态壁纸稳住，重启手机后再重设；
- **完全静止**：视差类效果依赖陀螺仪，检查传感器相关开关是否被关闭；慢动效类图本身位移就小，盯着看几秒再下结论。

## 四、主屏锁屏配不同图的组合

值得记的一个搭配：主屏给动态图管氛围，锁屏给静态深色图管续航。锁屏每天被通知点亮几十次，静态图把这块开销直接掐掉；主屏只在真正使用时渲染，动态的代价可控。这笔账在 [安卓动态壁纸费电吗](安卓动态壁纸费电吗-动效类型与省电设置.md) 里算得更细。部分应用还支持自定义充电动画，挑与壁纸同题材的深色动效，观感能从桌面一直延续到插电瞬间。

设置顺一遍就会发现，动态壁纸没有任何需要「折腾」的部分——卡点都集中在第一次安装的授权上，过了那关，剩下的只是挑图。
