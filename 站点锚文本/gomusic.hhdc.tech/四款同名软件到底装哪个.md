# 四款同名软件到底装哪个

> 搜"GoMusic"至少能撞见四款不同的软件：安卓播放器、开源歌单迁移网页、电脑终端工具、国际版播放器。装错软件、功能对不上号，多半就是没分清这四款。这篇按"你想干什么"来对号。
> **相关文档**：[安卓版怎么装到手机上.md](安卓版怎么装到手机上.md) · [网易云歌单怎么整份搬进来.md](网易云歌单怎么整份搬进来.md)

---

## 一、四款对照

| 名称 | 形态 | 解决什么 | 识别特征 |
| --- | --- | --- | --- |
| GoMusic 安卓播放器 | 安卓 App，中文 | 在线搜歌播放、歌单 ID 导入、本地音乐管理 | 版本 1.0，包名 `com.gomusic.zixtty` |
| GoMusic 歌单迁移工具 | 开源网页 | 把网易云/QQ 音乐歌单解析成文本清单，配合迁移网站搬到 Apple/YouTube/Spotify | GitHub 开源，浏览器里用，不装 App |
| gomusic 终端工具 | 电脑命令行 | 在 Linux/macOS 终端里连 YouTube Music 搜、播、下载 | GitHub 开源，跑在电脑上 |
| GO Music（GOMO Live） | 安卓 App | 面向海外市场的播放器 | 走 Google Play 分发，版本号 4.x，界面偏英文 |

## 二、按你要干的事对号

- **想在手机上搜歌、听歌，顺便把网易云歌单搬进来接着听** → 是第一款。它不需要登录任何音乐平台的账号，一个歌单 ID 就能整份导入，安装步骤见 [安卓版怎么装到手机上.md](安卓版怎么装到手机上.md)。
- **想把歌单搬到 Apple Music、Spotify 这些国际平台** → 是第二款（开源网页工具）。它的做法是把歌单解析成"歌名 - 歌手"的通用清单，你再拿清单去 TunemyMusic、Spotlistr 这类迁移网站完成搬家；项目地址是 [`https://github.com/Bistutu/GoMusic`](https://github.com/Bistutu/GoMusic)，作者也提供了在线页面，不想自己部署就直接在浏览器里用。
- **在电脑命令行里连 YouTube Music** → 是第三款，与手机无关。
- **在 Google Play 上搜到的那个英文界面的 GO Music** → 是第四款，开发者是 GOMO Live，与第一款不是同一个软件。

## 三、按名字核对，别按图标

四款里有两款是安卓 App，最容易混。拿到安装包后别看图标，直接对特征：第一款的特征是版本 1.0、包名 `com.gomusic.zixtty`、安装包约 20.65 MB、中文界面。对得上就是它；对不上，多半拿到的是别的东西，回上面表格重新对号。

确认是第一款之后，从哪拿安装包、怎么装，[GoMusic 安卓版下载与安装](https://gomusic.hhdc.tech/)这篇有完整步骤；导入歌单的具体操作在 [网易云歌单怎么整份搬进来.md](网易云歌单怎么整份搬进来.md)。

## 四、迁移工具的三步顺带说清

因为搜索"GoMusic"的人里有不少其实想要第二款，这里把它的一次完整迁移也交代了：

1. **拿链接**：在网易云或 QQ 音乐里打开歌单，分享 → 复制链接；
2. **解析**：在迁移工具的页面粘贴链接，生成"歌名 - 歌手"清单，复制结果；
3. **搬家**：到 TunemyMusic 或 Spotlistr，来源选"任意文本"，粘贴清单，目的地选目标平台，确认迁移。

两点预期要摆正：按名字匹配意味着源平台下架、两边曲库不一致的歌带不走，结果页会列丢失清单；迁移网站是第三方服务，免费额度与可用性以它们自己的页面为准。
