# GoMusic 安卓版怎么装到手机上

> 这个安装包不走应用商店，安卓会拦一次"未知来源"，很多人卡在这一步。这篇从拿安装包讲到装好打开，四步，顺带把拦路的那几个提示都解释清楚。
> **相关文档**：[四款同名软件到底装哪个.md](四款同名软件到底装哪个.md) · [网易云歌单怎么整份搬进来.md](网易云歌单怎么整份搬进来.md)

---

## 一、先确认手上是哪款

叫这个名字的软件不止一个，装错名字功能就对不上。安卓上那款中文播放器的特征：版本 1.0、包名 `com.gomusic.zixtty`、安装包约 20.65 MB、界面中文。对不上这几个特征的话，先去 [四款同名软件到底装哪个.md](四款同名软件到底装哪个.md) 对照一遍再回来。

## 二、安装包从哪拿

安装文件资源放在网盘分享里，不重复贴地址——[GoMusic 音乐播放器介绍](https://gomusic.hhdc.tech/)的下载页里有入口，打开后先转存到自己的网盘，再把 APK 下载到手机存储。手机上直接操作就行，不用连电脑。

## 三、给下载应用开一次安装权限

安卓默认只信任应用商店，第一次装会弹"安装被阻止"。要放行的对象不是这个播放器，而是**负责下载或打开 APK 的那个应用**——浏览器、网盘客户端或文件管理器：

1. 打开设置，直接搜"未知"两个字最快；
2. 进"安装未知应用"（部分品牌藏在：应用管理 → 特殊应用权限里）；
3. 找到你用来下载/打开 APK 的那个应用，打开允许开关；
4. 装完可以把开关关回去，不影响已装好的软件。

品牌差异：小米在"应用设置"里，华为在"安全 → 更多安全设置"附近，其他品牌大同小异。

## 四、装好并打开

在文件管理器里点开下载好的 APK → 选"安装" → 弹安全提示选"仍然安装" → 完成后点"打开"。第一屏就是一个搜索框，输歌名就能开始用；想把攒好的歌单搬进来，接着读 [网易云歌单怎么整份搬进来.md](网易云歌单怎么整份搬进来.md)。

## 五、两个常见卡点

- **反复提示"安装被阻止"**：十有八九是权限开错了对象——开给了播放器自己，而不是下载用的那个应用。回到第三节第 3 步核对。
- **装好打开，切出去就停**：省电激进的机型会把后台清掉。在应用信息 → 电池（或耗电管理）里选"无限制 / 允许后台"，有自启动管理的一并打开。
