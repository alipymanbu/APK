# 进山没信号也能继续导航：离线地图要提前做对的事

> 本篇讲 komoot 的离线使用：哪些东西要在家下载好、没信号时哪些功能照常工作、哪些操作必须在有网时完成。
> **相关文档**：[徒步骑行路线自己画.md](徒步骑行路线自己画.md)

---

## 结论先说

没信号能不能顺利导航，取决于出门前有没有把区域地图下载到手机。定位靠 GPS，不依赖蜂窝网络；语音转向提示在离线状态下照常播报。反过来，没下离线包就进山，导航会受影响——这件事没法在山顶补救。

## 免费区域怎么用

注册后可以免费解锁一个区域，把离线地图下载到手机。选区域的原则很简单：选常去的那一块，家门口的徒步山头、周末骑行的环绕范围，一个区域基本够用。

区域地图的体积大约在 200–600 MB，走 Wi-Fi 下载更稳妥。更多的区域按需单独购买，也有一次性解锁全球地图的 World Pack，按出行半径决定要不要买。

## 出发前的检查清单

按这个顺序过一遍，两分钟：

1. **路线已同步**：在电脑网页上画的线，登录同一账户后会自动出现在手机应用的已计划列表里，不用手动导出导入；
2. **区域地图已下载**：起点、终点和途经区域都覆盖到——跨区路线要把相邻区域也下上；
3. **电量与省电策略**：长时间导航建议带充电宝，或在系统设置里允许应用后台运行，锁屏后定位中断会影响语音报点。

## 没信号时，什么能用什么不能

| 功能 | 无信号时 |
| --- | --- |
| 沿路线导航、显示当前位置 | 照常（GPS 定位） |
| 语音转向提示 | 照常播报 |
| 已下载区域的地图浏览 | 照常 |
| 搜索新地点、加载未下载区域 | 不可用，需回到有网环境 |
| 活动记录 | 照常记录，回网后自动同步 |

一句话总结：**已下载的都能用，没下载的都要网**。

## 想看得更省，耳朵比眼睛好用

骑车时把手机放进背包或车架包，用蓝牙耳机或车把音箱听语音报点；徒步时胸前口袋就能听清。搭配 Garmin 码表或智能手表的话，路线可以直接传到设备上，转向提示在手腕或码表上看，手机全程待在包里。

图文版的五步用法与安装文件资源获取入口，见 [komoot 路线规划介绍](https://komoot.djnf.quest/)；画路线的具体操作（拖拽改线、加途经点、读路面构成）写在[徒步骑行路线自己画.md](徒步骑行路线自己画.md)里。
