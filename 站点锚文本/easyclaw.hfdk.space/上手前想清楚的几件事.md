# EasyClaw 上手前想清楚的几件事

> 本篇不吹功能，只回答装之前值得问的四个问题：要不要懂技术、钱怎么花、数据在哪、三种跑法怎么选。

EasyClaw 名字里带着「Easy」，上手确实不难，但几个前提先想明白，用起来才不别扭。安装包的获取入口在 [EasyClaw 介绍站](https://easyclaw.hfdk.space/)，本篇讲装之前和用之后的事。

## 一、要不要懂技术

不用。它走图形界面：装上、登录、开聊，不需要申请 API Key，也不用碰配置文件。所谓的「龙虾」「Agent」只是叫法，实际体验就是在聊天框里派活。想深度折腾（自定义模型、写专属技能）确实有空间，但那不是门槛，是进阶选项。

## 二、钱怎么花

安装包本身免费下载，注册送体验积分；之后按积分计费，任务越重消耗越多，另有面向重度使用的套餐。两个省钱建议：

1. **先小后大**：新任务先拿最小规模试跑一遍，确认结果符合预期再放量，避免一晚上烧掉一堆积分跑出错的东西。
2. **重活想清楚再挂**：7×24 盯盘、批量抓取这类持续任务才是消耗大头，轻量问答和短任务消耗很有限。

## 三、数据在哪

分两半看：

- **文件与执行**：本地模式下任务在你的电脑上跑，文件不动窝；云端模式跑在专属云主机上。
- **对话与记忆**：存在你的账号里，越用越懂你的「记忆」也在这里。所以账号别外借——它连着能操作你电脑的权限。

## 四、三种跑法怎么选

| 跑法 | 适合 | 前提 |
| --- | --- | --- |
| 手机端 + 电脑端 | 人在外面，活在家里电脑上 | 电脑开机在线、两端同账号 |
| 手机端 + 云端 Bot | 不想开机、任务要常驻 | 按量付积分，云端主机待命 |
| 只装手机端 | 先看看它长什么样 | 大部分活派不出去，仅体验对话 |

一句话：**手机是指挥部，电脑或云端才是工地。** 明确了这一点，剩下的就是想好让它干什么活，可以直接翻 [能替你干哪些活](能替你干哪些活.md)；装好之后怎么派活，见 [手机端怎么用](手机端怎么用.md)。
