# Para 安卓版怎么下载安装？从转存到登录一篇讲完

Para 目前是安卓端应用，安装包通过夸克网盘分享渠道分发。整个过程不需要任何额外工具，按下面四步走即可。

## 四步装好

1. **转存分享资源**：打开分享页，登录夸克账号，把安装包转存到自己的网盘。转存这一步能避免分享链接失效，之后随时可以回自己的网盘取。
2. **下载到手机**：在手机上的网盘 App 里找到刚转存的文件，下载到本机存储。
3. **允许安装**：首次点开安装包时，系统会提示「禁止安装未知来源应用」。按提示到「设置 → 安全」里，允许当前打开安装包的应用（浏览器或网盘 App）安装未知应用，再回到安装页重试。
4. **打开并登录**：装好后打开应用，用手机号或微信一键登录。建议先进「我的」页把身份卡填一填——它既是真人社交的敲门砖，也能让数字人更快懂你。

## 两个常见小问题

**点安装没反应、提示安装被阻止？** 这是安卓的默认保护机制，不是安装包有问题。按第 3 步把「未知来源应用安装」权限放给对应 App 就能解决。

**文件在手机上打不开？** 检查两件事：是否已经先转存到自己账户（预览页里是没法直接安装的）；下载是否已完成——从通知栏或「文件管理」里找到 APK 文件再点开，不要停留在预览页反复点。
