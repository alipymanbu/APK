# 免费额度与Pro功能对照

> 不付费能用吗？能，而且免费版能下的内容与 Pro 完全一样。差别集中在三处：每天次数、设备数、一批进阶动作。这篇把两边拉平对照，顺带讲清 3 天试用怎么开、到期了会怎样。

## 一、先看结论：限量不限质

免费账号与 Pro 账号面对的是同一个内容池：同样的支持站点、同样的视频图片保存、同样的整理功能。Pro 买到的是「更宽的量」和「更多的加工动作」，不是「更高级的内容」。对照如下（条款可能随版本调整，以应用内显示为准）：

| | 免费 | Pro |
| --- | --- | --- |
| 每天下载次数 | 5 次 | 不限 |
| 一个账号绑几台设备 | 1 台 | 3 台 |
| 视频、图片保存 | 有 | 有 |
| 合集、收藏、历史整理 | 有 | 有 |
| 音频、字幕单独提取 | — | 有 |
| 4K / 8K 画质（源提供时） | — | 有 |
| 下载前预览格式 | — | 有 |
| 一键下载（跳过格式列表） | — | 有 |
| 批量：多链接粘贴、清单导入、播放列表展开 | — | 有 |
| 片段剪辑、转 MP3 | — | 有 |
| 并行连接数 / 并行下载数 | 各 1 | 可调 |

有一个容易误会的地方：免费账号在设置里照样能看到代理、自动重试这些进阶开关，它们不会隐藏——只是真的启用去用时才需要 Pro 权益。所以按教程找设置项，位置永远是对的。

## 二、3 天试用：怎么开、到期了会怎样

试用只有一种开法：**在应用内新建账号（UID）**。首次启动的引导页会写明这一点，点一下就开始，管 3 天，期间 Pro 一列的功能全部可用。

到期之后的事情，规则说得很死：

- 账号自动回到免费额度，试用不绑定付费方式，**不存在自动扣费**；
- **什么都不删**：已下载的文件、整理好的合集、历史记录、设置全部原样保留；
- 变的只有限额——回到每天 5 次、一台设备。

## 三、次数是怎么计的

按「点了开始」计数，不是按文件数。一次性勾八行格式、点一次开始，可能第六行就不再启动——那不是坏了，是这天的额度用完了，队列里剩下的项第二天接着来。批量排队时如果前排正常、后排迟迟不动，先想到的就是这件事：打开侧边栏底部的账户页看一眼剩余额度，比反复重启应用省时间。

免费账号还能打开播放列表，只是只能逐条点开里面的单个视频保存；「整张列表一键进队列」才是 Pro 的批量动作。额度之外的日常操作——怎么把链接喂给它、格式怎么挑——写在 [分享菜单存视频的操作步骤.md](分享菜单存视频的操作步骤.md)。

## 四、账号本身：一串 UID

这套体系里没有邮箱也没有密码，账号就是一串形如 `1234-5678-9012` 的 UID。它既是登录凭证也是权益凭证：任何一台设备用它验证通过，就继承对应的套餐。也正因为它不可找回，备份比什么都重要——保管、设备绑定的规则单独写在 [UID账号与设备绑定规则.md](UID账号与设备绑定规则.md)。
