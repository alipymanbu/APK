# 分享菜单存视频的操作步骤

> 在安卓手机上把刷到的视频存进相册，最顺手的路径不是复制粘贴，而是把系统分享菜单交给 9xbuddy 处理。这篇按实际操作顺序拆解：怎么把链接喂进去、格式列表怎么读、点开始之后文件去了哪。

## 一、两条把链接送进去的路

第一条路最省事：在短视频、社交、浏览器等任何应用里，点视频旁边的**分享**按钮，在弹出的分享面板里找到 9xbuddy。它接到链接后会自动解析，把这一页能保存的格式列出来，全程不用打字。

第二条路是手动粘贴：复制视频页的链接，打开 9xbuddy，粘进首页顶部的输入框再点下载。两条路最终看到的格式列表完全一样，选顺手的用。顺手的小技巧：输入框里直接打关键词而不是链接，它会调用设置的搜索引擎帮你找视频，从一条记得的名字出发也能走到文件。

## 二、格式列表怎么读

解析完成后，每一行代表一种可保存的格式，行首有勾选框。列表上方还有过滤器，把结果按类型收窄：全部、视频、图片（音频与字幕的单独提取属于 Pro 权益）。几个常用控件值得记住：

| 控件 | 用途 |
| --- | --- |
| 勾选框 | 勾上才会下载，可以同时勾多行（比如视频加它的字幕，字幕需 Pro） |
| Get size | 源页面没报文件大小时，点它现查一次 |
| ⓘ | 看这一行的技术细节：编码、容器、码率 |
| 滑块 | 只调整这一行自己的选项 |

列表只反映源页面真正提供的内容：源上没有 4K，这里就不会出现 4K。想存某个画质却找不到时，先回源页面确认它的最高画质，再决定换不换链接。

## 三、点开始之后：队列与文件去向

勾完格式，列表上方的确认栏会显示三样东西：勾了几行、存到哪个文件夹（可以改）、开始按钮。点下去之后任务进队列，进度挂在系统通知栏里，切去别的应用不耽误；传输页里可以暂停、恢复、重试某一条。传完的文件离开队列，进 Library 陈列——带缩略图、能直接播放、能分享给其他应用，默认保存在系统下载目录，也可以在设置里改位置。

## 四、免费额度先知道：一天 5 次

免费账号每天能发起 5 次下载，按「点了开始」计数。一次性勾很多行、或整批排队时，额度可能在中途用完，队列后面的项不会启动，第二天自动恢复。想看当前剩余额度，打开侧边栏底部的账户页就能看到。免费与 Pro 的完整差别，单独整理在 [免费额度与Pro功能对照.md](免费额度与Pro功能对照.md)。

## 五、一句话提醒

只保存自己拥有或已获授权的内容。私享、已删除、带版权保护的内容本来就拿不到，这不是工具的问题，换什么软件都一样。
