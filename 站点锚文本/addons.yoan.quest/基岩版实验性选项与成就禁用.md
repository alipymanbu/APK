# 基岩版实验性选项与成就禁用

> 给脚本类模组开 Experiments 之前，先花三分钟看这篇：开关在哪、哪些包才需要开、开了要付出什么代价——成就判死、关不掉、存档有风险，以及怎么把这些代价降到最低。
> **相关文档**：[我的世界基岩版模组导入后没反应怎么办.md](我的世界基岩版模组导入后没反应怎么办.md)

---

## 一、什么模组才需要动这个开关

大多数 Add-On 激活就能用，不需要碰实验性选项。**只有脚本类模组**——那些自定义界面、加原版行为包做不到的新机制的包——才依赖实验功能，对应开关是 **Beta APIs**。

判断依据看模组自己的说明页：它没提实验开关或 Beta APIs，就先别动，直接按普通包激活测试；激活后确实没反应，再回来按脚本包处理。

## 二、开关位置与开启步骤

1. 主界面 **Play** → 点世界旁边的**铅笔图标**进入编辑世界（新世界则在创建页）；
2. 左侧列表找到 **Experiments**（实验性）；
3. 在 Add-on creators 区域打开 **Beta APIs**（说明文字是 use "-beta" versions of API modules 的那个）；
4. 弹确认框时选**「仍然开启」**那一侧——注意有些弹窗里绿色按钮反而是「取消返回」，点错等于没开。

开完回到世界，激活对应的脚本包，重进世界测试。

## 三、开了要付的代价（先看这条再动手）

- **成就被禁用**：开启后，这个世界的成就直接判死，左栏挂着 Achievements disabled，再也拿不回来；
- **关不掉**：实验性选项在世界创建后无法关闭，只能一直开着；
- **存档风险**：给重要存档直接开实验功能有翻车风险，翻车了没有回头路。

这三条叠加起来就是一条纪律：**先复制一份世界，在副本上开**。副本里试清楚了、确认模组能跑，再决定要不要在常用存档上承担成就代价。

## 四、一个过时说法的纠正

不少老教程会让开启 **Holiday Creator Features**。这个实验开关在 1.21.20 版本更新中已被移除——现行版本里根本没有这个开关。脚本类模组现在对应 **Beta APIs**；自定义方块、自定义物品这类功能也已转正，不再依赖实验开关。

如果你的游戏版本里还能看到别的实验项（如 Beta APIs 之外的创作者实验），以模组说明页的要求为准，没被要求的开关一律不动。

## 五、开了还是没效果

按顺序核对三件事：

1. 包本身是否在 **Active** 列表里，而不是停在 Available——实验开关只负责放行脚本，不负责激活包；
2. 行为包与资源包是否都激活了（只开行为包会缺材质，只开资源包生物不会动）；
3. 游戏本体是否为较新版本，旧版游戏跑不动用新 API 写的包。

前两条对不上，回排查路线那篇从头走一遍：[我的世界基岩版模组导入后没反应怎么办.md](我的世界基岩版模组导入后没反应怎么办.md)。想挑一些标明依赖关系的包来源，[MCPE Addons 排查手册](https://addons.yoan.quest/) 里有关于这类工具的介绍与使用说明。
