# 免费版和PRO订阅怎么选

> 本篇按「免费版能跑到哪、PRO 才接手什么」的边界整理 YAZIO 两种版本的分工，给一个先免费跑两周、再决定要不要订阅的判断顺序。
> **相关文档**：[卡路里目标计算公式怎么看](卡路里目标计算公式怎么看.md) · [断食计时怎么上手](断食计时怎么上手.md)

## 一、先说结论

只想把每天的热量账记明白，免费版从头到尾都用得上；开始馋食谱库、进阶断食程序和拍照识别时，再考虑订阅也不迟。这个结论来自两款版本的功能边界：核心记录闭环在免费范围内是完整的。

## 二、免费版有什么

按应用商店与帮助文档整理的免费范围：

- 卡路里与碳水、蛋白质、脂肪三大营养素追踪；
- 食品数据库检索加条码扫描记录；
- 基础断食计时器（16:8）；
- 体重与饮水量记录、身体数据追踪；
- 与 Google Fit、Apple 健康等平台同步步数与活动消耗。

也就是说，「设定目标 → 记录 → 看剩余」这个每天要用的主循环，免费版一步不缺。

## 三、PRO 接手什么

PRO 是订阅制（应用内购买，按时长分档），在免费范围之上加的是「增量弹药」：

| 功能 | 说明 |
| --- | --- |
| 食谱库 | 2,000+ 食谱，按热量、食材、饮食类型筛选，配营养图表 |
| 引导式断食程序 | 10+ 套成体系的断食课程，而非单一计时器 |
| AI 拍照记录 | 拍一张照片自动识别餐食内容 |
| 微量营养素分析 | 20+ 种细节（糖、纤维、钠等） |
| 个性化膳食计划 | 按目标生成计划并联动购物清单 |
| 无广告 | 界面纯净 |

## 四、一个可操作的判断顺序

1. 先用免费版实打实记满两周，感受「每天几十秒记账」的节奏能否留下来；
2. 观察自己卡在哪：是想吃的搭配没思路（食谱库）、还是断食想跟课程走（断食程序）、还是嫌手动输入烦（拍照识别）；
3. 卡点恰好是 PRO 的强项再订；一个卡点都没有，就继续用免费版——它不欠谁一个订阅。

订阅通过应用内购买完成，随应用商店账户管理、可随时在商店设置里取消续订。想先看看界面再决定，可以翻这份 [YAZIO 介绍站](https://www.ggcd.uno/)整理的四个高频页面截图；装好后的前三步，见[断食计时怎么上手](断食计时怎么上手.md)。
