# 关键帧缓动与预览卡顿

用 amls 剪到一半遇到两个高频状况：动画看着生硬、时间轴越剪越卡。这两件事的解法都藏在图层面板和设置页里，不用换设备。

## 动画生硬：给关键帧加缓动曲线

amls 的动画原理是「同一属性在两个时间点各记一个值」——起点一帧、终点一帧，中间由软件补齐。默认补齐方式是匀速直线，物体说动就动、说停就停，所以显得硬。

处理办法：选中关键帧，打开缓动曲线设置，选缓入缓出。运动开始时逐渐加速、结尾逐渐减速，观感立刻自然。做弹跳、滑入这类动作时，先摆好两端关键帧再加曲线，比反复挪帧位置省事得多。

进阶一点的做法是把位移和缩放分开两帧错开半拍，配合曲线做出「甩」的感觉——教程页「后续步骤」组里专门讲这一节。

## 时间轴卡顿：三个设置项按顺序排查

图层一多、特效一重，预览掉帧几乎是必然的。按下面顺序调，多数机型能救回来：

1. **低质量预览**：设置页里直接打开。它只降低编辑时的预览画质，不影响导出结果，是最先该动的一个开关；
2. **音频重采样**：低 / 高 / 超三档，预览卡顿时降到低档，导出前再回高位；
3. **演示模式**：不需要逐帧确认细节的粗剪阶段可以打开，减少实时渲染压力。

如果开了低质量预览还是卡，优先删减带模糊、发光这类重特效的图层试一试，而不是降分辨率——画质损失留给导出参数去控制更划算。
