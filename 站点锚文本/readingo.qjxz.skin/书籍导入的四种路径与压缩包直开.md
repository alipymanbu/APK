# 书籍导入的四种路径与压缩包直开

> 本地阅读器装完第一件事就是放书进去。本篇按场景整理 Readingo 的四种导入方式各适合什么情况，以及压缩包免解压直开的省事玩法。
> **相关文档**：[不带书城的本地阅读器怎么样](不带书城的本地阅读器怎么样.md) · [阅读主题排版与听书统计玩法](阅读主题排版与听书统计玩法.md)

## 一、先对格式

动手前确认文件 Readingo 认不认：正文格式支持 TXT、EPUB、PDF；压缩包 RAR、ZIP、7Z、TAR 可以在应用内直接打开，不必先解压，带密码的按提示输入即可。选文件时不在列表里的格式就是不支持，不用反复试。

## 二、四种导入方式，按场景挑

| 方式 | 怎么操作 | 适合什么情况 |
| --- | --- | --- |
| 手动导入 | 系统文件选择器里逐个勾选 | 清楚书在哪，最直接 |
| 自动扫描 | 授权后扫全机电子书，扫完勾选 | 书散落在手机各处，懒得找路径 |
| 文件管理器 | 在文件管理 App 里「用 Readingo 打开」 | 正好翻到了书，顺手就进 |
| WiFi 传书 | 应用内启动图书服务器，电脑浏览器访问给出的地址拖文件进去 | 书在电脑上，懒得插数据线 |

自动扫描第一次用会单独申请文件扫描权限，中途任何一步拒绝了权限，扫出来的列表就是空的——扫不出结果时先去系统设置里把存储/文件权限补开，再重进扫描页。

## 三、压缩包直开是最省事的入口

网上下载的书很多是一整个 ZIP 里塞了好几个 TXT。不必在手机上先解压再挑文件：直接把这个包导进来，应用会自己拆开取书，一次进来一整批。带密码的 RAR / ZIP 同样支持，导入时按提示输密码就行。

## 四、书进来之后：三层整理维度

- **分类**：支持无限层级，「科幻」下还能再分「硬科幻 / 太空歌剧」，每个分类可单独设定排序与封面；
- **标签**：给书打多个标记（「通勤」「待读完」都可以），保存时新标签自动创建；
- **作者**：填上之后可按作者筛选，「批量提取作者」能把一批书的作者从文件信息里自动扒出来。

书多了以后配合列表 / 网格视图切换、按名称或阅读时间排序、组合筛选来用，长按多选批量设标签、移分类，书架不会乱。

WiFi 传书连不上时，多半是「不在同一局域网」「地址没抄全」「传输页被关掉」这几样，换数据线或网盘中转也行。想看这款阅读器的整体功能与安装文件资源入口，见 [Readingo 本地阅读器介绍站](https://readingo.qjxz.skin/)；导入之后的排版与听书玩法，见 [阅读主题排版与听书统计玩法](阅读主题排版与听书统计玩法.md)。
