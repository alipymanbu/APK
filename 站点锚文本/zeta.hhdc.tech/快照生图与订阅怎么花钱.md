# 快照生图与订阅怎么花钱

本篇讲 zeta 的消费口径：哪些功能消耗 Pieces 点数、zeta pass 订阅解锁什么、免费账号长期玩走得通走不通。

## 先说结论

基础聊天不按条收费：和角色对话不限条数、自己捏角色、生成快照，免费账号都能用，主要代价是对话间隙和部分界面会插广告。愿意看广告，长期免费玩得通；这一点和不少按条计费的 AI 聊天应用不一样。

## Pieces 花在哪

Pieces 是应用内点数，主要消耗在三处：

| 去处 | 说明 |
| --- | --- |
| 快照 | 把当前对话场景变成一张插画，留住聊出来的名场面 |
| AI 生图 | 按风格词出图：发色、发饰、服装一个个叠，叠加的词越具体越接近想要的 |
| 高级模型 | luca 与 koji 两个模型走沉浸更深的方向，按点数消耗 |

各功能的具体扣点规则会随版本调整，以应用内提示为准。

## zeta pass 解锁什么

订阅的权益口径：去掉广告、私密创作数量放开、每月附 200 Pieces、响应更快。定价各区域不同，下单前以订阅页实际显示为准。订阅走应用商店账号管理，自动续费，取消要在到期前去商店订阅页操作——先取消扣费，再考虑其他动作，顺序别反。

## 要不要开，按实际用况判

- 每天聊一小时以内、不烦广告：不用开，免费额度绰绰有余；
- 一聊就停不下来、经常通宵长对话：广告频次加部分功能的限制会开始硌手，订阅主要买的是「不被打断」；
- 只想先试试：免费玩一两周，记一下自己实际碰到几次付费提示，比看任何评测都准。
