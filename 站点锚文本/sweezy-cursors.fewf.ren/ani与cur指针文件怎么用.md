# ani与cur指针文件怎么用

> 从光标站拿到的 .cur / .ani 文件不是双击就能用的，要进 Windows 的鼠标设置里替换指针方案。这篇讲清两种文件的区别、替换步骤和几个容易卡住的点。
> **相关文档**：[浏览器动态光标怎么换.md](浏览器动态光标怎么换.md) · [Roblox自定义光标文件替换.md](Roblox自定义光标文件替换.md)

---

## 一、两种文件分别是什么

- **.cur**：静态指针文件，一张定住的图。
- **.ani**：动态指针文件，帧动画，光标本身会动。

Sweezy Cursors 的每个光标详情页都按用途提供格式：动态的给 .ani，静态的给 .cur，还有 PNG 图片与整包 zip。想让系统全局换指针，取 .cur 或 .ani 就对了。

## 二、替换步骤（Win10 / Win11 思路一致）

1. 打开「设置 → 蓝牙和其他设备 → 鼠标 → 其他鼠标设置」（旧版本走控制面板搜「鼠标」），切到「指针」选项卡；
2. 在方案里选中当前使用的那一套，点「浏览」，选中拿到的 .cur / .ani 文件，逐个替换「正常选择」「链接选择」等角色；
3. 替换完点「另存为」存成一个自己的方案，再「应用」。桌面、资源管理器即刻生效，不用重启。

## 三、容易卡住的地方

- **.ani 双击打不开**：正常，它不是可直接运行的文件，只能在鼠标设置里挂载。
- **动态指针不播动画**：少数远程桌面、触屏环境下会被回退成静态，回到本机桌面就正常。
- **想恢复默认**：指针方案里选回「Windows 默认（系统方案）」，一键还原。

## 四、和浏览器扩展是什么关系

扩展管浏览器内的页面，.cur / .ani 管系统全局，两套一起换风格才统一。扩展的装法见 [浏览器动态光标怎么换.md](浏览器动态光标怎么换.md)。

具体有哪些主题可挑，[Sweezy Cursors 介绍站](https://sweezy-cursors.fewf.ren/) 的实拍区放了几张光标库截图，可以先看看再决定取哪种格式。
