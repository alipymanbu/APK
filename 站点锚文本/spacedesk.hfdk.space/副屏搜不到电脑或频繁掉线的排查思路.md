# 副屏搜不到电脑或频繁掉线的排查思路

> spacedesk 用着用着出状况：手机列表里根本不出现电脑、点了连接失败、用一会儿就掉线、提示 expired——本篇按出现概率把它们排成一条排查链，从头走一遍基本都能定位。
> **同站相关**：[手机当电脑副屏的连接方法与模式选择](手机当电脑副屏的连接方法与模式选择.md) · [副屏画面卡顿的优化顺序](副屏画面卡顿的优化顺序.md)

## 一、五步快查（先花一分钟）

1. 电脑端 spacedesk Driver Console 状态是不是 **ON**；
2. 手机和电脑是不是连的**同一个路由器**（注意访客 Wi-Fi 与主 Wi-Fi 是两个网络）；
3. 两端是不是都没开 **VPN**；
4. 电脑上有没有装**第三方安全软件**——它们自带防火墙，Windows 防火墙的例外对它们无效；
5. 两端都重启一次再试（驱动 OFF 再 ON，手机端 App 杀掉重开）。

大多数连接问题出在这五步里，快查没解决再往下对号入座。

## 二、列表里根本不出现电脑

按命中率从高到低：

| 原因 | 确认方法 | 处理 |
| --- | --- | --- |
| 不在同一网段 | 两端连的是不是同一个路由器 | 改连同一 Wi-Fi；多路由器 / 中继的确认没做网络隔离 |
| AP 隔离（访客网络常见） | 手机连的是不是访客 Wi-Fi | 关隔离或换主网络 |
| VPN 拦在中间 | 两端任一处开着 VPN | 都关掉再搜 |
| 电脑端驱动没开 | Console 显示 OFF | 点成 ON |
| 防火墙拦了 | 装 DRIVER 时没勾"加入防火墙例外" | 防火墙里手动放行 spacedesk，或重装并保持勾选 |
| 安全软件拦了 | 装了电脑管家类软件 | 在它自带的联网防火墙里放行 |

还搜不到的话，让电脑开热点、手机连热点再试一次：热点下能连上，问题就锁定在路由器网络侧。公司 / 学校网络常有设备隔离策略，这类环境换热点直连最省事。USB 方式的专属问题（共享开关灰着、报"未识别的网络"）多数不是故障——开关灰说明线材不能传数据或没先插线；"未识别的网络 / 无 Internet"是这条链路的正常状态，它本来就不需要能上网。

## 三、能搜到，但连接失败或闪退

- **两端版本差距过大**：电脑端 DRIVER 与手机端 Viewer 版本不匹配会连不上，两端都更到当前版本再试；
- **连接中途闪退**：清干净手机后台重开 App，内存紧张的旧设备更容易出现；
- **显卡驱动太旧**：先更新显卡驱动再试，历史上旧驱动与 spacedesk 同用出过蓝屏案例；
- **反复失败**：Console 里 OFF → ON 切一次，等 10 秒再连。

## 四、提示过期（expired）

spacedesk 的版本自带有效期，到期日显示在电脑端 Driver Console 里。到期后只有一条路：

1. 电脑端重装**当前**版本的 DRIVER；
2. 手机端用**当前**版本的 APK 重装（获取入口见 [spacedesk 副屏方案](https://spacedesk.hfdk.space/)的下载页）；
3. **两端都要更新**，只更新一头依然失败。

平时瞄一眼 Console 里的到期日，快到期顺手更两端，这个坑可以彻底避开。

## 五、连上但频繁掉线

- **Wi-Fi 信号弱或拥挤**：改热点直连或 USB 线，掉线率立刻下来；
- **USB 方式掉线**：多半是节电策略掐的——设备管理器里取消"允许计算机关闭此设备以节约电源"，电源选项里禁用"USB 选择性暂停"；手机侧关省电模式、插着电源；
- **虚拟机 / 多卡互联**：虚拟机里的 Windows、开启 SLI / CrossFire 的多显卡，都不在支持范围内，别在这上面耗时间。

排查完连得上了、但画面卡，去[副屏画面卡顿的优化顺序](副屏画面卡顿的优化顺序.md)调连法与设置；连法本身怎么选，见[手机当电脑副屏的连接方法与模式选择](手机当电脑副屏的连接方法与模式选择.md)。
