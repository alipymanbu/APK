# 手机当电脑副屏的连接方法与模式选择

> 手头有闲置的安卓手机或平板，想让它们给 Windows 电脑当第二块屏幕——spacedesk 就是为这件事准备的工具。本篇讲清它的两端架构、三种连接方式怎么选、连上之后扩展与镜像两种模式怎么切。
> **同站相关**：[副屏搜不到电脑或频繁掉线的排查思路](副屏搜不到电脑或频繁掉线的排查思路.md) · [副屏画面卡顿的优化顺序](副屏画面卡顿的优化顺序.md)

## 一、先认清两端架构

spacedesk 由两个部分组成，缺一不可：

| 设备 | 装什么 | 作用 |
| --- | --- | --- |
| Windows 电脑 | spacedesk DRIVER（驱动） | 当"被显示的一端"，状态默认开启 |
| 安卓手机 / 平板 | spacedesk Viewer（App） | 当"显示的一端"，画面落在它的屏幕上 |

电脑端支持 Windows 11 / 10 / 8.1（Windows 7 已不在支持列表）；安卓端要求 Android 5.0 以上。两端的安装与首次连接全过程，在 [spacedesk 副屏方案](https://spacedesk.hfdk.space/)的下载页里按步骤整理过，跟着走一遍即可。

## 二、三种连接方式，按场合挑

1. **Wi-Fi 局域网（首选）**：手机与电脑连同一个路由器，打开 Viewer 等列表刷出电脑名，点一下就连。日常桌面办公用这条最省事。
2. **热点直连（更顺滑）**：让电脑开移动热点、手机连上去，绕开路由器点对点传输。延迟通常比经过路由器的 Wi-Fi 好，笔记本加手机在外的场合也靠它。
3. **USB 数据线（最稳）**：手机开"USB 网络共享"、插线连接，不受任何 Wi-Fi 干扰。注意两点：线材必须能传数据（大量线是纯充电线，插上共享开关是灰的）；顺序是先插线再开共享。

三个补充事实：

- 画面数据**只在局域网内传输，不需要连接互联网**；
- 同一网络里的其他设备也可能搜到你的电脑，公共 Wi-Fi 下建议改用 USB 或热点直连；
- 开着 VPN 会让两端"看起来不在一个网络里"，是搜不到电脑的高频原因。

## 三、扩展还是镜像

连接成功后，手机默认成为**扩展屏**（桌面延伸出去的一块）。想换模式：

1. 电脑上按 `Win + P`，或右键桌面进显示设置；
2. **扩展**：两边内容不同，资料、聊天窗口拖过去，办公首选；
3. **复制**：手机与主显示器显示同样内容，适合把手机架起来当演示屏；
4. 显示设置里还能拖动两块屏幕的相对位置，让鼠标移动方向与实物摆放一致；副屏的分辨率、缩放也在这一页调。

## 四、连上之后还能怎么用

- **触控回传**：手机屏幕可以直接点按操作电脑，"触摸屏（绝对位置）"与"触摸板（相对移动）"两种模式在 App 设置里切换；
- **压感笔**：带手写笔的设备开启 Stylus 控制后，能当 Windows 的绘图板；
- **多设备同连**：平板放资料、手机竖着挂聊天窗口，每台 Viewer 各占一块扩展屏；同时连的设备越多，无线带宽压力越大，量力而行；
- **横竖屏**：转动手机画面跟着旋转，不需要时锁方向或在设置里关自动旋转。

模式选择与卡顿调优是两件事：连法决定下限，设置决定上限——后者见[副屏画面卡顿的优化顺序](副屏画面卡顿的优化顺序.md)；连都连不上的情况，直接翻[副屏搜不到电脑或频繁掉线的排查思路](副屏搜不到电脑或频繁掉线的排查思路.md)。

## 五、版本有效期的特殊机制

spacedesk 目前以 beta 形式发布，**每个版本自带有效期**，到期日显示在电脑端 Driver Console 里。到期后连接失效，且**电脑端与手机端要一起更新到当前版本**才能恢复，只更新一头无效。建议平时在 Console 里瞄一眼到期日，快到期就顺手把两端都更了。
