# 副屏画面卡顿的优化顺序

> spacedesk 连上了，但画面拖影、鼠标慢半拍、视频掉帧——大多数卡顿在连接方式选定时就注定了，设置只能再挤一截。本篇先给选路优先级，再讲链路之外能调的档位，最后区分"真卡"与"显示异常"。
> **同站相关**：[手机当电脑副屏的连接方法与模式选择](手机当电脑副屏的连接方法与模式选择.md) · [副屏搜不到电脑或频繁掉线的排查思路](副屏搜不到电脑或频繁掉线的排查思路.md)

## 一、先分清是"卡"还是"显示异常"

两种现象用药完全不同：

- **延迟类**（画面跟手但慢半拍、拖影、掉帧）→ 传输链路问题，看第二节换连法；
- **异常类**（黑屏、变色、闪烁）→ 多数是电脑端某个功能与它冲突，直接跳第四节。

## 二、连接方式性能排序

从上往下选，能插线就别走无线：

| 排序 | 连接方式 | 适用 |
| --- | --- | --- |
| 1 | 网线直连（电脑 ↔ 设备） | 带网口的平板 / 盒子 |
| 2 | 网线经路由器 / 交换机 | 双方都能插网线 |
| 3 | Wi-Fi 热点直连 / USB 网络共享 | 最推荐的无线与有线便捷档 |
| 4 | Wi-Fi 经路由器 | 万不得已再用 |

两个实测结论：

- **无线路由器是最大的卡顿来源**。同样两台设备，从"各自连路由器的 Wi-Fi"改成"电脑开热点、手机连热点"，观感差距立竿见影；
- **USB 共享是无线不稳时的兜底**，插根能传数据的线就绕开了所有 Wi-Fi 干扰。

另外让手机连同一路由器的 **5GHz** 频段而不是 2.4GHz，带宽与抗干扰都好一截。

## 三、链路之外还能调什么

- **副屏分辨率调低一档**：显示设置里选中副屏降分辨率，传的画面越小压力越小；
- **画质与帧率档位**：Viewer 设置里提供画质与帧率（常见 30 / 60 fps 两档）。纠结点就一个：无线网络下"低画质 + 60fps"通常比"高画质 + 30fps"观感好，有线带宽富裕才把画质拉满；
- **主屏别满载**：电脑同时渲染游戏或大量视频输出时，留给画面传输的处理空间变少；
- **手机别省电**：省电模式会限网络与性能，当副屏时关掉；
- 细调可以照开发手册的 Performance Tuning 章节过一遍，入口在 [spacedesk 副屏方案](https://spacedesk.hfdk.space/)有整理。

## 四、不是卡，是显示异常：四个已知冲突

| 现象 | 元凶 | 处理 |
| --- | --- | --- |
| 副屏黑屏 / 显示"已连接 - 显示关闭" | NVIDIA ShadowPlay / 游戏内覆盖在录制 | 关掉再连 |
| 桌面颜色发灰、变色 | 显卡面板开了 10bit 像素格式 | 改回 8bit 后重启 |
| 夜灯色调在副屏不生效 | Windows 夜灯 | 副屏不支持，属正常 |
| HDR 画面异常 | Windows HDR | 副屏不支持 HDR，属正常 |

另有一类用户反馈：电脑长时间不重启后出现"已连接 - 显示关闭"，重启能暂时恢复、几小时后复发——有用户靠**更新或重装显卡驱动**缓解。现象吻合时先动显卡驱动，别反复折腾 spacedesk 本身。

## 五、哪些用途别硬调

给个判断依据，替你省时间：文档、网页、代码、聊天窗口这类静态为主的画面，热点直连就够顺；**高帧率游戏、音画同步敏感的视频剪辑监看，不适合任何软传输方案**——链路延迟摆在那里，物理显示器的手感调不出来，这类需求直接上真显示器。

连法本身怎么选、扩展与镜像怎么切，见[手机当电脑副屏的连接方法与模式选择](手机当电脑副屏的连接方法与模式选择.md)；掉线与搜不到电脑在[副屏搜不到电脑或频繁掉线的排查思路](副屏搜不到电脑或频繁掉线的排查思路.md)。
