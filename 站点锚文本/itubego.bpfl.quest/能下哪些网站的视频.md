# 能下哪些网站的视频

> 本篇整理 iTubeGo 安卓版主页预加载的站点清单、列表之外的站怎么处理，以及判断「某个站能不能下」的实操办法。
> **相关文档**：[安卓版怎么下载视频.md](安卓版怎么下载视频.md) · [下载的视频存在哪里.md](下载的视频存在哪里.md)

## 一、主页预加载的站点

打开应用第一眼看到的「热门网站」网格就是开箱即用的入口，实测主页上预加载的有：

| 类别 | 站点 |
|---|---|
| 综合视频 | YouTube、Dailymotion、Vimeo、TED |
| 社交平台 | Facebook、Instagram、X、TikTok |
| 音乐音频 | SoundCloud、Vevo、Bandcamp、MixCloud、AudioBoom |
| 其他 | OK.RU、niconico、VK |

几点使用规律：

- **Google Play 商店里上架的那一版不含 YouTube 下载**（受商店政策限制），APK 安装包这一版才带。拿商店版试 YouTube 失败，不是操作的问题。
- **列表外的站不代表不能下**。智能链接检测认得媒体流就能解析，站点清单只是预加载过的部分；判定某个站行不行，最快的办法是实际送一次链接（三种送法见 [安卓版怎么下载视频.md](安卓版怎么下载视频.md)）。
- **站点本身改版会让解析暂时失效**，这是常态。某条视频解析不出来时，先换一种送链接的方式再试。

## 二、常去的站自己加到主页

主页预加载的站点有限，把常去的站加进来能省一步：

1. 在主页站点区点 Add。
2. 填一个自己认得出的标题。
3. 粘贴该站的网址，点 OK，图标就出现在主页上。

以后下载直接从这个图标进，不用先开浏览器再输网址。用内置浏览器逛到值得回访的视频页，也可以点右上角 Bookmark 收进书签，下次从书签直达。

## 三、输出格式与画质档位

视频存 MP4，档位从 360p 到 2160p（4K），具体某条视频能选到哪几档以弹窗里实际列出的为准；音频存 MP3、AAC、M4A，70 / 128 / 320kbps 三档，下载时先转换再落盘。音频的 ID3 标签（标题、封面、专辑等）会随文件保留，下载的歌进音乐播放器后通常不用手动补信息。

想动手试的话，安装包获取入口与界面演示在 [iTubeGo 安卓版介绍站](https://itubego.bpfl.quest/)；下载完成的文件去哪了，见 [下载的视频存在哪里.md](下载的视频存在哪里.md)。
