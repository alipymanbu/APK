# 安卓版怎么下载视频

> 本篇讲 iTubeGo 安卓版上把视频存进手机的三种方式，以及格式与画质怎么选、播放列表怎么整批下。
> **相关文档**：[能下哪些网站的视频.md](能下哪些网站的视频.md) · [下载的视频存在哪里.md](下载的视频存在哪里.md)

## 一、三种把视频送进应用的方式

**方式 1：内置浏览器直接找。** 打开应用，主页预加载了 YouTube、Facebook 等热门站点图标，点进去像普通浏览器一样浏览；播到想存的那条视频，点右下角的下载按钮即可。这是路径最短的一种——全程不用复制任何链接。

**方式 2：复制链接让它自动认。** 在任意浏览器或其他应用里复制视频链接，再打开 iTubeGo，它会自动检测剪贴板里的链接并弹出下载提示，点确认就开始解析，不用手动粘贴。

**方式 3：从其他应用分享进来。** 比如在社交应用里刷到一条视频，点「分享」，在分享列表里选 iTubeGo，应用会拉起并自动开始解析下载。

三种方式最终都会落到同一个下载设置弹窗，接下来的选项是一样的。

## 二、下载设置弹窗：只看两项

- **Type（类型）**：选 Video 出来的是带画面的 MP4；选 Audio 就只留声音，存成 MP3。
- **Quality（质量）**：视频档位按站点实际给的分辨率走，从 360p 到 2160p（4K），站点没提供的档位不会出现；音频是 70 / 128 / 320kbps 三档，想当铃声或存有声书就选 320kbps。

选完点 OK，任务先进转换队列再落盘，进度在底部 Download 区逐条可见。

## 三、播放列表一次整批下

1. 用内置浏览器打开目标频道，切到 Playlists 标签，进入其中一个播放列表。
2. 点下载按钮，先选好输出类型与质量。
3. 在弹出的清单里点 Select All 全选（也可以只勾几条）。
4. 点 Start Download 开始，先转换完的先落盘，以 Download 区的实际状态为准。

批量下之前建议先单下一条把档位试对——格式在下那一刻就定死了，已下完的文件不能在应用内改格式。

## 四、装不上或点下载没反应

点下载没反应，先确认存储权限给了，再看是不是开着「仅限 WiFi 下载」而此刻在用流量。安装阶段的拦路问题（未知来源、空间不足、解析包出错）在这个站的下载页有逐条处理办法：[iTubeGo 安卓版下载与安装](https://itubego.bpfl.quest/)。装好之后的文件管理细节见 [下载的视频存在哪里.md](下载的视频存在哪里.md)。
