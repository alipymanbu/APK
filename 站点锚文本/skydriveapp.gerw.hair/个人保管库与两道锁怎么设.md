# 个人保管库与两道锁怎么设

> 本篇讲手机借人、丢失场景下的两层防护：应用启动密码与个人保管库的设置方法与边界。
> **同目录其他文章**：[微软云盘安卓版的旧名与新生.md](微软云盘安卓版的旧名与新生.md) · [手机照片自动备份与腾地方.md](手机照片自动备份与腾地方.md)

## 一、两道锁各防什么

| | 应用密码 | 个人保管库 |
| --- | --- | --- |
| 防什么 | 别人拿起手机直接打开应用翻文件 | 账户被登着的前提下，敏感文件再加一道身份验证 |
| 验证方式 | 6 位 PIN，可换指纹解锁 | 短信 / 邮箱验证码 / Authenticator 等二次验证 |
| 作用范围 | 整个应用 | 只有「个人保管库」这一个文件夹 |
| 成本 | 开启即用 | 功能说明标注适用于 Basic / Personal / Family 档 |

日常防随手翻用第一道；证件、合同、扫描件放第二道。两道同时开不冲突。

## 二、给应用加启动密码

1. 头像 → **设置** → **密码** → 打开**需要验证码**；
2. 输入 6 位数字，再输一遍确认；
3. 开启后可调三项：**更改代码**、**密码超时**（5 秒到 2 分钟不等，多久没动重新要码）、**使用指纹进行身份验证**。

超时设太短会频繁要码，按自己切换应用的频率调。

## 三、启用个人保管库

保管库是云端的受保护文件夹，**每台设备要单独设置一次**：

1. 在应用里找到**个人保管库**文件夹，点**开始**；
2. 核对账户邮箱 → 验证身份；
3. 选验证方法（比如短信），收到验证码填入；
4. 设一个 PIN，完成启用。

之后每次进门都要过一遍所选的验证方式，**3 分钟不动自动上锁**（可在设置里改时长）。放文件的办法：选中文件 → **移动到** → 个人保管库；安卓端还能直接扫描文档、拍照、录像存进保管库，不经过相机胶卷。

## 四、几个容易踩的边界

- **收不到验证码**：最常见原因是账户安全信息里没绑手机号，先到账户设置里补上；
- **回收站里的保管库文件默认不显示**，要在回收站里手动「显示个人保管库项目」才列出来；
- 个人账户删掉的文件在回收站保留 **30 天**，工作或学校账户是 **93 天**，回收站满了 3 天后就自动清最早的；
- 误改比误删更难救：个人账户可以在网页端取回同一文件**最近 25 个版本**的历史版本，重要合同平时就放保管库。

## 五、装好再设锁，顺序更顺

先把应用装上、账户登好，再回来设这两道锁，一气呵成。安装包的功能介绍与获取入口见 [SkyDriveapp 说明站](https://skydriveapp.gerw.hair/)；照片备份与空间管理的开法在[手机照片自动备份与腾地方.md](手机照片自动备份与腾地方.md)。
