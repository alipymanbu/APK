# PrinterShare 手机怎么连打印机打印：四条连接路一次讲清

> 本篇讲的是安卓手机通过 PrinterShare（中文名"趣打印"）连接打印机的几种方式：附近 WiFi、蓝牙、USB OTG、经电脑中转或远程，外加"列印成 PDF"这个兜底做法。手边是什么条件，就走哪条路。

## 附近 WiFi：最常用的一条路

手机和打印机连上同一个无线网络，打开应用选好要打的内容，点"选择打印机"→"WiFi 打印机"，应用会自动扫描并列出可用的机型。HP、Canon、Epson、Brother、Samsung 等主流品牌的网络打印机基本都能被扫到，选中后设好份数和纸型就能出纸。

扫不出来先别换软件，大概率是两台设备不在同一个网络，后面有一篇专门讲排查。

## 蓝牙：热敏机、标签机走这里

蓝牙机型要在系统设置里先配对（设置 → 蓝牙 → 配对打印机），然后回到应用里选"选择打印机"→"蓝牙"，从已配对列表里挑机型。小票打印机、面单标签机、便携移动打印机多走这条通道。

## USB OTG：没有网络也能打

机房、门店这类没有无线网络的环境，一根 OTG 线就能解决：手机通过 OTG 线连上打印机的 USB 口，应用会自动识别接入的设备。前提是手机支持 OTG 功能，线材也要能传数据（市面上一部分 OTG 线只能充电）。

## 经电脑中转 / 远程打印

电脑上安装同款客户端并共享打印机，手机在"附近的打印机"里就能看到它——适合打印机接在台式机上的场景。注册账号后还能跨网络远程打印，从外面把文件打回家里或办公室；注意远程能力需要接收端电脑保持在线，并且维持订阅。

## 暂时没有打印机：列印成 PDF

应用里的"列印成 PDF"相当于一个虚拟打印机，把内容先存成 PDF 文件留在手机里，之后随时交给任意打印机输出，也方便留档转发。

## 四条路怎么选

| 场景 | 建议走哪条 |
| --- | --- |
| 家里/办公室有 WiFi 打印机 | 附近 WiFi |
| 小票机、标签机 | 蓝牙（先配对） |
| 没有无线网络 | USB OTG 线 |
| 打印机接在电脑上 / 人不在现场 | 经电脑中转 / 远程 |
| 只是想留个文件 | 列印成 PDF |

更完整的连接方式说明与截图示例，见 [printershare 介绍站](https://printershare.boop.uno/)。
