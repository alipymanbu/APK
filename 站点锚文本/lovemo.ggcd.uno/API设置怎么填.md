# lovemo API 设置怎么填：模型、接口、密钥三件套

> 这篇讲 lovemo 的 API 设置：三项各填什么、为什么填完还是发不出消息、免费模型的接入思路。只需要应用内额度的话可以跳过本篇，先看 [对话额度与免费聊天.md](对话额度与免费聊天.md)。

---

## 一、为什么打开还不能聊

lovemo 的对话由大模型驱动，既没配接口也没用应用内额度时，第一句话是发不出去的。这是它和"开箱即聊"类应用最大的差别，也是几乎所有第三方教程都会先讲 API 设置的原因。

## 二、三项配置一次说清

微信登录后进入「我的」页面，打开「API 设置」，需要配套填写三项：

1. **模型**：选择或搜索你要用的模型名称；
2. **API URL**：模型服务商的接口地址；
3. **API Key**：服务商为你生成的密钥。

三项必须来自同一家服务，只换其中任何一项都会连不上。模型列表支持按名称搜索，找不到就先在模型选择页搜一下再选。

设置页还有「使用自有 API」的选项入口，以及优先消耗哪种额度的切换，填完发一句话测试即可确认连通。

## 三、填完还是发不出消息

按顺序排查：

- 三项是否配套来自同一家服务（最容易错的一条）；
- 密钥是否过期、服务商账户里是否还有用量；
- 额度消耗方式是否切到了自备接口一侧；
- 改完配置后先发一句短消息测试，别用长对话试。

## 四、免费模型的思路

不少教程给过一条零成本路线：去支持免费模型的服务商处生成密钥，把免费模型名称、接口地址、密钥三件套填进来。思路就是"用服务商的免费档位替换应用默认模型"，具体哪些模型在免费档、怎么生成密钥，以各服务商当前页面为准，这里不展开。
