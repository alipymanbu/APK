# 手机端连接中枢的完整流程

> 安卓手机第一次连接 Home Assistant 中枢该怎么走：配对、登录、命名，以及人在外面的远程连接。**相关文档**：[把手机传感器用进自动化.md](把手机传感器用进自动化.md) · [桌面小部件与快捷磁贴怎么用.md](桌面小部件与快捷磁贴怎么用.md) · [通知与位置不生效的排查思路.md](通知与位置不生效的排查思路.md)

## 一、先确认中枢已经就位

Home Assistant 是「中枢 + 手机端」的两半结构：中枢跑在 NAS、树莓派或虚拟机上，24 小时在线负责连接设备与执行规则；安卓手机端只是访问与控制的那一半。手机端需要中枢版本在 0.104.0 以上，手机系统 Android 6.0 起步。中枢还没搭好的话，先把那一半跑起来再回来。

## 二、同一 Wi-Fi 下的首次配对

1. 打开 App，它会自动搜索同一网络里的服务器，找到就点一下；
2. 同一网络里有多个实例时会把列表列出来，选你自己的那台；
3. 搜不到就点「手动输入地址」，填 `http://服务器IP:8123`（8123 是默认端口）；
4. 输入在中枢里创建的用户名密码登录 —— 建议每次都手动登录，别走受信任网络免密，否则离开那张网 App 就没有凭据可用；
5. 给这台手机起个名字。名字会进实体 ID，多台手机连同一中枢时全靠它区分，起个一眼认得出的。

登录成功后，App 里的面板和浏览器里看到的完全一致，后续在中枢上改了面板，手机端同步生效。

## 三、人在外面怎么连

出门在外想看家里的面板，远程连接必须走加密通道，App 对明文 HTTP 的远程地址是直接拒绝的。常见的三条路：

| 方式 | 说明 |
| --- | --- |
| 远程订阅服务 | 中枢自带的一键远程，最省事，费用用于支持开源开发 |
| 反向代理 + 证书 | 家里有公网 IP 时的经典做法，端口转发加一张受信任的证书 |
| 内网穿透 | 没有公网 IP 时的替代方案，流量要过一道路由 |

配好后在 App 的连接设置里把远程地址（External URL）填成 https 开头的加密地址即可。中途换了地址或证书，连接抖动期间通知下发也会跟着失败，先确认连接本身是稳的。

## 四、装好之后值得一调的几处

- 连接设置里有安全级别选择，绝大多数家用场景选「最安全」（只在家里的 Wi-Fi 允许非加密连接）；
- 多台服务器都登录了的，每个服务器的传感器与通知是分开管的，逐台确认；
- 换机或重装后，记得去中枢的集成面板把旧设备条目清掉再配对，否则人的状态判断会被一台永远不动的旧设备带偏。
