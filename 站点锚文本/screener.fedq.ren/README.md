# Screener 调屏手册 · 站点导航

这是围绕安卓调屏工具 Screener 整理的一组中文说明页的入口。Screener 借助 Shizuku 提供的系统级授权，让普通用户也能修改屏幕分辨率、DPI 像素密度与刷新率，并配有应用后 10 秒无操作自动撤销的保护机制。

本目录的几篇文章按「先懂原理 → 再动手 → 出事能救」的顺序排列：

- [安卓分辨率与DPI修改方法.md](安卓分辨率与DPI修改方法.md)——改参数的具体路径与节奏；
- [Shizuku无线调试配对与授权.md](Shizuku无线调试配对与授权.md)——一切动手之前的授权前置；
- [降低手机分辨率的利弊与恢复办法.md](降低手机分辨率的利弊与恢复办法.md)——动手前值得掂量一遍的收益与代价。

工具的功能介绍、界面实拍与安装文件资源获取入口，见 [Screener 调屏手册站点](https://screener.fedq.ren/)。
