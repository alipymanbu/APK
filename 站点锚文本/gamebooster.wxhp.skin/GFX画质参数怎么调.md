# GFX画质参数怎么调：分辨率、帧率、阴影逐项说清

> GFX 工具改的是游戏本地图形设置项——跟玩家手动进游戏设置里调是同一类东西，只是把常用参数集中到了一处。本篇逐项说清每个参数改了什么、什么时候降、降到哪一档。

## 一、先弄懂一件事：画质换流畅是基本盘

帧率的上限由处理器、GPU 和机身温度共同决定，任何工具都越不过硬件本身。所以调参数的思路不是「全开最强」，而是**把看不出来的效果降下来，把看得出来的流畅感保住**。

## 二、四个核心参数逐项过

| 参数 | 它影响什么 | 什么时候降 | 常见档位 |
| --- | --- | --- | --- |
| 分辨率 RES | 画面精细度、GPU 负载大头 | 低配机、发热明显时 | SD / HD / FHD / 2K |
| 帧率 FPS | 动作流畅度、负载随上限走 | 机型撑不住时锁稳一档 | 30 / 60 / 90 |
| 阴影 SHADOW | 光影真实感，吃算力 | 想快速减负先砍它 | 开 / 关 |
| 抗锯齿 AA | 边缘平滑度，费 GPU | 小屏幕上收益有限 | 关 / 2x / 4x |

优先级建议：**先降分辨率或砍阴影，再看帧率能不能锁稳一档**；抗锯齿在小尺寸屏幕上几乎看不出区别，可以放心关。

## 三、GameBooster 里的调法

在 GameBooster 的 DASHBOARD 里点 GFX TOOL 进入参数区，改完不用来回切换——直接从 DASHBOARD 点游戏启动就能验证效果，退出游戏后本次优化随之结束。哪些机型撑哪一档没有标准答案，建议从「分辨率降一档 + 阴影关」这个保守组合试起，稳定了再逐项往回加。

界面上这套入口怎么找到、上号前还要查什么，见 [GameBooster 介绍站](https://gamebooster.wxhp.skin/) 的 90 秒检查流程。

## 四、安全与边界

- GFX 调的是游戏已有的设置项，属于玩家可见、游戏允许范围内的调整；
- 竞技类游戏对第三方工具普遍更敏感，**只在游戏允许的范围内调整**，拿不准的项目宁可不碰；
- 网上流传的「解锁 HDR / 解锁超高帧率」类说法因机型和游戏版本而异，不要当成默认能力。

## 五、两个高频疑问

**「降到什么程度算合适？」**——盯着两个信号：帧率能不能长时间稳定在你锁的档位、机身热不热。帧率稳、温度可控，就是合适的位置。

**「为什么我调了没变化？」**——部分游戏的画质项要在游戏内的设置里才生效，GFX 的修改需要游戏配合读取；另外确认是从加速工具里启动的游戏，而不是从桌面图标直接进。
