# 手机画施工图的 CAD 软件怎么选

> 本篇把「在手机上画施工图」拆开讲：哪些活一部手机就能干、哪些仍要回电脑、选型时看哪几处，并以 Arcsite 这类现场型工具为例说明手机 CAD 的能力边界。

在工地上想用手机画图，最先要回答的不是「哪款软件好」，而是「你要画的是什么图」。图类不同，答案差很远。

## 一、先分清你要画的是哪类图

| 你要干的活 | 一部手机够不够 |
| --- | --- |
| 现场量一段尺寸、记一处改动、画个草图 | 够，而且比回车里开电脑快 |
| 在航拍图或 PDF 底图上描边、算面积算料 | 够，这类活本来就是移动工具的主场 |
| 给班组出一份带尺寸标注的小图 | 够，导出 PDF 即可 |
| 成套施工图的深化设计、几十个图层的图纸 | 不够，这类仍建议电脑上的桌面 CAD 主力 |

一句话：**改动、量取、记录、小图交给手机；成套深化交给电脑**。两边用 DXF / DWG 打通，谁也不耽误谁。

## 二、手机 CAD 的三种形态

应用市场里叫「CAD」的软件大致三类，选型前先对号：

1. **看图工具**：只开图不改图，适合翻图核对，画不了新东西；
2. **通用手机 CAD**：能力接近桌面软件的缩缩版，功能全，但小屏幕上画一条带精度的线并不轻松；
3. **现场一体化工具**：为工地场景设计，画图只是入口，后面接测量、算料、报价与导出。

如果你搜「手机画施工图」的真实动机是第三类——画完还要量、要算、要交给别人——那通用型 CAD 往往不是效率最高的那档。

## 三、选型看这四处

- **出尺寸的方式**：好的现场工具能让底图描出来的线自动带尺寸，前提是先做一次画布校准（找一段已知长度、拖线、输入真实值，两分钟的事）；
- **算料怎么算**：能不能边画边出材料数量，而不是画完再手动数；
- **交出去的格式**：至少要能导出 PDF 给人看、导出 DXF / DWG 给电脑上的 AutoCAD；
- **图纸放哪**：云端同步加历史版本，换手机不丢图，改坏了能回退。
