## 一句话背景

Arcsite 是把「画图 + 算料 + 报价」收进一个应用的现场工具，手指直接画、不要求 CAD 基础，边画边按自己的产品与利润率实时计价，支持 iOS、Android 与 Windows；产品方口径称已有超过 2100 万份图纸、算料单与提案经它产出。本目录三篇文章分别覆盖选型、现场工作流与导出交接三个环节。
