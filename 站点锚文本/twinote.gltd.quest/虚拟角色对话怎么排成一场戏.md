# 虚拟角色对话怎么排成一场戏

> 本篇讲怎么用社交时间线样式的备忘应用给自建角色排对话：立人设、写台词、用互动数字营造气氛，以及把成稿导出分享时的分寸。

## 一、为什么时间线适合排对话

写角色对话最常见的痛点是「看不出节奏」：文档里一大段对白，谁抢话、谁冷场、哪句炸了哪句没人接，读起来全靠脑补。

把对话放进社交时间线，这些问题当场消失。每条动态有头像、有名字、有时间，一人一句往下排，节奏一眼就能跟上——就像看一场已经分好镜的戏。给角色立一个人设档案，台词短、口语化，配合头像与昵称的区分，对话的「长相」就已经成立。

用 TwiNote 这类应用来排的好处在于：账号数量不限，每个账号都能配上自己的名字、头像和简介，角色之间还可以设定关注关系，让某位角色的主页上出现「关注了谁」。

## 二、排一场戏的四个动作

1. **先立人设，再开戏。** 给每个账号起名、配头像、写一句话简介。这三样决定了读者对角色的第一印象，值得多花两分钟。
2. **让台词短下来。** 一条动态就是一句台词。写长了就拆成两条——现实里没人一口气说完五句话。
3. **用互动数字当舞台效果。** 哪条台词「炸场了」，就把那条的点赞和转发数调上去；想让某句显得无人问津，留零就行。数字是布置出来的气氛，不是统计。
4. **顺着时间线回看，修剪节奏。** 排完从头往下刷一遍，哪句接得太密、哪段冷场太久，滚动着看比翻文档直观得多，随手改那条动态就行。

## 三、导出和分享的分寸

排好的场面可以整页或单条导出成图片，发出去就是一张现成的「剧情截图」。这类图和真实社交平台的画面几乎无法区分——粉丝数、点赞数都是你自己填的。

所以分享之前记住一条：让对方知道这是摆拍的虚构创作。拿它做表情包、剧情演绎、世界观展示都没问题；拿它冒充真实账号的言论去误导人，就跑偏了。
