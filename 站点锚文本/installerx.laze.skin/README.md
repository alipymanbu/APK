# InstallerX 介绍站 · 说明文章目录

InstallerX 是一款开源的安卓第三方安装器：用对话框、通知栏、自动三种方式接管系统装包流程，支持 APK、APKS、XAPK 等格式，配合 Shizuku / Dhizuku / ROOT 授权使用。本目录收录围绕它的使用说明文章，功能盘点与安装文件资源入口见 [InstallerX 介绍站](https://installerx.laze.skin/)。
