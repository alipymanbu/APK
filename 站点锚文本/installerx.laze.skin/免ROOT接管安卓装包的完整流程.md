# 免ROOT接管安卓装包的完整流程

> 本篇讲在没有 ROOT 的手机上，怎么让第三方安装器接管系统的装包流程：从拿到安装包、完成安装，到授权、锁定、试装验证，一步步走通；各步骤的细节坑位在本目录的另两篇文章里展开。
> **相关文档**：[Shizuku授权装包与锁定默认安装器.md](Shizuku授权装包与锁定默认安装器.md) · [XAPK分包容器一次装完的方法.md](XAPK分包容器一次装完的方法.md)

## 一、为什么装包要"接管"

不少定制系统把安装环节做得层层加卡：确认页带广告位、二次确认、倒计时跳转，装个包要盯着点好几下。InstallerX 的解法是直接换人——授权后由它接管系统的安装角色，之后点任何 APK，弹出来的都是它的安装界面，装什么、怎么装、装完干什么都按预设执行。

它带来最直观的变化：

| 方式 | 体验 | 适合 |
| --- | --- | --- |
| 对话框安装 | 弹出安装卡片，列明应用名、版本、包名，确认才装 | 想看清每个包再放行 |
| 通知栏安装 | 不弹窗，确认与进度都在通知里 | 不想被弹窗打断 |
| 自动安装 | 从通知发起后一路静默装完 | 批量装包、发起就走 |

## 二、装上 InstallerX 本身

1. 打开 [InstallerX 介绍站](https://installerx.laze.skin/)的安装文件资源入口，把分享资源转存到自己的网盘，再下载到手机存储；
2. 在文件管理器里点开 APK，首次会提示"安装未知应用"，按提示给文件管理器授权后重试；
3. 装完打开，同意首启说明页进入主界面——这时点别的 APK 走的还是老安装器，接着做授权。

## 三、无 ROOT 的授权路线

InstallerX 调安装接口需要特权，无 ROOT 机型主要靠 Shizuku：Android 11 及以上用"开发者选项 → 无线调试"配对激活，老系统用电脑 ADB 启动一次。激活后在 Shizuku 的"使用它的应用"列表里给 InstallerX 打开授权，再回 InstallerX 的设置里把授权器选为 Shizuku。逐步操作与配对失败的排查见 [Shizuku授权装包与锁定默认安装器.md](Shizuku授权装包与锁定默认安装器.md)。

## 四、锁定并验证

授权器就绪后，在 InstallerX 设置里点**锁定为默认安装器**（这步必须在选完授权器之后做，否则没有权限锁定），然后随手找个 APK 试装——弹出 InstallerX 的安装卡片即接管成功。

两件常见的事提前知道：

- 部分定制系统会在系统更新或重启后把默认安装器重置回去，表现是过几天点 APK 又回到老安装页，重新锁一次即可；
- 装分包容器（XAPK、APKS）不需要额外设置，它会按设备自动挑选分包，见 [XAPK分包容器一次装完的方法.md](XAPK分包容器一次装完的方法.md)。

## 五、装完后的顺手设置

- **安装后自动删除安装包**：经常装包的人勾上它，APK 用完即清；
- **允许版本降级**：想从新版回退旧版时必须开；
- **按场景建配置**：配置选项卡里可以建多套方案（比如一套静默、一套手动确认），每套单独指定授权器与安装方式。

功能与设置的完整盘点，都在 [InstallerX 介绍站](https://installerx.laze.skin/) 上有整理。
