# 安卓手机与电脑文件同步教程

> 手机拍的照片、截的图、收的文件，想在家里这几台设备之间自由流动又不想上传到任何云端？Syncthing 走的就是这条路：设备之间点对点直传，文件始终留在自己的硬盘上。本篇把配对到同步的完整流程走一遍。
> **同目录其它文章**：[安卓版下载安装与首次启动设置](安卓版下载安装与首次启动设置.md) · [与网盘有什么区别](与网盘有什么区别.md)

## 先把两台设备都装上

同步发生在两台都装了 Syncthing 的设备之间。手机装安卓端（获取入口见 [Syncthing 同步手册](https://syncthing.wrwq.fun/) 的安装页），电脑从 syncthing.net 的下载页取 Windows / macOS / Linux 版，启动后浏览器会打开 `127.0.0.1:8384` 管理页面；群晖、威联通这类 NAS 在套件中心加社区源也能装。

## 互添设备 ID 完成配对

Syncthing 不用注册账号。每台设备首次启动会生成一个唯一的设备 ID（七段大写字母数字，形如 `ABCDE12-FGHIJK3-…`）：

1. 手机端在「设备」页点「+」，扫描电脑端显示的二维码，或把电脑端的 ID 粘贴过来；
2. 电脑端 Web GUI 会弹出「新设备」提示，点确认——这一步就是「另一边也要加你」；
3. 两边设备名旁都出现绿色圆点，配对完成。

配对的安全逻辑也在这里：光知道设备 ID 建立不了连接，两边都手动添加对方才会生效。

## 建立第一个同步文件夹

以「手机相册备份到电脑」为例：

- 手机端（发送方）：「文件夹」页点「+」，路径选到相机目录，在「共享给设备」里勾选刚配对的电脑，保存；
- 电脑端（接收方）：Web GUI 弹出「文件夹共享请求」，点「添加」，把路径改成本地存放位置（如 `D:\照片备份`），也可以把类型改成「仅接收」做成单向备份；
- 等左下角进度走完、文件夹状态显示「最新」，之后手机上新拍的照片就会在联网时自动出现在电脑里。

安卓 11 及以上对公共目录的写入有收紧，整个 DCIM 根目录可能选不了，把要同步的内容放进 `Documents/`、`Download/` 这类允许的位置即可。

## 文件夹类型怎么选

| 类型 | 行为 | 典型用途 |
| --- | --- | --- |
| 发送和接收 | 双向同步，两边增删改都互传 | 资料夹、项目目录 |
| 仅发送 | 只往外推，接收端改动不回传 | 相册 → 电脑备份 |
| 仅接收 | 只收不发，本机改动不外传 | 电脑给手机推电子书 |

「仅发送 / 仅接收」还能防误删：接收端误删的文件，下次同步会被发送端推回来。

## 同步什么时候发生

两台设备同时在线时才互传。连同一个家庭 Wi-Fi 最稳；隔着互联网也能同步，速度上限是两边上行带宽。锁屏后不动、亮屏才动，是电池优化没关——设置方法见[安卓版下载安装与首次启动设置](安卓版下载安装与首次启动设置.md)。
