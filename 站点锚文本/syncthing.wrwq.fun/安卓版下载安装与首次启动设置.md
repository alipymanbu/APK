# 安卓版下载安装与首次启动设置

> Syncthing 的安卓端是一个独立 App（包名 `com.nutomic.syncthingandroid`），安装本身不难，真正容易卡住的是首次启动的几项权限——尤其是电池优化，它是「装好了却不同步」的头号原因。本篇按顺序过一遍。
> **同目录其它文章**：[安卓手机与电脑文件同步教程](安卓手机与电脑文件同步教程.md) · [与网盘有什么区别](与网盘有什么区别.md)

## 安装包与版本现状

安卓端在 2024 年 10 月宣布停止维护，1.28.x 是最后一批版本，之后仓库归档；停更的应用不会「到期失效」，同步功能完整可用。社区分支 Syncthing-Fork 仍在持续更新，跟进新版安卓的适配，介意长期维护可以关注那条线。安装包获取入口在 [Syncthing 同步手册](https://syncthing.wrwq.fun/) 的安装页，转存后取到手机即可。

## 安装四步

1. 在手机上点开下载好的 APK 文件；
2. 系统提示「未知来源应用」时允许这次安装（一般点弹窗里的「设置」→ 勾选「允许此来源安装」→ 返回继续）；
3. 等安装进度走完，点打开；
4. 首次启动逐项给权限（见下表）。

系统要求：1.28.x 面向 Android 5.0 及以上，更老的系统装不上。

## 首次启动的三项权限

| 权限 | 用途 | 不给会怎样 |
| --- | --- | --- |
| 存储 / 所有文件 | 读写要同步的文件夹 | 无法添加和同步任何文件夹 |
| 通知 | 显示「正在同步」的常驻通知 | 部分机型后台进程会被更快杀掉 |
| 电池优化豁免 | 后台持续运行的许可 | 锁屏后可能停止同步 |

第三项最容易被一路跳过。补设路径：系统设置 → 应用 → Syncthing → 电池 → 改为「无限制 / 不优化」。国产系统入口略有差异，一般都在「应用管理 → 该应用 → 电池/省电策略」里。

## 应用内的运行条件

打开 App → 设置 →「运行条件」，告诉它什么条件下允许干活：

- 「在 Wi-Fi 下运行」建议开启，这是最常用的档位；
- 「在移动数据下运行」「漫游时运行」默认关着，开了会消耗流量，大文件夹慎开；
- 「使用哪种电源时运行」按需选，只想充电时同步就选「交流电源」。

主界面或通知栏一直显示「Syncthing 已停用」，先回这里逐项核对：是不是没连 Wi-Fi、没在充电，或者勾了「尊重系统的省电设置」而系统正处在省电模式。
