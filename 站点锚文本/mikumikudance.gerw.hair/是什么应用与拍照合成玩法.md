# mikumikudance 是什么应用与拍照合成玩法

> 搜 mikumikudance 时，安卓端找到的往往是 MikuMikuPhoto——本篇讲清这份安装包装出来的是什么、能做什么、不能做什么。

## 一、名字与实装应用的关系

以 mikumikudance 为名流通的这份安卓安装包，包名是 `jp.pujo.mikumikuphoto`，装出来叫 MikuMikuPhoto，出自开发者 PujoHead Soft。它借的是 MMD 圈现成的数据生态：读取模型数据（`.pmd`）与姿势数据（`.vpd`），把 3D 角色叠加到照片上。

需要先说清的是：它**不是** PC 上那套 MikuMikuDance 动画软件的手机版，而是同好生态里的另一件独立作品。两者分工如下：

| | PC 版 MikuMikuDance | MikuMikuPhoto |
| --- | --- | --- |
| 平台 | Windows | Android |
| 产出 | 角色唱跳的动画视频 | 合成照片（静帧） |
| 数据 | 模型 + 动作数据 | 模型 + 姿势数据 |
| 操作 | 键鼠编排 | 触屏手势 |

想做跳舞动画视频，这款应用给不了；想在手机上和 3D 角色合影、出静帧图，它就是干这个的。

## 二、拍照合成的玩法脉络

1. 启动后选入口：现场取景（Launch Camera）或用相册照片当背景（View Photo），推荐后者；
2. 按 Photo 选背景照片，按 Character 载入角色，按 Pose 挑姿势；
3. 长按拖动平移角色，单指滑动旋转朝向，双指捏合缩放大小；
4. 快门成像，结果保存为照片。

快门之前还能在 Option 里调灯光颜色、阴影、五官表情、轮廓线与模糊效果——对照背景照片里的光源方向调灯光，合成痕迹会明显变小。

自带内容随版本不同：早期构建里是初音未来、镜音铃、镜音连三个模型加九款姿势；不够用可以自己导入配布数据，方法见 [MMD模型与姿势怎么导入.md](MMD模型与姿势怎么导入.md)。

## 三、版本与兼容的小事

- 这份安装包对应 1.0.14b，属于最初期构建，「用已有照片合成」的入口在其后的版本才加入，启动后若只有相机入口属版本原因；
- 应用是纯 Java 实现、不挑 64 位架构，新机型装得上，但相机走老接口，取景黑屏在个别新机型上无解；
- 它已不在 Google Play 上架，获取走安装包，步骤见 [安卓版下载与安装步骤.md](安卓版下载与安装步骤.md)。
