# MMD 模型与姿势怎么导入

> 自带的模型与姿势很有限，本篇讲怎么把 MMD 圈配布的 `.pmd` 模型与 `.vpd` 姿势放进手机，让应用认出来。

## 一、先分清文件与目录

应用从存储里一个固定结构的 `MikuMikuPhoto` 文件夹读取自定义数据：

```text
MikuMikuPhoto
├─Data
└─UserFile
   ├─Model    ← .pmd 模型放这里
   └─Pose     ← .vpd 姿势放这里
```

两个要点：

- 「SD Card」是老说法，对应现在手机的内置共享存储根目录——文件管理器打开后看到的顶层位置；找不到这个文件夹时，先启动一次应用再回来看；
- 这份 1.0.14b 属于早期构建，对 `.pmx` 扩展模型的支持存疑，稳妥起见优先用 `.pmd` 模型。

## 二、导入步骤

1. 手机连电脑（USB 选「文件传输 / MTP」），或直接在手机上用文件管理器操作；
2. 找到存储根目录下的 `MikuMikuPhoto` 文件夹；
3. 模型放进 `UserFile/Model`，姿势放进 `UserFile/Pose`；
4. 断开连接，**重启应用**——新文件要重启后才会被读到。

模型通常不是单个裸文件，还带着贴图等一串同目录文件，把「装着模型的那整个文件夹」原样拷进 `Model` 最稳妥，拆散了容易载入失败或显示异常。

## 三、放进去却不显示

按顺序排查：

1. 没重启应用——最常见的一条；
2. 放错层级——文件在 `MikuMikuPhoto` 根目录或 `Data` 下，没进 `UserFile` 对应子目录；
3. 格式不被这份早期构建支持——换 `.pmd` 模型再试；
4. 只拷了模型本体、丢了贴图——按整个文件夹的方式重新拷。

## 四、数据从哪来

MMD 圈的模型与姿势多在日语站配布：VPVP wiki 维护着模型与姿势数据的汇总页，BowlRoll 是常见的配布文件站，Niconico 上搜配布标签也能找到入口。拿之前过两层规约：角色受 Piapro Character License 约束，数据作者的要求看他包里的 `readme.txt`；不少配布包设了下载密码，通常藏在配布视频或配布图的说明文字里。

数据就位后，回到拍照合成的流程里选新角色新姿势即可，玩法见 [是什么应用与拍照合成玩法.md](是什么应用与拍照合成玩法.md)；还没装好的，先看 [安卓版下载与安装步骤.md](安卓版下载与安装步骤.md)。

渠道汇总与站内功能图文，也可以翻 [mikumikudance 安卓端介绍站](https://mikumikudance.gerw.hair/)。
