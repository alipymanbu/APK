# 连麦没声音怎么排查

> 按「没声音」的具体表现分情况排查：自己说出去没人听见、听不到对方、连麦断断续续，以及匹配雷达半天推不出人——多数问题不用重装就能解决。
> **相关文档**：[不露脸的交友软件怎么玩](不露脸的交友软件怎么玩.md)

---

## 一、先分清是哪一种「没声音」

语音社交里一半的挫败感来自「声音出问题」。表现不同，原因差得很远，先对号入座：

| 表现 | 大概率原因 |
| --- | --- |
| 你说话，别人听不见 | 麦克风权限没给、被房主禁麦、房内静音开着 |
| 你听不到别人 | 媒体音量太低、蓝牙耳机抢了音轨 |
| 声音断断续续 | 网络不稳、后台在抢带宽 |
| 雷达一直推不出人 | 资料太空、时段不对、定位没给 |

以 PicoPico 为例逐项过一遍，其他语音房的思路基本通用；玩法背景见 [PicoPico 声音社交站](https://picopico.fwen.ren/)。

## 二、说话没人听见：五步清单

按顺序做，做完一步试一步：

1. **系统设置里查权限**：手机设置 → 应用管理 → PicoPico → 权限，确认麦克风是「允许」。第一次连麦时弹窗点了拒绝，后面就一直哑着，全靠这里补开。
2. **关掉抢麦克风的设备**：游戏语音、通话录音、直播软件这些占着录音通道的先关掉；蓝牙耳机断开重连一次，确认声音走的是想要的设备。
3. **房内查音量条**：连麦界面看自己的音量条动不动，静音开关开着的先关掉。
4. **确认没被禁麦**：房主有权禁麦某个用户，被禁时自己这边一切正常、房间里却听不见，找房主解除。
5. **重启应用**：以上都对还不行，杀掉应用重新进房，多数疑难到这一步就通了。

## 三、听不见别人 / 声音卡顿

- **媒体音量**：连麦走的是媒体音量不是通话音量，按音量键时确认当前调的是「媒体」那一档；
- **换网络对比**：WiFi 与流量互换着试，哪边稳用哪边；WiFi 慢就离路由器近一点；
- **让后台让路**：下载、投屏、视频应用在后台抢带宽，先停掉再连麦；
- **换人少的房**：人数爆满的房连麦容易卡，换一个同主题的房体验立刻不同。

## 四、匹配雷达推不出人

这不是声音问题，但体验上同样是「没反应」，一并放在这里：

1. 把声线介绍、兴趣标签补具体，权重比头像高；
2. 避开凌晨等低在线时段，晚间推得快；
3. 检查定位权限是否给了，筛选条件别设得太苛刻——越严等得越久，这是取舍不是故障；
4. 以上都做了还是空转，多半是资料过于空白，先补齐再等推送。

声音出问题十有八九卡在权限这一步，先做完第二节第 1 条再考虑别的。App 还没装好的，安装步骤也整理在 [PicoPico 声音社交站](https://picopico.fwen.ren/)的下载页；想了解这类 App 都能玩什么，看[不露脸的交友软件怎么玩](不露脸的交友软件怎么玩.md)。
