# 手机连打印机的三种方式

> 本篇整理手机（安卓）连打印机打印时最常用的几种接法：各自适合什么场景、要满足什么前提，以及接法选不对时该换哪条路。
> **相关笔记**：[手机上打印照片和文档的流程](手机上打印照片和文档的流程.md) · [打印机搜不到的排查清单](打印机搜不到的排查清单.md)

---

## 一、WiFi 局域网：最常用的默认接法

手机与打印机连**同一路由器**，多数打印应用打开后会自动扫描列出可用的机型。

- 适合：家用、办公场景，打印机本身带 WiFi 模块；
- 前提：手机别用移动数据；访客网络常常隔离设备，尽量连主网络；
- 加分项：机身或包装上带 AirPrint、Mopria 标识的机型，接入会更顺。

## 二、蓝牙：便携打印机的专用通道

随身小票机、标签机、便携照片打印机多走蓝牙。

- 先在手机系统蓝牙设置里完成**配对**，再到打印应用里选用——应用内搜不到时，多半是系统层还没配对；
- 蓝牙适合小体积、近距离的打印任务，大文件传输速度不如局域网。

## 三、USB-OTG 直连：没有网络时的兜底

打印机没有 WiFi 模块、所处环境也没有可用网络时，一根几块钱的 OTG 转接头加打印机自带的 USB 线就能物理直连。

- 前提：手机支持 OTG（随便插个 U 盘能识别就是支持）；
- 关键一步：插线后手机会弹「允许应用访问 USB 设备」，不点允许后面全白搭；
- 一个坑：部分充电线不带数据芯，外观完全一样但传不了数据——插上没反应先换线。

## 四、打印机插在电脑上：共享出来再连

打印机挂在电脑上、自己不能联网时，在电脑系统里把打印机设为共享，手机与电脑连同一网络后从局域网连（Windows 共享走 SMB/CIFS，Mac/Linux 走 Bonjour/IPP/LPD）。

## 五、怎么选

| 场景 | 优先选 |
| --- | --- |
| 家里 / 办公室，打印机带 WiFi | WiFi 局域网 |
| 便携小票机、标签机 | 蓝牙 |
| 没网络、老打印机 | USB-OTG 直连 |
| 打印机只有 USB 口且插在电脑上 | 电脑共享 |

这些接法在移动打印应用里通常一屏切换。以安卓上常见的 NokoPrint 为例，它在[它的介绍页](https://nokoprint.fedq.quest/)里对惠普、佳能、爱普生、兄弟等主流品牌系列与三种连接方式都有对照说明，接法选型可以参考。

搜不到打印机时先别换接法，多数出在几条高频原因上，按[打印机搜不到的排查清单](打印机搜不到的排查清单.md)过一遍更快；连上之后的选文件、设参数见[手机上打印照片和文档的流程](手机上打印照片和文档的流程.md)。
