# 手机上打印照片和文档的流程

> 本篇讲从装好应用到出纸的完整流程：选什么应用、怎么连上打印机、照片和文档分别从哪里选、打印参数哪些项值得动。
> **相关笔记**：[手机连打印机的三种方式](手机连打印机的三种方式.md) · [打印机搜不到的排查清单](打印机搜不到的排查清单.md)

---

## 一、先备好两样东西

1. **一台安卓手机或平板**，装一个移动打印应用（这类应用不少，功能大同小异；以 NokoPrint 为例，它的[介绍页](https://nokoprint.fedq.quest/)里有功能与连接方式的完整说明）；
2. **一台连得上的打印机**——接法选型见[手机连打印机的三种方式](手机连打印机的三种方式.md)。

## 二、标准流程：四步

1. 打开打印应用，等它扫描并列出打印机；
2. 选中自己的打印机（列表里会标 WiFi / 蓝牙 / USB 的连接类型）；
3. 选要打的内容：相册里的照片、手机存储里的 PDF 与 Office 文档、邮件附件、云端文件，或直接用内置浏览器打开网页打；
4. 调参数、看预览、按打印。

## 三、照片打印的两个实用设置

- **多图合一页**：选多张照片后设置每页张数，打证件照排版时省纸；
- **无边距**：想要照片打满整张纸不留白边，打开「无边距」并配光面或哑光照片纸；普通 A4 纸上开无边距容易在边缘溢墨。

## 四、文档打印最常动的三个参数

| 参数 | 什么时候动 |
| --- | --- |
| 页面范围 | 长文档只要其中几页（比如只打第 3~5 页） |
| 彩色 / 黑白 | 纯文字页关掉彩色，省墨又快 |
| 双面 | 页数多的材料选双面，纸质减半 |

打之前先看预览：页边距、裁切对不对在预览里就能发现，别直接浪费纸。

## 五、两条能少踩坑的经验

1. **先打 1 页测试再批量**：尤其换了纸张尺寸或质量档位之后；
2. **微信里的文件不用传电脑**：长按文件 → 分享 → 选打印应用，直接进打印流程——这类应用普遍接入了系统的「分享」与「打印」菜单。

列表里找不到自己的打印机时，按[打印机搜不到的排查清单](打印机搜不到的排查清单.md)逐条排查；接法本身拿不准的，回[手机连打印机的三种方式](手机连打印机的三种方式.md)对号入座。
