# 打印机搜不到的排查清单

> 本篇专治「打印应用打开后，打印机列表是空的」：六条高频原因快查，再补手动按 IP 添加与换接法两条兜底路。
> **相关笔记**：[手机连打印机的三种方式](手机连打印机的三种方式.md) · [手机上打印照片和文档的流程](手机上打印照片和文档的流程.md)

---

## 一、六条高频原因，按顺序过

| 序号 | 检查什么 | 怎么处理 |
| --- | --- | --- |
| 1 | 手机在用移动数据 | 切到打印机连的那个 WiFi；USB 直连的不受此条影响 |
| 2 | 打印机连在访客网络 / 另一个路由器 | 手机与打印机必须同一路由器下的同一网络，访客网络通常隔离设备 |
| 3 | 位置 / 附近设备权限没给 | 系统「应用详情 → 权限」里打开后，把打印应用完全关掉重开 |
| 4 | 打印机在休眠 | 按一下机身任意键唤醒，部分机型休眠时不响应搜索 |
| 5 | 打印机自己没连上网 | 在打印机面板看 WiFi 标志或网络状态，显示离线先重连打印机的网络 |
| 6 | 偶发扫描失败 | 打印机、路由器各重启一次，再重新打开应用搜 |

安卓系统对局域网设备扫描有统一的权限要求，第 3 条是「列表一直为空」最常见的原因——权限给了还不行，一定是完全关闭应用重开，切后台不算。

## 二、扫不出来：手动按 IP 添加

打印机其实在网上、只是扫不出来时，绕过自动搜索直接按 IP 添加：

1. **拿打印机的局域网 IP**：打印机面板进「设置 → 网络 / 无线」看显示的地址（形如 `192.168.1.x`）；或登录路由器管理页，在已连接设备列表里找；
2. 在打印应用里选「手动添加 / 按 IP 添加」，把地址填进去；
3. 添加成功后会留在列表里，之后直接选用。

填了还是连不上 → 路由器多半重新分配过地址，重查一次再填；也可以在路由器里给打印机绑固定地址，一劳永逸。

## 三、换一条接法兜底

WiFi 这条路实在不通，不必死磕：

- 打印机有 USB 口 → 一根 OTG 转接头直连手机，没网络的环境最稳；
- 打印机插在电脑上 → 电脑开打印机共享，手机从局域网连；
- 便携机型 → 蓝牙先配对再回应用里找。

接法怎么选、各自要什么前提，见[手机连打印机的三种方式](手机连打印机的三种方式.md)。安卓上以 NokoPrint 这类移动打印应用为例，四种接法在应用里一屏切换，具体界面与功能说明可以看[它的介绍页](https://nokoprint.fedq.quest/)。

连上之后的选文件、调参数流程见[手机上打印照片和文档的流程](手机上打印照片和文档的流程.md)。
