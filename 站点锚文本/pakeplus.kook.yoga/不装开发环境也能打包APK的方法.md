# 不装开发环境也能打包APK的方法

> 给"没配过开发环境、也不打算装一整套 SDK"的读者：本篇讲云端编译与本地打包两条路线各要什么、各限制什么，按你的情况直接选一条。
> **相关文档**：[把网址打包成手机APP的完整流程.md](把网址打包成手机APP的完整流程.md) · [安卓安装被拦与APP打不开怎么办.md](安卓安装被拦与APP打不开怎么办.md)

---

## 为什么可以什么都不装

PakePlus 把最重的编译环节搬离了你的电脑：桌面客户端本身只有约 10M，配有 Windows、macOS、Linux 版本和网页版。你只负责填来源、选路线、取结果，构建过程要么在 GitHub 的服务器上跑，要么由本机一条精简流程完成。

## 两条路线逐项对比

| 对比项 | 云端打包 | 本地打包 |
| --- | --- | --- |
| 账号要求 | 需要 GitHub 账号和 Token | 不需要任何账号 |
| 耗时 | 几分钟（含平台排队） | 项目文档标注约 30 秒 |
| 文件限制 | 单个文件建议不超过 10M（受 GitHub 限制） | 不限制文件数量和大小 |
| 多平台 | 一键同时编译安卓、iOS 与三大桌面端 | 以客户端当时提供的选项为准 |
| 出错排查 | 发布页与客户端右上角看提示 | 客户端内直接看提示 |
| 产物存放 | 挂在发布页，换设备也能取 | 保存在本机 |

## 走云端：Token 怎么准备

Token 是云端路线唯一的准备工作。按开发者给的指引，在 GitHub 的设置页生成：

- **beta 版本**需要勾选：派生原始模板仓库（All repositories）、管理 Actions、仓库与文件管理（Administration）、内容增删改查（Contents）、提交问题（Issues）。
- **经典（classic）版本**需要勾选：repo 与 workflow 两项权限。

生成后把 Token 填进客户端即可。安全性方面，Token 只保存在你本机，不上传到任何别的服务器；项目文件也都在你自己的 Git 仓库里。

## 按情况选

- 手机上现打现用、从没配过 GitHub：走本地，整个 Token 环节都省掉。
- 想同时拿到安卓、iOS 和桌面三份安装包：走云端，一次操作多端出包。
- 项目里有超过 10M 的大文件（本地视频、大图）：云端会被单文件限制卡住，走本地更省事。

工具的获取入口与安装步骤整理在 [PakePlus 介绍站](https://pakeplus.kook.yoga/)；装好之后从网址到 APK 的完整过程，见 [把网址打包成手机APP的完整流程.md](把网址打包成手机APP的完整流程.md)。
