# Lemuroid 支持哪些主机与游戏格式

> 本篇列 Lemuroid 能模拟的主机、每档主机的性能要求，以及游戏文件用什么格式、怎么整理才容易被扫描认出。

Lemuroid 建立在 Libretro 模拟内核生态上，一个应用整合了二十多类经典主机；游戏文件需要自己提供。装之前先对照这份清单确认自己的游戏在不在支持范围、手机性能够不够，再按格式要求整理文件。每档主机的实际画面与手感，可以到 [Lemuroid 复古模拟器介绍站](https://lemuroid.djnf.quest/) 看界面截图参考。

按厂商分组（以本地记录的 1.16.2 版本为准，新版本可能增补）：

性能上按四档预估：

- **老设备也基本满速**：8 / 16 位机（NES、SNES、GB 系、世嘉系、雅达利、Neo Geo Pocket、WonderSwan、PC Engine）；
- **近十年中端机无压力**：N64、PSX、FBNeo 街机；
- **建议性能较好的机型**：PSP、Nintendo DS——弱机先关掉 HD 高分辨率渲染与屏幕仿真；
- **旗舰机再尝试**：Nintendo 3DS。

## 二、游戏文件的格式要求

1. **压缩包只认 zip，一包一个游戏**：rar、7z 不支持；一个 zip 里塞多个文件会被跳过。不压缩直接放原始文件最容易过。
2. **文件名贴近游戏原名**：扫描靠内置数据库匹配（CRC、序列号、文件名都参与），改成自创的简称可能认不出来。
3. **PSX 多碟游戏配 m3u 列表**：建一个 `.m3u` 文本文件，每行写一张碟的文件名，与碟文件放同一目录。
4. **FBNeo 街机用非整合（non-merged）romset**，文件要与数据库 CRC 一致。
5. **按主机分文件夹**（`gba/`、`psx/`、`snes/` 各一个目录）是识别率最高的整理方式。

还有一条例外：**Sega CD 需要额外的固件（BIOS）文件**才能运行，其它主机基本放好游戏就能玩；PSX 个别游戏备一份固件兼容性更稳，固件请从自己合法拥有的主机上提取。
