# Bilby 安卓版下载安装步骤

> 本篇讲怎么把这款第三方 B 站客户端装到安卓手机上：转存、下载 APK、允许未知来源、扫码登录，一次说清。装完想先了解界面逻辑，看[订阅动态首页怎么用](订阅动态首页怎么用.md)。

## 装之前先知道的三件事

1. 它是一个第三方开发的 B 站客户端，聚焦看视频、追动态这两个核心场景：首页只放已关注 UP 主的更新动态，没有算法推荐流，也没有商城、直播这类板块（以 0.11.1 版本的实际界面为准）。
2. 登录靠扫码：打开应用会出现二维码，用手机上的哔哩哔哩客户端扫一扫、确认即可，全程不需要输账号密码。
3. 它只有安卓版，安装包只有 7.45M，中低端机型也能装能跑；iPhone / iPad 上没有对应版本。

## 安装步骤

1. **转存安装包**：打开 [Bilby 安卓客户端介绍站](https://bilby.fewz.tech/) 下载页给出的网盘分享地址，把资源转存到自己的夸克网盘。
2. **下载 APK 到手机**：在自己的网盘里找到 APK 文件，下载到手机存储。
3. **允许安装未知来源**：在手机上点开 APK，系统首次会提示「不允许安装未知来源应用」，按提示给文件管理器或浏览器开启「安装未知应用」权限，再返回继续。
4. **完成安装并扫码登录**：等安装完成、点打开，第一屏就是登录二维码，用哔哩哔哩客户端扫一扫确认即可。

## 常见安装问题

**点了 APK 提示「禁止安装」？**
这是安卓的未知来源限制，不是安装包坏了。按弹窗进设置，给下载 APK 用的那个应用勾选「允许安装未知应用」，返回重装即可。

**和已装的哔哩哔哩客户端冲突吗？**
不冲突。两者是不同的应用，通常可以在同一台手机上并存、互不覆盖；日常搭配是刷动态看视频用它，投稿、直播、充值切回原来的客户端。

**装完首页是空的？**
先扫码登录；登录后仍为空说明还没关注任何 UP 主，搜几个常看的进主页点关注，动态就会出现（见[订阅动态首页怎么用](订阅动态首页怎么用.md)）。锁屏听音频总被打断的排查思路，整理在[后台播放与保活设置](后台播放与保活设置.md)。
