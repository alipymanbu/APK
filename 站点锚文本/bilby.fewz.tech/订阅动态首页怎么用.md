# Bilby 订阅动态首页怎么用

> 这款第三方 B 站客户端的首页没有推荐流，只放已关注 UP 主的更新。本篇讲它的首页逻辑、搜索技巧和稍后再看的入口。还没装好的先看[安卓版下载安装步骤](安卓版下载安装步骤.md)。

## 首页只看你关注的人

首页展示的是**已关注 UP 主的更新动态**——你关注了谁，首页就出现谁的更新，下拉刷新拉最新。这和「打开就是推荐」的使用习惯完全不同，刚上手记住两点：

- 别在首页找热门推荐：这里没有推荐流，想看什么要么翻动态、要么直接搜；
- 首页空了先查关注列表：刚登录时为空，是因为你还没关注人，搜几个常看的 UP 主进主页点关注即可。

## 搜索的几个实用点

点底部放大镜打开搜索框：

1. **模糊关键词也能搜**：不用输完整标题，记得什么输什么；
2. **结果区分合集与单个视频**：找连续剧、系列教程时不容易点错；
3. **支持排序筛选**：按不同维度缩小范围，比逐个翻快；
4. **搜人再关注**：直接搜 UP 主名字进主页点关注，这是给首页「喂」内容的主要方式。

## 稍后再看与播放页

- 刷动态遇到想看但当下没空的，从条目菜单选「加入稍后再看」，之后统一看；
- 播放页里可以发弹幕、投币，0.11.1 起长按点赞触发一键三连，收藏进账号的默认收藏夹；
- 视频简介在 0.11.1 改成了底部面板，完整标题、简介与标签都在里面，不挤占播放画面；
- 评论里形如 `12:34` 的时间点可以点击直接跳转，自己写时间点时用半角冒号更稳。

## 涉及花钱和创作的事

充值 B 币、管理大会员、看直播、投稿这些需求，在 0.11.1 的界面上没有对应入口，要切回哔哩哔哩客户端或网页端完成。账号是同一个，操作都落在你的账号上——常见的搭配就是：刷动态、看视频、发弹幕用它，消费与创作切回去。
