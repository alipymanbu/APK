# EZView 告警推送收不到的原因与解决

> 本篇讲 EZView 的告警推送链路断在哪一环最常见，以及「收到的推送比告警少」时怎么对账。
> **相关阅读**：[设备添加与连接失败排查](设备添加与连接失败排查.md) · [安卓版下载与安装步骤](安卓版下载与安装步骤.md)

## 一、推送是一条链，三处都要通

从设备到手机通知栏，断任何一环都收不到：

1. **App 内按设备开启**：菜单 > 告警通知（Alarm Notifications）> 允许通知，勾选要接收告警的设备；新版可以把配置同步到云端，换手机不用重设。
2. **手机系统层放行**：系统设置里 EZView 的通知权限必须开着——系统层被关，App 内开一百次也没用。
3. **别让系统杀后台**：不少安卓系统的省电策略会在后台杀进程，在系统设置里允许它后台运行或自启动；iPhone 检查「专注模式 / 勿扰模式」；装了手机管家的确认没被拦。

## 二、一条硬性范围，先知道少走弯路

只有**云端设备**和**免注册添加**的设备支持推送到手机通知栏；用 IP/域名等方式直连的**本地设备不推送**——它不是收不到告警，告警页里照样有记录，只是不会弹窗。要弹窗，就把设备绑到云账号上。

## 三、「收到的推送比告警少」的三种解释

| 现象 | 原因 |
| --- | --- |
| App 内告警数 > 手机收到的推送数 | App 列表统计所有设备的事件；弹窗只推云端与免注册设备 |
| 告警通知页的设备 < 设备列表的设备 | 从未联网上线的云设备不出现在告警页 |
| 提示「无法为更多低版本设备开启告警通知」 | 低版本设备 + 本地设备的推送上限共 64 台；升级固件或关掉不重要设备的推送 |

## 四、让告警更好用的三个设置

- **联动查看**：点开一条告警可直接跳到关联的实况画面、告警录像和截图（部分告警类型不支持，以设备为准）；
- **筛选与值守**：按设备、类型、时间筛选，支持确认处理——多人值守时用「确认」标记谁处理过；
- **细分规则**：高级设置里按通道、时间段、告警类型配置推送，比如只推夜里的移动侦测。

另一头别忘了：**侦测规则决定什么时候产生告警**。推送链路通了却一条都不来，多半是设备端的移动侦测 / 人体检测 / 录像计划没配——远程配置属于依赖新协议（Protocol 3）的功能，老设备先在设备编辑页把流媒体协议切到 Protocol 3 再改。
