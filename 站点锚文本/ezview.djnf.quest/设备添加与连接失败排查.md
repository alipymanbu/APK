# EZView 设备添加与连接失败排查

> 本篇讲把宇视摄像头、录像机加进 EZView 的几种方式，以及「绑不上」「突然掉线」两类故障的排查顺序。
> **相关阅读**：[安卓版下载与安装步骤](安卓版下载与安装步骤.md) · [告警推送收不到的原因与解决](告警推送收不到的原因与解决.md)

## 一、五种添加方式，选合适的那个

App 里点菜单 > 设备 > 添加，会看到这些选项：

| 方式 | 操作 | 适用场景 |
| --- | --- | --- |
| 扫码 | 扫设备二维码 | 最常用；机身贴纸没码就进设备系统取（IPC/NVR 在 `Setup > Network > EZCloud` 页面） |
| 自动搜索 | App 自动发现同网段设备 | 手机和设备连同一个路由器的 Wi-Fi 时最快 |
| IP/域名 | 手填设备地址直连 | 设备没绑云，但知道它的局域网或公网地址 |
| EZDDNS | 填设备注册的动态域名 | 设备在外网、宽带是动态 IP |
| 云端同步 | 无需操作 | 换手机或重装后，登录同一云账号，设备自动出现 |

两条路线心里要有数：**云账号绑定**（远程实况、推送、共享都在线）和**免注册添加**（需设备端开启 P2P 开关，局域网看就够用）。两条路随时可以补齐，互不冲突。

## 二、绑不上：按顺序查四样

扫码或添加报错时，依次确认：

1. **设备联网了吗**——有线接到路由器或配好 Wi-Fi，设备端 EZCloud 状态在线才绑得上；
2. **二维码找对了吗**——机身贴纸没有就进设备 Web 管理界面取；
3. **刚上云等了吗**——新设备平台侧上线要一会儿，建议等 2 分钟再试，列表下拉刷新；
4. **被别的账号绑了吗**——一台设备只能绑一个账号，提示「设备已被其他账号添加」时先解绑再绑，买二手设备的人经常卡在这里（安全设计，绕不过去）。

## 三、突然掉线：查设备端链路

之前好好的，突然连不上：

- 设备端 EZCloud 显示「未添加到云平台」→ 重新扫码绑一次；
- 显示「设备不可达 / 网络断开」→ 查物理链路：网线、路由器端口、DHCP 是否开启、设备 IP 是否与路由器同网段（NVR 上可用 `菜单 > 维护 > 网络检测` 分别 ping 网关和公网地址定位断点）；
- DHCP 正常仍离线 → 检查 PPPoE 拨号是否误开、默认路由指向、DNS 可先填路由器地址；最后在路由器上为设备做端口映射。

排查仍无解时，设备端问题占多数，App 这边能做的只有换网络环境重试。

## 四、画面卡顿与播放报错的快速处理

- **看一会儿自动停**：进 `Me > General` 关掉「自动暂停视频」（省流量开关，挂机盯画面的人要关）；
- **进度条卡住后报错**：设备编辑页把流媒体协议在 Protocol 2 / 3 之间对调，保存后完全退出 App 重开；仍不行把设备端 MTU 改成 576；
- **高清画质转圈**：先切流畅档——高清码流对上行带宽要求高，带宽不够设备端出不去画面。

设备都绑好、连稳之后，让设备主动通知你是下一件事：见[告警推送收不到的原因与解决](告警推送收不到的原因与解决.md)；还没装应用的从[安卓版下载与安装步骤](安卓版下载与安装步骤.md)开始。功能总览与界面展示见 [EZView 介绍站](https://ezview.djnf.quest/)。
