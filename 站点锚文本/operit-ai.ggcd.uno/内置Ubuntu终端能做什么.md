# 内置 Ubuntu 终端能做什么

在安卓手机上跑 Linux 命令，过去要靠 Termux 这类终端模拟器自己搭环境；而 Operit AI 把这件事做成了开箱即用的内置能力——通过 chroot 方案装入完整的 Ubuntu 24 用户空间。本文整理这套环境能做的事，以及使用时需要注意的边界。

## 一套完整用户空间，不是一个玩具终端

Operit AI 内置的 Ubuntu 24 与宿主系统共享内核，但拥有独立的用户空间，相当于在手机里装了一个完整的 Linux 环境：

- **apt 直接装包**：软件源里的工具按需安装，不用自己找编译链；
- **开发工具开箱可用**：Python、Node.js、vim、SSH 等常用工具拿来就用；
- **脚本与长任务**：批处理脚本、定时同步这类任务可以在手机上挂机跑；
- **与 AI 联动**：终端不只是手敲——Operit AI 能在对话里直接调度命令、读取执行结果，把"说需求"变成"跑命令"。

配合 Shizuku 等系统权限，它还能做到接近系统层的操作，比如应用权限管理、屏幕自动化等，这也是它区别于普通聊天助手的地方。

## 一个真实的用法切片

比如想把相册里某个目录按月归档压缩，传统流程是：装应用 → 学操作 → 手动归类。在这套环境里，一句自然语言加上一条 `zip` 命令的组合就能完成；再比如跑一个 Python 数据整理脚本，apt 装 pip、拉依赖、执行，全程不需要切换应用。

工具箱里还预置了格式转换、文件管理、命令终端入口等常用件，轻量需求不必进终端就能完成。

## 边界与注意事项

能力越强，越要想清楚边界：

- chroot 方案与宿主共享内核，**没有真正的隔离**，装什么、跑什么，建议自己心里有数；
- 系统级权限逐项授予，用不到的先不开；
- 大体积应用（安装包约 386MB）与编译任务对存储和电量都有消耗，量力而行。
