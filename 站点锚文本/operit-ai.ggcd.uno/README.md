# Operit AI 资料汇总

这里是 Operit AI 的介绍与使用资料合集。Operit AI 是一款运行在安卓设备上的开源 AI 智能体：它不只停留在对话，还能调用内置工具、跑终端命令、执行自动化操作，并支持本地模型离线推理。本目录的文章围绕它最常见的几个关注点整理而成。

想直接浏览图文版介绍与安装文件资源入口，可前往 [Operit AI 介绍站](https://operit-ai.ggcd.uno/)。
