# Foscam 摄像头连接手机配网教程

新摄像头开机后怎么绑进 foscam App：先把准备工作做足，配网成功率能高一大截。

## 配网前的四件事

1. 摄像头通电，等它完成开机自检——带语音提示的机型会播报准备进行无线配置，网络指示灯绿灯快闪。
2. 手机装好 App 并登录 Foscam 账号，还没装的先看 [foscam 安卓 App 怎么下载安装](foscam安卓App怎么下载安装.md)。
3. 找到摄像头底部（部分机型在侧面）的标签，上面有二维码和 UID，配网全程要用。
4. 二手或之前配过的摄像头，先长按 Reset 键 12~15 秒恢复出厂再重新添加。

## 三种联网方式怎么选

| 方式 | 适用 | 要点 |
| --- | --- | --- |
| 有线 | 首选，最稳 | 网线接路由器，配置成功后再拔线改 WiFi |
| WiFi（Ezlink 2.0） | 不想拉网线 | 手机输路由器 WiFi 密码，App 生成二维码给镜头扫 |
| WPS | 路由器带 WPS 键 | 先按摄像头 WPS 键 2 秒，60 秒内按路由器 WPS 键 |

## 扫码配网分步

1. App 首页「我的摄像机」页面点「+」添加新设备。
2. 用手机扫机身标签上的二维码，UID 自动填入；标签模糊就走手动添加，逐位输入 UID。
3. WiFi 方式：输入路由器 WiFi 密码，App 生成动态二维码，**屏幕对准镜头 15 厘米以内**、亮度调高。
4. 摄像头先报 "WiFi connecting"，再报 "Wireless connection succeeded"，设备自动进列表。
5. 首次添加会要求重设摄像头的用户名和密码（出厂默认 admin / 空密码），设完记牢。

## 配网失败的高频原因

- **手机没连 2.4GHz**：双频路由器下配网必须用 2.4GHz 频段，多数机型不支持 5GHz 配网；新路由器「双频合一」的，先到后台把两个频段分成两个名字。
- **密码带特殊字符**：含 `^ & * $ % #` 或中文的密码部分机型认不了，先临时改成纯字母数字。
- **距离与断电**：手机离路由器 3 米以内，配网全程别给摄像头断电。

哪一步都试过还是不行，或者后来换了路由器要重新配网，结合 [监控画面远程查看与报警设置](监控画面远程查看与报警设置.md) 里的远程排查一起看；站点版的功能对照与界面预览在 [foscam 远程看家站](https://foscam.wxhp.skin/)。
