# 搜不到结果与连接失败的处理

> 打开后一直转圈，或者能搜但永远是 0 结果——多数不是软件坏了。本篇按现象分情况给排查顺序，从网络环境到关键词逐层排除。

## 一、先分清是哪种「不行」

| 现象 | 更可能是 | 去看 |
| --- | --- | --- |
| 刚打开一直转圈，连不上 | 连接需要时间，或网络环境受限 | 第二节 |
| 能搜，但结果永远为空 | 关键词或资源本身的问题 | 第三节 |
| 以前能用，最近突然不行 | 运营商限制或网络波动 | 第二、三节 |

## 二、连接不上：先等，再换网络

1. 打开后不要立刻搜，等它完成连接再开始，等一两分钟很常见；
2. 确认手机本身能正常上网（随手开个网页试试）；
3. 在 Wi-Fi 和移动数据之间切换一次再试——部分运营商会限制电驴网络的服务器与连接协议，不同网络限制程度不一样；
4. 换个时间段再开，P2P 网络的可用性本身随时间波动；
5. 以上都试过仍不行，卸载后装回新版本再试——旧版本的连接信息失效后怎么等都连不上。

版本问题导致的连接失败，换新包是最省事的一步；安装文件资源的获取入口与安装步骤，见 [p2psearcher](https://p2psearcher.gltd.quest/) 介绍站的下载页。

## 三、搜不到结果：从关键词下手

- 把长句换成短词：搜「某电影 2019 高清完整版」不如直接搜「某电影 2019」；
- 换同义词再试：中英文名互换、全称与缩写互换；
- 冷门资源搜不到不算故障——电驴网络里没人共享过的东西，任何搜索工具都搜不出来；
- 关键词没问题但条条都是 0 结果，回到第二节的网络排查，尤其是 Wi-Fi 与移动数据的切换。

关键词的具体写法与结果挑选，见[电驴磁力资源搜索入门](电驴磁力资源搜索入门.md)。

## 四、搜到了，但下载没速度

这多半是资源冷门、当下没人共享，换下载工具也没用：

- 热门影视剧、常用软件一般速度不差；
- 任务长时间停在「资源连接中」时，重启下载工具、切换网络、或重新复制一次完整链接再添加；
- 对没速度的任务，先挂网盘离线，过几小时回来取，比反复重开任务省心。

磁力与电驴两种链接在速度上的差别，另见[磁力链接和电驴链接怎么选](磁力链接和电驴链接怎么选.md)。

## 五、还想再确认一步

在另一台手机上装同一份包试一次，能区分是软件问题还是这台手机的网络问题。若只是想先确认内容对不对，走云播预览比直接下载更省时间，用法见[云播预览用法与通道切换](云播预览用法与通道切换.md)。
