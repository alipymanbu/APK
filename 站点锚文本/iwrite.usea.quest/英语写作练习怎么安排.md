# 英语写作练习怎么安排：班级作业与自主练习两条线

> 写作课要求交作业，自己又想额外刷题，两边记录会不会混？在 iWrite（爱写作）里这是两条独立的线：班级作业跟着课程走，自主练习自己安排，各记各的、互不干扰。本篇讲两条线分别怎么用、什么情况走哪条。

## 班级作业这条线

进班靠老师给的**班级授权码**：老师在系统里建班后把码发下来（常在课程通知或班级群里），学生在「我的班级」里输入加入。进班后「我的作业」会出现老师布置的题目，题型就两类：

- **日常写作**：读题 → 写作 → 提交，题目页写明时限、字数、总分；
- **续写任务**：先读原文材料，再做阅读理解，最后接着往下写——中间那一环别跳过，续写的衔接点常藏在阅读理解里。

作业通常带同伴互评：截止后系统在班级内随机一对一分配。想参与互评就按时交，逾期提交不进自动分配名单；交早了也不用担心，互评取的是截止前最新一版。

## 自主练习这条线

不需要班级、不需要授权码，谁都能练：

| 路径 | 适合场景 |
| --- | --- |
| 题库写作 | 备考四六级、考研、专四专八、托福、雅思时挑同类型题练，评分尺度更接近真考 |
| 自由写作 | 有想写的话题但没有对应题目时随手写，同样拿四维度机评（内容维度因自定标题参考价值打折） |
| 写作资源 | 浏览语法点与写作技巧材料，也能上传自己的资料进去检索 |

练过的每次都留底。练习记录的正确用法是回看：翻同一类题的两篇对比，确认高频错误是不是还在重复。

## 两条线怎么排

按目标排优先级：

1. **有作业**先保作业——时限、互评、分值都挂在班级作业上，脱离时限谈练习没有意义；
2. **备考**走题库写作，按考试方向选题，一篇一篇对照四维度报告改；
3. **补短板**先看学习档案的错误类型统计，挑占比最高的一类，回题库找对应体裁专练；
4. 真想随手写点什么，自由写作兜底。

两条线的数据最后都汇进学习档案，练不练、练多少，曲线会说实话。
