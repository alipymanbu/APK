# 图生视频与首尾帧的玩法拆解

> 本篇讲怎么让一张静态图动起来：直接图生视频、用主体参考锁定人物形象、用首尾帧控制开头和结尾，各适合什么场景。

## 一、图生视频：一张图变成一段视频

在创作区选「图生视频」，上传一张照片或草图，补一句动作描述，几秒到几十秒后得到一段连贯视频。主体、光影、运动都顺着原图延续，不需要会剪辑。

什么样的图容易出好结果：

| 图片类型 | 效果 | 适合做 |
| --- | --- | --- |
| 人物肖像 | 表情、微动作自然 | 让照片「活过来」、社交内容 |
| 风景 / 建筑 | 光影流动、云雾水面动 | 氛围短片素材 |
| 手绘 / 二次元 | 保持画风不变加动作 | 让角色立绘动起来 |
| 草图 / 线稿 | 顺着笔触补全画面 | 概念演示 |

动作描述同样建议写「动作 + 运镜」而不是形容词。

## 二、主体参考：多镜头不变脸

如果需求是「同一个人出现在好几段视频里」——短剧、个人 IP、虚拟形象——就用**主体参考**：上传 1–3 张同一人物的照片，生成时角色长相与造型在整段视频里保持一致，镜头切换也不变脸。

三条经验：

1. 照片挑清晰的正面照，光线均匀、脸部无遮挡，一致率明显更高；
2. 想控制谁出场就把谁放参考里，没进参考的人物形象会「飘」；
3. 多段视频用同一组参考照片，人物才能跨镜头统一。

## 三、首尾帧：把起点和终点都定住

首尾帧是把视频的第一帧和最后一帧分别固定成两张图，中间的过渡过程由模型生成，适合变身换装、草图到实景、画风转换、动作起止可控这类场景。只给结尾一张图就是「仅尾帧」，用终点倒推整段画面。

注意分辨率限制：512p 档不支持首尾帧与仅尾帧，要做这类玩法至少选 768p。两张图跨度越大越容易跑偏，跑偏了换一对更接近的图重试，比改提示词有效。
