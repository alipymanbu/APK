# 等级称号与圈内黑话速查

> 本篇把 OTTOhub 的账号等级、称号体系与圈内高频黑话整理成对照表，给刚进社区、被「冷藏」「♿」「别急」整得一头雾水的新吉吉国民用。

## 等级：意大利语数字

经验值到了等级自动上去，没有跳级机制。以下对照以站内说明页当时显示为准：

| 等级 | 所需经验 | 升到该级解锁 |
| --- | --- | --- |
| ZERO | 0（注册即有） | 点赞、冷藏、评论、私信、投稿动态与视频 |
| UNO | 50 | 发弹幕 |
| DUE | 500 | 举报违规内容 |
| TRE | 1000 | — |
| QUATTRO | 3000 | — |
| CINQUE | 8000 | 可向站长申请成为审核（超管） |
| SEI ~ OTTO | 15000 ~ 80000 | — |

新手最容易卡住的两处：弹幕要 UNO、举报要 DUE——按钮用不了不是故障，评论、点赞、投稿都能攒经验。等级名其实也在玩梗：otto 是意大利语的「八」，等级最高一级正是一个人叫 OTTO。

## 称号：另一套体系

称号看身份与贡献，与经验值无关：

- **吉吉国民**：注册即得，全体用户的统一称呼；
- **轮椅英雄 / 二阶**：给站点捐赠一次 / 两次，管理员手动授予；
- **超管**：就任审核后授予；
- **站长**：不对外开放。

「轮椅」的来历见下面的黑话表——它不是骂人的词。

## 高频黑话对照

| 词 | 意思 |
| --- | --- |
| 冷藏 | 就是收藏；被冷藏的内容不公开展示，只有自己在个人页能看 |
| ♿ / 轮椅 | 主播早年腿部有伤定制过电竞椅，被观众戏称坐轮椅；二创标题大量出现 |
| 别急 | 圈内最高频口头禅，出自「主播都没急你们急什么」 |
| 稳健棍 | 主播的外号，出自职业生涯对「稳健」打法的自我评价 |
| 韭菜盒子 | 直播点外卖被漏送韭菜盒子的名场面，相关语录流传至今 |
| 鞍山大法庭 | 发布封禁公示的站内账号 |
| 超管 | 审核员的站内叫法 |
| 引流狗 | 贬义：跑到不相关社区到处刷梗的人，圈子里很反感这种行为 |

先潜水几天把词对上号，圈内交流方式偏抽象，硬接梗容易被认出来；玩梗留在站内，别四处刷。社区的背景与内容生态见 [吉吉国视频社区是什么](吉吉国视频社区是什么.md)，还没装的可以从 [ottohub 介绍页](https://ottohub.fwen.ren/)进，安装流程见 [安卓客户端下载与安装步骤](安卓客户端下载与安装步骤.md)。
