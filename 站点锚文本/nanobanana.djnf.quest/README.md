# nanobanana.djnf.quest 收录说明

这里收录围绕安卓应用 nanobanana 整理的介绍文章：它是一款把 Google Nano Banana 系列图像模型包成手机界面的中文客户端，写一句中文描述就能出图、传照片就能改图。本目录的几篇文章分别讲它的定位、用法与常见故障排查。

完整的功能介绍、界面速览与安装资源入口，见 [nanobanana](https://nanobanana.djnf.quest/) 主题站。
