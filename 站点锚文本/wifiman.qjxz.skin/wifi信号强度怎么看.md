# WiFi 信号强度怎么看

> 本篇讲手机上看到的信号格与真实信号强度（RSSI）的关系，以及怎么用工具把家里的信号死角找出来。
> **相关文档**：[手机扫描局域网设备的方法](手机扫描局域网设备的方法.md) · [网速慢排查思路](网速慢排查思路.md)

## 一、信号格数不等于信号好坏

手机状态栏那几格信号是系统粗略折算的结果：同样三格，有的手机代表 -65 dBm，有的可能已经是 -78 dBm。想判断某个房间的 WiFi 到底行不行，得看原始数值——RSSI（接收信号强度），单位 dBm，**负数，越接近 0 越强**。

日常可以按这个区间读数：

| RSSI 数值 | 含义 |
| --- | --- |
| -30 ～ -50 | 非常好，贴着路由器的水平 |
| -50 ～ -65 | 良好，日常使用毫无压力 |
| -65 ～ -75 | 勉强够用，视频可能开始缓冲 |
| -75 以下 | 差，网页都可能打不开 |

## 二、怎么实测：边走边看曲线

要看每个位置的读数，装一个带信号监测的工具最直接。安卓上 [WiFiman 资源站](https://wifiman.qjxz.skin/)整理的这款工具打开「信号」页就能看到当前网络的实时强度曲线——拿着手机从路由器旁边出发，依次走进每个房间，在感兴趣的位置停三到五秒让读数稳定，走完一圈回头看曲线，塌下去的那段就是信号死角。

测的时候注意两件事：

1. **一次只变一个条件**：先看同一位置不同时间的波动，再看不同位置的差异，别混在一起下结论。
2. **承重墙、金属门、鱼缸都吃信号**：这些障碍物后面的读数掉得快是正常的，不是路由器坏了。

## 三、找到死角之后

读数确认了死角位置，处理思路无非三种：把路由器挪到更居中的位置、加一台子路由或 AP 补覆盖、或者把常用设备挪到信号好的房间。改完之后在原死角再测一次，数值有提升（哪怕只提升几个 dBm）就说明改动有效。

判断「改动有没有用」看趋势比看单次更靠谱，这也是为什么建议用带曲线记录的工具：改之前走一圈、改之后再走一圈，两条曲线一对比，结论自己会说话。
