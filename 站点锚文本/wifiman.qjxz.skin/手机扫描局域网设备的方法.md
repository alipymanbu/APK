# 手机扫描局域网设备的方法

> 本篇讲怎么用手机把家里 / 办公室局域网里在线的设备扫出来、认出来，以及扫不到时的三个常见原因。
> **相关文档**：[WiFi 信号强度怎么看](wifi信号强度怎么看.md) · [网速慢排查思路](网速慢排查思路.md)

## 一、什么时候需要扫一遍局域网

最常见的三种处境：

1. **找某台设备的 IP**：监控主机、打印机、NAS 明明在网里，管理页面却要填 IP 地址才能访问，扫一遍就列出来了。
2. **确认设备到底在不在**：摄像头掉线，先看它在不在扫描结果里——不在，问题在设备或线路；在，问题在其服务配置。
3. **查有没有陌生设备蹭网**：对着扫描结果里的 MAC 与主机名逐个认，认不出的就要留心了。

## 二、用手机扫的步骤

以 [WiFiman 资源站](https://wifiman.qjxz.skin/)介绍的这款工具为例，它的「发现」页干的就是这件事：

1. 手机连上要排查的那个 WiFi（必须与目标设备**同一个网络**）。
2. 进「发现」页开始扫描，等列表出来。
3. 按 IP、主机名或厂商认人；认得出的设备信息更全，只回基础协议的设备至少有 IP 和 MAC。
4. 点开任意一台还能继续深挖：ping 它看通不通、扫端口看服务活不活。

首次使用记得把定位权限给全，安卓规定不给位置权限读不到周边网络信息，扫描结果会缺。

## 三、扫不到？先看这三个边界

设备明明在网里却不出现在结果里，多数是下面三条之一：

- **不在同一网段**：手机连了访客 WiFi、设备在主网络，互相看不见是正常结果。切到与设备相同的网络再扫。
- **开了 AP 隔离**：部分路由器默认开启「客户端隔离 / AP 隔离」，设备之间互相不可见。到路由器设置里关掉它。
- **设备防火墙拦了探测**：个别设备不回应任何发现协议，这种只能靠路由器后台的已连接列表兜底。

三条都排除了还是不行，可以重启路由器后再试一次。扫出来之后想核对信号质量，转去读[WiFi 信号强度怎么看](wifi信号强度怎么看.md)；如果扫出来的设备里就有拖慢网速的嫌疑对象，排查思路见[网速慢排查思路](网速慢排查思路.md)。
