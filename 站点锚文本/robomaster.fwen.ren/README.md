# RoboMaster 机甲大师：应用介绍与资源入口

RoboMaster（中文名「机甲大师」）是大疆创新为教育机器人打造的移动端配套应用，管理 RoboMaster S1 与 EP 系列两台机器：开着机甲跑 FPV 图传竞速、用触屏或体感练射击，再进实验室给机甲写自己的程序。本目录收录围绕这款应用与配套机甲的入门文章。

- 想直接装 App 的，从 [S1 机器人配套 App 安装与激活步骤](S1机器人配套App安装与激活步骤.md) 看起；
- 连不上机器人、想组一场多人对战，看 [S1 机器人怎么连手机与多人对战](S1机器人怎么连手机与多人对战.md)；
- 想学编程玩法，看 [Scratch 图形化编程入门玩法](Scratch图形化编程入门玩法.md)。

应用的功能速览、操控方式对照与实机画面，也可以在 [RoboMaster 机甲大师 App 介绍站](https://robomaster.fwen.ren/) 里直接翻。
