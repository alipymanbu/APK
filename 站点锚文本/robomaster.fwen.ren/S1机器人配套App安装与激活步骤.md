# S1 机器人配套 App 安装与激活步骤

> 本篇讲怎么把 RoboMaster（机甲大师）应用装到安卓手机上、装完第一次打开要做的事：装前核对什么、系统拦截怎么放行、新机器人为什么必须先激活。
> **相关文档**：[S1 机器人怎么连手机与多人对战](S1机器人怎么连手机与多人对战.md) · [Scratch 图形化编程入门玩法](Scratch图形化编程入门玩法.md)

## 一、装之前先核对三件事

1. **手机系统**：安卓端要求 Android 5.0 及以上；厂商早年公布的推荐机型集中在 2017-2019 年的旧款，新机型不在清单里不等于一定跑不动，只是没有适配承诺。
2. **剩余空间**：安装包约 407MB，加上图传缓存、程序文件的临时空间，剩余空间留出 1GB 以上更稳妥。
3. **手里有没有机甲**：这款应用管的是 RoboMaster S1 和 EP / EP Core 两台教育机器人，没有实机时能用的只有内置教学资源，操控、编程、对战都用不上——先确认设备再装。

## 二、四步装进手机

1. 从夸克网盘资源页把安装包转存到自己的网盘，再用手机客户端下载到本机存储。
2. 在系统设置里搜索「安装未知应用」，给文件管理器或浏览器授权——这个包不在应用商店里，系统必拦一道，放行即可。
3. 点开下载好的 APK 完成安装，确认安装前留意来源与文件名，别装到名字相近的其他应用。
4. 打开应用，按提示登录账号。

更多细节与截图，可以在 [RoboMaster 机甲大师 App 介绍站](https://robomaster.fwen.ren/) 的下载页逐步照着做。

## 三、新机器人必须先激活

全新的 S1 / EP 要在应用里完成激活才能正常使用：

1. 让手机联网（激活需要互联网）；
2. 登录账号，没有就现场注册；
3. 按应用提示走完激活流程——期间会做电机寻址、装甲寻址等初始化动作，别断电、别退出应用。

激活完的机器人如果固件提示不一致，先按应用里的提示逐项升级（多配件的 EP 平台，机械臂、电池等模块的固件也要一起升），升级中断电可能导致失败。

## 四、关于「还能不能更新」

厂商下载页已把这款应用标注为停止更新，最终版本停在 1.2.0，商店渠道不会再有新版。对 S1 / EP 用户来说功能依旧完整——从网盘拿到的安装包就是该终版。
