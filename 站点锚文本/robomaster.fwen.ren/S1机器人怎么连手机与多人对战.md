# S1 机器人怎么连手机与多人对战

> 本篇讲 RoboMaster（机甲大师）应用怎么连上机甲：直连和路由器两种模式怎么选、路由器要满足哪四个条件，以及多人对战为什么只能走路由器模式。

## 一、两种连接模式怎么选

机器人通电后，手机靠 Wi-Fi 连上智能中控（不是数据线也不是蓝牙），应用里进入连接页就能看到两个入口：

| 对照项 | 直连模式 | 路由器模式 |
| --- | --- | --- |
| 连接方式 | 手机直接连机甲发出的 Wi-Fi 热点 | 手机和机甲都连同一台路由器 |
| 图传延时（厂商标称） | 80-100 ms | 100-120 ms |
| 最远传输距离（厂商标称） | 约 140 m（2.4 GHz） | 约 300 m（5.8 GHz） |
| 适用场景 | 单机驾驶、没有局域网的环境 | 多台机器人组网对战 |

延时与距离都是厂商在无干扰、无遮挡环境下测得的，家里有墙、有其他 Wi-Fi 时会打折扣。

## 二、直连模式：五步连上

1. 装好电池，长按电池上的电源键开机；
2. 把智能中控上的模式开关拨到直连档位；
3. 打开手机无线网络列表，找到机甲发出的 Wi-Fi——名称印在机身贴纸上；
4. 输入贴纸上的 8 位密码连接；
5. 打开应用，按界面提示进入操控界面。

直连模式下手机连的是机甲热点，此时手机上不去互联网是正常的，别在这个状态下尝试登录账号或更新固件。

## 三、路由器模式：先过路由器这一关

多人对战必须走路由器模式，而且路由器要同时满足四个条件：

1. Wi-Fi 加密方式为 WPA/WPA2-PSK（老 WEP 或开放网络连不上）；
2. 接入设备数没到上限；
3. 允许已连接设备之间互相通信（「AP 隔离 / 访客网络」要关掉）；
4. 没有二次登录认证（连 Wi-Fi 还要弹网页输账号的那种不行）。

连不上时按顺序排查：模式开关位置 → 手机连的 Wi-Fi 对不对 → 路由器四项条件。另外机器人别在多个路由器之间来回切换，容易出现连接中断。

## 四、对战怎么开

所有机器人和手机都接到同一路由器后，在应用里建房即可开局。对战中机甲靠装甲上的击打检测模块判「掉血」：水晶弹直径不小于 6mm、命中时速度不低于 20m/s、弹道与装甲平面夹角不小于 45° 才算有效击中，检测频率最高 15Hz。也有占领基地这类靠图像识别判胜负的玩法。

安全上记住三条：只在合适的场地玩、不对着人和动物发射、按说明佩戴护目镜——水晶弹是实体弹丸，别在室内对着易碎物练枪。
