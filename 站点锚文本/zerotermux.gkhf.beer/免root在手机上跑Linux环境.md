# 免 root 在手机上跑 Linux 环境

> 本篇面向想在安卓手机上获得 Linux 环境的读者：为什么免 root 也能跑、
> 跑起来之后能做什么、上手需要什么前提。整体面貌可先看
> [ZeroTermux 介绍站](https://zerotermux.gkhf.beer/)，界面实拍一目了然。

---

## 为什么不需要 root

传统印象里，在手机上跑 Linux 要先解锁、刷机、拿 root。而 ZeroTermux 这类
终端方案走的是另一条路：应用在自己的沙盒目录里搭起一套完整的用户态环境，
配合 PRoot 做文件系统与权限的「模拟」，不碰系统分区、不动引导——所以
正常安装就能用，不牺牲保修，也几乎不存在变砖风险。

需要说明的是：PRoot 模拟的是环境而不是内核，绝大多数命令行场景足够了；
真要碰底层操作才涉及 root，那属于进阶玩法的可选项。

## 跑起来之后能做什么

- **开发工具链随身带**：apt / pkg 装 Python、Node.js、git，写脚本、跑爬虫、
  做文本处理，手机就是一台口袋开发机；
- **部署发行版容器**：Ubuntu、Kali、Debian 一键拉起，图形面板里点选即可，
  性能损耗低；
- **当轻量服务器用**：起一个 sshd，电脑远程连上来管理；配个支持供电的
  拓展坞接键鼠，临时应急办公也能顶；
- **更进一步的折腾**：X11 图形桌面、QEMU 虚拟机跑其他系统，社区里都有
  成熟玩法。

## 上手前提

- Arm64 架构的安卓手机，系统 Android 7.0 及以上；
- 存储留足余量（建议 1GB 起步，跑发行版和桌面再多留些）；
- 首次启动会初始化基础环境并联网，耐心等它准备就绪。
