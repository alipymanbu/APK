# BUD 界面怎么换成中文

> 装完打开全是英文？这篇把切中文的菜单路径、找不到入口时的对照说法，以及切换后没生效的处理一次讲清。
> **相关文档**：[捏脸与手绘服装玩法.md](捏脸与手绘服装玩法.md) · [零代码创作入门.md](零代码创作入门.md)

---

BUD 面向全球发行，商店页列了英语之外 15 种以上的语言，简体中文在列。它不一定默认跟随手机系统语言，不少用户装完看到的是英文界面——好在新版里切中文只要四次点击，不用改手机系统设置。

## 一、主界面里的切换路径

进到主界面之后：

1. 点**右上角三条横线**的菜单图标；
2. 选 **Settings**（设置）；
3. 选 **Language**（语言）；
4. 列表里找到**简体中文**，选中后点 **Done**。

设置一次就会被记住，之后再进应用仍是中文。也有版本把语言入口放在主界面下方的地图图标菜单里——路径可能因版本而异，要找的东西都一样：**设置页里带「Language」字样的那一项**。

还有一条更早的入口：**登录界面**右下角的图标里也能选 Language，下滑找到「中文（简体）」点 Done——等于装完第一次打开、还没进主界面就能把语言定好。

## 二、界面全是英文时的对照

| 你想找的 | 屏幕上显示的 |
| --- | --- |
| 设置 | Settings |
| 语言 | Language |
| 简体中文 | Chinese (Simplified) / 简体中文 |
| 确认 | Done / OK |

选完语言如果界面没立刻变，把应用从后台彻底划掉再打开一次。

## 三、切换之后还要知道的

- 换的只是**界面语言**：世界标题、聊天内容、别人写的简介都是玩家创作的内容，不会跟着翻译；
- 商城里部分活动道具名可能仍以英文显示，属正常现象；
- 想换回英文或其他语言，同一条路径再选一次就行。

还没装的话，可以先看 [bud 安卓版玩法与安装说明站](https://bud.qjxz.skin/) 的安装步骤页；装好之后想玩什么，从[捏脸与手绘服装玩法.md](捏脸与手绘服装玩法.md)看起。
