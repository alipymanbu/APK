# Beta测试构建90天到期打不开怎么办

> 装好的 Beta 版应用某天突然打不开，列表里还写着「Expires in x Days」——这不是手机坏了，也不是应用被删，是构建到了 90 天的有效期上限。这篇把这条规则拆开讲：从哪天起算、到期什么表现、怎么续上。

## 90 天从哪天开始算

起点不是你安装的那天，而是**开发者上传构建的那天**。同一个构建，你早加入就多测几天，晚加入就少几天——所以列表里同一个应用，不同测试员看到的剩余天数可能不一样。

剩余天数就显示在 TestFlight 应用列表的应用名称下方（例如「Expires in 84 Days」），点进应用详情页也能看到到期时间。

## 到期后是什么表现

构建过期后点开会无法启动，仅此而已：

- 不影响设备里的其他应用；
- 不影响该应用的 App Store 正式版；
- 之前测过的数据是否保留，取决于开发者上传新构建后的处理，重要数据先自行备份。

## 三种续上测试的办法

| 办法 | 说明 |
| --- | --- |
| 等新构建推送 | 开发者一般会在到期前补传新版本，TestFlight 会推送通知，附上这轮「测什么」的说明 |
| 打开自动更新 | TestFlight 3 及以上支持自动更新，新构建到位后自动安装，不用手动重装 |
| 主动进应用查看 | 收不到通知时，打开 TestFlight 看应用列表，有新构建就直接点安装 |

## 一个常见误会

「到期打不开 = 被开发者踢出了测试」——不是。过期只是这条构建的生命周期到了，你的测试员身份还在；只要开发者上传新构建，你就能继续装、继续测。真正的身份变化是「测试员被移除」，那会连应用列表里的条目一起消失（状态会显示 Tester Removed）。
