# 文生视频提示词怎么写

> 可灵AI 的文生视频命中率，大半取决于提示词怎么组织。本篇给出可复用的六段式结构、失败样例对照，以及几条少走弯路的改写习惯。

## 先记住六段式

把一句话拆成六个槽位，按顺序填：**主体 + 运动 + 场景 + 镜头语言 + 光影 + 氛围**。这是产品方指南里给的结构，也是社区里被验证最多的组织方式——六段全填，命中率明显高于随手一句。

```text
差：一只狗在跑
好：一只金毛犬在开满野花的草地上奔跑，镜头侧面跟随，
    午后阳光斜照，草叶随风摆动，画面明亮，慢动作
```

逐段拆开看：

| 槽位 | 写什么 | 反例 |
| --- | --- | --- |
| 主体 | 一个具体的对象，带细节（品种、穿着、材质） | 「一个人」 |
| 运动 | 唯一的主要动作 | 五六个动作堆一句 |
| 场景 | 地点与环境元素 | 只写主体不写环境 |
| 镜头语言 | 推近、拉远、跟随、环绕 | 「随便拍」 |
| 光影 | 时间与光线方向 | 不写 |
| 氛围 | 画风或情绪词（胶片质感、赛博朋克霓虹） | 不写 |

## 三条改写习惯

1. **一次只改一两个要素**。第一条片子不满意很正常，整句推翻重写等于重新抽奖；只换运动词或光线词再跑，收敛快得多。
2. **负向提示词别空着**。界面有这一栏的话，把「文字、水印、变形的手指」这类明确不要的东西写进去，能省掉不少返工。
3. **画风词放结尾**。想要特定质感就在句尾点破，比把风格词埋在中间稳定。

试词阶段每次生成都要扣值，先用最短的时长把提示词试稳，成本最低——省值的思路整理在 [灵感值怎么领才够用.md](灵感值怎么领才够用.md)。提示词稳定之后，音效、对口型、续写延长怎么接成一条完整的出片动线，[kerning](https://kerning.bmww.store/) 这份资料站按创作流的顺序整理成了一页，比零散翻功能条目顺。
