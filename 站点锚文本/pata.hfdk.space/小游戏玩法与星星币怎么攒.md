# Pata 小游戏玩法与星星币怎么攒

> 本篇整理 Pata 内置的多人派对玩法清单、怎么加入对局，以及星星币这条经济线的来源与去处。
> **相关文档**：[是什么应用与核心玩法.md](是什么应用与核心玩法.md) · [安卓下载安装与登录步骤.md](安卓下载安装与登录步骤.md)

Pata 的内置小游戏全是多人局，为熟人小圈子设计：靠文字和动作表达，不需要全程开语音，不擅长聊天的人也接得住。你装的版本里有哪几款，以游戏界面上实际列出的为准。

## 玩法清单

| 玩法 | 一句话说明 |
| --- | --- |
| 谁是卧底 | 人手一个词只有一个不同，描述、投票、互相怀疑的经典局 |
| 你演我猜 | 一人比划一人猜，考好友之间对彼此脑回路的了解 |
| 默契问答 | 同一道题各选各的，对不上就说明「最好的默契就是没默契」 |
| 画画拼图 | 每人画一笔往下传，看最后那幅画能离谱成什么样 |
| 专注花园 | 和好友互卷赛博种花，谁坐得住谁的花长得好 |
| 寻宝冒险 | 派宠物出门冒险，开出来的宝藏全看运气 |

对局以房间形式存在：进游戏界面选一个玩法就能匹配开局，也能直接加入好友正在玩的房间；不想下场就用观战模式，站在旁边看朋友互相怀疑。对局里的表现还会被写进宠物的观察日记，变成几个人共同的记录。

## 星星币从哪来、花到哪

**来源**（每天点两下就够）：

- 每日签到：「我的」页里点一次，最稳定的一条；
- 任务中心：喂养宠物、访问好友空间、参与一局对局，按列表做完领币；
- 邀请与活动：邀请好友的活动期有套装与星星奖励，主题活动的产出以活动页当时显示为准。

**去处**：装扮商城给宠物买衣服造型，家具商城给小屋添摆件——买之前记得先试穿预览，再跟共屋的好友对一下审美，别各买各的。

**要不要充钱**：应用挂着内购入口，但签到加任务的产出足够慢慢把看中的东西换回家；装扮不会跑，攒几天再买也行。
