# Local AI 安卓站说明

一个介绍 Local AI（清鸽LocalAI）的第三方说明站：这款应用把 GGUF 大语言模型装在安卓手机本地运行，断网也能对话，聊天数据不上云。站点整理了它的功能亮点、机型内存与模型参数量的搭配、GGUF 量化档位选择，以及从网盘转存安装包到装入模型开始对话的完整安装步骤。

入口：<https://local-ai.yoan.quest/>

站内两页：

- [首页](https://local-ai.yoan.quest/)——功能介绍、机型搭配、数据去向与常见疑问；
- [下载与安装](https://local-ai.yoan.quest/download.html)——安装包获取入口与四步安装流程。

本目录下的文章从不同角度展开「在手机上跑本地大模型」这件事，可在站内说明的基础上配合阅读。
