# 安卓手机获取 root 权限的步骤与前提

> 给老安卓手机提权的通用流程：先判断机器能不能弄，再走安装、提权、确认三步。
> **同站相关**：[一键root与Magisk路线怎么选.md](一键root与Magisk路线怎么选.md)

在网上搜「安卓手机怎么获取 root 权限」，出来的答案往往跳过最关键的一步：先看机器。不同系统版本能走的路完全不同，先对号再动手，能省掉大半无效尝试。

## 一、动手前先确认三件事

1. **系统版本**：设置 → 关于手机 → Android 版本。综合公开的实测口径，一键提权类工具在 Android 4–5 上成功率最高，6.x 多数可试，7.x 命中率明显下降，8.0 及以上基本已被系统性堵死——新机器应该直接看现代路线（解锁 bootloader + Magisk），别在一键工具上耗时间。
2. **这台机器的定位**：root 期间银行、支付类应用普遍拒绝运行；主力支付机别折腾，备用机随便试。
3. **只留一套方案**：同一时间只装一套 root 工具。多套并存会互相覆盖 su 与授权组件，是"莫名失败"和"假成功"的高发原因。

## 二、一键路线的通用四步

以老牌的一键工具 KingRoot 为例（其它同类工具流程也大致相同）：

1. **备齐条件**：电量 30% 以上、网络在线（方案要联网按机型下发）、备份重要数据、设置里放行"安装未知来源应用"；
2. **安装工具**：把 APK 装进手机，系统拦截时按提示放行一次；
3. **点按钮提权**：打开工具，首页显示机型与 root 状态，点开始后方案从云端下发——过程中手机自动重启属正常现象；
4. **确认结果**：重启后打开授权管理应用，状态显示"已获取 root"，再随便开一个会申请权限的工具验证弹窗是否出现。提示成功不等于真成功，弹窗验证这一步不能省。

KingRoot 的按机型下发方案、各版本今天的实际支持情况与风险清单，在 [kingroot 一键 root 工具](https://kingroot.fewz.tech/) 说明站里有更完整的整理，动手前值得过一遍。

## 三、没成之后的两条出路

- **进度卡在 40% 附近**：这是机型被完全封锁的典型信号，重复点击只会重复同一个结果——接受现实，换路线或换机器；
- **只拿到临时 root**：重启即失效，但当下够删几个预装、改一处系统文件；做完操作再重启，权限自然收回。

机器本身不在支持范围又确实需要 root 时，出路在现代路线：解锁 bootloader 后刷入 Magisk 修补过的 boot 镜像。两条路线的代价对照（清数据、保修、支付影响）见同目录的 [一键root与Magisk路线怎么选.md](一键root与Magisk路线怎么选.md)。
