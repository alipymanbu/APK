# 机场贵宾室怎么进：从查位置到扫码入场

很多人对「机场贵宾室」的印象还停留在头等舱旅客专属，其实通过 Priority Pass 这样的独立贵宾室使用计划，普通经济舱旅客一样能进——入场资格跟着会籍走，与乘坐哪家航司、买什么舱位无关。这里按一次真实出行的时间顺序，把进门这件事拆开讲。

## 第一步：出发前先查好去哪家

打开 Priority Pass 的应用，按城市、机场名称或三字码搜索目的地，首页的 Nearby 也会直接列出附近机场。每个贵宾室条目都写明所在航站楼、位置说明与开放时间；少数贵宾室收附加费或限时段，详情里会标注。部分枢纽机场还有餐厅、水疗这类非贵宾室体验可以选。

更完整的流程拆解可以看这份 [Priority Pass 贵宾室应用介绍](https://priority-pass.gerw.hair/)，它按出行时间线把每一步都配了截图。

## 第二步：门口出示电子会员卡

注册会籍并登录应用后，「卡」选项卡里就是电子会员卡。进门流程是：

1. 在前台说明自己是 Priority Pass 会员，把电子会员卡的二维码亮给工作人员；
2. 同时出示当日有效的登机牌——会员本人和同行宾客都要，且姓名要与登机牌一致；
3. 带了同行人，前台会当场登记人数；
4. 扫码完成后即可入场。

几个实用细节：读卡器对暗屏识别率低，扫不出来先把亮度拉满；几乎所有贵宾室都接受电子卡，个别不接受的会在条目「设施」栏标注；手机没电时只能靠实体卡，卡的照片或手抄卡号不能替代有效凭证，长途出行建议实体卡随身带。

## 第三步：进门之后

免费餐食饮品是基本盘，部分机场还有睡眠舱、Be Relax 水疗，一些合约餐厅也接受入场权益。到访记录和剩余次数在应用账户页实时更新，不会出现「门口才发现次数用完」的尴尬。

## 常被问到的一个问题

没有会籍能不能先装应用？可以——没有会籍也能浏览贵宾室列表，但进不了门。会籍要么自行购买，要么来自银行信用卡附赠的权益；拿到会籍并登录后，电子会员卡才会出现。相关选择可参考[会籍三档怎么选](会籍三档怎么选.md)。
