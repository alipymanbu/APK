# 同行宾客与到访次数怎么算

用 Priority Pass 进贵宾室，最容易被算糊的就是两笔账：带人一起进要花多少钱、这一年的免费次数还剩几次。这里把规则摊开讲清楚。

## 宾客怎么计费

三档会籍都允许带同行宾客，宾客按人次收访问费，公开口径为每人每次 US$35，前台入场时登记人数并当场结算。也就是说：

- 自己有免费名额时，宾客的费用是否从名额里扣，取决于会籍类型——部分会籍的免费访问只覆盖会员本人；
- Standard 这类按次付费的会籍，会员本人和宾客各自按次付费；
- 个别贵宾室对所有人都收附加费，这与宾客规则无关，条目详情里会单独标注。

一个容易忽略的硬性要求：**会员与宾客都需出示当日有效登机牌，且姓名要与登机牌一致**。想把名额借给别人单独使用是行不通的，入场凭证对得上人才放行。

## 到访次数在哪看

应用账户页的 Visit History 和剩余次数实时更新：这次进了哪家、年度内还剩几个免费名额、有没有还在处理中的到访记录，都列在「MY ENTITLEMENT」下。每次刷码进场后，记录通常会稍延迟一点入账，看到次数暂时没变不用慌。

## 几个边界情况

**换新实体卡后**：电子会员卡绑定在具体那张实体卡上，收到新卡要在应用里重新激活，旧的那份随之失效。

**次数用完了**：超出免费名额后按次收费，费用结算到绑定的支付卡上，不会出现「刷不进去」被拦在门口的情况——除非这张卡本身有问题。

**手机没电**：电子会员卡打不开就只能靠实体卡，卡的照片和手抄卡号都不算有效凭证。这也是长途出行建议带实体卡的原因。
