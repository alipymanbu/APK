# anyview 是什么？从 2007 年读到现在的老牌手机阅读器

本篇讲 anyview 这款阅读器的来历与定位：它诞生于什么年代、跑过哪些平台、为什么到现在仍有一批固定用户。

---

## 一、诞生：为「不用做书」而生的阅读器

anyview 诞生于 2007 年。那个年代在手机上看电子书，市面上的成熟方案往往需要对每一本书单独制作，读一本折腾一本。anyview 的思路正好相反：把阅读器做成通用工具，书是什么格式、放在哪个文件夹都不重要，打开软件扫一遍就能读。

它最初用 Java 编写，只要手机支持 Java 和 JSR-75 标准就能装，后来陆续出现在塞班 S60、黑莓、Windows Phone、iOS 以及安卓等平台上，能运行它的手机型号一度超过上百种——从诺基亚、摩托罗拉到各种国产按键机，都有它的身影。

## 二、定位：目标锁定在文本阅读上

从第一个版本起，anyview 的目标就很明确：做好的手机阅读器，给用户良好的阅读字体、顺手的操作和足够强的阅读功能。它提供了超过 50 项用户设置，愿意折腾可以调出完全个人化的读法；不折腾，默认状态也顺手好用。大多数操作一两步就能完成，这是它在按键机时代就练出来的功夫。

## 三、2022 年的插曲：老用户的挽留

2022 年 3 月，开发者一度计划下架 anyview，消息传出后，大量老用户在各个渠道表达留恋。一款多年未大更新的阅读器能被这么记挂，说明「打开就能读、读完不留打扰」这件事本身就有人需要。它后来延续了下来，安卓版仍在持续迭代，目前版本为 4.3.0。

## 四、现在：老手机当阅读器正好

如今的 anyview 安卓版延续着本地阅读的路子：TXT、UMD、EPUB 等格式直接读，压缩包不解压翻，扫一遍存储书进书架。手里有旧手机、硬盘里囤着一堆 txt 小话本的话，把它装上正合适。格式细节见[电子书阅读器支持哪些格式](./电子书阅读器支持哪些格式.md)，导入步骤见[怎么把小说导入手机书架](./怎么把小说导入手机书架.md)；这款应用的介绍与获取入口整理在 [anyview 阅读器介绍站](https://anyview.kook.yoga/)。
