# 和朋友在同一张画布上画画的步骤

> 从新建画布到所有人落笔，一场联机共绘其实就四步。本篇按顺序拆开讲，顺带说清密码房和公共服务器这两件事。
> **相关文档**：[多人联机画画软件怎么选](多人联机画画软件怎么选.md) · [安卓手机联机绘画的使用要点](安卓手机联机绘画的使用要点.md)

---

## 一、四步流程总览

1. **新建画布（或打开本地文件）**
   单独用的时候，它就是一款普通的绘画软件：新建画布、选笔刷、开画。离线状态下所有功能照常，联机只是把这块画布「开放」出来。

2. **主持一间会话（Host）**
   在会话菜单里选择「主持」，填好画布尺寸等参数。选择「远程」方式并把地址指向公共服务器，房间入口就会挂进会话列表——这一步不需要自己搭任何服务器。

3. **把入口发给朋友**
   进房方式有三种：邀请链接、服务器地址、会话编码。三种都行，让朋友在「加入会话」里填进去，或在「房间大厅 / 会话列表」里找到房间名双击加入。

4. **各画各的，或接力着画**
   进来的人可以各占一层互不打扰，也可以在同一层接龙。想上色、铺背景的活儿分开干，就用图层组；谁画哪块，开画前说一声就行。

## 二、密码房：想安静画画就加一道门

主持会话时可以设置密码。加了的房间就是私房，只有拿到邀请的人进得来；不加密码的公开房间则会出现在会话列表里，任何逛列表的人都能进来画两笔。

| 想法 | 做法 |
| --- | --- |
| 只有固定几个人画 | 主持时设密码，链接和密码发给朋友 |
| 想认识画友、开放接龙 | 不设密码，起个清楚的名字挂进列表 |
| 防止有人捣乱 | 房主用权限管理，可以限制或请出参与者 |

## 三、公共服务器的一条规矩

默认的公共服务器谁都能用，但容量有限：**一小时没有任何活动的会话会被自动结束**。画到关键处记得随手保存文件；要开长期房间，可以换用其他社区服务器，或者自建一台——这些都在能力范围内。

## 四、画完之后

成果不用留在软件里：

- 存成 **ORA**（OpenRaster），Krita、MyPaint、GIMP 打开后图层结构原样还在，接着精修；
- 存成 **PSD**，配合其他支持 PSD 的软件接力；
- 画的过程还能导出成延时视频，合绘的成果连过程一起留念。

工具本身的功能与获取入口，见 [Drawpile 共绘介绍站](https://drawpile.hhdc.tech/)；手机上进房操作的具体差异，看[安卓手机联机绘画的使用要点](安卓手机联机绘画的使用要点.md)。
