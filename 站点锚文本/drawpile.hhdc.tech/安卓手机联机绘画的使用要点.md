# 安卓手机联机绘画的使用要点

> 手机上也能正经参与同画布共绘。本篇讲安卓版与桌面版的差别、触控手势怎么调，以及小屏进房前值得做的几项设置。

## 一、安卓版是什么成色

Drawpile 的安卓端是原生客户端，不是套壳网页：绘画、做动画、进房间都在。近期版本对移动端做了一整轮打磨——首次启动会先询问界面缩放、修掉了一批键盘输入问题、还支持了触控笔的笔杆旋转。桌面版有的图层、混合模式、剪辑、时间轴动画，手机上同样是齐的。

安装文件资源的获取入口在 [Drawpile 共绘介绍站](https://drawpile.hhdc.tech/)，从那里的下载页进入。

## 二、第一次打开：先定界面大小

启动时会让你选界面缩放档位，图标和文字的大小取决于这一步。手机小屏建议调大一档，别省——画的时候工具栏按得准比界面显得「专业」重要得多。选错了也不怕，设置里随时能改。

## 三、触控手势：按自己的习惯逐项调

安卓版的「触控」设置页把指法逐项列了出来，默认大致是这样：

| 手势 | 作用 |
| --- | --- |
| 单指轻点 | 绘画 |
| 双指合捏 | 缩放 |
| 双指扭动 | 旋转画布 |
| 三指轻点 | 撤销 |
| 四指轻点 | 隐藏面板 |

每一项都能改成别的动作。两个建议：**撤销**这个动作务必留给一个顺手的手势（画错是高频事件）；**旋转画布**在手指操作时比找菜单快得多，值得保留。手写笔用户则可以把手指专门用来导航、笔尖只管画，避免误触。

## 四、界面与小屏的几项细扣

「界面」设置页里有几项对小屏用户有用：

- **缩放比例与字体大小**：整体 UI 密度按设备调，不用迁就默认值；
- **屏幕滚动**：惯性滚动开关与阈值，影响画布拖动的手感；
- **图层相关的提示**：新建图层时显示提示、删除图层时要求确认——联机时图层是大家的分工界面，多一层确认少一次误删。

## 五、进房前后的三件小事

1. 用「加入会话」填地址或编码，或去房间大厅、会话列表里挑公开房；
2. 进房先看一眼图层列表，问清楚分工再落笔，比自己找位置画礼貌得多；
3. 公共服务器上的会话一小时没活动会被自动结束，画完随手把文件存下来带走。
