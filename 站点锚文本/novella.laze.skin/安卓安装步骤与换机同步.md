# 安卓安装步骤与换机同步

> 从拿到安装包到换机不丢书架，这篇按动手顺序写：装前确认什么、装的时候会卡在哪、数据怎么跟人走。
> **相关文档**：[轻书架第三方安卓客户端是什么.md](轻书架第三方安卓客户端是什么.md) · [阅读排版设置与双页布局.md](阅读排版设置与双页布局.md)

---

## 一、动手前确认两件事

- **系统**：Android 7.0 及以上，旧机型装不上多半卡在这一条。
- **空间**：安装包约 84M，装完占用更大；建议再留出 500M 以上，给离线缓存的书留位置。

安装包从哪里拿：这款客户端的安装文件资源走网盘分享渠道，入口集中在 [Novella 介绍站的下载页](https://novella.laze.skin/)（进去后按页面按钮操作即可，版本与体积以你实际拿到的那份为准）。

## 二、四步装好

1. **转存并下载**：打开网盘分享页，把文件转存到自己的网盘，再从网盘应用下载到手机存储。
2. **放行未知来源**：点开 APK 时系统若提示禁止安装，按弹窗前往设置，对**下载时用的那个应用**（浏览器或文件管理器）放行「允许安装来自此来源的应用」——注意放行对象不是 Novella 本身。
3. **同意免责声明**：首次打开会出现免责声明页，选同意并继续。
4. **登录账号**：进到账号页完成登录；老用户装好后先别急着翻书，先做下一节的还原。

装不上的情况多数是这两类：部分国行机型在未知来源之外还有「纯净模式 / 安装守护」一层，按提示临时关掉再装；文件在转存或传输中损坏的话，回到分享页重新下载一次覆盖安装。

## 三、换机时，书架怎么带走

这款客户端的跨设备同步走 **GitHub Gist**：书架、阅读进度、书签、阅读时长写进你自己的 Gist，新设备登录同一账号、指向同一个 Gist 就能读回同一份数据。同步免费，前提是有一个 GitHub 账号。

推荐顺序：

1. 旧设备联网状态下手动同步一次，确认最近一次状态是成功。
2. 新设备装好、登录同一账号，拉取一次还原。
3. 对一眼书架条目与进度位置，**核对无误后再卸载旧应用**。

一个容易踩的坑：离线缓存的书文件存在本机，**不跟着同步走**，换机后要在书库里重新下载；别在确认还原成功前清空旧设备。
