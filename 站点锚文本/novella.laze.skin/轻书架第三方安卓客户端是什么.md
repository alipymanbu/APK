# 轻书架的第三方安卓客户端是什么

> 你在搜「轻书架 客户端」或「Novella」时看到的这款应用，来路和定位一次说清：它从哪来、跟浏览器阅读有什么区别、开源身份意味着什么。
> **相关文档**：[安卓安装步骤与换机同步.md](安卓安装步骤与换机同步.md) · [阅读排版设置与双页布局.md](阅读排版设置与双页布局.md)

## 一、先说结论

轻书架是一个轻小说阅读站点，而这款客户端是社区开发者围绕它做的**第三方安卓应用**：包名 `sh.celia.novella`，以 AGPL-3.0 许可开源，代码放在 [github.com/celia-sh/Novella](https://github.com/celia-sh/Novella) 公开仓库里。它不改变内容的来源，做的事情是把「在浏览器里凑合看」升级成「在手机上认真读」——排版可调、书架与进度跨设备同步、讨论区随手进。

提醒一句：搜索「Novella」会撞见几款互不相干的产品（同名桌面写作工具、Google Play 上另一款英文小说平台）。认准**包名** `sh.celia.novella` 就不会装错。

## 二、和直接用浏览器看，差在哪

差别不在内容本身，而在阅读这件事的顺手程度：

- **排版**：字号、段落间距、左右边距、背景色都归你调，还有浅色、深色、纯黑三种模式；具体设置方法见[阅读排版设置与双页布局.md](阅读排版设置与双页布局.md)。
- **进度**：书架、阅读进度、书签、阅读时长可以通过 GitHub Gist 跨设备同步，换手机不必从头再来。
- **社区**：讨论区、周榜这类站点生态直接进了应用，找书和交流不用来回切网页。

想先看整体功能与界面截图，可以翻这份 [Novella 轻书架客户端介绍](https://novella.laze.skin/)，看完再决定装不装。

## 三、开源身份对你意味着什么

对你这样的一般读者，开源至少有两层实际意义：

1. **看得见**：代码与更新记录公开，功能怎么做的、改了什么，仓库里都有迹可循，不用担心来路不明。
2. **在生长**：项目正从 Flutter 迁往 React Native 与 Expo（iOS 客户端在重写计划里），功能清单公开在仓库的 Issues 与 Discussions 中，读者反馈可以直接参与。

装与用的具体操作，见[安卓安装步骤与换机同步.md](安卓安装步骤与换机同步.md)。
