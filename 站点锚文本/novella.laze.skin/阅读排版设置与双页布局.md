# 阅读排版设置与双页布局

> 这篇只讲一件事：把阅读页调成你自己的样子。字号间距、背景主题、简繁显示、翻页方式与双页布局，每项的入口和效果都在这。

## 一、设置面板从哪调

阅读页**点击屏幕中央**就会呼出设置面板，字号、间距、背景、亮度都在这一层；调完即生效，换一本也沿用同一套设置。想先了解这款客户端的整体情况，可以看[轻书架第三方安卓客户端是什么.md](轻书架第三方安卓客户端是什么.md)。

## 二、文字排版的可调项

| 项目 | 你能做什么 |
| --- | --- |
| 字号 | 连续调节，从小字密排到大字舒展都有余量 |
| 段落间距 | 控制段与段之间的呼吸感 |
| 左右边距 | 页面两侧留白，横竖屏观感差别大，值得单独调 |
| 简繁转换 | 同一本书的简体、繁体显示随时切换 |
| 首行缩进 | 中文书的段首缩进渲染与网页端一致 |

具体数值范围以应用内滑杆实际两端为准，不必对着别人的截图较劲。

## 三、背景与主题

- **预设背景**：黑白灰与护眼色系都备好了，选一个就走；也可以自定义配色，白天和夜间各存一套。
- **三种模式**：浅色、深色、纯黑（OLED）随系统或手动切换，夜里看书建议纯黑或深色。
- **封面取色**：书籍详情页会从封面提取主色调当页面主题色，每本书有自己的氛围；纯黑模式下封面也不会显得发灰。

## 四、翻页与双页布局

- **翻页方式**：点击左右翻页、上下滑动都可选，切换不丢进度；章节内还有进度滑块，想回看某一段不用一页页翻。
- **双页布局**：平板、横屏等大屏下有 Expanded 与 Split 两种双页排版可选，一页排两栏，纸质感更接近实体书；手机竖屏用不上它，不必纠结。
- **章节标题与脚注**：样式与网页端一致，带脚注的书读起来不会跳来跳去。

## 五、一个阅读小习惯

调排版别一步到位：先固定背景与模式，再调字号，最后微调间距和边距——三分钟就能找到舒服的组合。想看功能全貌或准备安装，去 [Novella 轻书架客户端介绍](https://novella.laze.skin/)；换机搬书架的顺序写在[安卓安装步骤与换机同步.md](安卓安装步骤与换机同步.md)里。
