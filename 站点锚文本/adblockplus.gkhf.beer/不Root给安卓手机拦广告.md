# 不Root给安卓手机拦广告

> 不想 Root、也不想折腾系统，照样能给安卓手机加一层广告过滤。这篇按「装好 → 选模式 → 配代理」的顺序走一遍免 Root 的完整流程，末尾把两个最常见的"为什么没拦住"也讲清楚。
> **相关文档**：[手机广告过滤方案怎么选.md](手机广告过滤方案怎么选.md) · [EasyList过滤规则入门.md](EasyList过滤规则入门.md)

## 一、免 Root 能拦到什么程度

先把预期摆正：不 Root 时，过滤靠 WiFi 代理实现，覆盖的是**当前这条 WiFi 下的网页流量**。浏览器里刷网页、网页内嵌的广告基本都在射程内；移动数据网络下的流量，系统不交给本地代理处理，这是机制边界，不是配置失误。

想覆盖更多流量的路线对比，见 [手机广告过滤方案怎么选.md](手机广告过滤方案怎么选.md)。

## 二、四步配好

1. **装上 App 并打开**：经典独立版的安装包经网盘分享获取，转存下载后正常安装（安装包 5.75MB，老系统也能装）。安装时若出现权限提示，与 Root 设备的自动配置有关，未 Root 设备用不到、照常继续即可。
2. **首次引导里选过滤模式**：打开 App 会让你选过滤模式，未 Root 设备选与本地代理对应的模式。
3. **给 WiFi 手动配代理**：进系统「设置 → WLAN」，长按当前连接的网络选「修改网络」，代理选「手动」，主机名填 `127.0.0.1`，端口按 App 内提示的数字填写，保存。
4. **验证**：随便开一个常出现广告的网页，对比配置前后的观感；没变化就回到第 3 步检查代理是否保存成功。

配置动作只需要做一次，之后这条 WiFi 下的网页流量都会先过一遍过滤再进浏览器。换 WiFi 环境时，新网络要重配一次。

## 三、两个"为什么没拦住"

**HTTPS 页面还有广告？** 如今大量网页走 HTTPS 加密，本地代理对加密流量天然受限，这部分拦不到属于正常现象。页面越传统（HTTP 明文、静态资讯站一类），拦截效果越明显。

**连着流量上网没效果？** WiFi 代理只覆盖 WiFi 网络，移动数据不在范围内。这个方案的使用习惯就是"在家/在办公室 WiFi 下享受干净浏览"，两者别混着期待。

## 四、装完之后调松紧

默认规则会放行符合"可接受广告"标准的非侵入式广告，想全拦或想自己加规则，都在设置里完成，具体见 [EasyList过滤规则入门.md](EasyList过滤规则入门.md)。
