# 安卓下载安装与故障排查：从转存到打开只需四步

Tappytoon 的安卓安装文件资源通过夸克网盘分享获取：转存到自己网盘、下载 apk、允许未知来源安装，全程不改动安装包本身。这篇按实际操作顺序写，装完遇到的常见问题也一并整理；机制与玩法层面的内容另见 [免费追更机制详解](免费追更机制详解.md)。

## 一、安装四步

1. **转存分享**：打开分享链接，登录夸克网盘后选「保存到我的网盘」。文件夹里如有说明 txt，先按提示操作；转存的好处是分享方日后原地更新文件时，链接保持不变。
2. **下载 apk**：在自家网盘里找到转存好的 apk，下载到手机本地存储。
3. **授权安装**：点开 apk，系统若提示「禁止安装未知来源应用」，按引导给当前使用的文件管理器或浏览器打开「安装未知应用」权限。只给这一个应用授权即可，装完可以关掉。
4. **首次打开**：安装完成后首次启动需要联网——作品列表、封面与章节图片都在线拉取，断网状态下首页出不来。

想换界面语言：底部 More → Language → 选语言 → Done。语言选项同时决定能浏览的作品范围（网络小说目前只有英语）。

## 二、点安装就被拦，装不上

绝大多数卡在「未知来源」权限：

- 路径：设置 → 应用 → 特殊权限 → 安装未知应用；
- 只给用来打开 apk 的那个应用（文件管理器或浏览器）授权，不用全局放开；
- 授权后回到文件管理器重新点安装即可。

## 三、装好了却打不开、闪退、图片不加载

按顺序来，别跳步：

1. **清缓存**：设置 → 应用 → Tappytoon → 存储 → 清除缓存；
2. **查网络**：内容全部在线加载，换 Wi-Fi 或流量各试一次；
3. **卸载重装**：前两步无效再重装。

注意反复卸载重装会占用账号的设备名额——同一账号上限 5 台。超了以后去网页端 Manage Devices 里重置设备列表，该操作每 3 个月只能做一次，别频繁点。

## 四、和已有应用会互相覆盖吗

有一种情况会「装出两个 Tappytoon」：应用商店版与网盘这份安装包的包名不同，系统视为两个独立应用，图标并存、互不覆盖。两个都在时注意：

- 分清当初的注册方式——社交登录与邮箱登录是两套独立账号体系，换一种方式登录进去的是空账号；
- 点数、购买记录、收藏只跟着账号走，不跟着图标走。

## 五、搜不到想看的作品

先做两层检查：切到英语界面（More → Language）再搜一次；确认它是漫画还是网络小说，两个分类分开检索。部分作品只在特定语言与地区上线，平台也会随时调整上下架。

装好之后点数怎么攒、会员值不值，看 [点数获取与会员权益](点数获取与会员权益.md)；更多界面与功能说明可逛 [Tappytoon 介绍站](https://tappytoon.wrwq.fun/)。
