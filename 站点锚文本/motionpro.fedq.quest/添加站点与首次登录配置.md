# MotionPro 添加站点与首次登录配置

> 本篇讲第一次使用 MotionPro 时怎么填网关信息、怎么完成系统授权、连上之后怎么断开。
> 还没安装的先看 [功能介绍与适用人群.md](功能介绍与适用人群.md)；登录失败转
> [登录失败与连不上排查.md](登录失败与连不上排查.md)。

## 一、动手前先准备三样东西

MotionPro 里要填的内容全部来自单位 IT 或学校网络中心，不是自己能猜出来的：

| 需要准备 | 长什么样 | 问谁拿 |
| --- | --- | --- |
| 网关地址 | `vpn.xxx.com`，或带端口的 `vpn.xxx.com:443` | 单位 IT / 网络中心 |
| 账号密码 | 一般是工号 / 学号对应密码，有的单位另发 VPN 账号 | 同上 |
| 认证方式 | 只要密码，还是要短信码、动态口令 | 同上 |

端口不确定时先不加，客户端默认走 443；学校的配置说明里一般会写全，照抄即可。

## 二、添加站点

1. 打开 MotionPro，点右上角的「+」（添加站点 / 添加网关）；
2. 逐项填写：
   - **标题**：自己起，方便认就行，比如「公司」「学校」；
   - **网关（主机）**：填 IT 给的地址，带端口就连端口一起填；
   - **用户名**：工号 / 学号 / IT 给的 VPN 账号；
   - **保存密码**：私人手机可以勾；公用或借来的设备建议不勾；
3. 点「存储 / 保存」，站点列表里会出现刚建好的这一条。

部分单位会发 `profile.ini` 之类的配置文件让导入（桌面端常见），安卓端一般手动填这几项
就够；两种都给你时任选其一，别重复建。

## 三、首次登录与系统授权

1. 在站点列表里点刚建的那一条；
2. 输入密码登录。单位启用了短信验证码或动态口令的，按页面提示继续填；
3. 第一次连接时，安卓系统会弹「是否允许创建 VPN 连接」——必须点允许，否则账号密码
   再对隧道也起不来；
4. 登录成功的标志：回到「网关」页面，「安全隧道」一行显示已连接。

## 四、用完记得断开

在「网关」页面点右上角的退出按钮（部分版本是电源样式图标）即可断开；断开后内网资源
立刻不可访问，手机恢复直连上网。不少单位给的是全局隧道：开着的时候全部上网流量都绕经
单位网络，挂着不断既费电又拖慢日常上网，用完就断是个值得保持的习惯。

更多功能说明与安装文件资源入口，见
[MotionPro 介绍站](https://motionpro.fedq.quest/)。
