# Blackbox 黑盒介绍站（blackbox.xnyx.quest）

这个目录收录 [Blackbox](https://blackbox.xnyx.quest/)（黑盒）的第三方介绍资料。Blackbox 是一个运行在安卓手机上的开源虚拟引擎：不用 Root 就能把同一个应用克隆出互相隔离的独立副本，Xposed 框架直接内置在容器里，虚拟定位还能按应用逐个设置。整理的入口站在这里：[Blackbox 黑盒 - 免 Root 的安卓虚拟引擎](https://blackbox.xnyx.quest/)。

## 本目录的文章

- [免 Root 多开与虚拟定位玩法](免Root多开与虚拟定位玩法.md) —— 多开、克隆与按应用设置定位的操作思路
- [Xposed 模块在容器内启用的步骤](Xposed模块在容器内启用的步骤.md) —— 不刷机跑模块的完整流程
- [和应用分身与同类容器的区别](和应用分身与同类容器的区别.md) —— 按需求选对工具层次
