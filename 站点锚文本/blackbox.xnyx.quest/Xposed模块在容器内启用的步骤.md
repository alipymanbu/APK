# Blackbox Xposed 模块在容器内启用的步骤

> 本篇讲在不 Root、不解锁的前提下，用 Blackbox（黑盒）内置的 Xposed 框架加载模块的完整流程：启用框架、装入模块、重启生效，以及模块勾了却不生效的排查表。多开与定位玩法见 [免 Root 多开与虚拟定位玩法](免Root多开与虚拟定位玩法.md)。

## 一、为什么框架可以不用 Root

传统玩法里，跑 Xposed 要解锁 Bootloader、刷入框架，多数情况还要 Root，一套下来有变砖风险。Blackbox 把框架直接做进了自己的容器：手机系统一个字都不用动，模块只作用于盒内的应用，原系统和原版应用完全不受影响。

这也是它的边界——框架只能影响装进黑盒里的那份应用，改变系统界面、状态栏之类的全局模块在容器里没有作用对象，装了也白装。挑模块时优先选「针对单个应用功能增强」的类型。

## 二、启用框架的四步

1. 打开 Blackbox，点右上角三个点进入设置；
2. 找到「启用 Xposed 框架」开关，打开；
3. 重启 Blackbox——从最近任务里划掉再打开即可，不是重启手机。首次启用后必须重启软件，框架才真正生效；
4. 回到设置确认框架状态为已启用。

## 三、装入模块并激活

1. 模块 APK 先装进盒子：和添加普通应用一样，点主界面右下角「+」，从列表选或从 APK 文件安装；
2. 设置里进入模块管理，把要用的模块勾选启用；
3. 再重启一次 Blackbox，让模块挂载生效；
4. 打开模块自己的界面做配置。

顺序记不清就记一句：**装模块 → 勾选 → 重启**。凡动了框架相关的东西，都重启一次黑盒再试。

## 四、模块勾了却不生效：按这张表核对

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 勾选后毫无反应 | 没重启容器 | 重启 Blackbox 再试 |
| 模块界面在、功能不生效 | 目标应用没装进盒子 | 模块和目标应用都装进 Blackbox，二者要在同一环境里 |
| 模块管理里根本没出现 | 模块装到了手机系统而不是盒里 | 按「+」重新装进黑盒 |
| 模块改的是系统界面 | 容器改不了系统 | 这类模块在所有应用级容器里都无效，不是操作问题 |

## 五、两点边界

- 设置页里有「隐藏框架」「隐藏 Root」两个开关，是容器自带的普通设置项，按需启停即可；但别把它理解成万能隐形——个别应用的完整性检查仍可能识别出容器环境，登录失败或功能受限时只能退回真机。
- 项目说明写明稳定性未经大量测试、仅供学习交流。启用框架后闪退增多，先关框架对比排查，确认是模块问题再逐个加回。

工具的定位与同类对比，见 [和应用分身与同类容器的区别](和应用分身与同类容器的区别.md)；安装入口与完整介绍整理在 [Blackbox 黑盒介绍站](https://blackbox.xnyx.quest/)。
