# Blackbox 免 Root 多开与虚拟定位玩法

> 本篇讲 Blackbox（黑盒）两个最高频用法：把一个应用克隆出多个互相隔离的副本，以及给盒内应用单独设置虚拟位置。工具的整体情况见 [和应用分身与同类容器的区别](和应用分身与同类容器的区别.md)。

## 一、多开是怎么实现的

Blackbox 本身只是一个几 MB 的容器应用。你把应用「添加」进盒子，容器里就生成一份这个应用的独立副本——有自己的数据目录、自己的用户身份，和手机上的原版互不读写。同一款应用于是可以原版登一个号、盒里登一个号，同时在线互不干扰。

操作路径很短：

1. 打开 Blackbox，主界面右下角点「+」；
2. 从已安装应用列表里选中目标应用，等待装入；
3. 回到主界面点图标即可启动盒内副本。

要给同一应用开第三个号，在主界面空白处由左向右滑动，可以再克隆一份新实例，原则上次数不限。不同实例之间数据完全隔离，这点和「同一应用反复退出换号」有本质区别。

## 二、虚拟定位的入口与原理

虚拟定位是 Blackbox 自带功能，不用装任何模块：主界面右上角进入虚拟定位，在地图上选一个位置保存即可。定位是**按应用分别设置**的——A 应用设一个坐标、B 应用设另一个，互不影响。

原理上，容器会禁用基站定位和 Wi-Fi 定位，只向盒内应用提供修改过的 GPS 读数：

| 定位方式 | 容器能否干预 |
| --- | --- |
| GPS 定位 | 能，改成你设置的位置 |
| 基站定位 | 直接禁用 |
| Wi-Fi 定位 | 直接禁用 |
| 按 IP 的网络定位 | 不能干预 |

## 三、「改了位置没生效」的常见原因

最常见的一种：应用走的是 IP 定位。网络定位是服务端按上网 IP 反推的，手机上的容器管不着 IP。判断办法是先查自己当前 IP 被定位到哪，再和应用内显示的位置对比——两者一致，说明应用走 IP 定位，虚拟定位对它无效；不一致且接近你设的位置，说明 GPS 层已生效。

另一种更基本：应用不是从盒里启动的。虚拟定位只作用于盒内那份副本，从手机桌面点原版图标，读到的仍是真实位置。

## 四、多开前的两句提醒

- 平台风控对「同一 IP 下多账号同步操作」很敏感，部分游戏对容器内运行有明确拦截，触发会直接报错。重要账号是否放进盒子，建议先掂量。
- 卸载 Blackbox 会连盒内所有应用与数据一起删除，重要应用先在应用内做备份或账号绑定。
