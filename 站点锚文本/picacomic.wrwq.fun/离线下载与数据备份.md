# 离线下载与数据备份

> 本篇讲把漫画下到本机离线看、以及收藏数据的两条命：本地收藏与网络收藏差别很大，搞混了换机会丢东西；文末给一份换机前的动作清单。
> **相关笔记**：[漫画源切换与自定义源配置.md](漫画源切换与自定义源配置.md) · [源失效与常见故障排查.md](源失效与常见故障排查.md)

## 一、把漫画下载到本地

在漫画详情页发起下载：选章节（整本全选或只挑几话）→ 确认后在下载管理里看进度。三点实际情况：

- **内容跟源走**：只能下载当前源里的漫画，下好的文件在本机、断网可看；
- **体积别小看**：长篇全本下载可能占几百 MB，空间紧张就按章节挑着下；
- **速度取决于源站**：源站限流时快不起来，这不是应用坏了，换个时段或换源重试。

已下载的漫画从「已下载 / 本地」列表打开即可；想腾空间就在同一处删除本机文件，删错了也还能重新下。应用还支持把漫画导出为 PDF——想把某几话存成单个文件传到别的设备，比搬图片文件夹方便。

## 二、两种收藏，别搞混

| 对比 | 本地收藏 | 网络收藏 |
| --- | --- | --- |
| 存在哪 | 只存这台设备的应用数据里 | 存在漫画源网站的账号下 |
| 换手机 / 重装 | 不做备份就没了 | 登录账号就能拉回来 |
| 前提 | 无 | 对应源已登录账号 |

收藏入口都在漫画详情页。给一部漫画点收藏时，它进哪一类取决于当前源与登录状态：picacg 这类要求登录的源会同步到账号；不登录时基本只落在本机。整理收藏时先把两类分开看，免得以为「都收藏了」，换机时却只找回了网络那部分。

## 三、换机或重装前的动作清单

1. 对照上面的表格，想清楚多少收藏只存在本机；
2. 登录 picacg 等需要账号的源，让网络收藏都落上去；
3. 配好 WebDAV 并做一次**上传方向**的同步，把本地收藏、阅读历史推到自己的网盘空间——地址、密码类型（应用密码 vs 登录密码）、空间容量是配置时最常错的三处；
4. 已下载的漫画文件不进同步范围，要保留就用传输工具搬走，或导出 PDF 后再传。

日常追更建议养成「加了新收藏就顺手同步一次」的习惯，成本一次点击，换来任何时候设备出问题都能恢复到最近一次的状态。

功能入口与界面细节在 [PicaComic 介绍站](https://picacomic.wrwq.fun/)有整套截图对照；同步失败、下载卡住之类的故障先翻[源失效与常见故障排查.md](源失效与常见故障排查.md)。
