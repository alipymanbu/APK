# 漫画源切换与自定义源配置

> 本篇讲聚合型漫画阅读器 PicaComic 里「源」的玩法：内置了哪些源、浏览时怎么切、哪些源要登录，以及 3.0.0 之后怎么用 JS 配置文件接入自定义源。
> **相关笔记**：[离线下载与数据备份.md](离线下载与数据备份.md) · [源失效与常见故障排查.md](源失效与常见故障排查.md)

## 一、内置了哪些漫画源

按项目仓库的说明，内置源包括 picacg、E-Hentai / ExHentai、JM Comic、Hitomi、绅士漫画、nhentai。不同版本会有增减，装的那份以应用内实际列表为准。这些源对应不同的漫画网站，内容范围、语言、账号规则各不相同——切换源之后，分类、排行、搜索结果会整套装换一遍。

## 二、切换当前源的两个位置

1. **浏览时切**：首页、探索或分类页顶部的源切换入口（下拉列表），换了之后列表立刻变成那个源的数据；
2. **设置里管理**：设置中有漫画源管理项，控制源的启用状态（不同版本入口名称略有差异，以应用内实际界面为准）。

一个实用习惯：想清楚自己看什么类型的内容，固定用一两个源并放在顺手的位置。多源应用最低效的用法，就是每次打开都从头把源挨个切一遍。

## 三、哪些源需要登录账号

部分源要求注册登录，典型的是 picacg：未登录时浏览受限或直接提示要登录。注意登录状态**按源分开**——在 picacg 登录了，不代表别的源也登录了；登录后才能用「网络收藏」这类跟随账号的功能（与只存本机的收藏是两回事，见[离线下载与数据备份.md](离线下载与数据备份.md)第三节）。账号注册、找回密码只能在对应漫画网站自己的体系里完成，应用本身不替人管账号。

## 四、接入自定义漫画源（3.0.0+）

从 3.0.0 起，应用支持接入它原本不认识的源：

- 自定义源以 JS 配置文件的形式提供，也可能是一条指向该文件的链接；
- 入口在设置的漫画源管理里，粘贴链接或导入本地文件即可；
- 配置内容由对应站点或社区提供，写错了这个源就加载不出来。

两个最常踩的点：**格式兼容**——3.1.0 对自定义源机制做过一次大改造，3.0 时代的老格式文件在 4.x 上很可能直接失效；**调试有专门入口**——加载失败的日志在「设置 → App → Logs」里看。另外，自定义源的可信度完全取决于提供它的人，来历不明的源文件不要导入。

## 五、源打不开时先别急着怪应用

原因几乎都出在源网站那一侧：先切到别的源判断是「单源不行」还是「全挂」——单源不行就重新登录该源账号、换个时段再试、确认接口地址没变更；全都打不开先查手机自己的网络。完整的排查顺序整理在[源失效与常见故障排查.md](源失效与常见故障排查.md)。

更多功能说明与安装文件资源的获取方式，见 [PicaComic 介绍站](https://picacomic.wrwq.fun/)。
