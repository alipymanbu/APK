# PicaComic 整理笔记（picacomic.wrwq.fun）

这里收录开源漫画阅读器 PicaComic 的使用整理：它把 picacg、E-Hentai、JM Comic 等多个漫画源聚合在一个应用里，支持章节离线下载与 WebDAV 数据同步。功能介绍与安装文件资源的获取入口见 [PicaComic 介绍站](https://picacomic.wrwq.fun/)。

## 本目录的笔记

- [漫画源切换与自定义源配置](漫画源切换与自定义源配置.md)——内置源一览、切源入口、JS 配置文件接入自定义源
- [离线下载与数据备份](离线下载与数据备份.md)——按章节下载、导出 PDF、两种收藏的区别与 WebDAV 同步
- [源失效与常见故障排查](源失效与常见故障排查.md)——源打不开、下载卡住、同步失败、打开闪退的排查顺序
