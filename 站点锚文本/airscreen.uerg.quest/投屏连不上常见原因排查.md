# 投屏连不上常见原因排查

> 发送端列表里看不到设备、看到了连不上、连上了黑屏没声——按命中率从高到低逐条排，每做一条回去验证一次。
> **相关文档**：[安卓电视怎么接收手机投屏.md](安卓电视怎么接收手机投屏.md) · [iPhone投屏到普通安卓电视怎么弄.md](iPhone投屏到普通安卓电视怎么弄.md)

---

## 一、列表里根本看不到接收设备

这一档九成是网络层面的问题，按命中率排：

1. **不在同一个 Wi-Fi**。手机连了蜂窝数据、或连了另一个名字的信号（很多路由把 2.4GHz 和 5GHz 拆成两个名字）都会导致互相看不见；
2. **AP 隔离或访客网络开着**。这两个开关的作用就是禁止同一路由下的设备互访，开着就一定搜不到，去路由设置里关掉；
3. **发送端开着 VPN / 代理**。局域网发现包发不出去，手机上尤其常见，关掉再刷新列表；
4. **路由长期没重启**。设备发现依赖组播，老化的路由经常失灵，按「重启接收应用 → 重启大屏设备 → 重启路由」的顺序来一遍；
5. **接收端没就绪**。确认接收应用确实开着、主界面能看到 `AS-xxxx` 设备名、没有弹窗挡着。

接收端应用从哪装、就绪状态长什么样，见 [安卓电视怎么接收手机投屏.md](安卓电视怎么接收手机投屏.md)；文中提到的 [AirScreen 投屏接收站](https://airscreen.uerg.quest/) 也整理了协议与安装的完整说明。

## 二、看得到，但一直连不上

- **配对码输错**：苹果设备首次连接时电视会给一串配对码，输错会直接退回列表，重选设备重新输一次；
- **权限没给全**：接收端首次启动时拒绝了网络或后台权限，表现就是「开着但连不上」，去系统设置的应用权限页补齐；
- **版本太旧**：发送端系统已升到最新、接收应用还是几年前的版本时，握手协议可能对不上，先升级接收应用再试。

## 三、连上了，但黑屏、卡顿、没声音

| 症状 | 多半是 | 动作 |
| --- | --- | --- |
| 一连上就黑屏 | 受版权保护的内容在拦截 | 换非受限视频验证；能放说明设备正常 |
| 画面一顿一顿 | Wi-Fi 带宽不够 | 清晰度调低一档；设备离路由近一点 |
| 声音比画面慢 | 镜像链路延迟累积 | 开硬件加速，看剧改用推流方式 |
| 投一会儿就断 | 接收端被杀后台 | 电池优化选「不限制」、开后台常驻 |
| 只有画面没声音 | 电视静音 / 手机连着蓝牙耳机 | 查电视音量、断开蓝牙再试 |

## 四、排除完还没解决的取舍

换协议是性价比最高的动作：AirPlay 不通试 Cast，Cast 不通试 DLNA——三条路覆盖的发送端类型不同，一条不通不代表全堵。也可以换一台发送端交叉验证：所有设备都搜不到，问题在网络；只有某一台搜不到，问题在那台设备的设置。
