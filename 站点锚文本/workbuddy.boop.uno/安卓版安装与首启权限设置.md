# WorkBuddy 安卓版安装与首启权限设置

WorkBuddy 的手机端是个典型的「轻安装、重配置」应用：APK 本身四十多 MB，两分钟就能装完，但首次启动的权限授予和账号选择，会直接影响后面「连接电脑」等核心玩法能不能用顺。这篇按真实安装顺序讲清楚每一步。

## 装之前，先认准安装包

市面上叫 WorkBuddy 的应用不止一个——另有同名的境外销售团队工具，和这款完全无关。动手安装前认准两点：开发者是「腾讯云计算（北京）有限责任公司」；装完后可以在「设置 → 应用管理」里核对包名，安卓版的包名是 com.tencent.workbuddy.app。

安卓应用市场（华为、小米、应用宝等）里能搜到它；如果手机上没有合适的市场，或者想装指定版本，走安装文件资源的方式更直接。入口和版本信息整理在 [WorkBuddy 手机版介绍站](https://workbuddy.boop.uno/)，安装步骤那篇也备好了。

## 四步装好

1. **把安装包弄进手机**：从网盘保存后用网盘 App 下载到手机存储，或在电脑上下载后用微信、QQ、数据线传过去。记住文件位置，一般在「下载」或「文件管理」里。
2. **点开 APK，允许安装**：系统会提示「是否允许安装未知应用」。这里的授权对象是你用来打开它的那个文件管理器，只对单个应用生效，不是全局放开——换了个文件管理器打开，就要给新的那个授权。
3. **等安装完成**：回到文件管理再点一次，点「安装」，几十秒就好，装完在桌面找到图标进入。
4. **登录**：手机号、QQ、微信都能登录，勾选用户协议即可。

## 首次启动：四项权限建议全部允许

第一次打开会依次申请权限，各有明确用途：

- **相机**：拍照上传、扫码。不给的话，纸质单据、白板内容发不进去。
- **麦克风**：语音下达任务。路上有灵感说一句就开工，靠的就是它。
- **存储或相册**：上传图片和文件、保存生成的产物。
- **通知**：任务在后台跑完的完成提醒。

误点了拒绝也不用卸载重装，去「设置 → 应用管理 → WorkBuddy → 权限」里逐项补开就行。

## 一个现在留意、后面省事的细节

如果打算用「连接电脑」模式——手机上指挥电脑端的 WorkBuddy 干活——那么 App 登录的微信账号，要和电脑端登录的微信账号保持一致，否则连不上。这是最常见的失败原因：很多人微信有大号小号两套，两端登录的不是同一个。装好后第一次登录时就把账号选对，后面能少排查一轮。
