# KakaoPage 账号注册登录与多端同步

> KakaoPage 没有独立的注册体系，账号走 Kakao 体系。本篇讲海外手机号怎么注册、登录选哪条路径、登录不上先查什么，以及手机与电脑之间同步什么。
> **相关文档**：[新手入门与核心玩法.md](新手入门与核心玩法.md) · [等待免费与每日领券技巧.md](等待免费与每日领券技巧.md)

## 一、用的是 Kakao 账号

登录 KakaoPage 就是登录你的 **Kakao 账号**——与 KakaoTalk 同属一套账号体系，不需要单独注册一个「KakaoPage 密码」。首次登录会弹一次服务条款同意，点掉即可进入应用。

## 二、海外手机号也能注册

不持有韩国手机号也能注册，关键是能收到短信验证码的手机号，两条路径任选：

**路径 A：网页版注册**

1. 电脑浏览器打开 KakaoPage 网页版，点右上角个人资料图标，选注册（회원가입）；
2. 选择「我有电子邮箱账户」（이메일 계정이 있습니다）；
3. 填邮箱地址完成验证邮件确认。

**路径 B：手机端注册**

在手机上装 KakaoTalk 后注册，注意两点：

- 国家区号选对：注册界面常默认韩国（+82），大陆手机号要手动改回 +86，输号码不要带前导 0；
- 用实体手机号：网络电话号码（VoIP）验证经常被拒，实卡成功率最高。

注册完成后记得**绑定邮箱**作为备用验证方式——以后换号、丢卡、收不到短信，都靠这个邮箱找回。

## 三、在应用里登录

- 手机装有 KakaoTalk：打开 KakaoPage，登录页选 KakaoTalk 登录，跳转确认一次即完成；
- 没装 KakaoTalk：直接用 Kakao 账号的邮箱（或手机号）加密码登录。

## 四、登录不上先查这几条

| 现象 | 处理 |
| --- | --- |
| 短信验证码收不到 | 等满 60 秒再点重发；核对区号有没有被默认成 +82；连续收不到改走邮箱路径 |
| 登录后卡在条款页 | 退出重新进一次；换网络环境（Wi-Fi 与移动数据互换）再试 |
| 密码忘了 | 用注册时绑定的邮箱走找回流程 |

另外一件事受政策限制：成人（19+）作品的实名认证走韩国运营商实名通道，海外账号完成不了，这类作品在账号正常的情况下也看不到——这是政策层面的限制，不是账号出了问题。

## 五、多端同步什么

同一账号下，这些内容跟着账号走而不是跟着设备走：

| 内容 | 表现 |
| --- | --- |
| 阅读进度 | 手机看到哪一话，电脑网页打开同一作品从同一处继续 |
| 收藏 / 书架 | 两端同一份列表，任何一端加的书另一端可见 |
| 已购话数 | 租借券或永久券买过的话，两端都能打开 |
| 现金与免费券 | 应用里领的券、充的现金，网页端直接可用 |

发现进度没对上，先确认两端登录的是**同一个 Kakao 账号**，再刷新页面；个别情况下同步有几秒延迟。想了解平台整体玩法与安卓端获取方式，见 [KakaoPage 使用参考站](https://kakaopage.fedq.ren/)；追更玩法则整理在[等待免费与每日领券技巧.md](等待免费与每日领券技巧.md)。
