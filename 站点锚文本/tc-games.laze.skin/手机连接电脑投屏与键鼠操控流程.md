# 手机连接电脑投屏与键鼠操控流程

> 本篇按时间顺序讲 TC Games 从安装到玩起来的完整流程：装哪两个包、怎么连上电脑、键位怎么弄才生效，以及顺手后的调节位置。定位与取舍见相关文档。
> **相关文档**：[真机投屏键鼠玩手游的工具.md](真机投屏键鼠玩手游的工具.md) · [投屏玩手游与模拟器的取舍.md](投屏玩手游与模拟器的取舍.md)

---

## 第一步：装两件套

TC Games 分两个安装包：手机端 App 装在安卓手机（Android 6.0 及以上），电脑端客户端装在 Windows 7 及以上的电脑。先装电脑端并注册登录，手机端通常不用手动装——第一次用 USB 线连接时，电脑端会把它自动推送安装到手机；推送不顺利再手动装。

## 第二步：连上电脑

连接前做两件事：手机在开发者选项里打开 USB 调试（MIUI 等系统还要同时开「USB 调试（安全设置）」）；准备一根能传数据的数据线，只充电的线识别不了手机。

| 方式 | 特点 | 适合 |
| --- | --- | --- |
| USB 数据线 | 延迟低、稳定 | 日常玩，首选 |
| WiFi 扫码 | 免插线，受网络影响 | 轻度使用；首次要先 USB 连一次 |
| HDMI | 画质延迟最好 | 进阶用户，需拓展坞等硬件 |
| 直播投屏 | 只投画面不能控制 | 推流直播，配合窗口捕获 |

新用户从 USB 或 WiFi 开始即可。WiFi 记得连路由器的 5GHz 频段；连不上多半是没先用 USB 连过一次，或手机 USB 模式停在「文件传输」。

## 第三步：配键位

投屏成功后按顺序试三个来源：键位中心按设备分辨率搜现成方案 → 看软件给的推荐按键 → 都没有就一键生成。生成之后还有一步不能省：**用鼠标把每个虚拟按键拖到与游戏内按钮重合的位置**，没对准的按键按了不会有任何反应。

几个常用状态：

- **~ 键**在「鼠标当手指」和「视角控制」之间切换，射击类玩法平时停在视角控制状态，左键开火。
- **WASD** 默认传统模式走直线，识别发僵就换摇杆模式，它模拟手指滑动的曲线轨迹。
- **射击准星**摆在游戏界面里不会弹弹窗的空白区域（左上角最稳），位置不对鼠标就打不准。

## 第四步：调顺手

- 鼠标发卡：游戏鼠标驱动里调低回报率，常见组合是 DPI 1050 + 回报率 500Hz + 软件帧率 60FPS。
- 指针「飘」：Windows 鼠标设置里关掉鼠标加速。
- 画面卡顿：USB 3.0 通道、散热背夹、5GHz WiFi 逐项过；N 卡用户把控制面板里的「最大帧速率」设为显示器刷新率。

## 装好之后

装好只是开始，日常用得顺不顺看连接与键位这两关。从资源获取到每一步操作的细节，[TC Games 投屏玩手游说明站](https://tc-games.laze.skin/)里都有对应页面可以对照；工具本身的定位与适用人群，见 [真机投屏键鼠玩手游的工具.md](真机投屏键鼠玩手游的工具.md)。
