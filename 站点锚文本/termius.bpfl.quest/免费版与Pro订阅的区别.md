# Termius 免费版与 Pro 订阅的区别

> 很多人第一次打开 Termius 都会问：不订阅能不能用？这篇按公开的方案信息把两边的能力摊开，再给一个「什么时候值得升级」的判断思路。

## 一、先说结论

**单台手机、不跨设备的日常连接，免费版一直用下去没有问题。**SSH 连接、SFTP 传文件、端口转发、密钥管理、主机分组这些核心动作，免费版都包含。

## 二、两边能力对照

按产品公开的方案说明（Starter 免费档 / Pro 个人档）整理：

| 能力 | 免费版（Starter） | Pro 订阅 |
| --- | --- | --- |
| SSH 与 SFTP 连接 | 可用 | 可用 |
| AI 辅助命令补全 | 可用 | 可用 |
| 端口转发 | 可用 | 可用 |
| 本地密钥库（Local Vault） | 可用 | 可用 |
| 跨设备云同步主机与密钥 | 不含 | 含（个人云 Vault） |
| Snippets 自动化、会话日志 | 不含 | 含 |
| 团队共享 Vault、实时协作 | 不含 | 团队 / 企业档 |

一句话概括分界线：**单机能力免费，多设备协同与团队协作走订阅。**

## 三、怎么判断要不要升

三个问题自问：

1. **是不是两台以上设备要共用一份主机配置？** 电脑上配好的服务器列表和 SSH 密钥，希望手机打开就直接能用——这是订阅最典型、也几乎是唯一的刚需场景；
2. **经常在服务器间跑重复命令吗？** Snippets 自动化与会话日志对高频运维的人省力明显，偶尔登录看看的人用不上；
3. **设备丢了怎么办？** 免费版的密钥只存在本机，换机前要自己留好去处（导出备份或每台服务器的 `authorized_keys` 里多留一行公钥）。介意这一点，云同步确实是省心的方案。

三条都不沾，继续用免费版；命中第一条，再考虑按年付的 Pro 档。
