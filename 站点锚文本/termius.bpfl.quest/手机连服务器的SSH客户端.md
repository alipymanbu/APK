# 手机连服务器的 SSH 客户端怎么选

> 给「服务器在远处、人不在电脑前」的场景写的一篇综述：手机上远程运维需要哪些能力、Termius 在这类工具里处在什么位置、以及怎么判断它合不合适。

## 一、手机运维的真实需求

手机上连服务器不是把桌面终端缩进屏幕里，而是要处理三件更现实的事：

- **应急响应**：收到告警时先确认状况——看一眼负载、日志尾部、进程状态，多数时候并不需要完整的工作站环境；
- **碎片时间**：通勤路上改一行配置、重启一个服务、把测试环境的页面打开看看效果；
- **触屏操作**：没有实体键盘，Ctrl、Tab、方向键这些高频键要触手可及，长命令最好能存成片段一键发送。

所以选客户端时，重点看的不是协议列表多长，而是这几件事做得顺不顺手。

## 二、Termius 的定位

Termius 是一款跨平台 SSH 客户端，Windows、macOS、Linux、iOS、Android 全都覆盖，安卓端是本文关注的重点。它的思路是「把远程运维的整套家当装进一个应用」：

| 能力 | 在手机上的形态 |
| --- | --- |
| SSH / Telnet / Mosh / Serial | 主机列表点一下直连；Mosh 适合地铁、基站切换这类网络抖动场景 |
| SFTP 文件传输 | 双栏界面，一边手机一边服务器，选中即传 |
| 端口转发 | Local / Remote / Dynamic 三种规则，服务器上只监听 127.0.0.1 的服务映射到手机浏览器看 |
| 密钥管理（Keychain） | 应用内生成 ED25519 密钥、导入已有私钥、配 passphrase |
| Snippets 与补全 | 常用命令存成片段点一下发送；输入时自动补全命令与路径 |

主机可以按用途分组（生产 / 测试），列表管理在手机上不显得乱。

## 三、上手路径

流程很短：装上应用 →（可跳过账号登录）→ 在 Hosts 里添加第一台服务器（地址、端口、用户名、认证方式四样）→ 点条目连接，首次连接确认主机指纹即进入终端。

已经在电脑上用 Termius 的话，订阅了云同步的手机端登录同一账号就能带走主机列表与密钥；只用免费版就在手机上重新登记一遍，成本也不高。

想看完整的功能介绍与界面截图，可以到 [Termius 安卓版介绍站](https://termius.bpfl.quest/) 逛一圈，安装包获取入口也在那里。
