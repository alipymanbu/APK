# 直播卡顿换源与DNS设置经验

> 直播画面卡在缓冲圈、某个台点开是黑的、晚上黄金时段越看越卡——这些毛病的处理顺序，比处理手段本身更重要。这篇按「先分清、再动手」的思路整理一遍，配合 MeTV 这类多信号源直播应用使用效果最好。
> **相关文章**：[打开即看的电视直播应用怎么挑](打开即看的电视直播应用怎么挑.md) · [电视盒子装第三方直播软件分步做法](电视盒子装第三方直播软件分步做法.md)

## 一、先做两个动作，把问题定位到三分之二

遇到卡顿别急着动手，先做两个对比：

1. **换一个台**：别的台正常 → 问题在那个台，不在你的设备；所有台都不正常 → 问题在网络或设备本身。
2. **换一个网络**：用手机开热点让电视或盒子连上去试。一换就好 → 问题在原来的宽带，应用和频道都没毛病。

这两个动作做完，问题基本落进三种情况之一：

| 结论 | 表现 | 处理方向 |
| --- | --- | --- |
| 个别台不行 | 换台就好，或过一会儿自己恢复 | 不用管，换台看 |
| 所有台都不行 | 每个台都转圈或黑屏 | 按下一节的顺序查网络 |
| 只有某台一直黑 | 换源也没用 | 这一路源这个时段不通，隔天再试 |

## 二、多信号源：最省事的一招

MeTV 这类多源直播应用，给同一个频道备了不止一路信号源。所以绝大多数卡顿的处理方式就是**换一路源**：

- 画面卡在缓冲圈超过十秒不动 → 换；
- 点开是黑的、同类型其他台正常 → 换；
- 能播但画质糊得明显 → 换一路对比；
- 换台后迟迟不出画 → 等两三秒，还不行再换。

一个反面提醒：**别连着按换台键**。每次换台都是一次新连接，连按会让几路连接叠在一起抢带宽，越换越卡。选中一路，等它出画，不行再动。

## 三、网络层排查：从轻到重的六步

所有台都不行时，按这个顺序做，前一步管用就不用往后：

1. **退出应用重进**：界面卡住点了没反应，多半是应用自己的状态问题；
2. **换网络再试**：第一节的手机热点对比，能立刻分清是宽带还是应用；
3. **重启路由器**：长期不关的路由器掉速很常见，重启后经常好转；
4. **有线替无线**：电视和盒子能插网线的优先插网线——同一个宽带，无线和有线看高清台的差距经常很大；
5. **换 DNS**：下一节展开；
6. **看存储与设备年龄**：剩余空间太少缓存写不进，老盒子解码高清吃力，这两条只能降档或换设备。

## 四、换 DNS 具体怎么做

宽带 DNS 解析慢会拖住起播和换台。改法：

1. 进电视或盒子的「设置 → 网络 → 当前网络 → 手动设置」（有的机型叫高级设置）；
2. 把 DNS 从「自动」改成「手动」；
3. 主 DNS 填 `223.5.5.5`，备用填 `119.29.29.29` 或 `114.114.114.114`；
4. 保存后断开网络重连一次，回应用里换台对比。

找不到「手动设置」入口的话，在设置搜索里搜「DNS」通常能直接跳过去。这一条在大屏设备上收益明显，尤其原本用的是运营商默认 DNS 的时候。

## 五、几种容易误判的情况

- **晚上七八点特别卡，白天正常**：所在网络高峰期整体拥堵，不是应用坏了。这个时段降一档清晰度改善最直接；
- **刚打开那几秒卡，之后顺畅**：起播要建连接填缓冲，正常现象，不用处理；
- **只有高清台卡、标清台顺**：源码率差异，不是故障；高清台对带宽要求高，网络紧张时先看标清；
- **手机上看顺、电视上卡**：两者网络路径不同，电视无线信号弱就插网线，盒子太老则是解码问题；
- **昨天好好的今天全不行**：先换热点网络确认，很多时候是宽带当时的状况，不是应用变了。

## 六、小结

直播卡顿的处理心法就一句话：**先定位（换台、换网络），再动手（换源最优先），最后才轮到网络层（网线、DNS、路由器）**。顺序对了，大部分问题两分钟解决；顺序错了，重装十次也没用。这款应用的完整介绍与安装指引，见 [MeTV 大屏直播室](https://metv.bpfl.quest/)；设备安装的步骤细节，见 [电视盒子装第三方直播软件分步做法](电视盒子装第三方直播软件分步做法.md)。
