# 电视盒子装第三方直播软件分步做法

> 智能电视和安卓盒子出厂不自带电视直播应用，想装 MeTV 这类第三方直播软件，得靠 U 盘送进设备。这篇把整条流程拆开讲：授权、格式、拷贝、安装，一步一验。
> **相关文章**：[打开即看的电视直播应用怎么挑](打开即看的电视直播应用怎么挑.md) · [直播卡顿换源与DNS设置经验](直播卡顿换源与DNS设置经验.md)

## 一、装之前先备齐三样

- **一份安卓安装包**：apk 文件，从网盘取到电脑或手机上（MeTV 的安装包只有 15.99M，任何 U 盘都装得下）；
- **一个 U 盘**：容量不限，格式是关键，下一节讲；
- **电视或盒子的遥控器**：全程要用方向键和 OK 键。

设备方面确认一件事：系统版本不低于安卓 5.2。老盒子、老电视低于这个版本时，多半提示不兼容或装完闪退，不值得耗时间。

## 二、第一步：放行「未知来源」

安卓默认只允许从应用商店安装，第三方包会被拦。先去设置里放行：

1. 进电视或盒子的「设置」；
2. 找「账号与安全」「安全」或「通用」这类条目（各品牌叫法不同）；
3. 把「安装未知来源的应用」改为允许；
4. 记不住位置的话，在设置顶部的搜索框里搜「未知来源」，能直接跳到那一页。

这一步没做，后面点 apk 时会一直弹「已阻止安装」，是安装失败里最高发的原因。

## 三、第二步：把 U 盘格成 FAT32

U 盘格式直接决定电视认不认：

| U 盘格式 | 安卓电视 / 盒子上的表现 |
| --- | --- |
| FAT32 | 兼容性最好，优先用 |
| NTFS | 电脑认，很多安卓电视不认 |
| exFAT | 看设备，不如 FAT32 稳 |

操作：U 盘插电脑，右键 → 格式化 → 文件系统选 FAT32 → 开始。32G 及以下的 U 盘出厂多是 FAT32，可以直接用；64G 以上的常是 exFAT 或 NTFS，需要自己转。

「U 盘插上去毫无反应」的排查顺序：换一个 USB 口（优先机身背面，前置口供电常不足）→ 换一个 U 盘对照 → 重启电视再插一次。

## 四、第三步：拷包、插入、找到文件

1. 把 apk 拷到 U 盘**根目录**，不要放进多层文件夹——电视的文件管理器常常只展开一层，藏深了它就当不存在；
2. U 盘插进电视或盒子的 USB 口；
3. 多数设备会弹「检测到新的 USB 设备」，选「打开」；没弹窗就去「应用」或「我的」里找本地媒体、U 盘入口；
4. 找到那个 apk 文件。

个别品牌的自带文件管理器不给直接安装 apk，这时用电视上已有的第三方工具（欢视助手这类）进「管理 → U 盘 → 安装包」，在它的列表里点开同一个文件，一样能装。

## 五、第四步：安装与首启

1. 点 apk，按提示点「安装」，等进度走完；
2. 装完回桌面，能看到应用图标；
3. 点开，直接进直播画面——以 MeTV 为例，到这一步不需要任何账号，选台菜单一唤即出，按分类挑台就行；
4. 首次启动如果弹权限申请，网络与存储两项给上（不给的话频道加载不出、缓存写不进），其余不影响观看。

## 六、装完点开就退回桌面？

按顺序查：

- **系统版本**：低于安卓 5.2 的设备会闪退，这是硬件层面不够，无解，换设备；
- **解码能力**：特别老的盒子播高清台吃力，表现为能进界面但画面一出来就退，试试换标清台；
- **安装包本身**：重新取一次包再装，排除下载不完整的可能。

装好之后如果遇到换台卡顿、某个台黑屏，处理顺序见 [直播卡顿换源与DNS设置经验](直播卡顿换源与DNS设置经验.md)；这款应用本身的频道分类与使用门道，见 [打开即看的电视直播应用怎么挑](打开即看的电视直播应用怎么挑.md)，或直接看 [MeTV 大屏直播室](https://metv.bpfl.quest/) 整理的完整指引。
