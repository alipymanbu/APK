# 手机离线跑大模型可行吗

> 可行，而且门槛比想象中低：一台近几年的安卓手机加上一个几百 MB 到几 GB 的模型文件就能起步。这篇讲清楚可行性边界、适合的场景，以及从哪一步开始。

---

## 可行的前提是什么

手机离线跑大模型，靠的是三件事同时成立：

1. **模型被压缩到合适体积**。开源模型通常以量化后的 GGUF 格式分发，同一模型有不同精度的版本，体积从几百 MB 到数 GB 不等，精度低一档，体积和显存占用就小一截。
2. **推理引擎跑在手机上**。llama.cpp 这类端侧推理引擎已经把计算压到了消费级硬件能承受的水平，手机芯片就能完成推理。
3. **有现成的应用把这些打包好**。不用命令行、不用敲配置，应用内点几下就能把模型装进手机。

三者齐备之后，「断网对话」就成了常态功能：飞行模式下照样能问能答，只有换新模型时需要联网。

## 适合谁，不适合谁

| 场景 | 是否合适 |
| --- | --- |
| 隐私敏感的提问（记录、代码、私人事务），不想经过任何服务器 | 合适，对话全程不出设备 |
| 地铁、飞机、信号差的环境里需要随手问答 | 合适，推理在本地完成 |
| 需要最新资讯、实时联网检索的回答 | 不合适，本地模型没有联网能力 |
| 期望旗舰级大模型的完整能力 | 有落差，手机端通常跑小尺寸模型 |

一句话：它替代的不是云端顶级模型的「聪明程度」，而是「随时可用、绝对私密」这部分价值。

## 从哪一步开始

最省事的路径是装一个现成的手机端应用。[PocketPal](https://pocketpal.fedq.quest/) 就是为这件事做的开源应用：应用内直接搜索 Hugging Face 上的模型、下载后加载即可对话，界面有中文，安卓和 iOS 都有版本。装好后如果跑得不顺，可以接着看[手机跑大模型卡顿怎么办](手机跑大模型卡顿怎么办.md)。
