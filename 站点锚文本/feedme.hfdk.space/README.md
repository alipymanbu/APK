# FeedMe 介绍站

FeedMe 是安卓端的 RSS 聚合阅读应用：接入 Feedly、Inoreader、FreshRSS、Miniflux 等多种服务，支持全文离线、播客收听与 TTS 朗读。功能盘点、兼容服务对照与上手路径见 [FeedMe 介绍站](https://feedme.hfdk.space/)。
