# 已Root手机装Xposed框架的完整步骤

> 本篇给一条从零到激活的完整装机线：确认前提 → 分清两个包 → 装管理器 → 装框架本体 → 验证，含 KernelSU / APatch 用户的额外一步。
> **相关文档**：[Xposed模块在安卓14上还能用吗.md](Xposed模块在安卓14上还能用吗.md) · [装完模块开不了机怎么救.md](装完模块开不了机怎么救.md)

这类框架的装机坑不在「难」，而在「两个包分不清」：管理器 APK 只是操作界面，框架本体是 Root 管理器里的模块 zip 包，两者装齐才算能用。下面按顺序走。

## 一、先确认三条前提

1. **设备已 Root**，且装好了 Magisk（要求 v24 以上）或 KernelSU、APatch；
2. **系统版本在支持范围内**：以 1.9.x 这一支为例，支持安卓 8.1 到 14；
3. **Magisk 的 Zygisk 已打开**（设置里开，开了要重启一次才生效）。

三条有一条不满足，先去解决前提——框架装不上或装完不起作用，多数是前提没齐，不是步骤错了。

## 二、装管理器 APK（界面）

从网盘把管理器的安装包转存到手自己的网盘，再下载到手机安装。安装前在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的应用放行。包名以 `org.lsposed.manager` 为准，与随框架出现的管理器一致，属覆盖安装，升级或重装不丢设置。

装完先别急着下结论——这时候打开它，显示「未安装」是正常的，因为框架本体还没装。

## 三、装框架本体（模块 zip）

1. 取得对应环境的模块包：文件名带 `zygisk` 的对应 Zygisk 环境，带 `riru` 的对应 Riru 环境，**二选一**，装错的那支不会报错、只是不生效；
2. 把 zip 传进手机，Magisk → 底部「模块」→ 从本地安装；
3. 出现重启提示后重启；
4. 重启完成后状态栏会出现一条 LSPosed 通知，点它就能打开管理器，首页显示「已激活」即成功。

**KernelSU / APatch 用户**多一步：这两套 Root 方案本身不含 Zygisk，要先装一个提供 Zygisk 环境的模块（如 ZygiskNext），重启确认生效后再按上面的步骤装框架包。另外不要在 Magisk 和 KernelSU 里各装一份框架——两边同时启用模块会互相冲突，表现为其中一边永远显示未激活。

## 四、装完的最小验证

1. 管理器首页显示框架已激活；
2. 随便装一个模块 APK，回到管理器「模块」页，看它有没有出现在列表里；
3. 给模块勾一个作用域（挑个不重要的应用），重启该应用，观察效果有没有出现。

三步都通，说明链路是好的；之后按「能少勾一个作用域就少勾」的原则扩规模，稳得多。站点的功能介绍与界面截图见 [LSPosed 说明站](https://lsposed.bpfl.quest/)，作用域的勾法与排查思路也整理在那里。

## 五、出问题去哪查

- 管理器一直显示未激活：回看第一节的三条前提，重点查 Zygisk 是否被系统更新重置；
- 模块装了没反应：先查作用域与目标应用是否重启过；
- 重启卡在开机动画：别反复重启，按 [装完模块开不了机怎么救.md](装完模块开不了机怎么救.md) 的三条路径处理。
