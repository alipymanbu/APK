# 手机打印照片和文档

手机打印这件事，难点从来不在「按打印」那一下，而在三处：文件从哪来、参数怎么调、第一次打怎么不走弯路。这篇以 NokoPrint 为例，把三处一次说清。

## 一、能打哪些文件、从哪取

打印应用的文件来源比多数人以为的广：

| 来源 | 内容 |
| --- | --- |
| 手机相册 | JPG、PNG、GIF、WEBP 照片与图像 |
| 手机存储 | PDF、Word / Excel / PowerPoint 等常见文档 |
| 邮件附件 | PDF、DOC、XLS、PPT、TXT |
| 云端 | 网盘、Google Drive 里的文件 |
| 网页 | 内置浏览器打开后直接打印 |

一个省事的关键点：这类应用通常接入了系统的「分享」与「打印」菜单 —— 微信里收到的 PDF、邮箱里的登机牌，**长按 → 分享 → 选 NokoPrint**，不用先存到手机再打开应用找文件。

## 二、参数只动常用的那几项

按打印前会进参数与预览页，选项不少，真正常动就这几样：

- **份数与逐份打印**：发材料给一组人时用，多页多份选「逐份」省去手动理页；
- **页面范围**：长文档只要第 3~5 页这类场景；
- **纸张尺寸与类型**：换纸必改，照片纸要选对类型；
- **彩色 / 黑白**：纯文字页关掉彩色，既省墨又快；
- **双面**：页数多的材料选双面；
- **无边距**：照片打满整张纸不留白边，配光面或哑光照片纸用。

预览窗口能看到最终版面，页边距、裁切对不对先在这里确认，别直接浪费纸。

## 三、第一次打的推荐顺序

1. **先连打印机**：确保列表里已经有目标打印机（连接方式的选择见[手机怎么连打印机](手机怎么连打印机.md)）；
2. **打一页测试**：挑个一页的 PDF 试打，确认纸张尺寸、黑白设置无误；
3. **再加量**：测试页没问题后，再打正式的多页文件或照片。

## 四、打照片的两个高频坑

- **照片被裁掉一块，或缩得只剩中间一小块** —— 缩放方式没对上：调成「适应页面」，并核对参数里的纸张尺寸与实际放的纸一致；
- **照片四周有白边，想要满版** —— 打开「无边距」选项，它配光面或哑光照片纸才正常，普通 A4 上开容易边缘溢墨。

多张照片合成一页（证件照排版常用）在选图时就能设「每页张数」。

连不上打印机或列表为空，排查思路单独整理在[打印机搜不到怎么排查](打印机搜不到怎么排查.md)；功能总览与界面截图见 [NokoPrint 介绍站](https://nokoprint.fedq.ren/)。
