# 打印机搜不到怎么排查

打开打印应用，列表转了半天还是空的 —— 这是最常见的移动打印故障。原因九成出在网络与权限，按下面顺序过一遍，多数几分钟能解决。

## 一、快查清单：按顺序过

| 序号 | 检查什么 | 怎么处理 |
| --- | --- | --- |
| 1 | 手机是不是在用移动数据 | 切到打印机连的那个 WiFi |
| 2 | 打印机是不是在访客网络 | 手机与打印机必须在**同一路由器**下，访客网络通常隔离设备 |
| 3 | 位置 / 附近设备权限给了没有 | 系统应用详情里打开权限，把应用完全关掉重开再搜 |
| 4 | 打印机是不是在休眠 | 按一下机身任意键唤醒，部分机型休眠时不响应扫描 |
| 5 | 打印机自己连上网没有 | 打印机面板上看 WiFi 标志或网络状态，离线先重连 |
| 6 | 是不是偶发扫描失败 | 打印机、路由器各重启一次，再重新打开应用 |

第一到三条覆盖了绝大多数情况：以 NokoPrint 为例，WiFi 打印机的扫描依赖局域网广播，这三条任何一条不满足，列表就是空的。

## 二、自动搜索一直失败：手动按 IP 添加

打印机其实在网上、只是扫不出来时，可以绕过自动搜索：

1. **拿打印机的局域网 IP**：打印机面板进「设置 → 网络」这类菜单直接看（形如 192.168.1.x），或在路由器管理页的「已连接设备」列表里找；
2. 在打印应用里选**手动添加 / 按 IP 添加**，把 IP 填进去；
3. 添加成功后这台打印机会留在列表里，之后直接选用。

填了 IP 还是连不上，多半是打印机的 IP 被路由器重新分配过 —— 在路由器里给打印机绑一个固定 IP，一劳永逸。

## 三、蓝牙与 USB 的「搜不到」是另一回事

- **蓝牙打印机**：先到系统蓝牙设置里完成**配对**，再回应用里找；应用内搜不到多数是系统层没配对；
- **USB 直连**：插上没反应通常是线的问题 —— 部分充电线不带数据芯，外观一样但传不了数据；其次检查「允许访问 USB 设备」的授权弹窗有没有给。

## 四、实在不通就换路子

WiFi 这条路死磕不值得，两条兜底都便宜：

- 打印机有 USB 口 → 几块钱的 OTG 转接头走直连；
- 打印机插在电脑上 → 电脑开打印机共享，手机从局域网连。

连接方式的全面对照见[手机怎么连打印机](手机怎么连打印机.md)；连上之后的选文件与参数设置见[手机打印照片和文档](手机打印照片和文档.md)。功能界面与更多使用说明，见 [NokoPrint 介绍站](https://nokoprint.fedq.ren/)。
