# NokoPrint 使用介绍（nokoprint.fedq.ren）

NokoPrint 是一款安卓手机打印应用，手机通过 WiFi、蓝牙或 USB 直连主流品牌打印机，照片、PDF、Office 文档、网页都能直接输出。本目录围绕它的日常使用整理了几篇说明，安装包获取入口与功能速览见 [NokoPrint 介绍站](https://nokoprint.fedq.ren/)。
