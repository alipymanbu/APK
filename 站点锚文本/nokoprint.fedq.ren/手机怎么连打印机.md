# 手机怎么连打印机

安卓手机连打印机，常见就四条路子：WiFi 无线、蓝牙、USB 数据线直连、借电脑共享。以 NokoPrint 这类移动打印应用为例，四条路子各有适合的场景，选对了基本一次就通。

## 一、WiFi 连接：家里和办公室的首选

前提只有一条：**手机与打印机连同一个路由器**。连好后打开打印应用，它会自动扫描同一网络里的打印机，列表里点选即可。

两个容易翻车的点：

- 手机在用移动数据，或打印机连的是访客网络 —— 访客网络通常隔离设备，互相看不见；
- 打印机在休眠 —— 部分机型休眠时不响应扫描，按一下机身任意键再搜。

机身或包装上带 **AirPrint** 或 **Mopria** 标识的机型，走 WiFi 基本即搜即连。

## 二、蓝牙连接：便携打印机的主力通道

口袋热敏打印机、小票机、标签机多走蓝牙。顺序是先在**系统蓝牙设置里完成配对**，再回到打印应用里选它 —— 应用内搜不到时，多数是系统层还没配对，不是应用的问题。

## 三、USB 数据线直连：没网络也能打

一根几块钱的 OTG 转接头 + 打印机自带的 USB 方口线，就能把打印机直接接在手机上：

1. 先开打印机电源再插线；
2. 转接头接手机，USB 线接打印机；
3. 手机弹出「允许访问 USB 设备」时选允许 —— 这步不给，后面全白搭；
4. 回到打印应用，列表里会以 USB 方式出现这台打印机。

这条路子的价值在没有网络的环境：酒店、仓库、老打印机没有 WiFi 模块，都能靠它出纸。缺点是离机器近、占充电口。注意部分充电线不带数据芯，外观一样但传不了数据，插上没反应先换线。

## 四、电脑共享：打印机插在电脑上时

打印机本身不能联网、只插在电脑上时，在电脑系统里把打印机设为共享，手机与电脑连同一局域网后，打印应用可以从网络上找到它（Windows 共享走 SMB/CIFS，Mac/Linux 走 Bonjour/IPP/LPD）。

## 五、怎么选

| 场景 | 建议 |
| --- | --- |
| 家里、办公室，打印机支持无线 | WiFi |
| 口袋热敏机、小票机、标签机 | 蓝牙（先系统配对） |
| 没网络、老打印机没有无线模块 | USB 直连（OTG 线） |
| 打印机只插在电脑上 | 电脑开共享 |
