# 手机取色器怎么用

> 这篇讲安卓上用 Color Picker 取色的完整操作：相机对着实物实时取色、打开照片定点取色，以及让读数更稳的几个设置。应用的功能总览与安装包获取见 [Color Picker 取色工具](https://color-picker.wxhp.skin/)。

## 两条取色路子

- **相机取色**：打开应用就是相机画面，屏幕中央有个取色框，对准要测的位置，颜色名称和色值直接刷出来。适合测墙漆、布料、家具这类拿不走的实物。
- **图片取色**：把照片、截图在应用里打开，双指缩放拖动定位，点哪儿取哪儿。也可以在相册里选中图片点「分享」发给应用，直接进取色界面。图是固定的，读数比相机稳。

## 取色框的手势

- 在屏幕上滑动可以缩放取色框；
- 形状有圆、方、点三种：点只读一个像素，圆和方可以在「中心点颜色」与「区域平均色」之间切换；
- 表面有纹理、反光不均时（布料、墙面、木纹）选区域平均色，单点读数会一直跳。

## 让读数更稳的两个设置

| 设置 | 作用 |
| --- | --- |
| 对焦模式 | 没对上焦时读数发虚，手动锁焦更稳 |
| 白平衡 | 自动白平衡随环境光漂移，锁定后数值不飘 |

部分版本还提供曝光调节、手电筒补光，入口在相机设置页，以手机上实际显示为准。

## 取完之后

- 点保存，颜色进历史列表，随时重开查看；
- 详见与相近色在颜色详情页里，较新版本还带 Delta E 色差值；
- 想把照片里的颜色转成 CSS 能用的 HEX，接着读 [照片取色转HEX色值.md](照片取色转HEX色值.md)；对涂料色号的需求看 [涂料RAL色号对照查询.md](涂料RAL色号对照查询.md)。
