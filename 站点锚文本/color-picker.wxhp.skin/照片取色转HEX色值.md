# 照片取色转HEX色值

> 这篇讲把照片里的颜色取出来变成 HEX 色值的完整路子：适合设计对色、写 CSS、做配色方案的场景。Color Picker 应用的功能总览见 [Color Picker 取色工具](https://color-picker.wxhp.skin/)。

## 从照片到 HEX 的三步

1. 把照片或设计稿截图存进手机相册；
2. 在 Color Picker 里打开这张图（或在相册里点「分享」发给应用），双指缩放定位到目标位置；
3. 点一下，HEX 色值就出来了，形如 `#8DB600`，长按复制或用系统分享发出去。

比相机取色的好处：图是固定的，读数不会飘，适合需要精确值的场合。

## 拿到的数值各干什么用

| 数值 | 用在哪 |
| --- | --- |
| HEX | 写 CSS 直接粘贴，发给别人不容易错 |
| RGB | PS、Figma 里新建颜色时填 |
| HSL / HSV | 想手动调「更亮一点、更灰一点」时按这两个调 |
| CMYK | 印刷参考值，与实际印刷有偏差 |

同一颜色在 HSL 和 HSV 下数值差得很远——两个模型算法不同，对数值前先确认对方用的是哪套。颜色详情页还会给出库内相近色列表，找替代色时有用。

## 存起来复用

- 每取一色点保存，颜色进历史列表；
- 攒多了用 CSV 导出，Excel / WPS 打开就能把色值列贴进设计说明或配色清单；
- 换机迁移也是同一份 CSV，新手机上导入即可。
