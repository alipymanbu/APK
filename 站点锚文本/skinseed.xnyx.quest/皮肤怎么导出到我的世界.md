# 皮肤怎么导出到我的世界

> 本篇讲皮肤做完之后怎么送进《我的世界》：一键导出到国际服手机版和 PC 版、保存到相册后在游戏里手动选图，以及网易国服为什么走不通这两条路。
> **相关文章**：[皮肤编辑器玩法入门.md](皮肤编辑器玩法入门.md)

## 一、先看你玩的是哪个版本

| 你玩的版本 | 走哪条路线 |
| --- | --- |
| 国际服手机版（基岩/PE） | 路线一：App 内一键导出；不行再走路线二手动选图 |
| 国际服 PC Java 版 | 导出得到皮肤图片后，在账号页或启动器的皮肤入口上传 |
| 网易国服 | 两条路线都不适用，见第四节 |

## 二、路线一：一键导出

Skinseed 支持把当前皮肤直接导出到 Minecraft：皮肤详情页点导出按钮，选目标版本（手机版或 PC 版），下次进游戏角色就换上新皮肤了。这是最省事的走法，多数情况一次就成。

导出没反应、或进游戏皮肤没变，按这个顺序排查：确认导出动作真的完成（等完成提示再切游戏）→ 到游戏皮肤设置的「经典皮肤」分类里重新选一次 → 进地图走两步再看（主界面预览常不刷新）→ 重进游戏。

## 三、路线二：存相册再手动选图

一键导出不好使时，手动路线一定走得通——App 能把皮肤存成相册里的图片，而国际服手机版本身就支持从相册选图换肤：

1. 选中要用的皮肤，右上角三个点，选「保存至照片」；
2. 打开《我的世界》国际服，进主界面的皮肤设置页；
3. 切到「经典皮肤」分类；
4. 点空白槽位，选「选择新皮肤」；
5. 从相册选中刚存的那张图，等加载完成即可。

存出的图片就是标准皮肤文件，所以这条路同样通向 PC Java 版：图片传到电脑后，从启动器或账号页的皮肤上传入口加载即可。

两个游戏端的已知坑顺带一提：安卓基岩版有官方缺陷跟踪器记录在案的导入故障（文件明明是 64×64 仍提示尺寸不对）；"皮肤装上、退出设置又变回去"也有记录在案的案例。碰到这两种不是你操作错了，改用一键导出、更新游戏版本或过几天随版本修复再试。

## 四、网易国服：导出不适用

国服没有开放外部皮肤文件的直接加载，App 的导出目标里也不包含国服。想换形象只能走国服自己的组件中心；在 App 里画的皮肤可以先「保存至照片」留档，等玩国际服时再用。

## 五、换机与重装的保险

本地画的皮肤卸载即丢，两条保险提前做：登录账号让数据同步；重要皮肤逐张存相册留底。相册里的皮肤图就是标准文件，新设备上随时能重新导入。
