# 手机上写 JavaScript 是什么体验：Auto.js 的开发环境一览

> 本篇从「开发环境」的角度介绍 Auto.js：手机端编辑器、悬浮窗工具、连电脑协同、脚本打包——一部手机如何凑齐一整套自动化开发工具链。安装文件资源获取入口见 [auto.js 安卓版介绍站](https://auto-js.hhdc.tech/)。
>
> 相关文档：[无需 Root 的安卓自动化方案](无需Root的安卓自动化方案.md) 、[安卓自动签到脚本怎么写](安卓自动签到脚本怎么写.md)

## 编辑器就在手机里

Auto.js 自带的编辑器支持代码补全与语法提示，新建脚本、改代码、点运行，一气呵成。对碎片时间多、又想练手 JavaScript 的人来说，通勤路上改两行代码、马上看到手机自动动起来，反馈回路极短。

它的语法基于 JavaScript（4.1.x 版本基于 Rhino 引擎，支持 ES5 与部分 ES6 特性），有网页开发基础的人几乎零成本上手；纯新手也可以把它当作一门「立刻能看到效果」的 JavaScript 入门课。

## 悬浮窗：手机端的调试工具条

运行脚本时，屏幕边缘的悬浮窗是使用频率最高的入口：

- **录制**：手动操作一遍，自动生成脚本；
- **查看包名 / 活动**：一眼看到当前应用的包名与页面 Activity，写 `launch()` 时直接照抄；
- **布局分析**：类似 Android Studio 的 Layout Inspector，逐层查看界面控件树，选择器该写 `text()` 还是 `id()` 全靠它。

## 写大段逻辑？连电脑更舒服

手机屏幕上写几百行代码终究费劲。Auto.js 提供了 VS Code 插件：电脑上安装插件后，手机与电脑连入同一网络即可配对，代码在电脑上写、一键推到手机运行，还支持基本的远程调试。

配合侧边栏里的「连接电脑」「打开 USB 调试」开关，这套流程在社区教程里通常被称为「桌面开发模式」，是写复杂项目时的标准姿势。

## 写完还能打包成应用

配合打包插件，可以把脚本封装成独立的 APK：别人装上就能用，不需要再装 Auto.js 本体。把自己写的效率小工具分享给朋友，或者给自己做个专属的启动入口，都靠这一步。

## 学习资源去哪找

- 官方性质的文档与社区教程覆盖了绝大多数内置模块：文件操作、网络请求、对话框、多线程、图片处理都有对应章节；
- 社区里流传最广的是各类「场景脚本」：签到、抢课、批量改名，读别人的脚本是进步最快的路子；
