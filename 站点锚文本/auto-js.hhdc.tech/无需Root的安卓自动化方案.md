# Auto.js 是什么：无需 Root 的安卓自动化脚本工具

> 本篇讲清楚 Auto.js 的定位与工作原理：它是一款运行在安卓手机上的 JavaScript 自动化工具，靠系统无障碍服务实现界面操作自动化，全程不需要 root。想直接获取安装文件资源，可到 [auto.js 介绍站](https://auto-js.hhdc.tech/) 查看。
>
> 相关文档：[安卓自动签到脚本怎么写](安卓自动签到脚本怎么写.md) 、[手机上写 JavaScript 是什么体验](手机上写JavaScript脚本是什么体验.md)

## 它解决的是什么问题

安卓手机上有很多「路径固定、重复次数多」的操作：每天打开同一个应用点签到、把下载目录里的文件按规则归类、对着一张表单反复输入。这类活人做起来枯燥，机器做起来却极其擅长。

Auto.js 的思路是：让用户在手机上写一段 JavaScript，由它代替手指去完成这些界面操作。它自带脚本编辑器与运行环境，写完即跑，不必连电脑、不必刷机。

## 为什么不需要 Root

很多人一听「自动化」就以为要 root。Auto.js 走的是另一条路——安卓系统提供的**无障碍服务**（Accessibility Service）。

无障碍服务本来是给读屏、 switch Access 这类辅助功能用的系统接口，它具备两项关键能力：

- **读取屏幕上的控件**：能看到当前界面上每个按钮、输入框的文字、ID、描述；
- **代替用户执行操作**：点击、滑动、输入都可以由这个服务代为完成。

Auto.js 把这两项能力封装成了简单的 JavaScript 函数：`text("签到")` 找到屏幕上写着「签到」的按钮，`.click()` 就把它点掉。因为走的是系统正规通道，普通手机授权无障碍服务后即可使用，系统本身不被改动。

## 手机端能做的事

从社区里公开的功能清单看，这个工具在手机端提供了相当完整的开发体验：

- **脚本编辑器**：带代码补全，常用逻辑直接在手机上写；
- **悬浮窗快捷操作**：录制操作序列并回放、查看当前应用的包名与页面活动；
- **布局分析**：类似 Android Studio 的 Layout Inspector，能查看界面控件结构；
- **选择器 API**：按文字、ID、描述定位控件，支持遍历与取值，思路接近 Google 的 UI 自动化测试框架；
- **连接电脑**：配合 VS Code 插件，在电脑上写代码、推到手机上运行。

## 版本脉络，一图理清

搜索资料时常见 4.1.1、AutoX、AutoJs6 混在一起，简单理一下：

1. 2017 年 1 月，开发者 hyb1996 发布 Auto.js；
2. 2020 年 3 月，原项目停止维护，最后的免费开源版本是 4.1.1 系列（MPL-2.0 协议）；
3. 此后社区在其开源代码上延续出 AutoX、AutoJs6 等分支，继续适配新系统。

对新手而言，4.1.1 版本教程多、上手快，至今仍是常见的入门选择。
