# 直播源和节目单怎么配

> 让 TVBox 变成一台「直播应用」的不是别的，正是接口里带的直播源；而频道旁那栏「现在播什么、接下来播什么」，靠的是 EPG 节目单。这篇把两者的来龙去脉理一遍。
> **相关文档**：[空壳播放器是什么意思](空壳播放器是什么意思.md) · [电视盒子怎么安装应用商店外的软件](电视盒子怎么安装应用商店外的软件.md)

## 一、直播能力从哪里来

TVBox 支持电视直播：当接口配置里包含直播源时，应用内就会出现频道列表，CCTV、卫视频道按序排列，遥控器直接换台——体验上相当于集成了一台直播应用。

反过来说，接口里没有直播源，这能力就处于「待机」状态。直播内容的有无与质量，完全取决于所用接口的整理者，这也是社区里大家反复比较不同接口的原因。

## 二、EPG 节目单是什么

EPG 全称电子节目指南（Electronic Program Guide），就是频道列表旁边展示「现在播什么、接下来播什么」的那块信息。

早些年网上有不少公开维护的 EPG 服务，填个链接就能用；但这类服务跑在别人的服务器上，到期、停更、流量见顶都会让它失效——不少玩家遇到过「节目单突然全空」的情况，多半就是源头下线了。所以 EPG 也是随接口一起配置的一枚地址，失效了换一枚即可。

## 三、播放端的几个顺手设置

直播之外，播放器本身的设置也值得过一遍：**切换解析线路**能在一条线路卡顿时换另一条；**倍速播放**与**跳过片头片尾**是追剧刚需；外挂字幕放进同目录就能导入加载。这些能力都是壳自带的，与接口无关。

把接口、直播源、EPG 三样配齐，一台普通盒子基本就能顶替专门的应用了。整套流程的图文版，可参考这篇 [TVBox 介绍与安装指引](https://tvbox.fewz.tech/)；接口配置的原理则见《空壳播放器是什么意思》。
