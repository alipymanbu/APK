# TVBox 介绍与使用资料

围绕 TVBox（GitHub 上公开的开源大屏播放器）整理的第三方资料：它为什么装完是空的、接口机制怎么运作、电视盒子怎么把它装上去、直播与节目单又怎么配。更多图文入口见 [TVBox 介绍站](https://tvbox.fewz.tech/)。

## 本目录文章

- [空壳播放器是什么意思](空壳播放器是什么意思.md) —— 装完打开是空界面，不是装坏了
- [电视盒子怎么安装应用商店外的软件](电视盒子怎么安装应用商店外的软件.md) —— U 盘与推送两条送达路线，未知来源权限一次讲清
- [直播源和节目单怎么配](直播源和节目单怎么配.md) —— 直播能力与 EPG 节目单都来自接口

> 本目录为第三方整理的公开资料，与该开源项目及其衍生版本的开发者无隶属关系；安装文件资源一律以介绍站内标注的网盘入口为准。
