# 设备兼容与日常程序玩法：SmartThings 接入与自动化要点

> 本篇讲两类高频问题：什么设备能加进 SmartThings、怎么把已接入的设备串成自动执行的日常程序。
> **相关文档**：[全屋智能中控应用介绍.md](全屋智能中控应用介绍.md) · [安卓版获取与安装步骤.md](安卓版获取与安装步骤.md)

---

## 一、设备能不能接入，看三条标准

买设备前对照包装或详情页的标识，占任意一条就能接入：

| 接入途径 | 认什么 | 说明 |
| --- | --- | --- |
| 生态徽标 | Works with Samsung SmartThings | 带标识的设备开箱直连 |
| Matter 标准 | Matter 兼容标识 | 灯、插座、传感器、摄像头等跨品牌设备大多能接 |
| HCA 标准 | Home Connectivity Alliance | 符合标准的家电与电视不限品牌可接入 |

还有一笔账可以省：2022 年之后发布的三星电视、Family Hub 系列带屏冰箱、SmartThings Station 充电板底座，本身就内置网关功能——家里有任意一台，单独买网关的钱就省了。

## 二、加设备的路径

- **自动发现**：手机连上家里 Wi-Fi、靠近通电的新设备，屏幕会自动弹出注册窗口，选好位置和房间即可。
- **手动添加**：自动弹窗没出现就走「添加 → 设备 → 按品牌」，选品牌与设备类型后按提示操作；电视类设备会要求在电视上确认并输入屏幕显示的 PIN 码。
- **邀请家人**：二维码、账号邮箱、分享链接三种方式效果一样，接受后控制的是同一批设备，上限 20 名成员。

搜不到设备时按命中率排查：手机和设备是否连同一个 Wi-Fi（部分路由器 2.4G 与 5G 频段隔离会互相看不见）→「位置」与「附近设备」权限是否都给了 → 手机是否离设备太远。设备频繁离线的另一个高频原因是路由器只开了 5GHz——很多智能设备只认 2.4GHz，进路由器管理页把 2.4GHz 打开即可。

## 三、日常程序：让家里自动干活

日常程序（Routines）的公式很简单：**触发条件 + 执行动作**。

- 触发条件支持四类：时间（工作日七点）、设备状态（门磁打开）、天气（下雨）、位置（到家 / 离家）。
- 动作可以是多台设备的多个操作：开灯、调温、播放内容、启动清扫。
- 保存后程序常驻后台，条件满足自动执行；也可以手动点一下立即运行来验证动作对不对。

几个容易落地的组合：位置离开家 → 关掉不需继续运行的电器；位置回到家 → 空调调到惯用温度；工作日固定时间 → 打开电视。应用还会根据你已接入的设备主动建议新程序，第一次配完设备去建议列表翻一翻，比自己从零搭快。

程序还能一键共享：把生成的分享内容发给同样在用 SmartThings 的家人，对方接受即获得同一套配置。
