# MITO 影视应用站点目录

这里收录围绕 MITO（一款安卓手机上的影视聚合应用）整理的第三方介绍与使用短文。它把电影、连续剧、动漫、综艺、短剧分区陈列在一个应用里，靠搜索、分类与热度榜单三条路找片，支持多线路切换与离线缓存。

想先看它的功能盘点、界面截图与使用提示，可以到 [MITO 影视应用介绍站](https://mito.fedq.quest/) 细读；目录里的几篇短文则分别回答「怎么挑、怎么缓存、卡了怎么办」三件高频的事。
