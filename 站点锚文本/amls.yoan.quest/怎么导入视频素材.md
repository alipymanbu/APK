# amls 怎么导入视频素材

> 本篇讲 amls（凉笙版）里把手机中的视频、图片、音乐导入工程的完整路径，以及存储权限没弹、导不进时的排查。
> **相关文档**：[卡点视频制作流程](卡点视频制作流程.md) · [导出失败与卡顿怎么办](导出失败与卡顿怎么办.md)

amls 的剪辑从建工程开始，素材进得来才有后续。还没装好的，先到 [amls 凉笙版介绍站](https://amls.yoan.quest/) 看下载与安装步骤。

## 一、建工程

1. 打开应用，点首页底部中间的蓝色添加按钮；
2. 输入工程名称，选比例（竖屏 9:16 / 横屏 16:9 / 方形 1:1）、分辨率与帧率；
3. 点「创建工程」进入编辑页。

比例按发布平台定好再动手，建完再改等于重排版面。

## 二、导入的六步

1. 编辑页点右下角的「笙」图标；
2. 弹出插入面板，分「媒体、音频、形状、手绘、矢量图层」几类；
3. 手机里的视频和图片走「媒体」入口（部分版本默认停在「音频」标签，手动切一下）；
4. 首次导入会弹「允许访问」，点允许，让应用读取手机存储；
5. 在文件选择器里找到要导的视频；
6. 点选后素材落到时间线，导入完成。

原始素材在成片导出前先别删，避免工程里的引用失效。

## 三、权限被拒或弹窗不再出现

存储权限是导入一切素材的前提，弹窗点过拒绝后应用一般不会主动再问：

1. 系统设置 → 应用管理 → 找到 amls；
2. 权限 → 存储 / 照片和视频 → 改为允许；
3. 回到应用重新走一遍导入。

## 四、还是选不到文件

改完权限仍选不到，多半不是权限问题：换一个视频试一下，能加进来说明原来那份格式或编码不识别，先转码再导；素材落到时间线上黑屏花屏的，是源文件损坏，重新取一份。

导入之后怎么让素材动起来，见[卡点视频制作流程](卡点视频制作流程.md)；工程太重导不出片的，见[导出失败与卡顿怎么办](导出失败与卡顿怎么办.md)。
