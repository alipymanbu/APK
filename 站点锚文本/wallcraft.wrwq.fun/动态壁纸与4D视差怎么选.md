# 动态壁纸与 4D 视差怎么选

> 本篇讲安卓动态壁纸的几种常见形态（视差 4D、Live 动态、视频壁纸）各自的呈现原理与耗电差别，以 Wallcraft 里提供的类型为例，帮你按「想要的动感 × 愿意付出的电」做选择。
> **相关文档**：[手机壁纸分辨率与清晰度.md](手机壁纸分辨率与清晰度.md) · [自动更换壁纸设置技巧.md](自动更换壁纸设置技巧.md)

想给手机换上「会动」的壁纸，最先碰到的不是挑哪张图，而是分清几种动态形态的差别。以壁纸应用 Wallcraft 为例，它的动态类型可以分为三层，耗电与效果逐级递增。

## 一、视差 4D：省电的「动感」

视差（Parallax）图本身仍是一张静态图，动感来自陀螺仪：手机倾斜或滑动桌面时，图面按传感器数据产生位移景深。它的耗电来源只是传感器持续采样，远低于持续渲染动画的类型，适合当常驻主屏壁纸。

两个使用提示：

- 个别关掉传感器或开启皮套模式的机型上，4D 效果会打折，图不动了先查系统传感器设置；
- 想要更明显的立体观感，选前景与背景层次分明的图，效果比大平面的风景图强。

## 二、Live 动态与视频：氛围感换电量的买卖

Live 动态壁纸与视频壁纸在亮屏期间持续渲染动画，是所有形态里最耗电的。它们的合理位置是锁屏——锁屏只在亮屏瞬间展示，把最耗电的类型放在曝光最短的地方，氛围与电量可以兼得；主屏则交给静态或视差图。

省电组合可以记成一句：**动态效果只给锁屏，主屏用静态**。OLED / AMOLED 屏优先选暗色系，黑色区域几乎不发光，整机功耗还能再降一截。

## 三、组合型玩法：Double 与 24h

除了「单张图动起来」，还有两种组合形态值得一提：

- **Double 双屏成对**：锁屏与主屏两张图成对设计，解锁前后画面衔接统一；它是两张静态图，不需要持续渲染，耗电特征接近普通静态图；
- **24h 时段变化**：一组图按一天的时间段切换，早晚屏幕不一样，同样不需要常驻渲染。

这两类适合喜欢「有变化又不想费电」的用户，是静态与纯动态之间的中间档。

## 四、一条选择路径

按使用场景总结：

1. 主力机日常 → 静态或 3D 图，设置完由系统接管，几乎无感；
2. 想要「会动」又不心疼电 → 视差 4D；
3. 锁屏要氛围 → Live 动态或视频，主屏保持静态；
4. 要变化但怕耗电 → Double 或 24h。

各形态在应用里的具体设置入口与更多省电细节，可以看 [Wallcraft 导览站的形态对比](https://wallcraft.wrwq.fun/)；换壁纸后若出现屏幕发黑、耗电异常，先从系统图层与壁纸类型两方面排查，多数与应用本身无关。
