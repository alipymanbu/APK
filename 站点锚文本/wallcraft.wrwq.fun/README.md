# Wallcraft 导览：壁纸形态、分辨率与安装资源索引

这里是 Wallcraft（安卓壁纸应用）的第三方介绍索引：这款应用按设备屏幕分辨率筛图，静态、视差 4D、Live 动态、视频等形态齐全，还支持自动更换与聊天 / 键盘背景。应用介绍站（含安装文件资源入口）见 <https://wallcraft.wrwq.fun/>。

## 一句话背景

Wallcraft 由 WallpapersCraft 团队开发（包名 `com.wallpaperscraft.wallpaper`），在第三方应用市场的安装量以亿计。它的特色是「先认屏幕再给图」：识别设备分辨率后只展示尺寸匹配的壁纸，配合人工裁剪，基本免去手动调整裁剪框的麻烦。

更多形态对比、免费与 PRO 的能力边界、常见问题排查，见 [Wallcraft 导览站](https://wallcraft.wrwq.fun/)。
