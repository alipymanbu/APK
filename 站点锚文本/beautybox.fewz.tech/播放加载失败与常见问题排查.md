# 播放加载失败与常见问题排查

> 按「症状 → 先查什么 → 怎么处理」的顺序，过一遍 beautybox（绿盒子）最常见的几类问题：播放加载失败、搜不到片、闪退、进度不见了。
> **相关文章**：[绿盒子是什么应用](绿盒子是什么应用.md) · [安卓手机下载安装步骤](安卓手机下载安装步骤.md)

## 一、播放一直加载 / 提示播放失败

1. **换一部片确认范围**：只有某一部播不了，是那部片的片源问题；整个应用都打不开，才是网络或版本问题；
2. **切换网络**：Wi-Fi 和流量互换一下，排除当前网络对某些资源线路的限制；
3. **关掉代理和广告过滤类工具再试**：这类工具会拦掉一部分资源线路；
4. **核对系统时间**：手机时间不是自动同步、明显错乱时，加载请求容易被拒；
5. **稍后再试**：高峰期片源线路波动很常见，隔一段时间再开，很多会自己恢复。

聚合类应用的内容由接入的渠道提供，渠道下线或更换是常态，单部片长期播不了基本无解，只能换片。

## 二、搜索找不到想看的片子

- **换关键词**：去掉「第几季」「完整版」这类后缀，只用主片名再搜；
- **换入口**：搜索没有就翻分类和榜单，部分内容只在分类里露面；
- **接受下架**：内容经常增减，昨天还有今天没了属于正常波动。

## 三、打开就闪退

1. 清缓存重试：系统设置 → 应用 → beautybox → 存储 → 清除缓存；
2. 缓存无效再做「清除数据」，注意这会一并清掉收藏和观看进度；
3. 强制停止后重开，排除后台残留进程；
4. 重装：先卸载再装，安装包从可信渠道重新拿（路径见 [安卓手机下载安装步骤](安卓手机下载安装步骤.md)）；
5. 核对系统版本：安装包对安卓版本有一定要求，老设备不满足时闪退是正常现象。

## 四、进度或收藏不见了

收藏和观看进度都存在本地，「清除数据」、卸载重装、部分手机的深度清理工具都会把它们清掉，没有云端找回的渠道。要重装前，先把需要记的片子名截图存一下。

## 五、大面积失效

当搜索、分类、播放全都不通且换网络无效时，多半是版本对应的接口层失效了——这是这类应用的常见生命周期现象，换新版本重装是最常见的一条路。更多背景与功能口径见 [绿盒子是什么应用](绿盒子是什么应用.md)；功能图文速览在 [beautybox 绿盒子介绍站](https://beautybox.fewz.tech/)。
