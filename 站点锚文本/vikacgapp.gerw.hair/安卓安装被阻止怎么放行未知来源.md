# 安卓安装被阻止怎么放行未知来源

从网盘下载 APK 装应用，十有八九会在最后一步碰上「禁止安装」弹窗。这不是安装包有问题，而是安卓对商店外安装包的默认防线——放行一次就能装，不同品牌的路径略有差异。

## 先确认弹窗是哪种

常见的是两种提示：「出于安全考虑，已禁止安装」和「安装包解析失败」。前者是权限没放行，照下面的路径处理；后者是文件没下完整，回到网盘重新下载一遍再装，反复点安装没有用。

## 各品牌的放行路径

- **小米 / 红米（MIUI、澎湃 OS）**：设置 → 隐私保护 → 特殊权限 → 安装未知应用，找到你用来打开 APK 的浏览器或文件管理器，允许「安装未知应用」。
- **OPPO / 一加（ColorOS）**：设置 → 安全与隐私 → 更多安全设置 → 安装外部来源应用，按应用逐一放行。
- **vivo（OriginOS / Funtouch）**：设置 → 安全 → 更多安全设置 → 安装未知应用，选中对应应用打开开关。
- **华为 / 荣耀（HarmonyOS、EMUI）**：设置 → 安全 → 更多安全设置 → 安装外部来源应用，按需放行。
- **原生安卓 / 其他品牌**：设置 → 应用 → 特殊权限 → 安装未知应用，路径大同小异。

放行只针对单个应用，装完想收回权限，回到同一位置关掉开关即可。

## 装完之后

第一次打开维咔这类社区应用，通常会有推荐设置向导和邮箱注册流程，跟着走完就能进社区。装之前想了解这个应用是什么、值不值得装，可以先读这份 [VikACGapp 介绍](https://vikacgapp.gerw.hair/)；入站之后积分签到怎么玩最划算，见[二次元社区App积分签到怎么玩](二次元社区App积分签到怎么玩.md)。

还有一条老规矩值得记住：核对包名。装完进「设置 → 应用管理 → 应用详情」看一眼包名是不是 `com.sailoud.vikacg`，对得上才算装对了正主。
