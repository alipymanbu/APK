# 服务来源与API密钥配置

> AIRI 装完发消息没反应，十有八九是还没接"大脑"。这篇讲服务商怎么选、API Key 和端点地址填在哪、模型怎么挑，以及 Key 的安全习惯。安装环节的问题不在这里。
> **相关文档**：[安卓版下载安装与首次启动配置.md](安卓版下载安装与首次启动配置.md)

---

## 一、为什么装完不能聊

AIRI 的形象、动作、语音这些"身体"是本地的，理解和生成回复依赖外部的大语言模型服务。没配服务商时，发消息不会有任何回应——这不是卡住，是结构如此：它本身不带大模型，"大脑"由你决定接哪家。

第一次打开 App 时，初始化引导就会带你走一遍配置（选语言后点"配置您自己的 AI 服务来源"）；如果当时跳过了，进设置找到"服务来源"一栏随时可以补。还没装到这一步的话，[AIRI 安卓版介绍](https://airi.fewa.skin/)里有完整的下载安装流程。

## 二、服务商怎么选

初始化界面里能选的来源不少，按你的情况对号入座：

| 接入方式 | 适合谁 | 需要准备 |
|---|---|---|
| OpenAI 兼容接口 | 手里有任意兼容 OpenAI 格式的 Key（聚合站、中转站大多是这个格式） | API Key + Base URL |
| OpenRouter | 想用一个 Key 切换多家模型 | OpenRouter 的 API Key |
| Ollama（本地） | 不想把对话发给云端，电脑上跑得动本地模型 | 本机已启动 Ollama 服务 |
| Gemini / Claude / DeepSeek 等 | 有对应服务商的账号与 Key | 对应服务商的 API Key |

两点补充判断：

- **OpenAI 兼容接口是万能兜底。** 国产厂商大多提供这种格式的端点，只要拿到 Key 和 Base URL 两个值就能填；不确定选哪个时，先从你已经有账号的那家开始。
- **先想成本再选型。** 云端按调用量计费，各厂商价格差异不小；Ollama 本地路线不产生按量费用，但回复速度取决于设备性能。

## 三、配置就四步

1. 在服务来源列表里选中要用的服务商，点"下一步"；
2. 填入 API Key；选"OpenAI 兼容"类型的话还要填 Base URL（服务商接口文档里通常能直接复制）；
3. 点"下一步"进入模型列表；
4. 挑一个模型，点"保存并继续"。

保存后回主界面发一句话，有回复就通了。

## 四、模型怎么挑

模型列表里的名字都来自你配置的服务商，两个实用建议：

- **优先选不带"思考"的普通对话模型。** 带推理（reasoning）的模型生成回复要等更久，日常闲聊体验差一截。
- **想让她画画要留意工具调用。** 之后打算用图片生成的话，聊天模型必须支持工具调用（Tool Calling），否则只会回文字。选型前在服务商那边确认这个能力。

另外，每张角色卡都能在自己的"模块"设置里单独指定服务商和模型——养两张卡：一张绑便宜快速的模型日常闲聊，一张绑能力更强的模型处理复杂请求，切卡即切换整套配置，不用反复进设置改。

## 五、Key 的安全习惯

- API Key 只保存在你自己的设备里，凭据不经过第三方服务器，这是 AIRI 的设计方式。
- 别把 Key 截图、贴群、发到任何公开场合——泄露等于把你的账户送给别人刷。
- 怀疑泄露就立刻去服务商后台吊销重开，再到设置里替换新 Key。
