# 安卓版下载安装与首次启动配置

> 这篇写给想在安卓手机上装 AIRI 的人：装之前要知道的两件事、四步装完、以及第一次打开后必做的两项配置。装完不能聊的问题在另一篇里展开。
> **相关文档**：[服务来源与API密钥配置.md](服务来源与API密钥配置.md)

---

## 一、装之前先知道两件事

**第一，AIRI 本身不带大模型。** 它是一个开源的 AI 虚拟角色应用：Live2D / VRM 形象、语音、记忆这些"身体"部分都跑在你的设备上，负责思考和回复的"大脑"要你自己接入一个大模型服务。所以装完打开、发消息没反应，不是坏了，是还差一步配置——怎么配见[服务来源与API密钥配置.md](服务来源与API密钥配置.md)。

**第二，它仍在快速开发中。** 手机端目前覆盖的是日常链路：文字聊天、角色卡、形象显示、语音交互；游戏联动、聊天机器人这类能力现阶段主要在桌面端或需要从源码运行。把预期放在"一个随身的数字伙伴"上，体验是完整的。

## 二、安装包从哪拿

获取入口已经整理在 [AIRI 安卓版介绍](https://airi.fewa.skin/)站的下载页里：页面上的"获取安装文件资源"按钮会带你去网盘分享页，先转存到自己的网盘，再从网盘客户端下载到手机——不转存直接下载有时会受限，先转存最稳。

安装包不小（两百兆上下这一版），下载和安装都比小应用慢一点，属正常现象。版本更新快，以你拿到手的包为准。

## 三、四步装好

1. **转存并下载**：按上面说的流程，把安装文件落到手机存储里。
2. **放行"安装未知应用"**：安卓默认只信任应用商店。在系统设置里搜索"安装未知应用"或"特殊权限"，给用来下载的浏览器或文件管理器授予"允许安装应用"。
3. **点开安装**：在下载目录找到 .apk 文件点开确认；提示"此应用未经过验证"时继续即可，这是非商店渠道安装包的常规提示。
4. **首次启动**：见下一节，还有两件事要做。

## 四、第一次打开后的两件事

1. **选界面语言**：欢迎页右上角的地球图标就是语言菜单，英语、西班牙语、法语、日语、韩语、俄语、越南语、简体中文、繁體中文共九种，选"简体中文"即可。
2. **接上大脑**：欢迎页下方有两个入口——"登录"（用开发者提供的模型服务）或"配置您自己的 AI 服务来源"（自己填服务商和 Key）。选后者的话，流程是：选服务商 → 填 API Key → 选模型 → 保存。每一步怎么填、服务商怎么挑，[服务来源与API密钥配置.md](服务来源与API密钥配置.md)里逐项展开。

配完回到主界面发一句话，有回复就说明通了。安装那一步被系统拦下来，多半是第 3 步的权限没放行，回到设置补一次授权再装即可。
