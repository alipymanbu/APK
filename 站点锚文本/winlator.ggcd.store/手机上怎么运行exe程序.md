# 手机上怎么运行 exe 程序

> exe 是给 Windows x86 体系写的可执行文件，安卓手机是 ARM 芯片，两者指令集不同，所以 exe 不能像 APK 那样直接点开。本篇讲清手机运行 exe 的可行路径、原理与门槛。
> **相关文档**：[安卓玩电脑老游戏要什么配置.md](安卓玩电脑老游戏要什么配置.md)

## 一、先弄明白为什么打不开

电脑上的 exe 文件里是 x86 / x86_64 指令，还会调用 Windows 系统的 API；安卓手机用的是 ARM 指令集，系统内核也不是 Windows。直接双击 exe，安卓只会把它当成一个不认识的文件。想在手机上跑起来，中间必须有一层"翻译"：把 Windows API 调用换成安卓能接受的调用，再把 x86 指令逐段翻译成 ARM 指令。

## 二、目前主流的几条路

- **兼容层方案（推荐先试）**：以开源项目 Winlator 为代表，它把 Wine（API 转译）和 Box64（x86_64 转 ARM64 指令）打包成安卓应用，程序装进隔离的"容器"里运行，全部计算发生在手机本机，不联网也能用，也不需要 root。想直接看安装与上手过程，可以到 [Winlator 说明站](https://winlator.ggcd.store/) 看真机界面与步骤说明。
- **远程串流 / 云电脑**：程序实际跑在另一台电脑上，手机只负责画面传输。画质受网络影响，离开网络就没法用，但本机性能不足时它是备选。
- **模拟整机虚拟机**：在手机上模拟一台完整电脑。开销大、配置繁琐，中端机型体验普遍不好。

## 三、兼容层方案要满足什么条件

不是每台手机都装得动，动手前对照三点：

1. **系统与芯片**：Android 9.0 起，64 位 ARM 芯片；骁龙机型（Adreno GPU）兼容性最好。
2. **图形支持**：Vulkan 1.1 以上，整个图形转译栈都建立在它上面。
3. **内存与存储**：内存 4GB 起步（跑 3D 内容建议 6–8GB），存储预留 5GB 以上。

## 四、能跑什么要有预期

DirectX 9 时代的老游戏和 Windows 工具软件是兼容层表现最好的场景；较新的 3D 内容要看机型性能；重度 DirectX 12 的东西目前还不稳。同一份程序在手机上的帧率低于电脑属正常——翻译指令本身就有开销。装好之后第一步是建一个低分辨率容器试跑，跑得起来再往上加要求。
