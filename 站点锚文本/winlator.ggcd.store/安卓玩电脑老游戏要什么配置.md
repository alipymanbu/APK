# 安卓玩电脑老游戏要什么配置

> 想在安卓手机上玩那些 Windows 时代的电脑老游戏，关键不在"游戏有多老"，而在手机能不能扛住实时转译的开销。本篇按芯片、内存、存储、系统四项说清门槛，并给出试跑顺序。
> **相关文档**：[手机上怎么运行exe程序.md](手机上怎么运行exe程序.md)

## 一、先看芯片：骁龙为什么被反复点名

目前最成熟的方案是开源的 Winlator：它用 Wine 处理 Windows API、Box64 把 x86_64 指令翻成 ARM64，图形则经 DXVK 一类组件转成 Vulkan。骁龙处理器的 Adreno GPU 有专门的 Turnip 驱动，是兼容性最好的一档；Mali 芯片的机型可以改用 Vortek 或 VirGL 驱动，能用，但效果弱一档；麒麟机型因为 Vulkan 支持的短板，社区普遍反馈难以稳定运行。

## 二、四项配置的参考线

| 项目 | 底线 | 舒服线 |
| --- | --- | --- |
| 系统 | Android 9.0 | Android 11 及以上 |
| 内存 | 4GB | 6–8GB |
| 图形 | Vulkan 1.1 | Vulkan 1.1 以上 |
| 存储 | 预留 5GB | 更多——容器里每装一个游戏都要占空间 |

这张表是社区与评测资料里的经验值。底线配置适合跑 DirectX 9 时代的 2D 与早期 3D 游戏；想碰 DX9–DX11 的 3D 游戏，直接按舒服线找机型。

## 三、老游戏也分三六九等

- **最稳的一档**：DirectX 9 时代的 2D 游戏和早期 3D 游戏；更老的 DirectDraw 游戏还有专用包装器兜底。
- **看机型的一档**：DX9–DX11 的 3D 游戏，骁龙中高端（845 及往上）多数有可玩帧率。
- **先别碰的一档**：重度 DirectX 12 内容与帧数敏感的联网对战——前者支持还是实验性质，后者会被转译开销拖垮。

## 四、试跑顺序比调参更重要

同一个游戏在不同机型上表现差异极大，别人的结论只能当参考。靠谱的做法：装好 Winlator 后先建一个 1280×720 的默认容器，把游戏文件放进去跑十分钟，稳定了再逐步调高分辨率、换图形驱动、动 Box64 预设。具体每一步在哪个界面操作，[Winlator 安卓版说明站](https://winlator.ggcd.store/) 里有真机截图对应着讲。
