# RikkaHub 安卓 APK 安装步骤与常见问题

> RikkaHub 只出 Android 版，国内应用商店里搜不到，装 APK 是主要方式。本篇讲从拿到安装包到装进手机的四步，以及装不上时最常见的几种情况。
> **相关文档**：[怎么配置API密钥和服务商.md](怎么配置API密钥和服务商.md) · [助手记忆与MCP工具用法.md](助手记忆与MCP工具用法.md)

## 一、装之前先知道三件事

- RikkaHub 是一款开源的安卓 AI 聊天客户端（AGPL-3.0 许可，源码在 GitHub 上），本身不带模型，装好后要自己填服务商的 API 密钥；
- 开发者提醒过：网上有大量 RikkaHub 的分叉改版，出问题没人负责还可能索要多余权限，装包认准可靠来源；
- 没有 iOS 版，网上声称 iPhone 能装的包基本都是假冒的，别碰。

## 二、安装四步

1. **拿到 APK**：从 [RikkaHub 安卓版下载与功能介绍](https://rikkahub.bpfl.quest/) 这个介绍站进入网盘资源页，转存后把安装包下载到手机（这份为 2.3.2 版，约 37MB）；
2. **允许安装**：在文件管理里点开 APK，系统提示「禁止安装来自此来源的应用」时，按提示跳到设置，给当前的文件管理器或浏览器开「允许安装未知应用」；
3. **完成安装**：回到安装界面点「安装」，等进度走完，点「打开」；
4. **首次启动**：欢迎页点「开始使用」，添加一家服务商填入密钥，或先选内置的免费小模型试手感，选好默认模型就能开聊。

## 三、常见问题

**点 APK 提示「禁止安装」**
来源限制：给当前用的文件管理器或浏览器开「允许安装未知应用」，回来重装即可。

**装完打不开 / 闪退**
先到系统「设置 → 应用管理」核对包名是 `me.rerere.rikkahub`——对不上说明装到了改版包，卸掉换可靠来源的包重装；对得上还闪退，就卸载重装一次，依旧复现带上版本号去项目的 GitHub Issues 反馈。

**提示系统版本过低**
设备系统低于应用要求，先升级系统或换设备；最低版本要求以 Google Play 页面标注为准。

**不配密钥能先聊吗**
能。应用内置了与硅基流动合作的免费小模型（如 Qwen3-8B），装好就能直接对话；想用更强的模型再按 [怎么配置API密钥和服务商.md](怎么配置API密钥和服务商.md) 配置。

**换手机怎么迁移**
在旧机的「服务商设置」里把配置导出成二维码，新机扫码导入，免重新敲密钥；二维码含完整密钥，导出后别截图乱放。装好后的进阶玩法见 [助手记忆与MCP工具用法.md](助手记忆与MCP工具用法.md)。
