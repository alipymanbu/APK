# RikkaHub 怎么配置 API 密钥和服务商

> RikkaHub 装好后还不能直接聊天：它是一个「壳」，不带任何模型，要自己填入服务商的 API 密钥。本篇把密钥来源、配置步骤、API 格式选择一次讲清。
> **相关文档**：[助手记忆与MCP工具用法.md](助手记忆与MCP工具用法.md) · [安卓APK安装步骤与常见问题.md](安卓APK安装步骤与常见问题.md)

## 一、密钥从哪来

RikkaHub 需要你自己准备一家的 API 密钥，常见来源：

| 来源 | 能用什么模型 | 备注 |
| --- | --- | --- |
| platform.openai.com | OpenAI 系 | 按量计费 |
| aistudio.google.com | Google Gemini 系 | 有免费额度，政策以页面为准 |
| console.anthropic.com | Claude 系 | 按量计费 |
| 各类 OpenAI 兼容端点 | 中转 / 聚合服务上的模型 | 要另外填 Base URL |
| 本地推理端点（Ollama、LM Studio 等） | 本机跑的模型 | 同样走 OpenAI 兼容格式 |

暂时不想花钱也有办法：应用内置了与硅基流动合作的免费小模型，不配任何密钥就能先聊。密钥等同密码，只填在应用里，别发给任何人。

## 二、配置步骤

1. 侧边栏底部进设置，选「服务商设置」（Provider Settings）；
2. 列表里有现成的服务商就直接点进去，没有就点右上角新建；
3. 填入 API 密钥；服务商不是内置的那几家时，再一并填 Base URL；
4. 保存后回到服务商页，滚到底部「模型」区，多数服务商支持一键拉取模型列表，勾选要用的即可；
5. 回设置页选「默认模型与提示词」，给各功能分配合适的模型：聊天用主力模型，标题生成、摘要这类小活儿交给参数量小的稳定模型，输入框上方的「聊天建议」不需要就直接关掉。

界面措辞随版本略有出入，以上按 2.3.x 的布局描述。

## 三、API 格式怎么选

| 格式 | 适用 |
| --- | --- |
| OpenAI（默认） | 绝大多数服务商与中转站 |
| OpenAI Responses API | OpenAI 接口或镜像 GPT 模型的中转，在服务商页切换 |
| Google | Gemini 自家格式 |
| Anthropic | Claude 及兼容它的服务 |

拿不准就用默认的 OpenAI 格式先试，报错了再对照服务商文档换。

## 四、Base URL 是最容易踩的坑

用中转或本地端点时，故障多半不是密钥错，而是 Base URL 没对上：

- 地址要以服务商后台给出的为准，结尾路径段（`/v1`、`/v1beta`）必须照抄；
- 不少中转把不同厂商的模型放在不同渠道类型下：`/v1` 一般对应 OpenAI 兼容通道（GPT、Claude 走它），`/v1beta` 往往只服务 Gemini——同一个 key 只有部分模型能用，多半是这里没对上；
- 每种渠道类型单独建一个服务商条目，别在一个条目里混填；
- 自动拉取模型列表拉不全时，去后台抄准确的模型 ID 手动添加，逐字符核对。

## 五、配好之后

服务商配置支持二维码导出 / 导入，换手机很省事；但二维码含完整密钥，导出后别截图乱放。配置好想进一步折腾助手、记忆和工具调用，见 [助手记忆与MCP工具用法.md](助手记忆与MCP工具用法.md)；安装环节的问题见 [安卓APK安装步骤与常见问题.md](安卓APK安装步骤与常见问题.md)。
