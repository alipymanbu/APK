# 自动报备能报备哪些内容

> 7 类事件、28 种操作：到达离开、打开应用、连接 Wi-Fi、通话、电量，还有关定位这类敏感操作。
> **相关文档**：[情侣定位共享怎么绑定](情侣定位共享怎么绑定.md) · [安卓手机怎么下载安装](安卓手机怎么下载安装.md)

LinkUp 最有辨识度的能力是「自动报备」：对方手机发生特定事件时，你这边会自动收到通知，不用一遍遍发消息问。下面把这些事件类别一次列清楚。

## 一、会自动报备的事件

| 事件类别 | 你会知道什么 |
|---|---|
| 到达 / 离开某地 | 对方到了或离开了某个位置 |
| 解锁 / 使用手机 | 对方解锁、开始用手机 |
| 打开 App | 对方打开了哪个应用、用了多久 |
| 连接 Wi-Fi | 对方连上了哪个 Wi-Fi |
| 接打电话 | 来电、去电的记录与时长 |
| 电量与充电 | 电量告急、开始 / 结束充电 |
| 账号与设备变更 | 关定位、换手机、网络变更等敏感操作 |

## 二、手机报告与使用统计

除了即时通知，还有汇总类的视图：

- **手机报告**：今日屏幕使用时长、解锁次数、当前网络、流量使用、剩余电量与预计可用时长；
- **App 使用记录**：按时间点列出打开的应用（如「20:36 打开抖音，用了 6 分钟」），也汇总单应用当日累计时长；
- **通话统计**：每日来电、去电的次数与通话时长自动统计。

## 三、这些通知靠什么在跑

所有报备都依赖对方手机上的授权：对方关闭共享或卸载应用，你这边相应数据立即断更，历史记录保留到断更那一刻为止。换句话说，这套机制的前提始终是「对方知情且同意」——这也正是它的产品立场。

## 四、报备之外还能做什么

紧急联系有实时语音（对方锁屏、静音也会外放）；想帮对方管住游戏时间，有一键锁机（锁整台手机或只锁指定 App）。功能的完整拆解与界面截图，可以看 [LinkUp 位置共享与自动报备应用介绍](https://linkup.fewa.skin/)。
