# Magisk模块和LSPosed模块在哪下

> 刚解开 BL 锁，想给手机装几个模块，却不知道去哪下、下完怎么装？这篇讲模块下载的两条常用路子，以及 toolkit 应用里把「下载」和「刷入」串起来的走法。

## 一、两条仓库，管两种模块

Magisk 模块与 LSPosed 模块不是一回事，下载渠道也分开：

| 仓库 | 管什么 | 装到哪 |
|---|---|---|
| Magisk 仓库 | 系统级增强模块（zip 包） | Magisk 应用 → 模块 → 从本地安装 |
| LSPosed 仓库 | 依赖 LSPosed 框架的功能模块 | LSPosed 管理器里启用 |

Magisk 模块动的是系统层（字体、内核参数、去验证之类）；LSPosed 模块挂在使用 Zygisk 的应用钩子上（改应用行为的居多）。装错仓库的包不会生效，先分清再下。

## 二、在 toolkit 里下载与刷入

toolkit 把这两路仓库收进了刷机资源板块，流程是一条线：

1. 打开 toolkit，进「刷机资源」板块；
2. 选仓库：小米 ROM / Magisk 仓库 / LSPosed 仓库；
3. 在列表里找到目标模块，点界面上的下载，文件落到手机本地存储；
4. 打开 Magisk 应用 → 模块 → 从本地安装 → 选中刚下的 zip → 重启生效（LSPosed 模块则去 LSPosed 管理器启用，长按模块是卸载）。

两个容易忽略的点：

- **LSPosed 入口默认不在 toolkit 主页**，要去刷机资源板块里找；
- 浏览与下载这一段不依赖 root，但**把模块刷进系统**需要手机已经 root、Magisk / LSPosed 环境就位，环境没搭好时装了也用不上。

## 三、风险边界

- 模块质量靠社区筛选，装之前看清说明与适配版本，一次别装太多——出问题时逐个停用定位冲突源；
- 小米机型的 BL 解锁有等待期，解锁会清数据，动手前备份；
- 仓库里能下到什么以打开时的列表为准，个人开发者项目更新快，入口偶尔随版本调整。

模块下载只是第一步，刷入环节的前提与机型匹配，建议配合工具箱的板块说明一起看。[toolkit 玩机工具箱介绍站](https://toolkit.fewf.ren/)把刷机资源板块的界面与流程按步骤拆开讲了，照着走不容易漏环节。
