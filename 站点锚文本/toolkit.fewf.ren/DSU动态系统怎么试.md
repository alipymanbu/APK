# DSU动态系统怎么试

> 想试试另一套安卓系统，又舍不得真刷机？DSU（动态系统更新）就是给这种需求准备的：镜像装进独立分区，重启进新系统，再重启回原系统。这篇讲它靠不靠谱、前提是什么、toolkit 里那个入口怎么用。

## 一、DSU 是什么

DSU（Dynamic System Updates）是安卓 10 起引入的一项能力：把 GSI 系统镜像写入独立的动态分区，设备重启后临时运行这套镜像，原系统分区分毫未动。从安卓 11 开始它还支持替换多个分区。

对玩机的人，它解决的是一个经典矛盾：想体验新系统，又不想承担刷机变砖、丢数据的风险。试完不满意，开发者选项里丢弃 DSU、重启一次，手机回到原来的样子。

## 二、前提与边界，先说清

- **Bootloader 必须已解锁**：这是社区反复强调的硬前提，没解锁不要尝试，工具内也会给出对应提示；
- **机型要求**：设备需要支持动态分区、与 GSI 镜像架构兼容；
- **空间开销**：要给新系统分配用户数据分区，建议预留 20GB 起的存储空间，装之前清一清手机；
- **临时属性**：DSU 系统重启后可能退回原系统，适合「试」，不适合「日常驻留」。

## 三、toolkit 里的入口

toolkit 的功能主页上单独留了 **DSU Sideloader** 板块，把「选镜像 → 分配空间 → 安装 → 重启进入」这条链收进了应用：准备好 `.zip` 或 `.img` 格式的 GSI 文件，在板块里选中镜像、按需调整用户空间大小，点安装后等进度跑完，按提示重启即可进入动态系统。

安装过程耗时与镜像大小、设备性能有关，通常在几分钟到二十分钟之间；期间保持电量充足、别拔电池别重启。想退出时，去开发者选项的「动态系统 / DSU Loader」相关条目选择删除或丢弃，重启即回原系统。

## 四、适合谁

适合满足两个条件的进阶玩家：机型支持 DSU，且已经历过 BL 解锁。只想给手机清清内存、加速日常使用的普通用户，用 toolkit 的实用功能板块就够了，不必碰这一块——它本来就摆在主页上，进与不进都是你自己的选择。

工具箱里各板块的关系、免 root 能用的范围，分别在[玩机工具箱怎么选.md](玩机工具箱怎么选.md)与[免root能用的功能有哪些.md](免root能用的功能有哪些.md)里有更细的拆分；界面与安装包的获取入口见 [toolkit 玩机工具箱介绍站](https://toolkit.fewf.ren/)。
