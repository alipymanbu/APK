# 免root能用的功能有哪些

> toolkit 的介绍里常出现两种说法：一说无需 root 即可使用，一说高级功能需要 root。这篇把两条边界捋清楚：不 root 能用哪些、root 之后多出哪些。
> **相关文档**：[玩机工具箱怎么选.md](玩机工具箱怎么选.md) · [Magisk模块和LSPosed模块在哪下.md](Magisk模块和LSPosed模块在哪下.md) · [DSU动态系统怎么试.md](DSU动态系统怎么试.md)

---

## 一、先记住一句合并口径

把两种说法并在一起就是实际体验：**下载与日常工具不用 root，动系统的操作要 root**。root 不是使用 toolkit 的门槛，只决定你能用到哪一层。

## 二、免 root 就能用的部分

首次启动给过文件管理权限之后，下面这些全部可用：

- **实用功能八件套**：智能翻译、PING 检测、文本转换、文字生成二维码、ChatGPT AI、标准体重计算器、心情日记、功德笔记——其中翻译与 AI 问答走网络，其余本地完成；
- **刷机资源的浏览与下载**：小米 ROM、Magisk 仓库、LSPosed 仓库的列表浏览、模块与固件下载，都只是「把文件存到本地存储」，不碰系统；
- **Minecraft 专区的全部动作**：模组、资源包、地图下载与服务器信息查询，导入游戏是文件层面的操作，同样不需要 root。

换句话说，把它当「在线资源下载器 + 日常小工具合集」用，一台完全没 root 的手机就是够的。

## 三、root 之后才打开的部分

- 在 Magisk 里「从本地安装」下载好的模块 zip 并重启生效；
- 在 LSPosed 管理器里启用模块（前提：root + Zygisk + LSPosed 框架就位）；
- 刷入固件包、动分区这类系统级操作。

这一层的前提不是 toolkit 给的，而是你手机自身的 root 环境与解锁状态。root 有失去保修、部分应用拒绝运行等代价，是否走这一步是对设备的取舍，动手前备份好数据。

## 四、装不上或点了没反应时

免 root 的功能点了没反应，按两类排：在线功能（翻译、AI、仓库）先查网络；本地功能（文本转换、二维码）重启应用再试。安装环节卡住——未知来源被拦、同名包冲突、Beta 版闪退——属于安装问题，处理办法写在 [toolkit 玩机工具箱介绍站](https://toolkit.fewf.ren/)的安装步骤一节里，对号入座即可。
