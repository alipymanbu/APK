# 安卓手机装漫画App被拦怎么办：未知来源与转存步骤

> colamanga 的安卓安装文件不走应用商店，而是放在网盘分享里，所以安装流程比商店装应用多一步「转存」，也更容易在「未知来源」这道系统关卡上被拦。这篇把整条流程拆成四步，再单独讲三个真会挡路的卡点。

## 为什么会多一步「转存」

网盘分享的文件默认挂在分享者的账号下，转存就是把安装文件复制进自己的网盘：之后随时能重新下载，不再依赖原分享链接的状态。这一步只需要登录自己的网盘账号，点一下转存按钮。

## 四步装好

1. **打开分享页并转存**：从介绍页的获取入口进入网盘分享页，登录后把安装包转存到自己网盘；
2. **下载到手机**：在网盘客户端里找到刚转存的安装包，下载到本机存储，流量紧张就等 Wi-Fi；
3. **允许安装未知应用**：首次点开安装包时，系统大概率提示「禁止安装未知来源应用」，这时到「设置 → 应用管理 → 安装未知应用」里，找到你用来打开安装包的那个应用（浏览器或文件管理器），允许它安装；各品牌菜单名称略有出入，在设置里直接搜「未知来源」就能定位；
4. **安装并打开**：回到下载目录重新点安装包，装完桌面出图标，打开后把常看的作品收进书架就能开追。

## 三个常卡住的点

**点安装没反应、直接被系统拦**：就是第三步的「未知来源」没放行。注意允许的对象是「打开安装包的那个应用」，不是 colamanga 本身；勾选后回到安装包重新点安装即可。

**转存失败**：先确认登录了自己的网盘账号、剩余空间够放安装包；分享链接偶尔有访问高峰，换个时间段再试一次一般就能过。

**装好了但打不开、闪退**：先重启手机再试一次；仍然不行就卸载后重新下载安装包——安装包在下载过程中损坏是闪退的常见原因，重下即解。
