# 音理音理是什么应用

「音理音理!」是开源安卓播放器 NeriPlayer 在界面里显示的中文名。这篇从名字说起，把这个应用的来历、玩法和适合的人一次讲清。

---

## 名字的来历

这个项目在 GitHub 上的仓库名是 NeriPlayer，装到手机后桌面图标下显示的却是「音理音理!」——作者给中文界面起的昵称，读起来像「内里」的谐音，也带点「音乐理论」的俏皮。两个名字指的是同一个应用：一个以 GPL-3.0 许可开源、用 Kotlin 和 Media3 写成的安卓音频播放器。

## 它解决什么问题

多数人的歌是散着放的：网易云里有日常歌单，哔哩哔哩收藏夹里存着一批只有 B 站才有的现场与翻唱，手机存储里还躺着下载好的无损文件。这个应用的思路是**不自建曲库**——把你已有的平台账号接进来，在线搜索与收藏歌单照常使用，本地音频扫进同一个媒体库，一处的播放队列里可以混排在线与本地曲目。

具体能力上一句概括：

- 搜索走网易云、哔哩哔哩、YouTube Music 三个音源，标签切换；
- 本地音频（MP3、FLAC、WAV 等）自动扫描，同目录封面与 .lrc 歌词一并认领；
- 歌单、收藏、播放历史可以同步进你自己的 GitHub 私有仓库，或走 WebDAV；
- 播放页逐字歌词、动态取色、睡眠定时器这些细节都齐。

## 适合谁用

手上有多平台歌单、又存了一批本地音频的人，是最对口的用户；在意听歌记录被云端画像的人也会喜欢它的做法——没有广告 SDK、不做埋点，数据要么留在设备里，要么同步进你自己的仓库。想动手装一个的话，[NeriPlayer 介绍站](https://neriplayer.yoan.quest/)整理了完整的功能说明与安装文件资源的获取入口。

## 与「官方出品」的距离

说清楚关系：它是独立开发者维护的开源项目，与它接入的各音乐平台没有隶属关系，也不是任何一家出品的应用。平台账号授权只存在手机本地，播放时按曲目来源实时取流。也正因为没有自建服务，它才做到轻巧——安装包只有十 MB 上下，老机型照样流畅。

装好后的第一站是「设置 → 登录三方平台」；各平台能搜索、能播放的范围差异不小，下一篇专门讲这件事：[网易云与B站歌单聚合收听](网易云与B站歌单聚合收听.md)。
