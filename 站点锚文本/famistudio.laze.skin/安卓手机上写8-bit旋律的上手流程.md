# 安卓手机上写 8-bit 旋律的上手流程

> 装好 FamiStudio 之后从哪开始？这篇按真实操作顺序把「打开应用 → 认识界面 → 放下第一个音符 → 做出一段能循环的旋律」走完，手机端全程适用。

FamiStudio 做的是红白机芯片音色，操作却是现代编曲软件那一套：钢琴卷帘加拖拽，全程不碰十六进制。手机上没有鼠标，等价动作是**长按**——任何元素的更多选项都在长按菜单里，这相当于电脑上的右键。

## 一、界面就三块

打开一首歌后，你会反复在三个区域之间来回：

| 区域 | 在哪 | 管什么 |
| --- | --- | --- |
| Project Explorer（工程区） | 屏幕一侧的列表 | 工程、歌曲、乐器、样本等所有对象的属性都在这里展开 |
| Sequencer（编排区） | 钢琴卷帘上方的格子条 | 安排每个通道在不同段落用哪个 pattern |
| Piano Roll（钢琴卷帘） | 主区域 | 画音符、拖音符、调长短，写旋律的地方 |

先点开工程区里自带的演示歌播一遍，对照着看三个区域怎么联动，比自己空看描述快得多。

## 二、认识五个基础通道

新建工程默认是 NES 标配的五个通道，每个通道一个声部：Pulse 1 出主旋律、Pulse 2 出和声、Triangle 压低音、Noise 打鼓点、DPCM 放采样。各通道的发声原理与玩法单独写在[红白机音色拆解：五个声道与扩展芯片.md](红白机音色拆解：五个声道与扩展芯片.md)，上手阶段知道谁管什么就够了。

## 三、从零到第一段旋律

1. **新建工程**：主界面新建，起个名字。
2. **建 pattern**：在编排区给想用的通道各建一个段落，短到十几拍最好写。
3. **画音符**：切到钢琴卷帘，选中通道，在格子上轻点就放下一个音符；按住拖动改位置，拖右边缘改长短。拖动时有声音预览，不用反复播放。
4. **写旋律**：先只写 Pulse 1，一句 4~8 拍的短句就够。
5. **补低音和鼓**：Triangle 上写几个根音，Noise 上在高音区点出节拍，三样齐了就有那味儿。
6. **设循环点**：在编排区把 pattern 首尾的循环标记拖好，播放时就会在循环点之间来回。
7. **调音色**：觉得声音太干，回工程区展开乐器，改音量包络和颤音。
8. **随便撤销**：整个应用支持完整的撤销与重做，写坏了大胆乱试。

## 四、触屏手势速查

| 想做什么 | 手势 |
| --- | --- |
| 放一个音符 | 轻点卷帘空白处 |
| 移动音符 / 改长短 | 先轻点选中，再按住拖动 |
| 打开更多选项 | 长按（等于电脑上的右键） |
| 快速删音 | 双击后按住拖动，进入橡皮擦模式 |

两个习惯能省很多误触：**横屏使用**；能用长按菜单的就别去找小按钮。
