# FamiStudio 安卓版：手机上的红白机音乐编辑器

这里是 FamiStudio 的第三方介绍小站（[famistudio.laze.skin](https://famistudio.laze.skin/)）的配套文档区，收录安卓版下载安装、上手流程与音色导出的零散笔记。FamiStudio 是一款开源的 NES / FC 芯片音乐编辑器：钢琴卷帘点按写谱、五个经典声道之外还能开启 VRC6、VRC7 等卡带扩展芯片，安卓与桌面端共用同一套 `.fms` 工程。安装文件资源的获取入口统一放在 [FamiStudio 安卓版介绍站](https://famistudio.laze.skin/)，本目录只聊怎么用。
