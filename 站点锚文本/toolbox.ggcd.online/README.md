# Toolbox 站点目录：Minecraft 基岩版功能层启动器

这里是 Toolbox for Minecraft: PE 的介绍站目录。Toolbox 是安卓平台上挂在 Minecraft 基岩版（PE）之上的启动器与功能层：从它的图标拉起游戏，画面上会浮出一颗绿色 M 按钮，发放物品、附魔、X-Ray 选矿、快速建造、小地图 HUD 都在这份悬浮菜单里。下面几篇按真实使用里的高频疑问整理：菜单里有什么、装完没反应怎么排查、版本怎么配对。完整的图文指引见 [Toolbox 介绍站](https://toolbox.ggcd.online/)。
