# 二手手机验机清单

> 当面交易二手手机，几分钟内最该查什么、按什么顺序查，本篇给一份可以照着走的清单。

二手交易最怕「看着都好，回家才出问题」。验机的核心思路是：**容易被动手脚的先查，坏起来最影响日常的也先查**，每一步都要有明确的判据，不靠手感下结论。

## 验机顺序清单

1. **屏幕（最优先）**：纯色画面铺满全屏，黑屏看亮点漏光、白屏看暗点灰斑、红绿蓝确认子像素；顺手划一遍全屏确认触控没有断区。硬件信息工具里的屏幕测试功能就是干这个的，Castro 的工具页内置了这套纯色测试，[介绍站](https://castro.xnyx.quest/)上有它四个主分区的界面速览。
2. **电池**：看容量、温度、电压，支持的机型还能看循环次数——循环次数明显偏高说明用得狠。注意「容量显示正常」不能单独当作电池没换过的证据，换过第三方电池的机器容量一栏读不到真实值，要结合循环次数与卖家描述一起判断。
3. **规格核对**：CPU、GPU、内存、存储逐项对照卖家宣称的配置。存储总量对不上是改信息卖机的常见破绽；频率与标称有小差距属正常调速，差距离谱才要追问。
4. **传感器**：逐个点开加速度计、陀螺仪、光线、磁力计，一边看实时曲线一边动手机——遮光线孔、翻转机身，数值完全不动的就是失效传感器。
5. **摄像头**：参数页核对分辨率、光圈、防抖，再实际各拍一张确认能对焦。
6. **Wi-Fi 与蓝牙**：连一次 Wi-Fi 看安全类型与连接状态，配一次蓝牙耳机确认能配对。

## 两个加分动作

- **系统自带检测入口兜底**：不少机型拨号盘里有工程测试菜单（三星常见 `*#0*#`、小米常见 `*#*#6484#*#*`），可以和第三方工具互相印证；部分运营商会禁用这些入口，拨了没反应就跳过。
- **验完留档**：把设备参数导出成报告当场发给自己存底，报告能证明「当时这台机器是什么配置」，后续有争议时比口头描述管用。验机用到的仪表盘读数怎么逐项理解，先看[手机硬件信息怎么查看](手机硬件信息怎么查看.md)；电池那一步的详细口径在[电池循环次数与健康状态怎么看](电池循环次数与健康状态怎么看.md)。
