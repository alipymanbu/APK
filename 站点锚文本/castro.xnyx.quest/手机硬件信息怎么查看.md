# 手机硬件信息怎么查看

> 想知道自己的手机用什么处理器、电池还健不健康、内存到底剩多少，安卓机上查这些参数有几种路子，本篇按场景说清。

查手机硬件信息，最直接的路子是系统设置里的「关于手机」，但那里只给机型、系统版本这类皮毛；想看每颗 CPU 核心的实时频率、电池温度电压、传感器曲线，就得借助专门的硬件信息工具。

常见的几种方式：

1. **系统自带入口**：设置 → 关于手机能看基础参数；部分机型拨号盘里的工程代码（如 `*#*#4636#*#*`）能看网络与电池统计，但不少运营商会禁用这些入口。
2. **电脑端工具**：连数据线用 ADB 查询，信息全但操作门槛高，适合折腾过开发环境的人。
3. **安卓硬件信息应用**：装一个工具类应用最省事。以 [Castro 介绍站](https://castro.xnyx.quest/)整理的内容为例，这类工具打开后是一块仪表盘，CPU、电池、网络、内存四项实时读数聚合在一屏，往下还有按硬件分类的详细信息页——传感器有实时曲线，摄像头给分辨率与防抖参数，编解码器列全支持格式。

用工具类应用查看时有几点提醒：

- CPU 频率忽高忽低是正常的调速行为，手机一闲就降频，不代表硬件有问题；
- 部分字段受设备上报限制，比如换过第三方电池后，电池容量读不到真实值；
- 想把整份参数存档发给别人，选带「数据报告导出」功能的工具，一次生成整份文件，对方不需要装任何东西就能看。
