# 摄像头配网与添加设备教程

> 摄像头是先通电、再由手机端带着它连上家里 WiFi 的，这一步做完它才会出现在首页。这篇按「扫码 / 热点 / 网线」三种方式拆开写，并把配网过程中摄像机会说的四句话逐句给出处理办法。整理好的图文版见 [iCam365 手机端使用笔记](https://icam365.fwen.ren/)。

## 一、动手前先确认四件事

1. **摄像机已通电并等够时间**：接上电源后等约 1 分钟，听到开机提示音再操作；一直没声音，先长按机身 Reset 键重置。
2. **手机已登录账号**：添加设备时会绑定到当前登录的账号，没账号先用邮箱或手机号注册一个。
3. **WiFi 是 2.4GHz 且没被隐藏**：摄像机只认 2.4GHz，5GHz 的网络它扫不到；双频合一的路由器先在后台拆成两个名字，手机连 2.4G 那个。WiFi 名和密码建议只用英文字母和数字。
4. **安卓手机先把定位（GPS）打开**：安卓端添加设备要用定位服务。第一次打开 App 时拒绝定位权限，是「一直添加不成功」的常见根源——卸载重装、重来时把权限给上即可。

## 二、三种添加方式怎么选

| 方式 | 原理 | 适合什么情况 |
| --- | --- | --- |
| 扫码添加（推荐） | 手机先连家里 WiFi，再把 App 生成的二维码给镜头看 | 机身二维码清晰、可正常识别的绝大多数情况 |
| 快速添加（AP 热点） | 手机先连摄像机自己发出的热点，再把 WiFi 信息交给它 | 扫码不成功、或机身二维码破损/丢失 |
| 有线网络添加 | 摄像机直接用网线接路由器 | 旁边有网口，或 WiFi 环境复杂想图稳定 |

## 三、扫码添加的完整步骤

1. 让摄像机离路由器近一些再操作，中间尽量别隔墙。
2. App 里点 `+`，用手机扫机身底部或背面的二维码；扫不出来就手动选「监控摄像头 → WiFi 摄像头 → 扫码添加」。
3. 选择家里 2.4GHz 的 WiFi，输入密码提交。
4. 手机屏幕出现二维码，把它对着镜头，距离大约 10~30 厘米。
5. 听到「扫码成功」提示后点下一步，等它自己连 WiFi、连服务器，整个过程约 30 秒到 1 分钟。
6. 连上后给设备起个认得出的名字（比如「客厅」「大门」），后面告警推送里用的就是这个名字。

## 四、配网过程中会听到的四句话

| 摄像机说的话（大意） | 表示什么 | 卡住时先查什么 |
| --- | --- | --- |
| 请用扫码或热点方式配置摄像头 | 等你下发 WiFi 信息 | 没听到这句说明没进配网模式，先重置 |
| 请稍等，正在连接 WiFi | 已收到信息，正在连路由器 | 密码是否填错；离路由器是否太远；WiFi 是否隐藏 |
| 请稍等，正在连接网络 | 连上了路由器，正在连服务器 | 宽带是否正常；密码里的特殊符号先去掉再试 |
| 网络已连接，欢迎使用云摄像头 | 配网完成 | 回 App 首页看画面是否出现 |

## 五、换 WiFi、挪位置与重置

- **只换 WiFi 不挪位置**：进这台设备的设置，在 Wi-Fi 网络一项重新选网填密码。
- **接网线的机型**：拔掉网线后必须重新上电，它才会去连 WiFi。
- **换路由器或改了 WiFi 密码**：设备不会自己跟着变，先长按 Reset 重置（听到提示音再松手）再重新配网；重置不清存储卡里的录像。
- **挪到别的房子**：通电后首页显示「设备已断开」，点「故障排查 / TROUBLESHOOT」重新走一遍配网。

## 六、一台摄像机只能绑一个账号

设备与账号一对一绑定：挪给另一个账号前，必须先在当前账号里删除设备（解绑）。家人想一起看不必换账号、也别共用账号——同一账号同一时间只能在一台手机登录，后登的会把先登的顶下线，正确做法是分享设备，一台最多分享给 10 个账号。

装好手机端、配好网之后，日常就是看画面、翻回放、收提醒，具体见[回放与告警设置技巧](回放与告警设置技巧.md)；还没安装的先看[安卓版下载安装步骤](安卓版下载安装步骤.md)。
