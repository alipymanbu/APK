# 手机遥控电脑怎么连

> 本篇讲普通安卓设备安装 Armoury Crate 之后最常见的玩法：与华硕 ROG 游戏本或台式机配对，远程切性能档、看硬件状态、控风扇与灯效。

## 一、这个玩法适合谁

手机端的 Armoury Crate 在 ROG 手机之外最常见的用途，是给华硕/ROG 游戏笔记本、台式机当一块「第二屏幕」：游戏跑在电脑上，人在沙发上用手机看温度、切性能档、调风扇转速，不用打断电脑画面。

前提条件有三条：电脑上装好 PC 版 Armoury Crate（华硕支持渠道或微软商店可取）；手机与电脑网络连通（同一 Wi-Fi 最省事，也支持蓝牙）；手机上装有安卓版 Armoury Crate。

## 二、配对步骤

1. 电脑上打开 PC 版 Armoury Crate。
2. 手机端进入「笔记本电脑远程控制」板块，按界面指引进入配对流程。
3. 两种方式任选其一：电脑端显示二维码、手机扫码连接；或双方登录同一 ROG ID 完成配对。
4. 配对成功后，手机端出现电脑的可控制面板。

从应用商店的实际反馈看，**扫码方式的成功率明显高于 ROG ID 登录**——有用户反馈 ROG ID 路线会报错，配对一直失败时优先改走二维码。

## 三、连上之后能控制什么

| 手机端操作 | 作用在电脑上的效果 |
| --- | --- |
| 切换 Turbo / Performance / Silent 三档 | 在最高性能、游戏平衡、安静低载之间一键切换，几秒生效 |
| HyperFan 风扇控制 | 调整电脑风扇策略：全力散热、游戏降噪、低噪音轻载 |
| System Info 硬件监控 | 查看 CPU/GPU 频率、占用率、温度、风扇转速、电压 |
| Aura Sync 灯效 | 远程调整电脑端 Aura Sync 灯光设置 |

三档的实际差异：Turbo 用最高频率与风扇转速顶满 CPU/GPU，适合视频渲染、3D 处理；Performance 为游戏优化，噪音与帧率兼顾；Silent 适合看片、浏览、办公。跑分烤机时手机正好当监控面板，直播联机时切静音档也不用退出全屏。

## 四、连不上怎么排查

- 双方应用都在前台运行：电脑端最小化到托盘后，手机端可能直接失去目标。
- 核对网络：手机走流量、电脑走有线时不在同一网段，是最常见原因；公司/学校 Wi-Fi 的 AP 隔离也会让设备互相发现不了，换热点测试。
- ROG ID 登录报错就改扫码，这是实测里最有效的替代路径。
- 配对成功但面板一直加载，多为应用自身的加载故障，清缓存换网络再试。
- 电脑端版本过旧会导致功能面板缺失，把 PC 版更新到当前版本再重连。
