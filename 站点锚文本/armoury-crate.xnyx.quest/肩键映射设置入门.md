# 肩键映射设置入门

> 本篇讲 ROG 游戏手机 AirTriggers 超声波肩键的游戏内映射方法、手感参数调校与按压不灵时的排查顺序。
> **相关文档**：[X模式三档怎么选.md](X模式三档怎么选.md) · [手机遥控电脑怎么连.md](手机遥控电脑怎么连.md)

## 一、一套硬件，两种用法

AirTriggers 是机身边框上的超声波按压区域，同一套硬件在两种场景下工作方式不同：

| 用法 | 触发方式 | 设置入口 |
| --- | --- | --- |
| 游戏映射 | 横握时食指自然搭住的机身两侧按键 | 游戏内从屏幕左侧边缘滑出 Game Genie，点 AirTriggers |
| 系统握压 | 竖握时握压边框下方 | 系统设置 → 高级功能 → AirTriggers，绑定打开相机、截屏等快捷动作 |

两套手势相互独立、互不影响；游戏映射是肩键的主要用途。

## 二、游戏内怎么映射键位

1. 进入游戏，从屏幕左侧边缘向内滑出 Game Genie 面板，点「AirTriggers」。
2. 选择手势类型：点击、单侧双键、滑动（长滑）、速滑（拨滑）、体感（抖一抖，部分机型支持）。
3. 把对应颜色的圆圈拖到游戏技能按钮上：左肩键蓝色、右肩键红色、体感键位黄色。
4. 同一个游戏可保存多组肩键配置，切换英雄或场景时调出对应一组即可。

映射的前提是技能按钮位置固定。以射击类游戏为例的常见搭配：左侧单侧双键分别映射开镜与开火，右侧速滑映射起跳与蹲下，体感「抖一抖」映射换弹——这是 ROG 产品手册举过的参考组合，按自己的操作习惯调整即可。

## 三、手感参数在哪里调

统一入口在应用的控制台 → AirTriggers → 偏好与手感设定，主要可调项：

| 参数 | 作用 |
| --- | --- |
| 点击手感 | 调按压力道，重按防误触、轻按省力 |
| 单侧双键手感 | 设定单边两个触发区域的分界位置 |
| 长滑手感 | 滑动距离加成决定边框滑动对应屏幕滑多远；触发距离决定滑多长才开始触发 |
| 拨滑手感 | 调速滑的触发速度阈值 |
| 震动反馈 / 触发视觉 | 触发时是否振动、游戏内是否显示视觉提示 |

调校原则：先按默认玩一局，哪个动作容易「按不出来」就把对应阈值调灵敏，哪个动作容易误触发就调迟钝；每改一项单独验证，不要一次全调。

## 四、按压不灵的姿势因素

- 用指腹或指尖集中按压小面积区域，整只手攥压反而不稳定；
- 按肩键的同时轻触屏幕下半部按键，避免手指压到肩键旁的屏幕角落；
- 握持稳定，用力紧攥机身会让边框上的感应元件检测不稳；
- 装保护壳时确认四角完全贴合，壳没装正会持续给边框施压，导致触发变钝或误触。

## 五、失灵排查顺序

按华硕支持页给的步骤走：确认系统设置里 AirTriggers 开关已启用 → 系统更新到最新版本 → 擦拭机身侧边触控区域 → 重启手机 → 仍无效则联系华硕售后。

映射问题（键位点了没反应）与硬件失灵（按压毫无反馈）要分开看：前者多半是游戏更新改了界面，重新拖一次映射点即可。这款控制台应用还有性能档位、风扇灯效等模块，[armoury crate 功能总览站](https://armoury-crate.xnyx.quest/) 把各模块的入口做了汇总，配合食用更顺。
