# X 模式三档怎么选

> 本篇讲 ROG 游戏手机上 X 模式的档位划分、各自适合的场景与解锁条件，顺带说清高档位与酷冷风扇的关系。
> **相关文档**：[手机遥控电脑怎么连.md](手机遥控电脑怎么连.md) · [肩键映射设置入门.md](肩键映射设置入门.md)

---

## 一、X 模式做了什么

X 模式是 ROG 游戏手机专为游戏设计的高性能模式：开启后自动优化后台、移除暂时不用的应用释放内存，并提升硬件使用效率，让游戏跑得更稳。开启瞬间机身背面的 ROG 灯效与已连接的兼容配件会同步点亮，这是系统联动的一部分。

普通安卓设备上没有这套硬件联动，装了应用也找不到这些档位，属于正常现象。

## 二、三个档位的差别

以 ROG Phone 3 这一代的媒体实测为准，后续机型的划分思路基本延续：

| 档位 | 实际表现 | 适合场景 |
| --- | --- | --- |
| L1 | 优化流畅度与响应，主要在加载、触控交互时提频 | 日常轻度游戏、怕发热 |
| L2 | 同时压榨 CPU 与 GPU，不怎么顾及功耗与发热 | 中度负载的主流网游 |
| L3 | 性能全开，机器自动能给到的最高档 | 重负载大型游戏 |

关键差别在解锁条件：**L3 通常需要外接酷冷风扇才可用**。接入对应代数的酷冷风扇（如 ROG Phone 3 配酷冷风扇 3）后才能开启 L3；不接风扇时 L3 选项置灰或缺失，这不是故障。

## 三、选档思路

- 刷视频、聊天：不开 X 模式，开着只会多发热、多耗电。
- 一小时左右的网游：L1 或 L2 足够，温度与帧率更平衡。
- 长时间大作或夏天高温环境：接上酷冷风扇再开 L3，主动散热对背面温度的压制远比被动强。
- 想让某个游戏一进去就自动切档，把档位写进该游戏的场景配置即可，不用每次手动点。

开高档位前值得做两件事：先手动划掉明显用不到的后台大应用；边充边玩叠加高档位发热会翻倍，能拔线就先充满再玩。

高档位跑一阵后帧率仍往下掉，多数是机身温度到了保护阈值触发降频，属于散热物理上限，换更低档位或加强散热才是解法。

## 四、在哪里打开

常见入口有三处：快速设置面板里的「X 模式」图标；游戏中心（智控中心）内的开关；以及在 AirTriggers 设置里把短握或长握肩键绑定成 X 模式开关，横握时不用腾手指拉菜单。

想量化它到底有没有用，进游戏后从屏幕左侧滑出游戏精灵开「实时信息」，浮窗看 FPS，开与关各跑几分钟一对比就有结论。

想集中了解这款控制中心应用的各项功能与安装方式，可以看这份 [armoury crate 专题整理](https://armoury-crate.xnyx.quest/)，界面结构与连接方式都有截图说明。
