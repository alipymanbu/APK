# 安卓版怎么安装到手机

> PCNapp（p.cn）不在应用商店上架渠道里，安装包走网盘分享获取。本文给从拿到安装包到登录进应用的完整步骤，以及三个最常见的安装故障的处理办法。
> **相关文档**：[网址导航桌面怎么用](网址导航桌面怎么用.md) · [P币签到与P指数面板解读](P币签到与P指数面板解读.md)

---

## 一、装之前确认三件事

1. **系统版本**：需要安卓 5.2 以上，低于这个版本系统会直接拒绝安装；
2. **存储空间**：安装包约 45M，装完还要留运行空间，建议剩余空间 200M 以上；
3. **安装包来源**：认准分享页里的 `PCNapp_v3.4.2.apk`，版本号对得上再装。

## 二、安装四步

1. **打开分享页，先转存**：进入夸克网盘分享页，登录自己的账号，把安装包「保存到我的网盘」。先转存到自己名下，以后随时能重新下载，不怕分享链接中途失效；
2. **下载到手机**：在自己网盘里找到这个 APK，下载到手机存储，完成后在通知栏或「下载」目录能看到它；
3. **允许未知来源**：点开 APK 时系统会提示「禁止安装来自此来源的应用」——这是安卓对安装包的标准拦截，不是包有问题。按提示进「设置 → 安装未知应用」，给下载时用的那个应用（浏览器或文件管理器）打开允许开关，再返回点安装；
4. **打开并登录**：装完打开应用，首页的导航内容不登录也能看；要用自定义桌面、签到这些功能，用手机号接收短信验证码注册登录即可，两三分钟完成。

## 三、装不上？按现象对号入座

| 现象 | 原因与处理 |
| --- | --- |
| 点安装没反应、提示被拦截 | 第 3 步的权限没开：设置 → 安装未知应用 → 给来源应用开允许；个别机型从旧版本升级安装会报冲突，先卸载旧版再装 |
| 提示「解析包时出现问题」 | 多半是安装包没下完整（网络中断会产生残包），回到网盘重新下载一遍；存储不足也会报同样的错 |
| 装好打开一直转圈 | 它的导航和资讯需要联网拉取，确认网络可用，Wi-Fi 与移动数据各试一次；仍不行到系统设置的存储管理里清一次缓存再打开 |

## 四、装完先做什么

登录之后建议先做两件事：一是进「我的桌面」把常用的几个网址加进去，配合云同步以后换机不用重加；二是不着急的话可以先用「推荐桌面」的现成分类过渡。界面各区块的具体用法见[网址导航桌面怎么用](网址导航桌面怎么用.md)，签到与 P 币的玩法见[P币签到与P指数面板解读](P币签到与P指数面板解读.md)。

更直观的版本：[PCNapp 功能介绍站](https://pcnapp.boop.uno/) 的下载安装页里也整理了同一步骤，两边对照着装都可以。
