- 想直接上手查动作：先读[人体地图怎么点](人体地图怎么点.md)；
- 想把应用装到安卓手机：读[安卓安装步骤与常见问题](安卓安装步骤与常见问题.md)；
- 站点入口（功能介绍与安装文件资源获取指引）：[MuscleWiki 人体地图动作库](https://musclewiki.usea.quest/)。
