# 电视端 B 站客户端怎么选

> 想在电视上刷 B 站，应用商店里的版本功能又总觉得差口气——这篇把目前几条路线摆在一起对比，看完就知道哪条适合自己。

## 一、三条常见路线

**1. 电视应用商店里的云视听小电视**

商店直装、开箱即用，是门槛最低的一条路。代价是功能面精简：弹幕可调项很少，搜索、动态、历史这些能力要么缺要么弱；看超清与部分影视还要单独开电视专属会员，手机端的大会员在它这里不通用。

**2. 手机投屏**

把手机画面投到电视上，内容与手机端完全一致。问题是占用整部手机，来了消息投屏就断，遥控器也没法参与操作，只适合临时看个视频。

**3. 第三方开源客户端（BBLL 一类）**

代码公开在 GitHub 的开源项目，把 B 站公开接口封装成电视端应用。功能照着手机端的完整度做：19 个分区、直播、UP 主动态、一键三连、弹幕全套自定义都有；会员口径与手机 / 网页端一致，不用再开一份电视专属会员。代价是需要自己动手安装（商店里没有），并且可用性受接口变化影响，版本需要偶尔更新。

## 二、按需求对号入座

| 你的情况 | 更适合的路线 |
| --- | --- |
| 只想最省事，画质功能无所谓 | 商店直装版 |
| 偶尔投一下，不想折腾 | 投屏 |
| 大会员已经在手、要弹幕要分区要 4K 以上 | 第三方客户端 |
| 老旧盒子（Android 4.4 时代） | 第三方客户端的兼容分支 |

## 三、选第三方客户端前先确认三件事

- **设备系统版本**：Android 5.0 以上基本都行，更老的机型看项目有没有兼容分支；
- **解码能力**：播放依赖硬件解码（H.264 / H.265），4K 档位老设备未必带得动；
- **动手意愿**：安装要走「允许未知来源 → 文件管理器装包」这套流程，愿意花十分钟就能搞定。

设备与安装的完整流程，[BBLL 介绍站](https://bbll.yoan.quest/)里有逐步说明；会员账怎么算更划算，见[电视上看B站要不要单独开会员](电视上看B站要不要单独开会员.md)；老设备安装的细节坑，见[老电视盒子怎么装第三方B站客户端](老电视盒子怎么装第三方B站客户端.md)。
