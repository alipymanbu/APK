# OpenClaw 网关怎么部署：从一台空电脑到能对话

> 本篇讲主机侧的部署路径：要装什么、怎么引导、渠道怎么接、手机怎么配对。安卓应用的下载与安装步骤，见[介绍站的下载页](https://openclaw.fewf.ren/download.html)。
> **相关文章**：[安全风险与权限收紧.md](安全风险与权限收紧.md) · [费用与模型选型.md](费用与模型选型.md)

## 一、先备齐三样东西

- **一台能常开的机器**：家里的旧电脑、小主机或一台云服务器都行，OpenClaw 的网关要长期挂着才有意义；
- **一个模型 API 密钥**：网关本身不内置智能，理解和回答靠你接上去的大模型，主流供应商的接口都支持；
- **常用环境**：Node 24（或 22 LTS 及以上），项目文档口径下从安装到能对话约五分钟。

## 二、安装与引导

在主机上执行两步（以项目文档为准）：

```bash
npm install -g openclaw
openclaw onboard --install-daemon
```

`onboard` 是引导向导：选模型、填密钥、装成常驻服务。跑完之后可以打开网页控制台看一眼：

```bash
openclaw dashboard
```

默认地址在本机的 18789 端口，聊天、配置、会话管理都在这个控制台里做。macOS、Windows、Linux 也有打包好的桌面应用，会把网关和设置界面一起装好，不想碰命令行可以走这条路。

## 三、接一个聊天渠道

渠道接在主机一侧，推荐从 Telegram 开始（机器人创建最简单）：

1. 主机上执行 `openclaw channels login`，按提示完成渠道登录；
2. 在配置里给渠道加白名单，比如 WhatsApp 的 `allowFrom` 只填自己的号码——**这一步别跳过**，开了「谁来都能聊」，陌生号也能指挥你的助手；
3. 用自己的号发一条消息测试，几秒内回话就说明链路通了。

## 四、把手机配进来

安卓应用的角色是配套节点：应用里进入网关设置页，选自动发现到的主机或手动填地址（局域网直连最简单；跨网络建议走 Tailscale 这类加密通道，不要把网关端口裸露到公网）。配对成功后，主机状态页里能看到这台手机，语音、相机、Canvas 这些设备能力才真正接进系统。

整套部署完成后，日常入口就是你的聊天软件；想随时对照着操作，可以打开 [OpenClaw 介绍站](https://openclaw.fewf.ren/)，界面截图与安装说明都在上面。

## 五、部署常见卡点

| 现象 | 多半是 |
| --- | --- |
| 引导向导跑一半报错 | Node 版本过低，先升到 22 LTS 以上 |
| 发消息没反应 | 渠道白名单没放行、密钥填错或额度用完 |
| 手机配对不上 | 两端不在同一网络，或网关服务没在跑 |
| 控制台打不开 | 端口没对上，确认 18789 与服务状态 |
