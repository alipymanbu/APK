# LocalSend 互传站导读

这里是 LocalSend 的第三方介绍站导读。LocalSend 是一款开源的跨平台局域网传输工具：手机与电脑连上同一个 Wi-Fi 就能点对点互传文件，数据不经过云端、不消耗流量，Windows、macOS、Linux、安卓、iOS 上都能装。

本目录的几篇文章围绕两类最常见的搜索需求整理：怎么把文件在设备之间搬、搜不到对方设备时怎么排查。工具的功能拆解、上手步骤与真机界面都收在 [LocalSend 互传站](https://localsend.bpfl.quest/)。
