# 游戏打不开怎么办：闪退、黑屏、方框排查

> 游戏加进列表却点开就退、画面全黑、中文变方框——高频问题的排查思路都在这篇，先按现象对号入座。
> **相关文档**：[启动器插件怎么装.md](启动器插件怎么装.md) · [手机玩电脑RPG游戏.md](手机玩电脑RPG游戏.md)

## 一、点开就闪退或没反应

按命中率从高到低查：

1. **缺插件**。RPG Maker XP/VX/Ace、Ren'Py、Flash、Godot 的游戏都依赖对应插件，只装主程序跑不起来，对照关系见[启动器插件怎么装.md](启动器插件怎么装.md)。
2. **Ren'Py 插件选错分支**。Ren'Py 8 的游戏配了 7.x 插件（或反过来）会直接打不开；两支可共存，换一支再试。
3. **启动文件选错**。RPG Maker XP/VX/Ace 选到了 `www` 里的文件、Ren'Py 选到了 `lib` 目录——删掉这条记录，重新添加时认准游戏根目录的 `Game.exe` 或与游戏同名的 `.exe`。
4. **游戏文件夹不完整**。解压不完整、传输中断都会缺资源，现象是启动到一半退出；重新完整解压覆盖一份。
5. **游戏本身不兼容**。Godot（约 50%）与 Flash（约 60%）兼容度偏低，重度自定义脚本的 RPG Maker 游戏也可能异常——拿同引擎的另一款游戏试，能跑就是这一款的事。

## 二、弹出英文报错

| 报错关键字 | 原因 | 处理 |
| --- | --- | --- |
| `Failed to load: Graphics/...` / `Audio/...` | 缺 RTP 共享素材包（XP/VX/Ace 游戏） | 获取对应版本的 RTP 素材包后，在菜单里「添加 RTP」导入（zip 不用解压） |
| `No game scripts specified (missing Game.ini?)` | 游戏文件夹缺 `Game.ini` | 重新解压；个别游戏打包时漏了它，找游戏作者要 |
| `Failed to read script data` | 脚本包缺失或游戏加密 | 先重解压；仍报错说明是加密游戏，跑不了 |
| 「网页不可用」/ WebGL 不支持（HTML、MV/MZ 游戏） | WebView 过旧或代理干扰 | 更新系统的 Android System WebView；开着 VPN / 私人 DNS 先关掉 |
| `Read-only file system` | 没有写入权限，存不了档 | 给主程序和 RPG Maker Plugin 都开「所有文件访问」权限 |

注意第一条与插件无关：RTP 是 RPG Maker 的共享素材包，作者做游戏时没把素材打进去、假定玩家电脑上装过，所以这类游戏在电脑上能跑、拷进手机就报缺文件。缺哪个版本看游戏引擎（XP / VX / VX Ace 各一套），分不清就三个都备着。

## 三、黑屏（有声音、按键有反应，就是没画面）

- **MV/MZ 与 HTML 游戏**：多是渲染问题，进这条游戏的设置把渲染器切换一下（认 Graphics / Renderer / WebGL 字样，比如 WebGL 换 Canvas）。软件渲染最慢但兼容面最广，卡在特定场景过不去时用它救场。
- **XP/VX/Ace 游戏黑屏**：先查 RTP，见上一节。
- **大游戏在低配机上初始化慢**：加载几十秒才出画面属正常，先等一等再下结论。

## 四、中文显示方框或乱码

字体问题，换个自定义字体通常能解决：主程序右上角菜单 → Settings → RPG Maker 设置区 → Custom Font，从手机里选一个 `.ttf` / `.otf` 字体文件。**选笔画较细的字体**（细黑体一类），粗字重的字库在游戏里反而容易继续显示方框。改完重启游戏生效。

## 五、还解决不了的时候

- 存不了档：给「所有文件访问」权限时主程序和 RPG Maker Plugin 要**都**开；部分机型对 `Android`、`Download` 等特殊目录限写，把游戏挪到普通目录再试。
- 卡顿掉帧：玩 MV/MZ 与大型 HTML 游戏前清后台、关省电模式；旧引擎的 2D 游戏负载最轻。
- 从头没装利索的，回到[手机玩电脑RPG游戏.md](手机玩电脑RPG游戏.md)把准备与添加两步重新过一遍；完整的功能介绍与获取入口在 [JoiPlay 介绍站](https://joiplay.wrwq.fun/)。
