# 启动器插件怎么装：引擎对照与安装顺序

> JoiPlay 主程序只自带 HTML 类游戏支持，玩其余引擎的游戏要单独装插件。本篇讲哪个引擎装哪个插件、Ren'Py 插件怎么选分支、按什么顺序装。
> **相关文档**：[手机玩电脑RPG游戏.md](手机玩电脑RPG游戏.md) · [游戏打不开怎么办.md](游戏打不开怎么办.md)

## 一、哪些游戏免插件，哪些必须装

**免插件**（主程序直接支持）：RPG Maker MV / MZ、TyranoBuilder、Construct 2/3 及其他 HTML5 游戏。

**必须装对应插件**：

| 你玩的游戏 | 要装的插件 |
| --- | --- |
| RPG Maker XP / VX / VX Ace | RPG Maker Plugin |
| Ren'Py 8 引擎的游戏 | Ren'Py 8.5 Plugin |
| Ren'Py 7 引擎的游戏 | Ren'Py 7.7.1 Plugin |
| Adobe Flash 游戏（.swf） | Ruffle Plugin |
| Godot 4 游戏（GDScript） | Godot 4.3 Plugin |
| Godot 3 游戏（GDScript） | Godot 3.6 Plugin |

插件只装自己用得上的就行——每个几十 MB，全装没必要，装了也不冲突。

## 二、安装顺序与方式

1. **先装主程序，再装插件**，顺序别反；插件彼此之间不分先后。
2. 插件同样是 APK，安装方式与主程序一致：下载后用文件管理器点开安装。首次安装前要先给系统开「安装未知应用」授权（设置 → 应用 → 特殊应用权限 → 安装未知应用，给用来点开 APK 的应用授权）。
3. 装完打开主程序，右上角菜单的插件页面里能看到已装好的插件。

主程序与插件**各自独立更新**，版本号互不对应（主程序 1.21 配插件 1.22 是正常组合）；某类游戏突然集体打不开而别的类正常时，先看看对应插件有没有新版本。

## 三、Ren'Py 插件怎么选分支

Ren'Py 插件按引擎大版本分两支，**选错分支是 Ren'Py 游戏打不开的头号原因**：

- 游戏用 Ren'Py 8 引擎制作 → 装 Ren'Py 8.5 Plugin；
- 游戏用 Ren'Py 7 引擎制作 → 装 Ren'Py 7.7.1 Plugin。

游戏的引擎版本一般写在它发布页的说明或启动画面里；分不清就先装 8.5 这支试，打不开再换 7.7.1。两支插件可以共存，切换成本很低。

## 四、装了插件却"看不见"

常见于小米等 MIUI / HyperOS 机型：系统默认限制应用读取已安装应用列表，插件装了主程序也发现不了。处理：系统设置 → 应用 → JoiPlay → 权限，把「获取已安装应用信息」设为始终允许，重启主程序。

插件补齐之后游戏还是打不开的，就不是插件的事了，按[游戏打不开怎么办.md](游戏打不开怎么办.md)的现象继续排查；从安装包获取到装完插件的完整流程见 [JoiPlay 介绍站](https://joiplay.wrwq.fun/)。
