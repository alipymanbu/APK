# HP Smart 手机打印扫描与复印方法

> 本篇讲在 HP Smart 里发打印任务的两个入口、文件能从哪来、常用打印设置，以及不靠扫描仪、直接用手机摄像头复印和扫描的办法。
> **相关文档**：[打印机添加与无线连接.md](打印机添加与无线连接.md) · [安卓安装步骤与常见问题.md](安卓安装步骤与常见问题.md)

## 一、两个打印入口

主屏幕上「**打印文档**」和「**打印照片**」是两个独立磁贴：文档入口选 PDF 等文件，照片入口选相册图片。先在主屏选中要用的那台打印机（点打印机图像可切换），再进磁贴，免得打完发现发到了另一台上。

## 二、文件从哪来

- **手机本地**：相册里的照片、下载目录里的 PDF 等文件；
- **云账号**：登录后可从 Google Drive、Dropbox 等账号里选内容打印，账号在首次选择来源时绑定；
- **其他应用转发**：微信、邮箱里收到的文件，用系统的「打开方式 / 分享」交给 HP Smart 处理。

一个细节：走远程打印（Print Anywhere）发送时只能打开 PDF 文档，Word、TXT 等格式要先转成 PDF；人就在打印机旁边的话没有这个限制。

## 三、照片打印前可以顺手修

照片入口选中图片后自带一组编辑工具：裁剪、旋转、加滤镜、加文字、调饱和度对比度亮度。只想原样打的话全部跳过也行。

## 四、常用打印设置

发送前在预览页能改（随机型支持程度不同）：

| 设置项 | 说明 |
| --- | --- |
| 份数 | 一次任务打几份 |
| 彩色 / 黑白 | 黑白文档选黑白，省彩墨明显 |
| 纸张尺寸 | A4、照片纸等，要与纸盒里实际放的纸一致 |
| 双面 | 仅带自动双面单元的机型可选 |
| 打印质量 | 草稿省墨，照片任务选高质量 |

纸盒里放的是什么纸，设置里就选什么纸——照片纸打文档这类错配，是打印歪斜、卡纸的常见起因。

## 五、手机当复印机用

安卓和 iOS 版有一个「**复印**」磁贴，不依赖打印机的扫描仪：

1. 打开复印磁贴，用手机摄像头对着文档或证件拍一张；
2. 选尺寸和份数；
3. 选彩色或黑白输出，发送到打印机。

光线均匀、纸面平整时效果最稳，拍的时候尽量让纸占满画面。

## 六、扫描：两种做法

- **走打印机扫描仪**：选「扫描」磁贴，从玻璃板或进纸器扫，适合多页文档；
- **直接用手机摄像头**：对纸面拍摄后自动裁边增强，适合单页、急用、打印机不在旁的场景。

扫完在预览页可以旋转、裁剪，再存成 PDF 或 JPEG，经邮件、云账号或聊天应用分享出去；扫出来一片黑多半是盖板没盖严或玻璃板脏了，有黑边歪斜就在预览里修正。

## 七、把固定流程做成一键快捷方式

「扫描完自动发邮件」「每周打印同一份表格」这类重复动作，可以用快捷方式（Shortcuts）磁贴录成一条：以后点一下磁贴直接跑完，不用每次重新设置。

打不出来、任务卡住这类故障的排查，与添加打印机时搜不到设备的处理，分别整理在[打印机添加与无线连接.md](打印机添加与无线连接.md)与站点常见问题里；应用本身还没装的先过一遍[安卓安装步骤与常见问题.md](安卓安装步骤与常见问题.md)。功能总览与界面截图见 [hp smart 安卓版介绍站](https://hp-smart.xnyx.quest/)。
