# Seetong 是什么？远程监控客户端的功能与日常用法

Seetong 是天视通（TVT）方案监控设备配套的远程查看客户端：把网络摄像机、录像机（NVR）绑到云账号下，就能在手机上实时看画面、收报警、调回放。常见的使用场景是店铺、庭院、仓库、大棚鱼塘这类「人不能一直守着」的地方——装一套摄像头，手机随身看。

相关文章：[监控画面怎么添加到手机](监控画面怎么添加到手机.md) · [收不到报警推送怎么办](收不到报警推送怎么办.md)

## 一、它管的是哪一类设备

天视通方案的摄像机与录像机，机身或包装上一般带 Seetong 云标识；支持 ONVIF 协议的第三方摄像机接进录像机后，同样能在这个客户端里查看。换句话说，判断「能不能用」最直接的办法是看设备来源——天视通方案及贴牌设备基本都覆盖。

## 二、核心功能一览

| 功能 | 说明 |
| --- | --- |
| 多路实时预览 | 画面分割、轮巡、横竖屏切换，不同网络环境可选播放模式 |
| 双向语音对讲 | 设备支持音频输入输出时，可远程喊话对话 |
| 人形侦测告警 | 侦测到人形活动推送通知，比纯移动侦测误报少 |
| 远程录像回放 | 按日期调取历史录像，本地相册统一管理 |
| 云存储 | 关键事件录像自动上传云端，设备被破坏画面也在 |
| 截屏录像 | 预览时随手截屏或录制片段，存到手机 |

## 三、日常用法三条线

1. **看**：打开客户端进设备列表，点通道看实时画面；多路画面用分割视图同屏盯；
2. **管**：设备的添加、改名、删除、时区设置都在客户端里完成，换手机登录同一账号即同步；
3. **防**：设置好人形侦测与布防时间，有动静第一时间收到推送，漏看的在报警记录里补查。

## 四、怎么获取与开始用

安卓端要求 Android 6.0 及以上，安装包约 78MB。注册登录后把设备添加进来（具体见 [监控画面怎么添加到手机](监控画面怎么添加到手机.md)），整个过程不要求手机与设备在同一网络。界面截图与安装文件资源入口都整理在 [Seetong 介绍站](https://seetong.fewf.ren/)，装好客户端后按文章里的步骤走即可。

装好之后想让设备「有动静就通知」，继续读 [收不到报警推送怎么办](收不到报警推送怎么办.md)。
