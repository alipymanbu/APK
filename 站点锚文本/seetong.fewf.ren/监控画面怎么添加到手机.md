# 监控画面怎么添加到手机：扫码、局域网搜索与云 ID 三种方式

设备要先绑进云账号，手机上才能看到画面。Seetong 提供三种添加方式，按手头的条件选：录像机接了显示屏能出二维码，用**扫码**；手机和设备连同一路由器，用**局域网搜索**；人不在设备旁或老设备扫不了码，用**手动输云 ID**。

相关文章：[远程监控客户端功能与用法](远程监控客户端功能与用法.md) · [收不到报警推送怎么办](收不到报警推送怎么办.md)

## 一、先确认设备联网激活

新装的录像机要先联网激活，否则怎么搜都会提示「暂未联网云服务器完成注册」：

1. 录像机接显示器，鼠标右键 →「系统配置」→「网络」，把 IP、DNS 配成路由器下发的内网地址（路由器要能上网）；
2. 状态栏出现「未激活：点击激活」时点它，按提示设置密码——需包含大小写字母和数字，不能用 123456 这类弱密码；
3. 等几分钟连上云服务器；云 ID 在「系统配置 → 网络」或「基本信息」里查看，二维码也在基本信息里。

## 二、方式一：扫二维码

1. 在录像机接的显示屏上进「系统配置 → 系统 → 基本信息」，屏幕显示云 ID 与二维码；
2. 打开客户端，用添加设备里的「扫一扫」对准二维码；
3. 需要时输入设备密码，添加成功后设备出现在列表里。

提示「不合法二维码」多是显示器分辨率不匹配导致二维码变形：把「系统设置 → 常规 → 常规设置」里的分辨率改一档再扫，或改用下面的局域网搜索。

## 三、方式二：局域网搜索

1. 手机连上录像机所连路由器的 WiFi；
2. 客户端右上角「+」→ 选「网络硬盘录像机」→ 局域网搜索；
3. 搜到设备后点添加，输入录像机的系统密码。

## 四、方式三：手动输入云 ID

1. 在录像机显示屏上记下云 ID（一串纯数字）；
2. 客户端里点「+」手动添加，填云 ID、用户名（默认 admin）和激活时设置的云密码；
3. 点「添加」，成功后设备进列表，即获得查看与管理权限。

## 五、两个高频报错

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 不合法二维码 | 显示器分辨率不匹配，二维码变形 | 改分辨率重扫，或改用局域网搜索 |
| 此设备暂未联网云服务器完成注册 | 设备没激活或没连上云 | 按第一节激活设密码，确认网线与 DHCP |

单独添加传统枪机、筒机（不经录像机）时，要先在电脑客户端里启用云平台并设置云密码，且只能实时预览、看不了回放。添加完成后，客户端的功能盘点见 [远程监控客户端功能与用法](远程监控客户端功能与用法.md)；安装包与界面速览在 [Seetong 介绍站](https://seetong.fewf.ren/)。
