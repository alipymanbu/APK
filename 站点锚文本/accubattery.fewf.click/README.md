# AccuBattery 电池数据观察站 · 收录目录

这里收录围绕 AccuBattery（一款 Android 电池监测工具）整理的介绍与使用文章。该工具通过读取充电过程的电流数据，估算电池真实容量（mAh）、逐次记录充电磨损，并提供可拖动的充电警报，站点入口见 [AccuBattery 介绍站](https://accubattery.fewf.click/)。
