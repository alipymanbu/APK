# ChatTTS · 站点导航

这里是 ChatTTS 安卓端的第三方介绍站收录页。ChatTTS 是开源社区里专为对话场景设计的语音生成模型，中英文都能读；安卓端应用把它装进了手机——输入一段文本，挑一个音色，调几组滑块，点一下开始生成，就能听到一段带停顿、语气起伏甚至笑声的自然语音。

站点地址：[ChatTTS 专题站](https://chattts.ggcd.store/)

站内目前整理了两块内容：

- 首页：按「输入文本 → 挑音色 → 调参数 → 开始生成」的实际操作流讲解界面，并把 Audio Seed、temperature、top_P/top_K、文本种子、符号文本优化逐项说清各自管什么；
- 下载页：安卓安装包的获取入口与四步安装流程，附安装被拦、首次启动慢、生成无声音等问题的处理办法。

想在手机上给短视频配音、做听书素材，或者只是想听听一段文字被读出对话感的读者，从这两页开始就够了。
