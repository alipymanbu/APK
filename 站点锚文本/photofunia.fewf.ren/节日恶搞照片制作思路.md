# 节日恶搞照片制作思路

> 万圣节、圣诞、情人节前后，朋友圈总少不了一张应景的整活图。本篇按节日盘点现成模板的玩法，手把手把「恶搞图」的出图时间压到一分钟内。
> **相关文档**：[雪地写字图片怎么做](雪地写字图片怎么做.md) · [人脸合成特效怎么玩](人脸合成特效怎么玩.md)

恶搞图的门槛其实只有一条：找对现成模板。图片特效应用把节日场景做成了分类模板，挑中场景、丢进照片，剩下的交给云端合成。

## 一、按节日选场景

| 节令 | 好用的场景方向 |
| --- | --- |
| 万圣节 | 鬼屋背景、南瓜灯刻脸、恐怖电影海报 |
| 圣诞 | 圣诞贺卡、雪景相框、挂满礼物的圣诞墙 |
| 情人节 | 玫瑰花环相框、巧克力包装、情侣杂志封面 |
| 复活节 | 彩蛋手绘风、春游野餐场景 |

节令模板是限时上新最勤的一批，应用的效果库每周都在云端追加，不升级应用也能看到新模板。

## 二、一分钟出图节奏

1. 打开应用切到对应节日分类（或直接搜节日关键词）；
2. 挑模板看示例图，确认效果再上传照片；
3. 生成后先存相册再分享，避免分享失败白做。

整套玩法的速览与安装入口见 [PhotoFunia](https://photofunia.fewf.ren/) 介绍站。

## 三、两条边界提醒

- 别拿别人的照片整活：上传的照片必须是你有权使用的，涉及他人肖像的恶搞图先征得同意；
- 恶搞归恶搞，别把合成图当真实信息传播——标注一句「效果图」能省去很多解释。
