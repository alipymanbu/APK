# 安卓安装包从哪来怎么装

> pilipili 不走国内主流应用商店，安装包靠网盘渠道分发，装的时候又牵扯「未知来源」授权——第一次装的人多半卡在这两处。这篇把从取包到打开的全流程拆成五步。
> **相关文档**：[是什么软件值得装吗](是什么软件值得装吗.md) · [追番弹幕App怎么用](追番弹幕App怎么用.md)

## 一、安装包从哪取

稳妥的路子只有一条：从专门的介绍站进入网盘分享页取包。pilipili 的介绍页（含界面实拍与功能说明）里放了网盘入口，[pilipili 安卓版介绍](https://pilipili.hfdk.space/) 首页和下载页的按钮都能直达。

不要来路不明的「直装包」——尤其是一些第三方站点套壳重打包的版本，装什么、改了什么没人说得清。

## 二、五步装好

1. **取包**：从介绍页进入网盘分享页，把 APK 安装包转存或下载到手机本地存储。记住用的哪个应用下载的（浏览器还是网盘客户端），下一步给它授权；
2. **开授权**：进系统「设置 → 应用 → 特殊应用权限 → 安装未知应用」（旧版系统在「设置 → 安全 → 未知来源」），给刚才那个下载用的应用打开「允许来自此来源」；
3. **点装**：回到下载管理或文件管理器，点 APK 文件，弹窗里确认「安装」，等进度条走完；
4. **首启授权**：装完点「打开」，应用首次启动会请求存储权限（缓存观看记录用），按需允许就能进首页；
5. **开追**：从新番页或剧场页挑几部加进追更列表，更新提醒从此自动到账。

## 三、装不上先对号入座

- **提示「已阻止安装」**：第二步的授权没做，点弹窗里的「设置」跳过去开就行；
- **提示「解析包出现问题」**：包没下完整，删掉重取一份再装；
- **「安装」按钮是灰色**：手机里可能有同包名的旧版本冲突，先卸载旧的；仍不行说明系统版本过低（低于安卓 5.0），得先升级系统。

装完第一件事，是按[追番弹幕App怎么用](追番弹幕App怎么用.md)里那条主线，把追番列表搭起来——工具装好只是开始，列表建起来才算用上。
