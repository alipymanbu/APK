# 不用 root 的安卓防火墙怎么选

> 想拦住应用偷跑流量、又不想解锁引导和 root 的人，这篇讲清免 root 防火墙的工作前提、挑的时候看什么，以及 NetGuard 在其中处在什么位置。
> **相关文档**：[禁止应用后台联网的设置方法](禁止应用后台联网的设置方法.md)

## 免 root 拦联网，靠的是什么

Android 从 5.0 起向普通应用开放了 VpnService 接口：应用可以在本机创建一条虚拟网络通道，把设备的出站流量先引到自建的过滤层再放行。免 root 防火墙全都建立在这个前提上——你没有系统最高权限，但你可以"占住"这条通道，让所有联网请求先过一遍你定的规则。

代价也有两个：

- 通道只有一条，同一时间只能有一个应用占用。装了免 root 防火墙，就不能再并行开代理、加速器或另一款 VPN 类应用；
- 通知栏会常驻一条"VPN 连接"提示，系统设置里它会以 VPN 的身份出现。这是机制本身，不是异常。

## 挑的时候看什么

| 看什么 | 为什么重要 |
| --- | --- |
| 流量是否只在本机过滤 | 有些同类产品会把流量导去自建服务器中转，等于把所有联网都交给别人过目；纯本机过滤则没有这个问题 |
| 是否开源 | 规则引擎决定谁能联网，代码可查才有底气说"不偷偷上报" |
| 有没有统计与广告 | 防火墙本身若带追踪代码，等于请了个看门的顺便翻你快递 |
| 规则粒度 | 至少要能按应用、按 Wi-Fi 与移动数据分开控制；能按地址过滤更好 |
| 体积与兼容 | 防火墙是常驻应用，安装包轻、老系统也能跑，才谈得上一直开着 |

## NetGuard 的位置

[NetGuard](https://netguard.fwen.ren/) 是这个品类里常被提起的一款：开源（GPLv3）、安装包 3MB 上下、Android 5.1 起可用，过滤全程发生在手机本地，流量不经过外部服务器，源码里也没有统计与追踪代码。控制粒度上，它支持按应用分开管 Wi-Fi 与移动数据，还有漫游拦下、亮屏才放行、管理系统应用等条件规则；进阶的按地址过滤与流量日志导出（PCAP 格式）放在专业版里。

它的具体设置动作，整理在[禁止应用后台联网的设置方法](禁止应用后台联网的设置方法.md)里，照着点就行。

## 两句提醒

- 免 root 防火墙管不了已经被授予设备管理权限的机型策略，单位配发的手机装之前先想清楚；
- 热点共享出去的设备流量不在管辖范围——规则只对本机可靠生效，别指望它顺带管住接进热点的笔记本。
