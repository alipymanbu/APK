# 积分与每日免费额度

> 本篇讲 AnyGen 的积分机制：不付费能不能一直用、积分从哪来、花在哪、导出次数为什么是另一套账。按其公开资料与第三方评测整理（截至 2026-09 的口径），具体数额以应用内「订阅与账单」页显示为准。

## 一、免费的底线

有免费档，不用先付费就能一直用：**每天登录就有一笔固定积分到账**。轻量使用（偶尔生成一篇文档、做一次纪要）靠每日积分是能自洽的；高频产出才需要考虑加积分的渠道。

量级参考：有第三方评测称每日登录可领 200 积分，让 AI 分析一份 145 页的 PPT 约消耗 315 积分。这两个数字没出现在产品文档里，只当「一次任务大概烧多少」的数量级参考。

## 二、积分从哪来、花在哪

| 渠道 | 说明 |
| --- | --- |
| 每日登录 | 长期机制，登录即有 |
| 新手任务 | 首次使用完成引导任务，拿额外积分 |
| 邀请与分享 | 限时活动，有没有、额度多少以应用内活动页为准 |
| 充值包 | 个人中心直接购买 |

生成任务的各环节都消耗积分。查账入口在「订阅与账单」页面：总共得过多少、还剩多少、每条任务各花了多少都有明细。发现积分掉得比预期快，先看是哪个任务消耗大，再回头看那次需求是不是返工太多。

## 三、导出次数是另一套账

免费档的每日下载次数有限，和积分分开算：积分够、导出次数用完，当天照样导不出文件。做 PPT、批量导内容的人最容易在这撞墙。撞限额当天有个不花钱的替代思路：把要导的合并成更少的任务，一次导完。

Pro / Max 两档订阅的差异集中在并发任务数、生成速度、积分上限与每日下载限额上。要不要升的判断很简单：算一下每天的生成量把免费积分和导出限额用满了没有，用不满就不用升。

## 四、装好之后先领积分

安卓安装文件资源的获取入口见 [AnyGen 介绍站](https://anygen.fedq.quest/)。装完第一件事：登录账号领当日积分，顺手把新手任务做一遍——任务完成有额外积分，还能把主要功能都点一遍。
