# SafeW 安卓下载安装完整步骤

> 本篇讲 SafeW 安卓安装包从哪取、装之前怎么放行未知来源、四步装好，以及装不上时按什么顺序排查。
> **相关文档**：[加密机制与隐私安全解读](加密机制与隐私安全解读.md) · [注册登录与隐私设置要点](注册登录与隐私设置要点.md)

---

## 一、取包前先认准版本

网上叫 SafeW 的站点很多，版本号与系统要求的说法不统一。以近期收录的安装包为准：版本 1.8.5、体积约 84 MB、安卓安装包包名 `org.safew.chat`。装完在系统「设置 → 应用管理 → SafeW → 应用详情」里核对包名，对得上才说明装的就是这一款。

安装文件资源存放在网盘分享里，本文不贴网盘地址——完整入口与分步指引整理在 [safew 介绍站](https://safew.usea.quest/) 的下载页里，点获取按钮就能进。

## 二、四步装好

1. **转存资源**：打开介绍站下载页的获取按钮进入网盘分享页，登录夸克账号后「保存到我的网盘」（手机浏览器网页版同样能操作，不装夸克 App 也行）；
2. **下载 APK**：在自己网盘的对应文件夹里把 APK 下载到手机存储，完成后在通知栏或「文件管理 → 下载」里找到它；
3. **放行未知来源**：安卓 8.0 以上不用开全局开关——点开 APK 时系统会弹「是否允许此来源安装应用」，给浏览器或文件管理器放行一次即可；MIUI、HarmonyOS、ColorOS 等国产系统的入口在「设置 → 安全 / 更多设置 → 安装未知应用」，有的系统多弹一次风险确认，属正常流程；
4. **安装并打开**：点「安装」等进度走完，打开注册登录就能用。

## 三、装不上的排查顺序

按出现概率从高到低：

| 现象 | 常见原因 | 处理 |
|---|---|---|
| 解析包时出现问题 | 下载不完整、文件被截断 | 删掉重下，核对体积是否与约 84 MB 对得上 |
| 应用未安装 | 已有同包名旧版且签名不一致 | 先卸载旧版再装 |
| 空间不足 | 剩余存储不够 | 清出至少 1 GB 再试 |
| 被安全软件拦截 | 非商店来源的通用提醒 | 核实来源后自行决定是否继续 |
| 提示系统版本过低 | 安卓版本不满足要求 | 升级系统或换设备，以安装时的系统提示为准 |

## 四、装好之后

- 注册登录的几种方式与多设备同步的注意点，见 [注册登录与隐私设置要点](注册登录与隐私设置要点.md)；
- 装机后建议先开截图提醒、给敏感对话设定时销毁，理由与设置路径见 [加密机制与隐私安全解读](加密机制与隐私安全解读.md)。

SafeW 同时有 Windows、macOS、Linux 与 iOS 客户端，一个账号多端同时在线；桌面端渠道真假难辨，动手前把「认包名」的习惯带过去。
