# KOReader 和 Readest 怎么选

两款软件经常被放在一起搜，是因为它们确实同源——Readest 出自 KOReader 原作者之手。但两条产品路线如今已经分得很开：一个扎在墨水屏与极客自定义里，一个做全平台的日常阅读。这篇按使用场景把选择思路摆开，想直接看产品资料的，可以从 [Readest 多平台阅读器介绍](https://readest.rggd.pw/) 入手。

## 同一个起点，两条路线

KOReader 是电纸书社区里服役多年的开源阅读系统，以极强的自定义和墨水屏适配著称，至今仍由社区维护推进。它的原作者后来另起炉灶，把经典桌面阅读器 Foliate 的思路用现代跨平台技术栈重写了一遍，2024 年 10 月在 GitHub 开源（[github.com/readest/readest](https://github.com/readest/readest)，AGPL-3.0 协议），这就是 Readest 的由来。

所以"谁抄谁"的担心不成立：两者是同一脉的兄弟产品，代码各自独立，更新也互不牵扯。

## 什么人适合 KOReader

- 主力设备是**电纸书 / 墨水平板**：KOReader 对各类墨水屏机型的适配深度，短期内没有对手；
- 喜欢折腾：手势、插件、渲染参数几乎全部可调，愿意花一个下午配置出专属阅读器；
- 不在乎界面现代化：它的 UI 以功能为先，新手上手需要一点耐心。

## 什么人适合 Readest

- 在**手机、电脑之间接力阅读**：Android、iOS、Windows、macOS、Linux 加网页版一套全齐，进度、标注、书文件自动同步；
- 想开箱即用：现代界面，导入书就能读，排版、主题、双语对照翻译都在设置面板里点两下的事；
- 看重数据自主：除了内置账号同步（免费 500MB），也能换成 OneDrive、WebDAV、iCloud 自己的存储。

## 一张表看清取舍

| 维度 | KOReader | Readest |
| --- | --- | --- |
| 主要阵地 | 墨水屏 / 电纸书 | 手机 + 电脑 + 网页全平台 |
| 上手难度 | 偏高，配置项多 | 低，导入即读 |
| 同步方式 | 插件对接为主 | 账号同步 + 自选网盘 |
| 界面风格 | 功能流 | 现代阅读应用 |
| 开源协议 | AGPL-3.0 | AGPL-3.0 |

两款都开源免费，其实并不冲突：不少重度读者的组合是墨水屏上跑 KOReader，手机和电脑交给 Readest，两者通过同步通道互认进度。相关阅读：[阅读进度多设备怎么同步](阅读进度多设备怎么同步.md)、[双语对照翻译怎么开](双语对照翻译怎么开.md)。
