# FunBox 模块 · funbox.fewz.tech

FunBox（前身 HaveFunPanel）是一个跑在 LSPosed 框架里的功能模块，装好激活后，微信、QQ 的聊天窗口里会多出表情面板与语音面板：长按就呼出，存图、斗图、发语音都比原生顺手。本目录收录围绕它的介绍与使用文章，功能全景与安装包资源的获取入口见 [FunBox 介绍站](https://funbox.fewz.tech/)。
