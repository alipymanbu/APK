# 微信QQ表情面板怎么加

微信自带的表情收藏有上限，斗图要的图又常常躺在相册里来回翻。想把「表情面板」这种玩法搬进微信和 QQ，目前圈子里的主流路子是模块方案：用 LSPosed 框架加载一个功能模块，在聊天窗口里加出专属面板。这篇讲清思路与落地步骤，想直接看功能全景的可以去 [FunBox 介绍站](https://funbox.fewz.tech/)。

## 一、思路：不是换软件，是加面板

这类方案不要求你换聊天软件，微信、QQ 还是原来那些，聊天记录、好友都不动。变化只有一点：激活模块后，聊天输入区长按表情会多呼出一个**表情面板**，长按语音则呼出**语音面板**。面板就挂在聊天窗口里，随用随呼，不用切应用。

以 FunBox 为例（它的前身叫 HaveFunPanel，4.0.0 起改名），表情面板能做的事包括：

- 聊天里收到的好图一键保存进面板，不用先存相册再上传；
- 在线表情库按沙雕、萌系、二次元等风格分类，看中直接收藏；
- 发送可选「以图片发」或「以表情发」，前者兼容性好、后者动图能播；
- 最近发送支持长按删除、跨包归类，最近列表的容量也能调。

## 二、落地要过四关

1. **框架关**：LSPosed 一般经 Magisk / KernelSU 等 Root 方案安装，这是整个玩法的前提；
2. **安装关**：模块本体是一个普通 apk，装上后自带管理界面；
3. **作用域关**：到 LSPosed 里把模块的作用域勾上微信和 QQ，需要哪个勾哪个，作用域越小越稳；
4. **重启关**：强制停止微信 / QQ 或重启手机——模块在聊天进程启动时注入，旧进程不重启，前面全白做。

重启后打开微信进「设置」页，能看到模块的面板入口就是激活成功。安装包的获取入口与更细的安装步骤，[FunBox 介绍站](https://funbox.fewz.tech/)的下载页写得比较全。

## 三、几个常见疑问

**QQ 也能用吗？** 能。模块的作用域同时支持微信和 QQ，收录信息里还提到 TIM；不过 QQ 本体升级后面板偶尔会跟着失效，等模块更新适配是常态。

**会动我的聊天记录吗？** 不会改聊天软件的安装包，卸载模块后聊天软件回到原生行为。但面板的保存、推荐功能运行在聊天进程内，会接触到消息内容，介意就把推荐类开关关掉。

**装完没效果怎么办？** 九成是漏了重启这一步，剩下的按 [模块装完没反应怎么排查](模块装完没反应怎么排查.md) 对着现象查。

表情玩腻了还可以试试语音面板的玩法，见 [聊天语音包与文字转语音玩法](聊天语音包与文字转语音玩法.md)。
