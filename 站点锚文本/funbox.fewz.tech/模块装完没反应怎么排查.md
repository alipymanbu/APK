# 模块装完没反应怎么排查

给 LSPosed 装了模块，重启之后聊天软件里却毫无动静——这是模块玩家最常撞上的坎。多数情况不是模块坏了，而是链条里有一环没扣上。这篇以 FunBox（微信 / QQ 的表情与语音面板模块）为例，按现象把排查路子过一遍；还没装好的先去 [FunBox 介绍站](https://funbox.fewz.tech/) 把安装步骤走完再回来。

## 一、装完毫无动静

按顺序过这五项，命中哪项修哪项：

1. **总开关**：LSPosed 管理器 → 模块，模块的开关是否打开；
2. **作用域**：进模块的作用域页，微信 / QQ 是否勾上——只勾了模块不勾作用域，等于装而未用；
3. **重启**：勾完有没有**强制停止**聊天软件或重启手机。模块在聊天进程启动时注入，这是最常漏的一步；
4. **入口确认**：重启后打开微信进「设置」页，找模块的面板入口；入口在但没效果，进去把启用开关打开；
5. **框架版本**：以上都对还不行，把 LSPosed 升到较新版本。

一个有用的对照点：LSPosed 日志里出现 `Failed to init Isplant` 之类的提示，属于框架适配问题，不是模块本身的问题——看到它就把精力放在框架版本上，别在模块设置里来回折腾。

## 二、QQ 里的特殊现象

- **安卓 12 上 QQ 找不到入口**：老版本模块在这系统上确实有此问题，升级模块可解；
- **QQ 升级后长按菜单消失**：聊天软件本体大版本升级后，模块跟着失效是常态，等模块更新适配；
- **群里收到特定动图就闪退**：较新的模块版本里加了「阻止闪退」开关，拦下已知的异常动图，去模块设置里找它打开。

## 三、功能开了却用不了

- **表情加载转圈**：在线表情要联网获取，只有已下载的能离线用；网络环境受限时在线资源可能一直转圈，换个网络再试；
- **保存失败 / 提示空间不足**：进模块设置的存储管理清临时文件，素材多就迁移到外部存储；
- **功能开关点不动**：先确认模块版本较新，再重启手机或重新授权权限，部分机型关掉省电模式试试。

## 四、还没解决的话

把模块停用，确认聊天软件本身一切正常，再逐项把上面的路子重过一遍。装好之后长期使用还有一批值得留意的坑，比如微信 / QQ 升级前先备份聊天记录、作用域别勾进支付银行类应用——这些在 [微信QQ表情面板怎么加](微信QQ表情面板怎么加.md) 的注意事项里都有展开。玩转面板之后，语音面板的玩法见 [聊天语音包与文字转语音玩法](聊天语音包与文字转语音玩法.md)。
