# 聊天语音包与文字转语音玩法

打字嫌慢、斗图嫌吵，聊天里还有第三种表达：语音包。不用自己开口录，选一段现成的发出去，气氛立刻不一样。这篇讲语音包玩法怎么在微信、QQ 里落地——以 FunBox 模块的语音面板为例，选、录、导、变四条路都通；模块还没装好的先去 [FunBox 介绍站](https://funbox.fewz.tech/) 看安装步骤。

## 一、入口：长按语音

激活模块后，在聊天输入区长按语音图标就能呼出语音面板，和表情面板是并排的两块。面板会记住你上次停在哪个分类、听到哪一条，下次接着用。

## 二、四条素材路

| 玩法 | 做法 |
| --- | --- |
| 用现成的 | 面板里按分类挑（DJ、恶搞、铃声等），先试听再发送，不占自己的存储 |
| 自己录 | 面板里点录音，说完保存；文件落到你在设置里指定的存储路径，路径和文件名都能自己挑 |
| 导入本地 | 手机里已有的音频从面板右上角的导入口选文件，进了自定义分类统一管理 |
| 文字变语音 | 输入文字生成语音再发送，不想开口的话让模块替你说 |

## 三、两个顺手的细节

- **silk 转 mp3**：QQ 语音常见的 silk 格式音频可以转成 mp3 再处理，想把它在别的设备上回放就不用再折腾格式；
- **路径设好再玩**：录制和转换的文件都落在模块设置里指定的存储路径，先把路径指到一个你常整理的目录，日后再找不会乱。早期版本里「存储路径第一次点不动」「设了无效路径后闪退」这类问题都修过，遇到先升级模块。

## 四、玩语音也要守边界

语音好玩，但自动化类的红线别碰——批量自动发送、自动抢红包一类行为是账号风控的重点，开发者自己也早就把抢红包功能移除了。老实用面板发着玩，风险最小。

表情面板的加法与整体激活流程见 [微信QQ表情面板怎么加](微信QQ表情面板怎么加.md)；装完面板没动静的，按 [模块装完没反应怎么排查](模块装完没反应怎么排查.md) 对着现象查。
