# 手机常驻 AI 智能体是什么体验

> 一类「长在手机里、一直在线」的智能体应用正在多起来。本篇讲它和普通聊天 App 差在哪、能接什么、能干什么、适合谁，并以其中一款安卓应用 ZeroAI 为例展开。

## 从「养龙虾」说起

个人 AI 智能体 OpenClaw 走红后，中文社区把训练它叫成「养龙虾」，各手机品牌与大厂也纷纷跟进自己的方案。不过大部分大厂产品走的是云端路线：智能体跑在厂商的云沙箱里，手机只是发指令的遥控器。

另一条路线是把智能体直接装进手机本地，ZeroAI 就是这一类里的代表——一款安卓应用，智能体核心以 Rust 编写、界面用 Kotlin 写，装好之后以前台服务形态常驻，不再依赖谁家的云端环境。

## 和聊天 App 差在哪

| | 普通聊天 App | 常驻型智能体应用 |
| --- | --- | --- |
| 交互方式 | 一问一答 | 下达目标，由它拆成步骤执行 |
| 在线状态 | 打开才在 | 前台服务持续运行，随时接活 |
| 模型选择 | 绑定一家 | 一个应用里配置多家，按需切换 |
| 费用 | 订阅或免费额度 | 按各供应商的 API 用量计费 |
| 触达渠道 | 只在应用内 | 能伸进聊天软件、邮箱等外部通道 |

一句话：只想随手问答，聊天 App 更省事；想让 AI 替你盯任务、跑流程、守着消息，才是这类应用的用武之地。

## 以 ZeroAI 为例，它长什么样

按公开资料与真机截图，ZeroAI 的形态大致是：

- **常驻但不失控**：仪表盘能看到守护进程状态与运行时长，另有醒目的「紧急停止」按钮，随时一键叫停；
- **模型随你换**：OpenAI、Anthropic、Gemini、Grok、DeepSeek、Qwen、Ollama、OpenRouter 八家按开关接入，密钥自己申请、用量自己掌控；
- **通道往外伸**：Telegram、Discord、邮箱、Google Messages 都能接，同一条智能体在不同地方替你应答；
- **带一把真终端**：内置 Terminal 支持斜杠命令，切到 TTY 模式后可以 SSH 直连服务器，手机秒变随身运维台；
- **能自己动手**：网页搜索、抓取、HTTP 请求、多模态这些工具齐全，智能体还能在推理过程中自己写脚本、跑脚本；
- **有点彩蛋**：内置一个由 AI 自己操作的 Game Boy 模拟器，说一句「play pokemon」就能围观它打游戏。

想看更完整的功能清单、真机界面与安装入口，可以逛逛 [ZeroAI 介绍站](https://zeroai.wrwq.fun/)。

## 适合谁、不适合谁

适合的人大致有三类：愿意花十几分钟申请 API 密钥、想自己控制模型与开销的人；有重复性活要交出去（定时汇总、盯消息、批量整理）的人；想给聊天软件挂一个自己的机器人、或在手机上管服务器的人。

先想清楚再装：它不内置模型额度，不配密钥基本用不起来；后台常驻意味着常驻通知与耗电；项目仍处于实验阶段，别一上来就把要紧事全交给它。
