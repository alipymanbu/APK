# 安卓 AI 智能体的安装与密钥配置

> 本篇讲把 ZeroAI 装进安卓手机的完整路径：从哪里拿安装文件、装的时候会被什么拦、首次启动要做哪几件事、模型密钥怎么配，以及装完没反应时的排查思路。
> **相关文档**：[手机常驻AI智能体是什么体验.md](手机常驻AI智能体是什么体验.md) · [让AI机器人接管Telegram和Discord.md](让AI机器人接管Telegram和Discord.md)

---

## 装之前先确认三件事

- **系统版本**：ZeroAI 要求 Android 9 及以上，老设备装不了；
- **心里有数**：它不送模型额度，装完还需要至少一家供应商的 API 密钥才能真正干活，密钥自己申请、用量自己付费；
- **存储空间**：预留出安装包两倍以上的空闲，安装过程需要展开临时文件。

## 从哪里拿安装文件

ZeroAI 的安装文件通过 [ZeroAI 介绍站](https://zeroai.wrwq.fun/) 的下载页统一指引获取：站点会带你到网盘分享页，把文件转存到自己的网盘账号后，再用网盘 App 下载到手机本地存储。下载完留意一下文件大小是否与网盘内标注一致，明显偏小说明没下完整，重新下载即可。

## 安装四步

1. **点开安装包**：在文件管理器里找到下载好的 apk，点它开始安装；
2. **允许未知来源**：首次安装系统会拦一次，按弹窗跳到设置，允许对应应用「安装未知应用」，返回后再点一次安装包；
3. **过引导页**：一路 Next 过完欢迎说明；
4. **完成首次设置**：期间有两件事别跳过，下面单独说。

各品牌对「安装未知应用」的入口叫法不同，类原生系统在「设置 → 应用 → 特殊应用权限」里，小米、OPPO、vivo 等通常在弹窗里直接给授权按钮，照着走即可。

## 首次启动的两个关键设置

- **电池优化豁免**：这是它后台常驻的前提。跳过了这一步，之后指令发出去没动静多半就是这个原因——去「设置 → 应用 → ZeroAI → 电池」里改成不受限制即可补上；
- **应用 PIN**：它管着你的密钥和通道配置，值得加一道锁。PIN 没有找回途径，务必记牢。

## 配模型密钥

进主界面后，在 Agents 页按开关接入模型供应商。选择上可以按这个思路：

| 想法 | 可以先接 |
| --- | --- |
| 国内网络环境省事 | DeepSeek、Qwen（DashScope） |
| 生态与多模态 | OpenAI、Google Gemini |
| 追求性价比与聚合 | OpenRouter（一个密钥转发多家） |
| 想完全本地跑 | Ollama |

密钥在各家平台的开发者页面自行申请，填进应用即可。同一会话支持供应商级联与智能路由，一家不够它会自动换下一家。

## 装完没反应的排查顺序

1. 指令发出去没动静 → 先查电池豁免与省电白名单（见上文）；
2. 应用内状态不是 ● Running → 回仪表盘看守护进程是否停止，重新启动；
3. 想确认它到底在干什么 → 底部 Terminal 输入 `/help` 看可用命令，`/cost` 看会话开销。

装好之后想让它守在聊天软件里替你应答，继续读 [让AI机器人接管Telegram和Discord.md](让AI机器人接管Telegram和Discord.md)；对这类应用的定位与边界先补课，看 [手机常驻AI智能体是什么体验.md](手机常驻AI智能体是什么体验.md)。
