# 让 AI 机器人接管你的 Telegram 和 Discord

> 本篇讲怎么把 ZeroAI 接进 Telegram 与 Discord：机器人怎么创建、Token 填在哪里、接好之后它能替你做什么，以及两个真会踩的坑。

## 为什么要接聊天软件

手机本地常驻的智能体，价值不只在应用内那块屏幕：接上通道后，它在 Telegram 群里被 @ 就能答话，在 Discord 服务器里随叫随到，你人在外面、手头只有聊天软件时照样能派活。ZeroAI 支持的通道包括 Telegram、Discord、邮箱（IMAP/SMTP）、Google Messages（实验性）与应用内终端，本篇只讲最常用的前两个。

## 接 Telegram：三步

1. **创建机器人**：在 Telegram 里找 BotFather，发送 `/newbot`，按提示起名并选一个用户名，完成后会拿到一串机器人 Token；
2. **填进应用**：打开 ZeroAI，进 Hub 的 Apps 区，把 Token 填到 Telegram 通道的配置里并启用；
3. **对话验证**：在 Telegram 里给你的机器人发条消息，它回复了就说明通道已通。

创建机器人、拿 Token 这些动作在 BotFather 对话框里就能完成，全程不需要写代码。

## 接 Discord：同样是三步

1. 在 Discord 的开发者后台新建应用并添加机器人，拿到 Bot Token；
2. 决定权限与意图（想读消息、回消息，就把对应的勾打上），生成邀请链接，把机器人拉进你的服务器；
3. 回到 ZeroAI 的 Hub，把 Discord 的 Token 填入并启用，群里说话测试一下。

## 接好之后能干什么

- **群里待命**：被提及或私聊时由智能体应答，模型走你在 Agents 页配置的那几家；
- **派长活**：让它定时汇报、盯关键词、整理频道内容——常驻服务到了点自己会动；
- **跨通道一致**：Telegram 里交代的事与 Discord 里问的结果是同一个智能体、同一套记忆，不用两边重复交代。

## 两个真会踩的坑

- **Token 别外泄**：机器人 Token 等于它的操控权，发出去谁都能顶替它说话。Token 意外泄露时，去创建处重置一个再填回应用；
- **记住手机别断电**：智能体跑在你的手机上而不是聊天软件的服务器里，手机关机、断网或后台被杀，机器人就下线了。装完先做电池豁免那一步，细节见 [安卓AI智能体安装与密钥配置.md](安卓AI智能体安装与密钥配置.md)。
