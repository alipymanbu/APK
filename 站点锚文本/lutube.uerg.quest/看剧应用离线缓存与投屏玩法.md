# 看剧应用离线缓存与投屏玩法

> 本篇讲两件让观影更自由的事：把片子缓存到手机里离线看，以及投到电视大屏上看。以 lutube 的实际操作为准（v1.1.90 已支持下载与离线播放），其他版本的入口名称可能略有差异。
> **相关文档**：[安卓影视应用怎么下载安装.md](安卓影视应用怎么下载安装.md) · [视频播放转圈闪退问题排查.md](视频播放转圈闪退问题排查.md)

## 一、离线缓存：通勤与弱网环境的刚需

lutube 支持把在线视频下载到手机本地、断网也能播放：

1. 在片库或搜索结果里找到想存的片子；
2. 点视频条目旁的**下载**按钮（有的版本这个按钮在播放页里）；
3. 弹出清晰度选择时选一个，开始缓存；
4. 缓存完成后，到**我的 → 本地播放**（有的版本叫「离线缓存」「我的下载」）里找到并播放。

几点提醒：

- 缓存依赖存储权限，点下载没反应时，先去系统设置确认存储权限已经打开；
- 缓存的视频默认只能在应用内播放，拷到别的播放器不一定认得；
- 标了 VIP 的内容能否缓存以应用内提示为准，部分内容只允许在线看。

应用的功能定位与安装入口见 [lutube 安卓影视应用介绍站](https://lutube.uerg.quest/)，这里只展开玩法。

## 二、缓存占满空间时

- 应用设置里一般有**清理缓存**入口，定期清一次，应用整体状态也会更稳；
- 看完的离线视频在本地播放列表里逐条删除；
- 分清「缓存」和「下载的视频」：清缓存通常不会动你特意存的片子，但两个入口常常相邻，删之前看清楚名字。

## 三、投屏到电视

把手机里的片子放到电视上看，按家里设备的类型选路径：

1. **先确认同一局域网**：手机和电视（或盒子）连的是同一个 Wi-Fi，这是投屏成立的前提；
2. 在应用里打开想看的视频，点**分享**按钮（或播放页上的投屏图标）；
3. 在弹出的设备列表里选你的电视 / 盒子，连上后画面就上大屏了。

| 家里的设备 | 能不能直接投 |
| --- | --- |
| 支持 DLNA 的电视 / 盒子 | 可以，应用里直接选设备 |
| 不支持 DLNA | 借助 Chromecast 这类投屏设备中转 |
| 两种都没有 | 用手机系统的无线投屏（各品牌叫「智能投屏」「无线显示」「多屏互动」）做整体镜像 |

搜不到设备时按这个顺序查：手机和电视是否真的在同一个 Wi-Fi、路由器是否开了「AP 隔离」（开了会挡住设备互相发现）、电视端的投屏接收服务有没有被安全软件禁用。

## 四、小屏之外的其他看片姿势

- **画中画 / 悬浮窗**：退出播放页后视频缩成小窗继续播，边回消息边看；有的版本把这个叫「悬挂模式」，入口在播放页，找不到就说明该版本没带；
- **倍速**：全屏唤出播放控制条后调，赶进度和二刷都用得上；
- **手势操作**：播放界面左右滑动调进度、上下滑动控亮度音量，不用特意去找按钮。

这些都救不了放不出来的片源——视频转圈先按 [视频播放转圈闪退问题排查.md](视频播放转圈闪退问题排查.md) 的顺序处理，装应用的过程则参考 [安卓影视应用怎么下载安装.md](安卓影视应用怎么下载安装.md)。
