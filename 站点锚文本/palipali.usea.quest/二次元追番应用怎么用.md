# 二次元追番应用怎么用

> 本篇讲从打开一款追番应用到稳定追更的完整路径：首页怎么逛、怎么搜番、播放页有哪些操作、怎么靠收藏和进度记忆把追更变成不用动脑的事。以 palipali（帕哩帕哩）为例，其他同类应用的思路也通用。
> **相关文档**：[追番应用打不开与加载失败怎么办](追番应用打不开与加载失败怎么办.md) · [离线缓存与画质怎么选](离线缓存与画质怎么选.md)

## 一、先逛首页，再谈技巧

palipali 打开后不需要登录就能直接用，首页默认是推荐流，按热门程度排当前的动漫作品，点封面就能进详情页；往下翻会按热血、恋爱、搞笑这类题材分组陈列。第一次用、还没想好看什么的时候，先把首页翻一遍，比到处找片单效率高。

首页还有两个常用入口：

- **搜索框**：在页面顶部，明确知道要看什么时用它最快。
- **榜单入口**：通常在搜索框附近，点进去是热播榜（动漫、电视剧、电影、综艺等分类排行），不知道看什么就来这逛逛。

## 二、搜番的正确姿势

1. 点顶部搜索框，输入番剧名称。支持中文原名，部分版本也认别名或拼音缩写；记不清全名就输入最有辨识度的两三个字。
2. 在结果列表里按封面和年份认准你要的那部——同名翻拍不少，注意别点错。
3. 进详情页先看简介和剧集列表，确认是你要的版本，再点第一集开看。

搜不到时先换关键词（全名 → 简称 → 别名）再试；换了几轮还是搜不到，那部作品可能就是不收录，属于内容覆盖的问题，不是操作错了。

## 三、播放页的常用操作

进播放页后，点一下屏幕中央呼出控制栏，常用的都在这里：

| 你想做的事 | 怎么做 |
| --- | --- |
| 快进 / 快退 | 拖动底部进度条；看长番时直接拖比按倍速跳更准 |
| 换一集 | 在控制栏里点「选集」，点对应集数即切换 |
| 调清晰度 | 控制栏里的画质选项，卡顿先切「流畅」 |
| 看讨论 | 播放画面上滚动显示其他观众的评论，部分版本支持发弹幕 |
| 全屏 | 点全屏按钮，或旋转手机自动切换 |

## 四、收藏、进度与追更

追番主要靠这三个机制：

- **收藏**：播放页或详情页点收藏，之后从「我的收藏」（或书架）进入，不用再搜索。
- **进度记忆**：看过的每一集自动记进度，下次打开从上次的位置继续。
- **更新跟进**：连载中的番更新后，进详情页或收藏列表就能看到新一集；上线节奏以应用内实际显示为准。

刚装好还没用过、想先把功能摸熟的，建议先拿一部短番把「搜 → 看 → 收藏」走一遍；遇到打不开、加载转圈的情况，去 [追番应用打不开与加载失败怎么办](追番应用打不开与加载失败怎么办.md) 对症排查；通勤路上想离线看，看 [离线缓存与画质怎么选](离线缓存与画质怎么选.md)。
