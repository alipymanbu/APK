# Typeless 和普通语音输入的区别：不是转写，是整理

> 本篇回答一个常见疑问：手机自带的语音输入已经能用，为什么还要换 Typeless。核心差异在三处——成稿质量、格式化能力、跨语言与隐私的处理思路。
> **相关笔记**：[语音键盘怎么用](语音键盘怎么用.md) · [翻译与多语言场景](翻译与多语言场景.md)

---

## 一、自带听写是逐字记，Typeless 是替你理稿

传统语音输入的目标是「把音节原样落成字」：语气词、重复、中途改口全都留在屏幕上，说完还得自己删改。Typeless 的处理在云端过一轮 AI：口述内容先被理解，再按书面的习惯输出——

- 「嗯、那个、就是说」不进成稿；
- 「明天七点——不对，下午三点」只留最终说法；
- 念清单自动排成项目符号列表，口述邮件自带称呼与落款；
- 同一件事，在邮件应用里出稿更正式，在聊天应用里更随意。

一句话：自带听写给你的是「说的过程」，它给你的是「想清楚的结果」。

## 二、速度口径

厂商给出的对比数据是：语音键盘约 220 wpm，普通键盘打字约 36～45 wpm，相差数倍。即便日常口述达不到上限值，「先说一遍再微调」也比逐字敲快，尤其是微信长回复、邮件开头这类最耗时间的内容。

## 三、能力面不一样

| 维度 | 自带语音输入 | Typeless |
| --- | --- | --- |
| 整理能力 | 逐字转写 | 去语气词、去重复、留最终版 |
| 格式化 | 无 | 列表、分段、称呼落款自动排 |
| 语音编辑 | 无 | 选中文字说出改法即生效 |
| 翻译 | 需另开翻译工具 | 长按上滑，译文直接进输入框 |
| 词典 | 无 | 专有名词越用越准 |
| 高质量转写 | 部分可离线 | 需联网，云端处理 |

## 四、代价也要说清楚

它对网络的依赖比自带输入大：断网时出不了高质量成稿，这是换取整理能力的前提。隐私方面，厂商声明云端零留存、内容不用于训练模型，历史默认只在本机、保留时长可自选；介意音频经过服务器的场景（如涉及敏感内容的口述），这块键盘并不合适。

## 五、适合先装来试试的人

微信里要回大段话、邮件周报开头难、通勤路上记想法、要跟外语伙伴来回沟通——这四类场景的收益最直接。安装包与安装步骤见 [Typeless 语音键盘介绍站](https://typeless.qhah.skin/)，装好后前 30 天是全功能试用，够判断值不值得留下来。
