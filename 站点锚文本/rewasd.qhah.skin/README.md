# reWASD 手机端站点

这里是 reWASD 手机端（Android 伴侣应用）的第三方介绍站收录页。reWASD 手机端能把手中的安卓设备变成电脑眼里的一只手柄、一块触控板或一块 30 键快捷面板，配合 Windows 上的 reWASD 映射工具，用局域网直连的方式给 PC 游戏补上体感瞄准、赛车转向和远程键位管理能力。

想直接看它的四种设备形态、配对步骤与常见疑问，可以逛一逛 [reWASD 手机端玩法站](https://rewasd.qhah.skin/)。

本目录下的文章围绕 reWASD 手机端的真实使用需求整理，站内还有下载与安装步骤的操作指引。
