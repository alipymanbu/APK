# x 模式三档性能与场景配置怎么用

> 本篇讲 ROG 游戏手机上 x 模式三档强度的差别、高档位的解锁条件，以及怎么用场景配置让每个游戏自动套用预设。风扇对高档位的影响见[是什么与能干什么.md](是什么与能干什么.md)。

## x 模式做了什么

x 模式是 ROG 手机专为游戏准备的高性能模式：开启后自动清理后台、释放内存、提升硬件调度效率。日常社交、刷视频不必开——只多发热、多耗电，流畅度没有收益。

## 三档强度的差别

| 档位 | 表现 | 适合 |
| --- | --- | --- |
| L1 | 加载与触控交互时提频，克制保守 | 轻度游戏、怕发热 |
| L2 | CPU 与 GPU 同时拉升 | 主流网游 |
| L3 | 性能全开 | 重负载大型游戏 |

关键在解锁条件：**L3 通常需要外接酷冷风扇**。不插风扇时最高档置灰或缺失，不是故障；接上对应代数的 AeroActive Cooler 后即可开启，风扇对背面温度的压制也远比被动散热明显。

## 用场景配置把档位写进游戏

逐次手动切档很繁琐，场景配置（部分机型叫游戏档案）解决的就是这件事：

1. 进入应用的场景配置板块，从列表选中目标游戏；
2. 给它固定性能档位、肩键映射、风扇联动等参数后保存；
3. 之后检测到你打开这个游戏就自动套用，退出恢复日常状态。

按游戏类型给个起点：射击类映射开镜开火到左右肩键、配 L2/L3；MOBA 类 L2 加快捷键映射；挂机卡牌类直接关 x 模式省电。技能按钮位置会移动的游戏不适合映射，键位固定的才稳。

## 档位失效的两个常见原因

- 游戏没从桌面或游戏中心正常入口启动（分身、模拟器入口可能不被识别）；
- 游戏更新改了界面，肩键映射点位漂移——重新拖一次映射点即可。
