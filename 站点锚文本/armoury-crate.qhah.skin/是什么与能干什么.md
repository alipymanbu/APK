# armoury crate 是什么？一款应用的两副面孔

> 本篇面向第一次接触这个名词的读者：说清 armoury crate 的定位、它在 ROG 手机与普通安卓机上的两种角色，以及各有哪些核心能力。连接电脑的配对细节见[手机连接电脑教程.md](手机连接电脑教程.md)。

armoury crate 是华硕面向 ROG（玩家国度）生态推出的控制中心软件，桌面版跑在 Windows 上，手机版装在安卓设备里。它的设计思路是把散落各处的设置收进一个界面：性能档位、风扇转速、RGB 灯效、游戏专属配置，都从一个入口下发。

## 在 ROG 游戏手机上：完整控制台

ROG 手机出厂就带着它，此时它管的是整机调度：

- **X 模式**：三档强度的高性能模式，最高档需要接酷冷风扇解锁；
- **场景配置**：给每个游戏单独存一份性能、肩键、风扇的预设，开游戏自动套用；
- **AirTriggers 肩键**：边框超声波按键的映射与手感调校；
- **灯效**：背面点阵 Logo 与配件的 Aura RGB 效果。

这一类设备上它属于系统组件，跟随系统更新即可，通常不必手动安装。

## 在普通安卓设备上：电脑的第二块屏

没有 ROG 硬件的手机装上它，功能收敛为"远程操控"：与装了桌面版的华硕游戏本、台式机配对后，可以切 Turbo / Performance / Silent 三档、调 HyperFan 风扇策略、查看 CPU / GPU 频率与温度。跑分烤机时把手机当监控面板、直播联机时随手切静音档，都是这套能力的典型用法。配对方法见[手机连接电脑教程.md](手机连接电脑教程.md)。
