# 手机连接电脑远程控制怎么配对

> 本篇讲 armoury crate 手机端与电脑端配对的完整流程、两种连接方式的取舍，以及连不上时的排查顺序。基础定位见[是什么与能干什么.md](是什么与能干什么.md)。

把手机变成游戏本的第二块操控屏，是这套软件在非 ROG 设备上最实用的玩法：人躺在沙发上，游戏跑在电脑上，手机看温度、切性能档、压风扇噪音，不打断电脑画面。

## 配对前的三个前提

1. 电脑上已装桌面版 armoury crate（华硕支持页面或微软商店可取），版本保持较新——V3.0.4 以上才支持手机配对；
2. 手机与电脑网络互通：同一 Wi-Fi 最省事，也支持蓝牙通道；
3. 手机端已装好安卓版并打开。

## 配对步骤

1. 电脑端打开 armoury crate，点右上角的 **Mobile Connect**（移动连接）图标；
2. 手机端打开应用，选择"通过扫描二维码连接"，同时确认手机的 Wi-Fi 与蓝牙已开启；
3. 用手机扫描电脑端显示的二维码，等待配对完成；
4. 成功后手机端出现电脑的可控制面板：HyperFan 三档、系统信息、设备配置都在这里。

两种配对方式里，扫码之外还支持双方登录同一 ROG ID 配对；但从大量用户反馈看，**扫码的成功率明显更高**，ROG ID 登录报错时直接改走二维码即可。

## 连不上时的排查顺序

- **双方应用都在前台**：电脑端最小化到托盘后，手机端可能直接失去目标；
- **核对网段**：手机用流量、电脑用有线是最常见的"不在同一网络"；公司、学校 Wi-Fi 常开设备隔离（AP 隔离），互相发现不了，换家用网络或热点验证；
- **扫码优先**：账号登录失败就改扫码；
- **电脑端版本过旧**：手机端新版可能对不上旧版面板，先把桌面版升到当前版本再重连。

配对成功后面板空白或一直加载，多属应用侧的加载故障，清缓存重启通常可解。性能档位与监控能力的全貌见[是什么与能干什么.md](是什么与能干什么.md)；实机界面可在 [Armoury Crate 介绍站](https://armoury-crate.qhah.skin/)直接查看。
