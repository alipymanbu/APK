# 与Termux的区别和图形化增强

> 本篇讲 ZeroTermux 和原版 Termux 到底差在哪：哪些能力是继承来的，哪些是它自己补上的图形层。装错预期是新手最常见的坑——看完这篇再决定要不要装。相关内容：[一键换源与备份恢复实操](一键换源与备份恢复实操.md)、[免root在手机跑Linux发行版](免root在手机跑Linux发行版.md)。

---

ZeroTermux 是基于 Termux 项目改进的社区分支，项目页面的自我定位写得很直白：站在 Termux 的肩膀上，让新手通过图形化快速入门命令行。也就是说，它不是另一个终端，而是给 Termux 这套成熟的安卓 Linux 环境**加了一层可视化外壳**。

## 继承下来的部分

- **pkg / apt 包管理**：软件包体系和桌面 Linux 同源，`pkg search`、`pkg install` 照用不误；
- **无需 root 的类 Linux 环境**：装完即用，运行在内部存储，不动系统分区；
- **SSH 与脚本工具链**：远程连服务器、跑自动化脚本，与原版体验一致；
- **附加仓库机制**：root-repo、x11-repo 这些扩展仓库照样随时开启。

## 新增的图形层

这是它存在的理由，也是安装它最实际的理由：

| 操作 | 原版 Termux 的做法 | ZeroTermux 的做法 |
| --- | --- | --- |
| 换软件源 | 编辑 sources.list 或跑半自动引导 | 工具箱「一键更换软件源」 |
| 定时任务 | 手写 crontab 条目 | 「定时执行」面板配置 |
| 备份恢复 | tar 打包、命令行还原 | 侧边栏「备份 / 恢复」一键完成 |
| 文件管理 | ls / cd / nano 一路敲 | 内置 ZT 目录管理，支持克隆仓库与 wget 直下 |
| 部署发行版 | proot-distro 逐条命令 | 引导式脚本选好发行版自动生成启动命令 |

另外还有两处手感差异值得单独提：

1. **手势呼出**：双指单击屏幕直接打开工具箱，右侧滑出内置文件管理器，小屏上不用翻菜单；
2. **在线脚本与恢复包**：社区脚本合集和网友上传的一键恢复包有内置入口，环境部署可以「抄作业」。

## 该怎么选

已经在用 Termux 且命令行熟练的话，原版够用；想把精力花在环境本身而不是命令记忆上，或者需要频繁备份迁移环境，图形化分支更省心。想看真实界面长什么样，[ZeroTermux 图文介绍站](https://zerotermux.kook.yoga/)整理了面板对照与截图实拍。
