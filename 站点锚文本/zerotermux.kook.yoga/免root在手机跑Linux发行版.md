# 免root在手机跑Linux发行版

> 本篇讲怎么在不 root 的安卓手机上跑 Ubuntu、Debian、Kali 这些发行版：原理是什么、ZeroTermux 里怎么一步步装、装完之后能干什么。相关内容：[与Termux的区别和图形化增强](与Termux的区别和图形化增强.md)、[一键换源与备份恢复实操](一键换源与备份恢复实操.md)。

---

## 原理：容器而不是双系统

手机没 root 也想跑完整 Linux，靠的是用户空间的容器方案：PRoot 在普通应用权限内模拟出根文件系统，把发行版的目录结构"伪装"出来，不需要动系统分区；有 root 的设备则可以用 Chroot 拿到更好的性能。ZeroTermux 把两种方式都做进了面板，默认走免 root 的路线。

## 部署步骤

1. 呼出工具箱，找到 Linux 发行版部署的入口；
2. 在引导界面选发行版（Ubuntu、Debian、Kali、Alpine 等按需选）与架构；
3. 等待脚本下载并部署 rootfs，期间保持网络稳定；
4. 部署完成后脚本会自动生成启动命令，之后在终端敲这条命令即可进入发行版环境；
5. 进入后按习惯 `apt update && apt upgrade` 一轮，环境就绪。

也可以走原版路子 `proot-distro install <发行版>`，效果等价——区别只在于图形引导对新手更省事，而且对国内网络的下载路径做了适配。

## 装完能干什么

- **开发练习**：完整的 apt 生态，Python、Node、GCC 随装随用，通勤路上写代码不是口号；
- **安全学习**：Kali 里的常用工具集可以在这类容器里跑起来，配合练习靶场学原理；
- **轻量服务**：跑个 Web 服务、定时脚本、爬虫任务，旧手机秒变巴掌大的小服务器；
- **桌面体验**：配合 X11 还能把图形桌面装出来，外接键鼠就是一台便携 Linux 机。

## 性能与预期管理

- 容器方案有性能折损，编译大项目不如真机；
- 手机发热降频时速度会明显波动，属于正常现象；
- 想跑 x86 镜像或做更重的虚拟化，可以用面板里的 QEMU 管理入口，但对设备性能要求更高。

部署前记得先按[一键换源与备份恢复实操](一键换源与备份恢复实操.md)把源换到国内镜像，下载 rootfs 和后续软件包都会快很多。安装包与界面实拍见 [ZeroTermux 图文介绍站](https://zerotermux.kook.yoga/)。
