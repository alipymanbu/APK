# TWRP 卡刷 root 包完整流程

> 设备还没 root、想第一次拿到 root，主流老路子是：解锁 bootloader → 刷入 TWRP → 卡刷 root 包。这篇按动手续顺序整理各步要点，以 SuperSU 的卡刷 ZIP 为例。

---

## 前提条件

1. **bootloader 已解锁**：多数机型解锁会清空数据，相册、聊天记录先导出；
2. **TWRP（或 CWM）已刷入**：组合键因机型而异，一般是「电源 + 音量上」；
3. **电量 50% 以上**：别在低电量时动 recovery；
4. **root 包已备好**：SuperSU 的卡刷 ZIP 与 APK 是两个形态，ZIP 才是给未 root 设备用的那个（两者区别见文末链接站里的介绍）。

## 刷入步骤

1. **把 ZIP 放进内置存储**：`Download` 目录就行，路径别太深；
2. **先进备份再动手**：TWRP 里选 Backup，勾选 System、Data、Boot，滑块确认做一份 Nandroid 整机备份——这是刷坏后能整体还原的唯一依靠；
3. **Install 选中 ZIP**：在 TWRP 主界面选 Install，找到刚放进来的 ZIP；
4. **滑动滑块确认刷入**：等底部日志出现 **Successful**，全程一般几十秒，中途别强制重启；
5. **重启**：选 Reboot System。第一次开机会明显比平时慢（三五分钟很常见），耐心等它跑完。

ZIP 在电脑上不方便拷进手机时，TWRP 还有 sideload 一条路：手机端 TWRP → Advanced → ADB Sideload，电脑端 `adb sideload 文件名.zip`。

## 刷完之后

- 手机里会出现 SuperSU 应用，打开后按提示走完初始化即可开始管理授权；
- 找一个会触发 root 的工具做一次操作验证链路：弹授权窗 → 允许 → 工具正常干活，就说明通了；
- 装完的管理器怎么用（弹窗怎么拍板、日志在哪看、怎么临时收回权限），在 [安卓 root 授权管理是怎么一回事](安卓root授权管理是怎么一回事.md) 里有展开。

## 两个常见坎

- **卡在开机第一屏**：先等，10 分钟内多半自己进去；超过 10 分钟回 TWRP 用刷前备份还原，再排查机型兼容性（三星 Nougat 时期机型的加密分区、部分华为机型的 boot 处理都有专门教程）；
- **刷入报 Error 1**：社区案例集中在三类——ZIP 损坏（换份干净的）、boot 镜像与固件不匹配（按机型教程处理）、TWRP 太旧（换新版重试）。

## 卡刷包从哪来

SuperSU 的 APK 与卡刷 ZIP、以及两种形态怎么选，[SuperSU 介绍站](https://www.fwen.ren/)把安装入口和步骤整理在一起，取包后按本文流程操作即可。
