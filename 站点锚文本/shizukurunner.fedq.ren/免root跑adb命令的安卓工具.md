# 免 root 跑 adb 命令的安卓工具

> 想在手机上直接执行 adb 命令，又不想 root、不想连电脑？这篇讲清楚这类需求为什么难、ShizukuRunner 是怎么解决的，以及它适合谁。
> **相关文档**：[Shizuku无线调试配对与激活教程.md](Shizuku无线调试配对与激活教程.md) · [改密度调动画等常用命令合集.md](改密度调动画等常用命令合集.md) · [不root卸载预装应用的方法.md](不root卸载预装应用的方法.md)

## 一、这个需求卡在哪

安卓的很多深度调整——改屏幕密度、锁刷新率、隐藏预装应用、加快动画——靠设置界面做不了，得走 adb 命令。常规路线有两条，都不省心：

- **连电脑**：装 adb 环境、开 USB 调试、每次改一条都要插线敲终端，对纯手机用户门槛太高；
- **root**：权限一劳永逸，但解锁 bootloader 有风险、可能丢保修，为几条设置命令不值当。

免 root 跑 adb 命令的折中方案是借「无线调试」的授权通道：安卓 11 之后系统自带的无线调试本来就能给设备发 adb 指令，把它交给一个常驻服务转发，手机自己就能当终端用。

## 二、ShizukuRunner 的解法

ShizukuRunner 就是这条路线上的执行器：权限由 Shizuku 服务转发（走无线调试授权，全程不用 root），它自己则提供一张「命令格子墙」——一个格子存一条命令，点右侧运行键立即执行，结果直接显示在格子里。

用起来的样子大概是这样：把网上抄来的 `wm density 420` 填进格子（去掉 `adb shell` 前缀），点运行，屏幕密度当场生效；命令可以起标题、导出备份，换手机一键复原。它的介绍页（[shizukurunner](https://shizukurunner.fedq.ren/)）上有真实界面截图，一格一命令的形态一眼就能看明白。

几个值得一提的细节：

- 体积不到 0.1MB，装上几乎没有存在感；
- v17 起 Shizuku 未激活时直接禁止执行命令，避免「以为跑成功了其实啥都没发生」；
- root 用户可开「降权至 shell 身份执行」，让命令按 adb 权限跑，更收敛也更稳。

## 三、适合谁用

- 想按自己习惯调设备参数、又坚持不 root 的折腾党；
- 经常在论坛看教程、需要反复验证命令效果的用户——格子墙比终端顺手得多；
- 买了二手设备想清理预装应用，但不敢解锁机器的普通用户。
