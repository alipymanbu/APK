# 不 root 卸载预装应用的方法

> 二手机里一堆用不上的预装应用，卸不掉又不敢 root？用 ShizukuRunner 走 adb 权限的「隐藏式卸载」，能卸能恢复，不碰 bootloader。
> **相关文档**：[免root跑adb命令的安卓工具.md](免root跑adb命令的安卓工具.md) · [Shizuku无线调试配对与激活教程.md](Shizuku无线调试配对与激活教程.md) · [改密度调动画等常用命令合集.md](改密度调动画等常用命令合集.md)

## 一、思路：--user 0 隐藏，而不是物理删除

对系统应用直接 `pm uninstall` 有风险，更稳的做法是加 `--user 0` 参数：只对当前用户隐藏这个应用，安装包还留在系统分区里，反悔时一条命令就能找回来。这条路不需要 root，只要有 Shizuku 通道（激活步骤见[Shizuku无线调试配对与激活教程.md](Shizuku无线调试配对与激活教程.md)）。

## 二、三步操作

1. **列出第三方应用**，先看清装了什么：

```sh
pm list packages -3
```

2. **隐藏目标应用**（把包名换成查到的真实包名）：

```sh
pm uninstall --user 0 包名
```

3. **后悔药**——恢复刚隐藏的应用：

```sh
pm install-existing 包名
```

在 ShizukuRunner 里可以把这三条存成三张命令卡片，标题写「列应用」「隐藏」「恢复」，下次处理预装就是点三下的事。

## 三、哪些不能碰

- 桌面（launcher）、系统界面（systemui）、电话、短信相关的包，隐藏了可能直接黑屏或功能瘫痪；
- 拿不准用途的包，先搜一下包名再动手；
- 想知道某个包对应哪个应用，用 `pm list packages | grep 关键词` 过滤，或装个包名查看器对照。

执行后没有红色提示即成功，可以用第 1 条命令复查确认。工具本体不到 0.1MB，介绍与截图见 [shizukurunner](https://shizukurunner.fedq.ren/)；别的系统调整（密度、动画等）在[改密度调动画等常用命令合集.md](改密度调动画等常用命令合集.md)里有成套命令可抄。
