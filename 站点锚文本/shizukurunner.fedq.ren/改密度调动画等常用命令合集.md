# 改密度调动画等常用命令合集

> ShizukuRunner 通道打通之后跑什么？这篇整理几组最常用的命令：动画提速、改密度分辨率、休眠常亮，全部抄去就能用，附恢复方法。
> **相关文档**：[免root跑adb命令的安卓工具.md](免root跑adb命令的安卓工具.md) · [Shizuku无线调试配对与激活教程.md](Shizuku无线调试配对与激活教程.md) · [不root卸载预装应用的方法.md](不root卸载预装应用的方法.md)

## 一、填法先说清

网上查到的命令一般带着 `adb shell` 前缀，填进 ShizukuRunner 的命令格子时**只留后面的本体**（比如只填 `wm density 420`）。执行成功通常静默无输出，出现红色提示才说明没跑成。命令可以长按卡片起标题（如「半速动画」），改完记得记下原值方便恢复。

## 二、动画提速（AOSP 通用）

把三个动画缩放一起调小，系统观感立刻利落：

```sh
settings put global window_animation_scale 0.5
settings put global transition_animation_scale 0.5
settings put global animator_duration_scale 0.5
```

恢复就把三个值改回 `1`。这是最安全的一组命令，适合当作跑通通道后的第一条验证。

## 三、屏幕密度与分辨率

```sh
wm density            # 先查当前密度
wm density 420        # 按需修改
wm density reset      # 恢复默认
```

分辨率同理：`wm size` 查、`wm size 1080x2400` 改、`wm size reset` 恢复。数值别改太激进，界面挤到点不到按钮时，先用系统「显示大小」救急再跑 reset。

## 四、休眠与常亮

```sh
settings put system screen_off_timeout 600000   # 自动锁屏 10 分钟
svc power stayon true                            # 插电时屏幕常亮
```

调试或跟教程时特别有用，不需要了跑 `svc power stayon false` 关掉。

## 五、执行结果的两个保护机制

- 输出超过 1000 字符会被掐断并返回 141——防止应用被海量输出卡死，不是命令写错；
- `logcat` 这类永远停不下来的命令别在格子里跑，要跑就重定向到文件。

想清理预装应用的，单独看[不root卸载预装应用的方法.md](不root卸载预装应用的方法.md)；通道还没打通的先回[Shizuku无线调试配对与激活教程.md](Shizuku无线调试配对与激活教程.md)。工具本体的介绍与界面截图在 [shizukurunner](https://shizukurunner.fedq.ren/) 一站里有完整展示。
