# 天气地图怎么看：图层、颜色与时间轴的读法

> 本篇讲怎么读"画在地图上的天气"：温度色块、降水深浅、风场流线分别代表什么，时间轴怎么拖才能看到过去与未来。以 Ventusky 这类地图优先的天气应用为例。

## 一、为什么地图比文字预报直观

传统天气应用给的是"结论"：今天最高 12 度、傍晚有雨。地图类应用给的是"过程"——整片降雨云系正从哪个方向压过来、冷锋推进到了哪里。看懂一张天气地图，等于自己得出结论，还能顺手判断"几点开始下、下多大"。

## 二、常见图层的颜色语言

| 图层 | 怎么读 |
| --- | --- |
| 温度 | 蓝紫是冷、绿黄是温、橙红是热；色块边界越密，说明温度梯度越陡，往往对应锋面 |
| 降水量 | 颜色越深雨越大；图上标注的数字通常是每 3 小时的毫米数，和"日降水量"口径不同，别直接对比 |
| 风场 | 流线的方向就是风向，线的疏密与颜色代表风速；沿海和山口经常能看到明显的加速带 |
| 卫星云图 | 白亮厚实的是发展中的云系，稀薄发灰的是高云；配合动画看移动趋势 |
| 空气质量 | 铺开 PM2.5、二氧化氮等指标，污染团的来路与消散都能在图上追踪 |

## 三、时间轴：往左是回放，往右是预演

地图天气应用的底部通常有两行刻度：日期与小时。拖动它，整张地图跟着切换时刻：

1. **往右拖**看预报——大部分应用能看到未来两周，逐小时精度足够安排周末；
2. **往左拖**看回放——刚过去的降雨带走到哪了，一清二楚；
3. **播放键**让整段时间连续动画，追台风、看冷锋过境时最直观；
4. 点地图上任意一点，会弹出该点的数值曲线，比看整张图更精确。

## 四、两个进阶技巧

- **多模型交叉验证**：同一张图往往可以切换不同预报模型（ECMWF、GFS、ICON 等）。多数模型一致的结论更可信；只看到极端数字、别的模型都没有，先别当真。
- **实测与预报分开看**：雷达回波和卫星云图是"正在发生的实测"，模型图层是"算出来的预报"。判断一小时内要不要带伞看雷达，安排三天后的出行看模型。
