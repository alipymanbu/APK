# 自己动手做保养的安全底线

> 看视频学修车，省的是工时费，赌不起的是安全——先立规矩，再谈省钱。
> **相关文档**：[按车型查维修视频的用法.md](按车型查维修视频的用法.md) · [英文汽修视频没字幕怎么办.md](英文汽修视频没字幕怎么办.md)

跟着 CarCareKiosk 这类视频库自己动手做保养，省下的大头是工时费：空调滤、空滤、雨刮、灯泡这些项目件钱便宜、几乎不用工具，五到十五分钟搞定，差价比例最高；换机油这类项目净省有限，更多是顺手学会。但所有「自己动手」的前提是同一条——**不受伤**。本文把硬规矩列在前面，查看对应车型的教程视频可以从 [carcarekiosk](https://carcarekiosk.bmww.store/) 整理的入口进。

## 一、一条不能破的规则

**千斤顶（含随车剪式千斤顶）只负责把车举起来，不负责把车停在半空。** 人要钻到车底之前，重量必须落在安全支架上。液压密封会老化渗漏、地面会轻微沉陷、车身会被拧螺丝的力道带得移位——任何一种情况发生，车都会掉下来，而车底只有你一个人。

## 二、举升的标准流程

1. **选地面**：平整坚硬的实地（水泥地最佳）；碎石、泥土、草地、斜坡一律不行；
2. **拉手刹 + 垫轮挡**：手刹拉死，在不打算举起的那侧车轮前后塞上轮挡；
3. **按车主手册找顶升点**：手册标注的加强部位才能受力，不准顶排气管、悬挂摆臂、塑料护板、车身钣金；
4. **举升到位后立刻放支架**：支架放在手册指定的结构支撑点，一对使用，额定承载盖过车重；
5. **缓慢落车到支架上**：重量完全压在支架上，千斤顶撤走或只留作备份；
6. **摇车测试**：下手推一把车身，纹丝不动才允许钻进去。

几条硬性禁令：绝不在只用千斤顶撑着的车底作业；绝不用砖头木块代替支架；绝不只放一根支架；车还热着不急着钻底（排气管烫伤）；护目镜、手套、包头鞋戴上，车库内着车必须通风。

## 三、哪些项目适合新手，哪些别碰

| 适合新手（看一遍视频就能上手） | 没有训练别碰 |
| --- | --- |
| 空调滤、发动机空滤 | 正时皮带 / 正时链条 |
| 雨刮片、灯泡 | 变速箱维修与换油 |
| 换机油、机油滤 | 悬挂弹簧、减震器拆装 |
| 蓄电池（注意极性） | 安全气囊相关作业 |

判断原则一条：**这个项目搞砸了会不会直接让车抛锚、影响刹车或转向**——会，就先交给专业的人。挑项目的完整流程见 [按车型查维修视频的用法.md](按车型查维修视频的用法.md)。

## 四、什么时候不值得自己做

住公寓没固定车位、地面是草地或斜坡，举升条件不满足，直接送店更划算；一年只做一次的项目（如变速箱油），工具投入摊不平；快修店报价本身就低时，净节省接近于零。工具是一次性投入，入门套装大约等于一次进店的账单，之后每次动手都是净省——前提永远是：把第一节那套举升规矩走齐，一次都不打折。
