# 安卓启动器装完是空的怎么办

在安卓手机上装好 Minecraft Java 版启动器，点开一看：没有游戏版本、世界列表空空如也，主界面还提示「没有游戏账户」。先别急着卸载重装——对这类启动器来说，这多半不是装错了，而是它本来就是这个状态。

## 为什么装完是空的

原因一句话：**安装包里只有启动器，不带游戏本体**。手机商店里的游戏下载下来就能玩，但 Java 版启动器是另一类东西——它只负责搭环境，游戏本体、资源文件都要装好之后在应用内另行获取。

所以正确的预期是：

- 装完启动器 → 空的，正常；
- 在应用内「下载」页选好版本、等本体和资源下完 → 才有东西可启动；
- 账户也要在应用内添加，支持微软账号登录与离线模式，登录后才能进对应的世界。

以 [HMCL 安卓版](https://hmcl.bmww.store/)（HMCL-PE）为例，首次打开的主界面左侧就是「账户」和「游戏」两个入口，右侧「启动游戏」按钮在没装任何版本时会明确提示没有游戏版本——看到这个提示，说明启动器在正常工作，等你在下载页把版本装上就行。

## 安装环节常见的三个卡点

**一、点开 APK 提示无法安装或被拦。** 这类启动器不走应用商店，系统首次会按「未知来源」拦一下，在弹窗里允许对应来源安装即可。放行之后还装不上，就查文件本身。

**二、文件大小不对。** 以 HMCL-PE 2.0.8 为例，完整 APK 在 171 MB 上下。如果手里的文件明显偏小，基本是下载不完整，删掉重下；装完还可以核对包名是不是 com.tungsten.hmclpe，对不上就别装——安卓上的 Java 版启动器不止一个，认错包会白忙一场。

**三、装上了但一打开就闪退。** 先回头对硬件门槛：Android 8.0 以下、32 位设备、运存不足 4 GB，都可能直接起不来。门槛都达标还闪退，重启手机再试；仍不行就得考虑系统兼容性——HMCL-PE 已停更，2.0.8 是最终版，较新的系统上遇到问题不会再有修复版本。

## 装好之后

启动器能用、版本装上、账户登录完成，剩下的配置就顺手了：全局设置里调内存分配和渲染分辨率（低配机先压分辨率保流畅），然后按需加模组、装整合包。更完整的安装顺序和界面说明，可以回到 [手机上玩Java版我的世界](手机上玩Java版我的世界.md) 那篇从头看。

一句话收尾：**空的不是故障，是起点**——启动器装好只是第一步，游戏本体要自己下，账户要自己加，配完这一套，世界才会出现。
