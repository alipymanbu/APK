## 一、免费版覆盖的日常场景

应用本体无广告，下面这些装好就能用：

| 图层 | 内容 |
| --- | --- |
| 温度 | 地表温度，含多个高度层 |
| 体感温度 | 综合湿度与风的影响 |
| 降水量 | 1 小时 / 3 小时 / 累积值 |
| 天气雷达 | 实测降水回波与雷电检测 |
| 卫星 | 云图 |
| 空气污染 | PM2.5、PM10、二氧化氮、臭氧、AQI 等 |
| 风 | 地表风场动画流线 |

时间轴、地点搜索、地点数值图表，以及全球四万多个公共摄像头的实况入口，都在免费范围里。出门前看下雨、降温、台风路径，空气质量、周末骑行看风，这些日常需求免费版已经接住了。

## 二、订阅（Premium）多出来什么

| 类别 | 图层 |
| --- | --- |
| 风 | 约 16 层高空风、阵风 |
| 云 | 云量分层（高/中/低）、雾 |
| 气压 | 海平面气压等 |
| 雷暴 | CAPE、风切变、抬升指数、螺旋度 |
| 海洋 | 浪高、涌浪周期、洋流、潮汐 |
| 湿度与其他 | 各高度层湿度、露点、积雪、能见度 |

订阅入口在应用内：点高级图层时会出现购买引导，价格与档位以购买页当时显示为准。订阅绑定账号不绑设备，换手机登录原账号、在订阅页点「恢复购买」即可。

## 三、按用途对号入座

- 日常看天气、判断带不带伞：免费层足够；
- 关心空气质量：PM2.5 等主要指标免费就有；
- 徒步、骑行、登山看阵风与高空风：要订阅；
- 关注台风、出海、飞行相关：海浪、洋流、雷暴指标都在订阅里；
- 还在犹豫：先用免费版跑一段时间，缺什么再补。

图层的具体划分可能随版本微调，以应用内图层面板实际显示为准。想直观感受各图层的画面效果，[Ventusky 天气地图观察站](https://ventusky.djnf.quest/)把温度、雷达、空气质量几个层的实拍图摆在一起，可以对照着看。
