# 逐帧动画手机上怎么做：洋葱皮与时间轴的实操说明

> 让角色动起来不一定要开电脑。手机上装个绘画应用，配洋葱皮和时间轴，逐帧动画一个人也能做出来。这篇讲清原理、步骤和导出口径。
> **相关文档**：[平板画漫画用什么工具.md](平板画漫画用什么工具.md) · [手机画画软件怎么选.md](手机画画软件怎么选.md)

## 一、逐帧动画的原理一句话

每帧画一张，连起来播就是动画。难点从来不是「画」，而是**对不准**——上一帧画的线，下一帧要接着它动，全靠参照。洋葱皮（onion skin）就是干这个的：把前后几帧以半透明叠在当前帧下面，你画的时候随时能对位。

## 二、在手机上做，需要应用具备什么

核对四条，缺一条体验都会打折：

| 能力 | 为什么重要 |
| --- | --- |
| 洋葱皮帧数与不透明度可调 | 参照帧太多会花，太少对不上位，要能按习惯调 |
| 时间轴支持加帧、复制帧、删帧 | 循环动作直接复制上一帧改一点，效率翻倍 |
| 帧率可调 | 8 帧每秒和 24 帧每秒的顺滑度、工作量完全两回事 |
| 成品按画布全分辨率导出 | 导出糊成一团的动画等于白画 |

HiPaint 的动画辅助就是按这套做的：洋葱皮前后帧的数量与透明度都能调，时间轴上加减帧点两下的事，成品按画布原分辨率导出，分镜、GIF、短动画都在一块画布里完成。

## 三、从零做一个走路循环

拿最经典的走路循环举例，步骤压缩成五步：

1. **建小画布**：动画先练手，画布不用大，减少每帧的绘制量；
2. **画关键帧**：先画「双腿张开」和「双腿交错」两个极端姿势，作为第 1 帧和第 5 帧左右；
3. **补中间帧**：在关键帧之间加帧，开着洋葱皮对照前后帧补中间姿势，位置跟着洋葱皮影子走就不会抖；
4. **拉时间轴回放**：调帧率来回播，抖得厉害的地方回去改那几帧；
5. **导出**：确认顺滑后按全分辨率导出，需要发平台的再压一份 GIF。

## 四、两个容易踩的坑

- **帧数贪多**：新手常见病。逐帧动画越顺滑帧数越多、工作量指数涨，先用低帧率把动作节奏做对，再考虑加密；
- **忽略过程记录**：很多绘画应用能把作画过程回放导出成 MP4，做动画时这段过程视频发社交平台效果极好，记得开。
