# 网页视频嗅探与保存

> 网页里正在播的视频想存下来，X浏览器可以嗅探出资源地址，再交给第三方下载器下载，M3U8 流媒体还能自动转成 MP4。这篇把链路拆开讲。
> **相关文档**：[广告拦截与油猴脚本配置](广告拦截与油猴脚本配置.md) · [一款只有 2MB 的安卓浏览器](2MB的小体积安卓浏览器.md)

## 一、先嗅探：找到页面里的媒体资源

在播放视频的页面上，点开页面工具菜单里的「嗅探媒体资源」，浏览器会列出当前页面加载到的视频、音频资源地址。嗅探成功后屏幕上会出现一个视频工具条，提供下载、播放等操作。

两个小经验：

- 资源往往是开始播放后才加载的，先播一段再嗅探，列表更容易命中；
- 不是所有网站都能嗅探到，部分站点做过处理，嗅探不到属正常限制，不必反复重试。

## 二、再下载：为什么要绑第三方下载器

内置下载器走「保持简单」的路线，只做 HTTP 直链和断点续传。碰上大文件、BT 种子、M3U8 流媒体，就需要专业下载器接管。常见的可绑下载器包括 1DM、ADM、迅雷、FluxDown 等，绑定方式有两种：

1. **临时选**：下载时弹出的对话框里直接切换由谁接手；
2. **设默认**：在「设置 → 基本设置 → 当前下载器」里固定一个，之后所有下载请求自动交给它。

绑定第三方下载器不影响内置下载器已有的下载记录，两边各自独立，也可以同时装几个按场景切换。

## 三、M3U8 转 MP4：下载后自动完成

M3U8 是流媒体格式，一个索引带一堆小片段，普通方式拿不到完整视频。配合支持它的下载器（1DM、ADM、迅雷、FluxDown 都可以），流程是四步：

1. 在目标页面嗅探出 M3U8 地址；
2. 点视频工具条上的「下载」；
3. 下载器解析出可选分辨率（如 1080p、720p），选一个；
4. 下载完成后自动合并转成 MP4，不需要手动拼接。

下载速度取决于视频源、网络和片段数量，卡慢时优先换稳定的 Wi-Fi。只保存自己有权使用的内容，版权责任在使用者。

## 四、其他玩法

嗅探到的资源除了下载，还能用第三方播放器在线播，或通过 DLNA 投屏到电视、盒子上。广告拦截与脚本配置见[广告拦截与油猴脚本配置](广告拦截与油猴脚本配置.md)；功能总览与安装文件资源入口见 [X浏览器介绍页](https://xbrowser.fwen.ren/)。
