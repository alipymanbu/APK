# 密码保险库换手机怎么迁移：三条路线与一张检查清单

> 换手机最怕的不是装不上 App，而是旧数据回不来。密码管理器的数据尤其如此——保险库打不开，里面的账号密码就全部作废。本篇以 Enpass 为例讲清楚迁移路线与防丢要点，思路对同类工具也适用。
> **相关文档**：[离线密码管理器怎么选.md](离线密码管理器怎么选.md) · [README.md](README.md)

## 一、迁移前先弄清：你的数据到底在哪

Enpass 这类本地优先工具里，「卸载 App」和「删数据」是两件事：条目全部存在保险库文件里，而不在应用本体中。所以迁移前先回答一个问题——你的保险库文件现在放在哪：

- **配置了云盘同步**：保险库跟着你的 iCloud / Google Drive / OneDrive / Dropbox / Box / NextCloud / WebDAV 走，新设备登录同一个云盘账号即可找到；
- **纯离线使用**：保险库只在新旧两台手机里的某一台上，需要手动备份文件再搬运；
- **分不清**：打开旧手机的 Enpass，进 设置 → 保险库，看每个库的存放位置，一目了然。

## 二、三条迁移路线

### 路线 A：云盘同步（最省事）

旧手机确认已开启同步并完成一次上传；新手机装好 Enpass，首次启动选「恢复」，登录同一个云盘账号把保险库拉回来，输入主密码解锁即完事。

### 路线 B：手动备份（离线用户必走）

旧手机进 设置 → 保险库 → 选中保险库 → 备份，导出一个带时间戳的备份文件，通过数据线、局域网或任意你信得过的方式传到新手机；新手机首次启动选「恢复」指向这个文件。备份文件和主密码这两样凑齐才能开门，缺一不可。

### 路线 C：从别的密码管理器导入

从云端托管派搬家过来的，不用一条条手抄：Enpass 支持从浏览器、CSV 表格和常见密码管理器批量导入，导入后按类别整理、逐条补两步验证码即可。反方向同理，导出 CSV 时记得选加密传输或用完即删。

## 三、主密码与密钥文件：迁移路上最容易翻车的两处

- **主密码无法找回**：恢复保险库时必须输入当初的主密码，连错多次只会更久才能再试。换机前先确认你还记得它，记不牢就在纸上写好放固定位置，迁完再处理。
- **密钥文件（keyfile）是第二把钥匙**：如果开启了密钥文件，恢复时「主密码 + 这个文件」两样都要到场。它平时就该和备份分开存放——备份在网盘、密钥文件在 U 盘，换机时两样都得带上。

## 四、迁移后的检查清单

1. 随机抽 3~5 条重要条目，确认密码能复制、能自动填充；
2. 两步验证码条目逐条点开试出码，TOTP 依赖时间，确认手机时间同步；
3. 附件（证件扫描件之类）抽验能否打开；
4. 新手机把生物识别快速解锁和自动填充重新授权一遍（这两项权限不跟着保险库走）；
5. 确认同步状态正常后，旧手机再决定是否卸载——**先验新机，再动旧机**。

## 五、常见坑

- **先卸载后备份**：本地保险库只存在于旧手机时，手一抖卸载连同数据清空，神仙难救。任何清理动作都放在新机验收之后。
- **云盘账号登错**：个人 iCloud 与家庭共享空间、工作 OneDrive 与个人 OneDrive 长得很像，恢复前看清楚账号邮箱。
- **装不上新机**：安卓侧放行「安装未知应用」即可，安装入口与步骤见 [Enpass 密码保险库介绍站](https://enpass.uerg.quest/)；iOS 侧直接从 App Store 安装。
- **忘记主密码**：没有找回通道，只能清空重建。所以本篇反复念叨的那句话——主密码先落实，再动手机。
