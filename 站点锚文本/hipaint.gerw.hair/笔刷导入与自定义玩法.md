# HiPaint 笔刷怎么导入与自定义

> 本篇讲 HiPaint 的笔刷这一套：内置笔刷大致有哪些、`.hbr` 笔刷文件怎么导进来、笔刷工作室里哪些参数最影响手感、去哪找更多笔刷。
> **相关文档**：[图层混合模式与剪辑蒙版用法.md](图层混合模式与剪辑蒙版用法.md) · [手绘板连接与压感设置.md](手绘板连接与压感设置.md) · [逐帧动画与洋葱皮上手.md](逐帧动画与洋葱皮上手.md)

## 一、内置笔刷的基本盘

HiPaint 内置的笔刷有上百款：素描铅笔、炭笔、气笔、喷枪、油画棒、水彩晕染、马克笔、像素笔，以及各种材质纹理与噪点纹理，按笔刷组管理。画笔、橡皮擦、涂抹这几支基础工具常驻工具栏，不走笔刷库切换。

两条管理上的硬规则先记住：

- **默认笔刷删不掉**，能删的只有自己新建或导入的笔刷；
- 笔刷参数支持**压感与倾斜**，笔尖轻重带来的线条变化要在带压感的笔或手绘板上才能体现出来。

## 二、把 .hbr 笔刷文件导进来

HiPaint 的笔刷文件后缀是 `.hbr`，导入走系统的「打开方式」链路：

1. 先把 `.hbr` 文件存到手机存储（聊天工具、网盘、浏览器下载来的都行）；
2. 在文件管理器里点它 → 「打开方式」→「其他应用」→ 选 HiPaint；
3. 导入成功后笔刷出现在笔刷库里，可以再拖进自己的笔刷组。

两个常见卡点：

- 部分手机自带的文件管理器不认 `.hbr` 后缀，列表里根本看不到文件——换一个能显示全部文件的文件管理器再试；
- 笔刷**组**也支持整组导入导出，搬别人整套笔刷时不用一支支来。

## 三、笔刷工作室：先动这几项参数

笔刷工作室里可调的参数有几十上百项，第一次进去别都碰，先调最影响手感的：

| 参数 | 调了会怎样 |
| --- | --- |
| 大小 / 硬度 | 线条粗细与边缘虚实 |
| 透明度 | 叠色时的通透程度 |
| 平滑 / 稳定器 | 手抖修正，勾线时开高一点线条更顺 |
| 快速滑块 | 画布上直接拖，快速改笔刷粗细与不透明度 |

调好的自定义笔刷能导出成 `.hbr` 发给别人；换机前把笔刷组整组导出、新机上再导入，配置就带走了。

## 四、去哪找更多笔刷

应用的设置里有社区资源入口，用户自制的笔刷从那里拿（不同版本入口名称略有差异）。从第三方渠道拿笔刷文件时，先确认是 `.hbr` 格式再往里导。

还没装这款应用的，可以先到 [HiPaint 画室笔记](https://hipaint.gerw.hair/) 看一遍功能全貌再决定。笔刷越攒越多之后，作品里怎么分层配合不同笔刷，见 [图层混合模式与剪辑蒙版用法.md](图层混合模式与剪辑蒙版用法.md)。
