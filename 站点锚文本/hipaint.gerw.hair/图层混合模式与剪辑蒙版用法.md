# HiPaint 图层混合模式与剪辑蒙版用法

> 上色上阴影该用哪档混合模式、剪辑蒙版与 α 锁定分别管什么、图层到上限了怎么办——画复杂作品之前先把这篇过一遍。

## 一、图层数不是固定的

HiPaint 新建图层会碰到上限，这个上限由**画布尺寸**和**设备性能**共同决定——画布越大上限越低，设备越强上限越高。新建画布的界面上会直接显示当前设置下的最大图层数，建之前看一眼就有数。

真的不够用时两条路：

- 新建时把画布尺寸定小一档；
- 把已经定稿的部分合并成一层，给后续绘制腾位置。

这是防崩溃的保护机制，不是付费门槛——换更强的设备，上限会跟着涨。至于宣传页里「上千图层」「最多 100 层」等不同口径，以你设备上新建画布界面显示的那个为准。

## 二、混合模式：上色最常用的几档

HiPaint 提供二十多种图层混合模式，不同版本数量略有出入，以图层面板里实际列出的为准。日常上色最常用的是这三档：

| 模式 | 典型用法 |
| --- | --- |
| 正片叠底 | 压暗、上阴影 |
| 滤色 | 提亮、做发光 |
| 叠加 | 叠材质与纹理 |

## 三、图层编辑功能对照

| 操作 | 什么时候用 |
| --- | --- |
| 复制图层 | 想在原稿基础上试一版改法，不动底稿 |
| 合并 / 栅格化 | 定稿收层；文字、形状要直接用笔刷画时先栅格化 |
| α 锁定 | 只在这一层已有像素的范围内落笔——上阴影不画出界靠它 |
| 剪辑蒙版 | 挂一层在下一层之上，效果只作用于下层有内容的部分，调色、贴纹理常用 |
| 图层组 | 几十上百层的作品整组移动、整组开关 |
| 多选图层 | 把多个元素同时挪位置、做变换 |

## 四、一个版本相关的提醒

图层界面的布局在 6.1.x 版本做过一次改版，网上找的老教程截图可能和你的界面对不上——按**功能名**找入口，别照截图上的按钮位置找。

想先把这款应用装起来试一遍，可以从 [HiPaint 画室笔记](https://hipaint.gerw.hair/) 进去拿获取指引。图层多了之后导出想连图层结构一起带走，记得选 PSD 或 HSD 格式；动画作品的图层配合，见 [逐帧动画与洋葱皮上手.md](逐帧动画与洋葱皮上手.md)。
