# DeepTalk 介绍站：功能、安装与使用整理

这个目录收录围绕 DeepTalk（安卓即时通讯工具）整理的介绍文章：它是一款主打简洁界面与消息加密的聊天软件，支持文字、语音、图片、视频、文件五类消息，群聊自带公告与话题标签，还有类似朋友圈的动态功能。

完整的功能盘点、界面截图与安装包获取入口，见 [DeepTalk 介绍站](https://deeptalk.gerw.hair/)。

## 简要信息

- 类型：手机即时通讯工具（安卓）
- 开发者：广西成昊信息网络有限公司
- 安卓包名：`com.deeptalk.chat`

叫 DeepTalk 的产品不止一个（另有 AI 深度对话、实时翻译类同名产品），认准「手机聊天工具」这个形态即可区分。
