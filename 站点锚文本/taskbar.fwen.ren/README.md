# TaskBar 站点导航与资源说明

> 这是「TaskBar 安卓任务栏工具」介绍站的目录页：汇总站点里两篇主题文章，并说明安装文件资源的获取路径。

## 这个站讲什么

[TaskBar](https://taskbar.fwen.ren/) 是一款开源的安卓任务栏工具，把「开始菜单 + 最近任务托盘」常驻在屏幕顶部，让手机和平板能按 PC 的习惯翻应用、切任务；再配合自由窗口模式与 Android 10 桌面模式，还能把应用装进可拖动的浮动窗口，或投到外接显示器上当桌面系统用。

站在 [taskbar.fwen.ren](https://taskbar.fwen.ren/) 上整理了两篇主题文章：

| 文章 | 适合谁看 |
| --- | --- |
| [安卓平板变身桌面模式教程.md](安卓平板变身桌面模式教程.md) | 想给平板或手机接显示器、玩出 PC 体验的人 |
| [开始菜单小窗多任务玩法.md](开始菜单小窗多任务玩法.md) | 想先在本屏上把多任务效率提起来的人 |

## 安装文件资源怎么拿

站点首页与下载页都放了获取入口，安装包经网盘转存后下载安装；站内文章只讲玩法与设置，不重复贴地址，跟着入口走即可。
