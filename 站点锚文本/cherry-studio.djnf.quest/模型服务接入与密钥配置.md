# Cherry Studio 模型服务接入与密钥配置

> 本篇讲 cherry studio 手机版装好之后的第一道坎：API 密钥从哪来、服务商怎么加、发不出第一条消息时先查什么。装不装、值不值得装的问题见 [手机版怎么样值得装吗](手机版怎么样值得装吗.md)；智能体与工具的用法见 [助手市场与 MCP 工具玩法](助手市场与MCP工具玩法.md)。

## 为什么装完还不能直接聊

Cherry Studio 是客户端，本身不附带模型额度。第一次打开时最重要的动作，是把至少一个模型服务接进来。两个容易踩的认知坑：

- **别把平台登录密码当密钥**。密钥是在平台「开放接口」页面里单独创建的一串字符，和账号密码是两回事；
- **普通聊天会员不一定含接口额度**。在某家平台充了会员，不代表它的接口能随便调，额度规则去平台侧确认。

调用产生的费用由模型平台按量收取，明细也在平台侧查，客户端里看不到账单。

## 两条配置路线

**路线 A：手机直配**。设置 → 模型服务 → 添加服务商，常用平台在列表里都有，连连接设置都预填好了；列表里没有的平台就建自定义服务商，按平台说明填基础地址。粘入密钥、保存、同步模型列表、选一个常用模型并启用，然后回对话页发条短消息验证。

**路线 B：配对导入**。电脑上已经在用桌面版的话，手机与电脑连同一个局域网，桌面端打开「设备互联」出示二维码，手机端扫码勾选要同步的服务商即可。提醒一句：把已有服务商再同步一次，会用电脑上的地址和密钥**覆盖**手机那份，两边密钥不同的话想清楚再点。

## 密钥从哪来

- 各模型平台的开放接口页面：注册账号后进开放平台或个人中心创建；
- 部分合作渠道会提供无需密钥的体验模型，想先试试水可以先接那些（活动随时可能调整）；
- 模型列表拉取失败不代表不能用：把平台文档里的准确模型 ID 复制下来手动添加即可。

## 发不出消息的排查顺序

1. 换一条**不带附件的短消息**重试，先用最小情况确认链路；
2. 核对密钥：有没有多余空格、是否保存并启用、是不是误填了登录密码；
3. 确认服务商与模型都处于启用状态，对话顶部选的也是它底下的模型；
4. 检查网络：部分平台的服务器在境外，网络环境不通时什么客户端都救不了。

界面上有 401 / 403 / 429 这类报错码时，对着介绍站或站点内页的报错对照表查就行；更多界面细节与安装步骤，见 [Cherry Studio 手机版介绍站](https://cherry-studio.djnf.quest/)。
