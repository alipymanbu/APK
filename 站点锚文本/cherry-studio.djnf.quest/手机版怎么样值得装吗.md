# Cherry Studio 手机版怎么样，值得装吗

> 本篇回答一个高频搜索疑问：cherry studio 手机版到底怎么样、现在的完成度如何、适合什么样的人装。配置与玩法细节分别见 [模型服务接入与密钥配置](模型服务接入与密钥配置.md) 与 [助手市场与 MCP 工具玩法](助手市场与MCP工具玩法.md)。

---

## 先说结论

Cherry Studio 手机版值得装，但要对「Beta 阶段」有预期。它是 CherryHQ 在桌面版迭代多年之后放出的移动端：核心的多模型对话、智能体、联网搜索、图片生成都已经齐了，日历、提醒这类设备能力也在跟进；只是界面与功能随版本调整比较快，偶尔要更新之后再找入口。

它的定位很清晰——**客户端不自带模型额度**。你在里面看到的每个回答，都是它拿着你自己配置的密钥去对应平台请求回来的。这个「自备钥匙」的设计决定了两件事：

- 隐私与账单都在自己手里：用量与费用去创建密钥的平台查，客户端不掺和；
- 上手多一步：装完要先接一个模型服务才能发出第一条消息（步骤见 [模型服务接入与密钥配置](模型服务接入与密钥配置.md)）。

## 和桌面版的关系

两套客户端同属一个开源项目（AGPL-3.0 协议），桌面版覆盖 Windows / macOS / Linux，功能更全——知识库这类桌面级能力目前以电脑版为准。手机版的优势在「随身」：随手聊几句、把照片丢给模型看、出门在外改改图。

两边可以打通：手机与电脑连同一个局域网，扫码配对就能把电脑里配好的服务商与模型整批导入手机。注意边界——聊天记录不会自动同步，配对带的只是配置。

## 安卓与 iOS 的获取方式

- **安卓**：以 APK 安装包形式发布，面向 ARM64 设备；安装时的授权、报错排查可以看介绍站的安装步骤页。
- **iPhone / iPad**：通过 TestFlight 参与测试，名额与有效期受平台机制管理。

想直接看功能清单与界面截图，去 [Cherry Studio 手机版介绍站](https://cherry-studio.djnf.quest/) 翻一遍就有数了。

## 适合谁装

- 手机是主力设备、想随时用各家模型的人；
- 已经是桌面版用户、想把配置带进口袋的人（配对导入一次到位）；
- 喜欢自己管密钥、在意用量透明的人。

如果是拿不定主意的桌面版老用户，直接两边都装，试一周就有答案。
