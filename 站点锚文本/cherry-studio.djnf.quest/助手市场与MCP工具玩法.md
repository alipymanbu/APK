# Cherry Studio 助手市场与 MCP 工具玩法

> 本篇讲 cherry studio 手机版里最能拉开使用差距的部分：智能体怎么建、MCP 工具接在哪、联网搜索与图片生成怎么开。基础配置见 [模型服务接入与密钥配置](模型服务接入与密钥配置.md)；整体定位见 [手机版怎么样值得装吗](手机版怎么样值得装吗.md)。

---

## 智能体：一套可复用的任务设定

把智能体理解成「名称 + 任务说明 + 默认模型 + 工具」的打包。给翻译任务写好固定要求存成智能体，下次直接开它，不用每次重打提示词；同一个智能体下面还能开多段互不干扰的对话。

初始自带的 Cherry 智能体开箱可用；想找现成角色，去**助手市场**按分类逛——产品经理、社群运营、内容运营这类职业角色都写好了任务说明，取用就能聊。需要执行工具的智能体在动作前会弹确认，复核完再放行，不放心工具乱动东西的话留意这个环节。

## MCP 工具：给对话接上手脚

手机版的 MCP 市场里内置了几类连接器，常见的有：

- **@cherry/fetch**：从 URL 抓取网页内容，配合「总结这条链接」的需求正好；
- **@cherry/time**：获取当前时间，别再让模型瞎猜今天几号；
- **@cherry/calendar / @cherry/reminder**：读取、添加手机上的日程与提醒事项。

第一次用到某项系统能力时会弹授权，不同意就只用不了那一项，其他功能不受影响。挂自定义 MCP 服务也支持，但建议先把一个智能体配顺（模型 + 一两个工具）跑通，再往上叠。

## 联网搜索与网页阅读

联网开关的位置有个小坑：它在**当前智能体的编辑页**里，不在输入框上。先在设置里配好搜索服务，再到智能体编辑页打开联网开关，之后直接在消息里提搜索要求就行——查近期新闻、核对变化中的价格、总结网页内容都顺手。搜索结果带的来源建议点开看一眼，模型转述二手信息偶尔会走样。

## 图片生成与文件输出

- **图片生成**：从一句提示词或视觉模板起步，选图像模型出图；不满意把已有图当参考图继续改，生成历史会留着；
- **导出**：对话内容可以导出成 Markdown、HTML 或图片，换设备前把要留的先导出来——手机和电脑不会自动同步聊天记录。

找不到某个入口时先别急着卸载重装：Beta 阶段界面调整快，先更新版本再看；插件按钮只在有可用连接时出现。更多界面速览与安装步骤，去 [Cherry Studio 手机版介绍站](https://cherry-studio.djnf.quest/)。
