# Send Anywhere 传法手册：站点导读

这里是 Send Anywhere 的第三方介绍站导读。Send Anywhere 是一款跨设备传文件工具：六位数字键现传现收、链接分享留给不在线的人、两台安卓没有外网也能扫码直连，安卓、iOS、Windows、macOS、Linux 与浏览器网页版都有它的位置。

本目录的几篇文章按真实使用场景整理了这个工具的传法与排查思路，站点主页按场景拆解四种传法的完整对比：[Send Anywhere 传法手册](https://send-anywhere.gltd.quest/)。

- [没有网络怎么传文件.md](没有网络怎么传文件.md) —— 两台安卓的 Wi-Fi Direct 扫码直连
