# 备份同步与换机迁移

> 笔记记了一年最怕丢。本篇讲 StarNote 的三条数据保全路线——云同步、本地备份、导出存档，以及换手机时怎么把旧笔记完整搬过去。
> **相关文档**：[手写笔刷与图层玩法](手写笔刷与图层玩法.md) · [PDF文献批注入门](PDF文献批注入门.md)

## 一、先登录，云同步才生效

首次启动用邮箱或手机号注册登录，之后在设置里绑定云服务做同步。双保险建议：重要笔记同时「云同步 + 导出一份 PDF 存本地」——只靠云同步，账号出问题就没有退路。

## 二、本地备份

不想依赖云服务就把整库笔记备份进设备存储，定期把备份文件拷到电脑或 U 盘一份。不依赖网络，缺点是换机要手动搬。

## 三、导出成文件

| 格式 | 用在哪 |
| --- | --- |
| PDF | 发同学同事、打印、长期存档（可带手写批注） |
| PNG / JPEG | 单页取用、插到别处 |

不用整本导出的话，可以只挑部分页面导出；给敏感内容加密，在笔记本设置里单独上锁，上锁不影响同步与导出。

## 四、换机迁移四步

1. 旧设备：确认云同步已完成（设置里看最近同步时间），或做一份本地备份；
2. 新设备：装好应用并登录同一账号，云同步的笔记会自动下来；
3. 走本地备份的：把备份文件拷到新设备，从备份入口恢复；
4. 跨平台（苹果与安卓之间）迁移前后，各导出一份 PDF 存档兜底——有用户反馈过跨平台同步不到的情况。

## 五、笔记不见了怎么办

先停手别再新建或编辑，避免覆盖数据，然后按顺序试：换个网络环境再同步一次 → 从本地备份恢复最近一份 → 都不行就联系应用内「帮助与反馈」。日常把双保险做足，真出事也有退路。

换新机后想装这款应用，可以到 [StarNote 手写笔记介绍站](https://starnote.wrwq.fun/) 看安装包获取方式；装好后的笔刷与图层玩法见 [手写笔刷与图层玩法](手写笔刷与图层玩法.md)。
