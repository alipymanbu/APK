# 手写笔刷与图层玩法

> 拿触控笔在 StarNote 里记笔记，顺手与否取决于两件事：笔刷合不合手、图层分不分得清。本篇把这两块掰开讲。
> **相关文档**：[PDF文献批注入门](PDF文献批注入门.md) · [备份同步与换机迁移](备份同步与换机迁移.md)

## 一、四支常用笔，各管一摊

| 笔刷 | 什么时候用 |
| --- | --- |
| 钢笔 | 日常书写主力，笔触随下笔力度变化 |
| 铅笔 | 打草稿、画示意图 |
| 荧光笔 | 在已有文字上划重点 |
| 马克笔 | 大面积粗线条标注 |

每支笔都能调粗细、透明度与颜色，颜色既可用推荐色集也可开调色盘自调。

## 二、笔盒：按场景分组换装

把常用几支笔加进笔盒，再按场景分组——「上课组」放一支钢笔一支荧光笔，「刷题组」放铅笔加马克笔，切换文档时直接选组，不用每次重新调参数。工具栏也支持自定义，高频工具提到顺手的位置。

## 三、图层：批注与原稿分家

图层是 StarNote 里最值得养成习惯的功能：

- 导入的文档算一层，你的批注算一层，贴的图片又是一层；
- 刷题对答案：只显示答案层，其余隐掉；
- 想重做：清掉批注层，原稿分毫不动；
- 做手帐：素材层和字迹层互不干扰，后期调整省事。

配合橡皮（支持涂抹擦除与压感）和套索（圈选后整体移动、缩放），返工成本很低。

## 四、实时字迹调整与文具

开着「实时字迹调整」，手画的直线、圆会被自动修整成规整形状，想要手绘原样就关掉。文具里还有胶带（盖住内容复习时自测）、贴纸、尺子、计时器、放大镜（密排文档行间写小字）和表格，写不开就切无界画布，往任意方向延展。

想先把这款应用装到设备上试试，功能全景与获取方式见 [StarNote 手写笔记介绍站](https://starnote.wrwq.fun/)；文献批注的展开讲法见 [PDF文献批注入门](PDF文献批注入门.md)。
