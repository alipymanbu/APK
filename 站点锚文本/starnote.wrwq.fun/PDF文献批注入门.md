# PDF文献批注入门

> 课件、试卷、知网文献都能导进 StarNote 里直接写。本篇按「导入 → 腾地方 → 双开」的顺序过一遍批注流程。
> **相关文档**：[手写笔刷与图层玩法](手写笔刷与图层玩法.md) · [备份同步与换机迁移](备份同步与换机迁移.md)

## 一、支持哪些格式

PDF、DOC / DOCX、PPT、EPUB、MOBI、AZW3、TXT 与常见图片格式都支持，比较难得的是连知网下载的 **CAJ** 文献也认——不少安卓批注应用卡在这一步。纸质资料也可以直接拍照导进来批。

## 二、导入路径

1. 新建或进入一本笔记，用「导入」选择设备里的文件；
2. 或者直接拍照 / 选图，把纸质材料拍进来；
3. 导入后每一页都可写，选支笔就能落笔。

## 三、页面留白：给密排文档腾地方

导入的 PDF 排版通常很满，直接批注没处写字。用「页面留白」把文档往一侧缩，空出的白边就是批注区，原文件排版不动，导出时批注跟着页面一起走。给整本教材留批注位、给试卷留演算位，都是这一个功能。

## 四、双开：一边读一边写

开启双开后屏幕分成两块：左边读 PDF，右边写笔记。上课「课件在左、笔记在右」，读文献把摘录写在旁边，都靠它。看视频网课还能配合画中画，课程视频浮成小窗，笔记接着写。

## 五、批注之外

- **摘录互联**：把文档里一段话摘到另一本笔记，两处互相链接，复习时能跳回原文；
- **划词翻译**：读外文文献选中即译；
- **OCR 搜索**：导入的 PDF 与手写内容都能按关键词搜；
- **合并 / 拆分**：几份文档合成一份，或一份拆开重排。

安装包获取与界面主题展示见 [StarNote 安卓版介绍](https://starnote.wrwq.fun/)；导入的图片想删、笔记不见了这类问题，先看 [备份同步与换机迁移](备份同步与换机迁移.md)。
