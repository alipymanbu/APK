# Minecraft Java 版怎么装模组：加载器选择与排错

> 手机上装模组和电脑上是同一套逻辑：先装加载器，再放 mod 文件。本篇讲 Forge 与 Fabric 怎么选、安装器怎么用，以及最常见的几处卡点。
> **相关文档**：[手机怎么玩MinecraftJava版.md](手机怎么玩MinecraftJava版.md) · [MinecraftJava版触屏与键鼠操作.md](MinecraftJava版触屏与键鼠操作.md)

## 一、两条路线：Forge 与 Fabric

两条路线对应两种玩法，按想玩的模组来选：

- **Forge**：老牌加载器，大型整合包的常客，模组数量与历史积累最深；
- **Fabric**：轻量、更新快，性能优化模组（Sodium、Iris 这类）的主要阵地。

同一世界里两者不混用，mod 文件也不会互通——想玩什么模组，就用它标注的加载器。社区还有基于 Fabric 的衍生加载器，玩法一致。

## 二、安装加载器

启动器内置模组安装器，带图形界面，不需要连电脑：

1. 确认所选游戏版本与加载器版本互相匹配（加载器发布页都标有对应关系）；
2. 在启动器里打开模组安装器，选中目标版本执行安装，过程中会有一段黑窗口跑脚本，属于正常现象；
3. 安装完成后版本列表里会多出一个带加载器标记的版本，从它启动即可。

## 三、放置 mod 文件

加载器装好后，mod 文件的摆放与电脑版完全一致：找到游戏目录下的 mods 文件夹，把下载的 .jar 模组文件放进去，重启对应版本生效。手机上没有鼠标，用文件管理器操作即可；个别启动器版本提供游戏目录的快捷入口，省去找路径这一步。

## 四、光影与优化模组的搭配

想跑 Sodium、Iris 这类优化与光影模组，除了装 Fabric，还要注意渲染器：

| 渲染器 | 适合谁 | 备注 |
| --- | --- | --- |
| GL4ES（默认） | 老版本、老机型 | 覆盖面最广，跑光影能力有限 |
| Zink | 支持 Vulkan 的新机型 | 基于 Vulkan，新版本游戏黑屏时可先试它 |
| LTW | 支持 OpenGL ES 3.0 的机型 | 面向新版本加优化模组的组合 |

机型够不着新渲染器时，光影别硬上，先把分辨率和视野调低。

## 五、常见卡点

- **装完模组进不去世界**：先核对加载器与游戏版本是否匹配，再核对 mod 文件是给哪个加载器的；
- **世界加载到一半闪退**：大概率是内存分配不足，在启动器设置里把内存调高一档，但别超过设备物理内存的一半；
- **画面全黑**：渲染器与机型不匹配，换回默认渲染器再逐个试。

启动器本身的能力与版本跨度，可以看这份整理好的 [PojavLauncher 介绍站](https://pojavlauncher.fewa.skin/)；装好进世界之后的操作问题见 [MinecraftJava版触屏与键鼠操作.md](MinecraftJava版触屏与键鼠操作.md)。
