# 安卓安装包获取与安装步骤

> 本篇讲 AiPPT 安卓安装包从哪里取、转存下载到安装验证的完整步骤，以及安装被拦、装完打不开这两类状况的处理。
> **相关文档**：[一句话到整套演示稿要过几道关.md](一句话到整套演示稿要过几道关.md) · [免费额度与会员计费规则盘点.md](免费额度与会员计费规则盘点.md) · [文档导入转换的硬限制与排查.md](文档导入转换的硬限制与排查.md)

在手机上用 AiPPT 的好处是「题目一想起来就能拟稿」。安卓端的安装不复杂，按下面的顺序走，大部分拦路虎都能避开。

## 安装包从哪里取

安装包放在夸克网盘里维护，入口统一走 [AiPPT 流程观察](https://aippt.djnf.quest/) 这一站的下载页——首页和下载页的按钮都指向同一个网盘地址，点开后先**转存到自己网盘**，再下载到手机。这份安装包为 V3.3.0、约 43.38 MB，建议 **Android 8.0 及以上**的系统。

## 四步装好

1. **转存再下载**：直接打开分享链接拿不到完整文件，先转存到自己的网盘账户，再从自己网盘下载；
2. **放行安装权限**：进 `设置 → 应用 → 特殊应用权限 → 安装未知应用`，给打开安装包的那个应用（文件管理器或浏览器）打开开关；
3. **点开安装**：出现「应用未经过安全检测」类提示属第三方渠道的常规提示，选择继续安装；
4. **登录并小验证**：登录方式手机号或微信二选一（记清用的是哪种，两套账户互不相通，详见 [免费额度与会员计费规则盘点.md](免费额度与会员计费规则盘点.md)），随手输个主题试到大纲出来，说明网络与登录都正常。

## 两类常见状况

**点安装被拦**：多数是「安装未知应用」权限没放行，回到第 2 步给对应应用开开关；另一种原因是手机里已有同名但签名不同的版本，会直接安装失败——先把旧的那个卸载再装。

**装完打不开、一点就退**：先核对系统版本是否在 Android 8.0 及以上；版本没问题仍打不开，把安装包重新下载一遍再装，排除文件下载不完整的可能。

装好之后，先按 [一句话到整套演示稿要过几道关.md](一句话到整套演示稿要过几道关.md) 把第一份演示稿走通；材料已经是现成文档的，看 [文档导入转换的硬限制与排查.md](文档导入转换的硬限制与排查.md)。
