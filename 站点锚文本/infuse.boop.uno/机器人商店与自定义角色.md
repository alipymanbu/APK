# Infuse 机器人商店与自定义角色：攒一套自己的文字处理阵容

> 本篇盘点 Infuse 开箱自带的八个内置机器人各自管什么，以及怎么用「添加机器人」按自己的高频场景搭阵容。
> **相关文档**：[使用入门与触发字符.md](使用入门与触发字符.md) · [无障碍权限与隐私答疑.md](无障碍权限与隐私答疑.md)

Infuse 的能力都挂在「机器人」这个载体上：每个机器人对应一类文字任务，各自带名称、模型、触发方式。想先弄清机器人怎么跑起来，可以先看 [Infuse 安卓版介绍](https://infuse.boop.uno/) 里的机制拆解，再回本篇挑阵容。

## 一、开箱自带的八个机器人

应用首页与商店里现成摆着八个，每个卡片都写明了用途：

| 机器人 | 干的事 |
| --- | --- |
| 重写 | 保持原意，把一段话换成另一种说法 |
| 总结 | 在原文语言里提炼简明版本，留住关键信息 |
| 翻译 | 把输入文字快速转到目标语言 |
| 电子邮件回复 | 起草、润色邮件类文本 |
| 解释 | 把复杂概念或不熟的术语讲清楚 |
| 语法检查 | 从语法与风格两头给修改建议 |
| 扩展 | 把一句短语、几条要点扩成完整段落 |
| Facebook 帖子优化 | 按社交平台语感润色帖子文案 |

具体列表以所装版本为准——卡片会随版本微调，多一个少一个都正常。

## 二、这八个怎么组合最顺

按使用频率分两层：

- **高频层**（配触发字符）：翻译、重写这类随手就要的，给它们各配一串好记的触发字符，在输入框里直接唤起；
- **低频层**（主页手动调）：帖子优化、邮件起草这类场景明确的，留在主页按需点开，不占触发字符。

## 三、自定义机器人：四个空格填满一个角色

「添加机器人」新建时，编辑页有四栏：

1. **机器人名称**——起个一眼能认的名字，比如「周报口吻化」比「机器人 3」好用得多；
2. **聊天模型**——按任务难度挑，吃理解力的换强模型；
3. **触发方式**——设一串特殊字符，输入时敲下即触发；清空即关闭快捷唤起；
4. **快速访问**——把常用机器人放进顺手位置。

同一类需求别挤在一个机器人里反复改指令——「摘要给老板看」和「摘要给自己存档」可以拆成两个，各自定好触发字符，调用时反而更快。

## 四、角色与应用的搭配思路

这套工具另一个值得玩的地方是按应用配角色：社交平台派一个会写帖子的，邮箱派一个起草回复的，浏览器里派一个做总结的。角色贴着应用走，每次唤起就不用再解释上下文——这也是它和普通聊天应用最大的分工差异。机制背后需要哪些权限、什么数据会离开手机，见 [无障碍权限与隐私答疑.md](无障碍权限与隐私答疑.md)。
