# Gator 怎么用：首次扫描、查看明细与自动清缓存

本篇讲 Gator 装好之后怎么用：仪表盘上六张卡片各自管什么、第一次扫描的完整路径，以及最特别的自动清缓存是怎么工作的。还没装好的先看[安装步骤那一篇](安卓版下载安装步骤.md)。

## 先认识仪表盘

Gator 打开就是 Dashboard（仪表盘），功能按卡片排布，和它「把账算清楚」的思路一致：

- **System Cleaner**：系统清理，处理系统产生的冗余文件、应用残留、剪贴板内容、浏览器历史等可安全删除的杂项；
- **Cache Cleaner**：专管应用缓存；
- **Duplicate Finder**：在内置和外置存储里找内容相同的重复文件；
- **Exporter**：把图片、视频、音频、文档、压缩包和 APK 搬去外置 SD 卡；
- **Storage Analyzer**：存储空间构成分析，谁占的、占多少；
- **App Manager**：应用的卸载、备份与详情。

每一张卡片右下角是 Scan（扫描）或 View（查看），先用哪个点哪个。

## 第一次扫描的完整路径

1. 在 **System Cleaner** 卡片上点右下角的 **Scan**；
2. 第一次扫描会停下要求授权，按提示给完权限，再点一次 Scan；
3. 结果列出来后，点每一类左侧的**眼睛图标**展开具体文件明细——先看再删，这是它设计上最值得用的一步；
4. 勾选要清理的项目，点右下角的清理按钮执行；
5. 完成后到 **Storage Analyzer** 里看一眼，腾出来的空间能直接对上账。

重复文件（Duplicate Finder）同理：扫描 → 看清单 → 确认两份文件的路径 → 删掉多余的副本。连拍照片和重复下载的视频通常是大头。

## 自动清缓存是怎么工作的

安卓 8.0 之后收紧了权限，第三方应用没法直接替别的应用清缓存。Gator 的做法是借**无障碍服务**把手工动作自动化：

1. 按清单打开某个应用的应用信息页；
2. 代替手指点按「清除缓存」按钮；
3. 逐个应用走完，全程屏幕上可见，随时可取消。

所以开启后屏幕上会自己跳一些系统界面，那是它在执行动作，属正常流程。这套机制的好处是省去逐个应用的重复操作；介意的话可以不授无障碍权限，手动清理功能完全不受影响。
