# 手机存储空间不足怎么办：一套能对上账的清理思路

本篇不讲某一款应用的按钮在哪，而是给一条「能对上账」的清理思路：空间到底被什么吃了、哪些能放心删、哪些该搬走。文末提到的 Gator 正是按这套思路设计的工具，功能细节与安装方法见本目录的其他两篇文章。

## 第一步：先看构成，别急着删

存储焦虑的常见原因是不知道空间去了哪。先看构成——应用缓存、系统残留、照片视频、重复文件、大文件，各占多少。心里有数之后，删什么才有依据，也不会出现「删了一堆还是满」的挫败。

Gator 的 Storage Analyzer 干的就是这件事，把内置存储拆开给你看；它的仪表盘卡片也是按这个思路排的。

## 第二步：按「可再生程度」分层清理

从最安全的一层开始：

1. **缓存类**——应用运行产生的临时数据，删了会自动重建，几乎零风险。这部分量通常不小，一个个点进设置页去清又太繁琐；
2. **残留类**——卸载后留下的空文件夹和孤儿数据，删了没有任何影响；
3. **重复文件**——连拍、多次下载的同一份视频，删之前看清路径、确认保留哪份；
4. **该搬走的**——照片、视频、旧压缩包这类「要留但不常用」的内容，搬到外置 SD 卡或 U 盘，比删掉更稳妥。

前两层交给 System Cleaner 和 Cache Cleaner 这类工具批量处理，后两层适合用 Duplicate Finder 和 Exporter 慢慢过。Gator 把这四件事做成了四张卡片，配合起来正好走完整个流程。

## 第三步：让清理变成后台习惯

手动清理是救急，定时清理才是保持。它的 Scheduler 可以安排定时自动清理，设置一次就不用管；配合无障碍服务自动代点「清除缓存」，连逐个应用的手工动作都省了。缓存类垃圾每天都会再生成，交给自动化比攒到爆仓再大扫除轻松得多。

## 顺带说一句「不该信的」

清理类工具里常见「一键加速」「手机降温」的宣传，这类说法测不出也验不了。真正的收益只有两个数字：腾出了多少空间、清掉了多少可再生的垃圾文件。Gator 自己也把「不玩性能加速噱头」写在介绍里——选工具时，这反而比承诺更多更值得当标准。
