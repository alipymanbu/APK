# 安卓应用是 32 位还是 64 位怎么看

> 判断一个安卓应用装在手机上跑的是 32 位还是 64 位，看的是它的 ABI 架构标签。本篇讲清楚标签在哪里、各标签代表什么、多标签同时出现时怎么读。
> **相关文档**：[APK里的第三方库和组件怎么查看.md](APK里的第三方库和组件怎么查看.md)

## 三十秒看出结果

最快的办法是用 LibChecker 这类应用架构查看工具：装好后打开应用列表，每一项右侧都直接挂着架构标签，多数情况不用点进详情就能读出答案。

以 [LibChecker 应用分析工具](https://libchecker.fedq.quest/)为例，列表项上会同时出现「64 BIT」位宽徽标和 `arm64-v8a` 这样的架构代号；开了标签着色选项后，32 位与 64 位还能用颜色区分，扫一眼就能分完一屏应用。

## 架构标签对照

| 你看到的标签 | 含义 | 位宽 |
| --- | --- | --- |
| `arm64-v8a` | 64 位 ARM，近几年手机的主流架构 | 64 位 |
| `armeabi-v7a` | 32 位 ARM，老设备与部分模拟器常用 | 32 位 |
| `armeabi` | 更早的 32 位 ARM 架构，如今罕见 | 32 位 |
| `x86_64` | 64 位 x86，平板与模拟器常见 | 64 位 |
| `x86` | 32 位 x86，多见于老旧平板与模拟器 | 32 位 |
| 无原生库 | 应用不含 `.so` 文件（纯 Java/Kotlin 实现） | 不受架构限制 |

判断口径：带 `64` 的（`arm64-v8a`、`x86_64`）是 64 位；`armeabi-v7a`、`x86` 是 32 位。

## 一个应用挂了好几个标签怎么办

一个安装包可以同时内置多套架构的库，每套各带一份。装到手机上之后实际跑哪一套，由系统按自己的架构挑选——64 位手机优先跑 64 位那套。所以要看「你这台设备上」的结果才有意义：同一个应用，在模拟器上查出来的结果可能和真机不一样。

模拟器是常见的坑：部分安卓 9 内核的模拟器默认实例会把应用装成 32 位，哪怕安装包本身带 64 位库。装完后再用工具复查一遍，就能确认实际装成了哪种。

## 什么场景用得上

- **排查兼容性**：应用闪退或功能异常，先看它是不是只有 32 位库，而设备或模拟器只跑 64 位。
- **确认 64 位适配**：Google Play 自 2019 年起要求新应用提供 64 位支持，更早的老应用未必有。
- **核对模拟器装机结果**：装完复查一遍，确认实际位宽。
