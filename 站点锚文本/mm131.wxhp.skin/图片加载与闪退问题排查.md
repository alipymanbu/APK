# MM131 图片加载与闪退问题排查

用 MM131 时最常碰到的几类状况：安装失败、打开闪退、图片刷不出来、设壁纸没反应。这篇按命中率从高到低给出排查顺序，多数问题两三步就能定位。

## 一、安装时提示「解析失败 / 安装失败」

1. **安装包没下完整**——头号原因。删掉这个 apk，回网盘重新下载一遍；下载中途断网、切网都可能产出残缺文件；
2. **存储空间不足**——安装包约 115MB，加上解包临时空间，剩余空间最好留出 1GB 以上；
3. **传输损坏**——电脑中转的换一种传法再传一次，数据线最稳。

## 二、打开就闪退

1. 先重启手机，排除内存被占满的临时状态；
2. 确认系统版本——这版需要较新的安卓系统，太老的系统装上也跑不起来；
3. 清除应用缓存或数据再开（系统设置 → 应用管理 → MM131 → 存储）；
4. 还不行就卸载重装，安装文件从头按[安卓版下载安装全流程](安卓版下载安装全流程.md)走一遍，别用来路不明的旧包。

## 三、图片加载不出来 / 一直转圈

1. 检查网络：图库内容走在线加载，网络不稳就是刷不出来，切 Wi-Fi / 流量对比一下；
2. 从最近任务里把应用彻底划掉再打开；
3. 清缓存后重试；
4. 长时间整体刷不出来，可能是内容服务在维护或调整，隔几小时再看。

## 四、设壁纸没反应

1. 回顾操作路径：大图页点「设为壁纸」，部分机型要跳到系统预览页再点一次「应用」；
2. 到系统设置确认应用的存储等权限已开启，权限被关时设置动作会静默失败；
3. 换一张图试试，个别超大图在部分机型的壁纸服务上会失败；
4. 实在设不上，把图保存到相册，用系统相册的「设为壁纸」完成同样的事。

## 五、还没装 / 想重装

安装文件资源的获取入口统一整理在 [MM131 介绍站](https://mm131.wxhp.skin/)，日常挑图换壁纸的操作见[壁纸设置与分类浏览上手](壁纸设置与分类浏览上手.md)。
