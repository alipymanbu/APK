# switch520 是什么：一个聚合多平台游戏条目的安卓客户端

> switch520 把 Switch、PC、PS4、PS5 等平台的游戏条目、资讯、攻略与发售表收进一个十几 MB 的手机应用。本篇讲清它的定位、分区结构与适合谁用；安装方法见[安卓客户端安装步骤](安卓客户端安装步骤.md)，拿到文件的具体操作在[游戏搜索与网盘取件流程](游戏搜索与网盘取件流程.md)。

## 它的定位：索引与界面，不是仓库本体

很多人第一次打开会疑惑：应用只有十几 MB，怎么装得下那么多游戏？答案是它只负责「索引 + 操作界面」——条目信息、分类导航、搜索框都在本地跑，真正的游戏文件体积大得多，取件时走网盘链接。所以判断它好不好用，看的不是应用体积，而是条目全不全、找起来快不快、凭据给得清不清楚。

## 分区结构：主机各自成区，工具单独归栏

左侧抽屉菜单把内容切成几块，各管一件事：

| 分区 | 里面有什么 | 适合谁 |
| --- | --- | --- |
| Switch 游戏 | NSP/XCI 条目按类型、热度排列，中文与多语言版本都有标注 | 主机玩家主力逛的区 |
| PC 游戏 | 从 3A 大作到独立作品，类型跨度大 | 想在电脑上玩的用户 |
| PS4 / PS5 | 主机大作条目，按更新时间排序 | 索尼系玩家 |
| 其他主机 / 掌机 / 模拟器 | 小众平台与模拟器相关条目 | 怀旧与收藏向玩家 |
| 资讯区 | 新闻、攻略、评测、发售表、礼包信息 | 盯新游、查攻略 |

按第三方站点的公开介绍，收录条目规模在两万以上，热门新作上线后更新较快；实际体验以你打开的版本为准。

## 适合谁用

- 想先看条目、截图和介绍，再决定要不要花时间找资源的玩家；
- 记不住英文名、习惯搜中文的用户——搜索框输入中文名即可，记不清全名也能按分类翻；
- 需要发售表配合收藏功能盯新游上线时间的人。

## 上手路径一分钟版

注册登录 → 搜索或按分区浏览 → 进详情页看介绍 → 点「立即下载」拿到链接、提取码、解压密码 → 去网盘取文件。每一步的细节在[游戏搜索与网盘取件流程](游戏搜索与网盘取件流程.md)里展开；还没装上的先看[安卓客户端安装步骤](安卓客户端安装步骤.md)。
