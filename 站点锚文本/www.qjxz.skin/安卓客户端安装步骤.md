# switch520 安卓客户端安装步骤：从转存到打开

> switch520 的安装包通过网盘分享分发，本文只讲「把应用装进手机」：获取包、允许未知来源、覆盖安装升级，以及装不上时的三个排查方向。应用本身的定位先看[客户端功能与上手流程](客户端功能与上手流程.md)。

## 装之前对一眼信息

以当前流通的安装包为准：版本 v1.1.2，体积 15.93 MB，要求 Android 5.2 及以上。系统版本在 设置 → 关于手机 里能查到，低于要求会装不上或一打开就退。

## 四步装好

1. **转存安装包**：从分享入口把整个文件夹转存到自己的网盘（里面还有一份说明 txt，一起转存），再用网盘客户端把 APK 下载到手机；电脑端下载后用数据线传过去也可以；
2. **点开 APK**：用文件管理器或网盘客户端找到 `switch520_v1.1.2.apk`，点它开始安装；
3. **允许未知来源**：系统提示「禁止安装未知来源应用」时，按提示进 设置 → 安全/隐私 → 允许安装未知应用，给当前这个来源（文件管理器或网盘客户端）打开开关，返回后继续；
4. **完成并打开**：首次启动申请网络等权限，按需允许即可进入首页。

## 升级与重装

- **升级**：新版本安装包直接覆盖安装，包名一致会原地升级，不用先卸载——卸载会清掉应用内的本地数据；
- **重装**：真要卸了重装，先确认账号密码还在手里，登录后收藏与记录能从服务端接回来；
- **别混装**：来源不同的同名安装包可能签名不一致，覆盖会报「签名冲突」，先卸旧的再装新的。

## 装不上的三个高频现象

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | 文件没下完整（中途断流） | 换稳定网络重新下载，别硬装残缺包 |
| 安装被系统阻止 | 未知来源限制没开 | 按第三步给对应来源开开关 |
| 一打开就闪退 | 系统版本不足或存储紧张 | 确认 Android 5.2+，清出 200 MB 以上空间后重启再试 |
