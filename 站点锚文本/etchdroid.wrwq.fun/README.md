# EtchDroid 站点目录

这个目录收录与 EtchDroid 相关的介绍文章。EtchDroid 是一个运行在安卓手机上的开源镜像写入工具，可以把 Linux 发行版 ISO、树莓派系统卡镜像直接写进 U 盘或 SD 卡，不需要 root，也不依赖电脑。

想快速了解它的功能、界面与安装方式，可以看这里整理好的 [EtchDroid 介绍站](https://etchdroid.wrwq.fun/)；本目录下的文章按具体使用场景展开，可从下面几篇进入：

- [手机写U盘启动盘教程.md](手机写U盘启动盘教程.md)——没有电脑时怎么用手机把系统镜像写进 U 盘
- [免root给树莓派写系统卡.md](免root给树莓派写系统卡.md)——树莓派镜像的解压与手机写入方法
- [写盘后U盘打不开怎么办.md](写盘后U盘打不开怎么办.md)——写完提示"U盘有问题"的原因与恢复办法
