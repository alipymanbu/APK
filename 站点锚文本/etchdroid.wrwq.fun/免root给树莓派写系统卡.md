# 免root给树莓派写系统卡

> 给树莓派装系统，传统做法要先有一台能读卡的电脑。这篇讲怎么用安卓手机直接把系统镜像写进 SD 卡，全程不需要 root。
> **目录内相关文章**：[手机写U盘启动盘教程.md](手机写U盘启动盘教程.md) · [写盘后U盘打不开怎么办.md](写盘后U盘打不开怎么办.md)

---

## 为什么手机能干这个活

树莓派的系统镜像本质就是一张可直接写入的磁盘镜像，和 Linux 发行版 ISO 是同一类东西。安卓手机通过 OTG 接上 USB 读卡器后，[EtchDroid](https://etchdroid.wrwq.fun/) 就能像操作 U 盘一样把镜像写进卡里——应用走的是系统提供的 USB 接口，不碰分区、不碰系统底层，所以完全不需要 root。

## 先解压，再写入

树莓派官方提供的镜像大多是 `.img.xz` 压缩包，**直接选压缩包写入会失败**，先做一步解压：

1. 把 `.img.xz` 下载到手机存储（树莓派官网的下载页手机浏览器就能访问）。
2. 用手机上的解压应用把它解出 `.img` 文件（部分解压应用支持直接解 xz 格式，没有的话换一个支持的应用）。
3. 解出来的 `.img` 动辄 4~8 GB，确认手机存储装得下。

## 写卡步骤

1. **组装**：SD 卡插进 USB 读卡器，OTG 转接头连到手机（Type-C 直插读卡器可省转接头）。
2. **选镜像**：打开应用选写入镜像，选刚才解压出的 `.img` 文件。
3. **选卡**：设备列表里选读卡器对应的条目——注意手机**内部**卡槽不会被识别，这是安卓系统的限制，任何应用都绕不过，必须走 USB 读卡器。
4. **写入**：确认覆盖后开写。写卡比写 U 盘慢一些，8 GB 镜像可能要半小时上下，期间保持供电、别拔读卡器。

## 写完装卡开机

把 SD 卡插进树莓派的卡槽，接上屏幕键盘或直接走无头配置（预先在 boot 分支放好配置文件），首次开机按所用发行版的引导走完初始化即可。

如果这张卡以后要重用或换系统，直接重写一遍就行；想恢复成普通存储卡，格式化方法见 [写盘后U盘打不开怎么办.md](写盘后U盘打不开怎么办.md)。第一次接触手机写盘的话，先看 [手机写U盘启动盘教程.md](手机写U盘启动盘教程.md) 里的注意事项，供电与 OTG 的坑是通用的。
