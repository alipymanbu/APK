# 安卓安装步骤与常见问题

> 本篇讲 Dododex 安卓安装包怎么装到手机上，以及装不上、打不开时的排查顺序。
> **相关文档**：[方舟驯服计算器怎么用](方舟驯服计算器怎么用.md) · [服务器倍率怎么填才准](服务器倍率怎么填才准.md)

Dododex 是方舟玩家的驯服数据工具，安卓安装包通过夸克网盘分享获取。装之前留意系统要求：较新版本对安卓版本有要求，安装时以手机实际提示为准。

## 一、安装步骤

1. **转存分享文件**：打开分享链接，登录后把安装包转存到自己的网盘空间，原分享之后失效也不影响取用；
2. **下载到手机**：在网盘里把安装包下载到手机存储，也可以先下到电脑再传过去；
3. **允许本次安装**：点开 apk，系统提示「禁止安装未知来源应用」时按提示进设置允许本次安装，再返回继续；
4. **联网完成首次启动**：装完打开，首次启动会拉取最新生物数据，保持网络畅通即可。

安装包与更多功能说明都在 [Dododex 介绍站](https://dododex.djnf.quest/)，站内下载页有完整的安装指引。

## 二、装不上或打不开怎么办

- **点安装没反应或被拦截**：这是安卓对非商店来源的默认拦截，按弹窗提示允许本次安装；仍不行先检查手机剩余存储是否够用；
- **打开一直转圈、提示数据加载失败**：启动需要联网。依次试：强行停止后重开、换 Wi-Fi 或流量、检查这个应用的联网权限有没有被单独关掉；
- **报 JSON parse error**：是数据端本身的临时故障，等一会儿再刷新；
- **重装后设置丢失**：倍率、收藏、自定义武器列表都存在本地，重装即清空 —— 重装前把数值抄下来，装好照着重填。

装好后第一件事是把服务器倍率设对，口径见[服务器倍率怎么填才准](服务器倍率怎么填才准.md)；计算器的完整用法见[方舟驯服计算器怎么用](方舟驯服计算器怎么用.md)。
