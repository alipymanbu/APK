# Dislike 到点没提醒排查步骤

> Dislike 到点没弹提醒时，按概率从高到低排查：勿扰与通知分类 → 后台管控 → 重启后的正常现象 → 账号与版本。
> **相关文档**：[强提醒设置与权限开启](强提醒设置与权限开启.md) · [农历生日提醒怎么设](农历生日提醒怎么设.md)

## 一、先查两个最容易被忽略的开关

1. **勿扰模式**：下拉快捷面板看「勿扰」是否开着——它压掉所有应用的通知，是「单独这个应用没提醒」里最常见的误会。有些手机还会定时自动开启勿扰，把日程也查一遍。
2. **通知分类（渠道）**：安卓 8 及以上，每个应用的通知按渠道单独开关。进 系统设置 → 应用 → Dislike → 通知，把总开关和下面每个分类都过一遍；某一类被单独关掉或设成「静默」，那一类提醒就没了。

## 二、后台被清了：厂商省电策略

各品牌的后台管控都会「杀后台」，应用被清掉就弹不出提醒。各家入口不同，思路一致——把 Dislike 设为不受限：

- **华为/荣耀**：设置里搜「应用启动管理」，关掉自动管理，打开允许自启动、关联启动、后台活动；再到「电池优化」里设为不允许优化。
- **三星**：设置 → 电池 → 后台使用限制，确认 Dislike 不在「深度睡眠」名单里。
- **小米/OPPO/vivo 等**：一般在 电池 → 省电策略/应用智能省电 里设为「无限制」，并在最近任务里给它上锁。

入口名称随系统版本变化，拿不准就在设置里直接搜应用名。

## 三、两种正常现象，别当故障

- **开机或重启后**应用还没启动过，提醒收不到——打开一次 Dislike 就恢复；
- 一键清理后台后提醒停了——重新打开应用即可。

所以别把 Dislike 加进一键清理的动作里，日常上滑清后台时也留意别顺手划掉。

## 四、还没好，按这个顺序收尾

1. 升级到新版本再试；
2. 进应用确认那条事件没被标记完成、日期与提醒设置没被改过；
3. 退出账号重新登录，让数据重新同步一遍；
4. 仍不行就通过应用内的反馈渠道联系开发者（邮箱在应用介绍页能查到）。

从头到尾还没装过应用的，[Dislike 安卓版安装与功能整理](https://dislike.fedq.ren/)里有序列完整的下载安装步骤；权限该开哪几处，见[强提醒设置与权限开启](强提醒设置与权限开启.md)。
