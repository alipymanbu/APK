# Dislike 农历生日提醒怎么设

> 本篇讲怎么让生日、纪念日按农历每年准点提醒：重复规则的设法、内置订阅里的生日条目，以及几个顺手的小设置。
> **相关文档**：[强提醒设置与权限开启](强提醒设置与权限开启.md) · [到点没提醒排查步骤](到点没提醒排查步骤.md)

## 一、核心设法：重复单位选「年」，勾上农历

建事件时把重复单位选「年」并勾选**农历**，之后每年都按农历落日期，不会漂到公历去。这是 Dislike 重复机制里最常用的一招，父母长辈的生日、传统纪念日都靠它。

顺手可以做的：

| 你想表达的事 | 怎么设 |
| --- | --- |
| 农历生日、纪念日 | 重复单位选「年」+ 勾选农历 |
| 每月固定日还贷、交租 | 重复单位选「月」 |
| 周一/周三/周五健身 | 重复单位选「周」，多选星期 |
| 工作日例行事务 | 重复单位选「周」，只勾周一到周五 |

重复周期支持多选组合；节日、生日这类事件还有专门画的趣味图标，完成状态不再是单调的对勾。

## 二、懒得手建：先翻内置订阅

亲友生日这类事，内置订阅里有现成条目（含生日祝福类订阅），一键打开就有，日期与提醒方式都替你配好。订阅覆盖健康、财务、居家、出行、社保几个领域，不订阅的不会出现在时间线里。

## 三、到点没响，先看两处

农历生日一年就一次，漏了最伤感情。到点没提醒，多数是系统把通知压了：先看勿扰模式，再查通知分类开关，逐项排查走[到点没提醒排查步骤](到点没提醒排查步骤.md)。

想把这套设置用起来，得先装上它：[Dislike 介绍站](https://dislike.fedq.ren/)整理了安卓安装文件资源的获取入口与安装步骤，iOS 端也能在应用市场直接搜到。装好后按[强提醒设置与权限开启](强提醒设置与权限开启.md)把权限开全，一年一次的提醒就稳了。
