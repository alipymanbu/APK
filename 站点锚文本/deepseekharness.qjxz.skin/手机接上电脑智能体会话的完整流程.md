# 手机接上电脑智能体会话的完整流程

> 本篇讲怎么把安卓手机接到一台正在跑 DeepSeek Harness 的电脑上，人离开书桌后照看会话、回消息、派任务。
> **相关文档**：[电脑端插件安装与远程通道选择](电脑端插件安装与远程通道选择.md) · [局域网扫码连不上电脑怎么办](局域网扫码连不上电脑怎么办.md)

## 一、先分清要装的三样东西

很多人一上来只装手机 App，结果扫描列表永远是空的。整套组合其实是三件套：

1. **DeepSeek Harness（dsh）**：电脑上跑的 Agent 运行环境，一条 `npx @deepseek-ai/dsh web` 就在本机 3080 端口打开 Web 界面，日常任务都在这里跑。
2. **dsh-mobile 插件**：装在电脑端 DSH 里的社区插件，负责把「移动访问」入口加进 DSH，处理设备发现、通道开关和配对授权，不动 dsh 本体。
3. **安卓 App**：装在手机上的配套应用，打开的就是电脑上那份界面——选电脑、建任务、发指令、看进度。

插件与 App 由社区开发者以开源协议维护，并非 DeepSeek 公司出品；三者通过插件机制衔接、各自独立升级。

## 二、推荐的首次连接顺序

1. 电脑端装好 dsh 并跑起来，确认本机能打开 Web 界面。
2. 电脑端装 dsh-mobile 插件，重启 DSH，界面左下角出现「移动访问」入口。
3. 手机装好 App，先别急着点开。
4. 手机和电脑连同一个 Wi-Fi（或手机热点），电脑端打开「移动访问」面板。
5. 手机 App 里点「开始扫描」，选中自己的电脑；也可以直接点「扫码配对」对准电脑端二维码。
6. 配对完成后，手机里就是电脑上同一批会话与工作区，之后长期可用，不用重复配。

完整的安装文件资源与截图对照，可以在 [DeepseekHarness 介绍站](https://deepseekharness.qjxz.skin/)的下载页里按步骤走。

## 三、配对之后能做的事

- **会话同步**：电脑上跑到一半的任务，手机上接着看消息与进度，两端的记录是同一份。
- **任务通知**：任务完成或等待输入时，安卓系统通知直接提醒，锁屏上的文本会脱敏。
- **多台电脑**：家里台式机、公司工作站各自配对后，在 App 的设备列表里统一管理。

出门在外的场景不需要重新折腾——提前在电脑端开好远程通道即可，具体做法见[电脑端插件安装与远程通道选择](电脑端插件安装与远程通道选择.md)；如果扫码这一步就卡住了，先翻[局域网扫码连不上电脑怎么办](局域网扫码连不上电脑怎么办.md)。
