# 电脑端插件安装与远程通道选择

> 本篇讲电脑端 dsh-mobile 插件的几种装法，以及出门在外时远程通道怎么挑、怎么开。
> **相关文档**：[手机接上电脑智能体会话的完整流程](手机接上电脑智能体会话的完整流程.md) · [局域网扫码连不上电脑怎么办](局域网扫码连不上电脑怎么办.md)

## 一、插件的三种装法

按电脑上装 DSH 的方式三选一，装完重启 DSH：

1. **npm 命令行**：终端里跑 `dsh plugin --profile web add dsh-mobile@latest`，再执行一次 setup 让它记住当前局域网网卡；网卡识别错了才需要手动指定地址。
2. **DSH 桌面端**：在应用的插件页面里搜索并启用 dsh-mobile，然后打开「移动访问」面板完成配置。
3. **插件市场**：装上插件市场后，在设置里搜 dsh-mobile 直接安装。

插件走 DSH 的插件机制装与卸，不改本体；dsh 仍按默认只监听本机，公网暴露与否完全取决于你自己开不开远程通道。

## 二、远程通道怎么挑

出门后还想连家里或公司的电脑，就得在电脑端先开一条远程通道。常见的几种按场景挑：

- **只想快速能用**：cpolar，装好开通即得一个公网入口，适合临时用。
- **手上有组网服务**：Tailscale，设备进同一虚拟网络后体验接近局域网。
- **自己有域名和服务器**：cloudflared 或自建 FRP、反向代理，入口长期稳定，还能复用现有证书。

通道选好后手机不用做额外设置——App 扫「远程配对二维码」会自动识别走的哪条通道，或把电脑端生成的 HTTPS 配对链接发到手机上，用配对链接连接也能完成。两条远程与局域网路线的开关在电脑端分开管理，互不影响。

各通道下手机端的入口位置与扫码界面，[DeepseekHarness 介绍站](https://deepseekharness.qjxz.skin/)的远程通道一节配了实拍截图可对照。

## 三、安全上值得知道的几点

- 局域网链路用插件自建的证书体系加密；公开远程入口按标准 HTTPS 校验，自签入口也由 App 固定远程证书。
- 配对凭据存在安卓系统的密钥库里，不落明文；哪台设备能连、什么时候撤销，都在电脑端的配对授权里管。
- 设备令牌只发往配对时的确切地址，来源对不上的连接默认拦截。

装好插件之后下一步就是手机端安装与首次扫码，顺序见[手机接上电脑智能体会话的完整流程](手机接上电脑智能体会话的完整流程.md)；扫码一直失败的话，排查清单在[局域网扫码连不上电脑怎么办](局域网扫码连不上电脑怎么办.md)。
