# Lanerc 追番怎么用：排期表、收藏清单与离线缓存

> 装好之后从哪开始？这篇按「找到番 → 追住更新 → 离线看」的动线，把日常追番最常用的几个功能串起来。

## 第一步：找到想看的那部

打开应用就是内容页，没有绕人的引导。找番按手头的信息选路径：

| 你知道什么 | 走哪条路 |
| --- | --- |
| 作品名字 | 搜索框直接搜；搜不到就换译名再试，同一部日本动画常有多个译名 |
| 只记得题材画风 | 分类筛选：题材、年份、地区组合着缩范围 |
| 想看电影版 | 进剧场版专区，剧场版动画单独归拢 |
| 没有目标 | 翻首页推荐与更新列表，新番与经典分开陈列 |

进详情页先看三样：剧情概述（决定看不看）、分集列表（从哪开始）、更新状态（追连载的进度参照）。

## 第二步：把更新追住

每周更新按星期几排在排期表里，每部标注更新时间与最新话数，每天扫一眼就不会漏。看到想追但暂时没空的，加进收藏或追番清单，之后在「我的」页面集中继续播放。

清单、弹幕、评论这些功能的完整体验需要登录账号：注册入口在「我的」页面，注册后还有一道限时「入站答题」，答够题数才算正式入站。不登录也能正常观看，只是互动这两层用不上。

## 第三步：离线缓存省流量

计划看的剧集提前缓存到本地，通勤隧道、信号差的场合直接看已缓存内容。两个注意点：

1. 缓存占的是手机本地存储，缓存前确认剩余空间，看完的旧包及时清掉；
2. 画质越高占的空间越大，Wi-Fi 环境下提前缓存最划算。

播放环节的常用调整：网络不好降一档画质、倍速按需调、弹幕可开关；卡顿按「查网络 → 降画质 → 换线路 → 停后台下载任务」的顺序排查，多数在前两步就解决。
