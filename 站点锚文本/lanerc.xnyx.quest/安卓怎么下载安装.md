# Lanerc 安卓怎么下载安装：从拿到 APK 到进站看番

> 这款追番应用没上架主流应用商店，拿包和安装都靠自己动手。这篇按顺序写清每一步，以及装不上时最常撞见的三种提示怎么处理。

## 装之前先弄清楚

这是一支安卓端的动漫在线观看应用，安装包体量不大（30.7 MB 上下），近几年的安卓设备都能满足系统门槛。由于不走应用商店分发，获取方式就是拿 APK 安装包侧载安装——系统会拦一次「未知来源」，放行即可，属于这类应用的常规操作。

## 四步装好

1. **拿到安装包**：打开 [Lanerc 介绍站的获取指引](https://lanerc.xnyx.quest/download.html)，页面里的按钮指向夸克网盘分享，登录自己的账号后转存或直接下载；
2. **放行未知来源**：在文件管理器里点开 APK，系统拦截时选允许。安卓 8.0 以上路径一般是设置 → 应用管理 → 特殊应用权限 → 安装未知应用，给打开安装包的那个文件管理器放行；小米机型先关「纯净模式」的拦截；
3. **完成安装**：回到文件管理器重新点开，等安装结束，点「打开」进入；
4. **初始化**：首次启动按需允许存储权限（离线缓存要用），然后就能进精选页挑番了。

## 装不上的三种常见提示

- **「禁止安装未知来源应用」**：按第 2 步把权限给到位再重试；手机管家拦截的先放行；
- **装到一半失败、提示包损坏**：多半是下载环节出的问题，删掉重下一份，换 Wi-Fi 与流量再试；
- **「与已安装应用冲突」**：手机里有同包名的旧版本，卸载旧的再装。

还有一点容易踩坑：搜这个名字会撞到漫画阅读类的同名应用，装完在应用信息里核对包名是 `com.clggjv.xcjfmd.ffo` 才算装对了那一支。
