# 手机投电脑画面怎么弄

想把手机上的游戏、视频或者聊天记录挪到电脑大屏上看，思路其实只有两条：要么走 WiFi 无线投屏，要么插一根 USB 数据线。两条路最终效果一样，差别在准备动作和稳定程度。

## 先把两端都准备好

投屏是「手机端 + 电脑端」配合完成的：手机上装客户端，电脑上也装一份。两端都登录之后才能互相发现，这一步没做好，后面搜不到设备多半是它。安装文件资源可以从 [ApowerMirror 投屏指南](https://apowermirror.bpfl.quest/) 整理的网盘入口获取，装完再回来看连法。

## 路线一：WiFi 无线连

1. 手机和电脑连**同一个 WiFi**（这是最常翻车的一步，路由器如果分 2.4G 和 5G 两个名字，注意别一边连一个）；
2. 两端都打开软件，等待互相搜索；
3. 安卓手机点「投屏」，在列表里选中电脑的设备名；
4. iPhone 走控制中心 →「屏幕镜像」，点选对应设备即可。

WiFi 连法省事，适合看视频、翻照片这类对延迟不敏感的场景。

## 路线二：USB 有线连

1. 电脑端打开软件，用数据线把手机插上；
2. 安卓要先开 **USB 调试**：设置 → 关于手机 → 连点版本号 7 次进入开发者模式，再打开 USB 调试开关；
3. 重新插线，手机弹窗上允许调试，进度走到 100% 就投上了。

有线连接延迟明显低一档，玩手游、追求手感就走这条路。顺带一提，劣质充电线只能充电不能传数据，插上没反应先换一根原装线。

## 连上之后还能反向操作

投屏工具里有一类支持「反控」：画面投到电脑后，直接用鼠标点选、键盘输入来操作手机。打游戏把走位映射到 WASD、发消息用实体键盘打字，效率比在屏幕上戳指尖高不少。具体哪些场景值得这么用，可以看[电脑键鼠反控安卓手机怎么实现](电脑键鼠反控安卓手机怎么实现.md)那篇。

## 搜不到设备先查三件事

- 两端是不是真的在同一个网段；
- 路由器有没有开 AP 隔离（开了就互相看不见，关掉或换手机热点验证）；
- 手机端是不是被省电策略杀了后台，MIUI 等系统把对应应用设为「无限制」再试。

按这个顺序排查，绝大多数「列表空白」都能解决。
