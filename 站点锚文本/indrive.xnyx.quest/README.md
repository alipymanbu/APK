# inDrive 出价打车整理站：玩法、安全与安装入口

> 这里是围绕打车应用 inDrive 做的第三方整理索引：议价玩法怎么走、司机怎么挑、支付与安全怎么设、装不上去哪查。
> 相关阅读：[出价打车怎么用.md](出价打车怎么用.md) · [司机挑选与行程安全.md](司机挑选与行程安全.md) · [支付方式与常见问题.md](支付方式与常见问题.md)

inDrive 是一款由乘客先报价、司机再应价的打车应用，目前覆盖约 48 个国家的上千座城市，市内打车之外还有跨城、货运与顺路拼单几种坐法。它与传统叫车软件最大的差别在价格：数字由你填，司机接不接受、还不还价，谈判空间留给双方。

图文版的界面速览、出价技巧与安全功能清单，整理在 [inDrive 出价打车介绍站](https://indrive.xnyx.quest/)，安卓安装包的获取入口也放在那里。

## 这个目录里有什么

- **出价打车怎么用**：从选城市到挑司机的完整流程，第一次报价报多少、没人接怎么调。
- **司机挑选与行程安全**：报价卡片上按什么顺序比，上车前后的安全功能分别在哪。
- **支付方式与常见问题**：现金、绑卡、本地钱包的切换时机，验证码收不到、账号被限制等挡路问题的处理。
