# inDrive 司机挑选与行程安全：比价看什么、路上靠什么

> 讲报价卡片上按什么顺序挑司机，以及上车前后的安全功能：行程分享、紧急按钮、可信联系人与司机核验。
> 相关阅读：[出价打车怎么用.md](出价打车怎么用.md) · [支付方式与常见问题.md](支付方式与常见问题.md)

## 一、报价卡片上按什么比

报价陆续进来后，每张卡片上都带着可比的信息，按这个顺序过基本不会错：

| 看什么 | 为什么 |
| --- | --- |
| 评分与评价 | 历史乘客打分的沉淀，分低的先放一放 |
| 完单车次 | 接得越多，对流程越熟 |
| 车型与车牌 | 上车时核对用，与应用内显示必须一致 |
| 预估到达时间 | 同价选更快到的 |
| 备注 / 条件 | 有的司机会附「等待时间」「行李」等条件 |

部分城市的发单表单还提供车型档位（Comfort / Premium 之类）：更新的车、更高的司机标准，价码自然高一档；没有这个选项就是所在城市未开。

## 二、上车前：三对照

司机注册时平台会核验驾照、身份证件、车辆信息和本人照片，注册后还会定期通过人脸与车辆照片复核。乘客这侧要做的是对照：

1. 司机**头像**与真人一致（认证时拍的自拍）；
2. **车牌、车型**与应用内显示一致；
3. 对不上就别上车，取消订单并联系客服。

车到了找不到人，用应用内通话或聊天联系——双方号码都是隐藏的。

## 三、行程中：安全中心在哪、有什么

- **入口**：侧边菜单 → Safety；行程中则是地图上的**盾牌图标**，会带上当次行程的快捷项；
- **分享实时路线**：行程开始后点盾牌 → 分享我的路线信息，选一位联系人，对方打开链接就能看到你的实时位置、司机姓名、车型车牌，免注册；
- **紧急按钮**：安全中心里直拨当地警察、急救电话；
- **可信联系人**：Safety → Emergency contacts，最多设 5 位，紧急情况下平台会通过这些号码联系；
- **优先客服**：从安全中心发出的消息会标为优先处理，比普通工单快。

觉得不对劲可以立即结束行程，费用争议事后再说——安全永远排在前面。

## 四、隐私与保障

- 应用内打电话、发聊天都不向对方暴露手机号，行程结束后没有互相骚扰的入口；
- 平台说明是行程从上车到下车处于保险覆盖之下；真出事故，平台会先冻结涉事账号、收集聊天与行程数据取证，必要时对接执法部门，客服协助走理赔；
- 乘客的义务就几条：系安全带、路线变更在应用内改（改路线通常改价）、别提行程之外的要求。

## 五、出了纠纷怎么留证据

先在安全中心联系客服报备，再到**侧边菜单 → Request history（行程记录）**找到该单，把行程时间、路线、聊天记录一并提供；订单在完成后 24 小时内进列表，历史只保留当年与前一年，需要更早的联系客服调取。
