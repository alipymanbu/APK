# sensetime 是什么应用与名字由来

> 本篇讲清 sensetime 这个名字对应的手机应用「商量（SenseChat）」：名字怎么对号、开发者是谁、核心功能有什么。
> **相关文档**：[安卓版下载与安装步骤](安卓版下载与安装步骤.md) · [验证码登录与使用疑问](验证码登录与使用疑问.md)

搜「sensetime」的朋友常带着同一个疑问：这是一款什么应用？答案要从三个名字说起。

## 一、三个名字，同一个应用

- **sensetime**：出现在安卓包名（`com.sensetime.chat`）、安装包文件名与部分资源目录里，是偏技术场合的名字；
- **商量**：它在各应用商店上架时用的中文名，也是用户日常叫法；
- **SenseChat**：产品公开资料里的英文名。

三个名字指向同一款应用——商汤科技「日日新」大模型体系下的 AI 对话应用。开发者登记信息为上海商汤智能科技有限公司；应用内《个人信息保护政策》写明的运营方是上海禹幻科技有限公司及其关联方。

## 二、它是一个什么样的应用

商量 SenseChat 的定位是「AI 聊天问答助手」：以对话为核心交互方式，把问答、读文档、看图片、打电话式音视频通话装进同一个对话框。综合产品公开页面与发布信息，它的主要能力包括：

| 能力 | 说明 |
| --- | --- |
| 长文本问答 | 中文理解强，公开口径支持理解 20 万字级别的超长文本 |
| 网页搜索 | 回答结合互联网检索结果，适合问时效性信息 |
| 文档解析 | 支持上传 pdf、doc、docx、pptx 等格式，读要点、做摘要、找条款 |
| 图片问答与生成 | 拍照提问、识别图片内容，也能按文字描述生成图片 |
| 音视频实时通话 | 聊天陪伴、指间点读翻译、拍题讲解三类典型场景 |
| 互动讲故事 | 面向孩子的主打场景，故事讲到一半可以插嘴提问，它顺着接 |

## 三、适合什么人

- 想要一个能开口说话的 AI 陪聊伙伴；
- 经常跟长报告、合同、论文打交道，想让 AI 先读一遍理出要点；
- 家里有需要辅导的孩子，用得上数学答疑、批改纠错与互动讲故事。

也要知道边界：第三方评测提到它在复杂推理、高难度代码任务上与头部模型仍有差距，长对话偶尔跑题，关键结论建议自己复核。
