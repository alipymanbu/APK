# ColorOS 状态栏时钟显秒与双排网速怎么开

> 想让 ColorOS 状态栏的时钟显示秒数、双排摆放，网速常驻双行——系统设置里找不到这些开关。
> **相关文档**：[ColorOS锁屏按钮与图标怎么移除.md](ColorOS锁屏按钮与图标怎么移除.md) · [README.md](README.md)

---

## 一、先说清：系统设置里没有这两个选项

ColorOS 的状态栏定制粒度很粗：时钟只有"显示 / 不显示"，网速是单行、刷新也慢，秒数和双排布局在设置里压根没有入口。所以这事的路径只有一条：Root 之后刷 LSPosed 框架，再装一个覆盖系统界面（SystemUI）的模块去改。

[LuckyTool](https://luckytool.bpfl.quest/) 就是干这个的模块之一，它把状态栏、控制中心、锁屏、桌面这些位置的"隐藏开关"集中到一个面板里，逐项勾选生效。下面按实际操作顺序讲。

## 二、动手前的三个前提

| 前提 | 说明 |
| --- | --- |
| 设备已 Root | Magisk、KernelSU、APatch 任一均可 |
| 已装 LSPosed | 常见是 Zygisk 版：Magisk 开 Zygisk 后刷入，重启生效 |
| 系统版本 | 推荐 ColorOS 12 及以上；开发者的日常测试机是一加 9RT（Android 14 / ColorOS 14） |

三者缺一，装了也不会生效。不在这套系统上的机器（原氧、Realme UI 等）不在适配口径内，能不能用要自己试。

## 三、开关都在哪一页

模块功能页里与状态栏有关的主要是"状态栏相关"和"状态栏控制中心"两页，常用项：

| 你想要的效果 | 对应开关 |
| --- | --- |
| 时钟显示秒数 | 状态栏时钟 → 显秒 |
| 时钟双排摆放、调字体大小 | 状态栏时钟 → 双排显示 / 双排字体大小 |
| 往状态栏里加年月日 | 自定义时钟 → 预设或自定义格式 |
| 网速双行常驻、刷得勤一点 | 状态栏网速 → 启用双行网速、刷新率设 1s |
| 下拉面板里调磁贴行列数 | 状态栏控制中心 → 磁贴行列数 |

同一页里还有些减法项：移除电量百分号、移除绿点隐私提示、移除充电完成通知等，按需勾。

## 四、改完怎么让它生效

这是最容易踩空的一步，顺序照做：

1. 在 LSPosed 管理器里启用模块，按提示勾选推荐的作用域（系统界面、系统桌面、设置这些都要勾上）；
2. 打开模块，弹出 Root 授权时点允许；再到系统设置里给它"所有文件访问权限"（导日志用）；
3. 把要的开关逐个打开，回到模块主页，点右上角重启按钮 → 选"重启作用域"；
4. 状态栏改动落在系统界面（SystemUI）上，属于普通应用作用域，重启作用域后下拉状态栏就能看到变化；个别涉及系统框架的功能才需要整机重启。

开关打开了但没重启作用域，是这类模块"假故障"的第一名——先补这一步再排查别的。

## 五、两个常见的不对劲

- **更新模块后状态栏突然回到默认样子**：版本更新后建议重启一次系统，很多"更新后失灵"就是漏了这一步。
- **系统大版本升级后不报错但不生效**：用模块重启菜单里的"优化 Dex"跑一遍，或在 LSPosed 里长按"系统界面"选"重新优化"，重建优化缓存即可。

锁屏上那些去不掉的按钮和图标是另一套开关，位置和生效条件略有差别，见
[ColorOS锁屏按钮与图标怎么移除](ColorOS锁屏按钮与图标怎么移除.md)。
