# EasyTouch 悬浮球怎么用

> 本篇讲 EasyTouch（安卓悬浮球辅助工具）装好后的入门用法：先把悬浮窗权限开起来让球出现，再学会拖动、隐藏与唤回，最后按自己的习惯给四下手势分配动作。
> **相关文档**：[下载安装步骤](下载安装步骤.md) · [悬浮球消失与卸载问题排查](悬浮球消失与卸载问题排查.md)

---

## 一、先让悬浮球出现

刚装完打开应用，第一屏是权限引导，两件事做完球就出来了：

1. **开启悬浮窗权限**：跳到系统设置里找「显示在其他应用上层」，给 EasyTouch 打开。不开这一项，悬浮球根本不会出现。
2. **开启自启动**：允许开机自启，重启手机后球能自动回来。

点「开始使用」，屏幕边缘出现一颗半透明小圆点，这就是悬浮球。

## 二、球的基本操作：拖、藏、唤回

- **挪位置**：按住球不放拖到想要的位置松手，屏幕四边都能贴。看视频或玩游戏时拖到不挡按钮的角落。
- **临时藏起来**：默认「长按」就是隐藏动作，球会立刻消失。
- **找回来**：隐藏后在桌面或应用列表里重新点开 EasyTouch，球就回来了。

## 三、双击展开快捷面板

默认「双击」展开悬浮面板，里面是九个常用功能：截屏、锁屏、手电筒、通知、最近任务、返回、主屏、加速清理、系统设置。面板分两页，顶部有搜索框，输入名字可以直接打开任何已装应用。

面板不是固定的：**长按面板空白处**进入编辑，从应用、联系人、快捷开关里往里加图标；显示设置里还能用滑块调球的大小与透明度，换图标样式和主题。

## 四、给四下手势各配一个动作

打开应用 → 「悬浮按钮手势」→ 点任意一项换动作。默认分配是：

| 手势 | 默认动作 |
| --- | --- |
| 单击 | 最近任务 |
| 双击 | 悬浮面板 |
| 三击 | 最近任务 |
| 长按 | 隐藏按钮 |

常见的搭配思路：单击给截屏或锁屏最省事；双击保留悬浮面板；长按别改掉「隐藏按钮」。

各功能的权限要求（锁屏要设备管理器、通知要通知使用权、手电筒要相机）在这篇里有细说：[悬浮球消失与卸载问题排查](悬浮球消失与卸载问题排查.md)。想看图文并茂的版本，去 [easytouch 悬浮球介绍站](https://easytouch.djnf.quest/) 翻一遍即可。
