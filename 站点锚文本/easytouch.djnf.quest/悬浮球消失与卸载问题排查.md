# EasyTouch 悬浮球消失与卸载问题排查

> 本篇汇总 EasyTouch 用起来最容易卡住的三件事：悬浮球不见了、点了功能没反应、想卸载却卸不掉，每条都按排查顺序给做法。
> **相关文档**：[悬浮球怎么用](悬浮球怎么用.md) · [下载安装步骤](下载安装步骤.md)

---

## 一、悬浮球不见了 / 重启后不出现

按这个顺序查，多数在第二步就解决：

1. **是不是自己藏了**：长按悬浮球默认是隐藏动作，重新打开一次 EasyTouch 应用即可找回。
2. **被省电策略清了后台**：把自启动权限打开，「设置 → 电池」里把 EasyTouch 设为「不优化 / 无限制」，再在多任务界面把它的卡片下拉（或点锁形图标）锁定。国产系统省电很激进，这三件不做，球过一会儿就会消失。
3. **悬浮窗权限被收回**：到「设置 → 应用 → EasyTouch → 显示在其他应用上层」确认开关还开着；小米这类系统还要在安全中心的权限里允许「弹出界面」。
4. 上面都做完还不行：重启一次手机，权限刚开时个别系统要重启才生效。

## 二、点了功能没反应

面板功能不是都开箱即用，缺权限的点下去系统会提示，对照补齐：

- **截屏**：悬浮窗权限；部分系统还要「出现在顶部」或无障碍授权。截出来是黑的，通常是银行、政务类应用或有版权保护的画面，系统禁止截取，换个界面再试。
- **锁屏**：需要激活设备管理器。
- **手电筒**：相机权限（闪光灯走相机接口）。
- **通知**：在「设置 → 通知使用权」里授权。
- **联系人快捷拨打**：电话权限。

都开齐了还没反应：清一次应用缓存（设置 → 应用 → EasyTouch → 存储 → 清除缓存），从最近任务划掉重开。

## 三、卸载不掉

**现象**：长按图标找不到卸载，或点了被系统拒绝。

**原因**：激活过设备管理器（锁屏功能需要）。安卓规定带设备管理器的应用不能直接卸载，不是应用在耍赖。

**做法**：

1. 打开「设置 → 安全 → 设备管理器（设备管理应用）」，老系统在「设置 → 位置和安全 → 选择设备管理器」。
2. 找到 EasyTouch，取消激活。
3. 回应用列表正常卸载。

另外提醒一句：用设备管理器锁屏后，下一次解锁系统会要求先输密码，指纹人脸暂时不可用——这是安卓机制，介意的话把锁屏手势换掉。更多日常玩法见 [悬浮球怎么用](悬浮球怎么用.md)，图文版内容都收在 [EasyTouch 说明站](https://easytouch.djnf.quest/)。
