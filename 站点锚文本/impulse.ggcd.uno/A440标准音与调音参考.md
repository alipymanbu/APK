# A440标准音与调音参考

乐队合奏前对音，所有人一起吹响或拨响同一个 A——那个 A 是 440 Hz。这个数字是现代音乐的通用参照点，背后有一段不长但值得知道的历史。

## 440 Hz 是怎么定下来的

历史上各地区的音高并不统一，同一个「A」在不同城市能差出好几个赫兹，乐团跨城巡演时常被搞得狼狈。1939 年在伦敦召开的国际会议建议把 A4 定为 440 Hz，1955 年国际标准化组织把它写入 ISO 16 正式固定下来。选择 440 并没有声学上的特殊理由——它只是当时英语世界已广泛通行、数字整齐、电子振荡器也容易生成的一个折中值。如今调音器、电子键盘、交响乐团的默认标准音都是它。

## 倍频关系一推就是一串音

标准音定了，其余音按倍频展开：880 Hz 是高八度的 A5，220 Hz 是低八度的 A3，440 与 880 之间再按十二平均律均分出其余十一个音。对管乐、弦乐来说，一个准确的 440 Hz 参考音足够把整件乐器的音准拉回正轨。

## 用手机当调音参考音

一部能定频发声的应用就能胜任：输入 440、外放、开始对音。Impulse 打开默认就是 440 Hz，点 Start 即响，预设页还存了 440 / 1000 / 2000 / 3000 Hz 四个常用点——[Impulse 音频信号发生器介绍站](https://impulse.ggcd.uno/)上有完整的功能说明和界面实拍。练耳时也可以用同一套思路：先放 440，再放 880，感受八度的距离感，是不错的音准训练起点。

给吉他这类六弦乐器调音，标准音只是起点：第六弦到第一弦的空弦音是 E2、A2、D3、G3、B4、E4，其中 A2（110 Hz）就是标准音的两次减半，从 440 一步步除以二就能推出来。手机外放参考音加耳朵比对，对初学者是成本最低的调音方式。
