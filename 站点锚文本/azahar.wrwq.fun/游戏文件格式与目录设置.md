# azahar 游戏文件格式与目录设置：列表扫不出游戏先查这里

> 装好 azahar、游戏文件也放进手机了，列表却一片空白——这是新手最常撞上的墙。这篇讲清楚 azahar 认哪些格式、目录怎么摆、以及「扫不出来」的两大常见原因。
> **相关文档**：[手机配置要求.md](手机配置要求.md)

## azahar 认的几种格式

| 扩展名 | 是什么 | 备注 |
| --- | --- | --- |
| `.3ds` / `.cci` | 卡带镜像 | 同一种格式的两个名字；2120 版起不再认 `.3ds` 后缀，改名 `.cci` 即可被识别 |
| `.cia` | 安装型内容包 | 数字版游戏、DLC、系统内容常用 |
| `.cxi` / `.app` | 可执行内容 | 多见于系统程序或拆出的模块 |
| `.3dsx` / `.elf` | 自制程序 | 玩 homebrew 才会碰到 |

普通玩家手上的游戏文件不是 `.3ds`（或 `.cci`）就是 `.cia`，放进游戏目录都能被扫描到。

## 目录怎么摆最省事

1. **单建一个游戏目录**。在手机存储根目录附近建一个专门文件夹（比如 `3DSgames`），所有游戏文件集中放进去。散落在下载目录各处是「列表里找不到游戏」最常见的起因。
2. **首次启动时指定目录**。azahar 第一次启动会提示选择游戏文件夹；当时跳过了，之后在游戏列表界面重新添加也来得及。
3. **等扫描完成再下结论**。模拟器会连子目录一起扫，符合格式的文件逐个以图标加名称的形式出现；第一次进某个游戏时着色器在编译，开头卡顿属正常。

换手机或升级模拟器版本时，游戏目录本身不用动，重新指定一次路径即可。

## 扫不出来，九成是这两个原因

**其一：转储没有解密。** azahar 从 2120 版起不再支持加密的应用——加密转储扫不出来、点进去黑屏或报解密错误，都不是文件损坏，放密钥文件也救不了。解密要在导出环节完成：用自己的卡带通过 GodMode9 之类工具选解密导出，得到的文件才是 azahar 能直接读的形态。旧 Citra 时代「放个密钥文件就能跑加密转储」的经验在这里不再成立。

**其二：`.3ds` 后缀踩线。** 2120 版起不再认这个扩展名（格式没变，只是不认这个名字），把文件改名成 `.cci` 再扫一次，通常就出现了。

两条都排除了还不行，就去查这个游戏在兼容性列表里的状态——「本来就不兼容」的游戏，怎么折腾目录和设置都无济于事。

## 顺手的两个管理习惯

- **存档先备份再做任何变更**：游戏内存档与即时存档都在模拟器数据目录里，换机、重装、两种安装形态互换前，把整个数据目录拖出来一份（Android 11 及以上的受限目录用数据线连电脑访问最省事）。
- **版本更新不挪游戏目录**：APK 直装形态不会自动更新，出新版重装模拟器即可，游戏文件与目录原地不动。

设备档次不够跑不动的，先回 [手机配置要求.md](手机配置要求.md) 对表；还没装上的，[azahar 安卓版介绍站](https://azahar.wrwq.fun/)的下载页里有完整的装机步骤。
