# azahar 手机配置要求：什么手机能流畅跑 3DS 模拟

> 想在手机上用 azahar 跑 3DS 游戏，先看设备档次够不够。这篇把项目 README 给出的最低配置、每项配置背后的真实含义，以及选购或筛选旧手机的思路一次讲清。
> **相关文档**：[游戏文件格式与目录设置.md](游戏文件格式与目录设置.md)

## 最低配置表

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 系统 | Android 10.0 及以上 | 低于 10 的系统装不上 |
| 位宽 | 64 位 | 安卓包只发 64 位版本，32 位设备安装阶段直接失败 |
| 芯片 | 骁龙 835 或同等及以上 | 「能跑」的底线，不是「跑得好」的保证 |
| 图形 | OpenGL ES 3.2 或 Vulkan 1.1 | 两者至少支持其一 |
| 内存 | 2 GB 起，建议 4 GB | 模拟器本体不占地，游戏文件才占地 |

## 每一项背后的真实含义

**芯片档次决定上限。** 3DS 模拟的重头在单核 CPU 性能与 GPU，八核低能的芯片堆核数没用。骁龙 835 是 2017 年的旗舰芯片，此后各代中高端芯片（骁龙 8 系、天玑 8000 系以上）基本都能稳住多数游戏；骁龙 4 系、6 系这类入门芯片则要做好心理预期。

**Vulkan 与 OpenGL ES 怎么选。** 两个图形后端都内置了，较新的芯片、较新的驱动先试 Vulkan，不少设备上它的帧数上限更高；遇到花屏、闪退、黑屏再切回 OpenGL ES 对照。逐游戏取舍，没有全局最优解。

**内存 4 GB 是条实用线。** 2 GB 能开机，但安卓系统本身就吃掉大半，留给模拟器的余量紧张；4 GB 以上才谈得上后台不杀、长时间游玩。

**存储留给游戏文件。** 模拟器本体约 24 MB，可忽略；但一份 3DS 游戏动辄数百 MB 到数 GB，装之前给游戏目录留足空间，而且别把游戏散落在下载文件夹里——单建一个目录集中存放，扫描和后续管理都省事。

## 手上设备不达标怎么办

- 设置上能缓解：内部分辨率降到 1x、关闭放大相关的附加效果、避免边充电边玩（发热降频是掉帧大户）。
- 但底线救不回来：低于骁龙 835 的设备，怎么调都到不了「流畅」；个别游戏本身兼容性差，换设备也没用，先查兼容性列表再折腾。
- 淘汰的旧旗舰反而是性价比之选：两三年前的骁龙 8 系旗舰跑 azahar，往往比新的入门机强得多。

配置达标只是第一步，游戏文件本身的格式与放置方式同样影响体验，见 [游戏文件格式与目录设置.md](游戏文件格式与目录设置.md)；安装包的获取与装机步骤，可以看 [azahar 安卓版介绍站](https://azahar.wrwq.fun/)的下载页。
