# PingID 验证器介绍站说明

本目录收录围绕 PingID（Ping Identity 出品的手机端多因素验证应用）整理的介绍与使用说明。PingID 配合公司或学校的组织账号使用：登录时在手机上批准验证请求，也可用指纹面容确认或输入离线一次性密码。应用的获取入口、安装步骤与验证方式详解见 [PingID 验证器介绍站](https://pingid.laze.skin/)。
