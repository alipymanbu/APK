# 收不到验证推送怎么办

> 登录时手机不弹验证请求，是 PingID 用户最常撞上的问题。本篇按"权限 → 省电策略 → 品牌专项 → 兜底方案"的顺序给一份可照着逐项过的排查清单。

## 先分清两种"收不到"

- **一条通知都没有**：权限被拒，或应用后台被系统杀掉了；
- **通知要迟到几分钟**：省电策略在延迟投递——验证请求有时效，等它到时早已过期。

两种都先确认手机网络正常（Wi-Fi 或流量至少通一个），再往下查。

## 通知权限：最常见的拦路虎

安装时要是点了"拒绝"，之后一条验证都收不到。安卓 13 起通知是运行时权限，首次启动会弹窗；当时拒了就到这里补：

- 系统设置 → 应用 → PingID → 通知 → 允许；
- 顺手检查具体通知渠道没有被单独关掉（有的系统允许按类别关闭）。

权限一直开着还是收不到，问题多半在省电策略。

## 省电与后台策略逐项排查

1. **电池优化改为"不受限制"**：长按 PingID 图标 → 应用信息 → 电池 → 选"不受限制"；
2. **允许后台流量**：省流量模式会把后台应用的联网一起拦掉，把 PingID 加入不受限名单或关掉省流量；
3. **别用"强行停止"**：从设置里强停一个应用后，安卓在你再次打开它之前不会投送任何推送——系统标准行为，杀后台同理，尽量用"加锁"代替清理；
4. **关闭休眠类开关**：部分系统有"暂停不活跃应用的活动"选项，关掉对 PingID 的休眠。

### 品牌专项（菜单名称随系统版本有差异）

| 品牌 | 要动的开关 |
| --- | --- |
| 华为 EMUI | 手机管家 → 应用启动管理 → PingID 改"手动管理"，自启动 / 关联启动 / 后台运行三项全开；同时放行 Google Play 服务并保持 Google 账号已登录 |
| 小米 MIUI / HyperOS | 给 PingID 开自启动；省电策略选"无限制"；最近任务里加锁 |
| OPPO / 一加 / realme | 电池优化里选"不优化"；允许自启动 |
| 三星 One UI | 电池 → 后台使用限制 → 确认 PingID 不在休眠名单，加入"从不休眠的应用" |

各品牌后台管控的差异，dontkillmyapp.com 有份社区汇总可以对照参考。

## iPhone：四个系统开关

- **定时推送摘要**：关闭，或把 PingID 移出摘要名单；
- **专注模式**：关闭，或把 PingID 加入允许的通知列表；
- **低数据模式**：设置 → 蜂窝网络 → 蜂窝数据选项 → 关闭；
- **低电量模式**：设置 → 电池 → 关闭——它会限制应用后台运行，推送明显迟到。

顺带把应用与系统都保持更新，这类排查步骤同样把升级列了进去。

## 推送实在不来的兜底：OTP

验证请求不弹，直接打开 PingID——主界面就显示当前的一次性密码（OTP），把它输到登录页的验证框里即可通过。用法与离线前提见[一次性密码怎么用](一次性密码怎么用.md)；还没配对、连第一次验证都发不出来的，处理路径见[扫码配对激活流程](扫码配对激活流程.md)。权限、后台、网络都查过仍不行，联系组织管理员查账号侧配置。应用的最新安装包获取入口，见 [PingID 验证器介绍站](https://pingid.laze.skin/)。
