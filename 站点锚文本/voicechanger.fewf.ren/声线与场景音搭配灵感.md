# Voicechanger 声线与场景音搭配灵感

> 声线决定「你是谁」，场景音决定「你在哪儿」，参数决定「效果多狠」——这篇按用途把三十多种效果分好组，再给几组现成的组合配方。
> **相关文章**：[录音变声操作全流程](录音变声操作全流程.md) · [变声常见问题排查](变声常见问题排查.md)

## 一、声线按用途分组记

效果列表横滑点选、实时试听，一个个试太慢，按用途记组更快：

| 用途 | 典型声线 | 适合场合 |
| --- | --- | --- |
| 性别与年龄 | 女孩、男孩、婴儿、大叔、萝莉 | 群聊整蛊、角色扮演 |
| 科幻与恐怖 | 机器人（两档）、外星人、僵尸、幽灵、水下的 | 鬼故事、游戏配音 |
| 动物 | 狗、猫、狼、虎、鸟类 | 短视频搞笑桥段 |
| 演唱与搞怪 | 卡啦OK、音乐 | 改着调子说话、整活 |
| 器材与基础 | 工作室、电话、低音增强器、警笛、门铃 | 效果音、快速微调 |

一个取巧办法：先点「正常」，只手动调音调——不想换角色、只想让声音「高一点或低一点」时，这条路最快。

## 二、场景音是叠加层，不是备选项

环境音和声线是叠上去的关系：先定声线，再决定要不要空间感。界面右侧入口点选即加，再加错了点一下取消。

- 洞穴回音、雨天：氛围组，恐怖与抒情内容都好用；
- 嘈杂街面、火车车厢、夏天的晚上：真实感组，配合「街头偶遇」式的整蛊剧情；
- 烟花、警笛、门铃、电话铃：点缀组，一两条音频里出现一次就够，多了吵。

## 三、三组现成配方

- **恐怖故事**：幽灵声线 + 洞穴回音，变音强度拉到七成左右，讲鬼故事氛围立刻起来；
- **街头整蛊**：婴儿声线 + 嘈杂街面，发给朋友猜「这是在哪儿录的」；
- **游戏解说**：机器人 II + 低音增强器，系列视频固定这一套，几条内容的音色能保持一致。

## 四、参数微调的几个分寸

预设是开箱即用的，但每个人嗓音不同，同一效果落在自己身上可能偏高或偏低。语音编辑器里五项可拧：**音调**（太尖就回收）、**清晰度**（环境吵、出来发闷时加）、**音量**（变声后比原声小时加）、**回音**（拖尾长短）、**变音强度**（「不够像」和「太假」之间双向找位置）。

两条常见误区：一上来把强度拉满，效果浓到穿帮；已经选了婴儿这类高音调声线还手动升调，容易尖锐破音。边听边拧、小步调整，调坏了恢复默认重来即可，原录音不会被破坏。
