# Voicechanger 录音变声操作全流程

> 这篇把「录一段声音 → 换声线 → 叠场景音 → 保存 → 发出去」五步走完，第一次打开应用照着做即可。
> **相关文章**：[声线与场景音搭配灵感](声线与场景音搭配灵感.md) · [变声常见问题排查](变声常见问题排查.md)

## 一、开工前的两件事

先装好应用并给足权限：安装与权限设置的具体步骤，见 [Voicechanger 站点的下载安装页](https://voicechanger.fewf.ren/download.html)。装好第一次打开，系统会请求**麦克风权限**——变声的前提就是能把声音录进来，这一项务必允许；存储权限可以等到导入音频或保存作品时再给。

## 二、五步流程

1. **录一段**：主界面正中是录音键，点一下开始、再点一下停止。录的时候正常说话就行，原声会先存下来，变声是后加的效果，不用「边变边说」。
2. **挑声线**：停止后自动进入效果界面，一排声线图标横滑点选，点哪个立刻变成哪个声音并试听。不满意就换，同一段录音可以无限重试。
3. **叠环境音**：界面右侧是环境音入口，洞穴回音、雨天、嘈杂街面、火车车厢这些场景音，点选即叠加；再点一次取消。这一步可选，只换声线也完全成立。
4. **保存**：满意后点保存，作品进应用内的「我的作品」栏目。保存在手机本地完成，不依赖网络，之后随时回放。
5. **发出去**：保存界面有分享入口，可以直发微信、QQ、WhatsApp 这类社交应用，也能导出文件后自行转发，或者把成品设成来电铃声、闹钟。

## 三、不想开口？走文字转音频

主界面上还有「文字转音频」入口：打字生成语音，再套用任意声线与场景音。做旁白、鬼畜台词、不想露嗓子的整蛊消息，都从这里进，后续的换声流程与录音完全一致。

## 四、用现成音频来变声

已经录过的干声、别人发来的语音，不必重录：主界面「打开文件改变声音」入口可以从手机本地选音频文件，选中后走同一条「选声线 → 加场景音 → 保存」流程。只认常见音频格式，遇到少见的无损格式先转成 MP3 或 WAV 再导入。
