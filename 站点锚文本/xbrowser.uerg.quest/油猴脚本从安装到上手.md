# 油猴脚本从安装到上手

> xbrowser（X浏览器）把脚本管理器做在了浏览器里，不用装 Tampermonkey 这类扩展就能直接用油猴脚本。本文讲清两种安装方式、Greasy Fork 的安装流程与装完没反应的排查。
> **相关文档**：[广告拦截规则怎么订阅](广告拦截规则怎么订阅.md) · [轻量浏览器为什么受欢迎](轻量浏览器为什么受欢迎.md)

---

## 一、和桌面浏览器装脚本有什么不同

在 Chrome 上用油猴脚本，得先装一个管理器扩展；xbrowser 直接把这个管理器内建了——拿到脚本就能装。脚本能做的事与桌面端一致：页面翻译、自动翻页、去广告辅助、界面改造、暗色模式等。

管理入口统一在「浏览器设置 → 用户脚本」，装过的脚本都在这里开关和删除。

## 二、安装方式一：地址栏打开脚本地址

1. 复制脚本的 URL（通常以 `.user.js` 结尾）；
2. 粘贴到 xbrowser 地址栏打开；
3. 浏览器识别出油猴脚本，弹出安装提示，确认即可。

## 三、安装方式二：从 Greasy Fork 安装

[Greasy Fork](https://greasyfork.org/) 是主要的脚本分享站，脚本量大、更新勤：

1. 打开脚本详情页，点「安装此脚本」；
2. 第一次装脚本时站点会弹对话框，选「我已经安装了用户脚本管理器，让我安装」——xbrowser 内建管理器，直接这么选；
3. 再次点安装，弹出安装提示，确认完成。

## 四、装完没反应，按这个顺序查

| 现象 | 排查 |
| --- | --- |
| 页面没有任何变化 | 到「设置 → 用户脚本」确认脚本处于启用状态 |
| 启用了还是没反应 | 检查脚本的匹配规则（`@match` / `@include`）是否覆盖当前网页 |
| Greasy Fork 点安装没反应 | 站点先弹了「已安装脚本管理器」提示，走完流程再点一次安装 |
| 功能在手机上不对劲 | 很多脚本为 PC 页面编写，装前看作者说明是否兼容手机浏览器 |

另外注意脚本与广告拦截可能互相影响：脚本改坏页面、或拦截误杀脚本资源时，先分别禁用对照定位原因。

## 五、几个值得一试的方向

- **页面翻译**：给非中文网页加一键翻译；
- **自动翻页 / 自动展开全文**：长文和列表页不用手点「下一页」；
- **暗色模式助手**：给不支持夜间模式的页面补上暗色。

脚本之外，xbrowser 还有手势定制、视频嗅探、阅读模式等能力，界面与功能一览见 [xbrowser 介绍页](https://xbrowser.uerg.quest/)；把体积做到 1M 级却保留脚本引擎的思路，见[轻量浏览器为什么受欢迎](轻量浏览器为什么受欢迎.md)；拦截规则与脚本打架时的处理，见[广告拦截规则怎么订阅](广告拦截规则怎么订阅.md)。
