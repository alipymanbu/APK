# 9Apps 还能用吗？现状说明

> 本篇回答一个高频疑问：这个 2013 年上线的第三方安卓应用商店，今天拿到安装包还能不能正常用。结论先行，再给判断依据。

## 结论先行

**能装、能打开，但商店类在线功能已经不可用。**

9Apps 的服务端在 2020 年后随业务收缩停止维护，应用内依赖服务器的功能——首页推荐、搜索、分类浏览、在线下载——都没有运营方了，加载失败是必然结果，反复刷新、重装、换网络都救不回来。

## 装上之后是什么体验

| 动作 | 现状 |
| --- | --- |
| 安装 APK | 正常 |
| 打开应用、浏览本地界面 | 正常 |
| 界面切成简体中文（汉化构建） | 正常 |
| 首页推荐 / 搜索 / 在线下载 | 加载失败，属已知现象 |

把它当成一份「能跑起来的历史档案」来看待最合适：想看看当年的界面长什么样、给老设备装个轻量商店把玩，没问题；指望它当日常的下载工具，则不必了。

## 判断依据

- 2016 年前后它月活一度突破 2.5 亿，是印度、印尼市场最大的第三方安卓应用商店；2020 年印度市场变动后，UC 收缩业务，线上服务陆续停维；
- 各渠道流传的安装包版本与包名并不统一，装之前先核对版本，安装过程见[安卓版下载安装步骤](安卓版下载安装步骤.md)；
- 界面语言取决于构建类型，判断方法见[怎么设置中文界面](怎么设置中文界面.md)。

它的界面结构、特色功能与发展时间线，在 [9Apps 资料站](https://9apps.wxhp.skin/)里有更完整的图文整理，可以对照着看。
