# 9Apps 安卓版下载安装步骤

> 本篇讲怎么把这个第三方安卓应用商店装到手机上：从拿到安装包到打开，一共四步，外加三条真会挡路的排障提示。

## 安装前先知道

- 存档构建版本 4.1.8.0，体积约 7M，界面支持简体中文；
- 系统要求安卓 5.0 以上（存档记录口径为 5.2，以实际安装为准）；
- 它不在应用商店的货架上，安装包要走「未知来源」授权安装，这是安卓的默认机制，不是包有问题。

安装包的获取入口在 [9Apps 资料站](https://9apps.wxhp.skin/)的下载页，打开网盘分享页后**先转存到自己账号再下载**，链接失效时转存过的那份不受影响。

## 四步装好

1. **转存安装包**：打开网盘分享页，把安装包转存到自己的网盘账号下；
2. **下载到手机**：转存后把它下载到手机存储；用电脑下载也行，下完传过去；
3. **允许安装未知应用**：设置里搜「安装未知应用」，给「文件管理」或你用来打开安装包的那个应用授权；旧系统在 设置 → 安全 里勾选「未知来源」；
4. **安装并打开**：文件管理里点这个 APK → 安装 → 打开；首次弹出扫描提示属正常流程。

界面是英文的话，用 Settings → Language 切成简体中文，具体路径见[怎么设置中文界面](怎么设置中文界面.md)。

## 常见安装问题

**点安装没反应，或提示被禁止安装**
权限没给全。注意授权对象是「你用来打开安装包的那个应用」——用浏览器打开 APK 却只给文件管理授权，照样被拦。

**提示「解析包出错」或「应用未安装」**
先看包下完整没有：约 7M 的包，体积差很多就是断在了半路，删掉重新下；其次确认系统版本达标。都没问题还报错，换一个文件管理器打开再试。

**之前装过别的版本，覆盖安装失败**
不同渠道流传的安装包签名不一致，系统会拒绝覆盖。先卸载旧版再装；卸载它不影响手机里其他应用。

装完之后能干什么、哪些功能已不可用，见[还能用吗与现状说明](还能用吗与现状说明.md)；它的界面截图与功能整理在 [9Apps 资料站](https://9apps.wxhp.skin/)。
