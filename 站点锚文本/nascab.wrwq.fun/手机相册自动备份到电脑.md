# 手机相册自动备份到电脑

> 本篇讲用 NasCab 把手机相册自动备份回家里电脑的做法，以及备份之后怎么靠人脸、地点和智能相册把几千张照片理顺。
> **相关文档**：[旧电脑变私有云.md](旧电脑变私有云.md) · [出门在外访问家里电脑.md](出门在外访问家里电脑.md)

手机相册是最怕换机和丢设备的地方——云端相册要么限速要么压缩画质，照片原件攥在自己手里才踏实。前提是先按[旧电脑变私有云](旧电脑变私有云.md)把服务端装好、手机连上服务器，然后照下面做。

## 一、开启相册备份

手机客户端里找到相册备份入口，添加手机相册作为来源，备份在连接家里 WiFi 时自动进行，照片原图直接落到电脑硬盘，不经第三方服务器。之后拍的新照片按同样规则自动跟上，不用每次手动导。

## 二、照片怎么自动理顺

备份只是第一步，几千张照片靠人手翻不现实。NasCab 的相册功能会自动做几件事：

| 功能 | 实际用法 |
| --- | --- |
| 时间轴 | 按拍摄时间排开，回忆某次旅行直接按日期定位 |
| 地图查看 | 照片按拍摄地点落到地图上，去过哪里一眼可见 |
| 人脸识别 | 自动聚合同一个人的照片，找某人的照片不用翻 |
| 智能相册 | 按规则自动分组，新建后维护量为零 |

这些分析在服务端电脑上完成，手机端只是查看。

## 三、重复照片与整理习惯

照片库巨大、重复照片多的库，专业版提供照片去重功能；免费版可以先把备份跑起来，整理的活交给时间轴和智能相册。备份开始后别急着删手机里的原片，确认电脑端照片能正常打开、数量对得上，再清理手机空间。

## 四、备份之外还想干什么

想给朋友看某批照片，用文件分享生成带密码和有效期的链接就行，不用打包上传到别处。装好客户端之后从哪拿安装包、影音墙怎么建，都在 [NasCab 介绍站](https://nascab.wrwq.fun/) 有完整说明；出门在外想看家里的照片库，见[出门在外访问家里电脑](出门在外访问家里电脑.md)。
