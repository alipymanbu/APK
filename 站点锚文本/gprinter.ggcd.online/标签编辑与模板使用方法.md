# 标签编辑与模板使用方法

Gprinter 的日常使用基本围绕两件事：从模板库里挑一个现成版式，或者新建空白标签从零排版。这篇按实际使用的顺序，把模板选择、编辑器里的元素和批量打印讲清楚。

## 先从模板库挑一个底子

打开模板库，能看到按行业划分的分类：商品、餐饮、服装、珠宝、医药、资产、通信等。每个分类里是做好的版式——奶茶店的饮品价签（品名、规格、价格、条码一应俱全）、餐饮货架签、服装合格证等。

挑模板的思路很简单：找一个字段结构与自己的业务最接近的，进去只改文字内容就行。比如打 Asset（资产）标签，就用资产分类里的版式改编号和责任人；打奶茶价签，就在餐饮或商品分类里选带价格与条码字段的模板。

## 编辑器里能放什么

进入编辑器后，底部工具栏就是可添加的元素：

| 元素 | 用途 |
| --- | --- |
| 文字 | 品名、规格、价格等正文信息，字体大小与颜色可调 |
| 条形码 | 商品一维码，扫描枪可直接识别 |
| 二维码 | 放链接、批次信息或溯源内容 |
| 图像 | 店标、认证标志等小图 |
| 日期 | 自动取当天的生产/保质期，打批号省事 |
| 表格 | 规格参数类信息对齐排版 |
| 扫描 | 扫现有条码直接录入 |

排版逻辑与常见设计工具一致：选中元素拖到合适位置，改字号改颜色，层层叠放。服装合格证这类版面内容多的标签，建议先用表格把「品名 / 型号 / 色号 / 规格 / 等级」几行框住，再逐格填内容，打出来不容易歪。

## 批量打印与份数

同一版式要打多张时，在打印设置里把份数调高即可，打印机会连续出纸。仓库盘点、整批商品上新时，这个比一张一张点快得多。

打之前先确认两个参数与实际用纸一致：

- **纸张宽度**：58mm 纸型对应 48mm 打印宽度，其他幅宽同理；
- **标签间距**：间隙标签要让打印机找得到间隙定位，否则会越打越偏。

## 打出来不对怎么办

内容偏移、跳页多是尺寸或传感器模式设置与用纸不匹配；空白则常出在碳带安装与纸张类型上。逐条对号入座见[手机端打印常见问题排查](./手机端打印常见问题排查.md)；打印机还没连上的先看[蓝牙连接打印机步骤](./蓝牙连接打印机步骤.md)。

Gprinter 的界面截图、连接方式汇总与安装文件资源入口都整理在 [Gprinter 标签打印参考站](https://gprinter.ggcd.online/)。
