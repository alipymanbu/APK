# 安卓无损音乐社区怎么逛：分区、榜单与资源帖

> 想在手机上听无损音质的歌，很多人会撞见「音乐磁场」这个名字。它是一个聚焦无损音乐分享的在线社区，HiFiNi app 则是它的安卓客户端。本篇按真实的逛站动线讲：先逛哪个区、榜单怎么用、资源帖怎么读、哪些动作需要账号。
> **相关文档**：[音乐磁场安卓客户端入门.md](音乐磁场安卓客户端入门.md)

---

## 一、先认路：内容按语种与场景归档

社区把资源分成了清晰的板块，侧边菜单一次摊开，跨区切换不用返回首页：

| 分区 | 装什么 |
| --- | --- |
| 华语 / 日韩 / 欧美 | 按语种归档的正版转录与收藏资源 |
| Remix | 混音与改编版本 |
| 纯音乐 | 器乐、原声带、演奏专辑 |
| 异次元 | 动画、游戏相关的二次元向音乐 |
| 茶馆 / 百科 / 站务 | 闲聊、知识资料与社区公告 |

刚进去不必急着翻帖，先沿着自己常听的语种走一遍，摸清每个区的发帖密度与口味，之后找歌就有方向感了。

## 二、榜单是每天的开场白

首页顶部的切换标签给了五种时间窗：**最新、热门、月榜、周榜、日榜**。两种用法：

- 追新：开「最新」，社区当天的新转录、新分享都在这里冒头；
- 挖宝：翻「月榜」和「周榜」，被反复循环验证过的专辑更容易沉淀在这里。

日榜适合当每日 opener——花两三分钟扫一遍，比在曲库里漫无目的地刷高效得多。

## 三、资源帖：标题末尾的方括号就是门牌

这个社区的帖子标题自带编目规则，方括号里的标注直接告诉你音质规格：

- `[FLAC/MP3-320K]`：FLAC 是无损压缩格式，数据完整保留；MP3-320K 是高码率有损版本，体积小一些；
- `[Hi-Res DSD64 2.8MHz 1bit]`：母带级规格，面向有专业播放设备的听者；
- `[内嵌封面歌词]`：文件的元数据里带了封面与歌词，导入播放器后不用手动补。

点进帖子后，正文常随专辑信息与完整歌词，先试听确认是想要的版本，再决定收不收。部分资源的提取信息要回复帖子之后才能看到——留一句听后感，是这类社区的基本礼仪。

## 四、账号的边界：浏览免费登记，参与才注册

这是新手最常问的一条，边界其实很清楚：

| 动作 | 要不要账号 |
| --- | --- |
| 浏览分区、看榜单 | 不需要 |
| 搜索歌曲 | 不需要 |
| 在线试听 | 不需要 |
| 回复帖子（含查看部分提取信息） | 需要 |
| 每日签到、上传分享 | 需要 |

签到、回帖这类活跃行为会积累金币，金币与社区内的部分权限挂钩，具体规则以社区内的说明帖为准。也就是说：先当游客听几天，确认这里对口味，再注册不迟。

## 五、想把这套逛法搬到手机上

手机客户端把分区、榜单、资源帖和在线试听装进了同一个入口。分区与榜单的完整介绍、安装文件资源的获取入口，都整理在 [HiFiNi app](https://hifini-app.yoan.quest/) 介绍站里，装好后照着上面的动线走一遍就能上手。安装环节的注意事项，见[音乐磁场安卓客户端入门.md](音乐磁场安卓客户端入门.md)。
