# Kotatsu 介绍站（kotatsu.hfdk.space）

这里收录与 Kotatsu（安卓上的开源漫画阅读器）相关的说明文章。Kotatsu 的特点是图源目录随应用一起打包，不用像同类应用那样逐个装图源插件，装好就能搜书、追更、离线阅读；名字取自日语里的暖桌——窝在被炉里翻漫画的意象。
