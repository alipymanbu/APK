# 断网了怎么判断是谁的问题

> 刷不动视频、游戏掉线、网页转圈——问题到底出在运营商、路由器，还是你自己那台手机？这篇给一条十分钟内定位故障层的排查顺序。
> **相关文章**：[谁在蹭我的wifi怎么查.md](谁在蹭我的wifi怎么查.md) · [住酒店怎么检查隐藏摄像头.md](住酒店怎么检查隐藏摄像头.md)

## 一、先分清三层

网络问题无非三层：**外网断了（运营商故障）、外网没断但内网堵了（有人狂下东西或路由器抽风）、单台设备的问题**。逐层排除，别一上来就重启光猫瞎试。

第一步用 Fing 的测速功能（安卓安装入口见 [Fing 说明站](https://fing.fewa.skin/)）做个基准：下载、上传、延迟三个数字出来，问题在哪一层就清楚了大半。

| 现象 | 更可能的问题 |
| --- | --- |
| 测速完全连不出去，但手机显示 Wi-Fi 已连 | 外网出口或光猫 |
| 下载速度只有套餐标称的零头 | 线路质量或蹭网占带宽 |
| 测速正常但个别网页打不开 | DNS 解析 |
| 只有某一台设备异常 | 那台设备自身 |

## 二、测速要测得准

三个前提不做好，数字没有参考价值：

1. 手机尽量贴近路由器，信号弱本身就是变量；
2. 关掉后台正在下载、云备份、投屏的应用；
3. 连续测两三次取稳定值，单次波动很常见。

长期不达标就拿着几次测速截图去找运营商报障——有连续记录比口头说「慢」有用得多。

## 三、断网时按这个顺序查

1. **看设备清单还刷不刷得出来**。扫描工具能列出内网设备 → 内网是通的，问题在外网出口或 DNS；完全刷不出来 → 问题在路由器或光猫；
2. **ping 一下公网地址**。丢包严重或全部超时，出口有问题，先重启光猫；
3. **traceroute 看断在哪一跳**。卡在第一跳（自家网关）是路由器的问题；卡在运营商某一跳，把路由追踪截图交给客服；
4. **换个 DNS 试试**。域名解析不动也会表现成「网是通的但网页打不开」；
5. **端口扫描**排查内网主机有没有意外暴露的服务——这条偏安全检查，不是修断网的必经步骤。

这些工具（ping / traceroute / DNS 查询 / 端口扫描）在 Fing 的工具区里都有，免费版可用。注意只对**你有权管理的网络**使用，扫别人的网络属于越界。

## 四、查不出所以然的时候

九成「测出来不对劲」其实是内网侧的小问题：设备连错了网（连到邻居家的开放路由器）、路由器开了设备隔离、手机权限没授全。逐项排一遍，再不行就重启光猫和路由器——别笑，这招解决的故障比想象中多。
