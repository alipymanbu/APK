# ExaGear 安卓版下载与安装步骤

> 这篇讲把 ExaGear 装进安卓手机的完整流程：安装包分 APK 与 OBB 数据两部分，最容易出错的是数据包的摆放位置。
> **相关文档**：[手机玩红警添加游戏教程](手机玩红警添加游戏教程.md) · [目录](README.md)

---

## 装之前先确认两件事

- 你的手机是 ARM 芯片的安卓机即可，全程**不需要 Root**；
- 它只翻译 32 位的 x86 程序，64 位软件不在支持范围——装它就是为了跑老程序，先想好要跑什么再动手。

## 安装包含哪几部分

完整的安装文件资源由两个文件组成，缺一个都开不起来：

| 文件 | 作用 |
| --- | --- |
| APK 安装包 | 程序本体，负责界面与环境管理 |
| OBB 主数据包 | 运行环境所需的数据，文件名形如 `main.xxx.com.eltechs.ed.obb` |

两部分一起打包放进了网盘分享，获取入口整理在 [ExaGear 安卓版下载与安装指南](https://exagear.ggcd.uno/)，先把它们下载到手机存储里再继续往下走。

## 四步装完

1. **转存下载**：打开分享页，把安装文件资源保存到自己的网盘账号，再用网盘客户端下载 APK 与 OBB 两个文件到手机。
2. **装 APK**：在文件管理器里点开 APK；如果系统提示"禁止安装未知来源应用"，到设置里给这个文件管理器授予"安装未知应用"权限，回来重试。
3. **放 OBB**：把 OBB 文件移动到 `Android/obb/com.eltechs.ed/` 目录（路径不存在就手动逐级新建同名文件夹），文件名保持原样，不要改名、不要加 `.1` 之类的重复后缀。
4. **开应用**：安装与数据都就位后点开 ExaGear，第一次进入会让你创建容器（Container），建好就到了环境管理界面。

## 装完还是打不开？

十有八九是 OBB 的位置不对。回到第 3 步逐项核对：目录是否为 `Android/obb/com.eltechs.ed/`、文件名是否与下载时一致。装好之后该往里面放游戏、怎么进桌面，接着看[手机玩红警添加游戏教程](手机玩红警添加游戏教程.md)。
