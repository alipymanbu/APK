# 手机玩红警添加游戏教程

> 装好 ExaGear 只是第一步，这篇讲怎么把自备的游戏文件摆进去、从哪里启动，以及红警、三国群英传这类老游戏在手机上的实际体验。

## 游戏文件放哪里

这是中文玩家圈里流传最广的一套摆法，就一个关键词：**ExaGear 文件夹**。

1. 在手机存储根目录新建一个文件夹，命名为 `ExaGear`；
2. 把你自备的游戏文件夹整个复制进去（保持游戏内部目录结构原样，别打散文件）；
3. 打开 ExaGear，在环境管理里启动容器，进入桌面；
4. 从桌面或开始菜单里找到游戏主程序点开，走的就是转译运行。

进不去桌面、提示缺组件的，多半是容器里缺字体或运行库，在"扩展包"里按需勾选补上即可。

## 这类玩法适合什么游戏

转译层方案对 32 位的小体量程序最友好，玩家圈里跑得最多的就是这些：

| 游戏 | 手机上的体验 |
| --- | --- |
| 红色警戒 | 触屏点选部队、框选建造，老玩家上手很快 |
| 三国群英传 | 回合节奏慢，正好适合碎片时间来一局 |
| 合金弹头 | 横版操作考验按键布局，建议接手柄 |
| 魔法门 | 纯点按探索类，触屏几乎无损 |

手柄不是必需品，但动作类的体验会好一截；玩法与入口的完整说明也可以翻 [ExaGear 手机玩 PC 游戏指南](https://exagear.ggcd.uno/)，那边连界面截图一起讲了。

## 点了游戏没反应？

按顺序排查三处：

- **游戏位数**：只有 32 位 x86 版本能跑，64 位版或重制版直接不支持；
- **文件夹位置**：确认游戏文件夹在 `ExaGear` 文件夹里面，而不是散在根目录；
- **容器参数**：机型偏老的话，把容器设置里的环境参数调低一档再启动。

以上都试过还不行，回[安卓版下载与安装步骤](安卓版下载与安装步骤.md)核对 OBB 数据包是否放对位置——那一步出错，整个环境都起不来。
