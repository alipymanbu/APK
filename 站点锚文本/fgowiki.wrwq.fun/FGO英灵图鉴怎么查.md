# FGO英灵图鉴怎么查

> 这篇讲怎么在手机上快速查 FGO 的英灵资料：用什么工具、筛选条件怎么叠、详情页各栏看什么。

## 一、用哪个工具查

FGO 的从者数据量很大，靠记忆和攻略帖零散翻效率很低，通常用一个 Wiki 类资料应用随身查。这里以安卓端的 fgowiki 为例（介绍与获取入口见 [fgowiki 掌上资料库](https://fgowiki.wrwq.fun/)），它的英灵图鉴覆盖了从一星到五星的全部从者，数据跟着玩家共同编写的中文 Wiki 更新。

## 二、怎么快速找到目标从者

打开图鉴后，搜索和筛选可以叠加使用：

1. **搜索框直查**：输入从者名字的一部分就能模糊匹配，记不全名字时很有用。
2. **星级筛选**：先按 4 星 / 5 星收窄，比逐页翻快得多。
3. **职阶筛选**：Saber、Archer、Lancer 等职阶分栏，找打手时先按职阶过一遍。
4. **指令卡配色**：按 Q 卡 / A 卡 / B 卡的配卡分布筛，组蓝卡队或红卡队时按这个找成员。
5. **属性与阵营**：混沌、秩序、中立这类标签，做限定属性的任务时用来凑数。

条件选完下滑就是结果，点重置可清空全部条件。

## 三、详情页各栏看什么

点进一位从者后，重点看这几块：

| 栏目 | 看什么 |
| --- | --- |
| 基础数值 | 各灵基阶段的面板与成长曲线 |
| 配卡 | 三色指令卡分布，决定主要打法 |
| 技能 | 三个技能的效果与升级变化，含强化本后的形态 |
| 宝具 | 类型（单体 / 群体）、色卡与倍率、附带效果 |
| 灵基再临 / 灵衣 | 各阶段立绘与解锁材料 |
| 素材需求 | 升级与技能练满各要多少材料 |

组队前的习惯动作：先看配卡与宝具色卡，再看技能有没有自充能或增伤，最后翻素材需求估一下养成成本，再决定练不练。
