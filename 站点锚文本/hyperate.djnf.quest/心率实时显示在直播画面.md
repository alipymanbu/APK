# 心率实时显示在直播画面

直播里把真实心跳挂上画面，已经成了恐怖游戏、竞技对局和体能挑战类内容的标准配置：观众看着 BPM 数字随剧情起伏，主播的紧张和激动无需多言。本文按最常见的三类做法，把这条链路讲清楚。

## 为什么要用心率叠层

- **内容张力直接拉满**：数字一飙，弹幕自然就热闹了，比任何口头描述都有说服力。
- **切片素材现成**：心跳飙升的瞬间往往就是高光时刻，回看录像时很好定位。
- **门槛极低**：一条蓝牙心率带加一部手机就能跑，不需要额外采集卡或硬件。

## 三种常见做法

1. **浏览器源叠层**：心率服务提供一个网页地址，贴进 OBS 的浏览器源里，透明底的心率组件就浮在游戏画面上。这是目前最省事、兼容性最好的方式。
2. **窗口捕获**：手机或另一块屏幕上开着大字号表盘，直接作为窗口源进场景。布置简单，但占画面空间，样式也吃屏幕本身的观感。
3. **插件与桥接工具**：部分工具提供专用插件或桥接页面，能以更低的延迟把数据送进直播软件，适合对同步精度要求高的主播。

## 心率数据从哪里来

胸带类设备走心电测量，剧烈晃动时数字依然稳；手表类设备方便但光电测量在跑步、跳跃时容易丢拍。公开教程普遍建议以直播为主用途的用户选蓝牙胸带，手表作为轻量替代。设备只要支持标准低功耗蓝牙（BLE）心率广播，大多数心率工具都能直接识别。

## 从连接到上屏的完整流程

以安卓端为例：安装心率应用 → 授予蓝牙与附近设备权限 → 搜索并连接心率带 → 应用给出分享链接或短 ID → 链接贴进 OBS 浏览器源 → 叠层上线。整个过程中手机只负责采集和中转，数据的实时性由服务端转发保证，公开资料口径的端到端延迟可以压到 200 毫秒以内。具体的连接步骤与界面，可以看[HypeRate 实时心率介绍站](https://hyperate.djnf.quest/)整理的三站数据链说明。
