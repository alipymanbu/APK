# Voscreen 听力训练方法与难度选择

> 本篇讲 Voscreen（一句英语）的训练编排：怎么摸底定档位、语法专项怎么开、生词本怎么配合，给一套能直接照抄的每天 20 分钟排法。

## 一、先摸底，再定档

素材按难度分五级（beginner 到 advanced），并按句长细分——句子越长，结构通常越复杂。上手别纠结选哪档：从中间档刷 20 题摸底，基本不卡就升一档，错一半就退一档。App 内的设置路径（第三方教程口径）：登录后进首页的「定制学」入口，在视频播放页点右上角「更多」即可调整难度。

## 二、语法听不出来，就开专项

语法书看得懂、耳朵听不出来，是最常见的坎——he's / he is、can't / can 这类靠结构判断的题，光靠眼睛没用。走 voStructure 语法专项：选定一个语法点（一般现在时、时态、连词、短语动词、关系从句、名词性从句等），系统只推含这个结构的片段，让耳朵在同一种结构上反复过。

配套节奏建议每周挑 1~2 个语法点做专项，练完就换，别贪多。

## 三、字幕、提示与生词本的配合

| 工具 | 建议用法 |
| --- | --- |
| 字幕 | 先盲听两遍，实在听不出再开字幕核对 |
| 提示 | 给的是同义替换，不等于答案，卡住再用 |
| 生词本 | 点单词即查即听发音，一键收进本子，隔天集中复习 |

专项练完把生词收进生词本、第二天先复习再开新题，比只顾往前刷题留得牢。

## 四、每天练多少、怎么排

给一个可直接照抄的排法：

1. 每天固定量：官方建议每天至少 20 分钟，拆成几次都行，连续坚持比单次时长重要；
2. 每周 1~2 个语法点专项；
3. 备考方向（四级、商务、求职）按场景分类对准刷；
4. 中途断了也不用担心，积分与记录不受影响。
