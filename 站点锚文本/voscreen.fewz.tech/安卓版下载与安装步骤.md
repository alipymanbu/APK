# Voscreen 安卓版下载与安装步骤

> 本篇讲 Voscreen（一句英语）安卓安装包怎么拿到手、装进手机的四步流程，以及安装被拦、桌面无图标这些常见坎的处理。
> **相关文档**：[刷视频练听力是什么体验](刷视频练听力是什么体验.md) · [听力训练方法与难度选择](听力训练方法与难度选择.md)

## 一、装之前先对一下条件

- **系统**：安卓 5.2 及以上（安装包信息标注）；
- **空间**：安装包约 175M，建议再留出等量以上的剩余空间，装完占用更大；
- **来源**：安装包经夸克网盘分发，需要允许「安装未知来源应用」。

安装包对应版本 3.5.2。应用市场里可能看到更新的版本号，装哪一版自己定；本文的版本与体积以这份安装包为准。

## 二、四步装好

1. **打开资源页**：进入 [voscreen 介绍站的下载页](https://voscreen.fewz.tech/download.html)，点「获取安装文件资源」打开夸克网盘分享；
2. **转存**：登录夸克账号，把安装包转存到自己的网盘（电脑上操作同理）；
3. **下载 APK**：在夸克网盘 App 或网页版对安装包选「下载」，得到 .apk 文件；
4. **安装**：点开 .apk，系统提示禁止安装未知来源应用时，允许来自当前来源的安装（安卓 8 及以上按来源授权，装完可再关掉），完成后点「打开」。

首次打开先进登录页，可能弹出存储权限申请——用于缓存视频素材，按需授予即可。注册、登录与进度同步的问题不在本篇展开。

## 三、最常见的三个坎

| 现象 | 处理 |
| --- | --- |
| 点安装被拦 | 在弹窗里选「仍要安装 / 允许来自此来源」；被安全软件拦的，去拦截记录里放行一次再装 |
| 桌面没有图标 | 多是安装被安全软件静默拦截，放行后重装；或安装本身没完成，重走一遍 |
| 空间不足 / 装完闪退 | 至少留 1~2GB 剩余空间；闪退先重启手机，仍复现就卸载重装当前版本 |

## 四、装好之后

主界面就是刷视频答题的训练流。建议先读 [刷视频练听力是什么体验](刷视频练听力是什么体验.md) 了解玩法，再按 [听力训练方法与难度选择](听力训练方法与难度选择.md) 里「中间档刷 20 题摸底」的办法定档位开练。界面截图与功能清单也可以在 [voscreen 一句英语站](https://voscreen.fewz.tech/) 对照看。
