# 远程桌面连接失败排查

手机连电脑桌面，报错比想象中有规律：0x104 是「找不到这台电脑」，0x204 是「找到了但连不进去」，凭据报错则是「人认出来了、密码不对」。本篇按这个顺序排一遍。还没连上过的先看[手机远程连接电脑桌面方法](手机远程连接电脑桌面方法.md)把两端配好，再回来对号入座。

---

## 先分清三种报错

| 报错 | 含义 | 大方向 |
| --- | --- | --- |
| 0x104 | 客户端找不到远程电脑 | 地址、网络、发现问题 |
| 0x204 | 找得到但建立不了连接 | 端口、防火墙、网络环境 |
| 用户名或密码不对 | 认证失败 | 凭据格式与权限 |

## 0x104：找不到电脑

1. **核对地址**：电脑换了 Wi-Fi 或重启路由后 IP 会变，回电脑上用 `ipconfig` 重新看一眼 IPv4 地址，手机端改成当前值；或者干脆用「设置 → 系统 → 关于」里的完整计算机名。
2. **两端先同网验证**：手机和电脑连同一个 Wi-Fi 再试一次。同网能连、跨网不能连，说明客户端配置没问题，是外网访问的链路问题（路由器端口转发或虚拟专用网络，属进阶配置）。
3. **电脑端的「网络发现」开着**：设置 → 网络和 Internet → 高级网络设置 → 高级共享设置，当前配置文件下把网络发现打开。
4. **手机端排除干扰**：手机上开着虚拟专用网络、网络加速类应用时先关掉再试——这类应用改路由，是移动端 0x104 的常见肇因。

## 0x204：找得到但连不进

1. **防火墙放行远程桌面**：Windows 防火墙 → 允许应用通过防火墙，确认「远程桌面」在专用和公用网络都勾上了（默认端口 3389）。
2. **电脑端远程桌面开关确实开着**：设置 → 系统 → 远程桌面，开关为开、NLA 保持开启。
3. **换网络环境交叉验证**：用另一台手机开热点，电脑和手机都连这个热点再试——能连，说明原网络环境（公司局域网、校园网常见）拦了 3389 端口。
4. **电脑端也排查一遍网络栈**：装过虚拟网卡类软件、改过 hosts 的电脑，可以试试重置网络（`netsh winsock reset` 后重启电脑）。

## 凭据报错：用户名或密码不对

- 微软帐户登录的电脑：用户名填**完整邮箱**，密码是帐户密码；**PIN 不行**，系统 PIN 和帐户密码是两回事。
- 本地帐户：填电脑上那个帐户的用户名和密码，注意大小写。
- 帐户权限：这个帐户得在电脑的「远程桌面用户」组里（管理员默认在）。
- 电脑名输对了吗：微软帐户网页上显示的设备名不是计算机名，别混用。

## 排完还连不上

按顺序做一轮全量复核：电脑重启 → 确认远程桌面开着 → 手机重新添加连接（旧条目删掉重加，地址重新填）→ 换热点验证。多数顽固情况在「换热点」这一步就分出了是设备问题还是网络问题。连上之后的操作问题，去看[安卓手机远程操作电脑的手势技巧](安卓手机远程操作电脑的手势技巧.md)；想了解这个客户端本身，去 [windows 安卓版](https://windows.ggcd.uno/) 介绍页。
