# 手机远程连接电脑桌面方法

本篇讲怎么用安卓手机连上一台 Windows 电脑的桌面：先在电脑上把远程桌面开起来，再到手机端把这台电脑添加进去。相关文档：连接失败时的处理见[远程桌面连接失败排查](远程桌面连接失败排查.md)，连上之后的触控操作见[安卓手机远程操作电脑的手势技巧](安卓手机远程操作电脑的手势技巧.md)。

---

## 先弄清两端的角色

手机远程连接电脑，两端各干一件事：

- **被连的电脑**是「主机」：它需要开着机、联网，并把远程桌面功能打开。这一端必须是 Windows 专业版——家庭版没有远程桌面主机功能，这也是很多人配了半天连不上的第一个原因。
- **手机**是「客户端」：装一个远程桌面客户端（也就是 [windows 安卓版](https://windows.ggcd.uno/) 这个应用），把电脑的地址填进去就能连。

两端不用在同一网络里，但首次配置时让手机和电脑连同一个 Wi-Fi，最容易排除变量。

## 第一步：在电脑上开启远程桌面

1. 打开 设置 → 系统 → 远程桌面，把开关打开并确认。
2. 「要求设备使用网络级别身份验证（NLA）」保持开启，这是更安全的默认方式。
3. 记下「电脑名称」：在 设置 → 系统 → 关于 页面里显示的完整计算机名，手机端填的就是它（填 IP 地址也可以，但 IP 会随网络变化，电脑名更稳）。

## 第二步：在手机端添加电脑连接

1. 打开客户端，点「+」号，选择「电脑连接（PC 连接）」。
2. 电脑名称一栏填刚才记下的计算机名或 IP 地址；如果改过默认端口，写成 `10.0.0.1:3389` 这样的形式。
3. 用户名可以先选「每次输入」，连的时候再填；也可以先添加用户帐户存起来，之后连一下就进。
4. 保存后回到「设备」标签，点这条连接，输入密码，等画面出来就完成了。

## 密码填什么，最容易卡住的地方

- 电脑用**微软帐户**登录的：用户名填完整邮箱，密码填这个帐户的密码——**PIN 码不能用来做远程登录**，这点踩的人最多。
- 电脑用**本地帐户**登录的：填本地帐户的用户名和密码。
- 用来登录的帐户得有远程登录权限：管理员帐户默认有；普通帐户要把电脑设置里的「远程桌面用户」组加上它。

## 连上之后

手机屏幕上出现的就是电脑桌面，应用、文件、浏览器都是电脑里那份。首次连入建议先把显示分辨率调到顺手的大小，常用的几台电脑可以收藏起来，以后从收藏列表一点就进。如果这一步报错，翻一下[远程桌面连接失败排查](远程桌面连接失败排查.md)；想让手指用起来更像鼠标，看[安卓手机远程操作电脑的手势技巧](安卓手机远程操作电脑的手势技巧.md)。
