# 安卓手机远程操作电脑的手势技巧

手机连上电脑桌面只是开始，真正决定顺不顺手的是手指怎么用：点、按、拖、缩放在远程会话里各有对应的动作，会话工具条里还有两种鼠标模式可切。连接与排查的前置内容见[手机远程连接电脑桌面方法](手机远程连接电脑桌面方法.md)和[远程桌面连接失败排查](远程桌面连接失败排查.md)。

---

## 先选鼠标模式

远程会话里屏幕顶部有工具条，两种鼠标模式任选：

- **直接触控**：手指按在哪，就等于在哪个位置点击鼠标，屏幕上不出现指针。连到 Windows 10 及以上的电脑时，原生触控与多点触控手势都能直接用，最像「摸电脑」。
- **鼠标指针**：屏幕上显示一枚指针，手指按住移动时指针跟着走。需要悬停提示、精确右键、在表格里框选区域时，这个模式更稳。

两种模式随时切换，按手头的活儿选，不用固定一种。

## 手势对照

| 想做的操作 | 手上的动作 |
| --- | --- |
| 左键单击 | 单指轻点 |
| 右键单击 | 直接触控：单指按住后松开；指针模式：双指轻点 |
| 拖动（如拖文件、框选） | 连点两下并按住，再拖动 |
| 缩放画面 | 双指捏合缩小、张开放大 |
| 滚动长页面 | 直接触控模式里双指滑动（对应滚轮） |

习惯建议：看网页、翻文件夹用直接触控；改表格、用设计软件切到鼠标指针。缩放画面不会改变远程桌面的分辨率，只是放大看局部，松手即回。

## 会话工具条与快捷键

- 会话进行中，屏幕顶部的**连接栏**可以收起会话、切回本机、断开连接，误触到屏幕边缘时别慌，先找它。
- 外接键盘（蓝牙或 Type-C）后有几个关键映射：`Ctrl+Alt+End` 相当于远程电脑上的 `Ctrl+Alt+Delete`（锁屏、改密码都用它）；`Alt+Page Up` / `Alt+Page Down` 相当于 `Alt+Tab` 切窗口；日常的 `Ctrl+C / Ctrl+V` 原样可用。
- 手机本机与远程会话的剪贴板是打通的：电脑上复制一段文字，手机上能直接粘出来，反过来也一样。

## 常见小状况

- **画面字太小**：先双指放大看局部；长期在手机上用，把远程会话的显示分辨率调低一档会更清楚。
- **点了没反应**：确认是不是在「直接触控」里用了双指右键（那是滚轮手势），换按住后松开试试。
- **键盘弹不出来**：在会话工具条里找键盘图标，点它呼出输入法。
