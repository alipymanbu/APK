# 在安卓手机上从安装到开机一台「旧电脑」

> 本篇讲什么：把 bochs 安卓移植版（v2.6.11，安装包约 12.8 MB）装进手机、挂上系统镜像、按 Start 开机的完整流程，以及开机后手指、音量键怎么当鼠标用。
> 相关文档：镜像来源与可跑系统见 [它能跑哪些系统，镜像从哪里来](能跑哪些系统与镜像从哪来.md)。

---

## 先准备两样东西

- **模拟器本体**：安卓端的 bochs 由 Lyubomyr Lisen 移植维护，安装包只有十几 MB，老机型也能装。安装文件资源的获取入口整理在 [bochs 模拟器介绍站](https://bochs.ggcd.uno/)里，按页面指引转存下载即可。
- **一台「电脑」的硬盘**：也就是系统磁盘镜像。没有现成的也不用愁，应用里自带几个小系统的下载入口（下一节细说）。

## 安装四步

1. **装 APK**：首次安装系统会提示「未知来源应用」，按指引允许当前来源安装即可。
2. **认识三个标签页**：打开应用后是 `存储` / `配置` / `其它` 三页——存储页挂载软盘与 ATA 磁盘镜像，配置页调 CPU 类型、芯片组、内存、VGA 显卡与声卡网卡，其它页管 ROM 镜像与时钟同步。
3. **挂镜像**：在存储页勾选 `ata0-master`，选择镜像文件；自备镜像改名为 `c.img` 放进 SD 卡根目录的 `SDL` 文件夹也会被自动识别。
4. **开机**：回主界面按 `Start`，先看到一串 BIOS 自检文本滚动，然后就是老系统熟悉的启动画面。首次开机请耐心——这是纯软件逐条指令模拟，启动以分钟计是正常现象。

## 开机之后怎么操作

模拟出来的是一台带鼠标的 PC，操作逻辑和普通安卓应用不一样：

| 想做的事 | 实际操作 |
| --- | --- |
| 移动鼠标光标 | 手指在屏幕上滑动（相当于笔记本触控板） |
| 鼠标左键 | 音量上键 |
| 鼠标右键 | 音量下键 |
| 往「电脑」里带文件 | SD 卡根目录建 `HDD` 文件夹，重启系统后它就是一个盘符 |

支持 OTG 的机型可以直接外接 USB 键盘鼠标，平板上配合支架使用，体验已经非常接近一台真电脑。

## 一条务实的预期

这套玩法图的是「整机能开、老系统能摸到」，不是性能。选精简版镜像、把虚拟机内存调到手机可用内存的一半左右、关掉用不到的外设，流畅度会明显改善。
