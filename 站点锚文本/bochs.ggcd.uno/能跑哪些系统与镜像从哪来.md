# 它能跑哪些系统，镜像从哪里来

> 本篇讲什么：bochs 的纯软件整机模拟路线决定了它能跑什么——从 DOS、Windows 95/98/XP 到各种迷你 Linux；以及三条获取系统镜像的路子。
> 相关文档：安装与开机流程见 [在安卓手机上从安装到开机一台「旧电脑」](手机上从安装到开机一台旧电脑.md)。

---

## 为什么它「不挑食」

bochs 不依赖硬件虚拟化，而是把 386 到 x86-64 的指令集、i440fx 芯片组、Cirrus VGA 显卡、NE2000 网卡、声卡、串并口整套 PC 硬件用软件仿真出来。对客户机系统来说，它就是一台看得见摸得着的「真电脑」——所以那些年代久远、只在老硬件上肯启动的系统，在这里照样认账。

代价也来自同一条路线：速度按每秒指令数（IPS）计算，跑得慢是路线自带的属性，换 faster 的手机改善有限，选对镜像才是关键。

## 三条镜像路子

**1. 应用内直接下载**

安卓端内置「下载磁盘映像」入口，开箱能拉：

- muLinux（约 34 MB）
- FreeDOS（约 114 MB）
- Tiny Core Linux（约 123 MB）
- Puppy Linux（约 690 MB）

想先验证链路是否跑通，选个几十 MB 的迷你系统最省事，下载完直接 Start 开机。

**2. 社区做好的镜像**

Bochs 吧、各类玩机论坛里常年流传着网友整理好的 Win95/98/XP 精简镜像，很多还顺手调好了内存与 IPS 参数。下载后改名为 `c.img` 放进 SD 卡根目录的 `SDL` 文件夹即可。

**3. 自己动手做盘**

桌面版的 bochs 自带磁盘镜像创建工具，配合虚拟光驱把安装光盘装进一块空白 `c.img`，再拷到手机上——想定制分区大小、预装软件，这是最自由的路子。

## 系统选型建议

| 目标 | 建议 |
| --- | --- |
| 只想看看能不能开机 | FreeDOS / muLinux 这类迷你系统 |
| 怀旧老游戏、扫雷画图 | Win98 精简镜像，流程顺畅 |
| 完整的老 Windows 体验 | XP 精简镜像（内存给足、耐心等开机） |
| 学 Linux / 折腾实验 | Tiny Core、Puppy Linux |

镜像选对了，剩下的就是按 [在安卓手机上从安装到开机一台「旧电脑」](手机上从安装到开机一台旧电脑.md) 的流程开机。模拟器的安装文件与更多介绍，都在 [bochs 模拟器介绍站](https://bochs.ggcd.uno/)。
