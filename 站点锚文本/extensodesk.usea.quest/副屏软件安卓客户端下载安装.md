# 副屏软件安卓客户端下载安装

决定把平板变成电脑副屏之后，装机环节通常卡在两件事上：安卓客户端从哪里拿、APK 装不上怎么处理。这篇按顺序把 ExtensoDesk 安卓端的安装流程过一遍，Windows 服务端的部分也一并交代。

## 装之前先分清两个程序

这套工具是两端配合使用的，要装两份：

- **Windows 服务端**装在电脑上，负责把画面推给平板；
- **安卓客户端**装在平板或手机上，负责接收画面、回传触摸与手写笔输入。

电脑端要求 Windows 10 2004 及以上；平板端 Android 5.0 以上即可运行，1.4.3 是目前安卓端的较新版本。安装前顺手把电脑的显卡驱动更新一下，驱动过旧是连上后画面异常的常见原因。

## 安卓端的安装四步

1. **拿安装文件**：通过夸克网盘的分享入口把文件转存到自己网盘，再从平板端取回。转存到本人名下比直接在分享页点下载更稳，分享链接日后失效也不影响已转存的文件。
2. **允许未知来源**：平板上点开 APK 时，系统会提示"禁止安装未知来源应用"。在弹出的设置页里，允许所用网盘 App 或浏览器安装应用，再回到确认页继续。
3. **完成安装并打开**：装完桌面出现图标，打开后第一屏是设备列表，此时会自动搜索局域网内的电脑端。
4. **配对电脑端**：电脑侧装好 Windows 服务端并放行防火墙后，设备列表里就会出现电脑的条目；插 USB 线的话，顶部直接给出"USB 有线连接"入口。

## 装不上、搜不到，对症处理

- **点安装没反应**：多半是未知来源权限没给到位。到"设置 → 应用管理 → 网盘 App → 安装未知应用"里确认开关已打开；部分定制系统还有纯净模式需要退出。
- **打开 App 搜不到电脑**：先确认服务端在运行，再确认防火墙放行过，最后确认两端在同一局域网。急用直接插 USB 线验证。
- **转存受限或速度慢**：网盘侧的容量与速度规则以平台为准，转存到自己账号后再下载是最稳妥的路径。
