# 平板当电脑副屏怎么连接

手头有一台安卓平板，想给 Windows 电脑加一块不要钱的屏幕，最常见的第一个问题就是：两台设备到底怎么"握手"。这篇文章把 ExtensoDesk 的两条连接路径讲清楚，顺带说说连接失败时先查哪里。

## 先把两端都准备好

这是一套两端配合的软件：电脑一侧要装 Windows 服务端（要求 Windows 10 2004 及以上版本），平板一侧装安卓客户端（Android 5.0 以上即可运行）。任何一端缺位，另一端都搜不到"人"。

装好之后打开平板端的 App，第一屏是设备列表。它会自动扫描同一局域网内的服务端，扫描结果直接列在页面上；如果插了 USB 数据线，列表顶部会固定显示一个"USB 有线连接"入口，不需要搜索。

## 路径一：WiFi 无线连接

无线连法适合随手扩展桌面的场景——平板放在桌上当收件箱屏、文档屏，不占线缆。

要点有三个：

1. 两端必须挂在同一个路由器网络下，跨网段搜不到；
2. 电脑端服务端首次运行时，系统防火墙弹窗要选择放行，这一步被拦是最常见的"搜不到"原因；
3. 连接前 App 会弹一个横竖屏选择提示，选完如果画面显示被拉伸或缩放异常，去电脑端的显示设置里把对应屏幕也设成相同方向即可对齐。

## 路径二：USB 有线连接

拿一根数据线把平板插到电脑上，设备列表里点"USB 有线连接"就能走有线通道。有线的好处很直接：延迟更低、画面更稳，还不受 WiFi 波动影响。经常在平板上作画、玩电脑游戏的用户，建议默认走这档。

一个容易被忽略的细节是"USB 转 WiFi"开关：开启后，把数据线拔掉，两端会自动切到无线通道重连，会议中途换姿势、抱着平板换房间都不用重新配对。

## 连不上时按这个顺序排查

- 电脑端服务端是否在运行（托盘里看不到图标就是没开）；
- 防火墙是否放行过该程序；
- 两端是否在同一局域网；
- 都没问题还连不上，换 USB 线直连验证一次，能连上说明问题出在网络环境。

连接建立之后，扩展屏与镜像两种模式可以在两端切换着用。更多设置层面的细节——比如触摸模式怎么选、画质怎么调——可以看这篇 [平板当数位板用手写笔压感.md](平板当数位板用手写笔压感.md)；如果是第一次装，先读 [副屏软件安卓客户端下载安装.md](副屏软件安卓客户端下载安装.md)。
