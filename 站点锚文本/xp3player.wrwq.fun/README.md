# XP3Player 相关整理目录

> 这里收着两篇与 XP3Player 有关的短整理：一篇讲吉里吉里（Kirikiri）引擎游戏在手机上怎么跑起来，一篇讲 `.xp3` 封包文件本身该怎么对待。

## 目录内容

- [吉里吉里模拟器手机版怎么用.md](吉里吉里模拟器手机版怎么用.md) —— 认引擎、判断游戏对不对口、装好后的头两步与常见故障；
- [xp3文件怎么打开.md](xp3文件怎么打开.md) —— 认封包、手机上直接运行的路径、点开报错的三种情况。

想直接了解这个模拟器的功能与安装文件资源的获取方式，见 [XP3Player](https://xp3player.wrwq.fun/)。
