# 吉里吉里模拟器手机版怎么用：从认引擎到点开游戏

> 想在安卓手机上玩 Kirikiri（吉里吉里 / Krkr）引擎的游戏，先弄清这一族运行器是什么关系、怎么判断手里的游戏对不对口，再动手安装。
> **相关文档**：[xp3文件怎么打开.md](xp3文件怎么打开.md)

---

## 一、吉里吉里是什么引擎

Kirikiri（吉里吉里，圈内常写作 Krkr）是日本开发者 W.Dee 的开源游戏引擎，同人圈里大量视觉小说用它开发。这类游戏的资源不散放，而是打成一个 `.xp3` 封包——打开游戏文件夹，最显眼的那个 `data.xp3` 就是主角。

所以「吉里吉里模拟器」这个词组里，真正要模拟的不是某台游戏机，而是这套引擎的运行环境。

## 二、手机上的运行思路

安卓上跑这类游戏，走的是移植运行器的路子：把 Kirikiri2 / KirikiriZ 的运行环境搬进手机，让它直接读手机存储里的游戏文件夹。

社区里 XP3Player、Kirikiroid2、吉里吉里2模拟器、KRKR模拟器这些名字经常混着出现——它们指的是同一族应用，只是分发渠道和整合包的叫法不同。名字认不准没关系，装好后打开是「黑底条纹的文件列表」、菜单里有「转换/解密XP3封包」这类选项，就是它了。

## 三、拿到游戏先花 30 秒判断

不是所有手机游戏资源都能塞给它跑，打开文件夹扫一眼就能下结论：

| 文件夹里有什么 | 结论 |
| --- | --- |
| 有 `.xp3` 文件（尤其 `data.xp3`） | 基本能跑 |
| 资源方标了 KrKr / 吉里吉里 / Kirikiroid2 版 | 明确能跑，整合包通常连补丁都配好了 |
| 只有 `.exe`、没有 `.xp3` | 少数作品封包内嵌在主程序里，可以直接点 `.exe` 试一把 |
| 是 `.rpa`、Unity 数据文件、RPG Maker 资源结构 | 跑不了，换模拟器也没用 |

判断依据和「装好之后怎么走」整条流程，在 [XP3Player](https://xp3player.wrwq.fun/) 的介绍页里按「判、导、拧」铺成了一条线，装之前扫一遍能省不少折腾。

## 四、装好后的头两件事

1. **给足文件权限**：首次打开会请求文件访问，选「允许管理所有文件」。不给权限，应用里就是一块空列表。
2. **把游戏完整解压**：是整个文件夹一起解压——封包、补丁、资源目录一个不少。只拷一个 `data.xp3` 进手机是新手最常见的翻车点。

之后浏览到目录、点 `data.xp3`，等加载结束就该看到标题画面了。

## 五、第一晚最常撞上的三件事

- **一打开游戏就闪退**：全局设置里把渲染器切回软件渲染，OpenGL 模式的兼容面不如它；
- **文字缺半截、显示方块**：缺中文字库，往游戏目录放一个字体文件改名 `default.ttf`；
- **点 `data.xp3` 直接报错**：大概率是封包加密，需要对应的 `xp3filter.tjs` 放进游戏目录——这个文件从你获取游戏的地方一并拿，与游戏一一对应。

具体每个旋钮在哪个菜单里，介绍页与相关文档里都有对位说明。
