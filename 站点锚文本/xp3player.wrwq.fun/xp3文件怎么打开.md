# xp3文件怎么打开：手机与电脑两种场景分开说

> `.xp3` 不是普通压缩包，而是 Kirikiri（吉里吉里）引擎的游戏封包。能不能「打开」，取决于你想在什么设备上跑这个游戏——手机上是直接运行，不是解开它。
> **相关文档**：[吉里吉里模拟器手机版怎么用.md](吉里吉里模拟器手机版怎么用.md)

---

## 一、先认清楚这是什么文件

Kirikiri 引擎的游戏会把剧本、立绘、音频、脚本统统打进一个 `.xp3` 封包，游戏目录里最常见的入口叫 `data.xp3`。所以双击它的正确预期不是「解压出图片」，而是「游戏从它启动」。

与之同目录的还常有这几类文件，见到就能确认这是个 Kirikiri 游戏：

| 文件 | 角色 |
| --- | --- |
| `data.xp3` | 主封包，启动入口 |
| `patch.xp3` | 补丁包，汉化或修正常走这里 |
| `xp3filter.tjs` | 加密封包的解密脚本，与游戏一一对应 |
| `savedata/` | 存档目录 |

## 二、手机上：不解开，直接点开

安卓上不需要、也不建议先把封包拆开。做法是装一个认 Kirikiri 封包的运行器，让它直接读：

1. 游戏压缩包**完整解压**成文件夹，原样拷进手机存储；
2. 装好运行器并给「允许管理所有文件」权限——比如 [XP3Player](https://xp3player.wrwq.fun/)，打开就是文件列表；
3. 浏览到游戏目录，点 `data.xp3`，等加载完就进游戏了。

整个过程里封包保持原样，游戏存档也写在游戏自己的目录里，整体备份整个文件夹就能搬走。

## 三、点开报错，分三种情况

- **提示错误且这游戏比较冷门**：先怀疑封包加密。把与游戏对应的 `xp3filter.tjs` 放进游戏目录（与 `data.xp3` 同级）再启动。这个脚本从你获取游戏的地方随包拿，拿不到就没有正常途径启动这个游戏——这是引擎能力的边界，换设置解决不了。
- **弹出提示后直接退出**：大头是游戏文件在下载、复制、解压哪一步坏了，重新完整获取一遍再试。
- **提示脚本或插件不兼容**：游戏用到了运行器没实现的扩展插件，换版本也改变不了结论，只能放下这一个游戏。

## 四、电脑上呢

PC 上这类游戏本来就是 Kirikiri 引擎原生运行的，双击游戏目录里的启动程序即可，不需要手动处理封包。手动拆包只在改字幕、查素材这类折腾场景才有意义，与「玩游戏」无关，这里不展开。
