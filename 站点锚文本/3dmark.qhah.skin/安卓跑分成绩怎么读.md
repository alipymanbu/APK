# 安卓跑分成绩怎么读：分数、帧率与百分位各看什么

很多人跑完分只记住一个总分，其实一张成绩页里的信息远不止它。以 3DMark 这类跨平台基准测试为例，Wild Life、Solar Bay 这类测试跑完后，页面通常按三层展开，逐层看下去才能把数字变成判断。

## 第一层：总体分数只是入口

总体分数是把图形测试结果换算后的综合值，适合快速定位一部设备的大概档位。它把渲染分辨率、API 差异都折算进去了，所以跨机型可比；但也因为折算得太浓缩，看不出瓶颈在哪。

## 第二层：帧率明细暴露瓶颈

往下看是平均帧率和分章帧率。以 Solar Bay 为例，场景分三章、光线追踪负载逐章递增，三段帧率一对比就能看出设备是在几何处理还是光照计算上掉链子：平均帧率尚可但后面两章明显走低，说明重负载下先撑不住。

## 第三层：百分位才是横向坐标

成绩页最有信息量的是两组对比：

- **你的分数 vs 这个型号**：和同型号其他用户的成绩比，得出一个百分位。同一台手机散热好坏、后台负载高低，都会反映在这里——低于 50% 就值得查查环境温度和后台。
- **你的分数 vs 所有设备**：放进近 5,000 台安卓、iOS 设备的成绩库里排位，换机时判断"到底升不升级"就看这张分布图。

跨平台比较还有个前提值得记住：Wild Life 系列在安卓和 Windows 上走 Vulkan、在 iOS 上走 Metal，低开销 API 天然占优，所以跨系统看排名趋势比抠绝对分差更靠谱。

跑分前别忘了测试数据要按需下载，各测试包大小不一样，空间紧张的话先装当前要跑的那一项。想动手跑一遍的，可以从 [3DMark 安卓版介绍站](https://3dmark.qhah.skin/) 进去把安装和测试项选择弄清楚，跑完再回来看这篇对数。
