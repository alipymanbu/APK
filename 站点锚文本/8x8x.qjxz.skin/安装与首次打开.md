# 8x8x 安装与首次打开

> 本篇整理 8x8x 这款安卓影音播放器从拿到安装文件到第一次打开的完整过程，以及各品牌手机放行「未知来源」的入口差异。
> **相关文档**：[投屏到电视没反应怎么办.md](投屏到电视没反应怎么办.md) · [离线缓存与清晰度设置.md](离线缓存与清晰度设置.md)

## 一、安装前确认两件事

- 手机系统为安卓 5.2 及以上，低于这个版本会直接提示不兼容；
- 剩余空间不少于 120M：安装包本身 56.82M，安装过程还需要临时解压空间。

安装文件的获取入口在 [8x8x 放映厅](https://8x8x.qjxz.skin/)的下载页，进入夸克网盘分享页后先转存到自己的网盘，再下载到手机，文件名形如 `8x8x_v1.6.apk`。

## 二、安装四步

1. 在文件管理里点开刚下载的 apk；
2. 弹出「是否允许安装」时选择允许；第一次安装可能被跳到设置页，进入第 3 步；
3. 在「安装未知应用」里给点开 apk 的那个应用授权（用文件管理开就授权文件管理，用浏览器下载就授权浏览器），再返回重新安装；
4. 进度条走完后点「完成」或「打开」。

各品牌入口略有差异：小米在「设置 → 隐私保护 → 特殊权限 → 安装未知应用」；华为 / 荣耀在「设置 → 安全 → 更多安全设置 → 安装外部来源应用」；OPPO / 一加、vivo / iQOO 在「安全」或「权限管理」下的同名菜单里。菜单名称以手机实际显示为准。

## 三、被系统拦截时

- 华为 / 荣耀（HarmonyOS 3.0–4.0）：「设置 → 系统和更新 → 纯净模式」里关闭「增强防护」再装，提示「未经检测」就勾选已知悉后继续；
- 三星（One UI 6.1.1 及以上）：「设置 → 安全与隐私 → 自动拦截程序」临时关闭，装完再打开；
- 提示「风险应用」「发现有害应用」时，多数版本会给「仍要安装」的继续入口，按提示走完即可。

安装完成后建议把上面临时关闭的开关逐个恢复——平时开着能拦住真正的流氓安装。

## 四、第一次打开

- 首次启动会请求存储权限，同意后离线缓存功能才能正常写入；
- 第一次联网播放会有几秒初始化等待，属正常现象，不是卡死；
- 若提示「解析包出错」，多半是文件在传输中损坏，重新下载一次再装；
- 手机里若装过同名的另一版本（签名不同），系统会拒绝覆盖，先卸载旧版再装。

装好之后想在大屏上看，接着读[投屏到电视没反应怎么办.md](投屏到电视没反应怎么办.md)；想离线追剧、调画质，看[离线缓存与清晰度设置.md](离线缓存与清晰度设置.md)。
