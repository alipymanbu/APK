# 8x8x 投屏到电视没反应怎么办

> 把 8x8x 里正在播的影片投上电视，靠的是 DLNA 无线投屏；设备列表搜不到电视、投上就断、画面很卡，基本都能从网络与设置两端找到原因。本篇按现象逐条排查。
> **相关文档**：[安装与首次打开.md](安装与首次打开.md) · [离线缓存与清晰度设置.md](离线缓存与清晰度设置.md)

## 一、投屏成立的三个前提

| 前提 | 怎么确认 |
| --- | --- |
| 手机与电视连同一个 Wi-Fi | 手机设置里的 Wi-Fi 名要与电视网络设置里的一致；路由器开了「AP 隔离」时设备互相看不见，需要关掉 |
| 电视端投屏服务已开启 | 智能电视一般在「设置 → 网络」或「我的应用 → 无线投屏」里；老电视可加一个支持 DLNA 的电视盒子 |
| 应用能正常播放 | 还没安装的话，先看[安装与首次打开.md](安装与首次打开.md) |

## 二、标准操作五步

1. 手机和电视连到同一个 Wi-Fi；
2. 电视端打开 DLNA / 无线投屏服务（小米电视：我的应用 → 无线投屏）；
3. 打开 8x8x，搜索片名进入播放页；
4. 点播放页里的「投屏」按钮；
5. 在设备列表里选中电视，连上即播。

投屏成功后手机就成了遥控器，进度、清晰度、音量、选集都在手机上操作；退出播放页去聊天、刷网页，电视上的播放不受影响。

## 三、按现象对症处理

**设备列表里搜不到电视**
逐项核对：是否同一 Wi-Fi → 电视端投屏服务是否打开 → 路由器「AP 隔离」是否关闭 → 手机离路由器是否太远。小米电视要在「我的应用」里手动启用「无线投屏」，否则列表里不会出现。

**投上去了但画面卡顿**
把清晰度从 4K 降到 1080P，并关掉家里其他占带宽的下载任务；路由器与电视之间隔墙越多影响越明显。清晰度档位的选择思路见[离线缓存与清晰度设置.md](离线缓存与清晰度设置.md)。

**有声音没画面（或有画面没声音）**
多为该条片源格式特殊，换一条播放线路或换一部影片验证；单部影片出问题时换线路就能解决。

**看到一半自动断开**
依次重启路由器、电视、手机后重连，多数是网络临时波动；部分手机 Wi-Fi 的省电策略会掐断后台连接，投屏时先关掉。

## 四、设备怎么都搜不到时

支持 AirPlay 的电视可以直接走屏幕镜像；老电视不带 DLNA 的，接一个电视盒子当投屏目标，兼容性通常比电视自带服务更稳。都试过仍不行的，换个时段再试一次——同一台电视在拥挤网络下也会偶发失联。
