# 户型从图纸到3D效果图

很多软件都能画平面图，但平面图和自己未来的家之间总差一层想象。Planner 5D 的特点是 2D 与 3D 随时互通：图纸上每改一笔，切到 3D 就能立刻看到这个家"住进去"是什么样。本文讲怎么从一张空图纸走到一张能拿去和施工方沟通的效果图。

## 为什么 2D 和 3D 要在同一个项目里

装修沟通里最常见的误会都出在"各自想象"上：业主想的是开放式，施工方理解的是半开放。同一个项目里 2D/3D 互通的价值就在这里——

- 图纸负责精确：尺寸、门窗位置、水电点位都落在数字上；
- 3D 负责直观：家具高度、灯光氛围、动线宽度一眼可辨；
- 两边不用来回重做，改哪边另一边自动跟上。

## 从图纸到 3D 的完整路径

整个流程可以概括成四段，每段都有对应的界面支持：

1. **画户型**：在 2D 图纸上画墙、开门开窗，按实际尺寸填数字；
2. **选家具**：从 8000 多件的物品目录里挑，颜色、材质、尺寸都能改；
3. **切 3D 环视**：一键切换视角，像人站在房间里一样四处看看；
4. **渲染快照**：用"快照"功能把当前视角渲染成一张带真实光影的图片。

前三段做完，项目本身就已经很完整；第四段出来的图片，适合发给家人征求意见，也可以直接贴给装修师傅当参考。

## 快照渲染怎么用

在 3D 模式下找到相机图标，选好取景角度后生成快照，稍等片刻就能得到一张处理过光照和阴影的实景图。几个让效果图更真实的小技巧：

- 取景高度放低到人眼视角（约 1.5 米），空间感更接近实际；
- 先调好时间和灯光：不同光源对成品氛围影响很大；
- 靠近拍局部：想要看沙发和窗帘搭不搭，别用全景凑合。

## 精度不够时怎么办

免费版可以完成从画图到渲染的基础流程，部分高清晰度渲染和完整目录属于订阅能力。对大部分"开工前比方案"的场景，基础渲染已经够用；要是需要更高分辨率的输出，再考虑升级也不迟。
