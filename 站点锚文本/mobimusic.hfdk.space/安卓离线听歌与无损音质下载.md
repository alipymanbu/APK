# 安卓离线听歌与无损音质下载

> 地铁里信号断断续续、流量月底不够用、耳机换了好却总在听压缩音源——离线听歌和无损下载解决的就是这三件事。本篇讲音质档位怎么选、下载与本地管理怎么做，以摩比音乐（MobiMusic）为例。

---

## 一、音质档位怎么选

摩比音乐提供从省空间到无损的几档音质，按设备和场景对号入座：

| 档位 | 适合场景 |
| --- | --- |
| 128k | 通勤外放、听个响，省空间省流量 |
| 320k | 高品质 MP3，体积与音质均衡，多数人的日常选择 |
| FLAC | 无损压缩，戴耳机差别明显，体积约为 320k 的 2~3 倍 |
| FLAC 24bit | 更高规格，有对应解码设备才听得出差别 |

两个实用提醒：

- **不是每条音源线路都有全档位**——某首歌选不到 FLAC，多是这条线路没这个资源，换音源再下；
- **无损也别盲目囤**——一首 FLAC 十几 MB 起步，几百首下来就是几个 GB，先看一眼剩余空间。

## 二、下载与离线播放

下载的操作路径：打开目标歌曲的播放页 → 点顶部**下载图标** → 挑音质档位确认 → 到「我的 → 我的下载」里查看。专辑页和歌单页支持整批下载，不用一首首点。

下载完成后的歌**断网也能照常播放**，入口在下载管理或本地音乐里。流量紧张的话：在线播放的默认音质到设置里调低一档，下载留到 Wi-Fi 环境再做。

## 三、下载位置与本地音乐

- **改保存位置**：「我的 → 下载管理」右上角的文件夹图标，可以选择或更改保存目录。建议存到独立目录，卸载重装应用时不容易把歌一起清掉；
- **本地扫描**：切到「本地」板块，应用会自动认出手机里已有的 MP3、FLAC 等音频文件，以前用别的播放器下好的歌也能纳进统一管理。首次扫描稍慢，扫不到时先查存储权限给没给。

## 四、常见小问题

- **下载失败**：新版本会给出具体原因，多数是线路没资源（换源重试）或存储权限没给；
- **批量下载被限**：部分线路对一次批量下载数量有上限，分几次下；
- **后台播放被掐断**：到系统设置里给应用放开省电策略、后台运行、自启动这些选项。

装好应用是第一步，功能总览与安装文件资源的获取入口见 [MobiMusic 介绍与获取入口](https://mobimusic.hfdk.space/)。歌单迁移与这类应用的原理，分别见 [歌单怎么跨平台搬家](歌单怎么跨平台搬家.md) 和 [聚合音源的听歌播放器是什么](聚合音源的听歌播放器是什么.md)。
