# 歌单怎么跨平台搬家

> 换播放器最劝退的一步就是歌单：几百首的歌，总不能一首首重新搜。本篇讲通用的「歌单 ID 导入」做法，以及在摩比音乐（MobiMusic）里的具体操作路径。

---

## 一、原理：歌单 ID 是钥匙

几乎每个音乐平台都给歌单编了号——打开一个歌单的详情页，点「分享」，分享出来的文案里那串数字（或字母）就是这份歌单的 ID。第三方播放器拿到这个 ID，就能按清单把歌一首首对出来，按原顺序排好。

所以跨平台搬家的通用流程是：

1. 在原平台打开要搬的歌单，点分享，把歌单 ID 复制出来；
2. 在新应用里找到「导入歌单」入口；
3. 选来源平台、粘入 ID、确认；
4. 等它按清单对完歌，曲名与顺序都会保留。

## 二、在摩比音乐里的操作路径

1. 点底部导航栏的**歌单**，进歌单管理页；
2. 点右上角的**三个点**，打开更多功能菜单；
3. 选**导入歌单**；
4. 选来源平台，把歌单 ID 填进去，点确定。

导入成功后歌单会出现在自建歌单列表里。有一件事要有预期：**能不能整单播出来，取决于当前音源线路里有没有这些歌**——缺的那几首，换一条音源后手动补搜即可。

## 三、导入失败或缺歌，按这个顺序查

1. **ID 粘错了**——分享文案里除了 ID 还有标题和链接，只粘 ID 那一串；有的版本支持直接粘整条链接，让应用自己识别；
2. **来源平台选错了**——来源要和歌单实际所在的应用一致，选错会解析失败；
3. **导入成功但少了几首**——当前线路没有那几首的资源，换音源后补搜；
4. **大歌单超时**——几百首的大单在网络差时容易中断，换个稳定网络重试。

## 四、搬完之后：两件事值得顺手做

- **开云同步**：摩比音乐的「云端」板块能把本地歌单清单和收藏备份上去，换手机时恢复就省得再导一遍。注意同步的是**清单**（歌名、顺序），不是音频文件本身；
- **把常听的囤到本地**：按歌单整批下载，离线场景不用来回找。音质档位怎么选，见 [安卓离线听歌与无损音质下载](安卓离线听歌与无损音质下载.md)。

还没装这个应用的，先看它的功能总览与获取入口：[MobiMusic 介绍与获取入口](https://mobimusic.hfdk.space/)；想了解这类应用的整体逻辑，见 [聚合音源的听歌播放器是什么](聚合音源的听歌播放器是什么.md)。
