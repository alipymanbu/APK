# 一句话下指令：让手机自己办事的使用技巧

> 本篇整理 AutoGLM 的指令写法：为什么有的指令一次成功、有的反复卡住。相关阅读：[手机智能体是什么](手机智能体是什么.md)、[安卓安装与首次使用](安卓安装与首次使用.md)。

---

## 核心原则：把"大概想法"换成"可执行路径"

智能体读的是屏幕、执行的是点按，指令越接近"可执行路径"，成功率越高。对比一组常见写法：

- ✗ "帮我点份午饭" —— 它可能真的只搜到一份午饭，门店、口味、优惠都不确定；
- ✓ "打开美团，搜索黄焖鸡，选销量第一的那家，点大份，停在付款界面" —— 应用、目标、偏好、终点都交代清楚了。

注意结尾那句"**停在付款界面**"：把支付这类敏感环节留给自己，是让任务跑得又快又放心的常用句式。

## 五类场景的现成句式

| 场景 | 可以这样说 |
| --- | --- |
| 外卖 | 打开美团，搜索黄焖鸡，选销量第一的那家，点大份，停在付款界面 |
| 出行 | 帮我查一下明天广州到北京的机票 / 导航去鼓楼 |
| 购物 | 打开拼多多，搜索笔记本，看看销量最高那款的评价 |
| 内容 | 去哔哩哔哩搜索英雄联盟直播并播放 |
| 杂务 | 清空我的购物车 |

## 三个让成功率翻倍的习惯

1. **一次一件事**。任务有边界才好回放核查；串行地交代，比一口气堆三个目标稳得多。
2. **先从只读任务试起**。搜内容、查路线、看评价不会改动任何数据，适合用来熟悉它的节奏，再逐步放手下单、订票。
3. **给它留出"喊人"的余地**。遇到敏感操作或广告弹窗，它会暂停并请你接手——看到悬浮窗提示就手动处理一下，任务会接着跑。

## 指令没成功，先检查这几处

- 指令里有没有写清**用哪个应用**（"搜笔记本"不如"打开拼多多搜笔记本"）；
- 权限是否给全（无障碍、悬浮窗，详见 [安卓安装与首次使用](安卓安装与首次使用.md)）；
- 屏幕上是否有广告弹窗挡路——它会提示你去手动关闭。
