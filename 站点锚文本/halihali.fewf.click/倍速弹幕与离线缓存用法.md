# 倍速弹幕与离线缓存用法

> 装好哈哩哈哩（Halihali）之后，播放页里的几个开关最值得先摸一遍：倍速、弹幕、悬浮小窗、离线缓存、夜间模式。这篇按「你想达到什么效果」来讲。

## 你想要的效果，去哪调

| 你想要 | 去哪调 | 说明 |
| --- | --- | --- |
| 赶更新 / 细看作画 | 播放页「倍速」 | 0.5～2 倍速区间，通勤常用 1.25 或 1.5 |
| 安静补番 | 「弹幕设置」里关弹幕 | 名场面再开回来；弹幕过密时关掉还能给老机型减负 |
| 一边回消息一边看 | 「小窗播放」 | 退出播放页后缩成悬浮窗继续播，位置可拖 |
| 断网场景追番 | 播放页「缓存 / 下载」 | 选集数与清晰度先存本机，地铁航班直接从离线列表看 |
| 关灯不刺眼 | 「夜间模式」 | 压暗界面、去白底 |
| 换设备接着看 | 登录同一账号 | 收藏、追更、播放进度云端同步 |

## 两个省时间的习惯

- **弱网先降一档画质**：画质越高对带宽要求越高，网络差时降档比一路转圈舒服；
- **缓存看完就删**：离线内容占存储，空间吃紧会导致缓存失败甚至应用异常，看完随手清理。
