# DiskDigger 站点目录

这里是围绕 DiskDigger（安卓上的照片恢复工具，Defiant Technologies 出品）整理的第三方介绍与经验合集。它做的事一句话能讲清：照片误删后，把还留在存储缝隙里的残留翻出来——没 root 也能跑基础扫描，root 后能深挖整片存储。

想直接看它的能力边界、两种扫描模式与界面实拍，可以到 [DiskDigger 介绍站](https://diskdigger.bmww.store/) 细读；目录里的几篇短文则分别回答「还能不能救、为什么发糊、工具怎么挑」三件高频的事。
