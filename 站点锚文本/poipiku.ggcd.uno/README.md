# poipiku 安卓资源站

poipiku（ポイピク，圈内常称「破皮裤」）是日本的插画随手贴社区：草稿、线稿、练习图不经打磨就能发，没有文字评论与排行榜，公开范围可以细到密码与仅关注者。本目录收录围绕它的介绍与安装指引，安卓客户端的获取入口与界面实拍见 [poipiku 插画箱介绍站](https://poipiku.ggcd.uno/)。
