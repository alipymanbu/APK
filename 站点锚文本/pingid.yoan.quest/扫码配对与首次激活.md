# 扫码配对与首次激活：把手机和你的账号绑起来

> 装好 PingID 之后手机却停在欢迎页？差的就是配对这一步。本篇讲二维码从哪来、怎么扫、扫不了码怎么办，以及配对后的第一次验证怎么过。
> **相关文档**：[验证请求收不到的原因与兜底.md](验证请求收不到的原因与兜底.md) · [换手机怎么迁移账号.md](换手机怎么迁移账号.md)

---

配对（pairing）就是把手机上的 PingID 和你的组织账号绑成互相信任的一对。没配对的 App 只能停在一个服务条款欢迎页上，这不是装错了，而是流程还没走完。配对用的二维码或配对密钥只能由你的组织签发——它们和你的账号绑定，别人给不了你，你也给不了别人。

## 二维码的两个来源

- **登录页的注册窗口**：在电脑浏览器里登录公司账号时，页面会弹出设备注册界面，点 Start 后屏幕上显示二维码；
- **组织发的邮件**：IT 部门可能把二维码和操作说明直接发到你邮箱。

注意一个细节：把二维码显示在**另一台设备**（通常是电脑屏幕）上，再用手机去扫它。用同一部手机扫自己屏幕上的码是行不通的。

## 扫码配对的完整步骤

1. 手机打开 PingID，阅读服务条款后点 Continue；
2. 弹出通知权限时点 Allow——之后的验证请求全靠推送送达，这一步给了后面才顺利；
3. 在手机上点 Scan，允许访问相机，对准电脑屏幕上的二维码；
4. 等待配对确认，出现绿色对勾即成功。

**扫不了码的备用方案**：手机上点 Enter Pairing Key，把二维码下方那串长数字手动输进去，效果一样。

有些组织还要求自设 PIN。规则提前知道免得反复被拒：4 位 PIN 至少含 3 个不同数字，6 位至少含 4 个，不能用 1234 这类顺序数字；设了之后每次验证都要输，忘了只能找管理员重置。另外 App 在后台闲置约 3 分钟会自动上锁，连输错 3 次 PIN 会被暂时锁住。

## 第一次验证，才算真正激活

配对一成功，系统立刻发来一条验证请求："是不是你正在登录？"在手机上点 Yes 批准，或者按提示验一下指纹。请求有时限，超时没批就要重新发起。

批准通过后，App 主界面会显示当前的一次性密码数字——到这里激活完成。日常登录的几种验证方式怎么操作，可以看 [PingID 使用教程](https://pingid.yoan.quest/)，里面把数字匹配、离线通行码这些界面对着截图讲了一遍。

## 一部手机绑多个组织

如果你在不止一家用 PingID 的公司工作，不用装第二个 App：打开 PingID，用 Add organization 把其他组织的账号逐个配对进来，验证时 App 会自动区分请求来自哪一家。换手机时多组织账号怎么一起搬走，见 [换手机怎么迁移账号.md](换手机怎么迁移账号.md)。
