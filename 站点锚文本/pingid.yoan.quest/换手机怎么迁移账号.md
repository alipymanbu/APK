# 换手机怎么迁移账号：旧机还在手与旧机丢失两条路

> 换了新手机，PingID 里的组织账号怎么搬过去？分两种情况：旧手机还在手上用 Change Device 扫码迁移；旧手机丢了或坏了就走管理员的解绑重配流程。
> **相关文档**：[扫码配对与首次激活.md](扫码配对与首次激活.md) · [验证请求收不到的原因与兜底.md](验证请求收不到的原因与兜底.md)

---

PingID 的账号绑定是跟具体设备走的，换手机不会自动跟过去，所以迁移要主动做一次。好在流程不复杂——前提是你知道该走哪条路。

## 情况一：旧手机还在手上（Change Device）

这是最顺的一条路，全程不用麻烦 IT：

1. 新手机上先把 PingID 装好；
2. 旧手机打开 PingID，点菜单里的 **Settings → Change Device**，旧手机屏幕会显示一个二维码；
3. 用新手机打开 PingID 扫这个码；
4. 迁移完成：旧手机自动解除配对，所有组织账号出现在新手机的验证标签页里。

下次登录就能在新手机上批准验证请求了。如果你有多台设备绑在同一个账号上，记得去账号的设备管理页把不再用的旧设备解绑掉，免得留下隐患。

## 情况二：旧手机丢了、坏了或刷机了

旧手机不在手上，Change Device 就用不了，这时只能走组织的管理流程：

1. 联系组织的服务台或管理员，说明设备丢失，请他们把丢失设备从你的账号上解绑；
2. 管理员解除绑定后，像新用户一样重新配对：在电脑登录页的注册窗口（或 IT 发的邮件里）拿到新的二维码或配对密钥；
3. 新手机打开 PingID，扫码或手输配对密钥完成绑定；
4. 配对时允许通知权限，之后的验证请求才能正常送达。

设备丢失的场景建议顺手改掉账号密码——能拿到你密码的人，少了第二道验证就可能直接登进去。具体操作口径各组织不同，以你管理员的指引为准。

## 迁移后先验证一遍

无论走哪条路，迁完先别急着收工：在电脑上发起一次登录，确认新手机能收到请求、能正常批准。推送若是不来，多半是新手机的通知权限或省电策略还没调好，按 [验证请求收不到的原因与兜底.md](验证请求收不到的原因与兜底.md) 排一遍即可。

另外两点容易忽略：一是配对用的二维码只能来自你的组织，来源与获取方式见 [扫码配对与首次激活.md](扫码配对与首次激活.md)；二是想在动手机之前先弄清楚整个验证流程长什么样，可以看 [PingID 使用教程](https://pingid.yoan.quest/)，对着截图走一遍心里更有底。
