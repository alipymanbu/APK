# B 站视频离线缓存到手机的几种做法

> 想在没网的地方接着看 B 站视频，路子其实不止一条。这里把常见的几种缓存方式摆在一起，说说各自适合什么场景，以及一个专门做缓存的开源工具怎么用。

## 一、先分清两种需求

「把 B 站视频存下来」背后其实是两类不同的需求，先对号入座：

1. **离线自己看**：通勤、出差、流量不够，想在没网的手机上看完一整个视频或一季番剧；
2. **拿视频当素材**：剪辑、截图、逐帧研究镜头语言，要的是文件本身，而不只是「能播」。

第一类需求用平台客户端自带的缓存就能满足大半；第二类需求则要借助第三方工具，因为客户端缓存是加密分片格式，拿到手也剪不了。

## 二、客户端自带缓存：省事但有边界

B 站 App 的离线缓存入口就在播放页，选中清晰度后点缓存即可。它的优点是稳定、不折腾；局限也很明确：

- 缓存内容只能在客户端内看，导出到别的播放器基本没戏；
- 清晰度跟着账号权益走，未登录与低权益账号可选档位有限；
- 换设备后缓存不跟随，得重新下。

适合「我只是这两天没网」的场景。

## 三、开源工具路线：拿到真正的视频文件

想把视频变成普通 MP4 文件——能进播放器、能进剪辑软件——就需要专门工具。安卓端这一档的代表是 BILIBILIAS：一款开源的解析缓存工具，粘贴分享链接或 BV / AV / EP / SS 号就能解析视频与番剧，把画面流、声音流连同弹幕、字幕、封面一起取下来，最后自动合并成一个完整的 MP4。

它的几个特点值得单说：

- **文件是自己的**：缓存目录默认在 Download/BILIBILIAS，还能自定义到 SD 卡或自建目录，命名规则支持把集数编进文件名；
- **编码可挑**：下载对话框里能选 AVC（H.264）这类兼容性最好的编码，避免下完在自己播放器里黑屏；
- **后台与续传**：任务挂着就能切出去干别的，网络断了重连接着下。

具体的功能梳理、界面截图与安装包获取入口，见 [BILIBILIAS 功能说明站](https://bilibilias.wxhp.skin/)，这里不重复展开。

## 四、网页解析工具：偶尔下一两个图省事

还有一类是网页版的解析服务，粘贴链接出直链，手机电脑都能用。适合一年下不了几次、不想装 App 的人；缺点是批量任务难管理、弹幕字幕这些「附属品」通常不跟着走，稳定性也参差不齐。

## 五、怎么选

| 场景 | 建议 |
| --- | --- |
| 就想离线追个番 | 客户端自带缓存，最省心 |
| 要文件、要弹幕、要批量 | 安卓端装 BILIBILIAS 这类开源工具 |
| 偶尔下一个、不想装 App | 网页解析服务凑合用 |

选第三方工具时留意两点：一看是否开源（代码公开意味着功能与数据流向可查证），二看产物是不是标准格式（MP4 + 独立弹幕文件，而不是又一种私有封装）。想进一步了解画质档位与账号权益的关系，接着读 [B站高清画质下载的权益说明.md](B站高清画质下载的权益说明.md)；下载时想把弹幕字幕一并带走，见 [B站弹幕和字幕一起保存的做法.md](B站弹幕和字幕一起保存的做法.md)。
