# B 站高清画质下载的权益说明

> 选了 1080P 却只能下到 480P？想下 4K 发现列表里压根没有那一档？先把「画质档位是怎么定的」说清楚，再谈怎么办。
> **相关文档**：[B站视频离线缓存到手机的几种做法.md](B站视频离线缓存到手机的几种做法.md) · [B站弹幕和字幕一起保存的做法.md](B站弹幕和字幕一起保存的做法.md)

## 一、一句话结论

第三方缓存工具能拿到什么画质，取决于**账号权益与视频本身规格的交集**——账号里有什么，就取到什么；视频没有的，什么账号都变不出来。不存在「越过权益下高清」的操作，遇到声称能做到的工具要留个心眼。

## 二、各档位的对应关系

以安卓端常用的开源缓存工具 BILIBILIAS 为例（它走公开接口，档位规则与平台侧一致）：

| 账号状态 | 可取档位 |
| --- | --- |
| 未登录 | 最高 480P |
| 普通登录账号 | 1080P 一档可取 |
| 大会员账号 | 1080P 高帧率、4K、HDR 等高规格（前提是视频本身提供） |
| 付费番剧 / 电影 | 需要大会员账号，否则解析后给不出可下载的清晰度 |

两个容易误会的点：

1. **档位没出现 ≠ 界面没加载出来**。下载页的清晰度是勾选制，列表里没列出的档位就是当前账号拿不到的，刷新一百次也不会多出来；
2. **选了超权益的档位会自动降级**。工具不会报错，只是最终文件回到你权益内的最高档。

工具的功能与设置细节，见 [BILIBILIAS 功能说明站](https://bilibilias.wxhp.skin/)，这里只谈画质相关的部分。

## 三、视频本身的限制，账号救不了

账号权益是天花板的一半，另一半在视频那边：

- 一个最高只有 720P 的稿件，大会员登录也下不出 4K；
- 部分电影、纪录片这类商业内容受版权保护机制约束，即便账号有权益，可取的规格也偏低，个别付费内容甚至完全取不到；
- 缓存下来的视频统一带平台水印，这是画面的一部分，任何工具都「无损去不掉」——声称能去的多半是裁切画面或者来路不正。

## 四、编码与画质是两件事

档位解决「分辨率多高」，编码决定「你的设备能不能播」。同一个 1080P 档位，可能同时提供 AVC（H.264）、HEVC（H.265）、AV1 几种编码：高编码同画质体积更小，但老设备、自带播放器可能没有对应解码器，表现为「有声音、画面全黑」。

实用建议：缓存时拿不准就选 AVC，兼容性最好；真想要 HEVC/AV1 的小体积，先确认自己的播放器支持。BILIBILIAS 从 2.1.5 起就在下载对话框里提供编码选择，下错了换一版重下一次就行。

## 五、想拿高画质，正确的路径

1. 先看视频本身有没有高规格版本（播放页切一下清晰度就知道）；
2. 再看账号：普通账号解锁 1080P，高帧率 / 4K / HDR 与付费内容都要大会员权益；
3. 登录后重新解析一次，让档位列表重新拉取；
4. 缓存时选对编码，避免「下得出、播不了」。

顺带说一句：这些档位规则对在线播放和缓存下载是同一套，不存在「播放能看 4K、缓存拿不到」的亏——能播就说明权益够，缓存列表里也一定有那一档。工具的选择与上手路径，回看 [B站视频离线缓存到手机的几种做法.md](B站视频离线缓存到手机的几种做法.md)；弹幕字幕的打包方法见 [B站弹幕和字幕一起保存的做法.md](B站弹幕和字幕一起保存的做法.md)。
