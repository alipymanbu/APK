# Dhizuku 资料索引

> 第三方整理的 Dhizuku（Android 设备所有者权限共享工具）资料页：功能定位、激活路径与配套应用一览，安装包获取入口见 [Dhizuku 介绍与获取指引](https://dhizuku.fewa.skin/)。

Dhizuku 是一款开源（GPLv3）的 Android 玩机工具，思路参考 Shizuku：先让它自己占住系统里唯一的设备所有者（Device Owner）位置，接入了它接口的应用再向它借用这份权限，在没有 Root 的手机上完成隐藏、暂停应用等管理操作。激活一次长期有效，重启也不会掉。

本目录收录围绕它整理的几篇主题文章：

- [设备所有者权限怎么激活](设备所有者权限怎么激活.md)——激活前的三道检查、两条激活路径与报错排查。
- [和Shizuku有什么区别](和Shizuku有什么区别.md)——借出的身份、重启后的表现、激活门槛，一张表讲清。
- [免Root隐藏应用怎么实现](免Root隐藏应用怎么实现.md)——从权限借用链路看隐藏与暂停应用的实际效果。
