# 免 Root 隐藏应用怎么实现

> 不 Root 的手机上，隐藏、暂停应用这类管理操作是怎么做成的：一条「权限借用」链路，把设备所有者的能力递到工具类应用手里。
> **相关文章**：[设备所有者权限怎么激活](设备所有者权限怎么激活.md) · [和Shizuku有什么区别](和Shizuku有什么区别.md)

## 一、链路：三层结构

免 Root 隐藏应用不是单个应用的本事，而是一条三层链路：

1. **身份层**：Dhizuku 先占住系统里唯一的设备所有者位置（激活方法见[设备所有者权限怎么激活](设备所有者权限怎么激活.md)）；
2. **接口层**：项目提供了公开的接入接口，工具类应用集成后即可向 Dhizuku 发起权限请求；
3. **应用层**：Hail（雹）、Amarok 这类工具把借来的能力做成按钮——隐藏、暂停，点了就生效。

授权的动作只有一次：在目标应用里把工作模式切成 Dhizuku，弹窗里点允许，之后这份授权长期可用，重启也不需要重新来。

## 二、隐藏与暂停是两种力度

同样是「让一个应用消失」，实际有强弱之分，以 Hail 为例：

- **隐藏**：应用从桌面和已安装列表里消失，数据与安装包都还在，随时可以恢复——这是 Dhizuku 模式下能做到的最强力度；
- **暂停**：图标变灰、通知被拦、点开提示「应用已暂停」，但后台仍可能运行；
- **停用 / 强停**：比隐藏更彻底，Dhizuku 模式下**拿不到**这两个能力，需要 root 或 shell 级通道（如 Shizuku）。

选模式之前先想清楚要哪种力度：只是不想让别人看到，隐藏足够；想连后台行为一起摁住，就得评估另一条通道。

## 三、哪些工具接入了

目前明确支持 Dhizuku 模式的开源工具集中在应用管理一类：

| 工具 | 用途 | Dhizuku 模式下能做什么 |
| --- | --- | --- |
| Hail（雹） | 冻结 / 隐藏应用 | 隐藏、暂停 |
| Amarok | 隐藏应用与文件 | 应用隐藏（文档把该模式列为免 Root 设备的推荐选择） |
| InstallerX | 安装器 | 调用权限完成安装相关操作 |

数量确实不多——工具必须**主动接入接口**才能借到权限，市面上更多工具只接了 Shizuku 或只支持直接 adb 激活。挑工具前先看它的模式列表里有没有「Dhizuku」字样，没有就借不到。

## 四、三个实用提醒

1. **用什么模式冻，就用什么模式解**：中途换通道（Dhizuku 换 Shizuku）后，原来冻住的应用可能解不开，先回原模式解冻再切；
2. **撤销前先解冻**：不打算继续用时，先把依赖它的应用全部恢复，再处理 Dhizuku 本身，顺序反了会很麻烦；
3. **账号与分身随时可以加回来**：限制只存在于激活那一刻，完成之后登录账号、开分身都不影响已取得的身份。

链路与工具的整体介绍、安装文件资源入口，见 [Dhizuku 整理站](https://dhizuku.fewa.skin/)；两条授权通道的取舍对比，见[和Shizuku有什么区别](和Shizuku有什么区别.md)。
