# Dhizuku 设备所有者权限怎么激活

> 把 Dhizuku 设成设备所有者的完整流程：激活前的三道检查、电脑 ADB 与 Shizuku 两条路径、常见报错对号入座。
> **相关文章**：[和Shizuku有什么区别](和Shizuku有什么区别.md) · [免Root隐藏应用怎么实现](免Root隐藏应用怎么实现.md)

## 一、激活前先过三道检查

Android 只允许把「设备所有者」这个唯一位置交给一个应用，而且只在设备干净时才放行设置。三条任何一条不满足，命令都会当场被拒：

1. **账号清零**——设置 → 账号 里一个账号都不能留（同步账号、企业邮箱都算）。设置里看着空了不代表真的空了，可用 `adb shell dumpsys account` 复查底层残留；
2. **没有第二用户**——应用分身、手机分身、访客模式都会创建第二用户，先在设置里删掉（被删用户空间里装的应用会被一并卸载）；
3. **位置空闲**——冰箱、小黑屋、Island 这类工具如果之前被设成过设备所有者，位置还占着，要先去那边移交或移除身份。

## 二、路径 A：电脑 ADB 激活（通用）

手机开启 USB 调试连上电脑，确认设备连通后执行：

```bash
adb shell dpm set-device-owner com.rosan.dhizuku/.server.DhizukuDAReceiver
```

输出 `Success: Active admin and device owner set ...` 即成功，打开 Dhizuku 首页会显示已激活。Android 11+ 的设备也可以走无线调试（开发者选项 → 无线调试，配对后 `adb connect`），不必插数据线；手边没有电脑时，另一部手机加 OTG 线和任意 ADB 客户端应用也能执行同一条命令。

## 三、路径 B：借道 Shizuku

已经在跑 Shizuku 的设备可以不连电脑：打开 Dhizuku，在激活方式里选「通过 Shizuku 激活」，按提示授权即可。激活成功之后便不再依赖 Shizuku——设备所有者身份是持久的，重启也不掉。

## 四、常见报错对号入座

| 报错原文（节选） | 含义与处理 |
| --- | --- |
| `...already some accounts on the device` | 账号没清干净，回到第一节用 dumpsys 复查 |
| `...already some users on the device` | 还有第二用户，删掉分身 / 访客再试 |
| `...device owner is already set` | 位置被别的应用占着，先去那边移交身份 |
| `ProvisioningPreCondition 99` | OPPO / 一加等机型只放行白名单或测试签名应用，属机型签名限制，按机型到项目讨论区检索思路 |

两个补充：冻结账号类应用来「藏账号」的话，激活完成后或重启前记得解冻，一直冻着可能影响开机；激活成功后重新登录账号、开分身都不受影响——限制只存在于激活那一刻。

## 五、激活之后

1. 到 设置 → 安全 → 设备管理员 确认 Dhizuku 在列表里且停用按钮是灰的——「关不掉」才是真正的设备所有者；
2. 打开需要它的应用（如 Hail），把工作模式切成 Dhizuku，授权弹窗点允许，即可开始使用，场景见 [免Root隐藏应用怎么实现](免Root隐藏应用怎么实现.md)；
3. 想对比另一条通道的取舍，看 [和Shizuku有什么区别](和Shizuku有什么区别.md)。
