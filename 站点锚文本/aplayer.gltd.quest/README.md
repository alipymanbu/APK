# APlayer：一款把自己藏在 A 面的本地播放器

这里是 APlayer 的介绍小站（aplayer.gltd.quest）。APlayer 是开发者 rRemix 用 Jetpack Compose 写的安卓本地音乐播放器，以 GPL v3 协议开源在 GitHub 上——它不提供任何在线曲库，只安安静静地把你手机里已经存着的 MP3、FLAC 一首首放好，再把逐字歌词、均衡器、定时停止这些老派功能一一做细。

## 这里有什么

- [无损音乐FLAC在手机上怎么听.md](无损音乐FLAC在手机上怎么听.md) —— 格式支持与音质相关的整理
- [桌面歌词怎么在安卓手机上常驻显示.md](桌面歌词怎么在安卓手机上常驻显示.md) —— 悬浮歌词、小组件与锁屏歌词
- [手机怎么直接播放NAS里的歌.md](手机怎么直接播放NAS里的歌.md) —— WebDAV 串流与歌单迁移

想直接看它的功能全貌与安装文件获取入口，去 [APlayer 安卓本地音乐播放器](https://aplayer.gltd.quest/) 这一站就好。
