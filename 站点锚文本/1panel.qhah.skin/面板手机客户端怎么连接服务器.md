# 面板手机客户端怎么连接服务器

> 本篇讲手机客户端连接 1Panel 面板前的三项准备、添加服务的操作，以及连不上时按什么顺序排查。
> **相关文档**：[服务器告警通知到手机怎么配](服务器告警通知到手机怎么配.md) · [手机端服务器运维客户端怎么选](手机端服务器运维客户端怎么选.md)

## 一、先分清客户端与面板的关系

手机上的 1panel 客户端本身不带面板功能，它连接的是你服务器上已经装好的 1Panel 面板，把面板里的概览、应用、容器、网站这些常用操作搬到手机上。所以「连不上」多数时候不是手机这边的问题，而是服务器那头还没准备好。

## 二、连接前的三件事

1. **服务器上已装好面板**：1Panel 是开源的 Linux 运维面板，安装方式见其文档站，装完会得到面板地址与账号密码；
2. **面板已激活专业版许可证**：移动端 App 属于专业版的配套权益，社区版面板不在接入范围——这是新手最常撞上的门槛；
3. **手机能访问到面板地址**：先用手机浏览器打开面板地址试一试。云服务器一般用公网 IP 加端口；家用内网服务器要么与手机同处一个局域网，要么提前打通外网访问（端口映射、回家组网、内网穿透三种常见做法）。注意后两种都会把面板暴露到公网，打通前先改掉默认端口、设好强密码。

## 三、在客户端里添加服务

1. 打开 App，首次使用会引导添加服务，之后随时可以再加；
2. 按界面提示填写面板访问信息与登录账号（与浏览器登录面板用的是同一套）；
3. 提交后首页即出现该服务器的概览。

支持添加多台服务器：公司一台、家里一台、几台 VPS 都能加进同一个 App，在服务之间切换查看。

## 四、连不上时的排查顺序

按从外到内查，别一上来就重装：

| 现象 | 先检查什么 |
| --- | --- |
| 一直转圈 / 超时 | 手机浏览器能否打开面板地址；端口是否放行（云服务器看安全组）；服务器有没有到期 |
| 提示账号或密码错误 | 用同一套账号在手机浏览器登录面板网页，确认账号本身没问题 |
| 提示无权限 | 面板是否已激活专业版许可证 |
| 之前能连、现在连不上 | 面板地址或端口最近改过没；服务器 IP 变了没；许可证过期没 |

三样都确认就绪、还没装客户端的，可以从 [1panel 手机客户端介绍站](https://1panel.qhah.skin/)进到下载页获取安装文件资源。

## 五、连上之后建议做的两件安全事

- 面板密码按「丢了手机也不慌」的标准来设——客户端等于把管理入口常驻在手机上；
- 换机、卖机前先在面板网页改密码，旧设备上的登录状态会随之失效。
