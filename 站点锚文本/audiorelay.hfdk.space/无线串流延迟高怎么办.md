# 无线串流延迟高怎么办

> 用手机听电脑的声音，最影响体验的就是延迟：看视频口型对不上、打游戏音效慢半拍。这篇把延迟从哪来、怎么量、怎么压下去一次讲完，顺带说说音质和稳定性相关的几个开关。
> **相关文档**：[电脑声音怎么投到手机上放.md](电脑声音怎么投到手机上放.md) · [手机麦克风给电脑当话筒用.md](手机麦克风给电脑当话筒用.md)

## 先看数字再下结论

连接建立后，AudioRelay 的页面会实时给出三项数据，判断该不该动手调，先读它们：

- **延迟**：局域网状况好时普遍在几十毫秒以内，这个量级看视频、听音乐完全无感；
- **丢包**：正常应为 0%，不为 0 说明网络在丢数据，表现是声音断续；
- **缓冲**：接近或超过 100 毫秒，说明传输跟不上、在靠缓冲硬撑，这时才需要往下调。

这套数据口径与更多连接细节，整理在 [audiorelay.hfdk.space](https://audiorelay.hfdk.space/) 的连接方式一节。

## 压延迟的四板斧

1. **换 USB 线连**：打开手机的「USB 网络共享」，有线传输的体验明显好于 WiFi，对声画同步苛刻的游戏、剪辑场景都靠它。注意防着电脑顺这条路吃手机流量。
2. **WiFi 提质**：电脑接网线、两端设备凑近路由器、换 5GHz 频段，三件事任选都能立竿见影。
3. **调缓冲**：手机端设置里有缓冲大小选项，网络好就往小调；反复断续时适当放大换取稳定。
4. **先排除蓝牙**：若手机接着蓝牙耳机，延迟大头来自蓝牙本身，与串流链路无关——换有线耳机插手机再测，别冤枉 WiFi。

## 音质与稳定性顺手调

- **音量小**：收到的音量跟着电脑走，先把 Windows 主音量拉高，再用手机音量键微调；
- **CPU 占用高**：把播放设备的声道配置改成立体声即可，多声道输出是主因；
- **后台被清**：锁屏就断连，把应用加进电池优化白名单、开自启动，部分机型还要单独给通知权限；
- **被别的应用打断**：设置里的「独占音频」选停用后不再给其他应用让路，代价是两边声音会叠在一起，按场景取舍。

两个方向（放音、收音）可以同时开着用，互不冲突；只有多台设备同时连一台电脑属于付费解锁项，基础使用不受影响。安装与两端配对的完整流程见 [电脑声音怎么投到手机上放.md](电脑声音怎么投到手机上放.md)，麦克风方向的接法见 [手机麦克风给电脑当话筒用.md](手机麦克风给电脑当话筒用.md)。
