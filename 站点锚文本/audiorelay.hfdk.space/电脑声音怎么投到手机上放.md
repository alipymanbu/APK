# 电脑声音怎么投到手机上放

> 台式机没插音箱、笔记本喇叭破音、想在床上用耳机听电脑——这类需求都指向同一个做法：把电脑正在播放的声音实时串流到手机外放。这篇讲清它靠什么实现、延迟表现如何、连不上时从哪里下手。
> **相关文档**：[手机麦克风给电脑当话筒用.md](手机麦克风给电脑当话筒用.md) · [无线串流延迟高怎么办.md](无线串流延迟高怎么办.md)

## 用什么实现

方案叫 **AudioRelay**：电脑端和手机端各装一份，电脑端抓住系统混音，经局域网发给手机。声音数据只在同一路由器的网络里走，不经过公网。手机端在「播放器」页点电脑名即连；连上后手机就是一块外放，音量键直接调大小。安卓端安装文件资源的获取入口整理在 [audiorelay.hfdk.space](https://audiorelay.hfdk.space/)，配套的连接与设置说明也在同一处。

## 两种连法

**同一 WiFi（无线）**：手机和电脑接同一路由器即可，不需要外网可用。手机端自动发现电脑，列表点一下就通；也支持按 IP 手动直连，适合路由器开了设备隔离的环境。

**USB 网络共享（有线）**：数据线连接手机与电脑，手机打开「USB 网络共享」，服务器列表会多出一个条目。这条路传输质量明显好于无线，对声画同步敏感的场景（打游戏、剪视频）优先用它。注意防止电脑顺这条新网络消耗手机流量——同时连着 WiFi、关掉移动数据或开飞行模式都能规避。

## 连上看三个数

连接页会实时显示延迟、丢包、缓冲：延迟普遍在几十毫秒以内（USB 更低），看视频听音乐无感；丢包应为 0，不为 0 会听到断续；缓冲接近或超过 100 毫秒说明网络在硬撑，优先把电脑接网线、设备凑近路由器或换 5GHz 频段。

## 连不上电脑的排查顺序

1. **确认同一网络**：两端必须挂在同一路由器下，访客网络、AP 隔离都会让发现失效。
2. **防火墙规则**：电脑端安装时有一项防火墙勾选（Add firewall rules），取消过就重装补上。
3. **IP 直连兜底**：电脑端看本机 IP，手机端「使用 IP 地址连接」手动填入。
4. **后台被杀**：锁屏就断是省电策略所致，把应用加进电池优化白名单并开自启动。
