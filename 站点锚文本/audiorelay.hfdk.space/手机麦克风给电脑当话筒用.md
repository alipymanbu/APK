# 手机麦克风给电脑当话筒用

> 台式机前面没地方插麦、笔记本自带麦克风收音发闷，开会时对方总说听不清——把手机变成电脑的话筒是现成的解法。这篇讲这条反向链路怎么一次接通、接通后没声音按什么顺序查。
> **相关文档**：[电脑声音怎么投到手机上放.md](电脑声音怎么投到手机上放.md) · [无线串流延迟高怎么办.md](无线串流延迟高怎么办.md)

## 链路长什么样

用 **AudioRelay** 的麦克风方向：手机端采集麦克风声音，经 WiFi 或 USB 发给电脑，电脑上随之出现一个叫 **Virtual Mic** 的虚拟录音设备，会议、直播、录音软件把它选成输入设备即可。与「电脑投声音到手机」正好方向相反——这次手机是服务器（发声音），电脑是播放器（收声音）。安装文件资源的获取入口与完整使用说明整理在 [audiorelay.hfdk.space](https://audiorelay.hfdk.space/)。

## 三步接通

1. **手机端开始采集**：切到「服务器」页，音源选 microphone，首次弹出的录音权限给允许。
2. **电脑端接过来**：切到「播放器」页，把输出模式从默认放音切换成 **Mic**，再点列表里的手机。
3. **软件选对设备**：要么在系统声音设置里把 `Virtual Mic` 设为默认录音设备（顺带设为默认通信设备），要么进 Zoom / Discord / 录屏软件的麦克风设置里单独选它。

## 手机那侧的三个细节

- **离嘴近一点**：手机平放桌面收的是整间屋的动静，开会拿到面前效果立竿见影。
- **别被省电策略清掉**：锁屏没几分钟就掉线，多半是系统杀了后台，电池优化白名单和自启动权限都要给。
- **来电会打断采集**：通话期间麦克风被占用，挂断后重新点一下麦克风音源就恢复。

## 接通了却没声音，按序查

电脑端模式必须是 **Mic** 而不是默认放音；软件里选的设备必须是 `Virtual Mic`；Windows 的「允许桌面应用访问麦克风」隐私开关要打开——这个开关关着时虚拟设备在列表里却读不到任何声音；改完设置把连接断开重连一次，新设备路径才生效。都过了仍无声，回到 [audiorelay.hfdk.space](https://audiorelay.hfdk.space/) 的常见问答区对着现象逐条对，或带上两端版本号去产品社区发帖。
