# 安全级别怎么选：三档之间的取舍与几处必核对的设置

> 连上洋葱线路只是开始。本篇整理三档安全级别各禁了什么、页面异常时怎么判断是不是级别造成的，以及几处值得花两分钟核对的设置。
> **相关文档**：[手机匿名浏览的实现原理.md](手机匿名浏览的实现原理.md) · [网桥配置与连接失败自救.md](网桥配置与连接失败自救.md)

## 一、三档安全级别

入口：浏览器导航栏右侧三个竖点 → 隐私与安全 → 安全级别。原理是禁用部分可能被用来攻击你的网页功能，档位越高，个别网站的显示或交互越可能异常。

| 级别 | 实际行为 | 适用判断 |
| --- | --- | --- |
| 标准 | 全部功能开启 | 默认档，日常浏览 |
| 较安全 | 非 HTTPS 站点禁用 JavaScript；部分字体与数学符号停用；音视频点击播放 | 能接受小面积排版异常 |
| 最安全 | 所有站点默认禁用 JavaScript；部分字体、图标、图片停用 | 只看文字、优先保匿名 |

页面按钮点不动、图标缺失时，先调回「标准」再刷新，确认是不是级别造成的，别急着怀疑网络——这条排查纪律能省掉大部分误判。

## 二、语言与新线路

- **显示语言**：默认跟随系统语言，设置 → 语言里可改，即时生效不用重装；
- **新线路**：菜单里的选项，只给当前标签页换一条线路后重新加载，不影响其他标签页、不清任何数据。出口被目标站拒绝、验证码刷不出来时用它重试；
- 安卓版没有「新建身份」功能（桌面版才有），想整体换链路只能杀掉浏览器重开。

## 三、日常使用的几条纪律

1. **别装额外扩展**：预设的隐私规则已覆盖广告与追踪拦截，插件反而可能破坏匿名性；
2. **登录即实名**：在浏览器里登录任何账号，对这个网站而言你就不再匿名，需要匿名的浏览和需要登录的操作分开处理；
3. **文档先断开再打开**：从浏览器下载的 PDF、Office 文档可能内联联网资源，会话开着时打开有暴露风险；
4. **保护范围有边界**：它只保护浏览器里的流量，设备上其他应用不经过它——想让聊天、邮件也走洋葱线路，那是另一款系统级代理应用的分工。

## 四、从哪里开始

第一次接触这类浏览器，先把级别停在「标准」，跑顺了再按需上调。想装一份的话，[TorBrowser 介绍站](https://torbrowser.gltd.quest/)首页把原理、能力与安卓端表现整理成了两页，获取入口就在页面按钮上；连接环节卡住直接翻[网桥配置与连接失败自救](网桥配置与连接失败自救.md)。
