# 像素表盘与图案资源怎么找

> 给 Divoom 像素屏换内容有三条路：从社区图库挑现成的、在现成图案上改几笔、或者从零画。本篇按省力程度排序讲各条路的入口。
> **相关文档**：[像素屏设备怎么连接手机](像素屏设备怎么连接手机.md) · [天气小组件不刷新怎么办](天气小组件不刷新怎么办.md)

---

## 一、从社区图库挑现成的

设备连上后进入对应设备的图案页面，图库按节日、游戏、动物、天气等主题分类，也支持搜关键词；看中哪个点一下，图案直接推送到屏幕。图库由社区持续上传，分类和热门内容会随时间变化，找到喜欢的记得一键收藏。

## 二、在现成图案上改

比从零画快得多：选中图案进编辑，改几个像素、换配色再保存。几个常用入口：

| 入口 | 干什么 |
| --- | --- |
| Design | 单帧像素图绘制 |
| Animation | 多帧动画，逐帧画后连播 |
| Text Editor | 滚动文字条，选字体颜色与速度 |
| Pixel Coloring | 给像素画上色、改色 |

## 三、从零画自己的图案

1. 进入 Design 或 Pixel Coloring，画布尺寸自动匹配设备屏幕（16x16 到 64x64）；
2. 点格子逐个上色，或用填充工具整块刷；
3. 画完先在应用里预览，确认后发送到设备；
4. 保存后在「我的作品」里随时再推送。

画动画建议先想好帧数再动手：简单的两三帧循环往往比十几帧的效果更耐看。滚动文字是「加字」最省事的方式，不需要会画画。

## 四、把照片放上屏幕

支持传图的型号（Times Frame、Pixoo-64 等）可以走应用里的上传功能：从相册选图，应用自动缩放成屏幕分辨率并做像素化处理。同一张照片在 16x16 的小屏上只剩轮廓，在 64x64 的屏上才看得出细节——传之前对效果有个预期，能省掉反复重传。

找不到想要的风格时，先去 [Divoom 应用介绍站](https://divoom.bpfl.quest/)把功能入口摸一遍，再回图库按分类翻，效率会高不少。
