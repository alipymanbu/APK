# ybox 收不到通知与设备离线排查

> 设备配好之后的日常麻烦就三类：推送一条没有、画面调不出来、设备显示离线。本篇按命中率给排查顺序。安装与配网的前置步骤见 [安卓客户端下载安装步骤.md](安卓客户端下载安装步骤.md) 与 [摄像机配网与添加设备.md](摄像机配网与添加设备.md)。

## 收不到移动侦测通知

按命中率排序：

1. **系统通知权限没开**：安卓 13 及以上把通知做成显式开关，装 App 时手一滑点了拒绝，App 就永远安静；
2. **省电策略杀了后台**：这是"打开 App 才看到推送、平时一条没有"的典型原因。把它的电池策略改成不优化，三星、一加、华为等深度定制系统还要把它移出"睡眠应用"列表；
3. **后台数据被禁**：允许后台流量，开了省流量模式的把它加入不受限名单；
4. **位置权限被拒**：这类客户端的推送依赖位置权限读网络状态，位置关了推送也哑——最反直觉的一条；
5. **勿扰 / 专注模式**：会静默吞掉推送且不留提示，检查定时开关；
6. **设备端侦测没开**：设备设置里把移动 / 人形侦测打开，灵敏度别调最低。

## 设备显示离线

先看列表里的电量与信号数字：**数字还在刷新 = 设备活着**，只是休眠没醒，等几秒再刷新画面；数字陈旧不动才是真断线，对症查：

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 电池款离线 | 电量掉到临界值，主动断 4G 保命 | 取回满充一晚再挂回去；太阳能款查板子有没有被树枝遮住一条缝 |
| 4G 款反复离线 | 流量卡欠费 / 被休眠 / 当地无信号 | 把卡取出来插手机：能上网说明卡没问题，不能上网就是卡的事 |
| WiFi 款离线 | 断网、换了路由器 | 重启路由器；换宽带必须重新配网 |
| 信号一两格还常掉线 | 安装点在信号死角，或装在金属杆上 | 挪 1~1.5 米、天线朝天竖直，换位置比换设备管用 |

电量满、卡正常、信号也够还离线的，长按 reset 键硬重置一次，强制模组向最近的基站重新注册；重置后要重新配网绑定。

## 点开预览白等几秒

低功耗设备平时休眠，点开预览才远程唤醒，首帧等几秒不是卡了。画面转圈先从 HD 切回 SD；家里 WiFi 看也卡，多半是设备离路由器太远、穿墙太多。

更多功能说明与安装文件资源的获取入口，见 [ybox 使用说明站](https://ybox.fewz.tech/)。
