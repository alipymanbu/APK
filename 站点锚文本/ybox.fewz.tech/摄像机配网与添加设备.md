# ybox 摄像机配网与添加设备

> 本篇讲把太阳能摄像机、4G 电池摄像机、WiFi 门铃添加进 ybox 的两条配网路径，以及每一步失败时的排查点。还没装上客户端的，先看 [安卓客户端下载安装步骤.md](安卓客户端下载安装步骤.md)。

## 先分清设备走哪条路

配网路径取决于设备类型，看说明书或机身标识：

| 设备类型 | 配网方式 |
| --- | --- |
| WiFi 电池摄像机 / 太阳能款 / 门铃 / 全景款 | 扫二维码，连家里 2.4G WiFi |
| 中继套装 | 按 WiFi 流程，走中继信号 |
| 4G 无线电池摄像机 | 蓝牙发现，不连家里 WiFi |

入口在 App 首页"添加智能设备"，或设备列表右上角的加号。

## WiFi 设备：扫码配网

前提是手机连 **2.4G 频段**（5G 连不上，双频合一的路由器失败时可切访客网络试试），设备通电处于待配网状态（通常蓝灯闪烁）：

1. App 里选添加 WiFi 设备，等设备的语音提示"等待配网"；
2. 界面生成二维码，**拿设备镜头对准手机屏幕扫**，距离 15 厘米左右；
3. 屏幕亮度保持中间值——太亮反光、太暗读不出都会失败；
4. 听到提示音后等进度走完，给设备起名、标安装位置。

WiFi 名称能自动带出才说明位置权限正常；要手打 WiFi 名多半是权限没给，回安装篇把权限补齐。

## 4G 设备：蓝牙配网

前提是手机蓝牙已开，设备装好可用的流量卡并通电，状态灯**蓝灯常亮**（表示已注册运营商网络）：

1. 选"添加 4G 设备"，勾选蓝灯常亮点下一步；
2. 等蓝牙发现设备，弹出确认窗点"好"；
3. 设名称与位置，等绑定完成。

蓝牙搜不到时，兜底是扫设备机身的二维码绑定。提示"SIM 卡未检测""无可用网络服务"属流量卡侧问题：卡的方向与卡槽类型、欠费或被休眠、当地无信号，按这个顺序自检。

## 配网失败速查

进度卡住、灯一直红，按这几条来：

1. 长按设备 reset 键 4~5 秒重置，听到语音后从头再来；
2. 配网期间把设备挪到路由器 1.5 米内，成功后再装回原位；
3. 路由器开 DHCP，静态 IP 容易和这类设备冲突；
4. WiFi 密码注意大小写，特殊字符多就换 8~12 位纯字母数字再试。

装好之后点开预览要等几秒、收不到通知、设备显示离线，这些日常使用问题见 [收不到通知与设备离线排查.md](收不到通知与设备离线排查.md)；完整的界面与功能介绍在 [ybox 使用说明站](https://ybox.fewz.tech/)。
