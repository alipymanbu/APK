# ybox 安卓客户端下载安装步骤

> 本篇讲 ybox 安卓安装包从哪里拿、装到手机上的完整步骤，以及首次启动要逐项允许的权限。装好之后的配网添加设备，见 [摄像机配网与添加设备.md](摄像机配网与添加设备.md)。

## 装之前先核对两件事

ybox 是给太阳能摄像机、4G 无线电池摄像机、WiFi 门铃这类低功耗设备当"手机端"的专用客户端，单独装在手机上没有用处。动手前先核对：

1. **设备说明书指定的是不是它**。同一生态里还有个外观接近的 UBox，设备与 App 是配对关系，装错了扫不出设备；
2. **手机留够空间**。安装包 1.1.241 版约 120 MB，装好后占用更大，空间紧张先清一清。

## 下载与安装四步

1. 打开 [ybox 使用说明站](https://ybox.fewz.tech/)下载页给出的安装文件资源入口，把安装包转存到自己的网盘账号后下载到手机；
2. 在文件管理器里点开 APK，系统提示"禁止安装未知来源应用"时按提示放行——这是安卓对第三方安装包的常规拦截；
3. 等进度走完点"打开"，首次启动的权限申请逐个允许；
4. 用邮箱注册账号，去邮箱点验证链接完成验证后登录。

## 首次启动的权限清单

| 权限 | 不给会怎样 |
| --- | --- |
| 网络 / 蜂窝数据 | 设备添加直接失败 |
| 位置 | 配网带不出 WiFi 名，收不到侦测推送 |
| 通知 | 设备被触发时手机毫无提醒 |
| 存储 | 抓拍与录像存不进相册 |
| 麦克风 | 双向对讲说不出声音 |
| 相机 | 扫机身二维码添加失败 |

安装被拦截、验证邮件收不到这类挡路问题的处理办法，以及更多功能说明，都整理在 [ybox 使用说明站](https://ybox.fewz.tech/)的下载安装页，配好设备后回 [摄像机配网与添加设备.md](摄像机配网与添加设备.md) 继续设置。
