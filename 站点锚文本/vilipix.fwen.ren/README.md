# vilipix 插画世界介绍页

vilipix（插画世界）是一款安卓上的插画浏览应用，作品覆盖插画、漫画、小说三类，支持榜单追热门、长按存图设壁纸，也能向开放约稿的画师定制头像与立绘。这里整理它的 [vilipix 插画世界介绍与安装指引](https://vilipix.fwen.ren/)，从功能一览到安装步骤都能查到。

## 本目录文章

- [怎么保存图片和设置壁纸.md](怎么保存图片和设置壁纸.md)：存图的两种路径、画质怎么挑、存完怎么设成壁纸头像。
- [怎么向画师约稿.md](怎么向画师约稿.md)：五步走完一次约稿申请，以及约稿详情里要核对的内容。
- [和P站的区别与常见问题.md](和P站的区别与常见问题.md)：它是不是 P 站、排序要不要会员、打不开怎么排查。
