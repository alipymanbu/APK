# vilipix 插画世界和P站的区别与常见问题

> 本篇回答关于插画世界最常被问到的几个问题：它是不是 P 站、搜索排序要不要会员、图片保存到哪了、打不开怎么排查。
> **相关文档**：[怎么保存图片和设置壁纸.md](怎么保存图片和设置壁纸.md) · [怎么向画师约稿.md](怎么向画师约稿.md)

vilipix（插画世界）是一个面向插画爱好者的安卓应用，内容分插画、漫画、小说三类。围绕它的几个高频疑问，这里一次说清。

## 一、它就是「P 站」吗？

不是。插画世界聚合了大量画师作品，把高清插画整理好供用户直接浏览、下载与收藏，省去了访问门槛，但它并非 Pixiv 本站，账号体系、评论互动也与本站无关。可以把它理解成一座「随身画廊」：作品来自全球众多画师，逛图、存图、约稿都在这一个应用里完成。

## 二、搜索能搜什么，排序要会员吗？

搜索框支持作品名、角色名、标签、标题，也能按标签搜小说、直接搜画师名。几个提高命中率的习惯：

1. 先用中文名搜，没结果再换原语言名或罗马音；
2. 搜角色时把作品名一起带上，挤掉同名干扰；
3. 搜完点标签页进标签聚合，往往比继续换词更快。

按人气排序搜索结果属于高级会员功能；免费账号按默认顺序浏览完全够用，善用榜单与标签页基本不受影响。

## 三、图片存到哪了？

默认在系统相册（多归在「下载」或应用专属相册下），按时间倒序翻最快；相册没有就说明权限被拒或那次下载中断了，重新授权后再长按保存一次即可。

## 四、打不开、一直转圈怎么排查

按顺序做四件通用检查，多数问题都能定位：

| 症状 | 先做什么 |
| --- | --- |
| 首页空白、一直加载 | 换 Wi-Fi 或切流量再开 |
| 提示错误、频繁失败 | 等几分钟再开，服务端抖动时重试比反复杀进程有效 |
| 打开就闪退 | 清应用缓存；仍闪退则重装 |
| 只有图片不显示 | 查存储空间是否不足，清理后再试 |

版本过旧也可能与服务端对不上，重装一份较新的安装包往往直接解决，入口见这份 [vilipix 插画世界介绍与安装指引](https://vilipix.fwen.ren/)。

## 五、多版本号怎么分辨

不同页面上标着 4.8.8、4.9.8、5.0.0 等各种版本号，页面数字不等于手机里装的。以「设置 → 应用管理 → 插画世界」显示的版本为准；想确认某个安装包的版本，看文件名里的版本号并结合文件大小比对即可。
