# vilipix 插画世界怎么向画师约稿

> 本篇讲刷不到心仪作品时，怎么在插画世界里挑一位可约稿的画师、读懂约稿详情并提交申请，以及提交前后要留心的几件事。
> **相关文档**：[怎么保存图片和设置壁纸.md](怎么保存图片和设置壁纸.md) · [和P站的区别与常见问题.md](和P站的区别与常见问题.md)

约稿就是按自己的需求（头像、立绘、人设图等）向画师下一笔定制委托，画师按约定交付。它适合「刷了半天就是没有想要的那张」的场景——与其继续搜，不如直接说清楚要什么。整个流程在应用内就能走完。

## 一、五步提交申请

1. 进入「画师」界面，点右上角的「可约稿」页签；
2. 挑一位满意的画师，进入 TA 的主页；
3. 切到主页里的「约稿」页面，选约稿类型；
4. 仔细读「约稿详情」——流程、价格、周期都写在里面；
5. 滑到页面最底部，点「向 ta 申请约稿」。

前两步是筛选，第三四步是确认，第五步才是提交。**别跳过第 4 步**，价格、周期、交付张数全写在那里。

## 二、约稿类型怎么选

常见可选类型有头像、半身像、立绘、人设 OC（具体以画师主页显示为准，不同画师开放的类型不一样）：

| 类型 | 通常用途 |
| --- | --- |
| 头像 | 社交账号头像、群头像 |
| 半身像 | 带构图的个人主页图 |
| 立绘 | 完整人物立绘、OC 展示 |
| 人设 OC | 原创角色设定图 |

## 三、约稿详情里要核对什么

- **流程**：申请后怎么沟通、什么时候出草稿、怎么确认终稿；
- **价格**：该类型的报价，以及付款比例（如有）；
- **周期**：从确认到交付预计多久；
- **画风**：画师开放的风格范围与你的预期对不对得上。

价格与周期由画师自行定价、会随调整变化，以打开详情页时的显示为准。

## 四、提交前后的提醒

1. **先看作品再下单**：主页作品区是真实水平的样本，风格不合就换一位，别只看价格；
2. **需求写具体**：构图、配色、用途、交付格式说清楚，返工少一半；
3. **在应用内沟通**：聊天记录留在平台里，出分歧时有据可查；
4. **警惕场外骗局**：凡要求屏幕共享、让先付「测试金 / 保证金」再返款、催着删聊天记录的，一律终止——真被骗了保存好凭证立即报警；
5. **未成年人约稿**：先让家长知情同意，家长也要留意免密支付的额度。

浏览与存图不需要花一分钱，先逛再定更稳妥；想先体验这个应用，可以看这份 [vilipix 插画世界介绍与安装指引](https://vilipix.fwen.ren/)。
