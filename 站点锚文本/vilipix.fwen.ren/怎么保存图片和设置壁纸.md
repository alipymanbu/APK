# vilipix 插画世界怎么保存图片和设置壁纸

> 本篇讲在 vilipix（插画世界）里看中一张插画后，怎么把它存进手机相册、画质怎么挑、存完又怎么设成壁纸或头像。
> **相关文档**：[怎么向画师约稿.md](怎么向画师约稿.md) · [和P站的区别与常见问题.md](和P站的区别与常见问题.md)

在插画世界里找到心仪作品只是第一步，把图真正留下来才是多数人的目的。存图有两条路径，效果一样，差别只在于能不能挑画质。

## 一、两种保存方式

**路径 A：详情页下载按钮**

1. 点开图片进入详情页；
2. 点页面中的「下载」按钮；
3. 完成后到系统相册里查看。

**路径 B：长按图片保存（可挑质量）**

1. 在图片上长按，弹出菜单；
2. 选「保存图片」；
3. 选「图片下载质量」；
4. 点「立刻下载」；
5. 稍等片刻，图就存进了本地相册。

想拿原图当壁纸就走路径 B 选最高档；只是发群里当参考图的话，中低档更省空间。

## 二、画质与构图怎么挑

| 选择 | 适合场景 |
| --- | --- |
| 高清 / 原图 | 设壁纸、放大看细节、二次构图 |
| 中低档 | 当头像、聊天参考图 |

竖构图的图适合直接当手机壁纸；横构图更适合电脑壁纸或社交平台配图。下载前先看一眼长宽比，能省掉不少无效保存。

## 三、存完怎么设成壁纸或头像

1. 打开手机相册，找到刚保存的那张；
2. 点「更多 / 设为」，选「设为壁纸」或「设为头像」；
3. 按系统提示裁剪、预览、确认。

部分版本在详情页里也提供了直接设壁纸 / 头像的入口，两个入口效果一样，哪个顺手用哪个。

## 四、两件容易踩的事

1. **权限**：保存时若弹出「允许访问相册 / 存储」，记得选允许；拒绝了图就进不了相册，需要到系统设置里把权限改回来再重存。
2. **版权**：每张图都带作者信息，作品页会标明是否可商用；标注不可商用的图只能自己欣赏，别拿去发布或当商业素材。

收藏与下载的分工也值得知道：收藏留在账号里、换设备还在，下载落到本地、不依赖账号。建议两边都做——收藏当书签，下载当备份。想亲手装一个试试，可以看这份 [vilipix 插画世界介绍与安装指引](https://vilipix.fwen.ren/)。
