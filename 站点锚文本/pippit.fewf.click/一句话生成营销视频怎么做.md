# 一句话生成营销视频怎么做

Pippit 的视频生成接受三类输入：一句话描述、一个商品链接、一份已有素材。三条路的准备工作不同，成片的还原度也不同，先选对起点能省掉大半试错成本。本文把三种起点、两种模式与模型选择的思路一次讲清；软件的整体定位与安装入口见 [Pippit 功能与安装资源介绍](https://pippit.fewf.click/)。

## 三种起点怎么选

| 起点 | 适合场景 | 要准备什么 |
| --- | --- | --- |
| 一句话描述 | 手里什么都没有，只想要一条能看的片 | 把「谁、在哪、做什么、什么调性」写进提示词 |
| 商品链接 | 有现成商品页，想直接变成推广视频 | 链接需可公开访问，TikTok Shop、Shopify、Amazon 三家支持最好 |
| 上传素材 | 已有图片、短视频或文档 | 图片、视频、PPT／PDF 都可以，一次大致能挂 9 张图、3 段视频 |

三类可以混用：贴了链接再补一句提示词，或上传几张图再描述要什么，结果通常比只给一句话更贴近预期。

## 两种模式与模型选择

模式上先做一个取舍：Lite 求快，适合直接要一条能发布的广告片；Agent 可调项更多，适合对脚本、画面、数字人、音色有具体要求的场合。拿不准就先用 Lite 跑通一遍，看到成品再决定要不要换 Agent 重做，这样最省额度。

模型方面，新品与版本号会随更新变化，以应用内当页显示为准。实用的挑法是先用快速档出草稿，满意了再换高质量档重出——直接上最高档反复微调，是额度消耗最快的方式。

## 比例、时长与导出

生成前先定画面比例：16:9 对应横屏平台、9:16 对应竖屏短视频、1:1 方图与 4:3偏电商构图。先想好发到哪再选比例，生成完再裁会损失构图。时长上以单段 5 到 12 秒为主，长视频的做法是分段生成再拼接。

导出时可选分辨率（480p 到 1080p，付费档可放大到 2K／4K）、格式（MP4／MOV）与帧率。免费账号导出的成品带平台水印，这一点在排期前先确认。

## 结果不理想时的调整顺序

1. 提示词太笼统 → 补上主体、场景、光线、镜头感；
2. 素材太单一 → 多给几张不同角度的图；
3. 模型不对 → 换更高质量档重出；
4. 还不行 → Lite 换 Agent 重来。

商品图的生成逻辑与视频相通，把主体、构图、光线、风格四项写清楚，出图稳定性会明显变好，具体见 [商品图与海报批量出图](商品图与海报批量出图.md)。
