# 音游引擎平台是什么：把节奏游戏拆成「引擎 + 服务器」

> Sonolus 是一个音游引擎平台，而不是某一款固定的音游。这篇讲清它的定位、内容从哪来、适合谁，以及「打开一片空白」为什么不是故障。

## 一句话定位

常见音游把玩法、曲目、判定打包在一个应用里卖更新；Sonolus 把这三件事拆开：

- **玩法 = 引擎**：引擎以脚本形式存在，性能足够跑各种想象得到的音游玩法——从经典下落式到异形轨道、多点触摸，都能作为引擎接入；
- **内容 = 服务器**：曲目、谱面、排行榜、回放全部由服务器提供，本体一个都不内置；
- **客户端 = 运行环境**：安卓应用只负责把判定、回放、皮肤这些骨架做到位，换服务器就换一套玩法与曲库。

同一个客户端可以同时挂多个服务器，每个服务器通常对应一套玩法或一个社区的曲库，点哪个进哪个。

## 装完打开是空的，正常吗

正常，而且是这个平台的设计使然：刚装好时服务器列表里至多只有几个预置入口，内容非常有限——这不是安装包的问题，「有没有内容」从来不取决于装的是哪个包。自己动手把社区服务器接进来，首页立刻就不一样了。具体操作见 [社区服务器添加与自制谱面入门](社区服务器添加与自制谱面入门.md)。

## 它适合谁

- 想玩社区自制谱、追冷门曲目的音游玩家；
- 想在同一台手机上体验多种音游玩法、而不是为一款玩法装一个应用的人；
- 想自己做谱、把自己的作品发布给社区玩的创作者（做谱走网页端编辑器，同样见上面那篇）。

## 平台特性速览

| 特性 | 说明 |
| --- | --- |
| 脚本驱动 | 引擎即脚本，任何玩法都能被实现成引擎跑在客户端里 |
| 多服务器 | 一个客户端挂多个服务器，玩法与曲库随服务器切换 |
| 回放与排行 | 每局可回放复盘，榜单由所在服务器维护 |
| 收藏离线 | 关卡详情页点「保存」，断网也能从收藏夹打开常玩的歌 |
| 界面可定制 | 主题、皮肤、背景、流速逐项可调，手感随时改 |
