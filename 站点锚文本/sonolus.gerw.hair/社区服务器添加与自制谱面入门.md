# 社区服务器添加与自制谱面入门：接内容源、找关卡、做谱投稿

> 装好客户端只是第一步：曲目、排行、回放全在服务器上。这篇讲服务器地址从哪拿、怎么接、进去后怎么找歌，以及想自己做谱时整条创作与投稿链路长什么样。

## 一、服务器地址从哪拿

三条路，按省事程度排：

1. **社区服务器列表页**：社区维护的列表站按游戏 / 社区分类给出地址，点复制即可；地址可用性以列表页当时显示为准；
2. **邀请链接直加**：不少服务器提供 `open.sonolus.com` 形式的链接，手机浏览器点开会直接唤起应用并停在添加页，确认保存即可；
3. **手动填地址**：知道服务器域名时，在「自定义服务器」表单里手动粘贴，格式与字段说明可查社区百科的自定义服务器规格页。

## 二、手动添加的步骤

1. 首页点 **开始**，进入服务器选择页；
2. 找到 **自定义服务器** 一栏，点它下方的 **添加**（别点到「收藏夹」下面的添加，那是另一个入口）；
3. 表单里**名称**随便写（只是自己的备注），**地址**粘贴服务器链接，确认；
4. 应用连上服务器读取信息后，可改显示名，下一步即完成；
5. 回列表点刚加的那一项即可进入。

同一个客户端可以挂多个服务器，每个对应一套玩法或一个社区的曲库。

## 三、进去后怎么找想打的谱

- 进服务器点 **关卡**，首屏是最近或推荐的一批，点 **更多** 看全量，或用放大镜搜索；
- 搜索认**曲名原文**：日文歌打日文、英文歌打英文，中文译名与罗马音经常搜不中；
- 同一首歌的不同歌手、不同难度会拆成多个关卡，点开前看关卡信息确认；
- 第一次玩先点 **配置** 把流速调顺手，再开始。

想不联网也能打：在关卡详情页点 **保存** 收进收藏夹，资源就留在本地，断网也能从收藏夹打开常玩的歌。

## 四、自己做谱：网页端编辑器 + 审核发布

做谱不在手机应用里，而是用网页编辑器（手机、电脑浏览器都能开）：

| 工具 | 用途 |
| --- | --- |
| Horizon Editor | 通用谱面编辑器，支持实时预览 |
| Next SEKAI Editor | 针对特定玩法，可直接打开 `.sus`、`.usc` 老谱文件 |
| Sonolus Studio | 制作皮肤、背景、音效、粒子等素材 |

流程上：导入音频、定准 BPM 与起始偏移（这两项错了整张谱都会漂）→ 摆音符、调速度曲线 → 保存得到关卡数据文件。发布是**审核制**：在目标服务器的关卡区新建（先成草稿，可发给别人试玩收意见），改完提交审核，通过才会公开；被拒时按审核意见改完再提交。投稿前先读目标服务器的规范页——音频格式、封面尺寸、元数据完整性这些硬性条目各家不完全一样。

## 五、连不上或搜不到时

- 连接失败先**换线路**（同一服务器常配多条线路），换哪条都失败多半是服务端在维护，隔段时间再试；
- 粘贴地址多了空格、少了斜杠都会连不上，回表单核对；
- 提示**引擎不兼容**：服务器还在旧引擎上，1.x 客户端只认新引擎，换服务器或等作者适配；
- 装包与首次设置的问题回到 [安卓版怎么装与首次设置](安卓版怎么装与首次设置.md) 对照排查。

平台整体介绍与界面预览见 [音游引擎平台是什么](音游引擎平台是什么.md)，或直接逛 [Sonolus 资料站](https://sonolus.gerw.hair/)。
