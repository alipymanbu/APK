# 导出格式怎么选，字体丢了怎么修

> 生成得再顺，卡在导出上也是白做。这一篇讲 PPTX、PDF、图片、分享链接四种产出各适合什么场合，可编辑文件为什么常常拿不走，以及下载到本地后字体变了、元素错位的成因和修法。

整条使用链路（从输入主题到生成成品）的图文拆解收录在 [AiPPT 使用拆解站](https://aippt.yoan.quest/)，这一篇只解决「成品怎么拿走、拿走后走样了怎么办」这两件事。

## 一、四种产出，按用途选

支持的导出格式有 PPTX、PDF、PNG、JPEG，另外能生成在线分享链接（发给别人在浏览器里直接看，不必下载文件）。

| 你的目的 | 选哪个 |
| --- | --- |
| 还要继续改内容 | PPTX |
| 只要对方看到最终样子 | PDF 或图片 |
| 让对方在浏览器里直接看 | 在线分享链接 |
| 发朋友圈、贴进聊天 | PNG / JPEG |

选择逻辑一句话：**要改拿 PPTX，只看选 PDF，图省事发链接。**

## 二、「能生成」和「能拿走」是两件事

免费状态能生成、能预览，但下载可编辑的 PPTX 通常需要订阅。所以判断要不要付费，最直接的测试是：用免费额度把一次完整流程走到导出那一步，看看限制卡在哪，再决定。

还有一个和会员无关的常见误判：**下载类型选错**。想要能二次编辑的文件，下载类型必须选 PPT——选成 PDF 或图片，拿到手的就是不可编辑的成品。这类「改不了」先检查下载类型，别急着归因到账户权限。

## 三、字体变了、元素错位的成因与修法

下载到本地后版式乱了，多半不是文件坏了。成因有二：字体没嵌进文件，或者打开文件的电脑上没装那款字体。字体一缺，系统换一款替代字体渲染，字宽不同，原本排好的行就会挤出去或断开，看起来就是「元素错位」。

两条修法：

1. 用编辑器里的**一键替换字体**，把成品里的字体统一换成本机有的；
2. 先在本机**装上那款字体**，再打开文件。

顺带一条经验：幻灯片要在别人的电脑上放映（会议室、客户现场），**导出前就把字体换成最通用的几款**，比到了现场再发现缺字体强得多。

## 四、跨软件打开的预期

产品方并没有承诺导出文件在其他软件里版式分毫不变。跨软件使用的场合，PDF 通常比 PPTX 稳（只保版式，不保留可编辑性）。导出后先在自己电脑上完整打开一遍，重点看标题行、图表和带底色的文本框这三处。

另外值得记一条：订阅到期后，线上作品可能就无法继续访问了。要留档的东西，趁有效期内导出到本地，别把成品只存在云端。
