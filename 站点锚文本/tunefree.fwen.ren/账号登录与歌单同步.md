# TuneFree 介绍站·账号登录与歌单同步

> 登录方式有哪几种、登录后哪些数据会跟着账号走、换设备后歌单怎么找回。
> **相关文档**：[安卓版下载安装教程.md](安卓版下载安装教程.md) · [变色主题与音质歌词设置.md](变色主题与音质歌词设置.md)

## 一、不登录能用，登录更完整

TuneFree 不登录也能搜歌、播本地歌曲；但下面这些能力要登录后才完整：

- **歌单同步**：账号里建的歌单、收藏的歌单，换设备登录后原样出现；
- **红心收藏**：播放页点的小红心都归入「喜欢」，跨端可见；
- **云盘歌曲**：存在云盘里的曲目跟着账号走；
- **听歌记录**：各端合并，每日推荐与私人FM的结果也会更贴口味。

只在一台手机上听，可以先用着；一旦换机，或还想在电脑端接着听，就值得登一次。

## 二、四种登录方式怎么选

登录页一共给了四条路：**验证码登录、二维码登录、手机号登录、UID 登录**。

推荐优先**扫码**：打开网易云 App 扫一下并确认就行，不用输密码，也绕开了验证码收不到、频率限制这类麻烦。二维码有时效，过期就刷新再扫。登录态会保留一段时间，不必每次打开都重登；掉登了重新走一遍即可。

## 三、同步的边界在哪

把「什么跟着账号、什么留在本机」分清楚，能省掉大部分「歌单怎么没了」的困惑：

| 数据 | 是否随账号同步 | 说明 |
| --- | --- | --- |
| 歌单、红心、云盘曲目 | 是 | 跨端登录后可见 |
| 听歌历史 | 是 | 各端合并 |
| 手机本地音频文件 | 否 | 只存在设备上，换机自己拷 |
| 应用设置（主题、音质档） | 否 | 存在本机，换机重设 |

两个常见落差：A 手机加的红心在 B 手机没立刻出现——同步发生在登录与刷新时，退出重登或下拉刷新即可；本地歌曲列表换机后是空的——本地栏目读的是设备文件，把音频拷过去重新扫描就好。

## 四、换号与退登

设置或个人页里退出登录即可切号。退出只影响云端数据的读取，不会删手机里的本地文件；但歌单、红心这类云端内容会暂时不可见，换账号登录后显示的是新账号那份。多账号轮着用的话，先想清楚哪边是主用账号。
