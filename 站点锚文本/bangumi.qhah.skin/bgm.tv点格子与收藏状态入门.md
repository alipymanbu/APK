# bgm.tv点格子与收藏状态入门

「点格子」是 bgm.tv 圈子的黑话，指给「在看」的条目逐集打卡：看完一集点一格，进度就写进了账号。这篇从账号讲到格子，把新手上手的整条路走一遍。

**相关文档**：[追番进度管理工具怎么挑.md](追番进度管理工具怎么挑.md) · [新番时间表在哪看.md](新番时间表在哪看.md)

---

## 第一步：账号在网页端注册

bgm.tv 的账号体系在网站侧，客户端里没有注册入口。用浏览器打开 bgm.tv（入口域名有 bangumi.tv、bgm.tv、chii.in 几个），填邮箱注册，收到激活码后尽快填回页面完成激活——激活码有时效，过期要重来。涉及账号的操作尽量用 https 域名走，避开验证码循环这类老问题。

## 第二步：客户端里授权登录

装好客户端后，在「我的」页面点登录，它会拉起 bgm.tv 的授权页面，确认授权后回到客户端。登录页有个「不保存登录状态」的选项容易理解反，勾选状态留意一下，选错就会每次打开都掉登录。收藏、评分、进度全存在服务端，掉登录不丢数据，重新授权即可。

## 第三步：五种状态标起来

在任意条目页，把作品标进五类之一：

| 状态 | 什么时候用 |
| --- | --- |
| 想看 | 听说不错，先占个位 |
| 在看 | 正在追，每更新一集点一次格子 |
| 看过 | 整部看完，可以打分写短评 |
| 搁置 | 追到一半暂时放一放 |
| 抛弃 | 明确不看了 |

入坑建议：把片单先全部标「想看」，每周从里面挑几部转「在看」，列表才不会失控。

## 第四步：点格子

「在看」状态的条目会显示分集列表，每集前面有一个格子。看完一集点一格，客户端把「看到第几话」记进账号，网页端立即可见。顺手还能做两件事：给条目打 1~10 的整数分；点格子时带一句进度吐槽，出现在关注你的人的时间线上。

## 手机之外，网页端是一样的

手机没电或在电脑前，直接开 bgm.tv 网页版做同样的操作，数据完全互通。客户端的强项是快速点格子与碎片时间刷动态；写长评、做条目维基编辑，网页端更顺手。

这些动作在专门的安卓客户端里最快。czy0729 开发的那版开源客户端为移动端重做了 100 多个页面，功能拆解与安装入口见 [Bangumi 追番客户端介绍站](https://bangumi.qhah.skin/)；标好「在看」之后，配合 [新番时间表在哪看.md](新番时间表在哪看.md) 把一周的更新排成表，追番节奏就立起来了。
