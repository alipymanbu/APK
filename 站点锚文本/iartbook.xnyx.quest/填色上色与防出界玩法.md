# iArtbook 填色上色与防出界玩法

> 汇总 iArtbook 里几种填色入口与上色方式，以及颜色总涂出线稿的三个补救办法——填色玩家的上手篇。

iArtbook 的填色板块是整套应用门槛最低的部分：不用自己起稿，选一张线稿就能开涂。这篇按「入口 → 上色方式 → 防出界」整理，适合刚装好的时候对照着玩。

## 一、填色内容从哪进

| 入口 | 里面是什么 |
| --- | --- |
| 画册 | 各主题的填色页，题材多且会更新 |
| 探索（部分版本在底部标签） | 解压填色；切到「数字填色」分类按编号挑线稿 |
| 像素 | 像素风线稿，一格一格涂，考验耐心 |

入口名称随版本略有出入，找不到某个板块就说明这版没带，不必硬找。

## 二、三种上色方式

1. **点按填色**：选好颜色直接点目标区域，整块填上，最省事；
2. **质感涂色**：用记号笔、铅笔这类笔刷手动涂，笔触更接近在纸上涂色；
3. **色桶拖拽**：按住色圈拖到画布上松手，当前颜色填充目标区域。

调色板可以整套换：预设四十多套纯色与渐变配色，点一套就换一批搭配好的颜色，不必一个个调；也可以把常用色存成自建调色板并命名，画系列图时用色更统一。

## 三、颜色涂出界怎么办

按省事程度排序：

1. **上色层垫到线稿下面**：新建一层用来上色，拖到线稿图层**下方**——上层优先显示，线稿自然压住颜色，治本；
2. **先圈选再填**：用套索沿要涂的封闭区域圈一圈，再切到油漆桶填充，颜色只落在选区内；
3. **扩展像素参数**：新版本的填充工具带「扩展像素」，线稿缝隙闭合不严时用它减少外溢（老版本没有这一项）。

涂完还能加后期：渐晕、轮廓样式、纹理与滤镜都在涂色页的编辑区里；成品从应用导出到相册即可。
