# iArtbook 安卓版下载与安装步骤

> 讲怎么把 iArtbook 的安卓安装包拿到手、顺利装进手机：从网盘转存到允许安装，四步走完，再附三个最常挡路的问题。

想在安卓手机上用上 iArtbook，一般不是从应用商店直接点装——更多人是拿着一个网盘分享来取安装包。整个过程分成四步，每步都不复杂，照着走即可；图文更全的版本见 [iArtbook 画室笔记](https://iartbook.xnyx.quest/) 站点里的下载页。

## 一、安装前的三个核对

| 项目 | 建议 |
| --- | --- |
| 系统版本 | 安卓 5.2 及以上，低于该版本安装时会直接报不兼容 |
| 存储空间 | 安装包约 200.88M，解包阶段临时占用更大，建议留 1GB 以上余量 |
| 应用身份 | 认准包名 `com.tktn.ycfn` 的中文版，别和同名英文绘画应用搞混（辨别方法见[同名绘画应用怎么区分](同名绘画应用怎么区分.md)） |

## 二、从分享到安装的四步

1. **转存分享文件**：打开分享链接，登录网盘账号，把 APK 转存到自己网盘——转存之后就不受原分享状态影响；
2. **下载 APK 到手机**：从自己的网盘把安装包下载进手机存储，完成后在通知栏或文件管理器的「下载」目录里找到它；
3. **允许这一次安装**：首次点开 APK 会跳到「允许此来源应用安装」页面，把对应来源（浏览器或文件管理器）的开关打开再返回；
4. **安装并首次启动**：点「安装」等进度走完，点「打开」进入应用，同意隐私政策后即可使用。

部分国产系统装完还会再弹一次「确认安装」，属于系统行为，正常确认即可。

## 三、最常挡路的三个问题

- **提示「禁止安装未知来源应用」**：进系统设置 → 应用 → 特殊权限 → 安装未知应用，给刚才那个来源打开「允许安装」，再重新点 APK；
- **提示空间不足**：先清出 1GB 以上余量，200M 的安装包解包时需要的临时空间比它自身还大；
- **提示解析失败或不兼容**：多半是文件没下完整（体积明显偏小），重新下载一次；再核对安卓版本是否达到 5.2。

装好之后别急着画：先认一遍界面板块与常用手势，顺手很多；填色玩家可以直接看[填色上色与防出界玩法](填色上色与防出界玩法.md)。安装入口与更细的图文步骤，都在 [iArtbook 画室笔记](https://iartbook.xnyx.quest/) 的下载与安装页里。
