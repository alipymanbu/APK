# iArtbook 同名绘画应用怎么区分

> 搜「iArtbook」会同时冒出好几款完全不同的应用，这篇讲清楚怎么认准想找的那一款，避免教程对不上、装错包。

「iArtbook」这个名字至少被三款应用用过：一款是英文的专业绘画软件（版本号到 10.x，主打无限图层与 Apple Pencil），一款是安卓上的轻量涂鸦工具（包名 `risko.digitalpaint`），还有一款是中文界面的「绘画工作台 + 填色册」二合一应用。三款界面、玩法、甚至平台都不一样，搜教程时发现完全对不上，八成就是撞名了。

## 一、最可靠的核对办法：看包名

| 特征 | 中文安卓版（多数人要找的） |
| --- | --- |
| 包名 | `com.tktn.ycfn` |
| 版本号形态 | 2.x（如 2.2.7） |
| 界面 | 中文，「画册 / 创作 / 像素 / 我的」等板块 |
| 出品方 | 深圳市征弘科技有限公司 |

英文专业版的包名以 `com.` 开头但出品方不同，安卓轻量款的包名则是上面提到的 `risko.digitalpaint`。核对包名是唯一不踩坑的办法，看图标和应用名都靠不住。

## 二、三个快速印象

- **中文安卓版**：一套界面两种玩法——正经的绘画工作台（图层、笔刷参数、稳定器）加上门槛很低的填色与像素涂色，还带逐帧动画工作台；
- **英文专业版**：面向 iPad 用户的深度绘画工具，配合 Apple Pencil 使用，手机端体验有限；
- **轻量涂鸦款**：功能简单，随手涂鸦够用，想系统画画或玩填色就不够看了。

## 三、确认身份之后的动作

- 教程按包名对应的版本来跟，界面语言和板块名都对上了再照做；
- 想要中文安卓版的安装包，获取入口整理在 [iArtbook 画室笔记](https://iartbook.xnyx.quest/)，从那里的下载页进即可；
- 安装环节遇到问题看[安卓版下载与安装步骤](安卓版下载与安装步骤.md)，装好后的填色玩法见[填色上色与防出界玩法](填色上色与防出界玩法.md)。
