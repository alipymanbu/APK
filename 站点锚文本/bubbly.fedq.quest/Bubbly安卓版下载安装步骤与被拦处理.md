# Bubbly 安卓版下载安装步骤与被拦处理

Bubbly 是一款 AI 虚拟角色聊天应用，安卓端以 APK 安装包形式获取。这篇把从网盘转存到完成安装的全流程走一遍，被系统拦下的处理办法也一并写清。

## 装之前确认两件事

- **安装包信息**：安卓端当前版本 1.11.1，包名 io.iftech.bubbly，体积约 105 MB，建议在 Wi-Fi 下下载；
- **登录方式**：手机号验证码登录，首次打开按提示填昵称和性别——这决定 AI 角色怎么称呼你。

## 五步安装流程

1. 打开 [Bubbly 介绍站的下载页](https://bubbly.fedq.quest/download.html)，点「获取安装文件资源」进入网盘分享页，先把安装包转存到自己的网盘账户，再从网盘下载到手机；
2. 在文件管理器里找到下载好的 APK 文件点开；
3. 第一次安装会弹「是否允许安装未知来源应用」，按提示给文件管理器授权，或去 设置 → 应用 → 特殊应用权限 → 安装未知应用 里打开对应开关；
4. 回到安装界面点「安装」，进度走完点「打开」；
5. 手机号登录后先进「消息」页挑一个现成的预设角色试聊，熟悉了再照字段建议捏自己的角色。

## 安装被系统拦下怎么办

安卓对商店外的安装包普遍会拦一道，各家叫法不同，思路都是「确认来源后放行」：

- 弹「高风险禁止安装」时，在弹窗里找「继续安装 / 仍要安装」；
- **华为 / 鸿蒙**拦得较严：设置顶部搜索「外部来源应用检查」，关掉「文件管理」的检查开关，回文件管理器重装；安装中途的风险提示同样选「继续安装」；
- 其他品牌弹窗没有放行选项时，走 设置 → 应用 → 特殊应用权限（或「安全」）→ 安装未知应用，给文件管理器授权后重装。

## Lovemo 老用户的一句提醒

如果你是 Lovemo 的老用户，装好后应用会主动提示账号迁移，角色人设、聊天记录、余额都能搬过来。但迁移是**一次性、不可撤销的覆盖操作**——会清空 Bubbly 里现有的数据，最稳的顺序是先迁移、再开始玩。
