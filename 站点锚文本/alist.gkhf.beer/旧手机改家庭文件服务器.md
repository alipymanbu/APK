# 旧手机改造成家庭文件服务器

换机后留下的旧安卓手机，性能跑不动大型应用，插电连 WLAN 常驻做一台家庭文件服务器却绰绰有余。不需要买 NAS、不需要软路由，装一个 AListLite 客户端就能把 AList 服务端跑起来——它是社区开发者基于 AList 做的安卓封装，界面点开关即用。

## 硬件准备：三样就够了

- 一台还能正常开机的安卓手机（建议安卓 5.2 以上，4.x 老设备有已知闪退问题）；
- 一根常供电的充电线，保持不离电；
- 稳定的 WLAN 环境，手机与日常使用的设备在同一局域网。

## 软件侧的关键设置

装好应用后，除了常规的启动服务、设 admin 密码、挂载存储三步，把旧手机当常驻设备用还要多做两件事，都在应用的设置页里：

1. **打开唤醒锁**：防止锁屏后 CPU 休眠导致服务中断（部分系统可能仍会杀后台，需配合下一项）；
2. **开启机自启动服务**：断电重启后服务自动回来，不用人工再点。

担心发烫的话，摘掉手机壳、别摞在密闭柜子里，长期运行的温度会好看很多。

## 改造完成后的家庭用法

- 手机本机目录挂进列表后，它就是一块局域网共享盘，照片、资料随存随取；
- 夸克、阿里云盘等网盘逐个挂上，家里的电视、电脑、平板访问的是同一个入口；
- 挂上 WebDAV 后播放器直接拉流，网盘电影免下载上大屏，细节见 [WebDAV电视播放网盘电影.md](WebDAV电视播放网盘电影.md)。

从安装到挂载的完整四步流程整理在 [手机搭多网盘文件列表服务.md](手机搭多网盘文件列表服务.md) 一文；应用本身的介绍与界面实拍，见 [alist 安卓端介绍站](https://alist.gkhf.beer/)。

一台吃灰手机换回一个家庭文件入口，这套改造的成本几乎为零，值得先拿旧机试跑一遍再决定要不要上专业设备。
