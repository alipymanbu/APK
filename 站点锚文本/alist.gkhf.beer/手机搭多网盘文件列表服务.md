# 手机上把几个网盘汇成一个文件列表

夸克、阿里云盘、115 各装一个 App，找一部剧要在三四个应用之间来回跳——这是很多人想集中管理网盘的起点。在安卓手机上跑一个 AList 文件列表服务，就能把这些分散的存储按目录汇到同一个网页里，浏览器打开、逐层翻看，路径直达。

## 为什么选手机而不是电脑

AList 本体是一个支持多种存储的开源文件列表程序，通常部署在服务器或 NAS 上；而 AListLite 客户端把它直接搬进了安卓手机——不需要 Root，也不需要 Termux 折腾命令行，装上应用、点一下开关，服务就在本机 5244 端口跑起来了。家里那台换了新机后闲置的旧手机，插上电连上 WLAN 就是现成的运行环境。

## 从启动到看到文件列表，一共四步

1. **启动服务**：打开 AListLite，点右上角开关，界面显示页面地址、IP 与端口即成功；
2. **设置管理员密码**：菜单里给 admin 账户设一个自己的密码，这一步别跳过；
3. **挂载存储**：网页后台进「管理 → 存储」，先加一个本机存储练手，再把夸克等网盘逐个挂上；
4. **局域网访问**：电脑或电视连同一个 WLAN，浏览器输入 `http://手机IP:5244`，文件列表直接出现。

支持的存储驱动覆盖本机目录、夸克网盘、阿里云盘、百度网盘、115、OneDrive、Google Drive、123 云盘、PikPak、迅雷云盘，以及 FTP / SFTP 协议，添加时各指定一个挂载路径即可。

## 两个第一次最容易踩的坑

- **锁屏后服务断了**：系统省电策略清理后台导致。把应用加入电池优化白名单，设置页打开「唤醒锁」，常驻设备再开启「开机自启动服务」。
- **别的设备打不开页面**：先确认同一 WLAN（访客网络不行），地址填手机局域网 IP 而不是 `127.0.0.1`，手机上别开代理或 VPN。
