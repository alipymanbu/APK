# fgo挂机权限与保活设置：让周回脚本锁屏也跑得住

> 本篇讲 FGA 运行所需的五项权限各自管什么、Android 13 侧载应用的无障碍限制怎么解除、
> 以及各品牌手机的保活设置要点与验证方法。
> **相关文档**：[fgo自动周回工具怎么选.md](fgo自动周回工具怎么选.md) · [fgo周回战斗配置入门.md](fgo周回战斗配置入门.md)

## 一、五项权限各管一摊

FGA 第一次启动会进设置向导，逐项来要权限。少一项脚本就跑不起来，先弄明白每项是干什么的，卡住时也好对症：

| 权限 | 干什么用 | 不给会怎样 |
| --- | --- | --- |
| 无障碍服务 | 模拟点击与滑动 | 脚本没有任何动作 |
| 悬浮窗 | 在游戏画面上显示播放 / 停止按钮 | 游戏里无法启动脚本 |
| 屏幕捕获 | 截屏识别当前界面 | 认不出自己在哪个画面 |
| 电池豁免 | 防后台服务被系统回收 | 跑一半自己停 |
| 存储 | 保存礼装图与配置 | 助战礼装等功能不可用 |

截屏授权每次启动服务都会弹一次（系统机制），点「立即开始」即可；设备已 root 的话，可在高级设置里改用 root 截图模式摆脱每次授权。

## 二、Android 13 的「受限设置」

侧载安装（不是从应用商店装的）应用在 Android 13 起默认不许开无障碍，开关是灰的、提示「受限设置」。处理路径：系统设置 → 应用 → FGA → 右上角菜单 → 「允许受限制的设置」，确认后回无障碍列表就能打开了。

## 三、保活：挂机挂不住的根源

锁屏后安卓省电机制开始削减后台，国产厂商在原生机制之上叠的自家「应用清理」更激进——挂机挂不住几乎都是这一层干的。无论什么品牌，先做三件通用设置：

1. **电池白名单**：电池设置 → 电池优化 → FGA 选「不优化」；
2. **最近任务加锁**：多任务界面把 FGA 卡片下拉加锁，防「一键清理」带走；
3. **关省电模式**：省电一开，前两条都可能被压回去。

品牌针对性设置举几个代表：小米在「应用管理 → 省电策略」选无限制并允许自启动；vivo 要单独开「后台高耗电」与自启动（默认全拦）；华为 / 荣耀在「应用启动管理」关自动管理、手动允许后台活动；三星把 FGA 加进「从不休眠的应用」。部分机型重启后限制会复位，挂机前扫一眼省电策略还在不在。

## 四、设置完怎么验证

跑一个十分钟实测，别等挂一夜才发现白挂：让脚本跑起来 → 锁屏十分钟 → 解锁看两处——**通知栏的前台服务通知还在不在**、**脚本还在不在打**。两处正常才算过关；通知没了是进程被杀，回第三节补设置；通知在而脚本停了，多半是截屏授权被回收，把服务关一次再开。
