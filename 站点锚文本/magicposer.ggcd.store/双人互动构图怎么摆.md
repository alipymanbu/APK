# 双人互动构图怎么摆

> 一句话：两个人以上的画面难在空间关系与互动接触点，本篇从剪影关系、接触点、道具与高度差四个角度整理摆法。
> **相关文档**：[画动态姿势参考怎么找.md](画动态姿势参考怎么找.md) · [漫画手部姿势怎么画.md](漫画手部姿势怎么画.md)

---

## 一、双人画面的三个难点

- **空间关系**：谁前谁后、间距多远，靠脑补很容易错。
- **互动接触点**：递物、拉手、对视，接触位置差一点，关系感就假。
- **注意力分配**：两个人都要有戏，画面又不能散。

照片素材在这类场景命中率最低——你几乎搜不到“角度、身高差、互动方式都刚好对上”的图，所以双人构图尤其适合自己摆出来看。

## 二、先定两个人的剪影关系

动手前先选一个基本关系型，常见三种：

1. **对立型**：两人朝向相对、重心对抗（争吵、对峙、竞技）。剪影上留出中轴空隙，张力靠距离。
2. **呼应型**：朝向一致或镜像（并肩、背靠背）。剪影可以做部分重叠，亲密感靠贴合。
3. **主从型**：一人主导动作，一人回应（教学、救助、追逐）。注意别让回应者变成“站桩”，回应有轻重之分。

选型之后再进细节，顺序别反——先抠脸再定关系，几乎必然返工。

## 三、互动接触点逐个落实

| 接触类型 | 要画准的东西 |
| --- | --- |
| 递物 / 接物 | 两只手的间距与物体交接线，视线落点 |
| 牵手 / 拉拽 | 手腕的扭转方向、两人重心的对抗 |
| 对打 / 格挡 | 受力点到脚底的传递线，格挡方的偏转 |
| 对视 / 回头 | 两人的视线高度差、颈部旋转幅度 |

这些点在平面上想不清楚，摆一遍立刻明白。做法：两个 3D 人偶同屏，先把主导者摆好，再摆回应者去“接”对方；有的工具还允许加道具和换服装，把刀、杯子这类互动媒介直接塞进手里试。具体的玩法整理见 [MagicPoser 的介绍页](https://magicposer.ggcd.store/)，多模型同屏加道具组合是它的常规用法。

## 四、高度差与道具：让构图立起来

- **身高差**：站同一条地平线检查——两人脚底应落在同一透视面上。俯视/仰视会放大或压缩身高差，构图时可故意利用。
- **坐立组合**：一坐一站比双站好看画，视线高度自然错开。
- **道具分摊**：让其中一人持物（伞、剑、包），道具的线条能引导视线、填补两人之间的空隙。
- **光影分开**：给两人不同的受光面，前后层次立刻拉开。

摆完别急着画：把视角压低到角色眼睛高度转一圈，确认每一格想给观众看的东西都在剪影里。
