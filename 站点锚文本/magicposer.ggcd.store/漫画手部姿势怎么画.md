# 漫画手部姿势怎么画

> 一句话：手是画面里最藏不住的地方，本篇整理手的几何概括法、常见手部姿态的参考路径，以及用预设省时间的办法。

## 一、手为什么难画

三个原因叠在一起：

- **关节多**：一只手 27 块骨头，每个指节都能独立动，组合数量爆炸。
- **比例敏感**：手画大一点就“抢戏”，画小一点就僵。
- **遮挡复杂**：握拳、持物时手指互相叠压，明暗关系乱。

对策也简单：先学会“概括”，再靠参考解决“具体长什么样”。

## 二、几何概括：三块积木

把手拆成三部分来理解，大部分姿态都能套上：

1. **手掌**：一个略扁的梯形或方块，厚度决定手的体量感。
2. **拇指根部**：连在掌侧的一块独立楔形，能大幅转动——它是手势表现力的关键。
3. **四指**：每根手指三段，注意“收拢时指尖指向手掌中心”这条规律，手指就不会张开得像扇子。

画漫画时可以先只画到这一层，约稿线稿再补细节。

## 三、常见姿态的参考路径

下面这些姿态几乎每部漫画都会遇到，各自有省事的参考办法：

| 姿态 | 参考办法 |
| --- | --- |
| 张开的手（打招呼、接东西） | 拍自己的手，正面手背各一张 |
| 握持（剑、笔、杯子） | 实物拿在手里拍照，注意拇指压在哪 |
| 比手势（剪刀手、比心） | 对镜子摆，注意指节的先后折叠 |
| 插兜 / 背手 | 看袖口与手背的衔接，重点画“消失点” |
| 牵手 / 拉拽 | 难度最高，建议两模型互动摆出来看 |

最后那一行，单靠照片很难找到刚好对上的角度。可以借助 3D 工具：[MagicPoser 的介绍页](https://magicposer.ggcd.store/)里提到它内置五十多个手部预设，握剑、比心、插兜这类姿态直接调出来再微调，比掰半天手指关节省事，也方便转到任意机位看遮挡关系。

## 四、一条练习路径

1. 每天画 3~5 组自己左手（非惯用手）的速写，两分钟一组，只画概括层。
2. 每周挑一个“难姿态”（牵手、持物对打），用参考工具或照片认真画一张。
3. 存一个“手部参考集”：把画对的手按姿态分类存档，下次直接翻。
