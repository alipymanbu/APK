# 内地观众赴港看演出准备清单

> 本篇面向从内地去香港（澳门同理）看演出的观众：出发前要把证件、支付、手机、安检这四件事逐项核对清楚，避免票在手里却进不了场。
> **相关文档**：[演出购票从选座到入场全流程.md](演出购票从选座到入场全流程.md) · [港澳演唱会门票在哪买.md](港澳演唱会门票在哪买.md)

## 一、证件：先确认是不是实名场次

不是每场演出都查证件。实名入场多见于粉丝向、高需求场次，主办方会在购票规则里写明「入场实名验证」：

- **实名场次**：购票时填的证件信息会印在电子票上，入场时人、票、证三者核对，填错基本等于废票；
- **非实名场次**：出示电子票扫码即可，一般不核对证件。

实名场次要带的证件（以场馆公布的入场安排为准）：

| 观众身份 | 需出示 |
| --- | --- |
| 内地观众 | 往来港澳通行证正本（含有效签注） |
| 香港观众 | 本地身份证件正本 |
| 经海外入境 | 护照正本（与购票登记同一本） |

三条铁律：

1. 必须是**实体证件正本**——复印件、照片、截图一律不认；
2. 购票时就填**将来带去现场的那本证件**，内地观众填通行证号码，别顺手填成身份证；
3. 通行证过期或签注用完的，**先把证件办好再购票**，否则票到手也进不去。

## 二、支付：提前验证一遍

港澳场次可用的支付渠道与内地平台不完全相同，常见有国际信用卡（Visa / MasterCard）、支付宝、微信支付与银联渠道，具体到某一场以下单页实际显示为准。出发前的功课：

- 没有国际信用卡的，先确认该场次的支付宝 / 微信支付入口可用再下单；
- 刷卡被拒多因银行默认关闭境外线上交易，去银行应用里打开即可；
- 开售高峰期支付容易卡，**热门场次开售前就把支付方式验证好**。

购票应用的选座、限购与实名填写规范，见 [演出购票从选座到入场全流程.md](演出购票从选座到入场全流程.md)；渠道怎么选，见 [港澳演唱会门票在哪买.md](港澳演唱会门票在哪买.md)。

## 三、手机：入场全靠它

电子票存在购票应用里，入场环节完全依赖手机：

1. **提前装好购票应用并登录**——以 uutix 为例，安卓用户可通过 [uutix 购票平台介绍](https://uutix.qjxz.skin/)了解获取方式，iOS 用户在 App Store 搜索安装；
2. **电量拉满**，充电宝带上（注意部分场馆对充电宝容量有限制，出门前查当日公告）；
3. **进场前先把票页打开**——闸口人多网络拥堵，现场刷新可能出不来；
4. 别只靠截图：部分场次的票码会动态刷新，现场出示应用内最新票码最稳。

## 四、安检：这些东西带不进去

香港演出场馆的常见口径（各场馆松紧不同，以当日公告为准）：

| 类别 | 常见规定 |
| --- | --- |
| 随身包 | 鼓励不带包；超过约 38×30×20 厘米的包通常禁入，无包观众常可走特快通道 |
| 摄影器材 | 专业相机、摄影录音器材禁入，演出中禁止拍照录像 |
| 常见禁物 | 长柄伞、自拍杆、折叠凳、外来食品饮料、玻璃瓶、喷雾与利器 |
| 流程 | 过金属探测器、开包检查；扫码进场后离场一般不得再入 |

实用建议：空手或只带一个小包（证件、充电宝、手机），安检快、也不用排队寄存。

## 五、出发前最后一遍清单

- [ ] 证件正本在身上，签注有效，与购票登记一致
- [ ] 购票应用已装好、已登录、电子票可见
- [ ] 手机满电，充电宝在手
- [ ] 场次时间、场馆名称再核对一遍
- [ ] 比开演时间提前约 1 小时到场（热门场次闸机排队很常见）

都打勾，就可以安心出发了。
