# 修改器连不上与游戏检测不到排查

## 一、先做最有效的三件事

社区里被反复验证过的处理顺序就是这三条，别跳着试：

1. **两端彻底重启**：手机端真正退出（不是划到后台），电脑端从系统托盘退出或用任务管理器结束全部进程——只关窗口经常留下残留进程，让新连接沿用旧状态；
2. **确认同一网络**：手机与电脑连同一个 WiFi，不开访客网络这类会隔离设备的选项，手机流量下必失败；
3. **确认防火墙放行**：Windows 防火墙第一次连接时会弹窗，勾选专用与公用两项再允许；当初点了取消的，进控制面板的「允许应用通过防火墙」补勾。

绝大多数卡在输 PIN 这一步的问题，做完这三条就能解决。

## 二、按症状对照

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 输完 PIN 一直转，提示在电脑上打开应用 | 桌面端进程假死或状态没同步 | 按上面三条彻底重启两端再连 |
| 输 PIN 直接失败 | 不同网络或防火墙拦截 | 核对 WiFi、补防火墙放行 |
| 手机能打开但配对过不去 | 免费账号或订阅过期 | 遥控属于 Pro，对照 [修改器免费与Pro订阅差别](修改器免费与Pro订阅差别.md) |
| 之前好使突然连不上 | 桌面端被关或网络变了 | 确认桌面端开着、远程控制开关打开 |
| 开关点了没反应 | 修改项组合冲突 | 关掉其中一个再试另一个，恢复即组合冲突 |
| 换手机或重装后连不上 | 配对不保留 | 重新取 PIN 配对一次 |

顺带分清两类「没反应」：开关本身失效多是组合冲突，游戏里按热键没反应则要检查热键是否被改成了 Not set。

## 三、游戏列表空白与检测不到

先确认这款游戏该不该出现：支持范围是单机 PC 游戏（Steam、Epic、GOG、Ubisoft Connect 等平台版本）；主机、手机、浏览器与 VR 游戏，带反作弊保护的作品，以及联机为主的游戏不在支持范围——列表里没有它们是正常结果，不是故障。

游戏确实装了却没被扫到时，走手动添加：桌面端进那个游戏的页面，点 Add Game → Add Game Manually，把游戏的 exe 拖进去。注意桌面图标是启动器不是 exe，右键「打开文件所在位置」跳过去再选。右上角出现 Game not found 时，点旁边的 Fix 按钮走 Add Custom Installation 同样能手动定位。

微软商店与 Game Pass 版本装在受权限保护的 WindowsApps 目录下，常见做法有两条：以管理员身份运行桌面端（先结束全部进程再启动），以及把工具升级到最新版——旧版本存在商店游戏检测不到的问题，后续版本已修复。

## 四、都试过还不行

手机浏览器能打开的遥控页是一个好用的分流点：浏览器页连得上而应用连不上，问题多半在应用本身，强制停止重开或重装一次（安卓安装包入口见 [WeMod 遥控站](https://wemod.fwen.ren/) 的下载页）；两个都连不上，回到第一节按顺序再来一遍，重点核对网络与账号订阅状态。遥控端的定位与配对基础知识见 [手机当电脑游戏修改器的遥控器](手机当电脑游戏修改器的遥控器.md)。
