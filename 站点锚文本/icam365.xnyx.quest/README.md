# iCam365 资料整理与获取入口

iCam365 是深圳市探鸽智能科技推出的家用摄像头配套应用，负责把摄像头、智能门铃的画面装进手机：实时查看、云台转动、双向对讲、存储卡与云端双路回放、AI 人形检测告警都在这一个 App 里完成。本目录围绕它整理了几篇面向实际使用的说明，从摄像头连接手机、录像回放设置，到安卓端安装包的下载流程，按需取阅。
