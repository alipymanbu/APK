# 摄像头怎么连接手机

> 手里这台云摄像头通电之后不出画面，是因为它还没被「交」给手机上的配套应用。这一篇按扫码、热点、网线三种连接方式把流程说清，并附上配网时摄像头语音提示的对照处理办法。

## 连接前先备齐四件事

1. **摄像头已通电**：接上电源等约 1 分钟，听到开机提示音再操作；一直没声音，先长按机身 Reset 键重置。
2. **手机上已装好配套应用并登录**：还没装的，先看[安卓安装包下载流程](安卓安装包下载流程.md)把应用装上。
3. **WiFi 是 2.4GHz 且未隐藏**：这类摄像头只认 2.4GHz 频段，5GHz 的网络扫不到；路由器开了「双频合一」的，去后台拆成两个名字再连。WiFi 名与密码建议只用字母和数字。
4. **安卓手机打开定位**：安卓端添加设备要用到定位服务，第一次打开应用时把权限给上。

## 三种连接方式怎么选

| 方式 | 原理 | 适合情况 |
| --- | --- | --- |
| 扫码添加（推荐） | 手机先连家里 WiFi，再把应用生成的二维码给镜头看 | 机身二维码清晰可识别的绝大多数情况 |
| 快速添加（AP 热点） | 手机连上摄像头发出的热点，把 WiFi 信息交给它 | 二维码破损、扫不出来的情况 |
| 网线添加 | 摄像头用网线直连路由器 | 机身旁有网口，或想走有线图稳定 |

## 扫码添加的完整顺序

1. 让摄像头离路由器近一些，中间尽量不隔墙。
2. 应用里点「+」，扫机身底部或背面的二维码；扫不出来就手动选「监控摄像头 → WiFi 摄像头 → 扫码添加」。
3. 选定家里 2.4GHz 的 WiFi，输入密码提交。
4. 屏幕出现二维码后，把它对着镜头，距离保持 10~30 厘米。
5. 听到提示音后点下一步，等它自己连 WiFi、连服务器，全程约 30 秒到 1 分钟。
6. 连上后给设备起个认得出的名字（比如「客厅」「大门」），后续告警推送也用这个名字。

## 摄像头说的话，对照处理

| 语音提示（大意） | 表示什么 | 卡住先查什么 |
| --- | --- | --- |
| 请用扫码或热点方式配置摄像头 | 在等下发 WiFi 信息 | 没听到这句说明没进配网模式，先重置 |
| 正在连接 WiFi | 已收到信息，正在连路由器 | 密码是否填错、距离是否太远、WiFi 是否隐藏 |
| 正在连接网络 | 连上了路由器，正在连服务器 | 宽带是否正常、密码里是否带特殊符号 |
| 网络已连接 | 配网完成 | 回应用首页看画面是否出现 |

## 两个常见追问

- **想换 WiFi 或挪位置**：在设备设置里重新选网络填密码；接网线的机型拔线后要重新上电；换了路由器或改了 WiFi 密码的，必须先重置再重新配网。
- **换账号绑定**：摄像头与账号一对一绑定，要换账号先在原账号里删除设备。家人想一起看，不必换账号，走设备分享就行，玩法写在[录像回放与告警推送](录像回放与告警推送.md)里。

功能全貌与安装包入口，见 [iCam365 资料站](https://icam365.xnyx.quest/)。
