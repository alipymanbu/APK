# OMate 安卓版下载与安装步骤

本篇讲 OMate 这款 AI 角色扮演聊天应用在安卓手机上从取安装文件到打开应用的完整过程：资源在哪里、怎么转存、安装时要注意什么、装完第一件事做什么。想先了解这款应用能做什么，可以先看[角色卡导入与酒馆迁移](角色卡导入与酒馆迁移.md)。

---

## 资源在哪里取

OMate 的安卓安装包约 123 MB（本地整理到的版本为 1.9.4），安装文件资源放在夸克网盘分享中。[OMate 介绍站](https://omate.gkhf.beer/)的首页与下载页都挂了固定的资源入口按钮，点开后按提示操作即可。

## 转存 → 下载 → 安装

1. **转存到自己的网盘**：从介绍站进入分享页后，先登录自己的夸克账号，把资源转存到自己的网盘空间；转存成功后文件才真正可用。
2. **下载到手机本地**：在自己网盘里找到转存来的 APK 文件，选择下载到手机。文件比较大，建议在 Wi-Fi 环境下进行。
3. **允许安装**：手机上点开下载好的文件，首次安装会提示「未知来源应用」，按提示允许当前来源安装即可。
4. **完成并打开**：装好后打开 OMate，会先进入发现页。

## 装完第一件事：配置 API

OMate 走「自带 API」模式——应用本身不提供对话服务，角色能不能「活过来」取决于你自己配置的 AI 服务。首次打开时，先到「设置 → API 设置」填入自己在 AI 平台申请的密钥；没配之前，发现页也会直接提示先去添加配置。具体的配置项与模型分工写在[API配置与模型分工](API配置与模型分工.md)里。

## 安装环节的常见问题

- **提示「解析包出现问题」**：多数是文件没下完整或存储空间不足，删掉重新下载一次即可。
- **安装被系统拦截**：在系统提示里选择允许本次安装；不同品牌手机的入口略有差异，但逻辑一致。
- **反复提示添加 API**：属于正常流程，不是故障，按上一节配置好密钥就会消失。

安装完成、配好密钥、导入第一张角色卡，就能开始第一场对话了。
