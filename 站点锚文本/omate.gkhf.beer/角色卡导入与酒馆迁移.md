# OMate 角色卡导入与酒馆迁移

本篇回答使用 OMate 时问得最多的一件事：SillyTavern（酒馆）里积累的角色卡、世界书、预设和聊天记录，能不能搬到手机上继续用。答案是能，而且是整包搬。还没安装应用的先看[安卓版下载与安装步骤](安卓版下载与安装步骤.md)。

---

## 转化式兼容是什么意思

OMate 对酒馆生态做的是「转化式兼容」：文件在导入时被自动翻译成 OMate 自己的原生机制运行，不需要先弄懂两边的规则差异。把文件丢进导入入口，应用会自动识别每个文件的类型，完成后还会附一份转化报告——哪些字段完整转了、哪些被降级、哪些暂缓，报告里写得清清楚楚。

## 各类数据搬进来的样子

- **角色卡**：支持 PNG / JSON / charx 三种格式，覆盖 V1 / V2 / V3 规范，字段完整映射；charx 里内嵌的资源会自动取 icon 作头像。
- **世界书（World Info）**：进入 OMate 的原生世界书引擎，四种触发逻辑、正则关键词、插入位置与深度、概率、递归、时效与 token 预算，行为与酒馆对齐；设定只在被提及时注入上下文，不占固定篇幅。
- **预设（Preset）**：转为预设对象加提示词分组，可挂在全局、角色、对话、故事、朋友圈五处，按优先级拖拽叠加。
- **聊天记录（jsonl）**：自动新建对话并关联同名角色，完整的 swipes 历史保留，换到手机上能从原地方接着聊。
- **宏（Macros）**：{{char}}、{{user}}、{{random}}、{{roll}}、时间宏、变量与条件块等常用宏都能用。

## 导入入口在哪

打开「角色」页，右上角 **+ → 导入**，文件可以多选批量丢入，不必先按类型分类。卡内嵌的世界书在导入时选择「作为世界书导入」，就会自动绑定到该角色。

## 改完还能导出回去

在 OMate 里编辑过的角色，导出时会以原卡为底稿按双 chunk（V2 / V3）写回，分享回社区不丢数据。这条对卡作者很友好：手机上改设定、电脑上继续维护，两边互不折腾。

导入完成、配好密钥之后，剩下的就是聊天本身了；角色为什么「记得住」你，与各模型分别负责什么，写在[API配置与模型分工](API配置与模型分工.md)里。
