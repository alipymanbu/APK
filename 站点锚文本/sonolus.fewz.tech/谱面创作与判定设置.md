# 谱面创作与判定设置

> 打熟了想自己做谱、或想把手感调到最顺，这篇讲编辑器入口、投稿规范与两层设置的调法。
> **相关文档**：[是什么游戏与玩法核心](是什么游戏与玩法核心.md) · [安卓安装与加服务器步骤](安卓安装与加服务器步骤.md)

## 一、做谱不在手机里，工具是网页端

手机上的 Sonolus 负责玩与投稿，谱面本身用网页编辑器制作（手机、电脑浏览器都能开），常用的三个：

| 工具 | 地址 | 干什么 |
| --- | --- | --- |
| Horizon Editor | horizon-editor.sonolus.com | 通用谱面编辑器，支持实时预览 |
| Next SEKAI Editor | next-sekai-editor.sonolus.com | 针对 PJSK 类玩法，可直接打开 .sus / .usc 老谱 |
| Sonolus Studio | studio.sonolus.com | 做皮肤、背景、音效、粒子这些素材 |

制作时先定准 **BPM 与起始偏移**——这两项错了整张谱都会漂；摆完音符用实时预览反复检查手感，导出的关卡数据就是你要发布的东西。手里有 .sus / .usc 旧谱的，Next SEKAI Editor 能直接转。

## 二、发布是审核制，投稿先对规范

在目标服务器的关卡区点 Create 填写信息，新建关卡先是**草稿**，可以发试玩链接收意见；点提交审核后由服务器审核员过目，**通过才公开发布**，被拒会写明修改意见。

投稿前对着目标服务器的规范过一遍，常见的硬性条目：

- 音频用 **mp3 恒定比特率**（变码率在部分设备会出播放 bug），另配约 30 秒带淡入淡出的试听；
- 封面约 400×400，别糊；
- BPM 与同步必须正确；标题、作者、标签填全，关键词里补上别名与异写，别人才搜得到；
- 谱面本身要能正常打，别放会互相误触的堆叠音符；不搬运商业音游素材，版权方可以要求下架。

## 三、手感两层设置，改错地方等于白改

**全局设置**（对所有服务器生效）：

- **设备音频偏移**：管音乐与谱面整体对不齐，设置里自带校准，跟着提示走一遍能自动算出偏移值；
- **设备输入偏移**：管点击到判定的时差，极容易调出怪判定，非必要不动；
- **图像**：掉帧先降渲染比例与抗锯齿，多数卡顿在这两项上解决。

**关卡配置**（只对当前玩法与关卡生效）：

- **流速**：音符下落快慢，与曲速无关，第一件事调到看得清的位置；
- **皮肤**：换音符与判定线外观，可选项由所在服务器提供；
- **上隐**：调屏幕上沿显示范围，遮挡不适再动。

## 四、断网继续打的办法

首次加载关卡需要联网；在关卡详情页点**保存**收进收藏夹，资源就留在本地，断网也能从收藏夹打开，常玩的歌建议提前存好。装包与加服务器的流程见[安卓安装与加服务器步骤](安卓安装与加服务器步骤.md)，玩法结构复盘可以去 [Sonolus 玩法站](https://sonolus.fewz.tech/)对照看。
