# 安卓安装与添加服务器步骤

> 装上只是第一步，接上服务器才有曲库。本篇把「转存 → 安装 → 加服务器 → 找谱」整条链路一次讲完。
> **相关文档**：[是什么游戏与玩法核心](是什么游戏与玩法核心.md) · [谱面创作与判定设置](谱面创作与判定设置.md)

## 一、装之前先对一下条件

- **包体**：安卓 APK，约 72M，下载前留够空间；
- **系统**：安卓 7.1 及以上更稳妥（以安装包信息为准）；
- **来源**：安装包经夸克网盘分享分发，需要允许「安装未知来源应用」。

## 二、安装四步

1. **转存**：打开 [Sonolus 玩法站的下载页](https://sonolus.fewz.tech/download.html)，点「获取安装文件资源」进入网盘分享，登录后把安装包转存到自己账号；
2. **下载**：在夸克网盘 App 或网页版把安装包下载到手机，得到 .apk 文件；传输中断过就重新下一次，装不上多半是包不完整；
3. **安装**：点开 .apk，系统提示未知来源时允许「来自此来源的安装」（安卓 8 及以上按来源授权，装完可关掉）；
4. **首启**：点 Tap to Start，语言选「简体中文」界面立刻切换，再挑一个界面主题进入首页。

## 三、接入社区服务器

1. 首页点**开始**，进入服务器列表；
2. 找到**自定义服务器**一栏，点下方的**添加**（别点到收藏夹下面的添加，那是收藏夹自己的入口）；
3. 表单里**名称**随便写（自己的备注），**地址**粘贴拿到的服务器链接，确认后应用会连上去读取信息；
4. 回列表点刚加的那一项就能进入该服务器。

服务器地址从哪拿：社区维护的服务器列表站按玩法分类给出地址；也有不少服务器提供 `open.sonolus.com` 形式的邀请链接，手机浏览器点开直达添加页。同一客户端可以加很多个服务器，互不干扰。

## 四、进服后找谱与搜索技巧

进入服务器点**关卡**浏览，或点放大镜搜索。记住一条：**搜索用原文关键词**——日文曲名打日文、英文歌打英文，中文译名与罗马音经常搜不中。同一首歌的不同难度会拆成多个关卡，点开前看曲目 ID 与难度信息确认。

第一次开打前先在关卡详情页的**配置**里把流速调顺手；想离线玩的，在详情页点**保存**收进收藏夹，断网也能打，更多设置见[谱面创作与判定设置](谱面创作与判定设置.md)。

装完首页空空的属于正常现象，不是装坏了——原理见[是什么游戏与玩法核心](是什么游戏与玩法核心.md)。
