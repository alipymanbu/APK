# 用浏览器管理安卓手机的开源方案

> 本篇盘点「一个应用 + 一个浏览器地址」管好安卓手机的完整方案：功能覆盖、上手路径与适用人群。
> **相关文档**：[手机电脑互传文件不用数据线.md](手机电脑互传文件不用数据线.md) · [安卓手机屏幕镜像到电脑浏览器.md](安卓手机屏幕镜像到电脑浏览器.md)

---

## 一、思路：让手机自己变成一个网站

多数「手机管理」工具的形态是电脑装一套客户端、手机装一套、两边靠数据线或私有协议握手。还有一条更省事的路线：手机上跑一个本地网页服务，把管理界面直接做成网站——任何设备只要有浏览器、连着同一 Wi-Fi，输入地址就是完整的管理面板。[PlainApp 介绍站](https://plainapp.qhah.skin/)介绍的这款开源工具走的就是这条路。

它的核心事实：免费开源、无广告、不用注册账号、数据全程留在局域网内；传输加密采用 TLS + XChaCha20-Poly1305，源代码在 GitHub 公开可审。

## 二、面板里都有什么

| 模块 | 在浏览器里能做的事 |
| --- | --- |
| 文件 | 浏览内部存储 / SD 卡 / U 盘，上传下载、改名移动删除 |
| 媒体 | 按时间线翻相册，直接播放手机里的视频与音乐 |
| 短信与通话 | 大屏读写短信，通话记录搜索筛选 |
| 通讯录与通知 | 搜索编辑联系人，手机通知实时上屏 |
| 屏幕镜像 | WebRTC 串流手机画面，最高 30fps 带音频 |
| 应用管理 | 列出已装应用，导出 APK 备份 |
| 笔记与 RSS | Markdown 笔记、RSS 阅读器，手机与网页共一份数据 |

手机端本身也内置了笔记、RSS、音视频播放等独立功能，服务不启动也能当工具箱用。

## 三、上手路径

1. 手机安装应用（安装包约 86M，要求 Android 9.0 以上），按用途授予权限；
2. 点「启动服务」，记下屏幕上的 `http://192.168.x.x:8080` 形地址；
3. 电脑浏览器原样输入地址，进入面板开始使用；首次连接弹证书警告属正常，点「继续访问」即可。

常驻使用建议把网页面板固定成桌面应用（PWA），点开就是独立窗口。两个高频小状况：锁屏后断线是省电策略清了后台，把电池选项改成「不受限制」；人在外面想连家里手机，开个手机热点让电脑连上就行。

## 四、适合谁用

- 讨厌插数据线、又被微信传文件压缩画质折磨的人；
- 在意隐私、不想让手机照片过第三方云盘的人；
- 手上有旧安卓机、想把它改成家里媒体站或文件站的人。

具体的文件互传操作见 [手机电脑互传文件不用数据线.md](手机电脑互传文件不用数据线.md)，把画面投到电脑或电视的玩法见 [安卓手机屏幕镜像到电脑浏览器.md](安卓手机屏幕镜像到电脑浏览器.md)。
