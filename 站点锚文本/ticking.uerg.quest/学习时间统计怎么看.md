# 学习时间统计怎么看

> 计时只是记录，统计才是复盘的原料。本篇讲学习时间统计图表里值得盯的几个数字、常见的误读，以及怎么用它们排下一周，以安卓应用 Ticking（待办｜计时｜自习室）的统计功能为例。
> **相关文档**：[番茄钟和待办清单怎么配合](番茄钟和待办清单怎么配合.md) · [线上自习室有什么用](线上自习室有什么用.md)

## 一、先看哪几个数字

打开统计页，日/周/月/年几个视图可以切换，重点看三处：

| 看什么 | 说明 |
| --- | --- |
| 分类饼图 | 各科目/类别的时间占比，一眼看出这周到底偏科没有 |
| 总时长与次数 | 总时长看量，次数看节奏——次数骤降往往比时长掉得更早 |
| 周纵览 | 一周的任务与安排铺在一张图上，周末对着它排下周 |

## 二、两个常见误读

1. **只看总时长**。六小时里两小时在走神，不如两小时全神贯注。总时长要配合完成次数和任务进度一起看；
2. **拿排行榜当天平**。和自习室里的人比时长可以当激励，但每个人任务难度不同，比出来的数字说明不了效率。

## 三、从图表到下一周的计划

统计的价值在闭环：周五晚上花两分钟过一遍本周图表，找出「实际用时总超预估」的任务类型，下周铺任务时把这类任务多拆细一档；找出「专注最差的时段」，把最费脑的活挪走。时间花去了哪里，图表比记忆诚实得多。

铺任务与计时的配合方法在[番茄钟和待办清单怎么配合](番茄钟和待办清单怎么配合.md)里有一条完整流水线；一个人学不动的，[线上自习室有什么用](线上自习室有什么用.md)讲了怎么蹭氛围。

## 四、想在手机上看到自己的图表

Ticking 的统计视图按日/周/月/年切换，饼图按待办类别拆分，手机和平板都有适配布局（大屏还有双栏视图）。功能说明与安装文件资源入口见 [Ticking 学习计时介绍站](https://ticking.uerg.quest/)，装好计时几天，你自己的图表就有了。
