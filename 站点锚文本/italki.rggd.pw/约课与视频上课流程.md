# italki 约课与视频上课的完整流程

> 本篇按时间顺序讲一遍 italki 的上课路径：从筛选老师、发送课时请求，到进视频教室、处理设备与时区问题。第一次约课之前过一遍，能省掉大部分手忙脚乱。

相关文档：[专业教师和社区导师怎么选](专业教师和社区导师怎么选.md)、[收费方式与点数结算](收费方式与点数结算.md)

---

## 第一步：筛选老师

在老师列表里按三样东西筛：目标语言、价格区间、可约时间。筛出来的候选人依次做三件事——看介绍视频、读学员评价、核对资质标注（专业教师还是社区导师）。这三个动作花不了十分钟，但直接决定第一节课的体验。

## 第二步：发送课时请求

在老师日历里挑空闲时段。日历显示的时间是**你所在的时区**，跨时差约课不用自己换算。选好课时时长（30 / 45 / 60 / 90 分钟，60 分钟是基础款）后发送课时请求，等老师接受，预订才算成立。

预约通常要留出提前量，赶时间的话可以留意提供「即时课时」的老师——有空档就能立刻开课。

## 第三步：进视频教室

上课工具有两种选择：

- **italki Classroom**：平台内置的网页/应用教室，支持课堂文字、文件共享与课程回放相关功能，师生都不用额外装东西；
- **第三方工具**：部分老师习惯用 Zoom、Teams、Facetime 或微信上课，双方约好即可，课时页里会给出对应的联系方式。

第一次上课建议提前五分钟进教室，检查摄像头、耳机和麦克风。

## 第四步：课后收尾

下课后确认课时完成，费用从点数里扣除。老师留下的课堂笔记和作业记得翻一遍；把生词放进复习工具、写作练笔发到社区等批改，都是课与课之间维持语感的低成本做法。

## 设备与网络清单

| 项目 | 建议 |
| --- | --- |
| 设备 | 手机、平板、电脑均可，需带摄像头 |
| 音频 | 耳机 + 麦克风（哪怕几十块的有线款也明显更好） |
| 网络 | 视频通话对上行带宽敏感，Wi-Fi 优先 |
| 环境 | 安静、光线正面打脸，背景随意 |

## 常见小状况

**老师一直没接受请求怎么办？** 等待期间可以礼貌留言；临近开课仍未确认就取消并换人，点数不会损失。

**想改时间怎么办？** 按平台规则提前足够时间可以改期或取消，具体时限以订课页面提示为准。

**想换老师怎么办？** 直接换，点数在账户里不绑定任何一位老师——这正是按次付费的好处。
