# BoldVoice 安卓版下载与安装步骤

本篇面向想在安卓手机上安装 BoldVoice 的读者，整理从拿到安装包到完成首次发音测评的完整过程，并解释容易卡住的两个环节。安装入口与训练机制的更多说明，见 [BoldVoice 口音训练介绍](https://boldvoice.gkhf.beer/)。

---

## 拿到安装包

BoldVoice 在应用商店之外的安卓安装包通常以 APK 形式经网盘分享（如夸克网盘）流通：打开分享页后先转存到自己的网盘空间，再下载到手机。转存而非直接下载的好处是链接失效后仍可从自己账户里找回文件。

安装包体积在 150 MB 上下，下载前确认手机剩余存储不少于 3 GB，避免安装阶段因空间不足中断。

## 允许未知来源安装

APK 不走商店通道，首次安装时安卓会拦截一次：

1. 点开 APK，系统弹出"为了手机安全，已禁止安装未知应用"；
2. 按提示进入 设置 → 应用 → 特殊权限 → 安装未知应用；
3. 找到下载时使用的浏览器或文件管理器，允许"来自此来源的应用"；
4. 返回重新点开 APK，正常进入安装流程。

这是系统级的一次性授权，与应用本身无关，后续更新时不再重复。

## 首次启动：先做测评

装好打开应用，会先回答几个背景问题（母语、学习目标），然后录制一段短文完成发音测评。测评结果决定了之后生成的课程与每日计划——直接跳过测评，训练内容会退回通用路径，针对性明显变弱。

## 安装失败时先看两处

- 安装包不完整：下载中断会得到体积明显偏小的文件，重新下载一次即可；
- 存储不足：清理出 3 GB 以上空间再装。
