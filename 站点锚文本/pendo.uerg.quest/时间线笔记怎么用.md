# 时间线笔记怎么用

> 本篇讲「时间线笔记」这种记法的上手思路：为什么所有内容排成一条线反而更轻松、待办和笔记混着写怎么不打架、标签和颜色怎么用才不形式主义。例子用安卓上的 Pendo Note 来讲，思路换到同类应用同样成立。
> **相关文档**：[一句话把日程写进日历](一句话把日程写进日历.md)

## 一、先想清楚：分类是记录的敌人

很多人用过这种流程：想记个念头 → 打开应用 → 纠结该放进「随笔」还是「清单」还是「日程」→ 纠结完念头已经没了。文件夹式的分类法要求你在记录之前先做一次「归档决策」，这件事本身就在消耗记录的意愿。

时间线笔记把这个决策往后推：**想到什么写什么，所有内容按发生时间排成一条线**。随手记的一段话、列到一半的购物清单、下周的安排，先都落在同一条线上，之后再决定它是什么。

## 二、一条线上的三种内容，实际这么处

以 Pendo Note 为例，一条时间线上混着三类内容，各有各的处理办法：

- **随想的段落**：直接写，落进时间线就是一篇笔记。回找的时候按时间翻，或者用全局搜索按关键词找；
- **清单类**：写完内容后另起一行敲一个 `T` 回车，这段内容就变成待办清单，一行一项，勾掉一项它自动沉到清单底部，没做的始终留在眼前；
- **要占时间的计划**：写一句「每周二和周四晚上 8 点去健身房，坚持 3 周」这样的计划，具体怎么让它自动进日历，见[一句话把日程写进日历](一句话把日程写进日历.md)。

关键差别在于：分类不再是「记录前的门槛」，而是「记录后顺手的一个动作」。

## 三、标签和颜色：够用就好

标签在 Pendo Note 里被定位成「比文件夹更灵活」的分类方式，实际用起来有两条经验：

1. **一篇可以挂多个标签**：「工作」「周报」可以同时挂在同一篇上，这是文件夹做不到的；但别一开始就设计一套标签树，想到一个维度建一个，随用随建；
2. **颜色当信号灯用**：给标签配上颜色后，时间线上扫一眼就知道哪条是工作（蓝）、哪条是生活（黄）。约定两三种颜色就够了，颜色超过五种，扫一眼分辨的效果反而没了。

## 四、这类记法适合谁

- **日记党**：每天打开就写，时间线天然就是日记本的年月日排布，月底往前翻就是整月记录；
- **备考的人**：待办清单 + 循环任务管每日打卡，随想段落记错题和思路，一条线全收；
- **健身 / 习惯打卡**：周期性的事设一次重复，到点自动出现，配合颜色一眼看到今天完成了几件；
- **想法多但懒得整理的人**：这条最合适——时间线记法的全部意义，就是让「先记下来」比「先想好放哪」更容易。

## 五、想在手机上试试

Pendo Note 这款应用 2014 年就在移动端上线，安卓版和 iOS 版都在持续维护。它的时间线设计、一句话建日程的能力和安装文件资源的获取入口，都整理在 [Pendo Note 时间线笔记介绍站](https://pendo.uerg.quest/)，可以先看功能介绍再决定装不装。
