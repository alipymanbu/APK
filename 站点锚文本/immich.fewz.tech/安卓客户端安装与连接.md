# 安卓客户端安装与连接服务器

> Immich 的安卓端装好之后只是一个客户端，它要连上你自己的 Immich 服务器才能工作。这篇按顺序走完：拿安装包 → 安装 → 填服务器地址 → 开启自动备份，并汇总几个最容易卡住的点。

## 一、拿到安装包

Immich 安卓端有多个发布渠道（应用商店、项目发布页、F-Droid 等），签名各不相同，混着升级会被系统拒绝——选定一个渠道就固定用它。手边不方便访问那些渠道时，也可以走网盘分享：[immich.fewz.tech](https://immich.fewz.tech/) 整理了安卓安装文件的获取入口，转存后下载 APK 即可。

## 二、安装

1. 在文件管理器里点开下载好的 APK；
2. 系统第一次会提示「允许从此来源安装」，同意一次即可——这是对所有侧载安装包的统一提示，与这个包本身无关；
3. 装完打开，首屏就是服务器地址输入框。

## 三、连接自己的服务器

服务器地址的格式是 `http://服务器IP:2283`，`2283` 是 Immich 的默认端口。两个高频错误：

- **把公网 IP 当内网地址填**：在家里的 Wi-Fi 下应填服务器的局域网地址（一般是 `192.168.x.x`、`10.x.x.x` 开头），公网地址反而连不上；
- **漏掉端口**：只填 `http://192.168.1.10` 而不带 `:2283`，等于在访问 80 端口。

账号用的是网页端首次注册的那个（第一个注册的用户自动是管理员）。登录成功后，第一次会先构建缩略图索引，图库大时要等一会儿。

还没部署服务器的先回去补课：Docker Compose 拉起服务、注册管理员，流程见[自建照片备份方案](自建照片备份方案.md)的第四节。

## 四、开启自动备份

1. 登录后点右上角的**云朵图标**进备份页；
2. 勾选要备份的本地相册（不想整本传的可以排除掉）；
3. 拉到底点 **Enable Backup**，已有的照片开始上传。

上传规则值得知道：默认只在 Wi-Fi 下传，移动网络默认不动；每个文件先算校验和，服务器上已有相同内容的直接跳过，所以多台手机对同一账号开备份也不会传出一堆重复文件。

Android 上另一个常见状况是**后台备份不动**：很多机型的电池策略会把后台上传掐掉，到 dontkillmyapp.com 按品牌查关闭方法即可。前台切到后台就停属于正常机制，不是故障。

## 五、装好之后

- 出门在外想让手机继续备份，需要端口转发或用 WireGuard、Tailscale 之类的组网工具把手机拉回家;
- 老照片还在谷歌相册的，按[从谷歌相册搬家](从谷歌相册搬家.md)的路子迁，别直接拖文件；
- 界面与功能的整体印象，可以回 [immich.fewz.tech](https://immich.fewz.tech/) 看截图与功能一览。
