# freemind 是什么应用：手机上的思维导图工具

> 本篇回答「freemind 是什么」：搜这个名字时碰到的通常是哪款应用、和电脑上那个同名开源软件是什么关系、有哪些功能。想在手机上装一个的，看完就有判断了。
> **相关文档**：[手机画思维导图怎么入门.md](手机画思维导图怎么入门.md) · [思维导图换手机怎么迁移.md](思维导图换手机怎么迁移.md)

## 一、安卓手机搜 freemind，指的多半是它

在手机应用圈里，freemind 这个名字对应的安卓应用，正式名称是「思维导图」（MindLine），开发者是深圳市小棕熊科技有限公司。核对是不是同一款，看两条就够：

| 核对项 | 值 |
| --- | --- |
| 包名 | `czh.mindnode` |
| 开发者 | 深圳市小棕熊科技有限公司 |

它是一款手机思维导图工具：新建不同主题的导图，加主节点和子节点梳理思路，给节点改颜色、加图标区分内容，还能插图、写备注、做标记。画好的图可以存成图片或文档，也能一键分享出去。

## 二、和电脑上的 FreeMind 是两回事

容易混淆的是：还有一款知名的开源软件 FreeMind，运行在电脑上，用 Java 编写，历史比多数手机导图工具都久。两者名字相近，但不是同一个软件，文件也不通用。

分辨起来很简单：手机应用商店里、安卓下载渠道提到的 freemind，基本都指向 MindLine 这款手机版；电脑端的开源项目则要去它的项目主页获取。想从旧软件的图搬过来，先导出成大纲文字，再逐层重建即可。

## 三、它有哪些拿得出手的能力

- **分支好操作**：点加号加子分支，长按主干能向左添加，拖动加号拉长分支，换行字数可调；
- **样式可换**：新建时挑布局与配色，画到一半长按主干根支就地换；
- **文字大纲视图**：一键把图切成缩进清单，层级多时在大纲里调顺序更利索；
- **节点能塞东西**：图片、网址、附件、数学公式，长按菜单还有备注、标记、连接与汇总；
- **云同步**：登录后文件跟着账号走，手机、平板、电脑多端接力；
- **导出与分享**：图片、PDF、文字大纲，发文件或发链接都行。

## 四、要不要花钱

基础画图功能不收费。应用内有专业版内购（按月、按年或买断），先装来把基础功能用顺，碰到确实需要解锁的能力再考虑，档位以应用内购买页显示为准。

## 五、在哪装

安卓用户可以从应用商店搜「思维导图」认准开发者名安装；也可以走网盘资源。功能截图、安装步骤与常见问题，都整理在 freemind 手机版介绍站：[https://freemind.fewz.tech/](https://freemind.fewz.tech/)。
