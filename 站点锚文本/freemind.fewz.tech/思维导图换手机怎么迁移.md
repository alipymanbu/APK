# 思维导图换手机怎么迁移：云同步恢复全流程

> 本篇讲思维导图文件怎么跟着人走：换新手机、重装应用、临时用电脑时，靠云同步把导图完整带过去，一步不落。
> **相关文档**：[手机画思维导图怎么入门.md](手机画思维导图怎么入门.md) · [freemind是什么应用.md](freemind是什么应用.md)

## 一、先分清：本地画和云同步

不登录账号也能在手机上正常画图、导出，文件存在本机。但本机文件有两个风险：换手机带不走、误删没得捞。云同步只解决一件事——**文件跟着账号走**。所以重要导图，建议开工第一天就登录。

登录入口在「云同步」页面，手机号或邮箱都行。

## 二、两个手动按钮 + 一个自动开关

登录后有这些可用的东西：

| 操作 | 作用 |
| --- | --- |
| 同步文件到云端 | 把本机导图上传保存，当备份用 |
| 从云端下载文件 | 把云端的导图拉回本机，换机恢复全靠它 |
| 自动同步开关 | 打开后定期把所有图自动上云，云端有更新也会自动拉回 |

日常建议把自动同步直接打开，基本不用再管手动按钮；不过换手机前，最好还是在旧手机上手动点一次「同步文件到云端」，确认最新画的几张都上去了再动手。

## 三、换手机四步走

1. 新手机装好应用（安卓渠道与安装步骤见文末的介绍站）；
2. 打开「云同步」页面，登录**和旧手机同一个**账号；
3. 点「从云端下载文件」，或开着自动同步等它拉回来；
4. 打开文件列表，核对一遍导图都在、内容是最新版。

文件列表里的整理动作：左划文件可删除、移动、重命名；右上角加号能建文件夹，按工作、学习、待办分好类，迁移完核对起来快得多。

## 四、顺手把电脑也用起来

同一个账号在电脑端通用：Windows、Mac 有客户端，浏览器还能开网页在线版，直接编辑云空间里的导图。手机上画到一半的图，回家在电脑上接着改，靠的就是这套云同步。
