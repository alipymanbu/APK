# WearOS 手表怎么安装第三方 APP

想给 Wear OS 手表装个新表盘、离线音乐播放器或者计时工具，翻遍表里的应用商店却搜不到——这是国内 Wear OS 用户最熟悉的场景。这篇解释为什么手表装应用这么麻烦，以及眼下最顺的几条路。

## 一、为什么国内的手表装应用这么难

谷歌的开发者文档写明：中国版 Wear 应用商店尚未开放，并建议开发者改用 ADB 方式侧载应用做测试。也就是说，国内发行的 Wear OS 手表大多**没有可用的应用商店**，手表自带的那几个入口要么空置、要么只有极少的合作内容。想装第三方 APP，就得绕开商店，直接把安装包推送到手表上。

## 二、手机端工具是眼下最省事的路

给手表装应用传统上要连电脑、敲 ADB 命令，门槛不低。现在更常见的做法是用手机端的图形化工具完成同样的操作，比如 [WearOS 工具箱](https://wearos.yoan.quest/)：它把「给手表装 APK」做成了一个按钮——手机上存好安装包，连上手表后选中、点安装，包会自动推送过去完成安装。

大致流程：

1. 手机与手表连**同一个 Wi-Fi**，手表打开开发者选项和无线调试；
2. 手机装上工具箱，输入手表显示的 IP 端口建立连接（新版可自动扫描发现设备）；
3. 在「安装应用」入口选择本地 APK，确认后手表上就多了新图标。

部分工具还内置了应用商店入口，可以直接在列表里挑应用安装，省去找包这一步；一次安装多个安装包的功能一般需要捐赠解锁。

## 三、装不上或闪退，多半是包不对

手表和手机的处理器架构、屏幕尺寸都不一样，**给手表装 APK 要用适配手表的包**。用手机版的安装包硬推，典型表现就是安装失败或者应用打开即闪退。找包的时候认准 Wear OS / 手表适配版本；装完没看到图标的话，重启一次手表再看。

## 四、装完之后

新应用会出现在手表的应用列表里，表盘长按也能换成新装的表盘。日常维护之外，手机与手表之间的文件互传（表盘、音乐、截图）同样走这条 ADB 通道，工具箱的文件管理里就能双向传输。
