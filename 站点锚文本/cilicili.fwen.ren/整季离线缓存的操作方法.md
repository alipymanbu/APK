# cilicili 整季离线缓存的操作方法

> 本篇讲 cilicili 的离线缓存怎么用：从哪里进选集界面、一次圈多少集合适、缓存失败几种提示怎么处理，以及没网时到底什么能用什么不能用。
> **相关文档**：[番剧播放失败怎么换源自救](番剧播放失败怎么换源自救.md) · [投屏到电视的设置步骤](投屏到电视的设置步骤.md)

## 一、缓存的是什么

离线缓存是把某一集从片源下载到手机本地，下载完成后播放不再依赖网络，地铁、飞机上照常能看。缓存文件存在应用专属目录里，**卸载应用或「清除数据」会一起删掉**，清理手机空间时要留意。

## 二、缓存步骤

1. 打开要缓存的作品，进入**剧集详情页或播放页**；
2. 点**下载**图标，进入选集界面；
3. 勾选要缓存的集数，支持一次多选；
4. 确认后开始缓存，进度在【我的】→**下载管理**里看。

三个实操建议：

- **在 WiFi 下缓存**，一集高清按清晰度和时长浮动，流量下容易超量；
- **先用一集试水**，看清单集占多少空间再决定整季要不要下；
- **一次圈 3~5 集**，排队太多容易一直卡在「等待中」。

## 三、缓存失败怎么处理

| 现象 | 处理 |
| --- | --- |
| 立刻提示失败 | 当前播放源不可用，先换源再回来重新缓存 |
| 一直排队等待 | 减少批次，先下几集看进度 |
| 下到一半停住 | 多半是 WiFi 与流量互切过，保持网络不变重新下载该集 |
| 新出的集数下不了 | 新集刚上线源未就绪，隔一段时间再试 |

## 四、没网时什么能用

已缓存完成的剧集照常播放、进度照常记录；搜索、未缓存作品和弹幕这些依赖联网的部分暂时不可用。完全断网时首页可能停在加载状态，**这不代表缓存失效**——直接从【我的】→ 下载管理进入已缓存列表照样能播。

功能速览与获取入口整理在 [cilicili 追番笔记站](https://cilicili.fwen.ren/)；缓存下来想投到客厅大屏看，见[投屏到电视的设置步骤](投屏到电视的设置步骤.md)。
