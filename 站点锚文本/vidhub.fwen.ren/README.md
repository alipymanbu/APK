## 一句话认识 VidHub

VidHub 是一款覆盖 iPhone、iPad、Mac、Apple TV 与安卓手机、安卓电视的视频播放器：把本地、SMB、WebDAV、各类网盘以及 Emby / Plex / Jellyfin 服务器里的视频接进来后，自动抓取影视信息生成海报墙，电视剧自动分季分集，播放端支持倍速、在线字幕、4K 与 HDR。苹果设备之间可通过 iCloud 同步媒体库与播放进度，基础功能免费、完整能力应用内购买。
