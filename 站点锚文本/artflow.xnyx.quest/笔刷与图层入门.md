# ArtFlow 笔刷与图层入门

> 本篇按「画一笔 → 分层 → 改错了」的顺序，带你过一遍 ArtFlow 的笔刷工具与图层系统，适合刚装好、准备画第一张的你。
> **相关文档**：[安卓版下载安装步骤.md](安卓版下载安装步骤.md)

还没装上的先移步 [ArtFlow 安卓版下载与安装](https://artflow.xnyx.quest/)，装好再回来。ArtFlow 的界面把常用操作集中在画布四周，工具栏可以收起、把屏幕让给画面——本篇只讲你会用到的部分，不逐个列菜单。

## 一、新建画布

- 新建时先选尺寸：Pro 授权下画布最大 6144×6144 像素，实际能开多大取决于设备内存，老设备上选项会更小；
- 只发社交平台的图，2048 一档就够；要打印或接电脑细化的，尽量往上限开——放大画布容易，放大像素救不回来。

## 二、笔刷与工具

- 开发者介绍里写了内置 80 多种笔刷，加上涂抹（smudge）、渐变填充、橡皮等，授权后工具总量超过 100 种；
- 每种笔刷的尺寸、不透明度、流量、硬度都在侧栏滑杆里调，边画边看效果即可；
- 涂抹工具用来把颜色揉开，适合过渡；渐变填充适合铺天空、光晕这类连续色；
- 授权后可以用导入的图片自制笔刷——想把纸纹、布纹、干扫质感带进画面时用这个。

## 三、图层系统

| 能力 | 说明 |
| --- | --- |
| 数量 | 未授权版最多 3 层，Pro 最多 50 层（视内存） |
| 混合模式 | 正片叠底、叠加、变亮、变暗等，另有整体不透明度可调 |
| 剪贴蒙版 | 用下层图形限定上层的显示范围，上色不出界 |
| 选区与选区蒙版 | 先框范围再下笔，画不出去；选区可存成蒙版反复用 |
| 图层滤镜 | 10 种，含 HSV 调整、亮度/饱和度、色彩曲线等 |

3 层对「线稿 / 底色 / 阴影」刚好够，再多就要合并。有个习惯能省很多事：改动放在单独图层上，毁掉的只是一层。另需留意 ArtFlow 没有图层分组，图层一多时靠顺序和命名自己维持结构——画前先想好「线稿在下、细节在上」的层次安排。

## 四、撤销与重做

- 未授权版撤销只有 6 步——画错赶紧回，别等到第 7 步才发现回不去；
- 授权后撤销/重做步数不限（开发者功能清单口径）。

## 五、配合触控笔

用 S Pen 这类主动式触控笔时，笔尖压力会直接影响线条粗细与深浅；用手指画也可以开压感模拟。主动式触控笔通常笔尖悬浮有光标、笔身有按键；被动式电容笔（笔头是导电胶那种）没有压感，换任何应用都一样。这两项能力连同手掌防误触都有机型限制，个别设备不生效属正常例外。
