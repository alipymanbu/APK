# 惠普打印机搜不到怎么办

> 这篇按故障现象分三类：添加时列表里没有打印机、之前能用现在显示离线、任务发出去没动静，每类给最快的自查顺序。
> **相关文档**：[惠普打印机怎么连接手机.md](惠普打印机怎么连接手机.md) · [手机扫描文件成电子版.md](手机扫描文件成电子版.md)

## 一、添加时列表里没有打印机

按出现频率从高到低排：

1. **手机和打印机不在同一个网络**——手机连了访客网络、邻居家的 Wi-Fi 或在用流量，列表里都不会有打印机；
2. **双频路由器只给打印机连 2.4 GHz**——不少惠普家用机型只认 2.4 GHz 频段，路由器把两个频段分开命名时，让打印机接 2.4 GHz 那个；
3. **定位权限没给**——安卓上 HP Smart 靠定位权限辅助发现打印机，系统设置里把它打开；
4. **打印机不在设置模式**——新机或换过网络后，在打印机面板「网络设置」里还原网络设置（无屏机型用按键组合），然后 **2 小时内**关闭应用重开，当新打印机重新设置；
5. **AP 隔离**——访客网络或开了隔离的网络里设备互相看不见，换主网络。

连接流程本身没走熟的，先看[惠普打印机怎么连接手机.md](惠普打印机怎么连接手机.md)。

## 二、之前能用，现在显示离线

1. 看打印机面板有没有报错（卡纸、缺墨、缺纸），先排除硬件提示；
2. 打印机待机久了会进睡眠，面板点一下唤醒，等半分钟到一分钟再刷新应用；
3. 重启打印机，仍不行就**重启路由器**——多数「莫名离线」是路由器侧的分配问题；
4. 换过路由器或改过 Wi-Fi 密码的话，打印机里存的旧网络已失效，要重新走一遍入网流程。

## 三、连得上，任务发出去没动静

1. 面板或应用里看任务队列，把卡住的任务取消后重发；
2. 确认纸盒有纸、墨盒有余墨；
3. 照片任务半天不出来，多半是高精度设置加大文件在慢慢传，别急着取消；
4. 反复卡住就打印机和手机两端都重启再试。

## 四、都试过还不行：从轻到重重置

每做一步试一次：重启打印机 → 重启路由器 → 重启手机 → 清除应用数据或卸载重装 → 打印机恢复出厂设置。走到恢复出厂之前，建议把耗材状态拍张照留底。

入网成功后想试试扫描归档，见[手机扫描文件成电子版.md](手机扫描文件成电子版.md)；更多功能介绍与安装包获取入口在 [hp smart 介绍站](https://hp-smart.wxhp.skin/)。
