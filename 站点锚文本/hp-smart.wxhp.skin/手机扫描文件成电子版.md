# 手机扫描文件成电子版

> 这篇讲把纸质文件扫进手机变成 PDF 或图片的三种路子：打印机扫描、相册导入、摄像头拍摄，以及扫描设置和保存格式的选法。
> **相关文档**：[惠普打印机怎么连接手机.md](惠普打印机怎么连接手机.md) · [惠普打印机搜不到怎么办.md](惠普打印机搜不到怎么办.md)

## 三种取材方式

手机上装好 HP Smart 并让打印机入网后（没装过的先看[惠普打印机怎么连接手机.md](惠普打印机怎么连接手机.md)，安装包获取入口在 [hp smart 介绍站](https://hp-smart.wxhp.skin/)），主屏幕的「扫描」磁贴里可以选：

1. **打印机扫描**——原稿放玻璃板或自动进纸器（部分机型带），多页文件用进纸器一次送完，这是效果最稳的一路；
2. **导入照片**——从手机相册选已有图片当扫描件处理；
3. **手机摄像头拍摄**——直接拍纸面文档，更接近「拍照后修边」，光线不好时不如真扫描。

注意手机必须和打印机在**同一个 Wi-Fi 网络**里，打印机这一路才走得通。

## 扫描设置怎么调

| 设置项 | 建议 |
| --- | --- |
| 任务类型 | 批量扫多份材料选「批次处理」，一份扫完接着放下一份 |
| 纸张大小 | 与实际原稿一致（A4、Letter、4x6 英寸等） |
| 输入源 | 厚照片别走进纸器，容易刮伤，选玻璃板 |
| 解析度 | 300 dpi 够日常文档；要高画质再选 1200 dpi（更慢、文件更大） |
| 颜色 | 黑白文稿选灰度，文件体积小一大截 |

扫描后出现「检测边界」画面时：**自动**让应用找边缘，**手动**拖动边点自己框。

## 存成什么格式

预览页可以加页、旋转、删页，然后按用途保存：

- **基本 PDF**——多页合成一个文件，发别人的合同、证书选这个；
- **影像（JPEG）**——每页一张图，照片、素材选这个。

一个容易期待落空的地方：多项识别、书本扫描、存成可搜索 PDF 这几个进阶能力属于 HP+ 机型的增值功能，普通机型上看不到这些选项是正常的。

## 扫完直接交出去

预览页的分享按钮可以把结果直接交给系统面板：发邮件（自动作为附件）、传到绑定的云账号、走短信或聊天应用发给任何人。经常重复「扫描后发邮箱」这套动作的话，在应用里把它配成一键快捷方式更省事。

## 扫出来不对劲

- 一片黑：盖板没盖严或玻璃板脏了；
- 有黑边、歪斜：预览页里裁剪旋转，或重扫一次选「自动」边界；
- 进纸器卡纸：整叠纸抖齐、抽出粘住的便签再放；
- 应用里找不到扫描仪：先按[惠普打印机搜不到怎么办.md](惠普打印机搜不到怎么办.md)把连接恢复。
