# 电视大屏看七家直播的开源方案

> 想在电视或盒子上看虎牙、斗鱼、B 站的直播，又不想给每家平台各装一个 TV 应用？这里介绍一个把七个直播平台装进同一个客户端的开源方案 FUSE，讲清它在电视端的安装路径、遥控器操作和第一次打开要做的事。

## 一、这是一套什么方案

FUSE（前身叫 HuYaTv）是 GitHub 开发者 jayjd 维护的开源聚合直播客户端，把虎牙、哔哩哔哩、抖音、斗鱼、快手、YY、Twitch 的直播内容聚合到一个程序里。内容来自各平台的网页端，作者声明不收集个人信息；同一套安装包适配手机、平板、车机、电视和盒子，装上后第一次打开会让你选设备类型，电视上选「电视或盒子」即可，界面缩放和遥控器焦点操作都会随之调整。

想先浏览功能再动手，可以从 [FUSE 介绍站](https://fuse.qjxz.skin/) 看起，那里整理了各平台的功能矩阵和按键说明。

## 二、电视上的安装路径

安装包是 APK 格式，经网盘分享分发，电视上一般没有浏览器，走 U 盘最省事：

1. 在手机或电脑上把分享里的 APK 下载下来；
2. 拷入 U 盘，插到电视或盒子的 USB 口；
3. 用电视自带的文件管理器打开 APK 安装；装不上先到「设置 → 安全」里允许未知来源；
4. 装完打开，选择「电视或盒子」设备类型。

系统版本方面，新功能只针对安卓 6.0 以上适配，更老的 4.4 系统有开发者另发的旧版系列；聚合直播依赖各平台网页接口，接口一变旧版就会出现某个平台打不开，日常使用尽量保持新版本。

## 三、遥控器怎么用

电视端播放页的按键逻辑比较固定：菜单键呼出设置，弹幕与界面设置整合在一处；下键显示直播信息与更多直播内容；上键呼出收藏夹；左右键可以进入「刷直播」模式，上下键直接切换上一个、下一个直播间——这个模式默认关闭，怕的就是误触，想连着刷房再去播放页设置里打开。

在「刷抖音」板块里，遥控器逻辑更完整：菜单键能呼出全屏、评论、弹幕、清屏、不感兴趣等功能栏；手机扫码后还能把手机变成触摸板，上下换视频、左右快进，甚至直接发弹幕和搜索。

## 四、几个先知道的细节

- 只有虎牙板块提供搜索，想按主播名或房间号找房，切到虎牙再搜；
- 快手与 YY 没有弹幕，想看弹幕互动选别的平台；
- 未解锁 Live Pro 时，切换平台、进设置等操作受限，解锁入口在应用左上角，机制是「诚信付款」——先解锁，付不付由你自己决定；
- 单纯看直播不用登录任何账号，发弹幕、订阅这类互动才需要扫码登录对应平台。
