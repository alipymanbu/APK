# 聚合直播平台功能矩阵与弹幕设置

> 聚合了七个平台的直播客户端，每个平台能用的功能并不一样：有的能搜主播、有的没弹幕。这篇把 FUSE 的平台功能矩阵摊开讲，再带一遍弹幕面板里那些逐项可调的设置。

## 一、先看矩阵再决定怎么用

FUSE（前身 HuYaTv，开源项目）按各平台网页端接口的能力做了区分，下面是项目说明里给出的支持矩阵：

| 平台 | 直播 | 弹幕 | 画质 | 收藏 | 推送 | 搜索 |
| --- | --- | --- | --- | --- | --- | --- |
| 虎牙 | 有 | 有 | 有 | 有 | 有 | 有 |
| 哔哩哔哩 | 有 | 有 | 有 | 有 | 有 | 无 |
| 抖音 | 有 | 有 | 有 | 有 | 有 | 无 |
| 斗鱼 | 有 | 有 | 有 | 有 | 有 | 无 |
| 快手 | 有 | 无 | 有 | 无 | 无 | 无 |
| YY | 有 | 无 | 无 | 有 | 有 | 无 |
| Twitch | 有 | 无 | 有 | 有 | 有 | 无 |

读这张表的几个要点：

- 只有虎牙板块提供搜索，主播名、房间号都在那里查；
- 快手与 YY 没有弹幕，想互动就避开这两家；
- 网易 CC 曾在聚合之列，3.0.32 起被移除；
- 功能可用性以你手上版本的实际界面为准，旧版可能还没有后来加入的板块。

完整的平台说明与设备适配内容，见 [FUSE 介绍站](https://fuse.qjxz.skin/)，矩阵之外还整理了遥控器按键与「刷直播」模式的用法。

## 二、弹幕面板逐项可调

弹幕设置几乎是逐项给开关的，实拍界面里能看到这些条目：

- **弹幕开关**：一键全开或全关；
- **弹幕透明**：数值直调，1.0 为不透明；
- **弹幕大小**：字号数值直调，默认档在 18 上下；
- **弹幕行数**：同屏行数可减，屏幕小就少排几行；
- **弹幕去重**：打开后重复发言合并显示；
- **弹幕颜色**：默认样式之外可另选；
- **时间与网速**：播放页叠加显示，默认关闭；
- **首选项**：可按游戏直播这类分类来配。

画质方面，码率策略有自适应与最高档两档可切；播放器层面还能换自定义解码器、调渲染与缓冲模式。电视上遇到卡顿、花屏，先从这几处下手，而不是急着重装。

## 三、部分板块的播放方式不一样

虎牙、B 站、抖音、斗鱼这类主板块走应用内播放器；tvlive、weblive 两个板块走网页方式，播的是各平台网页端的内容，依赖系统 WebView——这两个板块加载异常时，先检查设备的 WebView 版本，再对照症状排查。
