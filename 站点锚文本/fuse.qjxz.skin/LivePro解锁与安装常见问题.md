# LivePro解锁与安装常见问题

> 装聚合直播客户端 FUSE 时，最常卡住的不是下载，而是三件事：Live Pro 没解锁导致切换平台受限、安装被系统拦下、老设备提示系统版本不符。这篇按问题逐条给出处理办法。

## 一、切换平台点不动：先解锁 Live Pro

装好 FUSE 后你会发现一部分功能点不动——切换平台、进设置等操作受限，多个第三方分享帖的说法一致。这不是坏了，是未解锁状态下的限制。

解锁入口在应用左上角的「Live Pro」：点开后选择「已诚信付款，解锁 LIVEPRO」即可。这是开发者内置的「诚信付款」机制——先解锁，之后付不付、付多少由你自己决定；认可这个工具的话，回它的 GitHub 项目捐一点，是这类个人项目能持续维护下去的方式。

解锁后如果某个平台仍然打不开，先确认是不是平台本身的问题：网易 CC 在 3.0.32 起已被移除，快手与 YY 本身就没有弹幕，别把这些当成故障。

## 二、安装被拦：放行未知来源

安卓对商店以外的安装包默认拦截，FUSE 又是经网盘分享分发的 APK，所以这一步几乎人人会遇到：

1. 点开 APK 时系统提示「不允许安装未知应用」；
2. 按提示进入设置，给你打开 APK 的那个应用（浏览器、文件管理器或网盘客户端）勾选「允许安装未知应用」；
3. 回到安装页重新点安装。

部分安全软件会额外提示风险——聚合直播客户端不在应用市场上架，被提示并不意外，确认来源后自行决定是否继续。更多安装细节可以看 [FUSE 介绍站](https://fuse.qjxz.skin/) 的安装步骤页，电视盒子走 U 盘的完整路径也写在那页里。

## 三、老设备：版本适配的边界

- 新功能只针对安卓 6.0 以上的设备适配，6.0 以下基本无碍、但仅保证能播；
- 安卓 4.4 有开发者另发的旧版系列（2.1.25.x），功能更新的节奏与 3.0.x 不同；
- 聚合直播依赖各平台网页接口，接口一变，旧版会出现某个平台打不开的情况——遇到「昨天还能看、今天加载不出」，先升级再排查。

## 四、装完后的第一件事

第一次打开会让你选设备类型（手机 / 平板 / 车机 / 电视或盒子），也可以自动检测。选错不用重装，进「设置 → 首选项」随时改。单纯看直播不需要登录任何账号；发弹幕、点赞、订阅这类互动才需要扫码登录对应平台。
