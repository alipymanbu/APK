# F-Droid 国内镜像仓库配置：给目录同步提速

> 默认仓库在国外、首次打开卡在目录同步、刷新索引总要等很久——这类问题的根源相同，换国内镜像仓库一次性解决。本篇给出已验证可用的镜像地址与完整配置步骤。
> **相关文档**：[下载安装与首次设置.md](下载安装与首次设置.md) · [是什么与收录标准.md](是什么与收录标准.md)

---

## 一、什么情况该配镜像

- 首次打开 F-Droid，应用目录（仓库索引）拉了很久都不完成，或反复报错；
- 每次下拉刷新索引都要等很久；
- 应用列表能出来，但下载安装包速度很慢。

镜像仓库在国内复制了一份完整的目录与安装包，客户端改从镜像同步后，速度与访问国内网站相当。

## 二、添加清华 TUNA 镜像

以清华大学 TUNA 镜像站为例（内容与源仓库同步，国内直连稳定）：

1. 打开 F-Droid，进 **设置 → 存储库**；
2. 点右下角的 **+** 新建一条仓库，名称随意填（如「TUNA 镜像」），地址粘贴下面这条：

   ```
   https://mirrors.tuna.tsinghua.edu.cn/fdroid/repo/?fingerprint=43238D512C1E5EB2D6569F4A3AFBF5523418B82E0A3ED1552770ABB9A9C9CCAB
   ```

3. 保存后回到存储库列表，**把默认仓库的开关关掉，只留镜像**——不关的话客户端仍会周期性去连国外源；
4. 回到首页下拉刷新，索引会从镜像重新同步。

之后想切回默认仓库，把开关开回来即可，两条仓库可以长期共存。

## 三、老版本应用的镜像（Archive 仓库）

另有一个 archive 仓库，保留大量应用的历史版本——老手机找能跑的旧版本时会用到。TUNA 同样镜像了它：

```
https://mirrors.tuna.tsinghua.edu.cn/fdroid/archive?fingerprint=43238D512C1E5EB2D6569F4A3AFBF5523418B82E0A3ED1552770ABB9A9C9CCAB
```

老机型用户建议两条一起加上；在应用详情页的版本列表里选历史版本安装，遇到「新版在老手机上闪退」的情况，往回退一两个版本经常能解决。

## 四、地址里那串 fingerprint 是什么

`?fingerprint=` 后面的长串是 F-Droid 源仓库的**签名密钥指纹**。客户端同步索引时会用它核对签名——镜像只负责搬运文件，目录与安装包必须仍是原密钥签发的那份才能通过校验，镜像方想塞私货过不了这一关。这也是可以放心添加镜像的原因。

## 五、两个注意点

- **镜像地址可能变化**：上面两条地址核对于 2026 年 9 月，以后若失效，以清华 TUNA 镜像站帮助页当时显示的为准，换新地址重新保存即可；
- **切换仓库不影响已装应用**：存储库只是下载来源，换镜像后已安装的应用照常运行，后续更新改从镜像走。

还没装好的话，先看[下载安装与首次设置.md](下载安装与首次设置.md)把安装走完；想了解这个应用收录了什么、适合谁，看[是什么与收录标准.md](是什么与收录标准.md)。
