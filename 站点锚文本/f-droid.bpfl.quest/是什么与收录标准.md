# F-Droid 是什么：一个只收录开源应用的安卓商店

> 本篇讲清 F-Droid 的定位、什么样的应用才进得了它的目录，以及它和手机里常见商店的差异。
> **相关文档**：[下载安装与首次设置.md](下载安装与首次设置.md) · [国内镜像仓库配置.md](国内镜像仓库配置.md)

## 一、一句话认识它

F-Droid 是装在安卓手机上的应用商店客户端，由志愿者社区维护，只收录自由开源软件。用它做的事情和别的商店一样：浏览、搜索、安装、更新，区别在于不要求注册任何账号，也不依赖谷歌服务框架——国产系统、老机型装不了常见商店的手机，照样能用。

它的基本盘（以收录的 1.23.2 版为准）：

- 安装包 11.85 MB，Android 6.0 起可装；
- 许可证 GPL-3.0，代码公开可查；
- 目录里没有付费解锁、没有内购。

## 二、收录标准：三条硬性门槛

应用要进它的目录，需要同时满足：

1. 代码以开源许可证发布（GPL、Apache、MIT 这类）；
2. 不含广告 SDK 与用户追踪成分；
3. 不做付费解锁、内购限制功能。

目录里的安装包由 F-Droid 项目从源码构建并签名，客户端同步与安装时会核对仓库索引签名与 APK 哈希，装到的包和公布的源码对得上。含广告、追踪这类成分的应用不会被藏起来，而是打上「反特性」标注留在目录里，挑选时一眼可见。

反过来说，国内主流的消费级 App 不在这个目录里——这是最常见的预期落差，先知道，免得装完找不到想找的东西。

## 三、和常见商店的对照

| 维度 | F-Droid | 常见手机商店 |
| --- | --- | --- |
| 需要账号 | 不需要 | 通常需要厂商或谷歌账号 |
| 广告与追踪 | 收录标准明确禁止 | 由开发者决定 |
| 付费内容 | 目录里没有 | 常见 |
| 依赖谷歌服务 | 不依赖 | 部分功能依赖 |
| 老机型支持 | Android 6.0 起可装 | 随系统升级逐渐抬门槛 |

两者互不干扰，可以并存——把它当成一个补充来源，专挑干净的工具类应用，是多数人的用法。

## 四、适合谁用

- 想要干净的工具应用：文件管理器、播放器、终端（如 Termux）、第三方客户端（如 NewPipe）这类需求，目录里都有对应选择；
- 不想为装应用绑账号、也不想装谷歌服务框架；
- 手里的老机型或国产系统装不了常见商店，又需要一个能管更新的应用来源；
- 不太适合：只想找国内主流消费级 App 的人。

想装一个试试，从[F-Droid 开源应用商店介绍站](https://f-droid.bpfl.quest/)进，里面有安装文件资源的获取入口和分步骤的安装说明；装好后的日常操作思路见[下载安装与首次设置.md](下载安装与首次设置.md)。
