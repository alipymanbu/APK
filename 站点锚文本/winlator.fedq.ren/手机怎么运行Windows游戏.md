# 手机怎么运行 Windows 游戏：条件、原理与预期

> 想在安卓手机上直接打开电脑游戏和 exe 程序，需要什么手机、能跑什么、跑不动什么，本篇一次讲清。
> **相关文档**：[图形驱动与Box64预设怎么调.md](图形驱动与Box64预设怎么调.md) · [exe游戏导入与快捷方式.md](exe游戏导入与快捷方式.md)

---

## 一、先说结论

中高端骁龙手机（845 及以后）可以把相当一部分 DirectX 9/11 时代的电脑游戏跑出可玩帧率；DirectX 12 新游和大型 3A 则不要抱期望。实现这件事不需要 root，也不需要连电脑，靠的是一类叫 Windows 兼容层的安卓应用，Winlator 模拟器是其中社区资料最多、更新最活跃的一个。

## 二、它靠什么跑起来

电脑游戏是给 x86 处理器和 Windows 系统写的，手机是 ARM 处理器加安卓系统，两头都对不上。兼容层做的事就是把这两层「对不上」翻译过去：

- **Wine** 接住程序对 Windows 系统的调用，换成安卓底层的等价操作；
- **Box86 / Box64** 在运行时把 x86 指令翻译成 ARM 指令——翻译本身要花性能，这是同一游戏在手机上比电脑慢的主要原因；
- **DXVK / VKD3D** 把游戏的 DirectX 画面调用转成 Vulkan，交给手机 GPU 渲染。

三个环节都在手机本地完成，所以离线也能玩，不依赖任何串流或云游戏服务。

## 三、手机要满足什么条件

| 项目 | 建议线 | 说明 |
| --- | --- | --- |
| 处理器 | ARM64，骁龙优先 | 内置的 Turnip 图形驱动面向 Adreno GPU，骁龙机型兼容性最好 |
| 内存 | 6GB 起 | 跑 3D 游戏时内存余量直接影响成败 |
| GPU | 支持 Vulkan | Mali 机型可以换 Vortek 或 VirGL 驱动，效果弱于骁龙方案 |
| 存储 | 预留 5GB 以上 | 兼容层本体加每个容器里安装的游戏都要占空间 |

没有 root 要求；系统版本只要能装上 APK 就可以试。安卓平板同样适用，屏幕大反而更适合触屏操作。

## 四、能跑什么、跑不动什么

- **跑得动**：DirectX 9 时代的老游戏与 2D 游戏是兼容性最好的一档，经典单机大多能进得去；.NET 写的工具软件在装上 Wine Mono 后也能用。
- **看机器**：DirectX 9/11 的 3D 游戏，骁龙中高端多数有可玩帧率，具体调法见[图形驱动与Box64预设怎么调.md](图形驱动与Box64预设怎么调.md)。
- **跑不动**：DirectX 12 特性依赖多的新游、对帧数稳定性敏感的联网对战游戏——兼容层的翻译开销在这两类上最吃亏。

同一份游戏在不同手机上差异很大，最省事的判断办法：先建一个低分辨率容器试跑，跑得起来再逐步加要求。

## 五、从哪一步开始

流程上分三段：拿到安装包并装好、建第一个容器、把游戏目录导进去。具体操作见[exe游戏导入与快捷方式.md](exe游戏导入与快捷方式.md)；安装包获取与安装步骤，可以直接看这个整理好的 [Winlator 资源与安装说明站](https://winlator.fedq.ren/)，按页面上的步骤走即可。
