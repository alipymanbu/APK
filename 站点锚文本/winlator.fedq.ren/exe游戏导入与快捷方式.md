# exe 游戏导入与快捷方式：从下载到开跑

> 装好兼容层之后，游戏怎么进手机、容器怎么建、快捷方式怎么用，本篇按操作顺序讲。
> **相关文档**：[手机怎么运行Windows游戏.md](手机怎么运行Windows游戏.md) · [图形驱动与Box64预设怎么调.md](图形驱动与Box64预设怎么调.md)

---

## 一、装好之后的第一件事：建容器

容器是一套隔离的 Windows 环境，程序都在容器里运行，相当于给每个用途单独配一台「小电脑」。主界面右上角点 **+** 新建容器：

1. 起个名字，其余选项先不动；
2. 骁龙机型保持默认即可；Mali 机型把图形驱动换成 Vortek 或 VirGL；
3. 分辨率先选低一档（如 1280x720），跑顺了再往上调。

## 二、把游戏目录放进手机

兼容层会申请文件访问权限，允许它。然后：

- 把电脑上的游戏文件夹整个复制到手机的 **Download** 目录（数据线、U 盘 OTG、局域网传输都行）；
- 在容器里打开文件浏览器，这个目录通常按 **D:** 盘出现——和给电脑插了块新硬盘一个道理。

安装类游戏（有 setup.exe 的）在容器里直接运行安装程序；免安装的绿色版，找到主程序的 exe 就能开。

## 三、快捷方式：每个游戏一套独立设置

在容器里选中 exe 可以生成「快捷方式」，回到主界面的快捷方式列表就能一键进入。它真正的价值在右侧的设置项：

- **单独附加运行参数**：比如 Unity 游戏加 `-force-gfx-direct`；
- **单独换 Box64 预设**：某个游戏卡，就只给它换档，不影响别的游戏；
- **单独选输入方案**：触屏键位、手柄映射都可以按游戏配置。

## 四、没手柄也能玩：虚拟按键

输入控制里有个「控件编辑器」，可以在屏幕上添加虚拟方向键与按键、调透明度和光标速度，配置文件能导入导出。外接手柄走蓝牙或 USB 直连，按键映射在同一个入口里配。

## 五、启动没反应或闪退

- **第一次建容器就闪退**：换图形驱动（Turnip / Vortek / VirGL 轮着试），Mali 机型别用默认驱动；
- **游戏打不开**：确认目录路径没有中文以外的特殊字符问题、exe 没有缺同目录的 dll 文件（复制游戏要整个文件夹一起）；
- **卡在黑屏**：降低容器分辨率、换 Box64 预设再试，排查思路见[图形驱动与Box64预设怎么调.md](图形驱动与Box64预设怎么调.md)。

如果还没装，先从 [Winlator 安装文件资源获取说明](https://winlator.fedq.ren/) 拿安装包、按步骤装好，再回来建容器。
