# 免 root 也能把安卓桌面换成 Pixel 风格

> 想要 Pixel 那套桌面，又不想刷机、不想动引导加载程序？本篇讲清楚免 root 换桌面的路线：需要什么、装什么、注意什么。

## Pixel 桌面的几个标志元素

用过 Pixel 手机的人对这套桌面都很熟：

- 屏幕底部常驻一条搜索栏，应用列表全收进抽屉；
- 桌面下方一排常驻 Dock，常用应用在任何页面都在手边；
- 应用有新消息时，图标上先冒一个通知圆点，长按才展开详情；
- 长按应用图标直接弹出快捷方式，比如「新建记事」「新建列表」，不用先点进应用再找入口。

问题在于，非 Pixel 的机型上，这套东西要么出厂就没有，要么被厂商桌面砍掉了部分——网格改不了、图标换不了、手势也不开放。

## 免 root 的路线是什么

Android 允许把「主屏幕应用」（也就是桌面启动器）换成第三方 APK。也就是说，把一个启动器应用装进手机、设为默认桌面，整个过程不需要 root、不需要解锁引导加载程序，系统更新和保修都不受影响。

Lawnchair 就是这条路线上最常见的选择之一：它是一个开源项目，代码基础是 Android 系统自带的桌面（AOSP Launcher3），目标是把 Pixel 桌面整套搬过来，再把每一处都开放给设置。装好设为默认的那一刻，底部搜索栏、Dock、通知圆点、长按快捷方式就都在了，之后你可以在设置里逐项按自己的习惯调。

它的各项能力与设置入口，可以到 [Lawnchair 启动器中文介绍站](https://lawnchair.bpfl.quest/) 先过一遍，装之前心里有数。

## 动手前先确认三件事

1. **系统版本**：收录的构建信息显示最低要求 Android 8.0。越老的系统，可调的项越少，但通知圆点这类能力在旧系统上也有兼容实现。
2. **安装方式**：这类启动器多走侧载安装，系统会拦一次「未知来源」——授权对象是"你打开安装包的那个应用"，不是全局开关。
3. **旧布局怎么办**：桌面上按习惯排了几年的图标不用重摆，启动器支持从 Nova 的备份文件直接导入布局，细节见 [从Nova迁移桌面布局.md](从Nova迁移桌面布局.md)。

换桌面只改变"摆放方式"，不动应用本身和个人数据，随时可以切回原桌面——这也算是这条路线最大的退路。
