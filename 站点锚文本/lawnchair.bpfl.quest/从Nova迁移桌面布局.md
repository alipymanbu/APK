# 从 Nova Launcher 换桌面：布局数据怎么搬

> 旧启动器上排好的图标、文件夹、小部件，换桌面时不用一个个重来。本篇讲从 Nova 换启动器时布局数据的两条搬家路径，以及搬不动的部分。

## 为什么这段时间换桌面的人变多

Nova 是很多老用户的长期主力桌面，但这几年它的归属变了：2022 年被 Branch Metrics 收购，2026 年 1 月再被 Instabridge 收购。此后有科技媒体报道，其新版中发现了广告追踪组件，还计划推出申请短信、通话记录、精确定位等敏感权限的助手功能。报道针对的是特定版本，情况还会变化，以最新消息为准——但对把"桌面干净、不追踪"放在第一位的用户来说，这段时间重新选启动器是合理动作。

## 布局数据的两条搬家路径

### 路径一：直接读 Nova 的备份文件

从 Nova 迁移过来的，Lawnchair 15 Beta 3 及之后的版本可以直接读取 Nova 导出的备份文件（`.novabackup`）。操作入口在：

```
主屏幕设置 → 更多（⋮）→ 恢复 Nova 备份
```

前提是你在旧桌面上先用 Nova 自己的备份功能导出过一份。恢复完成后，桌面网格、图标位置、文件夹结构会按备份内容还原。

### 路径二：用新启动器自己的备份体系

如果不是从 Nova 来、或者要在同一台手机上做快照，新桌面设置里的「备份」一节可以把当前布局存成文件，换机或重装后恢复回来。建议养成一个顺序：**动任何大改动之前，先备份一份**。

## 搬不动与容易踩的部分

| 情况 | 结果与处理 |
| --- | --- |
| 工作资料（工作账户）应用 | 不在备份范围内，各机型处理不一致，恢复不可靠，图标需手动补 |
| 低版本覆盖高版本 | 覆盖安装只在版本号往前走时顺利；想退回旧构建要先卸载再装 |
| 小部件 | 部分小部件恢复后需要重新授权或重摆一次，属正常现象 |

换成 Lawnchair 之后从哪里开始调，可以看 [Lawnchair 启动器中文介绍站](https://lawnchair.bpfl.quest/) 上按设置页顺序整理的说明；装不上或安装被拦，属于另一类问题，优先检查未知来源授权那条线。
