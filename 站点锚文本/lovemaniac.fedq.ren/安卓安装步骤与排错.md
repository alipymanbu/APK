# 安卓安装步骤与排错

LoveManiac 的安卓包拿到手就能装，整条路只有三步：转存、下载、安装。这篇把每步展开，再把装不上时最常撞见的三种报错按顺序排一遍。玩法与版本问题分别见 [弹幕躲刀与多路线玩法详解](弹幕躲刀与多路线玩法详解.md) 与 [版本更新节奏与语言现状](版本更新节奏与语言现状.md)。

## 先确认三件事

- **设备**：安卓 7.0 及以上；像素画风对硬件要求不高，近年主流机型都能跑；
- **空间**：安装包 89M 上下，安装需要临时空间，建议预留 500M 以上；
- **分级**：这是 18+ 成人向同人作品，未成年设备请不要安装。

## 三步装好

1. **转存到自己的网盘**：打开资源分享页，把安装包转存进自己的网盘账户。转存的意义在于分享链接可能失效，转存后包就稳稳落在你的账户里；
2. **下载到手机本地**：在网盘客户端里把 APK 下载到手机存储。别在预览页里直接点「打开」，先等文件完整下载完；
3. **允许未知来源，点击安装**：第一次点 APK 时系统会弹窗询问是否允许该应用安装程序，点允许，然后按「安装」等进度走完，点「打开」进游戏。

首次启动会加载大量资源，比平时慢一些，等十几秒再操作，别连点。

## 装不上？按这个顺序排

**点了 APK 提示「安装被阻止」**——没给安装权限。部分品牌（小米、华为等）会在点击 APK 时单独弹窗，直接在弹窗里允许即可；找不到弹窗就去 设置 → 安全（或「应用安装」）→ 安装未知应用，给浏览器或文件管理器开一次权限。

**提示「解析错误 / 应用未安装」**——几乎都是包没下完整：删掉已下载的文件，回网盘重新下载，下完确认文件以 `.apk` 结尾再装。存储空间不足也会报这个错。

**装好了但打不开、闪退**——先确认系统版本不低于安卓 7.0；再到应用信息里把存储权限打开（游戏要读写存档）；仍不行就清后台重进。若安装界面显示的应用名或图标明显不对，取消安装并重新下载。
