# 弹幕躲刀与多路线玩法详解

LoveManiac 的玩法骨架源自《传说之下》：剧情与战斗两条线交替推进，场景里做选择、方框里躲弹幕。这篇把两条线的机制与双端操作讲清楚，装好游戏之前可以先读一遍，心里有个底。装不上的问题看 [安卓安装步骤与排错](安卓安装步骤与排错.md)。

## 剧情线：选择比战斗更能改变走向

像素场景里走动、与角色交谈，是对话与 ACT 选择在推动路线。项目简介里那句「很多条路线最后是同一个结果，Chara 要跟你做个交易」基本概括了它的叙事姿态——分支很多、周目很多，但都围着 Chara 的这桩交易转。0.3.3 换上了新主菜单与新开场，从 0.3.4 起，主菜单里还能逛 Nebby 的商店，剧情场景也在持续加码。

## 战斗线：红心就是你自己

进入战斗后，屏幕中央的方框里有一颗红心，那就是你操控的单位。敌方回合，刀与骨头类的弹幕会从四面八方飞进方框，你要拖动红心在缝隙里走位；轮到你行动时，再从 FIGHT / ACT / ITEM / MERCY 四个指令里挑一个。这套「回合制外壳 + 弹幕内芯」的战斗不吃数值吃走位，新手在弹幕里死几次完全正常，别当成卡关。

两个与版本相关的体验点：0.3.3 里过场动画还跳不过（0.3.4 起才支持跳过）；游戏至今没有难度选项，社区从 0.3.x 一直在求，暂未加入。

## 手机端操作

安卓版提供两套触屏控件：虚拟方向键与虚拟摇杆，可以在设置里互相切换，部分场景摇杆比方向键顺手。对话与菜单用点按推进；战斗里部分场景直接用手指拖动红心。有玩家反馈虚拟按键偶尔失灵，点一下屏幕其他区域、或者换一套控件通常就能恢复。

## 电脑端操作

Windows 与 Linux 版走键盘：方向键移动，`Z` 或 `Enter` 确认，`X` 或 `Shift` 取消——这是《传说之下》系同人最通用的键位惯例。游戏没有键位自定义入口，个别键没反应时先确认输入法处于英文状态。

## 上手前半小时建议

1. 跟着开场走，先熟悉移动与点按；
2. 第一场战斗别急着赢，练「把红心送进弹幕缝隙」，躲得住就赢了一半；
3. 分叉剧情推进前留个心眼：跨版本更新有丢存档的风险，目前没有存档导出导入功能；
4. 语言默认英文（另有西语、俄语可选），短句配合像素演出大致能看懂走向。

想先看看实机画面再决定入不入坑，去 [lovemaniac 介绍站](https://lovemaniac.fedq.ren/) 翻截图区；版本与语言的问题见 [版本更新节奏与语言现状](版本更新节奏与语言现状.md)。
