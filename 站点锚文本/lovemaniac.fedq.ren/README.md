LoveManiac 是 Team Nebula 制作的 2D 像素风同人角色扮演游戏，取材自《传说之下》：对话与 ACT 选择推动多路线剧情，战斗靠拖动一颗红心躲避弹幕；作品含成人向内容，仅面向成年玩家。
