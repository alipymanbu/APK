# PS3模拟器固件与游戏导入

> 本篇讲模拟器装好后的两步关键操作：安装 PS3 系统固件、导入游戏文件。没有固件模拟器开不了任何游戏，没有游戏文件它就是个空壳。
> **相关文档**：[PS3模拟器手机版下载安装](PS3模拟器手机版下载安装.md) · [PS3模拟器哪些手机能玩](PS3模拟器哪些手机能玩.md)

---

## 一、为什么模拟器里什么都没有

装好的模拟器是空的，固件和游戏都不随 APK 一起分发——两者都受版权保护，只能由你自己准备。这不是缺功能，所有 PS3 模拟器（包括电脑版）都是这个规矩：

- **固件**：PS3 主机的系统软件，模拟器靠它才能像真主机一样运行游戏，从索尼提供的渠道免费获取。
- **游戏**：需要来自你自己的正版游戏备份（自己的光盘或主机里导出的数据），用别人的盗版游戏文件不在本篇讨论范围内。

## 二、下载并安装固件（PS3UPDAT.PUP）

1. 用手机浏览器打开索尼 PlayStation 的系统软件支持页面（playstation.com 的 PS3 system software 一节），选「用电脑更新」方式下载固件文件，得到约 200 MB 的 `PS3UPDAT.PUP`。
2. 把文件放进手机「下载」文件夹备用，只认这一个渠道就够了，别去第三方「固件下载站」找。
3. 打开模拟器进入主菜单，找到固件入口——没装过时一般显示 **Firmware: None**。
4. 选中文件等待安装完成，进度条可能分两次填满；装完状态不再是 None 即成功。固件只需装一次，之后升级模拟器一般不用重装。

## 三、导入游戏

### 支持的格式

| 格式 | 特征 | 说明 |
| --- | --- | --- |
| PKG | 单个 `.pkg` 文件 | 需在模拟器内安装，个别还要配套激活文件 |
| ISO | 单个 `.iso` 光盘镜像 | 自己光盘备份的常见形态，最省事 |
| 文件夹 | 含 `PS3_DISC.SFB` 与 `PS3_GAME` 子目录 | 主机硬盘备份的原始结构，整包拷入即可 |

### 导入步骤

1. 把游戏文件传到手机（USB、局域网、网盘都行，文件夹格式要保证目录结构完整）。
2. 打开模拟器，点主界面的 **+** 号；单个文件选「文件」，整批选「文件夹」。
3. 等待导入完成（PKG 安装耗时明显，属正常），列表没刷新就**下拉刷新**一次。

### 摆放建议

- **游戏文件平铺放在同一目录，别一层套一层**——嵌套太深会识别不到。
- 优先用解密好的 ISO，文件夹格式次之，PKG 最麻烦。
- 存储紧张可放 microSD 卡（建议 exFAT 格式），留意读卡速度对安装耗时的影响。

## 四、导入成功之后

- 游戏首次启动普遍很慢：模拟器要预编译游戏代码，几十秒到几分钟的黑屏转圈都正常，编译结果会存成缓存，第二次启动明显变快，中途别杀进程。
- 进游戏后第一件事是接蓝牙手柄，PS3 游戏按手柄设计，触屏方案很难同时模拟双摇杆加四个肩键。
- 还没装模拟器的，先看 [PS3模拟器手机版下载安装](PS3模拟器手机版下载安装.md)；不确定机器够不够格的，看 [PS3模拟器哪些手机能玩](PS3模拟器哪些手机能玩.md) 的门槛表，或直接去 [RPCS3 安卓版实测与配置专题](https://rpcs3.djnf.quest/) 查公开实测数据。
