# 追番时间表与找番技巧

> 搜索、分类、排行榜三条找番路径，以及连载季最好用的每周时间表。
> **相关文档**：[下载安装全流程.md](下载安装全流程.md) · [离线缓存与投屏电视.md](离线缓存与投屏电视.md)

追番最怕的不是没得看，而是「更新了不知道」。mifun 把找番和追更拆成了两套入口：找番靠搜索与分类，追更靠那张按星期排片的时间表。应用内完整的功能说明也可以在 [mifun 介绍站](https://mifun.gltd.quest/)里翻到。

## 三条找番路径

| 状态 | 用哪条路 |
| --- | --- |
| 就想看某一部，记得名字 | 顶部搜索框 |
| 没目标，想按口味挑 | 分类标签（题材 / 地区） |
| 想看看最近什么火 | 排行榜、首页推荐 |

搜索时名字打不全也能命中，只记得两三个字照样搜；搜不到就换一个说法，同一部作品的通行译名和民间叫法常不一样。

## 时间表怎么用

1. 找到时间表入口（底部标签栏里），在播的番按星期一到周日排开。
2. 看当天那一列，点番名直接进详情页。
3. 想追的先收藏，之后从「我的」页面进，不用每周重搜。

连载番每周固定时段更新，漏掉一两集是常态，从观看历史点开续播就行。周末用 WiFi 把下周要看的几集提前缓存，通勤路上直接离线播，具体操作见 [离线缓存与投屏电视.md](离线缓存与投屏电视.md)。
