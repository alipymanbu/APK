# 离线缓存与投屏电视

> 把剧集下载到手机离线看，以及把画面投到电视大屏上。
> **相关文档**：[下载安装全流程.md](下载安装全流程.md) · [追番时间表与找番技巧.md](追番时间表与找番技巧.md)

这两件事都在播放页里完成：缓存管「没网也能看」，投屏管「屏幕不够大」。mifun 介绍站上对两个功能的入口位置有更完整的截图说明，见 [mifun 介绍站](https://mifun.gltd.quest/)。

## 离线缓存四步

1. 进入想看那部番的播放页。
2. 点下载图标，弹出集数列表。
3. 勾选要下的集数，多选后开始下载。
4. 进度在「查看下载列表」里看，下载在后台进行。

三点提醒：缓存存在应用私有目录，外部文件管理器翻不到，管理只走「我的 → 离线缓存」；误删不能恢复，清理前看一眼有没有没看的集数；缓存文件不跟账号走，换手机或卸载重装就没了，重要剧集提前安排。

## 投屏到电视

1. 手机和电视连**同一个 WiFi**，这一步最关键。
2. 打开 mifun，进播放页。
3. 点右上角的投屏 / TV 按钮。
4. 等列表里出现电视设备，点它就连上。

连不上时按顺序查：是否同一网络；电视的投屏开关有没有打开；手机和电视离路由器是否太远；同一网络里有没有设备在大量下载。画面断续通常不是应用的问题，把画质降一档或改用 5GHz 频段会明显好转。

找番和追更的安排写在 [追番时间表与找番技巧.md](追番时间表与找番技巧.md)里，还没装应用的话先看 [下载安装全流程.md](下载安装全流程.md)。
