# 无Root手机怎么用网盘聚合服务

不少人在接触 CloudDrive2 这类聚合工具时，第一个疑问是：手机没 Root，是不是装了也没用？实际情况是——只有「把网盘挂载成本机目录」这一件事需要 Root，因为那要向系统文件系统申请挂载点；其余日常能力，浏览聚合后的网盘、跨盘传输、相册备份、对外提供 WebDAV，都不依赖 Root。安卓端打开后甚至会明确提示「未获得Root权限，不能本地挂载」，把边界讲在明处，而不是悄悄失效。

## 通道一：SAF，系统文件选择器里的网盘

SAF（Storage Access Framework，存储访问框架）是安卓系统提供的标准文件接口。在 CloudDrive2 的设置里打开「启用存储访问框架」之后，手机上支持 SAF 的应用——文件管理器、播放器、办公软件——在各自的「打开文件」界面里就能直接选中 CloudDrive 目录，读到的是聚合后的全部网盘内容。

几个要点：

- 开关在 App 设置页里，名字就是「启用存储访问框架（SAF）」，打开即生效；
- SAF 根目录默认是根路径，也可以在弹出的系统选择器里圈定某个子目录，把暴露范围收窄；
- 读写走的是系统标准接口，不需要给任何应用额外的存储授权，也不需要刷机。

适合的场景很典型：播放器里选片、文档工具里打开网盘里的压缩包、文件管理器里直接把网盘文件复制到本地——只要应用支持 SAF，网盘就像多了一个可挂的来源。

## 通道二：WebDAV，给不认 SAF 的应用用

另一条通道是 WebDAV。CloudDrive2 装好后本身就是一个 WebDAV 服务端，默认端口 19798，同网段的设备都能连。播放器、电视盒子、桌面软件里填上地址与账号，就能把整个聚合目录当作远程磁盘浏览。

两条通道怎么分工，可以简单记成：

- **SAF**：应用在本机、走系统文件选择器，适合零配置的场景；
- **WebDAV**：跨设备或应用只认协议地址，适合播放器、盒子和桌面端。

顺带一提，网页管理台也在同一个端口上：浏览器输入 `http://手机IP:19798` 就能进，添加网盘账号、整理目录都在那里完成，账号支持扫码与授权登录。

## 唯一的限制，以及要不要补上

如果某天确实需要「网盘出现在文件管理器根目录」这种本机挂载效果，那属于 Root 才能做的事，没有绕开的办法。但对多数「手机取用网盘文件」的需求，SAF 加 WebDAV 已经覆盖：一个管本机应用取用，一个管跨设备连接。
