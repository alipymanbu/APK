# PCNapp 导航首页与商城入口怎么用

> 本篇讲 PCNapp 装好打开后的两个主要用法：首页的网址导航，以及「奔跑吧 P客」商城聚合页怎么进、怎么逛。

## 一、先认识它的界面结构

PCNapp（应用市场里也写作 p.cn 或 PCN，包名 com.scce.pcn）的底部导航大致是「首页 / P信 / 我 / 更多」几栏。日常用得最多的是两块：

- **首页导航区**：新闻、影视、娱乐等常用站点按图标排开，点图标直达对应网站，省去先开浏览器再搜索的步骤；
- **商城聚合区**：从首页进入「P客」模块，就是「奔跑吧 P客」页面，把京东、苏宁易购、当当、国美在线等购物站聚成一屏，按「购物 / 生活 / 女性 / 旅游 / 海淘」分类摆放。

界面截图与版本信息（当前存档版本 3.4.2，安装包约 45 MB，安卓 5.2 起可装）可以在 [PCNapp 介绍站](https://pcnapp.fewa.skin/) 的「界面一览」一节看到实拍图。

## 二、导航页的日常用法

1. 打开应用，停留在首页；
2. 顶部搜索框支持「百度」等引擎切换，直接输关键词或网址都能走；
3. 往下滚动找常用站点图标，点开即达；桌面上方还有天气与时间小组件。

导航页里某个站点打不开时，先用系统浏览器访问同一个网址试试：系统浏览器也打不开，就是那个站点自己的问题，和工具无关。

## 三、「奔跑吧 P客」聚合页怎么逛

1. 首页找到「P客」入口点进去；
2. 顶部按分类切换（购物 / 生活 / 女性 / 旅游 / 海淘）；
3. 点具体商城图标（如京东、苏宁易购、拼多多、1号店等）会跳转到对应站点，浏览与下单都在对方站点完成。

要留意的两点：

- 聚合页只是「把入口摆在一起」，商品、价格、售后都归属各商城本身，遇到问题应找对应商城的客服；
- 商城内若出现「购物返 P币」「DP 抵扣」之类的活动提示，规则写得绕的先别参与，搞懂再动手（下篇会展开讲）。

## 四、别忽略的几个细节

- **网络要求**：导航与商城内容全部联网加载，页面空白或转圈先检查网络，切换 Wi-Fi 与流量各试一次；
- **权限收窄**：只用导航功能的话，存储、位置等权限可在「设置 → 应用 → PCNapp → 权限」里按需关闭；
- **版本过旧**：入口位置和本文对不上时，多半是版本差异，重新取一份新包装上即可（取包入口见 [安卓手机下载安装步骤](安卓手机下载安装步骤.md)）。
