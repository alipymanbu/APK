# 模型切换与使用技巧

> 一个对话框里装着六款模型，怎么选、怎么切、怎么让它把活干得更漂亮，这篇按场景拆开讲。

## 先认位置

打开应用后主界面就三块：顶部中间的模型下拉（默认显示 ChatGPT 4o）、中间的四个快捷入口、底部的输入框。右上角笔形图标用来新建对话——换话题就点它重开一轮，别在旧对话里硬切话题，上下文混在一起答案容易跑偏。

## 六款模型怎么选

| 你要做的事 | 优先试 |
| --- | --- |
| 数学、逻辑、要多步推理的题 | DeepSeek R1 / ChatGPT o1 这类推理款 |
| 日常问答、翻译、写短文案 | 默认的通用模型（ChatGPT 4o） |
| 长报告、长文献梳理 | Claude 3.5 |
| 中文问答 | DeepSeek V3 |
| 想对比同一问题的不同回答 | 切个模型再问一遍，放一起比 |

切模型不用退出对话：顶部下拉点开、选一个，接着聊就行。下拉里的名单以你手上那版实际显示为准，个别模型临时没响应就换一个再发。

## 四个快捷入口是预设模板

「创建图片、获取建议、制定计划、更多」本质是四组预设好的提示词：点进去把示例问题改成自己的再发送，比从空白输入框硬组织快得多。写东西想要更可控，开头一次说清给谁看、什么体裁、多长、什么口吻四件事；写完不满意别重打需求，直接追加「第二条再短一半」「语气正式些」这类修正。

## 三个进阶用法

1. **传文档提问**：文献、报告从输入框左侧「+」整个传进去，先让它用五条总结核心信息，确认读对了大意再追问细节，问句带上「根据我传的文档」更不容易跑偏；
2. **联网问时事**：问新闻、价格这类会过期的信息，问题里写明时间口径（比如「2026 年 9 月的」），拿到结论点开它给的来源核一遍再采用；
3. **整段翻译**：长文粘进去先加一句「列出需要我确认的术语」，确认完再翻，返工少。
