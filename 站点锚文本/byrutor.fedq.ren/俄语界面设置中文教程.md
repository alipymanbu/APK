# Byrutor 俄语界面设置中文教程

Byrutor 出自俄语区的游戏资源目录，装好后默认界面多半是俄语或英语。这篇给两条路：先找应用内语言选项，找不到就用翻译兜底。

## 一、先在应用内找语言选项

进个人中心或设置页，找 `Settings`（俄语常显示为 `Настройки`）或 `Language`（`Язык`）字样的入口，语言列表里若有 `中文` / `Chinese`，选中保存后回主界面看是否生效。

注意：不同版本的界面布局有差异，若你的版本里没有语言入口，直接走下面第二条路，不必折腾。

## 二、翻译兜底

页面类内容靠机器翻译就能看懂大意：

- 应用内或浏览器弹出「翻译成中文」提示时，直接点它；
- 没有弹窗，就把浏览器或系统层「网页自动翻译」打开再访问。

俄语页面走机器翻译，按钮、菜单、分类名大体翻得准，个别词条会生硬，对照图标理解即可——目录站的界面本就以封面图为主，文字障碍比想象中小。

## 三、认几个高频俄语词

翻译不可用时，记住这几个高频词就够日常浏览：

| 俄语 | 含义 |
| --- | --- |
| Категории | 分类 |
| Новинки | 新作 |
| Обновления | 更新 |
| Популярное | 热门 |
| Поиск | 搜索 |
