# Byrutor 打不开或白屏解决办法

打开白屏、一直转圈、人机验证过不去——这些症状多与网络可达性有关，而不是安装包坏了。按下面的顺序排查。

## 一、白屏 / 一直加载

1. **换网络重开**：Wi-Fi 和移动数据各试一次，先排除当前网络的问题；
2. **等 30 秒**：海外目录在部分网络下首屏偏慢，短暂等待有时就能加载出来；
3. **理解可达性差异**：它是俄语区服务，不同网络、不同时段的连通性差异很大——某个网络下打不开不等于应用失效，换网络能开就是网络路径问题。

## 二、人机验证过不去

首次启动的人机验证依赖网络请求：

- **验证框加载不出来**：页面资源被网络拦了，换网络再开一次；
- **点了没反应**：验证请求超时，退掉应用重新打开，让验证组件重新加载。

多数情况一两回就能过；反复失败先把第一步的网络问题排除。

## 三、搜不到想找的条目

这不是打不开，但常被当成「站坏了」：用**原文名**（外语名）搜而不是中文译名；记不全就只输前几个字母看联想；再试试去掉副标题或换系列简称。确实没有，就是目录暂未收录。

## 四、磁力点了没反应 / 下载停滞

磁力与种子要交给 torrent 客户端传输，浏览器直接点是没用的；做种人数长期为 0 的条目等多久都下不动，直接换条目。完整流程见[磁力与种子下载怎么用](磁力与种子下载怎么用.md)。
