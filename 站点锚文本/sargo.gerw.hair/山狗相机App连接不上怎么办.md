# 山狗相机App连接不上怎么办

> 手机搜不到相机热点、连上就提示无网络、实时画面卡顿、App 反复掉线——山狗相机与手机连接环节的高频问题，多数解决办法只是改一个手机设置。本篇按现象汇总排查顺序。
> **同目录其他文章**：[手机怎么连接山狗相机.md](手机怎么连接山狗相机.md) · [山狗相机视频怎么导出到手机.md](山狗相机视频怎么导出到手机.md)

## 一、先分清"连接失败"和"正常提示"

连上相机热点后手机提示「无网络 / 无法访问互联网」，**不是故障**：相机 WiFi 只用于相机与手机之间传数据，本来就不通互联网。此时选「仍要连接」、不要切回流量或家里 WiFi 即可；真正算连接失败的是下面这些情况。

## 二、手机搜不到相机热点

按顺序核对：

1. 相机 WiFi 是否真的开了——开机后快速连按两下按键，震动一次、黄（绿）灯亮才算成功；
2. 相机是否正在录像中——蓝灯闪烁说明在录像，先停录再双击按键开 WiFi；
3. 相机是否因没插卡即将自动关机——震动五次、红灯快闪后自动关机是没插卡或卡错误的表现，先插一张高速卡；
4. 手机贴近相机到几米内再看 WLAN 列表，隔墙信号衰减明显；
5. 重启相机、重开手机 WLAN 开关再试。

## 三、连上就掉线、热点被切走

安卓手机的「网络加速」「WLAN 助理」「双 WiFi 模式」检测到当前 WiFi 不能上网时会自动切到别的网络，而相机热点恰恰"不能上网"。进手机设置把这三类开关全部关掉（华为机型叫 WLAN+），再重连即可。

## 四、实时画面卡顿、掉帧

关闭手机的流量数据 / 蜂窝数据，只留相机 WiFi 一条通道；同时手机离相机近一点。相机热点是直连通道，速度和距离直接相关。

## 五、App 装不上或装完异常

华为 / 鸿蒙手机先到「设置 → 系统和更新 → 纯净模式」关闭增强防护再安装；安装来源与步骤可参考 [sargo.gerw.hair](https://sargo.gerw.hair/download.html) 的下载安装页。装完首次打开记得按提示允许存储、WLAN 权限，否则浏览相机文件会受限。

## 六、以上都排除后仍连不上

把相机恢复出厂设置再走一遍连接流程（恢复出厂会清空设置，存储卡里的文件不受影响）；仍无效就联系购买渠道的售后处理。连接成功后的预览、回放、下载操作见 [手机怎么连接山狗相机.md](手机怎么连接山狗相机.md) 与 [山狗相机视频怎么导出到手机.md](山狗相机视频怎么导出到手机.md)。
