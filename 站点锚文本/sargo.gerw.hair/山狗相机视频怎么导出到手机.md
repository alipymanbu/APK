# 山狗相机视频怎么导出到手机

> 山狗相机拍完的素材，最快的取用方式是用配套应用 SARGO 通过 WiFi 直接传进手机相册；整卡导出或应急场景还有数据线、OTG 两条路。本篇讲三条通道怎么选、怎么操作。
> **同目录其他文章**：[手机怎么连接山狗相机.md](手机怎么连接山狗相机.md) · [山狗相机App连接不上怎么办.md](山狗相机App连接不上怎么办.md)

## 一、三条通道怎么选

| 方式 | 适合场景 | 前提 |
| --- | --- | --- |
| App WiFi 下载 | 挑几个片段发手机、发社交平台 | 手机装好 SARGO 并连上相机 |
| 数据线连电脑 | 整卡素材导出、剪辑备份 | 原装数据线（不少第三方线只能充电不能传数据） |
| OTG 传手机 | 出门在外没有电脑 | 手机支持 OTG、OTG 线 / 读卡器 |

WiFi 下载方便但速度受相机热点限制，几十 GB 的整卡素材不值得；整批导出交给数据线，应急用 OTG。

## 二、App WiFi 下载：先回放再下载

1. 手机连上相机热点（完整连接步骤见 [手机怎么连接山狗相机.md](手机怎么连接山狗相机.md)）；
2. 进设备的文件列表，**先在线回放**翻一遍这次录了什么，挑出要留的片段——比"全部下载再逐个删"省时间得多；
3. 多选要留的文件，一次下载到手机相册；
4. 下载走的是相机热点直连，手机离相机越近越稳；过程中提示"无网络"属正常，别切网。

回放时看到想要的画面，也可以直接点拍照把当前帧存进相册，省去导出再截图的步骤。

## 三、数据线导出到电脑

1. 相机关机状态用**原装数据线**连到电脑 USB 口；
2. 相机被识别成存储设备（触屏款按屏幕提示选「U 盘 / 存储模式」）；
3. 打开盘符进 `DCIM` 之类的视频目录，把文件复制到电脑；
4. 复制完再拔线，别在传输中途断开。

各型号在电脑端的识别方式略有差异，机身上/说明书里的型号名是找对应教程的线索；A 系还分触屏版与按键版两种流程。

## 四、OTG 传到手机

用 OTG 线把相机（或把存储卡插进读卡器）接到手机，文件不经电脑直接进相册。两个注意点：

- 部分手机要在设置里手动打开 OTG 功能，搜不到设备时先去设置里搜「OTG」；
- 大批量传输时手机保持供电，掉电快的机型插着充电线再导。

WiFi 传输过程中画面、连接出现异常的排查思路，见 [山狗相机App连接不上怎么办.md](山狗相机App连接不上怎么办.md)。还没装配套应用的，从 [sargo.gerw.hair](https://sargo.gerw.hair/) 这个介绍站可以进入安卓安装文件资源的获取入口。
