# AI 助手安卓版怎么下载安装

想在手机上用上开源个人 AI 助手 OpenClaw，装好安卓端是第一步。这篇把获取路径、安装要点和容易卡住的地方一次说清，都是按真实安装流程整理的。

## 装之前，先分清“遥控器”和“主机”

OpenClaw 采用两端协作的结构：安卓应用是配套节点，负责让你在 WhatsApp、Telegram 这类聊天软件里发号施令、接收推送；真正执行任务的，是跑在电脑或服务器上的 Gateway 网关。换句话说，装 APK 只是拿到遥控器，主机那一头也得安排好，装完才有的聊。

## 从哪里拿到安装包

安卓端的分发渠道有 Google Play 和 GitHub Release 的签名安装包两种；访问不便时也可以走网盘转存路线：[OpenClaw 资料站](https://openclaw.fedq.ren/)的下载页收录了夸克网盘分享入口，登录后转存到自己的网盘，再用客户端下到手机即可。

## 安装四步

1. 打开网盘分享页，把文件转存到自己网盘；
2. 用夸克网盘客户端把安装包下载到手机存储；
3. 首次点开安装包，系统提示“禁止安装未知来源应用”，按引导允许刚才的下载来源安装应用；
4. 回到安装页点安装，桌面出现龙虾图标即完成。

## 两个高频疑问

**点安装被系统拦住？** 这是安卓对未知来源的保护机制，按弹窗提示给下载来源授权就行，不用改系统全局设置。

**装完打开却连不上？** 多半是主机侧网关还没跑起来，或者手机和主机不在同一网络。先确认主机进程在运行，再做配对；两端怎么分工、只有一部手机行不行，另一篇[只有一部手机能玩转AI助手吗](只有一部手机能玩转AI助手吗.md)有展开。
