# 电视搜不到投屏设备

> 手机上点开投屏，列表里却没有家里电视的名字——这是无线投屏最高频的故障。本篇按出现概率给排查顺序，从电视端状态到路由器设置逐项过。还没走通连接流程的先看 [手机怎么投屏到电视](手机怎么投屏到电视.md)。

## 一、按这个顺序查，多数在前三步解决

1. **电视端的无线显示开了没有**：电视必须停在「等待连接」界面，手机才可能扫到它。各品牌入口叫法不同（无线投屏 / 屏幕镜像 / Screen Mirroring / Smart View），先把它打开；
2. **两端是不是同一个 Wi-Fi**：手机开着流量、或家里主副路由各连一个，都互相看不见。电视插网线也算不在一个网里，先切到无线；
3. **两端 Wi-Fi 各自重开**：手机 Wi-Fi 关掉再打开，电视端投屏功能退出重进；
4. **电视断电重启**：电视久不关机会缓存住网络状态，断电半分钟再上电，对老电视尤其有效；
5. **路由器的「AP 隔离」或访客网络**：这两种模式会把局域网内设备互相隔开，手机和电视谁也看不见谁。进路由器管理页关掉 AP 隔离，或让两端都连主网络。

## 二、能搜到，但点了连不上

- 电视端弹出的确认框要在时限内点「允许」，超时有些电视会自动拒绝，重新发起并尽快确认；
- 手机和电视之间别隔墙，信号弱时握手容易失败；
- 换一条路试：系统设置里的投屏入口和第三方工具（比如 Miracast - Wifi Display 这类应用）连的是同一个功能，一个通道卡住时另一个可能就通了。工具的安装与使用见 [miracast 无线投屏工具](https://miracast.fewf.click/)；
- **热点验证法**：用另一台手机开个人热点，让投屏手机和电视都连这个热点再试。热点下能连——设备都好，问题出在原路由器；热点下也连不上——往设备本身找原因。

## 三、搜遍了就是没有这台电视

有一种可能要接受：电视根本不支持无线显示。老款智能电视可能没有任何投屏入口，此时：

- 电视带 HDMI 口的，外插一个 Miracast 电视棒 / 无线显示适配器，电视就有了接收能力；
- iPhone 投电视走的是 AirPlay 协议，跟安卓这套无线显示不是一个体系，接收端要单独支持；
- 只有 HDMI、纯接视频流的 DLNA 设备做不了整屏镜像，那属于另一类用法（见 [投屏镜像和推送的区别](投屏镜像和推送的区别.md)）。

## 四、搜到了也连上了，但画面卡

这属于另一类问题：镜像走局域网，卡不卡主要看路由器远近、Wi-Fi 拥挤程度和信道占用，跟外网带宽关系不大。让两端都连 5GHz 频段、手机离路由器五米以内、投屏时停掉家里的大流量任务，是最见效的三招。
