# 投屏镜像和推送的区别

> 「投屏」一个词，实际混着两种动作：整屏镜像和内容推送。搜不到设备、投出去效果不符合预期，多数是因为把两者当成了同一件事。本篇把它们拆开讲清。连接操作本身见 [手机怎么投屏到电视](手机怎么投屏到电视.md)。

## 一、核心差别：电视跟着谁走

| | 镜像（屏幕镜像） | 推送（Cast / DLNA） |
| --- | --- | --- |
| 电视显示什么 | 手机屏幕的实时复制，你看到什么电视就是什么 | 只显示被推送的那个视频，手机可以干别的 |
| 手机的角色 | 画面源，电视全程跟拍 | 类似遥控器，电视自己找内容播 |
| 常见入口 | 设置里的「无线显示 / Smart View」、Miracast 这类工具 | 视频 App 播放页里的电视图标 |
| 适合场景 | 投没有投屏按钮的内容、相册、游戏画面 | 看 App 自带片源的影视 |

一句话记忆：**镜像投的是「手机这块屏」，推送投的是「那一个视频」**。

## 二、Miracast 属于哪一边

Miracast 是无线显示标准的名字，也是安卓手机做整屏镜像所走的通道——手机把屏幕画面实时编码后通过 Wi-Fi 直接送 到电视，属于镜像这一边。Miracast - Wifi Display 这款同名工具做的事情，就是把系统里这个镜像入口收拢成一个「打开即扫、点一下就连」的界面，底层能力还是系统自带的。它的功能构成和设备要求可以在 [miracast 无线投屏工具介绍站](https://miracast.fewf.click/) 看到。

推送则走另一套协议（DLNA 或各家的 Cast），只把播放地址和进度交给电视，画面由电视自己拉取渲染。

## 三、选哪种，看你要投什么

- 想让电视显示**手机上的任意画面**——App 内没有投屏按钮的内容、相册照片、游戏过程、视频通话——用镜像；
- 只是想**在电视上看某个视频**，而且视频 App 自带电视图标——用推送更省心，手机还不被占用；
- 两个入口同时试是正常操作：同一台电视可能这条路通、那条路卡，尤其在不同网络环境下表现会有差异。

## 四、镜像常见的不理解

- **「为什么投出去手机不能干别的？」**——镜像投的就是整块屏，手机上的一切都会被看见，这是特性不是故障；
- **「为什么推送没有我的手机界面？」**——推送本来就只送内容不上屏手机画面，不是连错了；
- **「镜像卡顿怎么调？」**——看路由器距离、频段和拥挤程度，环境层面的处理思路整理在 [电视搜不到投屏设备](电视搜不到投屏设备.md) 的排查篇里。
