# LibChecker 站点文章合集

这里是围绕 LibChecker 的介绍与上手文章合集。LibChecker 是一款开源的 Android 应用检查工具，可以查看应用的 ABI 架构、内嵌第三方库与四大组件，并用快照对比应用升级前后的变化。

更多使用场景与安装文件资源入口，见 [LibChecker 检测台](https://libchecker.gkhf.beer/)。
