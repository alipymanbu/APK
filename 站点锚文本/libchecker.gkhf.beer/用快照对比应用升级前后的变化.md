# 用快照对比应用升级前后的变化

应用更新日志往往只有一句「优化体验，修复若干问题」——可组件到底加了几个、后台服务是多了还是少了，日志不会告诉你。LibChecker 的快照功能给了另一种查证方式：在应用升级前后各留一份「档案」，两相对比，变化清清楚楚。

## 快照是什么

快照可以理解为某个时间点上应用组件情况的存档：四大组件、原生库等关键信息按当时状态记录下来。升级一个应用前先拍一份，升级完成后再拍一份，两份档案之间的差异就是这次更新的真实变化。

## 操作路径

1. 打开 LibChecker，切到「快照」页；
2. 在应用升级前，为它创建一份快照；
3. 到应用商店或包管理器里完成升级；
4. 回到快照页再拍一份，选择对比，即可看到组件的增加、移除与变更。

对比结果会按「增加 / 移除 / 变更」分类呈现，每一条都能点开看具体是哪个组件。

## 什么时候用得上

- **权限与服务突然变多**：升级后后台服务数量变了，快照一对比就知道多了哪些；
- **大版本更新前后的体检**：跨大版本升级往往伴随组件重构，值得留档比对；
- **长期观察某款应用**：想知道它是不是越更越臃肿，历史快照就是证据链。

快照支持备份与恢复，换机或重装后档案可以迁移，长期观察不中断。
