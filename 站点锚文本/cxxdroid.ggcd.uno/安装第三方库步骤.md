# 安装第三方库步骤

C++ 的作业和练手项目迟早会用到库：数据结构课要 Boost，数据库练习要 SQLite，写个小游戏要 SDL2。本篇讲在 Cxxdroid 里把这些库装起来的做法，以及几个容易卡住的点。还没装好软件本体的，先看[手机写 C++ 离线编译指南](手机写C++离线编译指南.md)。

---

## 为什么手机上装库不折腾

自己在手机上交叉编译一个 C++ 库是相当硬核的活。Cxxdroid 的解法是内置一个包管理器，背后连着专属仓库：常用库都提前编译好了，做成一个一个的包，列表里点 INSTALL 就能用，不需要碰命令行。

## 实际操作步骤

1. **打开包管理器**。在 App 主界面进入 Package manager，库里按字母排好。
2. **搜索需要的库**。Boost、SQLite、ncurses、libcurl 这些常用项都在列表里，每个包会标注版本号和体积。
3. **点 INSTALL**。下载和解包自动完成，装完回到编辑器就能 `#include` 对应头文件。
4. **编译验证**。写个三五行的小程序调用库里的一个函数，能编译通过、能跑出输出，库就算就位了。

图形库（SDL2、SFML、Allegro）也在同一个仓库里，装好后在示例工程里能找到对应的演示代码，跑起来是带画面的小程序，很适合给自己打气。

## 三个容易卡住的点

- **空间不足**。装库前先看一眼剩余空间，Boost 这类大家伙单独就能占上百 MB，开发者建议整台手机留 200MB 以上的余量，别把存储压到极限。
- **装库才需要联网**。写代码、编译、运行都是离线的，只有从仓库下载包这一步需要网络；断网状态下点 INSTALL 会失败，连上网重试即可。
- **找不到某个库**。优先级是"先把常用的移植过来"，开发者的重心在覆盖常见库上。列表里确实没有的，只能等更新或换替代方案。

## 一个提醒

包管理器解决的是"装得上"，用得对不对还是语法问题。第一次用某个库，建议直接从内置示例里找对应的演示工程跑一遍，再改成自己的需求，比从零写省很多排查时间。
