# Cxxdroid 手机 C/C++ 编译器 · 文档导读

这里是围绕 **Cxxdroid**（安卓手机上的 C/C++ 编译器 IDE）整理的一组第三方文档，供想用手机学 C++、练代码的读者查阅。软件本体与获取入口见 [Cxxdroid 介绍站](https://cxxdroid.ggcd.uno/)，下面是本目录里各篇文章的索引。

## 文档列表

- [手机写 C++ 离线编译指南](手机写C++离线编译指南.md) —— 为什么手机不联网也能编译运行 C++，以及从零写出第一个程序的路径。
- [安装第三方库步骤](安装第三方库步骤.md) —— 用内置包管理器装 Boost、SQLite、ncurses、SDL2 等常用库的做法。
- [终端与 REPL 用法](终端与REPL用法.md) —— 交互终端、CERN Cling 解释模式各自适合什么场景。

## 阅读建议

刚上手先读第一篇建立整体认识；环境跑通后，第二篇解决"作业要用库"的问题；平时想随手验证一小段代码，第三篇的 REPL 会比建工程快得多。
