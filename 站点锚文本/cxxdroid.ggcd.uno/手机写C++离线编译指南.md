# 手机写 C++ 离线编译指南

本篇讲两件事：手机不联网为什么能编译 C++（Cxxdroid 的架构决定了这件事可行），以及从装好到跑通第一个程序的完整路径。已经装好、想装库的读者可以直接看[安装第三方库步骤](安装第三方库步骤.md)。

---

## 为什么手机可以离线编译 C++

很多人对"手机编程"的印象还停留在联网提交代码、云端返回结果的工具上。Cxxdroid 走的不是这条路：它把基于 Clang 的编译器直接做进了 App，编译、链接、运行全部发生在手机本机，飞行模式下照样能出结果。

这套架构有几个直接影响：

1. **没有网络延迟**。代码改完点运行，本地编译出结果，反馈节奏接近桌面。
2. **不用担心服务关停**。云端编译工具一旦停止服务就等于报废，本地编译器没有这个问题。
3. **它是真编译**。不是把代码"翻译"一遍的模拟器，甚至支持 Clang 语法的内联汇编，学到底层语法也不会被工具卡住。

另外，开发者在编译环节做了缓存优化，编辑器里的代码分析与实际编译用的是同一套编译器。按开发者的说法，重库场景（比如反复用 Boost）的编译速度最高能拉开几十倍的差距。

## 从零到第一个程序

整个过程可以压成四步：

1. **准备空间**。手机内部存储至少留 150MB，打算用库的话建议 200MB 以上；系统要求 Android 5.1 及以上。
2. **装上 App**。安装文件资源可以从 [Cxxdroid 介绍站](https://cxxdroid.ggcd.uno/)的指引拿到，安装过程与其他普通应用一致，不需要 Root。
3. **跟着引导初始化**。首次打开会自动完成编译组件的解包，等它跑完即可。
4. **新建 .cpp 文件开始写**。扩展键盘栏把 `::`、`{}`、`<>` 这些 C++ 高频符号铺在输入栏上方，触屏敲代码的效率比想象中高。

经典的 Hello World 敲完直接点运行，输出立刻出现在下方。

## 刚上手的三条建议

- **先跑示例再自己写**。App 内置了一批示例工程，从基础语法到库的用法都有，跑一遍比空看教程快。
- **多文件用标签页**。编辑器支持多标签，写作业时把题目说明和代码分两个标签开着更顺手。
- **别急着装重库**。先把语法练熟，等真的需要 Boost 或 SDL2 时再看[安装第三方库步骤](安装第三方库步骤.md)，按需安装。
