# 三档对话风格怎么选与提问技巧

> 更有创造力 / 更平衡 / 更精确三枚按钮分别适合什么场景，以及把问题问清楚的几个写法。

主页那三个样式按钮不是摆设：同一个问题用不同档位问，回答的长度、口吻、发挥程度都不一样。这套三档设计来自它连接的对话服务（2023 年 2 月该服务上线时就带着），服务方在发布说明里给过定义：精确档答案更短更贴搜索结果，创意档答案更长描述更充分，平衡档介于两者之间。

## 一、三种档位对照

| 档位 | 适合的事 | 典型问法 |
| --- | --- | --- |
| 更精确 | 查事实、查数据、要简短可靠的答案 | 「某某的 API 限速是多少？」 |
| 更平衡 | 日常问答、总结、解释、翻译 | 「把这段话总结成三点」 |
| 更有创造力 | 写作、起名、脑暴、玩梗 | 「给咖啡店起十个带季节感的名字」 |

选档原则一句话：**要答案选精确，要灵感选创造，拿不准选平衡**。切换不需要退出会话，直接点另一档再发下一条消息就行。同一道题用三档各问一遍，答案从篇幅到口吻都会不同，拿不准时这个对比法最直观。

## 二、提问写法比切档影响更大

档位定了之后，问题本身怎么写决定回答质量：

1. **限定范围**：「不超过 100 字」比「简单说说」可控，「2024 年之后」比「最近」清楚；
2. **要求给出来源**：事实类问题补一句「答案后面附上来源」，方便自己核对；
3. **分步走**：复杂的活先让它出提纲，确认后再逐段展开，比一口气说完靠谱；
4. **给它素材**：总结、改写类任务把原文完整贴进输入框（上限 8000 字），比让它凭印象写强；
5. **句子里点名风格**：直接写「简短精确地回答」或「放开写，越生动越好」，不改档位也能近似切档，适合一个问题一个风格的场合。

## 三、GPT-4 模式开关与长输入

样式按钮下方还有一枚「启用 GPT-4 模式」开关，控制对话所用模型的档位，不影响三种风格的划分——开与不开在回答质量与速度上的差别，用同一道题各跑一遍自己对比最直观。输入框右下角的 0/8000 是字数计数，超长材料建议拆开分几轮发；输入 `/` 可以唤起提示词，常用的问法存进「提示词管理」下次不用重复打。

## 四、回答不满意时的调整

- 回答太干、太短：切「更有创造力」或放松约束，让它展开某一点；
- 回答太飘、不贴题：切「更精确」，把关键条件在问题里重复一遍；
- 答到一半断了：先开新会话再试——单会话轮数和每日总量都有上限，这是服务侧的设计，不是操作错了。
