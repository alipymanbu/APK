# 装好 AIRI 发消息没回应？先接上大模型

> 这篇解决 AIRI 新用户最常撞上的第一道坎：应用装好了，欢迎页也过了，发消息却没有任何回应——原因不是安装失败，而是还差「大脑」。配套的安装问题见 [安卓安装包从转存到安装.md](安卓安装包从转存到安装.md)。

---

## 一、为什么装好却聊不了

AIRI 的设计把「壳」和「脑」分得很开：形象、动作、语音播放、记忆数据都留在你的设备上，而理解你说的话、生成回复，靠的是你另行接入的大模型服务。没有配置任何服务来源时，消息发出去自然石沉大海——这不是故障，是还没接电。

这个设计也带来一个常被忽略的好处：你填进去的 API Key 只保存在自己的设备里，不经过第三方服务器中转。

## 二、选一条接大脑的路线

按你的手头资源对号入座：

| 路线 | 适合谁 | 要准备什么 |
|---|---|---|
| 引导页直接登录 | 不想折腾、想五分钟开聊 | 模型服务方的账号 |
| OpenAI 兼容接口 | 手里有任意兼容格式的 Key | API Key + Base URL |
| OpenRouter | 想一个 Key 切换多家模型 | OpenRouter 的 Key |
| DeepSeek / Gemini / Claude 等 | 有对应服务的账号 | 对应服务的 Key |
| Ollama（本机） | 电脑上跑过本地模型、不想联网 | 本机已启动的 Ollama 服务 |

判断依据说直白点：省事先走「登录」；Key 玩家走兼容接口，市面上的聚合站几乎都提供 OpenAI 格式；介意隐私、手上设备算力够，Ollama 是唯一断网可用的路线，代价是回复速度看设备。

## 三、五分钟配置流程

1. 首次打开应用，欢迎页选好界面语言（有简体中文）；
2. 点「配置您自己的 AI 服务来源」，在服务商列表里选你要用的那条路线；
3. 填入 API Key；选兼容类型的话再补一个 Base URL（服务商的接口文档里一般能直接复制）；
4. 下一页从模型列表里挑一个，点「保存并继续」；
5. 回到主界面发一句话，有回复就算接通了。

每个环节的界面长什么样、八类服务商各自的入口在哪，[AIRI 接大脑入门](https://airi.fwen.ren/) 这个介绍站里有按截图走的完整版。

## 四、挑模型的两个实用提醒

- 日常聊天优先选不带「思考」的普通对话模型，带推理功能的模型要等更久，对话流畅度明显吃亏。
- 打算让她画画的话，选模型时确认支持工具调用（Tool Calling），否则图像任务提交不出去，她只会回你文字。

花费方面，本地 Ollama 不产生模型费用、只吃设备算力；自带 Key 按所选服务的定价走；登录方案按服务方规则计费。三条路线都能起步，先跑通再优化也来得及。
