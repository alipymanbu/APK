## 一句话认识 AIRI

AIRI 是开源社区维护的 AI 虚拟角色应用：Live2D / VRM 形象、语音交互、角色卡与记忆都跑在本地，唯独「理解和回复」需要你自己接入一个大模型服务——装好先接大脑，她才会开口。安卓端安装包约 193M，也有 Windows / macOS / Linux 桌面版和浏览器网页版。

本目录文章持续更新，内容基于公开资料与实际界面整理，属于第三方介绍口径，与开发方无关联。
