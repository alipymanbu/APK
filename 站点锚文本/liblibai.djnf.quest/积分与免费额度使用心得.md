# LiblibAI 积分与免费额度使用心得

> 本篇讲 LiblibAI 的积分消耗逻辑、免费能用到什么程度、两套积分体系的区别，以及把积分花在刀刃上的几个习惯。

## 一、什么操作会扣积分

生图、生视频、图像编辑、在线训练这类算力操作都按积分扣，消耗量随模型和参数浮动：张数翻倍扣得翻倍，视频类模型的单次消耗明显高于普通图片，训练一次 LoRA 又远高于一次生图。生成前界面上能看到当次预计消耗——先看一眼再点生成，是控制积分最快的习惯。

## 二、免费部分能做什么

- 每日登录有赠送积分（近期口径为每天 20 积分，随时可能调整，以平台页面为准）；
- 免费账号另有 3GB 云端存储空间；
- 免费积分够轻量试玩：小尺寸、少张数的图片生成本身消耗不高；大图、视频、训练这类重活基本要靠充值或订阅。

订阅会员的月度积分按 31 天周期重置，当期不用完就作废——囤着不用的思路在这里行不通。

## 三、两套积分，别充错

平台有互不相通的两套积分：出图用的创作积分，以及调用 API 接口才用的 API 积分。只是自己创作，充创作侧就够；搞开发对接才碰 API 侧。充错需要找客服处理，付款前先对准。

## 四、会员档位差在哪

创作会员按年/季/月订阅，从入门到至尊多个档位，档与档之间主要差五件事：每月积分（数百级到数万级）、并发任务数、云端存储、排队加速通道、是否去除品牌水印。价格与积分比例的活动很频繁，具体以会员页当时显示为准，这里不落死数字。

## 五、把积分花在刀刃上的习惯

- 先用低张数、小画幅试构图，满意了再上高参数出成品；
- 视频、训练这类高消耗操作，脚本与素材想清楚再跑，避免反复重试白扣分；
- 排队说明并发额度用完了：偶尔用一次，等一等比开会员划算；天天出图才值得算订阅的账；
- 积分扣了但没出图：先刷新任务记录确认状态，多数「卡住」只是页面没更新，仍缺失再找平台客服处理。

轻量试玩不需要多大投入，装个客户端就能开始——获取方式见 [安卓客户端获取与首次登录.md](安卓客户端获取与首次登录.md)；模型与训练的门道在[模型库挑选与LoRA训练入门](模型库挑选与LoRA训练入门.md)里，站内导览则集中在 [liblibai.djnf.quest](https://liblibai.djnf.quest/)。
