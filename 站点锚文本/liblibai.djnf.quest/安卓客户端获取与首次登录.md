# LiblibAI 安卓客户端获取与首次登录

> 本篇讲怎么把 LiblibAI 的安卓客户端装进手机：资源从哪来、安装被拦怎么处理、第一次打开要做什么。
> **相关文档**：[模型库挑选与LoRA训练入门.md](模型库挑选与LoRA训练入门.md) · [积分与免费额度使用心得.md](积分与免费额度使用心得.md)

## 一、这份客户端是什么定位

LiblibAI 是国内活跃的 AI 模型社区与在线创作平台，能力主体（在线生图、模型库、LoRA 训练、视频特效）都架在网页端；安卓客户端是个轻量入口，装它图的是手机上随手出图、刷灵感、套视频模板方便。两端共用同一套平台账号，积分与作品云同步，不存在「不装客户端就不能用」的说法。

安装包只有 1 MB 出头，对手机配置几乎没要求；真正的创作算力在云端，跑多大的图都与本机配置无关。

## 二、获取路径：网盘转存一份到自己账户

客户端的安装包通过夸克网盘分享的方式分发，[liblibai.djnf.quest](https://liblibai.djnf.quest/) 这个介绍站的下载页集中放了入口：打开分享页 → 转存到自己的夸克网盘 → 从网盘下载到手机。转存的好处是资源进了自己账户，后续随取随装。

## 三、安装被拦的几种提示

非应用商店来源的包，系统都会例行拦一道，常见措辞与处理：

| 提示样例 | 处理 |
| --- | --- |
| 「禁止安装未知来源应用」 | 按弹窗指引，允许「文件管理」或浏览器来源安装 |
| 华为/荣耀「该应用存在风险」 | 选「继续安装」，或在纯净模式设置里放行 |
| 小米「高危应用」 | 安装页验证后选「继续安装」 |
| OPPO/vivo「来源未经验证」 | 勾选「我已知晓风险」后继续 |

不同系统版本措辞有差异，以手机当时弹出的为准。

## 四、首次打开做三件事

1. **登录账号**：注册或直接登录；网页端已有的账号直接用，积分与会员状态会同步过来。
2. **认一遍四个入口**：图片生成、模型库、视频特效、发现灵感——首页的侧边导航就是这四块，界面上还有一排现成的灵感瀑布流。
3. **试第一张图**：进图片生成，挑个基础模型，按「主体 + 场景 + 光线 + 风格」的密度写几句描述，先小尺寸出一张看看手感。

装好之后想系统过一遍界面与玩法，介绍站里按「界面速览 → 三种高频玩法 → 上手备忘」整理了完整导览，从[手机端创作手账](https://liblibai.djnf.quest/)首页顺着读即可。
