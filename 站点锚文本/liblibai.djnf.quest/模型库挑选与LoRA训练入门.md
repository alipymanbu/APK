# LiblibAI 模型库挑选与 LoRA 训练入门

> 本篇讲在 LiblibAI 的十万级模型库里怎么按需求缩小范围、读模型详情页要看哪三样，以及在线训练专属 LoRA 的路径。

## 一、先分清四类东西

| 类型 | 作用 | 使用场景 |
| --- | --- | --- |
| Checkpoint（基础模型） | 决定画面的「底盘」：画风、质感、能否写字 | 每次生图都要先选一个 |
| LoRA | 往基础模型上加一层「补丁」，固定某个角色、画风或动作 | 要稳定复现特定人物或风格时叠加 |
| 风格模型 | 平台调好的快捷组合，选上就能用 | 不想折腾参数、要风格稳定时 |
| 工作流 / AI 应用 | 预搭好的处理流水线（放大、换背景、特效等） | 单一明确的处理直接套用 |

库里公开模型在十万级，覆盖摄影写实、动漫、插画、平面设计、建筑室内、中国风等领域，逐个试不现实，得按路径筛。

## 二、按需求筛的三步路径

1. **按领域分类缩范围**：摄影写真 / 动漫游戏 / 风格插画 / 平面设计 / 建筑室内 / 电商营销，先对号入座。
2. **看热度排序**：热度高的模型样图多、评论区反馈多，能提前看到实际用下来的问题。
3. **详情页看三样**：样图像不像你要的画面、LoRA 的触发词是什么、作者给的推荐参数长什么样。触发词漏写进提示词，叠加等于白加载；推荐参数照抄能避开大部分「出图糊、画面重复」。

带文字的海报、Banner、封面优先试 Qwen-Image、Seedream 这类对中英文文字渲染较准的模型——把要显示的文字用双引号括进提示词，识别更准；通用人像与插画从 F.1 起步。

## 三、在线训练专属 LoRA

登录后把一组图片传上去（最多两百张，png/jpg 都行），设置触发词与训练参数就能在云端练出专属模型，练完直接在生图页调用。几点实际体验：

- 训练主要在网页端操作，手机端可以随时看进度；
- 训练消耗的积分远高于一次生图，素材与触发词想清楚再开跑；
- 练成后先照推荐参数试几张，再决定要不要调学习率重练。

## 四、商用前先查授权

同一平台上不同模型的授权口径并不一样：有的标注可商用，有的限个人使用。拿生成图做商业用途前，回到模型详情页把授权说明看一遍；会员档位里「去除品牌水印」的权益也会影响成图能否直接对外用。不想逐个查时，模型广场里标注「可商用」的合集栏目（爆款、新热 Top100 之类）先挑先能用。
