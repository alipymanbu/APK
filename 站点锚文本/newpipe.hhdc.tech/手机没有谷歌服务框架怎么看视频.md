# 手机没有谷歌服务框架怎么看视频

本篇讲一个具体场景：手里的安卓手机没有预装完整的谷歌服务框架（GMS），很多依赖它的应用装不上或者装上打不开，这时候想在看视频这件事上有得选，路怎么走。相关话题还可以看 [安卓上无广告看视频的客户端选择](安卓上无广告看视频的客户端选择.md) 与 [视频离线保存与后台播放的日常用法](视频离线保存与后台播放的日常用法.md)。

---

先说结论：**换一个不依赖谷歌框架的客户端**，是最省事的路线。

## 为什么会卡在框架上

不少视频应用在启动、登录、推送这几个环节都会调用谷歌服务框架。手机里没有这套套件（国行机型、部分老款机型、平板都很常见），轻则功能残缺，重则直接闪退。刷入整套框架对普通用户来说门槛偏高，也不是人人都需要。

## 不走框架的思路

开源社区里有一类客户端的做法不同：它们不调用谷歌框架，而是**直接向内容平台请求播放所必需的信息**——拿到视频流、标题、封面这些数据就够了，其余环节一概不经过谷歌的服务。NewPipe 就是这类做法里最常被提到的一个：装上就能用，不需要登录任何账号，订阅和观看记录都保存在手机本地。

对没有框架的手机来说，这种「按需请求」的方式意味着：

- 安装不受框架限制，普通 APK 安装流程就能完成；
- 不需要登录账号，省掉注册和登录墙；
- 观看偏好不离开手机，也不用担心同步到别处。

## 具体怎么装

安装流程与普通应用一致：拿到 APK 安装包 → 允许系统安装未知来源应用 → 安装完成。安装包体积只有 10MB 出头，对存储紧张的老机型也友好。完整的获取方式与分步操作，整理在 [NewPipe 介绍站](https://newpipe.hhdc.tech/) 的安装步骤页里，照着做几分钟就能装好。

装好之后，第一次打开建议先到设置里把界面语言切换成中文，再到「内容」分类里按习惯调整图片质量和评论显示，上手会更顺。
