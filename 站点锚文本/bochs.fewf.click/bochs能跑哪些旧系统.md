# bochs能跑哪些旧系统

> 在动手装镜像之前先对齐预期：bochs 能运行哪些系统、各自表现如何、性能上限在哪。

bochs 的上游项目点名可在模拟环境里运行 Linux、DOS 与 Windows 系列的多代产品，CPU 可模拟从早期 386 到 x86-64 的各型号。它逐条指令翻译执行，不借用宿主机的任何加速能力——同一套核心在桌面与手机上都是这个脾气。所以选镜像前先接受一个前提：能跑起来是常态，跑得飞快不是。

## 各系统的实际口碑

综合玩家教程与用户反馈（二手经验，不同手机表现会有差异）：

| 系统 | 反馈情况 |
| --- | --- |
| MS-DOS / FreeDOS | 最轻量，进得最快，怀旧软件与老游戏从这里入门 |
| Windows 95 | 口碑普遍好于 98，对触屏操作相对友好 |
| Windows 98 | 能跑，但「卡在启动画面」的问题在它身上最常见 |
| Windows XP | 可以启动，内存建议 256MB 起，镜像大、进系统慢 |
| 轻量 Linux | Tiny Core、Puppy 这类小型发行版反馈较好 |

顺带一提内置镜像：应用设置里的下载列表直接提供 muLinux、FreeDOS、Tiny Core、Puppy 四个选择，都是几十到几百 MB 的体量，验证安装是否成功、熟悉操作手感，从它们开始成本最低。

## 性能预期与卡顿对策

有教程给出过「跑得动」的参考配置：四核 1.7GHz 以上的处理器、至少 1GB 内存、存储读写 20MB/s 以上。达不到也不代表不能用，只是更慢。

卡顿时的对策，按性价比排序：

1. 清掉后台应用，把内存让给模拟器；
2. 降低虚拟机的分辨率与颜色深度；
3. 把 `megs` 内存调到镜像真正够用的值，不是越大越好；
4. 换更轻的镜像——DOS 与 95 比 XP 轻得多。

## 几条能力边界

- **联网**：这个安卓版目前上不了网（用户反馈口径），上游自带的虚拟网卡能力在手机端按不可用预期即可；
- **声音**：设置里有声卡选项，但镜像里要装了对应驱动才出声，多数现成镜像没带；
- **存档恢复**：支持保存与恢复虚拟机状态，但共享文件夹用的 vvfat 模式不支持该功能（上游手册口径）；
- **存储空间**：应用本体不到 13MB，但镜像动辄几百 MB 到几 GB，系统运行时还会持续往镜像写数据，空间要留足富余。
