# bochs镜像准备与启动配置

> bochs 开不了机，九成卡在镜像这一步：镜像从哪来、放哪里、怎么命名、怎么挂载，一篇说全。

bochs 本身只是模拟出来的「裸机」，开机要靠三样东西凑齐：BIOS 文件（首次启动时应用已自动复制到位，不用另下）、一份装好系统的磁盘镜像（`.img`，需要自己准备的核心文件），以及告诉它「硬盘是哪个文件、从哪启动、内存多大」的配置。

## 镜像从哪来

三条路，按省事程度排：

1. **应用内置入口**：设置里的镜像下载列表直接提供了 muLinux（34MB）、FreeDOS（114MB）、Tiny Core Linux（123MB）、Puppy Linux（690MB）四个轻量系统，点一下就能先开个机；
2. **现成镜像包**：网上流传的 Windows / DOS 镜像多为 zip 压缩包，解压出 `.img` 即用；
3. **自己制作**：在电脑上用 `qemu-img create -f raw c.img 4G` 建一块空白虚拟硬盘（Bochs 认扁平 raw 格式，qcow2 / vmdk / vdi 都要先转换），挂进电脑虚拟机装完系统，再把整个文件拷到手机。

## 放哪、叫什么

- **存放位置**：应用数据目录 `/Android/data/net.sourceforge.bochs/files/`。安卓 11 起系统限制直接访问该目录——进目录时在弹窗里点「使用此文件夹」完成授权即可；更省事的做法是把镜像放在下载等普通目录，在存储设置里用文件选择器直接指认过去；
- **命名**：玩家们反复验证的经验是，找不到镜像就闪退时，把镜像改名成 `c.img` 或 `andows.img` 最稳妥——这是各篇教程里最常见的默认镜像名；
- 改名、移动镜像前先完全退出应用，别在模拟运行中动文件。

## 挂载与启动

图形界面路线：存储选项卡勾选「主储存器」→ 选择 → 按路径找到 `.img` → 确定；再到配置选项卡把内存按镜像需求给（Windows XP 建议 256MB 起，95/98 64~128MB 够用），最后点右上角 Start。

命令行路线（进阶）：编辑 `bochsrc.txt`，核心五行长这样：

```
megs: 256
romimage: file=BIOS-bochs-latest
vgaromimage: file=VGABIOS-lgpl-latest
ata0-master: type=disk, path="c.img"
boot: disk
```

`path=` 必须与实际文件名逐字一致；装系统时 `boot:` 可临时改成 `cdrom`，装完改回 `disk`。

启动后正常流程是 BIOS 自检滚屏、读硬盘、进系统，第一次进系统以分钟计——指令级模拟就是慢，属正常现象。退出时先在虚拟机系统里点关机、等它关完再退应用，镜像写到一半被切断会有损坏风险。

界面各选项卡的具体位置与截图，见 [bochs模拟器上手入门](bochs模拟器上手入门.md)；装好之后能跑什么、性能预期多少，见 [bochs能跑哪些旧系统](bochs能跑哪些旧系统.md)。
