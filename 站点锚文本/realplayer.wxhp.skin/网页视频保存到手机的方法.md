# 网页视频保存到手机的方法

> 刷到想留存的视频，下一次想看却找不到了——本篇讲把网页视频存进自己手机的两条路子：分享菜单标记与直接粘贴网址下载，以及存完去哪儿找。
> **相关文档**：[手机视频投屏电视的步骤与排查](手机视频投屏电视的步骤与排查.md)

## 一、先说清边界

保存的对象应该是**你有权保存的内容**：自己拍的、平台开放下载的、作者明确授权的。别人作品的版权归属由使用者自行判断，存下来自用与再传播是两回事，别越线。

## 二、路子一：分享菜单标记

适合在各类视频 App 里刷到的内容：

1. 在常用的视频应用里点**分享**；
2. 分享列表里找到 **Add to RealPlayer** 这一项；
3. 选择保存到**手机**或**电脑**——选电脑的前提是电脑端装了配套的 RealPlayer for Windows 并开启了 Mobile Access，视频会在电脑上自动下载入库。

这条路的覆盖面很广，凡是开放了分享菜单的应用基本都能走通。

## 三、路子二：粘贴网址下载

适合在浏览器里看网页视频的场景：

1. 在视频播放页的分享菜单里**复制链接**；
2. 打开手机端的 RealPlayer，点右上角菜单选**从一个网址下载**；
3. 把地址粘进去点保存，下载就开始了。

地址有时效性，提示抓不到内容时先回原页面重新复制一次链接再试。

## 四、存完去哪儿找

以 [RealPlayer 介绍站](https://realplayer.wxhp.skin/)里整理的这款应用为例，规律很简单：**下载到哪，就去哪个页面看**——选了手机，文件落到底部「手机」页，与本地视频列在一起；选了电脑，就到「我的电脑」页去找。电脑端默认还会留一份在「视频」文件夹的 RealDownloader 目录里，右键任意条目选 Locate File 能直接打开所在文件夹。

## 五、存下来的片子怎么用

本地视频的播放控制（倍速、10 秒快进、小窗）与投屏玩法，见[手机视频投屏电视的步骤与排查](手机视频投屏电视的步骤与排查.md)；担心换机丢片的，登录账号后还能把手机里的视频备份到云端，误删也能找回。
