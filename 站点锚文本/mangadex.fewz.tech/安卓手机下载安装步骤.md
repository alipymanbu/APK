# 安卓手机下载安装步骤

> 本篇讲把 MangadeX 装进安卓手机的完整流程：资源从哪拿、权限怎么开、装不上时先查什么。
> **相关文档**：[多源漫画阅读器是什么](多源漫画阅读器是什么.md) · [翻页模式与夜间主题设置](翻页模式与夜间主题设置.md)

## 一、装之前先弄明白

MangadeX 以 APK 安装包的方式分发，只在安卓设备上使用，iPhone 装 APK 是行不通的。它的安装包不大，约十几 MB，对存储几乎没有压力；版本信息以实际下载到的文件为准。

## 二、四步装好

1. **拿资源**：打开 [MangadeX 介绍站](https://mangadex.fewz.tech/) 的下载安装页，按页面按钮进入安装文件资源页，把安装包转存到自己的网盘账号下；
2. **下到手机**：在手机上打开网盘 App，找到刚转存的安装包，下载到本机存储；
3. **开权限**：安卓默认不允许从浏览器或文件管理器安装应用，先到系统设置搜索「安装未知应用」，给准备用来打开安装包的那个应用开一次允许；
4. **安装**：回到下载目录点开 APK，系统弹安全提示时选「仍要安装」（部分机型会确认两次），完成后从桌面图标进入。

## 三、装不上时先查这三处

| 现象 | 先查什么 |
| --- | --- |
| 提示「解析包出现问题」 | 安装包多半没下完整，重新下载并核对文件大小；系统过旧的机型也可能报错 |
| 点了 APK 没反应 | 第三步的「安装未知应用」权限开了没有；开了还不行就换系统自带的文件管理再试 |
| 安装到一半中断 | 存储空间是否不足，清出几百 MB 再装 |

装好后的第一站是「发现」页：挑一个顺眼的源逛起来，再把爱看的作品加进收藏。追更和离线的具体玩法写在 [追更列表与离线缓存](追更列表与离线缓存.md)，读感调优见 [翻页模式与夜间主题设置](翻页模式与夜间主题设置.md)。
