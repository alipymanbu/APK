# AudioRelay 连不上电脑怎么办：六步排查顺序

手机端列表里刷不出电脑、点连接没反应、连上又反复掉线——这类问题八成停在前两步。按下面的顺序查，每一步都是能直接照做的动作。

> 动手前先确认两端都装好并打开了：电脑端是服务器、手机端是播放器（或者反过来做麦克风玩法时互换），只开一边任何排查都白搭。安装环节的问题先看[audiorelay 介绍站的安装页](https://audiorelay.xnyx.quest/download.html)。

## 第 1 步：是不是同一个网络

手机连的 WiFi 和电脑必须是**同一个**局域网：手机用流量不算；电脑插网线连的是另一张网时，也要确认和手机在同一个网段。**别连访客网络（Guest）**——路由器的访客网络天生隔离设备，互相看不见。

## 第 2 步：路由器有没有隔离设备

到路由器管理页找这些词并关掉：**AP 隔离 / Access Point Isolation / Client Isolation / 访客模式 / Port isolation**。家用路由一般默认关着，公司网和随身 WiFi 上很常见。

## 第 3 步：防火墙

- Windows 的**网络配置文件改成「专用」**：设置 → 网络和 Internet → 选中当前连接 → 从「公用」改为「专用」，公用网络会拦入站连接。
- 装电脑端时如果取消过 `Add firewall rules` 勾选，重装一遍并保持勾选。
- 先临时关掉电脑防火墙试一次：能连了就说明是它——记得去防火墙里给 AudioRelay 加例外再开回来。
- 装了第三方安全软件的话，它们各有一套拦截，要单独放行；只放系统防火墙、被第三方拦住的情况很常见。

## 第 4 步：VPN 在捣乱

VPN 开着时要在其设置里放行局域网（`Allow LAN traffic` 这类选项），关掉「对局域网隐身」类开关；找不到就先断开 VPN 再试。

## 第 5 步：自动发现失败，手动填 IP

列表里刷不出电脑，不代表链路不通——广播被拦、单点连接还活着的情况很常见：

1. 电脑上 `Win+R` 输 `cmd`，运行 `ipconfig`，看无线/以太网适配器下的 **IPv4 地址**（形如 `192.168.1.23`）；电脑端页面右上角也会显示自己的 IP，两处对一下更保险。
2. 手机端列表页找 **Connect manually（手动连接）**入口，把这个地址填进去。
3. 电脑开移动热点给手机连的场景，要填**热点网段**的地址（Windows 惯例是 `192.168.137.1`，以 `ipconfig` 实际查到的为准）——照抄电脑端显示的另一张网卡 IP 会填错。

## 第 6 步：还不行，查端口 59100

手动填 IP 仍连不上时，用手机 ping 电脑：ping 不通说明问题在网络层，回头重做第 1、2 步；**ping 通了却连不上**就查端口——电脑上运行：

```cmd
netstat -ano | findstr "59100"
```

端口被别的程序占着就处理掉。手动加防火墙规则时，要加的是 **59100 的 TCP 与 UDP 两条入站规则**——只放行程序路径、不开端口，有时仍然连不上。

## 连上了但反复掉线、卡顿

- 两端版本都更到最新，版本差太多会对不上协议、无限重连。
- 卡顿与丢包按收益从大到小：关蓝牙（和 2.4GHz 同频段互相干扰）→ 电脑接网线 → 换 5GHz → 手机凑近路由器；彻底求稳走 USB 连法。
