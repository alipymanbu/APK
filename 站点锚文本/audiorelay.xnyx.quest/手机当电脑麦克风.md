# 手机麦克风给电脑用：把手机变成电脑的虚拟麦克风

电脑没有麦克风、或笔记本自带麦拾音太差时，AudioRelay 能把手机的麦克风声音实时送进电脑：会议、直播、录课软件里会出现一个叫 Virtual Mic 的录音设备，选它就行。手机拿到哪，麦就在哪，比凑近电脑上那颗小孔灵活得多。

> 声音的走向和「电脑投声音到手机」正好反过来：这次手机是服务器（发声音），电脑是播放器（收声音）。两边要点的页面正好互换，别照抄另一篇的点法。

## 三步接通

**第 1 步：手机端开麦克风采集**

手机打开 AudioRelay，切到 `Server`（服务器）页，音源列表里点 `microphone`。首次会弹录音权限，允许之后手机端就是一个在跑的服务器。

**第 2 步：电脑端接过来**

电脑端切到 `Player` 页，把输出模式**选成 Mic**——默认是放声音的模式，这一步必须切；然后在服务器列表里点你的手机。

**第 3 步：让软件用上虚拟麦克风**

电脑上这时多了一个 `Virtual Mic` 录音设备，但软件不会自动用它，二选一：

- **设成全局默认**：任务栏右键声音图标 → 声音设置 → 录音设备 → 把 Virtual Mic 设为默认设备和默认通信设备，之后所有软件都走它。
- **在单个软件里选**：进会议 / 直播 / 录屏软件的麦克风设置，直接选 Virtual Mic。

## 手机那侧的三个细节

- **别让系统杀后台**：采集端要一直在后台跑，被省电机制清掉后电脑那边会掉线或没声。
- **离嘴近一点**：手机放桌上收的是整间屋的动静，开会时拿到面前效果最好。
- **来电会打断**：通话时麦克风被占用，挂断后重新点一下麦克风音源即可。

## 接通了却没声音

按这个顺序查，多数卡在前两步：

1. 电脑端输出模式确实是 `Mic`，不是默认放音模式；
2. 软件里选的设备是 `Virtual Mic`，不是电脑自带麦；
3. Windows 的麦克风隐私开关（设置 → 隐私和安全性 → 麦克风 → 允许桌面应用访问麦克风）开着；
4. 改完设置在手机端**断开重连一次**，新的设备路径才生效。

需要先把两端装起来的，看[audiorelay 介绍站的安装页](https://audiorelay.xnyx.quest/download.html)；另一侧玩法（电脑声音投到手机外放）的连法在[电脑声音投到手机听.md](电脑声音投到手机听.md)；两端连不上的排查顺序见[连不上电脑怎么办.md](连不上电脑怎么办.md)。
