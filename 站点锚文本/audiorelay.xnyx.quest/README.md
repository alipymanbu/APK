# AudioRelay 站点导航：用法、连接与排查

AudioRelay 是把手机和电脑用局域网串起来传声音的工具：电脑的声音能实时投到手机上外放，手机的麦克风也能反过来变成电脑的虚拟麦克风。[audiorelay 介绍站](https://audiorelay.xnyx.quest/) 把两种玩法的接法、延迟与音质的调法、连不上电脑的排查顺序整理成了固定几页，配套的安装入口也在那里。

## 这个站里有什么

- [电脑声音投到手机听.md](电脑声音投到手机听.md)：无线与 USB 两种连法，连上之后看哪几个数判断质量。
- [手机当电脑麦克风.md](手机当电脑麦克风.md)：反方向玩法，三步接通，会议与录音软件里选 Virtual Mic。
- [连不上电脑怎么办.md](连不上电脑怎么办.md)：从同一网络、防火墙到手动填 IP 的六步排查顺序。

## 从哪开始

第一次用先看介绍站的[安装步骤页](https://audiorelay.xnyx.quest/download.html)，手机端与电脑端两头就位再谈玩法；装好后按上面三篇按需跳读即可。
