# 电脑声音投到手机上听，用 AudioRelay 怎么连

把电脑正在播放的声音实时传到手机上外放，是 AudioRelay 最常见的用法：电脑没接音箱、想把声音带到另一个房间，或者躺床上不想吵到别人时，手机就是一块随身的音箱。接法有无线和 USB 两种，下面按顺序走完。

> 两端分工是固定的：电脑端当服务器抓住系统声音，手机端当播放器主动去连。所以动作顺序永远是**先开电脑端，再开手机端**——只开一边不会有反应。还没装好的话，[audiorelay 介绍站的安装页](https://audiorelay.xnyx.quest/download.html)有完整步骤。

## 无线连法（最常用）

前提只有一条：手机和电脑在**同一个 WiFi** 下。不需要能上网，同一局域网就行。

1. 电脑上打开 AudioRelay，让它开着（最小化可以，别退出）。
2. 手机端切到 `Player`（播放）页。
3. 列表里点你的电脑名，页面会出现连接状态和延迟数据。
4. 电脑上随便放段视频，声音从手机出来就算通了。

连上之后手机音量键直接调大小；插了耳机又想投外放的话，先在电脑端确认选的输出设备对不对。

## USB 连法（延迟最低、最稳）

网络太差或没有 WiFi 时用它：

1. 用**能传数据**的数据线连接手机与电脑（原装线最稳）。
2. 手机通知栏打开「USB 网络共享」（USB tethering）。
3. 等电脑识别出一块新的网络适配器。
4. 服务器列表里**多出来的那条**就是 USB 通路，点它连接。

一个小提醒：USB 网络共享可能让电脑顺路走手机流量。AudioRelay 自己的数据是局域网内传的、不计流量，但怕别的程序扣流量就同时连 WiFi、关掉移动数据或开飞行模式。

## 连上之后看三个数

手机端连接页面的实时数据，直接决定体验：

- **延迟**：10ms 上下属正常，看视频打游戏无感。数字正常却觉得慢，多半是戴着蓝牙耳机听——蓝牙那段延迟不在这条链路上。
- **丢包**：应该是 0%。不为 0 就是网络在丢数据，优先让电脑接网线、换 5GHz 频段、关掉蓝牙。
- **缓冲**：接近或超过 100ms 说明网络跟不上，去设置里把音频输出换成 OpenSL ES、缓冲量选 Low buffer。

## 列表里刷不出电脑

广播被拦不代表链路不通：先确认不是访客网络、路由器没开 AP 隔离，再手动填 IP 连一次——电脑上 `ipconfig` 查 IPv4 地址，填进手机端的「手动连接」。完整的六步排查写在[连不上电脑怎么办.md](连不上电脑怎么办.md)，另一种玩法（把手机麦克风借给电脑开会）见[手机当电脑麦克风.md](手机当电脑麦克风.md)。

两种玩法的接法与调优也整理在了 [audiorelay 介绍站](https://audiorelay.xnyx.quest/)，页面里的安装入口与这篇讲的是同一套流程。
