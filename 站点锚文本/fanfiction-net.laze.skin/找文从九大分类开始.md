# 找文从九大分类开始

FanFiction.Net 的作品量以百万计，直接翻列表没有意义——这座文库的找文效率，取决于对「主分类 → fandom → 筛选器」这套路径熟不熟。这篇从最粗的分类讲到最细的条件组合。

相关文章：[离线书库和听书怎么用](离线书库和听书怎么用.md) · [和AO3比有什么不同](和AO3比有什么不同.md)

## 一、先认九大主分类

站内所有作品按原作载体归进九个主分类：Anime/Manga（日本动漫）、Books（小说原著）、Cartoons（欧美动画）、Comics（欧美漫画）、Games（游戏）、Movies（电影）、Plays/Musicals（戏剧与音乐剧）、TV Shows（电视剧）与 Misc（杂项）。追哪部原作就进哪个分类，分类下再按具体作品（fandom）细分，fandom 页里还能按角色筛戏份。

两个世界观混搭的交叉作品（Crossover）不在单个 fandom 页里，要进分类下的交叉区；记得两部作品名的话，全局搜索直接一起输更快。

## 二、把筛选器用顺

fandom 页与搜索结果页都能叠加这些条件：

| 维度 | 用法 |
| --- | --- |
| 分级 | K / K+ / T / M 四档，默认列表只展示 K 到 T |
| 状态 | Complete（完结）/ In-Progress（连载中），不想追坑选完结 |
| 篇幅 | 字数区间与章节数 |
| 排序 | 更新时间 / 评论数 / 收藏数 / 追更数，找热门文按收藏数排最直接 |

比大海捞针更快的两个入口：一是 **Community 社区合集**——老读者手工整理的专题书单，按题材建站、按质量收文，挑一个口味对上的等于直接拿现成书单；二是**顺藤摸瓜**——找到一篇对胃口的文后看作者还写了什么、被谁收藏，同好作者的收藏夹命中率通常高于随机搜索。

## 三、想读中文文怎么筛

作品按**写作语言**归档，中文是其中一个语言分区：进 fandom 页把语言筛选切到 Chinese 即可。预期先放好——中文分区以早年间积累的文为主，新文更新频率远低于英文区；应用界面本身是英文的，语言筛选只管作品、不管界面。

筛到想看的文，第一件事是加收藏或追更，第二件就是下载离线包，操作见[离线书库和听书怎么用](离线书库和听书怎么用.md)。整套流程的入口（安装包获取与安装步骤）在 [FanFiction.Net 客户端介绍站](https://fanfiction-net.laze.skin/)的下载页；拿不准这座文库适不适合自己，可以先看[和AO3比有什么不同](和AO3比有什么不同.md)。
