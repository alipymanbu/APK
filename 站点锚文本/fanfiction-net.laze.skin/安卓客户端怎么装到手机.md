# 安卓客户端怎么装到手机

FanFiction.Net（同好圈里常写作 FFN）网页端 1998 年就在了，手机上想舒服地读，走的是 FictionPress 出品的安卓客户端：整本缓存离线读、文字转语音当有声书听，这两样都只有应用里才有。这篇把从拿到安装包到首次打开的过程一次讲完。

相关文章：[离线书库和听书怎么用](离线书库和听书怎么用.md) · [和AO3比有什么不同](和AO3比有什么不同.md)

## 一、装之前的两句须知

1. **手机上没有 Google 服务框架也能装**。国行 ROM 普遍没有这套框架，商店渠道走不通时，从网盘把 APK 取到手机侧载是常规做法，功能与商店版没有差别。
2. **空间留够**。安装包约 65MB，装完之后离线章节才是大头，建议再留 1GB 以上的余量给书库。

## 二、四步装好

1. **转存安装包**。进入 [FanFiction.Net 客户端介绍站](https://fanfiction-net.laze.skin/)的下载页，点「获取安装文件资源」打开夸克网盘分享页，把安装包转存到自己的网盘账户下。
2. **下载到手机**。在网盘客户端里把 APK 下载到手机的「下载」目录；先下到电脑再数据线传过去也可以。
3. **放行未知来源**。第一次点开 APK 会弹「禁止安装未知来源应用」：原生系统去 设置 → 应用 → 特殊应用权限 → 安装未知应用，给文件管理器授权；MIUI、ColorOS、HarmonyOS 这类系统一般会在点开时直接弹窗引导到对应开关，按提示走即可。
4. **完成安装并打开**。授权回来再点 APK，等进度走完点「打开」。报「解析包错误」多半是下载不完整或存储不足，重下一遍再试。

## 三、首次打开的两件事

- **登录凭据是邮箱 + 密码**，不是笔名——注册时填的 Pen Name 只是对外展示的名字。不登录也能浏览、搜索、读文，要收藏、追更、跨设备同步才需要账号。
- **权限按需给**：麦克风对应私信语音、电话状态对应听书时来电自动暂停，拒绝哪项只是对应功能不可用，之后随时能在系统设置里补开。

装好之后先别急着翻列表，作品库以百万计，从哪里找起见[找文从九大分类开始](找文从九大分类开始.md)；想把通勤时间利用起来，[离线书库和听书怎么用](离线书库和听书怎么用.md) 讲的就是这件事。
