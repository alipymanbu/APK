# 安卓AI聊天应用免费模型用法

> 本篇讲不填 API Key、不注册账号，装好就能直接聊的用法：内置免费模型在哪、怎么切、适合什么场景。
> **相关文章**：[多服务商AI客户端API密钥配置方法](多服务商AI客户端API密钥配置方法.md) · [MCP与联网搜索配置思路](MCP与联网搜索配置思路.md)

## 一、免费模型从哪来的

这款客户端从 1.4.8 版本起与硅基流动合作，应用里默认内置了免费小模型——算力由合作方提供，走的是应用内的合作通道，不需要注册、不需要填 Key，装好即用。内置名单里常见的是 Qwen3-8B、GLM-4.1V-9B 这类小体积模型，具体以你手上版本的实际显示为准。

## 二、三步开始聊

1. 先把应用装上（获取方式见文末的资料站入口）。
2. 打开应用，直接落在对话页，不用做任何配置。
3. 点输入框左下角的模型选择器，选内置的免费模型，发消息就能聊。

默认助手开箱就是免费模型，上图那张实机截图——标题栏写着「默认助手 / Qwen3-8B（硅基流动）」——就是这个状态。

## 三、免费模型适合干什么

- **先试手感**：界面顺不顺手、回复速度怎么样，零成本试明白再决定要不要接自己的 Key。
- **轻量问答**：查个词、翻译一段、起个标题，小模型完全够用。
- **不适合的**：长文写作、复杂推理、大文件分析这类重度任务，小模型能力上限摆在那里，接一个付费服务商体验会完全不同。

## 四、之后想升级怎么办

免费模型随时可用，不排队也不限时；等确认这款应用适合自己，再去「设置 → 提供商」里填上自己的 Key，两步就能换到更强的模型，配置方法在[多服务商AI客户端API密钥配置方法](多服务商AI客户端API密钥配置方法.md)里逐步写过。客户端介绍、截图与安装文件资源入口，都在 [RikkaHub 资料站](https://rikkahub.fedq.quest/)。
