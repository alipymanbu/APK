# 多服务商AI客户端API密钥配置方法

> 本篇讲怎么把手里已有的各家 API Key 装进同一个安卓客户端统一管理：DeepSeek、硅基流动、OpenRouter、中转站，配一次就能随时切换。
> **相关文章**：[安卓AI聊天应用免费模型用法](安卓AI聊天应用免费模型用法.md) · [MCP与联网搜索配置思路](MCP与联网搜索配置思路.md)

## 一、先想清楚要接什么

手里已有的 Key 大概分三类，接法都一样：

- **厂商直连**：DeepSeek、智谱这类，Key 从各家后台申请，地址用默认的就行。
- **聚合平台**：OpenRouter、AiHubMix、硅基流动这种，一个 Key 能调多家模型，适合想多换几个模型对比的人。
- **中转站**：地址和 Key 都是平台给的，Base URL 每家不同，最容易填错的就是这一类。

## 二、三样东西填进去

在客户端的「设置 → 提供商」里新建一个服务商，界面上要填的就三样：

1. **名称**：随自己起，方便认就行，比如「我的 DeepSeek」。
2. **API Key**：从对应平台后台复制，粘贴时留意别带上空格。
3. **API Base URL**：厂商直连用默认地址；中转站按平台给的填，注意路径通常以 `/v1` 结尾——地址栏多一段少一段都会连不上。

填完保存，到「模型」页签拉取模型列表，勾选常用的；回对话页点左下角的模型选择器就能切换。

## 三、几个让配置更顺手的细节

- **高级设置**：新版本给服务商加了高级设置页，可以自定义请求头——遇到要求特殊鉴头的平台，就在这里补。
- **余额查看**：部分平台支持在应用里直接看账户余额，充了多少、还剩多少不用另开网页。
- **网络代理**：单独一页配置，内网环境或需要走代理时用得上。
- **按需启停**：每个服务商是独立卡片，不用的先停用，模型选择器里清爽很多。

## 四、配好之后

多服务商的意义在切换成本：写作用一家、查资料用另一家，都在同一个对话框里完成。想先不花钱体验，直接用内置的免费模型，路子看[安卓AI聊天应用免费模型用法](安卓AI聊天应用免费模型用法.md)；模型就位后想让它会查网、会调工具，看[MCP与联网搜索配置思路](MCP与联网搜索配置思路.md)。客户端本身的介绍与获取方式，见 [RikkaHub 安卓客户端](https://rikkahub.fedq.quest/)资料站。
