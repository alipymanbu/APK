# MCP与联网搜索配置思路

> 本篇讲让手机上的 AI 从「只会动嘴」升级到「会查资料、会动手」的两条路：接入搜索服务，以及配置 MCP 工具。
> **相关文章**：[多服务商AI客户端API密钥配置方法](多服务商AI客户端API密钥配置方法.md) · [安卓AI聊天应用免费模型用法](安卓AI聊天应用免费模型用法.md)

## 一、先分清两件事

- **联网搜索**：回答前先查网，适合问「今天的」「最新的」这类时效性问题。客户端内置了 Exa、Tavily、Brave 等检索服务的接入位。
- **MCP 工具**：按 Model Context Protocol 接上外部工具与数据源，模型可以主动调用，查库、控制服务、取本地数据都算这一路。

两者可以同时开，搜索管「看什么」，工具管「做什么」。

## 二、把搜索接上

在「设置 → 搜索服务」里选一家检索服务商，填上对应平台的密钥并开启即可。想先不花钱，也有两条被第三方教程提到的路：选有免费额度的服务，或者自建 SearXNG 这类聚合搜索再接进来——属于进阶玩法，以你手上版本的实际界面与所选服务商的说明为准。另外部分聚合平台提供内置联网能力的模型变体（模型名常带 search 之类后缀），联网走模型账单、不用单独配搜索密钥。

## 三、把 MCP 配上

「设置 → MCP」里添加服务器：

1. 抄准服务器的地址与鉴权信息，**请求头名称与取值一个字符都别错**——更新日志里就修过「请求头名称为空导致连接失败」这类问题，老版本遇到先升级再试。
2. 保存后确认该 MCP 服务本身在线，再回到对话里试着让它调一次工具。
3. 连不上时按顺序核对：地址拼写 → 请求头 → 服务是否存活，三处占大多数。

## 四、配上记忆，体验才完整

记忆功能让模型把你的偏好主动写进数据库，开新对话也能读到；入口在助手的「记忆」页签，可以开关、可以手动增改。记忆需要模型支持工具调用，配合 MCP 一起开最顺。客户端本身的功能总览与获取入口，见 [RikkaHub 使用介绍](https://rikkahub.fedq.quest/)；还没配 Key 的先看[多服务商AI客户端API密钥配置方法](多服务商AI客户端API密钥配置方法.md)。
