# 泰拉瑞亚手机版怎么装模组？用 tModLoader 三步搞定

> 本篇讲在安卓手机上给泰拉瑞亚装模组的完整路子：先装 tModLoader 手机移植版，再把 .tmod 模组文件放进模组目录，最后启用并重载。装模组遇到的报错，多半也能在 [闪退怎么办](闪退怎么办.md) 里找到答案。

在电脑上，泰拉瑞亚玩家装模组基本都走 tModLoader——它是社区里最出名的开源模组加载器，模组生态围着它转。手机上原本没这条路的，直到社区把它移植到了安卓：装上这份移植版，手机也能像电脑那样一个模组一个模组地加内容。

想先了解这份移植版本身（功能、机型建议、截图），可以看 [tModLoader 手机版介绍站](https://tmodloader.gerw.hair/)，这里不重复展开，直接讲装模组的操作。

## 第一步：把 tModLoader 装起来

模组管理器本身是一个 APK 安装包，从网盘把安装包下载到手机，允许安装未知应用后装上即可。具体步骤在站点的下载页写得很细，装的过程有两个点值得强调：

- 首次启动授予**存储权限**：模组文件的导入、模组目录的生成都靠这个权限，不给后面寸步难行；
- 装完先完整跑进一次泰拉瑞亚主菜单：模组目录要等它正常运行一次后才会生成，很多「找不到 Mods 文件夹」的问题就是少了这一步。

## 第二步：拿到 .tmod 模组文件

tModLoader 认的是 `.tmod` 后缀的模组文件，来源主要两条：

1. **模组作者的发布页**：大型模组基本都在 GitHub 的 Releases 页按版本分档发布，这是最稳的渠道；灾厄这类大型模组的本体和音乐包是两个独立的 .tmod，要分别下载。
2. **应用内模组浏览器**：部分移植版带联网的模组浏览器，能直接在应用里检索安装；拉不出列表就回到手动放文件的路子。

要留意的是号称「整合包」的压缩包：来路不明的合集没法确认有没有被掉包，宁可自己一个个从发布页拿。

## 第三步：放进模组目录并启用

1. 启动 tModLoader，进主界面的「模组管理」，点「打开模组文件夹」；
2. 部分机型不会自动跳转，就手动打开文件管理器，进入这个目录：

```text
/storage/emulated/0/Android/data/ModLoader.Explendesco/Mods/
```

3. 把 .tmod 文件复制或移动进去，支持一次放多个；
4. 回到「模组管理」，打开模组旁的开关；
5. 点「重新加载模组」，再选模式进游戏，新内容就生效了。

两个高频坑提前说：压缩包要先解压，别把 zip 直接扔进 Mods 文件夹；安卓 11 以后不少自带文件管理器看不到 Android/data 目录，换支持它的第三方文件管理器，或直接走应用内那个跳转入口。

## 装完没生效？按顺序查三处

- 开关是否真的打开，改完有没有点「重新加载模组」——改完直接进游戏是不会变的；
- 模组版本和移植版内核对不对得上：模组按特定版本编译，对不上时不生效或直接报错，换相邻版本再试；
- 依赖装全了没有：不少模组要前置库模组，缺了就加载失败，发布页一般会写明。

建议养成「一次只加一个新模组」的习惯：进游戏确认正常再加下一个，出问题时立刻能锁定是哪个引起的。装好了想拉朋友一起玩，先看 [联机与存档整理](联机与存档整理.md)，联机翻车九成出在双方模组不一致上。
