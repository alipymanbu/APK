# tModLoader 手机版闪退怎么办？按现象排查

> 本篇集中处理 tModLoader 安卓移植版的高频故障：一打开就闪退、找不到模组文件夹、模组不加载、能玩但卡。按你看到的现象对号入座。还没装上的，先去 [手机版怎么装模组](手机版怎么装模组.md) 把流程走完。

手机版 tModLoader 的故障大多有固定套路：权限没给、目录没生成、版本没对上。先说一个整体判断：**头几次启动闪退不等于装坏了**，这是移植版玩家反馈最集中的现象，多数人多开几次就能正常进入。

## 现象一：一打开就闪退

1. **查存储权限**：系统设置 → 应用 → tModLoader → 权限，确认「存储」已允许。没给权限时它可能连主界面都进不去。
2. **多开几次**：不少用户的经验是首次启动连着闪退两三次，之后就能正常进。这不是装错了，多试几次再看。
3. **清后台再试**：后台驻留的应用太多、内存紧张会加剧闪退，清掉后台重开。
4. **重启设备**：以上都试过仍然闪退，重启一次能解决大部分临时性问题。

反复闪退超过五次仍进不去，卸载后重装一次。重装前注意：**卸载会把存档一起删掉**，动手前先把存档目录复制出来（怎么备份看 [联机与存档整理](联机与存档整理.md)）。

## 现象二：文件管理器里找不到 Mods 文件夹

`Android/data/ModLoader.Explendesco/Mods/` 这条路径找不到，通常是两个原因：

- **应用还没完整跑过一次**：模组目录在应用首次正常运行到主菜单后才生成。先让它完整启动一次再回来找。
- **文件管理器看不到 Android/data**：安卓 11 以后不少系统的自带文件管理器限制访问这个目录。换支持访问该目录的第三方文件管理器，或走应用内「模组管理 → 打开模组文件夹」的入口跳转。

## 现象三：模组放进去了，游戏里没有新内容

1. 确认开关打开、且点了「重新加载模组」再进游戏；
2. 确认放进去的是解压后的 .tmod 文件，不是整个 zip；
3. 版本不匹配：模组按特定版本编译，对不上时不生效或报错，换与内核对应的模组版本；
4. 依赖没装全：缺前置库模组会加载失败，把说明里列的依赖逐个补齐再重载。

## 现象四：能玩但很卡

- 中低端机型带大型模组包吃力，属于性能余量问题而不是故障。减掉几个大型模组、只留必需的，帧数会明显回稳；
- 试试设置里的「跳帧」选项，不少玩家反馈对卡顿有改善；
- 长时间游玩发热也会掉帧，让手机降降温再玩；
- 世界越大、模组越多，进图加载越久，卡在加载界面先等一等，别急着杀后台。

## 还是不行的时候

卸载重装是兜底动作，顺序别乱：先备份存档 → 删应用 → 重装 → 恢复存档 → 重新导入模组。重装后问题依旧的话，多半是设备与这份移植版不兼容，换台内存大些的设备是最直接的办法。装模组的完整流程回顾见 [手机版怎么装模组](手机版怎么装模组.md)，站点里还有更多玩法层面的整理，在 [tModLoader 手机版介绍站](https://tmodloader.gerw.hair/)。
