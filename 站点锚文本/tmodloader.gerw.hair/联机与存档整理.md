# tModLoader 手机版联机与存档整理

> 本篇讲两件容易翻车的事：手机版怎么和朋友联机（模组必须对齐），以及存档放在哪、怎么备份。装模组还没走通的先看 [手机版怎么装模组](手机版怎么装模组.md)，联机后频繁闪退的去看 [闪退怎么办](闪退怎么办.md)。

模组泰拉瑞亚的联机翻车，九成出在「双方模组不一致」；存档翻车，则几乎都是「没备份就动了模组」。这一篇把两件事的操作与检查点列清楚。

## 联机的前提：双方完全对齐

进同一个房间之前，逐项核对：

| 核对项 | 要求 |
| --- | --- |
| 应用版本 | 双方 tModLoader 手机版版本一致 |
| 模组清单 | 启用的模组一模一样，多一个少一个都可能进不去 |
| 模组版本 | 同一个模组也要同一版本，不能你新版他旧版 |
| 依赖模组 | 主模组的依赖库同样要对齐 |
| 汉化包 | 用了汉化的话双方也要同版本，一边中文一边英文可能进不了房 |

一个省事的做法：开房的玩家把自己 Mods 文件夹里的 .tmod 文件打包发给朋友，让对方放进同样的位置再启用，清单天然一致。

## 联机步骤

以其中一台手机当主机：

1. 双方按上表对齐模组，各自先进一次游戏确认正常；
2. 主机玩家在主菜单选「多人游戏」；
3. 选「开服并进入游戏」，用自己的世界当联机房间；
4. 朋友在同一网络下从「多人游戏」里加入该房间。跨网络能不能连，取决于移植版的联网能力与网络环境，以实际版本支持为准。

进房后立刻掉线或卡在加载，先回头核对模组清单——这是联机故障里占比最大的一种，其次才是网络原因。

## 存档：独立存放，先备份再折腾

- **模组存档与原版分开**：tModLoader 体系的存档（.tplr / .twld 格式）与原版泰拉瑞亚的存档相互独立，玩模组不会覆盖你原版的进度，反过来原版存档也不能直接在模组环境里接着玩；
- **手机上可以手动备份**：用文件管理器把包含 ModLoader.Explendesco 的数据目录整个复制一份到别的位置（手机存储、电脑、云盘都行）。换模组、换版本、重装应用之前都先备一次；
- **删应用 = 删存档**：卸载 tModLoader 时它的存档会一起没掉。排查故障要重装之前，先确认存档已经备份出来；
- **PC 与手机互不相通**：电脑版的模组存档拿到手机上用不了，别白折腾。

## 换手机怎么搬

换机前把整个模组存档目录复制到新手机相同位置（路径里含 ModLoader.Explendesco 的那一套目录），模组文件也原样带过去；装好同版本应用、放回存档与模组，进度就能接着玩。装备与角色进度对不上时，优先检查存档是不是放错了目录层级。

想系统了解这份移植版的功能与机型建议，去 [tModLoader 手机版介绍站](https://tmodloader.gerw.hair/) 翻一遍再动手，能省不少试错成本。
