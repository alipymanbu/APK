# Struckd 站点目录：手机 3D 游戏创作应用介绍

这里是 Struckd 的第三方介绍站收录目录：Struckd 是一款在手机上拖拽搭建 3D 游戏的创作应用，2016 年由瑞士 Struckd AG 推出、2021 年并入 Unity 旗下，巅峰时期社区里汇聚了全球玩家做出的竞速、解谜、大逃杀等各类关卡。本目录的文章围绕它的玩法搭建方法、安卓版安装流程与在线服务停运后的现状整理。安装文件资源的获取入口见 [Struckd 介绍与下载站](https://struckd.qhah.skin/)。
