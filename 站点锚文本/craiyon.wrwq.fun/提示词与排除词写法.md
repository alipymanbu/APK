同一个想法，描述写法不同，九宫格的质量差距很大。Craiyon 对长句和复杂结构的理解能力有限，越具体、越简单的描述出图越稳——它对英文的响应也普遍好于中文，这是社区经验而非硬规则，两种都值得试。

## 一、三段结构：主体 + 场景 + 风格

一句够用的提示词通常长这样：

```text
主体 + 所在场景或动作 + 风格或氛围
```

拿一句被多方引用过的示范拆开看：`a cyberpunk cat wearing neon goggles, rainy Tokyo street, cinematic lighting`——

- 主体：戴霓虹护目镜的猫（一个就好，两个以上物体同框出错率明显升高）；
- 场景：雨夜的东京街头（时间、天气、地点都算场景信息）；
- 氛围：电影感打光（想要的具体颜色、光线直接写进描述）。

只写 `a cat` 三段缺两段，九张图会飘得没边；三段写齐，九张之间就只剩细节差异，挑图才有意义。

## 二、排除词（Exclude elements）兜底

排除词是单独的一个输入框，填「不想要什么」，官方建议填概念词而不是完整句子：

| 你不想要 | 可以填 |
| --- | --- |
| 画面整体偏蓝 | `blue` |
| 不想出现人 | `people` |
| 对比度太低、发灰 | `low contrast` |
| 图里长出乱码文字 | `text` |
| 手指多画了几根 | `extra limbs` |
| 画面发糊 | `blurry` |

排除词和正向描述一样作用于整批九张图，改完要重新生成才能看到效果。写不出正向描述的时候，先靠它兜底。

## 三、按「一次改一处」迭代

九宫格天生适合比稿，比稿的纪律是每轮只改一处：

- 换风格词、换场景、加一个排除词——一轮只动一样，才知道是哪处改动起了作用；
- 九张里只要有一张方向对，就照着那张的特征收窄描述；
- 改了三轮还整体崩面，说明描述里塞了太多元素，删到只剩主体加一个场景再试。

另外两条减少内耗的经验：人脸和手是模型的已知弱项，人物放小、放远比特写稳；图里要出现文字基本必崩，文字留到后期加。
