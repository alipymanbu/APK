# 相机取色与图片取色怎么选

> 本篇讲 Color Picker 两条取色路径的分工：什么时候用相机对着实物取，什么时候从相册或分享入口开图取，以及各自影响读数准头的因素。
> **相关文档**：[安卓取色工具安装步骤](安卓取色工具安装步骤.md) · [色温与主波长读数怎么理解](色温与主波长读数怎么理解.md)

---

同样是为了「认出一个颜色」，镜头对着实物和打开一张图，是两条不同的路。以 Color Picker 这款安卓取色工具为例，把两条路径的适用场景和注意事项摆在一起说。

## 一、相机取色：对着实物读

打开应用就是取景框，画面中央有个取样框，框住的区域实时给出读数：颜色名、HEX，还有匹配百分比。适合这些时刻：

- 站在涂料店或家具城，想知道眼前这块颜色接近哪个标准色号；
- 对比两个实物（一块布和一面墙）颜色差多少；
- 户外看中一个颜色，想先记下来。

影响准头的三件事：**对焦**（没对上焦读数会漂）、**白平衡**（白平衡不准整体色偏，可以像用相机 App 一样手动调）、**环境光**（强逆光和暖色灯光都会带偏读数）。取样框能换成圆形、方形或单点，测均匀大面用框，测一个像素点用单点。

## 二、图片取色：从图里挑像素

从相册打开图片，或把图片从聊天、修图应用里直接**分享**过来，放大、滑动，逐像素挑。适合这些时刻：

- 网页或设计稿里看到想抄的颜色；
- 想对比昨天拍的照片和今天实物的色差；
- 场景已经不在跟前，只剩照片。

图片取色的好处是**可复查**：同一个点反复取、和旁边像素对比都行；坏处是照片本身带了拍摄时的色偏，读数反映的是「照片里的颜色」，未必是「实物当时的颜色」。

## 三、怎么选

| 你的情况 | 更合适的路径 |
| --- | --- |
| 人就在现场，要读实物 | 相机取色 |
| 只有一张图 / 截图 | 图片取色 |
| 要逐像素抠一个精确值 | 图片取色（放大后单点） |
| 要区域平均色 | 两条路径都支持，框选取样 |

两条路径读出的结果都进同一条历史记录，之后按名字或 HEX 搜、导出 CSV 都在这条记录上操作。读完想对涂料色号，接着看[RAL色号查询与漆面对色](RAL色号查询与漆面对色.md)；想知道色温、主波长这些读数的含义，看[色温与主波长读数怎么理解](色温与主波长读数怎么理解.md)。两条路径的具体界面与读数样式，[Color Picker 取色站](https://color-picker.fewf.click/)上有按场景拆开的截图对照。
