# 5EPlay 手机版与电脑端怎么分工

> 同一个 5E 账号，手机 App 与电脑客户端各管一摊。这篇按事情分类：哪些在手机上就能办完，哪些必须回到电脑上，省得两头翻找。
> **相关文档**：[战绩与天梯分在哪查.md](战绩与天梯分在哪查.md) · [安装包从哪拿.md](安装包从哪拿.md)

---

5EPlay 是 5E 对战平台的手机端应用，与电脑上的平台客户端共用一个账号。很多玩家装完手机端后第一反应是「怎么打不了对局」——这不是装错了，而是两端本来就分工不同。

## 一句话分清两端

- **手机 App（5EPlay）**：管「局外事」。看战绩、追赛事、逛社区、处理账号与认证。
- **电脑客户端**：管「局内事」。实际进入对局、匹配排位、组队与训练房间。

两端登录相互独立，数据实时互通：手机上查到的天梯分，就是电脑端打出来的那个分。

## 手机上就能办完的事

| 事情 | 入口 |
| --- | --- |
| 查看个人战绩、天梯分与段位 | 「我的」页面战绩板块 |
| 追赛事比分、看直播与录像集锦 | 首页与赛事板块 |
| 实名认证的登记、查看与换绑 | 「我的 - 设置 - 账号管理」 |
| 改绑手机、找回密码 | 「设置 - 账户信息」 |
| 扫脸认证、5E 令牌 | 按 App 内提示操作 |
| 扫码登录网页端与客户端 | 「我的」界面右上角扫一扫 |

## 必须回电脑上做的事

| 事情 | 原因 |
| --- | --- |
| 进入对局、匹配排位 | App 不能打平台对局，这是客户端的核心用途 |
| 5E 账号绑定 Steam | 在电脑端本机登录 Steam 后由客户端读取，且绑后不可解绑 |
| 找搭子、组队大厅 | 入口在客户端的排位房间界面里 |
| 赛季通行证任务与兑换 | 任务随对局产生，在客户端结算 |
| 道具商城、改名卡 | 购买与使用都在客户端 |

另有一条容易踩的环境限制：平台客户端不支持虚拟机、Hyper-V、Windows 预览版与 Mac 系统，装之前先核对环境。

## 双端怎么配合着用

常见节奏是：电脑上打完几把排位，手机上随手看结算数据与天梯分变化；赛季切换后用手机盯定级赛进度；遇到需要扫脸认证或改绑手机这类事务，掏出手机就能办，不必专门坐回电脑前。

想动手装一份的，安卓安装文件资源与完整安装步骤都整理在 [5EPlay 手机端介绍站](https://5eplay.gerw.hair/)；装好之后各项数据在哪看，见[战绩与天梯分在哪查.md](战绩与天梯分在哪查.md)。
