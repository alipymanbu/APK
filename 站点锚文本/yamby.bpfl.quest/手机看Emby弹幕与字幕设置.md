# 手机看 Emby 的弹幕与字幕设置

> 弹幕匹配不上、字幕快半拍、手势划了没反应——这些观影小件的使用与排查，一篇说清。以安卓端第三方客户端 Yamby 为例，其余 Emby 客户端的对应功能可参照。
> **相关阅读**：[Emby安卓客户端怎么选.md](Emby安卓客户端怎么选.md) · [Emby服务器连接不上排查.md](Emby服务器连接不上排查.md)

## 一、弹幕：先懂机制，再调开关

Yamby 的弹幕基于 dandanplay 匹配当前播放的剧集，**只支持中文弹幕**。匹配机制决定了两件事：

- 小众片源、刚发布的资源，匹配库里可能还没有——匹配不上就没有弹幕，这是机制，不是开关没打开；
- 匹配上了之后，在播放器里确认弹幕开关处于开启状态即可，不需要额外装插件。

多季连看时先开一集有弹幕的确认链路正常，再回头看没弹幕的那集，就能分清「匹配库没有」和「开关没开」。

## 二、字幕：三个旋钮 + 一个兜底

| 症状 | 动哪个 |
| --- | --- |
| 字幕太小 / 挡画面 | 字幕缩放 |
| 字幕比声音快半拍 | 字幕时间偏移（正值延后、负值提前） |
| 中文字形不顺眼 | 自定义字幕字体 |
| 死活不显示 | 文件本身没有字幕轨，或服务器没开对应权限 |

内嵌字幕与外挂字幕都能选：一个文件带多条字幕轨时播放中随时切；剧集有多语言音轨也支持播放中直接换，不用退出重进。连续看剧时会自动沿用上一集选过的版本，不用每集重选。

## 三、手势：默认是关的

音量、亮度、进度的手势控制**默认关闭**——画面上滑没反应，先去设置里找手势开关，打开后再上画面试。这是被问得最多的一条：不是版本缺功能，是开关没开。

## 四、画中画与倍速

- **画中画**：播放中切到别的应用，画面缩成悬浮小窗继续播（需在系统设置里允许应用的画中画权限），点开小窗即回全屏；
- **倍速与缓存**：倍速不影响服务器原文件，课程与访谈随手加速；网络抖动频繁缓冲时调大缓存，设备内存紧张就别调太大。

这些参数没有「一次设对」的通用值，按习惯调到顺眼即可。
