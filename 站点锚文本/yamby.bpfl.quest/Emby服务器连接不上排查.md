# Emby 服务器连接不上排查

> 手机客户端一直转圈、提示连接失败——按「服务器活着吗 → 字段对不对 → 网络通不通」的顺序逐条查，多数问题在前三步就解决了。
> **相关阅读**：[Emby安卓客户端怎么选.md](Emby安卓客户端怎么选.md) · [手机看Emby弹幕与字幕设置.md](手机看Emby弹幕与字幕设置.md)

---

## 一、先查服务器那头

客户端再怎么折腾，也救不了关机的服务器：

1. **进程活着吗**：Emby Server 是否在运行、电脑/NAS 是否休眠了；
2. **浏览器交叉验证**：拿另一台设备开浏览器访问 `http://服务器地址:8096`，能打开登录页说明服务器与端口是通的，问题在客户端填法；浏览器也打不开，就是服务器或网络的问题；
3. **远程访问开关**：出了家门连不上，先确认服务器上 Emby 的「允许远程访问」已开启。

## 二、再核客户端填法

以 Yamby 为例（其余 Emby 客户端字段大同小异），三处最容易错：

| 字段 | 正确填法 | 常见错误 |
| --- | --- | --- |
| 地址 | 只填 IP 或域名 | 带了 `http://` 前缀 |
| 端口 + 协议 | 配对：HTTP `8096` / HTTPS `8920` | 选了 HTTPS 却填 8096 |
| 路径 | 直连服务器就留空 | 没配反代也填了东西 |

密码建议手敲一遍：复制粘贴容易带进尾部空格，表现为 401 一类的认证失败。

局域网内还可以先试自动发现：添加页面里看有没有自动扫出来的服务器，有就直接点。自动发现靠 UDP 广播，路由器开了 AP 隔离、访客网络、跨网段都会失效——失效就手动填，手动填永远是兜底方案。

## 三、然后查网络链路

- **同一局域网**：手机与服务器必须在同一个网；连的 Wi-Fi 是不是访客网络（访客网络通常隔离设备）；
- **端口转发**：外网访问需要路由器把 TCP `8096`/`8920` 转发到服务器内网 IP，服务器系统防火墙放行这两个端口；Windows 上把网络配置文件设为「专用网络」，「公用」会拦入站连接；
- **Strm 直通的特殊情况**：Strm 里写的是内网地址、手机在外网时拉不到流，表现为点了没反应或一直转圈——确认流地址从手机当前网络可达。

## 四、还不行就删掉重加

地址换过、服务器重装过之后，把客户端里的旧服务器条目删掉重新添加，比在旧条目上反复改干净得多。清数据或换设备前，把服务器地址与端口记下来，重填一次就能恢复。

客户端本身还没装的话，[Yamby 安卓客户端介绍站](https://yamby.bpfl.quest/) 有安装文件资源与功能介绍；装好后弹幕、字幕这些观影设置的调法见 [手机看Emby弹幕与字幕设置.md](手机看Emby弹幕与字幕设置.md)。
