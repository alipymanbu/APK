# Olib 安卓版下载与安装步骤

本篇讲清楚一件事：如何把安卓版的 Olib 装到手机上并完成首次登录。安装本身不难，真正容易卡住的是「未知来源应用」的授权环节，下面按顺序展开。

相关文档：[找书取书与线路切换技巧](找书取书与线路切换技巧.md)、[本地书导入与离线阅读设置](本地书导入与离线阅读设置.md)

---

## 一、安装包从哪里拿

Olib 是开源软件，源码公开在 GitHub 仓库，而安卓安装包（APK）的获取走网盘分享的路线：分享页里把文件转存到自己的网盘账户，再从网盘下载到手机即可。整个过程不需要电脑，也不需要在陌生站点点各种「高速下载」按钮。

如果只想看最直接的入口，可以到这个 [Olib 介绍站](https://olib.gkhf.beer/) 的下载页，从安装文件资源的获取按钮进入网盘分享。

## 二、四步完成安装

1. **转存分享文件**：打开网盘分享页，把安装包转存到自己的网盘；
2. **下载到手机**：在网盘客户端里找到刚转存的文件，下载到本地存储；
3. **允许安装**：点击 APK 时系统会提示「未知来源应用」，按引导允许该来源安装后继续；
4. **首次登录**：打开应用，同意用户协议后输入邮箱和密码登录——它没有独立的账号体系，直接用线上书库的邮箱账号即可，无需另注册。

## 三、安装环节的常见问题

**点 APK 没反应或被拦**
这是系统级的来源保护，不是文件问题。给浏览器或网盘客户端授予「安装未知应用」权限（一般在「设置 → 安全」或安装引导页里），再重新点开 APK 即可。

**装好后打开一直转圈**
多见于没选线路。在「选择线路」面板里换一条在线的线路（绿点状态），必要时检查网络后重试。

**想确认装的是哪个版本**
登录成功后进设置页，能看到下载历史、下载目录等配置项；应用的具体版本信息以安装包说明为准，不依赖猜测。
