# 界面英文看不懂怎么办

FanFiction.Net 的安卓客户端界面只有英文，应用内没有切换语言的选项——很多中文用户装完第一件事就是翻设置找语言项，翻不到不是操作问题，是它真的没有。这篇给你两条路：高频词认脸，以及用作品语言筛选读中文文。

## 一、高频界面词对照

日常操作翻来覆去就这几个词，认下来基本无障碍：

| 界面词 | 意思 |
| --- | --- |
| Library | 书库，收藏与下载的书都在这 |
| Downloaded | 已下载，离线可读的分区 |
| Follows / Favorites | 追更 / 收藏 |
| Reviews | 评论 |
| Forums / Community | 论坛 / 社区合集 |
| Crossover | 交叉，两个世界观混同的故事 |
| Complete / In-Progress | 完结 / 连载中 |
| Rating | 分级，K / K+ / T / M 四档 |
| Words / Chapters / Updated | 字数 / 章节数 / 更新时间 |

分级口径顺带记一下：K 全年龄，K+ 八岁以上，T 十三岁以上，M 十六岁以上；默认列表只展示 K 到 T，M 级文要在设置里确认年龄后才显示。

## 二、读中文写的作品：语言筛选是另一回事

界面语言和作品语言是两个维度。站内作品按写作语言归档，中文是其中一个分区：进具体原作（fandom）的页面，把语言下拉筛选切到 Chinese，列表就只剩中文写成的文。

预期先放平：中文分区以早年积累的存量为主，新文更新频率远低于英文区，更像一个小众角落。想在站内读新一点的中文创作，别把期待全押在这一个分区上。

## 三、机器翻译是个补充

应用的功能列表里出现过 Translation 条目：用内置引擎把故事译成你的语言读。两点注意——这个功能随版本迭代，你手上的版本有没有、藏在哪级菜单，以应用内实际显示为准；译文只能应付追情节，精读或玩文字梗的章节别只依赖它。

## 四、装机与上手

应用从哪来、怎么装，[FanFiction.Net 安卓端介绍站](https://fanfiction-net.gltd.quest/)把下载与安装步骤拆成了四步，界面实拍也放在那里，照着认图标比背单词快。装好之后先逛分类页，把语言筛选用起来；找 App 的整体思路见[手机看同人小说用什么 App](手机看同人小说用什么App.md)，安装环节卡住看[安卓端安装遇到问题怎么办](安卓端安装遇到问题怎么办.md)。
