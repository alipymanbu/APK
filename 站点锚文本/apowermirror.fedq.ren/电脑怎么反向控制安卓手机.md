# 电脑怎么反向控制安卓手机

> 本篇讲用电脑键鼠直接操作安卓手机（反控）的前置条件与激活顺序：为什么要先插一次 USB、手机端要开哪些服务、哪些机型会不支持，以及反控没反应时按什么顺序查。

## 一、反控是什么、能省掉哪些动作

反控指把安卓手机画面投到电脑上之后，直接用电脑的键盘和鼠标去点手机屏幕：输入验证码、在聊天软件里打长句、批量截屏，都不用再伸手拿手机。手机端的触控和电脑端的键鼠是同时生效的，两边谁都能操作。

免费账户下电脑反控只能连 1 台安卓设备；会员解锁后是 4 台。权益随版本可能调整，以购买页当时的说明为准。

## 二、第一次必须用 USB 数据线激活

反控模式不是 WiFi 连上就能用，激活顺序要注意：

1. 用 USB 数据线把手机连到电脑，两端都开着应用；
2. USB 连接成功后反控模式会自动激活，不需要额外开关；
3. 拔掉数据线，再走 WiFi 连接一次，确认反控仍然可用。

第一次就跳过 USB 直接 WiFi 连，反控大概率是灰的——这是最常见的弯路。

## 三、手机端要开的服务

1. **无障碍服务**：系统设置 → 无障碍 → 已下载的服务（或已安装的服务）→ 找到 ApowerMirror → 开启并确认；
2. **反向控制服务**：手机互控另一台安卓的场景下，还需要在无障碍列表里把「反向控制 Android」一并开启；
3. **省电策略**：小米 / 红米机型把应用的电池策略改成「无限制」，旧版 MIUI 关闭「隐藏模式」，否则后台服务被杀、投屏会莫名断。

## 四、WiFi 反控与机型差异

激活之后日常走 WiFi 反控没问题，但少数机型对 WiFi 反控支持不佳（点按延迟大或部分操作无效）。判断方法很简单：同一台手机换 USB 线连一次，USB 下反控正常、WiFi 下不正常，就是机型对无线反控支持有限——这类情况直接固定用 USB 线最省心。

想要连接方式与排查的完整清单，可以看这篇整理：[傲软投屏怎么用](https://apowermirror.fedq.ren/)，把四条投屏流向和连法放在同一页讲。

## 五、反控没反应时按什么顺序查

1. 手机端无障碍服务是否还开着——部分系统在重启或系统更新后会自动关掉它；
2. 是否用过 USB 连接完成过一次激活；
3. 数据线是否支持数据传输（只能充电的线连不上）；
4. 电脑端防火墙是否放行过应用；
5. 还不行就重启两端设备再连一次。
