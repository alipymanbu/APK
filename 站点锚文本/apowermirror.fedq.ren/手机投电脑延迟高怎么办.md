# 手机投电脑延迟高怎么办

> 本篇讲手机画面投到电脑后延迟高、画面跟不上的处理思路：先分清延迟出在哪一段，再按 USB 直连、WiFi 提速、网络隔离、防火墙的顺序逐项处理。

## 一、先分清延迟出在哪一段

投屏链路是「手机采集 → 传输 → 电脑解码显示」，卡顿来源基本只有三类：

| 表现 | 多半是哪一段 | 先动哪里 |
| --- | --- | --- |
| 画面整体慢半拍但流畅 | 传输链路慢 | 换 USB 或优化 WiFi |
| 帧率高但忽快忽慢 | WiFi 干扰 / 信号波动 | 换 5GHz、靠近路由器 |
| 一开始就卡、重连几次都卡 | 网络不通或被拦 | 看第三节隔离与防火墙 |

## 二、最快见效的两招

1. **改用 USB 数据线直连**：有线传输的延迟明显低于无线，滚动、打字、玩游戏的跟手程度差别一眼能看出来，而且不受 WiFi 环境影响；顺手还把反控模式激活了。
2. **WiFi 换 5GHz 频段**：手机和电脑都连到路由器的 5GHz，离路由器近一点、中间别隔承重墙；2.4GHz 频段拥挤时投屏质量会明显波动。

画质与流畅也可以互相换：把投屏分辨率调低一档，传输数据量变小，卡顿会轻不少——看文档、看演示时几乎无感，追求画质时再调回去。

## 三、网络环境问题：隔离与防火墙

- **校园网、公司网、酒店网**经常开启设备隔离，同一 WiFi 下的设备互相发现不了，这类网络下无线投屏基本走不通：要么接家用路由器，要么直接 USB。
- **电脑防火墙**拦截接收端口时表现为反复连接失败：在 Windows 防火墙的「允许应用通过防火墙」列表里放行 ApowerMirror。
- 搜不到设备时还有个兜底：用应用里的**扫码或投屏码**直连，不依赖设备发现。

## 四、连接方式怎么选

四条流向（手机→电脑、电脑→手机、手机→电视、手机互投）各自适合的连法不同，这篇页面把它们和延迟差异放在了一起：[ApowerMirror 连接方式选择](https://apowermirror.fedq.ren/)，挑连法之前先过一遍能少走弯路。
