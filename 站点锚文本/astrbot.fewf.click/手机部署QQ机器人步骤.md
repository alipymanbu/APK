# 手机部署QQ机器人步骤

想让 QQ 号自动回消息、接大模型聊天，又不想碰命令行和服务器，最省事的路线是 AstrBot 的社区安卓封装版：框架核心、NapCatQQ 协议适配器、Ubuntu 容器环境被打成一个 APK，装上就自动完成部署。本篇把全过程按顺序过一遍。

## 动手前的三件事

- **网络**：首次启动要联网下载容器环境，用家用 Wi-Fi 或手机流量；校园网、公司内网、公共 Wi-Fi 经常把下载拦住，是「卡进度条」的头号原因。
- **存储**：安装包约 87 MB，初始化后实际占用会明显更大，先清出空间。
- **账号**：接入走第三方协议，账号有被风控的可能，拿备用小号当机器人，主力号别上。

## 四步装完

1. **拿安装包**：从网盘分享页转存后把 APK 下到手机；
2. **放行安装**：系统提示「未知来源应用」时，给下载用的 App 勾上允许安装的权限；
3. **首次启动初始化**：App 自动复制系统镜像、装核心组件、起协议适配器。保持屏幕常亮、点一下屏幕可切到终端日志页看进度；通知权限务必允许——机器人靠这条常驻通知保活。中途失败就关掉重开，会从断点续装；
4. **登录配置**：初始化完成弹出 QQ 登录二维码，扫码登录后内置管理面板会打开，默认账号密码都是 astrbot，进去改密码、填一个大模型 API Key，保存重启即可。用另一个号发条消息验证，能自动回就通了。

初始化完成后的样子、终端日志怎么看，[AstrBot 手机端介绍站](https://astrbot.fewf.click/)的安装页配了实拍截图，可以对照着核对每一步。

## 装好之后的两个习惯

- 通知栏那条「正在运行」别手动清掉，清了服务就停；
- 同一个号别再在电脑 QQ 上登录——机器人占的正是电脑端协议，两边互挤会把机器人挤下线，这是最常见的「假故障」。
