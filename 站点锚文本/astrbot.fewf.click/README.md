# AstrBot 站点导航（第三方整理）

AstrBot 是一个开源的多平台 AI 聊天机器人框架：把 QQ、企业微信、飞书、钉钉、Telegram 等消息平台与 DeepSeek、OpenAI、Gemini 等大模型接进同一个工作台，社区插件超过一千个。本目录围绕「上手之前」的高频疑问整理了几篇文章，供检索到场的朋友按需阅读。

功能全貌与手机端安装入口见 [AstrBot 介绍站](https://astrbot.fewf.click/)；目录下的文章按主题展开。
