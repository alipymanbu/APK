# 电脑部署和手机App怎么选

同一个框架，两条路线：手机 App 是「装上就能跑」的社区封装，电脑/服务器部署是能力最全的原版。这篇把差异列清楚，帮你按实际用途选。

## 一张表看懂差异

| 维度 | 手机 App（社区封装） | 电脑 / 服务器部署（原版框架） |
| --- | --- | --- |
| 部署门槛 | 装 APK，全自动初始化 | 装 Python 3.12+ 或 Docker，按项目文档操作 |
| 命令行 | 完全不需要 | 多数方式需要一点 |
| 消息平台 | 仅 QQ 个人账号 | QQ、企业微信、飞书、钉钉、公众号、Telegram、Slack、Discord 等 |
| 代码沙箱 | 默认不可用 | 支持（Agent Sandbox，依赖 Docker） |
| 插件 / 人设 / 知识库 | 支持 | 支持，功能最全 |
| 挂机方式 | 跟着手机走，需保活设置 | 服务器上可长期不间断 |

## 两条路线的来历

框架原版由 AstrBotDevs 开源维护（AGPL-3.0 许可证），文档在 `https://docs.astrbot.app/`，提供 uv 一键部署、Docker、桌面 App、启动器等多种安装方式，改动框架用于商业网络服务需按许可证开源修改部分。

手机 App 是社区开发者把框架核心、NapCatQQ 适配器和 Ubuntu 容器环境打成的单一 APK（BSD-3-Clause 许可证），被收录进框架文档的「社区提供的部署方式」一节——收录不等于背书，出问题时别去找框架本体的锅。App 面板里的模型提供商、插件、人设这些概念与原版完全一致，以后想迁移到服务器，配置思路是相通的。

## 怎么选

- **选手机 App**：手机就是全部家当；只想让一个 QQ 号变智能；不想学命令行；能接受偶发问题时重启或清数据重来。
- **选服务器**：机器人要服务一个群或团队；要接微信生态、Telegram 等多平台；需要代码沙箱这类完整能力；打算长期不关机。

## 两条路不冲突

常见路径是先用手机版把玩法摸熟——模型怎么接、人设怎么调、插件装哪些——等需求长出来了再迁到服务器。想先看手机端长什么样，[AstrBot 介绍站](https://astrbot.fewf.click/)有能力清单与安装入口；动手顺序见[手机部署QQ机器人步骤](手机部署QQ机器人步骤.md)，能接什么模型见[支持哪些大模型与插件](支持哪些大模型与插件.md)。
