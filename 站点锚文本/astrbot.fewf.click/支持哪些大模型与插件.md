# 支持哪些大模型与插件

接哪个模型、装什么插件，决定了机器人到手后的实际能力。这篇把 AstrBot 的模型接入范围和插件生态摊开说，顺带讲清手机 App 上的能力边界。

## 模型：走「提供商」机制，随接随换

AstrBot 用统一的提供商（Provider）页面管理模型服务，填一个 API Key、选一个默认模型就能跑，换模型不用动机器人本体：

| 手头的情况 | 可选的接法 |
| --- | --- |
| 国产大模型 | DeepSeek、智谱 GLM、Kimi、MiniMax 等，多走 OpenAI 兼容接口 |
| 国外大平台 | OpenAI（GPT 系列）、Anthropic Claude、Google Gemini 原生接口 |
| 不想花 API 钱 | Ollama、LM Studio 里跑开源模型，填本机或局域网地址即可 |
| 已有智能体应用 | Dify、阿里云百炼、Coze 可直接接入 |

各家模型的价格、免费额度与可用性随时会变，接入前以对应平台当时的页面为准。Key 的申请入口都在各平台的开放平台页，DeepSeek、智谱这类门槛较低，适合先用起来。

## 插件：一千多个，一键装卸

插件在管理面板的插件页安装，装完即生效。常见的方向：

- **信息获取**：翻译、网页搜索，让机器人能查实时消息；
- **人格增强**：长期记忆、人设（persona）类，对话更像一个固定的角色；
- **群务与娱乐**：签到、群管理、互动娱乐，群里用得最多；
- **多模态**：绘图、语音合成、摘要总结；
- **外部系统**：MCP 与自定义工具，把别的服务接进对话。

完整插件市场可以在浏览器打开 `https://plugins.astrbot.app/` 浏览，装之前看一眼插件页的说明与依赖。

## 框架能力和手机 App 能力是两回事

上面这些属于框架层面的能力，但手机 App 做了聚焦：

- 只支持 QQ 个人账号（第三方协议接入），微信、Telegram 等平台接不了；
- 代码执行器（沙箱）默认不可用——它依赖 Docker 环境，安卓容器里没装；
- 插件、人设、知识库这些不依赖特殊环境的能力可正常用。

一句话：只想要 QQ 上一个会聊天的机器人，手机 App 够用；要接多平台、跑沙箱，得走电脑或服务器部署，两条路线的取舍见[电脑部署和手机App怎么选](电脑部署和手机App怎么选.md)。
