# 3DM论坛签到与金元：每天几分钟的攒法

> 论坛老用户每天进社区做的几件事：签到、攒金元、领手游礼包。规则不难，贵在坚持。
> **相关文档**：[安卓版下载安装步骤.md](安卓版下载安装步骤.md) · [Steam战绩绑定与游戏库用法.md](Steam战绩绑定与游戏库用法.md)

## 金元是什么

金元是 3DM 论坛的站内虚拟货币，只在论坛体系里流通：换道具、买勋章、解锁特殊用户组。它不对应真实货币，攒它纯粹是社区里的身份与乐趣。

## 每日签到怎么操作

论坛设有每日签到帖，登录后进签到帖、按当天的要求跟帖即算签到。手机上直接从 App 的论坛版块进去就行，不用切到网页端。断了也没关系，部分活动期有补签机会，多留意论坛公告。

## 金元能换什么

论坛历史公告里列过的兑换方向：

| 项目 | 作用 |
| --- | --- |
| 变色卡 | 自己的帖子高亮 72 小时（800 金元一张） |
| 提升卡 | 帖子提升一次（300 金元一张） |
| 持续提升卡 | 帖子持续提升 1 小时（1200 金元一张） |
| 勋章 / 特殊用户组 | 装扮与身份 |

攒法没有捷径：发帖、回帖、发布资源、参加活动，围绕活跃度的正向行为都算数。价格与项目可能调整，以论坛当前公告为准。

## 手游礼包别错过

3DM 手游板块挂着各家游戏的礼包入口，领到的是兑换码或激活码——注意**码不是输进这个 App**，而是进对应游戏的设置页，找到「礼包兑换」入口原样粘贴，奖励一般发到游戏内邮箱。领的时候看一眼时效，过期作废、每账号通常限一次。
