# 开源漫画阅读器怎么选：空壳设计值不值得折腾

在开源漫画阅读器这个类目里，候选不少：Komikku、JHenTai、Mangayomi、Yomikiru……各家的取舍不同。这篇不打算做成功能清单，只回答一个实际问题：**「空壳 + 脚本源」这种设计，适合什么样的读者。**

## 什么是空壳设计

Venera 用 Flutter 与 Dart 写成，GPL-3.0 许可，同一套代码覆盖 Android、iOS、Windows、macOS、Linux 五个平台。它最特别的决定是：软件本体不内置任何漫画内容，也不预置任何站点。网络内容靠导入 JavaScript 脚本源，本地内容靠自己导入文件。

这有点像一本装帧考究的活页夹：夹子本身一页纸都没有，写什么、插什么全由主人决定。

## 这种设计的好处

- **干净**：没有预装内容就没有冗余推送，公开评测对它的共识是没广告、没内购、没弹窗。
- **可扩展**：新站点不用等版本更新，写个脚本、导入即用；社区维护的源配置也在持续更新。
- **跨端一致**：五端同一套代码，手机上开始的书，桌面上接着看，收藏与进度跟着走。
- **代码可审计**：GPL-3.0 开源，介意隐私的人能自己看每一行在做什么。

## 它不适合谁

想装完就什么都能看的人会觉得麻烦——它要求你至少导入一次本地文件或脚本源，才有一点东西看。愿意花十分钟理解机制的人，换来的却是完全按自己意愿组织的书架。

## 和同类工具比，它的位置

Komikku 这类应用偏重「订阅追更」，对单一生态的用户很顺手；Mangayomi 把漫画与动漫、轻小说合在一个应用里，功能面更宽。Venera 的差异化在于**把「内容自己装」贯彻到底**，加上五端通吃和低占用（安卓安装包约 44 MB），在多设备读者群体里口碑一直不错。

如果你已经动心，可以先到 [Venera 介绍站](https://venera.rggd.pw/)看看真机截图与版本信息，再决定要不要装；装好之后的漫画源导入方法，同目录的[漫画源导入步骤详解](漫画源导入步骤详解.md)写得更细。
