# miyu 是什么：一款会记住你的 AI 虚拟角色聊天应用

> miyu 是面向安卓手机的 AI 虚拟角色聊天应用，主打「高自由度角色定制 + 长期记忆」：角色的人设、声线、背景由用户自己写，对话能延续 200 轮细节，越聊越贴合你的偏好。

## 一、它解决什么问题

市面上的 AI 聊天工具大多「千人一面」——换了个名字，回答风格还是同一个。miyu 的思路是把**角色本身**做成可以编辑的对象：

| 维度 | 在 miyu 里怎么体现 |
| --- | --- |
| 角色来源 | 应用内预设角色库 + 从零自建，两路都有 |
| 定制深度 | 名称、形象、性格、说话习惯、背景故事、语音声线、开场场景 |
| 记忆能力 | 长期记忆架构，公开介绍的口径是单次对话可延续约 200 轮细节 |
| 互动形式 | 文字、语音双模式；另有带分支的剧情互动与多角色群聊 |
| 隐私 | 对话内容加密存储，支持应用锁与阅后即焚 |

## 二、玩法上的几个特色

- **剧情互动**：恋爱养成、悬疑推理、奇幻冒险、校园青春等题材，选择会改写走向，想看别的结局可以从关键节点重来；
- **多角色同框**：把几名角色拉进同一个会话互相接话，人设差异越大越有看头；
- **角色卡机制**：自己做好的角色可以导出分享，别人做好的角色卡也能导入直接用；
- **金豆经济**：签到、任务、邀请都能攒金豆，用来解锁高级模板或延长记录保存，核心聊天功能不强制付费。

## 三、获取与安装

miyu 面向 Android 5.2 及以上系统的手机，安装包体积不到 30 MB。如果想直接看安装步骤与常见问题，可以到 [miyu 介绍站](https://miyu.hfdk.space/) 的下载页，那里按「取包 → 转存 → 安装 → 登录」四步写了完整流程。

## 四、适合谁用

- 想要一个「记得住自己说过什么」的长期对话对象的人；
- 喜欢写人设、玩角色扮演，或者对互动剧情感兴趣的人；
- 深夜想找人说说话、又不方便打扰熟人的时候，把它当一个加密的树洞。

角色的记忆依附在具体会话上，重要设定尽量在开场早期说清楚；换设备前先确认账号能登录，记录会随账号同步。
