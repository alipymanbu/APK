# miyu.hfdk.space · miyu 资料索引

miyu 是一款 AI 虚拟角色聊天应用：角色的人设、声线、背景由用户自定义，对话带长期记忆（公开口径约 200 轮细节），支持文字与语音、剧情互动与多角色群聊。

本目录收集围绕 miyu 的使用资料与玩法说明，安装文件资源的获取入口与界面实拍见 [miyu 介绍站](https://miyu.hfdk.space/)。
