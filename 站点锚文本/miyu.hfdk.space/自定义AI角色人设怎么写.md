# 自定义 AI 角色人设怎么写：从空壳到「活人」的填法

> 自建 AI 角色最怕「千人一面」：性格前后跳变、说话没有辨识度。这里以 miyu 的角色定制为例，把人设一项一项拆开讲怎么填，以及导入别人角色卡时要注意什么。
> **本目录更多内容**：[miyu是什么.md](miyu是什么.md) · [AI虚拟角色聊天新手入门.md](AI虚拟角色聊天新手入门.md)

## 一、先想清楚：这个角色「一句话立得住」吗

动笔前先写一句概括，比如「嘴硬心软的狐仙大人」「沉稳可靠的职场导师」。这句话立不住，后面的细节只会越填越乱。miyu 的创建入口在角色页的加号，起名确认后进入详细设定页。

## 二、逐项填设定的参照表

| 设定项 | 写什么 | 写不好的后果 |
| --- | --- | --- |
| 角色名称 | 好认、好搜索的名字 | 名字太泛，角色多了找不到 |
| 形象 / 头像 | 与气质一致的外观 | 群聊时辨识度低 |
| 性格 | 温柔、毒舌、傲娇、沉稳等基调 | 前后性格跳变，像换了个角色 |
| 说话习惯 | 口头禅、句长、语气词 | 千人一面，没有辨识度 |
| 背景故事 | 身世、职业、与你的关系 | 剧情缺铺垫，聊起来空 |
| 语音声线 | 与性格匹配的音色 | 声音与人设违和 |
| 场景 / 开场 | 初次见面的环境 | 开场生硬，要自己找话题 |

新手不必一次写满：先给「名称 + 性格 + 一句背景」，聊几轮觉得哪里不对再回来补。miyu 里部分高级模板与素材会消耗金豆，基础创建不收费。

## 三、让角色不「崩人设」的四个习惯

1. **设定自洽**：性格、背景、说话习惯三者别互相矛盾；
2. **开场立规矩**：把称呼、关系、它的态度写进设定，比聊到一半再纠正有效得多；
3. **别用现有会话做实验**：想试不同剧情就另建会话——记忆依附在会话上，同会话反复改设定只会把上下文弄乱；
4. **群聊控制在 2~4 人**：同屏角色越多越容易互相带跑人设。

## 四、角色卡：导入与分享

miyu 支持角色卡机制，别人分享出来的卡可以直接导入使用：

- **导入**：在创建角色页面找「导入角色卡」入口，粘贴或选择卡内容确认即可；卡里没写到的项会留空，自己补上属于正常现象；
- **导出**：进入角色详情页，用「分享 / 导出角色卡」生成内容发给朋友；
- **注意**：导入的卡人设质量参差，用前先看一眼；分享前确认人设里没有夹带真实姓名、电话这类隐私信息。

## 五、改了设定为什么不生效

已存在的会话沿用旧上下文，新设定通常只对**新会话**生效——这是最常见的一类误解。想让人设改动整体生效，最稳的做法是另开新会话从开场重新走一遍。想先体验再决定装不装，可以到 [miyu 介绍站](https://miyu.hfdk.space/) 看界面实拍与功能说明。
