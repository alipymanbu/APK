# 二次元站点导航聚合

想看番、追漫画、查资料，手上却没有一个现成的站点清单？本篇聊聊 anifun 把 ACGN 站点入口聚合到一个应用里的思路，以及日常怎么用最省事。功能概览与安装文件资源的获取入口见 [anifun 介绍站](https://anifun.fedq.ren/)。

## 一、聚合导航解决什么问题

二次元内容散落在视频平台、漫画平台、轻小说站与资料站里，各记一个网址既麻烦又容易忘。anifun 的导航板块把各类站点按「热门网站」「动画网站」「漫画网站」「小说站点」分组列好，点条目直接跳转，不用记网址也不用翻收藏夹。

## 二、先读简介，再决定点不点

不少条目下面带一句话简介，说明平台的定位与侧重——想看正版连载就挑简介里带「正版」字样的平台，想找特定题材就按简介判断。点开之前扫一眼，省掉进错站再退出来的功夫。

## 三、几个容易被忽略的工具入口

导航里除了内容站点，还混着几个工具类条目，找番之外照样用得上：

| 条目 | 用途 |
| --- | --- |
| 以图搜番 | 拿一张截图反查出自哪部作品 |
| 动画巡礼 | 圣地巡礼地图，查作品取景地 |
| 社区资料站 | 看路人评分与词条，再决定入不入坑 |

## 四、把高频入口固定下来

每天都要开的几个站点，收进个人导航页里，打开板块第一眼就是自己的常用入口。个别条目偶有访问波动，打不开就换分组里的同类备选——同类站点一般不止一个。
