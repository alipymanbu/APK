# 动漫百科与角色关系图

补老番、追群像剧，最怕记不住人、理不清线。本篇讲 anifun 的动漫百科词条与角色关系图各能查到什么、什么场景下用最顺手。功能概览与安装文件资源的获取入口见 [anifun 介绍站](https://anifun.fedq.ren/)。

## 一、词条：作品与人物两层资料

作品词条内部按小节组织——介绍、角色、声优、制作人员、相关情报，顺着往下翻即可，不用返回重搜；人物词条则直接列出从业者参与配音的角色与相关作品，想查「这位还演过谁」就从这两块入手。

## 二、关系图：先看图再入正片

关系图把角色之间的关联画成一张图——谁是家人、谁与谁对立、哪几个同属一个团体，一眼看清。两类场景特别适合先开图：

| 场景 | 用法 |
| --- | --- |
| 群像剧、多主角作品 | 角色多且分线叙事，先记结构再看正片 |
| 中途入坑的连载 | 从关系图反推前情，比从头补效率高 |

图里点到的角色可以跳回百科词条继续查详情，两步就能把一个陌生角色弄明白。

## 三、检索技巧

- **按作品名搜**：中文名、日文原名都能试；
- **按角色名搜**：记得住角色记不住作品时反着查，从角色词条跳回作品词条；
- **按声优名搜**：从人物词条的「相关作品」顺藤摸瓜；
- **拿不准全名**：先输关键词，再顺着结果里的词条互相跳。
