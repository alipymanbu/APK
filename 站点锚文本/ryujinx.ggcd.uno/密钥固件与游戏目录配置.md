# 密钥固件与游戏目录配置

> 本篇按 ryujinx 安卓版设置页的「程序 / 系统 / 图形 / 输入」四个分组，逐一说明每个开关管什么、什么情况下需要动它。前置的安装流程见[安卓版下载安装与首次配置](安卓版下载安装与首次配置.md)，出画面之后的故障处理见[黑屏闪退与性能设置排查](黑屏闪退与性能设置排查.md)。

---

ryujinx 安卓版把全部配置收进设置页的五个分组（程序、系统、图形、输入、日志），日常用到的集中在前四个。理解每个分组的分工，比到处抄「最佳设置」更靠谱——不同机型上同一开关的表现可能完全相反。

## 程序分组：三件套都在这里

这是首次配置的主战场：

- **导入 prod.keys**：选中放在手机存储里的密钥文件。密钥需从自己拥有的主机提取，模拟器本体不提供。
- **安装系统固件**：直接选中固件的 zip 包即可，应用会自行处理，**不需要解压**——解压再装反而容易失败。
- **选择目录**：指向存放游戏文件的文件夹，支持 NSP / XCI 格式。选完回列表页刷新即可看到游戏。
- **网格视图**：控制游戏列表用封面网格还是纯列表展示，纯外观选项。

## 系统分组：闪退时先动这里

- **使用 NCE**：原生代码执行，性能收益明显；但少数处理器不支持，是「一打开就闪退」的头号嫌疑，关掉后以兼容模式运行。
- **启用主机映射**：内存布局按主机方式映射，个别游戏必需，一般保持开启。
- **启用垂直同步**：消除画面撕裂；性能吃紧的机型可关掉减负。
- **启用缓存编译**：把编译结果缓存下来，二次进游戏加载明显更快，建议常开。

## 图形分组：画质与流畅的取舍

- **启用着色器缓存**：减少游戏中的卡顿，建议开启。
- **分辨率缩放比例**：默认 1.0x，高端机型可以往上探一档提升清晰度；掉帧就退回来。
- **启用纹理重新压缩**：省显存，画质敏感的游戏权衡后再开。
- **驱动**：图形后端相关的设置入口，没有明确需求时不动它。

## 输入分组：触屏与手柄两条路

- **显示虚拟按键**：纯触屏玩家的基本盘，屏幕上叠加按键布局。
- **启用重力感应**：用手机姿态替代体感操作，体感类游戏必备。
- **使用 NS 控制器布局**：外接手柄时让按键映射对齐主机习惯。
- **控制器摇杆灵敏度**：按手感微调死区与响应速度。

设置分组只是工具，真正决定能不能跑起来的还是密钥、固件与游戏文件三件套是否就位；都就位了还有问题，就轮到[黑屏闪退与性能设置排查](黑屏闪退与性能设置排查.md)里的几条经验。这三篇的完整版也可以在 [ryujinx 模拟器说明站](https://ryujinx.ggcd.uno/)上对照真实设置页截图阅读。
