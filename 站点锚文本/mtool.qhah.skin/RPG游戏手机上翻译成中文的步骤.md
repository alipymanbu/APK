# RPG游戏手机上翻译成中文的步骤

> 安卓端给 RPG、视觉小说游戏做翻译，路数与电脑端不同：不靠拖拽，靠目录约定。本篇按实际顺序讲完整流程——判断引擎、放进目录、启动、翻译、离线玩——以及每一步容易卡住的地方。

## 一、动手前：确认游戏引擎认不认

工具按引擎适配游戏，先对号入座能省掉大量试错。判断方法看游戏根目录的文件长相：

| 看到什么 | 多半是 |
| --- | --- |
| `Game.rgss3a` / `Game.rgss2a` / `Game.exe` 带 `Data` 文件夹 | RPG Maker |
| `Data.xp3` | Kirikiri |
| 带 `renpy` 字样的文件夹 | Ren'Py |
| `GamePro.exe` 或类似启动程序 | Wolf RPG |

系统要求以工具页面标注为准（当前为 Android 11.0 以上）；存储空间按"游戏本体 + 翻译数据"预留，几个 GB 比较稳。

## 二、把游戏放进指定目录

1. 用文件管理器把游戏压缩包解压成**完整的游戏文件夹**（加密包先解压，只丢一个压缩包进去它认不出来）；
2. 把整个文件夹复制或移动到手机的 `/MTool/Games` 下，里面的数据文件一个都不要拆出来；
3. 找不到这个目录就先启动一次工具，它会自己建；也可以直接在文件管理器里搜 `MTool`。

## 三、启动游戏

打开工具进游戏库，刚放进去的游戏会列出来，点启动即可。两点预期要有：

- 第一次启动要加载资源，几秒到十几分钟都正常，期间别最小化、让它待在前台；
- 键盘操作会映射成屏幕上的虚拟按键，方案可以按游戏分别保存，RPG、SLG 类基本够用。

游戏报不支持或起不来，先回上面的引擎表核对；还不行就在工具内点一次更新再试，多数奇怪的问题到这一步就消失了。

## 四、翻译：两种情况

**游戏包自带汉化文件**（json 格式）：启动时自动加载，什么都不用做，直接玩。

**没有汉化文件，自己翻**：

1. 进游戏后打开右上角的设置页，点「翻译」；
2. 选源语言与目标语言——日文游戏就是日语到简中；
3. 引擎先选不设门槛的基础款（必应这类，不用订阅也能用），点「开始翻译」；
4. 它会自动识别引擎、导出文本、调用引擎处理，完成后生成汉化文件并自动加载。

文本量大的游戏这一步要等一阵。翻完之后文本固定下来，**之后玩不需要一直联网**。想还原原文、或导出文本自己修改，入口都在翻译页同一处。

## 五、翻完之后

汉化文件跟着游戏文件夹走，整个文件夹拷到别的设备，进度与汉化都在。工具内更新、版本相关的问题，与改数值前的存档保护，分别看[游戏数值修改前怎么保护存档](游戏数值修改前怎么保护存档.md)与[外语单机游戏没有中文怎么办](外语单机游戏没有中文怎么办.md)；引擎适配与界面细节也可以直接翻[MTool 玩家介绍站](https://mtool.qhah.skin/)，按板块查得快。
