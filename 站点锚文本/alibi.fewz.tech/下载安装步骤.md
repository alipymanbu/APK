# Alibi 下载安装步骤（安卓版）

> 本篇讲安卓应用 Alibi 的安装包从哪里拿、怎么装、首次启动要给哪些权限，以及装完先做的两件事。
> **相关文档**：[行车记录仪用法与参数取舍.md](行车记录仪用法与参数取舍.md) · [后台自动停止排查.md](后台自动停止排查.md)

## 一、Alibi 是什么应用

Alibi 是一款开源（GPL-3.0 许可证）的安卓后台录制应用，思路来自行车记录仪：它在后台持续录制音频或视频，却只保留最近一段（默认 30 分钟），旧内容自动覆盖、不占存储；等你需要证据时点一下保存，最近那段才导出成普通文件。全程不需要联网，也没有广告与内购。

详细的界面截图与功能清单，可以看这篇 [Alibi 功能与界面介绍](https://alibi.fewz.tech/)，安装文件资源的获取入口也在那里。

## 二、安装前知道三件事

| 事项 | 说明 |
| --- | --- |
| 安装包形态 | APK 文件，通过网盘分享页转存后下载到手机 |
| 版本差异 | 网上资料多以最新版为准，你拿到的可能是发布当时的版本，覆盖安装即可升级 |
| 系统要求 | Android 7.0 及以上，不需要 root |

## 三、安装步骤

1. **拿到安装包**：从介绍站的获取入口进入网盘分享页，把安装包转存到自己的网盘账号，再下载到手机存储。
2. **允许安装未知来源应用**：首次用文件管理器打开 APK 会提示"禁止安装"，按弹窗指引允许该文件管理器安装应用；部分品牌在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里开。
3. **点安装**：回到安装界面点安装，等进度走完，先不急着打开。
4. **逐项授权**：首次启动开始录制时会依次申请权限——麦克风（录音必需）、相机（录像用，只录音可不发）、通知（后台常驻必需）、文件读写（保存导出用）。当行车记录仪用就全部允许。
5. **放行后台**：把电池策略改成「不受限制」，具体原因与各家系统的入口见[后台自动停止排查.md](后台自动停止排查.md)。

## 四、装完先做两件事

1. **试录验证**：录两三分钟，锁屏、切应用各试一遍，点保存确认能导出、能用播放器打开。这一步能提前暴露大部分设置问题。
2. **设好保存目录**：到设置里把保存位置改成一个好找的本地文件夹，别等出事了才找文件。

## 五、装好之后

第一次正式录制怎么开、各设置项的作用，见[行车记录仪用法与参数取舍.md](行车记录仪用法与参数取舍.md)；录制中途被系统停掉一类的问题，见[后台自动停止排查.md](后台自动停止排查.md)。
