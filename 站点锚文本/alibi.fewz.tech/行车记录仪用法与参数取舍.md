# Alibi 行车记录仪用法与参数取舍

> 把手机当行车记录仪用：从开始录制到保存导出的完整流程，以及保留时长、存储、供电这些参数怎么取舍。
> **相关文档**：[下载安装步骤.md](下载安装步骤.md) · [后台自动停止排查.md](后台自动停止排查.md)

## 一、核心用法一句话

Alibi 的思路是「一直在录，只留最近一段」：开始录制后它在后台持续工作，超过设定时长的旧内容自动被覆盖；需要证据时点保存，最近那段才导出成文件。默认保留最近 30 分钟，时长可改。

装好应用、给足权限是前提，步骤见[下载安装步骤.md](下载安装步骤.md)。

## 二、一次完整的使用流程

1. **开始录制**：打开应用，选音频或视频（视频 0.4.0 版起支持），点开始；状态栏会挂一条常驻通知，这是安卓对前台服务的硬性要求，关掉它录制就停了。
2. **切出去正常用手机**：录制在后台继续，通知栏能看到它还在跑。录制中还能暂停/继续（0.2.0 起）、长按保存键「保存并继续录」（0.5.0 起）、双指捏合调麦克风灵敏度（0.5.0 起）。
3. **出事当下点保存**：最近一段合并导出成普通视频/音频文件，写到设置的保存目录里。保存是手动的——不点它，旧内容会一直被滚动覆盖。

想先看看界面长什么样再决定装不装，可以逛逛这个 [Alibi 介绍站](https://alibi.fewz.tech/)，两页加起来几分钟就能翻完。

## 三、参数怎么取舍

| 事项 | 建议 |
| --- | --- |
| 保留时长 | 默认 30 分钟通常够覆盖一场事故前后；调大时长，暂存占用与发热都会跟着涨 |
| 存储预留 | 暂存占用随画质与时长变化，先用一两天观察实际占用，再决定预留多少 |
| 录音还是录像 | 当记录仪用开视频；只想要声音凭证就单开录音，省电也省空间 |
| 车内录音 | 麦克风会把车内对话一并录进去，涉及同行者时注意合规与告知 |
| 蓝牙干扰 | 连着车机或蓝牙耳机时，录音输入可能被蓝牙麦克风接管，试录一段确认录到的是车内声音 |

## 四、车内布置的几个要点

- **供电**：持续调用相机与麦克风是高耗电操作，全程接车充，别指望电池撑完全程；部分车机 USB 口电流偏小，会出现「越录电越少」，换个功率足的车充头。
- **机位**：支架固定牢、不挡视线；夏天暴晒加持续录制机身温度很高，系统在高温下可能限制摄像头导致录制中断，机位尽量选空调出风能吹到的位置。
- **防翻看**：停车后不想被别人翻录制记录，开应用锁（0.4.0 起支持指纹/生物识别）。

## 五、两个能力边界，先知道

- **开机不会自动开始录制**：上车后要手动点一次录制，之后靠「录满自动覆盖」挂着。
- **画面没有时间水印**：录像里不叠加时间戳，时间以导出文件的属性为准，重要场合保存后先核对文件时间。

## 六、出问题去哪查

录制切后台就停、通知消失这类故障，按可能性从高到低的排查顺序整理在[后台自动停止排查.md](后台自动停止排查.md)，装好后的第一件事就是先把电池优化放行。
