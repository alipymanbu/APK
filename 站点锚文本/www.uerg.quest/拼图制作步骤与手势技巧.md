# Layout 拼图制作步骤与手势技巧

> 本篇按实际操作顺序整理 Layout 的拼图流程：怎么选照片、挑版式、用手势调整每一格，最后保存或分享。
> **相关文章**：[下架后怎么装回安卓手机.md](下架后怎么装回安卓手机.md) · [快拍拼图和独立应用怎么选.md](快拍拼图和独立应用怎么选.md)

## 一、选照片

打开应用点「开始」就是选图区，一次最多选 **9 张**，入口有三个：

- **普通网格**：直接点选相册里的照片，点一张亮一张，选错再点一下取消；
- **Faces 标签**：只显示带人脸的照片，拼合影、聚会照时找图最快；
- **Photo Booth（连拍）**：倒计时自动连拍 4 张，适合当场拍一组连续动作，拍完直接套版式。

「最近」一栏列出最近 30 张照片，拼当天拍的图时最顺手。选图的同时，屏幕上方会按**已选张数**给出可选版式——选得越多，能挑的组合越少，这是正常逻辑。

## 二、挑版式

版式按格数分，两格到九格都有：横向分割、纵向分割、九宫格等。来回点版式栏，中间预览区实时换排布；换整套版式不用重新选图，已放进格子的照片会自动重排。

几个常见搭配：

| 格数 | 适合的画面 |
| --- | --- |
| 2 格横向 | 前后对比、左右呼应 |
| 3 格竖条 | 全景横片切三段、连拍动作 |
| 4 格（2×2） | 四宫格合集：一天四景、四套穿搭 |
| 6~9 格 | 大合照式汇总：一周记录、同主题批量图 |

## 三、用手势调每一格

进了编辑界面，任何一格都能直接动手：

- **点按**某张照片 → 左右镜像翻转；
- **长按拖动** → 与其他格子的照片换位置；
- **双指捏合或张开** → 调整这张照片在格子里的取景范围；
- **REPLACE（替换）** → 这一格换成别的照片；
- **FLIP（翻转）** → 上下颠倒。

相邻照片之间的蓝色分隔条可以拖动——想让某张照片占的面积大一点，就朝另一侧拖分割线。所有操作都在预览图上完成，不用进菜单翻找；按钮名称与位置随版本略有差异，以手机上显示的为准。

## 四、保存与分享

1. 调整完点右上角**保存**，成图进手机相册；
2. 保存成功会弹出分享面板，可以直接发到 Instagram、Facebook 或系统里任何能发图的应用；
3. 想加滤镜或文字：保存后去其他修图应用里打开这张成图——独立版本身不做滤镜，它只负责「把几张图排进一张图」。
