# 听电台太费流量怎么办

网络电台是持续流媒体——听多久传多久，出门用移动数据听很容易把套餐跑掉一大块。这篇按码率给出具体数字，再把几个省流量的开关一次说清（以 Tunein 为例，同类应用思路通用）。

## 一、先算清楚账

电台消耗由码率决定，和听的内容长短成正比：

| 码率档 | 每小时大约消耗 |
| --- | --- |
| 32 kbps（基本） | 约 14 MB |
| 64 kbps | 约 28 MB |
| 128 kbps（标准） | 约 57~60 MB |
| 320 kbps（高） | 100 MB 以上 |

粗略记法：常听的台按「每小时几十 MB 到 150 MB」做预算。通勤一小时、睡前一小时，一天就是一两百 MB 的量级。

## 二、三个开关把消耗压下来

1. **换低码率流**：在正在播放页的菜单里找「选择流」，这个台提供哪些码率就列哪些，选最低一档，声音糙一点但流量直接砍半以上。全局默认在 设置 → 高级设置 →「首选流质量」里改。
2. **关掉蜂窝数据**：设置里把「蜂窝数据」开关关掉，应用就只在 Wi-Fi 下播放，从根上杜绝后台偷跑。
3. **播客离线听**：电台直播没法离线，但播客可以——在 Wi-Fi 环境下让应用自动下载收藏节目的新单集，通勤路上直接放本地文件，零流量。

## 三、两个容易漏掉的耗流场景

- **后台没真正停**：听完了只是切走、播放条还在走，流量就一直传。放下手机前确认播放已经停了。
- **睡前忘了定时**：整夜挂着一台广播，天亮才发现套餐见底。设个睡眠定时到点自动停，方法见 [睡觉时听电台自动停的方法](睡觉时听电台自动停的方法.md)。

## 四、按码率算完再决定怎么听

不同电台提供的码率不同：有的台只有低码率流，选再高也上不去；有的默认给高码率。想看更多码率对照与设置入口的截图，可以去 [Tunein 收听站](https://tunein.xnyx.quest/)的收听技巧部分。连着 Wi-Fi 时这些都不用管——Wi-Fi 不计入手机套餐，放心听。
