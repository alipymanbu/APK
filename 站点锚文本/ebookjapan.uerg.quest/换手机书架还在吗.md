# ebookjapan 换手机后书架还在吗

> 本篇回答换机或卸载重装之后，ebookjapan 里买过的漫画还能不能找回来：书架恢复的步骤、设备数量上限、离线数据的边界。

先说结论：书不会丢。ebookjapan 的购买记录存在云端、挂在 Yahoo! JAPAN ID 下，换手机（包括安卓换苹果）之后用同一个 ID 登录，书架整个恢复，已购作品重新下载即可，不额外收费。硬币余额这类账户资产同样跟账号走。

## 一、新设备上的恢复步骤

1. 在新设备上装好应用（途径与核对项见 [安卓安装步骤.md](安卓安装步骤.md)）。
2. 用**当初购书的那个** Yahoo! JAPAN ID 登录——有多个 Yahoo 账号时最容易串号，书是跟着 ID 走的。
3. 登录后书架自动同步，购买记录出现在「本棚」里；怀疑缺书时到「購入済み」视图下拉刷新一次，再和网页版对比定位。
4. 把要离线看的作品重新勾选下载，完成后断网也能读。

## 二、两个容易误会的点

- **设备数量上限 6 台**：满 6 台再登新设备会失败，到「マイページ」→「端末登録」里删掉不再用的旧设备再登记。换机频繁的话，换完顺手删旧机。
- **离线数据不迁移**：已经下载到旧设备的离线内容只存在本地，卸载应用就一并清掉；书本身在账号里，新设备重新下载即可。所以换机前旧设备没有任何必须做的步骤，稳妥做法是先在新设备确认书架完整，再清理旧机。

## 三、删账号才是真正的销号

卸载应用不丢书；但删除 Yahoo! JAPAN ID 会让名下已购内容随账号一起失效，动手前把想看的书看完，具体以 Yahoo! JAPAN ID 侧说明为准。
