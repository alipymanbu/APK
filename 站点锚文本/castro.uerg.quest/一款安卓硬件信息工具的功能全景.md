# 一款安卓硬件信息工具的功能全景

> 本篇把 Castro 的界面结构、仪表盘读法与工具箱逐块讲清，帮你在动手验机之前先知道每个页面负责什么。

## 一、它解决什么问题

安卓系统把硬件信息拆得极散：CPU 频率藏在开发者选项、电池状态在设置深处、传感器干脆不给图形化展示。Castro（系统信息类工具，个人开发者作品）把这些数字收拢到一个应用里——打开就是仪表盘，往里翻是按硬件分类的信息页，再往里还有屏幕测试、报告导出这类随手能用的小工具。想先看看它的界面长什么样、或者准备装一个备用，可以移步 [Castro 安卓硬件信息站](https://castro.uerg.quest/)。

## 二、三块界面，各管一段

**仪表盘（Dashboard）**：第一屏就是结论。CPU 各核心频率、电池温度与状态、网络实时收发、内存占用四张卡片同屏实时刷新；切出去再回来，数值已经换了一轮。

**信息页（Information）**：往下一层按硬件分门别类——处理器（含 GPU 型号与活跃状态）、电池（温度、电压、健康度，支持的机型给循环次数）、内存与存储、网络与 Wi-Fi 安全类型、传感器实时曲线、摄像头参数（光圈、光学防抖）、编解码器完整列表、蓝牙与 DRM。信息项太多时用搜索页直接输关键词更快，而且搜索页不依赖权限也能出结果。

**工具页（Tools）**：屏幕测试（纯色查坏点、触摸坐标确认触控）、数据报告导出（整份参数生成文件走系统分享）、Root 分析器（逐项检查 Root 状态）、噪音检测。

## 三、两个版本怎么分

商店里同时存在 Castro 与 Castro Premium，是**两个独立应用**（后者包名以 `.pro` 结尾），不是应用内解锁的关系。Premium 多出深度主题自定义、桌面小部件、通知栏网速监控与电池指示器、CPU 占用监控、PDF 报告导出。日常看参数、做验机，基础能力已经覆盖；要不要为 PDF 导出这类便利多装一个，看个人习惯。

## 四、上手建议

装好后先别急着翻深层页面，在仪表盘放一两分钟，看看频率会不会随使用升降、电池温度是否平稳——对一台机器的"正常水位"有了基准，之后读数才有参照。具体的验机顺序与每一步的判据，接着读 [二手手机验机流程与判据.md](二手手机验机流程与判据.md)；哪些数值天生就可能不准，见 [硬件读数常见疑问与误差场景.md](硬件读数常见疑问与误差场景.md)。
