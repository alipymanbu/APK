# 二手手机验机怎么查真实配置

> 买二手机、翻新机时，别只看「关于手机」里的文案——那里想写成什么就写成什么。真正改不了的是硬件本身报出来的数据。

---

买二手机最怕的不是旧，是假：低端芯片冒充旗舰、扩容盘冒充大存储、翻新机当未拆修卖。系统里的型号与参数可以随便改，但处理器、内存、存储这些硬件向应用上报的原始读数改不了——所以验机的正确姿势，是装一个硬件信息工具，拿硬件一侧的说法和卖家的宣传逐项对照。[DevCheck](https://devcheck.fewa.skin/) 就是干这件事的工具，安卓手机装上就能用。

## 一、逐项对照这六处

装好后按这张表跑一遍，大部分猫腻当场现形：

| 检查项 | 在哪看 | 什么情况要警惕 |
| --- | --- | --- |
| SoC / GPU 型号 | 硬件页 | 与宣传的芯片对不上，或标旗舰却是低端芯片 |
| 核心数与大小核配置 | 硬件页 | 数量、架构与该芯片应有的规格不符 |
| 内存容量 | 硬件页 | 明显小于宣传值 |
| 存储容量 | 硬件页 | 与宣传差一档（扩容盘常见） |
| Android 版本与安全补丁 | 系统页 | 落后于宣传、补丁日期异常久远 |
| root / 解锁状态 | 系统页 | 与卖家描述不符 |

存储那一行先扣掉两笔正常损耗再下结论：厂商标「128G」按 1G=1000MB 算，系统按 1G=1024MB 显示，光换算就少一截；系统与预装应用还要占掉十几 G。标 128G 实际可用 110G 上下属于正常，差得多（比如只剩八九十 G 以下还对不上系统占用）才按扩容盘怀疑。

## 二、两处容易误判的地方

**相机数量对不上不一定有问题。** 手机给应用暴露的不总是「一颗镜头一条」，多摄常被合并成一个「逻辑相机」上报；宣传像素也往往不是上报给应用的那个值。所以摄像头数量、像素比宣传少，先别急着下结论——真正硬的指标是上面表格里的 SoC、内存、存储那几项。

**型号名偶尔也会认错。** 营销名不写在硬件里，是从标识符匹配出来的，同一颗芯片可能有马甲版、特供版，固件上报错标识时也会带偏。看到可疑的名字以硬件实际数据为准，名字错了不等于机器是假的。

## 三、顺手再测两样

- **电池侧**：循环次数和健康度反映使用强度，二手机尤其该看——不过很多机型对普通应用隐藏这些字段，怎么读出来见[手机电池健康度和循环次数在哪里看](手机电池健康度和循环次数在哪里看.md)。
- **密封性**：拆修过的机器防水基本归零，用气压计按压测一下曲线波动，方法见[安卓手机气密性检测方法](安卓手机气密性检测方法.md)。

两项都过了，再结合外观与价格做决定，踩坑概率就小多了。
