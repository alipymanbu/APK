# 手机电池健康度和循环次数在哪里看

> 电池用了多久、还剩几成命，藏在循环次数和健康度两个字段里——但很多手机不把它们直接给应用。
> **相关文档**：[二手手机验机怎么查真实配置](二手手机验机怎么查真实配置.md) · [安卓手机气密性检测方法](安卓手机气密性检测方法.md)

---

想知道一块电池的成色，看电量百分比没用，要看两个数：**循环次数**（充放电周期数，次数越多损耗越大）和**健康度**（当前满电容量相对出厂容量的比例）。这两个数系统设置里经常不给，需要借助硬件信息工具去读，比如 [DevCheck](https://devcheck.fewa.skin/)，免费就能看电池页的全部实时数据。

## 一、电池页里有什么

打开工具的电池页，从上到下能看到这些实时读数：

| 字段 | 含义 |
| --- | --- |
| 状态 | 充电中 / 已充满 / 放电中 |
| 电量、技术 | 当前百分比、电池化学类型 |
| 温度、健康 | 电池温度、健康状态 |
| 电压、电流、功率 | 实时电气参数，充电时看这三个 |
| 容量 | 当前可用电量的估算值 |

循环次数不在主列表里，而在电池页的设置里（点右上角齿轮进入），不同版本入口可能略有差别。

## 二、为什么你的手机什么都不显示

这是被问得最多的问题，原因基本固定：

1. **厂商对应用隐藏了这些字段**。很多手机不把循环次数、健康度开放给普通应用，工具只能显示「手机给它的」。
2. **健康度常常要充满一次才出现**。不少机型在电池充到 100% 之后，健康度才会显示出来，先充满再看。
3. **双电芯机型可能永远不给**。小米、POCO 这类双电池方案的手机，读不到准确数据时会干脆不显示容量估算——显示一个错的比不显示更糟。
4. **少数机型对任何应用都不开放**。这种情况下换哪个工具都读不到，不是工具的问题。

## 三、装 Shizuku 能解开一大半

Shizuku 是个免费开源工具，让普通应用用上系统级权限：**不用 root、不改手机**。Android 11 及以上可以用「无线调试」配对启动，或在电脑上用 adb 启动一次。它跑起来之后打开 DevCheck，多数机型就能多读出一批数据：温度、电池循环次数与健康度、估算容量、CPU 负载等。

## 四、充电电流「不对」是正常的

快充时你常会发现电流或功率远低于充电器标称值，这不是数据错了：有的机型测的是电池端而非充电端的电流，双电芯机型可能只上报其中一格，有的机型刷新很慢。这三个数用来**看趋势**（插电后电流是否上来、拔电后是否归零）比用绝对值较真更靠谱。
