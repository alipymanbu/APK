# 家人测量数据怎么分

> 一台秤全家轮流站，不先分好"这是谁的测量"，数据就会混在同一个人名下。这一篇讲 AiLink 里家人怎么建、测量前怎么切换、远方的好友怎么看结果，以及删家人为什么代价很大。
> **相关文档**：[怎么绑定蓝牙体脂秤.md](怎么绑定蓝牙体脂秤.md) · [下载安装与版本选择.md](下载安装与版本选择.md)

## 一、家人和好友是两回事

两个入口都跟"别人"有关，但用途完全不同：

| | 家人 | 好友 |
| --- | --- | --- |
| 建在哪 | 建在你自己的账号下 | 另一个独立账号，扫码或搜 ID 加来 |
| 用途 | 共用设备，数据分到各人名下 | 让对方看到你开放出来的数据 |
| 对方要装 App 吗 | 不用 | 要 |

一句话判断：**同住共用一台秤的，加成家人；不在一起住、只想给对方看结果的，用好友。**

## 二、建家人档案：两项要填对、一项不能改

入口在「我的 → 我的家人 → 添加家人」，填头像、关系、昵称、生日、性别。三个注意：

- **生日和性别是给数据换算用的**。体重、体脂一类结果要靠身高、性别、年龄这些参数换算，填错数值会跟着偏——给老人孩子建档时尤其注意生日要填真实出生日期。
- **「关系」一经填写无法修改**。它被当作这个家人在你账号下的唯一标识，填前想清楚（父亲 / 母亲 / 本人……），别随手选。
- **每个账户最多支持 20 个用户**。同住的人建议一次建齐，别用了几个月再回来补。

## 三、测量前，先把人切过去

家人建好不会自动生效：**在设备首页把人切换到对应的那位，测量结果才会存到那个人名下。**

用错人的典型表现：自己站上去称的，数据却挂到了妈妈名下，回头看曲线会看到一条突然的跳动。处理办法：切回正确的人，重新测一次。

## 四、给远方的人看结果：好友 + 数据开放

光加好友是不够的，开放数据要走三步：

1. 进自己的用户概况页，找到「隐私保护」；
2. 打开「数据开放用户」；
3. 勾选允许对方查看的家人。

三个容易踩的点：

- **只有勾中的人才会被看到**，一个都不勾，对方就什么都看不到——这不是故障；
- 主账户（你自己）默认开放；
- 你名下一个用户都没建时，你也不会出现在对方的好友列表里。

不想开放了，回同一个地方取消勾选即可，**取消不会删任何数据**。只需要把某一次的结果发给医生看，用设备首页右上角「…」里的分享更直接，不需要加好友。

## 五、删除家人：先算清这笔账

家人一旦删除，**这个家人名下的全部测量数据会一并清空，且不可恢复**。所以：

- 关系填错了想改 → 只能删了重建，历史数据一起没；
- 只是不想让对方看到 → 去取消数据开放，什么都不用删；
- 不想让某台设备再传数据 → 解绑那台设备，也不动数据。

长期记录体重、体脂的家庭，删除前先把要留的结果分享导出一份。
