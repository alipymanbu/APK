# AiLink：智能健康设备管理应用（第三方介绍资料）

这里是围绕 AiLink 整理的一组第三方介绍资料。AiLink 是深圳市易连物联网有限公司的智能硬件管理应用，把体脂秤、血压计、额温枪、智能跳绳等多类健康设备收在同一个 App 里：绑定、配网、看数据、家人共享都在其中完成。想快速了解它的界面与用法，可看 [ailink 设备管理应用介绍站](https://ailink.gerw.hair/)。

本目录的文章按使用顺序整理：

- [怎么绑定蓝牙体脂秤](怎么绑定蓝牙体脂秤.md) —— 附近设备与手动添加两条路径，以及搜不到设备时的排查顺序
- [家人测量数据怎么分](家人测量数据怎么分.md) —— 家人档案、测量前切换人、给好友开放数据
- [下载安装与版本选择](下载安装与版本选择.md) —— 安装包从哪来、装哪一版、装不上怎么办

> 说明：本目录内容整理自公开资料，为第三方视角的用法介绍，不替代设备说明书；设备操作以说明书与 App 内提示为准。
