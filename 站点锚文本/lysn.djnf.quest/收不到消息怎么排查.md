# 收不到消息怎么排查：从「是不是真收不到」查到系统层

> bubble 消息不推送、通知不响、图片语音打不开，按这篇的顺序查：先排除两种「不是故障」的情况，再从应用设置查到安卓系统层。

---

## 一、先确认是不是「真收不到」

两种情况不是故障，别白折腾：

- **没订阅**：bubble 是付费订阅制，没买某位艺人的利用券就收不到他的消息，订阅前也看不到历史消息。
- **艺人本来就不定期发**：条款明确不保证消息数量和频率；巡演、军训、休息期几天没动静属于正常。

排除这两种后，再往下查推送链路。

## 二、应用内通知设置

1. 打开应用右下角「更多(…)」，进右上角「设置」。
2. 找到「聊天通知设置」，检查三项：消息到达通知是否开启、通知栏显示内容、锁屏是否弹通知。
3. **单个聊天室静音了**：进那个聊天室点右上角「︙」，检查铃铛图标状态——很多人是被单独关了一个房间的通知。

## 三、安卓系统层：省电与后台

安卓机把应用后台杀掉，推送就断：

- **电池优化白名单**：设置 → 应用 → Lysn → 电池 → 选「无限制 / 不优化」。
- 部分机型常驻一条「Lysn 正在后台运行」的系统提示，想关掉它：设置 → 通知 → 高级 → 勾选「显示系统应用」→ 找到「Android 系统」→ 关掉「正在运行的应用」这类通知（关的是提示，不影响推送）。
- 装了省电类、清理类工具的，把 Lysn 加入它们的白名单。

改完后锁屏等几分钟，验证推送是否恢复。

## 四、图片、视频、语音打不开

| 现象 | 处理 |
| --- | --- |
| 图片/视频不显示 | 多为网络波动，切换 Wi-Fi 与流量后重进聊天室；还不出就退出重登 |
| 语音没声音 | 检查媒体音量与是否连着蓝牙耳机；仍不行重进聊天室再播 |
| 回复发不出 | 先重启应用再试；再确认是不是发满了每条 3/5 条的额度 |
| 手写体没生效 | 确认 FONT 券与 bubble 订阅是同一位艺人、商店扣款真的成功 |

## 五、换机重装后聊天还在吗

聊天记录存在服务端、不随手机走：换机或重装后登录同一账号，订阅艺人的聊天内容会重新拉下来。拉取不全或列表为空时，先检查登录的是不是原账号——邮箱拼错一个字母就是另一个新账号。

## 六、还不行

- **高峰期延迟**：新艺人开放日全平台挤，等高峰过去再试。
- **联系服务方**：邮件 help@lysn.com，或用应用内的「咨询」入口，附账号邮箱与问题截图。

应用的安装与获取见 [Lysn 使用站](https://lysn.djnf.quest/)；订阅前该弄懂的形态与规则写在 [bubble私信是什么.md](bubble私信是什么.md)，价格与渠道差异在 [bubble订阅渠道与价格.md](bubble订阅渠道与价格.md)。
