# bubble 私信是什么：一对多的真相与订阅规则

> 界面长得像和艺人一对一私聊，实际是完全不同的一种形态。这篇把它讲透：消息从哪来、为什么先收到消息的永远是艺人、付了钱能做什么不能做什么。

---

## 一、它是一种「群发的私信」

Lysn 里的 bubble，是艺人向订阅者发消息的服务。你收到的每一条，都是那位艺人发给**全部订阅者**的一条群发；聊天画面里只有你一个人，其他订阅者不出现在画面里，所以观感上像私聊。

由此推出几条关键事实：

- **先发的永远是艺人**。你无法主动开启一段对话，也收不到没订阅艺人的消息。
- **艺人看得到你的回复**，但订阅的人多，不会逐条看到，更不会逐一回复。
- **消息不保证频率**。服务条款写明消息按艺人个人安排非定期发出；巡演、军训、休息期几天没动静属于正常。

## 二、付费形态：按艺人、按月

bubble 是付费订阅制：

- 一份订阅（利用券）对应**一位艺人**、有效期一个月，到期自动续费；想收两位成员的消息就是两份钱，不按组合打包。
- 没订阅就收不到该艺人的任何消息，订阅前也看不到历史消息。
- 渠道有两种：应用内走应用商店结算，或走网页商店；两者价格与管理方式有差异，展开写在 [bubble订阅渠道与价格.md](bubble订阅渠道与价格.md)。

## 三、订阅之后你能做什么

| 能做 | 说明 |
| --- | --- |
| 收文字、照片、视频、语音 | 独家内容只在聊天室出现 |
| 回复艺人 | 每条消息限量几条（应用商店渠道 3 条、网页商店渠道 5 条） |
| 改称呼 | 注册时设的昵称是默认称呼，每间聊天室可单独改 |
| 攒纪念日 | 聊天室顶部有「在一起第 N 天」的 D-day 计数 |
| 保存内容 | 照片视频可存手机，常用消息收进 OUR BOX 集中回看 |

## 四、内容归属：红线先划清

条款写得很明确：bubble 里的文字、照片、视频、语音都是**仅限订阅者本人**的内容，截图外传、二次分发可能承担法律责任。粉丝圈自发翻译很常见，但原文截图随意扩散同样有风险。

## 五、动手之前

想清楚两点再付款：一是这是一段**单方面来信**的关系，把它当成艺人经营的一个专属频道来理解，期待就摆得正；二是退订不退已用的钱，注销账号会连带作废已购内容。

装应用这件事，[Lysn 使用站](https://lysn.djnf.quest/)里整理了安卓安装包的获取路径与完整安装步骤；订阅前想比价的看 [bubble订阅渠道与价格.md](bubble订阅渠道与价格.md)，装好后收不到消息的去 [收不到消息怎么排查.md](收不到消息怎么排查.md) 对着查。
