# 每天十几分钟怎么学：一篇课文从头走到尾

> 本篇按一次真实学习的顺序，讲 Langster 里一篇短文从挑选到复习会遇到哪些环节，适合刚装好、还不知道从哪开始的人。
> **相关文档**：[支持的语言与等级划分.md](支持的语言与等级划分.md) · [安卓版怎么下载安装.md](安卓版怎么下载安装.md)

## 一篇课文里有什么

每篇内容都是几分钟读完的真实短文——新闻时事、文化、科技、旅行这类题材，同一篇里配齐四样：

| 组成 | 能做什么 |
| --- | --- |
| 朗读音频 | 整篇连听，也能单句重复跟读 |
| 点词翻译 | 点任意单词出释义，动词还能看到变位 |
| 语法解说 | 每篇配一段针对本文的语法讲解 |
| 阅读测验 | 读完做几道理解题，检验有没有真看懂 |

应用每天还会推送新的阅读和听力任务，不用自己找内容，也不会断档。

## 一天这样走

1. 打开当天更新列表，挑一篇在自己等级内的短文，题材越熟越好——生词负担会小一截。
2. 先关掉音频默读一遍，生词逐个点开看释义，动词顺手看变位。
3. 开音频再过一遍，长句用单句重复功能听两三遍。
4. 做阅读测验，错的地方回原文找答案。
5. 把想再见的词加进单词卡，剩下的交给间隔复习提醒。

## 单词卡的用法

生词和短语可以随时收进自己的卡组，应用按间隔记忆安排复习节奏，按提醒清卡就行。卡组跟着账号走，换手机、上平板，登录同一账号都在。经验是当天词当天清，攒多了再复习会很痛苦。

## 零基础合适吗

这套内容更适合已有基础、想提升阅读和听力的人。完全零基础时，A1 的文章也会读得吃力，先配一门入门教材或发音课，再拿它当日常阅读材料会顺很多。等级怎么选，见 [支持的语言与等级划分.md](支持的语言与等级划分.md)。

更多玩法和界面细节，可以翻翻 [Langster 学习手册](https://langster.xnyx.quest/)，那里有按学习流程整理的图文介绍。
