# 支持的语言与等级划分：六种语言各按什么标尺分档

> 本篇列出 Langster 收录的语言、每个语言的等级标注方式，以及和常见考试的对应关系，帮你在开箱时选对起点。
> **相关文档**：[每天十几分钟怎么学.md](每天十几分钟怎么学.md) · [安卓版怎么下载安装.md](安卓版怎么下载安装.md)

## 语言与等级对照

| 语言 | 等级标注 |
| --- | --- |
| 英语 | A1 – B2 |
| 法语 | A1 – B2 |
| 西班牙语 | A1 – B2 |
| 德语 | A1 – B2 |
| 日语 | N5 – N2（按 JLPT） |
| 汉语 | HSK1 – HSK4 |

欧洲语言按 CEFR 欧标分档，日语跟 JLPT 走，汉语按 HSK 划档。语言清单和等级上限一直在扩充，新版应用里已出现 A1–C1 的口径和意大利语的身影，以应用内实际显示为准。

## 和考试的对应

介绍材料里点名了这些备考方向：全民英检、托业、托福、GRE、雅思、四六级（英语）；DELF、DALF、TCF（法语）；JLPT（日语）；HSK（汉语）。要注意它本身不是题库，内容是分级短文，适合当阅读和听力的日常材料，真题另找。

## 怎么挑等级

- 先试再定：同一主题在相邻两档各读一篇，生词多到影响理解的就往下降一档。
- A1/A2 句子短、词汇密度低，适合打底和查漏；B1/B2 接近原版新闻的句长和语速，适合拔高。
- 拿不准就先选低一档，读完顺了再升，等级之后随时能换。

## 内容主题

短文覆盖新闻时事、各国文化、科技、旅行、美食、娱乐、运动、科学与医疗等主题，每日更新。挑自己熟的题材读是实用技巧：熟悉领域的生词负担比陌生题材小得多。
