# 悬浮球怎么开启与设置

EasyTouch 装好之后，悬浮球并不会自己冒出来——安卓把「浮在其他应用上面」算成一项单独的权限，这项不开，一切免谈。本篇按首次启动的时间线，把权限引导、各品牌的设置路径差异、以及省电策略这三件事讲清楚。功能全貌与玩法整理，见 [EasyTouch 悬浮球站](https://easytouch.usea.quest/)。

## 首次启动：跟着引导走

打开应用，第一屏就是权限引导，只有两项：

1. **开启悬浮窗权限（必选）**：点过去会跳到系统设置，找到「显示在其他应用上层 / 在其他应用上方显示」，把开关打开。不开这项，悬浮球根本不会出现。
2. **开启自启动（建议）**：允许开机自启，重启手机后悬浮球能自动回来，不用每次手动打开应用。

两项都设置完，点底部的「开始使用」，屏幕边缘就会出现一颗半透明小圆点。

## 找不到开关？按品牌对路径

各品牌系统把这项目藏的位置不太一样，常见路径如下（菜单名随系统版本略有出入，找不到就在设置顶部搜索框搜「悬浮窗」）：

| 品牌 / 系统 | 参考路径 |
| --- | --- |
| 华为 / 荣耀 | 设置 → 应用 → 权限管理 → 找到应用 → 悬浮窗 → 允许 |
| OPPO（ColorOS 13+） | 设置 → 应用 → 特殊应用权限 → 悬浮窗 |
| OPPO（ColorOS 7~12） | 设置 → 应用管理 → 悬浮窗管理 |
| vivo | 设置 → 应用 → 权限里开「显示悬浮窗」，自启动在同一处 |
| 小米 | 手机管家 → 应用管理 → 权限 → 显示悬浮窗 |
| 三星 | 设置 → 应用 → 出现在顶部（部分版本收在「其他权限」里） |

## 悬浮球过一会儿就消失：省电策略的锅

权限都开了还是留不住，基本是国产系统的省电策略在清后台。三件事一起做：

1. 在「设置 → 电池」里把应用设为「不优化 / 无限制」；
2. 允许开机自启动；
3. 在多任务界面把它的卡片下拉锁定，防止一键清理顺手清掉。

做完把应用从最近任务划掉再重开一次，悬浮球一般就常驻了。装好后怎么把手势和面板调成顺手的样子，见[手势与快捷面板自定义.md](手势与快捷面板自定义.md)；权限开了仍不显示的顽固情况，翻[悬浮球不见了与卸载不掉怎么办.md](悬浮球不见了与卸载不掉怎么办.md)。
