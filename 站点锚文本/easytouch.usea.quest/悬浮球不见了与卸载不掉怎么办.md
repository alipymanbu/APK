# 悬浮球不见了与卸载不掉怎么办

EasyTouch 用下来最常见的两类故障：一是悬浮球莫名消失，二是激活过锁屏功能之后卸载被系统拒绝。两类都有明确的成因和解法，本篇按排查顺序整理。基础设置与手势调整见[悬浮球怎么开启与设置.md](悬浮球怎么开启与设置.md)和[手势与快捷面板自定义.md](手势与快捷面板自定义.md)；功能全貌在 [EasyTouch 悬浮球站](https://easytouch.usea.quest/)。

## 悬浮球不见了：四步排查

1. **是不是自己藏的**：长按悬浮球默认就是「隐藏按钮」动作，误触很常见——重新打开一次应用就能找回。
2. **被省电策略清后台**：到「设置 → 电池」把它设为不优化、允许自启动、多任务里锁定卡片，三者缺一不可，国产系统尤其如此。vivo 上自启动没开时，「重启后悬浮球不出现」是典型表现。
3. **悬浮窗权限被收回**：个别系统或安全软件会回收这项授权，回「设置 → 应用 → 显示在其他应用上层」确认开关还开着。
4. **还是不行**：把应用从最近任务划掉重开一次；小米这类系统还要在安全中心的权限里允许「弹出界面」。

另外两个小状况：点悬浮球没反应，去「设置 → 应用 → 存储」清一下缓存再重开；面板点开很卡，先用「加速」清一遍后台，特效多的主题换回简洁款。

## 卸载不掉：先取消设备管理器

**现象**：应用列表里长按找不到「卸载」，或点了被系统拒绝。

**成因**：面板里的「锁屏」功能依赖设备管理器，安卓规定带设备管理器的应用不能直接卸载，这是系统机制，不是应用恶意拦截。

**做法**：

1. 打开「设置 → 安全 → 设备管理器（设备管理应用）」，老系统在「设置 → 位置和安全 → 选择设备管理器」；
2. 列表里找到应用，取消激活；
3. 回应用列表正常卸载。

顺带提醒一个取舍：设备管理器锁屏之后，下一次解锁会要求输密码，指纹人脸暂时不可用——这也是系统限制。介意的话把手势里的锁屏换掉，改按电源键；不介意就继续用，毕竟它省的就是那枚最容易磨损的按键。
