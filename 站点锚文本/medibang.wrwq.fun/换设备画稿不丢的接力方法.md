# 换设备画稿不丢的接力方法

> 本篇讲画到一半要换设备时，稿子怎么从一台安卓手机平安接到平板或电脑：云端保存的前提、免费档位的三个数字、导出格式怎么选，以及动手前必须做的两件事。

## 一、云端接力靠账号，账号靠邮箱验证

MediBang Paint 在 Windows/Mac、iPad、iPhone、Android 都有版本，同一个账号下作品存云端，路上用手机起稿、回家用电脑接着画，笔刷等个人设置也能随账号同步。

不过云端功能有两个前提，缺一个就是灰的：设备联网；登录 MediBang 账号且**注册邮箱完成验证**。很多「云端功能用不了」的情况，根源就是注册完没去邮箱点那封验证邮件。

## 二、免费档位的三个数字

| 项目 | 免费账号 |
| --- | --- |
| 云端存储 | 3GB |
| 可加入团队数 | 3 个 |
| 版本回溯 | 最近 3 个版本 |

3GB 存的是分层工程文件，画短篇够用；超限后作品不会被删，但相关云端功能会受限。日常把画完的成稿导出 png/jpg 移出云端，把空间留给还在画的稿子，基本碰不到上限。

## 三、两个动作别做错

- **两种保存分清楚**：存本机走「新保存」，推云端走「云端新保存」——后者才需要登录账号。想接力的是云端这条入口，别存错了地方；
- **别把云端当唯一备份**：云端作品目前不支持批量下载，重要节点另外导出一份到本地才是稳的。

## 四、导出格式按去向选

| 格式 | 什么场合用 |
| --- | --- |
| mdp | 换设备接力、转到电脑继续画，保留全部图层与设置 |
| psd | 要带进 Photoshop、CSP 等别的软件接着改 |
| png / jpg | 发社交、传给人看，图层会合并 |

格式选错最常见的后果是「打开发现图层全没了」——给排版或合作方交稿前，先问清对方用什么软件接。

## 五、卸载或重装前，先救稿子

直接卸载应用会把没导出的画稿一起带走。卸载、重装、换机之前只做一件事就够：要留的稿子导出成 mdp 或 psd 放到设备公共目录，或者登录账号推上云端。做完这个再动手，稿子就丢不了。

工具本身的介绍与获取入口见 [MediBang Paint 手机漫画工作台](https://medibang.wrwq.fun/)，换新设备装好后，登录同一账号从云端把稿子调出来就能接着画。
