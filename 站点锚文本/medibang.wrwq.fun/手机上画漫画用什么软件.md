# 手机上画漫画用什么软件

## 一、先想清楚要画什么

画头像插图、条漫、还是多页漫画投稿，对工具的要求差别很大：画插图看重笔刷手感与混色；画条漫要频繁切分格、贴网点、写对白；画多页投稿还得管得了几十页原稿的页序。选软件先按创作类型对号，再比参数，不然容易被一长串功能清单带偏。

## 二、漫画向工具的四个硬门槛

- **分格工具**：漫画的分镜框应该是「拖一下就切出来」的效率活，而不是拿直线工具一格一格描；
- **网点与素材**：黑白漫画的灰度靠网点撑，应用里得有现成的网点库和背景素材，拖进去能缩放旋转；
- **图层体系**：线稿、上色、背景分层是基本功，最好还有半色调这类专为网点设计的图层类型；
- **页管理**：多页原稿要有按页管理的项目概念，不然几十页文件散在相册里，调页序是灾难。

这四项缺任何一项，画漫画的效率都会断在一半。

## 三、拿 MediBang Paint 逐项对照

MediBang Paint 是 MediBang Inc. 出品的免费插画与漫画绘制应用，安卓版同时支持手机与平板，系统要求安卓 8.0 及以上。按上面四个门槛过一遍：

1. **分格**：在画布上沿要切的位置拖一下即出格，格子可拖动、变形、单独上色，还有自动均分的漫画格分割；
2. **网点素材**：800 种以上网点与背景素材免费使用，另有半色调图层，涂到哪网点跟到哪；
3. **图层**：彩色、8bit 灰度、1bit 黑白、半色调四类图层，线稿上色背景各一层随便拆；
4. **页管理**：「漫画计划」把整篇原稿当一个项目管理，页数自动排好。

笔刷方面，从 28.0 版起 900 余支笔刷集中在一个列表里，每支带笔触预览；对白文字工具内置 20 种以上知名字体，还支持语音转文字输入。免费档的云端存储有 3GB，团队创作免费账号能加入 3 个。对预算有限、设备只有一台手机的入门者来说，这套配置够把第一篇漫画画完。

## 四、工具备好，从第一格开始

应用装好后先别急着画成稿，拿一页练手：切四个格、贴一层网点、写两行对白，把流程走通比看十篇评测有用。功能细节与安装入口在 [medibang](https://medibang.wrwq.fun/) 这份介绍站里有更直观的整理，配合真实界面截图看更快上手。
