# 分类、标签与英文搜索词：在壁纸图库里精准找图

## 一、图库的检索结构：分类是主干，标签是毛细血管

大型壁纸图库的图通常按两层组织：

- **分类（主题分区）**：风景、动漫、汽车、太空、动物、抽象这类大方向，通常有几十个，一个分区就是一整面缩略图墙，负责"逛"。
- **标签**：比分类细一圈的具体题材，比如某个游戏名、某个动漫角色名、某种天气。一个标签把散在不同分区里的同主题图收拢到一页，负责"直达"。

翻图的顺手路径是：大方向进分类，看到合适的再顺着标签收窄；分类页里的"相关分类"链接会把相邻题材串起来，不用每次都退回首页重新找入口。

排序方式也值得一试：同一分区按"下载数量"排出来的是经大多数人验证的图，按"评价"排偏向口碑，随机排序则适合没明确目标时淘图。

## 二、为什么搜中文常常没结果

不少老牌壁纸图库的标签体系以英文为主，中文搜索词匹配不到标签，自然返回空白。搜"猫"没结果，换 `cat` 立刻出来一整页。这不是搜索坏了，是词表对不上。

GoodFon 这类图库也有同样的特点——标签以英文为主。[GoodFon 壁纸库介绍站](https://goodfon.gerw.hair/) 的常见问题一节专门提过这一点，并把分类、标签、分辨率三种挑图方式整理成了对照说明。

## 三、直接可用的英文搜索词表

按你想找的题材，从下面挑词开始试：

| 想要的图 | 试试这些词 |
| --- | --- |
| 动物 | cat, dog, wolf, owl, horse, wildlife |
| 风景自然 | sunset, sunrise, mountain, forest, lake, ocean |
| 天气氛围 | fog, rain, snow, storm, aurora, starry sky |
| 太空 | galaxy, nebula, moon, planet, space art |
| 城市与交通 | cityscape, skyline, street, car, motorcycle |
| 动漫游戏 | anime, fan art（再叠加具体作品或角色的英文名） |
| 质感抽象 | abstract, minimalism, texture, gradient, dark |

两个组合技巧：

- **题材 + 修饰词**：`minimalist landscape`、`dark anime`，结果比单词精准得多。
- **颜色词收尾**：`blue abstract`、`green forest`，想在桌面上配一套色调时特别管用。

## 四、搜到之后别忘了初筛

关键词命中一页图之后，先按分辨率角标粗筛一轮再逐张点开，比从上往下逐张看省时间得多。点开后的验货步骤与发虚排查，整理在[壁纸分辨率与清晰度挑选.md](壁纸分辨率与清晰度挑选.md)里。
