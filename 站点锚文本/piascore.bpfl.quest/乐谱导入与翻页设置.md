# PIASCORE 乐谱导入与翻页设置

> 本篇整理把乐谱弄进 PIASCORE 的几条路子，以及翻页布局、自动滚动和免提翻页的设置思路。批注与练琴工具的用法见[批注与练琴工具用法.md](批注与练琴工具用法.md)，还没装应用的先看[安卓版下载与安装步骤.md](安卓版下载与安装步骤.md)。

## 一、三种导谱路径

PIASCORE 是乐谱的「浏览器」，打开后能看到什么，取决于先放进去什么。

- **已有的电子谱**：PDF 或图片格式的乐谱，先用聊天工具、网盘或数据线存进手机相册，再从应用里导入；
- **纸质谱直接拍**：在获取乐谱的入口选相机拍摄，正对纸谱、光线均匀、一页一拍，拍出来的页面和导入的谱一样能翻页、能批注；
- **公版古典乐谱**：应用内置 IMSLP（国际乐谱库项目）检索入口，巴赫、莫扎特、贝多芬这类公版作品按作曲家或曲名搜，选好版本即可下载进曲库；仍在版权期内的近现代作品不在公版库里，搜不到属正常。

导入的标准动作是四步：相册备谱 → 在「文稿」页新建空白文件 → 点新文件上方的「+」选中乐谱 → 调整显示比例。图片导不进去时，先确认图真的在相册主目录，有些应用下载的图会被收进「其他相册」。

## 二、翻页布局怎么选

乐谱视图底部工具栏的翻页（Page）按钮里可以切换布局，界面对应关系以实际版本为准：

| 布局 | 适合谁 |
| --- | --- |
| 单页 | 竖屏手机，最常用的默认形态 |
| 半页 | 竖屏看大谱面，一屏只显半页，翻页动作减半 |
| 双页 | 横屏平板，像摊开的纸质谱，一次看两面 |
| 纵向滚动 | 长曲连排，页面自动往下走 |

基本翻页手势：左右滑动换页、点屏幕右侧进下一页、拖底部页码滑条跳任意页。长曲排练可以开自动滚动，把滚速调到比实际演奏略慢一点，练几遍对上了再微调。

## 三、免提翻页的三种接法

手要按着乐器时，按投入从低到高：

1. **点击与手势**：零成本，坐姿练琴够用；
2. **蓝牙踏板**：AirTurn、PageFlip 一类踏板模拟蓝牙键盘，踩一下等于按一个键。配对一次长期有效；连上却翻不动页，先换踏板的发射模式档（方向键档 / 翻页键档），再到应用设置里找翻页键映射。买之前确认两点：支持安卓、发射的是标准键盘按键；
3. **无线翻页与眨眼翻页**：介绍资料里还提到借另一台设备无线翻页、识别眨眼动作翻页等玩法，安卓版里是否提供、入口在哪以实际界面为准，找不到就当没有，用踏板方案兜底。

## 四、演出前的检查清单

- 踏板和手机都充满电，提前配好对；
- 要演的谱子全部提前导入本地，开飞行模式防来电打断；
- 亮度提到舞台环境够看，自动锁屏关掉或调到最长；
- 用当前布局把整首曲子连走一遍，翻页点提前心里有数。

## 五、曲子多了怎么管

- **标签**：打上「练习中」「考级」「乐队曲目」这类标签，按标签过滤；
- **播放列表**：一场演出或一节课的曲目按顺序排好，现场顺着翻；
- **封面与目录**：每份乐谱可换封面（用自己的照片），从 PDF 导入的能生成目录，长谱跳页不用一页页翻。

换手机前，把带批注的重要乐谱逐份导出成 PDF 留底，新机上按四步导入法重新放进曲库。
