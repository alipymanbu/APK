# PIASCORE 安卓版下载与安装步骤

> 本篇讲 PIASCORE 安卓版从拿到安装包到装好能打开的全过程，顺带列出安装失败的常见排查办法。功能介绍见同目录的[乐谱导入与翻页设置.md](乐谱导入与翻页设置.md)、[批注与练琴工具用法.md](批注与练琴工具用法.md)。

## 一、装之前核对三件事

- 这是安卓应用（APK 安装包），装在安卓手机或平板上；iPhone / iPad 装不了 APK；
- 安装包体积约 208MB，装完加上乐谱缓存还会更大，动手前手机至少留 1GB 可用空间；
- 系统版本要求为安卓 5.2 及以上，实际以安装时系统弹出的提示为准。

另外提醒一句：搜「PIASCORE」会同时出现两款产品——iOS / iPad 上那款是日本团队开发的同名乐谱应用，走 App Store 分发；本篇对应的是安卓安装包版本。装安卓版的别照着 iPad 的教程找按钮。

## 二、四步装好

1. **打开分享页**：进入 [PIASCORE 电子乐谱介绍站](https://piascore.bpfl.quest/)的下载页，点「获取安装文件资源」，会跳到夸克网盘的分享页；手机上没有夸克网盘的，先到应用市场装一个；
2. **转存并下载**：把分享里的安装包转存到自己的网盘，再将 `PIASCORE_v2.2.6.apk` 下载到手机存储，记一下所在目录；
3. **允许安装**：用「文件管理」点开 APK。系统第一次会拦一下，提示「禁止安装未知应用」时，按提示允许「文件管理」（或你用来下载的那个应用）安装未知应用，返回后继续；
4. **打开授权**：安装完成后点「打开」。首次启动会申请权限：存储（导入乐谱要用，建议给）、网络（在线搜谱要用）、相机（拍纸质谱才需要）、麦克风（录音才需要）——按用途给，事后能在系统「设置 → 应用 → 权限」里逐项改。

## 三、装不上怎么排查

| 症状 | 先查什么 | 再做什么 |
| --- | --- | --- |
| 点 APK 没反应 / 提示「解析包错误」 | 安装包是否下载完整 | 回网盘重新下载一次 |
| 提示「应用未安装」 | 是否已装过别的渠道的同包名版本 | 卸载旧版再装 |
| 提示存储空间不足 | 可用空间是否还剩 500MB 以上 | 清理后再装 |
| 装完点开闪退 | 是否刚装完第一次启动 | 重启手机再试，确认系统版本达标 |

装好之后，先去[乐谱导入与翻页设置.md](乐谱导入与翻页设置.md)把谱子搬进曲库，再照着[批注与练琴工具用法.md](批注与练琴工具用法.md)配好练琴工具，就能开练了。
