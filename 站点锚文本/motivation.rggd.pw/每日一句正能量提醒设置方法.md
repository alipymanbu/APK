# 每天一条正能量提醒，怎么设置才不烦人

> 语录提醒的门槛不在「能不能设」，而在「设多少、什么时候发」——设得太密就成了打扰。这篇讲通知提醒的时间与频率怎么定、内容怎么跟着心情走，以及两种常见打扰的解法。桌面常驻的玩法另见 [桌面励志语录小组件怎么弄.md](桌面励志语录小组件怎么弄.md)。

---

## 一、先把权限打开，再调时间

语录提醒类应用的推送依赖通知权限，不给权限就什么都收不到。以 Motivation 为例，首次打开应用时会引导你开通知，跳过了也没关系，之后在系统设置 → 应用 → 通知里随时能补。

时间与频率的入口在应用内的「提醒」设置里：

| 设置项 | 建议 |
| --- | --- |
| 首条时间 | 放在你起床后半小时到一小时，睁眼就看到一句 |
| 频率 | 从每天 1 条开始用，觉得不够再加，别一上来就设五六条 |
| 分类 | 先只勾两三个最贴合现状的主题，之后再扩 |

## 二、内容跟着分类走，别贪多

提醒推送什么内容，由你勾选的分类决定。这步值得认真做：开始健身就加运动类，想调整心态就加对应的主题。勾得太杂的后果是推送内容与心情对不上号——深夜来一条运动语录，说服力有限。

一些应用还支持给不同时段配不同主题的提醒组，比如早晨推状态类、睡前推情绪类，设置时可以留意这个入口。

## 三、两种常见打扰的解法

- **提醒太密**：回提醒设置里减频率；只想保留某一时段的，把其他时段的提醒逐条关掉即可。
- **内容不对味**：去分类里取消对应主题。注意有的应用把「应用内阅读的内容」和「提醒推送的内容」分成两组偏好，改提醒的口味要去提醒那一组里改。

装好之后，把语录小组件也加到桌面上，提醒负责到点推送、小组件负责常驻，两条线正好互补——具体做法见[桌面励志语录小组件怎么弄.md](桌面励志语录小组件怎么弄.md)。想了解这款应用的整体玩法，可以看 [Motivation 每日语录小组件介绍站](https://motivation.rggd.pw/)。
