## 一、词书先对号，别贪多

词书按考试线组织，先对号入座再谈计划：

| 你的目标 | 对应词书 |
| --- | --- |
| JLPT N5 / N4 | 对应级别词汇词书 |
| JLPT N3 / N2 / N1 | 对应级别词汇 + 新完全掌握 + 真题词汇（红宝书覆盖 N1~N5） |
| 考研日语 203 | 考研日语蓝宝书、白宝书 |
| 高考日语 | 高中日语必修、选修词库（含人教版教材配套） |

MOJiTest 的词书库有 100 多本，以上是常见考试线点名的那几套。原则只有一条：**跟正在备考的那条线一致**，不同时开两本同级别词书——进度互相拖，一本都背不完。

## 二、每日任务怎么定

选定词书后，应用按艾宾浩斯遗忘曲线排任务：新词按固定节奏出现，旧词在快忘的节点安排复习。这套机制决定了：

- **每天清完当日任务**比「今天多背 200 个」重要——断一天，复习队列就往后堆；
- 每日新词量在设置里调，宁可调低到能天天完成，也不要定一个三天就弃的量；
- 完成每日复习任务后会自动开启拼写进阶题型，用来检验是真会了还是看着眼熟。

打卡日历记录累计学词量、学习天数和学习时长，坚持打卡能拿勋章——这些是记录工具，别把它们当目标。

## 三、题型自选的一个坑

背词题型可以自定义，但有一条经验值得记：**【看单词选释义】和【看单词选错义】建议只开一个**。两个题型对同一批词反复出，同时开会互相干扰判断，正确率反而虚高（靠排除法做对的题，不是真会）。

设置时先只开「看单词选释义」，过一周发现正确率注水，再换成「看单词选错义」加强辨析。

## 四、难词单独管

背词中记不住的词一键收藏进生词本，实用组合：

1. 每天背词时随手收藏记不住的词，不打断当日进度；
2. 周末集中过一遍，已经记住的移出；
3. 做真题遇到的生词也收进来——两处收藏汇成一本，考前只翻这一本。

## 五、发音与提醒

- **发音**：发音模式、语速、次数都能调。备考听力建议把发音次数设为一次——考试里听力只放一遍，平时按这个标准练；
- **学习提醒**：定一个每天确定有空的时间点（通勤、午休），别定在「理想作息」的点上——定错了只会天天关提醒。提醒不灵先查系统有没有给应用通知权限，很多手机默认把教育类应用的通知关了。
