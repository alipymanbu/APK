# 手机网络诊断工具分工

> 电脑上排查网络问题，老手会开一排命令行窗口：ping、tracert、nslookup、iperf……各有各的差事。手机上干同样的活，靠的是把这些命令行变成图形界面的工具集应用，PingTools 就是这类应用里收录比较全的一个。本文按「你想干什么」把它的十几个小工具分成几组讲分工，介绍站在 [pingtools.fewz.tech](https://pingtools.fewz.tech/)，这里只讲每件工具管什么、什么场景该轮到它出场。

## 一、测连通、看路径

- **Ping**：最常用的入口，而且不止 ICMP 一种——目标禁 ping 时换 **TCP Ping** 打指定端口，盯网站直接用 HTTP/HTTPS Ping；间隔、次数、超时都能调，开着后台工作与声音通知就能把手机放一边。
- **Traceroute**：数据包从手机到目标的逐跳路径，可视化模式标在地图上，卡在国内骨干还是出境后一眼分辨。
- **GeoPing**：另一个维度——你的网站「在别的地方」能不能被访问，一键从全球多个位置发起检查，各地可达性一次看全。
- **端口扫描器**：多线程 TCP 扫描，远程设备开放端口列成清单，多数端口带用途说明。

一个高频误区：**ping 不通不等于服务挂了**（可能是禁 ICMP），ping 通也不代表服务正常（主机活着而已）。两种 Ping 配合着用才下得了结论。

## 二、盯状态、压带宽

- **Watcher**：定时自动轮询的 Ping，状态一变（通→断或断→通）就发通知。盯家里路由器、NAS、单位业务主机都靠它。注意计划存在应用本地数据里，重装前先导出。
- **iPerf / SpeedTest**：测的是链路本身的吞吐（手机到另一台设备），不是公网下载速度。iPerf 基于 iperf3、支持服务端与客户端模式，测 Wi-Fi 实际速率、VPN 隧道损耗都用它；对端没有服务端程序时这组用不了。
- **Wi-Fi 扫描器**：周围访问点列表，厂商、信号强度、信道占用，2.4G 与 5G 都支持——给路由器选信道前先看一眼。

## 三、摸清局域网、查域名

- **局域网 / 子网扫描器**：列出网段内在线设备（IP、主机名、MAC、厂商），指定范围可扫任意 IP 段；只扫 22 找 SSH、扫 80/443 找带管理页的设备，具体手法见[局域网扫描与蹭网排查](局域网扫描与蹭网排查.md)。
- **UPnP 扫描器 / Bonjour 浏览器**：认设备身份——游戏机、电视盒子、苹果系设备，服务名常直接带设备名。
- **DNS Lookup / Whois / IP 计算器**：查解析记录（含反向解析）、查域名注册信息、算网段范围与可用地址数，换 DNS 后确认生效、划 VLAN 少手算都靠这组。
- **Info**：本机 IP、网关、公网出口、运营商信息与实时速率图，判断「手机到底连的哪个网」从这里开始。
