# 远程唤醒电脑设置清单

> 用手机发个「魔术包」把家里关机的电脑开起来，听起来玄乎，其实条件很明确——只是这些条件分散在目标电脑的 BIOS、网卡驱动和电源设置里，缺一处就唤不醒，WoL 也因此落了个「十有八九第一次不通」的名声。本文把条件列成清单，再给一份按命中率排序的排查顺序。手机端发包用的就是 PingTools 工具集里的 Wake on LAN 工具，工具总览见[手机网络诊断工具分工](手机网络诊断工具分工.md)，介绍站在 [pingtools.fewz.tech](https://pingtools.fewz.tech/)。

## 一、先确认场景做不做得到

1. **目标电脑用网线**——WoL 在有线以太网上最可靠；Wi-Fi 网卡大多不支持断电唤醒，能用线就插线；
2. **电脑没有彻底断电**——网卡唤醒靠关机后的待机电流，电源线拔了、插排开关关了，一切免谈；笔记本要接电源或电量充足；
3. **不是所有电脑都支持**——部分超薄本、低价主板在固件里砍掉了 WoL，硬件层面无解，查主板说明书确认。

## 二、目标电脑要改的四处（以 Windows 为例）

按顺序逐处核对：

| 位置 | 要做的事 |
| --- | --- |
| BIOS/UEFI | 开启 Wake on LAN / Power On by PCI-E（各品牌叫法不一）；固件里有 **ErP / Deep Sleep** 的**关掉**——它会在关机后切断网卡供电 |
| 设备管理器 → 网卡 → 电源管理 | 勾上「允许此设备唤醒计算机」和「只允许魔术包唤醒计算机」 |
| 设备管理器 → 网卡 → 高级 | 把 **Wake on Magic Packet** 设为启用；有节能以太网（EEE）选项的也建议关闭 |
| Windows 电源选项 | **关闭「快速启动」**——快速启动下的「关机」不是真关机，网卡不处于可唤醒状态 |

改动较多时，改完**正常开机一次再正常关机一次**再测。

## 三、手机端发送

1. 电脑**开机且联网**时，先用扫描工具找到它，抄下**有线网卡**的 MAC 地址——多数机器有线和无线网卡的 MAC 不同，抄错是常见失败原因；
2. 打开 Wake on LAN 工具，填入 MAC，同一局域网内直接发送；
3. 电脑应在几秒内启动。把这台设备存为收藏，下次一键发送。

## 四、发了没反应：按命中率排查

1. **ErP / Deep Sleep 还开着**——固件把网卡电断了，其余设置全对也没用；
2. **快速启动没关**——控制面板 → 电源选项 → 选择电源按钮的功能里取消勾选；
3. **MAC 抄错**——重新扫描，对着有线网卡再抄一遍；
4. **先验证基本连通**——先 ping 一下目标电脑的 IP，通再发包；ping 都不通说明不在一个网段或被隔离；
5. **电脑被拔过电**——断过市电的机器常需要再正常关机一次才恢复可唤醒状态。

## 五、人在外面怎么发

魔术包是广播包，默认出不了路由器。人在外网有两条路：

- **VPN 连回家再发**（多数家用路由器支持）——连上后手机等于在家里局域网，这是推荐做法，不对外暴露端口；
- **路由器做 UDP 端口转发指向广播地址**——可行，但等于给公网开了条唤醒通道，安全上要掂量。
