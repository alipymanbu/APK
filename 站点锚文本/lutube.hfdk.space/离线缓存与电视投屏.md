# lutube 离线缓存与电视投屏方法

> 本篇讲两件让观影更自由的事：把片子缓存到本地离线看，以及投到电视大屏上看，顺带说清缓存占空间时怎么清理。
> **相关文档**：[怎么安装到安卓手机](怎么安装到安卓手机.md) · [看剧卡顿转圈怎么办](看剧卡顿转圈怎么办.md)

---

## 一、离线缓存：通勤路上断网也能看

lutube 支持把在线视频下载到手机本地、断网也能播放（v1.1.90 已带下载与离线播放），地铁、高铁、信号差的场所最实用：

1. 在片库或搜索结果里找到想存的片子；
2. 点视频条目旁的**下载**按钮（有的版本这个按钮在播放页里）；
3. 弹出清晰度选择时选一个，开始缓存；
4. 缓存完成后，到**我的 → 下载管理**里找到并播放，已存内容与正在下载的进度分栏显示。

几点提醒：

- 缓存依赖存储权限，点下载没反应时，先去系统设置确认存储权限已经打开；
- 缓存的视频默认只能在应用内播放，拷到别的播放器不一定认；
- 标了 VIP 的内容能否缓存以应用内提示为准，部分内容只允许在线看；
- 想让观看记录跟着账号走，先把账号登录做好（装好后的第一步，见 [怎么安装到安卓手机](怎么安装到安卓手机.md)）。

## 二、缓存占满空间时

- 应用设置里有**清理缓存**入口，定期清一次，应用整体状态也会更稳；
- 看完的离线视频在下载管理里逐条删除；
- 分清「清缓存」和「删影片」两个入口：清缓存通常不动你特意存的片子，但两个按钮常常相邻，删之前看清楚名字。

## 三、投屏到电视：小屏换大屏

按家里设备的类型选路径：

1. **先确认同一局域网**：手机和电视（或盒子）连的是同一个 Wi-Fi，这是投屏成立的前提；
2. 在应用里打开想看的视频，点**分享**按钮（或播放页上的投屏图标）；
3. 在设备列表里选你的电视 / 盒子，连上后画面就上大屏了。

| 家里的设备 | 能不能直接投 |
| --- | --- |
| 支持 DLNA 的电视 / 盒子 | 可以，应用里直接选设备 |
| 不支持 DLNA | 借助 Chromecast 这类投屏设备中转 |
| 两种都没有 | 用手机系统的无线投屏（各品牌叫「智能投屏」「无线显示」「多屏互动」）做整体镜像 |

搜不到设备时按这个顺序查：手机和电视是否真的在同一个 Wi-Fi、路由器是否开了「AP 隔离」（开了会挡住设备互相发现）、电视端的投屏接收服务有没有被安全软件禁用。

## 四、小屏之外的看片姿势

- **画中画 / 悬浮窗**：退出播放页后视频缩成小窗继续播，边回消息边看；有的版本叫「悬挂模式」，入口在播放页，找不到说明该版本没带；
- **倍速**：全屏唤出播放控制条后调，赶进度和二刷都用得上；
- 片子放不出来先按 [看剧卡顿转圈怎么办](看剧卡顿转圈怎么办.md) 的顺序排查，处理完再回来玩这些。

还没安装的，从 [lutube 安卓版下载安装](https://lutube.hfdk.space/) 的下载页拿安装包，四步装好。
