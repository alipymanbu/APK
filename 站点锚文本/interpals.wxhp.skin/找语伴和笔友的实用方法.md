# 找语伴和笔友的实用方法

在 InterPals 上认识人，靠的不是滑卡配对，而是「先读资料、再写信」的搜索。这篇把筛选条件、四步锁定语伴的方法和几个容易被忽略的找人入口整理在一起；社区的整体定位与功能全貌，见 [InterPals 笔友社区介绍站](https://interpals.wxhp.skin/)。

## 一、先把筛选条件用对

搜索页能按五类条件筛人，每一类都有明确用途：

| 条件 | 怎么用 |
| --- | --- |
| 国家 | 想认识哪个国家的人就选哪个，180 多个国家可选 |
| 城市 | 想了解某座城市或约见面时用 |
| 年龄 | 按年龄段收窄范围 |
| 会说的语言 | 找母语者主要靠这一项 |
| 正在学的语言 | 找互惠语伴的关键条件 |

搜索结果是一份份完整的个人主页与相册，可以认真读完资料再决定写不写信——这正是笔友社区和速配软件最大的区别。

## 二、四步找到一个母语语伴

1. 打开搜索页；
2. 在「会说的语言」里选你想练的那门语言；
3. 把最低水平设为 Native（母语）或 Proficient（精通）；
4. 叠加国家条件（学日语就限定日本），优先挑那些**正在学你的母语**的人——双方都有得练，回复率也更高。

多读几份主页再下手：兴趣和目标与你相近的人，才是长期合拍的语伴。

## 三、除了搜索，还有这些入口

- **Online Now（此刻在线）**：在线的人更容易聊起来；
- **谁看过我的主页**：对浏览过你资料的人先打招呼，成功率不低；
- **群组与社区动态**：按兴趣加群、发帖，不用私聊也能先混个脸熟；
- **书签**：在别人主页底部点 Add bookmark 存起来，之后统一回访。

主页被看得多却没人来信，先检查两件事：语言两栏填全了吗、照片传了吗。资料就绪之后，主动找上门的消息会明显多起来。

## 四、发第一条消息之前

先读对方的「关于我」——很多人会写明想认识什么样的人（只交笔友、只谈语言、或也接受恋爱），看完再决定怎么开场。开场白具体一点，提一句对方主页里的内容，比群发模板有效得多。每天能主动联系的新人数量有限制，把名额留给筛出来的人；别人先来信、你回复不占名额。涉及转账的说法一律拒绝，具体的信号清单见 [语言交换入门与防骗要点](语言交换入门与防骗要点.md)。
