# Chatbox 聊天记录备份与换机迁移

> 本篇讲 Chatbox 的聊天记录存在哪、为什么必须手动备份、导出导入怎么操作。安装与配置分别在 [手机上怎么装.md](手机上怎么装.md) 和 [API-Key-获取与配置.md](API-Key-获取与配置.md)。

---

Chatbox 的聊天记录、配置和自定义 Prompt 全部存在设备本地，服务器上没有副本。这是它隐私上的优点，也是数据安全上的唯一软肋：卸载、恢复出厂、换手机，记录都会跟着消失且无法找回。动手前照下面的流程做一遍，风险基本归零。

## 一、备份文件里有什么

导出的全量备份包含所有对话历史、应用设置、自定义 Prompt 以及模型配置（含你填的 API Key）。因为 Key 也在里面，备份文件要当敏感文件保管，别随手发群、别传公开网盘。

## 二、导出与导入

安卓端路径：侧边栏 →「设置」→「数据管理」→「导出数据」，文件落在手机 `Documents/chatbox_ai_exports` 目录。格式有两种：

| 格式 | 用途 |
| --- | --- |
| JSON | 全量备份，可以再导回 Chatbox 恢复 |
| Markdown | 纯文本可读，适合存档翻阅 |

恢复时在新设备装好应用，进「数据管理」→「导入数据」选中 JSON 文件即可，对话、设置、Prompt 会一起回来。导入是快照式的：旧设备之后新增的对话不会自动跟上，需要时再导一次。

## 三、换机防丢清单

- 卸载前先导出——卸载动作会带走应用私有存储里的全部数据；
- 定期导一份 JSON 存进自己的网盘，手机丢失、损坏时才有得救；
- 换机当天先迁移、确认新设备记录完整，再清旧手机；
- 两台设备同时在用时记录各自独立，想合并就定期从主力机导出、往另一台导入。

还没装的人可以先到 [Chatbox 介绍站](https://chatbox.qjxz.skin/)了解功能与获取方式；已经用上的，建议现在就导出第一份备份。
