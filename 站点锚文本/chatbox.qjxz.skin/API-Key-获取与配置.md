# Chatbox 模型 Key 从哪拿、怎么填

> 本篇讲 Chatbox 的两条接入路线：登录账号领额度，或者自带 API Key 调用各家模型；顺带把自定义提供方的填法写全。安装步骤在 [手机上怎么装.md](手机上怎么装.md)。

---

Chatbox 本身不带模型，它是一个把各家模型服务装进同一个聊天界面的客户端。能聊什么模型，取决于接上了哪个提供方——这也是它和套壳应用最大的区别：模型、Key、费用都握在自己手里。还没安装的话，先到 [Chatbox 介绍站](https://chatbox.qjxz.skin/)拿安卓安装文件。

## 一、路线 A：登录 Chatbox AI 账号

适合不想折腾的人：邮箱注册一个账号，在应用里登录即可。新用户可以领免费计算点数，每天刷新，标准模型（DeepSeek 系、Kimi、Gemini Flash 档等）直接可用；用量大了再考虑订阅档位。一个账号最多 5 台设备同时在线，手机平板电脑都算。

## 二、路线 B：自带 API Key

已经有 OpenAI、DeepSeek 等平台 Key 的，直接在「设置 → 模型提供方」里添加对应厂商，把 Key 粘进 API Key 字段保存即可。Key 在各平台的开放平台后台创建，只在创建时完整显示一次，记得先存好。各家计费独立：DeepSeek 人民币充值门槛低，OpenAI 需要海外支付方式并建议设置用量上限。

## 三、自定义提供方

设置列表里没有的服务商（中转、聚合、自建服务），用「添加」自建一个，四个值填对就能通：

| 填项 | 说明 |
| --- | --- |
| API 类型 | OpenAI 兼容最常见，Gemini 原生接口的服务选 Gemini 兼容 |
| API 主机 | 服务商给的地址，别带末尾斜杠 |
| API 密钥 | 服务商的 Key，无鉴权的自建服务留空 |
| 模型 | 照服务商文档写模型 ID，别照官方名猜 |

保存后点「检查」验证连通，再回首页发一句话实测流式回复。

## 四、报错先看原文

`401/403` 找 Key（失效、欠费、复制不完整），`429` 找额度与限频，`5xx` 与超时找网络链路。把报错原文拿到对应平台的文档里查，比反复改配置快得多。日常问答换轻量模型、重活再切旗舰，点数和余额都省得快。
