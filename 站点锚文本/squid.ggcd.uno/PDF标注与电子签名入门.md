# PDF标注与电子签名入门：在安卓上批文件、填表单

> 本篇讲在安卓手机或平板上完成 PDF 批注、试卷批改、表单填写与文件签名的操作路径，示例应用为 Squid 手写笔记；应用之间的取舍问题在《安卓手写笔记应用怎么选》里单独讲过。相关文档：[安卓手写笔记应用怎么选](安卓手写笔记应用怎么选.md)

---

纸质文件的批注与签字，在安卓上都能用手写笔记应用完成：把文件导进应用，剩下的事就交给笔。下面按「导入 → 批注 → 签名 → 带走」的顺序走一遍，以 Squid 为例。

## 一、把文件请进应用

新建笔记时选择导入 PDF，文件里的每一页会变成一页笔记——白纸黑字的版面还在，只是从「只能看」变成了「能写」。图片同理，拍照的文件、扫描件、截图都能导入，进笔记后还能裁剪、缩放、排版，和手写内容混排在同一页。

给文件读取权限时留意一下弹窗说明：只在自己屏幕上写写画画不需要额外授权，导入本机 PDF 或图片时才用得上。

## 二、批注、勾画与填表

导入之后就是普通笔记页，之前用在白纸上的手段全部可用：

- **批改与勾画**：用笔直接在题目上画线、打勾、写批语；矢量笔迹放大后依然平滑，细小的分数格也能写进去。老师批试卷、审讲义就是这条路径。
- **填表单**：表格里的空栏用笔直接填字；写错了用笔画橡皮一划擦掉，不用来回找涂改工具。
- **整份整理**：多份 PDF 可以合并成一份，也能在中间插页——把签字页插到合同末尾、把补充说明插到章节之间，都是一次插入的事。

## 三、把名字签上去

签名是最常见的刚需。流程很简单：翻到要签字的那一页，选顺手的笔在签名栏写上名字即可；需要规范化的话，先在空白页把签名写好、调整到合适大小，再放到目标位置。

在导入的合同、授权书、申请表上签字，效果与纸面签字一致；签完的文件随后就能导出带走。

## 四、把成果带走

批完、签完的文件按需导出：交回 PDF 是最通用的选择，PNG / JPEG 适合单独抽某一页发消息。注意两点：

1. 笔记默认存在设备本地，导出前确认文件已经保存完整；
2. 长期保留的文件除了留在应用里，建议再导出一份 PDF 存到自选位置——本机数据在换机、卸载时不会自动跟人走。

整个流程装一个应用就能走完。Squid 的写画界面截图、纸型说明与安装文件资源的获取指引，见 [Squid 手写笔记介绍站](https://squid.ggcd.uno/)，装好后按上面四步操作即可。
