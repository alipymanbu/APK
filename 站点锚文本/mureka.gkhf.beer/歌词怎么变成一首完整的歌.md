# 歌词怎么变成一首完整的歌

> 手里有一段写好的词，或者只有一个模糊的主题，想让 Mureka 把它变成带人声、带编曲的成品——这篇按实际操作顺序讲清楚每一步该怎么给料，出活才稳。

## 先分清两种写法

创作页给了两个入口，按你手上的料选：

- **Lyrics 模式**：词已经写好了，整段贴进去。歌词框最多容纳三千字，主歌、副歌分好段落再提交，成品歌的结构会明显更完整。
- **Text 模式**：还没到"词"的程度，只把主题、心情、场景随手写几句，模型会理解你的意思并替你把内容发展完整。

两种模式支持中、英、日、韩等多语种创作——写哪种语言的词，出来的歌就用哪种语言唱。词写到一半卡住了，也可以交给 AI 按已有内容补全，补完不满意再手动改。

## 控制面板决定出活的方向

歌词区下面那一排控制项才是这一步的关键，四件事可以叠加着给：

| 控制项 | 什么时候用 |
| --- | --- |
| Custom | 心里已经有明确的曲风方向，写清"曲风 + 节奏 + 情绪 + 人声"四件事，描述越具体第一次生成越接近预期 |
| Music reference | 手上有首气质对路的参考歌，挂上去让整首贴着它的感觉走 |
| Singer | 直接指定由哪种声音演唱，不用等生成完再挑 |
| Humming motif | 脑子里有个调子，录一段哼唱让旋律从你的动机上长出来 |

只写两个字就想出好歌是常见误区。比如想要民谣就写"民谣、舒缓、女声、吉他伴奏"，想要说唱就写"嘻哈、重低音、男声、快嘴"——骨架给全了，积分才花得值。

## 生成与挑选

同一次生成会给出好几个版本，全部试听一遍再决定留哪首，这是最省积分的挑法。第一版不满意也不用整首推倒重来：哪一段不满意就单独重做那一段，歌太短可以在尾部继续延长，调整的粒度是"段"而不是"整首"。

想看完整的玩法与界面说明，可以到 [Mureka 介绍站](https://mureka.gkhf.beer/) 按板块翻，四条创作入口和生成后的修改空间都有对应的说明。
