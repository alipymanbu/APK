# 红板报有什么区别：Flipboard 国际版与中国版一次分清

> 名字相近、图标同色系，但这是两个不能混用的应用。本篇讲 Flipboard 国际版与"红板报"的来龙去脉、怎么一眼认出自己手上是哪个，以及该选哪个。
> **相关文档**：[杂志式资讯阅读核心玩法.md](杂志式资讯阅读核心玩法.md) · [安卓版安装步骤与常见问题.md](安卓版安装步骤与常见问题.md)

## 一、一段历史解释为什么有两个

Flipboard 2010 年在美国上线，2013 年底进入中国，最初是同一套产品的汉化版本。2017 年中国团队独立运营，另起了中文名「红板报」，服务器与内容运营都转由国内团队负责。从此两边各走各的版本线，各自积累账号数据。

这段历史留下的直接后果：

- **账号互不相通**。国际版账号登不进红板报，收藏与自制杂志也不会迁过去，反之亦然；
- **版本号没有对应关系**。两边各自发版，版本号对不上是正常的，不能拿来判断谁新谁旧。

## 二、一张表分清

| | 国际版（Flipboard） | 红板报（中国版） |
| --- | --- | --- |
| 桌面图标名 | Flipboard | 红板报 |
| 安卓包名 | `flipboard.app` | `flipboard.cn` |
| 界面文字 | 以英文为主 | 中文 |
| 内容编排 | 全球来源 + 区域版本 | 面向中文读者的本地化内容 |

## 三、手机上怎么确认装的是哪个

三条路任选一条：

1. **看图标下的名字**：写 Flipboard 的是国际版，写「红板报」的是中国版；
2. **看界面语言**：打开是英文引导的是国际版（注意：国际版切了 China 区域版也只换内容来源，界面不会变中文）；
3. **看包名（最可靠）**：设置 → 应用 → 应用信息里查包名，`flipboard.app` 是国际版，`flipboard.cn` 是红板报。

三条指向不一致时以包名为准——有些第三方站会把两个包的名字混着写，包名是唯一没法含糊的那项。

## 四、该选哪个

- **想读全球媒体、练英文、玩自建杂志** → 国际版。想读中文资讯也不必换应用，国际版内置区域版本，把 China 设上即可优先展示中文地区的媒体与话题（一次设一个区域，切换不丢关注）；
- **只想要全中文界面的本地化内容** → 红板报更顺手。
