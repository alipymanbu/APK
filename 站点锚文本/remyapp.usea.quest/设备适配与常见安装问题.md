# 设备适配与常见安装问题排查

> 围绕 remyapp 的安装与使用，把设备适配口径和几类高频问题集中列清楚，对号入座即可。
> **相关文档**：[3D空间记忆应用下载安装思路.md](3D空间记忆应用下载安装思路.md) · [环绕拍摄重建3D影像技巧.md](环绕拍摄重建3D影像技巧.md)

## 一、高频问题速查

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 安装客户端时提示「安全提醒」 | HarmonyOS 3.0 ~ 4.x 的纯净模式「增强防护」在拦 | 「设置 → 系统和更新 → 纯净模式」关闭增强防护后再装，安装界面勾选已知悉提示 |
| 提示解析错误 / 不兼容 | 系统低于安卓 5.0，或下载中断导致包体不完整 | 确认系统版本；重新下载一次安装包再试 |
| 提示需要登录华为帐号 | 部分设备版本要求登录后才能安装应用 | 按提示登录后再装 |
| 客户端装好了搜不到 Remy | Remy 深度适配 HarmonyOS 6，三方安卓设备可得性有限 | 先把客户端升级到新版本再搜；能否搜到以市场内实际结果为准 |
| 登录一直转圈 / 无法连接 | 网络或 HMS Core 版本问题 | 换网络重试；更新 HMS Core；确认系统日期时间为自动设置 |

## 二、关于设备得再啰嗦两句

- **HarmonyOS 5.0 及以上（纯血鸿蒙）**：不再兼容安卓安装包，但系统自带应用市场，搜索 Remy 即可，与安装包无关；
- **其他品牌安卓设备**：装市场客户端没问题，但 Remy 在这类设备上能否搜到、装上能否运行，以市场内的实际结果与产品方说明为准，搜不到时不必反复重装客户端；
- **iOS 设备**：公开资料明确不支持。
