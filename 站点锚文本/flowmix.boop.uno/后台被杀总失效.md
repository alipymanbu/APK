# Flowmix 后台被杀总失效：保活设置一次做完

本篇写给「切个微信回来 EQ 就没了」「锁屏十分钟再听又变成原声」的读者。均衡器需要常驻才能持续处理音频，而各家国产系统对后台应用都不客气——把这篇的几件事做完，驻留稳定性会完全不同。效果本身的排查见[开了没效果怎么排查](开了没效果怎么排查.md)，调音见[怎么调音效果好](怎么调音效果好.md)。

---

## 为什么会被杀

Flowmix 通过常驻通知以前台服务的形态运行，这已经是安卓给普通应用最高的优先级之一；但系统在内存紧张或省电策略激进时仍可能回收它。被回收后应用本身没有损坏，重新打开即可恢复，已保存的曲线配置都在——要解决的是「不被杀」而不是「重装」。

## 保活四件事

1. **授予通知权限**：这是前台服务存在的前提。没有通知栏常驻条目，后台存活率会断崖式下降。
2. **允许自启动**：开机或应用间拉起时不再被拦，路径因品牌而异，一般藏在应用管理或启动管理里。
3. **电池优化设为「不优化 / 无限制」**：设置里搜「电池优化」找到 Flowmix 选不优化；部分品牌在应用详情的耗电管理里设「无限制」。
4. **最近任务里锁定卡片**：多任务界面对 Flowmix 卡片上锁，手动一键清理时不会被带走。

这四件做完，绝大多数机型上效果就能持续在线了。

## 还有更狠的：无感后台

设置 → 实验性 → 「无感后台」，开启后应用不再出现在最近任务列表里，但仍在运行。好处是清理后台时不会被误杀，视觉上也清爽；官方建议先把上面四件事做完再开它，顺序别反。

个别机型上无障碍相关的「增强保活」也可选，遇到无障碍打不开的情况，卸载后改用系统自带文件管理器重新安装再开启即可。

## 一个习惯：用 Sync 页确认状态

每次切换音频设备（插耳机、连蓝牙音箱）后，顺手看一眼「Sync」页的设备与配置状态，确认当前设备挂的曲线是预期的那套——这比听感判断可靠得多，尤其是给不同设备配了不同 EQ 的用户。
