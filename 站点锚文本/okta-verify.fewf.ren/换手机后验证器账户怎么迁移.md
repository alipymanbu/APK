# 换手机后验证器账户怎么迁移

> 换新手机最怕登录卡在验证那一步。先说结论：这类验证器的账户不走云备份，密钥绑定在设备上——能不能顺利搬家，取决于旧手机还在不在、以及有没有留备用验证方式。

## 一、先对号入座

| 你的情况 | 能做什么 |
| --- | --- |
| 旧手机还在手边 | 蓝牙导出导入，不用麻烦管理员 |
| 旧机没了，但有短信、安全钥匙等其他验证方式 | 自己在组织面板重新注册 |
| 旧机没了，也没有任何其他验证方式 | 只能联系帮助台重置，无法自助 |

## 二、旧机还在：蓝牙导出导入

前提是账户启用了 FastPass、新机已设锁屏、两台设备蓝牙都打开。操作上：旧机进入账户详情选导出，屏幕出现二维码和一个 8 位字母码；新机装好应用（安装包入口见[双因素身份验证器怎么装到安卓手机](双因素身份验证器怎么装到安卓手机.md)）选导入，扫旧机二维码或手输 8 位码；最后把新机上显示的 6 位 PIN 输进旧机完成配对。特别提醒：这串 PIN 只该出现在自己的两台设备之间，别人发来的不要输。

## 三、旧机没了：面板重新注册

1. 浏览器打开组织登录地址，用短信或安全钥匙等其余方式通过验证。
2. 进入个人面板 → Settings → Security Methods，把旧手机那条记录移除。
3. 再点验证器的 Set up，用新手机扫屏幕上的新二维码，走一遍扫码注册。

## 四、什么都没了：只能重置

没有备用验证方式时无法自行恢复，联系帮助台由管理员重置，之后会收到新的注册邀请邮件。恢复访问后顺手补一条短信验证码或安全钥匙当备用，下次换机不至于再次卡死。

扫码注册的完整步骤与扫不了码的替代路径，[Okta Verify 说明站](https://okta-verify.fewf.ren/)的「账户与迁移」一节有更细的拆解；搬完家推送不响，见[登录双重验证收不到推送怎么办](登录双重验证收不到推送怎么办.md)。
