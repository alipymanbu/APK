# Aseprite文件互通与精灵表导出

本篇讲 resprite 与桌面工具交接文件的几条主路：读写 .aseprite 工程的注意点、PSD 导出带什么、精灵表怎么排，以及瓦片地图接入 Tiled 的方式。动画与安装相关内容见 [时间轴动画与洋葱皮用法](时间轴动画与洋葱皮用法.md) 与 [安卓版下载与安装步骤](安卓版下载与安装步骤.md)。

---

## .aseprite 文件：双向读写，但有转换损耗

resprite 支持把桌面上的 `.aseprite` / `.ase` 工程导入手机继续画，也能反向导出 `.aseprite` 文件交回团队管线。转换不是无损的，几个容易踩的位置：

- **图层组**：导入后组的不透明度会变成全不透明、混合模式回到 Normal，普通图层不受影响；
- **动画标签**：Aseprite 里允许重叠的 tag 范围，对应到 resprite 的不重叠片段时边界可能被调整；
- **帧时长**：按 100ms 为单位截断，最小 100ms，精细的短帧节奏会变；
- **瓦片图层**：Aseprite 的瓦片图层导入后不会变成 resprite 的瓦片图层，需要可编辑地图请走 Tiled 流程。

所以交接重要工程时，记得两边都留底：`.resprite` 原稿存一份，`.aseprite` 副本交出去，导出后先打开核对图层效果与帧节奏再继续往下走。

## PSD：单帧分层交接

把当前帧导出成 Photoshop PSD 时，图层组、剪贴蒙版、混合模式、Unicode 图层名、显隐状态与不透明度都会保留，实测在 Photoshop、Krita、Clip Studio Paint、GIMP 里都能正常打开。注意 PSD 只包含当前帧，多帧动画要逐帧导出，或者改走 GIF / 精灵表。

## 精灵表：引擎直用的排布

精灵表（Sprite Sheet）导出是无损 PNG，可配置帧范围、排列方向、每行数量、边距与放大倍数；新版还支持按帧、按片段或按图层拆成多个文件，组合条件与命名规则都能定制，接入 Unity、Godot 这类引擎时不用再手动切图。

## Tiled 地图：.tmx / .tsx 进出

resprite 的瓦片图层（矩形 / 等距菱形 / 六边形）可以导出成 Tiled 地图——通常是一个 zip 包，内含 `.tmx` 地图、`.tsx` 瓦片集与 PNG 图；同样也能把 Tiled 的地图与瓦片集带回来继续编辑。地形规则（Corner / Edge / Mixed）画出来的地面、水边、道路，会随瓦片集一起进 Tiled，关卡策划那边不用重画。

## 导出流程小结

1. 动画预览与社交分享 → GIF / APNG；
2. 引擎素材 → 精灵表 PNG（按需拆分）；
3. 桌面修图 → PSD（当前帧）；
4. 跨软件工程往来 → .aseprite（先核对再交接）；
5. 关卡地图 → Tiled zip 包。

这些格式的获取入口与功能概览都整理在 [resprite 安卓版下载站](https://resprite.ggcd.uno/)，与上面几篇配合着看，基本能覆盖独立游戏美术在手机上的完整交付链路。
