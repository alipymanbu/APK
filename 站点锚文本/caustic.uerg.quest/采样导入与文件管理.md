# 采样导入与文件管理：格式、传输路径与备份

> 本篇讲把外部采样与音色文件喂进机架类编曲工具的做法：哪些机器认哪些格式、文件放在设备哪里、怎么传与怎么备份。
> **相关文档**：[机架合成器怎么选.md](机架合成器怎么选.md) · [怎么在手机上做电子音乐.md](怎么在手机上做电子音乐.md)

---

## 一、格式是第一道门槛

以 [Caustic 机架式音乐工作站](https://caustic.uerg.quest/) 的口径为例（同类工具大同小异）：

| 机器 | 接受的文件 |
| --- | --- |
| 多采样波形合成器 | 非压缩 WAV、SoundFont（`.sf2`）、SFZ、FL Studio Mobile 乐器（`.instr` / `.ZIP`） |
| 采样鼓机 | 非压缩 WAV |
| 声码器 | 非压缩 WAV（作为载波输入） |

WAV 的要求是**非压缩**，8/16/24/32bit 都行、采样率不限。网上采样包绝大多数是 16bit / 24bit 的 PCM WAV，可以直接用；压缩 WAV 以及 mp3、ogg 这类压缩格式不在支持列表里，先转一次格式再导。

## 二、文件都存在公开存储目录

这类工具通常把歌曲、预设、采样直接写在设备**用户可访问的存储**里（比如根目录下的 `caustic/`，预设按机器分家在 `caustic/presets/<机器名>/`、采样在 `caustic/samples/<机器名>/`）。这带来两个好处：

- 用电脑的文件管理器就能直接翻看、整理这些文件，不依赖应用本身；
- 备份与换机迁移就是把整个目录拷走：换机时拷到新设备同位置，阶段备份拷出一份改名副本即可。

## 三、文件进出的三条路

1. **USB 数据线**：手机连电脑直接读写目录，最直白；
2. **应用内 FTP 服务器**：部分工具（含上面举例的这款）内置可选 FTP 服务，同一局域网内用电脑的 FTP 客户端连手机互传，不用插线；
3. **第三方内容包**：不少音色 / 采样包做成安装器 APK，装上后自动把预设与采样释放到对应子目录，释放完安装器本身可以卸载。

另外，带麦克风的设备还能在应用内**直接录采样**：录环境声、人声、乐器都行，录进来就是干素材，音色好坏靠后面在机器里调。

## 四、导入后不认文件，按这个顺序查

1. 格式对不对：压缩 WAV、mp3 先转非压缩 WAV；
2. 机器选对没有：`.sf2` / SFZ 只有采样波形合成器认，鼓机与声码器只吃 WAV；
3. 路径能不能看到：存储权限给过没有；
4. 版本差异：个别导入功能是后续版本修的，老版本导入失败先想想是不是版本原因。

机器怎么按用途挑，见 [机架合成器怎么选.md](机架合成器怎么选.md)；从零开始的完整流程在 [怎么在手机上做电子音乐.md](怎么在手机上做电子音乐.md)。
