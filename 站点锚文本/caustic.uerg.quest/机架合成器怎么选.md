# 机架合成器怎么选：12 种音源机器的分工与选型

> 本篇把一类「机架式」移动编曲工具里常见的音源机器按用途归类，给「从零开始 / 想要某类音色 / 爱折腾」三种典型需求的选型建议。
> **相关文档**：[怎么在手机上做电子音乐.md](怎么在手机上做电子音乐.md) · [采样导入与文件管理.md](采样导入与文件管理.md)

---

## 一、先按「声音从哪来」分三类

机架上的音源机器，按发声原理可以分成三类，选型时先问自己「这段声音从哪来」：

1. **纯合成引擎**：振荡器、滤波器、包络一路堆出来，不读外部文件；
2. **采样回放引擎**：加载真实声音的录制件（采样 / 音色库），按音高回放；
3. **建模引擎**：用算法模拟真实乐器或老设备的物理特性。

以 [Caustic 机架式音乐工作站](https://caustic.uerg.quest/) 的机器阵容为例，三种类型它都有覆盖。

## 二、纯合成类：经典电子味都在这里

- **模拟减法合成器**（Subsynth 一类）：贝斯、主奏、铺底万能，零基础从这里开始；
- **303 风格单音合成器**（BassLine 一类）：酸性贝斯线的味道源头，电子味最正；
- **FM 合成器**（FMSynth 一类）：电钢琴、钟铃、金属质感，DX 系数的经典路数；
- **谐波表铺底合成器**（PadSynth 一类）：长 pad 与氛围垫专属；
- **8bit 方程式合成器**（8BitSynth 一类）：芯片音乐与复古游戏机味；
- **超级锯齿复音合成器**（SawSynth 一类）：宽厚开阔的锯齿和弦，合唱感强；
- **音轮风琴**（Organ 一类）：Hammond 类风琴带旋转扬声器；
- **全可路由模块合成器**（Modular 一类）：信号路径自己接，进阶玩法。

## 三、采样与建模类：声音来自外部

- **多采样波形合成器**（PCMSynth 一类）：自由度最高的一台，能吃 WAV 采样、SoundFont（.sf2）、SFZ 等格式，当「万能乐器」用；
- **采样鼓机**（BeatBox 一类）：8 通道，每个通道都能换成自己的鼓组采样；
- **声码器**（Vocoder 一类）：8 段谐波处理外部人声，机器人声的关键；
- **弦建模合成器**（KSSynth 一类）：Karplus-Strong 算法出的拨弦、弹拨音色，拟真度高。

## 四、三种典型需求，三套配置

- **从零开始**：模拟减法合成器 + 采样鼓机两台就够起步，别急着摆满机架；
- **想用自己的音色**：多采样合成器是主力，格式细节见 [采样导入与文件管理.md](采样导入与文件管理.md)；
- **喜欢折腾**：模块合成器接信号路径，配合每台机器自带的效果槽，能玩出很深的声音设计。

选型没有唯一答案：空槽点开挨个切预设听一遍，比看任何参数表都直观。决定从哪台开始之后，回到 [怎么在手机上做电子音乐.md](怎么在手机上做电子音乐.md) 把第一段 pattern 做出来。
