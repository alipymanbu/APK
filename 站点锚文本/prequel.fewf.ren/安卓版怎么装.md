# Prequel 安卓版怎么装：从取回文件到打开应用

> 本篇讲安卓手机上安装 Prequel 的完整流程：取回安装文件、放行未知来源、核对应用名、给权限，以及装不上时最常见的三种情况。
> **相关文档**：[滤镜风格怎么选.md](滤镜风格怎么选.md) · [中文界面与订阅问答.md](中文界面与订阅问答.md)

## 一、安装前确认两件事

- **系统版本**：Prequel 要求较新的安卓系统，老机型先去「设置 → 关于手机」核对一眼，版本过低时即使装上也可能在启动或导出环节退出。
- **剩余空间**：安装过程要解压一份，加上后续编辑缓存，建议留出 500MB 以上空闲。

## 二、取回安装文件

安装包放在夸克网盘：打开分享页 → 转存到自己的网盘 → 从自己网盘下载到手机。转存后再下载比直接点原链接可靠，中途断了也能续传。下完在通知栏或文件管理器里能看到这个 `.apk` 文件。

图文版的取件入口在 [Prequel 下载安装页](https://prequel.fewf.ren/download.html)，页面里的按钮直接通向网盘分享地址。

## 三、安装步骤

1. 在通知栏或文件管理器里点开下载完成的 `.apk` 文件；
2. 首次安装会提示「不允许安装未知来源应用」——按提示进入「设置 → 应用 → 特殊应用权限 → 安装未知应用」，给当前用的浏览器或文件管理器勾一次允许；
3. 回到安装界面，确认应用名显示为 Prequel，点「安装」；
4. 等进度走完，点「打开」或回桌面进图标；
5. 第一次打开按提示给权限：照片与媒体（导入素材）、相机（应用内拍摄）、麦克风（视频录音）；其中「写入相册」建议放行，拒绝会导致编辑完保存失败——当时点了拒绝也能去系统设置补开。

## 四、装不上时对号这三种情况

| 现象 | 原因与处理 |
| --- | --- |
| 解析包出错 | 安装包没下完整，重新下载；别用第三方下载器续传后再装 |
| 提示「应用未安装」 | 手机里已有签名不同的同名应用，先卸载旧的再装 |
| 装完闪退 | 系统版本过低或内存不足：重启手机、清后台再开 |

## 五、装完第一件事

导入一张相册照片，套一个免费效果，拖动强度滑块，保存到相册确认——整条链路通了，再去研究订阅与 AI 效果也不迟。界面若默认英文，切换办法见 [中文界面与订阅问答.md](中文界面与订阅问答.md)。
