# Prequel 滤镜风格怎么选：五条主线看懂效果库

> 本篇讲 Prequel 效果库的挑选思路：按五条风格主线认方向，再按题材对号入座，最后用强度与叠加把效果调到自己想要的味道。
> **相关文档**：[安卓版怎么装.md](安卓版怎么装.md) · [中文界面与订阅问答.md](中文界面与订阅问答.md)

## 一、先认方向，再翻效果

Prequel 的效果库按风格分了几十类，数量口径在不同渠道说法不一，不必纠结总数。挑选时按五条主线去找，比按名字一个个翻快得多：

| 风格主线 | 典型效果 | 适合的题材 |
| --- | --- | --- |
| 复古胶片 | Film、Retro、Vintage、Lomography | 街拍、旅拍、人物肖像 |
| 千禧 Y2K | Y2K、Indie Kid、DISCO、PRISM | 夜景、闪光灯人像、穿搭图 |
| 电影感调色 | Cinematic、Teal、MIAMI | 风景、视频素材 |
| 磁带与故障 | VHS、Glitch | 短片段、有动态元素的素材 |
| 颗粒与质感 | Grain、Dust | 想要「拍出来」而非「修出来」的观感 |

翻效果时看到带小标识的条目，属于需要订阅的系列——先点开预览不受影响，看完效果再决定值不值得订。

## 二、强度是效果好不好看的第二一半

套上效果不等于结束。默认强度往往按「最明显」给，直接导出容易显得用力过猛：

1. 在效果上再点一下，调出强度滑块；
2. 往回拉到 60%~80%，多数场景比拉满自然；
3. 人像面部占画面比例大时，再降一档，避免肤色和背景一起偏色；
4. 海报、封面这类风格化场景可以拉满，追求的就是强烈。

## 三、叠加与预设的顺序

效果可以一层层叠：先套一条胶片定基调，再叠一层颗粒加质感，最后用文字或贴纸收尾。顺序影响观感——**先定色调、后加质感**比反过来稳定。

调出满意的组合后存成预设，同一场活动、同一套风格的账号配图直接复用；配合批量处理，一次最多能给十张照片套同一套设置。

## 四、按题材速查

- 日常记录与旅拍：复古胶片主线，强度七成；
- 夜店、演唱会、穿搭：Y2K 主线配闪光灯，可以拉满；
- 风景与 Vlog 视频：电影感调色，视频素材同样适用；
- 怀旧短片：VHS 或 Glitch，扫描线与色偏就是它的味道；
- 想要「什么都不做」的质感：只叠一层 Grain 或 Dust，强度压到三成以下。

效果名称里出现 D3D、Y2K 这类写法属于风格命名，不是显示异常。想按截图对照界面翻效果，[Prequel 滤镜图鉴站](https://prequel.fewf.ren/) 把五条主线的界面速览整理成了图文版，翻起来更直观。
