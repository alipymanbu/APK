# 安卓被控权限与连接排查

把安卓手机当被控端（让别人用电脑或另一台手机操作它）时，权限给到哪一层、连接卡在哪一步，是新手最常碰壁的两个点。这篇把权限分层与按现象排查的思路整理成一张"对号入座"的清单。

## 一、先分清"能看"和"能操作"

安卓给远程软件的权限是分层发的：

| 给的权限 | 对方能做的事 |
| --- | --- |
| 只给投屏（屏幕录制） | 看得到你的屏幕，点不了 |
| 投屏 + 无障碍（辅助功能） | 看得到，也能点击、输入、代你操作 |

临时让人"帮忙看一眼"只给投屏就够；要对方真正替你操作才开无障碍。这个权限很高，只对自己信得过的设备开，用完建议顺手关掉。

## 二、逐项权限在哪给

| 权限 | 在哪给 | 不给会怎样 |
| --- | --- | --- |
| 屏幕录制 / 投屏 | 首次发起被控时的系统弹窗 | 对方看不到画面 |
| 无障碍 / 辅助功能 | 系统设置的辅助功能服务列表 | 只能看，不能操作 |
| 电池白名单 / 后台运行 | 设置 → 电池（各品牌叫法不同） | 锁屏或切后台后连接就断 |

两个常见的坑：部分国产手机会定期自动关闭无障碍开关，怀疑时先去看开关还亮不亮；锁屏后连接中断，多半是电池优化杀了进程，把应用加进电池白名单再测。

### 安卓 13 的"受限设置"

安卓 13 起，凡是不经过应用商店、直接侧装 APK 的应用，系统默认禁止直接开无障碍：开关点了没反应，或弹"受限设置"提示。解法是长按桌面图标进应用信息 → 点右上角菜单 → "允许受限设置"，再回辅助功能列表开启。安卓 13 以下没有这道限制，开关点不动时先确认系统版本。

## 三、连接问题按现象对号

| 现象 | 先查什么 |
| --- | --- |
| 输入设备码提示找不到设备 | 被控端是否还开着；两端是否连的同一个服务 |
| 提示密码错误 | 大小写、前后空格；被控端是否刚改过密码 |
| 一直转圈连不上 | 切一次网络再试；P2P 打洞失败会走中继，中继不通就永远卡住 |
| 能连上但几秒就断 | 被控端进程被系统杀，回到上一节电池白名单 |
| 画面出来了但点不动 | 被控端权限没给全，回第一节补无障碍 |
| 白屏 / 花屏 / 卡顿 | 不是连接问题：逐个换视频编解码器，码率降到低于实测带宽 |

## 四、再进一步的自助手段

客户端支持自定义 API、WebSocket 与中继服务器地址，有服务器资源的可以把地址换成自己的；服务端与管理后台也都是独立的开源仓库，可以整套私有化部署。改完地址后做三层验证：能走到输密码（信令通）、能看到画面（打洞或中继通）、能点击操作（控制链路完整），哪层卡住就回上一步查地址与端口。
