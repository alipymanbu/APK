# 免费远控与商业远控的对比要点

挑远程桌面工具时，多数人先看三件事：免费版卡不卡脖子、画质与延迟够不够用、要不要为"手机被控"这类基础能力单独掏钱。这篇把 BilldDesk 与常见商业远控免费版的差异摆开，按需求对号入座。

## 一、免费版的"卡脖子"项目对比

商业远控的免费个人版通常在时长、画质、功能上分层设限。以某款常见商业远控的免费个人版为参照，BilldDesk 的对应能力都不设门槛：

| 能力 | BilldDesk | 商业远控免费个人版（典型口径） |
| --- | --- | --- |
| 连接时长 | 不限制 | 每月限时长与次数，单次限时 |
| 画质上限 | 不限制，可调至 8K 档位 | 最高 1080P / 30 帧 |
| 安卓被控 | 支持 | 多需购买专业版或插件 |
| 自定义设备码 | 支持 | 不支持 |
| 隐私屏 / 虚拟屏 | 支持 | 多为高阶付费档 |
| 网页端发起控制 | 支持 | 多需企业版 |
| 后台设备管理 | 支持 | 不支持 |
| 私有化部署 | 支持（开源） | 仅企业版 |

需要说明：这张表里的商业口径会随版本调整，买之前以其当前定价页为准；BilldDesk 一侧则是项目公开的功能清单口径。

## 二、它目前的短板也要知道

- **尚未发布稳定版**：项目仍在快速迭代，版本之间可能有破坏性改动，控制端与被控端建议保持同版本，"最新"不等于"更稳"。
- **一人开发的开源项目**：文档偶尔滞后于代码，遇到问题多翻项目的 issue 区。
- **游戏内键鼠**：未支持驱动级注入（Pro 版线有改进），在带风控的游戏窗口里键鼠可能不生效。

## 三、什么人适合它

1. 个人多设备用户：家里电脑 + 公司电脑 + 手机，想免费打通且不限时长。
2. 技术向用户：想要隐私屏、虚拟屏、屏幕墙这类原本要付费的能力，或想把自己的流量收回自己部署的服务器。
3. 小团队 / 工作室：需要批量管设备、群控操作，又不想按席位付月费。
