# IPTV播放器免费和付费差别

> 想知道 TiviMate 这类 IPTV 播放器的免费版是不是够用、付费到底买了什么，这篇把边界摆开讲。

## 先说结论

免费版不是几天就过期的试用版：一条播放源、直播频道、节目单、收藏，这些基础体验可以一直用。付费解锁的是重度使用的那几项——多个播放列表、录制、多画面同屏这类。要不要付，取决于你打算怎么用它，而不是「不付就不能看」。

## 免费版与付费版的功能边界

以 TiviMate 为例（综合多方公开资料整理，具体以应用内实际显示为准）：

| 功能 | 免费版 | 付费（Premium） |
| --- | --- | --- |
| 播放列表数量 | 1 个 | 不限 |
| 直播频道与节目单（EPG） | 有 | 有 |
| 频道收藏 | 有 | 有 |
| 录制到本地存储 | 无 | 有 |
| 多画面同屏（Multiview） | 无 | 有 |
| 回看播放（Catch-up）集成 | 基础 | 更完整 |
| 主题与界面个性化 | 有限 | 更多，含备份 |

只接一条源、看完直播就关的用法，免费版基本碰不到天花板；家里几条源要并存、或者想录像存节目，才是付费真正的适用场景。

## 付费怎么付、在哪个设备上操作

TiviMate 的购买入口不在电视端，而在 Android 手机上：

1. 手机装 TiviMate Companion 应用。
2. 在里面选套餐（年付或一次性买断）并登录 Google 账号支付。
3. 电视端的 TiviMate 登录同一个 Google 账号，Premium 自动解锁。

价格方面，第三方资料普遍写到年付 10 美元上下、另有买断档，实际随区域与渠道浮动，**以应用内显示为准**。一个授权最多同时绑 5 台设备，盒子多的家庭一般一份就够。

两点提醒：

- 付费解锁的只有软件功能，不含任何频道源；频道仍然要你自己准备。
- 网上有人卖远低于市场价的「已解锁」安装包，来路不明，装进电视盒子这种常驻联网的设备风险不小，不建议碰。
