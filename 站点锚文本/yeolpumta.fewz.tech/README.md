# Yeolpumta 目录：YPT 学习计时这件事，从哪看起

Yeolpumta（韩文原名 열품타，圈里常简称 YPT）是韩国 Pallo Inc. 做的学习计时应用：按科目开秒表、切走就停，配上群组、排名与月历统计，在备考圈里流传很广。这个目录把围绕它的常见搜索需求整理成几篇短文，按需取用。

- 想装到手机上：从 [安卓安装与中文设置](安卓安装与中文设置.md) 看起；
- 想知道计时怎么玩：看 [科目计时与专注模式怎么用](科目计时与专注模式怎么用.md)；
- 想拉人一起学：看 [群组自习与排名规则](群组自习与排名规则.md)。

三篇的汇总入口与界面截图在 [Yeolpumta 介绍站](https://yeolpumta.fewz.tech/)，一篇看完它的计时机制、群组玩法和新手起步路线。
