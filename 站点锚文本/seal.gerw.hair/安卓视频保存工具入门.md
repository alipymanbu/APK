# 安卓视频保存工具入门：认识 Seal

在手机上看到一条想留起来的视频，最顺手的路径是什么？对很多人来说答案是：装一个把「保存」做成本职工作的工具。Seal 就是这类工具里口碑比较稳的一个——它基于开源命令行引擎 yt-dlp，套上了一层适合手机的图形界面，让「贴链接 → 拿文件」这件事不用碰终端。

## 它的定位一句话说清

Seal 处理的是**公开可访问、且访问者有权查看的内容**：短视频平台、视频分享站、音频站、社媒平台的公开帖子，都在它擅长范围内；带版权保护的正版流媒体、需要登录的私有内容，则不在它的工作范围里——这是工具本身划定的边界，也是合理使用的前提。

## 为什么值得装

- **开源（GPL-3.0）**：源码公开在 GitHub 上，开发者是 JunkFood02，没有广告与内购；
- **引擎可持续**：站点改版是常态，yt-dlp 社区持续跟进，应用内一键更新引擎；
- **操作门槛低**：系统分享菜单里选一下，就能把链接递给它，全程四次点击以内；
- **功能有纵深**：音频抽取带封面、播放列表批量、字幕内嵌、aria2c 多路下载，进阶玩法都有。

## 装之前先知道的三件事

1. 它需要 Android 5.0 及以上，安装包体积约 41 MB；
2. 首次安装非应用商店来源的包，需要在系统设置里允许对应来源；
3. 装好第一次打开时，把存储权限给足，文件才能落到你能找到的目录。

想了解具体的操作路径，可以接着读[从链接到文件的操作步骤](从链接到文件的操作步骤.md)；装的过程中碰到拦截或报错，[下载失败与文件查找排查](下载失败与文件查找排查.md)按现象给了处理顺序。工具的完整介绍与界面截图，见 [seal](https://seal.gerw.hair/) 说明站。
