# 下载失败与文件查找：Seal 问题排查顺序

用下载类工具，总会遇到两类「卡住」：一是任务报错没下成，二是显示完成了却找不到文件。这两类问题的处理思路完全不同，分开说。

## 一、任务失败：先更新引擎，再对号入座

**第一动作永远是更新 yt-dlp**（设置 → 通用 → 更新 yt-dlp）。站点几乎每周都在改版，抓取能力跟着引擎走，大部分「昨天还好好的、今天集体失灵」更新完就恢复。更新后仍失败的，按现象处理：

| 现象 | 处理方向 |
| --- | --- |
| HTTP 403 | 站点访问校验收紧：换一段网络稍后再试，别连续高频重试 |
| 要求登录确认不是机器人 | 隔一段时间再试；批量任务拆小、拉长间隔 |
| 请求的格式不可用 | 回面板换「自动」或更低档位，该站点没提供你选的那档 |
| 下完的视频没声音 | 合并环节出岔子：更新引擎重下，或降一档清晰度 |
| 列表只下了几个就停 | 触发站点频控：拆批、放慢节奏，失败条目单独重试 |
| 大文件下到一半断 | 「设置 → 网络」里打开 aria2c 外部下载器，多连接加续传更稳 |

判断「该等还是该动手」的经验：单个链接失败是链接本身的问题；所有链接同时失败多半是站点改版，更新引擎或等几天；只有批量任务失败就是频控，放慢。

## 二、文件找不到：按目录顺序翻

任务显示完成、文件管理器里却没有——先打开 Seal 的「设置 → 下载文件夹」**抄下实际路径**，然后按命中率从高到低找：

1. 设置里写的那个路径；
2. 内部存储 `Movies/`；
3. 内部存储 `Download/`；
4. `DCIM/`、`Pictures/`；
5. `Android/media/`。

翻不到就用扩展名搜索：视频搜 `.mp4`、`.mkv`，音频搜 `.mp3`、`.m4a`。文件在、相册不显示，是媒体库没刷新——重启手机让相册重扫即可。根本没写进去的，回系统设置确认 Seal 的存储权限是允许状态。

## 三、一劳永逸的两个设置

- **保存目录固定到标准位置**（Movies / Download），相册、文件管理器、电脑连接都认得到；别放 `Android/data/` 这类应用私有目录，普通文件浏览器打不开；
- **文件名输出模板**按「标题-作者」这类规则设好，几十个文件的批量任务才不会乱。

安装环节的问题（来源被拦、签名冲突、架构不兼容）在[安卓视频保存工具入门](安卓视频保存工具入门.md)里有说明；日常操作流程见[从链接到文件的操作步骤](从链接到文件的操作步骤.md)。两项排查做完还想对照界面找入口，[seal](https://seal.gerw.hair/) 站内的截图可以当参照。
