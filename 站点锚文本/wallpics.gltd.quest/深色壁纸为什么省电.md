# 深色壁纸为什么省电：AMOLED 屏的发光原理与取舍

「深色壁纸省电」这句话流传很广，但它有明确的前提：**屏幕得是 OLED / AMOLED 面板**，
而且深得够彻底。这篇把原理、适用范围和实际取舍讲清楚。

## 一、原理：黑色像素不发光

LCD 屏幕靠一整块背光板照亮所有像素，显示什么颜色，背光都一样亮，所以换深色壁纸几乎不省电。
OLED / AMOLED 不一样——每个像素自己发光，显示纯黑（RGB 全 0）时像素**直接熄灭、不耗电**。

大面积纯黑画面意味着大量像素处于熄灭状态，屏幕整体功耗随之下降。这也是「AMOLED 深色壁纸」
作为一个独立题材存在的原因：它不只是审美选择，还是 OLED 设备上真实可测的省电手段。

## 二、两个前提

1. **面板得是 OLED / AMOLED**。LCD 设备上换深色壁纸只有观感变化，没有电量收益
   （设置 → 显示 里看有没有「深色模式增强 / AOD」相关选项，或查机型参数确认面板类型）；
2. **黑得越纯收益越大**。深灰、带纹理的深色图也有收益，但不及纯黑；
   壁纸里亮部（文字、光效、人物）越多，收益越打折扣。

## 三、深色 + 静态，是收益最大的一档

把「深色」和「静态」叠在一起，是壁纸这条耗电线上收益最大的组合——既熄灭大量像素，
又免掉了动态渲染的开销。多份实测给出的参照：近几年的中高端机，动态壁纸比静态每天多耗
1%~3%，视频循环类差距能到两位数（数据与两天自测法见 [动态壁纸耗电吗](动态壁纸耗电吗.md)）。

动态爱好者也有折中方案：**视差类壁纸**（倾斜手机时画面分层位移）只在桌面可见时产生少量
计算，比全程动画省电，还能保留"会动"的质感。

## 四、怎么挑一张合格的深色壁纸

- 题材上直接进「AMOLED 深色 / 深色」分类，避免在大库里翻；
- 优先纯黑底 + 少量主体（一只猫、一轮月、一行字）的构图，亮部越少越省；
- 锁屏同样换成深色静态——锁屏被通知点亮的次数比桌面多，收益更高；
- 挑好后在电池用量里观察一两天，确认变化符合预期。
