# Wallpics 站点导读

这里收录与 Wallpics（安卓动态壁纸应用）相关的中文整理文章：它能把手机桌面换成会动的 4K 画面，
也支持倾斜手机时分层移动的视差壁纸、纯黑省电的 AMOLED 深色主题，以及 DIY 壁纸工坊与充电动画。
本目录的几篇文章按真实使用场景组织——从挑题材、设置壁纸，到耗电实测与充电动画的开启方法。

想直接看这个应用的完整介绍与安装文件资源入口，可以访问
[Wallpics 动态壁纸](https://wallpics.gltd.quest/)专题页。
