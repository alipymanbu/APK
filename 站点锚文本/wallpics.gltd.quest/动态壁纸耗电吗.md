# 动态壁纸耗电吗：先看实测区间，再动设置

给手机换上会动的背景之前，最常见的顾虑就是费电。把公开实测的数据汇总在前面，结论其实是：
动态壁纸比静态图费电，但**费多少取决于壁纸怎么动**，而不是"动态"两个字本身。

## 一、几个可以参考的数字

多份独立测试（机型、亮度、壁纸类型各不相同）给出的区间大致是：

| 情况 | 每天比静态多耗 |
| --- | --- |
| 2021 年后的中高端机，用优化过的动态壁纸 | 1%~3% |
| 老机型或入门机 | 5%~10% |
| 视频循环类壁纸（整段视频反复解码） | 差距能拉到两位数 |

另有一条有用的参照：暗色基调、小面积光点的动画，比亮色满屏的视频壁纸省电约 40%。

为什么差距这么大？因为安卓在熄屏、以及全屏应用盖住桌面时都会暂停壁纸渲染——
真正费电的只有「桌面亮着的那段时间」。视频循环类在这一小段时间里持续解码，代价自然高。

## 二、两天对比法，测自己那台

与其纠结哪个数字可信，不如用系统自带功能实测：

1. 第一天用静态壁纸正常使用，晚上在 设置 → 电池 → 电池用量 里记下掉电曲线；
2. 第二天换成动态壁纸，尽量复刻同样的用法；
3. 差 5% 以内随便用；5%~10% 建议出门前换回静态；超过 10% 就换掉这张壁纸。

顺带看一眼电池用量排行榜，这类壁纸应用没进前几名，就说明它不是耗电源头。

## 三、想省电，按收益从大到小动这几下

1. **换静态深色壁纸**——AMOLED 屏显示纯黑时像素不发光，这是壁纸里收益最大的一招
   （原理见 [深色壁纸为什么省电](深色壁纸为什么省电.md)）；
2. **动态只设主屏，锁屏用静态**——锁屏整天被通知点亮，动画渲染时间远比桌面长；
3. **挑「慢动」不挑「视频循环」**——粒子缓慢飘、小幅位移最省；
4. **省电模式自动降档**——多数手机进省电模式会压低壁纸刷新。
