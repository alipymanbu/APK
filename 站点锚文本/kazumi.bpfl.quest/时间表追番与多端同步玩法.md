# 时间表追番与多端同步玩法

> 这篇讲 Kazumi 的追番动线：时间表怎么挑番、追番列表和更新提醒怎么用，以及 WebDAV 同步、一起看、以图搜番这些多设备玩法。
> **相关文档**：[自定义规则导入与XPath编写入门.md](自定义规则导入与XPath编写入门.md) · [弹幕超分与播放设置调优.md](弹幕超分与播放设置调优.md)

---

## 一、时间表：按星期挑番，评分挂在角标上

「时间表」页把当季新番按周一到周日排开，番剧元数据来自 Bangumi 开放 API，条目右上角带社区评分角标——先扫一遍分数再点开，能省掉不少试错。

底部导航的「推荐」栏另有标签筛选（日常、原创、校园、搞笑……），适合没有明确目标、随便逛的场景。整套动线的图文版在 [Kazumi 追番动线介绍](https://kazumi.bpfl.quest/)，装好应用前可以先看一眼。

## 二、追番列表与更新提醒

在看的番收进「追番」栏，应用盯着更新并在有新集数时提醒你，不用每周手动去搜。历史记录则按观看进度记，播到哪一集、第几分钟都记得住。

数据默认只存在本机，不需要注册账号——这也是后面同步玩法的起点：换设备时数据不会自动跟着走，要靠 WebDAV。

## 三、WebDAV：把观看进度带到下一台设备

观看历史与追番数据支持通过 WebDAV 同步，NAS 或支持该协议的网盘都能当同步端。两端配好同一个地址后，桌面看到一半、手机地铁上接着看，进度是对得上的。

两个值得记住的点：

- **覆盖升级不清数据**：同包名直接装新版本，追番、历史、规则都还在；
- **卸载等于清空**：本机数据没有云端备份时，卸载应用前先把 WebDAV 配好。

## 四、一起看与以图搜番

- **一起看**：基于 SyncPlay 协议与公共服务器实现，朋友进同一个房间后，每个人的播放进度被钉在同一秒，暂停、拖动全员同步；
- **以图搜番**：接入 trace.moe 的图片识别，把截图丢进去就能查出番名——刷视频刷到一段画面、不知道出处时特别好用。

## 五、平台清单

一套数据、多个设备都能接：

| 平台 | 要求 | 备注 |
| --- | --- | --- |
| Android | 10 及以上 | 多数人的安装入口 |
| Windows | 10 及以上 | 桌面端 |
| macOS | 10.15 及以上 | 桌面端 |
| Linux | — | 实验性支持 |
| iOS | 13 及以上 | 需侧载安装 |
| HarmonyOS | 5.0 及以上 | 走分支仓库，需侧载 |

侧载与分支仓库的发布细节，以项目 GitHub Releases 页当时显示为准。各平台的播放参数调优，见 [弹幕超分与播放设置调优.md](弹幕超分与播放设置调优.md)。
