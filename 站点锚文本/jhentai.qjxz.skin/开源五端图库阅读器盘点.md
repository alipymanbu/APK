# JHenTai 是什么：一个装进五端的开源图库阅读器

> 本篇讲 JHenTai 的项目来历、能装在哪些设备、界面布局怎么适配屏幕，以及它和常见漫画阅读应用的差别。
> **相关文档**：[手机安装与中文设置.md](手机安装与中文设置.md) · [下载配额与登录问题解答.md](下载配额与登录问题解答.md)

## 一、项目来历

JHenTai 是一位开发者用 Flutter 写的开源项目，最初的目的很简单：作者自己用安卓手机、iPad 和 Windows 电脑，当时市面上的同类阅读应用毛病不少，源码又看不懂，索性自己动手写一个。项目从 2022 年持续更新到现在，源码和全部安装包都挂在 GitHub 仓库的 releases 页面，谁都可以下载、审阅、提交建议。

用 Flutter 做跨端开发的好处在这里体现得很直接：同一份代码打出 Android、iOS、Windows、macOS、Linux 五个平台的安装包，功能几乎完全一致，在一台设备上养成的使用习惯，换台设备不用重新学。

## 二、能装在哪里

五个平台的安装方式各不相同，安卓最直接——就是一个普通 APK：

| 平台 | 安装方式 | 一句话提醒 |
| --- | --- | --- |
| Android | 按手机架构选 APK 直接安装 | 近几年的手机选 arm64-v8a |
| iOS | 下载 ipa 后用 AltStore 等工具签名 | 加上 AltStore 源后更新更省事 |
| Windows | 下载 zip 解压，双击运行 | 要用代理就在应用的网络设置页填 |
| macOS | 下载 dmg 安装 | 需在系统设置里信任；该平台已停更 |
| Linux | deb 或 AppImage 二选一 | 可能要先补 webkit2gtk-4.1；已停更 |

具体的下载与安装步骤，[手机安装与中文设置.md](手机安装与中文设置.md) 里按顺序列了四步。

## 三、界面跟着屏幕走

JHenTai 内置了三套布局，按设备尺寸自动切换，不用手动配置：

- **手机布局**：底部标签栏加列表，单手够得到全部入口；
- **平板布局**：左右分栏，左侧导航、右侧内容，横竖屏都撑得满；
- **桌面布局**：窗口化排版，键盘鼠标操作，列表与详情左右并排。

阅读页另有四种排版可切（垂直滚动、水平翻页、双列等），条漫和页漫各有合适读法，阅读时随时换。

## 四、几件核心能力

- **下载管理**：任务分组、手动调优先级，中断或重装后能恢复任务；整包下载方式不占按张计的配额，大部头优先走它；
- **过滤体系**：搜索漏斗、本地标签屏蔽、账号 My Tags、站点设置四层各管一段，不想看的内容层层设防；
- **本地阅读**：手机里已有的压缩包漫画直接丢给它打开，不联网也能翻；
- **隐私与迁移**：指纹解锁防翻看；换机前导出数据、装回后导入，下载产物还自动带 ComicInfo.xml 元数据，接进漫画管理工具不断档。

功能盘点的完整版（配三套布局的真实截图）放在 [JHenTai 介绍站](https://jhentai.qjxz.skin/)上，看完再决定装不装也不迟。

## 五、上手顺序建议

第一次装好先做两件事：把界面切成简体中文（[手机安装与中文设置.md](手机安装与中文设置.md)），再按需登录账号。之后碰到加载超时、图片打不开、登录 403 这类问题，直接翻 [下载配额与登录问题解答.md](下载配额与登录问题解答.md) 对症处理。
