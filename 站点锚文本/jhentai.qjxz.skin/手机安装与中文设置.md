# JHenTai 手机安装与中文设置

> 本篇讲安卓手机从转存到打开应用的完整安装流程、安装包架构怎么选，以及装完后把界面切成简体中文的四步。
> **相关文档**：[开源五端图库阅读器盘点.md](开源五端图库阅读器盘点.md) · [下载配额与登录问题解答.md](下载配额与登录问题解答.md)

## 一、装前先弄清两件事

JHenTai 没有上架任何应用商店，安卓版就是一个普通 APK，从项目仓库的 releases 页面或整理好的资源页获取。装它不需要特殊环境，只需给「安装未知来源应用」放行——这是所有商店外 APK 都要过的一关，不是这个应用的特殊要求。

安装包很小（当前一版约 13.55M），老旧机型也不用担心跑不动。

## 二、四步装到手机上

1. **打开资源页转存**：在[JHenTai 安装资源整理页](https://jhentai.qjxz.skin/)拿到安装文件资源的网盘入口，先把资源转存到自己的网盘账户，再从网盘下载 APK 到手机；
2. **点开 APK**：下载完成后点开文件，系统弹出「是否允许安装未知来源应用」时选择允许（不同品牌入口略有差异，一般在 设置 → 安全 → 安装未知应用）；
3. **等安装完成**：十几秒的事，期间不用任何额外操作；
4. **打开应用**：首次启动是英文界面——正常，下一节四步切成中文。

## 三、从 releases 自取时怎么选架构

如果直接从项目仓库的 releases 页面下载，会看到按处理器架构拆分的多个 APK：

- `arm64-v8a`：近几年的主流安卓手机（第 8 代 ARM 架构），绝大多数人选这个；
- `armeabi-v7a`：老一点的手机（第 7 代 ARM 架构）；
- `x86_64`：Intel/AMD 处理器的设备，极少见。

不确定自己手机是哪种就先试 arm64-v8a，装不上再换。

## 四、四步切回简体中文

应用内置了简体中文语言包，只是首次启动默认跟随英文：

1. 打开应用，点右下角（或侧边栏）的**设置**图标；
2. 进入 **Preference**（偏好设置）；
3. 点第一项 **Language**（语言）；
4. 列表里选 **简体中文**，立即生效。

个别页面残留英文时，把应用完全退掉再开一次即可。
