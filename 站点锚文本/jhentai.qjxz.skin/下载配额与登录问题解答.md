# JHenTai 下载配额与登录问题解答

> 本篇按报错原文逐条给排查动作：登录 403、Sad Panda 无数据、下载触发 509 配额、列表加载超时。
> **相关文档**：[手机安装与中文设置.md](手机安装与中文设置.md) · [开源五端图库阅读器盘点.md](开源五端图库阅读器盘点.md)

## 一、登录报 403：别反复试密码

应用支持三种登录方式：网页登录、账号密码登录、Cookie 登录。项目问答区给过明确结论：站点侧开启防护后，**账号密码与 Cookie 两种方式会返回 403，改用网页登录即可**——在应用内打开的网页里完成授权，一次就能过。

三种方式都在 403 与超时之间反复时，问题多半出在网络环境本身，先换网络或代理节点再试。

## 二、Sad Panda: No data 是怎么回事

画廊加载不出、提示 `Sad Panda: No data`，但同一账号在网页端正常——按项目 Wiki 的顺序排查：

1. **账号没有 EX 站权限**：受限画廊只有具备权限的账号能看，先确认账号状态；
2. **Cookie 里的 `igneous` 值异常**：账号密码登录那一刻网络环境不干净，拿到的 Cookie 可能是空的。到设置的 EH 相关页检查，异常就退出登录、换个稳定网络重新登录；
3. **Cookie 过期**：重新登录一遍；
4. **换网络再试**：以上都无效时换个代理节点。

另外把设置里的 `Redirect to EH if available` 打开，受限画廊在 EH 打不开时自动转去 EX 加载，能减少「网页能看、应用里打不开」的情况。

## 三、下载触发 509：配额用完了

`Exceed Image Limits`（509）是图片配额耗尽的提示——按张计的配额随浏览与下载消耗。缓解思路三条：

- **大部头改走 Archive 整包**：用站点内货币换整包，不占按张计的配额，下完自动解包直接读；
- **调低预加载数**：减少无效消耗，同一时间加载的图越少越省；
- **等额度恢复**：额度随时间回涨，恢复后接着下，已下载的页不用从头点。

当前剩余额度在 `设置 → EH` 里查看。

## 四、列表一直 Connect Timeout

画廊列表反复报连接或接收数据超时，按四步来：

1. 换代理节点、换网络条件试一次；
2. 网络确实慢，到 `设置 → 网络设置` 把超时时间调大；
3. 在网络设置里**关闭 domain fronting（域前置）**开关再试；
4. 仍不行，把报错里的英文原文对着看——那是站点直接给出的访问限制说明，按其说法处理。

桌面版用户注意：代理地址要填在应用的网络设置页，不是系统代理。图片直链本身有有效期（节点直链最短十几分钟），所以个别图片一直转圈时，**长按那张图触发重新解析**通常就能好。

## 五、搜索结果和网页端对不上

多数是过滤器在起作用，按快到慢查四处：搜索页右上角的漏斗、`设置 → 偏好 → Local Tag Filtering`、`设置 → EH Setting → My Tags`、`设置 → EH Setting → Site Settings`。漏斗最常被自己忘掉，先看它。按日期搜索时间对不上是时区换算——站点只认 UTC，应用里可把「画廊时间按 UTC 显示」的开关打开对齐口径。

这些功能点的全貌与三套界面布局的截图，都收在[JHenTai 介绍站](https://jhentai.qjxz.skin/)里；还没装好的先看[手机安装与中文设置.md](手机安装与中文设置.md)。
