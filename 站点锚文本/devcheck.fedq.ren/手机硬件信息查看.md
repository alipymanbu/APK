# 手机硬件信息查看

> 用 DevCheck 把安卓手机的真实配置一层层读出来：十个分区各管什么、哪些字段天生是空的、想多读一些要开什么权限。
> **相关文档**：[电池健康与循环次数查看.md](电池健康与循环次数查看.md) · [二手手机验机清单.md](二手手机验机清单.md)

---

## 一、为什么不用「关于手机」

系统设置里的「关于手机」是厂商写的招牌，可以想写什么写什么；而 DevCheck 读的是硬件驱动自己上报的数据——处理器、GPU、内存、存储、屏幕、电池、相机、传感器、网络，每一项都来自设备本身。装好它，就像给手机打开了一块仪表台：[DevCheck 介绍站](https://devcheck.fedq.ren/) 上有每个分区的逐页读法。

## 二、十个分区各读什么

| 分区 | 能看到什么 |
| --- | --- |
| 仪表盘 | CPU 频率、内存占用、电池状态、深度休眠与开机时长，实时刷新 |
| 硬件 | 芯片型号与工艺、大小核配置、GPU、内存类型与带宽、存储、屏幕参数 |
| 系统 | 设备代号、Android 版本、安全补丁级别、内核、root / BusyBox / KNOX 状态 |
| 电池 | 温度、电压、电流、功率、容量，进阶可看循环次数与健康度 |
| 网络 | IPv4 / IPv6、运营商、信号强度、公共 IP，双卡分开列出 |
| 应用 | 已装应用与运行中应用的详情 |
| 相机 | 光圈、焦距、ISO 范围、RAW 能力、每颗镜头的实际输出分辨率 |
| 传感器 | 全部传感器列表与实时曲线（加速度计、陀螺仪、气压计都能画波形） |
| 测试 | 手电筒、振动、按键、多点触控、屏幕等硬件测试 |
| 工具 | Root 检查、CPU 分析、蓝牙扫描；Pro 解锁完整性检查、Wi-Fi 扫描等 |

日常查配置，重点翻**硬件**与**系统**两页；盯性能表现，看**仪表盘**；排查网络与信号，截**网络**页。

## 三、哪些字段天生是空的

安卓不会把所有硬件细节开放给应用，各品牌的上报口径也不一致。DevCheck 的取舍是对「几台机器对不上」的字段宁可空着也不猜，所以：

- 温度读不到：很多厂商（联发科平台尤其普遍）把温度传感器对普通应用屏蔽；
- 电池循环次数、健康度空白：同样多见于厂商未开放的机型；
- CPU 负载、GPU 频率等细项缺失：需要更高权限才读得到。

这些都**不是安装包的问题**，换工具也解决不了——门槛在系统权限上。

## 四、想多读一些：两条路

1. **装 Shizuku**：免费开源工具，不 root、不改系统，Android 11 以上用「无线调试」配对即可启动。DevCheck 检测到它在运行会自动多读一批数据（温度、循环次数、健康度、CPU 负载等）。
2. **给 root 权限**：已 root 的机器在 DevCheck 右上角菜单里授权一次即可，能解锁的细项比 Shizuku 更多。

两条路都可撤销，不想用了随时收回权限。

## 五、装好之后

应用无广告，查看信息全部免费；跑分实验室、悬浮监视窗、桌面小组件属于付费的 Pro 部分，日常使用用不到也完全不影响。安装包获取入口与分步安装说明见 [DevCheck 介绍站](https://devcheck.fedq.ren/)。
