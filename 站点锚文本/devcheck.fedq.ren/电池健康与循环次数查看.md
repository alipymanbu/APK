# 电池健康与循环次数查看

> 电池页每个字段什么意思、循环次数的入口藏在哪、为什么你的手机什么都不显示——一次讲清。
> **相关文档**：[手机硬件信息查看.md](手机硬件信息查看.md) · [二手手机验机清单.md](二手手机验机清单.md)

## 一、电池页的字段

DevCheck 的电池页实时刷新这些读数，全部来自电池驱动的原始上报，不做二次换算：

| 字段 | 含义 |
| --- | --- |
| 状态 | 充电中 / 已充满 / 放电中 |
| 电量、技术 | 当前百分比、电池化学类型 |
| 温度、健康 | 电池温度、健康状态 |
| 电压、电流、功率 | 实时电气参数，充电时看这三个 |
| 容量 | 当前可用电量的估算值 |

## 二、循环次数在哪看

入口不在电池页的主列表里：进电池页 → 点右上角**齿轮图标** → 电池设置里找循环次数（不同版本入口略有差别，以实际界面为准）。前提是手机肯把这个数开放给应用——看不到时先读下一节。

## 三、为什么你看不到

问得最多的就是这条，原因基本固定：

1. **厂商对应用隐藏了字段**：不少机型不把循环次数、健康度开放给普通应用，DevCheck 只能显示手机给它的；
2. **装 Shizuku 能解开一大半**：免费、免 root、不改系统，运行时打开 DevCheck 会自动多读循环次数、健康度与估算容量；
3. **健康度常常要充满一次才出现**：不少机型充到 100% 之后才显示；
4. **双电芯机型可能永远不给**：小米、POCO 这类双电池方案，读不到准确数据时干脆不显示容量估算——显示一个错的比不显示更糟；
5. **少数机型对任何应用都不开放**：这种换哪个工具都读不到，不是 DevCheck 的问题。

## 四、充电电流「不对」是正常的

快充时电流或功率常低于充电器标称值，别急着怀疑数据错了：有的机型测的是电池端而非充电端；双电芯机型可能只报其中一格；有的机型刷新慢，看到的是几秒前的读数。所以这三个数**看趋势**（插电后是否上来、拔电后是否归零）比用绝对值较真更靠谱。

## 五、在哪下这个工具

DevCheck 应用内无广告，电池与硬件信息查看全部免费。获取入口、版本与安装步骤都整理在 [DevCheck 介绍站](https://devcheck.fedq.ren/)，装好后按上面第二节的路径直接进电池设置。
