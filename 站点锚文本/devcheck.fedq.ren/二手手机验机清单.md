# 二手手机验机清单

> 买二手机、翻新机时，用 DevCheck 把卖家说的配置和硬件实际报的数据逐项对一遍——六处硬指标，一张表跑完。
> **相关文档**：[手机硬件信息查看.md](手机硬件信息查看.md) · [电池健康与循环次数查看.md](电池健康与循环次数查看.md)

---

## 一、这套方法为什么管用

山寨机、改标机可以把「关于手机」里的型号随便写成旗舰，但处理器、内存、存储这些硬件本身报出来的数据改不了。装上 DevCheck，看到的就是硬件一侧的说法，拿它和卖家的宣传逐项对照即可。工具的介绍与获取入口见 [DevCheck 介绍站](https://devcheck.fedq.ren/)。

## 二、六处硬指标对照表

| 检查项 | 在哪看 | 什么情况要警惕 |
| --- | --- | --- |
| SoC / GPU 型号 | 硬件页 | 与宣传的芯片对不上，或标旗舰却是低端芯片 |
| 核心数与大小核配置 | 硬件页 | 核心数量、架构与该芯片应有的规格不符 |
| 内存容量 | 硬件页 | 明显小于宣传值 |
| 存储容量 | 硬件页 | 与宣传差一档（扩容盘常见） |
| Android 版本与安全补丁 | 系统页 | 落后于宣传、日期异常久远 |
| root / 解锁状态 | 系统页 | 与卖家描述不符 |

一张表跑完，心里就有数了。相机那页的镜头数与像素经常对不上宣传——多摄常被合并成「逻辑相机」上报、宣传像素也不是上报给应用的值，所以**相机不作为硬指标**，以前四行和系统页为准。

## 三、存储容量先扣两笔正常损耗

容量厂商标「128G」按 1G=1000MB 算，系统按 1G=1024MB 显示，光换算就少一截；系统与预装应用还要占掉十几 G。所以标 128G 实际可用 110G 上下属于正常，**差得多（比如只剩八九十 G 以下还对不上系统占用）才按扩容盘怀疑**。

## 四、顺手做的三个补充检查

- **电池循环次数**：进电池页设置里看（部分机型需要 Shizuku），循环数异常高的「准新机」要留心，读法见 [电池健康与循环次数查看.md](电池健康与循环次数查看.md)；
- **气密性参考测试**：传感器页点开气压计，按压屏幕看曲线是否起伏，能对拆修与否做个粗略参考；
- **硬件测试**：测试页跑一遍屏幕、多点触控、振动、听筒，当场暴露暗病。

## 五、两条提醒

1. 少数情况下 DevCheck 显示的设备营销名会认错（营销名是从标识符匹配出来的，马甲芯片、区域变体都可能带偏）——**型号名错了不等于机器是假的**，仍以第二节硬件数据为准；
2. 各机型能读出的字段多少不一，缺几项是常态；关键三项（SoC、内存、存储）读得全，验机就够用了。
