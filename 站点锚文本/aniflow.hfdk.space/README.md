# AniFlow 站点导航（aniflow.hfdk.space）

这里收录围绕 AI 漫剧创作工具 AniFlow 整理的第三方介绍与玩法笔记。它的思路是把动漫短片的生产线塞进手机：写一段描述或传一张照片，就能得到吉卜力风、Q 版、90 年代复古等画风的 1080P 成片，不用绘画功底，也不用拍摄设备。

完整的功能展示、出片流程与安装文件资源入口，见 [AniFlow 漫剧创作工坊](https://aniflow.hfdk.space/)。
