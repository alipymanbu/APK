# 安卓上怎么把它用顺手

> 本篇面向已经装好（或正打算装）DuckDuckGo 安卓版的用户：从设默认浏览器、迁移旧数据，到应用追踪防护与火焰按钮，把几处关键设置一次过完。

## 装完第一件事：设成默认浏览器

进 **系统设置 → 应用 → 默认应用 → 浏览器应用** 选 DuckDuckGo；也可以在它自己的 **设置 → 默认浏览器** 里一键跳转。设完之后，其他应用里点开的链接都会落到它那里，防护才开始覆盖日常浏览。

## 第二件事：把旧数据搬过来

入口在 **设置 → 导入**，按提示从 Chrome 等浏览器迁移书签与密码，不用手动一条条抄。多设备之间如需持续同步，可在设置里开启加密同步。

## 第三件事：认识两个特色开关

**应用追踪防护**：普通浏览器只管网页里的追踪，这项能力往下多管一层——检查设备上其他应用的流量，拦下其中隐藏的追踪请求。它借助系统的本地 VPN 通道实现，数据不出设备，不需要额外装任何东西。开启入口在设置里，首次打开会有几步引导。

**火焰按钮**：标签栏上的火焰图标，点一下清掉标签页与浏览数据，公用设备或临时借机场景很好用。常登录、不想被清掉登录状态的网站，可在该站点页面选择「加入防火站点」。

## 日常使用的小习惯

1. 地址栏旁的**盾牌图标**值得常点开看：这个页面拦了什么、加密是否生效一目了然；个别网站功能被拦坏时，也在那里按站点放宽，改完只影响这一个站。
2. Cookie 同意弹窗默认会被自动处理，偏隐私的选项替你点掉，不用每次手动选。
3. 想要更干净的搜索入口，可把浏览器内的默认搜索引擎保持为 DuckDuckGo，搜索词不进画像。
