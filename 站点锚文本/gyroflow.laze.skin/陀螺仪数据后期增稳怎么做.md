# 陀螺仪数据后期增稳怎么做

> 拍运动相机、无人机素材时，机内防抖力度不够或干脆没开，事后还有救吗——聊聊以陀螺仪数据为核心的后期增稳路线，以及这条路上最常被提到的工具 Gyroflow。
> **相关文档**：[手机拍的视频太抖怎么补救](手机拍的视频太抖怎么补救.md)

## 一、后期增稳和机内防抖差在哪

机内电子防抖（EIS）是拍摄当下实时裁切补偿，拍完即所得，但强度写死在机器里；后期增稳则是在时间轴上「翻旧账」——按陀螺仪记录的真实运动轨迹逐帧反推相机的姿态变化，再对画面做反向补偿。两条路线不冲突，后者最大的价值是**参数可调、随时重跑**：同一份素材，想要「贴地飞行」式的死稳还是保留呼吸感的轻稳，各导一遍就行。

Gyroflow 是这条路线里比较有代表性的开源工具（GPLv3 许可，跨 Windows / macOS / Linux / Android / iOS），它把这套流程拆成了三个环节：数据读取、镜头校正、稳定导出，预览区全走 GPU 加速，拖动滑杆立刻能看到效果。想快速了解它支持哪些机型、功能都有什么，可以看这份整理：[Gyroflow 后期增稳工具介绍](https://gyroflow.laze.skin/)。

## 二、第一步：确认素材里有没有运动数据

后期增稳的原料是「拍摄时记录的陀螺仪数据」，所以动手前先确认素材带没带料：

- **内嵌数据**：GoPro HERO 5 及之后、DJI Action / Avata / Neo 系列、Insta360 OneR / GO / Ace 系列、Sony a7 / FX / ZV 部分机型，都会把陀螺仪数据直接写进视频文件，导进工具就能读；
- **外挂日志**：无人机飞控的 Betaflight 黑盒、ArduPilot 日志，或用另一台设备（运动相机、手机 + 传感器记录应用）绑在机身上当记录器，录成 .gcsv / CSV 事后挂载；
- **完全没有数据**：只能走光流估算的简化模式，效果对得起「轻晃」，撑不起剧烈运动。

有两个容易踩的记录条件：DJI 机型要**关闭机内防抖、FOV 选 Wide** 档才会把数据写进文件；GoPro 与 DJI 单文件到 4GB 会分段，各段各带各的数据，后期要按序列一起处理。

## 三、第二步：镜头配置与同步

数据就位后，工具需要知道这颗镜头的畸变长什么样才能正确去畸变——热门机型有内置配置文件自动加载；冷门组合拍一段棋盘格标定视频就能自制。接着做**同步**：把数据时间轴和画面时间轴对齐，自动同步点一下通常就够；两个设备分开开机记录时，时间差可能超出默认搜索窗口，手动填个大致偏移再同步是常规操作。同步没对齐的典型症状是稳完反而出现「反向拉扯」，这时候先回同步，别急着调平滑度。

## 四、第三步：稳定参数与导出

稳定环节几个关键旋钮：

- **平滑度**：低则保留原始运动感，高则接近云台的死稳，越高越吃裁切余量；
- **视场角**：小于 1.0 是放大裁切、画面更稳但构图缩水，保持 1.0 配合平滑度调是常见用法；
- **地平线锁定**：强制地平线水平，航拍素材尤其好用；
- **滚动快门校正**：快速横摇、高速飞行素材的果冻效应对症药。

导出环节选好编码（H.264 / H.265 走 GPU 加速）与输出尺寸即可，导完把成片拖回预览复检一遍，不满意回参数页重跑——这正是后期增稳相对机内防抖最奢侈的地方。
