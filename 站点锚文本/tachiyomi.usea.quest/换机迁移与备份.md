# 换机迁移与备份

> 本篇讲怎么把书架与阅读进度打包带走：备份里存了什么、换机怎么恢复、哪些东西要单独拷。
> **相关文档**：[扩展源安装与书架搭建.md](扩展源安装与书架搭建.md) · [停更后的分支怎么选.md](停更后的分支怎么选.md) · [为什么选开源漫画阅读器.md](为什么选开源漫画阅读器.md)

## 一、备份文件里有什么

「更多 → 设置 → 备份与恢复 → 创建备份」，勾选要包含的内容后生成一个 `.tachibk` 文件（早期版本显示为 `.proto.gz`）。里面装着：

- 书架列表与分类；
- 每部作品的阅读进度、已读章节；
- 历史记录；
- 各项应用设置。

**不在里面**的：下载到本地的章节文件、扩展本体、追踪器账号的登录态。这几样要么体积大、要么涉及系统权限，要按第四节单独带走。

## 二、手动备份与自动备份

- **手动**：上面那条路径，创建完把文件拷到手机存储或网盘存一份；
- **自动**：同一页里「自动备份」可设定时执行（如每 6 小时、每天），备份文件自动写到指定目录。

对一个已经停更、没有团队兜底的阅读器来说，自动备份尤其要开着——数据丢了就真没了。

## 三、恢复备份

在装好的新环境里走「更多 → 设置 → 备份与恢复 → 恢复备份」，选中备份文件即可。两种典型场景：

1. **同版本恢复**：0.15.3 恢复到 0.15.3，逐项完整还原；
2. **恢复到后继应用**：Mihon 等社区分支沿用这套备份格式，旧备份可以原样导入（分支情况见 [停更后的分支怎么选.md](停更后的分支怎么选.md)），导入时勾上书架、分类、进度即可。

## 四、换机时单独带走的四样

| 内容 | 位置 | 怎么带走 |
| --- | --- | --- |
| 备份文件 | 自己设的备份目录 | 直接拷走 |
| 已下载章节 | 首次启动时选的下载文件夹 | 整个文件夹拷到新机，再把下载路径指向它 |
| 扩展 | 系统里 | 不随备份走，新机上按清单重装 |
| 追踪器登录 | 各平台账号 | 新应用里重新登录绑定 |

## 五、旧手机退役前的完整流程

1. 手动创建一次备份，确认文件已生成；
2. 备份文件与整个下载文件夹一起拷到新机（或电脑中转）；
3. 新机装好后恢复备份、重装扩展；
4. 抽查两部作品，确认进度没丢、章节能更新，再处理旧机；
5. 旧机卸载前最后看一眼自动备份目录——确认最新一份已经被拷走。

还没装的话，先到 [Tachiyomi 中文介绍站](https://tachiyomi.usea.quest/) 的下载页拿安装文件资源，装好后再照 [扩展源安装与书架搭建.md](扩展源安装与书架搭建.md) 把扩展配齐。
