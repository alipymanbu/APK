# 扩展源安装与书架搭建

> 本篇是装好 Tachiyomi 之后的第一课：为什么书架是空的、扩展怎么装、书架和阅读模式怎么调。
> **相关文档**：[为什么选开源漫画阅读器.md](为什么选开源漫画阅读器.md) · [换机迁移与备份.md](换机迁移与备份.md) · [停更后的分支怎么选.md](停更后的分支怎么选.md)

## 一、为什么装完什么都没有

Tachiyomi 的本体只是一台阅读机器：书架、翻页、下载、备份都在里面，唯独「从哪里取漫画」不内置。内容渠道叫「源」，以扩展（Extension）的形式单独安装——每个扩展都是一个小 APK，装几个、留几个自己定。

所以首次使用的固定路径是：**装本体 → 装扩展 → 从源里把漫画加进书架**。唯一的例外是内置的「本地源」，不联网、不用扩展，直接读手机存储里自己的漫画文件。

## 二、装扩展的步骤

1. 底部点「浏览」，切到「扩展」标签；
2. 按语言或名字筛选，找到想用的扩展，点「下载」；
3. 系统弹出安装确认（扩展本质是个 APK），点「安装」；
4. 装完回到扩展列表，该扩展显示为已启用；
5. 切到「来源」标签就能看到新装的源，点进去搜漫画、加书架。

两个容易卡住的点：

- **扩展仓库地址要先换**。原团队的扩展仓库在 2024 年 1 月随项目一并下线，0.15.3 里内置的地址拿不到新扩展；入口在「更多 → 设置 → 扩展 → 扩展仓库 → 添加」，把社区维护的仓库地址（通常是 `index.min.json` 结尾的 URL）粘进去保存。
- **签名要一致**。如果手机里装过别的分叉版本，旧分叉装的扩展会因签名对不上而装不上，先卸干净再装。

## 三、把书架搭起来

加作品的动作叫「加书架」：进一个源 → 搜到或翻到想看的作品 → 点开详情页 → 点封面旁的「+」。加第二部作品时会让你选分类，分类在「更多 → 分类」里建，「在读 / 养肥中 / 已完结」随意。

书架顶部的筛选与排序可以按未读数、最近更新、字母序排；长按可多选，批量挪分类、批量删除。阅读进度自动记录，下次打开直接落在没读完的那一章。

## 四、把阅读器调成自己的

详情页或阅读界面里都能改当前作品的阅读模式：日漫原版翻页方向选「从右到左」，页漫选「上下连续滚动」，韩式长条漫选「网络条漫」。阅读时点屏幕中央唤出菜单，亮度、背景色（黑 / 灰 / 白，还有贴合页面颜色的自动档）与缩放都在那里。这些设定可以「仅此作品」生效，也可以存成全局默认。

追更节奏在「更多 → 设置 → 更新」里调：检查频率、是否只在 Wi-Fi 下更新；「更新」标签页是每次检查的结果，新章节从那里直接点开读。

## 五、两个加分项

- **进度同步**：在 MyAnimeList、AniList、Kitsu、MangaUpdates、Shikimori、Bangumi 有账号的话，到「设置 → 追踪」里绑定，章节进度自动同步过去。
- **隐身模式**：「设置 → 隐私」里开启，期间的阅读不写进历史也不同步给追踪器，想恢复记录手动关掉即可。

界面的实际样子（书架、详情页、阅读页实拍）在 [Tachiyomi 中文介绍站](https://tachiyomi.usea.quest/) 的「界面一览」一节能看到，装之前先去认认脸熟。哪天要换手机，提前读一遍 [换机迁移与备份.md](换机迁移与备份.md)，书架数据一点不丢。
