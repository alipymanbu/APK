# vilipix · 插画世界资料小站

这里整理 vilipix（中文名「插画世界」）这款安卓插画应用的使用资料：它把插画、漫画、小说三个内容区装进一部手机，日榜周榜月榜随时翻图，长按选画质存图设壁纸，还能按头像、立绘、人设 OC 等类型向画师约稿。

**目录内容**：

- [找图存图与壁纸设置攻略.md](找图存图与壁纸设置攻略.md) —— 找图路线、画质挑选、壁纸设置一条龙；
- [向画师约稿的流程与避坑.md](向画师约稿的流程与避坑.md) —— 约稿五步走与交易风险判据。

想直接在手机上看图文版，打开 [vilipix 插画世界速览站](https://vilipix.bpfl.quest/) 即可，两页读完安装与使用都齐了。

> 本目录为第三方整理的公开资料汇总，与该应用的开发团队无隶属关系；展示素材版权归原作者所有。
