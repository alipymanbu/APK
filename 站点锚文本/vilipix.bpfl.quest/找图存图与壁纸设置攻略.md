## 一、找图的三条路线

翻图不必大海捞针，站内给的路已经够用：

| 路线 | 什么时候用 |
| --- | --- |
| 日榜 / 周榜 / 月榜 | 想看当下最热门的作品，日榜换得快，月榜是硬货 |
| 特辑与标签 | 想按一个主题或题材连着看一组 |
| 氢壁纸 / 2K 分类 | 专门拿壁纸，按分辨率备好，竖构图对上手机屏幕比例 |

没目标就顺着首页推荐刷；有目标直接搜：先用中文名搜，没结果换原语言名或罗马音，搜角色时把作品名一起带上。搜索结果按人气排序属于高级会员功能，免费账号按默认顺序看即可。

## 二、把图存进相册的两种方法

**方法 A**：点开图片进详情页，直接点「下载」。

**方法 B（可挑画质）**：

1. 在图片上长按，弹出菜单；
2. 选「保存图片」；
3. 选「图片下载质量」——设壁纸选最高档，当头像或发参考图选中低档省空间；
4. 点「立刻下载」，稍等片刻图就进了本地相册。

首次保存会弹相册 / 存储权限申请，允许它；拒绝的话图片写不进相册。收藏与下载建议两边都做：收藏留在账号里换机不丢，下载落到本地随取随用。

## 三、设成壁纸或头像

图片已经在系统相册里，按通用做法操作：相册里找到那张 → 点「更多 / 设为」→ 选「设为壁纸」或「设为头像」→ 按提示裁剪确认。部分版本在详情页里也有直接设壁纸的入口，效果一样。

版权一句：每张图都带作者信息，标注不可商用的作品只适合自己欣赏，别拿去发布或当商业素材。
