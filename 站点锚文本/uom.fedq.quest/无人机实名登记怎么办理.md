# 无人机实名登记怎么办理

> 《无人驾驶航空器飞行管理暂行条例》要求民用无人机所有人在 UOM 平台完成实名登记，不登记就飞可能面临罚款，而且 2026 年 5 月新国标生效后，未登记的机器连激活都过不了。本篇讲在手机 App 里登记一台无人机的完整步骤、序列号（SN）去哪找、登记标志怎么拿。
> **相关文章**：[登记后激活新规要点](登记后激活新规要点.md) · [序列号被占用申诉与登记卡点](序列号被占用申诉与登记卡点.md)

## 一、登记前备齐四样东西

| 要准备的 | 说明 |
| --- | --- |
| 已实名认证的账号 | 个人账号即可，注册时用微信扫码做人脸核验 |
| 无人机正面照片 | 拍清楚整机外观 |
| 序列号（SN）照片 | 拍清楚机身贴纸，常见位置见下文第三节 |
| 品牌、型号、SN 码 | 品牌机在系统列表里选型号后，其余参数一般自动匹配 |

## 二、App 端登记步骤

1. 登录 App，进入「我要办事 → 实名登记」；
2. 按提示逐步填写实名认证信息，完成微信人脸识别验证；
3. 填无人机信息：选生产厂家 → 勾选产品型号 → 填产品序列号；
4. 拍摄并上传无人机正面照片和序列号照片；
5. 提交完成，登记信息出现在实名登记列表里。

网页端路径与之等效：登录 uom.caac.gov.cn 后走「实名登记 → 注册品牌无人机」。自己攒的机器不走品牌登记，改走「自制无人机登记」入口。

## 三、序列号（SN）常见位置

- 电池仓内侧的贴纸上；
- 包装盒的条形码贴纸处；
- 厂商 App 里也能查：以 DJI Fly 为例，连接飞行器后进「右上角 ··· → 关于 → 飞机序列号」。

两个高频坑：别把遥控器的码或认证码当成机身 SN；机身序列号与飞控序列号不一致时，登记飞控序列号。

## 四、拿到登记标志

登记成功后系统生成实名登记标志，由 11 位登记号（UAS 开头）加二维码组成。在登记列表里双击二维码可放大；点「发送二维码 → 登记标识」可把它发到注册邮箱，下载附件打印后贴在机身显著位置，供地面核查。

## 五、登记完还有一步：属地公安备案

多数地区实行「双备案」：UOM 平台登记完成后，还要向属地公安机关备案。全国性入口是微信小程序「无人驾驶航空器公安管理平台」，部分省份用本地平台（如湖南走「湖南公安服务平台」小程序）。线下备案一般要带身份证件、无人机、购买凭证和实名登记二维码。

装 App 这一步还没完成的，可以从 [UOM 平台手机端说明站](https://uom.fedq.quest/) 进入安卓安装包资源页；登记完成后要飞管制空域的，接着了解飞行活动申请。日后卖掉、送人或报废，记得及时注销登记，见 [序列号被占用申诉与登记卡点](序列号被占用申诉与登记卡点.md)。
