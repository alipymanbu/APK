# UOM 平台手机端说明

UOM（民用无人驾驶航空器综合管理平台）是中国民用航空局信息中心建设的全国统一无人机监管服务平台，手机 App 覆盖实名登记、登记后激活、飞行活动申请与操控员资质等业务。本目录整理手机端办理各项业务的说明文章，供无人机所有人参考。
