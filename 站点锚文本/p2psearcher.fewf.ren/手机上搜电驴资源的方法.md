# 手机上搜电驴资源的方法

> 电驴网络里沉淀了二十年网友共享的电影、剧集、动漫、音乐和电子书，想在安卓手机上把它们翻出来，核心就是一款搜索工具。本篇讲这类搜索的原理、关键词怎么写、结果怎么筛。

## 一、电驴网络里能搜到什么

电驴（eDonkey / eMule）网络是全球用户互相共享文件形成的分布式网络，里面最常见的内容：

- 老电影、纪录片、冷门剧集——流媒体平台下架或从未上线的内容，这里往往还有人在共享；
- 动漫全集、原声碟、美术设定集；
- 电子书、杂志扫描本、软件安装包。

特点很明确：越热门的内容速度越快，越冷门的内容越看运气——但只要有人共享过，就有机会翻出来。

## 二、手机上用什么搜

桌面时代大家习惯用电驴客户端直接搜，手机上更轻量的做法是装一个专门的搜索工具，比如 p2psearcher 的安卓版：它不负责下载，只负责把电驴网络里的共享文件检索出来，搜到之后再交给下载工具。想了解它的界面与功能，可以看这份 [p2psearcher 安卓版图文介绍](https://p2psearcher.fewf.ren/)，里面把搜索、云播预览、复制链接三个环节都配了说明。

## 三、关键词怎么写

- **宁短勿长**：搜「某电影 2019 高清完整版」不如直接搜「某电影 2019」，修饰词越多命中率越低；
- **中英文名互换**：外语片搜不出结果时换原名单词试一次；
- **全称与缩写互换**：软件、剧集都有各自的圈内叫法；
- **加集数或季数收窄范围**：找某季某集直接写「片名 S02」。

## 四、结果怎么筛

搜索结果通常带三列信息：文件大小、文件类型、热度（共享人数）。

| 看哪里 | 判断什么 |
| --- | --- |
| 大小 | 几十 KB 的「电影」基本是假资源或广告；正片常在几百 MB 到几 GB |
| 类型 | 只要视频就按类型过滤，滤掉无关格式 |
| 热度 | 共享人数多 = 下载速度通常更快 |

拿不准内容对不对，先在线预览一段再决定，比下完才发现是预告片省时间得多。

## 五、搜到之后

搜索工具只解决「找到」。要把文件真正存进手机，走下载工具那条链，具体操作见[搜到的磁力链接怎么下载](搜到的磁力链接怎么下载.md)；如果打开工具后一直连不上、搜什么都 0 结果，先看[连不上与搜不到结果的解决思路](连不上与搜不到结果的解决思路.md)再下结论。
