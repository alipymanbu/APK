# 连不上与搜不到结果的解决思路

> 打开搜索工具一直转圈、或者能搜但永远是 0 结果——多数不是软件坏了，是网络环境或关键词的问题。本篇按现象分情况给排查顺序，以 p2psearcher 为例，其他电驴搜索工具同样适用。

## 一、先分清是哪种「不行」

| 现象 | 更可能是 | 去看 |
| --- | --- | --- |
| 刚打开一直转圈，连不上网络 | 连接需要时间，或网络环境受限 | 第二节 |
| 能进界面、能点搜索，但结果为空 | 关键词或资源本身的问题 | 第三节 |
| 以前能用，最近突然全搜不到 | 运营商限制或版本因素 | 第二、四节 |

## 二、连接不上：先等，再换网络

1. 打开后不要立刻搜，等连接完成再开始，等一两分钟很常见；
2. 确认手机本身能上网（随手开个网页试试）；
3. 在 Wi-Fi 和移动数据之间切换一次——部分运营商会限制电驴网络的服务器与连接协议，不同运营商、不同网络的限制程度差别很大，这是这类工具连不上的头号原因；
4. 换个时间段再开。电驴网络的可用性本身随时间波动，同一网络换一个时段往往就能连上；
5. 以上全部无效时，卸载后装回新版本再试——旧版本的连接信息失效后怎么等都连不上。

## 三、搜不到结果：从关键词下手

- 长句换短词：搜「某电影 2019 高清完整版」不如搜「某电影 2019」；
- 换同义词：中英文名互换、全称与缩写互换；
- 接受现实：冷门资源搜不到不算故障——电驴网络里没人共享过的东西，任何搜索工具都搜不出来；
- 关键词没问题但条条都是 0 结果，回到第二节的网络排查，尤其是 Wi-Fi 与移动数据的切换。
