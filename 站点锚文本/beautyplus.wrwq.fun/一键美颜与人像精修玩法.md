# BeautyPlus 一键美颜与人像精修玩法

> 本篇按「拍照或导入 → 一键美颜 → 手动精修 → 上妆 → 调身材」的顺序，把 BeautyPlus 的人像功能过一遍，每一步都写清楚入口在哪、怎么调比较自然。

## 一、先分清两个入口

- **相机**：首页的拍照入口，直接取景拍摄，拍完自动进编辑流程；底栏左右滑动能切到 Film Cam 等拍摄模式；
- **编辑**：从系统相册导入已经拍好的照片再修，适合处理旧照片或别的设备拍的照片。

美颜分两层：一层是**一键美颜（HD Retouch）**，导入照片后自动出一个整体效果，你只管调强度；另一层是**手动工具**，按部位逐项细调。日常自拍用一键的就够，想精修再进手动。

## 二、一键美颜怎么调才自然

1. 选好照片（或拍完一张）进入编辑；
2. 找到 HD Retouch / 一键美颜，应用后面部轮廓和皮肤会自动处理一遍；
3. 用滑杆控制整体强度，拉到 60%~70% 左右通常比较自然，拉满容易出现「塑料感」。

一键结果不满意时不要反复叠加，直接转手动工具修具体部位。

## 三、手动精修：五官与皮肤逐项来

| 部位 | 能调什么 | 操作方式 |
| --- | --- | --- |
| 眼睛 | 放大、提亮、去黑眼圈和眼袋 | 点按或滑动，黑眼圈在眼周涂抹 |
| 鼻子 | 整体大小、缩窄、鼻梁挺直、鼻尖形状 | 拖动滑杆，逐项叠加 |
| 嘴唇 | 丰满度、位置、微笑弧度上扬 | 拖动滑杆 |
| 皮肤 | 祛痘、去油光、平滑毛孔、提亮 | 祛痘点按消除，其余多为涂抹 |
| 牙齿 | 矫正（含戴牙套的情况）、美白 | 涂抹需要变白的区域 |
| 脸型 | 瘦脸、下颌与下巴重塑、发际线 | 按住推拉或拖滑杆 |

两条实操经验：一次只调一两个部位，调完看整体；皮肤类工具先用低强度涂一遍，不够再补。

## 四、上妆与身材

- **妆容**：先选一套接近目标的完整妆（口红、眉毛、腮红的组合），再单独微调单项；直接逐个叠加容易显得脏。部分妆容素材带会员标识，边界见[免费版和会员怎么选.md](免费版和会员怎么选.md)。
- **身材**：用「推拉」方式改轮廓——身高拉长、腰收细、肩线调整。先把画面放大到要改的部位，小幅度推多次比一次推到位稳；背景有门框、墙线这类直线参照物时要格外小心，推拉会把直线一起弯掉。

## 五、拍完之后

Classic 模式可以开自动保存，编辑完成的图通常落在系统相册的 BeautyPlus 文件夹里。想看滤镜、贴纸、消除路人这些「修脸之外」的功能，读[AI滤镜与老照片修复玩法.md](AI滤镜与老照片修复玩法.md)；这两篇的完整图文版也整理在了 [BeautyPlus 功能速览站](https://beautyplus.wrwq.fun/)上，配合界面截图更好对照。
