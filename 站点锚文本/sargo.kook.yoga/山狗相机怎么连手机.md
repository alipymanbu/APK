# 山狗相机怎么连手机：WiFi 直连六步与三个拦路设置

> 山狗（SARGO）相机没有数据传输接口给手机 App 用，手机要看到画面、拿文件，全靠相机发出的那条 WiFi 热点。这篇按真实操作顺序把六步走完，顺带把最常拦路的三个手机设置提前关掉。
> **相关文档**：[相机视频怎么传到手机](相机视频怎么传到手机.md)

---

## 先把手机设置里三件事关掉

安卓手机的「网络加速」「WLAN 助理」「双 WiFi 模式」都会在检测到当前 WiFi 不能上网时自动切换网络，而相机热点恰恰就是不能上网的——不关掉，连接会被系统反复掐断。不同品牌叫法不同（华为叫 WLAN+），在设置里搜「网络加速」或「智能切换」认准关闭。

华为 / 鸿蒙手机多一件：安装应用前先到「设置 → 系统和更新 → 纯净模式」关掉增强防护，否则 APK 装不上。

## 六步连上

1. **打开相机 WiFi**：开机后快速连按两下按键，相机震动一次、黄（绿）灯亮才算成功。只按一下是开始录像，得先停录再操作；
2. **认热点名**：热点以型号开头，P10 机型叫 `P10***`，G10 叫 `G10***`，星号是每台相机不同的流水号；默认密码 `12345678`，改过以说明书为准；
3. **App 里添加设备**：打开 SARGO，首页点「添加设备」，按引导走；
4. **去手机 WLAN 连热点**：弹出「此网络无法访问互联网，是否使用」时选「仍要连接」——相机热点本来就不通互联网，这个提示是正常现象，不是故障；
5. **回到 App 进入设备**：实时画面出现，开始 / 停止录制、调参数都在这个界面；
6. **用完关 WiFi**：再双击按键退出 WiFi 模式，相机回到普通拍摄状态。

## 搜不到热点时，先看灯

| 你看到的 | 相机状态 |
| --- | --- |
| 蓝灯闪烁（短按震动一次） | 正在录像，双击不会切 WiFi，先停录 |
| 黄（绿）灯亮（双击震动一次） | WiFi 已打开 |
| 蓝灯 + 黄绿灯同亮 | WiFi 已被手机连上 |
| 红灯快闪后关机 | 电量耗尽，先充电 |
| 震动五次、红灯快闪，约 10 分钟后关机 | 没插卡或卡错误 |

「WiFi 开了但手机搜不到」多数落在前两行：相机在录像中，或没插卡处于即将关机的状态。贴近几米内再刷新 WLAN 列表，重启相机与手机 WLAN 开关也是有效动作。

## 连上之后

实时预览就是遥控取景器，相机挂在车上、头顶、高处时手机画面代替小屏；在线回放可以先翻一遍再挑着下载。具体取文件的路数写在 [相机视频怎么传到手机](相机视频怎么传到手机.md)。

还没装 App 的，[SARGO 相机配套应用介绍站](https://sargo.kook.yoga/)里把安装文件获取入口、装前设置和连接步骤按顺序整理成了一站，照着走即可。
