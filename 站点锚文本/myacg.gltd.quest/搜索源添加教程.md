# 搜索源添加教程

> MyACG 装完打开几乎是空的，因为它是一个「壳 + 源」结构的检索工具：应用本体不提供内容，内容入口全靠一条条搜索源。本篇讲怎么把源加起来、怎么导入外部源，以及源失效后怎么补。
> **本目录相关笔记**：[打开是空的怎么办](打开是空的怎么办.md) · [换机数据迁移](换机数据迁移.md)

---

## 一、先弄懂：源是什么

MyACG 没有自带搜索引擎，也不存放任何资源。它运行的是一条条由规则写成的「搜索源」——每条源对应一类站点和一组检索规则，支持 JsonPath、CSS Query 两种规则写法，也能通过加载 JavaScript 代码实现搜索或在线资源加载。加了多少条源，就能从多少个站点找东西。

源的对应站点都是第三方站点，站点内容是否合适、是否符合当地法规要求，需要自己留意把关。

## 二、添加内置搜索源

MyACG 自带了一批覆盖漫画、小说、动漫、音乐、轻小说、图片、网盘搜索等类别的源，直接添加就能用：

1. 底部导航点「浏览」；
2. 进入「网络搜索」；
3. 点右上角的「搜索源管理」；
4. 列表里就是内置的各资源站，点每条后面的「添加」按钮逐条加，或在右上角选项里选「当前分组操作 → 全部添加」整组加齐。

不同版本的界面叫法略有差异（「网络搜索 / 搜索」「搜索源管理 / 搜索源」「添加 / 安装」），找不到本篇写的名称时，在相邻位置找同义叫法即可。

## 三、导入外部搜索源

搜索源管理页的右上角选项里提供三种外部导入方式：

| 导入方式 | 适用场景 | 操作 |
| --- | --- | --- |
| 本地导入 | 手里有下载好的源文件 | 从手机存储里选中源文件 |
| 网络导入 | 拿到的是一条源订阅链接 | 填入链接让应用自动拉取 |
| 剪贴板导入 | 源内容以文本形式在剪贴板里 | 复制后直接选剪贴板导入 |

网上找到的第三方源规则文件基本就是 JsonPath 与 CSS Query 两种写法；别人分享的源质量参差不齐，加之前先确认来源可靠。

## 四、源失效了怎么办

搜索源对应的是第三方站点的检索规则，对方站点改版、下线或限流，这条源就会跟着失效——这是这类工具的常态，不是操作错了。处理方式：

- 在「搜索源管理」里把失效的源删掉或停用，换别的源用；
- 同一源站常有使用者更新维护新规则，从网络导入或剪贴板导入新版本即可接上。

源加好之后，搜索和浏览的具体玩法见站点笔记：[MyACG 聚合检索工具](https://myacg.gltd.quest/)。搜不到结果时的排查思路写在[打开是空的怎么办](打开是空的怎么办.md)里。
