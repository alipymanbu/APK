# MyACG 站点笔记

本目录是与站点 myacg.gltd.quest 配套的一组第三方整理笔记：MyACG 是一款安卓端聚合检索工具，本身不带内容，靠添加搜索源去各站点找漫画、小说、动漫、音乐和网盘资源。这里把加源、排查、迁移几件最常遇到的事分篇讲清。

站点入口：[MyACG 聚合检索工具](https://myacg.gltd.quest/)（含安装文件资源获取方式与下载安装步骤）。

- [搜索源添加教程](搜索源添加教程.md)——从内置源到外部导入，把检索入口建起来。
- [打开是空的怎么办](打开是空的怎么办.md)——首次空白与搜索无结果的排查思路。
- [换机数据迁移](换机数据迁移.md)——搜索源与配置的备份、恢复与换机搬运。
