# 截图发出去之前，把不该露的信息遮掉

> 聊天记录、快递单、车票的截图里常有验证码、地址、证件号。本篇讲手机上遮挡这几类信息的常用工具怎么选、按什么顺序处理，以及发送前的最后一遍检查。

## 一、四样工具各管一摊

安卓修图应用 runway 的编辑工具箱里，四样东西常被用来处理截图，适用情形并不一样：

| 工具 | 适合的情形 |
| --- | --- |
| 马赛克 | 验证码、账号、地址——怕被认出来、怕信息泄露的 |
| 贴纸 | 只是「看着干净」就行；顺手加节日、心情类小元素 |
| 涂鸦 | 帮人看图时圈出重点、手写标注一句 |
| 文字 | 加说明、做日签打卡图；字别压在人脸上 |

## 二、马赛克和贴纸，二选一怎么判

判断标准就一条：遮的东西泄不泄露。

- 只是想让画面别那么乱、没有泄露风险的，用贴纸盖，比满屏马赛克好看；
- 验证码、账号、住址、证件号这类真怕泄露的，老老实实用马赛克——贴纸偶尔会挪位，马赛克涂上就生效。

## 三、按什么顺序处理

工具可以叠加，顺序对了省一半功夫：

1. 先裁剪：把画面边缘的杂物裁掉，能裁掉的就不必遮；
2. 再遮敏感信息：马赛克或贴纸上，一次把要遮的都盖掉；
3. 最后加标注：涂鸦圈重点、文字补一句说明，放最上层不影响底下的遮挡。

## 四、发送前最后一遍检查

发出去之前，把图缩小成缩略图看一遍整体——有些遮挡在缩略图下会露边——再放大核对遮挡的边缘有没有露出原字的笔画。两遍都过了再发，基本不会出岔子。
