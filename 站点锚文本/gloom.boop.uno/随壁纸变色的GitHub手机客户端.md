在手机上逛 GitHub，网页版要反复缩放，通知和讨论也散落在各个页面里；一个顺手的第三方客户端，往往就是"碎片时间能不能真正读进开源项目"的分水岭。

## Gloom 是什么

Gloom 是 MateriiApps 组织旗下以 GPL-3.0 协议开源的 GitHub 第三方安卓客户端，采用 Kotlin 与 Jetpack Compose 构建。项目的一句话介绍很有辨识度——"GitHub reimagined with Material You"：它不是把网页搬进 WebView，而是按 Material 3 的设计语言把仓库浏览、探索、个人主页这些动线重新做了一遍。

## 动态取色：界面跟着壁纸走

Gloom 最出挑的特色是 Material You 动态取色：在 Android 12 及以上系统，应用会从当前壁纸提取主色调，生成一整套协调的界面色板。壁纸换成绿色调，界面强调色就偏绿；夜里切到深色模式，配色依旧协调。同一个应用，每台手机上的观感都不完全一样——这恰恰是它"个性化"的来源。

## 界面动线一览

实机截图里能看到四条主要动线：

- **个人主页**：头像、README、置顶仓库一览；
- **Starred 收藏**：星标过的仓库按语言与热度排列，碎片时间正好翻一遍；
- **仓库列表**：自己与关注项目的更新近况逐条呈现；
- **所属组织**：组织概览与项目分组，跟进团队项目更省事。

再加上仓库与代码浏览、Issue / Pull Request 阅读，日常"看" GitHub 的事基本都覆盖了。

## 适合哪些人

- 想要一个界面清爽、有原生 Material 3 气质的 GitHub 客户端；
- 在意开源透明度，希望代码公开可查；
- 喜欢界面与壁纸联动的个性化观感。

完整的功能介绍与实机截图，可以到 [Gloom 介绍站](https://gloom.boop.uno/) 进一步了解，那里也整理了安装文件资源的获取方式。
