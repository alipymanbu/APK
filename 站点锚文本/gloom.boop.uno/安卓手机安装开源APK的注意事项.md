# 安卓手机安装开源 APK 的注意事项

> 本篇整理在安卓手机上安装开源应用 APK 的准备动作与常见失败的处理办法，以 Gloom 为例。
> 相关文档：[随壁纸变色的 GitHub 手机客户端](随壁纸变色的GitHub手机客户端.md) · [GPL 3.0 开源协议对使用者意味着什么](GPL3.0开源协议对使用者意味着什么.md)

---

开源应用的安装包一般以 APK 形式直接分发，不经应用商店中转。装这类包不难，但有几件事提前弄清楚，能省掉大部分"点安装没反应"的来回。

## 安装前：三件小事

1. **确认来源可信**：开源项目优先从项目方认可的渠道获取。Gloom 的安装文件资源入口整理在 [Gloom 介绍站](https://gloom.boop.uno/)，从站点进入拿包，路径最短。
2. **看一眼基本信息**：安装包的版本号、体积与项目公开信息对得上，基本就能排除"下了一半"或"拿错文件"的情况。
3. **预留存储空间**：安装包本体之外，安装过程还需要少量临时空间，存储告急的机型先清一清。

## 安装中：未知来源怎么放行

安卓默认只允许从应用商店安装。首次点开网盘里下载的 APK 时，系统会提示"禁止安装未知来源应用"——这不是包有问题，而是系统默认策略：

- 进入系统设置的「安装未知应用」；
- 找到会用到的应用（浏览器或网盘客户端）；
- 打开"允许安装"开关，回到安装包重新点击。

## 装不上：两种高频情况

- **提示解析包失败**：多半是下载不完整。删掉已下载的文件，重新下载一次；反复失败时检查手机系统版本是否过旧。
- **点安装直接被拦截**：回到上一步，把对应来源的"允许安装"打开再试；个别安全软件也会拦，临时放行即可。

## 装好之后

以 Gloom 为例，首次打开用 GitHub 账号登录，收藏、个人主页与所属组织就会同步进来；界面颜色来自壁纸取色，换张壁纸就能看到配色变化。更多功能细节见目录里的相关文档。
