# GPL 3.0 开源协议对使用者意味着什么

> 本篇解释 GPL-3.0 协议的核心含义，以及它对普通使用者的实际价值——以开源 GitHub 客户端 Gloom 为例。

挑第三方应用时，"开源"两个字经常被一笔带过；但对安卓用户来说，协议类型直接决定了这个应用"用起来有多明白"。Gloom 采用的正是自由软件世界里最严格的 GPL-3.0。

## GPL-3.0 的三句话版本

1. **自由使用与分发**：任何人都可以免费使用、复制、分发这份软件，不必支付授权费；
2. **源代码公开**：发布时必须附带完整源代码，用户能看到程序到底做了什么；
3. **衍生同样开源**：任何基于它的修改版，也必须以 GPL-3.0 开源发布——"改了闭着卖"这条路被协议堵死。

## 对使用者的实际价值

- **装得放心**：代码公开意味着没有黑箱，社区可以逐行审计，有权限滥用的苗头会被发现；
- **没有隐藏收费逻辑**：协议本身决定了它不可能做成"锁定付费功能"的闭源产品；
- **生命周期可预期**：即使原开发团队停更，任何开发者都能基于公开代码接手维护，应用不会"人走茶凉"。

## 以 Gloom 为例

Gloom 的完整代码托管在 GitHub（MateriiApps 组织），任何人都可以查阅、提交 issue、参与翻译。它是一款以 Material You 动态取色为特色的 GitHub 第三方安卓客户端——协议保证了它的开源身份，界面则靠动态取色与深浅模式把体验做了上去。功能与截图详见 [Gloom 介绍站](https://gloom.boop.uno/)。

## 一点提醒

开源不等于"随便什么渠道的安装包都安全"：拿到安装包前后，仍建议核对来源可信度与文件完整性。具体的安装姿势与排查方法，见相关文档。
