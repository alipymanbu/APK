# BiliPai 插件中心都有哪些内置能力

> 本篇整理 BiliPai 插件中心的十个内置插件：各自管什么、什么时候开，以及导入外部规则插件前要看的东西。
> **相关文档**：[扫码登录后高画质怎么开.md](扫码登录后高画质怎么开.md) · [安卓手机安装步骤与拦路问题.md](安卓手机安装步骤与拦路问题.md)

插件是 BiliPai 最有辨识度的部分：它把「跳过恰饭、弹幕过滤、投屏」这类需求做成了可单独开关的能力，全部随应用自带，不用额外下载。想先看这款客户端的整体面貌与安装方式，可以移步 [BiliPai 纯净客户端介绍站](https://bilipai.usea.quest/)。

## 十个内置插件速览

| 插件 | 用它做什么 |
| --- | --- |
| 空降助手 | 接社区数据库，一键跳过视频里的恰饭段落 |
| 去广告 | 过滤信息流与界面里的广告位 |
| 弹幕增强 | 屏蔽规则支持正则与前缀语法，可按关键词过滤、高亮 |
| Anime4K | 实时画质增强，低分辨率片源看着更锐 |
| CDN 属地优选 | 换更合适的播放节点，卡顿时优先开它 |
| 夜间护眼 | 关灯看时压低画面刺激 |
| 今日推荐单 | 生成一份当天的推荐清单 |
| 初见推荐 | 按初次接触的口味做推荐 |
| DLNA | 投到同一局域网的电视或盒子 |
| Google Cast | 投到 Chromecast 类设备 |

入口在「设置」里（部分版本叫「插件中心」）。装好后第一件事不是找新插件，而是把主开关和自己要用的几项打开——尤其播放卡顿先试 CDN 属地优选，家里有智能电视就按设备二选一启用投屏项。

## JSON 规则插件：不装包也能改行为

只想改「推荐流里不出现什么、弹幕里屏蔽什么」的话，JSON 规则插件就够了：写好或拿到一份规则文件（`.bp` / JSON 格式），在插件中心选「从 URL 导入」或导入本地文件，启用后规则立即生效。规则可按字段过滤，比如隐藏某类时长或某关键词的条目。

## 导入第三方插件前，先看能力声明

这是最值得多花十秒的地方：能发网络请求（NETWORK）、能读本地观看记录（LOCAL_HISTORY_READ / LOCAL_FEEDBACK_READ）、能接管播放器（PLAYER_CONTROL）这三类敏感能力，出现在一份来路不明的「弹幕过滤」插件里就该警惕。只从信得过的来源装插件，可疑插件直接卸载即可恢复。

另外，外部 `.bpplugin` 插件包的执行链路仍处于预览阶段，社区直接发的包装上后行为未必稳定，别把日常体验押在它上面。登录、画质这些主流程的设置，见 [扫码登录后高画质怎么开.md](扫码登录后高画质怎么开.md)。
