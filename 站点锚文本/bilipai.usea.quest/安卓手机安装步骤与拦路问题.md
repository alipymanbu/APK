# BiliPai 安卓手机安装步骤与拦路问题

> 本篇讲 BiliPai 在安卓手机上怎么装：从拿安装包到扫码登录共四步，以及安装被拦、解析失败、装完闪退这三类最常挡路的问题。
> **相关文档**：[扫码登录后高画质怎么开.md](扫码登录后高画质怎么开.md) · [插件中心都有哪些内置能力.md](插件中心都有哪些内置能力.md)

BiliPai 是以 APK 形式分发的安卓应用，不在应用商店的货架上，装法比普通 App 多一步「允许未知来源」，但也只是多这一步。整包 21M 出头，要求 Android 8.0 及以上、64 位机型优先。装好后的玩法（插件、画质、缓存）可以逛逛 [BiliPai 纯净播放客户端介绍](https://bilipai.usea.quest/)，本篇只管把安装这关过了。

## 四步装完

1. **拿安装包**：从可信渠道拿到 `BiliPai_v8.1.3.apk` 这类安装包文件，下载到手机本机存储；
2. **点开 APK**：在通知栏或文件管理器里点开，系统第一次会提示「不允许安装未知来源应用」；
3. **临时放行**：按提示进「设置 → 应用 → 特殊权限 → 安装未知应用」，对刚才下载用的那个应用（浏览器 / 文件管理器 / 网盘）打开允许，再回来点安装——装完可以把权限关回去；
4. **打开并登录**：首屏点「开始探索」进主界面；要用动态、收藏同步和高画质档位，去「我的 → 安全登录」扫码（登录相关细节见 [扫码登录后高画质怎么开.md](扫码登录后高画质怎么开.md)）。

## 三类拦路问题的处理

**点安装没反应或被拦**：就是上面第 3 步的未知来源拦截，给发起安装的应用放行即可，不是包的问题。

**提示解析失败或包损坏**：基本是下载中断导致文件不完整，删掉重下一次；下完对照页面标的大小看是否差得离谱，差得多就是没下完整。

**装完一点开就闪退**：按成本从低到高试——重启手机清后台；长按图标进应用信息清缓存（**先别清数据，会丢登录态**）；换网络环境再开；仍不行就卸载重装。个别机型的兼容问题会随版本更新修掉，装新版再判断。

同包名的新版 APK 直接安装即可覆盖升级，登录状态一般会保留；跨大版本升级后建议确认一下登录态还在不在。
