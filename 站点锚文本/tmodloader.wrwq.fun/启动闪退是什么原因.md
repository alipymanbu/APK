# 启动闪退是什么原因

手机版 tModLoader 的启动故障大多有固定套路：权限没给、目录没生成、内存吃紧。装完打开就闪退先别急着下结论「装坏了」，按下面这个顺序排，多数情况几分钟内能解决。

## 现象一：点开就闪退，主菜单都进不去

这是新装机用户反馈最多的，多半发生在头几次启动：

1. **查存储权限**：系统设置 → 应用 → tModLoader → 权限，确认「存储」已允许。没给权限时它可能连主界面都进不去。
2. **多开几次**：社区用户的普遍经验是首次启动连着闪退两三次，之后就能正常进入。这不是装错了，多试几次再看。
3. **清后台再试**：后台驻留应用太多、内存紧张会加剧闪退，清掉后台重开。
4. **重启设备**：以上都试过仍闪退，重启一次能解决大部分临时性问题。

反复闪退超过五次仍进不去，就卸载重装一遍；重装前注意备份存档（下面会说）。装好之后模组的放法见[手机版怎么导入模组](手机版怎么导入模组.md)。

## 现象二：能进游戏，但模组放进去没反应

这不算启动故障，但和「目录没生成」是同一个根子：

1. 确认应用至少完整跑进过一次主菜单——模组目录是那时才生成的。
2. 进「模组管理」看开关是不是开的；开完必须点「重新加载模组」。
3. 确认放进 Mods 文件夹的是 .tmod 文件，压缩包要先解压。
4. 版本不匹配也会表现为「没反应」：换与你这份移植版内核对应的模组版本，思路见[灾厄模组怎么装到手机上](灾厄模组怎么装到手机上.md)。

## 现象三：能玩但卡顿、加载慢

- 中低端机型带大型模组包吃力，这是性能余量问题而不是故障；减掉几个大型模组，帧数会明显回稳。
- 长时间游玩发热也会掉帧，降降温再玩。
- 世界越大、模组越多，进图加载越久，卡在加载界面先等一等，别急着杀后台。

## 折腾之前：把存档先备份出来

卸载 tModLoader 时，它的模组存档会一起被清掉。所以重装排查、换模组、换版本之前，先用文件管理器把存档目录整个复制一份到别的位置（手机存储、电脑、云盘都行）。模组存档与原版泰拉瑞亚的存档是相互独立的两套，备份时认准路径里含 ModLoader.Explendesco 的那一套目录。

## 还是不行的时候

卸载重装是兜底动作：备份存档 → 删应用 → 重装 → 重新导入模组。重装后问题依旧，多半是设备与这份移植版不兼容，换设备或转回 PC 版是仅剩的两条路。安装包重新获取与安装步骤，可以看 [tmodloader 手机版介绍站](https://tmodloader.wrwq.fun/)。
