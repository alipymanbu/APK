# 手机版怎么导入模组

装好 tModLoader 只是第一步，模组文件是单独放的——不把 .tmod 文件放进模组目录，游戏里就不会多出任何新内容。本篇按手机移植版主界面上实际能看到的按钮，把导入与启用的完整流程走一遍。

## 先把模组目录找出来

1. 启动 tModLoader，首次启动让它完整跑到泰拉瑞亚主菜单——模组目录要等应用跑起来才会生成，没跑过一次就去找，多半找不到。
2. 回到主界面点「模组管理」。刚装好时列表是空的，正常。
3. 点列表下方的「打开模组文件夹」。部分机型不会自动跳转，就手动打开文件管理器，进入这个位置：

```text
/storage/emulated/0/Android/data/ModLoader.Explendesco/Mods/
```

「找不到 ModLoader.Explendesco 文件夹」通常还有另一个原因：安卓 11 以后不少系统自带的文件管理器限制访问 Android/data 目录。换支持该目录的第三方文件管理器，或直接走应用内「打开模组文件夹」的入口跳转。

## 放文件、启用、重载

1. 把下载好的 .tmod 模组文件移动或复制进 Mods 文件夹，一次放多个没问题。
2. 返回应用，重新进入「模组管理」，新放进来的模组会出现在列表里。
3. 点模组旁边的开关启用它。
4. 点「重新加载模组」——启用、停用之后都必须重载，改完直接进游戏是不会生效的。
5. 回主菜单选模式进游戏，模组内容就在了。

## 模组文件从哪里拿

- **模组作者的发布页**：正规渠道是作者的 GitHub Releases 页，.tmod 按版本分档，能对上你这份内核的概率最大。
- **应用内模组浏览器**：部分移植版带联网浏览器入口，能直接检索安装；拉不出列表就退回手动放文件。
- **警惕来路不明的整合包**：别人打包的模组合集无法确认有没有被掉包，宁可自己一个个从发布页拿。

## 启用之后常碰到的三件事

- **版本要对上**：模组按特定 tModLoader 版本编译，内核对不上时模组不生效或直接报错。「模组启用后无效」优先怀疑版本不匹配，换对应版本再试。
- **依赖要补齐**：不少模组依赖基础库类模组，只放主模组会加载失败，按发布页说明逐个补齐。
- **一次加一个**：先确认能进游戏，再一个个加新模组，出问题立刻能锁定是哪个引起的。
