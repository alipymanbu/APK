# 灾厄模组怎么装到手机上

灾厄（Calamity）是泰拉瑞亚模组里被问得最多的一个，但它在手机上能不能装，不取决于你想不想，而取决于移植版内核与模组版本能不能对上。本篇把绕不开的几个检查点列出来，按顺序走能少走弯路。模组文件的放入与启用方法先看[手机版怎么导入模组](手机版怎么导入模组.md)，这里不再重复。

## 先拿到对的文件

- **作者发布页是正路**：大型模组基本都在 GitHub 的 Releases 页发布 .tmod 文件。以灾厄为例，本体和配套的灾厄音乐（Calamity Music）是两个独立的 .tmod，要分别下载、都要放进 Mods 文件夹。
- **应用内浏览器能用就用它**：部分移植版带模组浏览器入口，能检索安装最省事；拉不出列表就回到手动放文件。
- **别从来路不明的渠道拿**：号称「整合包」的压缩包来路不清时不要用，模组文件也是会被掉包的对象。

## 版本匹配是成败关键

模组按特定 tModLoader 版本编译，手机移植版的内核编号又和 PC 版不是一套体系，所以装大型模组前想清楚一件事：**要找的是与你这份内核匹配的模组版本，不是最新版**。

社区里有用户分享过能跑的组合：旧移植内核 0.11.6.2 搭灾厄 1.4.3.2 与灾厄音乐 1.4.3.1（用户分享，供参考思路）。手上这份 1.1075 对应哪一版灾厄，没有公开对照表——实际操作就是试：装一版、重载、看报错，不行就换相邻版本。加载时报「版本不匹配」或没反应，就是这一版不对。

## 装完之后的四步检查

1. **依赖补齐**：大型模组常有前置库模组，发布页会写明，缺了就一起下载放入。
2. **启用并重载**：模组管理里开开关后，必须点「重新加载模组」。
3. **接受加载时长**：灾厄体量大，进图加载明显比原版慢，卡在加载界面先等一等；等太久或直接闪退的处理顺序，见[启动闪退是什么原因](启动闪退是什么原因.md)。
4. **对性能有预期**：中低端机型带灾厄明显吃力，掉帧、发热是常态。真带不动就减内容，或者回 PC 玩完整灾厄。

## 想玩中文的注意汉化包

灾厄本体是英文，中文靠社区做的汉化模组。汉化一般也是独立的 .tmod，同样放进 Mods 文件夹启用，而且**汉化版本要和灾厄版本对上**，否则游戏里会出现大段英文或直接冲突。打算联机的话，汉化包也在「双方必须一致」的清单里——联机与存档的注意事项会在后续文章里展开。

安装包从哪来、手机带不带得动这类基础问题，[tmodloader 手机版介绍站](https://tmodloader.wrwq.fun/)的首页与安装步骤页有完整说明。
