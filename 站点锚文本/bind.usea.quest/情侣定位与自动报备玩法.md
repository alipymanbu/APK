# Bind 情侣定位与自动报备玩法全解

> Bind 是一款给两个人用的定位报备应用：各自装上、用 Bind 码绑定后，位置共享、到达提醒、手机动态这些功能全部走你们之间那条专属连线。本篇把它能自动替你说的话整理成一份玩法清单。

## 先把关系建起来：Bind 码绑定

Bind 的所有双人功能都建立在一次绑定上，步骤很短：

1. 两个人各自用手机号注册账号（别共用一个）；
2. 一方在首页点「邀请」，把自己的 Bind 码发给对方；
3. 对方输入这串码、确认邀请，绑定关系就建立了。

绑定是所有功能的前提——只装一台手机，位置共享和报备都没有意义。想看同屏观影的玩法，直接跳 [异地恋一起看电影怎么弄.md](异地恋一起看电影怎么弄.md)。

## 自动报备：这些消息不用问

绑定之后，对方手机上的变化会以通知的形式推给你，一条条列出来是这样的：

| 时机 | 你会收到什么 |
| --- | --- |
| 坐车下车、到家、到公司 | 「我下车了」「我到了」这类自动报备，附里程、用时、最快车速的小卡 |
| 连上新 WiFi、断网 | 网络切换提醒，连上哪个网络都写明 |
| 电量吃紧、开始或停止充电 | 手机动态提醒，不用再打电话问"怎么关机了" |
| 拿起手机、屏幕使用变化 | 玩手机小报告：今天第几次、用了多久 |
| 深夜还在玩 | 熬夜提醒；早上还有情侣叫醒帮你喊人 |

这些通知要能送到，前提是对方装了 Bind、完成绑定并授权对应权限——报备是自动的，授权是自愿的，每一项都可以单独开关。

## 实时位置与全天轨迹

地图页看两个人的实时位置，是 Bind 的另一半：

- 3D 卫星地图上看着对方实时移动，位置能看到楼栋这一层；
- 双方距离、停留时长直接标在地图上；
- 一整天的足迹按段生成报告：距离、时间、路线、走路步数与车速。

## 锁屏常驻：动态不用点开 App

对方最新的报备和动态可以直接显示在锁屏上，不用解锁进应用；锁屏界面还能一键给对方发响铃和震动，适合"到家了敲一下"这种不需要打字的场景。

## 适合谁用

异地恋、通勤不同路的情侣，或者想给家人一个"到了说一声"渠道的人，都是 Bind 的典型使用者。它的特点是把"主动汇报"变成"自动发生"，省掉一天几遍的"到哪了"。
