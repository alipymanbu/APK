# Bind 提醒收不到怎么办：后台与权限逐项排查

> 绑定都完成了，"我下车了""连上 WiFi"这些提醒却迟迟不来，问题几乎都出在权限和后台这两层。本篇按从最常见到最少见的顺序排查，几分钟走完。
> **相关文档**：[情侣定位与自动报备玩法.md](情侣定位与自动报备玩法.md) · [异地恋一起看电影怎么弄.md](异地恋一起看电影怎么弄.md)

---

## 第一层：定位权限是不是「始终允许」

到达、离开、轨迹这类功能依赖后台定位，只给"使用应用期间"是不够的——锁屏或切走之后 Bind 就拿不到位置，提醒自然停了。

处理：系统设置里找到 Bind 的权限页，把定位改成「始终允许」。这是收不到提醒的头号原因，先改这一项再看。

## 第二层：通知权限开了没有

提醒是靠系统通知送达的。检查两个地方：

- 系统设置 → 应用 → Bind → 通知，确认整体通知是开的；
- 应用内的「通知设置」里，把想要的提醒逐项打开（网络切换、充电没电、熬夜、起床这些各有独立开关，关了哪项哪项就不响）。

## 第三层：后台有没有被省电策略杀掉

国产安卓对后台应用普遍下手狠，Bind 被杀后台，报备就断。按品牌处理：

| 品牌 | 建议动作 |
| --- | --- |
| 小米 / 红米 | 省电策略改成无限制，锁定最近任务卡片 |
| 华为 / 荣耀 | 电池里允许后台活动，应用启动管理改为手动管理并三项全开 |
| OPPO / vivo / iQOO | 允许自启动与后台运行，加入高耗电白名单 |
| 三星 | 电池 → 让应用始终保持运行 |

做完之后最好实测一轮：让对方开关一次 WiFi 或充一次电，看通知几秒内能不能到。

## 第四层：权限是对方的开关

Bind 的隐私设计里，你能看到什么取决于**对方**开放了什么：定位、电量、手机动态这些上报项，都是数据提供方在应用里逐项授权的。所以如果只有某几类提醒缺失（比如看得到位置、收不到电量提醒），让对方进应用检查自己的共享开关，而不是在你这边反复折腾。

## 耗电与省电的平衡

开完整定位功能后耗电变高属正常。两个折中办法：

- 在设置里把定位刷新频率从"实时"调低到几分钟一次，精度略降、续航明显好转；
- 出门前充满电，或让对方电量紧张时自行收紧共享项——权限随时可以单独关掉，不必解绑。

## 装不上、解析报错的顺带一提

如果卡在安装这关：提示「解析包错误」多半是安装包没下完整，删掉重新下载；安装被系统阻止就去设置里允许对应应用"安装未知应用"。完整的下载与安装步骤在 [Bind 情侣定位 App 介绍站](https://bind.usea.quest/) 的下载页里有逐条列出，绑定玩法则见 [情侣定位与自动报备玩法.md](情侣定位与自动报备玩法.md)。
