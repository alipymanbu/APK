# Shizuku 无线调试配对教程

Canta 这类工具要靠 Shizuku 才能拿到 ADB 级权限，而 Shizuku 的启动方式里，「无线调试」是唯一不需要电脑的一条。这篇把配对过程按步骤拆开，顺带回答「重启后掉线」这个最常被问的问题。

## 开始前的准备

- 手机为 Android 11 或更高版本（9/10 需要电脑 ADB 协助启动，本篇不展开）；
- 已安装 Shizuku 与 Canta；
- 手机和无线调试处于可用状态（连过一次 Wi-Fi 即可，配对过程本身不需要网络）。

## 配对四步

1. **开启开发者选项**：设置 → 关于手机 → 连续点击「版本号」七次，提示已进入开发者模式。
2. **打开无线调试**：设置 → 系统 → 开发者选项 → 无线调试，开启后进入该条目（要点进去，而不是只拨开关）。
3. **获取配对码**：选「使用配对码配对设备」，屏幕会弹出一组六位配对码和「IP 地址:端口」。
4. **在 Shizuku 里输入**：下拉 Shizuku 的通知，点「输入配对码」，把六位码和屏幕上的端口填进去确认；配对成功后回 Shizuku 点「启动」，状态变为「运行中」即完成。

配对只需做一次，之后每次「启动」服务即可。

## 在 Canta 里完成授权

Shizuku 跑起来后打开 Canta，会弹出授权请求，确认请求方是 Canta 后选择允许。回到主界面能看到应用列表（含带 SYSTEM 标记的系统应用），整条链路就算通了。更完整的说明在 [Canta 说明站](https://canta.rggd.pw/)。

## 重启后服务掉线怎么办

未 Root 的设备上，Shizuku 服务不会开机自启，重启后掉线属正常现象：重新打开 Shizuku 点「启动」即可，之前给 Canta 的授权记录一般会保留。若列表仍为空，检查 Shizuku 状态并重新触发一次授权。
