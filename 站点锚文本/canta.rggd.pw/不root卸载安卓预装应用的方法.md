# 不 Root 卸载安卓预装应用的方法

安卓手机出厂自带的运营商应用、厂商重复应用、预装的社媒与演示软件，很多既用不上又删不掉。这篇把「不 Root 删除系统预装」这条路讲清楚：为什么删不掉、靠什么工具删、删错了怎么办。

## 预装为什么删不掉

预装应用随系统镜像写进 `/system` 分区，桌面长按只有「停用」没有「卸载」；停用只是不让它运行，安装包仍占着存储。Root 虽然能删，但要解锁 Bootloader、刷入权限，银行和支付类应用可能因此拒绝运行，代价偏高。

## 用 Canta 走第三条路

Canta 是一款基于 Shizuku 的开源清理工具：Shizuku 通过无线调试拿到 ADB 级权限，Canta 借它调用系统包管理接口来卸载应用——效果和电脑上执行 ADB 卸载命令一样，但全程不需要电脑、不修改系统分区。具体原理与配置步骤可以看 [Canta 说明站](https://canta.rggd.pw/)上的完整说明。

它内置社区维护的预装清单，给每个系统应用标了风险徽章：

- 绿色（可移除）：通常非必要，删前确认自己用不用得到；
- 黄色（进阶）：可能影响部分小功能，先备替代品；
- 红色（专家）：可能破坏重要功能，别碰；
- 紫色（危险）：涉及系统关键组件，保持原样。

## 删错了还能回来

删除只作用于当前用户，APK 仍留在系统分区里。误删后打开 Canta 的「已卸载」标签页，选中应用点还原即可装回，不需要重新下载。最坏情况（误删关键组件导致开机循环）恢复出厂也能救回设备，不存在「变砖」。
