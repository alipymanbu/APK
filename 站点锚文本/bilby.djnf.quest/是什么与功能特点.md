# Bilby 是什么与功能特点

> 本篇讲 Bilby 的定位：它是一款什么样的客户端、砍掉了哪些板块、留下了哪些功能，适合什么样的人用。安装与上手步骤见 [上手使用与登录步骤](上手使用与登录步骤.md)。
> **相关文档**：[上手使用与登录步骤](上手使用与登录步骤.md) · [账号安全与使用取舍](账号安全与使用取舍.md)

## 一、一句话定位

Bilby 是一款由第三方开发的哔哩哔哩内容客户端：它把首页直接做成「关注动态流」——你关注了哪些 UP 主，首页就出现谁的更新。推荐流、直播、商城、活动页这些板块一概没有，界面里只剩看视频和追动态这两件事。

## 二、它留下了什么

- **关注动态首页**：订阅式的信息流，下拉即刷新，不掺任何推荐内容；刚登录时首页是空的，关注几位 UP 主之后才会有东西看。
- **完整的观看体验**：视频可发弹幕、点赞、投币；长按点赞会触发一键三连，收藏自动落进账号的默认收藏夹。
- **搜索找内容**：底部搜索框可以找视频，也可以直接搜 UP 主进主页关注，这是给首页「喂」内容的主要方式。
- **稍后再看**：刷动态时遇到当下没空看的长视频，先加进稍后再看，有空统一消化。
- **锁屏听音频**：针对后台播放做了优化，锁屏状态可以持续出声，配合应用内的保活开关，通勤路上当播客听。

## 三、它砍掉了什么

首页没有算法推荐，也没有直播、商城、会员购这些板块；充值、大会员、投稿管理这类操作，在 0.11.1 的界面上没有对应入口，需要回到哔哩哔哩客户端或网页端完成。账号是同一个：你在 Bilby 里发的弹幕、投的币、点的赞，都会落在你自己的 B 站账号上。

## 四、基础信息

| 项目 | 情况 |
| --- | --- |
| 类型 | 第三方哔哩哔哩内容客户端（安卓） |
| 版本参考 | 0.11.1（安装包约 7.45 MB） |
| 系统要求 | 安卓 5.2 及以上 |
| 登录方式 | 扫码授权，无需输入账号密码 |
| 苹果设备 | 暂无对应版本 |

轻量是它最实际的优势：安装包只有几 MB，运行内存占用也低，入门级、小内存的旧机型可以正常带动，这也是不少用户拿它当「备用客户端」的原因。

## 五、适合谁用

追更党最合适——只关心关注的 UP 主更没更新，不想被推荐流拉着刷到半夜。其次是主力机配置一般、想要一个占用低功能聚焦的客户端的人。如果你习惯在主客户端处理充值与直播，刷动态、看视频的部分完全可以交给它，两者可以在同一台手机上并存。

更多界面截图与安装文件资源的入口，见 [Bilby 介绍站](https://bilby.djnf.quest/)。
