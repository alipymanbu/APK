# Bilby 上手使用与登录步骤

> 本篇讲从装好 Bilby 到日常用顺的全过程：扫码授权怎么操作、登录后哪些数据跟着账号走、首页为什么是空的、搜索与追更的日常用法。功能与定位的介绍见 [是什么与功能特点](是什么与功能特点.md)。
> **相关文档**：[是什么与功能特点](是什么与功能特点.md) · [账号安全与使用取舍](账号安全与使用取舍.md)

## 一、第一次打开：扫码授权

Bilby 的登录方式只有一个：扫码。步骤如下：

1. 打开 Bilby，首屏出现登录二维码；
2. 打开手机里的哔哩哔哩客户端，点右上角「扫一扫」；
3. 对准二维码扫描，在弹出的确认页里点确认登录；
4. 回到 Bilby，能进入首页即登录成功。

二维码有时效，放久了会失效，刷新一个再扫就行。全程不需要在这个客户端里输入账号密码——授权确认动作发生在你信任的哔哩哔哩客户端里，这也是它的登录设计里比较让人安心的一点。

## 二、登录后哪些数据跟着走

| 数据 | 跟随情况 |
| --- | --- |
| 关注列表 | 跟账号走，哔哩哔哩客户端里的关注直接生效 |
| 弹幕、投币、点赞、评论 | 跟账号走，主客户端里同样可见 |
| 收藏（一键三连默认收藏夹） | 跟账号走 |
| 保活开关、播放设置等本地配置 | 只在当前手机上，换机要重设 |

简单记：你「做过什么」跟账号走，你「怎么设置的」只跟手机走。

## 三、首页是空的？先关注再说

刚登录时首页大概率一片空白——不是故障，是你还没关注任何 UP 主。两个入口可以解决：

- 用底部搜索框搜 UP 主名字，进主页点关注；
- 用关键词搜内容，从结果里发现合胃口的创作者再关注。

关注之后首页就是一份纯粹的更新清单：谁更新了什么，一眼看完。下拉可以刷新，翻到一半刷新也不会丢位置（0.11.1 已修复旧版下拉后回到列表顶部的问题）。

## 四、日常追更的几个顺手操作

- **稍后再看**：订阅页条目菜单里可以「加入稍后再看」，长视频先存着，有空再看；
- **时间点跳转**：评论里形如 12:34 的时间点可以直接点跳，写评论时用半角冒号更稳；
- **一键三连**：播放页长按点赞即完成点赞、投币、收藏，给常看的 UP 主点支持最快的方式；
- **简介面板**：视频简介在底部面板里展开，不挤占播放画面。

遇到锁屏或切后台后播放中断的情况，多是系统省电机制清了后台：把系统电池设置里放行、打开应用内「音频后台保活」开关即可解决。安装包的获取入口与安装步骤，见 [Bilby 介绍站](https://bilby.djnf.quest/)。
