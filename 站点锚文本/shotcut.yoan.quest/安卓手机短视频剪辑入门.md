# 安卓手机短视频剪辑入门

想在手机上剪出一条能发的短视频，门槛比想象中低：设备是现成的，工具装一个就够，真正决定成片质量的是动手顺序。这篇按「定比例 → 导素材 → 搭结构 → 加包装 → 导出」的顺序，把新手第一次剪辑该做的事捋一遍，工具演示以安卓上的 ShotCut 为例。

相关阅读：[手机视频自动加字幕的方法.md](手机视频自动加字幕的方法.md) · [照片配音乐做成视频的思路.md](照片配音乐做成视频的思路.md)

## 一、先定比例，再动手

发抖音、快手、Shorts 这类平台，用 9:16 竖屏；发横屏平台用 16:9；朋友圈或社区帖子常用 1:1 或 4:5。比例决定画面取舍——横屏素材硬套竖屏框，人物容易被裁掉半张脸。先想好发到哪，再开始剪，比剪完再改省一整轮返工。

## 二、把素材一次导齐

开剪前把要用的视频、照片集中到一个文件夹，导入时一次选完。两点提醒：

- 导入的是素材引用而非复制，剪辑期间别去删动相册里的原文件，否则项目里的片段会变空；
- 素材多、体积大时导入需要等几秒，转圈读完再操作。

## 三、用时间线搭结构

进入编辑界面后，画面下方就是时间线。新手优先掌握四个动作就够用：

| 想做什么 | 怎么做 |
| --- | --- |
| 去掉开头结尾的废镜头 | 拖动片段两端的滑块 |
| 去掉中间一段 | 播放头定位后分割，选中删除 |
| 调整叙事顺序 | 长按片段拖到新位置 |
| 换掉某个镜头 | 用替换功能，位置时长保持不变 |

ShotCut 的多轨时间线把文字、视频、音频、音乐各放一条轨，同屏对照着排；素材段数多时还有批量裁剪，一次给多段设同样的保留区间。这个阶段只管把镜头顺序理顺，先别碰特效。

## 四、加包装：字、乐、节奏

结构顺了之后再做三件事：

1. **字幕**：口播类视频让 AI 自动识别生成字幕条，逐句核对后铺上画面，做法见[手机视频自动加字幕的方法.md](手机视频自动加字幕的方法.md)；
2. **配乐**：按内容场景挑一段免版税音乐，音量压到人声的两三成；
3. **节奏**：给关键镜头加变速或转场——ShotCut 的曲线变速面板里有现成的运动节奏，快慢起伏拖几个点就能调出来。

## 五、导出前完整看一遍

导出很花时间，先完整试播一遍，把错剪都清掉。常规规格选 1080p 就够清楚，普通导出不带水印；导出途中别切去别的应用，部分手机的后台清理会打断任务。

想上手这款工具的话，[ShotCut 安卓剪辑应用拆解](https://shotcut.yoan.quest/)里把界面、功能与安装步骤整理得更全。把上面这条顺序走完一条完整的片子，第二支起就会快很多。
