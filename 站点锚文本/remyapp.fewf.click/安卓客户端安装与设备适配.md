# remyapp 安卓客户端安装与设备适配

> remyapp（Remy）从华为应用市场分发，所以「装上它」的第一步是先有一台装着市场客户端的设备。本篇讲清两件事：安装包从哪里拿、你的设备属于哪种情况。
> 相关篇目：[环绕拍摄重建3D空间玩法](环绕拍摄重建3D空间玩法.md) · [拍摄重建技巧与问题排查](拍摄重建技巧与问题排查.md)

## 一、先分清三个名字

搜 remyapp 的人常把三个名字混在一起：

| 名字 | 是什么 | 和你的关系 |
| --- | --- | --- |
| remyapp / Remy | KIRI 与华为合作首发的 3D 空间记忆应用 | 你最终要用的应用 |
| 华为应用市场（AppGallery） | 华为终端的应用分发平台 | Remy 的首发渠道；需要先装它的客户端 |
| HMS Core（华为移动服务） | 华为帐号与基础服务组件 | 非华为设备上支撑登录、付费、安装记录等功能 |

## 二、安装包从哪里拿

Remy 本体在市场内下载，而市场客户端的安卓安装包已整理进网盘资源：打开 [remyapp 介绍站](https://remyapp.fewf.click/)的下载页，点「获取安装文件资源」进入夸克网盘分享，把文件转存到自己的网盘后下载安装即可——具体四步流程（转存下载 → 允许安装 → 点开 APK → 进市场搜 Remy）在该页写得很细，这里不重复。

## 三、设备适配速查

| 设备 | 怎么装 | 说明 |
| --- | --- | --- |
| HarmonyOS 6 设备 | 自带市场，直接搜 Remy | 独家首发深度适配的平台 |
| HarmonyOS 5.0+ / NEXT | 自带市场，直接搜 Remy | 纯血鸿蒙只支持原生包，不兼容安卓 APK——不需要也不存在「装客户端」这回事 |
| HarmonyOS 2.0 ~ 4.x | 可安装安卓客户端 | 3.0 起需先关闭纯净模式的「增强防护」再装 |
| 华为 EMUI 设备 | 可安装安卓客户端 | 直接安装 |
| 其他品牌安卓设备 | 多数可装（安卓 5.0+） | 建议先装 HMS Core 再登录华为帐号；Remy 能否搜到、能否运行，以市场内实际结果为准 |
| iOS 设备 | 不支持 | 没有对应版本 |

## 四、装好之后

1. 打开应用市场，登录华为帐号（部分设备不登录无法安装应用）；
2. 搜索「Remy」进入它的页面安装；
3. 装好后就能开始环绕拍摄了——玩法见[环绕拍摄重建3D空间玩法](环绕拍摄重建3D空间玩法.md)，拍不出理想效果时翻[拍摄重建技巧与问题排查](拍摄重建技巧与问题排查.md)。

一个容易误会的事：通过市场下载的应用，安装成功后安装包会被市场自动删除——这是设计行为，不是文件丢了。
