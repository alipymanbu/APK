# remyapp 介绍站

remyapp 是 Remy——KIRI 与华为合作在鸿蒙生态首发的 3D 空间记忆应用的常见搜索叫法。本目录整理它的玩法说明与安装获取指引，站点入口见 [remyapp 介绍站](https://remyapp.fewf.click/)。

## 本目录内容

- [环绕拍摄重建3D空间玩法.md](环绕拍摄重建3D空间玩法.md) —— 环绕拍摄、3D 重建与沉浸空间的完整玩法线
- [安卓客户端安装与设备适配.md](安卓客户端安装与设备适配.md) —— 安装获取路径与各类型设备的适配口径
- [拍摄重建技巧与问题排查.md](拍摄重建技巧与问题排查.md) —— 让重建效果更好的拍法，以及装不上、搜不到时的排查
