# 安卓多协议下载器怎么选

> 本篇讲在安卓上挑下载器该看哪几处：协议覆盖、后台保活、扩展能力、维护活跃度，并以 Gopeed 为例把这几项拆开对照。
> **相关文档**：[磁力和种子下载慢的排查思路.md](磁力和种子下载慢的排查思路.md) · [直链大文件为什么要换专用工具.md](直链大文件为什么要换专用工具.md)

---

手机上要下的东西五花八门：安装包是直链、影视资源常是磁力、老收藏里还有电骡链接。多数下载工具只管其中一两类，于是桌面囤了三四个 App 轮流用。挑一个能统一收口的多协议下载器，是省事的第一步。

## 一、先看协议覆盖

一个称手的下载器至少要接住这三类链接：

| 链接类型 | 长什么样 | 常见用途 |
| --- | --- | --- |
| HTTP / HTTPS 直链 | `https://` 开头指向文件 | 安装包、压缩包、文档 |
| BT / 磁力 | `.torrent` 文件或 `magnet:?xt=urn:btih:` 开头 | 大文件分发、资源合集 |
| ed2k | `ed2k://|file|…` 开头 | 电骡网络的历史资源 |

BT 这一类的门槛最高：DHT、PEX、uTP、UPnP 这些环节缺一个，冷门资源就可能找不到同行者。选型时可以直接问一句——不挂 tracker 它能不能动起来，答案如何基本能判断 BT 栈的完整度。

## 二、再看后台保活

安卓对后台应用的清理是下载器最大的隐形杀手：任务下到一半锁屏走人，回来发现进度停了。这不全是软件的问题，但好的下载器会把代价降到最低——任务进度持久化，应用被杀后重开能从已下载的部分继续，而不是从头再来。配合系统里把应用排除出电池优化、多任务卡片加锁，挂机下载才稳。

## 三、扩展能力决定上限

网盘分享页、视频站这类地址贴进任务框通常下不动，因为真实文件地址藏在页面逻辑后面，需要先解析。把这层做成开放扩展机制的下载器，能力上限由社区决定：今天要下某个视频站的合集，装对应扩展就行，不用等软件本体发版支持。

## 四、以 Gopeed 为例对照

上面几项放到 Gopeed 上是这样的：

- **协议**：HTTP/HTTPS、BT、磁力、ed2k 四类原生支持，单任务连接数默认 16、上限 256，支持断点续传；
- **后台**：任务进度持久化，被系统清理后重开继续，配合电池白名单可长期挂机；
- **扩展**：JavaScript 编写、去中心化分发，视频站、网盘、代码托管、文件床都有现成扩展，另有浏览器扩展接管 Chrome / Edge / Firefox 的下载；
- **维护**：Golang + Flutter 的开源项目（GPL-3.0），发版节奏稳定，同一套代码覆盖安卓、桌面与自部署场景。

它的安装包获取入口整理在 [Gopeed 安卓版下载站](https://gopeed.xnyx.quest/)，转存到自己网盘即可下载；装好之后协议用法与参数调整，可接着看[磁力和种子下载慢的排查思路.md](磁力和种子下载慢的排查思路.md)与[直链大文件为什么要换专用工具.md](直链大文件为什么要换专用工具.md)。
