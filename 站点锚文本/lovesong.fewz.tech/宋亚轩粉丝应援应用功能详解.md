# 宋亚轩粉丝应援应用功能详解

> LoveSong 是一款面向时代少年团成员宋亚轩粉丝的应援类安卓应用，由后援会主导开发、目前处于内测阶段。本文把它的功能、界面与定位整理成一篇总览。

## 一、这是一款什么应用

LoveSong 由宋亚轩后援会推出，专为粉丝群体设计，把追星日常里最常见的四件事装进了同一个应用：看行程公告、了解应援物、连接现场灯牌、收集活动印章。应用整体走清新的天蓝色调，首页是圆角卡片配手绘小狗涂鸦，顶部还有一条可以播放的欢迎语音，观感与「小宋」的应援风格高度统一。

它目前处于内测阶段，核心功能优先开放，个人专属空间、粉丝交流社区、独家影像等内容在后续版本里陆续加入。iPhone 版本还在筹备中，现阶段以安卓为主。

## 二、首页四个入口对应四件日常

| 入口 | 能做什么 |
| --- | --- |
| 最新公告 | 演唱会场次、行程变动、应援物购买渠道、限定印章开放时间等重要消息在这里发布 |
| 应援物介绍 | 左右滑动浏览应援棒、灯牌、应援横幅等周边的样式与说明 |
| 连接发光物 | 蓝牙连接应援棒、灯牌与演唱会 mini 灯箱 |
| 收集印章 | 在指定地点扫二维码，把印章收进专属 PASSPORT |

公告的重要性值得单独强调：限定印章的开放窗口、应援物的购买方式这类信息只在应用内公告里首发，出发看演出前先开一次应用确认，比在任何第三方转述里翻找都可靠——巡演计划随时可能调整，应用内的那条才是最新口径。

## 三、几个有记忆点的细节

- **欢迎语音**：首页中间是播放控件，点开能听到属于宋亚轩的语音内容，页面下方一行「ALL FOR SONG」的小字点题；
- **便签式公告**：公告页做成线圈便签的样子，重要的提醒会用红色字标出，阅读重点一眼可见；
- **「轩」字灯效**：连上灯牌后，屏幕中央一个大大的「轩」字就是编辑入口，点进去改颜色、改字体，灯牌实时同步；
- **PASSPORT 集章册**：印章页被设计成一本护照的模样，甜品、小旗、冰淇淋围绕两小小狗，收集进度记在账号上。

## 四、适合谁用

- 准备去看宋亚轩演唱会、想让灯牌跟现场联动的大批粉丝；
- 想第一时间拿到行程与活动通知、不想错过限定活动的关注者；
- 喜欢集章打卡这类仪式感玩法的粉丝。

应用对机型要求不高：安卓 5.2 及以上即可安装，安装包体积不到 50 MB。图文版的功能展示与安装包获取入口，见 [LoveSong 介绍站](https://lovesong.fewz.tech/)。
