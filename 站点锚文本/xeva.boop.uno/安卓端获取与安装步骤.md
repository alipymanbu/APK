# XEva 安卓端获取与安装步骤

> 一句话：讲安卓手机上从哪里拿 XEva 安装文件资源、四步装好，以及安装被阻止等常见问题的处理。
> **相关文档**：[克隆人玩法与训练流程.md](克隆人玩法与训练流程.md) · [情感模式与超级模式花费对比.md](情感模式与超级模式花费对比.md)

---

XEva 目前主要在手机端使用，安卓安装文件资源经由第三方介绍站给出的夸克网盘分享通道获取。本篇只讲流程与避坑；装好之后玩什么，见[克隆人玩法与训练流程.md](克隆人玩法与训练流程.md)。

## 一、从哪里拿安装文件资源

1. 打开介绍站 [XEva 克隆人笔记](https://xeva.boop.uno/)，首页和下载页都有「获取安装文件资源」按钮；
2. 点击按钮会跳转到夸克网盘的分享页面；
3. 登录夸克账号，把文件**转存到自己的网盘**，再从网盘客户端下载到手机本地存储。

提醒：整包下载到手机本地再安装即可，不需要额外工具；下载前建议先确认剩余存储空间够用。

## 二、四步装好

1. **打开分享页**：点介绍站上的获取按钮，进入网盘分享页；
2. **转存并下载**：登录后转存到自己的网盘，再下载安装包到手机；
3. **允许未知来源**：首次安装时系统会提示阻止，按弹窗指引去设置里允许「安装未知应用」，返回重试；
4. **打开应用**：安装完成后打开 XEva，注册或登录，进入广场或开始创建克隆人。

## 三、卡住了怎么办

| 现象 | 处理 |
| --- | --- |
| 提示「禁止安装」 | 进入「设置 → 应用 → 特殊应用权限 → 安装未知应用」，给用来打开安装包的浏览器或文件管理器授权后重装 |
| 网盘页面打不开 | 换系统浏览器打开（部分应用内置浏览器会拦跳转）；转存和下载都要先登录夸克账号 |
| 装好后打开闪退 | 确认系统版本满足要求、空间充足；删掉安装包重新下载一次，排除下载中损坏 |

## 四、装好之后

新用户建议的顺序：先逛广场看看别人怎么玩——加 V 的克隆人会唱歌、写文案、能视频通话；再动手创建自己的克隆人，从人设、声线、容貌到记忆库一点点训练。玩法细节见[克隆人玩法与训练流程.md](克隆人玩法与训练流程.md)；付费前先把两档订阅的差异看完，见[情感模式与超级模式花费对比.md](情感模式与超级模式花费对比.md)。
