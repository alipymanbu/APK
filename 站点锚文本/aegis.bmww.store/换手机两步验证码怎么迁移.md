# 换手机两步验证码怎么迁移

> 换机最怕的不是照片聊天记录，是那些开了两步验证的账号。这篇按「旧机导出 → 新机导入 → 逐条核对 → 收尾」的顺序把迁移走完。
> **相关文档**：[两步验证器怎么选.md](两步验证器怎么选.md) · [两步验证码不对怎么排查.md](两步验证码不对怎么排查.md)

验证码密钥没有「找回」一说——服务端不会替你存第二份（云同步型除外），搬丢了就只能逐个账号走客服流程重绑。所以迁移的核心不是操作多难，而是顺序别错：**先确认新机能出码，再动旧机**。

## 一、旧手机：导出

以本地保险库型的 Aegis 为例：

1. 确认保险库密码还输得进（锁一次屏试试，别等到格机之后才发现忘了）；
2. 「设置 → 导入与导出 → 导出」，格式选 JSON 并保持加密；想让备份文件用独立密码，需要提前在安全设置里开「备份与导出单独密码」；
3. 把导出文件传出新机——数据线、自己的云盘、加密压缩包都行。**别只在旧机里留一份**，那台手机马上就不属于你了。

用 Google Authenticator 的走「转移账号 → 导出账号」，旧机会显示二维码，码多时是分屏轮播的，新机这边要**全部扫完**；用 Authy、Microsoft Authenticator 这类不提供导出文件的，通常要么读取应用数据（需要 root），要么逐个网站重新绑定。

## 二、新手机：导入

1. 装好验证器并走完首次引导（以 Aegis 为例，引导里只能导入它自己的保险库文件；搬别家验证器的码要进「设置 → 导入与导出」选对应来源）；
2. 选中刚传过来的文件，输入加密密码；
3. 导入对话框会显示「导入多少条、跳过多少条」，把这个数字和旧机的条目数对一遍，差得多就回旧机重导。

加密备份弹窗要密码时注意：那个密码是**导出方应用当初设的**，不是新机的解锁密码。

## 三、逐条核对，别只看列表

条目出现在列表里不等于迁移成功：

- 挑三五个最要紧的账号（主邮箱、支付、常用社交），各走一次完整登录，用新机的码通过验证；
- 某一条始终对不上，先按 [两步验证码不对怎么排查.md](两步验证码不对怎么排查.md) 查手机时间和条目参数，还不行就回网站重新绑定这一条；
- 全部核对过，再去处理旧机。

## 四、收尾

1. 新机立刻接上自动备份：保险库加密的前提下，让条目变动时自动写入指定目录；
2. 旧机这时才卸载验证器（或直接恢复出厂）；
3. 备份密码、保险库密码这类信息别只存在旧机里——写在纸上放抽屉也算数，存在旧机里等于没记。

迁移路线本身怎么选（本地保险库还是云同步），见 [两步验证器怎么选.md](两步验证器怎么选.md)；文中提到的功能细节与界面，可以在 [Aegis 验证器介绍站](https://aegis.bmww.store/) 看到对应的截图说明。
