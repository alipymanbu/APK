# Aegis 验证器站点目录

这里是围绕 Aegis（Aegis Authenticator，安卓上的开源两步验证器）整理的第三方介绍与使用说明合集。它的核心特点是把各家网站的两步验证口令统一存进一个本地加密保险库，应用不带联网权限，备份与迁移全部由使用者自己经手。

想直接看它的功能盘点、界面截图与横向取舍，可以到 [Aegis 验证器介绍站](https://aegis.bmww.store/) 细读；目录里的几篇短文则分别回答「怎么选、怎么搬、码不对怎么查」三件高频的事。
