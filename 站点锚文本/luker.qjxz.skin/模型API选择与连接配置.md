# 模型 API 选择与连接配置

> 装好 Luker 后发消息没反应？不是装错了，是还差一步：接入一个大语言模型 API。这篇讲它为什么必须配、有哪些类型可选、以及多套配置怎么管理才省钱。
> **相关文档**：[手机上跑AI角色扮演的实现思路.md](手机上跑AI角色扮演的实现思路.md) · [从酒馆迁移角色卡到手机.md](从酒馆迁移角色卡到手机.md)

## 为什么装完还不能聊

Luker 本身不带模型，它是一个「前端」：把你的消息和角色设定组装成请求发给大语言模型，再把回复渲染成聊天界面。所以第一次使用必须告诉它三件事——用哪家服务、地址是什么、密钥是什么。这一步绕不过去，好在只需配一次。

## 两大类连接

**聊天补全（Chat Completion）**：大多数人用这类。OpenAI（GPT 系列）、Anthropic（Claude 系列）、Google（Gemini 系列）、OpenRouter（一个 Key 聚合多家），以及任何 OpenAI 兼容格式的中转服务都算。

**文本补全（Text Completion）**：主要面向本地或自托管模型——KoboldAI、Ollama、llama.cpp 等。想省 API 费用、手头又有能跑模型的电脑或 NAS，可以考虑这条线，让手机上的应用连本地服务地址。

不确定选哪个，就先走聊天补全。

## 五分钟配好一个连接

1. 点界面顶部的 **API 连接** 图标；
2. 选 API 类型（比如 Claude、OpenAI 或自定义兼容）；
3. 填 API 地址和密钥；
4. 点测试连接，通过后选一个具体模型，回聊天界面试一句。

连不上时先查三处：密钥是否填错或带了多余空格、账户是否还有额度、模型名是否选对。再不行就打开内置的请求检查器（Request Inspector），每次请求的完整内容与返回一目了然。

## 省钱的关键：连接管理器

连接管理器可以并存任意多套配置，切模型不用重填地址密钥：

- 日常闲聊挂一套便宜模型；
- 写长剧情时切到旗舰模型；
- 记忆图、多 Agent 编排这类幕后任务各自只做「提取、检索、规划」的结构化活，单独给它们配一套便宜模型的连接，长期开销能压下去一大截。

还有更快的切换写法：聊天框里 `/profile 名称` 直接换配置，`/profile-list` 列出全部。

## 配好之后

API 通了、模型选好了，接下来就是挑一张角色卡开聊——卡从哪来、怎么捏，可以回到 [从酒馆迁移角色卡到手机.md](从酒馆迁移角色卡到手机.md) 看迁移与导入；应用本身还没装的话，[Luker 安卓端介绍站](https://luker.qjxz.skin/) 有功能介绍与获取入口。
