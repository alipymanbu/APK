# 手机上跑 AI 角色扮演的实现思路

> 想在安卓手机上和 AI 角色长聊、跑剧情，主流有三种路径：纯云服务、远程连接自建服务、本地 APK。这篇把三条路的取舍讲清楚，并给出大多数人适用的选择。
> **相关文档**：[从酒馆迁移角色卡到手机.md](从酒馆迁移角色卡到手机.md) · [模型API选择与连接配置.md](模型API选择与连接配置.md)

## 三条路径的取舍

**一、纯云服务（网页角色扮演站）**：开箱即用，注册就能聊；但角色卡生态封闭、自定义空间小，聊天数据存在别人服务器上，长期玩限制多。

**二、远程连接自建服务**：在电脑或 NAS 上跑一套角色扮演前端，手机用浏览器访问。自由度最高，但需要一台常开的机器、会配端口和内网穿透，门槛偏高。

**三、本地 APK（推荐大多数人）**：装一个独立应用，打开就是完整界面。不用常开的电脑、不用 Termux 刷环境，也不用浏览器输地址——聊天记录和设定都在本机，换网络环境也不影响打开应用。

## 安卓 APK 路线代表：Luker

酒馆圈近年讨论较多的一个选择是 [Luker](https://luker.qjxz.skin/)：它从社区项目 SillyTavern 深度重构而来，保留了角色卡、世界书、预设这套成熟生态，又把数据传输改成增量补丁式——手机流量场景下这点很实在。它的内置工具也齐：记忆图负责长剧情不失忆，多 Agent 编排负责群聊和复杂剧情，都是装好就有、不用逐个找扩展。

APK 版对新手友好的一点是：装完只需再配一个模型 API 就能开聊，配置方法见 [模型API选择与连接配置.md](模型API选择与连接配置.md)；手里已有酒馆数据的，迁移入口就在首次启动的欢迎对话框里，具体见 [从酒馆迁移角色卡到手机.md](从酒馆迁移角色卡到手机.md)。

## 怎么选

| 情况 | 建议 |
| --- | --- |
| 只想偶尔随手聊两句 | 云服务够用 |
| 已有电脑部署、家里常开机 | 远程连接，屏幕大体验好 |
| 手机为主、想带着剧情到处走 | 本地 APK，一步到位 |

功能与获取方式可以在 [Luker 安卓端介绍站](https://luker.qjxz.skin/) 查到，装好后再按需把酒馆数据搬进来。
