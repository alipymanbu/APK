# 不root远程控制安卓手机的方法

> 被控手机没 root 也能远程控制：一条路是开辅助功能（无障碍）授权，另一条路是在电脑上做一次免 root 设置，本篇说清两条路怎么走、权限丢了怎么补。

## 一、方式一：开辅助功能（无障碍）授权

这是最常用的路子，适合运行安卓 7.0 及以上的设备：

1. 被控手机装好 AirDroid 并登录账号；
2. 按提示跳转到系统的无障碍（辅助功能）设置，找到 AirDroid 并允许；
3. 回到 AirDroid 的「安全及远程功能设置」，确认「远程控制」已开启；
4. 从控制端重新发起一次连接即可。

这条路不用连电脑，几分钟搞定；代价是无障碍权限属于敏感权限，部分品牌的系统会盯得比较紧（见第三节）。

## 二、方式二：电脑上做一次免 root 设置

无障碍方式在个别机型上不稳，可以改走桌面客户端：

1. 电脑上安装 AirDroid 桌面客户端并登录同一账号；
2. 用数据线把被控手机连到电脑，按客户端里的「免 root」引导操作一次；
3. 完成后拔掉数据线，之后从 AirMirror 发起远程控制就不受 root 限制。

这个设置做一次长期有效，适合打算长期远程管理这台设备的情况。

## 三、权限被系统收回去怎么办

控制突然失灵、画面能动但点不动，多半是被控端的无障碍权限被系统自动关闭了——魅族等品牌的机型在 App 更新或重装后尤其常见。处理办法：

- 回系统设置的无障碍页面，重新开启 AirDroid 的授权；
- 或改用上面第二节的免 root 方式，绕开无障碍这条依赖。

免 root 之外的连接问题（账号、网络、后台存活）属于另一类，排查思路见 [手机怎么远程控制另一台安卓手机.md](手机怎么远程控制另一台安卓手机.md)；两端各装什么、从哪里发起，也可以先看 [AirMirror 介绍站](https://airmirror.gkhf.beer/) 再动手。
