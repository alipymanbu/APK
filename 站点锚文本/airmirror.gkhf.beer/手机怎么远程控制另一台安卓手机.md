# 手机怎么远程控制另一台安卓手机

> 两台安卓手机，一台当操控端、一台当被控端：各装什么、账号怎么配、权限开在哪，本篇按实际操作顺序讲清。

**相关文档**：[不root远程控制安卓手机的方法.md](不root远程控制安卓手机的方法.md) · [远程协助爸妈处理手机问题.md](远程协助爸妈处理手机问题.md)

## 一、先分清两端，各装各的

手机控制手机靠的是两个 App 搭配，不是装一个就够：

| 角色 | 装什么 | 干什么 |
| --- | --- | --- |
| 操控者手里这台 | AirMirror（控制端） | 发起远程控制、查看远程相机、镜像屏幕 |
| 被操作的那台 | AirDroid（被控端） | 接受连接，交出屏幕、相机与通知 |

两个 App 都是同一开发者出的，界面长得像但分工一头一尾：要「管别人」的装 AirMirror，被「管」的那台装 AirDroid。两端都建议安卓 7.0 或更高版本。

## 二、连接四步

1. 两端各装好对应 App，注册并登录**同一个账号**；
2. 被控端在 AirDroid 里按提示完成授权引导，并在「安全及远程功能设置」里开启「远程控制」；
3. 打开 AirMirror，进入「设备」页，选中要操作的那台手机；
4. 点「远程控制」，接通后对方的屏幕就投过来了，点按、滑动都在本地完成。

配对关系、界面入口与注意事项，整理在 [AirMirror 介绍站](https://airmirror.gkhf.beer/)，对着页面看比凭记忆找按钮省事。

## 三、连不上，先查这几项

- 两端是否都登录了**同一账号**（最常见的原因）；
- 被控端的 AirDroid 是否被系统省电机制杀掉了后台——小米、华为、OPPO、vivo、三星、魅族各有自己的自启动与后台规则，按机型设置允许后台运行；
- 网络是否通畅：优先 Wi-Fi 或 4G/5G，公共 Wi-Fi 常常把设备间的连接拦下来；
- 以上都正常仍连不上，重启两端再发起一次。

跨网（不在同一 Wi-Fi 下）使用会消耗账户的远程数据流量，免费账户每月额度有限，长时间跨网操作前先看一眼账户余量。
