# wuwubox 是什么软件？功能与界面一次看懂

## 一、一句话定位

wuwubox 是一款安卓端的影视聚合应用，圈子里常叫它「绿色盒子」：把电影、电视剧、综艺、动漫整合进一个界面，打开就能搜片、看榜单、直接播放，界面为简体中文。它不做复杂的账号体系，装上打开就是片库，上手门槛很低。

## 二、界面就四个页签

底部一排页签，所有功能从这里进出：

| 页签 | 干什么 |
| --- | --- |
| 首页 | 推荐与最新内容，顶部搜索框（占位词会轮播热门片名）、下载入口、播放历史都在这页 |
| 排行 | 热播榜、飙升榜等榜单按名次列片，条目自带「立即播放」 |
| 分类 | 按类型分组的片库，海报右下角带评分 |
| 我的 | 收藏、下载管理与个人设置的落脚点 |

首页还有一排内容标签：推荐、新剧、华语、欧美、日韩、动漫，横向滑出更多；海报上直接标「53 集全」「更新至 24 集」这类进度，追剧的时候不用点进去数。

## 三、播放与缓存

- **播放**：详情页或榜单条目上点「立即播放」就进播放页；播放页提供线路选项，当前线路卡顿时换一条接着看；
- **缓存**：详情页与播放页都有缓存入口，支持单集与整部缓存，下完在下载管理里，断网也能看；
- **续播**：首页时钟图标是完整播放历史，记到第几分钟，点条目接着上次的进度放。

## 四、适合谁用

- 不想在多个平台之间来回切换找片的人；
- 通勤或出差路上想离线看剧的人——缓存功能正好补上没网的场景；
- 选片困难户：榜单配评分、条目带导演主演信息，照着刷就行。
