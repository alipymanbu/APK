# wuwubox 卡顿、闪退怎么处理？分现象排查

> 播放转圈、画面卡、点开就退，按现象对号入座，从最快的办法试起。
> **相关文档**：[是什么软件.md](是什么软件.md) · [怎么安装到手机.md](怎么安装到手机.md)

---

## 一、先分清是哪一类

「用不了」其实是三件不同的事：

| 现象 | 归哪类 |
| --- | --- |
| 安装时就报错 | 安装问题，先看 [怎么安装到手机.md](怎么安装到手机.md) 第四节 |
| 装好了，点图标闪退 | 本文第二节 |
| 能打开，播放卡、转圈 | 本文第三节 |

## 二、闪退、点开就没反应

按出现频率排序，逐条试：

1. **彻底关掉重开**：从后台划掉再点图标，偶发的启动失败这一步就解决；
2. **清缓存**：系统「设置 → 应用管理 → wuwubox → 清理缓存」。只清缓存，别点「清除数据」（会清掉播放历史与设置）；
3. **查存储与后台**：存储快满时应用写不进临时文件，容易启动即退；后台应用太多也会被系统杀掉，清一批再试；
4. **查网络**：首屏就要拉数据，连着需要网页认证的 Wi-Fi 时应用可能直接退出，换流量对比一次；
5. **卸载重装**：以上都不管用，重新下载安装一遍——下载中断产生的坏包，本来就是闪退的常见原因。

## 三、播放卡顿、转圈

1. **先换一部片子定性**：换了就不卡，是原来那部的片源问题；几部都卡，往下查手机与网络；
2. **换线路**：播放页里提供线路/源选项，卡顿时换一条再播，这是最直接的自救手段；
3. **等缓冲、别猛拖进度**：刚点开就拖到后面，缓冲要从头追，看起来像「越拖越卡」；
4. **关掉占带宽的东西**：同一 Wi-Fi 下有设备在下载或在放 4K 视频，都会把带宽吃光；
5. **清缓存、重启应用**：后台待久了的偶发卡顿，彻底关掉重开多半恢复。

## 四、只有声音没画面

通常是解码或该条线路异常：先等 5~10 秒；持续定格就退出重进或换线路；换了线路仍如此，换一部片子验证——别的正常，就是这一部的片源问题。

## 五、都不行的时候

确认手机自身网络正常的前提下，卸载后重新走一遍安装（入口见 [怎么安装到手机.md](怎么安装到手机.md)），重装后收藏与缓存会被清掉。日常的界面与功能介绍，也可以回到 [wuwubox 介绍站](https://wuwubox.fewz.tech/)翻一遍再定位问题。
