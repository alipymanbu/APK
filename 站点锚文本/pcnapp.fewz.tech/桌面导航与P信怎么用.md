# PCNapp 桌面导航与P信怎么用？一张桌面管住日常入口

> 本篇讲 PCNapp 装好后的核心玩法：三栏上网桌面怎么摆、CAS 程序是什么、P信聊天在哪，顺手给出几条省时间的设置建议。

## 一、打开就是一张桌面

PCNapp 与常见应用不同的地方在于它的首屏形态：打开不是信息流，而是一张「上网桌面」。顶部是搜索框（默认走百度搜索），中间按格子摆放常用网站，底部导航挂着首页、P信、我、更多四个入口。

还没安装的先看 [怎么下载安装到手机](怎么下载安装到手机.md)，装好再回来对照操作。

## 二、三栏桌面各管什么

| 栏目 | 用途 |
| --- | --- |
| 我的桌面 | 自己添加的常用网址，一处添加长期保存 |
| 推荐桌面 | 应用内推荐的现成入口，不想自己挑时直接用 |
| CAS 程序 | 应用内的小程序位，打卡、计步等任务入口挂在这里 |

习惯养成的建议：把真正每天打开的三五个网站放进「我的桌面」，其余的留在推荐桌面里随取随用——格子越少，这张桌面越好用。

## 三、P信与个人中心

- **P信**：应用内置的聊天模块，支持单聊、群聊与表情语音，账号与桌面、任务体系通用，不用单独注册；
- **我**：签到入口、任务列表与积分资产都从这里进，具体玩法见 [签到领P币任务玩法](签到领P币任务玩法.md)；
- **更多**：设置、清理缓存与账号信息所在，登录状态异常时先到这里检查当前登录的手机号。

## 四、两条使用提醒

1. 部分功能会申请存储、位置等权限，只当导航与聊天用的话，可在「设置 → 应用 → PCNapp → 权限」里按需关闭；
2. 桌面里的推荐入口指向的第三方站点与本资料无隶属关系，打开后的交易、注册行为请自行留意页面条款。
