# 国内机场贵宾室怎么挑不白跑

> 国内主要机场确实接入了这个贵宾室网络，但「搜到了」和「进得去」是两回事。本篇讲旅客类型标签怎么读、为什么跨航站楼常常去不了，以及出发前怎么把一家贵宾室核对到位。

## 一、先看条目上的旅客类型

每家贵宾室在应用里都标着旅客类型，这是决定能不能进的第一个条件：

| 标签 | 面向 | 进得去的前提 |
| --- | --- | --- |
| Domestic / 国内 | 国内航班出发 | 手里是国内航段的登机牌 |
| International / 国际 | 国际航班出发 | 手里是国际航段的登机牌 |
| Schengen / Non-Schengen | 申根区内 / 区外航班 | 行程方向与标签对得上 |
| In Transit / 转机 | 转机旅客 | 人处于转机区通行范围内 |

同一个机场里，两家的标签可能完全不同。你飞国内段，国际出发那家标签再好也进不去——标签对不上时，到门口被拦是机场安检侧的规定，不是前台为难人。

## 二、跨航站楼，多数去不了

这是白跑最集中的一类情况：你在 T3 登机，贵宾室在 T2，而两栋航站楼在安检后不互通——凭会籍刷不开机场安检，这点要在出发前想清楚。

判断顺序：

1. 确认贵宾室在你**已经能到达的那一侧**：条目位置说明会写「安检后（空侧）」还是「安检前（陆侧）」；
2. 有捷运或摆渡互通的机场，也要确认是**安检前**互通，还是本来就安检后互通；
3. 联程中转时，人待在转机区，只有落在转机区里的贵宾室才用得上。

## 三、大陆机场的分布特点

北京、上海、深圳等主要机场都有接入，机场检索里能直接查到北京首都（PEK）、北京大兴（PKX）、上海虹桥（SHA）、上海浦东（PVG）、深圳宝安（SZX）等。整体分布偏向国际出发侧，国内出发段可选的少——飞国内航段时，先确认该航站楼有没有标注 Domestic 的贵宾室，别默认随便哪间都能进。

贵宾室网络随时增删，营业时间与规定也会变，一切以应用里条目当时显示为准。

## 四、出发前把四件事过一遍

1. 航站楼：只看与你登机航站楼一致的条目；
2. 旅客类型：与你的航段匹配（国内段、国际段或申根方向）；
3. 时间：营业时间盖得住你的航班，最长逗留时间够用；
4. 备选：顺手记下同航站楼的第二家，第一家满员或临时关闭时不用现查。
