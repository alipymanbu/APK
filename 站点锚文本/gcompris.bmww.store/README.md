# GCompris 站点目录

这里是 GCompris（KDE 社区出品的开源儿童学习活动合集，面向 2~10 岁孩子）的第三方介绍与使用说明目录，收录活动体系、安装上手与家长设置相关的整理文章。

软件的站点入口：[GCompris 介绍站](https://gcompris.bmww.store/)，里面有两页内容——软件介绍页讲清它适合谁、活动怎么按年龄挑；下载页带安卓版的获取与安装步骤。
