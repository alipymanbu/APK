# 儿童启蒙学习活动有哪些

> 给 2~10 岁的孩子挑学习内容，往往不是缺素材，而是素材太散。这篇按 GCompris 这套开源学习软件的分类，过一遍学龄前到小学低年级各阶段能练什么、怎么挑。
> **相关阅读**：[安卓版怎么装到老平板上](安卓版怎么装到老平板上.md) · [给孩子用前先调好的几个设置](给孩子用前先调好的几个设置.md)

---

GCompris 是 KDE 社区维护了二十多年的儿童学习活动合集，把启蒙内容拆成一个一个的小活动，每个活动只练一件事：认一个字母、拨一次时钟、混一种颜色。最新的 26.x 分支里活动总数有 197 个，按类别挂在主界面上，孩子像逛游戏厅一样一格格玩过去。

## 七个类别，各练各的

| 类别 | 练什么 |
| --- | --- |
| 探索电脑 | 认识键盘、鼠标、触摸板，学会"指挥"设备 |
| 阅读 | 字母、单词、短句，一步步靠近文字 |
| 算术 | 数数、比大小、四则运算、乘法表 |
| 科学 | 运河闸门、水循环、可再生能源这类直观小实验 |
| 地理 | 认国家、认地区，把世界拼图摆回原位 |
| 游戏 | 国际象棋、四子棋、记忆配对，跟设备真对弈 |
| 生活认知 | 颜色、形状、认时钟、盲文，低龄起步的基础盘 |

竖屏使用时类别栏会移到左侧；算术这类大类下还有子分类（数数、算术、测量）做二次过滤，找某类题不用一层层翻。

## 看星星挑活动，不用记参数

每个活动图标上都有星星，颜色标年龄段、颗数标难度：

- **黄星（2~6 岁）**：2~4 岁先玩颜色、形状、认识时间这类没有失败惩罚的纯探索活动；
- **红星（6 岁以上）**：8~10 岁可以上科学实验、国家拼图和国际象棋这类有策略深度的。

同一个活动内部还分难度级，进活动后用底部的左右箭头就能切级，没过完当前级也能直接跳。所以不必按年龄死对号——孩子从最低级开始，觉得太简单就升一级，卡关了就降回来。

## 各年龄段的一条主线

- **2~4 岁**：生活认知类打底，键盘鼠标类的随意点按当玩具，目标是"敢点、愿意点"；
- **5~7 岁**：数数与简单运算、字母与单词，配上记忆配对棋，练一段换一类换换脑子；
- **8~10 岁**：科学和地理类展开，棋类对弈开始讲输赢，正好练"输了再来一盘"。

各分类在[GCompris 介绍站](https://gcompris.bmww.store/)里有更展开的说明和真实界面截图，装之前可以先看看活动长什么样；装法与设备适配见[安卓版怎么装到老平板上](安卓版怎么装到老平板上.md)。
