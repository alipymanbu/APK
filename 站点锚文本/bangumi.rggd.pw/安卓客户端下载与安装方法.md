# Bangumi 安卓客户端下载与安装方法

> 本篇整理 Bangumi 安卓客户端的安装渠道现状与完整安装步骤：从哪里拿到 APK 安装包、手机上如何授权安装、装好之后怎么登录使用。想先了解这个客户端能做什么，可以看[追番进度管理与超展开使用入门](追番进度管理与超展开使用入门.md)。

---

Bangumi 是 bgm.tv（番组计划）社区的移动端第三方客户端，基于 React Native 构建，以 MIT 协议开源，免费且无广告。由于应用商店渠道的分发已经停滞，安卓端目前主要通过 APK 安装包的方式获取。

## 安装前的三件事

1. **确认系统版本**：客户端要求 Android 5.0 及以上，主流智能手机基本都满足。
2. **认准安装包来源**：APK 文件建议从整理好的介绍站或项目发布页获取，避免来路不明的二次打包版本。
3. **准备一个网盘账号**：安装包经由夸克网盘分享，转存前需要一个免费注册的夸克账号。

## 四步完成安装

1. **打开资源入口**：进入 [Bangumi 安卓客户端介绍站](https://bangumi.rggd.pw/)，页面上「获取安装文件资源」按钮就是网盘分享入口，首屏与页面右下角都有。
2. **转存并下载**：在网盘分享页把 `bangumi_v8.24.7.apk`（约 36 MB）转存到自己的网盘空间，再下载到手机本地。
3. **允许未知来源安装**：首次点开 APK 时系统会提示禁止安装，按弹窗指引允许刚才用来下载的那个应用（浏览器或网盘 App）安装即可，各品牌手机弹窗略有差异但流程一致。
4. **登录账号开始使用**：安装完成后打开客户端，登录 bgm.tv 账号（没有可当场注册），收藏与追番进度会自动和网页端同步。

## 安装常见问题

- **提示「安装被阻止」**：这是系统的未知来源限制，授权对象是下载 APK 的那个应用，重新点开安装包即可继续。
- **打开后闪退**：先确认系统是 Android 5.0 以上；若满足仍异常，删掉安装包重新下载一次，排除文件损坏。
- **内容加载空白**：条目数据来自 bgm.tv 社区，首次启动需联网拉取，检查网络后下拉刷新即可。
