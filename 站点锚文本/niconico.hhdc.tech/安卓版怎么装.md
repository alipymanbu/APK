# Niconico 安卓版怎么装：从拿到安装包到首次打开

> 本篇讲在安卓手机上安装 Niconico 应用的完整流程：安装包从哪里来、系统拦截怎么处理、第一次打开后先设什么。弹幕功能本身怎么用，见 [弹幕怎么看](弹幕怎么看.md)。
>
> 相关文档：[弹幕怎么看](弹幕怎么看.md)

---

## 装之前：两个前提

- **系统**：安卓手机均可尝试，应用体积不大（几十 MB 级别），老机型也能跑；
- **安装包来源**：应用通过网盘分享的方式分发，转存到自己网盘后再下载，比直接点陌生链接稳得多。

安装包与图文介绍都收在 [Niconico 弹幕视频指南](https://niconico.hhdc.tech/) 的下载页里，按指引进网盘分享页即可。

## 四步装完

1. **转存并下载安装包**：打开网盘分享页，把安装包转存到自己的网盘账号，再从网盘下载到手机存储；
2. **允许「安装未知应用」**：首次点开 APK 时系统会拦截，按提示给所用浏览器或文件管理器授权——这是安卓对应用商店之外安装的标准防护，授权一次即可；
3. **完成安装并打开**：装完点「打开」，启动页会有两个入口：登录注册，或「以访客身份开始」；
4. **首次启动先做两件事**：进设置把**弹幕透明度**调低一点、加几条 **NG 关键词**，然后随便点开一部人气视频感受一下。

不确定要不要注册？可以先走访客入口逛一圈，想发弹幕、订阅作品时再注册也不迟。

## 卡住了怎么办

- **点安装没反应**：多半是「未知来源」没授权。进系统设置 → 应用 → 特殊应用权限 → 安装未知应用，给打开 APK 的那个应用授权后重来；
- **打开后加载不出来**：应用需要联网，检查网络与 App 的联网权限；部分内容登录后可看的范围更完整；
- **界面是日文**：设置里找「言語 / Language」，部分版本提供简体中文；没有语言选项的版本保持日文也不影响操作，主要按钮位置是固定的。

装好之后去哪试手？回到 [弹幕怎么看](弹幕怎么看.md) 看一遍常用弹幕习惯，再开一部排行榜上的视频，十分钟就能上手。
