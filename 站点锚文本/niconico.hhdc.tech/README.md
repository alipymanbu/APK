# Niconico 站点目录

这里是 Niconico（ニコニコ動画）相关内容的索引页。Niconico 是 2006 年上线的日本弹幕视频社区，评论会按时间点叠进画面里飞过，动画、音乐、游戏实况与直播内容各有板面。

本目录整理两篇常被问到的话题：弹幕怎么看、安卓手机上怎么装。更完整的介绍（含 App 功能清单与常见问题）见 [Niconico 弹幕视频指南](https://niconico.hhdc.tech/)。

- [安卓版怎么装](安卓版怎么装.md)：从拿到安装包到首次打开的完整步骤，以及安装被阻止时的处理思路
