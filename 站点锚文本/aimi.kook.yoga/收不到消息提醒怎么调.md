# Aimi 消息不提醒时的逐项排查

> 这篇解决一个具体麻烦：消息没有提醒、提醒延迟几个小时，打开应用才看到新消息——按什么顺序把手机设置过一遍。
> **相关文档**：[自己捏一个专属AI角色.md](自己捏一个专属AI角色.md)

---

## 一、先分清是哪一种「收不到」

三种情况的病根不同，先对号入座，再往下动手：

| 现象 | 更可能的原因 |
| --- | --- |
| 一直不提醒，打开应用才看到新消息 | 通知权限没给全，或后台被系统清了 |
| 提醒延迟几分钟到几小时 | 省电 / 省流量模式在限制后台联网 |
| 应用里也收不到消息、界面一直转圈 | 不是提醒问题，是网络或应用本身，重启应用、切网络再试 |

顺带一条正常现象：手机刚重启后一段时间收不到提醒，是因为应用还没被系统拉起，手动打开一次 Aimi 就会恢复，不用改任何设置。

## 二、把通知权限给全

按华为、vivo 等厂商客服页的通用路径（各家菜单名略有差异）：

1. 进「设置 → 通知 → 应用通知管理」，找到 Aimi。
2. 打开「允许通知」，横幅、锁屏、角标、提示音按需全开。
3. 关掉「静默通知」类选项——静默意味着消息只进通知栏，不响也不弹。
4. Android 13 以上系统，首次启动会弹一次通知权限询问；当时点了「不允许」，通知类功能就全失效了，就是在这里补开。
5. 部分版本还要在应用内的设置里再开一次消息提醒开关，两处都确认到才算给全。

## 三、别让系统把后台清掉

后台被杀，推送自然到不了。三件事按顺序做：

- **自启动**：设置里搜「自启动」，允许 Aimi 自启动。
- **后台加锁**：最近任务里找到它的卡片，下滑加锁，防止一键加速把它清掉。
- **后台耗电**：设置里搜「后台耗电管理」，允许后台高耗电。华为机型对应「应用启动管理」里关掉自动管理、手动允许自启动与后台活动。

## 四、关掉省电与省流量的限制

这两项是**提醒延迟**最常见的根因：

- 「设置 → 电池」关掉省电模式；部分品牌在「后台使用限制」里把应用设为不受限。
- 「设置 → 电池优化」里对 Aimi 选不允许优化。
- 「智能省流量」关掉，或把 Aimi 加进豁免名单——省流量模式下应用后台不联网。
- 长按图标进应用信息 → 流量，确认「允许后台流量」开着。

## 五、还没好的话

- 「勿扰」与专注 / 睡眠模式会按白名单放行通知，确认应用不在被拦的名单里。
- 个别对话若开了「消息免打扰」，只有那一路不提醒，属应用内设置。
- 以上都试过仍收不到，卸载重装一次；安装包的获取方式与安装步骤，见 [Aimi 玩法介绍](https://aimi.kook.yoga/) 里的安装文件资源一节。

通知调顺之后，角色回复基本都能实时弹出；想让提醒里多几个值得等的角色，可以照 [自己捏一个专属AI角色.md](自己捏一个专属AI角色.md) 造一两个自己的。
