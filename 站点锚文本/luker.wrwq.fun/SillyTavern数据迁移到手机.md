# SillyTavern 数据迁移到手机

> 本篇讲怎么把电脑或 Termux 上酒馆（SillyTavern）里的数据整箱搬到手机：哪些能搬、三种搬家路径怎么选、为什么随时还能搬回去。
> **相关文档**：[安卓酒馆从安装到开聊.md](安卓酒馆从安装到开聊.md) · [AI角色扮演总失忆怎么办.md](AI角色扮演总失忆怎么办.md)

---

## 一、哪些数据能直接用

Luker 基于 SillyTavern 构建，数据格式 100% 双向兼容——这意味着迁移不是「导入导出」，而是「换个地方继续住」：

| 数据类型 | 迁移后 |
| --- | --- |
| 角色卡（.png / .json，V1 / V2） | 直接可用 |
| 聊天记录（.jsonl） | 直接可用 |
| 世界书（World Info） | 条目原样生效 |
| 预设 | 直接可用，连接参数会被自动分离出来 |
| 用户人设、群聊、扩展设置 | 直接可用 |
| API 密钥（secrets.json） | 格式不变，直接可用 |

唯一搬不动的是 Luker 独有功能（记忆图、多 Agent 编排）产生的状态文件——它们在酒馆里没有对应物，但也不会干扰原始数据。

## 二、三种搬家路径

按你原来的酒馆跑在哪选：

- **电脑 / 服务器 / Docker**：把酒馆的 `data/` 目录内容整体复制进 Luker 的数据根目录，首次启动自动识别加载。这是最省事的主路径。
- **Termux → 手机**：安卓沙盒不让两个应用直接互拷，走「打包 ZIP → 首启向导导入」：在 Termux 里把 `~/SillyTavern/data` 打成 ZIP 放进 Download 目录，装好后欢迎向导中间的「Migrate from SillyTavern」选它导入即可。子目录层级不用纠结，导入器能自动识别。
- **只想搬几张卡**：不用走迁移，在应用里逐张导入 .png / .json 角色卡就行。

错过了首启向导也没关系：电脑路径直接复制文件就能补上；Termux 用户清一次应用数据可让向导重现（先导出值得保留的聊天记录）。

## 三、去留自由

迁移是双向的。哪天想搬回酒馆，把数据目录复制回去就完事——Luker 生成的那几个状态文件酒馆不认识，忽略即可，不会报错。

两条老生常谈但必须再说的提醒：

1. **动手前先备份**：原数据目录整体拷一份再操作，「随时能回退」的前提是原数据没被动过；
2. **预设会拆开**：Luker 把预设里的连接参数分离出来，API 连接和提示词预设从此是两套东西——换模型不再拖着整套提示词跑，这是和原版使用习惯差别最大的一点，也是最受欢迎的一点。
