# 安卓酒馆从安装到开聊

> 本篇讲怎么在安卓手机上跑起一间 AI 酒馆：拿安装包、装好、接上模型、导入角色卡，四步迎来第一段对话。全过程不需要 Termux，也不需要电脑陪跑。
> **相关文档**：[SillyTavern数据迁移到手机.md](SillyTavern数据迁移到手机.md) · [AI角色扮演总失忆怎么办.md](AI角色扮演总失忆怎么办.md)

---

## 一、为什么选手机端

跑 AI 角色扮演的人，早晚都会遇到同一个坎：酒馆（SillyTavern）功能全，但要 Node、要终端、要一台常开的机器。想在手机上玩，Termux 折腾一遍也得掉层皮。

[Luker 安卓版](https://luker.wrwq.fun/)把这件事简化成了「装一个 App」：整套服务端直接打包进 APK，后端就跑在手机里，点开图标酒馆就开张。界面支持简体中文，首启向导里切一下语言即可。

## 二、安装四步

1. **拿安装包**：从网盘分享页把安装包转存到自己的账号，再用网盘客户端下载到手机。安装包约 400 MB，建议预留 1 GB 存储余量。
2. **允许未知来源**：在文件管理器里点 APK，系统提示「禁止安装未知来源应用」时，按指引允许你的文件管理器安装应用。
3. **首启选中文**：装完打开，「Welcome to Luker!」向导顶部就是语言选择器，切到简体中文，界面即时切换。
4. **接模型开聊**：点顶部 API 连接图标，选 API 类型（OpenAI、Claude、Gemini 或兼容格式都行），填地址与密钥，选一个模型；再导入一张角色卡，发出第一条消息。

系统要求为安卓 5.2 及以上；软件本体开源（AGPL-3.0），花费只来自所接入模型服务的按量计费。

## 三、装好之后的进阶路线

开聊只是起点，这间酒馆还有几样值得慢慢摸熟的家当：

- **记忆图**：聊天内容沉淀成知识图谱，几百轮前的伏笔也能召回，长剧情不再失忆，原理与开启方法见 [AI角色扮演总失忆怎么办.md](AI角色扮演总失忆怎么办.md)；
- **多 Agent 编排**：多个 Agent 先做剧情分析再交给创作模型落笔，群戏、长线故事的好帮手；
- **AI 捏卡**：用自然语言改角色卡，改动逐条以差异形式确认，捏卡速度翻倍；
- **局域网同步**：手机与电脑上的两个实例配对后，聊天记录、角色卡、世界书自动保持一致。

之前在电脑或 Termux 上养了一屋子角色卡的，不用从零开始——数据能整箱搬过来，步骤见 [SillyTavern数据迁移到手机.md](SillyTavern数据迁移到手机.md)。
