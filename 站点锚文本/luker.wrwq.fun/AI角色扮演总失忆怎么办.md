# AI角色扮演总失忆怎么办

> 聊了几百轮，角色忘了早期的约定、人物关系乱了套——本篇讲清 AI 角色扮演「失忆」的真实原因，以及记忆图怎么把长剧情的记忆接回来。
> **相关文档**：[安卓酒馆从安装到开聊.md](安卓酒馆从安装到开聊.md) · [SillyTavern数据迁移到手机.md](SillyTavern数据迁移到手机.md)

## 一、失忆不是卡的错

先说结论：角色聊久了忘事，是所有大语言模型上下文窗口的固有限制——对话太长，最早的内容被挤出窗口，模型自然「想不起来」。换角色卡、重roll 都治不了本。

治本的思路是给模型外挂数据库：把对话里值得记住的信息存下来，每轮回复前把最相关的部分重新注入上下文。这套机制在酒馆生态里通常靠世界书 + 总结插件拼装，而在 [Luker 安卓版](https://luker.wrwq.fun/)里，它是一个开箱即用的内置功能——**记忆图**。

## 二、记忆图怎么工作

记忆图是一张知识图谱：聊天内容被持续提炼成带类型的节点（人物、地点、事件、剧情线），节点之间连线成网。每轮回复生成前，先走一遍图、把与当前剧情最相关的记忆注入上下文。

实际体感是这样的：主角回到几十章前去过的地方，当年在那里出场、之后长期没戏份的角色会被重新提起；第 3 轮埋的钥匙，第 300 轮还能掏出来开门。早期剧情细节被引用时也不再张冠李戴。

## 三、开启与省钱两件事

开启路径只要五分钟：打开扩展抽屉 → Memory → 把 Enable 打开。默认配置即可用，真正要动手的是给「写入」和「召回」各指定一套模型配置——这两步各自调用模型，但都是结构化的提取检索活，**不必动用主聊天的旗舰模型**，单独配一套便宜模型的连接，长期跑剧情能省下大笔开销。

两个值得调的开关：

- **提取间隔**：默认每轮回复都提取，设成 2 就是两条提一次，模型调用直接减半；
- **召回方式**：默认的 LLM 召回最省事，先用它；RAG 召回更快但要额外配向量检索，用顺手了再研究。

## 四、和酒馆数据的关系

从酒馆搬过来的数据不含记忆图内容（那是 Luker 的新增状态文件），用一段时间后备份自然会包含它们；哪天搬回酒馆，这部分图数据看不了，但原始聊天记录、角色卡毫发无损。搬家的具体操作见 [SillyTavern数据迁移到手机.md](SillyTavern数据迁移到手机.md)。
