# XbotGo 设备配对与固件升级：连不上时的排查顺序

> 本篇讲应用怎么和 Chameleon、Falcon 建立连接：两条通道各干什么、配对步骤、连不上的逐条排查，以及固件升级的两个坑。

## 一、先分清两条通道

很多人把「连不上」怪在蓝牙上，其实设备与应用之间有两条通道，各干各的：

| 通道 | 走什么 | 干什么 |
| --- | --- | --- |
| 配对与控制 | 蓝牙 | 设备发现、初始配对、控制指令 |
| 数据传输 | 设备发出的局域 Wi-Fi 热点 | 画面回传、监看、文件传输 |

由此有两个实用结论：场地里没外网也能正常拍（只有直播才需要互联网）；配对一直转圈时，先断开手机上无关的 Wi-Fi 再试。

## 二、配对四步

以 Chameleon 为例，Falcon 流程相同：

1. 设备电量充足，长按电源键开机，等开机自检的上下校准动作做完。
2. 手机打开应用并登录账号。
3. 点「添加设备」，在列表里点 `Xbot` 开头的设备完成配对。
4. 进入控制界面能看到摄像头画面，说明两条通道都通了。

机身侧面那盏状态灯是好判据：呼吸式慢闪是可配对状态；常亮表示已被某台手机连着——不是你的话，先让旧手机断开。

## 三、连不上的排查顺序

**列表里有设备但连不上：** 确认电量 → 设备管理页点刷新 → 完全关闭应用重开 → **双击设备电源键重置蓝牙** → 重启设备 → 让占用的手机断开 → 清理手机里不用的历史蓝牙记录。

**列表里刷不出设备：** 蓝牙开关 → 应用的蓝牙与位置权限 → 等设备完成自检 → 关掉省电模式 → 再走一遍双击电源键与重启。

都试过还不行，换一台手机试连，用来区分是设备问题还是手机问题。

## 四、固件升级的两个坑

应用与设备固件是配套的，连接异常、追踪发飘时第一步永远是两边都升到最新：应用里「我的 → 设置 → 固件升级」，有更新按提示走完。看不到升级入口时，退出账号重新登录、重连设备再找。

另外 Falcon 充电有讲究：用非苹果的 PD 快充（最高 18W），升级固件前先把电充满。

配对完成后，开拍前的设置见 [自动追拍与机位摆放要点.md](自动追拍与机位摆放要点.md)；应用还没装好的，先过一遍 [安装包获取与安装步骤.md](安装包获取与安装步骤.md)。更多玩法整理在 [XbotGo 场边介绍站](https://xbotgo.fwen.ren/)。
