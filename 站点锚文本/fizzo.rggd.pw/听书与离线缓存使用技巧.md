# Fizzo 听书与离线缓存使用技巧

装好 Fizzo 之后，真正拉开体验差距的是两个功能：听书和离线缓存。一个解放双眼，一个解放网络——组合起来，追更这件事几乎不受场景限制。

> 还没装好的话，先看[下载安装步骤与常见问题](./下载安装步骤与常见问题.md)。

## 听书：阅读页里的耳机图标

进入任意一本小说的阅读界面，点一下屏幕唤出菜单，找到**耳机图标**点击即可——应用会用语音合成把当前章节朗读出来，不需要下载额外的语音包或插件。

几个适合切听书的场景：

- 通勤路上挤地铁，看屏幕费劲；
- 做家务、做饭，双手被占着；
- 睡前想闭目养神，又想知道剧情走向。

朗读进度与阅读进度是连贯的，切回文字接着读也不会乱。

## 离线缓存：提前把书装进口袋

追更最怕两种时刻：地铁进隧道、月底流量见底。Fizzo 的做法是把故事**整本下载到本地**：

1. 打开想追的小说详情页；
2. 找到下载入口，把当前已更新的章节整体缓存；
3. 之后在无网络环境下也能从书架直接打开。

建议在 Wi-Fi 环境下提前缓存，长途出行前一晚把在追的书全部更新一遍，路上就完全不看网络脸色。

## 书架：小说与短剧一起管

Library 书架是整个追更流程的中枢——小说和短剧混放在同一处，哪本更新了、哪部剧追到第几集，都集中提示。配合按 Genre、Character、Trope 三个维度的题材筛选，找下一本书的成本很低。

应用会根据读完的书和看过的剧持续调整推荐，用得越久，首页推送越对味。

## 从哪开始

安装入口在 [Fizzo 站点](https://fizzo.rggd.pw/)，经夸克网盘转存即可获取安装文件资源。
