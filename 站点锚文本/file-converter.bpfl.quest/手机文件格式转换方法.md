# 手机文件格式转换方法：不用电脑也能转

> 手机收到一份打不开的文件、要把 Word 转成 PDF 发出去、或者想给 Kindle 塞几本书——这些事都可以直接在手机上完成。本篇按文件类型整理安卓端的转换思路，并落到一款覆盖面足够宽的工具上。
> **相关文章**：[视频转GIF动图与铃声制作](视频转GIF动图与铃声制作.md) · [电子书格式互转方法](电子书格式互转方法.md)

## 一、先看文件属于哪一类

手机上的格式转换工具基本都按文件类别组织入口，先分清类别再找输出格式，路才不会走岔。以功能覆盖比较全的 File Converter 为例，它的转换器分成这些类别：

| 类别 | 典型需求 | 常见输出 |
| --- | --- | --- |
| 文档 | Word 转 PDF 定稿、纯文本互转 | DOCX、ODT、RTF、PDF |
| 表格与演示 | 报表给程序读、幻灯片打印 | XLSX、CSV、PPTX、PDF |
| 图片 | 照片压缩、透明背景、网页小图 | JPG、PNG、WebP、SVG |
| 音频 | 无损转有损、提取音轨 | MP3、FLAC、WAV、AAC |
| 视频 | 全平台能播、压体积 | MP4、MKV、WebM |
| 电子书 | 给不同阅读器喂书 | EPUB、MOBI、AZW |
| 工程类 | 图纸、模型、轨迹、字幕 | DWG、STL、GPX、SRT |

最后一行值得单独说：CAD 图纸、3D 模型、GPS 轨迹、字幕这类冷门文件，手机上能转的工具屈指可数，挑选工具时可以优先确认这几类的支持情况。

## 二、弄清转换发生在哪

安卓端转换工具有两种工作方式，直接影响体验：

- **云端转换**：文件上传到服务器处理，速度快、手机不发热，但全程要联网。文档、图片、表格这类小文件走这条线最舒服。
- **本地转换**：转换在手机上完成，文件不出设备、没有网也能转，代价是耗时与耗电，大视频尤其明显。

File Converter 的划分方式比较清楚：文档、电子书、图片、表格、CAD 等类别走云端，音频和视频走本地离线转换。用它转录音录像素材时不用担心流量，转扫描件和大 PDF 则建议连 Wi-Fi。

## 三、一次转换的三步流程

1. **选文件**：点进对应类别的转换器，从手机里挑文件，支持跨目录多选，一批图片或一组文档可以一起挂上；
2. **选输出格式**：在类别页点选目标格式，需要精细控制就展开高级设置——OCR 识别、音频比特率、视频旋转与裁剪、电子书的目标阅读器型号都在这一层；
3. **取结果**：任务后台排队，完成后从任务列表里把结果文件存回手机或直接分享给别的应用。

上传云端这类转换提交后就可以切出去干别的，完成会有通知；本地转换（尤其视频重编码）就别把应用从后台清掉了，任务被杀只能重来。

## 四、几个容易踩的坑

- **带密码的文件转不动**：加密的 PDF、ZIP 不在支持范围，先解密再转；
- **DRM 内容转不动**：商店购入的带版权保护电子书、音乐必然失败，没有变通办法；
- **扫描件转出来还是图片**：高级设置里勾上 OCR 文字识别，图里的字才会变成可编辑文本；
- **GIF 转出来巨大**：先裁时长再降尺寸，源视频越短越小越好，具体参数见[视频转GIF动图与铃声制作](视频转GIF动图与铃声制作.md)。
