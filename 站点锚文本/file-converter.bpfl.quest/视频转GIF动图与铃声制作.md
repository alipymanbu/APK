# 视频转GIF动图与铃声制作：手机上的两条高频路线

> 视频派生出来的转换需求里，转 GIF 动图和提取音频做铃声是出现最多的两条。两条路在安卓上都能离线完成，本篇把参数怎么调、体积怎么压、铃声怎么剪一次说清。
> **相关文章**：[手机文件格式转换方法](手机文件格式转换方法.md) · [电子书格式互转方法](电子书格式互转方法.md)

## 一、视频转 GIF：先剪短，再缩小

GIF 没有压缩率可言，体积几乎只由时长和分辨率决定。File Converter 的视频转换器支持这条路线，而且走本地离线转换，素材不出手机。操作顺序：

1. 进视频转换器，选好源视频，输出格式挑 GIF；
2. 高级设置里先**裁剪（trim）时长**——只留要表达的那几秒，10 秒和 3 秒的动图体积差好几倍；
3. 把**输出尺寸降下来**：发聊天工具宽度 320~480 像素足够看清，1080P 源直接转出来的文件谁都发不出去；
4. 提交转换，转完先自己播一遍再发。

最后一步不是多虑：GIF、MP4 这条路线偶尔会产出打不开或表现异常的文件，转完先检查，不正常就重转一次，仍不行就换个时段再试（这条路线走的是本地转换，重转不花流量）。

## 二、提取视频音频：文件不出手机

同一个视频源，输出格式改选 MP3、M4A、AAC 等音频格式，就是提音轨。这条同样走离线转换。音频的高级设置里有三样可调：

| 参数 | 作用 | 怎么选 |
| --- | --- | --- |
| 比特率 | 音质与体积的平衡 | 音乐 192kbps 起步；人声、讲座 96~128kbps 够用 |
| 采样频率 | 高频细节 | 常规内容保持默认，老转录素材才需要纠结 |
| 裁剪 | 只保留一段 | 提高潮片段、做铃声前先在这里剪 |

一个事实提前知道：转出音频的质量上限就是源视频里的音轨质量，源是低码率的，把输出比特率调多高都不会变好，只会变大。

## 三、做成手机铃声

铃声本质是一段剪好的音频文件，用上面第二步的提取加裁剪就能做：

1. 从视频或音频源文件转出音频，裁出想要的段落——安卓铃声建议控制在 40 秒以内，太长系统会自动截断；
2. 安卓直接用 MP3 / M4A，转完在系统声音设置里指定成铃声；
3. 给 iPhone 做的话输出格式选 M4R，转完通过电脑导入。

想要「把文章读出来」而不是提取原声——比如把一篇电子书变成听书音频——那是文字转语音的路线，走法不一样，入口在文字类源文件的音频输出方向上。

## 四、为什么这两条路适合离线

音频和视频是 File Converter 里少数不联网的转换类别：录音录像素材往往体积大、隐私敏感，走本地既不耗流量，文件也始终只在手机里。代价是中端手机转两小时视频可能要跑几十分钟且明显发热——插着电转、别清后台，是仅有的两条注意事项。这套云端与离线的分工细节，整理在 [file converter](https://file-converter.bpfl.quest/) 介绍站的「转换在哪跑」一节，处理大批量视频任务前值得先看一眼。
