# 电子书格式互转方法：EPUB、MOBI、AZW 怎么选

> 从网上下到的书打不开、传进 Kindle 显示格式不支持、换阅读器后书库全要重下——电子书格式的问题几乎人人遇得到。本篇按阅读器整理格式偏好，并给出手机端的转换路子。
> **相关文章**：[手机文件格式转换方法](手机文件格式转换方法.md) · [视频转GIF动图与铃声制作](视频转GIF动图与铃声制作.md)

## 一、先对号：什么设备吃什么格式

| 设备 / 场景 | 格式偏好 |
| --- | --- |
| Kindle（电子墨水屏） | AZW、MOBI，新机型也吃 EPUB 导入转换 |
| 手机阅读 App（多看、微信读书导入等） | EPUB 最通用 |
| 电脑上看 | PDF 排版固定不跑版；DOCX 方便继续改 |
| 老款阅读器 | FB2、PDB、LRF 这类旧格式各有地盘 |

判断顺序很简单：先看手里的阅读器支持什么，再看手里的书是什么，中间差的那一段就是需要转换的部分。

## 二、手机端怎么转

安卓端的转换工具里，电子书是 File Converter 覆盖比较全的一个类别：输出方向包含 AZW（Kindle）、EPUB、MOBI、FB2、PDB、RTF、DOCX、HTML、TXT、PDF 等，基本把上面表格里的目标格式都接上了。操作路径与其它类别一致——进电子书转换器选文件、挑输出格式、提交转换。

两个专属于电子书的可调项值得展开：

- **元数据**：书名、作者信息可以在这里改，转换完书库里显示的名字就是它，批量整理书库前先把这层理顺；
- **目标阅读器型号**：高级设置里可以指定 Kindle、Kobo、Nook 等型号，选对型号能省掉不少排版跑偏的问题——有用户反馈电子书转完排版乱，多数就是这一项没选。

## 三、两条转不动的边界

- **带密码的电子书文件**：加密文件不在支持范围，先解密再转；
- **带 DRM 保护的购入书**：商店买的部分电子书带数字版权保护，这类内容转换必然失败，这是行业通行的限制，换任何工具结果一样。

遇到打不开的书，先排除这两种情况再怀疑工具。

## 四、转完排版乱了怎么办

电子书转换是云端处理，格式本身的兼容性比文档类更挑：

1. 回到高级设置确认目标阅读器型号选对了；
2. 换一个输出方向重试（EPUB 乱就试 MOBI，反过来也一样）；
3. 源文件本身排版混乱（网页爬下来的 EPUB 常这样）就别指望转换修复，那是源的问题。

转换提交后一直报错的排查思路（网络、加密、体积）与文档类相同，参考[手机文件格式转换方法](手机文件格式转换方法.md)的坑点列表即可。

## 五、工具与入口

电子书转换在手机端工具里算检验成色的试金石：格式列表短的工具转 Kindle 书基本没戏。File Converter 的完整输出格式清单（含电子书之外的视频、音频、CAD 等类别）整理在 [file converter](https://file-converter.bpfl.quest/) 介绍站，安装包也从那里获取指引进入，装好后按本篇第一节的对照表选输出格式就行。
