# 免费版能用多少功能

> 动作库类应用常被问一个问题：不付费到底能不能正常用？本篇把 MuscleWiki 免费版的能力边界一次讲清，帮你判断要不要直接上付费版。

## 一、主线功能不设限

查动作、看视频、学姿势这条主线路径，免费版完全开放：

- 动作库（实拍视频 + 分步说明）可用；
- 基础交互人体地图可用；
- 1RM、热量、宏量营养计算器可用；
- 核心功能支持离线运行，信号差的场馆也能用；
- 查动作、看视频不需要注册账号。

## 二、分界线在「保存数量」

免费与付费的主要差别集中在保存上限（公开付费页口径）：

| 功能 | 免费版 | 付费版 |
| --- | --- | --- |
| 个性化计划 | 最多 3 个 | 不限 |
| 自定义例程 | 最多 3 个 | 不限 |
| 进度追踪 | 最多 3 条 | 不限 |
| 数据分析 / 进阶筛选 | 无 | 有 |
| AI 课表生成 | 无 | 有 |

3 个例程对「胸 / 腿 / 背」三分化刚好够用；想按周排更细的课表、多套计划轮换，才会碰到天花板。

## 三、判断方法

先免费跑一个月：如果 3 个例程从没觉得不够，就没必要付费；一旦开始轮换多套课表、想看容量走势，再考虑升级也不迟。价格随地区与活动有变动，以应用内结账页显示为准。

相关阅读：[点身体地图找动作](点身体地图找动作.md)、[新手第一周怎么安排训练](新手第一周怎么安排训练.md)。

功能的完整拆解与安卓安装文件获取方式，见 [MuscleWiki](https://musclewiki.wxhp.skin/) 介绍站。
