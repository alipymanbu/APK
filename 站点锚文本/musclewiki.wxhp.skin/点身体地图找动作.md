# 点身体地图找动作是什么体验

> 健身动作库类应用不少，但「在一张人体图上点部位、直接出动作清单」的交互并不多见。本篇讲这种玩法到底顺不顺手、适合谁，以及想练某个部位时的实际操作路径。

## 一、为什么「点地图」比「搜动作名」省事

多数时候健身者的起点不是「动作名」，而是「今天想练的部位」。传统动作库要你先知道动作叫什么，再搜名字；点地图的思路反过来：

1. 打开就是一张人体图，正面 / 背面可切换；
2. 点发亮的区域——胸、背、肩、手臂、腹、腿、臀；
3. 大肌群下还有子部位（胸分上中下、背分背阔肌与斜方肌），能点到很细；
4. 出来的动作列表再按手头器械一筛，剩下的全能直接练。

整个流程不需要记任何肌肉学名，新手第一次打开也不会迷路。

## 二、筛器械这一步才是精髓

光点部位还不够，动作做不了的原因十有八九是「没有那件器械」。按器械过滤把这个问题直接消掉了：家里只有哑铃就锁哑铃分类，什么都没有就锁徒手；在健身房凳子被占，切到绳索或哑铃分类，同一部位马上换替代动作。

常见分类覆盖：徒手、杠铃、哑铃、壶铃、固定器械、史密斯机、绳索、弹力带、悬挂带、拉伸、瑜伽、药球、平衡球、杠铃片，基本囊括居家到商用健身房的全部场景。
