# 支持的引擎与游戏文件摆法

tyranor 是一款跑在安卓手机上的多引擎视觉小说运行器，很多玩家第一次用它时卡住的不是安装，而是「游戏文件夹怎么摆才能被认出来」。本篇讲清它识别引擎的思路、各类游戏目录该长什么样，以及扫描相关的几个设置。

**相关文档**：[添加游戏与路径选择](添加游戏与路径选择.md) · [手势与常见问题排查](手势与常见问题排查.md)

---

## 靠特征文件认引擎，不靠文件名

tyranor 扫描目录时，判断一个文件夹「是什么游戏」的依据是目录里的**特征文件**，而不是游戏名。所以同一个文件夹里文件摆对位置，比改名重要得多。认出引擎后，运行会交给对应的引擎环境，玩家全程不需要手动选择。

## 各类游戏目录长什么样

- **KRKR / Kirikiri 2**：目录里有 `.xp3` 封包或 `startup.tjs`。这类游戏多数以压缩包形式分发，放进手机前要先解压，让 `.xp3` 露在目录里——直接把整个 zip 丢进去是扫不出来的。
- **Artemis Engine**：认 `system.ini` 与 `.pfs` 封包。
- **RPG Maker / RPG Maker MZ**：网页运行时结构，分别看 `js/rpg_core.js` 与 `js/rmmz_core.js` 是否存在。
- **Tyrano / TyranoScript**：目录里有 `index.html` 加 `tyrano/` 文件夹。
- **VN Maker**：认 `globalData.vndata`。
- **ONS / ONScripter**：认 `nscript.dat` 与 `.nsa` 资源；这个引擎是 v2.3.4 版本新增的，旧版本要先升级。

## 文件摆放的三个约定

1. **根目录的 Tyranor 文件夹**：游戏解压或整体放进手机存储根目录下的 `Tyranor` 文件夹，这是默认的扫描起点。
2. **封面图命名**：把图片命名为「封面」（jpg / png 均可），放进 `index.html`、`root.pfs` 或 `system.ini` 所在的那一层文件夹，游戏列表里就会显示这张图；不命名则使用内置封面。
3. **扫描开关**：「其他 → Tyranor 设置」里有「启动时扫描」开关和「启动时扫描最大深度」，游戏藏在层级较深的子目录时把深度调大；确认无误后重开应用，游戏会按引擎自动归类陈列。

## 版本差异值得留意

v2.3.4 的更新里有两处直接影响兼容面：一是新增 ONS 引擎支持（可扫描 SD 卡内的 ONS 游戏）；二是修复了 KR2 游戏在非中文语言环境下的启动闪退。手头版本较旧、遇到「目录都摆对了还是不认」的情况，先升级再排查。

更多图文对照（含真机设置页截图）整理在 [tyranor 模拟器介绍站](https://tyranor.boop.uno/)，引擎特征、摆放方式与设置项一一对应。
