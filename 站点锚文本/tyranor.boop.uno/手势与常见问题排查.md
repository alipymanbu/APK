# 手势与常见问题排查

游戏跑起来之后，tyranor 的操作以触屏滑动为主；这一篇把常用手势列成表，再收几个真会挡路的故障：黑屏、闪退、存档迁移。

**相关文档**：[添加游戏与路径选择](添加游戏与路径选择.md) · [支持的引擎与游戏文件摆法](支持的引擎与游戏文件摆法.md)

---

## 游戏内手势速查

| 手势 | 作用 |
| --- | --- |
| 单指从文本框向右滑 | 关闭当前文本框 |
| 单指上滑 | 打开文本记录（回顾已读对话） |
| 单指下滑 | 打开游戏内设置 |
| 双指点屏幕中央 | 返回 |
| 三指右滑 | 文本快进，跳过已读段落 |

这套手势在多数引擎下通用；个别 RPG 玩法多的游戏，触屏不便时可以考虑外接键盘或手柄。

## 黑屏与闪退

- **先退出重进**。相当一部分「黑屏」只是加载中断，重开应用就好。
- **Artemis 游戏卡住、起不来**：给该游戏单独开**兼容模式**（逐游戏生效）；仍不行再开全局的**慢速加载**——注意它需要预留不小于游戏体积的存储空间，加载也偏慢，属于救急手段。
- **KR2 游戏一启动就闪退**：v2.3.4 已修复非中文语言环境下的启动闪退，旧版本先升级；升级后仍闪退，进「KR2 游戏设置」把**图形渲染器**换一条路线（默认走软件渲染器，可配合限制 FPS 到 60fps 观察稳定性）。

## 存档与数据

v2.3.4 支持把 SD 卡里 KR2 游戏的存档**导出到 Android/data** 目录，换机或备份时把这一块整体拷走即可。已扫描的游戏列表有缓存，重装应用后重新扫一遍目录就能恢复陈列。

## 游戏列表是空的

按顺序查三件事：游戏是否放在根目录的 `Tyranor` 文件夹；KRKR 游戏是否解压出 `.xp3` 所在目录；「启动时扫描」是否开启、扫描深度是否够。三处都对还不显示，就用「添加」手动指一次路，顺便确认目录结构没摆错。

更多排查思路与设置页截图见 [tyranor 模拟器介绍站](https://tyranor.boop.uno/)，遇到新问题可以先去那里对一对界面。
