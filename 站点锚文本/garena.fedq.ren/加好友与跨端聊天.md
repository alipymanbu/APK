# Garena 加好友与跨端聊天

> 本篇讲在 Garena 手机版上怎么找到你的朋友：按 ID 搜索、扫码添加，聊天里能发什么，以及消息发不出去时先查什么。
> **相关文档**：[账号注册登录与安全设置.md](账号注册登录与安全设置.md) · [手机版功能分区与上手路径.md](手机版功能分区与上手路径.md)

---

Garena 手机版把聊天做成了常驻功能，也是很多玩家装它的主要理由：人不在电脑前，PC 客户端上的好友喊话照样收得到。前提是已经登录了账号，注册与登录见[账号注册登录与安全设置.md](账号注册登录与安全设置.md)。

## 先找到聊天入口

打开应用后点上方（或底部）的聊天 / 好友入口，这里集中了好友列表、加好友和会话记录。不同版本的入口位置可能微调，认准「聊天」或「好友」字样即可。

## 两种加好友的方式

**方式一：按好友 ID 搜索**

1. 进聊天入口，选「查找好友 / Add Friend」（也可以点首页右上角的信息图标，再点加号里的发现好友）；
2. 输入对方的好友 ID——让对方在他的个人资料页把 ID 报给你，直接发一串文字过来复制粘贴最稳；
3. 搜到后发送好友申请，等对方通过。

**方式二：扫码添加**

查找好友页同时提供二维码：你的二维码在自己的资料页里，见面时让对方扫你的码（或你扫他的），比手动输 ID 快。

搜不到人多半是 ID 输错。另外注意：同意好友申请后，好友关系要过一段时间才会在游戏内显示，一小时到一天不等，不用着急。

## 聊天里能做什么

- 发文字消息，单聊或群聊；
- 发语音、发图片，比如发一张战绩截图、一局回放的画面；
- 在群聊里约组队时间、丢攻略链接。

聊天和平台内容是联动的：从资讯流或战绩页看到好友的动态后，直接切到聊天里聊，不用退出去翻好友列表。

## 对方在用 PC 客户端怎么办

不用怎么办——直接发。Garena 的聊天在手机端和 PC 端互通，你的好友哪怕此刻坐在电脑前用 Garena PC 客户端，你从手机发的消息他也能收到，回你也是同一条会话。换手机也一样：新手机装好登录原账号，好友与资料跟随账号走。

## 消息发不出去、收不到时先查三样

1. **网络** —— 应用需要联网，Wi-Fi 和流量切一下试试，部分网络环境访问海外服务不稳定；
2. **登录态** —— 长时间没用可能被登出，回到登录页重新登录；
3. **应用版本** —— 太老的版本可能连不上服务器，重装或更新一份；安装文件资源的获取入口见[Garena 手机版介绍站](https://garena.fedq.ren/)。

好友加好之后，去[手机版功能分区与上手路径.md](手机版功能分区与上手路径.md)看看查战绩、领转盘奖励这些入口的位置。
