# Garena 账号注册登录与安全设置

> 本篇讲 Garena 账号怎么注册、登录方式怎么选、密码与两步验证在哪设置，以及验证码收不到时的排查顺序。
> **相关文档**：[手机版功能分区与上手路径.md](手机版功能分区与上手路径.md) · [加好友与跨端聊天.md](加好友与跨端聊天.md)

---

Garena 手机版的聊天、战绩查询、转盘奖励都挂在账号上，装好后第一件事就是把账号弄好。注册在应用内直接完成，不需要去别的地方办。还没装应用的话，先从[Garena 手机版介绍站](https://garena.fedq.ren/)拿安装文件资源。

## 注册一个新账号

1. 打开 Garena，进入登录页，点「注册」（或「Create Account」之类的入口，以页面实际显示为准）；
2. 选注册方式（手机号或邮箱等，以注册页实际提供的选项为准，不同地区开放方式可能不同）；
3. 填入手机号或邮箱，等验证码（短信或邮件），填入完成验证；
4. 设置密码（需包含大小写字母、数字和符号），完成注册后登录。

两个常踩的小坑：

- 手机号要带正确的区号，用海外号码注册时区号选错，验证码就发不到；
- 验证码邮件容易掉进垃圾箱，收不到先翻垃圾邮件，再点一次重发。

## 登录已有的账号

| 情况 | 做法 |
| --- | --- |
| 记得密码 | 直接输账号（手机号或邮箱）+ 密码 |
| 忘记密码 | 点「忘记密码」，按提示通过绑定的手机号或邮箱找回 |
| 用第三方账号注册过 | 用对应的第三方登录方式进入 |

手机端和 PC 客户端是同一套账号：早就玩过 Garena 平台游戏的，直接用老账号登录手机版即可，好友和战绩是连着的，不需要重新注册。

## 密码与两步验证

改密码的路径是 **My Account（我的账号）→ Security Settings（安全设置）→ Change Password（修改密码）**，从应用内可以跳转。密码强度要求可以直接当清单用：至少 8 个字符、大小写混用、含数字与特殊字符、不在其他平台复用。

两步验证在同一处设置里：**Security Settings → Two-Factor Authentication**，按页面提示开启。开启后每次新设备登录都会多一道验证码，账号被盗的门槛高很多。

## 绑定邮箱与手机号

密码忘了、设备丢了，能找回账号全靠事先绑定的邮箱和手机号，两项都在 **My Account → Account Settings** 里设置：

- 邮箱：填入后收验证邮件，点确认链接；
- 手机号：填入后收短信验证码（OTP）填入。

两项都绑是最稳的做法——邮箱负责找回，手机号负责身份核验。趁账号还新鲜，把绑定和两步验证一次做完。

## 验证码收不到，按顺序查

1. 区号选对没有，区号错一位短信就发不到；
2. 邮箱验证码翻垃圾箱；
3. 等一分钟再点重发，短时间内反复请求可能触发冷却，等十几分钟到半小时再试；
4. 查手机端的骚扰拦截，验证码短信可能被静默收进「已屏蔽」，顺带确认收件箱没满；
5. 手机号渠道不行换邮箱渠道，反之亦然；
6. 邮件渠道长期收不到（比如曾退订过 Garena 邮件），提交工单恢复接收。

账号安全问题（被封、异常登录、道具不对劲）走应用内的客服入口提交，准备好账号信息和截图；验证码不给任何人，冒充客服的人才会索要密码或 OTP。
