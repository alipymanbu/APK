# Sonolus 添加服务器与搜索谱面的方法

> 装好后首页空空如也？内容全靠服务器提供。本篇讲服务器地址从哪拿、怎么添加、进去之后怎么搜到想打的谱面。
> **相关文档**：[音游引擎平台是什么与玩法特色.md](音游引擎平台是什么与玩法特色.md) · [安卓版安装与首次设置步骤.md](安卓版安装与首次设置步骤.md)

## 一、为什么必须加服务器

Sonolus 客户端本体不内置任何曲目——它只提供判定、渲染、回放这些骨架。曲目、谱面、排行榜全部由服务器提供，所以「添加服务器」是上手路上绕不开的一步。刚装好时打开看到空首页或者只有寥寥几个预置入口，都不是出了问题。

同一个客户端可以同时挂多台服务器，每台通常对应一套玩法或一个社区的曲库，点哪台进哪台。

## 二、服务器地址从哪拿

三条常见路子，按省事程度排：

1. **社区服务器列表站**：有玩家维护的公开列表，按游戏与社区分类给出地址，复制即可用；地址可用性以列表页当时显示为准。
2. **邀请链接**：不少服务器提供 `open.sonolus.com` 形式的直达链接，手机浏览器点开会直接唤起应用并停在添加页面，确认保存就完成了。
3. **手动填写**：已经知道服务器域名时，在添加表单里直接粘贴。

## 三、手动添加的完整步骤

1. 首页点**开始**，进入服务器选择页。
2. 找到**自定义服务器**一栏，点它下方的**添加**——注意别点到「收藏夹」下面的添加，那是收藏夹自己的入口。
3. 表单里**名称**随便写（只是自己的备注），**地址**粘贴拿到的服务器链接，确认提交。
4. 应用连上服务器读取信息，加载完可改显示名，再点下一步完成。
5. 回到列表，点刚加好的那项即可进入。

## 四、进服务器后怎么搜谱

1. 进入服务器后点**关卡**，首屏只展示最近或推荐的一批；点**更多**看全量，或点放大镜搜索。
2. 搜索关键字一般要用**原文**：日文曲名打日文、英文曲名打英文，中文译名或罗马音经常搜不中。
3. 同一首歌的不同歌手、不同难度会被拆成多个关卡，点开前看关卡左上角的曲目 ID 与难度信息确认。
4. 第一次玩先点**配置**把流速调顺手，再点开始——流速、皮肤这些都是逐关卡的设置，随时可改。

## 五、两个常见坑

- **提示引擎不兼容**：说明那台服务器还跑在旧版引擎上，1.x 正式版客户端只认新引擎；加服务器前先看它的说明。
- **想离线玩**：首次加载关卡需要联网；之后在关卡详情页点「保存」收进收藏夹，资源留在本机，断网也能从收藏夹打开。
