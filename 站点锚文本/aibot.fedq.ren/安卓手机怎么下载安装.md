# 安卓手机怎么下载安装 AIbot

AIbot 没有上架统一的应用商店，获取方式走网盘资源：把安装文件转存到自己的夸克网盘，再用手机下载安装。这篇把从拿到文件到打开应用的每一步列清楚，功能介绍见 [AIbot 能用来做什么](能用来做什么.md)，主入口在 [AIbot 应用介绍站](https://aibot.fedq.ren/)。

## 一、安装前确认三件事

| 项目 | 应该是 |
| --- | --- |
| 系统版本 | Android 5.2 及以上 |
| 存储空间 | 留出几百 MB 空闲 |
| 安装包版本 | 1.1.2（46.31 MB） |

版本号以拿到的安装包为准：不同渠道收录的版本可能不同，装好后可在 App 的设置或关于页核对。

## 二、四步装好

1. **拿到安装文件**：打开 [AIbot 应用介绍站](https://aibot.fedq.ren/) 上的获取入口，进网盘分享页，选中安装包点「保存到网盘」；
2. **下载到手机**：打开手机上的夸克 App，在「我的网盘」里找到刚保存的安装包，点下载；
3. **允许安装**：在下载列表或文件管理器里点开这个 .apk，系统弹出「是否允许安装」时点允许；安卓 8 以上会细到「允许来自此来源的应用」，对文件管理器（或下载用的 App）开一次开关即可；
4. **完成并打开**：进度走完后点「打开」，首次进入按引导同意用户协议与隐私政策、放行网络与存储权限，就能开始用了。

在电脑上操作也行：网页端转存后用夸克客户端下载，再通过数据线或微信文件传输助手把安装包传到手机。

## 三、装不上时的对照

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 提示「未知来源」 | 安卓默认只放行应用商店 | 按提示允许「来自此来源安装」，只需开一次 |
| 解析包出错 | 安装包没下完整 | 回网盘重新下载一次再装 |
| 覆盖安装失败 | 已装同包名的其他来源版本 | 先卸载旧版再装（会清本地数据，先导出） |
| 打开就闪退 | 系统版本不够或文件损坏 | 确认安卓版本；重新下载安装包 |

## 四、装好之后

四个板块（聊天 / 创作 / 绘画 / 数字人）在底部导航一字排开，第一次用建议从 AI 聊天进，问一两个实际问题找找手感；绘画玩法另见 [AI 绘画一句话出图怎么玩](AI绘画一句话出图怎么玩.md)。

安装文件资源与最新介绍都收在 [AIbot 应用介绍站](https://aibot.fedq.ren/)，换机重装前记得先把生成的图片和文件导出——它们默认只存在手机本地。
