# AIbot 的 AI 绘画怎么玩：一句话出图的门道

AIbot 的绘画板块走「描述词 + 风格 + 尺寸」三步，门槛低，但出图质量主要卡在描述词上。这篇给一套能直接套用的描述词组织方式、几个现成例子和常见翻车的改法。应用的整体功能见 [AIbot 能用来做什么](能用来做什么.md)，还没装的话先走 [安卓手机怎么下载安装](安卓手机怎么下载安装.md)，主入口在 [AIbot 应用介绍站](https://aibot.fedq.ren/)。

## 一、描述词的五个槽位

文生图通用的一句结构：**主体 + 细节 + 场景 + 风格 + 画质**。在描述框里按这个顺序一次说全，比生成后再补救省次数。

| 槽位 | 作用 | 例子 |
| --- | --- | --- |
| 主体 | 画面核心 | 「一个穿汉服的少女」「一只橘猫」 |
| 细节 | 外观、动作、道具 | 「手持团扇」「毛茸茸、戴红色项圈」 |
| 场景 | 在哪、什么氛围 | 「樱花树下」「窗台边，柔和的光」 |
| 风格 | 画风方向 | 「漫画风格」「水墨风」「赛博朋克」 |
| 画质 | 清晰度与质感 | 「高清」「细节丰富」「壁纸级」 |

修改的技巧是换槽位不换整句：先只换主体看方向，再换场景，最后换风格——每次动一处，才知道哪个成分在影响出图。

## 二、三个能直接抄的例子

- 手机壁纸：「一只橘猫躺在窗台，午后阳光，柔和的光，高清，竖屏壁纸」
- 漫画人物：「短发少女，校服，站在天台，风吹起头发，漫画风格，高清」
- 小说推文配图：「雨夜小巷，霓虹灯倒影，一个人撑伞的背影，电影感，细节丰富」

按用途倒推着写：画漫画人物就把细节花在脸部与服饰；做壁纸写清「竖屏、留白位置」；推文配图直接把书里那一幕的场景写进去。

## 三、翻车对照表

| 现象 | 多半是 | 改法 |
| --- | --- | --- |
| 出图和描述对不上 | 一次塞了太多不相关元素 | 砍到一个主体 + 一个场景，重生成 |
| 人物脸崩 | 没写清人物特征 | 补「特写/半身、发型、表情」 |
| 画面太空或太挤 | 没说构图 | 加「特写」「全身」「留白」这类词 |
| 风格不像 | 只写了「好看」没锁定画风 | 换具体画风词（水墨、漫画、赛博朋克等） |

绘画页开放的基础项就是描述词、风格与尺寸；其他工具里常见的种子、步数这类进阶参数这里没有，找不到不用怀疑自己漏了步骤。

## 四、出图不理想时的处理顺序

1. 先改描述词里最薄弱的一段（通常是细节或场景）；
2. 再换风格选项；
3. 最后换尺寸重试；
4. 连续失败或一直转圈属生成服务问题，先确认网络，隔段时间再试。
