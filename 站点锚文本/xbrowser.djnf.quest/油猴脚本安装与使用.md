# xbrowser 油猴脚本安装与使用

> 在桌面浏览器上用油猴脚本，得先装 Tampermonkey 这类管理器扩展；xbrowser 把脚本管理器直接做进了浏览器，拿到脚本就能装。这篇讲安装的两种方式、去哪找脚本、装完没反应怎么查。

**相关文档**：[广告拦截规则订阅方法](广告拦截规则订阅方法.md) · [轻量浏览器到底怎么选](轻量浏览器到底怎么选.md)

## 一、有什么不一样

脚本管理器内建，意味着不需要任何前置扩展。脚本能做的事与桌面端一致：页面翻译、自动翻页、去广告辅助、界面改造等。管理入口在「浏览器设置 → 用户脚本」，装过的脚本都在这里开关和删除。

## 二、安装方式一：地址栏直接打开

1. 复制脚本的安装地址（通常以 `.user.js` 结尾）；
2. 粘贴到 xbrowser 地址栏打开；
3. 浏览器识别出油猴脚本，弹出安装提示，确认即可。

这是最简单的方式，适合从别人那里直接拿到脚本地址的场景。

## 三、安装方式二：从脚本站安装

以最大的脚本分享站 Greasy Fork 为例：

1. 打开脚本详情页，点「安装此脚本」；
2. 第一次装脚本时，站点会先弹一个确认框，选「我已经安装了用户脚本管理器，让我安装」——xbrowser 内置管理器，直接这么选就对了；
3. 再次点安装，浏览器弹出安装提示，确认完成。

各脚本站的合集列表可以在脚本社区里搜「用户脚本站点合集」找到，热门脚本基本都集中在几个大站上。

## 四、装完没反应，按这个顺序查

| 现象 | 排查 |
| --- | --- |
| 页面毫无变化 | 到「设置 → 用户脚本」确认脚本处于启用状态 |
| 启用了还是没用 | 检查脚本的匹配规则（@match / @include / @exclude）是否覆盖当前网页 |
| 脚本站上点安装没反应 | 站点先弹了「已安装脚本管理器」确认框，走完流程再点一次安装 |
| 功能在手机上不对劲 | 很多脚本是为桌面页面写的，装前看看作者是否注明兼容手机浏览器 |

另外注意脚本与广告拦截可能互相影响：脚本改坏页面、或拦截误杀脚本资源，排查时先把两者分别开关对照确认。

## 五、小结

内置脚本管理器 + 现成的脚本生态，让这款小浏览器的能力上限高出不少。还没装的话，先看[轻量浏览器到底怎么选](轻量浏览器到底怎么选.md)了解整体情况，装好后建议顺手把[广告拦截规则订阅方法](广告拦截规则订阅方法.md)里的规则配好，两者配合体验最佳。

功能全景与安装文件资源入口见 [xbrowser 介绍站](https://xbrowser.djnf.quest/)。
