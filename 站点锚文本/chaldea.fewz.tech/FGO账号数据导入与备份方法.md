# FGO账号数据导入与备份方法

> 这篇讲两件最怕丢数据的事：账号的从者与素材数据怎么导进规划工具，以及换机、重装前怎么把规划保住。

规划类工具的全部价值都建立在「你的账号数据」上：从者练度、素材库存导进来，缺口和刷本路线才算得准。Chaldea 支持国服、台服、日服、美服四个区服的数据导入，工具本身在 [Chaldea 安卓版介绍站](https://chaldea.fewz.tech/)有完整说明。

## 一、按区服选导入方式

| 区服 | 路线 | 备注 |
| --- | --- | --- |
| 国服 / 台服 | 抓包导入 | 证书装好、抓到登录响应即可，Android / iOS 都可行 |
| 日服 / 美服 | 游戏安卓客户端抓包 | 日服要证书装到系统层；美服支持有限 |
| 任意区服 | 导入备份文件 | 手上有 userdata.json 时最省事 |

抓包的核心是拿到登录那条请求的响应体：国服、台服是 base64 字符串，日服、美服是 json；只导响应体、不带响应头。导入前先确认工具里选中的是目标账号——导错账号就得重来。

## 二、导入后核对三件事

1. 从者列表：数量、技能等级、宝具等级与游戏内一致；
2. 素材数量：统计页勾「包含库存」，数量级应与游戏内接近；
3. 区服：别把国服数据导进日服账号，从者阵容一眼能看出不对。

## 三、备份：卸载前必做

安卓上卸载应用会连应用数据目录一起清空，养成规划、导入的账号数据全在里面。所以换机、重装、跨大版本升级前，先任选一种方式备份：

- **应用内导出**：设置 → 用户数据 → 备份，生成一份 userdata.json；
- **历史备份**：应用每天自动留一份，忘了手动导出也有兜底；
- **服务器备份**：上传后换设备下载恢复，注意它不是自动同步，要手动传、手动下。

恢复时导入任意一份 json 即可；不同版本的数据结构可能不兼容，重要数据别只留一份。

数据就位后规划怎么排，见 [FGO养成素材规划怎么算.md](FGO养成素材规划怎么算.md)；想验证队伍强度，见 [FGO3T队伍模拟器怎么用.md](FGO3T队伍模拟器怎么用.md)。
