# FGO3T队伍模拟器怎么用

> 这篇讲战斗模拟器的用法：怎么选关卡、摆队伍、读结果，以及模拟伤害和实战对不上时先查哪几处。

周回本想三回合通关，队伍配置差一点就会在第二面翻车；进游戏试错要耗体力，用模拟器推演则零成本。Chaldea 内置的 Laplace 就是干这个的——选关卡、摆队伍，逐回合算出每张指令卡与宝具的伤害、NP 回收和掉星。工具的界面与入口见 [Chaldea 战斗模拟介绍站](https://chaldea.fewz.tech/)。

## 一、选关卡的四种方式

- 下拉菜单直接选自由关卡；
- 从章节进关卡详情，点计算器图标跳进模拟器；
- 输入 Atlas ID 或关卡链接（限日服、美服数据）；
- 导入 Atlas 格式的 JSON 关卡数据，还能自建关卡改敌人配置。

## 二、摆队伍时把练度填对

点从者头像进入设置，等级、技能等级、宝具等级、芙芙、礼装等级都可以逐项调；已加入养成规划的从者还能直接按规划的当前练度或目标练度参与计算——模拟「现在打不打得过」选当前，模拟「练满之后」选目标。队伍可以存成本地模板，同一关卡反复迭代时直接载入改数字。

## 三、看结果：两件事定生死

1. **每面伤害是否过线**：对照敌方血量核对，宝具等级或技能等级填错时差距会很大；
2. **NP 回收是否够连发**：鞭尸与过量伤害的回收加成，模拟里都会算进去。

卡关时可以翻「共享队伍」，里面是其他玩家上传的、真实通关过当前关卡的编成，点详情能看到操作序列，照抄思路再按自己卡池替换即可。

## 四、数值对不上先查这三处

- 随机数档位：实战伤害有 0.9~1.0 浮动，模拟默认可能按下限算；
- 天赋树与礼装细节：漏配一项就是实打实的差距；
- 敌方技能实现度：部分敌方技能与 buff 尚未实现，高难关卡里「敌人没按预期行动」多半是这类。
