# FGO抽卡模拟与GSSR保底怎么选

> 这篇讲模拟抽卡能帮你做什么：出率看在哪、十连怎么白嫖着体验、保底十连的每个档位怎么按期望挑。

周年与生日的保底十连，每个档位给的从者差别很大，选错等得多肝一年；而模拟抽卡正好能在不出石的前提下把概率这件事摊开看。Chaldea 的卡池模块把「查卡池、跑模拟、算保底期望」做在了一起，获取方式见 [Chaldea 卡池模拟介绍站](https://chaldea.fewz.tech/)。

## 一、卡池列表先筛再看

按收藏、分类（常规限定 / 保底 SSR / 保底 SSR+SR）过滤卡池，过期与否按你设置里填的游戏进度判定，进度没填准筛选就不准；日文标题没翻译的卡池切到卡面图模式，对号入座更方便。日替 Pick Up 点进概览页能看到每位从者的具体出率。

## 二、模拟抽卡是概率体验，不是游戏标称出率

单抽十连随便跑，结果页能翻历史记录、看概率统计表。注意统计表是模拟算法大量运行后的经验值——从者 SSR 略高于标称 1% 属模拟波动，别当成游戏内公布的概率引用。想见识沉船分布就多跑几组十连，模拟器里的圣晶石是无限的。

## 三、GSSR 保底按期望挑

保底十连的选择流程：

1. 给候选从者打分：已拥有默认 0 分，未拥有默认 5 分，越想要分越高；
2. 按「期望最高 / 概率最好 / 概率最差」排序；
3. 看排第一的是不是你能接受的答案，不满意就回去调分数。

打分是关键一步：把歪了也不亏的压到 0，把差一点就井的抬上去，排出来的第一名就是账面上的最优选。工具只负责算，最终按自己的卡池缺口定。

抽完决定练谁，就回到养成线：目标怎么定、缺口怎么算，见 [FGO养成素材规划怎么算.md](FGO养成素材规划怎么算.md)；新从者编进队后能不能稳定 3T，见 [FGO3T队伍模拟器怎么用.md](FGO3T队伍模拟器怎么用.md)。
