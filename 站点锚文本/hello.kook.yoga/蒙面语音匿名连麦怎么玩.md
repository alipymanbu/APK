# 蒙面语音匿名连麦怎么玩

> 「蒙面语音」是先用声音认识人、聊得来再亮身份的玩法：限时匿名连麦，互相公开后才能延长。本篇讲入口在哪、一局怎么走、以及公开身份前后的几个注意点。
> **相关文档**：[房间里怎么上麦排麦.md](房间里怎么上麦排麦.md) · [开黑车队怎么组队发车.md](开黑车队怎么组队发车.md)

---

## 一、入口与匹配

在应用里找到「蒙面交友」入口，进去后系统会把两个都戴着「面具」的人配进一间小房间：双方头像默认盖着面具图案，谁也看不到谁的真实资料，聊天从声音开始。匹配是随机的，换一批点「换一批」即可。

## 二、一局怎么走

1. **限时开始**：配对成功后进入约 3 分钟的匿名时限，页面中间有倒计时；
2. **匿名聊**：时限内畅所欲言，话题卡会给出提示，比如分享最近看过的电影、最喜欢的游戏，卡壳时抽一张就能接上；
3. **决定公开与否**：时限到了之后，双方各自选择是否公开身份——只有两个人都点了公开，聊天才能延长，资料才会互相展示；
4. **不合适就换**：单方面不公开，本局就此结束，不会有残留资料。

## 三、几个注意点

| 情形 | 建议 |
| --- | --- |
| 对方催着加联系方式 | 匿名阶段不必给，聊得投缘再公开也不迟 |
| 遇到不舒服的言论 | 房间内有举报入口，退出并举报即可 |
| 不想让熟人认出 | 匿名阶段资料本就不展示，公开选择权在自己手里 |
| 未成年人 | 这类连麦玩法不适合，账号安全相关内容应先过家长 |

## 四、公开之后去哪

双方都公开身份后，可以从蒙面房间转到普通语音房间继续聊，也能互加好友、去动态广场看对方的日常。语音社交的乐趣在「先听声音再看人」，公开前多聊几轮，比急着公开更不容易踩坑。

第一次接触这类应用、还卡在上麦操作的话，先看[房间里怎么上麦排麦.md](房间里怎么上麦排麦.md)；想知道它除了交友还主打什么，这份[Hello语音](https://hello.kook.yoga/)介绍站里有按年份整理的赛事履历，看完心里有数。
