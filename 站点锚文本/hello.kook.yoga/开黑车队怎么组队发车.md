# 开黑车队怎么组队发车

> 「发车」就是车队长把固定麦位挂出来、凑齐队友再一起进游戏。本篇讲怎么找车队、怎么自己发车、以及凑不齐人时的两条备选路。
> **相关文档**：[房间里怎么上麦排麦.md](房间里怎么上麦排麦.md) · [蒙面语音匿名连麦怎么玩.md](蒙面语音匿名连麦怎么玩.md)

---

## 一、找一辆现成的车

1. 登录后进游戏板块，按自己在玩的游戏筛房间：王者荣耀、和平精英、QQ飞车这类热门项目的车队房最多；
2. 房间标题就是发车信息，写明缺什么位置——「再来个辅助就发车」「缺一个打野」这类，按自己会玩的位置进；
3. 进房后点空麦位坐下，在公屏报一声位置和段位，车队长确认人就发车；
4. 跟车期间语音常开，报点、报技能、报位置都在麦里完成。

## 二、自己当车长发车

1. 首页点「创建房间」，把房间名写成明确的发车信息：游戏名 + 缺位 + 段位要求；
2. 设置房间公告，把规则写清楚，比如「上车报位置，秒退拉黑」；
3. 麦位开几个留几个：车队长占一个，剩下的按队友到齐顺序分配；
4. 人齐后从房间直接开黑，游戏里组好队，语音就挂在后台不用切。

## 三、凑不齐人的两条路

| 情形 | 做法 |
| --- | --- |
| 好友不同时在线 | 在动态广场发条约玩动态，写清游戏、时间和缺位，同好会来接 |
| 想就近找搭子 | 用「附近的人」按距离筛，标签里能看到对方会玩什么，私信约一把 |

## 四、车队里的小礼节

发车前先把麦克风权限确认好，进房不说话是最常见的翻车原因；跟车时听车长指挥，别抢麦别插话；输了别挂机甩锅，语音社交圈子里口碑传得飞快。想约长期队友，就把自己的位置和在线时段写进房间公告，比每次重新喊人省力。

从零装这个应用的话，安卓安装包可以从这份[Hello语音](https://hello.kook.yoga/)介绍站指引的网盘入口去拿，装好后按上面四步发车；上了麦不会操作，回[房间里怎么上麦排麦.md](房间里怎么上麦排麦.md)补一遍。
