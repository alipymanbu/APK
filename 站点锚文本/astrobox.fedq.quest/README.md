# AstroBox 站点导航

AstroBox 是一款面向小米、Redmi 穿戴设备的开源工具箱，装第三方表盘、快应用与固件资源都在这一个入口完成。[AstroBox 介绍站](https://astrobox.fedq.quest/)把功能、适配机型与连接方式整理成了两页导览，配安卓安装包资源入口。

本目录收录围绕 AstroBox 整理的使用文章：

- [小米手环怎么装第三方表盘](小米手环怎么装第三方表盘.md) —— 资源来源、安装路径与适配提醒
- [手环连不上设备怎么办](手环连不上设备怎么办.md) —— 四种连接方式与连不上时的排查顺序
- [表盘和快应用资源去哪找](表盘和快应用资源去哪找.md) —— 内置源、社区源与本地文件三个去处

机型支持情况会随版本调整，动手安装前建议先到介绍站的机型清单里对一眼。
