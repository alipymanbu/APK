# 手环连不上设备怎么办

用第三方工具箱管理小米手环，第一道坎就是设备连接。连不上多半不是工具坏了，而是账号、权限、确认状态三处有一处没到位。本篇把连接方式与排查顺序一次理清。

## 一、四种连接方式，先选对路

| 方式 | 适合谁 | 说明 |
|---|---|---|
| 小米账号同步 | 小米 / Redmi 设备，首选 | 登录后自动拉取名下绑定的设备 |
| 手动填 AuthKey | 不想登录账号 | 用社区工具读出设备凭据再填入 |
| vivo 账号同步 | vivo / iQOO 手表 | Watch GT 系列为实验性支持 |
| 手动填 OpenID | vivo 设备替代路 | 凭据从设备侧获取 |

## 二、账号同步的标准动作

1. 手环上进入「设置 → 我的设备 → 连接新手机」，停在出现的确认界面；
2. 工具箱里登录小米账号，等设备列表刷新；
3. 点选目标设备，手环震动后在其屏幕上确认；
4. 手机弹出系统配对提示时点「绑定」（安卓有时藏在顶部通知里）。

## 三、连不上的排查顺序

- **列表里没有设备**：登录的账号与手环绑定的不是同一个，换绑定账号重登；
- **刚绑了新设备**：到账号设置里重新同步一次列表；
- **手环不在确认页**：回手环重走「连接新手机」，停住别退出；
- **蓝牙干扰**：先关掉手机蓝牙，让手环停在确认界面，再开蓝牙连；
- **权限不全**：位置权限要「精确位置」、蓝牙始终允许、「附近设备」开关打开，三处缺一不可；
- **iOS 报 TargetRejected**：到系统蓝牙里忽略该设备再重连。

用 AuthKey 连接的，注意凭据等同设备钥匙：不截图、不外发，怀疑泄露就在各工具里删除已保存设备并重新绑定。
