# 直播与比分叠加设置

> 讲用 XbotGo 把比赛画面边拍边推到直播平台：三个一键推流目标、自定义 RTMP 怎么填、ScoreSync 比分怎么叠进画面，以及第二部手机实时监看的接法。
> **相关文档**：[追踪模式与机位怎么选](追踪模式与机位怎么选.md) · [设备配对与首次开拍](设备配对与首次开拍.md) · [安卓机型要求与安装步骤](安卓机型要求与安装步骤.md)

## 一、直播是唯一强制要外网的动作

追踪和录制走设备到手机的局域热点，不联网也照样拍；直播则要把手机的上行带宽实时交出去。开赛前确认三件事：

1. 手机网络稳定——室外场地用流量还是场馆 Wi-Fi，提前测一次上行；
2. 目标平台账号已授权（YouTube、Facebook 各一次）；
3. 设备连接正常、运动类型已选好，直播画面沿用当前拍摄配置。

另外手机一边收回传一边推流，耗电比单纯录制快得多，长时间直播给手机接个充电宝。

## 二、三个一键目标

| 目标 | 特点 | 适合 |
| --- | --- | --- |
| YouTube | 授权后直接开播，链接可分享给亲友 | 最常用的远程观赛方案 |
| Facebook | 走自己的主页或群组 | 队伍社群已有 Facebook 习惯的 |
| XbotGo Live | 无需第三方账号 | 不想折腾注册，只求最快开播 |

路径都是从拍摄界面进直播选项，选平台、授权、给比赛起个标题，然后开始推流。

## 三、推到别的平台：自定义 RTMP

联赛或俱乐部有自己的直播服务器时走 RTMP：在直播选项里选自定义推流，把平台直播后台给的**推流地址**和**推流密钥**两串都复制过去（别手抄，末尾空格是最常见的翻车点），开始推流后回平台后台确认收流。注意平台后台要先点「开始直播」等收流。

## 四、ScoreSync：比分实时压进画面

直播和录制通用的比分叠加：在直播/拍摄面板里开启 ScoreSync，随比赛进程手动加减比分，画面上就实时挂着一条比分栏——观众看直播、赛后回看都能对上分数脉络。

## 五、第二部手机监看（Monitor）

夹在设备上的手机是拍摄机，手里的另一台是监看机：实时看画面、调机位、控录制。要点有三：

- 两台手机装同一应用，且**在同一个网络里**——有现场 Wi-Fi 就都连它；场外没 Wi-Fi 时，让一台开移动热点、另一台连这个热点；
- 两台第一次用都会弹「本地网络」权限，点允许；
- 拍摄机在录制界面点监看图标（变橙即开启），监看机在首页点「监控器」选拍摄机；刷不出来就扫拍摄机屏幕上的二维码，成功率更高。

注意：Falcon 目前不支持第二台设备同时监看——它的手机本来就是监看屏。

## 六、直播失败速查

| 现象 | 先查什么 |
| --- | --- |
| 一开播就断 | 上行带宽；换网络或降低推流档位 |
| 画面卡顿花屏 | 设备热点被别的 Wi-Fi 干扰；离设备近一点 |
| 平台收不到流 | 地址与密钥是否填对；平台是否点了等收流 |
| 直播没声音 | 应用的麦克风权限是否被拒 |

其他故障集中在 [设备配对与首次开拍](设备配对与首次开拍.md) 的排查清单里。
