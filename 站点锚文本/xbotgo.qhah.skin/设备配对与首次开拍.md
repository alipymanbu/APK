# 设备配对与首次开拍

> 讲 XbotGo 应用和 Chameleon、Falcon 两类硬件怎么建立连接：两条通道各干什么、配对四步、状态灯怎么读，以及连不上时从便宜到贵的排查顺序。
> **相关文档**：[追踪模式与机位怎么选](追踪模式与机位怎么选.md) · [直播与比分叠加设置](直播与比分叠加设置.md) · [安卓机型要求与安装步骤](安卓机型要求与安装步骤.md)

## 一、先分清两条通道

很多「连不上」被怪到蓝牙头上，其实设备和应用之间是两条通道：蓝牙负责设备发现、初始配对和控制指令；画面回传、监看、文件传输走的是设备自己发出的局域热点。由此有两个实用结论：

- 场地里没有外网也能正常拍，追踪、录制、回看都是设备到手机的点对点传输；
- 配对时一直转圈，先把手机上无关的 Wi-Fi 断开——别的 Wi-Fi 会干扰热点切换。

## 二、配对四步

以 Chameleon 为例（Falcon 流程相同）：

1. 确认电量充足，长按电源键开机，等开机自检的上下校准动作做完，设备才算完全启动；
2. 手机打开应用并登录账号；
3. 在应用里点「添加设备」，列表里以 `Xbot` 开头的设备名就是它，点它完成配对；
4. 配对成功进入控制界面，能看到摄像头画面说明两条通道都通了。

设备侧面那盏状态灯是好用的判据：呼吸式慢闪 = 蓝牙未连接、可配对；常亮 = 已被某台手机连着——如果不是你的手机，先让那台断开再配。机身正面四格电量灯，每格约 25%。

## 三、连不上时的排查顺序

**列表里能看到设备但点不上**：确认电量 → 设备管理页点刷新 → 完全关掉应用重开 → **双击设备电源键重置蓝牙** → 重启设备 → 让占用的手机断开 → 清理手机里不用的历史蓝牙设备 → 应用升级到新版本。

**列表里根本刷不出**：手机蓝牙开关 → 系统设置里确认应用拿到蓝牙与位置权限（安卓要求蓝牙扫描配位置权限）→ 等设备完全启动 → 关掉省电模式（它会掐后台蓝牙扫描）→ 再走一遍重置蓝牙与重启。

都试过还不行，换一台手机试连一次，就能区分问题在设备还是在手机。

## 四、固件与账号

应用和设备固件是配套的，连接异常、追踪发飘时第一件事是两边都升到最新：进「我的」→「设置」→「固件升级」，当前版本显示在右上角。看不到升级入口时，退出账号重新登录、重连设备再找。Falcon 充电有个坑：要用非苹果的 PD 快充（最高 18W），升级固件前先把电充满。

配对只是第一步，开拍前还要选运动类型、摆机位，见 [追踪模式与机位怎么选](追踪模式与机位怎么选.md)。
