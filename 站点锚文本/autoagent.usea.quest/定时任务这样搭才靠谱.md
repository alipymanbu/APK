# 定时任务这样搭才靠谱

> 本篇讲安卓定时自动化任务从搭建到稳定运行的全部要点：怎么选触发、怎么排动作、为什么到点不跑，以及长期不掉链子的几个设置习惯。以 AutoAgent 为例展开，其它同类工具思路相通。
> **相关文档**：[安卓自动化助手怎么选怎么用.md](安卓自动化助手怎么选怎么用.md) · [模拟点击与悬浮球用法.md](模拟点击与悬浮球用法.md)

## 一、先想清楚「什么时候跑」，再想「跑什么」

定时任务搭不好，多数时候不是动作配错，而是触发条件没想清。AutoAgent 里触发分三类，搭之前先对号：

- **时间触发**：到某个点跑一次，或按天、按周周期跑——路况查询、每周清缓存属这类；
- **状态触发**：电量低于阈值、连上指定 Wi-Fi、插入耳机时跑——本质不是「定时」，但和定时任务常配合使用；
- **手动触发**：留个开关，想跑的时候点一下，或从悬浮球划出来。

典型组合是「状态 + 动作」打底、「时间 + 动作」做主力，比如：通勤时间点自动查路况（时间），低电量弹提醒（状态），两者互不干扰。

## 二、搭建四步，一步别省

以「工作日早上自动查一次路况」为例，在 AutoAgent 里的完整顺序：

1. **新建流程，选触发**：触发类型选时间，设工作日早上你出门前的那个点；
2. **拼动作**：把路况查询类动作加进流程；要连着做几件事就继续往下加，顺序就是执行顺序；
3. **手动试跑**：先点一下手动执行，确认每一步结果符合预期——直接交给定时，出错了你都不知道错在哪一步；
4. **启用，交给触发条件**：试跑没问题再等触发点，之后每天到点它自己跑，不用管。

同一界面里可以并行搭多条流程，它们在各自独立窗口执行、互相不打断；但同时跑太多条，性能和电量会有感知，按需取舍。

## 三、到点不跑？按这个顺序查

定时任务「没反应」的排查顺序，按出现频率从高到低：

1. **触发条件本身**：回编辑界面确认触发类型选对了、时间触发已启用、周期设的是想要的那几天；
2. **权限缺项**：悬浮窗、无障碍没开的话动作执行不了或只跑一半；状态触发还额外依赖系统状态读取权限；
3. **自启动被关**：定时启动依赖自启动——应用退出后靠它拉起任务。到「手机设置 → 权限设置 → 自启动」确认允许（各品牌菜单名略有出入）；
4. **后台被杀**：把电池策略改成「不优化」、在最近任务列表里把应用卡片锁定，别让一键清理把它清掉；
5. **屏幕与省电**：长时间任务（挂机类）把屏幕超时调长或接着电源，屏幕一灭任务容易被系统暂停。

大部分「不跑」都出在 2~4 这三处，权限按提示补全后先手动试跑一次再观察。

## 四、长期稳定运行的三个习惯

- **改流程先试跑**：调整过动作顺序或参数后，先手动执行一遍再交给触发，别直接上线；
- **系统大版本更新后复查**：更新后无障碍等开关可能被重置或收紧，回头把权限开关过一遍；
- **备份重要流程**：流程数据在本地的话，卸载应用就没了。AutoAgent 从 V1.1.0 起支持动作分享，重要的流程分享出去存一份，重装后导入即可。
