# 安卓自动化助手怎么选怎么用

> 本篇讲安卓手机上的自动化能帮你做什么、挑这类工具看哪几处，以及从安装到搭出第一条流程的上手路径，并以 AutoAgent 为例拆开说。

## 一、手机上哪些事适合交给自动化

判断标准很简单：**固定步骤 + 反复发生**。满足这两条的事都值得录成流程，比如：

- 每天出门前查一次路况，不用上车才掏手机开地图；
- 每周固定清理一次应用缓存与冗余文件；
- 电量掉到两成就提醒充电，不用惦记着看电量；
- 每天要依次打开好几个应用、在每个里点同样位置的「打卡式」操作；
- 游戏挂机、每日签到这类纯重复的点击。

反过来，需要临场判断、每次都不一样的事，自动化帮不上忙，别硬套。

## 二、挑这类工具看哪几处

安卓上的自动化工具不少，挑的时候建议对四件事：

1. **触发类型够不够全**。基础的是手动点一下就跑；再往上是按时间到点跑、按周期跑；更实用的是按手机状态触发——电量、网络、耳机这类状态一变就响应。三类都有的工具，能覆盖的场景才宽。
2. **是不是可视化拼流程**。好的工具把「触发条件 + 动作」做成积木式拼装，在图形界面上加节点、调顺序，不用写一行代码；改起来也是拖动就行。
3. **权限用途说没说清**。自动化依赖悬浮窗、无障碍这类高敏感权限，正规做法是按需申请、把每个权限对应哪个功能写清楚，不用的功能可以拒绝授权。
4. **数据放哪**。流程搭起来是要长期用的，弄清数据存在本地还是云端、卸载会不会丢，动手前心里有数。

## 三、AutoAgent 的功能构成

AutoAgent 是一款安卓手机自动化助理应用，开发者是惠州市速点科技有限公司。它的玩法可以概括成「三类触发 + 一串动作 + 一个悬浮球」：

- **三类触发源**：按时间（到点、按周期）、按手机状态（电量、Wi-Fi、耳机等变化）、手动触发，想怎么开跑都行；
- **动作像积木**：快捷拨打、快捷发信息、一键导航、扫二维码、清理缓存等动作逐个拼进同一条流程，按顺序执行，多条流程还能同时在线、互不打断；
- **悬浮球绑定**：常用动作绑在悬浮球各个方向上，任何界面一划就调出来，不用来回切应用。

它还提供预置脚本，支持自定义点击脚本——点击的位置、时间间隔都会被记录，改参数直接在编辑界面调，游戏挂机、每日签到这类重复操作是典型用法。

## 四、上手路径：从安装到第一条流程

1. **确认机型**：安卓 5.0 以上、主流机型都能装；
2. **拿到安装文件**：装它需要一个 APK 安装包，整理好的功能介绍、界面实拍与安装文件资源入口在 [AutoAgent 资料站](https://autoagent.usea.quest/)，照着下载页的步骤走即可；
3. **开权限**：首次启动同意隐私协议后，按提示开悬浮窗与无障碍。从网盘等非商店渠道安装的包，安卓 13 起开无障碍会弹「受限制的设置」，去应用信息页选「允许受限制的设置」再开；
4. **搭第一条流程**：从「定时清理缓存」这种最简单的开始——选时间触发，加一个清理动作，手动试跑一遍确认没题目，再交给触发条件自动跑。

跑起来之后如果遇到「到点不执行」，优先查权限（自启动、后台常驻、电池策略），这类问题占大头；其余排查思路写在 [定时任务这样搭才靠谱.md](定时任务这样搭才靠谱.md) 里，点击脚本怎么配见 [模拟点击与悬浮球用法.md](模拟点击与悬浮球用法.md)。
