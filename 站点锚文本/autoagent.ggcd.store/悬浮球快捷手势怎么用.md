# 悬浮球快捷手势：把最常用的动作放在拇指边上

安卓手机上有个一直被低估的交互位：屏幕边缘的悬浮球。它不占桌面、不抢通知栏，却永远悬浮在当前应用之上——正好适合放「任何界面都想随时用一下」的动作。

## 为什么悬浮球适合放自动化动作

快捷方式的核心矛盾是：入口越方便，越值得放高频动作；但高频动作往往发生在**别的应用里**——听歌切歌、开关手电、截屏转发，没有一件是专门回到桌面去做的。悬浮球恰好解决「人不在桌面」的问题，一划即达，不用退出当前应用。

## 四向手势的用法

以 [AutoAgent 手机自动化助理](https://autoagent.ggcd.store/)为例，它的悬浮球是**四个方向各绑一个动作**的设计：

| 手势方向 | 绑什么合适 |
| --- | --- |
| 左侧 | 最常用的那一个，比如播放/暂停媒体音乐 |
| 右侧 | 次高频动作，如进入开关设置 |
| 上侧 | 流程类动作，如启动某条工作流 |
| 下侧 | 「急停」类，如停止当前流程 |

四个方向分好工后，肌肉记忆很快就能建立：拇指往哪边划，出什么结果，不再需要看屏幕找按钮。

## 绑定时的三个建议

1. **宁缺毋滥**：四个方向没必要绑满。方向绑得太满，「想想该往哪划」的成本反而超过收益，先绑两个最顺手的；
2. **方向按使用频率排**：拇指自然落点最容易划的是「向左」，把使用频率最高的动作放那里；
3. **留一个回退位**：四向里留一个「停止当前流程」，自动化流程跑偏时随时能掐断，比翻回应用里找停止按钮省事得多。

## 和定时、手动入口配合

悬浮球解决的是「人在手机前」的场景；人不在时，交给定时触发；偶尔才用一次的，收进动作列表当手动入口。三种唤起方式各管一段，整套自动化才不会变成「什么都要划一下」的负担。
