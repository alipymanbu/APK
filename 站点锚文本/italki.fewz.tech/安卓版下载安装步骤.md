# italki 安卓版下载安装步骤

> 从网盘拿到安装包，到装好、登录进 App，四步走完；装不上时按最后一节排查。
> **相关文档**：[订课与老师怎么挑.md](订课与老师怎么挑.md) · [点数付费与退款规则.md](点数付费与退款规则.md)

---

italki 的 App 和网页端用同一个账号，课表、点数、钱包都挂在账号上。想在手机上约课上课，先把 App 装上。

## 一、四步装好

1. **转存并下载**：打开整理好的安装包分享页，先转存到自己的网盘账号，再用网盘客户端把 apk 下载到手机；安装包约 98 MB，建议预留 1 GB 以上空间；
2. **点开安装**：在文件列表里点这个 apk；用数据线从电脑拷过来装也一样；
3. **放行来源**：系统弹「禁止安装来自此来源的应用」时，按提示进设置，只对当前这个来源（文件管理器或浏览器）打开允许开关，装完可以随手关掉；
4. **登录账号**：首次启动会依次请求摄像头、麦克风、通知权限——前两项上课要用，建议允许。登录窗口分「电子邮箱」「手机号码」两个标签，按注册方式选，选错会提示找不到账号。

装好后先设两件事：**账户时区**（订课页显示的时间跟着它走，时区不对会约错时间）和**账单国家/地区**（决定支付页出现哪些支付方式）。

## 二、装不上按现象排查

| 现象 | 处理 |
| --- | --- |
| 提示解析错误 / 文件损坏 | 下载不完整，回网盘重新下一次再装 |
| 提示与已安装应用冲突 | 手机里已有其他渠道装的 italki，签名不同；先卸载旧版再装，课表与点数跟账号走 |
| 一直「等待安装」不动 | 手机安全中心拦了第三方安装，去拦截列表里放行后重试 |
| 打开就闪退 | 确认剩余空间够，再补齐摄像头与麦克风权限 |
| 提示存储空间不足 | 清出至少 1 GB 再装，安装包解压后占得更大 |

第三方渠道的版本号可能与手机商店里显示的不一致，装哪份由你决定；想核对文件是否完整，下载完对一下文件大小再装更稳。

## 三、装好之后

- 时区、账单地区设好，去发第一节约课请求，流程见[订课与老师怎么挑.md](订课与老师怎么挑.md)；
- 点数、课时包怎么付怎么退，见[点数付费与退款规则.md](点数付费与退款规则.md)。

安装包的获取入口与页面版说明，整理在 [italki 介绍站](https://italki.fewz.tech/)。
