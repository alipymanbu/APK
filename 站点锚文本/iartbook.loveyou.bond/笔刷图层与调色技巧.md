# iArtbook 笔刷图层与调色技巧

> 整理 iArtbook 画布创作里最常被问到的三块：笔刷怎么挑怎么调、图层日常用哪几个动作、配色与调色板怎么管理，适合已经装好应用、准备认真画一张的人。
> **相关文档**：[数字填色与照片涂色教程.md](数字填色与照片涂色教程.md) · [安卓绘画应用怎么选.md](安卓绘画应用怎么选.md)

在 iArtbook 里从零画完一张图，绕不开笔刷、图层、颜色这三件事。它们各自的入口都藏在画布工具栏里，参数项多但常用的就几样。下文按「你会碰到什么问题」来组织，操作以 2.2.7 中文版为基准，不同版本选项名称可能略有出入。

## 一、笔刷怎么挑

预装笔刷覆盖了几类常见媒质，先按画风挑大类：

| 类型 | 适合画什么 |
| --- | --- |
| 铅笔 | 打稿、素描线条，笔触细 |
| 水彩 | 通透的晕染上色，颜色叠着叠着就润了 |
| 炭笔 | 粗粝的明暗块面 |
| 马克笔 | 干净的色块、平涂 |
| 喷枪 | 柔和的渐变与光影 |
| 记号笔 / 涂抹笔 | 勾边，以及把已有颜色揉开 |

按干湿特性还能分成干性、湿润、光泽三类，湿润类里又细分不带拉扯、带拉扯、超精准几种。不用记名词——画的时候各试一遍，留下顺手的就行。有评测称这款应用的笔刷数量在 150 款以上，具体数量以你设备里的列表为准。

## 二、把笔刷调成自己想要的手感

- **详情设置**：在画布上方工具栏点开当前笔刷进入详细设置，参数有 50 多项；常用的就粗细、不透明度、硬度、纹理四样；
- **快速设置**：偏好简单圆形笔刷的话，设置里有硬度、椭圆度、旋转几个快捷项，调这三个就够用；
- **过程滑条**：画布左侧两个小滑条，上下滑动实时调笔刷大小和透明度类参数，画画途中最顺手；
- **线条稳定**：勾线手抖就把书法稳定类选项调高，用手指画也能得到较顺滑的线条；
- **揉色**：任何笔刷配合涂抹工具（手指图标）都能当涂抹笔用，有几种涂抹算法可选，水彩晕染感主要靠它；
- **带走笔刷**：笔刷支持导出成文件再导入另一台设备，换机时自己调好的笔刷不丢；调好常用笔刷后在列表里点名字可以重命名，比如改成「我的勾线」方便下次找。

另外兼容主流手写笔，笔触粗细随压力变化（有评测提到这一点，实际表现以你的设备为准）。

## 三、图层日常就这几个动作

图层没有数量上限，日常用到的是：

1. **新建**：图层面板点「+」加空白层，勾线、上色、背景各一层，改哪层不影响哪层；
2. **排序与显隐**：长按或拖动调上下顺序，点眼睛图标切换可见；
3. **透明度**：把参考图垫在底下并调低整体不透明度，方便照着描；
4. **复制 / 删除 / 清空 / 填充**：面板里都有对应入口；
5. **图片进图层**：相册里的图直接作为一个新图层进来，不用退出再导；
6. **蒙版**：挂蒙版控制显示范围，上色出界时比橡皮擦好补救；
7. **无损变换**：对图层内容移动、缩放、旋转，画质不像合并后那样损失。

## 四、混合模式先记四个

图层的混合模式有 20 多种（有版本标注为 27 种），日常最常用的其实就四个：

| 模式 | 典型用法 |
| --- | --- |
| 正片叠底 | 投影、加深，颜色只会更暗 |
| 滤色 | 提亮、做光效 |
| 柔光 | 温和过渡明暗、统一色调 |
| 叠加 | 增强对比，比柔光更冲 |

拿不准时先试正片叠底和滤色，八九成的场景都是这两个。选区工具还能配合羽化数值用，边缘柔化的选区适合做发光或渐变过渡。

## 五、配色与调色板

- 应用带两个取色器和一个颜色混合器：先取色调好色，再混色观察过渡是否自然；
- 预设调色板 40 多种，纯色和渐变都有，做填色时整套调用很省事；
- 自建调色板：把常用色存成一组并命名，画系列图时保持用色统一；
- 调色板支持导入 / 导出，换设备时配色方案能一起带走。

画布最高支持 4096×4096（评测数据），画布越大越吃性能——新画布按需选尺寸，手机上一般用预设就够，超大画布是掉帧的头号原因。

## 六、想系统练笔刷手感

建议开一张小画布，把同类笔刷各铺一排色块，再各画一条从粗到细的线，十分钟就能摸清每只笔的脾气。想先从不上色的玩法入手，看 [数字填色与照片涂色教程.md](数字填色与照片涂色教程.md)；还没装应用的话，可以先到 [iArtbook 安卓版介绍站](https://iartbook.loveyou.bond/)看版本参数与安装指引；拿不定该选哪款绘画应用时，参考 [安卓绘画应用怎么选.md](安卓绘画应用怎么选.md)。
