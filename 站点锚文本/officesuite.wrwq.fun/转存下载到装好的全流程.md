# 转存下载到装好的全流程

> OfficeSuite 的安卓安装包通过网盘分享获取，从打开分享页到装好点开，顺利的话几分钟就能走完。这篇按顺序写每一步做什么，以及最常见的三个卡点怎么处理。

## 先说结论

流程是「转存 → 下载 → 放行未知来源 → 安装」四段。安装包体积不小（两百多 MB 的量级），动手前看一眼剩余空间，建议留出 2GB 以上；装完安装包本身可以删掉，不影响已装好的应用。

## 第一步：把分享文件转存到自己网盘

安装文件资源放在夸克网盘的分享里。点开分享页后登录网盘账号，选中文件转存到自己名下，再从自己的网盘里发起下载。转存这一步的意义在于文件进了自己的账号，之后换机、重装都能随时重新下载，不依赖原分享链接的状态。

获取入口整理在 [OfficeSuite 安卓版下载与安装步骤](https://officesuite.wrwq.fun/download.html)这一页，按钮点开就是分享页。

## 第二步：下载到手机存储

手机上打开网盘客户端，找到刚转存的文件，下载到本机存储。因为体积大，建议在 Wi-Fi 环境下进行。下载完成后，安装包通常躺在「文件管理」的 Download（下载）目录里。

## 第三步：放行「安装未知应用」

安卓默认拦下一切来自应用商店之外的安装包，第一次装必然在这里停一下。点开安装包提示被拦时，按提示跳进设置，把「文件管理器」这个来源的安装权限放开，再返回继续：

1. 进入「设置 → 应用 → 特殊应用权限 → 安装未知应用」（各品牌入口名称略有出入，在设置里搜「未知」两个字基本都能定位）；
2. 找到用来打开安装包的应用（文件管理器或浏览器）；
3. 允许来自此来源的应用；
4. 回到下载目录，重新点安装包。

授权对象是文件管理器，不是 OfficeSuite 本身；装完不放心可以把权限关回去。

## 第四步：装好并完成首次设置

进度条走完点「打开」，先同意用户协议，随后就是应用主页那排五个彩色圆点——文档、电子表格、演示文稿、PDF、电子邮件。登录账号后能用到 5GB 免费的 MobiDrive 云空间和文档协作，不登录单机使用也完全可以。

## 卡住的三种情况

**点安装没反应或提示被阻止**：回到第三步，把来源权限放开再试；个别机型的系统安全组件还会再拦一次，选「仍要安装」。

**提示空间不足**：清理出 2GB 以上空间再装。安装过程的临时占用比安装包本身还大，是失败的高发原因。

**装完闪退或一直加载**：先重启手机再打开；仍不行就确认系统版本满足要求，或清除应用缓存后重试，也可以换相邻版本再装。
