# KMS 安卓安装包怎么下载安装

> 本篇讲 KMS（KMStation）安卓安装包的获取与安装步骤：从网盘把 APK 拿到手机、允许未知来源安装、装完核对，以及 iPhone 用户的替代方案。
> **相关文档**：[专辑特典与签售活动攻略](专辑特典与签售活动攻略.md) · [目录说明](README.md)

## 一、先认准要装的是哪个 kms

搜索引擎里搜「kms」，排前面的结果大多是 Windows 的系统激活工具，和手机上这个不是同一个东西。这里说的 KMS 是粉丝圈对 **KMStation** 的常用叫法——一款面向追星族的韩国专辑购物应用，安卓包名为 `com.KMStation.benben`。装完打开，底部显示「首页 / 商城 / 粉丝团 / 我的」四个标签，就说明没装错。

## 二、获取安卓安装包

安装包经夸克网盘分享：打开分享链接，先把资源转存到自己的网盘（分享链接可能过期，转存一份更稳妥），再在夸克网盘客户端里把 APK 下载到手机。参考版本信息：1.8.2 / 39.96M，实际拿到的那份以网盘里为准——应用后续发新版本，商店里的版本号通常更新，日常下单与查单不受版本影响。

## 三、安装步骤

1. 点开下载好的 APK，系统提示「不允许安装未知来源应用」时，按引导允许网盘客户端或文件管理器安装应用（入口一般在「设置 - 安全」，不同品牌手机名称略有差异）；
2. 点「安装」等待完成，不需要额外配置；
3. 首次打开会申请网络、存储等常规权限，允许后才能正常加载商品图片与物流信息；
4. 注册走邮箱验证：在「我的」页点头像处的「登录/注册」，语言选中文、地区选韩国，注册成功即可下单。

## 四、iPhone 用户怎么装

网盘里那份是安卓 APK，iPhone 装不了。iOS 设备在 App Store 搜索 KMStation 获取对应版本；两个平台的账号数据互不相通，下单前先确认好用哪台设备。

## 五、装完先看什么

第一次进 App 建议按这个顺序逛：商城搜一遍想买的专辑看有没有货 → 翻「活动日历」看最近的签售与特典档期 → 到「地址管理」把收货信息提前填好。预售与现货的等待时间差别很大，下单前的取舍可以参考这篇[专辑特典与签售活动攻略](专辑特典与签售活动攻略.md)；更多界面截图与玩法整理，见 [KMS（KMStation）介绍站](https://kms.qjxz.skin/)。
