# 手机当电脑遥控器：配对连接与远程控制

> 本篇讲普通安卓设备上 Armoury Crate 的主玩法：与华硕 ROG 游戏本、台式机配对，远程切性能档、看硬件状态、控风扇与灯效，以及配对失败时怎么排查。

## 一、什么情况下用得上

手机上的 Armoury Crate 在 ROG 手机之外最常见的用途，是给华硕 / ROG 游戏笔记本、台式机当一块「第二屏幕」：人在沙发上，游戏跑在电脑上，你用手机看温度、切性能档、调风扇转速，不用打断电脑画面。

前提条件：

- 电脑上已安装 PC 版 Armoury Crate（华硕支持页或微软商店提供）；
- 手机与电脑网络连通（同一 Wi-Fi 最省事，也支持蓝牙方式）；
- 手机上装有安卓版 Armoury Crate。

## 二、配对连接步骤

1. 电脑上打开 PC 版 Armoury Crate。
2. 手机上打开安卓版，在电脑端右上角找到「Mobile Connect」（移动连接）入口。
3. 两种配对方式任选其一：
   - **二维码**：电脑端显示二维码，手机扫码完成连接；
   - **ROG ID**：双方登录同一 ROG 账号配对。
4. 配对成功后，手机端出现电脑的可控制面板。

从实际反馈看，**扫码的成功率明显高于 ROG ID 登录**——有用户反馈 ROG ID 会报错，配对一直失败时优先走二维码路线。

## 三、连上之后能控制什么

| 手机端操作 | 作用在电脑上的效果 |
| --- | --- |
| 切 Turbo / Performance / Silent 三档 | 在最高性能、游戏平衡、安静低载三档间一键切换，几秒生效 |
| HyperFan 风扇控制 | 调电脑风扇策略：全力散热、游戏降噪、低噪音轻载 |
| System Info 硬件监控 | 看 CPU / GPU 频率、占用率、温度、风扇转速、电压 |
| Aura Sync 灯效 | 远程调整电脑端 Aura Sync 灯光设置 |

两类场景特别顺手：跑分或烤机时手机屏正好当监控面板；直播或联机时切静音档降噪不用退出全屏。

## 四、连不上时的排查顺序

1. **双方应用都在前台**：电脑端最小化到托盘后，手机端可能直接失去目标；
2. **核对网络**：手机走流量、电脑走有线不在同一网段是最常见原因；公司 / 学校 Wi-Fi 的 AP 隔离也会互相发现不了，换热点测试；
3. **改用二维码**：ROG ID 报错就扫码，这是实测最有效的替代路径；
4. **更新电脑端**：PC 版过旧时手机端新版可能不兼容，功能面板缺失先升级电脑端。

配对成功但面板一直加载属于应用加载故障，处理思路见[打不开一直加载怎么办.md](打不开一直加载怎么办.md)。想先了解这个应用的整体定位与功能全貌，看[ROG控制中枢全解.md](ROG控制中枢全解.md)；[Armoury Crate 控制中枢介绍站](https://armoury-crate.fewz.tech/)里也放了实机界面截图，配对前可以对照确认入口位置。
