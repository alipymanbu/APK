# Armoury Crate X 模式怎么开、三档怎么选

> 本篇讲 X 模式的三个打开入口、L1 / L2 / L3 三档的实际差异与解锁条件，以及日常场景下怎么选档不踩坑。

## 一、X 模式做了什么

X 模式是 ROG 游戏手机上专为游戏设计的高性能模式：开启后自动优化后台、移除暂时不用的应用来释放内存，并提升硬件使用效率，让游戏跑得更流畅。开启瞬间机身背面的信仰之眼灯效与兼容配件会同步点亮，这是系统联动的一部分。

普通安卓设备上没有这套硬件联动，找不到 X 模式开关属于正常现象。

## 二、三个打开入口

1. **快速设置面板**：主画面从上往下滑出快速设定，点「X 模式」图标即开即关，是最快的日常入口；部分机型在负一屏的性能面板里也有同一开关。
2. **游戏中心（智控中心）**：进游戏中心点「X 模式」开启，还能顺带看到后台释放内存的效果。
3. **肩键握压**：在 Armoury Crate 的 AirTriggers 设置里，把短握或长握肩键绑定成 X 模式开关，横握玩游戏时不用腾手指去拉菜单。

## 三、L1 / L2 / L3 三档的区别

以 ROG Phone 3 这一代为参考（后续机型划分思路基本延续）：

| 档位 | 实际表现 | 适合场景 |
| --- | --- | --- |
| L1 | 优化流畅度与响应，主要在加载、触控交互时提频 | 日常轻度游戏、怕发热 |
| L2 | 同时压榨 CPU 与 GPU，不怎么顾及功耗与发热 | 中度负载的主流网游 |
| L3 | 性能全开，机器自动能给到的最高档 | 重负载大型游戏 |

关键差别在解锁条件：**L3 通常需要外接酷冷风扇才可用**。不接风扇时 L3 选项置灰或缺失，这不是故障；接上对应代数的 AeroActive Cooler 后，最高档随配件解锁，厂商还给风扇 6 这代标了最高约 25℃ 的表面温降。

## 四、怎么选档不踩坑

- 日常刷视频、聊天：不开 X 模式，开着只会多发热多耗电。
- 玩一小时左右的网游：L1 或 L2 足够，温度与帧率更平衡。
- 长时间跑大型游戏或夏天室温高：接风扇开 L3。
- 边充边玩加上高档位发热会叠加，能拔线就先充够再玩。
- 高档位跑一阵后帧率仍掉下来，多数是机身温度到保护阈值触发降频，属于散热物理上限。

想让某个游戏一进去就自动切档，把档位写进该游戏的场景配置即可，不用每次手动点。更完整的整机功能盘点见 [Armoury Crate 控制中枢介绍站](https://armoury-crate.fewz.tech/)的 X 模式专节，含三档对照表与实机截图。

## 五、开高档位前的两件小事

1. 先把明显用不到的后台大应用划掉，内存释放空间更大；
2. 检查保护壳是否贴合——壳没装正既影响肩键触发，也影响散热预期。
