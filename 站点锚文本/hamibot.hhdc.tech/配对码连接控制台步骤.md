# 配对码连接控制台步骤

> 装好客户端只是第一步，Hamibot 真正的用法是网页控制台下发指令、手机执行——中间靠配对码把两边接起来。本篇把配对这一段拆成带细节的步骤。
> **相关文档**：[免root安卓自动化怎么上手.md](免root安卓自动化怎么上手.md) · [无障碍权限被杀脚本秒结束怎么办.md](无障碍权限被杀脚本秒结束怎么办.md)

## 配对前想清楚一件事：绑哪台手机

免费账号自带的配对额度只有 1 个，也就是免费档只够绑一台设备；想多绑就得订阅扩容。所以先把要挂任务的那台手机定下来再开始，免得额度用在了一台不常用的设备上。

## 拿配对码：在控制台设备页

1. 电脑浏览器打开 Hamibot 控制台，登录账号；
2. 切换到「设备」页（路径形如 `https://hamibot.com/dashboard/robots`）；
3. 点「添加设备」，页面会显示一串配对码——把它记下来，下一步要用。

没有账号的话先注册一个，手机号即可；国内站与海外站账号通用，选一个顺手用就行。

## 输配对码：在手机客户端

1. 手机上打开 Hamibot 客户端，首页会有「前往控制台获取配对码」的提示；
2. 点「配对」按钮，在弹出的输入框里填上刚才那串数字，点确定；
3. 输对了客户端会显示「已配对」，回到控制台刷新一下，设备列表里就能看到这台手机。

整个过程几秒钟，不插线、不需要局域网同一网段——控制台和手机各自连网就行。

## 配对常见的小状况

| 现象 | 多半是 |
| --- | --- |
| 配对码输不进去 | 复制时带上了空格或换行，手动重输一遍 |
| 客户端已配对、控制台看不到设备 | 控制台页面没刷新，下拉刷新即可 |
| 提示配对额度不足 | 免费档的 1 个额度已经被占，先解绑旧设备或扩容 |
| 输码后一直转圈 | 手机网络到服务端的链路不稳，换个网络再试 |

配对只是把设备挂上号，脚本能不能跑起来还取决于权限——无障碍服务被系统结束、后台弹出没开，都会让脚本起不来，排查思路写在[无障碍权限被杀脚本秒结束怎么办](无障碍权限被杀脚本秒结束怎么办.md)这一篇里；如果还在选工具阶段，可以先看[免root安卓自动化怎么上手](免root安卓自动化怎么上手.md)。
