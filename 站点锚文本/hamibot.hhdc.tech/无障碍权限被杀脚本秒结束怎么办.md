# 无障碍权限被杀脚本秒结束怎么办

> 脚本一点「运行」几秒就提示结束、或者反复提示无障碍没开启——十有八九是权限或后台策略的问题。本篇按出现频率把这些状况排了个序，照着排查即可。
> **相关文档**：[配对码连接控制台步骤.md](配对码连接控制台步骤.md) · [免root安卓自动化怎么上手.md](免root安卓自动化怎么上手.md)

## 先分清：是权限没开，还是权限被杀

两种情况的表象很像，但处理办法不同：

- **权限没开**：从来没打开过对应开关，脚本一跑就退出。逐项开齐（见下一节）就能解决；
- **权限被杀**：明明开过了，过一阵子再跑又提示没开。这是系统在后台把无障碍服务结束了，最快的恢复办法是重启手机，之后再按保活清单把设置补齐。

## 必开的权限清单

| 权限 | 作用 | 去哪开 |
| --- | --- | --- |
| 无障碍服务 | 脚本找控件、点按钮全靠它，必要权限 | 系统设置搜「无障碍」，在已下载的应用里找到 Hamibot 打开 |
| 后台弹出界面 | 客户端在后台时才能拉起目标应用 | 应用详情 → 权限管理里允许 |
| 悬浮窗 / 截屏 | 部分脚本运行时要弹框或截屏授权 | 运行时系统弹出授权框，勾选「记住选择」 |

大多数「运行后很快就结束」的脚本，缺的是无障碍和后台弹出这两项；个别脚本对权限有额外要求，作者会写在脚本介绍页里，装之前看一眼能少走弯路。

## 保活清单：让设备一直在线

云端型的工具要控制台能把指令发到手机，设备在线是前提。国产系统对后台限制普遍很严，这几项一次开齐：

- 电池策略里允许 Hamibot「无限制」或不省电；
- 允许自启动、允许后台运行；
- 锁屏策略别选「清理后台」那种最激进的一档；
- 长时间挂任务的话，充电不锁屏、让客户端保持在前台最稳。

不同品牌的设置项名称不一样，产品方以 MIUI 12 做过演示：无障碍在「设置 → 更多设置 → 无障碍 → 已下载的应用」里开；其他系统在设置里搜「无障碍」一般都能找到。

## 排查顺序小结

1. 先看无障碍开关还在不在（设置里再确认一遍，别只看 App 内的提示）；
2. 不在 → 开回来；在 → 补开「后台弹出界面」等其余权限；
3. 开齐了还是不行 → 重启手机再跑一次；
4. 重启能解决但过几天又犯 → 按保活清单逐项补设置；
5. 设备显示离线、控制台发不出指令 → 多半就是保活没做好，回到第 4 步。
