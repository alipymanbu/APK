# 游戏直充和代充有什么区别？到账时间与选择建议

> 同一款游戏在商城里往往挂着两类充值商品：只填 UID 的直充，和要交账号密码的代充。本篇把两者的差异、到账时间与适用场景一次讲清，帮你下单前选对。

## 一、两类商品的核心差异

两类商品的差别不在价格，而在"谁来操作充值"：

| 对比项 | 直充类 | 代充类 |
| --- | --- | --- |
| 发货方式 | 全自动，类似充话费 | 人工操作，客服登录你的账号执行 |
| 需要提供 | 游戏 ID（UID） | 游戏账号、密码、角色 ID |
| 典型到账 | 几分钟 | 15~30 分钟，活动期可能排队 |
| 填错了会怎样 | ID 不存在，短时间内退回失败并退款 | 信息错误无法充值，需要重新对接 |
| 等待期间 | 该干嘛干嘛 | 不要登录游戏，配合客服验证 |

判断方法很直接：商品标题会写明属于哪一类，商品页的"充值说明"也会写要填什么。看到"仅填 UID / 游戏 ID"就是直充，看到"提供账号"就是代充。

## 二、怎么选

- **优先直充**：不想交账号密码、只想到账快的，直接选直充。填 UID 付款即可，几分钟内进游戏核实。
- **直充缺货再考虑代充**：部分限定礼包、特殊面额或区服没有直充商品时，代充是补充选项。交账号前先读一遍[代充账号安全注意事项](代充账号安全注意事项.md)，把要确认的事过一遍。
- **赶时间就避开高峰**：新版本上线、节日活动期间，代充订单量上来后会排队，急用就别挑这个时段。

## 三、下单前核对两件事

1. **区服**：同一款游戏不同区服（美服 / 欧服 / 亚服 / 港台）的商品是分开的，面额与价格也不一样。先确认自己账号所属区服，再进对应商品页。
2. **UID**：进游戏点头像 / 个人资料找 UID 或玩家 ID，复制粘贴，别手敲。个别游戏填的不是 UID 而是绑定邮箱，以商品页说明为准。
