# 特典小卡与签售活动玩法

> 本篇讲 KMStation 的渠道特典有哪几种形态、签售活动的参与流程，以及抽重了的小卡怎么在交换区流转。
> **相关文档**：[注册下单到收货全流程](注册下单到收货全流程.md) · [专辑购物应用入门与安装](专辑购物应用入门与安装.md)

## 一、渠道特典是什么

KMStation 作为销售渠道会自带一层赠品体系，和专辑里原本的配置分开算。商品标题里出现的「KMS特典」「幸运卡特典」「独家特典」指的都是这一类。常见形态：

| 形态 | 规则 |
| --- | --- |
| 按版本给小卡 | 买哪个版本送对应版本的随机小卡，数量随购买张数增加 |
| 拍立得加赠 | 同一版本买满两张以上，在普通小卡外再加送随机拍立得卡 |
| 幸运卡特典 | 整张专辑随机掉落一张指定款小卡 |
| 早鸟赠品 | 在活动截止日前下单，额外加赠 |

每一期的规则、样式、门槛都不一样。以公开活动为例，曾有某团专辑预售把特典分成五套，分别对应不同实体版本与整套购买情形，截止日前下单再加赠拍立得卡。**下单前把当期商品页的特典公告逐条读完再付款**，避免到手后预期落差。

## 二、签售活动有哪几类

应用与网页商城里常驻三类形式，首页入口随档期轮换：

- **线上视频签名会**：中选后与艺人一对一视频通话完成签名；
- **线下签售**：到公告指定的现场参加；
- **一日店长**：艺人以店长身份参与的宣传期活动。

App 内设「中签公告」与「活动日历」两个栏目：中选名单在公告里发布，档期看日历。

## 三、参与流程

1. 招募期内打开应用，进入该艺人签名会的招募页；
2. 通过链接下单购买指定专辑，购买即获得抽选资格；
3. 招募期结束后在公告位置公布中选名单；
4. 中选者按公告时间参加。

每一次活动的时间、抽选规则、限购数量都不同，报名前逐条读当期公告，时间以公告标注的时区为准。

## 四、交换区出卡

抽重了的小卡可以发帖与其他用户交换：首页功能区进「交换区」→ 点右上角「+」→ 选分类、填内容、上传凭证 → 提交后展示。帖子由用户自行发布，交易对象与方式自行把握，凭证图记得先打码个人信息。

## 五、活动期下单的几个提醒

- 特典发放以商品页公告为准，客服无法追认公告之外的口头承诺；
- 早鸟有截止时间，卡点下单前先确认收货地址已填好；
- 预售类商品的等待期与售后口径，见[注册下单到收货全流程](注册下单到收货全流程.md)的预售与售后两节；
- 还没装应用的读者，从这份 [kms 专辑购物应用介绍](https://kms.djnf.quest/) 进去看看界面与功能，再决定要不要入坑。
