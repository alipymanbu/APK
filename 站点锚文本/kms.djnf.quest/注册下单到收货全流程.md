# 注册下单到收货全流程

> 本篇讲 KMStation 的注册要点、预售与现货怎么选、版本与支付注意事项，以及出库后怎么盯物流。
> **相关文档**：[专辑购物应用入门与安装](专辑购物应用入门与安装.md) · [特典小卡与签售活动玩法](特典小卡与签售活动玩法.md)

## 一、注册：区域与邮箱

注册入口在「我的」页头像处。流程要点：语言选中文、地区选韩国，然后用邮箱完成验证，注册成功即可下单。验证邮件收不到先翻垃圾箱，仍收不到就换个邮箱重试。

区域选错会影响商品展示与配送范围，注册时选错先去设置里找切换入口，找不到就联系客服处理。直邮订单要填能正常派送的收货地址（省市区 + 街道 + 收件人 + 手机号），建议提前在「地址管理」里填好——包裹出库后再改地址基本来不及。

## 二、先分清预售与现货

商品卡片上的标签决定等待时长：

| 标签 | 含义 |
| --- | --- |
| Pre-sale / 预售 | 先付款、后发货，按出库时间排队 |
| 现货 | 已入仓，下单后正常出库 |
| 韩国直邮 | 从韩国直接寄出 |
| starting | 该版本最低配置的起步价 |

预售要经历出库、国际运输、清关三段，整体等待比现货长得多，赶时间的优先看现货区。下单前把商品页承诺的发货时限截图存档，超时主张权利时用得上；「随机凑套」这类宣传不要当作承诺，公开反馈里有多买收到重复版本的案例。

## 三、选版本与付款

同一张专辑常有多个实体版本，配置、价格与对应特典都不同，结算前逐个核对。支付方式以结算页实际显示为准：近期版本里支付通道升级，一段时间内仅支持支付宝付款，微信入口暂停；下单时以页面提示为准。

订单提交后出现在「我的 - 我的订单 - 待付款」，付款后依次经过待发货、待收货、已完成。

## 四、盯物流与收货

出库后订单进入「待收货」，物流进度在订单详情里查。直邮段受国际运输与清关影响，时效浮动属于正常现象；长时间没有物流更新，再带着订单号联系客服，日常反复催促意义不大。

状态标了「已发货」却长期查不到揽收信息时，及时截图提出异议；系统的「自动确认收货」会关闭售后入口，倒计时结束前要把争议挂上。

## 五、售后与风险预期

跨境订单的退换规则与国内电商不完全一样，大件或拆封商品退不退得了，下单前先和客服确认一次。公开投诉平台上能查到关于发货拖延、退款入口难找、客服触达难这类争议反馈，所以更稳妥的姿势是：优先现货、留好证据、别把宣传当承诺。真走到纠纷那一步，按「App 内申请 → 盯确认收货倒计时 → 外部渠道（12315、投诉平台）」的顺序推进。
