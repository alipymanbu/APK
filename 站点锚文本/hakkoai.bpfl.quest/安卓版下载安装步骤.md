# 安卓版下载安装步骤

> 本篇讲 HakkoAI 安卓版怎么装：安装文件资源走网盘分享，转存到自己的账号再下载，四步装完登录。

HakkoAI 的安卓安装包不在应用商店的也没关系，走网盘分享同样能装；整条路只有四步，真正容易卡住的是「未知来源」那个系统提示，下面一并说清。

## 一、四步装好

1. **转存资源**：打开分享链接，把安装文件资源转存到自己的夸克网盘账号下；
2. **下载 APK**：在手机端网盘里找到刚转存的文件，下载到本机存储，文件约 88.56 MB，建议连 Wi-Fi；
3. **允许安装**：点开 APK，系统若提示「不允许安装未知来源应用」，按手机给出的指引允许该来源即可——这是安装非商店应用的标准提示，不是异常；
4. **注册登录**：装完打开应用，按提示注册并登录账号，然后挑第一位 AI 伙伴。

网盘里这份资源为 3.3.11 版，开发方更新较勤，装完可在应用内检查升级到新版本。

## 二、卡住了按这个顺序查

- **安装被拦**：不同品牌手机的开关位置不同，有的叫「安装未知应用」，有的藏在浏览器或文件管理器的权限设置里，按提示跳过去允许本次安装，装完可以关回去；
- **装完打不开或闪退**：先确认安卓系统版本——各渠道对系统要求标注不一，有的标安卓 8.1 及以上；确认没问题仍闪退就重启手机再试；
- **想在电脑上用**：PC 端是独立的 Windows 客户端，不走这份安卓包，且需要先装 .NET Desktop Runtime，缺了它起不来。
