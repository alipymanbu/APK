# 安卓安装与首次上手

> 本篇讲把 OMate 装上安卓手机的完整路径：安装包从哪来、安装被拦怎么处理、装好后的三步上手。
> **相关文档**：[API密钥配置与模型分工](API密钥配置与模型分工.md) · [角色卡导入与酒馆生态迁移](角色卡导入与酒馆生态迁移.md)

---

## 一、安装包从哪来

OMate 面向安卓手机（iOS 侧另有上架，更新有延迟）。安装包可通过 [omate 安卓下载与安装指引](https://omate.usea.quest/) 页面获取：资源放在夸克网盘分享里，登录后转存到自己的网盘、再把 APK 下载到手机即可。

版本说明：网盘渠道的安装包更新节奏与商店版不同，装之前看一眼文件名里的版本号即可；核心玩法（角色创建与导入、聊天、长期记忆、故事模式）在各版本间一致，世界书、预设系统等属于后续版本新增的能力。

## 二、安装步骤与两个常见坎

安装就四步：

1. 允许「未知来源」：系统「设置 → 应用管理（或安全设置）」里，给文件管理器或浏览器开「安装未知应用」；
2. 点开 APK 按提示安装；
3. 首次启动按需授予存储等权限；
4. 装完建议把「未知来源」授权关回去。

两个真会挡路的坎：

| 现象 | 处理 |
| --- | --- |
| 点安装被系统拦 | 「未知来源」授权没开或只给了部分应用，找到实际打开 APK 的那个应用单独放行 |
| 提示「解析包错误」 | 多半安装包没下完整（文件明显偏小），删掉重下；个别老机型系统版本过低也会报 |

## 三、装好后的三步上手

1. **配密钥**：设置 → API 设置 →「+」，填名称、选规范（OpenAI / Claude）、贴密钥。首次启动时弹「请先到设置页面添加API配置」是设计行为，不是装错了；
2. **找角色**：发现页挑卡直接导入；本地 PNG / JSON 角色卡、含角色数据的链接也都能进；
3. **开聊**：对话页右上角「+」，选角色（必选）与面具（可选），创建后就能看到流式回复。

密钥的机制、六类模型的分工与省钱路径展开在 [API密钥配置与模型分工](API密钥配置与模型分工.md)；从酒馆搬家的对照表见 [角色卡导入与酒馆生态迁移](角色卡导入与酒馆生态迁移.md)。
