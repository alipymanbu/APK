# API密钥配置与模型分工

> 本篇讲 OMate「自带钥匙」的机制：为什么必须填自己的密钥、配置怎么加、六类模型各管什么，以及想省钱时怎么分工。
> **相关文档**：[角色卡导入与酒馆生态迁移](角色卡导入与酒馆生态迁移.md) · [安卓安装与首次上手](安卓安装与首次上手.md)

---

## 一、为什么必须填自己的密钥

OMate 不提供模型服务，所有 AI 回复都走用户自己填的 API 密钥。这带来三个直接后果：

- 聊天质量取决于选的模型，与应用本身无关；
- 费用由服务商直接收取，应用不收额外的服务费；
- 兼容 OpenAI 规范的中转站、局域网里的本地模型（Ollama 这类）理论上都能接。

支持两种接口规范：OpenAI 规范通吃，Claude 规范从 1.0.13 起可用（覆盖聊天和总结模型）。各家服务商支持程度不同，个别服务商下可能无法正常工作，选主流服务商出问题的概率最低。

## 二、添加配置与日常管理

1. 进「设置 → API 设置」，点「+」新增；
2. 填三项必填：名称（随意）、API 规范、密钥；
3. 保存后自动成为活跃配置，全局生效。

日常操作都靠滑卡片：左滑编辑、右滑删除（要输入确认，且至少保留一个配置）。表单右下角的浮动按钮能快捷填入预设服务商配置；配置支持导出成文件、扫码导入，换机迁移省事。每个对话还能单独换用另一套配置——日常聊天用便宜模型，写长篇时切到更强的。

## 三、六类模型各管什么

功能不止聊天一种，不同功能吃不同的模型：

| 模型类型 | 管什么 | 能否用对话模型顶替 |
| --- | --- | --- |
| 对话模型 | 与角色聊天 | ——（主力） |
| 总结模型 | 记忆提取、自动标题；不填则对话模型兼任 | 可顶替（单独配个便宜的更省） |
| 嵌入模型 | 知识库向量化 | 不能 |
| 语音模型 | 语音播放与通话的合成 | 不能 |
| 生图模型 | 创建角色时生成头像背景 | 不能 |
| 语音识别模型 | 语音通话里把你说的话转文字 | 不能 |

记两条就够：**只聊天，配一个对话模型就行**；**想用知识库、语音、生图，对应位置必须另填专门模型**——拿对话模型的名字填进嵌入模型位置是不工作的。

## 四、省钱与零成本的路径

- **降低调用单价**：选硅基流动这类聚合服务商，一个 key 能把六类模型配齐，模型以 DeepSeek / Qwen 等开源系为主，价格低于挤官方 API；
- **应用本身**：不收月费，Pro 功能按应用内提示激活；
- **零成本方案**：本地跑 Ollama，手机与电脑连同一局域网，API 地址填 `http://<电脑局域网IP>:11434/v1`——省的是调用费，换来速度与能力取决于电脑硬件，且嵌入、语音、生图这类专用模型本地未必有。

## 五、配好之后怎么验证

发一条消息，有流式回复就是通了。报错先查规范选对没有、密钥是否有效、服务商兼容性，九成的「没回复」都出在 API 配置这一层。装好应用是这一切的前提，步骤见 [安卓安装与首次上手](安卓安装与首次上手.md)；想让角色真正开口，还差一张角色卡，见 [角色卡导入与酒馆生态迁移](角色卡导入与酒馆生态迁移.md)。

更多功能拆解与界面实拍，见 [omate 速览站](https://omate.usea.quest/)。
