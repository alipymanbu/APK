# 手机上的三维星图怎么玩

多数天文应用只画星座盘，Celestia 走的是另一条路：它把整个宇宙做成可以飞的三维场景，行星、卫星、恒星、星团、星系都在数据库里，选中哪颗就飞到哪颗跟前，而且太阳系天体的位置和运动按真实规律逐秒推算——此刻火星在哪、木卫排成什么样，打开就能对上。

## 先记住四个手势

手机屏幕没有滚轮和右键，桌面版的操作在这里全部换成了触屏动作：

| 手势 | 作用 |
| --- | --- |
| 单指拖动 | 绕选中天体旋转视角 |
| 双指拖动 | 在空间中平移机位 |
| 双指捏合 | 拉近、拉远 |
| 单指点按 | 选中天体 |

学会这四个动作，看哪颗天体都是同一套操作。找天体用搜索框，输入英文原名（比如 `Mars`、`Io`）就能直达；每颗天体都带半径、自转周期这样的档案数据，行星的卫星子系统还能逐层展开。

## 时间才是真正的主角

默认状态下一切按真实时间走，行星的运动慢到几乎察觉不到。把时间流速调快，几分钟内就能看出地球自转、木卫绕转；调慢可以定格某个瞬间；它还支持整体倒转——把已经过去的天象「倒回去」重放一遍。

想精确对到某个日期，直接在时间设置里改；日食、月食这类天象甚至不用自己算时刻，内置的日食查找器会列出清单，选中一次就把视角带到对应的位置与时刻。

## 上手顺序建议

1. 跟着首次启动的教程过一遍手势；
2. 搜一颗熟悉的行星（比如 `Mars`）练习前往、跟随、锁定；
3. 打开时间控制，加速看一段卫星绕转；
4. 觉得画面里的星太少时，去 设置 → 图形 → 渲染参数 把星等下限调大。
