- 想快速了解它的玩法与界面，先读[手机上的三维星图怎么玩](手机上的三维星图怎么玩.md)；
- 想蹲一场日食、去追国际空间站，看[看日食与追踪空间站的模拟器玩法](看日食与追踪空间站的模拟器玩法.md)；
- 安装与首次启动遇到坎，参考[装不上或启动慢怎么办](装不上或启动慢怎么办.md)。
