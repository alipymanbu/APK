# Saylo 介绍站（saylo.fwen.ren）

这里是 AI 角色剧情聊天应用 **Saylo** 的第三方介绍站收录页。Saylo 把剧情聊天、捏角色、语音通话、漫画与动画短片装进同一个应用：你说一句台词、做一个动作，剧情就随你的选择往下走，聊出的好桥段还能一键排成多格漫画。

站点整理了它的玩法亮点、界面一览与安卓下载安装步骤，入口见 [saylo.fwen.ren](https://saylo.fwen.ren/)。
