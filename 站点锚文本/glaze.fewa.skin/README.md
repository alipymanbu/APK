## 这个名字下有什么

用搜索引擎查「glaze」，结果里会同时出现好几种东西：一款手机修图应用、芝加哥大学一个防止 AI 模仿画风的学术工具、还有一个网页小工具集合站。本目录讲的是第一款——导入照片、挑选画风、导出带笔触质感的"画作"，安卓端以安装包形式分发，入口与玩法说明都在 [glaze](https://glaze.fewa.skin/) 站点里。
