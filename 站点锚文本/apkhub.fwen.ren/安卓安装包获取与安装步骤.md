# 安卓安装包获取与安装步骤：apkhub 从下载到打开全流程

> 本篇按顺序讲 apkhub 的安装全流程：安装文件从哪拿、装之前要动哪个设置、四步怎么点、装不上时先查什么。
> **相关文档**：[聚合应用商店功能盘点.md](聚合应用商店功能盘点.md) · [资源搜索与下载技巧.md](资源搜索与下载技巧.md)

## 一、先弄清楚要装的是什么

apkhub 是安卓手机上的聚合应用商店，找应用、下游戏、管更新都在这一个 App 里。安装文件为 APK 格式，整理资料时对应的版本是 4.1.2，约 29.41M，需要 Android 5.2 及以上的系统。它不走系统自带商店分发，所以安装时 Android 会多拦一道「未知来源」，下面第三节专门处理。

## 二、拿安装包：从资源页到手机

安装文件资源放在夸克网盘，入口在 [apkhub 资料站](https://apkhub.fwen.ren/)的首页与下载页都有大按钮，点进去就是分享页。拿到手的方式有两种：

- **手机端**：在夸克 App 里打开分享页，转存到自己的网盘后，从「文件」里点开 APK 直接安装；
- **电脑端**：下载到电脑后，用数据线、局域网共享等方式把 APK 传进手机存储，再在文件管理器里点开。

装之前留够空间：包约 29.41M，加上安装后的占用，剩余空间建议至少 100M。

## 三、安装前动一处设置：允许「安装未知应用」

Android 8.0 起这项不再是全局开关，而是**按应用授权**——给你用来打开 APK 的那个应用（夸克、浏览器或文件管理器）开「允许安装未知应用」。入口一般在「设置 → 应用 → 特殊权限 → 安装未知应用」，个别品牌菜单略有差异：

| 品牌 | 常见入口 |
| --- | --- |
| 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 | 设置 → 安全 → 安装未知应用 |
| vivo | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 应用 → 特殊访问权限 → 安装未知应用 |

（以手机实际菜单为准。）

## 四、四步装好

1. 在文件管理器里点开 `apkhub_v4.1.2.apk`；
2. 系统弹「是否安装此应用」时点「安装」；
3. 装完点「打开」，或回桌面点图标；
4. 首次启动若弹网络、存储等权限请求，按需允许——网络权限必须给，否则内容加载不出来。

## 五、装不上时按现象查

- **「解析包时出现问题」**：安装包多半在传输中损坏，回资源页重新取一份再装；
- **点安装没反应**：第三节那个授权给错了对象——要授给打开 APK 的应用，不是授给 apkhub 自己；
- **装上了连不上、页面空白**：先切换一次网络试试；还要访问谷歌商店的内容时，确认网络环境能正常访问谷歌服务；
- **反复闪退**：划掉重开、清缓存、卸载重装，仍不行就核对系统版本是否达到 Android 5.2。

## 六、装完去哪继续

装好第一件事是把界面摸熟：[聚合应用商店功能盘点.md](聚合应用商店功能盘点.md) 把五个栏目与核心功能捋了一遍，[资源搜索与下载技巧.md](资源搜索与下载技巧.md) 教你把找资源的三条路走顺。两篇加上本篇，都同步挂在 [apkhub 资料站](https://apkhub.fwen.ren/)上，手机上看着更方便。
