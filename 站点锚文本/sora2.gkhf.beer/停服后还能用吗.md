# Sora 2 停服后还能用吗

> 本篇回答一个最常被问到的疑问：sora2 现在装上还能不能正常生成视频。按时间线讲清停服经过、哪些功能受影响、为什么这份安装包仍然值得留存。相关文档：[下载与安装步骤](下载与安装步骤.md) · [与山寨应用的区分](与山寨应用的区分.md)。

---

先给结论：**装得上，但用不了。** 生成、登录、信息流这些联网功能已经全部关闭；能留下来的，是安装包本身和它承载的界面设计。

## 一条时间线看明白

| 时间 | 事件 |
| --- | --- |
| 2025-09-30 | Sora 2 模型与同名社交应用发布，声画一体生成、Cameo 客串、Remix 二创是当时讨论度最高的三件事，三天登顶美国 iOS 应用榜 |
| 2025-11-04 | 安卓版在部分国家与地区上架，手机端用户这才拿到入场券 |
| 2026-04-26 | OpenAI 在产品页面挂出通告，Sora 应用与网页端自此不再可用 |
| 2026-09-24 | API 通道关闭，最后一条联网路径也没了 |

## 哪些功能受影响

服务端一关，所有依赖联网的环节都随之失效：

- **登录**：应用停在账号验证页，无法进入主界面；
- **生成**：文字生视频、图片生视频自然无从谈起；
- **信息流与 Remix**：视频源在云端，加载不出来。

这些都不是安装包损坏——换任何一份 APK 结果都一样。

## 那装它还有什么用

价值在界面本身。For You 信息流的排版、Remix 的提示词交互、创作者主页把赞、二创数与关注关系铺在一张卡片上的做法，都是当年被反复讨论的产品设计样本。对做设计、做产品研究的人来说，装一份在真机上翻一翻，比看十篇回顾文章直观。

想装一份留档的话，安卓安装包可以从 [sora2 存档站](https://sora2.gkhf.beer/) 取，站点里还留着四帧当年的真实界面截图；具体安装过程写在 [下载与安装步骤](下载与安装步骤.md) 里，动手前建议先看一眼 [与山寨应用的区分](与山寨应用的区分.md)，别把套壳应用当成它。
