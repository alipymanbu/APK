# PS1 模拟器的 BIOS 与游戏镜像准备

> ePSXe 装好只是第一步——它本身不带任何游戏，能不能玩起来取决于两样自备材料：一份 PS1 的 BIOS 文件，以及正确格式的游戏镜像。本篇讲清楚这两样东西是什么、放哪里、怎么被识别。

---

把模拟器类比成一台"虚拟主机"最好理解：安装包只是主机壳，BIOS 是开机固件，游戏镜像则是放进光盘仓的那张碟。三者缺一，开机画面都见不到。

## 先弄懂基准文件夹

从 2.0.16 起，安卓 11 及以上系统收紧了存储访问方式，ePSXe 也随之改用分区存储：首次启动会要求指定一个"基准文件夹"（ePSXe base folder），记忆卡、即时存档、金手指、补丁、BIOS、游戏目录全部收纳在这里。

两种选法差别很大：

| 选法 | 数据落点 | 卸载后 |
| --- | --- | --- |
| 共享存储（建议） | 你新建的文件夹，如内部存储根目录的 epsxe | 一般保留，用文件管理器就能拷走备份 |
| 私有存储 | Android/data 下的应用私有目录 | 随应用一起被系统删除 |

选好之后路径还能改：Preferences → Storage preferences → ePSXe base folder。从旧版本升级上来的，直接选旧版留在存储根目录的 epsxe 文件夹，旧档案才能被继续读到。

装完如果明明放了文件却读不到，多数是"所有文件访问"权限没放开：系统设置里搜索"所有文件访问权限"，找到外部存储项打开"允许管理所有文件"，再重启应用。

## BIOS：开机固件

ePSXe 启动商业游戏需要一份 PS1 的 BIOS 文件（通常是 SCPH 开头编号的 bin 文件），放进基准文件夹即可被识别。没有它，游戏镜像放进去也只会黑屏。

## 游戏镜像：格式与存放

支持的常见镜像格式包括 bin/cue、img、pbp 等。把镜像文件拷进基准文件夹下的游戏目录，回到主界面刷新，游戏就会出现在列表里——列表会自动读取镜像自带的游戏名与封面信息。

几个容易踩的小坑：

- bin/cue 是成对出现的，两个文件要放在同一目录，缺了 cue 侧的索引，游戏识别不到；
- 多碟游戏（如多张 CD 的 RPG）每张碟各自是一个镜像，切换碟片在模拟器菜单里操作；
- 镜像文件名建议保留原始命名习惯，部分游戏的补丁文件按文件名匹配。
