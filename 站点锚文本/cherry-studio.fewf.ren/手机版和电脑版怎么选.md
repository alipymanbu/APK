# Cherry Studio 手机版和电脑版怎么选

> Cherry Studio 有手机移动版和电脑桌面版两套客户端。本篇讲它们的平台、成熟度与功能边界，以及「配对导入」能带什么、不能带什么。
> **相关文章**：[是什么与能做什么](是什么与能做什么.md) · [手机版接入模型服务步骤](手机版接入模型服务步骤.md) · [助手市场与MCP工具玩法](助手市场与MCP工具玩法.md)

## 一、先给结论

两套客户端同属 CherryHQ、都开源，核心玩法一样——用你自己的 API 密钥接入多家模型服务。区别在成熟度：桌面版迭代多年、功能更全；手机版 2026 年起才放出、目前是 Beta，界面与功能会随版本快速调整。

## 二、双端对照

| 对比项 | 手机移动版 | 电脑桌面版 |
| --- | --- | --- |
| 平台 | Android（APK 安装，ARM64 设备）、iPhone / iPad（TestFlight 测试） | Windows / macOS / Linux |
| 成熟度 | Beta 阶段，变动快 | 正式版，迭代较久 |
| 招牌能力 | 口袋里的多模型对话 + 手机系统能力 | 知识库等桌面级功能 |
| 与另一端的关系 | 可扫码配对导入服务商配置 | 提供配对二维码 |

## 三、功能边界（截至 2026-09 的口径）

- **手机版有的**：多模型对话（流式回复、附件）、助手、MCP 工具、联网搜索、图片生成、文件导出，以及日历、提醒、位置这些系统能力的接入。
- **桌面版更全的地方**：知识库这类桌面级功能在移动端还没有对应入口，这类需求目前以电脑版为准。
- **两端打通的地方**：手机版可与桌面版配对，把电脑里配好的服务商与模型导入手机。

## 四、配对导入：能带什么、不能带什么

配对的范围是**模型服务商配置与已启用模型**；聊天记录、插件授权不在导入范围内，也不是远程控制电脑的方式。配对成功后不会持续自动同步，以后想更新配置要再手动同步一次。

大致步骤：手机与电脑连同一局域网 → 桌面端打开「设备互联」出二维码 → 手机端 **设置 → 设备互联 → 扫描二维码** → 勾选要同步的服务商。三个要点：

1. 同步会**覆盖**手机上同名服务商的地址与密钥——两端用不同密钥的话，想清楚再点；
2. 手机独有的服务商与模型不会被删；电脑端已停用的不导入；
3. 电脑上的本地模型服务（Ollama、LM Studio 这类）导不过来。

扫码成功但同步失败时，按顺序查：桌面端是否还开着、两台设备是否还在同一局域网、防火墙或代理有没有拦、手机是否拒绝了局域网权限。

## 五、怎么选

- 主要在手机上用、随时聊几句、发图读文件 → 手机版够用；
- 要建知识库、跑长任务、写长文 → 桌面版，密钥两端通用，配置还能导过去；
- 拿不准就两边都装，配对导入一次，差异一试便知。

两套都从同一个开源项目发布；安卓端安装包资源的获取入口与安装步骤，整理在 [Cherry Studio 安卓版介绍站](https://cherry-studio.fewf.ren/) 的下载页。装好后的配置走 [手机版接入模型服务步骤](手机版接入模型服务步骤.md)。
