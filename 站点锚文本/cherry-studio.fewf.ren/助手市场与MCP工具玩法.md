# Cherry Studio 助手市场与MCP工具玩法

> 手机版里最能拉开使用差距的一块：智能体怎么建、联网搜索与图片生成怎么开、MCP 工具接在哪、授权卡住了怎么办。

## 一、助手（智能体）是什么

把助手理解成一套可复用的「名称 + 任务说明 + 默认模型 + 工具」配置。给翻译任务写好固定要求存成助手，下次直接开它干活，不用每次重打提示词；同一个助手下面还能开多段互不干扰的对话。

自带的默认助手开箱可用；等你有了固定场景，再自建：

1. 从对话顶部打开助手编辑页；
2. 写清任务说明（扮演什么、输出什么格式、注意什么），选定默认模型；
3. 按需挂上工具（比如联网搜索），保存。

需要执行工具的助手，动作前会弹确认让你放行——不放心工具乱动东西的话，留意这个环节。

## 二、联网搜索与网页阅读

联网开关在**当前助手的编辑页**里，不在输入框上：先在设置里配好搜索服务，再到助手编辑页打开联网开关，之后在消息里直接提搜索要求就行。适合查近期新闻、核对变化中的价格、总结丢给它的网页链接。

模型转述二手信息偶尔走样，结果里带的来源建议顺手点开核对。找不到联网开关或插件按钮，多半是版本差异或插件还没连接——先更新，或去侧边栏连接插件。

## 三、图片生成与文件输出

- **图片生成**：从一句提示词或视觉模板起步，选图像模型生成；不满意拿成品当参考图继续改，历史会留着随时翻。
- **生成与修改文件**：让 AI 把回答整理成文件再继续迭代。
- **HTML 转长图与 PPT**：网页形式的输出转长图或演示文稿，方便直接转发。
- **导出对话**：选中内容导出为 Markdown、HTML 或图片，换机或存档时用得上。

## 四、MCP 工具接在哪

手机版的 MCP 市场里列着内置连接：网页抓取（fetch）、时间、日历、提醒事项等，拨动开关即可启用；按 MCP 协议还能接更多外部工具与服务。日历、提醒、位置属于手机系统能力，第一次使用会弹授权，不同意就只用不了那一项，其他功能不受影响。

上手节奏建议：先把一个助手配顺（模型 + 一两个工具）跑通，再往上叠。接好后在对话里直接说需求，模型会自己决定何时调用哪个工具。

## 五、授权卡住了怎么办

- 插件授权页面完成后一直没动静：回到应用里看状态，把账号或工作区的确认做完；
- 授权过期：重新发起一次；
- 组织权限不足：先去对应服务平台把权限申请下来；
- 「模型没反应」「工具不执行」这类问题，先回 [手机版接入模型服务步骤](手机版接入模型服务步骤.md) 核对密钥与服务商状态。
