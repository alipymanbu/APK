# Cherry Studio 手机版接入模型服务步骤

> 装好 Cherry Studio 手机版后发不出第一条消息？多半是还没接入模型服务。本篇讲密钥从哪来、两条配置路线怎么选、怎么验证配置成功。
> **相关文章**：[是什么与能做什么](是什么与能做什么.md) · [手机版和电脑版怎么选](手机版和电脑版怎么选.md) · [助手市场与MCP工具玩法](助手市场与MCP工具玩法.md)

## 一、为什么装完还不能聊

Cherry Studio 是客户端，不附带模型额度。你看到的每个回答，都是它拿着你提供的 API Key 去对应平台请求回来的。所以第一次打开要先做一件事：把至少一个模型服务接进来。

两个常见误解先澄清：

- **API Key 不是账号密码**——它是你在模型平台开放接口页面单独创建的一串字符；
- **聊天会员不等于接口额度**——在某家平台充了会员，不代表它的 API 能随便调，额度规则以平台说明为准。

## 二、两条路线，先选一条

| 你的情况 | 走哪条 |
| --- | --- |
| 电脑上已在用桌面版、服务商都配好了 | 扫码配对，把配置导入手机（步骤与边界见 [手机版和电脑版怎么选](手机版和电脑版怎么选.md)） |
| 第一次用，或电脑上没配过 | 在手机上直接添加服务商，按下面三步走 |

## 三、手机上添加服务商

1. 首次使用向导里直接选服务商；错过了向导就从 **设置 → 模型服务 → 添加服务商** 进去。
2. 内置服务商列表覆盖常用平台，连接设置都预填好了；列表里没有的平台选自定义，按平台说明填基础地址。
3. 粘贴平台给你的 API Key，保存。
4. 同步模型列表；拉取失败不代表性不能聊，把平台文档里的准确模型 ID 复制下来手动添加即可。
5. 回头确认服务商处于启用状态，再到对话顶部选好刚启用的模型。

## 四、密钥从哪来

- **各模型平台的开放接口页面**：DeepSeek、硅基流动、智谱等平台注册后在开放平台或个人中心创建，各家入口名不一样，以当时页面为准。
- **免费体验的模型**：产品方与合作渠道会不定期提供免密钥或免费的模型供体验，活动随时可能调整。
- **用量与账单**：记在你创建密钥的平台那一侧，客户端里看不到账单。

## 五、发一条消息验证

1. 用自带的默认助手，在对话顶部选好刚配置的模型；
2. 发一句「用三句话介绍你能帮我做什么」；
3. 收到回复，基础配置就完成了。

没收到回复时，先换一条不带附件的短消息重试；还不行就按顺序核对密钥、服务商启用状态与网络。配置跑通之后，值得先去 [助手市场与MCP工具玩法](助手市场与MCP工具玩法.md) 挑两个顺手的助手存成常备。

还没装上的话，[Cherry Studio 安卓版介绍站](https://cherry-studio.fewf.ren/) 的下载页整理了安装包资源的获取入口与完整安装步骤。
