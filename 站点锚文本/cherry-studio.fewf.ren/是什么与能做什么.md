# Cherry Studio 是什么与能做什么

> 本篇回答最基础的疑问：Cherry Studio 到底是个什么软件、能拿来干什么、要不要花钱。
> **相关文章**：[手机版接入模型服务步骤](手机版接入模型服务步骤.md) · [手机版和电脑版怎么选](手机版和电脑版怎么选.md) · [助手市场与MCP工具玩法](助手市场与MCP工具玩法.md)

## 一、一句话定位

Cherry Studio 是一款开源的 AI 聊天客户端（桌面端按 AGPL-3.0 协议开放源码），由 CherryHQ 团队开发。它本身不生产模型，而是充当「统一入口」：把 DeepSeek、GLM、Gemini、Claude 等主流模型服务接进来，让你在同一个界面里对话、比较、协作，不用为每家模型各装一个应用。

它的核心逻辑是「自带密钥」——你在各模型平台的开放接口页面创建 API Key 填进去，调用产生的费用由平台按量结算，客户端本身的核心功能不收费。

## 二、能做的事情盘点

- **多模型对话**：流式回复、Markdown 渲染、图片与文件附件；同一个话题里随时切换模型，哪家的回答更合意一眼便知。
- **预设助手**：内置上千个分类助手，覆盖写作、翻译、编程、产品、运营等场景，也能为固定任务自建。
- **工具扩展**：支持 MCP（Model Context Protocol）协议，网页抓取、日历、提醒这类内置连接开箱即用，还能接 Notion 等外部账号。
- **联网搜索**：给助手打开联网开关后，新闻、价格这类时效性问题可以直接问，结果带来源链接。
- **图片生成**：选一个图像模型，从一句话或视觉模板起步出图，成品还能当参考图继续改。
- **文件输出**：把回答整理成文件、网页输出转长图或演示文稿，对话内容可导出为 Markdown、HTML 或图片。

手机端（安卓 APK 形式发布，iPhone / iPad 走 TestFlight 测试）把上面这些能力搬进了口袋，还多了日程、提醒、位置等手机系统能力的接入。功能全貌与安装包资源的获取入口，见 [Cherry Studio 安卓版介绍站](https://cherry-studio.fewf.ren/)。

## 三、适合谁用

- **手里已有 API 密钥的人**：密钥不再绑死在某一家，一个客户端全用上。
- **想在手机上随时用 AI 的人**：通勤路上问一句、随手拍图让模型看，比开电脑轻得多。
- **喜欢折腾工具链的人**：MCP 协议 + 自建助手，可以把日常流程串成自动化。

## 四、开始之前要知道的三件事

1. 装完不能直接聊，先接入至少一个模型服务——两条配置路线见 [手机版接入模型服务步骤](手机版接入模型服务步骤.md)。
2. 手机端还在 Beta 阶段，界面与功能会随版本调整，个别入口找不到多半是版本差异。
3. 桌面版功能更全（如知识库），双端的取舍在 [手机版和电脑版怎么选](手机版和电脑版怎么选.md) 里有对照。
