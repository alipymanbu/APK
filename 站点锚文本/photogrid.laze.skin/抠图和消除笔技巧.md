# 抠图换背景与消除路人的实用技巧

手机上两个高频修图动作：把主体从背景里抠出来，以及把画面里多余的东西抹掉。这篇以 PhotoGrid 里的「Cutout」和「Remove」两个功能为例，说说各自在什么情况下效果好、什么情况下要收着用。

## 一、智能抠图：点一下就出来

1. 打开照片进编辑，找到「Cutout」入口；
2. 点一下主体（人物、宠物、物品），边缘自动识别，主体就被抠出来了；
3. 换背景：纯色、渐变、图案都行，也能从相册另选一张照片当背景；
4. 边缘不干净（发丝、毛边）时，用擦除 / 修复笔沿着轮廓手动修一圈。

典型用途：做头像、商品图换底色、把人从合影里单独拎出来再合成。背景越干净（纯色墙、天空），识别越利索。

## 二、消除笔：小面积分次涂

1. 编辑时选「Remove」；
2. 把要去掉的东西涂出来：路人、电线、地面杂物都可以；
3. 松手后应用拿周围画面自动补上；不满意就撤销，换个范围再涂。

两个经验：

- **背景简单效果好**：人群、树叶、砖墙这类复杂纹理，补出来的区域容易有涂抹感，分小块多试几次；
- **一次别贪大**：小面积分多次消除，比一整块涂掉效果好得多。

## 三、顺手的其它工具

| 工具 | 干什么用 |
| --- | --- |
| 滤镜 / 调节 | 整体调色，或手动微调亮度、色温 |
| 文字 | 加字、换字体，支持弧形排布 |
| 贴纸 | 数量多，可按关键词搜索 |
| 马赛克 / 模糊 | 挡车牌、人脸这类敏感信息 |
