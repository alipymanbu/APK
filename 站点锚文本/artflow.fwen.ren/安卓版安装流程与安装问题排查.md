# 安卓版安装流程与安装问题排查

> ArtFlow 的安卓安装文件走网盘分享，流程比应用商店多一步「转存」，安装时最常见的拦路虎是「未知来源」提示和「应用未安装」报错。这篇按顺序写全四步，再把三类典型问题逐一给处理办法。

## 装之前

网盘收录的这一版约 12.56 MB（版本 2.9.40），要求 Android 9.0 及以上。体积小，普通网络几十秒能下完；系统版本可以直接在「设置 → 关于手机」里核对，老机型装不上这一版多半卡在这条，不是步骤做错。

## 四步装完

1. **转存**：打开网盘分享页，登录后选「保存到我的网盘」，把安装文件先存进自己账号。转存的意义是文件从此在自己账号里，之后随时能重新下载，不受原分享状态影响。
2. **下载**：在自己账号的网盘里找到这份文件，下载到手机或平板的「下载」目录。中途断网就删掉重下，装坏包比不下更耽误事。
3. **放行未知来源**：点开 APK 时系统若提示「不允许安装未知应用」，按「设置 → 应用管理 → 特殊权限 → 安装未知应用」的路径，给你用来打开安装文件的那个应用（文件管理器或浏览器）勾上允许，再回去重新点安装包。这是安卓对手动安装的常规提示，装完可以把权限关回去。
4. **安装并打开**：装完点打开，首次进入会请求存储权限，允许后新建画布就能开画。

获取入口与界面截图都整理在第三方站 [ArtFlow 安卓版下载与安装](https://artflow.fwen.ren/) 里，照着页面的四步走即可。

## 三类典型问题

**提示「应用未安装」**
设备里多半已有一份同包名的其他来源版本，签名对不上就会这样报。把旧的那份卸载干净，再装这次下载的文件即可。两份应用图标长得一样也不要留着共存，卸旧装新是唯一解。

**安装中途失败或卡进度**
先查剩余存储空间，清出几百 MB 以上再试；空间够还失败，回网盘重新下载一遍——下载中断产生的坏包，安装器跑到一半必然失败。

**装好就闪退或打不开**
先核对系统版本是否达到 Android 9.0；达标仍闪退就重启一次设备再开。若曾经用「冻结/禁用」类工具动过系统应用权限，把 ArtFlow 从冻结名单里放出来。

## 装完之后
