# 画笔图层与压感从零上手

> 第一次打开 ArtFlow 不知道从哪落笔的话，照「起稿 → 选笔 → 调色 → 分层 → 导出」这条会话路线走一遍就够。这篇把每一步会碰到的设置项和容易漏的小开关列出来，压感与手掌防误触单独说。

## 五步会话路线

**起稿**：新建画布后直接开画。顶栏集中了画笔、橡皮、填充、选区、裁切这些高频工具，右侧竖条调笔刷粗细，不用翻菜单。第一遍线条乱没关系，画在单独一层上，后面好收拾。

**选笔**：笔刷面板里按类挑——铅笔、马克笔、粉蜡笔各有用处，每支笔点齿轮图标进设置能改参数。进阶玩法是把导入的图片做成自定义笔刷：想要纸纹、喷溅、排线，自己造一支。涂抹（smudge）和填充工具与画笔同栏，铺色过渡一气呵成。

**调色**：色轮转大类，RGB 滑块微调；常用的颜色点一下就固定进下方色板，下一张画还在。

**分层**：最多可开 50 个图层（部分上限需 Pro 许可）。阴影单独一层用 Multiply 压暗，高光一层用 Screen 提亮，整体对比用 Overlay——混合模式有 Normal、Multiply、Screen、Overlay 等一整套，改哪层都不牵连别的。剪切蒙版和选区蒙版也在这一块面板里。

**导出**：PNG、JPG 直接出图；要回电脑继续画就导出 PSD，图层与混合模式原样带走。菜单里还有「Record timelapse」，整段作画过程能录成延时视频。

## 压感与防误触怎么开

- **有压感笔**（S Pen、同类主动笔）：默认直用，笔迹随力度变化，不需要额外设置。
- **纯触屏**：设置里有压感模拟开关，打开后靠笔速和轨迹估算轻重，手写感尚可，笔锋层次不如真压感笔。
- **手掌防误触**：同样在设置里开。掌缘搭在屏幕上不再被当成笔迹，托着手画长线才稳。这几项的支持程度依设备而定，开启后画几笔试下手感最直接。

## 容易漏的三个小习惯

1. **先 Save 再导出**：导出 PNG/JPG 是成品图，工程文件要另外在菜单里 Save 一份，下次才能接着改。
2. **撤销历史有长度**：免费版的撤销步数有限，大改动前手动存一层副本，比依赖撤销可靠。
3. **画布别一味开最大**：6144×6144 配 50 层对老设备压力大，速写用 2048 一档更流畅，成品再升画布。
