# 怎么训练角色 LoRA，让 AI 画的角色不换脸

用 AI 画同人图最崩溃的一刻：昨天那张女主明明很好看，今天再生成就换了个人。问题不在模型，而在玩法——想让同一个角色反复出现，靠的是把角色训成一个 LoRA 模型，之后每次生成都挂上它。PixAI 把「训练 LoRA」做成了 App 里的标准功能，这也是它区别于一般 AI 绘画应用的地方。

## 训练之前：先把素材洗干净

LoRA 的质量上限由训练素材决定，上传前逐张过一遍：

- **同一个角色**：混进别的角色，模型学出来的脸就会"串味"；
- **去水印、去文字**：水印会被当成画风的一部分学进去；
- **背景尽量干净**：杂乱背景会稀释角色本体的特征权重；
- **数量适中**：一组同角色、不同角度与表情的图，比一大堆重复角度的图更管用。

## 选对训练类别

PixAI 的训练面板按目的分了五类，画人最常用第一类：

| 类别 | 用途 |
| --- | --- |
| Character | 锁定角色长相（同人创作主力） |
| Style | 复刻某种画风笔触 |
| Animal | 动物形象 |
| Clothing | 一整套服装造型 |
| Realistic | 写实向对象 |

## 训练流程五步走

1. 在 App 里进入 LoRA 训练面板，新建训练任务；
2. 上传准备好的角色图片；
3. 给 LoRA 起名，并填一个**触发词**——这个名字就是以后在 prompt 里召唤角色的暗号；
4. 选类别、模型类型与主题；
5. 点开始训练，排队跑完后它会出现在自己的模型列表里。

## 生成时怎么用

训练完成后，在生成页把该 LoRA 叠加进任务，并把触发词写进描述里。据公开资料，免费档单次生成最多可以叠 3 个 LoRA——典型组合是「角色 LoRA + 画风 LoRA」，付费档上限更高（最高一单 15 个）。叠太多反而互相打架，先从两个开始试。

出图仍有个别张脸崩，属于正常波动：换种子重抽、或把触发词权重调高一档，比全盘推翻重训划算。
