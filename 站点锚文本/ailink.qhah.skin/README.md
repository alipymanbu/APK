# ailink 说明站目录

这里是 ailink（AiLink）应用的第三方说明专辑。ailink 是深圳市易连物联网为其智能硬件产品线配套的应用，体脂秤、血压计、体温计、血糖仪等设备通过它完成绑定与数据查看；本专辑围绕设备适配、连接排查、数据分享三个真实使用场景做了整理，安装包获取入口见文内说明。
