# ailink 能连接哪些设备

> ailink（AiLink）是深圳市易连物联网面向自家智能硬件做的配套应用，很多牌子的体脂秤、血压计、体温计说明书上写的「适配 AiLink App」指的就是它。这一篇把它的设备版图列清楚，买硬件前可以先对照，看手里这台要不要装它。

## 一、设备版图按六大类铺开

与很多「一件硬件配一个 App」的做法不同，ailink 走的是「一个应用接多品类」的路子，厂商给这些设备做了统一的接入协议：

| 类别 | 典型设备 | 连接方式 |
| --- | --- | --- |
| 智能健康 | 四电极 / 八电极体脂秤、营养秤、咖啡秤、婴儿秤、身高仪 | 蓝牙或 WiFi |
| 智能医疗 | 血压计（蓝牙 / WiFi / 4G）、血糖仪、血氧仪、体温计、额温枪 | 蓝牙、WiFi 或 4G |
| 个护运动 | 蓝牙电动牙刷、筋膜枪、智能跳绳 | 蓝牙 |
| 智慧安全 | 蓝牙门锁、箱包锁 | 蓝牙 |
| 智慧出行 | 胎压监测、智能滑板车 | 蓝牙 / 透传 |
| 仪器仪表 | 温湿度计、环境监测仪、食物温度计 | WiFi + 蓝牙 |

同一台设备具体用哪种连接方式，以机身或说明书标注为准：只写蓝牙的，手机直连即用；带 WiFi 标识的，绑定后还要做一次配网，设备才能在无人值守时继续上报数据。

## 二、怎么确认手里的硬件适配它

三个办法，按顺序试：

1. **看说明书**：适配页通常会直接写「AILink」字样，有的还会给出扫码下载入口；
2. **看 App 内列表**：在「添加设备 → 手动添加」里翻分类列表，能找到对应型号就说明适配；
3. **问销售渠道**：购买页的参数表一般会标注配套应用名称。

顺带一提，同一家厂商还有 AICare 等其他应用，部分设备同时支持多个 App。买错应用的情况不算少见——列表里翻不到自己的型号时，先别急着反复重试，对照说明书确认应用名称更省时间。

## 三、系统与手机要求

- 手机蓝牙 4.0 及以上；
- 系统版本 Android 4.4 / iOS 9.0 起步；
- 八电极体脂秤这类功能较新的设备，对应用版本要求更高（说明书会标注最低版本号），装的时候留意一下版本是否达标。

设备能不能发挥全部功能，一半取决于应用装没装对。想看这个应用各页面的实际样子，可以浏览 [ailink 应用说明站](https://ailink.qhah.skin/)，站里按设备版图、核心功能、常见疑问分块做了整理。
