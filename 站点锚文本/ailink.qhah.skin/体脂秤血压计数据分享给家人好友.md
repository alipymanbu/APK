# ailink 体脂秤血压计数据分享给家人好友

> 一台秤全家轮流站、爸妈的血压想让孩子远程看到——在 ailink（AiLink）里这是两条不同的路：「家人」管同一屋檐下共用设备的分人记账，「好友」管跨账号看数据。这一篇把两条路各自的用法和坑写清楚。
> **本目录相关文章**：[能连接哪些设备.md](能连接哪些设备.md) · [搜不到设备怎么办.md](搜不到设备怎么办.md)

## 一、家人和好友，先分清再用

| | 家人 | 好友 |
| --- | --- | --- |
| 建在哪 | 建在自己的账号下 | 对方是另一个 ailink 账号 |
| 用途 | 共用设备，测量结果分人归档 | 查看开放出来的数据 |
| 对方要装应用吗 | 不用，家人不需要账号 | 要，好友必须是另一个账号 |
| 典型场景 | 一家三口共用一台八电极体脂秤 | 异地子女看爸妈的血压记录 |

一句话：同住、共用同一台设备的加「家人」；不住一起、只想让对方看结果的走「好友」。

## 二、家人：建好之后测量前要切换

1. 打开「我的 → 我的家人 → 添加家人」，填头像、关系、昵称、生日、性别；
2. 测量前在设备页把人**切换到对应的人**，这次读数才记到那个人名下；
3. 每个账户最多支持 20 位家人。

两个要当心的地方：

- **生日与性别是数据换算参数**，体脂率这类指标靠它们计算，随手乱填会让结果跟着偏；
- **「关系」一旦填写无法修改**，它是这个家人在账号下的唯一标识。而删除家人会连人带数据一起清空、不可恢复——想改关系只能删了重建，历史曲线会一并消失，动手前想清楚。

## 三、好友：扫码加人，勾选开放

1. 对方装好 ailink 并注册账号；
2. 通过「扫一扫」扫对方二维码，或用「搜索 ID / 账号」发验证加好友；
3. 关键一步：在「隐私保护」里打开「**数据开放用户**」，勾选要开放给好友查看的家人——没勾选的，对方看不到；
4. 主账户的数据默认开放；自己名下没有任何可选用户时，好友列表里不会出现这个人。

取消勾选只是让对方看不到，数据本身不受影响，随时可以再开回来。只想临时发一次结果的话，用设备首页右上角「…」里的分享，不必加好友。

## 四、数据归属的几个细节

- 同一个人用两台秤，同类数据会汇总到这个人名下的同一条曲线里，不按设备分家；
- WiFi 设备离线期间测的记录，联网后自动匹配到对应用户，匹配不上的不保存；
- 发现数据挂错了人（比如自己测的记到了家人名下），切回正确的人重测一次即可。
