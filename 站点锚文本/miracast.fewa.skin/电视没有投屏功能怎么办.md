# 电视没有投屏功能怎么办

想用投屏，翻遍了电视菜单却连「无线投屏」「屏幕镜像」的字样都找不到——这台电视是不是彻底没戏了？分几种情况说。

## 先确认是不是「叫法不同」

Miracast 是无线显示标准的名字，电视厂商很少原样印在菜单里，更常见的是换成自家说法：

- 无线投屏 / 多屏互动 / 屏幕镜像
- Screen Mirroring（三星等外资品牌常用）
- Smart View / AnyView Cast 等

以小米电视为例，入口藏在「我的应用 → 无线投屏 → Miracast」，打开后进入等待连接状态。所以第一步是把设置里的网络、显示、更多应用几个分区翻一遍，尤其留意带 "Cast"、"Mirror"、"Miracast" 字样的条目。

## 真没有接收能力时，还有一条正路

如果菜单里确实什么都没有（常见于老款智能电视和早期非智能电视），电视本身当不了接收端，但只要它**带 HDMI 接口**，就能插一个无线显示适配器（俗称投屏电视棒）来补上这块能力：

1. 适配器接电视 HDMI 口并供电，电视切到对应信号源；
2. 适配器自身进入无线显示等待状态；
3. 手机端用 Miracast 这类安卓投屏工具搜索设备、发起连接——从此电视就「变成」了一台支持无线显示的接收端。

这条路线的花费不高，也不用动电视本身的系统。手机端工具怎么拿、怎么装，可以看 [Miracast 投屏使用整理站](https://miracast.fewa.skin/download.html)，页面里按下载与安装的顺序整理了步骤。

## 这些情况要先排除，别急着怪电视

- **手机系统太老**：安卓 4.2 以下用不了这类投屏，先确认手机端版本；
- **手机被厂商关了投屏**：个别机型在系统层限制或关闭投屏能力，这种硬件限制换应用也救不回来；
- **两端不在一个网络环境**：部分电视的投屏入口依赖局域网发现设备，路由器开了「智能带宽分配」类功能时也可能干扰连接，排查时可以先关掉再试。

## 连上之后就一劳永逸了吗

适配器方案一次性解决了「电视接不住」的问题，之后手机相册视频、在线影片、手游画面都能走整屏镜像或按内容推送上大屏。连接细节（PIN 码验证、画面比例调整、频段选择）在[手机游戏画面怎么投到电视](手机游戏画面怎么投到电视.md)一篇里有展开。
