# 安卓端安装步骤与首次注册

> 手上没有应用商店渠道也能在安卓手机上装 Kindroid。本篇按实际顺序写：安装包从哪来、未知来源权限怎么放行、装完怎么注册登录，以及两个最常见的安装报错。

## 装之前确认两件事

- 手机系统建议安卓 7.0 及以上，过低会装不上或闪退；
- 安装包走夸克网盘分享：先转存到自己网盘空间，再下载 APK 到手机存储。

两种获取渠道（应用商店与安装包）登录同一账号即可，对话与记忆云端同步，不用迁移数据。

## 四步装好

1. **下载 APK**：从网盘把文件下载到手机存储；
2. **点开 APK**：在文件管理器里找到它，点开；
3. **放行未知来源**：系统提示「禁止安装未知来源应用」时按提示允许——不同品牌入口略有差异，一般在 设置 → 应用 → 特殊应用权限 里；
4. **完成安装并打开**：进度走完点打开，进入注册流程。

## 首次启动与注册

打开应用，先看到品牌启动页，随后是登录选择：

- **Google 一键登录**：手机上有 Google 账号就选这条，最快；
- **邮箱注册**：填入邮箱接收一次性验证码，15 分钟内有效，输完即完成注册。

注册完进入首页就可以建第一个角色、开聊了。新账号一般有一段全功能试用期，结束前留意订阅开关，原因见[免费档与订阅价格怎么选](免费档与订阅价格怎么选.md)。

## 两个常见报错

| 提示 | 先做什么 |
| --- | --- |
| 解析包失败 / 应用未安装 | 多半是下载不完整，删掉本地文件重新下载再装；反复失败核对系统版本 |
| 点安装没反应 / 被禁止 | 给文件管理器或浏览器授「安装未知应用」权限，再回来重新点安装 |
