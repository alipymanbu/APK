# 眼前的山叫什么名字？用什么查最准

> 这篇讲几种把「眼前那座山」对上名字的实用办法：从最容易上手的地图软件，到专门认山的全景工具，各适合什么场合。
> **相关文档**：[山里没信号怎么认山](山里没信号怎么认山.md) · [徒步前怎么预演要看到的山](徒步前怎么预演要看到的山.md)

---

在山顶或垭口看到一排山头，却一个名字都叫不出，是很多徒步和摄影爱好者的共同经历。下面几种查法各有长短，按场合挑着用。

## 一、地图软件：先定位置，再看周边地名

高德、奥维这类地图软件能确认脚下坐标，放大后能看到周边标注过的地名。优点是人人都有；缺点也明显——只标「收录过的地名点」，一座没有标注的无名峰在地图上就是一片空白，而且 2D 俯视视角很难跟眼前的实景对上号。

## 二、认山全景工具：按视线方向逐座标名

专门做认山的工具（如 PeakFinder）走的是另一条路：按当前位置实时渲染一圈 360° 山峰线稿全景，视野内每座山拖着线标注名字，还能把全景叠加到相机画面上，指着实景逐个确认。它内置地形高程模型和山峰目录，收录山峰以百万计，连不起眼的小山头大多有名字——查不到标注的山，用它的「望远镜」功能逐座确认是最快的办法。

实际体验可以用这个 [PeakFinder 认山全景站](https://peakfinder.wrwq.fun/)了解它的玩法与获取方式。

## 三、请教人与查资料：慢，但补充细节

- **当地向导、老乡**：方言名、别名、登山口位置，这些是任何软件都查不全的活资料；
- **县志、登山报告、游记**：适合考证一座山的历史叫法与攀登记录；
- **天文与观山社区**：拍「日照金山」的人群常互相核对机位与山名。

## 四、怎么选

| 场合 | 建议 |
| --- | --- |
| 城市周边、有信号 | 地图软件够用 |
| 深山、垭口、没信号 | 提前装好离线认山工具（见[山里没信号怎么认山](山里没信号怎么认山.md)） |
| 要写游记、考证名字 | 软件先定位，再用文献核实 |
| 拍风光要等光线 | 选带日月轨迹推演的工具（见[徒步前怎么预演要看到的山](徒步前怎么预演要看到的山.md)） |

把两三类办法搭配着用：软件负责「快」，向导与资料负责「准」。
