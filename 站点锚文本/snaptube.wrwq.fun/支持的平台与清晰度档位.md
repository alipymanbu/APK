## 能从哪些站点存内容

Snaptube 的定位是「一个应用管多个平台」，不同页面的口径在 50+ 到 100+ 之间，常见的是这些：

| 类别 | 平台 |
| --- | --- |
| 视频 | YouTube、Facebook、Instagram、TikTok、Twitter/X、Vimeo、Dailymotion |
| 音乐 / 音频 | SoundCloud 及各站点的音乐内容 |
| 社交 / 短视频 | Instagram、Facebook、TikTok 的帖子与 Reels |
| 即时通讯 | WhatsApp 状态（Status）保存 |

两条边界要心里有数：

- **能存到什么，最终由内容平台决定**。平台改接口、内容有地区或年龄限制时，个别内容可能解析不出来，属于常见波动，换个同类内容验证即可；
- 不是所有平台都给同样的档位——**源内容提供什么，选择窗里才出现什么**。

## 视频档位（MP4）

| 档位 | 适合 |
| --- | --- |
| 144p / 240p | 极省流量 |
| 360p / 480p | 竖屏小视频够用 |
| 720p / 1080p | 手机观看的主流选择 |
| 2K / 4K | 投电视、大屏看（源支持时） |

## 音频档位（MP3 / M4A）

| 码率 | 适合 |
| --- | --- |
| 70k | 语音类内容 |
| 128k | 日常听歌 |
| 160k | 比 128k 略好一档 |
| 320k | 追求音质 |

同一条内容既要视频又要音乐时，分两次下：一次选 MP4 档位、一次选音频码率。具体的选择操作见[怎么把视频音乐保存到手机](怎么把视频音乐保存到手机.md)。

## 设备与平台边界

| 问题 | 结论 |
| --- | --- |
| iPhone / iPad 能用吗 | 不能，只有安卓版，iOS 版已下架 |
| 电脑上有吗 | 没有原生版本，所谓「电脑版」都是安卓模拟器加 APK 的组合 |
| Google Play 能装吗 | 不能，商店政策不允许上架这类应用，只能装 APK 或看厂商商店 |
| 需要 Root 吗 | 不需要，普通安卓机直接装 |
| 需要登录吗 | 不需要，装完即用 |
| 最低安卓版本 | 口径为 Android 5.0 以上 |

装的过程中遇到问题，转到[安装不上的常见原因与解决办法](安装不上的常见原因与解决办法.md)；功能全貌与安装文件资源的获取入口，见 [Snaptube 功能介绍与安装指引站](https://snaptube.wrwq.fun/)。
