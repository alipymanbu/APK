# 怎么把视频音乐保存到手机

> 本篇讲 Snaptube 装好之后的实际操作：三种保存入口按场景怎么选、格式与清晰度怎么定、下载过程怎么控制、文件最后存在哪。
> **相关文档**：[支持的平台与清晰度档位](支持的平台与清晰度档位.md) · [安装不上的常见原因与解决办法](安装不上的常见原因与解决办法.md)

---

## 三种保存入口，按当时场景挑

| 入口 | 操作 | 适合场景 |
| --- | --- | --- |
| 分享转发 | 在别的应用里点「分享」→ 选 Snaptube | 已经刷到了想存的内容，这是最快的一条路 |
| 粘贴链接 | 复制内容链接 → 打开 Snaptube，搜索框会自动识别剪贴板 | 链接在网页或聊天窗口里 |
| 应用内搜索 | 顶部搜索框输关键词，或按平台分类浏览 | 还没锁定具体哪一条，想边看边挑 |

以 Instagram / Facebook 的视频为例：在应用里点分享 → 更多 → Snaptube，下载入口会直接弹出来；WhatsApp 的状态（Status）则是先在 WhatsApp 里看一遍，再打开 Snaptube 就能存。

## 点下载之后：格式怎么选

下载按钮点下去会弹格式选择窗，默认给几个常用项，不够就点「更多格式」看完整清单：

- **只想听歌**：直接选音频分类下的 MP3 或 M4A，128k 码率日常够用，有要求再上 320k——不用先下视频再转，应用只抓音频流；
- **手机上看**：MP4 选 720p / 1080p，清晰度与体积比较平衡；
- **投电视大屏看**：源视频有多高就选多高，最高 4K；
- **流量紧张**：视频选 360p 以下，或干脆只下音频。

每个档位旁都标着预估文件大小，选之前扫一眼就不会超存储预算。带字幕的内容在「更多格式 → 字幕/CC」里选语言；打开一个播放列表点下载，可以整批加入队列。

## 下载过程中的几个控制

- 下载管理页里可以看进度，支持**暂停 / 继续 / 取消**；
- 网络断了恢复后点重试，会**从断点续传**，不会从零开始；
- 下载可以退到后台跑，切去聊天、锁屏都不影响（把 Snaptube 加进系统的「后台不限制」名单更稳）；
- 只想 Wi-Fi 下下载：设置里开「仅 Wi-Fi 下载」，误点也不会烧流量。

## 文件存哪了

- 默认在手机内部存储的 **Snaptube 文件夹**，视频与音乐分文件夹归类；
- 应用的「我的文件」里可以直接播放、分享、删除，系统文件管理器和相册里也找得到；
- 机型支持插卡的话，可在设置里把保存路径改到 SD 卡；误删的文件试试 设置 →「恢复已删除文件」。

更多格式与平台边界的说明，见[支持的平台与清晰度档位](支持的平台与清晰度档位.md)；想了解这个工具的完整功能面貌与安装文件资源的获取方式，可以看 [Snaptube 功能介绍与安装指引](https://snaptube.wrwq.fun/)。
