# 现场怎么接CDJ和控制器：rekordbox 手机版的两种接法

> 本篇讲 rekordbox 手机版连接硬件的两种场景：在家接 DDJ 控制器练手感，在俱乐部把手机接到 CDJ / XDJ 上放歌，含连不上的排查顺序。
> **相关文档**：[手机打碟从零上手.md](手机打碟从零上手.md) · [免费版和订阅怎么选.md](免费版和订阅怎么选.md)

## 一、连之前的三项准备

1. **登录账号**：连接 DJ 设备打碟属于需要登录 AlphaTheta 账号的功能，没登录时硬件连上了也无法使用。
2. **确认机型**：手机版只支持适配清单内的型号，不在清单里的设备（包括很多能接电脑版的控制器）连上也不会被识别。
3. **备好线材**：控制器走 USB 线或蓝牙；接播放器则视机型选对线——标 Type-B 的用 A 转 B 数据线，标 Type-C 的用 C 对 C 线，手机那头可能还要 OTG 转接头。

## 二、在家练手：接 DDJ 控制器

适配清单内的入门控制器（DDJ-200、DDJ-FLX2、DDJ-FLX4、DDJ-GRV6）用 USB 数据线连手机，或在蓝牙设置里配对。识别成功后，推子、转盘、打击垫直接控制手机界面，耳机预监听是否可用取决于订阅状态。

机型清单会随版本更新，购买前先在最新的适配说明里核一遍。

## 三、去俱乐部：手机接 CDJ / XDJ

手机在俱乐部场景里就是一只 U 盘，两种接法：

- **USB 有线**：手机直连播放器的 USB 口。切换有线前要先关掉手机 Wi-Fi，否则连接不生效。这条最稳，现场网络不可控时首选。
- **PRO DJ LINK 无线**：手机与播放器接同一台路由器，在应用里选 PRO DJ LINK 入口识别出播放器后无线取歌，还支持多台播放器共享。手机流量热点不适合这种接法（不在同一网段）。

两个容易踩的坑：XDJ-RR / RX3 / RX2 这类一体机没有无线，只能靠线连，出门前确认带了线和转接头；资料库里标题发灰的歌说明音频文件本体不在手机上，播放器读不出来，出发前务必逐张播放列表检查一遍。

## 四、连不上的排查顺序

1. **控制器没被识别**：确认型号在适配清单内；换一根数据线（很多线只能充电）；USB 不行先试蓝牙。
2. **连上但无法操作**：检查是否已登录账号，未登录时硬件功能不开放。
3. **播放器读不到手机**：换线与接口；把手机的 USB 模式设为文件传输；仍不行改走无线。
4. **无线搜不到设备**：确认手机与播放器在同一网段，路由器的 AP 隔离关掉。

安卓机型之间 USB 模式差异不小，个别机型线连播放器就是不通，遇到就别硬试，改走 PRO DJ LINK。功能与订阅的关系见[免费版和订阅怎么选.md](免费版和订阅怎么选.md)；更多玩法从[手机打碟从零上手.md](手机打碟从零上手.md)看起，[rekordbox 手机版介绍站](https://rekordbox.uerg.quest/)则汇总了全部内容与安装入口。
