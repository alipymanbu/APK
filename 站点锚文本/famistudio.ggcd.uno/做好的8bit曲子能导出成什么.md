# 做好的 8-bit 曲子能导出成什么：从 WAV 到 NES ROM

> 本篇讲 FamiStudio 的导出口径：写完的曲子能变成哪些格式、各自适合什么场合，以及跟 FamiTracker、MIDI 的往来关系。写曲的入门路径见 [在手机上写 NES 曲子，从五个通道开始](手机上写NES曲子怎么入门.md)，想折腾更多音色见 [NES 扩展音源芯片有哪些](NES扩展音源芯片有哪些.md)。

## 四个去向，按用途挑

FamiStudio 的导出不是随手列一排格式，而是照着 chiptune 社区的真实去向设计的。手机上做好的曲子，一般走这四条路：

### 1. WAV：直接当音频分享

最省事的一条路。导出成 WAV 后发到聊天群、社交通讯软件或视频平台都行——想让朋友按一下播放键就能听到，选它。

### 2. NSF：社区的单曲循环格式

NSF 是 NES 的音乐文件格式，chiptune 社区里有大量播放器支持它。发一首 NSF 到社区，懂行的人会用专门的播放器循环一整天。

### 3. ROM：在模拟器与真机上运行

导出成 ROM 之后，曲子就变成了一个能运行的 NES 程序：模拟器里直接打开，刷进实体卡带还能在真机上播放。给自己的曲子办一场「客厅音乐会」，靠的就是这条路。

### 4. Homebrew 音源：给自制游戏当配乐

把作品导出成 CA65、NESASM、ASM6 三种音源引擎代码之一，就能接进自制 NES 游戏的项目里当背景音乐。做 homebrew 游戏的玩家，多半是冲着这个功能来的。

## 与 FamiTracker、MIDI 的往来

- **从 FamiTracker 迁移**：支持导入 FamiTracker 的工程文件（FTM）与其文本格式，桌面端的老作品可以无缝接着写；
- **MIDI 双向进出**：MIDI 文件既能导入也能导出，手机版同样支持—— 和别的编曲工具接力时不必重抄一遍音符。

## 一点建议

导出之前先把曲子完整听一遍开头与结尾：导出的 WAV 会忠实记录播放结果，循环点没对齐，听感就会差一口气。对循环敏感的内容（比如当游戏 BGM 用的曲子），尤其值得多检查一遍。
