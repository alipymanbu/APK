# NES 扩展音源芯片有哪些：VRC6、VRC7、FDS 与更多

> 本篇讲 NES 的扩展音源芯片是怎么回事：为什么五个通道不够用、当年卡带里的芯片都做了什么，以及 FamiStudio 支持的七块扩展分别是什么来头。入门写曲的路径见 [在手机上写 NES 曲子，从五个通道开始](手机上写NES曲子怎么入门.md)，写完的去向见 [做好的 8-bit 曲子能导出成什么](做好的8bit曲子能导出成什么.md)。

## 五个通道为什么不够用

NES 主板自带的音频单元只有五个通道，功能强、但天花板也明显：音色方方正正，声部一多就捉襟见肘。当年游戏厂商的解法很直接——往卡带里再塞一块音源芯片，让游戏发出主板发不出的声音。这些「卡带里的芯片」就是扩展音源，不少经典系列的招牌音色都靠它们撑起来。

FamiStudio 把这套历史遗产完整继承了过来：项目设置里开启扩展后，编曲器的通道列表会随之加长，能用的音色也跟着变多。

## 七块扩展，各有来头

| 芯片 | 一句话来历 |
| --- | --- |
| VRC6 | 三路额外声部的卡带芯片，厚实的方波与锯齿波是它的招牌 |
| VRC7 | 内置调频音源，一开就是一股街机味 |
| FDS | 磁碟机系统的音源，能录音也能写出滑音丰富的音色 |
| MMC5 | 大容量卡带的控制芯片，顺带多给了两路矩形波 |
| Namco 163 | 用波形存储发声，可同时容纳多路自定义音色 |
| Sunsoft 5B | 某几款游戏卡带里的冷门芯片，音色别致 |
| EPSM | 社区扩展方案，调频音源加回减少量，通道数量级提升 |

不必一次全开。新手从默认的五通道开始，等某天觉得「这条低音想要更厚」「想要一个铜管味的音色」，再去设置里把对应的扩展打开——每块芯片都是当年某款卡带的答案。

## 在手机上怎么用

手机版与桌面版使用同一套项目格式：桌面端开了扩展的工程，传到手机上照常编辑；在手机上新建项目时，也可以按需开启扩展。通道多了之后，长按通道名就能静音或独奏，编曲器里照旧一列通道安排样式。
