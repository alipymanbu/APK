# 局域网设备扫描工具怎么选

> 想知道家里 Wi-Fi 上连着哪些设备：这类扫描工具看什么、怎么挑，以及 NetX 在这件小事上做对了什么。
> **相关文章**：[WiFi蹭网排查与陌生设备提醒.md](WiFi蹭网排查与陌生设备提醒.md) · [远程开机唤醒电脑设置清单.md](远程开机唤醒电脑设置清单.md)

## 一、先想清楚要解决什么问题

设备扫描类工具解决的是「可见性」：路由器后台虽然能看到已连设备清单，但翻进管理页太重，而且看不出哪台是谁。一个好用的扫描工具要做到三件事：

1. **扫得全**——同网段在线设备逐台列出来，别漏；
2. **认得出**——给出 IP、MAC、厂商之外，最好能问出设备自己广播的名字（苹果设备的 Bonjour 名、Windows 电脑的 NetBIOS 名）；
3. **留得下**——离线的设备保留历史记录，方便隔几天对比一次。

## 二、NetX 在这三件事上的做法

NetX（全名 NetX Network Tools，NetGEL 出品的安卓应用）把上面三条做成了日常动作：

- 打开应用即扫当前网络，下拉刷新就重新盘点，不用进出任何管理页；
- 列表里每台设备给出 IP、MAC 地址、按 MAC 前缀查出的厂商，再配合 Bonjour / NetBIOS 名字认人，哪台是 iPhone、哪台是 Windows 主机一眼可辨；
- 之前发现过的设备即使离线也留在列表里，做「这周多了什么、少了什么」的对比正合适。

再往深处走，它还带了 Ping、常用端口扫描、Wi-Fi 信道拥堵图这些诊断能力，扫描发现的目标可以直接变成探测对象，不需要复制粘贴 IP 到另一个应用里。

## 三、挑选时还有几条实际标准

- **权限要克制**：扫描只需要网络与附近设备权限，要通讯录、短信的一律警惕；
- **界面语言**：中文界面在读设备名、厂商时省力得多，NetX 支持 11 种语言（含简体中文）；
- **历史记录能导出**：能整份导出 CSV 的工具，才谈得上长期留档比对。
