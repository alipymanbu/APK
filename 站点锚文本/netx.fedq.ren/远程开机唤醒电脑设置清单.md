# 远程开机唤醒电脑设置清单

> 用手机把关机的台式机叫醒：Wake on LAN 的前提条件、常见失败原因、顺手把 SSH 关机也配好。
> **相关文章**：[局域网设备扫描工具怎么选.md](局域网设备扫描工具怎么选.md) · [WiFi蹭网排查与陌生设备提醒.md](WiFi蹭网排查与陌生设备提醒.md)

## 一、唤醒这件事的前提全在电脑侧

网络唤醒（WOL）的原理是往局域网里发一个「魔术包」，开着唤醒的网卡收到就替你按一次电源键。所以手机端只是发令枪，条件都落在目标电脑和网络两侧，逐条核对这份清单：

- [ ] 主板支持且 BIOS 里开了唤醒（找 `Wake on LAN` / `Power on By PCI` 之类的选项，在电源管理或高级设置里）；
- [ ] 系统里网卡属性 → 电源管理，勾选「允许此设备唤醒计算机」；Windows 网卡高级页把 `Wake on Magic Packet` 设为 Enabled；
- [ ] 机器处于关机或睡眠状态——彻底拔了电源的机器谁都叫不醒；
- [ ] 手机与它在同一局域网（跨网段、访客网络隔开都不行）。

## 二、最常见的两个翻车点

1. **Windows 快速启动**：默认开启时的「关机」其实是混合关机，网卡不进入可唤醒状态，魔术包发过去石沉大海。关掉路径：控制面板 → 电源选项 → 选择电源按钮的功能 → 更改当前不可用的设置 → 取消「启用快速启动」。
2. **主板 ErP 节能**：开着时关机会切断网卡供电，判断方法是关机后看网口指示灯——灯全灭说明网卡断电了，先回 BIOS 把 ErP 关掉。

一个好用的判据：改用「睡眠」再试一次。睡眠能唤醒、关机不能，问题基本就锁定在快速启动上。

## 三、手机端用什么发

安卓上配一个带 WOL 的网络工具即可，NetX 里扫到那台电脑（列表里能看到它），选中后选网络唤醒就能发包；它还顺带支持通过 SSH 让开着的电脑休眠或关机——前提是电脑上装好并启动了 SSH 服务端、防火墙放行了端口。

工具的功能与获取入口整理在 [NetX 网络工具介绍](https://netx.fedq.ren/)，装好后按上面清单把电脑侧配完，一次配好长期受用。

## 四、验证与兜底

- 配完先在同一局域网里试：电脑关机，手机连着家里 Wi-Fi 发一次唤醒——注意 WOL 包出不了本网段，跨网络唤醒需要在路由器上做转发，先在网内验证电脑侧没问题；
- 叫不醒时先看网口灯，再查 BIOS 与快速启动，最后查手机是否开着 VPN——VPN 会把魔术包引去别的出口；
- 个别网卡固件确实不吃唤醒包，更新驱动与 BIOS 后仍不行，就换「睡眠 + 唤醒」的组合替代。
