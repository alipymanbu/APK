# Shizuku 启动与授权的完整流程

> 本篇讲 Shizuku 的三种启动方式（无线调试配对、电脑 adb、Root）、怎么把权限授给需要它的应用，以及启动失败时最高频的几条原因。以 Nrfr 这类依赖 Shizuku 取得系统权限的免 Root 工具为使用背景。
> **相关文章**：[双卡手机分别修改国家码的方法](双卡手机分别修改国家码的方法.md) · [修改国家码后没生效的排查思路](修改国家码后没生效的排查思路.md)

---

很多人装好 Nrfr 之后打开就提示「需要 Shizuku 权限」甚至闪退，问题不在安装包，而在 Shizuku 这个前置环节没走通。Shizuku 是一个独立的权限管理工具，它借助安卓的调试机制把一部分系统级权限临时交给普通应用使用——Shizuku 没跑起来，依赖它的工具就什么也做不了。

## 一、先分清：启动、授权是两件事

顺序固定为：**先启动 Shizuku → 再给应用授权 → 然后才轮到应用里干活**。启动是把 Shizuku 服务跑起来；授权是让 Nrfr 这类应用进入 Shizuku 的许可名单。两步缺一不可，卡在哪一步，表现也不一样。

## 二、启动方式一：无线调试配对（Android 11 及以上）

1. 进入设置 → 关于手机，连续点击「版本号」多次打开开发者选项。
2. 在开发者选项里打开「无线调试」，**保持这一页不退出**。
3. 打开 Shizuku 应用，点「配对」→「使用配对码配对设备」，系统跳到无线调试页面后再点一次「使用配对码配对设备」，会出现 6 位配对码。
4. 通知栏弹出「输入配对码」通知，把 6 位码填进去；没看到通知就把 Shizuku 切回前台。
5. 配对成功后回 Shizuku 首页点「启动」，状态变成「正在运行」即完成。

两条硬规则：**配对只需做一次，但每次重启手机后都要重新点一次启动**；点启动没反应时，先把无线调试关掉再打开重试。

## 三、启动方式二：电脑 adb（Android 10 及以下 / 无 Root 低版本）

1. 电脑上下载 Google 的 SDK Platform Tools，解压到任意文件夹。
2. 手机打开 USB 调试，数据线连接，弹出的调试授权选允许。
3. 在解压目录开终端，执行 Shizuku 应用内「通过连接电脑启动」页面显示的那条命令（PowerShell 下命令里的 `adb` 要写成 `./adb`）。
4. 命令跑完，Shizuku 显示正在运行即可。

## 四、启动方式三：Root 直接启动

已解锁 Root 的设备在 Shizuku 里直接以 Root 启动，一步完成。不过多数想免 Root 改卡地区的用户走的是前两条路。

## 五、把权限授给 Nrfr

1. Shizuku 显示「正在运行」时打开 Nrfr，通常会直接弹出授权窗，点允许。
2. 没弹窗的话，打开 Shizuku 首页的应用列表，找到 Nrfr 打开授权开关。
3. 有一种界面小毛病：勾选授权后 Shizuku 仍显示「已授权 0 个应用」——把 Shizuku 从后台划掉重新打开就会正常显示，授权状态本身没丢。

工具的界面预览与获取入口可以参考 [Nrfr 介绍站](https://nrfr.xnyx.quest/)，授权完成后就能进应用里做实际修改了。

## 六、启动失败的高频原因速查

- **重启后 Shizuku 停了**：正常现象，重新点一次启动即可，配对不用重做。
- **配对码输不进去、一直搜索配对服务**：多与通知样式、后台限制有关——MIUI 等系统要把 Shizuku 的通知设为重要、并允许后台运行。
- **授权窗一闪而过或无响应**：确认 Shizuku 首页确实是「正在运行」，服务没起来时授权弹窗不会出现。
- **adb 连不上设备**：核对数据线是否支持数据传输、驱动是否装好、手机上的调试授权是否点了允许。

启动与授权都走通之后，应用内的修改操作本身反而是最简单的部分，具体步骤见 [双卡手机分别修改国家码的方法](双卡手机分别修改国家码的方法.md)。
