# LunaTalk 站点目录

AI 角色扮演应用 LunaTalk 的第三方资料页：角色广场用聊天数与粉丝数给角色排名、创作者有作者排行榜，自建角色可发布进广场被人玩，底层由多模型驱动。[LunaTalk 角色扮演介绍站](https://lunatalk.wxhp.skin/)整理了广场实拍、角色创作要点与积分规则。
