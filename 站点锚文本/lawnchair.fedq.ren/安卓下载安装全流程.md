# Lawnchair 安卓下载安装全流程

> 本篇讲把 Lawnchair 装进安卓手机的完整路径：三条渠道怎么挑、侧载安装时怎么逐项放行系统拦截、装完怎么设为默认桌面，以及装不上时先查哪里。
> **相关文档**：[安卓桌面启动器是什么来头.md](安卓桌面启动器是什么来头.md) · [和NovaLauncher哪个好.md](和NovaLauncher哪个好.md)

---

## 一、先挑渠道，再动手

Lawnchair 有三条获取渠道，包名彼此不同、可以并存：

| 渠道 | 更新方式 | 适合谁 |
| --- | --- | --- |
| GitHub 发布版 | 项目定期发布，手动覆盖安装 | 求稳的大多数人 |
| Nightly 每日构建 | 跟随代码自动构建，应用内自带更新器 | 想第一时间拿修复的尝鲜党 |
| Play 商店版 | 商店自动更新，上架晚一至两周 | 只习惯商店管理应用的人 |

求稳从 GitHub 发布版或 Play 商店版起步；Nightly 修得快但偶尔带新问题。多数教程与评测也是按这个口径建议的。

## 二、侧载安装五步

以侧载 Nightly 构建为例（GitHub 发布版流程完全相同）：

1. **拿到安装包**：从网盘分享页转存到自己的账户，再下载 APK 到手机「下载」目录；
2. **允许「安装未知应用」**：设置 → 应用 → 特殊访问权限 → 安装未知应用，给接下来用来打开 APK 的文件管理器（或浏览器）授予权限——授权对象是"打开安装包的应用"，不是全局开关；
3. **放行 Play Protect**：安装时弹出警告就点「仍然安装」；没有这个选项时，到 Play 商店 → Play Protect → 设置齿轮，临时关闭应用扫描，装完再打开；
4. **完成安装并设为默认桌面**：设置 → 应用 → 默认应用 → 主屏幕应用，选中 Lawnchair——装完不设默认，桌面不会有任何变化；
5. **Android 13 及以上解锁「受限设置」**：侧载应用默认拿不到无障碍等敏感权限，先开一个会触发拦截的开关让「受限设置」提示弹出，再从 主屏幕设置 → 右上角 ⋮ → 应用信息 → ⋮ → 允许受限设置。

## 三、装不上先查这三处

- **提示「应用未安装」**：旧版本没卸干净或安装包不完整——低版本覆盖高版本必然失败，先卸载再装、安装包删了重下；
- **桌面没变化**：安装不等于启用，回第二节第 4 步把默认桌面切过去；
- **改设置不生效**：主屏幕设置 → 右上角 ⋮ → 重启 Lawnchair，这个动作不动布局与设置。
