# 电视搜不到投屏设备的排查思路

> 本篇讲投屏应用里设备列表一直空着怎么办——这是投屏场景里命中率最高的故障。按出现概率从高到低排查，多数情况在前几条就能解决。
> **相关文档**：[手机投屏电视的操作步骤与条件](手机投屏电视的操作步骤与条件.md) · [Chromecast 电视棒与手机的日常搭配玩法](Chromecast电视棒与手机的日常搭配玩法.md)

## 一、先花一分钟做快查

别急着进路由器后台，先把这六条过一遍：

1. 手机和设备连的是**同一个 Wi-Fi 名字**（留意双频路由器拆成两个名字的情况）；
2. **VPN 和代理关掉**——它们会把局域网发现广播拦掉；
3. 从系统设置里**强行停止**投屏应用，再重新打开；
4. 给 Chromecast 设备**断电十秒再通电**；
5. 设备列表里**下拉刷新**一次；
6. 确认电视**停在设备所在的 HDMI 输入源**上，能看到待机画面。

## 二、按概率排列的原因

| 命中概率 | 原因 | 处理办法 |
| --- | --- | --- |
| 高 | 手机与设备不在同一个 SSID | 让手机连到设备所在的那个 Wi-Fi，名字必须逐字一致 |
| 高 | 双频路由器拆成两个名字 | 手机和设备连到同一个名字下，或在路由器后台合并双频 |
| 中 | 路由器开了 AP 隔离 | 能上网但互相发现不了是典型特征；进路由器后台关掉「AP 隔离 / Client Isolation」 |
| 中 | 手机的定位或「附近设备」权限没给 | 系统设置 → 应用 → 对应投屏应用 → 权限，补上并允许「仅在使用中」 |
| 低 | 手机系统时间不准 | 开「自动获取时间」后重启手机，时间差超过约十分钟会导致握手失败 |
| 低 | 设备固件太旧或状态卡死 | 断电重启；仍异常就给设备重新配网、检查固件更新 |

权限那一行多说一句：安卓 13 起，这类 Wi-Fi 发现用的权限从「定位」改叫「附近设备」，名字不同、作用一样，看到哪个就允许哪个。

## 三、设备端值得检查的几件事

手机侧查完仍不行，回头看设备：

- **供电用原装电源插墙插**。插电视 USB 口虽然能亮，但电视一关机设备跟着断电，时好时坏最难查；
- **看指示灯**。常亮是正常待机，闪烁多为启动中或没连上网，完全不亮查供电；
- **信号差就挪位置**。设备躲在电视背后信号会被挡，用附送的 HDMI 延长线把设备挪出来能明显改善；
- **重置是最后一步**。长按设备上的重置键约十秒恢复出厂，之后要重新走一遍配网。

## 四、换个判据交叉验证

换了手机、换了网络设备仍然谁都搜不到，可以用别的投屏应用搜同一台设备做对照：别的应用也搜不到，问题多半在网络或设备本身；只有投屏应用搜不到，再回头重点核对权限那两行。
