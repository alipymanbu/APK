# ChromeCast 站点目录

这里收录围绕 ChromeCast 投屏应用整理的介绍与上手文章。ChromeCast 是装在安卓手机上的第三方投屏与遥控工具，能把手机里的本地视频、照片、音乐推送到通过 Chromecast 连接的电视，也支持整屏镜像和虚拟遥控器。

- 应用功能、界面与安装文件资源入口，见 [ChromeCast 投屏介绍站](https://chromecast.bmww.store/)。
