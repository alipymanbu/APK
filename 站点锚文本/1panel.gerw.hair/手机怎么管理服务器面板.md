# 手机怎么管理服务器面板

> 本篇讲在手机上管理 1Panel 面板的完整路径：手机端能做哪些事、连不连得上取决于什么。
> **相关文档**：[专业版和社区版区别.md](专业版和社区版区别.md)

---

## 先想清楚：手机管的是「面板」，不是服务器本身

很多读者搜「1panel 手机管理」，其实是两个需求混在一起：一是想在手机上**看一眼**服务器的状态，二是想**处理**一些不复杂的运维动作。1Panel 的做法不是把整套 Web 面板塞进手机浏览器，而是提供了一个专门的手机客户端——1Panel App，安卓和 iOS 都有。

也就是说，手机端的角色是「遥控器」：它把面板里最常回头看的部分搬了过来，包括：

- 多台服务器一屏概览：每台主机的 CPU、内存、负载、网络各占一个圆环，状态好坏扫一眼就有数；
- 应用管理：面板应用商店里装的应用（网站程序、数据库、缓存等），版本、运行状态、启停操作都能在手机上做；
- Docker 容器：暂停、重启、新建，以及占用与日志的实时查看；
- 网站安全：WAF 防火墙的请求数、拦截数与近 7 日趋势。

改变服务器配置、部署面板这类「重活」仍然回到电脑上的 Web 端做更稳妥。

## 三个前提，缺一个都连不上

装好 App 只是拿到了遥控器。能不能真正管起来，看这三件事：

1. **服务器上已经装好 1Panel 面板**。App 自己不带面板功能，服务器上什么都没装的话，它无事可做；
2. **面板激活了专业版许可**。移动端 App 是专业版独占内容，社区版面板无法被 App 接入——这是「装完连不上」最常见的原因，版本差异在[专业版和社区版区别](专业版和社区版区别.md)一篇里有对照；
3. **面板开启了 API 接口**。App 通过面板的 API 连接，凭密钥加时间戳令牌认证，手机上不需要输入服务器密码。开启入口在面板的设置里。

三样都齐了，在 App 里扫码或填入连接信息即可添加服务器，支持同时管理多台。

## 安卓安装包从哪里拿

各应用商店（小米、华为、vivo、Google Play）搜「1Panel」可以直装；如果手上的机型用商店不方便，也可以从 [1Panel App 手机客户端](https://1panel.gerw.hair/)的介绍站进入获取安装文件资源，转存到自己的网盘后下载安装，安装时留意允许「未知来源应用」。具体步骤在该站的下载页有逐步说明。
