# 手机自动备份怎么开：条件、范围与恢复时机

> 「开了备份」不等于「备份在跑」。本篇把设备备份的覆盖范围、三个触发条件、最常见的失败原因和换机恢复的正确姿势一次说清。

## 一、它备份什么、不备份什么

设备备份是**安卓系统级**的那条线，和相册备份相互独立：

| 内容 | 归谁管 |
| --- | --- |
| 联系人、短信/彩信、通话记录 | 设备备份 |
| 应用及应用数据（仅限支持备份的应用） | 设备备份 |
| Wi-Fi、显示、语言等设备设置 | 设备备份 |
| 照片、视频 | 相册自己的开关，独立走 |

应用本地目录里的私有文件、退出了备份的应用数据，不在覆盖范围内。别把所有希望压在一条线上，重要的东西两条开关都打开。

## 二、三个条件缺一不可

自动备份只在**连着 Wi-Fi、正在充电、屏幕闲置**同时满足时触发。最常见的「怎么一直没备份上」，就是插着电刷手机——人在用，它就不动。

想立刻跑一次：应用里手动点「立即备份」，然后连上 Wi-Fi、插电、锁屏放着。

## 三、总失败按这个顺序查

按命中率高到低：

1. 当时没连 Wi-Fi、没充电或正在用手机；
2. 登录的账号不是做备份那个（系统「设置 → 账号」里核对）；
3. 账号额度满了——备份同样占空间，满了传不上去，先清理或扩容；
4. 应用里的备份开关根本没开，或手机系统层的备份总开关关着。

## 四、换新手机怎么恢复

恢复**只能在开机初始设置向导里做**，进了桌面就找不到入口了。大方向：新机连 Wi-Fi 走向导，到「复制应用和数据」选「从云端恢复」，登录**做备份时用的那个** Google 账号，选最近一次备份勾选恢复。

两个前提记牢：新机系统版本不能比备份时更老；恢复期间 Wi-Fi 别断。照片不走这条链路，它们随相册账号自动回来。

旧机还在手边的话，开新机前先在旧机上手动点一次「立即备份」，能保证恢复到最新一份。
