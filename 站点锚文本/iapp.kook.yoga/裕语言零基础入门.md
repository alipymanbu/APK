# 裕语言零基础入门：在手机上写下第一段代码

裕语言是 iApp 内置的脚本语言，也是这个工具的核心。它设计得很口语化：赋值用 `s`，输出用 `syso()`，判断和循环的写法都短。对第一次碰编程的人来说，门槛比想象中低。

## 从几个小片段开始

赋值和输出：

```
s a = 1
syso(a)
```

判断：

```
s a = 1
if a == 2 {
  syso("结果为二")
}, else {
  syso("结果为一")
}
```

循环：

```
for s b = 1, b < 5, b++ {
  syso(b)
}
```

这几段就是编辑器示例里的常见句式。在 iApp 里新建项目，把代码敲进去，点运行，日志悬浮窗会立刻把结果显示出来——反馈快，是入门阶段最重要的体验。

## 版本线怎么选

新建项目时会遇到 V3、V5、V7 这些版本线，它们决定指令集和打包能力。刚入门不必纠结：跟着教程走，教程用哪条线就选哪条线；多数新教程已经在用 V5 或 V7。

## 学习路径建议

1. 先把界面拖拽玩熟，找到“我改的东西马上能看见”的感觉；
2. 再把上面几个语法片段各写一遍，体会变量、判断、循环；
3. 然后拆项目列表里的现成示例，看别人怎么组织界面和逻辑；
4. 最后回到自己的点子，做一个只给自己用的小工具。

工具从安装到写出第一段代码大概一个下午就够。还没有安装包的话，可以从这个介绍站进去按步骤来：[iApp 掌上开发工具](https://iapp.kook.yoga/)。

语法遇到拼不准的指令，编辑器的语法高亮会当场变色提醒，配合日志输出排查，大部分问题自己就能解决。想了解这个工具整体是怎么回事，可以翻翻[这里整理的软件定位说明](iApp是什么软件.md)。
