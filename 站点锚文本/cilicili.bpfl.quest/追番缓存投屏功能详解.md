# 追番缓存投屏功能详解

> 本篇盘点 cilicili 的日常用法：四大片库栏目怎么分工、离线缓存怎么下、投屏为什么搜不到电视，以及画质弹幕倍速这几个播放开关的实际取舍。

## 一、片库的分工：推荐流与分类筛选是两条路

首页顶部按来源分栏目：**推荐、日本动漫、国产动漫、欧美动漫**，剧场版另有陈列位。两条找番路线各有分工：

- **推荐流**是热度口径，更新快、题材跨度大，适合随便看看；
- **分类筛选**是检索口径，能按类型（热血、恋爱、悬疑、日常等）、地区、年代叠加条件——补老番走这条快得多，同一部作品在推荐流里可能早就沉下去了。

搜索框在首页头部，部分版本收进底部频道页最上方；只记得关键词片段可以直接输片段，结果按名称匹配。搜不到时先换简繁或中英文写法再试一次，确认是片库没有而不是词写错。

## 二、离线缓存：通勤与飞行模式的主力

缓存入口在剧集详情页或播放页的下载图标，勾选集数后开始，进度统一在「我的」→ 下载管理里看。几个实操建议：

- **在 WiFi 下缓存**，一集高清剧集的体积按清晰度浮动，流量下容易超量；
- **先用一集试水**，不同清晰度体积差别不小，心里有数再决定整季要不要下；
- **别边看边下整季**，缓存与在线播放同时抢带宽，两头都不讨好。

缓存完成后的播放不再依赖网络，地铁隧道里照常能看。要注意缓存文件存在应用专属目录里，**卸载或「清除数据」会连同删掉**——看完的整季去下载管理里清掉，是控制占用的最好习惯。

## 三、投屏：前提只有同一台路由器

投屏走局域网，手机和电视必须连在**同一台路由器下的同一网段**。操作是播放页右上角的投屏按钮，应用会自动搜出设备，选中后画面即转到电视，手机接着当遥控器用（换集、切画质都在手机上）。

搜不到设备时的三个低成本动作：

1. 确认电视开机且联网——待机状态搜不到；
2. 确认手机没连访客网络——访客网络与主网络之间通常隔离，一定失败；
3. 完全退出应用重开，重新进播放页点一次投屏。

投出去之后很卡，先降画质：投屏把视频流推给电视，链路压力比本地播放大，画质从超清降到高清多数卡顿立刻缓解；弹幕也会一起投上大屏，客厅观看建议提前关掉。

## 四、播放开关的取舍

| 开关 | 建议 |
| --- | --- |
| 画质 | 默认跟随网络；流量紧张手切标清更省，投屏时切太高反而容易卡 |
| 弹幕 | 默认开启；看剧情、投大屏时关掉 |
| 倍速 | 补番用 1.25~1.5 倍，2 倍以上人声明显变形 |
| 播放源 | 藏在片名后面；画面出不来、缓存一直失败时先换它 |

进度是按作品分开记的，退出播放页不用记集数，下次从详情页进来接着上次的位置继续；观看历史在「我的」里，找回前几天随手点开的那部比回忆名字快得多。

## 五、游客与登录的边界

打开就能浏览和播放，登录只多两样东西：**收藏列表跟着账号走**（换手机还在）、**更新提醒**推送到位。追季番的话把收藏和提醒都点上，「追更」和「随便看看」的分界就在这一步。
