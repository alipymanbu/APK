# 安卓追番工具怎么装到手机

> 本篇讲 cilicili 这类安卓追番应用从拿到安装包到正常打开的完整流程：装之前核对什么、未知来源开关在哪里、装不上的提示怎么对号入座。
> **相关文档**：[追番缓存投屏功能详解](追番缓存投屏功能详解.md)

---

## 一、装之前，先确认手里的是哪一份

同一个名字在网上能搜到好几个安装包，包名、体积、界面细节可能都不同，装错版本最常见的后果是旧数据读不出来，或者桌面上出现两个图标。动手之前留意两点：

- **看版本与体积**：不同构建的体积差别明显，下载完成后如果文件体积与页面标注对不上，多半是下载被截断或版本不一致；
- **看适配系统**：老旧机型装过新的安装包会提示系统版本过低，这属于正常拒绝，不必反复重试。

如果手机里已经装过另一个包名的同名应用，新装的一份会**并排共存**而不是覆盖更新——这是包名不同导致的正常现象，决定留哪个之后把另一个卸掉即可。

## 二、安装流程，四步走完

1. **把安装包存到手机**。通过网盘分享页转存并下载，安装包通常落在夸克的下载目录里；想用系统文件管理器安装的话，先把它挪到 `Download` 这类好找的目录。
2. **允许安装未知来源应用**。这个开关藏在设置的应用管理里：找到用来点安装包的那个应用（文件管理器 / 夸克 / 浏览器），在「安装未知应用」里放行。不同品牌叫法略有差别——华为是「外部来源应用下载」，小米是「安装未知应用」，OPPO、vivo 在「特殊应用权限」下。
3. **点击安装包完成安装**。系统先解析再写入，体积不大时十秒内结束；被安全中心拦截时在弹窗里选择「继续安装」。
4. **首次打开**。这一类追番应用通常打开即用，不注册也能浏览和播放；追更提醒需要通知权限，首次打开时顺手允许即可。

## 三、装不上的几种提示与处理

| 提示 | 常见原因 | 处理 |
| --- | --- | --- |
| 解析包时出现问题 / 安装包损坏 | 下载没下完、取回时被截断 | 重新下载一遍，装前核对体积 |
| 应用未安装 / 签名不一致 | 装过同名但签名不同的版本 | 先卸载旧版再装；本地缓存会一并删除 |
| 存储空间不足 | 剩余空间小于安装包体积的 2~3 倍 | 清理后重试，安装与解压都要临时空间 |
| 安装被安全中心拦截 | 未知来源被当成风险行为 | 弹窗里选「继续安装」或临时关闭扫描 |
| 系统版本过低 | 系统低于安装包标注的适配线 | 换支持的设备，别硬装低版本口径的包 |

安装环节过了一遍还不顺，多半不是流程问题而是版本问题——换回核通过的同一份安装包，比反复换安装姿势有效。

## 四、装好之后先做三件事

1. **给通知权限**，收藏的番剧更新提醒依赖它；
2. **确认缓存习惯**，离线缓存随集数与清晰度涨体积，起步留 1~2 GB 比较稳；
3. **试一次投屏**，电视侧开关与路由器设置都会影响结果，提前试一次，追到一半才发现投不出去最扫兴。
