# ColaManga 漫画阅读工具介绍

ColaManga（读者圈里常叫"可乐漫画"）是一款运行在安卓手机与平板上的漫画阅读工具，书库覆盖日漫、韩漫、国漫与欧美作品。它把找书拆成了题材筛选、连载状态、字母索引三道闸门，配上拼音模糊搜索和热门搜索榜；阅读端则提供九种主题换肤、夜间护眼模式与三种翻页方式，支持单次最多批量下载 100 话离线阅读。

想按顺序了解从筛书、搜书、追更到夜读的完整体验，可以看这篇整理：[ColaManga 漫画阅读工具实际体验](漫画阅读体验.md)。
