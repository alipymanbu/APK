# mcpedl 模组地图与皮肤怎么下载导入

> 本篇讲装好 mcpedl 之后怎么用：五类内容各是什么文件、在应用里怎么下载、怎么导进 Minecraft 基岩版并在世界里激活，以及导入报错的对号处理。
> **相关文档**：[安卓版下载与安装入口.md](安卓版下载与安装入口.md)

---

## 一、五类内容与文件后缀

| 类型 | 改变什么 | 常见后缀 |
| --- | --- | --- |
| 模组 / 附加包 | 新生物、新物品、新机制 | `.mcaddon` |
| 材质包 | 方块与物品贴图外观 | `.mcpack` |
| 光影 | 光照、阴影、水面效果 | `.mcpack` |
| 地图 / 世界 | 整张世界存档：跑酷、生存、解谜 | `.mcworld` |
| 皮肤包 | 角色外观 | `.mcpack` |

这些后缀只用于基岩版（手机版 / Win10 版）。挑内容时先看详情页标注的「适用版本」——包要求的游戏版本高于手机上的 Minecraft 时，导入后可能不生效。

还没装应用的，先看[安卓版下载与安装入口.md](安卓版下载与安装入口.md)，把 mcpedl 和 Minecraft 基岩版都装到同一部手机上再回来。

## 二、在应用里下载内容

1. 按门类浏览或用搜索框找内容，点开详情页看说明、评分与适用版本；
2. 点下载按钮，等进度走完；
3. 下载完成的条目集中在应用的下载页，后续导入从这里点。

连续下载多个内容时下载按钮偶有卡住的情况，重启应用可缓解；一个条目下完再点下一个更稳。

## 三、导入 Minecraft 并激活

**导入**：在下载页点已完成条目，系统弹出「选择打开方式」时点 Minecraft，游戏拉起后自动导入，屏幕上方出现 `Import started...`，完成提示 `Successfully imported`——此时文件进了游戏，但**还没生效**。

**按类型激活**：

- 附加包：编辑世界 → 「行为包」「资源包」→「可用」→ 激活（两边都要开，只开一边功能会缺；部分包还要求开「实验性玩法」）；
- 地图：导入完直接出现在世界列表；
- 皮肤：主界面「更衣室」→「经典皮肤」；
- 材质 / 光影：单个世界在世界设置里激活；想全局生效，去「设置 → 全局资源」。

## 四、导入报错对号处理

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `Duplicate Pack Detected` | 同一包已导入过，新旧冲突 | 游戏「设置 → 存储」删掉旧版再导 |
| `Failed to import` | 常见是包缺清单文件 | 重启游戏再导一次，仍失败找内容作者 |
| `Not a Valid Zip Archive` | 下载损坏或打包不规范 | 重新下载；还不行改手动解压 |

导入显示成功但游戏里没效果的，按命中率排查：没在世界里激活 → 附加包只开了一边 → 没开实验玩法 → 激活的是另一个世界 → 游戏版本不满足包要求。

## 五、成就提醒

开过模组、实验玩法或作弊的世界无法解锁成就——这是基岩版的游戏规则，与应用无关。想一边玩模组一边刷成就，留一个干净的原版生存世界分开用；装模组前先在世界编辑菜单里「复制」一份，也是一份保险备份。

mcpedl 的完整功能介绍、界面截图与安装包入口，都在 [mcpedl 内容库介绍站](https://mcpedl.wrwq.fun/)；还没装应用的，从[安卓版下载与安装入口.md](安卓版下载与安装入口.md)开始。
