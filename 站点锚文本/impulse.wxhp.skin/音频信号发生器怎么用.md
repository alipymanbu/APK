# 音频信号发生器怎么用

手机上的音频信号发生器把「指定频率发声」这件事做到了两步操作：输一个数，点开始。这类工具里 Impulse 的界面最干净——深色底、绿色按钮，全部功能就三个标签，五分钟就能上手。下面按它的实际界面逐项说明。

## 一、Generation：定频率、开始发声

打开应用默认就在这个标签，从上到下四样东西：

1. **Frequency 输入框**：直接敲频率数字，单位 Hz，默认 440（标准音 A4）。要精确就手输，要快速试就拖下面的滑杆；
2. **滑杆**：粗调定位，细值再回输入框微调；
3. **To frequency 开关**：勾上会多出一个终点频率栏。设好起止两点再点 Start，输出就在两点之间连续滑动（扫频），适合一次听完整段频响；
4. **Start 按钮**：点下即发声，按钮下方实时显示当前频率，再点一次停止。

发声后没声音，先查媒体音量——纯音不响多半是音量被单独调到了零，或者插着耳机让信号走了耳机口。

## 二、Presets：不用记数字的一键按钮

第二个标签里排着三组现成频率，点任意按钮立刻发声：

| 分组 | 频率 |
| --- | --- |
| Anti Mosquito（驱蚊） | 12 / 14 / 16 / 20 kHz |
| 猫狗哨 | 7 / 10 / 15 / 19 kHz |
| 用户预设 | 440 / 1000 / 2000 / 3000 Hz |

用户预设一行右侧的小图标可以把常用频率存成按钮。驱蚊与哨音的实际效果和分寸，说法不少，用之前值得把两边说法都看一遍再决定开不开。

## 三、Options：只有两项的设置页

右上角三个点进入，页面上就两行：

- **Enable sound in sleep mode**：勾上后锁屏、息屏发声不中断。排水、扫频这类要跑一两个小时的场景全靠它，建议常开；
- **Sample rate**：采样率，默认 44100 Hz（CD 口径），没有明确理由不用改。

## 四、一个上手建议

第一次用，不妨从 440 Hz 起步：先确认双声道都有声，再用一次 20 Hz → 20000 Hz 的完整扫频听一遍自己的耳机——哪一段突然变小、哪里有杂音，一听便知。想接着玩更具体的场景，可以看[扬声器排水频率多少合适](扬声器排水频率多少合适.md)和[高频听力自测方法](高频听力自测方法.md)。
