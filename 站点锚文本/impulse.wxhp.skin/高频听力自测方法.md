# 高频听力自测方法

人耳理论上的可闻范围是 20 Hz 到 20 kHz，但高频端会随年龄增长逐渐收窄——同是成年人，能听到的上限差别很大。想知道自己的耳朵还能听见多高，一部手机加一个信号发生器应用就能粗测：从 1 kHz 起步逐档升高，记下「刚好听不见」的位置。这篇讲完整流程与结果解读。

## 一、测试前的准备

- 找一间安静房间，戴耳机（外放的高频衰减快、干扰多）；
- 媒体音量调到**中等**——纯音和音乐不同，同一频率会持续轰炸耳朵，先小后加；
- 手机装好能精确设频率的应用，比如 [Impulse](https://impulse.wxhp.skin/) 这类音频信号发生器，操作见[音频信号发生器怎么用](音频信号发生器怎么用.md)。

顺带记一个耳机圈常引用的「60-60 原则」：音量不超过设备最大音量的六成，连续收听不超过一小时。

## 二、测试流程

1. 先放 **1 kHz**，确认自己听得很清楚（这是中频基准）；
2. 逐档升高：5k → 10k → 12k → 15k → 17k → 19k，每档停留几秒；
3. 记下**刚好听不见**的档位；
4. 高频听不到先别下结论，换一副耳机再试——很多手机和耳机的扬声器在 15 kHz 左右就没有输出了，那是设备的上限，不是你的耳朵。

朋友之间也常拿这个当谈资：15 kHz 以上的「蚊子音」年轻人听得见、年纪大的人听不见。反过来提醒一句——你放驱蚊音、哨音时自己没感觉，不代表旁边的年轻同事或家里的猫狗没被吵到。

## 三、结果怎么解读

- **自测不是体检**：这套流程只给粗略印象。真的怀疑听力下降，去做正规纯音测听；
- **高频变差不等于听不清说话**：日常对话的声能集中在 500~3000 Hz，即使高频上限已掉到 12~15 kHz，聊天照样没问题。高频听力往往先于言语听力受损，自测出上限偏低，把它当作去做正规检查的提醒即可；
- **某频段破音**：先降音量再听——小音量不破是大音量失真，小音量也破才是单元问题；
- **低频忽大忽小**：小房间里常是驻波作怪，换个位置强弱就变，属环境问题。

## 四、再进一步

测完听力，同一套扫频还能反过来看设备：逐点听 60/100 Hz 的低频下限、5 kHz 的毛刺、10~18 kHz 的延伸，给耳机音箱做一次频响体检，具体听查点参考[扬声器排水频率多少合适](扬声器排水频率多少合适.md)里对低频排水的说明。应用获取入口见 [Impulse 介绍站](https://impulse.wxhp.skin/)。
