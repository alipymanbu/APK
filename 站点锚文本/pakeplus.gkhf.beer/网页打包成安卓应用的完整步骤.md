# 网页打包成安卓应用的完整步骤

本篇把「一个网址 → 一个安卓安装包」的全过程拆成可照抄的步骤，覆盖打包前的准备工作、界面上的五步操作，以及打包完成后的安装方式。相关内容可先看 [安卓版下载与安装方法](安卓版下载与安装方法.md) 与 [GitHubToken获取与权限配置](GitHubToken获取与权限配置.md)。

---

## 打包前要准备什么

只需要两样东西：一个能正常访问的网页地址（或一份 Vue / React 项目编译后的 dist 静态文件），以及一个 GitHub 账号生成的访问令牌。令牌的生成与勾权步骤在 [GitHubToken获取与权限配置](GitHubToken获取与权限配置.md) 里有逐项说明，这里不展开。

打包工具本身推荐用手机版：安装包只有 2.5M 上下，安卓 5.2 以上的手机都能装，获取入口见 [安卓版下载与安装方法](安卓版下载与安装方法.md)。

## 五步打出安装包

1. **新建项目**：打开工具后新建项目，项目名要求用英文；填入要打包的网页地址、应用名称（支持中文）和一张正方形图标。图标最好提前做成 PNG 正方形再上传，避免裁剪后不理想。
2. **配置窗口**：按需调整窗口大小等细节。想给页面注入自己的脚本（去广告、自动签到之类）也在这一步写好。
3. **预览**：点预览会弹出窗口展示最终效果，能正常打开、布局没有错位，就可以进入下一步。
4. **发布编译**：点发布后交给云端编译，一般 15 分钟左右完成；期间可以关掉窗口去干别的。本地打包则约 30 秒出包，适合反复调整的场合。
5. **下载安装包**：编译完成后进入资源页，下载安卓对应的安装包，按 [安卓版下载与安装方法](安卓版下载与安装方法.md) 装进手机即可。

## 打包出来的应用长什么样

产物不是浏览器收藏夹那种快捷方式，而是一个独立应用：全屏运行、有自己的图标和名称，顶部是系统状态栏，没有地址栏和标签页。体积走 Rust 技术路线，5M 上下，比传统 Electron 方案小约 20 倍。

想先看整体介绍再动手，可以从 [PakePlus 安卓版介绍站](https://pakeplus.gkhf.beer/) 的效果示例与流程图入手，对照着操作更不容易漏步骤。

## 几个容易踩的点

- 网址要带完整的 `https://` 前缀，格式不完整会导致应用窗口加载不出内容；
- 云端编译依赖令牌权限，权限没勾全会卡在发布环节，回 [GitHubToken获取与权限配置](GitHubToken获取与权限配置.md) 逐项核对；
- 修改配置后要重新发布才会生效，预览只是本机模拟。
