# 安卓玩galgame的多引擎模拟器

> 本篇讲在安卓手机上玩 KRKR、Artemis 系视觉小说为什么会卡在「引擎」这一步，以及 Tyranor 这类多引擎模拟器是怎么把这件事简化成一个安装包的。

## 为什么手机打不开这些游戏

日式 AVG 和 Galgame 大多不是「一个视频文件」或「一个普通 App」，而是建立在特定引擎上的程序：吉里吉里（KRKR）作品的核心是 `data.xp3` 一类数据包，Artemis 作品是 `root.pfs`，网页技术系的 Tyrano 则是 `index.html` 加资源目录。安卓系统本身不认识这些格式，普通播放器也读不了，于是「把游戏搬进手机」和「在手机上玩到」之间，隔着一个引擎运行环境。

## 多引擎模拟器的思路

早期在手机上跑这类游戏，往往一款引擎配一个播放器：玩 KRKR 装吉里吉里播放器，玩 ONS 装 ONScripter 系。游戏库一杂，手机里就得维护一堆播放器。

Tyranor 走的是另一条路：把多套引擎环境收进一个 APK。按其 2.3.4 版的资料，它覆盖吉里吉里 KRKR / KR2、Artemis Engine、RPG Maker（含 MZ）、Tyrano、VN Maker，并在这一版正式加入了 ONScripter，支持扫描 SD 卡内的 ONS 游戏。判断手上的游戏归哪类引擎，最直接的办法是打开游戏文件夹看标志文件——`data.xp3` 对 KRKR、`root.pfs` 对 Artemis、`nscript.dat` 对 ONS，一类都对不上，大概率是这个模拟器不支持的格式（比如 Ren'Py 或 Unity 作品）。

装好后，模拟器会扫描手机存储，把识别出的游戏自动分类列出，点图标即可启动，不用为每款游戏单独配播放器。

## 装之前值得确认的三件事

1. **游戏资源本身要是「能跑的形态」**：多数 PC 原版目录直接搬进手机是跑不起来的，能稳定运行的通常是带手机版数据文件的打包，或已打过手机适配补丁的目录；
2. **存储空间**：安装包本身 50 MB 上下，游戏文件另算，单个游戏常见几百 MB 起步；
3. **包名核对**：安装后包名应为 `com.akira.tyranoemu`，对不上就说明装的不是这个软件，卸掉换来源。
