# 手机导入galgame与触屏操作

> 本篇讲 Tyranor 装好之后怎么把游戏文件放进手机、让模拟器认出来，以及进游戏后 PC 鼠标操作对应的触屏手势。
> **相关文档**：[安卓玩galgame的多引擎模拟器.md](安卓玩galgame的多引擎模拟器.md) · [安卓galgame黑屏闪退排查.md](安卓galgame黑屏闪退排查.md)

---

## 先把游戏文件夹放对位置

模拟器本体不带游戏，它读的是手机存储里现成的游戏文件夹。准备工作三步：

1. **解压**：下载下来的 `.zip` / `.7z` 压缩包用文件管理器解压成一个完整文件夹，KRKR 作品解压后应能看到 `data.xp3` 之类的文件；
2. **放到固定目录**：建议在内置存储根目录建一个 `Tyranor` 文件夹，每个游戏单独一个子目录，路径越短、名字越干净越省事；
3. **别动本体文件**：`data.xp3`、`root.pfs`、`nscript.dat` 这类文件是引擎识别的依据，不要改名，也不要单独挪出游戏文件夹。

手上的资源属于哪种引擎、能不能跑，判断思路见 [安卓玩galgame的多引擎模拟器.md](安卓玩galgame的多引擎模拟器.md)。

## 扫描与手动添加

首次打开应用会申请存储权限，选允许；较新的系统还会额外要求「管理所有文件」，同样要给，否则扫不到游戏目录。多数情况下应用会自动扫描并生成游戏列表；没出现就手动指一次路径：

1. 点底部导航的「添加」；
2. 点右上角按钮进入路径选择窗口；
3. 定位到放游戏的目录，点右下角勾号确认；
4. 返回主界面，游戏出现在列表里即添加成功。

一个 2.3.4 版之后的注意点：已扫描的游戏列表会缓存，重启应用也不清除。如果「先扫了一遍、之后才把游戏文件补进目录」，列表可能一直是旧的——重新走一次「添加」让模拟器重扫即可。

## 鼠标操作换成触屏手势

进游戏之后，PC 上靠点击、滚轮、右键完成的动作对应一套触屏手势：

| 手势 | 对应操作 |
| --- | --- |
| 单击屏幕 | 推进对话 / 确认选项 |
| 长按屏幕 | 唤出菜单（存档、读档、设置） |
| 上滑 | 查看已读文本记录 |
| 下滑 | 打开设置 |
| 双指点击 | 返回 |
| 三指右滑 | 文本快进 |

第一次进游戏，先在任意对话界面把这套手势挨个试一遍，比翻设置快。

## 存档与备份

长按屏幕唤出菜单就能存档读档，关键分支前多存一个槽位。存档跟着游戏目录或应用数据走，各游戏互相独立；卸载重装、换机或清理存储前，把整个游戏目录连同 `Tyranor` 目录一起复制出来备份最稳妥。

界面截图、引擎清单与安装文件资源入口都汇总在 [Tyranor 模拟器介绍站](https://tyranor.gerw.hair/)；进游戏后黑屏闪退的排查思路见 [安卓galgame黑屏闪退排查.md](安卓galgame黑屏闪退排查.md)。
