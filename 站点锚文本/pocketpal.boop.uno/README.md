# PocketPal 使用资料索引

> 围绕 PocketPal AI（手机离线跑大模型的开源应用）整理的两篇实操资料：一篇讲完整上手步骤，一篇讲模型怎么选。

PocketPal AI 是一款开源（MIT 协议）的手机应用，用 llama.cpp 引擎在本机运行 GGUF 格式的开源模型，安卓与 iOS 双端可用，模型下载一次之后对话全程离线。

两篇资料的分工：

- **从零开始装到能聊** → 看[手机离线跑大模型的完整步骤.md](手机离线跑大模型的完整步骤.md)，含内存要求、安装放行、模型下载与离线验证；
- **拿不准该下哪个模型** → 看[手机跑大模型的内存与档位选择.md](手机跑大模型的内存与档位选择.md)，含运行内存对照表与量化档位取舍。

应用的界面实拍、按内存选模型的对照工具与安装后的问题排查，整理在 [pocketpal](https://pocketpal.boop.uno/) 介绍站，配合上面两篇一起看更省事。
