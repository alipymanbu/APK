# HMCL 手机版启动器下载安装步骤

想在安卓手机上启动 Java 版 Minecraft，绕不开一个趁手的启动器。HMCL-PE（Hello Minecraft! Launcher Pocket Edition）就是为这件事而生的安卓端应用：版本管理、账号登录、模组加载都收在启动器里。这篇按顺序讲清获取与安装的全过程，装完就能进主界面。

## 一、先核对手机能不能装

动手前花一分钟对一遍底线，省得装到一半才发现带不动：

| 项目 | 底线 |
| --- | --- |
| 系统 | Android 8.0 及以上 |
| 设备 | 64 位安卓手机 |
| 内存 | 建议 4 GB 及以上 |
| 存储 | 启动器自身约 500 MB，游戏本体另算 |

内存低于 4 GB 不是装不上，而是进了游戏大概率吃力。更细的配置账怎么算，见 [安卓手机玩Java版我的世界需要什么配置](安卓手机玩Java版我的世界需要什么配置.md)。

## 二、安装包从哪来

HMCL-PE 的安装文件资源通过网盘分享的形式提供：进入介绍站的下载页，点「获取安装文件资源」按钮，会跳转到夸克网盘的分享页——登录网盘账号、把安装包转存到自己网盘，再下载到手机存储即可。

整个链路不需要注册任何新账号，也不用在手机上装别的工具。具体的按钮位置和页面入口，见 [HMCL 启动器介绍站](https://hmcl.bpfl.quest/)的下载页。

## 三、四步装好

1. **保存安装包**：按上面的路径把安装包下载到手机存储，认准下载完成的文件，体积明显偏小说明没下完整；
2. **允许安装**：在文件管理器里点开安装包，系统弹「未知来源应用」提示时选择允许——这是安卓对商店外安装包的默认限制，不是包有问题；
3. **首次启动授权**：装完打开应用，首次启动会请求存储权限，选择允许，游戏文件和存档都写在这里；
4. **加账号、下游戏**：先加一个账号（离线账号只填用户名，有正版就登微软账号），再进「下载」页挑一个游戏版本下载，完成后点「启动游戏」。

四步里没有任何要填参数的地方，卡住了多半是第二步的权限或第一步的文件完整性，回对应环节重试即可。

## 四、装完之后

启动器只是起点：想装模组、开光影、和伙伴联机，都是在应用内继续操作，各项功能的入口和用法在介绍站里都有对应栏目可查。

手机配置吃紧的话，进游戏前先把分配内存调低一档，能避开大半闪退问题。
