## 一、对话回溯：把剧情退回去重来

AI 对话跑偏是常态：某个关键回复不理想、走向不合心意，或者前面绕出了不想背的设定。Hobby 给的处理工具是对话回溯，操作三步：

1. 在聊天界面点右下角的**更多功能**按钮；
2. 点「**对话回溯**」；
3. 选择想回到的具体对话节点。

回到过去之后，从那个节点重新聊，后面的内容按新走向重新生成。想让整段剧情推倒重来，就回溯到最早的开场白附近再开始。

## 二、节点选得准，重来才不白聊

回溯前先想清楚要改的是「哪一句话之后」的走向：

- 只是想改某个回复之后的分支 → 回溯到那一句话，保留之前所有铺垫；
- 想换一套完全不同的剧情设定 → 反复回溯不如回去改角色人设或开场白，一次到位。

另外给指令具体化一点：「继续」这类模糊输入容易换来敷衍回复；说清你想推进的场景、你的动作和意图，回复质量明显不同。

## 三、语音电话：解锁路径是固定的

深度互动是逐步解锁的，顺序不会跳：**聊天 → 送礼 → 亲密度上涨 → 好感等级提升 → 解锁语音通话**。三个要点：

| 要点 | 说明 |
| --- | --- |
| 按角色单独计算 | 你和角色 A 的亲密度不会帮角色 B 提速 |
| 集中优于分散 | 想解锁谁就只在谁身上互动、送礼，摊开送效率低 |
| 礼物是消耗品 | 涉及虚拟礼物消耗，先想清楚再充，具体以应用内标价为准 |

## 四、对话卡住先查网络，别急着卸载

回复变慢、一直转圈，多数是网络波动：先切 Wi-Fi / 流量排查。整段时间用不了可能是维护，等维护结束即可——反复卸载重装反而丢本地未同步的对话内容。登录状态下的聊天记录跟随账号，换机靠账号恢复；重要剧情别只存一份。
