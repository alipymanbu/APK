# Hobby 安卓版下载安装步骤与装不上排查

> 讲怎么把 Hobby 装到手机上：安卓端从安装文件资源到装好要几步、iOS 端去哪找，以及点不开 APK、安装被拦、闪退三类问题的排查顺序。
> **相关文档**：[养崽融合与课程表攻略.md](养崽融合与课程表攻略.md) · [对话回溯与语音解锁技巧.md](对话回溯与语音解锁技巧.md)

## 一、先分清你要装哪一端

Hobby 由上海微烽科技开发，是面向手机的 AI 角色扮演社交应用，只有移动端：

| 端 | 分发方式 | 分级标注 |
| --- | --- | --- |
| 安卓 | APK 安装包（安装文件资源，夸克网盘） | 年满 16 周岁（第三方市场标注） |
| iOS | App Store，仅 iPhone | 18+（商店页面标注） |

没有电脑版；安卓包体积不小，装之前把剩余空间清到 1 GB 以上，避免装到一半失败。

## 二、安卓版：四步装好

1. **打开安装文件资源**：从 [Hobby 下载安装说明](https://hobby.usea.quest/) 页面顶部的入口进入，把 APK 转存到自己的夸克网盘，再下载到手机本地存储（大文件可能需要在 App 内操作）；
2. **点开 APK**：在手机文件管理器里找到刚下载的安装包，点开安装；
3. **放开安装权限**：首次安装会提示「允许安装未知来源应用」，按品牌路径放开一次——
   - 小米 / 红米：设置 → 隐私保护 → 特殊权限 → 安装未知应用；
   - 华为 / 荣耀：设置 → 安全 → 更多安全设置 → 安装外部来源应用；
   - OPPO / vivo / 一加：设置 → 安全 → 安装未知应用；
4. **打开并登录**：装完打开，按提示用手机号注册登录。之前装过旧版本的，直接装新版通常在原数据上升级。

## 三、iOS 版：去 App Store 搜

在 App Store 搜索「Hobby」或「HobbyAI角色扮演」，开发方显示为 Shanghai Weifeng Technology Co., Ltd. 就是它。两个提醒：登录的 Apple ID 地区会影响能否搜到；iOS 版体积明显更大，确认 Wi-Fi 环境再下载。

## 四、装不上，按这三条对号入座

- **点 APK 没反应或提示解析失败**：最常见原因是传输中断导致包损坏，回到资源页重新下载一次；同时确认剩余空间够；
- **安装进行到一半被拦**：手机管家的「安装拦截」先关掉，「未知来源」权限按上面的品牌路径放开，都不行就换个文件管理器再点；
- **装上了但打开就闪退**：先重启手机；还不行就强制停止后重开，再到 设置 → 应用管理 → 存储 → 清除缓存；系统版本过旧对大体积应用支持差。语音等功能不可用，去系统设置里放开麦克风、存储权限。
