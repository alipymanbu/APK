# 跟读评分和精听填空怎么用：把一句话吃透的四件工具

> voscreen（一句英语）的听力答题之外，还有一组把短句吃透的工具：精听填空、跟读打分、语法专项与生词本。本篇按「遇到一个好句子之后怎么处理」的顺序把它们串起来讲。
> **相关文档**：[碎片时间英语听力训练.md](碎片时间英语听力训练.md) · [README.md](README.md)

## 一、精听填空：从「大概听懂」到「逐词听清」

答题只是第一层。遇到听得半懂句子时，精听练习会把关键词挖空，边看视频边补全——填不出来的那几个词，就是你听力里真实的洞。系统挖的是句子骨架词（动词、名词、连接词），补完再重听整句，比单纯多听几遍更有效。

填空卡住时可以点提示，但提示给的是同义替换方向，不是直接亮出答案，最终还是得靠耳朵确认。

## 二、跟读打分：发音问题有据可依

看懂一句不等于说得出口。跟读功能让你对着原句录音，然后按三个维度打分：

| 维度 | 看什么 |
| --- | --- |
| 流利度 | 有没有频繁停顿、卡壳 |
| 正确率 | 单词发音准不准 |
| 完整度 | 有没有漏词、吞音 |

哪个维度低就针对性练哪个：流利度低就多读几遍再录，正确率低就点开单词听标准发音逐个纠正。每段只有一句话，跟读一遍的成本很低，这也是「一句英语」这个名字的由来——一次只吃透一句。

## 三、语法专项：耳朵专治「看得懂听不出」

语法书看得懂、耳朵听不出来，是听力进阶最常见的瓶颈。voStructure 功能就是冲着这个来的：选定一个语法点（时态、连词、短语动词、关系从句、名词性从句等），之后推送的片段全都会含这个结构，让耳朵在同一个句型上反复受训。

像 he's / he is、can't / can 这类靠结构判断的题，专项练几组就能听出差别。难度另有五级分级、按句长细分，答起来不卡就升一档、错一半就降一档，语法专项和难度分级可以组合使用。

## 四、生词本：把查过的词管起来

听的过程中点任意单词即可查释义、听发音，一键收进生词本。配合方式建议：专项练完当晚收词，第二天开新题之前先花几分钟过一遍生词本——隔天复习一次，比刷完就丢记得牢得多。
