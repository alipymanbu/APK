# voscreen 站点导航

voscreen（中文名「一句英语」）是一款用十秒左右影视片段练英语听力的应用：先听原句，再在倒计时里选出意思一致的说法。这里围绕它的两个高频搜索需求各整理了一篇说明。

- [碎片时间英语听力训练.md](碎片时间英语听力训练.md)：核心训练循环、计分排行与两种选项口径；
- [跟读评分和精听填空怎么用.md](跟读评分和精听填空怎么用.md)：精听填空、跟读打分、语法专项与生词本的配合。

想直接看界面与功能全貌，或拿安卓安装文件资源，去 [voscreen 介绍站](https://voscreen.xnyx.quest/) 即可。
