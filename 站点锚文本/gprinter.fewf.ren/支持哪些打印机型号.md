# 支持哪些打印机型号

> 本篇讲 Gprinter 的机型适配范围：公开资料里明确与之同框的佳博打印机型号记录，怎么确认你手里那台能不能用，以及 Gprinter / GprinterHD / Uprinter 三个名字相近的应用别装混。
> 相关文章：[怎么连接打印机](怎么连接打印机.md) · [打标签排版技巧](打标签排版技巧.md)

## 一、先分清三个应用，别装混

佳博（Gainscha）同时维护着几个名字相近的配套应用，装的不是对应的那一个，打印机就搜不到：

| 应用 | 适用设备 |
| --- | --- |
| **Gprinter** | 竖屏安卓手机 / 平板（另有 iOS 版在 App Store） |
| **GprinterHD** | 横屏安卓系统，工控屏、收银一体机 |
| **Uprinter** | 另一套配套应用，覆盖标签、票据、双色、RFID |

打印机说明书或产品页写哪个名字就装哪个；没写应用名的老机型，一般从 Gprinter 试起。

## 二、公开资料里出现过的适配记录

这些型号在手册、规格书或下载条目里明确与 Gprinter 一起出现过（来源不同，可信度都标在备注里）：

| 型号 | 类型 | 备注 |
| --- | --- | --- |
| PT-280 | 便携票据机 | 随机手册点名配套 Gprinter；纸宽 58mm / 打印宽 48mm |
| iSH58 | 便携票据机 | 自检页拿蓝牙名，配对后连接 |
| Q80 | 便携打印机 | 下载条目注明适用于该机型 |
| GP-M421 | 4 寸便携机 | 规格书标注安卓与 iOS 版均可配 |
| 2120TF / 2120TL | 桌面标签机 | USB / 蓝牙 / 网络接口通信 |
| D12 系列 | 桌面标签机 | 与 2120 系列同批适配记录 |

按佳博对这套应用的功能定位，它面向 200dpi / 300dpi 的热敏标签机，也支持票据打印——你的机器属于这两类之一的话，大概率在适配范围内。表里没有的型号不代表不支持。

## 三、怎么确认你那台能不能用

按省事程度排序：

1. **翻自检页或说明书**：佳博随机手册的连接一节都会写配套应用的名字，写 Gprinter 就是直接支持；
2. **查厂商渠道的产品页**：在你型号的「资料下载 / 相关下载」里看配套应用名称；
3. **问客服**：厂商公布的咨询热线是 400-038-0088，报上型号即可确认。

确认能用之后，连接步骤见[怎么连接打印机](怎么连接打印机.md)；连好后的排版与打印见[打标签排版技巧](打标签排版技巧.md)。

Gprinter 的功能介绍、界面实拍与安装文件资源入口，见站点：<https://gprinter.fewf.ren/>
