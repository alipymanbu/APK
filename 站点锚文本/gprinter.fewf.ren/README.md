# Gprinter 站点导航

这里是 Gprinter 的介绍与使用说明汇集处。Gprinter 是佳博（Gainscha）热敏标签打印机的手机端配套应用：在手机上排好合格证、价签、封口贴，通过蓝牙或网络发给打印机出纸。

软件的完整介绍、界面实拍、适配机型清单与安装文件资源入口，见站点：<https://gprinter.fewf.ren/>

## 本目录文章

- [怎么连接打印机](怎么连接打印机.md) —— 自检页找蓝牙名、系统配对、App 内选机，以及搜不到打印机时的权限处理
- [打标签排版技巧](打标签排版技巧.md) —— 控件式编辑、扫码与拍照录入、模板复用，顺便避开打印偏移
- [支持哪些打印机型号](支持哪些打印机型号.md) —— 适配机型记录，以及 Gprinter / GprinterHD / Uprinter 别装混
