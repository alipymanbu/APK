# 打标签排版技巧

> 本篇讲在 Gprinter 里把标签排好、打好：新建标签先把尺寸选对，控件式摆内容，扫码、拍照、语音三种快捷录入，存成模板复用，以及打印偏移的预防。
> 相关文章：[怎么连接打印机](怎么连接打印机.md) · [支持哪些打印机型号](支持哪些打印机型号.md)

## 一、新建标签：尺寸先对上纸

新建标签第一步选尺寸，**这里填的尺寸要和打印机里装的纸一致**——纸宽 58mm 的便携机就选 58mm 档，桌面机按标签纸规格选。尺寸选错是打歪的第一大原因。高度方向有下限：版面高度别低于 10mm，否则内容容易打偏。

## 二、往版面上放控件

编辑器是控件式的，从控件栏往版面加元素，每个元素单独调整：

| 控件 | 典型场景 |
| --- | --- |
| 文字 | 商品名、价格、说明 |
| 一维码 | 零售标价签、资产标签 |
| 二维码 | 设备管理标签、小程序码 |
| 图像 | 品牌标识、外观图 |
| 表格 | 规格参数、成分表 |
| 日期 | 生产日期、保质期起点 |

双击控件改内容与样式，单指拖动移位，拖角缩放。做一排整齐的价签：先放好一个、对齐锁定，再复制几个改文字，比每次重摆快。

## 三、三种快捷录入

1. **条码扫描**：对着现有条码 / 二维码扫一下，内容直接进版面——补打或照旧标签重做时最省事；
2. **图文识别**：拍一张现有标签或单据，把上面的文字识别出来用；
3. **语音识别**：口述转文字，双手腾不开的时候好用。

## 四、存模板，下次直接调

排好的版面存成本地模板，命名带上用途（如「水果价签」「网线标签」），下次改几个字就打。云端另有价签、封口贴、物品标签这类现成版式，套上替换文字即可。

## 五、打印前最后核对

1. 打印机已连接（连接卡住回[怎么连接打印机](怎么连接打印机.md)排查）；
2. 标签尺寸与实际纸宽一致——横向偏移、右侧截断基本都是宽度三处（纸的实际宽、标签尺寸、机器打印宽）没对齐；
3. 纵向跳页查装纸与传感器：装纸居中、间隙传感器卡进标签间隙，黑标纸与间隙纸别混装；
4. 打印太淡浓度调高一档即可，不必拉满——浓度过高会缩短打印头寿命。
