# Chameleon 配对与开拍设置实操

> 本篇讲把手机夹上 Chameleon 之后到按下录制之间的全部动作：蓝牙配对怎么走、机位摆哪、运动类型与年龄段怎么选。带硬件的完整玩法与常见问题，见[家长拍孩子比赛的自动跟拍方案](家长拍孩子比赛的自动跟拍方案.md)。

---

## 一、配对前先分清两条通道

很多人连不上就怪蓝牙，其实设备和应用之间是两条通道各干各的：

| 通道 | 走什么 | 干什么 |
| --- | --- | --- |
| 配对与控制 | 蓝牙 | 设备发现、初始配对、发控制指令 |
| 数据传输 | 设备发出的局域热点 | 画面回传、监看、传文件 |

由此两个结论：场地没外网照样能拍；配对一直转圈时，先把手机上无关的 WiFi 断开，避免抢占通道。

## 二、配对四步

1. 设备长按电源键开机，等开机自检的上下校准动作做完。
2. 手机打开应用并登录，点「添加设备」。
3. 设备列表里选中 `Xbot` 开头的那台完成配对。
4. 能看到摄像头画面，说明两条通道都通了。

侧灯是现成的判据：呼吸式慢闪 = 等待配对；常亮 = 已被某台手机连着（可能不是你的）。昨天还好好的、今天突然连不上，先双击设备电源键重置蓝牙再连。

## 三、机位：位置比设备贵贱更要紧

- 任何标准 1/4 英寸螺口三脚架都能用，机位优先摆在**中线附近**。
- 小场（篮球馆、5 人制）矮架就够；大场（9 人制、11 人制）架高明显更好，条件有限就找看台、高坡。
- 手机装进夹子前摘壳，后置摄像头与设备的追踪镜头对齐，拧紧锁紧旋钮——比赛中间手机滑落是最不值的损失。
- 设备装上三脚架时握住底座旋转锁紧，不要拧机身本体。

## 四、开录前的三项确认

| 设置项 | 为什么重要 |
| --- | --- |
| 运动类型 | 足球、篮球、网球等各套各的追踪与取景逻辑，选错镜头跟错目标 |
| 场地尺寸 | 大场配大扫动范围，小场配小，选反了镜头甩来甩去 |
| 年龄段 | 青少年场次按成人速度预测容易跟丢 |

篮球模式还有一个专门的球衣号码追踪：选中号码后全场只跟这一个人，拍自家孩子或做球探素材正合适。这些设置与玩法的更完整图文版，见 [XbotGo 用法介绍站](https://xbotgo.gerw.hair/)，配对成功只是开始，设置对了才出好片。

## 五、追踪发飘先别调参数

按顺序过一遍：应用与固件都升到最新 → 核对机位是否中线附近、高度是否匹配场地 → 核对摄像头对齐 → 核对三项设置 → 看光线（顶灯逆光、傍晚大逆光是追踪算法的天然弱项）。多数「追踪不准」其实是机位和设置错位，不是算法问题。
