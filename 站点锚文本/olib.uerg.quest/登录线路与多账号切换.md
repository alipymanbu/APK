# 登录线路与多账号切换

> 打开 Olib 就要先过登录页？这篇讲清楚它的账号逻辑：登录用的是书源账号而不是应用自己的账号，线路怎么选、登不上先查什么、多账号怎么切，都按可执行的顺序列出来。
>
> 相关阅读：[手机看电子书的开源客户端](手机看电子书的开源客户端.md) · [本地电子书导入与书架整理](本地电子书导入与书架整理.md)

## 先弄明白：登的是谁的账号

Olib 只做阅读界面与书架，在线搜书、下载书的数据来自外部书源，所以登录页里填的是**你在书源侧注册的邮箱和密码**，应用本身不发账号、也没有注册入口。只想读本地书的读者同样要过这一页（这一版还没有「跳过登录」入口），过完登录就能导入本地书，导入与阅读不依赖账号。

## 线路是什么、怎么选

「线路」是客户端连接书源用的不同服务器入口，同一个账号在哪条线路上都能登录。内置多条线路，还有自定义线路地址的选项。选择上没有玄学：

1. 默认线路先试一次；
2. 登录超时或搜索一直转圈 → 换一条线路再登录；
3. 换线路后原来的搜索结果不会自动刷新，要重新搜一次。

## 登不上时的排查顺序

| 现象 | 先检查什么 |
| --- | --- |
| 一直转圈不出结果 | 换一条线路；确认手机能正常上网 |
| 提示密码错误 | 确认填的是书源账号，别把应用当成有独立账号的软件 |
| 账号没错仍失败 | 书源侧可能限制登录频率，隔一段时间再试或换线路 |
| 之前能用现在不行 | 书源侧入口会变化，关注项目页面的说明 |

## 多账号与切换

应用支持保存多个书源账号并在它们之间切换，两个场景最常用：一个日常号加一个备用号；或一家人共用一台设备、各用各的账号。切换入口在账号相关的设置页里，切换前把重要的下载文件确认清楚。

## 结语

账号与线路都理顺之后，搜索、下载、阅读就能一路畅通；只想安静看本地书的读者，直接翻[本地电子书导入与书架整理](本地电子书导入与书架整理.md)。还没安装的话，[Olib 介绍与安装获取页](https://olib.uerg.quest/)里可以拿到安装包。
