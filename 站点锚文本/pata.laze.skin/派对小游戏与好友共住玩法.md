# Pata 派对小游戏与好友共住玩法

> Pata 的热闹都在「人齐」之后：怎么把好友拉进同一间小屋、内置的派对小游戏怎么开一局，这篇讲清这两条线。
> **同目录相关阅读**：[电子宠物领养与养成入门.md](电子宠物领养与养成入门.md)

## 一、前提：双方都装好并登录

好友共住与多人小游戏都建立在「绑定好友」之上，而绑定要求**双方都装了应用并注册登录**。所以第一步永远是让对方把应用装上——安卓端可以从网盘安装包走，入口与安装步骤都整理在 [Pata 玩法与介绍站](https://pata.laze.skin/)；iOS 端在 App Store 搜索安装即可。

## 二、把好友拉进同一间小屋

按公开教程整理的路径（按钮位置随版本可能调整，以屏幕上实际给出的为准）：

1. 进底部导航的**空间**入口，打开个人空间页；
2. 点右上角的**好友**图标，进好友管理界面；
3. 点**邀请好友**，系统生成专属**邀请链接与邀请码**；
4. 把链接发给对方（微信、QQ 都行）；
5. 对方装好并登录后，输入你的邀请码（或直接点链接）完成绑定；
6. 回空间页点**共享空间**，选中好友发起共享邀请，**对方同意**后你们就共住一间屋了。

两个容易卡住的点：邀请不会自动读通讯录，必须走一遍「发邀请 → 对方接受」；最后一步要对方点同意，共享才算成立。小屋是多房间格局，家具和摆件几个人一起挑——买之前先对一下审美，免得把屋子摆成两套风格。

## 三、派对小游戏：全部只打字就能玩

游戏设计偏熟人局，所有玩法都能不开语音、纯文字参与，介绍里反复提「社恐也能玩」。公开介绍里出现过的玩法：

| 玩法 | 一句话说明 |
| --- | --- |
| 谁是卧底 | 人人拿到不同的词，描述与投票，找出最可疑的那个 |
| 你演我猜 | 一人比划一人猜，考好友间的默契 |
| 默契问答 | 同题各答，对不上就是「最好的默契就是没默契」 |
| 画画拼图 | 每人画一笔往下传，看最后画成什么离谱东西 |
| 谁最有可能 | 互相投「最有可能做这件事的人」 |
| Pata 猜词 | 宠物出题的知识向猜词，单人也能玩 |
| 专注花园 | 和好友比拼专注时长，赛博种花 |
| 寻宝冒险 | 拼运气的出门冒险，宝藏看脸 |

**怎么开局**：进主界面下方的游戏入口 → 选一个玩法 → 进匹配；2.3.0 起能更快找到好友正在对局的房间，直接加入即可。不想下场就用 2.2.0 加的观战模式，站在旁边看朋友互相怀疑。

## 四、玩过之后去哪看

对局与串门的互动会被写进宠物的**观察人类日记**——它视角下的共同生活流水账，在日记页翻看。人齐之后的动线其实很简单：一起摆屋子、拉群聊、开一局，剩下的交给宠物记日记。
