# PDF 合并拆分与页面整理方法

> 手机上把多份 PDF 拼成一份、把一份拆成几份，或者抽取其中的几页、转正横倒的扫描页——本篇讲 PDFelement 安卓版里这些页面整理操作的做法与适用场景。
> **相关文档**：[手机上怎么编辑PDF文字与图片](手机上怎么编辑PDF文字与图片.md) · [扫描件OCR转可编辑文字教程](扫描件OCR转可编辑文字教程.md)

## 一、常用的页面整理操作

多页文件的操作集中在页面整理类工具里（合并与批量整理属于会员能力）：

| 操作 | 用法 |
| --- | --- |
| 合并 | 把多个 PDF 拼成一个文件，交付前最常用 |
| 拆分 | 按页把一个文件拆成几份 |
| 提取 | 只留需要的几页另存 |
| 删除 | 去掉空白页或不要的页 |
| 旋转 | 把横倒的扫描页转正 |
| 重排 | 拖动调整页面顺序 |
| 插入空白页 | 加一页白纸补内容 |

整理完记得保存；只发某几页给别人的场景，先提取再分享最省事。

## 二、PDF 与其他格式互转

整理之外，PDFelement 也支持格式转换（会员能力）：

| 转换方向 | 典型用途 |
| --- | --- |
| PDF → Word（.docx） | 拿到电脑上继续改文档 |
| PDF → Excel（.xlsx） | 提取报表里的数据 |
| PDF → 图片（JPEG / PNG） | 发到只收图片的地方 |
| 图片 / 相机 → PDF | 截图、拍照件合成一份文件 |

两点提醒：

- 扫描件转 Word 前要先做文字识别，否则转出来还是整页图片，识别步骤见 [扫描件OCR转可编辑文字教程](扫描件OCR转可编辑文字教程.md)；
- 多栏、嵌套表格这类复杂排版的转换还原度有限，转出来排版乱了属于正常范围，必要时改用提取文字的方式。

## 三、转换或整理失败时看什么

- 文件本身是加密 PDF：先输密码打开，或解除限制后再转；
- 转换卡在进度条：大文件耗时与页数相关，别在中途杀掉应用；
- 合并后顺序不对：回页面整理里拖动重排，保存覆盖即可。
