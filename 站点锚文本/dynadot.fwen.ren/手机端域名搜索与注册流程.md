# 手机端域名搜索与注册流程

> 在 Dynadot 安卓客户端里怎么搜到想要的域名、比对各后缀价格、批量筛选并完成付款。适合第一次用手机注册域名，或想把选名流程整个搬上手机的读者。
> **相关文档**：[安卓客户端安装与账户安全设置.md](安卓客户端安装与账户安全设置.md) · [域名续费与到期处理实操.md](域名续费与到期处理实操.md) · [域名拍卖与二手市场出价入门.md](域名拍卖与二手市场出价入门.md)

## 一、这篇解决什么

打开 App 首页就是 Domain Name Search 搜索页：输入想注册的词，选后缀，可注册的直接加购物车结账。本篇按操作顺序讲——搜索、看价、用工具、批量查、下单付款。域名还没装客户端的，先看 [安卓客户端安装与账户安全设置.md](安卓客户端安装与账户安全设置.md)；客户端的获取入口在 [Dynadot 安卓客户端介绍站](https://dynadot.fwen.ren/)。

## 二、搜索框怎么用

1. 首页搜索框输入域名主体（比如 `mybrand`），点 Search；
2. 结果页列出各后缀的可注册状态与价格，首屏价格条常显示 `.co`、`.vip`、`.io` 这类后缀的促销价，首年优惠价与原价并排；
3. 可注册的勾选加购物车，已被占用的通常给替代建议或跳转二手市场入口；
4. 购物车在页面右上角，核对年限与总价后结账。

价格随时间与后缀变化，促销价往往只管首年，续费价是另一档——下单前以结算页金额为准。

## 三、首页面板的工具

搜索框下方有一排快捷入口，常用的几个：

| 入口 | 用途 |
| --- | --- |
| Transfer | 发起域名转入，把别家注册的域名转过来 |
| TLD Prices | 查各后缀的注册与续费价格表 |
| Whois | 查注册信息与到期时间，确认是否可注册 |
| Appraisal | 域名估价参考 |
| Manage | 进入已有域名的管理列表 |
| Prepay | 给账户充值（预付款） |
| Tracker | 关注列表，盯住想买的域名，有变化收通知 |
| Custom | 自定义常用功能入口 |

## 四、一次查多个：批量搜索

几十上百个名字逐个输不现实，用批量搜索：

- App 内置批量搜索与批量注册；
- 网页版批量搜索支持粘贴名单、按后缀过滤、导入与导出 CSV；每日次数按账户等级不同：普通账户 1,000 次/日，Bulk（累计消费 $500）2,000 次/日，Super Bulk（$5,000）5,000 次/日——以产品页面当时显示为准；
- 批量查本身免费，查出来可注册的可以一键全部加购物车。

## 五、下单与付款

1. 购物车里选年限，1 年起，最长可一次注册多年；
2. 付款方式有账户余额、信用卡、已关联的 PayPal 三种，默认走余额；
3. 余额没充值时先去 Prepay 充值，或改用其他方式；
4. 注册成功后域名立即进入账户，就能去管理页改解析了。

**没有国际信用卡怎么办**——支持的付款渠道里，国内用户常用的几个（以支付页面当时显示为准）：

| 方式 | 要点 |
| --- | --- |
| 支付宝 | 人民币付款，单笔上限 30,000 元 |
| 银联 | 人民币付款，国内银行卡直付 |
| PayPal | 支持 USD/EUR/GBP 等多币种 |
| 信用卡/借记卡 | Visa / Mastercard / AmEx / JCB 等，接受境外发行卡 |
| 银行电汇 | 最低 $500，适合大额，建议先充成余额再下单 |

**关于 Prepay 余额**：最低 $5 起充、永不过期、下单最快（注册常在数秒内完成）；但充进余额的钱不可退款，按需充。设置自动充值需要账户注册满 1 年且有订单记录。

## 六、注册前顺手确认两件事

- **Whois 隐私**：WHOIS Privacy 免费，注册后在账户设置里决定开不开；开了以后公开查询显示的是代持信息，不是真实资料；
- **名字被占了怎么办**：先看 Whois 的到期时间与历史，判断值不值得等它掉下来；急着要就走二手市场，见 [域名拍卖与二手市场出价入门.md](域名拍卖与二手市场出价入门.md)。

买完之后的续费、到期、解析管理，都在 [域名续费与到期处理实操.md](域名续费与到期处理实操.md) 里。
