# Dynadot 安卓客户端安装与账户安全设置

> Dynadot 是一家 ICANN 认证的域名注册商，其安卓客户端把域名搜索、注册、续费与拍卖出价搬到了手机上。本篇讲这款客户端怎么装、装完如何登录，以及两步验证、账户锁定这些安全机制怎么配。
> **相关文档**：[手机端域名搜索与注册流程.md](手机端域名搜索与注册流程.md) · [域名续费与到期处理实操.md](域名续费与到期处理实操.md) · [域名拍卖与二手市场出价入门.md](域名拍卖与二手市场出价入门.md)

## 一、这是个什么应用

Dynadot 的安卓客户端和网页端共用同一套账户、同一份数据：手机上改的 DNS、续的费用、出的价，电脑端同步生效。它不是功能阉割版的小工具，而是覆盖了日常全部动作的完整客户端——搜索下单、组合管理、二手市场出价、在线客服都在里面。平板另有专门优化的 HD 版本，界面按大屏重新排版，功能一致。

## 二、安装从哪里入手

安装包属于 APK 格式，需要经网盘分享获取后转存下载。具体的获取入口与分步操作（转存、下载、允许来源、登录）已经整理在 [Dynadot 安卓客户端介绍站](https://dynadot.fwen.ren/) 的安装页里，照着走大约两三分钟就能装完，这里不重复展开。

装的时候会遇到的唯一一道坎是安卓的陌生来源拦截：点开 APK 时系统提示"禁止安装来自此来源的应用"，进入设置的"安装未知应用"，给用来打开文件的文件管理器授权即可。装完建议把这条授权关回去。

## 三、登录要准备什么

- **用户名 + 密码**：App 与网页端同一套账号，登录入口在侧边菜单里；
- **两步验证码**（若已开启）：验证器动态码或短信码；
- **账户处于锁定状态时**：登录后还要先解锁才能改账户级设置（见第五节）。

## 四、两步验证：装完就该配的第一件事

域名是资产，账户安全规格值得拉满。Dynadot 支持验证器 App（Google Authenticator、Microsoft Authenticator、Authy、Duo Mobile 都行）、短信验证与安全密钥三种方式。以验证器为例：

1. 手机装好任意验证器 App；
2. 网页登录后进 My Info → Security → Manage Two-Factor Authenticator；
3. 输入 Security PIN 解锁进设置页；
4. 点验证器旁的加号，弹出 Key 与二维码；
5. 验证器扫码或手输密钥，添加成功后条目显示为 `Dynadot:用户名`；
6. 把页面生成的 token 填回验证框，启用；
7. 同一页点 Backup Codes 生成一串一次性备份码，**务必保存**。

第 7 步最容易省掉，但备份码是手机丢了之后唯一能自助登录的通道。

## 五、账户锁定是怎么回事

- 账户**默认处于锁定状态**，这是安全设计，不是账号出问题；
- 解锁要验身份：2026 年 8 月 18 日及之后注册的账户用账户密码，之前的用 4 位 Security PIN；开了两步验证的还要一并输入验证码；
- 解锁后才能编辑账户信息、解锁域名、改两步验证配置；
- 解锁状态 1 小时后会自动重新锁上，也可以手动锁回。

改 DNS、续费这类日常操作一般不需要解锁；某天操作时突然被要求输 PIN，就是这道闸在起作用。

## 六、手机丢了 / 验证码收不到

按顺序自救：

| 情况 | 入口 | 走向 |
| --- | --- | --- |
| 验证器在旧手机上 | Lost Cellphone | 用密保问题申请重置验证方式 |
| 备份码还在 | 登录页直接输入备份码 | 登录后把验证器换绑新手机 |
| 安全密钥丢了 | Lost Security Key | 提交重置申请，人工审核约 2 个工作日 |
| 忘了 Security PIN | Forgot Security PIN | 答密保问题换新 PIN |

密保问题是最后的兜底：从 10 个题里选 3 个作答，答案区分大小写，每 30 天只能改一次，务必存进密码管理器。

## 七、装好之后去哪

登录完成后，首屏就是域名搜索页。怎么搜、怎么看价格、怎么付款，见 [手机端域名搜索与注册流程.md](手机端域名搜索与注册流程.md)；已有域名要续费或改解析的，直接看 [域名续费与到期处理实操.md](域名续费与到期处理实操.md)。
