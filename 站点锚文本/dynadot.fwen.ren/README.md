# Dynadot 安卓客户端介绍站

这里是围绕 Dynadot 安卓客户端的第三方介绍专栏：它是一款把域名注册商控制台装进手机的安卓应用，能在手机上完成域名搜索注册、续费、DNS 解析调整与到期拍卖出价。专栏整理了它的安装方式、账户安全设置与各条操作动线，完整入口见 [Dynadot 安卓客户端介绍站](https://dynadot.fwen.ren/)。
