# 自带密钥用 AI（BYOK）是什么玩法

> 这篇解释 BYOK（Bring Your Own Key，自带密钥）这种用法：它和包月订阅类产品有什么区别、适合谁、要注意什么。

## 一、BYOK 的意思

大部分 AI 应用把模型服务打包成订阅卖给你；BYOK 客户端则把模型这一层拆出来——你自己去模型服务商那里注册账号、生成 API 密钥，把密钥填进客户端，请求从你的设备直连该服务商。客户端只负责对话界面与本地功能，不碰你的模型额度。

以安卓上的开源客户端 [Agora](https://agora.yoan.quest/) 为例：它对主流服务商提供预设，也支持自定义 OpenAI 兼容端点，自建服务、远程 Ollama 地址都能接。聊天花多少钱、答得多快，取决于你配的那家服务商。

## 二、这种玩法适合谁

- **已经有服务商账号的人**：注册过任何一家提供 API 的模型服务商，BYOK 客户端能立刻把这些额度用起来。
- **想自由切换模型的人**：同一个界面里配多家服务商，按问题难度换模型，不必在每个应用之间跳。
- **在意数据流向的人**：对话请求直连你选的服务商，客户端不做中转；再配合本地模型路线，敏感对话可以完全不联网。

## 三、密钥保管的三个常识

1. 密钥等同账户余额，别截图发群里。像 Agora 这类客户端会用系统级加密存储密钥（Android Keystore，AES-256-GCM），但导出备份时若勾选了密钥项，归档里是明文，要当成密码对待。
2. 服务商后台通常支持随时作废重发密钥，泄露了就立刻换。
3. 不同服务商的计费口径差异很大，先在小额度上试，熟悉了再放量。

## 四、怎么开始

流程通常三步：填密钥 → 同步模型列表并勾选 → 底部栏选中开聊。安装包与更完整的上手说明，可以在 [Agora 介绍站](https://agora.yoan.quest/)找到。没有密钥也不着急，同一条路线配本地 GGUF 模型就能先体验起来。
