# 对话记录的备份与换机迁移做法

> 这篇聊 AI 对话记录怎么保住：为什么换机最容易丢数据、备份要盯住哪几个动作、迁移时有什么坑。

AI 对话攒久了和聊天记录一样值钱：调好的提示词、反复打磨过的方案、重要的结论都在里面。而这类数据往往存在应用本机——卸载应用或清除数据，记录就没了。

## 一、换机丢数据的两个常见原因

1. **只存在应用里，没导出过**：会话数据在应用自己的数据库中，换新手机不会自动跟过去。
2. **清应用数据时手快**：清理空间时点了「清除数据」，等于直接删库。动手清理前，先确认有备份文件。

## 二、备份盯住两个动作

以 [Agora](https://agora.yoan.quest/) 为例，它的备份体系是两层：

- **自动备份**：首次启动引导里就能打开，按设定间隔定时执行，备份类别与周期可在设置里调，之后不用再管。
- **手动导出**：设置 → 导入导出，把会话、记忆、提示词打包成 `.agora` 归档文件。换机前建议无论如何手动导一份，两道保险。

导出的归档若勾选了密钥项，里面是明文保存的 API 密钥——这份文件别发给别人、别丢进公开场合，迁移完成后删掉多余副本。

## 三、迁移的标准流程

1. 旧手机：手动导出一份 `.agora` 文件，传到电脑或网盘中转。
2. 新手机：装好客户端（安装入口见 [Agora 介绍站](https://agora.yoan.quest/)）。
3. 新手机：同一入口选导入，选中归档文件，按提示勾选要恢复的类别。
4. 导入后花一分钟核对：会话数量对不对、服务商页面里密钥还在不在。

## 四、从别的应用搬家

如果之前用的是别的 AI 应用，部分客户端支持直接导入历史记录——Agora 可以读取 ChatGPT 导出的对话文件，把旧对话转成本地会话，换阵营不用从零开始。导入大文件时耐心等它处理完，中途退出容易产生半截会话。
