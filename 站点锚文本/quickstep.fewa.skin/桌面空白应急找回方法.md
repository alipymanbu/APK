# 桌面空白应急找回方法

> 开机后桌面图标全消失、只剩状态栏时的从零恢复流程：先分清「没了」还是「崩了」，再用通知栏应急，最后用电脑 ADB 把桌面装回来。
> **相关文档**：[系统桌面组件的作用与常见疑问.md](系统桌面组件的作用与常见疑问.md) · [全面屏手势设置与失灵排查.md](全面屏手势设置与失灵排查.md)

## 一、先分清两种情况

| 现象 | 状态 | 处理方向 |
| --- | --- | --- |
| 反复弹「Quickstep 已停止运行」，偶尔还能看到图标 | 桌面在，崩溃 | 重启 → 强制停止 → 清缓存 → 系统更新，顽固时清除存储重置桌面 |
| 开机直接黑屏桌面，图标一个没有，只能拉通知栏 | 桌面没了 | 本篇流程 |

桌面「没了」通常是：停用或 root 后误删了桌面组件；用 ADB 精简系统应用时把桌面一起移除了；刷机或恢复出厂后桌面没装回。**手机数据本身没有丢**——应用、照片都在，只是没有界面把它们摆出来。

## 二、通知栏应急：先弄一条能操作的入口

没有桌面时，通知栏是唯一还能用的界面：

1. 从屏幕顶部下滑打开通知栏，多数系统把设置齿轮放在这里，点进系统设置；
2. 在设置里搜索「USB 调试」并打开（搜不到开发者选项的话，先去「关于手机」连点「版本号」7 次解锁）；
3. 顺便搜「文件」：自带文件管理器若还能进，直接在里面安装 APK 是最快的路。

## 三、电脑 ADB：三条命令按序试

电脑装好 Google 开源的 platform-tools，手机连数据线、开 USB 调试，在工具目录打开命令行（Windows 把 `grep` 换成 `findstr`）：

```bash
adb devices
adb shell pm list packages | grep launcher
```

输出里有 `com.android.launcher3` 说明程序本体还在，多半只是被停用，走第 2 步；什么都没有说明组件被移除，直接走第 4 步。

**第 2 步：被停用的，重新启用**

```bash
adb shell pm enable com.android.launcher3
```

**第 3 步：被按用户卸载的，挂回现有组件**

```bash
adb shell cmd package install-existing com.android.launcher3
```

**第 4 步：组件真没了，装一份完整包**

```bash
adb install -r Quickstep_v3.0.12.apk
```

完整安装包从 [Quickstep 介绍与下载安装](https://quickstep.fewa.skin/) 获取，下载后放到命令行所在目录再执行；出现 `Success` 后按一次 Home 或做上滑手势，桌面应该就回来了。

## 四、没有电脑时的绕路

- **借另一台手机中转**：用能正常用的手机打开上面的站点拿到安装包，通过蓝牙或就近分享传过来；部分系统的分享完成页能直接点「打开」进入安装；
- **兜底方案**：以上全部走完仍不行，只剩恢复出厂（关机后用电源键 + 音量键组合进 Recovery，选清除数据）。它会抹掉应用和数据，动手前尽量把照片、通讯录备份出来。

桌面找回后，如果手势导航（上滑回桌面那条）没反应，按 [全面屏手势设置与失灵排查.md](全面屏手势设置与失灵排查.md) 的顺序检查；想了解这个组件本身的角色，见 [系统桌面组件的作用与常见疑问.md](系统桌面组件的作用与常见疑问.md)。
