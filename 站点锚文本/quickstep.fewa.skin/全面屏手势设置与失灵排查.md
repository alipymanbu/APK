# 全面屏手势设置与失灵排查

> 手势导航的开关位置、每条手势对应什么动作，以及上滑没反应、多任务打不开时按什么顺序查。
> **相关文档**：[系统桌面组件的作用与常见疑问.md](系统桌面组件的作用与常见疑问.md) · [桌面空白应急找回方法.md](桌面空白应急找回方法.md)

## 一、在哪里打开或关闭

原生系统的入口是「设置 → 系统 → 手势 → 系统导航」，二选一：

- **手势导航**：屏幕底部只剩一条横条，所有操作靠滑动；
- **三按钮导航**：底部是返回、主屏幕、最近任务三个键。

不同品牌菜单层级有差异，有的叫「全面屏手势」或「系统导航方式」，找不到就在设置顶部搜「导航」。两种模式随时互切，切换立刻生效，不用重启。

## 二、手势对照

| 手势 | 结果 |
| --- | --- |
| 从屏幕底部上滑 | 回到主屏幕 |
| 底部上滑后停住不松手 | 打开最近任务（多任务卡片） |
| 从左或右屏幕边缘向内滑 | 返回上一级 |
| 沿底部横条向左或右滑 | 在最近两个应用之间快速切换 |
| 多任务里把卡片往上甩掉 | 关闭该应用 |

上滑幅度和停顿时长决定结果：一滑到底是回桌面，中途停一下才出多任务——很多「多任务打不开」其实是松手太快。每条手势的动态演示整理在 [Quickstep 介绍与下载安装](https://quickstep.fewa.skin/) 的手势对照一节，可以对着练。

## 三、手势没反应时按这个顺序查

1. **确认模式**：进导航设置看当前是不是「手势导航」，三按钮模式下上滑当然没反应；
2. **确认默认桌面**：装了第三方桌面并设为默认后，深度手势由默认桌面承接，部分第三方桌面只支持三按钮模式——想用全手势就把默认桌面切回系统桌面；
3. **确认桌面没在崩溃**：手势由 Quickstep 接管，它一崩溃手势跟着失灵，先处理「已停止运行」的弹窗（重启 → 强制停止 → 清缓存 → 系统更新）；
4. **桌面整个没了**：手势和图标全无反应属于桌面组件丢失，直接按 [桌面空白应急找回方法.md](桌面空白应急找回方法.md) 补装。

## 四、底部提示条要不要隐藏

部分系统允许关掉底部那条手势提示横条。它只是视觉提示，隐藏后手势依然有效；但设备手势识别本来就不灵敏的话，留着横条有助于对准起手位置。

## 五、这些疑问顺带说清

- **手势和桌面是两回事但绑在一起**：导航模式在系统设置里，可上滑出多任务这类深度手势由默认桌面执行，所以换桌面可能改变手感；
- **Quickstep 能不能删**：不能也不该删，它是手势与桌面的承载者，原因见 [系统桌面组件的作用与常见疑问.md](系统桌面组件的作用与常见疑问.md)；
- **想确认当前模式**：连电脑 ADB 执行 `adb shell settings get secure navigation_mode`，返回 `2` 是手势，`0` 是三按钮。
