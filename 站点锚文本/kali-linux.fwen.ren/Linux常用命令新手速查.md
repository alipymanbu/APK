## 一、目录与文件：先能在系统里"走路"

```bash
pwd                 # 我在哪
ls -la              # 这里有什么（含隐藏文件）
cd /etc             # 去 etc 目录
cd ..               # 退上一层
cat 文件名          # 看文件内容
less 文件名         # 翻页看长文件（q 退出）
```

新手最常犯的错是 `ifconfig` 与 `ipconfig` 敲混——后者是 Windows 的，Linux 下是 `ifconfig` 或更新的 `ip a`。

## 二、权限与安装：apt 与 sudo 两兄弟

```bash
sudo apt update               # 刷新软件源索引
sudo apt install nmap         # 安装一个工具
sudo apt full-upgrade -y      # 系统级更新（Kali 文档建议装完先跑）
```

- 前缀 `sudo` = 以管理员权限执行；提示输密码时屏幕**不显示任何字符**，输完直接回车；
- `command not found` 先查拼写，再用 `apt search 关键词` 找命令属于哪个包；
- 下载报 `404` 或 `Hash Sum mismatch` 多半是源的问题，重跑 `apt update`，仍不行核对源配置（以 kali.org 文档当前写法为准）。

## 三、网络排查三连

```bash
ping -c 3 1.1.1.1        # 通不通
ip a                     # 网卡与地址
ss -tulnp                # 谁在监听哪些端口
```

DNS 报 `Temporary failure resolving`：能 ping 通 IP 说明是 DNS 问题，换 DNS（如 1.1.1.1、8.8.8.8）再试；ping 都不通就先修网络本身。

## 四、读教程与上机的关系

命令这东西，看十遍不如敲一遍。碎片时间可以先在手机上把章节读顺——比如这份 [kali linux 手机教程应用](https://kali-linux.fwen.ren/) 按主题分章讲基础、命令与工具——到了电脑前再集中上机验证，效率最高。

给自己定的规矩很简单：

1. 每条命令至少在虚拟机里敲通一次；
2. 每个报错都自己先读一遍原文（英文报错搜英文）；
3. 卡死十分钟就跳过，回头再看往往秒懂。
