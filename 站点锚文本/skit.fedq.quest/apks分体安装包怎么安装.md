# apks分体安装包怎么安装

> 从网上拿到的安装文件是 .apks / .apkm / .xapk，点开报「解析错误」？这不是文件坏了，是分体包——系统自带安装器不认识它。这篇讲清来龙去脉与装回去的办法。
> **相关文档**：[安卓应用管理工具能做什么.md](安卓应用管理工具能做什么.md) · [怎么提取手机应用的安装包.md](怎么提取手机应用的安装包.md)

## 一、分体包是怎么来的

2018 年起安卓引入 App Bundle：开发者上传的不再是一个大而全的安装包，而是「基础包 + 按屏幕密度、CPU 架构、语言拆开的分片」，商店下载时按你的设备挑分片拼装。2021 年起，新应用与更新基本都走这套。

分片在本地拼好后可以打成单个文件流转，社区把这种格式叫 .apks；.apkm、.xapk 是类似思路的多分片打包。它们的本质是「一袋安装包」——不是损坏的文件，也不是另一个应用，只是系统安装器只认单个 .apk，直接点开才会报解析错误。

## 二、用什么装回去

需要一个认识分体格式的安装器。以 Skit 为例，3.0 起内置分体包安装器，3.3 起还能从其他应用直接调起，两条路都能走：

**方式 A：从文件管理器调起**

1. 在文件管理器里找到 .apks / .apkm / .xapk 文件；
2. 点开，选择用 Skit 打开；
3. 它解析出包内分片后按提示确认安装。首次这样做，系统会要求授权「安装未知应用」，允许一次即可。

**方式 B：在应用内部安装**

1. 打开 Skit，在工具入口里找到安装器；
2. 浏览到分体包所在目录（下载目录都在列表里）；
3. 选中文件，确认安装，进度跟着系统弹窗走。

安装完成后如果想顺手把这个应用管理起来，Skit 这类工具的介绍与获取入口可以看 [Skit 安卓版介绍站](https://skit.fedq.quest/)。

## 三、装不上时的对照表

| 现象 | 原因与处理 |
| --- | --- |
| 点开提示「解析错误」 | 用分体格式支持的安装器打开，别用系统安装器直接点 |
| 提示与已装应用签名不一致 | 新旧两份包不是同一签名方，只能卸载旧的再装（该应用数据会丢，先确认） |
| 安装到一半失败 | 多半是存储不足，或分片与本机架构不匹配——拿别人机型的分体包本来就可能缺你这台的分片 |
| 一直转圈没反应 | 退出重试一次；仍卡住换一份完整的包再试 |

## 四、两个常见误区

**「转成单个 .apk 就万事大吉」**：部分工具支持把分体包强行合并成单个 .apk，但合并只能保留一套配置分片，换到屏幕、架构不匹配的设备上可能装不上或功能缺失。优先让分体格式原样进原样出。

**「提取出来的也是坏的」**：用管理工具提取按 App Bundle 分发的应用时，导出的同样是 .apks 分体包——这不是提取失败。它与管理工具导出的文件彼此兼容，装回手机的方法就是本文第二节的两种。

分体格式是安卓分发的大势，认识它一次，以后遇到就不会再当坏文件删掉了。
