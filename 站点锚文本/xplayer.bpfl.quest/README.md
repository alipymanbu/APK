# XPlayer 影音手册（xplayer.bpfl.quest）

这里是围绕安卓视频播放器 XPlayer（上架名 Video Player All Format）整理的介绍与使用笔记：它能直接播放 MP4、MKV、AVI、RMVB 等几乎全部本地视频格式，靠硬件加速撑住 4K 片源，还带隐私文件夹、字幕下载、悬浮窗与 Chromecast 投屏。完整的功能速览与安装文件资源入口见 [XPlayer 影音手册站](https://xplayer.bpfl.quest/)。

- [隐私文件夹与本地视频保护.md](隐私文件夹与本地视频保护.md) —— 把私人视频锁起来，以及卸载前必做的一步
