# 全格式视频播放与解码设置

手机存储里最常见的几类视频——手机录制的 MP4、剧集常见的 MKV、早年下载的 AVI 和 RMVB——换播放器经常碰到"格式不支持"。XPlayer（上架名 Video Player All Format）的卖点是把这些格式一并收进支持列表，拿来就播。本篇整理它的格式覆盖与解码设置思路。

## 一、格式覆盖速查

| 手上的文件 | 播放情况 |
| --- | --- |
| MP4 / M4V / MOV | 直接播，手机录制与主流下载视频多为此格式 |
| MKV / TS | 直接播，高清剧集常见；多音轨文件可在菜单里切换音轨 |
| AVI / WMV / RMVB / FLV / 3GP | 直接播，老视频与网络视频常见 |
| 4K / 超高清 | 支持，流畅度取决于机型性能 |

字幕文件（srt、ass 等）不属于视频格式，但同样有配套支持，玩法写在[字幕下载与投屏电视的玩法.md](字幕下载与投屏电视的玩法.md)。

## 二、卡顿、花屏先动解码

播 4K 或高码率片源不顺时的处理顺序：

1. 进播放设置确认「硬件加速」处于开启状态；
2. 仍卡，在硬解与软解之间切换再试——软解更吃处理器，但兼容性好，个别片源硬解异常导致的花屏、绿屏，切软解往往能解决；
3. 低端机型播 4K 吃力属正常，换 1080p 片源立竿见影；伴随发热明显就清后台、降温后再播。

## 三、播放界面上顺手的小功能

- **手势调节**：音量、亮度、进度都能在播放界面滑动调节，误触担忧可用「锁屏」功能锁掉触控；
- **倍速**：0.5 到 2.0 之间调节，网课加速、慢放看细节都靠它；
- **夜间模式**：暗光环境降低刺眼感；
- **快速静音**：来电话或有人说话时一下关掉声音。

想边回消息边看的场景，配合悬浮窗小窗更顺手；后台听剧的设置见[字幕下载与投屏电视的玩法.md](字幕下载与投屏电视的玩法.md)。装包与界面速览可到 [XPlayer 影音手册](https://xplayer.bpfl.quest/)查看。私人视频的管理另见[隐私文件夹与本地视频保护.md](隐私文件夹与本地视频保护.md)。
