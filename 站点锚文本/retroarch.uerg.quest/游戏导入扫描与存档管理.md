# RetroArch 游戏导入扫描与存档管理

> 本篇讲把自备的游戏文件放到手机哪个位置、怎么扫描生成带封面的游戏列表，以及存档文件存在哪、换手机怎么把整套进度带走。
> **相关文章**：[模拟核心选择与下载](模拟核心选择与下载.md) · [虚拟按键与手柄配置](虚拟按键与手柄配置.md)

## 一、游戏文件放在哪

RetroArch 不提供游戏本体，需要自备拥有使用权利的游戏文件。两个原则：

- **放它能看到的地方**：安卓 11 以后 `Android/data` 这类目录在部分手机上无法用普通文件管理器浏览，最省事的做法是在内部存储根目录自建文件夹，例如 `RetroArch/roms/`，再按主机分子文件夹（GBA、SNES、PS1……）；
- **保留原始文件名**：扫描靠文件名和校验值对号入座，乱改名的游戏容易匹配不上。

`.zip`、`.7z` 压缩包可以直接扫描加载，不必解压；PS1 建议优先找 `.chd` 整盘镜像，省空间也免换盘。

## 二、扫描前的准备与扫描方法

1. 装好对应主机的核心（见[模拟核心选择与下载](模拟核心选择与下载.md)），没装核心扫出来也玩不了；
2. 主菜单 → **Online Updater** → **Update Databases**，顺手把 **Update Core Info Files** 也点了；
3. **Playlists** → **Import Content** → **Scan Directory**，选中放游戏的文件夹确认，大合集扫描要几分钟。

扫描默认是严格模式：文件必须在数据库里精确对上号才进列表。扫完发现缺游戏，用 **Manual Scan** 放宽条件再扫一遍，或用 **Scan File** 逐个指定；偶尔玩一次可以 **Load Content** 直接加载，不建列表。

多盘游戏合并成单个 `.chd` 后当一张盘玩最省心；逐盘文件的在快速菜单 → **Disc Control** 里换盘。

## 三、给列表补封面

主菜单 → **Online Updater** → **Playlist Thumbnails Updater**，选中要补图的主机列表即可联网下载封面。图包不小，可以只挑常玩的列表下载；手动扫描生成的列表命名对不上缩略图库时会一直是灰格子，不影响游玩。

## 四、存档目录与换机迁移

两套存档的位置都在 RetroArch 自己的目录下：游戏内存档（`.srm`）与即时存档（`.state`）分开放。换手机时把整个 RetroArch 目录（含 roms、saves、states）拷到新机同样位置，进度原样接上；跨核心的即时存档不通用，迁移后用游戏内存档接续最稳。

## 五、装好了从哪开始

应用还没装的话，先看[安卓版安装与首次启动](安卓版安装与首次启动.md)；操作键位不顺手去看[虚拟按键与手柄配置](虚拟按键与手柄配置.md)；想按页面图文对照操作，可以到 [retroarch 安卓版介绍站](https://retroarch.uerg.quest/) 把三步流程串起来走一遍。
