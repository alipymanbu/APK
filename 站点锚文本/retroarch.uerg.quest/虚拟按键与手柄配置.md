# RetroArch 虚拟按键与手柄配置

> 本篇讲手机上两种操作方式怎么调：屏幕虚拟按键的布局与透明度、外接手柄的自动识别与重映射，以及即时存档等快捷键的绑定建议。
> **相关文章**：[模拟核心选择与下载](模拟核心选择与下载.md) · [游戏导入扫描与存档管理](游戏导入扫描与存档管理.md)

## 一、屏幕虚拟按键（触屏覆盖层）

没接手柄时，游戏画面上会叠一层虚拟按键。相关开关在游戏运行中调：

1. 游戏中唤出**快速菜单**（Quick Menu，默认返回键或手势可达，以你的快捷键设置为准）；
2. 进入 **Controls** → **Touchscreen Overlay**；
3. 这里可以切换预设布局、调整按键透明度与大小，或整个关掉。

横版街机游戏可以换成六键布局；嫌按键挡画面就调低透明度，接了手柄直接关掉覆盖层，画面干净得多。

菜单里的确认/取消键位是另一套：**Settings → Input → Menu Controls → Menu Swap OK & Cancel Buttons**，觉得菜单确认键反直觉就在这里调。

## 二、外接手柄

蓝牙手柄和 USB 手柄（含 Type-C 直插）流程一致：

1. 在系统设置里配对手柄，确认系统层面能用；
2. 打开 RetroArch，进 **Settings → Input → Auto Config**，开启后它会按内置配置表自动认出常见品牌手柄的键位；
3. 进游戏逐个试键，个别不对的在 **Controls** 里重映射并保存。

重映射分三个层级：全局、按核心、按游戏。只给某个游戏改键，就在那个游戏的快速菜单 → Controls 里改并保存为该游戏专用，不污染全局设置。

## 三、快捷键绑定建议

手机上没有键盘，组合键全靠 **Settings → Input → Hotkey Binds**。建议优先绑好：

| 功能 | 用途 |
| --- | --- |
| 快捷键启用键 | 其他快捷键都要先按住它，防误触 |
| 保存 / 读取即时存档 | 随时存进度、回进度 |
| 快进 | 跳过开场动画、练级 |
| 退出游戏 | 从游戏返回主菜单 |

没有手柄时，虚拟按键区通常留了一个可自定义的快捷键按钮，在覆盖层设置里绑定。

## 四、两套存档别混淆

- **游戏内存档**：游戏自带的存档，随进度走；
- **即时存档（Save State）**：把当前画面瞬间拍下来，任何时刻可存可读，只对当前核心有效。

日常两种都建议用：游戏内存档保底，即时存档应付「打 BOSS 前先存一下」。存档目录与换机迁移的细节在[游戏导入扫描与存档管理](游戏导入扫描与存档管理.md)里展开；还没装好的先看[安卓版安装与首次启动](安卓版安装与首次启动.md)，也可以到 [retroarch 整理站](https://retroarch.uerg.quest/) 把安装与配置连起来过一遍。
