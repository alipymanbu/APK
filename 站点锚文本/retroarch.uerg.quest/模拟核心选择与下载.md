# RetroArch 模拟核心选择与下载

> 本篇讲 RetroArch 的「核心」机制是什么、怎么在手机上把核心装进去，以及各台经典主机对应哪个口碑核心，帮你跳过逐个试错的阶段。
> **相关文章**：[安卓版安装与首次启动](安卓版安装与首次启动.md) · [游戏导入扫描与存档管理](游戏导入扫描与存档管理.md)

## 一、核心是什么，为什么刚装好什么都玩不了

RetroArch 本体只是一个「壳」，真正干模拟活的是一个个叫**核心（Core）**的插件：FC 有 FC 的核心，PS1 有 PS1 的核心。刚装好的 RetroArch 一个核心都没有，所以什么都玩不了——先把目标主机对应的核心下载下来，这是装好之后的第一个动作。

## 二、下载核心的步骤

1. 回到主菜单，选 **Load Core**（加载核心）；
2. 选 **Download a Core**（下载核心）；
3. 列表按主机英文名分组排列，例如 `Nintendo - Game Boy Advance` 分组下就是 GBA 核心，点一下即开始下载。

核心可以同时装多个、随时卸载重下，互不干扰。下载核心要访问 Libretro 的构建服务器，速度慢或一直转圈多半是网络问题，换个网络环境重试；核心列表本身很短、只有几十个，说明装的是受限渠道版本，换安装包渠道重装即可。

## 三、各主机推荐核心

同一台主机往往有好几个核心，性能与兼容性差别很大。手机上口碑较好的常用组合：

| 主机 | 推荐核心 | 备注 |
| --- | --- | --- |
| FC / NES | Nestopia UE、FCEUmm | 轻量流畅 |
| 超任 / SNES | Snes9x | 速度快，手机首选 |
| Game Boy / GBC | Gambatte、SameBoy | 精准还原 |
| GBA | mGBA | 手机上的默认选择 |
| 世嘉 MD / GG | Genesis Plus GX | 世嘉全能 |
| PS1 | PCSX-ReARMed | 移动端最成熟，多数游戏不需要 BIOS |
| N64 | Mupen64Plus Next | 部分游戏需逐个调插件 |
| PSP | PPSSPP | 新机型体验好 |
| Dreamcast | Flycast | 性能要求较高 |
| NDS | melonDS、DeSmuME | 双屏依赖触屏或外接手柄 |
| 街机 | MAME 2003 Plus、FBNeo | 按游戏年代选 |

高画质主机（N64 及以后）对手机芯片要求直线上升，老机型卡顿先换低配核心再调设置。

## 四、更新与卸载

- **更新**：主菜单 → **Online Updater** → **Update Installed Cores**，一键把已装核心升到最新；
- **卸载**：Load Core → Installed Core List 里选中卸载，删错了重新下载即可。

核心装好后，下一步是把游戏文件导进来建列表，见[游戏导入扫描与存档管理](游戏导入扫描与存档管理.md)；还没装应用的先看[安卓版安装与首次启动](安卓版安装与首次启动.md)，或直接到 [retroarch 安卓版资源站](https://retroarch.uerg.quest/) 按流程操作。
