# 安卓滚动歌词应用怎么选

> 本篇从选型角度拆解安卓上的滚动歌词应用：先分清"整行滚动"与"逐字歌词"两种形态，再看歌词来源、翻译、设备要求这些实际差异，最后给一个按需求对号入座的结论。
> **相关文档**：[手机上怎么看Spotify歌词](手机上怎么看Spotify歌词.md) · [Spotify歌词翻译怎么显示](Spotify歌词翻译怎么显示.md)

---

## 一、先分清两种歌词形态

安卓上的歌词展示基本分两派：

- **整行滚动**：一句一句翻，当前句高亮，胜在稳定、省电、几乎不挑歌；
- **逐字歌词（卡拉OK式）**：字跟着唱到哪亮到哪，观感好，但对歌词数据要求高，冷门歌经常没有。

选之前先想清楚自己要哪种。很多 disappointment 其实是拿"逐字"的期待去要求一个"整行滚动"的工具。

## 二、对比的四个维度

| 维度 | 要看什么 |
| --- | --- |
| 歌词来源 | 单一来源还是多来源共享词库，冷门歌命中率差很多 |
| 翻译支持 | 词库版本自带翻译，还是支持手动导入带翻译的版本 |
| 配套生态 | 手机端之外的电脑端能不能导入、修正歌词 |
| 系统要求 | 模糊背景之类的效果有没有系统版本门槛 |

## 三、以 Lyricify Mobile 为例过一遍

拿一个具体对象来看会更直观。Lyricify Mobile 是 WXRIW 歌词系列里的移动端成员，只服务 Spotify 用户：

- **形态**：整行滚动，官方口径是没有加入逐字歌词的计划——想逐字得回到 Windows 上的 Lyricify 4；
- **词库**：与电脑版共用一份歌词库，词源覆盖 QQ 音乐、网易云音乐、酷狗、MusixMatch、Apple Music 等平台；
- **翻译**：词库版本自带翻译就显示，没有的可以电脑端导入带翻译的版本；
- **门槛**：安卓 5.0 以上可装；背景模糊效果要 Android 12 以上才看得到。

它的功能边界与界面实拍，[Lyricify 手机版介绍站](https://lyricify.fewf.ren/) 整理得比较全，选型前值得过一眼。

## 四、按需求对号入座

- 只想在手机上看清 Spotify 正在放的歌的词 → 整行滚动类完全够用，Lyricify Mobile 这类工具就是为此设计的；
- 一定要逐字卡拉OK效果 → 找电脑端方案，或者接受逐字歌词在手机上覆盖率的现实；
- 外语歌多、需要翻译 → 优先选能导入带翻译版本的，别指望每个源都自带；
- 用 iPhone / iPad → 选型前先确认工具在 iOS 上的安装方式，有些并不在应用商店上架。
