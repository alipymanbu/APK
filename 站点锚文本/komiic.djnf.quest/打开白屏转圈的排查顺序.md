# 打开白屏转圈的排查顺序

> 能装、能打开，就是一直转圈、白屏、图片出不来——这类问题九成出在网络与缓存。这篇按症状分流，给出从轻到重的排查顺序。
> **相关文档**：[追更連載漫画的完整动线](追更連載漫画的完整动线.md) · [安卓安装包转存与来源权限设置](安卓安装包转存与来源权限设置.md)

---

## 一、先分清卡在哪一层

| 症状 | 多半在哪一层 |
| --- | --- |
| 打开就白屏，内容一直拉不动 | 网络或缓存 |
| 只有某一页空白、一直转 | 单章图片加载 |
| 装不上、提示解析包出错 | 安装包本身，另见安装那篇 |
| 搜不到想看的作品 | 搜索写法 |

## 二、白屏转圈：按顺序做

1. **确认网络本身是通的**——同一个网络下开个别的网页试试，通了再往下；
2. **切网络**——Wi-Fi 和手机流量互换一次；家里路由器可以断电三十秒再通电；
3. **清应用缓存**——系统设置 → 应用 → Komiic → 存储 → 「清除缓存」。注意只清缓存，别点「清除数据」，登录状态和本地记录会一起被清掉；
4. **强停再开**——应用信息页点「强制停止」，重新打开；
5. **重启手机**——把后台残留的异常状态清掉。

做到哪一步恢复了就停，不必全做一遍。

## 三、应用内的两个自救入口

较新版本的更新日志里专门修过中国线路：「重新连线」会真的重建线路，卡住时能自动恢复；「网路诊断」也改成按实际连线测试判定，不再一律显示正常。这两项在设置或个人页面里找。你装的版本若没有这两个入口，按上面第二节的顺序处理即可，效果等价。

网页版连不上时还有一个开关可切：主站为 komiic.com，中国大陆另有 komiic.cc 入口，连接不稳时用它代替。

## 四、只有某一页加载不出来

漫画页是边读边拉的图片，网络一抖就表现为某一页空白或一直转——把那一章退出重进，通常会重新拉取。缓存积久了也会让旧章节显示异常，清一次缓存再打开同一话验证。手机剩余存储太少同样会卡，清出几个 GB 的空闲空间再试。

只有某一部作品异常、其他都正常的话，是这部作品自身的数据问题，换个章节或隔天再看。

排查之外，首页的常见问题区还收了版本号对不上、账号要不要注册等几条高频疑问，见 [Komiic 漫画追更指南](https://komiic.djnf.quest/)；装不上则是另一类问题，处理办法在[安卓安装包转存与来源权限设置](安卓安装包转存与来源权限设置.md)里。
