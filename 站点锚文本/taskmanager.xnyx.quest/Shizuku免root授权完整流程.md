# Shizuku 免 root 授权完整流程

> 想在安卓上用需要系统级权限的工具又不想解锁 root，Shizuku 是目前最顺的一条路。本篇按「装 → 启动 → 授权」把整条链走一遍，并说清重启后失效这种最常见的坑。
> **相关文档**：[安卓查看进程CPU占用的几种办法.md](安卓查看进程CPU占用的几种办法.md) · [结束后台应用被自动拉起怎么办.md](结束后台应用被自动拉起怎么办.md)

---

## 一、Shizuku 是干什么的

安卓的沙箱机制让每个应用只能看见自己：读不到别的应用占了多少 CPU，更没权限把别人结束掉。Shizuku 是一个独立的开源项目，思路是借 adb 或 root 起一个常驻服务，让被授权的应用经由这个服务去调用系统接口——效果接近 root，但手机不需要解锁。

很多进阶工具都走这条路：进程监控、批量停用应用、自定义桌面……它们的共同前提都是 Shizuku 处于「正在运行」状态。服务没起来，这些工具打开就是空面板或直接报错。

## 二、先把它装上

Shizuku 本体是个普通应用：在 Google Play 搜包名 `moe.shizuku.privileged.api`，或到项目的 GitHub 发布页下载 APK，常规安装即可。装完先别急着点，启动方式取决于你的机型，见下一节。

## 三、三种启动方式，按机型对号

| 方式 | 适合谁 | 重启后 |
| --- | --- | --- |
| root 启动 | 已解锁 root 的设备 | 服务保持有效（是否开机自启看 root 管理器设置） |
| 无线调试配对 | 无 root，Android 11 及以上 | 每次重启后要重新点一次「启动」 |
| 电脑 adb 启动 | 无 root，Android 10 及以下 | 每次重启后要连电脑重跑一次 |

**root 启动**最省事：打开 Shizuku 点「启动」，在授权弹窗里同意即可。

**无线调试配对**是无 root 机型的主路径，全程不用电脑：

1. 「设置 → 关于手机」连点版本号 7 次，打开开发者选项；
2. 进开发者选项，打开「USB 调试」，再打开「无线调试」；
3. 在 Shizuku 里进入配对流程；
4. 回到系统的无线调试页面，点「使用配对码配对设备」，记下 6 位配对码和端口号；
5. 把配对码填进 Shizuku 通知栏的输入框，提示配对成功；
6. 回到 Shizuku 点「启动」，状态变成「正在运行」即完成。

**配对只需做一次**，以后重启手机只需要重复第 6 步。无线调试启动失败时，把开关关掉再开一次通常就能解决。

**电脑 adb 启动**适合老系统：电脑装 Google 的 SDK Platform Tools，手机连电脑并允许 USB 调试，然后在终端执行 Shizuku 界面给出的那条 `adb shell sh /sdcard/.../start.sh` 命令。窗口别关，下次启动还要用。

## 四、把权限授给具体应用

Shizuku 跑起来只是修好了「路」，具体应用要拿到权限还差一步授权：

1. 确认 Shizuku 主界面显示「正在运行」；
2. 打开要用权限的那个应用，首次进入时会弹出 Shizuku 的授权请求，选「始终允许」；
3. 不小心点了拒绝也没关系：到 Shizuku 的「已授权应用」列表里重新勾上即可。

以安卓上的开源任务管理器 [TaskManager 安卓版](https://taskmanager.xnyx.quest/)为例：它依赖 Shizuku 读取全局的 CPU、内存与进程数据，授权没完成时打开只会看到「Shizuku not running」的空面板——先走完上面的第 2 步，面板才有内容。

## 五、最常踩的坑：重启后「突然没数据了」

不是应用坏了，是非 root 方式启动的 Shizuku 服务不跨重启。习惯上记住一句话：**重启手机后，先开 Shizuku，再开依赖它的应用**。另外别卸载 Shizuku、别关开发者选项里的无线调试，否则整条链路会一起断。

配对码输错、授权列表显示数量不对这类小问题，把 Shizuku 从后台划掉重进一次，多数就正常了。
