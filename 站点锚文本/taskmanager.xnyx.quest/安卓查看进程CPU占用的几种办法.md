# 安卓查看进程CPU占用的几种办法

> 手机发热、掉电快，想知道到底是谁在吃 CPU？本篇把安卓上能看进程占用的几条路摆在一起：自带的、借权限工具的、连电脑的，各自能看到哪一步，一次说清。
> **相关文档**：[Shizuku免root授权完整流程.md](Shizuku免root授权完整流程.md) · [结束后台应用被自动拉起怎么办.md](结束后台应用被自动拉起怎么办.md)

---

## 一、先说结论

偶尔查一次，用系统自带的「运行中的服务」就够了；想持续盯曲线、看每颗核心和每条进程的细节，就用 Shizuku 配套的监视器工具；连电脑的 adb 方式适合动手能力强的人做一次性深查。

## 二、办法一：开发者选项里的「运行中的服务」

这是系统内置的入口，不用装任何东西：

1. 「设置 → 关于手机」连点版本号 7 次，开启开发者选项；
2. 进「系统 → 开发者选项 → 运行中的服务」；
3. 列表里能看到正在运行的服务与各自消耗的内存，点开还能看子进程，菜单里也能切换到「缓存的后台进程」。

它的局限也明显：只有一份静态清单，内存是唯一给出来的占用维度，没有随时间变化的 CPU 曲线，也看不到 GPU 这类扩展信息。而且入口藏在开发者选项里，开一次要专门跑一趟。另外提醒一句：在这里停止某个子进程可能连带影响它的主进程，下手前想清楚。

## 三、办法二：Shizuku 系的监视器工具

想要桌面系统监视器那种体验——实时曲线、按进程排序、点开看优先级和线程数——就得让工具拿到系统级权限，Shizuku 是免 root 的标准解法（完整配置见 [Shizuku免root授权完整流程.md](Shizuku免root授权完整流程.md)）。

这条路能看到的粒度和自带入口完全不是一个量级：

| 维度 | 运行中的服务 | Shizuku 系监视器 |
| --- | --- | --- |
| CPU 占用 | 看不到 | 每进程百分比 + 实时曲线 |
| 内存 | 服务级 | 进程级，含 SWAP |
| 进程详情 | 仅子进程列表 | 优先级（Nice 值）、线程数、启动时间、可执行路径 |
| 直接结束进程 | 停止服务（可能影响主进程） | 可结束单个应用或进程 |

这一类里的代表是 [安卓任务管理器 TaskManager](https://taskmanager.xnyx.quest/)：开源、界面按 CPU / RAM / GPU 分页签，进程页里每个应用一行内存与占用，点进详情还能看到它从几点起跑了多久——排查「到底谁在后台干活」时特别有用。

## 四、办法三：连电脑用 adb

手机连电脑、开着 USB 调试，用 `adb shell top` 这类命令能直接读进程表，配合 `sort` 参数还能按占用排序。适合做一次性深查，缺点是要装 SDK Platform Tools、敲命令，日常用不顺手，这里不展开。

## 五、怎么选

- 只想知道「现在谁最吃资源」：办法一，两分钟的事；
- 想长期观察、找出间歇性发热的元凶：办法二，配一次 Shizuku，以后打开就有数据；
- 排查某个具体进程的行为来源：办法二看详情，必要时办法三兜底。

查明元凶之后怎么处理，是另一件事：直接结束可能治标不治本，先看[结束后台应用被自动拉起怎么办.md](结束后台应用被自动拉起怎么办.md)再动手，少走弯路。
