# 从安装到第一次对话要几步：RikkaHub 上手路径

> 本篇讲 RikkaHub 的安装与首次配置路径：从哪里拿安装包、怎么装进安卓手机、第一次对话前要配哪几样；应用本身的能力全景见 [安卓多模型聊天客户端怎么样](安卓多模型聊天客户端怎么样.md)。

---

RikkaHub 是原生安卓应用，装起来不复杂，真正的「门槛」只有一个：第一次对话前需要配置至少一个 AI 服务商。下面按实际顺序拆开讲。

## 第一步：拿到安装包

安装包在 [RikkaHub 介绍站](https://rikkahub.gkhf.beer/) 的下载页有现成入口，走夸克网盘分享：打开链接、转存到自己的网盘，再把 APK 文件取出到手机存储。这种方式的好处是包体长期有效，不用到处找版本。

## 第二步：装进手机

1. 在文件管理器里点开 APK，系统提示「未知来源」时按弹窗指引允许该来源安装；
2. 等安装完成，桌面出现 RikkaHub 图标即可打开。

不同品牌的安卓手机「允许未知来源」的入口略有差异，但都在安装弹窗里能直接跳过去开。

## 第三步：配置一个服务商

这一步决定能不能聊起来：

1. 打开应用，从侧边栏进「设置」→「提供商」；
2. 内置了主流服务商预设（OpenAI、Gemini、Claude、DeepSeek、硅基流动等），选你手上有 Key 的那家，直接填入 API Key；
3. 用的不是预设服务商就点右上角新建，协议选 OpenAI 兼容，填上对方给的 Base URL——OpenRouter、本地 Ollama、各类中转都属于这种接法；
4. 进服务商详情页拉取模型列表，勾选要用的模型。

密钥只保存在设备本地，请求直连所配置的地址，不用担心被应用方转手。

## 第四步：发第一条消息

回到设置页，进「默认模型和提示词」，给对话等功能选好默认模型（辅助功能可以配便宜些的快模型），然后回主界面：

- 底部输入框打字发送，回复是流式输出的；
- 底栏左侧可以随时换模型，同一个问题切到另一家模型再问一遍，答案对比一目了然。

试一句「介绍一下你能帮我做什么」，感受一下手头这家模型的水准，再开始正经任务。
