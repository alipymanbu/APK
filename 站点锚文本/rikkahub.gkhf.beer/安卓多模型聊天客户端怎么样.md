# 安卓多模型聊天客户端怎么样：RikkaHub 能力全景

> 本篇讲 RikkaHub 这款开源安卓 AI 聊天客户端的定位、核心能力与适用人群；上手安装路径见 [从安装到第一次对话要几步](从安装到第一次对话要几步.md)，工具扩展玩法见 [给AI接上工具和实时信息](给AI接上工具和实时信息.md)。

---

RikkaHub 是一款在 GitHub 上开源的安卓 AI 聊天客户端，用 Kotlin 和 Jetpack Compose 原生构建。它要解决的问题很具体：手机上同时用着好几家大模型——OpenAI 的 GPT、Google 的 Gemini、Anthropic 的 Claude，再加 DeepSeek、硅基流动这些国产服务——每家装一个 App，密钥各存一份，切换起来非常碎。RikkaHub 把这些服务商全部收进同一个对话界面，配置一次，聊天时随手换模型。

## 它和「每家装一个 App」的区别

- **一处配置，随聊随切**：每个服务商就是一张配置卡片，填一次 API Key 之后，对话底栏的模型选择器里随时切换，不用退出应用。
- **密钥留在手机里**：API Key 只保存在设备本地，请求直连所配置的服务商地址，应用方不经手。
- **额度自己说了算**：应用本身开源免费，对话消耗的是各家的 API 用量，用哪家、用多少、什么时候换，都由自己决定，没有订阅捆绑。
- **界面跟手**：遵循 Material You 设计规范，支持深色模式和动态取色，原生开发的手感在滑动的流畅度上能直接感受到。

## 能力全景

| 方向 | 具体 |
| --- | --- |
| 服务商接入 | OpenAI（Chat Completions 与 Responses 两种接口）、Google Gemini、Anthropic Claude、一切 OpenAI 兼容端点（OpenRouter、Ollama 本地模型、自建中转） |
| 工具调用 | 内置 Model Context Protocol（MCP）支持，SSE 与 Streamable HTTP 两种传输方式，可按工具开关、敏感操作执行前确认 |
| 信息时效 | 集成 Exa、Tavily、Brave 等搜索引擎做联网增强，回答可以落在最新信息上 |
| 编辑体验 | 消息分支（任何回复处都能分叉探索）、智能记忆、完整 Markdown 渲染（代码高亮、LaTeX、表格、Mermaid 流程图） |
| 进阶玩法 | 手机里基于 proot 的 Linux 工作区（免 root、内置终端）、聊天中直接绘制折线 / 柱状 / 散点图、二维码分享提供商配置 |

## 什么人适合用

- 手里已经有多家服务商的 API Key，想让它们在同一个界面里排队的重度使用者；
- 想在手机上体验 MCP 工具调用、Agent 任务的折腾党——Linux 工作区不需要 root 就能跑；
- 在意密钥与对话数据的存放位置、更愿意直连服务商的隐私敏感型用户。

如果你还在挑工具，可以先到 [RikkaHub 介绍站](https://rikkahub.gkhf.beer/) 看真机截图与安装入口，再决定要不要把它请进手机。
