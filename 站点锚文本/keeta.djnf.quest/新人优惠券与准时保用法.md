# Keeta 新人优惠券与准时保用法

> 本篇讲 Keeta 新用户能拿到哪些优惠、怎么用才不浪费，以及「准时保」超时补偿的判定规则。下单前的机制都在这里。
> **相关文档**：[点餐下单到收餐流程](点餐下单到收餐流程.md) · [配送范围与支付方式说明](配送范围与支付方式说明.md)

## 一、券从哪里来

Keeta 走「不用买会员、直接发券」的路子，手里能有的券大致四个来源：

1. **迎新券包**：新注册用户可领优惠券礼包。刚进入香港市场时公布的礼包价值为 300 港元，内含 50 港元现金券、无门槛体验券与多张免运费券；礼包内容随活动期变化，以注册当时应用内显示为准。
2. **邀请奖励**：邀请新用户注册、对方 7 日内下单，邀请人可得一张 50 港元大额满减券。
3. **平台活动**：「日日有着数」每日随机发券、阶段性免运费活动轮着来；免运费券面额按送餐距离计算，活动期公布的单笔最高可省 45 港元。
4. **商户折扣**：店内页的折扣菜品与满减活动，能否与平台券叠加看结算页提示。

领券入口集中在三处：首页优惠位、「我的 – 优惠券」、下单结算页的券包列表。

## 二、券怎么用才不浪费

结算页勾券时按这四条判断：

| 情况 | 处理 |
| --- | --- |
| 券有最低消费门槛 | 先看订单金额够不够门槛，差一点就凑单或换张券 |
| 券限指定餐厅或品类 | 换店后券置灰就是这个原因 |
| 免运费券与小额订单 | 运费高于节省金额时优先用免运费券 |
| 多张券 | 通常一笔订单只勾一张，以结算页允许的为准 |

券只能在有效期内按面额条件使用，过期不补。凑门槛时记得把每单 2 港元的平台费与浮动运费一起算进「够不够」，别只看餐品小计。

## 三、一人饭堂：一个人吃也划算

这是 Keeta 专为一食客场景开的专区，特点是一价全包：标价把餐费和运费算在一起，不用再另付配送费。上线初期的公开口径是 60 港元上下就能点到（含运费），专区内有 KFC、南记、板长寿司等连锁，也有本地小店。一个人点餐、不想被运费和最低消费卡住时，直接从首页进专区挑，看到的价格基本就是最后付的钱（用券另算）。

## 四、准时保：超时了会赔什么

准时保是 Keeta 的履约保障，下单即自动获得、不用付费。实际送达时间超出结算页预计的最迟送达时间后，按超时时长补偿无门槛优惠券，约 24 小时内自动发进券包：

| 超出预计最迟时间 | 补偿（港元券） |
| --- | --- |
| 15 分钟起 | 10 |
| 20 分钟起 | 20 |
| 30 分钟起 | 50 |
| 60 分钟起 | 100 |

三点注意：

- 补偿发的是优惠券不是现金，下次下单时用掉；
- 判定基准是「预计最迟送达时间」，高峰期预计时间偏晚属正常，它同时决定补偿起点；
- 档位金额是该平台进入香港时公布的规则，后续可能调整，以订单页与券包当时显示为准。
