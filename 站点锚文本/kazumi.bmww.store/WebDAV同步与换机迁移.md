# Kazumi WebDAV 同步与换机迁移

> 这篇讲 Kazumi 的数据存在哪、怎么用 WebDAV 把追番与观看记录同步到多台设备，以及换手机、卸载重装时怎么不丢数据。
> **相关文档**：[时间表与追番管理](时间表与追番管理.md) · [规则导入与视频源配置](规则导入与视频源配置.md) · [播放设置与画质调优](播放设置与画质调优.md)

## 一、数据默认在哪

Kazumi 不设账号体系。追番清单、观看历史、观看统计默认**只存在本地设备**：

- 覆盖升级（同一个包名直接装新版本）数据保留；
- **卸载应用等于清掉这些本地数据**——卸载前先把同步配好。

## 二、WebDAV 同步：自己选服务器

同步不走任何账号，走的是 WebDAV 协议——你自己填一台 WebDAV 服务器（Nextcloud、ownCloud 或任何兼容服务都行）。设置项在偏好设置的 WebDAV 同步一节：

| 设置项 | 说明 |
| --- | --- |
| 连接你的云盘 | 填服务器地址、用户名、密码或应用授权码 |
| 启用 WebDAV | 总开关，默认关闭 |
| 观看记录 | 同步播放进度与历史，默认关闭 |
| 收藏 | 同步所有追番分类 |
| 弹幕屏蔽词 | 同步你设置的屏蔽词 |

用法：两台设备填**同一个服务器与账号**，把开关打开，进度和收藏就会往同一份数据上合并。

## 三、换手机的标准动作

1. 旧机：配好 WebDAV 并打开同步，等观看记录与收藏推完；
2. 新机：装好应用，登录同一台 WebDAV 服务器，打开同步，数据接管；
3. 规则不跟数据走也无妨——装完从规则仓库重装一遍即可，步骤见 [规则导入与视频源配置](规则导入与视频源配置.md)。

## 四、Bangumi 同步（可选）

偏好设置里另有 **Bangumi 同步**（修改追番状态时同步到 Bangumi），默认关闭；本来就用 Bangumi 记录追番的人再开，两者互不冲突。
