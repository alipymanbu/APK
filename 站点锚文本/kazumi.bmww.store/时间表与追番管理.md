# Kazumi 时间表与追番管理

> 这篇讲怎么把「追番」这件事管起来：每周更新时间表、五档追番状态、观看统计，以及搜索筛选的几个实用按钮。
> **相关文档**：[规则导入与视频源配置](规则导入与视频源配置.md) · [播放设置与画质调优](播放设置与画质调优.md) · [WebDAV 同步与换机迁移](WebDAV同步与换机迁移.md)

## 一、搜索与筛选

主页左上角放大镜输入番名回车即可搜索。结果页有两个按钮决定你看到什么：

- **排序方式**：按热度、排名、评分、匹配程度排；
- **筛选番剧**：按题材标签、放送时间、评分与排名过滤。

搜索依赖已启用的规则——规则没装或失效时搜索会空手而归，先检查规则再怀疑软件（排查思路见 [规则导入与视频源配置](规则导入与视频源配置.md)）。

## 二、时间表：这周哪天更新什么

主页 → `时间表`，按星期序列查看本周每天更新的番剧：

- 上方星期序列切到具体某天；
- 左上角 `切换放送季度`，追旧季度或看新季度排期；
- 右上角 `排序与筛选`，可以「隐藏看过」「隐藏抛弃」「保留正在追的」，把时间表过滤成只看你关心的那批。

追新番最顺的用法：把时间表钉进每天的习惯，周四开的番周四看，更新一集补一集。

## 三、五档追番状态

在番剧详情页可以打标记，一共五档：

| 状态 | 用在哪 |
| --- | --- |
| 在看 | 正在追、还没完结的 |
| 想看 | 立了 flag 还没开始的 |
| 看过 | 已经补完的 |
| 搁置 | 暂时不想追、又舍不得删的 |
| 抛弃 | 看了几集不合适的 |

详情页展示的番剧资料（简介、标签、吐槽、角色、关联）来自 Bangumi 数据，右上角按钮可跳到对应的 Bangumi 页面看更全的资料——挑番时先看这里，比只看封面准。

打完标记，主页 → `追番` 就是你的清单页；点卡片上的 `观看状态` 按钮可以直接改标记，不用点进详情。

## 四、历史记录与观看统计

- **历史记录**：`我的` → `历史记录`，记着你看过的每一集，续播从这里进；
- **观看统计**：`我的` 页上方展示 `看过番剧` 数与 `观看集数`，纯粹是个数字概览。

这些都默认存在本地设备，不登录任何账号；想跨设备接着看，走 WebDAV 同步，见 [WebDAV 同步与换机迁移](WebDAV同步与换机迁移.md)。

## 五、从安装到开播

还没装的朋友，[Kazumi 观测站](https://kazumi.bmww.store/) 首页有功能清单、界面截图与安卓版安装文件资源入口；装好后按上面第二节配好规则，时间表立刻就能用起来。
