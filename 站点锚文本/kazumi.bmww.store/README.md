## 一句话认识 Kazumi

Kazumi 是一款以 GPL-3.0 协议开源的番剧播放器，本身不存任何视频：搜索、线路、弹幕、进度全靠「规则」驱动，导入规则后才成为可用的追番工具。想直接看它的功能清单与界面截图，去 [Kazumi 观测站](https://kazumi.bmww.store/) 翻一遍即可。
