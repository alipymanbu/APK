# NewPipe 后台播放与悬浮窗怎么开

> NewPipe 有三种播放形态：全屏观看、后台只听声音、悬浮窗小窗。这篇讲清三种形态怎么切、各要给什么权限，以及「一锁屏就没声」该怎么排查。
> **相关文章**：[订阅与数据怎么备份搬家](订阅与数据怎么备份搬家.md) · [离线缓存与下载设置](离线缓存与下载设置.md)

---

## 一、形态按钮在哪

打开任意视频进入播放页，点一下屏幕唤出控制条，形态按钮就在暂停键附近。三种形态随时互切，进度不丢：

| 形态 | 画面在哪 | 典型场景 |
| --- | --- | --- |
| 普通 / 全屏 | 应用内 | 正常看视频，可横屏全屏 |
| 后台播放 | 只有通知栏控制条 | 听歌、听播客、锁屏听 |
| 悬浮窗 | 小窗浮在其他应用上 | 一边聊天一边看 |

切到后台播放后直接锁屏或退出应用都行，声音继续——它只拉音频流，流量和耗电都比挂着画面小得多。

## 二、两个权限要给对

后台播放依赖两处系统权限，缺一个就会表现成「一锁屏就没声」：

1. **通知权限**：后台播放靠一条常驻通知控制（上一首 / 暂停 / 下一首）。首次使用时弹的「允许发送通知」要点允许；已经拒绝的，到 `设置 → 应用 → NewPipe → 通知` 里打开。
2. **悬浮窗权限**：只影响悬浮窗形态，路径是 `设置 → 应用 → NewPipe → 显示在其他应用上层`。没给权限时切悬浮窗会被系统静默拦下，看起来就像「按钮没反应」。

## 三、悬浮窗小技巧

- 拖小窗边缘缩放，拖标题栏挪位置；
- 点小窗展开回应用，点关闭结束播放；
- 悬浮窗在所有 Android 版本上都能用，系统弹「允许绘制在其他应用上」时允许即可。

## 四、锁屏就没声的排查顺序

1. 通知权限是否已打开（九成是这条）；
2. MIUI 设备再到 `设置 → 通知 → 锁屏通知格式`，设成「显示通知和内容」，改完重启应用；
3. 华为 / 部分国产 ROM 的省电策略会杀后台服务：把 NewPipe 加进电池优化白名单（在设置里搜「后台」或「省电」，各品牌叫法不同，思路一致——别让系统杀它）；
4. 切后台瞬间音频停一下再续，是没开「最小化到后台」，在应用设置里打开即可无缝续播。

注意后台播放仍在联网拉流，断网就停；想断网也听，得先把内容缓存到本地，做法见[离线缓存与下载设置](离线缓存与下载设置.md)。卸载换机前别忘了订阅数据的去留，见[订阅与数据怎么备份搬家](订阅与数据怎么备份搬家.md)。
