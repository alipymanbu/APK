# NewPipe 离线缓存与下载设置

> 想把视频或音频存到本地离线看，最容易卡住的是保存目录授权。这篇讲清下载入口怎么用、目录怎么选、下载失败按什么顺序排查，以及缓存好的文件去哪放。
> **相关文章**：[后台播放与悬浮窗怎么开](后台播放与悬浮窗怎么开.md) · [订阅与数据怎么备份搬家](订阅与数据怎么备份搬家.md)

---

## 一、下载入口与可选档位

打开任意视频，播放页的下载按钮（向下箭头）点开，会让你分别勾选：

- **下载什么**：视频 / 音频 / 字幕，三者独立；
- **格式**：视频常见 WebM、M4A 配对，音频单独拉 M4A / WebM 流；
- **分辨率**：144p 到 4K，取决于该视频本身提供哪些档位。

只想听歌就只勾音频，体积小得多；要投电视看再选高分辨率。流量紧张的话，`设置 → 下载` 里还能把默认下载分辨率直接调低。

## 二、第一次下载前：先设好保存目录

NewPipe 走 Android 的「存储访问框架」（SAF），**目录没授权对，下载会直接失败**。规则按系统版本分：

- **Android 11 及以上**：不能把保存位置设在 `Download` 目录本身，也不能设在内部存储 / SD 卡的根目录。**新建一个单独的空文件夹**专门给它用，在文件选择器底部点「使用此文件夹」完成授权；
- **Android 10 及以下**：选 `Download` 下的子目录一般没问题，同样建议单独建一个。

路径在 `设置 → 下载` 里分别给视频和音频设置，每次改动都会弹一次系统文件选择器；视频与音频指到同一个文件夹最省事。

## 三、下载失败，按这个顺序查

1. 保存目录是不是按上一节选的（Android 11+ 别选 `Download` 本身与存储根目录）；
2. 文件选择器弹出时，底部的「使用此文件夹」点了没有——没点等于没授权；
3. `设置 → 下载` 里的「使用 SAF」开关：SD 卡老出问题的设备可以反过来关掉 SAF 走传统方式；
4. 应用权限里有没有给「存储 / 媒体」权限；
5. 内部存储和 SD 卡互换着试，立刻能区分是卡的问题还是目录的问题。

精简 ROM 还有一种冷门情况：缺少处理文件选择的系统组件 `DocumentsUI`，这种情况需要先把系统组件补回来。

## 四、缓存好的文件去哪了、怎么放

- 文件就在 `设置 → 下载 → 下载的位置` 指定的文件夹里，手机自带文件管理器能直接找到；
- **应用内不播放离线文件**——这是设计取舍，定位是流媒体客户端而不是本地播放器；离线播放用系统自带播放器或你顺手的播放器打开即可；
- 音频想转 MP3：应用内不内置转码（避免安装包膨胀），需要借助外部转码工具处理 M4A / WebM 流。

缓存文件是普通文件，重装应用不影响；会丢的是订阅、播放列表和设置——换机重装前先看[订阅与数据怎么备份搬家](订阅与数据怎么备份搬家.md)，下好的视频配上悬浮窗边聊边看的用法见[后台播放与悬浮窗怎么开](后台播放与悬浮窗怎么开.md)。

应用本身的功能总览与安装包获取方式，见 [NewPipe 安卓客户端介绍站](https://newpipe.fedq.ren/)。
