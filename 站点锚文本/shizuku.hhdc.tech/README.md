# Shizuku 资料索引（shizuku.hhdc.tech）

第三方整理的 Shizuku 使用资料目录：围绕这款安卓权限桥接工具最常见的三件事——无线调试配对、冻结预装应用、重启后失效排查，各整理了一篇实操说明。安装文件资源的获取入口统一放在 [Shizuku 介绍站](https://shizuku.hhdc.tech/)，本目录只做文字资料。

## 一句话认识 Shizuku

它本身不带功能：由你手动启动一个带 adb 权限的服务，之后受支持的应用逐个申请授权，就能做到冻结预装、管控权限这类过去要 root 才行的事。新手建议从[无线调试配对教程.md](无线调试配对教程.md)读起。
