# Shizuku 重启后失效、随机停止：原因与处理

重启手机后 Shizuku 提示「未运行」、或用着用着服务自己停了——这是两类不同的问题：前者是未 root 启动方式的机制使然，不是故障；后者多半是省电策略在杀后台。这篇把两种情况的处理都讲清。如果你还没走到配对那一步，先看[无线调试配对教程.md](无线调试配对教程.md)；工具授权相关的用法在[冻结预装应用方法.md](冻结预装应用方法.md)。安装文件资源与图文说明在 [Shizuku 介绍站](https://shizuku.hhdc.tech/)。

---

## 一、重启后「未运行」：机制，不是故障

通过无线调试或电脑 adb 启动的服务，权限随系统重启被回收，安卓就是这么设计的——所以每次重启手机后，都需要重新点一次启动。

关键点：**重新启动 ≠ 重新配对**。

| 动作 | 重启后要不要重做 |
| --- | --- |
| 打开开发者选项、开启 USB/无线调试 | 不用（个别机型系统更新后会重置，确认一下即可） |
| 配对码配对 | **不用**，一次就够 |
| 点「启动」 | **要**，每次重启后都点一次 |

操作路径：打开 Shizuku → 首页点「启动」→ 看到绿色「正在运行」即可恢复所有已授权应用。

## 二、想把重启这一步也省掉：两条路

1. **root 机型**：用 root 方式启动后，在 Shizuku 设置里开启开机自启，重启后服务自动就位；
2. **不 root**：接受「重启后点一次启动」这个成本，它换来的是不解锁、不刷机的安全感。目前没有稳定的免 root 自启方案，别装来路不明的「自启辅助」。

## 三、服务随机停止：找省电策略

用着用着 Shizuku 没了、授权过的应用集体失效，基本是系统把服务当后台耗电杀了。处理顺序：

1. 设置 → 应用 → Shizuku → **电池**，改成「不受限制 / 无限制」；
2. 通知类别全部保留（部分机型的前台服务通知被关会连带服务被杀）；
3. 厂商管家类应用（省电精灵、智能助手等）里把 Shizuku 加入**后台白名单**；
4. 部分机型的「深度睡眠」激进策略也会断服务，锁屏后失效明显的重点查这里。

改完重启验证一次：如果还偶发，把上面第 1、3 条对调优先级再试。

## 四、另一种「失效」：权限受限

有些应用提示「权限不足」，但 Shizuku 明明显示运行中——这不是服务挂了，而是 adb 通道的权限边界：个别系统接口 adb 拿不到，属于正常现象，换 root 方案才解决。判断方法很简单：换一个应用试试，普遍失效才是服务问题，单个应用失效是它要的权限超出了 adb 通道的供给范围。

---

一句话总结：重启失效靠「再点一次启动」解决，随机停止靠「电池白名单」解决，权限不足是通道边界。三个都排除不了时，把 Shizuku 更新到新版本再看[介绍站的常见问题](https://shizuku.hhdc.tech/)对照排查。
