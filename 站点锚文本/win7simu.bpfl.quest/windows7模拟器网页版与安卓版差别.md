# Windows 7 模拟器网页版与安卓版差别

> Win7 Simu 有网页与安卓两种形态，图形和大部分功能一致，但几样关键能力只在安卓版给得了。本篇按设备与使用习惯给出怎么选的对照。
> **相关文档**：[手机上重温windows7桌面.md](手机上重温windows7桌面.md) · [windows7模拟器安卓版安装步骤.md](windows7模拟器安卓版安装步骤.md)

---

## 一、两版是什么关系

两版由同一开发者维护，一套模拟环境的两种分发方式：网页版 2021 年 8 月上线，浏览器打开即用，不装任何东西；安卓版是独立的 APK 安装包，装在手机或平板上。图形、界面和大部分功能一致，差异集中在系统级能力上。

## 二、功能差异对照

| 能力 | 安卓版 | 网页版 |
| --- | --- | --- |
| 离线使用 | 支持 | 支持 |
| 系统通知 | 支持 | 不支持 |
| 显示控制（亮度等） | 支持 | 不支持 |
| 鼠标 / 触控板控制 | 支持 | 不支持 |
| 文件上传下载 | 部分支持 | 支持 |
| 访问本地 / 原生应用 | 部分支持 | 不支持 |
| 账号同步设置、多主题、多语言 | 支持 | 支持 |

两点补充：受系统存储限制，两版都不能让模拟环境里的文件管理器直接读写手机本地文件，都要靠上传的方式传文件；账号两版通用，用于同步设置。

## 三、按情况怎么选

- **想离线玩、要系统通知和显示控制**：安卓版，这些是它独有的能力；
- **手边只有电脑，想随手怀旧一下**：网页版最省事；
- **用 iPhone / iPad**：没有客户端，开发者说明过不会上架 App Store，浏览器就是替代方案，可以「添加到主屏幕」当应用用；
- **拿不准**：先在浏览器里玩网页版，觉得合适再把安装包装进手机。

决定装安卓版的话，四步安装流程与排障整理在 [windows7模拟器安卓版安装步骤.md](windows7模拟器安卓版安装步骤.md)；两种形态的完整介绍与截图对照，见 [win7simu](https://win7simu.bpfl.quest/) 介绍站。
