# Windows 7 模拟器安卓版安装步骤

> 把 Win7 Simu 的安卓安装包装进手机，从拿到安装包到看完开机动画一共四步；本篇同时整理了安装被拦、提示冲突、打开黑屏这三类最常见的坎。
> **相关文档**：[手机上重温windows7桌面.md](手机上重温windows7桌面.md) · [windows7模拟器网页版与安卓版差别.md](windows7模拟器网页版与安卓版差别.md)

## 一、这份安装包是什么

安卓版以 APK 安装包的形式分发。流传较广的网盘版本是较早的 3.19.x，安装包约 80 MB，包名为 `com.visnalize.win7simu`，对新老设备都比较宽容；现行新版本已迭代到 4.x，功能更多，但对系统版本的要求也更高（约 Android 7.0 上下，以应用商店当时标注为准）。

## 二、四步装好

1. **拿到安装包**：从网盘分享页把 APK 转存到自己的网盘账号，再下载到手机本地存储；
2. **允许「未知来源」**：第一次从第三方来源安装时，系统会弹窗提醒；在弹窗里允许本次安装，或到「设置 → 安全」里给文件管理器 / 浏览器放行（不同品牌叫法略有差异）；
3. **点开 APK 等装完**：在文件管理器里点开刚下载的文件，等待安装完成；建议此时剩余空间还有几百 MB，运行时还要写入数据；
4. **打开看开机动画**：第一次启动会经历 BIOS 自检画面和开机动画，随后进入登录界面和桌面——点一下是左键，长按是右键。

安装入口与版本说明都整理在 [Win7 Simu 安卓版下载与安装](https://win7simu.bpfl.quest/) 页面里，随版本更新维护。

## 三、装不上时的三条排查

- **提示「未知来源」被拦**：这是系统对第三方来源安装的正常提醒，在安装弹窗里点允许，或按上面的第 2 步设置后再试；
- **提示安装失败或与应用冲突**：手机里如果已经装过同包名的版本——比如从应用商店装的新版——两者只能保留一个，先卸载旧版本再装；
- **装完打开一直黑屏**：多与系统的 Android WebView 组件有关，把它更新到最新版一般就能解决；仍不行可以先在浏览器里试网页版，确认不是设备个例。
