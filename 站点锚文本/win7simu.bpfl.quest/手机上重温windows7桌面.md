# 手机上重温 Windows 7 桌面

> Windows 7 的支持在 2020 年就结束了，但它的 Aero 玻璃桌面被一套复刻模拟器搬回了手机与浏览器。本篇讲这套模拟器的来历、它还原了什么、适合谁。

## 一、一套为怀旧而做的模拟器

Win7 Simu 是开发者 Visnalize 出品的 Windows 7 复刻模拟器，出发点很直接：重温那套带 Aero 玻璃质感的桌面。它有网页与安卓两种形态，图形、界面和大部分功能一致；想随时随地打开，通常会选择装在手机上。

时间线摆出来更好理解它为什么存在：

- **2009 年 10 月 22 日**：Windows 7 发布，接替口碑平平的 Vista，被评价为「一个巨大的进步」；
- **2020 年 1 月 14 日**：对 Windows 7 的支持停止，而当天它的市场份额仍有 32.75%，排在所有操作系统第二位；
- **2021 年 8 月 28 日**：网页版上线，没有安卓设备的人也能在浏览器里打开同款桌面；
- **现在**：版本迭代到 4.x，应用商店累计 8 万多条评分、均分 4.2 出头。

## 二、它还原了哪些「当年感」

- **完整的开机仪式**：第一次启动会先经历 BIOS 自检画面和开机动画，然后停在登录界面——极光壁纸、白色输入框，都按当年的样子重做；
- **开始菜单与内置程序**：计算器、命令提示符、Internet Explorer、记事本、Windows Media Player 都收在菜单里；
- **桌面小工具**：时钟、日历这类只在 Vista 和 7 里出现过的侧边小工具也一并回来；
- **触屏化的鼠标逻辑**：点一下等于左键单击，长按等于右键，整套桌面操作被翻译成手指动作；
- **换壳玩法**：以 7 的内核为基础做了 Windows 3.1、XP、10、macOS、Ubuntu 等怀旧主题，还有单独的 Theme Studio 用来自制主题。

## 三、适合谁

- 想给新手机找点旧时光的人：开机动画和玻璃质感都是原味复刻；
- 需要演示或截图 Windows 7 界面、又不想折腾虚拟机的人；
- 在老设备上想找一款轻量模拟器的人：网盘里流传较早的 3.19.x 安装包对新老设备都比较宽容，较新的 4.x 则需要 Android 7.0 上下的系统。
