# Cinetry 资源库怎么添加：各类型填法与连不上排查

Cinetry 装完是空的，第一步永远是「添加资源库」。这篇按实际填表的顺序，把每种数据源该填什么、哪些地方最容易错、连不上时按什么顺序排查，一次讲清。

> **相关文档**：[多源聚合播放器功能与亮点盘点](多源聚合播放器功能与亮点盘点.md) · [电视盒子上怎么用与播放问题排查](电视盒子上怎么用与播放问题排查.md)

## 一、添加入口与通用填法

首次打开点界面正中的「添加资源库」（之后添加走同一入口），表单不管哪种类型都是同一套骨架：

| 栏位 | 填什么 | 提醒 |
| --- | --- | --- |
| 名称 | 自己认得出的名字，如「家里 NAS」 | 随意，不影响连接 |
| 地址 | 服务的访问地址，写法见下表 | 最容易错的一栏 |
| 账号 / 密码 | 该服务的登录凭据 | 注意大小写 |
| UserAgent | 留空即可 | 不会填就别动 |

各类型地址的写法：

| 类型 | 地址写法 | 补充 |
| --- | --- | --- |
| Jellyfin / Emby | `http://{地址}:{端口}` | 默认端口多为 `8096`，两台同机别撞端口 |
| 苹果 CMS | 域名，或域名 + `/api.php/provide/vod/` | 接口必须返回 json |
| IPTV | m3u 地址，或 TVBox 的 txt 直播源 | 两种格式都认 |
| WebDAV | `http://{地址}:{端口}` | 自动读同目录的 `.nfo`、海报与字幕，支持 `.strm` |
| Alist / OpenList | 地址末尾**带上 `/dav`** | 漏掉这一段是头号连不上原因 |
| 音乐服务 | Subsonic、Navidrome、audiobookshelf 等 | 同样是地址 + 账号密码 |

## 二、填之前先花一分钟验证

添加前用浏览器把地址打开，能省掉大半排查：

1. Jellyfin / Emby：能出登录页，说明地址和端口都对；
2. CMS 接口：浏览器里应直接返回一串 json；
3. WebDAV / Alist：能列出目录最好，Alist 记得带 `/dav`。

浏览器里都打不开的地址，填进客户端也一定连不上。

## 三、连不上时的排查顺序

添加后一直转圈或列表为空，按命中率从高到低查：

1. **同一个网络吗**——手机和服务器是否在同一局域网；出门在外要看服务器有没有公网入口或内网穿透。
2. **地址抄对了吗**——`http` 与 `https` 有没有写反、端口有没有漏。
3. **服务活着吗**——浏览器能打开登录页说明服务正常，问题出在 App 侧的填写。
4. **账号密码**——大小写、账号是否被服务器侧禁用。
5. **类型选对了吗**——把 WebDAV 当 Jellyfin 填，接口对不上永远拉不到数据。
6. **权限给了吗**——服务器刚建好或账号没有该库权限时，客户端这边就是空的。
7. 以上都正常还连不上，删掉这条资源库重新添加一次，排除保存时的残留配置。

## 四、多台服务器与导入

- 每台服务器的配置保存在本地，添加入口里可以随时再编辑；
- 「添加资源库」页面的菜单里还有「导入」：把别人分享的资源库列表地址与密码填进去，整份列表批量进库；
- 想按用途拆库（电影一个、儿童动画一个），多建几条即可，首页会分类展示。

配置就绪后，找片可以直接用聚合搜索一次查完所有库，玩法与界面细节见 [Cinetry 介绍与获取入口](https://cinetry.gerw.hair/)；电视端的填表技巧与遥控器操作写在[电视盒子上怎么用与播放问题排查](电视盒子上怎么用与播放问题排查.md)。
