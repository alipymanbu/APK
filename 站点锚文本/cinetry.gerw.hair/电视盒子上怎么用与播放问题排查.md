# Cinetry 电视盒子怎么用：安装、TV 模式与遥控器操作

大屏看电影才是这类播放器的主场。这篇讲 Cinetry 怎么装进电视盒子、TV 模式在哪开、遥控器每个键管什么，以及客厅网络最常见的两个坑。

> **相关文档**：[多源聚合播放器功能与亮点盘点](多源聚合播放器功能与亮点盘点.md) · [资源库怎么添加与连不上怎么办](资源库怎么添加与连不上怎么办.md)

## 一、装哪个包：直接用安卓安装包

电视盒子没有专门的 TV 包，做法就是**把安卓版的 apk 装进盒子**：把安装包放进 U 盘，插到盒子上用文件管理器点开安装；或者先在手机上装好，再通过盒子自带的应用推送能力安装。

装完第一次打开记得先添加资源库——在电视上输入地址比较费劲，建议先在同网络的手机上配好，或者提前把地址抄在便签上再手输。各类型的地址写法见[资源库怎么添加与连不上怎么办](资源库怎么添加与连不上怎么办.md)。

## 二、TV 模式开关

较新版本的设置里有「TV 模式」切换，**开启后需要重启应用才生效**。切换后界面会按大屏与方向键重排：首页、列表、焦点移动都围绕遥控器设计。手上版本设置里没有这一项也不影响使用，默认界面的按键功能同样齐全。

## 三、遥控器按键对照

| 按键 | 作用 |
| --- | --- |
| OK（确认） | 播放 / 暂停；列表里是进入选中项 |
| ← / → | 后退 / 快进 |
| ↑ / ↓ | 切换上一集 / 下一集 |
| 菜单键 | 显示 / 隐藏控制页 |
| 返回键 | 退回上一页 |

几个顺手的小技巧：

- 播放中按**菜单键**唤出控制条，再用方向键移动焦点，就能切音轨、字幕和选集；
- 剧集连播时 ↑/↓ 直接换集，不用退回列表；
- 焦点找不到时按返回退一级再进，焦点会回到默认位置。

## 四、客厅网络的两个常见坑

电视盒子大多只连 Wi-Fi，比手机更容易踩网络问题：

1. **路由器开了 AP 隔离或访客网络**：盒子和 NAS 被隔在两个网络里，服务器地址填得再对也连不上——关掉隔离或让两者进同一网络。
2. **信号弱**：4K 播放对带宽敏感，卡顿时改用有线，或把盒子挪近路由器复测。

播放层面的问题（花屏、无声、高码率卡顿）多半在设置里就能解决：切换「硬件解码」开关、关闭 Http/2 试试；更多排查思路与手机端是通用的，可以在 [Cinetry 图文介绍站](https://cinetry.gerw.hair/)的功能介绍里对照着看。
