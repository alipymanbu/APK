# F-Droid 镜像仓库配置方法（国内提速）

> 默认仓库服务器在国外，目录拉不动、刷新慢是它在国内最常见的"故障"，其实换个镜像源就能解决。这篇给出已验证可用的镜像地址与完整配置步骤。
> **相关文档**：[安卓下载安装步骤](安卓下载安装步骤.md) · [来源可靠性与使用注意](来源可靠性与使用注意.md) · [找应用与更新应用技巧](找应用与更新应用技巧.md)

## 什么情况该配镜像

- 首次打开时应用目录（仓库索引）拉了很久不完成，或反复报错；
- 每次下拉刷新索引都要等很久；
- 应用列表能出来，但下载安装包很慢。

这些现象的根源是同一个：默认源在国外。镜像仓库在国内复制了一份完整的目录与安装包，改从镜像同步后，速度与访问国内网站相当。

## 添加清华 TUNA 镜像

以清华大学 TUNA 镜像站为例（内容与主仓库同步，国内直连稳定）：

1. 打开 F-Droid，进 **设置 → 存储库**；
2. 点右下角的 **+** 新建一条仓库，名称随意（如"TUNA 镜像"），地址粘贴这条：

   ```
   https://mirrors.tuna.tsinghua.edu.cn/fdroid/repo/?fingerprint=43238D512C1E5EB2D6569F4A3AFBF5523418B82E0A3ED1552770ABB9A9C9CCAB
   ```

3. 保存后回到存储库列表，**把默认源的开关关掉，只留镜像**——不关的话客户端仍会周期性去连国外源；
4. 回到首页下拉刷新，索引会从镜像重新同步。

之后想切回默认源，把开关开回来即可，两条仓库可以长期共存。

## 老版本应用的镜像（Archive 仓库）

另有一个 archive 仓库，保留大量应用的历史版本——老手机找能跑的旧版时会用到。TUNA 同样镜像了它：

```
https://mirrors.tuna.tsinghua.edu.cn/fdroid/archive?fingerprint=43238D512C1E5EB2D6569F4A3AFBF5523418B82E0A3ED1552770ABB9A9C9CCAB
```

老机型建议两条一起加上；切换仓库不影响已装应用，后续更新自动改从镜像走。

## 地址里那串 fingerprint 是什么

`?fingerprint=` 后面的长串是主仓库的**签名密钥指纹**。客户端同步索引时会用它核对签名——镜像只负责搬运文件，目录与安装包必须仍是项目方密钥签发的那份才能通过校验，镜像方想塞私货过不了这一关。这也是可以放心添加镜像的原因，签名机制的整体说明见[来源可靠性与使用注意](来源可靠性与使用注意.md)。

## 两个注意点

- **镜像地址可能变化**：以上地址核对于 2026 年 9 月，若日后失效，以清华 TUNA 镜像站帮助页当时显示的为准，换新地址重新保存即可；
- **镜像只解决"慢"**：安装包本身的获取入口与安装步骤，见[安卓下载安装步骤](安卓下载安装步骤.md)；配好镜像后，"首次打开等 2~10 分钟"基本可以跳过。
