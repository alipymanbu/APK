# Wallcraft 壁纸尺寸与屏幕不匹配怎么办：按分辨率挑图的逻辑

> 本篇回答一个高频疑问：为什么 Wallcraft 里看到的图总能铺满屏幕、换了设备尺寸就变了，以及下载回来的壁纸模糊或填不满屏幕时该怎么处理。

## 一、为什么它不容易「尺寸不对」

Wallcraft 会先识别设备的屏幕分辨率与机型，浏览时只展示尺寸匹配的那部分图，列表里不会出现「下载回来填不满屏幕」的内容。常见档位的对应关系：

| 档位 | 典型像素 | 适合的设备 |
| --- | --- | --- |
| HD | 720x1280 | 入门机型、旧手机 |
| 全高清 | 1080x1920 | 目前大多数主流手机 |
| 2K QHD | 1440x2560 | 各家旗舰机 |
| 4K UHD | 2160x3840 | 支持 4K 屏的新旗舰 |
| 6K / 8K | 更高 | 专属内容，随订阅解锁 |

这个机制顺带带来两个好处：列表加载更快（不传输用不上的大图），流量与电量也更省。每张图都经过人工裁剪，设置时一般不需要再手动调裁剪框。

## 二、下载回来的壁纸模糊，先查画质档位

预览页里选「下载 / 设置」时，部分图会给多档画质。模糊通常是这几件事之一：

- **档位选低了**：2K / 4K 屏的机型选了低档画质，放大铺满后自然糊——重新下载，选与你屏幕匹配或更高的一档；
- **图被放大**：把横图强行竖用、或低分辨率图设到高分屏上，都会被拉伸发虚，换一张尺寸匹配的图即可；
- **系统压缩**：个别系统的省电模式会给壁纸加暗色着色或降清晰度，充上电或关掉省电模式再对比一次。

## 三、换设备后内容对不上屏幕

同一账号换新机后，分辨率档位变了，之前下载的图可能不再匹配——这不影响已保存到相册的图，但在应用内浏览时会按新屏幕重新筛图。把「按屏幕筛图」这件事交给应用自己做，就基本不会再遇到尺寸问题；想手动核对档位，对照上面的表看自己手机的分辨率落在哪一档即可。

## 四、尺寸之外的选图建议

- 大文件（4K 档）在 Wi-Fi 环境下再下载，省流量也更稳；
- 锁屏与主屏可以用成对设计的 Double 图，解锁前后画面衔接统一；
- 把下载的图设成聊天工具背景或键盘背景也行，浅色低对比的图比高对比大场景图更实用（消息气泡更易读）。
