# Wallcraft 怎么设置动态壁纸：视差、Live 与视频壁纸的差异和使用建议

> 本篇讲在 Wallcraft 里把「会动」的壁纸设到手机上的完整过程：三种动态形态（视差 / Live / 视频）各自的表现、设置路径，以及动态壁纸常见的两个坑——不动了、太耗电。

在壁纸应用里，「动态」不是一个单一类型。Wallcraft 的壁纸库里，会动的内容分成三种形态：视差（Parallax / 4D）、Live 动态和视频壁纸。三者的原理不同，耗电也不同，设置前先分清自己要的是哪一种，能少走很多弯路。想系统了解七种形态的全貌，可以看 [Wallcraft 壁纸玩法解析站](https://wallcraft.uerg.quest/)上的形态对比。

## 一、三种动态形态的区别

| 形态 | 动起来的原理 | 耗电程度 |
| --- | --- | --- |
| 视差 / 4D | 随手机倾斜、滑动产生位移景深，依赖陀螺仪 | 低 |
| Live 动态 | 持续播放的动态效果 | 中 |
| 视频壁纸 | 以短视频形式循环播放 | 高 |

简单记：视差是「你动它才动」，Live 和视频是「它一直在动」。所以给主力机当日常壁纸，视差最划算；Live 适合放在锁屏偶尔亮屏看；视频壁纸氛围感最强，但建议短期换着玩，别长期挂。

## 二、设置路径

三种形态的设置动作是一致的：

1. 在首页分类或搜索里找到目标图——视频壁纸有专门的「视频壁纸」分类，视差图在 PARALLAX 栏目下；
2. 点开进入全屏预览，确认动效效果；
3. 选「下载 / 设置」，按需选画质档位（档位越高文件越大）；
4. 选择作用位置：主屏、锁屏，或两张都设；
5. 回桌面看效果，不满意就换下一张。

## 三、「设完不动」的两个原因

- **传感器被关**：视差效果依赖陀螺仪。个别机型关掉了传感器，或开了皮套模式，图就会静止——到系统设置里检查传感器相关开关，再回应用里重设一次；
- **桌面冲突**：动态壁纸服务偶尔与第三方桌面冲突，表现为黑屏或不动。先换一张静态图稳住，重启手机后再重设动态图。

## 四、耗电异常的判断

先分清是「动态形态的固有耗电」还是「应用异常」：视频和 Live 本身就比静态费电，这是形态决定的；如果挂的是静态图也出现掉电加快，那就不是形态的问题，去系统电池面板看应用的耗电排名再对症处理。锁屏挂动态图、主屏挂静态图，是观感与续航兼顾的常见搭配。

自动更换壁纸与动态形态叠加使用时，建议把更换间隔拉长一些，减少常驻渲染的时间。具体的间隔档位与来源设置，见[自动更换壁纸设置方法](自动更换壁纸设置方法.md)。
