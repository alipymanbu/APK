# 安卓安装包下载安装步骤

> 本篇讲 Prequel 安卓安装包从转存到装好的完整流程，以及装不上时的三种常见状况怎么处理。
> **相关文档**：[滤镜效果库与AI头像玩法盘点.md](滤镜效果库与AI头像玩法盘点.md) · [中文界面设置与保存失败怎么办.md](中文界面设置与保存失败怎么办.md)

## 一、装之前先对两件事

Prequel 由 Prequel Inc. 开发，安装包本体 105MB 上下（本站整理的版本为 1.97.0，包名 com.prequel.app），安装过程还要解压一份，加上后续编辑产生的缓存，建议装之前留出 500MB 以上的空闲空间。系统方面要求安卓 5.2 及以上，多年前的机型先去「设置 → 关于手机」确认一下再动手。

在哪里取安装包：站点 [Prequel 安卓版安装文件入口](https://prequel.uerg.quest/) 的下载页给出了夸克网盘分享入口，先转存到自己的网盘再下载，比临时链接可靠，中断了也能续。

## 二、四步装好

1. **转存**：打开网盘分享页，登录后把安装包转存到自己网盘的目录里；
2. **下载**：在网盘里把 apk 下载到手机存储，下完在文件管理器里看一眼体积，105MB 上下才算下全；
3. **授权**：点开 apk 时系统会拦「不允许安装未知来源应用」，按提示进入 设置 → 应用 → 特殊应用权限 → 安装未知应用，给当前用的浏览器或文件管理器授权一次；
4. **安装核对**：回到安装界面确认应用名显示为 Prequel，点安装；装完在应用信息里核对包名是 com.prequel.app、开发方是 Prequel Inc.，对得上就是这一份。

首次打开会陆续问几项权限：照片与媒体（导入素材、保存成片，其中写入权限最容易被误点拒绝，点了保存必失败）、相机（应用内拍摄）、麦克风（视频录音）。按用途给即可，漏掉的之后去系统设置 → 应用 → Prequel → 权限里补开。

## 三、装不上时的三种状况

- **解析包错误**：安装包没下完整，回网盘重新下载；不要用第三方下载器断点续传后再装，残包大概率报同样的错。
- **应用未安装**：手机里已有一个签名不同的同名应用，先卸掉旧的那份再装；旧应用里有没导出的编辑项目时，先导出再卸。
- **装完闪退**：多数是系统版本过低或可用内存不足——确认安卓版本达标，重启手机并清掉后台应用再打开；仍闪退就清一次应用缓存（选「清除缓存」而不是「清除数据」）。

装好之后中文界面怎么切、效果库怎么翻，见 [中文界面设置与保存失败怎么办.md](中文界面设置与保存失败怎么办.md) 与 [滤镜效果库与AI头像玩法盘点.md](滤镜效果库与AI头像玩法盘点.md)。
