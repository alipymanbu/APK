# 中文界面设置与保存失败怎么办

> 本篇解决两个高频卡点：打开全是英文怎么切回中文，以及编辑完了保存失败、相册里找不到成片的排查顺序。

## 一、界面全是英文，不是没做中文

Prequel 的界面语言默认跟随手机系统，中文系统进去却是英文，一般是系统语言被设成英文、或之前手动改过应用级语言。两条路切回来：

- **应用内**：底部导航最右侧的个人页 → 右上角菜单 → 语言 → 选简体中文。不同版本入口位置略有出入，认准「能选中 Chinese / 简体中文」的那一项；
- **系统级**：设置 → 应用 → Prequel → 语言（部分国产机型在「应用管理 → 语言与地区」里），单独给它指定中文，手机其余部分不用动。

改完从最近任务里强制关闭应用再打开，界面有时不重启不刷新。另外两点容易被误解：效果名称里的 D3D、Y2K 属于风格化命名，本身不翻译；切成中文也不会让模板自带的英文字幕跟着变，素材里的字要编辑时自己替换。

## 二、保存失败，按顺序查两处

编辑完点保存没反应或报错，逐条来：

1. **相册写入权限**：安装时对「照片与媒体」点了不允许，保存必失败。安卓去 设置 → 应用 → Prequel → 权限 → 照片与媒体，改成允许；这项是最高频原因，先查它；
2. **剩余空间**：导出过程临时占用的空间比成片本身更大，不足就先删几段无用视频再导。

长视频一次性导出容易中途失败，把素材切短分几次导更稳。导出走的是前台服务，切出去回消息不影响；但别从最近任务里把应用强制划掉，那会直接终止导出。

## 三、提示成功，相册里却没有

多半不是没保存上，而是相册还没扫到：先换到「图集 → 所有照片」看（按保存时间排序）；图片通常很快出现，视频可能要等媒体库扫完；文件管理器里按时间能查到文件，就说明确实写进去了，重启一次手机相册就会刷新。

导出的视频被裁掉边缘，是素材画幅和项目画幅不一致——在编辑页把比例换成与原素材一致即可；导入的照片方向不对，编辑页旋转一次就好，不损画质。
