# BoldVoice 怎么下载安装到安卓手机

> BoldVoice 是 Wellocution, Inc. 出品的美式英语发音训练应用，主打好莱坞口音教练视频课加 AI 逐音素评分。它不走国内应用商店分发，安卓安装包从网盘资源页拿。本篇按顺序讲：转存、下载、允许安装、首次启动，每一步附卡住时的排查动作。

## 一、装之前对一下手机条件

- 系统版本：安装包信息标注为 Android 5.2 以上，旧机型先在「设置 → 关于手机」里确认；
- 存储空间：安装包 v2.4.7 约 156 MB，解压安装后占用更大，留出 300 MB 以上空闲更稳妥；
- 网络环境：安装本身不挑网络，但首次启动的引导问卷需要联网完成，建议全程 Wi-Fi。

## 二、四步装好

1. **打开介绍站拿入口**：在 [BoldVoice 安卓版介绍站](https://boldvoice.fedq.quest/) 的下载页点获取按钮，进入网盘分享页，把安装包转存到自己账号——转存后资源在自己网盘里，不怕原分享变动；
2. **下载到手机**：手机上打开夸克 App，在「我的网盘」里找到刚转存的 APK 点下载；电脑端转存的，下载后用数据线或任意传输方式挪到手机存储；
3. **点开安装**：在文件管理器里点开安装包，系统弹「禁止安装未知来源应用」时按提示去「设置 → 应用 → 特殊应用权限 → 安装未知应用」，给对应的文件管理器授权，回来再点「安装」；
4. **首次启动**：装完点「打开」，先走引导问卷（称呼、学习动机、流利程度、母语背景），随后会请求麦克风权限——这个应用的评分全靠录音，建议选「仅在使用中允许」。

## 三、卡住了对号排查

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 解析包出错 / 点了没反应 | 安装包没下完整 | 回网盘删掉重下一遍再装 |
| 安装按钮置灰或被拦 | 系统默认拦截未知来源 | 按「安装未知应用」授权一次，只对下载来源开 |
| 引导问卷转圈进不去 | 问卷要联网 | 检查网络后重进，实在不行清应用数据重走引导 |
| 练习时一直不出分 | 麦克风权限或蓝牙耳机抢麦 | 给足麦克风权限，断开蓝牙用手机自带麦克风 |
