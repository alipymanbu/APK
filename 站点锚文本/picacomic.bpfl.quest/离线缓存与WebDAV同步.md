# PicaComic 离线缓存与WebDAV同步

> 本篇讲把漫画下到本地离线看、两种收藏的区别，以及用 WebDAV 把收藏和阅读历史同步到自己的网盘空间——换机、重装前该做的动作都在这里。
> **相关文档**：[安卓版下载与安装步骤.md](安卓版下载与安装步骤.md) · [漫画源切换与自定义源配置.md](漫画源切换与自定义源配置.md)

## 把漫画下载到本地

在漫画详情页发起下载：挑章节（可整本全选，也可只选部分）→ 确认后开始下载 → 在下载管理里看进度。几点实际情况：

- **内容跟源走**：只能下载当前源里的漫画，下载完成后的文件在本机，断网也能看；
- **体积别小看**：整本长篇全选可能占几百 MB，空间紧张就按章节挑着下；
- **速度取决于源站**：源站限流时快不起来，换时段或换源重试，不是应用坏了。

看完想腾空间，从「已下载」列表删除对应条目即可，只影响本机文件。应用还支持把漫画导出为 PDF（v4.0.4 的更新日志里有对导出文件名问题的修复记录），想把几话存成单个文件传到别的设备，这个比搬图片文件夹方便。

## 两种收藏，别搞混

| 对比 | 本地收藏 | 网络收藏 |
| --- | --- | --- |
| 存在哪 | 只存在这台设备 | 存在源网站账号下 |
| 换手机 / 重装 | 不备份就没了 | 登录账号能拉回来 |
| 前提 | 无 | 对应源已登录 |

给漫画点收藏时进哪一类，取决于当前源与登录状态。整理收藏前先把两类分开看，免得以为「都收藏了」，换机时却只找回了网络那部分。

## 用 WebDAV 同步数据

WebDAV 解决「数据只存在本机」的问题。准备一个支持该协议的网盘或自建服务，拿到服务器地址、账号、密码（不少服务要求用专门的应用密码，而不是网页登录密码——配置失败十有八九是它）三样东西，然后：

1. 设置里找到数据同步项，依次填入地址、账号、密码；
2. 先做**连接测试**，通过后执行一次「上传」，把当前设备的数据完整推上去；
3. 新设备填同样三项，执行「下载」把数据拉回来。

方向别搞反：旧设备上传、新设备下载；两边都改过再互相同步，后写的一方可能覆盖先写的。常见报错对号入座：连接测试失败查地址拼写；401 认证失败多半是密码类型用错；能连上但上传失败查空间是否已满。注意**已下载的漫画文件不参与同步**，需要保留就用文件传输搬走或导出 PDF。

## 换机或重装前的动作清单

1. 登录各源账号，让网络收藏都落上去；
2. 配好 WebDAV 并推一次数据，把本地收藏和阅读历史保住；
3. 需要整包搬家时用应用自带的数据导入 / 导出（入口在设置里，以应用内实际显示为准）；
4. 已下载的漫画单独处理：传文件或导出 PDF。

应用还没装好的话，先看[安卓版下载与安装步骤.md](安卓版下载与安装步骤.md)；源相关的设置与排查，见[漫画源切换与自定义源配置.md](漫画源切换与自定义源配置.md)。功能与截图的总览，可以在 [PicaComic 资料站](https://picacomic.bpfl.quest/)首页一页看完。
