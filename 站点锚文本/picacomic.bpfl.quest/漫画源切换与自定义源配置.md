# PicaComic 漫画源切换与自定义源配置

> 本篇讲 PicaComic 的「漫画源」机制：内置了哪些源、怎么切换、哪些源要登录账号、自定义源文件从哪来怎么导入，以及源打不开时的排查顺序。
> **相关文档**：[安卓版下载与安装步骤.md](安卓版下载与安装步骤.md) · [离线缓存与WebDAV同步.md](离线缓存与WebDAV同步.md)

## 内置了哪些漫画源

PicaComic 起初是 picacg（哔咔）的第三方客户端，后来逐步扩展成多源应用。按项目仓库的说明，内置源包括 picacg、E-Hentai / ExHentai、JM Comic、Hitomi、绅士漫画、nhentai 等，不同版本可能略有增减，以应用内实际列表为准。切换源之后，分类、排行、搜索结果会整套换掉——每个源对应不同的漫画网站，内容范围、语言、账号规则都不一样。

## 切换当前源

日常主要在两个地方碰「源」：

1. **浏览时切源**：首页或探索页顶部的下拉列表可以直接换当前源，换了之后列表立刻变成那个源的数据；
2. **设置里管理**：设置中有漫画源管理项，可以控制源的启用状态（不同版本入口名称略有差异）。

一个实用习惯：想清楚自己看什么类型的内容，固定用一两个顺手源，别每次都把源从头切一遍。

## 哪些源需要登录

部分源要求先注册并登录账号，典型的是 picacg：未登录时浏览会受限或直接提示需要登录。三点提醒：

- 登录状态**按源分开**，在 picacg 登录了不代表其他源也登录了；
- 登录后才能用「网络收藏」这类跟随账号的功能（与本机收藏是两回事，见[离线缓存与WebDAV同步.md](离线缓存与WebDAV同步.md)）；
- 注册、找回密码只能在对应漫画网站自己的体系里完成，应用不替你管理账号。

## 添加自定义源

从 3.0.0 版本起支持自定义漫画源，它是停止维护后让源继续可用的关键手段：

- **源文件从哪来**：自定义源本质是一份 JS 配置文件，社区里常有人分享现成的；项目作者也维护了配置仓库（wgh136/pica_configs），里面的 template.js 是带注释的模板。来历不明的源文件不要导入——它能以你的身份发起网络请求；
- **怎么导入**：设置 → 漫画源管理 → 添加自定义源，选择本地 .js 文件或粘贴文件链接，导入后源会出现在列表里像内置源一样切换；
- **兼容性是最大的坑**：3.1.0 版本对自定义源机制做过大改造，3.0 时代的老格式文件在 4.x 上很可能直接失效，导入不生效先怀疑这一点。

## 源打不开时，按这个顺序查

1. **判断范围**：切到别的源试试——只有单个源不行是那个源站的问题，全都打不开先查手机网络；
2. **看账号状态**：需要登录的源，密码失效、被顶下线都会表现成「加载失败」，重新登录一次；
3. **换个时段**：源站维护、限流期间应用侧怎么重试都没用，等恢复；
4. **补自定义源**：项目已停止维护，内置源地址只会越来越旧——源失效后，按上一节导入一份新配置是主要修复手段。

调试自定义源时，加载失败的日志在「设置 → App → Logs」里看，比反复试错快。这个应用的版本现状、实拍截图与安装包获取入口，见 [PicaComic 安卓版资料站](https://picacomic.bpfl.quest/)；装好应用的第一步是把安装包拿到手，见[安卓版下载与安装步骤.md](安卓版下载与安装步骤.md)；下载与数据备份的日常操作见[离线缓存与WebDAV同步.md](离线缓存与WebDAV同步.md)。
