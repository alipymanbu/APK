# PicaComic 资料站锚文本

本目录收录与 [PicaComic](https://picacomic.bpfl.quest/) 相关的介绍与使用文档。PicaComic 是一款开源的聚合漫画阅读应用：多个漫画源切换、自定义源导入、章节级离线下载与 WebDAV 数据同步，对应的安卓版本为 v4.0.4。站点里整理了它的功能亮点、实拍截图与安装文件资源入口。

## 目录内文档

- [安卓版下载与安装步骤.md](安卓版下载与安装步骤.md) —— 从网盘取包到装进手机的四步流程，附安装被拦、失败、闪退的排查；
- [漫画源切换与自定义源配置.md](漫画源切换与自定义源配置.md) —— 内置源说明、登录要求、自定义源导入与源失效排查；
- [离线缓存与WebDAV同步.md](离线缓存与WebDAV同步.md) —— 离线下载、两种收藏的区别与换机前的备份清单。
