# Nicegram 多账号同时在线与切换

> 这篇讲怎么在一部手机上同时挂多个 Telegram 账号：数量上限、添加与切换的入口、通知怎么区分，以及换机时用会话备份文件整体迁移的办法。

## 一、为什么多账号要靠第三方客户端

Telegram 本体的手机客户端最多同时登录 3 个账号，再多就得退出一个再登录另一个。Nicegram 把这个上限放开：可以添加几十个账号，全部保持在线，切换时在侧边栏账号列表里点一下就行，不用反复收验证码。

每个账号本质上是一个独立的登录会话，消息由 Telegram 云端按账号分开保存，互不串扰；通知也按账号区分，给某个号单独关通知不影响其他号。

## 二、添加账号的入口

1. 打开 Nicegram，进 Settings（设置）→ Add Account（添加账号）；
2. 输入另一个 Telegram 手机号，完成验证码验证（两步验证密码也要输）；
3. 添加完成后，侧边栏头像处下拉即可看到全部账号，点选切换。

每个手机号都要单独走一遍验证流程；之后换机、重装就不用再收码了——用第三节的会话备份文件迁移。

## 三、换机迁移：导出会话备份文件

Android 端支持把登录会话导出成文件（iOS 还有 iCloud 自动备份，Android 只有文件导出一种）：

1. 旧设备：Settings → Nicegram → Accounts → Export as File，生成备份文件；
2. 新设备装好客户端后：Settings → Nicegram → Accounts → Import from File，选中文件即恢复。

两点务必记住：这份文件等于账号的登录凭证，谁拿到谁能登录，只能放私密位置；建议平时就导出一份存好，换机时才不慌。

同一个 Accounts 入口里还有 Delete Sessions，用来清理废弃设备的登录记录。

## 四、把某些号藏起来：Double Bottom

挂着工作号和私人号，不想每次递手机都被看光，可以用 Double Bottom：给应用设两份密码，输 A 密码只显示选定的主账号，输 B 密码才展开全部。它是界面层面的隐藏（消息本身仍由 Telegram 的加密体系保管），不需要订阅。

前提：至少 2 个 Telegram 账号，且已开启 Telegram 的 Passcode Lock 密码锁。设置路径：Settings → Nicegram → Double Bottom。

## 五、数量与性能的现实边界

账号不是挂得越多越好：几十个号在低端机上切换和加载会明显变卡，设备性能与 Telegram 自身的会话限制都会影响实际可用数量。日常真正常用的号挂上即可，闲置号可以删会话或只在需要的设备上登录。
