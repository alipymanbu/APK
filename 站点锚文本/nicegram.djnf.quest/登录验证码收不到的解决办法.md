# Nicegram 登录验证码收不到的解决办法

> 这篇专门处理装好之后登录不了的情况：验证码实际发到了哪里、短信不来时的自查清单、以及三条绕开短信的登录路。

## 一、先搞清验证码的送达顺序

Nicegram 登录走的是 Telegram 的验证流程，送达顺序是固定的：

1. **优先发到你已登录 Telegram 的其他设备**——打开手机或电脑上还登着的 Telegram 应用，翻「Telegram」服务对话，登录码多半已经躺在那里；
2. 该账号没有其他在线设备时，才发**短信**到手机号。

所以第一动作不是盯着短信等，而是先去其他设备里找。

## 二、短信不来的自查清单

| 现象 | 原因 | 动作 |
| --- | --- | --- |
| 短信一直不来 | 码发到了别的已登录设备 | 去其他设备的服务对话里找 |
| 号码格式错误 | 没用国际格式 | 区号选对（中国大陆 +86），填纯手机号，不带本地长途前缀 |
| 短信被拦 | 境外短信被手机或运营商过滤（多地反馈这是最常见的拦截点） | 翻手机的骚扰拦截/垃圾短信文件夹；问运营商有无国际短信拦截开关 |
| 反复请求无响应 | 连续点发送触发频控 | 隔几分钟再试，别连着刷 |
| 请求发不出去 | 本机网络不稳 | 换 Wi-Fi/流量，重启应用再试 |

## 三、绕开短信的三条路

按可行性排序：

1. **用其他已登录设备接码**：任何一台还登着这个 Telegram 账号的设备（手机、电脑）都能收到验证码，零成本；
2. **会话备份文件迁移**：旧设备上还装着 Nicegram 的话，先在旧设备 Settings → Nicegram → Accounts → Export as File 导出会话文件，新设备 Import from File 导入，完全跳过验证码环节；
3. **付费语音验证**：短信多次无法送达时，登录页会出现电话报码的付费选项（Telegram 侧收费，与客户端无关），价格与是否出现以登录页当时显示为准。

## 四、登录成功后做两件事

- 在 Telegram 应用里**设置两步验证密码**（Settings → Privacy and Security → Two-Step Verification），新设备登录时多一道保障；
- 在 Nicegram 里**导出一份会话备份文件**存到私密位置，换机、重装直接导入，不再跟验证码较劲。注意这份文件等同登录凭证，别放进任何公开分享的链接里。

## 五、不是验证码问题的情况

- 提示验证码错误：确认码没过期、没拿旧码重复用；
- 登录成功但聊天一直加载不出来：这是网络连不上 Telegram 服务，与验证码无关，先查本机网络；
- 提示账号受限无法登录：只能走 Telegram 的申诉渠道处理，客户端侧帮不上。
