# 搜「PIASCORE」跳出两个应用，怎么认准安卓这份

> 在搜索引擎输入 PIASCORE，结果里常同时出现一款安卓 APK 和一款日本团队做的 iOS 应用，教程与截图混在一起。这篇给出几个一眼区分的办法。

## 一、两个名字，两个产品

| | 安卓这份（APK 安装） | 同名的另一个（iOS 应用） |
| --- | --- | --- |
| 平台 | 安卓手机、平板 | iPhone、iPad |
| 分发方式 | APK 安装文件安装 | App Store |
| 开发方 | 深圳市坤焱科技有限公司 | Piascore, Inc.（日本） |
| 包名 | com.syjxx.piano | 无 APK 包名，走商店分发 |

两边都是电子乐谱阅读器，功能介绍高度相似——批注、免手翻页、古典曲库在两边的介绍里都出现过，所以教程才容易混。

## 二、怎么确认手里这份是安卓版

- **看安装来源**：从网盘分享、 APK 文件直接装的，只能是安卓这份；iPhone 上通过 App Store 装的是另一份，两者安装渠道互不通用。
- **看界面布局**：安卓这份首页按「曲谱库、教程、工具」组织，开局先选乐器与声部；另一份的按钮位置与它并不相同。
- **看系统要求**：安卓手机弹出的安装确认、未知来源授权，都是这份独有的流程。

搜到的图文教程先对一眼截图和自己的界面，对不上就别按它的步骤找按钮。
