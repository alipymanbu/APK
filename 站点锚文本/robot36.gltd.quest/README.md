# robot36 收图站

这里是 Robot36（安卓上的 SSTV 慢扫描电视解码应用）的第三方整理页：把这款开源工具的工作原理、收图步骤与收听经验集中在一处，帮助业余无线电爱好者用一部手机收到第一张 SSTV 图。

- 应用定位：把短波电台、空间站发来的 SSTV 音调信号实时解码成图片
- 内容方向：解码原理、收图三步、常用频率、异常排查
- 相关入口：[robot36 收图站](https://robot36.gltd.quest/)（介绍与安装指引）
