# 解码异常与收不到图排查

> 界面没反应、解出的一半是花屏、图像整体倾斜——本篇按现象归类，给出从音频链路到信号环境的逐条排查顺序。
> **相关文档**：[SSTV收图入门指南.md](SSTV收图入门指南.md) · [短波与空间站收图频率.md](短波与空间站收图频率.md)

## 一、先分清「链路问题」还是「信号问题」

排查前先做一个二分：

- 界面**完全没有**音频跳动、频谱是平的 → 链路问题（麦克风没收到声音）；
- 频谱在动、也听到了音调，但出图异常 → 信号问题（噪声、衰落、频偏）。

Robot36 的界面底部有实时频谱，这个一眼可辨的指示器就是排查的第一工具。

## 二、链路问题：界面没反应

1. **麦克风权限没给**：系统设置 → 应用 → Robot36 → 权限，确认麦克风已允许；首次启动拒绝过的话，解码输入就是空白；
2. **声音根本没放出来**：确认声源（电台 / 录音 / 远程接收站）确实在播放，音量不为零；
3. **距离与音量**：麦克风凑近扬声器几厘米到十几厘米，音量清晰但不破音——破音会让频谱削顶，反而解不出来；
4. **静噪推不开**：收空间站或强信号电台时，把接收机静噪全部打开，SSTV 音调推不开正常设置的静噪，会漏掉图像开头。

## 三、信号问题：出图但质量差

### 倾斜（斜条纹）

与收发两端时钟偏差有关，是 SSTV 接收的常见现象，不全是接收方的问题——很多发射台本身就带一点偏差。轻微倾斜不影响辨认画面；持续严重倾斜可换别的信号源验证设备是否正常。

### 撕裂、错位

多发生在信号衰落或频偏时：

- 短波衰落是常态，图像解到一半变差、随后恢复属正常，等下一张即可；
- 收空间站时按三步法补偿多普勒（145.805 → 145.800 → 145.795 MHz），紧跟信号能明显减少撕裂；
- 换时段或换波段再试——传播是收图质量的最大变量。

### 偏色、发绿

多为信号弱、噪声混入所致：改善声学环境（到室外或窗边、远离电器噪声源）、提高信噪比后即恢复。想从根本上摆脱环境噪声，可以改用音频线直连（需要衰减与隔离电路，不能拿普通音频线直通）。

### 整幅花屏、认不出模式

发送端用的可能是老旧黑白格式或暂不支持的模式——画面会以 Raw 模式显示原始扫描线。这不算故障：它证明链路是通的，只是这张「图」没有被当成已知模式来解。

## 四、重试前的两件小事

- **等下一张**：短波互传一张接一张，ISS 活动按「发两分钟、停两分钟」连发，错过开头或解坏了都不用急；
- **换样本验证**：拿一段确定良好的 SSTV 录音外放解一遍——能出图说明设备与设置没问题，剩下的变量就是信号本身。
