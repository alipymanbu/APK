## 一、先记住一条铁律

**不给只在网上认识的人转账。**编「突发医疗急事」「旅行被困」「生意机会」要钱的，全是骗局；礼品卡、加密货币与现金一样，一律不给。「投资理财」「荐股带单」这类主动送上门的发财机会同样要警惕。社区明文禁止成员之间的金钱往来——真正的朋友不会向刚认识的网友开口要钱，遇到就停聊、举报、拉黑，不用觉得不好意思。

## 二、常见骗局信号清单

对照下面的红旗信号，命中越多越要警惕：

| 信号 | 说明 |
| --- | --- |
| 好得不真实 | 照片过于漂亮、人生经历近乎完美 |
| 感情推进极快 | 没见过面就迅速表白、谈婚论嫁 |
| 拒绝视频 | 一提视频通话就找各种借口 |
| 开口提钱 | 任何形式的金钱请求，零例外 |
| 急着转移到站外 | 立刻想把你引到邮箱、其他聊天软件私聊 |
| 语言前后矛盾 | 语法混乱、消息像复制粘贴的模板 |
| 发可疑链接 | 推来路不明的网站让你点 |

另外：InterPals 的定位是友谊与语言交流，不是约会软件。对方主页会写明想认识什么人，联系前先看一眼，能避开大部分尴尬与麻烦。

## 三、举报一个账号的五步

1. **停止回复**可疑消息；
2. 在对方主页底部点 **Report（举报）**；
3. **选择原因**（假资料、骗子、垃圾信息等）；
4. **写清细节**——附上可疑行为的具体例子，细节越全越容易被受理；
5. **拉黑**对方，断掉后续接触。

两点预期：审核由志愿者与自动化系统处理，不会立刻有结果，也可能因证据不足不处理，所以证据尽量写全；举报是保密的，被举报的人永远看不到是谁举报的，不必有心理负担。

## 四、拉黑与保护自己

- 最快的拉黑方式：在对方主页点 Block this user；批量管理在 Settings → Privacy 里编辑黑名单。拉黑即时生效，对方无法再联系你、也看不到你的资料，且不会收到任何通知；
- 个人信息晚点给：全名、住址、电话、财务信息，都不要在刚认识时就交出去；
- 对话留在站内：出了问题才有人能帮你；急着把你引去别处私聊的，本身就是一条红旗；
- 见面或深聊之前先视频：这是确认「屏幕对面是谁」最直接的办法。
