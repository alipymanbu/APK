# 在 InterPals 上怎么找到母语语伴

> 本篇讲搜索筛选条件的用法、四步锁定母语语伴的方法、除了搜索之外的其他找人入口，以及发出第一条消息前的准备。

## 一、搜索条件有哪些

InterPals 的搜索页可以按这些条件筛人：

| 条件 | 说明 |
| --- | --- |
| 国家 | 想认识哪个国家的人就选哪个，180 多个国家可选 |
| 城市 | 想了解某座城市或约见面时用得上 |
| 年龄 | 按年龄段收窄范围 |
| 会说的语言 | 找母语者主要靠这一项 |
| 正在学的语言 | 找互惠语伴的关键条件 |

## 二、四步锁定一个母语语伴

这是语言交换场景下最有效的搜法：

1. 打开搜索页；
2. 在「会说的语言」里选你的**目标语言**（你想练的那门）；
3. 把该语言的最低水平设为 Native（母语）或 Proficient（精通）；
4. 叠加国家条件（学日语就限定日本），最后优先找**正在学你母语**的人——双方都有得练，回复率也更高。

语言档案的五档水平（入门 / 中级 / 高级 / 精通 / 母语）要填准：搜索按它筛人，把中级标成母语，招来的对话会超出承受能力，反而聊不下去。练了几个月水平涨了，记得回主页把档位改上去。

## 三、搜索之外的找人入口

- **Online Now（此刻在线）**：在线的人更容易聊起来；
- **谁看过我的主页**：对你主页感兴趣的人，可以主动打招呼；
- **群组与社区动态**：按兴趣加入群组、发帖，不用私聊也能先混个脸熟；
- **书签**：在别人主页底部点 Add bookmark 存起来，之后统一回访。

主页被看得多但没人来信？先检查两件事：语言两项填全了吗（直接影响搜索命中率）、照片传了吗。资料就绪之后，主动找上门的消息会明显多起来。

## 四、发出第一条消息之前

- 先读对方的「关于我」——主页写明了想认识什么人，先看再开场；
- 开场白具体一点，提一句对方主页里的内容，比群发模板有效得多；
- 等得起——大多数人会在一两天内回复，笔友社区节奏本来就慢；
- 每天能主动联系的新人有限额，注册越久上限越高，别把名额挥霍在群发上。

找一个能长期互练的语伴，比广撒网重要得多。如果还没装手机应用，可以从 [InterPals 笔友社区介绍站](https://interpals.yoan.quest/)的[安卓应用安装步骤](安卓应用安装步骤.md)入手；聊天时遇到不对劲的人，处理方法见[聊天安全与防骗要点](聊天安全与防骗要点.md)。
