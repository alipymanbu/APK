# 手机版怎么连接电脑传壁纸

Wallpaper Engine 的安卓端本身不带壁纸商店，社区里那成千上万张动态壁纸要靠电脑版「递」过来。整个过程走局域网无线传输，第一次配对输一次 4 位 PIN，之后基本不用再管。想先拿安装包的，可以从 [Wallpaper Engine 安卓版](https://wallpaperengine.rggd.pw/) 的站点入口进去找资源指引。

## 配对前的三件事

1. **电脑上装好 Windows 版 Wallpaper Engine**：手机端的价值建立在电脑版之上——壁纸库、场景优化都由它完成；
2. **两端连同一个局域网**：手机别开流量、别连访客网络，部分路由器的「AP 隔离」也会挡住互相发现，遇到搜不到就先关掉它；
3. **Windows 防火墙放行**：第一次运行电脑版时弹出的防火墙询问选「允许」，当时点了取消的话，到防火墙设置里把 Wallpaper Engine 重新放行。

## 配对步骤

1. 打开电脑版 Wallpaper Engine，点界面右上角的**「移动设备」**按钮；
2. 在弹出的设备概览里点**「连接新设备」**，屏幕上会出现一个 4 位 PIN；
3. 打开手机端应用，点右下角的**「添加」**，再选**「与计算机配对」**；
4. 应用会搜索局域网里正在运行的电脑版，几秒后点选你的电脑；
5. 输入电脑屏幕上的 4 位 PIN——输对了，手机状态栏和电脑右上角按钮会同时变绿。

配对成功后，两端同时在线时会自动重连，日常使用不用每次重新输 PIN。

## 把壁纸送到手机

- 在电脑版的壁纸列表里**右键**任意兼容壁纸，选**「发送至移动设备」**，再挑目标手机；也可以按住 Ctrl 多选，一次传一整组；
- **场景类**动态壁纸（会动、会交互的那种）发送前会先针对手机硬件做一轮优化，耗时视壁纸复杂度而定，属正常现象；
- 优化时会问你要哪种**质量**：高分辨率壁纸在手机上卡顿的话，选「均衡」这条路线通常就能跑顺；
- 传完在手机端列表里点开壁纸，预览、拖动调整显示范围，确认后设为桌面。

## 搜不到电脑时的排查顺序

1. 先确认两端真的在同一网段（手机开热点给电脑用也算同一局域网）；
2. 电脑版是否正在运行——它没开，手机端自然搜不到；
3. 防火墙 / 安全软件有没有拦局域网通信；
4. 以上都对还是不行，退而求其次走导出方案：在电脑版把壁纸导出成 `.mpkg` 包，传到手机后用「导入文件」装进去，效果与无线传输一致。
