# 视频与GIF怎么做成动态壁纸

没有电脑版在身边，也能让手机桌面动起来。Wallpaper Engine 的安卓端留了一个「导入文件」入口：存储里的视频、GIF，以及从别处拿到的 `.mpkg` 壁纸包，都能直接变成动态壁纸。安装包资源的获取指引见 [Wallpaper Engine 安卓版介绍站](https://wallpaperengine.rggd.pw/)。

## 能导入哪些东西

| 格式 | 适用情况 |
| --- | --- |
| MP4 等视频 | 自己拍的视频、下载的短片，是最省事的动态壁纸来源 |
| GIF | 循环短动画；时长长、帧数多的 GIF 会比较占内存 |
| .mpkg 包 | 别人从 Wallpaper Engine 里分享出来的壁纸包，可能包含场景类动态壁纸 |

## 导入步骤

1. 把素材放到手机存储里（聊天工具发给自己、数据线拷贝、网盘下载都行）；
2. 打开手机端应用，首页有两个大按钮，选**「导入文件」**；
3. 在文件选择器里找到目标视频 / GIF / mpkg，选中后应用会生成预览；
4. **左右拖动**调整壁纸的显示范围（视频比屏幕长时尤其有用）；
5. 把底部拖柄向上拖，能展开更多设置：播放速度、动态响应等偏好都在这里；
6. 点右上角确认，再到系统壁纸设置里选「壁纸引擎」作为当前壁纸。

## 从电脑版或朋友那里拿 mpkg 包

- 在**手机端**的壁纸列表里长按想分享的壁纸，选**「分享文件」**，即可把它打包成 `.mpkg` 发给别人；
- 拿到包的人同样走「导入文件」这条路径装入手机；
- 需要注意：创意工坊里需要授权的场景壁纸不在可分享范围，能分享的多为开放授权的内容。

## 视频壁纸的几个实用建议

- **时长控制在 15~30 秒**：循环自然、文件不大，渲染压力也小；
- **优先选暗色调素材**：亮色大面积长时间渲染更费电，图标可读性也差；
- **避开高帧率素材**：60fps 的视频壁纸对中端机是纯负担，30fps 的观感差距很小；
- 导入后记得把**帧率上限**调低一点，配合省电暂停使用，见 [动态壁纸费电怎么调](动态壁纸费电怎么调.md)。

想用社区创作者的场景类壁纸，还是得走电脑版传输那条路，具体见 [手机版怎么连接电脑传壁纸](手机版怎么连接电脑传壁纸.md)。
