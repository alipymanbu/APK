# rpcs3 安卓版固件安装与游戏导入

> 本篇讲模拟器装好后的两步关键操作：安装 PS3 系统固件、导入游戏文件。没有固件模拟器开不了任何游戏，没有游戏文件它就是个空壳。还没装上模拟器的先看 [安卓版下载与安装步骤.md](安卓版下载与安装步骤.md)。

## 一、为什么模拟器里什么都没有

装好的模拟器是空的，固件和游戏都不随 APK 一起分发——两者都受版权保护，只能由玩家自己准备。这不是缺功能，所有 PS3 模拟器（包括电脑版）都是这个规矩：

- **固件**：PS3 主机的系统软件，模拟器靠它才能像真主机一样运行游戏，从索尼提供的系统软件页面获取。
- **游戏**：需要来自玩家自己的正版游戏备份（自己的光盘或主机里导出的数据）。用别人的盗版游戏文件不在本篇讨论范围。

## 二、下载 PS3 固件（PS3UPDAT.PUP）

固件在索尼 PlayStation 的系统软件页面免费提供：

1. 用手机浏览器打开索尼的支持页面，找到「How to update PS3 system software」一节，选 **Update using a computer**（用电脑更新）。
2. 点 **Download PS3 Update** 下载固件文件，个别浏览器需要长按链接选「在新标签页打开」才会触发下载。
3. 下载得到的就是 `PS3UPDAT.PUP`，体积约 200 MB，放在「下载」文件夹备用即可。

只认索尼这一个渠道就够了，别去第三方「固件下载站」找。

## 三、安装固件

不同移植版本的菜单入口略有差别，流程一致：

1. 打开模拟器，进主菜单（通常是左上角的三横线按钮）。
2. 找到固件入口，没装过时这里一般显示 **Firmware: None**（固件：无）。
3. 点进去会调起系统文件选择器，定位到刚下载的 `PS3UPDAT.PUP` 选中它。
4. 等待安装完成，装完界面上固件状态不再是 None 即为成功。

固件只需要装一次，之后升级模拟器版本一般不用重装（个别大版本更新后要求重装，届时再装一遍）。

## 四、导入游戏

### 支持的格式

| 格式 | 特征 | 说明 |
| --- | --- | --- |
| PKG | 单个 `.pkg` 文件 | 需要在模拟器内安装，个别还要求配套激活文件才能启动 |
| ISO | 单个 `.iso` 光盘镜像 | 光盘备份的常见形态，使用最省事 |
| 文件夹 | 含 `PS3_DISC.SFB` 与 `PS3_GAME` 子目录 | 主机硬盘备份的原始目录结构，整包拷进手机 |

不同移植版本对格式的支持进度不同，以所用版本发布的说明为准。

### 导入步骤

1. 把游戏文件传到手机（USB、局域网、网盘都行；文件夹格式的游戏要保证目录结构完整）。
2. 打开模拟器，点主界面的 **+** 号。
3. 单个游戏选「文件」，去文件选择器选中 ISO 或 PKG；一次导一批就选「文件夹」，选中放游戏的目录。
4. 等待导入完成，PKG 的安装耗时明显属正常现象。
5. 有的版本导完不会自动刷新，在游戏列表页下拉刷新即可。

### 文件摆放建议

- 游戏文件平铺放在同一个目录里，别一层套一层——有玩家反馈部分移植版本对深层嵌套支持不好，识别不到游戏。
- 优先用解密好的 ISO，社区反馈里最省事；文件夹次之，PKG 最麻烦。
- 存储紧张时游戏可以放 microSD 卡（建议格式化成 exFAT），导入时留意读卡速度对耗时的影响。

## 五、导入成功之后

- 游戏首次启动普遍很慢（在预编译缓存），黑屏转圈几十秒到几分钟都有可能，中途别杀进程，第二次起同一游戏会明显变快。
- 进游戏后第一件事是接手柄：系统蓝牙配对后，在设置的按键映射里按真实 PS3 手柄布局对号入座，L2 / R2 这类模拟量按键重点检查。
- 游戏黑屏、闪退或速度极慢，先对照 [哪些手机能跑得动.md](哪些手机能跑得动.md) 查机器是否达标，再核对游戏格式与固件状态。

安装包还没到手的，入口在 [rpcs3 掌上手册](https://rpcs3.yoan.quest/) 的下载页；装好后的完整上手路线也可以从 [安卓版下载与安装步骤.md](安卓版下载与安装步骤.md) 接着走。
