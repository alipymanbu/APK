# 注册账号邮箱与验证的注意点

想玩橘子系的游戏，账号这一关绕不开 Beanfun。注册流程本身不复杂，但邮箱怎么选、手机验证有地区限制、动态密码器怎么绑，这几处每年都有玩家踩坑。本文把注册环节的注意点集中整理一遍。

## 动手前备好三样东西

| 要准备的 | 说明 |
| --- | --- |
| 常用邮箱 | 确认信、找回密码、异地登录通知以后都走它，别用随手注册的一次性邮箱 |
| 真实出生日期 | 参与日后身份类认证的资料比对，填假的后患不少 |
| 能收短信的手机号 | 手机验证有地区限制，见下文 |

注册入口有两个：手机 App 首页的「注册」，或电脑浏览器打开会员站点注册，两边同一账号体系。装了 App 的话直接在 App 里走完最省事。

## 流程与邮箱选择

注册六步：点「注册」→ 填邮箱收确认信 → 点确认链接 → 设账号密码 → 填会员资料 → 登入一次确认能进主界面。

邮箱方面，玩家社群多年积累的经验就两条：

- 部分国内邮箱（尤其 QQ 邮箱）有收不到验证信、或信件进垃圾箱的情况；几分钟没收到先翻垃圾邮件再重发。
- 普遍建议用 Gmail、Outlook 这类国际邮箱——注册只是一次性，收信是长期的，找重密码、安全通知都靠它。

## 手机验证的地区限制

这是最容易卡住的一步：

- **台湾账号**：手机验证面向台湾本地号码，大陆手机号过不了这层验证；
- **香港账号**：双重认证绑手机目前支持香港、澳门号码（以页面当时提示为准）；
- 没有对应号码时，账号通常仍可注册和基础使用，只是涉及手机验证的进阶功能做不了——不要为了过验证乱填号码。

## 双重认证：先装验证器再点下一步

Beanfun 支持用 Google Authenticator 或 Microsoft Authenticator 生成动态密码（每 30 秒一换）。绑定流程：App 内进账号安全设置 → 选绑定 → 页面出二维码 → 验证器扫码 → 抄 6 位动态码填回确认。

最容易踩的坑是顺序反了：页面提示「下载验证 APP」就一路点下去，等要扫码时验证器还没装好，二维码早过期了。正确顺序是**先装好验证器、能打开，再点下一步出码**。绑定后换手机时动态密码不会自动跟过去，迁移方法值得提前了解；相关登录与排错话题另见[扫码登录电脑游戏的操作与排错](扫码登录电脑游戏的操作与排错.md)。

## 注册完之后

账号就绪后，下一步按用途分流：要充点数的先弄清账号分区，读[乐点卡分区与储值常识](乐点卡分区与储值常识.md)；要装 App 的可以从 [beanfun.qhah.skin](https://beanfun.qhah.skin/) 介绍站拿安卓安装文件资源的入口。
