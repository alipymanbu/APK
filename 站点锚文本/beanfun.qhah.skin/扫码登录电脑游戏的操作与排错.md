# 扫码登录电脑游戏的操作与排错

在电脑上玩橘子系端游（新楓之谷这类）时，登录走的是网页流程：账号密码输完还要应付各种额外验证。用手机上的 Beanfun App 扫二维码，是玩家更爱走的那条路——电脑上全程不碰密码，手机在手边才能放行，安全省事。本文整理扫码登录的完整操作和扫不上的排查思路。

## 为什么推荐扫码

- 电脑端不输密码，键盘记录、输错锁定这类风险直接绕开；
- 确认动作发生在你自己的手机上，别人拿到你的电脑也登不进你的账号；
- 新设备、异地 IP 触发的额外检查，扫码确认一下就能过。

## 操作步骤

1. 手机上先登录好 Beanfun App（还没注册的先看[注册账号邮箱与验证的注意点](注册账号邮箱与验证的注意点.md)）。
2. 电脑上启动游戏，走到登录页选扫码（QR Code）方式，屏幕出现二维码。
3. 打开 App 里的扫一扫，对准电脑屏幕上的二维码。
4. 手机弹出确认框，核对设备信息后点确认。
5. 电脑登录页自动跳转，回游戏就能进了。

注意两点：手机必须能上网，且 App 登录的账号和电脑要登的是同一个；一个主账号下可以建多个游戏子账号，登录前先选对要用的那一个。

## 扫不上的时候按这个顺序查

| 现象 | 处理 |
| --- | --- |
| 扫完电脑页面没反应 | 网页会话过期，刷新登录页重新出码再扫（二维码一两分钟就失效，属设计如此） |
| 手机提示网络错误 | 换 Wi-Fi 或流量再试 |
| 扫码成功但登录页报错 | 核对两边是否同一账号、同一分区（台湾站与香港站账号不通用） |
| 二维码扫不出来 | 调高屏幕亮度、关掉护眼滤镜，扫码窗对准整个码 |
| 常用设备也频繁要验证 | 检查浏览器 Cookie 是否被清过；偶尔多验一次属正常安全机制 |

实在扫不了码（屏幕反光、摄像头不便）时，登录页也支持「账号 + 密码 + 动态密码」的方式，前提是验证器已绑定。

还没装 App 的玩家，可以从 [beanfun.qhah.skin](https://beanfun.qhah.skin/) 这个介绍站入手，里面有安卓安装文件资源的获取入口和安装步骤。
