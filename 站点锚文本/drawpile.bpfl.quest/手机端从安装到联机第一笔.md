# 手机上用 Drawpile 画画：从装好到联机第一笔

Drawpile 的安卓版同时照顾手机与平板：竖屏用紧凑布局，平板横屏自动铺开成桌面布局。这篇按上手顺序把装好之后的事捋一遍——把界面调顺手、记住几组触屏手势、确认笔能出墨，然后进房间和朋友同画一块布。

## 一、先把界面调顺手

应用默认按窗口大小在两种布局间自动切换，手机竖屏收紧、平板横屏铺开，一般不用管。想固定某一种，去「首选项」的用户界面设置里改；画布显示比例不对时，「视图」→「适应屏幕」一键复位。

## 二、触屏手势速记

| 手势 | 作用 |
| --- | --- |
| 单指点按并按住 | 从画布上取色 |
| 双指点按 | 撤销一步 |
| 三指点按 | 重做一步 |
| 双指拖动 | 平移画布 |
| 双指捏合/张开 | 缩放画布 |
| 双指旋转 | 旋转画布（转回近 0 度自动摆正） |

全部手势都能在「首选项」→「触摸」标签里改。注意按住取色是「点按后不松手」，不是长按菜单；手势失灵先检查是不是手掌握住了屏幕边缘造成误触。

## 三、笔不出墨的两组开关

用手指画不出东西时，两处要对齐：「首选项」→「触摸」里，触摸模式选 Touchscreen、单指输入选 Draw，改完立刻生效。用压感笔没有粗细变化时，先换几支默认笔刷试（压感挂在笔刷的「压力动态」上），再到「首选项」→「平板」确认压感总开关开着；「帮助」→「平板测试器」里画出绿色或蓝色笔迹，才说明压感输入被认出来了。没有压感笔也能画，只是线条没有粗细变化。

## 四、进房间和朋友同画

装好后开画室只要三步：菜单「会话」→「托管」设定画布尺寸与标题开房，把会话链接发给画友，对方从「会话」→「加入」进来，笔迹就实时长在同一块画布上。具体的房间管理、密码与操作员权限，见 [房间开法与权限速查](房间开法与权限速查.md)。

软件的界面细节、功能盘点与安卓安装包的获取入口，都整理在 [Drawpile 联机绘画应用介绍](https://drawpile.bpfl.quest/)，动笔之前可以先过一眼。
