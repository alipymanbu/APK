# Drawpile 房间玩法速查：开房、加房与权限管理

Drawpile 的一切联机活动都围绕「会话」展开：一间房间就是一块所有人共享的画布，谁落一笔，其他人的屏幕上立刻出现这一笔。本篇把开房、加房、找房和房主常用的管理操作归成一份速查，装好应用后照着做就能开画。

## 一、自己开一间房间

1. 菜单里选「会话」→「托管」；
2. 设定画布尺寸与房间标题，需要的话勾上密码；
3. 托管位置选内置服务器（自己这台设备就是画室，最省事），或挑一个公共服务器；
4. 确认后房间即开，把会话链接发给画友即可。

自己托管的房间随房主下线而解散，画到一半记得勤保存；想开一间不依赖某人在线的房间，得架在一直开机的服务器上，普通玩家用内置托管就够了。

## 二、加入别人发来的房间

- 复制邀请链接（形如 `https://…/join/…` 的地址），走「会话」→「加入」粘贴进入；
- 房间设了密码就向房主要，密码区分大小写；
- 拿到的是 IP 或主机名也一样填进「加入」的地址栏；
- 部分服务器的邀请链接在手机浏览器里点开就能进，不用装客户端。

## 三、在公共会话列表里找画室

菜单「会话」→「浏览」会列出当前公开的房间，显示标题与在线人数，挑一间点进去围观或加入。想让自己的房间被人找到，就设为公开并起个能看出主题的标题。进别人的房间先看规则，不少房间有房主定的约束（比如不许盖别人的画）。

## 四、房主常用的管理操作

| 操作 | 在哪 | 效果 |
| --- | --- | --- |
| 设房间密码 | 开房时勾选；运行中走「会话」→「设置」 | 没密码的人进不来 |
| 分配操作员 | 用户列表长按/右键菜单 | 被授予的人可管理图层、踢人 |
| 锁定会话 | 会话菜单 | 其他人暂时不能下笔，适合讲课交接 |
| 踢出/封禁 | 用户列表菜单 | 把捣乱的人请出去 |
| 调撤销步数上限 | 「会话」→「Undo Limit」 | 撤销历史用完时放宽额度 |

两件联机时容易困惑的事：撤销历史是**全房共享**的，延迟高的房间里撤销会慢半拍；别人画了几笔后撤不回自己更早的笔画，也是同一条历史线的缘故，把 Undo Limit 调大能缓解。

进房被踢、改不了东西这类问题属于房主设置，直接找房主问。想看更完整的介绍与安装入口，见 [Drawpile 联机绘画应用介绍](https://drawpile.bpfl.quest/)；手机端上手路径另见 [手机端从安装到联机第一笔](手机端从安装到联机第一笔.md)。
