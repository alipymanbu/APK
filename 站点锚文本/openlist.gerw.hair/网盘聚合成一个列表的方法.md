# OpenList 网盘聚合成一个列表的方法

> 阿里云盘、百度网盘、OneDrive 各一个客户端来回切换太累：这篇讲怎么把它们连同手机目录一起挂进 OpenList，变成一个统一入口。
> **相关文档**：[手机当文件服务器的搭建步骤.md](手机当文件服务器的搭建步骤.md) · [电视电脑直接播放网盘影片.md](电视电脑直接播放网盘影片.md)

---

## 一、添加存储的通用步骤

不管挂什么，入口都在管理后台：

1. 登录后进管理界面（页面底部的「管理」按钮）；
2. 左侧菜单选「存储」，右上角点「添加」；
3. 选驱动（要挂的网盘或存储类型），填**挂载路径**——这个存储在列表里的位置，比如 `/阿里云盘`；
4. 按驱动要求填令牌、地址或路径，保存后回到首页刷新即可看到。

两个通用注意点：挂载路径必须唯一，重复了会报 `UNIQUE constraint failed: x_storages.mount_path`，换一个没被占用的位置即可；不少网盘驱动要求目标文件夹真实存在，先去网盘里建好目录再挂。

## 二、挂载阿里云盘

1. 浏览器打开 `https://api.oplist.org`（在线令牌工具）；
2. 下拉选「阿里云盘 App 登录」，没有自建开放平台应用的话，勾选使用 OpenList 提供的参数；
3. 登录后拿到**刷新令牌（refresh token）**，复制；
4. 回到添加存储页，选阿里云盘 Open 平台对应驱动，把令牌填进去，挂载路径填一个未占用的位置，保存。

一条值得原样转述的红线：**不要把挂载后的阿里云盘公开分享，不要让账号被多个 IP 访问**，否则账号可能被触发风控冻结且无法解除；个人自用、少量 IP 访问是安全区。

## 三、挂载百度网盘与其他

百度网盘流程一致：同一个令牌工具里选百度网盘验证登录、取刷新令牌、回存储页填入保存。部分网盘还需要在自家设置里允许第三方应用授权，遇到授权报错先去这一边检查。想挂手机里的相册、电影目录，驱动选「本机存储」类，根文件夹路径填手机目录即可；已有 NAS 或服务器的，选 WebDAV / FTP / SFTP 对应驱动，填地址端口账号密码。

## 四、不想挂了：解除网盘授权

换用或停用时，建议顺手把网盘侧的授权撤掉——授权列表里显示为 **Alist** 字样的条目就是它（沿用同一套开放平台接入）：

| 网盘 | 解除路径（以各 App 当前版本为准） |
| --- | --- |
| 百度网盘 | 我的 → 设置 → 帐号管理 → 授权管理 → 找到 Alist → 解除 |
| 阿里云盘 | 我的 → 右上齿轮 → 隐私设置 → 授权管理 → 找到 Alist → 解除 |
| OneDrive | 网页打开 `https://account.live.com/consent/Manage` → 移除授权 |

解除后对应存储的令牌立即失效，再挂要重走一遍令牌流程。

## 五、挂好之后能干什么

首页按挂载路径逐级浏览，右下角工具栏有刷新、上传、离线下载、批量重命名、聚合移动等操作；上传可勾选「尝试秒传」或「添加为任务」后台慢慢传；离线下载支持 Aria2、qBittorrent、SimpleHttp。想在电视、电脑上直接播放这些网盘影片，走 WebDAV，参数与客户端见[电视电脑直接播放网盘影片.md](电视电脑直接播放网盘影片.md)；界面上每个功能的位置，[OpenList 图文介绍站](https://openlist.gerw.hair/)里有逐屏截图可对照。
