# OpenList 电视电脑直接播放网盘影片

> 网盘里的电影不想先下载再拷 U 盘：这篇讲怎么用 WebDAV 让电视、电脑、播放器直连 OpenList 里的文件，填一次参数长期受用。
> **相关文档**：[网盘聚合成一个列表的方法.md](网盘聚合成一个列表的方法.md) · [手机当文件服务器的搭建步骤.md](手机当文件服务器的搭建步骤.md)

---

## 一、先把 WebDAV 权限打开（默认是关的）

内置服务沿用上游默认权限，初始账号的 WebDAV 默认不开启，客户端直连会被拒。开启位置在管理后台：

1. 管理 → 用户 → 编辑要用的账号（默认是 admin）；
2. 只想看和播放：勾选「**WebDAV 读取**」；
3. 还要在客户端里上传、改名、删除：再勾「**WebDAV 管理**」，并同时勾上对应的具体文件权限（创建目录或上传、重命名、删除等）——只勾「WebDAV 管理」一项是不够的。

## 二、连接参数怎么填

| 配置项 | 填什么 |
| --- | --- |
| 地址 | `http://手机IP:5244/dav/`（配了外网访问就换成对应域名地址） |
| 路径 | `dav` |
| 端口 | 与网页端一致，默认 `5244` |
| 用户名 / 密码 | 与网页端登录用的完全一致 |

三个易错点：结尾的 `/dav/` 不能漏；端口必须和访问网页用的端口一致；密码就是网页登录密码，不存在另一个单独的 WebDAV 密码。

## 三、各平台怎么连

| 平台 | 文件管理 / 挂载 | 媒体播放（可直连播放） |
| --- | --- | --- |
| Android | Solid Explorer、MiXplorer、X-plore | nPlayer、Kodi、VLC |
| Windows | RaiDrive（挂成网络磁盘）、Mountain Duck、rclone | PotPlayer、Kodi |

选型建议：想把文件服务变成电脑上的一个盘符，用 RaiDrive 这类挂载工具；电视盒子上看电影，用 Kodi 或 nPlayer 直接添加 WebDAV 源最省事。

## 四、三个典型场景

- **电视看网盘电影**：电视装 Kodi → 添加视频源选 WebDAV → 填上面的参数 → 直接浏览播放挂载的网盘视频，不用先把文件下到本地；
- **同一台手机自挂**：在手机的文件管理器里添加 WebDAV，地址填 `http://127.0.0.1:5244/dav`（端口以应用内为准），再配 nPlayer 播放，应用开着时即插即用；
- **电脑当本地盘用**：RaiDrive 填参数挂成 Z: 盘，在资源管理器里直接拖拽复制。

## 五、连不上的排查顺序

按顺序过一遍：权限开了没有 → 地址端口对不对 → 账号密码对不对 → 手机端服务还在不在后台跑。能浏览却不能写（比如 RaiDrive 往里扔文件提示没权限），几乎都是服务端用户权限没配全——回管理后台把「WebDAV 管理」连同具体文件权限一起勾上。服务本身起不来或频繁断连的处理，见[手机当文件服务器的搭建步骤.md](手机当文件服务器的搭建步骤.md)。
