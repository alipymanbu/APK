# SOLIDWORKS 文件在手机上怎么打开

> 手里的 .sldprt / .sldasm 文件想在手机上看一眼，又不想开电脑：这篇把可行路子、格式门槛和常见失败原因整理成一篇可操作的说明。

工位上没有电脑、出差路上收到同事发来的模型——这类场景在机械行业太常见了。SOLIDWORKS 的原生文件（零件 .sldprt、装配体 .sldasm、工程图 .slddrw）在安卓手机上是可以直接打开的，用达索系统出品的 eDrawings 安卓版即可：它就是为「把设计文件发给不看 CAD 的人看」这件事而生的查看器。

## 一、先核对文件类型

手机上能直接打开的文件不只有 SOLIDWORKS 原生格式，下面这些都是 eDrawings 安卓版的支持范围：

| 类别 | 扩展名 | 说明 |
| --- | --- | --- |
| SOLIDWORKS 原生 | .sldprt / .sldasm / .slddrw | 零件、装配体、工程图 |
| eDrawings 审阅格式 | .eprt / .easm / .edrw | 桌面端发布后的轻量文件 |
| AutoCAD 交换格式 | .dxf / .dwg | 2D 图纸常见 |
| 通用 3D 交换格式 | .step / .stp / .stpz、.iges / .igs | 跨软件协作的兜底选择 |
| 其它 | .jt（v10.0 及更早）、.ifc | JT 不含 PMI；IFC 是建筑常用 |

注意边界：Inventor、CATIA、Creo 这类工业格式**手机版打不开**（那是桌面版的能力）。收到这类文件，先在电脑上转成 STEP 或 eDrawings 文件再传手机。

## 二、打开的具体路子

1. **文件先进手机**：微信 / QQ 文件传输助手、邮箱附件、夸克等网盘 App 都行；局域网共享文件夹和 FTP 直链也是 eDrawings 认的来源。
2. **装好看图应用**：安装文件资源的获取入口整理在 [eDrawings 手机版介绍站](https://edrawings.fewf.click/)，从那里进网盘转存下载即可。
3. **打开方式**：在文件管理器或传输工具里点开文件，选择用 eDrawings 打开；也可以先进 eDrawings，从它的打开入口选云存储或网络位置。
4. **转动看细节**：单指旋转、双指缩放平移，双击回到适配视图；装配体若发布时带了爆炸状态，直接就能看装配关系。

## 三、打不开时按这个顺序排查

- **扩展名对不对**：传输过程有时会把扩展名弄丢或改掉（比如 .sldprt 变成 .sldprt.1 或不带后缀），改回来就能识别；
- **文件完整吗**：大装配体传输中断并不少见，重新传一遍再试；
- **版本是不是太新**：用旧版查看器打开「更新版本 SOLIDWORKS 保存」的原生文件可能失败，让对方另存为 STEP 是最稳的兜底；
- **格式本身不支持**：对照上面的清单，Inventor / CATIA / Creo 需要先转换。
