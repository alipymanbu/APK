# 免费版看图够不够用

> 装上 eDrawings 之后不花一分钱能干哪些事、什么情况下才真的需要升级 Pro：这篇按功能一条条划清楚，帮你判断要不要掏这笔钱。

先把结论放前面：**只收图、看图、转发图，免费版就够了；要量、要剖、要圈改回传，才考虑 Pro**。手机上只有一个应用本体，Pro 是应用内购买解锁，不存在「再装一个 Pro 版」的说法。

## 一、免费版能干的事

- 打开 2D / 3D 文件：SOLIDWORKS 原生、eDrawings 审阅文件、DXF/DWG、STEP、IGES 等都在列；
- 触控操作：单指旋转、双指捏合缩放、双指平移，双击屏幕回到适配视图；
- 动画标准视图：3D 模型的标准视角按动画方式切换，转向过程看得见；
- 爆炸视图：从 SOLIDWORKS 发布的文件自带分解状态，手机上直接看装配关系；
- 2D 工程图逐张翻页浏览；
- 全屏查看 + AR 增强：把模型投进真实场景做适配核对（依赖 ARCore 支持）。

对应的安装方式与格式清单整理在 [eDrawings 手机版介绍站](https://edrawings.fewf.click/)，这里不重复展开。

## 二、Pro 才有的三件事

| 功能 | 具体能力 | 谁需要 |
| --- | --- | --- |
| 测量 | 距离、角度、长度、点对点 | 现场核尺寸、验收 |
| 横截面 | XY / YZ / ZX 方向剖切、可拖动 | 查内部结构 |
| 标记 | 文字注释、手绘符号、随文件共享 | 圈改后回传设计 |

升级路径：应用内右上角菜单 → Upgrade to Pro → Google Play 完成购买。换手机后登录同一 Google 账号可恢复购买。

## 三、两个「不花钱也能量」的例外

1. **审阅启用文件**：对方用桌面版 eDrawings Professional 发布的文件自带审阅属性，你用免费版就能测量和标注。收到文件先开来试试，再决定升不升级。
2. **原始格式不受文件开关限制**：直接打开 SOLIDWORKS 原生、STEP、DWG 这类「原始格式」时，测量只看你的版本（免费还是 Pro）；但 eDrawings 文件（.easm / .eprt / .edrw）还有一道**文件级开关**——发布时没勾「允许测量」的，谁打开都量不了，买了 Pro 也没用，只能让发件方重新发布。

## 四、决策参考

- 车间对照、给客户展示、通勤路上收图 → 免费版 + 好好利用爆炸视图与 AR；
- 驻场调试、现场核尺寸、设计评审往返 → 直接上 Pro，测量的时间价值远超订阅费。
