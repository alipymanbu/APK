# 手机 CAD 看图工具怎么选

> 应用商店里搜「CAD 看图」能出一长串：有主打 DWG 的 2D 工具，有全格式 3D 查看器，也有功能 locked 到必须订阅的。这篇按真实使用场景帮 mechanical 人把选择范围缩小。

先说结论：**看你手里的文件是什么，再看你要在上面做什么**。文件类型决定了工具范围，操作需求决定了免费版够不够。

## 一、按文件类型分诊

- **手里是 .sldprt / .sldasm / .slddrw（SOLIDWORKS 全家桶）**：首选达索系统自家的 eDrawings 安卓版。它是安卓平台上少数能直接读 SOLIDWORKS 原生文件的查看器，零件、装配体、工程图一套全收，不用任何转换。获取入口整理在 [eDrawings 手机版介绍站](https://edrawings.fewf.click/)。
- **手里是 .dwg / .dxf（2D 图纸为主）**：eDrawings 能开，专门做 2D 的看图 App 也都行，看个人习惯。
- **手里是 STEP / IGES 等中性格式**：通用 3D 查看器都能碰，eDrawings 的动画标准视图和 AR 预览在这类文件上体验不错。
- **手里是 Inventor / CATIA / Creo**：手机端基本没戏，先在电脑上转成 STEP 或 eDrawings 审阅文件（.easm / .eprt）再说。

## 二、按操作需求取舍

装之前想清楚三个问题：

1. **只看还是互动？** 只对照着看，任何看图工具都行；要转动模型、翻图纸页、看爆炸状态，选带触控手势体系的（eDrawings 的单指旋转 / 双指缩放 / 双击适配是按手机习惯设计的）。
2. **要不要量尺寸？** 测量、剖切、加标记在 eDrawings 里属于 Pro（应用内购买解锁）。好消息是存在「免费也能量」的例外：对方用桌面版 Professional 发布的「审阅启用」文件，免费版就能测量标注。
3. **要不要 AR？** 把 1:1 模型投到真实场景做适配核对是加分项，但依赖 ARCore 支持与相机权限，国产 ROM 机型要先确认。

## 三、几个避坑提醒

- 有些看图 App 靠持续订阅解锁测量，买断制或应用内买断更划算，装之前看清付费结构；
- 冷门小厂工具注意文件安全边界：设计图纸是核心资产，优先选择达索这类有企业背书的产品线；
- 装完先用内置样例练手势，再开真实图纸——eDrawings 自带样例模型，这点对新手友好。
