# KernelSU 资料索引

围绕 KernelSU（基于 Linux 内核的 Android root 方案）的第三方整理资料：它工作在内核态，root 权限由内核直接发放，管理器 APK 负责读状态、发授权、装模块。整理内容以公开资料为源，安装文件资源的获取入口见 [KernelSU 介绍站](https://kernelsu.bpfl.quest/)。

## 本目录文章

- [设备支持与内核版本判断](设备支持与内核版本判断.md) —— 判断能不能用看内核版本而非 Android 版本，附三种状态对照
- [LKM与GKI安装模式怎么选](LKM与GKI安装模式怎么选.md) —— 不替换内核与整体替换两条路的取舍与安装前必做项
- [与Magisk的区别和共存问题](与Magisk的区别和共存问题.md) —— 授权粒度、模块挂载体系、Zygisk 接入与共存边界

> 本目录为第三方整理的公开资料，与软件开发者无隶属关系；安装文件资源一律以介绍站内标注的网盘入口为准。
