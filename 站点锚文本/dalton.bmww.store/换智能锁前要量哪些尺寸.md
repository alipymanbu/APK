# 换智能锁前要量哪些尺寸

> 买智能锁翻车，十有八九卡在尺寸与供电上：锁体装不上玻璃门、厚门买薄了、续航比预期短。这篇把下单前该量的、该问的一次列全，数字均取自厂商产品页与 FAQ 的公开口径。
> **相关文档**：[智能门锁远程开锁怎么设置.md](智能门锁远程开锁怎么设置.md) · [门锁临时密码怎么发.md](门锁临时密码怎么发.md)

换锁不是「选个好看的型号」就完事——门的信息决定你能在哪几个型号里挑，联网方式决定这把锁最终能做什么。

## 一、量门：三处数字

1. **门厚**：常见锁吃 35~50mm，厚门型号能到 120mm；玻璃门款只吃 10~12mm 的单层玻璃。卷尺量门边侧的厚度即可。
2. **开门方向**：左开还是右开、内开还是外开，决定面板朝向与锁舌方向；装反是最常见的翻车点。
3. **天地钩与原有锁体**：拆旧锁前先拍照记下孔位布局，对照新锁说明书确认能不能直接换。

## 二、看环境：防护与温度

- 防护等级以 IP54 居多，部分型号到 IP64——这类锁多设计在屋檐或门廊下使用，别装在正对雨淋、暴晒的院门上；
- 工作温度方面，多数型号经过高低温测试，北方冬天零下、南方夏天暴晒的门口都能扛，具体温度区间按型号页面为准。

## 三、算续航：供电方式决定体验

| 项目 | 常见口径 |
| --- | --- |
| 供电 | AA 干电池或可充电锂电池 |
| 续航 | 6~12 个月，Wi-Fi 与摄像头型号更耗电 |
| 低电量提醒 | 锁屏提示、app 推送、提示音 |
| 应急供电 | 面板留有应急供电口，可临时接充电宝 |
| 最后兜底 | 每把锁配 2 把机械钥匙 |

有一点厂商 FAQ 写得很直白：电池耗尽后锁**不会自动打开**，门依旧锁着——用应急供电口或机械钥匙都能进，不必慌。

## 四、比容量：家里几口人，锁能记几个

每种开锁方式能录的用户数按型号分档，通用范围是 50~100 个。几个常见型号的公开标注：

| 型号 | 容量口径 |
| --- | --- |
| D14 | 每种方式 100 用户、10 个管理员 |
| D05 | 100 密码 + 100 指纹 + 1000 张卡、3 个管理员 |
| P90 | 100 密码 + 100 指纹、9 个管理员 |
| Z10 | 最多 150 用户（掌静脉、指纹、密码、卡合计 90） |

人脸与掌静脉识别只有 P90、Z10 这类带摄像头的高配才有；普通户型选指纹+密码+卡的组合就够用。

## 五、确认联网：这决定你能不能远程

Wi-Fi 直连型号连上路由器即可远程；蓝牙型号要加网关才有远程能力。打算给民宿、出租屋用的话，优先选 Wi-Fi 直连款——配合手机端发限时密码、看开锁记录会顺很多，具体玩法见 [门锁临时密码怎么发.md](门锁临时密码怎么发.md)。

都核对完，装好 app 绑定即可上手；各界面的实拍与功能分块，[DALTON 门锁应用介绍站](https://dalton.bmww.store/) 里有完整的截图导览。最后提醒一句：以上数字是厂商产品页与 FAQ 当时显示的口径，各型号有出入，下单前以你手上那本说明书为准。
