# DALTON 门锁应用站点目录

这里是围绕 DALTON（配 DALTON 智能门锁使用的手机端管理应用，安卓端叫 DALTON、iPhone 上叫 DALTON LOCK）整理的第三方介绍与使用说明合集。这个 app 管的事包括：长按圆环开锁、给访客发限时或一次性密码、查看开锁记录、收门铃与告警提醒。

想一次看清它的界面实拍、三种使用场景与型号适配，可以到 [DALTON 门锁应用介绍站](https://dalton.bmww.store/) 细读；目录里的几篇短文则分别回答「远程开锁怎么弄、临时密码怎么发、换锁前量什么」三件高频的事。
