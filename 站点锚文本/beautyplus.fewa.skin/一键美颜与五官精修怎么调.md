# BeautyPlus 一键美颜与五官精修怎么调

> 本篇讲 BeautyPlus 人像修图的两条路怎么走：一键美颜的强度怎么给、五官和皮肤逐项精修时先调哪后调哪，都是实操层面的顺序与经验值。安装环节的问题在[安卓手机安装流程与报错处理.md](安卓手机安装流程与报错处理.md)。

BeautyPlus 的人像工具分两层：一层是导入照片就自动出效果的**一键美颜（HD Retouch）**，另一层是按部位逐项调的**手动精修**，应用内标注的人像调整工具在 22 项以上。日常自拍用一键的就够，想精修再进手动，两条路不用来回切。

## 一、一键美颜：强度决定成败

导入照片后选 HD Retouch，轮廓和皮肤会自动处理一遍，你只需要拖滑杆：

- 经验值在 **60%~70%** 之间最自然；
- 拉满容易出「塑料感」，皮肤纹理全没了；
- 一键结果不满意时不要反复叠加，直接转手动工具修具体部位。

## 二、手动精修：按部位逐项来

手动工具按五官分组，常用的几组：

| 部位 | 能调什么 |
| --- | --- |
| 眼睛 | 放大、提亮、去黑眼圈和眼袋 |
| 鼻子 | 大小、缩窄、鼻梁挺直、鼻尖形状 |
| 嘴唇 | 丰满度、位置、微笑弧度 |
| 皮肤 | 祛痘、去油光、平滑毛孔、提亮 |
| 牙齿 | 矫正、美白（涂抹需要变白的区域） |
| 脸型 | 瘦脸、下颌与下巴重塑、发际线 |

两条顺序上的经验：

1. **一次只调一两个部位**，调完退出来看整体，比全部拉满更容易控制；
2. 皮肤类工具**先低强度涂一遍，不够再补**，一上来就高强度反而显脏。

## 三、妆效与身材

妆效入口有成套妆容（口红、眉毛、腮红的组合），先选一套接近目标的，再单独微调口红颜色或眉毛深浅；逐个单项叠加容易显脏。身材工具用「推拉」改轮廓，小幅度推多次比一次推到位稳，人物边缘有直线参照物（门框、墙线）时格外注意，推拉会把直线一起弯掉。

## 四、滤镜收尾

调完人像再上滤镜：按风格分类（自然、胶片、黑白、美食），每个滤镜都能调强度，人像建议 50%~80%。记住**先调光再上滤镜**，顺序反了，调光会把选好的滤镜效果又改变一遍。
