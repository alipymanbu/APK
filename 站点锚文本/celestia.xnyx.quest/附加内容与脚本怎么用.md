# 附加内容与脚本怎么用

> 本篇讲往 Celestia 里加新天体与高清纹理（add-ons）的方法、extras 目录的位置，以及脚本与 cel:// 链接的用法。
> **相关文档**：[四个手势玩转星空.md](四个手势玩转星空.md) · [用时间机器看日食月食.md](用时间机器看日食月食.md)

---

Celestia 的天体数据库被设计成可扩展的：新天体条目、高分辨率纹理、航天器模型都能以后挂内容（add-ons）的形式加进来，脚本则能驱动视角与时间做一整套演示。装完基础版觉得意犹未尽，可以从这篇开始"扩建"自己的宇宙。

## 一、附加内容能加什么

按项目公开资料，常见类型有：

| 类型 | 举例 |
| --- | --- |
| 新天体条目 | 彗星、恒星、扩展星表 |
| 高分辨率纹理 | 行星表面的更高清贴图 |
| 三维模型 | 按精确轨道运行的小行星与航天器 |
| 虚构物体 | 知名科幻作品里的星舰等 |

数据库容量也随之扩展：默认星表超过 60 万颗恒星，装入附加星表后可到 177 万以上；深空天体同样有对应的扩展目录。

## 二、extras 目录放在哪

安卓版从 **extras** 目录读取附加内容，路径为：

```text
Android/data/space.celestia.mobilecelestia/files/CelestiaResources/extras
```

使用要点：

1. 把下载到的附加内容**保持其自带的目录结构**放进 extras；
2. 重启 Celestia 后生效；
3. Android 11 之后的系统对 `Android/data` 目录有访问限制：可以用数据线连电脑，从电脑上把文件夹复制进去，部分机型的系统文件管理器也能进入该目录；
4. extras 里的脚本会出现在收藏（Favorites）里，可直接加载。

## 三、脚本与 cel:// 链接

脚本有两种格式，分工不同：

| 格式 | 特点 | 适合 |
| --- | --- | --- |
| `.cel` | 项目自有脚本语法，一条条命令顺序执行 | 固定路线的演示，比如绕太阳系一圈 |
| `.celx` | 基于 Lua，可以写逻辑与交互 | 带菜单、能中途改变行程的复杂脚本 |

一段最简单的 `.cel`，作用是选中地球并在 3 秒内飞过去：

```cel
select { object "Sol/Earth" }
goto   { time 3 }
wait   { duration 3 }
```

脚本放进 extras 后从收藏（Favorites）里加载运行；它还支持 `cel://` 形式的链接——点开这类链接，应用会直接把视角带到链接记录的位置与时刻，适合分享自己摆好的观察机位。

新装的天体与普通天体一样，用搜索或星体浏览器都能找到，操作见[四个手势玩转星空.md](四个手势玩转星空.md)；给新装的高清月面配一次月食回放，见[用时间机器看日食月食.md](用时间机器看日食月食.md)；还没安装应用本身的话，流程见[安卓版怎么下载安装.md](安卓版怎么下载安装.md)，或直接到 [Celestia 星穹漫游手册](https://celestia.xnyx.quest/) 看完整介绍。
