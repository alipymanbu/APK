# 用时间机器看日食月食

> 本篇讲 Celestia 的时间流速调节、时间倒转，以及用日食查找器（Eclipse Finder）看日食、月食与卫星凌星。
> **相关文档**：[四个手势玩转星空.md](四个手势玩转星空.md) · [附加内容与脚本怎么用.md](附加内容与脚本怎么用.md)

---

Celestia 里的天体按真实规律持续运动，默认速率下行星的移动几乎察觉不到。把时间流速调快或倒转，才能肉眼看到公转、绕转与掩食这类过程——这也是这款模拟器最上瘾的玩法。

## 一、时间流速怎么调

- **调快**：天体运动明显加快，地球自转、木卫绕转几分钟内就能看出变化；
- **调慢**：贴近逐帧观察某个瞬间；
- **倒转**：支持时间反向，把已经过去的天象「倒回去」重演一遍。

时间控制在界面菜单的时间项里，加减速与倒转都从那里切。选档的原则是**先快后慢**：先用大档位定位到大趋势，再落到小档位看细节。

## 二、用日食查找器看日食

安卓版内置日食查找器（Eclipse Finder），不用自己算日期：

1. 打开操作菜单，进入 Eclipse Finder（日食查找器）；
2. 选择关注的天体系统（如地球—月球）与时间范围；
3. 在列出的日食 / 月食条目里选中一次；
4. 应用会把视角带到对应的位置与时刻，再配合加减速微调，看食入食出的全程。

## 三、适合用时间功能看的几类天象

| 天象 | 看法 |
| --- | --- |
| 日食 / 月食 | 直接用 Eclipse Finder 跳到时刻，再微调流速 |
| 木卫食、卫星凌木星 | 视角对准木星，中等速度加速 |
| 行星公转与两星会合 | 大幅加速，视角拉远 |
| 地球自转与昼夜交替 | 小幅加速，视角固定在地表附近 |

## 四、追航天器要对准年代

数据库里还有一部分按真实轨道运行的人造航天器。搜 `ISS`（国际空间站）、`Hubble` 这类英文名就能找到；搜不到多半是时间没对上——和平号空间站 2001 年就已坠入太平洋，用当前时间自然找不到。把日期改到任务进行中的年份再去搜即可，注意轨道数据的起止日期按 UTC 编码而非当地时间，对不准就把应用时区切到 UTC。
