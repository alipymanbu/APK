# 四个手势玩转星空

> 本篇讲 Celestia 安卓版的四个核心手势、天体搜索技巧与画面显示调节。
> **相关文档**：[安卓版怎么下载安装.md](安卓版怎么下载安装.md) · [用时间机器看日食月食.md](用时间机器看日食月食.md)

---

手机屏幕没有鼠标滚轮和右键，Celestia 把桌面版的操作全部换成了手势。先记住这四个动作，之后无论去看哪颗天体都是同一套路子。

## 一、四个核心手势

| 手势 | 作用 |
| --- | --- |
| 单指拖动 | 绕当前天体旋转视角 |
| 双指拖动 | 在空间中平移移动 |
| 双指捏合 | 拉近 / 拉远 |
| 单指点按 | 选中天体 |

点按选中天体后，信息面板里会给出「前往 / 居中 / 跟随 / 锁定」等一排动作按钮：前往把视角带过去，跟随让目标一直留在画面里，看移动中的天体（比如木卫绕转）时特别有用。忘了手势的时候，点开操作菜单里的 Help（帮助）可以再查一遍。

## 二、搜索天体的窍门

1. 点搜索框，输入天体名称；
2. 名称用**国际通用的英文拼写**，例如 `Mars`（火星）、`Io`（木卫一）、`Hubble`（哈勃望远镜），输中文一般搜不到；
3. 在结果里点选目标，选「前往」即可。

搜索结果较多时，先看清条目所属的天体系统再进，避免同名条目选错。常去的位置可以存进收藏，下次直接跳转，不用重新搜索。

## 三、星星太少？调一处参数就够了

手机上看星星觉得稀疏，多数不是数据缺，而是**星等显示下限**设得保守。调节路径：

> 三横菜单 → 设置 → 图形 → 渲染参数

把「星等下限（faintest visible）」往大调，画面里的恒星数量会明显增加。同一个面板里还有几项常用旋钮：觉得夜半球太黑就调高环境光（ambient light），看深空星系时可以适当调高星系亮度（galaxy brightness），嫌行星表面标注太密就调大标注最小尺寸。

按项目公开资料，默认星表收录超过 60 万颗恒星，装入扩展星表后可到 177 万以上——数据余量完全够用，画面里"星太少"基本都是显示口径的问题。
