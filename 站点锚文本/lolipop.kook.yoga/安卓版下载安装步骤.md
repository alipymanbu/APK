# 安卓版下载安装步骤

> 本篇讲怎么把 Lolipop 装到安卓手机上：安装文件从哪里拿、怎么转存、允许未知来源在哪里开、装完怎么进对话。玩法层面的内容另见[AI角色扮演聊天怎么玩](AI角色扮演聊天怎么玩.md)，安装文件资源的获取入口在 [Lolipop 安卓版下载页](https://lolipop.kook.yoga/download.html)。

---

## 装之前先对一遍条件

- 系统需要安卓 5.2 以上；
- 安装包约 56MB，留出一点剩余空间；
- 应用内容分级 17+，面向成年用户；
- 它不在国内应用商店上架，安装包走网盘分享获取，所以会用到「允许未知来源」。

## 四步装好

1. **进分享页转存**：打开 [Lolipop 安卓版下载页](https://lolipop.kook.yoga/download.html)上的网盘入口，把安装文件转存到自己的夸克账号再下载到手机——转存一份在自己账号里，日后分享链接失效也不影响你手里这份；
2. **允许安装未知应用**：安装包不经过应用商店，手机会拦一下，在弹窗里选择允许；错过弹窗就去「设置 → 应用 → 特殊权限 → 安装未知应用」里给浏览器或文件管理器放行（不同机型叫法略有差异）；
3. **点开安装包**：在通知栏或文件管理器里点开下载完成的 APK，等进度走完；
4. **打开应用开聊**：启动页选「Guest Mode」游客身份直接进，或用 Google / 邮箱登录；进发现页翻角色卡，点聊天气泡就开始了。

## 常见安装问题

- **点安装被拦**：这是安卓对商店外安装包的正常防护，在拦截弹窗里允许即可，装完可以把权限关回去；
- **装到一半失败**：多半是下载传输中断，把安装包删掉重新下载一遍再装；
- **打开全是英文**：不影响聊，在聊天框发一句「说中文」就能切换，具体操作见[聊天怎么设置中文](聊天怎么设置中文.md)。

装完不知道从哪开始，[Lolipop 图文介绍站](https://lolipop.kook.yoga/)把「挑角色 → 开聊 → 走剧情」的完整流程配图讲了一遍。
