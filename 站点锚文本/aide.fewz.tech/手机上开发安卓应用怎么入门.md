# 手机上开发安卓应用怎么入门

> 手里只有一部安卓手机，想试着做个自己的 App，从哪里下手、要装什么、第一步写什么。

不少人对安卓开发的第一印象是「得先配一台电脑、装一大套开发环境」，实际上还有一条更轻的起步路：直接在安卓设备上完成。这类做法的代表工具是 AIDE——一款装在手机上的集成开发环境，全称 Android IDE，开发者是 appfour。它自带移动端安卓 SDK，从新建工程、写代码到编译出 APK 并装到手机上，整条链路都在同一部设备里闭环，全程不需要 root。

## 一、先想清楚要做什么样的应用

入门第一步不是写代码，而是确定方向，因为这决定后面用什么技术栈：

- **常规安卓应用**（界面 + 交互）：用 Java + XML 布局，走安卓 SDK，是最主流的路线；
- **游戏或性能敏感的逻辑**：可以走 C/C++ 加 NDK（支持 ARM 机型），或者先从游戏开发课程学起；
- **网页套壳类的跨平台应用**：HTML5 + CSS + JavaScript，配合 PhoneGap 方向；
- **只想练语法和算法**：纯 Java 控制台工程就够，点运行会弹出模拟控制台看输入输出。

方向没想好也不要紧，从最经典的「Hello World」学起即可——几乎所有入门教材的第一个例子都是它，目的只有一个：完整跑通「写代码 → 编译 → 运行」这个循环，建立手感。

## 二、环境怎么搭

手机端起步的好处在这里就体现出来了：不需要另外装 JDK、不需要配置 SDK 路径，开发工具本身把这些都带上了。大致三步：

1. 在手机上装好 AIDE（安卓 5 以上可安装，安装包约 40 MB，无需 root）；
2. 首次打开会给它存储权限——要允许，工程文件都存在手机存储里；
3. 启动时会看到 Learn 和 Code 两个入口：Learn 是互动课程，Code 直接进工程环境。

装好之后第一次打开，界面布局、编辑器手势这些细节，可以参考 [AIDE 介绍站](https://aide.fewz.tech/)整理的真机截图，对照着认一遍顶栏图标和菜单位置，后面上手会快很多。

## 三、第一个工程长什么样

从 Code 入口新建 Android App / Hello World 项目后，会自动生成两个最关键的文件：

| 文件 | 干什么用 | 你会怎么改它 |
| --- | --- | --- |
| `main.xml` | 用 XML 描述界面层级 | 加按钮、改文字、调间距 |
| `MainActivity.java` | 页面逻辑，加载布局、绑定事件 | 让按钮点了有反应 |

改动可以很小：把界面上的默认文字换成自己的名字，或者加一个按钮并写上点击事件。写错的地方编辑器会即时标红，长按报错位置还能弹出修复建议——这个反馈速度对新手非常友好。

改完点一下工具栏的运行图标，增量编译几秒到几十秒出包，自动装进手机并启动。第一次运行时系统会提示「允许来自此来源的应用」，同意一次即可，之后反复调试都不会再问。

## 四、接下来往哪走

跑通第一个例子之后，三条路按需选：

- **系统学语法**：进 Learn 的 Java 编程课程，每课几分钟、边讲边练；
- **学安卓专项**：控件、界面、Activity 这些，走 Android 开发课程或直接在工程里试；
- **把电脑上的工程搬过来**：Eclipse 格式的工程整个文件夹拷进手机就能打开，Android Studio 默认目录结构的工程也能直接读，也可以用内置 Git 在电脑和手机之间同步。

具体选哪条、各自怎么操作，可以接着看本目录的 [零基础学安卓开发用什么工具](零基础学安卓开发用什么工具.md) 和 [手机写的程序怎么打包成安装包](手机写的程序怎么打包成安装包.md)。

## 五、几个务实提醒

- 兼容性方面，从大量使用者反馈看，Android 11 及以下机型跑得比较稳，更新的机型是否顺畅要以实机为准；
- 应用本体可以免费用来写代码、编译、运行；调试器、UI 设计器、进阶课程是单独的可选付费项，入门阶段用不到不必买；
- 学习资料认准应用内的课程与帮助入口，第三方教程注意发布时间，太旧的可能对不上当前版本。
