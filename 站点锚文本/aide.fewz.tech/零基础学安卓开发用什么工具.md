# 零基础学安卓开发用什么工具

> 还没写过代码，想学安卓开发：需要准备什么设备、装什么软件、从哪门课开始。

零基础学安卓开发，最容易在「配环境」这一步劝退：装 JDK、配 SDK、下 IDE，每一步都有坑。其实现在有一条门槛低得多的路——用 AIDE 这类装在手机上的开发环境，把配环境这一整步跳过去。它是 appfour 开发的安卓端集成开发环境，装上就能建工程、写代码、编译运行，对初学者相当友好。

## 一、工具选型的三条路

按设备条件和学习目标，常见三种组合：

1. **只有手机 / 平板**：直接装 AIDE。写代码、编译、把 App 装到自己手机上，全程一部设备搞定；平板接上键盘甚至可以当一台小型开发机用。
2. **有电脑，想走专业路线**：电脑装 Android Studio，手机装 AIDE 做补充——通勤路上改代码、跑测试，回到电脑继续深入。
3. **只想先试试自己有没有兴趣**：还是从手机端起步最划算，几分钟就能见到第一个能跑的程序，值不值得深入马上有答案。

无论哪条路，初期学的语言是同一门：Java。语法、面向对象、常用类库，这些底子打到哪条路上都通用。

## 二、手机端这套工具能覆盖什么

别小看「手机上的 IDE」，它的完成度比很多人想象的高：

- **编辑器**：Java 和 XML 的代码补全、实时报错、语法高亮、无限撤销重做，错处长按还能弹出修复建议；
- **编译运行**：点一下就出 APK 并自动安装到手机，增量编译让反复修改的等待很短；
- **课程体系**：内置互动课程覆盖 Java 编程、Android 开发、游戏开发、Android Wear、网页开发几条线，每课都要求亲手改代码，不是看视频式的被动学习；
- **工程管理**：兼容 Eclipse 工程格式和 Android Studio 默认目录结构，内置 Git 支持提交、推送、拉取、分支与合并，以后升级到电脑开发也不浪费积累。

这些能力的真机界面长什么样，[AIDE 介绍站](https://aide.fewz.tech/)上有按功能分区整理的截图和说明，装之前先看一眼，心里更有底。

## 三、零基础的学习路径建议

按下面的顺序走，每一步都有可验证的产出：

1. **第一周：跑通流程**。装好工具，新建 Hello World 工程，改一行文字再运行——目标不是学会什么语法，而是确认「我改的东西能在手机上生效」。
2. **第二三周：过一遍 Java 基础**。用内置的 Java 编程课程，每天一两个小课，重点练变量、条件、循环和方法。
3. **第四周起：学界面**。进入 Android 开发课程，认识控件和布局，试着做一个能点、能跳页的两三个页面的小应用。
4. **有想法就动手**：课程学到一半就可以开始自己的小项目，遇到不会的再回头查课——带着问题学，效率最高。

课程的入口在启动页的 Learn 里；每一课都标了预计完成时间，适合用碎片时间推进。

## 四、钱要花在哪

先把账算清楚：写代码、编译、运行这个核心闭环用免费版就能完整体验，零基础阶段一分钱不用花。进阶之后的可选付费项有三类——调试器、可视化 UI 设计器、应用内进阶课程——买的是便利，不是基础功能的钥匙。学到什么阶段、需不需要，到时候再决定都来得及。

## 五、设备与系统的注意事项

- 安装包要求安卓 5 以上，体积 40 MB 出头，装在手机或平板上都行；
- 使用者反馈中 Android 11 及以下机型兼容性比较稳，更新的机型建议先装上试跑再投入学习；
- 外接键盘是加分项：工具支持自定义按键映射，平板加键盘的输入体验接近笔记本电脑。
