# keepsafe 介绍站

这里是 [keepsafe](https://keepsafe.fwen.ren/) 的第三方介绍页：keepsafe（Private Photo Vault）是一款安卓照片保险箱应用，能把照片视频锁进带 PIN 的加密空间，还能把整个入口伪装成一台计算器。站点整理了它的伪装机制、私密云同步与安装步骤，目录下的文章围绕照片隐私保护里最常被搜到的几个疑问展开。
