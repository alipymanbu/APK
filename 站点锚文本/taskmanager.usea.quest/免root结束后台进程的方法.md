# 免root结束后台进程的方法

> 不解锁 boot loader、不 root，也能结束顽固的后台应用——思路是借 Shizuku 之手。
> **相关文章**：[安卓手机怎么看哪个应用占CPU](安卓手机怎么看哪个应用占CPU.md) · [后台应用杀掉又自动启动怎么办](后台应用杀掉又自动启动怎么办.md)

## 一、为什么普通应用杀不动别的应用

安卓的沙箱机制下，每个应用只能管自己，看不到别的进程，更没有权限结束它们——这是系统安全模型，不是某个工具不给力。绕过这条线的传统做法是 root，但 root 门槛高、还影响支付与保修。

另一条路是 **Shizuku**（开源项目）：用 adb 或 root 起一个常驻服务，让被授权的应用借这个服务的权限去调系统接口。效果接近 root，却不用解锁手机——这就是免 root 结束后台进程的原理。

## 二、三步把环境配起来

1. **装 Shizuku**：Google Play 搜 Shizuku，或从其 GitHub 仓库获取安装包；
2. **启动服务**：Android 11 及以上可用「无线调试」配对启动，全程不用电脑；已 root 的设备可用 root 方式启动，重启后依然有效；
3. **授权给任务管理器**：以开源的 TaskManager 为例——打开它、工作方式选 Shizuku、弹窗里点「始终允许」，之后进程列表就能刷出数据、结束按钮才会生效。

非 root 方式启动的 Shizuku 不跨重启：手机重启后要重按一次「启动」，配对记录则保留、不用重做。这一步没做，应用里就会提示 Shizuku not running，功能全空。

## 三、结束操作的边界在哪

| 操作 | 权限要求 |
| --- | --- |
| 结束安卓应用 | Shizuku 运行中并已授权 |
| 结束底层 Linux 进程 | Shizuku 必须由 root 方式启动 |
| 调整进程优先级 | 同上，需 root 方式启动 |

也就是说，免 root 状态下能干的是**应用级结束**——把某个吃资源的应用当场停掉。动内核级进程、改调度优先级这类更深的操作，仍然只有 root 环境能做。

## 四、安全边界同样重要

- 只结束**能说出包名归属**的应用，认不出的进程只看不碰；
- 系统服务、输入法、桌面、电话相关进程不要动，轻则功能失灵、重则重启；
- 结束前先看一眼 CPU 与内存曲线，确认它真的在持续占用——数据怎么看见[安卓手机怎么看哪个应用占CPU](安卓手机怎么看哪个应用占CPU.md)。

## 五、预期要摆正

结束进程是「当场停」，不是「永久封」：推送到了、定时任务到期，系统照样会把应用拉回来。想断根，靠的是系统的后台限制开关，方法写在[后台应用杀掉又自动启动怎么办](后台应用杀掉又自动启动怎么办.md)。两者配合——先结束、再限制——才是完整的一套。
