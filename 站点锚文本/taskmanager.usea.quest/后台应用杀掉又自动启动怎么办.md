# 后台应用杀掉又自动启动怎么办

> 用任务管理器结束进程，几分钟后它又躺在列表里——这不是没杀干净，是系统把它请回来的。
> **相关文章**：[安卓手机怎么看哪个应用占CPU](安卓手机怎么看哪个应用占CPU.md) · [免root结束后台进程的方法](免root结束后台进程的方法.md)

## 一、先弄清它为什么回来

结束（Force stop）只作用于**当下这一刻**：进程确实死了。但只要系统需要它干活——推送到了、定时任务到期了、别的应用绑定了它的服务——就会把它重新拉起来。安卓默认并不禁止应用在后台活动，「杀一遍就永久清静」本来就不是系统承诺的行为。

所以反复杀没有意义，正确做法是切到系统的后台限制开关，管住「你不碰它时它别自己动」。

## 二、原生安卓的「受限」开关

路径（不同版本措辞略有差异）：**设置 → 应用 → 查看全部应用 → 选中目标 → 电池用量 → 受限**。

被设为「受限」的应用：

- 仍可手动打开，打开后功能正常；
- 无法在后台运行作业与闹钟、无法在后台联网；
- 无法运行前台服务；
- 随时可以改回「不受限制」。

## 三、各品牌还有自己的一层

国产系统普遍在原生之外另有一套后台管理，两层都设才稳（叫法以实际系统为准）：

| 品牌 | 常见入口 |
| --- | --- |
| 小米 / 红米 / POCO | 自启动管理 |
| 三星 | 电池设置里的休眠应用 |
| OPPO / 一加 / Realme | 电池优化里的逐应用后台控制 |
| vivo / iQOO | 后台高耗电名单 |
| 原生及其他 | 只有上一节的「受限」档 |

部分品牌系统更新后会**重置**这些规则，改完隔段时间回头核对一眼。

## 四、哪些应用别设成受限

限制是拿通知换安静的，设错了比不设更难受：

- **不该受限**：即时通讯、邮件、闹钟时钟——任何「通知晚到会耽误事」的应用；
- **适合受限**：不常玩的游戏、偶尔打开的购物资讯类、装了就忘的工具。

判断标准就一条：**等不等它的推送**。

## 五、怎么验证生效

设完正常用一天，再到「设置 → 电池 → 电池用量」看该应用的后台耗电：生效的表现是后台占用接近零、没有持续唤醒。数值照旧就回二、三节把两层开关再核一遍。

## 六、和任务管理器怎么配合

两套工具管两件事：系统开关管「别自己动」，任务管理器管「已经在跑的立刻停」。先用 TaskManager 结束当下的进程，再用系统开关断掉它回来的路；结束操作怎么配权限，见[免root结束后台进程的方法](免root结束后台进程的方法.md)。
