# Markor：安卓上的离线笔记本（第三方说明）

这一小站整理安卓开源笔记本 Markor 的功能介绍与上手资料：它用 Markdown 记笔记、用 todo.txt 管待办，所有内容都存成手机文件夹里的普通文本文件，全程离线、不要账号。安装文件资源的获取入口与安装步骤见 [https://markor.qjxz.skin/](https://markor.qjxz.skin/)。

本目录的几篇文章分别对应三类最常见的使用问题：

- [安卓离线笔记上手.md](安卓离线笔记上手.md) —— 从装好到写出第一篇笔记；
- [todo待办与快速笔记.md](todo待办与快速笔记.md) —— 待办、草稿纸与稍后读三件套；
- [手机与电脑同步笔记.md](手机与电脑同步笔记.md) —— 让手机和电脑共享同一份笔记本。

展示素材来自公开资料，版权归原作者所有。
