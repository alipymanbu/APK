# NewPipe 介绍与文章索引

本目录收录 NewPipe——一款开源的轻量安卓流媒体客户端——的介绍与使用文章：它不需要登录任何账号，订阅与播放列表全部保存在本机，支持后台播放、悬浮窗小窗和视频音频的离线下载，安装包只有约 10MB，也不依赖 Google 服务框架，国产 ROM 与精简系统的手机同样能装能用。

想直接获取安装包，可前往 [NewPipe 介绍站](https://newpipe.usea.quest/) 查看功能说明与获取指引。
