# NewPipe APK 安装与权限设置

> 本篇讲 NewPipe 安装包从下载到装好能用的完整流程：系统版本要求、未知来源授权、首次启动的权限取舍，以及装不上时的三个排查方向。
> **相关文档**：[锁屏后台播放与悬浮窗.md](锁屏后台播放与悬浮窗.md) · [视频离线下载与订阅迁移.md](视频离线下载与订阅迁移.md)

NewPipe 是一款开源的安卓流媒体客户端，没有上架应用商店，装它需要手动安装 APK。功能与界面的整体介绍见 [NewPipe 介绍站](https://newpipe.usea.quest/)，下面只讲安装这一件事。

## 一、先确认系统版本

0.28.7 这一版起要求 **Android 6.0 及以上**（更早的 0.28.6 及以前还支持 Android 5）。查看路径：`设置 → 关于手机 → Android 版本`。系统低于 6.0 的机器只能停在旧版本，而旧版本解析视频经常失效，实际使用意义不大。

另一个常见门槛是 Google 服务框架——NewPipe **不依赖**它，没有 GMS 的国产 ROM、精简 ROM 照常能装能用，这也是很多人找它的原因。

## 二、安装步骤

1. 先拿到安装包：安装包通过夸克网盘分享分发，在 [NewPipe 介绍站](https://newpipe.usea.quest/) 的下载页可以取到当前版本（0.28.7，约 10.4MB）。
2. 用文件管理器点开 APK，系统会弹「禁止安装来自此来源的应用」。
3. 按提示进入 `设置 → 安全/隐私 → 安装未知应用`，给用来打开 APK 的那个应用（文件管理器、浏览器或网盘应用）打开「允许来自此来源」。各品牌菜单名略有差异，在系统设置里搜「未知」两个字最快。
4. 返回继续安装，等进度走完点「打开」。
5. 首次启动建议**允许通知权限**——后台播放的常驻控制条靠它；悬浮窗权限按需给，用到小窗播放时系统会另行提示。

## 三、装不上时按这三个方向查

- **点安装没反应 / 中途被拦**：多半是第二步的授权没给对人——必须是「点开 APK 的那个应用」。部分品牌（如 MIUI）还要在更多设置里再放行一次「安装」；同时确认 APK 下载完整，中途断网得到的残缺包装不上，重新下载即可。
- **提示解析错误 / 应用未安装**：先核系统版本（见第一节）；如果手机上装过其它渠道得来的旧版，签名不一致会拒绝覆盖安装——先在设置里导出数据库备份，卸载旧版再装新版，装完导入备份，订阅和设置不会丢。
- **装好后锁屏就没声**：这不是安装问题，是通知权限没给，处理办法见[锁屏后台播放与悬浮窗.md](锁屏后台播放与悬浮窗.md) 第二节。

## 四、装好之后

订阅怎么整体搬进新装机、视频怎么存到本机离线看，分别见[视频离线下载与订阅迁移.md](视频离线下载与订阅迁移.md)与[锁屏后台播放与悬浮窗.md](锁屏后台播放与悬浮窗.md)。
