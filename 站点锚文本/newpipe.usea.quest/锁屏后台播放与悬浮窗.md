# NewPipe 锁屏后台播放与悬浮窗

> 本篇讲 NewPipe 三种播放形态（普通/全屏、后台、悬浮窗）怎么切换、各要给什么权限，以及"一锁屏就没声"的处理办法。
> **相关文档**：[APK安装与权限设置.md](APK安装与权限设置.md) · [视频离线下载与订阅迁移.md](视频离线下载与订阅迁移.md)

把视频当播客听、一边聊天一边看，是很多用户选择 NewPipe 的两大理由——这款开源客户端把播放形态的切换做得很轻：一个按钮，进度不丢。安装与版本要求见 [NewPipe 介绍站](https://newpipe.usea.quest/)，本篇只讲播放。

## 一、三种播放形态，一个按钮切

打开任意视频进入播放页，控制栏上有三个形态按钮，随时互切：

| 形态 | 画面在哪 | 典型用法 |
| --- | --- | --- |
| 普通 / 全屏 | 在应用内 | 正常看视频，可横屏全屏 |
| 后台播放 | 只有通知栏控制条，屏幕可关 | 听歌、听播客、锁屏听 |
| 悬浮窗 | 小窗浮在其它应用上 | 一边回消息一边看，小窗可拖动可缩放 |

切到后台后直接锁屏或退出应用都行，声音继续；后台只拉音频流，流量和电量都比挂着画面省得多。

## 二、权限给对，后台才稳

后台播放依赖两处系统权限，缺一个就会表现成「一锁屏就没声」：

1. **通知权限**：后台播放靠一条常驻通知控制（上一首 / 暂停 / 下一首）。装完第一次用的弹窗要点允许；已经拒绝的到 `设置 → 应用 → NewPipe → 通知` 打开。MIUI 机型还要把「锁屏通知格式」设成允许显示的选项，改完重启应用。
2. **悬浮窗权限**（只影响悬浮窗形态）：`设置 → 应用 → NewPipe → 显示在其他应用上层` 打开，没给权限时切小窗会被系统静默拦下。

部分国产 ROM 的省电策略会杀后台服务。把 NewPipe 加进电池优化白名单（或允许自启动、后台运行）即可，各品牌的开关多叫「自启动管理」「后台运行」，在系统设置里搜「后台」或「省电」就能找到。

## 三、顺手省流量的两个技巧

- **只听就切后台**：视频画面停掉只走音频，比挂着播放器省一大截。
- **切后台不断音**：设置里打开「最小化到后台」，切走的瞬间音频无缝续上，切回来画面自动恢复。

另外两个常见误会：后台播放仍在联网拉流，断网就停（要断网听，先走离线下载，见[视频离线下载与订阅迁移.md](视频离线下载与订阅迁移.md)）；播放页找不到形态按钮时，先点一下屏幕把控制条唤出来，按钮就在暂停键附近。
