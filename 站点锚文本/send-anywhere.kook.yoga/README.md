# Send Anywhere 介绍与使用指引

> 这里收录 Send Anywhere 的使用说明文章：6 位数字密钥怎么用、手机和电脑之间怎么互传、链接分享的规则与大文件限制，按你遇到的问题挑一篇读。

这个目录里的文章围绕一个传文件的小工具展开。它的用法很直接：发送端生成一把 6 位数字密钥，接收端把这串数字输进去，两台设备就实时对传，文件不经云端存储。想先看整体介绍与界面实拍，可以读 [Send Anywhere 介绍站](https://send-anywhere.kook.yoga/)，再回到这里按问题深入。
