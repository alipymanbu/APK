# 链接分享与大文件传输限制

> 两端凑不到同一时间在线时，密钥直传派不上用场——这时走链接分享。本篇讲清链接模式和直传的差别，以及单次大小、文件数的具体上限。
> **相关文档**：[6位数字密钥怎么用.md](6位数字密钥怎么用.md) · [手机电脑互传文件步骤.md](手机电脑互传文件步骤.md)

---

密钥直传有个前提：两端必须同时在场，实时对传。可你经常遇到的情况是——对方现在不方便收、文件要发给好几个人、或者一个大打包要隔天再给。这时把文件挂成一条链接更合适：文件先暂存到中转服务器，对方按链接来取，时间错开也没关系。两种模式的取舍先在 [Send Anywhere 使用介绍](https://send-anywhere.kook.yoga/) 里过一遍，再看下面的具体规则。

## 直传与链接分享，差别在哪

| | 密钥直传 | 链接分享 |
| --- | --- | --- |
| 两端是否需同时在线 | 必须 | 不必，错时取件 |
| 文件经过哪里 | 设备之间点对点流动，不经云端存储 | 暂存中转服务器，对方按链接取走 |
| 是否要登录 | 不用 | 管理链接需要注册账号 |
| 单次上限 | 不设文件大小门槛 | 免费档单次最大 10GB |
| 文件数量 | 不拘 | 单条链接最多 1000 个文件 |

## 链接分享怎么操作

1. 在发送端选好文件，切换到链接分享方式生成一条分享链接。
2. 把链接发给对方——聊天窗口、邮件、便签，随便什么渠道。
3. 对方点开链接即可下载；想统一管理自己发出去过的链接，注册后集中在「我的链接」里维护。

## 传大文件前先对一遍数

- **大小**：免费档单次 10GB；再往上还有更高档位（单次 20GB、30GB），按需选择。
- **数量**：一条链接最多装 1000 个文件，批量照片打包足够用。
- **时效**：暂存的文件有保存期限，挂链接时留意页面提示，别让文件在中转服务器上过期。

## 怎么选

两端都在场、立刻要传——密钥直传，不经云端、大小不限；人凑不齐、要错时取件或发给多人——链接分享，注意 10GB 与 1000 个文件的单条上限。密钥的用法细节见 [6位数字密钥怎么用.md](6位数字密钥怎么用.md)，安卓端的安装步骤在介绍站里单独成页。
