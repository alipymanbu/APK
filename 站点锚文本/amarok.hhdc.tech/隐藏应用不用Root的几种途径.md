# 隐藏应用不用Root的几种途径

> 本篇盘点在安卓上不获取 Root 权限也能隐藏应用的主流做法，说明各自的原理、代价与适用场景，并解释为什么不同设备该走不同的路线。相关文章：[手机借出去前怎么快速隐藏隐私应用](手机借出去前怎么快速隐藏隐私应用.md)、[相册里的私密照片视频怎么藏起来](相册里的私密照片视频怎么藏起来.md)。

---

「隐藏应用」本质上是让目标从桌面启动器和系统设置里消失，这需要动用系统级权限。Root 是最直接的一档，但不是唯一一档——安卓的权限体系里还有几条免 Root 的路可以走。

## 途径一：借助 Shizuku 共享 ADB 权限

Shizuku 的思路是把 ADB 级别的权限共享给其他应用使用。对安卓 11 及以上的设备来说，它是最顺手的方案：

- 可以直接在手机上用「无线调试」激活，全程不需要电脑；
- 激活后，支持 Shizuku 的隐藏工具（比如 Amarok）就能以停用应用的方式把目标从桌面移除；
- 代价是每次重启设备后，Shizuku 需要重新激活一次。

装有 Magisk 框架的设备可以改用 Sui，配合关系更紧密一些。

## 途径二：借助 Dhizuku 共享设备所有者权限

Dhizuku 共享的是「设备所有者」权限，同样不需要 Root，最大的优点是**重启后依然生效**，不用反复激活。它的问题在首次配置：一般需要一台装了 ADB 的电脑配合操作，部分机型还要求先登出设备上的全部账号，流程对新手不算友好。

简单说：嫌 Shizuku 重启后要重新激活麻烦、又愿意折腾一次的，走 Dhizuku。

## 途径三：老设备的 DSM 路线

安卓 10 及更早的未 Root 设备，无线调试不可用，Shizuku 走不通，剩下的免 Root 选择是 DSM（Delegated-Scopes-Manager）：需要安装冰箱（IceBox）或小黑屋这类管理员应用，并以**设备管理员（Device Owner）模式**激活，然后由隐藏工具借用这份权限。

注意两点：普通 ADB 方式激活对 DSM 无效；这条路线的原项目已停止维护，能升级系统的设备建议优先走 Shizuku。

## 途径四：Root 模式

已 Root 的设备最简单：隐藏工具直接执行 su 命令完成停用，重启也一直生效。Root 本身有门槛和风险，这里只作为已有 Root 环境时的选项列出。

## 一张表总结

| 途径 | 需要 Root | 重启后仍生效 | 适用场景 |
| --- | --- | --- | --- |
| Shizuku / Sui | 否 | 需重新激活 | 安卓 11+，免 Root 首选 |
| Dhizuku | 否 | 是 | 想一劳永逸，能接受首次折腾 |
| DSM | 否 | 是 | 安卓 10 及更早的未 Root 老设备 |
| Root 模式 | 是 | 是 | 已有 Root 环境 |

Amarok 把以上四种模式都做进了同一个应用，在设置里按设备情况选一种激活即可；具体的判断顺序和常见报错处理，可以参考 [Amarok 介绍站](https://amarok.hhdc.tech/) 整理的模式选择指南。
