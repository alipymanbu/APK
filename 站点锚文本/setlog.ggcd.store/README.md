# setlog 站点导航：玩法、安装与常见疑问

这里是 setlog 介绍站的文档索引。setlog 是一款来自韩国的整点实拍记录相机：每到整点拍 2 秒实时短片，凌晨 4 点自动把 2–12 人小圈里的片段拼成一张分屏 Vlog，不修图、不收库存画面，被称为「熟人版 BeReal」。

下面的文章按真实使用疑问组织，从玩法规则到安装上手逐篇展开；想直接看图文介绍与安装文件资源获取方式，可移步 [setlog 介绍站](https://setlog.ggcd.store/)。
