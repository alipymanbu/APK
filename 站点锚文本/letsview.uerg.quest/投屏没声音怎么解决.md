# 投屏没声音怎么解决：声音通路两层开关逐个打开

> 画面投上去了、声音还在手机里——这是投屏工具最常见的预期差。声音走不走得出去由两层独立开关决定：应用内的喇叭开关，和手机端的投射音频设置。

## 先做三步快速排查

1. **检查各端音量**：手机、接收端（电脑或电视）有没有被静音，逐一打开——最傻的原因排第一，因为它最常见。
2. **打开应用内喇叭按钮**：投屏成功后，需要在手机端界面里点选**喇叭图标**打开声音开关。这个开关独立于系统音量，不少人卡在这一步。
3. **唯独某个游戏没声音**：先拿视频、音乐验证投屏音频通路正常；只有某个游戏不出声，多半是游戏自身对音频通路的限制，不是投屏设置能解决的。

## 手机端「投射音频」设置

声音往哪走、传什么，在手机端应用的设置里定：

1. 进设置（主界面左上角）；
2. 找到**投射音频 / Cast audio**；
3. 二选一：**系统声音**（媒体声音跟着画面走）或**麦克风声音**（把手机麦克风收到的话音传出去）。

设置完回到主界面**重新连接一次投屏**，新选择才会生效。

## 想把说话声传给电脑

远程讲解、帮人调手机时用麦克风传声：

1. 手机端设置里开启 Cast microphone audio；
2. 回主界面，搜索并连接电脑（连接步骤见[手机投电脑电视怎么连](手机投电脑电视怎么连.md)）；
3. 系统弹授权窗，点允许。

开启麦克风传声后，手机和电脑离远一点——否则声音在两个麦克风之间循环放大，就是刺耳的啸叫。

## 系统声音走不通时的 Miracast 路线

普通投屏通道在部分手机上传不了系统媒体声音，替代路线是手机系统自带的「无线投影」（基于 Miracast）。这条路对电脑有硬件门槛，先核对再折腾：

| 检查项 | 怎么查 | 达标线 |
| --- | --- | --- |
| Windows 版本 | `Win + R` 输入 `winver` | Windows 8.1 及以上 |
| 显卡支持 | `Win + R` 输入 `dxdiag`，保存后在文本里搜 Miracast | 显示「已受支持 / Available」 |
| 无线网卡 | PowerShell 跑 `Get-NetAdapter`，看 WLAN 的 NdisVersion | ≥ 6.40 |

三项达标后：两端连同一 Wi-Fi，手机设置里找「无线投影」（各品牌叫法不同），选电脑连接——这样投出的画面才带同步的系统声音。显卡或网卡不达标先更新驱动。

## 投屏时想让电脑闭嘴

看视频投到电脑、电脑又外放出自己声音的场合：投屏成功后，点界面底部的 Sound: On 切成 **Sound: Off**，电脑端静音、手机端继续出声。

画面层面的连接失败、掉线问题去[搜不到设备连接失败排查](搜不到设备连接失败排查.md)；某些高清画质档位与录屏画质和会员档位挂钩，对照见[免费版投屏时长与画质](免费版投屏时长与画质.md)。
