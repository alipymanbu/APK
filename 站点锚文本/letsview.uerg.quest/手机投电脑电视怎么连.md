# 手机投电脑电视怎么连：LetsView 三种连接方式详解

> 把手机画面投到电脑或电视，本质上是让两端进入同一个网络再互相发现。这篇按搜索连接、扫码连接、设备码连接三条路逐一展开，并给出各自适合的现场。

## 连接前的两件准备

1. **两端都装好应用**：手机端装安卓版（[LetsView 安装文件资源获取入口](https://letsview.uerg.quest/) 页面有完整的下载安装步骤），电脑端或电视端也要装对应版本——只装手机一端是投不出去的。
2. **连同一个 Wi-Fi**：手机关掉流量只留 Wi-Fi；注意有些路由器把 2.4G 和 5G 拆成两个名字，部分机型会因此互搜不到，尽量选同一个名字连。

## 方式一：搜索连接（最省事）

同一网络下设备会自动出现在列表里：

1. 打开手机端，等设备列表刷新；
2. 点选名字形如「LetsView + 设备名」的那一项；
3. 选「共享本机屏幕」；
4. 系统弹「是否允许录制/投射屏幕」→ 点允许 → 再点「立即开始」。

适合家里的常规场景，首次连过之后，以后直接从列表点设备名即可。

## 方式二：扫码连接

列表刷不出来时的第一备选，不依赖自动发现：

1. 电脑或电视端进入「屏幕镜像」页，界面上会显示投屏二维码；
2. 手机端点右上角扫码图标；
3. 对准屏幕上的二维码扫描，弹窗授权后开始投。

## 方式三：设备码连接

同样不依赖设备发现，特别适合教室里多台手机投同一块屏：

1. 接收端主界面能看到一串数字设备码；
2. 手机端点右上角输入图标，输入设备码；
3. 点确认图标，弹窗授权后完成连接。

## 三种方式怎么选

| 现场 | 建议 |
| --- | --- |
| 家里常规投屏 | 搜索连接，一次授权长期可用 |
| 列表刷不出目标 | 扫码，最快绕开发现失效 |
| 多台手机轮流投同一屏 | 设备码，逐台输入最稳 |

## 电脑开热点这条兜底路

公司、酒店这类 Wi-Fi 常开设备隔离，互搜不到是网络策略问题，不是软件坏了。让电脑自己开热点、手机连上这个热点再投，两端就处在同一个「小网络」里，投屏发现和带宽都不再经过路由器。代价是手机连着热点不能同时上网，投完切回来即可。
