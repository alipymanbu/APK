# KWGT 组件不更新或不显示的排查思路

时间停在旧值、重启后组件消失、打开是空容器——KWGT 的绝大多数问题不是预设坏了，而是系统把它的后台拦了、桌面没配合好，或者文件本身坏了。这篇按从简到繁给排查路径，最后一节是现象对照表。工具还没装好的，先去 [KWGT 小组件工坊](https://kwgt.wrwq.fun/) 看安装与添加流程。

## 一、先做两件最快的事

1. **重启手机**；
2. **打开一次 KWGT 应用本体**——打开应用会触发一次刷新，很多「冻住」的组件会当场活过来。

如果打开应用后组件立刻恢复、过一会儿又冻住，基本可以确定是后台被杀，直接看第二节。

## 二、时间不更新：电池与后台

组件的刷新靠 KWGT 的后台服务活着，系统省电机制把它杀了，组件就停在最后一次刷新的值。逐项核对：

| 检查项 | 位置 | 应设为 |
| --- | --- | --- |
| 电池 | 设置 → 应用 → KWGT → 电池 | 不限制 / 无限制 |
| 电池优化 | 同上 | 已关闭优化 |
| 自启动 | 应用信息页（有此选项的设备） | 允许 |
| 后台活动 | 同上 | 允许 |

国产系统（MIUI 之类）还要多查一层：省电策略、智能省电、后台清理白名单，把 KWGT 加进去，改完重启再观察。折中手段是在 KWGT 设置里开**常驻通知**——带常驻通知的后台进程在多数系统上更不容易被杀，代价是通知栏多一条常驻项。

另外把预期调对：安卓对组件刷新频率有系统级上限（通常约每分钟一次，这是省电机制），时钟精确到分钟属正常；想跟到秒级可在 KWGT 设置的高级选项里把更新模式（Update Mode）调成 Fast，更耗电。刷新慢是上限问题，完全不刷新才是本节要处理的后台问题。

## 三、重启后组件消失或变透明

这个现象的常见根源是权限和桌面，不是 KWGT 本身：

1. **查权限**：部分系统需要给 KWGT「修改系统设置」类权限，在应用信息页的权限列表里补上；
2. **查桌面**：换一个桌面（如 Nova）再放同样的组件验证——个别桌面更新后就不再刷新第三方组件，这种情况换桌面比折腾 KWGT 有效；
3. 第二节的电池与后台清单同样过一遍。

## 四、加载出来是空的或提示损坏

编辑器里预设显示 Corrupted、打开是空容器，问题在文件本身：

- 0 字节文件 → 重新拿一份干净的；成因与预防见[预设导入与套用](预设导入与套用.md)第三节；
- 后缀带 .zip → 改名或解压；
- 下载没完成 → 重下。

## 五、升级系统后大面积失效

系统大版本升级后组件集体不更新的反馈并不少见，处理顺序：

1. 把 KWGT 更新到应用商店最新版；
2. 强停应用并清除缓存，重新走一遍第二节清单；
3. 仍然不行，去开发者论坛（forum.kustom.rocks）反馈，同类反馈集中出现时通常会跟进修复。

## 六、现象对照表

| 现象 | 最可能的原因 | 对应章节 |
| --- | --- | --- |
| 时间停在旧值，打开应用就恢复 | 后台被杀 | 二 |
| 重启后组件消失 / 变透明 | 权限缺失或桌面兼容 | 三 |
| 预设列表显示 Corrupted / 空容器 | 预设文件损坏 | 四 |
| 系统大版本升级后全部不更新 | 版本适配 | 五 |

排查恢复正常后，想继续折腾布局与样式，回[小组件怎么添加](小组件怎么添加.md)看调整尺寸的做法。
