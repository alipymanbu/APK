# KWGT 预设导入与套用方法

KWGT 的每块小组件内容都存成一个预设文件（.kwgt）——从别人那里拿成品、装预设包、换机备份，全都围绕这个文件转。这篇讲它存在哪、怎么进手机、套用时怎么选，以及最容易踩的「文件变 0 字节」坑。工具本身的介绍与获取入口在 [KWGT 小组件工坊](https://kwgt.wrwq.fun/)，这里直接从文件说起。

## 一、预设文件放在哪

KWGT 在手机内部存储建一个 `Kustom` 文件夹，小组件预设都放在其中的 `widgets` 子目录。同一家族的应用各管各的目录，别放混：

| 应用 | 预设目录 |
| --- | --- |
| KWGT（小组件） | `Kustom/widgets` |
| KLWP（动态壁纸） | `Kustom/wallpapers` |
| KLCK（锁屏） | `Kustom/lockscreens` |

把 .kwgt 文件放进 `Kustom/widgets`，它就会出现在编辑器的预设列表里；删掉文件，列表里随之消失。

## 二、把文件装进手机的两种方式（二选一）

**方式一：文件管理器直接拷**

1. 用文件管理器把 .kwgt 文件复制到 `Kustom/widgets`；
2. 打开编辑器，在预设列表里找到它，选中、保存。

**方式二：编辑器内导入**

1. 打开编辑器，点「导入」；
2. 从 `Kustom` 文件夹之外的任意位置（比如 Download 目录）选中文件；
3. 导入完成后，预设同样出现在列表里。

两种方式做的是同一件事，选一种即可。

## 三、0 字节损坏是怎么来的

最经典的翻车：文件已经拷进了 `Kustom/widgets`，又对它执行了一次「导入」——等于让程序把文件复制到它自己身上，原文件被一个 0 字节空文件覆盖，列表里显示损坏（Corrupted）、打开是空容器。这是重复导入这个动作本身不成立导致的固定行为，不是操作姿势问题。

预防只有一条：**文件已经在 `Kustom/widgets` 里，就别再点导入**。下载来的文件先落到 Download 之类的普通目录，再按上面两种方式任选其一。

## 四、后缀不对的几种情况

| 拿到的文件 | 处理 |
| --- | --- |
| `xxx.kwgt` | 直接用 |
| `xxx.kwgt.zip` / `xxx.zip` | 先去掉 `.zip` 后缀改名试试；仍被当成损坏文件，可能真是压缩包，解压取出里面的 .kwgt |
| 其他后缀 | 大概率不是预设文件，别硬导 |

## 五、导出与换机

编辑器里可对当前预设执行导出生成 .kwgt 文件。换机迁移的完整动作：

1. 导出预设，或直接把整个 `Kustom/widgets` 文件夹打包备份（更稳妥）；
2. 传到新手机；
3. 按第二节的方式装回 `Kustom/widgets`；
4. 在新桌面放一块空白组件，选中对应预设、保存。

预设里用到的图片、字体若放在 Kustom 文件夹之外的自定义路径，换机时要一并搬过去，否则预设会缺素材。

预设装好了套不上（点了没反应、显示损坏），先按第三、四节核对文件本身；文件没问题但组件不刷新，看[组件不更新排查](组件不更新排查.md)；组件还没放上桌面的，先读[小组件怎么添加](小组件怎么添加.md)。
