# KWGT 小组件怎么添加到桌面

装好 KWGT 之后桌面上不会自动出现任何东西——它的全部产出都以「小组件」的形态长在桌面上，而摆放这一步要靠桌面（启动器）自己完成。这篇按顺序走一遍添加流程，并说清第一次创建内容的两条路：套现成预设、从零做一个最简单的。还没安装的话，可以先看 [KWGT 小组件工坊](https://kwgt.wrwq.fun/) 里的安装说明，装好再回来接着操作。

## 一、先放一块空白组件

1. 在桌面空白处长按，唤出桌面的「小组件 / 添加插件」列表；
2. 在列表里找到 KWGT，会看到一排不同尺寸的空组件（1x1、2x2、4x2、4x4 等）；
3. 第一次建议挑大一点的（如 4x4），空间多好操作，之后随时能缩小；
4. 拖到桌面后是一块空白区域，**点这块空白区域**才会打开 KWGT 编辑器。

桌面上可以同时放多块 KWGT 组件，各自装不同内容，互不影响。

## 二、第一次内容：套现成预设

1. 点桌面的空白块进入编辑器；
2. 在预设列表（Library）里选一个已装好的预设；
3. 预览没问题就点右上角的保存（软盘图标）；
4. 回到桌面，空白块已经变成预设的样子。

预设从哪来：应用商店搜「KWGT」能找到大量预设包应用；单个 .kwgt 文件的导入方法见[预设导入与套用](预设导入与套用.md)。不少预设按特定尺寸设计，放进尺寸差太远的空块会被压缩或裁切，长按组件用桌面自带的「调整大小」改一改即可。

## 三、从零做一个最简的：点组件打开应用

想自己动手，用这个五分钟的小例子摸清编辑器：

1. 点空白块进入编辑器，新建一个预设；
2. 点右上角「+」，选「图像」，从相册挑一张图放进画布；
3. 切到「触摸」选项卡，添加一个触摸动作，选「启动应用」，再挑一个具体应用；
4. 保存，回到桌面。

现在点这块组件就会打开选定的应用。照这个路数把常用应用排一遍，就做出了一套自己的快捷启动区；让内容随电量、时间、天气变化，则要进阶到公式与全局变量的写法。

## 四、保存了但桌面没变化

按顺序核对：

1. 编辑器里点的是**保存**，不是直接退出；
2. 桌面上点的确实是 KWGT 的空白块，而不是别的应用提供的组件；
3. 空白块尺寸与预设设计尺寸差太远会显得不对劲，长按组件调整大小；
4. 还是不行，按[组件不更新排查](组件不更新排查.md)的现象对照表走一遍。
