# 一个应用看四个直播平台

> 手机里同时装着虎牙、斗鱼、B站、抖音四个直播应用，只为一群主播来回切换？这篇讲 Simple Live 是怎么把这四家装进同一个应用的，以及它适合什么样的观看习惯。

## 一、它解决的是什么问题

看直播的人多半不止混一个平台：游戏赛事在斗鱼虎牙，虚拟主播在 B 站，深夜想看户外闲聊又去刷抖音。平台一多，手机桌面就被各种直播应用占满，追一个主播还得记住"他在哪家"。

Simple Live 的做法很直接：把四个平台的直播间放进同一个应用，顶栏一字排开四个标签，点一下就换台。搜索框也是统一的——输入主播名或房间号，不用先想"该去哪家搜"。

## 二、四个平台分别是什么观感

| 平台 | 在 Simple Live 里的观感 |
| --- | --- |
| 虎牙直播 | 赛事与主播覆盖完整，蓝光画质档位可手动切换 |
| 斗鱼直播 | 游戏直播为主，多线路可选，评测里常提到 1080P 60 帧档位 |
| 哔哩哔哩直播 | 分区齐全，虚拟主播、游戏赛事都有，部分内容需登录后观看 |
| 抖音直播 | 竖屏直播流，户外、聊天、才艺房间居多，划卡式浏览 |

首页的直播间卡片直接铺开，人气值挂在画面右上角，先刷再点，不用先进分类翻。想按游戏找房间的，分类页里有网游、手游的分区，直达具体游戏。

## 三、适合谁、不适合谁

- **适合**：混多平台的观众、只想"打开就看"不想折腾的人、以及想在电视大屏上看赛事的人（电视端另有单独版本）；
- **不适合**：习惯在直播间发弹幕互动、送礼物参与活动深度绑定单一平台账号的用户——它更像一个"看"的工具，互动功能以弹幕为主。

另外要说明：它是一个独立的开源项目，与四家平台没有隶属关系，个别房间偶尔失效属于正常现象，换线路或稍后再进通常就能解决。

## 四、从哪里了解它的界面

想先看一眼实际长什么样再决定装不装，可以看 [Simple Live 介绍站](https://simple-live.fewz.tech/)，那里的截图全部来自真机：首页刷直播、按分类找房、观看记录与账号管理页都有，安装文件资源的获取入口也在同一个站里。
