# 电视端与免登录使用说明

> 想在电视大屏上看赛事，或者担心"要不要注册账号""换手机记录还在不在"这类使用门槛？这篇把 Simple Live 的电视端、账号与多设备相关的疑问一次说清。

## 一、电视端是单独的版本

Simple Live 的电视端不是把手机版直接搬上大屏，而是项目单独开发的 Android TV 版本：界面按遥控器操作重新排过，焦点移动、返回层级都是电视的使用逻辑，目前仍标着测试版，但基础观看已经完整。

安装方式与手机端一样走安装包。装之前先确认设备是安卓系统——电视盒子型号繁杂，个别系统并非安卓，那种装不进去。大屏看赛事、看游戏直播，体验比举着手机舒服得多。

## 二、要不要登录账号

多数情况不用。虎牙、斗鱼、抖音的直播间，装好打开、选平台、点进去就能看，全程没有注册环节；哔哩哔哩的部分内容需要登录账号后观看，这是平台侧的要求，需要时在应用内的账号管理里登录一次即可。

也就是说，应用本身不强制注册、不设邀请码，账号只在特定平台的部分内容上才用得到。

## 三、换设备之后记录还在吗

"我的"页里有"数据同步"入口，关注与观看记录可以跟着账号走；换手机或同时用手机、平板时，先把同步打开，新设备登录同一账号后把数据拉下来即可。具体支持的范围以应用内当前显示为准，同步前建议先看一眼说明。

## 四、内容为什么会偶尔打不开

四家平台的直播内容都从对应平台的公开渠道获取，平台侧调整时个别房间会暂时失效。遇到打不开，先试两件事：换一条线路、换个清晰度；还不行就稍后再进。项目在 GitHub 上持续维护（`dart_simple_live`），更新后重新安装即可跟上修复节奏。

想看电视端之外手机端的实际界面，[Simple Live 下载与安装页](https://simple-live.fewz.tech/) 整理了真机截图和安卓版的安装步骤，装的时候照着走就行。
