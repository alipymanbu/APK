# 龙猫AI助手功能一览与适合谁用

「LongCat」是美团推出的 AI 助手应用，中文名「龙猫」，依托美团自研大模型，把问答、搜索、生图、语音通话装进同一个 App。本篇把它的功能摊开盘点一遍，帮你判断这只绿猫适不适合自己。

**相关文章**：[深度思考与联网搜索怎么开.md](深度思考与联网搜索怎么开.md) · [AI生图和语音通话体验怎么样.md](AI生图和语音通话体验怎么样.md)

## 功能盘点

| 功能 | 能干什么 | 适合的场景 |
| --- | --- | --- |
| 智能问答 | 多轮对话，回答结构化、条理清楚 | 生活百科、专业问答、写文案 |
| 深度思考 | 复杂问题先拆解再回答，给出推理过程 | 行程规划、数学逻辑题、方案对比 |
| 联网搜索 | 现查网页再作答，附检索来源 | 查价格、政策、赛事比分等新信息 |
| 图片生成 | 一句话出图，画面里的中文字渲染较准 | 做封面、海报、配图 |
| 图片编辑 | 生成后接着说「换风格」「去路人」就能改 | 二次修改，不用换工具 |
| 图片理解 | 传截图、报错、题目让它分析 | 拍照识图、学习辅导 |
| 音视频通话 | 像打电话一样直接聊，低延迟、懂方言 | 通勤做饭时动嘴不动手 |

## 适合谁用

- **想要一个随手可用的问答工具**：打字、按住说话都行，回答带来源可核对；
- **经常做内容的人**：生图改图在一个对话里完成，海报上的中文文字是它的强项；
- **家里有学习任务的人**：传题目让它讲思路，拍照识图省去打字描述；
- **习惯动嘴的人**：语音通话像打电话，方言口音也能听个大概。
