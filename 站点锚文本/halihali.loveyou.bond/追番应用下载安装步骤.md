# 哈哩哈哩下载安装步骤：从拿到安装包到桌面上图标

> 想在安卓手机上装哈哩哈哩（Halihali），这篇按顺序讲清三件事：去哪拿包、怎么装、装不上怎么对表排查。
> **相关阅读**：[弹幕倍速小窗设置技巧.md](弹幕倍速小窗设置技巧.md) · [二次元追番应用怎么选.md](二次元追番应用怎么选.md)

## 一、先核对手上的包

网上同名包很多，渠道不同版本也不同。动手机之前，先对一眼这份包的身份信息：

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.0.0 |
| 包名 | myapp.halihali |
| 安装包大小 | 3.34M |
| 系统要求 | 安卓系统 5.2 及以上 |

装好之后想先把播放设置摸一遍，可以看 [弹幕倍速小窗设置技巧.md](弹幕倍速小窗设置技巧.md)，那里按「想调什么 → 去哪调」列了速查表。

## 二、获取与安装四步

1. **拿包**：从夸克网盘的分享页把 APK 转存或直接下载到手机，文件名形如 halihali_v1.0.0.apk；
2. **点开文件**：在「文件管理 → 下载」里点开它；系统提示「禁止安装来自此来源的应用」时，点进提示里的设置项，给当前来源打开「允许安装」再返回；
3. **等进度走完**：桌面出现图标即成功；建议装在机身存储，外置存储卡读写不稳，容易出现打开异常；
4. **首次启动授权**：存储、网络按需给，拿不准的先拒绝，用到时应用会再申请。

部分手机安全软件会对新包提示「有风险」，这是常见误判；介意的话先核对包的 MD5 校验值，对得上再继续装。

## 三、装不上的常见报错

| 现象 | 处理办法 |
| --- | --- |
| 解析包时出现问题 | 重新下载，下完核对大小与校验值 |
| 应用未安装 | 手机里多半已装过另一渠道的同名应用，先卸载旧的再装 |
| 安装按钮点了没反应 | 去设置里给当前来源开「安装未知应用」权限 |
| 装完就闪退 | 核对系统是否达到安卓 5.2；不满足只能换设备 |
| 提示降级失败 | 手机上已是更高版本，卸载高版本后再装 |

装好之后如果打不开、白屏，先切一次网络、强停应用再开、清一次缓存，这三步能解决大部分启动问题；逐层排查思路在站内说明页里有更细的整理，入口见 [Halihali 追番手册](https://halihali.loveyou.bond/)。

## 四、网页端为什么进不去

平台方发过通告，网页端的在线观看功能已停止运营，番剧、漫画与社区内容改为只在应用内浏览。所以浏览器打不开网页版不是网络故障——想在电脑以外的场景追更，装应用登录原账号即可，收藏与播放进度都跟着账号走。
