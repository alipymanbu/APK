# yt-dlp 在安卓上的图形界面怎么用

> 本篇面向搜「yt-dlp 安卓」的人：yt-dlp 本身是命令行工具，想在手机上点着用，装一个图形前端即可。这里以 YTDLnis 为例，讲从粘链接到拿文件的操作路径，以及命令行参数在界面里的对应位置。**相关文档**：[安卓把视频存成mp3的几种做法.md](安卓把视频存成mp3的几种做法.md) · [apk安装提示未知来源怎么处理.md](apk安装提示未知来源怎么处理.md)

## 先弄清关系：工具与外壳

- yt-dlp 是一个命令行下载工具，支持一千多个网站，本身没有图形界面；
- YTDLnis 是第三方开发者做的安卓应用，把 yt-dlp 包成图形界面，系统要求安卓 7.0 以上；
- 它以 GPL-3.0 协议开源、无广告，安装文件资源的获取入口见 [YTDLnis 资料站](https://ytdlnis.wxhp.skin/)。

也就是说，你不需要会敲命令，也能用上 yt-dlp 的能力；本来就会用的，终端也给你留着（后面会讲）。

## 日常三步：粘贴 → 选格式 → 等完成

1. **把链接交给应用**：在浏览器或其它应用里看到想保存的视频，点系统的「分享」，选 YTDLnis，下载卡片会直接浮在当前界面上；也可以回到应用首页，把链接粘进搜索框；
2. **在下载卡片里做选择**：视频还是音频、容器格式（mp4、mkv、mp3 等）、分辨率与音质、要不要字幕、封面和元数据，逐项点选；文件名模板也能按自己的习惯改；
3. **交给队列**：确认后任务进队列，在后台继续，你可以同时排多个任务，随时暂停、恢复或调整顺序。

完成的文件存在应用的下载页里，实际落盘位置在「更多 → 设置 → 文件夹」里查看和修改。

## 命令行参数在界面里的对应位置

| 你以前可能这样敲 | 现在点哪里 |
| --- | --- |
| `yt-dlp "链接"` | 首页搜索框粘贴链接 |
| `-f` 选格式 | 下载卡片里的容器与画质选项 |
| `--write-subs`、`--embed-thumbnail` | 下载卡片里字幕、封面、元数据的开关 |
| `--sponsorblock-remove sponsor,intro` | 下载卡片里 SponsorBlock 相关开关 |
| `yt-dlp` 原生命令 | 「更多」里的终端，支持多会话 |

参数组合敲得多的话，把它们存成命令模板，之后套用一次点击，具体见应用内「命令模板」入口。

## 两个值得知道的批量玩法

- **播放列表**：粘整个列表链接，任务列表里每个条目可以单独改，也能统一下载类型、文件夹与文件名；
- **观察源**：对频道或播放列表设周期检查，有新内容就按你配置好的参数自动下载，适合追更。

## 常见边界

- 平台侧没有的画质或音质，选了也不会凭空出现；
- Netflix、Spotify 这类受 DRM 保护的流媒体不在支持范围内；
