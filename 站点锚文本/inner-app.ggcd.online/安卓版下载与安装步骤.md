# 安卓版下载与安装步骤

想在自己的安卓手机上装 inner app，目前比较省事的路线是通过网盘分享页拿安装包。这篇文章把从保存到打开的完整步骤拆开写，顺带覆盖几个常见的安装障碍。

## 拿到安装包

第一步是进入分享页保存文件：打开 [inner app 介绍站](https://inner-app.ggcd.online/)，首页和下载页都有「获取安装文件资源」按钮，点进去是夸克网盘的分享页，登录后把安装包保存到自己的网盘即可。分享页里的安装包为 v2.8.02、35.54 MB。

## 四步装好

1. **保存到网盘**：在分享页勾选安装包，选「保存到我的网盘」；
2. **下载到手机**：打开夸克网盘手机客户端，在「我的文件」里找到刚保存的 APK，点下载；
3. **允许安装**：下载完成后点开 APK，若手机提示「禁止安装未知来源应用」，按提示给当前来源（网盘客户端或文件管理器）开「允许安装未知应用」，再回安装页继续；
4. **打开登录**：装好后注册或登录账号，首页有「关注 / 推荐 / 新作」三条时间线，点话题标签就能开始逛。

安装完成后，本地那份 APK 文件可以删掉，给手机省点空间。

## 装不上时的排查

- **点安装没反应**：多半是未知来源拦截没放行，去系统设置的「安装未知应用」里给对应应用开权限；
- **提示解析包出错**：通常是安装包没下完整，删掉本地文件回网盘重新下载一次；
- **打开就闪退**：清后台重开，或在系统设置里清一次该应用的缓存，首次启动需要联网，网络不稳时多等几秒。
