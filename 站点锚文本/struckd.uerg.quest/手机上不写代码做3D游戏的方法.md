# 手机上不写代码做 3D 游戏的方法

> 想在手机上做出一个能跑、能玩、还能给朋友看的 3D 游戏，又不想碰代码？这类需求在安卓上曾经有一条很成熟的路——拖拽式游戏创作应用。这里以其中最有代表性的 Struckd 为例，把这套方法完整讲一遍。

---

## 一、核心思路：像拼积木一样做游戏

传统游戏开发要装引擎、学脚本；而拖拽式创作应用把这条链路压缩成「选玩法 → 摆素材 → 定规则 → 试玩」四步，全程手指点点拖拖就能完成。Struckd 是这条路上走得最远的产品之一：2016 年面世，2021 年并入 Unity 旗下，巅峰期每天有数千个新游戏被玩家做出来。

它的编辑器逻辑值得单独一说：

- **素材横条**：从 1500 多个元素的库里点选角色、载具、建筑、收集物，先放进屏幕底部的横条；
- **拖进场景**：再从横条把元素拖进立体场景，点选后出现选中框，可移动、旋转、缩放、无限复制；
- **地形与风格**：地形（Terrain）工具搭环境起伏，风格（Style）工具统改整体外观。

## 二、先定玩法机制，再动手

新建草稿的第一步是选核心机制，它决定角色的默认动作与胜负判定。常见类型有六种：竞速、冒险跳跑（jump'n'run）、物理解谜、RPG、大逃杀、塔防。机制允许混搭——比如竞速加射击——但混合玩法要多试玩几轮再收敛。

先定机制再摆素材，是返工最少的做法；反过来先堆素材再想玩法，几乎注定要推倒重来。

## 三、规则层：让素材「活」过来

摆好素材只是骨架，规则才是玩法。点选任意物件或角色会弹出属性面板，可调的东西比想象中多：

| 可调项 | 能做什么 |
| --- | --- |
| 数值 | 攻击力、移速、跳跃高度、侦测距离，甚至设为隐形、去碰撞 |
| 生存与破坏 | 设为可被摧毁，配血量、生命数、爆炸效果 |
| 行为（NPC） | 站立 / 跟随 / 防守 / 逃跑 / 巡逻 / 攻击 六选一 |
| 对话（NPC） | 写台词与任务文本 |
| 摄像机 | 俯视 / 第一人称 / 第三人称 |
| 胜利条件 | 加时限，或守住某处即获胜 |

这套「数值 + 行为」两层结构，是当年很多玩家在这个应用里做出相当完整作品的秘诀。

## 四、试玩即调，发布分享

草稿随时可以点试玩直接开一局，发现数值不对、摆位别扭，退出立刻改。满意后填标题、描述、封面就能发布，社区里的玩家在手机和网页端都能搜到、玩到；创作者主页会记录游玩数与点赞数。

想系统回顾这套玩法的话，[Struckd 资料站](https://struckd.uerg.quest/)上按同样的四步流程做了图文整理，还配了编辑器、竞速、冒险、多人对战的实机截图。

## 五、这条路现在还能走吗

要如实说明：Struckd 已于 2026 年 8 月 1 日终止线上服务，新玩家已经无法再登录、联机或发布作品。但「拖拽做 3D 游戏」这个思路并没有过时——同类工具在应用市场里仍能找到，而在电脑端，把 Struckd 作品导出到 Unity 编辑器继续开发的工程也仍然可以修改。相关现状梳理见[停服后还能怎么玩.md](停服后还能怎么玩.md)；还想留一份安装包作纪念的，获取与安装办法见[安卓安装包获取与安装步骤.md](安卓安装包获取与安装步骤.md)。
