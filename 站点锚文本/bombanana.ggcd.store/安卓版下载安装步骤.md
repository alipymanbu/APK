# bombanana 安卓版下载安装步骤：从转存到进游戏

> 这篇讲 bombanana 安卓版怎么从网盘装进手机：转存、下载、允许未知来源、进房组队，四步走完。玩法层面看 [三人拆弹怎么玩](三人拆弹怎么玩.md)；装好之后想少炸几回，翻 [盲聋哑三猴配合技巧](盲聋哑三猴配合技巧.md)。

bombanana 的安卓版安装包很小（约 2.7MB，v1.0），从打开分享页到装好进游戏，大概两分钟。整件事的核心只有一条：先转存到自己网盘，再下载到手机——安装包不容易失效，中途断了也能重来。

## 四步装好

1. **打开分享页，先转存**：进入 bombanana 的网盘分享页，选择"保存到我的网盘"完成转存，资源从此躺在自己的网盘里，随时能取；
2. **下载安装包到手机**：在自己网盘里找到 bombanana 的安装包（bombanana_v1.0.apk），用手机端网盘下载，注意别在传输中途断网；
3. **允许"未知来源"安装**：点开安装包，系统弹出未知来源提示时，选择允许该来源安装应用——这是一次性授权，装完可以改回去；
4. **装好开组队**：安装完成直接打开游戏，约上两位好友各领一只猴子，三人到齐就能进第一关。

装之前瞄一眼手机剩余空间：安装包只有约 2.7MB，但系统和后续缓存会再占一点，留 100MB 以上余量更稳妥。

## 三个最常见的安装拦路问题

- **点安装没反应，或提示被拦截**：多数是"未知来源应用"权限没开——进系统设置，找到浏览器或网盘应用，允许它安装未知应用，再回来重新点安装包；
- **安装包下载到一半失败**：网盘偶发的传输中断，重新下载一次即可；反复失败就先核对文件大小是否约 2.7MB，差得多就删掉重新转存一份再下；
- **装好了却进不了房间**：游戏需要联网组队，先确认手机能正常上网；房间要凑齐三只猴子才能开，人没到齐会一直停在等待位。

## 装好之后

第一局建议和熟人开语音：聋猴听不见、哑猴说不了，剩下的信息还得靠嘴传；面对面坐成一排直接喊，效果比语音还好。更多角色与模块的整理版内容，可以逛逛 [bombanana 拆弹小队介绍站](https://bombanana.ggcd.store/)，按"角色 → 说明书 → 关卡"的顺序过一遍再上车。
