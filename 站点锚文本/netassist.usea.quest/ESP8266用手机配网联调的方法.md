# ESP8266 用手机配网联调的方法

ESP8266、ESP32 这类 WiFi 模块拿到手，第一件事是把路由器的名称和密码写进去（配网），第二件事才是验证它联网后能不能正常收发数据。这两件事都可以只用一部安卓手机完成，不必接电脑刷参数。

## EspTouch 配网的原理与步骤

EspTouch 是乐鑫（Espressif）为自家模块设计的配网方案：手机把 WiFi 名称和密码编码进一串 UDP 组播/广播报文里发出去，模块处于 SmartConfig 状态时在空中"听"到这串报文，解析后就自己连上路由器。整个过程不用给模块接线，密码也不经过任何服务器。

具体操作：

1. 手机连上目标路由器（模块将来也要连这个）；
2. 让模块进入 SmartConfig 状态——通常固件上电后自动进入，或按开发文档用 AT 指令开启；
3. 手机端打开带 EspTouch 功能的调试工具，输入当前 WiFi 的密码，发送；
4. 几秒内模块应答配网成功，路由器后台能看到它上线。

配网失败多出在这几处：模块固件没进 SmartConfig；手机用了 5GHz 频段而模块只支持 2.4GHz；路由器开了无线安全策略拦组播。逐项排除即可。

## 配完网怎么验证

配网只证明模块"上了网"，报文通不通还要再验一步：

- 让模块跑客户端固件，手机开 **TCP 服务端**填好端口等模块连入，连上后互发数据；
- 或者手机当 **TCP 客户端**，去连模块固件监听的端口；
- 模块用 UDP 通信时，手机选 **UDP** 模式填对端地址端口，单播广播都能测。

收发验证建议文本和 HEX 各来一轮：AT 指令、JSON 报文用文本看，自定义协议帧用 HEX 对字节。

## 一部手机够用的原因

传统流程是电脑装串口调试助手加网络调试助手各一套，现场联调时设备可能装在楼道、天花板上，拖电脑反而不现实。手机端工具把配网（EspTouch）和网络调试装进同一个应用，站在设备旁边就能完成"配网—建链—收发"整条链路，这也是这类工具在嵌入式圈子里流行的原因。想直接上手，可以从 [网络调试助手手机版这个介绍站](https://netassist.usea.quest/) 入门，里面对三种连接模式和界面都有截图说明。
