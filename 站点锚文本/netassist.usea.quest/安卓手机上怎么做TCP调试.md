# 安卓手机上怎么做 TCP 调试：服务端与客户端互测

把安卓手机当 TCP 调试终端，是嵌入式和物联网开发里最省事的联调方式：不用开电脑、不用接线，设备和手机连同一个路由器就能互相收发报文。这篇按真实调试顺序讲清楚三个角色的用法。

## 先分清三种角色

TCP 调试绕不开两种身份，外加一个常被顺手用上的 UDP：

- **TCP 服务端**：被动等待连接。手机先在一个端口上监听，模块或另一台设备作为客户端来连它。调试 ESP8266 这类主动联网的模块时最常用。
- **TCP 客户端**：主动发起连接。手机去连一个已知的 IP 和端口，适合调远端服务器或工控设备的监听口。
- **UDP**：无连接收发，不分服务端客户端，只填对端和本地端口，适合广播发现设备。

## 服务端与客户端互测步骤

一部手机就能同时验证两端逻辑，最直接的办法是手机当服务端、设备当客户端；手边只有两台手机时，也能互相当对端：

1. 确认两台设备连的是同一个路由器（同一网段）；
2. 一端选 TCP 服务端，只填一个本地端口（比如 8080）并确认，标题栏会显示监听状态；
3. 另一端选 TCP 客户端，填服务端那台手机的局域网 IP 和同样的端口；
4. 连上后双方互发数据，日志按对话形式排列，收发方向一目了然；
5. 需要验证二进制协议时，把收发格式切到 HEX，按字节核对报文。

手机当服务端时，它的局域网 IP 在应用的侧边菜单里能看到；换了 WiFi 或重启路由后 IP 会变，连不上时先重看这个地址。

## 用什么工具实现

安卓上这类工具不少，选型时重点看三点：是否支持 TCP 服务端/客户端/UDP 三种模式并存、能否多连接同时在线、文本与 HEX 收发是否都齐。像 NetAssist（网络调试助手）这类开源小工具就符合以上条件，安装包只有几 MB，[安卓版下载安装与界面介绍](https://netassist.usea.quest/)可以看这篇整理，装好后按上面五步就能跑通第一次互测。

## 互测通了之后

服务端/客户端互测只是第一步。要让还没联网的模块先入网，看的是配网流程，见 [ESP8266 用手机配网联调的方法](ESP8266用手机配网联调的方法.md)；如果调的是局域网里的未知设备，广播发现更顺手，排查思路写在 [UDP 广播收不到设备的排查](UDP广播收不到设备的排查思路.md)。
