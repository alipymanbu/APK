# 扫地机器人配网绑定手机教程

> 讲怎么把石头扫地机器人连上家里 Wi-Fi 并绑进 Roborock App：配网前的四个前提、扫码与搜索两种添加方式、Wi-Fi 指示灯怎么看。
> **相关文档**：[扫地机器人App怎么下载安装.md](扫地机器人App怎么下载安装.md) · [扫地机器人地图与清扫设置.md](扫地机器人地图与清扫设置.md) · [扫地机器人离线与搜不到设备排查.md](扫地机器人离线与搜不到设备排查.md)

## 一、配网就一句话

让机器人连上你家 Wi-Fi，再绑到你的账号下。入口在 App 首页右上角的「+」，顺利的话几分钟走完。绑到哪个账号，设备就归哪个账号管。

## 二、先满足四个前提

差一条，配网多半卡在半路：

1. **机器人电量充足**——先放回充电座充一会儿再配；
2. **手机连的是家里的 Wi-Fi**——不是流量；
3. **Wi-Fi 是 2.4GHz 频段**——多数机型只支持 2.4GHz、不认 5GHz。双频路由器把两个频段分开命名（比如 `xxx_2.4G` 和 `xxx_5G`），配网时选 2.4G 那个；共用一个名字的直接选它试，连不上就去路由器后台分开；
4. **App 拿到了位置权限**——搜设备要用，安卓搜不到机器人多半是这条没给。

另外提醒：App 没有针对平板做适配，iPad 或安卓平板上配网容易出问题，用手机操作。

## 三、支持扫码的机型

Q7 Max、Q7、Q5、S8 系列、Q Revo、Q5 Pro、Q8 Max 等系列支持扫二维码添加（以你机型的实际情况为准）：

1. 打开机器人上盖，找到二维码（部分机型贴在尘盒上或机身顶部）；
2. App 首页点「+」添加设备，按提示扫码；
3. 选 2.4GHz 的 Wi-Fi 名称、输密码；
4. 开着上盖观察 Wi-Fi 指示灯，等 App 提示配网完成。

## 四、没有二维码的机型

1. 打开机器人上盖，找到 Wi-Fi 指示灯；
2. App 首页点「+」→「搜索设备」，点「未找到二维码」继续；
3. **重置 Wi-Fi 让机器人进入等待配网状态**：按住机身上的「局部/定点清扫」和「回充/充电座」两个键，听到 Resetting WiFi 语音、指示灯转慢闪即成功（机型不同按键位置略有差异，以说明书为准）；
4. 回到 App 按引导继续：选 2.4GHz Wi-Fi、输密码，等配网走完。

用 iPhone 的话中途会多一步：切到系统 Wi-Fi 列表，选中名字以 `roborock-vacuum` 开头的机器人热点，选完再回 App。

## 五、看懂 Wi-Fi 指示灯

| 状态 | 含义与处理 |
| --- | --- |
| 慢闪 | 已重置、正在等待配网，正常状态 |
| 一直快闪 | 可能在连网；反复快闪下不去，多半是**密码输错了**，重置 Wi-Fi 再来 |
| 复位后仍慢闪不动 | 检查 App 的 Wi-Fi/位置权限是否给全，再重试 |

配网成功后回 App 首页点进设备，等初始化进度到 100%，就能开始使用了。

## 六、配完先跑一次全屋

连上只是开始，机器人要先建图，之后才能按房间、区域派活。建图与清扫设置的具体玩法见 [扫地机器人地图与清扫设置.md](扫地机器人地图与清扫设置.md)；装 App 的入口在[Roborock App 介绍站](https://roborock.fewz.tech/)；配网反复失败的，翻 [扫地机器人离线与搜不到设备排查.md](扫地机器人离线与搜不到设备排查.md)。
