# 扫地机器人离线与搜不到设备排查

> 石头扫地机器人在 App 里显示离线、配网一直失败、搜不到设备？按这篇的顺序查：从路由器和指示灯查起，重置 Wi-Fi 是最后一步。
> **相关文档**：[扫地机器人配网绑定手机教程.md](扫地机器人配网绑定手机教程.md) · [扫地机器人App怎么下载安装.md](扫地机器人App怎么下载安装.md) · [扫地机器人地图与清扫设置.md](扫地机器人地图与清扫设置.md)

## 一、按这个顺序查，别上来就重置

设备离线九成出在网络上：支持的频段、Wi-Fi 密码、路由器设置、App 权限，从便宜到贵一条条排。重置 Wi-Fi 放最后，先把前面的查完。

## 二、显示离线，先查路由器

1. **机器人只认 2.4GHz**：家里最近换过频段设置（关了 2.4G、合并了双频），机器人就会掉线——去路由器后台把 2.4GHz 开回来；
2. **改过 Wi-Fi 名称或密码**：机器人还记着旧的，需要在 App 里重新配一次网，步骤同 [扫地机器人配网绑定手机教程.md](扫地机器人配网绑定手机教程.md)；
3. **重启路由器**：等两三分钟看设备会不会自己上线，多数「离线」到这步就好了；
4. **机器人没电或关机**：确认开机、电量不为零，放回充电座充几分钟再看；
5. **刚换了手机**：多半是在新手机上登录了个新账号——设备和地图跟着原账号走，退出后用原来的账号重新登录。

## 三、配网失败：对号入座

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 搜不到设备 | 位置权限没给、机器人没进配网状态 | 给 App 开位置权限；重置 Wi-Fi 到慢闪再搜 |
| 指示灯一直快闪 | Wi-Fi 密码输错 | 重置后重新输，注意大小写和特殊字符 |
| 复位后仍慢闪、配不进去 | App 的 Wi-Fi/位置权限被系统收回 | 系统设置里补全权限再试 |
| 配上了又掉线 | 信号弱、2.4G 干扰重 | 充电座挪到离路由器近一点再配 |

App 没有适配平板，配网反复失败时换手机试，别用 iPad 或安卓平板。

## 四、重置 Wi-Fi 再重配

前面都查过还不行，做一次干净的配网：

1. 按住「局部/定点清扫」+「回充/充电座」组合键，听到 Resetting WiFi 语音、指示灯转慢闪（机型不同按键有差异，以说明书为准）；
2. App 首页点「+」重新添加设备，选 2.4GHz Wi-Fi、输密码；
3. iPhone 中途会切到系统 Wi-Fi 选 `roborock-vacuum` 开头的机器人热点，选完回 App；
4. 配完回首页点进设备，等初始化到 100%。

重配网不影响账号；地图是否保留因机型而异，图丢了按 [扫地机器人地图与清扫设置.md](扫地机器人地图与清扫设置.md) 重新建一次。
