# 提词器文字反了镜像设置

> 拍出来发现提词的文字左右翻转、读着费劲？十有八九是镜像开关和你的观看方式没对上。这篇讲清原理和开关判断，一分钟修好。

## 一、为什么会出现反字

反射式提词器的玻璃会把手机屏幕上的字「翻转一次」再送进你的眼睛——这是光学原理，不是故障。所以应用里要先在播放设置中开启文档镜像，让文字预先翻转一次，两道翻转抵消，隔着玻璃看到的才是正字。

## 二、开关判断就一句话

**隔着玻璃看 → 开镜像；直接看屏幕 → 关镜像。**

- 手机装进 NEEWER X 系列这类反射式提词器托架，读的是玻璃反射出来的字：镜像开。
- 手机架在摄像头旁边、直接看屏幕念：没经过反射，镜像必须关，开了字全是反的。

拍完回看发现画面里字是反的，或者自己读着别扭，先去播放设置里核对这一项，别急着动玻璃角度。

## 三、装进提词器托架的完整顺序

1. 撕掉玻璃保护膜（忘了这步，字会糊成一团，跟反字是两回事）；
2. 玻璃调到约 45° 锁紧；
3. 开镜像、进播放界面；
4. 调整托架和遮光罩，确认取景器里看不到托架和提词器部件。

遮光、镜头焦距（大于 28mm）和收纳注意事项，在 [Teleprompter 现场笔记](https://teleprompter.wrwq.fun/) 的遥控与布置一节有完整清单；字号速度的配合见[口播提词器怎么用才自然.md](口播提词器怎么用才自然.md)，遥控器相关见[提词器蓝牙遥控器搜不到.md](提词器蓝牙遥控器搜不到.md)。
