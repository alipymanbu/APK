# 提词器蓝牙遥控器搜不到

> Teleprompter 配 NEEWER 蓝牙遥控器（RT-110 / RT111 / RT113）时，最常见的三类故障：搜不到设备、配对失败、连上但按键没反应。这篇按官方说明书的排查顺序整理成清单，从最容易漏的一步开始。

## 一、先看指示灯

遥控器用蓝灯状态区分模式：**闪烁 = 配对模式，可以被搜到；常亮 = 已连接**。搜不到时先长按电源键重新开机，让它回到闪烁状态再搜。完全不亮就是电池问题，RT111 / RT113 换新 AAA 电池，注意正负极。

## 二、搜不到：四步排查

1. 电池装对、电量足；
2. 手机蓝牙已开；
3. **定位服务也打开**——部分安卓机型的蓝牙扫描依赖定位，这是最容易漏的一步；
4. 遥控器关机重开，手机蓝牙开关一次或直接重启手机。

周围耳机、手表连得多的话，先把其他蓝牙连接断开再搜，减少干扰。

## 三、配对路径不对：换一条路重来

这套应用的配对材料存在两种口径：一类说明要求**在应用内**的设备连接入口搜「NEEWER RT…」连接，不要直连系统蓝牙；另一类说明则写**先在系统蓝牙里配对**，再回应用使用。两种路径对应不同型号批次，卡住时的实际解法是：

1. 在手机蓝牙设置里对这个遥控器执行「取消配对 / 忽略此设备」；
2. 换另一条路径重来；
3. 连上后进播放界面按一下播放键验证。

## 四、连上了但按键没反应

- 确认装的是 NEEWER Teleprompter 本体，第三方套壳应用收不到遥控指令；
- 完全杀掉应用重进（不是切后台）；
- 按键对照：电源键管播放暂停，A+ / A− 管字号，▲▼ 在播放中调速度、暂停时翻页。

还没装应用的，先从 [Teleprompter 现场笔记](https://teleprompter.wrwq.fun/) 拿到安装文件资源入口；用法见[口播提词器怎么用才自然.md](口播提词器怎么用才自然.md)，字反了见[提词器文字反了镜像设置.md](提词器文字反了镜像设置.md)。
