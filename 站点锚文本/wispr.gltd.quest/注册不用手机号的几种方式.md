# 注册不用手机号的几种方式

> 这篇盘点加密通讯应用 Wispr 的注册入口：手机号、邮箱与 Matrix ID 三种方式的差别、收费档位和怎么选。
> 相关文档：[密钥和聊天记录都存在哪.md](密钥和聊天记录都存在哪.md) · [添加联系人要等对方接受才聊得成.md](添加联系人要等对方接受才聊得成.md)

---

多数聊天应用注册的第一步都是填手机号，Wispr 把这件事做成了可选项。按产品方公开页的信息，注册入口有三种，对应不同的保护强度和价位，装好应用后第一次打开就会遇到怎么选的问题，这篇提前帮你把差别理清。

## 三种入口对照

| 注册方式 | 费用 | 依赖什么 | 保护强度 |
| --- | --- | --- | --- |
| 手机号 | 免费 | 一个能收验证码的号码 | 中等 |
| 邮箱 | 免费 | 一个邮箱地址 | 中等 |
| Matrix ID | 付费（按产品方页面标价，以当时显示为准） | 不依赖手机号/邮箱 | 强 |

手机号和邮箱两档都能连接外部通讯方式，日常使用没有门槛；Matrix ID 档接入的是另一套协议体系，注册出来的是一个不与你的手机号挂钩的身份标识，这也是它在保护强度上与免费档拉开差距的地方。另有面向组织的 Enterprise 档，按需报价，个人用户用不到。

## 怎么选

- **只是想先试试**：手机号或邮箱注册足够，免费、流程短，选哪个看你更愿意交出哪样信息；
- **在意身份与号码的绑定关系**：走 Matrix ID 档，代价是每年一笔订阅费；
- **犹豫不决**：先用免费档注册把应用跑通，确认自己长期用，再考虑换档——注册方式没选好的，卸载重装即可重新选择，成本不高。

## 注册完的第一步

账号建好后别忘了这个应用的特殊之处：添加第一位联系人时，要等对方接受请求才能开始加密会话，卡在这一步不是异常，原理与等待时间在[添加联系人要等对方接受才聊得成](添加联系人要等对方接受才聊得成.md)里专门讲过。

顺带一提，账号决定的是"别人怎么找到你"，而你的聊天记录存在哪、能不能恢复，由设备说了算，两件事互不相干。这层的逻辑，[Wispr 解析站](https://wispr.gltd.quest/)的数据存放一节有更完整的展开。
