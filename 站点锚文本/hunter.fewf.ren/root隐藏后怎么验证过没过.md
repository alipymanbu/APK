# Root 隐藏后怎么验证过没过

> 用 Magisk 一类方案隐藏 Root 之后，验证到底生没生效的完整思路：拿什么扫、看哪里、没过时怎么处理。
> **相关文档**：[检测项逐条解读.md](检测项逐条解读.md) · [黑灰设备提示怎么处理.md](黑灰设备提示怎么处理.md)

## 一、为什么改完配置还要再测

隐藏 Root 靠的是配置与模块的组合，改一个参数、换一个模块版本，结果都可能变。所以验证不是一次性的事：每次动过 Magisk 配置或更新模块之后，都应该重新扫一遍，确认隐藏配置还有效。

## 二、验证的完整流程

1. **先跑一遍全量检测**。[Hunter 检测](https://hunter.fewf.ren/)这类环境检测工具打开即扫，不用配置；它一次覆盖 Root、框架、沙箱、调试器、模拟器与设备指纹，适合当验证的主力。
2. **看总判定**。首页直接给本次结论：通过就说明当前隐藏方案在这台机器上有效；列出了风险项，就进入下一步。
3. **没过时看它列出的进程与服务**。报告会写明哪些进程、服务在干扰隐藏，不会只丢一句「未通过」。
4. **照单处理后复测**。用进程管理工具把列出的项逐个关掉，再扫一遍，直到相关项不再报。

## 三、两个实操提醒

- **别只信一个工具的判词**。同一台机器拿两三个检测工具各扫一遍，两个以上都指向同一项基本可以确认；只有一个报，优先按误报排查。
- **版本要对齐**。检测项随版本增减，对比「改动前 / 改动后」的结果时，前后用同一个版本才有可比性。
