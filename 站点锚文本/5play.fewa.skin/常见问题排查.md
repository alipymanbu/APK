# 5play 常见问题排查

> 按「现象 → 处理」整理 5play 最常被问到的几类问题：装不上、打开空白、搜不到、下不动。
> **相关文档**：[怎么下载安装.md](怎么下载安装.md) · [怎么找资源和下载.md](怎么找资源和下载.md)

---

5play 是个轻客户端，问题大多出在两件事上：安装环节的来源权限、运行环节的网络。先按现象对号，大部分两分钟内能解决。

## 一、安装环节

| 提示 | 处理 |
| --- | --- |
| 解析包时出现问题 | apk 多半没下完整，重新下载并核对大小约 2MB 再装；先转存再下载更稳 |
| 已阻止安装未知来源 | 按弹窗入口进设置，允许该来源安装；各品牌入口位置不同，一般在「应用管理 → 特殊应用权限」附近 |
| 安装失败（已有旧版） | 先卸载旧版再装；应用内数据会被清，介意先记下收藏内容 |
| 存储空间不足 | apk 本身只要 2MB 出头，清出几百 MB 余量即可——真正占地方的是后续下载的资源 |

安装全流程见 [怎么下载安装.md](怎么下载安装.md)。

## 二、启动与联网

- **打开后一直空白或转圈**：内容全靠联网获取，先确认手机能上网，再检查是否给应用禁了网络权限（部分系统可按应用限网，解除即可）；
- **打开就闪退**：先重启手机排除临时故障；仍复现就卸载后重装一遍安装包。

## 三、搜索与下载

- **搜什么都搜不到**：检查输入有没有多余空格，换更短的关键词再试；
- **点了下载没反应**：任务走系统下载管理器，进度在通知栏看，不在应用内——通知栏没有就回应用重按一次；
- **进度反复归零**：换稳定网络，系统下载器支持断点续传，网络一稳会接着下；
- **下完了找不到文件**：系统「下载」目录里按时间排序找最新的 apk。

## 四、兜底办法

以上都对不上时，卸载重装一遍最直接。重装会清掉应用内数据，但已经装好的游戏和应用不受影响。装完核对包名 `com.wplay.hw`，对得上才算装回了同一款。

从零开始装见 [怎么下载安装.md](怎么下载安装.md)；功能模块的完整说明在 [5play 介绍站](https://5play.fewa.skin/)首页。
