# Mineradio 安卓版下载安装步骤

> 本篇讲怎么把安卓版 Mineradio 装进手机：从哪里拿到安装文件、装的时候要授什么权限、卡在哪几处最常见。
> **相关文档**：[粒子视觉效果怎么调](粒子视觉效果怎么调.md) · [本地音乐导入与音效设置](本地音乐导入与音效设置.md)

---

## 一、装之前先对一眼机型

这份安卓安装包是 v1.1.5 存量版本，约 40.85 MB，系统要求安卓 5.2 及以上。Mineradio 本身按 GPL-3.0 协议开源，免费、无广告、无内购，安装时不需要任何账号，装好即可离线使用。

安卓版本低于 5.2 差得远的机型装不了这一版，安装中途提示「系统版本过低」就别反复重试了。

## 二、从哪里拿安装文件

安装文件资源放在夸克网盘，入口收集在 [Mineradio 介绍站](https://www.bpfl.quest/) 的下载页里，打开后按页面提示把资源转存到自己的网盘，再从网盘下载 `Mineradio_v1.1.5.apk` 到手机存储。

下载完先看一眼文件大小：在 40.85 MB 上下才算完整，明显偏小说明没下完，重下一次再装，装一半的包十有八九会报「解析失败」。

## 三、安装步骤

1. 在手机文件管理里点开 `Mineradio_v1.1.5.apk`；
2. 系统弹「是否允许安装」时选择允许；
3. 若提示先开启「安装未知来源应用」，按提示跳到系统设置，把权限授给这次打开安装包的入口（浏览器或文件管理器），再返回重试；
4. 等安装走完点「打开」；首次启动会申请「读取本地音频」权限，允许后应用自动扫描手机里的歌曲；
5. 想同步网易云或 QQ 音乐的收藏歌单，点首页右上角「登录」按提示授权即可。

## 四、装不上时对照这几条

| 现象 | 处理 |
| --- | --- |
| 提示「解析失败」或「解析包出现错误」 | 先重下安装包并核对大小；部分机型的「纯净模式」会拦第三方安装包，关掉再装 |
| 提示存储空间不足 | 清出比安装包大出数倍的空间，安装过程需要额外空间展开文件 |
| 提示与已有应用冲突 | 手机里装过同包名的旧版，先卸载再装 |
| 装好打开就闪退 | 确认机型安卓版本达标，重启手机后再开一次 |

装好之后想调播放页的粒子画面，看 [粒子视觉效果怎么调](粒子视觉效果怎么调.md)；把本地音乐整理起来、调出顺耳的音色，看 [本地音乐导入与音效设置](本地音乐导入与音效设置.md)。
