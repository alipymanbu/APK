# Mineradio 介绍站

Mineradio 是一款按 GPL-3.0 协议开源的安卓音乐播放器：播放页里粒子随节拍律动、镜头随旋律运镜，本地曲库与网易云、QQ 音乐的收藏歌单汇成同一个队列，另带桌面悬浮歌词、十段均衡与天气电台。

本目录收录围绕它的使用整理：

- [安卓版下载安装步骤](安卓版下载安装步骤.md)
- [粒子视觉效果怎么调](粒子视觉效果怎么调.md)
- [本地音乐导入与音效设置](本地音乐导入与音效设置.md)

安卓安装文件资源的获取入口见 [Mineradio](https://www.bpfl.quest/) 介绍站。
