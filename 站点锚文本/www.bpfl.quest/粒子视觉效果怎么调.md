# 粒子视觉效果怎么调

> 本篇讲 Mineradio 播放页那套粒子画面怎么调教：入口在哪、能改哪些参数、卡顿怎么降负载、特效突然消失怎么查。

## 一、这套画面是什么

Mineradio 的播放页不满足于放进度条：音乐响起时画面里会生成粒子特效，形态、颜色与运动轨迹跟着节奏、鼓点和旋律变化，歌单与歌曲切换时还带运镜转场。它的启动页写着 PRIVATE VISUAL RADIO——私人视觉电台，这四个字基本概括了它和普通播放器的分野。

## 二、能调哪些参数

进入视觉设置面板（有的版本叫「视觉实验室」或「视觉控制台」，以实际界面为准），可调的东西分三路：

| 调节对象 | 可改的内容 |
| --- | --- |
| 粒子系统 | 粒子密度、运动速度 |
| 背景动画 | 背景色调、背景画面 |
| 歌词样式 | 歌词位置、展示效果 |

另外还有多套视觉预设可以一键切换：封面粒子、音域回响、星河、唱片、星球、滚筒，以及收掉全部粒子的「虚空」模式；调好的配置可以存成自己的配置档。播放页的镜头支持 360° 自由拖转，部分版本还支持导入 MP4 视频当动态背景、用摄像头手势隔空操控。

## 三、低配机卡顿怎么降负载

粒子的形态与数量是这套视觉里主要的性能消耗来源。播放卡顿、发热偏大时按这个顺序收：

1. 把粒子密度调到最低一档；
2. 简化背景动画与色调层；
3. 切到无粒子的「虚空」类模式；
4. 还不行就在画质和流畅里二选一——基础播放本身不受影响。

## 四、特效突然不显示了

播放时画面一片素净，按这个顺序查：

1. 进视觉控制台确认特效开关是开的，误关过就重新打开；
2. 换一个视觉预设再播放，排除当前预设出问题；
3. 彻底退出应用重进——后台被系统清掉重载后偶发异常。
