# itch.io 是个什么平台：独立游戏库的来龙去脉

> 手机上那份叫 itch 的应用，名字来自独立游戏圈最有名的平台之一 itch.io。本篇讲这座平台的来历、运转模式与社区生态，帮你看懂「这份安卓应用」与「那座平台」之间的关系。

## 一、来历：2013 年至今

itch.io 在 2013 年 3 月上线，创始人是 Leaf Corcoran。它做的事一句话能说清：给独立游戏开发者一个直接发布作品的货架，玩家直接从开发者手里拿游戏。截至 2024 年底，平台上托管的项目已经超过一百万个——游戏之外还有漫画、音乐、游戏素材这类创作内容。《A Short Hike》《Dicey Dungeons》这些后来登上主机与主流商店的独立名作，最初都在这里发迹。

## 二、它和常见游戏商店的差异

| 维度 | itch.io 的做法 |
| --- | --- |
| 分成 | 开发者自己定平台抽成比例，默认 10%，可以调到 0 |
| 定价 | 大量作品走「随喜付费」，定价 0 也能拿，愿意支持就多付 |
| 版权管理 | 文件原样分发，不加 DRM 限制 |
| 页面 | 每个开发者可以自定义自己作品页面的样式 |

低门槛让个人开发者几乎零成本上架，反过来也意味着作品质量参差——既会捡到宝，也会遇到做了一半的实验品，挑的时候多看介绍与截图。

## 三、Game Jam：限时做游戏的社区活动

itch.io 是各类 Game Jam（限时游戏创作活动）的主要举办地之一：参与者在限定时间（常见一至三天）内按主题做出一款游戏并公开，最有名的包括 Game Maker's Toolkit 办的 GMTK Jam。对玩家来说，这意味着货架上永远有新鲜、大胆的实验小品可翻。

## 四、桌面端与移动端的现状

- 桌面端有一款与平台同名的 itch 应用（Windows / macOS / Linux），负责下载、更新与离线游玩，2016 年前后就有了；
- itch.io 团队没有出过安卓端，手机浏览器直接访问 itch.io 网站是最直接的姿势；
- 安卓上的第三方移动客户端（如 F-Droid 上的开源作品 Mitch）由社区维护，与平台团队无隶属关系。

## 五、手机上这份 itch 应用怎么定位

它是一款第三方打包的游戏库应用（包名 `com.newh5itch`），把 itch.io 的作品浏览与获取搬到手机上，逛法与浏览器访问一脉相承。货架上的内容由社区发布，下载前看体积、看介绍、看截图，自己把关。
