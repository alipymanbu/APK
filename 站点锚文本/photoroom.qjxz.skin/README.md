# PhotoRoom 站点目录

这里是 PhotoRoom（安卓图片编辑应用）的介绍文章目录。PhotoRoom 主打 AI 抠图与背景更换：选图后自动把主体抠出来，换白底、套场景、加阴影，几分钟做出能上架的商品图。

想快速了解这个应用的功能与上手流程，看这篇入门：[photoroom](https://photoroom.qjxz.skin/)。
