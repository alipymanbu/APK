# 模型导出与格式选择

> 在 Nomad 里捏完的模型怎么拿出来：导出入口在哪、OBJ / STL / glTF 各自给谁用、颜色怎么带出去，本篇按用途讲清楚。
> **相关文档**：[安卓3D雕刻入门.md](安卓3D雕刻入门.md) · [笔刷与雕刻技巧.md](笔刷与雕刻技巧.md)

## 一、导出入口

导出藏在顶部左侧的文件菜单里，与导入、保存项目放在一起。导出前建议先存一份项目文件：项目保留图层与可编辑状态，而导出的通用格式是"烤死"的成品，改不回去。

## 二、三种格式按用途选

| 格式 | 特点 | 典型去处 |
| --- | --- | --- |
| OBJ | 最通用的交换格式，几何与顶点颜色都能带 | 导进 Blender、Maya 做后续处理 |
| STL | 只有几何、没有颜色 | 3D 打印切片软件 |
| glTF | 现代格式，能携带材质与绘画信息 | 实时引擎、需要保留材质的流程 |

几个容易踩的点：

- **顶点颜色不等于贴图**。Nomad 把颜色、粗糙度、金属度直接画在顶点上；做过烘焙的话，导出 OBJ 时贴图会一起带出，可以直接拿去别的绘画软件继续画；
- 想在别的软件里继续做 UV 与贴图：低多边形物体可以直接 UV 展开；顶点颜色能烘焙成贴图，贴图也能投射回顶点，两个方向都在拓扑菜单里；
- 别人给的 OBJ / STL / glTF 从文件菜单丢进来，就能接着刻。

## 三、颜色对不上怎么办

分两种情况排查：

1. **画的时候就觉得色不对**：PBR 模式按物理光照显示，鲜亮颜色会显得发暗。想看"画的是什么色"，把光照切到 Unlit（无光照）或选个偏白材质球的 Matcap，颜色原样呈现；
2. **导出后在别的软件里对不上**：目标软件的光照与色彩管理不同，换中性环境或调曝光后再核对。

做贴纸、虚拟服饰时有个常用路子：视角摆到与参考照片一致、加一盏方向相近的灯，导出透明背景的 PNG，再进修图软件合成——这条链路只用渲染图，不碰模型格式。

## 四、和桌面软件的边界

能互通的是通用格式与 Alpha 贴图；不能互通的是各自的工程文件——Nomad 的项目文件只能由它自己打开，换设备前把项目文件夹整个拷走。ZBrush 的私有工具文件导不进来，但它的 Alpha 贴图可以拿来当笔尖用。

从捏形到导出，整条链路在安卓设备上就能闭环；还没装的先去 [Nomad 资源站](https://nomad.uerg.quest/) 取安装包。导出去的模型想继续精修，笔刷层面的功夫补在 [笔刷与雕刻技巧.md](笔刷与雕刻技巧.md)；刚上手的新手回到 [安卓3D雕刻入门.md](安卓3D雕刻入门.md)。
