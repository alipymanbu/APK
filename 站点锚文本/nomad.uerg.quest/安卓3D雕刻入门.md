# 安卓 3D 雕刻入门：从一颗球开始

> 本篇写给没接触过 3D 雕刻的新手：Nomad 打开长什么样、手势怎么用、第一件作品怎么从一颗默认球体捏出来，以及怎么把界面切成中文。
> **相关文档**：[笔刷与雕刻技巧.md](笔刷与雕刻技巧.md) · [模型导出与格式选择.md](模型导出与格式选择.md)

## 一、先认界面

启动后屏幕上有一颗默认球体，界面分成几块：顶部两串图标分别管场景对象（文件、拓扑、材质、光照）与工具设置；右侧一条可滚动的工具箱装着全部雕刻工具；左侧是半径、强度两枚滑块，外加减泥（Sub）、抹平（Smooth）、对称（Sym）、遮罩（Mask）、移动控件（Gizmo）等高频开关；底部一排管撤销、重做与历史记录。

手机横竖屏都能用，屏幕小的时候顶部菜单会自动合并，别担心功能丢了。左撇子可以在界面设置里把工具栏整体镜像。

## 二、五个手势走天下

| 想做什么 | 手势 |
| --- | --- |
| 雕刻 | 在模型上单指（或压感笔）拖动 |
| 旋转视角 | 在模型外的空白处拖动 |
| 缩放 | 双指捏合 / 张开 |
| 平移 | 双指按住拖动 |
| 撤销 | 双指轻点一下 |

对称默认开启，捏脸、做手这类左右对称的结构最省事；做不对称的细节时记得关掉。

## 三、捏出第一件东西

1. 用默认的 Clay（粘土）工具在球体上涂，表面会鼓起来——这就是"堆泥"；
2. 强度滑块先调低，慢慢堆比一笔下去大力出奇迹好修；
3. 点左侧 Sub 切成减去模式往里挖，再点一次恢复；
4. 表面坑洼了点 Smooth 抹平；
5. 做砸了双指轻点撤销，底部历史记录能往回翻很多步。

"堆泥 → 减泥 → 抹平"这个循环跑顺了，雕塑的门槛就算迈过去了。想捏一个卡通头，先把这个循环练熟，再去碰工具箱里的其他家伙。

## 四、切中文界面

默认是英文界面，切换只要三下：点屏幕左上角的 Nomad 图标打开设置 → 找到 Language → 选 Chinese，界面文字立刻变中文。工具的中文标注与在线中文手册（nomadsculpt.com/manual/zh-hans）可以对照着查。

从零到捏出第一件作品，一台安卓设备就够了；安装包与更多介绍见 [Nomad 资源站](https://nomad.uerg.quest/)。练熟基础操作后，下一步是认识更多笔刷，见 [笔刷与雕刻技巧.md](笔刷与雕刻技巧.md)；做完想带出去打印或接进其他软件，见 [模型导出与格式选择.md](模型导出与格式选择.md)。
