# 笔刷与雕刻技巧

> 工具箱里二十来个工具怎么分组记忆、笔刷参数在哪里调、从球体起型的几条常用路子，本篇一次讲清。
> **相关文档**：[安卓3D雕刻入门.md](安卓3D雕刻入门.md) · [模型导出与格式选择.md](模型导出与格式选择.md)

## 一、按颜色记工具

右侧工具箱里的工具用颜色分了组，认组比一个个记名字快：

| 分组 | 代表工具 | 干什么 |
| --- | --- | --- |
| 笔刷类 | Clay、Brush、Smooth、Layer、Inflate、Nudge、Stamp | 表面加减体积、抹平、堆细节 |
| 移动类 | Move、Drag | 抓住一片区域整体拖动，调大形定比例 |
| 切割类 | Trim、Split、Project | 沿笔画轨迹切开、切掉、投平，像木工下刀 |
| 遮罩类 | Mask、Selection Mask | 圈住一块区域保护起来，只在别处动刀 |
| 绘画类 | Paint、Smudge | 上颜色、抹匀颜色 |
| 构造型 | Tube、Lathe、Insert、Gizmo | 用管状、旋转体、预设几何体快速起稿 |

新手最顺手的组合拳：Move 拉大形 → Clay 堆体积 → Crease 刻缝隙 → Smooth 收表面 → Mask 圈住局部精修。

## 二、参数在哪里调

选中任意笔刷后，左侧两枚滑块管半径（笔刷多大）与强度（一笔多重）。更细的设置在右上角第一个 Settings 图标里：

- **Stroke（笔划）**：半径口径有 Screen（按屏幕像素，缩放视角粗细不变）与 Constant 3D（按模型尺寸）两种；手抖就开懒人绳与笔划平滑。手指遮挡落笔点时，打开 Stroke Offset（笔划偏移），笔触会显示在手指前方——手机上值得常开；
- **Alpha**：灰度图当笔尖印章，皮肤纹理、鳞片全靠它；
- **Falloff（衰减）**：笔刷中心到边缘的力度曲线，决定笔触是圆润一坨还是硬边一块；
- **Pressure（压感）**：配压感笔时，笔尖力度映射到半径与强度。

另有两个高频开关：减泥模式 Sub 在左侧工具栏；对称的镜像平面在对称菜单里，旋转过物体后记得重新对准轴向。

## 三、起型的几条路子

1. **球体 + 局部细分**：最经典的路径，哪里要细节就在哪里加面；
2. **动态拓扑**：笔触经过之处网格自动加密，边塑边长细节，代价是面数涨得快；
3. **体素重拓扑（Voxel Remesh）**：一键重新布线，几块泥揉成一个整体，起大形阶段非常好用；
4. **多对象**：头、身体、配饰分开做，各自调整后合并；
5. **管状工具（Tube）**：手指、尾巴、绳子这类细长结构先拉管子再改截面，比从球里抠快得多。

## 四、设备与性能的现实

- 多数作品把面数控制在 50 万面以内，中端设备也能流畅刻；几百万面是新旗舰才玩得起的区间；
- 移动设备没有主动散热，长时间雕刻发热降频属正常现象，卡顿先想到这个；
- 保存或重拓扑时退出，基本是内存不足——合并图层、降面之后再操作。
