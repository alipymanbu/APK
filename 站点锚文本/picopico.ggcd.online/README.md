# PicoPico 语音社交站导航

PicoPico 是一款以声音为核心的社交 App：语音派对、甜蜜合拍、匹配雷达、说说广场都装在同一座"线上乐园"里。这个目录收录围绕它整理的介绍文章，帮助想入坑的人把玩法、体验和安装问题一次弄明白。

想直接看整理好的站点，可以从这里进：[PicoPico 乐园导览](https://picopico.ggcd.online/)。
