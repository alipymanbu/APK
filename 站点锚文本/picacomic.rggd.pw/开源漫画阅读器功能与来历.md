# PicaComic：一款开源的多源漫画阅读器，功能与来历一次说清

> 本篇讲 PicaComic 的定位、内置漫画源与核心能力，并交代这个项目的来路与现状。安装相关的内容写在 [安卓版获取与安装步骤](./安卓版获取与安装步骤.md)，进阶玩法见 [自定义源与 WebDAV 同步用法](./自定义源与WebDAV同步用法.md)。

---

PicaComic 是一个代码公开在 GitHub 上的漫画阅读应用，采用 MIT 许可，由 Flutter 构建——这意味着同一份代码可以覆盖 Android、iOS、Windows、macOS 与 Linux 多个平台，仓库里保留着各端的工程目录。

## 它解决什么问题

看漫画的人常遇到一个麻烦：想看的作品分散在不同的来源里，每个来源一个应用，翻找起来很碎。PicaComic 的思路是把多个漫画源装进同一个阅读器：

- 内置 picacg、E-Hentai / ExHentai、jmcomic、hitomi、nhentai 等多个漫画源，按入口切换，浏览与阅读的操作路径保持一致；
- 从 3.0.0 版本起，还能在应用内添加自定义漫画源（测试阶段），接入自己需要的接口。

## 阅读器本身可调的空间

比起单纯"能看"，它的设置项给得很细：

- 点按翻页（方向可反转）、音量键翻页、宽屏时显示控制按钮；
- 阅读模式可选，比如从左至右翻页；
- 图片预加载页数、自动翻页时间间隔都可调；
- 外观上支持主题切换与深色模式（可跟随系统），深色模式下还能单独降低图片亮度，高刷新率机型另有开关。

## 收藏、历史与同步

本地收藏和网络收藏分开管理，阅读历史有迹可循；换设备时，通过 WebDAV 把收藏与进度同步过去，具体做法记录在 [自定义源与 WebDAV 同步用法](./自定义源与WebDAV同步用法.md)。

## 来路与现状

这个项目最初围绕 picacg 展开，后来陆续接入其他来源，成长为多源聚合的阅读器。作者已在项目 README 标注进入维护收尾阶段，后续精力转向后继项目 Venera；4.0.4 作为成熟版本，目前仍被广泛使用。

想先看看它长什么样、再决定装不装，可以先到 [PicaComic](https://picacomic.rggd.pw/) 介绍站浏览功能截图与说明，再按 [安卓版获取与安装步骤](./安卓版获取与安装步骤.md) 动手。
