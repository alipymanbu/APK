# 歌单怎么从别的平台搬过来

> 本篇讲怎么用一条歌单分享链接，把攒在某个音乐平台里的歌单整单迁进聚合播放器，以及导入失败时先查什么。

## 一、搬家前的两个前提

歌单迁移靠的是**歌单分享链接**本身，所以动手前确认两件事：

1. 目标歌单在原平台处于**公开（或至少分享可见）**状态——私密歌单的链接拉不到内容；
2. 手机上已经装好聚合播放器（还没装的话，先照 [安卓手机从下载到安装的完整过程](安卓手机从下载到安装的完整过程.md) 走一遍安装）。

## 二、四步整单导入

以 Listen1 手机版为例，它的「网络导入」按链接拉取整份歌单：

1. **复制链接**：打开原来的音乐 App，找到目标歌单，进分享菜单选「复制链接」——各家分享菜单里都有这一项；
2. **新建歌单**：回到聚合播放器的「我的」页，点歌单区旁的加号；
3. **选网络导入、粘贴链接**：在新建界面里点「网络导入」，把刚复制的链接粘进去确认；
4. **等它拉完、抽几首核对**：整份歌单按歌曲条目拉进来，完成后随机点几首确认能正常播放。

歌单多的话，一份一份按这个流程走即可，顺序无所谓。

## 三、导入之后的三件事

- **导入的只是歌曲条目**：之后在原平台增删歌曲，两边不会再同步；日常的增删、收藏都应在新歌单里做；
- **原歌单可以先留着**：确认新歌单没问题、听了一阵子之后再删原平台里的也不迟；
- **顺手做一次备份**：搬完家的歌单是本地数据，进设置里导出一份备份文件存到网盘或电脑，之后换机、重装都有退路。恢复是覆盖式的——别拿旧备份盖掉新攒的内容。

## 四、导入失败，按这个顺序查

1. **链接复制全了吗**：分享链接往往很长，截断一个字符都拉不回来，重新完整复制一次；
2. **歌单是不是私密的**：把原歌单改成公开或分享可见再试；
3. **换首歌核对**：链接没问题、导入也成功，只是个别歌播不了——那是那首歌在来源侧暂时不可用，与迁移无关；
4. **确认原歌单还活着**：链接指向的歌单被删或失效，自然拉不回内容。
