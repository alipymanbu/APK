# 安卓手机从下载到安装的完整过程

> 本篇讲怎么把 Listen1 安卓手机版装进手机：从哪里拿安装包、怎么转存下载、系统拦下「未知来源」时怎么放行，以及两类最常见的安装失败怎么处理。

## 一、装机前先弄清两件事

1. **装的是哪条产品线**：Listen1 分浏览器插件、电脑桌面版、手机版三条线，本篇只针对**安卓手机版**——包体约 24M、Android 4.1 及以上可装，覆盖 arm64 等四种架构，新旧手机都不挑；
2. **手机版没有应用商店国内区上架**：安装走「拿安装包自己装」的路子，也就有了下面「未知来源」授权这一步。

## 二、从下载到打开，四步

1. **拿安装包**：安装包放在网盘分享里，转存到自己的网盘后下载到手机存储；手机上直接下，或电脑下载后数据线传到手机都行；
2. **点开 APK**：在文件管理器里找到下载好的安装包点开；
3. **放行「未知来源」**：第一次安装会弹「禁止安装未知来源应用」——点弹窗里的「设置」，把「允许此来源安装应用」打开，返回后继续。安卓 8 及以上按来源授权，只放行下载时用的那个渠道即可；
4. **打开试一首**：装完点「打开」，首页就是搜索栏，输个歌名验证能播就算装成了。

## 三、装不上时的两类高频问题

**提示「应用冲突」或「签名不一致」**
手机里装过别的渠道来的同包名版本，同包名不同签名不能共存。处理顺序：设置里导出歌单备份 → 卸载旧版本 → 装新包 → 用备份恢复。歌单和收藏都在手机本地，卸载即清空，**备份这步别跳**。

**提示存储空间不足**
清出比 24M 更多的余量再试，安装过程本身还需要额外空间；反复失败就重启一次手机再装。

## 四、装完之后

第一件事不是急着搬歌单，而是先确认「搜索 → 播放 → 红心收藏」这条最短路径在你机器上跑得通；跑通了再做两件事——把旧平台的歌单用链接整单导入（步骤见 [歌单怎么从别的平台搬过来](歌单怎么从别的平台搬过来.md)），以及在设置里导出第一份备份。

装好之后觉得「原来几个平台的歌能这么管」，想系统了解它的功能与边界，去 [listen1 的介绍页](https://listen1.wrwq.fun/) 翻一遍界面截图与功能盘点；要不要把它当主力播放器的判断，[多平台听歌为什么要用聚合播放器](多平台听歌为什么要用聚合播放器.md) 里写过适用的几类人。
