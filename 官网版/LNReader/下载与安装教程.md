## 一、安装前先确认这几点

LNReader 是一款开源的安卓轻小说阅读器，源码托管在 [GitHub（LNReader/lnreader）](https://github.com/LNReader/lnreader)，MIT 协议。官方 FAQ 写明应用不内置统计、追踪或广告，数据留在你设备上（除非自己启用外部备份或同步）。它本身不带任何书源，装好后需要自己添加书源插件才能搜书，这一步见[书源插件安装教程](书源插件安装教程.md)。

动手安装前，先对一遍下面这张表：

| 项目 | 内容 |
| --- | --- |
| 适用系统 | Android 6.0 及以上（官方 FAQ 口径；部分社区资料写 7.0+，以官方页面为准） |
| 安装包版本 | 2.1.0（2026-07 发布，官方后续仍有新版本） |
| 包名 | `com.rajarsheechatterjee.LNReader` |
| 安装包大小 | 48.72 MB |
| MD5 | `DB267F595E9DFFFF55FA126B4FF53A5A` |

截至 2026-09，官方已发布到 v2.1.4。先装好手上这份 2.1.0 完全能用，之后想升级按第五节走，书架数据不受影响。

## 二、从哪里获取安装包

获取渠道有这几个，按需选：

- **夸克网盘**：[LNReader 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2e92275313cf)就是 2.1.0 版的安装包，转存到自己网盘后即可下载到手机。
- **官方发布页**：[GitHub Releases](https://github.com/LNReader/lnreader/releases) 每次发版都会附上各架构的 APK，文件名形如 `LNReader-v版本号-arm64-v8a.apk`，以发布页实际列出的文件为准。
- **尝鲜构建**：官方文档提示，想提前用上未发布的功能可以去 GitHub 仓库的 Actions 页拿每日构建的 APK，稳定性不如正式版，日常使用建议选正式版。

不确定该下哪个文件的话，先看第四节的架构对照。

## 三、安装步骤

1. 把 APK 传到手机存储（网盘客户端直接下载、数据线拷贝都可以）。
2. 在文件管理器里点开 APK。系统会提示「不允许安装未知来源应用」，按提示给你所用的文件管理器或浏览器开「安装未知应用」权限。
3. 回到安装界面点「安装」，完成后在应用列表里找到 LNReader 打开。
4. 首次打开应用里什么都没有，先去添加书源插件：[书源插件安装教程.md](书源插件安装教程.md)。

安装时如果提示「应用未安装」，多半是架构不匹配或安装包下载不完整，换对应架构的包重新下载，必要时核对 MD5。

## 四、选哪个架构的 APK

官方发布页会同时给出多个 APK，按设备 CPU 架构选：

| 文件名里的标记 | 适合谁 |
| --- | --- |
| `arm64-v8a` | 近几年的绝大多数安卓手机，优先选它 |
| `armeabi-v7a` | 年头较早的老手机、老平板 |
| `x86` / `x86_64` | 电脑上的安卓模拟器、少数平板 |
| `universal` | 分不清架构时图省事的选择，包体更大 |

## 五、升级到新版本注意两件事

- **升级前先做备份**：进「设置 → Backup & Restore（备份与恢复）」生成一份备份文件，具体见[备份恢复与换机迁移.md](备份恢复与换机迁移.md)。
- **跨大版本升级**：官方文档明确提示，从低于 v2.0.3 的版本升级时要先装 v2.0.3 过渡，再升到更新版本。手上这份是 v2.1.0，直接覆盖安装最新版即可。

升级用的是同一个包名，覆盖安装后本机的书架和阅读进度都保留，但备份这一步不要省。
