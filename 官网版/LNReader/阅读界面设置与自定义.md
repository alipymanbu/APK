## 一、设置在哪进

阅读时点一下屏幕中央呼出菜单，里面有阅读设置入口；全局偏好也在主界面的「设置」里。改动即时生效，不需要额外保存。菜单名称以你设置的界面语言为准，下文按常见叫法描述。

## 二、把排版调到顺眼

- **字体与字号**：可以换字体、调字号，行距单独调。默认字体对中文支持一般的话，换一个你系统里可用的中文字体往往立竿见影。
- **全局还是单本生效**：排版设置可以全局套用；不同源的书排版差异大，也可以只对某一本书单独调。
- **翻页方向**：上下滚动和左右翻页两种，选习惯的。

## 三、主题与背景

内置多套主题，也可以自己配色：背景色、正文色、强调色分开选。夜里看用深色背景，白天看反着来。还有沉浸模式，把状态栏等界面元素收起来，屏幕全部留给正文。

## 四、手势

点按翻页、滑动调节这类手势可以在设置里改。具体能改哪些项、默认是什么，以你版本里的手势设置页为准，不同版本略有出入。

## 五、用朗读把书「听」完

设置里有 TTS 朗读（文字转语音），走系统自带的语音引擎。朗读没声音时先查系统侧：

1. 系统设置里的 TTS 引擎能否正常预览发声；
2. 对应语言的语音包是否已下载；
3. 换一个系统 TTS 引擎再试。

断句或标点处理不理想的情况，先更新到新版本再看，这类修复在更新日志里出现过。

## 六、进阶：自定义 CSS 与 JS

阅读界面支持自定义 CSS 和 JS 脚本，入口在「设置 → Reader → Advanced」，改动重新打开章节后生效。首行缩进、标题配色、隐藏滚动条这类可直接抄的示例整理在[自定义CSS调整阅读排版.md](自定义CSS调整阅读排版.md)；官方原文见 [Custom CSS & JS](https://www.lnreader.app/docs/custom-css-js)。普通读者用第二节和第三节就够，不用碰这层。

排版之外的使用问题汇总在[常见问题排查.md](常见问题排查.md)。
