# CHEMIST 常见问题排查

> 本篇汇总装不上、打不开、实验里现象异常这几类最常碰到的问题，先判断问题出在哪个环节，再按对应小节处理。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [实验操作入门.md](实验操作入门.md) · [设置项与实验报告.md](设置项与实验报告.md)

---

CHEMIST 是一款上线多年的应用，问题集中在两头：安装环节卡在系统权限与包文件本身，使用环节则多半是「容器怎么突然没了」「试剂怎么找不到了」这类规则没对上的情况。先按现象对号入座。

## 一、安装环节的问题

**提示「无法解析安装包」或安装到一半失败：**

1. 先核对文件完整性：算一下 APK 的 MD5，与 [下载与安装教程.md](下载与安装教程.md) 里列的值比对，不一致就重新下载——传输中断导致的坏包是这类提示最常见的原因；
2. 确认存储空间充足，安装包本身 22.91M，但安装过程需要额外的解压空间；
3. 换一个文件管理器或浏览器重新打开 APK，权限授予对象会跟着变。

**装是装上了，但发现功能和别人说的不一样：**先在「设置 → 应用」里核对包名是不是 `air.thix.sciencesense.chemist`。官方历史上同时存在完整版与免费试用版，包名不同、功能范围不同，版本对不上，讨论的现象自然对不上。

## 二、启动闪退或黑屏

这款应用的安卓版本发布时间较早，在新版安卓系统上兼容性不如新应用，启动异常时按这个顺序试：

1. 重启手机后再开一次；
2. 「设置 → 应用 → CHEMIST → 存储」，清缓存后重试；
3. 清缓存无效就卸载重装（重装会清掉应用在本地的数据，重要现象先截图）；
4. 仍不行，换一台系统版本更老的设备或平板试试——它本身就是按平板场景设计的。

## 三、实验里的「异常」，多数是规则

**容器或物质凭空消失：**两种可能，都不是 bug——超出了容器容积上限，多出的部分会被自动移除；或者温度超过了容器耐热上限（普通容器 900°C），容器炸掉了。参数表见 [器材用法与加热操作.md](器材用法与加热操作.md)。

**反应把界面炸得一塌糊涂：**爆炸性反应、超温都会真炸。只想看产物的话，到设置里把爆炸开关关掉，入口和各设置项见 [设置项与实验报告.md](设置项与实验报告.md)。

**试剂库里找不到昨天用过的试剂：**试剂分类跟着实验室温度走，改过温度后物态变了、分类也跟着变（比如高温下水归入气体类）。回设置里确认当前实验室温度，或想想这种试剂在当前温度下是什么物态。

**Label 数值显示 `<0.1` 或 `-`：**`<0.1` 表示值大于 0 但不足 0.1；`-` 表示该物态不适用这个属性（对固体问摩尔浓度就是这样），不是出错。

**瓶子上方有小圆点：**CloudLab 联网补充的新增试剂标记，不影响使用。

## 四、还解决不了

官方渠道两条：官网 [thix.co](http://thix.co)，支持邮箱 [support@thixlab.com](mailto:support@thixlab.com)。操作类的问题先翻一遍 [实验操作入门.md](实验操作入门.md)，多数「以为坏了」的情况其实是手势不对。
