CHEMIST 是 THIX 出品的虚拟化学实验室应用，在手机或平板上模拟倒试剂、加热、搅拌等实验操作，适合化学课预习复习、以及想在零风险环境里随便折腾反应的人。国内的应用商店里不容易搜到它的安装入口，通过安装包安装是最常见的方式，本篇按「核对信息 → 拿包 → 安装 → 验证」的顺序讲一遍。

## 一、安装前先核对这几项

下面是这份安装包的本地实测信息，装完后可以拿来对号：

| 项目 | 值 |
| --- | --- |
| 版本 | 5.0.4 |
| 包名 | `air.thix.sciencesense.chemist` |
| 安装包大小 | 22.91M |
| MD5 | 5DC93BF971E63CB25DB2D8F16745EE68 |

两个用途：

- **包名**是应用的唯一身份。装完后在「设置 → 应用」里找到 CHEMIST，进应用信息能看到包名，对得上就说明装的是这份包，而不是名字相近的别的应用（官方历史上同时存在完整版和免费试用版，包名不同，功能范围也不同）；
- **MD5** 用来确认文件没在传输中损坏。会算的话，装不上时先算一遍 MD5 和上表比对，不一致就重新下载。

版本背景也交代一下：这款应用的安卓 5.0 版本线在 2017 年初发布（5.0 → 5.0.1 → 后续修订），官方更新记录显示 iOS 渠道后来走到了 5.2（2021 年初）；上面这份 5.0.4 属于安卓 5.0 线的修订版。看到「官网版本更新了」和手里这份对不上，是正常现象，不影响安装使用。

## 二、获取安装文件资源

安装包从夸克网盘取：[CHEMIST 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f27db9d10ce7)。

1. 打开上面的链接，选择转存到自己的网盘（夸克网盘的分享文件需要先转存才能稳定下载）；
2. 在网盘里找到 APK 文件，下载到手机存储；
3. 记住下载位置，一般浏览器的下载目录或夸克 App 自己的下载目录都行。

## 三、安装步骤

1. 在文件管理器里点刚下载的 APK 文件；
2. 系统会弹出「不允许安装未知来源应用」之类的提示，点提示里的设置项，允许**浏览器或文件管理器**「安装未知应用」——这个权限只授予你用来点开 APK 的那个 App，不用全局放开；
3. 回到安装界面，点「安装」，等进度条走完；
4. 点「打开」直接进入，或回桌面点图标启动。

启动后第一屏是实验桌面和顶部的三个入口按钮，怎么上手看 [实验操作入门.md](实验操作入门.md)。

## 四、装不上或打不开

按出现的位置分两种情况：

- **安装环节失败**（提示解析失败、未安装成功）：先核对 MD5 排除文件损坏，再确认手机存储够用（安装包 22.91M，加上安装空间留出几百兆比较稳妥）。老应用的安装包在新版安卓上偶尔会遇到兼容拦截，多试一次或换一个文件管理器打开。
- **装上了但启动异常**：这是另一类问题，处理思路不同，直接看 [常见问题排查.md](常见问题排查.md)。

## 五、其他平台的情况

不装安卓包也有别的入口，按设备分：

- **iPhone / iPad**：App Store 里搜「化学家 - CHEMIST」，中国区标价 ¥58（截至检索时，以商店页面为准），支持包括中文在内的 13 种语言，内容与安卓版同一套玩法，版本比安卓线更新；
- **安卓**：第三方收录的官方更新记录显示，安卓渠道多年没有新版本，安装包是目前最现实的获取方式，也就是本篇讲的路子。

两个平台的操作完全一致，本套文档其他各篇（[实验操作入门.md](实验操作入门.md) 等）对 iOS 用户同样适用。
