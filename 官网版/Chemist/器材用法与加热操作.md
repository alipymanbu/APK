# CHEMIST 器材用法与加热要点

> 本篇把 17 件器材一次讲全：每种容器能装多少、耐热多少，怎么组装加热，过滤、盖盖、导管连接分别怎么做，以及什么情况下容器会炸。

做实验最常见的两个翻车点都和器材参数有关：一是加热时温度超过容器耐热直接炸掉，二是倒液超了容积不知道东西去哪了。先把这张清单过一遍，后面分组讲操作。

## 一、17 件器材清单

器材库共 17 件，其中 10 件是容器、7 件是支撑与辅助件：

| 类别 | 器材 | 说明 |
| --- | --- | --- |
| 容器 | 50mL 试管 | 小剂量反应 |
| 容器 | 100mL / 250mL 烧杯 | 最常用的敞口容器 |
| 容器 | 100mL / 250mL 锥形瓶 | 敞口，颈细液面稳 |
| 容器 | 100mL / 250mL 烧瓶（boiler） | 唯一耐热上限更高的一档 |
| 容器 | 250mL 集气瓶 | 收集气体用 |
| 容器 | 表面皿、蒸发皿 | 浅口，不能接导管 |

## 二、容器都有两条命门：耐热和容积

- **耐热上限**：除两种烧瓶（boiler）能扛到 1200°C 外，其余容器都是 900°C。加热温度超过上限，容器会炸——这是「实验做到一半突然爆了」的第一大原因。
- **容积上限**：任何时刻超出容器最大容积的物质会被**自动移除**（不是溢出来，是直接消失），腾出的空间会由实验室空气里的气体回填。所以别指望把 300mL 水倒进 250mL 烧杯再留「多出来的一点」观察，那部分已经没了。

## 三、加热的两种搭法

- **铁架台搭法（温度可调）**：容器放在铁圈上，灯放在底座上。上下移动铁圈的高度，就能改变加热温度——圈离火越近温度越高。需要控温的反应用这种。
- **三脚架搭法（火力全开）**：灯放三脚架下面，容器直接架在三脚架顶上，加热温度就是灯具的最高温度（本生灯 900°C、酒精灯 400°C）。

想让反应快点达到目标温度，选本生灯；只想温和加热（比如 400°C 以内），酒精灯就够。点燃灯具用工具菜单里的火柴。

## 四、过滤、盖子和导管

- **过滤**：把滤纸放在铁架台的铁圈上，滤纸上再立一个容器，就能过滤混合物。
- **盖子**：把盖子拖到容器口盖上，能阻止气体跑出去——收集气体、观察气体生成量时必用。盖子顶端会出现一个红叉，点红叉开盖。
- **导管**：先把导管的一端拖到容器 A，再把另一端拖到容器 B，两个容器就连通了，气体可以顺着管子过去；点导管中间的红叉拆除。**注意有四类容器接不了导管**：100mL 和 250mL 烧杯、表面皿、蒸发皿，要连通它们只能靠倾倒。

## 五、想炸而不炸：爆炸开关

两类情况会触发爆炸：反应本身是爆炸性的，或容器温度超过耐热上限。如果你只是想观察爆炸性反应的产物而不想屏幕一黑，去设置里把爆炸开关关掉，反应照常进行、只是不炸。开关位置和其他实验室参数（温度、时间、气体成分）一起放在 [设置项与实验报告.md](设置项与实验报告.md) 里讲。

器材里最难一次到位的是「铁架台 + 铁圈 + 滤纸」这套过滤组合，第一次搭不成功很正常，回 [实验操作入门.md](实验操作入门.md) 复习一下拖放手势再试。试剂选择有疑问的，去 [试剂库与信息查询.md](试剂库与信息查询.md) 查试剂信息卡。
