# CHEMIST 实验工具用法与 Label 数据标签

> 本篇讲六件工具各自怎么用（重点是最难上手的滴管和用途最多的火柴），以及 Label 标签功能怎么把容器里的实时数据读出来。
> **相关文档**：[实验操作入门.md](实验操作入门.md) · [器材用法与加热操作.md](器材用法与加热操作.md) · [设置项与实验报告.md](设置项与实验报告.md)

---

工具都不重，但每件都有固定手势，特别是滴管「按住—上滑—下滑」这套动作，不看说明基本摸索不出来。先给一张速查表，再单独讲两件最常用的。

## 一、六件工具速查

| 工具 | 拖到容器上做什么 |
| --- | --- |
| pH 试纸 | 读出容器内溶液的 pH 值 |
| 温度计 | 读出容器内物质的平均温度（摄氏度） |
| 玻璃棒 | 搅拌：加快反应速率、加快温度变化和变色 |
| 胶头滴管 | 转移 5mL 以内的小剂量液体 |
| 火柴 | 点燃药品或灯具、检验气体 |
| 冰冻魔杖 | 和火柴相反，把容器内物质降温冷冻 |

拖放方式统一：点右边按钮打开工具菜单，把工具拖到目标容器上。多指可以同时操作多件工具，具体见 [实验操作入门.md](实验操作入门.md)。

## 二、滴管：按住、上滑吸液、下滑滴液

滴管一次最多取 5mL，适合「加几滴就行」的场景（比如往溶液里滴指示剂类试剂）。手法四步：

1. 把滴管拖到源容器上，**按住不放**，容器上会出现一个小圆球标记；
2. 手指沿滴管**向上**滑动，圆球逐渐充满，充满时会有晃动提示——这一步是从源容器吸液；
3. 手指移到目标容器上，圆球再次出现；
4. 沿滴管**向下滑动**，圆球变空，液体滴进目标容器。

吸多了想少放点？没有半放模式，一次就是一整球，所以上滑时到充满就停，别贪量。

## 三、火柴的三种用途

1. **点火**：点燃可燃物，或者点亮酒精灯、本生灯（加热搭法见 [器材用法与加热操作.md](器材用法与加热操作.md)）。把火柴拖到灯上按住即可；
2. **持续灼烧**：按住不放期间，火柴会一直灼烧容器里的物质，松手就灭；
3. **验气**：这是它的隐藏用法——把火柴拖向装满气体的容器，看火柴的反应来判断气体成分：
   - 纯氧：火柴**复燃窜起火苗**；
   - 无氧环境：火柴**直接熄灭**；
   - 氢氧混合气：出现**火花**（别在开着爆炸开关时试这个）。

用火柴验气比用 Label 看成分直观，是检查「我的集气瓶到底集到没有」的最快办法。

## 四、Label：把数字挂在每个容器上

右下角有一个小矩形按钮，点开就是 Label 功能。选定想看的属性后，每个容器上方会实时挂出化学名称和对应数值，不用一件件把工具拖过去。

**能显示的五种属性**：质量（g）、体积（cm³）、物质的量（mol）、温度（°C）、摩尔浓度（mol/L）。

**文字颜色代表物态**：

| 颜色 | 含义 |
| --- | --- |
| 白色 | 固体 |
| 蓝色 | 液体 |
| 灰色 | 气体 |
| 粉色 | 溶于水的溶质 |

**读数规则**：数值四舍五入到 0.1。看到 `<0.1` 表示这个值大于 0 但小于 0.1（不是没有）；看到 `-` 表示这种物态不适用该属性（比如对固体问摩尔浓度）。

做滴定这类需要盯着浓度变化的实验，Label 开着摩尔浓度一栏比反复用 pH 试纸方便；等实验做完，设置里的实验报告会把整场的反应方程式列出来，见 [设置项与实验报告.md](设置项与实验报告.md)。
