## 一、先说结论

PP体育 客户端里看比赛的路径很固定：首页/赛程里找到场次 → 点进直播间 → 开播后调画质、解说、投屏；错过直播就去回放或集锦。**但有一场比赛在哪能看，取决于版权在谁手里** —— 同一赛季不同联赛的直播权可能分属不同平台，PP体育 官网 [www.ppsports.com](https://www.ppsports.com) 的赛程页才是你判断「今晚这场有没有」的权威入口。

## 二、找到你想看的场次

1. 打开 App，首页顶部就是当日赛程；也可以从导航栏进入具体赛事频道（官网导航上能看到的口径包括中超、英超、西甲、意甲、欧冠、德甲、法甲、欧联、NBA、亚冠、中国篮球等栏目）。
2. 每场比赛的卡片会标开赛时间、对阵双方、是直播还是图文/回放。开赛前点进去一般可以收藏或预约提醒，入口以页面当时显示为准。
3. 想按联赛整体看，用赛程页（[ppsports.com 的 schedules 页](https://www.ppsports.com/schedules)）按赛事筛选，比在首页里翻快。

**判断这场能不能在 PP体育 看**：进直播间若显示需要跳转或提示版权受限，说明这场的直播权不在 PP体育 这边，别在这儿干等——换到持有该场版权的平台看。赛季中途版权归属会变，以场次页面当时显示为准。

## 三、直播间里你会用到的操作

| 你想做什么 | 怎么操作 |
| --- | --- |
| 调清晰度 | 播放页的画质按钮（标清/高清/超清等档位按页面实际显示）；网络差先降一档 |
| 换解说/视角 | 直播间里的「解说」「视角」类切换项，有多个源才显示 |
| 看数据、阵容 | 直播间下方的数据页签（比分、控球、射门等实时数据） |
| 全屏 | 点全屏按钮或旋转手机 |
| 投到电视 | 播放页找投屏按钮，选中同一 Wi-Fi 下的电视或盒子 |

几个实用点：

- **画质不是越高越好**：手机流量下开超清容易卡顿转圈，先把画质降一档，比反复缓冲省时间。
- **投屏的前提是同网**：手机和电视/盒子必须连同一个 Wi-Fi；投屏失败的排查见[那篇](黑屏闪退打不开的排查.md)。
- **直播卡顿时**先切低画质，再考虑换网络；持续卡顿通常是本地网络或该场次线路问题，与你账号无关。

## 四、错过直播怎么看回放

1. 赛后回到该场比赛的详情页，通常有「回放 / 集锦 / 录像」入口，点开即看。
2. 找不到入口多半是版权方只放出集锦、或该场次回放已下架——这是内容策略，不是你的操作问题。
3. 直播入口没有的场次，官网 [www.ppsports.com](https://www.ppsports.com) 的新闻与视频栏目（`/article/` 下的图文报道与短视频）往往还有集锦和赛后内容，可以当回放的替代——它不是全场录像，但比分、关键球、赛后反应都能看到。
4. 想长期留着某场，赛后趁还在有效期缓存到本地（播放页的缓存/下载按钮），比指望一直在线回看可靠。

**回放和集锦的可看时长由版权方规定**，各联赛不一致且会变，别默认「永远能看」，重要的比赛建议赛后尽快看或缓存。

## 五、会员与免费内容的边界

直播、回放里你可能碰到三种情况：完全免费、需要会员、需要单独的赛事/场次权益。区别在于：

- 免费场次直接点开就播；
- 会员场次会提示开通，开通方式与**连续包月的退订路径**见[会员那篇](会员开通与自动续费关闭.md)——尤其看清默认勾选的是不是自动续费；
- 少数赛事（如部分格斗赛事）有独立的会员包，价格与权益以购买页当时显示为准。

不想付费就先看免费场次与资讯栏目；PP体育 里还有 7×24 的体育新闻、图文集锦和自制节目，不涉及会员也能刷。

## 六、看直播前的快速检查

1. 账号已登录（会员权益和预约提醒都跟着账号走）；
2. 赛程页确认这场在 PP体育 有直播；
3. 画质先设成与网络匹配的档位；
4. 想投屏就确认手机和电视同一 Wi-Fi。

开播后仍黑屏、无声、闪退的，直接转[黑屏闪退打不开的排查.md](黑屏闪退打不开的排查.md)。
