## 一、直播黑屏 / 一直转圈 / 有声无画

按顺序试，哪步好了就停：

1. **先降画质**：播放页把清晰度调低一档。多数「转圈」是当前网络撑不住高清码率。
2. **换网络对比**：Wi-Fi 和流量各试一次。只有某个网络不行 → 问题在本地网络；都不行 → 可能是该场次线路问题，退出直播间重进，或稍后再试。
3. **退出重进 + 重启 App**：直播间加载失败是常见瞬时故障，杀掉 App 重开比一直等有效。
4. **确认这场真在 PP体育 有版权**：黑屏也可能是该场次本就不在本平台播出，回[赛程页](https://www.ppsports.com/schedules)核对（详见[直播那篇](怎么看比赛直播和回放.md)）。
5. **会员场次没登录/权益过期**：页面会提示而非纯黑屏；登录对的账号，权益问题见[会员那篇](会员开通与自动续费关闭.md)。

## 二、App 打不开 / 闪退 / 安装失败

| 现象 | 处理 |
| --- | --- |
| 点图标闪一下就退 | 手机剩余空间不足（安装包 148.97M，安装解压需要更多），先清理存储再重装 |
| 安装时提示「解析包错误」 | 下载的包不完整，重新下一次；下完可核对 MD5 是否为 `37b0669aa2969e906f071efa9b491107`（对应版本 8.1.6 那份） |
| 覆盖安装提示签名冲突 | 先卸载旧版再装（收藏、会员跟账号走，卸载不丢） |
| 提示「禁止安装来自此来源」 | 对下载来源单独授权（见[安装教程](下载与安装教程.md)第三节） |
| 打开就卡死 | 设置 → 应用 → PP体育 → 清除缓存；还不行再清数据（清数据会退出登录，会员权益不丢） |
| 老机型装不上 | 应用商店会按系统版本判兼容；过旧的系统可能确实跑不动新版，先升级系统再试 |

## 三、登录不上 / 记录丢了

1. 确认手机号没换、验证码收不到就检查短信拦截；
2. 收藏、观看记录**跟账号走**，先退出再用同一账号登录一次，通常就同步回来了；
3. 换了手机号的老账号登不上，走 App 内的账号申诉/客服通道（电话见下）。

## 四、投屏连不上电视

1. 手机和电视/盒子**必须在同一个 Wi-Fi**，有一边走了流量或访客网络就搜不到设备；
2. 部分电视需要先打开自带的投屏/接收功能；
3. 搜得到但没画面：电视端断开重连一次，或改用电视自带的应用商店搜该平台客户端（若提供）。
