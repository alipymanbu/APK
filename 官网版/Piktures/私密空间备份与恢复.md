## 一、先记住这条硬规则

官方帮助原话的意思是：私密空间存在 Piktures 应用专属的存储里，**删除 Piktures，私密空间就没了**，而且官方明确说明团队没有任何途径替你恢复里面的文件 —— 没有云端备份，也没有后台副本。

这是 Android 11 引入分区存储（Scoped Storage）之后的刻意设计：私密空间藏进应用专属目录后，其他应用（包括各种「清理大师」）碰不到它，安全性确实提高了；代价是它和应用的存亡绑在一起。所以**卸载、重置手机、换机之前，必须先做备份**。私密空间的日常用法见 [私密空间与隐私保护.md](私密空间与隐私保护.md)。

## 二、卸载前：用应用内的导出功能

Piktures 自带私密空间导出：

1. 进私密空间，找到导出（Export）入口；
2. 选一个手机本地的普通文件夹作为去处；
3. 导出完成后，用文件管理器确认照片真的到了目标文件夹，再动手卸载。

导出的是**解密后的普通照片**，之后你想重新启用私密空间，再从相册里移回去即可。

## 三、重置／换手机前：整包备份 .Piktures 文件夹

私密空间的数据在设备上一个以 `.Piktures` 开头的文件夹里，结构是：

```text
.Piktures/
├── d1.dat        ← 加密的账户信息（恢复通行证的载体）
├── 02/           ← 照片按编号子文件夹存放
├── 15/
└── …
```

官方给出的恢复流程：

1. 把整个 `.Piktures` 文件夹**完整复制**到 SD 卡或电脑（`.nomedia` 这类隐藏文件别漏）；
2. 重置手机／在新手机上安装 Piktures；
3. 把文件夹放回**原来的位置**；
4. 重新打开应用，它会检测到这个文件夹，提示你输入**之前的邮箱地址和 PIN 码**；
5. 输入正确，私密空间连同照片一起回来。

两个前提缺一不可：`.Piktures` 文件夹要完整（照片都在编号子文件夹里，`d1.dat` 是账户信息），以及**当年的邮箱 + PIN 还记得**。恢复路上的其他坑见 [常见问题排查.md](常见问题排查.md)。

## 四、注册邮箱的验证坑

启用新版私密空间时要验证邮箱，官方明确提示过的两个坑：

- **非 Gmail 邮箱容易出问题**：验证流程对 Gmail 之外的手机邮箱（如 Outlook）兼容性差；
- **别用 Firefox 打开验证链接**：官方说明 Firefox 不支持 Piktures 的私密链接，点了没反应 —— 换 Chrome 或 Brave 打开。

验证邮箱建议用手机上登录着 Gmail 的环境一次做完，别拖到要恢复的时候才发现邮箱没绑成。

## 五、恢复的边界在哪

| 手里有什么 | 能恢复什么 |
| --- | --- |
| 完整的 `.Piktures` 文件夹 + 旧邮箱 + 旧 PIN | 照片全部回来 |
| 只有旧邮箱 + 旧 PIN | 能证明身份，但照片本体在丢失的文件夹里，无解 |
| 导出过的普通照片 | 已经是解密照片，直接用，不需要恢复流程 |

一句话：私密空间的保险只有一道 —— **你自己提前备份**。这项工作没有替代品，官方团队帮不上忙。
