## 一、它解决的问题是「照片散在五六个地方」

照片分散在不同位置是常态：手机本机一份、SD 卡一份、网盘若干份、电脑硬盘里还有历史存档。Piktures 的主打能力就是把这些来源**接进同一个相册**浏览，官方页面与商店介绍里列出的来源包括：

| 来源类型 | 具体服务／要求 |
| --- | --- |
| 公有云盘 | Google Drive、OneDrive、Dropbox、Box、pCloud 等 |
| 个人云 | 支持 WebDAV 的服务、Nextcloud 服务器 |
| 电脑 | Piktures Media Server（Mac / Windows / Linux 客户端） |
| USB 外设 | U 盘或读卡器，**要求 FAT32 格式** |
| 本机与 SD 卡 | 装好后自动扫描 |

各版本实际支持的服务可能有出入，以你手机上「添加来源」界面列出的清单为准。

## 二、连接云盘账号的通用步骤

各家云盘的接入流程基本一致：

1. 在侧边面板或设置里找到云服务／添加账号入口；
2. 选择服务（如 Google Drive），跳转到对应登录页授权；
3. 授权完成后，该账号的照片目录就会出现在相册列表里，与本机照片同屏浏览。

两点提醒：授权是**你自己的云盘账号**对应用开放，Piktures 声明不把你的照片数据传到它自己的服务器；另一个是硬数字 —— **免费版最多挂 2 个云盘接入点**，再多就要高级版（官方付费功能说明里的明确数字），见本文最后一节。

## 三、WebDAV 与 Nextcloud：自己搭的云也能接

如果你用 Nextcloud、群晖等自建网盘，走 **WebDAV** 协议接入：

1. 在服务的网页管理端确认 WebDAV 地址与账号（Nextcloud 一般形如 `https://你的域名/remote.php/webdav/`）；
2. 在 Piktures 里选 WebDAV／Nextcloud 来源，填地址、账号、密码；
3. 连接成功后，自建云里的照片和其他云盘一样出现在相册里。

几个官方说明过的实际能力：通过 WebDAV 不只是「看」—— **上传、下载、管理**照片都行；Box、pCloud、Yandex 这几家本身原生支持 WebDAV，Piktures 就是走这个协议连它们的；群晖（Synology）这类 NAS 设备也可以按同样的方式接进来。

对不想把照片放在公有云的人来说，这条路线是「手机相册 + 私有云」的关键一环；隐私方面的其他口径见 [私密空间与隐私保护.md](私密空间与隐私保护.md)。

## 四、连电脑：Piktures Media Server

电脑端的 **Piktures Media Server** 有 Mac、Windows、Linux 三个版本，装好后手机与电脑在同一局域网内即可互看：

1. 在电脑上从官方下载渠道安装：Windows 是 `.msi` 安装包，Mac 分 Apple Silicon（M 系列）与 Intel 两种 `.pkg`（下载地址见官方帮助中心的 Media Server 章节，[help.piktures.app](https://help.piktures.app)）；
2. 配置四样东西：**显示名称、登录账号与密码、监听端口、共享文件夹位置** —— 手机端连的就是这套信息；
3. 手机端添加「电脑」来源，按同样的账号密码连上；
4. 电脑硬盘里的照片、电影都能在手机上直接浏览播放。

两个 Windows 用户容易忽略的点：**首次运行要在防火墙里允许它在「专用网络」通信**，否则手机连不上；想让电视盒子随叫随到，把它加进 Windows 的开机自启（官方帮助里也是这么建议的）。

它走的是局域网直连，不经过外部服务器；出门在外连不上同一网络时，这个通道自然就断了。

## 五、U 盘与读卡器：认准 FAT32

相机卡插读卡器、U 盘直连手机（OTG）都可以被 Piktures 直接读取，但官方明确要求 **FAT32 文件系统**。exFAT 或 NTFS 格式的盘读不到时，把盘格式化成 FAT32（注意会清空数据，先备份）再试。拍完照把相机卡插到手机上挑片发朋友圈，是最顺手的用法。

## 六、免费版与高级版的差别在哪

免费版功能已经完整，高级版（Premium）按官方付费功能说明主要补这几块：

| 能力 | 免费版 | 高级版 |
| --- | --- | --- |
| 基本相册、编辑、私密空间 | 有 | 有 |
| 云盘接入点数量 | **最多 2 个** | 不限 |
| 自建标签（给照片打自己的标签） | — | 支持 |
| 视图自定义 | 基础选项 | 完整自定义 |

官方还预告过后续版本会给高级版加云盘 PIN 锁、选择性同步文件夹、私密空间放 SD 卡等能力（以实际更新为准）。

要不要升级只看一件事：**你是否真的有超过 2 个云盘接入点要同时挂**。只用一个云盘加一台电脑的用户，免费版就能跑完日常流程。来源连接过程中遇到装不上、打不开的情况，先回 [下载与安装教程.md](下载与安装教程.md) 核对安装包版本与 MD5。
