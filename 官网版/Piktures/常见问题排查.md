# Piktures 常见问题排查

> 本篇收的是「装好了但表现不对劲」的几类高频问题：缓存文件夹刷屏、相册改名不生效、删除报错、照片不显示。

## 一、列表里一大堆缓存文件夹

装好后相册列表乱、缓存图刷屏，多数是 `/sdcard/Android/data` 这个目录在捣乱 —— 各应用的缓存图片都堆在那。这里有个多数人不知道的机制：安卓约定目录里放一个 `.nomedia` 空文件，相册类应用就会跳过这个目录。Piktures 总体遵守这个约定，但官方说明了**两个例外**：

- 根目录 `/` 下的 `.nomedia` 不生效（否则一张文件就能让全机照片消失）；
- `/sdcard/Android/data` 目录的 `.nomedia` 不生效（那里全是各应用的资源目录，遵守的话反而会漏掉大量正常照片）。

所以缓存目录不会自己消失，要**手动排除**：

1. 进设置 → FOLDERS → Manage Exclude folders（管理排除文件夹）；
2. 把 `/sdcard/Android/data` 加入排除；
3. 回到相册列表刷新，缓存目录就没了。

操作入口的完整说明见 [界面与相册管理.md](界面与相册管理.md) 第五节。

## 二、相册改了名，文件夹名字没变

在 Piktures 里给相册改名，改的只是**应用内显示的名字**，磁盘上的真实文件夹不会跟着改名 —— 官方帮助里专门列了这一条。反过来也一样：你在文件管理器里重命名文件夹，相册列表里的名字可能仍显示旧的。

要动真实文件夹名，去文件管理器操作；只想让列表好看，用应用内的改名就行。两套名字各管各的，别指望同步。

## 三、删除文件时弹错误

删除报错时，官方说明的原因是 **Android 系统拦截了文件操作**，常见于这几种情况：

| 情形 | 处理方向 |
| --- | --- |
| SD 卡上的照片删不掉 | 检查 SD 卡是否处于只读／写保护状态，或重新挂载 |
| 系统弹窗没确认 | 部分系统对删除/写入要逐次确认，弹窗被拒就会报错 |
| 回收站清理失败 | 重进回收站再清一次；仍失败就重启手机重试 |

删除功能与回收站的日常用法见 [界面与相册管理.md](界面与相册管理.md) 第六节。

## 四、拍了照片却不显示

按这个顺序查：

1. **权限**：系统「设置 → 应用 → Piktures → 权限」，确认照片／存储权限是允许状态。Android 13+ 是「照片和视频」权限，如果你选过「仅允许部分照片」，新照片不在授权列表里就不显示 —— 改成允许全部；
2. **`.nomedia`**：照片所在文件夹里若被某个应用塞了 `.nomedia` 文件，Piktures 会遵守约定不显示它（第一节说的两个例外除外）。用文件管理器打开「显示隐藏文件」，删掉那个文件即可；
3. **媒体库未刷新**：刚拍的照片有延迟属正常，重启手机会强制媒体库重扫；
4. **照片真的在别处**：用文件管理器确认照片本体还在，别把「应用不显示」误判成「文件丢了」。

## 五、还解决不了时

官方帮助中心在 [help.piktures.app](https://help.piktures.app)，常见问题都在上面；应用内还有调试模式（Debug mode），遇到反复出现的故障可以在里面开启，把日志交给开发者排查。私密空间相关的问题先看 [私密空间备份与恢复.md](私密空间备份与恢复.md) —— 那一类的操作窗口期短，优先级高于普通故障。
