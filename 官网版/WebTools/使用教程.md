## 一、先搞清楚它能帮你做什么

Web Tools 把「连服务器、测网站」这两类事装进了一个手机应用。你不用开电脑，在手机上就能完成上传文件、登服务器敲命令、看接口返回、测网速这些操作。

| 你想做的事 | 用哪个工具 |
| --- | --- |
| 上传、下载服务器上的文件 | FTP / SFTP 客户端 |
| 登录服务器执行命令 | SSH 客户端 |
| 快速摸一下老服务器的资源 | Telnet 客户端 |
| 看某个网址返回了什么、响应多快 | HTTP 测试 |
| 调试 JSON / XML 接口 | REST API 测试 |
| 测当前网络的上下行速度 | 速度测试 |
| 看某个 IP 通不通 | 可达性检查 |
| 改几行网页代码、查语法错误 | 代码编辑器 |
| 服务器出问题时第一时间知道 | 站点监控 |

## 二、第一次打开：把站点加进来

打开应用后，主界面就是你的站点与工具入口。第一次使用先添加你要管理的网站：

1. 点主界面右下角的「+」号；
2. 在弹出的输入框里填入你要管理的网站地址；
3. 保存后，这个站点就会出现在列表里，后续的测试、监控都围绕它进行。

要连接自己的服务器（FTP/SSH），需要的服务器地址、端口、账号密码信息见[FTP与SSH连接服务器教程.md](FTP与SSH连接服务器教程.md)。

## 三、日常最常用的三条路径

- **改完代码查一眼**：用代码编辑器改或粘贴代码，查语法错误，再用 HTTP 测试请求一下线上地址，确认改动生效；
- **发版前后抽查**：用 HTTP 测试看状态码与响应时间，REST API 测试直接看接口返回的 JSON / XML 内容对不对；
- **上班路上看服务器**：SSH 登上去 `df -h`、`top` 看一眼磁盘和负载，需要动文件再切到 SFTP。

## 四、站点监控：不用 24 小时盯着

官方对这个应用的定位之一就是站点监控：配置好后，应用可以监控远程服务器上的故障。你的做法是：

1. 把要盯的站点加进列表；
2. 对该站点开启监控，应用会周期性检查；
3. 服务器出问题时你能更快发现，不用等用户来报告。

监控的检查频率与告警方式以应用内实际可调的选项为准，不同版本入口名称可能有差异。能不能长期稳定跑，还取决于手机系统给不给后台：把它加入电池优化白名单、允许自启动（国产 ROM 的设置里搜「自启动」），息屏后检查才不容易被掐掉。监控出现漏报、误报时，去[常见问题与故障排查.md](常见问题与故障排查.md)第三节排查。
