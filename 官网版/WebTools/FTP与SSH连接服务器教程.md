## 一、先分清四个协议，别选错

| 协议 | 默认端口 | 是否加密 | 你什么时候用它 |
| --- | --- | --- | --- |
| FTP | 21 | 否 | 内网传文件、接老设备；公网上不建议，密码明文传输 |
| SFTP | 22 | 是（基于 SSH） | 公网传文件的首选，一般虚拟主机、云服务器都支持 |
| SSH | 22 | 是 | 需要敲命令时：看日志、改配置、重启服务 |
| Telnet | 23 | 否 | 快速试探老设备的网络服务；仅限可信内网 |

一句话记法：**传文件选 SFTP，敲命令用 SSH**，FTP 和 Telnet 只在明确的旧环境里用。

## 二、连接前把这几样准备好

无论哪种协议，你手上都要有这些信息，通常在你买服务器 / 虚拟主机的那封开通邮件里：

- **主机地址**：IP 或域名；
- **端口**：没改过就用上表的默认值，改过的以服务商给的为准；
- **用户名与密码**：SSH/SFTP 的用户名通常是 `root` 或你创建的用户；
- **服务器侧已放行**：确认服务商的防火墙 / 安全组开了对应端口——连不上的原因一半出在这里。

## 三、连接与文件管理

Web Tools 把文件管理器和 FTP/SFTP 做在了一起：连上之后，服务器的目录就当本地文件夹一样操作。

1. 在应用里新建连接，选 SFTP（或 FTP），填入第二节准备的主机、端口、账号；
2. 连接成功后，你会看到服务器上的目录树；
3. 上传：从手机存储里选文件发送到当前目录；下载：点文件选下载，存到手机里查看。

适合的场景：改完网页文件随手传上去、把服务器上的日志拉到手机里看、备份某个配置文件。传中文文件名的文件遇到乱码时，处理办法单独成篇：[FTP中文文件名乱码怎么解决.md](FTP中文文件名乱码怎么解决.md)。

## 四、SSH：登上去敲命令

SSH 客户端连上后就是一个命令行终端，你输入的命令在服务器上执行、结果回显在屏幕上。常用的几条：

```bash
df -h          # 看磁盘还剩多少
top            # 看 CPU / 内存占用（按 q 退出）
tail -n 100 /var/log/nginx/error.log   # 看最近 100 行报错日志
systemctl status nginx                 # 看 Web 服务状态
```

如果你在服务器上临时改了什么，想确认网站对外表现是否正常，切到[网站测速与HTTP测试.md](网站测速与HTTP测试.md)里的 HTTP 测试工具看一眼状态码和响应时间。

## 五、Telnet 的用途

Telnet 客户端用来快速访问服务器上的网络资源，比如确认某个端口上的老服务还在不在响应。它不加密，只在你信任的内网环境里用，不要拿它连公网服务器做敏感操作。

## 六、连不上时的检查顺序

按这个顺序过一遍，绝大多数连接问题都能定位：

1. 手机当前网络能否上网（换个网络试试，排除公司 Wi-Fi 封端口）；
2. 主机地址、端口、账号密码逐字核对；
3. 服务器安全组 / 防火墙是否放行了对应端口；
4. 服务器侧服务是否在运行（`systemctl status sshd`）。

更完整的故障清单（含 FTP 中文文件名乱码）见[常见问题与故障排查.md](常见问题与故障排查.md)。
