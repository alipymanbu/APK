## 一、先确认你的手机能不能装

Web Tools 是开发者 BlindZone 发布的安卓应用，面向需要随时随地管理网站和服务器的开发、运维人员。装之前先对照下面的信息：

| 项目 | 信息 |
| --- | --- |
| 官方名称 | Web Tools |
| 本篇对应版本 | 2.84 |
| 安装包大小 | 15.11M |
| 包名 | `webtools.ddm.com.webtools` |
| 安装包 MD5 | `3FA8E1F7625B4657E382A0CDE4530750` |
| 开发者 | BlindZone |
| 界面语言 | 简体中文 |
| 系统要求 | 安卓 5.2 以上（以安装时设备提示为准） |

**关于版本号**：官方在 Google Play 上的版本迭代较快（截至 2026-09 检索时最新为 3.4，更新内容是整体改进与稳定性修复），你通过下方网盘拿到的是 2.84 版。两个版本的核心能力一致——FTP/SFTP/SSH 连接、HTTP 测试、测速、代码编辑器这些都在；想要官方最新版可以去 [Google Play 页面](https://play.google.com/store/apps/details?id=webtools.ddm.com.webtools) 安装。

## 二、拿到安装包

安装包从 [WebTools 安装文件资源（夸克网盘）](https://pan.quark.cn/s/fb20d0e491b9) 获取：打开链接后先转存到自己的网盘，再从网盘下载到手机存储里。这是一个 15.11M 左右的 APK 文件，手机剩余空间几十 MB 就够。

## 三、安装步骤

1. 打开手机「文件管理」，在下载目录里找到刚下好的 APK 文件；
2. 点开它，系统提示「允许安装未知来源应用」时，按提示允许本次安装；
3. 等进度走完，点「打开」直接进入应用，或回桌面点图标进入。

如果手机上有安全管家类应用，首次安装可能弹出风险提示——这是所有非应用商店安装包的常规提醒，确认来源是你自己转存的包即可继续。

## 四、装不上时按这个顺序查

1. **提示不兼容 / 系统版本过低**：对照第一节表格里的系统要求，老机型（安卓 5 以下）装不了新版；
2. **提示包损坏或解析失败**：下载过程断网、传输中断都会导致包不完整，重新下载一次；校验通过的话，MD5 应为 `3FA8E1F7625B4657E382A0CDE4530750`；
3. **存储空间不足**：清出几十 MB 余量再装。

安装成功后先看[使用教程.md](使用教程.md)了解怎么添加你要管理的站点；更多故障场景（连接失败、中文乱码等）集中在[常见问题与故障排查.md](常见问题与故障排查.md)。
