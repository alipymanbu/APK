## 一、下载前先知道的几件事

PiliPalaX 是一个开源的 B 站第三方客户端，只有安卓安装包这种获取形态，不上架国内应用商店。它的官方仓库已于 2025 年 7 月标记归档（只读），也就是说版本不会再更新 —— 你拿到哪一版，就会一直用哪一版。

2. **GitHub Releases**：官方仓库 [github.com/orz12/PiliPalaX](https://github.com/orz12/PiliPalaX) 右侧的 Releases 页面。仓库虽然已归档，历史 release 仍然可以下载，最终一个版本是 1.1.2-beta+187。

不管走哪个渠道，装之前建议核对一次 MD5，确认文件没有在传输中损坏（方法见下面第四节）。

## 三、安装步骤

PiliPalaX 是安卓应用，系统要求 **Android 5.0 及以上**（项目构建配置里最低兼容到 API 21），手机和平板都能装，没有桌面端。

1. 把 APK 文件下载到手机存储里；
2. 在文件管理器里点开这个 APK（文件名形如 `pilipalax_v1.1.0.apk`）；
3. 系统会提示「不允许安装未知来源应用」，点设置里允许你的文件管理器或浏览器"安装未知应用"（不同品牌的入口位置不同，一般在 设置 → 安全/隐私 里）；
4. 回到安装界面点「安装」，等进度走完；
5. 打开应用，会直接进入推荐流首页，不登录也能浏览（登录相关见 [登录与账号使用.md](登录与账号使用.md)）。

## 四、装不上时的核对清单

- **提示"解析包错误"或安装中断**：多半是文件没下完整。在电脑上核对 MD5（Windows 命令行）：

  ```powershell
  certutil -hashfile pilipalax_v1.1.0.apk MD5
  ```

  输出与上表里的 MD5 一致才算文件完好，不一致就重新下载。
- **存储空间不足**：安装时除了 59.49 MB 的安装包，还需要额外的解压空间，预留 200 MB 以上比较稳。
- **装上了但打开就闪退**：先确认系统版本到了 Android 5.0 以上；仍闪退参考 [无法播放与加载失败排查.md](无法播放与加载失败排查.md) 里的通用处理步骤。
- **想换新版本**：项目已归档，1.1.0 之后官方只发到 1.1.2-beta+187，能否拿到以仓库 Releases 页当时显示为准。

## 五、装完之后

第一次打开不需要任何配置，直接就能刷视频。接下来你大概率想做两件事：登录自己的 B 站账号同步收藏和历史，或者先把播放设置按自己的习惯调一遍 —— 分别见 [登录与账号使用.md](登录与账号使用.md) 和 [播放设置与手势操作.md](播放设置与手势操作.md)。
