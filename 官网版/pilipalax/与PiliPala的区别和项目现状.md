## 一、PiliPalaX 和 PiliPala 是什么关系

PiliPala（无 X）是一位开发者用 Flutter 写的 B 站第三方客户端，开源在 GitHub（guozhigq/pilipala）。PiliPalaX 是从它 fork 出来的分支，由另一位开发者（orz12）维护，在原版基础上做了更大幅度的改动 —— 这句关系写在 PiliPalaX 仓库自己的致谢里，向原作者的开源精神致谢。

两者的功能盘子大体相近（推荐、番剧、直播、弹幕、缓存、动态那一套），社区里的普遍反馈是动态页面两边差异较大，其余区别不算大。选哪个更多是看界面习惯，建议都装上试几分钟再定。

## 二、项目现状：官方仓库已归档

这是本篇最重要的一条信息：

- **PiliPalaX 的官方仓库（github.com/orz12/PiliPalaX）已于 2025 年 7 月 17 日被作者标记为 archived，变成只读** —— 代码还能看、历史 release 还能下，但不再接受任何更新；
- 归档前最后一个 release 是 **1.1.2-beta+187**（修复关注操作权限不足、个人主页读取用户信息失败）；
- 背景：2025 年 7 月有媒体报道，PiliPala 原版作者收到哔哩哔哩的律师函，函件认为该项目未经许可聚合平台数据、对平台构成实质性替代，要求立即停止开发并下架项目。PiliPalaX 在此前后归档，与这轮第三方客户端的整体处境是同一时间线。协议层面对普通使用者的含义单独整理在 [第三方客户端会封号吗.md](第三方客户端会封号吗.md)。

## 三、"已归档"对你的实际影响

| 方面 | 影响 |
| --- | --- |
| 版本更新 | 不会再有。网盘里这份 1.1.0 就是最终形态之一，bug 也不会再修（哪些已知问题见 [无法播放与加载失败排查.md](无法播放与加载失败排查.md)） |
| 接口适配 | B 站调整接口时，旧版功能会陆续失效，且无人修复 |
| 已装的包 | 不受影响，已下载的安装文件可以继续安装使用 |
| 安装包来源 | GitHub Releases 的历史页面仍在；获取与核对方法见 [下载与安装教程.md](下载与安装教程.md) |
| 社区交流 | 官方 README 里留的 Telegram 交流群（[t.me/+162zlPtZlT9hNWVl](https://t.me/+162zlPtZlT9hNWVl)）仍可访问，归档后的动态以群内消息为准 |

## 四、后续版本的线索

归档之后，社区里出现了继承这一脉络的新项目 PiliPlus（GitHub: bggRGjQaUbCoE/PiliPlus），有用户认为它是 PiliPalaX 系功能的延续、迭代更活跃。这属于社区反馈，两个项目是否一脉相承以各自仓库的说明为准；如果你看重"还在维护"这一点，可以去它的仓库页面自行了解。

## 五、和官方 App 摆在一起看

| 对比项 | PiliPalaX | B 站官方 App |
| --- | --- | --- |
| 开发者 | 个人开源项目 | 企业产品 |
| 代码 | 公开（GitHub） | 不公开 |
| 应用内注册账号 | 不支持，需先在官方渠道注册 | 支持 |
| 平台 | 安卓、iOS、平板 | 全平台 |
| 更新状态 | 已归档停更 | 持续更新 |

两边不是替代关系里的二选一：很多人是官方 App 照常装着、第三方客户端当一个备用的观看入口。账号和数据是同一份（原因见 [登录与账号使用.md](登录与账号使用.md)），切换过去不会丢东西。
