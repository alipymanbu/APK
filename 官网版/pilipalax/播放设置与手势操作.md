## 一、全屏播放时的手势

装完先把手势过一遍，日常用起来基本不用碰按钮：

| 想做的事 | 手势 |
| --- | --- |
| 快进 / 快退 | 水平方向滑动，或双击快进/快退 |
| 播放 / 暂停 | 双击 |
| 调亮度 / 音量 | 屏幕垂直方向滑动 |
| 进全屏 / 退全屏 | 垂直方向上滑全屏、下滑退出 |
| 倍速播放 | 长按屏幕临时提速，1.1.0 这一线还加了长按倍速递增 |

各手势的触发区域和灵敏度能在**手势设置**里调，设置支持按 JSON 标准导入/导出 —— 换手机时把配置文件带过去，不用一项项重调。

## 二、画质、音质与解码

设置里可以把三样东西预设好，之后每个视频都按预设来：

- **画质**：可选不同清晰度档位，实际能选到哪一档取决于视频本身和你的账号登录状态。官方功能列表对这一项的备注是「高清画质未解锁」—— 也就是说部分高清晰度档位在这个客户端里选不到，网上流传的"免登录看高清"之类说法与官方功能列表不符，能选哪些以播放页实际显示的档位为准；
- **音质**：视视频而定，不是所有视频都有多档音质；
- **解码方式**：可选不同解码格式，配合**硬件加速**开关（是否生效视机型而定，老机型遇到卡顿可以先从这里排查）。

另外几项和观看体验直接相关：**记忆播放**（下次打开接着上次的位置）、**视频比例**（高度/宽度适应、填充、包含等）、**高帧率**、**自动全屏**、**横屏适配**、**震动反馈**，都在设置里逐项开关。

## 三、弹幕与字幕

- 弹幕和直播弹幕都支持开关，弹幕相关的容错在 1.1.0 系列里做过一轮加固（拉取弹幕失败时最多自动重试 3 次）；
- 字幕可手动选择，同一合集内选过的字幕会被继承；
- **1.1.0 已知问题**：默认字幕偏好设置会失效 —— 这是这一版就存在的 bug，官方在 1.1.1 里修掉了，但项目随后归档，1.1.0 不会再收到修复。表现就是每次播放都得手动选一次字幕，属于用起来有点烦但不影响看的小毛病。

## 四、播放页与评论区能做的事

- **选集（分 P）切换**：多 P 视频在播放页直接切换；视频同时带合集和分 P 时，官方在 1.1.0 后段调整为尝试优先按分 P 循环播放；
- **评论区**：支持排序查看（最热 / 最新）、楼中楼展开与回复、评论点赞；评论用户带身份标识，UP 主的回复能直接认出来；
- **评论笔记图片**：评论区里的笔记图片可以查看和保存到本地；
- **相关视频**：播放页下方能看到与当前视频相关的内容，不用回首页重新搜。

## 五、界面与外观设置

主题模式支持亮色 / 暗色 / 跟随系统三选，图片质量可以单独设定（弱网环境下调低能明显减少加载等待）。首页底栏和侧栏会随横竖屏自动切换。

## 六、设置调完还是播不了怎么办

画质档位灰着、视频转圈加载不出来，多数时候和设置无关，而是接口或网络层面的问题，按 [无法播放与加载失败排查.md](无法播放与加载失败排查.md) 的症状对照表处理更快。要不要登录对画质档位有影响这一点，在 [登录与账号使用.md](登录与账号使用.md) 里也提过。
