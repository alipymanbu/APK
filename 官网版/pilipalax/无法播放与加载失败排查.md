## 一、排查前先认清一个前提

PiliPalaX 这类第三方客户端靠调用 B 站接口工作，平台一侧调整接口时，旧版本就会出现各种"加载失败"。而它的官方仓库已在 2025 年 7 月归档（详见 [与PiliPala的区别和项目现状.md](与PiliPala的区别和项目现状.md)），**不会再有针对新接口的适配更新**。所以本篇能解决的是"这一版已知怎么处理"的问题；属于接口层面整体失效的，只能接受或换用仍在维护的客户端。

网盘里的这一版是 **1.1.0**，下文所有"某版本已修复"的说明都以官方仓库的 release 记录为准。

## 二、症状对照表

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 推荐流页面空白，其他页面正常 | 与登录方式相关，有用户反馈重新登录可临时缓解但会复发 | 换一种登录方式（扫码 ↔ 短信验证码）重新登录；必要时清除应用缓存。这是 1.1.0 之前就有人遇到的老问题，官方后来加过接口参数优化 |
| 个别视频加载不出来，别的都正常 | 1.1.0 存在一个"备选播放地址为空字符串导致偶发加载失败"的已知缺陷，官方在后续版本修过 | 切换网络（WiFi ↔ 流量）后重试；退出该视频重新进入 |
| 评论区切换"最热/最新"排序后白屏 | 排序切换的加载问题，官方仓库有对应修复记录 | 退出评论区重进；暂用默认排序 |
| 播放器弹出菜单用返回键关闭后黑屏 | 1.1.0 所在版本线的已知 bug（官方当时就标注了） | 关弹窗时**点弹窗以外的屏幕位置**，别按返回键 |
| 关注操作提示权限不足、个人主页读不出用户信息 | 官方在 1.1.2 里修复，1.1.0 仍会触发 | 无法在 1.1.0 内解决；关注/取关等操作可临时改用 B 站官方 App 完成 |
| 从外部网页点专栏文章跳进来报网络异常、黑屏 | 专栏无限重定向问题，1.1.0 所在版本线已修复过一轮 | 若仍遇到，改为在应用内搜索找到该专栏再打开 |
| 一键三连提示非法访问 | 接口参数问题，官方在 1.1.0 系列后段修复 | 换成分别点赞/投币/收藏；稍后再试 |
| 默认字幕偏好每次都要重选 | 1.1.1 修复的已知问题，1.1.0 仍在 | 手动选字幕用；见 [播放设置与手势操作.md](播放设置与手势操作.md) |

## 三、通用处理步骤

症状对不上号、或对照表的办法无效时，按这个顺序来一遍：

1. **切换网络**：WiFi 和移动数据各试一次，排除 DNS 或运营商线路问题；
2. **清除应用缓存**：系统设置 → 应用 → PiliPalaX → 清除缓存（先别点"清除数据"，那会清掉登录状态和本地配置）。应用的数据目录在内部存储的 `Android/data/com.orz12.PiliPalaX/` 下，Android 11 起文件管理器一般进不去这个目录，所以从系统设置的入口清最省事；
3. **重新登录**：退出登录再登一次，顺便换一种登录方式；
4. **重启应用 / 重启手机**；
5. **检查剩余存储与后台**：有用户反馈内存紧张或省电模式激进时容易闪退，给手机留 1 GB 以上可用内存、把省电策略放宽后再试（这条来自个别用户反馈，仅作参考）。

## 四、如果全部无效

那就是接口层面的问题了：平台调整导致旧版请求不再被接受。项目已归档，1.1.0 不会自我修复，能做的是去官方仓库的 Issues 区看看别人是否报了同样的问题、有没有人给出临时办法（仓库地址见 [与PiliPala的区别和项目现状.md](与PiliPala的区别和项目现状.md)）。安装包本身有问题（装不上、闪退）则回到 [下载与安装教程.md](下载与安装教程.md) 的核对清单。
