## 一、取消订单：两个入口

- **还没付款**：订单默认保留 **30 分钟**等待支付（秒杀类订单以页面提示为准），超时自动取消；想立刻取消就到「我的 - 全部订单 - 订单详情」里操作。
- **已付款未发货**：同样进「我的 - 全部订单」→ 订单详情 → 申请退款/退货，按页面步骤提交。

注意：**订单取消后无法恢复**，要买只能重新下单 —— 重新下之前的先确认券、积分、国补资格都还在（见 [商城下单与优惠券使用.md](商城下单与优惠券使用.md) 与 [国家补贴领取与使用规则.md](国家补贴领取与使用规则.md)）。

## 二、改订单：什么能改、什么不能改

| 情形 | 能否处理 |
| --- | --- |
| 未发货，改收货信息 | 可以：订单详情页点收货信息右侧「修改」 |
| 未发货，改颜色 / 型号 | 不能直接改：联系在线客服或 95033 试协商；常规做法是退款重拍 |
| 已发货，改地址 | 联系在线客服协助联系快递（EMS 邮政不支持跨省市区改） |
| 已发货，改颜色 / 型号 | 只能等包裹送达后拒收，再重新下单（商城收到包裹后预计 48 小时左右办退款） |
| 镭雕定制订单 | 已发货或镭雕完毕不支持拒收退货、不支持换色 |

镭雕定制还有一条要记住：**非质量问题不支持无理由退货**，下单前把刻字内容确认好。

## 三、退款多久到账

退款一律**原支付通道返回**，时效分两段看：

1. **仓库验收**：商城收到退回的包裹（含拒收）验收无误后，预计 **3-4 天内**办理退款（大促或新品上市期间会延长）。
2. **到账**：

| 付款方式 | 受理成功后到账 |
| --- | --- |
| 支付宝余额（含花呗）、微信余额 | 24 小时内 |
| 支付宝 / 微信绑定银行卡快捷支付 | 预计 1-3 天（以银行处理为准） |

对到账时间有疑问时，先看订单里的退款状态，再等银行侧短信；两边都查不到再找在线客服。

## 四、7 天无理由退货怎么走

- **起算点**：从**物流签收时间**开始算 7 天；手机、平板**已激活也可**享受 7 天无理由退货；拆封、插卡都不影响。
- **流程**：订单页 → 退款/退货 → 选原因提交 → 审核通过 → 全部商品（含赠品）寄回 → 收货退款。
- **退货注意**：清单上注明订单号与退货原因；商品数量齐全、赠品一并寄回；**清掉锁屏密码与个人隐私数据**；寄回时核对 IMEI 与原机一致（拨号 `*#06#` 查）；推荐顺丰并保价。
- **运费**：个人原因拒收退货，退回运费从退款里扣；符合条件的订单用「上门取件」可自动用退换货免邮券。
- **不支持无理由的情况**：超期、外观磕碰、进液、人为拆机；镭雕定制商品（非质量问题）；生活日用部分商品拆封后。

换货（30 天内）路径不同：要先到 vivo 售后服务中心开换机故障检测单，再凭单联系在线客服登记寄回，详见 [真伪查询与维修价格查询.md](真伪查询与维修价格查询.md)。

## 五、券和积分会退吗

退货后优惠券按券的规则处理（一般退回后原有效期不变，以券详情为准）；积分抵现的积分按实际退款金额退回，一般 1-3 个工作日回账，详见 [积分获取与会员权益.md](积分获取与会员权益.md)。享受过国补的订单退货，补贴资格如何处理以当期活动规则为准。
