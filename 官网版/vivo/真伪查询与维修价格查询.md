## 一、真伪查询：先拿到识别码

验机靠三类码，不同产品用不同的码：

| 产品 | 用什么码查 |
| --- | --- |
| 手机 | IMEI |
| 平板 / 手表 / 真无线蓝牙耳机 | 序列号 SN |
| 部分包装 | 防伪码 |

获取方式：

- **手机**：拨号键盘输入 `*#06#`，屏幕直接显示 IMEI 1；
- **平板**：设置 → 系统管理 → 关于手机（关于平板）里查看序列号；
- **包装盒**：盒身标签上印有 IMEI / SN / 防伪码，与机身显示的对照即可。

## 二、在哪查

- **网页查**：打开 [support.vivo.com.cn/service/authenticityCheck](https://support.vivo.com.cn/service/authenticityCheck)，输入 IMEI / SN / 防伪码点查询；官网 [www.vivo.com.cn](http://www.vivo.com.cn) 的「服务 → 真伪查询」也通向同一入口。
- **App 内**：vivo官网 App 的服务板块里也有真伪查询入口（App 装法见 [下载与安装教程.md](下载与安装教程.md)）。

查出来是正品就到此为止；查无此码或信息对不上，带上购机凭证联系官方客服 95033 核实。

## 三、维修价格：修之前先看价

官方维修价是公开的，别到店了才第一次知道数字：

- **App 内路径**：vivo官网 APP → **我的 → 维修价格**，选机型和配件即可看到报价；手机、平板、蓝牙耳机（单只 / 充电盒）、手表等都能查。
- **网页版**：[www.vivo.com.cn/service/accessory](https://www.vivo.com.cn/service/accessory)。

口径要点：

- 客户服务中心**只收配件费，不收手工费**；配件按公司指导价执行，均为原厂全新件。
- 页面查不到的配件，打服务中心电话或 95033 问。
- 价格会调整，**以查询页面当时显示为准**。

## 四、维修进度怎么查

送修之后有三条路子查进度：

1. vivo官网 App → 我的 → 我要维修 → 了解维修进度；
2. vivo官网 → 服务 → 维修进度查询 → 用送修时的手机号验证；
3. 关注「vivo智能手机」微信公众号 → 服务中心 → 预约与查询服务 → 维修进度查询。

## 五、三包与保修期怎么算

- 手机执行国家三包：**7 天包退、30 天包换、1 年保修**（凭有效发票与三包凭证）。
- 商城购物的保修期从**快递签收日**起算：手机 / 平板 1 年，手表、无线耳机 1 年；vivo 品牌充电器、数据线 1 年并支持全国联保，第三方品牌配件由对应生产商保修。
- 换机后三包**从换机日重新计算**。
- 保修凭证都丢了，服务中心会按出厂日期后推 90 天计算保修时间。
- 进水、摔坏等人为损坏不在保修范围内，可到服务中心付费换原厂件。

去服务中心前带齐：换货带设备全套 + 购机凭证；检测维修带设备 + 发票或保修卡（开机状态下注册的电子保修卡也可作凭证）。网点地址在官网 [www.vivo.com.cn/service/map.html](https://www.vivo.com.cn/service/map.html) 查。
