## 一、自主练习和老师布置的作业是两条线

「我的作业」里的题来自班级，有截止时间、有分值、要参与互评；「自主练习」是你自己安排的训练，**不需要班级，也不需要授权码**。已经加了班级的人同样可以用自主练习，两者各记各的记录。

想自己安排训练时，从这里进入。

## 二、自由写作

自由写作解决的是「有想写的话题，但没有对应题目」的情况：

1. 进自主练习，选自由写作；
2. 自己给这篇定一个标题；
3. 在作答区写完并提交；
4. 提交后同样会拿到机器评分，读法与作业完全一致——四个维度、综合评语、分句点评都在。

因为题目是你自己出的，**评分里的「内容」维度参考价值会打折**：系统看到的是你写的内容与你自己定的标题是否自洽，而不是是否切了老师想要的题。把自由写作当成练语言与结构的手段更合适。

## 三、题库写作

题库写作是「从现成的题目里挑一道来写」，比自由写作更接近考试场景：

- 题库覆盖考试类题型，包括大学英语四级、六级，硕士研究生入学考试，英语专业四级、八级，托福、雅思等方向的写作题；
- 选中题目后按题面要求写作并提交，同样走机器评阅；
- 题目自带标题与指令，所以四个维度的评分都能正常发挥作用。

**准备具体考试时优先用这条路径**：同类题型的评分尺度更接近你要面对的那场考试，比自定标题练出来的手感更有参照意义。

题库的范围与题量会随平台更新变化，具体能挑到哪些题，以你进入题库时看到的列表为准。

## 四、练习记录

每次练习都会留下来，形成练习列表。它的用法是**回看而不是收藏**：

- 翻自己写过的题，确认同一类错误是否还在重复；
- 想对比进步时，拿同类型题目的两篇来比，比拿两篇不同体裁的作文来比更说明问题；
- 练习记录的汇总统计与作业数据一起进「学习档案」，见[学习档案与成绩统计怎么看.md](学习档案与成绩统计怎么看.md)。

## 五、写作资源

写作资源区放的是写作材料，两条用法：

| 用法 | 说明 |
| --- | --- |
| 查看资源 | 浏览已有材料，常见的语法点说明与写作技巧类内容在这里 |
| 添加资源 | 自己上传写作材料进资源区，之后可以直接检索 |

老师也会通过作业把相关材料发下来，那部分随作业一起出现在作答页，不用到资源区里找。

## 六、什么时候该用哪条路径

| 你的情况 | 建议路径 |
| --- | --- |
| 有老师布置的作业 | 写作业，按时交，拿批改与互评 |
| 备考某场考试 | 题库写作，挑同类型题目 |
| 想针对自己的高频错误补练 | 先看学习档案里的错误类型统计，再回题库挑对应题型 |
| 只想随手写点东西 | 自由写作 |

练完想看点更细的数据，见[学习档案与成绩统计怎么看.md](学习档案与成绩统计怎么看.md)；刷不出题、提交失败这类问题见[常见问题与排查.md](常见问题与排查.md)。
