## 一、授权码是老师生成的，不是你自己找的

作业是老师发布到某个班级里的，所以你得先进入那个班级。学生自己进班靠的是**班级授权码**：

- 老师在系统里创建班级后，系统会为该班级生成一个授权码；
- 老师把授权码告诉你（通常随课程通知、班级群或课件一起发）；
- 你用这个码把自己加进班级。

**拿不到授权码、老师也没有直接把你加进名单，你的列表里就不会有老师布置的作业**：题目的时限、字数、分值都挂在班级的作业上，脱离班级就取不到这些设置。

拿不到授权码时，先按下面顺序处理：

1. 看一下课程通知、班级群公告里有没有一串代码；
2. 直接问任课老师要，说明你需要用 iWrite 写作；
3. 都没有时，用「自主练习」先写着——自由写作与题库写作不依赖班级，见[自主练习与写作资源.md](自主练习与写作资源.md)。

## 二、加入班级的步骤

1. 登录后进「我的班级」。
2. 点右上角「加入班级」。
3. 在输入框里填入老师给的授权码，点「搜索」。
4. 搜索框下方会显示该班级的信息，核对一下班级名称是不是老师说的那个。
5. 点「加入班级」，弹窗自动关闭，就完成了。

加入之后回到「我的作业」，老师已发布的作业会出现在列表里。

## 三、加进去之后能看到什么

点班级名称进去，能看到同班同学的名单，以及公开的统计信息：

| 列 | 含义 |
| --- | --- |
| 姓名 / 学号 | 同学的身份标识 |
| 年级 | 班级所属年级 |
| 作业数 | 该班级已发布的作业总数 |
| 完成数 | 该同学已完成的作业数 |
| 范文 | 被设为范文的篇数 |

名单也支持按姓名搜索，班里人多的时候比上下翻页快。

**提醒**：这一页是同学之间的公开信息，你也在这份名单里。写作业时别在无关内容里留下不适合公开的个人信息。

## 四、退出班级、班级过期、换班

- **退出班级**：进班级详情后可以退出。退出后该班级的作业不再出现在你的「我的作业」里。
- **班级过期**：班级有有效期，任课老师可以重新激活并把有效期延长。学生这一侧看到的是「不在了」，处理方式是问老师有没有重新激活。
- **历史班级**：已经退出或已经过期的班级不会凭空消失，点左上角的「历史班级」可以翻到，用于回看当初的作业与批改。
- **换班级**：换了任课老师或换了课，通常会有一张新的授权码。用新码加入新班级即可，旧班级会沉到历史班级里。

## 五、加不进班级时的排查顺序

按这个顺序查，基本一次能定位：

1. **授权码有没有抄错**：字母大小写、数字 0 与字母 O、1 与 I 这类最容易出错，建议直接从老师发的原文复制。
2. **是不是过期了**：班级有有效期，学期初发的码到学期末可能已失效——问老师。
3. **是不是加错班级**：搜索结果里的班级名称与老师说的对不上，说明码是别的班的。
4. **是不是已经加过**：已经在该班级里时，不会重复加入，去「我的班级」看一下。
5. **身份信息是否完整**：个人资料里学校/学号没填完，可能影响班级归属的核对，见[注册登录与个人信息填写.md](注册登录与个人信息填写.md)。

以上都排除了还是加不进去，见[常见问题与排查.md](常见问题与排查.md)。
