## 一、先搞清楚这是什么

iWrite（官方中文名「爱写作」）是外研社 Unipus 平台的英语写作教学与评阅系统，官方站点是 [iwrite.unipus.cn](https://iwrite.unipus.cn)。老师那一侧用它布置作文、批改、看班级统计；学生这一侧用它读题、在线写作、提交，再看机器评分与老师的批注。

它不是「装完就能随便写」的通用写作软件：自主练习部分谁都能用，但老师布置的作业要凭班级授权码才拿得到。所以装完之后的动作顺序是固定的——登录、把身份填成学生、加入班级。

## 二、先核对你要装的是哪一份

同名或近名的应用不止一款，装之前对一下这张表：

| 项目 | 值 |
| --- | --- |
| 应用名 | iWrite |
| 包名 | `com.iwrite.pk` |
| 版本号 | 1.1 |
| 安装包体积 | 2.53 MB |
| MD5 | `A3B77FB1BE72D3AB364EA7058349EA5E` |
| 信息核对时间 | 2026-09-23 |

版本号、包名、体积一律以网盘里这份 **1.1** 为准。官方网页端会持续更新，页面上的版本与本安装包不是同一版，别拿它来对。

这是 Android 安装包（`.apk`），不是 iOS 版。手机上装了它，用浏览器打开官网网页端同样能看到作业与批改，两边共用同一个账号。

**系统要求**：这份包的下载页上标注的条件是「需要支持安卓系统 5.2 以上」，判断自己手机是否满足时，以你下载时页面上标注的为准；旧机型上即使能装，页面显示也可能不完整。这个应用以联网使用为主，装完建议连着网先试一遍登录与打开作业。

## 三、安装包从哪拿

网盘入口在本文开头的提示块里（[iWrite 安装文件资源（夸克网盘）](https://pan.quark.cn/s/353d31b5b980)）。两步走：

1. 打开链接后**先转存到自己的网盘**，再从网盘下载到手机。分享链接有失效风险，转存之后资源跟着你的账号走。
2. 下载得到的是 `.apk` 文件，不是压缩包，不需要解压。

这份包 2.53 MB，流量和存储都不构成负担。只想先看看题目和批改报告的话，用手机浏览器登录 [iwrite.unipus.cn](https://iwrite.unipus.cn) 也能办，安装包不是唯一入口；官方另有微信公众号入口（公众号名「iWrite爱写作」），菜单以公众号当时显示为准。

不建议去搜索结果页里的第三方下载站取包：那些站点的下载按钮常层层跳转，最后落到哪个文件、有没有被重新打包，你没法确认。要核对文件，拿上表里的 MD5 比一下。

`iwrite` 这个名字同时被好几类写作产品占用，下载站上的介绍文字常互相矛盾。按什么判据确认你装的是课程要的那一份，见[同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 四、安装步骤（Android）

1. **找到文件**：在手机「文件管理」里进下载目录，或在夸克 App 的下载列表里直接点开。
2. **允许本次安装**：第一次从应用商店以外的来源装包时，系统会提示「禁止安装未知应用」。点提示里的「设置」，把**你正在用来打开这个文件的那个 App** 的「允许安装应用」开关打开，装完可以关回去。
3. **点 apk 安装**：读一遍权限列表再确认。这个应用要联网取作业与批改、要读写存储保存草稿，所以看到网络、存储这类申请是正常的。
4. **核对包名（可选）**：装完在「设置 → 应用 → iWrite → 应用信息」里看包名是不是 `com.iwrite.pk`。对不上说明装的不是这一份。

「解析包时出现问题」「应用未安装」「安装被拦截」这几类提示的处理见[常见问题与排查.md](常见问题与排查.md)。

## 五、装完第一次打开

按下面的顺序做，跳过哪一步后面都会卡：

- **注册或登录 Unipus 账号**。手机号或邮箱都能注册，一个账号在 Unipus 各平台通用。见[注册登录与个人信息填写.md](注册登录与个人信息填写.md)。
- **把身份填成「学生」**，并填姓名、学号、学校。老师那一侧的班级名单靠这些信息认人。
- **加入班级**。这一步要老师给你的班级授权码；暂时没有就先做自主练习。见[加入班级与授权码怎么用.md](加入班级与授权码怎么用.md)。
- **进「我的作业」看一眼**，确认列表里有老师布置的作业。

题目和批改都是联网取的，第一次打开后先连着网用几分钟，把当次要写的题加载出来。

## 六、以后怎么更新

拿到新版本安装包后**直接覆盖安装**即可：同一个包名覆盖安装不会清掉已登录的账号状态。不要先卸载再装——那会连本地缓存一起清掉，得重新登录。
