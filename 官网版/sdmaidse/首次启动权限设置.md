## 一、为什么权限决定它能不能干活

SD Maid SE 的每个工具都对应一类系统权限：没给权限，工具照样出现在列表里，但扫出来是空的、或者扫到了删不掉。第一次启动它会用向导逐项要权限，你也可以事后在它的**设置 → 权限/设置向导**里重新进入。四项核心权限如下：

| 权限 | 谁要用 | 不给会怎样 |
|---|---|---|
| 所有文件访问（存储） | 扫描与删除公共目录里的文件 | 扫不到、删不了 |
| 使用情况访问（Usage Access） | AppCleaner 识别各应用 | 无法按应用列出缓存 |
| 无障碍服务（Accessibility） | AppCleaner 自动点"清除缓存" | 只能手动一个个删 |
| 忽略电池优化 | 后台扫描、计划任务 | 调度任务不按时跑 |

## 二、逐项怎么开

**1. 所有文件访问（存储）**
首次向导里弹出"允许访问所有文件"时直接允许。错过的话：系统设置 → 应用 → SD Maid SE → 权限 → 文件和媒体 → 允许（部分机型叫"所有文件访问"）。

**2. 使用情况访问**
向导会把你带到一个系统页面，里面列出一批应用，找到 SD Maid SE 打开开关。这个权限让 AppCleaner 知道装了哪些应用、分别占了什么，是"按应用清缓存"的基础。

**3. 无障碍服务**
路径是系统设置 → 无障碍（部分机型在"已安装的服务"里）→ 找到 SD Maid SE → 开启。它用于自动替你点进各应用的设置页点"清除缓存"按钮 —— 安卓不允许应用直接删别的应用的私有缓存，只能靠这个方式自动化。官方声明该服务只用来点按钮，不采集信息。

建议：**先不开也行**。不开无障碍时 AppCleaner 仍能扫出结果，只是删除那步会引导你手动处理；等你确定要频繁清缓存再开。无障碍权限敏感，只给你信任的应用开。

**4. 忽略电池优化**
应用内向导会请求"不要让系统杀掉后台"。允许它，否则 [计划任务](卸载残留与缓存清理教程.md) 到点不执行、扫描中途被杀。小米/Redmi/HyperOS 这类机型还要额外做两件事：在系统"自启动"管理里允许 SD Maid SE，电池设置里选"无限制"—— 官方在 HyperOS 上也会主动弹自启动提示，照着做即可。

## 三、给了权限还是扫不动

按这个顺序查：存储权限是否真给了（部分机型显示"允许"但实际没生效，重开一次开关）→ 使用情况访问是否开了 → 扫的是不是应用私有目录（如 `/Android/data/` 下的缓存，没有 root 或 Shizuku 时系统不让碰，详见 [Shizuku免Root权限开启.md](Shizuku免Root权限开启.md)）。更多症状对照见 [常见问题与故障排查.md](常见问题与故障排查.md)。
