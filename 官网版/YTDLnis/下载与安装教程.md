YTDLnis 是一款免费开源的安卓下载工具，把命令行工具 yt-dlp 的能力搬进了一个手机界面，支持上千个网站的视频与音频下载。它只发安卓版，装法与应用商店里的应用不同，装完之后还有一步必须自己补上。这篇讲的就是从取包到能用之间的全部动作。

## 一、装之前先对一下这张表

安卓设备都能试，但没有 iOS 版，也没有 Windows / macOS 客户端。动手之前先对一遍这张表：

| 项目 | 这一版的情况 |
| --- | --- |
| 软件名 | YTDLnis |
| 开发者 | Denis Çerri（个人开发者维护） |
| 版本号 | 1.8.1.1 |
| 包名 | com.deniscerri.ytdl |
| 安装包大小 | 42.70 MB |
| 安装包 MD5 | 52D26037919475D6622079B90BC60716 |
| 适用设备 | 安卓手机、安卓平板 |
| 系统要求 | 官方下载页当前标注 Android 7.0 或更高 |
| 开源许可 | GNU GPL v3.0 |
| 整理时间 | 2026-09-23 |

有三件事先说清楚，能省掉后面不少困惑：

1. **版本号以本页为准。** 这个项目迭代很快，官方现在的最新版已经比 1.8.1.1 高出一截。本页写的是随安装文件一起放出的那一版，功能描述按 1.8.x 的口径；要核对你手上那份，看「设置里的版本号 + 包名」两处就够了。
2. **它不会上 Google Play。** 官方给出的原因是 yt-dlp 这类工具与 Google Play 的内容政策冲突，为避免被下架，只从自己的渠道分发。所以应用商店里搜不到是正常的，商店里搜到同名的也一律不是它。
3. **没有 iOS 版，也不会有。** 官方说明里明确写了不做 iOS / iPadOS 版本，理由是两端代码库差异太大、iOS 上也没有对应的 yt-dlp 运行库。任何自称「YTDLnis for iOS」的产品都与它无关，官方把这类页面直接定性为骗局。

## 二、从网盘把安装包取出来

1. 打开 [YTDLnis 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9c5594487114)。手机、电脑上都能操作，用夸克 App 打开更顺手。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存之后，下载就不再依赖原分享链接是否还在。
3. 取包分两种走法：
   - **直接装到手机上**：在网盘 App 里下载，文件会落到手机的「下载」目录。
   - **先存电脑再传手机**：电脑端下载后用数据线或聊天工具传过去。安装包在电脑上双击没用，最终还是要回到手机上装。
4. 下完核对两件事：文件名以 `.apk` 结尾；MD5 是 `52D26037919475D6622079B90BC60716`。对不上就删掉重下 —— 安卓装到一半报「解析包错误」，绝大多数是包没下完整或被传坏。

## 三、手机上的安装步骤

这份包不是从手机自带商店里下的，安装时系统会拦一下，属于正常现象，不代表文件有问题。

1. 打开手机的「文件管理」，进 `Download`（下载）目录，找到刚下好的安装包，点它。
2. 系统弹出「不允许安装来自此来源的应用」之类的提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要绕一层：设置 → 应用 → 特殊应用权限 → 安装未知应用，在里面找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」，把下面第四节的设置做完再进去，省得来回切。

安装包按处理器架构分开打包（常见手机是 arm64；模拟器和 Windows 上的安卓子系统要用 x86-64 那一份）。如果装的时候被提示「应用与此设备不兼容」，多半是拿错了架构，回官方下载页按页面给出的建议重取一份即可。

## 四、装完第一次打开，先做这三件事

1. **更新 yt-dlp，并把自动更新打开。** 这是官方反复强调的第一步。进「更多 → 设置 → 更新」，里面能找到 yt-dlp 的更新项，先手动更一次，再把自动更新打开。刚装上却一下载就报错，多数是这一步没做。具体排查见 [常见问题与排查.md](常见问题与排查.md)。
2. **给存储权限、选好下载目录。** 存储权限没给全，下载会直接失败或文件找不到。在「更多 → 设置」里把默认下载位置改成你需要的目录（外置存储或某个自建文件夹都行）。
3. **认清主界面。** 顶部是搜索框，往下是搜索结果，导航栏里的「下载」图标对应下载队列。后面所有操作都从这三处进；第一遍下载的完整走法见 [第一次下载怎么走完一遍.md](第一次下载怎么走完一遍.md)。

应用自带的一套运行库够跑常规下载。Python、FFmpeg、NodeJS、Deno、Aria2c 这几个组件可以在同一个「更新」区里单独升级或降级，不影响应用本身，用到再装。

界面语言默认跟随系统，中文系统的手机装完直接就是中文界面。如果你的系统不是中文、又想单独把界面设成中文，在「更多 → 设置」里有语言相关的项可以指定（不同版本的选项名略有差异，以你装的那一版为准）。

## 五、怎么确认装到的是正版

- **看包名**：必须是 `com.deniscerri.ytdl`。第三方播放器要调用它，填的也是这个包名。
- **看签名**：官方仓库公开了发布用的证书信息，签名证书的 SHA-256 摘要是 `263645cb5272eb290759fe1f59149ae24df6ce171e9f6666eead981d3fc64c95`，发布版按可重现构建做。签名对不上，说明这个包被第三方改过。
- **看来源**：官方只从自己的下载页和 GitHub 发布页分发。搜索引擎里排在前面的「高速下载」类站点一律不要碰，既可能夹带改动，也常冒充官方。
- **别信「汉化版 / 增强版」这类旗号**：这个应用界面本身就带多语言（含中文），不需要额外汉化；它本身免费、无广告、也不用注册账号。
