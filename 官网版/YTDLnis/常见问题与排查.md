用 YTDLnis 遇到的麻烦，绝大多数落在三类里：安装环节、yt-dlp 解析环节、系统限制环节。这三类的处理办法完全不同，先按现象定位到哪一类，再照那一节做，比一股脑重装有效得多。

## 一、装不上、装了打不开

| 现象 | 处理 |
| --- | --- |
| 提示「解析包错误」 | 安装包没下完整或被传坏，回网盘重下，核对 MD5 与 `.apk` 后缀 |
| 提示「应用未安装」 | 设备上有同包名的旧版且签名对不上，先卸载旧版再装 |
| 提示「应用与此设备不兼容」 | 大概率拿错了处理器架构那一份，回官方下载页按建议重取 |
| 提示「系统版本过低」 | 设备安卓版本低于应用要求的基线，换设备或模拟器 |
| 装完打开就闪退 | 卸载后重装一次；仍闪退时确认是不是第三方改过的包 |

安卓版本门槛以官方下载页当时显示为准（当前标注 Android 7.0 或更高）。另外提醒：**更新版本直接覆盖安装即可**，但要先确认新旧两份的签名一致；如果覆盖时报「应用未安装」，说明签名不同，只能卸载旧版再装 —— 卸载会一并清掉应用内的记录，动手前先想清楚要留什么。

## 二、一下载就报错

先给报错归个类，比一上来就乱改设置有效。同一条报错落在哪一类，处理方向就定了：

| 你看到的报错 | 归到哪一类 | 往哪走 |
| --- | --- | --- |
| 需要确认你不是机器人 / 403 禁止访问 | 信任与权限 | [提示需要登录或验证怎么办.md](提示需要登录或验证怎么办.md) |
| 提示需要登录、会员专属 | 账号权限 | [登录才能看的内容怎么下载.md](登录才能看的内容怎么下载.md) |
| 请求的格式不存在 | 格式选择 | 回下载卡片重新挑一条实际还存在的格式 |
| 合并、转码、分离音轨时报错 | 组件缺失 | 到「设置 → 更新」里补齐 FFmpeg |
| 解析失败、站点规则像是变了 | 解析器过期 | 更新 yt-dlp（本节下面） |
| 下到一半中断、超时 | 网络或环境 | 本篇第三节、第七节 |

**再走标准流程：更新 yt-dlp。**

这个应用把解析工作交给 yt-dlp，源站一改规则，旧版解析器就会失败。进「更多 → 设置 → 更新」，先把 yt-dlp 更到最新，再试一次。

更新源可以选，在「更多 → 设置 → 更新 → yt-dlp 来源」里：

| 来源 | 稳定性 | 建议给谁用 |
| --- | --- | --- |
| Stable（默认） | 最稳，修复最少 | 偶尔用、只下一个固定站的人 |
| Nightly | 稳定与新鲜度平衡 | 多数人，官方也推荐这一档 |
| Master | 最新但最不稳 | 只有必要时，或愿意承担试错成本的人 |

另外，同一个「更新」区里还能单独升级 Python、FFmpeg、NodeJS、Deno、Aria2c 这些组件 —— 它们不用等应用出新版就能自己更新。有些站点的下载依赖其中的某一个，更新完再试往往就好了。

如果还是失败：进「下载队列 → 出错」分区，点那一项的文件图标打开日志，日志里会写明具体原因，参见 [下载队列与定时下载怎么用.md](下载队列与定时下载怎么用.md) 第六节。

## 三、下到一半卡住、速度慢、中途断

按可能性从高到低查：

1. **网络本身**：换个网络（如从移动数据切到 Wi-Fi）再试一次，能通说明是链路问题。
2. **源站限速**：某些来源对连续请求会限速甚至临时拒绝，放一段时间再试比反复点重下有效。
3. **下载目录不可写**：外置存储卡被拔掉、目录权限变化，都会让下载在某一步失败。回设置里确认下载目录还在。
4. **存储权限没给全**：新系统上权限可能分成「照片和视频」「音乐和音频」几项，缺一项就可能在保存那一步失败。
5. **并发太多**：同时跑一堆任务会互相抢带宽，也更容易触发限速，减少同时下载的数量再试。

## 四、某些站就是下不了

这不是故障，是能力边界，早知道能省很多时间：

- **带数字版权保护（DRM）的平台下不了**，包括 Netflix、Amazon Prime、Spotify 这一类。官方写明原因：这类平台受数字版权保护，法律层面不允许处理，yt-dlp 不做这件事。这类内容只能用平台自己的官方离线功能。
- **它不是在线观看工具**：定位是下载视频/音频流，不能拿它当流媒体客户端用（官方 FAQ 里也专门澄清了这一点）。
- **支持面很广但不等于全支持**：能下的站点数量在上千级别，且随 yt-dlp 版本变化。某个站突然不行，通常更新 yt-dlp 就好；某一个视频不行而同一个站的其它视频可以，问题多半在那条内容本身（已删除、地区限制、需要登录），需要登录的走 [登录才能看的内容怎么下载.md](登录才能看的内容怎么下载.md)。

## 五、下完了但找不到文件

1. 先看「下载历史」里那一项记录的路径，比自己在文件管理器里翻快得多。
2. 再回设置里确认默认下载目录到底是哪个 —— 换过存储卡或改过设置后，最容易出现「以为在 A，其实在 B」。
3. 如果开了按章节拆分、或同时另存了一份音频，一次任务会产出多个文件，别只看第一个。
4. 排除自定义文件名模板的影响：模板里带字节截断或子目录时，实际文件名与标题并不一致。模板写法见 [内置终端和自定义命令.md](内置终端和自定义命令.md)。

## 六、下完了却放不出来

文件在、但播放器不认，通常是容器或编码的问题，不是文件坏了：

- 换一个支持面更广的播放器先验证文件本身；
- 如果确认是容器的问题，回下载卡片把容器改成设备支持的格式再下一次；
- 想转码时优先用「重编码」，但要清楚这是有损操作，只在必要时做。

同类问题还有字幕与音轨：字幕没嵌进去、音轨选错了，都在下载卡片那一支里调，见 [下载卡片怎么配置音视频.md](下载卡片怎么配置音视频.md)。

## 七、排了定时/追更但到点没动静

这类问题的根源几乎总是系统的后台限制，不是队列坏了：

1. 进系统「设置 → 应用 → YTDLnis」，把电池相关的策略改成「不受限制」或加进白名单；
2. 部分机型在手机管家里还有一层「后台运行管理」，要一并放行；
3. 别用第三方清理工具冻结它的后台进程，被冻结后的表现就是「排了但不动」；
4. 做完这些再看队列里的定时项，必要时点「立即开始」验证一次。

## 八、iOS 版、同名包与渠道辨识

- **没有 iOS 版，也不会有。** 官方明确说明不做 iOS / iPadOS，也没有移植计划；官方还特别点名，任何自称「YTDLnis for iOS」的产品都与它无关，属于骗局。
- **应用商店里搜到的一律不是它。** 官方不上 Google Play，原因是 yt-dlp 这类工具与 Play 的内容政策冲突。
- **看到「汉化版 / 增强版」要警惕。** 这个应用自带多语言（含中文），本身免费、无广告、无需注册，不存在需要额外汉化的理由。
- 核对正版看两点：包名必须是 `com.deniscerri.ytdl`；签名摘要要与官方公开的一致（见 [下载与安装教程.md](下载与安装教程.md) 第五节）。

## 九、想反馈问题去哪

官方的首选渠道是 GitHub 的 issue 区，提之前先搜一遍已有的，避免重复；其次是官方社群频道。提问题时把「出错」分区里的那份日志一起贴上，比只描述现象有用得多。写日志前注意：日志里可能带有你账号相关的信息，贴出去前先看一眼。
