下载卡片是这个应用里配置量最大的一个界面，音频与视频两支各有一串选项。绝大多数选项只在特定场景下才需要动，其余保持默认反而画质音质最好。这篇按「你什么时候会用到它」来分组，每个选项都给出建议值或判断依据。

## 一、先分清下载卡片里的三种下载类型

打开下载卡片后，顶层有三种下载类型：音频、视频、命令。下面讲前两支；命令那一支完全是另一套玩法，见 [内置终端和自定义命令.md](内置终端和自定义命令.md)。

两支里有几个概念是共通的：

- **容器（Container）**：把文件装进哪种封装格式，相当于换壳。换壳不增加信息量，只解决「你的播放设备认不认这个壳」的问题。
- **清晰度 / 音质**：真正决定拿到什么码率的原始流，由你在设置里配好的偏好决定，卡片上这一栏是展示与临场改动用。
- **标题、作者**：进卡片时已由取数据过程自动填好。留空则不改写原始元数据，保留原样。

容器这一栏最容易选错，先记住这张对照表：

| 容器 | 什么时候选它 |
| --- | --- |
| mp4 | 要在电视、车机、老播放器上放，兼容性最省心 |
| mkv | 要同时装多条字幕或多条音轨 |
| webm | 源站本来就是这种原样格式，不打算动它 |
| m4a、opus | 音频的原样格式，音质与体积的平衡最好 |
| mp3 | 只在你手上的播放设备完全不认 m4a / opus 时才转，属于有损操作 |

判断原则只有一条：**能原样留就原样留**。换容器不增加信息量，只在设备不认时才有意义。

## 二、音频这一支

想要一段纯声音（歌、播客、讲座），选音频类型。可调的项：

| 选项 | 作用 | 什么时候开 |
| --- | --- | --- |
| 容器 | 把音频转封装成指定格式 | 播放设备不认原始格式时才转 |
| 音质 | 展示当前选中的格式，可临场切换 | 想对照大小与编码挑一条时 |
| 封面图 | 把视频缩略图写进音频作封面 | 想在音乐播放器里看到封面 |
| 方形封面 | 把封面裁成正方形 | 配合上一条，更像正规专辑封面 |
| 按章节拆分 | 有章节的音频按章节切成多个文件 | 下一整张专辑/合集视频，想一首一首分开 |
| SponsorBlock | 去掉赞助段等非正片内容 | 见第五节 |
| 文件名模板 | 控制输出文件名 | 见第六节 |
| 额外命令 | 追加原始 yt-dlp 参数 | 见 [内置终端和自定义命令.md](内置终端和自定义命令.md) |
| 截取 | 只下某一段时间 | 见第四节 |

**关于音质，有一条要先破除误解**：很多「YouTube 转 MP3 320kbps」的说法是不成立的 —— 源站本来就不提供 MP3，只给 m4a 或 opus。所以「转成 MP3」这一步只会损失质量，不会凭空变好。除非你的播放设备确实不认 m4a / opus，否则容器这一栏建议保持原样。

## 三、视频这一支

要画面时选视频类型。除了容器与清晰度，可调的项多了起来：

- **保存缩略图**：在视频旁边额外存一份封面图，格式在设置里配。
- **写入章节**：原视频有章节的话，把章节写进文件元数据；如果同时开了 SponsorBlock，赞助段章节也会一并写入。
- **按章节拆分**：按章节把视频切成多个文件，适合「一集讲十个产品」这类结构化的长视频。
- **字幕**：三种做法任选 ——
  - **嵌入字幕**：把字幕流压进视频里；
  - **另存字幕**：把字幕作为单独文件存在视频旁边，格式在设置里配；
  - **另存自动字幕**：把源站给出的自动字幕也存下来。
  - 注意组合关系：**嵌入默认不包含自动字幕**；要让自动字幕也进到视频里，得同时开「另存自动字幕」+「嵌入字幕」。
- **音频**：可以「去掉声音」（做成静音视频），也可以「同时另存一份音频」（点下载时按音频设置额外生成一条下载项）。
- **重编码**：需要换编码格式时才用，属于有损操作，非必要不要开。
- **SponsorBlock**、**文件名模板**、**额外命令**、**截取**：同音频那一支，见后面几节。

字幕语言怎么配在设置里单独有一项，不是在这张卡片上选。

## 四、只下其中一段：截取

截取用来把一整条视频里的某一段单独拿出来。可以一次设多段，一段就是一个起止时间。

卡片上有一个「在切点处强制关键帧」的开关，作用是把切点对齐到关键帧，让切出来的片子更精确。代价是处理过程明显变慢，长视频尤其明显。官方注明这条依赖 yt-dlp 的实验性功能，个别情况下可能不生效 —— 追求速度就别开，追求精确再开。

## 五、去掉赞助段与片头片尾：SponsorBlock

SponsorBlock 是一个公开的众包标记库，靠社区标注出视频里哪些片段是赞助、片头、片尾等。开启后，被标记的片段会在下载时被去掉（也可以选择作为章节写入）。

可标记并去掉的类别包括：非音乐部分、赞助、片头、片尾、自我推广、预告、填充内容、订阅提醒。

什么时候值得开：

- **下音乐**：能自动剪掉「本期视频由某某赞助」这类插播；
- **下教程/长视频**：能省掉固定片头和片尾。

什么时候别开：内容本身就是讲广告、讲营销的，剪掉后反而不完整。标记来自社区众包，冷门内容可能没标注，这时开了也不会有变化。

## 六、文件名与子目录

文件名由「文件名模板」控制，用的是 yt-dlp 的标签写法，例如：

```text
%(uploader).30B - %(title).170B
```
这条的含义是：取上传者名字、长度不超过 30 字节，取标题、长度不超过 170 字节，中间用连字符连接，输出类似 `Eminem - Rap God`。字节截断能防住超长标题导致的文件名过长问题。

想把文件收进子目录，直接写成路径形式：

```text
mysubfoldername/%(title)s
```

这样会在你设定的下载目录下先建 `mysubfoldername` 文件夹，再以标题为名放进去。子目录名也可以用标签，比如用播放列表名当子目录：

```text
%(playlist)s/%(title)s
```

文件扩展名由应用自动补上，模板里不用写 `%(ext)s`。

## 七、想更高音质，先看这条

源站对音频质量有硬上限，改应用里的设置突破不了。以 YouTube 为例：

- 最高音质需要你自己有 Premium 订阅，并且让应用带着你的登录凭证去取，否则拿不到那条更高码率的流；
- 常规情况下能拿到的上限是 128kbps 一档，有订阅时是它的两倍左右（约 256kbps，即格式 id `141`）；
- 再往上「转容器 / 选更高音质」都不会有效果，要么没变化，要么反而更差。

登录凭证也就是 Cookie 的用法，见 [登录才能看的内容怎么下载.md](登录才能看的内容怎么下载.md)。

## 八、配置改错了怎么办

下载卡片上的改动只对当前这一项生效，不会污染全局设置，所以可以放心试。要是想恢复默认，把卡片关掉重新点一次那一项即可。真正影响所有下载的偏好（默认格式、默认清晰度、默认字幕语言、默认下载目录）都在「更多 → 设置」里，改之前先想清楚。
