## 一、一句话看懂两者的分工

快捷指令是你**自己存的模板**（最多 20 条，手动增删），历史指令是软件**替你记的流水**（最近 50 条，自动滚动覆盖）。前者解决「天天要打的指令不想重敲」，后者解决「昨天那条查询指令是什么来着」。你在手机上敲黑屏指令的大部分操作，最后都落到这两张列表上。

## 二、怎么发一条指令

手机键盘没有电脑上的 F12 和小 Enter 键，所以 iEterm 的发送方式改成了屏幕上的按钮（官方使用帮助三）：

1. 点击屏幕调出键盘，输入指令。
2. 点**屏幕上方的发送按钮**发出，或点键盘上的 `send` 键。
3. 返回结果出来后，按住屏幕上下滚动查看。
4. 需要**多行指令**时，点发送按钮旁边的**回车按钮**切换换行。

## 三、快捷指令：最多 20 条的自定义模板

按官方使用帮助六操作：

1. 展开菜单，点击**快捷列表**。
2. 点击**首行的添加项**，输入要保存的指令，点**保存**。
3. 之后在列表里**点一条**，它会自动插进输入框——可以直接发，也可以改几个字再发。
4. **长按**某条弹出删除提示，即可删掉它。

用法建议：把 `AV` 查座位、`PNR` 提取这类每天重复的指令存进去，出行程高峰期时省的是逐字重敲的时间。

### 存什么进快捷列表

存「骨架不变、只改日期数字」的模板最划算。中国航信 BSP 操作文档里的两个标准格式可以直接当模板：

```text
AV:PEKSHA/29MAY        查询北京—上海某日航班座位可利用情况
SK:PEKSHA/10JUN/CA     查询某城市对前后三天内指定航司的航班时刻
```

存进快捷列表后，点进输入框把日期改一改就能发——指令格式与电脑版 eTerm 完全一致（官网「关于我们」页的原话是「指令输入以及格式均与 eTerm 无任何差异」）。反过来，一次性、带大量客户数据的指令不必存模板，走历史指令更合适。

## 四、历史指令：最近 50 条自动留存

按官方使用帮助五：

- 软件自动记录你执行过的指令，**保留最近 50 条**，超出后循环覆盖最早的（百科资料与官方帮助口径一致）。
- **退出软件后历史指令不消失**，下次登录照样在。
- 展开菜单点**历史**，查看列表；**点一条**自动插入输入框，可编辑后再发。
- **长按**某条弹出删除提示，可以手动清掉不想留着的记录（比如含客户信息的查询指令）。

## 五、两张表的边界

| | 快捷指令 | 历史指令 |
| --- | --- | --- |
| 上限 | 20 条 | 50 条 |
| 谁写入 | 你手动添加 | 软件自动记录 |
| 会过期吗 | 不删就一直在 | 超 50 条循环覆盖 |
| 删除方式 | 长按删除 | 长按删除 |
| 退出后 | 保留 | 保留 |

两张表都是「点一下插入输入框、长按删除」，逻辑完全一样，上手成本基本为零。指令发出去之前，账号和服务器得先处于正常登录状态——那部分见 [登录与服务器地址设置.md](登录与服务器地址设置.md)。
