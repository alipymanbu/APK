## 一、两组测试分别测什么

主界面上有两个入口：

| 入口 | 测什么 | 安卓上用到的 API |
| --- | --- | --- |
| CPU Benchmark | 处理器与内存性能，分单核、多核两段 | 无（CPU 原生任务） |
| GPU Compute Benchmark | GPU 的运算性能（不是游戏帧率） | OpenCL、Vulkan |

几点先说清楚：

- CPU 部分分**单核**与**多核**两段，两段里都是整数与浮点两类任务，题目模仿真实应用场景：网页渲染、PDF 处理、照片整理与修图、文件压缩、物体检测、光线追踪等；
- GPU Compute 测的是 GPU「算东西」的能力——图像处理、计算机视觉、机器学习这类任务，**不等于**游戏里的图形渲染性能，两个数不能互相替代；
- OpenCL 和 Vulkan 各出一套分，同一块 GPU 在两个 API 下分数不同，跟别人比时要用同一个 API 的数。

## 二、跑分步骤

1. 打开 Geekbench 6；
2. 点 CPU Benchmark 卡片右侧的 **Run Benchmarks**；
3. 测试自动进行，页面会逐项显示正在跑的任务，全程保持应用在前台、屏幕常亮，CPU 一轮要几分钟（设备不同差别不小）；
4. 跑完自动进结果页：顶部是单核与多核两个总分，下面是逐项分数；
5. 想测 GPU 就回到主界面，点 GPU Compute Benchmark 右侧的 Run Benchmarks，流程一样，再花几分钟。

另外，6.2.0 起安卓版加入了历史记录与对比功能（你这份 6.3.0 包含）：测过的分数会留在应用里，能直接跟上一轮比，不用自己拿纸笔记录。

## 三、怎么跑出有参考价值的分

同一台手机两次测试差出几个百分点很常见，测之前：

- 电量充到一半以上，或者插着电跑；别开省电模式；
- 让手机凉一会儿再测，刚打完游戏、看完长视频就测，分数会明显偏低；
- 清一遍后台再开测；
- 测的过程别切出应用、别锁屏；
- 要拿去对比或发帖，跑 2~3 次，取最好那次或取大致水平，并注明「多次测试」。

温度高、电量低、后台拥挤都会把分往下压；分数反常地低、波动大时的系统排查见[分数不稳定怎么排查.md](分数不稳定怎么排查.md)。

## 四、要等多久

- CPU 一轮几分钟；核心数多的设备，多核那段会明显更久；
- GPU Compute 也是几分钟的量级；
- 任务与任务之间有短暂停顿，属于正常节奏，不是卡住——干等就行，别中途退出。
