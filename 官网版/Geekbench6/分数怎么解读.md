## 一、先看两个总分

结果页顶部是两个数：

- **Single-Core Score（单核）**：只用一个核心时的整体表现，影响日常单线程操作的响应速度；
- **Multi-Core Score（多核）**：所有核心一起上的表现，影响多任务、视频导出这类并行场景。

读数规则：

- 分数越高越好，**分数翻倍就是性能翻倍**，这是官方的标定口径；
- Geekbench 6 的 2500 分对齐的是 Intel Core i7-12700（官方口径为一台 Dell Precision 3460 工作站的得分），这是官方给的分数量尺起点；
- 具体某台手机该跑多少分，不用背数字，直接查官方安卓榜单（见第四节），榜单实时更新，比任何写死的区间都准。

## 二、逐项分比总分更有信息量

总分下面是逐项分，每个任务一行，各带自己的单位：

| 举例任务 | 单位形式 | 对应的实际场景 |
| --- | --- | --- |
| File Compression（文件压缩） | MB/秒 | 传输、打包大文件 |
| Photo Library / Photo Filter（照片类） | 张/秒 | 相册整理、修图 |
| HTML5 Browser（网页） | 页/秒 | 浏览器渲染 |
| PDF Renderer（PDF 渲染） | 百万像素/秒 | 看文档、导出文档 |
| Object Detection（物体检测） | 张/秒 | 相机识别、AI 功能 |

读法：按你自己的用法找行。经常修图就看照片那几行，经常传文件就看压缩那行——总分高的设备在某一项上被另一台反超很正常，逐项分才能看出这种差别。

## 三、GPU Compute 分数单独看

- GPU Compute 的结果与 CPU 分开列出，分 **OpenCL** 与 **Vulkan** 两套；
- 同一块 GPU 在两个 API 下分数可以差出不少，对比时必须用同一个 API 的数；
- 这个分数反映的是 GPU 参与图像处理、视觉与机器学习运算的能力，别直接当游戏性能用。

## 四、跟别的设备比

1. **结果页链接**：联网测完后结果会上传到 Geekbench Browser，得到一个可分享的网页链接，里面是逐项分与设备信息；入口在 [browser.geekbench.com](https://browser.geekbench.com/)；
2. **安卓榜单**：官方 [Android Benchmarks](https://browser.geekbench.com/android-benchmarks) 页面按用户提交的数据列出单核、多核、OpenCL、Vulkan 四张榜单；提交数少于 5 台的设备不上榜，冷门机型查不到属于正常；
3. 榜单实时变动，名次以打开页面当时为准。

## 五、只能同版本互比

Geekbench 6 的分数**只能跟 Geekbench 6 的分数比**。官网现在主推 Geekbench 7，6 已被官方归入 legacy（旧版本），Geekbench Browser 的结果页会明确标注这一点。

不能跨版本比的根本原因是：每换一代，量尺就重新标定一次——5 代以 1000 分对齐 Core i3-8100，6 代以 2500 分对齐 Core i7-12700，7 代以 2500 分对齐 Ryzen 7 7700。数字看着差不多，含义完全不同，官方也没给换算关系。

拿别人的分来比之前，先问一句对方用的哪个版本；版本对不上，要么找同版本的结果，要么两边用同一版本各跑一次。至于 Geekbench 与安兔兔这类跨工具的对比，更是两套量尺，见[和安兔兔跑分的区别.md](和安兔兔跑分的区别.md)。
