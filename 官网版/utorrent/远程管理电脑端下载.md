大文件更适合丢给家里一直开着的电脑挂机下载，人带着手机出门，路上随时看进度、暂停、加任务。做法是电脑端开 Web UI、手机浏览器登录管理（多数资料也提到安卓版带 BitTorrent Remote 远程管理能力，入口以你装的版本实际界面为准）。前提只有一个：**手机和电脑连同一个 Wi-Fi**。

## 一、先在电脑上把 Web UI 打开

电脑端的 µTorrent（或 BitTorrent）就是「被控端」，设置一次即可：

1. 打开电脑端 µTorrent。
2. 进入设置/偏好（菜单在 Options → Preferences 附近，不同版本入口略有差异）。
3. 找到 **Web UI** 一页（部分版本在 Advanced 分组下）。
4. 勾选 **Enable Web UI**。
5. 自己定一组**用户名和密码**（存在电脑本地，不是官方账号）。
6. 记下端口号，常见默认是 **8080**；改过就记你改的那个。

验证：在这台电脑的浏览器里访问 `http://localhost:8080/gui/`，能弹出你刚设的用户名密码并进入管理页，说明服务已生效。

## 二、手机上怎么连

1. 手机连到与电脑**相同的 Wi-Fi**。
2. 查电脑在局域网里的 IP（Windows 可用 `ipconfig` 看 IPv4 地址，形如 `192.168.1.100`）。
3. 手机浏览器访问 `http://192.168.1.100:8080/gui/`（IP 和端口换成你自己的）。
4. 输入第一步设置的用户名密码，就能看到电脑端的任务列表。

登录后可以做的事与电脑端一致：看进度与速度、暂停/继续、删除任务、直接粘贴磁力链接添加新任务（磁力链接的写法见 [磁力链接与种子下载方法.md](磁力链接与种子下载方法.md)，两端通用）。

## 三、连不上时按这个顺序查

| 现象 | 先查什么 | 处理 |
| --- | --- | --- |
| 页面打不开 | 电脑端 µTorrent 是否在运行 | 电脑端必须开着且联网 |
| 提示密码错误 | 用户名/密码是否输入错误 | 回电脑端 Web UI 设置里重设 |
| 局域网外连不上 | 是否不在同一网络 | 默认仅限同一 Wi-Fi 内访问；跨网络属高级用法，需自行研究路由器端口映射并评估风险 |
| IP 变了连不上 | 电脑 IP 是否被路由器重新分配 | 给电脑设静态 IP 或在路由器里做地址绑定 |

## 四、安全注意

- Web UI 的账号密码**一定要设**，空密码等于把下载控制权开放给同网段所有设备；
- 密码别与其他网站复用；
- 不用时可在电脑端关掉 Enable Web UI；
- 公共 Wi-Fi 下不要登录自家 Web UI（同网段的人都可能扫到端口）。

## 五、两端怎么分工

- **手机端**（本套文档主角）：自带下载能力，见 [下载与安装教程.md](下载与安装教程.md)；适合小文件与临时下载；
- **电脑端**：存储大、常开着，适合大文件挂机；手机远程管理它，见本篇。

两端速度优化思路一致，可参照 [下载速度设置与提速.md](下载速度设置与提速.md)。
