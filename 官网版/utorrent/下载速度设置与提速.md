µTorrent 本身对速度没有硬性上限，实际速度主要由三件事决定：应用内的限速设置、资源的热度、你用的网络。本篇逐项过一遍。

## 一、先确认两个限速没被卡住

应用内可以自己给速度设上限，如果你之前手动调过或不确定有没有调过，先来这两处确认。检查路径：

1. 打开 µTorrent，点左上角三横线菜单。
2. 进入 **Settings**。
3. 找到 **Download Limit**（下载限速）与 **Upload Limit**（上传限速）。
4. 把滑杆调到最大或直接填 **0** —— 0 表示不限速。
5. 点 **SET** 保存，之后的新任务按新上限跑。

这两项是速度问题里最容易被忽略的：它们只影响 µTorrent 自己，你不会感觉到手机网变慢，只会觉得「这个应用下载慢」。

## 二、同时下载的任务数

同时跑的任务越多，每个任务分到的带宽和连接数越少。设置里有活跃任务数（Active torrents 一类的选项）可以限制同时下载的数量：

- 同时下 1~2 个大文件时，单个任务通常能跑出更高速度；
- 一次挂十几个任务，热门资源反而会被摊薄。

社区常见的建议是一次保持 3~5 个热门任务，具体数值以你的带宽和习惯为准。

## 三、网络怎么选

| 网络 | 适合 | 注意 |
| --- | --- | --- |
| Wi-Fi | 大文件、挂机下载 | 首选；速度稳定、不耗流量 |
| 移动数据 | 小文件应急 | 大文件耗流量快；部分运营商对 P2P 流量有限速 |

应用内置 **仅 Wi-Fi 模式**（Wi-Fi only）：开启后离开 Wi-Fi 就自动暂停所有任务，回到 Wi-Fi 再自动继续。挂机下大文件建议开着它，防止流量账单出意外。该开关在设置里，逐个任务的开关也可能有，加任务时留意一下。

## 四、速度上不去的排查顺序

| 现象 | 先查什么 | 处理 |
| --- | --- | --- |
| 所有任务都慢 | 限速设置（第一节） | Download/Upload Limit 设为 0，确认生效 |
| 单个任务慢，别的正常 | 这个任务做种数 | 冷门资源换热门源；做种数为 0 的任务无解 |
| Wi-Fi 快、流量慢 | 运营商 P2P 策略 | 换 Wi-Fi 下载；仅 Wi-Fi 模式开着就不会用流量 |
| 锁屏就停 | 系统省电策略 | 见 [常见问题与解决方法.md](常见问题与解决方法.md) 后台一节 |
| 下载慢且网内其他设备也卡 | 上传是否跑满带宽 | Upload Limit 设一个上限（如总带宽的七八成），给下载和上网让路 |
| 任务列表卡满 | 同时任务数过多 | 暂停一部分，减少并发 |

按表从上往下排，绝大多数「慢」都能归到其中一行。任务本身加不上或反复失败的情况，另见 [磁力链接与种子下载方法.md](磁力链接与种子下载方法.md) 与 [常见问题与解决方法.md](常见问题与解决方法.md)。
