## 三、APK 安装步骤

用网盘里的 APK 安装时，流程如下：

1. 把 APK 文件下载到手机存储（网盘转存后在手机端下载）。
2. 在文件管理器里点开这个 APK，系统会提示「不允许安装未知来源应用」。
3. 按提示跳转到系统设置，允许你的文件管理器（或浏览器）安装应用；不同品牌手机的入口在「设置 → 应用 → 特殊应用权限 → 安装未知应用」附近，以你的手机实际菜单为准。
4. 返回继续安装，完成后点「打开」。

安装包 40.72M，另给下载目录留出足够空间即可，无需 root 权限。

**可选：核对安装包完整性。** 如果下载后安装反复失败，怀疑文件损坏，可以用支持 MD5 校验的工具应用比对安装包指纹，这份安装包的 MD5 应为 `D3F6201EAEC8A122D8D2348F339316DF`；对不上就说明文件在传输中损坏了，重新下载一遍再装。

## 四、首次启动要过的几道提示

第一次打开 µTorrent 会依次遇到：

1. **数据共享选择**：询问是否分享使用数据，选允许或拒绝都不影响使用。
2. **存储权限**：必须允许，否则应用读不到 APK、也存不下下载的文件。
3. **位置权限**：可以拒绝，下载功能不依赖它。

提示都过完后进入主界面，下一个动作就是添加下载任务，具体见 [磁力链接与种子下载方法.md](磁力链接与种子下载方法.md)。

## 五、免费版与 Pro 版

安卓版分两档，功能差异如下：

| 项目 | 免费版 | Pro 版 |
| --- | --- | --- |
| 下载功能 | 完整 | 完整（与免费版相同） |
| 广告 | 有横幅广告 | 无 |
| 电池保护 | 无 | 电量低于设定值时自动暂停下载任务 |
| 自动关闭 | 无 | 下载完成且应用在后台时自动停止，省电省流量 |

官方下载页对 Pro 标价 $2.99，价格以 [官方页面](https://www.utorrent.com/downloads/android/) 当前显示为准。本套文档其余内容对两档都适用。
