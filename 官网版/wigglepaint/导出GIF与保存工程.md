# WigglyPaint 导出 GIF 与保存工程文件

> 本篇讲 WigglyPaint 的两种保存方式：把作品导出成 GIF 图，以及把工程存成 .deck 以后接着画；顺带说说网页版"存成单个 HTML"的离线玩法。

## 一、导出 GIF（发出去用的成品）

1. 点画布左下角的「EXPORT」按钮；
2. 点「Save」；
3. 选手机里的文件夹（也可以新建一个）；
4. 把文件名改成 `xxx.gif`（带上 .gif 后缀）；
5. 点「保存」。

存完去相册里找，或者到刚才选的存储路径里翻。GIF 会保留线条的抖动动效，直接发聊天、社交平台都能动。导出后文件找不到、或存出来不会动，见[常见问题排查.md](常见问题排查.md)。

## 二、保存工程文件（.deck，以后接着画）

GIF 是成品，工程文件是"能继续改的底稿"：

1. 点左上角的「File」菜单；
2. 点「Save As」；
3. 选好文件夹，把文件名改成 `xxx.deck`；
4. 点「Save」。

下次想接着画，从「File」菜单点「Open」，选中之前那个 .deck 文件就能回到画布继续。认真画点东西的话，建议画到一半就存一次 .deck——别指望画布一直替你留着，中途应用被系统清掉、手机切后台过久，未保存的内容就没了。存好之后怎么打开、怎么传到电脑接着画，见 [deck工程文件怎么打开.md](deck工程文件怎么打开.md)。

## 三、网页版还有一个"单文件"玩法

网页版（手机浏览器也能开）支持把整个工具连同当前内容存成一个独立 HTML：在「File」菜单里选「Save As...」，文件名以 `.html` 结尾，保存后得到一个可以永久离线打开的网页文件。这是原版官方给的使用方式，适合不想装应用、又想离线用的人。安卓安装包同样不用注册账号，画画与保存都在你自己的设备上完成。

## 四、GIF 导出后往哪用

动图表情、群聊斗图、社交平台的动态贴，GIF 都是通用的。要是发现某个平台把 GIF 转成了静图、或压缩得厉害，换个对动图友好的发布入口通常就能解决——这不是文件本身出了问题。
