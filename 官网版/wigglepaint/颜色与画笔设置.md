## 一、改颜色的总入口：options 窗口

颜色、背景这些设置不在画布上直接改，而是在 options 窗口里：

1. 在画板界面点下方的「options」按钮；
2. 在弹出的设置窗口里改颜色、背景等各项设置；
3. 改完点「apply」应用；
4. 回到画布，新设置即可生效。

改完不满意，随时再进 options 调回来。已画上去的线条一般不会因为你换了颜色而跟着变——想让某根线换色，直接撤销重画往往更快。

## 二、options 窗口里有什么

点开 options 后，设置分几块：勾选透明背景、选预设调色板、填具体色值，旁边还有一处预览。

- **预设调色板**：每套调色板包含背景色、前景色和三支蜡笔各自的颜色，点选后界面立即切换（新版网页版备了 27 套，这份 v1.3 界面里有几套以实际显示为准）；
- **色值输入**：想要更精确的颜色，直接填十六进制色值（形如 `#FF4FA3`），比在色板里凑更准；
- 全部改完点右下角「Apply」保存返回。

另有一个顺手的设定：保存前把调色板设成常用的那套，下次打开会直接沿用（作者确认过的行为，细节见 [deck工程文件怎么打开.md](deck工程文件怎么打开.md)第四节）。

## 三、右侧工具列逐个说

| 工具 | 大致用途 |
| --- | --- |
| Pen（钢笔）/ Pencil（铅笔）/ Marker（马克笔）/ Brush（画刷） | 四种常规笔触，粗细与质感各有差异 |
| Spray gun（喷枪） | 喷雾状的散点笔触 |
| pink / cyan / yellow 蜡笔 | 三支以颜色名标注的蜡笔，实际颜色跟随调色板设置 |
| 橡皮擦 | 擦掉不要的线条 |

笔尖粗细不靠工具本身区分，而是用画布下方的「marker size」按钮调节：画细节调小、铺大面积调大。各笔触的实际差异，各画两笔对比最直观——这个工具的乐趣本来就在试。

## 四、透明背景与背景色

打算把作品叠到别处用（比如当聊天表情贴纸），在 options 里勾选透明背景，导出时背景就是透明的；不勾则是纯色背景，颜色由当前调色板的背景色决定。两种随时可切，画的过程中换背景不影响已经画好的内容。

## 五、改不动时的检查点

- 设置改了但画布没变化：确认点了「apply」，而不是直接关掉窗口；
- 找不到想要的预设调色板：列表比较长，先滚完整个列表再下结论；
- 整个界面找不到 options 按钮：这份安卓包内置的是 v1.3 时期界面，个别按钮位置与网上新版教程的截图对不上属正常，操作以本篇描述为准。
