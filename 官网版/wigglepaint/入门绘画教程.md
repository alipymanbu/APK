## 一、为什么你画的线会自己动

WigglyPaint 的核心效果是"线条沸腾"（line boil）：你落下的每一笔，都会在相邻帧之间轻微错位重画——静止看是一幅画，动起来就是那种手绘动画特有的、微微发抖的质感。你不需要做任何动画设置，正常画就行，效果是自动的；画完存成 GIF，这种抖动会被原样保留。

这套玩法与 KidPix、Shake Art 这类涂鸦工具气质相近：不追求精确作画，追求随手涂出来的活气。

## 二、认识界面

打开应用，先看到标题画面，点「Let's Draw!」进入画布。

进入画布后界面是英文的，顶部一排是 Decker 的标准菜单栏：

| 菜单 | 你会用它做什么 |
| --- | --- |
| File | 打开、保存工程文件（.deck） |
| Edit | 撤销、重做 |
| Tool / Card / Decker / Help | 工具与其他辅助功能，用得少 |

布局是固定的：右侧一列是画笔工具，从上到下是钢笔、铅笔、马克笔、画刷、喷枪等笔类，往下是 pink、cyan、yellow 三支蜡笔和橡皮擦；画布下方一排功能按钮，从左到右是 EXPORT、CROP、options、OOPS!、marker size，最右边的 OBLITERATE 一键清空整幅画。中间的大块空白就是画布。各画笔与 options 的细节见[颜色与画笔设置.md](颜色与画笔设置.md)。

这份安卓安装包内置的是 v1.3 时期的工具界面，与最新网页版的界面会有少量差异。

## 三、画第一幅会动的画

官方对使用流程的概括就一句话：选工具、随手画、按需裁剪、存 GIF。对应到操作上：

1. 从画布右侧的工具列选一支画笔（各类画笔的差别见[颜色与画笔设置.md](颜色与画笔设置.md)）；
2. 用手指在画布上涂画，线条会以抖动状态实时呈现；
3. 画错了点画布下方的「OOPS!」撤销（比绕去 Edit 菜单快），改到满意为止；
4. 想让成品只保留画面的一部分，点「CROP」裁剪：上下左右四个方向各有数值调节器，拿不准边界就点「Tight Fit」让四周自动贴住画的内容，最后「Apply」确认；
5. 从 EXPORT 出口把作品存成 GIF（完整步骤见[导出GIF与保存工程.md](导出GIF与保存工程.md)）。

## 四、手机上画，注意这两点

- **横过来画**：这套界面是横版桌面式布局（和电脑网页版一样），竖屏时会显得挤，横屏会舒服很多；
- **落笔放慢**：触屏比鼠标更容易抖，抖动效果还会把你的手抖放大。画细节时把线画得比预期更"松弛"一点，出来的效果反而更自然。

## 五、画什么最出效果

从社区里大家实际画的内容看，出效果的多是这几类：简笔小人、表情包、带一句台词的涂鸦、随手签名。共同点是线条少、轮廓大——抖动效果靠线条的错位感撑场面，画面越简单，抖得越明显、越可爱。线条太密太细的写实画，抖起来反而显乱。
