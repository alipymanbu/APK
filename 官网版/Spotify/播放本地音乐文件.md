# Spotify 播放本地音乐文件

> 本篇讲怎么让手机里的自有音频文件也出现在 Spotify 里播放：安卓和电脑端各自的开关位置、怎么把文件传进手机、放不出来时的排查。

## 一、这个功能和离线下载不是一回事

应用除了播它曲库里的歌，也能播放你自己存在设备上的音频文件。两个容易混的点先说清：

- 本地文件走的是**你手机里已有的文件**，不占用离线下载的额度，也不需要会员资格；
- 反过来，它也**不能**把本地文件变成云端曲库的一部分——换设备后要重新导入。

适用前提只有一条：文件是你合法拥有的（自己翻录、购买下载的音频等）。

## 二、安卓端：打开本地文件开关

1. 点右上角头像；
2. 进「设置与隐私」；
3. 进「应用与设备」（Apps and devices）；
4. 打开「本地音频文件」（Local audio files）开关；
5. 回到「资料库」，会出现一个「本地文件」（Local Files）文件夹，里面就是设备上扫到的音频。

第一次打开时系统可能要你授予文件访问权限，允许即可。

## 三、怎么把文件传进安卓手机

文件得先在手机存储里，应用才会扫到。常用三种来路：

| 来路 | 做法 |
| --- | --- |
| 电脑 USB 传输 | 手机解锁 → 数据线连接 → 在手机上点「允许访问数据」通知 → 电脑上选「打开设备以查看文件」→ 把音频拖进去 → 完成后安全弹出再拔线 |
| 网盘 / 云盘类应用 | 在能管理文件的应用（如 Google Drive）里找到文件，用「下载」存到本机 |
| Mac 用户 | 先装一个安卓文件传输工具，再通过数据线拷贝 |

传完回到应用刷新资料库，「本地文件」文件夹里应该能看到新文件；没看到的先检查文件格式是不是常见音频格式、路径是不是在媒体目录下。

## 四、电脑端：指定扫描文件夹

电脑端比手机端灵活，可以自己指定从哪些文件夹扫：

1. 点右上角头像，选「设置」；
2. 滚到「资料库」（Library），打开「显示本地文件」（Show Local Files）；
3. 在「显示歌曲来源」里勾选要扫的默认文件夹，或点「添加来源」（Add a source）指定别的文件夹；
4. 打开「资料库」，本地内容在「本地文件」里。

把下载目录、音乐目录逐个加进来是常见用法；不想让它扫某个盘，把对应来源关掉即可。

## 五、放不出来时的排查

本地文件不显示或点了没反应，按这个顺序试：

1. 确认应用和系统都更新到当前版本；
2. 如果之前把本地文件加进过歌单，先把它们从歌单移除，再从头做一遍导入步骤；
3. 还不行就做一次彻底重装——注意这会清空全部离线下载，代价见 [播放问题排查.md](播放问题排查.md) 第六节；
4. 文件本身的问题也占一部分：损坏的文件、应用不支持的格式，换一个文件对比就能分辨。

一个相关的小设定：开「淡入淡出」（Crossfade）后，应用会在**采样率和声道数相同**的本地文件之间做平滑过渡，采样率不一致的两首之间不会生效，这常被误当成「功能坏了」。

想调音质、均衡器，看 [音质与播放设置.md](音质与播放设置.md)；本地文件占的存储怎么清，见 [离线下载与存储管理.md](离线下载与存储管理.md) 第五节。
