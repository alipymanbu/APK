## 一、先记下这份安装包的基准值

| 项目 | 参考值 |
| --- | --- |
| MD5 | E9AA8B2FB98378868334F6AB0474FAF6 |
| 文件大小 | 约 17.38M（18,224,113 字节） |
| 版本 | 1.0.1 |

这是本资源对应那份安装包的值。你下载到的文件算出的 MD5 与它一致，说明文件完整、逐字节相同；对不上则说明下载不完整或文件被换过。

## 二、在 Windows 电脑上校验

用系统自带的 `certutil` 即可，不需要安装任何工具（文件名以你实际下载到的为准）：

1. 按 Win 键输入 `cmd` 回车，打开命令提示符；
2. 输入 `certutil -hashfile `（结尾留一个空格），把 APK 文件从资源管理器拖进窗口，完整路径会自动填上；
3. 在命令末尾补上 ` MD5` 再回车：

```bat
certutil -hashfile "C:\Downloads\MangadeX_v1.0.1.apk" MD5
```

4. 输出的一串十六进制就是 MD5，与第一节表格逐位比对（大小写不敏感，每一位都要相同）。

不想逐位比对的话，用 PowerShell 一行判断，输出 `True` 即一致：

```powershell
(Get-FileHash "C:\Downloads\MangadeX_v1.0.1.apk" -Algorithm MD5).Hash -eq "E9AA8B2FB98378868334F6AB0474FAF6"
```

顺带一句：MD5 用来核对「文件是否下载完整」是够用的；更严谨的发布方会同时提供 SHA-256，本资源只给了 MD5，按上面的方法核对即可。

## 三、在手机上校验

- 部分文件管理器自带「文件校验 / MD5」功能，在文件的属性或更多菜单里找；
- 手机上不方便的话，把文件传到电脑按上一节的方法查，比装一个额外的校验应用更省事。

## 四、对不上时怎么办

1. 先重新下载一遍——最常见的原因是下载中断；
2. 重下后仍不一致，就不要安装这个文件，换一处获取或核对来源；
3. 顺手比一下文件大小：连字节数都对不上，基本可以断定不是同一份文件。
