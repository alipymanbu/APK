## 一、主界面的结构

一个总开关控制全局效果是否生效；总开关下面按模块分区，每个模块有自己的开关和参数页。调音的基本动作是：**让目标应用播着歌，回到 RootlessJamesDSP 里动参数，实时听变化**。

## 二、各模块一览

| 模块 | 管什么 | 什么时候用 |
| --- | --- | --- |
| 图形均衡器（任意响应） | 按频段拉曲线 | 调音的起点，大部分调整从这开始 |
| FIR 均衡器 | 插值型均衡，作用类似但算法不同 | 和图形均衡器二选一即可 |
| 动态低音增强 | 自动探测低频并增强 | 觉得低音发闷、下潜不够 |
| 动态范围压缩 | 压小响度差距 | 夜里听歌想让小声的细节也听得清 |
| 限制器 / 输出增益 | 控制最终输出电平 | 其他效果拉太猛时防削波爆音 |
| 卷积器 | 加载脉冲响应文件模拟空间或设备 | 想给声音加厅堂感、换「渲染」风格 |
| 虚拟空间混响 | 加房间混响 | 看电影、听现场想要空间感 |
| 立体声扩展 | 拉宽声场 | 觉得声音都挤在中间 |
| 串扰（Crossfeed） | 给耳机做左右声道混合 | 耳机听久了头中效应难受 |
| 电子管建模 | 加二次谐波 | 想要偏暖的老式音色 |
| ViPER-DDC | 按校正曲线修频响 | 手上有现成校正曲线文件时 |
| 实时可编程 DSP | 脚本自定义音效 | 进阶玩法，普通使用用不到 |

模块名称以你装的版本界面为准，不同版本措辞略有差别。

## 三、AutoEQ 耳机校准：建议第一个试的功能

RootlessJamesDSP 内置了 AutoEQ 集成。AutoEQ 是一个公开的耳机频响校正曲线库，收录了大量常见耳机型号的曲线，导入后把你耳机的频响往平直方向拉，比凭感觉拉均衡器省事得多。

操作路径：**任意响应均衡器（图形均衡器）→ Magnitude response → AutoEQ profiles**，在里面搜你的耳机型号，选中导入即可。曲线库在云端，搜索和导入需要网络可用。你的型号没被收录的话，只能手动调 EQ 或找频响接近的曲线参考。

## 四、推荐的调音顺序

1. 先用 AutoEQ 导入你耳机型号的校正曲线；没有就用图形均衡器把整体曲线拉到自己听着顺。
2. 再动「口味」类模块：动态低音、立体声扩展、混响，一次只开一个，对比着听。
3. 最后用限制器 / 输出增益收尾，防止前面叠出来的增益削波爆音。
4. 每次只改一处 —— 同时开五个模块，出了问题你根本不知道是谁的锅。

## 五、配置的保存与备份

调好的参数记得备份：应用的设置里提供配置备份的导出/导入，换机、重装或恢复出厂前先导出一份。界面主题同样在设置里切换，与音效参数互不影响。

## 六、调完还是不满意

先确认你调的对象支持处理：部分应用拿不到音频流，调什么都没用，对照 [兼容性与应用支持列表.md](兼容性与应用支持列表.md) 换个应用验证；参数乱到不想收拾，用备份功能恢复一份旧配置；持续没声音则去 [常见问题与故障排查.md](常见问题与故障排查.md)。
