# AdGuard 网站打不开或功能异常怎么放行

> 拦截过度的典型表现是页面空白、按钮点不动、登录跳转失败。本篇给四种放行方式和它们的取舍。

放行是拦截的反面，也是使用 AdGuard 必须会的一件事。判断方法很简单：**把这个网站或这个应用临时排除掉，问题立刻消失，就说明是过滤造成的**。确认之后，本篇给四种放行方式，从最省事的到最精细的，按你的实际需要选一种即可，不必全都用上。

## 一、先确认是不是 AdGuard 拦的

1. 在 AdGuard 首页把保护整体关掉，重开那个网站或应用试一次。
2. 问题消失 → 确实是过滤造成的，继续往下看。
3. 问题还在 → 与 AdGuard 无关，别在这里继续折腾。

想跳过「关了再开」这一步直接看是谁拦的，进「统计 → 最近活动」，把状态筛到「已拦截」、来源筛到「第一方」，最新那几条里通常就有出问题页面的请求，点开能看到具体规则，也能一键解除。完整读法见 [最近活动日志怎么读.md](最近活动日志怎么读.md)。

## 二、方式一：把网站加进白名单（最常用）

在 AdGuard 里，白名单叫「允许清单」。加进去的域名，AdGuard 不再对它做过滤。

- **路径**：「设置 → 过滤」下的允许清单入口（不同版本可能收在「网络」小节里），把域名一行一个填进去。
- **效果**：该域名下的广告与跟踪请求也不再被拦，属于整体放行。

**更快的做法是走 Assistant**：从通知栏展开 AdGuard 的常驻通知，点「Assistant」，切到「Websites」标签，选中刚才出问题的网站，点「加入允许清单」。这一步不用回主界面翻菜单，遇到临时问题最省事。

## 三、方式二：写一条只放行文档的用户规则（更精细）

白名单会把整个域名的广告一起放掉；如果你希望**这个站点正常打开，但广告照样拦**，可以用一条只解除「文档级拦截」的用户规则。

- **路径**：「设置 → 过滤 → 用户规则」，新增一条：

```text
@@||example.com^$document
```

- 把 `example.com` 换成出问题的域名，`@@` 表示例外规则，`$document` 把它限定在「不许拦这个页面本身」这一层。
- 用户规则属于完整版功能，未激活时界面上的「用户规则」入口不让你保存。

两种放行的区别值得记一下：

| 做法 | 网站能正常打开 | 该站广告仍被拦 |
| --- | --- | --- |
| 加入允许清单 | 是 | 否 |
| `@@||域名^$document` | 是 | 是 |

## 四、方式三：只排除这个应用

如果是某个应用打不开或提示联网失败，不必动网站设置，直接在应用这一层处理：

1. 进「应用管理」，点开那个应用。
2. 把它的**过滤应用内容**关掉，或者把它的**路由**从 AdGuard 上摘掉。
3. 官方对一部分应用本身就不建议路由过滤（例如下载管理器、部分系统应用），这类应用出问题时按上面两步处理即可。

## 五、方式四：单独关掉某个域名的 HTTPS 过滤

有些网站会因为流量被拆开检查而拒绝服务（自检到证书变化就断连）。这类情况可以让该域名**不被 HTTPS 过滤**，但请求层的过滤仍然生效。

- **路径**：「设置 → 过滤 → 网络 → HTTPS 过滤 → 排除项」。
- 该页有两种模式：把指定网站排除在 HTTPS 过滤之外，或只对指定的网站做 HTTPS 过滤。日常用前者。
- 关掉之后，这个网站的加密广告就拦不到了 —— 属于用拦截率换可用性，逐个域名处理，别一次放一批。

## 六、如果放行了还是打不开

这时候要往 DNS 那一层看：

- 网站是被 **DNS 过滤器**拦的（「保护 → DNS 保护 → DNS 过滤器」），在网站允许清单里加域名不解决问题，要去 DNS 保护里给对应过滤器加例外。
- 你用的是**带过滤的公共 DNS**（例如 AdGuard DNS 的家庭保护版），拦截发生在解析服务器上，本机的放行设置对它无效。处理办法是换成不带过滤的解析服务器，或到 DNS 服务那边的后台加允许规则。细节见 [DNS保护怎么用.md](DNS保护怎么用.md)。

## 七、放行之后要做的两件事

1. **回归检查**：过几天再把这个域名从允许清单里拿出来试一次。过滤器和网站都在变，之前被误拦的往往在新名单里已经修好，长期挂在允许清单里等于永久放弃该站的广告拦截。
2. **别把放行当默认手段**：遇到网页异常先按 [广告拦不住怎么排查.md](广告拦不住怎么排查.md) 确认是哪一环，能靠更新过滤器或调整单个过滤器解决的，不要直接放行整个域名。
