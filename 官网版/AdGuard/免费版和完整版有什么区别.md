# AdGuard 免费版和完整版有什么区别

> 免费版只拦浏览器里的广告，完整版才拦应用内广告、跟踪器与危险网站，并放开自定义规则。本篇把两条线一次划清。

安装之后不激活也能用，但能力被限制在浏览器范围里。本篇是给「不确定自己要不要付费」的人看的：哪些功能免费就能用、哪些必须激活许可、不激活会遇到什么具体限制。判断依据取自官方知识库的「免费版和完整版」页，价格与许可政策以官方页面当时显示为准。

## 一、两条线怎么划

| 能力 | 免费版 | 完整版 |
| --- | --- | --- |
| 浏览器网页里的广告与弹窗 | 可以拦截 | 可以拦截 |
| 应用内广告（非浏览器应用里的广告） | 不能过滤 | 可以按应用逐个开启 |
| 跟踪保护（原「隐身模式」） | 不能开启 | 可以开启，分标准 / 高 / 极高三级 |
| 浏览安全（危险网站拦截） | 不能开启 | 可以开启 |
| 自定义过滤器与用户规则 | 不能添加 | 可以添加 |
| 用户脚本、AdGuard Extra、禁用 AMP | 不能使用 | 可以使用 |
| DNS 保护、防火墙、应用管理、统计 | 可以 | 可以 |
| 自带播放器看 YouTube 视频 | 可以 | 可以 |

一句话概括：**免费版让浏览器里干净，完整版让整个手机干净**。

## 二、免费版实际用起来是什么样

- 用系统浏览器、Chrome、Firefox 这类浏览器上网时，网页里的横幅、弹窗、跟踪脚本会被拦掉，这部分能力两个版本一致。
- **一旦离开浏览器就停了**。同一个新闻类应用里的开屏广告、信息流里插的推广位、小游戏里的插屏广告，免费版一律拦不到 —— 因为这些走的是应用自己的网络请求，属于「应用内广告」。
- 想按应用单独开过滤的入口能点进去，但对未激活的账号不生效，界面上会给出提示。
- 你仍然能用 DNS 保护与防火墙：前者在域名解析这一层拦，不会受「浏览器 / 应用」的区分限制；防火墙上可以直接切断某个应用的上网权限。这两项是免费版里最值得先摸熟的。

## 三、完整版多出来的东西，分别解决什么问题

1. **拦截应用内的广告**：这是最直观的一项。开启后，AdGuard 会在你指定的应用里过滤请求，效果依赖该应用是否走标准 HTTPS 与过滤器覆盖程度。
2. **跟踪保护**：阻止计数器、分析系统之类的请求，还能按级别选择是否去除链接里的追踪参数、是否清理第三方 cookie。级别越高越可能影响登录状态 —— 官方明确提示「高」级别以上会清理第三方 cookie，可能让你需要重新登录一些网站。
3. **浏览安全**：访问已知的危险站点前先拦下来。
4. **自定义过滤器与用户规则**：过滤器列表里没有的，可以自己写规则补；也能导入第三方过滤器。
5. **用户脚本**：可以跑 userscript，其中官方自带两个 —— AdGuard Extra 用来处理「绕过拦截后又把广告注入回来」的站点，Disable AMP 用来关掉搜索结果里的 AMP 页面。

## 四、几种典型情况怎么选

| 你的情况 | 建议 |
| --- | --- |
| 主要在浏览器里看网页，讨厌弹窗 | 免费版就够，先把过滤器自动更新和 DNS 保护用好 |
| 主要困扰是应用开屏广告、应用内推广位 | 需要完整版，免费版拦不到这一类 |
| 只想让某些应用彻底不能联网 | 免费版的防火墙就能做，不必为它付费 |
| 想要「一套设置管全部设备」 | 先看官方许可页的覆盖范围再决定，不同套餐支持的设备数不同（以官方页面为准） |

## 五、许可怎么来、怎么激活

- **官方提供试用**：官方产品页上标有试用期（当前页面写的是 14 天），试用期内可以完整体验上表里的完整版能力。试用期天数以官方页面上当时显示的为准。
- **购买**：走官方许可页下单。具体价格与优惠活动不在本篇范围内，会随时间变化。
- **激活路径**：装好应用后在「设置」里找到许可证与订阅一节，登录 AdGuard 账号或直接输入许可密钥即可。官方知识库的「许可证激活」一篇写得更细。
- **别用来路不明的密钥**：论坛、二手渠道流传的密钥可能被回收、也可能绑定到别人的账号上，激活失败或中途失效都会让完整版功能突然消失。

## 六、不激活时最容易踩的两个误会

- **「拦不住」其实是没激活**：应用内广告拦不到是免费版的设定，不是配置错了。按 [广告拦不住怎么排查.md](广告拦不住怎么排查.md) 逐项排查到最后一步会发现这一条。
- **「装完就能全拦」也是误会**：即使激活了，某些应用把广告内容和正文走同一条请求，或者用了证书固定，AdGuard 从原理上也拿不到可拦的请求；这属于应用侧的限制，不是设置问题。
