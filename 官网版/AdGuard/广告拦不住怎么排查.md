# AdGuard 广告拦不住怎么排查

> 拦截没效果基本落在六个环节上，本篇按「先查什么、怎么确认、怎么改」的顺序逐条给判据。

「装了但广告还在」是最常见的一类反馈，原因通常不在拦截本身，而在这条链路上某一环没接上：总开关、HTTPS 过滤、过滤器更新、应用是否被排除、是否属于免费版能力之外、以及缓存里还留着上一次加载的广告。本篇按这六环给出排查顺序，每一环都写清「看哪里」和「怎么算通过」。

## 一、先做一次 30 秒确认

打开一个广告密集的网页，回到 AdGuard 的「统计」页看两件事：

- **拦截数在涨**：说明链路是通的，问题多半在具体那个应用或那类广告上（跳到第五、六环）。
- **拦截数不动**：说明过滤没生效，从第二环顺着往下查。

不确定某一环有没有问题时，也可以不猜、直接看证据：「统计 → 最近活动」里逐条列着最近处理的请求，能看到哪一条被拦了、被哪条规则拦的。读法见 [最近活动日志怎么读.md](最近活动日志怎么读.md)。

## 二、总开关与保护项

逐项确认这几个开关是打开的：

1. 「保护」页顶部是否有整体关闭的开关，被关掉时首页会显示保护已停止。
2. 「保护 → 广告拦截」里的**基础保护**是否在开。基础保护与「AdGuard 基础过滤器」「AdGuard 移动广告过滤器」是联动的：这两个过滤器都关掉时，基础保护也会跟着关闭。
3. 「保护 → DNS 保护」是否在开。它在解析这一层拦域名，和请求层过滤是两条独立路径，两条都开拦截率才高。

## 三、HTTPS 过滤这一环

大部分广告走 HTTPS，这一环断了就只拦得到未加密的请求。

1. 在「设置 → 过滤 → 网络」里看 **HTTPS 过滤**是不是开着。
2. 看首页有没有「HTTPS 过滤已关闭」的提示条。
3. 证书装得对不对、装完不生效怎么处理，见 [HTTPS过滤与证书怎么装.md](HTTPS过滤与证书怎么装.md)。

## 四、过滤器是不是过期了

过滤器名单几乎每天在更新，用的是旧名单就拦不到新广告。

1. 「设置 → 过滤 → 过滤器」里，看各过滤器的**最后更新时间**。
2. 手动点一次「检查更新」，看能不能成功拉到新版本。
3. 回到「设置 → 常规 → 应用与过滤器更新」，把**自动更新**打开，避免以后每次都要手动。

更新始终失败时，多半是本机的网络到过滤器更新服务器不通，和广告拦截本身无关；可以换到别的网络下再试一次。

## 五、是不是这个应用被排除了

AdGuard 允许按应用逐个设规则，「拦不住」和「这个应用被排除在外」是同一种表现。

1. 进「应用管理」，找到那个应用，看它的**路由**是否指向 AdGuard、**过滤应用内容**是否打开。
2. 如果它被放到了排除名单里，去「设置 → 常规 → 高级 → 低级设置 → 保护 → 排除的应用」核对一次。
3. 官方把一部分应用标注为「可能出问题的应用」（例如下载管理器、部分系统应用与系统 UID），对这些应用默认建议不路由、不过滤。官方在低级设置里有完整的「不推荐过滤的应用」名单，需要时对照。

## 六、还剩几种常见情况

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 浏览器里能拦，一进应用就拦不到 | 应用内广告过滤属于完整版能力 | 见 [免费版和完整版有什么区别.md](免费版和完整版有什么区别.md) |
| 拦掉了一会儿，重开应用又出现 | 广告已被缓存到本地，新的拦截只对之后的请求生效 | 在系统设置里清掉该应用的缓存，再重新打开 |
| 只有某一个应用拦不到，其它都正常 | 该应用只信任系统证书区，或用了证书固定 | 没 root 的设备上解不开这层加密，属于应用侧限制，不是设置问题 |
| YouTube 官方应用里的广告拦不到 | 官方说明里就写着无法完全清掉官方应用内的广告 | 把视频分享给 AdGuard 自带播放器看，见 [YouTube广告怎么拦.md](YouTube广告怎么拦.md) |

## 七、浏览器自带加密 DNS 会绕过拦截

有些浏览器内置了「安全 DNS / DoH」并自己直连解析服务器，请求不经过 AdGuard 的 DNS 保护这一层，表现就是「同一个网站在别的浏览器里干净、在这个浏览器里照样有广告」。

处理方式二选一：

- 在浏览器的设置里**关掉安全 DNS**，让它回到系统解析；
- 或者把浏览器的安全 DNS 指向你在 AdGuard 里配置的那个加密 DNS 地址，让解析仍然经过过滤。

具体路径各家浏览器不同，通常在浏览器设置的「隐私与安全」一节里。

## 八、排查没结果时收集什么

官方支持在要求时会让你把日志级别调到 `Debug`（「设置 → 常规 → 高级 → 日志级别」）复现一次问题，然后把日志导出给他们。日志级别调高本身会占用更多资源，**排查完记得调回默认**。
