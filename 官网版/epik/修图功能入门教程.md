## 一、先认识界面

打开一张照片后，屏幕分三块：

- **上半部分**：照片预览区，你做的每一步修改实时显示在这里；
- **底部两行菜单**：最下面一行是主菜单（模板、滤镜、人像、调整等大类）；点中某个大类后，它上面那行会变成该类下的具体工具或素材缩略图。

刚上手会觉得「主菜单位置反常」，用两三次就习惯了。另外注意：**免费能用的功能直接点，带紫色 PRO 徽章（或带 + 圆标）的项目需要 PRO 订阅**，界面上分得很清楚。

## 二、一条完整的修图流程

以「把一张自拍修到能发社交平台」为例，推荐按这个顺序走，从大到小、从结构到细节：

1. **提升清晰度**：用 AI 工具里的 Enhance，把模糊、噪点多的照片拉回可用状态；
2. **修人像**：进人像分类——AI Skin 磨皮、祛皱纹瑕疵、Reshape 调脸型、妆容一键上妆；一键类的 Looks 会把磨皮、妆容、调色一起做掉，赶时间用它最快；
3. **调色**：Adjust 分类里的 HSL（单独调某种颜色）、Curves（曲线）、Split Tone（分离色调）、Selective（局部调整）；想偷懒就用 Lux 或滤镜直接套；
4. **加内容**：贴纸、文字、时间戳、模板都在主菜单；模板（Template）是别人做好的整套效果，点一下整套应用；
5. **检查后保存**：对比一下修改前后，确认后导出到相册。

中途不满意，返回键可以逐步撤销，不用怕点错。

一个实用预期：AI 功能和高级滤镜要把照片送到云端处理，加载几秒到十几秒都正常；有用户反馈在配置较老的手机上更容易卡顿。等渲染完成再点下一步，比反复点按、强退重开省时间。

## 三、工具分组对照表

EPIK 的工具多，按「你想干什么」查这张表比逐个试快得多：

| 你想干的事 | 用哪些工具 | 备注 |
| --- | --- | --- |
| 救模糊 / 低画质照片 | Enhance（AI 画质增强） | PRO 独占功能之一 |
| 抠出人物 / 物体 | Smart AI Cutout | 人物、物体、动物都能分 |
| 去掉画面里的杂物 | Remove | 路人、电线、水印痕迹类的小物件 |
| 换发型看效果 | Hairstyle、Hair Color | PRO 独占功能之一 |
| 精细调色 | HSL、Curves、Split Tone、Selective | 桌面级工具的移动版 |
| 做氛围感 | Lux、Texture、Grain、Vignette、Relight | 颗粒、暗角、重新打光 |
| 调构图 | Crop、Rotate、Mirror、Flip、Perspective | 透视用来矫正拍歪的楼 |
| 一次修多张 | Batch（批量编辑） | 同一套参数套用到多张图 |
| 局部修补 / 复制 | Patch、Clone | 仿制图章的思路 |
| 瘦脸瘦身 | Reshape、Body、Length | 全身照调身形 |
| 拼图 / 排版 | AI Collage、Layout、Background | AI 拼图会按照片自动排 |
| 局部保留颜色 | Spot Color | 黑白照片里留一点红那种效果 |
| 修视频 | Video Face Edit、视频马赛克、Retro Clip | 视频人脸修图、自动跟踪打码、复古短片 |

## 四、免费与 PRO 的界线在哪

免费可以完成上面大部分操作；碰到 PRO 徽章的功能与素材才需要订阅。如果你主要用增强、发型这类 PRO 功能，先看 [PRO会员与订阅管理.md](PRO会员与订阅管理.md) 再决定要不要订——那里把取消、恢复购买、退款都写清了。

不想逐个手动修，想试试「上传自拍、整套写真自动生成」的玩法，看 [AI写真与年度毕业照玩法.md](AI写真与年度毕业照玩法.md)。
