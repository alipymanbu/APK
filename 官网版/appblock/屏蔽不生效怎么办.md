# AppBlock 屏蔽不生效怎么办

> 规则建了却不拦、网站拦不住、拦着拦着自己失效 —— 本篇按「从最常见原因查起」的顺序给出排查清单。

## 一、先跑这四步

大多数「不拦」都是权限或后台问题，先做这四件事：

1. 打开 AppBlock 进 **Profile → Help → Troubleshooting**，看每项权限状态：使用情况访问、无障碍、显示在其他应用上层、电池优化，缺哪个补哪个（开启方法见 [安卓权限设置.md](安卓权限设置.md)）；
2. 确认对应的屏蔽计划确实在启用状态，且触发条件覆盖当前的时间、位置或 Wi-Fi；
3. 重启手机 —— 这一步能刷新系统权限状态，官方也把它列为常规排查手段；
4. 把 AppBlock 更新到可用的最新版本再试。

四步过完仍不行，按下面的场景分头查。

## 二、应用拦不住

- 计划里 **Launch** 和 **Notifications** 至少要勾一个，两个都没勾的规则不产生任何效果；
- 有没有别的计划在「帮忙」：两个计划同时覆盖同一应用时，**更严的那个生效**；开了 Allowlist（白名单）模式的计划会把没被允许的应用全拦掉，看起来就像「乱拦」；
- 屏蔽了整个分类（Social、Games）时，新装的同类应用也会被拦 —— 这是设计行为，不是故障；
- 用量上限（Usage limit）类条件是「用满才拦」，不是全程拦。

## 三、网站拦不住

- 无障碍权限没开的话，**任何浏览器都拦不住**，回 Troubleshooting 先恢复；
- 浏览器本身不受支持 —— 网站拦截只在受支持的浏览器里生效（官方清单见 [支持哪些浏览器.md](支持哪些浏览器.md)）；开了「屏蔽不支持的浏览器」选项时，不受支持的浏览器会被整个拦掉；
- 关键词匹配口径选错：「In domain」只匹配域名部分，「Anywhere in URL」匹配整个网址，换一种口径再试；
- 确认包含该网站的计划处于生效时段内。

## 四、拦着拦着自己失效

最常见的原因是**无障碍权限被系统自动关掉**，小米、华为、OPPO 上尤其高发 —— 系统为了省电会主动关闭无障碍服务，表现就是网站拦截突然全部失灵。处理：

1. 回 Troubleshooting 重新开启无障碍；
2. **设置 → 应用 → AppBlock** 里确认后台没被限制；
3. 电池优化设为「不优化」；
4. 有自启动管理的品牌（小米、华为、OPPO）允许 AppBlock 自启动；
5. 在最近任务界面把 AppBlock **下拉加锁**，防止系统清后台。

### 按品牌补充

- **华为**：电池管理里把省电计划设为性能模式；在「受保护的应用 / 启动管理」里允许 AppBlock 后台运行与自启动；
- **小米**：安全中心里允许自启动；后台电量策略设为「无限制」；最近任务里下拉锁定；
- **三星**：无障碍项灰色不可点时，走「允许受限设置」流程，具体步骤见 [安卓权限设置.md](安卓权限设置.md) 第二节。

### 两个特殊模式

- **超级省电模式**（ultra power saving）下 AppBlock 无法后台运行，拦截会整体失效 —— 这是系统层限制，任何依赖后台服务的应用都一样；要省电就用普通省电模式并把 AppBlock 排除出电池优化；
- **安全模式**（Safe Mode）下所有第三方应用都被禁用，正常重启回到普通模式即恢复。

## 五、该拦的没拦、不该拦的被拦

| 现象 | 常见原因 |
| --- | --- |
| 计划结束后应用仍被拦 | 偶发 bug，官方已知并修复中；重启手机可临时恢复 |
| 主屏幕或最近任务打不开 | 严格模式的 Block recent apps，见 [严格模式怎么用.md](严格模式怎么用.md) |
| 验证器、银行类应用被拦 | 严格模式的 Block device settings 连带影响 |
| 重装后的应用仍被拦 | 严格模式的 Block reinstalled applications 在起作用 |
| 位置计划不触发 | 位置权限没给全，或半径设得太小 —— 放大半径再试；部分品牌对后台定位限制严，触发会慢 |
| 视频在画中画小窗里照常播放 | 系统层限制，AppBlock 拦不到画中画窗口；到系统设置里关掉该应用的画中画权限（见下） |

位置计划再补充一点：半径太小会导致触发延迟甚至不触发；触发明显慢时，也可以在 Blocking 页下拉刷新一次屏蔽设置。

### 画中画（PiP）绕过怎么堵

视频类应用在你切到别的应用后，能以画中画小窗继续播放内容 —— 这类窗口不按普通应用拦截处理，AppBlock 拦不到，属于安卓系统层限制。最可靠的堵法是直接关掉目标应用的画中画权限：

1. **设置 → 应用**；
2. 找到「特殊应用访问权限」（或直接在设置里搜「画中画 / Picture-in-picture」）；
3. 选「画中画」，找到要限制的应用（如 YouTube）；
4. 关掉「允许画中画」。

部分应用自己也能关：YouTube 在播放设置里就有画中画开关。选项名称与路径随品牌和系统版本略有差异，找不到就用设置页里的搜索。

## 六、备份与统计的边界

备份功能（**Profile → Backup**）只覆盖**计划与屏蔽设置**，不含使用统计；网站统计只存本机，无法备份恢复。换机前先手动备份一次，统计部分认了。

以上都试过仍不正常，走 AppBlock 内 **Profile → Help → Contact support** 联系官方，附一段展示屏蔽设置的短视频（20 MB 以内）能明显加快定位。
