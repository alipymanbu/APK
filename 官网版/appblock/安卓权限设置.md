# AppBlock 安卓权限设置

> AppBlock 的拦截能不能稳定生效，取决于系统权限是否给全。本篇逐项讲每个权限的作用、开启路径与常见卡点。

## 一、哪些权限要给

首次打开 AppBlock 会走一遍引导，逐个申请权限。各项权限的作用如下：

| 权限 | 作用 | 必要性 |
| --- | --- | --- |
| 使用情况访问（Usage access） | 知道你当前在用哪个应用，是应用拦截的前提 | 必需 |
| 显示在其他应用上层（Display over other apps） | 拦截时把拦截页盖在被拦应用上面 | 必需 |
| 无障碍（Accessibility） | 浏览器网站拦截、部分应用拦截功能与严格模式都依赖它 | 强烈建议 |
| 电池优化白名单 | 避免后台被系统杀掉导致拦截失效 | 必需 |
| 位置（Location） | 只有用「位置」或「Wi-Fi」触发条件时才需要 | 可选 |
| 自启动（部分品牌） | 重启后自动恢复拦截 | 部分机型必需 |

前三项加电池优化，是绝大多数人的「必配四件套」。自查入口：AppBlock 内 **Profile → Help → Troubleshooting**，这个页面会列出每项权限的当前状态，缺哪项一目了然。

## 二、逐项怎么开

### 使用情况访问

AppBlock 内申请时会跳到系统页：**设置 → 应用 → 特殊访问权限 → 使用情况访问**（部分品牌叫「使用记录访问权」），找到 AppBlock 打开允许。

### 显示在其他应用上层

**设置 → 应用 → 特殊访问权限 → 显示在其他应用上层**，打开 AppBlock 的开关。

### 无障碍

**设置 → 无障碍 → 已安装的应用**（部分品牌叫「已下载的应用」）里找到 AppBlock，打开开关并确认弹窗。这项权限管着浏览器网站拦截 —— 能拦哪些浏览器有官方清单，见 [支持哪些浏览器.md](支持哪些浏览器.md)。

三星机型常见一个卡点：AppBlock 在无障碍列表里是**灰色的**，点击会弹「受限设置」。处理顺序：

1. 先去 **设置 → 应用 → AppBlock**，点右上角三点菜单，选「允许受限设置」，验证锁屏密码或指纹；
2. 再回到 **设置 → 无障碍 → 已安装的应用**，此时就能打开 AppBlock 的开关，确认「完全控制」弹窗。

### 电池优化

**设置 → 应用 → AppBlock → 电池**里选「不受限制」；或在 **设置 → 电池 → 电池优化**里把 AppBlock 设为「不优化」。

### 自启动（小米 / 华为 / OPPO 等）

在这些品牌的「安全中心 / 手机管家」里找到自启动管理，允许 AppBlock 自启动。这类系统对后台管控很严，光给权限还不够，配套做法见 [屏蔽不生效怎么办.md](屏蔽不生效怎么办.md) 的品牌部分。

## 三、权限给了还是不拦

先回 AppBlock 的 Troubleshooting 页面对照各项状态，再确认对应的屏蔽计划确实处于启用状态；重启一次手机能刷新权限状态，很多「明明给了权限却不拦」的情况重启后就正常了。仍不行就按 [屏蔽不生效怎么办.md](屏蔽不生效怎么办.md) 的清单逐项过。

无障碍权限被系统自动关掉是高频问题，小米、华为、OPPO 上尤其常见，表现是网站拦截突然全部失效 —— 到 Troubleshooting 里重新开启即可，同时把后台限制与电池优化一并处理，否则还会再被关掉。
