# AppBlock 严格模式怎么用

> 严格模式（Strict Mode）用来锁死自己设好的屏蔽规则：生效期间改不了、关不掉、也卸不掉 AppBlock。本篇讲解锁方式怎么选、能锁住哪些东西、被锁死了怎么自救。

## 一、它锁住什么

严格模式开启后，你将无法：

- 关闭正在生效的计划或 Quick Block；
- 编辑或删除屏蔽规则；
- 从屏蔽名单里移除应用或网站；
- 卸载 AppBlock（开了对应选项时）。

解锁的唯一办法是满足你开启时选定的解锁方式。所以选哪种解锁方式，直接决定这套规则是「防手滑」还是「真约束」。

## 二、六种解锁方式

| 解锁方式 | 行为 | 适合 |
| --- | --- | --- |
| PIN | 输入自设数字码解锁 | 第一次试用，怕把自己锁死 |
| Charger | 插上充电器才能解锁 | 第一次试用；或「睡前锁机」场景 |
| Timer（定时） | 到点自动解锁，中途改不了 | 考试周、固定专注时长 |
| Cooldown（冷却） | 申请解锁后要等一段时间才真正解锁 | 对抗「一时冲动关掉」 |
| Follow schedules | 只在计划运行期间维持锁定 | 只想在工作或学习时段锁 |
| Approval（担保人） | 由你指定的可信联系人批准解锁 | 最强约束，认真戒断时用 |

官方给的建议很直白：第一次用选 PIN 或 Charger，把流程摸清再上强度；正式约束自己时用 Approval 或长 Timer；重要事项（考试、截止日期）临近时，别临时搭一套复杂配置。

## 三、开启步骤

1. 先建好至少一条计划或 Quick Block（严格模式建立在屏蔽规则之上）；
2. 进 **Strict Mode**；
3. 选解锁方式；
4. 点 **Advanced options** 勾选锁定范围；
5. 核对条件后点 **Activate lock**。

### 锁定范围可选项

在 Advanced options 里按需勾选，常见的几项：

- **Lock blockings in app**：应用内的屏蔽规则不可改、不可停、不可删；
- **Disable AppBlock uninstalling**：禁止卸载 AppBlock；
- **Block device settings**：锁住系统设置入口；
- **Block reinstalled applications**：卸载重装的应用照样拦（堵「删了重装」这条路）；
- **Block recent apps**：封掉最近任务切换器（仅部分品牌可用：Samsung、Xiaomi、Pixel、Motorola、Poco）。

iOS 版还有禁止安装新应用、禁止改系统时间等选项；安卓端以你应用内 Advanced options 当时列出的为准，选项随版本会调整。

## 四、被自己锁死了怎么办

几个典型场景与出路：

- **主屏幕或最近任务也被锁**：这是 Block recent apps 造成的 —— 先按解锁方式解开严格模式，再去 **Strict Mode → Options** 关掉它，重新上锁；
- **银行或验证器应用打不开**：Block device settings 会连带限制需要访问系统设置做身份验证的应用（典型如 Google Authenticator 这类）。要么解开严格模式，要么重开前关掉这个选项，或用 **Show Available Settings**（Profile → Customize → Blocking preferences）放开部分设置页；
- **忘了 PIN、解锁条件无法满足**：走应用内 **Profile → Help → Contact support**，选 **Emergency unblocking**；
- **跨时区旅行后锁定期变得离谱**（官方收到过显示 99+ 天的案例）：不要关机重启，直接走 Emergency unblocking，解除后重装应用重置状态、再重建计划。官方同时提醒：出行期间尽量别关机别重启，能降低触发的概率。

## 五、开启前最后核对

严格模式的思路是「趁你还有理智时，锁住未来的自己」，所以点 Activate lock 之前把三件事过一遍：解锁方式自己真的能完成吗（PIN 别忘、Charger 的场景想清楚）；有没有应用被误锁会耽误正事（验证器、银行）；Timer 时长是否给足了缓冲。

不确定自己需要多强的话，先只用普通计划跑几天试试，见 [屏蔽应用和网站设置.md](屏蔽应用和网站设置.md)；权限层面的问题去 [安卓权限设置.md](安卓权限设置.md) 和 [屏蔽不生效怎么办.md](屏蔽不生效怎么办.md)。
