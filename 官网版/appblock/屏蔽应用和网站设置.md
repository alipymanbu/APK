## 一、两条路径怎么选

入口都在 AppBlock 底部的 **Blocking** 标签：

| | Quick Block | Schedules |
| --- | --- | --- |
| 适合 | 立刻开始的一次性专注时段 | 按固定规律反复生效的规则 |
| 触发 | 手动点「开始」 | 按时间、用量、位置、次数或 Wi-Fi 自动触发 |
| 典型用法 | 临时想专心 25 分钟 | 工作日 9:00–18:00 屏蔽短视频 |

Quick Block 解决「现在就要清净」；Schedules 解决「到点自动拦，不靠每天下决心」。

## 二、Quick Block

1. 打开 AppBlock，进 **Blocking → Quick Block**；
2. 添加要拦的应用、网站或关键词；
3. Premium 版可选定时（25 分钟 / 1 小时 / 24 小时 / 自定义）或番茄钟（Pomodoro）节奏；
4. 点 **Start**。

免费版直接点开始即可，结束时限时手动停用。

## 三、Schedules：五种触发条件

在 **Blocking** 页点 **+ Add** 新建（也可以从模板里选），触发条件五选一：

| 条件 | 生效逻辑 |
| --- | --- |
| Time（时间） | 选定时段内自动生效，可按星期几组合 |
| Usage limit（用量上限） | 当日或每小时累计使用到设定时长后开始拦 |
| Location（位置） | 进入（或离开）某区域的半径范围后生效 |
| Launch count（打开次数） | 当日或每小时打开次数达到上限后开始拦 |
| Wi-Fi | 连上指定 Wi-Fi（比如公司网络）时生效 |

选好条件后挑选要拦的对象（应用、网站或关键词），点 **Save**，再点 **Create → Let's focus** 完成创建。

### 拦启动还是拦通知

每个计划里有个设置项，至少要勾一个：

- **Launch**：被拦的应用直接打不开；
- **Notifications**：收不到被拦应用的通知。

两个都不勾的话规则等于没建。只想图清净、应用偶尔还要用的话，可以只勾 Notifications。

### Blocklist 与 Allowlist 两种名单

建计划时先选名单类型：

- **Blocklist（黑名单）**：拦掉名单里的应用与网站，免费版可用；
- **Allowlist（白名单）**：反过来 —— 拦掉**所有**应用，只放行名单里的（比如电话、地图、办公工具），适合「只留几个必需应用」的场景。Allowlist 计划属于 Premium 功能，归属见 [免费版与付费版区别.md](免费版与付费版区别.md)。

选对象前先想用哪种：要拦的就三五个应用时用黑名单；应用大多想拦、只留少数几个时用白名单省事得多。

### 只拦应用里的某一块

不整体屏蔽应用、只封里面最耗时间的板块（Instagram Reels、YouTube Shorts、Snapchat Stories/Spotlight）也做得到，设置步骤见 [只屏蔽短视频和Reels.md](只屏蔽短视频和Reels.md)。

### 选对象的省力做法

从 7.7.0 版起，AppBlock 会把应用按类别分组（Social、Games 等），整类勾选比逐个找快得多；首次添加应用时若弹过分类对话框，之后可在 **Profile → Customize → General → Blocklist categories** 里开关这个分组。注意屏蔽了整个分类时，后来新装的同类应用也会被一并拦住。

### Premium 的扩展选项

计划里还有一组 Extra options（Premium 功能），常用的几项：

- **新装应用自动纳入屏蔽**；
- **成人内容网站拦截**：覆盖各浏览器。首次开启要等站点数据库加载到 100%，期间别退出应用；它只对开了这个选项的那条规则在生效时段内起作用，想全程覆盖就得每条计划都单独开；另注意它拦不了 Google 图片搜索，也拦不了应用内的内容；
- **拦截应用内购买**；
- **屏蔽不支持的浏览器**：凡是没法做网站拦截的浏览器会被整体拦掉，配合浏览器支持清单看，见 [支持哪些浏览器.md](支持哪些浏览器.md)。

免费版是否包含某一项，以官方对照表为准，见 [免费版与付费版区别.md](免费版与付费版区别.md)。

## 四、网站与关键词

网站拦截依赖无障碍权限 —— 没开的话任何浏览器都拦不住（见 [安卓权限设置.md](安卓权限设置.md)），并且只在受支持的浏览器里生效（清单见 [支持哪些浏览器.md](支持哪些浏览器.md)）。添加网站时既可以给具体网址，也可以用关键词批量匹配；关键词有两种匹配口径：「In domain」只匹配域名部分，「Anywhere in URL」匹配整个网址，站点没被拦住时先检查选的是哪种口径。

另一个容易忽略的点：网站访问统计只存在本机，换机或重装后不会跟着备份恢复，行为和应用屏蔽设置的云端备份不同。

## 五、被拦时看到什么

规则生效时，打开目标应用会出现 AppBlock 的拦截页而不是应用界面。想确认规则真的在工作，拿一个不重要的应用当场试一遍最快。

规则建好之后，若怕自己关键时刻手软关掉，就轮到严格模式出场了，见 [严格模式怎么用.md](严格模式怎么用.md)。
