## 一、这是个什么应用，适合谁

Package Manager 是一款开源的安卓应用管理工具（GPL-3.0 或更高版本许可），你可以在上面查看设备里系统应用与用户应用的清单、导出 APK、安装分包格式的安装包；卸载/停用系统应用这类高级操作则需要 root 或 Shizuku。适合需要备份安装包、清理预装应用、处理 `.apks` / `.xapk` 分发包的用户。作者是 SmartPack（sunilpaulmathew），源码在 `https://github.com/SmartPack/PackageManager`。

## 二、获取渠道

| 渠道 | 说明 |
| --- | --- |
| Google Play | 有免费版与 Pro 版两个条目，搜 `Package Manager`（开发者 SmartPack） |
| F-Droid | [f-droid.org/packages/com.smartpack.packagemanager](https://f-droid.org/packages/com.smartpack.packagemanager)，由 F-Droid 构建签名 |
| GitHub Releases | [github.com/SmartPack/PackageManager/releases](https://github.com/SmartPack/PackageManager/releases)，发布页可下 APK |
| 离线安装包 | 如果你手上已经有一份离线包，用 [Package Manager 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8e49c94efec8) 转存后直接安装即可 |

从 F-Droid 或 GitHub 安装的应用不会走商店的自动更新，升级需要你手动重新安装新版本；在意的可以选 Play 渠道。另一个提醒：**各渠道的构建签名不同**（F-Droid 版由 F-Droid 自己构建签名），跨渠道换装前要先卸载旧版，否则系统会因签名不一致拒绝安装；好在 Package Manager 本身没有需要保留的数据，卸载重装没有损失。Pro 版与免费版的功能差异，以官方商店页说明为准。

## 三、离线 APK 的安装步骤

1. 把安装包转到手机存储里（下载、微信/网盘转存均可）。
2. 在文件管理器里点开这个 `.apk` 文件；系统会提示「不允许安装未知来源应用」。
3. 按提示允许你的文件管理器（或浏览器）安装未知应用：设置 → 应用 → 特殊权限 → 安装未知应用 → 对应应用开启允许。
4. 回到提示页点安装，完成后打开应用。
5. 首次打开应用通常会请求存储权限，允许后才能正常选取安装包、保存导出的文件。

不同厂商（小米、华为、OPPO 等）的「未知来源」入口名称略有差异，但路径都在「应用 → 特殊权限/权限管理」附近。

## 四、版本与系统要求

本篇资源里的版本是 **v7.1**（2024 年 1 月发布），安装包 3.01 MB，包名 `com.smartpack.packagemanager`。此版本在官方更新日志里的改动是迁移到新版 Shizuku、修复搜索时的崩溃、更新翻译。

系统要求方面，F-Droid 上近几个版本标注的是 Android 7.0 或更高；具体到你安装的那个版本，以 [官方发布页](https://github.com/SmartPack/PackageManager/releases) 当时显示为准。界面语言可以在应用内设置里直接切换（Language 选项），不需要跟着系统语言走。

## 五、装好后先做什么

打开应用后你会看到设备上全部应用的列表，每行是图标、应用名与包 ID。此时不需要任何特殊权限就能浏览、导出 APK；但「卸载系统应用」「批量停用」这类操作会提示需要 root 或 Shizuku。Shizuku 是免 root 使用这些功能的常见方案，见 [无root能用哪些功能.md](无root能用哪些功能.md)；如果你要安装 `.apks` / `.xapk` 这类分包格式，看 [分包与apks安装方法.md](分包与apks安装方法.md)。
