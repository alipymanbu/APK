## 一、三种权限状态的功能对照

Package Manager 打开就能用，但一部分按钮在你没有相应权限时会弹提示或不可点。对照下表看你属于哪种情况：

| 功能 | 无 root 无 Shizuku | Shizuku | root |
| --- | --- | --- | --- |
| 浏览系统/用户应用列表、搜索、排序 | 可用 | 可用 | 可用 |
| 查看应用详情（版本、包名、APK 路径、权限清单） | 可用 | 可用 | 可用 |
| 打开应用、跳转系统应用信息、跳转 Play 商店页 | 可用 | 可用 | 可用 |
| 导出 APK / 分包到存储 | 可用 | 可用 | 可用 |
| 安装 .apks / .apkm / .xapk | 可用 | 可用 | 可用 |
| 浏览已安装应用的文件内容（Package Explorer，实验性） | 可用 | 可用 | 可用 |
| 卸载用户应用 | 可用（走系统卸载） | 可用 | 可用 |
| 卸载/停用/启用系统应用 | 不可用 | 可用 | 可用 |
| 修改 AppOps（各项操作权限） | 不可用 | 可用 | 可用 |
| 清除应用数据（Reset） | 不可用 | 可用 | 可用 |
| 底部导航里的「Uninstalled Apps」页 | 不可用 | 可用 | 可用 |

一句话判断：**只要涉及系统应用或「帮别的应用做事」，就需要 root 或 Shizuku**；仅浏览、导出、装包这三类不需要。

免权限状态下还有两个只读页面值得看：**Permissions** 页把应用声明的权限按「已授予 / 已拒绝」列出来，装完新应用想审一遍权限时很省事；**Operations（AppOps）** 页显示系统记录的细粒度操作开关（相机、剪贴板、振动这一类）。AppOps 在有权限时可以修改，但改错会让应用对应功能直接失效——官方文档明确提示要清楚后果再动，不确定就只看不改。

## 二、Shizuku 是什么，怎么准备

Shizuku 是一个让普通应用临时借用系统级 API 的工具，效果接近 root，但不需要解锁手机。你需要先在手机上装好 Shizuku 并完成启动，它官方的安装与启动教程在 `https://shizuku.rikka.app/guide/setup/`（两种启动方式：开发者选项里的无线调试配对，或连电脑用 ADB 启动；重启手机后需要重新启动 Shizuku，除非你的设备已 root 可选开机自启）。

Shizuku 启动后，再打开 Package Manager，进入「卸载系统应用」「停用」这类操作时按应用内提示授权即可；入口以应用内实际显示为准。启动或授权环节卡住了，见 [Shizuku启动与授权问题排查.md](Shizuku启动与授权问题排查.md)。

## 三、没有 root 也没有 Shizuku 时怎么办

- **卸载系统应用**：普通用户应用走系统自带的卸载即可；系统应用在无权限状态下 Package Manager 会给你指一条 ADB 路径，即用电脑连手机通过 `adb shell` 执行卸载命令。这条路的操作成本比 Shizuku 高，且输错命令有风险，建议优先考虑 Shizuku。
- **停用系统应用**：不借助任何工具也有一个系统自带入口——设置 → 应用 → 点开目标应用 → 停用（部分厂商的预装应用不提供该按钮）。停用后应用不再运行、列表里标记为已停用，但文件仍在，想恢复随时可以启用。

## 四、权限状态在哪里看

最直接的验证方式是试一个需要权限的动作（比如长按一个系统应用选「停用」），应用会当场告诉你是缺 root 还是缺 Shizuku。授权失败时，先回 Shizuku 应用里确认它自己显示「运行中」，再回 Package Manager 重试。

装好权限之后能做的事就多了：批量卸载预装应用、批量停用，见 [批量操作与系统应用卸载.md](批量操作与系统应用卸载.md)；免 root 时导出 APK 做备份的完整流程见 [导出与备份APK.md](导出与备份APK.md)。
