# Package Manager 导出 APK 与备份方法

> 本篇讲用 Package Manager 把已装应用的 APK（含分包）导出到本机存储的方法、导出文件的位置，以及导出后的管理页面。

## 一、单个应用导出

在主列表点开一个应用进入详情页，找到 **Export** 按钮执行导出；导出的就是该应用当前安装的那个 APK（分包应用会导出整套）。这是不依赖 root 的功能，任何设备都能用。导出完成后可以直接通过系统的分享菜单把文件发给别的应用（网盘、局域网传输工具均可）。

## 二、批量导出

要一次备份多个应用：长按列表进入批量模式，勾选目标应用，选**导出**即可；分包应用的整包也会一起导出。批量前建议先按体积排序、预留足够存储空间。配合「导出详情」还能生成一份文本，记录每个应用的包名、权限清单和安装日期——换机后想核对版本时用得上。

## 三、导出的文件在哪

- **较新的版本**（v7.3 起，在新版安卓上）：导出文件位于内部存储的 `Download/Package Manager/` 文件夹。
- **更早的版本**（包括 v7.1 这类 2024 年的版本）：导出路径是旧版外部存储目录（应用内提示的实际路径为准）。

导出文件的命名方式可以在设置里调（Exported APK Name：按应用名或按包名命名）；这是较新版本提供的选项，老版本以应用内实际设置为准。

找不到导出文件时，优先在应用内的 **Exported Apps** 页面看——那里列着所有导出过的条目，不用去文件管理器翻。

## 四、Exported Apps 页面

底部导航进入 Exported Apps，这里集中管理你导出过的 APK 与分包整包：

- **安装**：点某个条目直接重装（分包安装细节见 [分包与apks安装方法.md](分包与apks安装方法.md)）；
- **分享**：把文件发到别的应用；
- **删除**：清理不需要的导出文件；
- **批量删除**：长按条目进入批量模式后整批删。

导出文件默认只在本机存储里，手机丢了就没了；要留底就自己把它们转存到网盘或电脑。如果你是想先拿到 Package Manager 这个应用本身，安装文件资源见 [下载与安装教程.md](下载与安装教程.md)。
