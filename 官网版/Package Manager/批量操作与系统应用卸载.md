## 一、怎么进入批量模式

在应用列表里**长按任意一行**，每行前面出现勾选框，这就是批量模式；勾选多个应用后，批量操作菜单会出现（不同版本的入口形态略有差异，长按或点图标都有可能，以你手上的版本为准）。返回键即可退出批量模式。列表支持按名称、包名、体积、安装/更新日期排序，勾之前先排序或搜索能省不少事。

## 二、五个批量动作

| 动作 | 作用 | 需要的权限 |
| --- | --- | --- |
| 启用/停用 | 批量把选中的应用设为停用或重新启用 | root 或 Shizuku |
| 卸载 | 批量移除选中的应用；卸载系统应用需要权限 | 用户应用免权限，系统应用需 root/Shizuku |
| 重置 | 清空选中应用的数据目录，相当于逐个「清除数据」 | root 或 Shizuku |
| 导出 | 把选中应用的 APK（含分包）保存到存储 | 免权限 |
| 导出详情 | 生成选中应用的详细信息文本（包名、权限、安装日期等） | 免权限 |

批量动作对勾选的每一项依次执行，系统应用批量卸载前务必确认清单，误删后恢复不一定容易。

## 三、卸载/停用系统应用（清理预装）

1. 先确认权限就绪：系统应用相关操作需要 root 或 Shizuku，没准备好的先看 [无root能用哪些功能.md](无root能用哪些功能.md)。
2. 搜索或浏览定位到要处理的预装应用；不确定它是系统应用还是用户应用，列表分类里可以只看系统应用。
3. **动手前先批量导出一份 APK**（导出免权限，方法见 [导出与备份APK.md](导出与备份APK.md)），万一误删还能装回来。
4. **建议先「停用」观察几天**：停用可随时在应用信息里启用回来，卸载则不一定能无痛恢复。
5. 确认后执行停用或卸载；卸载系统应用时 Package Manager 会明确提示风险——设备变砖、某功能失效的可能都存在，这个提示值得当真。

哪些能删、哪些不能删，没有通用清单（各厂商定制不同）。保守原则：通讯、相机、桌面（Launcher）、系统 UI、厂商账号服务这类不要碰；看不懂的先停用再决定。

## 四、停用、卸载、重置的区别

- **停用**：应用停止运行、不占后台、不显示在桌面，文件和数据都还在；随时可恢复。适合「不确定要不要删」的预装应用。
- **卸载**：对系统应用而言，通常是从当前用户移除（设备分区里的文件可能仍在），恢复需要重装或重置系统；对用户应用就是常规删除。
- **重置**：只清数据不动应用本身，用于某个应用状态混乱想「重装般清爽」的场景；批量重置对多应用同时执行，注意别把要保留的登录状态一起清了。

清理完成后，被卸载应用如果之前导出过 APK，可以从 Exported Apps 页面重新安装；导出方法见 [导出与备份APK.md](导出与备份APK.md)。
