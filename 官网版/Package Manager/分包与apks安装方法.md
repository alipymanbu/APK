## 一、为什么有的应用包双击装不上

应用商店分发的应用很多是「分包」形态：一个应用被拆成一个基础包加若干按设备、语言、架构切分的附加包。这类应用你拿到的往往不是单个 `.apk`，而是 `.apks`、`.apkm`、`.xapk` 整包文件，或一堆名字里带 `config`、`arm64`、`zh` 之类字样的散装 `.apk`。系统自带的安装器认不了这些格式，Package Manager 的安装器可以。

## 二、安装步骤

1. 打开 Package Manager，点主界面（或 Exported Apps 页）的**加号（+）**按钮，从文件管理器里选你要装的文件。
2. 按手里的文件形态走：
   - **`.apks` / `.apkm` / `.xapk` 整包文件**：直接选中它，按屏幕提示确认安装。
   - **散装的多个 split APK**：先把所有相关文件放进**同一个文件夹**，选择时**把需要的分包全部勾上**，再确认安装。
3. 系统弹出安装确认（和平时装普通 APK 一样），点安装即可。

散装分包漏选是装不上最常见的原因——尤其漏掉语言包或架构包。不确定哪些必须选时，全选通常可行；前提是这些文件本来就是同一个应用的同一套分包。

## 三、安装失败时的排查顺序

| 现象 | 先查什么 |
| --- | --- |
| 提示解析失败/「软件包无效」 | 是否漏选了分包；整包文件是否下载完整（对照原始大小）；架构是否匹配（arm64 的包装到 32 位老设备会失败） |
| 提示签名冲突 | 设备上是否已装过同包名的另一版本——先卸载旧的再装 |
| 加号按钮选不到文件 | 文件管理器路径是否可见；`.apks` 等后缀是否被改过名 |
| 安装中途失败 | 存储空间是否够；分包文件是否来自不同版本的混搭 |
| 点安装没反应或反复弹回 | 发起安装的那个应用有没有「安装未知应用」权限；重启手机再试一次 |

签名冲突那条尤其常见于「Play 商店装过、又想装导出的离线包」的场景：同一包名的签名不一致时系统会拒绝覆盖，只能先卸载再装，卸载会连数据一起清掉，重要数据先备份。另外系统不允许「降级」：设备上已装更高版本时，装低版本会被直接拒绝，同样只能先卸载。

还有一个容易忽略的点：**「安装未知应用」权限是按应用授予的**——从哪个应用里点开安装包，就得给哪个应用授权。在 A 应用里下载、却去 B 文件管理器里点安装，B 没授权时往往不弹提示、静默失败；最稳的做法是从下载它的那个应用里直接点开安装。

## 四、导出的分包还能装回去

用 Package Manager 导出的分包（导出方法见 [导出与备份APK.md](导出与备份APK.md)）和网上下载的分包一样，走上面第二节的流程就能重装。这也是备份小众应用的常见做法：先导出成 `.apks`，换机后用本应用装回去。首次使用本应用本身的安装问题，见 [下载与安装教程.md](下载与安装教程.md)。
