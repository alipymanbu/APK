## 一、Smart Dock 是什么

Smart Dock 是一款开源的安卓桌面启动器，它把手机或平板的界面换成类似电脑的任务栏形态：底部常驻一条 Dock，点开能看到全部应用，多个应用还能以可缩放的小窗同屏打开。经常外接键鼠、用平板办公，或觉得原生桌面翻页找应用太慢的人会用得上它。本篇只讲三件事：怎么拿到包、怎么装并设成默认桌面、首次启动要给哪些权限。

几个你在装之前该知道的事实：

| 项目 | 内容 |
| --- | --- |
| 官方名称 | Smart Dock |
| 包名 | `cu.axel.smartdock` |
| 许可 | GPL-3.0 开源，免费、无广告 |
| 开发者 | axel358（GitHub 同名账号） |
| 官方获取渠道 | F-Droid 与 [GitHub 发布页](https://github.com/axel358/smartdock/releases) |
| 系统要求 | 见本篇末尾「系统要求」一节 |

## 二、拿到安装包

**最省事的方式是直接从 [Smart Dock 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bfe072753368) 下载**，网盘里这份包的参数是：

- 版本：1.14.1
- 安装包大小：6.07M
- 包名：`cu.axel.smartdock`
- MD5：`988A51266E4ADA5D6F72B1D857726360`

如果你更倾向于官方渠道：官方仓库 README 写明「从 F-Droid 获取最新版」，F-Droid 与 GitHub Releases 都提供 APK。注意官方渠道给的是**最新版**（截至 2026-09 检索为 1.15.0），与网盘里这份 1.14.1 不是同一个版本，装哪个按你的系统版本来选（原因见[版本更新与开源信息.md](版本更新与开源信息.md)）。

## 三、安装步骤

1. 把 APK 传到手机（下载到电脑再数据线拷过去，或手机浏览器直接下载均可）。
2. 点击 APK 安装。安卓会弹「禁止安装未知应用」时，按提示给你的文件管理器或浏览器勾上「允许安装未知应用」再重试。
3. 装完先不要急着设置，先完成下面第四、五节的权限配置，再设默认桌面。

Smart Dock 只有 6.07M，安装过程没有额外下载，装完即可离线使用。

## 四、设为默认桌面

Smart Dock 装好后默认只是一个普通应用，按 Home 键仍会回到原桌面，要走一遍默认应用设置：

1. 打开系统设置 → 「应用」→「默认应用」（有的机型叫「默认应用设置」或在「应用管理」里）。
2. 找到「桌面」（有的机型显示为「主屏幕应用」「Home 应用」）。
3. 把它从原桌面改成 Smart Dock。

设完按 Home 键就会直接进入 Smart Dock 的界面。想换回原桌面，回到同一个设置项改回去即可 —— 原桌面不会被卸载，两个桌面可以共存随时切换。

另一条路是不设默认、把它当悬浮任务栏挂在原桌面上用（部分第三方教程这么教）；那样它就是普通后台应用，得按[后台保活与电池优化.md](后台保活与电池优化.md)放行白名单，否则会被系统清掉。

## 五、首次启动要给的权限

首次进入会引导你选布局（手机 / 平板 / 桌面三种，见[多窗口桌面模式使用指南.md](多窗口桌面模式使用指南.md)），随后需要放行几项权限，缺了它们部分功能会静默失效：

| 权限 | 用来做什么 | 不给会怎样 |
| --- | --- | --- |
| 无障碍 | 拦截系统级按键、支撑手势与快捷键 | 键盘快捷键、部分手势不生效 |
| 通知访问 | 在 Dock 上显示应用通知与角标 | 通知面板里没有内容 |
| 悬浮窗（显示在其他应用上层） | 让窗口以小窗形态浮在别的应用上面 | 小窗模式不可用 |
| 使用情况访问 | 识别正在运行的应用 | 任务栏上的运行状态不准 |

个别机型上「无障碍」和「通知」这两项在设置里**根本找不到**，这不是你操作错了 —— 官方给的解法是走「允许受限权限」，步骤见[ADB授权与高级功能设置.md](ADB授权与高级功能设置.md)。

## 六、系统要求

- 官方仓库主文档现在的说法是 **Android 10 及以上、无需 root**（对应最新版 1.15.0 起不再支持 Android 9 及以下）。
- 你手上这份 1.14.1 属于 1.14 系列，该系列在 F-Droid 元数据里标注的最低要求是 **Android 7.0**，目标版本 Android 14。
- 低版本系统装 1.14.1 通常可以，但新功能（如 1.15.0 的 Shizuku 集成）用不上。

两个口径并存是版本迭代造成的，装之前以官方页面当时显示为准。如果安装或启动时报错，对照[常见问题排查.md](常见问题排查.md)处理。
