# 常见问题排查

> 权限给不了、回不到桌面、窗口拖不动 —— 装完之后最常见的几类问题与处理顺序。

## 一、按 Home 键回不到 Smart Dock

这不是故障，是默认桌面还没设对或被系统改回去了。处理：

1. 系统设置 → 应用 → 默认应用 → 「桌面」，确认当前是 Smart Dock；
2. 有的系统（尤其国产 ROM 的「一键清理」或省电策略）会在后台把默认桌面重置，确认后再改一次；
3. 改完按 Home 验证；想临时回原桌面，同样在默认应用里切回去，两边共存不冲突。

## 二、设置里找不到「无障碍」或「通知」开关

这是部分机型对第三方应用隐藏了入口。按官方解法走：应用详情页 → 右上角三点菜单 → 「允许受限权限」，开关就会出现，步骤详见[ADB授权与高级功能设置.md](ADB授权与高级功能设置.md)第二节。如果连「允许受限权限」都没有，说明该 ROM 把这条路也堵了，只能改走 ADB 授权。

## 三、键盘快捷键、手势不生效

按出现频率排查：

1. **无障碍服务是否已开** —— 快捷键依赖它拦截系统按键，没开就是完全无反应；
2. **外接键盘是否已被系统识别** —— 蓝牙键盘先在系统设置里确认连接正常；
3. **是否授了 `WRITE_SECURE_SETTINGS`** —— 部分快捷键设置保存不生效是因为缺这个权限，执行[ADB授权与高级功能设置.md](ADB授权与高级功能设置.md)第三节的命令；
4. 升级后设置偶有失效 —— 官方更新日志里出现过「部分功能在打开对应设置页之前不工作」的修复（1.9.8），进设置里对应页翻一遍再退出，通常能激活。

## 四、小窗拖不动 / 窗口浮不起来

悬浮窗权限没给。系统设置 → 应用 → Smart Dock → 权限 → 「显示在其他应用上层」打开；部分 ROM 还要在「权限管理」里单独放行。给完杀掉进程重进。

## 五、通知不显示、角标数字不对

1. 通知访问权限是否已给（见上一条同款路径）；
2. 深色主题下通知计数文本颜色异常 —— 1.14.1 的更新日志明确修复了这个问题，如果你的版本更旧，升级即可；
3. 想让某个应用不出现在通知面板里：1.13.0 起支持**按应用忽略通知**，在通知面板的设置里勾选。

## 六、导航栏挡住了 Dock

走[ADB授权与高级功能设置.md](ADB授权与高级功能设置.md)第五节的隐藏导航栏方案；没有 root 的机器可以先用 Smart Dock 自身的全屏/手势模式凑合，不一定非要把系统导航栏干掉。

## 七、安装或启动报错、闪退

| 现象 | 原因与处理 |
| --- | --- |
| 安装时提示解析包错误 | APK 没下完整，重新下载（网盘文件大小应为 6.07M，可对照） |
| 安装被阻止 | 没给「安装未知应用」权限，按系统提示放行文件管理器 |
| 一启动就闪退 | 系统版本低于最低要求；1.14.1 需 Android 7.0 以上，若你的是 Android 6.x 则不支持 |
| 装了最新版后闪退 | 1.15.0 起不再支持 Android 9 及以下，低版本系统请改装 1.14.x 系列 |

版本线与各版本对应的系统要求，见[版本更新与开源信息.md](版本更新与开源信息.md)。

## 八、Dock 自己消失、通知变慢

进程被系统当后台应用清掉了，不是界面坏了。电池优化白名单、各品牌 ROM 的后台放行、最近任务加锁这一整套处理，单独写在[后台保活与电池优化.md](后台保活与电池优化.md)，照着做即可。

## 九、上滑/返回手势跟原桌面冲突

有第三方教程提到，在部分机型（如 OPPO 平板）上从屏幕底部上滑可在 Smart Dock 与原桌面之间来回切，属于各家 ROM 手势层面的行为，因机型而异。你的手势与 Smart Dock 抢冲突时，优先在系统里把「默认桌面」锁死为 Smart Dock，再在 Smart Dock 设置里调整手势灵敏度。

## 十、还没解决怎么办

官方支持渠道是 [Telegram 群](https://t.me/smartdock358)（`t.me/smartdock358`）与 [GitHub Issues](https://github.com/axel358/smartdock/issues)。提问前带上：系统版本、Smart Dock 版本、已授予的权限清单，能省掉一轮来回。
