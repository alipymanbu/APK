## 一、先对号入座

Smart Dock 要常驻后台才谈得上「任务栏随时在」。你如果遇到下面这些情况，就是被系统的省电策略清了，本篇的设置就是对症的：

- 用一段时间后底部 Dock 自己消失，点开应用才发现 Smart Dock 进程没了；
- 通知角标变慢、通知面板刷新不出来；
- 一键清理 / 手动清后台之后，Smart Dock 跟着被清掉；
- 重启手机后要手动打开一次才恢复。

**一个前置差别**：把它**设为默认桌面**后，系统对桌面进程通常更宽容，问题会少很多；如果你按第三方教程的用法把它当**悬浮任务栏**挂在原桌面上（不设默认），它就是个普通后台应用，下面每一条都用得上。两种用法见[下载与安装教程.md](下载与安装教程.md)与[多窗口桌面模式使用指南.md](多窗口桌面模式使用指南.md)。

## 二、原生 Android 的两处设置

1. **电池优化加白名单**：设置 → 电池 → 电池优化（有的机型在「应用与通知 → 特殊应用权限」里），列表切到「全部应用」，找到 Smart Dock，选**不优化**。
2. **后台限制别给限了**：系统设置 → 应用 → Smart Dock → 电池，确认是「无限制 / 允许后台运行」，不是「受限」。Android 8 以上还有一处「后台限制」（Background restrictions）要确认没启用。

改完杀一次进程重开验证。这两步覆盖原生系统，国内 ROM 还要再往下看。

## 三、各品牌 ROM 的对应位置

国产 ROM 的清理比原生激进，入口各不相同，按品牌对号（菜单名以你的系统当时显示为准）：

| 品牌 | 要动的设置 |
| --- | --- |
| 华为 / 荣耀 | 设置里搜「应用启动管理」→ 找到 Smart Dock → 关掉「自动管理」→ 手动打开允许自启动、关联启动、后台运行；再在「电池 → 电池优化」里设为不优化 |
| 小米 / Redmi | 应用信息 → 省电策略 → 选「无限制」；再进最近任务，下拉卡片锁定（加锁后一键清理不会清它） |
| OPPO / vivo / 一加 | 应用信息 → 「允许后台活动 / 后台耗电」放开；在手机自带的「清理」类功能里把它加入白名单 |
| 三星 | 电池 → 后台使用受限应用 → 确认 Smart Dock 不在列表里 |

各家的完整对照表可以查 [dontkillmyapp.com](https://dontkillmyapp.com)（按厂商分页的第三方汇总，页面持续更新）；华为那条有官方支持文档背书，其余为社区汇总，逐条试到生效即可。

## 四、三个容易漏掉的点

1. **最近任务里加锁**：清后台前，在最近任务界面对 Smart Dock 的卡片下拉加锁（多数 ROM 支持），这样「一键清理」也不会带走它。
2. **开发者选项别开过头**：如果你为调试开过开发者选项，检查「不保持活动」是关闭的、「后台进程限制」是「标准限制」——这两项设错会让任何桌面类应用都活不下来。日常用建议关掉开发者选项。
3. **第三方清理工具**：装了清理大师、管家类应用的话，把 Smart Dock 加进它们的白名单，或者干脆卸载 —— 这类工具的后台策略常比系统本身还狠。

## 五、验证是否生效

改完一轮后这样验：打开 Smart Dock → 切到别的应用放两分钟 → 从后台清一遍别的应用 → 回来看 Dock 是否还在、通知是否正常。还不行就回头检查第二节的两处是否真的改到了（有的 ROM 改完会自己弹回默认值），仍无解的话带上机型与系统版本去[常见问题排查.md](常见问题排查.md)末尾的官方渠道问。
