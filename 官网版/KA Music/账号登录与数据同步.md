# KA Music 账号登录与数据同步

> KA Music 使用酷狗账号登录（手机号 + 短信验证码），登录后收藏、歌单等数据跟随账号走。本篇讲登录步骤、哪些数据会同步、换手机怎么恢复，以及把它当第三方客户端用时的账号注意事项。

## 一、登录步骤

1. 打开 KA Music，进入登录页；
2. 输入你的酷狗账号绑定的手机号；
3. 获取并填入短信验证码，完成登录。

KA Music 没有独立的账号体系，用的就是酷狗账号。还没有酷狗账号时，可以先在酷狗官方 App 或官网注册一个，再回来登录。

## 二、登录后哪些数据跟着账号走

| 数据 | 是否跟随账号 | 说明 |
| --- | --- | --- |
| 收藏（我喜欢） | 是 | 换设备登录后仍在 |
| 自建歌单与收藏的歌单 | 是 | 整理方法见 [歌单管理与导入.md](歌单管理与导入.md) |
| 云盘音乐 | 是 | 应用内的个人云盘存储入口 |
| 个性化推荐 | 是 | 基于账号的听歌历史 |
| 已下载的歌曲、播放缓存 | 否 | 属于本机数据，换机或卸载后需要重新下载 |

一条实用判断：**账号里的东西换手机不丢，本机下载的东西换手机要重来**。换机前不必导出什么，新设备登录同一账号即可拉回收藏与歌单。

## 三、重装或换机后

1. 新装（或重装）应用后用同一手机号登录；
2. 收藏、歌单、云盘内容会自动回来；
3. 之前下载到本机的歌曲不会恢复，按 [离线缓存与下载管理.md](离线缓存与下载管理.md) 重新下载需要的部分。

## 四、当第三方客户端用，账号方面要知道的事

- KA Music 不是酷狗官方出品，是个人开源项目（MIT 许可证），项目页标注「仅供学习交流使用」；
- 用你的账号登录，意味着听歌记录、收藏等操作会写进这个账号，官方 App 里同样能看到；
- 音乐数据经由项目对接的接口获取，这类接口的可用性不受酷狗官方保障，某天整体不可用属正常风险，可关注项目仓库的更新；
- 如果介意日常账号里混入第三方客户端的听歌记录，可以单独注册一个酷狗账号专门给它用；
- 同一账号在多台设备上登录可能互相挤掉线——这是酷狗官方的账号安全策略，同类第三方客户端同样受此限制。

## 五、登录不上时的排查

| 现象 | 可尝试 |
| --- | --- |
| 收不到验证码 | 确认手机号无误后重发；检查短信拦截记录；换网络环境再试 |
| 验证码正确却登录失败 | 稍等几分钟再试；重启应用后再登录 |
| 登录后内容加载失败 | 先排除本机网络问题；持续失败可能与接口状态有关，去项目仓库看有没有相关反馈 |
| 重启后要求重新登录 | 避免用系统清理类工具清掉该应用的数据（登录态会一起被清）；持续出现可到项目仓库反馈 |
| 提示异地登录 / 需要验证 | 酷狗的安全机制被触发，按提示完成验证，或换网络环境再登 |
