# 顶部横幅弹窗怎么关

> BuzzKill 的静音动作管不住屏幕顶部的横幅弹窗（heads-up notification），本篇讲原因，以及用电脑 ADB 授权让静音规则顺带把横幅也藏掉的方法。

## 一、为什么静音了横幅还在

安卓的「横幅弹窗」是应用在亮屏时从屏幕顶部探出来的那块通知。BuzzKill 的 Mute 动作只负责「不响不震」，**默认藏不掉横幅**——这是系统权限的边界，不是规则没写对。

解决办法是给 BuzzKill 授一个特殊权限 `WRITE_SECURE_SETTINGS`，授权后它的静音规则就能在需要时临时关掉横幅弹窗。这个权限普通设置界面给不了，要连电脑走一次 ADB。这是官方提供的可选方案：不授权应用照常工作，只是管不了横幅。

## 二、授权步骤

### 第 1 步：打开开发者选项

系统设置 → 关于手机 → 连点「版本号」七次（小米机型连点「MIUI 版本」）。

### 第 2 步：打开 USB 调试

在开发者选项里启用「USB 调试」。个别品牌要多做一步：

| 品牌 | 额外操作 |
| --- | --- |
| 华为 | 同时开「USB 调试（安全设置）」；开发者选项在「附加设置」里 |
| realme | 勾选「停用权限监控」（disable permission monitoring） |
| 一加 | 勾选「停用系统优化」（disable system optimization） |

### 第 3 步：用 USB 线连接电脑

手机弹出「是否允许 USB 调试」时点允许。

### 第 4 步：执行命令

**Windows**：打开「命令提示符」（cmd），整段粘贴回车：

```text
curl -L https://dl.google.com/android/repository/platform-tools_r30.0.0-windows.zip -o platform.zip && ^
powershell -Command "Expand-Archive 'platform.zip' '.'" && ^
cd platform-tools && ^
adb.exe shell pm grant com.samruston.buzzkill android.permission.WRITE_SECURE_SETTINGS && ^
adb.exe kill-server && ^
cd .. && ^
del platform.zip && ^
rmdir /Q /S platform-tools
```

**Mac / Linux**：打开终端，整段粘贴回车：

```text
curl -s https://dl.google.com/android/repository/platform-tools_r30.0.0-darwin.zip -o buzzkill_adb.zip && unzip -qq -o buzzkill_adb.zip && ./platform-tools/adb shell pm grant com.samruston.buzzkill android.permission.WRITE_SECURE_SETTINGS && echo "Successfully granted permission" ; rm buzzkill_adb.zip && rm -r platform-tools
```

（Mac 用户把 URL 里的 `darwin` 换成 `linux` 即为 Linux 版命令。）

命令做的事：从 Google 服务器下载官方平台工具（执行即表示接受其许可协议）→ 给 BuzzKill 授权 → 清理下载物。Mac/Linux 成功时输出 `Successfully granted permission`；Windows 版不报错即成功。授权完成后，静音规则触发时横幅会被一并藏掉。

## 三、和「验证码看不到」不是同一个权限

如果你同时被两个问题困扰——横幅藏不掉、验证码读不到——它们对应**两个不同的特殊权限**，要分别跑两次授权命令（`WRITE_SECURE_SETTINGS` 与 `RECEIVE_SENSITIVE_NOTIFICATIONS`），步骤流程相同、命令不同。各自的命令见对应页面：本页是横幅弹窗，另一个见 [验证码通知看不到怎么办.md](验证码通知看不到怎么办.md)。

授权后如果静音规则还是不安静，先按 [常见问题排查.md](常见问题排查.md) 第三节查规则触发与静音模式。
