# 验证码通知看不到怎么办

> 安卓 15 起系统会把验证码类通知的内容挡在第三方应用之外，本篇讲原因和两条解法：关「增强通知」、或用电脑 ADB 给授权。

## 一、现象与原因

装好 BuzzKill 后，你可能会发现：银行、聊天应用发来的**验证码类通知**，历史记录里只有壳、没有内容，规则也匹配不上。这是安卓 15 的新安全机制造成的——系统会自动识别「疑似二次验证码」的通知（哪怕只是含一长串数字的通知也可能被波及），不让第三方应用读到内容。这不是应用坏了，是系统层在拦。

## 二、解法一：关掉「增强通知」（简单，推荐先试）

1. 打开系统设置应用。
2. 进入通知设置。
3. 关闭「Enhanced notifications」（增强通知）。

关掉之后，系统不再主动识别验证码类通知，BuzzKill 就能读到它们了。代价：快捷回复按钮这类依赖「增强通知」的智能功能会失效。介意这个代价的，用解法二。

## 三、解法二：用电脑给 BuzzKill 授权（需 USB 连电脑）

这条路是给 BuzzKill 单独授一个特殊权限 `RECEIVE_SENSITIVE_NOTIFICATIONS`——安卓把它归为特殊权限，普通设置界面给不了，官方因此提供 ADB 授权方案。全程约五分钟。

### 第 1 步：打开开发者选项

系统设置 → 关于手机 → 连点「版本号」七次（小米机型连点「MIUI 版本」）。

### 第 2 步：打开 USB 调试

在开发者选项里启用「USB 调试」。个别品牌要多做一步：

| 品牌 | 额外操作 |
| --- | --- |
| 华为 | 同时开「USB 调试（安全设置）」；开发者选项在「系统和更新 → 开发人员选项」或「附加设置」里 |
| realme | 勾选「停用权限监控」（disable permission monitoring） |
| 一加 | 勾选「停用系统优化」（disable system optimization） |

### 第 3 步：用 USB 线连接电脑

手机连上电脑后，手机会弹「是否允许 USB 调试」，点允许。

### 第 4 步：执行命令

**Windows**：打开「命令提示符」（cmd），整段粘贴回车：

```text
curl -L https://dl.google.com/android/repository/platform-tools_r30.0.0-windows.zip -o platform.zip && ^
powershell -Command "Expand-Archive 'platform.zip' '.'" && ^
cd platform-tools && ^
adb.exe shell cmd appops set --user 0 com.samruston.buzzkill RECEIVE_SENSITIVE_NOTIFICATIONS allow && ^
adb.exe kill-server && ^
cd .. && ^
del platform.zip && ^
rmdir /Q /S platform-tools
```

**Mac / Linux**：打开终端，整段粘贴回车：

```text
curl -s https://dl.google.com/android/repository/platform-tools_r30.0.0-darwin.zip -o buzzkill_adb.zip && unzip -qq -o buzzkill_adb.zip && ./platform-tools/adb shell cmd appops set --user 0 com.samruston.buzzkill RECEIVE_SENSITIVE_NOTIFICATIONS allow && echo "Successfully granted permission" ; rm buzzkill_adb.zip && rm -r platform-tools
```

（Mac 用户把 URL 里的 `darwin` 换成 `linux` 即为 Linux 版命令。）

命令会自动从 Google 服务器下载平台工具（接受其许可协议）、授权、再自我清理。Mac/Linux 成功时输出 `Successfully granted permission`；Windows 版不报错即成功。

报 `SecurityException` 的，回开发者选项临时勾选「停用权限监控」（realme 等）再跑一次。

### 第 5 步：重启手机

授权后**必须重启**。之后新来的验证码类通知，BuzzKill 就能正常读到、按你的规则处理了。

## 四、两条解法怎么选

| | 解法一：关增强通知 | 解法二：ADB 授权 |
| --- | --- | --- |
| 难度 | 设置里点两下 | 需要电脑 + USB + 命令行 |
| 代价 | 快捷回复等智能功能失效 | 无已知功能代价 |
| 可逆 | 随时开关 | 只改这一个应用的权限，日常使用无感 |

只想让验证码规则能跑起来的，先试解法一；在意快捷回复功能的，再走解法二。装好后的规则写法见 [过滤规则怎么写.md](过滤规则怎么写.md)，验证码自动复制的动作见 [通知动作一览.md](通知动作一览.md) 第七节。
