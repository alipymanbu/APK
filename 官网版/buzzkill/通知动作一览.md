## 一、九大类动作总览

动作就是规则的后半句「然后做什么」。官方把它们分成九类，和条件组合就能覆盖大多数场景（条件怎么写见 [过滤规则怎么写.md](过滤规则怎么写.md)；一条规则挂多个动作用 Multi-tool，其动作按排列顺序定优先级）：

| 类别 | 动作 |
| --- | --- |
| 静音类 | Mute、Cooldown |
| 提醒类 | Alarm、Pocket check、Remind me、Speak、Unsilence |
| 延迟类 | Batch、Batch every、Add snooze button |
| 改动类 | Custom alert、Flashlight、Secret、Sticky、Summarize、Add share button |
| 移除类 | Dismiss、Keep if、Undo dismiss |
| 自动化类 | Open notification、Press button、Reply |
| 复制类 | Copy verification code |
| 系统类 | Restore after reboot、Set ringer、Trigger Tasker、Trigger MacroDroid、Remove from history |
| 进阶类 | Multi-tool |

## 二、静音类

| 动作 | 效果 | 典型用法 |
| --- | --- | --- |
| Mute | 通知不响不震，但仍出现在通知栏 | 购物应用只留「订单更新」响铃，其余全静 |
| Cooldown | 放行第一条，之后一段时间内同一应用/会话的通知静音（或移除） | 对「一句消息拆成五条发」的人和刷屏的群 |

## 三、提醒类

| 动作 | 效果 | 典型用法 |
| --- | --- | --- |
| Alarm | 把通知变成全屏闹钟，走闹钟音量——静音和勿扰模式也拦不住，锁屏之上显示 | 值班待call；孩子学校或特定家人的来电消息 |
| Pocket check | 手机在兜里按一下电源键：有重要通知震三下，没有震一下 | 开会时不掏手机，确认有没有对象发来的消息 |
| Remind me | 按间隔反复响铃+震动，直到你处理掉这条通知 | 未接来电、不许错过的日历提醒 |
| Speak | 用 TTS 朗读通知（读标题、正文或自定义句子） | 骑车、做饭时听是谁发来的 |
| Unsilence | 手机静音/震动状态下，放行这一条让它出声 | 整夜静音但家人的电话照响；勿扰时段含 `urgent` 的消息照响 |

## 四、延迟类

| 动作 | 效果 | 典型用法 |
| --- | --- | --- |
| Batch | 在设定时段内藏起匹配的通知，时段结束后打包一次性还给你 | 上班时间扣住所有社交媒体通知，下班一起收 |
| Batch every | 按固定间隔批量送达，而不是攒到某个时刻 | 邮件一天收两三次 |
| Add snooze button | 给通知加一个「稍后再说」按钮，按下就藏起来、到点回来 | 午饭后再处理的消息，不想让它一直挂着 |

## 五、改动类

| 动作 | 效果 | 典型用法 |
| --- | --- | --- |
| Custom alert | 给通知换专属铃声或震动节奏，盖过应用默认的 | 老板、伴侣、快递各一种震动，不看屏幕也知道是谁 |
| Flashlight | 闪光灯按你定的节奏闪 | 手机扣在桌上戴耳机时用；听觉不便或在嘈杂环境时的视觉提醒 |
| Secret | 把通知替换成通用样式（标题你自己定 +「New notification」），真实内容藏起来 | 锁屏上不露银行、健康类通知的原文 |
| Sticky | 让通知不被「全部清除」一键清掉。注意：安卓 14 起系统允许手动单划走它，「全部清除」按钮才绕不过 | 容易被一键清掉的待办、要回的消息 |
| Summarize | 把匹配的多条通知合并成一条 | 新闻类应用的通知合成一条，一起划走 |
| Add share button | 给通知加「分享」按钮，把文字发给别的应用 | 转发验证码、地址、待办 |

## 六、移除类

| 动作 | 效果 | 典型用法 |
| --- | --- | --- |
| Dismiss | 把通知移除，可立即执行也可延迟 | 推广通知 10 分钟没碰就清掉；只留含「已发货/已送达」的物流通知 |
| Keep if | 反着用：命中例外条件的通知原样保留，**没命中的立即移除**（如「来自工作群的通知 → Keep if 包含 Boss 或 Emergency」） | 群里只留老板和紧急消息，其余清掉 |
| Undo dismiss | 匹配的通知被你划走后，弹 20 秒的「Restore」提示 | 防手滑：划错了还有 20 秒可以捞回来 |

## 七、自动化与复制类

| 动作 | 效果 | 典型用法 |
| --- | --- | --- |
| Open notification | 替你点开这条通知，可延迟执行 | 网约车/外卖到了自动打开应用 |
| Press button | 替你按通知上的按钮（如「标记已读」「归档」） | 自动归档订阅邮件；机器人账号的消息直接标已读 |
| Reply | 通过通知的快捷回复发消息，可延迟 | 开车连车载蓝牙时自动回「在开车，稍后回复」 |
| Copy verification code | 从通知里找出一次性验证码，复制到剪贴板并清掉通知 | 登录任何要短信验证码的应用，切回去时码已在剪贴板 |

## 八、系统与进阶类

| 动作 | 效果 | 典型用法 |
| --- | --- | --- |
| Restore after reboot | 重启后把重启前在屏上的通知原样补回来 | 没来得及看的消息不因没电重启而丢 |
| Set ringer | 把铃声模式切成响铃/震动/静音，可同时开关勿扰 | 日历显示开会开始 → 自动静音；特定的人来消息 → 恢复响铃 |
| Trigger Tasker / Trigger MacroDroid | 把通知的标题、正文、应用名、包名交给 Tasker 或 MacroDroid 继续处理 | 门铃通知触发智能灯亮；把某应用的通知逐条记进表格 |
| Remove from history | 把匹配的通知从 BuzzKill 的历史记录里抹掉 | 想让某类通知不留在历史里 |
| Multi-tool | 一条规则挂多个动作（组内按排列顺序定优先级） | 一条规则同时「换专属铃声 + 闪光灯」 |
