## 一、规则不触发 / 通知历史里是空的

这是国内用户最常撞上的一类问题。小米、OPPO 等厂商的后台管理非常激进，会把 BuzzKill 这样的常驻后台应用拦掉，表现为**历史记录缺通知、规则该动不动**。官方给出了对应处理清单：

**所有机型都要做的：**

1. 系统设置 → 应用 → BuzzKill：关掉一切会阻止它后台运行的电池/省电选项。
2. 系统设置 → 无障碍：把 BuzzKill 开进去。

**小米另做：**

- 系统设置 → 应用 → BuzzKill：开「允许受限设置」。
- 最近任务界面，长按 BuzzKill 卡片，点「锁定」。

**OPPO / 一加 / realme 另做：**

- 系统设置 → 电池 → 应用电池管理（部分版本在「更多设置」或「省电」里）→ BuzzKill：开「允许后台活动」「允许前台活动」「允许自动启动」，有「允许后台运行」也开上。
- 系统设置 → 应用 → 自启动（或叫「启动管理」）：允许 BuzzKill。
- 最近任务界面，点 BuzzKill 卡片角上的菜单，选「锁定」，避免被一键清理。
- 系统设置 → 电池：关掉「睡眠待机优化」和各类省电/超级省电模式。

改完之后**必须重启手机**——官方特别强调：光打开 BuzzKill 应用没用，只有重启才能让它重新常驻。

另外提示：换新手机或恢复出厂后，上面这些开关要**重新做一遍**，规则本身可以用导出功能带过去，见 [设置备份与换机迁移.md](设置备份与换机迁移.md)。

## 二、验证码类通知收不到 / 内容显示「已隐藏」

安卓 15 引入了新的安全机制：凡是像二次验证码这样的通知（甚至只是含一长串数字的通知），第三方应用默认读不到内容。解决办法二选一：

1. **关掉系统的「增强通知」**：系统设置 → 通知设置 → 关闭「Enhanced notifications」。代价是快捷回复按钮这类「智能」功能会失效。
2. **给 BuzzKill 授特殊权限**：需要在电脑上用 ADB 执行一条授权命令（`RECEIVE_SENSITIVE_NOTIFICATIONS`），不影响系统其他功能，授权后重启手机生效。

两种解法的完整步骤、Windows/Mac/Linux 三种命令、各品牌注意事项，单独整理在 [验证码通知看不到怎么办.md](验证码通知看不到怎么办.md)。如果你的规则要处理银行验证码、动态码这类通知，优先试第一种，简单且可逆。

## 三、静音规则「没生效」

先按这个顺序查：

1. **确认规则真的触发了**：去历史记录页找到那条通知，看它上面有没有「rule activated」标记。没有标记说明规则根本没匹配上，回头调条件的短语和范围。
2. **规则触发了但还在响**：改设置里的「Mute mode」（静音模式）。安卓本身没有「静音另一条通知」这个直通开关，BuzzKill 是用几种迂回手段实现的，分三档，激进程度递增：

| 档位 | 做法 |
| --- | --- |
| Low | 向系统请求把该通知静音（最温和的一档） |
| Default | 把通知短暂「打盹」（snooze）来实现安静 |
| High | 打盹之外，还会临时开启勿扰模式 |

默认档压不住的，切到 **High** 再试——官方的建议原话就是「把 Mute mode 设成 High」。另外注意规则冲突也会表现为「静音没生效」——一条更具体的规则给了它自定义响铃，冲突裁决后响铃那条赢，完整逻辑见 [过滤规则怎么写.md](过滤规则怎么写.md) 第四节。

## 四、部分应用的通知收不到 / 历史里没有它

个别应用的通知可能被排除在 BuzzKill 的读取范围之外，去检查通知权限的分类勾选：

1. 系统设置 → 通知设置 → 「通知读取、回复与控制」（各品牌叫法略有差异）。
2. 进入 BuzzKill 这一项，确认**全部分类都勾上**。
3. 点「查看全部应用」，把缺失的那个应用也勾上。

改完后看历史页里新通知有没有开始出现、规则有没有开始触发。

## 五、划掉的通知还能找回来吗

两种途径：

- **事前预防**：建规则时挂 **Undo dismiss** 动作，匹配的通知被你划走后会弹 20 秒的「Restore」提示，点一下就回来。
- **事后兜底**：BuzzKill 默认把所有通知存进**历史记录**（保留 30 天，可在设置里调到 3 或 6 个月），划掉的通知去历史页翻得到。若你在设置里把历史改成了「不保存」，那就真没了。

## 六、杂项小问题

| 现象 | 说明 |
| --- | --- |
| 界面没有中文 | 有用户反馈界面目前只有英文，功能不影响，按图标和位置能对上 |
| 工作资料 / 私密空间里的应用选不到 | 选应用时留意切换工作资料/私密空间目录，官方帮助中心有专门说明页 |
| 静音了但横幅弹窗照样探出来 | Mute 默认管不到横幅；想让静音规则连横幅一起藏，要走一次 ADB 授权，见 [顶部横幅弹窗怎么关.md](顶部横幅弹窗怎么关.md) |
| 震动不响 | 官方帮助中心有专页（`buzzkillapp.com` → Help → Problems），多数与系统震动设置或规则冲突有关 |
| 手表上看不到效果 | Wear OS 手表上大部分动作（提醒、静音等）都不支持，只会发生在手机上；官方的 Wear OS 伴侣应用目前只做一件事——手机触发 Alarm 规则时手表跟着响铃。另外把设置里的 Mute mode 调到 High，静音有机会连带作用到手表 |

以上现象如需深查，直接翻官方帮助中心 `https://buzzkillapp.com/help/`，按现象找对应条目。
