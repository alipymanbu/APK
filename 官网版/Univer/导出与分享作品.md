# Univer 作品导出与分享方法

> 本篇讲怎么把在 Univer 里做好的游戏导出成 APK 或小程序，以及分享、上架时的要点。

作品在编辑器里做完、试玩通过之后，最后一步是让它离开你的手机：导出成安装包发朋友，或者按平台规则提交上架。本篇讲 Univer 支持的导出方式、导出 APK 时能自定义什么，以及上架前要注意的事。创作环节本身见[怎么制作游戏.md](怎么制作游戏.md)。

## 一、支持哪些导出格式

Univer 的作品可以一键导出为两种格式：

| 导出格式 | 适合的用途 |
| --- | --- |
| APK | 发给别人直接安装、提交安卓应用商店上架 |
| 小程序 | 在支持小程序的平台上跑，适合轻量展示与传播 |

两种都是成品输出，玩家拿到手不需要装 Univer 本体就能玩。还有一点要先知道：截至 2026.1.1r1，Univer 只支持导出成品，工程文件的导入导出功能官方标注为「后续推出」——也就是说项目本身无法打包转移，想在另一台手机上继续做同一个项目，暂时没有官方途径。

## 二、导出 APK：能自定义什么

走 APK 这条路时，导出环节支持自定义签名、包名、图标三样东西。这三样正好是上架应用商店的硬性要求：

- **签名**：每个商店都要求提交的包经过正式签名，用你自己生成的签名即可；
- **包名**：改成你自己定的包名，别和其他已上架应用重复；
- **图标**：换成你的作品图标，商店审核也会看图标与内容是否一致。

导出前先在运行模式里把作品完整过一遍，确认没有明显 bug 再打包——导出的 APK 就是最终交给玩家或商店的东西，里面的问题都要靠重新导出来修。

还有一条安卓的通用规则要记住：**只有包名和签名都相同的 APK 才能覆盖安装升级**。改了包名或换了签名，新包会被系统当成另一个应用；签名不一致时覆盖安装会被直接拒绝，提示「应用未安装」。所以第一版导出时就把包名定好、签名文件保管好，后续更新沿用同一套，玩家才能直接覆盖升级而不用先卸载。

## 三、想上架应用商店的话

导出 APK 支持自定义签名、包名、图标，符合平台规则即可上架。实际操作时注意：

1. 不同商店对个人开发者的资质要求不同，有的需要先注册开发者账号并通过实名认证，有的还要求软件著作权等材料，提交前先看目标商店的入驻说明；
2. 包里不得含违规内容，商店会实际试玩审核，作品内容合规是前提；
3. 各商店的审核周期与驳回标准不一，被驳回时按商店给出的理由改了重新提交。

「符合平台规则」这六个字由目标商店解释，上架这件事的主动权在商店那边，材料备齐、内容合规是你能控制的部分。

## 四、不打算上架，只想给朋友玩

不上架也有简单的玩法：导出的 APK 文件本身就是个安卓安装包，通过社交平台、聊天工具发给别人，对方下载后允许「未知来源」安装即可游玩（这一步和安装 Univer 本体的流程一样，遇到问题可参考[下载与安装教程.md](下载与安装教程.md)第三节）。官方也明确支持把原创作品分享到社交平台展示。

小程序格式则更省事：对方无需安装任何 APK，在支持的平台里打开就能玩，适合发给不折腾安装的用户。

## 五、常见导出问题

| 现象 | 先检查什么 |
| --- | --- |
| 导出按钮点了没反应 | 手机剩余存储是否够写出新包；运行中的项目是否异常退出过 |
| 导出的 APK 装不上 | 签名、包名是否按平台要求配置过；包是否在传输中被截断 |
| 商店审核被驳回 | 看驳回理由：资质材料、包名冲突、内容合规，逐项对照处理 |

导出相关之外的问题（配置要求、素材导入、工程备份限制等）见[常见问题解答.md](常见问题解答.md)。
