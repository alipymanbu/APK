## 一、能从哪里导入素材

老版 Quik 的素材来源如下，一次项目里**最多放 75 个照片或视频片段**：

| 来源 | 说明 |
| --- | --- |
| 手机相册 / 图集 | 最常用的入口，点主界面下方的「+」后按相册勾选 |
| Google Photos | 云相册里的内容也能选（需能正常访问该服务） |
| Dropbox | 网盘素材直读 |
| GoPro Plus | GoPro 的云订阅账号里存的素材 |
| GoPro Quik Key | GoPro 出的 SD 读卡器，插手机直接读相机存储卡 |
| 动态照片（Motion Photos） | 各家手机拍的那种「会动一两秒的照片」，可以直接导入 |

用 GoPro 相机拍的素材同样认，具体哪些型号支持、需要什么前提，见 [常见问题与使用限制.md](常见问题与使用限制.md) 里的相机清单。用普通手机拍的素材是完整支持的，本文讲的流程对两类素材都适用。

## 二、Quik 自动做了哪些事

素材选完的一瞬间，它已经替你干完了大部分活：

1. **找精彩瞬间**：分析每段视频的声音、画面变化，把跳跃、欢呼、人声、加速这类时刻挑出来，只取精华几秒，不整段塞给你。
2. **人脸与色彩取景**：识别画面里的人脸和主体颜色，自动决定每张照片取景框的位置，横竖图都会自动裁到当前格式。
3. **配转场与对齐节拍**：按你选的主题和音乐，把片段串起来，转场落点和音乐的节奏对齐。
4. **检测到人声自动开声音**：片段里有人说话时，会自动把这段的原始声音打开，其余片段保持静音走音乐。

这套自动化出来的就是一版可以直接看的成片。你对它不满意的每一处，下面第三节都有对应的接手方式。

## 三、哪些地方可以手动接管

自动结果出来后，底部有一排入口（风格、音乐、编辑、格式、保存），逐个说说编辑那一项里能改什么：

- **调顺序**：长按任意片段拖动，重新排列；不要的片段直接删。
- **修剪视频**：点开单个片段选「修剪」，可以手动划定这一段从哪到哪；不手动改的话走 Smart Cuts（自动取精华）或整段全用。
- **照片取景与旋转**：自动取景不准的照片，手动挪取景框的焦点；方向不对可以旋转。
- **变速**：单段视频加速或慢放。
- **照片/标题页时长**：每张照片停留几秒可以单独调，改完它自动重新对齐节奏和转场。
- **加文字**：片段上加文字叠加层，或插一页标题页，还能加表情符号。
- **撤销与重做**：改错了随时撤回，再点一次还能恢复——在自动成果上放心动手。
- **循环播放**：编辑单个片段时可以循环播放反复看，判断修剪的出入点更省事。

这些改动都是即时预览的，改完底部换到「保存」就出片。导出参数怎么选见 [导出分辨率与分享设置.md](导出分辨率与分享设置.md)。

## 四、HiLights：让自动剪辑听你的

如果你觉得它选的瞬间不对味，不必完全手动剪——**HiLights 标记**是两者之间的折中：

1. 勾选视频素材时（或从 GoPro 相机导入时），在时间轴上把你觉得精彩的时间点点一下，打上标记。
2. 之后 Quik 会围绕每个标记点剪出一段，等于「你圈重点，它来下刀」。

GoPro 相机机身自带的 HiLight 标记键录下的高光时刻也会被 Quik 认出来，直接优先生成。

## 五、给大素材提个醒

一次塞满 75 个大体积视频片段，低配手机在分析阶段和导出阶段都可能吃力。实际用下来比较稳的做法：

- 长视频先在相册里截取到十几秒的精华段，再进 Quik；
- 一支片子控制在一二十个片段，超过的话拆成两个项目分别剪；
- 导出前手机留足存储空间，导出环节的注意事项见 [导出分辨率与分享设置.md](导出分辨率与分享设置.md)。

卡顿、闪退的具体排查写在 [常见问题与使用限制.md](常见问题与使用限制.md)。
