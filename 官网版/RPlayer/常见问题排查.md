## 一、某首歌放不出来

按出现频率从高到低查：

1. **格式不支持**：确认文件扩展名是它支持的（MP3、WAV、FLAC、AAC、M4A 等常见格式没问题；比较偏门的格式先用别的播放器试，能放说明文件没问题，是 RPlayer 不认这个编码）。
2. **文件本身坏了**：把同一文件放到电脑或另一个播放器上放，能放才说明问题在 RPlayer 这侧。下载中断的歌常见「能加载不出声」。
3. **存储空间不足**：手机快满时应用可能读不了文件，清理出几十 MB 再试。
4. **权限没给**：系统设置 → 应用 → RPlayer → 权限，确认媒体权限在允许状态；被拒绝后曲库可能是空的或只列出一部分。注意**不同安卓版本上这个权限的名字不一样**：老系统叫「存储」/「读取外部存储」，安卓 13 起拆成「照片和视频」「**音乐和音频**」等分类——音乐播放器要开的是「音乐和音频」这一项，找「存储」找不到是正常的。个别系统还提供「仅选中部分媒体」的受限授权，如果只允许了照片、没允许音频，歌照样扫不出来。
5. **路径太深或带特殊字符**：个别藏在多层目录、文件名带奇怪符号的文件会被跳过，把歌挪到 `Music/` 一级目录再重新扫描。
6. **改了权限不生效**：权限改动有的要重启应用（从最近任务里划掉再打开）甚至重启手机才生效，改完先做这两步再看曲库。

整批歌都放不出来、而不是个别文件，多半是权限或扫描目录的问题，回到 [使用方法与播放设置.md](使用方法与播放设置.md) 核对。

## 二、播放时有杂音

| 现象 | 先查什么 |
| --- | --- |
| 所有歌都有杂音 | 换一副耳机/换个蓝牙音箱放——外设问题最常见；都一样再往下查 |
| 只有某首歌有 | 文件本身质量问题，与播放器无关 |
| 开了音效才有 | 把均衡器与各类增强关掉试；叠加过载会发破（见 [界面主题与音效个性化.md](界面主题与音效个性化.md)） |
| 蓝牙下才有 | 蓝牙带宽与编码协商问题，断开重连或换回有线耳机验证 |

系统音质增强（杜比、厂商音效）与应用内音效同时开着也会互相打架，二选一。

## 三、歌词或封面不显示

1. **先看开关**：设置里「联网下载歌词和封面」是否打开——没开的话，文件没内嵌歌词的歌永远是空白页。
2. **状态栏歌词空白/无效**：这个功能只在部分设备上有用，系统不允许往状态栏画字的机型上开了也不显示；改用**歌词悬浮窗模式**（需悬浮窗权限）往往是更稳的办法。设置与权限的完整步骤见 [歌词与封面显示设置.md](歌词与封面显示设置.md)。
3. **桌面歌词不出现**：到系统设置里确认 RPlayer 的悬浮窗权限已授予。
4. **蓝牙连接后歌词异常**：历史上有版本在连蓝牙时状态栏歌词显示异常，升级到新版本通常已修复；当前版本仍异常就切悬浮窗模式。

## 四、通知栏按钮失效 / 歌中途停

这是定制系统（MIUI 等）杀后台导致的，不是应用坏了。四处放开，逐条做：

1. 系统设置 → 应用管理 → RPlayer → **允许自启动**（小米在「安全中心 → 应用管理 → 自启动」里另有总开关）；
2. 长按桌面 RPlayer 图标 → 应用信息 → **电池** → 选「**不限制后台**」/「无限制」——默认的「智能限制」会在锁屏一段时间后停掉播放；
3. **把应用锁进多任务**：呼出最近任务列表，找到 RPlayer 的卡片下拉（或长按）→ 点锁形图标。这样卡片不会被「一键清理」划掉，是各品牌安卓通用的一招；
4. 通知栏权限保持开启，歌在放时通知里才有控制按钮；手机开了「省电模式」把应用挂起时同样会中途停——听歌前临时关掉省电模式。

不同品牌的入口名称不同，但要找的就这四类：**自启动、电池策略、多任务锁定、通知权限**。全开完还停，就是 ROM 层面的策略限制（部分系统对非白名单应用强制限流），只能换机型或接受锁屏后不续播。

## 五、装不上 / 装了闪退

- **装不上**：系统拦截非商店来源时，按提示允许该来源「安装未知应用」；提示「解析错误」通常是下载的 APK 不完整，重新下（核对大小是否接近 10.99M，见 [下载与安装教程.md](下载与安装教程.md)）。
- **闪退**：先清缓存（系统设置 → 应用 → RPlayer → 清除缓存），不行再重装覆盖（同为 `com.r.rplayer`，直接再装一次即可，一般保留数据）。
- **版本太旧装不上新包或反之**：同包名覆盖安装即可，不必先卸载；要彻底重来才需要卸载，但那会丢掉播放列表等应用内数据。
