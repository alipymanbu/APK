## 一、指纹解锁能给你省什么

账户密码通常是一长串，每次开 1Password 都敲一遍既慢又容易被旁人看见。开指纹（或面容）解锁后，日常打开只按一下传感器；账户密码只在少数场景被要求重新输入。注意：**指纹只是替代输入动作，账户密码仍是根** —— 有几个场景它会回来找你，见第四节。

## 二、开启步骤

前提：手机本身已录入指纹 / 面容，且系统是 Android 12 以上。

1. 打开并解锁 1Password；
2. 右上角账户头像 → **Settings（设置）**；
3. 进 **Security（安全）**，打开你要的生物识别解锁选项（指纹 / 面容，设备支持哪些就显示哪些）；
4. 回到头像菜单点 **Lock（锁定）**，用账户密码锁一次再解锁 —— 之后就可以直接用指纹开了。

## 三、面容选项看不到？

不是漏做了步骤，是设备的面容实现不达标：1Password 只接 Android 的 Class 3 生物识别（安全等级最高那档）。很多手机的 2D 面容不满足，于是选项不出现。这种设备改用指纹解锁即可，功能上没损失。

## 四、这几种情况会强制你输账户密码

生物识别不是永久通行证，以下场景 1Password 会要求回到账户密码：

- 指纹 / 面容**连续多次识别失败**；
- 设置里「Confirm my account password（确认账户密码）」的时限到了 —— 这是官方故意设的周期性复核，可在 Security 设置里调整时长；
- 你在**系统里新增或删除过指纹 / 面容数据**（录新的手指、重录面容都会触发）。

所以账户密码不能只记在手机备忘录里 —— 它得配合 Secret Key 存在你确定找得到的地方，见 [忘记主密码怎么找回.md](忘记主密码怎么找回.md)。

## 五、自动锁定：锁太频繁烦，不锁有风险

同样在 **Settings → Security** 里管理，几项关键开关（以你的版本实际显示为准）：

| 设置 | 作用 | 建议 |
| --- | --- | --- |
| App unlock preset（解锁预设） | 一键套用一组安全档位，改前可预览会动哪些项 | 怕麻烦先看这个 |
| Lock when device locks（设备锁定时锁定） | 手机一锁屏，1Password 跟着锁 | 建议开 |
| Lock after idle（闲置后锁定） | 挂在后台一段时间没动就锁 | 5~15 分钟是常见取舍 |
| Require account password（要求账户密码的间隔） | 指纹用多久后必须重输一次密码 | 别设得太长 |

这些设置**不跨设备同步** —— 手机、平板、电脑各设各的，按各自的风险环境来。

## 六、改完没生效？

1. 改完安全设置后手动锁一次（头像 → Lock）再解锁，确认新策略已应用；
2. 指纹选项开了却不弹：先确认系统指纹本身能解锁手机；再在 Security 里关掉生物识别选项重开一次；
3. 仍异常时，删掉系统里的指纹数据重新录入，再回到 1Password 开一次（官方给出的排查顺序：更新到最新版 → 确认系统生物识别可用 → 关闭重开 → 重新录入生物数据）。

开完这些，自动填充那侧不受影响；若填充提示的行为需要单独调，见 [自动填充不弹出怎么解决.md](自动填充不弹出怎么解决.md)。
