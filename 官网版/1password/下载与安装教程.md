## 一、1Password 是什么

1Password 是 AgileBits Inc. 出的密码管理应用：你只记一个主密码，其余账号密码、银行卡、通行密钥（passkey）、安全备注都存在加密保险库里，登录时由它替你填。这篇讲怎么把它装到安卓手机上并完成第一次设置。

## 二、先确认你的安卓版本

1Password 对系统的要求分三档，装之前先对号入座（以[官方下载页](https://1password.com/downloads/android)当时显示为准）：

| 你要用的功能 | 系统要求 |
| --- | --- |
| 基本使用（存密码、自动填充） | 官方下载页当前标注 Android 12.0 或更高 |
| 指纹 / 面容解锁 | Android 12+，且设备支持 Android BiometricPrompt 接口 |
| 保存与使用通行密钥（passkey） | Android 14 或更高 |

本地这份安装包的采集记录标注「安卓 5.2 以上」，与官方页面当前口径不一致 —— 官方口径随版本抬高，**以官方下载页为准**；版本太老装不上就是不满足官方要求。

查自己的系统版本：手机「设置 → 关于手机 → 版本号」。

## 三、安装包从哪拿、怎么装

**方式一：网盘安装包（本文入口）**

1. 打开 [1Password 安装文件资源（夸克网盘）](https://pan.quark.cn/s/800665dac1df)，把 APK 转存到自己的网盘后下载到手机；
2. 点开 APK 安装，若系统弹出「禁止安装未知来源应用」，按提示给你的浏览器或文件管理器开一次「允许安装未知应用」；
3. 装完打开，先别急着注册 —— 见第五节。

## 四、首次打开：先看清楚它要什么

首次启动会依次出现这几步：

1. **登录 / 创建账户**：1Password 没有本地单机模式的「直接用」，你需要一个 1Password 账户。点创建账户会跳到官网注册页，填邮箱、设账户密码；
2. **Secret Key**：注册完成后官方会给你一串 Secret Key（密钥），并提供一份 Emergency Kit（应急包）PDF 下载。**这串 key 与账户密码是两把锁，缺一不可**，务必把应急包存到安全的地方（见 [忘记主密码怎么找回.md](忘记主密码怎么找回.md)）；
3. **进入保险库**：输账户密码（+ Secret Key）解锁，看到空的个人保险库。

已有账号的老用户选「登录」，输入邮箱 → 拉取账户地址 → 粘贴 Secret Key → 输密码，四步进去。

## 五、装完立刻做的三件事

1. **开指纹解锁**：否则每次开应用都要敲账户密码。步骤见 [指纹解锁与自动锁定设置.md](指纹解锁与自动锁定设置.md)；
2. **开自动填充**：这一步不做，密码存了也填不进浏览器和 App。步骤见 [自动填充不弹出怎么解决.md](自动填充不弹出怎么解决.md)；
3. **把应急包存好**：Secret Key 丢了、密码忘了，全靠它。打印或存进一个你确定不会丢的离线位置。

## 六、常见安装问题

- **装的时候提示「应用未安装」**：多为包不完整或系统版本不够。先核对 MD5 是否与上表一致；再确认安卓版本满足官方要求；
- **打开就闪退**：先确认系统版本；仍闪退可卸载后换方式一重装（数据在云端账号里，重装不丢，登录即可同步）；
- **注册页打不开**：注册与登录都要访问 1Password 官网，网络不通时检查你的网络环境；
- **不知道该装哪个版本**：网盘里这份是 8.11.22，日常够用；想要官方最新版可到 [官方发布页](https://releases.1password.com/android/) 查（截至 2026-09 官方最新为 8.12.36，以页面当时显示为准）。
