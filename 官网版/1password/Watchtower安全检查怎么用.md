# 1Password Watchtower 安全检查怎么用

> Watchtower 是应用内的安全雷达：告诉你哪些已存密码出过事、哪些太弱、哪些该换。

## 一、它到底在检查什么

Watchtower 拿你保险库里已保存的条目对照几类风险源，给出可直接行动的提醒：

| 检查项 | 回答的问题 |
| --- | --- |
| 数据泄露 | 你存过登录的网站是否出现在公开泄露事件里 |
| 弱密码 / 重复使用 | 哪条密码强度不够、或在多个网站复用 |
| 未启用两步验证 | 哪些网站支持但你还没开 2FA |
| 安全评分 | 上面几项汇总成一个可追踪的整体分数 |

一个关键细节：**评分与部分分析在你的设备本地完成**，不是把你的条目明细发到云端去算 —— 这与 1Password 的零知识架构一致。

## 二、在哪里打开

1. 打开并解锁 1Password；
2. 底部导航（或侧边栏）里点 **Watchtower** 入口；
3. 看到仪表盘：上方是评分与各类问题计数，下方是逐条问题列表。

泄露提醒还会出现在两处：Watchtower 本身、以及**受影响的那条登录项内部**（打开条目能看到告警）。

## 三、收到泄露提醒后的处理动作

按这个顺序做，一条泄露项的完整闭环大概长这样：

1. 打开受影响的登录项，看 Watchtower 标注的泄露信息；
2. 切到对应网站 / App，**改密码** —— 用 1Password 的密码生成器生成一条新的（长、随机、不与其它站重复）；
3. 回到条目里更新为新密码，保存；
4. 顺手把该网站的两步验证打开（条目里可加存验证码字段）；
5. 回 Watchtower 确认该条告警消失。

泄露提醒是**按网站对照公开泄露库**给出的；改完密码不等于从此免疫 —— 同一站点再次泄露会再次提醒，按同样流程再走一遍即可。

## 四、安全评分怎么看

评分汇总弱密码、复用、过期未改、未开 2FA 等维度，数字旁边会列出拖后腿的具体项。使用建议：

- **别追满分**，先把「已泄露」「明文复用」两类清零，这两类是真正会被利用的；
- 评分变化可以当体检周期用 —— 每隔一两周清一轮列表，比一次性大扫除更容易坚持；
- 分数与问题列表都随条目变动实时更新，改完密码回来看即可。

## 五、边界：它替代不了的事

- Watchtower 提醒依赖「你把密码存进了 1Password」—— 没存的账号它看不见，所以尽量让登录都走 1Password 保存；
- 它**不会自动帮你改密码**，每一步都要你去对应站点操作；
- 网站是否支持 2FA、泄露库收录是否及时，取决于第三方，提醒偶尔滞后属正常。

日常配好指纹解锁（[指纹解锁与自动锁定设置.md](指纹解锁与自动锁定设置.md)），就能高频地打开它清告警而不用反复敲密码。
