# 1Password 换新手机或手机丢了怎么办

> 数据不在手机里，在你的账户里 —— 所以换机只是重新登录，丢机才需要多做两步收尾。

## 一、先建立一个认知：手机上没有「唯一一份」数据

1Password 的条目保存在你的账户里，手机上只是**本地缓存**。这意味着：

- 手机丢了，数据没丢 —— 在任何一台新设备上登录就能全部拿回来；
- 换新手机不需要「迁移数据」，需要的是「在新机登录 + 把旧机的收尾做掉」。

真正要保护的只有两样东西：**账户密码** 和 **Secret Key（在应急包里）**。它们不在手机上，手机丢了也不受影响。

## 二、换新手机：四步接上

1. 在新机装 1Password（安装方式见 [下载与安装教程.md](下载与安装教程.md)）；
2. 打开选 **Sign in（登录）** → 输入注册邮箱 → 应用拉取你的账户地址；
3. 粘贴 **Secret Key**（从应急包里复制）→ 输入账户密码 → 登录；
4. 登录成功后条目自动从云端下来，**重新配指纹解锁**（设置不跨设备迁移）：见 [指纹解锁与自动锁定设置.md](指纹解锁与自动锁定设置.md)；自动填充也要在新机重开一次，见 [自动填充不弹出怎么解决.md](自动填充不弹出怎么解决.md)。

新机确认全部条目都在、能正常填充之后，再处理旧机（自用淘汰的直接抹除即可）。

## 三、手机丢了：按这个顺序处理

**第一件事不是改密码**。官方口径：你的账户密码从不存放在设备上，捡到的人拿不到它 —— 除非你有具体理由认为密码已泄露，否则不必急着改。

1. **在其它设备登录，确认数据完好** —— 装 1Password、按第二节登录，看到全部条目就放心了；
2. **重新生成 Secret Key**：官网登录 → 右上角头像 → **Manage Account** → **Regenerate Secret Key** → 输账户密码确认 → **下载新的应急包并存好**。旧 key 即刻作废，旧设备再也登不上你的账户；
3. **撤销丢掉的那台设备**：同一页面找到该设备条目 → 齿轮按钮 → **Deauthorize Device（撤销授权）**。做完这步，所有已登录设备下次启动都会被要求输入新 Secret Key；
4. **用系统工具定位或抹除手机**：安卓用 Google 的查找设备功能；
5. **改其它账户的密码**：丢的手机上如果登着邮箱、微信、银行 App 等，这些服务的防护水平与 1Password 无关 —— 用 1Password 生成器逐个换掉（优先改邮箱，它是所有「重置密码」链条的根）。

## 四、旧手机里的缓存会不会泄露

不会被读懂，但值得知道边界：设备上的条目缓存是用你的账户密码加密的，捡到的人打开应用先卡在锁屏，**连「你在哪个网站有账号」这类条目信息都看不到**（标题、网址同样加密）。真正薄弱的环节是**手机锁屏本身** —— 手机没设锁屏密码、应用没设「锁屏即锁」，风险就回到手机系统那一层。确认这项设置：见 [指纹解锁与自动锁定设置.md](指纹解锁与自动锁定设置.md) 第五节。

## 五、导出数据的两个注意点

个别场景（比如要把数据搬到别的密码管理器）你会想导出明文文件，注意：

1. **导出文件是明文的** —— CSV / 1PUX 不加密，拿到文件的人直接能看全部密码。不要用邮件发、不要传网盘，用完即删；
2. 手机端能做的事有限：完整的导出功能在桌面端（Mac / Windows 的 File → Export）。安卓端日常靠「复制字段 / 分屏拖拽」搬运单条即可，见 [自动填充不弹出怎么解决.md](自动填充不弹出怎么解决.md) 第六节。

顺带一提：换设备期间断网是常态，这期间能不能照常用，见 [离线能用吗与数据同步怎么回事.md](离线能用吗与数据同步怎么回事.md)。
