# 1Password 自动填充不弹出怎么解决

> 开了自动填充却在浏览器、App 里看不到提示？按这里的顺序逐项排查，多数情况是少设了一步。

## 一、先把自动填充打开（这是最常见的漏项）

1Password 不会自己接管安卓的自动填充，要手动指定。在应用里：

1. 打开并解锁 1Password；
2. 右上角点你的账户头像 → **Settings（设置）** → **Autofill（自动填充）**；
3. 点 **Open Settings**，在系统列出的「自动填充服务」里选 **1Password**；
4. 需要的话再打开 **Show filling suggestions（显示填充建议）** —— 打开后建议会出现在键盘上方或下拉框里。

做完这四步，回到浏览器点一个登录框，正常情况会看到 1Password 的提示。

## 二、Chrome / Brave 用户多做一步

如果你用 Chrome 141 及以上或 Brave 1.83 及以上，官方要求额外配置一次：

1. 打开 Chrome（或 Brave）→ 右上角三个点 → **设置**；
2. 下滑找到 **Autofill services（自动填充服务）**；
3. 选 **Autofill using another service（使用其他服务自动填充）**；
4. 按提示 **重启 Chrome / Brave**。

不重启不生效。这一步做完，浏览器里才能正常保存与填充密码、通行密钥、银行卡和地址。

## 三、提示该出现在哪：键盘上方 vs 输入框下方

1Password 的填充提示有两个位置可选，行为不一样：

- **键盘上方（suggestion strip）**：依赖输入法的「建议条」。如果你的键盘关了文本纠错建议条、或用实体键盘，提示就不出现；
- **输入框下方**：不依赖输入法，更稳。

设置路径：**Settings → Autofill → Display Autofill Prompts**，选 **Below the fields they relate to（在相关输入框下方）**，选完**重启 1Password**。反复出现「提示闪一下就消失」「点了没反应」的，先切到这个模式再试。

## 四、排查清单（从上到下逐条过）

不弹提示时按顺序检查，走到哪条修哪条：

1. 系统的自动填充服务是不是 1Password（第二节路径回查）—— 被别的管理器（如 Samsung Pass）抢回去就会失效：三星手机到「设置 → 安全和隐私 → 更多安全设置 → 密码、通行密钥和自动填充」，在附加服务里**取消勾选 Samsung Pass**；
2. 1Password 应用内 **Settings → Autofill** 有没有红色告警 —— 有就按它给的链接去修（Chrome 新版常有这项没配好）；
3. 输入法的建议条有没有开（Gboard 在「设置 → 文本纠错 → 显示建议条」）—— 只想用输入框下方模式的可跳过；
4. 1Password 是否处于**已解锁**状态 —— 锁着时部分场景不出提示，先打开它解锁再回登录页；
5. 该登录项有没有填对 —— 一点关系都没有时，长按输入框 → 「自动填充 / 自动补全」手动唤起，看 1Password 有没有出现在选择列表里；
6. 浏览器强制关闭后重开；仍不行，重启手机再试。

## 五、点了提示但没填进去

- **同一网站有多个登录项**：提示列表里滚动选择另一条；
- **分步登录（先输邮箱再输密码）**：第二步再点一次提示，重新选同一条；
- **App 提示「应用标识不匹配」**：每个安卓应用有唯一标识，旧登录项没存过标识就会警告，按提示把标识更新进该登录项即可（新存的登录项自动带）；
- **银行类 App 仍然不填**：部分金融类 App 主动限制自动填充，只能从 1Password 里复制字段手动粘贴 —— 打开应用 → 点开登录项 → 长按密码字段 → 复制。

## 六、实在不行的兜底：手动拖拽 / 复制

自动填充在个别场景（隐私系统、非常规浏览器）确实不工作时，两条兜底路：

1. **分屏拖拽**：同时打开 1Password 与目标应用（分屏），长按登录项里的字段拖到目标输入框，松手落下；
2. **复制粘贴**：打开 1Password → 点开条目 → 长按字段复制 → 切过去粘贴。

日常主力还是自动填充；这两条留给少数填不进去的场合。
