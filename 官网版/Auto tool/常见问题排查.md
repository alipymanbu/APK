## 一、完全不跳广告

按顺序核对，多数问题出在前两步：

1. **总开关没开**：回 Auto tool 首页看大开关的状态；
2. **无障碍被关了**：去系统无障碍页面确认 Auto tool 那一项还是开启状态（这是最高发的一步，原因见下一节；开关变灰开不了则是另一回事，见[无障碍无法开启或自动关闭](无障碍无法开启或自动关闭.md)）；
3. **该应用的拦截被关了**：在「应用设置」里看它的开关是否被你顺手关掉；
4. **跳过按钮不是文字**：有的应用把「跳过」做成图片或自绘控件，这类按钮识别不到，属于这一类工具的共性局限，等更新或自己补规则（见[跳过广告规则设置](跳过广告规则设置.md)）；
5. **本就没有跳过按钮**：强制看满 N 秒才能点的广告，没有任何按钮可点，无解。

## 二、无障碍开关过一会儿自动关闭

系统省电策略把 Auto tool 当成了「该被清理的后台应用」。基础动作三步：省电策略改成「无限制 / 允许后台运行」、开自启动并锁定任务卡片、清理类软件把它加白名单。

各品牌要动的完整开关清单（含 MagicOS 的「允许后台活动」这类容易漏的开关），单独整理在[无障碍无法开启或自动关闭](无障碍无法开启或自动关闭.md)第三节里，照着表逐项核对即可。

## 三、在没有广告的应用里乱点

界面上出现的某些文字（比如「跳过」「知道了」）被误认成了目标按钮。处理：

- 把该应用加入白名单，或直接在「应用设置」里关掉对它的拦截；
- 若是自定义规则误触发，进「规则」页把那条规则的条件收紧或停用。

## 四、点了「跳过」却进了广告详情页

说明点到的位置不对，多数发生在按钮特别小、或者你用自定义规则指定了坐标的场景。优先改用按文字 / 控件匹配的规则，少用固定坐标（不同分辨率手机上坐标会偏）。

## 五、耗电与后台常驻

这类工具必须常驻后台才能工作，耗电主要来自系统对它的调度，而不是它本身——安装包只有 3.75M，内存占用也小。如果你的手机省电策略已经设为无限制仍觉得耗电明显，先看系统电池页面的耗电排行确认是不是它，再考虑不常用时段手动关总开关。

## 六、隐私方面想清楚再开

无障碍服务能读取屏幕内容，这是它能「看到」跳过按钮的前提，同一类工具（GKD、李跳跳、开屏跳过等）都有这个权限。建议按自己的接受度取舍：

- 只在日常常用的设备上开启，不在公用或工作管控设备上用；
- 不需要跳广告的时段直接关总开关，服务停了就读不到屏幕；
- 配合自动登录确认、验证码复制用的，想清楚它会把登录确认和验证码内容一并读走，介意就只保留跳广告、关掉这两个功能对应的拦截；
- 除无障碍外，安装时系统列出的权限清单里通常还有网络访问、存储读写这类常规权限（以你设备上显示的为准），不是只用无障碍一项。

## 七、和同类工具冲突

GKD、李跳跳、开屏跳过等同类无障碍工具如果同时开着，可能出现重复点击或互相干扰。留一个即可，其他的卸载或关闭服务。

## 八、更新后行为变了

App 或被跳过的应用更新后，原有的规则可能失配。先清掉对该应用的旧规则再重录一次；仍不行，等规则或应用的下一次更新。
