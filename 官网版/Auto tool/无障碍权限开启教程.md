# 无障碍权限开启教程

> Auto tool 的跳广告、自动确认全靠无障碍服务支撑，不开权限它什么也不做。本篇按顺序列清楚要开哪些权限、各品牌手机去哪里开。

## 一、为什么必须开无障碍

你打开别的 App 时，Auto tool 靠无障碍服务「看到」屏幕上出现了「跳过」按钮，然后替你点一下。没有这个权限，它读不到屏幕，跳广告功能完全不工作。这也是为什么每次重启手机或被系统清理后台后，要先检查无障碍开关还在不在。

## 二、开启无障碍服务

- **走 App 内引导**：首次打开 Auto tool，在「权限设置」里点「开启无障碍权限」，会直接跳到系统对应页面；
- **手动路径**：手机 设置 → 无障碍（有的系统叫「辅助功能」）→ 已下载的应用 / 更多 → 找到 **Auto tool** → 打开开关 → 在弹出的提示里点「允许」。

开启时系统会警告「该服务可读取屏幕内容」，这类工具都绕不开这条警告，是否继续由你自己判断（隐私方面的说明见[常见问题排查](常见问题排查.md)）。如果开关变灰、提示「受限制的设置」或点了没反应，去[无障碍无法开启或自动关闭](无障碍无法开启或自动关闭.md)按步骤解除。

## 三、其余配套权限

在 Auto tool 的「权限设置」页里，除无障碍外还有几项建议一次开齐，缺一项都可能表现为「时灵时不灵」：

| 权限 | 作用 | 不开的典型表现 |
| --- | --- | --- |
| 悬浮窗（显示在其他应用上层） | 在广告页上显示提示与操作 | 功能在跑但你看不到任何反馈 |
| 后台弹出界面（小米等机型叫法不同） | 允许它在后台把你正在用的界面切走执行点击 | 只弹提示但不跳转 |
| 忽略电池优化 | 防止系统省电时把它杀掉 | 过一会儿无障碍开关自动变灰 |
| 自启动 | 开机后自动恢复服务 | 重启手机后要手动重开 |
| 后台内存优化（部分机型叫「后台运行」） | 允许常驻后台 | 一键清理后台后失效 |

自启动权限通常要去系统的「应用管理 → Auto tool」里单独开，App 内的按钮只是帮你跳过去。

## 四、各品牌的无障碍入口

找不到入口时，最省事的办法是在系统设置的**顶部搜索栏搜「无障碍」**。常见路径如下（以你的系统版本实际显示为准）：

| 品牌 / 系统 | 常见路径 |
| --- | --- |
| 小米 MIUI / HyperOS | 设置 → 更多设置 → 无障碍 → 已下载的应用 |
| 华为 / 荣耀 HarmonyOS、MagicOS | 设置 → 辅助功能 → 无障碍 → 已下载的服务 |
| OPPO / 一加 ColorOS | 设置 → 其他设置 → 无障碍 |
| vivo / iQOO OriginOS | 设置 → 快捷与辅助 → 无障碍 |
| 三星 One UI | 设置 → 辅助功能 → 已安装的服务 |
| 原生安卓 / Pixel | 设置 → 无障碍 → 已下载的应用 |

## 五、开完之后

1. 回到 Auto tool 主界面，打开总开关，界面上会开始累积执行次数；
2. 随便打开一个带启动页广告的应用试一次，看它是否自动点了「跳过」；
3. 没动静就按顺序排查：总开关 → 无障碍开关 → 上表的配套权限，逐项核对，仍不行看[常见问题排查](常见问题排查.md)。

服务生效后，再去[跳过广告规则设置](跳过广告规则设置.md)里按应用调拦截范围，避免它在不该动的应用里乱点。
