# 无障碍无法开启或自动关闭

> 从网盘装的安卓应用，在新系统上开无障碍常被「受限制的设置」拦下，开好了又容易被省电策略关掉。这篇把两类问题分开讲。
> **相关文档**：[无障碍权限开启教程.md](无障碍权限开启教程.md) · [常见问题排查.md](常见问题排查.md) · [下载与安装教程.md](下载与安装教程.md)

## 一、提示「受限制的设置」，开关点不动

安卓 13 起对**不是从应用商店安装**的应用收紧了无障碍授权，网盘下载的 APK 正属此类。表现是：系统无障碍列表里 Auto tool 的开关变灰，或提示「出于安全考虑，此设置目前不可用」「系统已拒绝向此应用授予访问权限」。

解除思路是先给应用「受信任来源」的地位，再去开开关（入口位置各系统略有差异，以实际显示为准）：

1. 打开系统 设置 → 应用管理 → Auto tool 的应用信息页；
2. 找「允许受限制的设置」：
   - 原生安卓：应用信息页**右上角菜单**里；
   - 小米 MIUI / HyperOS：应用信息 → **高级设置** → 允许受限制的设置；
3. 打开后回到无障碍列表重新开开关；
4. 仍提示不可用，**重启一次手机**再试。

## 二、开关能点，但点了没反应

个别对无障碍管得严的系统（ColorOS 一类），即便完成上一步也不生效。可以试：

- 用**系统自带的文件管理器**找到 APK 再装一遍（覆盖安装，不用卸载）——经系统信任的安装方式能解除这层限制；
- 如果你此前冻结或停用过系统应用安装器，先解冻再装。

## 三、开好了但过一会儿自动变灰

后台被系统清理时，无障碍服务会跟着掉。基础动作（省电策略、自启动）见[无障碍权限开启教程](无障碍权限开启教程.md)第三节，下面是各品牌要动的完整开关清单（以你的系统版本实际显示为准）：

| 系统 | 要动的开关 |
| --- | --- |
| 小米 MIUI / HyperOS | 应用信息 → 省电策略 → 无限制；手机管家 → 自启动允许；开「后台弹出界面」权限；最近任务里下拉卡片加锁 |
| 华为 / 荣耀 HarmonyOS、MagicOS | 电池 → 启动管理 → 手动管理：允许自启动 + 允许关联启动 + 允许后台活动（MagicOS 9 需单独确认「允许后台活动」，否则后台会被暂停） |
| OPPO / 一加 ColorOS | 电池 → 优化电池使用中排除该应用；自启动管理里允许 |
| vivo / iQOO OriginOS | 电池 → 后台功耗管理 → 允许后台高耗电；自启动允许 |
| 三星 One UI | 电池 → 后台使用限制 → 把 Auto tool 移出「深度睡眠」列表 |
| 原生安卓 / Pixel | 设置里搜「电池优化」，切到全部应用，对它选「不优化」 |

装了黑域、绿色守护或各类清理加速软件的，同样要把 Auto tool 加进它们的白名单，否则它们每次清后台，无障碍就掉一次。

## 四、重启手机后服务没恢复

自启动和忽略电池优化都开着时，多数机型开机后会自动恢复服务；没有恢复就手动重开一次开关（步骤见[无障碍权限开启教程](无障碍权限开启教程.md)）。频繁发生的话，回上一节核对自启动是不是真的允许了——小米的自启动开关藏在手机管家里，最容易漏。

## 五、系统隔三差五弹「可以查看和控制您的屏幕」

部分系统会周期性对无障碍应用弹出这类提示通知，这是系统层面的行为，不代表应用做了新动作；觉得吵可以在系统的通知管理里关掉这条通知，服务本身不受影响。
