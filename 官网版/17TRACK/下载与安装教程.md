17TRACK 是把多家快递、邮政和跨境物流的轨迹聚合到一起的查询应用：你填一个物流单号，它去对应承运商那里取回节点信息，再翻译成「运输途中」「到达待取」这类状态标签。本篇解决两件事：网盘里这份包是哪个版本，以及怎么把它顺利装进你的安卓手机。

## 一、先核对网盘里这份包是哪一版

各下载站登记的版本号与网盘里这份常常对不上。本文出现的版本、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | 17TRACK |
| 版本号 | 3.1.6980.1 |
| 包名 | `yqtrack.app` |
| 安装包体积 | 63.06 MB |
| MD5 | `049056bb8269b0591c86254126ad5250` |
| 形态 | 安卓 APK |
| 本文核对时间 | 2026-09-22 |

判断是不是同一个包，看**包名 + MD5**，不要看名字旁边的版本数字。两点容易混：

- 这个应用的名字统一写作 **17TRACK**：17 与 TRACK 连写、TRACK 全大写，不是「17 Track」也不是「17track」。
- 网上搜到的多是官方最新版，与网盘里这份不一定是同一版；版本号不同是正常的，本文只认上表。

## 二、安卓：装网盘里这份 APK

1. **先转存再下载**。打开 [17TRACK 安装文件资源（夸克网盘）](https://pan.quark.cn/s/dc5a8eb68a94)，把 APK 转存到你自己的网盘再下载到手机。这一步别省：分享链接失效后，只有转过存的那份还在。
2. **允许安装未知来源应用**。在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，允许你要用来打开安装包的那个应用（文件管理器、浏览器或网盘客户端），再点这个 APK 安装。
3. **提示「应用未安装」就先卸载旧版**。手机里已有同包名但签名不同的版本时，覆盖安装会直接失败，先卸掉再装。
4. **同一包名无法共存**。装着旧版再装这份，旧版会被覆盖；想保留旧版就别装这一份。

更愿意从官方渠道取包也可以：官方应用下载页是 `https://app.17track.net/`，Google Play 上的包名同为 `yqtrack.app`，包名对得上就是同一个应用。

两点补充：

- **这份包只装在安卓上**。用 iPhone / iPad 的话，网盘里这个 APK 装不了，需要到 App Store 搜索 17TRACK 安装，官方包名同为 `yqtrack.app`。
- **最低系统版本**以官方商店页显示的兼容信息为准，装之前可以在 Google Play 页面确认自己的系统是否满足。

## 三、第一次打开先做三件事

1. **放行通知**。应用内「账号与设置 → 功能设置」里可以开启推送；系统层面也要允许 17TRACK 发通知，否则开了也不响，细节见 [通知提醒怎么设置.md](通知提醒怎么设置.md)。
2. **决定要不要现在登录**。不登录也能查单，但单号列表只留在本机；打算换设备用或长期跟踪，就趁现在注册，见 [注册登录与多设备同步.md](注册登录与多设备同步.md)。
3. **设好常用语言**。设置里的常用语言会同时影响界面与轨迹文本的语言，跨境包裹那种中英混排的描述，换成中文更好读。

## 四、不想装 App 也能查

同一套账号在几个入口通用，按场景挑：

- **手机网页端**：`https://www.17track.net/zh-cn`，临时查一两个单号最省事，不用装东西；
- **微信小程序**：官方也提供了小程序入口，适合顺手查一下、又不想多装一个应用的情况；
- **电脑网页端**：批量粘贴单号的体验更好，一次最多 40 个，写法见 [单号怎么添加和批量查询.md](单号怎么添加和批量查询.md)。

区别在于：网页端关掉页面就不留什么痕迹，适合偶尔查；要长期跟踪、要状态提醒，还是装 App 更顺手。两边覆盖的承运商是同一套，见 [支持哪些快递公司和地区.md](支持哪些快递公司和地区.md)。

## 五、装完做一次最小验证

拿一个手边的真实单号走一遍「添加单号 → 看状态」：

- 提交后一直查不到轨迹 → 见 [查不到物流信息怎么排查.md](查不到物流信息怎么排查.md)；
- 装不上、提示解析包错误、一打开就退出 → 见 [常见问题与排查.md](常见问题与排查.md)。

能正常出状态就说明装好了；下次要一次查好几个包裹时，[单号怎么添加和批量查询.md](单号怎么添加和批量查询.md) 里有批量与归档的写法。
