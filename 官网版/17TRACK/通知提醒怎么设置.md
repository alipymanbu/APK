# 17TRACK 通知提醒怎么设置

> 讲清在哪开启包裹状态提醒、哪些变化才会触发提醒，以及收不到提醒时怎么排查。

跨境包裹在途时间长，靠手动刷列表不现实。把提醒开对，状态一变应用就会主动推给你。本篇说清开关在哪、什么时候会响、不响怎么查。

## 一、开关有两层，两层都要开

提醒不响，多半是只开了其中一层：

1. **应用内**：进入「账号与设置 → 功能设置」，把推送打开。这里是总闸。
2. **系统层**：手机「设置 → 通知 → 17TRACK」里允许通知，并按需打开横幅、锁屏显示。系统这一层关着，应用里开得再全也不会响。

## 二、什么时候会收到提醒

- **主状态发生变化时**才会触发，例如从「运输途中」变成「成功签收」，或从「查询不到」变成「运输途中」；同一状态内部的细碎节点，不一定每条都提醒。
- **已归档的单号不会提醒**。归档本来的含义就是「不用再盯着了」，想继续收提醒要先激活，见 [单号怎么添加和批量查询.md](单号怎么添加和批量查询.md)。
- **没登录也能收本机的提醒**，但换设备就没了；登录后单号和提醒设置跟着账号走，见 [注册登录与多设备同步.md](注册登录与多设备同步.md)。
- 注册账号后，除了应用推送，也可以在网页端让自己的包裹状态更新以邮件形式送达，多一条兜底渠道。

## 三、收不到提醒，按这个顺序查

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 完全不响 | 应用内推送没开 | 到「功能设置」打开推送 |
| 完全不响 | 系统通知权限被关 | 系统「设置 → 通知」里允许 17TRACK |
| 只在解锁后才看到 | 锁屏/横幅未开 | 打开锁屏显示与横幅 |
| 有时响有时不响 | 国产系统的省电与后台限制 | 允许 17TRACK 后台运行、自启动，并把它移出省电优化名单 |
| 一直没动静 | 状态本来就没变 | 长期停在「运输途中」属正常，见 [物流状态都是什么意思.md](物流状态都是什么意思.md) |
| 某个单号不提醒 | 该单号被归档了 | 激活该单号 |
| 换手机后不响 | 新设备没给通知权限 | 在新机上重做上面两步 |

国产安卓系统对后台应用管得较严，这是提醒时有时无最常见的来源：把 17TRACK 加进「后台运行白名单」、关掉针对它的「智能省电」之后通常会稳定下来。

## 四、不想被打扰时

- 只关系统那一层的通知，应用内的设置不用动，之后想恢复也快。
- 不想再单独跟某一个包裹，直接归档它即可，不必关全局推送。
- 提醒本身不消耗什么，宁可留着；真嫌多，按上表逐项收紧比一刀切更好。
