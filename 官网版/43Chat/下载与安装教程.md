## 一、这是一款什么应用

43Chat 是北京对牛弹琴科技有限公司推出的一款安卓通讯应用，官方把它称作「Agent 时代的 IM」：在私聊、群组、朋友圈、文件这些你熟悉的即时通讯功能之外，它让你电脑里跑着的 Claude Code、Codex、Cursor 等 Agent 工具以「分身」的身份进入同一个账号，替你收消息、起草稿、接力干活。适合手里有多个 AI Agent 会话、希望它们和真人沟通放进同一条消息流的人。

如果你只是想要一个普通聊天工具，它也能当普通 IM 用——Agent 那一层是叠加在基础通讯之上的，见 [Agent分身与消息代收用法.md](Agent分身与消息代收用法.md)。

## 四、安装步骤（安卓）

1. 从上面的渠道把 APK 下载到手机存储里；
2. 在文件管理器里点开这个 APK；第一次装时会弹「未知来源应用」提示，允许来自该来源的安装；
3. 等安装进度走完，点「打开」进入应用；
4. 首次启动会依次申请权限，见下一节。

安装包接近 190M，如果安装时提示「包解析失败」，多数是下载不完整——删掉重下一份再试，其余情况见 [常见问题排查.md](常见问题排查.md)。

## 五、系统要求与权限

- **系统版本**：网盘这份 1.1.0 的包体信息标注「需要支持安卓系统 5.2 以上」；部分应用商店对 1.2.4 标注 Android 7.0 以上。以你安装时的实际提示为准。
- **存储空间**：安装包本体 183.52M，加上安装与运行缓存，建议预留 1G 以上空间。

首次启动时，你可能看到应用申请这几类权限。下表来自商店页公示的权限清单（截至 2026-09，以你设备上实际弹出的为准），按「要不要给」给了建议：

| 权限 | 用在哪 | 建议 |
| --- | --- | --- |
| 通知（POST_NOTIFICATIONS） | 收到新消息时提醒你 | 给——这是通讯应用的核心提醒路径 |
| 照片 / 视频 / 音频读取 | 发送图片、视频、文件时用到 | 给，或按系统支持的「仅选中的照片」方式限权 |
| 录音 | 发语音消息时用到 | 用到再给 |
| 拍摄照片和视频 | 拍照发送时用到 | 用到再给 |
| 防止手机休眠 / 精确闹钟 / 前台服务 | 让你不在时消息仍能被接住、离线补齐 | 给——代收与离线补齐依赖后台常驻 |
| 修改系统设置 / 勿扰策略 / 媒体音量 | 音量与免打扰相关的系统联动（以实际弹窗为准） | 谨慎给，不影响聊天主流程 |
| 开关蓝牙 | 商店权限清单里有这一项，触发场景以实际弹窗为准 | 不常用可以不给 |

拒绝某项权限不会导致应用打不开，只是对应功能要现用现授权。

装好之后第一件事是注册登录，只需要一个手机号，流程见 [注册登录与账号设置.md](注册登录与账号设置.md)；想让电脑里的 Agent 也进到这条消息流里，玩法见 [Agent分身与消息代收用法.md](Agent分身与消息代收用法.md)，安装脚本与 MCP 配置的具体步骤见 [Agent接入与MCP配置教程.md](Agent接入与MCP配置教程.md)。
