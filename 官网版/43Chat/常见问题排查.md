# 43Chat 常见问题排查

> 本篇汇总 43Chat 从安装到日常使用里最容易碰到的状况：装不上、验证码、通知、Agent 没动静、占用偏高。按问题对号入座即可；找不到对应条目时，把应用退到后台重进一次再看。

---

> [!IMPORTANT]
> **43Chat 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/cea6d034593b](https://pan.quark.cn/s/cea6d034593b)

## 一、安装包点不开、提示解析失败

安装包接近 190M，这类报错九成出在「包不完整」：

1. 删掉当前 APK，重新下载一遍；还没转存的先转存 **43Chat 安装文件资源（夸克网盘）**：<https://pan.quark.cn/s/cea6d034593b>，网盘转存后建议先校验文件大小是否还是 183.52M 再传到手机；
2. 确认手机剩余存储够用——安装时除了包体本身还要留出解压空间，建议预留 1G 以上；
3. 从浏览器下载的检查一下是否被「下载管理」中断过，重新下完整版。

装上了但打不开的情况，重启一次手机再看；还不行就卸载重装。版本选择的注意事项见 [下载与安装教程.md](下载与安装教程.md)。

## 二、验证码一直收不到

注册和换设备登录都走手机号验证码，收不到时按顺序试：等一两分钟再点重发（别连点，连点会让前面的码作废）、到短信拦截目录里翻一翻、确认这张卡还能正常收短信。完整排查清单见 [注册登录与账号设置.md](注册登录与账号设置.md) 第二节。

## 三、锁屏后收不到消息提醒

按这个顺序检查：

1. **系统通知权限**——系统设置里找到 43Chat，确认「通知」是打开的；首次启动时如果拒绝了 POST_NOTIFICATIONS，这里会是关的；
2. **后台保活**——国产 ROM 的电池策略常把后台应用掐掉，把 43Chat 加入「无限制」「自启动」名单，锁屏后才有人把消息接住；
3. **勿扰模式**——系统级勿扰会压掉所有提醒，和应用的「勿扰权限」申请是两回事。

消息提醒恢复后，如果还是觉得「该来的没来」，看下一节。

## 四、Agent 代收没有动静

代收、起草稿这些动作由你接入的 Agent 分身完成。如果你还没在电脑侧做过任何接入，消息就只会停在手机里等你自己处理——这不是故障，是还没把 Agent 接进来。接入方式（完整接入 / 轻量接入）的入口在官网 [https://43chat.cn](https://43chat.cn) 的「CONNECT YOUR AGENT」区块，玩法说明见 [Agent分身与消息代收用法.md](Agent分身与消息代收用法.md)。

已经接入但没反应时，检查两头：

- **电脑侧**：接入脚本或 MCP 服务进程还在不在运行，重启一次再试；
- **手机侧**：确认分身列表里这个 Agent 显示在线，离线状态下它回来后会从上次位置补齐消息，需要等一会儿。

## 五、聊天记录和占用问题

安装包 183.52M 只是起点，图片、视频、文件的缓存会让占用持续上涨。两个习惯能控制住它：

- 系统设置 → 应用 → 43Chat → 存储，定期「清除缓存」（注意是缓存，不是「清除数据」，后者会清掉本地登录状态）；
- 群里的大文件下载完就删，需要时再重新取。

版本差异、权限对照这些安装前的信息都收在 [下载与安装教程.md](下载与安装教程.md) 里，装完出问题回来翻这篇就行。
