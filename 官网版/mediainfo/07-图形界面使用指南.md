## 一、打开文件

三种方式，任选其一：

| 方式 | 操作 |
| --- | --- |
| **拖放**（最快） | 把文件从资源管理器 / 访达直接拖进 MediaInfo 窗口 |
| **菜单打开** | 「文件 → 打开」选择文件，支持多选 |
| **右键菜单** | 安装时若集成了资源管理器集成，可在文件上右键 → 用 MediaInfo 查看 |

打开后**左侧为分组列表，右侧为字段明细**，顶部可切换视图。拖入多个文件时，可在左侧逐个切换查看。

> 界面版安装包见 [MediaInfo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7475c96060cb)；从零开始的安装步骤见 [03-Windows](03-Windows安装教程.md) / [04-macOS](04-macOS安装教程.md) / [05-Linux](05-Linux安装教程.md)。

## 二、视图模式

媒体信息在不同场景下看重点不同，MediaInfo 提供多种视图：

| 视图 | 特点 | 适合 |
| --- | --- | --- |
| **基本 / 简单** | 只显示最关键的几项 | 快速核对，一眼看完 |
| **树状** | 按 常规 / 视频 / 音频 / 文本 / 章节 分组折叠展开 | **日常最常用**，结构清晰 |
| **文本** | 纯文本报告，与命令行输出一致 | 需要复制成文字时 |
| **HTML** | 带标签的网页格式 | 需要贴到网页或邮件里 |
| **XML** | 结构化标签 | 需要交给程序处理 |

> 不同版本菜单措辞略有差异（有的叫「查看」，有的叫「视图」），以实际界面为准。

**实用技巧**：切到「文本」视图后全选复制，粘到聊天窗口发给别人，比截图更清楚。也可以直接用 [06-命令行使用指南](06-命令行使用指南.md) 里的 `--Output=HTML` 生成报告文件再分享。

## 三、导出与分享

- **导出报告**：通过「文件 → 导出」选择导出格式（文本 / HTML / XML / CSV 等），保存为文件；
- **复制内容**：切到文本视图后手动复制，或使用复制功能把当前视图内容放入剪贴板；
- **生成网页报告**：命令行更适合批量场景，见 [06-命令行使用指南](06-命令行使用指南.md#7-生成可分享的网页报告)。

## 四、界面语言

MediaInfo 支持在任意操作系统上切换显示语言：

- 一般通过菜单中的**语言 / Language** 项切换；
- 切换后界面与字段名会随之翻译。

> ⚠️ **注意**：切到中文界面后，字段名会被翻译，**与网上教程、脚本里看到的名字对不上**。写脚本或对照文档排查时，建议把界面语言切回英文，或直接用命令行的 `--Language=raw` 拿到原始字段名。

## 五、选项与自定义

「选项 / 设置」里通常可以调整：

- **视图自定义**：决定哪些字段出现在基本视图中，隐藏不关心的项；
- **默认视图**：设置打开文件时默认使用哪种视图；
- **语言**：界面语言；
- **集成设置**：右键菜单集成、拖放集成等（Windows）。

如果嫌默认视图信息太多，配置一次自定义视图能明显提升日常效率。

## 六、插件

MediaInfo 有两个可选插件，均在 Windows 上以独立安装包形式提供，GUI 内也可能支持自动安装：

| 插件 | 作用 | 说明 |
| --- | --- | --- |
| **Graph 插件** | 生成码率等数据的**可视化图表**（输出 SVG / DOT） | 分析码率波动时很有用；命令行下也有对应的 CLI 版本插件包 |
| **FFmpeg 插件** | 借助 FFmpeg 增强解析能力 | 个别格式无法直接解析时可启用 |

若 GUI 内自动安装失败，可到官网下载对应插件的独立安装包手动安装（在 [Windows 下载页](https://mediaarea.net/en/MediaInfo/Download/Windows) 中标注为「Manual download in case the automatic install from the GUI does not work」）。

## 七、界面看不到想要的信息怎么办

| 现象 | 处理 |
| --- | --- |
| 基本视图字段太少 | 切到「树状」或「文本」视图 |
| 还是找不到某个字段 | 命令行用 `--Full` 输出**全部内部字段**，见 [06-命令行使用指南](06-命令行使用指南.md) |
| 字段名看不懂 | 查 [09-支持格式与术语表](09-支持格式与术语表.md) |
| 界面是中文、对不上教程 | 切换界面语言为英文，或用命令行 `--Language=raw` |

## 八、什么时候该改用命令行

图形界面适合**看一两个文件**；以下情况请直接上命令行（[06-命令行使用指南](06-命令行使用指南.md)）：

- 文件有几十上百个，需要批量导出清单；
- 需要把结果喂给脚本、流水线、数据库；
- 需要固定格式输出（JSON / CSV）以便程序解析；
- 需要在服务器或容器里使用（没有图形界面）。

需要重新获取安装包时 → [MediaInfo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7475c96060cb)
