## 一、基本语法

```
mediainfo [参数...] 文件1 [文件2 ...]
```

最简用法——直接跟文件路径：

```bash
mediainfo video.mkv
```

输出为「常规 / 视频 / 音频 / 文本」的分组文本报告。

> 还没装？先取 [MediaInfo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7475c96060cb)，再按 [03-Windows](03-Windows安装教程.md) / [04-macOS](04-macOS安装教程.md) / [05-Linux](05-Linux安装教程.md) 完成安装。

## 二、参数速查

> MediaInfo 的命令行参数**不区分大小写**。

| 参数 | 作用 |
| --- | --- |
| `--Version` | 显示版本号后退出 |
| `--Help` / `-h` | 显示帮助 |
| `--Full` / `-f` | 输出**全部内部字段**（最详细） |
| `--Output=<格式>` | 指定输出格式，见第三节 |
| `--Inform=<模板>` | 自定义输出模板，见第四节 |
| `--Language=raw` | 使用**未翻译的原始字段名**（脚本解析必备） |
| `--ParseSpeed=<0~1>` | 解析深度：值越大结果越完整、耗时越长（默认约 0.5） |
| `--LogFile=<路径>` | 把结果同时写入文件 |
| `--Help-Inform` | 查看 `--Inform` 可用参数说明 |
| `--Info-Parameters` | 列出全部可用字段名 |

**脚本解析的第一条铁律：加 `--Language=raw`。** 否则在中文系统上字段名会被翻译成中文，脚本立刻脆断。

```bash
mediainfo --Language=raw --Output=JSON video.mkv
```

## 三、输出格式一览

通过 `--Output=` 指定，常用值包括：

| 格式 | 说明 |
| --- | --- |
| `TEXT` | 默认的文本报告 |
| `JSON` | 结构化 JSON，**脚本首选** |
| `XML` / `OLDXML` | XML 结构 |
| `HTML` | 带标签的 HTML，可直接贴进网页 |
| `CSV` | 逗号分隔，适合导入表格 |
| `EBUCore` / `EBUCore_JSON` | 广播行业元数据标准（EBU） |
| `PBCore` / `PBCore2` | 公共广播元数据标准 |
| `Graph_Svg` / `Graph_Dot` | 码率等数据的图形输出（需 Graph 插件支持） |

示例：

```bash
mediainfo --Output=JSON video.mkv    # JSON
mediainfo --Output=XML  video.mkv    # XML
mediainfo --Output=HTML video.mkv > report.html   # 存成网页报告
mediainfo --Output=CSV  video.mkv    # CSV
```

## 四、自定义输出模板 `--Inform`

格式为：

```
--Inform="<类别>;<模板文本>"
```

- **类别**可取：`General`、`Video`、`Audio`、`Text`、`Image`、`Menu`、`Chapter`；
- **模板文本**中用 `%字段名%` 引用字段；
- 模板文本也可以是文件路径，写成 `file:///路径` 的形式。

### 示例

```bash
# 只输出分辨率与时长
mediainfo --Inform="Video;%Width%x%Height% %Duration%" video.mkv

# 输出容器格式 + 视频编码 + 音频编码
mediainfo --Inform="General;%Format% / " --Inform="Video;%Format% / " --Inform="Audio;%Format%" video.mkv

# 只看整体码率（单位 bps）
mediainfo --Inform="General;%OverallBitRate%" video.mkv

# 只看字幕语言
mediainfo --Inform="Text;%Language%" video.mkv
```

> 不确定字段叫什么？先跑 `mediainfo --Info-Parameters` 或 `--Full` 找到字段名，再写进模板。

## 五、实战场景

### 1. 快速核对一个文件

```bash
mediainfo movie.mkv
```

重点看三行：`Duration`（时长）、`Width × Height`（分辨率）、音频轨数量与 `Channels`（声道）。

### 2. 只看关键指标（一行输出）

```bash
mediainfo --Inform="Video;%Width%x%Height% %FrameRate%fps %BitRate%bps" movie.mkv
```

### 3. 批量导出 CSV 清单

```bash
# Linux / macOS
for f in *.mkv; do
  echo -n "$f,"
  mediainfo --Inform="General;%Duration%,%OverallBitRate%,%FileSize%" "$f"
  echo
done > 清单.csv
```

```powershell
# Windows PowerShell
Get-ChildItem *.mkv | ForEach-Object {
  $info = mediainfo --Inform="General;%Duration%,%OverallBitRate%,%FileSize%" $_.FullName
  "{0},{1}" -f $_.Name, $info
} | Set-Content -Encoding UTF8 清单.csv
```

### 4. 批量输出 JSON 并用 jq 抽取

```bash
for f in *.mp4; do
  mediainfo --Language=raw --Output=JSON "$f" > "${f}.json"
done

# 统计所有文件的分辨率分布
jq -r '.media.track[] | select(."@type"=="Video") | "\(.Width)x\(.Height)"' *.json | sort | uniq -c
```

### 5. 简单的质量检查（QC）脚本

检查是否为预期编码与分辨率：

```bash
#!/usr/bin/env bash
# 用法: ./qc.sh file.mkv
target_w=1920; target_h=1080

w=$(mediainfo --Language=raw --Inform="Video;%Width%"  "$1")
h=$(mediainfo --Language=raw --Inform="Video;%Height%" "$1")
codec=$(mediainfo --Language=raw --Inform="Video;%Format%" "$1")
audio=$(mediainfo --Language=raw --Inform="Audio;%Format%" "$1")

echo "文件: $1"
echo "  视频: $codec ${w}x${h}"
echo "  音频: $audio"

if [ "$w" != "$target_w" ] || [ "$h" != "$target_h" ]; then
  echo "  ⚠ 分辨率不符合预期 ${target_w}x${target_h}"
fi
```

批量跑：

```bash
for f in *.mkv; do ./qc.sh "$f"; done
```

### 6. 在 Python 中调用

```python
import json
import subprocess

def probe(path: str) -> dict:
    out = subprocess.run(
        ["mediainfo", "--Language=raw", "--Output=JSON", path],
        capture_output=True, text=True, check=True,
    ).stdout
    return json.loads(out)

data = probe("video.mkv")
for track in data["media"]["track"]:
    if track.get("@type") == "Video":
        print(track.get("Format"), track.get("Width"), "x", track.get("Height"))
```

### 7. 生成可分享的网页报告

```bash
mediainfo --Output=HTML movie.mkv > movie.report.html
```

把生成的 HTML 直接发给别人，对方无需安装 MediaInfo 也能看到完整信息。

## 六、解析结果的稳定化建议

在脚本与流水线中使用时，建议固定三件事：

| 建议 | 原因 |
| --- | --- |
| 加 `--Language=raw` | 字段名不随系统语言变化 |
| 固定输出格式（如 `JSON`） | 文本报告的排版可能随版本微调 |
| 固定 MediaInfo 版本 | 新版可能新增字段或调整解析策略，避免升级后脚本突然失败 |

> 升级 MediaInfo 后**务必在测试样本上回归一次**你的脚本，再做全量处理。

## 七、大文件与性能

- 解析耗时与 `--ParseSpeed` 正相关，**默认设置已足以拿到常规字段**；只有在需要更完整的底层信息时才调高。
- 处理超大文件（几十 GB）时，如需更快出结果，可调低 `--ParseSpeed`，牺牲部分字段换取速度。
- 批量任务建议**串行或限制并发**，机械硬盘上并发读取反而更慢。
