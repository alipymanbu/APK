## 一、它是什么

MediaInfo 是由 **MediaArea** 开发并维护的开源免费工具，用于读取并展示**音视频文件的媒体信息与标签信息**。

一句话概括它的作用：**把一个媒体文件「内部长什么样」完整摊开给你看**——封装格式、编码方式、码率、分辨率、帧率、时长、音轨、字幕轨、语言、章节、写入软件等等。

它不播放、不转码、不修改文件，只做**读取与展示**。

---

## 二、能读到哪些信息

MediaInfo 把读取到的内容按五类分组呈现：

| 分组 | 英文标识 | 典型字段 |
| --- | --- | --- |
| **常规** | General | 文件大小、封装格式与格式档次（Profile）、商业格式名、总码率、时长、标题、作者、导演、专辑、音轨号、日期、写入程序与写入库 |
| **视频** | Video | 编码格式、编码 ID、画面宽高比、帧率、码率、色彩空间、色度抽样、位深、扫描方式（逐行 / 隔行）、扫描顺序 |
| **音频** | Audio | 编码格式、编码 ID、采样率、声道数、位深、语言、码率 |
| **文本** | Text | 字幕格式、编码 ID、字幕语言 |
| **章节** | Chapters / Menu | 章节数量、章节列表与时间点 |

> 字段含义不确定时，查 [09-支持格式与术语表](09-支持格式与术语表.md)。

## 三、三种产品形态

MediaInfo 不只有「一个软件」，它对外提供三种形态，共用同一套解析内核：

| 形态 | 说明 | 典型使用场景 |
| --- | --- | --- |
| **GUI（图形界面）** | 独立的窗口程序，拖入文件即可查看 | 日常单个文件核对 |
| **CLI（命令行）** | `mediainfo` 命令，支持文本 / JSON / XML / CSV 等输出 | 批量处理、脚本自动化、质量检查 |
| **库（Library）** | `MediaInfo.dll`（Windows）、`.so`（Linux）、`.dylib`（macOS），以及 JavaScript 模块 | 二次开发，把解析能力集成进自己的程序 |

三者在大多数平台上**可以共存**。安装包通常同时含 GUI 与 CLI；Linux 上则常拆成 `mediainfo`（CLI）与 `mediainfo-gui`（GUI）两个包。

使用方式分别见 [07-图形界面使用指南](07-图形界面使用指南.md) 与 [06-命令行使用指南](06-命令行使用指南.md)。

需要安装文件时，可直接取用 [MediaInfo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7475c96060cb)。

## 四、典型使用场景

1. **核对下载内容**——下载到的影片 / 音乐是否与页面描述一致（分辨率、码率、音轨数量）。
2. **排查播放问题**——「能播放但没声音」「画面卡顿」「播放器打不开」，先看它到底是什么编码与封装。
3. **转码前确认参数**——送入压制流程前，确认源文件的编码、位深、色彩信息。
4. **质量检查（QC）**——批量校验交付文件是否符合规范（帧率、声道布局、码率区间）。
5. **建库与归档**——批量导出元数据为 CSV / JSON，构建可检索的媒体资产清单。

## 五、技术特点

- **格式覆盖广**：涵盖主流容器、视频编码、音频编码与字幕格式，完整清单见 [09-支持格式与术语表](09-支持格式与术语表.md)。
- **多视图输出**：文本、树状、表格、HTML、XML、JSON 等，并可自定义模板（见 [06-命令行使用指南](06-命令行使用指南.md)）。
- **跨平台**：Windows、macOS、Linux 及多种 Unix 系统均有官方版本。
- **多语言界面**：可在任意操作系统上切换显示语言；做脚本解析时建议锁定为原始字段名，避免被翻译（见 [06-命令行使用指南](06-命令行使用指南.md) 的 `--Language=raw`）。
- **与系统集成**：Windows 支持安装时集成右键菜单与拖放。

> 需要**修改**元数据（写入标签）请使用 ExifTool 等工具，MediaInfo 只读。

## 七、与同类工具的差异

| 工具 | 定位 | 什么时候用 |
| --- | --- | --- |
| **MediaInfo** | 媒体信息**展示**，输出人类可读的分组报告 | 需要「看得懂」的完整报告，或需要多种现成输出格式（CSV / HTML / EBUCore 等） |
| **ffprobe** | FFmpeg 套件的探测工具 | 已经在用 FFmpeg 管线，需要与 FFmpeg 字段口径一致的 JSON |
| **ExifTool** | 元数据**读写**利器 | 需要修改标签、处理图片 EXIF |

两者对同一文件读数**偶尔不完全一致**（解析策略与字段定义不同），属于正常现象，说明见 [08-常见问题与故障排查](08-常见问题与故障排查.md)。
