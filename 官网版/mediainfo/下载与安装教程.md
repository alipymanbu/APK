## 四、安装前需要知道的三件事

1. **只从官网下载。** 第三方软件站常捆绑推广程序或二次打包，MediaInfo 本身免费，没有必要冒这个风险。入口见 [02-下载渠道与版本选择](02-下载渠道与版本选择.md)。

2. **GUI 与 CLI 是同一套内核的两种外壳。** 官方安装包通常同时含两者；但 Linux 上 GUI 与 CLI 常拆成两个包（如 `mediainfo` 与 `mediainfo-gui`），做脚本自动化请确认 CLI 那个包已装。

3. **它只读不写。** MediaInfo 用来**查看**文件信息，不会修改、转码或修复文件。需要改元数据请用 ExifTool 等工具。
