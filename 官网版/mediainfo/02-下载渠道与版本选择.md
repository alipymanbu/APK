## 二、版本号怎么读

MediaInfo 采用 **`年份.月份`」** 的滚动版本号，**按月发布**：

```
26.05   →  2026 年 5 月发布
24.11   →  2024 年 11 月发布
21.03   →  2021 年 3 月发布
```

由此带来两个实践结论：

1. **网上教程里写的版本号（如 24.11）通常已经过时**，这很正常。下载时以官网当下显示的版本为准，不必强求与教程一致。
2. **老操作系统要用老版本。** 例如官网对 Windows XP 只提供 21.03 及更早的包；Windows 95～2000 只提供 0.7.60。新版本安装包在这些系统上无法运行。

当前（本文档编写时）官方主版本为 **26.05**。

## 三、包型对照：我该下哪个

### Windows

| 包型 | 文件名形态 | 含什么 | 适合谁 |
| --- | --- | --- | --- |
| **GUI 通用安装包** | `MediaInfo_GUI_<版本>_Windows.exe` | GUI + CLI，自动识别 32/64/ARM64 | **不确定就下这个**（官网原话） |
| GUI 指定架构安装包 | `..._Windows_x64.exe` / `_i386.exe` / `_ARM64.exe` | 仅对应架构 | 明确自己架构、想要更小体积 |
| GUI 免安装版 | `..._Windows_x64_WithoutInstaller.7z` | 解压即用，不写注册表 | 便携使用、U 盘携带、无管理员权限 |
| **CLI 命令行版** | `MediaInfo_CLI_<版本>_Windows_x64.zip` | 仅命令行 | 只做脚本自动化 |
| DLL 开发库 | `MediaInfo_DLL_<版本>_Windows_x64.exe` | 供程序调用的库 | 二次开发 |
| Graph 插件 | `MediaInfo_GraphPlugin_...` | 生成码率图表 | 需要可视化码率曲线 |
| FFmpeg 插件 | `MediaInfo_FFmpegPlugin_...` | 借助 FFmpeg 增强解析 | 特殊格式解析 |

> 老版本 Windows（95～2000 / XP）的包型命名规则不同，且只有旧版本可用，详见 [03-Windows安装教程](03-Windows安装教程.md)。

### macOS

| 包型 | 说明 |

## 四、决策速查

| 你的情况 | 建议 |
| --- | --- |
| Windows，只想能看图省事 | GUI 通用安装包 `.exe` |
| Windows，公司电脑无管理员权限 | GUI 免安装 `.7z` |
| Windows，只写脚本 | CLI `.zip`，并把目录加入 `PATH` |
| macOS，普通使用 | 官方 `.dmg` |
| macOS，已用 Homebrew | `brew install --cask mediainfo` + `brew install media-info` |
| Linux，图省事 | 发行版包管理器装 `mediainfo`（+ `mediainfo-gui` 若需要界面） |
| Linux，要最新版本 | 添加 MediaArea 官方仓库，或使用 AppImage |
| 容器 / CI 环境 | 用发行版包管理器或官方 `.tar.xz`，只装 CLI |

## 五、为什么不建议从第三方软件站下载

- **捆绑安装**：下载器、推广程序常被塞进安装流程；
- **二次打包**：可能被替换为修改版，行为不可预期；
- **版本陈旧**：目录长期不更新，你拿到的可能是几年前的老版本；
- **来源不明**：一旦被植入后门，排查成本远高于从官网多花的那一分钟。

MediaInfo 本身**完全免费**，从官网下载没有任何额外门槛，因此没有理由走第三方渠道。

## 六、下载后的校验（可选但推荐）

1. **看文件名与体积**：与官网页面列出的名称、大小是否一致；
2. **比对哈希值**：若官网页面提供了校验值，可用以下命令计算本地文件哈希后比对：

```powershell
# Windows PowerShell
Get-FileHash .\MediaInfo_GUI_26.05_Windows.exe -Algorithm SHA256
```

```bash
# macOS / Linux
shasum -a 256 MediaInfo_GUI_26.05_Windows.exe
```

3. **Windows 上留意 SmartScreen**：新发布的安装包首次下载时可能弹出「Windows 已保护你的电脑」，确认文件名与来源无误后可选择「仍要运行」。

## 七、版本更新策略

| 场景 | 建议 |
| --- | --- |
| 日常使用 | 不必追每一个月版本，**每隔几个月更新一次**即可 |
| 遇到新格式读不出来 | 优先升级到最新版，新格式支持通常来自新版本 |
| 生产 / 归档环境 | 固定一个大版本，变更前先在测试文件上验证输出差异 |
| 老系统 | 停在系统支持的最高版本，不要强行装新版 |
