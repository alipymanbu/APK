# Volume Booster 增强自动停止怎么办

> 通知栏的控制用着用着消失、增强自己就停了——这通常是手机厂商的省电策略把后台服务杀掉了，不是应用坏了。本篇讲怎么判断、怎么给应用开后台白名单。

## 一、先判断是哪种「停」

看一眼通知栏有没有它的常驻通知，这是判断服务是否还活着的依据：

| 现象 | 说明 | 处理 |
| --- | --- | --- |
| 通知还在，只是面板不见了 | 服务正常，悬浮窗的问题 | 走[悬浮窗权限设置方法.md](悬浮窗权限设置方法.md)的排查 |
| 通知消失，增强也停了 | 服务被系统杀掉 | 按本篇下面的方法开后台白名单 |
| 只有你从多任务里划掉之后才停 | 这是正常行为 | 想让增强继续就别划掉它，按 Home 键回桌面即可 |

第三种值得单独说：在安卓上，从「最近任务」里把应用卡片划掉，就等于告诉系统「我用完了」——应用的前台服务会正常结束，增强随之停止。**想让它继续工作，用 Home 键退出就行，别划卡片**。

## 二、通用解法：把电池限制放开

所有品牌通用的第一步，是把 Volume Booster 从电池优化里放出来：

1. 「设置」→「应用管理」→ 找到 Volume Booster。
2. 进入「电池 / 电池优化」。
3. 选择「不受限制 / 不优化 / 允许后台活动」。

原生安卓（Pixel 等）做到这一步基本就够了；国产系统普遍在这之上还有自己的一套管控，见下一节。

## 三、各品牌的额外设置

国产系统后台管控最凶，只做第二步往往不够。各品牌的补充设置（菜单名随系统版本有出入，**以你手机上实际显示的为准**）：

| 品牌 | 补充设置 |
| --- | --- |
| 华为 / 荣耀 | 设置里搜「应用启动管理」→ 关闭该应用的「自动管理」→ 勾选「允许后台活动」；再搜「电池优化」→ 设为「不允许」；多任务界面下拉应用卡片加锁，防止被一键清理 |
| 小米 / 红米 | 「应用管理」→ 该应用 →「自启动」打开；省电策略改为「无限制」 |
| 三星 | 电池 →「后台使用限制」→ 把应用从「睡眠应用 / 深度睡眠应用」列表移出；关闭「自动让不常用的应用进入睡眠」 |
| OPPO / 一加 / realme | 允许「后台活动」与「自启动」；多任务界面下拉应用卡片加锁 |
| vivo / iQOO | 「后台耗电管理」里允许后台高耗电；「权限管理」→「自启动」打开 |

改完之后**彻底杀掉应用重新打开一次**，让服务以新策略重启，然后放段音乐观察几分钟，通知栏常驻通知不消失就说明稳了。

## 四、顺手复查的两个设置

- **通知权限**：第一次启动时如果拒了「发送通知」，通知栏入口本来就不会出现——去「设置」→「应用管理」→ Volume Booster →「通知」里打开。
- **省电模式**：低电量模式开着时，系统会临时收紧所有后台活动，测试期间先把它关掉，排除干扰。

## 五、如果管控实在关不掉

个别机型的管控层次多、还会在系统更新后重置，白名单配不齐时服务仍会偶尔被杀。务实的选择是**按需使用**：要看视频、听歌时顺手打开增强，用完不必常年挂着——既躲开了后台管控，也少占扬声器与听力，长时间大音量的边界见[声音失真与破音处理.md](声音失真与破音处理.md)。
