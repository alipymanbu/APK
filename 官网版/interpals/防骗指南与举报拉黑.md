## 一、先记住一条铁律

**不给只在网上认识的人转账。** 官方在安全页把话说得很死：编「突发医疗急事」「旅行被困」「生意机会」「感情故事」要钱的，全是骗局 —— 而且注意钱的形态：**礼品卡、加密货币和现金一样，一律不给**；「投资理财」「荐股带单」这类主动送上门的发财机会，官方同样明确定性为骗局。InterPals 明文禁止成员之间的金钱往来。真正的朋友不会向刚认识的网友开口要钱 —— 遇到就停聊、举报、拉黑（步骤见第三节），不用觉得不好意思。

## 二、常见骗局信号清单

对照官方 FAQ 整理的红旗信号，命中越多越要警惕：

| 信号 | 说明 |
| --- | --- |
| 好得不真实 | 照片过于漂亮、人生经历近乎完美 |
| 感情推进极快 | 没见过面就迅速表白、谈婚论嫁 |
| 拒绝视频 | 一提视频通话就找各种借口 |
| 开口提钱 | 任何形式的金钱请求，零例外 |
| 急着转移到站外 | 立刻想把你引到邮箱、WhatsApp 等平台私聊 |
| 语言前后矛盾 | 语法混乱、消息像复制粘贴的模板 |
| 发可疑链接 | 推来路不明的网站让你点 |

另外提醒一点：InterPals 不是约会软件，官方定位是友谊与语言交流。对方主页会写明想认识什么人，**联系前先看一眼**；遇到不受欢迎的骚扰信息，直接走下面的举报流程。

## 三、举报一个账号（官方五步）

遇到假资料或骗子，按官方 FAQ 给的步骤来：

1. **停止回复**可疑消息；
2. 在对方主页底部点 **Report（举报）**；
3. **选择原因**（假资料、骗子、垃圾信息等）；
4. **写清细节** —— 附上可疑行为的具体例子，细节越全越好审；
5. **拉黑**对方，断掉后续接触。

两点预期管理：审核由志愿者与自动化系统处理，每天要面对大量报告，**不会立刻有结果**；也可能因为证据不足不做处理 —— 所以举报时尽量把证据写全。另外不用有心理负担：**举报是保密的，被举报的人永远看不到是谁举报了他**（官方安全页口径）；举报直达风控系统，是保护自己也保护下一个人的最快途径。

## 四、拉黑

- 最快的方式：在对方主页点 Block this user；
- 想批量管理：去 Settings（设置）→ Privacy（隐私）里编辑黑名单。

拉黑即时生效，对方无法再联系你、也看不到你的资料；**不需要说明理由，对方也不会收到任何通知**（官方安全页口径），所以不必犹豫。注意一个规则细节：你主动发给某人的消息，对方永远可以回复（这是官方机制，见 [聊天私信与联系限制.md](聊天私信与联系限制.md)），所以对不想往来的人，重要的是不主动搭话加拉黑，而不是指望联系限制替你挡人。

## 五、保护自己的官方建议

- **个人信息晚点给** —— 全名、住址、电话、财务信息，都不要在刚认识时就交出去；
- **对话留在站内** —— 官方原话：留在平台上，出了问题才有人能帮你；对方急着把你引去别处私聊，本身就是第四节里的红旗之一；
- **见面或深聊之前先视频** —— 视频是确认「屏幕对面是谁」最直接的办法；
- **相信直觉** —— 觉得不对劲就停下来，该举报举报、该拉黑拉黑。

账号本身的加固（验证邮箱、一人一号、隐身设置）在 [注册与账号设置.md](注册与账号设置.md)；语言交换场景里同样适用本篇的规则，别因为「是来练语言的」就放松警惕 —— 场景见 [语言交换与翻译功能.md](语言交换与翻译功能.md)。
