## 一、搜索条件有哪些

InterPals 的搜索页可以按这些条件筛人：

| 条件 | 说明 |
| --- | --- |
| 国家 | 想认识哪个国家的人就选哪个，180 多个国家可选 |
| 城市 | 想约见面或了解某座城市时用得上 |
| 年龄 | 按年龄段收窄 |
| 会说的语言 | 找母语者主要靠这一项 |
| 正在学的语言 | 找互惠语伴的关键条件，见第四节 |

和左滑右滑的交友软件不同，这里没有滑卡配对，搜索结果就是一份份完整的个人主页与相册，你可以先认真读完资料再决定写不写信。这是官方特意保留的形态，也更符合「笔友」的相处节奏。

## 二、四步找到一个母语语伴

按官方 FAQ 给出的方法：

1. 打开搜索页；
2. 在「会说的语言」里选你的**目标语言**（你想练的那门）；
3. 把该语言的最低水平设为 Native（母语）或 Proficient（精通）；
4. 可以再叠加国家条件（比如学日语就限定日本）；最后优先找那些**正在学你的母语**的人 —— 双方都有得练，回复率也更高。

多读几份主页再下手，官方 FAQ 的建议是：兴趣和目标和你相近的人，才是长期合拍的语伴。语言水平的五档怎么填、互练怎么安排，见 [语言交换与翻译功能.md](语言交换与翻译功能.md)。

## 三、除了搜索，还有这些找人入口

- **Online Now（此刻在线）**：看当前在线的人，在线的更容易聊起来；
- **谁看过我的主页**：能查看浏览过你资料的用户，对你主页感兴趣的人可以先打招呼；
- **群组与社区动态**：按兴趣加入群组、发帖，不用私聊也能先混个脸熟；
- **书签**：在别人的主页底部点 Add bookmark 存起来，之后在书签列表里统一回访、删掉不要的。

主页被看得多但没人打招呼，先检查两件事：资料填全了吗（尤其语言两项，直接影响搜索命中率）；照片传了吗。新账号的资料就绪后，别人主动发来的消息会多起来。

## 四、发出第一条消息之前

- 读对方的「关于我」。官方 FAQ 提到，成员会在主页写明自己想认识什么样的人（只想交笔友、只谈语言、或也接受恋爱），**先看这个再决定怎么开场**，能省掉很多无效往来；
- 开场白具体一点：提一句对方主页里的内容，比群发模板有效得多；
- **等得起**：官网给读者的预期是「大多数人会在一两天内回复」—— 笔友社区节奏本来就慢，发完别急着催；
- 注意每天能主动联系的新人数量有限制，会员越久上限越高，别一上来就把名额挥霍在群发上 —— 规则细节见 [聊天私信与联系限制.md](聊天私信与联系限制.md)；
- 主动找你的人里可能混着骗子，转账要求一律拒绝，信号清单见 [防骗指南与举报拉黑.md](防骗指南与举报拉黑.md)。
