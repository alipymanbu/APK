## 一、结论先说

GeekTV 是安卓应用，**同一份安装包可以装智能电视、电视盒子、安卓手机**，不需要为电视和手机分别找两个包。装之前只要确认两件事：设备是安卓系统、版本别太旧。装完上手见 [电视端基本操作指南.md](电视端基本操作指南.md)。

## 二、支持的设备形态

| 设备 | 能不能装 | 备注 |
| --- | --- | --- |
| 智能电视（安卓系统） | 可以 | 走 U 盘安装，需打开未知来源权限 |
| 电视盒子 | 可以 | 同电视装法；老盒子可能受存储与系统版本限制 |
| 安卓手机 / 平板 | 可以 | 直接点 APK 安装，操作从遥控器换成触屏 |
| iPhone / iOS 设备 | 不可以 | iOS 装不了 APK |
| Windows / Mac 电脑 | 未验证 | 这是安卓包，需要模拟器环境，本文不展开 |

需要说明：市面没有公开可查的官方系统要求页，各家下载站给的标注也不完全一致——**主流标注是「安卓 5.2 以上」，也有站点标注「Android 4.0 或更高」**。两者并列在此，你按自己设备实测为准：设置 → 关于手机 / 关于本机里能看到系统版本。

## 三、手上这份包的参数（以采集记录为准）

网上流传多个版本（2.0.0.0、2.0.0.1、2.0.0.6 等），版本号各站不一致，**下文是本套文档对应的这一份的实测参数**，装之前照它核对：

| 项目 | 值 |
| --- | --- |
| 应用名 | GeekTV |
| 版本 | 2.0.0.4 |
| 包名 | `tv.kuaidou.iptv.v2` |
| 大小 | 12.44M |
| MD5 | `6e289042ccd04a3957fa6e1e51486018` |
| 界面语言 | 简体中文 |

三个用途：

- **包名**是应用的唯一身份——设置里查已安装应用的包名，能确认装到的是不是这个应用（同名的其他包不等于它）；
- **MD5** 是文件指纹——从任何渠道拿到包都先核这一项，对不上就不是同一份文件；
- **大小**用来快速判断包有没有下完整。

## 四、性能上的实际预期

- 安装包只有 12.44M，对设备的要求主要在**系统版本**和**网络**，不在存储；
- 直播与点播都是在线拉流，**带宽决定流畅度**：网络一般时把画质调到标清/高清更稳（操作见 [电视端基本操作指南.md](电视端基本操作指南.md)）；
- 老设备（十年前的盒子、1GB 内存的机器）容易出现打开慢、播一会卡的问题，排查步骤见 [常见问题与解决办法.md](常见问题与解决办法.md)。

拿不准要不要装，先把安装包下下来核对参数、确认系统版本够用再动手，步骤在 [下载与安装教程.md](下载与安装教程.md)。
