## 一、第一次打开：直接点 OK

首次启动会停在一个带【OK】按钮的页面，**直接按遥控器确认键点 OK 就能进**，不需要输入授权码、不需要注册登录。进入主页面之后，下次再打开会直接到主页，不用每次重新点。

如果你手上的版本停在别的页面不动，或者点了 OK 没反应，按 [常见问题与解决办法.md](常见问题与解决办法.md) 的「卡在启动页 / 一直转圈进不去」一节排查——先确认装的是不是完整包（对照安装篇的 MD5）。

## 二、主页面三个入口：直播、点播、搜索

进了首页，日常就三个去处：

| 入口 | 你会用它做什么 | 怎么进去 |
| --- | --- | --- |
| 直播 | 看电视直播频道，央视、卫视、地方台这类 | 首页选「直播」 |
| 点播 | 按片子挑电影、电视剧、综艺、动漫、纪录片 | 首页选「点播」 |
| 搜索 | 已经知道片名，直接找 | 首页选「搜索」 |

- **直播**进去是一个频道列表，遥控器上下键换台，确认键选中。具体频道清单随版本更新会有增减，以你打开后的实际列表为准。
- **点播**里按类型、地区、年份这类维度分好类，也可以看热播榜、新片榜。选中一部进详情页，再选集播放。
- **搜索**支持按片名关键词查，部分版本还能按导演、演员搜。输入用遥控器方向键选字母，慢但准。

## 三、播放中的常用操作

- **选集**：剧集类内容在详情页或播放页切换集数，遥控器左右键通常用于快进快退（具体以你这版界面提示为准）。
- **画质切换**：播放时可选标清 / 高清 / 超清 / 蓝光等档位。网络一般就往低了调——**卡的时候先降画质，比换台折腾网络快得多**。降了还卡，按 [直播卡顿怎么解决.md](直播卡顿怎么解决.md) 的顺序往下查。
- **收藏**：遇到常看的频道或片子，加进收藏，下次从收藏直接进，不用重新翻列表。
- **观看历史**：退出再进，播放记录会留着，从历史里能接着上次的进度看。注意清应用数据会把这些记录清掉（清缓存不影响，见 [常见问题与解决办法.md](常见问题与解决办法.md)）。

## 四、手机上装同一个包的区别

手机端与电视端是同一份安装包（包名 `tv.kuaidou.iptv.v2`），内容和栏目一致，差别只在操作方式：电视端靠遥控器方向键导航，手机端直接触屏点。所以本文的入口与栏目说明在手机上同样适用。

再提醒一次版本口径：本套文档对应的是 **2.0.0.4**，界面细节可能与你在网上看到的最新版截图略有出入，拿不准的地方以你设备上实际显示的为准。安装包从哪拿，见 [下载与安装教程.md](下载与安装教程.md)。
