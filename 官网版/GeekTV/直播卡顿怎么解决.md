## 一、先回答一个问题：所有台都卡，还是只有这一个卡

这一步决定了后面往哪查，30 秒就能做完：

| 现象 | 更可能的原因 | 往哪查 |
| --- | --- | --- |
| 换几个台、点几部片**都卡** | 你的网络或设备 | 看第二、三节 |
| **只有这一个台 / 这一部片**卡 | 这一路源的问题 | 看第四节 |
| **每天晚上固定时段**才卡 | 晚高峰网络拥挤或线路负载高 | 看第三节 |

后面所有步骤都建立在这个判断上——方向错了，调什么都白调。

## 二、最快见效：把画质降一档

播放器里有标清 / 高清 / 超清 / 蓝光多档，**卡的时候先降到标清或高清**，多数情况十秒内就能感觉到变化。作为参照：一路高清直播大约需要 10 Mbps 上下的**稳定**带宽，标清 3~5 Mbps 就够（经验值，以你家宽带实测为准）。

画质降下来还不卡了，说明问题就是带宽顶不住这一路的码率——继续用低档位看，或者按第三节把网络改善了再调回去。

## 三、网络：卡顿大多出在这一层

按成本从低到高排：

1. **重启一次设备和路由器**：断电 30 秒再插上，清掉路由器的临时状态。老设备长期不重启会越来越卡。
2. **确认不是有人在抢带宽**：同一 Wi-Fi 下有人在下大文件、看别的视频，你这边必然卡。错开或暂停一下试试。
3. **换个时段对比**：只在晚上卡、白天正常，基本就是晚高峰拥挤——这在网络侧无解，只能降画质顶过去。
4. **拉近距离或换有线**：盒子离路由器隔了几堵墙，信号衰减明显。设备有网口就直接插网线，有线比任何 Wi-Fi 都稳，这是改善幅度最大的一步。
5. **测一下真实网速**：在同网络的手机上打开 `fast.com` 或运营商测速页，看实际上下行。测出来带宽很低，问题在宽带本身，不在应用。

## 四、源的问题：等、换、别折腾网络

同一时间只有某一路卡，说明卡在那一路的线路上，你把家里网络翻个遍也不会有用：

- 换一个台、或者点另一部片，确认它恢复正常 → 就是那一路的问题，看你想看的内容绕开它；
- 球赛、晚会这类**观看人数暴增的时段**，个别线路负载上来会变卡，过一会或换路再看；
- 多数时候线路自己会恢复，不必为此重装应用或改设置。

## 五、设备：卡不是网络的锅时查这里

1. **清缓存**：设置 → 应用 → GeekTV → 清除缓存。缓存文件越积越多会拖慢启动与加载，**只清缓存、先别清数据**（清数据会丢收藏和记录）。
2. **看剩余存储**：存储快满时应用读写变慢，腾出几百 MB。
3. **看设备本身**：十年前的盒子解码高码率视频本来就吃力——判断方法是**放本地视频或别的应用也卡**，那就不是这一个应用的问题，换画质档位是最现实的缓解手段。
4. **断电重启后只开这一个应用**：后台挂着一堆应用会抢内存。

## 六、备选手段：换 DNS 试一试

有经验帖建议把路由器或设备的 DNS 改成 `1.1.1.1` / `8.8.8.8`（分别是 Cloudflare 与 Google 的公共 DNS），理由是解析慢会拖慢起播与换台——这类做法来自单一社区经验，**没写进系统设置前别大动干戈**，前三节都无效时拿来当最后的尝试即可。改坏了随时能改回「自动获取」。

## 七、什么时候不用再修

设备太老（内存 1GB 上下、系统版本很低）、带宽长期不够，这两种情况卡顿是硬件与线路决定的，软件层的调整只能缓解。把画质固定在标清/高清，能流畅看就达到了可用状态；实在看不了，参考 [常见问题与解决办法.md](常见问题与解决办法.md) 的自查三件事确认问题层级，再决定是换设备还是换网络。安装包与参数核对见 [下载与安装教程.md](下载与安装教程.md)。
