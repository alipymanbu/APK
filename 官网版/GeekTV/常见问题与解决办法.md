## 一、安装阶段的问题

### 提示「解析包出错」/「解析错误」

按顺序试：

1. 确认 APK **下完整了**——断点续传的包经常只有一半，删掉重新下一遍；
2. 确认文件没被改名成 `.txt`，也没在传输中损坏（核 MD5 `6e289042ccd04a3957fa6e1e51486018`，见 [下载与安装教程.md](下载与安装教程.md)）；
3. 文件放 U 盘或本地存储的**根目录**再点一次安装，别嵌多层文件夹；
4. 还不行就说明设备系统太旧，对照 [支持哪些设备与系统要求.md](支持哪些设备与系统要求.md) 的安卓版本要求。

### 装的时候提示「禁止安装」/「未知来源」

这不是故障，是系统的安全拦截。按提示进设置、给文件管理器或浏览器打开「安装未知来源应用」，再回来点安装。装完可以关掉这个开关。

### 提示存储空间不足

盒子和老电视的内置存储普遍很小。到设置里看剩余空间，卸掉不用的应用、清掉其他应用的缓存，腾出几百 MB 再装——安装包本身只有 12.44M，但安装过程需要的临时空间比这大。

## 二、打开阶段的问题

### 点开闪退 / 一闪就退回桌面

常见原因按概率排：

1. **装的不是这个包名的版本**：同名应用很多，先到设置 → 应用管理里看已安装应用的包名，确认是 `tv.kuaidou.iptv.v2`；
2. **系统版本过低**：安卓 5.0 以下的老设备跑不动新版本，参考设备要求那篇；
3. **装的是覆盖安装的旧版残留**：先卸载、再装新包——旧版本的数据与新版本打架是常见闪退原因；
4. **存储快满或缓存损坏**：到设置 → 应用 → GeekTV 里「清除缓存」再打开；
5. **盒子本身兼容性差**：个别老盒子对所有第三方 APK 都容易闪退，可以换个设备交叉验证——手机上能开、盒子上开不了，问题就在盒子。

### 卡在启动页 / 一直转圈进不去

- **先查网络**：用同一台设备打开别的联网应用试一下，网不通时它就一直加载；
- **换一个网络环境对比**：让手机开热点、电视盒子改连热点再打开——热点下能进说明是家里网络这一层，排查思路见 [直播卡顿怎么解决.md](直播卡顿怎么解决.md) 第三节；
- **再核安装包**：包下得不完整也会停在启动阶段，重下一次；
- **清缓存重开**：设置 → 应用 → GeekTV → 清除缓存（不用清数据，先试缓存）。

### 打开要我输授权码

正常情况就是停在带【OK】的页面，**点 OK 直接进**，不需要码（见 [电视端基本操作指南.md](电视端基本操作指南.md)）。如果你拿到的包要求必须输码才能进，那不是本文档对应这份包的行为，建议换用网盘里这份完整包。

## 三、播放阶段的问题

### 播放卡顿、转圈

先做个 30 秒定位：换几个台、点几部片**都卡**，问题在你的网络或设备；**只有某一路卡**，问题在那一路的线路上。完整的排查顺序（降画质、重启、换有线、清缓存、判断晚高峰）单独写在 [直播卡顿怎么解决.md](直播卡顿怎么解决.md)，这里只留最常用的四步：

1. **降画质**：播放器里把超清/蓝光降到标清或高清，这是最快见效的一步；
2. **看是不是只有这个源卡**：换个台、换部片试——只有一个源卡是源的问题，全都卡是网络的问题；
3. **看网络**：高峰期家里多人同时看会抢带宽，有线连接比 Wi-Fi 稳；老盒子离路由器远时信号衰减明显；
4. **重启设备**：盒子长期不重启会越来越卡，断电 30 秒再开机。

### 有声音没画面 / 画面花屏 / 黑屏

1. 换一个频道或另一部片，判断是个别源还是全部——个别源的问题等它恢复或换台即可；
2. 检查电视自身的图像设置（护眼模式、分辨率输出）是否被改过；
3. 退出应用重进，仍异常就清缓存；
4. 多个应用同时画面异常时，问题在电视或盒子本身，不在这个应用。

### 直播列表里找不到某个台

直播频道清单随版本与线路调整会变动，**列表以你打开后的实际显示为准**，本文不写死具体台名。找不到时先用搜索试试，搜不到说明当前版本的线路里没有，等更新。

## 四、还没解决怎么办

自查三件事，基本能定位问题层级：**包对不对**（包名与 MD5）、**设备够不够**（安卓版本与存储）、**网络通不通**（换应用对比）。三样都没问题还异常，多半是这个版本在你的设备上有兼容问题，可以留意下载渠道有没有更新版本（版本号以下载页当时显示为准）。安装包重新取一份，见 [下载与安装教程.md](下载与安装教程.md)。
