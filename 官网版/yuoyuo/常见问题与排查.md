## 一、注册收不到短信验证码

按这个顺序排查：

1. 手机号输错没有——注册页的号要能收短信。
2. 信号与网络：信号弱的环境短信会延迟，等 1~2 分钟再看。
3. 短信被拦截：查一下手机的骚扰拦截/短信过滤列表，验证码常被归进垃圾短信。
4. 短时间内反复请求会被限流，隔几分钟再试。
5. 都不行：换 Wi-Fi / 移动数据再试一次，仍收不到就稍后再注册（运营商通道波动时有发生）。

## 二、发消息没反应、一直转圈

这是网络问题的高发场景，按可能性排序：

1. **手机没网**：先确认 Wi-Fi 或流量本身能打开网页。
2. **应用没拿到网络权限**：系统设置 → 应用 → yuoyuo → 权限，确认网络权限允许。
3. **模型连不上**：有第三方页面的常见问题解答推测**服务可能部署在海外服务器**，国内网络直连可能不稳定；同一页面给出的办法是使用合规的网络加速工具改善连接。另一个更简单的判据：**Gemini 模型需要能连上其服务的网络环境、DeepSeek 国内网络一般可直连**——现象是同一个应用里换个模型又能聊，切到 DeepSeek 试试（切换方法见 [模型切换与角色创建.md](模型切换与角色创建.md) 第三节）。此为第三方口径，实际表现因网络环境而异。
4. **当日额度用完**：能打开界面但发不出去，看剩余次数（见 [注册登录与邀请码.md](注册登录与邀请码.md) 第四节）。

第 3 条是多个用户反馈与页面共同提到的口径，具体表现因网络环境而异，以你实测为准。

## 三、安装失败、闪退、黑屏

| 现象 | 处理 |
| --- | --- |
| 提示解析失败 | 安装包没下完或已损坏，重新下载（安装包应约 7.11M，见 [下载与安装教程.md](下载与安装教程.md) 第二节） |
| 提示禁止安装未知来源 | 按系统提示到设置里允许当前来源安装 |
| 装完打不开/闪退 | 先重启手机再开；仍闪退则卸载后重装一次最新包 |
| 界面显示错乱 | 有页面建议检查系统版本与 WebView 组件（Android System WebView）是否为最新；此条为单一来源建议，实测因机型而异 |
| 卡顿 | 在系统「应用管理」里清一次缓存 |

低配手机压力不大——安装包 7.11M，第三方页面也提到基础运行对手机配置要求不高。

## 四、聊天记录与账号问题

- **记录还在不在**：人设与聊天记录跟着账号存在服务端，重装/换手机后同手机号登录即可（见 [注册登录与邀请码.md](注册登录与邀请码.md) 第五节）。
- **AI 忘了之前聊的**：多半是切换过模型导致部分记忆重置，或长剧情输入过长，处理办法见 [模型切换与角色创建.md](模型切换与角色创建.md) 第四节。
- **角色人设变味**：把人设设定写得更具体，别在剧情中途频繁切模型。

## 五、什么时候该重新装一遍

试过上面所有办法仍不正常，且怀疑是本地安装的问题时：卸载 → 从 [yuoyuo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3fe01ddba6a1) 重新下载安装包 → 重装 → 同手机号登录。聊天记录在云端，卸载重装不丢记录。
