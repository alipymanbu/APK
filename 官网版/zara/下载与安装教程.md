## 二、安装前核对三件事

1. **存储空间**：安装包本身 135 MB，安装时还要解压落地，建议至少留出 1 GB 空闲存储。
2. **系统版本**：在系统设置里看自己的安卓版本，对照上文的系统要求。
3. **是否装过其他渠道的 Zara**：只要你之前装过包名相同（`com.inditex.zara`）但来源不同的版本，签名对不上就会安装失败。先卸载旧的再装——应用内的收藏夹、购物篮这类本地数据会一起被清掉，账号本身不受影响，重新登录即可。

## 三、从网盘拿到安装文件

[**Zara 安装文件资源（夸克网盘）**](https://pan.quark.cn/s/04fba16958ec)转存到自己网盘后，把 APK 文件下载到手机存储里，文件名形如 `zara_v15.14.0.apk`。然后在文件管理器里找到它、点开安装——第一次通常会卡在权限上，看下一节。

## 四、开启「安装未知应用」权限

安卓默认不允许安装官方应用商店之外的安装包，需要给「经手这个文件的应用」（一般是文件管理器或浏览器）单独放行：

1. 打开 **设置 → 应用 → 特殊应用权限（或「更多安全设置」）→ 安装未知应用**。
2. 找到你用来打开 APK 的那个应用（文件管理器 / 浏览器 / 网盘客户端）。
3. 打开「允许从此来源安装」。
4. 回到文件管理器重新点 APK 安装。

各品牌路径略有差异，但关键词都是「安装未知应用」。如果你用的是鸿蒙系统（华为 / 荣耀新机型），还要检查 **设置 → 系统和更新 → 纯净模式**，开启状态下外部 APK 会被直接拦下。

## 五、校验 MD5（可选但推荐）

下载中断可能造成文件损坏，安装时报「解析包出现问题」。如果你在电脑上下载后传到手机，可以顺手校验一次，结果应等于 `C861B08DA4ABD1F8A196E5A9AF939688`：

```powershell
certutil -hashfile zara_v15.14.0.apk MD5
```

对不上就重新下载一遍，别硬装。

## 六、装不上时按这张表排查

| 你看到的提示 | 多半是 | 怎么处理 |
| --- | --- | --- |
| 应用未安装（之前装过 Zara） | 签名冲突 | 卸载已装的版本再装，见第二节第 3 条 |
| 解析包出现问题 | 文件不完整或损坏 | 重新下载，核对文件大小与 MD5 |
| 与你的设备不兼容 | 系统版本过低 | 升级系统，或改用要求更低的版本 |
| 安装到一半提示空间不足 | 存储不够 | 清理出至少 1 GB 后重试 |
| 安装被拦截 / 按钮置灰 | 纯净模式或安全防护 | 按第四节放行来源，装完建议把「允许」关回去 |
| 一直停在「安装中」 | 安装任务卡住 | 重启手机后重新安装 |

降级提醒：安卓不允许用旧版直接覆盖新版。如果你手机上已经装着更高的版本号、想换回这份 15.14.0，需要先卸载再装。
