## 一、整体流程

```
输入灵感（一句话或几句话）→ 选风格与情绪 → 生成 → 试听 → 微调或重生成 → 保存 / 导出
```

一首完整歌曲包含歌词、旋律与编配，由应用一次生成。耗时参考：**约 30 秒到 2 分钟**（多数用户实测落在这个区间），晚间高峰期可能更久，转圈超过 2~3 分钟再考虑按失败处理。

## 二、灵感怎么输入

首页点「AI 写歌」（部分版本叫「AI 音乐」）进入创作页，把想写的主题用一两句话描述出来。

输入得越具体，成品越贴主题。对比：

| 输入 | 效果 |
| --- | --- |
| 「生日」 | 主题太泛，生成结果随机性大 |
| 「给闺蜜的 30 岁生日祝福，欢快一点，提到十年友谊」 | 主题、情绪、细节都有，歌词明显更贴 |

两种写法都可以：只给主题让应用生成全部歌词；或者自己先写好歌词，再让应用谱曲编配。

## 三、风格、情绪与 BPM 怎么选

生成前可以调这几个参数，各自管的东西不同：

| 参数 | 管什么 | 常见选项 / 参考值 |
| --- | --- | --- |
| 风格 | 编曲与配器的整体走向 | 流行、古风、电子、摇滚、说唱 |
| 情绪 | 旋律的明暗与节奏密度 | 欢快、悲伤、治愈 |
| BPM | 每分钟拍数，数值越大节奏越快 | 抒情慢歌常用 60~90，节奏快的歌 120 以上 |
| 段落长度 | 主歌 / 副歌的篇幅 | 想要短一点便于发视频，就调短 |

不确定选什么就先用默认值生成一版听效果，再针对性换参数——换风格重生成比反复微调更快看到差异。

一个省次数的顺序：免费可生成的次数有限，先把歌词和参数定得具体一些再点生成；「随手一试再重试」最烧次数，次数用完的说明在 [常见问题与付费说明.md](常见问题与付费说明.md)。

## 四、生成之后还能改什么

- **歌词**：点歌词句子可以手动改字句；应用带押韵调整，改完可以让它自动顺一遍韵脚；
- **版本对比**：同一首歌会保留可切换的不同版本，试听时逐个对比再定稿；
- **换风格重生成**：对旋律不满意时，换一个风格或情绪重新生成，比在原版上纠结更快；
- **转翻唱或 MV**：成品可以直接送去 AI 翻唱（见 [AI翻唱与MV制作.md](AI翻唱与MV制作.md)），或用照片生成对口型 MV。

## 五、生成失败或一直转圈

1. 先等满 2~3 分钟，云端生成高峰期就是慢；
2. 检查网络：生成在云端完成，断网或弱网会一直卡在生成页；
3. 换个时间段再试，连续失败多半是服务端排队；
4. 还不行就重启应用再发起一次。

次数用完、付费相关的问题在 [常见问题与付费说明.md](常见问题与付费说明.md) 里有汇总；第一次打开应用还没登录的，先回 [注册登录方法.md](注册登录方法.md)。
