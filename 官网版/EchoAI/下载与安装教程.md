## 四、安装步骤

1. 从网盘把 apk 下载到手机存储（分享页里一般有「转存」或「保存到网盘」的提示，按界面操作即可）；
2. 在文件管理器里点开下载好的 apk；
3. 系统弹出「禁止安装未知来源应用」提示时，按提示去设置里允许你的文件管理器（或浏览器）安装应用，返回后继续；
4. 点「安装」，等进度条走完；
5. 打开应用，首次启动会有几页功能引导，可以直接跳过，不影响使用。

装好后的第一件事是登录账号，步骤在 [注册登录方法.md](注册登录方法.md)。

## 五、装不上或打不开的排查

| 现象 | 先试什么 |
| --- | --- |
| 提示「解析包错误」 | 多半是下载不完整：重新下载，并核对文件大小是否在 70M 上下 |
| 安装按钮点不动 / 一直转圈 | 确认已给文件管理器「安装未知应用」权限；清理一下手机存储，预留比安装包大一倍的空间再装 |
| 提示系统版本过低 | 各渠道标注的系统要求不一（有 4.3 以上、5.2 以上两种说法），实在装不上就先把系统升级到较新的安卓版本 |
| 打开就闪退 | 重启手机再开；不行就清一下应用缓存或卸载重装 |
| 安装后图标消失 | 部分手机管家会把新装应用折叠进「风险应用」，去手机管家里恢复信任即可 |
| 手头是 iPhone，或想装在电脑上 | 这款只有安卓手机版，其他平台的可行办法见 [电脑版与苹果手机能用吗.md](电脑版与苹果手机能用吗.md) |
