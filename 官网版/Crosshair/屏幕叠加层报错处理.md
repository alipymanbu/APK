# Crosshair 屏幕叠加层报错处理

> 本篇讲 Crosshair 相关的悬浮窗权限疑难：授权时弹「屏幕叠加层已检测到」、悬浮窗开关点不动或灰置、侧装应用的权限受限。常规的权限开启路径在[下载与安装教程](下载与安装教程.md)第四节，装不上的问题在[安装被拦截与失败处理](安装被拦截与失败处理.md)。

## 一、「屏幕叠加层已检测到」是什么意思

给应用授予敏感权限时（或某些安装动作进行中），系统突然弹出「检测到屏幕叠加层 / Screen overlay detected」，授权按钮点不了 —— 这**不是手机坏了，也不是 Crosshair 出了问题**。

背景机制：从 Android 6.0 起，只要有别的应用持有悬浮窗权限，系统就会暂停这类敏感授权。原因是悬浮层理论上可以盖住授权弹窗、伪造按钮骗你点击，所以系统要求先把屏幕「清干净」再授权。

也就是说：此刻你屏幕上（或后台里）还有**另一个**应用开着悬浮窗，把它的悬浮权限临时关掉即可。注意闯祸的往往不是眼前看得见的那个悬浮球，而是藏在后台的滤镜、清理类应用。

## 二、三步修复授权被拦

1. **点弹窗里的「打开设置」按钮**（有的话），系统直接跳到悬浮窗权限列表；没有这个按钮就手动去：设置 → 应用 → 特殊应用访问权限 → 显示在其他应用上层（各品牌路径见[下载与安装教程](下载与安装教程.md)的表格）；
2. **在列表里找嫌疑应用，临时关掉它的开关**。高频元凶按命中概率排：
   - 聊天工具的聊天气泡 / 悬浮回复（Messenger 一类）；
   - 蓝光过滤、护眼滤镜、夜间模式类应用；
   - 录屏、投屏工具；
   - 手机清理、提速、游戏加速器类应用；
   - 你自己手机上的其他悬浮球、侧边栏、小窗工具；
3. **回到刚才的授权页重试**，成功后再把刚才关掉的应用悬浮权限开回去。

一次只关一个嫌疑应用再试，比全部关掉再逐个恢复省事得多。

## 三、找不到嫌疑应用：安全模式兜底

悬浮权限列表里看不出谁在捣乱时，用安全模式把第三方应用全部隔离：

1. 长按电源键调出关机菜单；
2. **长按「关机」选项不放**，直到弹出「将以安全模式重启」的提示，确认；
3. 重启后进入安全模式（屏幕角落有标识），此时所有第三方应用（包括各种悬浮窗）都不在运行；
4. 在安全模式里打开 设置 → 应用 → Crosshair，把悬浮窗权限授好；
5. 正常重启回到普通模式，权限已保留，报错消失。

## 四、悬浮窗开关灰置或点不动

侧装来的应用，悬浮窗开关有时是灰的，或提示「受限」。这是 Android 13 起对商店外安装应用的权限收紧策略，处理办法：

1. 设置 → 应用 → **Crosshair** → 右上角三点菜单 → 点「**允许受限设置**」（有这一项就点它，多数情况点了就解）；
2. 没有三点菜单这一项时，检查系统更新装到最新，再回来看；
3. 手机登录了公司账户或开了工作资料的，先退出工作资料再授权；
4. 上面都无效时，把 Crosshair 卸载，改用系统文件管理器（而不是第三方浏览器）重新安装一遍，再走授权 —— 安装来源会影响系统对它的信任判定。

授权通过后回 App 点 Start 验证；准星还是不出来的其他原因，按[常见问题与解决方法](常见问题与解决方法.md)第一节的顺序排查。
