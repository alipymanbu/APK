## 一、安装前先弄清三件事

1. **你手里这份是 1.0.22 版**，安装包约 11.34 MB，包名 `com.delightutils.crosshair`。官方后来出过改名加 AI 功能的 2.x 新版，但那份网盘资源固定在 1.0.22 —— 版本线索写在哪都一样，详见[版本历史与更新说明](版本历史与更新说明.md)。
2. **它靠悬浮窗工作**。装完第一次点 Start 时，系统会要求你授予「显示在其他应用上层」权限，不给这个权限，准星就叠不到游戏画面上。
3. **它是普通 APK 安装包**，不在应用商店里，需要走「安装未知来源应用」的流程，安卓 8.0 以上都支持这种安装方式。

## 二、从网盘拿到安装包

1. 打开上面的夸克网盘链接，把里面的 Crosshair 安装包**转存到自己的网盘**；
2. 在手机上打开夸克网盘 App，找到刚转存的文件，点下载；
3. 下载完成后直接点文件，系统会弹出安装确认。

资源是转发分享的常规用法，转存后文件就在你自己账号里，之后随时可以重新下载。

## 三、安装步骤

1. 点开下载好的 APK，系统提示「无法安装未知来源应用」时，按提示跳到设置页；
2. 找到**允许来自此来源的应用**（不同手机叫法略有差别，也可能叫「安装未知应用」），打开开关，返回安装界面；
3. 点**安装**，等进度走完；
4. 装完点**打开**，或者之后从桌面图标进入。

如果安装中途提示「解析包出错」，多数是下载不完整，回网盘重新下一次再装。装好后可以到手机的 设置 → 应用管理 里确认应用名为 Crosshair、包名是 `com.delightutils.crosshair`，避免和别的准星类应用搞混。

安装时还可能碰到两类拦截：系统弹「有害应用」警告（Play 保护机制的例行扫描，点「仍然安装」即可），以及点了安装却提示「应用未安装」—— 两种情况的原因与处理都整理在[安装被拦截与失败处理](安装被拦截与失败处理.md)。

## 四、开启悬浮窗权限（关键一步）

第一次进 App 点 Start，通常会直接弹出系统授权页，勾选允许即可。如果当时点了拒绝，或者准星一直不出现，就手动去设置里开：

| 手机品牌 | 大致路径 |
| --- | --- |
| 原生 / Pixel | 设置 → 应用 → 特殊应用访问权限 → 显示在其他应用上层 |
| 华为 / 荣耀 | 设置 → 应用和服务 → 权限管理 → 悬浮窗 |
| 小米 / Redmi | 设置 → 应用设置 → 授权管理 → 悬浮窗（或在应用详情的权限管理里） |
| OPPO / 一加 / realme | 设置 → 应用 → 应用管理 → 对应应用 → 悬浮窗 |
| vivo / iQOO | 设置 → 应用与权限 → 权限管理 → 悬浮窗 |
| 三星 | 设置 → 应用 → 对应应用 → 权限 → 其他应用上层显示 |

各系统版本菜单名称会有出入，找不到时直接在设置顶部搜索「悬浮窗」或「显示在其他应用上层」最快。权限开好后回到 App 再点一次 Start。

授权时如果弹出「屏幕叠加层已检测到」、或悬浮窗开关是灰的点不动，是系统层面的拦截，不是这个 App 的问题，解法在[屏幕叠加层报错处理](屏幕叠加层报错处理.md)。

## 五、首次运行检查清单

按顺序过一遍，缺哪步补哪步：

1. 悬浮窗权限已开启（第四节）；
2. 回到 App，点 **Start**，准星出现在屏幕上；
3. 按桌面键回到桌面，准星还在，说明悬浮层生效了；
4. 打开任意一款游戏，确认准星叠在游戏画面上；
5. 位置或样式不满意，进 [准星设置与调整方法](准星设置与调整方法.md) 调；
6. 不想用了，回 App 点 **Stop** 即可撤掉准星。

安装过程卡住、准星不显示这类情况的处理办法，集中写在[常见问题与解决方法](常见问题与解决方法.md)里。
