# Crosshair 安装被拦截与失败处理

> 本篇解决 Crosshair 安装环节的两类麻烦：系统或安全组件拦着不让装、点了安装却提示失败。正常安装流程本身在[下载与安装教程](下载与安装教程.md)，权限相关的另一类报错看[屏幕叠加层报错处理](屏幕叠加层报错处理.md)。

## 一、先分清你遇到的是哪一种

| 现象 | 大概率原因 | 去哪节 |
| --- | --- | --- |
| 安装前弹出「有害应用 / 风险应用」警告 | Play 保护机制对商店外安装包的例行扫描 | 第二节 |
| 三星手机上装不上，也没有明确报错 | 自动拦截器（Auto Blocker）在拦 | 第三节 |
| 提示「应用未安装 / App not installed」 | 存储不足、签名冲突、文件损坏等原因 | 第四节 |
| 装好了，但授权或使用环节出问题 | 与安装无关，是权限层面的事 | [屏幕叠加层报错处理](屏幕叠加层报错处理.md) |

## 二、Play 保护机制警告怎么处理

商店外的 APK 首次安装时，Google Play 保护机制几乎必扫一遍，可能弹「不建议安装此应用」一类的警告。它扫的是「来源不明的安装包」这个共性，不代表文件一定有问题，处理顺序：

1. **首选：点警告里的「仍然安装 / Install anyway」**。如果你核对过文件的 MD5（方法见[版本历史与更新说明](版本历史与更新说明.md)第四节），这步就是走个流程；
2. **弹窗里没有「仍然安装」选项时**，临时关掉扫描再装：
   - 打开 Play 商店 → 右上角头像 → **Play 保护机制**；
   - 点右上角齿轮图标；
   - 关闭「**使用 Play 保护机制扫描应用**」；
   - 回来重新安装，装完**立刻回去重新打开**这个开关 —— 它是安卓的主力安全防线，只在装这一下需要让路；
3. 装完可以主动到 Play 保护机制页面点一次「扫描」，让它重新过一遍已装应用，正常应显示无风险。

## 三、三星机型：先查自动拦截器

三星 One UI 在标准安全设置之外还有一道 **Auto Blocker（自动拦截器）**，开着时会直接拦下商店外安装：

1. 设置 → **安全和隐私** → **更多安全设置**；
2. 找到 **自动拦截器（Auto Blocker）**，临时关闭开关；
3. 重新安装，装完再把它开回来。

同类机型（老 One UI 版本）这道开关可能叫「阻止安装恶意软件」，位置在 安全和隐私 → 应用保护 一带，名称以你手机上实际显示为准。

## 四、「应用未安装」逐项排查

这条报错最含糊，背后是几种完全不同的问题，按命中概率排：

| 原因 | 判断方法 | 处理 |
| --- | --- | --- |
| 存储不足 | 设置 → 存储看剩余空间 | 清出安装包体积 2~3 倍的空闲再装 |
| 签名冲突 | 手机上已经装过同包名的别的版本（比如从别处下的准星应用） | 先卸载旧的 Crosshair，重启一次再装 |
| 安装包损坏 | 文件比 11.34 MB 明显小，或 MD5 对不上 | 回网盘重新转存下载（校验方法见[版本历史与更新说明](版本历史与更新说明.md)） |
| 系统版本过低 | 手机是很老的安卓版本 | 官方没公布过 1.0.22 的最低系统版本；过老的安卓可能装不上，可升级系统或换设备 |
| 传输不完整 | 用 QQ / 微信传的文件，被压缩或改名 | 走网盘客户端直接下载，别经聊天工具中转 |

排除完这些还是失败，重启手机后再装一次 —— 系统安装服务偶发卡住也会报这个错。
