# Crosshair 常见问题与解决方法

> 本篇收集 Crosshair 1.0.22 用起来最常碰到的几种状况：准星不显示、界面卡住、位置对不齐、账号顾虑、怎么彻底关干净。安装或权限问题先回[下载与安装教程](下载与安装教程.md)，授权弹「屏幕叠加层」报错看[屏幕叠加层报错处理](屏幕叠加层报错处理.md)，版本相关的疑问看[版本历史与更新说明](版本历史与更新说明.md)。

## 一、点了 Start 屏幕上没有准星

按命中率从高到低排查：

1. **悬浮窗权限没真正生效**。去 设置 → 应用 → Crosshair → 权限，确认「显示在其他应用上层」是开着的；部分品牌的手机管家还有一道独立的「悬浮窗管理」开关，也要放行；
2. **悬浮窗开关是灰的、点不动**。侧装应用会被系统收紧权限，去 应用详情的右上角三点菜单点「允许受限设置」，完整解法见[屏幕叠加层报错处理](屏幕叠加层报错处理.md)第四节；
3. **权限开了但 App 是在授权之前启动的**。把 Crosshair 从最近任务里划掉，重新打开再点 Start；
4. **被省电策略杀后台**。有些手机会在锁屏或切游戏后清理后台，把 Crosshair 加入电池白名单 / 自启动名单（小米叫「省电策略无限制」，华为叫「电池优化不受限」）；
5. **悬浮层被别的悬浮窗压住**。同时开着游戏加速器、录屏悬浮球这类工具时，先关掉它们试试。

上面都试过仍不出现，重启一次手机再点 Start —— 悬浮窗服务卡死的情况重启就能恢复。

## 二、调整界面卡住不动

1.0.22 这个版本的更新内容正是**修复界面冻结问题**，所以正常情况下不容易卡。如果你手里的包确实还会卡：

1. 停止操作几秒等它自己恢复，别连续狂点；
2. 没恢复就把 Crosshair 从最近任务划掉重开；
3. 反复出现的话，重启手机后再试；仍然频繁卡死，说明手里的安装包可能不完整或被改过，回到网盘重新转存下载一次（见[版本历史与更新说明](版本历史与更新说明.md)里核对 MD5 的方法）。

## 三、准星位置和游戏弹道对不上

悬浮窗位置是全屏的，不感知游戏状态，所以**开镜前后、不同枪械的弹道中心可能不一样**，这不是故障。处理思路：

- 选一把你最常用的武器和视角（腰际/开镜）作为基准，进训练场打两发看落点；
- 回 App 的 adjust position 里按偏差方向微调，调完回游戏验证（详细步骤见[准星设置与调整方法](准星设置与调整方法.md)第四节）；
- 换游戏后弹道中心变了，同样只调位置参数，一两分钟的事。

## 四、会不会影响游戏账号

先把事实说清楚：这类准星工具的原理是**在屏幕上叠加一个图形层**，不修改游戏文件、不注入游戏进程、不代替你操作，官方介绍里也明确它不需要任何作弊手段就能用。

但有两点你需要自己留意：

- **个别游戏的用户协议对第三方悬浮层有额外约定**，玩之前值得翻一眼你常玩游戏的条款，自己判断是否使用；
- **排位赛、正式比赛对屏幕覆盖物通常更敏感**，竞技场合建议关掉准星再打。

这两条没有标准答案，取决于你玩的具体游戏和场合，工具本身管不了这部分。

## 五、不用了怎么彻底关干净

分三档，按需选用：

| 目的 | 操作 |
| --- | --- |
| 本局不想看到准星 | 回 App 点 **Stop**，准星立即消失，设置保留 |
| 长期不用但想留着 | Stop 之后把 App 从最近任务划掉；再到系统设置里关掉它的悬浮窗权限，需要时再开 |
| 彻底不要了 | 设置 → 应用 → Crosshair → 卸载；卸载后悬浮窗权限随之回收 |

卸载不会残留什么后台组件 —— 它的全部工作就是那层悬浮窗，App 不在了悬浮窗自然也没了。哪天想再用，从[下载与安装教程](下载与安装教程.md)从头装一遍即可。
