## 一、应用内切换语言（先试这个）

有第三方教程提到，DreamFace 应用内自带语言切换入口（以你手上的版本实际界面为准）：

1. 打开 DreamFace，进入探索（Explore）主界面。
2. 点左上角的语言选项。
3. 在语言列表里选「简体中文」或你要的语言。
4. 返回主界面，显示语言即已切换。

如果左上角找不到语言入口，说明你这份版本的入口位置不同或功能有变动，接着往下看系统级的办法。

## 二、应用内没有语言选项时：让系统单独给这个应用换语言

Android 13 与 iOS 13 以后的系统都支持「只改某一个应用的语言」，不影响手机整体：

| 系统 | 操作路径 |
| --- | --- |
| Android 13+ | 设置 → 应用 → DreamFace → 语言 → 选简体中文 |
| iOS 13+ | 设置 → 往下滑到应用列表 → 点 DreamFace → 语言 → 选简体中文 |

两点前提：系统语言列表里要先有简体中文；应用本身支持中文（不支持时这一项是灰色或不出现）。改完退出应用重开一次再看效果。

## 三、应用不支持中文时的应对

按下面的对照找功能，够应付日常操作：

| 界面上的英文 | 对应功能 |
| --- | --- |
| Explore | 探索页，各功能入口都在这 |
| Video / Avatar Video | 做视频：数字人说话、照片动起来 |
| Photo / Image | 做图：AI 生图、滤镜 |
| Templates | 模板列表 |
| Upload | 上传照片或素材 |
| Generate / Create | 点这里开始生成 |
| My Works / History | 作品记录，生成完去这里找成片 |
| Settings | 设置 |
| Subscribe / Upgrade | 订阅与会员页 |

生成类操作的具体步骤，本系列文档都有中文流程：做动效视频看 [照片变视频的操作流程.md](照片变视频的操作流程.md)，做说话视频看 [说话数字人视频制作方法.md](说话数字人视频制作方法.md)。

## 四、装好后第一次打开就在哪设置

装完 DreamFace 第一次打开时，趁着还没开始用，先把语言调好：按第一节的入口找语言选项，找不到就用第二节的系统级设置。还没安装的先看 [下载与安装教程.md](下载与安装教程.md)，其他使用问题集中在 [常见问题与解决办法.md](常见问题与解决办法.md)。
