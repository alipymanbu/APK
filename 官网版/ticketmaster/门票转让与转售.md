# Ticketmaster 门票转让与转售

## 一、先分清两个动作

| | Transfer（转让） | Sell（转售） |
| --- | --- | --- |
| 给谁 | 你指定的朋友/家人 | 平台上的陌生买家 |
| 费用 | 免费 | 活动允许时才能挂 |
| 票的变化 | 对方接受后你这边旧码作废 | 平台作废旧票、**重新签发一张新票**给买家 |
| 你的收入 | 无 | 按你定的价，挂单页会显示实际到手金额；通常活动后 7 个工作日内到账 |

两者都**取决于主办方是否开启**：没开的活动，应用里不会出现对应按钮，或点了提示「Event Organizer hasn't activated transfer/resale」。这不是 bug，是主办方的选择。

## 二、Transfer：把票转给同行的人

1. 登录账号，进 **My Tickets**，点开对应活动。
2. 点 **Transfer**，选要转的那几张票。
3. 收短信一次性验证码，输入后确认（身份校验，防误操作）。
4. 填对方的手机号或邮箱，点 **Confirm**，系统给对方发一封接受邀请邮件。
5. 多人分票：填完点确认后选 **Transfer More** 继续加人。

之后的状态看两个词：

- **Transfer Pending** —— 对方还没接受，提醒他去邮箱点接受链接（收件箱、垃圾箱都看一眼）。
- **Transfer Complete** —— 转移成功。对方会拿到属于自己的新二维码，**你账号里的旧票从此不能入场**。

对方要有 Ticketmaster 账号；没有的话，接受邀请时用**收到邀请的那个邮箱**注册一个即可。

**转错了还能撤**：只要对方还没接受，进订单点 **Cancel Transfer**，票会回到你账号里。对方一旦接受就撤不回了。

## 三、Sell：把票挂出去卖

1. 进 **My Tickets**，点开活动，点 **Sell** → **Sell Your Tickets**。
2. 选要卖的票。若流程中出现 **Review & Accept Offer**，说明有即时收购报价，可以直接对比。
3. 定价。页面会同时显示**同区域其他卖家的报价**，用来参考；改价、下架随时可以。
4. 填收款方式。
5. 复核挂单信息，完成。

几个到账相关的硬条件（美国市场口径，其他国家以页面提示为准）：

- 挂单上架后**未必立刻成交** —— 是否允许转售、有没有上限，由主办方按场次决定。
- 卖出后回款通常在**活动结束后 7 个工作日内**打入你的收款方式；银行账户收款要先完成小额验证（两笔 1 美元以下的入账，添加后 3~5 个工作日出现，需在 7 天内记下金额回去填）。
- 账号里要留一张有效银行卡，用于活动改期/取消时给买家退款。
- 美国活动的卖家还需提交税务识别信息，加拿大卖家需确认非美国税务居民身份。

修改或撤下挂单：My Tickets → 活动 → **Edit Listing** 改价，或 **Cancel Listing** 撤单（App 内为 Cancel Listing）。

## 四、几个高频疑问

- **票显示「延迟交付」还能转/卖吗？** 条码与转让、转售功能可能到临近活动时才开放，稍等再试；一直没开见 [常见问题排查.md](常见问题排查.md)。
- **转出去的票我还能入场吗？** 不能，旧码在对方接受后即失效，详见 [手机票入场与离线使用.md](手机票入场与离线使用.md)。
- **别的渠道买的票能在这里卖吗？** 挂单入口出现在 **My Tickets** 里你本账号的订单上；订单不在这个账号下，就看不到 Sell 按钮。
