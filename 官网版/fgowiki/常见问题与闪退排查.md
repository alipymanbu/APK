## 一、解析包时出现问题

安装阶段最常见的错。按顺序排除：

1. **包没下完整**：重新下载一次；下完对一下大小是否为 13.77M。
2. **文件后缀不对**：确认文件名以 `.apk` 结尾，不是 `.zip`、`.bin`。传输工具偶尔会改后缀，改回来即可。
3. **系统版本过低**：有渠道页标注需安卓 5.2 以上，另有渠道页提示系统低于 6.0 时会出现解析错误——两条说法并存，以你设备实际安装结果为准。系统确实过旧的，升级系统再试。
4. **打开方式不对**：别在聊天软件的预览窗里点开，用文件管理器点。

## 二、装好后打不开或闪退

按代价从小到大试，多数到第二步就好了：

1. **清缓存 + 强制停止**：设置 → 应用 → fgowiki → 存储 → 清除缓存，再点强制停止，重新打开。缓存损坏是闪退的常见原因。
2. **确认联网**：应用的图鉴数据要联网加载，飞行模式或断网时容易白屏、卡首屏。换 Wi-Fi 或流量试一次。
3. **看存储空间**：手机剩余空间太少也会闪退，清出几百 MB 再试。
4. **查权限**：设置 → 应用 → fgowiki → 权限，看有没有被禁掉的必需权限；清理类工具的「锁后台」「限制后台联网」也一并放行。
5. **重装**：以上都无效就卸载重装。卸载前确认你没有在应用里存了会丢的记录（如收藏、自定义分类）。
6. **仍不行**：多半是该版本与你系统不兼容，换一个渠道包或等更新，安装包入口见 [下载与安装教程.md](下载与安装教程.md)。

## 三、图鉴或页面加载不出来

| 现象 | 处理 |
| --- | --- |
| 首次打开长时间白屏 | 首次加载数据本来就慢，等 10~20 秒；换个网络环境再试 |
| 部分页面空白、其余正常 | 该页数据在拉取中，下拉刷新一次 |
| 高峰期打开慢 | 有更新日志提到 v1.9.11 优化过服务器配置以提升高峰期打开速度，慢时多等一会即可，具体以实际体验为准 |
| 明显与游戏内容对不上 | wiki 数据更新滞后于游戏改版，等应用内数据刷新；确属错误的条目去应用的反馈渠道报 |

应用需要联网这一条是硬要求，离线状态下它基本不可用，别指望在没网时查资料。

## 四、「Mooncell 客户端」和这个是同一个吗

不是同一个包，别装混了：

- 本文这个 fgowiki，包名是 `com.umowang.fgo.fgowiki`。
- 另有一个叫 Mooncell 的客户端，旧版包名 `wiki.mooncell.app`、新版 `wiki.fgo.app`——两者包名不同，可以在安卓上共存。渠道页的常见问题里常把这两个客户端的说明混在一起，辨认方法是：点右上角三个点、有悬浮窗切换的那个是 Mooncell 新版客户端。

它们的数据源头都是同一个玩家共写的 FGO 中文 Wiki，但**安装包互不通用、签名也不同**：手机上已装 Mooncell 客户端的，装 fgowiki 不冲突；反过来装 Mooncell 时若提示签名冲突，先分清自己手上是哪一份包。

## 五、论坛登录不上 / 提示账号异常

v1.9.11 更换了论坛用户系统（保留原有用户数据），升级后第一次进论坛若提示登录状态异常，退出重新登录一次即可。历史帖子与账号数据按官方说明是保留的，找不到自己旧帖时先用搜索，而不是直接判定丢了。

## 六、其他零散问题

- **应用名显示为别的名字**：渠道页对它的叫法很多（FGOwiki、FGO英灵图鉴、FGO wiki mooncell），装到桌面看的是包里设定的应用名，认包名 `com.umowang.fgo.fgowiki` 即可。
- **升级要不要先卸载**：不需要，直接覆盖安装；只有出现「签名不一致」时才需要先卸载。
