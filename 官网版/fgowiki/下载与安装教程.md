## 一、这是什么，装的是哪一份

fgowiki 是给《Fate/Grand Order》（简称 FGO）玩家用的资料查询工具：英灵、礼装、素材、装备的图鉴，加上活动攻略与模拟抽卡，装在安卓手机上随时查。你从搜索引擎点进这篇，多半是想把包装到手机上，那就直接看下面的步骤。

先把手上这份包的事实说清楚（以本地留存的安装包为准，网上各渠道页显示的「最新版」未必是同一份）：

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.9.11 |
| 包名 | `com.umowang.fgo.fgowiki` |
| 安装包大小 | 13.77M |
| MD5 | `1fef778430ed2666b813dfbb723e8e88` |
| 留存时间 | 2026-09-21 |

版本号会随官方更新变动，你实际拿到的以网盘里那份文件名为准（形如 `fgowiki_v1.9.11.apk`）。

## 二、从哪拿安装包

安装文件在夸克网盘的分享里：[fgowiki 安装文件资源（夸克网盘）](https://pan.quark.cn/s/30c0ed6c6c5d)。

1. 打开上面这条分享链接，转存到你自己的网盘（或直接在浏览器里下载）。
2. 手机上用夸克 App 打开转存后的目录，点那个 `.apk` 文件开始下载。
3. 电脑上下载好的话，把文件发到手机（数据线、局域网传输、或网盘手机端拉取都行），再在手机的文件管理器里点它安装。

包只有 13.77M，流量下也很快。装完可以核对一下文件名与版本号，和上面表格对得上就说明拿对了包。

## 三、安装步骤

安卓装第三方来源的包，需要先给「打开安装包的那个应用」授权：

1. 用浏览器或文件管理器点开 `.apk`，系统若弹「不允许安装来自此来源的应用」，点进去打开展示的开关（安卓 8 以后是按应用单独授权，你用哪个应用打开的包，就给哪个应用授权）。
2. 回到安装界面，点「安装」，等进度走完。
3. 装完点「打开」，首次启动会加载图鉴数据，需要联网，等几秒到十几秒属正常。
4. 之后每次升级都是同样的流程：拿下新版包 → 直接覆盖安装，**不用先卸载**，账号与收藏数据会保留。

如果你之前装过同名应用但提示「安装失败：签名不一致」，说明手机上那份是另一个渠道的包（包名相同、签名不同），先卸载旧的再装这份。

## 四、装不上时先查这几项

按出现频率排序，逐条试：

| 现象 | 先查什么 |
| --- | --- |
| 「解析包时出现问题」 | 三种可能：包没下完整（重新下载）；系统版本低于应用要求（有渠道页标注需安卓 5.2 以上，另有渠道页提示系统低于 6.0 时易出此错，以你设备实际表现为准）；文件被改名成了 `.zip`（改回 `.apk`） |
| 「禁止安装未知应用」 | 按上面第三节给打开包的那个应用授权 |
| 「安装包已损坏」 | 下载中断过，删掉重下；下完可以对一下大小是不是 13.77M |
| 点开安装界面闪一下就没了 | 多半是安装器被清理工具拦截，先关掉手机管家类应用的「拦截安装」再试 |

更细的排查（闪退、打不开、页面加载失败）见 [常见问题与闪退排查.md](常见问题与闪退排查.md)。
