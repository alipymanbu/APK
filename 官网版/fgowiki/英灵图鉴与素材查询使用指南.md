## 一、图鉴入口在哪

装好打开（安装包见 [下载与安装教程.md](下载与安装教程.md)），底部或侧边栏里找到「图鉴」一栏，进去就是角色列表。你要查某个英灵的数值、配卡、宝具，或者某件礼装的效果，都从这里进；素材的掉落地点则在图鉴内的素材/道具分类里查。

整个应用需要联网加载数据，首次进图鉴或切换大分类时会有一段加载时间，属正常。

## 二、怎么快速找到一个英灵

列表页顶部有搜索框，也有筛选条件，两者可以叠加用：

1. 在搜索框直接输英灵名字（支持模糊匹配，输一部分也能带出来）。
2. 用下方的条件收窄范围，常用的有：
   - **星级**：先按 4 星 / 5 星缩小，比逐页翻快得多；
   - **职阶**：Saber、Archer、Lancer 这一栏；
   - **指令卡**：按 Q 卡 / A 卡 / B 卡配卡筛，组队时按这个找打手很方便；
   - **属性/阵营**：混沌、秩序、中立这类，做任务要凑属性时用得上。
3. 条件可以叠加，筛完下滑即是结果；想清掉条件，点筛选栏的重置。

## 三、角色详情页看哪几栏

点进一个英灵后，页面大致分这几块，各有各的用处：

| 栏目 | 你在这看什么 |
| --- | --- |
| 基础数值 | 各阶段的面板值、HP 与攻击力成长 |
| 配卡 | 三色指令卡的分布，决定它打蓝还是打红的打法 |
| 技能 | 三个技能的效果与升级效果，含强化任务后的追加效果 |
| 宝具 | 类型（单体/群体）、色卡、伤害倍率与附带效果 |
| 灵基再临/灵衣 | 各阶段立绘与解锁材料 |
| 素材需求 | 升级、技能练满需要的素材与数量 |

组队前的常规动作是：先看配卡和宝具色，再看技能有没有自带增伤或充能，最后翻素材需求估一下养不养得起。

## 四、素材掉落与掉率怎么查

素材这块是查「去哪刷」的：

1. 在图鉴的素材/道具分类里找到那个素材（可搜索）。
2. 进入素材详情，页面会列出**掉落地点**——对应哪个自由关卡、哪个周本，以及该地点的掉率数据。
3. 关卡条目里还会带出该图的敌人配置（任务怪物），方便你判断加成从者该怎么组。

v1.9.11 的更新日志提到这一版「重制了任务怪物和掉落素材，更利于快速查询」，所以如果你之前用过旧版、觉得素材页对不上，更新后再看一次。掉率是社区维护的统计值，会随游戏改版变动，以页面当前显示为准。

## 五、礼装、装备与其他图鉴

同一套筛选逻辑在其他分类通用：

- **礼装图鉴**：按 cost、卡位、套装效果筛，组队填卡位时查；
- **纹章/灵衣**：刻印与灵衣的解锁条件、所需素材；
- **道具一览**：除了掉落，还标了道具的用途与获取途径。

## 六、攻略与活动在哪看

图鉴之外，首页与分类栏里有活动一览、关卡配置、攻略文章（主线、活动、高难都有）。活动页通常带开始/结束时间与关联卡池，开活动前扫一眼能少漏东西。这部分内容跟着游戏版本走，具体条目以应用内当时显示为准。
