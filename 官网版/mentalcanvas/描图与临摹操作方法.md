# 描图与临摹操作方法：从导入参考图到描完收尾

> 本篇把导入图片、图层、不透明度这几个功能串成一条完整的临摹工作流：准备参考图 → 导入 → 隔离图层 → 调透明度 → 描线 → 收尾。各功能的单独用法见 [界面与绘画功能上手.md](界面与绘画功能上手.md)。

## 一、先把参考图收拾干净

参考图的干净程度直接决定描线时要不要「猜」：

| 参考图来源 | 要做的事 |
| --- | --- |
| 相机拍实物（手绘稿、书页） | 光线均匀、镜头正对纸面（斜拍会有透视变形）；拍完裁掉多余背景 |
| 网图 / 截图 | 挑分辨率高、线条清晰的；导入前裁剪到只留要描的部分 |
| 自己拍的详细照片 | 同上，另外避开反光面 |

手机原图动辄十几 MB，先在相册里裁小再导入，画起来更流畅。

## 二、导入参考图

在作品界面点左上角的插入按钮（入口以实际界面为准），从手机里选中整理好的图片，它会落在当前画布上。需要调整大小和位置时，用应用的选择/变换工具处理。

## 三、把参考图隔离到独立图层

临摹好不好改，全看这一步：

1. 确认参考图目前所在的图层；
2. 在参考图**之上**新建一层，作为描线层。

这样安排后，描线时手滑画错，橡皮只碰得到线稿层；描完想整体处理参考图，也是按层操作、一键到位。

## 四、调低参考图层的不透明度

选中参考图所在图层，把不透明度降到 30%~50%：参考线仍看得见，但不会晃眼压过你的线稿。描线层保持 100%。

## 五、描线

1. 用画笔沿参考线描，粗细按最终效果选——描线层将来就是成品线稿；
2. 复杂的图分区域描，每描完一块，把参考图层的不透明度临时调到 0（等于隐藏），单独检查这块线稿有没有漏线、断线，再调回来继续；
3. 线与线要闭合。后面要上色的话，缺口会让填充的颜色「溢」满整张画布，上色前先检查轮廓闭合。

## 六、收尾

1. **参考图层的处理**：不需要了就把该层内容清掉；想留着原图备用，把不透明度停在 0 即可，不占视觉也不碍事；
2. **保存**：作品实时保存，正常退出不丢；
3. **拿出成品**：导出入口与格式以你装的版本实际界面为准，遇到异常对着 [常见问题与解决方法.md](常见问题与解决方法.md) 查。
