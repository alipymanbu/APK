## 一、先搞清一个总开关：触摸绘画

平板上单指戳一下画布，到底是「画一笔」还是「挪画布」，由**触摸绘画**这一个开关决定：

- 打开：手指按上去就是画笔，指尖直接作画；
- 关闭：单指拖动变成平移画布，只有笔（或后续版本的自动检测）才画得出来。

它的位置在 **设置 → 配置 Krita… → 常规** 里的「触摸绘画」一项。你手上 5.2.11 这一版里它是启用 / 禁用两个选项；**官方在 5.2.13 才加入「自动」并设为默认**（检测到压感笔就自动关触摸绘画），所以 5.2.11 上要自己按习惯手动切。

拿笔作画的人建议把它设为「禁用」，手掌或手指搭上画布才不会画出莫名其妙的线；纯手指涂鸦的用法反之上调为「启用」。这条没调好，是最常见的「怎么老是误画」的根源，更多症状见[常见问题与解决办法.md](常见问题与解决办法.md)。

## 二、双指手势：缩放、旋转、平移

从 5.1 起，Krita 的**多指手势（移动、缩放、旋转）可自定义**，默认就绑了常用组合：

| 手势 | 默认效果 |
| --- | --- |
| 双指捏合 / 张开 | 缩放画布视图 |
| 双指扭转 | 旋转画布视图 |
| 双指拖动（触摸绘画关闭时） | 平移画布视图 |

想改某个手势做什么，去 **设置 → 配置 Krita… → 画布快捷键**，在触摸手势对应的动作里重新分配（比如只让双指缩放、不让它旋转，防止画着画着画布歪掉）。

注意：**手势只改变视图的显示状态**，旋转、镜像过的画布导出时还是原样，不会把图像真的转歪。检查构图时常用的水平镜像同理 —— 桌面版按 `M` 键，平板上到**视图 → 画布**菜单里找对应项，同一菜单里还有逐级旋转、重置旋转与缩放的入口（菜单文字以你装的版本为准）。

## 三、触摸屏辅助按钮面板

平板没有键盘，Krita 专门准备了**触摸屏辅助按钮**面板，全是方便手指点的大按钮。在 **设置 → 面板列表** 里勾选即可显示，常用项如下：

| 分组 | 按钮 |
| --- | --- |
| 文件 | 打开文件、保存文件、另存为 |
| 编辑 | 撤销、重做 |
| 笔刷 | 提高/降低不透明度、提高/降低笔刷颜色亮度、增大/减小笔刷尺寸、切换到上一个预设 |
| 视图 | 旋转画布（向左/向右 15°）、重置画布旋转和缩放、放大、缩小 |
| 其他 | 清除图层内容（慎点） |

把「保存文件」「重置画布旋转和缩放」「增大/减小笔刷尺寸」这几个高频按钮的位置先认熟，能顶掉大部分你记不住的快捷键（面板按钮位置固定，不可拖动重排）。保存的具体讲究见[导出图片与保存格式.md](导出图片与保存格式.md)。

## 四、界面本身也能折腾

Krita 的面板可以随意拖动、吸附、组合：**拖住面板标题栏**就能把它拽到屏幕另一侧吸附，按住 `Ctrl` 拖可暂时取消自动吸附；点面板右上角的 **x** 关掉它，从**设置 → 面板列表**再叫回来。整套布局调顺后可以存成工作区，下次直接切回。

小屏上可以把不常用的面板先关掉（比如不画动画就收起时间轴），把画布区域留给笔 —— 这比硬记操作更重要。想让手指在面板上也能直接滚列表，去 **设置 → 配置 Krita… → 常规** 里找「面板滚动」相关选项，设为触摸屏拖动。

笔刷怎么选、防抖开哪档，见[液化工具在哪与笔刷防抖设置.md](液化工具在哪与笔刷防抖设置.md)。
