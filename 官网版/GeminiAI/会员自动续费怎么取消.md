## 一、先搞清楚：这个应用有没有向你收过费

应用介绍里写的是「提供高级订阅服务，包括优先访问最新功能、更高使用额度、更快响应速度等」——这只是产品说明，**你实际会不会看到付费入口、价格多少，以应用内显示为准**。判断自己有没有开通，看两处：

1. 应用内的「我的 / 设置 / 订阅管理」页面有没有生效中的套餐；
2. 支付端的扣费清单（查法见下节），有没有这个应用的自动扣款协议。

两处都干净，就不存在续费问题，本篇可以只当通用常识读。

## 二、开通前：先把这三个动作做了

来自消费者保护机构（广州市消委会、中国消费者报）2025 年发布的避坑提示：

- **逐字找「自动续费」「连续包月」**：首月低价是常见诱饵，条款常藏在小字或默认勾选里。没有续费打算，就手动取消默认勾选，确认页面显示的是「仅购买单月 / 单次服务」再付款。
- **截图保存开通页面**：当时有没有显著提示、你选的是什么套餐，事后全靠这张图说话。
- **开通后立刻取消一次**：不是白折腾——趁还有入口，先把取消流程走一遍，记住它藏在哪。真到期时你已经知道从哪关。

## 三、取消入口在哪：三条路径

安卓应用的自动续费一般挂在三个地方，**应用内取消了还不够，支付端的绑定往往要单独关**：

| 路径 | 操作 |
| --- | --- |
| 应用内 | 我的 / 设置 → 订阅管理（或「会员中心」）→ 取消自动续费 |
| 微信 | 我 → 服务 → 钱包 → 支付设置 → 扣费服务 → 找到该项目 → 关闭扣费服务 |
| 支付宝 | 我的 → 设置 → 支付设置 → 免密支付/自动扣款 → 找到该项目 → 关闭服务 |

关掉后隔天再看一眼两处清单，确认状态已变——有用户只关了应用内、漏了支付端绑定，结果照样被扣（公开报道里的典型案例）。

## 四、已经被扣费了怎么办

依据是现行《网络交易监督管理办法》第十八条：自动续费应当在**续费日期前 5 日以显著方式提醒**，并提供**显著、简便的随时取消选项**。据此可以主张的权利：

1. **先固定证据**：扣费记录、开通页面截图、你尝试取消的路径截图。
2. **联系平台客服**：明确指出「未收到显著提醒」「取消入口不显著」，要求退款；协商时把这些证据发过去。
3. **协商无果就投诉**：拨打 **12345**，或通过**全国消协智慧 315 平台**在线反映。若平台以「已享受会员权益」拒绝退费，而它当初没做合理提示，该类格式条款可主张无效——这是有公开律师解答与消协提示背书的思路。

**卸载应用不等于取消续费**：有平台在用户卸载后仍继续扣费。要停就按第三节把支付端的协议关掉，别依赖卸载。

## 五、时效说明

本篇引用的是截至 2026 年可查的现行法规条文与消协公开提示；法规与平台入口会调整，以官方发布与你手机上的实际界面为准。GeminiAI 自身的订阅细则（价格、额度、退订条款）应用内未公开的信息本篇不作推测——遇到与应用内显示不一致的地方，以应用内为准，具体问题也可以先对照[常见问题与解决方法.md](常见问题与解决方法.md)。
