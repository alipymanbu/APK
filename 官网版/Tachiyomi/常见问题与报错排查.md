# Tachiyomi 常见问题与报错排查

> 本篇把 Tachiyomi 用起来最常撞见的问题集中列出：扩展装不上、源打不开、图片加载失败、下载卡住、应用闪退等。

## 一、扩展装不上

| 现象 | 检查顺序 |
| --- | --- |
| 扩展列表里点「下载」没反应 | 「更多」→「设置」→「扩展」看扩展仓库还配着没有；0.15.3 的官方仓库已下线，需要加社区仓库（见 [扩展插件与源管理.md](扩展插件与源管理.md) 第三节） |
| 弹了安装确认、装完却不出现 | 看通知栏是否被安全软件拦下；再到系统「应用管理」里确认扩展真的装上了 |
| 报「签名不一致」类错误 | 本体与扩展必须同一签名。如果你装过别的 Tachiyomi 分叉（不同签名的版本，分支情况见 [停更后还能用吗.md](停更后还能用吗.md)），先把旧分叉装的扩展全卸掉再装 |
| 扩展列表整个为空 | 仓库地址失效了，换一个还在维护的社区仓库地址重新添加 |

## 二、源打不开 / 一直转圈

1. 先分清范围：**全部源**都不行，多半是网络或系统 WebView 的问题；**单个源**不行，多半是那个站点自身的问题。
2. **WebView**：源站点的页面解析与人机验证依赖系统 WebView。到系统设置的应用列表里查「Android System WebView」版本，过旧就到应用商店更新，更新完重启手机再试。
3. **人机验证**：部分站点会弹 Cloudflare 之类的验证页，正常点一下就能过；如果卡在验证循环里，常见处理是更新 WebView、在系统设置里给 Tachiyomi 清一次缓存再进。
4. 站点挂了或改版了，只能等扩展维护者跟进；着急看的话用「迁移」换一个源（步骤见 [扩展插件与源管理.md](扩展插件与源管理.md) 第五节）。

## 三、封面 / 图片加载失败

- 同一源下所有封面都不显示 → 该源临时故障或被站点限流，隔段时间再看。
- 只有部分图片出不来 → 站点对连续请求限速，把设置里的图片加载并发调保守一些。
- 阅读页整章白屏 → 退出该章节重进；仍不行就清一次该源缓存再刷新。

## 四、下载卡住 / 一直排队

1. 「更多」→「下载队列」看卡在哪一章，点单章暂停再重试。
2. 检查是不是开了「仅 Wi-Fi 下载」而当前在用流量。
3. 该源正在限速时整批下载都会慢，宁可少选几章分批下。
4. 长期卡死的队列，重启应用即可清掉重来。

## 五、书架更新检查很慢或失败

- 更新检查是逐源请求的，装了几十个源自然就慢 —— 不用的源及时卸载（见 [扩展插件与源管理.md](扩展插件与源管理.md) 第六节）。
- 「设置」→「更新」里把检查时间挪到夜里、开「仅 Wi-Fi」，避开网络高峰。
- 个别源一直失败，去该源页面手动刷新一次，先排除是不是站点自己的问题。

## 六、应用闪退

1. 重启应用，先看能否复现。
2. 系统设置里给 Tachiyomi「清除缓存」。注意**别先清数据** —— 清数据会把书架一起抹掉，除非你已有备份。
3. 确认手机剩余存储充足：下载章节、缓存图片都会占空间。
4. 仍闪退且救不回来：先做一次备份（路径见 [备份恢复与换机迁移.md](备份恢复与换机迁移.md) 第二节），再卸载重装，最后恢复备份。
5. 一启动就闪退、且最近装过新扩展：有用户反馈个别损坏的扩展会让应用起不来 —— 扩展在系统里是独立的小应用（名字以阅读器名开头），到系统「应用管理」里把最近新装的扩展卸掉再试。

## 七、隐私与账号

- 不想留阅读记录：开「隐身模式」（见 [书架与阅读设置.md](书架与阅读设置.md) 第七节）。
- 追踪器不同步：到「设置」→「追踪」里看绑定状态，登录过期就重新登录。
- 卸载应用前记得：书架与进度都在应用数据里，**先备份再动手**。

## 八、本地源里的文件不显示

自己的漫画文件放好了却在「本地源」里看不到，按这几条查（本地源用法见 [本地漫画怎么导入.md](本地漫画怎么导入.md)）：

1. **位置错了**：必须是「内部存储/`Tachiyomi/local/`」，最容易错放成 `eu.kanade.tachiyomi/` 或下载文件夹里 —— 那两个目录本地源不扫。
2. **多套了一层**：作品文件夹必须直接在 `local/` 下面，中间不能再有别的层级。
3. **压缩包格式**：RAR5 新格式不支持，包内不要套文件夹；换 ZIP/CBZ 最稳。
4. **没刷新**：新加的章节不会自动出现，到作品详情页下拉刷新章节列表。
5. **权限**：确认给过应用「存储」访问权限。
