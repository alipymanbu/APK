## 一、装之前先知道的几件事

Tachiyomi 是一款开源（Apache License 2.0）的 Android 漫画阅读器，只有 Android 版，没有 iOS 版。它本身不带任何漫画内容，也不内置任何站点 —— 装好之后书架是空的，要靠安装「扩展」来添加内容渠道，这一步见 [扩展插件与源管理.md](扩展插件与源管理.md)。

你拿到的这份安装包信息（以本地采集为准，网上搜到的往往是别人重新打包的版本）：

| 项目 | 值 |
| --- | --- |
| 版本 | 0.15.3（2024 年 1 月，原项目最后一个正式版本） |
| 包名 | `eu.kanade.tachiyomi` |
| 安装包大小 | 21.66 MB |
| MD5 | `b90ad90279a69569eaf4b2ff372f8208` |
| 系统要求 | Android 6.0 及以上 |
| 许可证 | Apache License 2.0 |

## 二、下载安装包

Tachiyomi 从未上架 Google Play，原团队的发布渠道又已在 2024 年初下架，所以现在拿到安装包主要靠留存资源。上方网盘块里的 **Tachiyomi 安装文件资源（夸克网盘）** 就是这份 0.15.3 的 APK，转存后下载到手机即可。

下载完想核对文件，可以比对 MD5：`b90ad90279a69569eaf4b2ff372f8208`。

## 三、安装步骤

1. 在手机上点开下载好的 APK 文件，系统会提示「出于安全考虑，已禁止安装来自此来源的应用」，点「设置」。
2. 打开「允许来自此来源的应用」，返回安装界面继续。
3. 若弹出 Play Protect 扫描提示，选「仍要安装」这类继续项 —— 所有商店外安装的 APK 都会走这道流程，不是这份安装包特有的。
4. 等安装完成，点「打开」。

## 四、安装被拦 / 提示「应用未安装」

安装这步最常见的失败都与「手机里已有别的版本」有关：

| 提示 | 原因与处理 |
| --- | --- |
| 「应用未安装」（App not installed） | 手机上已装有**同包名但签名不同**的版本（比如别的分叉、别人改包的版本）。先做一次备份（见 [备份恢复与换机迁移.md](备份恢复与换机迁移.md)），卸载旧版后再装这份 |
| 提示不能降级安装 | 手机上已装的版本号比这份高，Android 不允许直接装回旧版 —— 想回到 0.15.3 只能先卸载再装 |
| 安装到一半空间不足 | 安装过程需要数倍于安装包的临时空间，至少留出几百 MB 再试 |
| 反复安装失败 | 重启手机再试；还不行就到系统「应用管理」里清一下「软件包安装程序」的缓存 |

更多运行期报错（扩展、源、闪退）集中在 [常见问题与报错排查.md](常见问题与报错排查.md)。

## 五、第一次启动的引导

首次启动是一个几步的引导流程，做完就能进主界面：

1. **选主题**：跟随系统 / 浅色 / 深色，之后随时能在设置里改。
2. **选默认阅读器**：先随便选一个（比如「从左到右」），读完第一本再按习惯调（各模式差异见 [书架与阅读设置.md](书架与阅读设置.md) 第三节）。
3. **选择下载文件夹**：点「选择文件夹」，建议新建一个名为 `Tachiyomi Downloads` 的目录，点「使用此文件夹」并允许访问权限。以后离线下载的章节都存在这里。
4. **允许安装未知应用**：这一步是给 Tachiyomi 本体放行「安装未知应用」权限，因为扩展是以 APK 形式装进系统的，不放行后面装扩展会失败。
5. 点「开始使用」进入主界面。

## 六、它会用到哪些权限

| 权限 | 干什么用 | 能不能拒绝 |
| --- | --- | --- |
| 存储读写 | 保存下载的章节、备份文件 | 用下载/备份功能就需要 |
| 网络访问 | 浏览扩展仓库、读取漫画页面 | 必需 |
| 安装未知应用 | 安装与自动更新扩展 | 装扩展就需要 |
| 保持设备唤醒 | 阅读时屏幕不熄灭 | 可选，只影响体验 |

## 七、装完之后

刚进主界面的书架是空的，这是正常的 —— 第一步是去装扩展，参考 [扩展插件与源管理.md](扩展插件与源管理.md)；装的过程中遇到报错，去 [常见问题与报错排查.md](常见问题与报错排查.md)；想先弄清楚这个项目现在的状态，看 [停更后还能用吗.md](停更后还能用吗.md)。
