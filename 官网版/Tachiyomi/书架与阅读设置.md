## 一、书架（Library）的基本用法

书架是你收藏的作品列表。往里加作品的动作叫「加书架」：

1. 「浏览」→「来源」→ 点进一个源。
2. 搜索或翻到想看的作品，点开详情页。
3. 点封面旁的「+」加进书架；加第二部作品前会问你放进哪个分类。

已加的作品在书架里点开就能读，阅读进度自动记住，下次打开直接落在没读完的那一章。

## 二、分类管理

作品多了以后靠分类整理：

1. 「更多」→「分类」，新建分类（比如「在读」「养肥中」「已完结」）。
2. 书架里长按作品可多选，批量挪分类、批量删除。
3. 书架顶部的筛选与排序可以按未读数、最近更新、字母序等排；下载了章节的作品也可以单独筛出来。

## 三、阅读模式怎么选

详情页或阅读界面里都能改当前作品的阅读模式：

| 模式 | 适合 |
| --- | --- |
| 从左到右（LTR） | 欧美漫画、横排页面 |
| 从右到左（RTL） | 日式漫画（原版翻页方向） |
| 上下连续滚动 | 一页一屏的传统页漫 |
| 网络条漫（Webtoon） | 韩式长条漫，无页间隙 |

阅读时点屏幕中央唤出菜单，可以调亮度、背景色（黑/灰/白，还有跟随页面颜色的自动贴合）与缩放。这些设置可以「仅此作品」生效，也可以存成全局默认 —— 同一部漫画内不同章节会沿用同一套设定。

## 四、离线下载

1. 详情页里长按章节可多选，点顶部的「下载」按钮批量下载。
2. 「更多」→「下载队列」看进度、暂停或调整顺序。
3. 下载完的章节在书架里直接看，不联网也能读；文件存在首次启动时选的那个文件夹里。
4. 手机里已有的本地文件同样能读能管，导入方法见 [本地漫画怎么导入.md](本地漫画怎么导入.md)。

## 五、章节更新

书架会按你设定的节奏去各源检查新章节：

1. 「更多」→「设置」→「更新」里可以改检查频率、是否只在 Wi-Fi 下更新。
2. 「更新」标签页里是每次检查的结果，从那里直接点新章节开读。
3. 不想追更的作品，在详情页里单本关掉自动更新即可。

## 六、追踪器绑定

如果你在 MyAnimeList、AniList、Kitsu、MangaUpdates、Shikimori 或 Bangumi 有账号，可以在「更多」→「设置」→「追踪」里登录绑定。绑定后在作品详情页的追踪图标里选对应平台，章节进度会自动同步过去。绑定与本地阅读互不影响，用不用看个人习惯。

## 七、隐身模式

不想留阅读痕迹时，在「更多」→「设置」→「隐私」里开「隐身模式」：开启期间的阅读不写入「历史」标签页，也不同步给已绑定的追踪器。它是全局开关，想恢复记录要手动关掉。
