## 一、本地源是什么

除了靠扩展联网取内容，Tachiyomi 还内置一个「本地源（Local source）」，直接读手机存储里你自己的漫画文件 —— 不用装任何扩展，也不联网。入口在「浏览」→「本地源」。

适合的场景：网上下好的整本打包文件、自己扫描整理的图片、从旧设备迁移过来的章节存档。放进本地源的作品和在线作品一样能加书架、分分类、记进度（这些操作见 [书架与阅读设置.md](书架与阅读设置.md)）。

## 二、目录怎么摆

本地源只认一个固定位置：**内部存储根目录下的 `Tachiyomi/local/`**。注意它不是 `eu.kanade.tachiyomi/`（那是应用数据目录），也不是你在首次启动时选的下载文件夹，别混了。

层级是「作品 → 章节 → 页」：

```
内部存储/Tachiyomi/local/
└─ 作品标题/
   ├─ cover.jpg        ← 可选，自定义封面
   ├─ details.json     ← 可选，详情元数据
   ├─ 第1话/           ← 章节文件夹，图片（.jpg/.png 等）直接放里面
   └─ 第2话.cbz        ← 压缩包整包当一个章节
```

要点：

- **作品文件夹名 = 书架里显示的名字**，章节文件夹（或压缩包）名 = 章节列表里的名字。
- 压缩包（ZIP/CBZ 等）**内部不要再套文件夹** —— 包内的目录结构会被忽略，包里所有图片（不管放多深）都会被当成这一章的页面，压缩包文件名就是章节名。
- 文件放在 SD 卡也可以（如 `/storage/xxxx-xxxx/Tachiyomi/local/`），但 Android 11 以后的存储限制会让 SD 卡读取偏慢，介意加载速度就放内部存储。

## 三、支持哪些格式

| 格式 | 支持情况 |
| --- | --- |
| 图片文件夹（.jpg / .png 等） | 支持 |
| ZIP / CBZ | 支持，性能与文件夹最好 |
| RAR / CBR | 支持，但 **RAR5 新格式不支持** |
| EPUB | 支持 |

压缩包如果识别不出来，先用电脑确认它不是 RAR5 格式；RAR/CBR 想省事就直接转成 ZIP/CBZ。

## 四、封面与详情（可选）

- **封面**：在作品文件夹里放一张名为 `cover.jpg` 的图片，本地源列表就会用它当封面。
- **详情**：在作品文件夹里放一个 `details.json`，把作者、简介、标签写进去，首次打开作品（或下拉刷新）时会读到：

```json
{
  "title": "作品标题",
  "author": "作者",
  "artist": "画师",
  "description": "简介",
  "genre": ["标签1", "标签2"],
  "status": "1"
}
```

`status` 常用值：`1` 连载中、`2` 已完结，不写就当未知处理。

- **不想让章节图片混进手机相册**：在 `local/` 文件夹里放一个空的 `.nomedia` 文件即可。

## 五、使用注意

1. **新增章节后要手动刷新**：往目录里加了新章节，本地源不会自动发现，到作品详情页下拉刷新章节列表才会出现。
2. **要给应用存储权限**：首次访问本地文件时系统会弹权限请求，拒绝了就读不到目录。
3. **路径层级不能错**：`local` 的上一层必须叫 `Tachiyomi`，作品夹直接放在 `local` 下 —— 中间多套一层文件夹就会显示为空。
4. 文件夹改名不会丢阅读进度，但作品在书架里会按新名字重新出现；大整理前先做一次备份（见 [备份恢复与换机迁移.md](备份恢复与换机迁移.md)）更稳妥。
5. 文件放好了却显示不出来，按 [常见问题与报错排查.md](常见问题与报错排查.md) 第八节排查；源机制的整体说明在 [扩展插件与源管理.md](扩展插件与源管理.md)。
