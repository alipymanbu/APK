# reWASD 手机版连不上电脑怎么办

> 手机端搜不到电脑、连上又掉线，几乎都是网络环境和电脑端设置这两类原因。本篇按出现概率从高到低列排查清单，每一条都是能直接动手验证的。

## 一、按概率排查：先过这张清单

| 排查项 | 怎么验证 | 怎么处理 |
| --- | --- | --- |
| 电脑端共享没开 | 打开电脑端 Preferences → Servers，看 Enable sharing via local network 是否勾选 | 勾上后点 Apply（最常见原因） |
| 不在同一局域网 | 手机和电脑是否连的同一台路由器；手机别用流量 | 两端连同一 Wi-Fi；电脑插网线也可以 |
| 路由器 AP 隔离 | 手机连的是不是访客网络；两个设备互相 ping 不通 | 关掉访客网络的 AP 隔离，或换主网络 |
| 防火墙拦了 | 电脑能上外网但手机端列表为空 | 给 reWASD 放行防火墙（见下节） |
| 电脑端网络接口选错 | 电脑同时有有线 + 无线 + 虚拟网卡 | Servers 页把 Network interface 改成 ANY |
| VPN / 代理干扰 | 电脑或手机正开着 VPN、加速器 | 断开后再试，虚拟网卡会干扰局域网发现 |
| 版本过旧 | 两端是否都是当前版本 | 都升级到较新版本（以官方页面为准） |
| 偶发抽风 | 以上都对但还是连不上 | 两端都重启：电脑端重开 reWASD，手机端杀掉应用重进 |

## 二、给 reWASD 放行 Windows 防火墙

手机端列表为空、但网络确认没问题，多数是防火墙拦掉了默认端口 `35474` 上的连接：

1. 打开「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」。
2. 点「更改设置」，在列表里找到 reWASD（没有就点「允许其他应用」手动添加）。
3. 把「专用」和「公用」都勾上，确定保存。

改完在手机端重新搜索电脑。

## 三、连上了但频繁掉线

- **信号**：手机离路由器太远时，持续的输入流传输最容易断，先缩短距离验证。
- **频段**：手机连路由器的 **5GHz** 频段。2.4GHz 频段和蓝牙、智能家居挤在同一片频率里，卡的表现不是平均变慢，而是一阵一阵「吞输入」式的尖峰——这是第三方测试普遍给的第一条建议，不是官方口径。
- **电量**：无线设备电量过低时发射功率会下降（第三方测试的普遍结论），表现为一阵一阵的卡顿而不是稳定变慢——手机当手柄玩之前先充电。
- **Transfer 参数**：把手机当手柄用（见[把手机当手柄用.md](把手机当手柄用.md)）时，General settings 里的 Transfer 是数据发送频率，调低一档能明显缓解高负载下的掉帧和断连。
- **省电策略**：部分国产手机会主动冻结后台应用，把 reWASD 加入省电白名单 / 允许后台运行，锁屏就掉线的情况多出在这里。
- **电脑端虚拟设备性能**：手机的输入最终经虚拟手柄发给游戏，虚拟手柄有独立的轮询率档位（Device Performance）；reWASD 9.0 起最高开放到 1000Hz（ultra 档），官方开发者在论坛解释过默认档位是兼顾 Windows 蓝牙栈兼容性的稳妥值——映射后手感「发肉」时可以换个档位对比，以官方帮助文档为准。

## 四、还是不行：重置配对关系

两端的连接状态是记住的，改了设置后有时旧状态会碍事：

1. 电脑端 Servers 页确认 PC Name、端口没被改过。
2. 手机端回到应用首页，按官方帮助里的说法**重新走一遍连接流程**（从首页重新选择电脑），不要依赖上次的旧连接。
3. 电脑端把 reWASD 完全退出再启动，手机端同步重试。

排查顺序走完仍连不上，最后剩下的可能就是两端版本兼容问题——升级电脑端和手机端到最新版再试。装不上最新版时，先用 [下载与安装教程.md](下载与安装教程.md) 里这份网盘资源里的版本把流程跑通，也能覆盖日常使用。
