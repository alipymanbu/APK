# reWASD 手机版与电脑版配对教程

> 手机端的所有功能——应用配置、改映射、把手机当手柄——都建立在「连上电脑」这一步之上。本篇按顺序完成配对：电脑端开共享、手机端连接、确认连上后能看到什么。

## 一、配对前的三个前提

1. **同一局域网**：手机和电脑连同一个 Wi-Fi（电脑插网线也算，只要路由器是同一台）。注意别把手机连到访客网络——不少路由器的访客网络开了 AP 隔离，设备之间互相不可见。
2. **电脑端已安装并正在运行**：手机端找的是「正在运行的 reWASD」，电脑端没开就搜不到。
3. **两端版本都别太旧**：旧版本遇到过新版本改了通信方式的兼容问题，装完连不上先把两端都升级到当前版本再试（以官方页面为准）。

## 二、电脑端：打开本地网络共享

这是最容易漏的一步——电脑端默认不一定开着共享：

1. 打开电脑版 reWASD，进入 **Preferences（首选项）→ Servers（服务器）** 标签页。
2. 勾选 **Enable sharing via local network**（允许通过本地网络共享）。不勾这项，手机端永远发现不了这台电脑。
3. **Network interface（网络接口）**：电脑上有多个网卡（有线 + 无线 + 虚拟网卡）又不确定选哪个时，选 **ANY**，reWASD 会在所有接口上等待连接。
4. **Port（端口）**：默认 `35474`，一般不用改。
5. **PC Name**：改成个好认的名字，手机端列表里显示的就是它。
6. 点 **Apply** 保存。

另外该页还有一个 **UDP server for emulators**（默认端口 `26760`）设置，那是给模拟器转发虚拟手柄数据用的，和手机配对无关，不用管。

## 三、手机端：连接电脑

1. 确认手机 Wi-Fi 和电脑在同一网络。
2. 打开 reWASD 应用，按页面引导搜索电脑——列表里会显示上一步设置的 PC Name。
3. 点选你的电脑，等待连接完成。

连接成功后，手机上会看到两样东西：**电脑版里的配置清单**和**当前连接的设备列表**（手柄、键盘鼠标等）。

## 四、连上之后能做什么

- **应用配置**：选中某份配置、应用到某只手柄，电脑端立即生效——游戏里不用切出来。
- **改映射**：在手机上打开一份配置直接编辑按键指派、Shift 层（Config Editor 功能要求电脑版为 9.2 及以上版本，两端都保持较新才能用，以官方说明为准）。
- **收通知**：手柄电量低、电脑端切换 Slot / Shift 层时手机会收到提醒。

之后想把手机变成手柄、触控板，接着读 [把手机当手柄用.md](把手机当手柄用.md)。如果第三步搜索不到电脑或者连上又掉，直接翻 [连不上电脑怎么办.md](连不上电脑怎么办.md)，按概率从高到低排查。
