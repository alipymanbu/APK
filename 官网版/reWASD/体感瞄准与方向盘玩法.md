# 用手机陀螺仪做体感瞄准和赛车方向盘

> 手机变成手柄之后，还有一层更值的玩法：用手机自带的陀螺仪做体感——Gyro 模式管视角和瞄准，Tilt 模式把手机当方向盘。本篇讲两种模式的差别、映射到游戏的完整路径和校准注意事项。

## 一、前提

1. 手机端已和电脑配对（见[手机与电脑配对教程.md](手机与电脑配对教程.md)），并已建好 Mobile Controller 设备（见[把手机当手柄用.md](把手机当手柄用.md)）。
2. 手机端的 Gamepad 模式里，**Sensor settings** 菜单把 **Gyroscope** 打开——不开这个，电脑端收不到任何体感数据。
3. 本篇的映射操作都在**电脑端**做，涉及的版本能力（陀螺仪映射、校准、Flick Stick）以电脑版 reWASD 的官方帮助文档为准。

## 二、Gyro 模式和 Tilt 模式：选错手感全毁

电脑端配置里点陀螺仪图标时，会让你在两种模式里选一个：

| 对比项 | Gyro 模式 | Tilt 模式 |
| --- | --- | --- |
| 手感 | 动多少转多少，手停画面就停 | 整台设备变成一根"大摇杆"，按倾斜角度持续输出 |
| 回中方式 | 停止转动即回中 | 要把手机摆回原位才回中 |
| 适合 | 视角控制、FPS 体感瞄准 | 赛车、飞行的转向 |
| 类比 | 鼠标 | 摇杆 |

一句话：**瞄准用 Gyro，开车用 Tilt**。两者不能同时生效，切换只需在配置里改模式。

## 三、把体感映射进游戏的完整路径

以「手机当赛车方向盘」为例（官方视频演示过的做法）：

1. 电脑端选中 Mobile Controller 设备，打开或新建一份配置。
2. 点配置里的**陀螺仪图标**，模式切到 **Tilt**。
3. 把转向方向指派给**左摇杆**——游戏的转向输入就走了摇杆通道。
4. 点 **Advanced** 调响应曲线：横轴是你转动的速度，纵轴是输出强度，转向太灵敏就压低曲线前段。
5. **Apply** 保存，进游戏试。

做体感瞄准时同理：模式选 **Gyro**，把 roll / pitch 方向映射到鼠标移动或右摇杆，曲线同样在 Advanced 里调。

## 四、三根轴：roll、pitch、yaw

官方文档沿用了飞机姿态轴的叫法，理解了这三根轴，映射就不会转错方向：

- **roll（滚转）**：手心朝上握持、左右倾斜——Gyro 模式默认用它"看四周"。
- **pitch（俯仰）**：抬头低头——管"看上 / 看下"。
- **yaw（偏航）**：手机平放在桌上水平旋转——Gyro 模式默认它对应 Lean 类映射。

两个实用细节：默认的转向轴（yaw / roll）可以在电脑端设置里对调，习惯不合就换；躺着玩、手机"头朝上"竖着握时，同样的手部动作对应的轴会变，映射不对先检查握持姿势。

## 五、校准：连上后先静置几秒

带陀螺仪的设备（包括手机）连接电脑后会**自动重新校准**——校准基准就是你连接那一刻的姿态。所以连接后把手机平放静置几秒再去拿起来玩，否则之后所有体感都偏。电脑端也提供手动校准入口：设备列表里右键设备图标选 Calibrate（reWASD 5.6 起支持）。

## 六、两个进阶组合

- **Flick Stick + 体感瞄准**：reWASD 5.8 起电脑端支持 Flick Stick（快速甩镜头的摇杆方案），和 Gyro 瞄准是公认的搭配。
- **给没有陀螺仪的实体手柄补体感**：把实体手柄和 Mobile Controller 组成设备组、一起映射到虚拟手柄，游戏里就是一只自带体感的手柄——具体步骤见[把手机当手柄用.md](把手机当手柄用.md)第六节。

体感玩法对传输延迟比按键敏感得多，如果画面跟着手"漂"或迟滞，先按 [连不上电脑怎么办.md](连不上电脑怎么办.md) 第三节把延迟压下去再调曲线。
