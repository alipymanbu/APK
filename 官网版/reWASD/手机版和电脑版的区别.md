# reWASD 手机版和电脑版的区别

> 搜索结果里「reWASD」同时指两个东西：Windows 电脑版的映射软件，和安卓/iOS 的手机端应用。很多人以为装了手机版就能改手机游戏的按键——实际不是。本篇把两边的分工讲清楚，免得装错方向。

## 一、两个应用各自做什么

| 对比项 | 电脑版 reWASD | 手机版 reWASD Mobile |
| --- | --- | --- |
| 平台 | Windows | Android / iOS |
| 角色 | 映射本体，所有映射在这里发生 | 伴侣应用，负责远程管理和变成输入设备 |
| 典型动作 | 给手柄按键指派键盘鼠标键、建组合键、调摇杆死区 | 查看和应用配置、改映射、收通知、把手机当手柄 |
| 单独安装有用吗 | 有用 | 没什么用，必须连上一台装了电脑版的 PC |

一句话：**映射的执行端在电脑**。手机端不重映射你手机里的任何游戏或应用，它只是「远程遥控器」+「一块可自定义的输入面板」。

## 二、手机版能做的事

1. **浏览和应用配置**：连上电脑后能看到电脑版里全部配置（config）清单和已连接设备，在手机上点一下就能把某份配置应用到某只手柄——不用在游戏里 Alt+Tab 出去操作。
2. **改映射**：手机上就能改按键指派、Shift 层，改完即时生效（官方文档把这套功能叫 Config Editor，对两端版本有要求，详见[手机与电脑配对教程.md](手机与电脑配对教程.md)）。
3. **把手机变成输入设备**：通过 Mobile Controller 功能，手机可以变成手柄、触控板或一块 30 键的控制面板，作为电脑的一只「虚拟外设」使用，具体见[把手机当手柄用.md](把手机当手柄用.md)。
4. **收电脑端的通知**：电脑端手柄电量低、切换了 Slot 或 Shift 层时，手机端会收到提醒。

## 三、手机版不能做的事

- **不能重映射手机本机的游戏**。它不会替你改安卓游戏里的虚拟按键布局，也不把实体手柄「转接」给手机游戏用——那些需求要在手机系统或游戏自身的设置里解决。
- **不能脱离电脑独立运行**。所有映射逻辑、虚拟设备都由电脑端的 reWASD 创建和执行，手机端断开连接后只是个空壳界面。
- **不是官方的云服务客户端**。两台设备之间靠同一局域网配对，没有账号漫游这回事。

## 四、授权上的一个差别

电脑版 reWASD 官方提供 7 天全功能试用。手机端本身免费，但其中 Mobile Controller（把手机当手柄）这项功能，官方说明里要求电脑端持有终身授权（lifetime）或正处于试用期内——这是手机端少数会被授权卡住的功能，其余的远程管理功能在电脑版授权有效时都能用。授权政策以官方页面为准。
