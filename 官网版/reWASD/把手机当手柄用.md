# 用 reWASD 把安卓手机当电脑手柄用

> Mobile Controller 是 reWASD 手机端最实的功能：把手机变成电脑眼里的一只手柄、一块触控板或一个 30 键控制面板。本篇讲四种模式怎么选、布局怎么自定义、以及怎么在电脑端给它做映射。

## 一、开用之前的两个前提

1. **先完成配对**：手机端必须连上装着 reWASD 的电脑（见[手机与电脑配对教程.md](手机与电脑配对教程.md)），Mobile Controller 的数据全部发给那台电脑。
2. **授权要求**：官方说明里这项功能要求电脑端持有终身授权，或在 7 天试用期内使用。到期后手机界面还在，但这套功能会被授权卡住，以官方页面为准。

## 二、创建一台「手机手柄」

1. 打开手机端 reWASD，点左上角菜单。
2. 选 **Mobile Controller**。
3. 点 **+** 新建一台设备（可以建多台，每台一套布局）。

创建后，电脑端的设备列表里会同步出现这台 Mobile Controller——游戏会把它当成一只普通的手柄。

## 三、四种模式怎么选

| 模式 | 是什么 | 适合的场景 |
| --- | --- | --- |
| Gamepad | 可自定义布局的手柄：摇杆、扳机、按键、触控板区域，还支持手机自身的陀螺仪和倾斜传感器 | 拿手机当一只完整手柄玩 PC 游戏 |
| Gamepad Touchpad | 全屏触控板，支持双指输入，分模拟 / 数字两种模式，右侧还有一小块可自定义的区域 | 模拟 DS4/DS5 触控板，或当笔记本触控板控制电脑鼠标 |
| Control Pad | 30 个按钮 + 2 根扳机式滑条的网格面板，可整版重排 | 放一套快捷键面板，剪辑、看直播、开会议时一键触发动作 |
| Mouse+Keyboard | 把手机面板变成键鼠输入面 | 手机当无线键盘鼠标用 |

四种模式都在 Mobile Controller 里切换，切到哪种、电脑端看到的设备形态就跟着变。

## 四、自定义布局

以 Gamepad 模式为例，编辑入口有三个：

- **Edit（编辑）**：缩放、删除、重排面板上的按键；删掉的控件按 **+** 找回来。对齐方式有三档——Magnet（磁吸）、Grid（网格）、None（自由摆放）。
- **Sensor settings（传感器）**：开关 **Gyroscope（陀螺仪）** 和 **Rotation Vector（倾斜）**。开了陀螺仪，手机姿态就能映射成视角控制或转向输入——Gyro / Tilt 两种模式怎么选、怎么映射进游戏，单独立了一篇：[体感瞄准与方向盘玩法.md](体感瞄准与方向盘玩法.md)。
- **General settings（通用）**：**Transfer** 参数控制数据发往电脑的频率，卡就调低、跟手就调高；**Haptic feedback** 控制按键振动反馈。

## 五、在电脑端给它做映射

1. 打开电脑版 reWASD，在设备列表选中 Mobile Controller。
2. 新建一个 Game Profile 或选现有配置。
3. 像映射实体手柄一样，把它的每个按键指派到键盘、鼠标或虚拟手柄动作上。
4. 应用配置，回游戏里测试。

## 六、和实体手柄组合：给没有陀螺仪的手柄补上体感

这是 Mobile Controller 一个单独提出来才好用的玩法：你的实体手柄没有陀螺仪，但手机有——

1. 在电脑端把 Mobile Controller 和实体手柄**组成设备组（group）**。
2. 把整组映射到一只虚拟手柄上。
3. 游戏里只会看到一只手柄，它同时接收实体手柄的按键和手机的陀螺仪数据。

同样思路也能把 Control Pad 的 30 键并进实体手柄的配置里，补足实体手柄键位不够的问题。

连上之后如果延迟明显或者频繁掉线，先把 Transfer 调低试试，还不行就按 [连不上电脑怎么办.md](连不上电脑怎么办.md) 排查网络。
