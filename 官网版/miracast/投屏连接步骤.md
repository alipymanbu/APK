# Miracast 手机投屏电视连接步骤

## 一、连接前先核对三件事

官方说明里给出的前提就三条，缺一条都连不上：

1. **电视端支持无线显示**：电视（或外接的电视棒、投屏器）必须支持 Wireless Display / Miracast 功能；
2. **同一个 Wi-Fi**：手机和电视要连在同一个 Wi-Fi 网络下——电视就算插了网线，也应该用无线方式加入同一个网络，搜不到时先把它切到 Wi-Fi 再试；
3. **手机系统达标**：安卓 4.2 及以上，这个标准是系统级投屏能力的起点。

具体怎么判断你的电视和手机算不算「支持」，[设备兼容与系统要求.md](设备兼容与系统要求.md) 里有逐项对照。

## 二、电视端：打开无线显示

不同品牌把这个功能藏在不同的名字下，常见的叫法有：

| 位置 | 常见名称 |
| --- | --- |
| 电视应用列表 | 无线投屏、屏幕镜像、Screen Mirroring |
| 电视设置 → 网络 | 多屏互动、无线显示 |
| 电视设置 → 显示 | 投屏、Cast |

打开之后电视会停在「等待连接」的界面。以小米电视为例，入口在「我的应用 → 无线投屏」，进去后选安卓设备的 Miracast 连接方式，屏幕上出现等待字样即可。你的电视具体叫什么，以电视实际菜单为准。

## 三、手机端：在应用里发起连接

1. 打开 Miracast；
2. 应用会自动扫描当前 Wi-Fi 网络里支持投屏的设备，把能找到的列出来；
3. 点连接按钮，从列表里选中你的电视；
4. 电视端确认连接后，手机画面整屏出现在电视上，包括主屏、应用、照片和视频。

你手机系统自带的投屏入口（比如设置里的「无线显示」）也能连，应用在这里起的作用是把这些入口收拢到一个更直接的界面里，省得你在设置菜单里翻。两者连的是同一个功能，连不上时可以互换着试；怎么选、各适合什么场景，见 [与手机自带投屏的区别.md](与手机自带投屏的区别.md)。

## 四、连上之后

- 投的是**整屏镜像**：你在手机上看到什么，电视上就是什么，声音也走电视出；
- 想让电视只显示某个视频而不暴露整个手机界面，那是推送（DLNA 那类）的用法，镜像模式做不到只投一半屏幕；
- 画面卡不卡、延迟高不高，主要取决于手机和电视离路由器的距离、Wi-Fi 是否拥挤，这类问题的处理见 [连接不上排查与常见问题.md](连接不上排查与常见问题.md)；卡顿拖慢的系统性解决步骤（换 5GHz 频段、热点验证、清理信道占用）单独成篇，见 [投屏卡顿延迟怎么解决.md](投屏卡顿延迟怎么解决.md)。

## 五、断开连接

在手机通知栏找到「正在投屏」的通知点断开，或回到应用里点停止；也可以直接关掉电视端的无线显示。断开后手机恢复正常使用，电视回到原来的界面。
