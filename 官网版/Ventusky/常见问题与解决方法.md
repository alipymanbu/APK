## 一、安装类

| 现象 | 排查 |
| --- | --- |
| 提示「无法安装」 | 先核对安装包 MD5 是否完整（见[下载与安装教程.md](下载与安装教程.md)第二节），不完整就重新下载；再确认手机系统版本满足要求 |
| 卡在「未知来源」 | 系统设置里给文件管理器或浏览器授予「安装未知应用」权限 |
| 安装后闪退 | 重启手机再试；仍闪退则清一下后台重开，或确认存储空间没有满 |

## 二、加载与数据类

- **地图空白或一直转圈**：多半与网络环境有关，换 Wi-Fi / 流量对比试试；雷达、卫星这类实时图层在弱网下加载明显更慢；
- **数据像是旧的**：模型每天更新数次、出图有先后，切换其他模型看是否同一现象；
- **和官方预报对不上**：模型来源与时间口径差异，对照[数据来源与更新频率.md](数据来源与更新频率.md)第四节；
- **数据卡住不动**：有用户反馈把应用从后台划掉重开后恢复，可以先试这一步。

## 三、定位与地点

- **定位不准**：给应用授予位置权限（精确位置），并在手机系统里确认定位服务已开；
- **想默认看某个城市**：搜索并点选该地点即可，下次打开会回到上次的视图位置。

## 四、通知与小组件

- 通知里可设置大风、雷击、降水、气压变化等自定义提醒，按需开关；
- 桌面小组件支持预报、雷达等样式：长按桌面空白处 → 小组件 → 找到 Ventusky 添加；
- 戴 Wear OS 手表的话，手表端可以看预报、雷达与表盘复杂功能。

## 五、订阅类

- **Premium 不生效**：确认登录的是购买时的同一账号，在订阅页点「恢复购买」；
- **换手机后 Premium 没了**：订阅绑定账号不绑定设备，登录原账号即可；
- 仍解决不了，去官方论坛 [my.ventusky.com](https://my.ventusky.com) 的 Premium 版块反馈，官方支持会在帖子里回复。

## 六、耗电与流量

这类反馈在商店评论里比较集中，可以按下面几条控制：

1. **雷达动画最吃电**：高分辨率雷达与持续动画是耗电大头，看完就把应用从后台划掉，别让它整天空闲着跑动画；
2. **后台定位也耗电**：应用商店的披露里写明「应用未打开时也可能使用你的位置」，不需要定位提醒的话，把位置权限改成「仅使用期间」；
3. **流量**：地图数据按需在线加载，刷得越勤流量越多；流量套餐紧张的话，提前在 Wi-Fi 下把要去的地方看一遍；
4. **没有离线模式**：公开资料里没有可离线缓存的地图功能，进山、出海这类没有信号的场景别指望它出数值，提前截图或记下关键预报。
