## 一、免费能用的图层

| 图层 | 内容 |
| --- | --- |
| 温度 | 地表温度，含多个高度层 |
| 体感温度 | 综合湿度与风的影响 |
| 降水量 | 1 小时 / 3 小时 / 累积值 |
| 天气雷达 | 实测降水回波与雷电检测 |
| 卫星 | 云图 |
| 空气污染 | PM2.5、PM10、二氧化氮、二氧化硫、臭氧、一氧化碳、AQI |
| 风 | 地表风场动画流线 |

应用本身无广告。免费图层的具体划分以你手上版本的应用内图层面板为准。

## 二、Premium 解锁的图层

| 类别 | 图层 |
| --- | --- |
| 风 | 各高度层风速（约 16 层）、阵风 |
| 云 | 云量（高 / 中 / 低 / 总量 / 云底）、雾 |
| 气压 | 海平面气压等 |
| 雷暴 | CAPE、风切变、CIN、抬升指数、螺旋度 |
| 海洋 | 浪高、涌浪周期、洋流、潮汐、风暴潮 |
| 湿度 | 各高度层相对湿度、露点 |
| 其他 | 积雪（总量 / 新雪）、冻结高度、能见度 |

以上清单来自官方对各图层组的说明，不同版本可能略有增减，以应用内图层面板实际显示为准。

## 三、订阅入口与生效

- **应用内订阅**：在图层面板里点高级图层时会出现购买引导；
- **网页购买**：[my.ventusky.com](https://my.ventusky.com) 的 Premium 页面；
- 价格与档期会变，以购买页当时显示为准，不在这里写死。有第三方评测（2026-08）提到 iOS 端 Premium 约 4.99 美元/月或 19.99 美元/年，另有一个更高的 Premium+ 档；安卓端价格、档位划分可能不同，购买前以应用内实际页面为准。

订阅后不生效（重装、换机后常见）：先确认登录的是购买时用的同一账号，再到订阅页找「恢复购买」；仍不行可去官方论坛 [my.ventusky.com](https://my.ventusky.com) 的 Premium 版块发帖反馈。

## 四、按用途对号入座

- 日常看天气、判断要不要带伞：免费图层已经覆盖；
- 关心空气质量：免费版已有 PM2.5 等主要指标；
- 户外徒步、骑行、登山看阵风与高空风：需要 Premium 的阵风与多层风场；
- 关注台风、出海、飞行相关：海浪、洋流、雷暴指标都在 Premium 里；
- 还在犹豫要不要订阅：先按[与Windy的区别与选择.md](与Windy的区别与选择.md)确认这个应用适合你，再决定付费。
