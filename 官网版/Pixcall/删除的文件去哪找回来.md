# Pixcall 删除的文件去哪找回来

> 讲清在不同的地方删文件分别会去了哪、怎么恢复、以及为什么「删了还是没空间」。

Pixcall 里的删除分两层：在应用内删的进 Pixcall 废纸篓，在电脑文件夹里删的有一部分会直接消失。本篇讲清各种删法分别去了哪、怎么恢复、怎么才算真正腾出云端空间。

## 一、先弄清你是在哪儿删的

| 删除位置 | 文件去了哪 |
| --- | --- |
| 手机端应用内删除 | 进 Pixcall 废纸篓（Android 1.0.42 起有废纸篓页面） |
| 电脑端应用内删除 | 进 Pixcall 废纸篓，**不进**系统的回收站 / 废纸篓 |
| 在电脑文件夹里删、且该文件还没同步到云端 | 直接删除，不进 Pixcall 废纸篓 |
| 在电脑文件夹里删、且该文件之前已同步到云端 | 进 Pixcall 废纸篓，文件名后加 `-删除备份-`，同步状态为仅云端 |

所以第一步是先回想删除动作发生在哪：**在系统回收站里翻是找不到的**，Pixcall 废纸篓是应用内独立的一份。

## 二、怎么恢复

- 在废纸篓里选中要找回的文件或文件夹，用右键菜单里的恢复即可；
- **有一种情况恢复会失败**：要恢复的文件所在的父文件夹已经被删掉了。这时别反复点恢复，把该文件直接拖到左侧文件目录树里的目标文件夹里就行；
- 手机端也是在废纸篓页面里操作，入口位置以你手机上那一版的界面为准。

## 三、为什么删了还是没腾出空间

废纸篓里的东西**照样占云端容量**：开通云端空间后，多台设备之间的废纸篓内容也会同步，废纸篓内的文件空间也计入你购买的空间容量。

于是「空间不够」的正确处理顺序是：

1. 先把不需要的文件删进废纸篓；
2. 再进废纸篓**彻底删除 / 清空**，这一步之后容量才还给你；
3. 回到上传流程继续传——空间不足时，手机端和网页版都无法再往资源库添加文件。

## 四、彻底删除前要确认的事

- 彻底删除是从电脑上直接删掉，**不会进系统的回收站 / 废纸篓**，删完就找不回来了；
- 清空动作会同步到其它设备，别在一台设备上顺手清、另一台还等着用那份文件；
- 大批量删除之前，先去电脑端确认这批文件的同步状态，别把还在上传中的文件当成冗余的删掉。

删除只是整理的一部分；把留下的素材归好类、之后能搜到，见 [标签文件夹与搜索怎么整理素材.md](标签文件夹与搜索怎么整理素材.md)。删除没有按预期进废纸篓、或者删完两端表现不一致，按 [同步异常与常见问题排查.md](同步异常与常见问题排查.md) 往下排。
