# Pixcall 同步异常与常见问题排查

Pixcall 的问题大多集中在三类：同步没到位、云端空间不够、账号或版本不对。本篇按现象分诊，每类给出先查什么、再动什么，尽量少走弯路。

## 一、先看是哪一类

| 现象 | 最可能的原因 | 先做这一步 |
| --- | --- | --- |
| 手机上少一部分文件 | 那部分在本地资源库里 | 回电脑端确认库的类型 |
| 新传的文件电脑端没有 | 电脑端没运行 / 云端空间满了 | 打开电脑端，再查云端容量 |
| 一直停在传输中 | 应用被切到后台 | 回到应用前台等它传完 |
| 登录直接报错 | 密码错 / 设备超限 / 连接错 | 见 [登录与设备上限怎么处理.md](登录与设备上限怎么处理.md) |
| 命名或含特殊字符的文件传不上去 | 文件名不合法 | 改文件名后重传 |
| 电脑端库打不开 / 缩略图异常 / 闪退 | 资源库文件夹放在了第三方同步网盘里 | 见下面第五节 |

## 二、同步没到位的排查顺序

1. **确认库的类型**：本地资源库的文件不上云，手机端看不到属于正常；只有同步资源库才会在两端出现（判据见 [手机版和电脑版怎么配合用.md](手机版和电脑版怎么配合用.md)）。
2. **确认电脑端在线**：电脑端不在运行的时候，手机上传的文件不会被拉到电脑文件夹里。
3. **等它传完**：同步不是瞬间完成的，文件多、体积大的时候要留出时间。
4. **在电脑端手动催一次**：官方帮助中心说明，Windows 与 macOS 桌面客户端的菜单里有「立即同步」，它会全面比对本地与云端的差异再同步，**不会把所有文件重新上传一遍**，只是要等。另外「重建索引」修的是文件列表与搜索索引，不能代替它。
5. **还不行就看同步状态**：同步资源库里的文件会显示「完全同步 / 上传中 / 下载中 / 同步异常」这类状态，标为异常的文件可以单独处理。

## 三、空间相关的三个坑

- **废纸篓占容量**：删了文件不等于腾出空间，废纸篓里的内容仍然计入云端容量，要清空才算数；
- **空间不足时无法继续添加**：剩余容量小于要传的文件大小时，新文件传不上去，手机端和网页版都是这个规则——处理办法是删文件、清空废纸篓，或者升级容量档位；
- **会员到期不是立刻清空**：官方说明里，云端空间会员到期后，已经在云端的文件会继续在云端保留 100 天；这段时间新文件传不上去，但已有文件仍能同步下来。所以到期后别急着认定文件没了，先把还在云端的下载回本地。

## 四、连接错误与传输中断

- **连接错误**：官方把这一类归因于网络或安全软件拦截。手机上先换个网络（Wi-Fi 与流量互换）再试；电脑端还得看安全软件有没有拦掉 Pixcall 的进程——官方常见问题里专门有一条讲安全软件冲突导致软件打不开、登录卡住，处理办法是把被拦的项设为允许后重启软件。
- **传输被掐断**：切到后台、锁屏都可能让上传中断，官方在版本更新里持续改这块（失败任务重试、返回应用后继续上传）。回到应用前台让它继续，失败的任务按应用内的重试入口再走一次。
- **版本不一致**：官方建议多设备使用 Pixcall 时把各端都更新到较新的版本；新旧版本差太多时，访问资源库可能出问题。

## 五、资源库文件夹不要交给第三方网盘同步

官方的帮助中心在这件事上给的结论很直接：把资源库放在第三方同步网盘里，**极易造成数据库文件损坏**，而且官方把「软件出现无法修复的异常」大多归因于此。资源库文件夹里除了你的文件，还有一份隐藏的系统文件夹存放索引和数据库，网盘客户端在后台改动、冲突覆盖这些文件时就会出事。

- **想多台电脑之间同步**：用官方的云端空间，别拿网盘客户端去同步资源库文件夹；
- **想省这笔钱**：用移动硬盘、NAS 这类外置设备承载资源库文件夹，官方另有一篇专门讲外置设备的注意事项，按它的说明来；
- **已经这么用、并且出现库打不开、缩略图异常、闪退的**：官方 FAQ 里有一整套「数据库文件损坏」的修复流程，涉及替换数据库文件。这套操作会动到库的系统文件，**动手前先把整个资源库文件夹备份一份**，步骤照官方页面走，别凭记忆改。

## 六、还是不行时的两条务实做法

1. **彻底重启客户端**：电脑端从状态栏图标彻底退出再打开（不是关窗口），比反复点界面管用；
2. **核对账号与库**：确认手机、电脑登录的是同一个账号，看的是同一个资源库——这一步能解掉相当一部分「文件不见了」的误报。

文件本身怎么上传、传上去之后怎么归类，见 [手机照片和文件怎么上传到资源库.md](手机照片和文件怎么上传到资源库.md)。
