Pixcall 是一款跨设备的素材管理工具：手机端负责把手机里的图片、视频和各类文件送进云端素材库，电脑端再用资源库把它们整理好，两端实时打通。本篇只解决一件事——把网盘里这份安卓包装进手机、登录成功，并且能看到自己的资源库。

## 一、先核对网盘里这份是哪一版

官方渠道的安卓客户端更新得比较勤，官方下载页上的版本号通常比网盘里这份新（**具体数字以官方下载页当时显示的为准**）；网盘里这份是制作文档时核对过的那一版，版本号对不上是正常的。本文出现的版本号、包名、体积都以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Pixcall |
| 版本号 | 1.0.18 |
| 包名 | `com.pixcall.android` |
| 安装包体积 | 11.01 MB |
| MD5 | `EFEDBD2B010A0D0661F5867917573774` |
| 核对时间 | 2026-09-23 |

三点补充：

- **版本号规则**：移动端是 `1.0.18` 这种形式，桌面端则是 `0.9.x+build` 这种形式，两套序列各走各的，不要拿桌面端的数字去对手机端的版本号。
- **包名别装混**：安卓上判断是不是同一个应用只看包名。上表这个 `com.pixcall.android` 才是官方那份；换了包名的同名应用在系统里就是另一个应用，装不上也覆盖不了。装之前对一眼。
- **系统要求**：官方下载页是按平台区分的（Android、iOS、Windows 10 及以上、macOS 12.0 及以上），**没有标出 Android 的具体最低版本**。所以本文不对你这台手机能不能装下结论——装前看官方下载页或应用商店当时显示的说明。

## 二、装之前要想清楚的一件事

Pixcall 手机版是配合电脑端用的：官方在应用商店的说明里直接写明「手机版主要是配合桌面版的 Pixcall 使用，打通手机和电脑的素材文件同步」。手机端能管理的只有**同步资源库**，**本地资源库**只有电脑端能建，而那类库里的文件不会出现在手机上。如果你在电脑上还没用过 Pixcall，装完手机端一样能登录、也会带出一个同步资源库，但整理这类重活在电脑端更顺手——两边的分工见 [手机版和电脑版怎么配合用.md](手机版和电脑版怎么配合用.md)。

## 三、安装步骤

1. **转存再下载**：打开 [Pixcall 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8438619906c3)，把安装包转存到自己的网盘后再下载。
2. **把包送到手机上**：手机端直接下载最省事；在电脑上下载的话，用数据线或任意传输工具拷进手机存储。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。部分国产定制系统把这一项收在「安全」或「隐私」分类下。
4. **点开 APK 完成安装**：系统提示「应用未经过安全检测」时选择继续安装即可，这是第三方渠道安装包的常规提示。
5. **回装低版本要先卸载**：安卓不允许用低版本安装包覆盖高版本。手机上已经装的 Pixcall 版本号若高于 1.0.18，想换成本文这份就得先卸载旧版，应用内的本地数据会一并清掉。
6. **装完先别急着打开用**：先把下一节的账号和权限过一遍，否则进去大概率看到一个空库。

## 四、首次打开：登录与权限

登录用的是手机号加密码（官方登录页就是这两项）。忘记密码时走登录页上的**重置密码**入口，用手机号重新设一次。首次在移动端登录时，账号会自带一个同步资源库；如果电脑端已经登录过同一账号，手机上看到的就是同一个库。

| 权限 | 用处 | 不给会怎样 |
| --- | --- | --- |
| 照片和视频 / 存储 | 上传手机里的图片、视频 | 选不到要传的内容 |
| 通知 | 上传与同步结果的提醒 | 可以不给，不影响上传本身 |
| 后台运行 / 电池优化 | 让上传和同步在切到后台后继续 | 切走应用可能中断传输，得回前台再试 |

Android 13 之后系统把相册权限拆成了「照片和视频」「音乐和音频」两档，Pixcall 要的是前者。系统若只给你「仅允许访问选中的照片」，那些没被勾选的照片在应用里同样看不到，要改成允许访问全部。

## 五、装完做一次最小验证

1. 登录后确认能看到资源库列表（新账号会有一个同步资源库）；
2. 上传一张手机相册里的图片；
3. 在电脑上打开 Pixcall 桌面客户端，或用浏览器登录 [网页版](https://pixcall.com/)，看这张图有没有出现；
4. 反过来在电脑端给这张图贴个标签或放进某个文件夹，回到手机确认能收到。

第 3 步看不到，通常是电脑端没在运行或者云端空间满了，按 [同步异常与常见问题排查.md](同步异常与常见问题排查.md) 逐项排；登录报错、提示设备数量超限，看 [登录与设备上限怎么处理.md](登录与设备上限怎么处理.md)。后续要换新版或者重装，从本篇头部的安装文件资源里取用即可。
