## 一、先分清是哪种问题

四种现象，原因完全不同，别一上来就重装：

| 现象 | 大概率出在哪 |
| --- | --- |
| 一直转圈、加载慢 | 网络或线路 |
| 画面糊、频繁缓冲 | 清晰度与带宽不匹配 |
| 打不开、白屏、卡在启动页 | 网络不通或应用状态异常 |
| 一闪就退、看一半崩 | 应用本身或手机存储 |

## 二、播放卡：先换线路再降清晰度

播放页里备着多条可切换的线路，卡顿时的正确顺序是：

1. **换线路**。在播放页找到线路/源切换入口换一条，通常立刻见效果——某条线路不通时，等是等不好的。
2. **降清晰度**。线路没问题但还是缓冲，就把清晰度从高清降到标清，先把内容看完，回家 Wi-Fi 下再看高画质。
3. **确认网络本身没问题**。用手机浏览器随便打开一个网页试试；网页都打不开就先修网络，不用在应用里折腾。
4. **错峰**。晚高峰大家都在线时容易挤，换个时间段对比一下，能区分是「你这网络差」还是「现在整体差」。

## 三、白屏、内容出不来

- 退出应用重进一次（从最近任务里划掉再开）。
- 确认没开飞行模式、VPN 类代理开着时先关掉试试。
- 还不行就清理应用缓存：`设置 → 应用 → Lanerc → 存储 → 清除缓存`。**只清缓存，别点「清除数据」**——后者会把本地登录状态一起清掉，需要重新登录。

## 四、闪退、启动就崩

按成本从低到高：

1. **重启手机**再打开。
2. **看存储**：手机可用空间不足 500M 时各种应用都容易崩，先清出空间（缓存管理里的旧缓存是最先该删的）。
3. **重装**：卸载后重新安装。装之前确认收藏与观看记录已登录账号（跟着账号走，见 [注册与入站答题教程.md](注册与入站答题教程.md)），然后从网盘重新下载安装包：[Lanerc 安装文件资源（夸克网盘）](https://pan.quark.cn/s/53a1ea6f57d7)，装完按 [下载与安装教程.md](下载与安装教程.md) 核对 MD5。
4. **版本问题**：一直崩且本版是老版本时，换一个渠道页当时显示的新版本试试——各渠道显示的版本会变（截至 2026-09 已有页面标到 1.0.8），换版本后原安装包的 MD5 不再适用。

## 五、和账号有关的几种情况

- **登录页转圈**：属于第二节的网络问题，按那节处理。
- **找不到入站问答入口**：多半是当前未登录，先登录；流程见 [注册与入站答题教程.md](注册与入站答题教程.md)。
- **换手机后收藏没了**：确认登录的是同一个账号，而不是新注册的空账号。
- **投屏失败**：投屏是另一套链路，按 [投屏与离线缓存教程.md](投屏与离线缓存教程.md) 单独排。

## 六、什么时候该重装、什么时候不用

重装只解决「应用自身文件坏了」这一类问题：闪退、启动崩、清缓存后仍白屏值得试。播放卡、线路不通、投屏连不上这些跟安装包没关系，重装多少遍都没用——照第二节和投屏那篇排。应用本身免费安装；有商店页标注含应用内购买项目，是否收费、收多少以你界面上当时显示的为准。
