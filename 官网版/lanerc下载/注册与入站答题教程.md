## 一、为什么先注册

Lanerc 装完就能翻首页、搜作品，但收藏、追番清单这些要挂在账号上才好管理；而且应用里还有一道「入站问答」，得先有账号才能开。本篇按顺序讲两件事：把账号注册出来，再把入站答题过掉。装应用本身还没做的，先看 [下载与安装教程.md](下载与安装教程.md)。

## 二、注册账号的步骤

1. 打开 Lanerc，点右下角的 **我的**。
2. 点页面上方的 **登录/注册**。
3. 在登录页点 **立即注册**（已经有账号的直接填账号密码登录，不用再走这步）。
4. 按界面要求填写信息——各版本界面要求的字段略有出入，常见的是邮箱、昵称、密码这类基础项，以你手机上看到的为准。
5. 提交后回到登录页登录，「我的」页顶部显示已登录状态即成功。

注册信息里邮箱和密码最要紧：邮箱是找回账号的凭据，密码别和其他平台共用一套。

## 三、入站问答是什么

「入站问答」是应用内的准入环节：登录之后才能开，要在规定时间内答对足够数量的题才算通过。没通过之前，账号仍停在未入站状态，与入站相关的入口会受限制。

多个攻略站对流程的描述一致，可以照下面走。

## 四、答题怎么开、怎么过

1. 用已登录的账号进 **我的**，点 **入站问答**。
2. 点下方的 **开始答题**。
3. 弹出提示框时点 **确定**，计时开始。
4. 在规定时间内把题答完，答对数量达到要求即提示入站成功。

几点实操提醒：

- **先看清计时规则再点开始**：弹窗里会说明时限与达标题数，心里没底就别急着点，答到一半超时比晚点开始更亏。
- **拿不准的题先放**：能跳过的先跳过，把确定的题做完再回头补，别在一道题上耗掉整段时间。
- **答不过就重来**：界面允许的情况下可以再开一轮，重新按第四节的步骤走即可。
- **换设备不影响**：入站状态挂在账号上，重新登录后仍在。

## 五、登录后能带走什么

收藏与观看记录跟着账号走——你换手机登录同一个账号，追番清单和上次看到哪一集还能接上（各渠道页也是这么描述的，具体同步范围以你实际用到的为准）。这也是注册时认真填邮箱的理由：账号丢了，这些就都没了。

## 六、常见疑问

| 你遇到的情况 | 怎么处理 |
| --- | --- |
| 登录页一直转圈 | 先按 [播放卡顿与闪退排查.md](播放卡顿与闪退排查.md) 确认网络能正常访问，再退回重进一次 |
| 找不到「入站问答」入口 | 确认当前是已登录状态；未登录时这个入口不出现 |
| 答题中途退出 | 计时不会等你，回到第四节重新开一轮即可 |
| 换了手机 | 用同一个账号登录，收藏与记录仍在 |
