## 一、为什么先注册

Lanerc 装完就能翻首页、搜作品，但收藏、追番清单这些要挂在账号上才好管理；而且应用里还有一道「入站问答」，得先有账号才能开。本篇按顺序讲两件事：把账号注册出来，再把入站答题过掉。装应用本身还没做的，先看 [下载与安装教程.md](下载与安装教程.md)。

## 二、注册账号的步骤

1. 打开 Lanerc，点右下角的 **我的**。
2. 点页面上方的 **登录/注册**。
3. 在登录页点 **立即注册**（已经有账号的直接填账号密码登录，不用再走这步）。
4. 按界面要求填写信息。多个渠道页的注册截图显示要填的是**邮箱、昵称、QQ、密码**这四项，你手机上看到的字段以实际为准（没有 QQ 那栏就忽略）。
5. 提交后回到登录页登录，「我的」页顶部显示已登录状态即成功；有渠道页提到注册完会自动登录，没自动登就手动进「我的」登一次。

注册信息里邮箱和密码最要紧：邮箱是找回账号的凭据，密码别和其他平台共用一套。

## 三、入站问答是什么

「入站问答」是应用内的准入环节：登录之后才能开，要在规定时间内答对足够数量的题才算通过。没通过之前，账号仍停在未入站状态。

**它卡的是互动权限**：多个攻略站的说法一致——评论区发言、弹幕这类互动功能要先过入站问答才解锁。也就是说，只看番不发弹幕的话，这一关可以往后放；想在评论区说话，就必须过。

## 四、答题怎么开、怎么过

1. 用已登录的账号进 **我的**，点 **入站问答**。
2. 点下方的 **开始答题**。
3. 弹出提示框时点 **确定**，计时开始。
4. 在规定时间内把题答完，答对数量达到要求即提示入站成功。

几点实操提醒：

- **先看清计时规则再点开始**：弹窗里会说明时限与达标题数，心里没底就别急着点，答到一半超时比晚点开始更亏。
- **拿不准的题先放**：能跳过的先跳过，把确定的题做完再回头补，别在一道题上耗掉整段时间。
- **答不过就重来**：界面允许的情况下可以再开一轮，重新按第四节的步骤走即可。
- **换设备不影响**：入站状态挂在账号上，重新登录后仍在。

## 五、题目都考什么、怎么准备

按各攻略站汇总的题库，题目分三类：

| 题型 | 考什么 | 举例（各站题库中反复出现的） |
| --- | --- | --- |
| 剧情细节 | 某部作品里某角色做了什么、说了什么 | 「吉良吉影的人设是什么」→ 一个普通的上班族 |
| 作品杂学 | 台词出处、设定、数字、声优 | 「《碧蓝之海》里乌龙茶的配方」→ 90% 伏特加 + 10% 威士忌 |
| 社区规范 | 看到烂片吐槽、有人骂战时你该怎么做 | 这类题的答案一律偏向「不攻击他人」 |

实际开考时的几个要点：

- **题目随机抽**，题库很大，你未必抽到攻略站列的原题——背答案用处有限，**按常识和「社区礼仪」的方向选**更稳。
- **覆盖面是二次元老番常识**：火影、柯南、巨人这类国民作的细节题占比高，平常看得多的占便宜。
- **限时是真限制**：拿不准的先跳过，把能确定的做完再回头（见第四节）。
- 各站题库是玩家自己整理的，**题目与答案都可能与你手机上实际抽到的不一致**，遇到没见过的题别慌，按剧情常识选。

## 六、登录后能带走什么

收藏与观看记录跟着账号走——你换手机登录同一个账号，追番清单和上次看到哪一集还能接上（各渠道页也是这么描述的，具体同步范围以你实际用到的为准）。这也是注册时认真填邮箱的理由：账号丢了，这些就都没了。

## 七、常见疑问

| 你遇到的情况 | 怎么处理 |
| --- | --- |
| 登录页一直转圈 | 先按 [播放卡顿与闪退排查.md](播放卡顿与闪退排查.md) 确认网络能正常访问，再退回重进一次 |
| 找不到「入站问答」入口 | 确认当前是已登录状态；未登录时这个入口不出现 |
| 答题中途退出 | 计时不会等你，回到第四节重新开一轮即可 |
| 换了手机 | 用同一个账号登录，收藏与记录仍在 |
