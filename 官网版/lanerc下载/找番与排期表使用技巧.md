## 一、本篇讲什么

打开 Lanerc 之后，真正决定你找不找得到想看的那一部的，是首页那四个分区、顶部搜索框和底部的排期表。本篇按你实际的操作顺序讲：怎么翻、怎么搜、怎么按天盯更新、怎么把作品收进自己的清单。账号还没注册先看 [注册与入站答题教程.md](注册与入站答题教程.md)。

## 二、界面先认清

底部固定四个入口：

| 入口 | 你来这里干什么 |
| --- | --- |
| 首页 | 翻分区、搜作品、看推荐位 |
| 排期表 | 按日期看今天有哪些番更新 |
| 排行榜 | 看当前热度高的作品 |
| 我的 | 登录、入站答题、看收藏与记录 |

首页顶部还有一排分区标签：**精选 / 日漫 / 剧场版 / 经典番剧**，点哪个就切到哪个列表。

## 三、四个分区各适合什么场景

- **精选**：懒得挑时从这进。上面是轮播推荐位，往下是「热门新番」这类分组，适合随便逛。
- **日漫**：当季连载的日漫按列表排，卡片上直接写着状态，点进去选集就能看。
- **剧场版**：电影版、剧场版集中在这里，卡片会标「已完结 | 共 N 集」，一次看完不用追更。
- **经典番剧**：老番全集，适合补童年那几部——列表里能看到「已完结 | 共 N 话」，长篇几百话的也标着总话数，心里先有个数再点进去。

卡片上除了封面和标题，还有两行有用信息：**状态**（连载中 / 已完结 + 总集数）和**题材标签**（奇幻、战斗、恋爱、校园这类）。拿不准剧情对不对胃口，先看标签再点，省得点进去发现不是这一路。

## 四、搜索怎么搜得准

1. 点首页顶部的搜索框（提示语是「今天你想看些什么？」）。
2. 输入作品名。中文原名、译名都能试，译名搜不到就换原名。
3. 结果通常是整系列一起出来（比如搜一部作品会连它的各季、剧场版一起列出），看清标题和年份再点，别点错季。

搜索适合你已经知道要看什么；不知道看什么就用上面的分区翻，或者去排期表按更新时间挑。

## 五、点进详情页与播放页之后

详情页是作品的落脚点，先看这几项再点播放：

- **简介与选集列表**：确认是哪一部、共几集、更新到哪了。
- **年份与题材筛选**（剧场版区尤其好用）：可以按年份、按题材筛，还能按时间或评分排序——找「某一年的剧场版」时比一页页翻快得多。
- **状态标签**：连载中还是已完结、总集数多少，决定你是追还是补。

进了播放页，你会用到这些开关（不同版本位置略有出入，认字不认位置）：

| 你想要的 | 找什么 |
| --- | --- |
| 快进补番 | 倍速播放 |
| 不想看弹幕 | 弹幕开关，一键收起 |
| 画面发虚、想更清楚 | 画质/清晰度选项，另有超分画质增强的开关，开了发虚就关掉 |
| 换一条线路 | 换源/线路切换，卡顿时先干这个 |
| 存到本地 | 缓存/下载，详见 [投屏与离线缓存教程.md](投屏与离线缓存教程.md) |
| 放到电视上 | 右上角 TV 图标，同见 [投屏与离线缓存教程.md](投屏与离线缓存教程.md) |
| 想免掉中途的广告 | 详情页里的激励视频入口，见 [免广告时长领取方法.md](免广告时长领取方法.md) |

评论与弹幕发言是另一回事：那要先过入站问答，流程在 [注册与入站答题教程.md](注册与入站答题教程.md)。

## 六、排期表怎么看

排期表按日期列出当天更新的作品，是追更时最省事的入口：你追的那几部哪天更，打开对照一眼就知道，不用挨个进详情页刷新。习惯做法是每天固定看一次，把当天更的补完，避免一周堆到一起。有渠道页提到排期表还能设更新提醒，界面上有没有这个开关以你看到的为准。

## 七、排行榜适合什么用

排行榜按当前热度排，适合两种情况：新坑没处找——从榜上看大家都在看什么；以及判断一部冷门作值不值得开——榜单长期在的通常更新也稳。它只反映热度，不等于合你口味，最终还是看题材标签。

## 八、收藏与追番

看到想追的，进作品详情页把它加进收藏 / 追番清单，之后在 **我的** 里集中查看，接着上次的进度看。收藏跟着账号走（前提是已登录），换手机、重装应用后重新登录就能拿回来——所以先按 [注册与入站答题教程.md](注册与入站答题教程.md) 把账号弄好再开始追，比中途补注册省事。

出门前想在路上看，先把要补的几集缓存下来，做法在 [投屏与离线缓存教程.md](投屏与离线缓存教程.md)。
