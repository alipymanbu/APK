## 一、这是个什么应用

Lanerc 是一款安卓端的动漫观看应用：你打开就能按题材翻番剧、剧场版和经典老番，也能搜具体作品、看当天更新的排期，追的进度记在账号里。有渠道页称它承接了 omofun 的番剧资源库——如果你是从那边过来的，两边的使用习惯是接得上的。装它只需要一个 APK，本篇就把这件事做完——后面注册和入站答题在 [注册与入站答题教程.md](注册与入站答题教程.md)。

- 本地记录没有标注最低安卓版本；不同渠道页的标注不一（Android 4.0+ 与 4.3+ 都见过），你手机能否装上以实际安装结果为准。

## 四、下载与安装步骤

1. 点下面的链接进入网盘，把 `lanerc下载_v1.0.6.apk` 下载到手机（或先下到电脑再传过去）：[Lanerc 安装文件资源（夸克网盘）](https://pan.quark.cn/s/53a1ea6f57d7)
2. 手机上首次安装 APK 时，系统会要求你允许「安装未知来源应用」。到 `设置 → 安全`（或 `设置 → 应用安装`）里找到来源应用（浏览器或文件管理器），逐个打开授权；不同品牌手机路径略有差别，按提示找即可。
3. 点开下载好的 APK → 安装 → 等进度走完。
4. 装完先打开一次，能进到首页（顶部有搜索框、底部有「首页 / 排期表 / 排行榜 / 我的」四个入口）就说明装成功了，接着按 [注册与入站答题教程.md](注册与入站答题教程.md) 把账号注册好。

## 五、装不上、装完打不开怎么办

按出现概率从高到低试：

1. **提示解析包出错 / 安装包损坏** —— 基本是下载不完整，回到网盘重新下载；下完先按第二节的方法核对 MD5。
2. **提示与已有应用冲突 / 签名不一致** —— 手机上装过来源不同的同款应用。先卸载旧版再装这份；你的收藏和观看记录跟着账号走，重新登录后仍在。
3. **提示存储空间不足** —— 清出空间再装，别只删安装包。
4. **装完一闪就退** —— 先重启手机再打开；仍闪退时卸载重装一次；再不行按 [播放卡顿与闪退排查.md](播放卡顿与闪退排查.md) 里的步骤走一遍。
5. **首页一片空白、封面全不出** —— 先确认网络能正常打开别的网页，再退出应用重进一次；长期不出图多为网络到内容服务器那一段不通，换个网络（比如从流量切到家里 Wi-Fi）再试。

## 六、要不要追最新版

各下载渠道显示的版本会比这份新：截至 2026-09，已有渠道页标到 1.0.8。本页这份是本地记录于 2026-09-21 的 1.0.6，装的就是它；想升级时，对照你信任的渠道页面看当时显示的版本号即可，升完后第二节的 MD5 就不再适用了。

升级时三个来自渠道页的提醒（均为单一来源，以你实际安装结果为准）：

- **从 1.0.3 升级可能不覆盖旧版**：装完桌面上会多出一个新图标，两个图标并存——认包名 `com.clggjv.xcjfmd.ffo` 是同一个应用，留下新的那个即可，别急着把「旧的」删掉。
- **升到 1.0.7 之后还有 1.0.8**：有渠道页的更新日志写着 1.0.7 之后又推了 1.0.8，你要升级就直接拿渠道页当时提供的那个包。
- **升级前先登录**：收藏与观看记录跟着账号走，登录态在，升完打开还是那些内容（见 [注册与入站答题教程.md](注册与入站答题教程.md)）。
