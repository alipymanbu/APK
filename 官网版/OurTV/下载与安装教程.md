## 一、动手前先确认三件事

1. **设备形态**：开发者的发布说明里，OurTV 分**手机版与电视版两套安装包**（以文件名中的 androidphone / androidtv 标记区分，并提醒勿装错版本）；不过第三方渠道流传时两种形态常被打包成同名的包，本文这套安装包按第三方渠道整理、界面为手机竖屏形态。装手机直接装；装到电视上如果发现交互对不上遥控器（比如只能触屏点按），换一个标注电视版的安装包再装。
2. **有没有装央视频**：OurTV 的包名与央视频完全相同，两者在同一台设备上只能留一个。安装前先去「设置 → 应用管理」看一眼，装了央视频就要先卸载它，否则安装会失败或被覆盖。原因和切换方法单独写在[不能与央视频同时安装.md](不能与央视频同时安装.md)里。
3. **版本基准**：本套文档以这份安装包的实测信息为准 —— 版本 3.0.0.10725、体积 26.65M、MD5 `EB8E717ED4CA0A715CE30D4BDE79D055`（2026-09-23 核对）。网上能搜到更高的版本号，各站点标注不一；界面与功能细节不同版本可能略有差异，以你实际装到的版本为准。

## 二、拿到安装文件

从 [OurTV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bcfc027cb768) 打开分享页，把里面的 APK 文件下载下来：

- **装手机**：直接用手机浏览器打开分享链接，下载到手机存储即可。
- **装电视**：先用电脑下载 APK，再拷进 U 盘（下一步讲怎么装）。

下载完如果文件名后缀不是 `.apk`（个别浏览器会改成别的名字），手动把后缀改回 `.apk` 再安装。

## 三、手机安装步骤

1. 打开系统「设置」，找到「安全」或「应用管理」里的**允许安装未知来源应用**开关（不同品牌叫法不同，如「安装未知应用」「未知来源」），给浏览器或文件管理器授权。
2. 打开文件管理器，找到刚下载的 APK，点击安装。
3. 系统提示「此应用与已安装应用冲突」之类的话，说明设备上装着央视频 —— 先卸载央视频再装，详见[不能与央视频同时安装.md](不能与央视频同时安装.md)。
4. 装完桌面会出现 OurTV 图标，打开即是直播画面，全程不需要注册或登录账号。

想核对安装包是否完整，可以比对 MD5：`EB8E717ED4CA0A715CE30D4BDE79D055`（26.65M）。对不上就重新下载一次再装。

## 四、装到电视或盒子上

1. 电脑下载 APK，拷进一个格式为 FAT32 或 exFAT 的 U 盘。
2. U 盘插到电视或盒子的 USB 口。
3. 打开电视自带的**文件管理 / 媒体中心**，找到 U 盘里的 APK，遥控器按 OK 开始安装。
4. 如果电视上没有文件管理器，先在电视上装任意一个文件管理类应用，再借它打开 U 盘。
5. 部分品牌电视会拦截 U 盘安装：去「设置 → 账号与安全」（或「安全」）里打开「允许安装未知来源应用」或「USB 安装」后再试。
6. 熟悉 ADB 的用户也可以走命令安装（电视需先开启开发者调试模式），开发者说明里给出的命令为 `adb install -r -f xxx.apk`。

装完第一次打开，按遥控器方向键就能唤出选台菜单，具体操作见[频道分组与换台操作.md](频道分组与换台操作.md)。

## 五、装不上或装完打不开

按现象先自查一遍：

| 现象 | 先查什么 |
| --- | --- |
| 提示安装包解析失败 | 文件没下完整或后缀被改，重新下载并比对 MD5 |
| 提示与应用冲突 | 卸载央视频再装（见[不能与央视频同时安装.md](不能与央视频同时安装.md)） |
| 电视提示禁止安装 | 打开「未知来源 / USB 安装」开关（见上文第四节第 5 步） |
| 装完打开就闪退或转圈 | 多半是网络问题，见[播放问题排查.md](播放问题排查.md) |

安卓版本过低的旧设备（安装包信息标注需安卓 5.2 以上）可能装不上或运行异常，这类情况只能换设备解决。
