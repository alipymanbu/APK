## 一、哪些频道有回看

回看挂在**节目单（EPG）**上：有回看能力的频道，节目单里会出现「回看」字样，没有字样的频道就没有回看。想进回看，先在选台菜单里调出该频道的节目单再看有没有标识（菜单怎么唤出见[频道分组与换台操作.md](频道分组与换台操作.md)）。

默认情况下只有部分频道带这个标识 —— 央视、卫视、港澳三组里也是参差的，扩展组多数频道连节目单都没有。

## 二、为什么你的回看是锁着的

开发者发布的项目说明里写明了这套机制（以下均为该说明与第三方站点转述的问答口径，非本文实测）：

- **直播本身完全开放**，回看属于「援助回馈」性质的功能：向开发者援助后开放**部分节目**的回看。
- 电视端 3.2.0 之后的版本，开发者说明的流程是：援助后把转账截图发给开发者；在电视端设置页把焦点移到「援助标识码」上，2 秒内快速点击 7 次，会出现二维码，拍照发给开发者；等大约 5 分钟生效。
- 第三方转述的问答里提到的金额为 39 元，援助渠道有电报与微信两种说法。金额、渠道、流程都可能随版本变化，**以你设置页里的实际提示为准**。

要注意两点事实：一是这个功能由开发者单方面定义和开启，没有公开的独立说明文档；二是开发者在项目说明里注明「本项目可能随时终止」。要不要为此付费，把这两点都算进去再决定。

## 三、怎么确认生效了

按转述的问答口径：

1. 进设置页看提示，出现「回看功能已放开」之类字样即已生效；设置页里原来的赞赏二维码消失也是生效标志。
2. 没生效先等 5 分钟以内的时间，再不行重启应用、重启电视。
3. 生效后重新打开频道节目单，带能力的频道会出现「回看」标识；仍然没有标识的频道就是不在开放范围内，不是操作问题。

## 四、回看中怎么操作（电视端）

以开发者说明的操作教程为准：

| 动作 | 操作 |
| --- | --- |
| 进入回看 | 在节目单里选中带「回看」字样的节目，按 OK |
| 快退 / 快进 | 回看时按左键 / 右键 |
| 唤出菜单 | 回看中按上下键 |
| 退出回看 | 四选一：菜单里选中「正在回看」按 OK 回到直播；连按两次返回键；直接换其他频道；快进到最新直播画面 |

回看时屏幕右上角会固定显示「正在回看」标识，看到它就说明当前在回看状态、不是直播。

## 五、顺带说一句「护眼提醒」

不少用户把观看一段时间后弹出的**护眼提醒**当成广告（见[播放问题排查.md](播放问题排查.md)第五节）。按开发者说明，这个提醒里带的是援助相关的二维码，走完第二节的流程后二维码会消失，但提醒本身是否完全不再弹出，以你装到的版本实际表现为准。
