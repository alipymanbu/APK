## 一、频道分五个过滤组

选台菜单里有一个「过滤器」，把频道分成五组，找频道时先选组再选台，比在长列表里翻快得多：

| 分组 | 里面是什么 |
| --- | --- |
| 全部 | 所有频道的完整列表 |
| CCTV | 央视各频道（综合、新闻、财经等核心频道都在这里） |
| 卫视 | 全国省级卫视，如湖南卫视、东方卫视等 |
| 港澳 | 凤凰卫视资讯台、凤凰卫视中文台、凤凰卫视香港台、TVB 翡翠台等港澳地区频道 |
| 扩展 | 不稳定的补充来源收在这里，频道数量随网络连通性增减，仅部分频道有节目单 |

前四组的频道基本固定；**扩展组是「流动」的** —— 某天多几个、过几天少几个都正常，转述的开发者问答里提到会优先收录来源稳定的频道。

## 二、手机上怎么操作

1. **唤出菜单**：播放时点一下屏幕，频道列表和菜单会出现。
2. **换台**：在频道目录里上下滑动找台，点一下即切换；也可以直接切过滤器分组缩小范围。
3. **调清晰度**：进设置切换清晰度档位。设置入口的位置各版本不统一 —— 第三方教程里有的写右下角设置图标，有的写左上角设置入口，两个都点一下试试，以你装到的界面为准。
4. 菜单不操作几秒后会自动收起，不影响观看。

## 三、电视上怎么用遥控器

1. **唤出选台菜单**：按上下左右任意方向键；菜单 10 秒无操作自动消失，按返回键立即消失。
2. **选组选台**：在菜单里移动光标到「过滤器」选分组（全部 / CCTV / 卫视 / 港澳 / 扩展），再选具体频道，按 OK 确认。
3. **调清晰度**：按**菜单键**（部分遥控器标注为 MENU）唤出设置页面，在里面切换清晰度。
4. 菜单收起后画面自动全屏，不挡节目。

手机与电视的功能是对应的，差别只在交互方式：触屏点按 ≈ 光标移动加 OK，右下角设置 ≈ 遥控器菜单键。

## 四、清晰度档位

清晰度分**高清、超清、蓝光**几档（不同频道提供的最高档位不同，以频道实际菜单为准）。画面卡顿时先降一档再观察，比反复换台有效。

## 五、节目单与回看入口

- 频道的节目单（EPG）能看当前和接下来的节目；扩展组只有部分频道带节目单。
- 有回看能力的频道，节目单里会出现「回看」字样，按提示进入即可回看已播内容；为什么很多频道没有回看、怎么开启，单独写在[回看功能怎么开启.md](回看功能怎么开启.md)里。

## 六、切换与自定义直播源

多个第三方教程提到 OurTV 支持**切换 / 自定义直播源**（自己添加播放线路）：手机端的入口在首页左上角设置里，进去后可切换直播源。这个入口随版本变化，装好后进设置页翻一眼即可确认当前版本给不给；添加直播源的具体格式没有公开的官方说明，以设置页内的实际选项为准。

**开机自动启动**：第三方整理提到电视版支持在设置里开启开机自启动（开机直接进直播画面），同样以你设备上的设置页显示为准。
