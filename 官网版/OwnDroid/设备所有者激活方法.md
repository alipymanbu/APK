## 一、先明白你在激活什么

安卓给「设备所有者」这个角色的权限远高于普通应用：冻结与隐藏应用、禁止卸载、管控相机与截屏、限制短信电话、管理多用户，都建立在这个身份上。**没有激活，OwnDroid 里的功能列表再多也点不动**，所以先激活，再看[管控功能与实操场景.md](管控功能与实操场景.md)。

两种主流工作模式：

| 模式 | 适合 | 特点 |
| --- | --- | --- |
| 设备所有者（Device Owner） | 管自己这台手机的整机 | 官方推荐，权限最全，但激活门槛高（见下文前提清理），且**一台手机只能有一个** |
| 工作资料 / 配置文件所有者 | 只想隔出一个小号空间 | 激活简单，但管不了整机 |

下文以设备所有者为主线。注意：设置成设备所有者后，多数系统不允许再创建工作资料（这是系统限制，不是故障，解法见[常见问题与注意事项.md](常见问题与注意事项.md)），想同时用两个模式的话想清楚再选。

## 二、激活前必须先做的清理

激活命令执行失败，九成是设备「不够干净」。安卓规定：设备上有账号、有多个用户、或已存在设备所有者时，拒绝设置新的设备所有者。所以先做三件事：

1. **删掉或冻结带账号的应用**：进「设置 → 账号 / 密码与账号」，把列表里同步着账号的应用记下来（邮箱、云服务、游戏渠道服等常见）。要么删掉这些账号，要么先用冻结类手段把对应应用停用。账号删了等激活完可以再加回来。
2. **删掉多余用户**：进「设置 → 系统 → 多用户」，把工作资料、私密空间、应用分身（微信/QQ 分身常挂在「分身」入口下）都删掉。主用户之外一个不留。
3. **确认没有别的设备所有者**：之前激活过类似管理工具（含公司 MDM、防丢类应用）的，先在那个工具里停用它的设备所有者身份，否则会报「device owner is already set」。

这三条做完，激活就只差一条命令或一次点击。

## 三、四条激活路径，按你的情况选

### 路径 A：ADB 命令（没有 root 的普通手机首选）

需要一台电脑和一根数据线。

1. 手机进「设置 → 关于手机」，连点「版本号」7 次打开开发者模式。
2. 进「设置 → 系统 → 开发者选项」，打开「USB 调试」。
3. 电脑上装好 adb 工具（Android 官方 platform-tools 即可），手机连电脑，弹窗选「允许 USB 调试」。
4. 电脑命令行执行 `adb devices`，确认列表里有你的设备。
5. 执行激活命令：

   ```bash
   adb shell dpm set-device-owner com.bintianqi.owndroid/.Receiver
   ```

6. 看到成功提示后，打开 OwnDroid 确认已激活。之后数据线随时可以拔，USB 调试也可以关掉 —— 激活是一次性的，不需要常驻。

### 路径 B：Shizuku

设备上已经在跑 Shizuku 的，打开 OwnDroid，在激活入口选 Shizuku 方式授权即可，全程在手机上完成，不用电脑。**还没装 Shizuku 的**，从装到配对到授权的完整分步操作见[激活不用电脑的办法.md](激活不用电脑的办法.md) —— Android 11 及以上的手机不连电脑也能激活，走的就是这条路。

### 路径 C：Dhizuku

已经在用 Dhizuku 托管设备所有者权限的设备，选 Dhizuku 方式激活。适合不想把设备所有者直接交给单个应用的玩法；Dhizuku 本身的准备同样见[激活不用电脑的办法.md](激活不用电脑的办法.md)的第四节。

### 路径 D：Root

有 root 权限的，直接在应用内选 Root 激活，或在 root 授权的命令行里执行：

```bash
dpm set-device-owner com.bintianqi.owndroid/.Receiver
```

## 四、激活报错对照表

报错信息对号入座：

| 报错（关键词） | 原因 | 解法 |
| --- | --- | --- |
| `Not allowed to set the device owner because there are already some accounts on the device` | 设备上还挂着账号 | 回到第二节第 1 条，删账号或冻结持有账号的应用 |
| `Not allowed to set the device owner because there are already several users on the device` | 还有其他用户 | 删掉工作资料、私密空间、应用分身等所有次要用户 |
| `Trying to set the device owner (com.bintianqi.owndroid/.Receiver), but device owner (xxx) is already set` | 已有别的设备所有者 | 先在原工具里停用它的设备所有者，一台设备只允许一个 |
| `SecurityException: Neither user 2000 nor current process has android.permission.MANAGE_DEVICE_ADMINS`（MIUI / HyperOS） | 小米系统拦了 adb 的设备管理操作 | 开发者选项里打开「USB 调试（安全设置）」（需登录小米账号），或改在 root 命令行执行 |
| `IllegalStateException: Unexpected @ProvisioningPreCondition`（ColorOS） | 系统签名校验拦截 | 换用官方 GitHub Releases 里的 testkey 版本，功能无区别 |
| `user limit reached`（三星） | 三星系统限制多用户能力 | 官方说明暂无解法，这类机型走不通设备所有者这条路 |

## 五、激活后想反悔：怎么停用

设备所有者身份下的应用**不能直接卸载**（系统会拒绝），必须先停用：

1. 打开 OwnDroid，进入设备所有者信息页（界面上盾牌样式的图标入口，7.0 里在右上角）。
2. 右上角三点菜单里选「停用 / Deactivate」，确认后设备所有者身份解除。
3. 之后就能像普通应用一样卸载或覆盖升级了。

停用前把你自己设置的管控项过一遍 —— 你设过「禁止卸载」「禁止安装应用」这类限制的，先解除，免得停用后还要找别的路子收拾。具体的日常使用坑都收在[常见问题与注意事项.md](常见问题与注意事项.md)。
