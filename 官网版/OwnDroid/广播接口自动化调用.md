# OwnDroid 广播接口自动化调用

> 本篇讲怎么让外部工具通过广播指令调用 OwnDroid 的管控能力：在应用里启用 API、设置密钥，然后按固定格式发送广播。适合会写点自动化脚本、想批量或定时执行管控动作的人；纯手动点界面的用不到这篇。

## 一、这套接口能干什么

OwnDroid 内置一套基于广播（broadcast）的对外接口：你在应用设置里启用 API 并设定密钥后，任何能发广播的东西 —— adb 命令、root shell、Tasker 类自动化应用、你自己的脚本 —— 都能带着密钥发指令，让 OwnDroid 执行隐藏应用、挂起应用、阻止卸载、锁屏这类操作。官方项目的说明里把这列为「高级用户」功能。

两个前提：

- **OwnDroid 已激活**（见[设备所有者激活方法.md](设备所有者激活方法.md)）。接口是借激活身份的权限干活的，没激活时指令发了也不生效。
- 密钥机制：OwnDroid 只执行「API 已启用 + 密钥对得上」的指令，两个条件缺一个都会被拒。

## 二、第一步：在应用里启用 API

打开 OwnDroid 的设置页，找到 API 相关开关启用，并设置一个密钥。两点建议：

- 密钥会明文出现在你发出的每条指令里，**别设短密码** —— 长一些的随机字符串更合适；
- 密钥设好后记下来，指令里要用。

## 三、第二步：按格式发广播

官方文档给的广播格式如下（以隐藏应用为例）：

```bash
am broadcast -a com.bintianqi.owndroid.action.HIDE \
  -n com.bintianqi.owndroid/.ApiReceiver \
  --es key 你的密钥 \
  --es package 目标应用的包名
```

各字段含义：

| 字段 | 作用 | 说明 |
| --- | --- | --- |
| `-a` | 指令动作名 | 决定执行什么操作，如 `HIDE`、`LOCK` |
| `-n` | 接收器组件 | 固定写 `com.bintianqi.owndroid/.ApiReceiver`，显式指向 OwnDroid 的接口接收器 |
| `--es key` | 字符串参数：密钥 | 换成你在应用里设的密钥 |
| `--es package` | 字符串参数：目标包名 | 应用类操作才需要；锁屏这类整机操作不用带 |

`-n` 这一段别省 —— 它把广播显式指到 OwnDroid 的接收器，不带的话系统不知道该把指令送给谁。

## 四、在哪执行、执行什么

**在哪发**：连电脑时在 adb shell 里发；有 root 的在 root 终端里发；Tasker 类自动化应用用其「发送 Intent / 广播」动作，组件与参数照上表填。

**能发什么**：隐藏/取消隐藏（`HIDE`/`UNHIDE`）、挂起/恢复（`SUSPEND`/`UNSUSPEND`）、阻止/允许卸载（`BLOCK_UNINSTALL`/`UNBLOCK_UNINSTALL`）、锁屏（`LOCK`）等，官方文档里还有权限管理、用户限制、重启等一长串。两点提醒：

- **完整清单以你所用版本设置页里列出的为准** —— 不同版本支持的操作与参数有差异，部分操作还有最低安卓版本要求；
- 包名不知道去哪查：在 OwnDroid「应用」板块里能看到每个应用的包名，直接复制。

一个完整例子 —— 隐藏某个应用后再锁屏（两条指令先后发）：

```bash
am broadcast -a com.bintianqi.owndroid.action.HIDE -n com.bintianqi.owndroid/.ApiReceiver --es key 你的密钥 --es package com.example.app
am broadcast -a com.bintianqi.owndroid.action.LOCK -n com.bintianqi.owndroid/.ApiReceiver --es key 你的密钥
```

## 五、调试顺序与安全提醒

- **先手动验证，再交给自动化**：写脚本前先在 adb shell 里手发一条，去 OwnDroid 对应板块确认操作生效了，再固化到自动化流程里。格式错了接口不会报错给你看，只会静默不执行。
- **指令没有二次确认**：广播发出去立即生效，`HIDE` 错了包名就是藏错应用。涉及撤销权限、清除数据的操作更要想一下再发。
- **密钥等于钥匙**：拿到密钥的任何应用都能发同样的指令，不要把带密钥的脚本分享出去，自动化应用也只装信得过的。
- 反向操作别忘了写进脚本：`HIDE` 之外留着对应的 `UNHIDE`，批量挂起的要有恢复入口，别把自己锁在门外（见[常见问题与注意事项.md](常见问题与注意事项.md)里隐藏应用找回那节）。

日常不写脚本的话，这些操作在界面里都能点出来，见[管控功能与实操场景.md](管控功能与实操场景.md)。
