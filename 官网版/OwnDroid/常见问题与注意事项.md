## 一、激活后建不了工作资料 / 新用户

激活成设备所有者后，你在系统设置里新建工作资料或新用户会被拒绝 —— 这是系统在设置设备所有者时自动加上的用户限制，不是 OwnDroid 出了故障。

两条路：

- **不折腾**：用 OwnDroid「用户」板块里自带的创建用户功能，它不受这个限制；日常切换用系统下拉栏的用户切换入口。
- **有 root 的**：在 root 的 adb shell 里依次执行下面几条解除限制（来自官方说明，各系统字段名略有差异，报「unknown restriction」就跳过那条）：

  ```bash
  pm set-user-restriction no_add_user 0
  pm set-user-restriction no_add_managed_profile 0
  pm set-user-restriction no_add_private_profile 0
  pm set-user-restriction no_add_clone_profile 0
  ```

  官方同时提醒：绕过这个限制可能出现预期外的行为，比如你建的用户在重启时被系统悄悄删掉。要走这条路自己权衡。

另一个硬约束记住即可：设备所有者和工作资料的所有者不能是同一个应用，别把两者都设给 OwnDroid，否则重启后可能掉权限。

## 二、系统备份好像失效了

有用户反馈：设置设备所有者后，系统的自动备份（如 GrapheneOS 上的 Seedvault）不工作了。对应的处理：在 OwnDroid 的「系统」板块 → 选项里，把「备份服务」开关打开。如果你依赖系统备份，激活完先检查这一项。

## 三、隐藏的应用去哪了、怎么找回来

用了「隐藏（Hide）」的应用：桌面图标消失、抽屉里也没有，但应用本体和数据都还在。找回方式：打开 OwnDroid →「应用」板块 → 找到该应用 → 取消隐藏。挂起（Suspend）的恢复同理，入口都在同一个应用详情页里。

建议隐藏前记一下藏了哪些 —— 藏多了自己也想不起来，虽然 OwnDroid 的应用列表里都能看到，但挨个翻总归麻烦。

## 四、想卸载 OwnDroid，系统不让卸

设备所有者身份下的应用，系统禁止直接卸载（防丢类工具正是靠这个保命）。正确顺序：

1. 先在 OwnDroid 里解除你设置过的管控项（阻止卸载、禁止安装应用、挂起的应用等）。
2. 停用设备所有者身份：设备所有者信息页（盾牌图标入口）→ 右上角三点 → 「停用 / Deactivate」。
3. 停用后回到桌面，正常长按图标卸载即可。

跳过第 1、2 步硬卸，系统只会一直拒绝，不是应用坏了。彻底没辙时的兜底：恢复出厂设置也会连带解除设备所有者身份 —— 数据会全部清掉，动手前先备份。

## 五、升级与版本差异

- 网盘这份是 7.0。官方迭代快，2026 年 8 月已到 8.x 系列，新版本改动看官方 [GitHub Releases](https://github.com/BinTianqi/OwnDroid/releases)。
- 覆盖安装新 APK 一般能直接升级；如果系统拒绝覆盖（设备所有者身份下偶发），先按第四节停用再装新版。
- 官方自 v7.3 起要求 Android 6.0 及以上（v7.2 是最后支持 Android 5 的版本）。老设备想升级前先对一下系统版本。
- 界面与功能随版本变化明显：比如「显示危险功能」开关、激活入口的位置，在不同版本里不完全一样。本套文档以 7.0 的界面为主，与你的版本对不上时以实际界面为准。

## 六、给自动化工具用的接口

OwnDroid 提供基于广播（broadcast）的对外接口：你先在应用设置里启用 API 并设定一个密钥，之后外部工具（Tasker、自动化脚本等）带上密钥发送广播，就能批量执行冻结、隐藏、授权这类操作。7.0 里功能包括挂起/恢复、隐藏/取消隐藏、阻止卸载、授权管理、锁屏、重启等，具体清单以你所用版本设置页里列的为准。广播格式、字段含义与调试顺序见[广播接口自动化调用.md](广播接口自动化调用.md)。

会写自动化脚本的才有这个需求，普通使用完全不用碰它。动手前先想清楚：这些操作跑起来是没有二次确认的。

## 七、几条通用提醒

- 权限越大越要克制：设备所有者能改的东西大多影响整机行为，每开一个限制，顺手记住在哪解除。
- 擦除数据是不可逆操作，7.0 里默认收在「显示危险功能」开关后面，没需要就别打开那个开关。
- 三星机型在激活阶段就受限（官方注明暂无解法），买来专门折腾管控的话避开三星（激活报错详见[设备所有者激活方法.md](设备所有者激活方法.md)）。
- 安装包来源与版本核对见[下载与安装教程.md](下载与安装教程.md)，装之前先对一眼 MD5。
