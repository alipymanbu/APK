## 一、这是个什么应用，先对上号

OwnDroid 是一个开源的安卓设备策略管理工具，作者是 BinTianqi，项目以 GPL-3.0 许可证发布在 [GitHub](https://github.com/BinTianqi/OwnDroid)。它做的事：让你通过安卓系统自带的设备管理接口，对自己这台手机做普通应用做不到的管控 —— 冻结应用、禁用摄像头、限制短信电话、管理多用户等。

适合谁：想深度掌控自己设备、愿意折腾一次激活步骤的进阶用户。它不是那种装上就能用的一键优化类工具 —— **不激活时它基本是个空壳**，激活是整套流程里最关键的一步（见[设备所有者激活方法.md](设备所有者激活方法.md)）。

## 三、从哪下载

两个渠道，按需选：

1. **本文提供的 [OwnDroid 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d18418ed1248)**：转存后即可下载 APK，版本即上表所列的 7.0。
2. **官方渠道**：GitHub 的 [Releases 页面](https://github.com/BinTianqi/OwnDroid/releases)，或收录了该项目的 IzzyOnDroid F-Droid 仓库。想要最新版走这里。

一个官方说明要注意：**ColorOS 用户应从 GitHub Releases 下载 testkey 版本** —— 通用签名版在部分 ColorOS 系统上激活会被系统拦截（激活报错详见[设备所有者激活方法.md](设备所有者激活方法.md)）。testkey 版与签名版只是签名不同，功能没有区别。

## 四、安装步骤

1. 把 APK 传到手机存储（网盘下载、数据线、局域网传输都行）。
2. 在文件管理器里点开 APK。系统会提示「禁止安装未知来源应用」，按提示允许你的文件管理器「安装未知应用」权限，再回来继续。
3. 点安装，等几秒完成。安装包不到 3 MB，占用很小。
4. 装完点「打开」，或在桌面图标进入。

安装本身没有任何特殊之处，全程普通应用权限，不会要求 root。特殊的是下一步激活 —— 激活完成后它的权限性质就变了，所以建议先想清楚再激活（激活前提与报错见[设备所有者激活方法.md](设备所有者激活方法.md)，激活之后的日常问题见[常见问题与注意事项.md](常见问题与注意事项.md)）。

## 五、第一次打开会看到什么

未激活状态下打开 OwnDroid，主体功能处于不可用状态，应用会引导你完成激活。7.0 这一版在打开时会提供 Shizuku、Dhizuku、Root、ADB 命令这几条激活途径，你按自己手机的情况选一条：

- 没刷机、没 root 的普通手机 → 走 ADB 命令，需要一台电脑；
- 已经在用 Shizuku / Dhizuku 的 → 直接在应用内授权激活；
- 有 root 的 → 应用内点一下即可。

具体每条路的分步操作、激活前的清理动作（删账号、删多余用户）、以及「设备上已有账号」「user limit reached」这类报错的对照解法，全部集中在[设备所有者激活方法.md](设备所有者激活方法.md)一篇里，这里不重复。
