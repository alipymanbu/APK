## 一、动手前先确认两件事

1. 你已经完成激活。下面所有操作都建立在设备所有者（或对应工作模式）身份上，没激活的先按[设备所有者激活方法.md](设备所有者激活方法.md)走一遍 —— 未激活时这些入口都在但点了无效。
2. 你清楚每项设置怎么撤销。设备所有者改的是系统层策略，大多数开关都是「设了就要记得解」：本文每个场景都写了对应的还原位置。

## 二、六大功能板块速览

| 板块 | 能做的事 | 你什么时候会用到 |
| --- | --- | --- |
| 系统 | 禁用相机、禁止截屏、全局静音、禁用 USB 信号、锁定任务模式、擦除数据 | 出借手机、给老人小孩专用机 |
| 网络 | 添加/修改/删除 Wi-Fi、查看网络统计、网络日志 | 批量配置家里几台设备的 Wi-Fi、排查流量 |
| 应用 | 挂起/隐藏应用、阻止卸载、授予/撤销权限、清除应用数据、安装/卸载应用 | 处理预装应用、管住应用权限 |
| 用户限制 | 禁短信、禁拨出电话、禁蓝牙、禁 NFC、禁 USB 文件传输、禁止安装/卸载应用 | 儿童机、备用机做减法 |
| 用户 | 查看用户信息，创建/启动/切换/停止/删除用户 | 一台机分身两个独立空间 |
| 密码与锁屏 | 重置密码、设置屏幕超时 | 忘锁屏密码的补救、统一锁屏时长 |

7.0 这一版的选项页里还有「显示危险功能」开关：擦除数据这类不可逆操作默认收着，需要时再打开显示。不用时建议关回去，防止误触。

## 三、场景一：冻结不想要的预装应用

诉求：图标还在桌面上、应用还在系统里，但点不开、不运行、不耗电，随时能恢复。

操作路径：

1. 打开 OwnDroid，进「应用」板块，找到目标应用。
2. 选「挂起（Suspend）」：应用图标变灰、无法启动。想更彻底的用「隐藏（Hide）」—— 图标直接从桌面消失，且不会出现在最近任务里。
3. 恢复：回到同一位置，解除挂起或取消隐藏。恢复后应用数据原样保留。

和「卸载」的区别：卸载（尤其对系统应用）改的是系统组成，恢复靠刷机或重装；挂起/隐藏只是运行层的状态开关，**解除即恢复**，是给预装应用做减法最可逆的一种方式。

想阻止别人（或自己手滑）把某个应用卸掉，用「阻止卸载」：设置后该应用从系统层面卸不掉，解除入口就在同一段设置里。

## 四、场景二：把一台备用机调成「儿童机」

诉求：孩子只能用指定的几个应用，其余功能收掉。

一条可落地的组合（都在「用户限制」和「应用」板块）：

| 限制项 | 设置位置 | 效果 |
| --- | --- | --- |
| 禁止安装应用 | 用户限制 | 拦住自行下载新应用 |
| 禁止拨出电话 / 禁止发送短信 | 用户限制 | 保留接听与紧急通话能力的同时收掉主动外联 |
| 禁用蓝牙 / 禁用 NFC | 用户限制 | 封掉近场传输的口子 |
| 禁止 USB 文件传输 | 用户限制 | 插电脑只能充电，拷不走文件 |
| 撤销目标应用的相机权限 | 应用 → 权限 | 个别应用不需要相机时单独收权 |

两项提醒：

- 设置前先用你自己的手测一遍每个限制的体验，别一次全开 —— 例如禁了短信后某些验证码流程就断了。
- 这套限制锁定的是这台设备的使用边界，解除入口都在 OwnDroid 对应板块里。设备要是转手给别人，记得先全部解除并停用设备所有者（见[常见问题与注意事项.md](常见问题与注意事项.md)的卸载前提）。

## 五、场景三：多用户与工作资料的取舍

诉求：一台手机分出两套完全独立的空间。

- **创建新用户**：在「用户」板块里新建，可以只保留最基础的系统应用。日常在系统下拉栏里切换用户，两个空间的应用、数据、账号完全隔离。
- **工作资料**：更轻量的双空间方案，但注意 —— 多数系统在你设置设备所有者后**不允许再建工作资料**（系统自动加了限制），这不是 OwnDroid 的问题。有 root 的可以按官方 README 给的命令解除这个系统限制；没 root 的，直接用「用户」功能替代即可。
- 一个硬性约束：设备所有者和工作资料的所有者**不能是同一个应用**，否则重启后可能掉权限。别把两者都设给 OwnDroid。

## 六、几个边界先说清

- 它管的是**你自己的设备**：这些能力与公司给员工配机用的管理接口是同一套，用在自有设备上是正当用途，但别拿来动别人的手机。
- 「擦除数据」是真擦：一键回到出厂状态且不可逆，7.0 里它默认收在「显示危险功能」开关后面，打开这个开关本身就该慎重。
- 想让别的工具调用这些能力（自动化脚本批量冻结应用之类），OwnDroid 有对外接口，需要在设置里开 API 并配置密钥，广播格式与可用操作见[广播接口自动化调用.md](广播接口自动化调用.md)。
- 应用锁、锁屏类设置改的是这台设备的锁屏策略，忘了密码时恢复路径有限，动「密码与锁屏」板块前想清楚。

还没装的话，安装包在本文开头与[下载与安装教程.md](下载与安装教程.md)里都有入口。
