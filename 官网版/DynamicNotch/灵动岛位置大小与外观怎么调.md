# DynamicNotch 灵动岛位置大小与外观怎么调

> 位置、尺寸、圆角、文字样式、主题都在「显示与自定义」里改；本篇给一套按顺序调的做法，并说清哪些选项会让岛和挖孔对不齐。

岛调得好不好，落到两个具体问题上：它和摄像头开孔对没对齐，它有没有吃掉状态栏图标的位置。本篇按官方给出的设置路径，把这两个问题拆成可逐项核对的动作。

## 一、调整入口在哪

官方给的操作路径是：

1. 打开 DynamicNotch 的设置页；
2. 进「显示与自定义」；
3. 在这里调岛的尺寸、位置与颜色；
4. 点「文字样式」改字体与外观；
5. 先看预览确认效果，再退出。

## 二、先调位置，再调大小

顺序不要颠倒：位置决定岛和挖孔是否对得齐，大小决定它会不会挤掉状态栏图标。

| 你遇到的问题 | 先动哪一项 | 判断是否调好的标准 |
| --- | --- | --- |
| 岛和摄像头开孔没对齐 | 位置（左右偏移、上下偏移） | 熄屏再亮屏一次，岛的水平中心与开孔中心重合 |
| 挡住了信号、电量图标 | 宽度 | 常驻状态下，状态栏图标仍然完整可见 |
| 岛太矮、显得局促 | 高度与圆角 | 与屏幕顶部的黑色区域自然衔接，看不出拼接边 |
| 岛偏左或偏右 | 左右偏移 | 竖屏、横屏各看一次都不偏 |

## 三、开孔在左边或右边怎么设

多数国产机型的摄像头开孔居中，但侧边开孔、以及带刘海的老机型需要把位置往对应一侧挪。

做法是先按居中试，再按上表的判断标准微调；如果怎么挪都对不齐，先把系统的状态栏改成「隐藏挖孔 / 隐藏刘海」这类显示方式，再回来调位置——系统自己那层遮罩会干扰你判断岛的真实位置。

## 四、文字样式

字体、字号、颜色三项都在「文字样式」里改，改完先看预览再退出。字号调大后，较长的曲名或应用名会被截断，这是岛上显示宽度有限导致的，属正常现象，把字号调小即可。
官方还支持**按应用分别设置背景与文字颜色**——想让某个聊天应用的消息用另一套配色，就在这一项里单独指定，不必全局改。

## 五、主题与自动跟随

主题里有多种样式可选，其中一类会跟随实时天气变化外观：岛的配色随当天天气走。想要外观稳定，选一套固定主题，不要挂天气主题。

## 六、在指定应用里隐藏

「在应用中隐藏」里把应用勾上，岛在该应用处于前台时就不显示。几个常见的用法：

| 场景 | 建议勾掉的应用 |
| --- | --- |
| 全屏看视频 | 视频类应用 |
| 横屏玩游戏 | 游戏应用 |
| 用相机取景 | 相机应用 |
| 看文档、看图纸 | 需要整屏阅读的应用 |

折叠屏机型另有「相机自动隐藏」，可以在展开与折叠两种状态下分别设定，入口在相机相关的设置项里。隐藏只影响显示，不影响岛在其他应用里的正常工作。

## 七、改完没生效怎么办

按这个顺序试，一般一次就能恢复：

1. 退回桌面再重进应用，确认改动被写进去了；
2. 关掉「动态刘海栏」总开关，再打开一次；
3. 重启应用；仍然不变的重启一次手机；
4. 还是不变，说明改动被系统的后台限制挡住了，按 [权限怎么给才不会被后台清掉.md](权限怎么给才不会被后台清掉.md) 检查权限与电池设置。

想在岛上放什么内容、哪些通知会显示出来，见 [哪些内容和通知会显示在岛上.md](哪些内容和通知会显示在岛上.md)。
