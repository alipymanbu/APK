# DynamicNotch 和手机自带灵动岛冲突怎么办

> 越来越多国产机型自带「岛」，两个岛同时工作会出现同一条消息弹两次、位置互相遮挡、点击落到另一个应用的问题。本篇说清怎么判断是哪一个在弹、以及两种处理办法。

手机系统里本来就有一套「岛」时，再装 DynamicNotch 就会撞车。冲突本身不损坏手机，但会把顶部区域搞得又乱又难点。本篇给的是判断与取舍的做法，不是让两个岛硬凑在一起。

## 一、哪些机型自带「岛」

| 系统 | 系统里的那个「岛」叫什么 | 大致覆盖范围 |
| --- | --- | --- |
| 小米 / 澎湃 OS | 超级岛（依赖「焦点通知」） | 澎湃 OS 3 起、带居中开孔的机型 |
| 荣耀 / MagicOS | 灵动胶囊 | 近两年的 Magic 系列等 |
| vivo / iQOO 的 OriginOS | 原子岛 | 部分机型 |
| OPPO / 一加 / realme 的 ColorOS | 实况窗及相关通知形态 | 部分机型 |
| 华为 / 鸿蒙 | 实况窗 | HarmonyOS 机型 |

同一品牌不同代际功能名与入口都可能变，以你手机系统当时显示的为准。

## 二、冲突的三种表现

| 表现 | 实际发生了什么 |
| --- | --- |
| 同一条消息弹两次、两个胶囊前后脚出现 | 系统的岛和 DynamicNotch 各自读了一遍通知 |
| 位置互相挤：一个占着开孔，另一个被推到下面或半遮 | 两层叠加视图都在抢同一块屏幕区域 |
| 点击落到另一个：点了 DynamicNotch 的岛，打开的是系统详情页 | 点击命中的是上层那个视图 |

## 三、做法一：只留一个

**要留系统自带的**：把 DynamicNotch 的总开关关掉，或直接卸载；安装包仍从网盘里取。

**要留 DynamicNotch**：把系统的那个关掉。不同品牌关的位置不同，通用找法是：

1. 在系统设置里搜索「超级岛」「灵动胶囊」「原子岛」「实况窗」这类关键词，找到总开关；
2. 找不到总开关的，退一步逐应用处理——小米的超级岛依赖「焦点通知」，可以长按桌面图标 → 应用信息 → 通知管理，把对应应用的焦点通知关掉；
3. 关完重启一次手机，让顶部区域重新排布。

## 四、做法二：各管一段（多数人的选择）

两个都留着，但让它们负责不同的内容，顶部就不会打架：

| 分工方式 | 怎么设 |
| --- | --- |
| 系统管出行类（导航、打车、外卖），DynamicNotch 管消息与音乐 | 在 DynamicNotch 的「在应用中隐藏」里把导航、打车、外卖类应用勾掉 |
| DynamicNotch 管充电、蓝牙、天气这些状态类，系统管消息 | 在 DynamicNotch 里关掉消息类显示，只留状态类 |

两套内容之间不要有交集，是这套做法能成立的关键。

## 五、三十秒判断该关哪个

1. **只放一首歌**，看弹出来的胶囊是什么外观：和你设置的样式一致，就是 DynamicNotch 在弹；样式偏向系统风格，就是系统的岛在弹。
2. **把 DynamicNotch 的总开关关掉**，再重复上一步：如果胶囊还在，说明那是系统自带的。

两步做完就知道头顶上到底有几个「岛」在工作，再按第三节或第四节处理。

## 六、岛压住了桌面图标或状态栏

先按 [灵动岛位置大小与外观怎么调.md](灵动岛位置大小与外观怎么调.md) 把宽度收窄、位置下移一点；仍然压住的话，把系统状态栏改成「隐藏挖孔 / 隐藏刘海」显示，再回来微调位置。
