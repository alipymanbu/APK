# DynamicNotch 通知上岛后看不到内容怎么办

> 岛显示的是通知的概要，正文能不能显示出来，取决于源应用与系统两处设置。本篇把「只有一句新消息、看不到是谁发的」这种情况拆成可逐项排查的原因。

通知已经弹到岛上了，但只有一行「你有一条新消息」，点开也没有发信人和正文——这不是应用坏了。岛上能显示什么，取决于那条通知送到系统时带着什么内容。

## 一、先分清「没上岛」和「上岛了但没内容」

| 现象 | 说明什么 |
| --- | --- |
| 岛完全没反应 | 通知没读到，或应用不在后台运行，见 [常见问题与排查.md](常见问题与排查.md) |
| 岛弹了，但只有一句笼统提示 | 通知本身就没带正文，本篇要解决的就是这一种 |
| 岛上有发信人和内容 | 一切正常 |

## 二、原因一：源应用自己关掉了「通知显示消息详情」

聊天、邮件类应用普遍有一个开关，控制通知里要不要带上发信人与正文。它关掉之后，系统收到的通知本身就只剩一句笼统提示，岛也只能显示这一句。

以微信为例，这个开关的位置大意是：「我」→「设置」→「新消息通知」→「通知显示消息详情」。不同版本可能叫「通知栏显示消息详情」，以应用里当时显示的为准。

其他聊天、邮件类应用的同类开关，名字通常是「显示消息详情」「在通知中显示内容」「通知预览」这一类。

## 三、原因二：系统在锁屏上隐藏了通知内容

Android 允许在锁屏上隐藏通知内容，只在解锁后显示。这条设置生效时，锁屏期间送到岛上的内容会先被系统擦掉。

| 系统 | 大致路径 |
| --- | --- |
| 原生 Android / Pixel | 设置 → 通知 → 锁屏上的通知 → 选「显示全部内容」 |
| 小米 / 澎湃 OS | 设置 → 通知与控制中心 → 通知管理 → 锁屏通知 → 显示内容 |
| 华为 / 荣耀 | 设置 → 通知 → 锁屏通知 → 显示全部内容 |
| OPPO / vivo 等定制系统 | 在「通知与状态栏」一类设置里找「锁屏通知内容」 |

各代系统名称会变，以你手机当时显示的为准。解锁后再看岛，内容回来了，就说明是这条设置在起作用。

## 四、排查顺序

1. **先解锁屏幕再看岛**：解锁后有内容、锁屏时没有 → 是第三节的系统设置；
2. **解锁后仍然只有一句提示**：进源应用把「通知显示消息详情」打开（第二节）；
3. **改动后让对方向你发一条新消息**：已经收到的那条通知不会补全内容，必须等新消息才验证得出来；
4. 三步都做完还是老样子，按 [常见问题与排查.md](常见问题与排查.md) 继续查。

## 五、打开锁屏显示内容的代价

把锁屏通知改成「显示全部内容」，等于旁人不用解锁就能从你的锁屏上看到消息正文；不打开，损失的只是岛上的预览，解锁后一切照常。这是取舍，不是故障，按你自己的使用环境定。

想在岛上显示概要的同时，弄清这款应用会不会把通知内容传走，见 [通知内容会不会被上传.md](通知内容会不会被上传.md)。
