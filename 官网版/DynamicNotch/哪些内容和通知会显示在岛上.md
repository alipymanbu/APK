# DynamicNotch 哪些内容和通知会显示在岛上

> 岛上能显示的不只是消息：音乐、来电、充电、蓝牙、天气、导航、计时器都在其中。本篇按类型说清各自显示什么、能操作到什么程度，以及为什么有的通知上不了岛。

岛上放什么，取决于你把哪几类内容打开、以及这些内容有没有正常推送到系统。本篇按官方列出的类型逐一说明，再交代上不了岛时该先查哪里。

## 一、默认能上岛的几类内容

| 类型 | 岛上显示什么 | 能在这里做什么 |
| --- | --- | --- |
| 应用通知 | 消息来源与概要 | 点开展开详情，或直接跳转到对应应用 |
| 音乐播放 | 当前曲目、专辑封面，封面作为模糊背景 | 播放、暂停、切歌，不用回到音乐应用 |
| 来电 | 来电人信息，以岛的形态呈现 | 直接接听或拒接，画面不被打断 |
| 充电 | 电量百分比与充电动画 | 只看状态，不能在这里改充电设置 |
| 蓝牙与无线设备 | 智能手表、耳机、免提等设备的连接状态与电量百分比 | 看电量，判断该不该给耳机充电 |
| 天气 | 温度与天气状况 | 看当天天气，不用下拉通知栏 |
| 地图导航 | 转向提示、剩余距离、预计到达时间 | 看路线进度，同时停留在别的应用里 |
| 计时与闹钟 | 倒计时进度、闹钟的稍后提醒 | 看剩余时间 |
| 系统录屏 | 录屏进行中的状态 | 知道录屏还在跑 |

## 二、音乐控制能控到什么程度

岛上能显示封面并不取决于 DynamicNotch 自己，而取决于那个音乐应用有没有把播放信息推给系统。表现上分三种情况：

- **能显示也能控制**：主流音乐应用的播放信息会走系统通知，岛上能看到曲目、封面，并直接暂停、切歌；
- **只能显示**：应用推了标题但不提供控制按钮，岛上就只显示曲目；
- **什么都不显示**：只在应用内部播放、不往系统发播放信息的应用，岛上不会有内容。

手机上同时装了几个音乐应用时，岛上显示的是当前正在出声的那一个。

## 三、导航怎么上岛

官方给的步骤是：

1. 在手机上打开 Google Maps；
2. 设定目的地，点开始导航；
3. 岛上出现带路线信息的视图；
4. 在岛上直接看转向、距离与预计到达时间；
5. 中途可以切到别的应用，路线信息继续留在岛上。

## 四、快捷控制：把常用入口放上岛

官方给的操作是：进 DynamicNotch 设置 → 打开「快捷控制」→ 添加或管理快捷控制项与应用快捷方式，之后可以随时增删。适合放的是高频、要一步打开的入口；不常用的别往上堆，岛的空间有限。

## 五、充电动画怎么换

1. 进 DynamicNotch 设置；
2. 打开「小充电动画」这一节；
3. 从多种动画样式里挑一个；
4. 点应用生效；
5. 插上充电器，动画就会按你选的样式出现。

## 六、哪些应用建议不让它上岛

| 情况 | 处理方式 |
| --- | --- |
| 全屏视频、横屏游戏、相机 | 在「在应用中隐藏」里勾掉这些应用，避免岛压在画面上 |
| 同一件事被系统自带的岛也显示了一遍 | 见 [和手机自带灵动岛冲突怎么办.md](和手机自带灵动岛冲突怎么办.md) |
| 高频广告类推送 | 直接在系统的应用通知设置里关掉该类通知，岛自然也不再显示 |

## 七、通知上不了岛，先查这三处

1. **应用本身有没有正常发通知**——先下拉系统通知栏确认这条消息本来就会弹出来；
2. **通知使用权给了没有**——没给的话消息类内容全部不上岛，见 [权限怎么给才不会被后台清掉.md](权限怎么给才不会被后台清掉.md)；
3. **岛是不是已经被系统清掉了**——如果连锁屏时钟、充电这类状态也不显示，问题不在通知，而在应用没在后台活着；
4. **通知上岛了但看不到内容**——那不是没上岛，而是通知本身没带正文，见 [通知上岛后看不到内容怎么办.md](通知上岛后看不到内容怎么办.md)。

以上几处都排过还是不正常，按 [常见问题与排查.md](常见问题与排查.md) 逐条对。
