# DynamicNotch 权限怎么给才不会被后台清掉

装好之后最常碰到的不是装不上，而是「刚装好能用，过一阵子顶部的胶囊就不见了」。原因几乎都出在权限与后台限制上。本篇把三项系统权限、各品牌机型的保活入口、权限被系统自动收回后的处置方式一次讲清。

## 一、三项系统权限，各管一段

| 权限 | 系统里的名字 | 在哪开 | 不给会怎样 |
| --- | --- | --- | --- |
| 悬浮窗 | 「显示在其他应用上层」 | 设置 → 应用 → 特殊应用权限 → 显示在其他应用上层 | 顶部那块胶囊画不出来，等于完全不生效 |
| 通知使用权 | 「通知使用权」/「通知访问」 | 设置 → 应用 → 特殊应用权限 → 通知使用权 | 消息、来电、音乐这类内容读不到，岛上只剩充电、蓝牙这类状态 |
| 辅助功能 | 「无障碍」/「已安装的服务」 | 设置 → 辅助功能 → 已安装的服务 | 点在岛上的操作没反应，点击、滑动、长按都失效 |

首次启动时应用会依次引导你跳到这三处，按顺序开完再回到应用点「确定」。

两点补充：

- **只需要这三项，不需要 root**：这类工具建立在安卓现成的权限体系上，不用解锁 Bootloader，也不用装框架。凡是先要求你刷机、装 Xposed / LSPosed 插件才能用灵动岛的说法，与这款应用无关。
- **通知使用权读到了什么**：官方隐私政策写明，这项权限只用于在岛上显示通知的概要，通知正文不会被保存、也不会传到服务器。完整口径见 [通知内容会不会被上传.md](通知内容会不会被上传.md)。

## 二、让岛熬过后台清理

三项权限给全了，还有一个更隐蔽的原因会让岛「过一会儿自己消失」：系统把应用从后台清掉了。处理方式是让它在电池管理里不被限制。

官方在应用内的常见问题里给的最小操作是：

1. 打开系统「设置」，搜索「电源」；
2. 找到「后台电量消耗」（不同机型也叫「耗电管理」「电池优化」）；
3. 找到 DynamicNotch，允许它在后台活动、不限制它的耗电。

各品牌把这一项收在不同位置，下面按常见路径整理，实际以你手机系统当时显示的名称为准：

| 系统 | 大致路径 |
| --- | --- |
| 小米 / 澎湃 OS | 设置 → 应用设置 → 应用管理 → DynamicNotch → 省电策略 → 无限制；另在「自启动」里允许 |
| 华为 / 鸿蒙 | 设置 → 电池 → 应用启动管理 → 关掉 DynamicNotch 的自动管理，手动允许「自启动」「关联启动」「后台活动」 |
| 荣耀 / MagicOS | 设置 → 电池 → 应用启动管理；再把 DynamicNotch 加进手机管家的后台保护名单 |
| OPPO / 一加 / realme 的 ColorOS | 设置 → 电池 → 应用耗电管理 → DynamicNotch → 允许完全后台行为 |
| vivo / iQOO 的 OriginOS | 设置 → 电池 → 后台耗电管理 → 允许后台运行；i 管家 → 自启动里允许 |
| 三星 One UI | 设置 → 电池和设备维护 → 电池 → 后台使用限制 → 把 DynamicNotch 加进「永不休眠的应用」 |
| 原生 Android / Pixel | 设置 → 应用 → DynamicNotch → 电池 → 不受限制 |

放行之后它就真的会一直在后台跑，这是代价。想知道这点开销在你这台手机上到底是多少，见 [耗电和内存占用怎么看.md](耗电和内存占用怎么看.md)。

## 三、权限被系统自动关掉了怎么办

定制系统在系统升级、应用长时间未使用、或一键清理内存之后，会把你已经给过的辅助功能与悬浮窗权限收回去。表现是「前几天好好的，今天突然不显示了」。按这个顺序查：

1. 把三项权限逐一打开，确认开关是不是还在原位；
2. 把 DynamicNotch 加进手机管家的「后台保护 / 自启动 / 白名单」名单——不在名单里的应用，常在一键清理时被一并杀掉；
3. 在多任务界面把 DynamicNotch 的卡片下拉锁定（卡角会出现锁形图标），避免被误清；
4. 如果是系统刚升级完才出现的，先重启一次手机，再回来检查权限；
5. 部分系统还有「自动管理 / 智能省电」这类总开关，会把长期没打开过的应用降级限制，把 DynamicNotch 从自动管理里排除掉。

## 四、怎么确认配置真的生效了

不用凭感觉，按下面三个动作各验证一次：

| 验证动作 | 期望看到 |
| --- | --- |
| 放一首歌，回到桌面 | 岛上出现曲目与封面，点开可切歌 |
| 插上充电器 | 岛上出现电量与充电动画 |
| 用另一台手机给自己发一条短信或聊天消息 | 岛上弹出该通知的概要 |

三项都过，说明权限与保活都到位了。只有充电那一项过、消息不来的，多半是通知使用权没给全，回看第一节。三条都不过的，检查总开关是不是开着，再对照 [常见问题与排查.md](常见问题与排查.md)。
