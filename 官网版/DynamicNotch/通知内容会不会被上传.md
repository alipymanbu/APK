# DynamicNotch 通知内容会不会被上传

> 这款应用要拿到「通知使用权」和悬浮窗，很多人的第一反应是「它是不是把我的消息都读走了」。本篇把官方隐私政策的说明整理成可对照的几条，并说清哪些权限可以不给。

要把通知画到屏幕上，就必须先读到通知，这是这类工具绕不开的一步。值得核对的是「读到了之后去哪了」。本篇照官方隐私政策逐项列出，也把官方口径之间对不上的地方摆出来，由你自己判断。

## 一、官方隐私政策的逐项说明

来源是官网的隐私政策页 [dynamicislandforandroid.com/privacy-policy.html](https://dynamicislandforandroid.com/privacy-policy.html)，页面上标注的最近更新日期是 2025 年 11 月 3 日（以该页当时显示为准）。

| 数据项 | 官方说明 |
| --- | --- |
| 姓名、邮箱、电话等个人信息 | 不收集 |
| 联系人 | 不访问、不存储 |
| 通知内容 | 不保存、不上传；只读取在岛上显示概要所必需的元数据 |
| 位置、照片、麦克风 | 官方写明不是本应用所需 |
| 崩溃日志与使用诊断 | 以匿名或汇总形式收集，可能交给 Firebase 这类分析服务 |
| 广告 | 若应用内展示广告，可能通过 Google Play 服务 / AdMob 使用广告标识 |
| 本地数据 | 设置与偏好存在本机，卸载即清除 |

## 二、和商店页权限清单对不上的地方

第三方应用信息站按商店页整理出的权限清单里，能看到位置、相机、联系人、麦克风、通话等系统级条目；而官方隐私政策逐项写明位置、照片、麦克风都不是本应用所需。两处口径并不完全一致，这里不替你选边。

落到做法上只有一条：**安装后按系统逐条弹出的授权项自己判断，用不到的就不点**。已经给过的可以随时收回，方式见下一节。

## 三、权限怎么收回

| 要收回的权限 | 在哪收 |
| --- | --- |
| 通道类权限（位置、相机、麦克风、通讯录等） | 设置 → 应用 → DynamicNotch → 权限 |
| 通知使用权 | 设置 → 应用 → 特殊应用权限 → 通知使用权 |
| 辅助功能 | 设置 → 辅助功能 → 已安装的服务 |
| 悬浮窗 | 设置 → 应用 → 特殊应用权限 → 显示在其他应用上层 |

收回悬浮窗或通知使用权之后，对应功能会减少或直接失效，这是预期结果，不是故障。

## 四、不给通知使用权会怎样

岛仍然能显示充电、蓝牙、天气这类不依赖通知读取的状态；但消息、来电、音乐这三类不会出现。先想清自己要哪种用法，再决定这项权限给不给。

## 五、卸载之后还剩什么

设置与偏好都放在本机，卸载就会清除。第三方分析与广告服务留下的汇总数据，按它们各自的保留政策处理，不在本应用的控制范围内。想在卸载前先把本地那部分也清掉，可以在系统里对 DynamicNotch 执行一次「清除数据」再卸载。

权限与保活怎么配才不影响日常使用，见 [权限怎么给才不会被后台清掉.md](权限怎么给才不会被后台清掉.md)。
