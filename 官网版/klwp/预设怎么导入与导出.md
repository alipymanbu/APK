# KLWP 预设怎么导入与导出

> 别人做好的 KLWP 主题叫预设（preset），本篇讲三种来源各怎么装：内置预设、.klwp 文件导入、预设包应用，以及免费版在这一步和 Pro key 的差别。预设装好后怎么改，见[入门使用教程.md](入门使用教程.md)。

## 一、先分清三种预设来源

| 来源 | 形式 | 需不需要 Pro key |
| --- | --- | --- |
| 内置预设 | 随应用附带 | 不需要 |
| .klwp 预设文件 | 别人导出的单文件 | **需要**（免费版不能从存储导入预设） |
| 预设包应用 | 开发者打包成独立 App 的主题合集 | 不需要（个别主题自身声明要 Pro） |

三种来源最终都进同一个地方：编辑器左上角菜单 →「Load preset」，在列表里选中即可应用。

## 二、加载内置预设

左上角三条线菜单 →「Load preset」→ 列表分「Featured」和「Installed」两栏，Featured 是内置的示例主题，点一个先预览再加载。加载后桌面立刻变成那个主题的样子，你可以在它基础上改——看懂别人怎么搭的，是上手 KLWP 最快的路径（编辑器结构见[入门使用教程.md](入门使用教程.md)）。

## 三、导入 .klwp 文件

社区里分享的主题，最常见的形态是一个 `.klwp` 后缀的文件。导入它**需要 Pro key**：Kustom 把「从存储导入/导出预设」划成了 Pro 功能，免费版里这个入口是灰的或直接无效。Pro key 是官方在 [Google Play](https://play.google.com/store/apps/details?id=org.kustom.wallpaper) 上单独发售的授权应用，装上后免费版自动识别为 Pro，不需要输入激活码。

导入步骤（已装 Pro key 的前提下）：

1. 把 `.klwp` 文件下载到手机存储的任意位置；
2. 打开 KLWP，左上角菜单 →「Load preset」；
3. 从「文件」或「Import」入口选中存储里的那个 `.klwp` 文件；
4. 加载成功后它出现在预设列表里，和应用内置预设一样使用与修改。

导入没反应、入口找不到，多数是免费版没装 Pro key，或文件没下完整——逐项对照[常见问题与排查.md](常见问题与排查.md)的预设一节。

## 四、导出自己的预设

Pro key 装好后，导出同样在菜单里：把当前预设保存成 `.klwp` 文件存到存储，发给别人；还可以进一步打包成独立 APK——对方装上这个 APK，就等于装了一个预设包应用，连 KLWP 的导入操作都省了。社区里那些「XX 主题包」应用就是这么来的。

## 五、从哪里找预设

- **Reddit 的 [r/kustom](https://www.reddit.com/r/kustom/) 社区**：Kustom 系列最大的交流地，作者们发成品时通常附预设下载；
- **Google Play 商店**：搜「KLWP preset」「KLWP theme」，有一批专门发预设包的应用；
- **KLWP 的导出文件**：朋友或论坛上直接交换 `.klwp` 文件。

找来的预设依赖额外图片或字体的，先把素材放进手机再导入，缺素材的预设会显示成默认样式。
