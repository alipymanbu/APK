## 一、先弄清楚：这份安装包是什么

KLWP 全称 Kustom Live Wallpaper，是 Kustom Industries 出品的安卓动态壁纸制作工具，包名 `org.kustom.wallpaper`。它和你常见的「挑一张图片当壁纸」不是一回事：你在它自带的所见即所得编辑器里用图层堆出整个桌面背景，时间、天气、电量、音乐信息、甚至可以点的快捷入口，都能直接画进壁纸里。它和同一家的小部件工具 KWGT、锁屏工具 KLCK 是同系列产品，但分工不同——KLWP 管的是整张桌面背景。

这份网盘里的安装包基本信息（版本、大小以此为准）：

| 项目 | 信息 |
| --- | --- |
| 版本 | 3.81b530515 |
| 安装包大小 | 33.67 MB |
| 包名 | org.kustom.wallpaper |
| MD5 | 07D459E4F4873312AFBA311419B50DD8 |
| 系统要求 | 需要较新的安卓系统（采集记录标注安卓 5.2 以上，以实际安装为准） |

KLWP 的版本号是「主版本.次版本 + b + 构建号」的形式（比如这份的 3.81b530515），官方更新比较频繁。网盘里这份是采集当时的版本，和 [Google Play 商店](https://play.google.com/store/apps/details?id=org.kustom.wallpaper)当前挂的最新版可能不是同一个，别拿它去对官方更新日志。

## 二、从网盘获取安装文件资源

头部给出的 KLWP 安装文件资源（夸克网盘）就是安装包的获取入口：把分享内容转存到自己的网盘后，在手机上打开夸克网盘 App，找到 `klwp_v3.81b530515.apk` 下载到本机；也可以先在电脑上下载，再传到手机里安装。

## 三、安装步骤

1. 在手机上找到下载好的 APK 文件（文件名类似 `klwp_v3.81b530515.apk`），点它；
2. 第一次安装第三方来源的应用时，系统会提示「不允许安装未知来源应用」，按提示给对应的浏览器或网盘 App 授予「安装未知应用」权限（各品牌叫法略有差异）；
3. 回到安装界面点「安装」，等进度走完；
4. 装完点「打开」，直接进入 KLWP 的编辑器界面就成功了——它没有传统意义上的主页，打开就是编辑器。

## 四、装不上时按这几种情况排查

| 现象 | 多半是 | 怎么处理 |
| --- | --- | --- |
| 提示「安装包解析失败」 | 下载不完整或文件损坏 | 重新下载；核对文件 MD5 是否为上表的值 |
| 提示「应用未安装」 | 手机里已装过同包名的旧版本，签名对不上 | 先卸载旧版本再装 |
| 点了没反应、不弹安装窗 | 没给「安装未知应用」权限 | 到系统设置的「安装未知应用」里给对应 App 授权 |
| 提示存储空间不足 | 剩余空间小于安装包加缓存 | 清出至少几百 MB 再装 |

装好之后还有两件事建议顺手做：

- **装在手机内存里**：KLWP 要在每次开机后常驻渲染壁纸，装到 SD 卡容易出现重启后壁纸失效（排查方法见[常见问题与排查.md](常见问题与排查.md)）；
- **别急着从零搭**：先加载一个内置预设看看效果，比对着空编辑器上手快得多，流程见[入门使用教程.md](入门使用教程.md)。
