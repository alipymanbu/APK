# KLWP 常见问题与排查

> KLWP 用起来最常撞上的几件事：重启后壁纸变回系统默认、耗电明显、导入预设没反应、天气不更新、桌面卡顿。按现象对号入座。

## 一、重启手机后壁纸变回系统默认

这是 KLWP 被系统在开机时「优化」掉的典型表现。动态壁纸靠 KLWP 常驻渲染，系统把它当后台杀掉，壁纸就跟着没了。逐项处理：

1. **确认应用装在手机内存**，不是 SD 卡（移动到内部存储）；
2. **关掉对 KLWP 的电池优化**：系统设置 → 应用 → KLWP → 电池，选「不受限制/不优化」；
3. **国产 ROM 再加一步自启动白名单**：MIUI、EMUI 等的「自启动管理」里把 KLWP 打开；
4. **别用一键清理**类工具扫后台，KLWP 被清一次壁纸就可能失效一次，重设一遍即可恢复。

按上面做完仍复发，多半是 ROM 的激进省电策略，到对应品牌的省电/后台设置里再查一遍。

## 二、耗电快

动态壁纸是持续刷新的画面，耗电天然比静态壁纸高，但幅度取决于你让壁纸干多少活。减耗电的顺序按性价比排：

| 手段 | 效果 |
| --- | --- |
| 减少循环动画的数量与复杂度 | 最明显，动画是持续重绘的 |
| 关掉陀螺仪视差类效果 | 手机一动就重算，费电且费性能 |
| 图片压小再用 | 大图每次合成都慢 |
| 天气刷新间隔调长 | 少一些定位与联网动作 |

改完用系统自带的耗电排行对比一两天的变化再决定要不要继续删元素。

## 三、桌面滚动卡顿、掉帧

和耗电同源：层数太多、大图太多、滤镜叠加太厚。优先精简 Items 里不常看的层，把装饰性元素合并；多屏壁纸只保留必要的数据显示。低端机上，把动态效果整体收敛后流畅度提升立竿见影。

## 四、导入 .klwp 预设没反应

最常见原因是**免费版不支持从存储导入预设**，这不是故障——「导入/导出预设」是 Pro key 的功能，Pro key 是官方单独发售的授权应用，装上后免费版自动识别。买不买、怎么导入的完整流程见[预设怎么导入与导出.md](预设怎么导入与导出.md)。

已装 Pro key 仍导入失败时再查两点：文件是否下载完整（对一下文件大小）、`.klwp` 文件是否被下载 App 自动改了后缀名。

## 五、天气不更新或显示空白

1. 到系统设置里确认 KLWP 有**定位权限**与后台联网权限；
2. KLWP 编辑器根设置里有 Weather 一节，检查天气源与刷新间隔是否被改过；
3. 刚改完设置不会立刻刷新，等下一个刷新周期或重启一次壁纸看效果。

## 六、编辑器里显示 `#ERROR`

公式写错了：括号不配对、函数名拼错、引号用了中文引号都会报。排查思路见[公式与全局变量入门.md](公式与全局变量入门.md)的最后一节。

## 七、想换回静态壁纸

长按桌面空白处 → 壁纸 → 从系统壁纸或相册里另选一张即可；确认不再用了再把 KLWP 卸载，导出过的预设文件仍在你手机存储里，重装后还能导回来。
