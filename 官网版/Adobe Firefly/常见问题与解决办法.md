## 一、支持哪些图片格式与规格

按官方技术要求页整理（页面会更新，以当时显示为准）：

| 用途 | 支持情况 |
| --- | --- |
| 上传：生成式填充 | JPG、PNG、WebP |
| 上传：文生图的构图/风格参考 | JPG、PNG、WebP |
| 下载导出 | JPG、PNG |
| 下载最大分辨率 | 2000×2000 像素 |

上传图打不开、传不上去，先对照左列核格式；下载后觉得不够大，是上表的分辨率上限，不是你手机的问题。

## 二、界面语言与提示词语言

- **提示词想写什么语言写什么**：官方说明 Firefly 能理解多种语言的提示并照常生成；
- **界面语言**：官方页面列出的包含英语、法语、德语、西班牙语、葡萄牙语、日语、韩语等，另有页面把简体/繁体中文等列入更长的清单 —— 两边口径不完全一致，你手机上实际能看到哪些，以设置里的列表为准；
- 界面不是中文时：生成操作照 [图片与视频生成怎么用.md](图片与视频生成怎么用.md) 的图标顺序走即可，菜单本身不影响功能。

## 三、手机上做的东西，电脑上找不到

作品与积分挂在同一个 Adobe 账户上：只要几端登的是同一账号，生成历史、项目、偏好会在网页版与移动版之间同步 —— 手机生成的图，去 [firefly.adobe.com](https://firefly.adobe.com/) 的「文件/项目」里能看到；反过来也一样。看不到时按顺序查：

1. 是不是登了两个不同的账号（第三方登录与邮箱登录可能各是一个号）；
2. 手机是否刚生成完还没上传完（等进度走完）；
3. 网络是否稳定 —— 登录、生成、同步全靠联网，断网时本地看不到云端内容。

## 四、生成的图能不能商用

- 用 Adobe 自家 Firefly 模型生成、且功能没有 Beta 标记的输出，官方口径是**可用于商业项目**；Beta 功能按其页面标注为准；
- Adobe 模型的训练数据口径为「授权内容 + 已过版权保护期的公有领域内容」，且会给生成内容自动附上 **Content Credentials**（内容凭证），标明 AI 生成属性；
- 用第三方合作模型生成时，权利口径以该模型在 Firefly 内的说明为准，商用前看一眼对应条款。

## 五、报错、闪退、更新类问题

| 现象 | 先查什么 |
| --- | --- |
| 登录页反复失败 | 不是本篇范围，直接走 [登录不了怎么办.md](登录不了怎么办.md) |
| 「无法访问 Firefly」类限制提示 | 账户违反使用条款或所在地区不在服务区，判断依据见登录篇第五节 |
| 生成按钮点了没反应 / 次数莫名变少 | 免费额度每日有限、积分按月重置，见 [生成式积分与订阅价格.md](生成式积分与订阅价格.md) |
| 安装失败、解析包错误 | 系统版本低于 Android 10、安装包没下完整（核 MD5），见 [下载与安装教程.md](下载与安装教程.md) |
| 闪退、卡在启动页 | 机身内存不足 3GB、系统过旧、安装包与系统不兼容；清后台、升级系统后重装 |

版本号方面，网盘里那份包是 25.05.29；官方商店会持续更新，装新包时以商店或官方页面当时显示的版本为准。
