## 一、先确认自己是哪个版本

网盘里这份是 **1.9.6**，包名与体积的核对表在 [下载与安装教程.md](下载与安装教程.md) 第二节。版本不一致会导致无法联机，开黑前先对一下版本号（见 [联机组队教程.md](联机组队教程.md)）。

官方在 [kokots.com/the-phenomenon-release-notes.html](https://kokots.com/the-phenomenon-release-notes.html) 维护发布说明，各版本的最终条目以该页面为准；下面是帮你快速定位的摘要。

## 二、联机能力是哪几个版本攒出来的

这作从单机一路长出来，联机相关的里程碑都在 2022 年：

| 版本（2022 年） | 加入的东西 |
| --- | --- |
| 1.8.3 | 游戏重制，**跨平台多人**加入 |
| 1.8.6 | **创建 / 加入游戏**的选项出现 |
| 1.8.7 | **多人合作模式**加入 |

也就是说「房主建房 + 好友输代码进来」这套流程是后续版本才有的——网上早期（2018 年前后）的单机攻略不会提联机，是正常的。

## 三、近期版本（1.9.4~1.9.6）改了什么

截至 1.9.6，这一段更新集中在这几件事上（不同来源对个别条目的版本归属标注不一，故按主题归并，逐条归属以官方发布说明为准）：

| 更新 | 对你的实际影响 |
| --- | --- |
| 新增日期系统 | 对应攻略里的「一局 5 天」流程，天数推进从此有界面依据（规则见 [许愿瓶收集通关攻略.md](许愿瓶收集通关攻略.md)） |
| **多人游戏支持存档** | 早期联机进度不保存，更新后可续打；以实际进房界面为准 |
| 优化门的逻辑 | 开关门、门禁判定更顺，绿卡开门的坑变少 |
| **移除补给系统** | **旧攻略里提到的「物资/补给」在现版本已不存在**，照着找会扑空——以抽屉与刷新道具为准 |
| 新增 FPS 与 ping 显示 | 联机卡顿时先看 ping 分辨是网络还是性能（用法见 [画面与操作设置指南.md](画面与操作设置指南.md)） |
| 改进结局场景 | 通关闭幕的演出调整 |
| 新增帧率限制设置 | 可锁帧换发热与流畅度的平衡 |
| 持续修复漏洞 | 各版本均有，不必逐条追 |

## 四、旧攻略对不上时怎么办

- 玩法类攻略（瓶子数量、鬼的机制、道具用法）大多仍适用，见 [许愿瓶收集通关攻略.md](许愿瓶收集通关攻略.md) 与 [道具使用与鬼魂应对.md](道具使用与鬼魂应对.md)；
- 涉及**具体选项、系统、界面**的描述，先对照本篇确认该功能是哪个版本加的、或是否已被移除；
- 网上还有体积、包名与本套文档完全不同的同名包（版本号也各不相同），别拿它们的版本号来对照——核对基准以 [下载与安装教程.md](下载与安装教程.md) 的表为准。
