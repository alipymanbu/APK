## 一、通关目标与地图结构

一句话目标：**搜遍抽屉，集齐 14 个许愿瓶，带回一楼电梯间撤离**。瓶子分布是固定的两层各 7 个；地图整体呈「8」字形、分上下两层，你出生在「8」字中间的一楼电梯间——那是绝对安全区，鬼进不来，也是你每次休整与撤离的地方。

推进顺序被门禁卡卡着：

1. 开局只能在一楼活动；
2. 找到**绿色门禁卡**才能解锁二楼，入口在**电梯左手直行**处；
3. 两层都有大量抽屉，需要逐个翻查，联机时可分工扫楼。

绿卡刷在哪，几份玩家攻略说法不一：一说在一楼抽屉与办公室，一说高概率在二楼的 C 区走廊、A 区过道。**两边都翻一遍最稳妥**，反正抽屉迟早都要搜。每局的房间连通方式与道具位置会随机变化，背板作用有限，路线要临场规划。

另外，旧攻略里若提到「补给 / 物资系统」，该系统已在近期版本被移除，照着找会扑空；房间里的门与门禁逻辑也在更新中改过，与旧攻略描述有出入时以现版本为准——版本层面的差异统一见 [版本更新日志速览.md](版本更新日志速览.md)。

## 二、五天流程与死亡规则

这是最容易翻车的一节，规则先记牢（「5 天」这套推进方式与近期加入的日期系统是一体的，见 [版本更新日志速览.md](版本更新日志速览.md)）：

| 规则 | 内容 |
| --- | --- |
| 流程天数 | 一局共 5 天 |
| 每日死亡次数 | 每天可死 1 次；当天已拾取的瓶子能延续到次日 |
| 第二次死亡 | 当日第二次死亡直接结束本局 |
| 瓶子继承 | 已带回电梯的瓶子才作数；当日时长结束时没带回的瓶子无法继承 |
| 瓶子位置 | **未拾取**的瓶子在本局内位置固定，开新对局才重新随机刷新 |
| 憋气 | 人物最多憋气 2 次，用完要等恢复，别在鬼脸前耗光 |

多份攻略给的稳妥节奏是：**每天收集 3 个瓶子、单日游玩控制在 20 分钟左右**，稳比快重要——死一次就少一天，死两次整局作废。

## 三、一楼推进打法

1. 出生后别急着乱跑，先在**电梯旁放一个摄像头**，再在 A/B/C/D 区里挑两个区域摆上扫描仪，扫不到瓶子就换位置再摆；
2. 盯着监控预判鬼的动向，**鬼在哪个区就反向搜哪个区**；鬼会主动破坏你的设备，可以利用这一点把它牵制住，自己迂回搜集；
3. 每集齐 **2 个瓶子就回电梯休整一次**，迷路了看电梯旁摄像头辨方向；
4. 遭遇贴脸时按 [道具使用与鬼魂应对.md](道具使用与鬼魂应对.md) 里的自保手段脱身，手里有瓶子时更要小心——被抓会掉落，得重捡；
5. 搜到绿色门禁卡后，从电梯左手直行的入口上二楼。

## 四、二楼推进打法

1. 二楼同样是 7 个瓶子，先在**二楼中央放摄像头**；
2. 上楼前在一楼楼梯口观察鬼的位置，再反向迂回探索，**搜完一个区就挪位置**，别久留；
3. 二楼的怨灵会瞬移、正面遭遇基本秒杀：看到它的背影就立刻开自保手段并向反方向撤离，不要站着观察；
4. 当天在二楼被淘汰，**已拾取的瓶子仍会保留**，补充进度继续即可。

## 五、撤离

14 个瓶子全部到手后，回到一楼电梯间即可撤离、完成通关。带瓶子的路上被鬼抓到会掉瓶子，宁可绕远也别抄近道贴脸过。

## 六、联机时的分工

和好友开黑（怎么开局见 [联机组队教程.md](联机组队教程.md)）时，规则变成团队资源：多人模式只有两条命、携瓶者被抓全员受损，所以有人专职布置监控、有人分片搜抽屉、有人断后最有效率；瓶子按区收集，集中的路线减少暴露面。单人与联机的地图规则完全一致，只是容错率不同。
