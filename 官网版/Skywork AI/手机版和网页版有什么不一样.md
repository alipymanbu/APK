# Skywork AI 手机版和网页版有什么不一样

> 同一个账号，手机与电脑上能做的事并不相同。本篇讲清两端的分工，别在手机上硬做该在电脑上做的活。

Skywork AI 有手机应用、网页版工作区，以及面向 Windows 的桌面客户端。三者不是「功能不一样的产品」，而是同一套能力的不同入口，用同一个账号登录、内容互见。区别在于：输入方式、屏幕空间、能处理的任务体量。本篇给你一份分工表，以及常见的「换端后找不到东西」怎么排。

## 一、两端能力对照

| 事项 | 手机应用 | 网页版工作区 |
| --- | --- | --- |
| 用同一个账号 | 是 | 是，内容互见 |
| 发需求、看结果 | 适合 | 适合 |
| 录音转写 | 主要入口，随身录更实用 | 可以上传音频文件 |
| 传参考文件 | 受手机文件管理限制 | 更方便，可批量 |
| 编辑幻灯片 / 表格 / 网页 | 能看、能小改 | 分屏编辑、逐元素调整、版本回退都在这里 |
| 发布网页、绑域名 | 不涉及 | 发布与域名设置只在网页版 |
| 长文档与多产物任务 | 能跑，但盯着改不方便 | 更适合 |
| 任务历史与产物管理 | 有 | 更完整 |
| 桌面客户端 | — | Windows 端另有客户端，官方说明需对应档位会员，以官方页面为准 |

一句话概括分工：**手机上负责「录进来」和「看一眼」，电脑上负责「改到能用」。**

## 二、手机上适合做的四件事

1. **随手发一个短任务**，等结果，满意就收下。
2. **录音转写**：开会、听课、临时访谈这类只能当场录的场景，手机是最顺手的入口（电脑上录完再上传也行），方法见 [录音转写与语音笔记怎么用.md](录音转写与语音笔记怎么用.md)。
3. **在已有任务里补一句话**，比如把某个部分再压缩一半。
4. **查看与轻量分享**：把产物下载下来发给别人，或先看一眼进展。

## 三、留到电脑上做的四件事

1. **多份材料的对比整理**，一次传多个文件、反复引用。
2. **幻灯片的排版与页序调整**，小屏幕上看不出整体节奏。
3. **表格的公式与结构改动**，手机上点选单元格很费劲。
4. **网页类产物的反复预览**，在电脑上边改边看更直观。

网页类产物还有一步只能在网页版做：把它「发布」出去，别人才访问得到；绑自己的域名同样只在网页版，步骤见 [生成的网页怎么发布和绑域名.md](生成的网页怎么发布和绑域名.md)。

## 四、换端之后找不到东西怎么办

- **先确认账号一致**：两端必须登录同一个账号，用不同方式登录（比如一边用邮箱、一边用第三方账号）偶尔会落到不同账号上。
- **刷新、别急着重发**：刚在手机上提交、马上开电脑看，列表可能还没刷出来。刷新一次再判断，不要重复提交同一个任务，那会白花一份额度。
- **任务有没有在跑，看任务列表状态**：状态长时间不动才是卡住，处理办法见 [常见问题与排查.md](常见问题与排查.md) 第四节；超出同时登录设备数、或额度被限制，见 [积分和会员怎么算.md](积分和会员怎么算.md) 第四节。
