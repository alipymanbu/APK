# Skywork AI 怎么用一句话生成文档和幻灯片

> 从一句需求到一份能交出去的文档、表格或幻灯片，本篇讲清中途你要做哪几步、产物能不能改。

Skywork AI 的用法和普通聊天式 AI 不一样：聊天式 AI 给你一段文字，Skywork AI 给你一个文件。你说明需求，它按任务类型挑对应的智能体去干活，最后交付文档、幻灯片、表格、图片、网页、播客、视频这些成品。本篇讲的就是这条「一句话进、成品出」的路径，以及中间你该盯什么。

## 一、它会给你什么

官方帮助中心列出的能力分这几类，产物形态不一样，提需求时要的措辞也不一样：

| 任务类型 | 常见产物 | 你在什么场景会用到 |
| --- | --- | --- |
| 通用工作区 | 由任务自行决定 | 一句话里有多个目标，说不清该归哪一类 |
| 文档 | 可下载的文档文件 | 报告、方案、文章、调研整理 |
| 幻灯片 | 可编辑的演示文件 | 汇报、提案、把已写好的文档转成演示 |
| 表格 | 表格文件与图表 | 数据整理、对比、简单测算 |
| 图片 | 图片文件 | 配图、海报、图示 |
| 网页 | 可访问的页面 | 落地页、活动页、简单站点 |
| 视频 / 播客 | 视频、音频文件 | 口播、配音、把材料转成音频节目 |

不知道该选哪一类时，就走**通用工作区**，让它自己决定拆成哪些产物；需求明确（比如「要一份能下载的演示文件」）时，直接点名对应类型，返工更少。

调研类产物会在正文里带上可点的来源标注。**有来源不等于结论就对** —— 怎么核出处见 [生成的内容怎么核对来源.md](生成的内容怎么核对来源.md)。

## 二、把需求说清的四个要素

产出的质量几乎全取决于你给的输入。一条能用的需求通常包含这四件事：

1. **给谁看**：内部对齐、客户提案、公开发布，决定语气与详略。
2. **要什么形态**：「一份文档」「一页演示」「一张对比表」，说清是文件还是答复。
3. **范围与边界**：时间跨度、地区、只讲哪几点、不要写什么。
4. **长度与结构**：几页、几个部分、要不要放数据表格。

例如：「给公司内部做一份 AI 办公工具的对比材料，只比文档生成和幻灯片生成两项，不要推荐结论，输出一份能下载的文档，控制在两页以内。」

反过来，「帮我写点关于 AI 的东西」这类需求，它会用追问的方式补信息，或者给你一个泛泛的结果 —— 两种情况都要多花一轮。

以幻灯片、网页这类任务为例，提交前输入框下方还有几个可调项，先设好能少返工：

- **视觉风格**：自动、创意、偏调研几种取向，按交付对象挑；
- **篇幅**：不限、限定在若干页以内、或指定区间；
- **模型**：可以指定由哪个大模型来跑，留默认则由系统按任务类型分配。

另外，任务跑到一半时它可能先把大纲给你确认再往下做。**这是人把关成本最低的位置**，别直接跳过 —— 结构错了，后面全要返工。

## 三、一次完整操作长什么样

1. **在输入框写下需求**，需要参考材料时同时把文件传上去（单次任务能带多少文件、单个文件多大，见 [积分和会员怎么算.md](积分和会员怎么算.md)）。
2. **提交后等它跑**。它在这段时间里联网查资料、梳理结构、生成产物。跑得久不代表卡住；判断卡住的办法见 [常见问题与排查.md](常见问题与排查.md) 第四节。
3. **中途它可能反问**。信息不够时它会给你几个选项让你确认，选完它继续跑，不要关掉页面。
4. **拿到产物后先看结构再看细节**：目录/分页/表头对不对，比抠字句更值得先花时间。
5. **不满意就继续提要求**：在同一个任务里说清改哪里（「第三部分压缩到一半」「表格加一列环比」），不要另起一个新任务重做。

## 四、产物能不能直接用

生成只是起点，多数成品要改一轮。以幻灯片为例，工作区里提供这几层改法，按改动大小选：

| 改动大小 | 怎么改 |
| --- | --- |
| 整页重做 | 悬停该页，选重新生成这一页 |
| 整页按你的话改 | 悬停该页，选自定义改写，把要求写进弹窗 |
| 只改一个文字框、图片或图标 | 直接在画布上点中它 —— 调字体字号颜色、拖动位置、调前后层级、单独删除 |
| 改错了想退回 | 用撤销 / 重做 |
| 想拿回上一个版本 | 画布下方有版本滑块，可在多次生成结果之间切换 |

想要可编辑的原始文件，就在需求里说清要哪种格式：拿到可编辑的幻灯片或表格文件后，你可以在本地接着改；只要图片或 PDF 的话，后续小改动都得回到工作区重跑。

导出与打开时文件不对、或手机上打不开的问题，见 [常见问题与排查.md](常见问题与排查.md) 第六节。

## 五、手机上做还是留到电脑上做

手机上适合发短需求、看结果、临时改一句话；长文档的排版、幻灯片的分页调整、批量文件处理，在电脑上做会顺得多。如果产物是网页，还要经过「发布」这一步别人才访问得到，步骤见 [生成的网页怎么发布和绑域名.md](生成的网页怎么发布和绑域名.md)。两端分工见 [手机版和网页版有什么不一样.md](手机版和网页版有什么不一样.md)。
