# Skywork AI 常见问题与排查

出问题的时候，先分清是「装错了客户端」「网络到服务端不通」「账号被限制」还是「任务本身跑得慢」—— 这四类的处理方式完全不同。本篇按现象分类，每条给出原因与下一步动作。

## 一、先确认装的是这个应用

同名软件不少，装机前后都值得核一次，最靠得住的是包名：

- 包名应为 `ai.skywork.app.android`；
- 安装包体积 50.07 MB，MD5 是 `60361E13F31E942A263EF187D26F24BE`。

装完之后在「设置 → 应用 → 全部应用」里找到它，进「应用信息」页，部分系统能直接看到包名，看不到的用一个应用信息类工具查。包名对不上，说明你装的是另一个同名软件，本篇后面所有条目都不适用 —— 换法见 [下载与安装教程.md](下载与安装教程.md) 第一节。

## 二、安装环节

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 安装包没下完整 | 从 [Skywork AI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/06b6ae0adfb2) 重新下载，再按第一节核对 MD5 |
| 提示「已阻止安装未知应用」 | 系统没给打开安装包的那个应用放行 | 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里打开对应开关 |
| 提示「应用未安装」 | 手机上已有同一包名的另一个签名版本 | 先卸载旧的再装 |
| 装完桌面没有图标 | 被归进应用抽屉，或安装其实没完成 | 去应用抽屉翻一遍；没有就重装一次 |
| 下载时要求输入手机密码 | 系统对非商店来源安装做的安全验证，不是应用要的 | 输一次即可；想少弹这一步，在设置里搜「验证」，把验证范围调窄 |

## 三、登录、账号与额度

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 收不到注册 / 验证邮件 | 邮件归到垃圾箱，或该邮箱拒收 | 先翻垃圾邮件与推广箱，再换邮箱重试 |
| 登录后内容是空的 | 落到了另一个账号上 | 确认两端用的是同一种登录方式与同一个账号 |
| 提示账号被限制 | 触发官方的使用限制条款 | 官方禁止共享账号、转售使用权、用程序批量抓取数据；认为是误判就走官网右上角的「Contact Us」联系官方 |
| 积分比预期少很多 | 任务复杂度高，或反复返工 | 见 [积分和会员怎么算.md](积分和会员怎么算.md) 第三节的省法 |
| 提示超出同时登录设备数 | 登录的设备超过了档位上限 | 在旧设备上退出登录，再登录新设备 |

## 四、任务发出去没反应或一直不动

先分清「在跑」和「卡住」：任务列表里状态还在变、或能看到中间进展，就是在跑，长任务跑得久是正常的。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提交后一直排队不动 | 同时进行的任务数到了档位上限 | 等前一个跑完，或先停掉一个不需要的；上限见 [积分和会员怎么算.md](积分和会员怎么算.md) 第一节 |
| 状态长时间不变、也没进展 | 网络中断或任务异常 | 换 Wi-Fi 与移动数据试一次；仍不动就重新提交该任务 |
| 中途弹出让你选一个选项 | 信息不足，它在向你确认 | 选一个继续，别关页面，否则任务停在那里 |
| 在手机上提交、电脑上看不到 | 列表还没刷新，或两端账号不同 | 刷新一次；仍没有就核对账号，别急着重复提交 |

## 五、录音与权限

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点录音没反应、只有转圈 | 没给麦克风权限 | 在「设置 → 应用 → Skywork AI → 权限」里打开麦克风 |
| 传文件时看不到要选的文件夹 | 没给文件/存储权限 | 同上路径，打开存储或文件访问权限 |
| 录完整段没有文字 | 录音期间退出了应用或断了网 | 保持前台并联网重录一次 |
| 说话人分不清 | 多人同时说话 | 让发言依次进行再录音；已有录音只能接受区分结果不准 |

## 六、导出与打开文件

- **产物下载不下来**：先确认网络稳定，再试从网页版的工作区里下载 —— 手机端在文件管理上更容易卡住。官方说明里文件下载是不限量项，卡住通常不是额度问题。
- **下载的文件电脑上打不开**：确认你导出的是可编辑的原始格式，而不是图片或 PDF；需要后续修改就重新导出成对应格式。
- **单个文件传不上去**：单个文件上限 50 MB，一个任务最多 50 个文件，超了要先压缩或拆分。

## 七、界面语言

官方列出的支持语言里包含中文；顺带说明，应用界面的语言由系统语言决定：

- 手机系统是中文时，它一般会直接显示中文界面；
- 想让它单独用某个语言，Android 13 及以上可以在「设置 → 系统 → 语言和输入法 → 应用语言」里为它单独指定；系统里没有这一项，就是该机型或该系统版本不支持逐应用设置。

界面还是英文、而系统确实是中文时，先把应用更新到较新版本再试一次。

## 八、产出找不到，或内容对不上

- **找不到刚生成的东西**：先在任务列表里打开那一条任务，产物挂在任务下面；换过设备的话，确认两端登录的是同一个账号。发布过的网页不在任务里找，在账号设置里的网站清单里。
- **本地相册 / 下载目录里没有**：产物默认留在工作区里，点下载才会落到手机存储；存储权限没给会导致下载失败，见第五节。
- **内容里的来源点不开、或看着对不上**：按 [生成的内容怎么核对来源.md](生成的内容怎么核对来源.md) 的三步核一遍；确认是错误引用，就在同一个任务里指出那一处让它重改，不必整篇重做。
- **产物要怎么变成别人能访问的网页**：那是发布环节的问题，见 [生成的网页怎么发布和绑域名.md](生成的网页怎么发布和绑域名.md)。
