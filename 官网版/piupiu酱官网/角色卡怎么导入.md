## 一、角色卡是什么

角色卡是这个应用的核心玩法单位：一张卡里写清角色的名字、性格、背景故事、口头禅、开场白，导入后 AI 就按这份「人设契约」扮演。你既可以下载别人做好的卡，也可以自己从零写一张。市面上流通的卡大多是通用格式，PiuPiu酱 兼容它们，不必担心导入后格式错乱。

## 二、导入外部角色卡

角色卡最常见的来源是压缩包（从角色市场或社区下载的「角色卡包」）。步骤：

1. 进入角色大厅，点页面**顶部的加号**按钮，调出功能菜单。
2. 选 **「导入角色卡」**。
3. 在文件列表里找到解压好的角色卡文件夹（卡包是压缩格式时，先用文件管理器解压，再回来导入）。
4. 进入文件夹后会看到角色分类，点进分类、再点目标角色的图片，弹出「导入成功」即完成。

如果手里只有**单张卡文件**（不在卡包里），还有一条更短的路：在手机文件管理器里直接点该文件、选择用 PiuPiu酱 打开，应用会自动完成注册。

**兼容格式**（截至 2026-09 的公开资料）：

| 格式 | 说明 |
| --- | --- |
| JSON 数据卡 | 文本形式的角色数据，社区分享最多 |
| TXT 文本卡 | 纯文本描述的人设 |
| PNG 图片卡 | Tavern Card V2 酒馆卡，数据藏在图片里，图片本身看不出内容 |

## 三、自己创建角色卡

不想用现成的，就捏一个属于自己的：

1. 角色大厅右上角点 **「+」→「创建角色卡」**。
2. 填写角色昵称、选择角色形象。
3. 编写故事背景与开场白 —— 这两项决定对话往哪个方向走，值得多写几行。
4. 点右上角 **「完成 / 保存」**，新角色会出现在角色大厅首页，点它即可开始聊天。

## 四、导入前值得知道的两件事

- **一张卡 = 一套人设**。同一角色导入两次会在列表里出现两份，不需要的那份删掉即可，不会影响聊天记录。
- **卡的来源要挑**。从你信得过的社区拿卡，导入前看一眼卡内文本有没有异常外链；遇到夹带引流或付费引导内容的卡，直接弃用。

导入完成后怎么配合模型、语音使用，见 [聊天功能怎么用.md](聊天功能怎么用.md)；导入后角色表现不对劲怎么处理，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
