# 角色卡导入失败怎么办

## 一、先做 30 秒自检

按顺序过一遍，多数问题在这一步就解决了：

1. **看文件大小**：正常的 JSON / TXT 卡是几 KB 到几百 KB；PNG 图片卡通常在 100KB~3MB。只有几十 KB 的「图片卡」多半已经丢了数据。
2. **用文件管理器选原文件**，不要从相册、聊天软件的预览图里选 —— 部分机型从相册取图会送出重新编码过的副本。
3. **换 JSON 版本重试**：同一张卡如果既有 PNG 又有 JSON，导 PNG 失败就换 JSON。
4. **简化文件名**：多个公开教程都提到，文件名带特殊符号会导致导入失败，把文件名改成纯文字后重试。

## 二、PiuPiu酱 侧的高频原因

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点导入后报错或无反应 | 文件损坏、格式不兼容 | 检查文件完整性，换一张卡验证是「这张卡的问题」还是「导入功能的问题」 |
| 导入卡顿、应用变慢 | 单次导入的卡体积过大（大世界书 + 高清立绘） | 拆分世界书、换小体积版本的卡 |
| 导入后列表里没出现 | 同名角色冲突 | 列表里已有同名角色时，先删旧的再导（酒馆类客户端的常见行为，可先试这一步） |
| 只想导世界书却混在卡里 | 卡与世界书是两回事 | 见 [世界书怎么用.md](世界书怎么用.md) |

## 三、传输环节把卡弄坏了（酒馆社区经验）

PiuPiu酱 兼容酒馆（SillyTavern 系）角色卡格式，所以酒馆社区踩过的传输坑对你同样适用：

- **聊天软件压缩图片**：微信、QQ 直接当「图片」发 PNG 卡，会重新编码并抹掉藏在图片元数据里的角色数据 —— 让对方以「文件」方式发送，或打包成 zip 传输。
- **另存时 JSON 乱码**：聊天软件转发 txt / json 后编码损坏，用文本编辑器打开看到乱码就是这个原因，重新拿一份原文件。
- **随手改了后缀**：`.png` 改成 `.json`（或反过来）不会转换格式，只会两头都不认。
- **下载到的是预览图**：浏览器长按保存的图可能是站点压缩过的预览，要点页面提供的下载按钮拿原文件。

**链路越短越安全**：下载到手机 → 文件管理器 → 导入，两步到位；中间每多经过一个应用，就多一次被转码的机会。

## 四、格式版本问题

酒馆卡规范有 v1 / v2 / v3 三代：v1 最老、字段少，部分客户端直接拒收；v2 是目前流通最广的；v3 新增多角色等能力。你手上是老卡导不进时，优先找该角色的 v2 版本。具体到 PiuPiu酱 支持到哪一代，公开资料没有明确口径 —— 实测以你的版本为准（网盘留档版 2.6.8）。

## 五、逐条排除后仍失败

把范围收窄到三选一，就知道问题在哪：

1. 换一张**确认没问题的卡**导入 → 仍失败，是应用侧（版本、缓存）问题：清缓存或重装，见 [常见问题与故障排查.md](常见问题与故障排查.md)。
2. 用**文件管理器打开同一张卡换一种导入方式**（直接点文件选「用 PiuPiu酱 打开」）→ 成功，说明原入口没识别这个文件。
3. 同一张卡在**另一台手机**上导入 → 也失败，说明卡本身有问题，回来源处重新下载。
