# ESHOW 演示者模式与投屏后台

> 本篇讲接收端那一头的管控功能：投屏码、主持人模式、在大屏上反向控制手机，以及怎么进投屏后台改设置。发送端 App 里找不到这些开关是正常的——它们都在投屏器一侧。

## 一、先分清开关在哪一头

投屏码、主持人模式、反控、热点开关，这些全部属于接收端（投屏器主机）的功能，手机上的 ESHOW 只负责连接与发送。所以：

- 你是临时演示的客人 → 这些开关与你无关，照[连接投屏器与投屏操作](连接投屏器与投屏操作.md)投出去就行；
- 你是会议室或教室这台投屏器的管理员 → 本篇就是给你的，多数设置在投屏后台或大屏上的管理菜单里完成。

## 二、投屏码与主持人模式

两类「防乱入」手段，对应不同的会议形态：

| 手段 | 行为 | 适合 |
| --- | --- | --- |
| 投屏码（连接密码） | 开启后，新设备连接前要先输入投屏码 | 防隔壁会议室误连，日常开会常开 |
| 主持人模式 | 其他设备允许连入，但大屏上显示哪一路画面由主持人主动控制切换 | 多人轮流发言、按议程控场的正式会议 |
| 锁屏审核 | 新设备要投屏需经当前使用者审核同意 | 与主持人模式类似，开关在投屏器上 |

两种码别搞混：投屏码由管理员在投屏器上设置，谁能连由管理员说了算；PIN 码则是投屏器连上大屏后直接显示在画面上的动态数字（见[连接投屏器与投屏操作](连接投屏器与投屏操作.md)第四节）。现场都是把当前有效的码报给参会者即可，不需要私下传。

## 三、在大屏上反向控制手机

接收端连的是触控大屏时，可以在大屏上反向操作已投屏的安卓手机、平板或 Windows 电脑——翻页、点按都不用回到座位拿设备。教室场景里老师站在大屏前直接批注、会议室里主讲人站定讲解，靠的就是这个。

反控不生效时按顺序核对：大屏确实是触控屏；反控权限在投屏器侧已允许；你投的是安卓设备或 Windows 电脑（这套反控不含苹果设备）。

## 四、进投屏后台改设置

WiFi 中转、画面旋转、组播这类设置都在投屏后台里改。官方给出的进入步骤：

1. 投屏器主机连上大屏，屏幕上会显示设备 IP 信息（官方示例为 `192.168.118.1`）；
2. 手机连上投屏器的热点（名称形如 `ESHOWxx`，默认密码 `12345678`）；
3. 手机浏览器打开上一步的 IP 地址，默认账号与密码均为 `admin`；
4. 进后台后按需设置，改完设备会自动重启，重启后设置才生效。

后台里常改的几项：

| 设置项 | 作用 |
| --- | --- |
| 连接路由器 WiFi | 输入路由器的 WiFi 名称与密码，让投屏器并入现有局域网 |
| 画面旋转 | 在画面显示设置里旋转 90° 或 270°，适配竖装的大屏 |
| 组播 | 开启后支持一对多投屏，一台源同发多块屏 |

后台能改的不止这些，具体以你手上投屏器的后台界面为准。改完设置连不上了，先重启投屏器，再走[常见问题排查](常见问题排查.md)。

## 五、关掉热点，只走路由器

演示者相关的设置里还有一项：关闭 DHCP 后，其他设备将搜不到投屏器的 WiFi 热点。适合投屏器已插网线并入局域网、不再需要热点直连的固定会议室——现场少了一个人人可连的免费热点，连接方式统一走路由器（组网方式对照见[连接投屏器与投屏操作](连接投屏器与投屏操作.md)第二节）。需要注意关掉之后，临时访客的手机若不能上同一局域网，就连不进来了。

整套软硬件的搭配关系与版本要求，见[适用设备与搭配](适用设备与搭配.md)。
