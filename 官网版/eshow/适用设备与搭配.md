## 一、先分清发送端与接收端

ESHOW 在整套方案里只承担「把画面发出去」这一半，画面要上大屏，还得有接收端：

| 角色 | 是什么 | 例子 |
| --- | --- | --- |
| 发送端 | 装在你手机或电脑上的软件 | 本文的安卓版 ESHOW、Windows 版 ESHOW |
| 接收端 | 接在大屏上的硬件 | AWIND 奇机 A 系列无线投屏器（官方称覆盖 A100 至 A900 各型号）、内置 ESHOW 接收端模块的会议一体机 |

所以装好应用却搜不到任何东西，先别怀疑手机——现场得真的有一台配套的接收端盒子接在大屏上。这也解释了它与家用投屏 App 的区别：它面向的是会议室、教室这类「接收端固定装好、发送端人来人往」的场景。

## 二、各平台的搭配情况

| 平台 | 有无 ESHOW | 投屏方式 |
| --- | --- | --- |
| 安卓手机 / 平板 | 有（本套文档的主角） | 安装后扫描接收端镜像投屏 |
| Windows 电脑 / Surface | 有 | 装 Windows 版，或直接用 USB 按键 |
| iPhone / iPad / Mac | 无 | 系统自带「屏幕镜像」（AirPlay）连接收端 |

安卓侧还有一个不装任何 App 的备选：部分接收端支持 Miracast，手机自带的「无线投屏」开关（一般在设置的连接类菜单里）也能直接连。接收端不支持 Miracast 时，就需要 ESHOW 这类发送端；PIN 精准投屏、设备备注、锁屏审核这些会议室向的功能，也只有通过它才能用上（见[连接投屏器与投屏操作](连接投屏器与投屏操作.md)）。

## 三、Windows 电脑这一侧怎么投

虽然本套文档围绕安卓版展开，同场的 Windows 设备常需要一并交代：

- **常规方式**：官方给每台投屏器配的 USB 按键，插上电脑、按一下即投；
- **没有按键时**：在电脑上装 Windows 版 ESHOW 当发送端，与接收端同网即可；
- **台式机没有 WiFi**：给投屏器插上网线接入局域网，电脑也走有线，同样能配对；
- **注意电脑状态**：电脑睡眠或锁屏时，装在它上面的 ESHOW 也一起待机，投不出去——遇到「PC 连不上」先看电脑是不是睡着了。

官方还提供过一个把 ESHOW 程序放进 U 盘、插哪台电脑用哪台的便携玩法；首次在别的电脑上运行时可能要装驱动、在杀毒软件里放行，属一次性成本。

## 四、「一键联主机」是怎么回事

较新的主机软件（官方说明为 V2.5.0 及以上）支持「一键联主机」功能，安卓版 ESHOW 的更新日志里也加入了对它的支持。能否用上取决于接收端那头的主机软件版本，发送端这边把应用更新到较新版本即可。具体开关位置以你手上设备的管理界面为准。

一台接收端、一部手机加一份安装包，就能把整套东西跑起来——安装包获取见[下载与安装教程](下载与安装教程.md)，跑不通的先去[常见问题排查](常见问题排查.md)。
