## 一、先确认你要装的是哪一版

ESHOW 有安卓版和 Windows 版两个发送端，两者不能混用安装包：

| 版本 | 适用设备 | 说明 |
| --- | --- | --- |
| 安卓版（本篇） | 安卓手机、平板 | 就是包名为 `com.eshow.sender` 的 APK |
| Windows 版 | Windows 电脑、Surface | 从奇机官网获取，另有 USB 按键方案 |

苹果手机、平板、Mac 上没有 ESHOW 版本，Apple 设备直接用系统自带的「屏幕镜像」（AirPlay）连接同一套投屏器即可，见[常见问题排查](常见问题排查.md)里的说明。

## 二、获取渠道

按官方公开的说法，安卓版可以从这几个渠道拿到：

| 渠道 | 入口 | 特点 |
| --- | --- | --- |
| 奇机官网 | [www.awind.com.cn](https://www.awind.com.cn) → 资料下载 → 发送端 → ESHOW 安卓同屏软件 | 官方直出，版本以官网当时显示为准 |
| 华为应用市场 | 应用市场内搜索 ESHOW | 华为手机较方便 |
| 应用宝 | 搜索「ESHOW投屏」 | 小米等其他安卓机可用 |
| 大屏扫码 | 投屏器连上大屏后，待机画面上一般有下载二维码 | 现场装机最快，扫出来的是配套版本 |

如果你手头已经有上面那个夸克网盘里的安装包，直接跳到下面的安装步骤即可。外面应用市场给出的版本号往往比这份包更新（应用市场随官方节奏滚动更新），版本对不上不影响理解本套文档的操作步骤，但**涉及版本号、包名、体积时以本地安装包为准**。

## 三、安装步骤

1. 从上面任一渠道拿到 APK 文件；走网盘的话，先转存 [ESHOW 安装文件资源（夸克网盘）](https://pan.quark.cn/s/aae76fde6598) 再下载到手机存储。
2. 在文件管理器里点开 APK。首次安装第三方包时，系统会提示「允许安装未知应用」，按提示允许对应来源即可。
3. 等待安装完成，打开应用。
4. 首次使用会请求相关权限：推送本地视频、照片依赖存储读写权限；官方说明里提过还会用到摄像头权限（不同版本请求的权限略有差异），按需允许即可。
5. 确保手机与投屏器接收端处于同一网络（两种组网方式见[连接投屏器与投屏操作](连接投屏器与投屏操作.md)），启动应用扫描设备。

安装过程中如果遇到问题，转到[常见问题排查](常见问题排查.md)。
