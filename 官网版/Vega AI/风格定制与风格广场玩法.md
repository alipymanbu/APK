## 一、风格定制适合谁

你在 [文生图与图生图操作指南.md](文生图与图生图操作指南.md) 里会发现，选风格只能用现成的那几个。如果你想要的是「我自己 / 我家猫 / 我的公司 IP 形象 / 我常用的那种画风」这种市场上没有的风格，就得自己训一个。训练一次，之后在文生图、图生图里都能反复调用这个风格。

## 二、训练自己的风格模型

### 准备图片（决定成败的一步）

| 项目 | 建议值 |
| --- | --- |
| 数量 | 至少 8 张起步；社区实测 25 张以上效果明显更稳，上限约 100 张 |
| 分辨率 | 每张 512x512 像素以上 |
| 内容一致性 | 同一个人 / 同一种画风 / 同一类物体，别混着来 |
| 画质 | 清晰、无水印、主体够大，小头像式的图贡献不了多少信息 |

用你自己生成的图来训完全可行：在文生图里固定同一套描述多跑几张，攒够数量就是一份不错的训练素材。

### 训练操作

1. 在创作界面找到**风格定制 / 训练**入口；
2. 把准备好的图片批量上传；
3. 给风格起个名字（之后调用时靠它认）；
4. **选基础模型**——这一步影响最大：真人选「写真」，卡通形象选「3D 二次元」或「虚拟建模」，选错基础模型，训练出来的风格会跑偏；
5. 点开始训练，然后等。训练不是秒完成的，通常几十分钟到一两个小时（也有 3 小时左右的实测案例），期间你可以正常去做别的操作，训练完成后会有提示，新风格出现在风格列表里。训练页若提供「迭代步数 / 学习率」这类选项，社区教程的口径是把它们调高，训练出的风格会更贴近你上传的素材。

### 训练效果的调法

训练完成后第一次用，把**风格强度**从低到高各试一次：强度高画面更像你的训练图但容易僵，强度低更自由但风格感弱。另外训练素材的质量上限就是风格的上限——素材糊、杂、少，调参数救不回来，回头补图重训一遍更划算。

## 三、风格广场：直接用别人的成果

不想自己训、或想先看看别人都在做什么：

1. 进入**风格广场**（社区风格的集中页）；
2. 浏览别人分享的风格，看到顺眼的点「采用 / 收藏」；
3. 收藏后的风格会进入你的风格列表，回创作界面就能像内置风格一样调用；
4. 你自己训好的风格也可以分享上去，供别人采用。

一个省事的路子：在风格广场找一个接近你想要的方向的风格先跑几张，不满意的地方再用图生图局部修改，比自己从零训模型快得多。

## 四、一个完整案例：毛坯房效果图

有用户分享过一条跑通的完整流程，可以作为「风格广场 + 图生图」组合的参考：

1. 在风格广场搜索「室内设计」，选一个合适的风格点采用；
2. 回到图生图，上传**正面拍摄**的毛坯房照片（拍摄角度歪了效果会打折）；
3. 写一句渲染方向（比如装修风格与空间类型），点生成；
4. 画面不贴合时把风格强度、叠加强度拉满，配合步数与文本强度一起调（各参数含义见 [提示词写法与参数调整.md](提示词写法与参数调整.md)）。

同样的「采用风格 → 图生图」套路可以平移到换装、换头像、产品图换背景这类任务上。

## 五、训练中的常见疑问

- **训练要多久？**几十分钟到两小时都正常，和排队人数有关，不是卡死；
- **训练期间能关应用吗？**可以，训练在账号侧进行，重新登录回来照样继续；
- **能训几个风格？**可以训多个，不同主体（人 / 画风 / 物件）各训各的，互不干扰；
- **为什么我的风格用出来不像？**九成是素材问题（数量少、不清晰、主体不一致），先补素材重训，再考虑调风格强度。
