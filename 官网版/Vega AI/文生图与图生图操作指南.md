## 一、先认一眼工作台

登录后进入创作界面，你会用到这几块东西（不同版本入口名称略有差异，以应用内实际显示为准）：

- **创作方式**：文生图、图生图等选项，决定这次用什么方式出图；
- **基础模型**：决定整体画风的大方向，是所有生图操作的「底色」；
- **风格**：在基础模型之上叠加的具体画风，可以不选；
- **描述输入框**：你想要什么画面，用文字写在这里；
- **生成按钮**：参数都定好后点它，等几秒到几十秒出图。

## 二、文生图：从一句话到一张图

### 第 1 步：选基础模型

基础模型选错了，后面怎么调都不对味。常用场景对照：

| 基础模型 | 适合做什么 |
| --- | --- |
| 写真 | 真人照片感的人像、写真、cos 类画面 |
| 虚拟建模 | 有光泽感的虚拟人、产品、物体 |
| 二次元 | 平面感的动画人物、插画场景 |
| 3D 二次元 | 立体质感的动画人物、游戏角色、盲盒风 |
| 真实影像 | 宠物、电影感画面、工业与包装设计 |

### 第 2 步：选风格（可选）

风格是叠加在基础模型上的具体画风。不选也能出图，选了画面会更统一。风格强度数值越高，画面越贴合所选风格的特征；数值低则风格淡、你文字描述的话语权更大。刚上手建议从 0.5 左右试起，两头各试一次就知道自己喜欢哪边。

### 第 3 步：写描述文案

描述写「谁 + 在哪 + 在做什么 + 什么氛围」就够用，例如「一个穿晚礼服的模特戴着黑色手套，在镜头前摆姿势」。几个实用习惯：

- 中文直接写即可，不需要翻译成英文；
- 主体放句首，越重要的词越靠前；
- 想要什么就写什么，比写「不要什么」有效；
- 没思路时用输入框附近的推荐文案，点一下就能填进来改。

### 第 4 步：定尺寸和张数，点生成

图片尺寸提供 512x512、512x682、512x768 这类常用分辨率，手机上看随意、打算做成壁纸就选竖版；一次生成张数可选 1~4 张，探索阶段选 4 张一次挑，省钱省时间。

点生成后等几秒到几十秒，出图不满意就改文案重跑——同一个描述多刷几次，每次结果都不一样，这是正常现象不是故障。

## 三、图生图：在原图基础上改

适合「我有张图，想换风格 / 换局部」的场景：

1. 选**图生图**，上传一张清晰的图片（截图、压缩过头的图效果会打折）；
2. 用画笔涂抹想被改动的区域——只涂脸就是换脸式改写，涂大块区域就是大改；
3. 选基础模型和风格（思路同上文生图）；
4. 简单写一句你想要的画面方向；
5. 点生成，等十几秒左右出新图。

两张思路可以直接串着用：先用文生图刷一张满意的底图，再把它丢进图生图里精修局部，比一次到位更容易出效果。

## 四、出图之后

- **高清放大**：点开图片后的 HD / 高清相关按钮可以把图优化到更高分辨率（可到 2K、4K 档，具体档位以应用内为准），要打印或商用前都建议先放大一遍；
- **历史记录**：生成过的图会自动留在历史记录里，关掉应用也不会丢，随时能回去重新查看或再次编辑；
- **保存**：长按或点下载按钮存到手机相册，之后想训练自己的风格模型，用的就是这些图，见 [风格定制与风格广场玩法.md](风格定制与风格广场玩法.md)；
- **继续调优**：描述词写法、普通/高清模式怎么选、步数与采样器这些高级参数，见 [提示词写法与参数调整.md](提示词写法与参数调整.md)。
