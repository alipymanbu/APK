## 一、先把自动填充服务打开

存了密码不等于能填进去，第一步是把系统级的自动填充服务指给 Bitwarden：

1. 打开 Bitwarden 应用 → **设置（Settings）** → **自动填充（Autofill）**；
2. 点 **自动填充服务（Autofill services）**，跳到系统设置页；
3. 在「密码、通行密钥和自动填充服务」里选 **Bitwarden**（系统会提示确认信任，点确认）；
4. 回到 Bitwarden 的自动填充设置页，在「显示自动填充建议（Display autofill suggestions）」里选一种样式：
   - **内联（Inline）**：建议出现在**键盘**候选区，需要 Android 11+ 且你用的输入法支持内联；
   - **弹窗（Popup）**：建议以浮层出现在输入框旁，需要 Android 8+。

## 二、三种填充方式对照

除系统自动填充服务外，Bitwarden 还提供另外两条路，按你的系统版本选：

| 方式 | 需要版本 | 还要额外开什么 | 表现 |
| --- | --- | --- | --- |
| 自动填充服务 | Android 8+ | 无 | 输入框获得焦点时弹出建议 |
| 内联填充 | Android 11+ | 先开自动填充服务 + 支持内联的输入法 | 建议显示在键盘上 |
| 无障碍方式 | 全版本 | 系统「无障碍」里启用 Bitwarden | 弹窗让你去保险库挑条目 |

无障碍方式的快捷磁贴（Quick-action tiles）不依赖自动填充服务，但它靠系统无障碍接口常驻，**容易被电池优化杀掉**（见第五节）。日常用前两种就够。

## 三、浏览器里填不上

用 Chrome、Brave 当浏览器时，还有一个开关要做：在 Bitwarden 的自动填充设置里打开 **Use Chrome autofill integration / Use Brave autofill integration**，会跳到该浏览器设置里，再允许它使用第三方填充服务 —— 不开这个，浏览器里基本填不进。

两条限制：Chrome/Brave 的安卓版**对 HTTP 站点默认不提供自动填充**（非加密站点），要么让站点走 HTTPS，要么在浏览器里手动开相关 flag；自定义字段与「用户名、密码分两屏」的登录流程，移动端自动填充目前不支持。

## 四、App 内填不上：多半是匹配问题

自动填充靠**登录条目里的 URI** 与当前应用比对，对不上就不会弹。安卓端规则：

- 网页登录存网址（如 `https://gmail.com`）；
- **App 内登录存包名**，格式 `androidapp://com.xxx.yyy`（如 `androidapp://com.instagram.android`）。

查一个 App 的包名最省事的办法：去 Google Play 打开它的商店页 → 分享 → 复制链接，形如 `https://play.google.com/store/apps/details?id=com.instagram.android`，`id=` 后面那段就是包名。拿到后编辑登录条目，填进「网站（URI）」字段。

条目里存了 URI 还不弹，可在条目里调整**匹配检测（Match detection）**：默认按主机匹配，子域名登录不上时改成「主机或其任何子域」，还不行再用正则。改法在网页端编辑条目的 URI 字段旁。

## 五、系统厂商的坑（弹窗根本不出现时）

设置都对但界面毫无反应，先查这几处系统开关：

| 品牌 / 场景 | 要开的东西 |
| --- | --- |
| 华为 / 荣耀 | 「手机管家」→ 中部 **Dropzone（贴纸/悬浮）** 打开 |
| OPPO 等 | 设置 → 隐私 / 安全 → **悬浮窗管理**，允许 Bitwarden |
| 用无障碍方式 | 给 Bitwarden **关掉电池优化**，否则系统会悄悄停掉它 |
| 后台被清 | 最近任务里把 Bitwarden 上锁（锁定后台），别「强行停止」它 |

`dontkillmyapp.com` 这类站点有各品牌默认省电策略的说明，拿自己的机型对一下即可。

## 六、一条安全提醒

安卓不强制包名唯一，**仿冒 App 可以伪装成知名应用的包名**骗取你填充的账号。所以只从 Google Play、F-Droid 这类可信渠道安装应用，也只往官方版 App 里填充 —— 这比任何设置都重要。

## 七、还是不行怎么办

按顺序：确认系统版本满足该方式的最低要求（第二节表格）→ 核对条目的 URI 写法（第四节）→ 关掉 VPN / 广告拦截插件试一次 → 手机端同步一下保险库（设置 → 其他 → 同步）。网络与同步层面的排查见 [登录不上与数据不同步排查.md](登录不上与数据不同步排查.md)。
