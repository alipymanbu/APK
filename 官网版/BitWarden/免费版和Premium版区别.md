## 一、一句话结论

只存密码、多设备同步、自动填充 —— **免费版全都有，不设条数上限**；要内置验证码器（TOTP）、文件附件、应急访问、安全体检报告才需要 Premium。以下价格为官方个人套餐当前标价，**以官网当时显示为准**。

## 二、价格表（个人套餐）

| 套餐 | 标价 | 计费 | 包含 |
| --- | --- | --- | --- |
| 免费 | $0 | 永久免费 | 单人全功能基础版 |
| Premium | $1.65/月 | 按年付 $19.80 | 1 个账号的高级功能 |
| Families | $3.99/月 | 按年付 $47.88 | 最多 6 个账号，每个都是 Premium |

企业侧另有 Teams（$4/人/月）与 Enterprise（$6/人/月），按年计费，个人用户用不到。汇率与税费以官网结算页为准。

## 三、免费版包含什么

| 功能 | 免费版 |
| --- | --- |
| 无限密码、无限设备、多端同步 | 有 |
| 密码 / 用户名生成器、passkey 存取 | 有 |
| 安卓自动填充、指纹 / PIN 解锁 | 有 |
| 加密导出、CSV 明文导出 | 有 |
| Bitwarden Send（加密分享） | 有 |
| 与另一名用户共享条目 | 有 |
| 两步验证：FIDO2 硬件密钥、验证器 App（TOTP）、邮箱 | 有 |

对绝大多数只「存密码 + 自动填充」的人，这套已经是完整体验 —— 免费版没有广告，也不靠卖数据赚钱（开源、零知识是它的公开口径）。

## 四、Premium 解锁什么

| 功能 | 免费 | Premium |
| --- | --- | --- |
| 内置验证器：给别的网站存 TOTP 验证码并在填充时一并填入 | 无 | 有 |
| 条目文件附件（扫描件、证件照等） | 无 | 有 |
| 应急访问（Emergency Access，授权他人紧急取用） | 无 | 有 |
| 安全体检报告（弱密码、泄露密码、未开 2FA 的站点等） | 无 | 有 |
| 两步验证：Duo、YubiKey OTP | 无 | 有 |
| 优先支持 | 无 | 有 |

注意：**给别的网站存 TOTP 验证码**（俗称「2FA 一体」）是 Premium 里最常被用到的一项 —— 想把验证器 App 也并进 Bitwarden 的人，这就是买单理由。给 Bitwarden 自己开两步验证不需要付费，见 [两步验证与恢复码怎么设置.md](两步验证与恢复码怎么设置.md)。

## 五、怎么判断自己要不要买

- **不买的信号**：密码存在浏览器里也能忍、验证码器用独立 App 也行、不需要别人应急进你的库 —— 免费版直接够；
- **该买的信号**：想在填充密码时顺手把 TOTP 验证码也填了；有证件扫描件要加密存；希望家人在你出事时能接管账号；想定期看一眼哪些密码该换（安全报告）；
- **Families 的适用场景**：一家 6 口都要 Premium 功能且要互相共享 —— 单买 6 份 Premium 更贵，套餐价打包更省。

先按免费版用一两个月，遇到「这个功能要付费」的提示再回头对照第四节，比一开始就升级更准。

## 六、订阅之外的替代方案（自建）

官方还提供**自托管**：自己架服务器跑 Bitwarden 服务端，客户端全部照常用，数据完全放自己机器上（Premium 与 Families 套餐支持自托管选项）。适合有服务器、想数据自持的人；代价是备份、升级、证书都得自己管。客户端怎么指向自建服务器，见 [连接自建服务器登录出错怎么解决.md](连接自建服务器登录出错怎么解决.md)。
