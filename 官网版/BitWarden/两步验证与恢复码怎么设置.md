## 一、为什么要开

主密码泄露的最坏后果是整个保险库被人登走。两步验证（官方叫 Two-step Login，也叫 2FA）要求登录时再出一道验证 —— 别人拿到主密码也进不去。保险库的 2FA 是**登录时**要过、日常解锁（指纹/PIN）不用过，不影响使用体验。

设置入口在**网页端**：登录 [https://vault.bitwarden.com](https://vault.bitwarden.com) → 设置（Settings）→ 安全（Security）→ 两步验证（Two-step login）。

## 二、可选方法对照（截至 2026-09 官方口径）

| 方法 | 说明 | 订阅要求 |
| --- | --- | --- |
| FIDO2 WebAuthn 硬件密钥 | YubiKey、Google Titan 等 | 所有人免费 |
| 验证器 App（如 Bitwarden Authenticator） | 扫二维码出 6 位动态码 | 所有人免费 |
| 邮箱验证码 | 官方**默认开启**的方式 | 所有人免费 |
| Duo Security | Push / 短信 / 电话 / 安全密钥 | 需 Premium |
| YubiKey OTP | 4/5 系列、NEO/NFC | 需 Premium |

不要用短信验证码当 2FA（SIM 劫持风险是公开常识，官方也不支持）。可以同时开多种；登录时按优先级出现：Duo（组织）> FIDO2 > YubiKey > Duo（个人）> 验证器 App > 邮箱，登录页点「使用其他两步验证方法」可切换。

## 三、开完立刻保存恢复码

开启**任意一种**方法时，官方会生成一个**恢复码** —— 它是「验证设备全丢」时的唯一自救凭证：

1. 网页端 设置 → 安全 → 两步验证 → **View recovery code**，输主密码确认后显示；
2. **打印一份放抽屉**（或存进离线介质）—— 别只存手机相册、别存保险库里；
3. 恢复码用过一次就会**换新码** —— 用完记得把新码再存一遍。添加新方法、改主密码不影响恢复码。

官方明确说过：恢复码丢了他们也取不出来。这一步偷懒，第二节开的锁就可能变成自己的牢门。

## 四、恢复码怎么用（被两步验证挡在外面时）

1. 打开对应区域的恢复页：美区 [https://vault.bitwarden.com/#/recover-2fa/](https://vault.bitwarden.com/#/recover-2fa/)，欧区 [https://vault.bitwarden.eu/#/recover-2fa/](https://vault.bitwarden.eu/#/recover-2fa/)（自建服务器则是 `https://你的域名/#/recover-2fa/`）；
2. 填邮箱 + 主密码 + 恢复码，提交；
3. 成功后**所有已开的两步验证会被全部关闭**，直接进保险库 —— 然后马上重新至少开一种方法，并保存新恢复码。

## 五、没存恢复码，验证设备又丢了

按还剩的抓手试，顺序即成功率顺序：

| 抓手 | 动作 |
| --- | --- |
| 开了多种方法 | 登录页选「使用其他两步验证方法」换一个能过的 |
| 有已登录的其他设备 | 用那台导出保险库数据，注册新账号导入（见 [忘记主密码怎么找回.md](忘记主密码怎么找回.md) 第三节） |
| 有组织账户恢复 | 找组织管理员重置你的两步验证 |
| 有应急联系人（接管权） | 让对方发起应急访问，等等待时间过后替你收尾 |
| 都没有 | 官方无法协助找回，只能删号重建（数据以此前导出为准） |

## 六、没开两步验证的人也在被验证

2025 年 3 月起，官方对**未开两步验证**的账号在「新设备登录或清过浏览器 Cookie」时强制加一道邮箱一次性验证码 —— 这不是你的两步验证开了，是官方的兜底。嫌它烦可以开真正的两步验证，或在 设置 → 我的账户 → 危险区域里关掉「新设备登录保护」（关了就少一层防护，自己权衡）。新设备收不到验证码邮件的排查见 [登录不上与数据不同步排查.md](登录不上与数据不同步排查.md)。
