两个常规途径：

转存与下载的顺序：打开链接 → 登录夸克账号 → 保存到网盘 → 在网盘里把这个 APK 下载到手机存储。

## 三、安装步骤（安卓）

1. 在手机「文件管理」里找到下载好的 APK（文件名一般类似 `mtxx_v11.23.0.apk`，以你实际下载到的为准）。
2. 点开安装。首次安装第三方安装包时，系统会提示「允许安装未知来源应用 / 未知应用」，按提示允许本次安装后继续。
3. 装完点「打开」。首次启动会依次申请相册、存储等权限，不授权也能进，但选不了照片；要正常修图，建议按需允许。

装完先别急着一个个点，入口都在哪直接看 [常用修图功能从哪里进.md](常用修图功能从哪里进.md)。

首次启动会弹的权限，对应关系大致如下（以实际弹窗为准，不授权也能用核心功能，只是对应入口用不了）：

| 权限 | 对应什么动作 |
| --- | --- |
| 照片 / 存储 | 挑照片进编辑、把成片存回相册 |
| 相机 | 「拍摄 / 相机」入口拍照 |
| 麦克风 | 拍摄视频时收音 |
| 通知 | 导出、素材下载的进度提醒 |

## 四、对手机系统的要求

- 这版 11.23.0 在安卓 5.2 及以上的系统上可以安装。
- 应用商店里的更新版本对系统的要求也可能更高（多数资料写安卓 6.0 及以上），以官方商店页面当时标注的为准。
- 空间提醒：安装包 175.14M，装完之后加上基础资源与使用中产生的缓存，实际占用会明显大于安装包本身，空间紧张的手机先清理再装。

## 五、装不上或装完打不开，先查这几条

| 现象 | 先查什么 |
| --- | --- |
| 提示解析包出错 | 安装包没下载完整，重新下载一遍；有条件的核对一下 MD5 是否与上表一致 |
| 安装到一半失败 | 手机剩余空间不足；或者手机上已装着更高版本——低版本盖不过高版本，先卸载再装 |
| 装完点开就闪退 | 先重启手机再试；系统版本太老带不动新功能时，换低一点的版本安装 |
| 安装时提示「风险应用」 | 先核对包名与 MD5 是否与第一节一致，确认安装包没被动过再决定是否继续 |

已经装了更高版本又想回到 11.23.0 的情况，卸载与覆盖的注意事项见 [版本号怎么看与各平台区别.md](版本号怎么看与各平台区别.md)。
