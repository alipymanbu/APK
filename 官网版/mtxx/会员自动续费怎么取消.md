## 一、先弄清扣款走的是哪个渠道

在哪开通的就回哪去关。想不起来时这样查：翻支付宝、微信的扣款记录里有没有美图秀秀，或者 iPhone 的「订阅」列表里找；两头都没有，再回到 App 内的会员页看订阅状态。

## 二、三条取消路径（官方协议给的方式）

| 扣款渠道 | 路径 |
| --- | --- |
| 苹果（iOS 内购） | 设置 → 点 Apple ID 头像 → 订阅 → 选「美图秀秀」→ 取消订阅 |
| 支付宝 | 我的 → 设置 → 支付设置 → 免密支付/自动扣款 → 找到美图秀秀 → 关闭服务 |
| 微信 | 我 → 服务 → 钱包 → 支付设置 → 自动续费 → 找到美图秀秀 → 关闭扣费 |

关完回列表确认状态已变成「已关闭」；App 内的会员或账号设置页里也可能有订阅管理入口，以你版本的实际显示为准。

## 三、取消续费不等于会员立刻失效

- 关掉的是「自动续费」：已付费的时段内权益照常，用到到期为止，到期自然停。
- 已扣的钱能不能退，按官方政策一般不支持无理由退款；遇到扣费争议，先走官方客服渠道（官方协议页留有客服邮箱 support@meitu.com 与客服电话 400-009-3360，以官方页面为准），再考虑向扣款渠道申诉。
- 按现行监管要求，自动续费应在每次扣款前提醒、并允许随时取消（2026 年施行的《互联网平台价格行为规则》有明确要求，以最新规定为准）；没收到提醒就被扣款，可以直接以此为凭据去申诉。

## 四、会员体系里容易混的几件事

- 美图秀秀的付费会员分粉钻 SVIP 与粉钻 PRO 等档位；按现行协议，粉钻 SVIP 覆盖 App 端、PC 端、WEB 端，而更早的普通 VIP 与 PC/WEB 端会员曾是分开的体系——买之前在购买页看清覆盖哪些端，以当时页面说明为准，端与端的区别另见 [版本号怎么看与各平台区别.md](版本号怎么看与各平台区别.md)。
- 素材列表里免费与会员内容混排，带 VIP / 粉钻标的模板、滤镜、字体要会员才能用，下载时看标（哪些功能要碰素材，见 [常用修图功能从哪里进.md](常用修图功能从哪里进.md)）。
- 按官方协议口径，会员素材下载后仅限个人娱乐、学习、研究、欣赏用途，要商用需另行确认授权。
- 价格、档位、权益随时调整，本篇不罗列数字，一律以购买页当时显示为准。
