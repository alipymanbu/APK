## 一、首页的几个大入口

打开 App 后，首页第一排的大按钮对应几大类活儿（不同版本略有增减）：

| 入口 | 干什么 |
| --- | --- |
| 美化图片 | 修单张照片：滤镜、调色、贴纸、文字、消除笔、抠图等都在里面 |
| 人像美容 | 专修人像：磨皮、美白、瘦脸、美妆、美发等，各项细节见 [人像美容各项怎么调.md](人像美容各项怎么调.md) |
| 拼图 | 把多张照片排成一张，有多种版式 |
| 视频剪辑 | 剪视频、加配乐、视频美颜，流程见 [视频剪辑功能入门.md](视频剪辑功能入门.md) |
| 拍摄 / 相机 | 直接调起相机拍照，部分版本带实时美颜 |

## 二、美化图片里的工具栏

进入「美化图片」选中一张照片后，工具在底部横向排列、可以左右滑动。按你想做的事对号入座：

| 你想做的事 | 找哪个工具 |
| --- | --- |
| 套现成的风格 | 滤镜 |
| 手动调亮度、对比度、饱和度、色温 | 调色（细项里有曲线、HSL、色调分离） |
| 加贴纸、文字、边框 | 贴纸 / 文字 / 边框 |
| 给证件号、车牌打码 | 马赛克 |
| 去路人、去水印、去杂物 | 消除笔（分自动与手动两种打法，见 [消除笔去水印怎么用.md](消除笔去水印怎么用.md)） |
| 抠人、抠物、换背景 | 抠图 |
| 画面四周不够大、想往外扩 | AI 扩图（部分版本叫智能扩图） |
| 模糊老照片变清楚、黑白照上色 | 画质修复 / 老照片上色 |
| 生活照改证件照、换底色改尺寸 | 证件照（流程与底色对照见 [证件照换底色改尺寸.md](证件照换底色改尺寸.md)） |

工具位置随版本会调整，找不到就先把工具栏左右滑到头再看一遍。

## 三、AI 功能集中在哪

- 消除笔、抠图、扩图、画质修复这类 AI 工具，多数收在「美化图片」的工具栏里；部分版本首页会单独放一个「AI消除」入口，进去就是消除笔的自动模式，部分版本还会单独分一个 AI 组。
- AI 合照（把两张不同场合拍的人像合成到同一张里）是 11.x 这一代加入的功能；在你的版本里能不能看到、入口摆在哪，以实际界面为准，拿不准先核对版本（见 [版本号怎么看与各平台区别.md](版本号怎么看与各平台区别.md)）。

## 四、配方与素材

- 「配方」是把滤镜、调色、贴纸打包成的一整套参数，点一下整张照片直接套用，适合批量出一组风格统一的图；配方与模板入口在首页或美化图片里。
- 贴纸、边框、字体等素材分免费与会员两类，带 VIP 标的需要会员才能用，以下载时的实际提示为准；开通前后要留意的续费问题见 [会员自动续费怎么取消.md](会员自动续费怎么取消.md)。
- 部分滤镜与素材包需要联网下载后才会出现在列表里，列表里缺东西时先检查是不是没下载。

## 五、找不到功能时的排查顺序

1. 先确认版本——功能入口调整最常见的原因就是版本不同；
2. 在对应的大入口里把底部工具栏左右滑到头；
3. 看该工具是不是需要下载素材包，没下载就不会出现；
4. 还找不到，就在应用商店的版本记录里看看这个功能是不是新版本才加入的。
