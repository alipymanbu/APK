## 一、入口与基本操作

首页 → 人像美容 → 选一张带清晰人脸的照片 → 底部横向工具栏里挑项目。单项基本都是滑杆或点选式，调完点右下角对勾确认这一项，全部调完再统一保存。

入口找不对时，先看 [常用修图功能从哪里进.md](常用修图功能从哪里进.md) 的首页入口表。

## 二、各项目对照表

| 项目 | 管什么 | 调的时候注意 |
| --- | --- | --- |
| 磨皮 | 皮肤平滑、去粗糙 | 力度大会糊掉皮肤纹理，先从低档试 |
| 肤色美白 | 整体提亮、换肤色倾向 | 有预设肤色可选，冷白与自然色差异明显 |
| 瘦脸瘦身 | 脸型轮廓 | 拖动时留意背景的直线是否被带歪 |
| 面部重塑 | 五官比例调整 | 一次只调一处，方便和上一版对比 |
| 面部丰盈 | 苹果肌等部位的饱满度 | 幅度小才自然 |
| 祛法令纹 / 祛双下巴 | 局部纹路、下颌线 | 部分项目支持滑杆细调效果 |
| 自然美妆 | 整套妆容模板 | 妆容强度还能再单独降 |
| 智能美发 | 发型、发色 | 头发边缘清晰的照片效果更稳 |
| 增高塑形 | 天鹅颈、直角肩、长腿等体态 | 形变容易在背景的横竖线上露馅，调完检查背景 |

各项名称在不同版本里有增有减，以你界面里实际列出的为准。

## 三、调整顺序的建议

按「先整体、后局部」的顺序走，能少走回头路：

1. 先整体：磨皮、美白；
2. 再五官：眼睛、鼻子、嘴、面部重塑；
3. 后轮廓：瘦脸、塑形；
4. 最后美妆、美发。

顺序反过来，前面调好的五官常会被后面的轮廓改动带偏，只能重调。

## 四、调过头了怎么办

- 大多数项目里都有看原图的方式（长按画面或对比按钮，以界面为准），先看原图再决定回调多少；
- 单项滑杆直接往回调，比撤销整个重来快；
- 底图本身太糊或太小时，美容效果的上限就低，换一张清晰点的原图往往比反复调参数管用。
- 办正式证件照时美颜收着点，底色与尺寸的处理见 [证件照换底色改尺寸.md](证件照换底色改尺寸.md)。

视频里的人像处理是另一套耗时逻辑，见 [视频剪辑功能入门.md](视频剪辑功能入门.md)。
