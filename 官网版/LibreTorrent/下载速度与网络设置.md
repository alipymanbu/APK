## 一、先判断速度卡在哪一层

BT 下载速度由两端决定：资源端（做种人数）和你这一端（网络环境、设置）。同一个种子在 LibreTorrent 里速度不理想时，先换个热门资源试试——热门资源也慢才值得动设置；冷门资源（做种个位数）怎么调都快不起来，这不是客户端的问题。

设置入口在主界面侧边栏的「设置」里，本篇按用途分组讲。

## 二、限速与调度

- **全局限速**：分别给上传、下载设上限。家庭宽带上行小的话，把上传限速设为上行带宽的一半左右，通常能避免整个网络被 BT 拖卡，下载速度反而更稳。
- **按网络条件自动切换**：可以设置仅在 Wi-Fi 下下载，或对移动网络单独限速，避免流量跑超。电池策略里也能按充电/电量状态决定是否继续任务。
- **计划任务（Scheduling）**：指定每天某个时段才开始下载、做种。比如白天正常用网、凌晨放开全速，两不耽误。

## 三、连接与协议设置

这些设置影响你能不能连上更多 peer：

| 设置项 | 作用 | 什么时候动它 |
| --- | --- | --- |
| DHT | 无 Tracker 也能找到 peer | 保持开启 |
| LSD / PeX | 本地 peer 发现 / peer 交换 | 保持开启 |
| UPnP / NAT-PMP | 自动在路由器上开端口 | 路由器支持就开；端口通了对速度帮助明显 |
| 协议加密 | 对 peer 连接做加密 | 有的网络对 BT 流量干扰，开加密可能改善；也可能损失部分 peer |
| µTP | 更温和的传输协议 | 保持默认 |

这几项默认都是开的，一般不用动。真遇到「一直连不上 peer」再逐项排查，对应步骤见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、代理与匿名

- 设置里可以为 Tracker 与 peer 连接分别配置代理，常见用法是 SOCKS5。
- 社区常见的匿名做法是配合 Orbot（Tor 的手机端）提供的本机代理端口。注意走 Tor 下载 BT 的速度会非常慢，只适合对匿名要求高、不在乎速度的小文件。
- 官方在 4.1 版新增了「所有连接强制走代理」的 kill switch 选项（代理断开时不让连接泄漏出去）。你手里网盘这份是 4.0.1，没有这一项，需要的话得换官方新版。

## 五、IP 过滤

LibreTorrent 支持导入 eMule dat 与 PeerGuardian 格式的 IP 黑名单，在连接层面挡掉广告、监控与恶意 IP 段。黑名单文件要自己准备（网上有公开维护的列表），在设置里指定文件路径生效。列表越大加载越慢，按需选择即可。

## 六、RSS 自动下载与网络条件配合

订阅自动下载的任务同样受网络条件与计划任务约束，两者搭配可以做到「只在夜间 Wi-Fi 下自动抓新资源」。订阅本身的配置见 [RSS订阅自动下载.md](RSS订阅自动下载.md)。
