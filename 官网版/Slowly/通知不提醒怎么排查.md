# Slowly 通知不提醒怎么排查

> 本篇先分清「没提醒」和「还没发生」，再按顺序给出排查动作，最后说明哪些情况只能等它自己恢复。

## 一、先看官方到底会推哪几类

Slowly 的推送不是每个动作都发。官方列出的触发场景只有这几类：

- 有人通过 Slowly ID 加你（好友申请）；
- 新笔友第一次给你写信；
- 有人给你寄出了新信；
- 你收到的信抵达了；
- 有人向你发起照片分享或语音分享请求；
- 你的好友生日临近；
- 你的免费礼物可以领了。

所以「对方一直没回我」十有八九不是通知坏了，而是信还在路上——信真正抵达时才会推一次。判断在途状态的方法见 [信件送达时间与状态怎么看.md](信件送达时间与状态怎么看.md)。

## 二、按这个顺序排查

1. **关掉挡通知的模式**：确认手机不在勿扰、省电、电池优化模式下。官方特别提了一句：**错过的通知之后不会再补发**，别指望打开权限后把之前的都收回来。
2. **看系统通知权限**：
   - Android：设置 → 应用与通知（或应用管理）→ 通知 → Slowly → 打开全部权限；
   - iOS：设置 → Slowly → 通知 → 允许通知。
3. **看应用内的开关**：个人中心 → Settings → Push Notifications 一段，确认是打开的。
4. **更新 Google Play 服务**（Android）：Slowly 的推送依赖它，版本太旧会收不到。
5. **退出所有设备**：首页 → 右上角二维码图标 → 拉到最下面 → Log out from all devices。旧设备留下的失效推送令牌是漏通知的常见原因，清掉再重新登录。
6. **重装应用**：卸载重装可以刷新推送令牌，账号和信件在云端，用同一个账号登录即可，不会丢。

## 三、排查完还是没恢复

官方说明：Slowly 的通知大多是**定时发送**的，发送时间和收到时间之间本来就可能有延迟；而且做完上面这些动作后，此前已经排定好、但还没发出的通知依然可能收不到。需要给它 1 到 2 天，通知才会回到正常节奏。

## 四、只想少收几类提醒

不想被好友生日、免费礼物这类通知打扰，可以在「个人中心 → Settings → Push Notifications」里逐项关掉。这是通知范围的问题，不用走上面的排查。
