## 一、注册只需要笔名和头像

Slowly 不要求真实姓名和照片：给一个笔名、挑一个插画头像、勾上你会用的语言和感兴趣的话题，账号就算建好了。注册入口有四个：Facebook 账号、Google 账号、Apple 账号、邮箱。其中 **Sign in with Apple 只在 iOS 客户端里有**，网盘里这份安卓包装上后看不到这一项，用 Google 或邮箱注册即可。登录凭证也可以是手机号，那取决于你注册时用的是哪一种。

能用 Slowly 的地方有两处：手机 App，以及只在桌面浏览器上工作的网页版 [web.slowly.app](https://web.slowly.app)。网页版在手机上打不开，这是官方设计如此，不是没做好，它的用法单独写在 [在电脑上用网页版.md](在电脑上用网页版.md)。

## 二、登录凭证要选好

| 登录方式 | 适合谁 | 要注意 |
| --- | --- | --- |
| 邮箱 | 想长期用、怕换号 | 得是能收到验证邮件的邮箱 |
| 手机号 | 只在自己手机上用 | 换号前先把邮箱绑上 |
| Google / Apple / Facebook | 不想记密码 | 那个第三方账号本身要能登录 |

至少要留一种「换个设备也能登进去」的凭证，邮箱最稳。否则手机一丢，账号里的信和邮票都取不回来。

**收不到验证邮件或验证码时**，按这个顺序试：

1. 翻一趟垃圾邮件/垃圾短信箱，把官方发信地址标记为可信，避免下次又被拦；
2. 等几分钟——不同邮件服务商的投递速度不一样，偶尔就是会慢；
3. 确认注册时填的邮箱/手机号没写错；
4. 给账号设一个密码。设了密码就不必每次等一次性验证码，以后直接用密码登录，这一步能长期省掉上面三个麻烦。

前三条都试过还是收不到，可以联系官方客服，报上你的笔名和注册邮箱，让他们给一个替代的登录方式。

## 三、笔名、头像和个人资料

- **改笔名**：点底部导航最右边的头像进个人中心 → 点名字右侧的箭头 → 在「笔名」一栏改写 → 保存。
- **头像**：用内置的捏脸工具拼，发型、表情、服装、配件都可以换；较新版本还支持双色发色、给头像加小挂件。
- **资料完整度**：个人中心会显示资料完成进度，补全问答等栏目更容易被匹配到（9.5 版本加入的功能）。
- **配对偏好**：性别、年龄范围、话题、排除的话题与地区都在个人资料里设置，逐项说明见 [怎么找笔友和配对规则.md](怎么找笔友和配对规则.md)。

## 四、Slowly ID 是做什么用的

Slowly ID 是一串只属于你的编号，和笔名不是一回事，也不会公开展示——它存在的意义是让现实中已经认识的人能精确加到你。

- **查自己的 ID**：个人中心 → 在 About Me 一段找到 Slowly ID → 点旁边的复制按钮。
- **加对方的 ID**：底部导航中间那栏 → Discover People → Slowly ID → 在 Add Friend By Slowly ID 里输入那串 ID → 点 Request。
- **前提**：对方要在「个人中心 → Accepting New Friends」里打开「允许别人通过 ID 加我」，否则你在 ID 里搜不到他。
- **一点区别**：靠 ID 加上的好友会计入好友申请流程，需要对方通过；而且这类好友不会影响「发信:收信比例」的统计。

## 五、把界面语言切成中文

手机 App：个人中心 → 右上角齿轮 Settings → 拉到 About Slowly 一段 → App Language → 选好语言后 Save。

网页版：点右上角头像 → Settings → App Language → 选好 → Save。

两个端的语言是各自设置的，改了手机端不会同步到网页端。

## 六、换手机、重装与停用

- **信会不会丢**：不会。官方说明是信件会自动同步到云端，换设备或重装后用同一个账号登录，信件都能取回。
- **重装之后**：用原来的凭证登进去就行。如果当初是手机号登录而那个号已经停用，会卡在验证码这一步——这也是第二节建议先绑邮箱的原因。
- **不想用了**：官方提供「暂时停用账号、以后再来」的方式，也支持直接删号；删号或移除笔友之前，应用会提醒你先写一封告别信（10.0 版本加入的功能）。真要操作时按设置里当时的菜单走。

## 七、哪些信息是公开的

| 别人能看到 | 别人看不到 |
| --- | --- |
| 笔名、头像、国家/地区、使用的语言、兴趣话题、最后上线时间 | 真实姓名、照片、邮箱、手机号、你的 Slowly ID |
| 发信:收信比例（可以在资料设置里隐藏） | 你的往来信件内容，只有你和对方能看到 |

关于「对方能不能看到我的实时位置」，官方帮助中心有单独一篇说明，结论以应用内设置项与帮助中心当页为准。
