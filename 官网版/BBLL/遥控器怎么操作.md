## 一、第一次打开

装好首次启动会弹用户协议，确认后进主界面。没登录也能浏览，只是搜索、动态这些要账号的入口进不去 —— 先扫码再逛会顺很多，流程见[扫码登录与账号同步.md](扫码登录与账号同步.md)。

## 二、主界面布局

- **左侧竖排导航**：搜索、主页（分类）、动态、直播等入口；遥控器方向键上下选中、确认进入；
- **顶部横排标签**：推荐、热门、番剧、影视等频道，方向键左右切换；
- **中间内容区**：封面卡片，方向键移动焦点、确认打开；
- **左下角齿轮**：设置入口（通用 / 播放 / 弹幕三组，见[电视上播放设置怎么调.md](电视上播放设置怎么调.md)）。

**刷新当前页面**：点一下左侧导航里**当前高亮的那个 Tab** —— 推荐流不更新时先用这招，不用退出应用。

## 三、遥控器按键速查（浏览时）

| 按键 | 作用 |
| --- | --- |
| 方向键 | 移动焦点 / 切换标签与频道 |
| 确认键 | 打开选中的视频或进入菜单 |
| 返回键 | 退出播放 / 返回上一级 |
| 点高亮 Tab | 刷新当前页面 |

平板上触屏操作逻辑一致：点选代替方向键，滑动代替翻页。

## 四、播放中怎么操作

按确认调出控制条，常用项从左到右大致是：倍速（速度）、音轨、清晰度、视频编码、字幕、弹幕开关。各项该在什么情况下改，见[电视上播放设置怎么调.md](电视上播放设置怎么调.md)。

**快进快退有四种方式**，按你遥控器的条件选：

1. **双击屏幕左侧 / 右侧** —— 最常用，不依赖遥控器功能；
2. **拖动进度条**：焦点移到进度条上按左右方向键；
3. **播放控件已隐藏时直接按方向键左右**；
4. 遥控器上有**多媒体快进快退键**的，直接按那两个键。

其他播放中的操作：

- **一键三连 / 关注 UP 主**：控制条里对着 UP 主信息操作；
- **弹幕参数**：弹幕开关旁边进细调（区域、字号、透明度、速度）；
- **退出播放**：返回键。

## 五、搜索怎么输字

左侧导航进搜索页，会调出系统或应用内的输入法，用遥控器方向键选字。搜索既是找视频的入口，也是进直播间的途径之一（直播也可从左侧「直播」分区浏览；有用户反馈部分直播间只能靠搜索房间名进入 —— 两种说法以你手上版本的实际界面为准）。
