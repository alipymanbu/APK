## 一、这个包申请了哪些权限

下面是[应用宝权限页](https://sj.qq.com/permission/cn.ifile.tech)对包名 `cn.ifile.tech` 公示的权限清单（以页面当时显示为准），按用途归了组：

| 分组 | 权限 |
| --- | --- |
| 文件读写 | 读取 SD 卡中的内容、修改或删除 SD 卡中的内容 |
| 网络 | 完全的网络访问权限、查看网络连接、更改网络连接性、查看 WLAN 连接、连接 WLAN 网络和断开连接 |
| 应用安装与任务 | 请求安装文件包、检索正在运行的应用 |
| 界面 | 在其他应用之上显示内容（悬浮窗）、展开/收拢状态栏 |
| 设备状态 | 读取手机状态和身份、控制振动、防止手机休眠 |
| 位置 | 访问大致位置信息、访问确切位置信息 |
| 麦克风 | 录音 |
| 电话 | 重新设置外拨电话的路径 |

## 二、哪些权限建议给足

- **存储两项（读取/修改 SD 卡）**：这是文件管理类应用的命根子。拒绝了，扫描、浏览、删除、解压输出、转换写文件全都不工作——装完第一件事就是去 设置 → 应用 → ifile → 权限 里确认这两项已允许。
- **网络与 WLAN**：用于在线能力与网络状态判断。你要用的纯本地功能（扫描、管理、解压）不联网也能跑，但拒绝网络权限可能让部分入口报错，网络类权限按提示给即可。
- **请求安装文件包**：只有你要用它安装 APK 时才用得上。系统在真正安装时还会再弹一次确认，这层把关仍在系统手里；不用这个功能就拒绝，不影响其余功能。

## 三、哪些权限可以按需拒绝

位置（大致/确切）、录音、外拨电话路径这三项，与「管理手机文件」这个核心用途没有直接关系。你可以按这样处理：

- 位置、录音平时用不到就拒绝，用到某个具体功能弹出来时再临时允许；
- 悬浮窗（在其他应用之上显示内容）拒绝后，个别浮窗类功能会缺一块，但主流程不受影响；
- 事后随时可在 设置 → 应用 → ifile → 权限 里改，改错了也能改回来。

## 四、常见问题排查

**1. 扫描或分类里看不到本该有的文件**
先查存储权限（第二节）。权限正常仍缺文件时：确认文件确实存在于手机存储而非 SD 卡外置路径；安卓 11 及以上对 `Android/data`、`Android/obb` 目录有系统级限制，任何第三方文件管理器都读不进去，这不是应用的 bug。微信/QQ 分类下为空时，先确认那两个应用里确实收发过文件。

**2. 安装失败**
按[下载与安装教程.md](下载与安装教程.md)第四节的三条顺序查：包完整性（MD5）、系统版本、安装未知应用授权。系统弹的报错原文是最有用的线索，先记下来。

**3. 装上就闪退或用一会闪退**
依次试：设置 → 应用 → ifile → 存储 → 清除缓存（不清数据）；重启手机；确认系统版本满足要求。清缓存不管用再考虑重装（重装前确认网盘里那份包还在，见[下载与安装教程.md](下载与安装教程.md)）。

**4. 解压失败**
三查：压缩包是否完整（下载中断的包解不开，重新下载）；是否带密码（密码只有压缩时设置的人知道）；剩余空间是否大于解压后的体积。操作入口见[压缩解压与格式转换教程.md](压缩解压与格式转换教程.md)。

**5. 格式转换失败或输出文件找不到**
按[压缩解压与格式转换教程.md](压缩解压与格式转换教程.md)第四节的顺序查：源文件可打开 → 存储权限给足 → 剩余空间够。输出结果先去该页的「转换记录」里找。

**6. 应用管理里的「卸载」点了没反应**
系统预装应用多数不允许第三方卸载，按钮点不动就是机型限制。可卸载的普通应用点后还会弹系统确认，确认才生效；想保留一份安装包再卸，先在文件管理里把它的 APK 复制出来。
