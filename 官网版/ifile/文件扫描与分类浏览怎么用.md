> 本篇讲主界面底部的五个标签页分别干什么，以及「文件扫描」「文件管理」两页怎么把手机里的文件翻出来。

## 一、先认识底部五个标签页

打开应用，底部固定五个标签页，所有功能都从这里进：

| 标签页 | 你在这里能做什么 |
| --- | --- |
| 文件扫描 | 按类型深度扫描全机文件，把散落各处的文件找出来 |
| 解压缩 | 处理压缩包，解压与压缩入口集中在这一页 |
| 文件管理 | 看存储占用、按分类浏览文件、进应用管理卸载应用 |
| 格式转换 | TXT/表格转 PDF、PDF 转图片、音频格式转换 |
| 私密相册 | 存放不想让别人看到的照片视频 |

想按分类直接翻文件、看还剩多少空间，走「文件管理」；想找一个不知道丢在哪的文件，走「文件扫描」。压缩与转换类操作见[压缩解压与格式转换教程.md](压缩解压与格式转换教程.md)。

## 二、文件扫描：五类扫描入口

「文件扫描」页顶部是设置齿轮，中间一条「文件管理专家 · 深度扫描 · 高清导出」的横幅，下面是「数据分类」区的五个入口：

- **图片扫描** —— 找出手机里所有图片文件；
- **视频扫描** —— 找出所有视频文件；
- **音频扫描** —— 找出所有音频文件；
- **文件扫描** —— 按通用文件维度扫描；
- **压缩扫描** —— 找出手机里的压缩包，扫完可直接转去解压。

用法就是点对应入口 → 等扫描完成 → 在结果列表里浏览、挑选。扫描要把手机里的文件挨个过一遍，文件多的手机会多花一点时间；如果你要的文件本来就有明确位置（比如微信收到的文档），直接用下一页的分类入口更快。

## 三、文件管理：先看存储占用，再按类翻文件

「文件管理」页上方是一张「手机内部存储」卡片，显示已用/总量和一个环形占比（截图示例是 108 GB / 134 GB）。这张卡就是你的空间体检表：占比接近满格时，先去各分类里清大文件。

卡片下方是「文件类型」入口，把文件按用途分好了类：

- **图片 / 音频 / 视频 / 文档** —— 按媒体与办公类型浏览；
- **微信 / QQ** —— 直接进这两个应用收发过的文件，不用在目录树里一层层找；
- 另有压缩包、安装包等入口（不同版本入口数量略有差异）。

哪一类占空间大，就进哪一类删。删之前确认文件确实不要了，别顺手清掉了还要用的东西。

## 四、应用管理：批量卸载入口

「文件管理」板块里还有「应用管理」页，列出手机上已装的应用（每项显示图标与名称，右侧一个「卸载」按钮），适合集中清理一批用不上的应用。点「卸载」后系统还会再弹一次确认，确认后才真正卸载。

系统预装应用能不能卸载取决于机型，按钮不可用就是系统不让卸。想把 APK 留一份再卸，先在文件管理里找到它的安装包复制出来。

## 五、扫描结果里没有文件时

明明有文件却扫不出来，九成是权限没给够：存储权限被拒的应用读不到任何本地文件。去 设置 → 应用 → ifile → 权限 里确认存储/文件访问已允许；安卓 11 及以上对 `Android/data` 这类目录另有系统级限制，即使授权也读不进去。完整排查步骤见[权限说明与常见问题排查.md](权限说明与常见问题排查.md)。
