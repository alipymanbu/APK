## 一、先确认你要装的包

ifile 是一款安卓文件管理工具，把文件扫描、压缩解压、文件管理、格式转换、私密相册做在同一个应用里，适合想用一个应用管完手机文件的用户。应用商店里的上架名是「手机文件管理IFile文件夹」，开发者与运营者都是成都墨巴格网络科技有限公司；下面这份是本页对应安装包的本地事实：

| 项目 | 值 |
| --- | --- |
| 版本 | 6.2.6 |
| 包名 | `cn.ifile.tech` |
| 大小 | 54.65M |
| MD5 | `5179AB3FA155A9B73164E4E5F3552DC5` |
| 系统要求 | 安卓 5.2 及以上（以安装时的提示为准） |
| 整理时间 | 2026-09-23 |

两点先说清楚：

- **商店里的版本号和这份不一致是正常的**。[应用宝页面](https://sj.qq.com/appdetail/cn.ifile.tech) 显示的版本是 6.2.629、体积 86.1MB（页面数据截至其 2026-01-03 的更新，之后以页面当时显示为准），那是商店渠道包，跟网盘里这份 6.2.6 / 54.65M 不是同一个包。你要装哪份自己定：装网盘这份就核对上表的包名与 MD5。
- 装好后想确认版本，进 设置 → 应用 → 应用信息 → ifile，看版本号是否为 6.2.6。

## 二、下载与安装步骤

1. 打开 [ifile 安装文件资源（夸克网盘）](https://pan.quark.cn/s/70650f9caa63)，把安装包转存到自己的网盘，再下载到手机；
2. 下载完先核对文件名与体积是否对得上（约 54.65M），拿不准就用 MD5 校验工具比对 `5179AB3FA155A9B73164E4E5F3552DC5`，对不上说明文件不完整，重新下载；
3. 在手机上点开这个 APK。系统会提示「禁止安装来自此来源的应用」——这是安装第三方 APK 的常规拦截，确认继续即可（不同品牌路径略有差异，一般在 设置 → 安全/安装未知应用 里给浏览器或文件管理器授权）；
4. 装完打开，底部能看到文件扫描、解压缩、文件管理、格式转换、私密相册五个标签页，就算装成功了。

## 三、首次启动会碰到的授权

第一次用的时候，应用会向你要存储访问、文件读写这类权限——不给的话扫描和管理功能都读不到你的文件，建议按提示给足。它还会申请一批与文件管理关系不大的权限（位置、录音等），哪些该给、哪些可以拒绝，逐条列在[权限说明与常见问题排查.md](权限说明与常见问题排查.md)里。

另外，从应用里安装 APK、卸载应用时，系统会再单独弹一次确认（安装未知应用、是否卸载），这类系统级确认点的还是你自己，按需决定即可。

## 四、装不上或装上就闪退，先查三件事

1. **包是否完整**：MD5 对不上就重新下载，半截文件装不上或装上必闪退；
2. **系统版本**：低于上表要求的系统装不了，以安装时的提示为准；
3. **安装来源授权**：部分机型要在 设置 → 安全 里允许安装未知应用。

三条都排除了还装不上，把系统弹的报错原文记下来，连同扫描不到文件、解压失败等问题的处理办法，一起看[权限说明与常见问题排查.md](权限说明与常见问题排查.md)。
