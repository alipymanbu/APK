## 一、好友列表：先看谁在线

打开应用就是好友列表，在线状态直接标在名字旁边，正在玩什么游戏也能看到。想拉人开一局，先扫一眼这里就知道谁有空。

列表顶部的搜索框可以按名字找人，好友多了以后比翻列表快。

## 二、把常聊的人放进收藏栏

官方支持页给出的做法有两种，效果一样：

- 在好友列表里**长按**某个好友；
- 或在与他的聊天里点顶部标题栏，进入该好友的设置页。

从那里可以把对方加入收藏栏（Favorites）。加进去之后他会常驻在列表顶部，不用每次都翻着找。

## 三、用邀请链接加好友

朋友还没在你好友列表里时，最省事的办法是生成一条邀请链接发过去：

1. 点应用**左上角的菜单按钮**；
2. 选 **Add a Friend**（添加好友）；
3. 选 **Invite Link**（邀请链接）；
4. 生成链接后，用短信、邮件或任何聊天工具发给对方。

对方点开链接接受，你们就成为好友。这比报 Steam ID 再搜索要少出错——尤其对方 ID 里带数字、下划线这类容易看漏的字符时。

发不出邀请还有一种可能：Steam 的**受限账号**（limited user）没有发送好友邀请的权限，邀请链接也生成不了——但接收邀请不受影响。这是账号层面的限制，与在哪端操作无关，官方说明见 [help.steampowered.com/en/faqs/view/71D3-35C2-AD96-AA3A](https://help.steampowered.com/en/faqs/view/71D3-35C2-AD96-AA3A)。

## 四、聊天里的几个输入技巧

| 想做的事 | 做法 |
| --- | --- |
| 发 GIF 表情 | 在输入框打 `/giphy`，后面跟**英文**搜索词，发送的就是 GIPHY 的搜索结果 |
| 图片标剧透 | 发送前点输入框角落的**眼睛图标**，对方要先点一下才能看到图 |
| 分享视频 / 推文 / GIF | 直接把链接贴进消息，会以卡片形式展示出来 |

`/giphy` 的搜索词要用英文，中文词基本搜不出结果。

## 五、手机和电脑的会话是同一套

聊天记录跟着 Steam 账号走：在电脑端 Steam 聊到一半，打开手机上的 Steam Chat 能接着聊；反过来也一样。换设备不需要导出、同步任何东西。

## 六、聊不了的时候

发不出消息、加不上好友，问题多半出在登录或网络环节，排查思路见 [登录与常见问题.md](登录与常见问题.md)。收得到消息但不响不震，是提醒配置问题，见 [收不到消息提醒怎么办.md](收不到消息提醒怎么办.md)。应用本身的缺陷或建议，可以去官方反馈组 [steamcommunity.com/groups/steamchatapp](https://steamcommunity.com/groups/steamchatapp) 发帖。
