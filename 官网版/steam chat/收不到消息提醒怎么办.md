# Steam Chat 收不到消息提醒怎么办

> 手机上 Steam Chat 明明在线却收不到好友消息提醒，多数不是应用坏了，而是安卓的通知权限、电池策略或账号状态挡住了。本篇按从常见到少见的顺序排查。

## 一、先对症状

| 症状 | 大概率原因 | 先查哪节 |
| --- | --- | --- |
| 只有它没提醒，其他应用正常 | 通知权限或通知渠道被关 | 二 |
| 解锁手机、点开应用后消息才涌进来 | 电池策略限制了后台 | 三 |
| 提醒有，但不响不震 | 勿扰模式、通知音量或渠道被设成静音 | 四 |
| 通知横幅有，锁屏上看不到 | 锁屏通知隐私设置 | 四 |
| 所有应用都没提醒 | 全局勿扰、省电模式或断网 | 四 |

安卓各版本、各品牌的设置入口名称略有差异，找不到就用系统设置的搜索框搜「通知」或应用名。

## 二、通知权限与通知渠道

1. **Android 13 起新装应用要单独授予通知权限**：首次打开 Steam Chat 时弹的「允许发送通知」如果点过拒绝，后面就一条提醒都不会有。去系统设置 → 应用 → Steam Chat → 通知，打开「允许通知」。
2. 同一页面往下是**通知渠道**（分类）：逐个检查有没有哪个分类被单独关掉、或被设成「静默」，把需要的改回「提醒 / 默认」。
3. 长按桌面图标 → 应用信息 → 通知，是到同一页面的快捷入口。

## 三、电池与后台策略

厂商的省电优化会在后台杀应用，应用被杀就收不到推送——典型症状就是解锁、点开应用后消息才一次性涌进来。处理方向：

- 系统设置 → 应用 → Steam Chat → 电池，选**不受限制**（或「不优化」「允许后台活动」）。
- 三星机型还有一层：设置 → 电池 → 后台使用限制，把 Steam Chat 从「睡眠中应用 / 深度睡眠应用」列表里移出来。
- 国产 ROM（小米、华为、荣耀、OPPO、vivo 等）通常还有**自启动、后台运行、多任务里锁定任务卡片**这几个开关，都在应用信息页附近。
- 各品牌后台策略的差异可以查 [dontkillmyapp.com](https://dontkillmyapp.com/)，那里按厂商整理了「谁在杀后台」与对应解法。

## 四、全局设置与账号状态

- **勿扰 / 静音**：下拉快捷面板确认勿扰没开着；再按音量键展开音量条，把「铃声与通知」音量拉起来——通知权限全开但音量为零，也是「不响」的常见原因。
- **锁屏通知**：设置 → 通知 → 锁屏上的通知，确认允许显示（部分机型默认隐藏敏感内容，锁屏上就只剩个图标）。
- **省电模式 / 流量节省**：全局省电模式会连通知一起压，流量节省会掐后台数据；要么关掉，要么把 Steam Chat 加进例外名单、允许后台数据。
- **账号在线状态**：Steam 账号的在线状态有一档「请勿打扰」（Do Not Disturb），开着它聊天消息与邀请的通知会被压掉。手机端看不出来时，在电脑端或浏览器打开 [steamcommunity.com/chat](https://steamcommunity.com/chat) 检查自己的状态并改回「在线」。
- **重启手机**：以上都查过还不行，重启一次再试。

## 五、还不行的话

- 确认账号还处于登录状态：被登出时不会有任何提醒，重新登录的排查见 [登录与常见问题.md](登录与常见问题.md)。
- 消息发不出去、收不到，与「有消息但不提醒」是两回事，先看 [登录与常见问题.md](登录与常见问题.md) 与 [好友与群聊使用技巧.md](好友与群聊使用技巧.md)。
