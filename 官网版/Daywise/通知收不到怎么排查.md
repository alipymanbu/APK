# Daywise 设置后通知收不到怎么排查

> 本篇按出现概率排序，逐条排查「到点不推送」「通知全没了」「批量通知一直不出现」三类问题。

## 一、先分清是「哪种收不到」

三种症状原因完全不同，先对号入座：

| 症状 | 更可能的原因 |
| --- | --- |
| 批量应用的通知到点也不出现，收件箱始终空 | 通知使用权被收回，或 Daywise 被系统杀后台 |
| 所有应用（含 Instant）都没通知 | 系统层面的问题（勿扰、通知总开关），与 Daywise 无关 |
| 偶尔某次到点没推送，之后又正常 | 后台被临时清理，属偶发；频繁发生才需要处理 |

按顺序过下面几条，通常前两条就能解决。

## 二、检查通知使用权还在不在

Daywise 靠系统的「通知访问权限」读取通知，这个权限会在系统更新、清理加速、或权限管理收紧时被悄悄收回。检查路径：`设置 → 通知 → 特殊应用权限 / 通知访问权限 → Daywise`，确认开关仍是打开的；或在设置里直接搜「通知访问」。各品牌路径略有差异，找不到就用搜索。收回后再打开，之前攒下的通知不会自动补进收件箱，从打开那一刻起重新计算即可。

## 三、把后台限制放开

Daywise 必须常驻后台才能在到点时推送。国产 ROM 的省电策略会优先杀掉不活跃的后台应用，表现为「装完头几天正常，后来到点没动静」。逐项检查：

1. **电池优化**：`设置 → 应用 → Daywise → 电池`，选「不受限制 / 允许后台运行」（不要选「受限」）；
2. **锁后台**：在最近任务列表里下拉 Daywise 卡片加锁，防止一键清理把它清掉；
3. **厂商加速/省电白名单**：把 Daywise 加进「白名单」或「自启动」允许名单；
4. **清理工具**：如果你装了第三方清理或管家类应用，确认它没有把 Daywise 列为可清理对象。

判断是否生效：改完设置后等到下一个推送时间点，收件箱里应有汇总通知出现。

## 四、确认不是系统勿扰在挡路

系统自带的**勿扰模式（DND）**、睡眠模式、专注模式会拦下一切通知——包括 Daywise 的推送汇总。检查快捷开关面板里勿扰是否亮着，以及 `设置 → 声音与振动 → 勿扰` 里有没有定时规则在生效。这类模式与 Daywise 的批量是两套独立机制，同时开着会互相叠加，排查时先把系统勿扰关掉，确认 Daywise 恢复正常后再按需单独启用系统侧的规则。

另外确认系统通知总开关没关：`设置 → 应用 → Daywise → 通知`，总开关与各个通知渠道都要处于打开状态。

## 五、自查设置本身

排除掉系统因素后，回到 Daywise 里核对三处：

- **日程时间点**：PICK SCHEDULE 里的时间点是否还是你预期的那几个——升级或重装后若恢复了默认值，会表现为「推送时间全变了」；
- **应用分类**：出问题的那个应用是不是被挪进了 Batched（批量通知到点前本来就不显示，见 [通知定时推送设置教程.md](通知定时推送设置教程.md)）；
- **是否处于暂停中**：主界面右下角的暂停按钮如果还开着，所有通知走的是即时通道，收件箱自然一直是空的，等暂停到期或手动恢复即可。

## 六、还不行就重装

以上都排除后，可以卸载重装一次来重置状态。卸载前注意两点：先把要保底的应用挪进 Instant 或给关键联系人加上 VIP（设置会随卸载丢失，重装后要重新配一遍）；重装后第一步重新授予通知访问权限，否则又会回到 [下载与安装教程.md](下载与安装教程.md) 里「装了等于没装」的状态。安装文件仍从同一处取：[Daywise 安装文件资源（夸克网盘）](https://pan.quark.cn/s/09373d7f5a36)。
