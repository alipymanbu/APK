## 一、先过一遍最快的四条

列表里看不到对方时，按顺序勾，多数情况前两条就解决：

| 检查项 | 具体怎么做 |
| --- | --- |
| 同一个网络 | 手机和电脑必须连**同一个路由器**的网络；手机如果走的是流量、或连了别的 Wi-Fi，必然互不可见 |
| 两端都开着 | 电脑端图标在任务栏托盘里才算在运行；手机端切到后台别被系统杀掉 |
| 可被发现开着 | 手机端 设置里的 Discoverable（可被发现）打开；关着时你的设备不响应别人的搜索 |
| 权限给了没 | 手机的「本地网络」权限（安卓在应用的联网/权限设置里）没拒绝，拒绝了发现功能整段失效 |

## 二、还不行，看网络本身

- **访客网络 / AP 隔离**： 很多路由器的「访客网络」和「AP 隔离」会把设备之间隔开——手机连访客网络、电脑连主网络，或路由器开了隔离，局域网内也互相看不见。把两端接到同一个主网络，并在路由器设置里关掉 AP 隔离（有的叫「无线客户端隔离」）。
- **频段问题**： 路由器的 2.4 GHz 和 5 GHz 双频有时分属不同网段，一端连 2.4G、一端连 5G 可能发现不了。先把两端手动连到**同一个频段**试一次。
- **公司 / 校园网**： 这类网络普遍开了客户端隔离，LANDrop 大概率搜不到人；换手机热点验证是最快的区分办法——热点下能传，就说明问题在网络，不在应用。

## 三、电脑侧的防火墙

Windows 防火墙或第三方杀软默认会拦陌生程序的局域网通信，手机发文件到电脑时会表现为「电脑一直不弹确认框」：

1. Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙；
2. 在列表里找到 LANDrop，**专用和公用**网络都勾上（找不到 LANDrop 就点「更改设置 → 允许其他应用」手动添加其主程序）；
3. 第三方杀软（火绒、360 等）里同样检查一遍 LANDrop 是否被拦，或暂时退出对比验证；
4. 电脑的网络配置文件类型最好是「专用网络」，公用网络下 Windows 会采用更严的入站策略。

## 四、确认、传输阶段的问题

- **弹了确认框但点了拒绝**： 手机端会显示传输失败，重新发起一次即可；6 位码不一致时别接受，说明你看到的可能是另一笔请求。
- **收着收着断了**： 多半是其中一端切后台被系统冻结。手机端把 LANDrop 加入后台白名单（允许后台运行 / 锁屏不清理），传大文件期间保持屏幕常亮。
- **时好时坏**： 重启两端应用、再重启路由器（设备重新广播后发现往往就恢复了）；仍不稳定时对照[电脑版下载与安装.md](电脑版下载与安装.md)核对两端版本是否都较新。
- **跨网络传输失败**： 不同网络之间走的是 WebRTC 近距离分享路径，受双方网络环境影响大，不保证成功；重要文件还是约到同一局域网里传，流程见[手机和电脑互传文件.md](手机和电脑互传文件.md)。
- **列表里死活没有对方，但你知道它的 IP**： iOS 端从 2.7.0 起支持按 IP 地址直接向设备发送（官方更新说明），知道对方局域网 IP 时可以绕开设备列表直接发起；其他端有没有同样入口以实际版本为准，没有的话回到本篇第一、二节把发现修好。

## 五、速度慢、传到一半卡住

发现正常但速度不对劲时，按这几条调，每条都有明确动作：

- **两端连同一个频段**： 一端 2.4G、一端 5G 时，速度会被拖到慢的那一端。手动把两端都连到 5GHz（同频段、离路由器近）再试。
- **靠近路由器、少穿墙**： Wi-Fi 信号衰减直接反映在传输速度上，挪近两米测试立见分晓。
- **关掉省电模式**： 手机的省电/低电量模式会压低后台网络活动，大文件传输期间先退出省电模式。
- **暂停两端的后台抢网**： 云备份、系统更新、别人正在看的 4K 视频都在抢带宽，传大文件前把两端的同步与下载停一停。
- **一次少传点**： 一批几百个文件中途失败就分批发（比如每次 50 个），单批越小越不容易被一次网络抖动打断。
- **重启路由器**： 路由器长时间运行会积累状态问题，断电 30 秒再通电是屡试不爽的老办法。

速度参考：有用户实测电脑往手机传 1GB 左右压缩包约 6MB/s 以上——局域网传输的上限由路由器与网卡决定，和宽带套餐无关；怎么选工具的场景差异见[和微信传文件有什么区别.md](和微信传文件有什么区别.md)。
