## 一、先确认你要装的包

LANDrop 是一个跨平台的局域网文件传输工具，装在手机上就能和同一 Wi-Fi 下的电脑、平板互传文件，不注册账号、不走互联网。手机端是安卓 APK，下面这份是本页对应的安装包事实：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.8.1 |
| 包名 | `app.landrop.landrop_flutter` |
| 大小 | 45.16M |
| MD5 | `4231C2C0F249AA478412DC14B7E7CB70` |
| 系统要求 | 安卓 5.2 及以上（以安装时的提示为准） |
| 整理时间 | 2026-09-23 |

官方商店与官网页面上的版本会随更新变动，如果你要装的就是这一版，核对包名与 MD5 即可；只想装最新版，可以对照[电脑版下载与安装.md](电脑版下载与安装.md)里说的官网入口。

## 二、下载与安装步骤

1. 打开 [LANDrop 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9f85e5f9d145)，把 `LANDrop_v2.8.1.apk` 转存到自己的网盘后下载到手机；
2. 在手机上点开这个 APK，系统会提示「禁止安装来自此来源的应用」——这是安装第三方 APK 时的常规拦截，确认继续即可（不同品牌路径略有差异，一般在 设置 → 安全/安装未知应用 里给浏览器或文件管理器授权）；
3. 装完打开应用，进入主界面就算成功。

安装失败或装上就闪退时，先核对下载的文件是否完整（MD5 对不上就重新下载），再看是不是手机系统低于上表要求。

## 三、首次启动给两样权限

打开 LANDrop 后，你至少会碰到这两个授权请求，都建议同意，否则功能会缺一块：

- **本地网络（局域网）权限**： LANDrop 靠它发现同一网络里的其他设备。拒绝了就谁也看不见谁，事后要到 设置 → 隐私 → 本地网络 里手动补开（iOS 端同样叫「本地网络」）。
- **存储 / 文件访问权限**： 用来读你要发的文件、保存收到的文件。安卓 13 及以上一般叫「照片和视频 / 音乐和音频」，按提示给即可。

第一次启动时有的机型会提示重启应用才生效，按提示退出再进一次就行。

## 四、别忘了另一端

LANDrop 至少要两台设备才玩得起来：手机这端装好后，电脑那端也要装一个，两端同时开着、连在同一个 Wi-Fi 下才会互相出现在设备列表里。电脑端（Windows / macOS / Linux）怎么拿，见[电脑版下载与安装.md](电脑版下载与安装.md)；装好之后怎么收发，见[手机和电脑互传文件.md](手机和电脑互传文件.md)。如果列表里看不到对方，按[找不到设备怎么办.md](找不到设备怎么办.md)逐条排查。
