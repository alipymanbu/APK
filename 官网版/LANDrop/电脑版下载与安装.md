## 一、电脑端去哪下

LANDrop 官方下载页是 [landrop.app](https://landrop.app/)，页面上的下载区分 iOS、Android/TV、macOS、Windows、Linux 几个标签，点对应的标签取安装包即可；官方还维护一个版本信息接口 `https://releases.landrop.app/versions.json`（页面自动读取，你不用管），各平台当前版本以官网下载区当时显示为准。

2026-09 查到的各端版本供参照（**会随更新变化，以官网为准**）：

| 平台 | 版本 | 获取方式 |
| --- | --- | --- |
| Android | 2.8.1 | 官网 APK，或本页头部的[LANDrop 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9f85e5f9d145) |
| Windows / macOS / Linux | 2.7.2 | 官网对应标签下载（Windows 为 ZIP 压缩包，Linux 提供 AppImage） |
| iOS | 2.8.2 | App Store 搜索 LANDrop |

Android TV 与安卓手机共用同一个 APK，官网下载区标注了「supports TV」。

## 二、Windows 上怎么跑起来

1. 下载到的是一个 **ZIP**，用系统自带的解压或任意解压工具解开；
2. 双击解压目录里的 `LANDrop.exe`，右下角出现通知、任务栏托盘里出现图标，就说明已经在运行；
3. 它**没有安装向导**，绿色解压即用——所以目录别随手删，删了入口就没了；想常驻的话用下面第三节的开机自启。

macOS 下载 `.dmg` 拖进应用程序即可；Linux 的 AppImage 需要赋予可执行权限后运行，官方也提示个别发行版可能跑不起来，遇到时需要自行编译（依赖 Qt 与 libsodium，参考其 GitHub 仓库 README）。

## 三、值得先改的三个设置

电脑端在托盘图标的右键菜单 / 设置界面里能改这些：

- **开机自启**： 开机自动挂到托盘，手机随时能发过来，不用每次手动开；
- **接收保存目录**： 默认位置收完就找不着文件的人很多，提前改成你常用的文件夹，收完直接落在那里；
- **设备名**： 电脑默认设备名可能和别人重名或不好认，在设置里改成一眼能认出的名字——手机端列表里显示的就是它，认错设备常常是名字太像引起的。

## 四、电脑端收不到手机文件

十有八九是防火墙没放行，走[找不到设备怎么办.md](找不到设备怎么办.md)第三节；若网络条件本身不满足（不同网、隔离、频段），同一篇的第一、二节就是对症的排查。装好电脑端后的完整收发流程，在[手机和电脑互传文件.md](手机和电脑互传文件.md)。
