# imageX 提示词写法与效果调整

> 本篇讲 imageX 里那句「提示词」怎么写更容易出想要的图：一个可套用的描述结构、应用自带的优化功能怎么用、生成结果不对劲时往哪个方向调。

## 一、提示词就是那句「画面描述」

你在创作页输入的文字，就是应用生成图片的依据——写「一只戴帽子的猫」，出来的就是它对这句话的理解；写得越具体，结果越接近预期。一个够用的描述结构：

```text
主体 + 动作/状态 + 场景 + 风格 + 画质要求
```

举例（可直接改着用）：

- 一只橘猫，趴在窗台上打盹，午后阳光，水彩风格，画面柔和；
- 未来城市夜景，雨后街道霓虹灯，赛博朋克风格，高清细节。

不用追求一次写到位：先写个大概，出图后按缺口补词，比憋一个完美提示词更快。

## 二、不会写就先点「优化提示词」

创作页的输入框旁有提示词优化功能——把你随手写的一句交给它改写成更完整的描述，再决定用不用。官方服务协议里也写明：生成结果不理想时，可以调整提示词或使用提示词优化功能。

两种输入语言都可以：输入框支持中文，也可以选择输入英文提示词。同一画面两种语言各试一次，效果经常不一样。

## 三、风格和参数放在一起调

风格在创作页的风格列表里选，常用方向：

| 想要的感觉 | 可以试的风格 |
| --- | --- |
| 动漫、插画感 | 二次元、动漫 |
| 传统绘画 | 油画、水彩、粉彩画 |
| 国风题材 | 国风华服 |
| 科幻、未来感 | 赛博朋克、概念艺术 |
| 复古游戏画面 | 像素艺术 |
| 影视质感 | CG 渲染、超现实 |

风格列表以应用内实际可选为准，版本更新会增减新风格——有渠道的 1.3.1 更新说明提到这一版新增了「像素艺术」「CG 渲染」两种风格。同一句提示词配不同风格各出一张，比反复改词更直观。

## 四、生成结果不对劲，按这个顺序调

1. **结果跑偏**：描述里补上主体数量、动作、环境等缺口信息，重新生成；
2. **画面发糊**：提高分辨率档位，或在提示词里补「高清画质、细节丰富、光影柔和」这类画质词；
3. **整体可以、局部不行**：用局部重绘功能，只重画那一块，别整张重来；
4. **怎么调都不满意**：去广场搜相近主题的成品，点开看别人的关键词，生成同款后再改。

## 五、提示词被拒绝的情况

应用对提示词有敏感词过滤，官方服务协议说明会对提交的描述做合法性判断——涉及违规内容的提示词不会出图。被拦下时换一个正常、合规的描述即可，这不是故障。调整思路回到上一节的顺序，出图入口的操作见 [AI创作出图流程.md](AI创作出图流程.md)。
