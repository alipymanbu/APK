## 一、四个词就够了

| 词 | 可以把它理解成 | 在手机上怎么用 |
| --- | --- | --- |
| 对象 Object | 一页内容：一篇笔记、一个任务、一本书 | 空间里点加号新建，或从类型入口建 |
| 类型 Type | 对象的归类：笔记、任务、联系人 | 新建时先选类型，类型决定这一页长什么样 |
| 属性 Property | 挂在对象上的字段：截止日期、状态、作者 | 编辑对象时在头部区域添加、填写 |
| 查询 Query | 按条件自动聚合同类对象的列表 | 类型页面自带，相当于自动生成的目录 |

查旧教程时会碰到两个改名：**0.37 版起 Relations（关系）改叫 Properties（属性），Set（集合）改叫 Query（查询）**。东西还是那些东西，只是换了名字。

0.37 之后类型的权重更高：布局和属性都定义在类型上，同类型对象自动继承；模板则退回去只管内容块，不再管属性和布局。你在手机上给一个对象改属性值没问题，但想让整类对象都长一样，要去改类型本身。

## 二、空间（Space）

- 一个身份（库）里可以建多个空间，比如「工作」「个人」「读书笔记」，空间之间内容互相隔离。
- 0.39 版重做了库首页：加了**空间搜索**，空间多了不用翻找；通过快捷菜单可以置顶、管理或退出空间。
- 退出他人共享的空间不再需要空间主批准，自己点退出即生效。

## 三、手机上从零建一条内容

1. 进入一个空间，点新建按钮。
2. 选一个类型（笔记 Note 是最通用的起点）。
3. 正文区是块式编辑：键盘上方工具栏可插入标题、清单、待办、图片；0.39 起撤销/重做按钮常驻在这个工具栏上，写错了随手可退。
4. 建完回到空间首页——第一个该类型的对象创建后，首页会**自动生成一个小部件（Widget）**把同类对象聚在眼前；不需要就删掉，也可以在空间设置里关掉自动创建。

## 四、对象链接可以直接分享

0.37 起，对象菜单里的「复制链接」得到的是一条 HTTPS 链接：发给同样装了 Anytype 的人，对方点开直达该对象；如果对象在共享空间里，链接还附带加入邀请。浏览器里直接点开这类链接通常进不去——处理办法见 [移动端常见问题排查.md](移动端常见问题排查.md)。

## 五、界面语言与外观

- **界面语言**：设置里提供社区翻译版本可选，其中有简体中文；翻译覆盖不一定完整，部分界面仍会显示英文，以应用内的语言列表为准。
- **外观**：明亮、深色、跟随系统三种颜色模式。
- **默认对象类型**：可指定每次点 + 新建时默认打开的类型，固定记某一类内容的话能省一步。

这些选项主要在「设置」里找，手机端与桌面端的入口位置以实际界面为准。

## 六、手机端先别期待的功能

多列布局、看板/日历/图谱视图、公式、嵌入块、导入导出、PIN 锁等在手机端暂未提供，完整清单与替代做法见 [移动端常见问题排查.md](移动端常见问题排查.md)。这些需求目前要回桌面端完成：桌面版的获取方式在 [下载与安装教程.md](下载与安装教程.md) 里一并给了官方入口，导入导出的具体操作见 [数据导入与导出.md](数据导入与导出.md)。

上手顺序建议：先用默认类型记三五条，找到「对象+类型」的手感，再考虑自建类型和属性——一上来就设计结构，是这类工具最常见的劝退点。
