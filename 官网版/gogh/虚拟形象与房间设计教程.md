## 一、移动与视角：手势对照

房间里所有操作都靠这套手势，先熟悉它：

| 你想做什么 | 操作 |
| --- | --- |
| 移动角色 | 选中角色后**拖动** |
| 给角色换姿势 | 选中角色 → 点「姿势」 |
| 让角色坐下 | 点**椅子** → 选「姿势」 |
| 让角色躺下 | 点**床** → 选「姿势」 |
| 换掉当前姿势 | 再点一次正在摆姿势的那件物品 |
| 镜头拉近/拉远 | **双指捏合/张开** |
| 镜头水平平移 | 双指按住屏幕，向任意方向拖 |
| 选中物品 | 点它（点别的会把选择转移过去） |

左下角还有个摇杆可以走镜头，两种方式随便用哪个顺手。

## 二、往房间里加东西 / 收东西

1. 点**屏幕左侧的画笔按钮**，进房间编辑界面；
2. **放置**：点物品图标直接放，或**长按拖到屏幕上半部分**摆到你想要的位置；
3. **收起**：选中要收的物品 → 点「删除」。

配色是这套编辑器的重点：家具、小物件都能调颜色与角度，墙面、地板、天花板这类**内装**也能整体换——换个墙纸整间房的气质就变了。

**两个上限（移动版）**：

- 房间内可放置的物品**最多 200 件**；
- 房间物品上可附加的图片**总共最多 50 张**（具体以你版本的官方页面为准）。

堆太多会直接反映成卡顿，处理办法见 [常见问题与闪退卡顿排查.md](常见问题与闪退卡顿排查.md)。

## 三、贴纸：贴上去与删掉

**贴法**：在编辑房间或角色时，带「贴纸」按钮的物品才支持——**长按想要的贴纸拖到屏幕上半部分**，落点就是它的位置。

**删法**（贴错、贴多了都走这里）：

1. 房间编辑界面 → 选中物品 → 点「编辑」；
2. 点贴纸（方框）按钮 → 点**文件夹图标**；
3. 点「选择并删除」，勾掉不要的贴纸。

你自己的贴纸库存**上限是 50 张**。要注意：显示器、相框这类「上传了图片」的家具，图片会**自动存进你的贴纸库**；如果你在贴纸库里删了它，家具上的那张图过一段时间也会跟着消失。

贴纸满了或者突然加不上图，见 [常见问题与闪退卡顿排查.md](常见问题与闪退卡顿排查.md)。

## 四、形象怎么改、怎么重置

点**右下角的虚拟形象按钮**进编辑界面：发型（短/中/长等）、眼睛形状、瞳孔图案、服装与配饰逐项挑，部件支持调色（改明度/彩度），还能贴贴纸。改完保存即可。

**重置形象**：形象编辑界面 → 右下角图标 → 右侧的重置图标 → 勾选「我已了解以上内容」→ 重置。**当前外观和服装会全部清掉**，没有中间态，按之前想清楚。

**重置房间**同理，路径稍不同：首页右侧「…」→「房间设置」→「重置」→ 选新房间风格 → 勾选确认。**房间里已摆放的道具会全部删除**——想保留现有布置就别走这条路。

## 五、拍照与录像

- 点**屏幕左侧的相机图标**开相机；
- 快门上方的「照片 / 视频」切换模式；
- 右下角的相机图标切换拍摄方式：
  - **无人机相机**：用摇杆推着镜头走；
  - **手持相机**：举起手机，像真拿相机一样环顾房间。

**视频最长 30 秒**。拍完的画面会存进相册，配合账号功能可以分享（用到照片权限，见 [下载与安装教程.md](下载与安装教程.md)）。

## 六、三个「看起来像 bug 其实是设计」的点

| 现象 | 真相 |
| --- | --- |
| 放不了窗帘 | 窗帘**只能放进特定房间**，跟房间样式有关 |
| 想换窗外的风景 | 换不了，**窗外景色绑定房间设计**，选完就定死 |
| 画面局部发白 | 你把颜色调得接近纯白了，改深一点就好 |
