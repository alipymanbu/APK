## 一、卡顿、发热：先动三个开关

官方排障文档的第一条就是这里，顺序别乱：

1. **首页左上角进设置 → 「图形」**；
2. 选 **「低画质」+「30fps」**——这是立竿见影的一档；
3. **减少房间里摆放的物品数量、减少贴上的贴纸数量**；
4. 关掉其他后台应用再试；还不行就重启应用、更新版本、重启手机。

这是一款 3D 应用，机器负载与房间里的东西直接挂钩，所以「房间越满越卡」不是玄学。

## 二、闪退 / 运行异常

按这条链走：

1. 同上，降画质、减物品、减贴纸；
2. 关闭其他应用后重试；
3. 重启应用 → 检查有没有新版本 → 重启设备；
4. **换一台设备试**——能跑说明是本机性能或系统版本问题；同样闪退则是版本/账号侧的问题，考虑重装（安装包见 [下载与安装教程.md](下载与安装教程.md)）。

官方对该问题的定位是「3D 图形需要内存，部分设备可能无法正常运行」，所以低配机降画质是长期方案，不是将就。

## 三、加载慢、卡在加载画面

| 现象 | 官方给的判断 |
| --- | --- |
| 一直进不去 | 网速可能不达标，先测速 |
| 加载时间很长 | 3D 数据量大，换 Wi-Fi 环境再试 |
| 空间（多人）一直加载 | **首次进入会额外下载 CG 数据包**，慢网要多等 |

## 四、计时没记上、通知不弹

这不算崩溃，但比崩溃更常见：**计时器只有手动按「结束」才会写进统计**，被系统杀掉、划掉应用都记不上。当天可补录，路径与后台设置见 [番茄钟计时器怎么用.md](番茄钟计时器怎么用.md)。通知不弹则是**后台自动启动权限**没给，按那一篇的说明开。

## 五、贴纸满了 / 图片加不上

- **「我的贴纸已满」**：上限 50 张，删掉用不上的（删除路径见 [虚拟形象与房间设计教程.md](虚拟形象与房间设计教程.md)）。注意显示器、相框上贴的图会自动占库存，删库存可能连累家具上的图；
- **加不进新图**：如果你刚删过一大批（超上限后清过），删除要一段时间才生效，**等一会儿再试**，不是坏了；
- **提示「允许访问照片」**：先把应用彻底关掉一次，再去系统设置里授予照片权限。官方同时说明：**你的照片不会被自动上传**。

## 六、空间（多人功能）里的异常

空间是什么、怎么进怎么退，见 [多人空间与好友功能怎么用.md](多人空间与好友功能怎么用.md)；出了问题对下表：

| 现象 | 原因与处理 |
| --- | --- |
| 进空间就崩 | 空间**要求至少 4GB 运行内存**，先对推荐配置；人多、别人贴纸多也会撑爆内存 |
| 空间里没有其他人 | 分到的实例可能已满，等别人进，或用「已加入的好友」功能直达（官方标注为**实验功能**，可能不准） |
| 自己的座位动不了 / 看不见某人 | 多半是被判定成「已退出」（切后台就会被判）。**重启应用重新进空间** |
| 某人一直杵在空间里没走 | 对方没点退出就关了应用或闪退了，等他自己恢复即可 |
| 改了 BGM 怎么别人都没变 | 设计如此，音量按人各自生效 |

## 七、界面类的疑问

- **iPad 上物品列表看着特别少**：不是缺了，是屏幕显示区域问题——**往下滚动虚拟形象菜单**就能看到其余的；
- **邀请好友进我的房间**：移动版**做不到**，「房间公开」是 Steam 版功能；
- **想放窗帘**：窗帘只在特定房间样式里提供；
- **画面发白 / 过曝**：两个来源——①画质设成了「低画质」，官方说明这一档**本身就会出现过曝**；②房间物品或形象用了接近白色的颜色。按①②各调一次；
- **房间里飞的黑色小生物**：官方说是表情显示的 bug，「它本来是可爱的」。

## 八、账号与登录出问题

验证码收不到、密码忘了、换手机找回——全部走 [下载与安装教程.md](下载与安装教程.md) 第五节的账号排查，那边按官方帮助中心逐条列了。
