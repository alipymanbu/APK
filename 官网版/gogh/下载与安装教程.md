## 一、这是个什么应用

gogh 是一款「虚拟形象 + 专注」的效率类应用：你先捏一个自己的 3D 角色、布置一间房，然后开着计时器、放上音乐，让角色陪你在画面里一起学习或工作。它免费、无广告，账号体系独立于 Steam 版（两者数据不互通，详见 [和Steam版有什么区别.md](和Steam版有什么区别.md)）。

官方名称就是小写的 `gogh`，中文名常写作「咕盒」，开发者署名 gogh Japan。

## 三、系统要求（三个来源，各有口径）

同一份资料里系统要求常出现三个不同数字，别混淆：

- 本地留存的这份安装包标注：**安卓 5.2 以上**；
- 应用商店页面标注：**安卓 8.0 及以上**；
- 官方帮助中心的「推荐配置」：**Android 13 或以上、骁龙 690 5G 或以上、运行内存 4GB 或以上**（以官方页面当时显示为准）。

实际体验上，这是一款 3D 应用，**低于推荐配置的机器能装、但可能卡**——处理办法见 [常见问题与闪退卡顿排查.md](常见问题与闪退卡顿排查.md)。移动端支持 iOS、iPadOS、Android，官方帮助中心同时给出 iOS 17.7+、iPadOS 18+ 的推荐值。

## 四、安装步骤（安卓）

1. 从 [gogh 安装文件资源（夸克网盘）](https://pan.quark.cn/s/720d2dd8a221) 取到 `.apk` 文件；
2. 在手机文件管理器里点该文件开始安装；
3. 若提示「禁止安装未知来源应用」，按系统提示给文件管理器（或浏览器）授予一次「安装未知应用」权限，再回来点安装；
4. 装完先别急着删安装包——建议核对一次包名 `com.goghjapan.gogh_android` 与 MD5；
5. 首次启动会申请照片、通知等权限。照片权限用于把图片贴到家具/贴纸上，可以先允许，也可以之后在系统设置里再改。

走官方商店的路径是另一回事：Google Play 与 App Store 里搜 `gogh` 即可，商店版会自动更新；网盘这份是某个时间点的离线包，不会自动更新。

## 五、注册与登录

移动版**需要注册账号**（这是官方对「移动版 vs Steam 版」差异表里明确写的一条）。官方帮助中心列出的登录方式共四种：

| 方式 | 适用 |
| --- | --- |
| 邮箱地址 | 全平台 |
| Google 账号 | 全平台 |
| Apple ID | 仅 iOS |
| 电话号码 | **仅日本** |

几个实打实会卡住人的点：

- **验证码是 6 位数字**，官方要求在发出后 **3 分钟内**粘贴进应用；
- 发出 **60 秒后**右下角会出现「重发」按钮，点了会换新码——重发后要用**最新一封**邮件里的号码，否则提示「代码不一致」；
- 验证邮件标题是 `Verification Code from gogh`，收不到先翻**垃圾邮件箱**，再确认邮箱/手机号没打错、没用成以前注册过的账号；
- 官方曾公告 Gmail 收码存在临时故障，收不到时换个邮箱服务注册，或改用手机号注册；
- 忘记密码：标题画面选「登录」→「无法登录」里可以改密码（已在应用内的话，先从设置里退出登录回到标题画面）。

换手机怎么把数据接上、忘了当初用哪种方式注册怎么找回、能不能绑多个登录方式——这些都归「账号连携」管，单独写在 [换手机与数据找回怎么办.md](换手机与数据找回怎么办.md)，本篇不重复。

**注册之后你仍然可以随时改形象和房间**，不用怕先注册会锁死选择。

## 六、首次进入建议先做的三件事

1. **进设置（首页左上角）把画质调好**：中低端机直接选「低画质 + 30fps」，比出问题再救省事（这一档可能让画面过曝，真出现了按 [常见问题与闪退卡顿排查.md](常见问题与闪退卡顿排查.md) 第七节调）；
2. **建一个计时器预设**：gogh 的计时器要先建预设才能用，见 [番茄钟计时器怎么用.md](番茄钟计时器怎么用.md)；
3. **确认照片权限**：想往房间里贴图的话，权限没给会在用到时才报错，提前给掉更顺。
