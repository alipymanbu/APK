## 一、先说结论：这是两个独立应用

官方在更新通讯里反复强调：**移动版和 Steam 版是当成两款不同的应用开发的**——不是「免费版 vs 付费版」，也不是「移动版是 Steam 的阉割版」。

- 移动版：2024 年上线（官方通讯写的是 2024 年 7 月），免费、需注册账号；
- Steam 版：2025 年 4 月 30 日上线，买断付费（国区定价 45 元，另有付费 DLC，价格以商店页当时显示为准），不需要注册 gogh 账号；
- **两边账号不互通、进度不共享**，官方明确回答过「不能账号互通」这个高频问题。

所以你在手机上捏的房子和角色，**不会**出现在电脑上，反之亦然。手机端的安装与账号问题见 [下载与安装教程.md](下载与安装教程.md)。

## 二、功能对照（官方帮助中心口径，截至 2026-07-30）

| 项目 | Steam 版 | 移动版 |
| --- | --- | --- |
| 收费 | 付费 | 免费 |
| 账号注册 | 不需要 | 需要 |
| 支持语言 | 15 种 | 4 种 |
| 保存多个虚拟形象 | 最多 18 个 | 不支持 |
| 形象服装方案保存 | 每形象 3 套 | 不支持 |
| 保存多个房间 | 最多 27 个 | 不支持 |
| 房间状态存档 | 每房间 3 个 | 1 个 |
| 房间物品数量上限 | 1000 件 | 200 件 |
| 物品附加图片总量 | 约 4000 张（总容量 4GB） | 50 张 |
| 附加 GIF、网络摄像头流 | 支持 | 不支持 |
| 网格摆放 | 支持 | 不支持 |
| **计时器预设** | 不支持 | **支持** |
| To-Do 清单 | 支持 | 支持（日常习惯、日记则仅 Steam） |
| 文字/手绘聊天 | 支持 | 不支持 |
| 创意工坊 | 支持 | 不支持 |
| 面部追踪、隐藏形象、镜头 FOV/滤镜 | 支持 | 不支持 |
| 本地音乐播放列表 | 支持 | 不支持 |
| 多人玩法 | **房间发布**（可去别人房间） | **空间功能**（进公共空间） |
| 贴纸功能 | 不支持 | **支持** |
| 好友功能 | 不支持 | **支持，最多 200 人** |

三点容易看错的：

1. **移动版不是全面落后**——计时器预设、贴纸、好友、空间是它独有的，「随手开个番茄钟」这件事手机端更顺；
2. **两边的多人是两套系统**：Steam 走「房间发布」（把自建房公开、别人能进来），移动版走「空间」（进公共场合，见 [常见问题与闪退卡顿排查.md](常见问题与闪退卡顿排查.md) 第六节）；
3. 这张表**会随版本更新变化**（官方每期通讯都会刷新），一切以官方帮助中心当时那张表为准。

## 三、差异是怎么来的（官方解释的要点）

官方在「gogh 通讯 第12期」里给过说明，跟你的选择直接相关的就两条：

- **两支团队分开做**：移动版上线时并没打算做 PC 版，Steam 版是后来应用户要求、由另一拨人从头做的，两边各自按平台特性演进；
- **性能约束不同**：手机的 CPU/GPU/内存远不如电脑，所以移动版砍掉大房间、低物品上限、换用「空间」而非「房间发布」，是为了让更多机型跑得动。

理解这两条，就不会把「这个功能怎么没移植」当成区别对待——两边本来就是并行迭代、互相抄作业的关系（官方举的例子是 Steam 端呼声高的「彩度滑块」后来加到了移动端）。

## 四、怎么选

- **只在手机/平板上用，图免费** → 移动版就够，重点看 [番茄钟计时器怎么用.md](番茄钟计时器怎么用.md) 和 [虚拟形象与房间设计教程.md](虚拟形象与房间设计教程.md)；
- **想要大房间、多存档、要聊天、要创意工坊** → 上 Steam 版，Windows 与 macOS 都能用；
- **两边都想用** → 接受它是两份数据的事实，别指望同步（换机怎么接数据见 [换手机与数据找回怎么办.md](换手机与数据找回怎么办.md)）。

## 五、真要上 Steam，机器得够格

官方 Steam 版 FAQ 给的配置口径（截至检索时，以官方页面当时显示为准）：

| 项目 | 最低 | 推荐 |
| --- | --- | --- |
| Windows 系统 | Windows 10 / 11，64 位 | 同左 |
| 处理器 | Intel Core i5-1235U | Intel Core i7-6700 / AMD Ryzen 5 2600 |
| 内存 | 8 GB | 16 GB |
| 显卡 | Intel Iris Xe Graphics | NVIDIA GTX 1060 / Radeon RX580 |
| DirectX | 11 | 11 |
| 硬盘空间 | 3 GB 可用 | 3 GB 可用 |
| macOS | Apple M1、16 GB 内存、macOS 14.0 (Sonoma) | Apple M2、16 GB 内存、macOS 14.0 |

对照手机端的推荐配置（Android 13+ / 骁龙 690 5G+ / 4GB，见 [下载与安装教程.md](下载与安装教程.md) 第三节），差别主要在显卡与内存——两边对机器的要求根本不是一个量级。
