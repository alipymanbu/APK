# AniFun 导航站收录了哪些站点

> AniFun 的导航板块按分组收录了各类 ACGN 站点，这篇把分组结构、代表性条目和几个容易忽略的工具类入口列清楚。

## 一、分组结构一览

导航板块（网页版入口 [anifun.cn/nav](https://anifun.cn/nav)）把站点按用途分组，找内容前先对号入座：

| 分组 | 收什么 | 代表条目 |
| --- | --- | --- |
| 热门网站 | 日常大站与通用工具 | 哔哩哔哩、YouTube、Pixiv、萌娘百科、MyAnimeList |
| 动画网站 | 视频/番剧类平台 | 哔哩哔哩、腾讯视频、爱奇艺、优酷、AcFun、巴哈姆特动画疯、Niconico、Crunchyroll |
| 漫画网站 | 漫画阅读平台 | 哔哩哔哩漫画、腾讯动漫、快看漫画、漫客栈、动漫屋、LINE WEBTOON |
| 小说站点 | 轻小说阅读站 | 哔哩轻小说、轻之国度 |

站点的收录会随时间调整，上面是整理时的条目，以站内当前展示为准。

## 二、先读条目简介，再决定点不点

不少条目下面带一句话简介，说明了这个平台的定位与内容侧重，例如腾讯动漫标着「以原创国漫、日漫正版授权为核心内容」，快看漫画标着「以条漫、少女漫、原创 IP 为特色」。点开之前先扫一眼简介，能省掉进错站再退出来的功夫：想看正版连载就挑简介里带「正版」字样的平台，想找特定题材就按简介里的侧重判断。

## 三、容易忽略的工具与资料站

导航里除了内容站点，还混着几个工具与资料类入口，找番之外照样用得上：

| 条目 | 用途 |
| --- | --- |
| 以图搜番 | 拿一张截图反查出自哪部作品 |
| 动画巡礼 | 圣地巡礼地图（[anitabi.cn/map](https://anitabi.cn/map)），查作品取景地 |
| 萌娘百科 / MyAnimeList / Bangumi | 作品与角色的社区资料站，评分与词条比官方介绍更接地气 |
| 猫耳FM | 广播剧与声音类内容 |

截图找不出的番、取景地打卡、想看「路人评分」再决定入不入坑，这几个入口就是干这些的。

## 四、把常用入口固定到「我的导航」

每天都要开的几个站点，别每次都去分组里翻 —— 把它们收进「我的导航」（网页版路径 [anifun.cn/my/nav](https://anifun.cn/my/nav)），打开导航板块第一眼就是自己的高频入口。导航板块在 app 里的位置与整体用法，见 [怎么用与找番方法.md](怎么用与找番方法.md)；两个入口（app 与网页版）的取舍见 [官网入口与App怎么选.md](官网入口与App怎么选.md)；在这里找到想追的番之后，按季安排更新见 [新番时间表与追番规划.md](新番时间表与追番规划.md)。
