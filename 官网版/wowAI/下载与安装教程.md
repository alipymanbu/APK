## 一、安装前先知道这几件事

Wow 是美团旗下团队做的 AI 陪伴社区应用（应用商店里就叫「Wow」，不少人搜「wowAI」找到的也是它），开发与运营方都是上海三快省心购科技有限公司。它是纯手机应用，没有官方电脑版；想在电脑上跑，只能借助安卓模拟环境，见[常见问题解答](常见问题解答.md)里的电脑使用一节。

运行它需要联网，离线状态下角色对话和语音通话都用不了。

**先说一件更要紧的事**：Wow 已于 2025 年 12 月 18 日关闭服务器（详见[停服说明](停服说明.md)）。安装包现在仍能正常安装，但**装上后无法登录**，聊天、通话、创建角色都不可用 —— 想留档研究或回看操作流程再装，装了是登不进去的。

本次安装包的基本信息如下，装之前可以核对一下：

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.18.2 |
| 安装包大小 | 67.76M |
| 包名 | com.meituan.like.android |
| MD5 | 108C7DA575D019B8C60E31C0415EE7AB |
| 开发者 | 上海三快省心购科技有限公司 |

两点提醒：不同渠道展示的体积可能不一样（有的商店标 90M 上下，统计口径与版本不同所致），以你实际下载到的安装包属性为准；网上搜到的「官方最新版」版本号可能更高，属于正常现象，本资源是 1.18.2 这一版。

## 二、从夸克网盘获取安装包

[Wow 安装文件资源（夸克网盘）](https://pan.quark.cn/s/273084200748)里放的是上面表格中这一版的安装包，取用步骤：

1. 手机或电脑上打开上面的网盘链接；
2. 把文件**转存到自己的网盘**（分享内容先保存再下载，避免失效）；
3. 手机装好夸克网盘 App 后，在转存的位置找到 `.apk` 文件，点下载；
4. 下载完成后直接在下载完成页点「安装」，或去网盘的「传输列表」里找到该文件安装。

如果你对安装包完整性有要求，可以比对 MD5：手机上可用带校验功能的文件管理器，电脑上可用 `certutil -hashfile 文件名.apk MD5`（Windows）算出值，与表格里的 `108C7DA575D019B8C60E31C0415EE7AB` 对得上就说明文件没坏。

## 三、安装步骤

1. 点开下载好的 `.apk` 文件；
2. 系统弹出「是否允许安装」时选允许。如果提示「禁止安装未知来源应用」，去手机 **设置 → 安全（或隐私）→ 安装未知应用**，给夸克网盘（或你用的浏览器）授权「允许安装未知应用」，再回来重试。不同品牌的菜单位置略有差异，搜「安装未知应用」一般能直接找到；
3. 等安装进度走完，点「打开」或回到桌面点 Wow 图标。

## 四、首次打开

第一次打开会依次遇到两件事：

1. **隐私政策**：勾选同意后才能进入；
2. **登录**：用手机号验证码登录。停服前登录是没问题的；现在这一步会**失败**——登录请求已无服务端处理，这不是你操作或验证码的问题。

停服前的登录之后会进入角色推荐页，接下来的玩法见[聊天与语音通话玩法](聊天与语音通话玩法.md)；想造一个完全按自己心意来的角色，看[AI角色创建教程](AI角色创建教程.md)。

## 五、装不上时的排查顺序

按出现概率从高到低：

| 现象 | 先查什么 |
| --- | --- |
| 提示「应用未安装」 | 安装包是否下载完整（重新下载一次，再对 MD5）；手机剩余存储是否够（建议留出安装包 2 倍以上空间） |
| 点了没反应 / 一闪而过 | 未知来源授权是否已给到「下载它的那个应用」；重启手机再装一次 |
| 提示系统版本过低 | 手机系统太旧，先升级系统；老机型装不上没有替代办法 |
| 安装中断 / 卡住 | 关掉正在运行的清理类软件，避免安装过程被杀后台 |
| 装上了但登录不上 / 验证码收不到也不算异常 | 服务器已于 2025-12-18 关闭，登录必然失败，见[停服说明](停服说明.md) |

装好之后的其他历史问题（对话被拦、回复不连贯等）整理在[常见问题解答](常见问题解答.md)里。
