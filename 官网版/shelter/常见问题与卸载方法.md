## 一、安装与启动类

**Q：装的时候提示签名冲突？**
说明设备上已有另一个渠道签名的 Shelter（Google Play、F-Droid、自建源三者签名不同）。先按下面第五节卸干净，再装你想要的那个渠道版本。渠道之间不能覆盖升级。

**Q：设置向导拉不起工作资料 / 一建就闪退？**
Shelter 完全依赖系统的 Work Profile 实现，部分国产 ROM 对它的实现不完整。已知开发者明确点名过 MIUI 这类实现可能有问题的系统；ColorOS 部分版本上也有装完用不了的反馈。先升级到最新版再试（本地这份是 1.9.1，1.9.1 正是针对 Android 11 以下崩溃的热修复版），仍不行就只能等系统更新，没有通用绕法。

**Q：设置向导里的英文/说明能不能跳过？**
不建议跳。官方把已知限制与注意事项都写在向导里，README 第一句就是「开始用之前先把 README 读完」。真看漏了，回头也会在跨空间登录、文件访问这些地方撞上同样的限制。

## 二、日常使用类

**Q：Shelter 老在后台挂着，费电吗？**
官方给的处理办法：每次关掉它时，顺手从「最近任务」里把它的卡片划掉。划掉后仍持续出现在通知里并耗电，就属于异常，去官方问题反馈渠道报（见下）。

**Q：能开第二个工作资料吗？和 Island 能一起装吗？**
都不能。一台安卓设备只允许存在一个工作资料，且不允许同时有第二个管理工作资料的应用。Shelter 与 Island、部分手机自带的「安全文件夹」类功能属于互斥关系，装一个就得放弃另一个。

**Q：为什么工作资料里的应用没法用微信登录 / 分享？**
跨空间调用被隔离机制挡住了，属正常表现。解决思路不是开权限，而是在那一份应用里直接输账号，或者用[文件穿梭功能怎么用.md](文件穿梭功能怎么用.md)把需要的东西复制过去。

**Q：隔离到底防得住什么？**
Shelter 官方自己列得很清楚：它不是完整沙箱，防不住安卓系统与 Linux 内核自身的安全漏洞、系统或固件里被预置的后门，以及系统强加的其他限制。它能做的是让被隔离的应用读不到你另一侧空间的数据。对系统本身不放心的话，开源 ROM 才是对应的解法。

**Q：为什么不直接用 Island？**
Shelter 作者的原话是：Island 不是自由开源应用、捆绑了非自由 SDK，Shelter 就是照着它写的开源替代品 —— 除了这一点，两者没有别的取舍差异。你更看重开源可审计就选 Shelter，否则两个都可以试。三条路线（含厂商自带分身）的完整对照见[和自带应用分身及Island的区别.md](和自带应用分身及Island的区别.md)。

**Q：隔离区里的应用收不到消息、推送延迟？**
先看它是不是被你冻住了（图标置灰），没冻的话按[工作资料应用收不到通知怎么办.md](工作资料应用收不到通知怎么办.md)的顺序从上往下查 —— 电池优化与工作资料被暂停是两大常见原因。

## 三、报障时提供什么

遇到崩溃或行为异常，反馈时附上：系统版本与机型、Shelter 版本号（在应用内可见，1.9 起会同时显示构建用的代码提交）、以及 logcat 日志。注意官方维护者说的是**邮件列表与 Matrix 聊天室优先**，代码托管平台上的 issue 列表与 PR 没人定期看。

## 四、卸载前先想清楚

卸载 Shelter **不等于**删掉工作资料。工作资料是系统里的独立空间，里面装的应用、数据会留在系统中。想彻底清掉，按下面顺序来；只想暂时关掉，把工作应用全部冻结就够了，见[冻结应用与自动冻结设置.md](冻结应用与自动冻结设置.md)。

## 五、三步卸载干净

1. **先删工作资料**：打开系统「设置 → 用户与账号」，找到「工作」条目，移除工作资料（不同品牌路径略有差异，有的在「用户与账号 → 工作」）。
2. **再解绑设备管理员**：「设置 → 密码与安全（或安全）→ 系统安全 → 设备管理器（高级设置里的设备管理应用）」，把 Shelter 的管理员权限停用。
3. **最后正常卸载**应用本体。

顺序不能反：工作资料还在时直接卸应用，会留下一个系统里无主的工作资料，之后清理很麻烦。第一步做完后，桌面上带公文包标记的图标应全部消失，没消失就说明还没删干净，回到第一步再确认。
