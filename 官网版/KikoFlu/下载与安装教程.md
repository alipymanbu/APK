## 一、安装前先了解：这是什么应用

KikoFlu 是一个开源的跨平台同人音声客户端（GPL-3.0 协议，源码在 `https://github.com/pa-jesusf/KikoFlu`），支持 Android、iOS、Windows、macOS、Linux 五个平台。它的定位是「播放端」——你需要连接一个音声服务（在线服务或自建的 Kikoeru 服务器）才有内容可听，装完第一件事是配服务器与账号，见 [服务器连接与账号注册.md](服务器连接与账号注册.md)。

界面语言支持简体中文、繁体中文、英语、日语、俄语，默认中文，不用改设置。

## 三、安卓安装步骤

1. 从开头给的 **KikoFlu 安装文件资源（夸克网盘）** 转存后下载 APK 文件（[https://pan.quark.cn/s/3cd0b1b27945](https://pan.quark.cn/s/3cd0b1b27945)）。
2. 点开下载好的 APK。首次安装会提示「未知来源应用」，按手机品牌走一遍允许安装的流程（小米/澎湃在「安装应用」权限里放行，OPPO/一加在「特殊应用权限—安装未知应用」里放行，各机型路径略有差异）。
3. 安装完成后启动。应用本身不大（34 MB 量级），但后续的音频缓存会占空间，建议确认存储余量，相关设置见 [缓存下载与离线收听.md](缓存下载与离线收听.md)。
4. 启动后先别急着找内容——它需要先连上一个音声服务才有东西可听，接着看 [服务器连接与账号注册.md](服务器连接与账号注册.md)。

如果安装或启动卡在某一步，先去 [常见问题排查.md](常见问题排查.md) 对号入座。

## 四、其他平台的版本从哪拿

KikoFlu 是同一套代码编到五个平台，功能基本一致。安卓之外的版本不走网盘，从官方 GitHub Releases 获取：

| 平台 | 发布物 | 说明 |
| --- | --- | --- |
| Android | universal / arm64-v8a 两种 APK | 日常机型选 arm64-v8a 即可，拿不准就选 universal |
| iOS | 未签名 IPA | 不能直接安装，需要签名或走 AltStore / SideStore，完整步骤见 [iOS%20安装与签名教程.md](iOS%20安装与签名教程.md) |
| Windows | 安装包 / 便携版 | 便携版解压即用 |
| macOS | DMG | 拖入应用程序目录 |
| Linux | x64 / arm64 | 按 CPU 架构选择 |

获取入口统一是官方发布页：[https://github.com/pa-jesusf/KikoFlu/releases](https://github.com/pa-jesusf/KikoFlu/releases)。桌面端同样要在设置里配置服务器地址后才能使用。
