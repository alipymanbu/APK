## 一、播放器的基本盘

日常收听会用到这些，都在播放界面或通知栏：

| 功能 | 在哪用 | 说明 |
| --- | --- | --- |
| 后台播放 | 切出应用后自动继续 | 通知栏有播放/暂停、切曲目控制，不用回到应用 |
| 倍速播放 | 播放界面 | 加快过长篇内容、放慢听台词都行 |
| 循环与随机 | 播放界面 | 单曲循环、列表循环、随机播放三种 |
| 全局音频增益 | 播放设置 | 音量偏小的音频可以整体增强，也能衰减 |
| 迷你播放器 | 界面底部 | 浏览其他页面时悬浮着，随时唤出播放页 |
| 进度记忆 | 自动 | 播放项目与进度会持久化，杀掉应用重开也能接着听 |
| 音频触感反馈（Beta） | 播放设置 | 移动端按声音特征让设备振动，不需要就关掉 |

一个作品里往往不止音频——视频、文本、图片、PDF 都可能出现，播放界面里按文件类型切换即可。

## 二、字幕：从哪来、怎么调

字幕相关的能力覆盖面广，实际用下来分三种来源：

1. **自动加载**：作品自带字幕文件时，播放时直接展示，不用手动操作。
2. **自己导入**：支持 `.vtt`、`.srt`、`.lrc`、`.txt`、`.ass`、`.ssa`、`.sub`、`.idx`、`.sbv`、`.dfxp`、`.ttml` 十一种格式。导入后可以编辑文本、调轴（改时间轴对齐音频）、翻译。
3. **播放时实时翻译**：正在播的歌词/台词可以即时翻译，完成后保存下来，下次播放直接用。

一个已知的坑：非标准的 `.lrc` 文件（用毫秒、逗号做分隔符，或时间字段只写了一位数、省略小数部分）在旧版里会被判为「不支持的格式」。官方更新日志显示 v3.8.2 已修复这类识别；你手里这版 3.8.1 遇到 LRC 加载失败，先把文件转成标准格式再导入，或直接更新应用。

看不懂日语作品的用户，标题、文件目录、文本文件、标签都能翻译，翻译目标语言可以单独设置（中/英/日自动标签翻译）。

## 三、悬浮字幕

切到其他应用或熄屏听音频时，字幕可以悬浮在画面之上继续显示：

- Android：悬浮窗支持锁定/解锁，锁定后触控会穿透，不会误触到字幕本身；
- 桌面端（Windows / macOS / Linux）：同样有悬浮字幕，支持点击穿透；
- iOS：走系统画中画（PiP）来显示。

## 四、播放相关的两个设置项

设置里与收听体验直接相关的还有两处，建议在第一次大量缓存前就定下来：

- **音频格式偏好**：同一个音频存在多种码率时，按你设的偏好选，音质与流量之间自己权衡；
- **预加载**：提前加载下一首的量，设大了流畅但费缓存，配合 [缓存下载与离线收听.md](缓存下载与离线收听.md) 里的缓存上限一起调。

字幕库检索慢、字幕错位这类问题，去 [常见问题排查.md](常见问题排查.md) 找对应条目。
