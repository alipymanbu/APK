## 一、注册账号总是失败

现象：在应用内注册，转半天提示失败。

处理：**改到网站端注册**。在浏览器里打开你所用服务的官网（如 asmr.one 的 `https://www.asmr.one/`），在网页上完成注册，然后回应用里登录。有用户反馈这条路更稳妥——应用内注册失败，不代表网站端注册出的账号登录不了。

## 二、连不上服务器 / 内容空白

按顺序查：

1. 服务器设置里**测连接延迟**——有延迟说明网络通，看地址和账号；超时看下一条。
2. 地址是否带 `https://`、有没有多余空格。
3. 你的网络环境到这些服务的连通性（部分网络需要代理）。注意你手里这版 3.8.1 的代理设置形态以应用内实际显示为准，项目后续版本更新过这部分。
4. 换一个服务器地址试试，排除单一服务抽风。

更完整的排查流程在 [服务器连接与账号注册.md](服务器连接与账号注册.md) 第四节。用的是自建后端的话，还有几项功能本来就不可用（播放列表、部分高级搜索、标签添加、点赞），边界清单在 [自建服务器搭建与连接.md](自建服务器搭建与连接.md) 第四节。

## 三、iOS 装不上：IPA 是未签名的

官方发布的 iOS 包是**未签名 IPA**，不能像安卓那样点开就装，必须先经过签名。AltStore / SideStore 路线与自签路线的完整步骤、证书有效期多长，单独写在 [iOS%20安装与签名教程.md](iOS%20安装与签名教程.md)。

## 四、公共场合怕旁人看到屏幕：「防社死模式」

KikoFlu 有个「防社死模式」，顾名思义，用于地铁、办公室这类场合——开启后避免屏幕上的作品信息被旁人一眼看到。开关在设置里，出门前打开即可。界面另支持明暗主题自适应，夜间可切深色。

## 五、字幕对不上 / 看不懂

- **时间轴错位**：导入的字幕可以调轴，在字幕编辑里微调偏移量；
- **格式不认**：确认扩展名在支持列表里（`.vtt`、`.srt`、`.lrc`、`.txt`、`.ass`、`.ssa`、`.sub`、`.idx`、`.sbv`、`.dfxp`、`.ttml`），冷门封装先转成 `.srt`；
- **日语看不懂**：开着播放时的实时翻译，或把标题/标签的自动翻译目标语言设成中文。

字幕功能全貌见 [播放与字幕功能使用.md](播放与字幕功能使用.md)。

## 六、缓存被自动清了 / 下载排队不动

- 缓存消失基本是清理策略在起作用：查设置里「缓存大小限制与清理策略」，上限设小了会自动回收旧缓存，长期要留的内容改走下载；
- 下载一直排队：并发下载有上限，前面的任务完成才会轮到，急用的先暂停其他任务。

两者的分工逻辑见 [缓存下载与离线收听.md](缓存下载与离线收听.md)。

## 七、以上都解决不了

应用内日志可以导出，遇到说不清的现象，把日志带上再去项目的 GitHub Issues（`https://github.com/pa-jesusf/KikoFlu/issues`）反馈。另外在设置里开一下「更新检查」，不少老版本的问题在新版里已经修掉——官方更新日志在发布页 `https://github.com/pa-jesusf/KikoFlu/releases`，每版改了什么都有记录，更新前后版本号的对照参考 [下载与安装教程.md](下载与安装教程.md) 第二节。
