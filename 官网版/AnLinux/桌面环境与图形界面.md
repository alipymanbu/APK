## 一、可选的桌面环境

官方支持 5 种桌面环境（截至 6.x 版本，以[官方页面](https://github.com/EXALAB/AnLinux-App)为准）：

| 桌面环境 | 特点 | 适合 |
| --- | --- | --- |
| Xfce4 | 轻量均衡 | 大多数人的默认选择 |
| Mate | 传统桌面风格 | 习惯经典布局的用户 |
| LXQt | 极轻量 | 老设备、内存小 |
| LXDE | 极轻量 | 同上 |
| KDE | 功能全、相对重 | 配置较好的设备 |

两点注意：

- 不是每个发行版都支持全部 5 种 —— 在 AnLinux 里选定发行版后，可选的桌面环境列表会跟着变
- 早期版本还支持过 Awesome、IceWM 两个窗口管理器，后因 `/dev/tty0` 报错问题已整体移除，官方说明里不再提供

## 二、安装桌面环境的步骤

前提：对应的发行版已经装好（没装的先看[安装Linux系统教程.md](安装Linux系统教程.md)）。

1. 打开 AnLinux，进入桌面环境（DESKTOP）选项
2. 选择发行版 + 桌面环境
3. 点 COPY 复制安装命令
4. 粘到 Termux 执行 —— 这一步要下载的桌面组件比基础系统大得多，耐心等它跑完，中途别杀 Termux
5. 跑完后桌面不会自动出现，还需要走 VNC（下一步）

## 三、用 VNC 打开图形界面

1. 先装一个 VNC 客户端应用（如 VNC Viewer，各应用市场都有）
2. 在 Termux 里进入系统：`./start-ubuntu.sh`
3. 启动 VNC 服务：

   ```bash
   vncserver-start
   ```

   首次使用时按终端提示设置连接密码；若脚本没有提示，可在系统里手动执行 `vncpasswd` 设置
4. 打开 VNC Viewer，新建连接，地址填 `127.0.0.1:1`，密码用上一步设置的
5. 连上后看到的就是完整桌面，可以像操作普通安卓应用一样触摸交互

用完停止桌面：

```bash
vncserver-stop
```

## 四、几个使用要点

- **VNC 只在本机通信**：地址 `127.0.0.1` 指向手机自己，不暴露到局域网，不用担心被外部连上
- **没有声音**：截至 6.x 版本，官方说明的「未来目标」里还列着音频支持，也就是桌面里播视频、听歌没声音属正常现象；社区流传在 Termux 里跑 PulseAudio 的方案，但那不是 AnLinux 自带功能，折腾前先确认版本
- **画面卡顿**：KDE 明显更重，手机配置一般就选 Xfce4 或 LXQt；卡顿时先关桌面特效
- **退出按顺序**：先在 VNC Viewer 断开连接，再执行 `vncserver-stop`，最后 `exit` 退出系统；直接杀掉 Termux 可能留下残留进程，下次启动报端口占用
- **连接被拒绝**：多半是 `vncserver-start` 没执行或没成功，回 Termux 看输出再连
- **跑着跑着 Termux 弹 `[Process completed (signal 9)]`、桌面整个断掉**：是 Android 12 起的系统杀后台机制干的，不是桌面装坏了，处理办法见[Termux环境准备与报错处理.md](Termux环境准备与报错处理.md)第三节
- **连上后黑屏**：常见原因是桌面环境没装完或没随 VNC 启动，排查思路见[常见问题与解决方法.md](常见问题与解决方法.md)
