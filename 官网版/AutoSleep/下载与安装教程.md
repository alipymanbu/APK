## 一、安装前先核对包信息

这份安卓安装包的关键信息如下，装完后可以在系统「应用信息」里对照包名，确认装的是同一个应用：

| 项目 | 信息 |
| --- | --- |
| 应用名称 | AutoSleep |
| 版本号 | 20200406（形如日期编排的版本号，2020 年 4 月的构建） |
| 安装包大小 | 19.52M |
| 包名 | `com.urbandroid.sleju` |
| MD5 | `943796A4344A8D202CE3643993FBDE6A` |
| 系统要求 | 安卓 5.2 以上（以实际安装为准） |

两点说明：

- 版本号 `20200406` 不是传统的 x.y.z 写法。网上搜到同名应用的其他版本时，别只看名字对不对，先对包名；
- 这是一款基于手机自身传感器的安卓应用，与 iOS 平台上同名的 AutoSleep 不是同一款产品，区别见[后台运行与常见问题.md](后台运行与常见问题.md)。

想确认下载下来的安装包没有损坏，可以核对 MD5：Windows 上在命令行执行 `certutil -hashfile 文件名.apk MD5`；安卓手机上部分文件管理器自带「哈希 / 校验」功能。算出的值与上表的 MD5 一致，就说明文件完整。

## 二、从网盘拿安装包

1. 复制下面的网盘链接，用浏览器或夸克 App 打开；

## 三、允许安装未知来源应用

安装包不是从应用商店下的，系统默认会拦一次。安卓 8 及以上按「来源」授权，装完可以再关掉：

1. 点开 APK 后系统提示「不允许安装未知来源应用」时，选「设置」；
2. 勾选「允许来自此来源的应用」，部分系统是直接选「仅此一次允许」；
3. 返回安装界面继续。

各厂商入口不完全一样，找不到就在系统设置里直接搜「未知」两个字：

| 厂商 | 常见路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / vivo / 一加 | 设置 → 安全（或应用管理）→ 安装未知应用 |
| 三星 / 原生系统 | 设置 → 应用 → 右上角菜单 → 特殊访问权限 → 安装未知应用 |

## 四、安装与首次启动

1. 点开下载好的 APK，选「安装」，等待完成；
2. 打开应用，按提示逐条授予权限。睡眠监测依赖**运动传感器**整夜持续采样，通常还会申请存储、通知等权限，按需允许；
3. 第一晚建议什么都不调，先用默认状态睡一次，看看记录是否完整，再按[后台运行与常见问题.md](后台运行与常见问题.md)把保活设置补齐。

## 五、装不上时的排查

| 现象 | 常见原因与处理 |
| --- | --- |
| 提示「解析包出现问题」 | 安装包下载不完整，重新下载并核对大小是否为 19.52M；或系统版本低于要求 |
| 提示「与应用冲突」、无法覆盖安装 | 手机里已装过同包名的应用，先在「应用管理」里确认是否卸载旧版 |
| 点安装没反应 / 被拦截 | 手机管家把安装拦了，在管家的「安装拦截」记录里选择允许 |
| 提示存储空间不足 | 清出足够空间再装，安装后的占用会比安装包本身更大 |
| 装上了但一打开就退出 | 先重启手机再试；仍不行按[后台运行与常见问题.md](后台运行与常见问题.md)逐项检查权限 |
