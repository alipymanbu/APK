# Amethyst 模组资源包与存档安装

> 本篇讲 Amethyst 的游戏目录结构：mod、资源包、存档分别放哪，zip 解压到什么程度才算装对，以及工具箱里「执行 JAR 文件」的用法。

## 一、先打开游戏目录

装 mod、资源包、存档，全部通过游戏目录操作，不用连电脑：

1. 在启动器主菜单里点「打开游戏目录」，会直接跳到 `.minecraft` 文件夹。
2. 想装 mod 的，先确认你启动的是带模组加载器的版本（Forge 或 Fabric），纯原版版本没有 `mods` 文件夹也不会读 mod；创建带加载器版本的方法见 [账号登录与版本安装.md](账号登录与版本安装.md)。

## 二、mod 放进 mods 文件夹

1. 打开 `.minecraft` 下的 `mods` 文件夹（没有就新建一个）。
2. 把下载好的 mod `.jar` 文件原样放进去，一个 mod 一个 jar。
3. 重启游戏，在模组列表里能看到就装上了。

目录长这样：

```
.minecraft
└── mods
    ├── mod1.jar
    └── mod2.jar
```

注意 mod 版本要与游戏版本和加载器类型对应：Forge 的 mod 与 Fabric 的 mod 不通用，1.20.4 的 mod 也不能丢进 1.20.1 的版本里。

## 三、资源包放进 resourcepacks

1. 打开 `.minecraft` 下的 `resourcepacks` 文件夹。
2. 把资源包 `.zip` **整个原样**放进去，不要解压。
3. 进游戏 设置 → 资源包，把包从"可用"移到"已选"。

## 四、存档放进 saves

1. 打开 `.minecraft` 下的 `saves` 文件夹。
2. 把世界文件夹整个复制进去（里面有 `level.dat` 的那一层才是世界文件夹）。
3. 重启游戏，单人游戏列表里就能看到。

## 五、zip 结构不对 = 白装（最容易踩的坑）

资源包和存档最常见的失败原因，是**多套了一层文件夹**：

```
资源包（zip 不解压，但第一层就要能看到 pack.mcmeta）
  错误：pack.zip → pack（文件夹）→ pack.mcmeta
  正确：pack.zip → pack.mcmeta

存档（必须是文件夹，不能整个 zip 丢进 saves）
  错误：saves → world.zip → level.dat
  错误：saves → world.zip → world（文件夹）→ level.dat
  正确：saves → world（文件夹）→ level.dat
```

装完游戏里看不到，先按上面的结构核对层级，把多出来的一层去掉。

## 六、执行 JAR 文件是干什么的

启动器工具箱里的「执行 JAR 文件」可以选中一个 `.jar` 用选定的 Java 运行时直接运行，常用于手动跑 Forge 这类安装器、或运行独立的 jar 工具。用的时候注意：

- 选对运行时（对应关系见 [账号登录与版本安装.md](账号登录与版本安装.md) 的对照表），版本不对安装器会起不来。
- 安装器界面是电脑布局，用触屏指针操作会更顺手（见 [触屏控制与操作设置.md](触屏控制与操作设置.md)）。

装完进不了游戏、或 mod 列表报红，去 [常见问题与解决办法.md](常见问题与解决办法.md) 对照排查。
