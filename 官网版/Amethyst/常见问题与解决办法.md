## 一、安装环节

| 现象 | 原因与处理 |
| --- | --- |
| 提示"解析包出现问题" | 文件没下完整或传输中损坏。核对 MD5 与大小（方法见 [下载与安装教程.md](下载与安装教程.md)），不一致就重新下载 |
| Play Protect 弹窗拦截 | 非商店 APK 的常规扫描提示，选择继续安装即可；介意的话先在 Play Protect 设置里关闭扫描应用 |
| 提示安装被系统禁止 | 在 设置 → 应用 → 特殊应用权限 里，允许你的文件管理器"安装未知应用" |

## 二、登录环节

- **微软登录一直转圈**：切换网络（Wi-Fi 与移动数据互换）再试；网页授权页打不开时，换个浏览器打开。
- **提示账号无法登录该游戏**：确认该微软账号拥有 Minecraft: Java Edition；只有 Xbox Game Pass PC 版权益的情况以微软当前的政策为准。
- **登录成功但界面空白**：杀掉启动器重开一次，首次拉取账号资料偶尔超时。

## 三、下载游戏版本失败

1. 先看存储空间是否还够（建议留 1~2 GB，见 [下载与安装教程.md](下载与安装教程.md)）。
2. 换网络重试；公共 Wi-Fi 限速时用移动数据往往反而快。
3. 反复失败就换个版本号先装，排除是该版本源文件暂时抽风。

## 四、闪退与黑屏

按出现概率从高到低排：

1. **Java 运行时不匹配**：1.17 以上用 17 或 21，1.16.5 及以下用 8，对照表见 [账号登录与版本安装.md](账号登录与版本安装.md)。
2. **内存分配不当**：给少了进世界就退，给多了会被系统直接杀掉 —— 两者表现一样。按设备内存对照表改（见 [内存分配与卡顿优化.md](内存分配与卡顿优化.md)），并清掉后台大应用再试。
3. **渲染后端不兼容**：在设置里切换渲染后端再启动，不同机型的表现差异很大。
4. **刚发布的快照版**：最新快照兼容性没稳定，先退回最近的正式版。

黑屏卡在 logo：多数与渲染相关，先切渲染后端；仍不行把游戏版本换掉验证是不是版本本身的问题。

## 五、没有声音

音频在官方文档里标注为"多数设备可用" —— 部分机型就是无声或断续。可以试：媒体音量调到最大、重启启动器；仍无声就先接受（不影响存档），等新构建修复，或到官方渠道反馈机型信息。

## 六、卡顿掉帧

系统性的调法（内存分配档位、渲染距离、性能模组）已单独成篇，见 [内存分配与卡顿优化.md](内存分配与卡顿优化.md)。这里只补两条快速判断：

- **进世界就卡、越玩越卡**：多半是内存给少了或材质包太重，先查分配档位。
- **一直平稳但帧数低**：是渲染压力问题，降渲染距离、用画面缩放（见 [触屏控制与操作设置.md](触屏控制与操作设置.md)），比调内存有效。

## 七、拿日志与反馈

- **看日志**：主菜单工具箱里有「分享日志文件」，游戏崩溃后先导出日志，报错信息都在里面；排错时把日志发给别人比口头描述有用得多。
- **官方渠道**：源码与 issue 区在 [github.com/AngelAuraMC/Amethyst-Android](https://github.com/AngelAuraMC/Amethyst-Android)，官方文档站是 [wiki.angelauramc.dev](https://wiki.angelauramc.dev/)，反馈与求助也可走官方 Discord。

提 bug 时带上：启动器版本（本篇对应 20250803 这版构建）、安卓版本、机型、游戏版本、完整日志。
