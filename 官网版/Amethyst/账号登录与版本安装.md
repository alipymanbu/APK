# Amethyst 账号登录与游戏版本安装

> 本篇讲装好启动器之后的两步：登录微软账号，以及选择并下载要玩的 Minecraft 版本（含模组加载器与 Java 运行时怎么选）。

## 一、第一次打开启动器

安装完成首次打开，启动器会直接进到账号登录页。这一步要联网，之后每次打开都会自动带上次的账号，不需要重复登录。

还没装上的话，先看 [下载与安装教程.md](下载与安装教程.md)。

## 二、登录微软账号

Amethyst 玩的是 Minecraft: Java Edition，登录用的微软账号需要已购买 Java 版（或持有 Xbox Game Pass 对应权益）。登录流程：

1. 在登录页选微软账号（Microsoft）登录方式。
2. 会拉起网页登录，输入微软账号密码完成授权，再跳回启动器。
3. 登录成功后账号会记在启动器里，界面上能看到你的角色皮肤头像。

登录转圈很久或报错时，多数是网络问题：切换网络（Wi-Fi 与移动数据互换）再试一次，或换个时间段重试；仍然不行去 [常见问题与解决办法.md](常见问题与解决办法.md)。

另外说明一个你可能会在登录页看到的入口：部分构建提供「本地账号」（Local）选项，输入任意用户名即可进入界面。它只对得起"离线"两个字 —— 进不了需要正版验证的在线服务器，联机功能基本用不上；入口与叫法随构建不同，以你实际看到的界面为准。

## 三、选 Java 运行时（多数人不用管）

Amethyst 内置多套 OpenJDK 运行时（8 / 17 / 21），不同 Minecraft 版本要求不同：

| 你要玩的版本 | 对应运行时 |
| --- | --- |
| 1.7.10 及更早 | OpenJDK 8 |
| 1.8 ~ 1.16.5 | OpenJDK 8 |
| 1.17 ~ 1.20.4 | OpenJDK 17 |
| 1.20.5 及更新 | OpenJDK 21 |

选版本下载时运行时一般会自动配好。只有启动报"Java 版本不匹配"一类错误时，才需要到设置里手动把该版本对应的运行时改对。

## 四、下载游戏版本

登录完成后进版本选择，Amethyst 支持的范围很宽 —— 从 rd-132211 这类远古版本到较新的正式版与快照都有（官方 README 的说法是"几乎所有可用版本"）。操作路径：

1. 在版本列表里选一个原版（vanilla）版本，或先选模组加载器再选它支持的游戏版本。
2. 确认后启动器开始联网下载游戏本体与资源文件，几十 MB 到几百 MB 不等，耗时取决于网络。
3. 下载完回到主界面，点启动就能进游戏。

模组加载器方面，官方 README 明确支持 Forge 与 Fabric 两条路线；第三方资料还提到 NeoForge 与 Quilt，以你手上这个构建的版本列表里实际出现的选项为准。装了加载器的版本怎么放 mod 文件，见 [模组资源包与存档安装.md](模组资源包与存档安装.md)。

版本下载反复失败时：先确认存储空间够（见 [下载与安装教程.md](下载与安装教程.md) 的准备一节），再换网络重试。

## 五、多版本共存

每个游戏版本是独立的条目，可以同时保留原版 + Forge + Fabric 等多个组合，启动时选哪个就进哪个。旧版本不想要了，在版本管理里删掉对应条目即可，不影响其他版本。

装好能进游戏之后，下一步是把手机上的操作调顺手：虚拟按键、控制布局的改法都在 [触屏控制与操作设置.md](触屏控制与操作设置.md)。
