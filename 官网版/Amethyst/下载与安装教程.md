## 一、装之前先弄清楚三件事

Amethyst 是一个开源的第三方启动器（LGPLv3 协议），作用是让你在安卓手机或平板上运行 Minecraft: Java Edition。它本身免费，但它不是游戏本体 —— Minecraft: Java Edition 是买断制付费游戏，进游戏前需要登录一个已购买 Java 版的微软账号。

动手机之前建议先核对：

1. **设备**：安卓手机或平板，主流 ARM 机型即可；屏幕越大、内存越充裕，体验越接近电脑。
2. **存储空间**：安装包本身约 176.71M 只是起步 —— 之后下载游戏文件随版本不同还要 300 MB 到 1.5 GB，装模组、资源包、存档另计。社区经验是总共留出 4~6 GB 可用空间比较从容，具体以你玩的内容为准。
3. **账号**：提前确认你的微软账号能正常登录，并且该账号拥有 Minecraft: Java Edition。

## 二、安装包从哪来

Amethyst 没有上架 Google Play，官方的分发方式是 GitHub 仓库 [github.com/AngelAuraMC/Amethyst-Android](https://github.com/AngelAuraMC/Amethyst-Android) 的 Actions 持续集成构建，官方安装文档也写明多数人直接选 `app-debug` 产物即可。这条路需要 GitHub 账号，还要在构建列表里找版本，比较绕。

不折腾 GitHub 的话，可以直接用这份 **Amethyst 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/7ebf52d3310a](https://pan.quark.cn/s/7ebf52d3310a)，转存后取出的就是本篇版本信息对应的那个安装包。

| 项目 | 值 |

| 大小 | 176.71M |
| MD5 | FBC8DC6BA9201963EC3D6EBFF53CF723 |

两个容易让人疑惑的点：

- **版本号 20250803 是个日期**（2025 年 8 月 3 日的构建），不是 1.x.x 那种语义化版本。这类走持续集成的启动器常用构建日期当版本号，数字越大越新。
- **包名带 `.debug` 后缀不代表修改版或二次打包**：这是官方 CI 用 debug 方式打包的产物，官方安装文档推荐普通用户选的就是 `app-debug` 这个构建类型，装出来的应用与普通应用没有使用上的区别。

## 四、安装步骤

1. 把安装包下载或转存到手机存储里。
2. 点开 APK，系统首次会提示"不允许安装未知来源应用"，按提示允许你的文件管理器（或浏览器）安装应用；不同品牌入口不同，一般在 设置 → 应用 → 特殊应用权限 附近。
3. 回到安装界面点"安装"，等进度走完。
4. 若弹出 Google Play 保护（Play Protect）的扫描提示，选择继续安装 —— 这是所有非商店渠道 APK 都会遇到的常规提示。
5. 装完点打开，进入启动器。

先别急着进游戏：登录账号、下载游戏版本的步骤在 [账号登录与版本安装.md](账号登录与版本安装.md)。

## 五、装不上或想核对文件

- **提示"解析包出现问题"**：多数是文件没下完整或传输中被损坏。在电脑上核对一下 MD5（Windows 用 `certutil -hashfile 文件名.apk MD5`），结果与上表不一致就重新下载一遍。
- **提示与已装应用冲突**：只有包名完全相同的应用才会要求先卸载。手机里装过其他 PojavLauncher 系启动器不会和它冲突，包名不同。
- **想换新版本**：直接用新 APK 覆盖安装即可，不需要先卸载旧版。

装完之后遇到闪退、黑屏之类的问题，去 [常见问题与解决办法.md](常见问题与解决办法.md) 对照排查。
