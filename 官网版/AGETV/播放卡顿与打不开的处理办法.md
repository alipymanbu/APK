# AGETV 播放卡顿与打不开的处理办法

> 番剧加载不出来、播放卡住、整个应用打不开时，按这篇从里到外排查：先换线路，再查网络，再动应用，最后确认是不是官方地址变了。

## 一、先换线路（解决大多数卡顿）

播放卡住或一直转圈时，第一步不是重启应用，而是在播放页面里**换一条线路**。同一集通常有多条片源线路，一条卡、一条通是常态，换线路是成本最低的解法。

推荐的排查顺序：

1. 换线路；
2. 换清晰度（当前画质过高而带宽跟不上时降一档）；
3. 退出播放页重进；
4. 还不行才往下走网络排查。

## 二、网络层面

- **切网络试试**：Wi-Fi 卡就切移动数据（或反过来），能立刻判断问题出在哪一侧；
- **受限网络**：校园网、公司网这类环境可能限制视频流量，换个网络环境对比一下；
- **高峰期**：晚 8~10 点卡顿更常见，错峰观看或多换几条线路；
- **测个速**：其他视频应用同样卡 → 是你的网络问题，不是 AGETV 的问题。

## 三、应用层面

网络正常、每条线路都卡或首页都刷不出来时，再动应用：

1. **清缓存**：手机「设置 → 应用管理 → AGETV → 清除缓存」（只清缓存，不动数据）；
2. **更新版本**：网盘里这份是 1.0.2 版，官网后续可能已发布修复了服务地址的新版 —— 先到官方发布页确认，见 [官网地址与版本说明.md](官网地址与版本说明.md)；
3. **重装**：以上都不行，卸载后按 [下载与安装教程.md](下载与安装教程.md) 重装一遍。

## 四、闪退、无响应、打开就退出

按这个顺序做，每做一步试一次：

1. **强停重开**：设置 → 应用管理 → AGETV → 强行停止，然后再打开；
2. **重启手机**：清掉卡住的进程与占满的内存；
3. **清缓存**：仍是「只清缓存不动数据」，缓存坏了会直接导致启动异常；
4. **清数据**：设置 → 应用管理 → AGETV → 存储 → 清除数据。**注意**：这一步会把应用里的记录（观看记录、收藏这类）一并清掉，相当于回到刚装好的状态，放最后再做；
5. **卸载重装**：彻底重置，装法见 [下载与安装教程.md](下载与安装教程.md)。

手机剩余存储低于 20% 时闪退也会变频繁，先清出空间再试。做完 1~5 还闪退，多半等下一个版本修复，别反复重装。

## 五、整个应用打不开 / 首页一直空白

这不是你手机的问题 —— 这类应用的服务端地址会不定期更换，地址一换，旧版应用里配置的入口就失效了，表现就是首页空白、搜索无结果或一直加载。

处理办法：

1. 到官方发布页看当前可用的入口地址（GitHub 发布页与 rentry 页，见 [官网地址与版本说明.md](官网地址与版本说明.md)）；
2. 确认手机其他应用能正常上网；
3. 发布页地址也没换、什么都试过了 → 可能是服务端在维护，隔几小时再试，维护期间没有本地能做的操作。

网页版站还能打开时，也可以先在浏览器里应急观看，等应用端恢复。
