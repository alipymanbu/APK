## 一、入口与上限

提示词框就在生成按钮上方，右下角有字数统计（0/2000，单条上限 2000 字）和「清除」按钮。框下方是「快速开始示例」的一排方向标签，右上角还有「随机」按钮——不知道写什么，就先从示例里挑一个方向、把主体换成自己的，比从零写快得多。

2000 字的上限远超一条提示词的实际需要，把该说的说清即可，堆字数不加分。

## 二、文生图：按五段结构写

一条够用的文生图提示词，把五件事说清就成：

```text
主体（谁/什么） + 动作或状态 + 场景背景 + 风格与光线 + 构图与用途
```

示例：

```text
一只橘猫趴在洒满阳光的木窗台上，窗外有绿植，午后暖光，浅景深，写实摄影风格，竖构图，适合手机壁纸
```

「一只猫」和「一只橘猫趴在窗台上」出的是两种图。写得越具体，越接近你想要的。Google 官方给这条模型的使用建议也是同一方向：用自然口语描述，别堆复杂语法和所谓咒语技巧——五段结构每段一句话就够了。

## 三、图生图：说清改哪、改成什么、保留什么

图生图的指令和文生图完全是两套逻辑——你得先告诉它**别动什么**：

```text
把背景换成海边日落，保留人物的姿势、服装和表情不变
```

三个要素按顺序过一遍：

1. **改哪里**：背景、服装、头发、画面左侧的水杯……点名具体区域；
2. **改成什么**：新背景是什么、风格转成什么；
3. **保留什么**：人脸、姿势、构图、图里的文字——想保留的都写出来，没写的它可能顺手也改了。

结果里脸变了、字没了，多数是指令里漏了第三条。

## 四、内置示例方向对照

应用内「快速开始示例」内置了这些方向，各自适合的场景：

| 示例方向 | 适合做什么 |
| --- | --- |
| 文艺复兴风格 | 人像、油画质感头像 |
| 奇幻场景 | 游戏插画、小说封面 |
| 家庭场景 | 生活化配图、温馨风插画 |
| 赛博朋克城市 | 科幻海报、霓虹街景 |
| 波普艺术 | 海报风、潮流配图 |
| 黑白肖像 | 质感人像、杂志风 |
| 水彩画 | 插画、清新风配图 |
| 海滩背景 | 旅行感配图、换背景练习 |

示例只是起点：选中后把示例里的主体换成你自己的内容，效果最稳。

## 五、效果不对时先查这四点

- **一次改太多**：文生图塞了五六个主体，图生图要同时换背景、换衣服、换发型——拆成几次生成，一次改一处；
- **没写保留项**：图生图改完脸变了、logo 没了，回指令里补「保留×××不变」；
- **描述太抽象**：「好看一点」「高级一点」模型接不住，换成可执行的具体说法（如「背景换成纯白，人物提亮」）；
- **比例选反了**：构图怪异先回去检查宽高比，竖版内容别用横版比例生成。

改完后还是报错、出空结果的，多半不是提示词的问题，翻[积分登录与生成失败排查.md](积分登录与生成失败排查.md)对一遍。
