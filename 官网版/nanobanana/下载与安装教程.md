## 一、先核对安装包信息

拿到安装包后，先确认与下表一致，避免装成别的版本：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.1.3 |
| 包名 | com.davinci.ai.flux |
| 大小 | 28.40M |
| MD5 | AA120E85AB80E22A0E21C23BFE7B5086 |

以上为 2026-09-27 核对的信息，网盘里的文件名是 `nanobanana_v1.1.3.apk`；后续若有新版本，以安装包实际属性为准。

## 二、下载安装包

1. 打开上面的 [nanobanana 安装文件资源（夸克网盘）](https://pan.quark.cn/s/18c69a0ce8cb)；
2. 选中 APK 文件转存到自己的网盘（手机装了夸克 App 的，转存后直接下载即可）；
3. 把 APK 下载到手机本地存储。

用电脑操作也一样：先转存，PC 端下载后通过数据线或聊天工具传给手机再装。

## 三、安装步骤

1. 点开下载好的 APK，系统会提示「禁止安装来自此来源的应用」，这是安卓对应用商店之外安装的默认限制；
2. 按提示进入设置，给你的浏览器或文件管理器开「安装未知应用」权限（常见路径：设置 → 应用 → 特殊应用权限 → 安装未知应用，不同品牌 ROM 的叫法略有差异）；
3. 返回重新点 APK，等安装完成。

装完后建议把刚才的「安装未知应用」权限收回去，平时用不到，留着是个风险口子。

## 四、（可选）校验 MD5

想确认文件没下坏，把算出来的 MD5 与第一节表格里的值比对。Windows 电脑上用 PowerShell：

```powershell
Get-FileHash "下载路径\nanobanana_v1.1.3.apk" -Algorithm MD5
```

Linux 与 macOS：

```bash
md5sum nanobanana_v1.1.3.apk     # Linux
md5 nanobanana_v1.1.3.apk        # macOS
```

对不上就重新下载一次，别强行安装。

## 五、首次启动

- 界面是中文的，首页就有「文生图」「图生图」两个模式按钮；
- 点「生成」前需要登录，新用户注册有免费积分可领（界面横幅写的是「注册即可领取免费积分」）；
- 生成一张图需要 1~3 分钟，期间别关页面，具体原因见[积分登录与生成失败排查.md](积分登录与生成失败排查.md)。
