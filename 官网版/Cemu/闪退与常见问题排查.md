## 动手前先对一遍这三样

多数「跑不起来」最后都出在这三处，先花两分钟确认，能省掉大半排查：

1. **存储权限给没给**：系统设置 → 应用 → Cemu → 权限，存储/文件权限必须是允许。
2. **游戏文件从哪来的**：来源不明的压缩包解压一半失败、文件损坏，是导入失败的常见原因，换份干净的文件再试。
3. **机型档次**：Wii U 模拟对性能有硬要求，低端机跑大型游戏卡顿、发热、闪退都可能只是性能不够，别急着怪设置。你的机器属于哪一档，见[手机配置要求与实测表现.md](手机配置要求与实测表现.md)。

## 报 Encrypted Title

现象：点游戏就弹 Encrypted Title（加密标题）之类的报错，进不去。

原因和处理：你导入的是 WUD/WUX 这类加密镜像，模拟器解密需要密钥文件（keys.txt），而官方版和移植版都不附带密钥。两条路：从你自己的 Wii U 主机导出密钥文件配置好；或者直接换 WUA 格式的游戏文件，彻底绕开密钥这一步。格式区别和导入细节见[游戏文件格式与导入.md](游戏文件格式与导入.md)。

## 提示 You must perform a system update

现象：进《塞尔达传说：旷野之息》这类游戏时弹「You must perform a system update to play...」并退回主菜单。

这是社区教程里专门讲过的常见报错。修法与移植版版本相关，旧帖的固定步骤未必适用：把报错原文照抄去搜，找与你手上版本对应的处理办法。这不是性能问题，调画面设置没用。

## 游戏列表是空的

按顺序查：

1. **路径指对没有**：游戏路径要指到「一个游戏一个子文件夹」的那一层，指深了或指浅了都扫不到。回设置 → Game paths 看一眼当前指向。
2. **压缩包解压了没有**：`.zip` / `.7z` 没解压直接导入是扫不出来的，先解压完整再导。
3. **格式认不认**：WUA、RPX、WUD、WUX 之外的形式（比如只拷了部分文件夹的零散文件）扫不出来，对照格式表核对。
4. **权限**：存储权限被系统收回后列表也会清空，重新授权再刷新。

## 进游戏黑屏或闪退

1. **先排除文件问题**：换另一个游戏试——只有一个游戏崩，是该游戏文件或对应图形包的问题；个个都崩，才是设置或性能问题。
2. **关图形包**：进得了设置就把图形包全部关掉再试，个别图形包与游戏版本不兼容会直接崩。
3. **图形 API 换一下**：Vulkan 不稳的机型换 OpenGL 试（反之亦然），改完重进游戏。
4. **清后台重进**：长时间挂后台内存被占满，闪退概率明显升高，清掉后台重开。
5. **还崩就重装**：卸载重装（记得先确认安装包 MD5 与你下载时的一致），重装后存储权限要重新给。

## 卡顿掉帧

间歇卡顿多数与设置有关，按[画面与性能设置.md](画面与性能设置.md)里的排查顺序来：先关图形包、再降分辨率、确认 Vulkan 和异步着色器两项都开、最后看是不是长时间运行发热降频。第一次玩某游戏时的短暂顿卡是着色器在编译，开了异步着色器编译后大多无感，不是故障。

## 还是不行

按[下载与安装教程.md](下载与安装教程.md)核对安装包信息（版本、MD5），确认你手上这份安装包本身没问题；操作和手柄相关的设置问题在[虚拟按键与手柄设置.md](虚拟按键与手柄设置.md)。
