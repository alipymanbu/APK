## 一、先认清这是哪个应用

iBetter 的全名是「iBetter · 习惯养成打卡 - 人生养成计划」，开发者是每日科技（上海）股份有限公司（iDaily / Clover 团队），同一套账号体系还有 iPhone / iPad 版。它做的事很单一：建几条想坚持的习惯，每天早晚提醒你，完成后打卡记录，坚持到一定天数发勋章。

本文针对的是安卓手机（APK 安装包）的安装。如果你用的是 iPhone / iPad，直接在 App Store 搜「iBetter」安装即可，不需要走本文流程。

## 二、安装包与版本信息

网盘里这份安装包的关键信息如下，安装前后都可以用来核对：

| 项目 | 值 |
| --- | --- |
| 版本 | 8.0.0 |
| 包名 | `com.clover.ibetter` |
| 安装包大小 | 29.70M |
| MD5 | `7574252E4726D746F8FDC4488E118AB0` |

几点说明：

- 官方商店（小米商店、应用宝等）上架的最新版本已是 8.1.0（2025 年更新），与网盘里这份 8.0.0 不是同一个版本。核心功能（建项目、打卡、提醒、勋章）在两个版本里都有，具体功能差异以你安装后应用内实际显示为准，两个版本各差了什么见 [版本更新与新旧版差异.md](版本更新与新旧版差异.md)。
- 官方最新版本号以后以官方商店页面为准：`https://ibetter.clover.ly/` 是官方入口页，里面同时提供 Google Play 与 App Store 链接。
- 核对 MD5 可以在电脑上用 `certutil -hashfile 文件名.apk MD5`（Windows）确认下载没损坏。

## 三、系统要求

- 安卓版：本地这份安装包的要求是 Android 5.2 及以上；不同上架渠道标注略有出入，以你手机能正常安装为准。
- iOS 版：在 App Store 页面查看当期系统要求。

## 四、安装步骤（安卓）

1. 从 iBetter 安装文件资源（夸克网盘）下载 APK 文件到手机存储：[https://pan.quark.cn/s/4f28768c75e8](https://pan.quark.cn/s/4f28768c75e8)（夸克网盘的分享文件需先转存到自己的网盘再下载）。
2. 在手机文件管理器里点开这个 APK。第一次安装时系统会提示「不允许安装未知来源应用」，按提示允许你的文件管理器（或浏览器）安装应用，再回到安装页继续。
3. 安装完成后点「打开」。首次启动可能弹出权限申请，逐项看清楚再允许（见下一节）。
4. 进入应用后先建一两条自己的习惯项目，再决定要不要开提醒，可以按 [打卡项目创建与管理.md](打卡项目创建与管理.md) 的顺序操作。

## 五、安装时会用到哪些权限

以下是这款应用在应用商店公示的安卓权限清单，逐条解释它要来做什么：

| 权限 | 用途 |
| --- | --- |
| 网络 / 查看 WLAN 状态 | 联网同步数据 |
| 精确闹钟（SCHEDULE_EXACT_ALARM） | 保证提醒在设定时间准点弹出 |
| 发布通知（POST_NOTIFICATIONS） | 展示每日提醒与打卡通知 |
| 前台服务 | 让提醒调度在后台持续有效 |
| 读写文件与文档 | 存取打卡记录与分享图片 |
| 指纹 / 生物识别 | 应用锁等本地验证场景 |
| 检索运行中的应用、防止休眠 | 维持提醒调度的常见辅助权限 |

其中「发布通知」和「精确闹钟」两项与提醒功能直接相关：新版安卓（Android 13 及以上）在首次启动时会单独弹窗询问通知权限，拒绝掉的话提醒就收不到。装完最好按 [提醒与通知排查.md](提醒与通知排查.md) 把这两处检查一遍。「指纹 / 生物识别」这项对应的是付费版的应用锁（密码保护）功能，详见 [会员订阅与内购项目.md](会员订阅与内购项目.md)；不用应用锁的话这条权限实际不会用到。

- 想立刻开始记录习惯，继续看 [打卡项目创建与管理.md](打卡项目创建与管理.md)；对免费范围、能否在电脑上用这类问题有疑问，看 [常见问题排查.md](常见问题排查.md)。
