## 一、版本演进速览（安卓）

下表按更新说明整理，列的是「对日常使用有实际影响的」变化，纯稳定性修复不列：

| 版本 | 引入 / 变化的功能 |
| --- | --- |
| 8.1.0（2025 年，商店最新） | 新增 100+ 学科类项目图标；交互与稳定性优化 |
| 8.0.0（2024 年，网盘这份） | 打卡可开启「自我评分」，给每次打卡打分量化；完成当日全部项目（三个以上）解锁每日特殊成就 |
| 7.0.x（2023 年） | 周 / 月回顾（记录并分享努力）；目标天数支持填任意数值（此前只能选预设档位）；日历颜色可选（绿 / 粉 / 蓝 / 橙） |
| 5.3.x（2022 年） | 「我的记录」年度打卡可视化；周记录量化每周成果 |
| 5.2.x（2021 年） | 同一条项目一天可打卡多次（上限 24 次）；超紧凑列表模式，首屏放下更多项目 |

说明：以上取自应用商店与第三方应用库收录的官方更新说明，早期版本的具体措辞以当时的更新页为准；日历颜色这类小设置在部分渠道版本里可能出入。

## 二、8.0.0 和 8.1.0 差在哪

官方对 8.1.0 的更新说明集中在「新增学科类图标」与体验优化，核心玩法（建项目、打卡、提醒、勋章、自我评分）两个版本完全一致。结论：

- 手里已经有 8.0.0 且用着正常 → 不必特意追新，图标数量不影响功能。
- 在意图标选择余地或界面细节 → 走应用商店更新到 8.1.0，最新版本号以官方商店页面为准。
- 想要 8.0.0 这份安装包，走 [iBetter 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4f28768c75e8)，核对信息见 [下载与安装教程.md](下载与安装教程.md) 第二节。

## 三、确认自己装的是哪一版

1. 打开应用，进设置或「关于」页面看版本号。
2. 版本号对不上表里的功能预期时（比如想着 8.0.0 却找不到自我评分入口），先确认项目编辑页有没有相关开关，再对照 [打卡项目创建与管理.md](打卡项目创建与管理.md) 第三节。
3. 商店渠道升级是覆盖安装，打卡数据不受影响；跨大版本升级前想留底，看 [常见问题排查.md](常见问题排查.md) 第五节。

## 四、iOS 版版本号不一样

iOS 端在 App Store 独立发布，版本号已经走到 9.x（含深色主题、任务网格视图、月度总结等更新），与安卓的 8.x 不是同一套节奏。两边版本号不同属正常，不要拿 iOS 的更新日志套安卓版的功能。内购与会员两端的口径见 [会员订阅与内购项目.md](会员订阅与内购项目.md)。
