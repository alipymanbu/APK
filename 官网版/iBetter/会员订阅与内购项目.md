## 一、免费与付费的边界

应用本体免费下载，建项目、打卡、提醒、勋章收集这些核心玩法不付费就能一直用。付费部分集中在「Pro 会员」与打赏两项，属于增强性质——换句话说，先用免费版建起习惯清单完全走得通，觉得某些增强功能正好戳中需求再考虑付费。

## 二、官方公示的内购项目（iOS 端）

App Store 页面公示的内购项如下（截至检索时，价格与项目以 App Store 当时显示为准）：

| 内购项 | 公示价格 | 说明 |
| --- | --- | --- |
| iBetter Pro · 月度会员 | 每月 ¥3 | 自动续订订阅 |
| iBetter Pro（买断） | ¥30 | 一次性买断，公示说明含「密码保护等 Pro 功能」 |
| Coffee for Developer | ¥15 | 打赏 |
| Coffee for Designer | ¥38 | 打赏 |
| No Coffee for PM | ¥98 | 打赏 |
| Coffee for Everyone | ¥198 | 打赏 |

从这份清单能读出两件事：

- **Pro 功能的一个实锤是「密码保护」**（应用锁）。这与应用申请的生物识别权限（指纹 / Face ID 类）对得上——不想被人随手翻打卡记录的话，这是付费点之一。其他 Pro 权益以应用内会员页的说明为准。
- **打赏类内购不对应任何功能**，买不买不影响使用。

## 三、订阅规则与取消（iOS 端）

官方对月度订阅的条款要点：

- 确认购买后从 Apple ID 账户扣费；
- 每个周期结束前 **24 小时内**自动续订，续订前想停，要在周期结束**至少 24 小时前**取消；
- **已订阅的周期无法取消**——决定订阅前把这条算进去，最短也要花一个月的钱。

取消入口不在应用里，在系统层面：App Store 账户的「订阅」管理页里找到 iBetter 取消即可。

## 四、安卓端怎么办

安卓端没有公开的内购清单，是否提供会员入口、价格几何，以你应用内「会员 / 设置」页面的实际显示为准。两点通用的判断：

- 打卡数据本身不锁在会员后面（免费版即可同步与打卡），不会因为不付费而丢记录；
- 在第三方渠道（网页推荐页、群文件）看到「会员免费拿」之类的说法，一律不要信，那类渠道提供的安装包来路不明，换回官方渠道安装（见 [下载与安装教程.md](下载与安装教程.md)）。

## 五、值得花钱吗

这题不替你答，只给判断素材：

- 每月 ¥3、买断 ¥30 的绝对金额都低，但要先问自己「密码保护这个功能我真的需要吗」——打卡应用的核心价值在于你每天打开它，付费点不在打卡本身；
- 打赏纯属心意，与功能无关；
- 拿不准就先用免费版跑满两周（对应官方「7 天养成一个习惯」翻倍的时间），确认自己会长期用再考虑。
