## 一、这份安装包对应的是哪个版本

Skyscanner（中文站叫「天巡网」）是一个把机票、酒店、租车的比价结果归到一处的旅行搜索应用。它本身不卖票、不收款，你选中一趟之后会被送到航空公司或旅行社的网站上完成下单。下面这张表是本文配套安装包的信息，装之前先对一眼。

| 项目 | 内容 |
| --- | --- |
| 应用名 | Skyscanner |
| 运行平台 | Android（手机、平板） |
| 版本号 | 7.191 |
| 包名 | `net.skyscanner.android.main` |
| 安装包大小 | 39.25 MB |
| MD5 | `593e278f20911e735144b8c13be03953` |

两点说明：

- **版本号对不上是正常的。** 官方应用商店上架的往往已经是更新的版本，本文这套资料配的是 7.191；文档里出现的版本号和体积一律以这张表为准。想确认手里的文件没下坏，用任意 MD5 校验工具算一遍，与上表一致即可。
- **包名用来认人。** 同类应用不少，装完可以在手机「设置 → 应用 → Skyscanner」里看一下包名是不是 `net.skyscanner.android.main`，是就对了。

## 二、装之前先确认三件事

### 系统版本

对 Android 版本的要求会随应用更新往上调，没有一个长期不变的底线。能不能装，以你手机弹出的提示为准；如果装完打不开或者一开就闪退，多半是系统版本过旧，换台新一些的设备再试。

### 存储空间

安装包本身约 39.25 MB。解压安装、再加上搜索缓存，建议预留 **150 MB 以上** 的可用空间，只留跟安装包差不多的空间，装完就可能提示不足。

### 网络

比价结果全部来自联网查询，**第一次打开就要联网**，否则会停在加载页。搜索、比价、设置价格提醒都需要在线；已经登录过之后，最近搜索过的行程会留在应用里。

## 三、从网盘获取安装包

1. 打开 [Skyscanner 安装文件资源（夸克网盘）](https://pan.quark.cn/s/11339f8b7e98)。
2. 先**转存**到自己网盘，再从自己的网盘里下载——直接下别人的分享，文件失效时就得重新找。
3. 把 APK 下载到手机本地，记住存在哪个目录（一般是「下载」）。

## 四、安装步骤

1. 打开手机自带的**文件管理**，进入「下载」目录，找到刚下好的 APK 文件。
2. 点击它。大多数 Android 会先拦一下，提示「禁止安装未知应用」。
3. 按提示进入设置，为**这个文件管理器**（或浏览器）打开「允许安装未知应用」开关。
4. 回到安装界面，点**继续 / 安装**。
5. 装完点**打开**，或回桌面找 Skyscanner 图标。

## 五、第一次打开要做的三件事

1. **语言跟着手机走。** 手机版 Skyscanner 没有独立的语言开关，界面语言由手机系统语言决定。想让界面显示中文，得去手机「设置 → 系统 → 语言」里把系统语言改成中文，而不是在应用里翻设置。搜索结果显示成外币是另一回事，币种和地区在「个人资料 → 设置」里改，见 [价格显示外币怎么改.md](价格显示外币怎么改.md)。
2. **先搜一趟试试。** 打开后默认停在机票搜索页，填出发地、目的地、日期，点搜索，能看到结果列表就说明网络和版本都没问题。怎么搜、怎么筛见 [机票搜索与筛选怎么用.md](机票搜索与筛选怎么用.md)。
3. **允许通知（建议开）。** 应用会请求通知权限，用途是价格提醒的推送。不想要可以拒绝，之后在手机设置里也能补开；不开只是收不到推送，邮件提醒不受影响。

登录不是必须的：不登录也能搜索和比价，只有要保存行程、设置价格提醒时才需要一个账号。

## 六、装不上或装完打不开

如果安装被拦、装完闪退，或者打开后一直转圈加载不出内容，先按 [搜索不到航班或价格对不上怎么办.md](搜索不到航班或价格对不上怎么办.md) 里「应用打不开、白屏或一直转圈」一节排查；多数情况重启应用或重装即可解决。
