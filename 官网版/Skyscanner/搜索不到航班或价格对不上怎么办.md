# Skyscanner 搜索不到航班或价格对不上怎么办

> 搜不到想要的航班、点进去价格变了、应用打不开、界面不是中文——本篇把这些最常见的几类问题按原因拆开，一条条给出排查顺序。

## 一、搜不到某个航班、航司或航线

先确认不是自己的筛选条件把结果砍掉了：

| 可能原因 | 怎么办 |
| --- | --- |
| 航线或航司被筛掉 | 清掉航空公司、机场、中转次数、出发到达时段这几项筛选，重新搜一遍 |
| 出发 / 到达机场填得不对 | 同城有多个机场时，确认填的是哪个；或勾上「附近机场」扩大范围 |
| 日期或目的地定得太死 | 换成整月视图，或把目的地改成「任意地点」再试 |
| 转机时间太紧的航班看不到 | 结果一般不列转机少于 1 小时的航班；要么勾「附近机场」，要么接受更长中转 |

把筛选全部清掉还是搜不到，说明这条航司或这条航线确实没进这批搜索结果，这时换航司官网或别处再查更直接。

## 二、点进去价格变了，或者结算页比列表价贵

- 机票、酒店、租车的价格都是**动态**的，随余票、余房和时段需求变化，列表上的报价只是当时那一瞬间的。
- 结算页可能会加上你自己选的附加项（托运行李、选座、房型升级、租车保险），或者按支付方式收手续费。
- 判断口径只有一个：**以出票方结算页显示的金额为准**。列表价与结算价不同属正常，不是被坑。

## 三、日历、图表页的价格和搜索结果页对不上

日历、图表那一类页面给的是根据近期搜索记录估算出来的**参考价**，作用只是帮你挑日子；点进具体日期的搜索结果页，才是当时可用的报价。两处数字不一样不是故障。

还有一种「对不上」是币种搞的鬼：结果里显示的是美元、欧元，你按人民币在心里换算自然觉得不对。币种与地区设置怎么改见 [价格显示外币怎么改.md](价格显示外币怎么改.md)。

## 四、应用打不开、白屏或一直转圈

按下面的顺序试，一般到第二三步就能恢复：

1. 完全关掉应用，重新打开；
2. 确认手机能正常上网，换 Wi-Fi 或流量再试一次；
3. 确认用的是较新的版本，版本太旧就重装——安装包见 [Skyscanner 安装文件资源（夸克网盘）](https://pan.quark.cn/s/11339f8b7e98)；
4. 进手机设置里清一次应用缓存；
5. 卸载后重装。

## 五、提示被阻止访问，或页面要求做验证

遇到「被阻止使用服务」这类提示，多半是当前网络环境触发了风控。可以换一个网络环境再试；如果还是不行，就带上你的 IP 和报错截图联系 Skyscanner 官方客服处理。

## 六、界面不是中文

手机版 Skyscanner 的界面语言跟随系统语言，应用里没有单独的语言开关。要把界面改成中文：

- **手机应用**：去手机「设置 → 系统 → 语言与输入 → 语言」，把系统语言设为中文，再打开应用；
- **网页版**：在页面顶部的地球或国旗图标里选语言。

注意语言和币种是两套设置：改语言要在系统里改，改币种则在应用/网站的设置里，见 [价格显示外币怎么改.md](价格显示外币怎么改.md)。

## 七、价格提醒一直没收到通知

- 检查应用的通知权限有没有开；没开的话只有邮件提醒，不会有推送。
- 进「个人资料 → 价格提醒」确认这条提醒还在。
- 价格没达到触发条件时，不会一有波动就发通知，这是正常的。
