# Skyscanner 价格显示外币怎么改

## 一、币种在哪儿改

不同端口的入口不一样，认准「地球 / 旗帜 / 个人资料」这几处：

| 你在用哪个 | 怎么进设置 |
| --- | --- |
| 桌面网站 | 点页面顶部的**地球图标**，在弹窗里选币种 |
| 移动端网页 | 登录个人资料后点**国家/地区旗帜**，或滚到页面底部进区域设置 |
| 手机应用 | 进「**个人资料**」→「**设置**」，找到币种那一项 |

可选的币种有 150 多种，常用的、不常用的都在里面。

## 二、币种和地区是连在一起的

币种不是孤立的：区域设置同时决定默认币种和显示的站点市场。换一个市场之后，能看到的供应商和价格展示有时会不一样。所以改完币种，最好把同一趟搜索重搜一遍再比，不要拿改之前记下的数字和改之后的对。

## 三、跳转后币种又变了怎么办

- 供应商网站可能按它自己的市场显示另一种币种，这跟你在 Skyscanner 里选的币种不一定一致。
- 大多数情况可以在对方的网站上再改一次币种。
- 如果最后以外币结算，**发卡行或支付渠道会用自己的汇率换算**，还可能收一笔货币转换费。下单前先问清银行或支付平台按什么汇率算、收不收手续费，别只盯着页面上的数字。

## 四、为什么你的价格和别人看到的不一样

币种、地区、搜索时间任何一个不同，看到的价格数字就会不同；价格本身还是动态的。要比价就在**同一币种、同一地区**下比，跨币种直接比数字没有意义。

同一趟搜索在不同时间、不同币种下结果不同属正常现象，想弄清某次价格到底变没变，见 [搜索不到航班或价格对不上怎么办.md](搜索不到航班或价格对不上怎么办.md)。
