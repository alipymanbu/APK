# Skyscanner 机票搜索与筛选怎么用

> 本篇讲在 Skyscanner 手机上怎么发起一次机票搜索、结果怎么排序、筛选条件都用在哪儿，以及挑到合适航班后下单的那一步在哪里完成。

## 一、一次搜索要填哪几项

打开应用默认就在机票搜索页，从上到下依次填：

| 项目 | 怎么填 |
| --- | --- |
| 出发地 / 目的地 | 城市、机场、国家/地区都能填；填国家/地区会覆盖该国的所有机场 |
| 日期 | 可以指定具体日期，也可以走「灵活日期」看整月价格，见 [全月最低价与价格提醒怎么用.md](全月最低价与价格提醒怎么用.md) |
| 旅客 | 成人、儿童、婴儿分开填，人数直接影响总价 |
| 舱位 | 经济舱、超级经济舱、商务舱、头等舱 |

填完点放大镜图标开始搜索。

## 二、结果怎么排序：Best / Cheapest / Fastest

结果列表顶部有三档排序，换一档，看到的顺序完全不一样：

| 排序 | 含义 | 什么时候用 |
| --- | --- | --- |
| Best | 综合价格与总时长，并把中转次数、是否要换机场、有没有超长中转这类「麻烦程度」一起算进去 | 默认先看这档，性价比最均衡 |
| Cheapest | 从低到高按票价排 | 只看价格、时间能迁就 |
| Fastest | 从短到长按总时长排 | 赶时间，价格可以放宽 |

## 三、筛选条件用在哪儿

搜索结果页的筛选面板里，逐项勾选可以快速把不想看的选项清掉：

- **中转次数**：直飞、一次中转等；
- **出发与到达时段**：只看白天或者只要红眼航班都靠它；
- **航空公司**：常旅客有偏好时先筛掉不想要的；
- **出发 / 到达机场**：同城多机场时可指定其中一个；
- **飞行时长**：想压在一段时长以内时用；
- **舱位**；
- **附近机场**：同城或邻近城市有多个机场时，勾上「附近机场」能把这些机场的航班一起搜进来，出发地和目的地两端都能勾。填目的地时输入框会顺带列出附近机场以及它们离目的地的距离，拿不准飞哪个先看一眼。

用法上没有固定顺序：想先看便宜的就先按 Cheapest 排，再用筛选砍掉不能接受的；想先看快的就是反过来。

## 四、结果里那些提示要看一眼

- 结果里会标出**最短行程**，也会提醒**超长中转**、以及往返分别从**不同机场**起降这类情况——落错机场要额外折腾，别只看价格。
- 每家报出这条价的航空公司或旅行社下面带一个**供应商评分**，是依据其他旅客对它的评价给出的星级，选不熟的那家前可以先扫一眼。
- 价格里已经含了估算的税费与手续费；最终金额可能因为附加项或支付方式发生变化，见 [搜索不到航班或价格对不上怎么办.md](搜索不到航班或价格对不上怎么办.md)。价格显示成外币时，改币种见 [价格显示外币怎么改.md](价格显示外币怎么改.md)。
- 转机时间太紧的航班一般不会列出来（少于 1 小时的基本不显示）；由不同航空公司承运的航段会被标成「自主转机」，行李怎么算、误了下一段怎么办见 [行李额度和转机时间怎么确认.md](行李额度和转机时间怎么确认.md)。

## 五、多人出行与儿童票

- 多个人一起搜时，列表上会给**总价**，也会折算出**人均价**（儿童、婴儿按各自的低票价折算进去）。
- 同一个订单里孩子中途过生日，或者未满 18 岁单独乘机，各航司的规则和票价都不一样。Skyscanner 不参与定价与出票，订之前直接看出票方怎么规定。

## 六、选好之后，下单在哪里完成

点中某条结果旁的「选择」，会列出一批提供这条票价的航空公司与旅行社；你再点进其中一家的网站，在那儿选座、填常旅客号、付款、拿到确认单。Skyscanner 只负责把选项并排摆出来，收钱和出票都是对方在做。

所以改期、退票、开发票这些事都不在 Skyscanner 里办，找的是最终出票那家，见 [预订后改期退票找谁.md](预订后改期退票找谁.md)。
