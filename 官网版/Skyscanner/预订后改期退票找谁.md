## 一、先说结论：Skyscanner 不处理你的订单

Skyscanner 是旅行搜索引擎，不是旅行社。它把各家航空公司与旅行社的报价搜集起来并排展示，你点进去、在对方网站上付款出票。因此：

- 它不能帮你改期、退票、开发票；
- 确认邮件、行程单、发票都由出票的那家发；
- 有任何售后问题，联系的是出票方，不是 Skyscanner；
- 用它不花钱：不收预订费，也不在票价上加价——同一张票，在它这里看到的价格和出票方网站上的价格一致。

## 二、怎么确认自己是通过谁订的

1. 翻邮箱找**预订确认邮件**，里面通常写着出票方的名称和预订编号（PNR 或确认号）。
2. 找不到就翻一遍垃圾邮件箱。
3. 还没有，就查银行或支付账单，上面会显示收款方名称。
4. 拿到名称后，直接去这家航空公司或旅行社的官网、客服入口处理。

## 三、常见情况该找谁

| 情况 | 找谁 | 说明 |
| --- | --- | --- |
| 想改期 / 改签 | 出票方 | 能不能改、收不收费，按你买的票价规则 |
| 想退票 | 出票方 | 退款金额与到账时效由出票方定 |
| 不小心重复预订 | 出票方 | 尽快联系，越早越好 |
| 航班时间被航司改了 | 出票方 / 航司 | 可能可以改签或退款，按具体政策 |
| 乘客姓名写错要更正 | 出票方 / 航司 | 常有额外限制或费用 |
| 加托运行李、选座、买餐 | 出票方 / 航司 | 在对方的订单里操作 |
| 赶不上转机或误机 | 出票方 | 能不能改签、怎么处理，看你买的票价与是否联程 |
| 账单上出现不认识的公司扣款 | 出票方 | 多半就是你的出票方，银行账单上的名字可能与品牌不同 |

行李额度怎么确认、能不能预订后再加、转机时间怎么算，见 [行李额度和转机时间怎么确认.md](行李额度和转机时间怎么确认.md)。

## 四、航班取消或航变时，先别自己退

如果航司已经取消了你的航班，通常有两条路：全额退款，或者改到另一个航班，具体看航司政策与航班出发地的规定。

**如果航班还显示正常，就不要自己先去取消。** 自愿取消可能受票价规则限制，反而影响退款资格。航班状态以航司官网和官方 App 为准，机场显示屏有时更新不及时。

## 五、酒店和租车的改退也一样

房费和租车同理，都在你下订的那家网站处理。订的是「可免费取消」的房型或车辆时，最晚什么时候取消，以对方的条款为准——下单前先看清那一行。

## 六、找不到出票方的联系方式

- **航司**：进官网找「管理我的预订」，或直接找客服；
- **在线旅行社**：用它的订单页或客服入口；
- 实在翻不到，可以去看 Skyscanner 官方帮助中心里关于「查找合作伙伴联系方式」的说明，按提示操作。
