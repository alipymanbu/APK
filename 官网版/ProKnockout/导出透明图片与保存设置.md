## 一、什么情况该存透明底

抠出来的主体只要还想二次利用——当贴纸、垫到别的背景上、在别的软件里做合成——就该存成透明 PNG，而不是带背景的 JPG。PNG 会保留主体周围的透明区域，JPG 会把透明处填成白色，后者再抠一次就麻烦了。

## 二、导出透明 PNG 的步骤

1. 在抠图结果页确认边缘已经修干净（透明导出会把你留下的所有杂边一起带上）；
2. 点保存 / 导出，格式选 PNG；
3. 如果页面上有「透明背景」相关开关，确认它是开着的；
4. 导出后到相册或文件里看一眼：背景显示为棋盘格（或深色格）才是真透明，白色实底说明格式选错了。

导出的透明图可以直接再导回应用当贴纸用，也可以给其他修图软件当素材。

## 三、保存时的选项怎么挑

| 选项 | 怎么选 |
| --- | --- |
| 格式 | 二次合成选 PNG（保留透明）；成图发布选 JPG（体积小） |
| 清晰度 | 要打印或提交的选最高档；社交发图标准档够用 |
| 尺寸 | 与用途匹配即可，放大不会变清晰，按原图尺寸导出最稳 |

保存时可选的格式与档位以你安装的版本实际显示为准，不同版本菜单略有出入。

## 四、保存后找不到图的排查

- **相册里没有**：先确认存储权限是允许的，权限被拒时保存会静默失败；到应用的权限设置里打开后重新保存一次；
- **相册没刷新**：部分手机要重启相册应用或等它重新扫描才会出现，用文件管理器搜 PNG/JPG 的最新文件确认是否真存下来了；
- **存到了应用目录**：有些版本会存进相册下的独立文件夹（通常以应用名命名），在相册的「文件夹」视图里找；
- **怎么都存不上**：检查手机剩余存储空间，空间不足时导出同样会失败；
- **保存时弹出付费提示**：高清导出是这款应用的常见付费点（iOS 商店的内购清单里有「保存高清图片一次」这类单次项），不是出了故障；付单次还是开订阅划算、试用扣费怎么防，见[会员订阅与自动续费注意事项.md](会员订阅与自动续费注意事项.md)。

## 五、透明图的后续用法

存好的透明 PNG 三种常见去向：再导回本应用进贴纸专辑复用（见[图片合成与滤镜效果.md](图片合成与滤镜效果.md)）；垫底色做证件照素材（见[证件照换底色步骤.md](证件照换底色步骤.md)）；发给其他设备上的软件继续加工。抠图环节的工具回顾在[抠图换背景怎么操作.md](抠图换背景怎么操作.md)。
