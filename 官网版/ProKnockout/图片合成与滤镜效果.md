## 一、多图合成的操作顺序

1. 进入图片合成功能，一次导入两张以上的图；
2. 底下那张是背景层，其余的作为前景逐张叠上去；
3. 选中某一层后可以缩放、旋转、挪位置，还有组合与对齐选项帮你对齐多张图；
4. 调前景层的透明度，让两层的光影衔接自然；
5. 满意后保存，导出选项见[导出透明图片与保存设置.md](导出透明图片与保存设置.md)。

常见用法：抠出的人像垫到风景图上、给商品图叠促销标签、把两张合影里最好的部分拼到一张。

## 二、合成不自然的三个调整点

| 问题 | 调整 |
| --- | --- |
| 前景像「贴」上去的 | 降低透明度两三档，或给前景加投影，让它落在背景的光线里 |
| 两张图色调对不上 | 先分别用滤镜把色调拉到接近，再合成 |
| 边缘生硬 | 回抠图步骤给边缘做羽化，再导回来叠 |

合成的前置工作其实是抠图质量，主体边缘干净，合成就成功了一半。

## 三、特效滤镜有哪些类型

应用内置一百多款特效，大致分这几类，按你想要的方向挑：

| 方向 | 代表效果 |
| --- | --- |
| 立体感 | 投影、高光、描边 |
| 风格化 | 现代艺术、卡通、动画书 |
| 光学模拟 | 模糊、玻璃 |
| 手绘感 | 铅笔 |
| 像素处理 | 马赛克 |

同一张图换不同特效就是不同的成品气质；特效支持实时预览，不满意可以撤回换下一个，逐个试比自己猜快。除了单发的特效，应用还有二十多种混合模式（iOS 商店的功能列表里写的是「23 种混合模式」），把前景层的混合模式挨个切一遍，比调透明度更快找到融合得好的那种。

## 四、贴纸与素材的配合

- 应用内置贴纸库与背景素材库，合成时直接取用，不用到外面找图；
- 自己抠出来的主体可以存成贴纸，放进独立的贴纸专辑，下次合成直接调用；
- 透明 PNG 素材也能导入进来当图层用，和内置贴纸混编。

把常用素材都攒进贴纸专辑，做系列图（比如同风格的社交配图）时效率会明显提高。

## 五、消除笔与 AI 功能（新版 / 在线版）

比较新的版本里多了一组「删东西」和「补画面」的功能，做合成时常能用上：

- **魔法消除（消除笔）**：抹掉画面里的路人、杂物，应用会把背景补回去——适合先把背景清理干净再合成；
- **老照片修复与上色**：把翻拍的老照片先修清晰再拿去抠人像，边缘比翻拍的模糊原图好处理得多；
- **AI 扩图 / 背景虚化**：背景不够大时向外扩一圈，人像合成时给背景加虚化突出主体。

这几个功能在官网的在线工具里也有对应入口（[消除笔](https://www.proknockoutapp.com/remove-objects)、[清晰度修复](https://www.proknockoutapp.com/photo-enhancer)、[背景虚化](https://www.proknockoutapp.com/blur-background)、[AI 扩图](https://www.proknockoutapp.com/ai-image-extender)），不用装应用也能偶尔用一次。注意：这些属于较新版本的能力，网盘里那份 5.7.2 不一定都有，以你应用里实际显示的功能入口为准。

## 六、合成结果怎么处理

合成完的图两条路：直接保存为成品图，或只导出某一层做透明底素材留作他用，操作见[导出透明图片与保存设置.md](导出透明图片与保存设置.md)。抠图环节的细节工具回顾可以看[抠图换背景怎么操作.md](抠图换背景怎么操作.md)。
