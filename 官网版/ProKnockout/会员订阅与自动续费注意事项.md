## 一、哪些功能可能触发付费

ProKnockOut 本体免费下载，属于「免费 + 内购」模式。iOS 版商店页面显示的内购档位如下（截至 2026-09，安卓端的档位与价格以应用内实际显示为准）：

| 类型 | 档位 | 标价 |
| --- | --- | --- |
| 单次付费 | 保存高清图片一次 | ¥3.00 |
| 单次付费 | 保存高清证件照 | ¥3.00 |
| 单次付费 | 通用解锁 1 次 | ¥3.00 |
| 订阅 | 连续包周高级会员 | ¥29.00 |
| 订阅 | AI 周会员 | ¥30.00 |

对应到使用场景：基础抠图、换背景这类日常操作大多不设门槛；**高清导出**（高清图片、高清证件照、高清贴纸）是最常见的付费点。按使用频率挑付费方式更划算——偶尔要一张高清图就买单次项，短期集中处理再考虑周期订阅，订阅前先看清是不是「连续包」。

## 二、免费试用与自动续费的坑

黑猫投诉平台上针对这款应用有多条与订阅相关的投诉，集中在这几点：

- 免费试用到期后直接转自动扣费，扣费前没有收到短信或弹窗提醒；
- 卸载应用后扣费仍在继续；
- 想退款时发现应用内联系不到人工客服。

这些是投诉方的单方陈述，但「先试用后扣费」「无提醒续费」与近年消协曝光的 App 通用套路一致。不管在哪端开通，建议照这三条做：

1. 开通前逐字看页面上的「连续包周 / 连续包月 / 自动续费」字样，默认勾选的自动续费要手动取消；
2. 记下试用期截止日，到期前一天自查扣费状态；
3. 开通后立刻按下一节路径确认签约状态，别等到扣款才发现关不掉。

## 三、怎么取消自动续费

订阅在哪里扣的费，就要去哪里取消。四个常用入口：

| 支付渠道 | 取消路径 |
| --- | --- |
| iOS（App Store 订阅） | 设置 → 点顶部 Apple ID → 订阅 → 选中该应用 → 取消订阅 |
| 微信支付 | 我 → 服务 → 钱包 → 支付设置 → 自动续费（扣费服务）→ 关闭 |
| 支付宝 | 我的 → 设置 → 支付设置 → 免密支付 / 自动扣款 → 选中协议 → 关闭服务 |
| 华为帐号 | 设置 → 帐号中心 → 付款与账单 → 自动续费 → 退订 |

两个容易漏的点：

- **只删应用不等于取消订阅**，签约协议仍然生效，必须去上表的入口里关；
- 在支付平台列表里找不到对应协议时，到「已关闭服务」里确认是不是此前已经解约过（这是支付宝官方帮助里的说明）。

## 四、联系客服与退款

应用商店的官方简介里留了两个渠道：微信公众号（微信内搜索 knockout）与 QQ 群 616718243。不过上面提到的投诉里，有用户反映公众号里没有人工客服、群内也难以解决退款，协商不畅时可以走通用维权渠道：拨打 12345，或在全国消协「智慧 315」平台在线提交（这是中国消费者报给出的建议路径）。

苹果端的订阅扣费，退款直接找 Apple（[reportaproblem.apple.com](https://reportaproblem.apple.com)）申请，比找应用方更直接。
