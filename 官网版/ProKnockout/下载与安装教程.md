## 二、安装步骤

1. 从上面的 ProKnockout 安装文件资源（夸克网盘）进入分享页，把安装包转存到自己的网盘后下载到手机；
2. 在手机文件管理里找到下载好的 APK 文件，点它开始安装；
3. 如果系统提示「禁止安装未知来源应用」，到 **设置 → 安全（或应用管理）** 里允许浏览器或文件管理器安装应用，再回来重试；
4. 安装完成点打开，首次启动会依次请求相册、相机等权限，允许后才能正常选图和拍照。

部分手机（如小米、华为）还会在安装时额外弹一次「继续安装」确认，属于系统行为，点继续即可。

## 三、安装失败的常见排查

| 现象 | 先查什么 |
| --- | --- |
| 安装到一半提示失败 | 存储空间是否够用——安装包本身 182.78M，加上解压后的占用，建议预留 1GB 以上 |
| 点了安装没反应 | 「未知来源应用安装」权限是否已允许 |
| 提示包损坏 | 重新下载一遍，核对 MD5 是否与上表一致，不一致说明下载不完整 |
| 提示与已装应用冲突 | 手机里已有同包名的其他来源安装包，先卸载旧的再装 |
| 下载很慢或中断 | 网盘大文件建议在 Wi-Fi 下转存后下载，中断的续传一次即可 |

## 四、首次打开需要的权限

启动后会用到这几类权限，按需允许即可：

- **存储 / 相册读取**：选照片进来编辑、把成品保存回相册，核心功能依赖它；
- **相机**：直接拍照当素材；
- **通知**：接收任务或活动提醒，不影响主功能，可以拒绝；
- **读取听觉媒体**：给视频类功能读取配乐用，不做视频编辑的话给不给都不影响修图。

拒绝存储权限会导致选不了图，属于必给项；其余按你的使用习惯决定。

## 五、要不要换装商店里的新版

网盘这份是 5.7.2，包名与商店版一致，属于同一条应用线。两种选择：

- **沿用当前版**：功能满足需求就不必动，Android 7.0 以上的手机可以直接运行；
- **升级到新版**：直接在商店更新，或用新安装包覆盖安装，数据通常保留；升级前建议先把要紧的成品图导出备份。
