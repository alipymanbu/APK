## 一、为什么要先转存，而不是直接下载

夸克网盘的分享链接指向的是分享者的文件，分享方随时可以取消分享，链接也可能因为其他原因失效。先把文件**转存到你自己的网盘**，这份文件就归你的账号管，之后哪怕原链接失效，你也能随时从自己网盘里重新下载。装 yoki 这类几百 MB 的安装包，免费账号的初始空间完全够用。

## 二、手机端：转存与下载

1. 打开 [yoki 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9367ec00452a)；如果没有装夸克网盘 App，手机上通常会让你选择「用网页打开」或「唤起 App」，两种都行，登录账号即可；
2. 勾选文件，点「转存」，选一个位置（比如「来自：分享」或自建文件夹）；
3. 转存成功后，进自己网盘的对应位置，点文件旁的「下载」；
4. 在网盘 App 的「传输列表」里能看到下载进度，完成后按系统提示打开，或去文件管理器找。

大文件下载建议连 Wi-Fi；下载中途断了，重新点下载一般会接着传，不用从头来。

## 三、电脑端：下载后怎么传到手机

在电脑浏览器打开夸克网盘网页版并登录，同样可以转存和下载。装安卓应用需要最终在手机上完成，所以下载到电脑后还要传一步：

- **数据线**：手机连电脑，选「文件传输（MTP）」模式，把 APK 拷进手机的「Download」文件夹；
- **聊天工具传文件**：通过微信「文件传输助手」、QQ 一类把 APK 发到手机再保存；
- **手机端直接下**：不嫌麻烦的话，其实最省事的是手机连 Wi-Fi 直接在网盘 App 里下载，跳过传输这一步。

传到手机后，用文件管理器找到 APK 点开安装，步骤见[下载与安装教程](下载与安装教程.md)。

## 四、失败对照表

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 链接提示「分享不存在 / 已失效 / 已取消」 | 分享方取消或链接到期失效 | 回到本文开头确认链接没复制错；仍失效就只能等分享方重新分享 |
| 转存时提示「空间不足」 | 自己网盘剩余空间不够 | 删掉自己网盘里不需要的文件再转存；免费初始空间装这一个安装包是够的，不够多半是网盘里已存了不少东西 |
| 找不到「转存」按钮 | 没登录，或打开的是网页预览态 | 先登录账号；手机上建议装夸克网盘 App 操作 |
| 下载速度慢或中途停 | 网络波动 | 切 Wi-Fi / 换网络重试；App 内下载比网页稳，中断后重下会续传 |
| 下载完成但找不到文件 | 不清楚保存位置 | 在网盘 App「传输列表」查看已完成任务；或用文件管理器搜索 `.apk` |

各版本 App 的按钮位置和提示文案可能略有出入，以你手上的版本实际显示为准；空间、转存数量等额度政策也可能调整，以网盘内说明为准。
