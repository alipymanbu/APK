## 一、安装前先确认这几件事

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 系统版本 | 安卓 5.2 及以上 | 以安装时系统实际检查为准，近几年的主流安卓手机都满足 |
| 存储空间 | 建议预留 1GB 以上 | 安装包约 217 MB，安装解压还要额外空间，也得给后续使用留余量 |
| 网络 | 建议用 Wi-Fi | 包体积大，用移动流量前先确认流量额度 |
| 系统设置 | 允许安装未知来源应用 | 见第三节，各品牌入口不同 |

yoki 是纯手机端应用，装好这一个 App 就能用，不需要额外的电脑端程序或插件。

## 二、获取安装包：先转存、再下载

安装包通过夸克网盘分享链接分发，流程是「转存到自己的网盘 → 从自己网盘下载到手机」：

1. 打开 [yoki 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9367ec00452a)，没登录就先登录（没有账号用手机号现场注册一个即可）；
2. 勾选分享里的文件，点「转存」，选一个自己网盘里的位置；
3. 转存完成后，进自己网盘找到该文件，点「下载」到手机本地存储；
4. 下载完成后记住保存位置（一般在系统「下载」目录或网盘 App 的下载目录，以 App 内设置为准）。

建议先转存再下载，而不是只在分享页里在线预览：分享链接可能失效，转存到你自己网盘后，这份文件就跟着你的账号走，之后随时能重新下载。转存或下载卡住了，按[网盘转存与下载失败处理](网盘转存与下载失败处理.md)的对照表排查。

## 三、允许安装「未知来源应用」

安卓默认只允许从应用商店装应用，从浏览器或文件管理器直接装 APK 会先被拦一下，这是正常保护，放行即可：

- **通用路径**：设置 → 应用 → 特殊应用权限（或「更多设置」）→ 安装未知应用 → 找到你用来打开 APK 的那个应用（浏览器或文件管理器），允许「来自此来源的应用」；
- **小米 / 红米（MIUI）**：设置 → 隐私保护 → 特殊权限 → 安装未知应用；
- **华为 / 荣耀（鸿蒙 / EMUI）**：设置 → 安全 → 更多安全设置 → 安装外部来源应用；
- **OPPO / vivo**：在设置里搜「未知来源」或「安装未知应用」最快。

各系统版本入口措辞略有差异，找不到就用设置页顶部的搜索框搜「未知」。

## 四、安装步骤

1. 打开文件管理器，找到刚下载的 APK 文件；
2. 点它，系统弹出「是否安装此应用」，选「继续 / 安装」；
3. 第一次装会先跳到「允许来自此来源的应用」那一页，按第三节放行后回到安装页；
4. 等进度条走完，点「打开」或回桌面点图标。

如果手机上装过旧的 yoki，直接覆盖安装即可；若提示签名冲突，先卸载旧版再装。账号在云端，卸载重装后用手机号重新登录即可，详见[常见问题与解决办法](常见问题与解决办法.md)。

## 五、安装包信息核对

本文对应的安装包信息如下，与你下载到的那份核对：

| 项目 | 值 |
| --- | --- |
| 应用名 | yoki（yoki星球） |
| 版本 | 1.5.1 |
| 包名 | com.yuyin.yokixingqiu |
| 安装包大小 | 约 217 MB |
| MD5 | 4207680F665A468DEF728F54B2707B80 |

想核对 MD5 的话：电脑上打开命令提示符，执行 `certutil -hashfile 文件完整路径 MD5`；安卓上部分文件管理器（如 MT 管理器一类）在文件属性里直接显示 MD5。注意不同渠道分发的同一版本安装包哈希可能不同，以你实际拿到的那份算出来的为准；哈希对不上只说明文件不同源或传输中损坏，装不上就回第二节重新下载一份。

## 六、装不上时的对照

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | 文件没下完整，或系统版本低于要求 | 重新下载；确认安卓版本满足第一节的要求 |
| 「存储空间不足」 | 剩余空间小于安装包加解压体积 | 清出至少 1GB 再装 |
| 「签名不一致 / 存在冲突」 | 手机里装过另一个来源的同名应用 | 卸载旧的那份再装 |
| 点 APK 没反应 | 没有授予文件管理器「安装未知应用」权限 | 回到第三节放行 |
| 安装中途自动退出 | 下载中断导致文件损坏 | 删掉重新转存、重新下载 |

装好之后第一步是注册登录，流程见[注册登录与资料设置](注册登录与资料设置.md)；装不上又对不上号的问题收在[常见问题与解决办法](常见问题与解决办法.md)里。
