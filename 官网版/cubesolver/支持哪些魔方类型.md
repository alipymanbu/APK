## 一、支持清单

Cube Solver 的覆盖范围远不止三阶。以下是官方页面列出的类型与对应解法步数（官方宣传口径，实际步数会随版本优化略有出入）：

| 类型 | 官方标注解法步数 |
| --- | --- |
| 二阶家族（Pocket、Mirror、Tower Cube） | 14 步以内 |
| 三阶（3×3） | 约 27 步 |
| 四阶（4×4） | 约 63 步 |
| 五阶（5×5） | 约 136 步 |
| 斜转魔方（Skewb） | 11 步以内 |
| 斜转菱形（Skewb Diamond） | 10 步以内 |
| 金字塔（Pyraminx） | 11 步 |
| Ivy Cube | 8 步以内 |
| Kilominx（五面体十二面体） | 约 44 步 |

其中**二阶镜像魔方（2×2 Mirror Cube）是它重点宣传的能力**——官方称自己是唯一能解该类型的移动应用。镜像魔方靠形状而非颜色区分块位，输入时比普通二阶多一分耐心。

## 二、主界面上能看到的入口

打开应用，主界面通常直接铺开这些入口：Timer（计时器）、Customization（配色与主题）、Pocket Cube（二阶）、Tower 2×2×3、Mirror Cube 2×2、Rubik's Cube（三阶）等。选类型的方式很直白——你手里是什么魔方，就点哪一格，之后的流程一律是「填颜色 → 解算 → 跟 3D 步骤转」（详见 [三阶魔方怎么还原.md](三阶魔方怎么还原.md)）。

具体入口会随版本增减，以你装的版本实际显示为准。

## 三、版本差异：你手上这份是 4.5.5

网盘里这份安装文件是 **4.5.5**（包信息见 [下载与安装教程.md](下载与安装教程.md)），而官方商店版本一直在往前走。对照官方更新日志，几处和「支持类型」直接相关的差异：

- **Kilominx 是 5.0.3 版本才加入的新魔方**——你手上的 4.5.5 里没有这一项；
- 5.0.4 给二阶、四阶、五阶、Tower 2×2×3、金字塔、斜转、Ivy、Dino Cube 等补齐了色盲友好主题，并新增二阶镜像魔方的配色；
- 5.0.5 缩短了五阶的解法步数，并给图案加了新国旗。

也就是说：**清单里没有的类型，别在 4.5.5 里硬找**；想解 Kilominx 这类新类型，需要更新到对应版本以上的安装文件（以官方渠道当时提供的版本为准）。反过来，4.5.5 已经覆盖了上表除 Kilominx 外的绝大部分类型，日常使用够用。

## 四、怎么判断某个类型该怎么选

拿不准类型时有个笨办法：看你的魔方**块位靠什么区分**——

- 靠颜色区分、六面正方 → 按阶数选（二阶/三阶/四阶/五阶）；
- 靠形状（块有凸起）区分 → 镜像类（Mirror Cube 2×2）；
- 四个三角面 → 金字塔（Pyraminx）；
- 斜着转的方块 → 斜转（Skewb）；
- 叶子状单块可按 → Ivy Cube。

选错类型的后果只是「填颜色时对不上」，换一格重选即可，不会弄坏数据。实在不确定，从三阶那一格进（[三阶魔方怎么还原.md](三阶魔方怎么还原.md)），流程最标准。选对了类型却解算失败的，走 [解不出来怎么排查.md](解不出来怎么排查.md)。
