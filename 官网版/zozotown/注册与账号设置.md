## 一、注册前先知道三件事

1. **一个邮箱就够**：ZOZOTOWN 的账号体系叫 ZOZO ID，注册时填的邮箱地址本身就是 ZOZO ID，同一个邮箱不能重复注册；
2. **注册免费**：没有入会费、年费；不定期会有新会员送积分或优惠券的活动——这类活动通常要从活动页进入注册才算数，直接注册可能拿不到，注册前可到官网确认（[zozo.jp](https://zozo.jp/)）；
3. **界面是日语**：注册页面没有中文选项，各字段的含义见下一节。

## 二、注册步骤

1. 打开 App，进入「新規会員登録」（新会员注册）；
2. 依次填写：性别（性別）、出生年月（生年月日）、邮编（郵便番号）、邮箱（メールアドレス）、密码（パスワード）；
3. 按页面提示完成提交，留意邮箱里的确认邮件；
4. 未成年注册需要监护人同意。

注册时填的邮编用于确定默认收货地区；收货地址必须是日本境内（配送范围的限制见 [配送范围与退换货规则.md](配送范围与退换货规则.md)）。

## 三、游客购买与会员的差异

不注册也能下单，ZOZOTOWN 称之为「ゲスト購入」（游客购买），但功能上有明显差异：

| 功能 | 游客购买 | 会员 |
| --- | --- | --- |
| 预约商品、抽选商品 | 不能下单 | 可以 |
| ZOZO 积分 | 不返还 | 返还 |
| 支付方式 | 仅信用卡、货到付款 | 全部（含便利店付款、后付款、PayPay、LINE Pay） |
| 便利店/门店自提 | 不能指定 | 可以 |
| 随时以旧换新（いつでも買い替え割） | 不可用 | 可用 |
| 每日店铺优惠券 | 不能使用 | 每天可领 |

只有一次性购物需求的话，游客购买省事；打算比价、蹲降价、长期使用，直接注册会员更省心。优惠券的领法与排查见 [优惠券与积分攻略.md](优惠券与积分攻略.md)。

## 四、登录常见问题

| 提示/现象 | 多数原因 | 处理 |
| --- | --- | --- |
| 「このメールアドレスは登録できません」 | 邮箱已被注册过 | 走密码重置（パスワードを忘れた方）流程 |
| 收不到验证邮件 | 邮箱把官方邮件当成了推广邮件 | 检查垃圾箱，把官方发件域加入白名单 |
| 换设备后收藏不见了 | 登录了另一个账号 | 确认用的是同一个 ZOZO ID |

## 五、多设备同步

收藏的商品、收藏的品牌、尺码设置都挂在 ZOZO ID 上：手机 App、平板、电脑网页端登录同一账号，看到的是同一份数据。在 App 里收藏的商品降价或补货时，开启了推送的设备会收到通知。

装好、注册好之后，下一步就是挑东西下单：[购物流程与支付方式.md](购物流程与支付方式.md)。
