## 一、先分清三类优惠

| 类型 | 内容 | 门槛 |
| --- | --- | --- |
| 新会员积分 | 从活动页进入注册后赠 ZOZO 积分，数额与有效期随活动变化 | 仅限通过活动页注册的新会员 |
| 店铺优惠券（本日のクーポン） | 每天更新，单店立减 500~3,000 日元 | 会员；每店每天一次 |
| LINE 通知 | 收藏商品进入优惠券范围、降价、有活动时推送 | 绑定 LINE ID |

第三类不是券本身，是「别错过前两类」的通知渠道。优惠口径会变动，领取页面以官方当日显示为准。

## 二、店铺优惠券怎么生效

ZOZOTOWN 的店铺优惠券没有券码、不需要提前「领」：

1. 在优惠券页（[zozo.jp/coupon](https://zozo.jp/coupon/)）看今天有哪些店参加；
2. 商品缩略图左下角会标「○○円クーポン」之类的标记，详情页直接写「クーポンご利用なら○○円で購入できます」；
3. 把这类商品加入购物车，结算时自动按券后价显示（购物车里叫「クーポン値引」一行）；
4. 每家店每天限用一次；一次买同一家店的多件商品时，券按该店商品计。

## 三、券没生效的常见原因

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 购物车里没有「クーポン値引」这一行 | 商品不在券的适用范围（同一家店也有适用与不适用商品混着卖） | 换带券标记的商品 |
| 之前用过一次 | 同一家店当天只能用一次 | 第二天再来，或换一家参加的店 |
| 昨天还能用今天不行 | 券每天更新，昨天的券已过期 | 到优惠券页看今天的名单 |
| 未登录状态看到打折却结算不了 | 店铺优惠券仅限会员 | 先注册或登录（见 [注册与账号设置.md](注册与账号设置.md)） |

## 四、ZOZO 积分与 ZOZOCARD

- **ZOZO 积分**：1 点按 1 日元在 ZOZOTOWN 购物时抵扣，只能站内用，不能换成别家积分；
- **ZOZOCARD**（官方联名信用卡，由 Pocket Card 发卡，年费免费）：在 ZOZOTOWN 消费返 5% 积分（按用券、抵扣积分之后的税前实际金额计算），站外消费返 1%；申请后卡片没寄到也能先在站内使用（有额度上限）；
- **有效期要盯紧**：ZOZOCARD 在 ZOZOTOWN 消费所返积分，从到账日起 90 天内有效；站外消费返的积分有效到「最后一次获得积分月份」的一年后月底，且不因新积分而延长。普通购物返的积分有效期以注册信息页「ZOZOポイント」栏目显示为准；
- 积分到账时点：ZOZOCARD 的站内消费积分在配送完成后约 2 周内到账。

打算长期用的话，把「下单前先看积分余额、先抵扣旧积分」变成固定动作，90 天的窗口足够两个购物周期。

## 五、下单前的一分钟核对

1. 优惠券页有没有这家店今天的券（ [zozo.jp/coupon](https://zozo.jp/coupon/) ）；
2. 商品有没有券标记，详情页的券后价是多少；
3. 积分余额与最近一笔的到期日；
4. 支付方式选了免手续费的（信用卡 / PayPay / LINE Pay），手续费差异见 [购物流程与支付方式.md](购物流程与支付方式.md)。
