## 一、谁能放、放哪边

官方在应用说明里写明：**业主和代理都可以放盘**，入口有两个 —— 用 28Hse App，或用香港版主站（[www.28hse.com](http://www.28hse.com)）；**楼盘资料在网站与 App 同步更新**，在哪儿改的另一头都会跟着变。

所以选入口只看习惯：人在外面想随手改照片就用 App，坐在电脑前批量填资料就用网页。App 的安装文件在 [28Hse 安装文件资源（夸克网盘）](https://pan.quark.cn/s/944b36f0ad17)，装法见 [下载与安装教程.md](下载与安装教程.md)。

费用上，官方的口径是**平台不向放盘人收取佣金**（App Store 与官网应用说明均如此表述）。这句话说的是「放盘这件事本身不收费」，与你和租客/买方之间、或与持牌代理之间的交易安排无关 —— 谈之前把费用问清楚，别把两件事混为一谈。

## 二、放盘前先备齐这些字段

对照楼盘详情页会长成什么样来准备，缺一项就补一项：

| 字段 | 填写要点 |
| --- | --- |
| 物业类型与用途 | 住宅 / 唐楼 / 工商铺 / 土地 / 车位，选错类型会挂到没人看的列表里 |
| 地区与屋苑 | 精确到片区与屋苑名，搜索与地图搵楼都按这个索引 |
| 租金 / 售价 | 叫价是谈的起点；租盘还要写清**差饷、地租、管理费是否已包** |
| 面积 | 实用面积与建筑面积两栏都填，页面会自动算 `@尺价` / `@尺租` |
| 房型与座向楼层 | 房间及浴室数、座向、单位楼层 |
| 照片 | 列表按照片数量展示，图多的盘点击率明显更高；竖图放房间、横图放厅与景观 |
| 联络方式 | 电话 / WhatsApp，香港版访客主要走 WhatsApp 联系 |
| 刊登标题 | 页面上的标题会原样展示，写清关键卖点与地址特征 |

照片与资料之后随时能改（见第四节），**不必为了「一次填完美」而压着不发** —— 盘早挂一天，进订阅推送的机会就早一天。

## 三、挂出去之后能出现在哪

一个盘上架后会进入这几条曝光路径：

1. **地区列表**：按刊登时间排序，新盘在最上面；
2. **地图搵楼**：按地理位置圈选时被捞出来；
3. **订阅推送**：符合别人存过的筛选条件时，以推送通知的形式发给对方（这一条依赖对方开了通知权限）；
4. **屋苑详情页**：挂进对应屋苑的在售 / 在租列表，顺带被看楼价走势的人看到（口径见 [按揭计算与楼价走势怎么看.md](按揭计算与楼价走势怎么看.md)）。

代理名下的盘还会展示在代理公司页面上，公司牌照与个人牌照号码一并列出 —— 这是访客判断「这个盘是不是真的持牌代理在放」的依据，填全联系方式与牌照信息能让点进来的人更快决定要不要约看。

## 四、改资料、换照片、下架

官方说明里明确 App 提供房源管理功能，**会员可以随时修改照片与信息**，常用动作：

- **调价 / 改描述**：租售叫价变了、家私情况变了就改，资料过期是访客流失的主因之一；
- **换照片**：新装修、新家电拍好后替换，列表的封面图决定第一眼；
- **刷新刊登**：楼盘页上的「刊登 / 更新日期」是访客判断盘还在不在的第一依据，长期没动静的盘会被直接跳过；
- **下架**：已租 / 已售就撤下来 —— 留着一个已成交的盘，只会浪费联络你的人的时间，也影响你下一个盘的可信度。

改完在网站与 App 各看一眼（两边同步，但页面缓存可能让你以为没生效），对照 [怎么找租房房源.md](怎么找租房房源.md) 第四节的字段清单检查一遍有没有漏填。

## 五、租约与后续

官方支持无纸化签约：租约协议可以用 App 或网站完成数字签署（Agreement 功能），方便业主、租客与代理三方不在同一地点时推进。

签完之后有一条业主的硬性义务别漏：**须在租约签订后 1 个月内，向差饷物业估价署递交表格 CR109**（新租出或重订协议通知书），载明租期、租金、由哪一方支付差饷与管理费等资料；迟交要缴罚款，而未递交该表格的业主无权向租客追讨租金（地监局消费者教育资料）。多数情况由代理或律师楼代为安排，但责任在业主，办完记得要一份回执。

按金收多少、印花税怎么分担、租约要不要打厘印，费率与流程见 [看楼到签约要花多少钱.md](看楼到签约要花多少钱.md)；租客那侧会拿这些条款反过来核对你的盘，字段填全能省一轮来回。

签之前该核对的、谈租金时该问的，仍以线下逐条确认为准 —— 平台负责把盘与人对上，交易条款由你自己把关。
