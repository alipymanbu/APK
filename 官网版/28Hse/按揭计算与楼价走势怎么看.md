## 一、按揭计算器：三个输入决定月供

App 内置按揭计算器，输入楼价就能算出每月要还银行多少钱。用之前先知道它的结果由哪几个数决定：

| 输入 | 说明 |
| --- | --- |
| 楼价 | 用成交价或叫价都行，两者算出来的月供差一大截 |
| 按揭成数 | 借多少成直接决定本金，可借上限以银行按你情况核定为准 |
| 按揭年期与利率 | 年期越长月供越低、总利息越多；利率变动会直接改结果 |

算出来的只是**在你填的假设下的月供**，不是银行批给你的实际条款 —— 实际可借成数、利率与还款安排由银行审批决定。多试几组「楼价跌一成 / 利率升一厘」的组合，比只看一组数字有用。

月供也不是买房的全部现金支出，一次性那部分（按金、税费）在租房一侧的算法在 [看楼到签约要花多少钱.md](看楼到签约要花多少钱.md)，买房侧以银行与律师楼核算为准。

## 二、屋苑页的楼价走势表：先看更新时间

每个屋苑详情页都有一张楼价走势表，页脚写明口径：**取最近 90 日的成交资料，逢星期六更新**。所以周一看到的表和周五看到的可能是同一份，别把它当实时行情。

表里各列的含义与怎么用：

| 指标 | 口径 | 你会怎么用它 |
| --- | --- | --- |
| 平均成交尺价 | 90 日内成交折算的屋苑平均尺价，官方注明会按单位楼层与特质做对应 | 和放盘叫价的 `@尺价` 并排比，差得远就是叫价偏高 |
| 成交量 | 该 90 日内的成交宗数 | 个位数成交量时，平均价被一两单极端成交带偏的可能很大 |
| 有盈利比例 / 蚀让比例 | 同一批成交里账面赚 / 赔的占比 | 蚀让比例高说明这屋苑近来是买方市场 |
| 一年转手率 | 一年内转手单位占比 | 转手率低的屋苑，看中了别指望马上有第二套可选 |
| 一年前尺价 | 对比基准 | 与当前尺价一起看，判断这一年的方向 |
| 放盘叫价区间 | 当前在售/在租的叫价与 `@尺价` | 叫价是谈的起点，成交价才作数 |

**成交量小的屋苑，这张表只当参考。** 页面会把成交明细一并列出，你完全可以自己按单数一遍。

## 三、成交纪录：注册处成交和市场成交不是一回事

明细页（买卖 / 租务 / 历史成交三个标签）里，每条记录标注来源：

- **注册处成交**：已过土地注册处登记的正式记录，价格与日期最可靠。
- **市场成交**：市场层面的成交信息，先于登记出现，时间上更早但可能与最终登记有出入。

每条给出实用面积、`@尺价`、成交日期，以及相对前次的涨跌百分比。**估这套房值多少钱，优先看注册处成交**；市场成交适合用来判断近期趋势是否已经转向。

租务那一栏同理，另有四个常被拿来判断入场时机的数：

| 指标 | 怎么读 |
| --- | --- |
| 平均成交尺租 | 与当前租盘叫价的 `@尺租` 比，高出一截说明叫价虚 |
| 租务回报率 | 页面按房型分列（如 1 房、2 房各一个数），与按揭月供对照，就知道「以租养供」大概是什么水平 |
| 租务活跃率 | 租务成交的活跃程度，低则可慢慢挑 |
| 租盘叫价区间 | 当前在租盘的最低到最高叫价 |

## 四、双币种与小组件

- **人民币换算**：内地版站点与 App 提供港币与人民币双币显示，不用自己换算（汇率以页面当时显示为准）。
- **桌面小组件**：把收藏的屋苑放到桌面，直接看该屋苑的成交数据，不必每次打开 App 翻进去。

两者都需要先把 App 装上，安装方式见 [下载与安装教程.md](下载与安装教程.md)。

## 五、判断一份数据能不能信

这套数据的价值在于**口径写在页面上**（90 日、逢星期六更新、来源为成交登记），而不是在于数字本身。三个自检动作：

1. 看更新日期 —— 是否已过本周六；
2. 看成交量 —— 个位数时不下结论；
3. 看来源 —— 注册处成交优先于市场成交。

数据看完要落到行动上：筛选与约看的动线在 [怎么找租房房源.md](怎么找租房房源.md)，手上这套房怎么挂出去看 [业主放盘与管理房源.md](业主放盘与管理房源.md)。
