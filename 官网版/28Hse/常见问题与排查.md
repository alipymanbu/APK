## 一、安装环节

### 点击 APK 提示「禁止安装未知应用」

安卓对非商店渠道的安装一律先拦一道，给弹窗里指定的来源（浏览器或文件管理器）打开「允许安装此应用」再返回继续。这不是病毒报警；担心包本身有问题，就按 [下载与安装教程.md](下载与安装教程.md) 的表格核对包名 `com.hse28.hse28_2` 与 MD5。

### 安装按钮置灰 / 提示无法安装

按顺序试三件事：清出至少 200MB 剩余空间（包体 49.96M，安装还要额外解压）；确认系统版本不低于包内声明的下限（本包登记为安卓 5.2 以上）；到厂商安全中心（纯净模式、支付保护之类）里放行本次安装。系统版本低于下限是硬拦截，只能换设备。

### 装完打开就闪退

按代价从小到大处理：

1. 强行停止后重新打开，再重启一次手机；
2. 到设置 → 应用 → 存储里**清缓存**（清缓存一般不动登录状态，清数据会）；
3. 确认手机存储不紧张、系统时间是自动设置（时间偏差会让登录校验失败，表现像闪退）；
4. 关掉 VPN 或广告拦截类工具再试一次 —— 这类工具改写网络请求时，应用常在启动联网那一步崩掉；
5. 还不行就从 [28Hse 安装文件资源（夸克网盘）](https://pan.quark.cn/s/944b36f0ad17) 重新转存一份并核对 MD5，排除下载环节把文件弄坏，再卸载重装。

以上是安卓通用排查顺序，不是该应用的已知故障清单；每一步都无副作用，可逐条回退。

### 想确认装的是不是同一个应用

到设置 → 应用 → 28Hse 里看包名，应为 `com.hse28.hse28_2` —— 与 Google Play 同名应用一致。版本号 3.13.5 是这份包的定版号，官方渠道此后更新过的版本号以商店页当时显示为准。

## 二、推送收不到

订阅了筛选条件却没动静，先分清是「没推」还是「没显示」：

| 检查点 | 操作 |
| --- | --- |
| 系统通知权限 | 设置 → 应用 → 28Hse → 通知，总开关与各分类都要开 |
| 后台运行限制 | 厂商系统的省电策略会拦推送，把该应用设为「无限制」或允许后台活动 |
| 订阅条件 | 条件筛得太窄（价格区间、户型同时卡死）时，本来就不会有新盘命中，放宽一项再观察 |
| 应用内登录 | 订阅与收藏跟账号走，退出登录期间的推送不会补发 |

顺带确认目标盘是否真的有效：楼盘页的**更新日期**超过一个月、或**浏览人次**已很高，多半已经租出，见下节。

## 三、联络不到代理 / WhatsApp 打不开

**先看你在哪一版入口看到的盘**：香港版主站（[www.28hse.com](http://www.28hse.com)）以 WhatsApp 联络代理与业主，内地版（[www.28hse.com.cn](https://www.28hse.com.cn)）以微信为主。跨版套用联络方式是联络不上的头号原因 —— 拿着 WhatsApp 号码去内地版找对应按钮，或反过来，都找不到人。

其余常见情况：

- **列表页号码显示成 `852-90400xxx`**：这是列表层的遮挡，进入楼盘详情页的「放盘联络人」区才能看到完整号码，点开即拨或直接跳 WhatsApp。
- **提示无可用应用**：手机没装 WhatsApp / 微信，先装上再回来点；或者直接用页面上的电话号码拨打。
- **拨通没人接**：改用页面底部的预设问句发消息（可以约睇吗、还在吗），文字留言比连环拨号更容易被回复。

谈之前顺手核对页面列出的**公司牌照号码与代理个人牌照号码**，这是判断对方身份的正规依据 —— 到监管机构的公开目录输入号码就能查到当前是否有效，见面还要看地产代理证，完整步骤见 [代理牌照怎么查真假.md](代理牌照怎么查真假.md)。

佣金数额谈不拢、或被告知要先交钱才能看房，按 [看楼到签约要花多少钱.md](看楼到签约要花多少钱.md) 的口径核对：佣金金额由双方协商但必须写进代理协议，未核实身份前不付款。

## 四、两版网站和 App 看到的房源对不上

三件事会造成「不一致」的错觉：

1. **缓存与刷新时机**：网站与 App 的盘源同步更新，但列表页有缓存；一边刚改完价、另一边还停在旧页面，下拉刷新或重进即可。
2. **你搜的入口不同**：香港版与内地版的默认展示语言、币种换算不同（内地版带人民币换算），看起来像两套数据，实际盘源同源。
3. **放盘人刚改过**：楼盘页同时给「刊登」与「更新」两个日期，以**更新日期**为准；实在存疑就直接问，别拿缓存页的数字当结论。

## 五、账号：哪些事不用登录

| 动作 | 需要登录吗 |
| --- | --- |
| 搜索、筛选、看楼盘详情、看楼价走势 | 不需要 |
| 地图搵楼、浏览纪录（App 内） | 不需要 |
| 收藏房源、看收藏列表 | 需要 |
| 订阅条件推送 | 需要 |
| 放盘、修改房源资料 | 需要（会员） |

官方原话是「注册会员不是必需的」—— 所以在注册页卡住时，先退回去把房看完，需要收藏了再注册。

## 六、还不确定怎么办

把出问题的那一步截图（含系统版本、应用版本号、楼盘编号），连同你走过的路径一起，通过楼盘页或官方站点的联络渠道反馈。涉及具体某个盘的疑问，直接问放盘联络人比问平台快 —— 盘源信息是代理与业主自己维护的，见 [业主放盘与管理房源.md](业主放盘与管理房源.md) 第四节。
