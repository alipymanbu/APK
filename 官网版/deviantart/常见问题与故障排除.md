# DeviantArt 打不开、登录不上、收不到通知怎么办

## 一、登录不上：密码明明是对的

按命中率从高到低试：

1. **先清应用数据** —— 手机上最常见的是本地缓存把登录态搞坏了。路径：设置 → 应用 → DeviantArt → 存储 → **清除缓存 + 清除数据**。清完重开应用、重新登录。（清数据会退出登录，不会删你账号里的东西。）
2. **换网络再试** —— Wi-Fi 和移动数据各试一次。Wi-Fi 显示连着但出不去网的情况很常见，换个网络能直接排除掉一大类原因。
3. **查是不是服务端在故障** —— 如果清缓存、换网络都不行，可能是平台本身在宕机。用第三方服务状态查询站点（搜 `deviantart downdetector`）看一眼是不是大面积故障 —— 是的话你什么招都没用，等恢复即可。
4. **重置密码** —— 走官方的找回密码流程，用注册邮箱收重置链接。
5. **账号可能被限制了** —— 少数情况下，异地登录、异常活动会触发安全锁定，此时报错往往很含糊。只能通过官方支持渠道提交工单处理。

**判断顺序**：先清数据 → 再换网络 → 再查故障 → 最后才怀疑账号。反过来做会浪费时间。

## 二、图片加载慢或刷不出来

国内直连这家的服务本来就偏慢，这是最常见的体感问题，不是你装错了包。

- **先确认是不是全站都慢**：切到移动数据对比一下；换个时段再试（高峰时段更慢）。
- **清一次缓存**：缓存里堆积的失效数据会让图片区反复加载失败，路径同上（设置 → 应用 → DeviantArt → 存储 → 清除缓存）。
- **别只盯着首页**：如果只有个别大图刷不出来，多半是单张图的加载超时，往下刷或重进即可。
- **判断基准**：首页作品流能出图 = 网络是通的。完全不出图才需要按上面三条排查。

## 三、收不到推送通知

通知是三层开关叠出来的，任何一层关了都不响：

1. **系统通知权限** —— 设置 → 通知 → 应用 → DeviantArt → 打开「允许通知」。首次启动时如果点了「拒绝」，就是这里被卡住。
2. **系统省电策略** —— 设置 → 电池 → 找到 DeviantArt → 设为「不优化 / 允许后台运行」。很多国产系统会默认杀后台，杀掉后推送就发不出来，只能等你手动打开应用才补上。
3. **应用内通知设置** —— 进应用的设置里确认各类通知（回复、关注、私信）的开关没被关掉。
4. **后台数据** —— 确认没给这个应用关掉后台联网（设置 → 应用 → DeviantArt → 移动数据与 Wi-Fi → 后台数据）。

另外一个历史坑：**Android 13 上曾出现推送和聊天集体失效的问题，官方在 3.3.3 版本修过**。如果你手上是很老的版本，先升级再排查（网盘里那份是 3.3.4，已包含该修复）。

## 四、闪退、卡在启动页

1. **清缓存 / 清数据**（路径同上），八成情况到这一步就好了。
2. **确认版本**：在应用的关于页看版本号，网盘那份应显示 3.3.4；版本太旧就重装新包。
3. **看存储空间**：可用空间见底也会导致启动即崩，先腾出几百 MB。
4. **仍不行就卸载重装** —— 别在旧包上覆盖安装，容易留下不一致的数据。卸载前确认你的账号密码记得住（作品都在账号里，不在本地）。

## 五、安装失败：「解析包时出现问题」

- **包没下完整** —— 下载中断会导致文件损坏。重新下载一次；校验方式见下。
- **系统版本过低** —— 第三方信息页标注要求 Android 5.0 及以上，系统太老的机器装不上也跑不动。
- **来源权限没开** —— 从文件管理器安装时，要给它开「允许来自此来源」，否则安装按钮是灰的（步骤见[下载与安装教程.md](下载与安装教程.md)）。

重新获取安装包时，用这份 [DeviantArt 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2916c1620a15)，包名 `com.deviantart.android.damobile`，37.85M，MD5 `AEF2A2DFA4A99266C7CEB5241F71CCBD` —— 下载完可用校验工具比对 MD5，对得上说明文件完整。

## 六、界面是英文，看不懂

- 界面语言**以你装上后实际所见为准**：各信息页对「是否支持中文」的说法不一致（有的标注支持多语言，有的明确说没有中文版本），别按任何一篇的说法下结论。
- 应用内如果有语言设置项（一般在 Settings 里的账号或显示相关区域），可以手动切一次看看。
- 只是想看懂网页版内容的话，用带翻译功能的浏览器打开官网，整页自动翻译比等客户端汉化快得多。

## 七、广告太多怎么办

免费版带广告是平台的既定模式，不是异常。想屏蔽广告就开 Core 会员，说明见[免费版与Core会员区别.md](免费版与Core会员区别.md)。**不要为了屏蔽广告去找改版安装包** —— 那类包常被夹带恶意代码，账号风险不划算。

## 八、注册收不到验证邮件

1. 先查垃圾邮件 / 垃圾箱文件夹。
2. 确认用的不是临时邮箱 —— 部分一次性邮箱域名收不到验证信，换常用邮箱重新注册。
3. 换个邮箱服务商试（不同服务商对这家的投递表现不一样）。
4. 都不行就等几分钟再重新触发一次验证邮件，短时间内重复请求可能被限流。

## 九、搜索没有结果

先分清是「搜了没图」还是「图加载不出来」：后者按第二节处理。前者按这个顺序：

1. 换英文关键词、砍词数（搜索靠标签命中，中文词基本不中）；
2. 清掉排序 / 时间段 / 类型筛选 —— 叠加的筛选会把结果清零；
3. 改走浏览（Browse）入口，按分类树或热门标签找 —— 它不依赖搜索框；
4. 都试过还是空的，清一次应用缓存（路径见本篇第一节），缓存里的失效数据会影响结果页。

完整的搜索排查顺序与内容过滤设置在[新手使用指南.md](新手使用指南.md)。

## 十、设置总跳回默认

浏览偏好（敏感内容显示方式这类）是**账号级**设置，最常见的失效原因按序排：

1. **当时没登录** —— 未登录状态下的改动不落盘，切回登录页就还原了。登录状态下改，改完退出重进确认一次。
2. **账号信息不完整** —— 新注册、年龄信息没填全的账号会按更严格的档位执行过滤，看起来就像「设置没生效」。
3. **只改了一处** —— 有的偏好在网页端与应用端各存一份，改了一边另一边还是旧值。

改完仍反复重置的，清缓存 + 重新登录（第一节的路径）再设一次。

## 十一、还是解决不了

把「症状 + 你已经试过的步骤」整理清楚，走官方支持渠道（官网页脚的 Support 入口）提交。比反复卸载重装有效 —— 大部分「修不好」其实是没定位到是网络、缓存还是账号的问题。

排完故障回到[新手使用指南.md](新手使用指南.md)继续逛，或者去[上传作品与版权设置.md](上传作品与版权设置.md)发自己的作品。
