# Google Maps 登录和不登录的区别

> 本篇讲不登录 Google 账号能用到什么程度、登录后多出哪些东西、以及未登录时遇到「受限视图」是怎么回事。

## 一、结论先说

不登录：搜地址、看路线、开车导航，核心功能全都用得了。登录：多出收藏同步、历史记录、评论照片这些「跟账号走」的部分。装完急着用，可以先跳过登录；长期用，建议登录。

## 二、不登录时你能做什么

- 搜地址、搜店名、看地点详情里的地址与营业时间
- 规划路线、切换出行方式、开始驾车导航
- 打开图层看路况、卫星图
- 用 [离线地图下载与更新.md](离线地图下载与更新.md) 存离线地图并导航

代价是所有东西都**不跨设备**：这台手机上搜过的、存过的，换台手机就没了；评论、照片、评分这类社区内容也可能不完整（见第四节）。

## 三、登录后多出来的

点头像 → 添加账号，登录 Google 账号后：

| 功能 | 不登录 | 登录 |
| --- | --- | --- |
| 搜索、路线、导航 | 能 | 能 |
| 收藏地点（家、公司、清单） | 只存本机 | 云同步，换设备还在 |
| 搜索历史与最近去过 | 不留 | 留，可回看 |
| 时间轴（去过哪的记录） | 无 | 有，可在账号设置里管理或关闭 |
| 发评论、传照片 | 不能 | 能 |
| 地点评论与用户照片 | 可能不显示 | 正常显示 |

多账号用户不用退出再登：点头像可以直接在已登录的账号间切换，也可以继续添加。要退出登录，同样在头像菜单里选移除账号——移除只会把账号从这台设备上摘掉，收藏数据还在账号云端。

## 四、未登录时的「受限视图」

2026 年起有用户反馈：不登录时页面进入「受限视图」，评论、用户照片、周边推荐被隐掉，只剩地址、营业时间这类基础信息。有媒体报道过这一变化，Google 方面没有公开说明改动原因，网络环境异常、浏览器扩展干扰也可能触发这类简化页面（有用户反馈登录后恢复正常）。

所以遇到「地图突然变干净了、评论没了」，先点头像登录再看——多半就回来了。

## 五、登录遇到问题

- **登不上**：先确认设备能正常访问 Google 服务，网络本身不通时什么账号都登不进。
- **验证码 / 二次验证收不到**：新设备首次登录常要验证，按提示走恢复流程，别反复重试触发锁定。
- **担心位置记录**：时间轴是账号级功能，不需要就在时间轴设置里关掉或删除记录，位置数据由账号设置统一管理，与登不登录无关的本机缓存可在应用设置里清。
