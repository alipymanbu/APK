# Google Maps 定位不准怎么办

> 本篇讲蓝点偏移、方向反了、圆圈一大圈这些定位问题该从哪查起：权限、系统设置、校准、环境，逐条排除。

## 一、先分清是哪种不准

不同症状对应的原因不一样，先看一眼屏幕再动手：

| 症状 | 更可能是 |
| --- | --- |
| 蓝点整体偏到隔壁街 | 系统没开高精度 / 只用了网络定位 |
| 蓝点周围一大圈浅蓝 | 定位精度低，信号弱或权限没给精确位置 |
| 蓝点不动、灰色 | 位置权限被拒，或系统位置服务没开 |
| 地图朝向与你面朝的方向相反 | 指南针没校准 |
| 导航中提示「GPS 信号丢失」 | 手机所在位置收不到卫星信号 |

## 二、权限先给够

要动的开关都在系统里，不在应用内：

1. 长按 Google Maps 图标 → **应用信息** → **权限** → **位置**，选「仅在使用该应用时允许」或「始终允许」（要后台导航就选始终）。
2. 同一页确认 **使用精确位置** 的开关是打开的——关着时应用只能拿到大致范围，蓝点圆圈会一直很大。
3. 系统总开关也要开：设置 → 位置（有的手机叫「安全和位置」），确认位置服务没被关掉。

之前点过「拒绝」且勾了「不再询问」的，应用里不会弹第二次提示，只能进系统设置改。

## 三、把系统定位精度调高

安卓的「位置」设置里有一项 **Google 位置准确度**（有的手机叫「提高准确度」），打开后系统会同时用 Wi-Fi 和蓝牙扫描辅助定位——室内、高楼间只靠卫星信号时，这两项能把偏差明显拉小。路径：设置 → 位置 → Google 位置准确度 / 提高准确度，把 Wi-Fi 扫描与蓝牙扫描都打开。

还有一招成本最低的：把位置开关**关掉等十秒再打开**，强制系统重置定位，能解决一部分偶发的蓝点漂移。

## 四、方向反了：校准指南针

蓝点射出的光束方向和你实际朝向对不上，是磁力指南针没校准：

1. 打开地图，点蓝点本身。
2. 点弹出的 **校准**。
3. 按提示把手腕画「8」字（横向无穷大符号），直到蓝点光束变窄、指向正确。

带 AR 步行导航的版本会让你把镜头对准街对面的建筑与路牌，按屏幕提示走即可。校准在金属贴膜、磁吸支架附近容易失效——贴了金属隔热膜的车里，手机挪到挡风玻璃无遮挡处再试。

## 五、环境因素先排除

- **室内、地下车库、隧道**：卫星信号被遮挡，只有网络定位，偏几十米是正常表现，出到室外就恢复。
- **行车中反复「GPS 信号丢失」**：把手机挪到挡风玻璃下方、天空视野好的位置；有用户反馈深色金属隔热膜会挡信号，可到车外对比验证是不是膜的问题。
- **系统时间不对**：时间偏差会拖慢定位，顺手核对设置里的时间是否为自动。

## 六、还不准再走这三步

1. 重启手机——最简单也常有效，先做这个。
2. 清应用缓存：设置 → 应用 → Google Maps → 存储 → **清除缓存**（不清数据，收藏和离线地图都还在），详见 [闪退打不开怎么办.md](闪退打不开怎么办.md)。
3. 开了 VPN 或代理的话先关掉：网络定位是按网络出口算的，VPN 会把你的位置顶到出口服务器那里去，看起来像「定位突然到了另一个城市」。

走完上面六节还没解决，大概率是机型的固件问题——同一型号用户反馈集中出现时，等一次系统更新比继续折腾设置管用。
