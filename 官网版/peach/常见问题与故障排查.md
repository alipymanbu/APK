## 一、登录不上

| 现象 | 处理 |
| --- | --- |
| 微博登录点了没反应或报错 | 2.8.4 的更新记录就是「紧急修复微博用户登录问题」，说明这一版对微博登录敏感；先用手机号 + 验证码登录顶上，微博入口稍后再试 |
| 验证码收不到 | 检查信号与骚扰拦截（短信可能被分进拦截箱）；等 60 秒再点重发；双卡设备把默认短信卡切到目标卡 |
| 登录成功但资料是空的 | 多半是登进了另一个账号（微博号绑定的邮箱不同即视为新用户），确认登录方式与上次一致 |
| 提示账号异常 | 走微信服务号「Peach」（inPeach）找官方渠道，不要信私聊里「帮你解封」的人 |
| 充值了宝石没到账 | 按 [宝石充值与消费安全.md](宝石充值与消费安全.md) 第四节的顺序处理，先确认扣款、再找官方反馈 |

## 二、房间里没声音

按这个顺序查，多数在第二步就解决：

1. **麦克风权限**：手机「设置 → 应用 → Peach陪趣 → 权限 → 麦克风」设为允许——对方听不到你看这里；
2. **扬声器/媒体音量**：你听不到别人，先按音量键把「媒体音量」拉上去，再检查是不是误开了静音；
3. **蓝牙耳机抢占**：蓝牙耳机连着但没戴，声音会走耳机通道；断开蓝牙再试；
4. **上麦状态**：派对房里通常要主动点「上麦/开麦」，不上麦就只是听众；
5. 以上都正常还不行，杀掉应用重进，房间连接断了会表现为「单方面没声音」。

## 三、闪退与卡顿

- **重启应用**先来一次，多数偶发闪退到此为止；
- **清缓存不清数据**：手机「设置 → 应用 → Peach陪趣 → 存储 → 清除缓存」。不要手滑点「清除数据」，那会把登录状态和本地记录抹掉；
- **确认安装包完整**：2.8.4 是较早的版本（沿革见 [开发者背景与版本沿革.md](开发者背景与版本沿革.md)），安装包下载不完整也会反复闪退，对一遍 MD5 后重装，见 [下载与安装教程.md](下载与安装教程.md)；
- **卡顿掉线**：语音连麦对上行带宽敏感，切到稳定的 Wi-Fi，或关掉后台大流量应用再试。

## 四、消息与通知收不到

1. 手机「设置 → 应用 → Peach陪趣 → 通知」确认为允许；
2. 国产系统的省电策略会杀后台：把该应用加入「受保护应用/白名单」（各家叫法不同，都在电池或自启动管理里）;
3. 私信、房间邀请只在应用在线时实时送达，离线消息上线后才会补。

## 五、安全上的几条硬线

语音社交场景里这几类套路反复出现，事先记住能省掉大部分麻烦：

- **凡是谈到钱就停**：充值只走应用内或微信服务号「Peach」（inPeach）等官方渠道（细节见 [宝石充值与消费安全.md](宝石充值与消费安全.md)）；任何「客服」让你转账、扫码的都是诈骗；
- **私聊里的「兼职」「刷单」「带你赚」**：与平台无关，是通用诈骗开场，拉黑即可；
- **不给证件照、不给定位**：刚认识的人索要身份证照片、实时位置，直接拒绝；
- **未成年人**：此类陌生人语音社交应用不适合未成年人使用，家长可在手机系统的「健康使用手机/家长控制」里限制安装与使用。

排查不到答案的问题，去 [注册登录与账号管理.md](注册登录与账号管理.md) 看官方联系渠道。
