## 一、注册方式

- **手机号 + 验证码**：这是最基础的一条路，填手机号、收验证码（第三方收录的新手指引提到可能还要设密码），然后补全资料（头像、昵称、性别、生日）。资料里除了手机号都是可选的，但空资料在语音房里不好获得连麦机会。
- **微博登录**：第三方下载站的 2.8.4 版本记录里写着「紧急修复微博用户登录问题」，说明这一版内置了微博登录入口。入口是否仍在、能不能用，以你手里这个版本的实际界面为准。

注册只用手机号就够了，不需要填真实姓名、身份证之类的信息；遇到索要这类信息的一律不给（见 [常见问题与故障排查.md](常见问题与故障排查.md) 的安全一节）。

## 二、登录与换机

- 重新安装或换手机后，用**同一个手机号**走验证码登录，资料和好友关系会跟着账号回来；
- 之前用微博登录的，换机后同样从登录页的微博入口进；
- 收不到验证码先看 [常见问题与故障排查.md](常见问题与故障排查.md) 的对应小节，多数是拦截或信号问题，不是账号没了。

## 三、绑定、充值走哪里

Peach陪趣 有一个官方微信公众号「Peach」（微信号 `inPeach`），其官方简介写明用途是**手机绑定、宝石充值、领取红包**：

| 事项 | 走哪里 |
| --- | --- |
| 手机号绑定 | 应用内设置，或通过微信服务号「Peach」（inPeach） |
| 宝石（应用内虚拟币）充值 | 微信服务号「Peach」（inPeach）或应用内充值入口，以实际界面为准 |
| 红包领取 | 同上 |

充值相关的完整注意（小额试充、不到账处理、未成年人消费）单独成篇，见 [宝石充值与消费安全.md](宝石充值与消费安全.md)。

## 四、注销与隐私

这里要说明实情：截至检索时，公开渠道**查不到** Peach陪趣 对外公开的隐私政策全文，也查不到明确的账号注销步骤，本节因此不编具体流程。能给你的可执行动作是：

1. 在应用内找「设置 → 账号/安全/隐私」一类页面，看有没有注销入口，有就按页面提示走；
2. 没有入口的，通过微信服务号「Peach」（inPeach）联系官方渠道问注销；第三方收录的官方 iOS 版资料页还标注过客服邮箱 `PeachServe@inpeach.com`，可一并尝试（能否收到回复以实际为准）；
3. 不管注不注销，先做这几步止损：手机「设置 → 应用 → Peach陪趣 → 权限」里**逐项关掉麦克风、相机、存储、位置**授权；
4. 确定不再用的，解绑能解绑的（如微博绑定）、清空应用数据后卸载。

语音社交的通话内容和你的声音本身就是敏感信息，和陌生人聊天时同样按「不给住址、不给证件照、不给转账」三条底线来。

## 五、手机号不用了怎么办

换号前先把应用内能改绑的手机号改掉；如果旧号已经注销、收不到验证码，只能靠微信服务号或应用内客服渠道申诉，此时能提供注册时间、充值记录（有宝石充值的话）会好办很多。具体入口以你版本的实际界面为准。
