## 一、先确认你要装的是这个 Peach

用「Peach」当关键词去搜，撞到的一多半是别的产品。截至检索时，同名的至少有三类，认准特征再装：

| 名称 | 主体特征 | 是不是本篇讲的 |
| --- | --- | --- |
| Peach陪趣（应用宝在架名称「Peach陪趣-恋爱交友处CP」） | 开发者为北京凹凸有致科技有限公司，安卓包名 `com.peach.app` | 是 |
| Peach - 這裡藏了一個可愛的你 | App Store 上由个人开发者上架，反馈邮箱指向 `peach-live.com` | 否，是另一款语音直播派对应用 |
| Peach.com 社交应用 / Peach Aviation 日本廉航 | 与语音社交无关 | 否 |

最稳的判别方式是**包名**：安卓平台为 `com.peach.app`，开发者公司名对得上「北京凹凸有致科技有限公司」再装。表里另一款语音社交应用（`peach-live.com` 那个）与它形态相近，但账号、充值互不相通，装错了连不上的不只是人，还有你充进去的钱。

## 二、安装包与版本核对

本篇对应的安装包信息（以网盘内实际文件为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.8.4 |
| 安装包大小 | 约 36.26 MB |
| 包名 | com.peach.app |
| MD5 | 2456FC517768645D1C6C8CF5C91490CF |

下载完成后可以核对一下 MD5，确认文件没下坏：

```powershell
# Windows（在 apk 所在目录执行，文件名以实际为准）
certutil -hashfile peach_v2.8.4.apk MD5
```

```bash
# macOS
md5 peach_v2.8.4.apk
```

版本号相同的安装包，在不同渠道分发时 MD5 也可能不一致，对不上不一定代表文件损坏，能正常安装即可。

## 三、安装步骤

1. 转存并下载 [Peach陪趣 安装文件资源（夸克网盘）](https://pan.quark.cn/s/035ed9e98498)，得到 apk 文件；
2. 点开 apk，安卓 8 以上系统会弹「是否允许此应用安装」，选允许；部分厂商的入口在「设置 → 安全 → 更多安全设置 → 安装未知应用」，按应用单独授权；
3. 装完先不急着冲进房间，首次启动会依次申请**麦克风、存储、通知**权限——语音社交的麦克风权限是必需项，拒绝就连不了麦；
4. 注册或登录后进「广场」挑个派对房试一下说话（玩法见 [语音房间玩法入门.md](语音房间玩法入门.md)）。

## 四、系统要求

- 平台：安卓手机。iOS 版有 2016 年的上架记录（沿革见 [开发者背景与版本沿革.md](开发者背景与版本沿革.md)），但现行是否仍在架未能确认，且 App Store 上能搜到的同名 Peach 是另一款产品（见第一节），苹果用户请先核对开发者再下载；
- 最低系统版本各处口径不一致：有的渠道标注「安卓 5.2 以上」（原文如此，安卓正式版本号并无 5.2），第三方应用市场则标注 Android 4.4.4 以上。以你设备上安装时的实际提示为准。

## 五、装不上时按顺序排查

| 现象 | 先查什么 |
| --- | --- |
| 「解析包出现错误」 | 安装包没下完整，重新下载；确认文件后缀是 `.apk` 没被改名 |
| 「安装失败」或闪退在安装页 | 存储空间不足，至少留出几百 MB；或手机里已有同包名旧版本且签名不一致，先卸载旧版再装 |
| 安装按钮点了没反应 | 手机管家的「未知来源拦截」还开着，按厂商说明放行一次 |
| 装上了但打不开 | 见 [常见问题与故障排查.md](常见问题与故障排查.md) 的闪退一节 |

安装顺利、登录环节卡住的话，直接翻 [注册登录与账号管理.md](注册登录与账号管理.md)。
