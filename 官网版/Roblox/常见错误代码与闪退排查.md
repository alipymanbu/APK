## 一、先做这三步通用排查

Roblox 官方帮助中心对安卓端的建议顺序就是这三条，八成问题到这里就解决了：

1. **重启手机**，然后**强行停止 Roblox** 再重新打开（设置 → 应用 → Roblox → 强行停止）。
2. **检查日期和时间**：设置里打开「自动设置日期和时间」。Roblox 与服务器严格校验时间，时间不对会登录失败、进不去游戏。
3. **换一个网络再试**：从 Wi-Fi 切到热点、或反过来。能排除是当前网络的问题，还是 Roblox 服务本身的问题。

顺带确认两件事：官方服务状态看 [status.roblox.com](https://status.roblox.com)（全站故障时只能等）；App 是不是最新版（旧版本进游戏会直接被拦，见下文错误码 280）。

**先分清是哪一类**：

| 现象 | 大概率原因 | 去哪节 |
| --- | --- | --- |
| 打开 App 就闪退、卡在启动图 | 本地文件/缓存/存储问题 | 第二节 |
| 登录输对了密码也进不去 | 时间、验证、网络 | [账号注册与登录安全.md](账号注册与登录安全.md) |
| 首页能开、点进某个游戏报错 | 连接或版本问题 | 第三节 |
| 能进游戏但很卡、发热 | 性能问题不是故障 | [画质设置与卡顿优化.md](画质设置与卡顿优化.md) |

## 二、闪退、白屏、打不开

按顺序试，每做一步就重开一次 App：

1. **清缓存**：设置 → 应用 → Roblox → 存储 → **清除缓存**。缓存坏了的典型表现是启动图卡死或反复闪退。
2. **清数据**（会登出，先确认记得密码）：同一页面点**清除数据**，App 恢复默认状态。
3. **确认存储空间**：可用空间不足 2 GB 时，加载体验数据中途会失败甚至闪退。
4. **确认系统版本**：Android 低于 8.0 官方不支持，装上也跑不稳（见 [下载与安装教程.md](下载与安装教程.md) 第三节）。
5. **重装**：卸载后重新安装。重装不丢进度——你的资产跟账号走，不在本地；只要记得密码（或已绑邮箱能重置）。
6. 手机开了省电模式会限制 CPU，进游戏前关掉；MIUI/EMUI 类系统还要把 Roblox 加入**电池优化白名单**，否则后台连接会被杀。

## 三、错误代码对照表

官方「报告漏洞 / Roblox 错误代码」栏目收录的常见码，及对应动作：

| 错误码 | 含义 | 你该做什么 |
| --- | --- | --- |
| **279 / ID 17** | 无法连接到游戏（客户端与服务器建不起连接） | 走第一节三步；再清缓存；还不行卸载重装；换网络排除自身网络问题 |
| **266** | 连接已超时，检查网络后重试 | 网络不稳或体验服务器太挤，换网络、稍后重进 |
| **277** | 与游戏服务器的连接已中断 | 同上；频繁出现按第五节排查本地网络 |
| **268** | 客户端异常行为，你已被踢出 | 重启 App；若反复出现，清数据/重装（本地状态损坏） |
| **280** | 你的 Roblox 版本过旧，升级后重试 | 去 Google Play 更新；网盘固定版本包需换新包 |
| **264** | 同一账号在不同设备上登录 | 退出其中一台，再在目标设备登录 |
| **267 / 600** | 被该体验封禁 | 换个体验玩；申诉走该体验页面的举报/联系渠道 |
| **524** | 没有加入此体验的权限 | 该体验设置了进入限制（如好友限定、年龄限定），不是故障 |
| **403** | 访问被拒绝 | 多为地区或风控限制，换个网络环境再试；持续出现记录客服工单 |

不确定的码不要猜：官方错误码列表在 `en.help.roblox.com` 的「报告漏洞」栏目下有逐条页面，按码查最准。

## 四、进游戏时报「设备安全」类提示

有的体验会开启更严的**设备完整性校验**（官方叫 remote attestation），此时你可能看到这几类提示：

- 「此游戏启用了额外的硬件安全要求，请在受支持的设备上运行 Roblox」
- 「Roblox 无法验证应用完整性，请确保操作系统受信任且为最新，然后从官方渠道重新安装」
- 「此场所要求受信任的操作系统」

按官方说明，触发原因与对应处理：

| 原因 | 处理 |
| --- | --- |
| 系统版本旧 | 设置 → 系统 → 软件更新，装到最新 |
| App 来路不正或损坏 | 从 Play Store / 三星应用商店等官方渠道重装 |
| 手机已 Root、刷了第三方 ROM、Bootloader 解锁 | 恢复官方系统并重新锁 Bootloader（高级操作，不熟就换设备） |
| 在安卓模拟器/虚拟机里跑 | 官方按不可信处理——换实体手机 |

两个边界，别白折腾：**不是所有游戏都开这个校验**——过不了时你照样能玩没开校验的其他体验；支持与否由**机型与系统决定**，App 里没有开关。官方列的已知可过机型会随时间变化，以帮助中心当时的名单为准。多数遵循谷歌安全要求的主流新机默认就能过。

## 五、进得去但总断线

- **带宽**：官方最低要求 4~8 Mb/s。移动网络信号弱时优先连 Wi-Fi。
- **VPN/代理**：会干扰客户端与服务器的连接，排查时先关掉再试。
- **路由器**：官方提到 Roblox 用 UDP 49152~65535 端口；家用路由器一般不用动，但公司/校园网可能拦。
- **大体验加载慢**：有的地图首次进入要下载几十秒，不是死机——等一等，或连 Wi-Fi 再进。

## 六、什么时候该找官方客服

走完上面还不行，到 [www.roblox.com/support](https://www.roblox.com/support) 提工单，附上这些信息能大幅加快处理：

- Roblox 用户名
- 完整的错误信息原文（截图或逐字）
- 手机型号、安卓版本、App 版本
- 复现步骤：从哪一步开始出错、之前做过什么改动（更新、换网络、清过数据）

账号本身登不上（密码收不到重置邮件、验证不过）也走这个入口，准备好了注册邮箱与历史充值记录等归属证明，见 [账号注册与登录安全.md](账号注册与登录安全.md)。
