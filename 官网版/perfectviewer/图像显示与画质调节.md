## 一、缩放方式怎么选

Perfect Viewer（本文对应版本 5.0.4.4）的图像缩放提供这几种视图模式，阅读时随时可切：

| 视图模式 | 效果 |
| --- | --- |
| Full size | 按原始尺寸显示，超出屏幕的部分拖动查看 |
| Fit screen | 整页塞进屏幕，可能上下留空 |
| Fit width | 按屏幕宽度撑满，看整页漫画常用 |
| Fit height | 按屏幕高度撑满 |
| Fixed size | 固定你指定的缩放倍数 |
| Stretch | 拉伸铺满，画面比例会变形 |

看整页漫画选 Fit width 或 Fit screen；扫描件页边距大时配合下一节的白边裁剪一起用。

## 二、平滑算法

放大图片时用哪种算法插值，直接决定画面是锐还是糊。应用提供四种：

- **Averaging**（平均）
- **Bilinear**（双线性）
- **Bicubic**（双三次）
- **Lanczos3**

觉得字小发虚、线条肉，就换一种算法对比着看，四种在显示设置里切换，选你眼睛最舒服的那个。这属于典型的「同一部漫画换个滤镜观感差很多」的设置，值得花两分钟试一遍。

## 三、画面调节与白边

- **亮度、对比度、伽马**：三样都能在阅读时直接调，扫描偏灰、偏暗的漫画调对比度立竿见影；
- **自动裁白边**（auto cut off white border）：老扫描件四周有大片留白，开了之后每页自动裁掉白边， Fit width 下画面能大一圈；
- 调过的参数只对当前阅读有效还是全局生效，以你实际操作时界面给出的保存选项为准。

## 四、黑白稿上色（捐赠版功能）

应用支持把黑白图转成 4 色上色图。这个功能**只有捐赠用户可用**：需要单独安装 Perfect Viewer 的捐赠应用（官方说明写明 donated users only）。如果你在免费版里翻不到这个入口，不是设置问题，是版本功能范围。功能细节和获取方式以官方页面为准，本篇不展开。

## 五、放大镜与投屏

- **气泡放大镜（balloon magnifier）**：阅读时呼出放大镜看细节，看小字对话、看图章编号用；
- **Chromecast 投屏**：支持把画面投到 Chromecast 设备上，电视上看图。

## 六、这些设置和阅读模式的关系

缩放、滤镜管的是「一页画得清不清楚」；一次一页还是两页、往左翻还是往右翻，在[阅读模式与翻页设置](阅读模式与翻页设置.md)里调。读 PDF、XPS 这类文档时显示设置同样生效，前提是先按[支持的文件格式清单](支持的文件格式清单.md)把插件装好。改完设置画面异常、闪退的，去[常见问题与解决](常见问题与解决.md)。
