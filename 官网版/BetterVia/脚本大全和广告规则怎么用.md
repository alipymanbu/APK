## 这两个入口解决的是同一类麻烦

Via 本身就能跑用户脚本、能拦截广告，缺的往往不是能力，而是「去哪找脚本、去哪找规则」。模块里的脚本大全和广告规则就是把这步搬到浏览器里：一个给你挑脚本，一个给你补过滤规则。真正执行这些脚本和规则的仍是 Via，模块负责把东西送到它手上。本篇讲这两处怎么用，以及最常见的「装了没反应」怎么一步步排掉。

## 脚本大全

- 入口在模块里，是一个脚本列表页，挑中一个装上即可。
- 装上的脚本会出现在 Via 的脚本列表里：能在 Via 里看到它、临时停用或删掉。
- 脚本只对它头部声明的网址范围生效，访问别的站点时它不参与，这属正常现象。
- 排查页面异常时，停用比删除更好用——停用不会丢脚本，确认无关再恢复。
- 脚本与规则这类资源是联网加载的，模块里可以选 Gitee 源或 GitHub 源；某个源加载不出来时，换另一个再试。

按钮与页面的具体名称会随模块版本调整，以你那一版的实际显示为准。

## 广告规则

- 作用对象是 Via 的广告拦截：模块这里负责下载与更新过滤规则。
- 规则是一份列表，站点页面结构一变，旧规则就可能失效，所以定期更新一次比较省事。
- 某个站点拦得不干净，通常不是模块坏了，而是规则没覆盖到那种广告位。

## 装了没反应，按这个顺序查

1. 这个脚本或规则适不适用当前站点？先确认脚本声明的网址范围包含它。
2. 是不是被别的脚本或规则干扰？把其余脚本先停用，只留这一个再试。
3. 站点是不是在 Via 内置的功能限制名单里？是的话看[白名单限制是怎么回事.md](白名单限制是怎么回事.md)。
4. 打开 Via 的脚本页，确认它处于启用状态，必要时重启一次 Via。
5. 以上都排除，再看[装完不生效或闪退怎么排查.md](装完不生效或闪退怎么排查.md)。

## 装脚本之前该注意什么

- 脚本由社区用户编写，不属于模块自带内容，装之前先看清它要做什么。
- 来源不明的脚本不要装；要求输入账号密码、索要额外权限的，先放一放。
- 只用在自己账号、自己的设备上，并遵守所访问站点的服务协议。
