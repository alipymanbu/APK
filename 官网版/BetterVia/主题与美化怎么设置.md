## 这几组设置分别管什么

模块里跟外观有关的设置集中在三处：主题、莫奈时刻、以及美化与护眼一类的开关。动手前先弄清一件事——这些设置改的是 Via 的界面与网页显示，模块自己只是那个控制面板，关掉模块这些效果就没了。本篇按「换了怎么退回来」的思路讲每一项。

## 一键主题更换

- 在模块的主题页里挑一套现成的，套用即可。
- 换完之后 Via 界面配色与样式随之变化，通常不用重启应用。
- 主题不是一次性操作，不满意随时换回另一套。

## 主题编辑器

想微调而不是整套换，就用编辑器：

1. 先在主题页套一套现成主题，把它当底子。
2. 进编辑器改你想改的那几项，具体的可改项以你装的那一版模块页面为准。
3. 改完保存，回到主题页套用。

不建议一上手就从零改：编辑器里项目多，先套现成的再微调，改坏了也知道原本长什么样。

## 莫奈时刻（莫奈取色）

这一项是外观设置里最需要提前了解的：

- **实现方式是「改包」**。作者在更新记录里说明过，取色功能不容易在模块内部完成，所以改用替换 Via 安装包的方式，官方把它标为实验性功能。
- **副作用要提前知道**：用过之后你手上的 Via 不再是官方原包了。以后要更新 Via，得等模块跟进支持对应版本，或者先装回官方包。
- **可能会遇到 bug**。作者也说过这是实验期功能，按需使用。
- **想还原**：装回官方 Via 安装包即可。

如果你的模块版本较旧、没看到这一项，属正常——它是后续版本才加入的功能。

## 护眼与屏蔽类开关

| 设置项 | 大致作用 |
| --- | --- |
| 护眼模式 | 调整网页显示的亮度、色温一类参数，长时间读页面时降低刺眼感 |
| 屏蔽组件 | 把 Via 界面里你不想看到的组件隐藏掉 |
| 屏蔽菜单栏 | 针对指定站点屏蔽长按菜单；较新版本里是填想要屏蔽的网址 |
| 美化设置 | 界面细节的一组调整项 |

这几项都是开关式的改动，改完在对应页面上就能看到效果；具体某个开关影响的是哪个界面元素，以模块内该页的说明为准。

## 给日志和资源嗅探页面加背景图

模块还能给「看日志、看资源嗅探结果」这类信息页配一张背景图。设置时有两条经验是作者在更新记录里给的：挑与手机屏幕尺寸比例一致的图片，显示出来才不会被拉伸；再把遮罩色度调一调，让压在图片上的文字仍然看得清。

## 改错了怎么退回

- 只是换了主题或点错了开关：回到模块里改回去，或换回默认主题。
- 用过莫奈时刻：装回官方 Via 包；之前的取色效果会随之消失。
- 改完 Via 打不开、或界面错乱到没法操作：按[装完不生效或闪退怎么排查.md](装完不生效或闪退怎么排查.md) 走一遍，必要时先卸载修补包再装官方包。

## 提醒一句

外观相关的设置在模块里属于「随时可改」的部分，改动不涉及账号数据，所以试错成本很低。唯一要当心的是莫奈时刻，它动的是 Via 安装包本身，属于「改之前先想清楚」的那一类。
