## 先看清你装的是什么

BetterVia 是一个给安卓浏览器 Via 用的模块，包名 `com.jiguro.bettervia`，安装包只有 0.39 MB。它本身不提供浏览功能，得先有一个能加载模块的框架、再挂到 Via 上才有作用。本篇给出安装包核对方法，以及有 root、没有 root 两条安装路线。没有 root 的机型请直接看[没有root怎么用LSPatch修补.md](没有root怎么用LSPatch修补.md)。

## 安装前先核对安装包

网盘里那份安装包的事实如下（网上搜到的版本号通常更新，不以此为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.1.0 |
| 包名 | `com.jiguro.bettervia` |
| 安装包大小 | 0.39 MB |
| MD5 | `4B84BB6F6E109B20635BD4C72E0F28A9` |

还没有安装包的话，从本文页头那份 [BetterVia 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7ae8d7f2de04) 取，拿到后先按下面的方式核对一遍。在 Windows 上核对 MD5：

```powershell
Get-FileHash -Algorithm MD5 "你的安装包文件名.apk"
```

算出来的一串与上表一致，说明包是完整的；对不上就重新下载一次。手机端可以用文件管理器查看安装包属性。

顺带说明一点：模块的官方发布渠道是它的 GitHub 仓库、Gitee 仓库和 Xposed 模块仓库，更新比网盘里这份快，所以两者版本号对不上是正常的，不是包出了问题。

## 前提：你的设备走哪条路

| 设备情况 | 需要准备的东西 | 对应章节 |
| --- | --- | --- |
| 已 root（装了 Magisk、KernelSU 之类的 root 方案） | LSPosed 框架 | 有 root 的安装步骤 |
| 没有 root | LSPatch 或其它免 root 框架 | 没有 root 的安装步骤 |

两条路都能用，功能上没有差别，区别只在模块被谁加载。选哪条只看你的设备有没有 root，不用纠结。

还有两个版本前提要先对一下：Via 本体需要 V6.6.0 及以后版本；系统方面，作者说明模块在 Android 10 到 16 上测试通过，安卓版本过低或过高都可能不行。

## 有 root 的安装步骤

1. 确认 LSPosed 已经装好并且能用。LSPosed 本身需要先有 root 方案配合，装法与机型相关，以 LSPosed 官方说明为准。
2. 安装 BetterVia 的安装包。
3. 打开 LSPosed，进「模块」列表，找到 BetterVia 并勾选启用。
4. 进「作用域」，勾上 Via。国内版包名是 `mark.via`，谷歌版是 `mark.via.gp`；如果你用的是改过包名的 Via，勾对应的那一个。
5. 按框架提示重启作用域应用，或者直接重启一次手机。

## 没有 root 的安装步骤（概览）

1. 装一个免 root 框架（LSPatch 或它的衍生版本）。
2. 在框架里对 Via 做修补，选本地模式或便携模式。
3. 卸载手机上原来那份 Via，安装修补出来的包。
4. 回到框架的模块页，启用 BetterVia，并勾上作用域（也就是修补后的 Via）。

修补会换掉 Via 的签名，随之而来的限制与处理办法单独写了一篇，动手前建议先看[没有root怎么用LSPatch修补.md](没有root怎么用LSPatch修补.md)。

## 装完之后的入口在哪

- 模块自己有一个可以独立打开的界面，第一次打开有一段启动动画，所有设置项都在里面。
- 打开 Via，进它的设置页，也能看到 BetterVia 的入口。
- 较新版本带上了模块自己的更新检测：打开 Via 就能看到当前装的模块有没有新版本。

入口的名字和位置会随模块版本调整，以你装的那一版实际显示为准。

## 不想让模块的图标留在桌面上

模块里可以把自己的桌面图标隐藏掉。有两点是作者在答疑里提到过的：一是隐藏前先在 LSPosed 里关掉「强制显示桌面图标」，否则改了不生效；二是部分机型的桌面上仍会留一个图标，点开是应用详情而不是模块界面，这是系统层面的限制，遇到时不用反复折腾。

## 模块提供哪些设置

下面这张表按官方功能列表整理，用来让你知道拿到手之后能改什么：

| 设置项 | 大致作用 |
| --- | --- |
| 一键主题更换 / 主题编辑器 | 换 Via 界面主题，或自己改一套 |
| 莫奈时刻 | 用取色方式改变界面配色 |
| 脚本大全 | 挑用户脚本挂到 Via 上 |
| 广告规则 | 给 Via 的广告拦截补充过滤规则 |
| 白名单限制 | 解除 Via 对部分站点的功能限制 |
| Cookie 管理器 | 按站点查看与清理 Cookie |
| 隐私锁 / 超级隐身 / 截屏防护 | 隐私相关的一组开关 |
| 护眼模式 / 美化设置 / 屏蔽组件 / 屏蔽菜单栏 | 显示与界面相关的一组开关 |
| UA 大全 / 快捷命令 / 视频缩放倍速 / 启动执行 | 浏览与播放相关的一组设置 |

功能会随版本增加，其中莫奈时刻、屏蔽菜单栏、开发者模式日志等是作者在后续更新里陆续加入的，越旧的版本入口越少。具体某一项怎么用，看模块里那一页的说明。

## 想撤掉模块的时候

- 有 root：在 LSPosed 里取消勾选作用域或停用模块即可；不需要了就卸载模块。
- 没有 root：要先卸载修补版 Via，再从官方渠道装回原版，因为修补包的签名与原版对不上，不能直接覆盖安装。

卸载前提醒一句：浏览数据（书签、历史、Cookie）会跟着卸载一起消失，需要的话先用 Via 自带的备份功能导出一份。
