## 先分清三个东西

浏览器标识（UA）是告诉网站「我用的是什么设备、什么浏览器」的一串信息；电脑模式是把这套信息切成桌面浏览器的样子，同时让页面按宽屏排版；模块里的 UA 大全则把常用标识收在一起，还能结合你的机型生成一套。三者服务同一个目的，但入口不同，改错地方最常见的表现就是「改了没反应」。本篇按你实际遇到的情况，反过来讲该动哪一个。

## 三个入口分别在哪

| 你想改的 | 入口 | 说明 |
| --- | --- | --- |
| 浏览器标识 | Via 设置里的浏览器标识 | 有默认与若干预设，也能自定义 |
| 电脑模式 | Via 的菜单里 | 一个开关，切到桌面版排版 |
| UA 大全 | 模块里 | 收录常用标识，可结合机型信息生成一套，再套到 Via 上 |

## 按场景选怎么设

| 你遇到的情况 | 怎么设 |
| --- | --- |
| 页面一直提示「请下载 App 打开」 | 开电脑模式，标识选桌面版 |
| 人机验证反复失败、页面提示连接不安全 | 关掉电脑模式，标识改回默认 |
| 排版错乱、按钮点不动 | 先把标识改回默认 |
| 部分站点（如知乎）正文出现乱码 | 关电脑模式、标识回默认；仍乱的话，该站点可能要求登录后再看 |

「关电脑模式 + 标识改回默认」这两步，是第三方整理的资料里反复提到的处置，也是所有网页显示类问题的第一处置。

## 改完为什么没变化

- 标识和电脑模式影响的是之后加载的页面：改完重新打开一次页面，必要时清一次缓存再看。
- 设置只对当前这个浏览器生效，换设备、换浏览器都不会带过去。

## 什么时候该改回默认

网页打不开、加载异常、排版错乱、验证过不去，这几类问题的第一处置都是改回默认标识再看。默认那一套是站点兼容性最好的，先用它排除「是我自己改坏了」这种可能，再往别处查。

## 这一项能改什么、不能改什么

- 标识和电脑模式只决定「网站以为你是什么设备」，不改变账号权限：你是谁、能看什么，仍然由你的账号状态决定。
- 用桌面版标识去访问只提供桌面版的页面是常见用法；站点若有明确的访问限制，以其规则与所在地规则为准。
