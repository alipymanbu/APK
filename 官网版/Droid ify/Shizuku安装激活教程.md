## 一、先弄清 Shizuku 在这里扮演什么角色

Droid-ify 更新应用时，默认的 Session 安装方式每次都要你在系统弹窗里点一下"安装"。把 Droid-ify 的安装方式切到 Shizuku 后，只要 Shizuku 服务在运行，安装与更新就不再弹确认——这正是"后台自动更新"能完全放手的条件（见[后台自动更新设置](后台自动更新设置.md)第二节）。

Shizuku 本身是另一个开源应用（[官方手册](https://shizuku.rikka.app/guide/setup/)、代码在 GitHub RikkaApps/Shizuku），它给受支持的应用提供一份"ADB 级"的权限。它不是 root，不影响系统完整性，给出去的权限也可以随时在它的"已授权应用"列表里收回。

## 二、三种启动方式，先对号入座

| 你的设备 | 启动方式 | 要不要电脑 |
| --- | --- | --- |
| Android 11 及以上 | 无线调试（手机上独立完成） | 不要 |
| Android 10 及以下 | 电脑 adb 命令启动 | 要 |
| 已 root | Shizuku 里直接启动 | 不要 |

下面主要讲最常用的无线调试方式，全程在手机上完成。

## 三、无线调试激活步骤（Android 11+）

1. **开开发者选项**：设置 → 关于手机 → 连点"版本号"7 次（不同品牌入口略有差异，不确定就搜"你的机型 + 开发者选项"）；
2. **开两个开关**：在开发者选项里打开"USB 调试"和"无线调试"（两个都要开，这是官方手册的要求）；
3. **装 Shizuku**：从 [Google Play](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api) 或 [GitHub Releases](https://github.com/RikkaApps/Shizuku/releases) 安装；
4. **配对（只需一次）**：
   - 打开 Shizuku，点"通过无线调试启动"下的**配对**；
   - 按提示进入系统的"无线调试"页面，选"**使用配对码配对设备**"，屏幕会显示 6 位配对码；
   - 配对码会出现在 Shizuku 的**通知**里，把它输进弹出的输入框，提示配对成功即可；
   - 若收不到带配对码的通知，先去系统设置里把 Shizuku 的通知权限打开；
5. **启动服务**：回到 Shizuku 首页点"启动"，状态变成"Shizuku 正在运行"就成功了。

## 四、关键限制：重启后要重新启动服务

无线调试方式有个系统层面的限制：**手机每次重启后，Shizuku 服务就停了**，需要回到 Shizuku 点一次"启动"才能恢复。这一步不能省——如果你发现 Droid-ify 的静默更新某天忽然又弹确认了，八成是重启后 Shizuku 没再启动。

root 设备可以让 Shizuku 开机自启，没有这个顾虑；普通设备没有正规的自启办法，接受"重启后手动点一下"即可。

## 五、接回 Droid-ify

1. 确认 Shizuku 状态是"正在运行"；
2. 打开 Droid-ify → 设置 → 安装方式，选 **Shizuku**；
3. 首次使用时 Shizuku 会弹授权框，允许 Droid-ify 使用；
4. 之后在 Droid-ify 里装应用、更应用就不再弹系统确认了。

网盘这份 0.6.6 除了 Shizuku 还支持 **Sui**（同一开发思路的提权方案，root 用户以模块形式提供），选择逻辑一样：在安装方式里切换。

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 一直显示"正在搜索配对服务" | 到开发者选项把"无线调试"关掉再打开，回 Shizuku 重试（官方手册给的办法） |
| 收不到配对码通知 | 给 Shizuku 开通知权限；部分系统要在通知分类里单独允许 |
| 输入配对码后立刻失败 | 配对码有时效，重新生成一次再输；确保输入的是当次显示的码 |
| 用几天后 Droid-ify 又开始弹确认 | 手机重启过，Shizuku 服务已停，回 Shizuku 点"启动" |
| Shizuku 运行中但 Droid-ify 报权限错误 | 在 Shizuku 的"已授权应用"里检查 Droid-ify 是否还在授权列表；重新切换一次安装方式 |
| adb 权限受限（个别 ROM） | 该系统限制了无线调试的 adb 权限，官方手册 FAQ 有对应说明，只能换 root 或 Session 方式 |

还有一类问题是 Shizuku 被系统省电策略杀掉：把它加进电池优化白名单，与 Droid-ify 的做法相同（见[后台自动更新设置](后台自动更新设置.md)第一节）。

## 七、安全边界，两句话

- Shizuku 的权限高于普通应用，**只给它信任的应用授权**，不用的及时在授权列表里收回；
- Droid-ify 借它做的事只有"装/卸/更应用"，属于这类工具里的常规用法，不涉及越权操作。
