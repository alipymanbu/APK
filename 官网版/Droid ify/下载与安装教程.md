## 一、装之前先确认三件事

| 事项 | 说明 |
| --- | --- |
| 系统版本 | 网盘里这一版（0.6.6）按采集记录需安卓 5 以上；官方后续的 0.7.x 版本要求 Android 6.0 及以上，以官方页面为准 |
| 安装包大小 | 约 3.98 MB（版本 0.6.6），对存储几乎没有压力 |
| 安装渠道 | 本文安装文件资源（夸克网盘）、[GitHub Releases](https://github.com/Droid-ify/client/releases) 或 [F-Droid 官方源](https://f-droid.org/packages/com.looker.droidify/) |

包名是 `com.looker.droidify`，安装前可在系统安装界面核对，避免装到套壳应用。

## 二、从网盘获取安装包

1. 打开 [Droid-ify 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f8d9cc209836)，转存到自己网盘后下载 APK 文件；
2. 文件名形如 `Droid ify_v0.6.6.apk`，大小约 4 MB；
3. 下载完成后直接点开，系统提示"允许安装未知应用"时，授权给对应的文件管理器或浏览器即可。

> 网上能搜到官方最新版，但版本号常与网盘里这份不是同一个：这版 0.6.6 的包名、体积、MD5 均以本地采集记录为准（MD5：`7E07EAFF4EDB0E0B5ADCB4CFD4A6BAB5`）。

## 三、安装步骤

1. 点开 APK，系统会列出它申请的权限（联网、通知、安装应用等，都和"装应用、同步软件源"这件事直接相关）；
2. 确认后点"安装"，几秒即可完成；
3. 装完先不要急着退，直接进入首次启动流程（见下一节）。

**覆盖安装注意**：如果你手机里已经装过 F-Droid 官方客户端或其他来源签名的 Droid-ify，系统可能报"应用未安装"或签名冲突，这是 Android 的签名机制在起作用，处理办法见[常见问题与故障排查](常见问题与故障排查.md)。

## 四、首次启动：等源同步完

第一次打开 Droid-ify，它会先同步默认软件源的索引（应用目录数据）：

- 顶部或列表页会出现同步状态，等它跑完再搜索、浏览；
- 同步完成后，浏览和搜索在断网时也能用（数据已经缓存在本地）；
- 如果同步一直卡住或报错，先检查网络，再对照[常见问题与故障排查](常见问题与故障排查.md)里的"同步失败"一节。

同步完之后，主界面顶部是三个页签：**探索**（浏览与筛选所有应用，页内还有"所有应用"分类下拉）、**已安装**、**更新**；找具体应用用右上角的放大镜搜索。找应用、装应用、更应用都在这几处完成。

## 五、四种安装方式怎么选

Droid-ify 装其他应用时支持多种"安装器"，在设置里切换：

| 安装方式 | 适合谁 | 前提 |
| --- | --- | --- |
| Session（默认） | 绝大多数人 | 无，Android 系统自带的会话安装 |
| Legacy | 老系统或 Session 报错的机型 | 无 |
| Root | 已 root 的手机 | 授权给 Droid-ify，装应用时不再逐个弹窗 |
| Shizuku | 未 root 但会折腾的手机 | 需先装好并激活，步骤见[Shizuku安装激活教程](Shizuku安装激活教程.md) |

普通用户保持默认 Session 就行；Root/Shizuku 的价值是"静默安装"，配合自动更新时省掉每次确认，配置细节见[后台自动更新设置](后台自动更新设置.md)。

## 六、装完之后建议做的三件事

1. **加软件源**：默认源之外（如 IzzyOnDroid）按需添加，步骤见[自定义软件源添加教程](自定义软件源添加教程.md)；
2. **开自动更新**：默认它只在打开时检查更新，想要后台自动更，看[后台自动更新设置](后台自动更新设置.md)；
3. **核对版本信息**：侧栏或设置里能看到当前版本号，网盘这版是 0.6.6；官方更新到 0.7.x 后界面与功能有变化，差异见[与F-Droid官方客户端的区别](与F-Droid官方客户端的区别.md)。
