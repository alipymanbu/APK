## 一、安装 Droid-ify 本身时报"应用未安装"

最常见的原因是**签名冲突**：手机里已经有一个包名相同（`com.looker.droidify`）但来自不同渠道、签名不一样的版本，比如此前装过 F-Droid 源构建的 Droid-ify 或 GitHub Releases 的包。

处理办法二选一：

- **卸载旧版再装**：Droid-ify 只是"应用商店"，卸载它不影响你装过的其他应用；损失的是它自己的设置（软件源列表、偏好），重装后要重新加源；
- **保持渠道一致**：认准一个渠道更新（网盘这版 0.6.6、F-Droid 源、或 GitHub Releases 三选一），以后升级也从同一渠道拿包。

普通应用之间也有同样的机制问题：**在 Droid-ify 里更新某个应用时报签名冲突**，说明这个应用当初不是从 F-Droid 体系的包装的，两边签名对不上，只能卸载重装成源里的版本——重装前先确认应用数据有备份。

## 二、源同步失败 / 一直转圈

按顺序查：

1. **网络本身**：换个网络（Wi-Fi ↔ 流量）再手动同步一次；
2. **系统时间**：手机日期时间不准会导致 HTTPS 证书校验失败，同步必报错——确认时间设为自动获取；
3. **源地址**：手输的地址多一个斜杠、少一段路径都不行，对照[自定义软件源添加教程](自定义软件源添加教程.md)第二节逐字核对；
4. **源本身临时不可用**：大源偶有维护窗口，过几小时再试；
5. 新版 Droid-ify 支持复制同步错误的详细信息反馈，报错文案里带状态码的直接对照说明看（0.6.6 没有这项，只能看到失败结果）。

## 三、应用下载到一半失败或卡住

- 先下拉刷新重试一次，多数是网络抖动；
- 换网络后重试（某些网络对源服务器不友好）；
- 检查存储空间——安装包虽小，下载和解压也要余量；
- 反复失败的应用换个源里的版本试试（同一个应用常在多个源上架，见[自定义软件源添加教程](自定义软件源添加教程.md)第二节末尾）。

## 四、图标和截图加载不出来

应用列表的图标、详情页截图来自源服务器，首次显示需要在线拉取。有用户反馈过部分网络环境下批量图标加载失败的情况；官方在后续版本里调整过图标/截图的加载链路。碰到时：稍后重试，或换网络；**已缓存下来的部分不受影响**，浏览与搜索功能本身可用（同步过索引之后 Droid-ify 离线也能查）。

## 五、扫码添加源没反应

1. 确认已授权**相机**权限（系统设置 → 应用 → Droid-ify → 权限）；
2. 二维码要完整入框、光线充足；
3. 扫码功能在不同版本间修过几次问题，个别版本扫不出就退回**手输地址**（见[自定义软件源添加教程](自定义软件源添加教程.md)第二节），功能不受影响。

## 六、装应用时报安装器错误

| 现象 | 原因与处理 |
| --- | --- |
| Session 方式弹不出安装界面 | 部分 ROM 限制"未知应用安装"，到系统设置里给 Droid-ify 授予"安装未知应用"权限 |
| Shizuku 方式报错 | Shizuku 服务没在运行——先用无线调试或 ADB 把 Shizuku 激活再重试，步骤见[Shizuku安装激活教程](Shizuku安装激活教程.md) |
| Root 方式没反应 | 在授权管理（Magisk/KernelSU 等）里把 Droid-ify 加进授权名单 |
| 装到一半提示不兼容 | 该应用要求的安卓版本或处理器架构（ABI）与手机不符，这是应用本身的要求，换旧版本或放弃 |

安装方式的切换入口与四种方式的差异，见[下载与安装教程](下载与安装教程.md)第五节。

## 七、更新列表里同一个应用出现两条

同一个应用在多个启用的源里都有收录时会出现两个条目，各自跟随自己的源更新。选留一个源（一般留应用官方指定或你更信任的那个），把另一个源停用即可，操作见[自定义软件源添加教程](自定义软件源添加教程.md)第二节末尾。停源不影响已装应用本身。

## 八、卸载 Droid-ify 会怎样

- 它装过的应用**原样保留**，数据不动（应用是你装在你手机上的，跟商店卸载无关）；
- 失去的只是 Droid-ify 自己的设置与缓存（源列表、下载缓存）；
- 想彻底清掉某个应用，用系统设置或 Droid-ify 里该应用的卸载按钮都行。
