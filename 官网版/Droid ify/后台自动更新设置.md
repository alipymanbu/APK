## 一、自动更新要开的开关

后台自动更新是 Droid-ify 的核心功能之一，但默认配置下它多半只在你打开应用时才检查更新。想要"后台自己更"，把这几处配齐：

1. **应用内**：设置里打开自动更新相关开关（不同版本叫法略有差异，认准 Update / 自动更新字样），可选只更已装应用或全部源内应用；
2. **系统侧**：设置页里点"忽略电池优化"时系统会弹授权，**允许**它——国产 ROM 的省电策略经常把后台任务直接掐掉，这是"自动更新不动"的头号原因；
3. **通知**：保留它的通知权限，更新进度和结果都走通知，关掉后你以为它没干活，其实是被系统静音了。

配完可以做个验证：在已安装列表里留一个已知有新版本的应用，锁屏放一晚，第二天看它有没有自己变新。

## 二、安装方式决定"要不要你点确认"

自动更新只是把"发现新版本 → 下载"这一段自动化了，**装**这一步是否需要你点一下，取决于安装方式：

| 安装方式 | 更新时的体验 |
| --- | --- |
| Session / Legacy（默认） | 每个更新弹一次系统安装确认，你点一下才装 |
| Root | 静默安装，不弹确认 |
| Shizuku | 静默安装，不弹确认（前提是 Shizuku 在运行） |

也就是说：**纯免确认的全自动，只有 Root 或 Shizuku 两种方式能做到**。普通用户如果不想 root，Shizuku 是折中方案——Android 11 以上在手机上就能激活，不需要电脑，完整步骤见[Shizuku安装激活教程](Shizuku安装激活教程.md)；方式切换在设置里完成，各方式的适用场景见[下载与安装教程](下载与安装教程.md)第五节。

## 三、它需要哪些后台权限，各干什么

从它的权限申请就能看出后台更新的运作方式，都是"自动更新"直接相关的：

| 权限 | 用来干什么 |
| --- | --- |
| 后台数据同步（前台服务） | 后台下载更新包 |
| 开机自启 | 重启手机后继续负责自动更新 |
| 忽略电池优化 | 防止省电策略中断后台任务 |
| 更新无需用户操作 | 对它自己装的应用做静默升级（配合系统支持） |
| 查看所有应用 | 找出哪些已装应用有新版本 |

这条链上任何一环被系统关掉，表现都是"明明开了自动更新却一直不动"，按第三节排查。

## 四、自动更新不动的排查顺序

1. **看通知栏**：有没有同步/下载中的通知？没有说明后台任务没跑起来；
2. **查电池优化**：系统设置里确认 Droid-ify 在电池优化白名单里（部分 ROM 要在"自启动管理"里再放行一次）；
3. **查安装方式**：更新卡在"等待确认"，是因为 Session 方式每次都要你点——这是正常的，不是故障；
4. **查源同步**：更新列表是空的，先手动下拉刷新看源同步是否报错，源的问题见[自定义软件源添加教程](自定义软件源添加教程.md)第五节；
5. 还不行，对照[常见问题与故障排查](常见问题与故障排查.md)逐项过。

## 五、两个值得知道的行为

- **它自己也能被更新**：通过 F-Droid 源安装的 Droid-ify，会出现在自己的更新列表里；从网盘/GitHub 装的这份则要靠你手动回来拿新包（[Droid-ify 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f8d9cc209836)）；
- **版本差异**：0.7.x 新增了"装完删安装包"等开关，网盘这份 0.6.6 没有；功能差异的完整对照见[与F-Droid官方客户端的区别](与F-Droid官方客户端的区别.md)。
