# Goondori 桌面小部件与头像设置

> 本篇讲两件让 goondori 顺手起来的事：把倒计时放到桌面小部件上随时看，以及给每个对象换上你想要的照片。

小部件是 goondori 高频使用的入口——官方为它做了多种尺寸，还支持调透明度；头像则决定主页和卡片上显示的是谁。

## 一、添加桌面小部件

1. 在手机桌面**长按空白处**，弹出菜单里选**「小部件 / 窗口小工具」**；
2. 在列表里找到 Goondori；
3. 挑一个尺寸与样式（韩区用户教程提到过 **4 种样式**，各版本可能增减；大的能看到军衔与百分比，小的基本只有 D-Day）；
4. 拖到桌面合适位置，松手即添加。

添加后小部件的数据与应用主体同步，打开应用改了日期，桌面上的数字会跟着变。个别机型出现过小部件不刷新的反馈，此时把小部件删掉重新添加一次，多数能恢复。

## 二、调整小部件透明度

透明度在应用的设置里调：

1. 打开 goondori，进入设置相关菜单；
2. 找到**小部件透明度**选项，拖动调节；
3. 调完回到桌面看效果，不满意再回来改。

透明度调太低会跟壁纸混在一起看不清数字，建议先调到一半左右再微调；官方也提示这个参数就是为了「不影响桌面美观的同时看清军衔与倒计时」。

## 三、给对象设置头像/照片

1. 打开侧边菜单 → **「编辑及追加」**；
2. 选中要改的对象，点**「改变头像」**；
3. 从相册选图并确认，主页与桌面卡片随之更新。

给爱豆、男朋友、家人各自配一张照片，多人登记时一眼就能分清是谁。首次选图时系统会申请**「照片和视频」**权限，这是官方标注的可选权限，拒绝后就选不了图。

## 四、头像换不了，按这个顺序排查

| 可能原因 | 判断方法 | 处理 |
| --- | --- | --- |
| 图片格式不支持 | 文件是不是非常见的 jpg/png 之外格式（如动图、特殊编码） | 转成 jpg 再选 |
| 图片过大 | 几十兆的原片、超长截图 | 裁剪或压缩后再选 |
| 网络不佳 | 换 Wi-Fi / 流量对比 | 切网络后重试 |
| 应用状态异常 | 换图、换网络都不行 | 卸载重装后重新登录再试 |

有用户反馈过「换不了头像」，实测多数落在格式与体积这两格。重装是最后一招，做之前确认账号能正常登录，否则数据接不回来。

## 五、其他外观项

- **主题**：官方商店页提到可更换主题（较新版本的功能，旧版设置里没有属正常）；
- **照片的其他用途**：「照片和视频」权限的说明里还包括发帖配图与信件装饰，社区相关用法见 [应援与社区功能说明.md](应援与社区功能说明.md)。

设置都收拾利落后，日常基本可以只看桌面小部件；偶尔进应用改日期或刷社区。遇到读数、登录之类的问题，先翻 [常见问题与解决办法.md](常见问题与解决办法.md)。
