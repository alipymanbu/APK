goondori 的主功能是退伍日计算器（전역일계산기）：输入入伍日期与兵种后，界面实时给出 D-Day、服役百分比和军衔进度，你自己、亲友、爱豆都可以登记。

## 一、添加第一个服役对象

1. 打开侧边菜单（左上角三条杠），点最上方的**「编辑及追加」**；
2. 点右上角的 **+** 号进入编辑页；
3. 依次填写：头像（可选）、姓名、**入伍日期**、**兵种**；
4. 填完入伍日期与兵种后，退伍日期会按韩国兵役制度自动算出来；
5. 保存，回到主页就能看到这个对象的倒计时卡片。

入伍日期填错影响最大——退伍日是从它推算的，先核对清楚再保存。

## 二、主界面每个数字是什么意思

| 界面元素 | 含义 |
| --- | --- |
| D-Day | 距离退伍还剩多少天（或已服役天数，取决于显示位置） |
| 百分比 | 服役进度，实时变化，不用刷新 |
| 军衔 | 按服役时长对应的现行军衔（韩国兵役按时间自动晋衔） |
| 下一军衔进度 | 距离晋升到下一个军衔/薪级还剩多少天 |

百分比和 D-Day 是同一进度的两种表达：百分比涨了，倒计时就减了。官方称主页能看到「实时变化的军生活量表」，指的就是这块。

## 三、手动调整退伍与晋升日期

自动推算不一定贴合每个人的实际情况（提前退伍、延长服役、兵种变更都会造成偏差）：

1. 进入该对象的编辑页；
2. 直接修改**退伍日期**或**晋升日期**；
3. 保存后主界面的所有读数按新日期重新计算。

遇到「缩短服役」这类特殊情况，就是靠手动改退伍日期来对齐的；改完建议记一笔实际依据，免得之后自己都对不上。为什么自动算出来的日期会跟实际不一致、各兵种法定服役期多久，[退伍日期计算规则.md](退伍日期计算规则.md) 里有一整篇。

## 四、同时登记多人

- 可以登记多个对象，一张主页集中管理；
- 数量上限各版本不同：早期版本为 **8 人**，较新版本放宽到 **12 人**，以你手上版本实际为准；
- 每个对象独立一份头像、日期与军衔进度，互不影响。

追多个团、或者既追爱豆又记亲友服役的，直接挨个添加就行。

## 五、断网了还能看吗

可以。4.4.8 版本起官方加入离线支持：**已加载过的页面断网也能打开，登录状态保持有效**。倒计时的天数靠本地日期推算，断网不影响数字跳动；但社区、应援这类需要联网的部分离线时不可用。

## 六、通知与其他板块

倒计时之外，应用里还有这些板块，用不用看你自己的需求：

- **通知**：晋级、服役纪念日、社区与活动提醒，走「通知」这一可选权限；
- **部队菜单表（식단표）**：按部队查每天的伙食，服役者本人用得多；
- **休假管理（휴가관리）**：把假期安排跟剩余天数放在一起看；
- **军人优惠（혜택）**：官方聚合的折扣与福利信息；
- **鼓励弹窗**：官方称会按剩余天数考虑服役者心理，在合适的时间点弹出打气内容。

其中菜单表、休假、优惠这几块在较新版本的官方介绍里出现得更多，你手上 4.8.2 有没有对应入口、名字叫什么，以应用内菜单实际显示为准。

## 七、版本差异，先对一眼再找功能

网盘里这份是 4.8.2。官方此后的版本陆续加入过这些内容，旧版上找不到别怀疑自己：

| 版本 | 变化 |
| --- | --- |
| 4.8.2 | 服役计算器新设计，信息更丰富（本文对应版本） |
| 5.1.0 | 新增 Content 板块（军营生活信息与资讯） |
| 5.4.0 | 会员体系升级，加入身份验证 |
| 5.6.0 | 名人档案下载等应援相关改进 |

再往后官方可能还有更新，以 [goondori.com](https://goondori.com/) 与应用商店的更新说明为准。界面找不到某功能时，先到 [常见问题与解决办法.md](常见问题与解决办法.md) 对一遍版本差异；主界面之外的玩法（小部件、换头像）在 [桌面小部件与头像设置.md](桌面小部件与头像设置.md)。
