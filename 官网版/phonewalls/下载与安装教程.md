PhoneWalls 是 YTECHB 团队 2020 年底上线的安卓壁纸应用，收录各手机品牌的原厂壁纸，以及 4K 静态图和动态壁纸，应用本体只有几 MB。本篇按「核对文件 → 转存下载 → 安装 → 首次打开」的顺序走一遍，全程在手机上就能完成。

## 一、安装前核对文件信息

本文使用的安装文件本地核对信息如下：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.7.90 |
| 包名 | com.phonewalls.stockwallpapers |
| 大小 | 8.20 MB |
| MD5 | 1D1C49D026388F25FAB6D55264751555 |
| 系统要求 | 安卓 5.2 及以上（本地安装包记录，以安装时手机提示为准） |
| 记录日期 | 2026-09-23 |

两点说明：

- **包名是判断「是不是同一个应用」的可靠依据**。在其他渠道看到同名应用时，核对包名是否为 `com.phonewalls.stockwallpapers` 即可；
- **版本号以你手里这份为准**。PhoneWalls 更新较勤，官方商店里的版本随时在变，界面细节可能与本套文档的描述略有出入。

装之前想先弄清楚它要什么权限、数据怎么处理，看 [权限与隐私说明.md](权限与隐私说明.md)。

## 二、把安装文件拿到手机

**PhoneWalls 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/f1d1262c0966](https://pan.quark.cn/s/f1d1262c0966)

1. 用浏览器或夸克网盘 App 打开上面的链接；
2. 登录后先把文件「转存」到自己的网盘空间；
3. 在自己的网盘里找到 APK 文件，下载到手机本地存储。

手机流量紧张的话，也可以先在电脑上完成转存和下载，再用数据线或局域网传输把 APK 送进手机。

## 三、安装步骤

1. 在文件管理器里找到下载好的 APK，点它；
2. 系统提示「未知来源应用」时，选「仍要安装 / 允许此次安装」继续。部分手机会跳到设置页，要你给「文件管理器」开「允许安装未知应用」权限，开完返回再点一次 APK；
3. 等安装完成，点「打开」。

## 四、首次打开

- 内容需要联网加载，第一次打开请保持网络通畅，等列表刷出来再操作；
- 列表里看到的是压缩缩略图，偏模糊是正常的，点进单张壁纸才是完整分辨率；
- 一直转圈或空白页，按 [常见问题排查.md](常见问题排查.md) 第一节处理。
