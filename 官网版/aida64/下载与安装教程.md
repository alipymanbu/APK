## 一、AIDA64 是什么

AIDA64 是 FinalWire Ltd 出品的硬件与系统信息工具，2015 年 3 月推出安卓版，同一套产品线还有 Windows 上的 AIDA64 Extreme 等桌面版本。你装到手机上后，它把处理器、屏幕、电池、传感器、系统版本这些平时看不到的参数逐页列出来，还支持手机、平板、电视盒子和安卓手表。Google Play 上它是免费应用（含广告与内购），本文对应的是可离线安装的 APK 包。

典型使用场景就三类：买二手机核对配置是否与卖家说的一致、排查「手机是不是降频/虚标」这类问题、以及单纯想看清自己设备的硬件底细。装好之后先看 [各页面参数怎么看.md](各页面参数怎么看.md) 了解每个分区该读什么。

| 项目 | 要求 |
| --- | --- |
| 系统下限（官方页面标注） | Android 4.4 及以上 |
| 系统下限（本安装包登记） | 安卓 5.2 以上 |
| 存储占用 | 安装包 10.05M，安装后占用也很小 |

两处下限不一致时，以你的设备实际能否安装成功为准：低于包内声明的版本，系统会在安装时直接拦下来。

## 四、安装步骤

1. 把 APK 从网盘下载到手机存储（用系统自带的「文件管理」打开下载目录即可）。
2. 点击 APK 文件，系统会弹出「安装未知应用」拦截 —— 这是安卓对侧载安装的默认限制，不是病毒报警。
3. 按提示给浏览器或文件管理器授予「允许安装此应用」，返回继续安装。
4. 装完打开，首屏就是分区列表，无需注册、无需联网也能读取大部分硬件参数。
5. 想把界面改成中文，按 [中文设置与主题切换.md](中文设置与主题切换.md) 里的步骤点三下就行。

部分厂商系统（MIUI、ColorOS 等）还会额外弹一次「纯净模式」或安全确认，选继续安装即可；若安装按钮始终置灰，见 [常见问题与排查.md](常见问题与排查.md)。

## 五、它申请的四个权限是干什么的

官方在应用说明里逐条解释过每个权限的用途，装之前可以先放心：

| 权限 | 用途 |
| --- | --- |
| `ACCESS_NETWORK_STATE` | 读取网络连接状态，显示在「网络」页 |
| `ACCESS_WIFI_STATE` | 读取 Wi-Fi 信号强度与 SSID，Wi-Fi 信息页要用 |
| `INTERNET` | 应用本身不靠它上传数据，Google Play 的数据安全声明写明「不收集、不共享数据」 |
| `CAMERA` | 只读取相机硬件参数（分辨率、支持的模式），AIDA64 不会拍照或录像 |

除这四项外它不申请存储、通讯录、位置等敏感权限，**也不需要 root** —— 全程不会弹超级用户授权，具体见 [常见问题与排查.md](常见问题与排查.md)。装完想进一步了解每个参数的含义，直接接着看 [各页面参数怎么看.md](各页面参数怎么看.md)。
