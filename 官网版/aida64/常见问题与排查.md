## 一、安装环节

### 点击 APK 提示「禁止安装未知应用」

安卓对非应用商店渠道的安装一律先拦一道。给弹窗里指定的来源（浏览器或文件管理器）打开「允许安装此应用」，返回继续装即可。这不是病毒报警；真担心包本身有问题，核对 [下载与安装教程.md](下载与安装教程.md) 里列出的包名与 MD5。

### 安装按钮置灰 / 提示「未安装应用」

三个常见原因：系统版本低于包内声明的下限（这份包登记的是安卓 5.2 以上）、手机存储空间不足、或厂商安全中心（纯净模式、支付保护之类）在后台拦截。清理空间、在安全中心里放行后重试；系统版本过低则无法安装，只能换设备。

### 装完打开闪退

2.07 版官方修复过一个「启动崩溃」问题，如果你手里的包是更早版本，优先换成 2.07；已是 2.07 却仍闪退，先重启手机再打开，还不行就重新从网盘转存一次并核对 MD5，排除下载环节把文件弄坏的可能。

## 二、读数类：这些「不准」是官方明确过的

官方在应用说明的 Known issues 一节写清了四条已知误差，遇到时先对照这里，别急着判定手机有毛病：

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 屏幕对角线尺寸算出来不对 | 厂商把错误的 xdpi/ydpi 写进了设备配置 | 尺寸一栏别信，以分辨率与实测为准；可在应用的 About 页提交设备报告，官方会在后续版本修正 |
| 相机参数与实际不符 | 同上，厂商写错了相机能力值 | 以相机实际拍出来的分辨率为准 |
| 电池容量显示的不是换装后的大容量 | 系统读不到出厂值以外的电池信息 | 容量只反映设计值；换过电池的机器看充电循环次数与实际续航综合判断 |
| 充放电速率显示异常 | 设备没正确支持 Android 5.0 引入的新电池 API | 属设备兼容问题，非故障；换页再进、升级系统后复测 |

这几条在验机场景里尤其重要 —— [二手机验机实操.md](二手机验机实操.md) 里让电池、屏幕两项「留个心眼」，依据就是它们。

## 三、界面与功能类

### 打开是英文 / 想换语言

右上角菜单 → 设置 → 第一项「语言」，选中文简体即可，完整步骤见 [中文设置与主题切换.md](中文设置与主题切换.md)。

### 数值一直在跳

CPU 频率、GPU 频率、电池温度、传感器读数都是实时量，随负载与姿态每秒变化，属于正常刷新而不是故障。真正该稳定字段（型号、版本、总量）如果也在跳，那才是异常，见 [各页面参数怎么看.md](各页面参数怎么看.md) 对页面性质的划分。

### 部分分区条目比别人少

分区列表的条目数随设备类型（手机/平板/电视/手表）与硬件配置变化，手表上看到的条目天然比手机少。缺的多半是这台设备本来就没有的硬件，不是软件没装好。

### 某个传感器没有读数

先确认该传感器在这台机器上是否存在（低端机可能根本没有陀螺仪）；存在却无读数或数值卡死，多半是硬件损坏或拆修后没接好，结合 [二手机验机实操.md](二手机验机实操.md) 的传感器检查流程判断。

## 四、还不确定怎么办

把出问题页面的截图连同设备型号一起，通过应用内 About 页的报告功能发给官方 —— 屏幕尺寸、相机参数这类读错的情况，官方明确过会依据用户提交的设备报告在后续版本修正。提交前可先把报告保存到本地（方法见 [中文设置与主题切换.md](中文设置与主题切换.md)），自己留一份底。
