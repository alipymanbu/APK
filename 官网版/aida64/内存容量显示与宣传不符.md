# 内存容量显示与宣传不符怎么回事

> AIDA64 读出的 RAM、存储与包装宣传对不上时的四种原因，以及逐步分辨的办法。

## 一、先分清两个数字：标称总量 vs 当前可用

手机「关于手机」和宣传页写的是**标称总量**（器件规格），而系统开机就占掉一部分 —— 华为官方客服的解释是：系统与常驻应用运行时一直在占用内存，所以实际可用值必然小于宣称值；存储同理，固件与系统预留也吃掉一块。AIDA64 系统页显示的是**物理总量**，你在设置里看到的「可用」是扣掉占用后的余量，两个数字本来就不该相等。判断标准：**总量对得上标称，可用小于总量，就是正常**。

## 二、宣传里的「+8GB」是虚拟内存，不在物理总量里

近两年的宣传话术是「12GB + 8GB」这种写法：加号后面的部分是**内存扩展**（各厂叫法不同：扩展内存、RAM Plus、Memory Extension），拿存储空间模拟出来的虚拟内存，不是插在主板上的物理颗粒。它的作用是让后台应用少被杀掉，代价是占一部分存储。所以你在 AIDA64 里读到物理 RAM 是 12GB 而宣传页写着 20GB 时，差值就是扩展部分 —— 看物理配置一律以 AIDA64 系统页的总量为准，宣传里的「+N」不计入硬件规格。

分辨方法就一条：宣传页如果出现「+」号或「扩展」字样，那个数不进物理总量；没有扩展字样却对不上，继续往下排查。

## 三、盒子与虚标机：数字整个是假的

低价电视盒子、山寨机是重灾区。AIDA64 官方论坛上有用户反馈过典型样本：包装标 4GB 内存 + 64GB 存储的盒子，AIDA64 读出来只有 2GB + 16GB，而系统自带的「关于手机」页仍显示 4GB/64GB —— 也就是说系统信息页的数值可以被厂商写死，未必反映真实器件。（单一用户案例，具体到你自己的机器要综合判断。）

结合这类实例，虚标机的识别可以看三处交叉：

1. AIDA64 系统页的物理 RAM 与存储总量 —— 与包装宣传差一半级别，基本坐实；
2. 系统「关于手机」页与 AIDA64 的数字是否一致 —— 一致但都远低于宣传，说明整机参数都按宣传值伪造；
3. 实际可用空间与安装几个应用后的余量 —— 真 64GB 与虚 16GB 用两天就见分晓。

完整核对流程见 [二手机验机实操.md](二手机验机实操.md)。

## 四、逐条排查清单

按顺序过，命中即停：

1. **宣传写「N+M」** → 差值是虚拟内存，正常，见第二节；
2. **可用远小于总量、总量对得上宣传** → 系统占用，正常，见第一节；
3. **总量明显低于宣传且无扩展字样** → 先查该机型官方规格页确认宣传口径，再对照第三节判断是否虚标；
4. **AIDA64 数字与系统页不一致** → 记下两组数值，结合实际可用空间与应用安装余量综合判断，必要时用多个信息工具交叉读（读数含义的划分见 [各页面参数怎么看.md](各页面参数怎么看.md)）。

存储侧的「已用/剩余」口径差异也按同一套清单处理；对数值性质有疑问时，[常见问题与排查.md](常见问题与排查.md) 里汇总了官方明确过的各类读数误差。
