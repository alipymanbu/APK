## 一、先建立读法：分区数量不固定

打开 AIDA64，你看到的是一列可点的分区入口，但**分区数量会随设备类型变化** —— 手机、平板、电视盒子、手表显示的条目不尽相同，一般在十几个上下。所有页面都是同一套读法：左侧是字段名，右侧是数值，数据基本是实时刷新的（CPU 频率、电池温度这类会每秒跳动）。下面按最常见的几页说明各自该看什么。

## 二、核心分区速查表

| 分区 | 回答什么问题 | 重点看这几项 |
| --- | --- | --- |
| 系统（System） | 这台机器是谁造的、叫什么 | 制造商、型号、设备类型、RAM 总量 |
| 中央处理器（CPU） | 真实的芯片是什么 | SoC 型号、核心数、架构、各核实时频率 |
| 显示（Display） | 屏幕和 GPU 的底细 | 分辨率、像素密度、GPU 型号 |
| 网络（Network） | 联网走的哪条路 | Wi-Fi SSID 与信号强度、移动网络类型、本机 IP |
| 电池（Battery） | 电池现在什么状态 | 电量、温度、电压、状态（充电/放电）、充电循环次数 |
| Android | 系统软件层面的信息 | Android 版本、安全补丁级别、内核版本 |
| 设备（Devices） | 外设硬件的能力 | 相机分辨率、Vulkan / OpenCL 设备清单 |
| 温度（Thermal） | 机身发热读数 | 温度来源与实时数值 |
| 传感器（Sensors） | 传感器齐不齐、活不活 | 加速度计、陀螺仪、磁力计的实时数值在不在变 |
| 应用（Applications） | 装了哪些 app | 包名、版本、占用 |
| 编解码器（Codecs） | 视频能硬解什么 | 支持的音视频编解码格式清单 |
| 目录 / 系统文件 | 文件都在哪 | 系统目录结构与关键文件路径 |

## 三、三个最常被问到的页面

### CPU 页：型号比频率重要

你会看到每个核心的实时频率在不停变 —— 这是正常的，安卓按负载动态调频，空闲时降频不代表降级。真正用来确认「这台机器用的什么芯片」的是 SoC 型号一行，再往下核对核心数与架构（如 `ARMv8` / `ARMv9`）。买二手机时这一页是重点证据，具体核对流程见 [二手机验机实操.md](二手机验机实操.md)。

### 电池页：容量和循环次数不是一回事

电量、温度、电压、充放电状态都是实时值，随手看就行。容量（Capacity）一栏显示的是**出厂设计容量** —— 官方明确说过，电池被换成第三方更大容量的型号后，系统和 AIDA64 都读不到新容量，你看到的仍是出厂值。从 2.03 版起这一页还多了充电循环次数，能反映电池被充过多少次。容量为什么可能对不上、充放电率为什么会失真，见 [常见问题与排查.md](常见问题与排查.md)。

### 传感器页：看数值动不动

这一页把手机里的传感器逐个列出并实时打印读数 —— 加速度计、陀螺仪、磁力计、光线/距离传感器等。判断一个传感器好不好使，就看它有没有条目、晃动手机时数值变不变。默认采样频率可以在设置里调（见 [中文设置与主题切换.md](中文设置与主题切换.md)）。

## 四、哪些数值可以直接信，哪些要留个心眼

- **基本可以直接信**：SoC 型号、核心数、Android 版本、内核版本、RAM 总量、Wi-Fi 信息、已装应用清单 —— 这些来自系统接口，与设备真实配置一致。
- **通常可信但有例外**：屏幕尺寸（对角线英寸）、相机参数 —— 官方在应用说明里承认，部分厂商把 xdpi/ydpi 或相机能力值写错进系统配置时，AIDA64 读出来也会跟着错（详见 [常见问题与排查.md](常见问题与排查.md)）。
- **实时跳动属正常**：CPU/GPU 频率、电池温度、传感器读数 —— 这些本来就是动态量，不同时间看数值不同不代表有问题。
- **对不上先分口径**：内存容量与宣传数字不一致，多数是虚拟内存与系统占用的口径问题，不一定虚标 —— 单独拆了一篇讲怎么分辨：[内存容量显示与宣传不符.md](内存容量显示与宣传不符.md)。

读完参数想拿去比对真伪，直接进入实操篇 [二手机验机实操.md](二手机验机实操.md)。
