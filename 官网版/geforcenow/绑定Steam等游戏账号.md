# GeForce NOW 绑定 Steam 等游戏账号

## 一、先弄清楚一件事：游戏还是你自己的

这是新用户最容易误解的地方。GeForce NOW 是个「云端的电脑」，你在里面打开的是自己 Steam 库里买过的游戏、或者商店里的免费游戏。它不提供游戏本体，也不存在绕过购买直接玩付费游戏的途径。所以绑定商店账号是必经步骤：

| 商店 | 能绑定吗 |
| --- | --- |
| Steam | 支持，游戏最多的一个 |
| Epic Games 商店 | 支持 |
| Ubisoft Connect | 支持 |
| Battle.net | 支持 |
| EA app | 支持 |
| GOG | 支持 |
| Xbox / PC Game Pass | 支持，Game Pass 订阅里的游戏也能串 |

不用全部都绑，你有哪个商店的账号就绑哪个。另外还有几百款免费游戏（如各类 free-to-play 网游）不需要购买，装了商店账号就能玩。

## 二、推荐的绑定顺序：先在电脑上绑

官方的安卓快速上手指南给过一个很实用的建议：**先在 PC 或 Mac 上用 GeForce NOW 把商店账号登一遍**。理由有两个：

1. 在电脑上用实体键盘输入商店的账号密码、过两步验证，比在手机小屏幕上操作顺畅得多；
2. 在电脑上登录过的商店账号，之后在安卓 App 里打开时账号已经处于已连接状态，直接就能看到游戏。

手机端遇到商店登录验证码收不到、页面卡住这类问题时，切到电脑上操作一遍再回来，往往就绕过去了。

## 三、在安卓 App 里绑定

如果只能用手机完成，步骤如下：

1. 打开 App，进入设置里的「连接」（Connections）页面；
2. 点你绑定的商店（如 Steam），弹出该商店的官方登录页；
3. 输入商店账号密码，完成两步验证；
4. 回到 App，游戏库开始同步，玩家库里已拥有且受支持的游戏会陆续出现。

绑定时输入的是**商店自己的账号密码**，NVIDIA 侧只保存连接关系，不存你的商店密码。

## 四、在我的游戏库里找到游戏

绑定成功后，App 的「我的游戏库」（My Library）里会出现你拥有且受支持的游戏。三个要点：

- **搜不到某款游戏 ≠ 绑定失败**：GeForce NOW 支持的池子有几千款，但不是全网游戏都在里面。某个游戏搜不到，多半是它还没被支持，或者你所在地区没有上架（地区差异在官方游戏列表页可以查）；
- **玩过的游戏会自动进库**：你在 GeForce NOW 上开过什么游戏，之后都会出现在我的游戏库里，下次从库里直接点进；
- **进度跟着游戏自己的云存档走**：支持云存档的游戏，你在手机上玩到一半，换到 PC 上的 GeForce NOW 接着玩，进度是连续的。

## 五、绑定失败或登录转圈的排查

1. **账号密码没错但登不上**：先在手机浏览器里直接登录该商店官网，确认账号本身没有被风控锁定；
2. **Steam 提示「登录被拒绝」**：Steam 对新设备登录要过邮箱验证码，去邮箱收信；如果你给 Steam 设了登录令牌，按提示输；
3. **绑定成功但库里是空的**：等几分钟再下拉刷新；游戏确实支持但还不显示，退出 App 重新登录一次 NVIDIA 账号；
4. **提示需要先选会员类型**：这是注册了 NVIDIA 账号但没选 Free 会员的情况，处理方法见 [下载与安装教程.md](下载与安装教程.md) 的首次启动一节。

绑定做完之后，开玩前记得确认手柄已经连好（见 [手柄连接与键鼠设置.md](手柄连接与键鼠设置.md)），否则点开游戏又会卡在输入设备检查那一步。
