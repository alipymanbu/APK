## 一、装不上或装完打不开

| 提示 | 处理顺序 |
| --- | --- |
| 解析包错误 | 核对安装包体积是否约 44.07 MB、MD5 是否为 `6f7c143953063e66da03f4d2a721f8d0`；对不上就重新下载 |
| 应用未安装（签名不一致） | 手机里有同包名 `com.agtechltd.molai` 的另一个版本，先卸载再装；别忘了卸载会清掉只存在本机的数据 |
| 安装被拦截 | 在安全中心的拦截记录里选「继续安装」，或临时关闭安装拦截 |
| 装上后一打开就闪退 | 先重启手机再试；仍闪退时卸载重装一份完整包，从 [molai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8568a33b836d) 重新取 |

安装前的权限设置与完整步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 二、注册验证码收不到

按顺序试：翻邮箱的垃圾邮件与广告邮件文件夹 → 等一两分钟后重新获取（不要连点）→ 换一个邮箱服务商重开注册 → 换个网络环境再取一次。

换邮箱是见效最快的一步，尤其是用国内邮箱收境外发信时偶尔会延迟。详细排查见 [注册登录与邀请码怎么填.md](注册登录与邀请码怎么填.md)。

## 三、AI 回复跑题、聊几句就开始重复

这类问题九成出在设定不够具体，而不是应用坏了：

1. **检查角色人设。** 详情页里人设只有一两句的角色，聊到第三轮后内容开始打转属于常见现象。
2. **把关键设定写进人设或人设马甲。** 想让角色一直记得你的称呼、身份、忌讳，写在设定里比在对话里临时嘱咐更稳。
3. **换一个对话模型试试。** 同一角色的不同模型在「主动推进剧情」这件事上差别明显，见 [聊天模型切换与人设马甲设置.md](聊天模型切换与人设马甲设置.md)。
4. **开一个新会话。** 长会话里早期的细节会被后来的内容冲淡，重要剧情建议新开一场。

自建角色的人设怎么写更耐用，见 [怎么创建自己的AI角色.md](怎么创建自己的AI角色.md)。

## 四、聊天记录会不会丢

记录与账号绑定：换设备用同一个邮箱登录，会话会跟着回来。需要注意两处：

- **卸载重装前想清楚。** 未同步完成的本地内容会随卸载消失，重装后能拿回的是已经存到账号里的部分。
- **登录的包名要对上。** `com.agtechltd.molai` 与 `cc.molai.app` 是两个互不相干的包，登同一个邮箱也可能各算一份数据。

## 五、萤石是什么，怎么来

萤石是 molai 里的虚拟道具，具体能兑换什么、兑换比例多少，**以应用内的兑换页面为准**，不同版本会调整。已知的获取途径主要有：

- 应用内的充值或活动入口（涉及付费，按需决定，绝不勉强）；
- 面向新用户的邀请码奖励：注册后填写邀请码会发放一笔萤石，应用内提示为 50 萤石，不填不影响正常使用。

## 六、要不要花钱

打开应用能看到充值入口与会员之类的档位，属于自愿消费；对话模型在公测期间按应用内提示可免费使用，**后续是否收费、收多少，以应用内当时的页面为准**，本文不做承诺。

另外提醒一句：只从可信渠道取安装包，来源不明的包别装——为省下一点费用去用来路不明的包，风险不对等。

## 七、一直转圈、提示网络异常

1. 先用浏览器打开一个网页，确认手机本身能上网；
2. 切换 Wi-Fi 与移动数据再试一次，排除单个网络的问题；
3. 关掉再打开应用，让它重新拉一次会话；
4. 检查系统时间是否准确——时间偏差过大会让部分接口校验失败；
5. 都不行时，错开高峰时段再试，服务端偶发拥塞也会表现为长时间转圈。

## 八、想彻底清干净重装

1. 先在应用内确认重要会话已经同步到账号；
2. 在「设置 → 应用 → 应用管理」里卸载 molai；
3. 重新从 [molai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8568a33b836d) 取包安装；
4. 用原邮箱登录，确认会话回来了。

装完如果首页一片空白，多半是网络或账号没登进去，先回到第七节和第二节核对一遍。
