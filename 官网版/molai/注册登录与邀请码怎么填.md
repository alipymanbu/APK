molai 不提供「打开就能聊」的游客模式，进入应用后先要有账号。账号体系很轻：邮箱 + 密码，注册时收一封验证码邮件。本篇按「注册 → 登录 → 邀请码 → 出问题怎么办」的顺序讲一遍。

## 一、账号长什么样

| 项目 | 说明 |
| --- | --- |
| 注册方式 | 邮箱 + 自设密码 + 邮箱验证码 |
| 登录方式 | 同一个邮箱与密码 |
| 数据归属 | 角色对话与自建角色跟随账号，换设备登录同一账号即可继续 |

用邮箱注册的好处是换手机不用换号；代价是验证码邮件可能被邮箱服务商丢进垃圾邮件，这一步卡住的人最多，处理办法在第四节。

## 二、注册一个新账号

1. **在手机上装好 molai**（安装包见 [molai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8568a33b836d)，版本 1.0.5）。
2. **打开应用，进入登录界面**，在底部或页面上找「注册」入口。
3. **填邮箱与密码**。建议用一个你真能打开的邮箱，密码单独设一个——这类应用账号一旦泄露，被人拿去翻聊天记录比较尴尬。
4. **点「获取验证码」，去邮箱里找那封邮件**，把验证码填回去。
5. **提交注册，回到登录界面用同一组邮箱密码登录。**

注册完成后首页会刷出角色列表，接下来就是挑一个角色开聊，见 [怎么找一个想聊的角色.md](怎么找一个想聊的角色.md)。

## 三、邀请码在哪个位置填

邀请码是注册环节的一个可选步骤，通常在你注册完成后自动弹出填写入口。跳过了也有机会补：在应用内的个人中心或设置页再找一次「邀请码」入口，不同版本的入口位置可能不一样，以当前版本显示为准。

关于它能带来什么，按应用内的提示口径理解：

- **不填不影响使用。** 邀请码不是必填项，不填也能正常注册、正常聊天。
- **填了会得到一笔萤石奖励。** 应用内提示新用户填写邀请码后发放 50 萤石；这笔奖励到账在账号里，属于应用内的虚拟道具。
- **萤石用来做什么，以应用内的说明为准。** 它可以在应用内的兑换或商店入口使用，具体能换什么、够不够用，不同版本有调整，这里不预先承诺。

有些版本还会把邀请码入口藏在「我的」页面的二级菜单里，找不到时可以在个人中心从上往下翻一遍。

## 四、卡住了怎么办

**收不到验证码邮件**，按这个顺序查：

1. 邮箱的垃圾邮件、广告邮件文件夹——这类验证邮件被误判的概率不低；
2. 换一个邮箱服务商重试（国内邮箱收到境外发信有时会延迟几分钟）；
3. 等一两分钟后点「重新获取」，不要连续点，多数服务端对短时间内重复发信有次数限制；
4. 都不行，先放一会儿再试，服务端发信偶发延迟与本地网络无关。

**登录报密码错误**：确认输入的邮箱是不是注册时那个；密码区分大小写。注册页面一般有「忘记密码」或重置入口，走一遍重置流程比反复试密码快。

**登录后角色与聊天记录是空的**：先确认登录的是不是原来那个邮箱。同一个邮箱在两个包名不同的客户端上登录（`com.agtechltd.molai` 与 `cc.molai.app`），数据也可能各算各的，装之前先看清包名，见 [下载与安装教程.md](下载与安装教程.md)。

**想换账号**：在个人中心退出登录后重新输入邮箱密码即可，应用内一般不做多账号切换。

如果确认是包装错了，重新从 [molai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8568a33b836d) 取一份包名对得上的包装上，再用原邮箱登录。
