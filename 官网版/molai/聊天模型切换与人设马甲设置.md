同样是那个角色，换一个对话模型，回复的节奏、用词、主动程度都可能变样。molai 把「模型」和「人设马甲」这两个开关放在对话页里，本篇讲清它们各自管什么、在哪改、改完为什么感觉没生效。

## 一、对话模型在哪切换

1. 进入某个角色的对话页；
2. 看**输入框附近**——当前使用的模型名会显示在这个位置；
3. 点这个模型名，弹出可选模型列表；
4. 勾选你要用的那个，确认后回到对话页，新回复就按新模型生成。

可选模型的具体名单会随版本调整，**以应用内弹出的列表为准**，这里不列清单。关于费用，应用内的提示口径是公测期间各模型可免费使用；后续是否调整、哪些模型属于付费档，都以应用内当时的显示为准。

网上流传的模型清单经常对不上——有的版本列的是几个通用大模型，有的版本换了一批，网盘里这份为 1.0.5（见 [molai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8568a33b836d)），你看到什么就以什么为准。

## 二、换模型之后手感差在哪

同一段对话换个模型继续，通常能感到这几处差别：

| 观察点 | 表现 |
| --- | --- |
| 回复长度 | 有的模型短句成段，有的习惯成篇叙述 |
| 主动性 | 有的会主动推进剧情，有的只顺着你给的信息答 |
| 用词风格 | 有的偏文艺书面，有的更像日常口语 |
| 响应速度 | 不同模型的出字速度不一样，长回复等得更久 |

用法上有个建议：**同一场剧情不要来回换模型**。模型之间对上下文的理解方式不同，频繁切换容易出现前后语气断裂，像换了个人在演同一个角色。要比较手感，最省事的办法是拿同一个开场白分别在两个模型下各聊几句，再挑一个固定下来。

## 三、人设马甲是什么

角色的人设决定「它是什么人」，**人设马甲决定「你是什么人」**。同一个角色，你在它眼里可以是同学、邻居、同事或别的身份，它会按这个身份称呼你、调整说话方式。

设置步骤：

1. 在对话页点右上角的三条横线（菜单）；
2. 选择「人设马甲」；
3. 编辑马甲内容——写清你的身份、与角色的关系、以及你希望它怎么称呼你；
4. 保存后回到对话。

要点两条：

- **马甲是省事的替代方案**。想在对话里改变身份，用马甲比逐句向角色解释要稳得多，也不会把聊过的内容推翻。
- **一个角色一套马甲**。给不同角色设成不同身份完全没问题，互不影响。

改完马甲后接着聊，角色会从下一句开始按新身份说话；历史消息不会重写。

## 四、多角色群聊怎么开

你可以在同一个会话里把多个角色放进来互动，适合想同时看几个角色对戏的场景。做法上通常是在会话里通过菜单添加更多角色，具体入口名称以当前版本为准。群聊里有两点和单聊不一样：

- **每个角色仍按各自的人设说话**，但话题推进由几个角色共同分担，你插话的时机更随意；
- **人设马甲在群聊里同样生效**，几个角色看到的都是同一个你。

## 五、改完设置没生效时

按下面顺序排查，多数情况第一步就够了：

1. **完全退出对话页再重新进入**，让会话重新加载一次；
2. **确认修改保存成功**——返回编辑页看一眼内容还在不在；
3. **重启应用**，排除界面状态没刷新；
4. 仍然不生效，再看 [常见问题与排查.md](常见问题与排查.md) 里的网络与账号部分。

如果**模型列表整个是空的**、点进去没有任何可选项，那是另一类问题，先确认客户端没装坏：重新从 [molai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8568a33b836d) 取包装一次，再登录同一个账号看列表是否回来。

想把角色本身调得更贴你的预期（说话方式、背景设定），改角色人设比改马甲更根本，做法见 [怎么创建自己的AI角色.md](怎么创建自己的AI角色.md)。想同时体验几套不同风格的回复，也可以在选角色时多挑几个设定差异大的，对比着聊，见 [怎么找一个想聊的角色.md](怎么找一个想聊的角色.md)。
