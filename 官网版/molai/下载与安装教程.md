molai 是一个中文 AI 角色对话应用：内置一批可以设定人设的角色，也能自己捏角色，对话时可在多个对话模型之间切换。它走的是手机端安装包路线，需要自己把 APK 装进手机。本篇只做一件事——把网盘里这份包装好并正常打开。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本信息通常是官方当时的最新发布版，与网盘里这份未必是同一个版本号。本文所有版本号、包名、体积都以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | molai |
| 版本号 | 1.0.5 |
| 包名 | `com.agtechltd.molai` |
| 安装包体积 | 44.07 MB |
| MD5 | `6f7c143953063e66da03f4d2a721f8d0` |
| 适用平台 | Android（手机端 APK） |

安装包本体在 [molai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8568a33b836d) 里，转存到自己网盘后下载即可。

几点先说明白：

- **包名是 `com.agtechltd.molai`。** 网上能搜到另一个包名（`cc.molai.app`）的同名应用条目，那是另一条渠道的包。两者在系统里会被识别成两个不相干的应用，**不能互相覆盖安装**，聊天记录与设置也各算各的。装之前先确认你手上这份的包名，在「设置 → 应用 → 应用管理」里点进该应用就能看到。
- **版本号属于 1.0.x 系列。** 官方后续版本号可能已经高于 1.0.5，具体以官网 [www.molai.cc](https://www.molai.cc/) 当时显示的为准，这里不预判后续编号。
- **官网 molai.cc 提供网页入口与 App 下载引导。** 入口是 [www.molai.cc](https://www.molai.cc/)，能不能直接在浏览器里聊、手机端最低要哪个系统版本，以官网页面的说明为准。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [molai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8568a33b836d)，在手机夸克 App 里打开最省事。
2. **先转存再下载**：选中安装包，转存到自己的网盘目录，再下载到本机。分享链接以后可能失效，转存过的那份不受影响。
3. **确认下载完整**：下载完成后在文件列表里看一眼体积是否约 44.07 MB。中途断网重连后体积偏小，装的时候会直接报「解析包错误」。
4. **想校验完整性**：在电脑上把包算一遍 MD5，结果应当与上表一致。

```cmd
certutil -hashfile molai_v1.0.5.apk MD5
```

（文件名随版本变化，以网盘里实际提供的为准。）

## 三、安装步骤

1. **让文件管理器获得安装权限**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，把用来打开 APK 的那个应用（文件管理器或浏览器）的开关打开。国产定制系统这项常收在「安全」或「隐私」分类下。
2. **点击 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续——这是侧载安装包的常规提示，不代表文件有问题。
3. **回装低版本要先卸载**：安卓不允许用更低版本覆盖更高版本，会直接报「应用未安装」。如果手机里已装了一个更高的版本号，先卸载再装这份，否则数据会随卸载一起清掉。
4. **留意包名冲突**：同包名冲突的报错形如「应用未安装：签名不一致」，处理办法在本篇第五节的表里。

## 四、第一次打开要确认的三件事

1. **能联网**：molai 的角色列表、对话、模型切换都在服务端，打开后如果停在加载状态，先在浏览器里确认手机能正常上网。
2. **能注册或登录**：第一次进入需要账号，注册用邮箱加验证码。收不到验证码的排查见 [注册登录与邀请码怎么填.md](注册登录与邀请码怎么填.md)。
3. **能看到角色列表**：首页刷得出角色卡片，说明数据侧通了；再从列表里挑一个角色点进对话，发一句「你好」，能正常收到回复就算装好了。找角色的具体方法见 [怎么找一个想聊的角色.md](怎么找一个想聊的角色.md)。

## 五、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包下载不完整 | 核对体积与 MD5，从 [molai 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8568a33b836d) 重新下载一次 |
| 提示「应用未安装：签名不一致」 | 手机里已装同包名的另一个版本 | 先卸载旧包再装；卸载前注意聊天记录是否只存在本机 |
| 安装被安全中心拦截 | 侧载安装包被系统安全策略拦下 | 在安全中心的拦截记录里选择「继续安装」 |
| 装上后闪退 | 系统版本过低、内存不足或安装残缺 | 见 [常见问题与排查.md](常见问题与排查.md) |
