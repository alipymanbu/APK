## 一、什么时候需要外接 Stackmat

想用和比赛同款的实体计时器（Stackmat）来练，而不是手指点屏幕。设置里的「产生成绩通过」选成 Stackmat 后，成绩由计时器产生、直接进 DCTimer 的成绩列表，后续的统计口径与普通计时完全一样。

## 二、要准备的东西

| 物件 | 说明 |
| --- | --- |
| OTG 线 / 转接头 | 按手机接口选（Type-C 或 Micro-USB 转 USB-A），接口不匹配就插不上 |
| USB 声卡 | 普通外置 USB 声卡即可，作用是把计时器的信号转成手机能读的音频输入 |
| 3.5mm 转 2.5mm 音频线 | 3.5mm 一头接声卡，2.5mm 一头接 Stackmat 的接口 |
| Stackmat 计时器 | 本体，处于可用状态 |

线材要用支持数据传输的：仅供电的充电线插上也不传信号。

## 三、连接与设置步骤

1. 手机 → OTG 线 → USB 声卡，依次插好；
2. 用 3.5-2.5 音频线把声卡与 Stackmat 的接口连起来；
3. 看手机顶部状态栏出现**耳麦图标**，说明声卡已被识别；
4. 打开 DCTimer，点左上角导航菜单里的「Stackmat 计时器」，确认连接状态正常；显示不正常时回到这一页调整采样率、格式等参数；
5. 回到设置，把「产生成绩通过」选成 **Stackmat**；之后正常还原，成绩会从计时器自动进列表。

进了列表之后的改惩罚、删成绩、算平均，与普通计时完全一样，见 [成绩统计与图表.md](成绩统计与图表.md)。

## 四、连不上或计不出成绩

- **状态栏没有耳麦图标**：OTG 线或声卡没被识别，换一根支持数据传输的 OTG 线再试；
- **图标有、但应用里读不到信号**：回导航菜单的「Stackmat 计时器」页调整采样率与格式；
- **别把「两手模拟 Stackmat 计时」当成外接**：那是用两只手按屏幕模拟计时器动作的触摸模式，与外接硬件无关，两者开混了会互相干扰判断。

## 五、为什么不能用「分线器直插耳机口」的老办法

0.8 以前的版本确实支持通过音频分线器把计时器直接插进手机耳机口。但近年手机普遍带降噪处理，解析不了计时器传出的信号，从 0.9 版起这条路已从应用里移除——还能搜到的「分线器直连」老教程对新版本不适用，必须走上面 OTG + USB 声卡的方案。
