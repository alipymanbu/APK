## 一、安卓：导出与导入数据库

1. 打开 DCTimer，点左上角打开导航菜单；
2. 选「导出导入数据库」（部分版本菜单里显示为「导入导出数据」，是同一个入口）；
3. 导出：选一个手机里的保存路径，得到一个数据库文件；
4. 导入：选中之前导出的数据库文件即可。

两条必须知道的规则：

- **导入是直接覆盖**：导入后手机上现有的数据会被换掉，不会合并。所以导入之前，先把当前数据也导出一份留底，防止拿错文件覆盖错。
- **格式不兼容旧版**：从 0.9 版起数据改用数据库格式，0.9 之前版本的文本格式数据导进不来。跨过大版本升级时，先在新版里导出确认能正常打开，再删旧版。

## 二、iOS（DCTimer²）怎么备份数据

iOS 没有应用内的导出入口，走的是文件共享：

1. 用数据线把手机连到电脑，通过 iTunes 或第三方助手的「文件共享 / 应用文件」功能找到 DCTimer²；
2. 把里面的 `spdcube.sqlite` 保存到电脑上，这就是全部成绩数据；
3. 恢复时把这份文件放回应用的共享目录即可。

新旧版本的数据库文件格式相同，旧版 DCTimer 的数据可以直接转到新版 DCTimer² 上。

## 三、什么时候该备份

| 时机 | 原因 |
| --- | --- |
| 升级版本前 | 防止升级过程出问题丢数据 |
| 换手机前 | 数据不在云端，不导就带不走 |
| 恢复出厂 / 清数据前 | 本地数据库会被清空 |
| 每攒够一段时间的成绩 | 养成习惯，成本只有一次导出 |

换机的完整顺序：旧机导出 → 把文件传到新机（任意方式）→ 新机装好 DCTimer（安装见 [下载与安装教程.md](下载与安装教程.md)）→ 导入 → 打开成绩列表抽查几条确认完整。

导入后成绩列表空了或者打不开，先确认导入的是 0.9 之后导出的数据库文件，再对照 [常见问题与排查.md](常见问题与排查.md) 检查。
