模组文件不随安装包一起分发，装好 tModLoader 只是第一步——你还需要单独拿到 .tmod 模组文件并放对位置，游戏里才会出现新内容。本篇按你在主界面「模组管理」里实际能看到的按钮来讲。

## 路线一：用界面里的「打开模组文件夹」

这是多数手机版用户走的一条路，全程在应用与文件管理器之间切换：

1. 启动 tModLoader，在主界面点「模组管理」。刚装好时列表是空的，属于正常现象。
2. 点列表下方的「打开模组文件夹」，记住它跳转到的位置；部分机型不会自动跳转，你就手动打开文件管理器，进入下面这个目录：

```text
/storage/emulated/0/Android/data/ModLoader.Explendesco/Mods/
```

3. 把你下载好的 .tmod 模组文件移动或复制到这个 Mods 文件夹里，支持一次放多个。
4. 返回应用，重新进入「模组管理」，新放进来的模组会出现在列表里。
5. 点模组旁边的开关启用它；如果提示需要重新加载，点「重新加载模组」。
6. 回到主菜单，正常选择模式进入游戏，模组内容就会生效。

「找不到 ModLoader.Explendesco 这个文件夹」多半是你还没完整启动过一次应用——目录要等它跑起来才会生成，先按[下载与安装教程.md](下载与安装教程.md)空跑一次再找。

## 路线二：内置模组浏览器

部分移植版在模组管理里带有联网的模组浏览器入口，可以直接在应用内检索并下载模组，省去手动搬文件的步骤。能不能用、能搜到多少模组，取决于你手上这份移植版的内置内核与网络状况——浏览器拉不到列表时，改走路线一手动导入即可。

## 模组文件从哪里来

- **模组作者的发布页**：正规渠道是模组作者的 GitHub Releases 页，那里发布的 .tmod 按版本分档，能对上你这份内核的概率最大。
- **应用内模组浏览器**：可用的话直接检索安装，省去搬文件；用不了就手动放。
- **警惕来路不明的"整合包"**：别人打包好的模组合集无法确认有没有被掉包，宁可自己一个个从发布页拿。

灾厄这类大型模组的版本挑选与汉化包，单独写在[灾厄等大型模组怎么装.md](灾厄等大型模组怎么装.md)里。

## 启用之后：版本匹配与依赖

- **版本要对上**：模组是按特定 tModLoader 版本编译的。同一个模组在不同版本下可能加载失败或直接报错，遇到「模组启用后无效」「加载时出错」，优先怀疑模组版本与移植版内核不匹配，换与内核对应的模组版本再试。
- **依赖要装全**：不少模组依赖基础库类模组（比如共享 API 库），只放主模组不放依赖会加载失败。下载页面一般会写明依赖，逐个补齐后再重载。
- **一次加一个**：一次只启用一个新模组，进游戏确认正常再加下一个。出问题时你才能立刻定位是哪个模组引起的。
- **重载才算生效**：启用、停用之后都要「重新加载模组」，改完直接进游戏是不会变的。

## 联机前先对齐模组

打算和朋友联机的话，模组环节就要提前对齐：双方启用同一批模组、版本一致，才能进同一个房间。具体的联机步骤与存档注意事项见[联机与存档须知.md](联机与存档须知.md)。
