模组泰拉瑞亚的联机翻车，九成出在「双方模组不一致」；存档翻车，则几乎都是「没备份就动了模组」。这一篇把两件事的操作与检查点列清楚。

## 联机的前提：双方完全对齐

进同一个房间之前，逐项核对：

| 核对项 | 要求 |
| --- | --- |
| 应用版本 | 双方 tModLoader 手机版版本一致 |
| 模组清单 | 启用的模组一模一样，多一个少一个都可能进不去 |
| 模组版本 | 同一个模组也要同一版本，不能你新版他旧版 |
| 依赖模组 | 主模组的依赖库同样要对齐 |
| 汉化包 | 用了汉化的话，双方汉化也要同版本，一边中文一边英文就可能进不了房 |

一个常见的省事做法：开房的玩家把自己 Mods 文件夹里的 .tmod 文件打包发给朋友，让对方放进同样的位置再启用，这样清单天然一致（模组文件的放置方法见[模组导入与启用步骤.md](模组导入与启用步骤.md)）。

## 联机步骤

以其中一台手机当主机：

1. 双方按上表对齐模组，各自先进一次游戏确认正常。
2. 主机玩家在主菜单选「多人游戏」。
3. 选择「开服并进入游戏」，用自己的世界当联机房间。
4. 朋友在同一网络下从「多人游戏」里加入该房间。不在同一网络时是否可连，取决于移植版的联网能力与网络环境，以实际版本支持为准。

进房后如果立刻掉线或卡在加载，先回头核对模组清单——这是联机故障里占比最大的一种，其次才是网络原因。

## 存档：独立存放，先备份再折腾

- **模组存档与原版分开**：tModLoader 体系的存档与原版《泰拉瑞亚》的存档相互独立，玩模组不会覆盖你原版的进度；反过来，原版存档也不是直接就能在模组环境里接着玩。
- **手机上可以手动备份**：安卓版《泰拉瑞亚》的世界与角色文件允许用文件管理器访问，tModLoader 的存档同理。动手换模组、换版本、重装应用之前，先把存档目录整个复制一份到别的位置（手机存储、电脑、云盘都行）。
- **删应用 = 删存档**：卸载 tModLoader 时它的存档会一起没掉。卸载重装排查故障前，先确认存档已经备份出来。
- **PC 与手机互不相通**：PC 版 tModLoader 的存档拿到手机上用不了，反过来也一样，别白折腾。

## 换手机怎么办

换机前把整个模组存档目录复制到新手机对应的相同位置（路径里含 ModLoader.Explendesco 的那一套目录），再把模组文件也原样带过去。装好同版本应用、放回存档与模组，进度就能接着玩。装备与角色进度对不上时，优先检查存档是不是放错了目录层级。
