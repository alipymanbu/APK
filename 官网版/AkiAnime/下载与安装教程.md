## 一、AkiAnime 是什么

AkiAnime 是一款安卓端的追番应用，你能用它在线看日漫、国漫、韩漫、剧场版等内容，也可以把剧集缓存到本地离线看。它打开就能用，不要求先注册账号，界面上没有开屏广告和播放贴片。本篇只讲「怎么拿到安装包并装上」，装好之后怎么找番、怎么投屏，见后面的几篇相关文档。

## 二、安装包信息（以本地保存的这份为准）

网上各应用市场页面标的是官方最新版（版本号会持续变动），而网盘里保存的是下面这一份，两者常常不是同一版。凡涉及版本号、包名、安装包大小，以下表为准：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.3.1 |
| 包名 | `aki.akiani.app` |
| 大小 | 54.34M |
| MD5 | `1A5E0850DEB11C35F94B3F10E880480C` |
| 采集时间 | 2026-09-23 |

v2.3.1 这一版的更新内容是更换了界面与应用图标、增加了分类和专区。

## 三、下载与安装步骤

1. 打开 [AkiAnime 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3ca5de40e9f8)，把安装包转存到自己的网盘后下载到手机。
2. 下载完成后在文件管理器里点 `.apk` 文件开始安装。
3. 如果系统弹出「禁止安装来自此来源的应用」，这是安卓对侧载安装的默认拦截：按提示进入「设置 → 允许安装未知应用」，为你的浏览器或文件管理器开启该权限，再回来继续安装。
4. 装完打开应用，首次启动会弹权限申请，按提示逐项授权即可——拿不准就先允许，之后按第六节收紧。

## 四、系统要求

本地采集记录标注「需要支持安卓系统 5.2 以上」，另有第三方应用页面标注需 Android 7.0 才能安装。两处口径不一致，实际以你手机安装时的提示为准——装不上时先看系统版本，而不是怀疑安装包损坏。

## 五、确认装的是同一份包

想核对下载到的文件与网盘里那份是否一致，可以在电脑上算一下 MD5 与上表比对；对不上说明下载不完整或文件被替换，重新下载即可。安装后也可以在「系统设置 → 应用管理 → AkiAnime → 关于」里看版本号是否为 2.3.1。

## 六、装完之后的权限管理

有第三方应用页面统计过，该应用申请的权限数量明显多于一般的播放器（含位置、相机等）。你可以只给必需的那些，路径是「系统设置 → 应用管理 → AkiAnime → 权限」，按功能对号入座：

| 权限 | 不给会怎样 |
| --- | --- |
| 存储 / 媒体文件 | 离线缓存写不进去，下载功能不可用 |
| 位置（安卓把「获取网络信息」归在这里） | 投屏时搜不到同网段的电视，见[投屏搜不到设备怎么排查.md](投屏搜不到设备怎么排查.md) |
| 相机、通讯录等与播放无关的 | 可以拒绝，不影响看番与投屏 |

拿不准就先全部按弹窗允许、用起来之后再回来收紧——安卓支持随时改，改坏了也能随时恢复默认。

装好之后，先看[找番与更新排期表使用技巧.md](找番与更新排期表使用技巧.md)熟悉界面；播放出问题时按[播放卡顿与闪退排查.md](播放卡顿与闪退排查.md)逐项处理。
