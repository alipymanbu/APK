## 一、这篇给谁看

装好 AkiAnime 之后，面对首页一屏封面不知道从哪下手、或者明明在追的番更新了却找不到入口，这篇把几个找番入口的用法讲清楚。所有操作都在应用内完成，不需要登录。

## 二、各入口分别适合什么场景

| 入口 | 适合场景 |
| --- | --- |
| 首页推荐 | 没明确目标，想看当前热门 |
| 分类筛选 | 按题材挑，如热血、恋爱、悬疑、科幻 |
| 专题板块 | 找冷门、小众作品 |
| 排行榜 | 看别人都在追什么（热门榜、新番榜等） |
| 更新排期表 | 追连载，确认某部番今天更不更 |
| 搜索框 | 已知名字，直接定位 |

## 三、更新排期表怎么看

追连载最怕漏更。应用内有更新排期表，按天列出当日更新的剧集：打开排期表，对照你追的番看它在周几更新，到点进详情页即可。配合「收藏」（见[账号登录与设置调整说明.md](账号登录与设置调整说明.md)）能把想追的番都收进自己的列表，不用天天翻排期。

## 四、搜索的两个技巧

1. **中文译名搜不到就换日文原名**。部分番剧的条目名是日文原名或罗马音，输入译名可能匹配不上，换原名再试一次通常就能出来。
2. **搜不到就改用分类/专题浏览**。冷门作品可能没进搜索索引，到「专题」板块按分类翻，往往能挖到。

## 五、找番的日常动线

1. 打开应用先扫一眼首页推荐，有想看的直接点封面进播放页；
2. 追连载的番，隔几天看一次更新排期表，确认更新日；
3. 补旧番时用排行榜或分类筛选，按题材缩小范围；
4. 播放中想调画质、倍速、字幕，见[账号登录与设置调整说明.md](账号登录与设置调整说明.md)；
5. 想在电视上看，按[投屏与离线缓存教程.md](投屏与离线缓存教程.md)操作。
