# 投屏搜不到设备怎么排查

> 手机投屏时设备列表是空的、或连上了没画面没声音，这篇按从最常见到最少见的顺序逐项排查。

## 一、这篇解决什么

投屏功能本身的操作没几步（步骤见[投屏与离线缓存教程.md](投屏与离线缓存教程.md)），真正卡人的是「点了投屏图标，列表里什么都没有」。原因几乎都在网络发现这一层，不在应用本身。下面每步做完回去搜一次设备，有效就停。

## 二、第一步：确认手机和电视在同一个网络

这是搜不到设备最常见的原因，要查的不是「都连了 WiFi」，而是**是不是同一个网络**：

- 在两台设备的设置里对照 **WiFi 名称是否逐字一致**——手机连 `xxx-5G`、电视连 `xxx` 或 `xxx-Guest`（访客网络），就算都能上网也互相发现不了；
- 路由器开了「双频合一」或「AP 隔离」「访客模式」的，暂时关掉再试——这些功能会让连入的设备互相隔离；
- 电视用网线、手机用 WiFi 时，确认两者接的是同一台路由器/同一个网段；
- 手机开着 VPN 或私人 DNS 的先关掉——它们会挡住局域网内的设备发现；
- 手机同时开着移动数据且 WiFi 信号弱时，系统可能悄悄切回流量，短暂关掉移动数据再搜。

## 三、第二步：让电视停在「等待连接」画面

很多电视必须先手动进入投屏接收页面，手机才搜得到它。不同品牌入口不一样（截至 2026 年各品牌的常见路径）：

| 品牌 | 电视上进入等待连接画面的路径 |
| --- | --- |
| 三星 | 主页 → 遥控器「节目源」→ Screen Mirroring |
| 索尼 | 主页 → 遥控器「输入源」→ 菜单选「屏幕镜像」 |
| 小米 | 主页 → 我的应用 → 无线投影 |
| 创维 | 主页 → 应用 → 我的应用 → 爱投屏 → 镜像 |
| 长虹 | 主页 → 我的应用 → Miracast |
| 海信 | 主页 → 我的应用 → hi投屏 → 游戏投屏 → 安卓 |
| LG | 主页 → 我的应用 → Miracast |

盒子类设备同理：打开盒子上的投屏/接收应用并保持在页面上，别退回主页。

## 四、第三步：检查手机端权限

安卓的设备发现依赖局域网访问：到「设置 → 应用管理 → AkiAnime → 权限」里确认**位置权限**没有被禁——安卓把获取网络信息归在位置权限下，禁掉后应用就搜不到同网的电视（安装时若选了「仅使用期间允许」即可，不必给「始终允许」）。存储权限同理，禁掉会影响后续步骤，见[下载与安装教程.md](下载与安装教程.md)。

## 五、第四步：重启这三个环节

确认网络和电视端都没问题却仍搜不到时，按顺序做：

1. 关掉再重新打开手机上的投屏入口（点退出后重进）；
2. 退出并重新打开电视端的投屏接收页面；
3. 重启路由器，或让手机、电视重新连一次 WiFi。

「设备找不到」很多时候只是网络状态没刷新，重连一次比反复点搜索有效。

## 六、连上了但黑屏、没声音、画面卡

| 症状 | 先查这几项 |
| --- | --- |
| 黑屏 | 电视输入源切对没有；该内容是否带版权保护不支持镜像（换成应用内投屏而非镜像） |
| 没声音 | 电视音量、手机媒体音量都调了吗；蓝牙耳机是否还连着手机把声音截走了 |
| 画面卡顿 | 手机靠近路由器；减少同时占网的设备；隔墙或距离远时换个摆放位置再试 |

## 七、最后一步：换投屏通道

以上都试过仍不行，说明电视自带的接收端与手机不兼容。网上整理的 AkiAnime 常见问题解答给的建议是：在电视端安装「光元素投屏」电视端应用（该应用主打纯净无广告）后重试；也可以改用乐播投屏、当贝投屏这类支持多协议的第三方投屏工具，在电视应用商店里搜索安装即可。仍无效果时，让电视改连手机开的热点再搜一次——能搜到说明是路由器配置的问题，搜不到就是电视接收端的问题。
