## 一、装之前先核对三件事

| 项目 | 官方最低要求 |
| --- | --- |
| 系统 | Android 10.0 及以上，**64 位** |
| 芯片 | 骁龙 835 SoC 或同等及以上 |
| 图形 | 支持 OpenGL ES 3.2 或 Vulkan 1.1（至少其一） |
| 内存 | 2 GB，建议 4 GB |

来源是官方仓库的 README，配置口径可能随版本调整，以官方页面为准。

核对要点：

1. **32 位手机装不上**。Azahar 的安卓包只有 64 位版本，系统是 32 位的设备会在安装阶段直接失败。
2. **留出存储空间**。模拟器本体不大，但游戏文件本身每份动辄数百 MB 到数 GB，安装前给游戏目录留足空间。
3. **芯片档次决定体验**。骁龙 835 只是能跑的底线，低于这条线的设备设置调不回来；具体影响见 [性能与画面设置.md](性能与画面设置.md)。

## 二、认准官方渠道，小心高仿假站

官方在 2025 年 3 月专门发过一篇博客提醒：**官方网站只有 [azahar-emu.org](https://azahar-emu.org/) 这一个**。搜索引擎里出现过 `azahar-emulator.org` 这类高仿域名，外观做得与官方站很像，与官方团队没有任何关系，可能分发被动手脚的安装包。别的同名站点一律当不可信处理。

真正靠谱的渠道只有这几个：

| 渠道 | 地址 | 说明 |
| --- | --- | --- |
| 官方下载页 | [azahar-emu.org/pages/download](https://azahar-emu.org/pages/download/) | 全平台入口，安卓选 Android 一栏 |
| GitHub Releases | [github.com/azahar-emu/azahar/releases](https://github.com/azahar-emu/azahar/releases) | 桌面版与安卓 APK 都在这发 |
| Google Play | 搜索 Azahar（包名 `io.github.lime3ds.android`） | 官方上架的商店版本 |

## 三、两个安卓版本怎么选

Azahar 在安卓上有两个形态，**包名相同，来源不同**：

- **Play 商店版**：从 Google Play 安装，自动更新、省事。代价是受谷歌的存储策略约束，访问游戏文件要经过系统的文件夹授权流程。
- **Vanilla 版（APK 直装）**：官方原样打包的 APK。官方 README 的说法是它用了另一种文件管理方式、**读取文件更快**，但因为不符合商店政策不能上 Play 商店，只能自己装 APK 或通过 Obtainium 之类工具订阅 GitHub 仓库安装。

两个版本的取舍很简单：怕折腾选 Play 版，在意文件读取速度、游戏文件放在 SD 卡或特殊目录的选 Vanilla 版。

注意一点：**APK 直装不会自动更新**，出了新版本要自己重新下载安装。

## 五、安装步骤

1. 从上面的 azahar 安装文件资源（夸克网盘）下载 APK 到手机。
2. 在文件管理器里点开这个 APK。系统弹出「未知来源 / 允许安装未知应用」提示时，按提示给当前来源授权后继续（不同品牌的授权入口不一样，一般在弹窗里直接给）。
3. 安装完成点开应用。**第一次启动它会建立自己的数据目录**，别急着删数据。
4. 打开后游戏列表是空的，这是正常的——下一步是把游戏文件放进来并指定目录，做法见 [游戏文件格式与添加方法.md](游戏文件格式与添加方法.md)。
5. 装完先别删安装包所在的文件夹，万一要重装（比如换了图形设置后崩溃排查），省得再下一遍。

装完之后遇到打不开游戏、黑屏的，多数不是安装的问题，先看 [系统文件与密钥准备.md](系统文件与密钥准备.md)，再对照 [常见问题与报错处理.md](常见问题与报错处理.md)。
