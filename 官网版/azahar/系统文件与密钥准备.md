# Azahar 需要的系统文件与密钥怎么准备

> 本篇讲 Azahar 数据目录里 `sysdata` 下两个文件的来历：`aes_keys.txt` 与 `seeddb.bin`，以及怎么从你自己的 3DS 把它们导出来。

## 一、为什么有的游戏打不开

3DS 的游戏内容是加密的。模拟器在运行加密内容时要用到主机侧的密钥，而**模拟器本身不附带这些密钥**——这不是缺陷，是项目刻意的设计。所以缺密钥时你会看到：

- 加密的游戏转储扫不出来，或列表里显示异常；
- 点进去黑屏、闪退，或报与解密相关的错误；
- 未加密的内容（比如多数自制程序）反而一切正常。

遇到这些症状，先按本篇把两个文件补齐，再去查别的。

## 二、缺的是哪两个文件

| 文件 | 作用 | 放置位置 |
| --- | --- | --- |
| `aes_keys.txt` | 解密所需的主密钥表，缺它加密内容读不了 | Azahar 数据目录下的 `sysdata/` 文件夹 |
| `seeddb.bin` | 部分游戏需要的种子数据库 | 同上，`sysdata/` 文件夹 |

两个文件都很小，一起放进 `sysdata/`，重启模拟器生效。

官方仓库里带了一个配套的 **DumpKeys 脚本**（GodMode9 脚本），位置在 [github.com/azahar-emu/azahar 的 dist/dumpkeys 目录](https://github.com/azahar-emu/azahar/tree/master/dist/dumpkeys)——官方自己给的就是「从真机导出」这条路，照官方脚本走最省事。

## 三、从你自己的 3DS 导出（GodMode9 流程概览）

前提只有一条：**这两个文件只能来自你自己拥有的 3DS 主机**。本篇只覆盖这一条路径，不涉及任何其他获取方式。

流程概览（具体细节随机型和系统版本而异，按你的机型搜对应的 GodMode9 教程）：

1. 在你的 3DS 上装好 GodMode9（一个运行在自制环境下的文件管理工具；让 3DS 进入自制环境的方法因机型和固件差异很大，这一步照你机型的教程做）。
2. 把上面说的官方 `DumpKeys.gm9` 脚本复制到 SD 卡的 `gm9/scripts/` 目录。
3. 按住 START 键开机进入 GodMode9，按 HOME 键打开菜单，选 **Scripts**，再选 **DumpKeys** 执行，等它跑完回到主菜单。
4. 关机，把 SD 卡插回电脑（或用读卡器），取走两个产物：
   - `gm9/aes_keys.txt`
   - `gm9/seeddb.bin`
5. 把这两个文件复制到手机上 Azahar 数据目录的 `sysdata/` 文件夹里，重启 Azahar。

一句话记住：**脚本放 SD 卡 → 真机跑一次 → 取走两个文件 → 丢进 sysdata**。

## 四、放好之后怎么验证

1. 重启 Azahar（最好连后台一起划掉再开）。
2. 之前黑屏或扫不出来的加密游戏，重新点进去，能正常进标题画面即为生效。
3. 还不行的，按这个顺序排查：
   - 文件名对不对（`aes_keys.txt` 一个字符都不能差，别带 `.txt.txt` 这类双重后缀）；
   - 位置对不对（必须在数据目录的 `sysdata/` 下，不是游戏目录）；
   - 游戏本身在不在官方兼容性列表的「能跑」范围里（见 [游戏文件格式与添加方法.md](游戏文件格式与添加方法.md) 第四节）。
4. 密钥排除了还崩溃的，转 [常见问题与报错处理.md](常见问题与报错处理.md)。
