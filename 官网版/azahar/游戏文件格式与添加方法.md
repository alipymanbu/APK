## 一、这几种格式分别是什么

Azahar 作为 3DS 模拟器，吃的是 3DS 的标准内容格式。你手上常见的文件无非下面几种：

| 扩展名 | 是什么 | 什么时候会见到 |
| --- | --- | --- |
| `.3ds` / `.cci` | 卡带镜像（同一格式，CCI 是它的真名） | 从实体卡带转储的原始镜像，最常见的游戏文件；`.3ds` 后缀的支持随版本变过，见下文说明 |
| `.cia` | 安装型内容包 | 数字版游戏、DLC、系统内容常用这种封装 |
| `.cxi` / `.app` | 可执行内容 | 多见于系统程序或拆出来的单个可执行模块 |
| `.3dsx` / `.elf` | 自制程序（homebrew） | 官方把模拟器也当作自制软件的开发调试环境，这类文件直接运行 |

**`.3ds` 后缀要看版本**：官方从 2120 起不再认 `.3ds` 这个扩展名（格式本身没变，只是不再支持这个后缀），把文件改成 `.cci` 就能被识别。另有用户反馈 2124.3 起又恢复了 `.3ds` 的直接支持（单一来源、未见官方口径），两种说法并存——最省事的处理是：扫不出来就改名，改个后缀而已。

判断你该用哪个不用纠结：普通游戏不是 `.3ds`（或 `.cci`）就是 `.cia`，放进游戏目录都能被扫描到；`.3dsx` 主要是玩自制程序才碰。

## 二、把游戏加进列表

1. **先建一个专门的游戏目录**。在手机存储里建一个固定文件夹（比如 `3DSgames`），把游戏文件都放进去，别散落在下载目录各处——目录乱是「列表里找不到游戏」最常见的起因。
2. **打开 Azahar，指定游戏目录**。第一次启动时会提示你选择游戏文件夹；跳过了也没关系，之后在游戏列表界面里再添加即可。
3. **等扫描完成**。模拟器会扫描该目录及其子目录，符合格式的文件逐个出现在列表里，显示为游戏图标和名称。
4. **点游戏即开始运行**。第一次进某个游戏时着色器还在编译，开头可能卡顿，属正常现象。

换手机或换模拟器版本时，游戏目录本身不用动，重新指定一次路径即可。

## 三、转储没解密：列表看不到或启动黑屏先查这里

典型症状：

- 文件明明在目录里，列表就是扫不出来；
- 能点进去，但黑屏、闪退，或报解密相关的错误。

原因：**Azahar 2120 起不再支持加密的应用**，它要的是**已经解密的转储**——不是文件坏了，也不是放个密钥文件就能救。解密要在导出环节完成：用 GodMode9 从你自己的卡带导出时选解密导出（dump decrypted），出来的就是可直接用的文件。密钥与系统文件现在管的是另一摊事（系统内容、eShop 功能），现状与导出流程单独写在 [系统文件与密钥准备.md](系统文件与密钥准备.md) 里。

## 四、先查兼容性，再折腾设置

3DS 模拟不是「放进去就能跑」的关系，每个游戏的兼容状态不一样：

- 官方维护着一份**兼容性列表**：[azahar-emu.org/pages/compatibility](https://azahar-emu.org/pages/compatibility/)。游戏名搜进去能看别人报告的运行状态（完美 / 可玩 / 崩溃等）。报告有滞后性，实际情况可能比列表更新。
- 兼容性列表里标着「崩溃 / 无法运行」的游戏，你在自己设备上怎么调设置都救不回来，别浪费时间反复重装。
- 排除兼容性之后还跑不动的，才是设置或设备性能的问题，去 [性能与画面设置.md](性能与画面设置.md) 对症调；其他怪现象汇总在 [常见问题与报错处理.md](常见问题与报错处理.md)。
