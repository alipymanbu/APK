## 一、先认清瓶颈在哪

3DS 模拟的重头在**单核 CPU 性能和 GPU**，核数堆再多也帮不上忙。官方最低线是骁龙 835、OpenGL ES 3.2 或 Vulkan 1.1（详见 [下载与安装教程.md](下载与安装教程.md) 第一节的表格）。低于这条线的设备，下面的设置只能缓和、救不回来；达到或超过这条线的，按本篇调一般能稳住大多数游戏。

## 二、图形 API：Vulkan 还是 OpenGL ES

Azahar 的图形后端两个都支持，选哪个看你的设备驱动表现：

| 情况 | 建议 |
| --- | --- |
| 较新的芯片、驱动较新 | 先试 **Vulkan**，很多设备上它的帧数上限更高 |
| Vulkan 下花屏、闪退、黑屏 | 切回 **OpenGL ES** 对照 |
| 同一游戏两种 API 表现差异大 | 以实际游戏为准，逐游戏定，没有全局最优解 |

具体操作路径不用背：设置里的图形 / 图像区块找「图形 API（Graphics API）」下拉项切换即可，切换后重新进游戏生效。

## 三、内部分辨率：清晰度与流畅度的主旋钮

3DS 的原生分辨率很小——上屏 400×240、下屏 320×240。模拟器按倍数放大内部渲染分辨率，这就是「内部分辨率」选项：

- **倍数越高，画面越锐利，GPU 负担越大**。这是画面和流畅度之间最直接的一个旋钮。
- 卡顿先**降倍数**（从 2x 起步往下试）；流畅有余再往上加，加到掉帧临界点为止。
- 注意：**开局场景不代表全程负载**，改完设置进游戏跑一段剧情或战斗再下结论。
- 3DS 原生分辨率本来就不高，放大倍数高到超出你手机屏幕的物理像素后就没有额外收益了，别无脑拉满。

## 四、其他值得动的开关

下面这些在不同版本里的叫法可能略有差异，以你手上版本的设置页为准：

1. **硬件着色器**：保持开启（默认开）。关掉它帧数只会更差。
2. **异步 / 后台着色器编译**：开启后新画面的着色器在后台编译，能明显减少游戏进行中「突然卡一下」的现象。有的版本是一个总开关，有的拆成几项，全开即可。
3. **ASTC 解码加速**：3DS 部分贴图用 ASTC 压缩，开启解码加速后这类贴图的加载压力小很多。支持该特性的设备上建议开着。
4. **音频缓冲**：偶发爆音、声音断续时把它调大；调大的代价是声音延迟变高。它不是性能开关，别为了帧数去动它。
5. **禁用右眼渲染（Disable Right Eye Rendering）**：官方 2120 加的性能开关。原理是 3DS 即使关掉裸眼 3D 也在同时渲染左右眼两份画面，这个开关把右眼那份省掉——官方更新说明里给的数字是**部分游戏性能提升可达 50%**。代价是个别游戏会出画面异常，所以逐游戏开着试；想确认它真的生效，可以开立体并排显示模式，看右眼画面是不是已经被禁用。出了画面问题的，去 [常见问题与报错处理.md](常见问题与报错处理.md) 对号入座。

## 五、双屏布局与触控

3DS 的操作面是「上屏看画面 + 下屏触控」，安卓版默认把两块屏摆在一块物理屏上：

- **布局**：设置里可以选上下堆叠或左右并排，按横竖屏习惯选；有的版本还允许调两块屏的大小比例与位置，把下屏缩小一点、上屏放大的组合最适合多数游戏。
- **触控**：下屏直接用手指点即可，无需额外配置。
- 部分游戏对布局敏感（下屏按键要一直盯着），进游戏后按实际观感微调，比在设置页里空想快得多。

## 六、帧数不稳时按顺序排查

1. 降内部分辨率（第三节）。
2. 换图形 API（第二节）。
3. 关掉放大相关的附加效果（纹理过滤之类的选项，逐个关、对照帧数）。
4. 清后台、注意机身发热降频；发热降频的掉帧发生在游戏进行一段时间后，和「一进来就卡」是两回事。

按顺序做完还是不稳的，大概率是设备档次或该游戏兼容性的问题——先回 [游戏文件格式与添加方法.md](游戏文件格式与添加方法.md) 查兼容性列表，再对照 [常见问题与报错处理.md](常见问题与报错处理.md) 排查其他原因。
