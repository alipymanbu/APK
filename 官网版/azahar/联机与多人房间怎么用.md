## 一、先对版本：这份 2122-alpha1 的安卓版没有房间功能

把丑话说在前面：**安卓版的多人房间系统是官方 2126.0（2026 年 8 月正式版）才加进去的**，本文对应网盘里这份 2122-alpha1 的安卓版**没有**这个功能，具体版本线以官方更新日志为准。想用安卓联机，需要照 [下载与安装教程.md](下载与安装教程.md) 的渠道换成 2126 及以上的正式版。

桌面版（Windows / macOS / Linux）的多人房间是 Citra 血统里一直延续下来的，早在 2122 这个版本线上就能用。

## 二、桌面版怎么联机

桌面版菜单里有 Multiplayer（多人）入口，三条路：

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| 浏览公开房间 | 打开公开房间列表，选一个加入 | 蹭陌生人的局 |
| 创建房间 | 自己开房间，把房间信息给朋友 | 和固定朋友玩 |
| Direct Connect（直连） | 直接填主机 IP 和端口进入 | 有自建服务器或朋友开房 |

背景知识：Citra 官方的联机服务器 2024 年就关闭了，所以「公开房间列表」依赖的是社区第三方服务，不是官方基础设施——这也是下一节风险提示的由来。

## 三、安卓版房间怎么用（2126 及以上）

官方给安卓版的房间功能和桌面版对齐：

1. **搜索公开房间**并加入；
2. **创建私密房间**，只把房间信息发给朋友；
3. **内置聊天**，进房后可以直接打字沟通。

官方说明的硬限制有两条：**连不上真实的 3DS 主机**（模拟器之间互连而已），也**不支持附近安卓设备直接无线互联**。网络条件只有一种：同一房间里的设备**都在同一个 Wi-Fi 下，或都用同一个热点**。

## 四、公开房间列表要自己配地址（重点看这里）

Azahar 到现在**没有官方的房间服务器列表**。想看到公开房间，要自己在配置里填一个第三方 web API 地址——社区里流传的地址都是个人或小团体搭的，意味着：

- **不要在任何这类服务里输入账号、密码或任何凭据**；
- 这些地址多为 HTTP 明文传输，可用性随时可能归零，失效了不是你的问题；
- 流传地址多来自论坛帖子（用户反馈级别），本篇不代填具体地址，自行甄别。

**最稳的做法是绕开公开房间**：一个人建私密房间，把直连信息发给朋友，全程不经过任何第三方列表服务。

## 五、联机前先确认两件事

1. **游戏本身支持无线联机**才有后面的事。个别游戏在模拟器上的联机功能本身就不完整，先到官方兼容性列表查这个游戏的状态（见 [游戏文件格式与添加方法.md](游戏文件格式与添加方法.md) 第四节）。
2. **同一房间的人用同一版本的游戏**，版本或区域不一致会有人进不了房。联机过程中游戏异常的，先看 [常见问题与报错处理.md](常见问题与报错处理.md)，再怀疑网络。
