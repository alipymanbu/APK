## 一、离线能玩到什么程度

这个应用的卖点就是「不需要网络」：装好之后，游戏本身在你的手机上运行，开局、操作、存分数都不走网络，所以飞行模式、地铁隧道、没有信号的房间里都能正常玩。官方商店描述也把它定位成飞行、通勤、旅行场景下的消遣工具。

离线状态下**不能**做的主要是这些联网相关的事：

| 操作 | 需要网络吗 |
| --- | --- |
| 打开应用、玩各类小游戏 | 不需要 |
| 查看已保存的分数与进度（存在本机） | 不需要 |
| 购买内购项目（如去广告） | 需要 |
| 加载广告（如有在线广告位） | 需要 |
| 从应用商店更新到新版本 | 需要 |

## 二、出行前的准备清单

出发前在有网的环境下把这几步做完，路上就不会翻车：

1. **装好应用**（步骤见[下载与安装教程.md](下载与安装教程.md)）。
2. **联网打开一次**，让首屏内容与各游戏入口正常加载完，别装完直接断网首开。
3. **开飞行模式实测**：断掉 Wi-Fi 与移动数据，挑 2~3 个你打算在路上玩的游戏各开一局，确认能正常进入、能正常操作。
4. **确认电量与存储**：留够电量；确认手机还有可用空间（应用装完后本机占用高于 112.85 MB 的安装包体积）。
5. 想玩最新版本的话，**出行前先更新**，避免路上想装新游戏却没网更新。

## 三、断网时广告是什么表现

这个应用免费下载，**含广告，也有付费内购**（其中包括去广告类购买，价格以商店页面当时显示为准）。有第三方指南提到：断网状态下广告请求拿不到返回，广告可能加载不出来，而游戏本身照常进行 —— 也就是说飞行模式下你大概率只会看到游戏，看不到在线广告。这只是一条第三方观察，不是官方承诺，别把它当成「永久去广告」的手段；想要稳定的无广告体验，正规途径是应用内的付费去广告。

另外注意：**内购买必须联网才能完成**，别在飞行模式里点购买，会直接失败。

## 四、几个适合离线玩的场景

- **航班与高铁**：起飞前装好测好，途中玩数独、纸牌、2048 这类不依赖反应的棋盘游戏最稳。
- **地铁通勤**：隧道里信号断续，玩本机运行的游戏不会卡在加载页；选贪吃蛇、井字棋这种短局，到站随时放下。
- **信号死角**：候诊室、山区、地下室，只要手机有电就能玩。
- **省流量**：游戏过程不走网络流量；只有广告与内购会用到数据，介意的话可以在系统里单独给该应用关掉移动数据权限（购买内购、检查更新时再打开）。
