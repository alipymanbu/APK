## 一、先搞清楚谁在扣你的钱

应用内购买的订阅**不由应用自己扣款**，而是由你下载它的商店代收：账单上显示 `APPLE.COM/BILL` 就是走的 App Store，显示 `GOOGLE` 就是走的 Google Play。先打开账单看清这两者，后面所有操作都在对应的商店里做——在应用里翻是翻不到取消按钮的。

## 二、在哪取消

- **iPhone（App Store 计费）**：`设置 → 点顶部你的名字 → 订阅 → 找到 niji・journey → 取消订阅`。
- **Android（Google Play 计费）**：`Google Play → 点头像 → 付款和订阅 → 订阅 → 找到它 → 取消`。
- 取消后页面会显示到期日——**当前已付费的周期内服务照常可用，到期才停**，这是正常的，不是没取消成功。
- 两条容易踩的坑：
  1. **删掉 App 不等于取消订阅**——卸载只移除图标，商店侧的扣款照旧；
  2. 取消时留一张订阅状态页的截图，写着「已取消 / 到期日」的那张，日后有争议就是凭据。

## 三、取消了还在扣款

按这个顺序查：

1. 先确认取消真的生效了：回到商店的订阅页看状态，显示「已取消」才算数；只记得自己点过几下、没见到确认，就再取消一次并截图。
2. 取消**当期**仍会看到一笔扣款记录属正常——订阅在周期开始时收费，你取消的是下一期。
3. 如果**取消日期之后又产生了新一期扣款**，说明上一次取消没提交成功：在订阅页重新取消，同时对那笔扣款发起退款（下一节）。
4. 账单上出现了你不认识的金额，先核对是不是家里人或别的账号用同一张卡支付的。

## 四、申请退款

退款同样走商店，不由应用方直接处理：

- **App Store**：在苹果的「报告问题」页面（`reportaproblem.apple.com`）用 Apple ID 登录，找到那笔订单，选相应理由提交；结果与到账时间以苹果的回复为准。
- **Google Play**：`头像 → 付款和订阅 → 预算和订单记录 → 找到该订单 → 报告问题`，填明情况提交。

提交时把话说清楚：**哪天扣的款、哪天取消的、为什么认为不该扣**，并附上取消状态的截图。各商店对可申请退款的时间窗有各自规定（一般以扣款后 90 天上下为常见口径，以商店当时显示为准），越早提越好。

## 五、商店不处理时

1. 先在应用的官方帮助中心（[nijijourney.com/help-center](https://nijijourney.com/help-center)）发工单说明，附订单号与截图——有书面记录，后面每一步都用得上。
2. 协商无果，再向发卡银行发起交易争议（拒付）：向银行说明「取消后仍被扣款 / 未授权这笔消费」，提供取消截图与沟通记录。这是最后手段——部分服务会对发起拒付的账号做限制，先走完前两步再考虑。

## 六、取消之后账号还在吗

取消只停扣款，不删账号：你的登录方式、已生成的图片记录都跟账号走（见 [订阅价格与免费次数.md](订阅价格与免费次数.md) 第四节），到期后重新订阅即恢复原档位。想先看看自己还剩多少免费额度与档位差别，回那篇第一节、第二节对照。
