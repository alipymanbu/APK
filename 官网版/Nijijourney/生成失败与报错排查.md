## 一、先分清是哪一类

| 你看到的现象 | 更可能是哪类问题 | 先做什么 |
| --- | --- | --- |
| 提交后弹出 `Action needed to continue` | 提示词被内容审核拦下 | 改提示词（见第二节） |
| 弹 `Internal server error` | 服务端失败（过载 / 维护） | 查状态页后等待（见第三节） |
| 一直 `Waiting to start` 不动 | 高峰排队 | 等一轮或取消重投（见第四节） |
| 以前很快、突然变慢 | 快速时间用尽 | 查订阅额度（见第五节） |
| 完全没反应、连报错都没有 | 本机网络 / 客户端 | 按 [常见问题与排查.md](常见问题与排查.md) 走 |

## 二、`Action needed to continue`：提示词被拦了

这是内容审核对你的提示词判了「需要修改」，任务没有开始，也不扣次数。处理顺序：

1. 把提示词里可能触发判定的描述改掉——通常是某个词与人物描述的组合让人物年龄或内容判定出问题，拆开重写最直接。
2. 有教程提到提示下方有 `Appeal`（申诉）入口，点了会交给更高级的判定再看一次；反复被拦时别耗在这，直接改词更快。
3. 改完先用一句最简单的描述试水（主体 + 场景，不带复杂修饰），通了再换回完整提示词。

注意：这里要做的是把描述改得正常、清楚，不是想办法绕开审核——绕的写法既违反服务条款，也大概率过不去。

## 三、`Internal server error`：先查是不是服务端的锅

这类报错的意思是「请求送到了，但服务端没处理完」，多数与你的账号和提示词无关，常见于访问高峰或维护窗口。顺序：

1. 打开官方状态页 [status.midjourney.com](https://status.midjourney.com/) 看有没有进行中的事故；Discord 版也可以看官方服务器里的 #status 频道。
2. 状态页显示有事故 → 什么都不用改，等 10~30 分钟再试；这时候反复重试只会一直失败。
3. 状态页正常 → 换一句极简提示词提交一次。极简的能出、原来的不能，问题才在提示词本身；极简的也失败，就是这一时段的服务问题，继续等。

## 四、卡在 `Waiting to start`

高峰时段的排队状态，多数等一会自己会开始。等得不耐烦可以取消这次任务重新提交，有时比干等快——取消方式：

- Discord 版：给那条任务消息加反应，搜 `x` 选红色叉号即可取消。
- App / 网页版：在任务处找取消入口后重投。

反复提交同一个任务不会让你插队，反而可能让队列里堆好几个同名任务，取消干净再投一次就好。

## 五、以前秒出、现在一直慢

八成是**快速生成时间用尽**：订阅里含的快速时长按月发放，用完后当月进入慢速队列，慢到一定程度看起来就像失败。确认与处理：

1. Discord 版可在任意频道发 `/info`，看剩余快速时长是不是 0。
2. 是 0 → 要么等下个计费周期重置，要么单买 Fast Hours，规则见 [订阅价格与免费次数.md](订阅价格与免费次数.md) 第三节。
3. 不是 0 → 回到本篇第一、三节，按报错类型处理。

## 六、Discord 版机器人完全不响应

按顺序排除：

1. 先看 [status.midjourney.com](https://status.midjourney.com/)，服务故障时机器人就是不响应，等即可。
2. 确认机器人在你的服务器里有发言与使用应用命令的权限（缺了它，`/imagine` 会直接没反应）。
3. 完全退出 Discord 重开（网页版则关标签页、清缓存后再进），再发一次最简单的提示词。
4. 只有你的服务器不响应、别处正常 → 把机器人移除后从官方邀请重新添加一次。

## 七、什么时候不用折腾

报错只出现一两次、换台设备或换个时段就好了的，属于临时抖动，不用记。真正要跟进的是：同一提示词每次都失败、或状态页持续红——前者按第二节改词，后者等官方恢复即可；都试过还卡着，走 [常见问题与排查.md](常见问题与排查.md) 第三节的官方帮助中心入口提工单。
