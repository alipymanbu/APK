## 一、参数在哪输

三个入口的输入方式不一样，别拿错了地方：

| 入口 | 参数怎么给 |
| --- | --- |
| 手机 App | 图形界面点选（风格、比例、参考图都有对应按钮），不手写参数 |
| Discord | `/imagine` 后面接提示词，参数追加在提示词末尾 |
| 网页版 | 顶部输入框直接写提示词 + 参数，**不用**打 `/imagine` 前缀 |

下面的写法适用于 Discord 与网页版；在 Midjourney 本体里想调用 Niji 模型，末尾还要加 `--niji 7`，而 niji・journey 侧默认就是 Niji 模型，不用加。

## 二、常用参数速查

| 参数 | 作用 | 常用值 |
| --- | --- | --- |
| `--ar` | 画面比例 | `1:1`、`3:4`、`16:9` |
| `--s` | 风格化强度 | 低更贴字面，高更有画感，默认 100 |
| `--sw` | 画风参考的权重 | 0~1000，默认 100；300~500 反明显 |
| `--sref` | 指定画风（图片链接或数字代码） | `--sref 123456789` |
| `--cref` | 指定角色（用已有角色图） | 跟一张角色参考图 |
| `--niji` | 切 Niji 版本（仅在 Midjourney 侧需要） | `--niji 7` |

## 三、画风代码（sref code）怎么用

画风代码是一串数字，把「某种色感、线条与质感」打包成一个编号，最大的用处是**可复现**：

1. 看中一张图的画风，记下它的 sref 代码；下次换题材时在提示词末尾写 `--sref 那串数字`，出来的东西会回到同一套画风上。
2. 想随机探索新画风，教程站给的写法是 `--sref random`——每次分配一个随机代码，翻到喜欢的把它记下来。
3. 画风太淡就调 `--sw`：默认 100 只是轻描淡写，200~500 明显加深，0 等于关掉画风参考。
4. **同一串代码在 niji・journey 与 Midjourney 出的效果并不一样**——前者往动漫插画偏、后者往写实偏，别把别处抄来的代码预期原样套。
5. 记录自己的代码时连同提示词一起存：同一代码配不同提示词，画面质感一致但内容照常随提示词走。

## 四、角色参考与画风参考的区别

- `--cref` 管「**这是谁**」：给一张角色图，让后续出图沿用这个角色的长相与服装设定。
- `--sref` 管「**什么画风**」：只影响色彩、线条、质感，不锁定人物。
- 想让系列图既同人又同风，两个一起给，提示词其余部分保持一致。
- 效果边界要有预期（有实测教程的结论）：发色、瞳色、服装样式、体型这类**设计层面**的元素跨图保持得不错；精确到痣、疤痕、微妙表情的**身份级完全一致**，单靠参数达不到，得靠后期修图或多抽几张挑。

## 五、参数「写了没效果」的排查

按这条顺序过一遍，多数能对上：

1. **版本太老**：画风参考至少要 Niji V6 之后的模型才识别，老版本会直接忽略它。当前版本见 [和Midjourney的区别.md](和Midjourney的区别.md) 第二节。
2. **权重太低**：`--sw` 停在默认 100 时效果本来就淡，先往上加到 300 再判断有没有生效。
3. **只有图、没有文字**：有教程指出，提示里一张文字都没有时画风参考不参与生效——留一句文字提示。
4. **参考链接失效**：Discord 里传的图，其链接放久了可能打不开；用到的参考图尽量选近期的，链接打不开就重新上传取新链。
5. **排除法**：先去掉所有参数只留一句话出图，通了再一个个加回去，加到哪个开始失效就是哪个的问题。

都排完还是不对，多半是这一时段的服务问题，转 [生成失败与报错排查.md](生成失败与报错排查.md) 第三节。
