# 不用安装器怎么手动装

> 图形安装器在你的机器上跑不通时，用电脑 + adb 把官方二进制推进去的完整步骤。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [装好后命令不生效的排查.md](装好后命令不生效的排查.md) · [常用命令速查.md](常用命令速查.md)

> **BusyBox 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/eb2f313d9c4a](https://pan.quark.cn/s/eb2f313d9c4a)

## 一、什么时候走这条路

三种情况值得换这条路线：

- 安装器界面在你的机型上打不开、或点 INSTALL 没反应（先按 [装好后命令不生效的排查.md](装好后命令不生效的排查.md) 排一遍，仍不行再走这里）；
- 你要一次给好几台设备装，电脑上用 adb 批量做更快；
- 你想要的版本和安装器里提供的对不上。

动手前的条件：手机已 root（终端里 `su` 能进）、电脑装好 adb、手机打开 USB 调试。

## 二、先认准 CPU 架构

选错架构是这条路最常见的翻车点，装之前先查：

```sh
adb shell getprop ro.product.cpu.abi
```

| 返回值 | 对应机型 | 二进制怎么选 |
| --- | --- | --- |
| `arm64-v8a` | 现在绝大多数手机 | 优先 arm64 版；没有就用 armv8l |
| `armeabi-v7a` | 老一点的 32 位 ARM 机 | armv7 或 armv5l 版 |
| `x86_64` / `x86` | 少数机型与部分模拟器 | 对应 x86 版 |

官方 [FAQ](https://www.busybox.net/FAQ.html) 给的起步建议是：armv4tl 是最通用的 arm 版本，x86 的 `busybox-i686` 通常 32/64 位都能跑。二进制下载入口在 [busybox.net 的 binaries 页面](https://busybox.net/downloads/binaries/)，具体有哪些文件名以官网当时显示为准。

## 三、推进去、装上

```sh
# 1. 把二进制送到手机
adb push busybox-armv8l /sdcard/busybox

# 2. 进 shell 拿 root
adb shell
su

# 3. 放到目标目录（换成你要装的路径）
cp /sdcard/busybox /system/xbin/busybox

# 4. 给执行权限，再用它自己铺开所有命令链接
chmod 755 /system/xbin/busybox
/system/xbin/busybox --install -s /system/xbin
```

两个要点：

- 官方发布的预编译二进制是**静态链接**的（官方 FAQ 原话），不依赖手机系统里已有的库 —— 所以只要架构选对，就能直接跑。
- 第 3 步报 `Read-only file system` 时**换个可写目录重来**，不要照老教程去 remount 分区，原因与处理见 [装好后命令不生效的排查.md](装好后命令不生效的排查.md) 第五节。

装完在 shell 里敲 `busybox`，能看到命令清单就成功了；命令名直接敲不灵的话，按 [装好后命令不生效的排查.md](装好后命令不生效的排查.md) 第三节补链接。

## 四、和走安装器的方式差在哪

装进系统的东西是一样的 —— 同一个程序、同一批命令链接，装完的用法完全一致（见 [常用命令速查.md](常用命令速查.md)）。差别只在过程：

| | 安装器（app） | 手动（adb） |
| --- | --- | --- |
| 选版本 | 界面里下拉选 | 自己去官网挑文件 |
| 挑命令 | 勾选框里点 | 全装，或装完自己删 |
| 卸载 | 应用里一键 | 自己删链接 |
| 出错时 | 有界面反馈 | 全看终端报错 |

手动方式建的链接，清理也要自己来 —— 先看哪些链接指向它，再逐个删：

```sh
ls -l /system/xbin | grep busybox
rm /system/xbin/列表里看到的那个名字
```

删完再敲一次 `busybox`，确认没残留；拿不准哪些建议先只删一个试水。
