## 一、动手之前先确认三件事

BusyBox 是一个把几百条 Linux 命令打包在一起的工具，你在手机上装好它，就能在终端里用上 `vi`、`grep`、`wget` 这些安卓本身没提供的命令。它不是点图标操作的软件，装完之后的用法全在终端里，具体能敲什么看 [常用命令速查.md](常用命令速查.md)。

动手前先确认三条：

- **手机已经 root**。这个应用一启动就会申请 root 授权，没 root 的机器装上了也做不了任何事。
- **手上有一个能开 root 的终端应用**，装完的验证步骤要在里面敲命令。
- **系统版本达标**：这份安装包标注要求安卓 5.2 以上，实际能不能装以安装器在你手机上的提示为准。

另外分清两件事：这个应用是**安装器**（作者 Stericson），BusyBox 本体是另一个开源项目，官网在 [busybox.net](https://www.busybox.net)。你装的是前者，它负责把后者放进系统。

想确认文件完整，可以在电脑上算一次 MD5 再比对（Windows 自带工具一行就够）：

```powershell
certutil -hashfile BusyBox_v71.apk MD5
```

## 三、安装步骤

1. 把 APK 拷到手机点开安装；系统若提示「禁止安装未知应用」，允许这一次即可。
2. 打开应用，第一次启动会弹 root 授权请求，点允许；你的 root 管理器若提供「永久允许」，建议勾上，省得每次都要点。
3. 主界面上选 **BusyBox 版本**与**安装路径**。路径默认多为 `/system/xbin`，不熟悉就保持默认。
4. 点 **INSTALL**，等进度走完。Pro 版还能手挑要装哪些命令（applets），只想装一部分就在勾选列表里去掉不要的。
5. 打开终端做一次验证，见下一节。

## 四、验证装没装成功

在终端里敲：

```sh
busybox
```

输出开头是 `BusyBox v…` 并跟着一长串命令名，就说明装好了。如果回的是 `command not found`，别急着重装，多半是链接没建好或路径没进 PATH，按 [装好后命令不生效的排查.md](装好后命令不生效的排查.md) 逐条过一遍。

也可以直接看文件在不在（路径换成你第三步选的那个）：

```sh
ls -l /system/xbin/busybox
```

## 五、换版本或卸载

Pro 版自带卸载功能。想换安装路径、或者怀疑装残了，先在应用里点卸载清掉旧链接，再重装一次 —— 新旧链接混在一起是后面命令行为诡异的常见来源，处理办法同样在 [装好后命令不生效的排查.md](装好后命令不生效的排查.md) 里。
