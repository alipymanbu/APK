## 一、两种敲法，先选一种

安装器把命令链接好之后，你可以直接敲命令名：

```sh
grep "error" /data/log.txt
```

也可以加 `busybox` 前缀：

```sh
busybox grep "error" /data/log.txt
```

两种的区别在「用哪一份」：你手机系统自带了一套精简命令，BusyBox 装进去的是另一套，两份都在时谁先被找到就用谁。**加前缀就等于强制用 BusyBox 这份**，行为可预期；不加前缀则是「系统没有就用它、有就用系统的」。你自己敲命令时随意，写进脚本里建议加前缀，理由见 [shell脚本里怎么调用它.md](shell脚本里怎么调用它.md)。

## 二、按用途分组的常用命令

| 用途 | 命令 |
| --- | --- |
| 文件操作 | `ls` `cp` `mv` `rm` `mkdir` `cat` `find` `ln` `du` `df` |
| 文本处理 | `grep` `sed` `awk` `cut` `sort` `head` `tail` `tr` `wc` `vi` |
| 网络 | `wget` `ping` `netstat` `ifconfig` `nslookup` `nc` |
| 进程与系统 | `ps` `kill` `killall` `top` `free` `mount` `chmod` `chown` `id` `uname` |
| 压缩与校验 | `gzip` `gunzip` `tar` `md5sum` `sha1sum` |

这只是你会用到的那部分，完整的清单敲一次 `busybox` 就能看到 —— 它会把这份二进制里所有命令名列出来，通常有几百条。

## 三、每个命令怎么查用法

几乎每个命令都带 `--help`：

```sh
busybox vi --help
busybox wget --help
```

要注意这些是**精简版实现**：选项比 GNU 版少，但保留下来的那批用法与 GNU 基本一致。你从 Linux 教程里抄来一个选项却报 `unrecognized option`，先查 `--help` 看这条支不支持，别默认它和电脑上一样全。

## 四、几个用得上的实际例子

```sh
# 找文件
find /sdcard -name "*.apk"

# 给脚本加执行权限
chmod 755 /data/local/tmp/script.sh

# 核对文件指纹
md5sum /sdcard/BusyBox_v71.apk

# 直接下载一个文件
wget -O /sdcard/demo.txt https://example.com/demo.txt

# 批量替换文本内容
sed -i 's/old/new/g' /data/local/tmp/config.txt

# 截取日志里带关键字的那几行
grep -n "Exception" /data/log.txt
```

`wget`、`vi`、`sed` 这几个是安卓原生不带的，也是很多人装这套工具的直接原因；系统自带命令缺什么、和它怎么选，见下一节。

## 五、和手机自带命令的关系

安卓系统自带的命令集只覆盖基础的文件与进程操作，`vi`、`wget` 这类通常没有；装好 BusyBox 之后这些才有。反过来说，自带那份永远在 PATH 里，不会因为你装了它就消失 —— 所以偶尔会出现「同一个命令名，行为和教程里不一样」的情况，处理办法在 [装好后命令不生效的排查.md](装好后命令不生效的排查.md) 里讲。
