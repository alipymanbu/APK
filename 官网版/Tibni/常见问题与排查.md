## 一、安装与启动

| 现象 | 先做什么 | 还不行再做什么 |
| --- | --- | --- |
| 安装时提示解析失败 / 包损坏 | 校验 MD5 是否为 `23260b2e8484dc68b6ef6dc524472c00` | 重新下载安装包，见 [下载与安装教程.md](下载与安装教程.md) |
| 安装被系统拦截 | 允许当前来源安装未知应用 | 卸载同包名旧版本后重装 |
| 打开即闪退 | 清一下后台、重启手机 | 到系统设置 → 应用 → Tibni → 存储，清缓存后重开；还不行就重装（重装不丢账号，只丢本机草稿） |
| 打开白屏转圈 | 切换 Wi-Fi 与移动数据各试一次 | 网络本身能开网页的话，稍后再试，可能是服务端波动 |
| 一直停在协议页 | 重新点同意 | 强杀应用重开一次 |

闪退有一个与安装包直接相关的诱因：**文件没下完整**。如果你跳过了 MD5 校验直接安装，出现闪退第一件事就是回头校验（方法在 [下载与安装教程.md](下载与安装教程.md) 第二节）。

## 二、登录与验证码

收不到验证码、注册失败的完整排查在 [注册登录与收不到验证码怎么办.md](注册登录与收不到验证码怎么办.md)，核心四条：查信号与网络 → 查短信权限与拦截箱 → 重新发送 → 换手机号或改用邮箱注册。登录后发现作品、关注不在了，先确认当前登录的账号是不是你原来那个（换过手机号或第三方登录入口的，容易登错号）。

## 三、拍摄与剪辑

- **调不起相机 / 相册**：权限没给。系统设置 → 应用 → Tibni → 权限，把相机、麦克风、存储（照片和视频）全部设为允许，然后强杀应用重开。
- **导入素材卡、预览掉帧**：素材太长或分辨率太高（如 4K 长片）而手机性能不足。先剪短片段，或降低预览清晰度；导出时再拉满画质，思路见 [视频剪辑与导出教程.md](视频剪辑与导出教程.md) 第四节。
- **导出失败 / 相册里找不到成品**：多半是导出中途切走或锁屏被系统杀了后台。重新导出一次，导出时保持应用在前台；仍失败就检查存储空间是否不足。
- **音乐/音效加载不出来**：这类素材要在线拉取，网络不通就换网络；本地已下载的素材不受影响。
- **字幕识别不准**：如果这个版本提供自动字幕，环境噪音大、语速过快都会拉低识别率，先降噪再识别，识别完手工改错字；没有自动字幕就手动加。

## 四、发布与播放

- **上传的视频播放不流畅**：先排查网络——网络不稳会导致加载延迟，切到 Wi-Fi 重新上传或稍后重试；其次确认视频格式与大小符合应用要求（以发布页的提示为准）。
- **发布按钮点不了**：多半是还有必填项没完成（标题、话题、可见范围），或者正在导出/上传中没结束，看页面顶部的进度提示。
- **作品发布后自己都搜不到**：先看可见范围是不是选成了「仅自己」或「仅粉丝」，见 [发布作品与可见范围设置.md](发布作品与可见范围设置.md) 第三节；范围没问题就去创作者中心看是否审核中。
- **播放数据异常低**：在创作者中心看播放来源构成，「推荐页」占比过低，说明这条基本没进推荐，可以从话题标签、封面、开头几秒的留存这三处入手，调整后发下一条验证。

## 五、什么时候该重装、什么时候不该

| 情况 | 建议 |
| --- | --- |
| 闪退、白屏，清缓存无效 | 重装。账号数据在服务端，重装不丢；**本机剪辑草稿会丢**，先确认有没有要保的草稿 |
| 只是某功能报错 | 不要重装，先查权限与网络，按上面对应小节处理 |
| 安装包版本与网盘不一致 | 以 [下载与安装教程.md](下载与安装教程.md) 表格里的版本与 MD5 为准，别混装两个来源的包 |

以上排查步骤覆盖了装不上、用不了、发不出三类高频场景。仍解决不了的问题，多数与账号状态或服务端有关——这类只能等官方侧处理，本地反复重装没有帮助。
