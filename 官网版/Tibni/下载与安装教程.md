## 一、先确认拿到的是哪个版本

Tibni 是一个集「短视频观看 + 拍摄剪辑 + 发布分享」于一体的手机应用，安卓端与 iOS 端是两套包。下面这份教程针对的是**安卓安装包**，网盘里放的就是它，核心事实如下（以这份文件为准，网上搜索到的「最新版」可能不是同一个）：

| 项目 | 数值 |
| --- | --- |
| 版本号 | 1.0.0 |
| 包名 | `com.pousf.awq` |
| 安装包大小 | 185.75M（约 194,772,945 字节） |
| MD5 | `23260b2e8484dc68b6ef6dc524472c00` |
| 文件名 | `Tibni_v1.0.0.apk` |

有第三方下载站标注系统要求为安卓 4.5 以上，官方渠道没有公布过最低系统版本——你的手机能不能装，最终以安装时系统的提示为准。安装前先确认手机还有 500M 以上的可用空间：安装包本身 185.75M，解压安装还要再占一份。

## 二、从网盘拿到安装包

1. 打开 [Tibni 安装文件资源（夸克网盘）](https://pan.quark.cn/s/87d2716b954a)，登录你的夸克账号（没账号用手机号注册一个即可）。
2. 进入 `Tibni（先保存再下载）` 文件夹，里面是 `Tibni_v1.0.0.apk` 和一个 `先保存再下载避免失效.txt` 说明文件。
3. 选中 apk 点「保存 / 转存」，把它存进你自己的网盘空间。
4. 在手机上打开夸克 App，在网盘里找到这个文件，选择「下载到本地」。
   - 包比较大（185.75M），建议在 Wi-Fi 下下载，中途断了可以继续，不用重头来。
5. 下载完成后**先别急着点开**，先做一步校验（可选但推荐）。

### 校验文件有没有下完整

安装包下载中断是最常见的安装失败原因，MD5 对得上就说明文件完整无损。在电脑上校验：

```powershell
# Windows PowerShell
Get-FileHash .\Tibni_v1.0.0.apk -Algorithm MD5
```

```bash
# macOS / Linux
md5sum Tibni_v1.0.0.apk
```

输出应为 `23260b2e8484dc68b6ef6dc524472c00`（大小写不敏感）。对不上就删掉重新下载。

> 如果你是在手机上直接下载的，也可以用文件管理器查看文件大小是否接近 185.75M，明显偏小说明没下完。

## 三、安装

安卓默认不允许安装「未知来源」的应用，所以第一次装 apk 必须手动放行一次：

1. 在文件管理器或夸克的下载列表里点 `Tibni_v1.0.0.apk`。
2. 系统弹出「禁止安装来自此来源的应用」之类的提示 → 点进去，允许当前这个应用（文件管理器或夸克）安装未知应用。只对当前来源放行即可，不用开全局。
3. 返回安装界面，点「安装」。185M 的包解压安装需要一点时间，进度条别关。
4. 装完可以先点「完成」，回到桌面找图标；也可以直接「打开」。
5. 首次打开会弹用户协议与隐私条款，同意后才能进主界面；随后会连续索要存储、相机、麦克风等权限——**先全部允许**，否则拍摄、从相册导入素材这些功能都用不了（后面随时可以在系统设置里逐项关掉）。

### 安装被拦或装不上的排查

| 现象 | 处理 |
| --- | --- |
| 提示「解析包时出现问题」 | 文件没下完整，回到第二步重新校验并重新下载 |
| 提示「安装包已损坏」 | 同上，MD5 校验大概率对不上 |
| 提示「与已有应用签名不一致」 | 手机里装过同包名的其他来源版本，先卸载旧的再装 |
| 提示「无法安装」且无更多说明 | 多半是系统版本过低或存储不足，先清空间、确认系统版本，以系统提示为准 |
| 装完图标打不开、秒退 | 见 [常见问题与排查.md](常见问题与排查.md) |

## 四、装好之后

装完的第一步是注册或登录账号，才能看完整内容与发布作品，见 [注册登录与收不到验证码怎么办.md](注册登录与收不到验证码怎么办.md)；接着想直接上手剪一条视频，看 [视频剪辑与导出教程.md](视频剪辑与导出教程.md)。

关于包名的说明：`com.pousf.awq` 是这个应用在安卓系统里的唯一标识，升级时系统靠它识别「是同一个应用」。以后你自己核对下载站给的包是不是同一个，对比这个字符串最可靠——名字都可能重复，包名不会。
