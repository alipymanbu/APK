## 一、这条流程能帮你做什么

Tibni 的剪辑功能在应用内的「创作」板块，核心是**视频编辑器**：导入手机相册里的视频，用底部工具栏裁剪、加字幕、配音乐，最后导出成一条成品保存到相册。整个过程不依赖电脑，本篇按实际操作顺序走一遍，另外还会说明拍剪一体的拍摄入口和几类常用工具的用法。

## 二、打开编辑器并导入素材

1. 打开 Tibni，切到**创作**板块。
2. 点**视频编辑器**（同一板块里还有图片编辑、智能拼图、海量模板等入口，别点错）。
3. 第一次使用会弹**权限申请**——允许访问相册/存储，否则选不了素材。拒绝过的话去系统设置里手动打开（设置 → 应用 → Tibni → 权限）。
4. 在素材选择页勾选要剪的视频（可多选），确认导入。

导入后进入编辑界面：上方是预览窗，下方是时间轴和工具栏。素材越长加载越慢，185M 的应用本体跑 4K 长素材时，预览卡顿先怀疑手机性能而不是操作有误。

## 三、底部工具栏里常用的几类工具

按第三方整理的功能说明，编辑器底部提供这些常用能力（界面文案以你的版本为准）：

| 需求 | 用哪类工具 | 要点 |
| --- | --- | --- |
| 去掉多余片段 | 裁剪 / 分割 / 拼接 | 时间轴上把播放头拖到目标位置再切，切错了用撤销 |
| 加文字 | 字幕 / 贴纸 | 版本提供自动识别就先自动打底再手工改错字，比全程手打快 |
| 配音乐 | 音乐 / 音量 / 配音 | 内置背景音乐与音效可直接选；也支持调原声与背景音的音量比例 |
| 换感觉 | 滤镜 / 特效 | 滤镜一键应用，多个片段可以分别设 |
| 调节奏 | 变速 | 支持曲线变速，做卡点、慢动作用它 |
| 画面处理 | 蒙版 / 关键帧 | 局部特效、创意转场用，属于进阶操作 |

**拍剪一体**是这个应用的一个特点：你也可以不先录好再剪，直接在拍摄页边录边用，录完接着进编辑，省去来回跳转。拍摄时长按录制键开始/停止，分段拍摄可以多场景切换。

## 四、导出

1. 剪完点右上角**导出**。
2. 选择分辨率与帧率——**分辨率和帧率调到你想要的最高档**即可，导出画质由这里决定，与你导入素材的原始质量有关。
3. 点**确定导出**，等待进度条走完。
4. 完成后作品自动保存到手机相册，去相册确认一下再决定要不要发。

导出时别锁屏、别切走应用；大文件导出过程中被系统杀后台是「导出失败/文件找不到」的常见原因，遇到就重新导一次（见 [常见问题与排查.md](常见问题与排查.md)）。

## 五、几条让成品更稳的经验

- **先导出、再发布**：把成品先存相册，发布失败或要改文案时不用重剪一遍。
- **同一首音乐别拉满音量**：背景音乐压过人声是最常见的废片原因，导出前在预览里完整听一遍。
- **注意素材来源**：转发来的视频可能带别人平台的水印，剪之前先看一眼四角。
- **中途存草稿**：复杂剪辑分几次做的话，退出前确认草稿已保存；草稿只存在本机，不跨设备同步（换机前先导出成品，见 [注册登录与收不到验证码怎么办.md](注册登录与收不到验证码怎么办.md)）。

剪完想把作品发出去、控制谁能看到谁能评论，接 [发布作品与可见范围设置.md](发布作品与可见范围设置.md)。
