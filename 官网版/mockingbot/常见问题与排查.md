# 墨刀 常见问题与排查

> 按现象查：打不开 / 连不上服务器、登录不上、项目列表是空的、离线演示打不开、闪退，以及去哪问。

## 一、打不开 / 连不上服务器

官方帮助中心给了一套按顺序排查的办法，从命中率最高的开始：

1. **先判断是不是网络问题**：用浏览器（推荐 Chrome）打开墨刀网页版。网页版能开、只有 App 打不开，多半是本机网络不稳定，换网络或等 20 分钟再试。
2. **关掉网络代理 / VPN**：开着代理时 App 经常连不上服务器，**完全关闭**后再打开 App。
3. **改 DNS**：把设备 DNS 改成 `114.114.114.114` 或 `8.8.8.8` 再试，手动改 DNS 的步骤在系统设置里搜"DNS"即可。
4. **换网络**：Wi-Fi 换流量、或连手机热点试一次；能开就说明是原来那套网络的问题。

## 二、卡在启动界面 / 一打开就闪退

- **卡在"正在打开"这类启动界面**：多为缓存问题。先清 App 缓存（**只清缓存、不要清数据**，清数据会把离线缓存一起删掉），再重开；不行就重启手机。
- **一打开就闪退**：清缓存 → 重启手机 → 确认存储余量充足 → 卸载重装。重装前记好账号，项目都在云端，重装不会丢。
- **装的时候被系统拦住**：提示"未知来源被禁止"，回到 [下载与安装教程.md](下载与安装教程.md) 第四节，给对应的应用打开安装权限。

## 三、登录后项目列表是空的 / 少了项目

按这个顺序查，命中率依次降低：

1. **账号对不对**：手机 App 登录的账号，是否与电脑端建项目时用的**完全同一个**（同一个手机号 / 微信 / 邮箱）。用微信注册的号和用手机号注册的号是两个号，墨刀不会自动合并——绑定与合并办法见 [账号注册与登录方法.md](账号注册与登录方法.md) 第二节。
2. **服务器选对了没**：如果登录页有服务器选项，选错服务器进去就是空工作台，不同服务器的账号体系互相独立。
3. **是不是团队项目**：团队文件需要对应的**席位**才能看到与编辑；只有审阅权限或"待分配"的成员，能看到的内容不一样，找空间管理员确认。
4. **下拉刷新一次**：多端同步有延迟，切到别的页面再回来，或重开 App 试一次。

## 四、手机上找不到"离线演示"的开关

离线开关**不在设置菜单里**，而是在预览界面上**双指点击屏幕**调出的设置面板中（见 [手机预览与演示原型.md](手机预览与演示原型.md) 第五节）。另外两点容易踩：

- 没提前在有网时打开过的文件，开了离线也打不开；
- 清了 App 数据或换了手机，离线缓存需要重新加载。

## 五、演示时的几个小问题

- **页面上多出一圈高亮框**：那是"高亮链接区域"。在电脑端工作台选中文件 →「分享」→ 取消勾选「高亮链接区域」即可；手机 App 与微信扫码都跟随这个设置。
- **演示时页面列表碍眼**：点运行界面右上角的「全屏模式」把它收起来。
- **微信里扫码或点链接没反应**：换成手机浏览器打开分享链接再试，微信内置浏览器对部分页面支持有限。
- **别人说分享链接打不开**：先确认你**没有关掉链接权限**——默认分享的链接一旦被关掉会立刻失效，高级分享的链接被删除也会失效；如果设了密码，对方需要先输密码。这些开关的位置见 [分享链接与权限设置.md](分享链接与权限设置.md) 第二、五节。

## 六、还有问题去哪问

- **帮助中心**：[modao.cc/hc](https://modao.cc/hc)，账号、服务器异常、付费、发票都有专门条目
- **在线客服**：工作台右下角的问号入口，或官网底部的在线客服
- **官方邮箱**：`support@modao.cc`

找客服前把这些备齐：账号（手机号 / 邮箱）、问题发生的时间、设备型号与系统版本、报错截图。一次说清，能少一轮来回。
