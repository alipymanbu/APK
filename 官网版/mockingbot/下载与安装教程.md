## 一、先弄清这个安装包装的是哪一端

墨刀（英文名 MockingBot）是在线原型设计与产研协作平台，由北京磨刀刻石科技有限公司开发，2014 年上线，官网是 [modao.cc](https://modao.cc/)。它不止一个端，装错端会白忙一场：

| 端 | 主要用途 |
| --- | --- |
| 网页版 / Windows / macOS 客户端 | 画原型、写 PRD、做流程图与思维导图，是"干活"的那一端 |
| 安卓 / iOS 移动端（本文这份包） | 登录同一账号后，在手机上预览与演示已有项目；v6 起也带了 AI 生成能力 |

也就是说，装了这个 App **不等于**能在手机上从零画完一套原型——主力创作仍在电脑上。手机上这一端适合的场景是：评审时随手把原型拉出来演示、通勤路上用 AI 先起个稿、给客户当面看效果。

## 二、这份包的实际信息（以本地记录为准）

网上能搜到的都是官方最新版，网盘里这份是记录时的那一版，两者常常不是同一个版本号。凡涉及版本、体积、包名，一律以这张表为准：

| 项 | 值 |
| --- | --- |
| 版本 | v6.0.5 |
| 包名 | `com.mockingbot` |
| 大小 | 131.25M |
| MD5 | `55A3507CB4CBE69462E40A5B70AE14B7` |
| 记录时间 | 2026-09-23 |
| 平台 | Android |

131.25M 在工具类 App 里算偏大，因为这一版把 AI 相关能力也打进了安装包，下载和安装过程中都别中途断网。

## 三、装之前要准备什么

- **手机**：Android 系统的手机或平板，能正常联网。
- **存储空间**：安装包本身 131.25M，装完占用比这更大，建议至少留出 500M 余量。
- **账号**：提前准备一个墨刀账号（注册方式见 [账号注册与登录方法.md](账号注册与登录方法.md)）。手机上只承担"看"和轻量编辑，**项目要先在电脑端建好**，这一步别省。
- **系统设置**：因为是从网盘装 APK、而不是从应用商店装，需要临时允许"安装未知来源应用"。

## 四、安装步骤

1. 打开 [墨刀 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b25ef75ec004)，把安装包**转存到你自己的夸克网盘**再下载。直接下分享里的文件，容易因分享失效而中断。
2. 下载完成后先核对 MD5：用手机上的校验工具或文件管理器查看，结果应与 `55A3507CB4CBE69462E40A5B70AE14B7` 一致。不一致就别装，重新下一次。
3. 允许安装未知来源应用：在「设置 → 应用 → 特殊权限（有的机型叫"更多安全设置"）→ 安装未知应用」里，给你用来打开 APK 的那个应用（浏览器 / 文件管理器）打开开关。不同品牌手机的菜单名略有差别，按关键字"未知"找即可。
4. 点开下载好的 APK，按提示安装。
5. 首次启动会申请权限：**存储与网络**必须给；其余（相机、位置等）按实际需要给。给少了会影响后续打开项目和演示。

## 五、装完的第一件事：登录

打开 App 后按 [账号注册与登录方法.md](账号注册与登录方法.md) 登录。**务必用你电脑端建项目时的同一个账号**——换个账号登录，项目列表会是空的。

登录成功后就能看到账号下已有的项目；接下来怎么在手机上打开、演示，见 [手机预览与演示原型.md](手机预览与演示原型.md)。如果安装或首次打开就报错，直接跳到 [常见问题与排查.md](常见问题与排查.md)。

另外提前说一句：**免费版有文件数与页面数上限**，而且导出离线演示包（HTML / 安卓 APK）属于付费功能——如果你装这个 App 是奔着"离线演示包"来的，先看 [免费版与会员权益区别.md](免费版与会员权益区别.md) 再决定要不要付费。
