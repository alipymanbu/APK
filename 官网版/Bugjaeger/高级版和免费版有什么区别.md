# Bugjaeger 高级版和免费版有什么区别

> 本篇讲免费版和完整版（高级版）的差别、两个包装在同一台机器上会怎样、以及怎么确认自己装的是哪一版。

Bugjaeger 在官方商店里是两份独立的包：一份带广告的免费版，一份去广告并且放开若干条数限制的完整版（商店里叫 Bugjaeger® Premium，以下简称完整版）。两者的基础功能一致，差别集中在「次数上限」和几项额外能力上。选错版本本身不影响连接，但会直接影响你能做多少事。

## 一、两个版本怎么区分

| 项目 | 免费版 | 完整版 |
| --- | --- | --- |
| 包名 | `eu.sisik.hackendebug` | `eu.sisik.hackendebug.full` |
| 商店名称 | Bugjaeger（免费版） | Bugjaeger® Premium |
| 广告 | 有 | 无 |
| 获取方式 | 官方商店免费下载 | 官方商店单独售卖 |

判断自己装的是哪一份，不用看图标：进 Android 的「应用信息」页，或者用 Bugjaeger 在另一台设备上查已安装应用列表，看包名最后有没有 `.full` 就行。

## 二、完整版多出来的部分

| 能力 | 免费版的限制 |
| --- | --- |
| 自定义命令数量 | 有限额，完整版不限 |
| 一次交互式 shell 会话里能执行的命令数 | 有限额，完整版不限 |
| 截图数量 | 有限额（完整版也受本机剩余存储限制） |
| 实时录屏 | 完整版可以保存成视频文件 |
| 文件权限修改 | 完整版提供 |
| Wi-Fi 连接时更换端口 | 完整版可在默认 5555 之外指定端口 |

其余功能（Shell、文件管理、日志、进程、包管理、屏幕镜像、fastboot 等）两个版本都有，完整版不是多出一套新功能菜单，而是放开上面这些上限。哪些功能本身就需要 ADB 授权才能生效，见 [免root能做什么不能做什么.md](免root能做什么不能做什么.md)。

商店页只写了哪几项「不限」、哪几项「有限」，**没有给出限额的具体数字**，免费版实际能截多少张、能存多少条自定义命令，以你装上后应用内的提示为准。

## 三、网盘里这份属于哪一版

这次提供的安装包就是完整版：

| 项目 | 值 |
| --- | --- |
| 版本 | 7.0 |
| 包名 | `eu.sisik.hackendebug.full` |
| 大小 | 23.05M |
| MD5 | `552449F49420B8ED1E0C18BA31012459` |

也就是上文表格里那份带 `.full` 后缀的包，在系统里会被识别为完整版，而不是商店里那个免费版。安装后想确认，按第一节的方法看包名即可。获取入口见 **[Bugjaeger 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1be4ae2ef549)**。

## 四、两份包装在同一个主机上会互相抢

这是官方特别提醒过的一点：**如果主机上同时装了免费版和完整版，两者访问 USB 设备时会冲突**，典型表现是设备列表里时有时无、连上了又掉。所以：

- 已经装了免费版再装完整版 → 把免费版卸载，只留一份；
- 只打算用完整版 → 一开始就别装免费版。

装完之后的连接与授权步骤见 [下载与安装教程.md](下载与安装教程.md) 和 [手机连手机怎么连上设备.md](手机连手机怎么连上设备.md)。

## 五、更新怎么处理

版本更新走官方应用商店最省事：商店版本能自动更新，也不会有别人二次打包带来的额外改动。如果你想留在当前这份 7.0 上，注意两点：

- 新版本可能调整界面与命令位置，文档里描述的按钮位置以你实际看到的为准；
- 应用内那些「有限额」的项目在 7.0 这一版同样适用，别把新版评测里的功能当成旧版就有。
