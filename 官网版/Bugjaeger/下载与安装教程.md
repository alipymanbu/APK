Bugjaeger 是一个跑在 Android 上的 ADB / fastboot 工具，作用是让你用一部手机，通过 USB OTG 线或同一个 Wi-Fi，去调试、管理另一台 Android 设备。本篇只解决「装」这一步：装在哪台机器、系统有什么门槛、装完的授权顺序，以及装不上时按什么顺序查。

## 一、先确定装在哪台设备

官方把两台设备分开叫，装错位置是新用户最常犯的错：

| 叫法 | 指哪台设备 | 要不要装 Bugjaeger |
| --- | --- | --- |
| 主机（host） | 你手里用来操作的那台 | 要，Bugjaeger 装在它上面 |
| 目标机（target） | 被调试、被控制的那台 | 不用装，只需打开开发者选项与 USB 调试 |

所以你至少要有两台 Android 设备：一台当操作台、一台当被控对象。手机控制手机、手机连接手表 / 电视 / 车机 / VR 一体机，都是同一套逻辑。还有一种特殊情况是同一台设备自己连自己，前提和步骤写在 [手机连手机怎么连上设备.md](手机连手机怎么连上设备.md) 里。

## 二、系统与硬件门槛

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 主机系统 | Android 7.0 或更高（以官方应用商店页面标注为准） | 版本号门槛会随更新变化，装前看一眼商店页写的「需要 Android 版本」 |
| 主机硬件 | 支持 USB Host（OTG） | 只走 Wi-Fi 连接也必须先有一次 USB 连接（Android 11 及以上目标机除外），所以 OTG 能力基本绕不开 |
| 目标机 | 打开开发者选项 + USB 调试（走无线调试时是「无线调试」开关） | 目标机装不装 Bugjaeger 都行，但这个开关必须开 |
| 目标机连接方式 | 支持 USB 调试或无线调试 | Android 11 及以上的目标机可以完全不用线 |

官方商店页标注的系统要求只针对 Bugjaeger 本身，**没有单独列出「目标机最低要哪个 Android 版本」**；目标机行不行取决于它的调试开关和 USB / 无线实现，以实测为准。

注意别把两个「7.0」搞混：网盘里这份安装包是**应用版本 7.0**，和 Android 系统版本没有关系。

## 三、安装步骤

1. 从上面的 **[Bugjaeger 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1be4ae2ef549)** 拿到 APK，保存到**主机**的本地存储。
2. 在主机上点开这个 APK。系统提示「不允许从此来源安装」时，去弹窗里的入口给当前的文件管理器 / 浏览器打开「允许安装未知应用」权限，再返回重装。
3. 装完先**只装这一份**。如果主机上原本已经装了 Bugjaeger 的免费版，官方建议把免费版卸载，否则两个包在访问 USB 设备时会互相抢，表现为设备列表里时有时无（两个包的区别见 [高级版和免费版有什么区别.md](高级版和免费版有什么区别.md)）。
4. 首次打开时按提示允许通知等常规权限。Bugjaeger 要在后台维持 ADB 连接，通知权限建议给，方便你随时看连接状态。

## 四、装完第一次打开要做什么

打开应用只是第一步，走 USB 线或「先线后 Wi-Fi」这条路时，**真正决定能不能用起来的是两台设备上的两次授权**，缺一次都连不上：

1. 目标机：设置里连点「版本号」开启开发者选项，再进开发者选项打开 **USB 调试**。
2. 主机：插上 OTG 线后，Bugjaeger 会弹出请求访问 USB 设备的对话框，选允许。
3. 目标机：屏幕上还会出现一次「允许 USB 调试吗」的授权弹窗，勾选「一律允许」并确认。

这两次授权不是同一件事：第 2 步是主机把自己的 USB 口交给 Bugjaeger 用，第 3 步是目标机承认这台主机有调试资格。两次都过了，目标机才会出现在 Bugjaeger 顶部的设备列表里。顺序与更多连接方式见 [手机连手机怎么连上设备.md](手机连手机怎么连上设备.md)。

## 五、这份安装包对应的版本信息

文档里凡涉及版本号、包名、体积，都以这份包为准（网上能搜到的通常是官方最新版，和这里的不是同一版）：

| 项目 | 值 |
| --- | --- |
| 应用版本 | 7.0 |
| 包名 | `eu.sisik.hackendebug.full` |
| 安装包大小 | 23.05M |
| MD5 | `552449F49420B8ED1E0C18BA31012459` |

包名后缀 `.full` 表示这是完整（高级）版，不是商店里那个带广告的免费版。想把 MD5 核对一遍的话，在电脑上用任意 MD5 校验工具对 APK 文件算一次，与上表逐位比对即可。

## 六、装不上的几种情况

| 现象 | 原因方向 | 处理 |
| --- | --- | --- |
| 提示「解析软件包时出现问题」 | 文件没传完 / 下载中断 | 重新从网盘转存下载，并核对 MD5 |
| 一直提示「禁止安装未知应用」 | 当前打开 APK 的那个应用没有安装权限 | 在弹窗入口给**打开 APK 的这个应用**授权，而不是给 Bugjaeger 授权 |
| 安装成功但连接设备时反复掉线 | 主机上同时装了免费版和完整版 | 卸载免费版，只留一份 |
| 卡在安装界面不动 | 主机可用存储不足 | 腾出空间；APK 本身只有 23.05M，但运行时要缓存截图与日志 |

装完连不上设备，属于另一类问题，按 [连不上设备怎么排查.md](连不上设备怎么排查.md) 的顺序逐步排除。
