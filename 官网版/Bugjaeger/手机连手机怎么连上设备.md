# Bugjaeger 手机连手机怎么连上设备

> 本篇讲「主机」和「目标机」怎么连起来：USB OTG 直连、先线后 Wi-Fi、Android 11 以上免线配对三种方式，以及连上之后在哪切换设备。

想用手机调另一台设备，先得让两台机器建立 ADB 连接。Bugjaeger 提供了三条路：一根 OTG 线直连最省事；改成无线要先插一次线；目标机是 Android 11 及以上则可以完全不插线。三者的连接步骤、能维持多久、适合什么场景差别很大，本篇逐条说明。

## 一、连接前的准备（两台设备都要动）

| 设备 | 要做的事 |
| --- | --- |
| 主机 | 装好 Bugjaeger；若走线，主机要支持 USB Host（OTG） |
| 目标机 | 打开开发者选项，再打开 **USB 调试**；走 Wi-Fi 时两台机器要在同一个局域网 |

首次连接会出现**两次**授权确认，别漏第二次：

- 主机上弹出的「允许 Bugjaeger 访问 USB 设备」——同意，主机才肯把 USB 口交给应用；
- 目标机上弹出的「允许 USB 调试吗」——勾「一律允许」再确认，目标机才认这台主机。

## 二、方式一：USB OTG 直连

最直接，也是后面两种无线方式的第一步。

1. 在**目标机**上打开开发者选项与 USB 调试。
2. 在**主机**上打开 Bugjaeger。
3. 用 USB OTG 线把主机（USB 口）和目标机连起来。
4. 主机上同意「访问 USB 设备」，目标机上同意「USB 调试」。
5. 目标机随后会出现在 Bugjaeger 顶部的设备列表里，选中它即可开始操作。

线的两端别接反：主机一端必须是能对外供电/当 USB 主机的那一侧。USB-C 对 USB-C 直连时还要在系统设置里确认端口角色（见排查篇）。

## 三、方式二：先 USB，再 Wi-Fi

适合目标机被固定在别处、不方便一直插线的情况。核心是一句命令的效果：把目标机的 ADB 守护进程配置成监听 TCP 端口。

1. 先按方式一，用 USB 线连上并把目标机选为当前设备。
2. 切到 Bugjaeger 的 **Commands**（第一个标签页），执行 **Connect through WiFi** 命令。它等价于在电脑上执行 `adb tcpip 5555`，即让目标机监听 **5555** 端口。
3. 点顶部设备列表右侧的 **+plug** 图标打开连接对话框，填入目标机的 **IP 地址**和端口 **5555**，点 **CONNECT**。
4. 目标机 IP 可以在目标机的 Wi-Fi 高级设置里看，也可以在 Bugjaeger 里执行 **Get WiFi IP address** 命令直接读出来。

几个容易踩的点：

- 对话框里 **CONNECT** 和 **PAIR** 是两个不同动作。用方式二时点 CONNECT；点到 PAIR 会进到配对流程里，按这套端口是连不上的。
- 执行完 Connect through WiFi 后 Bugjaeger 会尝试自动连一次，这一步**不一定成功**——不同目标机初始化速度不同，有的设备在这个瞬间还会短暂断开 USB 连接。自动连失败就按第 3 步手动连。
- 首次用一台新主机连目标机时，目标机上还会有一次 ADB 授权弹窗，需要手动确认。
- 多数手机 / 平板**重启后会丢掉这个监听配置**，得重新插线执行一遍 Connect through WiFi。Android TV 一类设备出厂就可能已经监听 5555，可以跳过插线这一步。

## 四、方式三：Android 11 及以上的无线调试配对

目标机是 Android 11 或更高时，可以完全不用线。它是 Google 在开发者选项里加的 **无线调试**，多了一个「配对」环节用来建立信任，**配对只需要做一次**。

1. 目标机：开发者选项里打开 **无线调试**。
2. 主机：点设备列表右侧的连接图标，在对话框里点 **PAIR**。
3. 两种配对方式任选：
   - 手动：在目标机「使用配对码配对设备」里读出 IP、端口和六位配对码，手动填进 Bugjaeger 的配对界面；
   - 二维码：用 Bugjaeger 生成二维码，在目标机上扫码完成配对。
4. 配对成功后回到连接对话框，填**连接用的 IP 与端口**（注意它不是配对时显示的那个端口），点 CONNECT。

配对信息里会同时出现「配对端口」和「连接端口」两个数字，两者不一样，**端口填错是这一路连不上最常见的原因**。具体以目标机当时屏幕上显示的两组信息为准。

两个实操细节：

- 目标机上的配对信息弹窗**只要切走界面就会关闭**，先把 IP、配对端口、六位配对码记下来或截个图，再切到 Bugjaeger 里填；支持分屏的机型可以一边显示弹窗一边填。
- **配对只需要做一次**。之后用同一台主机连同一台目标机，直接填连接端口点 CONNECT 就行，不用再配对。

## 五、连接对话框里的三个按钮怎么选

| 按钮 | 做什么 | 什么时候用 |
| --- | --- | --- |
| CONNECT | 按你填的 IP + 端口直接连 | 首选，快且确定 |
| SEARCH | 扫描本网段、逐个地址尝试连接 | 不知道目标机 IP 时碰运气用；慢，且不是每个网络 / 设备都能成功 |
| PAIR | Android 11+ 的无线调试配对 | 只有目标机开了「无线调试」、需要首次建立信任时才用 |

能自己查到 IP 就手动填，SEARCH 属于兜底手段，等待时间可能很长。

## 六、连上之后

- 同时连了多台设备时（比如一根 OTG 线接了 USB Hub、或者又连了一台无线设备），在 Bugjaeger **顶部的设备列表**里切换当前目标机，之后所有命令都作用于选中的那台。
- 无线连接稳定与否受网络影响，路由器隔离（AP 隔离）、跨网段都会导致连不上；两台设备务必在同一网段。
- 连接断了不一定是应用的问题，按 [连不上设备怎么排查.md](连不上设备怎么排查.md) 里的顺序查，比反复重装有效。
- 连上以后能做什么、哪些操作必须 root 才做得到，见 [免root能做什么不能做什么.md](免root能做什么不能做什么.md)。

## 七、让同一台设备自己连自己

有一种需求是：只用一部手机，让它对自己执行 ADB 命令。这在 Bugjaeger 里是支持的，但**第一次仍然需要另一台设备或一台电脑帮忙**：

1. 直接的办法：拿电脑装好 ADB，用数据线连上这台手机，执行 `adb tcpip 5555`，然后在 Bugjaeger 里按 IP 连自己——本机地址填 `127.0.0.1` 或本机局域网 IP。
2. 没有电脑时：借第二台设备装 Bugjaeger，用 USB 线连上，执行 **Connect through WiFi**；然后在这台手机上也打开 Bugjaeger，设备列表里会出现一个类似模拟器的条目，选中它即可对自己下命令。
3. 手机是 Android 11 及以上：直接用上面第四节的「无线调试 + 配对」，不需要第二台设备。
