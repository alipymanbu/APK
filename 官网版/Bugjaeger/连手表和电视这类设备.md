手表和电视是最需要「手机替电脑」的两类设备：它们要么没有能插数据线的口，要么插上线也没地方摆。好在它们绝大多数是 Android 内核，开发者选项和调试接口一般都有，只是入口位置和手机不一样。本篇把手表和电视分开讲，步骤按官方说明整理。

## 一、这类设备为什么基本都走 Wi-Fi

| 设备 | 连接方式 | 原因 |
| --- | --- | --- |
| Wear OS 手表 | 基本只能走 Wi-Fi | 多数手表没有对外可用的数据口，官方也建议用「Debug over Wi-Fi」 |
| Android TV / 机顶盒 / 部分车机 | 通常可直连 Wi-Fi | 一般已配置为监听 ADB 端口，插线反而不方便 |
| 手机 / 平板 | USB 或 Wi-Fi 都行 | 两种方式都成熟 |

只要走无线连接，**主机与目标设备就得在同一个 Wi-Fi 网络里**，这一点在三类设备上是一致的（USB 直连不涉及这一条）。

## 二、连 Wear OS 手表（含三星手表）

1. 先在手表上打开 **Wi-Fi**，连到和手机同一个网络。部分手表默认只用蓝牙，需要手动去设置里把 Wi-Fi 打开。
2. 开开发者模式：进 `设置 → 关于手表 / 系统 → 软件`，对着 **软件版本** 连点 5 次以上，直到出现类似「开发者模式已开启」的提示。
3. 进 `设置 → 开发者选项`，打开 **ADB 调试** 和 **Debug over Wi-Fi（通过 Wi-Fi 调试）** 两项。
4. 打开后，**Debug over Wi-Fi 这一项下面会直接显示 IP 地址和端口**，形如 `192.168.x.x:5555`。端口以你手表屏幕上显示的为准，不要照抄这个例子。
5. 在手机上的 Bugjaeger 里点顶部设备列表右侧的 **+plug** 图标，把第 4 步看到的 IP 和端口填进去，点 **CONNECT**。
6. 手表上会弹出「允许调试?」的授权窗口，选 **Always allow from this computer（始终允许此电脑）**，以后就不用每次再确认。

## 三、手表连不上时按顺序试

官方给手表这一路的排查动作比手机更少，基本就这几条，按顺序做：

1. 在手表开发者选项里把 **Debug over Wi-Fi** 关掉再打开一次；
2. 重新打开后如果 **看不到 IP 地址**，去手表的 `设置 → 连接 / Connectivity` 里把 Wi-Fi 关掉，再打开并**手动重连**你的网络（有些手表不会自动重连）；
3. 重启手机上的 Wi-Fi；
4. 再确认一次两台设备在同一个 Wi-Fi 网络上。

手表走无线时耗电明显更快，调完记得把 Debug over Wi-Fi 关掉，不然它会一直保持监听。

## 四、连 Android TV 和机顶盒

这类设备通常在出厂或初次配置时就打开了 ADB 监听，所以往往**不需要先插 USB 线**：

1. 在电视上开启开发者选项（一般在 `设置 → 关于` 里连点版本号），打开 **USB 调试 / 网络调试（ADB）**；
2. 在电视的网络设置里查出它的 IP 地址；
3. 在 Bugjaeger 里用 **+plug** 填 IP 与端口连上去。如果连不上，先按 5555 端口试，再确认电视上显示的调试端口是多少。

部分品牌的电视把「网络调试」做成了单独的开关项，名字可能是「ADB 调试」「网络调试」「开发者模式」之一，以电视上实际显示为准。

## 五、连上以后最常用的几件事

手表和电视的界面小而难操作，下面这几件事在手机上做省事得多：

| 想做的事 | 做法 |
| --- | --- |
| 装一个 APK | 用 Packages 标签推送安装，或把文件推到设备上再装 |
| 抓日志 | 手表、电视上的应用崩溃，用 Logcat 抓下来带走 |
| 截图 | 电视界面 / 手表界面截图，比拍照清楚 |
| 启动或强停应用 | Packages 标签点运行、Processes 标签点叉 |
| 远程操作界面 | 用屏幕镜像加手势点击直接操作，不用满屋找遥控器 |

具体入口和注意事项见 [看日志截图和录屏怎么用.md](看日志截图和录屏怎么用.md) 与 [装应用传文件和备份.md](装应用传文件和备份.md)。

## 六、两条容易忽略的提醒

- **授权选项决定要不要每次确认**。第 6 步如果只点了「允许」，下次连接手表还会再弹一次；选「始终允许」才能省事。
- **手表电池和保护机制**：手表在息屏或省电模式下可能中断调试连接，操作期间保持屏幕点亮更容易成功。电视则要注意别在接调试线或无线调试期间待机，待机可能直接断开 ADB。
