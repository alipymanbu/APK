弹幕、字幕和视频画面是分开保存的文件：视频本身能直接播放，而弹幕和字幕文件单独拖给大多数播放器是"没反应"的——这不是下载失败，而是格式没对上。

## 一、弹幕文件：XML 格式，多数播放器不直接认

B 站弹幕的原始格式是 XML，常见的本地播放器（PotPlayer、VLC、mpv 等）不会把它当弹幕渲染，直接拖进去什么都不会发生。两条路：

**路一：用能直接读 XML 弹幕的播放器**。例如弹弹play（有 Windows 与 Android 版），把视频和 XML 弹幕一起打开即可。

**路二：先把 XML 转成 ASS 字幕文件，再当字幕加载**。转换工具有在线转换页、DanmakuFactory、danmaku2ass 等多款（以工具当前可用为准，自行搜索验证）。转换时注意两点：

- **分辨率要和视频对上**（1080p 的视频就选 1920×1080），否则弹幕位置会飘或被裁掉；
- 转出来的 ASS 与视频放在**同一目录、同名**（`xxx.mp4` 配 `xxx.ass`），播放器会自动加载；不自动的，从播放器的字幕菜单手动添加。

## 二、字幕文件：当外挂字幕加载

字幕（CC 字幕，2.3.1 起可下、需登录）拿到手后就是一条外挂字幕：与视频同目录、同名，播放器一般会自动加载；不自动就手动添加。个别播放器对某些编码支持不全，换 PotPlayer、VLC、mpv 这类主流播放器再试。

## 三、封面图

封面是普通图片文件，任何看图应用都能打开，不存在加载问题。

## 四、手机上怎么看带弹幕的视频

- 用弹弹play 的 Android 版直接读 XML 弹幕；
- 或把 XML 转成 ASS 后，用支持外挂字幕的手机播放器（如 VLC 的 Android 版）加载。

拿到文件后先看扩展名再决定怎么处理：`.xml` 按弹幕的路子走（专用播放器或转 ASS），`.srt` / `.ass` 按字幕加载。下载这些文件的操作见 [视频解析与下载步骤.md](视频解析与下载步骤.md) 第三节；导出与文件位置见 [下载文件导出与格式转换.md](下载文件导出与格式转换.md)。
