## 一、网盘这份是 2.3.5

网盘里的 BiliDownload 安装文件资源是 **2.3.5** 版（2026 年 9 月整理）。这一版相对更早版本的关键改动（摘自官方更新日志）：

- 支持下载后自动删除原始音视频文件；
- 添加音频播放器；
- 支持设置下载源（下载反复失败时可换线路）；
- 支持自动转换音频封装；
- 设置外部目录时可自定义输出文件名；
- 支持直接下载到外部媒体库；个人主页新增最近点赞视频；
- 增强下载恢复能力；修复外部下载文件删除后空间未释放。

官方后来还发布了更高版本（截至 2026 年 9 月为 2.3.7），之后的改动以 [GitHub Releases](https://github.com/KafuuNeko/BiliDownload/releases) 页面为准。

## 二、主要版本时间线

| 版本 | 主要改动（摘自官方更新日志） |
| --- | --- |
| 2.1.4 | 音视频封装格式与编码转换；个人页面（历史记录、收藏夹、稿件） |
| 2.2.1 | 视频下载支持多选；导出默认文件名为视频标题 |
| 2.2.2 | 扫码登录；修复部分视频解析失败 |
| 2.3.0 | 弹幕下载；保存视频封面；搜索历史记录 |
| 2.3.1 | 直接播放资源；资源多选与批量导出；下载字幕（需登录） |
| 2.3.2 | 自定义下载路径；倍率播放；更换下载引擎解决断点续传 |
| 2.3.5 | 网盘资源里的版本，见上节 |
| 2.3.6 | 视频与剧集列表多选、多分 P 批量下载；系统分享导入 |
| 2.3.7 | 主页样式优化；稍后再看列表与后台播放；小窗口播放 |

应用早期发布名叫 **BVD**（2.3.2 及之前），2.3.5 起的发布名是 **BiliDownload**，包名一直是 cc.kafuu.bilidownload。

## 三、要不要升级

先用 [视频解析与下载步骤.md](视频解析与下载步骤.md) 过一遍日常流程，缺的功能恰好是你想要的（比如搜索结果整页多选批量下载），就走官方渠道升到最新版，获取渠道见 [下载与安装教程.md](下载与安装教程.md)；只下单个视频的话，2.3.5 已覆盖上面时间线里 2.3.5 及之前的能力。
