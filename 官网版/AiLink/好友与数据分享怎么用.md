# AiLink 好友与数据分享怎么用

> 想让孩子在外地看到你每天称重的结果，靠的是 AiLink 的好友功能和「数据开放」这两件事。这一篇讲好友怎么加、为什么加了却看不到数据、一次测量结果怎么单独发给别人。

## 一、好友和家人的分工，先分清

- **家人**建在你自己的账号下，用来解决「一家人共用同一台设备」的问题 —— 目的是把数据分到不同的人名下。
- **好友**是另一个独立的 AiLink 账号，用来解决「不在一起住的人相互看结果」的问题 —— 目的是共享。

加好友之前，先确认你想要的到底是哪一种。要的是「同住的人各记各的」，那该做的是加家人，见 [家人管理与测量数据怎么看.md](家人管理与测量数据怎么看.md)；要的是「让对方能看到我」，才是这一篇。

## 二、加好友的两种方式

官方说明里给了两条路：

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| 扫一扫 | 打开扫一扫，扫对方的二维码 | 两个人当面，最快 |
| 搜索 ID / 账号 | 打开「搜索 ID / 账号」，输入对方的账号或 ID 搜索 | 不在一起，把账号报过去就行 |

搜索出来之后会先进入对方的用户概况页，**需要通过验证才成为好友**。也就是说，加好友这一步不是单方面生效的。

## 三、加了却看不到数据：去开「数据开放」

这是用得最多、也最容易误解的一点。**光加好友是不够的**，官方说明在「如何查看好友数据」里写得很清楚：

1. 进到自己的用户概况页，找到「隐私保护」。
2. 打开「数据开放用户」。
3. 在里面勾选**允许对方查看的家人**。

三个关键细节，逐条对一下：

- **只有你勾中的那些家人才会被对方看到**。一个都没勾，好友那边就是看不到数据 —— 这不是 bug。
- **主账户（也就是你自己）默认是开放的**。
- **如果你名下没有任何可选中的用户，自己也不会出现在别人的好友列表里**。所以一个人用、没建过家人的账号，别人加了你也看不到东西。

想让对方随时能看，就一次性把要开放的人勾好；不想开放了，回同一个地方取消勾选即可，不需要删除好友。

## 四、把一次测量结果单独发给别人

好友功能是「长期开放某几个人的数据」，还有一种是「就发这一次」。后者走分享：

1. 在设备首页点右上角的「…」。
2. 选分享方式。
3. 数据分享默认带的是**最近一组数据**；想拿两次数据做对比，选对比数据分享。

这样发出去的是**一条结果**，不涉及账号绑定，也不要求对方装 App。日常用得比较多的两种场景：

| 场景 | 建议用哪种 |
| --- | --- |
| 让家人随时能看到每天的记录 | 好友 + 数据开放 |
| 把今天这一次的结果发给医生说清楚 | 分享（对比数据分享更直观） |
| 家里人共用一台秤，各记各的 | 家人（不是好友） |

## 五、开放数据前先想清楚的事

- **好友看到的是你勾选的那几个人，不是你自己的全部设备数据**。开放范围是可控的，别忘了这个开关在哪。
- **家人删除会连带清空数据**（见 [家人管理与测量数据怎么看.md](家人管理与测量数据怎么看.md) 第六节），但**取消好友的数据开放不会删任何东西**，只是看不到，随时可以再开回来。
- **不想让某台设备再自动回传数据**，去解绑那台设备就够了，不必取消好友开放、更不必注销账号。这三件事各自会停掉什么，见 [换手机重装与账号注销后数据还在吗.md](换手机重装与账号注销后数据还在吗.md)。
- 对方一直说看不到、你也确认勾选了，先让他在自己那边退出重新进一次，再看 [常见问题与排查.md](常见问题与排查.md)。

另外，同一家厂商给别的产品做的定制 App 也容易和 AiLink 搞混，见 [支持的设备类型与品牌显示不一致.md](支持的设备类型与品牌显示不一致.md)。
