# AiLink 家人管理与测量数据怎么看

> 一台秤全家轮流站上去，如果不先分好「这是谁的测量」，数据会混在同一个人名下。这一篇讲家人怎么加、测的时候怎么切、数据页上的记录怎么读，以及删家人为什么代价很大。

## 一、家人和好友是两回事，别混着用

两个入口都跟「别人」有关，但对方看到的东西完全不同：

| | 家人 | 好友 |
| --- | --- | --- |
| 建在哪 | 建在你自己的账号下 | 是另一个账号，通过扫码或搜索加过来 |
| 有什么用 | **共用设备**：切换过去之后，测量结果存到这个人名下 | **看开放出来的数据**：对方只能看到你愿意开放的那部分 |
| 对方要不要装 App | 不用，家人不需要自己的账号 | 要，好友必须是另一个 AiLink 账号 |
| 明细在哪看 | 就在你自己的数据页里 | 在好友功能里看 |
| 主要章节 | 本篇 | [好友与数据分享怎么用.md](好友与数据分享怎么用.md) |

一句话判断：**同住、共用同一台秤的，加成家人；不在一起住、只是想给对方看结果的，用好友。**

## 二、怎么添加家人

1. 打开「我的」。
2. 进「我的家人」，这里能看到已有的家人列表。
3. 点「添加家人」，填头像、关系、昵称、生日、性别。

有两项要特别当心：

- **生日和性别是给数据换算用的**，填之前先看 [注册登录与账号设置.md](注册登录与账号设置.md) 第五节，里面写了这两项为什么必须填对。
- **关系这一项，官方说明里写明「一旦填写无法修改」**。它被当作这个家人在你账号下的唯一标识。填之前想清楚该填什么（父亲/母亲/本人 一类），别为了省事随便选一个。

## 三、测量时先切换到对应的人

家人建好不会自动生效，**测量前要在设备首页把人切换过去**。切换之后这次的测量结果才会存到那个人名下。

用错人的典型表现：明明自己站上去称的，数据却挂到了妈妈名下 —— 回头看曲线会发现这条线突然跳了一下。遇到这种情况，最直接的处理是切换回正确的人、重新测一次。

## 四、数据页上的记录怎么读

官方对数据页的说明是：**和你相关的测量数据会汇总在一起**。理解这一页有两个要点：

- **按人汇总，不按设备汇总**。同一个人家里有两台秤，两台秤产生的体重数据会统一归到这一个人的同一个数据项下，不会因为换了台秤就出现两套曲线。
- **点数据项看汇总，点记录看当次**。首页显示的是最近一次结果和实时状态；点进某一类数据可以看这个人的历史汇总，再点某一条记录则是那一次测量的详情。

设备首页上还会出现几种状态提示，认一下：

| 界面上的表现 | 含义 | 你能做什么 |
| --- | --- | --- |
| 显示实时数值、滚动更新 | 正在测量 | 保持姿势不要动 |
| 显示最近一次结果 | 测量已完成并入账 | 点进记录看详情 |
| 出现感叹号图标 | 连接失败或超时 | 点一下图标会弹出正确测量的指引 |
| 测量完成后弹框 | 和上一次数值差得比较多 | 按提示确认是否保存这条数据 |

## 五、数据会记到谁名下

除了「测量前切错人」，还有三种情况会让一条记录的归属和你预想的不一样，官方说明里都写了：

| 情况 | 官方说明 | 你该做什么 |
| --- | --- | --- |
| 设备离线期间测的（带 WiFi 的设备） | 离线历史记录会在重新联网后**自动匹配**到对应用户，不需要你手动认领；**匹配不上的记录，设备不保存** | 想确保这条留下，就在对应的人名下、联网状态再测一次 |
| 设备认不出这次测量是谁的（WiFi 设备） | 会**把数据同时发到这台设备绑定过的多个账户**，由你自己确认是不是本人的数据 | 测完回数据页看一眼归属，不属于自己的就处理掉 |
| 同一个账号下的人太多 | 官方八电极体脂秤的说明里写明，**每个账户最多支持 20 个用户** | 家人列表控制在 20 个以内 |

还有一条来自官方隐私政策的建议：不愿意把这台设备共享给多人使用时，办法是**避免让这台设备被多人使用并绑定**；这么做不影响你使用其他功能。

## 六、删除家人的代价

官方说明写得很明确：**家人一旦删除，这个家人名下的所有数据会一并清空，且不可恢复。**

所以按「删了重建」来处理问题前，先算一下这笔账：

- 关系填错了、想改成另一个关系 → 只能删了重建，而这个家人名下的历史测量记录会一起没有；
- 只是想让对方看不到某些数据 → 不需要删，改共享设置就行，见 [好友与数据分享怎么用.md](好友与数据分享怎么用.md)；
- 家人列表里出现的「垃圾桶」图标就是删除入口，它没有回收站，点下去就生效。

长期使用的家庭，建议一开始就把「本人 + 家人」几个人一次建齐，避免用了几个月再回来补人。

数据分好之后，如果还想让不住在一起的人看到结果，走好友那条路 —— 见 [好友与数据分享怎么用.md](好友与数据分享怎么用.md)。
