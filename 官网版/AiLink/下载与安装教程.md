## 一、先确认你手里的是哪一份包

网盘里放的是安卓安装包（`.apk`），装之前先对一遍下面这张表。这几项对得上，说明你拿到的是这一份，后面的步骤才适用。

| 项目 | 内容 |
| --- | --- |
| 应用名 | AiLink |
| 开发者 | 深圳市易连物联网有限公司 |
| 包名 | com.pingwang.elink |
| 版本 | 1.84.01 |
| 安装包大小 | 110.85 MB |
| MD5 | 5FED7DD28607B9FF7C5B7D18823BD385 |

四点要留意：

- **版本号说的是这一份包**。应用商店里的 AiLink 已经更新到更高版本（检索时应用信息页上显示的是 2.x 一档，具体数字会随时间变化），和网盘里这一份不是同一个版本。所以本文档里出现的版本号、包名、安装包大小，一律按上面这张表理解，别拿商店页的数字来对。
- **包名 `com.pingwang.elink` 是它和别的应用的分界线**。手机里同时装着同一家厂商的其他 App 是正常的，它们各自独立、不会互相替代，清理手机时别只看图标相似就删错。
- **这是「一个 App 管多种设备」的那一个**，不是某款单品的专用 App。同一家厂商还给别的产品做过定制版 App，名字各不一样 —— 怎么区分见 [支持的设备类型与品牌显示不一致.md](支持的设备类型与品牌显示不一致.md)。
- **设备比较新的话，先看它说明书上的「适用版本」**。部分设备的官方说明会写明它要求的 App 版本，例如八电极体脂秤写的是 AILink V2.01.00（Android）/ V1.97.00（iOS）及以上。网盘里这一份是 1.84.01，低于这类要求，配这类设备建议改用应用商店里的当前版本，功能才齐全。

## 二、系统要求与装之前要确认的事

- **系统版本**：官方帮助中心里对 AiLink 的说明是「蓝牙 4.0 以上，iOS 9.0 或 Android 4.4 以上」；而这一份安装包的说明页标注的是「需要支持安卓系统 5.2 以上」。两处数字对不上（安卓并没有 5.2 这个正式版本号），稳妥起见**按 Android 5 以上准备**。手机系统还停在 Android 4.x 的，先别折腾。
- **存储空间**：安装包 110.85 MB，装完之后占用会更大，留出 300 MB 以上比较省事。
- **安装权限**：因为不是从应用商店装，需要先允许「安装未知应用」（部分系统叫「未知来源」）。这个开关是给**你用来打开安装包的那个应用**（文件管理器或浏览器）的，不是给 AiLink 的。装完之后可以关回去。
- **蓝牙和定位权限**：不在这一步给。它们要到你在 App 里搜设备、绑设备的时候才用得上，见 [绑定设备与蓝牙配网.md](绑定设备与蓝牙配网.md)。

## 三、安装步骤

1. 打开 [AiLink 安装文件资源（夸克网盘）](https://pan.quark.cn/s/dbee6f6570f9)，把安装包转存到自己网盘后再下载到手机，也可以直接在手机上打开这条链接下载。
2. 下载完的文件后缀是 `.apk`。用手机自带的文件管理器在「下载」目录里找到它，点一下开始安装。
3. 如果弹出「出于安全考虑，已禁止安装未知来源的应用」，点提示里的设置入口，把当前这个文件管理器的开关打开，返回后重新点安装。
4. 装完桌面出现图标即成功。图标点不开、或者装到一半报错，看第五节。

## 四、装上之后核对一下 MD5

网盘下载的安装包，花半分钟核一下校验值，能直接排除「下载断流导致装不上」这类问题。在电脑上把手机里的包拷出来，或者直接用电脑下载一份，然后执行（文件名以你实际下载到的为准）：

```powershell
certutil -hashfile "D:\Downloads\ailink_v1.84.01.apk" MD5
```

算出来的 32 位十六进制串应该与 `5FED7DD28607B9FF7C5B7D18823BD385` 完全一致；不一致就删掉重新下载一次。手机上也可以用支持查看文件哈希的文件管理器核对。

## 五、装不上、打不开怎么办

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现错误」 | 安装包下载不完整 | 删掉重新下载，下完先按第四节核 MD5 |
| 提示「应用未安装」 | 手机里已有同包名但签名不同的 AiLink | 先卸载原来的再装；卸载前确认不需要保留 App 内的绑定设置 |
| 点了安装没有反应、不弹安装界面 | 没给「安装未知应用」权限 | 按第三节第 3 步开权限后重试 |
| 装上了一打开就闪退 | 系统版本过低，或系统对新装的旧版本包不兼容 | 换一台系统版本较新的手机试；也可以改用应用商店里的当前版本 |
| 装完打开是空白页、转圈 | 多半是网络或账号问题，不是安装问题 | 见 [常见问题与排查.md](常见问题与排查.md) |

装好之后的下一步是注册账号、把设备绑进来，接着看 [注册登录与账号设置.md](注册登录与账号设置.md)。
