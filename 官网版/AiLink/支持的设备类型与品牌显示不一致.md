# AiLink 支持的设备类型与品牌显示不一致

> AiLink 是一个「一个 App 管多种设备」的公版 App，同一家厂商还给不同产品做过各自的定制 App。所以会出现两种困惑：我的设备到底能不能用 AiLink？以及为什么装完之后 App 里显示的品牌不是我买的那个？

## 一、AiLink 是什么形态的 App

开发者是深圳市易连物联网有限公司，AiLink 是它的**公版管理 App** —— 不是某一款秤、某一款血压计的配套 App，而是把智能健康、智能安防、智能电工等多种类型的设备收在同一个 App 里管。设备接进来之后，绑定、配网、看数据、共享都在 AiLink 里完成。

理解这一点很关键：**你的设备说明书上写的是不是 AiLink，决定了它能不能用这个 App。**

## 二、官方帮助中心列出的设备类型

官方帮助中心按设备逐个给了使用说明。检索时页面上列出的条目包括（以官方页面当时显示为准）：

| 类别 | 具体条目 |
| --- | --- |
| 体重/体脂 | 体脂秤（蓝牙）、体脂秤（WiFi）、八电极体脂秤、咖啡称、营养秤 |
| 血压/血氧 | 血压计、BLE+WiFi 血压计、蓝牙血氧仪 |
| 体温 | 额温枪、工业测温枪、食物温度计、温湿度计、环境检测仪 |
| 运动/个护 | 智能运动手表、智能跳绳（蓝牙）、智能牙刷（蓝牙）、智能耳勺、筋膜枪 |
| 其他 | 风速计、钳表、智能胎压、门锁、门锁遥控器 |

这份清单会随产品线变化，**以官方帮助中心页面当时的列表为准**。同型号但连接方式不同（蓝牙版 / WiFi 版），说明页也是分开的两份。

还有一项比设备清单更容易漏：**部分较新设备的说明页会写「适用版本」**，列出它要求的 App 版本。例如八电极体脂秤的说明书写的是 AILink V2.01.00（Android）/ V1.97.00（iOS）及以上。网盘里这一份是 1.84.01，低于这类要求 —— 配这类较新的设备，改用应用商店里的当前版本，功能才齐全。

## 三、怎么判断手里的设备能不能用 AiLink

按这个顺序看，一般一两分钟就能确认：

1. **看说明书或包装上的 App 下载入口**。写的是 AiLink（或给出 AiLink 的下载二维码），手机端就用 AiLink。
2. **看设备的蓝牙广播名**。官方对接资料里写着，走这套方案的设备默认广播名以 `AiLink_` 开头，后面跟几个字符；用手机蓝牙扫一圈能看到这个名字，基本就能确认。
3. **在 AiLink 的「手动添加」列表里对型号**。能选到你的设备型号，就走这个 App；选不到，多半说明这款产品对应的不是 AiLink。

反过来说：**AiLink 只支持采用这套方案的设备**。别的品牌自成体系的设备，通常是连不进来的，添加列表里也找不到它 —— 这不是搜不到，而是本来就不在支持范围内。

## 四、为什么装完显示的品牌和我买的不一样

这是自己吓自己最多的一处。官方对 App 的定位就是「可提供中性和定制化 App」：同一份 AiLink，装上之后**会根据所连设备里带的客户 ID，自动读取对应的展示配置**，包括启动页、硬件名称、关于信息、购买入口、使用帮助这些内容。

所以下面这些现象都是设计内的，不是装错了包：

- 你买的品牌名出现在 App 的「关于」里，而不是「AiLink」；
- 设备页上的产品名、图标和别人截图里的不一样；
- 「使用帮助」「联系电话」「联系邮箱」几项，有的显示有的不显示 —— 官方说明里写明这几项是厂商配置了才显示。

**唯一需要核实的是包名**：本文档涉及的这一份包名是 `com.pingwang.elink`，这是区分「同一个 App」和「另一个 App」的硬标准。

## 五、厂商改了产品信息，为什么 App 里没变

官方管理后台的说明里提到过这点：App 端对这类个性化配置有缓存，**改了产品信息之后，需要把设备解绑再重新绑定一次，才会看到新的配置**。

对你来说只有一条动作：**发现展示内容和说明书对不上、或者厂商说已经改好了，就把这台设备解绑再重绑一次，而不是卸载重装 App。**

## 六、名字容易混的几种情况

搜 AiLink 的时候会碰到名字相近的东西，按下面的方式区分：

| 你看到的东西 | 是不是本文档讲的这个 App | 怎么认 |
| --- | --- | --- |
| AiLink / AILink / ailink | 是 | 包名 `com.pingwang.elink`，产出方是深圳市易连物联网有限公司 |
| 另一家公司的站点（页面品牌名是「艾灵」） | 不是 | 域名是 `ailinking.com`，做的是别的业务，和这个 App 没有关系 |
| 好美丽 / 好牙 / 好身材 / 好营养 | 不是 | 同一家厂商给别的产品做的定制版 App，各自独立 |
| AICare | 不是 | 同一家厂商的另一款 App，官方有些设备的说明里会把 AiLink 和 AICare 的适用版本并列写出来 |

如果你手上设备的说明书让你装的正是后面那两类中的某一个，那这篇文档讲的 AiLink 不适用于它 —— 按说明书上的那个 App 走。

另外，手机里同时装着同厂的两三个 App 是正常的，它们互不替代，别只看图标像就删。

## 七、找不到对应设备的说明怎么办

官方给了两条路：

- **官网帮助中心**：官网 [www.elinkthings.com](https://www.elinkthings.com) 上有帮助中心，按设备名逐条列出使用说明；
- **App 内「使用帮助」**：绑上设备后，在设备页的相关位置能看到厂商配好的使用帮助内容（厂商没配就没有这一项）。

两条都查不到，直接在 App 的「意见反馈」里问，或者写邮件到 [app@elinkthings.com](mailto:app@elinkthings.com)。

确认设备能用了，下一步是把它绑进来 —— 见 [绑定设备与蓝牙配网.md](绑定设备与蓝牙配网.md)。
