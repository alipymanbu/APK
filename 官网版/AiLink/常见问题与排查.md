# AiLink 常见问题与排查

> 把 AiLink 从装上到用起来最容易卡住的地方集中在这一篇：验证码、搜不到设备、测完没数据、好友看不到结果。每条都按「先查什么 → 还不行怎么办」写成可直接照做的顺序，并指向详细那一篇。

## 一、安装与打开

| 现象 | 先查什么 | 还不行怎么办 |
| --- | --- | --- |
| 提示「解析包时出现错误」 | 包是不是下完整了，核一遍 MD5 | 删掉重新下载，见 [下载与安装教程.md](下载与安装教程.md) |
| 提示「应用未安装」 | 手机里是否已有同包名、签名不同的 AiLink | 卸载旧的再装 |
| 点安装没反应 | 打开安装包的那个应用有没有「安装未知应用」权限 | 到系统设置里给文件管理器开权限 |
| 一打开就闪退 | 手机系统版本是不是太低 | 换系统较新的手机，或改用应用商店里的当前版本 |

## 二、注册与登录

| 现象 | 原因与处理 |
| --- | --- |
| 点了发送，验证码一直不来 | 官方说明里验证码有效期是 120 秒，超时后回上一页重新点「发送」；用邮箱注册的，顺手翻一下垃圾邮件文件夹 |
| 密码怎么填都提示不合规 | 要求 6~16 位，且必须同时含数字和字母；注意别把空格带进去 |
| 忘记密码 | 走登录页的找回流程：填账号 → 收验证码 → 设新密码 → 提交重置，见 [注册登录与账号设置.md](注册登录与账号设置.md) |
| 换了新手机，登录后看不到以前的记录 | 先用同一个账号（同一入口）登录确认；用微信授权和用手机号注册是两个不同的入口，别进错，见 [换手机重装与账号注销后数据还在吗.md](换手机重装与账号注销后数据还在吗.md) |
| 登录后一直转圈 | 先确认网络正常，再退出 App 重进一次 |

## 三、设备连接与配网

| 现象 | 先查什么 | 还不行怎么办 |
| --- | --- | --- |
| 「附近设备」里什么都搜不到 | 手机蓝牙开了吗；AiLink 的**蓝牙和定位**权限给了吗；设备是否还在广播 | 给设备重新上电，改走「手动添加」 |
| 设备页出现感叹号图标 | 连接失败或超时 | 点一下这个图标，会弹出正确测量的指引 |
| 绑上了，但一直显示离线 | 这台设备以前是否绑在别的账号下 | 在原账号里解绑，再用当前账号重绑 |
| 设备加不进来、添加列表里也没有这个型号 | 这款设备对应的可能不是 AiLink | 见 [支持的设备类型与品牌显示不一致.md](支持的设备类型与品牌显示不一致.md) |
| WiFi 配网反复失败 | WiFi 密码对不对；中途设备有没有断电 | 按 [绑定设备与蓝牙配网.md](绑定设备与蓝牙配网.md) 第五节重做一遍 |

## 四、测量数据

| 现象 | 原因与处理 |
| --- | --- |
| 测完了，App 里没有这条数据 | 手机蓝牙是否开着、App 是否在前台；回设备页下拉手动同步一次 |
| 离线时测的，联网后记录还是没出现 | 离线记录会在联网后自动匹配用户，**匹配不上的设备不保存**；在对应的人名下、联网状态再测一次 |
| 数据挂到了别人名下 | 测量前没切换用户。切换回正确的人，重新测一次 |
| 家里两台秤的数据对不上 | 同一个人在不同设备上产生的同类数据会汇总到同一人名下；先确认两次测的是同一个人 |
| 历史记录怎么翻 | 首页显示的是最近一次和实时状态；点进具体的数据项看这个人的汇总，再点某条记录看当次详情 |

## 五、共享与好友

| 现象 | 原因与处理 |
| --- | --- |
| 加了好友，对方却看不到数据 | 九成是没开「隐私保护」里的「数据开放用户」。打开并勾选要开放的家人，见 [好友与数据分享怎么用.md](好友与数据分享怎么用.md) |
| 自己没出现在对方的好友列表里 | 你名下没有可选中的用户时，就不会显示；先在「我的家人」里把人建齐 |
| 只想发一次结果给对方 | 用设备首页右上角「…」里的分享，不需要加好友 |
| 取消开放会不会删数据 | 不会。取消只是看不到，随时可以再开回来 |

## 六、其他

| 现象 | 处理 |
| --- | --- |
| App 界面不是中文 | 在设置里手动切换语言，默认是跟随手机系统的 |
| 设备页看着太挤 | 设置里可以把显示方式在列表和宫格之间切换 |
| 想在电脑上用 | 官方没有出电脑端客户端。应用商店页面给的电脑用法，是装它的电脑版模拟器再运行手机版，属于非原生用法，界面和操作跟手机端不会完全一致 |
| 想给厂商提问题或报 bug | App 内「意见反馈」，能附截图；也可以写邮件到 [app@elinkthings.com](mailto:app@elinkthings.com) |
| 想查某款设备的具体操作 | 官网帮助中心按设备逐条列了使用说明，入口是 [www.elinkthings.com](https://www.elinkthings.com) |
| 不想用了，想把账号里的东西全清掉 | 入口是【我的】→【账户与安全】→【停用账号】，会永久删除设备、消息、账号、测量数据等全部信息，且不可恢复；只是不想让手机里留着 App 的话，卸载就够了，见 [换手机重装与账号注销后数据还在吗.md](换手机重装与账号注销后数据还在吗.md) |

换了手机之后，账号下的数据还在原账号里，用同一入口重新登录即可；**设备绑定关系是否会跟着账号走，官方资料没有写明，以你在新手机 App 里实际看到的状态为准** —— 没看到设备，就按 [绑定设备与蓝牙配网.md](绑定设备与蓝牙配网.md) 重新绑一次。解绑设备、注销账号这些动作各自会删掉什么，单独整理在 [换手机重装与账号注销后数据还在吗.md](换手机重装与账号注销后数据还在吗.md) 里。
