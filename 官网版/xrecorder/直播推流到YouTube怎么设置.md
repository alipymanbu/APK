XRecorder 除了录屏还带直播推流能力（走 RTMP 协议，YouTube、Twitch 这类平台都认这一套）。想边玩边播、或把教学画面实时推给观众，本篇把从准备到开播的路径走一遍。界面入口以你手上版本的实际显示为准。

## 一、开播前的三件事

1. **装好应用并授权**：还没装的话，从上方 [XRecorder 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8a5d5cb58f9b)先装好，权限按 [下载与安装教程.md](下载与安装教程.md) 第三节给齐。
2. **平台侧开通直播**：以 YouTube 为例，新账号的直播功能要单独开通，启用后一般还需等待最长 24 小时才可用。没开通前推流地址拿了也没用，先去 YouTube Studio 把直播功能打开。
3. **网络**：直播比录屏吃网络得多，优先用稳定的 Wi-Fi；推流中切后台、锁屏都可能中断，尽量保持亮屏充电。

## 二、方式一：平台账号直连

部分版本在直播入口里可以直接登录 YouTube / Twitch 账号，登录后选「开始直播」即可，应用替你处理推流地址。这条路最省事，有就优先用。

## 三、方式二：RTMP 手动推流

平台直连不可用或想推到别的 RTMP 服务时走这条路：

1. **从平台拿两个东西**：推流地址（URL）和串流密钥（Stream Key）。YouTube 的位置是 YouTube Studio → 直播 → 「串流密钥」页，两项都在那里；Twitch 在创作者仪表板的设置里。
2. **在 XRecorder 里选 RTMP 推流**，把地址和密钥分别粘进去。地址和密钥都是平台生成的，抄错一位就连不上。
3. **开播前把声音来源设好**：推流用的音频跟随应用的音频设置，想播游戏声选「内部声音」，想带解说选「内部 + 麦克风」，参考 [录屏参数怎么设置才合适.md](录屏参数怎么设置才合适.md) 的音频来源表。
4. 点开始，等平台侧出现「直播中」状态即为成功。

**串流密钥等同账号密码**，不要发给任何人、不要截图发到群里；泄露了去平台页重置一个。

## 四、开播后常见问题

| 现象 | 先查什么 |
| --- | --- |
| 一直显示「未连接」 | 地址与密钥是否抄对；平台直播功能是否已开通 |
| 能连上但画面卡 | 推流分辨率降一档；确认走的是 Wi-Fi |
| 直播里没声音 | 回音频设置查来源，别是「静音」；排查思路见 [录屏没声音黑屏怎么办.md](录屏没声音黑屏怎么办.md) 第一节 |
| 画中画人脸没出现 | 悬浮窗工具里先开人脸小窗，见 [悬浮窗控制与录屏操作.md](悬浮窗控制与录屏操作.md) 第五节 |
| 走了流量 | 部分实现默认用移动数据推流，在网络设置里确认选了 Wi-Fi |

直播同时应用也在占编码资源，低配机推 1080p/60fps 容易掉帧，推流分辨率建议比录屏低一档起步，稳了再升。
