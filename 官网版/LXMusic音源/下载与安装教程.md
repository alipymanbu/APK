## 一、这是什么软件

LX Music 移动版是一个免费开源的 Android 音乐播放器，装好后要自己导入音源才能搜索、播放歌曲。本篇只负责把你手上的 APK 装进手机，并讲清楚装之前该核对什么；装完第一步要做什么在[音源导入与配置.md](音源导入与配置.md)里。

| 项目 | 内容 |
| --- | --- |
| 软件名 | LX Music（洛雪音乐）移动版 |
| 包名 | `cn.toside.music.mobile` |
| 最低系统 | Android 5 及以上 |
| 明确不支持 | iOS、HarmonyOS NEXT（官方写明暂无计划） |
| 开源协议 | Apache License 2.0，另有官方补充条款 |
| 原始发布地址 | GitHub Releases；官方声明原始发布地址只有 GitHub，其他渠道均与本项目无关 |

官方入口：[软件下载页](https://lxmusic.toside.cn/download) · [移动版文档](https://lxmusic.toside.cn/mobile) · [GitHub Releases](https://github.com/lyswhut/lx-music-mobile/releases)。版本号会随时间变化，具体以官方页面当时显示为准。

## 二、包型怎么选

官方为同一个版本发布多个架构包，文件名里的架构后缀决定它装到哪种机器上：

| 后缀 | 适用场景 | 怎么选 |
| --- | --- | --- |
| `arm64-v8a` | 大多数近几年的手机 | **优先选它** |
| `armeabi-v7a` | 老的 32 位手机 | arm64 装不上再试 |
| `universal` | 架构不确定时的备选 | 见下方的版本号坑 |
| `x86` / `x86_64` | 模拟器、x86 平板 | 普通手机用不到 |
| 文件名带 `sl` | 「墨·状态栏歌词」特别版 | 依赖第三方 Xposed 模块，普通用户选不带 `sl` 的 |

两个容易踩的坑（均出自官方下载页）：

1. **`universal` 包的内部版本号总是低于单架构包**（跨版本也是）。装新版本时如果系统提示「版本号太低」，换个单架构包装即可。
2. 官方建议优先下载 `arm64-v8a`，装不上再退回 `universal`。

**这个 MD5 值可以直接核对**：官方 Releases 页面会公布每个安装包的 MD5，`d942e9cc1498a6825cf2ee5d73694d0e` 正是官方 v1.8.4 的 `arm64-v8a` 包所列的值，所以这份包对应的架构就是 `arm64-v8a`。下载完在 PowerShell 里算一下：

```powershell
Get-FileHash -Algorithm MD5 .\文件名.apk
```

输出的哈希与上表一致即可放心装；不一致说明文件不完整或被换过，重新下载。文件名以网盘里实际显示的为准。

## 四、安装步骤

1. 把 APK 传到手机（网盘 App 下载、数据线、任意文件管理器均可），点击文件开始安装。
2. 系统如果弹出「禁止安装来自此来源的应用」，按提示进入设置，允许本浏览器或文件管理器安装未知应用，再回来点安装。
3. 装完点「打开」，或回桌面找图标。

常见安装失败提示的处理：

| 提示 | 处理 |
| --- | --- |
| 「无法安装」「应用未安装」 | 先卸载手机上同包名的旧版本再装（会清掉应用数据，想保留歌单先在软件内导出备份） |
| 「版本号太低」 | 换包型，见第二节第 1 条 |
| 「解析包时出错」 | 多半是下载没完成，重新核对 MD5 |

卸载前想保住收藏和歌单，先在软件的「设置 → 备份与恢复」里导出列表数据，装好后从同一处导入。

## 五、首次启动该注意什么

- **装完直接搜索会失败，这是预期行为**：官方从 2023-10-18 起不再提供内置在线服务，移动版 v1.2.0 移除了所有内置音源，你需要先导入自定义源，步骤见[音源导入与配置.md](音源导入与配置.md)。
- **先把设置翻一遍**：官方在移动版文档里明说，默认设置与 UI 操作不以新手友好为目标，建议用前按自己的习惯浏览一遍设置，并读一遍[歌单导入与列表使用.md](歌单导入与列表使用.md)里讲的播放列表机制，否则会出现「我只是点了一首歌，它却跑进了试听列表」这种困惑。
- **杀毒软件报毒怎么办**：官方 FAQ 的口径是——安装包由 GitHub Actions 拉取源代码构建、代码开源可查，作者只保证自己写的代码不含恶意代码与信息收集；同时第三方依赖可能带来供应链风险，且这番保证只对从官方主页链接下载的安装包成立。是否继续使用由你自己判断，这也是各杀毒软件误报时官方给的建议。
- **顺手把通知权限给上**：播放器靠通知栏那块控制条来暂停、停止，通知被禁用时它就使唤不动了。官方的处理是启动时会弹提示框让你点「去开启」启用通知；如果当时点了拒绝，去系统设置里把 LX Music 的通知重新打开，否则以后锁屏、下拉栏都没法直接控制播放，排查方法见[播放中断与歌词显示问题.md](播放中断与歌词显示问题.md)第二节。
- **首次导入音源、添加本地歌曲时会要存储权限**：允许即可，拒绝的话后面选不到文件，分别见[音源导入与配置.md](音源导入与配置.md)与[本地歌曲导入与播放.md](本地歌曲导入与播放.md)。

## 六、升级与版本

- 版本号形如 `v1.8.4`（主版本.次版本.修订号），你在用的这份是 1.8.4。
- 正式版只发在 [GitHub Releases](https://github.com/lyswhut/lx-music-mobile/releases)，更新内容看仓库里的 [CHANGELOG](https://github.com/lyswhut/lx-music-mobile/blob/master/CHANGELOG.md)；测试版走 GitHub Actions，下载需要登录 GitHub 账号，也可以用 `nightly.link` 取最新构建，但测试版可能不稳定，普通用户用正式版即可。
- 升级新版本前建议先在「设置 → 备份与恢复」导出一次列表数据，安装失败要回退时不至于丢收藏。
