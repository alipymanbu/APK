## 一、装完搜不了歌是正常的

LX Music 移动版本身不带任何在线音源，它更像一个「留了接口的播放器壳子」。官方在常见问题里写明：由于收到腾讯方面的投诉、被要求停止内置其平台的在线播放与下载服务，从 2023-10-18 起 LX Music 不再提供内置的在线播放与下载，移动版 v1.2.0 移除了所有内置自定义源，旧版本里内置的源也早已失效。

所以你第一次打开、直接搜索会一无所获，**这不是安装坏了，是你还没给它接上音源**。下面第二节就是接上的过程。

还没把软件装到手机上的，先取 [LXMusic音源 安装文件资源（夸克网盘）](https://pan.quark.cn/s/029004d89547)。

## 二、导入音源的步骤

导入入口在软件的设置里（各版本的第三方教程写法一致，均为下面这条路径，以你手机上实际界面为准）：

1. 打开 LX Music，进入 **设置 → 音乐来源 → 自定义源管理**；
2. 点 **导入**，两种方式二选一：
   - **文件导入（本地导入）**：先拿到音源脚本文件（`.js` 后缀），在文件选择器里选中它；
   - **在线导入**：粘贴一条音源链接后确认，适合链接还有效、你手边没有文件的情况；
3. 导入成功后，该源会出现在自定义源管理列表里，能看到它的名字和它声明支持的音质；
4. **回到列表里勾选 / 启用这个源**，再把它设为默认来源 —— 只导入不启用，搜索时它不会被用上；
5. 如果导完仍然搜不到东西，**完全退出应用再打开一次**（不要只按返回键退到后台）。

判断「源到底有没有在工作」的标准很简单：随便搜一首歌，能出结果、点开能播就是通了；全部歌曲都提示换源失败，跳到第四节处理。

## 三、音源脚本是个什么东西

你导入的那个 `.js` 文件是一个 JavaScript 脚本，官方对它的要求（出自移动版「自定义源脚本编写说明」）：

- 编码必须是 **UTF-8**，语法可以用 ES6+；
- 文件开头必须有一段注释头，应用靠它识别源：

```javascript
/**
 * @name 源的名字
 * @description 源的描述（可不填）
 * @version 1.0.0（可不填）
 * @author 作者（可不填）
 * @homepage 主页（可不填）
 */
```

`@name` 建议 24 字符以内，`@description` 36 字符以内。

- 脚本加载时要声明自己支持哪些平台的源（可选的 key 为 `kw` / `kg` / `tx` / `wy` / `mg` / `local`）以及支持的音质，音质只有四档：`128k`（标准）、`320k`（高品）、`flac`（无损）、`flac24bit`（Hi-Res）——你实际能看到哪几档，取决于源声明了什么；
- 移动端的脚本环境与桌面端不完全一样：浏览器、Node.js 的常用 API 在这里不可用，可用的只有一个很小的集合。自己写脚本的话照官方那份说明来，别把桌面版脚本的能力想当然搬过来。

**官方不提供任何音源脚本**，只提供导入入口与编写规范。脚本要么你自己写（[自定义源脚本编写说明](https://lxmusic.toside.cn/mobile/custom-source)），要么用别人分享的——后者来源五花八门，文件内容你看不到也改不了，是否可靠、是否合法都需要你自己判断；官方许可协议里也明确要求使用者遵守所在地法规、尊重版权，出了问题由使用者自行承担。

## 四、换源是怎么工作的

LX Music 播放一首歌时，会把歌名、歌手等信息交给当前启用的「源」，由它返回一个音频链接。由此带来两件事：

- **某个源拿不到这首歌时，软件会自动去试你启用的其他源**，这就是「换源」；所有源都拿不到，才会提示「换源失败，请尝试手动换源」。
- 源返回什么它就播什么，软件无法校验链接对不对，所以偶尔会出现「播出来的歌和点的不是一首」——多半是源给错了数据，不是你的操作问题。

想少遇到失败，通常的做法是**多导入一两个源并启用**，让自动换源有得可挑。换源相关的报错怎么排，见[播放中断与歌词显示问题.md](播放中断与歌词显示问题.md)。

### 手动指定某一首歌用哪个源

从 v1.6.0 起，长按「我的列表」里的歌曲打开菜单，有 **歌曲换源** 项，用来解决自动换源失败或换错歌的问题：选中你想用的来源，确认后软件会把列表里原来的那首替换成你选的（v1.7.1 起的行为就是直接替换，之后再播这首会优先走你指定的源）。

## 五、源失效了怎么办

音源脚本依赖对方的接口，**失效是常态**，跟软件版本无关。典型表现与处理：

| 现象 | 判断 | 处理 |
| --- | --- | --- |
| 所有歌都提示换源失败 | 源本身挂了或没启用 | 换一个还能用的源脚本重新导入并启用 |
| 部分歌失败、部分能播 | 源对这些歌没有数据 | 靠自动换源兜底，或给这首歌手动换源 |
| 之前好好的突然全不行 | 先分清是源的问题还是网络的问题 | 按[播放中断与歌词显示问题.md](播放中断与歌词显示问题.md)第三节先排查网络 |

换源脚本不会随软件自动更新，得你自己盯失效情况、自己换。
