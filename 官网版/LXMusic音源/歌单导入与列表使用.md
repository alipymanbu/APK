## 一、播放列表机制：点一首歌为什么它进了「试听列表」

这是官方 FAQ 单独拿一整页讲的机制，也是新用户最容易困惑的地方：

- 默认情况下，你在「搜索」「歌单」「排行榜」里播放某首歌时，软件会**先把这首歌加进「我的列表」下的「试听列表」，再开始播放**。它和你手动把歌加进试听列表再去播，是同一件事。
- 想一次播多首，用**多选**（长按列表里的条目进入多选模式），选完可以「添加到我的列表」或用「稍后播放」。这条对「搜索」「歌单」「排行榜」「我的列表」都适用。
- 「稍后播放」的歌进的是一个**优先级最高的特殊队列**：点「下一曲」会先按顺序消耗这个队列，且不能用「上一曲」回溯它。
- 如果你没用「上一曲 / 下一曲」，而是直接点另一个排行榜或列表里的歌来切歌，**「稍后播放」队列会被清空**；处于随机播放模式时，「已播放歌曲」队列同样会被清空（v1.1.0 起默认不清空「已播放歌曲」，需要的话在「设置 → 播放设置」里开「自动清空已播放列表」）。
- 「设置 → 列表设置 → 点击列表里的歌曲时自动切换到当前列表播放」这个选项**默认关闭**（v0.11.0 加入），且只对「歌单」和「排行榜」生效。

## 二、整份歌单、整个排行榜怎么播和收藏

| 你想做的事 | 操作 |
| --- | --- |
| 临时播一遍某歌单 | 歌单详情页上方的播放按钮 |
| 把歌单存下来反复用 | 歌单详情页的「收藏」按钮，会收进「我的列表」 |
| 播放整个排行榜 | 长按排行榜名称，在弹出的菜单里选「播放」 |
| 收藏整个排行榜 | 同上，弹出菜单里选「收藏」 |

收藏下来的在线歌单会过时，更新方式：在「我的列表」里点该列表名右侧的 `...` → 菜单里点「更新」。**这个功能只对从歌单详情页点「收藏」收藏进来的歌单有效**，你手动逐首加进去的不算。

## 三、打开别人分享的外部歌单

在软件里粘贴一个歌单链接就能打开，但有一条硬规则：

- **不支持跨源打开歌单**。歌单页右上角有个按钮标着当前的歌单源，链接是哪个平台的，就得先把歌单源切到哪个平台，否则一定打不开。
- 分享出来的链接打不开时，先在浏览器里打开它，再从浏览器地址栏复制完整 URL 粘进软件。
- 知道歌单 ID 的话，直接输入 ID 更省事。

两个官方 FAQ 里专门记了坑的场景：

**QQ 音乐源歌单打不开**：如果你的 QQ 个人主页设成了隐藏，软件就导入不了你名下的歌单。去把个人主页设为公开——PC 端是左上角头像进个人资料页、点右侧小锁图标解锁；手机端是「我的」→ 点头像进主页 → 右上角 `...` →「访问设置」→ 打开。

**网易源「私人雷达」这类打不开的歌单**：可以拼一个 Token 再打开，格式是 `歌单链接或ID###Token`，例如：

```
https://music.163.com/#/playlist?id=11332&userid=123456###你的Token
11332###你的Token
```

Token 怎么取：移动端浏览器没有开发者面板，官方建议用电脑上的桌面浏览器操作，步骤见[桌面版 FAQ 的对应章节](https://lxmusic.toside.cn/desktop/faq/cannot-open-songlist)。

## 四、多选与「不喜欢」的细节

**多选**（长按列表进入）有三种选法，官方 FAQ 给的例子：

| 想要 | 怎么点 |
| --- | --- |
| 连续选 1~5 项 | 取消默认选中，切到「区间」模式 → 点第 1 项 → 点第 5 项 |
| 只选第 1、3 项 | 直接点第 1 项、再点第 3 项 |
| 全选当前列表 | 点「全选」 |

一个坑：**在线列表是分页加载的，全选只选中已加载的那部分**——想整个歌单全选，先往下滑把它加载完，再点全选。选好后点任意一首已选中歌曲右侧的 `…`，对整批做操作（加入我的列表、稍后播放、调整顺序等）。

**「不喜欢的歌曲」**用来在自动切歌时跳过你不想听的，规则分三档：某位歌手的某一首、某一首特定的歌、某位歌手的全部歌。执行「上一曲 / 下一曲」时自动跳过命中的歌，但你手动点它还是能播。添加入口在歌曲右侧的 `...` 菜单（我的列表和在线列表都行），改规则去「设置 → 其他」里编辑。

列表数据要搬家或换设备时，用「设置 → 备份与恢复」导出、导入；导入时软件会弹二次确认（v1.8.0 起），确认覆盖前想清楚，别把本机的列表冲掉。

想把收藏同步到电脑端，走的是「数据同步」功能：需要桌面版 v2.4.0 以上（或你自己部署的独立同步服务），手机和电脑还得在同一个局域网里。配置步骤看[官方同步说明](https://lxmusic.toside.cn/mobile/faq/sync)；注意同步数据是**明文传输**，只在自己信任的网络下开。连接失败通常卡在三处：电脑防火墙拦了端口、两端不在同一网络、路由器开了 AP 隔离——官方给的自检办法是在手机浏览器里打开 `http://x.x.x.x:23332/hello`，能显示出问候语就说明网络通了。

列表机制的原文在[音乐播放列表机制](https://lxmusic.toside.cn/mobile/faq/playlist)；多选、批量排序、更新收藏这些细节也都汇总在 [FAQ 列表](https://lxmusic.toside.cn/mobile/faq) 里，用页面右上角的搜索能直接定位。

## 五、为什么这些功能在你这版里长这样

官方在移动版文档里说得很直白：为了提高使用门槛，默认设置与 UI 操作不以新手友好为目标。所以「点了一首歌却多出一条试听记录」「歌单打死打不开」这类体验不是 bug，是这套列表设计的既定行为——先按上面的机制理解它，再决定要不要改设置。
