## 一、装之前先确认它是不是你要的东西

ZOOT 是一款面向《明日方舟》玩家的同人 AI 聊天工具：内置数十位干员的角色设定，接 DeepSeek 大模型来生成对话，你可以和干员一对一私聊、拉群聊，也能自己调人设。它是第三方同人作品，**不是鹰角网络官方出品**，与游戏官方没有隶属关系。

先把手里这份安装包的事实核清楚（以本地保存的这一份为准，网上各页面标注的版本可能更新或更旧）：

| 项目 | 数值 |
| --- | --- |
| 版本 | 1.0 |
| 安装包大小 | 177.23M |
| 包名 | `com.rhodesisland.zoot` |
| MD5 | `ECACBC14F954E0DC66B8294B184CFB3C` |
| 系统要求 | 安卓手机（公开页面对最低系统版本的标注不一，以你手机实际安装为准；截至 2026-09 未见 iOS 版） |
| 语言 | 中文 |

另有两件事装之前就该知道：一是它**必须配一个 DeepSeek API 密钥才能聊起来**（应用本体只负责角色卡与界面，AI 回复走 DeepSeek 的服务，费用按 DeepSeek 官方定价计），具体见 [API密钥获取与首次配置.md](API密钥获取与首次配置.md)；二是安装包接近 180MB，安装解压过程还需要额外空间，手机存储建议留出 1GB 以上再动手。

应用本身按公开介绍免费使用、无内置广告（个别渠道页面标注含内购项，口径不一，以你装到手的实际表现为准）。它还有个别名叫「罗德岛通讯端」，搜资料时两个名字都能试。

## 二、获取安装文件资源

这份 ZOOT 安装文件资源（夸克网盘）在：[https://pan.quark.cn/s/704ea0ae3cd4](https://pan.quark.cn/s/704ea0ae3cd4)

获取步骤：

1. 手机或电脑上打开上面的链接，先把分享内容**转存到自己的夸克网盘**（分享文件可能随时失效，转存后才是你的）；
2. 转存后在网盘里找到 APK 文件，下载到手机本地存储；
3. 下载完成后先别急着安装，建议按下一节核一遍 MD5。

## 三、核对 MD5（可选但建议做）

从网盘转存再下载，中间多一道环节，文件损坏的概率虽低但确实存在。核一遍 MD5 只花半分钟：

1. 手机端可用带哈希校验功能的文件管理器，或装一个校验类小工具；电脑端在 PowerShell 里执行：

   ```powershell
   Get-FileHash "C:\下载路径\ZOOT_v1.0.apk" -Algorithm MD5
   ```

2. 把算出的值与 `ECACBC14F954E0DC66B8294B184CFB3C` 比对（不区分大小写）；
3. 对不上就删掉重新下载，别硬装 —— 损坏的包装到一半报错，排查起来反而费时。

## 四、安装步骤

安卓安装非商店来源的 APK，系统默认会拦一道，流程如下（不同品牌菜单名略有差异）：

1. 在文件管理器里找到刚下载的 APK，点它；
2. 第一次安装会弹「禁止安装来自此来源的应用」之类的提示 → 按提示去系统设置，给**文件管理器（或你用的浏览器）**开「安装未知应用」权限；
3. 返回后继续点安装，等待完成；
4. 如果手机上以前装过 ZOOT（哪怕是别的渠道下载的），签名不一致会报「应用未安装」—— 先卸载旧版再装。注意卸载会清掉本地的聊天记录与存档，有要留的内容先在应用里保存好（见 [常见问题与故障排查.md](常见问题与故障排查.md) 第六节）。

## 五、装完第一步：别急着找干员聊天

点开 ZOOT，你会先进入一个「罗德岛通讯端」风格的界面，但此刻还聊不了 —— 首次启动要先完成三件事：**选择 AI 模型、填入 API 密钥、填写博士姓名**。这三步的具体操作与密钥从哪来，直接看 [API密钥获取与首次配置.md](API密钥获取与首次配置.md)，配完就能进联系人列表挑干员开聊了。

安装环节卡住（点开没反应、解析包出错、装完闪退等）时，去 [常见问题与故障排查.md](常见问题与故障排查.md) 按现象对号入座。
