## 一、为什么必须先配密钥

ZOOT 本体里放的是干员角色卡、人设逻辑与界面，真正生成对话的是 **DeepSeek 大模型** —— 应用把你的消息和人设一起发给 DeepSeek 的服务，拿回回复再以干员口吻显示出来。所以：

- 没有密钥，首次设置的向导走不完，进不了联系人列表；
- 密钥是你自己的 DeepSeek 账号凭据，**对话的 token 费用记在这个账号上**，与 ZOOT 无关；
- 密钥别发给别人 —— 拿到它的人可以用你的额度聊天。

## 二、获取 DeepSeek API 密钥

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com)，用手机号注册并登录；
2. 登录后进入 **API keys** 页面，点「创建 API key」；
3. 给密钥起个名字（比如 `zoot`，方便以后辨认用途），确认创建；
4. 页面会显示一次完整的密钥（一长串字符）—— **只显示这一次，当场复制保存**，关掉就再也看不全了，只能删掉重建。

费用方面按 token 用量计费，价格与充值方式以 DeepSeek 官网当时显示为准；实际用掉多少可在平台的用量明细页核对，聊得越多花得越多，心里有数再用。账户额度用尽时对话会失败，处理方式见 [常见问题与故障排查.md](常见问题与故障排查.md) 第一节。

## 三、在 ZOOT 里完成首次配置

打开 ZOOT，首次启动会直接进入设置向导，三步：

1. **选择 AI 模型**：列表里选 DeepSeek（应用内置了模型选项，不需要你手动填接口地址）；
2. **粘贴 API 密钥**：把上一节创建的密钥完整粘进输入框 —— 常见翻车是粘贴时带上了空格或少了头尾字符，粘完从头到尾目视检查一遍；
3. **填写博士姓名**：这是干员称呼你的名字，会出现在对话里，随意起但建议别用真实姓名；

保存后进入首页，能看到联系人页面就说明配置生效了。后续修改：设置入口一般也在首页可达，换密钥、改名字都在同一个地方操作。

## 四、配置完还是不能聊，按这个顺序查

1. **密钥无效提示**：多半是复制不完整 —— 回到 DeepSeek 平台删掉这枚 key 重新创建一枚，重新粘贴；
2. **额度不足 / 余额为零**：DeepSeek 账户没有余额时 API 调用会被拒绝，去平台充值或等额度恢复（规则以官方为准）；
3. **报网络错误**：确认手机能正常上网；部分网络环境访问境外服务商不稳定，换 Wi-Fi 或流量试试；
4. 以上都对仍然无回复、界面空白，转到 [常见问题与故障排查.md](常见问题与故障排查.md) 第一节，那里还有运行中途突然失效的处理办法。
