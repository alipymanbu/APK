# popupControl 管不了的弹窗与替代方案

> 它只管通知横幅这一种弹窗；应用内广告、来电全屏、网页弹窗各是另一套机制。本篇帮你先分清看到的是哪种，再给每种对应的系统开关。

## 一、先分清你看到的是哪种「弹窗」

「弹窗屏蔽」这个词容易让人以为它什么都能拦。实际上安卓里能盖在你屏幕上的东西至少有四类，popupControl 只对应其中一类（通知横幅，判据见 [按应用与分类关闭弹窗.md](按应用与分类关闭弹窗.md) 第一节）。先对照下表归类，再去对应的章节处理：

| 你看到的 | 归类 | 它管吗 | 去哪处理 |
| --- | --- | --- | --- |
| 从屏幕顶部滑下、悬停几秒、下拉能在通知栏找到 | 通知横幅（heads-up） | **管** | 本应用列表里关 |
| 只在打开某个应用时出现，关掉后应用里还有、通知栏里也找不到 | 应用内广告/应用自己画的界面 | 不管 | 见第二节 |
| 来电、闹钟直接占满整个屏幕、锁屏也亮 | 全屏接管（full-screen intent） | 不管 | 见第三节 |
| 浏览器里网页弹出的新窗口/广告层 | 网页弹窗 | 不管 | 见第四节 |

判断小技巧：弹出来之后**下拉通知栏找一找**——找得到这条内容，它就是通知，归 popupControl 管；找不到，就按上表往下走。

## 二、应用内广告：通知栏里找不到的那种

**判据**：广告只在你使用某个应用的过程中出现，关掉之后应用界面里还在，通知栏里也找不到对应条目。这不是通知，是应用自己在界面上画的元素，任何通知管理工具都碰不到它。

处理顺序：

1. 先确认它到底是不是通知（用第一节的下拉检查法）；
2. 确认是通知但横幅关不掉 → 回 [常见问题与排查.md](常见问题与排查.md) 第三节按序排查；
3. 确认不是通知 → 只有两条路：去**该应用自身的设置**里找广告/推送开关；或者把该应用的通知权限整个关掉（系统设置 → 通知 → 该应用 → 关闭允许通知），看它还弹不弹——通知整个关掉后仍弹，就坐实了是应用内元素，与 popupControl 无关。

## 三、来电、闹钟的全屏接管

来电界面、闹钟响铃是**全屏 intent** 通知，设计上就是要占满屏幕（防止你错过），不走普通横幅那套规则，所以 popupControl 的开关对它无效。安卓系统对此有单独的管控：

- 路径：**设置 → 应用 → 特殊应用权限 → 全屏 intent**（英文系统叫 Full-screen intent；菜单名以你的系统为准，可在设置里搜「全屏」）；
- 列表里逐个应用开关：把不需要占屏的应用关掉，来电、闹钟类应用保持开着；
- 截至安卓 14，全屏 intent 被收紧为特殊权限，新装应用默认拿不到，多数应用已自动退回普通横幅——若某应用还能全屏弹，先来这个页面看它的开关。

想让某类通知**更安静**（不响铃、不振动），不在这里设，去系统设置 → 通知 → 该应用 → 通知类别里把对应类别调成「无声」。

## 四、浏览器里的网页弹窗

浏览器内的弹窗由浏览器自己拦，与系统通知无关。以 Chrome 为例：**设置 → 网站设置 → 弹出式窗口和重定向**，保持关闭即可；个别网站需要放行时，在同一页面单独加允许。其他浏览器在自己的设置里找「弹窗拦截」「Pop-ups」字样，开关逻辑一样。

手机桌面上冒出的「某某网页」广告通知，则回到通知范畴——用 popupControl 关它的横幅，或直接在系统里关掉那个来源应用的全部通知。

## 五、什么时候不用 popupControl 也行

对照自己的诉求选：

| 你的诉求 | 更直接的做法 |
| --- | --- |
| 某个应用彻底安静（不横幅、不响铃、通知栏也不收） | 系统设置 → 通知 → 该应用 → 关闭「允许通知」，一步到位 |
| 只是不想看横幅打断，但通知还要留着、还要响铃 | 这正是 popupControl 的场景（[按应用与分类关闭弹窗.md](按应用与分类关闭弹窗.md)） |
| 一段时间内全安静（睡觉、开会） | 系统自带的勿扰模式，按日程自动开关 |
| 同一应用只留重要类别弹出、营销类别闭嘴 | popupControl 按类别设，或系统设置里该应用的通知类别逐项调 |

两条路最终都是让通知不弹横幅，具体表现以你手机上的实际效果为准；混着设搞不清时，先用 popupControl 的 Restore default settings 清掉它的改动，回到干净状态再逐项试。应用本身的获取与安装见 [下载与安装教程.md](下载与安装教程.md)。
