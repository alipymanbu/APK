## 一、为什么必须开这个权限

popupControl 的工作方式是接管系统的通知显示规则：你要先告诉系统「让 popupControl 来决定哪些通知能弹横幅」。对应到系统里就是**通知访问权限**（英文界面叫 Notification access）。不开这一步，应用里的应用列表加载不出来，设置也全部不生效——首次设置向导会卡在「必须先选择应用」的提示上。

这也是整个应用唯一需要你手动授予的特殊权限，安装阶段本身不需要其他授权（安装步骤见 [下载与安装教程.md](下载与安装教程.md)）。

## 二、标准路径（原生及接近原生的系统）

不同安卓版本菜单名略有差别，路径是同一套：

- Android 12 及以上：**设置 → 应用 → 特殊应用权限 → 通知访问权限**，或直接在设置顶部搜索框搜「通知访问」；
- Android 10 / 11：**设置 → 隐私 → 权限管理 → 特殊应用权限 → 通知访问权限**；
- Android 9 及以下：**设置 → 应用和通知 → 高级 → 特殊应用权限 → 通知访问权限**。

进入「通知访问权限」列表后，找到 **popupControl**（有的系统显示为 Disable Notification Popups），把开关打开，系统弹出的确认对话框选允许。

拿不准就直接在设置里搜「notification access」——这是最省事的办法，各品牌的菜单层级经常变，搜索能直达。

## 三、常见国产品牌的入口

国产品牌把这套菜单改了名字，对照下表找：

| 品牌 | 大致入口（菜单名以当前系统为准） |
| --- | --- |
| 小米 / Redmi（MIUI、HyperOS） | 设置 → 隐私保护 → 特殊权限 → 设备与应用通知（通知使用权） |
| 华为 / 荣耀 | 设置 → 搜索「通知使用权」或「通知访问」 |
| OPPO / realme、vivo / iQOO | 设置 → 安全/隐私 → 更多特殊权限 → 通知使用权 |
| 三星 | 设置 → 应用 → 右上角菜单 → 特殊访问 → 通知访问权限 |

找不到就用系统设置的搜索功能，输入「通知」或「notification」逐条看结果。

## 四、Android 13+：侧载后开关是灰的（受限设置）

从商店以外渠道装的 APK（包括网盘里下载的），Android 13 起会被标记为「受限应用」，通知访问权限的开关直接置灰、点了没反应。解除方法：

1. 正常点一次那个灰开关，系统会弹「受限设置」提示，先关掉它；
2. 回到 **设置 → 应用 → popupControl** 的应用信息页；
3. 点右上角 **⋮（三个点）菜单 → 允许受限设置**，输入锁屏密码确认；
4. 再回到通知访问权限列表，此时开关已可点，打开即可。

注意：那个 ⋮ 菜单里的「允许受限设置」**只有在你先点过一次被拦的开关之后才会出现**，直接去看是找不到的。如果你是从 Google Play 装的，则没有这一步。

## 五、开完怎么确认真的生效

回到 popupControl，首次设置向导的应用列表应当加载出你手机里装的应用；列表是空的说明权限没给到位，见 [常见问题与排查.md](常见问题与排查.md) 第二节。列表正常后，按 [按应用与分类关闭弹窗.md](按应用与分类关闭弹窗.md) 选择要屏蔽的应用即可。

## 六、权限被系统收回了怎么办

部分品牌手机在重启、系统更新或清理后台后会收回通知访问权限，表现是「以前关掉的弹窗又冒出来了」。处理很直接：重新走一遍第二节的路径，确认 popupControl 的开关还开着；顺带把该应用加入电池优化白名单、允许自启动（各品牌叫法不同），减少被后台管理误杀的概率。更多表现与排查顺序见 [常见问题与排查.md](常见问题与排查.md)。
