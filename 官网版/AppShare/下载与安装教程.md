## 一、先分清你要装的是哪一份

AppShare 由邢台市牧歌信息技术有限公司开发，包名 `info.muge.appshare`，目前能碰到的获取渠道主要有两类，拿到的不是同一份东西：

| 渠道 | 版本 | 商店页/来源简介里写的能力 |
| --- | --- | --- |
| 应用商店（如[应用宝详情页](https://sj.qq.com/appdetail/info.muge.appshare)） | 5.0.2（截至 2026 年 9 月的商店页面） | 查看应用信息、导出 APK 到公共文件夹、模糊搜索、查看系统应用等本机功能 |
| 本文的网盘资源 | 5.0.9 | 完整客户端，除本机功能外还带应用分享社区（资源区、广场、积分等） |

如果你只想要「看本机应用信息 + 导出安装包」，商店版也能满足；想用它的应用分享社区，就用网盘这份 5.0.9。两份装好后的界面以你手机上实际显示的为准。

## 二、安装前先核对一遍安装包

网盘里这份安装包的信息如下。下载完成后，建议先核一遍再点安装：

| 项目 | 值 |
| --- | --- |
| 版本号 | 5.0.9 |
| 包名 | `info.muge.appshare` |
| 大小 | 33.15 MB |
| MD5 | `77EC855B149E7F2986147487C175217B` |

核对 MD5 的办法：

1. 安卓上用带「校验文件」功能的文件管理器（不少国产系统自带），或装一个小型哈希校验工具，对 APK 算 MD5；
2. 算出的值与上表逐字比对（不区分大小写）；
3. 对不上就别装——要么下载不完整，要么文件被替换过，回网盘重新转存一份即可。

## 三、安装步骤

1. 打开 [AppShare 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6394c32b10dd)，把安装包转存到自己的网盘后下载到手机存储；
2. 在文件管理器里点开这个 APK，系统第一次会提示「未知来源应用」，按提示允许该来源安装（不同厂商的入口见下一节）；
3. 回到安装界面点「安装」，等进度走完；
4. 点「打开」进入应用；第一次启动一般会有权限申请与协议弹窗，按需同意即可。

## 四、安装被拦下来怎么办

国产系统对应用商店之外的安装包普遍有拦截，常见的几种处理方式：

| 现象 | 一般处理 |
| --- | --- |
| 提示「禁止安装未知来源应用」 | 系统设置里搜「安装未知应用」，给你用来下载/打开 APK 的那个应用授权 |
| 小米/红米：提示被「纯净模式」拦截 | 设置里暂时关闭纯净模式，装完可再打开 |
| 华为/荣耀：提示被「应用管控/纯净模式」拦截 | 关闭纯净模式或按弹窗指引「继续安装」 |
| 装到一半提示「解析包错误」 | 多半是下载不完整或版本与系统不匹配，先按第二节核对 MD5，再确认自己的安卓版本 |

以上入口名称各系统叫法不同，以你手机设置里的实际搜索结果为准。

## 五、首次启动会用到哪些权限

按开发者 2026 年 1 月发布的[隐私政策](https://link.appshare.muge.info/appshare/privacy.html)，应用围绕「展示已装应用列表、提取 APK」申请这几项权限：

| 权限 | 用途 |
| --- | --- |
| 查询全部应用（QUERY_ALL_PACKAGES 等） | 列出并展示本机已安装应用 |
| 存储读写 | 保存提取出的 APK 文件与应用图标 |
| 剪贴板（写入） | 你点「复制包名」「复制签名」时把文本放进剪贴板 |

政策原文同时声明：查询结果与导出文件只保存在本地，不收集身份、位置、通讯录等个人信息。政策内容可能随版本更新，装好后以应用内展示的版本为准。
