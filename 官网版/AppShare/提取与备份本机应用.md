## 一、能对本机应用做什么

打开应用后进入本机应用列表，你能对每一个已装应用做到这几件事（能力范围来自商店页简介与开发者隐私政策，个别入口的位置以你手机上的实际界面为准）：

| 动作 | 说明 |
| --- | --- |
| 查看应用信息 | 版本、包名、权限等基础信息，系统应用也能查 |
| 模糊搜索 | 按名称等各种信息搜，应用多时找目标快 |
| 导出 APK | 把该应用当前的安装包提取出来，存到公共文件夹（如 Download 一类目录） |
| 复制包名 / 签名 | 一键写进剪贴板，方便去别处比对或提工单时贴给对方 |

列表里会同时出现普通应用和系统应用。系统应用通常用不上导出，但查看信息（搞清楚某个预装应用是什么）是个常见用途。

## 二、导出 APK 的操作步骤

1. 在应用列表里找到目标应用（搜索框可以按包名、名称模糊匹配）；
2. 点进应用详情，选导出/提取；
3. 导出的文件会保存到你设置的导出目录（首次导出会请求存储权限，允许即可）；
4. 用系统文件管理器进入对应文件夹，就能看到 `.apk` 文件，长按可以分享、复制、上传网盘。

给你的两个判断依据：

- **导出≠备份全部数据**。APK 只是安装包，聊天记录、账号数据、缓存都不在里面；换机场景下它能帮你省「重新找安装包」这一步，数据本身仍要走各应用自己的迁移通道。
- **系统应用的包别指望装回别的设备**。系统应用常带设备或厂商签名约束，导出来留档可以，跨设备安装大概率失败或不可用。

## 三、导出的安装包有什么用

- **留底**：某个应用商店突然下架、或最新版你不满意时，手里有旧版 APK 就有退路；
- **传给别人**：把 APK 发给朋友，对方直接安装，不用再去找资源；
- **回填社区**：AppShare 社区本身吃用户上传，你手里的冷门旧版本正是别人会搜的东西，上传规则见[上传分享与积分规则](上传分享与积分规则.md)。

## 四、几个边界提前知道

- 你导出的是「本机装的这一版」，与商店当前在架版本可能是两个东西；发给别人前最好注明版本号；
- 导出行为只读你自己的设备，不碰应用数据，但分发别人版权应用的 APK 仅限朋友间自用，别拿去做资源生意；
- 导出大量应用时建议按批次来，公共文件夹里同名应用注意先看清版本号再删旧的，误删了就再导一次（应用还在，随时可重导）；
- 系统安装器拦着不让装导出的包时，可以换第三方安装器试试——应用 5.0.x 的更新日志里提过新增第三方安装器支持，入口以实际界面为准。

装 AppShare 本身如果还没落定，安装与权限说明在[下载与安装教程](下载与安装教程.md)；资源区那边怎么搜旧版本，见[资源下载与更新提醒](资源下载与更新提醒.md)。
