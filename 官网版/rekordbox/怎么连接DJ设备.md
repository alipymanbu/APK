# rekordbox 手机版怎么连接DJ设备

> 手机版可以接两类硬件：DJ 控制器（在家打碟练手感）和 CDJ/XDJ 播放器（把手机当 U 盘用）。本篇讲控制器怎么连、连之前要准备什么、连不上的排查顺序；CDJ/XDJ 的机型与接法细节单独成篇。

## 一、连之前的三项准备

1. **登录账号**：连接 DJ 设备打碟属于需要登录 AlphaTheta 账号的功能，没登录时连上硬件也无法使用。
2. **确认型号在兼容列表里**：手机版只支持官方列出的控制器型号，不在列表里的设备（包括很多支持电脑版的控制器）连上也不会被识别。
3. **准备好线材或蓝牙**：部分控制器走 USB 线连接，部分支持蓝牙，个别型号两种都支持。

## 二、兼容的 DJ 控制器

官方页面列出的手机版兼容控制器（截至撰写时，以官方页面为准）：

| 控制器 |
| --- |
| DDJ-200 |
| DDJ-FLX2 |
| DDJ-FLX4 |
| DDJ-GRV6 |

连接方式为 USB 数据线或蓝牙（官方对兼容控制器的统一说明），具体到某一型号支持哪种、需要什么转接件，以该型号的官方页面为准。这几款均为官方清单内的型号，购买前建议在官方支持页面再核一遍兼容清单——这个列表会随版本更新。

## 三、连接控制器的步骤

1. 打开控制器电源；用 USB 线连到手机（部分手机需要带供电的转接），或在手机蓝牙设置里与控制器配对。
2. 打开 rekordbox，登录 AlphaTheta 账号。
3. 在应用的硬件连接入口选择已连接的控制器，等待识别完成。
4. 控制器识别成功后，推子、转盘、打击垫会直接控制手机版界面；耳机监听（预监听）功能受订阅状态影响，见[免费版和付费订阅区别](免费版和付费订阅区别.md)。

## 四、把手机接到 CDJ/XDJ 上播放

俱乐部场景下，手机版可以把手机当作 U 盘使用，让 CDJ/XDJ 播放器直接读取手机资料库里的曲目，走 Wi-Fi（PRO DJ LINK）或 USB 线两种接法。这一块细节多——兼容机型表、各机型要用的线材类型、以太网接法——单独放在[CDJ和XDJ怎么连手机](CDJ和XDJ怎么连手机.md)里讲。这里只给两条最常用的经验：

- 出发前把要用的歌、CUE 点都准备好，灰色标题的歌先把文件本体同步到手机——现场网络不稳时，USB 直连是最稳的一条路。
- 部分安卓机型存在 USB 连接 CDJ 失败的情况（与各厂商 USB 模式差异有关），连不上就改走 Wi-Fi。

## 五、Lite 模式：没接硬件时的简化玩法

手机版内置 Lite 模式，只用屏幕就能开始混音。它刻意砍掉了一批进阶操作来降低上手门槛：

- **可用**：同步（固定开启）、智能推子（固定开启）、交叉推子、采样器、打击垫效果。
- **不可用**：CUE 点设置（Hot Cue / Memory Cue）、自动与手动循环、节拍跳跃、变速杆、SLIP、调音台 EQ 与增益、键盘模式、录音及上传。

也就是说 Lite 模式适合「先随手混着玩」；等你需要设 CUE 点、精细控制音量与效果时，切出 Lite 模式用完整界面。完整界面的功能边界受订阅影响。

## 六、连不上的排查顺序

1. **控制器没被识别**：确认型号在第二节列表内；换一根数据线（很多线只能充电）；USB 直连不行的先试蓝牙。
2. **连上但无法使用**：检查是否已登录 AlphaTheta 账号——未登录时硬件功能不开放。
3. **CDJ 读不到手机**：换 USB 线与接口；安卓手机把 USB 模式设为文件传输；仍不行改用 PRO DJ LINK 无线连接。
4. **PRO DJ LINK 搜不到设备**：确认手机与播放器在同一网段；路由器 AP 隔离关掉。

其余软件侧的问题（登录、录音、同步）见[常见问题与解决办法](常见问题与解决办法.md)。
