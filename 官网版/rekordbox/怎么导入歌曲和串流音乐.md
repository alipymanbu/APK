# rekordbox 手机版怎么导入歌曲和串流音乐

> 手机版打碟的前提是资料库里有歌。本篇覆盖三条取歌途径：导入本机音频文件、从电脑同步曲库、登录串流服务在线取歌，以及各自会用到的限制。

## 一、先确认文件格式

手机版能直接处理的音频格式包括 MP3、AAC、WAV、AIFF、FLAC、ALAC。不在列表里的格式（如部分加密或小众封装）导入后可能无法解析，转成上述格式再导入即可。

## 二、导入本机文件

1. 首次启动应用时同意「音乐和音频」访问权限，否则应用看不到手机里的歌曲。
2. 在应用内的导入入口选择手机存储里的音频文件，加入资料库。
3. 导入后应用会分析每首歌的 BPM 与节拍网格——这是设置 CUE 点和自动混步的基础，文件多时需要等一段时间。

装好应用后，最快的一批歌通常就是你手机里已有的下载音乐。安装步骤见[下载与安装教程](下载与安装教程.md)。

## 三、从电脑同步：Mobile Library Sync

如果你的歌都整理在电脑版 rekordbox 里，手机版可以走 **Mobile Library Sync** 拿过来：

1. 电脑与手机连到**同一个 Wi-Fi 网络**（这是最常见的不成功原因）。
2. 电脑版 rekordbox 开启移动设备同步相关选项，手机版发起连接。
3. 同步是双向的：在手机上改的 CUE 点、播放列表，重新连到同一网络后会写回电脑的曲库。

此功能免费，不需要订阅；但需要登录 AlphaTheta 账号。注意它同步的是 rekordbox 曲库数据，不能同步到 ver. 5 及更早的电脑版。

## 四、云曲库同步：Cloud Library Sync

- 作用：把曲库放到云端（配合 Dropbox 账号），多台设备通过任何网络自动保持一致，不用挤同一个 Wi-Fi。
- 额度：订阅了 Creative 或 Professional 计划时不限量；Free 与 Core 计划只有 20 首的同步额度。
- 入口：手机版登录 AlphaTheta 账号后开启。

要不要为云同步付费，判断标准只有一个：你是否真的需要多设备、多地点自动保持曲库一致。只在单台手机上用的话，它没有存在的必要。

## 五、串流服务在线取歌

手机版支持登录串流服务直接取歌打碟，已上线的包括 Apple Music、TIDAL、Spotify（Spotify 为 2025 年 12 月起支持；各地区可用的服务不同，以应用内实际显示为准；Beatport Streaming 仅 iOS 版提供）。

用串流曲库时要知道两条限制：

1. **串流曲目不能录音**——录下自己的混音时，串流来源的轨道会被排除。
2. **离线不可用**——串流歌曲依赖网络，演出场合建议把关键曲目换成本地文件。

另外，串流账号是各服务自己的订阅，rekordbox 这边不代替你付费。

## 六、导入或同步失败的排查方向

| 现象 | 先查什么 |
| --- | --- |
| 导入入口里看不到歌 | 是否授予了音频文件访问权限；文件是否为支持的格式 |
| Mobile Library Sync 连不上 | 两台设备是否真在同一网段；路由器是否开了 AP 隔离 |
| 云同步只有 20 首 | 当前订阅计划是否为 Free/Core，见[免费版和付费订阅区别](免费版和付费订阅区别.md) |
| 串流登录失败 | 该服务在你所在地区是否可用；账号订阅是否有效 |

仍解决不了的问题，转到[常见问题与解决办法](常见问题与解决办法.md)对照更多条目。
