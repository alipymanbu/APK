# CDJ和XDJ怎么连手机

> 把手机上的歌放到俱乐部设备上播，有 Wi-Fi（PRO DJ LINK）和 USB 线两种接法。本篇列出官方兼容机型表、每种接法要准备的线材，以及连不上的处理。

## 一、先分清两种用途

- **手机当 U 盘给播放器读**：手机用线（或 Wi-Fi）接到 CDJ/XDJ，播放器像读 U 盘一样浏览手机资料库里的歌——这是俱乐部场景最常用的方式。
- **PRO DJ LINK**：手机与播放器接入同一网络后无线加载曲目，还支持多台播放器共享。

两种用途都要求设备在官方兼容列表内，且手机端已登录 AlphaTheta 账号、要播的曲子已导入手机资料库（导入方法见[怎么导入歌曲和串流音乐](怎么导入歌曲和串流音乐.md)）。

读这张表的三个要点：

1. **USB 一列标的是播放器那头的端口类型**——标 Type-B 的机型用 A 转 B 的数据线，标 Type-C 的机型用 C 对 C 数据线；标「不支持」的机型走不了 USB 有线，只能 Wi-Fi 或以太网。
2. **XDJ-RR / RX3 / RX2 没有 Wi-Fi**——这三台一体机只能靠线连手机，出门前确认带了线和转接头。
3. **XDJ-AN / OMNIS-DUO 只有 Wi-Fi**——不支持 USB 与以太网有线。

## 三、Wi-Fi 连接（PRO DJ LINK）

1. 准备一台无线路由器（带交换机功能的更好，方便播放器接线）。
2. CDJ/XDJ 用网线接入路由器；一体机连自家网络或按说明书配置。
3. 手机接入同一台路由器的 Wi-Fi。
4. 打开手机上的 rekordbox，选择 PRO DJ LINK 连接入口，等待识别出播放器。
5. 在播放器上浏览手机资料库、加载曲目播放。

现场如果路由器不可控，用自己的随身路由器比碰运气稳得多；手机流量热点不适合 PRO DJ LINK（播放器不在同一网段）。

## 四、USB 有线连接

1. 确认播放器的 USB 端口类型（见第二节表格第二列）。
2. 准备对应线材：Type-B 机型用 USB A 转 B 线，Type-C 机型用 C 对 C 线；手机那头视接口可能需要 OTG 转接头。
3. 手机接上播放器的 USB 端口。
4. **切换到有线前，先关掉手机的 Wi-Fi**（官方说明的要求，否则连接不生效）。
5. 在播放器上像浏览 U 盘一样浏览手机资料库。

官方同时说明：外部设备、线材、转接头的组合千差万别，官方不保证所有组合都能正常工作；实测中部分安卓机型 USB 连不上 CDJ（与厂商 USB 模式差异有关），遇到就改走 Wi-Fi。

## 五、以太网连接

Wi-Fi 环境不稳但设备支持以太网时，手机可以用「网线 + 转接头」接入路由器：手机经 USB 转以太网适配器接到路由器或 LAN 分线器，播放器也接同一网络，再按第三节的流程识别。同样要先关手机 Wi-Fi 再切换有线。

## 六、两个常见误区

1. **手机版不能把歌「导出」到 U 盘**。官方明确：rekordbox 移动版不支持向 USB 存储设备导出。想给俱乐部设备备一份歌，要么手机直接接播放器，要么在电脑版里导出。
2. **「灰色的歌」在播放器上放不出来**。资料库里标题呈灰色的曲目表示音频文件不在手机上（只有曲库信息）；用 Mobile Library Sync 或云同步把文件传到手机后再带去现场，同步步骤见[怎么导入歌曲和串流音乐](怎么导入歌曲和串流音乐.md)。

连接环节之外的问题（登录、识别不到设备等）见[常见问题与解决办法](常见问题与解决办法.md)；控制器（DDJ 系列）的连接见[怎么连接DJ设备](怎么连接DJ设备.md)。
