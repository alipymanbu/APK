## 一、免费版的边界

官方对手机版免费版的口径是：基础功能免费、无广告。具体来说：

- 导入本机歌曲、管理曲库、建播放列表——不受限。
- 在手机上打碟（完整界面与 Lite 模式）——可以用。
- 连接兼容控制器（DDJ-200 / DDJ-FLX2 / DDJ-FLX4 / DDJ-GRV6）——可以用。
- 录音——可以录，但**只给 AAC 64kbps 一种低码率格式**；订阅后才能选 WAV 或更高码率的 AAC。
- 云曲库同步——Free 计划只有 20 首的同步额度。

还没装的话，可以从 [rekordbox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/31ac6dc10f6e) 获取安卓安装包，先按免费版把流程走通再考虑要不要订阅。

## 二、应用内订阅解锁什么

手机版的应用内订阅按 **周付（7 天）/ 月付（30 或 31 天）/ 年付（365 天）** 三档计费，在应用内直接购买。解锁的增强项包括：

| 解锁项 | 免费版的表现 |
| --- | --- |
| 去广告 | 官方应用内问答把「隐藏广告」列为付费功能，官网页面又宣传「基础功能免费且无广告」，两处口径不一致——以你设备上的实际显示为准 |
| 播放时横屏 | 免费版锁竖屏 |
| 更多效果器 | 免费版效果种类较少 |
| 预监听（Pre-cueing） | 接控制器时用耳机提前听下一轨；未订阅不可用 |
| 控制曲目调性（Key 控制） | 免费版不可用 |
| 打击垫自定义 | 免费版为固定布局 |
| SLIP 模式 | 免费版不可用 |
| 高质量录音 | 免费版仅 AAC 64kbps，订阅后可选 WAV 44.1/48kHz 与 AAC 64~320kbps |

其中对实际影响最直接的是**预监听**和**录音码率**：想接控制器认真练，先确认这一项——它决定你能否在公放前用耳机提前听下一轨；想把自己混的带子发出去，则要知道 64kbps 属于低码率格式，听感损失可辨。

## 三、电脑版订阅计划对手机端的影响

官网购买的订阅计划（Free / Core / Creative / Professional）主要服务电脑版，但其中**云曲库同步（Cloud Library Sync）的额度直接决定手机端云同步体验**：

| 计划 | 手机端云同步额度 | 单订阅可激活设备数 |
| --- | --- | --- |
| Free | 20 首 | — |
| Core | 20 首 | 3 台 |
| Creative | 不限量 | 4 台 |
| Professional | 不限量（附 5TB 云存储与自动上传） | 8 台 |
| Free / Core / Creative 加购 Cloud Option | 全库同步，自动上传上限 1TB | 3 台 |

两点细节：

1. Free 与 Core 的「20 首」不是随便挑 20 首，而是只能同步放进官方指定播放列表（Trial playlist - Cloud Library Sync）里的曲目，整库不会被同步。
2. 会变的数字写在这里也提醒一句：激活设备数与计划内容以官方订阅页面当时显示为准。单机用户几乎碰不到这些差异；有多台设备或需要跨网络同步曲库的，才值得往 Creative 及以上看。

## 四、别把三种付费混为一谈

1. **应用内订阅**：只作用于手机端增强项，取消后预监听、横屏、高码率录音等回到免费状态。
2. **电脑版订阅计划**：作用于桌面端功能与云同步额度，与手机应用内订阅互不替代。
3. **串流服务会员**：Apple Music / TIDAL / Spotify 各自的订阅，rekordbox 只负责登录取歌；没有对应会员，串流曲目自然用不了。

按需组合即可：只在手机上随便玩玩，一分钱不用花；接控制器练琴，考虑月付应用内订阅；多设备同步曲库，看电脑版 Creative 计划。

## 五、订阅管理要注意的两点

1. **取消不退款**：官方订阅条款明确，随时可以取消，但已付费用不退；取消后可用到当前付费期结束。桌面端计划在订阅开始后 14 天内可通过官方指定渠道申请退款，应用内订阅则按 Google Play 的政策处理。
2. **改计划不用先解约**：换档在订阅页面直接选新计划；解约后在下一个扣费日前无法订购其他套餐。

具体价格与各档功能对照，以官方订阅页面为准；价格随地区与促销变动，本文不列具体金额。
