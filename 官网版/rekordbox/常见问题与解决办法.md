## 一、为什么打开应用要求登录

手机版有几类功能必须登录 AlphaTheta 账号，不登录时这些功能入口直接不可用：

- 连接 DJ 设备打碟（DDJ-FLX2、DDJ-GRV6、DDJ-FLX4、XDJ-AN 等）
- 云曲库同步（Cloud Library Sync）
- 与同一 Wi-Fi 下的电脑版 rekordbox 同步曲库
- 通过 CloudDirectPlay 在兼容设备上播放云曲库

只在本机导入歌曲、用屏幕打碟，不登录也能用。账号在官网注册；登录同时用于跨设备识别你的订阅状态。

## 二、安装与运行问题

| 现象 | 判据与处理 |
| --- | --- |
| 提示「应用未安装」 | 检查剩余存储是否够（安装包约 222 MB，安装展开还要更多空间）；重新下载 APK 并核对 MD5，损坏的包装不上 |
| 装上后闪退 | 确认系统版本在官方兼容范围（当前页面为 Android 13~16，随版本更新变化）；部分机型系统定制可能导致不兼容，官方明确不保证所有安卓机型可运行 |
| 界面不是中文 | 语言跟随系统；在系统设置里把应用语言设为中文后重启应用 |
| Google Play 装不了 | 从 [rekordbox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/31ac6dc10f6e) 获取 APK 手动安装，步骤见[下载与安装教程](下载与安装教程.md) |

## 三、录音相关问题

| 现象 | 判据与处理 |
| --- | --- |
| 录音按钮不可用 | 设备剩余空间是否 ≤ 500 MB（含 SD 卡合并计算）；串流来源的曲目不能录 |
| 只能录 AAC 64kbps | 这是免费版的格式上限，订阅后可在设置里选 WAV 44.1/48kHz 或 AAC 64~320kbps；格式要在录音前先设好 |
| WAV 录音被截断 | WAV 格式单次录音约 6 小时封顶；更长的录音改用 AAC（无时长上限） |
| 想把录音发出去 | 在「录音列表」里直接上传到 Mixcloud 或 SoundCloud，或先保存到手机再分享 |

## 四、同步与串流问题

| 现象 | 判据与处理 |
| --- | --- |
| Mobile Library Sync 连不上电脑 | 两台设备必须接入同一 Wi-Fi；路由器开了 AP 隔离时互相看不见，需关闭；确认电脑版不是 ver. 5 及更早版本 |
| 找不到「连接 rekordbox (Mac/Win)」入口 | 这个菜单只在**竖屏模式**的浏览界面显示，横屏下不出现；转回竖屏再找 |
| 歌名是灰色的，播不出来 | 表示音频文件本体不在手机上（只同步了曲库信息）；用 Mobile Library Sync 把文件本体传过来，见[怎么导入歌曲和串流音乐](怎么导入歌曲和串流音乐.md) |
| 想把歌导出到 U 盘带去演出 | 手机版不支持向 USB 存储设备导出（官方明确）；可选手机直接接播放器，或用电脑版导出，见[CDJ和XDJ怎么连手机](CDJ和XDJ怎么连手机.md) |
| 云同步超过 20 首不工作 | Free 与 Core 计划的云同步额度就是 20 首，不限量需要 Creative 或 Professional 计划 |
| 串流曲目在混音里缺声 | 检查串流服务在你所在地区是否可用、账号会员是否有效；串流歌曲离线即失效 |
| 串流曲目录不进混音 | 官方设定：串流来源不支持录音，把关键曲目换成本地文件再录 |

## 五、账号与设备数上限

桌面版订阅计划按档位限制同时激活的设备数：Core 3 台、Creative 4 台、Professional 8 台（Free 加 Cloud Option 也是 3 台）。提示「激活设备数已达到上限」时，先在账号页面停用一台旧设备，再激活新的。这个数字以官方订阅页面当前说明为准。

## 六、什么问题该去找官方

以下情况自行排查意义不大，直接走官方支持渠道：

- 付费后订阅状态没有生效（应用内显示已购但功能未解锁）
- 账号无法登录或需要注销
- 特定机型反复出现系统性崩溃（附上机型与系统版本提交反馈）

提交反馈前先记下：应用版本、手机型号、系统版本、触发步骤，这四项能让客服少一轮来回。
