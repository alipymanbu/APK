## 一、装之前先确认它是不是你要的东西

Uki 是一款面向年轻人的陌生人社交应用：注册用真手机号，但聊天时互相比拼的是虚拟形象和有趣程度，匹配上先聊三分钟，聊得来再互关深交。它是上海辰龙信息科技有限公司运营的产品，**仅面向成年人开放**——官方用户协议写明 18 岁以下用户不得使用，应用商店的年龄分级也是 18+。

先把手里这份安装包的事实核清楚（以本地保存的这一份为准，线上商店的版本可能更新）：

| 项目 | 数值 |
| --- | --- |
| 版本 | 5.98.0 |
| 安装包大小 | 203.27M |
| 包名 | `cn.neoclub.uki` |
| MD5 | `7EDB2196F58F71F02FE51439AC6A87DD` |
| 系统要求 | 安卓手机（来源页面对最低系统版本的标注不规范，以你的手机实际能装上、能运行为准） |
| 年龄限制 | 仅面向成年人（官方协议与商店分级均为 18+） |
| 语言 | 中文 |

安装包超过 200MB，安装解压还要额外占用空间，手机存储建议先腾出 1GB 以上。另外它要用手机号注册，装机前确认你手头的手机号还没注册过 Uki 账号。

## 二、获取安装文件资源

这份 Uki 安装文件资源（夸克网盘）在：[https://pan.quark.cn/s/b5534f5ff6f9](https://pan.quark.cn/s/b5534f5ff6f9)

获取步骤：

1. 手机或电脑上打开上面的链接，先把分享内容**转存到自己的夸克网盘**（分享文件可能随时失效，转存后才是你的）；
2. 转存后在网盘里找到 APK 文件，下载到手机本地存储；
3. 下载完成后先别急着点安装，建议按下一节核一遍 MD5。

## 三、核对 MD5（可选但建议做）

从网盘转存再下载，中间多一道环节，文件损坏的概率虽低但确实存在。核一遍只要半分钟：

1. 电脑端在 PowerShell 里执行：

   ```powershell
   Get-FileHash "C:\下载路径\Uki_v5.98.0.apk" -Algorithm MD5
   ```

   手机端可用带哈希校验功能的文件管理器，或装一个校验类小工具；
2. 把算出的值与 `7EDB2196F58F71F02FE51439AC6A87DD` 比对（不区分大小写）；
3. 对不上就删掉重新下载，别硬装——损坏的包装到一半报错，排查起来反而费时。

## 四、安装步骤

安卓安装非商店来源的 APK，系统默认会拦一道，流程如下（不同品牌菜单名略有差异）：

1. 在文件管理器里找到刚下载的 APK，点它；
2. 第一次安装会弹「禁止安装来自此来源的应用」之类的提示 → 按提示去系统设置，给**文件管理器（或你用的浏览器）**开「安装未知应用」权限；
3. 返回后继续点安装，等待完成；
4. 如果手机上以前装过 Uki（哪怕是别的渠道下载的），签名不一致会报「应用未安装」——先卸载旧版再装。注意卸载或清除数据会清掉本地的账号登录状态，账号本身在云端，重新登录即可找回。

## 五、装完第一步

点开 Uki，第一件事是**用手机号注册登录**，然后才是填资料、捏虚拟形象——这两步的顺序和各权限给不给的建议，直接看 [注册登录与账号设置.md](注册登录与账号设置.md)。想先弄清这应用里都有什么玩法再决定要不要认真填资料，翻 [是什么和核心玩法.md](是什么和核心玩法.md)。

装完打不开、闪退、收不到验证码这类情况，去 [常见问题与账号封禁处理.md](常见问题与账号封禁处理.md) 按现象对号入座。
