## 一、打不开、闪退、收不到验证码

按顺序排查，大多数卡在这一层的都能解决：

| 现象 | 先做这些 |
| --- | --- |
| 安装时报「解析包错误 / 应用未安装」 | 核对 MD5（见 [下载与安装教程.md](下载与安装教程.md)）；确认存储剩余 1GB 以上；以前装过 Uki 的先卸载旧版再装 |
| 打开就闪退 | 重启手机再试；确认系统版本不至于太老；仍闪退就卸载重装（账号在云端，重装不影响账号本身） |
| 收不到短信验证码 | 检查拦截软件与垃圾短信；关掉再开飞行模式重试；隔几分钟再要一次，别连点 |
| 界面加载不出、匹配一直转圈 | 换网络（Wi-Fi 与流量互切）；确认应用是较新版本 |
| 消息迟到、发出去对方半天没显示 | 服务器繁忙导致的延迟是常见原因，稍后重试即可；高峰期尤其明显 |
| 语音房没声音 / 麦克风不工作 | 系统设置里查 Uki 的麦克风权限是否开启（权限对照见 [注册登录与账号设置.md](注册登录与账号设置.md)） |

做完这些还不行，走应用内「反馈」入口，带上机型、系统版本和现象描述。

## 二、匹配次数用完了

每天免费匹配次数有限（多篇公开教程标注为 10 次，以应用内显示为准），用完有三个选择：等次日刷新；互关过的老朋友不受限制，正常私聊照聊；确实需要更多次数的，会员会加每日次数（见 [会员充值与自动续费.md](会员充值与自动续费.md)）。匹配次数是按天重置的，没有攒积机制，睡前把次数用掉是免费玩家的常见节奏。次数没用完却匹配不到人、匹配质量差，是另一类问题，排查思路见 [匹配不到人怎么办.md](匹配不到人怎么办.md)。

## 三、账号被封禁了

先分清处罚类型——官方用户协议列明的处罚包括**警告、账号封禁、设备封禁、功能封禁**，严重程度递增：

| 类型 | 表现 | 能怎么办 |
| --- | --- | --- |
| 功能封禁 | 某些功能点不开，账号能登 | 等期满，或申诉 |
| 账号封禁 | 登录提示被封 | 因隐私协议被封的，可自助查询封禁期限，期满自动解封；其他类型走申诉 |
| 设备封禁 | 换账号登录同一台手机也被拒 | 只能申诉；换设备登录是唯一临时绕法，但账号本体仍被封着 |

申诉渠道按顺序试：

1. **应用内客服**：入口在「主页 → 右下角个人中心 → 设置」页面最底部（官方在应用商店评论区回复中给出的路径）；被封禁到进不去应用的，走「我的 → 右上角 → 联系客服」。查询时报得出身份信息：手机号登录的直接报手机号，其他方式登录的报 Uki 昵称与所在省市（这一报法来自用户总结的客服沟通经验，供参考）；
2. **官方邮箱**：`hello@neoclub.cn`，写清账号 ID、注册手机号、封禁提示原文；
3. **客服专线**：`021-60952873`（来自应用商店官方页面公示，以最新为准）。

三个时间敏感的点：

- **尽快申诉**：有用户在投诉平台转述的平台规则称，封禁后需在**60 日内**申诉，超期账号可能被回收、账号内钻石积分等虚拟资产被清空——这一时限未经官方页面直接证实，但指向一致：收到封禁通知当天就开始申诉，别拖；
- **「发起聊天过于频繁」别忽视**：有用户反馈这类提示实际上可能是封号的前兆或已封号的表现，出现后先走客服查询账号状态，确认没事再继续用；
- **设备封禁连带新号**：用户投诉中出现过「账号永久封禁 + 设备被锁」同时执行的情况——同一台手机换注册新账号也登不上。这也意味着申诉成功与否影响的不只是这个账号。

申诉材料准备账号 ID、注册手机号、封禁提示截图，若认为误判，附上相关聊天记录或动态截图佐证。有用户通过第三方消费者投诉平台申诉解封成功的公开案例（提交账号信息与「要求人工复核」的说明后，平台跟进处理），应用内渠道多轮无果时可以作为下一步。申诉期间别频繁重复提交相同内容，也别轻信网上「付费代解封」——那类服务只会有两种结局：骗钱，或者教你在封号路上再进一步。

## 四、被骚扰或遇到违规内容

在对方资料页或聊天界面里用举报入口提交，平台会审查处理，情节重的按协议做封禁处罚。自己这边：别回怼（回怼可能被反向举报）、直接举报加拉黑；涉及借钱、投资、刷单的话术，按诈骗处理，保留聊天截图作为凭证。

## 五、账号不想用了

注销走「设置」里的注销确认，或通过客服办理，注销后果与操作细节见 [注册登录与账号设置.md](注册登录与账号设置.md) 第六节——注意被封禁状态下注销入口可能办不了，先把封禁问题处理完。

## 六、装不上或还没装

安装包获取、MD5 核对与安装步骤都在 [下载与安装教程.md](下载与安装教程.md)；装完先看的两件事（注册与权限）在 [注册登录与账号设置.md](注册登录与账号设置.md)。
