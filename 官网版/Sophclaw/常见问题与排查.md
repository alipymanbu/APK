## 一、安装类

### 提示「禁止安装来自此来源的应用」

安卓对未知来源安装的默认拦截。到 设置 → 安全/隐私 → 安装未知应用，给本次使用的文件管理器授权后重试；个别品牌路径在「应用管理」里。

### 装完提示「解析包时出现问题」或安装包损坏

按顺序核对：

1. 文件大小是否接近 **117.81M**（以本地留存这份为准，明显偏小 = 没下完，重下）；
2. MD5 是否为 `365C60A4E1C11F5023A69BD36E6D7645`（电脑上 `certutil -hashfile 文件名.apk MD5` 可算）；
3. 手机剩余空间是否充足（建议留 500M 以上）；
4. 系统版本是否满足**安卓 5.2 及以上**。

都对还不行，换一台手机试装，排除机型兼容问题。下载与核对细节见 [下载与安装教程.md](下载与安装教程.md)。

## 二、登录类

### 收不到验证码

- 等 60 秒再点一次「重新发送」，短信高峰偶有延迟；
- 检查短信拦截/骚扰箱；
- 用邮箱注册的，看垃圾邮件箱；
- 换网络试试（Wi-Fi 与移动数据交替），收码请求走网络；
- 连试两次仍收不到，稍后再试或换手机号/邮箱——这类问题多为服务端波动，隔段时间自愈。

### 登录后首页没有反应 / 对话框发不出消息

多半是你的 Sophclaw 还没创建完。回首页点「**即刻体验**」等待初始化完成再发；创建流程本身说明见 [新手使用教程.md](新手使用教程.md)。

## 三、运行类

### 打开就闪退 / 百分百打不开

从轻到重四步，多数能止血：

1. **强制停止 + 清缓存**：长按图标 → 应用信息 → 存储占用 → 清理缓存，再重新打开；
2. **检查权限**：应用信息 → 应用权限，把存储、网络等必要权限打开（权限被拒是闪退常见诱因）；
3. **清数据重开**：同一页面「清除数据」——注意这会退出登录、清掉本地记录，需要重新收码登录；
4. **卸载重装**：从 [Sophclaw 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d2f634d94371) 重新取安装包（取包步骤见 [下载与安装教程.md](下载与安装教程.md)）。

仍闪退时看两点外部因素：手机系统是否有待更新的补丁（设置 → 系统更新），以及 Android System WebView 是否为最新版（应用商店搜 `Android System WebView` 更新；已更新后反而异常的，可在应用信息里「卸载更新」回退）。

### 手机发烫、卡顿后应用无响应

手机过热时系统会降频，应用跟着卡。退出应用让手机降温，关掉后台不用的程序再进。Sophclaw 的任务在云端跑，本地卡顿一般不影响已发出任务的执行结果。

## 四、任务与网络类

### 指令发出去一直转圈 / 没动静

按可能性排查：

1. **网络**：切一下 Wi-Fi 与移动数据。推理在云端，断网/弱网都会卡住；
2. **服务端波动**：官方更新日志有过多轮「节点更新升级、服务波动约 30 分钟」的公告，这类情况等公告窗口过了再发即可；
3. **任务本身复杂**：多步骤任务耗时长，等它跑完（参考同类应用 5~20 分钟量级，供你判断「久等」还是「卡死」）；
4. **额度耗尽**：见下一节。

### 模型下线公告会影响我吗

平台会按官方节奏下线旧模型（如 2026-10-09 对 DeepSeek-V4-Flash 部分节点下线）。如果你的任务突然变慢或报配额类错误，先看 [www.sophnet.com](https://www.sophnet.com/) 更新日志有没有相关公告，按官方建议把任务迁到新模型。价格与模型变动的背景见 [积分与费用说明.md](积分与费用说明.md)。

### 技能装不上 / 装完行为不对

安装指令与报错都回显在对话框里，从回显入手：

1. 回显是「未找到该 skill」——名字抄错了，回问 bot 官方清单核对拼写；
2. 回显是网络/超时类错误——隔几分钟重发一次安装指令；
3. 装上了但功能不对劲（读不到文件、行为像旧版本）——先发删除指令再重装（官方对 `sophnet-face-search` 就是这个处理法）；
4. 对话框对安装指令毫无反应——你这个端可能未开放 Skills 能力，见 [技能扩展怎么用.md](技能扩展怎么用.md) 第一节的适用范围说明。

## 五、额度与费用类

### 明明没充值却在扣费 / 余额对不上

1. 到 Sophnet 控制台账单页看扣费明细，确认扣的是体验金还是现金余额；
2. 核对自己是否填过邀请码、领过实名体验金——活动额度有有效期，过期作废不等于被盗（活动规则见 [积分与费用说明.md](积分与费用说明.md)）；
3. 明细里出现你没发起过的调用，立即修改账号密码并联系官方客服（官网右上角头像处有客服入口）。

### 额度用完了还能用吗

额度见底时任务会中断或无法发起。处理方式只有两种：等活动/赠送额度到账，或在控制台充值。没有官方之外的「免费续命」途径，别信第三方号称能白拿额度的路子。

## 六、还没答案怎么办

官方入口：[www.sophnet.com](https://www.sophnet.com/)（右上角登录/客服），以及官方文档的 Sophclaw 章节。提问时带上：手机型号与系统版本、App 版本号（当前留存这份为 1.4.0）、问题截图——信息越全，一次说清的概率越高。
