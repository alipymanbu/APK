## 一、Skills 解决什么问题

没装技能时，Sophclaw 靠通用对话能力干活——写文案、答问题够用，碰到「生成一份 Word」「读飞书表格」这类具体活就缺工具。Skills 是打包好的指令与工具集合，装上后你在对话里提相关需求，它就会按这套打包知识去做，输出格式稳定得多。官方文档列出的方向包括：文档处理（Word 创建/读取/编辑）、图片处理（编辑、人脸搜索）、飞书电子表格与多维表格读写、网页操作、代码执行等。

**适用范围先说清**：下面的安装方式来自 Sophnet 官方文档的 Skills 章节，对应其 OpenClaw 形态的对话界面（网页端/桌面端）。你的安卓 App 里是否照此办理，**以应用内实际界面为准**——对话框能发安装指令就照做，找不到对应入口就说明这个端暂未开放。

## 二、怎么装

官方给了两条等价路径，都是在对话框里直接说人话：

1. **先问有没有**：在对话框发「你安装了 sophnet-skill-installer skill 吗」——这是官方技能安装器，它的作用是列出、安装、更新平台官方提供的全部 Skills。
2. **没装就装**：若 bot 回复未安装，直接发：

```text
通过 https://github.com/DuffyCoder/awesome-sophnet-skills 安装 sophnet-skill-installer skill
```

3. **确认**：安装成功 bot 会提示；之后问它「官方都提供哪些 Skills」，它会列清单。
4. **装具体技能**：拿到清单后按名字装，例如发「帮我安装 sophnet-docx skill」。

多数单个技能就是一句话的事，不需要你碰配置文件。

## 三、装了能干什么（官方清单摘录）

| 技能 | 你能做的事 |
| --- | --- |
| `sophnet-docx` | 让它生成、读取、改 Word 文档；插图、找替换、处理修订评论。例：「帮我生成一个 Word 文档，标题『我的报告』，包含一段『这是我的报告内容』」——它回一个链接，打开预览下载 |
| `sophnet-face-search` | 上传一张人脸清晰的照片作为样本，让它在指定目录里找出同一个人的其他照片 |
| `sophnet-image-edit` | 对图片做修复、增强、风格转换类编辑 |
| `feishu-sheets` | 读写飞书电子表格的工作表与单元格（需先配好飞书机器人并在飞书开发者后台开通云文档权限） |
| `feishu-bitable` | 对飞书多维表格做表/记录/字段/视图的增删改查 |

用法模式是一致的：装完直接在对话里描述你要的结果，技能由它按需调用，你不用记命令。

## 四、什么情况要删掉重装

官方文档里有明确先例：`sophnet-face-search` 的老版本对文件夹支持不好，处理办法是先发「帮我删除 sophnet-face-search skill」删掉，再重新安装。照这个模式，任何技能出现「功能不对劲 / 读不到文件 / 行为像旧版本」时，都是**先删再装**，比重装整个 App 轻得多。安装、更新类指令都发在同一个对话框里，失败提示也回显在那里——报错内容见 [常见问题与排查.md](常见问题与排查.md)。

## 五、装之前该想的一件事

技能会带进来新的外部交互能力——读文档、查人脸、写飞书表格，每一项都意味着你的 Sophclaw 会更多地碰你的文件与第三方服务。装什么、给什么权限，是个安全决策而不只是功能决策，风险与自查动作见 [隐私与权限注意.md](隐私与权限注意.md)。只从官方清单（`sophnet-skill-installer` 列出的那批）里挑，别装来路不明的技能包。
