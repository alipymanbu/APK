# Design Mirror 的 WiFi 和 USB 连接方法

> 手机和电脑两端都装好后，用 WiFi 或 USB 把 Design Mirror 连起来；本篇讲两种方式各自的步骤和适用场景。

## 一、两种方式怎么选

| 方式 | 适合场景 | 特点 |
| --- | --- | --- |
| WiFi | 日常预览、多人同时看稿 | 手机、平板、浏览器可同时连接并同步刷新；要求同一局域网 |
| USB | WiFi 不稳、跨网段、没有网络 | 传输更快更稳；插线即用，边充电边预览 |

两条路不冲突，WiFi 平时用，USB 当备胎——网络环境差的时候它是不依赖网络的兜底方案。

## 二、WiFi 连接步骤

1. 把电脑和手机连到**同一个 WiFi**（办公网跨网段时两端可能互相看不见，这是最常见的失败原因）；
2. 手机打开 Design Mirror App，同一网络下会自动发现电脑——官方口径是自动识别设备，不需要手动输入 IP；
3. 选中你的电脑设备，连接成功后手机上就会显示当前打开的设计稿。

三点说明：

- 官方称采用电脑和手机双向通信机制，一般不需要手动去关防火墙；
- 网络不通时，可以改用电脑面板上显示的二维码扫码连接，不需要登录账号；扫码也适合把稿子快速给同事看；
- 支持多台设备同时连接（手机、平板、浏览器），同步刷新——你可以同时挂一台手机、一台平板看不同机型的适配效果。

## 三、USB 连接步骤

1. 用数据线把手机插到电脑上；
2. 官方口径是不需要复杂设置，在面板上点击对应按钮即可使用；Windows 和 Mac 都支持，iOS 和 Android 设备都支持；
3. 连上后传输速度比 WiFi 快，同时还在给手机充电。

USB 方式值得记住的一点：它不依赖 WiFi，会议室网络不让外设互连、或者你根本没网的时候，插上线就能继续预览。插上后电脑没反应，多半是线材或驱动的问题，排查思路见 [搜不到设备怎么办.md](搜不到设备怎么办.md)。

## 四、连接成功后

- 电脑端画布的改动会实时刷到手机上，具体操作见 [实时预览与快照对比.md](实时预览与快照对比.md)；
- 不同设计软件接入面板的位置不一样，对照 [支持哪些设计软件.md](支持哪些设计软件.md)；
- 还没装好两端的，先看 [下载与安装教程.md](下载与安装教程.md)。
