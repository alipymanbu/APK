## 一、先确认你要装的是哪个

这个应用只做一件事：配合 iFLYBUDS 系列耳机使用。没有耳机，装上它也用不了核心功能（录音转文字、耳机设置都要连上耳机才有意义）。

| 项目 | 信息 |
| --- | --- |
| 应用现名 | viaim（原 iFLYBUDS，改名后功能不变） |
| 开发者 | 安徽艾德未来智能科技有限公司 |
| 本篇对应安装包版本 | 6.2.7（2026-09-23 采集） |
| 安卓包名 | `tws.iflytek.headset` |
| 安装包大小 | 144.32M |
| 系统要求 | Android 8.0 及以上（官方下载页口径，iOS 13.0 及以上） |

网上应用商店里的版本通常比 6.2.7 新，功能入口可能略有变化，以你打开的 App 实际界面为准。

## 二、安装包从哪来

两个渠道，按你的情况选：

- **官方渠道**：官网下载页（`https://www.iflybuds.com` 的「软件下载」栏目）或各大应用商店搜「viaim」，装到的是商店当时的最新版。
- **网盘资源**：如果你就是要装 6.2.7 这一版（比如和手头这份 [iFLYBUDS 安装文件资源（夸克网盘）](https://pan.quark.cn/s/085412035d9a) 对应的耳机固件或教程配套），转存后把 APK 拷到手机上装。

录音记录挂在账号上：以后从商店装了更新版本，登录同一账号，云端记录还在。

## 三、安卓安装步骤

从网盘或浏览器拿到的 APK，手机默认不允许安装，需要先放开一次权限：

1. 把 APK 文件传到手机存储（微信传文件、数据线、网盘客户端均可）。
2. 在文件管理器里点开这个 APK。系统会提示「禁止安装未知来源应用」，按提示跳到设置页，允许你用的那个文件管理器「安装未知应用」。
3. 返回文件管理器再点一次 APK，等安装进度走完。
4. 点「打开」直接进入应用，或稍后从桌面图标进。

安装包约 144M，加上运行时缓存，建议手机预留 1GB 以上空间。

## 四、首次打开要做的事

第一次打开会连续要几个权限，别一路拒绝，每项都有用途：

| 权限 | 用途 |
| --- | --- |
| 蓝牙（部分系统附带位置权限） | 扫描并连接耳机 |
| 麦克风 | 录音与通话转写 |
| 存储空间 | 导出录音和文字 |
| 通知（可选） | 长时间录音时保持后台稳定 |

然后：

1. 注册或登录账号（手机号即可）。录音记录、转写时长都挂在账号上。
2. 打开耳机充电盒、让耳机进入配对状态，回到 App 里绑定耳机。具体手势和指示灯状态见 [耳机配对与固件升级.md](耳机配对与固件升级.md)。
3. 绑定成功后，首页会出现录音按钮，即可开始使用。

如果绑定这一步卡住，直接翻 [连接与录音问题排查.md](连接与录音问题排查.md)，大多数情况是耳机没进配对状态或被别的手机连走了。

## 五、电脑上要用怎么办

官方另有 Windows 与 macOS 桌面端（Windows 7 及以上、macOS 10.13 及以上），用于录制电脑上的通话与音频，录音功能需要连接会议狗（Kit 2）。苹果芯片的 Mac 用户可以不装桌面端，直接在 App Store 下载 iPad 版 viaim 来录电脑音频。桌面端同样从官网下载页获取。
