## 一、从一张手机照到能上架的主图

整个链路是：拍一张商品照 → 自动抠图 → 套白底或影棚图 → 按平台导出尺寸。拍摄环节的几条通用经验（不是应用的要求，但直接影响出图质量）：

- 光线均匀，宁可阴天散射光也不要直射强光，强反光的商品后面很难修。
- 背景尽量干净纯色，给抠图留余量。
- 商品摆正、占画面主体，四周留一点边。

后续抠图与换底的具体操作见[怎么抠图和换背景.md](怎么抠图和换背景.md)。

## 二、常用电商需求对照表

| 需求 | 用什么功能 |
| --- | --- |
| 白底、干净的主图 | 影棚图 / 白底背景 |
| 商品有立体感、不「飘」 | AI 阴影 |
| 生活场景图（没条件实拍） | AI 背景，输入场景描述 |
| 服装上身效果展示 | AI 时装模特 |
| 服装平铺、无模特展示 | 隐形人台、平铺图 |
| 衣服照片有褶皱 | 熨烫 |
| 同款商品出多个配色 | 改色 |
| 图片适配上架平台 | 电商尺寸调整 |

其中 AI 生成类（场景、模特）消耗额度且按套餐解锁，档位差异见[免费版和Pro版区别.md](免费版和Pro版区别.md)。

## 三、平台尺寸适配

官方列出的适配目标包括：Shopify、Amazon、Etsy、Depop、Poshmark、Vinted、Instagram、Facebook、TikTok、YouTube。做法：在导出或尺寸调整里选对应平台的预设，不用手动查每个平台的像素要求。预设清单随版本更新，以界面里实际显示的为准。

## 四、批量处理整个商品目录

- **批量编辑**：把同一套处理（抠图、背景、尺寸、阴影）一次套到多张图上，几百张的目录也能统一风格。
- 批量在**网页版**上做更顺手：电脑上文件进出方便、屏幕大好核对细节；手机版适合现场单张快修，分工见[网页版和手机版区别.md](网页版和手机版区别.md)。
- 注意额度消耗方式：批量导出通常按张数计入导出额度，30 个商品各出 4 个版本的图就是 120 次导出，先核对自己的套餐额度再批量跑。
- 单次批量能选多少张有限制：多份第三方资料记录 Pro 档单次约 50 张（这类数字官方会调整，以你界面里实际可选的上限为准），更大的量分批跑或走网页版 / API。

## 五、Shopify 店铺连接

Max 档及以上支持连接 Shopify 店铺：导入商品目录 → 应用统一编辑效果 → 直接在应用里创建、更新、发布商品，不用再手动来回传图。这个能力按官方页面口径属于较高档套餐功能，开通前以[官方定价页](https://www.photoroom.com/pricing)为准。

## 六、AI 生成结果上架前的自查

- 核对生成图里的商品：颜色、形状、材质、纹理、徽标有没有被改动。官方对「精准保留商品细节」有专门宣传，但上架前花十秒比对原图的成本更低。
- 文字类细节（吊牌、logo 小字）生成后容易失真，重点看这些位置。
- 生成图用于商业用途的授权范围与套餐挂钩，具体以官方条款为准。
