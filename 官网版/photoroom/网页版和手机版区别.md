## 一、三种形态一览

| 形态 | 入口 | 适合谁 |
| --- | --- | --- |
| 手机应用（安卓 / iOS） | 应用商店，或上方「安装文件资源」入口 | 随手拍随手修，单张出图最快 |
| 网页版 | [app.photoroom.com](https://app.photoroom.com/) | 电脑大屏改图、批量处理整个目录 |
| API | 官网开发者入口 | 平台方、开发者接入自动化，个人卖家一般用不到 |

三个形态登录同一个账号使用，不是三个独立产品。

## 二、手机版适合什么

- 现场拍完当场修：拍商品 → 抠图 → 换底 → 导出，一条链路在手机上闭环，不用传电脑。
- 界面为触屏设计，修一张图的最短路径在手机上。
- 安装方式见[下载与安装教程.md](下载与安装教程.md)；抠图换底的具体操作见[怎么抠图和换背景.md](怎么抠图和换背景.md)。

## 三、网页版适合什么

- 地址是 [app.photoroom.com](https://app.photoroom.com/)，浏览器直接打开，不用装任何东西。
- **批量编辑是网页版的强项**：一次把同一套处理套用到整个商品目录，电脑上文件进出、逐张核对都更省事。
- 手机版也有批量处理能力（有评测称移动端功能与网页版基本对齐），不过整目录的批量在电脑上核对细节效率明显更高。
- 需要对照表格、文案来排版图的时候，大屏效率明显更高。

手机修单张、网页跑批量，是两种形态的典型分工，配合电商场景的具体做法见[商品图与电商使用技巧.md](商品图与电商使用技巧.md)。

## 四、账号与数据

- 作品保存、套餐订阅管理都挂在账号上，换设备登录同一账号即可继续用。
- 手机和网页版用同一账号登录，编辑的内容可以衔接；具体哪些数据实时互通以实际使用为准。
- 订阅状态在账号体系里通用，网页上改了套餐，手机端同样生效。

## 五、用量大之后的进阶用法（API）

API 面向开发者和平台方：把抠图、批量编辑接进自己的系统或电商流程，适合每天要处理成百上千张图的团队。个人卖家到不了这个量级的话，直接用网页版的批量编辑就够了。接口能力与计费以官网开发者页面为准。
