# Ruffle 黑屏白屏打不开的排查方法

> 按现象分类的排查清单：先分清是安装问题、文件问题还是兼容性问题，再逐项处理。

## 一、先把现象归类

| 现象 | 大概率属于 | 先看 |
| --- | --- | --- |
| APK 装不上 | 安装问题 | 第二节 |
| 应用能开，但文件加载后黑屏 / 白屏 | 文件或兼容性问题 | 第三节 |
| 网址加载空白 | 站点或版本问题 | 第四节 |
| 画面正常但按键 / 点击没反应 | 操作映射问题 | 第五节 |

## 二、安装失败的排查

1. **未知来源权限**：安装被拦，去设置里给文件管理器放行「安装未知应用」，具体步骤见 [下载与安装教程.md](下载与安装教程.md) 第三节；
2. **系统版本**：安卓 8.0 以下装不上，先确认手机系统版本；
3. **文件损坏**：核对大小是否 42.14M、MD5 是否 e378e72bbe29bd9096ea6ef8bc7b4ada（网盘里这份的口径），对不上就重新下载；
4. **存储空间**：预留比安装包更大的空余空间再装。

## 三、本地文件黑屏 / 白屏

1. **换一个文件验证**：拿一个确定简单的老动画（年代越早越好）试。它能正常播放，说明应用没问题，问题在原来那个文件；
2. **检查文件完整性**：传输中断会导致文件损坏，重新传一次；
3. **兼容性原因**：内容用了较新的 ActionScript 3，兼容度未满，详见 [哪些Flash游戏能玩.md](哪些Flash游戏能玩.md)——这类只能等版本更新，不是设置能解决的；
4. **确认文件确实是 swf**：有些文件只是扩展名叫 .swf，实际内容损坏或被改过名，这类文件谁也放不出来。

## 四、网址加载空白

1. 先确认你开的是 .swf 直链还是普通网页，直链成功率高得多；
2. 站点下线、内容撤下、防盗链都会导致空白，换一个源验证；
3. 有用户反馈某些版本对任何网址都显示空白画布——遇到就升级到官方渠道的新版本（以官方页面当时显示为准），或改用本地文件方式，操作见 [本地SWF文件怎么打开.md](本地SWF文件怎么打开.md)。

## 五、按键与点击问题

- 点击没反应：先确认内容本身需要点击交互——有些动画只是自动播放，点哪里都没反应是正常的；
- 方向键类游戏：需要调出虚拟键盘，用法见 [虚拟按键与触屏操作.md](虚拟按键与触屏操作.md)；
- 网页内容里点击无效：可能是内容调用了尚未实现的 API，属于兼容性问题，处理思路同第三节第 3 条。

## 六、都试过还不行

- **升级版本**：官方渠道（F-Droid，或 GitHub 仓库 [github.com/ruffle-rs/ruffle-android](https://github.com/ruffle-rs/ruffle-android) 的 Releases 页）更新频繁，新版本可能恰好修了你遇到的问题；
- **反馈问题**：用户 FAQ 在 [github.com/ruffle-rs/ruffle/wiki](https://github.com/ruffle-rs/ruffle/wiki/Frequently-Asked-Questions-For-Users)，问题反馈走 [github.com/ruffle-rs/ruffle/issues](https://github.com/ruffle-rs/ruffle/issues)，也可以到官方 Discord（[discord.gg/ruffle](https://discord.gg/ruffle)）提问；
- **反馈时带全信息**：到 GitHub 提 issue 前把这几项写清楚——应用版本、手机型号、文件是本地加载还是网址加载、具体表现（黑屏 / 白屏 / 报错原文），能省一轮来回；
- **过段时间再试**：兼容性在持续改进，今天玩不了的文件，过几个月再拿同一个文件试一次。
