## 一、安装前先核对这几项

ChromeCast 是一款运行在安卓手机上的投屏与遥控工具，用来把手机里的视频、照片、音乐推送到 Chromecast 等大屏设备，也能把手机屏幕实时镜像到电视上。安装包不大，但版本与包名值得先核对一遍，特别是你手上有多份来源不明的同名安装包时：

| 项目 | 本文对应的这份安装包 |
| --- | --- |
| 版本 | 3.0 |
| 安装包大小 | 18.15M |
| 包名 | `com.castfor.chromecast.remotecontrol` |
| MD5 | `94212DEC226B2F1FD9B7ED9CE37902A0` |
| 系统要求 | 安卓 5.2 及以上（以安装时的系统提示为准） |

两点提醒：

- **它不是 Google 出品的应用**。Google 官方应用的包名以 `com.google.` 开头，而这份安装包的包名是 `com.castfor.chromecast.remotecontrol`，属于第三方开发的投屏工具。它与 Google 官方的 Google Home 应用是两回事，功能有重叠但定位不同。
- **网上的"最新版"和你拿到的可能不是同一个版本**。应用商店里的版本号会持续更新，上面表格里的版本信息只对这份安装包负责。

## 二、下载与安装步骤

1. 从 [ChromeCast 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7d144a4118b5) 转存并下载 APK 文件到手机存储。网盘链接在手机浏览器或网盘客户端里打开都可以，文件下载完成后通知栏会给出完成提示。
2. 在文件管理器里找到刚下载的 APK，点它。安卓会提示"是否允许安装未知应用"，按提示授权给文件管理器（或你用的浏览器）即可，这一步只需要做一次。
3. 回到文件管理器再点一次 APK，进入安装界面，等进度条走完。
4. 安装完成后点"打开"，应用会请求若干权限（下一节细说），逐项允许后进入主界面。

## 三、安装失败的对照表

装不上的时候，先对号入座再看处理办法：

| 提示 / 现象 | 常见原因 | 处理办法 |
| --- | --- | --- |
| "无法解析安装包" / "解析包时出现问题" | 下载不完整、传输过程损坏，或系统版本低于要求 | 先用校验工具核对 MD5 是否为 `94212DEC226B2F1FD9B7ED9CE37902A0`，不一致就重新下载；一致但仍报错，检查系统版本是否达到要求 |
| "存储空间不足" | 手机剩余空间小于安装包体积加解压后的占用 | 至少腾出 100M 以上空间再装，安装完成后安装包本身可以删掉 |
| "与已安装的应用冲突" / 安装到一半失败 | 手机上已经装过一个不同签名的同名或同包名应用 | 卸载旧版本后重新安装，注意卸载会清掉旧版的设置 |
| 安装按钮点不动 / 一直转圈 | 文件管理器缺少"安装应用"权限 | 到系统设置的"应用管理"里给文件管理器补上"安装未知应用"权限 |

MD5 校验不需要额外装工具：很多第三方文件管理器自带"校验"或"属性"功能；也可以在电脑上用命令行处理，例如 Windows 的 PowerShell：

```powershell
Get-FileHash "ChromeCast_v3.0.apk" -Algorithm MD5
```

输出的哈希值忽略大小写后与上面表格一致，就说明文件完整。

## 四、装好后的第一次启动

首次打开 ChromeCast，系统会逐项弹权限申请，逐个说明它们是干什么的，你按需决定：

- **附近设备 / Wi-Fi 连接信息**：用来在同一局域网里搜索 Chromecast 设备。这是投屏类应用的核心权限，不给它就永远搜不到电视。
- **位置权限**（安卓 12 及以上常见）：安卓系统把 Wi-Fi 扫描归入位置类权限，部分机型不给定位就无法发现局域网设备。介意的话可以选"仅在使用中允许"。
- **照片、视频、音乐访问**：投本地文件用的。只打算投在线内容的话可以只给最小范围。

权限给完进主界面，下一步就是连电视了，具体流程见 [投屏连接与遥控使用.md](投屏连接与遥控使用.md)；如果装好了却搜不到设备，直接翻 [找不到设备的排查方法.md](找不到设备的排查方法.md)，那一篇按命中概率从高到低把原因排了序。
