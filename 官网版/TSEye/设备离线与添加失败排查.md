# 设备离线与添加失败排查

> 本篇讲设备在 TSEye 里显示离线、搜不到或添加失败时的排查顺序，以及每个环节怎么判断。

先分清两种表现，方向完全不同：**离线**是设备自己没连上网（或连的网变了），跟 app 无关；**添加失败 / 连接失败**多半是用户名密码不对。对症下药能省掉大半折腾。

## 一、设备显示离线

按这个顺序过一遍：

1. **手机有没有网**：手机自己上不了网，画面当然出不来。先随便开个网页确认。
2. **设备有没有电**：夜里看红外灯亮不亮（遮住光敏会触发红光），有线机看网口指示灯闪不闪——这是设备厂商 FAQ 里给的快速判断法。
3. **重启**：设备断电 30 秒再上电，路由器顺手也重启一次。大多数「莫名其妙离线」到这一步就好了。
4. **Wi-Fi 是不是改过**：改过路由器的 Wi-Fi 名或密码，设备还拿着旧凭证在连，必然离线。这类设备需要重新配网、重新添加。
5. **信号够不够**：设备离路由器太远、隔几堵墙，连接会断断续续。有条件就把设备挪近路由器试一次，能上线就是信号问题。

## 二、局域网里搜不到设备

供电正常但搜索列表是空的，最大嫌疑是**设备和手机不在同一个网段**：

1. 登录路由器管理页，看路由器的 IP 和网关（比如 `192.168.1.1`）；
2. 摄像机出厂默认 IP 常见是 `192.168.1.108` 这类，如果你的路由器网段不是它（比如网关是 `192.168.64.1`），就搜不到；
3. 处理办法：用电脑浏览器打开摄像机的 IP，进网页后台把摄像机的 IP 和网关改成与路由器同网段（网页后台的默认账号多为 `admin` / `admin123`，以设备标签为准），改完重新搜索；
4. 改完 IP 后要把 app 里加过的旧设备删掉再重新搜，不然留下的还是旧地址。

一个好用的判别办法是让一台手机开热点，设备连热点能上线，就说明问题出在自家路由器的设置上（过滤、隔离类功能），而不是设备坏了。

## 三、添加时提示连接失败

- **用户名密码错**：默认值常见 `admin` + 空密码或 `admin123`，各品牌不一，以机身标签和说明书为准（详见 [添加设备教程.md](添加设备教程.md) 第一节）；
- **云 ID 抄错**：手动输入时 `0`/`O`、`1`/`I` 最容易混，能用二维码扫就别手敲；
- **NVR 一体机的 SN 没找对**：带屏幕的录像机，系统码（SN）在系统界面的「云 / Cloud」信息页里能看到，机身也常贴有含 SN 的二维码。

## 四、加上了，出了家门就离线

这不是故障，是添加方式决定的：用「局域网搜索」加的设备记录的是内网 IP，只在同一个 Wi-Fi 下有效。要在外面看，删掉后改用**云 ID** 方式重新添加，见 [添加设备教程.md](添加设备教程.md) 第二节。

## 五、两个已知的小毛病

- 有用户反馈部分版本的设备列表在启动后不自动刷新，明明设备在线列表里却看不到——下拉刷新或退出重进即可；
- 回放没有快进按钮也是被提及较多的点，定位录像以拖时间轴为主，见 [实时预览与录像回放.md](实时预览与录像回放.md)。

## 六、以上都不行

- **设备侧的问题**（不通电、进不了后台、反复掉线）找设备的卖家或品牌客服——TSEye 只是查看端，设备硬件售后在卖家那里；
- 确认设备固件有更新的话，固件升级一般在设备网页后台的系统工具里操作，升级后再重新添加试试。
