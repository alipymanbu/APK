# TSEye 添加设备教程

> 本篇讲把摄像机、录像机加进 TSEye 的两种方式：云 ID 添加与局域网搜索，以及各自的适用场景。

装好 app、登录完账号，设备列表还是空的，这一篇把它填上。添加方式有两种，选哪种取决于你想在哪看：**只想在家里（同一 Wi-Fi 下）看，局域网搜索最快；人在外面也要看，必须用云 ID 添加**。不少第三方品牌的监控设备（随机附二维码指向 TSEye 的那类）都按这个流程走。

## 一、添加前的准备

1. 设备已通电，指示灯正常亮起；
2. 有线设备已用网线接到路由器；无线摄像机确认已在设备侧完成配网（配网方式以设备说明书为准）；
3. 知道设备的登录账号和密码。常见默认值：

| 项目 | 常见默认值 |
| --- | --- |
| 用户名 | `admin` |
| 密码 | 空密码，或 `admin123`，以机身标签和说明书为准 |

部分设备机身或底部贴有序列号标签，那串编号就是云 ID，外网访问全靠它。

## 二、方式一：云 ID 添加（推荐）

云 ID 是每台设备唯一的编号，走这方式添加的设备，手机在 4G、5G、别的 Wi-Fi 下都能看。

1. 在 TSEye 设备列表页点「添加设备」；
2. 选择手动输入或扫描设备标签/屏幕上的二维码，填入云 ID；
3. 给设备起个名字（比如「门口」「仓库」），方便区分；
4. 填设备用户名和密码（见上一节默认值）；
5. 保存后回到列表，点开确认出图。

家里几台设备就重复几次，全部挂在一个账号下。

## 三、方式二：局域网搜索添加

前提：**手机和设备连的是同一个路由器的网络**。

1. 设备列表页点「添加设备」，进添加表单；
2. 点「搜索」，app 会自动找出同一局域网里的设备；
3. 选中要加的设备，填用户名、密码，保存。

注意：这种方式添加的设备记录的是它的**内网 IP**——出了家门这个地址就不通了，在外面打开会显示离线或连接失败。要在外面看，删掉后改用云 ID 方式重新添加。

## 四、无线摄像机怎么连

添加表单里有 Wi-Fi 标签页，用于连接无线摄像机。首次给一台纯无线摄像机配网时，具体操作（热点连接、扫码配网等）因设备品牌差异较大，以你设备自己的说明书为准；配网成功后再按上面两种方式之一添加进 app。

## 五、添加后没画面

按顺序核对：

1. 设备是否通电、网线是否插好（无线机看指示灯是否已联网）；
2. 用户名密码是否输错——密码不对多数表现为连接失败而不是离线；
3. 局域网方式添加的，确认手机没切换到流量；
4. 云 ID 是否抄错（字母数字混淆是重灾区，比如 `0` 和 `O`）。

都不行就重启设备后再搜一次。预览出图后的操作见 [实时预览与录像回放.md](实时预览与录像回放.md)。
