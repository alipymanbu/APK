设备出图之后，剩下的都是界面操作。预览和回放的所有按钮都集中在播放画面那一屏，横竖屏行为不同：竖屏看缩略窗口，横屏自动进入全屏。

## 一、实时画面

在设备列表里点设备旁的播放入口就进入实时画面。播放页上常用的几个操作：

| 操作 | 在哪 / 干什么 |
| --- | --- |
| 切换分窗 | 1 / 4 / 9 / 16 窗口布局，多路设备一屏同看 |
| 切换画质 | SD / HD 按钮：SD 是流畅档，流量小；HD 是高清档，网络差时先用 SD 顶着 |
| 截图 | 把当前画面存到手机 |
| 本地录像 | 开始 / 停止按钮，把当前通道的画面录进手机存储 |
| 声音 | 打开 / 关闭所选通道的声音 |
| 对讲 | 手机按住说话，声音从设备端的喇叭放出来，需要给 app 麦克风权限 |

部分配套设备的说明书写明单屏最多支持 32 路画面，实际能开几路取决于你添加了多少通道。

## 二、云台控制（PTZ）

接的是会转的摄像机（球机、云台机）时，播放页有 PTZ 面板，方向键控制镜头转动。固定枪机没有电机，这个面板对它无效。预置位等进阶操作以界面上实际出现的按钮为准。

## 三、看录像回放

录像有两个来源，入口不同：

1. **设备端录像**（存在录像机硬盘或摄像机存储卡里）：播放页进回放模式，按时间轴选日期和时段看。回放里想找某件事，直接拖时间轴到大概时刻，比逐天翻快得多。
2. **手机本地录像**（第一节里你自己录的）：存在手机相册或 app 的文件目录里，拔了设备也能看。

一个要有预期的点：有用户反馈回放缺快进按钮，快进基本靠拖时间轴实现。找到目标片段后切回实时画面再进回放、从大致时刻慢慢逼近，比来回整段翻省时间。

回放看不了时先确认两件事：设备端是不是真的在录像（存储卡在不在位、硬盘有没有满）、你的账号对该通道有没有回放权限。

## 四、画面卡顿或黑屏

1. 先切到 SD 档，能出图说明就是带宽不够；
2. 退出该通道重新打开；
3. 确认设备在线状态——设备显示离线或反复掉线时，去 [设备离线与添加失败排查.md](设备离线与添加失败排查.md) 按现象排查供电和网络；
4. 家里宽带的上行速度决定外网看家的清晰度上限，上行小的宽带外网看 HD 会很勉强。

更多界面细节（报警消息、设备参数修改）在 app 内对应入口里，名称以你手上的版本为准。
