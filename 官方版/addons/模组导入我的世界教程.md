## 一、先弄清两段流程

导入分两段，很多人卡住是因为只做了第一段：**在 app 里下载并安装文件**，只是把包送进了游戏；**还要在游戏的世界设置里激活**，模组才会真的生效。安卓与 iOS 的第一段按钮不同，第二段完全一样。

## 二、安卓：下载 → INSTALL → 重启游戏

1. 在 app 里点开一个模组，点 `DOWNLOAD` 开始下载。
2. 下载完点 `INSTALL`，出现安装成功的提示。
3. **重启《我的世界》**（完全退出再进），刚装的包才会出现在游戏里。
4. 进游戏激活，见下一节。

部分版本点 INSTALL 后会连着弹两次确认（OK → CONTINUE），点完即完成导入。

## 三、iOS：Copy to Minecraft

1. 在 app 里点模组的下载按钮，下载开始。
2. 下载完成出现底部菜单，选 **Copy to Minecraft**。
3. 游戏自动启动，顶部出现导入提示：
   - 打开的是 `.mcworld`（整张地图）：游戏直接进入该世界；
   - 打开的是 `.mcpack`（单个包）：提示“成功导入”，包会出现在编辑世界的 Behavior Pack / Resource Pack 标签里。

## 四、游戏内激活（两个平台相同）

1. 主界面点 Play → Create New World（或点已有世界旁边的铅笔图标进编辑页）。
2. 左侧列表下滑，找到 **Resource Pack**（资源包）和 **Behavior Pack**（行为包），在 **Available** 标签里找到刚导入的包 → 点 **Activate**。
3. 激活成功的标志是包挪进了 **Active** 列表、旁边按钮变成 Remove。**两个标签都要检查** —— 只改外观的包在资源包里，改生物行为、道具、配方的包在行为包里，很多模组两者都带，漏一个就会出现“装了没效果”：只开了资源包，新生物站在那不会动；只开了行为包，它会显示成白盒或缺失材质。
4. 弹出确认框时注意别点到“取消”那侧 —— 有教程特别提醒，这类弹窗里绿色按钮常是 Don't add pack（不添加），点下面那颗才真的装上。
5. 进入世界验证效果。

**激活是按世界生效的，不是全局开关**：在 A 世界激活过，B 世界和第二天新建的世界里都得重新激活。所以“模组装过一次、新建世界后又不见了”多半不是丢了，是新世界还没给它开（见 [常见问题与排查.md](常见问题与排查.md) 第二节）。

## 五、常见文件类型对照

| 后缀 | 是什么 | 打开后的动作 |
| --- | --- | --- |
| `.mcpack` | 单个资源包或行为包 | 提示导入成功，去世界设置里激活 |
| `.mcaddon` | 打包在一起的多个包 | 一次导入多份，同样去激活 |
| `.mcworld` | 整张带模组的地图 | 直接进入该世界，无需再激活 |

在文件管理器里直接点这些后缀的文件，也会拉起游戏导入；导入时游戏左下角先显示 “Import Started”，成功变成 “Successfully Imported”。三条补充：

- 文件放在**手机内部存储**，放 SD 卡或纯云盘目录里的包游戏有时扫不到；
- 文件点不开时走万能入口：游戏 → 设置 → 存储 → Import，手动选文件；
- `.jar` 是 Java 版的 mod，手机上的基岩版永远不会导入它，看到 `.jar` 就说明拿错了版本。

若卡在导入中或提示失败，按 [常见问题与排查.md](常见问题与排查.md) 第三节处理。

## 六、部分模组要开实验性选项

少数**脚本类**模组依赖实验性功能，导入激活后仍不生效时，进世界设置的 **Experiments**（实验性）区域打开 **Beta APIs**。这不是没代价的开关 —— 开了之后该世界成就被禁用、且创建后关不掉，什么时候开、怎么开、代价是什么，单独写在 [实验性选项与成就禁用.md](实验性选项与成就禁用.md)。
