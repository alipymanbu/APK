## 一、提示 Duplicate pack detected（检测到重复包）

同一个模组装过旧版本时会出现。按官方 FAQ 的顺序处理：

1. 进《我的世界》→ 设置 → 存储，删掉该模组的旧包；
2. 彻底关闭游戏（后台也杀掉）；
3. 重新安装新版本模组。

## 二、导入成功了，世界里却看不到

依次检查，多数到第二步就解决：

1. **有没有激活**：世界设置 → Resource Pack / Behavior Pack → 确认包是启用状态（导入 ≠ 激活，见 [模组导入我的世界教程.md](模组导入我的世界教程.md) 第四节）；
2. **两个标签都看**：外观类在资源包、行为类在行为包，漏看一边就像没装；
3. **游戏是否为最新版**：大版本更新后旧包会失效，先更新《我的世界》再试；
4. **重新下载**：包文件缺失或损坏时，删掉重新导一次。

## 三、提示导入失败 / 导入没反应

- 确认文件后缀是 `.mcpack` / `.mcaddon` / `.mcworld` 之一，下载中断的包不完整，重新下一次；
- 先把游戏完全退出再点导入，游戏在后台运行时有时接不住导入请求；
- 手机存储空间不足也会导致导入失败，先清理出几百 MB 再试。

## 四、装了模组后游戏崩溃或行为异常

这是模组冲突的典型表现，按《我的世界》官方帮助的排查顺序做：

1. 重启游戏，等所有文件更新完再进；
2. 更新《我的世界》到最新版；
3. 停用模组再逐个启用 —— 同时开 3 个以上模组、或与商城内容混用时最容易冲突；
4. 多个包改同一资源时，**列表靠上的优先**，把想要的包调到最上层；
5. 新建一个世界单独测这个模组，能定位是不是它的问题。

## 五、打开就闪退、白屏

先按 [下载与安装教程.md](下载与安装教程.md) 核对包名是否为 `com.kayenworks.mcpeaddons`（装错同名应用会这样）；确认无误仍闪退，卸载后重装一次。App Store 评论里有用户反馈过平板上白屏闪退的情况，多数与设备或版本有关，升级到商店最新版后再试。

## 六、app 里「看广告免费获取」点不了

官方开发者在 App Store 对该问题的回复是：部分广告需要等几秒才会出现关闭或领取按钮，稍等再点；若一直点不了，把机型和系统版本发给开发者排查。另外按官方 FAQ 的说明，内容里的弹窗广告多来自第三方模组作者的请求 —— 作者靠广告收入维持开发，app 只是按其要求挂了链接，不影响你下载模组本身。上面这些都不管用时，把具体现象发到官方邮箱 [addons@kayenworks.com](mailto:addons@kayenworks.com)，官网常见问题页是 [kayenworks.com/mcpeaddons](https://kayenworks.com/mcpeaddons/)。
