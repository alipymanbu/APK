## 一、什么模组才需要开

大多数模组激活就能用，**只有脚本类模组**（自定义界面、原版行为包做不到的新机制）才依赖实验性功能。判断依据看模组说明页 —— 它没提就先别开，先按 [模组导入我的世界教程.md](模组导入我的世界教程.md) 激活测试。

顺带纠正一个过时说法：老教程里常让你开 “Holiday Creator Features”，现行版本的《我的世界》已经没有这个开关，脚本类模组现在对应的是 **Beta APIs**；自定义物品、方块这类功能也已经转正，不再需要实验开关（以你当前游戏版本界面为准）。

## 二、怎么开

1. 主界面 Play → 点世界旁边的铅笔图标进 Edit World（新世界则在创建页）；
2. 左侧列表找到 **Experiments**（实验性）；
3. 在 Add-on creators 区域打开 **Beta APIs**（说明写着 use “-beta” versions of API modules 的那个）；
4. 弹确认框时选“仍然开启”那侧 —— 有教程特别提醒：这类弹窗里绿色按钮常是“取消返回”，点错等于没开。

## 三、开了的代价（先看这条再动手）

- **成就被禁用**：开启后该世界左栏直接显示 Achievements disabled，这个世界再也拿不到成就；
- **关不掉**：实验性选项在世界创建后无法关闭，只能一直开着；
- **先复制存档**：拿重要的存档直接开实验功能有风险，先复制一份世界，在副本上开。

以上是截至 2026-09 多份教程一致的口径，具体警告文字以游戏内弹窗显示为准。

## 四、开了还是没效果

按顺序查：包是否两个都激活了（只开行为包会缺材质、只开资源包生物不会动，对照 [常见问题与排查.md](常见问题与排查.md) 第二节）；脚本包是否出现在 Active 列表而不是停在 Available；游戏是否为最新版（旧版游戏跑不了新包，见 [版本号与系统要求.md](版本号与系统要求.md) 第四节）。
