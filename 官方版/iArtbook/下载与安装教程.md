## 一、安装前的准备

| 项目 | 建议 |
| --- | --- |
| 系统版本 | 安卓 5.2 及以上（以安装包检测为准，低于该版本安装时会直接报不兼容） |
| 存储空间 | 安装包本身 200.88M，加上安装后的占用，建议预留 1GB 以上余量 |
| 安装来源 | 从下面的网盘链接下载 APK，属于「应用商店以外」的安装方式，需要临时允许一次「未知来源」 |
| 网络 | 安装过程不需要联网；首次启动同意隐私政策后，教程、填色素材这类内容需要联网加载 |

## 二、获取安装包

1. 打开上面的 **iArtbook 安装文件资源（夸克网盘）** 链接，用夸克 App 或网页版登录自己的账号；
2. 把分享里的文件转存到自己的网盘（转存后才不会受原分享状态影响）；
3. 从自己的网盘把 APK 文件下载到手机存储；
4. 下载完成后，在通知栏点开，或到文件管理器的「下载」目录里找到这个 APK 文件。

## 三、安装步骤

1. 点开下载好的 APK 文件，系统会弹出「是否允许安装」的提示；
2. 首次从浏览器或文件管理器安装时，会跳到「允许此来源应用安装」页面，打开开关后返回；
3. 回到安装界面，点「安装」，等待进度走完（安装包接近 200M，这一步在低端机上会慢一些）；
4. 点「打开」直接进入应用，或先点「完成」，之后从桌面图标进入。

部分国产系统还会在安装后再弹一次「确认安装」，属于系统行为，正常确认即可。

## 四、第一次打开要同意什么

- **隐私政策**：首次启动会先弹隐私协议，同意后才能进入主界面；
- **存储权限**：不是启动时就要的，而是你第一次往相册保存作品时才会弹——建议直接允许，否则保存会一直失败（见 [常见问题排查.md](常见问题排查.md)）；
- **照片/媒体权限**：想在「创作」板块导入相册里的图做底稿，也需要这个权限，按需允许即可。

## 五、核对拿到的是不是这一版

搜索「iArtbook」很容易搜到**好几款同名但完全不同**的应用，装错名字后面对的就是另一套界面。可以从这几点核对：

| 核对点 | 本文这一版 |
| --- | --- |
| 包名 | `com.tktn.ycfn` |
| 版本 | 2.2.7（更新内容为画板功能优化） |
| 安装包大小 | 200.88M |
| MD5 | `039BE953432445EF6D185890CFCA8080` |
| 界面语言 | 中文，主界面为「画册 / 创作 / 像素 / 我的」等板块 |

MD5 可以用文件管理器或校验工具算一下安装包，32 位值对得上就说明文件没有下岔。更多同名应用的辨别方法单独写在 [常见问题排查.md](常见问题排查.md) 里。

## 六、装不上先看这三条

1. **提示「禁止安装未知来源」**：回到系统设置里把刚才那个来源的「允许安装」开关打开，再重新点 APK；
2. **提示空间不足**：先清出 1GB 以上余量再装，200M 的安装包在解包阶段需要的临时空间比它自身还大；
3. **提示解析失败或不兼容**：多半是下载不完整（文件小于 200.88M）或系统版本低于要求，重新下载一次，或核对安卓版本。

这三条之外的情况，转到 [常见问题排查.md](常见问题排查.md) 对照处理。装好之后从 [界面入门与常用手势.md](界面入门与常用手势.md) 开始上手。
