笔刷和图层是这套应用里最值得花时间摸透的两块：前者决定线条和上色的手感，后者决定画面能不能分层修改。本文把常用的参数和操作按「你会碰到什么问题」来组织。

## 一、笔刷大致分几类

预装的笔刷覆盖了几类常见媒质，对应的手感不一样：

| 类型 | 适合画什么 |
| --- | --- |
| 铅笔 | 打稿、素描线条，笔触细 |
| 水彩 | 通透的晕染上色，颜色叠着叠着就润了 |
| 炭笔 | 粗粝的明暗块面 |
| 马克笔 | 干净的色块、平涂 |
| 喷枪 | 柔和的渐变与光影 |
| 记号笔 / 涂抹笔 | 勾边，以及把已有颜色揉开 |

按干湿特性还可以分成干性、湿润、光泽三类笔刷；湿润类里又分不带拉扯、带拉扯、超精准几种。不用记名词，画的时候各试一遍，留下顺手的即可。

## 二、把笔刷调到你想要的样子

- **笔刷详情设置**：在画布上方工具栏点开当前笔刷，能进入详细设置，参数有 50 多项，常用的就几样——粗细、不透明度、硬度、纹理；
- **快速设置**：如果你偏好简单的圆形笔刷，设置里有笔刷形状的硬度、椭圆度、旋转几个快捷项，调这三个就够用；
- **左右手滑条**：画布左侧的两个滑条是画的过程中随时调粗细和透明度用的（见 [界面入门与常用手势.md](界面入门与常用手势.md)）；
- **线条稳定**：写字或勾线时手抖，可以把书法稳定类选项调高，即使用手指画也能得到较顺滑的线条（不同版本里的选项名称略有差异）；
- **变成涂抹笔**：任何笔刷都能配合涂抹工具（手指图标）当涂抹笔用，有几种不同的涂抹算法可选，水彩晕染感主要靠它；
- **笔刷导入导出**：笔刷支持导出成文件、再导入到另一台设备，换机时自己调好的笔刷能带走；
- **重命名**：调好一只常用笔刷后，在笔刷列表里点击笔刷名可以重命名，改成「我的勾线」之类的名字方便下次找。

## 三、图层的日常操作

图层没有数量上限，日常用到就这几个动作：

1. **新建**：点开图层面板，点「+」加一个空白图层；勾线、上色、背景各一层，改哪层不影响哪层；
2. **排序与显隐**：长按或拖动调整上下顺序，点眼睛图标切换可见性（上色总盖住线稿的解法见 [填色玩法与防出界.md](填色玩法与防出界.md)）；
3. **透明度**：选中图层调整整体不透明度，常用来垫一张低透明度的参考图在底下描；
4. **复制 / 删除 / 清空 / 填充**：图层面板里都有对应入口；
5. **导入图片当图层**：相册里的图可以直接作为一个新图层进来，不用先退出再导入；
6. **蒙版**：给图层挂蒙版控制显示范围，上色出界时比橡皮擦好补救；
7. **无损变换**：对图层内容做移动、缩放、旋转，画面质量不会像合并后那样损失。

选区工具可以配合羽化数值使用，边缘柔化的选区适合做发光或渐变过渡。

## 四、混合模式怎么选

图层的混合模式有 20 多种（有版本标注为 27 种），日常最常用的是这几个：

| 模式 | 典型用法 |
| --- | --- |
| 正片叠底 | 投影、加深，颜色只会更暗 |
| 滤色 | 提亮、做光效 |
| 柔光 | 温和地过渡明暗，统一色调 |
| 叠加 | 增强对比，比柔光更冲 |

拿不准时先试正片叠底和滤色这两个，八九成的场景都是它们俩。

## 五、配色与调色板

- 应用自带两个取色器和一个颜色混合器，先在取色器里调好色，再混色观察过渡；
- 预设调色板有 40 多种，纯色和渐变都有，填色玩法里直接整套调用很省事；
- 可以自建调色板：把常用的几个颜色存成一组并命名，画系列图时保持用色统一；
- 调色板支持导入 / 导出，换设备时配色方案能带走。

调好颜色画完之后，怎么把图存出去看 [导出图片与动画方法.md](导出图片与动画方法.md)；笔刷设置里找不到某个选项时，先确认你的版本，再对照 [常见问题排查.md](常见问题排查.md)。
