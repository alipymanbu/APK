iArtbook 一套界面里装了两种玩法：一是正经的绘画工作台（画布、图层、笔刷），二是偏休闲的填色与像素涂色。本文以 2.2.7 版为基准带你认一遍入口，手势部分适合边开应用边对照。

## 一、主界面的几个板块

以 2.2.7 版为准，打开后主要能看到这几块：

| 板块 | 里面是什么 |
| --- | --- |
| 画册 | 新手入门指引，以及各主题的填色内容，适合从零开始的人 |
| 创作 | 导入自己的图片当底稿，在它上面二次创作或临摹 |
| 像素 | 像素风格的线稿画册，直接选一张开始涂色 |
| 我的 | 隐私设置、缓存清理等个人相关选项 |

部分版本还会在底部提供「探索」（解压填色、数字填色的入口）和「教程」（绘画课程列表）两个标签。你的版本里叫什么名字以实际界面为准，功能大同小异：一个是找线稿来涂，一个是跟着课程学。

界面本身也有几处可调：左手党可以把界面切到左手布局，深色 / 浅色主题和界面强调色在设置里换。第一次用先把这些调顺，比画画中途再改省事。

## 二、新建画布开始画

1. 在主界面点「绘画」，进入绘画工作台；
2. 点「新图像」，会出现一排预设尺寸（正方形、竖屏比例等）；
3. 想要自定义尺寸，点「选择新的图像尺寸」旁边的「+」号，自己填宽高；
4. 选中一个尺寸就进入画布，上方是工具栏（画笔、图层、颜色等），中间就是画纸。

画透视场景时，部分版本的画布还提供消失点 / 辐射线两种辅助线模式，打开后当空间参考（以版本为准）。

主界面里除了「绘画」还有「动画」入口，那是逐帧动画的工作台，导出方法写在 [导出图片与动画方法.md](导出图片与动画方法.md)。

## 三、画布上的常用手势

| 手势 | 作用 |
| --- | --- |
| 双指开合 | 缩放画布 |
| 双指点按 | 撤销上一步 |
| 三指点按 | 重做被撤销的一步 |
| 按住色圈拖到画布上 | 用当前颜色填充目标区域 |

这几个手势覆盖了日常绘画的大部分操作，比反复点工具栏快得多。撤销 / 重做的步数很深（有描述称超过一百步，以版本为准），画错了放心退。

## 四、调笔刷大小的两种方法

1. **画布左侧滑条**：进入画布后，屏幕左边有两个小方块条，上下滑动即可实时调节笔刷大小（另一个调的是不透明度类参数），这是画的过程中最顺手的方式；
2. **笔刷详情设置**：在上方工具栏点开当前笔刷，会弹出详细设置界面，里面有「画笔粗细」等参数，可以拖滑块或直接输数值，改的是这只笔刷的默认状态。

具体参数项随笔刷类型有差异，更多笔刷相关的设置见 [笔刷与图层使用技巧.md](笔刷与图层使用技巧.md)。

## 五、导入图片临摹

1. 回主界面，进入「创作」板块；
2. 选择导入相册里的图片，它会作为底稿进入工作台；
3. 在底稿上新建图层再动笔，原稿不被破坏，画完把底稿图层隐藏或删掉就行。

另有「跟画」类的学习玩法：选一张作品作为课程，画布上会在「你的画」和「课程图」之间切换（点屏幕左侧切换），还提供等大小、第一层、水平分割、垂直分割几种对照方式。填色玩法（含数字填色、照片涂色）单独整理在 [填色玩法与防出界.md](填色玩法与防出界.md)。

## 六、画完之后

作品是自动保存的，不用刻意找保存按钮；要把成果导出到相册或导出动画，看 [导出图片与动画方法.md](导出图片与动画方法.md)。画到一半卡住了，去 [常见问题排查.md](常见问题排查.md) 对症处理。
