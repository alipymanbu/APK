# iArtbook 常见问题排查

> 把 iArtbook 用起来最常碰到的几类问题——装不上、存不出、卡顿、丢作品、认错应用——按现象给出排查顺序。

以下按「现象 → 先查什么 → 怎么处理」组织，多数问题在 2.2.7 版上有实测依据，少数与系统相关的行为各机型可能有出入。

## 一、装不上

| 现象 | 先查什么 | 处理 |
| --- | --- | --- |
| 弹「禁止安装未知来源应用」 | 本次安装来源（浏览器 / 文件管理器）的安装开关 | 系统设置 → 应用 → 特殊权限 → 安装未知应用，给对应来源开「允许安装」，再重新点 APK |
| 提示空间不足 | 剩余存储 | 清出 1GB 以上余量（安装包 200.88M，安装阶段临时占用更大） |
| 提示解析失败 / 不兼容 | APK 是否完整、系统版本 | 文件小于 200.88M 说明下载不完整，重新下载；安卓版本低于 5.2 则装不了，以安装包检测为准 |

## 二、保存失败或相册里找不到图

1. **先确认权限**：设置 → 应用 → iArtbook → 权限，把「存储 / 照片和媒体」设为允许。首次保存时弹的授权如果被拒过，之后每次保存都会失败，必须到这里手动打开；
2. **再确认位置**：导出成功后图片在系统相册的最新一张，个别相册 App 会把刚存的图归到「其他相册」，翻一下时间线；
3. **文件确实没有**：重新走一遍导出流程（画布上方「三个点」→ Save → 选格式 → 存储图像），完整步骤见 [导出图片与动画方法.md](导出图片与动画方法.md)。

## 三、画画时卡顿掉帧

按影响从大到小排查：

1. **画布尺寸过大**：新画布时选了远超需要的分辨率，手机上一般用预设尺寸就够，超大画布是低端机掉帧的头号原因；
2. **图层数太多**：每层都占内存，画完一阶段就合并或删掉不要的层；
3. **后台程序多**：先把后台清一清再回应用；
4. **机型较旧**：运行内存小的设备建议控制画布和图层数量，逐帧动画也尽量控制在短篇。

## 四、作品会不会丢

- 绘画过程是自动保存的，正常退出不会丢，不需要手动找保存按钮；
- 「我的」板块里有缓存清理入口，清的是缓存数据；正常的绘画文件不会被它清掉，但卸载应用会连同作品一起删——**换机或重装前，先把要留的作品导出到相册**（方法见 [导出图片与动画方法.md](导出图片与动画方法.md)）；
- 应用崩溃后重开，一般能回到最近一次自动保存的状态，个别最后一两笔可能要补画。

## 五、搜到的可能不是这一款

「iArtbook」这个名字撞了好几款应用，搜教程时如果发现界面完全对不上，先核对是不是同一款：

| 特征 | 本文这一款（中文安卓版） |
| --- | --- |
| 包名 | `com.tktn.ycfn` |
| 版本号形态 | 2.x（如 2.2.7） |
| 界面 | 中文，绘画工作台 + 填色 / 像素板块 |
| 开发商 | 深圳市征弘科技有限公司 |

另有同名应用：一款是 App Store 上的英文专业绘画应用（版本号到 10.x，主打无限图层与 Apple Pencil，开发者并非上文公司）；还有一款安卓上的轻量应用用的也是类似名字（包名 `risko.digitalpaint`）。核对包名是唯一可靠的办法。需要重新拿安装包时，从 **iArtbook 安装文件资源（夸克网盘）** 获取并按 [下载与安装教程.md](下载与安装教程.md) 里的 MD5 核对。

## 六、免费还是收费

应用本体免费安装，内有应用内购买项目（具体是哪些内容、多少钱以应用内实际显示为准）。不购买也能使用绘画、填色等基础功能；如果发现某个功能被付费墙挡住，那是版本内的定价行为，与安装方式无关。
