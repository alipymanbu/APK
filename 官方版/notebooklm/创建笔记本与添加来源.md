## 一、笔记本是什么定位

一个笔记本 = 一组来源 + 围绕这组来源的问答和音频。你的问题、它给的答案、生成的音频都只基于笔记本里的来源，不会去互联网上随手抓内容。所以开工前想清楚「这次研究用哪堆资料」，把相关的都放进同一个笔记本，比每个文件开一个笔记本好用得多。

## 二、新建笔记本的入口

1. 打开应用，首页右下角点**新建**；
2. 起个名字（建议用主题命名，比如「毕业论文-文献综述」）；
3. 进入笔记本后先去添加来源，空笔记本没法提问。

首页每张卡片显示笔记本名称、表情符号、来源数量和日期，方便回头找。

## 三、能添加哪些来源

在笔记本底部切到**来源**（Sources）标签，点添加，常见类型如下：

| 来源类型 | 说明 |
| --- | --- |
| PDF | 需要带文字层的文本版；扫描图片型的解析不出内容 |
| 网页链接 | 公开可访问的 URL |
| YouTube 视频 | 公开视频，按字幕转写解析 |
| 粘贴文本 | 手里只有纯文本时直接贴进去 |
| 音频文件 | 录音、播客等，自动转写后可提问 |
| Google 文档 / 幻灯片 | 配合 Google Drive 使用 |
| 文本 / Markdown 文件 | .txt、.md 等纯文本格式 |
| Word 文档 | .docx，2025 年底起支持 |
| Google 表格 | 表格数据收进来后可直接针对数据提问 |
| 图片 | 手写笔记、宣传册拍照上传（官方逐步放开中） |
| Drive 文件链接 | 把 Drive 里的文件当网址粘贴，多个链接用逗号分隔 |

单个来源上限约 50 万词或 200MB，免费版每个笔记本可放 50 个来源，具体数字见[免费版额度与限制一览](免费版额度与限制一览.md)。

不想自己找资料时还有两条路：**发现来源**（Discover sources）输入一个主题，它会列出相关网页资源，选中的直接导入；**深度调研**（Deep Research）给一个研究问题，它会自动浏览大量网页、生成一份带来源的报告，报告和来源都能一键收进笔记本（入口在来源面板的「网页」，分快速调研和深度调研两档，2025 年底上线）。来源名额顶格时的合并办法见[来源放不下怎么办](来源放不下怎么办.md)。

## 四、手机上最快的加来源方式

不用先打开 NotebookLM 再找文件 —— 在任何应用里看到内容，直接用系统分享面板：

1. 在浏览器、PDF 阅读器或 YouTube 里点**分享**；
2. 分享列表里选 NotebookLM；
3. 选择目标笔记本，内容就作为新来源进去了。

看到一篇长文、一个视频想稍后处理时，这个路径顺手得多，省去复制粘贴。

## 五、来源加好后的三个整理动作

- **改名**：默认标题常是 `document(3).pdf` 这类乱名，改成描述性名字，后面提问和引用时更好认；
- **勾选**：每个来源前面有勾选框，提问时只勾选你想让它参考的那几份，答案会更聚焦（比如拿两份报告做对比，就只勾这两份）；
- **删除**：不需要的来源随时移除，给限额腾位置。

来源就绪后，就可以去生成音频概览了，完整步骤见[音频概览生成与收听](音频概览生成与收听.md)。
