# SHAREit 是什么软件

> SHAREit（中文名茄子快传）是一款跨平台文件互传应用，本篇讲它是谁家的、靠什么传文件、能传什么、除手机外还有哪些形态。

## 一、它是什么，中文名叫什么

SHAREit 的中文名是「茄子快传」，开发者是 Smart Media4U Technology Pte.Ltd.。它早期出自联想，这一点从安卓包名 `com.lenovo.anyshare.gps` 里还能看到痕迹（anyshare 即早期产品名）。在 Google Play 上的上架名是「SHAREit: Transfer, Share Files」，你搜到的「SHAREit」「茄子快传」「快传」指的多半是同一个东西。

它的用途一句话说清：你在两台设备之间直接互传文件，不消耗流量、不需要数据线。Google Play 的商店页同时标注了「含广告、含应用内购买」，也就是说你用核心传输功能不花钱，但会碰到广告——广告的形态、去广告的正规途径与权限细节，集中在 [广告与隐私权限说明.md](广告与隐私权限说明.md) 里讲。

## 二、传文件靠什么，要联网吗

传输走的是设备之间的直连：一台设备开出热点或建立直连通道，另一台接上去，数据在两台设备之间直接流动，不经过服务器。所以：

- 不消耗手机流量，也不要求旁边有能上网的路由器；
- 两台设备各开各的 SHAREit，一端点发送、一端点接收即可互相发现；
- 有一处例外要记住：iOS 设备**收**文件时，收发双方必须连在同一个局域网里，这是官方帮助中心写明的限制。

连接建立需要你的确认——别人向你发起连接时会先弹出邀请，你不点接受，对方传不了任何东西进来。

## 三、能传什么

按官方帮助中心的口径，类型上没有限制：文档、照片、音乐、视频、已安装的应用都可以，还能一次选多个文件、直接发整个文件夹、用群发（Group Share）同时发给多个人。

| 你想传的 | 可不可以 |
| --- | --- |
| 照片、视频、音乐、文档 | 可以 |
| 已安装的应用（把 APK 传给对方） | 可以 |
| 整个文件夹 | 可以，发送时在文件浏览器里选中文件夹 |
| 一次性发给多个人 | 可以，群发模式 |
| 单个文件大小 | 官方口径无上限，文件越大传得越久 |

速度方面，官方宣传口径是峰值 42MB/s、约为蓝牙的 200 倍。这是理想环境的数字；你实际能跑多快取决于 Wi-Fi 环境、两台设备的距离和手机自身状态，遇到速度不理想时可以按 [连接不上与传输失败排查.md](连接不上与传输失败排查.md) 里列的因素逐项看。

## 四、手机之外还有哪些形态

你手里这份安卓安装包只是它的一种形态，另外还有：

| 形态 | 在哪拿 | 适合什么场景 |
| --- | --- | --- |
| 安卓应用 | 本文的网盘资源或 Google Play | 手机、平板之间互传，安卓换机迁移 |
| iOS 应用 | App Store | 与安卓互传文件（收文件需同一局域网） |
| Windows / macOS 客户端 | 官方网站 | 手机与电脑大文件互传、备份照片 |
| Web 版 | 浏览器打开 `https://web.ushareit.com` | 在别人的或临时用的电脑上传文件，不装客户端 |

手机端除了传文件，还内置了媒体播放器、文件管理、手机克隆、PPT 遥控这类附加功能；不同版本的菜单里还可能见到隐私空间（Safebox）、视频压缩、垃圾清理等工具，以你手上的版本实际显示为准。怎么连电脑传文件见 [手机与电脑互传文件.md](手机与电脑互传文件.md)；换手机时整机迁移资料见 [换新手机迁移资料.md](换新手机迁移资料.md)；不想装第三方应用时，系统自带的互传方案也能覆盖一部分场景，取舍见 [和系统自带互传怎么选.md](和系统自带互传怎么选.md)。

## 五、版本号后面的字母是什么意思

你在不同渠道会看到 `6.27.49_ww`、`6.53.88_UD` 这类主版本号后面带字母后缀的写法，不同后缀对应不同分发渠道的构建。判断拿到的是不是同一款应用，看包名是不是 `com.lenovo.anyshare.gps` 就够了；版本号新旧比较没意义——不同渠道的构建进度并不一致。
