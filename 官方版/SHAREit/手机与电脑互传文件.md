# SHAREit 手机与电脑互传文件

> 讲手机和电脑之间怎么建立 SHAREit 连接：网页版扫码、电脑客户端扫码、热点直连三种方式怎么选，连上之后怎么互传。

## 一、先选一种连接方式

手机和电脑互传，前提是手机装好安卓端（安装见 [下载与安装教程.md](下载与安装教程.md)）。电脑端有两种形态，加上热点直连，一共三条路：

| 方式 | 电脑上要装东西吗 | 适合 |
| --- | --- | --- |
| 网页版扫码 | 不用，浏览器即可 | 临时用、别人的电脑、不想装客户端 |
| 电脑客户端扫码 | 装官方客户端 | 经常互传、想用电脑看手机里的文件 |
| 热点模式 | 不用 | 旁边没有路由器、连不上同一 Wi-Fi |

三种方式的传输都不走互联网、不耗流量，数据在手机与电脑之间直接流动。

顺带一提：如果你的电脑是 Windows、手机是较新的安卓，谷歌 Quick Share 也有官方 Windows 客户端，同样免数据线。两个都用得上的话，先比一比再定，见 [和系统自带互传怎么选.md](和系统自带互传怎么选.md)。

## 二、方式一：网页版扫码（推荐先试这个）

官方帮助中心给的连法：

1. 手机和电脑连上**同一个 Wi-Fi**；
2. 电脑浏览器打开 `https://pc.ushareit.com`，页面上会出现一个二维码；
3. 手机打开 SHAREit，选「连接电脑 / Connect to PC」，用手机扫电脑屏幕上的二维码；
4. 连接建立后直接在网页里选文件互传。

好处是电脑上什么都不用装。如果你是在公司或网吧这种临时环境用，这就是最省事的一条路。

## 三、方式二：电脑客户端扫码

1. 在电脑上装 SHAREit 客户端并打开（官方 PC 页面在 `https://ushareit.io/shareit-pc/`，支持 Windows 与 macOS，Windows 7 到 11 都在支持范围内）；
2. 电脑端点「Show QR Code / 显示二维码」；
3. 手机端选「连接到 PC」，扫描电脑屏幕上的二维码；
4. 连上后互选文件即可传输。

客户端比网页版多一个「Remote View」：连上后你可以直接在电脑屏幕上浏览手机里的文件、选中就传，不用在手机上来回点。批量传照片备份到电脑时，这个比网页版顺手。桌面端还支持把文件直接拖进窗口发送，成批的文件不用逐个点「添加」（以你装到的版本界面为准，找不到拖拽入口就走发送按钮）。

## 四、方式三：热点直连（没有路由器时）

旁边没有可用的 Wi-Fi 时：

1. 电脑端保持打开；
2. 用手机开出热点（手机设置里的个人热点）；
3. 让电脑连上手机开出的这个热点；
4. 再按方式二扫码或搜索连接。

也就是把手机热点当成那条「同一局域网」。反过来由电脑开热点、手机去连也可以，只要最终两台设备在同一个网络里。

## 五、连上之后怎么传

- **手机发电脑**：手机端点发送、选文件，选电脑的图标，电脑端确认接收；
- **电脑发手机**：电脑端点发送选文件，手机端点接收，弹出的连接邀请要点接受；
- 接收端确认是必须的一步，谁收谁确认；
- 电脑端收到的文件默认进下载目录，可在客户端设置里改保存位置。

传完之后文件在哪、传输记录在哪看，见 [接收文件保存位置.md](接收文件保存位置.md)。

## 六、连不上先查三样

按出现频率排：

1. **两台设备不在同一个网络里**——网页版和搜索方式都要求同一 Wi-Fi（或热点直连）；
2. **电脑防火墙拦了**——Windows 防火墙首次弹出的允许提示别点取消，拦住后电脑既搜不到手机也收不到文件；
3. **有一端的 SHAREit 没开着**——网页版方式里电脑只开网页还不够，手机端要保持在前台。

更全的排查清单在 [连接不上与传输失败排查.md](连接不上与传输失败排查.md)。
