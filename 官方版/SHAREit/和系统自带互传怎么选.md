# SHAREit 和系统自带互传怎么选

> 安卓有 Quick Share、苹果有 AirDrop、国产手机还有厂商互传——什么情况系统自带就够、什么情况才轮到 SHAREit，这篇给判据。

## 一、先把候选摆出来

| 方案 | 覆盖的平台 | 要不要装应用 |
| --- | --- | --- |
| SHAREit | 安卓、iOS、Windows、macOS | 两端都要装（电脑可用网页版） |
| Quick Share（谷歌） | 安卓机型之间；官方另有 Windows 客户端 | 安卓系统自带，PC 装客户端 |
| AirDrop（隔空投送） | 仅苹果设备之间 | 系统自带 |
| 厂商互传（小米、华为、OPPO、vivo 等） | 同品牌或同一互传联盟的机型之间 | 系统自带 |
| 聊天工具传文件（微信、QQ 等） | 任何能登录的设备 | 走云端中转，大文件与原图常受限制 |

各方案的最低系统要求与 PC 端支持随版本变化，以各家官方页面为准。

## 二、按场景对号入座

- **两台都是苹果**：AirDrop 直接用，SHAREit 帮不上忙（它对 iOS 还多一条收端要同局域网的限制）；
- **两台安卓、同品牌或同联盟机型**：系统互传零安装零广告，优先它；
- **两台安卓、不同品牌**：双方都支持 Quick Share 就用它；机型老旧或生态混杂时，SHAREit 的兼容面更宽；
- **安卓和 iPhone 之间**：系统自带方案跨不过生态，剩下聊天工具和 SHAREit 二选一——原图、长视频、安装包走 SHAREit，随手传张图走聊天工具；
- **手机和电脑之间**：安卓手机配 Windows 电脑时，Quick Share 官方客户端和 SHAREit 都能做；SHAREit 在 Android 与 Windows / macOS 的各种组合里走的是同一套流程，还提供免装客户端的网页版，连法见 [手机与电脑互传文件.md](手机与电脑互传文件.md)。

## 三、判断标准其实就四条

1. **平台对得上吗**——系统方案快的前提是两端在同一个生态里，跨生态时第三方应用才有意义；
2. **文件多大**——聊天工具对大文件与图片有限制，点对点工具没有（SHAREit 官方口径无单文件大小上限）；
3. **在意广告吗**——系统方案无广告；SHAREit 安卓版有广告与内购，细节见 [广告与隐私权限说明.md](广告与隐私权限说明.md)；
4. **要不要找历史记录**——SHAREit 有传输历史和固定的接收目录，翻旧文件方便；系统方案通常传完即散。

换手机这种一次搬几十 GB 的场景，还要考虑迁移深度：厂商自带的换机工具对自家应用数据的迁移通常比第三方应用做得深，选择思路见 [换新手机迁移资料.md](换新手机迁移资料.md)。
