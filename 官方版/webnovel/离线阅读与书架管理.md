## 一、书架（Library）：追更的中枢

在读的书籍点「Add to Library / 加入书架」，之后：

- 书架页按更新时间排列，有新章的书会标红点。
- 长按书封可以移出书架、置顶。
- 书架云端同步——换设备登录同一账号即可恢复（注册方式见 [账号注册与登录方式.md](账号注册与登录方式.md)）。

追更超过十几本的话，建议把不更新的完本书移出书架，只留连载中的，红点提示才有意义。

另外，书架不止在手机里：电脑浏览器打开 [WebNovel 官方网站](https://www.webnovel.com/) 登录同一账号，书架和阅读进度直接接着用——手机不在身边或没电时，用电脑把最新章追完。

## 二、章节下载：离线阅读

通勤、飞行模式或网络不稳时的用法：

1. 打开书籍目录页，点右上角的下载图标；或在阅读界面菜单里选「Download」。
2. 选择下载范围（最近几章 / 自定义区间），确认后开始缓存。
3. 缓存完成的章节在无网络时也能从书架直接打开。

注意两点：

- **已解锁的付费章节**才能缓存离线；未解锁的章节离线包里不会有，回到有网环境解锁后再下（解锁机制见 [金币与免费解锁章节.md](金币与免费解锁章节.md)）。
- 缓存占用的是本地存储，文字章节占不了多少，缓存漫画时体积会明显变大；空间紧张时在「设置 → 清理缓存」里清掉已读章节，不影响云端阅读进度。

## 三、阅读界面值得先调的设置

阅读时长按屏幕中央（或点阅读页中间）呼出菜单，这几项对长篇追更影响最大：

| 设置 | 建议 |
| --- | --- |
| 字号与字体 | 先调字号，长篇阅读 18pt 以上更省眼 |
| 背景色 | 深色界面夜间用，米黄底白天用 |
| 翻页方式 | 左右滑动 / 上下滚动，滚动模式适合网文长章 |
| 亮度 | 独立调节，不改系统亮度 |
| 自动滚屏 | 解放双手，速度可调，适合快节奏扫文 |

设置是全局记忆的，调一次对书架里所有书生效。

## 四、书单：别人整理好的合集

WebNovel 有用户自建的书单（Reading List / Booklist）功能：一份书单按题材、梗、完结状态归拢几十本书，首页或书籍详情页能看到别人的书单。找新书时按书单批量浏览比关键词搜索效率高，看中的书直接逐本加入自己的书架。自己整理的口味合集也可以建书单发布，写书的人常用它给新作导流。

## 五、更新提醒

- 应用内：书架红点 + 推送通知，推送开关在系统设置的应用通知权限里。
- 想知道某本书的更新规律（日更 / 周更 / 断更），看书籍详情页作者声明的更新表（Update Schedule），比等红点可靠。
- 断更很久的书别急着加书架，先看最近一章的时间再决定。

书架整理好了、离线也设好了，剩下的就是挑书和追更。如果读着读着想自己下场写，从 [作者写书与投稿流程.md](作者写书与投稿流程.md) 开始。
