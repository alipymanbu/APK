## 一、先分清免费和付费

WebNovel 采用免费 + 付费混合模式。每本书开头若干章免费，往后进入付费区，目录里带锁图标的章节就是付费章节。付费不等于必须花钱——平台给了两条不充值的路：签到拿 Fast Pass、等平台活动，先把机制看懂再决定花不花。

## 二、Coins：充值解锁

Coins 是充值获得的付费货币，用来解锁付费章节。要点：

- **解锁后永久可读**，已解锁章节记在账号下，换设备登录同账号仍在。
- **按章计费**，单章价格与章节字数挂钩，每章解锁前界面会标明本章需要的 Coins 数。
- **充值走应用商店的支付渠道**（Google Play 或 App Store 的账号支付），档位与单价以应用内「Top-up / 充值」页面当时显示为准。
- Coins 充进账号后不会过期，但**已充值的余额与已解锁章节一般不支持退款**，先少量充值试一章，确认阅读体验再加量。

## 三、Fast Pass：不花钱的解锁券

Fast Pass 是免费获得的临时解锁券，主要来源：

1. **每日签到**：连续登录领取，连签天数越多给得越多。
2. **应用内任务与限时活动**：看活动页面，任务形式会换。
3. **平台不定期发放**：版本活动、节日活动时会送。

使用时注意两条限制：

- Fast Pass **有有效期**，拿到后尽快用掉，攒着容易过期。
- 部分**特殊章节（如 Privilege 提前章）不能用它**，解锁按钮上会标明可用范围，以应用内说明为准。

## 四、Power Stones：免费投票票

Power Stones 是每天按账号等级发放的投票票，投给你在追的书，影响作品在排行榜上的名次与曝光。它不能当解锁券用，但追的书排名上去了更新和活动反而更勤，每天顺手投掉即可，过期作废。

## 五、怎么选：一张判断表

| 你的情况 | 建议 |
| --- | --- |
| 只是试试有没有想读的书 | 只读免费章节，先不碰解锁 |
| 每天追一本，量不大 | 靠每日签到攒 Fast Pass，基本够用 |
| 同时追多本、还要看老书 | 充少量 Coins，付费章节配合 Fast Pass |
| 想比连载进度提前看 | 这是 Privilege 提前章的范围，需要 Coins，按需选 |

## 六、扣费与记录查询

- 充值记录、Coins 余额在「我 → 钱包 / Wallet」里查；每笔解锁记录（哪一章、花了多少）也在同一处。
- 解锁卡住、扣了 Coins 章节没打开，先退出书籍详情页重新进，再核对钱包记录里这笔是否成功；确认扣了但章节打不开，走应用内 Help / Feedback 提交订单信息找客服。
- 家里有小孩共用手机的话，建议在 Google Play / App Store 里关掉应用内购买免密支付，充值页每次都要手动确认。
