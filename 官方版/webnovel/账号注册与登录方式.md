## 一、不登录能用什么

游客状态可以直接浏览和阅读免费章节，也能试读付费章节的开头。但下面这些必须登录后才可用：

| 功能 | 是否需要账号 |
| --- | --- |
| 读免费章节 | 不需要 |
| 加书架、追更提醒 | 需要 |
| 每日签到领 Fast Pass | 需要 |
| 评论、评分、投票 Power Stones | 需要 |
| 付费章节解锁记录、已购章节跨设备同步 | 需要 |

只是先看看有没有想读的书，可以先不注册；确定要长期追更，再注册不迟。

## 二、注册方式

WebNovel 支持的登录入口（以应用内「我 → 登录」页面实际显示为准）：

1. **Google 账号一键登录**：手机上登录了 Google 服务时最省事，点一下就完成，不用记密码。
2. **Facebook 登录**：有 Facebook 账号的话同样是一键授权。
3. **邮箱注册**：填邮箱、设密码、收验证码完成验证。没有 Google / Facebook 账号，或手机没法访问这两家服务时用这条路。

注册过程中不要求绑定手机号，邮箱验证通过即可。注册成功后账号自动在书架、阅读记录、已解锁章节之间通用——应用和官网网页版登录同一个账号，数据也是同步的。

选哪种：图省事选 Google / Facebook 一键登录；**打算长期用、或准备在上面写书的话，官方教程更推荐邮箱注册**——忘记密码或换设备登录网页版时，邮箱是找回成本最低的方式。

## 三、验证码收不到怎么办

邮箱注册时验证邮件偶尔会延迟或被拦截，按顺序试：

1. 等一到两分钟再点一次「重新发送」，连续点反而会触发频率限制。
2. 查邮箱的**垃圾邮件 / 广告**文件夹，搜发件人关键字 `webnovel`。
3. 把域名加入邮箱白名单后重发一次。
4. 还不行就换一个邮箱（Gmail、Outlook 成功率高一些），或先用 Google / Facebook 方式登录，进应用后再在设置里补充邮箱。

## 四、换设备与找回进度

- **阅读进度、书架、已解锁章节**都挂在账号上，换手机后下载应用、登录同一账号即可恢复，不需要手动迁移任何文件。
- 下载到本地的离线章节不会跨设备转移，新设备上要重新点一次下载，见 [离线阅读与书架管理.md](离线阅读与书架管理.md)。
- 用第三方账号（Google / Facebook）登录的人，换设备后也用同一第三方账号登录，**不要**另注册一个邮箱账号——两个账号的数据互不相通。
- 忘记密码：在登录页点「忘记密码」，用注册邮箱收重置邮件；第三方登录的账号没有独立密码，不需要这一步。

## 五、注销与账号安全

- **注销没有一键入口**：有用户反馈，想彻底删掉账号需要通过应用内 Help / Feedback 或客服邮箱提交申请并说明原因，等客服处理（以客服答复为准）。
- 注销前想清楚：**Coins 余额和已解锁章节会一并作废**，充值追更的账号注销前先权衡。
- 账号安全的最低配置：邮箱注册的绑定一个常用邮箱；第三方登录的确保 Google / Facebook 账号本身开了二次验证——WebNovel 侧的密码再复杂，也挡不住上游账号被盗。

## 六、登录后建议先做的两件事

1. **在设置里确认阅读语言偏好**，首页推荐会按这个过滤，不然推荐列表里会混进你看不懂的语种。
2. **把每日签到打开**。签到送的 Fast Pass 能免费解锁部分付费章节，长期追更等于每天省一章的钱，具体规则见 [金币与免费解锁章节.md](金币与免费解锁章节.md)。
