## 一、先确认你要的是哪个 WebNovel

WebNovel（起点国际）是阅文集团 2017 年 5 月上线的海外网络文学平台，主要面向海外读者，内容是英译为主的中文网文（如《诡秘之主》《全职高手》）加上各国作者写的原创英文小说，另有漫画板块。它和国内的起点读书是两个独立应用：**包名不同、账号不通、内容不通用**。想确认手里的安装包对不对，认包名 `com.qidian.Int.reader`，开发者是 Cloudary（阅文海外主体）。

本文讲的是 Android 手机版。其它平台的获取方式：

| 平台 | 获取方式 |
| --- | --- |
| Android 手机 / 平板 | Google Play 商店，或本文的本地安装包 |
| iPhone / iPad | App Store 搜 `WebNovel` |
| 电脑浏览器 | 直接打开 [WebNovel 官方网站](https://www.webnovel.com/) 阅读，无需安装 |

这份安装包采集时记录的系统要求是安卓 5.2 及以上；低于该版本的设备装上也大概率无法正常运行，先确认系统版本再动手。

## 二、安装包从哪拿

两条路，按你的情况选：

1. **Google Play 商店**（官方渠道，能自动更新）：在应用里搜 `WebNovel`，或直接打开 `https://play.google.com/store/apps/details?id=com.qidian.Int.reader`，认准开发者 Cloudary。
2. **手机没装 Google Play、或想要固定版本时用本地安装包**：从 [WebNovel 安装文件资源（夸克网盘）](https://pan.quark.cn/s/feb3d515e6f9) 转存安装包，传到手机上安装。这份包是固定版本快照，关键信息如下：

   | 项目 | 值 |
   | --- | --- |
   | 版本 | 8.17.1 |
   | 包名 | com.qidian.Int.reader |
   | 大小 | 80.12M |
   | MD5 | `4B1D3097D1BDA95838102413FEA93255` |
   | 整理时间 | 2026-09-27 |

装之前可以先核对完整性：用文件管理器或电脑算出的 MD5 与 `4B1D3097D1BDA95838102413FEA93255` 对不上，说明下载中途损坏了，重新转存一次再装。

## 三、商店里搜不到的常见原因

Play 商店里搜 `webnovel` 出不来安装按钮，先排查这三条：

1. **拼写**：官方名是 WebNovel 两个词连写，搜 `web novel`（带空格）或直接用上面第 2 条里的商店链接直达，比在搜索框里较劲快。
2. **系统版本不够**：设备 Android 版本低于应用要求时，商店页会隐藏安装按钮或提示「不兼容」——这不是搜索问题，升级系统或改用旧版本安装包也救不了所有机型，先确认系统。
3. **搜到了广告位**：搜索结果顶部的推广位常是同类阅读应用，认准包名 `com.qidian.Int.reader` 和开发者 Cloudary 再装，别点到换皮应用。

## 四、安装步骤（Android 侧载）

1. 把 APK 文件传到手机（数据线、聊天工具的文件传输、浏览器下载都行）。
2. 用手机的「文件管理」点开这个 `.apk`。
3. 系统弹出「禁止安装来自此来源的应用」——这是 Android 对非商店应用的默认拦截。到 **设置 → 安全 / 应用管理 → 允许安装未知来源应用** 里，对刚才用来打开 APK 的那个应用（文件管理器或浏览器）放行，各品牌菜单路径略有差异。
4. 回到安装界面点「安装」，装完直接打开。

两种常见报错的处理：

- **「解析错误」**：多半是系统版本低于要求，或 APK 下载不完整（回上一步重新核对 MD5）。
- **「已存在同名应用且版本更高」**：手机里已经装过更新的 WebNovel，直接用原来那个就行，不必用旧包覆盖。

## 五、第一次打开：三件事

1. **选界面语言**。应用默认英文，首次启动通常会让你选阅读语言与界面语言，选好以后在「我 → Settings → Language」里也能改。
2. **不登录也能读**。免费章节游客状态就能看；但每日签到、评论、书架云端同步这些功能需要账号，注册方式见 [账号注册与登录方式.md](账号注册与登录方式.md)。
3. **认识免费与付费的边界**。大部分作品开头若干章免费，往后的付费章节带锁标，解锁机制见 [金币与免费解锁章节.md](金币与免费解锁章节.md)，先看清再决定追哪本。

装完如果连不上或加载不出内容，先检查网络能否正常访问海外站点，再试官方网页版验证是不是应用本身的问题。
