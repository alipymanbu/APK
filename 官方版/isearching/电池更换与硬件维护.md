## 一、先判断是不是电池的问题

防丢器的电池是 CR2032 纽扣电池（也写作 CR2032 210mAh），超市、便利店、电商都有卖，不用找专用型号。典型症状对号入座：

| 症状 | 大概率原因 |
| --- | --- |
| 长按按钮没有任何声音 | 电池耗尽 |
| App 里显示在线但按了不响、距离明显变短 | 电量偏低 |
| 时连时断、报警声变弱 | 电量偏低 |

App 里通常有低电量提醒，弹了就尽快换，别等到彻底没电——没电的防丢器断连时不会报警，防丢功能等于停摆。续航一般能撑几个月（有的批次标称六个月上下），提醒频率、报警次数多都会更耗电，以实际为准。

## 二、换电池的步骤

1. **找到开口位置**：外壳沿按钮一侧或边缘的接缝处有可撬的口，用指甲或薄的硬卡片沿缝掰开，不要用金属刀硬撬。
2. **取下旧电池**：记住电池哪面朝上。装反了不通电，白忙一场——装之前对着壳内标好的正负极符号再核一遍。
3. **装入新电池**：正负极按壳内标识放，扣紧。
4. **合上外壳**：四边按压实，有异响说明没扣严。
5. **重新开机并连接**：长按按钮 3 秒听到两声短哔；然后到 App 里点该设备的「连接」重连即可，一般不需要删除后重新添加。连不上的话按[与防丢器配对教程](与防丢器配对教程.md)第五节的顺序排查。

买电池时认准 CR2032；同直径但更薄的其他型号（如 CR2025）电压虽同、厚度不足，接触可能不良，不要买错。

装上新电池还是没反应：先核正负极方向，再看壳内触点有没有发黑氧化——用橡皮轻擦触点再装回，多数能救回来；还不行就是壳体或按键坏了。

## 三、日常维护清单

- **别放进水里洗**：这类防丢器一般没有防水承诺，挂件脏了擦外壳即可；挂在经常要洗的衣物上的用途（比如儿童书包水洗）要先把防丢器取下来。
- **长期不用先关机**：长按 5 秒听到长哔关机，能明显省电；重新用时再长按开机。
- **摔与挤压**：纽扣电池受挤压变形可能接触不良，外壳裂缝后进灰也会影响按压手感，坏了直接换新，不值得修。
- **冬天室外灵敏度下降**：低温对纽扣电池影响明显，挂车钥匙的用户冬天发现报警变弱，先回温再判断是不是没电。

## 四、出行乘机注意

CR2032 属于锂金属纽扣电池，坐飞机有单独的规定：按民航局的现行公告，锂电池不允许放进托运行李，含电池的设备建议随身登机，备用电池要单个做好防短路（贴胶带绝缘电极、放回原包装或单独塑料袋）且只能放手提行李。规定会随时间调整，出行前以民航局最新公告与所乘航司的要求为准。

## 五、硬件参数参考

以下参数来自厂商公开的说明材料，不同批次硬件略有差异，以你手头防丢器的说明书为准：

| 项目 | 参数 |
| --- | --- |
| 电池 | CR2032 纽扣电池 |
| 净重 | 约 26 g |
| 外形尺寸 | 直径约 32 mm、厚约 8.8 mm |
| 有效距离 | 约 15~30 米（空旷环境） |
| 通信方式 | 蓝牙 4.0 及以上（部分批次为蓝牙 5.0） |

连上硬件后的软件侧设置（报警距离、勿扰）在[双向报警与防丢设置](双向报警与防丢设置.md)；有硬件以外的异常去[常见问题与连接断开排查](常见问题与连接断开排查.md)。
