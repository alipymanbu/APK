## 一、症状对照表

| 症状 | 可能原因 | 处理 |
| --- | --- | --- |
| 添加设备时一直搜不到 | 安卓定位权限没给；防丢器没开机；距离太远 | 查权限（见[安装教程](下载与安装教程.md)第五节）；长按防丢器 3 秒确认两声短哔；靠近到 1 米内 |
| 显示「连接断开」，点连接也连不上 | 电池没电；被别的手机连着；蓝牙状态异常 | 换电池（见[电池更换](电池更换与硬件维护.md)）；断开另一部手机的连接；手机蓝牙关开一次 |
| 频繁断连、走两步就报警 | 手机省电策略杀了 App 后台 | 按第二节处理后台保活 |
| 手机黑屏一段时间后防丢器突然报警 | 同上——后台被系统回收后蓝牙连接断开，触发断连报警 | 同上 |
| 双击防丢器手机不响 | 当时连接已断或超出范围；部分版本同时只对一台设备双向管理 | 先在设备页确认在线状态；多台同用时优先保留最常用的那台 |
| 勿扰时段没生效，半夜被吵醒 | 时段设置没保存或版本缺陷 | 核对勿扰时段；睡前手动开全局勿扰最稳 |
| 报警距离忽远忽近 | 室内墙体、微波炉等干扰；电量低 | 换电池；按实际场景调距离而不是照抄数值 |
| App 里部分功能选项空白 | 旧版本缺陷，历史版本有过此类反馈 | 升级到当前版本；仍异常就反馈给开发商 |
| 一进商场、地铁、电梯就断连报警 | 人多干扰与信号屏蔽，多属正常现象 | 按场景调报警距离或用勿扰；距离预期见[有效距离与适用边界](有效距离与适用边界.md) |

## 二、频繁断连与误报警：后台保活

防丢器的断连报警依赖 App 在后台保持蓝牙连接。手机为了省电，会按自己的策略冻结或杀掉后台应用——App 一被杀，蓝牙连接就断，防丢器那边立刻报警，手机这边却什么提醒都收不到，就成了「莫名其妙一直响」。

处理办法（不同手机叫法不同，意思一样）：

1. 系统设置的电池/省电管理里，把 iSearching 设为**不受限制 / 无限制耗电**（或关闭该应用的电池优化）。
2. 最近任务里把 iSearching 锁定（下拉加锁），避免被一键清理清掉。
3. 手机自带的自启动管理里允许 iSearching 自启。
4. 关掉手机的整体省电模式测试一次，确认就是它引起的。

做完这些还断连的，再检查防丢器电量——电量低时蓝牙发射功率下降，本来就会缩短有效距离。

## 三、换手机或重装后怎么办

这类防丢器没有账号体系，绑定关系存在手机本地。换新手机或卸载重装后，直接在新装好的 App 里重新添加一遍设备即可，原来设的名称与图标需要重新设一次。旧手机上如果不再使用，把旧 App 里的设备条目删掉或卸载 App，免得它还在后台抢连接。

## 四、关于多设备与兼容硬件的补充

- **多台同用容易卡的反馈**：有用户反馈同时挂多台 iTag 时 App 会卡死、只能重装。如果你确实要挂多台，别把所有设备的断连报警都开到最高灵敏度，先从一两台用起。
- **同一批硬件换个 App 也能连**：有用户反馈同款 iTAG 硬件在其他同类应用（如 My iTags、Kindelf）里也能配对使用。这属于用户经验而非官方承诺，你的防丢器说明书认哪个 App 就先用哪个，不行再试。
- **想远距离找人、找宠物**：蓝牙防丢器超出范围后没有任何定位能力，这个需求要靠 GPS 类设备；能力边界与替代路线见[有效距离与适用边界](有效距离与适用边界.md)。
- **隐私口径**：按应用商店页面的标注，这款应用不收集用户数据、不与第三方共享；上架信息以商店页面当时显示为准。

## 五、什么情况下该放弃排查

长按无任何声音（换过新电池也一样）、外壳开裂进灰、按键手感消失——这些是硬件到寿命的表现，纽扣电池可以换，壳和按键坏了直接换新更省时间。软件侧该试的都试过还异常时，确认你的 App 版本（见[下载与安装教程](下载与安装教程.md)第二节），再决定是等更新还是换硬件。
