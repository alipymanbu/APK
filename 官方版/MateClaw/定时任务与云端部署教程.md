## 一、单次任务与定时任务的分界

上一篇[一句话下达任务教程](一句话下达任务教程.md)里的任务都是**一次性的**：发一次、跑一次、拿结果。但有一类需求天生要重复：

- 每天早上汇总一次新闻；
- 每隔几小时盯一次数据/库存；
- 每周固定时间生成一份周报。

这类需求在 MateClaw 里走**定时任务**：设定一次，之后按周期自动执行。判断标准很简单——**同一个任务你打算发第二遍，就该挂成定时任务**。

## 二、怎么创建定时任务

1. 首页输入框下方有**「定时任务」快捷项**（带时钟图标），点它进入定时任务的创建入口。
2. 在任务描述里写清要做什么——措辞规则与单次任务完全一样，参照[一句话下达任务教程](一句话下达任务教程.md)第三节的模板。
3. 设定**执行周期**。界面提供的周期选项以应用内实际为准；如果你要的频率界面上没有，先用最接近的档位，把频次要求写进任务描述里（比如选「每天」但描述里写「每 4 小时检查一次」是否生效，以实测为准——不确定的行为不要当成保证）。
4. 保存。到点后 MateClaw 自动执行，结果回到你的会话里。

**建议从一个任务挂起**：先手动跑通一次（确认任务描述能产出你要的结果），再把它挂成定时。手动都跑不顺的任务，定时只会每天准时地产出一份你不想要的东西。

## 三、定时任务跑起来之后在哪看结果

- 结果会回到应用内的会话/任务卡片里，与单次任务的呈现方式一致：状态、结论、附件；
- 你打开应用时能翻到历史执行记录；
- 执行失败或没产出的情况，处理见[常见问题与解决方法](常见问题与解决方法.md)。

一个使用上的现实约束：**手机端能不能收到即时推送，取决于系统通知权限与后台存活策略**（见常见问题第三节）。定时任务的执行在服务端持续进行，但你要「到点被提醒」，需要把系统通知权限给足。

## 四、「云端主机一键部署」是什么

应用里会出现「云端主机一键部署」相关的入口，界面上是一个**本机 → 云 → 智能体**的连接示意，状态文案为「正在连接 / 正在安装工作环境」，底部有分页点表示部署分多步进行。官方对它的口径是：**更快捷、更安全，减少本地环境依赖**。

对你来说实际意味着三点：

1. **执行环境在云端**：任务的跑动（写文件、处理数据、生成网页）发生在云端主机上，不吃你手机的性能与电量；
2. **外出也能推进**：出门、手机锁屏，已启动的任务照常在云端继续；
3. **结果仍交回手机**：文档附件照旧出现在会话卡片里，点开即存。

**什么时候需要点它**：首次使用某些需要执行环境的任务时，应用会引导你完成部署；状态停在「正在连接 / 正在安装工作环境」迟迟不动，是排查重点，见[常见问题与解决方法](常见问题与解决方法.md)。

## 五、云端部署 + 技能 + 定时的组合打法

三个模块串起来才是完整用法：

```
技能市场学技能 → 手动派单验证 → 挂成定时任务 → 云端持续执行 → 结果回会话
```

举一个可直接抄的组合：

1. 去[技能市场使用教程](技能市场使用教程.md)里学一个「新闻写作」或资讯汇总类技能；
2. 手动发一次「用该技能汇总今天的行业要闻，输出 Markdown」，确认结果合格；
3. 挂成每天早上的定时任务；
4. 第二天开始，每天在会话里收成品。

先跑通一条小链路，再往里加任务——一次挂十个定时任务，只会得到十份需要返工的结果。
