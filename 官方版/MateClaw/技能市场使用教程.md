## 一、技能是什么、什么时候需要它

MateClaw 内置了一个**官方验证的技能市场**，官网口径是 9224+ 个专业技能，覆盖内容创作、数据分析、效率提升、搜索办公这些方向。你可以把技能理解成「给智能体装的专门手艺」：没装之前它靠通用能力硬做，装了之后它按这套技能的流程做，结果更贴该领域的惯例。

**不是所有任务都需要技能**。闲聊、简单问答、通用写作直接派任务就行（见[一句话下达任务教程](一句话下达任务教程.md)）；下面这几类情况值得先来市场逛一圈：

- 任务有**行业套路**：公众号文章、新闻写作、小说连载这类，技能里带着成型的写作流水线；
- 任务要**调外部数据**：天气、航班动态（截图里能看到「飞常准航班信息查询」）、API 调用类技能；
- 你**反复派同一类活**：把对应技能学下来，之后每次派单都更顺。

## 二、市场界面怎么读

技能市场页面从上到下：

1. **标题行**：左边「技能市场」，右边「我的收藏」标签——收藏过的技能都在那。
2. **搜索框**：框内提示会显示当前技能总量（如「当前已更新 9224 种 AI 超能力」，数字随官方更新变化）。**找特定技能用搜索最快**，别翻列表。
3. **分类标签**：全部 / 内容创作 / 数据分析 / 效率提升 / 提效…（右侧可横滑，分类也在持续扩充）。按大类过滤后再搜，噪音最小。
4. **技能卡片列表**，每张卡片上有四样信息：

| 卡片元素 | 例子 | 说明 |
| --- | --- | --- |
| 技能名 | 公众号文章创作 | 这个技能干什么 |
| 一句话描述 | 公众号写作助手——专注公众号文章创… | 点开可看完整说明 |
| 安装量 | 12.3万 / 1.8千 | 官方统计的使用人数，可当热度参考 |
| 版本号 | V1.0.0 | 技能自身的版本，与应用版本无关 |
| 操作按钮 | 学习 | 点它 = 把技能装进你的 MateClaw |

## 三、「学习」按钮怎么用

操作只有一步：卡片右侧点**学习**。之后：

- 技能进入已学状态，你在对话里派相关任务时，MateClaw 会按这个技能的流程执行；
- 想确认装没装上，去「我的收藏」或技能详情页看状态（以应用内实际显示为准）；
- 技能有新版本时，卡片上的版本号会变，重新点一次学习即可更新。

**按需学，别一次全学。** 市场里近万个技能，绝大多数你用不到；学得越多，派任务时可选路径越多、也越容易挑花眼。推荐节奏：先带着你手头的任务来搜 → 学 1~2 个 → 用一周 → 再补。

## 四、学完之后怎么在任务里用

学过的技能不需要你在对话里手动点名——正常描述任务即可，MateClaw 会自己挑已学的技能来执行。但**在任务描述里点名技能名**能显著提高命中率，例如：

```text
用「公众号文章创作」技能，写一篇关于{主题}的公众号文章，800 字左右，配 3 个小标题。
```

```text
用航班信息查询技能，查一下明天北京到上海的航班动态。
```

任务出问题时（技能没被调用、结果格式不对），处理办法见[常见问题与解决方法](常见问题与解决方法.md)。

## 五、技能与定时任务的配合

技能配定时任务才能**自动重复执行**：比如「新闻写作」技能配一个每天早上 9 点的定时任务，之后每天不用你动手就有新一版成品。这条链路的另一半在[定时任务与云端部署教程](定时任务与云端部署教程.md)，两篇配合着看。
