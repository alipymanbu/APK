## 一、这是个什么应用

MateClaw 是一款安卓端的 AI 智能体应用：你在手机上把任务交给它，执行过程发生在云端环境，做完你会在会话里收到结果（表格、文档、网页文件等）。官方入口是 [www.mateclawapp.com](http://www.mateclawapp.com)，官方联系邮箱 `support@mateclawapp.com`。

本篇只解决一件事：把安装文件弄到手机上并装好。装好之后怎么用，看[一句话下达任务教程](一句话下达任务教程.md)。

## 二、先核对版本信息

下面这组数字是**当前这份安装包的事实**，下载后可以逐项核对，避免装错包：

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.5.0 |
| 包名 | `com.eylktot.anplki` |
| 安装包大小 | 93.75M |
| MD5 | `195FD288239A34D69FB782D5894659E5` |
| 系统要求 | 安卓 5.2 及以上 |

两点提醒：

- 官网后续可能发布更新的版本，**上表以网盘里这份为准**；两者不是同一份时，以你想装的那份为准。
- 包名是应用在系统里的唯一身份。装完想确认装对没有，可以在系统「应用信息」里看包名是不是 `com.eylktot.anplki`。

## 三、从网盘拿到安装文件

1. 打开 [MateClaw 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0d22690b377a)，把分享内容**转存到自己的网盘**（不转存没法长期保存）。
2. 转存后在自己网盘里找到安装包文件，文件名为 `MateClaw_v1.5.0.apk`，所在文件夹叫 `MateClaw（先保存再下载）`。
3. 在手机上打开夸克，进到该文件夹，点这个 apk → 选「下载」或直接「安装到本机」，取决于夸克客户端的版本，界面文字略有差别。

> 提示：文件夹里通常还有一份 `先保存再下载避免失效.txt`，那是给网盘收藏用的说明，不用管它。

## 四、安装到手机

安卓对 apk 有统一的安装流程，卡点几乎都在「允许安装未知来源应用」这一步：

1. 如果是先把 apk 下到手机本地再点开安装，系统会弹「不允许安装来自此来源的应用」——这是**系统级拦截，不是应用有问题**。按提示进入「设置 → 允许来自此来源的应用」，给你的浏览器或文件管理器开这个权限，返回后继续安装。
2. 部分机型（小米、OPPO、vivo、华为等）还会多一层「风险应用」提示，点「仍要安装 / 继续安装」即可。
3. 装完打开，首次启动会申请网络等常规权限，正常放行即可。

如果你是从夸克 App 里直接选「安装到本机」，第 1 步的授权对象就是夸克本身，流程一样。

## 五、装完先做两个检查

1. **版本核对**：系统「应用信息 → MateClaw」里看版本号是否为 1.5.0。
2. **能不能跑起来**：打开应用，能进到首页（有输入框和任务入口）就算装成功；一直白屏或闪退，转到[常见问题与解决方法](常见问题与解决方法.md)按步骤排查。

安装包校验不是必须步骤，但如果你想确认文件完整（比如下载中途断过），可以在电脑上用命令核对 MD5：

```powershell
# Windows PowerShell
Get-FileHash .\MateClaw_v1.5.0.apk -Algorithm MD5
```

输出的哈希值应当等于 `195FD288239A34D69FB782D5894659E5`（不区分大小写）；对不上说明文件不完整，回网盘重新下载。

## 六、老版本怎么升级

同包名覆盖安装即可：用新版本的 apk 直接安装，系统会当作升级，聊天记录与已学技能按应用自身逻辑保留。换包名的版本不存在——MateClaw 的包名始终是 `com.eylktot.anplki`，如果装出来是别的包名，说明那份文件不是这个应用。
