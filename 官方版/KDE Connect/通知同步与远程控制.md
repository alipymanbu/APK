# KDE Connect 通知同步与远程控制功能

> 手机通知显示到电脑、在电脑上回短信、用手机遥控电脑播放与演示，这些「不碰手机也能办事」的能力都在这一篇。

通知同步是最多人留下的理由：手机在抽屉里充电，消息来了电脑上直接看、必要时直接回，不用反复解锁手机。这一篇把通知类与遥控类的功能一次说清。

## 一、手机通知出现在电脑上

前提是手机端的**通知使用权**已经授予（见 [配对连接与权限设置.md](配对连接与权限设置.md)）。之后手机上弹什么通知，电脑桌面就弹什么，电脑上还能直接关掉这条通知。

按应用过滤：在手机端应用里可以逐个应用开关「发送通知」，把微信、邮件这类你关心的开着，广告与垃圾推送关掉，电脑上就清净了。

**Android 15 的一个坑**：新系统默认把「敏感通知」（多为验证码、聊天预览）对第三方隐藏，表现为别的通知都同步，唯独验证码只显示「隐藏内容」。两个处理办法：

1. 系统设置里找到通知相关的「增强通知 / 增强型通知」开关关掉（机型叫法不一，搜「增强通知」）；
2. 或用电脑连手机执行一条 adb 命令给授权：

```bash
adb shell cmd appops set org.kde.kdeconnect_tp RECEIVE_SENSITIVE_NOTIFICATIONS allow
```

## 二、在电脑上收发短信

给了短信权限后，电脑端能读取手机上的短信会话，用键盘直接回复。要注意它只覆盖**短信**；微信、QQ 这类应用内消息不走系统短信通道，电脑上看不到，能看到的只是它们弹出的通知文本。在 Windows 上如果你更看重通话与手机应用投屏，也可以考虑微软自带的「手机连接」，两者取舍见 [与微软手机连接怎么选.md](与微软手机连接怎么选.md)。

## 三、手机变遥控器

- **媒体控制**：电脑上放音乐或视频，手机端显示当前曲目与播放进度，暂停、切歌、调音量都在手机上点；浏览器里放的视频同样可控。
- **虚拟触控板与键盘**：设备详情里打开「远程输入」，手机屏幕变成电脑的触控板，滑动即移动鼠标，手机键盘打字直接进电脑，躺着用电脑时很省事。
- **演示翻页**：接上虚拟输入后，音量键或屏幕按钮可以当翻页笔用，投影时手机就是遥控器。

## 四、几个顺手的小功能

- **找手机**：电脑端点「找手机」，手机立刻响铃，静音状态也照响，塞在沙发缝里时靠它；反过来手机上也能让电脑响铃。
- **电量显示**：手机电量直接显示在电脑端设备信息里，不用拿手机就知道要不要充电。
- **自定义命令**：在电脑端配置命令（如锁屏、休眠、关机），手机端一键触发；下班锁屏这种动作不用再起身。命令内容你自己定，官方文档给了常用示例。
- **来电暂停**：手机来电话时，电脑上正在放的音乐自动暂停，挂断后继续。

## 五、通知不同步时先看这两处

绝大多数「通知不来了」都是两个原因：通知使用权被系统收回（升级系统后尤其常见），或手机后台被省电策略清掉。逐项核对 [配对连接与权限设置.md](配对连接与权限设置.md) 的权限表，再按 [常见问题排查.md](常见问题排查.md) 处理后台保活，基本都能解决。
