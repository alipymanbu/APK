# KDE Connect 手机端后台被杀的保活设置

> 配对成功过一会儿就断、通知时有时无，几乎都是厂商省电机制把后台清掉了：本篇按品牌给出保活路径，设完能长期稳定在线。
> **相关文档**：[常见问题排查.md](常见问题排查.md) · [配对连接与权限设置.md](配对连接与权限设置.md)

KDE Connect 的手机端要在后台常驻，才能随时收发通知与文件。而国产手机系统普遍在这件事上格外激进： Android 自带的省电之外，厂商又叠了一层甚至几层后台清理，应用没被你打开就可能被悄悄结束。所以保活不是某个开关的事，要按下面几层逐个关掉对你的限制。

## 一、通用两步（所有手机都先做）

1. **电池优化改为不限制**：系统设置 → 应用 → KDE Connect → 电池（或「耗电管理」），选「无限制 / 不优化」；
2. **最近任务里上锁**：打开最近任务（多任务）视图，找到 KDE Connect 的卡片，下拉卡片直到出现锁图标——上锁的应用不会被一键清理波及。

做完这两步，多数原生系手机（Pixel、Moto 之类）就够了；国产系统还要看下一节。

## 二、各品牌的额外设置

同一种设置在不同系统版本里的叫法与位置差异很大，**找不到就按关键词在设置里搜**，以下路径供对照（截至 2026-09）：

**小米 / 红米（MIUI、澎湃 OS）**

- 手机管家（安全中心）→ 权限 → **自启动**：给 KDE Connect 打开；
- 设置 → 省电与电池 → 应用智能省电 → KDE Connect → **无限制**；
- 省电与电池 → 右上角齿轮 → **睡眠待机优化**：对 KDE Connect 关闭（夜间断连多半是它）；
- 注意：小米的系统更新或重启后，这类设置**可能被重置**，重新断连时先回来检查这几处。

**华为 / 荣耀（EMUI、HarmonyOS）**

- 设置 → 应用 → 应用启动管理 → KDE Connect → 关掉「自动管理」，手动管理里把**自启动、关联启动、后台活动**三项全部允许。

**OPPO / 一加 / realme（ColorOS）**

- 手机管家 → 权限与隐私 → **自启动管理**：给 KDE Connect 打开；
- 设置 → 电池 → 更多设置（或应用耗电管理）→ KDE Connect → **允许完全后台行为 / 不优化**。

**vivo / iQOO（OriginOS、Funtouch）**

- i 管家（或设置 → 应用）→ 权限 → **自启动**：打开；
- 设置 → 电池 → **后台高耗电**：允许 KDE Connect。

**三星（One UI）**

- 设置 → 电池 → **后台使用限制**：确认 KDE Connect 不在「睡眠中应用」名单里，需要时放进「永不睡眠」的应用列表；
- 设置 → 应用 → KDE Connect → 电池 → **无限制**。

## 三、别忽略通知渠道本身

系统设置 → 通知 → 应用通知 → KDE Connect：总开关与里面的各通知渠道（常驻状态、设备通知等）都不要被单独静音。常驻通知被关有两个后果——你看不到它是否活着，还会失去通知栏上「发送剪贴板」那个按钮的入口。

## 四、设完怎么验证

锁屏放着 5~10 分钟，然后从电脑端传个文件或点一次「找手机」：

- 能立刻响应 → 保活生效；
- 只有解锁手机后才响应 → 还是有一层在杀，重点复查「睡眠待机优化 / 后台高耗电」这类夜间机制；
- 彻底无响应、列表变灰 → 先按 [常见问题排查.md](常见问题排查.md) 查网络（VPN、路由器隔离、防火墙端口），网络通着却断连才继续调保活。

权限层面缺了哪块，对照 [配对连接与权限设置.md](配对连接与权限设置.md) 的权限表补齐。
