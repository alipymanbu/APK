# KDE Connect 手机与电脑配对教程

> 两端装好后，配对只需一次：本篇讲怎么让手机和电脑互相找到对方、怎么把该给的权限给齐，以及配对后按需开关各功能。

KDE Connect 的配对没有账号、没有扫码，只要两台设备在同一个局域网里，任何一侧发起请求、另一侧点确认就完成。配对完成后，具体功能能不能用，还取决于手机端权限给没给齐，本篇一并说清。

## 一、配对前先检查这三件事

1. **同一网络**：手机连 Wi-Fi、电脑连同一个 Wi-Fi（或电脑用网线插在同一台路由器上）都可以；手机开着流量、或手机和电脑连了不同的路由器，互相看不见。
2. **两端应用都开着**：手机端打开 KDE Connect 的主界面，电脑端打开客户端（Windows 上是托盘图标 + 主窗口）。主功能靠后台常驻，但第一次配对时最好两边都停在界面上。
3. **中间没有隔离**：先不开 VPN；别用访客 Wi-Fi；公司或学校的网络经常开了「设备隔离」，这种网络下设备互相不可见，回家再配。

检查完仍搜不到对方，直接翻 [常见问题排查.md](常见问题排查.md) 的防火墙一节。

## 二、配对步骤（哪边发起都行）

**从手机发起**：

1. 打开手机端，设备列表里会出现你的电脑名（未配对设备显示为「未配对」状态）；
2. 点电脑名，选「请求配对」；
3. 电脑上弹出确认提示，点接受，两边立刻显示已连接。

**从电脑发起**：

1. 打开电脑端窗口，未配对的手机会出现在设备列表里；
2. 点手机名，点「配对」；
3. 手机上收到请求通知，点接受。

接受之后就长期生效：以后两台设备一进同一个网络就自动连上，不用重复配对。

## 三、搜不到对方时的兜底：按 IP 添加

自动发现依赖局域网广播，个别路由器或网络环境会拦广播。这时可以手动加：

- 手机端：右上角菜单里的「添加新设备」，按提示填电脑的 IP；
- 电脑端：设备列表里的「按名称或 IP 添加设备」，填手机的 IP。

查 IP：手机在 Wi-Fi 详情页看「IP 地址」；Windows 电脑在命令提示符里运行 `ipconfig`，找「IPv4 地址」。

## 四、权限授予（Android 端，必做）

配对成功不代表功能就绪。Android 系统要求每类能力单独授权，缺哪个，对应功能就哑哪块。打开手机端应用，点进已配对的电脑，里面会把缺的权限一项项列出来，逐个去开；也可以从系统「设置 → 应用 → KDE Connect → 权限」进。

| 权限 | 管什么 | 不给会怎样 |
| --- | --- | --- |
| 通知使用权 | 手机通知同步到电脑 | 电脑上看不到任何手机通知 |
| 存储 / 所有文件 | 收发文件 | 传文件发不出或收不到 |
| 短信 | 在电脑上读、回短信 | 桌面短信功能不可用 |
| 通话记录 | 桌面上显示来电 | 来电信息不同步 |
| 辅助功能 | 用电脑的鼠标键盘控制手机 | 只在你确实要用这个功能时才需要 |

每一项权限对应什么、要不要给，应用内都有说明，按你的使用需求决定即可。通知权限默认是关闭状态，这是最常见的一个「配对了但没反应」的原因。

## 五、配对后：按需开关各功能

配对好的设备点进去，是一个插件（功能）列表，每个能力一个开关：剪贴板同步、通知同步、媒体控制、远程输入、文件收发、找手机等。建议这样处理：

- 用不到的（比如短信同步）直接关掉，少一条常驻通道；
- 开关改动即时生效，不用重连。

各功能具体怎么用，看 [文件传输与剪贴板同步.md](文件传输与剪贴板同步.md) 和 [通知同步与远程控制.md](通知同步与远程控制.md)。

## 六、多台设备同时用

配对不是一对一：一台电脑可以同时配好几台手机，一台手机也可以同时配家里和公司两台电脑，每对关系各自独立、互不干扰。设备多了以后，给每台设备起个备注名（见下一节）再按需关掉用不到的插件，列表才清爽。

## 七、改设备名与解除配对

- **改名字**：在设备详情里可以给对方设备起个备注名（比如「书房台式机」）；电脑端也能改自己的显示名，改名后不影响配对关系。
- **解除配对**：设备详情里选「解除配对」，两边都回到未配对状态。换手机、重装系统前解除一次，避免列表里留下一堆灰色的旧设备。
