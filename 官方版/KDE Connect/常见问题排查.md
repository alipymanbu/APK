# KDE Connect 常见问题排查

> 搜不到设备、连上就断、通知不响、传文件失败——这类问题九成出在网络隔离、防火墙端口或手机后台保活上，按本篇顺序排一遍基本都能定位。

排查原则：先确认「两台设备能不能互相看见」，再确认「权限给没给齐」，最后才怀疑应用本身。逐节往下对。

## 一、互相搜不到设备

按命中率从高到低逐项检查：

1. **不同网络**：手机用了流量、或连到了隔壁路由器；家里有主路由 + 子路由的，确认两端真的在同一网段。
2. **VPN 开着**：VPN 会把流量整个带走，两端自动发现直接失效，先断开再试。
3. **路由器隔离**：访客 Wi-Fi、公司网络常默认开「AP 隔离 / 客户端隔离」，同网设备互不可见；家用路由进管理后台把它关掉，公司网络则只能回家配。
4. **电脑防火墙没放行**：KDE Connect 用 **1714–1764** 这一段 TCP 和 UDP 端口通信，Windows 安装时首次弹的防火墙询问如果点了拒绝，就会出现这种状态。手动放行：Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙 → 找到 KDE Connect，专用与公用都勾上。
5. **Linux 防火墙**：按你用的防火墙工具执行对应命令：

```bash
# ufw
sudo ufw allow 1714:1764/tcp
sudo ufw allow 1714:1764/udp
sudo ufw reload

# firewalld
sudo firewall-cmd --permanent --zone=public --add-service=kdeconnect
sudo firewall-cmd --reload
```

6. **兜底：按 IP 添加**。跳过自动发现直接手动连，操作见 [配对连接与权限设置.md](配对连接与权限设置.md) 第三节。

## 二、搜得到、连不稳、动不动断开

这类几乎都是手机端后台被清理。先做通用的两步——把电池优化改为「无限制」、在最近任务里给 KDE Connect 上锁；小米、华为、OPPO、vivo、三星各家的额外开关（自启动、睡眠待机优化、后台高耗电等）逐项路径整理在 [国产手机后台保活设置.md](国产手机后台保活设置.md)。除此之外再查两处：

- **Wi-Fi 休眠**：部分手机息屏后 Wi-Fi 进入省电，在 Wi-Fi 高级设置里把「休眠时保持网络连接」改为始终；
- **电脑端**：睡眠状态自然连不上，想远程唤醒的话不在 KDE Connect 的能力范围内。

保活做好后，只要两端进了同一网络就会自动重连，不用手动操作。

## 三、连着，但某个功能没反应

| 现象 | 先查这里 |
| --- | --- |
| 电脑收不到手机通知 | 手机端「通知使用权」是否被系统收回（系统升级后常见），重新授予 |
| 通知里验证码显示「隐藏内容」 | Android 15 敏感通知限制，处理办法见 [通知同步与远程控制.md](通知同步与远程控制.md) |
| 手机复制的文字电脑粘不出来 | Android 10+ 的剪贴板限制，需手动「发送剪贴板」，见 [文件传输与剪贴板同步.md](文件传输与剪贴板同步.md) |
| 传文件失败或列表空白 | 手机端存储 / 所有文件权限 |
| 桌面短信功能不可用 | 手机端短信权限 |
| 用电脑控制手机没反应 | 手机端辅助功能权限，且需在系统无障碍设置里显式启用服务 |

## 四、改了还是不行：重置重配

清掉两端的关系与缓存重新来一遍，多数疑难杂症到此为止：

1. 手机端：系统设置 → 应用 → KDE Connect → 清除数据（不是只清缓存）；
2. 电脑端（Linux）把配置目录挪走再重启服务：

```bash
killall kdeconnectd
mv ~/.config/kdeconnect ~/.config/kdeconnect.bak
```

3. Windows 端直接卸载重装一次，装的时候记得在防火墙弹窗里选「允许」；
4. 重新按 [配对连接与权限设置.md](配对连接与权限设置.md) 走一遍配对与授权。

## 五、还不行

去官方文档站确认是不是已知问题：<https://userbase.kde.org/KDEConnect>。你的版本较老时，先升级两端再看——手机端安装文件资源见 [下载与安装教程.md](下载与安装教程.md)。
