# KDE Connect 下载与安装教程

> 手机和电脑要各装一个端才能用起来：本篇讲两端分别从哪里拿安装包、怎么装，以及安装时值得留意的版本与来源问题。
> **相关文档**：[配对连接与权限设置.md](配对连接与权限设置.md) · [常见问题排查.md](常见问题排查.md)

---

> [!IMPORTANT]
> **KDE Connect 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/e211704b267c](https://pan.quark.cn/s/e211704b267c)

KDE Connect 是 KDE 社区维护的开源项目，用于在手机与电脑之间同步通知、互传文件、共享剪贴板等。它的全部通信都走你自己的局域网，不需要注册账号，也没有云端中转。想把它跑起来，前提是手机和电脑两边都装好应用，下面分端说明。

## 一、先弄清楚：要装两个端

| 端 | 适用系统 | 从哪里装 |
| --- | --- | --- |
| 手机端 | Android 6.0 及以上（以官方说明为准） | 本文顶部的安装文件资源，或 Google Play、F-Droid |
| 电脑端 | Windows 10/11、macOS、主流 Linux 发行版 | Microsoft Store、官网安装包、发行版软件仓库 |

只装手机端或只装电脑端，都完成不了配对。建议先用手机扫一眼网盘里那份 APK 的版本，再决定电脑端去哪下。

## 二、手机端（Android）安装步骤

1. 从 [KDE Connect 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e211704b267c) 转存后下载 APK，得到安装包；这份包为 1.34.4 版、约 8.01 MB，包名 `org.kde.kdeconnect_tp`，采集于 2026-09-24。
2. 手机上点开 APK。系统第一次会提示「未知来源应用」，按提示允许本次安装即可（路径因机型而异，一般在设置的开发者或安全选项里）。
3. 装完打开应用，先把基础的存储、通知等权限给上，配对流程见 [配对连接与权限设置.md](配对连接与权限设置.md)。

两点说明：

- 官方渠道的最新版号可能更高（官方 Android 端一直在更新），功能差异以官方发布说明为准；对「传文件、同步通知」这些主功能来说，1.34.x 与新版没有大的行为差别。
- 如果你习惯从应用商店装，Google Play 与 F-Droid 里都有官方包；F-Droid 的包与商店版签名不同，两者不要混装覆盖。

## 三、电脑端安装

### Windows

- 打开 Microsoft Store 搜「KDE Connect」安装；
- 或者到官网 [kdeconnect.kde.org](https://kdeconnect.kde.org/) 下载离线安装包（Store 版更新偶尔慢一拍，离线包拿新版本更快）；
- 习惯命令行的话用 winget 装也可以：

```powershell
winget install kde.kdeconnect
```

安装完成后首次启动，Windows 防火墙一般会弹窗询问是否允许访问网络，两个网络都勾上允许，否则后面手机搜不到电脑。

### macOS

到官网 [kdeconnect.kde.org](https://kdeconnect.kde.org/) 下载 dmg 安装。macOS 版功能比 Windows/Linux 少一些，通知同步、传文件这类主功能是可用的。

### Linux

大多数发行版的仓库里直接就有：

```bash
# Ubuntu / Debian
sudo apt install kdeconnect

# Fedora
sudo dnf install kdeconnect

# Arch / Manjaro
sudo pacman -S kdeconnect
```

仓库里没有或版本太旧，用 Flatpak：

```bash
flatpak install flathub org.kde.kdeconnect
```

另外，GNOME 桌面用户可以改用 GSConnect 扩展——它把 KDE Connect 的协议直接实现在 GNOME Shell 里，装完不用另起桌面客户端，与手机端 App 互相兼容。

## 四、装好之后做什么

两端都装好后，把它们连起来只需要一次配对，具体步骤与权限授予见 [配对连接与权限设置.md](配对连接与权限设置.md)。如果装完手机和电脑互相搜不到，多半卡在防火墙或网络隔离上，去 [常见问题排查.md](常见问题排查.md) 对照处理。
