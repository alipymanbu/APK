## 一、Splashtop 是什么，两端各装什么

Splashtop 是一款远程桌面软件：你在手机、平板或另一台电脑上，看到并操作被控电脑的完整桌面。安卓端应用叫 Splashtop Personal，官方定位是个人、非商业用途。

它的结构是「两端」，先分清你要装的是哪一头：

| 角色 | 装什么 | 在哪台设备上 |
| --- | --- | --- |
| 受控端 | Splashtop Streamer（串流器） | 被你远程操作的电脑（Windows / macOS） |
| 控制端 | Splashtop Personal 应用 | 你的安卓手机 / 平板（也可以是 iPhone、iPad 或另一台电脑） |

Streamer 只有 Windows 与 macOS 版；想被控的如果是 Linux 机器，Splashtop Personal 这条产品线装不了。两端必须登录同一个 Splashtop 账号，应用里才能看到对方。

## 三、受控端电脑：安装 Streamer

1. 在被控电脑上打开官方下载页 [www.splashtop.com/personal/downloads](https://www.splashtop.com/personal/downloads)；
2. 在「Personal Streamer」一栏选 Windows 或 macOS 版下载；
3. 运行安装程序，按向导完成安装；
4. 启动 Streamer，注册一个 Splashtop 账号（邮箱 + 密码）并登录，或直接登录已有账号。

系统要求：Windows 7 及以上（含 Server 版本）、macOS 10.13 及以上。Windows 安装过程可能弹权限确认，允许即可；Streamer 需要随系统启动保持在线，否则应用里这台电脑会显示离线。

## 四、控制端：安装安卓应用并登录

1. 从第二节拿到 APK 并安装（或走 Google Play）；
2. 打开 Splashtop Personal，用第三步注册的同一个账号登录；
3. 登录后应用会列出在线的被控电脑。

两端账号一致是整个流程里唯一必须对上的东西——连接时提示「没有可用电脑」，多半是这一步出了岔子。
