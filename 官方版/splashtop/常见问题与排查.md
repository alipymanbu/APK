## 一、应用列表里看不到电脑 / 显示离线

按出现概率排：

1. **电脑端 Streamer 没在跑**：重启 Streamer，确认设置里勾了随系统启动；
2. **账号不一致**：两端必须登录同一个 Splashtop 账号，邮箱错一个字母就是两个账号；
3. **电脑刚开机**：Streamer 启动联网后才会出现在列表里，等半分钟刷新。

这三条之外的场景（电脑在睡眠、防火墙拦了 443、Streamer 被登出），照 [电脑离线与服务器不可达排查.md](电脑离线与服务器不可达排查.md) 的完整清单过；应用提示连不上 Splashtop 服务器的也归那一篇管。

## 二、点连接没反应或提示失败

- **提示需要订阅**：你处在跨网环境，免费版只覆盖同一局域网，口径见 [局域网免费与跨网订阅.md](局域网免费与跨网订阅.md)；
- **凭据错误**：这里要输的是被控电脑的系统登录用户名和密码，不是 Splashtop 账号密码；
- **连到一半断**：手机切换了网络（Wi-Fi 换流量）会话会断，重连即可；
- **系统弹窗挡住**：部分系统级弹窗（如 Windows UAC 确认）在远程会话里操作不了，需要之后在电脑旁本机处理一次。

## 三、连上但黑屏 / 花屏 / 卡顿

1. 先按 [画面与性能设置.md](画面与性能设置.md) 的顺序降画质、换渲染选项；
2. 黑屏且完全无画面：检查电脑是否设置了只向某个外接显示器输出；
3. 画面停在一个旧帧不动：断开重连，多数是网络抖动；
4. 每次都发生在固定操作后（比如打开某个全屏程序）：换渲染选项往往有效。

## 四、账号与设备数量

- 一个 Splashtop 账号可以在多台手机 / 平板上登录，换设备不用解绑，登录即用；
- 可添加的被控电脑数以应用内实际显示为准（官方页面口径在 2 到 5 台之间变过，且都限非商业用途）。

## 五、重装与官方支持

- 卸载重装安卓端时，可以从 [splashtop 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7f3f90559428) 再转存一份 APK；
- 被控端是 Linux 时 Personal 装不了，Streamer 只有 Windows 与 macOS 版；
- 官方支持文档站：`https://support-splashtoppersonal.splashtop.com/`，具体报错可在应用内的日志 / 关于页里查到后再去对照。
