## 一、连接前的三项检查

| 检查项 | 标准 | 不达标的表现 |
| --- | --- | --- |
| 电脑开着机 | 出门前保持开机；睡眠状态多半连不上 | 列表里这台电脑是灰的 |
| 电脑端 Streamer 在跑 | 托盘 / 菜单栏有 Streamer 图标 | 应用里这台电脑显示离线 |
| 两端同一账号 | 用户名一致 | 列表里看不到这台电脑 |
| 网络可达 | 免费版限同一局域网；跨网需要 Anywhere Access Pack（见 [局域网免费与跨网订阅.md](局域网免费与跨网订阅.md)） | 提示需要订阅，或连接超时 |

电脑灰掉、提示离线，按 [电脑离线与服务器不可达排查.md](电脑离线与服务器不可达排查.md) 的清单逐项过；应用提示连不上 Splashtop 服务器（和电脑离线是两回事）也在那一篇的第三节。

## 二、发起连接

1. 手机 / 平板打开 Splashtop Personal，登录账号；
2. 电脑列表里点你要连的那台，只有在线的电脑能点；
3. 首次连接通常会要求输入被控电脑登录 Windows / macOS 时用的用户名和密码（Streamer 安全设置不同，要求可能略有差异），输对才能进；
4. 进入后整块屏幕就是那台电脑的桌面，直接用手指操作。

注意：第 3 步输的是**电脑的系统登录凭据**，不是 Splashtop 账号密码，两者混了是最常见的连接失败原因。

## 三、触屏操作对照

| 你想做的 | 手势 |
| --- | --- |
| 单击 | 轻点 |
| 右键 | 双指轻点，或长按 |
| 拖动窗口 | 长按后拖动 |
| 滚动页面 | 双指上下滑动 |
| 缩放画面 | 双指捏合（只缩放画面显示，不改变远端分辨率） |
| 打开键盘 | 会话工具条里的键盘按钮 |

会话期间屏幕边缘有工具条：切回列表、调出键盘、在「直接触控」与「触控板」两种操作模式之间切换都在那里。小屏幕上精细点击费劲时，切触控板模式会顺手很多。

## 四、结束会话

点工具条上的断开按钮退出即可。断开后被控电脑不会自动锁屏；在公共网络环境用完，建议顺手在会话里给电脑锁个屏。想让连接时电脑屏幕黑掉（旁边人看不到你操作什么），用 Streamer 里的空白屏设置，见 [画面与性能设置.md](画面与性能设置.md)。

## 五、连不上怎么办

列表里电脑是灰的、连到一半断开、提示凭据错误——这三类按 [常见问题与排查.md](常见问题与排查.md) 的顺序逐项排查；连上了但画面卡，先去 [画面与性能设置.md](画面与性能设置.md) 降画质。
