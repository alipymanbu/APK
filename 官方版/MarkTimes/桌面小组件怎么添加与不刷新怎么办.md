## 一、有哪些小组件

官方更新日志里提到过整批新增：「添加了三个新的小组件：分组事件小组件，周视图小组件和周视图图标小组件」。不同版本的小组件列表会变，下面按用途分类，你手机上实际能加哪些，以系统小组件列表里 MarkTimes 那一组显示的为准。

| 小组件类型 | 桌面上看到什么 | 适合放在哪 |
| --- | --- | --- |
| 分组事件 | 某个分组下的事件清单 | 放在首屏，一眼扫到今天该做什么 |
| 周视图 | 这一周的打卡/记录分布 | 放在第二屏，用于每周回看节奏 |
| 周视图图标 | 周视图的精简形式，占位更小 | 桌面位置紧张时用 |
| 单个事件 / 打卡入口 | 只盯一个事件，点一下就是打卡 | 喝水、吃药、早睡这类高频打卡 |

选哪块，取决于你是「想看清」还是「想动手」：想看清用周视图，想动手用单事件打卡入口。两块同时放也行，但桌面上超过两三个标记类小组件，刷新都会变慢。

## 二、添加步骤

各品牌的入口名字略有差别，但路径一致：

1. 回到桌面，**长按空白处**，弹出菜单里选「小组件」（有的机型叫「添加工具」「桌面挂件」）。
2. 在列表里找到 **MarkTimes**，展开它能提供的样式。
3. **长按某一块拖到桌面上**，松手后落位；也有机型是点一下再加「添加」。
4. 如果小组件带配置项（比如要选哪个分组、哪个事件），落位后会立刻弹出选择界面，选完保存。

两点经验：

- **先把事件和分组建好再加小组件。** 小组件是按你已有的事件/分组渲染的，桌面加完再回去建事件，那块小组件往往要等下一次刷新才显示出来。
- **放在第二屏也无妨。** 打卡入口这类小组件其实不需要占首屏最好的位置，放在拇指一滑能到的地方就行。

## 三、加了但不刷新、点了没反应，按这个顺序查

这类问题几乎都不是应用本身出错，而是安卓在替你省电。**从第一条开始往下查，多数人停在第二三条就能解决。**

1. **确认事件本身有数据。** 打开应用看那条事件今天有没有记录。应用里没有，小组件当然也不会有。
2. **解开后台限制。** 设置 → 应用 → MarkTimes → 电池（或耗电管理）→ 选「无限制 / 允许后台运行」。默认的「智能限制」「后台省电」会把应用从内存里清掉，小组件就此定格在最后一次刷新的画面上。
3. **关掉系统的省电模式。** 不少机型一旦进入省电模式，会统一冻结所有小组件刷新。下拉通知栏关掉再观察一段时间。
4. **把小组件删掉重新加一次。** 长按桌面上的那块，拖到「移除」，再按第二节的步骤重新添一遍。这一步能解决大部分「装了但一动不动」的情况，而且不会动到任何数据。
5. **重启手机。** 前四条都试过仍不动，重启一次让系统重新挂载小组件进程。重启后如果提醒也跟着恢复，说明问题原本就在后台被清掉这一层，回头把自启动权限也放行一次，见 [打卡补卡与提醒设置.md](打卡补卡与提醒设置.md) 的第三节。
6. **清缓存。** 设置 → 应用 → MarkTimes → 存储 → 清除缓存。**注意不要点旁边的「清除数据」**，那等同于把应用里的记录全部删掉，清之前先按 [数据备份导出与换手机迁移.md](数据备份导出与换手机迁移.md) 导出一次。

## 四、几条边界，提前知道省事

| 情况 | 实际表现 | 说明 |
| --- | --- | --- |
| 换第三方桌面（Launcher） | 小组件消失或版面错乱 | 换桌面后要重新添加，各家桌面支持的尺寸不一样 |
| 应用被「强行停止」 | 小组件全部变灰或空白 | 到应用管理里重新打开一次应用即可恢复 |
| 应用装在 SD 卡上 | 小组件加不上或加完不显示 | 把应用移回内部存储，小组件依赖内部存储路径 |
| 开了「深色模式」 | 小组件配色跟着系统变 | 属正常表现，不是显示故障 |
| 桌面上放了多块 MarkTimes 小组件 | 刷新变慢、偶尔错位 | 减到一两块，或换成占用更小的周视图图标样式 |

小组件点了没记上、但打开应用看记录又正常，多半是后台被限速导致的写入延迟，先按第三节第 2 条放行后台权限；如果反复出现，把这条记下来，换用应用内的按钮打卡更稳。更多现象集中在 [常见问题与排查.md](常见问题与排查.md)。
