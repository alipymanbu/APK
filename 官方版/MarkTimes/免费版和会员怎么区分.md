## 一、先说明一条边界

官方公开的资料里，只有「成为会员可以解锁 MarkTimes 所有的付费功能，享受未来高级功能的免费更新」这样一句概括，**没有给出一份逐条对照的「免费能做什么、会员才能做什么」的清单**。所以这篇不编一张似是而非的对照表出来，只把能确定的事写清楚：怎么判断、去哪看、怎么退。

## 二、怎么判断自己有没有会员

按下面几处依次看，比猜更靠谱：

| 检查位置 | 看到什么说明有会员 |
| --- | --- |
| 应用内的会员/订阅页面 | 显示「已开通」「到期时间」之类状态，而不是「立即开通」 |
| 应用商店的订阅管理 | 该应用下有生效中的订阅条目，并带下次续费日期 |
| 苹果设备：设置 → Apple 账户 → 订阅 | 列表里出现 MarkTimes 的订阅项 |
| 安卓设备：应用商店 → 我的 → 订阅管理 | 列表里出现 MarkTimes 的订阅项 |

注意：**买过和正在生效是两回事。** 订阅到期没续，应用商店的历史购买记录里还留着，但会员权益已经停了，以「到期时间」那一栏为准。

## 三、价格和周期

安卓端的会员价格由你在哪个应用商店购买决定，各商店可能不一致，**以应用内购买页面当时显示的价格为准**。

苹果 App Store 的应用页面在 2026-09-23 这一版资料里，列出的应用内购买项目是这样的（会变，以官方页面当时显示为准）：

| 项目 | 页面标价 |
| --- | --- |
| 会员 - 一个月会员 | ¥8.00 |
| 会员 - 一年会员 | ¥48.00 |
| 终生会员 | ¥78.00 |
| 终生会员 | ¥148.00 |

同页出现了两条「终生会员」且价格不同，具体对应哪一种权益（例如是否区分了不同档位或不同时期的条目），以页面上的说明为准。本文档不替它做解释。

## 四、试用与自动续费

苹果的订阅规则在官方简介里写得比较明确，要点三条：

1. **确认购买并支付后，会从你的 Apple 账号自动续订。**
2. **到期前 24 小时内扣费**，扣费成功后订阅周期顺延一期。
3. **如果开了试用**，试用期内不取消，到期会自动开通订阅并扣款；没使用完的试用时长在购买后作废。

安卓这边走的是应用商店自己的订阅体系，规则与苹果类似（到期自动续费、需在到期前手动关闭），具体条款看你在哪个商店付的钱。

## 五、取消续费：按付款渠道走，不是按应用走

这是最常见的误区：**在应用里删掉账号或者卸载应用，都不会取消订阅。** 续费扣的是应用商店的账号，只能回应用商店关。

| 你在哪付的钱 | 取消路径 |
| --- | --- |
| 苹果 App Store | 设置 → Apple 账户 → 订阅 → 找到 MarkTimes → 关闭自动续费。需在当前订阅周期到期前 24 小时以前操作 |
| 安卓应用商店 | 打开付款时用的那个应用商店 → 我的 → 订阅管理 → 找到 MarkTimes → 取消订阅 |

三条提醒：

- **卸载应用不会退款也不会停止扣费。**
- **换手机不影响订阅。** 订阅跟的是应用商店账号，换设备后用同一个账号登录就能恢复权益；反过来，换了商店账号就找不回来了。**但跨平台是两套：**苹果端买的会员不会让安卓端解锁，反之亦然，见 [苹果版和安卓版有什么区别.md](苹果版和安卓版有什么区别.md)。
- **要退款得找商店。** 应用里没有退款入口，苹果走 Apple 的退款流程，安卓走对应商店的客服流程。

## 六、装的是哪一份，会影响你的权益吗

会。订阅绑在应用商店账号上，如果手机上装的是另一个渠道的同名包（例如包名 `kaisen.mark.timesyy` 的那一份），你在官方那份里买的会员不会在这里生效。认包名和开发者的方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

购买页面打不开、付了钱权益没到账这类现象，处理顺序写在 [常见问题与排查.md](常见问题与排查.md)。
