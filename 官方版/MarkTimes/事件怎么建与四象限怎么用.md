## 一、一个「事件」里能填什么

先看清单，再决定哪些填、哪些留空。官方反复强调的是：只有名称是必填的，其余都能后补。

| 字段 | 作用 | 什么情况下值得填 |
| --- | --- | --- |
| 事件名称 | 这条记录叫什么 | 必填。写短一点，比如「喝水」「跑步」「背单词」 |
| 图标 / 表情 | 列表里的视觉标识 | 同一分组里事件多的时候用得上，一眼能扫到 |
| 分组 | 把事件分类，比如工作、健康、学习 | 事件超过 10 个再分，否则分组本身比事件还多 |
| 属性 | 记录除「做了没有」之外的信息，官方说法是类似 Notion、飞书的属性 | 要记数值或选项时才加，见第三节 |
| 提醒 | 到点提示，并可生成待办 | 有固定时间点的事才设，见 [打卡补卡与提醒设置.md](打卡补卡与提醒设置.md) |
| 打卡周期 | 决定这个事件按天、按周还是按次记录 | 习惯类的要设，在事件的编辑页里选（不同版本的下拉项名称不一样）；一次性的记录不用设 |

## 二、第一次建事件的最短路径

不同版本的按钮位置会挪，所以按「找什么」来记，不要死记坐标：

1. 打开应用，进到记录列表（列表顶部可以在「所有」与各分组之间切换）。
2. 找到新建入口（通常在列表页右上角，标着「新建」或一个加号）。
3. 只填事件名称，保存。
4. 回到列表，点一下这条事件，让它产生第一条记录。
5. 打开趋势页看一眼，确认这条记录被统计进去了，见 [趋势统计怎么看.md](趋势统计怎么看.md)。

这三步跑通之后，再回去给它加图标、分组、属性。一次配太多，出问题时分不清是哪一项引起的。

## 三、属性怎么加，常用的就三类

属性是 MarkTimes 和普通打卡软件的差别所在：它允许你把「喝水」记成 8 杯，把「跑步」记成 5 公里，把「心情」记成一个选项，而不是只有一个勾。

| 属性类型 | 记出来是什么 | 典型用法 |
| --- | --- | --- |
| 数值 | 每次记录带一个数字 | 喝水量（毫升）、体重（公斤）、跑步距离（公里） |
| 文本 | 每次记录带一段文字 | 今天练了什么动作、吃了什么 |
| 评分 / 单选 | 每次记录从固定选项或分值里挑一个 | 睡眠质量、心情、精力状态 |

两点经验：

- **数值属性要和单位一起想好。** 后面趋势页里的折线、时长统计要靠它算，单位前后不一致（一会儿「杯」一会儿「毫升」）图就失真了。
- **属性的显示条件可以配。** 1.4.20 的更新日志里提到「优化属性显示条件的解析」，意思是属性可以只在满足条件时才出现。这类设置建议先从默认值用起，用熟了再动。

## 四、四象限怎么用

四象限是按「紧急」和「重要」两个维度把待办分成四格的视图，官方介绍里对应的是「四象限任务管理」。

| 格子 | 放什么 | 处理方式 |
| --- | --- | --- |
| 重要且紧急 | 今天必须交出去的事 | 今天就做，做完从格子里划掉 |
| 重要不紧急 | 长期有收益的事，比如健身、学习、体检预约 | 每天留固定时间推进 |
| 紧急不重要 | 别人的截止时间、临时通知 | 能转交就转交，能批量处理就批量处理 |
| 不重要不紧急 | 想起来顺手记下的杂事 | 攒着，闲的时候一起清 |

### 入口与两步操作

- **谁会被放进去：** 四象限管的是待办 / 计划类的那一侧，喝水、心情这类纯记录事件不会出现在格子里。
- **要让一件事进格子，做两步：** 先把它建成带时间要求的待办，再给出「紧急」「重要」两个判断。至于具体是拖到格子里、还是用选项标记，各版本界面不同，按你屏幕上出现的交互处理。
- **找不到入口时：** 先确认版本号与 [下载与安装教程.md](下载与安装教程.md) 第一节的表格一致、装的是同一份应用 —— 这类差异多半来自版本不同，而不是设置问题。

用起来的三条注意：

1. **只放「要动的」，不要放「想记的」。** 想把每天的记忆、灵感也塞进四象限，格子会很快堆成一个新的收件箱，反而看不出优先级。这类内容更适合另建事件用记录的方式存。
2. **格子之间要允许挪。** 一件事今天在「重要且紧急」，明天拖延了还在那儿，就说明这个格子正在失效，该重新判断一次紧急程度。
3. **不用每天从零开始摆一遍。** 长期事项（健身、读书）放在「重要不紧急」里不用动，每天只需处理前两格的变化。

## 五、分组与筛选

事件积累起来之后，真正影响体验的是「找得到」，不是「记得多」。

- 分组的粒度按场景走，比如「健康」「学习」「家务」，而不是按「常用 / 不常用」。
- 新建分组的入口在列表页切到「所有」视图之后（多数版本是标着房子形状的那个图标），进去可以新建分组；不同版本位置不一样，以你手机上看到的为准。
- 想临时看某一类，用列表顶部的分组切换；想看全部，切回「所有」。
- 时间维度上，应用提供月视图、周视图和时间轴三种看法：月视图适合回头看规律，周视图适合安排这一周，时间轴适合回顾某一天的顺序。三者的入口在同一处，切一下就能对照。

## 六、几个容易卡住的地方

| 情况 | 说明 |
| --- | --- |
| 建完事件没反应 | 事件本身不产生记录，要去点一下才会记上第一条 |
| 想改事件名或图标 | 进事件详情里改，改完历史记录还在；图标换成系统默认图标或表情都可以 |
| 建了打卡事件但不想天天打 | 官方口径是不强制打卡、允许事后补，具体见 [打卡补卡与提醒设置.md](打卡补卡与提醒设置.md) |
| 属性加了又想删 | 先想着这条属性已经产生过数据：删掉属性，那部分历史记录会一起消失，建议改成隐藏或换条件显示 |
| 同一个事件想在桌面上快速记 | 用小组件，见 [桌面小组件怎么添加与不刷新怎么办.md](桌面小组件怎么添加与不刷新怎么办.md) |
