## 一、装之前先对一下这张表

| 项目 | 这一份的情况 |
| --- | --- |
| 软件名 | MarkTimes |
| 版本号 | 1.4.19 |
| 包名 | `top.ideaapp.timemark` |
| 安装包大小 | 12.83 MB（13,450,623 字节） |
| 安装包 MD5 | `79301A8C95FB28337C557956E5CC0AD2` |
| 开发者 | 上海莫吉科技有限公司 |
| 适用设备 | 安卓手机 / 安卓平板 |
| 官方分类 | 生活实用 |

三点先说明：

1. **版本号以本页表格为准。** 官方应用商店同期已经更新到 1.4.20、1.4.21 一带（商店页面上的更新日期是 2026-09-23），而这份安装包是 1.4.19，两者不是同一个版本。搜索引擎上翻到的介绍页往往停在更早的版本号，不用拿去跟你手上的包对照。
2. **官方渠道没有公布最低安卓版本。** 商店页面里看不到「需要安卓几点几」这类说明，所以这份文档也不写一个数字出来。能不能装，以你在设备上点下去之后的提示为准。
3. **装完可以自己复核。** 安卓系统里进「设置 → 应用 → MarkTimes」，能看到版本号与占用空间；版本号和上表对得上，说明装的就是这一份。

## 二、从网盘把安装包取出来

1. 打开 [MarkTimes 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3166c95ea4dc)。手机、电脑都能操作，用夸克 App 打开更稳。
2. 点「保存到我的网盘」转存到自己账号下。转存之后，下载就不再依赖原分享链接是否还在。
3. 下载到本地，确认文件名结尾是 `.apk`。
4. 核对 MD5 是不是 `79301A8C95FB28337C557956E5CC0AD2`。在电脑上下载的话，Windows 可以在文件所在目录用下面这条命令算一遍，文件名换成你实际下到的那个（文件名里有中文或空格时，整段用英文双引号包起来）：

```powershell
certutil -hashfile "你下到的文件名.apk" MD5
```

5. 对不上就删掉重下。安卓装到一半报「解析包错误」，多数情况是包没下完整或传输被截断。

## 三、安卓安装步骤

这个包不是从手机自带软件商店里装的，安装时系统会拦一下，属于正常现象，不代表文件有问题。

1. 打开手机的「文件管理」，进 `Download`（下载）目录，找到刚下好的安装包，点它。
2. 弹出「不允许安装来自此来源的应用」时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要绕一层：设置 → 应用 → 特殊应用权限 → 安装未知应用，在里面找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」，别急着打开，先看下一节。

## 四、首次打开要做的事

1. **先把通知权限给上。** 应用第一次启动时会问通知权限，这里点了「不允许」，之后设的提醒到点了也不会有任何提示。给过一次之后还能改：设置 → 通知 → 应用通知管理 → MarkTimes → 允许通知。
2. **要用日历联动的话，日历权限一起放行。** 商店页面列出的权限里有「读取日历」「添加或修改日历活动」，打卡写进系统日历靠的就是这两条。不给也不影响打卡本身，只是记录不会出现在系统日历里，细节见 [打卡补卡与提醒设置.md](打卡补卡与提醒设置.md)。
3. **顺手确认这两条权限的语气。** 商店页面还列了「开机时自动启动」和「使用精确的警报 API」，前者影响重启后提醒还在不在，后者影响提醒准不准时。三星、小米、OPPO、vivo 这类机型另有「省电策略 / 后台限制」，交给系统自动限制过的应用，提醒会延迟甚至不来。
4. **先只建一个事件试试。** 官方介绍里反复强调「简单到你只需要设置个事件名」，那就照这个来：建一个只有名称的事件，点一下完成，看看趋势页有没有记上。确认跑通了，再去配属性和提醒，省得一次配太多、出问题不知道是哪一步。建事件的完整路径见 [事件怎么建与四象限怎么用.md](事件怎么建与四象限怎么用.md)。
5. **不强制打卡。** 漏了一天也允许事后补记录，这是官方口径里明确写的，别因为怕断掉而不敢用。

## 五、装不上时先查哪几处

| 现象 | 大概率原因 | 怎么处理 |
| --- | --- | --- |
| 「解析包错误」 | 包没下完整、传输被截断 | 删掉重新下载，用第一节的 MD5 核对 |
| 「应用未安装」 | 设备上已有同包名旧版，签名对不上 | 先卸载旧版再装。注意卸载会清掉应用内的记录，能覆盖安装就别卸载 |
| 提示不允许安装未知应用 | 系统的来源限制 | 见第三节第 2 步 |
| 装完图标不出现 | 装到了当前用户之外的空间 | 到系统「应用管理」里搜 MarkTimes，能找到就说明装成功了，从那里打开 |
| 打开就闪退 | 系统版本过低，或包在传输中损坏 | 换一台设备试，或重新下载原包后再装 |
| 装完版本号和第一节表格不一致 | 手机上还留着别的渠道装的同名应用 | 见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) |

## 六、这一版和官方最新版怎么取舍

官方商店的更新更快（这份是 1.4.19，商店同期已到 1.4.20 一带），更新日志里的改动集中在小组件、图表、日历这几处细节增强。

1. **判断标准只有一条：那些改动里有没有你每天要用的功能。** 没有就别动 —— 换版本要重新走一遍安装和权限设置。
2. **真要换，就别交叉装。** 先按 [数据备份导出与换手机迁移.md](数据备份导出与换手机迁移.md) 导出数据，再卸载旧版、装新版，最后导入。拿不同渠道的包直接覆盖安装，常见结果是「应用未安装」。
3. **换完重新核三处。** 版本号对第一节的表格；提醒、日历联动是否还需要重新授权；桌面小组件要不要重新添加一次。

打开后提醒不响、日历里出重复条目、数据换机后不见了，都在 [常见问题与排查.md](常见问题与排查.md) 里，不在这里重复。
