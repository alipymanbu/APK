# MarkTimes 同名应用与官方渠道怎么认

> 搜「MarkTimes」会搜出好几样东西：给照片打时间水印的 Timemark、国外的 B2B 订货平台 MarketTime，还有下载站上挂着同名却标着另一个包名的安卓包。这篇给你三个可核对的字段，让你一眼分清手里装的是哪一份。

## 一、认这三样就够

| 字段 | 本文档对应的值 |
| --- | --- |
| 软件名写法 | MarkTimes（首字母 M 与中间的 T 都大写，官方页面就是这么写的） |
| 包名 | `top.ideaapp.timemark` |
| 开发者 | 上海莫吉科技有限公司（苹果商店里署名是「Ji Mo」） |

大小写不是小事：搜索引擎按「marktimes」也能搜到，但下载站和小工具生成的文件名常写成全小写 `markTimes` 或 `marktimes`，那只是排版差异，**真正区分身份的是包名和开发者**。另外，开发者的隐私政策与用户协议页面挂在 [www.mojit.top](https://www.mojit.top) 这个域名下（应用商店页面里给出的就是这个），出现别的域名的「官网」，先当作存疑处理。

## 二、容易撞上的四类东西

| 撞上的东西 | 它到底是什么 | 怎么区分 |
| --- | --- | --- |
| Timemark（`help.timemark.com`） | 给照片加时间水印、工地拍照存档一类的工具，有网页版和 App | 用途完全不同：那个是拍照留证，MarkTimes 是记录与打卡 |
| MarketTime（`support.markettime.com`） | 国外的 B2B 订货平台，给品牌商、销售代理和零售商用的 | 名字中间多一个 t；面向企业采购，不是个人记录工具 |
| 包名 `kaisen.mark.timesyy` 的安卓包 | 部分下载站上挂着同一个名字、标称开发者是另一家公司 | 包名和开发者都对不上，装的不是本文档这一份 |
| 各种「XX下载站」的 MarkTimes 页面 | 页面里的版本号、大小、截图可能都停留在很早的旧版 | 版本号只以 [下载与安装教程.md](下载与安装教程.md) 第一节的表格为准，不用下载站页面的数字核对 |

## 三、从哪装最稳

1. **优先官方应用商店**：苹果 App Store、小米应用商店、应用宝等，搜「MarkTimes」，看开发者是不是上海莫吉科技有限公司。
2. **用本文档给的 [MarkTimes 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3166c95ea4dc)**：它对应的是包名 `top.ideaapp.timemark` 这一份，版本号与大小见 [下载与安装教程.md](下载与安装教程.md) 第一节。
3. **装完自己核一遍**：进系统「设置 → 应用 → MarkTimes」，多数国产系统的应用信息页会显示包名与版本号，对得上就装对了；如果那里不显示包名，退一步核对版本号与 [下载与安装教程.md](下载与安装教程.md) 第一节的表格一致、开发者信息能对上。
4. **核对不上就卸掉重装**，别在上面继续记录 —— 后面记录攒起来再换，迁移的麻烦要自己承担，见 [数据备份导出与换手机迁移.md](数据备份导出与换手机迁移.md)。

## 四、搜到的教程和你手机上的界面对不上

这是很常见的情况，原因通常有三个，都不是你操作错了：

- **版本不同。** 这份安装包是 1.4.19，官方商店同期已经到 1.4.20 一带；小版本之间按钮位置、列表项名称都可能调整。搜索到的文章大多对应更早的版本。
- **平台不同。** MarkTimes 苹果端与安卓端的界面并不完全一致，官方两边的更新节奏也不一样（应用商店页面上的更新时间常常相隔数月）。照苹果的截图在安卓上找按钮，找不到是正常的。
- **文章本身就是拼的。** 不少下载站的「使用教程」是通用模板，描述的操作路径在真实应用里并不存在。

所以看教程时只取「做这件事的思路」，具体按钮按你手机上实际的界面找。本篇以及同目录其它几篇尽量都写成「找什么功能」而不是「点屏幕哪个角」，就是为了少受版本影响。

## 五、发现装错了怎么办

1. 先导出数据（万一那边也有你记了东西），办法见 [数据备份导出与换手机迁移.md](数据备份导出与换手机迁移.md)。
2. 卸载那一份，按 [下载与安装教程.md](下载与安装教程.md) 重装官方这一份。
3. 如果之前在错的那一份里买过会员，权益不会转移过来，退款要回原付款的应用商店申请，见 [免费版和会员怎么区分.md](免费版和会员怎么区分.md)。

装完发现打不开、闪退、权限要得奇怪，对照 [常见问题与排查.md](常见问题与排查.md) 里的安装类条目处理。
