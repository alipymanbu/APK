# MarkTimes 趋势统计怎么看

> MarkTimes 的价值大半在趋势页：你记了多久、记了多少次、数值在往哪个方向走，都靠它呈现。这篇讲趋势页里各块图表分别在回答什么问题，以及统计结果和你印象对不上时先查哪几项。

## 一、趋势页在回答哪些问题

先把图看懂，比先把数据记全更重要。趋势页里的几块内容分工大致如下：

| 你看到的 | 它在回答 | 怎么用 |
| --- | --- | --- |
| 频次 / 热力图 | 这件事多久发生一次、哪几天断过 | 判断习惯是「真养成」还是「三分钟热度」 |
| 时长统计 | 累计投入了多少时间 | 用在带计时或时长的记录上，比如跑步、阅读 |
| 数值折线 | 带数值属性的指标怎么变 | 体重、喝水量这类；折线看趋势，单点看当天 |
| 使用天数 | 从第一次使用到现在的跨度 | 官方更新日志里提到这块支持长按修改首次使用时间 |

两块读图经验：

- **频次看「有没有断」，折线看「方向」。** 热力图突然出现一片空白的日期，那几天就是你实际放弃的窗口，比「连续 30 天」这种总数更有信息量。
- **折线不要追单日波动。** 体重、睡眠这类数值天然会上下跳，判断变化要看两到四周的走势。单日跳一下不代表任何事。

## 二、交叉分析：把两个维度叠在一起看

1.4.20 的更新日志里提到「时长和数值类型的交叉分析图表中也支持了小票分享」，这说明趋势页支持把两个维度的数据叠在一起看。典型用法是：

| 想搞清楚的事 | 怎么叠 |
| --- | --- |
| 练得多的日子睡得好不好 | 运动时长 × 睡眠评分 |
| 喝水少的日子是不是吃得多 | 喝水量 × 饮食记录 |
| 哪类事最占时间 | 各事件的时长横向对照 |

**「小票分享」是把当前筛选出的图表导出成一张图片**，用来存证或发给别人。分享前留意一下图上会不会带出你不希望出现的记录文本（比如心情随笔），确认清楚再发。

## 三、单位与筛选

- **时长单位可以点着切。** 1.4.20 里写明「时长统计里面点击时长文本可以切换分钟、小时、天的计量单位」，所以看到「1,440」别急着以为是小时，点一下文字，先确认当前单位是什么。
- **筛选条件会同时作用于图和数字。** 趋势页筛选之后剩下的记录才会参与计算，如果数字比印象里小很多，先看筛选是不是还留着上次的条件。
- **时间段的选择影响「一段时间」的口径。** 官方在 1.4.20 提到「查看时间段日历支持七天」，也就是可选的时间段粒度变细了。想横向比周与周之间的差别，先把两端的时间段选成一样长。

## 四、数字对不上时，按这个顺序查

| 现象 | 先查这几项 |
| --- | --- |
| 某天的记录在图里看不见 | 那天是不是补卡补的（补卡会重算，见 [打卡补卡与提醒设置.md](打卡补卡与提醒设置.md)）；这个事件是不是被隐藏了、或不在当前查看的分组里（分组与筛选见 [事件怎么建与四象限怎么用.md](事件怎么建与四象限怎么用.md) 第五节） |
| 频次比实际少 | 是否有多个同类型事件（比如「喝水」「多喝水」两条），各算各的，不会合并 |
| 折线缺了几段 | 那几天只打了勾、没填数值，没有数值自然画不出点 |
| 使用天数是错的 | 这块支持长按修改首次使用时间，换过手机或重装后经常需要手动改一次 |
| 换了手机之后数字断档 | 迁移时只导了一部分数据，处理办法见 [数据备份导出与换手机迁移.md](数据备份导出与换手机迁移.md) |

## 五、「记录得越细，统计越有用」怎么落实

官方那句「记录的事件越详细，生成统计数据也越详细」不是空话，落到操作上是三条：

1. **给需要看的指标加数值属性。** 只打勾，你得到的永远只有频次。
2. **属性名和单位一次定死。** 中途改名或改单位，前后数据会被当成同一列处理，图会突然跳一下。
3. **补卡时把属性一起补上。** 补了勾没补数值，那天在折线里就是空的。

这套记录方式的建立要看 [事件怎么建与四象限怎么用.md](事件怎么建与四象限怎么用.md) 第三节；手里的图标数据要长期留着，得先弄清楚应用把数据存在哪，见 [数据备份导出与换手机迁移.md](数据备份导出与换手机迁移.md)。
