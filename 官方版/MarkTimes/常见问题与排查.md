# MarkTimes 常见问题与排查

> 记录类应用的问题就那么几类：提醒不响、日历里多出条目、小组件不刷新、数据换机不见了、装不上。这篇按现象给排查顺序，每条都写清先看哪一处，避免来回瞎试。

## 一、先对一份速查表

| 现象 | 最可能的原因 | 第一步做这个 |
| --- | --- | --- |
| 提醒到点没声音、没弹窗 | 系统没给通知权限 | 设置 → 通知 → 应用通知管理 → MarkTimes → 允许通知 |
| 提醒晚了几分钟到十几分钟 | 缺精确闹钟权限 | 设置 → 应用 → 特殊应用权限 → 闹钟与提醒 |
| 锁屏久了提醒完全不来 | 被系统省电策略限制 | 设置 → 电池 → MarkTimes → 改为不限制 |
| 重启手机后提醒全失效 | 自启动权限被拦 | 设置 → 应用 → 自启动管理 → 放行 MarkTimes |
| 小组件停在旧内容不动 | 后台被清 | 见 [桌面小组件怎么添加与不刷新怎么办.md](桌面小组件怎么添加与不刷新怎么办.md) 第三节 |
| 系统日历里出现重复条目 | 同一条记录写了两次 | 到系统日历里删掉多余的那条，见第二节 |
| 新手机打开是空的 | 数据默认存本机，不自动跟过去 | 见 [数据备份导出与换手机迁移.md](数据备份导出与换手机迁移.md) 第三节 |
| 装不上或报「解析包错误」 | 包没下完整 | 按 [下载与安装教程.md](下载与安装教程.md) 第一节的 MD5 核对后重下 |

## 二、日历里多出条目

打卡联动日历之后，系统日历里会按记录生成条目。出现重复，通常是同一件事记了两次：

1. 回想最近有没有「补卡时改了日期又保存」—— 改日期的那次往往会在原日期和新日期各留一条。
2. 打开系统日历，定位到重复的那一天，把多余的那条删掉。**这一步只清系统日历，应用里的记录不受影响。**
3. 如果这类重复经常出现，说明你并不需要那份日历视图，可以在应用里关掉日历联动，之后打卡就不会再往系统日历写。联动的开关与权限前提见 [打卡补卡与提醒设置.md](打卡补卡与提醒设置.md) 第四节。

## 三、补卡补不进去、或者补了统计没变

| 情况 | 说明 |
| --- | --- |
| 补卡保存后列表上看不出变化 | 换到时间轴或趋势页去看，列表默认只展示当天的内容 |
| 补卡日期选不到更早的 | 部分视图有可选范围限制，回到该事件的详情里改日期更稳 |
| 补卡后连续天数变多/变少 | 正常。补卡会重算连续天数与频次，不是数据出错 |
| 补了勾但折线还是空的 | 那天缺数值属性的填写，折线需要数值才能出点，见 [趋势统计怎么看.md](趋势统计怎么看.md) |

## 四、记录确实丢了，还有多少救回来的可能

按这个顺序确认，别急着重装：

1. **先看是不是换了设备看的。** 数据默认存在本机，新设备本来就是空的，不代表旧设备上的记录丢了。
2. **旧设备还在的话**，按 [数据备份导出与换手机迁移.md](数据备份导出与换手机迁移.md) 导出再迁移。
3. **开过云同步且是苹果设备之间**：登录同一账号等它同步回来。
4. **做过导出**：按 [数据备份导出与换手机迁移.md](数据备份导出与换手机迁移.md) 第三节的办法导入。
5. **以上都没有，且执行过卸载或「清除数据」**：本机没有入口能找回。这时才有必要考虑重新开始记录。

另外提醒一句：应用里的「清除缓存」和「清除数据」挨在一起，前者安全，后者等于刚装好的状态。想点之前先确认自己点的是哪一个。

## 五、买了会员但权益没到账

1. 确认付款渠道：苹果买的应用商店账号和安卓商店账号是两套，换个渠道买不算数。
2. 打开应用里的会员页面，下拉刷新一次；订阅状态有时要重新拉取才更新。
3. 已在商店里看到生效中的订阅、但应用内仍提示未开通：先退出应用重进，仍不行就卸载重装（**重装前先导出数据**，见 [数据备份导出与换手机迁移.md](数据备份导出与换手机迁移.md)）。
4. 扣了钱但订阅列表里没有：到付款的那个商店里找「购买记录 / 客服」入口，退款与补单都由商店处理，应用内没有这个权限。价格与取消续费的路径见 [免费版和会员怎么区分.md](免费版和会员怎么区分.md)。

## 六、界面和教程对不上、找不到按钮

先确认两点再看教程：手里的版本号（系统里「设置 → 应用 → MarkTimes」能看）与教程写的是不是同一版；教程是苹果的还是安卓的。这两个对不上，按钮位置对不上是正常现象，按「做什么事」去找功能，不要按截图找坐标。同名应用与版本识别见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 七、什么时候该换一条路

同一件事连续试三条办法都没改善时，别再继续改设置，先退回到一条已知可用的路径上：提醒不响就改成每天固定时间打开应用手动记；小组件不刷新就直接在应用里打卡；日历重复就关掉联动。**记录本身比记录的方式重要**，等空闲了再回来调设置。
