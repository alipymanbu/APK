## 一、SecondMe 是一款什么应用

SecondMe 是成都艾威森联科技有限公司运营的社交应用，定位是「亚文化扩圈社交平台」，内容围绕「多元反差」主题展开——你可以把自己的不同侧面分成两组展示，比如「生活中的我 VS 圈子里的我」。社区要求用户年满 18 周岁，注册流程与认证要求见 [注册认证与隐私设置.md](注册认证与隐私设置.md)。

## 二、「反差」怎么玩

反差是 SecondMe 的内容单元：你围绕一组对比主题发布自己的两面，其他用户可以浏览、互动。

- **发布反差**：在发布入口选反差类型，上传对应两面的图文内容，发布后进入社区流转；
- **反差榜**：社区把热门反差做成榜单，想找内容看就从这里翻，也能看出当前流行哪类主题；
- **谁看得到**：较新版本支持给动态和反差单独设置可见范围与评论权限（见第四节版本对照），不想全员可见的可以收窄范围。

## 三、认识人、聊上天的几条路径

| 路径 | 入口 | 适合场景 |
| --- | --- | --- |
| 发现精彩 | 发现页 | 什么都不想设，先刷内容、看到顺眼的再进主页 |
| 附近同好 | 附近页 | 想找同城、同区域的人；部分版本支持位置漫游改定位城市 |
| 秒聊速配 | 消息/速配入口 | 想直接被匹配一个 1v1 聊天对象，跳过慢慢翻 |
| 亲密关系 | 对方主页/关系入口 | 和聊得来的人绑定平台内的关系等级 |

聊上天之后的一些实用开关都在消息设置里，比如只接收匹配用户的打招呼消息（防打扰）、聊天防截屏防录屏（防泄露），具体见 [注册认证与隐私设置.md](注册认证与隐私设置.md) 第四节。

一对一聊天之外还有多人场景：官方隐私政策里提到了频道、语音房与群功能（群名称、群公告、群成员昵称会存储在平台服务器）。这些入口在你那版里有没有、叫什么名，直接去发现页与消息页翻一遍最可靠，找不到就先别当它有。

## 四、你手上这版和官网最新版差在哪

本文安装包是 2.3.2 版。官方版本记录（[www.secondme.top/historyVersion.html](https://www.secondme.top/historyVersion.html)）显示，之后版本陆续加入了下表功能，最新版本号以官方页面为准：

| 功能 | 加入版本（官方记录） |
| --- | --- |
| 动态与反差的权限设置（隐藏/开放显示作品） | V2.9.0（2025-04-15） |
| 秒聊、附近秒聊、秒聊速配、隐私图标、我的足迹 | V2.11.0（2025-06-23） |
| 消息漫游 | V2.11.2（2025-07-01） |
| 礼物功能、秒豆兑换中心 | V2.12.1（2025-08-13） |
| 聊天防截屏防录屏、仅接收相互匹配用户的打招呼消息 | V2.13.0（2025-09-04） |
| 宠幸翻牌（匿名树洞玩法） | V3.0.1（2025-12-03） |
| 第二人格测试、自定义聊天背景与表情 | V3.4.0（2026-05-06） |
| 动态和反差的可见范围与评论权限设置 | V3.5.3（2026-06-19） |

也就是说，如果你用本文这版 2.3.2，上表功能可能没有或形态不同；判断自己能不能用某个功能，最直接的办法是在 App 里找对应入口，找不到就说明这版还没有。反差、动态、附近、聊天、关系这些基础模块在 2.3.2 里是齐的，日常交友不受影响。
