## 一、注册要准备什么

打开应用，第一页就是登录/注册。你有两种起号方式，选一个就行：

- **邮箱注册**：填邮箱 → 收验证码填入 → 设密码。这是官方下单流程里明确写出的注册路径（「SHEIN 新用户」+ 邮箱账号）。
- **手机号注册**：填手机号 → 收短信验证码 → 设密码。能不能用手机号，取决于你当前所在站点是否开放该国号码，页面上没有这一项就说明这个站点只认邮箱。

另外还能用第三方账号（Google / Facebook / Apple 等，以页面当时显示为准）直接登进来，它同样会在后台给你建一个 SHEIN 账号。

两点提前说清：

1. **密码别用「纯数字」**。多份公开注册页的口径是必须含字母、数字、特殊字符的组合，具体长度以你看到的页面为准。
2. **一个邮箱/手机号对应一个账号**。想再开一个号，得换邮箱或换号码。

注册完是新账号，首单优惠、新人券会自动挂在这个账号下 —— 具体额度以应用内当时显示为准（见 [优惠券积分与会员怎么用.md](优惠券积分与会员怎么用.md)）。

## 二、登录、切号与找回密码

- **日常登录**：「我的」→ 右上角设置 → 退出登录，回到首页登录页，用注册时的邮箱/手机号 + 密码登进来。
- **收不到验证码**：先查垃圾邮件箱（邮箱注册的验证码常被判为垃圾邮件）；再确认你选的站点支持你填的这个号码/域名；短信验证码则检查是否被拦截软件挡了。处理清单见 [常见问题与排查.md](常见问题与排查.md)。
- **忘记密码**：登录页点「忘记密码 / Forgot Password」，用邮箱收重置链接，或用手机号收重置码，设完新密码后旧设备会掉线，重新登一次即可。
- **换手机**：账号是云端的，新手机装好应用用同一套邮箱/密码登进来，订单、地址、收藏、积分都还在。

## 三、站点（国家/地区）决定你看到的一切

这是 SHEIN 最容易让人懵的一点：**同一个账号体系背后有很多个站点**，站点决定币种、语言、运费、可配送国家和可用的支付方式。你看到的价格不是「换算过来的」，而是该站点本来的定价。

**为什么要切**：默认站点常按 IP 或定位自动判定。人在 A 地、收货地址在 B 地，或想用某种支付方式时，就得手动切。

**怎么切**：应用内一般在首页顶部的站点/国家入口，或「我的 → 设置」里找「Shipping To / Country & Region / 配送至」这类项；网页版则在页面右上角选国家与币种。切换后页面会整体刷新，币种、可配送范围随之改变。

三点硬提醒：

1. **切了站点不一定还看得见原来的账号数据** —— 各站点的账户体系相互独立是常见情况，切站后如果发现订单不见了，先切回原站点再看。
2. **收货地址要和站点匹配**：站点选在 A 国、地址填 B 国，下单页多半直接不给下单。
3. **会员权益也认站点**：SHEIN CLUB 的权益只在你订阅时那个站点的订单上生效（见 [优惠券积分与会员怎么用.md](优惠券积分与会员怎么用.md)）。

## 四、界面语言怎么改

SHEIN 的界面语言跟着站点走，不跟着你的心情走 —— **站点没有中文，你就切不到中文**。

- **网页版**：国家/语言选择里通常有单独的语言项（部分站点提供 `English` 之外的多种语言，是否含中文以页面当时列出的为准）。
- **App 内**：到「我的 → 设置」里找 `Language / 语言` 一项；找不到这个入口，说明你当前站点的语言是固定的，改语言得靠切站点。
- 切换后一般会要求重启应用或刷新页面才生效，重启后再看菜单文字有没有变。

顺带一提，站点列表里有中文界面的站点，通常也是收货地址能填中文、客服能用中文沟通的站点。你从中文搜索引擎过来的话，优先找带中文的站点。

## 五、货币怎么改

价格显示的币种由站点与你选的支付方式共同决定。网页版在右上角能直接选币种，可选项通常包括美元、欧元、英镑、日元、港币、新加坡元等十几种（**以页面当时列表为准**）。

App 里一般没有单独的币种开关，跟着站点走。想看人民币标价的话，先找站点列表里有没有对应的中文站点；找不到就只能按当前币种下单 —— 最终扣款金额以支付页显示为准，跨境支付可能产生发卡行的货币转换费，这一笔由发卡行收取，SHEIN 侧不负责解释。

## 六、通知与隐私开关在哪

装完先到「我的 → 设置」里过一遍这几项：

| 想关掉什么 | 去哪找 |
| --- | --- |
| 促销推送（券到期、上新、降价） | 通知设置 / Notification，逐类关闭 |
| 系统通知（订单发货、签收） | 同上，建议保留 |
| 剪贴板/个性化推荐 | 隐私设置 / Privacy，部分站点提供开关 |
| 精准定位 | 回到**手机系统**的应用权限里关，关掉不影响下单 |
| 广告标识 | 隐私设置里若有「个性化广告」项可关 |

关掉定位与广告标识不影响浏览、下单、查物流。把促销推送关掉后，**优惠券到期提醒也会一并减少** —— 券在「我的 → 我的资产/优惠券」里能随时自己看，别光靠推送（见 [优惠券积分与会员怎么用.md](优惠券积分与会员怎么用.md)）。
