## 一、先查物流：包裹可能不是一个

登录 → **我的订单 / My Orders**，每个订单下能看到运单号与轨迹。两个常见现象提前知道：

- **订单会拆开发**：一个订单里的商品可能分多个包裹送到，所以会出现「还有几件没发货」。官方 FAQ 的说法是按订单号回查，看哪些商品还没发出、哪些已经在路上。
- **轨迹停更不代表丢件**：跨境段的轨迹更新频率由承运商决定，长时间停在某个中转节点是常见情况。超过订单页写的预计送达时间还没动静，再去联系客服（入口见 [常见问题与排查.md](常见问题与排查.md)）。

签收后在订单详情里点**确认收货** —— 这一步是积分入账的开关（见 [优惠券积分与会员怎么用.md](优惠券积分与会员怎么用.md)），不点积分不发。

## 二、退货窗口：30 天，从收货那天算

官方退货政策的主口径：

| 项目 | 口径 |
| --- | --- |
| 时限 | **收货之日起 30 天内**提交退货申请，并在时限内把包裹交寄 |
| 第三方卖家 | 部分第三方卖家商品的退货窗口不同，**以商品详情页当时写明的为准** |
| 商品状态 | 全新、未穿、未洗、未改动、未损坏，**吊牌齐全**、原包装在 |
| 提交入口 | 我的订单 → 找到该订单 → 订单详情 → **退货 / Return Item** → 选商品、选退货原因 → 下一步 → 选退款方式 |

**不能退的品类**（官方清单，各站点略有差异，以商品页标注为准）：

- 连体衣（bodysuit）、内衣内裤、珠宝首饰、美妆个护、宠物用品；
- 清仓 / 最终销售（Final Sale）标价的商品；
- 赠品、免费礼物；
- 定制商品（而且定制商品**连取消订单都不支持**）；
- 商品页明确标了「不可退」的任何商品；
- 美妆一旦**拆封**即不可退。

不同品类的收货要求也不一样，退之前对一眼：

| 品类 | 退回要求 |
| --- | --- |
| 服装（含婚纱、西装） | 未穿未洗未改动，吊牌在，卫生贴纸（如有）完整 |
| 假发（真人发） | 未洗未漂未剪未改，检查有没有洗染痕迹 |
| 鞋、包、行李箱 | 未穿过，原鞋盒与全部配件（鞋带、防尘袋）都在，试穿只能在干净柔软的地面 |
| 家具 | 未使用未损坏，连同全部配件、说明书、零件原包装 |
| 手机、笔记本、投影、平板等电子品 | **原封未激活**，个人信息已清除，附件与赠品齐全；缺件或不可再售则不给退款 |
| 套装/组合商品 | 整套一起退，不能拆着退 |

## 三、退货运费谁出

- **每单第一次退货免费**。
- **同一订单再退**，每次从退款里扣 **7.99 美元**运费（站点不同金额与币种不同，以退货页当时显示为准）。
- **少数情况收 6.99 美元**：官方有个「Fair Use / 公平使用政策」，对退货行为显著高于普通用户的账号，每次退货收 6.99 美元，用来覆盖异常高频退货的处理成本 —— 你如果没频繁退过货，不会碰到这条。
- 有些退货方式因承运商限制对特定商品不开放；超大超重件或偏远地区可能要**你自己先垫运费寄回**，并保留寄送凭证，验货通过后再联系客服申请补偿。
- **部分情况下原运费不退**（退款金额里会体现）。

**怎么退（美国站点的两种方式，其他站点以页面提供项为准）**：

1. **退货标签 Return Label** —— 要打印机，打出来贴包裹上；
2. **二维码 QR Code** —— 不用打印机，把码给网点工作人员扫。

两个码都只在**本地境内寄回**时有效。要合并退货的话：不同订单的商品满足条件时可以一起退，在「合并退货清单」里全选，**所有要退的东西必须打进同一个包裹**。

## 四、退款多久到账

官方时间线：

```
寄出退货  →  仓库签收  →  质检  →  平台退款  →  发卡行入账
5-7 天       5-7 天      1 天     （收到包裹后 5-7 天内处理）   1-10 个工作日
```

- **质检不通过会拒退**：洗过、穿过、吊牌剪了、改动过、缺配件，都可能导致不退款 —— 退之前按第二节的表核对一遍。
- **退款去向**：按你提交申请时选的退款方式，退回**原支付方式**或打进 **SHEIN 钱包余额**。退到卡上还要等发卡行入账，1-10 个工作日是**发卡行**的处理时间，不是平台拖着。
- **查进度**：我的 → 订单详情 → **退货与退款记录 / Return & Refund Record**，每一件的状态都在这里，不用反复问客服。
- **不用退回就退款**：个别情况下平台可以直接退款、不要求你把商品寄回，以页面提示为准。
- 尺码不合适要换大换小的，官方路径也是**先退后重新下单**（没有原地换货入口），流程同上。

## 五、发错货、少件、破损怎么走

三种情况处理路径不同，别都走「退货」：

| 你收到的 | 怎么做 |
| --- | --- |
| 发错了商品 | 在我的订单里对**这件**申请退货，原因选错发；每单仍有一次免费退货 |
| 少了一件 | 先看是不是拆成了多个包裹（第一节）；确认确实缺件，走订单详情里的售后/联系客服 |
| 收到就是坏的 | 直接在订单里发起售后并拍下破损状态，走客服通道，别先自行丢弃包装 |
| 快递显示签收但你没拿到 | 先问代收点与家人，再用运单号联系承运商，最后才是找平台客服 |

入口与联系方式集中在 [常见问题与排查.md](常见问题与排查.md) 里，这里不再重复写。
