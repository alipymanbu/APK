## 一、下单流程：从购物车到付款

官方给出的下单顺序是固定的五步：

1. 挑商品 → 选尺码/颜色/数量 → **加入购物袋**（商品页上的「Check My Size / 查看我的尺码」会按你填的身材数据给推荐尺码，建议先填再买）；
2. 点**查看购物袋**，核对数量与规格；
3. **登录或注册**账号（见 [注册登录与站点语言设置.md](注册登录与站点语言设置.md)）；
4. 填**收货地址** → 选**支付方式** → 选**配送方式** → 用**优惠券**和**积分**；
5. 点下单，跳转支付页填卡信息 → **Pay** 完成。

收到款项后平台才开始处理订单，并发一封订单确认邮件到你注册邮箱。之后在「我的订单」里能看状态与包裹轨迹（见 [退货退款与物流查询.md](退货退款与物流查询.md)）。

## 二、支付方式：你看到的列表才是准的

公开的官方支付页列出的方式（**各站点开放项不同，以结账页当时显示为准**）：

| 方式 | 说明 |
| --- | --- |
| 信用卡 / 借记卡 | Visa、Mastercard、American Express 等；没列你那张卡也可以试，能否成功由发卡行决定 |
| PayPal | 跳转 PayPal 登录确认；没有 PayPal 账户也能走「用借记卡/信用卡支付」这条路 |
| 电子钱包 | 例如 GrabPay，开放给马来西亚、菲律宾、新加坡等站点 |
| 先买后付 | 例如 Atome（新加坡，分三期、零利息零手续费）、Afterpay（部分英语区站点，分四期免息，具体以结账页为准） |
| 钱包余额 | 账户里的 SHEIN Wallet 余额，可与别的方式组合（部分站点） |

两条实用口径：

- **平台不收你的卡号**：官方支付页写明 SHEIN 不收集你的信用卡号与个人信息，卡信息在支付环节直接提交给支付机构。
- **一单不一定只用一种**：券、积分、余额、卡可以叠着算，但**优惠券本身一单只能用一张**（见下一节）。

支付失败的排查见 [常见问题与排查.md](常见问题与排查.md)。

## 三、优惠券：四条规则决定你能不能用上

| 规则 | 官方口径 |
| --- | --- |
| 能叠几张 | **一单只能用一张优惠券码**，多张不能叠加 |
| 码怎么输 | 必须和收到的码**完全一致**，前后不能有空格 —— 建议直接复制粘贴 |
| 什么时候生效 | 结账页点了「Apply / 应用」才会改总价，不点就等于没用 |
| 哪些商品不参与 | 部分商品不适用券（清仓、特价、第三方卖家商品常见），券面上会写明 |

券的类型通常有三类：**满减券**（满 X 减 Y）、**折扣券**（按比例减）、**运费券**（抵运费）。运费券在 SHEIN CLUB 会员里是定期发放的（见下一节）。

**券什么时候到期**：在「我的 → 我的资产 / 优惠券」里能看到每张券的有效期与使用门槛，到期即作废、不补发。把促销推送关掉的人尤其要自己去看这一栏（见 [注册登录与站点语言设置.md](注册登录与站点语言设置.md)）。

## 四、积分：100 分 = 1 美元，最多抵 70%

积分（Bonus Points）是官方规则里写得最死的一块：

- **换算**：100 积分 = 1 美元（等值币种按站点换算）。
- **抵扣上限**：一单**最多用积分抵掉商品金额的 70%**，剩下 30% 必须用别的方式付。
- **要用出来**：结账页填了积分码要点 **Apply**，不点订单总价不会变。
- **什么时候到账**：**你确认收货之后**才入账。发货中、已签收但没点确认，积分都不在账上。
- **在哪看**：「我的 → 我的资产 / My Points」能看到总额与**过期时间** —— 积分是会过期的，别攒到过期。
- **会员有加成**：SHEIN CLUB 会员下单拿到的积分比非会员多（见下节）。

## 五、SHEIN CLUB 付费会员：先看权益，再决定开不开

SHEIN CLUB 是付费会员，条款口径如下（**价格与具体权益以你所在站点的会员页当时显示为准**）：

**权益三项**

1. **额外 5% 折扣**：适用于非促销商品，页面上带会员折扣标的才吃这个 5%。**不适用**于第三方卖家商品、礼品卡等虚拟商品、税费与运费，也**不适用于闪购/特价/其他定向折扣商品**（一旦商品进入闪购，5% 就不叠加了）。多数站点还给这个 5% 设了**每 31 天的累计上限**（如意大利/西班牙站条款写的是每 31 天不超过 465 欧元）。
2. **定期发运费券**：每 **31 天**发一批 SHEIN CLUB 运费券，用来抵实物订单的运费，可与其他促销券同用；券有有效期，过期不补。
3. **积分加成**：会员下单拿的积分高于非会员，多出来的部分与标准积分、正在进行的双倍积分活动叠加。

**四条限制**

- **年龄**：订阅需年满 18 岁。
- **付款方式受限**：会员费**不能**用 SHEIN 钱包、礼品卡或积分支付，只能用常规支付方式。
- **时长与叠加**：季度会员对应 93 天；**会员期不能累加购买** —— 当前会员期没到期就买不了新一期，只能等它到期再续。
- **权益认站点**：会员权益只在订阅时那个站点的订单、该站点对应的配送国家上生效；切了站点（见 [注册登录与站点语言设置.md](注册登录与站点语言设置.md)）就别指望会员还生效。

**续费与取消**：到期前平台会发邮件或 App 推送提醒。**要注销账号之前，必须先联系客服取消会员并拿到取消确认** —— 条款写明账号一旦删除，会员与全部权益自动终止，未用完的券和未兑换的奖励一并作废，且不退费。

**怎么判断值不值**：拿你近三个月的**订单次数 × 当时站点的运费**，和会员费比一比；订单少、或者每单都凑到了免运费门槛，就没必要开。会员费按下单时页面显示为准，中途涨价不影响你已订阅的这一期，降价也不给你补差价。
