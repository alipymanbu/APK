## 一、装不上 / 装完打不开

| 现象 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| 提示解析包出错 | 包是否下完整、机型架构是否匹配 | 重新下一次包；网盘那份的核对方式见 [下载与安装教程.md](下载与安装教程.md) |
| 提示存储空间不足 | 空闲空间 | 清出 200 MB 以上再装 |
| 提示已存在同类应用 | 手机上是否已装 SHEIN | 卸载旧版后装新版（账号在云端，不受影响） |
| 装不上、系统版本过低 | 设置 → 关于手机里的安卓版本 | 版本低于要求就先升系统，或换匹配的旧版本包 |
| 打开就闪退 | 缓存与权限 | 清应用缓存 → 重启手机 → 仍闪退则卸载重装 |
| 一直卡在启动画面 | 网络 | 换 Wi-Fi / 流量试一次；再清缓存重开 |

第三方安装包站对近期版本标注的最低要求是 **Android 6.0 起、建议 1 GB 内存以上**；本文对应的 13.3.8 安装包信息里写的是「需要支持安卓系统 5.2 以上」。两者不一致时，**以你手机上实际能不能装为准** —— 装得上就不用管这些数字，官方商店页的要求也会随版本调整。

## 二、页面打不开、加载不出来

1. **先切网络**：SHEIN 是境外站点，部分网络环境下直连会超时。换一个网络（或换流量）再刷一次，能打开就说明是网络侧的问题，不用改应用。
2. **站点可能选错了**：你当前站点的服务器对该网络不可达时，页面会一直转圈。切到另一个站点试试（怎么切见 [注册登录与站点语言设置.md](注册登录与站点语言设置.md)）。
3. **清缓存**：设置 → 应用 → SHEIN → 存储 → 清除缓存（**别点清除数据**，那会把你登出）。
4. **卡在人机验证**：如果一直弹滑块或验证页，换网络后重开；反复失败时清缓存再试。

## 三、支付失败

按命中率从高到低排：

1. **卡的境外支付权限没开** —— 打开发卡行 App，确认这张卡允许境外线上交易与 3D 验证（Secure/Verified by Visa、Mastercard ID Check 等），然后重试。
2. **发卡行风控拦截** —— 大额首笔、异地 IP 常被拦。等几分钟重试，或换一张卡。
3. **支付方式在你这个站点不开放** —— 结账页列出的才是可用的（各站点不同，见 [优惠券积分与会员怎么用.md](优惠券积分与会员怎么用.md)）。没列 PayPal / 钱包，就说明这个站点不提供。
4. **券或积分把金额抵到 0 或异常** —— 积分最多抵 70%，把券和积分去掉再付一次，看总价是否恢复正常。
5. **订单会自动取消**：付款失败的订单不会一直挂着，超时会自动取消，重新下单即可；会员费支付失败时要在账号里**手动取消那笔订单**，否则它占着位置（见 [优惠券积分与会员怎么用.md](优惠券积分与会员怎么用.md)）。

卡信息在支付环节直接提交给支付机构，SHEIN 侧不保存你的卡号 —— 所以**卡被扣了钱但订单没生成**时，先别急着重复付，去「我的订单」看是否其实已成功；确实没有，扣款一般会在发卡行侧按未完成交易撤销，时限由发卡行决定，有疑问找客服。

## 四、收不到验证码 / 确认邮件

- **邮箱注册**：先翻**垃圾邮件**与**广告邮件**分类，验证码邮件几乎总在那里；把 `shein.com` 加进发件人白名单再收一次。
- **确认填的是注册用的那个邮箱**：大小写与拼写错一位就发到别人那里去了。
- **短信验证码**：查拦截软件与短信分类（安卓的「信息 → 骚扰拦截」）；确认号码前缀选对了国家。
- **站点不支持你的号码**：有些站点只开放邮箱注册，页面上没有手机号那一项就是这种情况。
- **换邮箱/换号**：账号绑定信息在「我的 → 账户设置」里改，改完重新登录一次。

## 五、尺码怎么选才不踩雷

SHEIN 的尺码体系偏欧美，同一件衣服在不同系列之间也可能不同。你的操作顺序：

1. 商品页点 **Check My Size / 查看我的尺码**，填身高体重三围，让系统给推荐码；
2. **看该商品自己的尺码表**（每件商品都有，别用上一件的经验套这一件）；
3. **看买家评价里的实拍与「偏大/偏小」反馈** —— 这一层官方不会替你总结，是最有用的一手信息；
4. 拿不准就往大一号买，退换成本比来回寄一次低（退货规则见 [退货退款与物流查询.md](退货退款与物流查询.md)）。

## 六、中国大陆能不能用 SHEIN

这一点**官方没有统一口径，二手资料的说法也不一致**，两边都摆出来你自己判断：

- 有跨境电商行业媒体与物流追踪站点的说法是：SHEIN **不直接面向中国大陆消费者提供服务**，境内访问站点与直邮都受限，境内消费者多通过代购或其他跨境电商渠道买到；
- SHEIN 本身是面向境外市场的跨境电商平台，站点覆盖 150 个以上国家与地区（公司公开介绍口径），主要市场在北美、欧洲、中东、东南亚与拉美。

所以：**能不能下单，以你所在站点当时给不给配送、能不能付款为准** —— 在结账页填上你的实际收货地址，能提交就是能用，不能提交就是该站点不配送到你这里。别按任何一篇攻略的结论下死判断。

## 七、联系客服

- **应用内**：我的 → 设置/帮助 → **客户服务中心 / Customer Service**，有 24 小时在线客服与实时聊天入口；订单相关的问题从**订单详情页**发起，能自动带上订单号，比从首页问快得多。
- **邮箱**：官方公开过客服邮箱 `support@shein.com`，写邮件时把订单号、账号邮箱、问题描述与截图一并附上。
- **邮件/工单多久回**：按问题量浮动，没有承诺时限 —— 紧急的（没收到货、要过退货期）优先用在线客服，别等邮件。

已经过了退货期或质检被拒的争议，同一条路走客服申诉，材料就是 [退货退款与物流查询.md](退货退款与物流查询.md) 里那些「商品状态要求」的对照项。
