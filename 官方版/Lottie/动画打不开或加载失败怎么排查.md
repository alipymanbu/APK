# 动画打不开或加载失败怎么排查

> 按现象逐条对：选了文件没反应、图片缺一块、网址加载失败、播着卡顿，各自是什么原因、怎么处理。

## 一、排查前先做的一件事

先播一个**内置动画**。内置的能播，说明应用本身与手机的渲染环境没问题，问题一定出在你那个文件或那条网址上；内置的都不播，才是应用安装的问题——重装一次（见 [下载与安装教程.md](下载与安装教程.md)），或换一台手机试同一个文件做对照。

## 二、选了本地文件，没反应 / 白屏

按可能性从高到低：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点了文件，回到界面什么都没发生 | 扩展名被改过（下载工具加过后缀）或根本不是 Lottie 文件 | 确认文件名以 `.json` 结尾；用文本编辑器打开能看到 `{` 开头的大段 JSON 才对 |
| 打开是一段报错或空白 | 文件是网页存下来的，不是动画本体 | 重新拿真正的动画文件，别用「网页另存为」 |
| 动画出来了但**图片位置是一块空白** | 图片没跟着 json 走 | 见下一段 |
| 一直转圈 | 文件特别大、或手机在后台被限制了 | 等几秒；不行就杀掉应用重开，换个小文件对照 |

**图片缺失**是本机加载最常见的一种：Lottie 动画是矢量为主，但有些动画里嵌了位图（比如导出时把 Illustrator 图层输出成了图片）。这种情况下图片**不在 json 里**，官方给的两种解法是：

1. 把 json 与全部图片打成一个 **zip**（图片文件名不能改），加载那个 zip——本地和网络两种方式都支持；
2. 或者按官方约定把图片放到指定的图片目录，由播放端去读。

你拿到的只有一个孤零零的 `.json`，图片位置空白就是这个原因，去找对方要打包好的 zip。

## 三、网址加载失败

1. **先在手机浏览器里打开这条地址**：能直接下载、或直接显示 JSON 文本 = 地址本身没问题；打开是个介绍页、或跳到登录/网盘首页 = 地址类型不对，按 [本地动画和网络动画怎么加载播放.md](本地动画和网络动画怎么加载播放.md) 第三节重新取直链。
2. **确认有网**：网络地址的动画是当场去取的，断网就取不到。
3. **看链接是否带临时签名**：很多网盘、CDN 的下载地址带会过期的参数，你昨天存的地址今天可能已经失效，重新取一次。

## 四、播着卡、掉帧

先开右上角的渲染图表看是不是真的掉帧（参考线含义见加载篇第四节）。确认卡顿后：

- **遮罩与蒙版（masks / mattes）是性能开销最大的一类**，官方明确写过这一点，而且开销与「被遮罩区域的交集大小」成正比——遮罩越大越费。这是动画文件本身的设计问题，你在应用里改不了，只能让对方简化。
- 同一个文件在不同手机上表现不同：拿一台更高端的手机对照，能区分是「文件太重」还是「这台手机带不动」。
- 换一个内置的简单动画对比，内置的流畅而你的卡，问题在文件；内置的也卡，问题在设备。

## 五、有开发者反馈的一类报错

如果是把动画接进自己应用的开发者，遇到 `Missing values for keyframe` 这类解析报错，有公开经验贴指出原因是**播放端的 Lottie 库版本低于 3.0**，而 Bodymovin 5.5 之后的导出格式做了优化，旧库读不了新文件——升级依赖版本即可（这条来自开发者社区的单一经验分享，不是官方文档口径，仅供参考）。

如果你只是拿手机应用播现成的动画文件，通常接触不到这类报错；碰到时按上面的思路确认文件与播放端的年代是否对得上。

## 六、还没解决时

- 换一个内置动画、换一台手机、换一个动画文件，三次对照基本能把问题定位到「文件 / 网址 / 设备」三者之一。
- 动画文件本身的格式、扩展名与素材打包规则，见 [动画JSON格式与素材哪里找.md](动画JSON格式与素材哪里找.md)。
- 应用没装上、装的不是这份包，回 [下载与安装教程.md](下载与安装教程.md)。
