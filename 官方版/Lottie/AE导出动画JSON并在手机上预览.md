# AE导出动画JSON并在手机上预览

> 给要自己做动画的人：在 After Effects 里装 Bodymovin、导出成 JSON、再丢进手机里预览的完整链路与几个必踩的坑。

## 一、要装的是 Bodymovin 插件

导出靠 **Bodymovin**——一个给 Adobe After Effects 用的插件，最早由 Hernan Torrisi 写的，Lottie 官方在它基础上扩展出了安卓、iOS、网页等各端的播放能力。官方文档给的安装步骤是：

1. **先把 After Effects 关掉**；
2. 装 **ZXP Installer**（地址：[aescripts.com/learn/zxp-installer](http://aescripts.com/learn/zxp-installer/)）——它用来安装 AE 插件的 `.zxp` 包；
3. 从 [github.com/airbnb/lottie-web 的 extension 目录](https://github.com/airbnb/lottie-web/tree/master/build/extension) 下载最新的 `bodymovin.zxp`；
4. 打开 ZXP Installer，把下载的 `.zxp` 拖进窗口里装完；
5. 重新打开 After Effects，在菜单 **Window > Extensions** 里能看到 **Bodymovin**，就是装好了。

LottieFiles 也出了一款 AE 插件，额外带真机测试与渲染图表，装哪个都行——但官方文档的设置说明是按 Bodymovin 写的，下面几节都按它来讲。

## 二、导出设置里最要紧的四个开关

打开 Bodymovin 面板，选中合成，点合成旁边的齿轮进设置：

| 设置 | 怎么选 | 原因 |
| --- | --- | --- |
| **Glyphs**（字形） | 勾上 = 文字转成形状导出，不依赖字体，但**只能渲染动画里实际用到的那几个字**；不勾 = 保留文本，由播放端提供字体文件 | 只播固定文案选勾；要改文字就别勾，否则换字就缺字 |
| **Hidden**（隐藏图层） | 表达式指向隐藏图层时必须勾，否则动画加载不出来 | 勾了会把所有隐藏图层一起导出，文件变大 |
| **Assets 里的图片选项** | 有位图时，要么让图片进 images 文件夹（别改名），要么勾进 json | 图片没跟着走，手机上就是空白一块 |
| **Demo** | 勾上会额外生成一个 `demo.html` | 在电脑浏览器里先验一遍，省得来回传手机 |

另外几个选项按需：`Split` 把长合成切成多个 json；`Standalone` 把播放器和动画打成一个文件；`Guided` 导出参考图层（表达式指向它们时才需要）。

## 三、导出前先避开不支持的东西

这是导出后「效果不对」的最大来源，两边文档（Airbnb 官方文档与 LottieFiles 的接入文档）都写到了：

- **表达式与效果菜单里的效果，一概不支持**（官方原话）。要用 wiggle 之类，先导出前用「关键帧辅助 > 将表达式转换为关键帧」烘成关键帧。
- **调整图层、摄像机、灯光图层不会被导出**；3D 旋转只部分支持（Z 轴位移通常没问题，完整 3D 旋转常常不行）——这几条来自 LottieFiles 的接入文档。
- **亮度遮罩（Luma Matte）在安卓端不支持**（官方的特性支持表里标的是不支持），要用遮罩就选 Alpha 遮罩。
- **遮罩与蒙版越大越费**：官方提示 alpha 遮罩的性能开销与遮罩覆盖的面积相关，能盖小就盖小。这条直接决定了你在手机上会不会掉帧，见 [动画打不开或加载失败怎么排查.md](动画打不开或加载失败怎么排查.md) 第四节。
- **渐变与图层样式**是常见的导出异常项，看到颜色变成一块实色，先回头查这两处。

拿不准的直接查官方的**特性支持表**（[lottie.airbnb.tech 的 Supported Features 页](https://lottie.airbnb.tech/#/supported-features)），它按 Android / iOS / Web 逐项列出支持与否，做之前扫一遍能省很多返工。

## 四、合成尺寸与帧率：按手机来，别按视频来

- **尺寸**：Lottie 会把 After Effects 里的 px 当作安卓的 dp 来渲染，为的是同一份动画在各尺寸屏上大小一致。所以别按 1920×1080 的视频思路做合成——官方给的参考是接近主流手机 dp 尺寸的量级（例：约 411×731 px）。做出来在手机上显得特别大或特别小、或者被裁，根子都在这里的画布尺寸。
- **帧率**：24 fps 文件最小、30 fps 是手机与网页的常规选择、60 fps 更顺但文件大约是 30 fps 的两倍（帧率这条来自 LottieFiles 的文档，不是 Airbnb 官方口径）。拿不准就 30 fps。

## 五、把文件弄小一点

官方在「保持简单」那节给的思路：路径关键帧动画最吃体积（每个顶点每个关键帧都要存一份数据），能用父子级关系解决的就别复制关键帧；自动描摹、wiggler 这类「每帧一个关键帧」的手法会让 json 暴涨；隐藏图层、深层嵌套合成也一样。总之——**能用简单图层做出来的动画，别用特效堆**。

## 六、导到手机上看

1. 导出后先把 `demo.html` 在电脑浏览器里过一遍，能排除一半问题；
2. 把 json（有图片就连同 images 文件夹打成 zip）传到手机，按 [本地动画和网络动画怎么加载播放.md](本地动画和网络动画怎么加载播放.md) 加载；
3. 有卡顿就开渲染图表看哪一层超了 16.66 ms 那条线，逐层对回 AE 里简化；
4. 选了文件没反应、图片空白，按 [动画打不开或加载失败怎么排查.md](动画打不开或加载失败怎么排查.md) 逐条对。

动画文件本身是什么结构、扩展名怎么分，见 [动画JSON格式与素材哪里找.md](动画JSON格式与素材哪里找.md)。
