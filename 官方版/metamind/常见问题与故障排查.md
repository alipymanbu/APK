## 一、安装类

**Q：安装时提示「解析包时出现问题」**
多为 APK 下载不完整或文件损坏。重新下载一次（[下载与安装教程.md](下载与安装教程.md) 里有获取步骤），下载完核对大小接近 42.44M 再装。

**Q：点安装后提示「未知来源」不允许安装**
系统默认禁止浏览器/文件管理器安装 APK。按弹窗进入对应来源的授权开关允许一次即可，装完可关掉。

**Q：安装成功但打开闪退**
先确认系统是否满足安卓 5.2 以上；再试「设置 → 应用 → 清除缓存」后重开。仍闪退时重启手机再试，个别机型需在系统电池设置里允许后台运行。

## 二、登录类

**Q：登录不上 / 登录后内容是空的**
最常见的原因是**登错了账号**：换过手机号、或曾用不同方式注册，都会进去看到一个空库。退出后换另一种登录方式试。官方渠道也有用户反馈过付费后次日登录异常、联系客服无回应的情况——若你已充值且持续登录不上，通过应用内客服入口留下订单信息跟进，处理周期以官方为准。

**Q：换新手机后记录都没了**
不是丢了，多半是没登录原账号或同步没跑完。登录原账号、联网等待同步完成再看；同步行为见 [图片OCR与多端同步使用说明.md](图片OCR与多端同步使用说明.md)。

**Q：卸载重装后怕记录丢**
记录挂在云端账号上，重装后登录同一账号即可恢复。重装前若想留一份安装包，从 [metamind 安装文件资源（夸克网盘）](https://pan.quark.cn/s/59a209cb5a04) 转存下载，不必去别处再找包。

## 三、录音与转写类

**Q：录完一直显示转写中 / 上传中**
转写与上传都走网络。弱网下会排队；1.3.4 版支持离线分片上传与断点续传，重连后会自动续传未完成部分。长时间不动就退出重进看进度，仍卡住则等网络良好时再开应用触发续传。

**Q：转写错误率高**
按顺序排查：麦克风权限是否给足 → 现场是否嘈杂、说话人是否离得远 → 是否方言口音重（官方称支持部分方言，重口音仍会掉准确率）。改收音条件比改设置有效。

**Q：边播边录录出来是静音**
部分机型对内部录音有系统限制。检查应用的录音权限、系统「麦克风/音频」隐私开关是否放行；仍静音说明该机型不支持此路径，改用外部收音（外放+录音）替代。

**Q：生成的会议纪要和实际有出入**
纪要由转写稿提炼，转写错它跟着错。先校正转写稿里的人名与关键数据，再重新生成一次。

## 四、图片与检索类

**Q：图片里的字搜不到**
先确认 OCR 已完成（图片详情里能看到识别文本再搜）；识别文本有错字时，用原图里的正确写法再问一次。检索技巧见 [AI记忆问答与检索使用教程.md](AI记忆问答与检索使用教程.md)。

**Q：问答说「没找到」，但明明记过**
按顺序确认三件事：那条内容当时是否记成功 → 是否同步完成（另一端/服务端检索依赖同步）→ 问题是否给了时间、场景等线索。三者都正常仍找不到，等同步完成后重试。

## 五、会员与账号类

**Q：怎么收费的**
应用为免费下载，部分能力走应用内购买（官方资费标注为应用内充值购买），具体套餐与价格以应用内「我的 / 会员中心」当时显示为准，网上查到的价格不作数。

**Q：买了会员没生效**
先重启应用、退出重登看是否到账；扣费已发生但超过 24 小时仍未生效，凭订单号联系支付渠道（微信/支付宝/苹果）与应用内客服核对。

**Q：怎么取消自动续费**
- 微信支付：微信「我 → 服务（支付）→ 钱包 → 支付设置 → 自动续费」。
- 支付宝：支付宝「我的 → 设置 → 支付设置 → 免密支付/自动扣款」。
- iOS：iPhone 设置 → 顶部 Apple ID → 订阅，选中后取消。

注意在续费扣款前 24 小时以上取消，临期取消当期仍会扣费。

**Q：数据隐私在哪看**
应用的用户协议与隐私政策入口在应用内登录页/设置里，涉及你记的录音、图片、笔记的存储与使用条款都以官方当前版本为准，装好后自己过一遍再决定记什么。

**Q：想注销账号、删除数据**
注销入口一般在账号中心/设置里（以你这版应用内实际路径为准）。动手前先想清楚两件事：**注销不可恢复**——账号里的录音、笔记、会员时长会一并清掉，重注册也是全新账号；**在会员期内注销**等于放弃剩余时长。要留的记录先导出（转写稿可导出 Word，见 [录音转写与会议纪要使用教程.md](录音转写与会议纪要使用教程.md)）再注销。处理时限与数据删除范围以官方隐私政策当时写明的为准。
