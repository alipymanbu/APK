# SeekMusic 锁屏后音乐停止怎么办

> 本篇解决一个高频问题：SeekMusic（觅音）一切后台或锁屏就没声。原因几乎都在手机的省电策略，本篇按「先查两个最简单的 → 通用开关 → 品牌专属设置」的顺序给一遍完整排查。

安卓和各手机系统都会为省电限制应用在后台活动，音乐应用被限制后，锁屏或切后台就可能停。SeekMusic 首次使用的教程里也把「设置电池优化」列为装好后的第一步，可见这个问题是使用前的必修项。下面按顺序排查。

## 一、先确认两件最简单的

1. **没有从多任务里划掉 SeekMusic**：从最近任务列表把应用卡片划掉等于强制停止，正在播的歌会立刻停。挂着歌听的时候，切到别的应用可以，划掉卡片不行；
2. **装完时做过电池优化**：没做的话先补上，入口见[下载与安装教程.md](下载与安装教程.md)第五节。

## 二、通用安卓开关（各品牌都先看这里）

设置 → 应用管理 → SeekMusic → 电池 → 选「无限制 / 不允许优化」。

这是所有安卓机型都有的基础开关，默认的「优化」档位就可能在你锁屏后暂停后台应用，改成无限制是第一步。

## 三、各品牌专属的省电策略

不少品牌在系统里另有一层更严的后台管理，只改第二节的开关经常不够：

| 品牌 | 设置路径（以手机实际显示为准） |
| --- | --- |
| 华为 / 荣耀 | 设置搜索「应用启动管理」→ 关闭 SeekMusic 的自动管理 → 勾选允许自启动、允许后台活动；再搜索「电池优化」→ 所有应用 → SeekMusic → 设为不允许；多任务界面下拉 SeekMusic 的卡片加锁 |
| 三星 | 设置 → 应用程序 → SeekMusic → 电池 → 选「无限制」；设置 → 电池 → 后台使用限制 → 把 SeekMusic 移出「睡眠应用程序 / 深度睡眠应用程序」列表 |
| 小米 / OPPO / vivo 等 | 各系统都有独立省电策略：在设置里搜索「省电策略」「自启动」或「电池」，给 SeekMusic 开允许后台运行 / 无限制；各品牌的具体入口可查 [dontkillmyapp.com](https://dontkillmyapp.com) |

各品牌菜单名称随系统版本变动，上面是各官方支持页给出的路径，以你手机上实际显示的为准。

两个可以顺手检查的点：

- **省电模式**（低电量模式）开着时后台更容易被限制，锁屏听歌的时段可以关掉；
- **华为机型**还可在「电池 → 更多电池设置」里打开「休眠时始终保持网络连接」，避免灭屏后断网导致在线播放中断。

## 四、还不行的话

把常听的歌下载到本地再锁屏听，对后台的要求最低，也不受灭屏断网影响，下载方法见[歌曲下载和歌词保存方法.md](歌曲下载和歌词保存方法.md)。

另外要区分「设置问题」和「应用取舍」：SeekMusic 没做通知栏播放控制，这是开发者的明确答复，所以锁屏界面同样不会有播放控制按钮，想切歌得回到应用里操作 —— 这不是你的设置出了问题。其他常见现象的排查见[常见问题排查.md](常见问题排查.md)。
