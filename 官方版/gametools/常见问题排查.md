# GameTools 常见问题排查

> 本篇把用 GameTools 时最容易卡住的几类问题放在一起：改完不生效、启动报错、提示 Gvas is null、画面异常、发热，对应各自的检查顺序。

## 一、改了画质，游戏里没生效

按这个顺序检查：

1. **保存配置时游戏是不是还在后台** —— 必须先彻底关掉游戏（从后台任务里划掉），再保存配置、启动游戏；
2. **有没有重新启动游戏** —— 配置只在启动游戏时写入，改完直接切回正在运行的游戏是看不到效果的；
3. **进了游戏之后又动了画面设置** —— 修改后别再碰游戏内的画面设置选项，动了可能被改回去；发现被改回就退出游戏，重新保存一遍；
4. **模式不合适** —— 分辨率怎么都改不动时，手机换 EC 模式试试（平板反过来选 UC 模式），换完重新保存；
5. **用过其他画质修改工具（GFX Tool 等）** —— 这类工具写的都是同一份游戏画面配置，会互相覆盖。这是这类工具通用的经验：先彻底关游戏，把游戏内画面设置恢复成默认，关掉其他同类工具的开机自启，再用 GameTools 改一遍。

游戏内画面设置里帧率一行不显示「当前」字样，不一定代表失败，先进一局看实际表现（详见[画质与帧率修改步骤](画质与帧率修改步骤.md)第四节）。

### 改完帧率，游戏里还是低帧

软件侧检查都过了还是锁帧，多半是设备侧在压帧 —— 手机厂商的官方说明列过这些常见原因，逐个对照：

| 原因 | 处理 |
| --- | --- |
| 机身发热，系统主动降频锁帧 | 静置降温后再玩，别边充电边玩，需要时加散热背夹 |
| 省电模式开着 | 下拉状态栏关掉省电模式 |
| 性能模式 / GT 模式没开 | 到手机的游戏助手或电池设置里打开 |
| 录屏开着 | 录屏会加重负载导致锁帧，关掉再试 |

## 二、启动游戏报错 / 卡屏 / 画面放大缩小

1. 打开 GameTools 的配置界面，滑到最下方，点**文件修复**；
2. 勾选其中的文件类型（UC、SAV 等，以界面列出的为准），点确定；
3. 重新保存配置并启动游戏。

个别机型用 EC 模式会出现卡屏或画面比例异常：先把游戏切到后台再切回来试一次，还不行就换 UC 模式重新保存。

### 想恢复游戏原本的画质

配置页里有**还原画质**入口，一键把游戏恢复成原生默认画面设置，不用手动逐项改回去。改乱了、或者不想再用修改后的画质了，用它收尾最省事。

## 三、提示「Gvas is null」

这是读取游戏配置数据失败时的一类提示，GameTools 帮助中心把它单独列了一条。按顺序试：

1. 确认游戏版本在支持范围内（游戏更新大版本后常出现这类不兼容，等适配）；
2. 用**文件修复**处理一遍再改；
3. 完全退出 GameTools（划掉后台）重新进。

都试过仍报错，可在应用的帮助中心联系在线客服反馈，描述时带上游戏版本号。

## 四、改完帧率，设备发热明显

帧率和画质拉高之后功耗上升是正常代价，不是故障。几个缓解办法：

- 低配设备别直接顶到最高档，先往下降一两档找平衡；
- 长时间游戏时留意机身温度，烫手就降档休息；
- 应用介绍里带温度过高自动限帧的温控机制，但别指望它兜底，以实际表现为准。

## 五、账号风险自己掂量

GameTools 改的是游戏在本地的配置数据。官方介绍称它不修改游戏核心数据，但「用第三方工具改游戏参数」这件事本身，和部分游戏的用户协议是有冲突空间的 —— 拿不准自己常玩那款的态度，就先想清楚再决定用不用，或者用小号先试。

## 六、设置里的「操作模式重置」「多用户适配」是干什么的

都在设置页里：

- **操作模式重置**：进入游戏配置时选过操作模式（如 File 模式），选错或想换，从这里重置后重新进；
- **多用户适配**：显示当前工作的用户空间（如 USER-0）。游戏装在应用分身、第二空间里扫不到时，来这里看看用户空间对不对。

改完操作模式后记得重新走一遍授权和保存配置的流程，见[画质与帧率修改步骤](画质与帧率修改步骤.md)。
