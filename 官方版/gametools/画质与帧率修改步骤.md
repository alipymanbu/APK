## 一、开始前先确认两件事

1. 要调画质的那款游戏已经装在设备上，并且 GameTools 首页能列出它（列不出来先看[支持哪些游戏](支持哪些游戏.md)）；
2. 游戏已经完全关闭，包括后台 —— 保存配置时游戏还在运行，改完大概率不生效。

## 二、修改画质与帧率的完整步骤

以和平精英为例（其他支持的游戏流程相同）：

1. 打开 GameTools，在首页点要调整的游戏图标；
2. 第一次进入会提示授予内存权限，操作模式选 **File 模式**，完成后点确定；
3. 授权后回到首页，再点一次游戏图标，进入配置界面；
4. 选择配置（档位以你手上的版本实际显示为准，下表是新版本软件介绍里列出的档位）：
   - **模式**：手机选 UC 模式，平板和需要改分辨率的设备选 EC 模式（两种模式的差别见下一节）；
   - **画质**：流畅 / 均衡 / 高清 / HDR 高清 / 超高清 / 极清共六档，按设备性能选；
   - **帧率**：60 / 90 / 120 / 144 / 165 等档位可选；设备硬件不支持的档位会置灰选不了，能选哪几档以软件里实际亮起的为准；
5. 基础配置之外，**高级配置**里还有这些可改项：
   - **分辨率**：480P / 720P / 1080P / 伪 2K / 2K / 4K 多档；
   - **画面风格**：经典 / 鲜艳 / 写实 / 柔和 / 电影五种滤镜；
   - **阴影、抗锯齿、游戏特效**：可单独开关；
6. 音效与操作相关的进阶项（音质编辑器、灵敏度超频、平板超广角、亮度提升）在配置页或侧边菜单里，按需进；
7. 点**保存配置并启动游戏**，游戏会被拉起，游戏内的画面设置就跟着这份配置走了。

操作模式除 File 外另有其他选项（如 DocumentFile、Shell），普通安装直接用 File 模式即可，用不到的选项不用管。

## 三、UC 模式和 EC 模式怎么选

两种模式改的是同一套配置，但限制不同：

| | UC 模式 | EC 模式 |
| --- | --- | --- |
| 适合谁 | 手机 | 平板、折叠屏，或想改分辨率的设备 |
| 改分辨率 | 部分设备改不了 | 能改，但被游戏锁分辨率的机型可能改不动 |
| 音质 | 可正常调 | 会锁定为「高」，改不了 |
| 已知问题 | 少 | 个别机型启动游戏后卡屏、画面放大或缩小 |

拿不准就用 UC 模式先试，分辨率改不动再切 EC 模式。切换模式后要重新保存配置再启动游戏。

## 四、保存之后：怎么算生效

- 启动游戏后进设置页看画面选项，游戏内的参数已经跟着配置变化就算生效；
- 有的游戏版本改完帧率后，画面设置里的帧率一行不显示「当前」两个字，这不代表失败，进一局实际体验即可；
- 期间不要再去动游戏内的画面设置，动了可能被改回去；
- 想换回游戏默认画质，把游戏彻底关掉，回 GameTools 重新保存一遍配置再启动。

改完不生效、进游戏报错的排查顺序，见[常见问题排查](常见问题排查.md)。
