## 一、这份安装包对应哪一版

Muniverse 是手机端的全球 K-POP 粉丝平台，客户端分安卓与 iOS 两条线。本页这份是**安卓安装包（APK）**，装不到 iPhone 上。下面先给出这份包的准确身份，装完可以在手机的应用信息里对照。

| 项目 | 内容 |
| --- | --- |
| 应用名 | Muniverse |
| 版本 | v1.0.3 |
| 包名 | `com.tnk.muniverse` |
| 安装包大小 | 103.21M |
| MD5 | `034D09BDD96BF957E5E297F399B85E38` |
| 收录日期 | 2026-09-23 |

官方商店里的版本号会不断往上走（iOS 端就出现过 1.0.10 这类版本），**版本号对不上不代表装错**：本页这份固定在 v1.0.3，主体功能一致，只是不含后续的小修小补与新增活动入口。想要最新版，去官方商店页看当前版本号。

## 二、装之前先确认三件事

1. **系统**：安卓手机或平板。官方没有在商店页写明最低安卓版本，实际能不能装以 Google Play 页面对该机型的标注为准；系统版本过旧时，即便装得上，也可能在登录环节出问题。
2. **空间**：安装包 103.21M，装完解压后占用会明显大于这个数字，建议额外留出几百 M 的可用空间；存储吃紧是这类内容型应用闪退的常见原因。
3. **网络**：首次打开必须联网完成登录。如果连不上，先换 Wi-Fi 与移动数据各试一次，排除单一网络的问题。

## 三、安装步骤

1. **取包**：打开 [Muniverse 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6c67a486f856)，转存到自己的网盘后下载到手机。直接在网盘 App 里下载比在电脑上下了再传手机省事。
2. **允许安装未知来源的应用**：安卓原生系统的路径是「设置 → 应用 → 特殊应用权限 → 安装未知应用」，找到你用来打开 APK 的那个应用（文件管理器或浏览器）并授权；国产系统（MIUI、ColorOS、OriginOS、HarmonyOS 等）一般会在你点击 APK 时直接弹窗引导，按提示走即可。华为鸿蒙较新的版本还会多一步「纯净模式」校验，需要先关闭纯净模式。
3. **点击 APK 安装**，等待进度条走完，桌面出现 Muniverse 图标。
4. **核对包名**：在「设置 → 应用 → Muniverse → 应用信息」里确认包名为 `com.tnk.muniverse`。这一步能挡掉绝大多数装错包的情况，尤其是从非官方渠道拿到安装包时。

## 四、第一次打开要做的四件事

按下面顺序做，能少走弯路，因为语言不通时连注册入口都不好找：

1. **先切语言**。打开右上角的菜单，底部会列出可选语言，选中文或英文后再进行后面的操作。
2. **注册或登录**。支持直接用第三方账号登录，不需要单独记一套密码 —— 具体可选哪几种见 [注册登录与账号设置.md](注册登录与账号设置.md)。
3. **选至少一个本命艺人**。这一步是必须的，不选后面首页与投票区基本是空的。
4. **放开后台限制**。国产系统默认会限制后台活动，结果是投票提醒、直播开播提醒收不到。路径通常在「设置 → 应用 → Muniverse → 电池/省电策略」，改成「不限制」或加入白名单。

## 五、装不上、装完打不开

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 安装包下载不完整，或传输过程损坏 | 重新下载；下载完先核对 MD5 是否为 `034D09BDD96BF957E5E297F399B85E38` |
| 提示「应用未安装」 | 手机上已装过同一包名的其他版本，签名不一致 | 先卸载旧版本再装这一份；卸载会清掉本地数据，但账号数据跟着第三方登录走 |
| 装完点开就闪退 | 系统版本过旧、存储空间不足、或与同机上的加速/改机类工具冲突 | 先清出存储空间并重启手机；仍不行按 [常见问题与排查.md](常见问题与排查.md) 逐项排查 |
| 一路卡在白色启动页 | 网络不通，或该地区访问受限 | 换网络重试；确认网络能正常打开官方站点 `https://www.muniverse.io` |
| 安装按钮点不动 | 系统禁止未知来源 | 回到「特殊应用权限 → 安装未知应用」重新授权 |

装完能正常登录，就进入 [注册登录与账号设置.md](注册登录与账号设置.md) 把账号和本命艺人配好，之后才是投票和看内容。
