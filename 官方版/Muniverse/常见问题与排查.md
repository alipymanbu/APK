## 一、先做通用四步

Muniverse 用起来最容易卡住的是登录、广告不给点券、投票入口消失和直播播放这几处。本篇先给一套不丢数据的通用处理四步，再按现象逐项对应闪退、登录、签到、投票、播放与通知问题，适合遇到异常先自查、不想直接找客服的用户。

下面这四步不分现象都能先做一遍，能解决相当一部分问题，而且不会清掉账号数据：

1. **完全退出再打开**：在多任务界面把 Muniverse 划掉，重新进入；
2. **切换网络**：Wi-Fi 与移动数据互切一次；
3. **清缓存**：「设置 → 应用 → Muniverse → 存储 → 清除缓存」。**不要点「清除数据」**，那会退出登录；
4. **重启手机**：模拟器用户重启模拟器。

做完仍然异常，再按下面的具体现象查。

## 二、打开就闪退或卡在启动页

| 可能原因 | 判断与处理 |
| --- | --- |
| 存储空间不足 | 查看剩余空间，这类内容型应用需要留出足够缓存空间；清出空间后重启再试 |
| 系统版本过旧 | 到系统设置里检查更新；应用新版本往往要求更高的系统版本 |
| 安装包损坏或不完整 | 卸载后从 [Muniverse 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6c67a486f856) 重新下载，装前核对 MD5 是否为 `034D09BDD96BF957E5E297F399B85E38` |
| 同机装了改机 / 虚拟定位类工具 | 这类工具会干扰应用的运行环境，临时关闭或卸载后重试 |
| 网络不通 | 卡在启动页多数是首屏请求超时，换网络并确认浏览器能打开 `https://www.muniverse.io` |

## 三、登录不上或登录后没数据

- **某个第三方登录无反应**：官方曾经专门公告过 X（原 Twitter）登录异常，遇到这类情况**先换另一种登录方式**试一次，能登进去说明账号没问题，是那一方平台的故障。
- **登进去发现本命艺人、历史都没了**：几乎一定是**登成了另一个第三方账号**。Muniverse 没有独立的账号密码，登录哪个第三方账号就进哪个账号，切账号不会有任何提示。
- **不记得当初用哪个账号注册的**：回忆首次登录时点的那个按钮；实在想不起来，用客服邮箱 `support@muniverse.io` 描述情况，说明可能的注册时间与使用的艺人。

## 四、看广告拿不到 Ad Lumy

1. **等一两分钟再刷新**：广告平台的回传有延迟，明细页不是实时写入；
2. **确认是在应用内看的**：网页版没有看广告的入口，在网页上刷不出点券；
3. **当天机会用完了**：广告机会有每日上限，用完之后再看也不会计数，等次日刷新；
4. **模拟器环境**：在模拟器里看广告失败的比例明显更高，想看广告建议用真机。

Lumy 的种类与有效期规则见 [Lumy积分怎么获得和使用.md](Lumy积分怎么获得和使用.md)。

## 五、签到相关

- **显示已签到但没加 Lumy**：先看发放明细，再看余额 —— 常有「已发放但恰好过期」的错觉；
- **时间不对导致签到日期错乱**：手机或模拟器时间被手动改过就会出现这种情况，改成自动获取网络时间；
- **过了零点还能补签吗**：签到按天重置，没有补签入口。

## 六、投票失败或票数不动

| 现象 | 处理 |
| --- | --- |
| 投票入口消失了 | 该轮投票已结束。事前投票按韩国时间周四 11:00 截止（北京时间 10:00），过点即关 |
| 提示点数不足 | 核对消耗种类：事前投票用 Ad Lumy，M PICK 类用 Free Lumy，直播投票用 Ad Lumy 或 Gold Lumy |
| 提交后排名不变 | 下拉刷新；计分与展示有延迟，不一定是没投上 |
| 直播投票找不到入口 | 直播投票只在节目直播期间开放，且直播取消时不进行 |
| 想退款 | 官方口径是投票完成后不支持退款与取消，这一条无法通融 |

投票规则与时间见 [怎么给偶像投票.md](怎么给偶像投票.md)。

## 七、直播与视频

- **黑屏、只有声音**：先降一档清晰度，再切换网络；仍不行换网页端打开同一场内容，用来判断是网络还是客户端问题；
- **一直转圈**：避开开播头几分钟的高峰；有观众反馈过开场处短暂卡顿，之后恢复正常；
- **找不到字幕开关**：字幕是否提供取决于该场内容本身，演唱会类内容经常没有字幕，不是设置问题；
- **回放不见了**：直播回放是否保留、保留多久由各场次自行规定，以活动页说明为准。

## 八、收不到投票或开播提醒

基本都是系统把应用冻结了。到「设置 → 应用 → Muniverse」里检查两项：**通知权限是否打开**；**电池 / 省电策略是否设为「不限制」**。国产系统还有「自启动」开关，一并打开。具体路径见 [下载与安装教程.md](下载与安装教程.md) 第四节。

## 九、需要找官方时

官方支持邮箱：`support@muniverse.io`。一次把信息给全，能省一轮往返：

- 登录用的第三方账号（哪种方式登录的）；
- 出问题的页面与操作步骤；
- 报错截图或提示原文；
- 涉及付款的，附上支付凭证与订单号。

要确认自己用的是不是官方客户端、有没有装到来路不明的改动包，看 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
