## 一、账号体系是什么样的

Muniverse 没有独立的手机号密码体系，走的是**第三方账号直接登录**：注册与登录是同一个动作，用什么第三方账号登进去，账号就归到那个人名下。对读者来说有两层意思：一是省事，不用再记一套密码；二是**换设备时只要还能登同一个第三方账号，数据就在**。

可选的方式（按官方登录页列出）：Google、Facebook、Kakao、Line、Apple、Naver、X（原 Twitter）。

## 二、七种登录方式怎么挑

| 登录方式 | 适合谁 | 注意点 |
| --- | --- | --- |
| Google | 有 Gmail、平时用安卓原生服务 | 国内网络环境下可能连不上，需要先解决网络问题 |
| Apple | iPhone / iPad 用户 | 隐藏邮箱功能可能影响后续用邮箱找客服，介意就选「共享我的邮箱」 |
| Kakao / Naver | 常驻韩国的用户 | 需要韩国手机号，境外用户基本用不上 |
| Facebook | 有 FB 账号的境外用户 | 账号被风控时会连带登不上 |
| Line | 日本、台湾、泰国用户 | 台湾用户较常用 |
| X（原 Twitter） | 追星原有社交账号就在 X 上的用户 | 官方曾专门发过「X 登录异常」公告，遇到时换其它方式登 |

**选择建议**：日常在国内使用、又不想被单一平台卡住，优先选一个你**长期不会弃用**的账号。追星场景里 X 账号最普遍，但它出过登录异常，所以不建议把 X 当作唯一入口 —— 至少心里清楚还有哪条退路。

## 三、注册后必须做的两件事

### 1. 至少选一个本命艺人

首次登录会引导你选择关注对象，**这是一道必答题**：一个都不选，首页推荐、投票区、直播提醒都不会有内容。之后可以在「My / 我的」里增删，选择的艺人数量不影响投票权，只影响你看到什么。

### 2. 切换界面语言

路径是**右上角菜单 → 底部语言列表**，选中文或英文。语言只有界面展示的作用，改语言**不会**改变账号归属，也不会清掉已选的艺人。

## 四、推荐好友制度（免费拿 Lumy 的正式途径）

这是官方在做的活动之一，规则明确，值得单独说：

- 注册时在「推荐人」一栏填入朋友的**邮箱地址**（不是昵称），也可以留空；
- 朋友的注册流程走完，**推荐人和被推荐人各得 300 Free Lumy**；
- 每个账号最多推荐 **50 人**，没有每日次数限制；
- 到账记录在「发放明细 / 充值明细」里查。

要注意两点：一是**推荐人一栏是可选的**，填错不会导致注册失败，但也拿不到 Lumy；二是这个制度针对的是**新注册账号**，已经注册过的老账号补填无效。

## 五、多账号与换设备

- **一台设备可以登多个账号**：官方没有公布设备数限制，爱好者整理的攻略里也普遍提到同一台设备可以轮流登多个账号。追星圈里常见的做法就是同一台手机切几个账号分别攒 Lumy，实际是否可行以你自己尝试的结果为准。
- **换手机**：用原第三方账号在新设备登录即可，关注列表、Lumy 余额、投票记录跟着账号走，不跟着设备走。
- **卸载重装**：同理，只要还登得上原第三方账号，数据不丢；但**没登录时的本地缓存会被清掉**，所以重装前先确认自己记得用的是哪个第三方账号。

## 六、登录出问题时的处理顺序

1. 第三方账号本身正常吗 —— 先在浏览器里登一次 Google / X / Line，确认不是对方平台的问题；
2. 换一种登录方式试 —— 官方支持多种方式，X 出问题时可以试试 Google；
3. 清应用缓存后重试 —— 「设置 → 应用 → Muniverse → 存储 → 清除缓存」，**不要**点「清除数据」，后者会登出当前账号；
4. 都无效时联系官方支持邮箱 `support@muniverse.io`，说明你用的是哪种登录方式。

账号配好之后，下一步就是每天要做的攒票与投票，见 [Lumy积分怎么获得和使用.md](Lumy积分怎么获得和使用.md) 与 [怎么给偶像投票.md](怎么给偶像投票.md)。
