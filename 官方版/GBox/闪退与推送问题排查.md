# GBox 闪退、收不到推送等问题排查

> 本篇按现象归类 GBox 的常见故障：闪退、锁屏后收不到 Gmail / WhatsApp 推送、License Error、Gmail 附件卡「上传中」等，逐条给出处理步骤。

## 一、先记住一条通用原则

大部分故障的第一处理动作是**把 GBox 升到最新版** —— 旧版与新系统、与新版本应用不兼容，是闪退和各类异常最常见的来源。升级用覆盖安装，沙箱内应用与数据不丢，方式见 [更新与卸载注意事项.md](更新与卸载注意事项.md)。

## 二、按现象对号入座

| 现象 | 首选处理 |
| --- | --- |
| 打开就闪退 | 清缓存 → 查系统版本 → 重启 |
| 锁屏后收不到推送 | 开自启动 + 忽略电池优化 |
| 应用提示 License Error | 重登 Google 账号 → 沙箱内重装该应用 |
| Gmail 附件一直「上传中」 | 升级到 v1.8.0.3 及以上 |
| Minecraft 卡在加载界面 | 升级 GBox 后重进 |
| Airbnb 房东功能异常 | 应用内切到房东模式再重登 |

## 三、闪退：四步排查

1. **升级到最新版**；
2. **清缓存**：「设置」→「应用」→「应用管理」→ GBox →「存储」→「清空缓存」。清缓存不删沙箱内已装的应用与数据，但个别临时登录态可能需要重新确认；
3. **查系统版本**：设备需为 EMUI 14+ 或 HarmonyOS 4.x；纯血鸿蒙 NEXT 装不了 APK，情况不同，参考 [鸿蒙与EMUI机型适配.md](鸿蒙与EMUI机型适配.md)；
4. **重启设备**后再打开。

四步走完还闪退，多半是机型兼容问题，只能等版本更新。别用「卸载重装」碰运气 —— 卸载会清空整个沙箱的数据。

## 四、收不到 Gmail / WhatsApp 推送

消息偶尔延迟或锁屏后完全收不到，基本是后台被系统省电策略回收了：

1. 「设置」→「应用」→「应用管理」→ GBox，开**自启动**；
2. 同一页面把 GBox 设为**忽略电池优化 / 不允许电池优化**；
3. 进 Gmail / WhatsApp 自己的设置里，确认应用内通知权限已开。

三项都开过之后仍整段收不到，切一下网络再观察 —— 推送链路同样依赖网络可达。

另外，部分 EMUI 版本把这两项收在「应用启动管理」里：应用管理中点开 GBox →「启动管理」，关闭「自动管理」，在手动管理里把**允许自启动、允许关联启动、允许后台活动**三项都勾上，效果等同上面两步。

## 五、License Error

个别授权校验类应用启动时提示 License 校验失败，按顺序试：

1. 在 GBox 里退出 Google 账号重新登录；
2. 沙箱内卸载该应用，回 Play 商店重装；
3. 确认 GBox 为最新版。

## 六、Gmail 附件卡「上传中」

添加附件后长时间显示「上传中」发不出去：把 GBox 升级到 v1.8.0.3 及以上（该修复在 2026-07 的版本里），重开 Gmail 再传；仍不行就换一个网络重试。

## 七、两个已知的应用级问题

- **Minecraft 卡在加载界面**：兼容层版本偏旧导致，升级 GBox 后重进；仍卡住就清一次缓存再试。
- **Airbnb 房东模式异常**：在 Airbnb 应用内把账号切到商务模式 / 房东模式；仍异常就退出账号重新登录，并保持 GBox 为较新版本。
