## 一、先分清格式与手机的支持情况

| 下载到的格式 | 手机自带播放器 | 说明 |
| --- | --- | --- |
| FLAC | 多数直接支持 | 安卓系统层面支持 FLAC，放不出声音先怀疑播放器 |
| WAV | 多数直接支持 | 无损的另一种封装，体积更大 |
| MP3 / MP3 320K | 全部支持 | 基本不存在放不出的问题 |
| DSD（.dsf / .dff） | 基本不支持 | 需要明确支持 DSD 的专用播放器 |

核心判据一句话：**换一个播放器能放，就不是文件的问题**。先用这条快速排除文件损坏的嫌疑。

## 二、换一个支持无损的播放器

免费播放器里的常见选择：AIMP、Musicolet、VLC、Salt Player（椒盐播放器）——听 FLAC 和 MP3 任选其一都够用。

只有当你下载的是 DSD 文件（.dsf / .dff）时才需要专用播放器，如 Poweramp、海贝音乐这类明确支持 DSD 的；没有外接解码器时，这类播放器会把 DSD 转成 PCM 播放。

以上是截至 2026-09 的常见推荐，播放器的功能以各官方页面为准。

## 三、导入与播放

1. 网盘下载完成后，文件通常落在「Download」目录或网盘 App 自己的下载目录；
2. 打开播放器，让它扫描本机音乐——多数播放器首次启动会自动扫描，扫不到就在设置里手动触发；
3. 按歌手或专辑找到刚下的文件，点播放。

改文件名时别动末尾的 `.flac`、`.mp3` 扩展名，改了播放器就认不出来了。

## 四、还是放不出来时的检查顺序

1. **换播放器验证**：能放 = 原播放器不支持，不能放 = 继续往下查；
2. **核对文件大小**：与帖子标注的体积差得远，说明没下完整，回[无损音乐下载步骤.md](无损音乐下载步骤.md)重新下载；
3. **检查扩展名**：确认文件末尾还是 `.flac` / `.mp3` / `.dsf`；
4. **DSD 文件单独确认**：播放器必须明确写支持 DSD，普通播放器放不了是正常的。

以上都排除后仍无声，问题多半在下载环节而不是播放环节，排查思路见[播放失败与常见问题排查.md](播放失败与常见问题排查.md)。
