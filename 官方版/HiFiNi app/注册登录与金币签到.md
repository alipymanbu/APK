## 一、哪些操作需要账号

| 操作 | 需要登录吗 |
| --- | --- |
| 浏览帖子、搜索 | 不需要 |
| 在线试听 | 不需要 |
| 回复帖子（看提取码的前提） | 需要 |
| 每日签到 | 需要 |
| 上传分享资源 | 需要 |

最常见的需求就是第一条：想拿提取码下载资源，必须先有账号并回复帖子，完整流程见[无损音乐下载步骤.md](无损音乐下载步骤.md)。

## 二、注册账号

1. 在应用内进入登录页，切到注册入口（或在应用对应的社区页面注册）；
2. 按注册页要求填写账号信息并完成验证，具体要求以注册页当时显示为准；
3. 注册完成后用新账号登录应用。

两点提醒：

- 注册页的具体字段与验证方式会随时间调整，本篇不写死细节，以当时页面为准；
- 保存好账号密码：换手机重新安装后，用它重新登录即可。

## 三、金币与签到

社区有金币体系：签到、回帖这类活跃行为可以积累金币，金币与社区内的部分权限挂钩。要点：

- 签到入口与金币的具体数值、兑换规则，社区内会有说明帖，且可能调整，以社区当时的说明为准；
- 金币通常不影响浏览和试听，主要影响有活跃度门槛的操作。

## 四、登录不上的常见原因

1. **账号密码输错**：先在网页端验证账号是否正常，再回应用里登录；
2. **登错了站点**：这个名字下有过多个相近站点，**彼此账号与金币互不相通**。在哪个站点注册的账号，就去哪里登录；换了入口登不上，先确认当前用的应用与服务端是不是同一个来源；
3. **服务端维护或关停**：社区型服务的可用性会波动，过段时间再试。
