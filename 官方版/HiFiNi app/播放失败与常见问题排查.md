## 一、问题对照表

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 点播放转圈但不出声 | 媒体音量为零；网络受限或波动；该帖音源暂时失效 | 先查媒体音量（不是铃声音量）；换网络（Wi-Fi 与流量互换）；清应用缓存后重进；换其他帖子验证 |
| 试听加载特别慢 | 首次启动缓存少、网络慢 | 多等片刻；用过几次后缓存生效会快一些 |
| 提取码看不到 | 未回复帖子，或未登录；个别帖子另有金币门槛 | 回复该帖并保持登录状态；回复后仍不显示就换帖，流程见[无损音乐下载步骤.md](无损音乐下载步骤.md) |
| 网盘链接打不开 | 提取码输错；链接末尾带空格；链接随帖子失效 | 重新完整复制（注意 0 与 O、1 与 l 的区别）；先转存到自己网盘再下载；仍不行换其他帖子 |
| 安装报「解析包出现问题」 | 安装包不完整；系统版本低于要求 | 重新下载安装包并核对大小与 MD5；确认系统为 Android 5.2 及以上，详见[下载与安装教程.md](下载与安装教程.md) |
| 打开就闪退 | 系统版本过低；安装包残缺 | 同上，先核对系统版本与包完整性 |
| 下载的无损文件放不出声音 | 播放器不支持该格式（DSD 尤其如此） | 换支持无损格式的播放器，见[flac文件在手机上怎么播放.md](flac文件在手机上怎么播放.md) |

## 二、两个判断思路

1. **先分清应用问题和内容问题**：换一首歌的帖子能正常播，是原帖音源的问题；什么都播不了，才是网络或应用本身的问题。
2. **先分清应用问题和服务端问题**：应用打不开、闪退属于应用侧，重装解决；能打开但内容加载不出，可能是服务端波动，等一段时间再试。
