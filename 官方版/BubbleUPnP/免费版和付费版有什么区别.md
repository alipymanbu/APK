## 一、先分清三个东西

讨论「付费」时经常混为一谈，其实是三样互相独立的东西：

| 东西 | 是什么 | 花钱吗 |
| --- | --- | --- |
| BubbleUPnP 主应用 | 手机上的本体，免费安装 | 免费 |
| BubbleUPnP License | 单独的一个小应用（包名 `com.bubblesoft.android.bubbleupnp.unlocker`），装上即解锁主应用的限制 | 一次性买断，价格随地区与渠道变动，以 Google Play 当时标价为准 |
| BubbleUPnP Server | 装在电脑/NAS 上的可选配套软件，提供转码、外网访问等能力 | 免费（另见第四节） |

也就是说：**主应用不收费，限制靠单独的 License 应用解除**；Server 是另一码事，装不装都不影响手机端的许可状态。

## 二、免费版的明确限制

以下条目来自官方 tips/changelog 页面与多方公开资料，数值可能随后续版本调整，**以应用内实际提示为准**：

| 限制项 | 免费版 | 买了 License 后 |
| --- | --- | --- |
| 播放列表（队列）条数 | 受限，常见反馈为 16 条 | 不限 |
| 投到外部设备的曲目数 | 单次启动限 16 条（本机播放不受限） | 不限 |
| Chromecast 转码时长 | 每次启动累计 20 分钟 | 不限 |
| Chromecast 原生格式播放 | **不限量**（MP3/AAC/Vorbis、MP4-H264/无 DTS 的 MKV/WebM、常见图片） | 同样不限 |
| 网盘内容投外部设备 | 不限 | 不限 |
| 下载（媒体存到手机） | 分批限制（一批最多 40 条） | 不限 |
| 广告 | 有 | 去除 |

两个容易误会的点：

1. **「16 条」限的是投到外部设备的量，不是你能浏览的量**——浏览、搜索、本机播放都不受限。只是听听手机外放、或者本机看视频，免费版完全够。
2. **原生格式投 Chromecast 不要钱也不限时**——官方 tips 页原文就是「unrestricted」。要花钱解锁的是**转码**（把不兼容格式转成 Chromecast 能播的）那一部分。

## 三、License 怎么买、怎么生效

1. 在 Google Play 搜「BubbleUPnP License」（开发者 Bubblesoft），买下并安装这个独立小应用——它本身没有界面，作用只是让主应用检测到「已购」。
2. 装完回到 BubbleUPnP，限制即解除；从主应用内「Buy License」入口跳转购买的，付完返回应用就自动生效。
3. 换手机时用**同一个 Google 账号**在新机上装回 License 即可，买断跟账号走。
4. 出现「License 已安装却仍受限」时，先确认 License 与主应用来自同一渠道（官方商店对官方商店）、都已是最新版；仍不恢复再按官方页面给出的方式联系技术支持。

网盘里提供的是主应用的安装包，License 是需要你在商店自行购买的付费应用，两者配合使用。

## 四、BubbleUPnP Server：另一维度的「增强」

Server 装在电脑或 NAS 上（需 Java 8+，官网提供 Windows/macOS/Docker 等包），手机端在同一局域网会**自动检测**到它（`More > 齿轮 > Chromecast > Current transcoding method` 里显示其 IP 即为已连）。它提供三类手机端本身给不了的能力：

1. **Chromecast 转码**：AVI、带 DTS 的 MKV、MOV、WMV、TS 等格式转成 Chromecast 能播的；只转必要的部分（比如只转音频轨），独立音频（FLAC/WMA 等）转 WAV 无损。装了它之后，上表里「免费版 20 分钟转码」的限制由 Server 侧承担，不再走手机端的额度。
2. **出门访问家里媒体**：手机在外面用流量也能安全地读家里媒体服务器的内容，带密码与 HTTPS；这条路要在 `More > 齿轮 > Internet access with BubbleUPnP Server` 里手动填 Server 地址与账号。
3. **Chromecast 变身 DLNA/OpenHome 渲染器**、媒体服务器代理等进阶玩法，官网 Server 文档有完整清单。

注意 Server 的资源开销：**视频转码很吃 CPU**，1080p 软转需要较强机器，多数 NAS 担不动（音频转码则随便什么机器都行）；官方也建议优先用有线连接的机器跑 Server。

## 五、要不要买，按用法判断

- 只在手机上放、或投自家电视播 MP4/MP3 这类原生格式 → 免费版没有实质障碍；
- 要整专辑连播到外部设备、天天投屏、播非标格式视频 → 队列 16 条与 20 分钟转码会反复撞上，License（或 Server，对转码而言）才解得开。

许可政策与价格会调整，购买前以 Google Play 商品页当时显示为准。
