## 一、这是个什么应用

BubbleUPnP 是安卓上的投屏与媒体播放应用：你用手机当遥控器，把手机本地、网盘、电脑共享、局域网媒体服务器里的音乐和视频，推到电视、音箱、游戏机等设备上放。开发者是 Bubblesoft，官网在 [bubblesoftapps.com](https://bubblesoftapps.com/bubbleupnp/)，Google Play 上的完整名字是「BubbleUPnP for DLNA / Chromecast」。

它同时还是个「双面」应用——既能控制别的设备播（控制点），也能被别的设备控制着播（渲染器），还能把手机内容开放给电视浏览（DLNA 媒体服务器）。这三个身份后文各篇会反复出现。

网上（Google Play、各种下载站）能搜到的是官方最新版，常常已经是 4.6.5、4.6.7 之后的版本，与网盘里这份 4.6.4 不是同一个文件——**版本号、包名、大小一律以上面这张表为准**，别拿网上的数字来核对。

## 三、安装步骤

1. 把 APK 从网盘下载到手机（或先下到电脑再传过去）。
2. 在手机上点开这个 APK 文件，系统会弹「是否允许安装未知应用」——只为这一次安装放行即可（给文件管理器或浏览器授这个权限）。
3. 按提示安装，装完打开。
4. 首次启动会请求若干权限（存储、附近设备等）。**「附近设备 / 本地网络」这类权限必须给**，否则它扫不到局域网里的电视和音箱，详见 [找不到设备怎么排查.md](找不到设备怎么排查.md)。

如果你手机上装的版本比 4.6.4 新，直接装会提示降级失败——要么换更新的 APK 覆盖装，要么先卸载旧版再装。卸载前留意：已保存的播放列表存在应用自己的存储里，卸载可能一并清掉，介意的话先把在意的曲目记下来。

## 四、装完先做三件事

1. **手机和电视/音箱连到同一个 WiFi**，且不是访客网络。这一步不做，后面所有功能都无从谈起。
2. 打开应用，底部切到「正在播放（Now Playing）」页，看设备列表里有没有你的电视或音箱。有 → 直接去 [投屏到电视和Chromecast教程.md](投屏到电视和Chromecast教程.md)；没有 → 先走 [找不到设备怎么排查.md](找不到设备怎么排查.md)。
3. 切到「媒体库（Library）」页，确认能看到「本地与云（Local and Cloud）」下的手机文件。能看到说明存储权限正常。

## 五、界面长什么样

应用主要靠底部几个页签切换（不同版本措辞略有差异）：

- **正在播放（Now Playing）**：当前播的内容、播放控制，以及**选哪台设备播**的入口；
- **播放列表（Playlist）**：播放队列，可拖动排序、多选删除；
- **媒体库（Library）**：选内容源（手机本地、网盘、SMB、局域网媒体服务器），按文件夹浏览；
- 部分版本还有独立的**设备（Devices）**页签，功能与正在播放页里的设备选择一致，可在设置里调出。

设置入口在「更多（More）」里的齿轮图标，后文各篇涉及设置项时都会写全路径（形如 `More > 齿轮 > Library`）。

## 六、升级与版本变化

官方更新节奏较密，版本号是 `主.次.修订` 形式（如 4.6.4），更新内容在官网的 [changelog 页面](https://bubblesoftapps.com/bubbleupnp/changelog.html) 公布，以官方页面当时显示为准。你在 Google Play 上装的话会自动更新；用网盘这份 APK 的话，拿到新版本 APK 后直接覆盖安装即可，已装的同签名升级会保留设置（反过来从新版降回 4.6.4 则要先卸载，见第三节）。

一个容易踩的配套坑：如果你同时在电脑/NAS 上装了可选组件 BubbleUPnP Server，**手机端版本太旧会连不上新版 Server 的 https 证书**（官方 Server 更新日志明确要求手机端 4.6.6+ 才能走新证书的 https 连接）。手机端与 Server 端版本尽量都保持较新，两者的更新日志都在各自官网页面上。
