## 一、先搞清它的玩法

BubbleUPnP 的用法是「**手机当遥控器，电视当播放器**」：媒体内容不经过手机屏幕，而是由电视/音箱自己去取流播放。所以第一步永远是「选一台播放设备」，第二步才是「从媒体库里挑内容」。播放设备和手机必须在同一个局域网里；扫不到设备时去看 [找不到设备怎么排查.md](找不到设备怎么排查.md)。

## 二、选播放设备

1. 打开应用，进入「正在播放（Now Playing）」页。
2. 页面上有设备选择入口（有的版本在顶部、有的在 Devices 页签），点开是一份**自动扫描出来的局域网设备列表**。
3. 你的电视、Chromecast、支持 DLNA 的音箱、游戏机等会以各自的设备名出现在里面，点一下即选中。
4. 换设备就再点开换选；播到一半换设备，播放会转到新设备上继续。

列表里还会有「本机（Local Renderer）」一项——选它就是在手机上播。**Local and Cloud 媒体库对本机播放是无限量的**，往外部设备播才有免费版的次数限制（见 [免费版和付费版有什么区别.md](免费版和付费版有什么区别.md)）。

## 三、浏览与播放

1. 切到「媒体库（Library）」页，左上角箭头/下拉可以**切换当前媒体库**：`Local and Cloud`（手机本地与网盘）、局域网里的 UPnP/DLNA 媒体服务器等。
2. 按文件夹逐层点进去找内容；支持搜索的媒体库可以直接搜。
3. 点一个曲目/视频，**默认行为是「从点击位置开始播该文件夹的项目」**（3.7 起的默认值）。想改成别的动作，去 `More > 齿轮 > Library > Item tap action`。
4. 想加入队列而不是立刻播，选中后用「加入播放列表 / Enqueue」类动作。
5. 多选：在列表里把条目**向左或向右滑**（不要从封面上滑），选中的会变蓝，文件夹也一样可以这样多选。

播放起来后，在「正在播放」页可以：左右滑封面切上一首/下一首、长按播放键停播并归零、用手机的**实体音量键直接调外部设备的音量**。

## 四、播放列表（队列）

「播放列表（Playlist）」页就是当前播放队列：

- **拖动封面上下移动**改顺序；**长按**条目出删除（垃圾桶）等动作；
- 菜单里的「Add Stream URL」可以手动加一条网络流地址（比如网络电台的 m3u/音频流）；
- 支持随机播放的多种模式、睡眠定时器（在设置里开）。

免费版的队列条数有上限（第三方资料普遍反馈为 16 条，官方口径以应用内提示为准），整专辑连播会被截断时先看 [免费版和付费版有什么区别.md](免费版和付费版有什么区别.md)。

## 五、Chromecast 的几个特殊行为

如果你投的是 Chromecast（含 Nest、带 Chromecast 的电视与音箱），有四点和普通 DLNA 设备不一样：

1. **没有「投屏」菜单**。在设备列表里选中 Chromecast 就是全部操作，之后和投 DLNA 设备一样正常播放即可。
2. **手机端要保持应用在线**。Chromecast 本身没有播放队列，切歌、续播全靠 BubbleUPnP 在手机上驱动——你把应用杀掉或断开，它播完当前这一条就停。云端内容是例外：投 Google Drive 之类网盘里的视频，Chromecast 是自己直接从云端拉流的，退出应用也会继续播。
3. **多个手机可以同时管一台 Chromecast**：另外一台手机打开 BubbleUPnP 选中同一台 Chromecast，就能看到同样的播放状态、互相不打架。
4. **格式原生支持的免费放、不支持的要转码**。Chromecast 原生能吃的是：音频 MP3 / AAC / Vorbis，视频 MP4(H.264) / 不带 DTS 的 MKV / WebM，图片 BMP / GIF / JPEG / PNG / WebP——这些免费版不限量地放。AVI、带 DTS 的 MKV、MOV、WMV、TS、FLAC 等格式则要靠电脑上的 BubbleUPnP Server 做转码，而**免费版每次启动应用只有 20 分钟的转码时长**（官方 tips 页写明，以官方页面为准）。

字幕：投 Chromecast 时外挂 `.srt` 与内嵌字幕都能显示，播放开始后几秒「正在播放」页顶栏出现字幕图标，点它选字幕轨；**默认不会自动显示**，要手动选一次。内嵌字幕的提取需要 Server 在线配合，外挂 srt 不需要。

## 六、投到游戏机与 Hi-Fi 设备

- **PlayStation**：PS3/PS4 从主机自带界面浏览 DLNA 服务器，可以把 BubbleUPnP 开放出的手机内容当服务器用（PS5 的官方描述只确认到 PS4，能否使用以实测为准）。
- **Xbox**：Xbox 360 起的机型都支持作为播放设备。
- **Hi-Fi 流媒体播放器**：Denon、Marantz、Onkyo、Pioneer 等品牌的 UPnP/DLNA 播放器可直接被它控制，Qobuz / TIDAL 的无损内容也能推给这些设备。
- **电脑/树莓派**：跑着 Kodi、JRiver、Volumio、Moode、upmpdcli 的机器都能当播放端。

## 七、播放不成功时的顺序

1. 设备没出现在列表 → [找不到设备怎么排查.md](找不到设备怎么排查.md)；
2. 设备在列表、点了没动静 → 确认该设备没被别的控制端抢占，换一台设备试一下，再回来重选；
3. Chromecast 报格式不支持/只有声音没画面 → 是转码问题，见本篇第五节与 [免费版和付费版有什么区别.md](免费版和付费版有什么区别.md)；
4. 本地视频想直接在手机上放却拉起了系统播放器 → 设置里把默认视频播放应用改回 BubbleUPnP，或按它弹窗里的「Fix」按钮进系统应用设置处理。
