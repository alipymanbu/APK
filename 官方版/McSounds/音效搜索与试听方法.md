# McSounds 音效搜索与试听方法

> McSounds 的搜索不是按应用分类点选，而是「输标签匹配」：标签之间用空格隔开，输完自动开始搜。本篇把搜索规则、中文搜法、试听操作一次讲清。

## 一、先记住四条搜索规则

在主界面点「搜索音效」，会出现一个「搜索音效..」输入框。这四个规则决定了你能不能搜到东西：

| 规则 | 说明 |
| --- | --- |
| 标签间用空格分隔 | 想组合多个条件时，直接敲空格，不需要加号或逗号 |
| 最多 4 个标签 | 多输的标签会被直接忽略，不是报错，所以搜偏了先数数标签个数 |
| 每个标签至少 2 个字符 | 单个字母或单个汉字匹配不上 |
| 输完自动搜索 | 不用点搜索按钮，输入框内容变化后结果自己刷出来 |

## 二、三种能用的搜法

同一个音效，可以用不同线索找到它：

1. **英文标签**——用游戏里的物品、生物英文名，比如 `bat`（蝙蝠）、`conduit`（潮涌核心）。这是最稳的搜法，覆盖面最全。
2. **中文标签**——项目带了中文标签索引，输入 `潮涌核心` 也能定位到 conduit 相关音效。中文叫法与你的习惯一致即可，搜不到再换英文。
3. **路径片段或文件名片段**——输入 `mob/bat` 这类路径开头，或者 `wood` 这类文件名关键词，能按文件本身的名字匹配。

搜「生物叫声」这类模糊需求时，建议直接用「生物英文名 + 场景」的组合缩小范围，例如搜狼的音效用 `wolf`，再从结果里挑咆哮、喘气等不同变体。

## 三、试试手气：随机找灵感

主界面另一个入口「试试手气」会随机推荐一个游戏内音效。它适合两种场景：

- 做视频配乐时没有明确的音效目标，随机刷几个碰碰灵感；
- 想快速了解这个库里都有什么，比翻列表快。

随机到的音效同样可以进入详情页试听和下载。

## 四、试听与看详情

- 在结果列表里**单击某个音效**，会播放一次预览，并弹出声音的详细信息（路径、所属分类等）。
- 想反复听同一段，可以在详情页里继续播放；从详情页返回列表时音频会停掉，不会在后台一直响。
- 音效是在线加载的，点播放后稍等一下才有声，加载快慢取决于网络。
- 结果里同一声音的多个变体会并列出现（游戏里的声音事件大多带若干条随机变体），挑一条听即可，不必觉得是搜重了。

试听满意之后怎么保存到本地、怎么把某条音效的链接发给朋友，见 [音效下载与分享外链.md](音效下载与分享外链.md)；想先弄清库里到底收录了哪些年代的音效，见 [音效内容与游戏版本对应.md](音效内容与游戏版本对应.md)。
