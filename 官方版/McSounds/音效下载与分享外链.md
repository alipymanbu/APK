## 一、从详情页下载音效文件

搜索并试听后，进入某个音效的详情页，**Download 栏目**就是下载入口，点击即可开始下载。两个要知道的细节：

- 点击后应用会给出「下载已开始」一类的提示。这个提示是后来加的，目的就是让你知道下载确实开始了——更早的版本点击后没有任何显示。看到提示就等文件落盘，不用重复点。
- 下载的是音效的**原始格式文件**（游戏素材原样，`.ogg` 后缀）。这不是压缩损坏的文件，剪辑软件、音频播放器都能直接打开；个别只认 mp3 的老软件需要你先转一次格式。

下载完成后在文件管理器里按时间排序，刚生成的 `.ogg` 文件就是；不同机型的默认保存目录可能不同，没找到就按后缀搜一下。

## 二、分享：把某条音效的链接发出去

详情页有「分享」按钮，点击会生成这条音效的链接。拿到链接的人用 McSounds（或同一项目的网页版）打开，就能直接定位到这条音效试听、下载。

典型的用法：

- 剪辑搭档分工找音效时，把选中的音效链接丢进群里，省得描述「就是蝙蝠叫那个声」；
- 自己收藏：把常用音效的链接记在备忘录里，下次直接打开，不用再搜一遍。

## 三、下载下来能干什么

这些音效来自 Minecraft 游戏本体的音频素材，常见的去处：

| 场景 | 怎么用 |
| --- | --- |
| 游戏短视频/解说 | 挖矿、受伤、开箱等标志性音效直接导入剪辑软件当点缀 |
| 配音与整活 | 用「试试手气」随机刷音效，配合画面制造节目效果 |
| 资源包/模组制作参考 | 先在库里试听确认想要的声音事件，再去游戏文件里替换对应音频 |
| 铃声/提示音 | ogg 文件转格式后按手机厂商的路径设为通知音 |

想在游戏里把这些声音直接播放出来（做地图演出、红石反馈），用的是 `/playsound` 指令，写法与音效 ID 的查法见 [游戏内播放音效指令.md](游戏内播放音效指令.md)。注意库里显示的文件路径不能直接填进指令，两套命名不通用。

装应用、找音效、下载这条链路里卡在哪一步，可以先翻 [常见问题与解决办法.md](常见问题与解决办法.md)；库里音效的来源与版本口径，见 [音效内容与游戏版本对应.md](音效内容与游戏版本对应.md)。
