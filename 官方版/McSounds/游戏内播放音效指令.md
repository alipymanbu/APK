# 游戏内播放音效指令

> 从 McSounds 里挑中的音效，想在游戏里直接放出来（做地图、整活、红石反馈），用的是 Minecraft 的 `/playsound` 指令。本篇讲指令怎么写、音效 ID 从哪查，以及最容易被坑的一处：库里显示的名字不能直接填进指令。

## 一、先分清两套名字

这是新手最容易踩的坑：**McSounds 库里显示的是音频文件的路径**（`mob/bat`、`ambient/cave` 这类），**而游戏指令里要填的是音效 ID**（`minecraft:entity.bat.ambient` 这类）。两套命名不通用，把库里的路径原样填进指令是不会响的。

所以推荐的分工是：McSounds 负责「试听挑声音」——先在库里确认你要的就是这个声；然后拿着「这是什么声音」的结论，去游戏或资料站查对应的音效 ID，再写指令。

## 二、Java 版的写法

Java 版的基本格式：

```text
/playsound <音效ID> <来源分类> <玩家>
```

例：给最近的玩家播放经验球的音效：

```text
/playsound minecraft:entity.experience_orb.pickup player @s
```

几个要点：

- **来源分类**（master、player、music、block、hostile 等）对应玩家音量设置里的声音分类，你可以借它把演出音效单独归到一类，方便观众调或关。
- 输入指令时游戏会**自动补全音效 ID**，记不清全名时打前几个字母按 Tab 逐个翻即可。
- 后面还能追加坐标、音量、音调参数做进阶控制（比如让声音从指定位置发出、变调），写法以游戏内指令提示为准。
- 单人世界需要先在设置里开启作弊；服务器需要相应的指令权限。

音效 ID 会随游戏版本增删（新生物、新方块都会带来新 ID），具体以你游戏版本的补全列表和官方 Wiki 对应条目为准。

## 三、基岩版的写法

基岩版的格式与 Java 版不同，音效 ID 也是另一套命名风格：

```text
/playsound <音效ID> [玩家] [坐标] [音量] [音调]
```

例：给所有玩家播放爆炸音效：

```text
/playsound random.explode @a
```

注意两点：

- 基岩版的 ID 长得像 `random.explode`、`mob.pig.say`，与 Java 版的 `minecraft:entity.*` 不是一套；
- 基岩版输入 `/playsound` 时**没有自动补全**，ID 必须先在外面查好、整个敲对，敲错指令不生效也不报具体原因。

同一部手机上的 McSounds 查声音很方便，但 ID 查询得借助对应版本的资料：官方 Wiki 的物品/生物条目里通常标有音效 ID；社区维护的 ID 查询表（如基岩版的 [playsoundlist.xyz](https://playsoundlist.xyz/)）可以按名字搜，Java 版也有类似的社区音效浏览器。

## 四、从试听到放进游戏的完整流程

1. 在 McSounds 里搜索、试听，确认要的声音（比如某条洞穴氛围音）；
2. 记下它是什么声音（生物？方块？环境？），不确定就再看一遍详情信息；
3. 去对应版本的 Wiki 或 ID 查询表查这个名字的音效 ID；
4. 按 Java 或基岩版的格式写指令，先对自己（`@s`）试放一次，确认无误再改成 `@a` 或指定玩家。
