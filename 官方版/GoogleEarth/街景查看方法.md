## 一、进街景的两条路

**路线一：从地点卡片进。** 搜索一个地点，结果卡片上如果有实景照片，直接点照片就进了，最快。

**路线二：拖街景小人。** 把地图缩放到能看到街道，屏幕角落有个橙色小人图标（Pegman），按住它拖到地图上；路上出现**蓝色高亮**的地方就是拍过街景的，松手落在蓝线上即可。

两条例外情况：

- 没有蓝线 = 这一片没拍过，换大点的城市主干道试试；
- 小人拖不动或没有小人图标，多半是缩放级别太远，先双指放大到街道可见。

## 二、街景里的操作

| 想做什么 | 怎么做 |
| --- | --- |
| 左右张望 | 单指拖动屏幕 |
| 沿街前进 | 点地面上的白色箭头，或者顺着路双击前方 |
| 凑近看细节 | 双指开合缩放 |
| 回到正北视角 | 点右下角罗盘 |
| 退出来 | 左上角的返回箭头 |

街景里没有「倾斜视图」那套操作，那是天上看地面的手势；街景里的视角本来就是平视的。

## 三、看历史街景

街景存有不同年份的影像，能看到一条街几年间的变化：

1. 进入街景后，找「查看更多日期」入口；
2. 打开时间轴，会以滑块或缩略图列出可用的拍摄日期；
3. 点某个日期，画面就切换到那一年；
4. 想回到当下，点「返回最新图像」。

不是每个位置都有多个年份，时间轴里只有一个日期就是只拍过一次。

## 四、覆盖范围的边界

街景不是全球覆盖，拍摄范围集中在大城市和交通干道，部分国家与地区没有收录。想知道某个地方有没有，两个办法：直接在地图上看有没有蓝线；或者查官方的覆盖说明页 [https://www.google.com/streetview/](https://www.google.com/streetview/)。

街景加载不出来和地球黑屏是一个原因类别，网络到不了服务器就什么都出不来，按 [加载失败与闪退排查.md](加载失败与闪退排查.md) 的网络一节处理。

看到有意思的街景位置想留着，把它保存进地点清单或项目里，方法见 [保存地点与创建项目.md](保存地点与创建项目.md)。
