# Google Earth 三个版本怎么选

> 手机版、网页版、桌面版 Pro 都是免费的 Google Earth，能力差别不小。本篇用一张表讲清分工，帮你决定日常用哪个、什么时候开哪个。

## 一、三个版本一张表

| | 手机版 | 网页版 | 桌面版 Pro |
| --- | --- | --- | --- |
| 平台 | Android / iOS | 浏览器（Chrome、Edge、Firefox 等） | Windows / macOS / Linux |
| 价格 | 免费 | 免费 | 免费 |
| 3D 城市与地形 | 有 | 有 | 有 |
| 街景 | 有 | 有 | 有 |
| 测量 | 测线、测面 | 测线、测面 | 工具更多（多边形、圆） |
| 历史卫星影像 | 有限 | 有限 | 完整时间轴 |
| GIS 数据导入导出 | 无 | 无 | 有 |
| 使用方式 | 装应用 | 开网页就用，不装任何东西 | 装应用 |

说明：历史影像的「有限 / 完整」是第三方对照资料的口径，官方对桌面版 Pro 的表述是「用历史影像回到过去、导入导出 GIS 数据」；各版本实际能力以你手头版本为准。

## 二、什么时候用手机版

带在身上的那一版：出门路上给朋友看个地方、实地对照周边环境、顺手把位置存进项目。这套文档里 [手势与基础操作入门.md](手势与基础操作入门.md)、街景、测量几篇讲的都是在手机版里怎么干这些活。

## 三、什么时候开网页版

不装任何东西，[earth.google.com](https://earth.google.com) 打开就用：借别人电脑临时查个位置、屏幕更大更好做项目编辑。项目创作类的编辑工具在网页版最全，手机版更偏查看与补充。

## 四、什么时候才需要桌面版 Pro

三件手机与网页版干不了或干不好的事：

1. **完整的历史影像时间轴**——看一个地方十几年间的变迁，Pro 的时间轴最完整；影像多久换一次的背景见 [影像多久更新一次.md](影像多久更新一次.md)；
2. **GIS 数据导入导出**——手上有 GPS 轨迹或 GIS 图层，要叠加到地球上看；
3. **更高阶的测量**——多边形、圆等工具（手机版能做的部分见 [测量距离与面积.md](测量距离与面积.md)）。

另有第三方资料提到 Pro 内置飞行模拟器（快捷键 Ctrl+Alt+A），属彩蛋功能，以你装到的版本为准。下载入口在官方版本页 [https://earth.google.com/earth/versions/](https://earth.google.com/earth/versions/)。

## 五、账号是同一套

三个版本登录同一个 Google 账号，保存的地点与项目互通——手机上存的、电脑上接着编辑，是这套东西的正确用法，细节见 [保存地点与创建项目.md](保存地点与创建项目.md)。
