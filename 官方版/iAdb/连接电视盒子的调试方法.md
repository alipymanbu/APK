# 连接电视盒子的调试方法

> 本篇讲用手机上的 iAdb 连接电视盒子或智能电视：在盒子上开调试、找 IP、连接授权、装应用。

## 一、适用场景与前提

- 手机与盒子连在同一个 Wi-Fi：访客网络、AP 隔离都会让两台设备互相不可见；
- 盒子能进系统设置——调试开关都被锁死的定制盒子，这条路走不通；
- iAdb 已装好（步骤见 [下载与安装教程.md](下载与安装教程.md)）。

## 二、在盒子上打开调试开关

1. 进「设置 > 关于」，遥控器连点「版本号 / Build 号」7 次，开启开发者模式；
2. 回到「设置 > 开发者选项」，打开「USB 调试」；有「网络调试 / 网络 ADB / 远程调试」开关的也一并打开（不同品牌叫法不同）；
3. Android 11 及以上的盒子在「无线调试」界面能直接看到 IP 与端口；老系统通常只开放 5555 端口。

## 三、找到盒子的 IP 地址

- Wi-Fi 连接的盒子：在当前网络的详情里看；
- 有线连接的盒子：网络设置里看；
- 也可以登录路由器后台看设备列表，按主机名认。

## 四、连接与授权

1. 打开 iAdb，输入盒子 IP（老系统端口填 5555，或以盒子设置里显示的为准），点击连接；
2. 第一次连接，盒子屏幕上会弹出「允许 USB 调试吗」的授权框——把焦点移到「一律允许」再按确定；
3. 连接成功后，iAdb 的设备列表里会出现这台盒子。

设备列表里显示 unauthorized / 未授权，说明授权框还没被确认：回到盒子屏幕把弹窗点掉，再重连一次。

## 五、给盒子装应用

```bash
adb install /sdcard/xxx.apk
```

- APK 先放到手机存储里，通过 iAdb 的文件功能推送到盒子，或直接执行上面的命令；
- `adb install` 只吃整包 APK：XAPK / APKM 这类分包格式直接装会报错，先转成整包再装；
- 有的系统装完不进首屏，去「全部应用」列表里找。

## 六、装应用之外的常用操作

```bash
adb shell screencap -p /sdcard/s.png    # 截屏盒子画面（文件落在盒子上，可再 pull 回手机）
adb shell am force-stop 包名            # 强停卡死的应用
adb shell pm list packages              # 查盒子上装了哪些应用
```

这几条命令的完整说明见 [常用ADB命令速查.md](常用ADB命令速查.md)。

## 七、连不上时按这个顺序查

盒子在休眠（唤醒并重新打开调试开关）→ 路由器开了 AP 隔离或在访客网络 → 手机开着 VPN → 盒子上的授权框没确认。再解决不了的，按 [常见问题与连接失败排查.md](常见问题与连接失败排查.md) 的完整清单逐条排查；无线调试的开启与配对细节在 [无线调试开启与配对步骤.md](无线调试开启与配对步骤.md)。
