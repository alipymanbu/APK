## 一、iAdb 是什么，适合谁

iAdb（包名 `com.iadb.helper`）是合肥玄帧科技有限公司出品的安卓无线调试工具。你把它装在手机上，就能开启无线 ADB 调试、执行常用 ADB 命令、给文件管理器授予 shell 级权限，全程不需要电脑配合，也不用 Root。

它适合两类人：一是想在手机之间互连调试、或用手机调试电视盒子的开发者和进阶玩家；二是想查看 `/Android/data` 这类系统限制目录、又不想 Root 的普通用户。第一次接触 ADB 也不用慌，应用内置了使用教程，边看边操作即可。

## 二、安装前核对这几项

| 项目 | 要求 |
| --- | --- |
| 设备 | 安卓手机（官方商店标注支持手机） |
| 系统版本 | 安装包要求 Android 5.2 以上（以安装包实际信息为准；无线调试等完整功能需要 Android 11 及以上） |
| 安装包大小 | 5.20M |
| 包名 | `com.iadb.helper` |
| MD5 | `ED92EC8AA7D6BA19C5302FE3841209B3` |

以上版本与大小以网盘里那份安装包的实际信息为准（2026-09 核对）。商店里的版本号可能更高，见第五节。

## 三、获取安装文件资源

iAdb 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/243e096b19d8](https://pan.quark.cn/s/243e096b19d8)

转存到自己的网盘后，把 APK 下载到手机存储里。下载完成后建议核对一次 MD5，与第二节表格一致再装，避免下载过程中文件损坏导致安装失败。

## 四、安装步骤

1. 在文件管理器里点击下载好的 APK，系统提示「禁止安装未知来源应用」时，按引导去设置里允许对应来源，再回来继续安装；
2. 安装完成后打开 iAdb，按提示授予权限——它申请的权限里包含发布通知与运行前台服务，通知权限会影响后台保活，建议允许；
3. 首页内置了使用教程，第一次用建议先翻一遍再动手。

装完别急着连设备：无线调试依赖系统的开发者选项，先做下一节的准备。

## 五、商店版本与网盘版本的差异

小米应用商店可以搜到「iAdb-无线调试工具」（开发者：合肥玄帧科技有限公司）。商店版本会持续更新（写本篇时为 1.4.3，以商店页面为准），网盘里则是 1.4.2（2026-09 核对）。两者包名一致，安装与使用方式没有区别；如果你跟着商店更新到了更高版本，界面入口以新版为准，本套文档的思路仍然适用。

## 六、安装后第一步：打开开发者选项

1. 进入「设置 > 关于手机」，连续点击「版本号」7 次，系统会提示已进入开发者模式；
2. 返回「设置」，进入「系统 > 开发者选项」（不同品牌菜单路径略有差异，找不到就搜你的手机品牌 + 开发者选项）；
3. 接下来开启无线调试、配对与连接设备的完整流程，见 [无线调试开启与配对步骤.md](无线调试开启与配对步骤.md)。
