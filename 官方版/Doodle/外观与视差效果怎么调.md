选好壁纸只是第一步，Doodle 的可调项主要集中在后面几页：视差怎么动、动多大、元素尺寸多大、配色跟不跟系统。这些选项大多有从「完全不动」到「动作明显」的连续区间，调对了观感好也不费电，调过头就是白耗电池。这篇按页面拆开讲，每一项都给出建议起点。

## 一、四个页面分别管什么

先给一张分工表，避免在错误的页面里找选项：

| 页面 | 管的是 | 主要影响 |
| --- | --- | --- |
| 外观 | 选哪款壁纸、变体、强调色、每日随机、夜间模式 | 桌面长什么样 |
| 视差 | 壁纸对手势的响应：滑动、倾斜 | 桌面动不动、跟不跟手 |
| 形状尺寸 | 图形元素的大小、效果强度、缩放行为 | 观感与耗电 |
| 其他选项 | 应用自身的配色主题、对比度、硬件加速、息屏相关、日志 | 应用界面与稳定性 |

**只有动态壁纸才会用到「视差」和「形状尺寸」里的多数选项。** 如果你选的是静态壁纸合集，这两页里大部分开关是灰的或者不起作用，这属于正常现象。

## 二、视差页：桌面到底动不动

视差效果分两种触发方式，可以分别开关：

- **滑动（Swipe）**：左右滑动桌面翻页时，壁纸跟着平移。它依赖启动器把翻页事件传给壁纸，所以兼容性取决于你用哪个启动器。原生风格的启动器（如 Pixel 启动器）一般支持较好；三星 One UI Home 上实测滑动效果无效。
- **倾斜（Tilt）**：倾斜手机时壁纸有轻微位移。它靠陀螺仪，跟启动器无关，绝大多数机器都能用。

两个开关的关系是「叠加」的：关掉滑动只留倾斜，桌面依然有动感，但翻页时不会跟手。**只在意外观、不想让壁纸一直动的话，把两个都关掉，壁纸就变成静止画面**，耗电会明显低于开着视差的状态。

强度一般也在这页（或邻近页面）里调。强烈建议从低档开始：强度拉满时，翻页会有明显「甩」的感觉，看久了容易累，而且动画幅度大意味着更频繁的重绘。

## 三、形状尺寸页：图形元素与缩放

这一页控制壁纸里图形元素本身的大小与强度，另外还有和缩放有关的效果（滑动、解锁时的缩放方向）。**不同版本的选项数量与名称有差异，以你手机上实际显示为准。**

可以按下面的顺序调：

1. **先定元素大小**。同一款壁纸在不同屏幕上观感差别很大，尤其是屏幕比例特殊的机型；元素太大容易显得挤，太小又看不出设计。
2. **再定强度**。强度偏高时，切换壁纸或翻页的动画会更明显。
3. **最后处理缩放**。如果你觉得翻页和解锁时的缩放让人眼晕，把相关项关掉或调低；平板上更值得关，因为屏幕大、位移量也大。

字号或显示缩放做过调整（系统设置里的「显示大小」「屏幕缩放」）的机器，回来重调一次这一页，否则壁纸元素可能偏大或偏小。

## 四、其他选项页：这些先别急着动

| 选项 | 作用 | 什么时候动它 |
| --- | --- | --- |
| 应用配色主题 | Doodle 自己的界面是浅色还是深色 | 系统是深色主题但应用界面刺眼时，改成跟随系统或深色 |
| 对比度 | 调高后浅色主题下的文字更清楚 | 觉得界面文字发灰时打开 |
| 硬件加速 | 与画面渲染方式有关 | 桌面滑动出现掉帧时，开关各试一遍，选不卡的那档 |
| 息屏过渡延迟 | 息屏显示切换时的延迟 | 息屏显示与壁纸衔接时闪一下，调这里 |
| 日志 | 记录运行信息 | 准备去官方仓库反馈问题时才需要开 |

**日志那一项要注意**：它写下来的内容会一直累积，平时不用开。只有在遇到崩溃、准备向官方仓库提交问题时再打开，拿到信息后关掉。

## 五、怎么在观感和耗电之间找平衡

动态壁纸通常比静态壁纸耗电，差别主要来自三处：动画帧率、视差幅度、以及元素本身的重绘量。按下面的顺序往下压，每压一档看一天的实际耗电：

1. 关掉「倾斜」，只留「滑动」——倾斜靠陀螺仪，是后台常驻的那一个。
2. 滑动和倾斜的强度各调低一档。
3. 每日随机的间隔拉长（或者干脆关掉），换壁纸越频繁，取图和重绘画面的次数越多。
4. 仍然觉得耗电，就换成静态壁纸合集那一组，同时保留 Doodle 的配色与观感。

改完任何一项，都回到桌面滑动几下、锁屏再解锁一次，确认效果是你想要的。改了没生效，按 [常见问题与排查.md](常见问题与排查.md) 里的顺序查。
