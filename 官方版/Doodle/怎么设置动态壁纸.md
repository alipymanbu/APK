# Doodle 怎么设置动态壁纸

Doodle 的用法和一键换壁纸的应用不同：你把壁纸选好、设过去，剩下的事由系统接走。所以第一次用的人常常卡在同一个地方——在应用里点来点去，桌面没变化。这篇讲清两条设置路径、动态与静态的分工，以及变体、每日随机、夜间模式各管什么。

## 一、壁纸分成哪几类

打开 Doodle，主要操作都集中在「外观」这一页。壁纸按来源分组，名字在不同版本里可能略有差别，但类别本身是固定的：

| 类别 | 是什么 | 会不会动 |
| --- | --- | --- |
| 涂鸦集锦 | 源自 Pixel 4 原版的 Doodle 动态壁纸设计 | 动：滑动、倾斜时会有视差 |
| 动态壁纸 | 独有的一套 Material You 风格动态壁纸 | 动：同上 |
| 静态壁纸合集 | 取自 Pixel 6 那批未正式发布的 Material You 静态壁纸，另含部分来自 Chrome OS 的壁纸 | 不动 |

想省电就选静态那一组；想要 Pixel 那种「桌面跟着手走」的感觉，就选动态的。动态壁纸的动画是否常驻、强度多大，可以在「视差」和「形状尺寸」两页里压到很低甚至关掉，见 [外观与视差效果怎么调.md](外观与视差效果怎么调.md)。

## 二、路径一：直接在 Doodle 里设

这是最短的一条路，适合刚装完、正在逐个试壁纸的阶段。

1. 打开 Doodle，进入「外观」页。
2. 点一款壁纸进入预览。动态壁纸在这里会实时动，静态壁纸就是一张图。
3. 如果这款壁纸有多个变体，预览区附近会出现切换项，左右换到你要的那一版。
4. 需要的话先设强调色、开关夜间模式（见第四节）。
5. 点设置按钮。系统会弹出选择框：
   - 主屏幕：只换桌面，锁屏保持原样；
   - 锁屏：只换锁屏；
   - 主屏幕和锁屏：两个都换。
6. 选定后回到桌面看一眼。动态壁纸在滑动桌面或倾斜手机时应该会有位移。

**注意第 5 步的选择框是系统的，不是 Doodle 的。** 有些机型会把「主屏幕 / 锁屏」做成一次只能选一个，想两边都换就得设置两遍。

## 三、路径二：从系统的壁纸选择器设

换了启动器、重装过应用，或者在 Doodle 里翻不到入口时，走系统这条更稳：

1. 长按桌面空白处。
2. 选「壁纸与个性化」「壁纸和风格」之类的入口（各家叫法不同）。
3. 找「动态壁纸」或「实时壁纸」分组。
4. 列表里会出现已安装的动态壁纸应用，其中一项是 Doodle，点进去预览后应用。

**想确认自己用的是哪个启动器**：设置 → 应用 → 默认应用 → 主屏幕应用（各家菜单名不同，有的在「桌面和壁纸」里）。这一项显示的就是决定滑动效果能不能生效的那个启动器。滑动没反应时，换一个启动器再试一次，就能判断问题是在启动器上，还是在别处。

静态的那一组壁纸不在这条路径里单独出现，要到 Doodle 应用内部的「外观」页里设置。

## 四、变体、强调色、每日随机、夜间模式

这四个选项都在「外观」页里，容易和壁纸本身的设置混在一起，分清楚省事：

- **变体**：同一款壁纸的不同版本，通常是配色或构图差异。选壁纸时顺带切换，不属于全局设置。
- **强调色**：给壁纸指定一个主色，Android 12 及以上系统的界面会用它来取色。**这条有前提**——取色能不能生效取决于启动器与系统版本，三星 One UI 上实测不生效。
- **每日随机**：让应用按你设的间隔自动换一款壁纸设计。间隔可选，不是只能「每天」。
- **夜间模式**：跟随系统的深浅色切换，切到深色时壁纸会自动用深色那一版。

## 五、锁屏上要注意的两点

- **不是所有系统都允许锁屏用动态壁纸。** 部分机型的锁屏只接受静态图，选了动态壁纸后会退回静态版本，这是系统行为，不是 Doodle 的问题。
- **深浅色切换在锁屏上可能滞后。** 有用户反馈，系统在浅色与深色之间切换后，锁屏上的壁纸不会立刻跟着变，需要重新打开一次应用才刷新。桌面部分一般正常。

设置完如果发现滑动没反应、或者锁屏偶尔出现花屏/错位，先看 [常见问题与排查.md](常见问题与排查.md)，里面按现象分了排查顺序。
