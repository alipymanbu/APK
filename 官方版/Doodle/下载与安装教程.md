Doodle 是一款安卓动态壁纸应用，壁纸素材取自 Pixel 4 原版 Doodle 动态壁纸与 Pixel 6 的 Material You 静态合集。它开源免费、无广告、无统计，不需要登录。安装本身不复杂，容易卡住的只有两处：手上这份是不是对的，以及设置壁纸的入口在哪（它不在桌面上，在系统壁纸选择器里）。

## 一、先说清这一份是哪个版本

动手前先对照下表，确认手上这一份是对的：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | Doodle |
| 开发者 | Patrick Zedler |
| 包名 | `xyz.zedler.patrick.doodle` |
| 版本号 | v5.5.1 |
| 安装包大小 | 18.39 MB |
| 安装包 MD5 | `AFC2D2D5A3B4E12712AF645DB71A3CA2` |
| 系统要求 | Android 5.0（Lollipop）及以上 |
| 是否需要联网 | 不需要。壁纸随安装包一起提供，应用也没有联网权限 |
| 授权 | 开源（GPLv3）、免费，无广告、无统计 |

**版本号别拿搜索结果里的来对。** 应用商店页和第三方下载站显示的一般是官方当前最新版，与这一份未必是同一个；官方后续版本已经更新到 6.x，加入了对 Android 15 的支持，具体以官方发布页为准。想确认装得对不对，只看两项：包名是不是 `xyz.zedler.patrick.doodle`，版本号是不是 5.5.1。

**不需要 Google 服务。** 这一点常被误解：Doodle 取了 Pixel 的设计，但并不依赖 Google 框架，没有装 Google 服务的机器照样能用。它只申请设置壁纸、控制振动这两项系统权限。

## 二、从网盘把安装包取到手机

1. 在手机上打开 [Doodle 安装文件资源（夸克网盘）](https://pan.quark.cn/s/95326987d8da)。浏览器和夸克 App 都能打开，**建议用夸克 App**，浏览器下大文件容易被切后台打断。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存之后，后续下载就不再依赖原分享链接还挂着。
3. 回自己的网盘找到这个文件，下载到手机存储里。

转存而不是直接点外站的「立即下载」，好处是链接固定、文件不会被中途替换。下完可以在文件管理器里核对一下大小是 18.39 MB；想更保险，用能算 MD5 的文件管理器或电脑算一遍，对上 `AFC2D2D5A3B4E12712AF645DB71A3CA2` 就说明文件完整。

**换渠道拿包时，体积对不上不一定有问题。** 不同的分发渠道会各自重新签名打包，同一版本的安装包体积可能相差一两兆。核对时以包名与版本号为准，体积只当参考。

## 三、安装：系统会拦一次，属正常

1. 在文件管理器里点这个 `.apk` 文件。
2. 第一次装会跳出「禁止安装未知应用」的提示，按提示跳到设置里，给当前这个文件管理器（或浏览器）打开「允许安装未知应用」的开关，再回来重试。这个开关是给整个应用开的，装完可以再关掉。
3. 如果系统提示「未通过安全检测」「可能有害」，这是应用商店之外来源的常规提醒，不是文件损坏。选择继续安装即可。
4. 安装完，桌面会出现 Doodle 的图标。

装完再回设置里把刚才那个开关关掉，是更稳妥的做法——留着它等于给这个文件管理器长期开了后门。

## 四、装完第一次打开：你要找的入口不在这里

打开 Doodle 会看到应用自己的界面，里面是壁纸列表、各类调节项和一个「关于」页。**它不是一个「点一下就把壁纸换了」的工具**，真正的设置动作走系统那条路：

- 路径一：在 Doodle 界面里选中一款壁纸，点设置按钮，系统会弹出「主屏幕 / 锁屏 / 两者都设」的确认框。
- 路径二：长按桌面空白处 → 壁纸与个性化 → 动态壁纸（有的系统叫「实时壁纸」）→ 在列表里找 Doodle。

第一次打开后建议先按路径一走一遍，确认壁纸确实变了、滑动桌面时有视差反应，再回过头去调节各项参数。具体怎么选、怎么设到锁屏，见 [怎么设置动态壁纸.md](怎么设置动态壁纸.md)；设完没反应的情况见 [常见问题与排查.md](常见问题与排查.md)。

官方仓库里也提供了构建好的安装包，如果你更习惯从官方渠道拿，可以从发布页下载；网盘里这一份的价值在于版本固定、随时可取。

## 六、卸载前先把壁纸换掉

动态壁纸应用卸载后，桌面通常会自动退回系统默认背景，而不是保留你最后看到的那一帧。所以想留住当前观感，先在系统壁纸里换一张普通静态图，再卸载 Doodle：

1. 长按桌面空白处 → 壁纸与个性化 → 选一张系统自带静态壁纸并应用。
2. 设置 → 应用 → 找到 Doodle → 卸载。

它不备份任何个人数据，卸载后也不再占用手机存储。
