# Doodle 常见问题与排查

> Doodle 装好后最常遇到的几类问题：滑动没反应、取色不生效、深浅色不同步、锁屏花屏、找不到入口，逐个给排查顺序。

Doodle 本身很轻，报错少，问题几乎都出在它和系统、启动器之间的衔接上。下面按「现象」分节，每节给一条最小排查顺序，先从最省事的动作试起。对照版本为网盘里那份 5.5.1（包名 `xyz.zedler.patrick.doodle`）。

## 一、先做这三步通用检查

不管遇到什么现象，先确认这三件事，能排掉大半问题：

1. **壁纸确实是 Doodle 设的**：长按桌面 → 壁纸与个性化，看当前动态壁纸是不是 Doodle。有时系统更新后会悄悄退回自带壁纸。
2. **应用没被系统限制**：设置 → 应用 → Doodle → 电池，把限制改成「无限制」或「不优化」。省电策略把应用冻结时，壁纸的动画会跟着停，有时它还会从系统的动态壁纸列表里整个消失。三星机型再往下走一步：设置 → 电池 → 后台使用限制，确认 Doodle 既不在「休眠应用」里，也不在「深度休眠应用」里。
3. **重启一次手机**：动态壁纸是常驻服务，重启能清掉状态错乱，是最便宜的一招。

## 二、滑动或倾斜时桌面不动

这是最高频的一类。先分清是哪种不动：

| 现象 | 最可能的原因 | 怎么办 |
| --- | --- | --- |
| 倾斜手机没反应 | 视差里的「倾斜」关了 | 打开「倾斜」并调高一点强度 |
| 翻页时壁纸不跟手 | 启动器没有把翻页事件传给壁纸 | 换用原生风格启动器，或接受只用倾斜效果 |
| 两种都没反应 | 选的是静态壁纸 | 静态壁纸本来就不会动，换动态的那一组 |

**三星 One UI 用户重点看第二条。** 实测在 One UI 自带的 One UI Home 上，滑动效果与界面取色都不生效，这是启动器处理方式导致的，不是设置错。倾斜效果不经过启动器，一般仍然可用。

## 三、界面取色（强调色）不生效

Doodle 可以为壁纸指定强调色，让系统拿它给界面上色，但这条链路上有两道限制：

- **系统版本**：取色是 Android 12 起才提供的系统能力，12 以下没有这个功能，选项存在也不会有效果。
- **启动器**：取色由启动器负责实现，部分启动器（含 One UI Home）不响应。

排查顺序：先在系统设置 → 壁纸与个性化里确认「取色 / 主题色」这一类开关是开的，再看你的启动器是否支持。两条都满足还不生效，就当作该系统组合不支持，壁纸本身不受影响。

## 四、深浅色切换后壁纸没跟着变

表现是：系统从浅色切到深色，桌面换过去了，但壁纸还是原来那一版，得重新打开一次 Doodle 才刷新。

这属于已知的刷新时机问题，尤其容易出现在锁屏上。可以这样处理：

1. 进 Doodle，确认「夜间模式」是开启状态。
2. 切换系统深浅色后，如果壁纸没变，把 Doodle 从最近任务里划掉再打开一次。
3. 想彻底绕开这个时机问题，就在 Doodle 里手动选浅色或深色版本，不跟着系统走。

## 五、锁屏或解锁时壁纸异常

有用户反馈在锁屏、解锁的瞬间壁纸偶尔会出现错位或花屏一闪，随后自己恢复。这类现象多出现在带息屏显示、或者锁屏与桌面切换动画较重的机型上。

按这个顺序压：

1. 到「其他选项」里调「息屏过渡延迟」，让壁纸和息屏显示错开。
2. 把「硬件加速」开关切换一次再观察。
3. 仍然偶发，就在「形状尺寸」里关掉缩放相关效果，减少切换瞬间的重绘量。
4. 如果一天出现多次，把「日志」打开、复现一次，然后带着日志去官方仓库提 issue，比描述现象有效得多。

## 六、装完找不到图标，或系统壁纸里找不到 Doodle

- **找不到图标**：检查是不是把应用从桌面隐藏了，或者被装进了某个应用抽屉分组。
- **系统壁纸列表里没有 Doodle**：动态壁纸只在「动态壁纸 / 实时壁纸」分组里出现，不在静态壁纸列表里。列表里通常显示为应用名加一个预览缩略图，名字可能不含「Doodle」，往下翻一翻。
- **列表里完全没有**：先看第一节第 2 条——Android 的自适应电池、三星的后台使用限制这类机制，会把长期没被主动打开的应用放进休眠名单，被放进去之后它可能从动态壁纸列表里直接消失。把 Doodle 从名单里移出来，再重启一次手机，系统会重新扫描已安装的动态壁纸。

## 七、会不会很耗电

动态壁纸通常比静态图耗电，而 Doodle 没有走吃电的 3D 渲染那条路，这也是它能在旧机上跑得动的原因。真正决定耗电的是你的设置，从这三处压下去收益最大：

1. 关掉「倾斜」（陀螺仪常驻的那一项）。
2. 降低视差强度。
3. 每日随机的间隔拉长或关掉。

想彻底不要动态效果，直接换用 Doodle 里的静态壁纸合集，界面配色照旧。

## 八、没有 Google 服务能用吗

能。Doodle 不依赖 Google 框架，也不需要登录任何账号，安装后即可使用。它只申请设置壁纸、控制振动这两项系统权限，没有读取存储、没有读取位置，也没有网络统计上报。

## 九、想反馈问题或看有没有已知缺陷

优先去官方仓库的 issue 列表搜一下，很多现象别人已经报过：

- [github.com 上的 doodle-android 仓库](https://github.com/patzly/doodle-android)
- [官方发布记录（更新日志）](https://github.com/patzly/doodle-android/releases)

提交时带上三样东西，处理效率高得多：手机型号与系统版本、Doodle 版本号（本份是 5.5.1）、以及「其他选项」里打开日志后复现一次得到的记录。
