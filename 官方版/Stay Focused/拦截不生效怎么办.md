# 拦截不生效怎么办

> 规则配了却弹不出拦截页、网站拦不住、通知关不掉、卸载卸不掉 —— 按症状走一遍排查，多数问题五分钟内能定位。

## 一、先按症状定位到哪一环

拦截链路是：**权限在 → 应用活着 → 规则命中 → 弹出拦截页**。哪一环断了，症状不一样：

| 症状 | 多半断在哪 | 直接跳到 |
| --- | --- | --- |
| 点开被拦应用毫无反应，正常进入 | 权限没给 / 被系统收走 | 第二、三节 |
| 以前生效，现在突然不拦了 | 权限被回收 / 应用被杀后台 | 第三节 |
| 应用拦得住，网站拦不住 | 无障碍没给 / 浏览器不受支持 | 第四节 |
| 规则到了结束时间还一直拦 | 规则没关干净 / 严格模式在锁 | 第五节 |
| 通知照样弹 | 通知读取权限没给 | 第二节 |
| 卸载不掉 / 强停不了 | 设备管理员 + 严格模式 | 第六节 |

## 二、新装完就不生效：权限没给全

按这个顺序查（各厂商菜单名略有出入）：

1. **使用情况访问**：`设置 → 应用 → Stay Focused → 权限` 看是否允许；再到 `设置 → 密码与安全/隐私 → 特殊应用权限 → 使用情况访问`（或「访问使用情况」）里确认它的开关是开的。**这项不给，应用拦截 100% 不生效**。
2. **通知静音不生效**：`设置 → 通知 → 通知使用权/读取通知` 里开启 Stay Focused。
3. **网站拦截不生效**：`设置 → 无障碍 → 已安装的应用` 里开启 Stay Focused 的服务（可选权限，见第四节）。
4. 给完权限**把应用杀掉重开**（最近任务里划掉再打开），再试一次规则。

规则本身也要核对：对象勾没勾对、方式选没选错、时间区间是否覆盖「此刻」、规则开关是否启用。最省事的验证法是建一条「从现在开始拦 5 分钟」的临时规则当场点开被拦应用 —— 弹了，说明链路通，之前只是规则没配到点上。

## 三、以前好好的，现在不拦了：权限被收、后台被杀

这是安卓上最高频的原因，按命中率排序：

1. **权限被系统自动关**：回到第二节逐项复查。国产 ROM 更新系统、清理加速、"一键优化"之后尤其容易发生。
2. **电池优化把应用杀了**：`设置 → 电池 → 电池优化`（或「省电策略」）里把 Stay Focused 设为**不优化 / 允许后台运行**；在最近任务里把它**加锁**（小锁图标），别让它被一键清理扫掉。
3. **厂商后台管控**：在「应用启动管理」（华为/荣耀）、`自启动`+`关联启动`（小米等）里把 Stay Focused 设为手动管理、允许自启动。系统清理或重启后它没起来，拦截自然停摆。
4. **应用被更新或重装后权限重置**：安卓在应用更新后偶发重置无障碍与通知使用权，重开一次即可。

每次手机系统更新、跑完「清理」类操作之后，顺手点开 Stay Focused 确认它的通知栏常驻还在、规则页正常 —— 这是这类应用是否活着的最快指示。

## 四、只有网站拦不住

网站拦截多依赖一条独立链路（无障碍读取当前网页），单独排：

- **无障碍没开或被收走**：`设置 → 无障碍` 里确认开启；很多 ROM 在省电时优先关无障碍，同样要加进电池优化白名单。
- **浏览器不受支持**：官方口径是「在受支持的浏览器中拦截网站与 URL」，但没公布完整清单 —— 系统自带浏览器与主流 Chromium 系浏览器一般在列，小众浏览器、另开的网页容器型入口不一定。先拿主流浏览器测一次，能拦就是那个入口不支持。
- **只想要应用拦截**：那就别纠结这条线 —— 应用拦截不走无障碍，权限给齐就稳（见[权限用途与隐私说明.md](权限用途与隐私说明.md)）。

## 五、到期了还一直拦着

1. **先看严格模式**：在锁就没到解除条件，不是故障 —— 到期时间、PIN、扫码、随机文本按你当初设的走，见[严格模式怎么开启与解除.md](严格模式怎么开启与解除.md)。
2. **没开严格模式还拦**：多半是另一条规则还在生效 —— 你可能配了多条规则/多个档案，时间重叠；或「每日限额」今天已经用完（那不是故障，是额度耗尽，第二天重置，也可以去把限额调高）。
3. **白名单模式搞反了**：白名单（只允许名单内）会让名单外的**全部**被拦，看起来像「怎么什么都拦」。回[应用与网站拦截规则怎么设置.md](应用与网站拦截规则怎么设置.md)第四节核对名单方向。

## 六、卸载不掉 / 强停不了

这是设备管理员权限在起作用（配合严格模式的设计），不是系统出错：

1. 先确认严格模式状态：锁着就等解除条件满足，或按你设的条件解锁。
2. 锁已结束还卸不掉：`设置 → 应用 → Stay Focused → 卸载`，若提示设备管理员占用，先到 `设置 → 安全 → 设备管理应用`（或「加密与凭据」下）取消它的管理员勾选，再卸载。
3. PIN 忘记、解除条件无法完成：官方商店页公布邮箱 `ava@innoxapps.com`，写邮件说明锁定内容与开启时间询问处理方式。流程与边界详见[严格模式怎么开启与解除.md](严格模式怎么开启与解除.md)第五节。

## 七、还不行的兜底顺序

1. 确认装的是完整包（对照[下载与安装教程.md](下载与安装教程.md)第二节的版本与大小）；
2. 在应用内找「重置设置 / 重新授权」类入口，重走一遍权限引导；
3. 重启手机（重启后顺带复查第三节的权限与后台设置 —— 重启常是权限重置的触发点）；
4. 换个时间段建 5 分钟临时规则复测，排除规则配置问题；
5. 以上都无效，带「机型 + 系统版本 + 症状 + 已查项」写邮件给官方（`ava@innoxapps.com`）—— 附上这些信息能让对方一次定位，比反复追问快。
