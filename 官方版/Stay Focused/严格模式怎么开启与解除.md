## 一、两条模式锁的不是同一件事

官方对两条模式的说法是「防止你修改配置文件、绕过应用」，但它们的锁点有分工：

| 模式 | 锁的是什么 | 解除代价 |
| --- | --- | --- |
| Strict Mode（严格模式） | 锁「拦截规则本身」：开着期间你改不了、关不掉已生效的拦截 | 到期自动结束，或按你设的解除条件完成才结束 |
| Lock Mode（锁定模式） | 锁「进入设置的门」：改任何设置都要先验证 | 每次改设置时验证一次 |

实际使用里 Strict Mode 是主菜 —— 它针对的就是「刷到一半手痒去把规则关了」这个瞬间。官方商店页也点明它有多种加强解锁条件（截至 2026-09 页面信息，以官方当时显示为准）：

- **PIN 码**：开启时设一串数字，解除时必须输对；
- **到期时间**：设定到某个日期/时刻才允许解除，此前一直锁着；
- **二维码扫描**：解除时需要扫指定的二维码才能继续（二维码生成与放置方式以应用内当时显示为准）；
- **随机文本输入**：解除时要求逐字输入一段随机生成的文字，防手滑秒解。

**开之前先想好用哪种解除条件**：设了到期时间就等于接受「到期前没有后悔药」；PIN 一定要记牢 —— 官方公开材料里没有自助找回流程，忘了只能走第四节的途径。

## 二、开启前的检查清单

严格模式锁的是「规则不被改」，前提是规则和权限本身已经就位。开之前确认：

1. 拦截规则已配好并验证过能弹拦截页（见[应用与网站拦截规则怎么设置.md](应用与网站拦截规则怎么设置.md)）；
2. 「使用情况访问」权限在位；要拦网站的话「无障碍」也要在（见[权限用途与隐私说明.md](权限用途与隐私说明.md)）；
3. **给必要应用留了出路**：电话、短信、相机、支付、紧急联系人放进白名单 —— 严格模式期间你改不了规则，锁死的电话打不出去不是开玩笑；
4. 想清楚解除条件（上一节四选一）并记下 PIN；
5. 确认自己真要锁到那个时间点 —— 以「到期时间」解锁的锁，到期前撤不回来。

全部打勾再开。开了之后规则进入「锁定期」，中途想改就得先走解除流程。

## 三、设备管理员权限与防卸载

Stay Focused 支持「设备管理员」权限，官方隐私页写明其用途：**启用后可以防止你自己卸载或强行停止它**，这是 Strict Mode 的配套保险 —— 否则拦截一弹出来，你直接卸载应用就绕过去了。

给不给这项权限，取舍很直接：

- 给：锁定期内卸载不了、强停不了，拦截的强制力完整；代价是这期间想卸也卸不掉。
- 不给：随时能卸，拦截只防「无意点开」，防不了「认真想绕」。

官方口径是 **Strict Mode 结束之后，你可以从手机或 Stay Focused 的设置里正常卸载、关闭设备管理员权限**。也就是说这把锁有终点，不是永久绑定 —— 但终点由你开启时设定的解除条件决定。

## 四、解除与卸载的正常路径

按状态对号入座：

| 你的情况 | 怎么办 |
| --- | --- |
| Strict Mode 在锁，但到了设定的到期时间 | 打开应用，进严格模式页确认已到期，正常关闭即可 |
| Strict Mode 在锁，设的是 PIN / 扫码 / 随机文本 | 按提示完成验证后关闭 |
| 锁已结束，想停用拦截 | 直接在应用里关规则或退出档案 |
| 锁已结束，想彻底卸载 | 先在系统「设置 → 应用」里停用它的设备管理员权限，再正常卸载；或从 Stay Focused 自带设置里的卸载入口走 |
| PIN 忘了 / 解除条件完成不了 | 见下一节 |

## 五、解不开时的处理

先分清是「哪种解不开」：

- **拦截页拦住了操作，但不是严格模式**：只是普通规则命中了，去关那条规则即可（没开严格模式的话设置改得动）。
- **严格模式真在锁、且条件没到**：那就只能等条件满足（到期时间到、或按要求完成验证）。这正是你当初设它的目的，别把它当成故障。
- **PIN 忘记或验证条件无法完成**：官方商店页公布的联系邮箱是 `ava@innoxapps.com`（[官网](https://www.stayfocused.me/)亦有入口），带上你锁定了什么、大概什么时候开的，写邮件问官方有没有处理流程 —— 这是目前公开材料里唯一的官方途径。
- **急着要用电话等必要应用**：先把必要应用确认进白名单（见第二节）；已经锁死了的话，等锁结束。拦截期间改不了规则是设计如此，不是故障。

怀疑「我没开严格模式却改不了设置」，那是另一类问题（权限或系统限制），看[拦截不生效怎么办.md](拦截不生效怎么办.md)。
