## 一、先分清是哪种「没响」

| 现象 | 大概率原因 | 去哪节排查 |
| --- | --- | --- |
| 整天没收到每日提醒 | App 内或系统通知开关、电池限制、改过时区 | 第二节 |
| 通知来了但晚了几小时 | 省电模式拦了后台、系统延迟投递 | 第二节第 3、4 步 |
| 通知来了但没声音 | 通知渠道的声音被单独关掉 | 第二节第 2 步 |
| 验证码收不到 | 运营商拦截或号码填写错误 | 第三节 |
| 发布一直转圈、上传失败 | 网络或服务端波动 | 第四节 |

## 二、每日提醒没来的排查顺序

按下面的顺序查，多数问题在前三步就能解决：

1. **App 内通知开关**：进资料页 → 右上角进入设置 → 通知，确认「每日 BeReal」「好友发帖」「评论」「RealMoji」这些分项都开着。只要有一项被关，对应的提醒就不会来。
2. **系统通知开关**：手机设置 → 应用 → BeReal → 通知，打开「允许通知」，并确认锁屏、横幅、声音这些呈现方式没有被单独关掉。
3. **电池优化与省电模式**：省电模式会冻结后台应用，通知就被压到下次打开 App 才出现。把 BeReal 从电池优化里排除（安卓在 设置 → 电池/应用 的电池选项里选「不受限制」；iOS 关掉针对 BeReal 的低电量限制，并确认后台 App 刷新开着）。
4. **后台数据**：安卓在 设置 → 应用 → BeReal → 移动数据 里，允许「后台数据使用」；关掉它，服务器发的提醒到不了手机。
5. **勿扰/专注模式**：这类模式会按规则静音通知，把 BeReal 加入允许名单，或在使用时段关闭该模式。
6. **时区**：官方帮助中心明确说明 —— **更改时区后，当天不会再收到通知**；时区设置每 24 小时只能改一次。跨时区出行当天没提醒属正常现象，第二天恢复。换时区还有一个副作用，见 [回忆存档与照片保存.md](回忆存档与照片保存.md)。
7. **重启手机**：以上都正常还收不到，重启一次再看。
8. **是不是大家都没收到**：问问身边同用 BeReal 的朋友，或用 [Downdetector](https://downdetector.com/status/bereal/) 这类状态页看是否在批量报障 —— 服务端故障只能等官方恢复，你这边怎么调都没用。

排查完可以在当天任意时刻打开 App 直接补拍：过了 2 分钟窗口的照片只会带迟到标记，规则见 [每日提醒与双摄拍摄玩法.md](每日提醒与双摄拍摄玩法.md)。

## 三、注册验证码收不到

BeReal 的验证码有效期只有一两分钟，过期作废属正常机制。收不到或总提示过期时，按这个顺序处理：

1. 确认国家区号和号码本身填对了（手滑多打或少打一位最常见）；
2. 短信被归进「拦截」「推广」分类的，去拦截记录里找；
3. 开关一次飞行模式再点重新发送，用新码立刻输入；
4. 连续失败会触发短时间限制，隔半小时左右再试。

更完整的注册流程说明在 [注册登录与账号设置.md](注册登录与账号设置.md) 第三节。

## 四、发布转圈、上传失败

1. 先确认网络本身可用（换个网页能不能打开）；
2. 彻底关掉 App 重开，再试一次发布；
3. 安卓可清除应用缓存（设置 → 应用 → BeReal → 存储 → 清除缓存）；iOS 直接重装 —— 账号数据在云端，重新登录即可；
4. 版本太旧也可能上传异常，按 [下载与安装教程.md](下载与安装教程.md) 的方式更新到新版本；
5. 身边人也传不上去，就是服务端波动，等一会儿再发 —— 当天只要发了就算数，迟到标记不影响玩法。

## 五、其他高频问题速查

| 问题 | 处理 |
| --- | --- |
| 打不开、闪退 | 更新到新版本；清缓存或重装；确认系统版本满足要求 |
| 看不到朋友的照片 | 你还没发当天的帖子 —— 先拍先发，规则见 [每日提醒与双摄拍摄玩法.md](每日提醒与双摄拍摄玩法.md) |
| 改了时区后少了一天照片 | 时区变更会移除当天帖子且不可恢复，说明见 [回忆存档与照片保存.md](回忆存档与照片保存.md) |
| 换手机登录不上 | 用注册手机号重新收验证码；号码停用走官方帮助中心表单，见 [注册登录与账号设置.md](注册登录与账号设置.md) |
| 想删掉发出去的照片 | 当天帖子右上角三点菜单选删除，注意连带影响，见 [每日提醒与双摄拍摄玩法.md](每日提醒与双摄拍摄玩法.md) |

以上排查都无效时，通过官方帮助中心 [help.bereal.com](https://help.bereal.com/hc/en-us) 提交工单，描述设备型号、系统版本与问题现象，官方支持会跟进。
