# Power Clean 功能与日常使用

> 本篇按日常实际会点到的顺序讲 Power Clean 的主要功能：清理、内存加速、应用管理、设备信息，以及哪些功能需要先给系统权限才能生效。

## 一、功能一览

| 功能 | 做什么 | 适合什么时候用 |
| --- | --- | --- |
| 一键清理 | 清缓存、释放内存 | 日常随手清理 |
| 深度清理 | 扫存储卡上的残留文件、无用安装包 | 存储空间吃紧时 |
| 缓存清理 | 按应用列出缓存，勾选清除 | 只想清某几个应用时 |
| 痕迹清理 | 浏览器历史、通话记录 | 出借手机前、定期清痕迹 |
| 短信清理 | 批量删除选定的短信 | 验证码、通知短信堆积时 |
| 内存加速 | 关闭后台运行的应用 | 切换应用变慢、卡顿 |
| 应用管理 | 批量卸载、备份 APK、转移到 SD 卡 | 换机前整理、腾内部空间 |
| 设备信息 | CPU / 电池温度、硬件状态 | 手机发烫时查原因 |
| 充电锁屏 | 充电时显示电量、整合通知的锁屏画面 | 想让充电时的界面更实用时 |

功能入口位置以你装的 3.1.4 版实际界面为准。

## 二、一键清理与缓存清理

- 打开应用后首页通常就是「一键清理」，点一次走完扫描 → 清理，日常用它就够了；
- 单独的「缓存清理」会把每个应用的缓存逐个列出，你可以只勾选部分——比如清掉视频类应用的缓存，保留聊天应用的缓存，避免聊天里的图片重新加载变慢。

## 三、深度清理与痕迹清理：动手前先想一下

- 深度清理扫的是存储卡上的文件：卸载残留、无用安装包等。删除前逐项确认，不要整批全选，有些「残留」你可能还要用；
- 痕迹清理会动浏览器历史和通话记录，短信清理会真的删短信，这两类操作删了就找不回来，动手前确认没有要留的记录；
- 想让某些应用的缓存或数据不被清掉，先把它们加入忽略 / 白名单（入口位置以实际界面为准），再跑清理。

## 四、内存加速

- 点「加速」列出正在后台运行的应用，一键关闭；
- 不想被关掉的应用（正在下载、正在播放音乐）先加入忽略名单，否则每次加速都会被关掉；
- 部分机型上「彻底关闭后台」要授予辅助功能（无障碍）权限，这个权限比较敏感，给不给由你自己权衡，不给也能用普通加速；授权后仍不生效，见[常见问题与解决.md](常见问题与解决.md)。

安卓 14 及以上还有一条要提前知道的系统行为：Android 官方文档明确，第三方应用关闭后台进程的接口只能作用于它自己，对其他应用不再生效；同一份文档也说明第三方应用无法改善设备的内存、功耗或散热表现。也就是说，在新系统上「加速」的实际效果有限，更现实的用法是把它当后台占用清单看，然后到系统设置里对常驻的应用逐个限制。

## 五、应用管理

清理类应用里，应用管理是与存储空间关系最直接的一块：

- **批量卸载**：勾选多个应用一次卸载；
- **备份 APK**：把已装应用导出成安装包文件，换机或误删后直接重装，重装方法见[下载与安装教程.md](下载与安装教程.md)；注意备份出来的是安装包本身，不含应用的数据与登录状态，重装后应用内部是空的，聊天记录之类要单独先导出；
- **转移到 SD 卡**：把支持搬移的应用数据挪到 SD 卡，给内部存储腾地方；能搬多少取决于系统版本，安卓新版本对此限制变多。

## 六、设备信息与温度监控

- 查看电池温度、CPU 温度、内存占用；
- 手机发烫时，先看这里列出的高耗电应用，把最耗的那一个处理掉，比整机加速更对症。

## 七、桌面小部件与晃晃清理

- 主屏小部件提供一键加速入口，不用每次进应用；
- 「晃晃清理」开启后晃动手机触发清理，介意误触就不开，不影响其他功能。
