## 一、装不上或被拦截

| 现象 | 处理 |
| --- | --- |
| 提示「不允许安装未知来源」 | 按提示授权「来自此来源的应用」后重试，完整步骤见[下载与安装教程.md](下载与安装教程.md) |
| Play Protect 弹安全警告 | 非商店安装包的正常提示，继续或取消自行决定 |
| 安装到一半失败 | 先核对安装包 MD5（方法见下载篇），确认完整后再清出一些存储空间重试 |
| 桌面没有图标 | 重启手机；仍没有则检查是否装到了工作资料 / 访客空间里 |
| 提示「应用未安装」 | 逐项排查：核对 MD5 确认安装包完整（方法见下载篇）；确认存储空间够用；手机里残留过签名不同的旧版时，先卸载再装 |
| 报错带「deprecated SDK」字样 | 这是安卓 14 起的系统限制：目标 API 低于 23 的安装包不允许安装，换一份包也解决不了，只能放弃这份安装包 |

## 二、功能点了没反应

- **加速、静默卸载不生效**：这类功能在部分机型上需要「辅助功能（无障碍）」权限，到系统设置 → 无障碍里查看 Power Clean 的授权状态；
- **扫描不到东西**：首次使用需要授予存储权限，授权后重新进入扫描页；
- **桌面小部件不刷新**：部分系统会把清理类应用限制后台，在系统设置的电池选项里允许它后台运行，小部件才会正常工作；
- **开机自启失效**：部分国产 ROM（MIUI、EMUI 等）要在「自启动管理」里另外放行；
- **加速点了像没效果**：安卓 14 及以上是系统行为，第三方应用只能关闭自己的后台进程，关不了其他应用（说明见[功能与日常使用.md](功能与日常使用.md)第四节）；把加速当后台占用清单看，再到系统设置里逐个限制常驻应用。

## 三、清理之后数据找不回

- 短信、通话记录、浏览器历史删掉后没有内置的恢复功能，删前务必确认；
- 照片和文件类清理只处理它扫描出的「垃圾」分类，正常相册目录不会被整批动；重复文件清理以扫描结果为准，勾选前看清保留的是哪一份；
- 担心误删，先把聊天、相册类应用加入忽略名单，再跑深度清理。

## 四、广告与通知

- 免费、无内购门槛的清理类工具界面里带广告位是常态，广告形式随版本不同；
- 不想收到它的通知：长按它发的通知关闭该应用通知，或到系统设置 → 应用 → Power Clean → 通知里关掉；
- 系统层面没有全局关闭应用内广告的正规途径，遇到整个界面被广告占住的版本，说明那份安装包来路可疑，换回核对过 MD5 的原始包（获取方式见[下载与安装教程.md](下载与安装教程.md)）。

## 五、安全扫描功能怎么看

- 3.1.4 这类版本里带有「病毒扫描」「WiFi 安全检查」入口；
- 有第三方安全评测（Trustlook，2019 年）实测后指出：对病毒样本的检出结果不可靠，WiFi 风险检测在构造的攻击环境下也未报警；
- 两边口径并列给你：官方把它当安全能力宣传，独立评测认为其检出能力有限。比较稳妥的用法是把它当清理与加速工具，安全防护交给系统自带的安全中心或 Play Protect；
- 它为什么从 Google Play 消失、公开报道里有哪些说法，见[下架原因与渠道现状.md](下架原因与渠道现状.md)。

## 六、想卸载时

- 系统设置 → 应用 → Power Clean → 卸载，或长按桌面图标卸载；
- 之前加了桌面小部件的，卸载后把残留的小部件从桌面移除一次即可。
