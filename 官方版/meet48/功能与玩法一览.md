## 一、这是个什么应用

MEET48 是丝芭传媒（SNH48 GROUP 的运营方）体系下、面向全球粉丝的偶像互动平台，2024 年年中上线，把追星这件事搬进了带区块链机制的应用里：你完成的应援动作会变成积分和投票券，投票排名会被公示。首次进入按提示注册账号即可，钱包由应用内置托管，官方团队访谈中说明这套方案让粉丝无感使用，你不需要自己备份助记词或提前懂区块链技术（具体流程以 app 内实际提示为准）。

## 二、界面里有什么

以 1.8.9 版为参照，日常使用集中在几块：

| 区块 | 你能在里面做什么 |
| --- | --- |
| 首页信息流 | 浏览偶像动态与平台最新消息，活动期会置顶投票入口 |
| 社区 | 发帖、互动，和同好讨论成员与活动 |
| 任务中心 | 做每日任务（点赞、看视频、分享等）攒积分 |
| 活动页 | 参与投票活动，用积分或投票券为成员助力 |
| 商店 | 用积分兑换周边、限定数字物品（含 NFT 收藏类）等 |

各版块名称和位置会随版本调整，找不到就翻底部导航或侧边栏，活动期最醒目的入口一定是当前进行中的投票。

## 三、新手上手顺序

1. **注册并完善账号**：首次打开按引导完成注册，能收到活动通知的选项建议打开。
2. **先逛首页和信息流**：确认你关注的团体和成员内容在更新，顺手熟悉界面。
3. **每天清一遍任务**：任务给积分，积分是投票和兑换的来源，日积月累差距很大。
4. **有活动再进活动页**：平时不用刻意研究投票，等活动开始（首页会推）再按 [投票活动怎么参与.md](投票活动怎么参与.md) 操作。

## 四、两件事提前知道

- **积分不是立刻能全花掉的**：部分投票玩法只认活动期间发放的投票券，日常积分和活动券的规则不同，参与前先看活动页规则说明。
- **版本差异**：功能入口随版本变动，本文基于 1.8.9 版；如果界面已经变了，以你手机里的实际显示为准。

想核对活动规则和平台公告，可以到官网 [www.meet48.com](https://www.meet48.com/) 看最新消息。装好后如果对「这和我用的口袋48是不是一回事」有疑问，看 [和口袋48有什么区别.md](和口袋48有什么区别.md)；第一次安装遇到问题回 [下载与安装教程.md](下载与安装教程.md) 排查。
