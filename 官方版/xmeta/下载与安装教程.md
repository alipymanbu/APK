只从上面两类官方渠道和自己的网盘转存进入，搜索引擎里排行靠前的「高速下载器」「打包下载站」不要用，容易带捆绑安装器。

## 二、安卓安装步骤

1. 把 APK 文件下载到手机存储（约 50.35M，留出至少 1G 空间更稳妥）。
2. 在文件管理器里点开这个 APK；系统弹出「禁止安装未知来源应用」提示时，点「设置」进入对应开关页。
3. 找到你用来打开 APK 的应用（文件管理器或浏览器），允许它「安装未知应用」。安卓 8 及以上的通用路径是「设置 → 应用 → 特殊权限 → 安装未知应用」，不同品牌路径略有差异（华为鸿蒙在「设置 → 安全 → 更多安全设置」里）。
4. 返回安装页点「安装」，等待完成。
5. 打开 App，按需允许其申请的权限，进入登录界面。

## 三、iOS 与不想装 App 的做法：H5 网页版

官方下载页目前标注 iOS 原生版暂未开放，苹果手机用户按页面提示使用 H5 网页版：

1. 用 Safari 打开官方下载页 [download.x-metash.cn](https://download.x-metash.cn/index.html)。
2. 按页面提示进入网页版入口，用账号登录。
3. 点 Safari 底部「分享 → 添加到主屏幕」，之后从主屏图标进入，体验接近原生 App。

网页版能提供哪些功能以实际页面为准；部分与支付、发货相关的操作若网页版入口不全，可换安卓设备或在网页版里找对应入口。

## 四、安装失败排查对照表

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「禁止安装未知来源应用」 | 权限未开启 | 按第二节第 3 步给文件管理器/浏览器开权限 |
| 「应用未安装」，且之前装过同应用 | 旧版残留或签名不一致 | 卸载旧版后重新安装 |
| 「解析包时出现问题」 | 文件下载不完整或被改名损坏 | 重新下载，核对文件大小是否约 50.35M |
| 点安装没反应 / 中途失败 | 存储空间不足（安装约需安装包两倍空间） | 清理存储后重试 |
| 系统直接判定不兼容 | 手机系统版本低于安装包要求 | 升级系统，或改用 H5 网页版 |
| 华为/部分新机型反复拦截 | 品牌安全策略（如纯净模式） | 在系统设置中暂时关闭对应拦截后再装 |

动手安装前建议先过一遍下面第五节的信息核对；装好后再进入注册环节，注册流程见[注册与实名认证流程.md](注册与实名认证流程.md)。
