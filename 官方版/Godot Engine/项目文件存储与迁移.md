## 一、项目放在哪里

新建项目时你选的那个文件夹就是项目根目录，之后所有场景、脚本、素材都落在这里，外加一个 `project.godot` 配置文件和一个 `.godot` 缓存目录。

能选哪些位置取决于权限：「所有文件访问」给全了，外置存储等任意可写位置都能建项目；没给的话，可选项非常有限。还有一种特殊情况——Android Go 设备的系统里根本没有「所有文件访问」这项权限，官方给的办法是：项目只建在「文档（Documents）」或「下载（Downloads）」目录里。

## 二、备份就是把整个文件夹抄一遍

一个 Godot 项目就是一个文件夹，复制整个文件夹就是完整备份，没有额外的导出动作。两点实操建议：

- `.godot` 目录是导入缓存，体积往往不小，备份时可以不带它——换设备打开项目时它会自动重新生成、重新导入一遍；
- 用网盘或同步盘备份时，把 `.godot` 排除在同步范围外更稳，两台设备来回同步缓存目录容易互相顶掉。

## 三、手机与电脑之间怎么搬

把项目文件夹整个拷走就行（数据线、局域网共享、云盘中转都可以）。到了另一头，用什么版本的编辑器打开是关键：

- **最稳**：电脑上也装 4.4.1，和手机上这份完全同版本。官方归档页有 4.4.1 的各平台安装包：[godotengine.org/download/archive/4.4.1-stable](https://godotengine.org/download/archive/4.4.1-stable/)；
- **可行但要留意**：更高版本一般也能打开 4.4 的项目，但编辑器会执行升级动作，配置不保证逐字兼容，跨大版本前先读官方迁移文档（4.3 升 4.4 的那篇在 [docs.godotengine.org](https://docs.godotengine.org/en/4.4/tutorials/migrating/upgrading_to_godot_4.4.html)）；
- **方向反过来也一样**：电脑上用 4.7 改过的项目，拿回 4.4.1 的手机编辑器打开，可能会遇到新版本才有的特性或格式变化，尽量别双向跨版本。

搬运前把手机上打开的场景和脚本都保存一遍，避免拷出去的是旧内容。

## 四、用 Git 在多台设备间同步

项目文件夹本身就是 Git 仓库的标准形态，官方文档推荐的做法是在安卓上装 [Termux 终端](https://termux.dev/en/)，用它跑 git 和 ssh：第一次用先在 Termux 里执行 `termux-setup-storage` 把存储写权限授给终端，之后就可以在手机上正常提交、拉取。

把 `.godot/` 写进 `.gitignore` 是惯例做法——它属于本地缓存，进版本库只会让仓库无意义地膨胀。

## 五、一个会让「现场」丢失的开关

开发者选项里的「不保留活动（Don't keep activities）」如果开着，编辑器切到后台再回来无法正确恢复，这是官方文档列出的已知问题——正在编辑的内容直接回到上次保存的状态。两个对策：关掉这个开发者选项；或者养成高频保存的习惯（手机上没有顺手的双指快捷键，就多点保存按钮）。
