# 用 Godot Engine 在手机上开发游戏可行吗

> 结论先行：能建项目、能写代码、能跑预览，但它目前是「早期体验」阶段的补充工具，这篇把能做的、做不了的、适合谁一次说清。

## 一、先说结论

在手机上用 Godot Engine 做 2D 和 3D 项目是真的能跑通的：新建项目、编辑场景、写 GDScript、运行预览，一整条链路都在。但官方把安卓编辑器标为「早期体验（early access）」阶段，界面没有针对小屏手机优化，外接键鼠几乎是必需品。它更适合的场景是：已经会用 Godot 的人，用平板或大屏手机继续改项目、调关卡、写脚本；而不是从零开始学引擎的新手，在 6 英寸屏幕上完成全部开发工作。

## 二、它能在手机上做到的事

- 新建项目，或导入电脑上创建的项目继续做；
- 编辑 2D / 3D 场景、写脚本、随时运行预览；
- 用非 Gradle 方式导出项目 APK，直接装回本机试玩（仅限不依赖 Gradle 的项目，细节见[在手机上打包 APK.md](在手机上打包 APK.md)）；
- GDExtension 插件可用，前提是插件作者提供了安卓原生库；
- 4.4 起官方还把编辑器带上了 XR 设备——Meta Quest 3 / Quest 3S / Quest Pro 渠道另有发行版。

## 三、它做不了的事（4.4.1 的限制清单）

下面几条来自 4.4 时期的官方文档，每一条都随版本变化，动手前以官方文档为准：

- **不支持 Gradle 构建**：依赖 Gradle 的项目（用到 Android 插件、自定义构建配置的）在手机上打不出包，出路见[在手机上打包 APK.md](在手机上打包 APK.md)；
- 因此也**不支持 Android 插件**（Android plugins），它们依赖 Gradle 构建链路；
- **不支持 C# / .NET**：C# 项目没法在安卓端继续开发，这是安卓编辑器和桌面版差异最大的一条；
- **不能使用外部脚本编辑器**：只能用内置代码编辑器写代码；
- **Forward+ 渲染器不推荐**：官方文档原话是存在严重性能问题。

清单会随版本收紧或放开——比如官方从 4.6 起提供伴生应用 GABE，把 Gradle 构建补到了手机端（2026 年 6 月正式上架）；以你所用版本的[官方文档](https://docs.godotengine.org/en/4.4/tutorials/editor/using_the_android_editor.html)为准。

## 四、体验上的三个现实

1. **屏幕形态决定下限**：官方建议的设备是平板、折叠屏、大屏手机和 Chromebook，小屏手机能装能跑，但面板挤压得很厉害。
2. **键鼠决定上限**：纯触屏写脚本很慢，蓝牙键鼠配上桌面版快捷键才接近正常开发节奏（设置细节见[首次启动与基本操作.md](首次启动与基本操作.md)）。
3. **渲染器选择决定流畅度**：Compatibility 是最稳的一档，选错渲染器会卡到没法用，对照表见[首次启动与基本操作.md](首次启动与基本操作.md)第三节。

## 五、不装 App，先在浏览器里试试

官方提供直接在浏览器里跑的 Web 编辑器，4.4.1 对应的地址是 [editor.godotengine.org/releases/4.4.1.stable](https://editor.godotengine.org/releases/4.4.1.stable/)。适合先摸一下界面和操作逻辑，再决定要不要装 App。

Web 编辑器比本地 App 更吃内存（官方系统需求页对移动端 Web 编辑器标的是 6 GB 内存起步，截至 4.7 文档口径，以官方页面为准），老旧设备在浏览器里未必带得动；而且它没法像 App 一样随时切回来继续，仅当体验入口更合适。
