## 一、先按顺序过这五步

绝大多数同步问题出在前三步。按官方帮助中心的排查顺序：

1. **另一台设备同步了吗**——笔记要等对方设备拉取才会出现。到另一台设备手动同步一次：手机点头像选 `Sync now`，桌面/网页点状态栏的同步图标；
2. **两端是同一个账号吗**——设置里核对两台设备显示的邮箱；
3. **这篇笔记被单独关掉同步了吗**——列表里同步图标被划叉的笔记，是被开了「Sync off」的：它不会同步到任何其他设备。注意官方的明确警告：**给一篇笔记开「Sync off」时会立刻把它从其他设备上删掉**；想恢复同步，再点一次 Sync off 关掉即可，本机这份不受影响；
4. **这台设备的同步被整体关掉了吗**——设置 → Account → Sync 里看「Disable sync」开关；
5. **有笔记卡在冲突状态吗**——冲突笔记会聚在列表顶部「Conflicted」分组里，并且**阻塞后续同步**，处理完冲突才继续走。

五步都正常还缺笔记，才考虑下面的强制操作。

## 二、「Sync disabled」图标的两种含义

状态栏提示 Sync disabled 时，看图标区分：

| 图标 | 含义 | 处理 |
| --- | --- | --- |
| 灰色的关闭图标 | 你自己在设置里开了 Disable sync | 回设置 → Account → Sync 关掉它 |
| 红色警报图标 | 注册邮箱还没点验证链接 | 状态栏会同时显示 Email not confirmed，去邮箱补确认 |

邮箱明明已确认却仍被这么提示：官方说明是服务器状态偶发滞后，应用会在下一次同步时自动刷新登录令牌，通常再同步一次就好；不行就退出重登。

## 三、提示未登录或「Unauthorized」

会话过期时会提示 Not logged in，或同步报 `Unauthorized.` / `User encryption keys not generated. Please relogin.`——都是同一件事：**退出再登录即可**，本机笔记还在，不用重新下载。

特别提醒：**不要用卸载重装来解决登录问题**。从来没上传成功的笔记只存在于这台设备上，卸载即丢。真要折腾登录，先做一份加密备份（做法见[导入与导出笔记](导入与导出笔记.md)）。

## 四、「Sync failed」报错对照

| 提示 | 含义 | 处理 |
| --- | --- | --- |
| 无具体提示，状态只是变成 Sync failed | 30 秒内连不上同步服务器 | 换网络再试；公司网/防火墙/VPN 后面常见 |
| Sync Server is not responding… | 服务器完全没有响应 | 检查本机网络 |
| You are being rate limited | 短时间请求过多被限流 | 停止手动连点同步，等几分钟让它自己跑 |
| Unauthorized. | 会话失效 | 退出重登（见第三节） |
| Failed to send all items. Sent X out of Y | 上传中途断掉 | 直接再同步一次，剩余的还在队列里 |

同步失败不丢本地数据：写下的内容都在设备上，下次同步成功时照常发出去。

## 五、Force push / Force pull：会覆盖数据，最后再用

这两个按钮（设置 → Account → Sync）只用于「数据确实漂移了」的修复，不是更强力的「立即同步」：

| 按钮 | 做什么 | 代价 |
| --- | --- | --- |
| Force push changes | 用**这台设备**的数据覆盖服务器 | 服务器上这台设备没见过的改动会丢 |
| Force pull changes | 用**服务器**的数据覆盖这台设备 | 本机从没上传成功的改动会丢 |

官方原话的要点：这样毁掉的数据**无法找回**；经常拿它们当日常同步用，也正是被限流的主因。按下之前先备份。

## 六、后台同步（实验性，手机端）

设置 → Account → Sync settings 里有「Background sync (experimental)」：应用关着也由系统定期唤醒同步。特点：

- 所有套餐可用，仅手机端有；
- 由操作系统安排时机，最多约 15 分钟一次，重启手机后自动恢复；
- 它是尽力而为，不保证另一台设备打开的瞬间就是最新的；遇到异常就关掉。

桌面端和网页版没有这一项——应用运行期间才会同步（桌面关到系统托盘也算在运行）。

## 七、状态栏图标速查

| 提示 | 含义 |
| --- | --- |
| Synced {时间} ago | 全部是最新的 |
| Syncing / Downloading / Uploading | 正在同步，括号里是已传输条数 |
| Merge conflicts（红色三角） | 有笔记冲突等你处理，处理后恢复同步 |
| Sync disabled + 红色警报 | 邮箱未确认 |
| Sync failed | 上一次同步没跑完 |
| Synced {时间} ago (offline) | 当前没有网络 |
| Sync disabled + 灰色图标 | 你在设置里关掉了同步 |

点这个图标即可手动同步（同步被禁用时除外）。
