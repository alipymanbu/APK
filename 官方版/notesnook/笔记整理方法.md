## 一、六种整理维度，别全用

Notesnook 给的整理手段不少，全用上反而乱。按「什么情况用哪个」来选：

| 维度 | 适合放什么 | 例子 |
| --- | --- | --- |
| 笔记本 | 一个明确的主题或项目，笔记长期属于它 | 「工作」「读书笔记」 |
| 标签 | 跨主题的共同属性，一篇笔记可挂多个 | 「待办」「2026」「灵感」 |
| 颜色 | 需要在侧边栏一眼直达的高频类目 | 红色 = 紧急事务 |
| 收藏 | 常要翻开的少数几篇 | 配置清单、常用资料 |
| 置顶 | 当前正在推进的事 | 本周的任务清单 |
| 归档 | 不再活跃但不想删的 | 去年做完的项目 |

经验顺序：先用笔记本定大框架，再按需加标签；颜色、置顶、收藏留给真正高频的东西。笔记本支持嵌套子笔记本，大主题下再分小题即可，用不着一口气建几十个平级笔记本。

## 二、免费额度够不够用

免费计划允许无限笔记、无限设备，但整理维度有数量上限。以[官方套餐页](https://notesnook.com/help/plans-and-limits)为准，免费档大致是：

| 项目 | 免费额度 |
| --- | --- |
| 笔记本 | 50 个 |
| 标签 | 50 个 |
| 颜色 | 7 种 |
| 活动提醒 | 10 个 |
| 侧边栏快捷方式 | 10 个 |
| 笔记历史版本 | 100 个 |

个人日常使用，50 个笔记本/50 个标签通常够；真不够再考虑付费档（额度对比以官方套餐页当时显示为准）。

## 三、笔记之间的互链

在一篇笔记里引用另一篇，用的是笔记链接：

- 编辑时输入 `[[`（或从工具栏插入链接）选择目标笔记，生成跳转链接；
- 被引用的那篇会显示「被哪些笔记引用」（反向链接），六个月前关联过的思路还能顺藤摸回去；
- 删掉链接不会删掉笔记本身。

这套链接适合把零散笔记串成主题：一篇「项目总览」链接到会议记录、资料页，翻总览就能到全部相关笔记。（精确链到某一段的块级链接属付费功能范围，以官方套餐页为准。）

## 四、侧边栏与搜索

- **侧边栏快捷方式**：笔记本、标签、颜色都能加进侧边栏，免费档最多 10 个，把最常用的放进去；
- **搜索**：顶栏搜索框做全库检索；先进入某个笔记本或标签页再搜，就是在当前范围内搜；
- **回收站**：删除的笔记先进回收站，到期自动清空（免费档不能关闭自动清理，属付费范围），误删从这里恢复。

## 五、一套可直接照抄的整理结构

从零开始的话，可以直接套这个：

1. 建 3~5 个笔记本：工作、个人、学习、临时收集；
2. 「临时收集」放一切未定型的东西，每周清一次：定型的移进对应笔记本，没用的删掉；
3. 标签只建两类：「状态」（进行中/已完成）和「来源」（网页剪藏/手写）；
4. 侧边栏放：活动中的提醒、进行中标签、最常用的 1~2 个笔记本。

结构轻一点、搜索补足剩下的，比建几十个笔记本再用不过来强。
