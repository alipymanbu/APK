## 一、支持的导入来源

导入器在应用内：**设置 → Importer（导入）**，全程在你自己的设备上跑，笔记不经过第三方。

| 来源 | 说明 |
| --- | --- |
| Evernote | 支持导出的 ENEX 文件 |
| Google Keep | 支持 Google Takeout 导出的 ZIP |
| Obsidian / Joplin / Simplenote | 各自的导出格式 |
| ColorNote / UpNote / Zoho Notebook / Fusebase | 各自的导出格式 |
| Markdown / HTML / 纯文本文件 | 单个或整包 |
| TextBundle | 带附件的打包格式 |

每个来源的具体导出步骤，官方帮助中心（[notesnook.com/help](https://notesnook.com/help/docs)）有对应页面，搜来源名字即可。

## 二、导入的实际操作与注意点

1. 先在旧应用里把笔记**完整导出**（Evernote 用 ENEX 全量导出，Keep 走 Google Takeout）；
2. 把导出文件传到要导入的那台设备上（网页版/桌面版屏幕大、选文件方便，比在手机上操作省事）；
3. 在设置 → Importer 里选对应来源、选文件，开始导入；
4. 导入完成后先抽查几篇：正文、图片、附件是否都在，确认没问题再动旧应用里的东西。

注意：

- 大批量导入（上千篇）耗时不短，插着电等它跑完；
- 导入是把旧笔记**复制**进来，旧应用里的原文不受影响；
- 图片和附件占附件额度（免费档每月 50 MB 流量、单文件 10 MB），带大附件的笔记要有预期。

## 三、导出：随时能带走

| 导出方式 | 得到什么 | 适合 |
| --- | --- | --- |
| 单篇导出 | PDF / HTML / Markdown / 纯文本 | 分享一篇、挪去别的软件 |
| 批量导出 | 同上，按笔记本或全库 | 整体迁移 |
| 加密备份 | 官方格式的备份文件 | 换机恢复、防灾 |

备份文件可以在任何一台设备上的 Notesnook 里恢复。同步解决日常，加密备份解决万一——定期做一份放在本地，是「怕丢笔记」最直接的办法。

## 四、从旧笔记应用整体搬家的路线

三个最常见场景：

- **Evernote → Notesnook**：Evernote 里逐本笔记本导出 ENEX → Notesnook 导入器读 ENEX → 按笔记本导入；
- **Keep/手机备忘录 → Notesnook**：Keep 走 Google Takeout 拿 ZIP 后交给导入器；手机自带备忘录多数只能逐篇复制，量少就手动搬；
- **Obsidian → Notesnook**：库本身就是 Markdown 文件，导入器直接读，不需要先转格式；还在犹豫要不要搬的，先看[与Obsidian怎么选](与Obsidian怎么选.md)。

搬家完成后两边各自独立，旧应用随时可删——建议留一两周再删，确认没有漏网的。
