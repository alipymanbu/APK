## 一、基础排版元素

编辑器是所见即所得的富文本，常用元素直接从工具栏点出来：

| 元素 | 怎么插入 | 备注 |
| --- | --- | --- |
| 标题 | 工具栏选级别，或输入 `#` 加空格 | 小节可折叠 |
| 列表 | 有序/无序/任务列表按钮 | 任务列表可勾选 |
| 表格 | 工具栏插入 | 免费档可建表；表格与 CSV 互导属付费范围 |
| 代码块 | 工具栏插入 | 带语法高亮 |
| 数学公式 | 工具栏插入 | LaTeX 写法 |
| 图片/附件 | 工具栏插入或直接粘贴 | 额度见第四节 |
| 提示块（callout） | 工具栏插入 | 属付费功能范围 |

各功能的付费归属以[官方套餐页](https://notesnook.com/help/plans-and-limits)为准，该页会随版本调整。

## 二、Markdown 快捷输入

在编辑器里直接打 Markdown 语法，会自动变成对应格式：

| 输入 | 得到 |
| --- | --- |
| `# ` / `## ` / `### ` | 一/二/三级标题 |
| `- ` 或 `* ` | 无序列表 |
| `1. ` | 有序列表 |
| `[] ` | 任务列表 |
| `> ` | 引用 |
| `**文字**` | 加粗 |

注意：Markdown 快捷输入属付费功能范围（免费档用工具栏手动排版），以官方套餐页为准。

## 三、任务列表与提醒

- **任务列表**：一列可勾选的条目。3.4.9 版起触屏上长按拖动排序已经稳定——这是该版本重点修的问题，之前长按经常变成选中文字；
- **提醒**：给笔记设定时提醒，免费档同时生效 10 个；每天/每周这类**重复提醒**属付费范围；
- **通知栏速记**：安卓端可以把笔记钉在通知栏快速查看或从通知栏直接记（属付费范围）。

## 四、附件额度（免费档）

| 项目 | 免费额度 |
| --- | --- |
| 单个文件上限 | 10 MB |
| 每月附件流量 | 50 MB |
| 原图上传（不压缩） | 属付费范围 |

额度只算图片、文件、音频这些**附件**，笔记文字本身不占。图片传不上去、画质被压缩，先对照这个表。

附件默认按需下载——换一台设备打开笔记时，图片要等联网拉取。想离线也能看到全部附件，在设置里开「Full offline mode」（付费档），代价是应用占用与全部附件等量的存储空间。

## 五、版本历史与回收站

- **版本历史**：每次修改存快照，笔记详情里可翻看并恢复到某一版（免费档保留 100 个版本）；
- **回收站**：删除的笔记在这里，可恢复或彻底删除；
- 不放心云端的话，随时把笔记导出成 PDF/HTML/Markdown/纯文本留底，做法见[导入与导出笔记](导入与导出笔记.md)。

## 六、在电脑上配合手机用

- **网页版**：[app.notesnook.com](https://app.notesnook.com/) 登录同一账号，浏览器里直接读写同一批笔记；
- **桌面版**：Windows/macOS/Linux 都有客户端，官方[下载页](https://notesnook.com/downloads/)可取；
- **网页剪藏**：浏览器扩展 Web Clipper（Firefox 与 Chromium 系浏览器可用），可以先在网页里选中想存的那几段再剪，不必整页照收。
