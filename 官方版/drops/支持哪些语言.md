## 一、数量先说清楚

Drops 主打词汇学习，可学语言的数量比多数同类应用多，而且覆盖了不少主流应用没有的小众语言：截至 2026 年，官方帮助中心的清单列出 57 种，官网首页写的口径是 55+，两种说法都来自官方、只是更新节奏不同。你要查「现在到底有多少种」，以官方页面为准：语言清单见 [https://support.languagedrops.com/hc/en-us/articles/23837237386131-What-Languages-are-Available-to-Learn-in-Drops](https://support.languagedrops.com/hc/en-us/articles/23837237386131-What-Languages-are-Available-to-Learn-in-Drops)。

2025 年 2 月官方一次性加入了 6 种此前主流学习应用基本不覆盖的语言：埃及阿拉伯语、威尔士语、瑞士德语、巴斯克语、格陵兰语、Ch'ti（法国北部方言）。小众与濒危语言多，是这个应用比较突出的特点。

## 二、常见语言举例

下表按用途分几组，方便你对号入座；完整 57 种清单以官方帮助中心为准。

| 用途 | 语言 |
| --- | --- |
| 出行、工作常用 | 西班牙语（卡斯蒂利亚 / 墨西哥）、英语（美式 / 英式）、法语、德语、意大利语、日语、韩语 |
| 国人常学 | 普通话、粤语（中文是「学」的方向，即你以其他语言为界面学中文） |
| 旅途中可能碰到 | 荷兰语、土耳其语、泰语、越南语、印尼语、波兰语、俄语、希腊语、希伯来语 |
| 北欧与小语种 | 挪威语、瑞典语、丹麦语、芬兰语、冰岛语、匈牙利语、爱沙尼亚语 |
| 濒危 / 特色语言 | 夏威夷语、毛利语（Te Reo Māori）、萨摩亚语、阿伊努语、威尔士语、爱尔兰语、巴斯克语、格陵兰语 |
| 其他 | 世界语、梵语（瑜伽方向）、约鲁巴语、斯瓦希里语、伊博语、乌克兰语、波斯语 |

注意一点：Drops 教的是**词汇和短语**，不做系统语法课程；2026 年起官方才开始分批给部分语言加语法练习（详见 [上手与学习方法.md](上手与学习方法.md) 第五节）。如果你的目标是考试或系统语法，它更适合当词汇积累的补充，而不是唯一教材。

## 三、International 版与语言专属应用的区别

官方除了全语言的 International 版，还把一部分语言单独做成了独立应用（比如专学韩语、专学日语的版本）。造成这种局面的原因是应用商店的搜索机制，官方帮助中心有专文说明。要点三条：

1. **内容上是同一家**：语言专属应用里的课程与 International 版对应语言一致，不是两家产品。
2. **Premium 通用于所在应用**：你在任何一个语言专属应用里订阅了 Premium，该应用内的全部语言都解锁，不需要再装好几个 Drops。
3. **官方推荐 International 版**：所有语言在一个应用里，切换学习语言不用换应用。

本文 [下载与安装教程.md](下载与安装教程.md) 对应的安装包包名是 `com.languagedrops.drops.international`，正是官方 International 版在 Google Play 上的包名。所以你不需要纠结选哪个版本。

同时学几门语言、或者切换正在学的语言，操作以官方专文为准：[How many languages can I learn and how do I change my learning language?](https://support.languagedrops.com/hc/en-us/articles/19332287585683-How-many-languages-can-I-learn-and-how-do-I-change-my-learning-language)。不再学的语言也可以从资料里移除，官方帮助中心有对应条目，搜「remove a language」即可。想清空某门语言的进度重来，见 [进度重置与账号注销.md](进度重置与账号注销.md)。

## 四、界面语言

应用界面本身可以换成你顺手的语言（不只是中文界面学外语，也可以反过来）。入口在个人资料（Profile）的设置里，找「界面语言 / interface language」选项；找不到时查官方帮助中心这篇 [How do I set my interface language?](https://support.languagedrops.com/hc/en-us/articles/19332328256531-How-do-I-set-my-interface-language)。

## 五、姐妹应用 Scripts

官方另有一款叫 Scripts 的应用，专门教书写系统与字母表（日语假名、韩语字母、阿拉伯字母，以及美国手语 ASL 字母表等）。它和 Drops 是两个独立应用、分开下载，学字母表的阶段可以配合使用。是否需要它取决于你学的语言：学西语、英语这类拉丁字母语言用不上。
