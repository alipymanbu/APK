## 一、先对齐一件事：你要的是手，还是头

「handmodel」这个名字容易让人以为是手部建模工具。实际分岔在这里：

- **iOS 上的 HandModel**：真正的手部参考工具，开发者 Kosuke Nishioka。用手部模型摆姿势作画参考，还能用摄像头识别你的真实手势来生成模型姿势，带 4 盏可调灯。**只有 iOS 版，没有官方安卓版**。
- **网盘这份安卓安装包**：包名 `io.castain.headmodel`，对应应用是 **Head Model Studio**，主角是**头部**模型，练的是头像、肖像、面部体块与光影。

所以如果你画的是手，网盘这份包并不解决你的问题，往下看替代工具；如果你头和手都要练，这份包可以负责「头」的那一半。

## 二、安卓上可以用的手部参考工具

在主流应用商店里能找到的同类（以商店当时上架情况为准）：

| 工具 | 平台 | 说明 |
| --- | --- | --- |
| Handy Art Reference Tool | iOS / Android | 可调关节角度的 3D 手部模型，还附带头、脚等其他部位 |
| Hand Mannequin | Android | 可摆姿势的 3D 手，支持逐段骨骼调节、4 盏灯、网格辅助 |
| Manikin | iOS | 人物姿势工具，模型含手部，支持多光源、动画与透明底截图 |
| Manus - Hand reference for art | iOS | 逐指调节弯曲、旋转与间距，含男女手模型与预设姿势 |

选择思路很简单：**先看平台**——iOS 用户选择面最宽，安卓用户主要看 Handy 与 Hand Mannequin 这类；**再看操作习惯**——有人喜欢整手拖姿势，有人喜欢逐根手指调，两款都装上试几分钟就知道自己顺手哪个。

## 三、桌面 / 平板生态的补充

如果你在电脑或 iPad 上画，还有一条路：**Clip Studio Paint 2.0 起，软件内置了 3D 头部模型与手部扫描功能**，可以直接在画布里摆姿势、定光源，不用在参考应用和绘画软件之间来回切。已经用 CSP 的话，优先试它自带的手部模型。

## 四、头手都要练的话

- 手部：从第二节表格里按你的平台挑一个；
- 头部：网盘这份 Head Model Studio 安装包可以负责——**[handmodel 安装文件资源（夸克网盘）](https://pan.quark.cn/s/273802a354e1)**，装法与版本信息见[下载与安装教程.md](下载与安装教程.md)，它具体能做什么见[是干什么的.md](是干什么的.md)。

两者配合的典型用法：手部工具定好手势、头部应用定好角度与光源，各截一张图并排摆在画布旁边，比单靠记忆或翻照片省事得多。
