## 一、一句话定位

这份安卓安装包对应的应用是 **Head Model Studio**：给画画的人用的 3D 参考工具。你在里面转动一个 3D 头部模型，从任意角度观察面部结构、体块切分和光影变化，用来辅助人像素描与肖像练习。

## 二、"handmodel"这个名字是怎么回事

这里有个容易混淆的地方，拆开说：

- **HandModel**（iOS 应用，开发者 Kosuke Nishioka）：一个 3D 手部参考工具，可以用摄像头识别真实手势来生成手部模型，只发布在 App Store，没有安卓版。
- **Head Model Studio**（iOS / Android，开发者 Wes Castain）：头部参考工具，安卓包名 `io.castain.headmodel`。

网上流传的「handmodel 安卓版」安装包，包名指向的是 Head Model Studio——也就是本篇说的这个应用。两者是不同开发者的不同应用，只是名字相近、用途同属「绘画参考」这个方向。所以如果你要的是手部姿势参考，这份安卓包并不对口，替代方案看[手部绘画参考工具.md](手部绘画参考工具.md)；如果你练的是头像、肖像，那这份包就是干这个的。

## 三、它具体能做什么

按官方介绍的口径，核心能力有这几块：

| 能力 | 具体内容 |
| --- | --- |
| 模型库 | 25 个不同的头部模型（其中 2 个免费），另有 5 个经典模型方向可扩展练习；从简单分面到复杂几何逐步进阶 |
| 视角控制 | 缩放、倾斜、旋转完全由你操作，想看哪个部位转到哪个部位 |
| 环境光 | 基于 HDR 照片的真实环境照明，可重现日出、正午、日落等光照条件 |
| 影棚光 | 多个聚光灯加不同颜色的布光组合，角度与强度都可调 |
| 渲染选项 | 边缘轮廓可以高亮面部平面（练体块时开、熟练后关）；材质光泽度可改 |
| 练习场景 | 内置一批做好的练习场景，不知道从哪开始时可以直接用 |

官方更新日志里还出现过按 Loomis 分步练习、表情控制、面部雕刻等条目——这些是后续版本逐步加入的功能，你手里的安装包是哪个版本，就以应用内实际功能为准（网盘这份是 2.0.1，见[下载与安装教程.md](下载与安装教程.md)）。

## 四、适合谁、不适合谁

**适合**：在学素描或肖像、想练头部体块与明暗的人；需要可调光源、多角度头部参考的人；不想每次都翻照片找角度、想自己控制光线方向强度的人。

**不太对口**：想找手部姿势、全身动作参考的——这个应用的主角是头部模型；全身类需求要看专门的姿势工具。
