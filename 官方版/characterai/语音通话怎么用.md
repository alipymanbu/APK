# Character.AI 语音通话怎么用

## 一、发起一通语音通话

1. 打开和角色的聊天界面。
2. 点聊天输入区附近的电话（听筒）图标。
3. 弹出确认时允许开始，并在系统弹窗里**允许麦克风权限**——第一次通话必弹，拒绝就说不了话。
4. 出现「Speak now」提示后直接说话，角色会实时语音回你。

通话中可以打断角色说话（点屏幕即可打断），不用等它把一整段说完。想回到打字，结束通话即可，聊天界面照常能用。

## 二、能用中文通话吗

可以。官方帮助中心明确列了支持的语言：除英语外，还有中文（普通话）、日语、韩语、西班牙语、葡萄牙语、俄语等。社区经验是开场就用中文说话，角色大多会自动跟着切中文；角色的人设定义里带语言标注的，识别也更稳。

## 三、通话记录还在吗

在。通话内容会同时存成文字聊天记录，挂断后回到聊天界面就能看到刚才通话的文字版，之后照常能在历史记录里查。

## 四、给角色换声音 / 自制声音

- 每个角色有默认声音；在一对一聊天里，你可以给**不是你创建的角色**也换上别的声音。
- 想自己做声音：首页底部点 Create（+）→ Voice，录一段或上传一段音频即可生成；做出来的声音可设为私密或公开。
- 这类声音功能对所有用户免费，跟订阅无关；受免费额度限制的是双向语音通话本身（对照见 [免费与付费区别.md](免费与付费区别.md)）。

## 五、通话打不开 / 没声音

| 现象 | 先查什么 |
| --- | --- |
| 点电话图标没反应 | 应用版本太旧，更新后重试 |
| 能拨通但对方听不见你 | 系统设置里应用的麦克风权限是否允许 |
| 听不见对方 | 媒体音量（不是铃声音量）是否被调零；蓝牙耳机是否抢占了声道 |
| 通话中声音断断续续 | 网络波动，换 Wi-Fi 或换位置 |

以上都试过仍不行，就清缓存重登（办法见 [常见问题与排查.md](常见问题与排查.md)），或者换 [character.ai](https://character.ai) 网页版试——官方网页版同样提供通话，可以用来排除是应用端的问题。
