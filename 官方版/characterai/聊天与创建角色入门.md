## 一、找到第一个角色开聊

首页就是角色广场：有为你推荐的角色、社区里正在流行的角色，也可以直接搜索名字。点开任意角色就进入聊天，对方会按人设先跟你打招呼。

类别覆盖很广：影视与动漫角色、历史人物、语言陪练、原创人设等。角色全部由社区用户创建，人设差异很大，不合口味就换一个，不用纠结。

## 二、聊天里的常用操作

| 操作 | 在哪 | 作用 |
| --- | --- | --- |
| 换一条回复 | 回复下方的切换箭头 | 不满意当前回复时重新生成 |
| 给回复打分 | 回复旁的星级 | 影响角色后续的表现 |
| 语音通话 | 聊天界面顶部 | 和角色进行语音对话 |
| 开新对话 | 对话内菜单 | 从头开始，不带当前剧情 |
| 找回旧对话 | 聊天列表的历史记录 | 久未打开的对话会被归档到这里 |

群组房间：可以把几个角色拉进同一间「房间」让他们互相对话，你也可以插话。

语音通话的入口、语言支持与打不开的处理，单独写在 [语音通话怎么用.md](语音通话怎么用.md)。

## 三、创建自己的角色

首页点 Create（创建）→ Create a Character，按表单填：

- **名字与开场白**：开场白是角色对你说的第一句话，决定剧情起点。
- **人设描述**：性格、说话风格、背景设定，写得越具体，角色越「像」。
- **进阶定义**：可以写示例对话让角色模仿你想要的语气（选进阶模式才出现这一项，快速模式没有）。
- **头像**：上传图片或用系统生成的。
- **可见性**：Public（所有人可见）、Unlisted（拿到链接才能看）、Private（仅自己）三选一。

填完点 Create and Chat，直接开始和你刚造的角色对话。之后随时能回来编辑设定、调整开场白。角色的可见性建议先设 Private 试跑，调顺了再公开。

## 四、语言这件事

界面语言以英文为主（截至本文写作时没有官方中文界面，以应用实际版本为准），但直接用中文和角色对话没有问题，角色会用中文回复；英文人设的中文语感可能不如英文自然，想要更顺的中文体验，可以在搜索里找标注会中文的角色。

## 五、角色说的内容要当娱乐看

角色会顺着剧情编造内容，可能一本正经地说错事实。它适合排解无聊、练对话、找灵感，不适合当百科问答或任何专业建议的来源——这一点应用里也会反复提示。遇到回复被拦截、角色突然拒答，属于内容审核在起作用，处理办法见 [常见问题与排查.md](常见问题与排查.md)；聊久了角色开始忘设定、人设跑偏，则是另一类问题，见 [角色记不住设定怎么办.md](角色记不住设定怎么办.md)。
