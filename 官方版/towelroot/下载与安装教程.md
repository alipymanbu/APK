# towelroot 下载与安装教程

> 本篇讲怎么把 towelroot 装进手机并跑完第一次 Root：拿到安装包、开未知来源权限、装 apk、点下唯一那个按钮。

towelroot 是 geohot（George Hotz）2014 年发布的一键 Root 工具，装在手机上点一个按钮就能给自己的设备获取 Root 权限，全程不需要电脑和数据线。它适合手里还留着 Android 4.4 年代老设备、想清预装软件或折腾系统的你；新机型大概率用不上它。本篇按步骤走完从安装到重启的全过程，机型是否支持先看 [支持的机型与系统条件.md](支持的机型与系统条件.md)。

## 一、装之前先确认三件事

1. **这是你自己的设备**：towelroot 的用途是给自己手里的手机、平板获取 Root 权限，官方页写明「免费供个人使用（free for personal use）」，同时声明不提供任何保修（no warranty expressed or implied）；
2. **机型大概在支持范围里**：判断标准是内核补丁日期早于 2014 年 6 月 3 日，对照方法见 [支持的机型与系统条件.md](支持的机型与系统条件.md)；
3. **重要数据已备份**：Root 前备份是底线，失败了通常只是重启一次，但备份这步不能省。

## 二、安装包信息

网盘里这份安装包的信息如下，版本、包名、大小以它为准（网上搜到的多是官方站的动态，与这份不一定是同一版）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.1 |
| 包名 | com.geohot.towelroot_cn |
| 大小 | 0.41 MB |
| MD5 | 75EB2276A1D4B38402608F516EA94113 |

装完如果想核对，用文件管理器或校验工具对一下 MD5 即可。官方站的发布页在 [towelroot.com](https://towelroot.com/)，它的版本线（v1、v3）是另一套编号，别和上表的 1.1 混着看。

## 三、开启未知来源安装权限

towelroot 不在应用商店上架，属于直接安装 apk：

1. 打开 **设置 → 安全**；
2. 勾选 **未知来源**（不同系统叫法有差异，Android 较新版本在「安装未知应用」里按应用单独放行）；
3. 弹出的风险提示选确定。

装完 towelroot 后这行开关可以关回去。

## 四、安装并执行 Root

1. 从 [towelroot 安装文件资源（夸克网盘）](https://pan.quark.cn/s/97d949717d7a) 转存后把 apk 下载到手机（也可以先下到电脑再用数据线拷过去）；
2. 点开 apk，按提示完成安装；
3. 在应用列表里打开 towelroot，界面极简：一行欢迎文字加一个 **make it ra1n** 按钮；
4. 点 **make it ra1n**，等大约 10~15 秒，手机会自动重启；
5. 重启回来，Root 过程就结束了。

成功后 towelroot 没有任何庆祝提示，也不会替你装别的东西 —— 任何应用此刻来要 Root 都拿得到，所以下一步是补一个权限管理工具把口子收窄，见 [Root成功后的权限管理.md](Root成功后的权限管理.md)。

## 五、点了没反应怎么办

点按钮后应用闪退、没重启、或重启后一切照旧，多半是这台机器不在支持范围。这类尝试一般没有破坏性，排查顺序与处理办法见 [常见问题与风险说明.md](常见问题与风险说明.md)。
