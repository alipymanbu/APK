# towelroot Root 成功后的权限管理

> towelroot 只负责把 Root 权限拿到手，不负责管：任何应用来要都直接给。本篇讲成功后怎么补一个权限管理工具、怎么验证、平时怎么授权。

Root 成功只是开始。towelroot 没有任何权限管理功能，这是个必须马上补上的口子 —— 本篇讲三件事：装 SuperSU、验证 Root、日常授权习惯。

## 一、为什么必须马上补权限管理

towelroot 的设计极简：它把 Root 权限拿到手，之后**任何应用来申请 Root 都直接给**，没有弹窗、没有确认、没有记录。这正是它「一键就成」的原因，也是它留下的风险 —— 一个来历不明的应用可以静默拿到系统最高权限。所以成功后第一件事不是去折腾系统，而是装一个权限管理工具，把「谁来都给」变成「你逐个决定」。

## 二、装 SuperSU 并更新二进制

当年的通行做法是装 SuperSU（Chainfire 出品，应用商店搜索安装）：

1. 首次打开会提示「SU 二进制需要更新」，选择继续；
2. 三星机型上可能弹出与 Knox 相关的询问，有用户整理的步骤是按保留 / No Thanks 处理；
3. 完成后重启一次手机。

之后再有应用申请 Root，会由 SuperSU 弹窗让你逐个放行或拒绝。想确认 Root 状态、或者授权后还有疑问，处理思路见 [常见问题与风险说明.md](常见问题与风险说明.md)。

## 三、验证 Root 是否真的成功

装一个 Root Checker 之类的检测应用，点 Verify Root：

- 第一次检测时权限管理会弹出授权询问，同意后显示已 Root 即成功；
- 显示未 Root 时先别急着下结论，按 [常见问题与风险说明.md](常见问题与风险说明.md) 的顺序排查（有没有重启过、机型是否在支持范围）。

## 四、Root 之后能多做的那些事

拿到 Root 权限后，一些原本做不了的操作就可行了（做不做得成因机型与系统而异）：

- 卸载预装的系统应用，清掉用不上的内置软件；
- 管理应用的开机自启动与后台唤醒；
- 更换全局字体、开机动画这类系统级外观；
- 使用需要 Root 才能工作的备份、防火墙、广告拦截类工具。

这些操作本身仍有把系统改出问题的可能 —— 动系统分区前先备份，卸载系统应用前先确认它不是关键组件。

## 五、日常授权的两个习惯

1. **逐个放行**：弹窗出现时看清是哪个应用在要 Root，不认识的一律拒绝；要 Root 的理由与应用功能对不上号的（比如一个手电筒要 Root），直接拒绝；
2. **定期翻授权记录**：权限管理工具里有「已授权应用」列表，隔段时间过一遍，把不再用的撤掉。

装好权限管理、验证通过之后，这篇的任务就完成了；用得过程中碰到的报错与疑虑都汇总在 [常见问题与风险说明.md](常见问题与风险说明.md)。
