# TravelBoast 怎么做旅行轨迹动画

> 从零做出一条会动的旅行路线：定起终点、拖途经点、挑交通工具、生成并保存。整个流程在手机上几分钟就能跑通，不需要注册账号。

## 一、流程总共五步

| 步骤 | 做什么 |
| --- | --- |
| 1 | 在地图上定起点和终点 |
| 2 | 拖动路线，加途经点 |
| 3 | 挑一个交通工具 |
| 4 | 按播放，生成动画 |
| 5 | 保存视频或直接分享 |

下面按顺序拆开讲。

## 二、定起点和终点

打开应用后，新建一条路线，在搜索框输入出发地和目的地（支持搜城市、机场这类地名），地图上会落两个点、连出一条线。如果你手里已经有现成的路线记录（比如运动手表导出的 GPX 文件），不用手动打点，直接走导入，见 [导入GPX轨迹与地图路线.md](导入GPX轨迹与地图路线.md)。

## 三、拖线加途经点

默认的直线只是起终点连线，真实行程往往有中途站。把路线中间任意位置按住往外拖，就能拖出一个新途经点；反复拖，就能把线修成你实际的走法 —— 转个城市、加个补给站都行。拖完觉得不顺，双击某个点就能把它删掉。

## 四、挑交通工具

官方提供 250 多种交通工具模型，从民航客机、高铁、小汽车、轮船，到热气球、马匹这类少见的选择都有，数字还在随版本更新涨。用法：

- 默认会给一个交通工具图标，**长按它**就能弹出选择菜单换掉；
- **同一条路线可以分段换乘**：长按路线上的任意一个点，在菜单里选该段用什么交通工具 —— 比如前半程开车、后半程飞机，动画会照着演。

## 五、给路线加细节

- **图文标注**：长按某个点，选「Annotation」，可以给这一站加文字备注、照片或短视频 —— 到过的城市、吃过的餐厅都能钉在地图上。有第三方对比提到每个点只支持一张照片配文字，想多传几张的以应用内实际为准。
- **路线线样式**：颜色、粗细、动画形态都可以调，跟地图底色搭配着选。
- **地图样式**：应用内置多种地图风格，含夜间样式，做暗色调短视频可以直接切夜间地图。
- **伴随特效与载具外观**：动画播放时可以叠加雪花、圣诞树、海鸥这类伴随特效烘托季节感；选中的交通工具还能调颜色和大小，让它跟画面比例匹配。

## 六、生成与保存

路线摆好后按播放键，地图上会沿着你画的路线播放动画。保存前可以调播放速度、横竖屏、要不要带国旗和公里数标注（以应用内实际显示的选项为准），然后导出视频存进相册。

注意：免费版导出的视频会带 TravelBoast 水印，想无水印、存 4K 要订阅，差别和取消方式写在 [订阅与常见问题解答.md](订阅与常见问题解答.md)；导出后的发布设置（横竖屏选择、发抖音/Instagram 的注意点）见 [视频导出与分享设置.md](视频导出与分享设置.md)。

## 七、编辑小动作速查

| 动作 | 效果 |
| --- | --- |
| 按住路线中段拖动 | 新增一个途经点 |
| 快速双击某个点 | 删除这个点 |
| 长按某个点 | 弹出菜单：换该段交通工具、加 Annotation 标注 |
| 长按交通工具图标 | 换当前段的交通工具 |

官方在 YouTube 频道放了一条 70 秒的完整演示和分步教程（搜 TravelBoast 官方频道），做完第一条想再精进的，可以对着视频补细节。
