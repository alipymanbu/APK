## 一、观测位置：预测的地基

所有过境预测都按你设的位置计算，这是应用里最优先要设对的一项。

### 四种设法

打开 Location 设置，可以从这几种方式里挑：

| 方式 | 适用场景 |
| --- | --- |
| 当前 GPS 定位 | 在观测现场设，最省事 |
| 按地址搜索 | 在家提前设，输入城市或地址 |
| 手动输入经纬度 | 已有精确坐标（比如常用观测点的坐标） |
| Maidenhead 网格坐标 | 业余无线电常用的定位格式，火腿会熟 |

### 位置要设到多准

官方 FAQ 给过口径，普通卫星观测**精确到 10 公里就完全够用**（大约经纬度小数点后一位）。原因：卫星几百公里高，你挪几公里，看到的过境时刻和方位几乎不变。

对位置敏感的特例（如当年的铱星闪光，见 [铱星闪光还能看到吗](铱星闪光还能看到吗.md)）官方建议精确到 1 公里（约 0.01°）。

### 度分秒换十进制

有些地图或资料给的坐标是「度 + 分 + 秒」格式，应用要的是十进制。换算：

```text
十进制度 = 度 + 分/60 + 秒/3600
```

例：北纬 48°15′23″ = 48 + 15/60 + 23/3600 = 48.25639。

**别忘了正负号**：南纬取负、西经取负。国内用户经东经、北纬都是正值，一般碰不到这个坑。

### 时区不用管

预测表里的时间全部是**当地时间**，夏令时切换应用会自动处理，不需要你做任何设置。

## 二、提醒通知：到点叫你

主界面点铃铛图标进通知设置。可配的项目：

| 项目 | 说明 |
| --- | --- |
| 提前量 | 过境开始前几分钟提醒，默认 5 分钟，够你走到开阔地 |
| 最早 / 最晚时间 | 只在这个时段内提醒，比如设 07:30–23:30 免得凌晨被吵醒 |
| 按类别开关 | ISS / 卫星 / Starlink / 无线电卫星可以分别选要不要提醒 |
| 用闹钟响铃 | 用系统闹钟通道代替普通通知，更可靠；代价是状态栏常驻一个闹钟图标 |

只想看 ISS 的话，把卫星和 Starlink 两类关掉，通知会清净很多。

### 提醒没响，先查这三层

通知这种「到点叫人」的功能，漏响的原因多半不在应用本身，而在安卓系统的层层拦截。按顺序查：

1. **系统通知权限**：安卓 13 起应用要显式拿到通知权限才能发提醒，首次启动时如果点过「不允许」，去系统设置 → 应用 → Heavens-Above → 通知，打开总开关。
2. **厂商省电策略**：不少国产与三星系统会杀后台，应用被「休眠」后提醒就发不出来。把 Heavens-Above 加入省电白名单 / 自启动名单（三星在「电池 → 后台使用限制 → 睡眠应用」里移出；其他品牌各有「省电策略 / 电池优化」入口，设为不优化或无限制）。
3. **应用内开关与时段**：第一节表里的类别开关、最早最晚时间是否把这次过境筛掉了，回应用里核对。

开了「用闹钟响铃」选项能绕开大部分通知拦截，要可靠就用它。

## 三、预测过滤：列表里只留你想看的

设置里的 Passes 部分控制过境列表的筛选条件：

- **最小仰角**：滤掉贴着地平线掠过的过境。仰角太低的过境容易被建筑物和树挡住，住城区建议设到 10° 以上。
- **最小星等**：数值越小代表越亮。默认 3.5 等上下；把数值改小，列表里就只剩更亮的过境。
- **仅显示可见的 ISS 过境**：开着可以滤掉白天从头顶过、根本看不见的 ISS 次数。

星等数值和亮度的关系见 [看懂过境预测数据](看懂过境预测数据.md)。

## 四、轨道数据更新

设置里有「下载数据」（Download satellite data）一项，旁边显示上次更新时间。前面说过预测是本地计算的，这一项就是那个「隔几天联网一次」的动作：

- 打开应用后它会自己拉取，你也可以手动触发；
- 出门前看到「上次更新」是一两周前，建议先更新一次再出门，低轨卫星的轨道常有调整，数据旧了时刻会漂。

设完位置和提醒，回去看 [核心功能使用入门](核心功能使用入门.md) 把各页面过一遍，就能开始用了。
