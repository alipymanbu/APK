## 一、描述词的基本结构

文生图类功能通用的一句结构：**主体 + 细节 + 场景 + 风格 + 画质**。在 AIbot 的描述框里按这个顺序组织，一次说全，比生成后再补救省次数。

| 成分 | 作用 | 例子 |
| --- | --- | --- |
| 主体 | 画面核心是谁/是什么 | 「一个穿汉服的少女」「一只橘猫」 |
| 细节 | 外观、动作、道具 | 「手持团扇」「毛茸茸、戴红色项圈」 |
| 场景 | 在哪、什么氛围 | 「樱花树下」「窗台边，柔和的光」 |
| 风格 | 往哪个画风走 | 「漫画风格」「水墨风」「赛博朋克」 |
| 画质 | 清晰度与质感方向 | 「高清」「细节丰富」「壁纸级」 |

再按 AIbot 收录的风格方向倒推着写：画漫画人物就把细节花在脸部与服饰上；做手机壁纸就写清「竖屏、留白位置」；小说推文配图直接把书里那一幕的场景写进描述词。

## 二、可直接改用的例子

- 手机壁纸：「一只橘猫躺在窗台，午后阳光，柔和的光，高清，竖屏壁纸」
- 漫画人物：「短发少女，校服，站在天台，风吹起头发，漫画风格，高清」
- 小说推文配图：「雨夜小巷，霓虹灯倒影，一个人撑伞的背影，电影感，细节丰富」

修改的技巧是换槽位不换整句：先只换主体看方向，再换场景，最后换风格——每次动一处，才知道是哪个成分在影响出图。

## 三、常见翻车与对应改法

| 现象 | 多半是 | 改法 |
| --- | --- | --- |
| 出图和描述完全对不上 | 一次塞了太多不相关元素 | 砍到一个主体 + 一个场景，重生成 |
| 人物脸崩 | 没写清人物特征 | 补「特写/半身、发型、表情」再生成 |
| 画面太空或太挤 | 没说构图 | 加「特写」「全身」「留白」这类构图词 |
| 风格不像 | 只写了「好看」没锁定画风 | 换成具体画风词（水墨、漫画、赛博朋克等） |

AIbot 的绘画页开放给你的是描述词、风格与尺寸这些基础项（收录页口径）；其他文生图工具里常见的种子、步数这类进阶参数未见提供，以 App 内实际选项为准，找不到不用怀疑自己漏了步骤。

## 四、生成结果不理想时的处理顺序

1. 先改描述词里最薄弱的那一段（通常是细节或场景）；
2. 再换风格选项；
3. 最后换尺寸重试；
4. 连续失败或一直转圈，属生成服务问题，排查见 [常见问题与解决.md](常见问题与解决.md)。

绘画功能的入口与生成步骤见 [使用方法.md](使用方法.md) 的绘画一节。
