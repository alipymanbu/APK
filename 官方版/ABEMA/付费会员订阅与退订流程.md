# 付费会员订阅与退订流程

## 一、免费能看什么，付费多什么

ABEMA 的直播频道和大量点播内容**不付费也能看**，这是它的默认状态。付费用在两类东西上：

1. **ABEMAプレミアム**（ABEMA Premium）：会员限定作品与先行配信可以看、正常观看时不插播广告，外加几个功能型权益——`追っかけ再生`（正在直播的节目已播过一半也能从头看）、`ダウンロード`（下载到本地离线看，数量有上限，以官方页面为准）。
2. **按次付费（PPV）**：部分演唱会、体育直播单独卖，用 `ABEMAコイン`（ABEMA 金币）购买，和订阅是两套账，订阅了也还要另买。

## 二、两档套餐对照

官方商店页面列出的两档（**价格随时会调，以官网当时显示为准**）：

| 套餐 | 月费（含税） | 内容 |
| --- | --- | --- |
| ABEMAプレミアム | 1080 日元 | 会员限定内容全部可看，无广告，含追っかけ再生、下载等功能 |
| 広告付きABEMAプレミアム | 580 日元 | 会员限定内容可看，**保留广告**，价格便宜一档 |

选哪档取决于你能不能忍受广告：两档的内容池相同，差价买的是「不看广告」；功能权益有无差异以官方页面为准。

## 三、订阅前的硬条件：先绑邮箱

**没绑邮箱密码，付费套餐一律注册不了**——这是官方写死的前置条件。先按 [账号注册与设备共享方法.md](账号注册与设备共享方法.md) 第三节把邮箱验证码走完，再回来订阅。

另一个前置确认：**已经在别的套餐里的话，要先切到你想订阅的那个账号再操作**，一个账号上不会给你叠两个套餐。

## 四、从哪订、怎么订

订阅渠道决定了以后**用什么方式付钱、也决定了从哪里退**，先看清楚再点：

| 你从哪订 | 实际走的支付 |
| --- | --- |
| 手机浏览器 / 电脑打开官网订 | 信用卡（Visa / Mastercard / JCB / American Express / Diners Club）、PayPay、后付费（ペイディ） |
| Android 应用内订 | Google Play 内购（走你的 Google 支付方式） |
| iOS 应用内订 | App Store 内购 |
| Fire TV / Fire 平板内订 | Amazon 内购（需先设置好 Amazon 一键支付） |

**Android 应用内订阅步骤**：`マイページ` → `視聴プラン` → 点 `登録する` → 确认注意事项后再点一次 `登録する` → 在 Google Play 弹出的付款页点 `定期購入`。

**官网订阅步骤**：菜单 `☰` → `アカウント・設定` → `視聴プラン` → `登録/解約する` → `詳しくみる` → `登録する` → 输入密码确认 → 选支付方式完成。

几点：

- 完成后会收到 `no-reply@mail.abema.tv` 发的注册完成邮件，留好；
- **登记之后不能撤销**——官方明确写了「登録後の取り消し・キャンセルやアカウントの統合はできません」：手滑点了「登记」不会自动退款，只能按第五节的正常流程退订，当期费用照扣；
- 同一个套餐在不同设备上看是否已生效，看 `視聴プラン` 页面显示的当前方案即可。

## 五、退订：时限、路径、三个误区

**统一时限：在下次扣款时间的 24 小时之前完成退订手续。** 超时一点就会自动续期扣款。下次更新时间在应用 `マイページ` → `視聴プラン` 页面能看到。

按你当初的支付方式选退订路径：

- **官网 / 浏览器订的**：官网菜单 → `アカウント・設定` → `アカウント管理` → `視聴プラン` → `登録/解約する` → 在当前套餐旁点 `解約に進む` → 按提示走到最后一步，确认显示 `解約済み`。完成后注册邮箱会收到退订完成邮件。
- **Android 应用内订的**：打开 Google Play → 订阅管理 → 找到 ABEMA → 取消订阅。
- **iOS 应用内订的**：iPhone 设置 → 你的 Apple ID → 订阅 → ABEMA → 取消。
- **Amazon 内购订的**：Amazon 账户的订阅管理里取消。

三个高频误区：

1. **卸载应用不等于退订**。官方专门警告过：应用卸载、设备重置、换手机，订阅都还在自动续费。
2. **看到「無料」不代表退订成功**。那多半是登错了账号——当前登录的账号没有套餐，而你扣钱的套餐挂在另一个账号下。按 [账号注册与设备共享方法.md](账号注册与设备共享方法.md) 第四节把账号切回去再退。
3. **降档不是随时能降**。ABEMAプレミアム 想改成更便宜的広告付き档，必须用**当初订阅的同一种支付方式**操作（App 内购就回 App 里改）；而且用 Amazon 内购或运营商代扣（キャリア決済）订的人**不能直接降档**，只能先退订、等当前周期结束后再重新订便宜档。

## 六、订了却看不了会员内容

常见原因不是扣款失败，而是地区限制——部分会员内容只在日本境内可播。如果你人在海外，先看 [海外观看与地区限制说明.md](海外观看与地区限制说明.md) 确认内容本身是否对你的地区开放，再排查登录的账号是否就是订阅的那个号。
