## 一、先确认你的设备能不能装

ABEMA 是日本株式会社 AbemaTV 运营的网络电视服务，2016 年 4 月开播，界面语言只有日文。它的 Android 应用包名是 `tv.abema`，官方商店页对手机 / 平板的系统要求是 **Android 7.0 及以上**。低于这个版本的设备装上也大概率打不开，先别白折腾。

其它平台的官方支持环境（截至 2025 年 6 月的官方设备清单，以官网当时显示为准）：

| 平台 | 最低要求 |
| --- | --- |
| Android 手机 / 平板 | Android 7.0 及以上 |
| iPhone / iPad | iOS 15.0 及以上 |
| Fire 平板 | Fire OS 6.0 及以上 |
| Windows 电脑 | Windows 8.1 及以上，用最新版 Edge 或 Chrome |
| Mac 电脑 | Mac OS X 10.10 及以上，用最新版 Safari 或 Chrome |

电视端不走这个 APK —— 智能电视、机顶盒各有各的装法，见 [投屏到电视的几种方法.md](投屏到电视的几种方法.md)。

## 二、安装包从哪拿

三条路，按你的情况选一条：

1. **Google Play 商店**（官方渠道，能自动更新）：在应用里搜 `ABEMA` 或直接打开 `https://play.google.com/store/apps/details?id=tv.abema`，认准开发者是株式会社AbemaTV。
2. **手机没装 Google Play 时用本地 APK**：从 [ABEMA 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d6cefedcd981) 转存安装包，传到手机上直接安装。这份包是固定版本快照，具体信息见下表：

   | 项目 | 值 |
   | --- | --- |
   | 版本 | 10.164.0 |
   | 包名 | tv.abema |
   | 大小 | 33.35M |
   | MD5 | `4d2d0a028fbbb8060c370a04e737933e` |
   | 整理时间 | 2026-09-22 |

3. **电脑浏览器直接看**：不想装应用也能用，Windows / Mac 打开 [ABEMA 官方网站](https://abema.tv/) 即可，不需要安装任何东西。

用本地 APK 前可以先核一遍完整性：算出的 MD5 与 `4d2d0a028fbbb8060c370a04e737933e` 对不上，说明下载中途损坏了，重新下一次。

## 三、安装步骤（Android 侧载）

1. 把 APK 文件传到手机（数据线、聊天工具文件传输、浏览器下载都行）。
2. 用手机的「文件管理」点开这个 `.apk`。
3. 系统会弹「禁止安装来自此来源的应用」——这是 Android 对非商店应用的默认拦截。你到 **设置 → 安全 / 应用管理 → 允许安装未知来源应用** 里对文件管理器（或浏览器）放开，各品牌菜单名略有差异。
4. 回到安装界面点「安装」，装完直接打开。

如果系统提示「解析错误 / 已安装更新版的应用」，通常是两种情况：系统低于 Android 7.0，或手机里已有的 ABEMA 版本比这个包新 —— 后者直接打开原有的就行，不用覆盖装。

## 四、第一次打开：三件事

1. **不注册也能直接看**。ABEMA 不要求会员注册，打开就能左右滑动切换频道看直播，这点和多数视频应用不同。
2. **界面是全日文**。官方应用没有中文或英文切换项，常见词先记几个：`テレビ` 是电视直播、`番組表` 是节目表、`マイページ` 是我的页面、`設定` 是设置。
3. **想换画质先找到设置**：点应用内菜单 `☰` → `設定` → `画質設定`，移动网络下可从 `通信節約モード`（省流量）调到 `最高画質`。移动中看视频建议先调低，流量账怎么算、离线下载怎么用，见 [流量节省与离线下载指南.md](流量节省与离线下载指南.md)；播放本身的异常按 [播放卡顿与闪退排查.md](播放卡顿与闪退排查.md) 处理。

## 五、更新与升级

- **商店装的**：Google Play 会自动更新，也可以进商店手动点更新。版本号形如 `10.164.0`，三段式递增，官方未公布固定更新日。
- **本地 APK 装的**：不会自动更新。下次换新版时重新从网盘取新包（入口见第二节），或临时去商店更新。版本以官方页面当时显示为准。
- **强制更新提示**：有时打开会直接要求「更新やアップデート」才能继续看，这时本地旧包已失效，必须更新到最新版；卡在这一步的处理办法见 [播放卡顿与闪退排查.md](播放卡顿与闪退排查.md)。
