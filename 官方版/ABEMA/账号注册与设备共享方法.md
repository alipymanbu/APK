## 一、先想清楚：为什么值得绑一个账号

不注册也能看直播，但你的观看数据只存在这台设备上。绑了邮箱账号之后，下面这些东西才跟着你走：

- 视听方案（是否订阅了付费套餐）；
- 个人资料与我的列表（`マイリスト`）；
- 观看历史；
- 跨设备登录——手机上看一半，换设备接着看。

换手机、清了应用数据、重装应用，没绑账号的话这些都会丢。官方帮助中心也建议：换设备或怕设备故障丢数据时，提前把邮箱设置上。

## 二、账号是什么：一个自动发的 ID

你第一次打开 ABEMA 时，它就自动给你发了一个账号 ID，不需要你填任何东西。这个 ID 存在设备本地，光有 ID 也登不进号——登录还需要密码或一次性密码。它的作用是：

1. 挂上你的套餐、列表、历史；
2. 客服查询时报这个 ID；
3. 通过「ID + 一次性密码」把账号临时共享到别的设备。

**光有 ID 不够**——设备一卸载重装、一恢复出厂，ID 就换了，数据留在旧 ID 下面取不回来。所以绑邮箱那一步才是关键动作。

## 三、绑定邮箱和密码（Android 应用内）

路径：应用底部 `マイページ`（我的页面）→ `アカウント管理`（账号管理）→ `メールアドレスとパスワード`。

1. 输入邮箱地址，点 `送信`；
2. 邮箱会收到一封验证邮件，里面有 **6 位验证码**；
3. 在应用里输入验证码——**有效期 30 分钟**，过期就得从头再来；
4. 设置密码，点 `完了`。

几点注意：

- 验证码邮件没收到，先翻垃圾箱，再确认邮箱地址没拼错；
- 电视设备上**不能**注册邮箱，只能在电视上做「切换账号」，注册得在手机或浏览器里完成；
- 注册免费账号不花钱，也不需要绑任何支付方式。

## 四、在另一台设备登录同一个号

两种方式，选一种：

**方式 A：邮箱切换**（你在原设备上已绑过邮箱）

在新设备打开 ABEMA → `マイページ` → `アカウント管理` → `アカウントを切り替える`（切换账号）→ 选 `メールアドレス` → 输入邮箱点送信 → 填 6 位验证码 → 完成。网页端路径是：菜单 `☰` → `アカウント・設定` → `アカウント管理` → `アカウントを切り替える`。

**方式 B：ID + 一次性密码**（没绑邮箱，或电视端）

1. 在**已登录的那台设备**上生成一次性密码：`マイページ` → `アカウント管理` 里有发码入口；
2. 在**新设备**上选择 `IDとワンタイムパスワード`，输入账号 ID 和刚发的密码。

一次性密码是一次性的、短时效的，发完记得在旧设备上确认操作完成。

## 五、两个最容易踩的坑

1. **重装应用 = 数据清零**。Android 上清缓存 / 清数据 / 卸载重装，我的列表和套餐状态会被重置。你要是订了付费套餐，重装后得做一次「方案恢复」才能继续生效（`視聴プラン` 相关的恢复入口在设置里，具体以官方页面为准）。顺序永远是：**先绑邮箱 → 再折腾设备**。
2. **一台设备上可能登着别人的号**。切换账号是双向的，你把账号切到手机上，原来那台设备就回到未登录状态。自己和家人共用时，先确认当前登录的是谁：`マイページ` 顶部显示的就是当前账号，管理页里能看到 ID。

注册、切换这两步做完，订阅付费套餐才有前置条件——具体怎么订、怎么退，见 [付费会员订阅与退订流程.md](付费会员订阅与退订流程.md)；登记或扣款出问题按 [订阅支付失败与扣款问题处理.md](订阅支付失败与扣款问题处理.md) 处理。另外，有公开资料称同一账号最多支持 2 台设备同时播放（多来源一致，具体以官方页面为准）。
