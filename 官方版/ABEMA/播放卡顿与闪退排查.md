# 播放卡顿与闪退排查

> 这篇按设备给排查顺序：画面卡、黑屏、闪退、投屏断了，分别先做哪几步，什么时候该清缓存、什么时候别清。

## 一、动手前先分清是哪类问题

| 症状 | 大概率原因在 |
| --- | --- |
| 画面频繁卡一下、画质忽高忽低 | 网络带宽或信号 |
| 完全黑屏 / 有声音没画面 | 设备或应用状态 |
| 应用打开就退、看着看着闪退 | 应用或系统状态 |
| 强制弹「更新」看不了 | 版本过旧 |
| 投屏图标灰的、投不上 | Chromecast 与网络 |

排查有一条铁律：**一次只做一步，做完看结果**。一口气全做一遍，好了也不知道是哪步起的作用，白白多清了一次数据。

## 二、通用三板斧（任何设备都先做这三步）

1. **重启设备**——关机再开，不是只锁屏；
2. **切换网络**：用移动数据的换成 Wi-Fi，用 Wi-Fi 的换个信号好的位置或重启路由器；有条件就插网线；
3. **强制关闭 ABEMA 再打开**：Android 在最近任务里划掉，iOS 上滑挂起后重开。

## 三、画质不稳定：先调设置，再谈网络

ABEMA 的画质不是固定的——网络一差，它会自动降画质保流畅，所以「画面变糊」本身就是网络吃紧的信号。分两步：

1. **手动设置**：Android 应用内 `☰` → `設定` → `画質設定` → `モバイル回線時`（移动网络下），档位从 `通信節約モード` 到 `最高画質`。省流量选低档，Wi-Fi 稳就开高档。PC 网页和电视设备没有这个手动项，画质随网络自动调。
2. **网络侧改善**：关掉同时在下大文件的设备；离路由器近一点；公共 Wi-Fi 卡是网络本身的事，找管理员。

设置调完还卡，回第二节三板斧，然后按设备往下走。

## 四、Android 手机 / 平板：闪退与黑屏

按顺序试，每步之间试播一次：

1. 确认系统在 Android 7.0 以上（官方最低要求）；
2. 重启设备；
3. 强制关闭 ABEMA 重开；
4. 换网络（见第二节）；
5. **清应用缓存 + 释放内存**：设置 → 应用 → ABEMA → 清除缓存；
6. 重装应用——**放到最后做**，见下面的警告。

**清数据 / 重装的代价必须先知道**：我的列表（`マイリスト`）和付费套餐状态会被重置。付费用户重装后要做一次套餐恢复（`視聴プラン` 复元）才继续生效；没绑过邮箱的账号重装后连账号本身都找不回来。所以顺序永远是：先按 [账号注册与设备共享方法.md](账号注册与设备共享方法.md) 绑好邮箱，再考虑重装；安装包入口在 [下载与安装教程.md](下载与安装教程.md)。

## 五、iOS 设备

1. 确认系统 iOS 15.0 以上；
2. 重启设备；
3. 强制关闭 ABEMA 及其它后台应用；
4. 移动数据换 Wi-Fi，或重置网络设置——**重置网络设置同样会把我的列表和套餐状态清掉**，重置前想清楚；
5. 还不行再重装，套餐恢复同上。

## 六、电脑浏览器

1. 把广告拦截之类的扩展先禁用——官方的排查清单要求先关掉这类插件再试；
2. 清浏览器缓存（**清缓存同样会重置列表与套餐状态**，先绑邮箱）；
3. Wi-Fi 换有线；
4. 浏览器保持最新版（Windows 8.1+ 配最新 Edge / Chrome，Mac 配最新 Safari / Chrome）。

## 七、Chromecast 与电视盒子

- **投屏图标灰 / 按不动**：手机和 Chromecast 是否同一 Wi-Fi → 重启 ABEMA → 重启手机与路由器 → 重设 Chromecast；
- **投上了但画面停住**：Chromecast 拔电源重插 → 手机端 ABEMA 重启 → 重连 Wi-Fi；
- **Fire TV / Android TV / Apple TV 播不动**：先确认应用是最新版 → 清该设备上 ABEMA 的缓存 → 重启应用 → 重启盒子。投屏的其它问题见 [投屏到电视的几种方法.md](投屏到电视的几种方法.md)。

## 八、提示「更新」却看不了、以及最后一步

打开就弹 `更新やアップデート` 是强制升级提示：本地旧 APK 已不被服务端接受，只能更新到最新版（渠道与办法见 [下载与安装教程.md](下载与安装教程.md) 第五节）。

以上全做完还不行，去官方帮助中心 [https://help.abema.tv/hc/ja](https://help.abema.tv/hc/ja) 搜对应症状，或用页面上的在线聊天联系客服——报障时报上你的账号 ID（`マイページ` → `アカウント管理` 里能看到），客服靠它查你的账号状态。人在海外先对照 [海外观看与地区限制说明.md](海外观看与地区限制说明.md)，别把地区限制当成了故障。
