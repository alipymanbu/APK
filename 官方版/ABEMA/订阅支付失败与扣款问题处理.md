# 订阅支付失败与扣款问题处理

> 这篇处理三件烦心事：登记会员时报错、钱扣了权益没到、解约忘了被多扣一期，分别按哪条路径排查和申诉。

## 一、先分清三种情况

| 你遇到的 | 走哪节 |
| --- | --- |
| 点「登记」直接报错，进不去付款页 | 第二节 |
| 钱扣了，但 `視聴プラン` 还是显示未登记 | 第四节 |
| 忘了解约被多扣一期，想把钱要回来 | 第五节 |

顺序上先做一件事：打开应用 `マイページ` → `視聴プラン`，看当前方案到底是什么。**很多「扣款了没生效」其实是登在了另一个账号上**——切换账号的办法在 [账号注册与设备共享方法.md](账号注册与设备共享方法.md) 第四节，这一步能消掉一半的虚惊。

## 二、登记时报错：按端找原因

**iOS（报错码 13 / 29 / 99）**：先确认到底订没订成。iPhone `設定` → `iTunes StoreとApp Store` → 点顶部 Apple ID → `サブスクリプション`（订阅），看列表里有没有 ABEMAプレミアム：

- 有 → 其实已订成功，回应用做一次套餐恢复（`視聴プラン` 的复元入口）通常就好；
- 没有 → 检查 Apple ID 是否绑了有效的付款方式，再重试。

**iOS（报错码 14）**：系统的「屏幕使用时间」把应用内购买禁了。`設定` → `スクリーンタイム` → `コンテンツとプライバシーの制限` → `iTunesおよびApp Storeでの購入` → `App内課金` 设为 `許可`。

**Android / 官网（信用卡）**：官方列的四个常见原因逐条排——卡号等信息输错、卡已过期、可用额度用尽、（走运营商代扣时）月度上限已到。用 Google Play 余额的，查礼品卡余额是否不足。

**Fire TV / Fire 平板**：要先完成 Amazon 一键支付（1-Click）设置，没设好就登不上。

## 三、Android 浏览器特有的坑：3D Secure 跳转后「浏览器不一致」

在 Android 手机浏览器用信用卡登记时，银行的本人验证（3D Secure）做完跳回 ABEMA，页面可能提示「クレジットカード情報を入力したブラウザと異なるブラウザでABEMAが開かれています」（打开 ABEMA 的浏览器与输入卡号的浏览器不一致）。

这时**登记还没完成**——按提示页面上的按钮，输入已注册的邮箱和密码、把账号切换回来，再继续登记即可。别以为页面报错就是扣款失败了，先看提示文案。

## 四、扣了钱、权益没到

1. **先按第一节确认账号没登错**；
2. **确认支付侧确实成功**：iOS 查 `設定` 里的订阅列表；Android 查 Google Play 的订阅与付款记录；
3. **重启应用，从 `視聴プラン` 页做一次恢复（復元）**——官方故障公告里的标准处置就是这一步。曾出现过 Google 内购通道故障导致「登记 / 复元失败」的先例（2024 年 11 月官方公告过、当日已修复），这种时候重试即可，钱不会白扣；
4. 还不行就报障，材料备齐见第六节。

## 五、解约忘了被多扣一期，钱能退吗

- **ABEMA 官方口径是不按日折算退款**：订阅是按周期的定期购阅，解约只停住「下一期」，当期费用不退。所以防扣钱的唯一可靠动作还是 [付费会员订阅与退订流程.md](付费会员订阅与退订流程.md) 里那条：**下次扣款 24 小时前完成退订**。
- **App 内购扣的款，可以向平台申请退款**：iOS 走 Apple 的退款申请入口（`reportaproblem.apple.com`，用 Apple ID 登录后选「请求退款」选中那笔订阅提交）；Android 在 Google Play 的付款记录里发起退款申请。**是否批准由平台审核决定**，越早申请越容易通过——这是平台的通用机制，不是 ABEMA 的承诺。
- 官网信用卡直连扣的款，没有对应的自助退款入口，只能联系官方客服说明情况，结果以客服答复为准。

## 六、报障前把材料备齐

无论走在线聊天还是邮件，官方要求你提供的信息是同一套：

1. 出现了什么问题、错误提示的原文；
2. 在哪个画面、做了什么操作之后弹出来的；
3. 出问题画面的截图；
4. 你的账号 ID（`マイページ` → `アカウント管理`）。

四样齐了，客服才能对上你的账户记录。支付类问题的入口在 [https://help.abema.tv/hc/ja](https://help.abema.tv/hc/ja) 的联系页面；播放本身没毛病、只是付钱的事没解决，别去反复重装应用（那会把列表和套餐状态清掉，见 [播放卡顿与闪退排查.md](播放卡顿与闪退排查.md) 第四节）。
