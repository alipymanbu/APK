「BotHub」是由两个常见英文词拼出来的名字，不同团队各自用了它，彼此不是同一个产品。搜这个词时，排在前面的未必是本份这一款，所以装之前值得花一分钟确认。

## 一、本份的识别特征

最硬的一条是包名，其余几条用来交叉验证：

| 项目 | 本份的值 |
| --- | --- |
| 包名 | `com.bot` |
| 版本号 | 4.3.17 |
| 安装包体积 | 6.43 MB |
| 界面语言 | 中文 |
| 打开后的形态 | 直接进对话页，不需要注册平台账号；设置里有「模型服务」「Bots 管理」「设备控制」 |
| 模型从哪来 | 你自己填服务地址和 API 密钥，用你各家服务商账上的额度 |
| 收费 | 应用免费；模型调用的费用由服务商按量结算 |

其中「**不需要注册平台账号**」和「**设置里有模型服务和设备控制**」这两条最好用——打开三十秒就能判断出来。

## 二、最常撞上的同名产品

搜索时最常见的另一个 BotHub 是一个**俄罗斯的 AI 聚合平台**，官网是 [bothub.chat](https://bothub.chat/) 与 [bothub.ru](https://bothub.ru/)，主站、Telegram 机器人和手机端都做。它和本份的差别很直观：

| 对比项 | 本份（`com.bot`） | 俄罗斯那款 BotHub |
| --- | --- | --- |
| 安卓包名 | `com.bot` | `chat.bothub.twa`（网页套壳） |
| 用模型的方式 | 自己填各家的服务地址与密钥 | 用平台自己的账号，平台内部点数计费 |
| 是否需要注册 | 不需要 | 需要，且要登录后才有界面 |
| 界面语言 | 中文 | 以俄文、英文为主 |
| 体积量级 | 数 MB | 与网页壳相当，形态是网页应用 |

**只看名字会把这两个当成一个**，但它们的安装文件、账号体系、付费方式全不是一回事。

此外还有别处自建的开源客户端也叫这个名字，形态同样属于「自己填接口」那一类。不用逐个去记——它们和本份的分别不在界面像不像，而在包名，用第一节那张表对一眼即可。

## 三、三条核对法，任选一条就能定

1. **看包名（最准）**：应用管理里点进 BotHub 的应用信息页，本份是 `com.bot`。对不上就不是这一份。
2. **看要不要注册平台账号**：一打开就要求登录、注册、充值某平台点数的，不是本份。
3. **看设置里有没有那三组**：「模型服务」「Bots 管理」「设备控制」都在，就是本份；只有聊天和一张模型下拉列表的，多半是别的客户端。

交叉验证用的体积和版本号也会帮你确认得更准，但**版本号会随更新变化**，别把它当唯一依据。

## 四、拿到不对的包怎么办

先把装错的那个卸载掉——不同包名之间可以共存，但你能拿到的账号数据、配置都留在各自应用里，混着用只会更乱。然后从 [BotHub 安装文件资源（夸克网盘）](https://pan.quark.cn/s/67dbb4e6bbb9) 重新取本份这份。

卸载旧包前留一句提醒：**卸载会清掉该应用本机的对话记录和已填的模型配置**，要留的东西先在应用内找导出入口。安装步骤照 [下载与安装教程.md](下载与安装教程.md) 第三节走。

装完再回第一节那张表逐项对一遍，全部对上就算认准了。以后再看到别处流传的「BotHub」，拿包名一比就有结论，不用重新判断一次。
