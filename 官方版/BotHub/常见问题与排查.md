这篇按「先分类、再定位」来写。BotHub 的毛病看着花样多，其实大多落在四个圈里：配置、网络与额度、系统权限、本机环境。**先判断属于哪一圈，能省掉大量反复重装的时间——重装对前两圈的问题基本无效。**

## 一、先分清是哪一圈的问题

| 症状 | 大概率是哪一圈 | 第一步做什么 |
| --- | --- | --- |
| 添加模型时提示「配置错误」 | 配置 | 见第二节 |
| 模型列表一直是空的 | 配置 | 见第二节 |
| 消息发出去没反应、一直转圈 | 配置、网络或额度 | 见第二节和第三节 |
| 切了模型，回复还是老样子 | 配置 | 见第四节 |
| 手机控制、电脑控制点了没动静 | 配置或权限 | 见第五节 |
| 打开就闪退、锁屏回来要重进 | 本机环境 | 见第六节 |
| 装不上、报解析包错误 | 包本身 | 见第七节 |

判断网络是不是元凶，最快的办法是**同时开一个网页**：网页打得开、BotHub 不出内容，问题在配置或服务商侧；网页也打不开，先把网络修好再谈别的。

## 二、配置层：配不通和列表空白

**提示「配置错误」**，按这个顺序逐项对，不要打乱：

1. **服务地址**：是不是漏了结尾的 `/v1`，或者把服务商的官网首页当成了接口地址。
2. **API 密钥**：复制时有没有带上空格、换行；有没有把「项目 ID」之类别的字段当成密钥。
3. **API 类型**：和该服务商实际提供的接口协议对不对得上，内地服务商基本都用「OpenAI 兼容」。
4. **模型 ID**：以服务商页面上的写法为准，别凭记忆拼。

**模型列表为空**，只有一个原因：还没有成功配过任何一个模型服务。配好至少一个之后列表才会出内容。如果确认配过还是空，去模型服务页看那条是**关闭**状态还是真没建成——关掉的模型不会出现在对话页的选择列表里。

**想省一遍遍试的功夫**：先在电脑上按服务商官方给的调用示例把同一把密钥跑通，再回手机填。电脑通、手机不通是手机侧的填法问题；电脑也不通就是密钥或额度的事，跟 BotHub 无关。

## 三、网络与额度

| 你看到的 | 意思 | 怎么办 |
| --- | --- | --- |
| 一直转圈、始终不出字 | 请求发不出去或对方没回 | 切 Wi-Fi 与流量互换重试；等 10~15 秒再发一句短的 |
| 401 / 密钥无效 | 密钥不对或已失效 | 回后台重新复制，或删掉旧密钥新建一把 |
| 403 | 该模型没开权限，或余额为零 | 看后台该模型是否开通、账上还有没有额度 |
| 429 | 请求太密或额度用尽 | 停一会儿再试，看后台用量说明 |
| 连接超时 | 地址写错、网络不通，或对方在维护 | 用手机浏览器直接打开那个地址看看有没有响应 |
| 连自己电脑上的 Ollama 连不上 | 默认只监听本机，手机算外部设备 | 按 [连自己电脑上的Ollama怎么连.md](连自己电脑上的Ollama怎么连.md) 第二节放开监听 |

额度这件事要单独记一嘴：**对话消耗的是你在各家服务商账上的余额或免费额度**，不在这个客户端里。免费额度到期、余额归零，表现就是「昨天还能用，今天不回了」，跟应用版本没关系。

还有两种「没反应」压根不是网络的错，先排掉再查网络：**一是模型服务被关掉了**（关掉后不发请求，自然什么都不回），**二是参数套装或默认模型切到了另一个模型**。两者的现象和网络故障几乎一样，处理办法见 [Bots管理和模型参数怎么切换.md](Bots管理和模型参数怎么切换.md) 第二节与第五节。

## 四、切了模型不生效

两种可能，分开看：

- **切换发生在「模型服务」页，但你要的是换对话用的模型。** 那一页管的是接不接某家服务；换对话用哪个，在对话页顶部选，或者在 Bots 管理页选一套参数套装。两者的分工见 [Bots管理和模型参数怎么切换.md](Bots管理和模型参数怎么切换.md) 第一节。
- **换了主力模型，但标题总结、聊天建议还指着旧的。** 这两项走的是「默认模型」，换完主力模型去默认模型那项对一遍，表现为聊天正常但标题一直不出来。

核对方法：新开一个对话，发一句「你是什么模型」之类的短问题，看回的是什么，对不上就说明还在用旧的。

## 五、设备控制没反应

手机控制和电脑控制都依赖同一个前提，先过这条：

1. **模型服务是否处于启用状态**——这是最常见的原因，对话页发一句能回字说明这一环没问题。
2. **设备控制页里对应的权限开关开了没有**——应用内的开关，和系统权限是两回事。
3. **系统权限、后台限制**——回「设置 → 应用 → BotHub → 权限」逐项看；再把 BotHub 加进电池优化白名单，避免锁屏后被清掉。
4. **换一个已知能正常回答的模型试一次**——能回字说明问题在控制这一侧，不回则回到第三节按状态码对一遍。这一步用来区分问题出在模型侧还是控制侧，不必反复重装。

## 六、打开就闪退、卡顿、发热、耗电

按影响面从大到小排：

1. **可用存储空间**：剩余空间过低（比如不足 1 GB）时，应用读写缓存容易失败，先清出空间。
2. **后台应用太多**：本机内存紧张时，长时间对话更容易被系统回收，表现为切回来要重新加载。
3. **系统版本偏旧**：这个包登记的系统要求是安卓 5.2 以上，长期不更新系统的设备更容易出问题。在「设置 → 关于手机」里对一眼版本号。
4. **边充边用**：连续对话加上手机控制这类持续操作，本身就是高负载，发热明显时先停一会儿。
5. **清应用数据之前想清楚**：清除数据会连同本机的对话记录、模型服务配置、参数套装一起清掉。动手前先确认有没有导出备份的入口（是否提供以应用内为准）。

## 七、安装、更新、卸载相关

装不上、提示解析包错误、签名不一致，这类属于安装环节，按 [下载与安装教程.md](下载与安装教程.md) 第五节逐条对。

- **更新**：网盘里换一份新的装上即可，安装动作与第一次相同；安装前确认新包版本号不低于当前版本。
- **卸载**：在应用管理里正常卸载即可。**卸载会一并清掉本机对话记录和模型配置。**
- **想退版本**：手上要留着旧包的安装文件，卸载新版再装旧版；旧包的记录和配置不会跟着回来。

## 八、怀疑装错了包

如果出现下面任何一种情况，先别继续排查应用问题，**很可能一开始装的就不是这一份**：

- 打开后要求注册某个平台的账号，还要充值它自己的点数；
- 界面语言不是中文；
- 应用管理里看到的包名不是 `com.bot`；
- 设置里找不到「模型服务」和「设备控制」这两组。

核对方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 第一节，认对了再谈别的问题。
