## 一、缓存下载怎么做

剧集详情页或播放页有「下载」按钮的，就可以缓存到本机离线看：

1. 进入选中的剧集，找到下载按钮（部分内容只在单集列表里提供）；
2. 点下载时选择清晰度——清晰度越高占的空间越大，通勤离线看选 480P 或 720P 就够；
3. 在个人中心（`ME`）的「我的下载/Downloads」里查看进度和已缓存内容。

三个要提前知道的边界：

- **VIP 集数要会员才能缓存**，免费账号只能缓存开放下载的免费内容；
- **缓存内容只能在应用内看**，视频存在应用私有目录里，文件管理器里拷不出来，也不能用别的播放器打开；
- **换设备缓存不迁移**，缓存跟设备不跟账号，换手机后要在新设备重新下。

下载速度与会员有关：官方口径 VIP 的下载速度比免费档快约 30%。

## 二、清晰度怎么选

播放时点屏幕唤出控制栏，点清晰度按钮（一般显示为当前档位，如 `720P`）即可切换：

| 档位 | 适合场景 | 说明 |
| --- | --- | --- |
| 360P | 手机流量、信号一般 | 最省流量，小屏上看够用 |
| 480P / 720P | 日常追剧 | 流量与画质折中，多数剧的中档位 |
| 1080P / 蓝光 | Wi-Fi、大屏 | 全高清档位，部分内容要求 VIP 才能选 |

清晰度可选项随片源和账号状态变化：同一部剧在 Wi-Fi 下能选到 1080P，用流量时可能只给到 720P；标注「VIP」的清晰度档位需要会员身份。播放器默认会用自适应码率，网络波动时自动降档保流畅，手动选定档位后则固定按你选的播。

## 三、省流量的几个设置

- 用流量看剧时把清晰度手动锁在 360P 或 480P，比依赖自动 adaptive 更稳；
- 提前在 Wi-Fi 环境下把缓存下满，通勤路上全程离线，不耗任何流量；
- 广告会额外消耗一点流量，这也是 VIP「免广告」在流量场景下的附带好处。

## 四、播放手势与续播

- **上下滑动**（屏幕左半边调亮度、右半边调音量），**左右滑动**快进快退；
- 点进度条两侧的「±10 秒」按钮可以微调（部分版本支持长按快进）；
- **续播**：上一次看到哪，下次打开同一集会从那个位置接着播，不用手动拖进度；
- 倍速、跳过片头片尾的开关也在控制栏里，长按屏幕部分版本可触发倍速播放。

夜间关灯看剧，可以在设置或播放页里找夜间模式（深色界面）的开关，屏幕不刺眼（入口位置以你这一版为准）。

## 五、缓存看不了先查这里

| 现象 | 先查什么 |
| --- | --- |
| 找不到下载按钮 | 该内容不支持缓存，或需要 VIP；换其他集试试 |
| 下载卡在 0% 或失败 | 网络是否正常；存储空间是否还够；退出应用重进再试 |
| 离线打开提示过期 | 部分内容的缓存有有效期（版权方要求），重新连网刷新一次授权即可 |
| 缓存突然没了 | 多为清数据、卸载重装或清理类应用把应用数据清掉了，缓存无法找回，需重新下载 |

播放中在线部分的问题（转圈、报错、地区提示）不在本篇范围，去 [地区限制与播放问题排查.md](地区限制与播放问题排查.md)。字幕没字或想换字幕语言，去 [切换中文界面与字幕.md](切换中文界面与字幕.md)。
