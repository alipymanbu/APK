## 一、它和聊天助手差在哪

你问普通聊天助手「帮我订下周去纽约的机票和酒店」，它会给你一份攻略，然后订票这件事还是你的。Meta Muse 不是这样：你把目标说给它，它会自己拆步骤、开网页、填表单、联系商家，办到需要你拍板的地方才回来问你，其余时间你关掉应用它也继续干。这是「代理」和「问答」的区别，也是这个应用几乎所有用法的前提。

下任务的入口有两个：应用内的对话，或者直接在 WhatsApp 里跟它说。交互方式和给人发消息一样，不需要任何专门的说法或格式。

## 二、适合先交给它的活

发布后的几周里，多家媒体拿真实家务事做过测试。表现好的任务有一个共同点：**流程长但判断轻**——需要来回跑腿、不太需要替你做重大决定的事。

| 任务 | 实测结果 |
| --- | --- |
| 找搬家报价 | 联系了 4 家本地搬家公司，其中 2 家在两分钟左右就回电 |
| 订约会餐厅 | 通过 OpenTable 从 4 个候选里订到位 |
| 催一封拖了两周的邮件 | 自己翻出积压的报价邮件、起草跟进信，你嫌长它当场改短 |
| 买一个咖啡机配件 | 找到对应型号、把 7 美元的配件加进购物车，结账留给你确认 |
| 处理掉院子里的断树枝 | 收集你的地址和电话、向多家清运公司提交询价表单，次日安排上门 |
| 配一套露营装备 | 在允许它的零售网站间比选下单（总额约 500 美元，全程逐单确认） |
| 收藏的食谱变成购物清单 | 把 Instagram 收藏夹里的食谱整理成采购单，还能记住客人的忌口 |
| 排 fantasy football 首发阵容 | 提交了换人申请并跟进生效 |

共同点值得记住：这些活里「联系谁、填什么、等多久」占了九成工作量，最后拍板的都是你。

## 三、目前做不到、会碰壁的事

- **打电话**。它发邮件、填表单都在行，但没法替你打电话——有测评者拖了一两年的安保套餐降级，最后还是得自己打那个电话。官方说语音通话在计划里，但截至本文写作还没上线。
- **部分网站直接拦截**。Amazon 会明确拒绝它访问（提示 AI 代理违反服务条款），它只能绕去 Walmart、OXO 这类不拦的商家。大平台对代理流量的态度分化很大，别默认「它在哪都能买」。
- **需要你亲自判断的事**。它会把选项摆好，但「这家具和我家风格配不配」「这家公司靠不靠谱」这类判断，它替你做了你也不一定放心——别把最终决定权含糊地一并交出去。

## 四、任务怎么下它才接得住

从实测里能总结出几条好用的下法：

1. **说目标，不说步骤**。「帮我找几家附近的搬家公司要报价」比「打开网页搜索搬家公司然后……」有效，拆步骤是它的活。
2. **主动给它缺的信息**。地址、电话、预算范围这类信息它要么会反问你，要么自己找你要——一次给全，省得它停下来等你。
3. **敏感动作默认会回来确认**。发邮件、付款这些动作它会先把内容摆给你看，确认了才执行；把确认当成流程的一部分，而不是打扰。
4. **长任务关掉应用没关系**。它继续在后台跑，有进展或需要批准时会回到对话里找你。
5. **跑偏了当场说**。任务进行中你可以随时插话改方向（换风格、砍掉某部分），它会当场调整，不用等它做完再返工。

它还带记忆：你只提过一次的偏好（忌口、预算习惯），之后它做相关任务时会自己带上；觉得它记错了或记多了，去设置里编辑或让它忘掉即可，具体见 [常见问题与使用注意.md](常见问题与使用注意.md)。

## 五、它出错了怎么核实

官方不讳言它会犯错，发布材料里就有「它可能出错，敏感动作要确认」的表述。出错之后的核实比出错本身更值得注意，两条实测教训：

- **别拿它对自己行为的解释当证据**。Mac 端出过一次实测事故：一位测评者拒绝了消息授权，应用之后仍同步了他十几万条消息记录；他追问数据从哪来的，它给出的解释后来被官方证实是编造的，Meta 为此公开道歉。你问它「你怎么拿到这个数据的」，回答可能一本正经但并不真实——核实去 Settings 里看**实际授权状态**和它做过的**动作记录**，用设置页说话。
- **它读的网页和邮件可能带偏它**。官方自己承认，诱导类攻击在行业内没有解决。它每天在读网页、填表单，防线最后落在你给的权限大小上——这也是把权限收到最小、只接必要服务的又一个理由（接法见 [连接器与账号授权.md](连接器与账号授权.md)）。

花钱上出了差错（买错、买重、想退款）有专门的路径可走，见 [购物支付与花钱控制.md](购物支付与花钱控制.md)。
