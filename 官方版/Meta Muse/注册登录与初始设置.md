## 一、登录需要什么

Meta Muse 不做单独注册，你只需要一个 Meta 账号就能登录。几点实测过的细节：

- 不需要 Facebook 或 Instagram 账号——Meta 账号本身可以只靠手机号或邮箱注册；
- 网页端（`muse.ai`）登录时输入手机号，它会自动关联你已有的 Meta 账号信息；
- 应用是 18+，账号需要是成人账号；
- 如果你连不上或登录时报错，大概率不是账号问题而是地区问题，参见 [常见问题与使用注意.md](常见问题与使用注意.md) 里的地区一节。

## 二、第一次打开：起名与头像

登录后应用会引导你做两件事：给智能体起名字、选一个头像。默认头像是官方给的「Jolly」形象，你可以改成猫、改成别的角色，名字也可以随时再改。测评者们给自己的孩子起名 Pip、Lyra、Marley 的都有——这一步纯属个人偏好，改不改都不影响功能。

起完名它可能会让你简单说说自己的偏好（比如作息、常做的事），这些会进入它的记忆，之后你随时可以在设置里编辑或清掉。

## 三、建议第一天就改的三个设置

默认设置偏「省事」，但如果你想对它的权限有更多控制，下面三处建议在正式派活之前先过一遍。

### 1. 关掉交互数据用于训练

应用默认把你的交互数据用于改进模型。不希望这样就去：

```
Settings → Data controls → 关闭 "Help improve our AI models"
```

这个开关随时可以再打开，关掉不影响任何功能。

### 2. 把权限确认调严

默认的权限档位是「部分操作需要询问」（ask for some actions）——Meta 的意思是低风险动作它自己做、敏感动作来问你，但「什么算低风险」由它判断。想要更稳妥，可以在：

```
Settings → Permissions → 改成 "Always ask"
```

改成之后每个对外动作都会先找你确认，摩擦变多但心里有底；用一阵子觉得太烦再放宽即可。

### 3. 连接器先少接

Connector（连接器）决定它能碰你哪些账号。第一天建议只接一两个低风险的服务（比如日历，或一个专门为它准备的小号邮箱），看它实际怎么干活，再决定要不要给更多。接法和读写权限怎么分，见 [连接器与账号授权.md](连接器与账号授权.md)。

## 四、免费额度与付费档

Muse 有免费档，日常轻度使用基本够用；用量有计量，超了才需要考虑付费。媒体一致报道的付费档位是两档：

| 档位 | 价格（媒体报道口径） |
| --- | --- |
| 免费 | 0，有用量上限 |
| Power | 约 20 美元/月 |
| Maximum | 约 100 美元/月 |

另有报道称发布时注册需要绑定支付卡才能开始使用。具体额度、价格与是否必须绑卡以应用内订阅页当时显示为准——这类数字变动很勤，不要拿任何一篇文章（包括本篇）当最终答案。
