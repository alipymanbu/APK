# EZCast 各品牌手机投屏开关在哪里

> EZMirror 要从手机系统的投屏入口发起，各品牌名称与路径都不同，找不到开关按本篇找。

## 一、先去下拉菜单里找

多数安卓手机把投屏做成了**快捷设置磁贴**：从屏幕顶部下拉（或上滑呼出控制中心），在磁贴里找名字带这些字样的图标 —— **投屏 / 无线投屏 / 屏幕镜像 / Smart View / 多屏互动 / 无线显示 / Wireless Projection**。点它 → 选中你的 EZCast 设备名，就进入 EZMirror 镜像。

没找到磁贴再进「设置」，路径见下表。

## 二、各品牌入口路径

| 品牌 | 功能名称 | 入口路径 |
| --- | --- | --- |
| 小米 | 投屏 | 设置 → 连接与共享 → 投屏；控制中心也有投屏磁贴 |
| OPPO | 手机投屏 / 多屏互动 | 设置 → 连接与共享 / 其他无线连接 → 手机投屏（部分版本叫「搜索投屏设备」） |
| vivo | 智慧投屏 | 设置 → 其他网络与连接 → 智慧投屏 → 屏幕镜像 |
| 荣耀 | 无线投影（Wireless Projection / MirrorShare） | 快捷设置磁贴；或去设置里的连接/显示类菜单找 |
| 三星 | Smart View | 快捷面板下拉找 Smart View 磁贴 |
| 华为 | 多屏互动 / 无线投屏 | 控制中心与设置里的连接类菜单，名称随系统版本变化 |

路径依据为各品牌官方支持页与说明书（截至 2026-09，系统改版后以搜索结果为准）；名称对照来自 EZCast 官方手册。同一品牌不同机型、不同系统版本路径会有出入，**在设置里直接搜「投屏」两个字是最快的兜底** —— 设置自带搜索能直达该功能页。

## 三、磁贴死活找不到：手动加进去

快捷面板一般有个**编辑入口（铅笔图标或「编辑」按钮）**，点进去能在磁贴池里找到「投屏 / 屏幕镜像」，按住拖到当前面板即可。荣耀官方说明给出的正是这条路：快捷设置里找不到，就进编辑模式添加。

## 四、开关找到了，投之前还差三个条件

1. **接收端停在待连接画面**：电视上的 EZCast 要开机、切对 HDMI 源、显示待机界面，手机才搜得到（[搜索不到设备与断连排查.md](搜索不到设备与断连排查.md) 第一节）。
2. **小米先关个人热点**：小米官方说明明确要求开启投屏前先关闭「个人热点」，否则投屏开关不可用。
3. **别开错对象**：EZMirror 是点对点直连，设备列表里要选 `EZCast-xxxx` 这类同屏器的名字，不是你家路由器的名字；投屏期间手机会脱离路由器 Wi-Fi 属正常（见 [投屏协议支持哪些设备.md](投屏协议支持哪些设备.md)）。

三条都满足还是搜不到设备，问题就不在开关上了，转 [搜索不到设备与断连排查.md](搜索不到设备与断连排查.md)。
