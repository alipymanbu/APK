## 一、打开文件与标签页

- 从文件管理器新建或打开 Markdown 文件；内容**自动保存**到当前工作区。
- 多个文件以标签页打开，标签页还能拆成多个编辑分组同屏对照，支持的文本文件可拖到独立桌面窗口。
- 常见的文本类代码文件也能打开；不支持的格式会显示「不可编辑」提示——NoteGen 主要管理 Markdown 和受支持的文本/图片文件。

## 二、可视化模式还是源码模式

| 模式 | 适合干什么 |
|---|---|
| 可视化（所见即所得） | 日常写作：标题、表格、图片直接渲染着改 |
| 源码 | 精确编辑原始字符、Frontmatter、暂不支持的语法 |

两种模式**共用同一个文件**，切换不会产生两份副本。默认模式在编辑器设置里选，源码模式可开行号和自动换行。首次切换后，拿含复杂 HTML 或超大文档的笔记检查一遍格式是否保持预期。

## 三、常用编辑操作

- 直接输入 Markdown 标记（`#`、`-`、`**` 等）会自动转成对应格式。
- 输入 `/` 打开斜杠命令菜单，键盘选块。
- 段落左侧的拖拽手柄可以上下调块顺序。
- 表格有行列增删、对齐方式的浮动操作条。
- 图片支持粘贴、拖入、选择上传、缩放和路径转换。
- 查找/替换支持上一个、下一个、大小写匹配；大纲按标题生成，可放编辑器左侧或右侧，**拖动标题就能整段搬章节**。
- 所有快捷键在「设置 → 快捷键」里可查可改，并会提示与全局快捷键的冲突；状态栏可显示字符数、单词数、行数。

## 四、数学公式与图表

- 行内公式 `$...$`，块级公式 `$$...$$`，由 KaTeX 渲染。
- Mermaid 代码块可渲染流程图、时序图、类图、状态图、ER 图、甘特图、饼图、旅程图。
- 点击公式或 Mermaid 图会打开专用编辑界面，改完即更新。

## 五、AI 怎么帮你写

三个入口，走的都是你在模型配置里选定的模型（没配就用内置免费模型）：

1. **内联补全**：底部打开 AI 补全开关后，编辑器会根据光标前后内容给建议，接受/取消的按键在「设置 → 快捷键」里配置。
2. **选区工具**：选中一段字，浮动工具栏提供**润色、精简、扩写、翻译**；结果流式显示，你可以接受也可以放弃，不满意不会覆盖原文。
3. **Agent 修改**：让 Agent 读当前文件并提出改动，改动以 **Diff** 形式展示，你确认后才写入；一次涉及多个文件时，在变更面板逐项审阅。

接自己的 API、换模型的方法见[AI模型配置与切换教程.md](AI模型配置与切换教程.md)。

## 六、导出

编辑器导出菜单支持 **Markdown、HTML、纯文本、JSON、PDF** 五种格式；文件管理器右键菜单也能导出 Markdown 文件。PDF 是按当前渲染结果生成的，复杂分页、远程图片、超宽表格这几类内容导出后建议打开检查一遍。

## 七、手机端的差异

手机端用的是同一套 Markdown 数据，操作按触控重排：

- 选区后出上下文栏，底部是写作工具栏，更多操作收在「更多」菜单里；
- 桌面端的悬浮按钮在手机上换成底部抽屉；
- 新标签页、分屏、独立窗口这类桌面特性手机上没有，对照阅读时可以配合导出或同步在电脑上进行。

如果你在整理记录时生成了初稿，会直接落到这个编辑器里接着改——流程见[记录与整理成笔记教程.md](记录与整理成笔记教程.md)。
