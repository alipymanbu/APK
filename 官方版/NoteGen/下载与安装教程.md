## 一、先认清你要装的包

NoteGen 是一款开源、跨平台的 Markdown AI 笔记应用，桌面端与手机端共用同一套笔记数据。装之前先确认两件事：

- **安卓包目前只有 ARM64**（官方下载页口径）。在手机「设置 → 关于手机」里看处理器架构，显示 `aarch64` / `arm64` 才能装；32 位老设备装不上官方包。
- **网盘里的包和官网最新版可能不是同一个版本**。下面这张表是网盘里那份包的事实：

| 项目 | 值 |
|---|---|
| 版本 | 0.30.0 |
| 包名 | `com.codexu.NoteGen` |
| 大小 | 167.41M |
| MD5 | `c392e5f04de7e3711b108829248a7394` |

要装最新版，以[官方下载页](https://notegen.top/cn/download)当时显示的版本为准；要和本文其它篇里的版本号对得上，就用网盘那份。

另注：这个项目的版本迭代比较快——截至 2026 年 9 月，公开的 Release 列表已到 0.37 系列（具体以 [github.com/codexu/note-gen](https://github.com/codexu/note-gen) 的 Releases 页面为准），网盘里的 0.30.0 与最新版之间隔着多个版本，功能界面可能有差异；本文各篇的版本号、包名、体积一律以网盘那份包的事实为准。

## 二、两种获取方式

1. **官方下载页**：[notegen.top/cn/download](https://notegen.top/cn/download) 提供 Windows 安装程序、macOS DMG、Linux 的 AppImage/Deb/RPM、Android APK（ARM64），iOS 走 TestFlight、可用性以页面为准。
2. **网盘**：[NoteGen 安装文件资源（夸克网盘）](https://pan.quark.cn/s/db34ce91c54b) —— 转存后按需下载，包含上表那份 0.30.0 的安卓包。

选哪个多半取决于你要不要「刚好是 0.30.0 这一版」：跟本篇表格核对过 MD5 的就是网盘这份；只想要最新版就去官方下载页。

## 三、安卓安装步骤

1. 把 APK 下载到手机（或先转存网盘再在手机上下载）。
2. 点开 APK，系统会弹「禁止安装未知来源应用」——按提示到设置里给当前安装来源（浏览器或文件管理器）开一次权限，再回来装。
3. 装完打开，NoteGen **不需要注册登录**就能用。
4. （可选）想核对包有没有下完整，用文件管理器的 MD5 校验功能对比 `c392e5f04de7e3711b108829248a7394`。

如果安装时提示「无法安装」「解析包时出现问题」，先回头核对 CPU 架构是不是 ARM64，再看[常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、桌面端安装

| 平台 | 安装包形态 |
|---|---|
| Windows | x64 安装程序 |
| macOS | DMG（Apple Silicon 与 Intel 各一份） |
| Linux | AppImage、Deb、RPM（x86_64） |

装法和普通桌面软件没有区别：Windows 双击安装程序走完向导；macOS 把 DMG 里的应用拖进「应用程序」；Linux 按发行版选 Deb/RPM 双击装，或直接运行 AppImage。具体可下载的版本以官方下载页当时显示为准。

## 五、首次启动该做的四件事

1. **直接进主界面**，不用注册、不用登录；核心功能免费，没有订阅墙（官方口径）。
2. 打开「记录」，随手建一条文本记录，确认界面能正常写入。
3. 打开「设置 → 模型配置」：先试试内置免费模型；要接自己的 API（比如 DeepSeek），步骤见[AI模型配置与切换教程.md](AI模型配置与切换教程.md)。
4. 多设备使用的话，到「设置 → 同步配置」选 GitHub、Gitee、GitLab、Gitea、S3 或 WebDAV，先别急着开「记录与配置自动同步」，想清楚哪台设备是主数据源再开。

## 六、升级与重装注意

- 升级前先退出还在后台跑的 NoteGen 进程，安全软件可能锁住安装文件导致更新失败。
- 新版打不开时，**先别清应用数据和工作区**——笔记都存在本机，清了就没了；处理办法见[常见问题与故障排查.md](常见问题与故障排查.md)的「更新或启动失败」。
- 降级不保证兼容新版数据库，装回旧版前先确认你手上有兼容版本导出的备份。

## 七、开源信息从哪查

代码与问题反馈都在 [github.com/codexu/note-gen](https://github.com/codexu/note-gen)：Issues 提 bug、Discussions 提使用问题、Releases 看各平台安装包。开源许可为 GPL-3.0（第三方资料与仓库许可徽章一致，具体以仓库里的 LICENSE 文件为准）；想确认某个功能是不是官方做的、或者版本之间改了什么，看仓库的提交记录与 Release 说明最可靠。多设备怎么接同步见[多设备同步与备份教程.md](多设备同步与备份教程.md)。
