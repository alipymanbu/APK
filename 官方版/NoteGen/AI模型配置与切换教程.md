## 一、先想清楚用哪种模型

NoteGen 的 AI 功能（对话、记录整理、润色翻译、录音转写、OCR 识别）都由模型驱动，两条路：

| 方案 | 适合谁 | 要做什么 |
|---|---|---|
| 内置免费模型 | 先体验功能、不想折腾 | 什么都不用配，装好就能试 |
| 自己的 API | 长期用、要选具体模型（如 DeepSeek） | 去服务商开放平台拿 Key，填进模型配置 |

官方口径是「无订阅、无需登录，核心功能免费」，但**接自己的 API 后，模型服务商按调用量计费**——那是你和模型服务商之间的账，与 NoteGen 无关。

## 二、添加一个 OpenAI 兼容服务（以 DeepSeek 为例）

1. 到模型服务商的开放平台注册并创建 API Key（Key 只显示一次，当场复制）。
2. 打开 NoteGen「设置 → 模型配置」，添加一个服务。
3. **Base URL 只填到版本号为止**，例如 `https://api.openai.com/v1`——**不要**在后面接 `/chat/completions`，这是官方排错文档点名的第一条坑。
4. 填模型名、模型类型、API Key。
5. 点模型配置里的**连接检测**，通过了再保存。
6. 之后在对话面板的工具栏（可配置模型、Prompt、回复语言那一条）里选用这个模型。

用本地模型（Ollama、LM Studio）的话，Base URL 指向本地服务即可，但**服务必须正在运行**，并且要允许 NoteGen 所在的设备访问它。

## 三、连接检测没过，按这个顺序查

- Key、模型名、模型类型三项逐个核对，模型名拼错是最常见的原因；
- Base URL 是否多带了 `/chat/completions` 后缀；
- 走代理的话，检查供应商级代理选的是「继承/直连」还是「自定义」，以及全局代理地址是否有效；
- 兼容旧接口的服务商，把 Token 限制参数从 `max_completion_tokens` 改成 `max_tokens` 再试。

更完整的原因清单（含同步、录音、OCR 等其它故障）在[常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、怎么切换模型

- **对话时**：对话面板工具栏上就能改当前会用的模型，配好多个服务商后随时切。
- **写作与整理时**：选区润色、内联补全、记录整理用的都是模型配置里生效的那个模型，换默认模型就在「设置 → 模型配置」里改。
- 想同时保留多家（例如日常用一家、长文用另一家），把它们都加进模型配置，按任务在工具栏切即可，不用反复填 Key。

## 五、用在线模型前知道的隐私边界

按官方隐私说明：笔记、记录、聊天、设置**默认存在本机**；一旦你启用在线模型（以及同步、图床、MCP），本次相关内容就会发给你选的那个服务。处理敏感笔记时，要么用本地模型，要么清楚内容会经过服务商的服务器。

## 六、这套配置在哪些设备生效

模型配置属于「配置」的一部分，跟随「记录与配置同步」走；没开同步时，**每台设备各配各的**——手机上配好了 DeepSeek，电脑上还得再填一遍。同步怎么开见[下载与安装教程.md](下载与安装教程.md)的首次启动一节。
