## 一、为什么记录时不用先分类

NoteGen 把「收碎片」和「成文」拆成两步：记的时候不用取标题、不用想放哪个文件夹，先记下来；等要写周报、总结、文章时，再从记录里挑出相关的那批，交给 AI 整理成结构化的 Markdown。你不会因为「还没想好放哪」而丢掉一条有用的碎片。

桌面端从左侧「记录」入口进入，手机端用的是独立的记录页面。

## 二、七种记录类型

| 类型 | 内容与用法 |
|---|---|
| 文本 | 手动输入、粘贴，或从剪贴板快速记录 |
| 录音 | 实时录音或导入音频，通过 STT 转成文字 |
| 扫描 | 截图后用本地 OCR 或视觉模型提取内容 |
| 图片 | 保存图片并生成识别文本或描述 |
| 链接 | 保存 URL、标题和说明，可打开原网页 |
| 文件 | 保存附件路径和描述，可从记录详情打开 |
| 待办 | 创建、编辑、勾选完成状态 |

录音、扫描 OCR、图片描述这些类型**依赖对应模型或系统能力**：没配模型时它们不会出结果，先按[AI模型配置与切换教程.md](AI模型配置与切换教程.md)把模型接上。七种记录入口的顺序和显隐可以在「设置 → 记录设置」里调整，那里还能开关**剪贴板监听**——开着时你复制的文本或图片会自动进记录流，不用手动切回来粘贴（关掉它也在这里，怀疑记录莫名其妙变多时先查这个开关）。

## 三、标签、搜索与筛选

- 每条记录属于一个标签，创建时可选目标标签；标签支持创建、重命名、排序、删除。
- **删标签不会连带永久删除**：里面的记录进回收站，可以再恢复。
- 视图可在列表、紧凑、卡片三种样式间切换。
- 搜索覆盖记录正文、描述和链接。
- 时间筛选：全部 / 今天 / 最近 7 天 / 最近 30 天；类型筛选可同时勾多种。
- 标签筛选能和搜索、时间、类型条件**组合使用**——比如「标签=项目A + 最近 7 天 + 只看链接」。

## 四、把记录整理成笔记（五步）

1. 打开整理面板，选择**整理模板**和记录范围，确认模板内容。
2. 按类型和标签筛选本次要用的记录，取消不想让 AI 看到的内容；赶时间也可以从第一步直接「快速整理」。
3. 设置**保存位置**与文章标题，决定是否包含图片、是否保留引用链接、是否移除思考内容。
4. 需要的话填一条补充要求（例如「控制在 800 字内」「保留来源链接」），然后开始整理。
5. AI 按模板把选中的文本、扫描、图片、链接、文件、录音、待办处理成一个 Markdown 文件，生成后自动进入编辑器供你继续改。

注意：**整理只读取本次选中的记录，不会删除原记录**；生成的笔记就是普通 md 文件，后续手动改动不会被整理操作覆盖。

## 五、整理模板怎么写才有用

模板 = 名称 + 启用状态 + 默认范围 + Prompt。会议纪要、学习总结、项目调研、日报这类重复场景值得各建一个模板。Prompt 里写清四件事：

- 输出结构（分几个章节、标题怎么起）；
- 是否保留来源链接；
- 图片放在什么位置；
- 待办用什么格式（列表还是表格）。

写得越具体，生成的初稿返工越少；生成结果不理想时，优先改模板 Prompt，而不是反复重新生成。

## 六、记录之后的去向

- 打开记录详情可以编辑内容、移动标签、打开源文件或链接、删除或恢复；多选模式支持批量操作；删除的记录都先进回收站。
- **把记录拖进编辑器**，可以直接插入到正在写的笔记里。
- 对话工具栏的「关联标签」可以把当前标签下的记录塞进 AI 上下文，让回答基于你记过的素材。
- Agent 也能通过工具查询、创建、更新记录，写入和删除前会先向你确认权限。

## 七、手机端与隐私边界

手机端的记录页面和桌面端是同一套数据，只是布局按触控重排（详细差异见[Markdown编辑器与AI写作教程.md](Markdown编辑器与AI写作教程.md)末尾一节）。

记录保存在**本机数据库**。两类操作会把内容送出本机：

1. 开启「记录与配置同步」后，记录、标签、聊天和允许同步的设置会上传到你选的同步平台；
2. 用在线转写、视觉模型或描述模型时，对应的音频、图片、文本会发给该模型服务。

不想让内容出门，就只用本地能力，不配在线模型、不开同步。
