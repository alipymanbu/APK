# NoteGen 常见问题与故障排查

> 模型连不上、录音没声、文件不显示、同步失败、手机端缺功能——按现象直接查对应小节。

## 一、模型无法连接

1. Base URL 通常只填到版本号，例如 `https://api.openai.com/v1`，不要附加 `/chat/completions`。
2. 核对 API Key、模型名称、模型类型三项。
3. 在模型配置中跑一次**连接检测**，看哪一步断的。
4. 本地 Ollama / LM Studio：确认服务在运行，且允许 NoteGen 所在设备访问。
5. 走代理的：检查供应商级代理是「继承、直连」还是「自定义」，确认全局代理地址有效。
6. 旧接口兼容：把 Token 限制参数从 `max_completion_tokens` 改为 `max_tokens`。

## 二、同步失败或发生冲突

- 先看当前平台是否显示「已连接」，Token 权限、仓库/存储桶/路径前缀逐项检查。
- GitHub 已有的仓库通常只需要 Contents 读写权限；让 NoteGen **新建**仓库还需要 Administration 读写。
- GitLab 用 REST API，需要 `api` 权限；Gitea 自建实例要填对地址。
- 冲突时三个选项：合并两边新增内容 / 远程覆盖本机 / 本机覆盖远程——后两个会丢一侧未同步的修改，动手前想清楚。
- 新设备第一次开「记录与配置自动同步」，先确认方向：该上传本机还是该拉取远程。
- 工作区路径这类设备专属配置默认不跨设备同步，换机后要重设。

## 三、录音或朗读没有声音

- 查系统麦克风权限和输入设备是否选对。
- 录音转写需要 STT 模型；内置免费服务不可用时，配你自己的模型。
- 朗读先把语音选「自动」，系统语音不可用再配 TTS 模型。
- 上传音频失败：确认格式受支持、文件没损坏。

## 四、工作区或文件未显示

- **改过工作区后要重启应用**，所有组件才会重新加载路径。
- 确认应用有该目录的读写权限。
- NoteGen 主要管理 Markdown 和受支持的文本/图片文件，不支持的格式会显示为不可编辑。
- 切换工作区**不会搬走旧文件**：可以从历史工作区切回去，或在系统文件管理器里手动迁移。

## 五、手机端用不了的功能（不是坏了）

| 现象 | 原因 |
|---|---|
| MCP 配了没反应 | 移动端仅支持 HTTP MCP，stdio 本地命令只在桌面端能跑 |
| 浏览器剪藏连不上 | 只有桌面端能接收剪藏，扩展默认连 `127.0.0.1:37421` |
| 本地命令型 MCP 选项缺失 | 该功能仅桌面端提供（官方平台表口径） |

手机端对应的替代做法：把要整理的内容用记录同步到电脑端处理，或改用 HTTP 形态的 MCP 服务。

## 六、OCR 或图片识别失败

- OCR 需要对应语言包，首次使用可能要先下载；语言代码例如简体中文+英文可填 `chi_sim,eng`。
- 手机端和 macOS 可能走系统原生 OCR，其它环境可能用 Tesseract——识别效果不同属正常。
- 视觉模型（VLM）需要可用的视觉/对话模型和网络；复杂排版适合 VLM，纯文本适合 OCR。

## 七、更新或启动失败

- 确认安装包与 CPU/平台匹配（安卓只有 ARM64），从官网或 GitHub Releases 重新下载。
- 更新前退出仍在运行的 NoteGen 进程；安全软件可能锁住安装文件。
- 新版打不开时，**保留应用数据目录和工作区**，不要先执行清理；可提交脱敏诊断信息后再决定是否降级。
- 降级不保证兼容新版数据库，优先恢复由兼容版本导出的 ZIP 备份。

## 八、还没解决怎么办

到 [github.com/codexu/note-gen](https://github.com/codexu/note-gen) 的 Issues 提问前，先搜一遍官方文档与已有讨论。提交时带上：NoteGen 版本、系统版本、复现步骤、预期结果、实际结果；**贴日志或截图前先移除 API Key、Token、私人路径和笔记内容**。
