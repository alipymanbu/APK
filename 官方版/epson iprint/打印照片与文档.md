## 一、能直接打哪些东西

| 内容 | 入口 | 说明 |
| --- | --- | --- |
| 照片 | 相册 | JPEG、PNG；一次最多选 30 张 |
| 文档 | 文档 | PDF 最稳；Word/Excel/PPT 能否直接打印因版本与地区而异（美区官方页面写支持，中国区 FAQ 写最新版仅支持 .pdf），以你 app 里实际能选中的文件为准，选不了就先转成 PDF |
| 网页 | 网页打印 | app 内置浏览器，输网址或从书签打开后直接打 |
| 云盘文件 | 在线存储 | Box、Dropbox、Evernote、Google Drive、OneDrive |

## 二、打印照片的路径

相册 → 选图（可多选，上限 30 张）→ 打印 → 设纸张与质量 → 打印。微信、邮件里收到的图打出来发糊，多半是原图在传输时被压缩过，能拿到原图就别用聊天软件里那份。

## 三、打印设置对照表

| 设置项 | 可选值 / 作用 |
| --- | --- |
| 纸张类型 | 照片纸 4x6 / 5x7 / 8x10；普通纸 A4、Legal（因机型而异） |
| 打印质量 | 照片建议选高，普通文档标准即可 |
| 彩色 / 黑白 | 黑白文档关掉彩色能省墨 |
| 双面 | 机型支持双面单元才会出现这一项 |
| 页数范围 | 多页文档指定打第几页到第几页 |
| 版式 | 部分版本提供 2 合 1 / 4 合 1，一页纸排多张 |
| 份数 | 一次打几份 |

设置项随机型与耗材配置增减，以 app 内实际显示为准。

## 四、从云盘打印

在线存储里登录对应账号 → 浏览并选中文件 → 打印。OneDrive 在部分时期出现过 iPrint 无法直接访问、提示通信错误的问题，官方 FAQ 给的临时办法是在手机上装 OneDrive app，用它的「分享」功能把文件发给 iPrint（截至本文检索时官方 FAQ 仍列有此条，以官方页面为准）。

## 五、远程打印的体积限制

用 Remote 方式连接时，文件大小有上限，而且不同地区官方 FAQ 的口径不完全一致：美区写本地打印约 70MB/任务、远程单文件 10MB / 整任务 70MB；中国区写远程文档 20MB、图片 10MB。遇到「The file size is too big.」就压缩、转 PDF 或拆分，别反复重试。同一 Wi-Fi 下的本地打印一般不受远程那套限制。远程打印的开通见[远程打印与邮件打印设置.md](远程打印与邮件打印设置.md)。

## 六、任务发出去却没动静

先看打印机本身：缺纸、卡纸、盖子没合、墨盒警告，任务都会停在队列里；队列积压太多也会报「Cannot print the document.」，到打印历史里删掉旧任务再试。报错原文对应的处理办法逐条列在[打印报错对照与处理.md](打印报错对照与处理.md)；打出来有横纹、断线、偏色，那是喷嘴问题而不是设置问题，处理步骤见[打印机维护功能.md](打印机维护功能.md)。
