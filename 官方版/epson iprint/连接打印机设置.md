## 一、先确认机型支持

iPrint 兼容带 Wi-Fi 或以太网的 Epson 机型，具体名单查官方兼容清单：[https://support.epson.com.cn/appinfo/iprint/cn/](https://support.epson.com.cn/appinfo/iprint/cn/)。另外注意功能差异：用手机控制复印、在打印机和手机之间传文件这类扩展功能，只有 2014 年 9 月之后发布的部分机型才有。

## 二、三种连接方式怎么选

在选择打印机页面里有 Local、Manual IP、Remote 三种方式：

| 方式 | 什么时候用 | 前提 |
| --- | --- | --- |
| Local | 家里 / 办公室日常打印 | 打印机与手机连同一个 Wi-Fi |
| Manual IP | 自动搜索不稳定、打印机固定了 IP | 你知道打印机的 IP 地址 |
| Remote | 人不在打印机所在的网络 | 打印机已注册 Epson Connect 服务 |

## 三、Local 连接四步

1. 在打印机面板的网络设置里把打印机连上家里 Wi-Fi（多数机型有连接向导）；
2. 手机连同一个 Wi-Fi；
3. 打开 iPrint，进入选择打印机页面，保持 Local 方式；
4. 等列表里出现你的机型，选中即可。

## 四、搜不到打印机的排查顺序

按命中概率从高到低逐项检查：

1. 打印机电源开着、没在深度休眠；
2. 打印机自己的网络设置里显示已连上 Wi-Fi（面板上一般有信号图标）；
3. 手机连的是不是同一个 Wi-Fi——家里「主路由 + 副路由」的组网常把设备分到两个网段，互相看不见；
4. iPrint 的定位权限已给（Android 6.0 以后扫描 Wi-Fi 必须开定位权限，见[下载与安装教程.md](下载与安装教程.md)第四节）；
5. 路由器没开「AP 隔离」，手机没连在访客网络里——这两种情况下设备之间互相不可见；
6. 频段问题：不少 Epson 机型只支持 2.4GHz Wi-Fi，如果路由器把 2.4G 和 5G 分成两个名字，把手机连到 2.4GHz 那个再试（以机型规格为准）；
7. 还不行就重启打印机和路由器，或直接改用 Manual IP。

## 五、Manual IP 怎么填

在打印机面板或它打出来的网络配置页上找到 IP 地址（形如 `192.168.x.x`），在选择打印机页面切到 Manual IP 填进去。打印机被固定 IP、或自动搜索时好时坏的环境下，这种方式最稳。

## 六、Remote 远程打印的前提

Remote 走的是 Epson Connect 服务：打印机要先按官方指引注册 Epson Connect，之后人在外地也能把文件发给这台打印机。注意远程打印对文件体积有限制：文档最大 20MB、图片最大 10MB；同一 Wi-Fi 下的本地打印不受这个限制。
