## 一、先确认机型支持

iPrint 兼容带 Wi-Fi 或以太网的 Epson 机型，具体名单查官方兼容清单：[https://support.epson.com.cn/appinfo/iprint/cn/](https://support.epson.com.cn/appinfo/iprint/cn/)。另外注意功能差异：用手机控制复印、在打印机和手机之间传文件这类扩展功能，只有 2014 年 9 月之后发布的部分机型才有。

## 二、三种连接方式怎么选

在选择打印机页面里有 Local、Manual IP、Remote 三种方式：

| 方式 | 什么时候用 | 前提 |
| --- | --- | --- |
| Local | 家里 / 办公室日常打印 | 打印机与手机连同一个 Wi-Fi |
| Manual IP | 自动搜索不稳定、打印机固定了 IP | 你知道打印机的 IP 地址 |
| Remote | 人不在打印机所在的网络 | 打印机已注册 Epson Connect 服务 |

## 三、Local 连接四步

1. 在打印机面板的网络设置里把打印机连上家里 Wi-Fi（多数机型有连接向导）；
2. 手机连同一个 Wi-Fi；
3. 打开 iPrint，进入选择打印机页面，保持 Local 方式；
4. 等列表里出现你的机型，选中即可。

## 四、搜不到打印机的排查顺序

按命中概率从高到低逐项检查：

1. 打印机电源开着、没在深度休眠；
2. 打印机自己的网络设置里显示已连上 Wi-Fi（面板上一般有信号图标）；
3. 手机连的是不是同一个 Wi-Fi——家里「主路由 + 副路由」的组网常把设备分到两个网段，互相看不见；
4. iPrint 的定位权限已给（Android 6.0 以后扫描 Wi-Fi 必须开定位权限，见[下载与安装教程.md](下载与安装教程.md)第四节）；
5. 路由器没开「AP 隔离」，手机没连在访客网络里——这两种情况下设备之间互相不可见；
6. 频段问题：官方 FAQ 明确说，除部分机型外，打印机连不上 5GHz 频段的 SSID（名字常带 `-a`、`-5` 后缀）——把打印机连到 2.4GHz 那个 SSID（名字常带 `-g`）再试；
7. 打一张网络状态页确认：多数机型能在设置里打印一张网络状态页，看 TCP/IP IPv4 一栏的 IP——是 `192.168.x.x` 这类地址说明打印机已正常入网；是 `169.254.x.x` 说明它根本没拿到有效地址，先让打印机重新连 Wi-Fi；
8. 还不行就重启：路由器断电等 30 秒再插回（稳定约需 2~3 分钟），打印机和手机也各重启一次；或者跳过搜索，直接改用 Manual IP。

## 五、Manual IP 怎么填

在打印机面板或它打出来的网络配置页上找到 IP 地址（形如 `192.168.x.x`，TCP/IP IPv4 一栏），在选择打印机页面切到 Manual IP 填进去。打印机被固定 IP、或自动搜索时好时坏的环境下，这种方式最省事。

## 六、Remote 远程打印的前提

Remote 走的是 Epson Connect 服务：打印机要先注册 Epson Connect，之后人在外地也能把文件发给这台打印机。注册的三个途径、Email Print 邮件打印的规则，见[远程打印与邮件打印设置.md](远程打印与邮件打印设置.md)。注意远程打印对文件体积有限制：文档最大 20MB、图片最大 10MB；同一 Wi-Fi 下的本地打印不受这个限制。
