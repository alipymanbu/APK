## 一、哪些机型能扫

带扫描单元的 Epson 一体机才有扫描入口，纯打印机没有。扫描可以走稿台玻璃，也可以走自动进稿器（ADF）——多页文件用 ADF 一次进纸、存成一个 PDF，比逐页翻稿台省事。

## 二、扫描步骤

1. 手机与一体机连同一 Wi-Fi，iPrint 里已连上这台机器；
2. 进「扫描」；
3. 先点「预览」看位置正不正，可以直接在预览图上拖动框选扫描区域，不合适再重新预览；
4. 设定分辨率与保存格式，点扫描；
5. 扫完选择存到手机、发邮件或传云盘。

## 三、分辨率与格式怎么选

iPrint 提供 75 / 150 / 300 dpi 三档；安卓端扫描结果可存 JPEG 或 PDF：

| 用途 | 建议设置 |
| --- | --- |
| 发微信、存档翻看 | 150 dpi，JPEG，文件小、够清晰 |
| 要二次打印的文档副本 | 300 dpi，PDF |
| 只要文字内容不追求画质 | 75 dpi，最快 |

## 四、扫完后的去处

- 存到手机本地；
- 作为附件发邮件；
- 传到 Box、Dropbox、Evernote、Google Drive、OneDrive；
- 直接再打印一份。

## 五、保存失败与「找不到扫描仪」

往打印机插着的 U 盘 / 存储卡保存时报「Error while reading. / Error while writing.」，到打印机设置里把 File Sharing（文件共享）设为 Network 或 Wi-Fi/Network；手机本身空间不足也会保存失败。提示「找不到扫描仪」则是另一类问题：确认一体机开着、网络已连上、与手机在同一网段，然后按[连接打印机设置.md](连接打印机设置.md)第四节的清单逐项排查，报错原文对照见[打印报错对照与处理.md](打印报错对照与处理.md)。
