## 一、连接类报错

| 报错原文 | 多半是 | 怎么处理 |
| --- | --- | --- |
| Cannot find printer. / Cannot find the scanner. | 不在同一网络，或打印机关着 | 确认手机与打印机同一 Wi-Fi、打印机已开机；逐项排查见[连接打印机设置.md](连接打印机设置.md)第四节 |
| Communication error. / A communication error occurred. | 通信中断 | 确认同一网络、打印机开机，稍后重试 |
| Printer is not selected. / Scanner is not selected. | 还没选打印机 | 回 app 里把打印机选上再操作 |

## 二、打印执行类报错

| 报错原文 | 多半是 | 怎么处理 |
| --- | --- | --- |
| Cannot print the document. | 服务器上积压的打印任务太多 | 到打印机的打印历史里删掉多余任务再试 |
| General error. | 卡纸等多种原因 | 查卡纸 → 打印机关机再开机 → 确认同一网络 → 确认文件不超过 20MB、格式受支持（照片 JPEG/GIF/TIFF/BMP/PNG，文档 PDF/Word/Excel/PPT） |
| Page not printed. / multi-page error | 进纸异常 | 查卡纸、重新装纸、确认纸张尺寸装对了 |
| Paper out. / Paper feed error. | 缺纸、纸张装反、纸型不对 | 按打印机屏幕提示重新装纸 |
| Paper size and paper type settings do not match the printer settings. | app 里的纸张设置与实际装纸不一致 | 把 app 的纸张尺寸 / 类型改成与实际装入的一致 |
| Cassette tray is not installed correctly | 纸盒没插到位 | 拉出来重新插到底 |
| Rear manual feed cover is closed. | 该走后部手动进纸 | 按提示在后部手动进纸口放单张纸 |

## 三、盖子与耗材类报错

| 报错原文 | 多半是 | 怎么处理 |
| --- | --- | --- |
| Ink cover open / Printer cover error | 墨舱盖 / 机盖没关严 | 关严再打 |
| The scanner cover is open. / Scanner unit open | 扫描单元没扣好 | 扣好扫描单元 |
| Head Cleaning can not be completed. | 墨水不足或已用尽 | 先补墨 / 换墨盒，再做[打印机维护功能.md](打印机维护功能.md)里的喷嘴检查与清洗 |
| Service required. | 打印机需要检修 | app 这边解决不了，联系 Epson 售后 |

## 四、文件与存储类报错

| 报错原文 | 多半是 | 怎么处理 |
| --- | --- | --- |
| The file size is too big. / Size of transmitted data is too big. | 超出体积上限 | 上限因连接方式与地区口径而异：本地打印约 70MB/任务；远程打印单文件约 10MB、整任务约 70MB（中国区 FAQ 另写远程文档 20MB、图片 10MB）。超了就压缩、转 PDF 或拆分 |
| The process is aborted due to lack of memory. / There is not enough free space. | 手机或存储设备空间不足 | 清出足够空间再保存 / 打印 |
| Error while reading. / Error while writing. | 往打印机上插的 U 盘 / 存储卡读写失败 | 到打印机设置里把 File Sharing（文件共享）设为 Network 或 Wi-Fi/Network |

## 五、远程打印专属报错

| 报错原文 | 多半是 | 怎么处理 |
| --- | --- | --- |
| Remote printing is not enabled for this printer. | 打印机没开远程打印子服务 | 登录 Epson Connect 账号把该打印机的 Remote Print 打开（打印机不是你的就联系机主）；注册与开通步骤见[远程打印与邮件打印设置.md](远程打印与邮件打印设置.md) |

## 六、CD/DVD 托盘类报错

| 报错原文 | 多半是 | 怎么处理 |
| --- | --- | --- |
| CD/DVD tray not set correctly / CD/DVD Tray in Use | 光盘托盘还架在机器上 | iPrint 不支持光盘打印，把托盘收好或关上盖子再打 |
