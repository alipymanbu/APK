## 一、先弄清 Epson Connect 是什么

Epson Connect 是爱普生的免费云服务：打印机注册后会拿到一个专属邮箱地址，并解锁 Email Print（发邮件就能打印）、Remote Print（iPrint 里异地直接打）、Scan to Cloud（扫描直接进云端）几个子服务，iPrint 的 Remote 连接也建立在它之上。人在外地想打家里或公司的打印机，走的就是这一套。

## 二、注册打印机的前提

- 打印机本身支持 Epson Connect（官方有支持机型列表，注册工具里也会直接提示）；
- 打印机连着**能上网**的网络——Wi-Fi 或网线都行，只插 USB 连电脑不行；
- 家用宽带一般不用改任何设置；公司网络要让打印机访问外网，官方注明 Epson Connect 走 5222 端口（仅打印机这一侧），网络受限时找管理员放行。

## 三、注册的三种途径

注册结果相同，按手边设备选：

| 途径 | 大致过程 |
| --- | --- |
| 打印机面板 | 支持的机型直接在面板的 Epson Connect / 网络服务设置里注册 |
| 电脑 | 官网下载 Epson Connect Printer Setup 工具，按向导注册 |
| 手机 / 平板 | 浏览器打开打印机的 Web Config 页面注册 |

注册完在 Epson Connect 用户页面能看到打印机的专属邮箱地址，也能逐个开 / 关各子服务。

## 四、iPrint 里的 Remote 打印

注册完成后，在 iPrint 的选择打印机页面切到 Remote，登录 Epson Connect 账号就能看到你的打印机。体积限制与常见报错见[打印报错对照与处理.md](打印报错对照与处理.md)；报「Remote printing is not enabled for this printer.」就是子服务没开，回用户页面把 Remote Print 勾上再试。

## 五、Email Print 的规则与限制

给打印机邮箱发邮件就能打印正文或附件，规则官方定死这几条（截至本文检索时，以官方页面为准）：

| 项目 | 上限 / 规则 |
| --- | --- |
| 邮件 + 附件总体积 | 20MB |
| 附件个数 | 10 个 |
| 收件打印机地址 | 最多 100 个 |
| 等待打印的队列 | 最多 100 封，满了先打印或删掉 |
| 密送（BCC） | 不会打印，写在收件人 / 抄送里才认 |
| 不认识的发件人 | 默认拒收；把发件人加进认可发件人列表 |
| 不支持的附件格式 | 先转成 PDF 再发 |

发出去没动静，去 Epson Connect 用户页面看打印日志，或在用户页面打开邮件通知——失败原因会以邮件发回给发件人或机主。

## 六、不用了记得收尾

打印机转卖、送人或报废前，在 Epson Connect 用户页面暂停该打印机的服务或把它从账号里删掉，避免打印机邮箱继续对外可用；整个账号也可以在官网注销。
