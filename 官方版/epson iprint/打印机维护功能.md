## 一、维护入口在哪

app 里选中打印机后进「维护」（部分机型显示为打印机维护 / 保养）。功能项随机型增减，常见有以下几样。

## 二、维护功能一览

| 功能 | 什么时候用 |
| --- | --- |
| 打印机状态 | 任务卡住先看这里：卡纸、缺纸、盖子未合都会显示 |
| 墨水余量 | 打印颜色变浅之前先看一眼 |
| 喷嘴检查 | 打印出现横纹、断线、偏色时 |
| 打印头清洗 | 喷嘴检查确认断线之后 |
| 固件升级 | 官方提示有新固件时 |

## 三、喷嘴检查与清洗的正确顺序

先做「喷嘴检查」打出检查图案 → 图案完整就什么都不用做 → 有断线才做「打印头清洗」→ 清洗完再跑一次喷嘴检查确认。清洗本身要消耗墨水，别一上来就连着洗好几遍，先检查、后清洗、再看结果。清洗到一半报「Head Cleaning can not be completed.」，基本是墨水不足或已用尽，先补墨再洗。

## 四、固件升级步骤

1. 进维护界面，点「固件升级」；
2. app 会先检查打印机固件是否最新，已是最新会直接提示；
3. 有新版时按提示点「升级」，手机上依次显示下载中、传输中、传输完成；
4. 打印机屏幕显示升级进度，期间不要关打印机电源、不要断网；
5. 升级完成后打印机会自动重启。

## 五、两个提醒

- 固件升级中途断电可能让打印机无法启动，手机电量不足先插上电再操作；
- 老机型可能没有固件升级入口，以 app 里实际显示为准。
