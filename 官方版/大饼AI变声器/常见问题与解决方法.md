## 一、排查前的万能两步

九成问题先做这两步就能定位方向：

1. **回到应用里试听**：选中音色说一句话——耳返里是变声 → 应用侧正常，问题出在「没传到对方那一环」（游戏/聊天设置、权限、后台被杀）；耳返里就是原声或无声 → 问题在应用侧，看下面第二节。
2. **重启应用再来一次**：音频通道被上次异常占用时，重启是最省事的复位手段。

## 二、应用侧：试听就没声 / 变声没效果

| 症状 | 按顺序检查 |
| --- | --- |
| 试听完全无声 | 麦克风权限是否允许；耳机是否插好；有没有别的应用（录音、K歌、会议）正占着麦克风，关掉它们 |
| 试听是原声 | 变声总开关没开，或音色被切到了「原声」，重新选一个音色 |
| 说话有声但换出来的声音发虚 | 你说话音量太小，用正常聊天音量再试；离麦克风近一点 |
| 偶尔没声 | 与耳返无声的处理相同：更新到新版本（官方更新日志里修过「耳返偶发无声」类问题），插拔一次耳机 |

## 三、应用正常、对方听不到

1. **权限**：悬浮窗没给，切到别的应用后变声管不着麦克风——去系统设置补上；开关是灰的或提示「受限设置」，按 [悬浮窗打不开怎么办.md](悬浮窗打不开怎么办.md) 解除；
2. **后台被杀**：锁屏/切后台后应用被清理，把它加入自启动与电池白名单（设置 → 应用 → 大饼AI变声 → 自启动/省电策略）；
3. **游戏侧设置**：麦克风输入改回「默认」，麦克风模式选听筒/耳机（完整顺序见 [游戏开黑实时变声怎么设置.md](游戏开黑实时变声怎么设置.md)）；
4. **聊天场景**：微信、QQ 本身没有麦克风设备选项，靠悬浮窗 + 后台保活生效，处理思路见 [微信QQ聊天变声方法.md](微信QQ聊天变声方法.md)；
5. **系统自带变声冲突**：手机设置里若有「变声/语音特效」功能，先关掉再试。

## 四、延迟明显、说话不同步

- 官方对实时变声的标称延迟是 **300ms 以内**（官网数据），体感上约一两个字的错位；实际数值受机型性能与耳机影响。
- **蓝牙耳机是延迟大户**：换有线耳机对比一次，差距通常立竿见影。
- 用耳返自测：耳返里自己的声音明显滞后，说明延迟来自本机链路；耳返正常而对方那边慢，问题多在对局网络，与变声无关。
- 老机型可以把音质/音效档位调低（若版本里提供该选项），牺牲一点音质换流畅。

## 五、回音、啸叫、听到自己

**几乎都是外放造成的**：声音从扬声器出来又被麦克风采回去，形成回路。戴耳机即可根治。耳机已戴好仍有回音——检查是不是同时插了两套音频设备（有线 + 蓝牙），只留一套再试。

## 六、闪退、卡顿、发热

1. 清一次应用缓存（设置 → 应用 → 大饼AI变声 → 存储 → 清除缓存），不清数据；
2. 关掉后台多余的大型应用，尤其一边打大型游戏一边变声的场景；
3. 缓存清完仍闪退 → 重装；重装前记好自己的登录手机号即可，账号数据在服务端；
4. 安装包损坏也会表现为装不上或秒退——用 MD5 对一下 [下载与安装教程.md](下载与安装教程.md) 第二节登记的值，不一致就重新下载。

## 七、其他高频问题

- **音色库加载不出来**：联网检查；应用需要联网才能拉音色列表，试听本身是否需要联网以版本为准。
- **登录收不到验证码**：确认手机号没填错、信号正常；官方登录页注明未注册手机号会自动创建账号，不存在「没注册所以登不上」。
- **更新后找不到原入口**：官方更新日志里做过「权限管理入口」「悬浮窗展示」这类界面调整，找不到的开关先在主界面和设置页各扫一遍，或以当前版本的引导页为准。
- **要不要用变声过验证**：涉及本人声音核验的场合（实名、声纹类）别开变声，验证以本人真实声音为准。
- **音色要付费吗**：不充值也能用（每周刷新的免费音色），买断特定音色才花钱，价目与避坑见 [免费音色与收费价格.md](免费音色与收费价格.md)。
- **手机版和电脑版别照搬**：电脑版走的是虚拟声卡方案（在第三方软件里选名为 `DubbingVirtualDevice` 之类的输入设备），手机上没有这一套——网上搜到的电脑版设置步骤对手机无效，手机按 [游戏开黑实时变声怎么设置.md](游戏开黑实时变声怎么设置.md) 来。
