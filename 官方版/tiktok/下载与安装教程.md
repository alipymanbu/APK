## 一、安装前先核对这份安装包的信息

通过安装包方式安装时，拿到的版本和官方商店最新版往往不是同一个。这份安装包的基本信息如下（信息核对于 2026-09-27）：

| 项目 | 值 |
| --- | --- |
| 版本号 | 46.9.3 |
| 包名 | com.zhiliaoapp.musically |
| 安装包大小 | 304.75 MB |
| MD5 | 84D2009804805306B52ACAB72D269D7A |
| 开发者 | TikTok Pte. Ltd. |
| 官方网站 | [www.tiktok.com](https://www.tiktok.com) |

两点说明：

- **包名里的 musically 不是装错了**。TikTok 的安卓包名一直是 `com.zhiliaoapp.musically`，来自它 2018 年与 Musical.ly 合并的历史——当时保留了原包名，这样老用户升级不丢数据。装完后在系统「设置 → 应用 → TikTok → 应用信息」里看到这个名字属正常现象。
- **版本以你手上这份为准**。官方最新版更新很快，具体到商店页面显示多少以官方页面为准；本文涉及的版本号一律指上面表格里这份。

## 二、从夸克网盘取安装包

1. 打开 [TikTok 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6e74748cbecc)，选择转存到自己的网盘（不转存直接下载部分文件类型会受限）。
2. 在夸克网盘客户端里找到转存后的 APK 文件，下载到手机本地存储。
3. 下载完成后，建议用文件管理器或校验类小工具核对一下文件大小是否约 305 MB；需要更严格校验时比对 MD5 是否等于 `84D2009804805306B52ACAB72D269D7A`，不一致说明文件在传输中损坏，重新下载即可。

## 三、安装步骤

安装包不来自应用商店，安卓默认会拦一道，需要先放行：

1. **允许安装未知来源应用**：各机型路径不同，常见入口是「设置 → 应用 → 特殊应用权限 → 安装未知应用」，给你用来打开 APK 的那个应用（文件管理器或浏览器）授予「允许安装」。
   - 小米/MIUI：「设置 → 隐私保护 → 特殊权限」；
   - 华为/鸿蒙：弹窗里直接选「仍要安装」或在「设置 → 安全 → 更多安全设置」里放开；
   - 三星：「设置 → 应用程序 → 右上角菜单 → 特殊访问权限 → 安装未知应用程序」。
2. 在文件管理器里点开下载好的 APK，按提示点「安装」。
3. 装完点「打开」，首次启动会依次请求网络、存储、相机、麦克风等权限——只看视频的话给存储与网络即可，要拍视频再给相机与麦克风。
4. 打开后可以先不注册直接刷视频；要发布内容需要先建账号，步骤见 [注册与登录方法.md](注册与登录方法.md)。

## 四、装不上时的逐条排查

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 文件下载不完整或损坏 | 重下一遍，顺手核对文件大小 |
| 点安装没反应 / 秒退回文件管理器 | 没给文件管理器「安装未知应用」权限 | 按第三节第 1 步放行 |
| 提示「与应用不兼容」 | 系统版本过低或存储空间不足 | 近年版本普遍要求 Android 5.0 及以上（不同渠道标注略有差异，以安装时提示为准）；再确认剩余空间大于 1 GB（安装包本身约 305 MB，解压安装还要额外空间） |
| 安装到一半失败 | 存储空间中途耗尽，或同时开了过多后台应用 | 清出空间后重试 |
| 覆盖安装被拦 | 手机上已有一个不同签名的同名应用（多为非官方来源的包） | 卸载旧的再装；卸载会清掉本地缓存与未同步数据，重要草稿先保存 |
| 装上但启动就闪退 | 机型太老、内存过小，或系统 WebView 版本异常 | 先重启手机；仍闪退说明这台设备跑不动当前版本，换设备，或留意所在地区是否提供官方更轻量的版本 |

安装环节的问题解决后，最常见的是装完刷不出视频、收不到通知这类使用故障，逐条处理办法见 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 五、更新与覆盖安装

用安装包方式装的版本不会自动更新，想升新版时两种做法：

1. **直接覆盖装**：从应用商店或可信渠道拿到新版安装包后直接安装，同包名（`com.zhiliaoapp.musically`）会覆盖升级，登录状态与云端数据不受影响；只有本地草稿与未同步的内容可能受影响，升级前先处理。
2. **卸载重装**：仅在覆盖安装被「签名不一致」拦截时才需要，等于清空重来，账号数据要重新登录。

覆盖装完打开时如果闪退，先重启一次手机再试（旧版本残留的进程偶尔会干扰首次启动）；仍不行回第四节对照排查。
