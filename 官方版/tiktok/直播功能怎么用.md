## 一、开播门槛：先对照自己够不够

LIVE 不对新账号开放，需要同时满足这些条件（截至 2026-09，以官方帮助页为准）：

| 条件 | 说明 |
| --- | --- |
| 粉丝数 ≥ 1000 | 最常被引用的硬门槛；个别账号提前解锁属于平台个案，无法主动申请触发 |
| 年龄达标 | 各来源口径不一：较新的资料称需年满 18 岁才能开播，也有资料写 16 岁可开播、18 岁才能收礼物（韩国为 19 岁）。两类说法并存，以你账号内「设置与隐私」里的实际提示为准 |
| 账号状态良好 | 有社区准则违规记录（strike）会被限制，即使条件都够 |
| 注册时长 | 有资料提到账号注册满 30 天才稳妥，此条并非每个地区都严格执行 |
| 账号非私密 | 私密账号无法开播，直播本质是公开内容 |

粉丝不够 1000 时有两条正规替代路：受邀作为嘉宾进入别人的直播间连麦（不需要自己满足粉丝门槛），或在「设置与隐私 → 报告问题」里按页面指引申请；有没有结果取决于平台审核，没有保证。

## 二、开播步骤

条件满足后，开播入口就在拍摄页：

1. 点底部「+」进入拍摄页。
2. 在底部模式条（拍照 / 视频 / 模板等）上滑动到 **LIVE**。找不到这一项就说明账号还没解锁，先看第五节的排查表。
3. 填标题，上限 32 个字符；选一个话题分类，帮助平台把直播间推给对的人。
4. 需要的话设定直播目标（viewers 打赏凑目标那种 goal）。
5. 点「Go LIVE」，短暂倒计时后开播。

开播后常用控制都在直播界面里：指派管理员、过滤评论、邀请观众或其他创作者连麦。想结束就点右上角关闭。

**电脑开播**：手机之外，官方还有桌面端的 TikTok Live Studio（Windows 应用），可以从电脑推流、接专业摄像头与麦克风，适合游戏、教学内容；部分地区可下载，且资料称通过它的试用申请，粉丝不足 1000 的账号也有机会提前获得开播资格——能不能用、入口在哪，以官方页面为准。

## 三、直播中的互动与礼物

- **观众侧**：发评论、点赞、送礼物。送礼物需要用「金币（Coins）」充值购买；多数资料称送礼物同样要求年满 18 岁，以充值页面提示为准。
- **主播侧**：收到的礼物折算成「钻石（Diamonds）」，累积后可按官方结算规则申请提现；比例与提现门槛以官方创作者页面为准，第三方流传的换算数值不要直接当真。
- **回放**：直播结束后有回放，资料称保存约 90 天，可在「设置与隐私」里查看、下载或删除，以 App 内实际显示为准。

## 四、直播买礼物与开店是两回事

直播间挂购物车、卖货属于 TikTok Shop 的功能，开通另有一套地区与资质要求（多数开放地区要求企业或达到销售门槛的创作者账号），和本篇的 LIVE 资格是两个独立开关。只在个别地区开放，你账号里没有「TikTok Shop」入口就是所在地区未开放，不用反复找。

## 五、找不到 LIVE 按钮：逐条对照

| 现象 | 最可能的原因 | 处理 |
| --- | --- | --- |
| 模式条上完全没有 LIVE | 粉丝数或年龄未达门槛 | 对照第一节；不满足只能等或走连麦嘉宾路 |
| LIVE 灰色不可点 | 年龄未达标或未验证 | 确认账号生日信息；未成年人没有合规开通途径 |
| 曾经能播，现在没了 | 有新的社区准则违规 | 到「设置与隐私 → 账号状态」查看记录并按指引申诉 |
| 粉丝已过 1000 仍看不到 | 有历史违规、账号被判定异常，或版本过旧 | 更新 App 后重启再试；仍无则在「报告问题」里反馈 |
| 别的账号有、自己没有 | 功能按地区与账号分批放开 | 属于地区差异，以自己账号内的实际显示为准 |

开播资格与账号绑定，与设备无关；重装 App、换手机都不会让门槛消失。账号本身的异常（收不到验证码、登录被拒）去 [注册与登录方法.md](注册与登录方法.md)，刷不出视频这类播放故障去 [常见问题与解决办法.md](常见问题与解决办法.md)。
