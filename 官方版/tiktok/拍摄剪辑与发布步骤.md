## 一、拍摄：分段拍是常用手法

点底部中间的「+」进入拍摄页：

1. 右侧选时长档位（15 秒 / 60 秒 / 10 分钟，实际档位随版本与地区有差异，以 App 内显示为准）。
2. 按住红色快门开始拍，**松手即暂停，再按住继续**——这就是分段拍摄，一段视频里可以换多个场景、多次起停。
3. 拍错的那一段在时间轴上选中后可以删掉，不用整条重来。
4. 不想现拍就点右侧「相册」，导入已拍好的视频或照片，同样能进后面的剪辑流程。

发布前的草稿都会留在拍摄页的「草稿」里，换机或卸载 App 前记得先发出去或导出，草稿不会跟着账号走。

## 二、剪辑与美化：常用的几样

录制完成后点「下一步」进入编辑页，常用工具就这几样：

| 工具 | 能做什么 | 用在什么时候 |
| --- | --- | --- |
| 裁剪 / 合并 | 删掉多余片段、调整各段顺序 | 分段拍完后整理节奏 |
| 文字 | 在画面上加字幕或说明，可设置出现时段 | 观众静音刷视频时也能看懂 |
| 贴纸 / 表情 | 加静态或动态贴纸 | 标注重点、增加信息 |
| 滤镜 / 美颜 | 调色调、磨皮瘦脸 | 人像内容常用 |
| 特效 | 转场、分屏、AR 道具等 | 开头几秒抓注意力 |
| 变声 / 语音效果 | 把原声改成不同音色 | 不想露声或搞笑向内容 |

配乐在编辑页顶部「添加声音」：可以从站内声音库挑热门音乐或原声。注意**部分歌曲只在特定地区可听可用**，你刷到的热门音乐在自己的账号里搜不到，多数是地区曲库差异，不是操作问题。

## 三、发布设置：这四项决定谁能看到

点「下一步」到发布页，逐项确认：

1. **文案与话题**：写一句说明，加 #话题标签能进对应话题页，被搜到的概率更高。
2. **封面**：从视频里选一帧做封面，或单独上传；封面决定主页列表里的观感。
3. **观看权限**：所有人 / 朋友 / 私密（仅自己）。想先存着不发就选私密，相当于存档。
4. **互动开关**：评论、合拍（Duet）、拼接（Stitch）都可以按条单独关掉，不想被二次创作就在发布前关。

确认后点「发布」。发布后在自己主页能看到这条视频的基础数据（播放、点赞、评论）；要更完整的观看分析，可把账号切换为商业账号（「设置与隐私 → 管理账号」里切换）。

## 四、合拍（Duet）与拼接（Stitch）

这两个都是「基于别人的视频做自己的视频」，区别在于形式：

- **合拍（Duet）**：你的画面与原视频左右分屏同框播放，适合跟拍、对口型、回应类内容。
- **拼接（Stitch）**：截取原视频的一段（最长几秒）放在你新拍内容的前面，适合接话、续拍、点评类内容。

用法：在你想互动的那条视频上点「分享」按钮，菜单里有「合拍」或「拼接」就说明作者开放了该权限；没有就代表对方关闭了。反过来，你自己在发布设置第三节里关掉这两项，别人就不能对你用同样操作。

发出去之后想改的内容只有文案与权限可以改，画面本身改不了，发布前把第三节的设置过一遍。视频之外想实时互动就是另一套流程了，见 [直播功能怎么用.md](直播功能怎么用.md)。

## 五、保存与导出：别把视频只留在账号里

- **发布前存相册**：编辑页点「下一步」之前，勾选「保存到设备」，成品视频（含你加的音乐与字幕）就进了手机相册，这一步不经过账号；
- **保存已发布的视频**：进自己主页点开那条视频 → 「更多 / 分享」→「保存至相册」。发布时没开「允许下载」也没关系，自己的视频随时可存；
- **不留水印的存法**：先把成品存成草稿 → 用私密（仅自己）权限发布 → 从私密视频里保存至相册，得到的文件不带站内水印；存完再把这条私密视频删掉即可；
- **草稿只在本机**：草稿不进云端，卸载 App、换机、注销账号都会带走它们（详见 [注销账号与恢复规则.md](注销账号与恢复规则.md)），想长期保留一律先按上面的办法进相册；
- **保存别人的视频**：取决于对方的下载开关——分享菜单里有「保存视频」就能存，没有就是作者关了下载权限，录屏替代（内容被二次使用时注意原作者的权益与平台规则）。
