## 一、视频刷不出来或加载慢

按顺序试：

1. 先确认网络本身可用（开个网页试试）。刷视频对带宽要求不高，看高清才吃带宽。
2. 查「省流量模式」：App 内「设置与隐私 → 流量使用（Data Saver）」，开着时视频清晰度会下降，弱网下反而更容易卡在加载，先关掉试。
3. 清缓存：「设置与隐私 → 清除缓存」。缓存清掉后首屏会重新拉数据，稍慢属正常。
4. 还是不行就退出账号重登，或把 App 彻底从后台划掉重开。刷不出内容同时伴随「无法刷新、一直转圈」且换网络也没用，结合所在地区是否在服务受限名单里判断，见第五节。

## 二、通知收不到

1. 系统层面先开：手机「设置 → 应用 → TikTok → 通知」，确认总开关与各类别（点赞、评论、粉丝、私信）都开着。
2. 国产 ROM（小米、华为、OPPO、vivo 等）还要给 TikTok「后台自启动」与「无限制后台」权限，否则进程被杀，通知必然收不到。
3. App 内再确认：「设置与隐私 → 通知」，里面按互动类型逐类开关。
4. 只有个别通知收不到：多为对方删了内容或账号被私了，不是故障。

## 三、存储被吃满：缓存与安装包都算

| 占用项 | 大概量级 | 处理 |
| --- | --- | --- |
| 安装包本体 | 约 305 MB（本文对应这份为 304.75 MB） | 装完就没了，不重复占 |
| 视频缓存 | 随使用增长，轻松到 1~2 GB | 「设置与隐私 → 清除缓存」，随时可清，不影响账号 |
| 下载与草稿 | 按你保存的内容计 | 已发布的视频可随时重下，草稿是唯一不留在服务器上的，换机前先处理 |

长期使用的机型定期清缓存即可；缓存只影响重新加载速度，清掉没有副作用。

## 四、闪退与卡顿

- **重启手机**：解决大多数临时性闪退。
- **低端机卡顿**：视频流应用对老设备压力大，滑动掉帧、发热明显属于正常范围；把「设置与隐私 → 流量使用」里的画质相关选项调低能缓解一部分。
- **持续闪退**：清缓存 → 确认系统 WebView 与系统更新 → 覆盖安装一遍安装包（同包名直接装，账号数据不丢，本地草稿除外）。都无效说明这台设备跑不动当前版本。
- **安装环节的失败**（解析错误、不兼容提示）在 [下载与安装教程.md](下载与安装教程.md) 第四节有专门的对照表。

## 五、账号与地区限制类现象

这几类现象不是 App 坏了，逐条对号：

| 现象 | 性质 | 能做什么 |
| --- | --- | --- |
| 商店搜不到、安装包能装但注册不了 | 地区不可用 | 无解，取决于所在地区服务状态，以官方页面为准 |
| 能看视频但发不了、播不了 | 地区功能受限 | 同上；功能范围以账号内实际显示为准 |
| 提示「账号被停用」或内容被移除 | 违规处理 | 「设置与隐私 → 报告问题」按流程申诉，结果以平台审核为准 |
| 密码突然失效、被陌生设备挤下线 | 疑似被盗 | 按 [账号被盗与找回.md](账号被盗与找回.md) 的场景逐条处理 |
| 主页暂时消失、别人搜不到自己 | 可能误触了停用 | 登录即可恢复；确认要删号的看 [注销账号与恢复规则.md](注销账号与恢复规则.md) |
| 直播按钮消失 | 资格或违规问题 | 对照 [直播功能怎么用.md](直播功能怎么用.md) 第五节 |
| 收不到验证码、登录被拒 | 账号与联系方式问题 | 见 [注册与登录方法.md](注册与登录方法.md) 第四节 |

判断一条问题属不属于「地区限制」的简单办法：换一个网络环境（比如换成另一个运营商）现象完全不变，且身边同地区用户同样如此，基本就是地区口径；现象随网络变化则更可能是网络与设置问题，回到第一、二节排查。
