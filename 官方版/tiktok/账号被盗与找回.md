## 一、先确认是不是真被盗

这些信号出现任意一条就要警惕：

- 收到「密码 / 邮箱 / 手机号已更改」的通知邮件，但不是你操作的；
- 突然被挤下线，原密码失效；
- 朋友说你的账号在发奇怪的消息或视频；
- 主页简介、头像、用户名被改过，或登录提醒里出现陌生设备与地区；
- 「喜欢」列表里出现你没点过赞的视频。

有确认迹象后动作要快：拖得越久，对方改掉绑定邮箱与手机号、把账号彻底锁死的概率越大。整个处理过程只在**你自己用过的设备与网络**上操作，别借别人的手机——常用设备是找回时最有力的凭证之一。另外一条底线：**验证码、密码永远不给任何人**，自称「官方客服」来要验证码的全是骗子。

## 二、还登得进去：按这个顺序抢回控制权

1. 「个人资料 → 菜单 → 设置与隐私 → 安全与权限」，改密码为一条从未用过的新密码；
2. 同一处的**设备管理**里，把不认识的登录设备全部踢下线；
3. 核对绑定的邮箱与手机号是不是你自己的——盗号者常悄悄加上自己的，方便日后「找回」；
4. 检查已授权的第三方应用，逐个撤销可疑授权；
5. 检查主页与私信：删掉对方发过的内容（简介里被塞的链接是典型痕迹），并通知朋友别理会账号发出的借钱、转账类消息。

绑定的邮箱如果和 TikTok 用的是同一个密码，邮箱密码也要立刻改掉——邮箱才是所有账号的总钥匙。

## 三、被改了密码但邮箱手机号还在：走正常重置

登录页点「忘记密码」，用还在你手里的邮箱或手机号收验证码重置。重置成功后立刻回到第二节，把设备、授权、两步验证全部过一遍。

## 四、邮箱手机号都被改了：走「账号被盗」身份申诉

这是最糟也最常见的情形，正常重置已经走不通。路径是：

1. 登录页选「忘记密码」，在重置选项里选「以上都不是 / 报告问题」类入口，选 **「我的账号被盗（My account was hacked）」**；
2. 按提示提交身份材料，通常包括：政府签发的带照片证件、原始绑定邮箱或手机号、账号注册的大致时间、以往发布内容或消费记录（金币充值凭证也算）等截图证据；
3. 提交后等审核，常见回复周期为几天到几周不等，期间按页面提示补充材料即可。

这条申诉流程的原理是**绕开盗号者加上的验证方式**，改用证件与真人视频自拍核验身份，所以对方设置的两步验证拦不住你。另外两个实用细节：

- 邮箱被改时，TikTok 会往**旧邮箱**发一封安全通知，里面常有「撤销此次更改」的限时链接，点它是最快的回头路；
- 申诉用的「注册设备指纹」这类凭证大约 90 天未活动会失效，所以**尽早提交**比什么都重要。

申诉期间的官方入口是帮助中心的「我的账号被盗」专页（`support.tiktok.com` 下的 log-in-troubleshoot 分栏）；没有客服电话，所有冒充客服来电都可判为诈骗。付费「代找回」服务一律不要碰。

## 五、两步验证：现在就去开

「设置与隐私 → 安全与权限 → 两步验证」，三种方式（手机短信、邮箱、验证器应用）**至少选两种**：

| 方式 | 特点 |
| --- | --- |
| 手机短信 | 最方便，但换机丢号时麻烦，且存在补卡劫持风险 |
| 邮箱 | 与账号找回绑定最深，务必保证邮箱本身也开了两步验证 |
| 验证器应用（Google/Microsoft Authenticator 等） | 最稳的一种；绑定时会展示二维码，**离线备份码要单独存好**，换手机就靠它 |

账号找回后第一件事就是补上这一步；备份码丢了、验证器换机丢了也不用慌，走第四节的身份申诉路一样能回来，只是慢。更省心的做法是防患于未然——注册完成当天就按 [注册与登录方法.md](注册与登录方法.md) 把安全设置过一遍；不想用了要退场，则看 [注销账号与恢复规则.md](注销账号与恢复规则.md)，别把「被盗后弃号」和「主动注销」混为一谈。
