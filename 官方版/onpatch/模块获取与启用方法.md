# ONPatch 的模块从哪来、怎么启用

> ONPatch 本身只是个框架，真正提供功能的是 Xposed 模块。本篇讲模块去哪找、怎么装、装完怎么让它对目标应用生效。

## 一、模块是普通 APK，来源就两类

Xposed 模块本质上是一个普通安卓应用，安装方式和日常装 APK 没区别。常见的获取渠道有两类：

1. **模块仓库**：例如 [https://modules.lsposed.org/](https://modules.lsposed.org/)，按功能分类收录了上千个模块，每个模块都给出源码仓库链接，更新记录一目了然；
2. **开发者的 GitHub 发布页**：不少模块只在 GitHub Releases 发包，从模块仓库页面点进去就能找到。

挑模块时建议优先看三样东西：是否开源（有源码仓库）、最近是否还在更新、评论区或 issue 区有没有人说在新系统上能用。模块是第三方写的，质量参差，装之前多看一眼能省掉后面很多排错时间。

## 二、把模块装进手机

模块 APK 直接安装即可。装好后打开 ONPatch，在模块列表里应该能看到它；如果列表里没有，重启一次 ONPatch 或手机通常就能刷出来。

有的模块自身还带设置界面，功能开关在模块自己的应用里调，不在 ONPatch 里调——ONPatch 负责的是「让模块生效」，模块功能怎么配置要看模块自己。

## 三、启用与作用域

模块装好后按你选择的修补模式走两条不同的路：

- **本地修补**：在 ONPatch 的模块管理里启用模块，再勾选它的作用域（即对哪些应用生效），目标应用重新打开后生效。后续模块出新版本，直接更新模块 APK 即可，不用重新修补目标应用——这正是本地模式最大的便利；
- **集成修补**：模块是在修补时打包进目标应用的，换模块或更新模块都要用新配置重新修补一次，流程见[模块注入与修补模式详解](模块注入与修补模式详解.md)。

作用域宁少勿多：只勾你确实需要的应用。勾得越多，和应用本身功能冲突的概率越大。

## 四、几个容易踩的点

- **模块和目标应用都要是最新匹配的版本**：目标应用大版本更新后，原本正常的模块可能失效，去模块的发布页看看有没有跟进更新；
- **一次只开一个新模块**：同时启用多个模块再出问题，你分不清是谁的锅；
- **模块不生效先重启应用**：模块逻辑通常在应用启动时加载，改完配置要彻底退出目标应用再打开，个别情况要重启手机；
- **个别模块天生不适配免 Root 环境**：有些模块依赖 Root 框架才有的能力，在 ONPatch 这类免 Root 方案里就是跑不起来，这不是你操作的问题，换模块即可。
