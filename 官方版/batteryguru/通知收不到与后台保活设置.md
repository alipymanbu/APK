## 一、为什么先查后台

Battery Guru 的核心显示（状态栏指示器、常驻通知、温度警报）都依赖**一条活着的后台服务**。而现在主流国产安卓系统（HyperOS、ColorOS、OriginOS、MagicOS 等）默认的后台管理比原生安卓激进得多：自启动被拦、后台活动被清、省电优化把应用冻住 —— 华为官方支持文档里甚至专门有一篇「应用无法后台运行怎么办」的排查清单，说明这是普遍现象而不是个例。

所以排查顺序是**先保活、再查权限**；后台活着，通知权限那些才有意义。

## 二、先做这三件通用的事

不管什么品牌，先把这三步做完，能解决大多数情况：

1. **电池优化里放行**：把 Battery Guru 从「被优化」改成「不优化 / 允许后台运行」。
2. **自启动 / 启动管理里放开**：允许它自启动、允许后台活动（有的系统叫「允许关联启动」）。
3. **最近任务里给它加锁**：打开应用后进多任务界面，下拉或长按它的卡片点「锁定」—— 锁定后清理后台不会把它杀掉。

测试期间顺手**关掉省电模式（低电量模式）**，它会额外拦截后台与通知；确认正常后再按需打开。

## 三、分品牌的具体路径

设置里的**搜索框**是最稳的入口 —— 各机型菜单名有出入，直接搜关键词即可。下表路径按各品牌公开支持文档整理，以你机上实际显示为准：

| 品牌 | 自启动 / 后台活动 | 电池限制 | 后台加锁 |
| --- | --- | --- | --- |
| 华为 / 荣耀 | 设置里搜「应用启动管理」→ 关闭该应用的自动管理 → 勾选允许后台活动 | 设置里搜「电池优化」→ 选「不允许」→ 找到该应用 | 多任务界面对卡片下拉加锁 |
| 小米 / 红米 | 设置里搜「自启动」→ 打开 | 设置 → 电池 → 右上角设置图标 → 应用电池节省 → 选「无限制」 | 多任务长按卡片 → 加锁 |
| OPPO / 一加 | 设置 → 应用管理 → 自启动管理 → 允许 | 设置 → 电池 → 电池优化 → 对它选「不优化」；应用信息里开「允许后台活动」 | 多任务界面对卡片点「锁定」 |
| vivo / iQOO | 设置里搜「自启动」→ 打开 | 设置 → 电池 → 后台耗电管理 → 对它选「允许 / 高后台耗电」 | 多任务界面对卡片点「锁定」 |
| 三星 | 智能管理器 → 应用管理 → 允许自动运行 | 应用信息 → 电池 → 选「不受限制」；并关掉「自适应电池」 | 多任务界面对卡片点「锁定」 |

华为机型还有一项值得开：**设置 → 电池 → 更多电池设置 → 休眠时始终保持网络连接**，熄屏后数据不断，实时数据才接得上。

## 四、改完怎么验证

1. 从最近任务里划掉 Battery Guru，重新打开 —— 看状态栏指示器是否立刻恢复刷新。
2. 插上充电器，看常驻通知里的电流数值是否跟着变化。
3. 做一次警报测试：进「保护」区域，把**充电限制提醒的阈值临时调到略高于当前电量**，继续充电到超过该值，看通知是否弹出；弹完把阈值改回你真正想要的值。
4. 三项都通过，说明保活配置到位；任何一项不过，回到第三节核对对应品牌的开关。

## 五、还不行的两条

- **第三方清理 / 管家类应用**也会强制清后台 —— 华为官方文档明确点名了这类软件。装有清理大师、加速类工具的，先卸载或把 Battery Guru 加进它们的白名单，再观察一天。
- **省电模式没关干净**：部分系统的「省电模式 / 超级省电」会绕过单应用设置继续拦截。测试时全关，日常使用时至少保证它不在「超级省电」下运行。

排查仍无进展的其余可能（通知权限本身没给、阈值设错），见 [常见问题排查.md](常见问题排查.md)；指示器显示哪些内容，见 [状态栏指示器与省电设置.md](状态栏指示器与省电设置.md)。
