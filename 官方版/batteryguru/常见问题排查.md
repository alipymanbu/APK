## 一、同名应用太多，怎么确认装的是这一个

「batteryguru」在搜索结果里至少有两拨，包名不同、来源不同：

| | 本篇讲的这个 | 另一个同名应用 |
| --- | --- | --- |
| 包名 | `com.jingtanhao.battery` | `com.paget96.batteryguru` |
| 开发者 | 苏州惊叹号科技有限公司 | Paget96 |
| 界面 | 简体中文 | 多语言 |
| 官方入口 | —— | Google Play 与 [paget96projects.com](https://paget96projects.com/applications/batteryguru) |

核对方法：**设置 → 应用 → 应用信息**，打开对应条目看包名，认准 `com.jingtanhao.battery`。各软件站页面上两拨应用经常共用「BatteryGuru」这个标题，只看名字区分不出来。本套文档写的安装包在 [下载与安装教程.md](下载与安装教程.md) 里，认那个包名就不会装错。

## 二、状态栏指示器 / 常驻通知不显示

1. **通知权限没给** —— 最常见的原因。去 **设置 → 应用 → Battery Guru → 通知**打开总开关；首次启动跳过了权限页的，回这里补。
2. **通知被系统折叠或静音**：在通知设置里把该应用的通知类别全部放开，别设成「静默」。
3. **系统省电策略冻结了它**：这是国产系统最常见的原因，按品牌把自启动、电池优化、后台加锁配好 —— 完整路径见 [通知收不到与后台保活设置.md](通知收不到与后台保活设置.md)。
4. 修好权限后仍不出现的，重启一次手机让通知渠道重建。

## 三、温度警报 / 充满提醒不响

按顺序查，前三条覆盖绝大多数情况：

1. 通知权限是否已开（同上）。
2. 「保护」区域里对应开关是否打开、阈值是否合理 —— 阈值设得太极端，正常充电根本碰不到。
3. 手机是否处于勿扰模式，勿扰会压掉通知。
4. 都对还不响，记录一次复现场景（充到多少度 / 多少电量时没响）再看是否是版本问题。

详细设置步骤见 [充电温度警报怎么设置.md](充电温度警报怎么设置.md)。

## 四、健康度 / 预估容量数字看着离谱

- **刚装好就显示特别高或特别低**：先核对**设计容量**读数对不对，不对就在配置页手动改成电池标称容量，健康百分比会跟着修正。
- **数字前后波动**：预估容量基于充电阶段估算，波动正常 —— 读法见 [怎么看电池健康.md](怎么看电池健康.md) 第三节。
- **同一个应用换个手机量出不同值**：两块电池本来就不一样，不是装错了包（前提是包名仍是 `com.jingtanhao.battery`）。
- **换完电池数据还是旧的**：估算基线没跟上，重新走 2~3 次完整充放电循环即可，详见 [怎么看电池健康.md](怎么看电池健康.md) 第五节。

## 五、装不上 / 装完闪退

1. **系统版本不够**：要求安卓 5.2 以上，低于它无法安装。
2. **没给安装权限**：弹「禁止安装来自此来源的应用」时，去 **设置 → 应用 → 特殊应用权限 → 安装未知应用** 给下载用的 App 开开关，步骤见 [下载与安装教程.md](下载与安装教程.md) 第三节。
3. **包不完整**：核对 MD5 与下载页给的值不一致就是文件坏了，重新下一次。
4. **装完打不开**：先重启再试；仍闪退时确认机型是否为安卓 5.2 以上，并用网盘里那份已核对过的包重装（不要混用别处下载的同名包）。

## 六、引导没走完 / 卡在某一步

- 每一步底部都有**「返回」**，可以退回上一步重新操作。
- 权限页漏授权的，除系统设置里补授权外，也可以在应用内权限页重新授予。
- 「配置」那一步读不到容量时，稍等片刻重试；确实读不准就手动填设计容量（配置页支持手动更正）。

## 七、电量百分比乱跳 / 充得离谱地快

百分比突然从 30% 跳到 10%、或几分钟就「充满」，多半是系统的电量计和电池实际状态对不上了，不一定是应用读错。realme 官方支持页给的标准处置：

1. **先重启**：临时的显示异常重启就能刷新电量监测逻辑。
2. **再校准电量计**：把手机用到自动关机 → 关机状态下连续充到 100% → 开机。让系统重新学习这块电池的实际容量。
3. **注意环境温度**：过冷过热时电压会波动、读数失真，在 15~35°C 的常温环境里充电再看。
4. **排除电池本身**：用了几年的手机，充得快、掉得也快是老化的典型表现，处理办法见 [怎么看电池健康.md](怎么看电池健康.md) 第八节。

系统侧校准完，应用侧的估算再等 2~3 次完整充放电循环收敛（见 [怎么看电池健康.md](怎么看电池健康.md) 第五节）；两个数字仍对不上的，回头检查配置页的设计容量。
