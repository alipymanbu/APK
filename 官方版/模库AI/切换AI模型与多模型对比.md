## 一、先搞清楚：模型在哪切

模库AI 的核心玩法是「一个界面，多家模型」。你在对话页顶栏能看到当前模型的名字（比如 `DeepSeek R1`），点它就展开模型列表，挑一个立刻生效，不用退出重进。切换只影响**之后**发出的消息——已经生成的回答不会重新用新模型算一遍。

## 二、切换模型的完整步骤

1. 打开模库AI，进入对话界面。
2. 看顶栏中间偏左的位置，那里显示着当前模型名，右侧带一个下拉小箭头。
3. 点模型名，弹出模型列表。
4. 点选你要的模型，顶栏名字随之变化，直接输入问题开始聊。

入口位置会随版本调整——iOS 版官方更新日志就提到过「首页全新改版，热门 AI 工具、AI 视频和 AI 生图更清晰易找」，说明不同版本的首页布局确有变动；如果你的版本把入口放在侧边栏设置里，以实际界面为准。

## 三、已接入哪些模型

按官方介绍与商店页的说明，已接入的模型包括：DeepSeek、豆包、千问（通义千问）、文心一言、Kimi、智谱清言、即梦。对话界面里能直接选到 DeepSeek R1 这类推理型号。

各模型的脾气不一样，选的时候可以按这个思路：

| 你手头的事 | 优先试 |
| --- | --- |
| 复杂推理、数学、代码逻辑 | DeepSeek R1 这类带「深度思考」的型号 |
| 日常问答、生活咨询、语气自然的对话 | 豆包、Kimi |
| 资料整合、中文写作 | 千问、文心一言、智谱清言 |
| 出图 | 即梦等生图模型 |

模型列表会随版本增减，看到的与这里不完全一致属正常。

## 四、多模型对比：一次提问，多家同答

多模型对比的用法是：同一个问题发出去，多个模型**同屏**各自输出，你横向对比谁答得更好——思路差异、文风好坏、响应快慢一目了然。写重要文案、挑模型时尤其有用：与其猜哪个模型强，不如让它们当场各写一版。

使用节奏大致是：发起对比 → 看各家输出 → 记住表现好的那个模型 → 回到单模型模式继续深入。厂商官网对该功能的描述是「多模型同屏输出，智能选优」，并会按场景推荐模型组合。

## 五、联网搜索与引用来源

开着联网能力时，回答会附引用来源——界面上能看到「引用 N 篇资料作为参考」这样的入口，点进去可查看出处。查时效性强的问题（新闻、价格、版本更新）建议开联网；纯粹聊思路、要创意文案，反而不受时效拖累。

配合 [AI写作与翻译教程.md](AI写作与翻译教程.md) 里的场景用法，你可以先用联网模型查资料，再换写作向模型成文。

## 六、切换没生效 / 模型不见了

- 顶栏名字没变：先确认点的是模型名本身而不是旁边的箭头图标，选完再发一条消息验证。
- 列表里少了某个模型：模型上下架随版本调整，以当前界面为准。
- 换了模型后回答风格没变：换个更明显的问题测一测；仍异常就按 [常见问题与故障排查.md](常见问题与故障排查.md) 排查网络。
