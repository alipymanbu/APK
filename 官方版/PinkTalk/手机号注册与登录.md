## 一、登录方式只有一种：手机号 + 验证码

PinkTalk 没有密码登录，也不接微信/QQ 一键登录（至少当前安卓版如此）。你装好应用、同意隐私协议后落在登录页，流程是：

1. 输入你常用的手机号；
2. 点「获取验证码」，等短信；
3. 把收到的数字填进验证码框；
4. 点确认登录，进主界面。

新用户走完这四步就算注册完成，没有单独的"注册"按钮——验证码通过即开户。

## 二、第一次进去先做两件事

- **允许必要的权限**：通知权限影响"角色主动发动态/消息"的提醒；存储权限在保存图片/语音时会用到。拒绝也能用，只是提醒会静默。
- **看一眼未成年人模式提示**：应用会弹年龄相关的提示与青少年模式入口。按你实际情况选择；这个选择会影响你能看到的角色范围（背景见 [常见问题与故障排查.md](常见问题与故障排查.md)）。

## 三、收不到验证码怎么办

按命中率从高到低排查：

| 现象 | 处理 |
| --- | --- |
| 短信被拦截 | 查手机的短信拦截/骚扰过滤列表，验证码常被当成广告拦掉 |
| 刚点过又点 | 验证码有发送间隔，等倒计时结束再重新获取 |
| 网络问题 | 切换 Wi-Fi / 流量后重试（验证码请求走网络，不是短信通道问题） |
| 号码填错 | 回上一步核对手机号，错一位就永远收不到 |
| 归属地/运营商异常 | 换一个手机号试；个别虚拟号段收不到平台短信 |

等了两三轮仍收不到，先别死磕——隔几分钟再试，或换网络环境。

## 四、换手机、重装之后记录还在吗

登录的是同一个手机号，账号下的聊天记录会跟着账号走，正常登录后能续上。但**卸载重装有风险**：本地缓存被清掉后，若云端没来得及同步，部分早期对话可能找不回来。结论：别随手卸载；真要换机，先在旧机上确认记录还在、登录正常，再在新机用同一手机号登录。

## 五、一个手机号就是一个身份

邀请奖励、心动值排行都挂在账号上（规则见 [邀请好友奖励规则.md](邀请好友奖励规则.md)）。同一手机号反复注册不算新用户，别指望换号刷奖励。
