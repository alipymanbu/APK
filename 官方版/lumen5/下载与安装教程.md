lumen5 是一款安卓端的 AI 视频制作应用，你在应用商店能查到的上架名是「lumen5视频制作」，开发者是深圳市顺林祥科技有限公司。你输入文字描述想要的画面与动作，就能得到一段对应的视频，也可以挑现成模板点「剪同款」改成自己的作品。本篇覆盖从获取安装文件到完成安装的全过程；这里的安装包是 1.0 版，约 79.36M。

## 一、动手前先确认三件事

| 确认项 | 说明 |
| --- | --- |
| 设备 | 这是一份安卓安装包（APK），装在安卓手机上用，电脑上无法直接运行 |
| 空间 | 安装包约 79.36M，建议手机剩余空间留出它的两倍以上，避免装到一半失败 |
| 同名产品 | 它与 `lumen5.com` 上的在线工具不是同一款产品：后者是海外 Lumen5 团队做的网页应用，在浏览器里使用；而这个安装包的包名是 `com.crlyechuhong.spzu`，在腾讯应用宝能查到包名一致的上架记录。先想清楚你要的是手机应用还是网页工具，再决定装不装 |

## 二、获取安装文件

安装文件放在夸克网盘里，全程三步：转存、下载、核对。

1. 打开 [lumen5 安装文件资源（夸克网盘）](https://pan.quark.cn/s/60992cfb138f)；
2. 登录夸克账号，选「保存到我的网盘」把它转存到自己名下，再从自己网盘里下载其中的 APK 文件；
3. 下载完成后核对一下文件：大小约 79.36M，MD5 为 `B95497C5D1B02C70C624237249A6CB8B`。大小明显偏小说明没下完整，重新下载即可。

## 三、安装步骤

1. 在手机上点开刚下载的 APK 文件；
2. 系统弹出「未知来源 / 允许安装未知应用」提示时，允许本次安装——这是安装非应用商店来源应用时的正常提示，装完也可以在设置里把这个授权关掉；
3. 等待安装完成，点「打开」进入应用。

部分手机的安全软件会在安装前额外扫描一遍，确认通过后放行即可。

## 四、装不上时的快速排查

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包错误 / 无法解析」 | 安装包没下完整，或传输中被破坏 | 重新下载并核对大小与 MD5 |
| 安装到一半中断 | 存储空间不足 | 清出足够空间后重试 |
| 提示系统版本不兼容 | 手机的安卓版本低于应用要求 | 升级系统后重试；特别老的设备可能确实装不了 |
| 安全软件拦截并取消安装 | 安装来源不在白名单 | 在安全软件里允许本次安装；对来源没把握就不要强行放行 |

照着查完还是不行，把具体现象带到 [常见问题与排查.md](常见问题与排查.md) 里对号入座；装好了直接看 [使用方法与生成同款视频.md](使用方法与生成同款视频.md) 开始做第一条视频。
