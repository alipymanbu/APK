# lumen5 使用方法与生成同款视频

> 本篇讲 lumen5 装好后的基本用法：输入文字生成视频、用模板剪同款，以及保存导出时要注意的地方。还没安装的先看 [下载与安装教程.md](下载与安装教程.md)；用的时候碰到问题去 [常见问题与排查.md](常见问题与排查.md)；想先弄清它和网页版工具的差别，看 [与网页版的区别.md](与网页版的区别.md)。

lumen5 的界面是全中文的，打开就能看懂：一条路是你自己写描述、让 AI 生成视频；另一条路是浏览模板、点「剪同款」，把别人的成品换成你的素材。本篇把这两条路径的步骤和注意点讲清楚。以下基于 1.0 版整理，具体按钮位置以你手机上的实际界面为准。

## 一、首次打开

- 界面语言是中文，主要功能入口打开应用就能看到；
- 首次启动可能弹出权限申请（如存储、照片权限），这与你后面要导入的素材有关，按需允许即可；拒绝之后要导入本地图片时再补授权也行；
- 建议先空手把模板区翻一遍，看看有没有和你想要的风格接近的成品，有就直接走「剪同款」，比从零写描述快。

## 二、路径一：输入文字生成视频

1. 在打开后的界面里找到文字生成视频的入口；
2. 输入你想要的视频内容——把画面、主体、动作写清楚，比如「一只橘猫在窗台上伸懒腰，阳光从侧面照进来」；
3. 提交后等它生成，期间不要杀掉应用或断网，生成耗时与网络状况、内容复杂度有关；
4. 生成完成后先预览，满意再保存。

描述写得越具体，结果越接近预期——主体是谁、在什么场景、做什么动作、什么氛围，都点到。写得太笼统（比如只给两个字「风景」），生成出来的东西随机性就大。这一条对这类文字生成视频的应用普遍适用。

## 三、路径二：模板与剪同款

1. 在模板区浏览成品视频，选一个和你要的内容同类型的；
2. 点「剪同款」，按引导把你自己的图片或文字素材替换进对应位置；
3. 确认后生成，得到一支与原模板同类型的视频。

剪同款省去自己构图的时间，适合赶时间发内容；素材被要求替换时，先想好每张图对应模板里的哪个画面，一次替换到位比反复改省事。

## 四、保存与导出

- 生成完成后在作品里保存或导出，成片一般会进手机相册或应用内的作品列表，以实际界面为准；
- 导出前留意相册（存储）权限是否已允许，否则可能出现「显示保存成功但相册里找不到」的情况；
- 想发到社交平台，先在手机本地看一遍成片再分享，避免把半成品发出去。

## 五、结果不满意怎么办

| 情况 | 调整方式 |
| --- | --- |
| 画面与预期差得远 | 把描述改得更具体，重新生成一次 |
| 风格不对 | 换一个模板再剪同款，或调整描述里的氛围词 |
| 多次生成都类似 | 换一批关键词（主体、动作、场景各换其一），避免描述高度重复 |

反复失败、生成卡住的排查方法在 [常见问题与排查.md](常见问题与排查.md) 的「生成相关」一节。
