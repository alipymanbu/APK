# lumen5 常见问题与排查

> 本篇汇总 lumen5 最常被问到的几件事：装不上、生成卡住、视频保存位置，以及它和 `lumen5.com` 同名网页工具的关系。安装步骤见 [下载与安装教程.md](下载与安装教程.md)，基本用法见 [使用方法与生成同款视频.md](使用方法与生成同款视频.md)。

使用 lumen5 时出问题的环节大多集中在安装和生成两处。本篇按环节列问题和处理办法，都是你自己动手就能操作的检查项；文中安装包信息以 1.0 版为准。

## 一、安装问题

| 问题 | 处理 |
| --- | --- |
| 解析包错误 | 多半是包没下完整：重新下载并核对大小约 79.36M、MD5 `B95497C5D1B02C70C624237249A6CB8B`；需要重取安装包时回到 [lumen5 安装文件资源（夸克网盘）](https://pan.quark.cn/s/60992cfb138f) |
| 提示系统版本不兼容 | 手机的安卓版本低于应用要求；能升级系统就升级后再装，特别老的设备只能换设备 |
| 安装中途停止 | 清出存储空间后重试 |
| 打不开 / 点图标没反应 | 重启手机再试一次；仍然如此说明设备兼容性不满足，换设备使用 |
| 安全软件报提示 | 来源可靠的安装包可在安全软件里放行；不确定来源的包不要强行放行 |

安装环节的完整步骤在 [下载与安装教程.md](下载与安装教程.md) 的第三、四节。

## 二、生成相关

- **生成卡在半截**：先确认网络可用，然后回到应用里重新发起一次；生成期间尽量别锁屏杀后台；
- **点生成没反应**：检查描述内容是否为空、网络是否可用；换一种说法再试；
- **生成失败提示**：稍等几分钟再重试，连续失败就换网络（比如从移动数据切到 Wi-Fi）；
- **结果与描述差太远**：把主体、动作、场景写具体，参考 [使用方法与生成同款视频.md](使用方法与生成同款视频.md) 第二节的写法。

## 三、做好的视频在哪里

成片一般落在两个位置之一：应用内的作品列表，或手机相册。找不到时按这个顺序查：

1. 回应用内看作品列表里有没有；
2. 打开手机相册（注意区分「相册」和「所有图片」两个视图）；
3. 都没有就检查应用是否被拒绝了存储/照片权限，补授权后重新导出一次。

具体保存路径以你设备上的实际表现为准，不同手机系统的相册归类不一样。

## 四、它和 `lumen5.com` 是什么关系

不是同一家，功能也不通用：`lumen5.com` 是海外 Lumen5 团队的在线网页工具，在浏览器里用；本文档讲的是安卓应用 lumen5（上架名「lumen5视频制作」，包名 `com.crlyechuhong.spzu`）。想在手机上离线做短视频，用安卓应用；想批量把长文章转成视频，网页工具更对路。两款产品的完整对比与怎么选，见 [与网页版的区别.md](与网页版的区别.md)。

## 五、版本信息

- 网盘里的安装包是 1.0 版，约 79.36M；
- 应用后续出新版本后，个别界面入口可能与本套文档的描述略有出入，以你手机上的实际界面为准；
- 想确认手里的包是不是这一版，核对包名 `com.crlyechuhong.spzu` 与 MD5 `B95497C5D1B02C70C624237249A6CB8B` 即可。
