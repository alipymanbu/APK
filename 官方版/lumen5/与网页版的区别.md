# lumen5 与网页版工具的区别

> 搜 lumen5 时你常会同时看到两样东西：一款安卓应用，和 `lumen5.com` 上的网页工具。本篇讲清两者的差别、各自适合谁，帮你确认要的是哪一个。安装步骤见 [下载与安装教程.md](下载与安装教程.md)，基本用法见 [使用方法与生成同款视频.md](使用方法与生成同款视频.md)，装完出问题看 [常见问题与排查.md](常见问题与排查.md)。

lumen5（安卓应用，上架名「lumen5视频制作」）和 `lumen5.com`（海外 Lumen5 团队的在线视频工具）不是同一款产品，只是名字撞在一起。一个装在安卓手机上离线用、界面全中文；另一个开浏览器用、面向把文章批量转成视频的团队。本篇给你一套两分钟就能做完的分辨方法，免得装错或注册错。

## 一、先分清你要的是哪一个

问自己两个问题就能定：

1. **你打算在哪用？** 手机上随手做一条短视频 → 安卓应用；电脑浏览器里批量把文章转视频 → 网页工具；
2. **你手里已经拿到的是哪个？** 是一个 APK 安装包 → 安卓应用；是要注册账号的网址 → 网页工具。

## 二、两款产品对比

| 对比项 | 这个安卓安装包 | `lumen5.com` 网页工具 |
| --- | --- | --- |
| 形态 | 安卓手机应用（APK） | 浏览器里用的在线服务 |
| 开发者 | 深圳市顺林祥科技有限公司（包名 `com.crlyechuhong.spzu`） | `lumen5.com` 的运营团队 |
| 界面语言 | 全中文 | 英文为主 |
| 典型用法 | 输入文字生成视频、模板剪同款，做完存进手机相册 | 把博客、文章、脚本文案转成视频，适合批量生产 |
| 素材 | 应用内自带模板与素材区 | 内置大量图库、视频片段与音乐（以官网当时说明为准） |
| 收费 | 网盘里的安装文件资源直接获取使用 | 有免费档（导出带官方标识、有条数与清晰度限制），付费档以官网当时显示为准 |
| 网络要求 | 生成时需要联网，成片保存在本机 | 全程在线使用 |

付费与限制类信息会随时间变化，下结论前以 `lumen5.com` 官网当时显示为准。

## 三、怎么选

- **想在手机上做、做完就发**：选安卓应用。安装包从 [lumen5 安装文件资源（夸克网盘）](https://pan.quark.cn/s/60992cfb138f) 获取，装完即用；
- **要批量把长文章转成视频、讲究品牌统一**：网页工具更对路，直接访问官网注册；
- **两个都想要**：不冲突，它们互不干扰，账号也不通用，各用各的。

## 四、容易混淆的几个场景

- **在应用商店搜「lumen5」**：可能同时出现安卓应用与海外相关产品的上架记录，认包名 `com.crlyechuhong.spzu` 和开发者「深圳市顺林祥科技有限公司」就能锁定本文讲的这个；
- **搜索引擎混排结果**：`lumen5.com` 的教程、评测和这款安卓应用的内容会混在一起出现，看清楚讲的是网页工具还是手机应用再照着操作；
- **别人给你一个安装包**：不确定是不是本文说的这个时，核对包名与 MD5（见 [下载与安装教程.md](下载与安装教程.md) 第二节的核对方法），对不上就不要装。
