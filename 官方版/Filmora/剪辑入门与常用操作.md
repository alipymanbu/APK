## 一、新建项目：先选对比例

打开应用 → 「新建项目」→ 从相册多选视频或照片 → 进入编辑器。开工前先想好发到哪个平台，因为比例决定画幅：

| 比例 | 适合发到哪 |
| --- | --- |
| 9:16 竖屏 | 抖音、快手、Reels、Shorts |
| 16:9 横屏 | B 站、YouTube、电脑播放 |
| 1:1 方形 | 部分信息流、图文号封面 |

比例在项目里也可以改，但改完素材要重新裁切构图，先定比例再开工省事得多。

## 二、时间轴上的高频操作

选中一段素材后，底部工具栏会切出对应操作，最常用的就这几个：

- **分割**：拖动播放头到要剪断的位置，点「分割」，再选中不要的那段点删除；
- **变速**：常规变速直接改倍数，曲线变速可以预设快慢起伏（官方教程里叫 Normal / Curve speed）；
- **倒放、旋转/镜像**：都在片段工具里，做回放效果或纠正竖拍横拍用；
- **音量**：视频原声可以单独调小或静音，留出背景音乐的位置；
- **复制**：同一段素材要用两次时直接复制，不用回相册再选。

剪辑时双指捏合可以缩放时间轴，把刻度放大后分割点能对得更准——细剪片段时这个动作几乎每一步都用得上。

## 三、文字、音乐与字幕

- **文字**：内置文字模板可以改字体、颜色、样式和动画，点住文字块拖动就能调整出现的时长；
- **音乐**：曲库直接选，或从手机里的视频提取音轨；选完把音轨铺在视频下方，调低原声、调高配乐；
- **字幕**：新一点的版本带 AI 字幕（自动把人声转成字幕，支持 20 种以上语言和双语显示），入口一般在文字工具里，生成后逐句核对错别字再定稿；
- **配乐卡点**：AI Beats 能按视频情绪匹配节奏点，卡点视频不用自己一格一格对。

曲库和素材按是否带 Pro 标记区分，带 Pro 的要付费版才能用，标了什么能不能用一目了然，见[免费版与付费版区别](免费版与付费版区别.md)。

## 四、进阶工具速览

这些不是每个项目都用，但知道在哪能省很多事：

| 工具 | 干什么用 | 什么时候用 |
| --- | --- | --- |
| 关键帧 | 手动做位置/大小/透明度的渐变 | 自己做推拉、飘字动画 |
| 运动跟踪 | 让贴纸/文字跟着画面里的移动物体走 | 给奔跑的人、车辆贴标签 |
| 绿幕/色度键 | 抠掉纯色背景换别的画面 | 有绿幕素材、换背景 |
| 智能抠像 | 不用绿幕也能抠人物/物体 | 手拍素材去背景 |
| 防抖 | 平抑抖动的画面 | 边走边拍的素材 |
| 调色 | 亮度、对比、色调校正 | 光线不好、想统一多段素材的色调 |
| 模板 | 套现成的成片框架，替换素材即可 | 赶时间、不知道怎么编排 |

具体入口的位置随版本略有变化，以你手上那个版本的应用内菜单为准。素材库里的模板官方列了 500 多个，按主题分类，选一个把自己的视频照片替换进去就能出片。
