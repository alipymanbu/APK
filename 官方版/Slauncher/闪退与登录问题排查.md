# Slauncher 闪退与登录问题排查

> 本篇汇总 Slauncher 打不开、闪退、登录不上、启动白屏这几类问题的排查顺序，按从轻到重一步一步做。

## 一、打开就闪退或没反应

按顺序做，做完一步试一步：

1. **重启应用**：把 Slauncher 从后台彻底划掉再打开；不行就重启手机；
2. **清缓存**：手机「设置 → 应用管理 → Slauncher → 存储」里点「清除缓存」，这一步不动你的存档和已导入的资源；
3. **查权限**：在同一页面确认存储权限是开启状态，权限被关会让启动器读不到版本文件；
4. **换新版本安装包**：多个介绍页都把「更新到最新版」列为闪退的常规解法，旧版在部分机型上存在兼容问题——重装前先备份存档；
5. **释放内存**：关掉后台其他大应用再试。

「清除数据」能处理更顽固的情况，但它会清空应用本地数据（包括导入记录），只在前几步都无效、且存档已备份时再用。

## 二、登录不上

登录失败基本就两个方向，介绍页给的解答也是这两条：

| 方向 | 排查动作 |
| --- | --- |
| 账号本身 | 确认用的是微软/Xbox 正版账号，账号密码在官方页面能正常登录；只玩单机的话改用离线模式进入，不需要登录 |
| 网络 | 切换 Wi-Fi 与移动数据对比着试；账号与联机线路的关系见[联机开房间与加好友方法](联机开房间与加好友方法.md) |

## 三、游戏启动后白屏或卡死

白屏、卡死发生在「点启动」之后的游戏加载阶段，和启动器本身打不开是两回事：

1. 回启动器设置里**调大内存分配**（位置见[首次启动与版本导入](首次启动与版本导入.md)），介绍页的建议是 2GB 以上，手机内存小就别一次给满；
2. 确认导入的基岩版游戏包是**完整的**，损坏的包会在加载阶段卡住；
3. 把版本删掉重新导入一次再启动。

## 四、导入版本或资源失败

1. 换系统自带的文件管理器重新选一次文件；
2. 有版本的更新日志提到修复过「文件管理器无法导入」的问题——始终导不进去时，先确认你的启动器不是太旧的版本；
3. 把要导入的文件重新下载一遍，损坏的包导入必然失败。

导入成功之后资源怎么用，见[材质包与模组安装方法](材质包与模组安装方法.md)那篇。
