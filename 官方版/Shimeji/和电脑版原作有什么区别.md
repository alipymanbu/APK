# 和电脑版原作有什么区别

> 讲清三样容易混淆的东西：电脑版原作 Shimeji、这款安卓版应用、还有名字很像的 Simeji 键盘。

## 一、同一个名字，两条不同的产品线

搜「Shimeji」会同时撞到电脑程序和安卓应用，它们不是同一个软件，但玩法一脉相承：

| | 电脑版原作 | 这款安卓应用 |
| --- | --- | --- |
| 是什么 | Java 写的桌面桌宠程序 | Google Play 上的桌宠应用 |
| 出身 | 2009 年前后由日本的 Group Finity（Yuki Yamada）发布，开源 | Digital Cosmos 开发的独立应用（官方声明与任何动漫、游戏、影视 IP 无关） |
| 平台 | Windows（需 Java 环境）；英文分支 Shimeji-ee 由社区维护至今 | 仅安卓，没有 iOS 版 |
| 角色来源 | 大量画手自制皮肤包流传于社区 | 内置原创角色库 + 自创 + 导入兼容皮肤包 |
| 玩法加成 | 无 | 等级、XP、解锁货币这套养成（见 [添加桌宠与互动玩法.md](添加桌宠与互动玩法.md)） |

一句话：你手机上装的这款是「借了这个玩法名字的安卓独立应用」，不是把电脑版移植过来。

## 二、名字和「蘑菇」的巧合

Shimeji 在日语里指的是一种蘑菇（蟹味菇一类），电脑版得名的原因是：蘑菇成片冒头，小人也成群冒出来。而这款安卓新版的解锁货币恰好就叫 **Mushroom（蘑菇）**——亮屏会自动积累、解锁角色和动作时消耗，算是把名字的梗用进了养成系统。这套货币机制是新版加入的，你手上的 v5.8 未必有，以应用内实际显示为准。

## 三、皮肤包能不能互通

电脑版的一个皮肤包，本质上是一个文件夹：一组按编号排列的 PNG 帧，加几份描述行为的配置文件。社区十几年来攒下了海量这种包。这款安卓应用的官方新版支持**导入兼容的 PC Shimeji 皮肤包**直接在安卓上用：

- 能不能导成功取决于包的结构是否兼容，导入失败多半是包不兼容，不是你操作错了；
- 导入方式与自创入口见 [自创角色与导入皮肤包.md](自创角色与导入皮肤包.md)；
- v5.8 这类旧版没有导入入口的话，只能换商店新版。

## 四、别和 Simeji 键盘搞混

还有一款叫 **Simeji**（少一个 h）的是日语输入法键盘应用，和桌宠毫无关系——这款应用的官方声明里专门撇清了这一点。认准开发者 Digital Cosmos 与包名 `com.digitalcosmos.shimeji`（核对方法见 [下载与安装教程.md](下载与安装教程.md)）。

## 五、你该用哪个

- 只想在**手机**屏幕上养几只小角色 → 就是这款，渠道见 [下载与安装教程.md](下载与安装教程.md)；
- 想在 **Windows 电脑**桌面上养 → 找电脑版原作或它的 Shimeji-ee 分支（需要 Java 环境），与这款手机应用互不相干；
- 两边都想要 → 手机用这款、电脑用原作，电脑版攒的皮肤包在新版安卓里还能导进来接着用。
