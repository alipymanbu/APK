# 连接Emby服务器教程

> 在 Yamby 里添加并连接你的 Emby 服务器：每个字段怎么填、自动发现失效时怎么办、连不上先查哪里。

## 一、添加服务器的入口

打开 Yamby，主界面右下角的加号按钮就是添加服务器的入口。点开后是一个表单，填服务器地址与登录信息，确认后点连接。连接成功会让你选一次服务器与用户，确认无误就进到媒体库首页。

## 二、每个字段怎么填

| 字段 | 填什么 | 常见取值 |
| --- | --- | --- |
| 服务器地址 | Emby 服务器的 IP 或域名 | 局域网内如 `192.168.1.10`；公网填域名 |
| 端口 | 服务器监听的端口 | HTTP 默认 `8096`，HTTPS 默认 `8920` |
| 协议 | HTTP 或 HTTPS | 服务器配了证书就选 HTTPS，否则 HTTP |
| 路径 | 一般留空 | 反代场景才需要填，没配反代就空着 |
| 用户名 / 密码 | 你的 Emby 账号 | 不是 Yamby 的账号，就是服务器上那套 |

三个容易踩的点：

1. **端口和协议要配对**：选 HTTPS 就填 `8920`（或你服务器实际的 HTTPS 端口），选 HTTP 就填 `8096`。配对错了会一直连不上。
2. **地址别带 `http://` 前缀**：协议已经在下拉里选了，地址栏只填主机部分（IP 或域名）。
3. **路径不是必填**：只有服务器挂在反向代理子路径下时才填，直接连服务器就空着。

## 三、局域网内：先试自动发现

同一局域网内，Emby 客户端通常能自动发现服务器（靠 UDP `7359` 端口的广播）。打开添加页面后留意有没有自动扫出来的服务器，有就直接点它，省去手填。

自动发现失效很常见（路由器开了 AP 隔离、访客网络、跨网段都会导致广播过不去），失效就手动填地址 —— 手动填的永远是兜底方案。

## 四、外网访问：服务器端要先具备的条件

出了家门还能连上，前提全在服务器那一侧，手机端无从补救：

- 服务器上 Emby 的「允许远程访问」要开启；
- 路由器要把端口转发到服务器内网 IP（HTTP `8096` / HTTPS `8920` 两个 TCP 端口）；
- 服务器系统防火墙要放行这两个 TCP 端口；如果自动发现也要用，UDP `7359` 一并放行；
- Windows 上把网络配置文件设为「专用网络」而非「公用网络」，「公用」会拦入站连接。

判断服务器侧通没通，最直接的办法是拿另一台设备开浏览器访问 `http://服务器地址:8096`，能打开 Emby 登录页说明端口是通的，剩下就是 Yamby 里填法的问题。

## 五、多个服务器：切换与隐藏媒体库

你可以添加多个 Emby 服务器并在它们之间切换（免费版对服务器数量有上限，上限以上见 [Pro专业版功能对比.md](Pro专业版功能对比.md)）。连上后如果某个服务器下的某些媒体库不想显示，可以在库里设置里把指定的库隐藏起来，首页就只剩你要看的那部分。

## 六、连不上先查这几条

按顺序过一遍，多数问题在前三条就解决了：

1. 服务器进程活着吗？电脑/NAS 没休眠、Emby Server 没退出。
2. 端口和协议配对对吗（见第二节）？
3. 手机和服务器在同一个网吗？连的 Wi-Fi 是不是访客网络？
4. 换浏览器开 `http://地址:8096` 能通吗？浏览器都不通，是服务器或网络的问题，不是 Yamby 的。
5. 密码手敲一遍，别复制粘贴（粘贴容易带进看不见的空格）。

更完整的排查表在 [常见问题与排查.md](常见问题与排查.md)。
