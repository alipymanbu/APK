## 一、先说清楚：免费版能干什么

连服务器、切服务器、隐藏媒体库、播放器手势、倍速与缓存调节、字幕缩放与偏移、内嵌外挂字幕、播放中换音轨、自定义字幕字体、画中画、直播电视、Strm 直通、弹幕、Emby 管理员操作（扫描媒体库、编辑与刷新元数据、编辑图片）—— 这些都在免费版里，日常看片不掏钱也够用。具体怎么用见 [播放器手势与字幕设置.md](播放器手势与字幕设置.md)。

## 二、功能对照表

| 功能 | 免费版 | Pro |
| --- | --- | --- |
| 服务器连接与切换 | 有（数量有上限） | 不限数量 |
| 播放器手势 / 倍速 / 缓存 / 字幕调节 | 有 | 有 |
| 画中画、直播、Strm 直通、弹幕 | 有 | 有 |
| 主题 | 基础主题 | 10 多种主题，含夜间模式与 Monet 动态取色 |
| MPV 播放器内核 | 无 | 可启用（字幕兼容性更好、支持软件解码） |
| 缩略图预览与跳过片头 | 无 | 有（**需服务器支持**） |
| Fanart 大图查看 | 无 | 有 |
| 跳过启动画面、直达上次服务器 | 无 | 有 |
| 列表动画 | 默认 | 更流畅 |
| 自定义应用图标 | 无 | 有 |

## 三、Pro 里两条容易误解的

**跳过片头与缩略图预览需要服务器配合**：这两个功能依赖 Emby 服务器对相应数据的支持，服务器没配好的话，装了 Pro 也照样跳不过去、出不来缩略图 —— 先在别的 Emby 客户端上确认服务器本身支持，再考虑是不是客户端的问题。

**MPV 内核是可选项**：Pro 里可以启用 MPV 播放器，主要收益是字幕兼容性与软件解码兜底；默认内核播得动就不用开。

## 四、购买与兑换

Pro 通过 Google Play 商店内购解锁，价格与订阅周期以商店页面当时显示为准（本文不写死数字，随时会变）。如果你手上拿到的是开发者发放的兑换码，在应用内的 Pro/订阅入口兑换即可。

升级入口、订阅管理都在 Play 商店的「订阅与已购」里，想取消自动续订也在那里操作。装的是手动 APK 的话，内购同样走 Play 商店完成，前提是手机上 Play 商店可登录且能联网。

购买前建议先用免费版跑通 [连接Emby服务器教程.md](连接Emby服务器教程.md) 那套流程 —— 连不上服务器的话，Pro 的加分项你也体验不到。
