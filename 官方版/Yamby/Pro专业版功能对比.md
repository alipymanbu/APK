## 一、先说清楚：免费版能干什么

连服务器、切服务器、隐藏媒体库、播放器手势、倍速与缓存调节、字幕缩放与偏移、内嵌外挂字幕、播放中换音轨、自定义字幕字体、画中画、直播电视、Strm 直通、弹幕、Emby 管理员操作（扫描媒体库、编辑与刷新元数据、编辑图片）—— 这些都在免费版里，日常看片不掏钱也够用。具体怎么用见 [播放器手势与字幕设置.md](播放器手势与字幕设置.md)。

## 二、功能对照表

| 功能 | 免费版 | Pro |
| --- | --- | --- |
| 服务器连接与切换 | 有（数量有上限） | 不限数量 |
| 播放器手势 / 倍速 / 缓存 / 字幕调节 | 有 | 有 |
| 画中画、直播、Strm 直通、弹幕 | 有 | 有 |
| 主题 | 基础主题 | 10 多种主题，含夜间模式与 Monet 动态取色 |
| MPV 播放器内核 | 无 | 可启用（字幕兼容性更好、支持软件解码） |
| 缩略图预览与跳过片头 | 无 | 有（**需服务器支持**） |
| Fanart 大图查看 | 无 | 有 |
| 跳过启动画面、直达上次服务器 | 无 | 有 |
| 列表动画 | 默认 | 更流畅 |
| 自定义应用图标 | 无 | 有 |

## 三、Pro 里两条容易误解的

**跳过片头与缩略图预览需要服务器配合**：这两个功能依赖 Emby 服务器对相应数据的支持，服务器没配好的话，装了 Pro 也照样跳不过去、出不来缩略图 —— 先在别的 Emby 客户端上确认服务器本身支持，再考虑是不是客户端的问题。

**MPV 内核是可选项**：Pro 里可以启用 MPV 播放器，主要收益是字幕兼容性与软件解码兜底；默认内核播得动就不用开。

## 四、购买与兑换（现状有变化，两种说法并存）

Pro 最初通过 Google Play 商店内购解锁。2025 年起情况发生了变化，公开渠道有两组不同说法：

| 说法 | 来源类型 | 内容 |
| --- | --- | --- |
| Pro 已基本免费放出 | 开发者渠道公告（经第三方转述）+ 社区指南 | 因开发者 Google 账号问题，99% 付费功能被放出，指南标注「大部分功能当前可免费使用」 |
| Google Play 上买不了 Pro | 多名用户反馈（2024 年起陆续出现） | 商店购买入口不可用，用户在发帖询问其他购买渠道 |

两边并列供你参考，**实际状态以你的应用内 Pro 页面与商店页面当时显示为准**（截至 2026-09 检索时，随时会变）。已经拿到兑换码的，在应用内的 Pro/订阅入口兑换即可。

另外两点事实：

- 国产手机大多没有预装 Google Play，而 Pro 内购依赖 Play 商店 —— 手机上没有 Play 的话，先看 [和官方Emby客户端怎么选.md](和官方Emby客户端怎么选.md) 里对现状的说明，别按旧教程反复重试付款。
- Pro 是 Yamby 自己的内购，与 Emby Premiere 是两套完全独立的东西，互不打通（区别见 [和官方Emby客户端怎么选.md](和官方Emby客户端怎么选.md)）。

购买前建议先用免费版跑通 [连接Emby服务器教程.md](连接Emby服务器教程.md) 那套流程 —— 连不上服务器的话，Pro 的加分项你也体验不到。
