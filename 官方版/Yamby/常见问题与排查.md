## 一、连不上服务器

按这个顺序查，每条都是实际最常见的原因：

1. **服务器在跑吗**：Emby Server 进程是否活着、电脑是否休眠了。手机端再怎么折腾也救不了关机的服务器。
2. **字段配对**：端口与协议必须配对（HTTP `8096` / HTTPS `8920`），地址栏不带 `http://` 前缀，详见 [连接Emby服务器教程.md](连接Emby服务器教程.md) 第二节。
3. **网络位置**：手机和服务器是否在同一局域网；连的 Wi-Fi 是不是访客网络（访客网络通常隔离设备）。
4. **浏览器交叉验证**：另一台设备开浏览器访问 `http://服务器地址:8096`。浏览器能开而 Yamby 不行 → 问题在填法；浏览器也打不开 → 问题在服务器或网络。
5. **服务器侧防火墙**：Windows 防火墙放行 TCP `8096`/`8920`、UDP `7359`；网络配置文件设为「专用网络」。
6. **密码手敲**：复制粘贴容易带进尾部空格，导致 401 类的认证失败。
7. **删掉重加**：地址换过、服务器重装过之后，把旧服务器条目删掉重新添加，比在旧条目上改来改去干净。

## 二、播放卡顿

播放流不流利，取决于三件事，与 Yamby 本身关系不大：

- **服务器负载**：同时看的人多、机器性能弱就会卡。
- **网络链路**：外网访问时线路质量是大头，高码率内容（4K、高码率蓝光）对带宽的要求完全不是一个量级 —— 点开前先确认当前网络扛得住这个码率。
- **转码还是直通**：能直通（direct play）最省资源；触发转码时服务器 CPU 压力上来，弱机器就会卡。

判断办法：换一个明显小码率的片子试。小片子流畅、大片子卡 → 链路或转码的问题；大小都卡 → 服务器负载问题。

## 三、提示没有兼容的流 / 播放报错

服务器说「没有兼容的流」，意思是这个文件的编码格式手机端播不了、服务器又没转出可用的流。两条路：

1. 在播放设置里把解码方式切换（如启用 Pro 的 MPV 软件解码，见 [Pro专业版功能对比.md](Pro专业版功能对比.md)）；
2. 让服务器能转码（Emby 端开启硬件加速转码），或换个该设备能直通的文件版本。

## 四、弹幕没有显示

- 弹幕只支持**中文弹幕**，且基于 dandanplay 匹配当前剧集 —— 匹配不上就没有弹幕，这是机制，不是开关没打开；
- 小众片源、刚出炉的资源往往匹配库还没有，等或换有匹配的集数；
- 先确认播放器里弹幕开关处于开启状态。

## 五、跳过片头 / 缩略图预览不生效

这两个是 Pro 功能，且**依赖 Emby 服务器的支持**（见 [Pro专业版功能对比.md](Pro专业版功能对比.md)）。先用其他 Emby 客户端验证服务器本身有没有这些数据：别的客户端也跳不过去 → 服务器侧没配，与 Yamby 无关。

## 六、Strm 文件点了没反应

Strm 走直通播放，流地址由服务器给出。手机连的是外网、而 Strm 里写的是内网地址时，手机拉不到这个流 —— 现象就是点了没反应或一直转圈。确认 Strm 里的地址从手机当前网络可达，或改用内网可达的地址写法。

## 七、升级后出问题

覆盖升级（同包名直接装新包）会保留设置；如果升级后出现怪问题且清不掉，先试「清数据」（设置里找到 Yamby → 存储 → 清除数据），再重新添加服务器。清数据等于回到首次安装状态，服务器地址要重填 —— 换新设备或重置前，把服务器地址和端口记下来（记在 [连接Emby服务器教程.md](连接Emby服务器教程.md) 那张表里就用得上）。
