## 一、改法只有三步

1. 打开 Chrome，点右上角竖排三点菜单 → 设置。
2. 在「基础」分组里点「搜索引擎」。
3. 在列表里选一个：常见的有 Google、Bing、Yahoo、DuckDuckGo、Ecosia。**列表内容会因地区、Chrome 版本、厂商定制而不同**，以你屏幕上实际出现的为准；你最近访问过的搜索引擎也可能被加进列表。

改完立刻生效：下次在地址栏输入关键词回车，结果页就由新引擎提供。

## 二、这个开关管的范围比你想的小

| 位置 | 是否受此设置影响 |
| --- | --- |
| Chrome 地址栏、新标签页里的搜索 | 是 |
| 桌面上的 Google 搜索小组件 | 否，小组件走 Google App 自己的逻辑 |
| 其他浏览器（三星浏览器等） | 否，各浏览器各有各的设置 |
| 系统桌面/抽屉里的搜索框 | 否，取决于启动器 |

也就是说：Android 上没有一个「全机统一」的搜索引擎开关，你在 Chrome 里改的只管 Chrome 里发起的搜索。想让搜索入口都换掉，得逐个 App 去改，或干脆换掉桌面上的搜索小组件。

## 三、手机上不能像电脑那样自定义引擎

电脑版 Chrome 可以在「管理搜索引擎」里手动添加任意站点（搜索网址里用 `%s` 代替查询词）；**安卓版通常只提供内置列表**，没有这个添加入口。想要的引擎不在列表里，只能等官方按地区放出，或改用其他支持自定义的浏览器——这一点是两端的真实差异，不是你没找到菜单。

## 四、改了没生效 / 被自动改回去

按这个顺序查：

1. **确认改在了对的地方**：改完回到 设置 → 搜索引擎 看一眼，显示的还是不是你选的那家；第三方 App 里的搜索框不归这个设置管（见第二节）。
2. **看有没有网站诱导**：某些网页会引导你在其页面里「设为默认」，属网站自己的行为，回到 Chrome 设置里改回来即可。
3. **反复被改回去就查最近装的应用**：多个资料都提示，搜索引擎被无故篡改可能与恶意软件或来路不明的扩展有关——回忆一下问题出现前装了什么，先卸载可疑应用，再把设置改回来。改回的操作与第一节完全相同。

需要排查「只有搜索打不开、网页正常」这类网络问题时，转 [打不开网页怎么办.md](打不开网页怎么办.md)；地址栏的另一个用法——扫码，见 [怎么扫描二维码.md](怎么扫描二维码.md)。
