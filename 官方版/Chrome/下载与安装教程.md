## 一、先认清你要装的包

Chrome 的官方名称是 Google Chrome（下文统称 Chrome），开发者是 Google LLC，安卓包名 `com.android.chrome`。网上搜到的多是官方最新版，与你手上这份安装包未必是同一个版本，所以版本号、包名、大小一律以下面这张表为准：

| 项目 | 值 |
| --- | --- |
| 版本号 | 146.0.7680.164 |
| 包名 | com.android.chrome |
| 安装包大小 | 18.76M |
| MD5 | 79fdf7d77cd2fa08cf81874465754aab |
| 整理时间 | 2026-09-22 |

Chrome 的版本号是四段式 `MAJOR.MINOR.BUILD.PATCH`，第一段是大版本号（也叫里程碑）。官方 Stable 通道大约每四周发一个大版本、每两到三周一次小更新——所以你以后再下载，拿到的版本比表里新很正常，核对时以安装包本身为准。

## 二、安装包从哪拿

[Chrome 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2a033d8d0af0)，打开分享页转存后下载 `Chrome_v146.0.7680.164.apk` 即可。下载完成后先确认文件名与大小（18.76M）与上表一致，再往手机里装。下载完在手机里找不到文件的话，见 [下载的文件在哪个文件夹.md](下载的文件在哪个文件夹.md)。

## 三、先给「打开安装包的那个应用」授权

Android 8.0 及以上不再有全局的「未知来源」开关，改成了**按应用单独授权**（官方 Android 开发者文档的口径）：系统限制的是「哪个应用有权安装 APK」，而不是「允许装所有 APK」。两种入口，任选一种：

1. **提前授权**：设置 → 应用 → 右上角三点 → 特殊权限 → 安装未知应用 → 选中你用来打开 APK 的应用（文件管理器或浏览器）→ 打开「允许来自此来源」。
2. **现场授权**：直接点开 APK，系统弹出「已阻止安装」类提示时点「设置」，会跳到同一个开关页，打开后返回再点安装。

这个权限只授予单个来源，装完后你可以随时回同一路径关掉。如果你的手机是三星 One UI 等定制系统，菜单名可能略有出入，认准「安装未知应用 / Install unknown apps」这个关键词即可。

## 四、安装时的 Play Protect 提示

安装包不来自 Google Play 时，系统的 Play Protect 可能弹出风险提示。来源是你自己确认过的就按提示继续安装；拿不准来源就先停手，别装。装完桌面会出现 Chrome 图标。

## 五、装完核对版本

打开 Chrome，在地址栏输入下面这行回车：

```
chrome://version
```

页面第一行就是当前版本号，应与表中的 146.0.7680.164 一致。对不上说明装的不是这个包，回头检查下载的文件。

## 六、以后怎么更新

- **手机带 Google Play**：打开 Play 商店搜 Chrome，让官方渠道自动更新即可（参见 [Google Chrome 帮助：如何更新 Chrome](https://support.google.cn/chrome/answer/95414?hl=zh-Hans)，以官方页面为准）。
- **手机没有 Google Play**：拿到新版本安装包后直接覆盖安装。Android 只允许**版本号更高**的安装包覆盖同包名应用，装更旧的版本会直接失败，先卸载又会丢掉本机数据——所以升级前建议先开同步，见 [书签和密码怎么同步.md](书签和密码怎么同步.md)。
- **换手机或重装系统**：登录同一个 Google 账号并开启同步，书签、密码会跟着账号回来；应用本体按本篇第三节重新安装即可。
