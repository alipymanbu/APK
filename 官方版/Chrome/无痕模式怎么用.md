## 一、打开与关闭

1. 打开 Chrome，点右上角竖排三点菜单。
2. 选「新建无痕标签页」。界面变成深灰色，左上角出现礼帽加眼镜的图标，页面会写明你已进入无痕浏览。
3. 在普通标签与无痕标签之间切换：点地址栏旁带数字的方块（标签页计数器），顶部会分成两组——普通标签一组、无痕一组，点对应图标即可来回切。
4. 关闭无痕：在标签页总览里点无痕标签旁的叉；也可以下拉通知栏，点 Chrome 通知里的「关闭所有无痕标签页」。

普通标签不必为了无痕而关掉，两组标签是并行存在的。

## 二、它不保存什么、还保留什么

| 类型 | 无痕下是否保留 |
| --- | --- |
| 浏览历史 | 关闭标签后不保留 |
| Cookie 与网站数据 | 关闭标签后不保留 |
| 表单里填过的内容 | 不保留 |
| 下载的文件 | **保留**，留在下载目录里 |
| 你手动加的书签 | **保留** |
| 登录过的网站状态 | 关标签即失效，下次要重新登录 |

## 三、它挡不住什么（最容易误会的一点）

无痕只是「不往你手机里记」，不是「上网不留痕」：你访问的网站本身、网络服务提供商、公司或学校网络的管理员，仍然看得到你去了哪些页面。把无痕当成对身边人隐藏记录的手段是成立的，把它当成匿名手段则不成立。

## 四、两个实用设置

- **离开就锁无痕**：部分版本在 设置 → 隐私和安全 里提供「关闭 Chrome 时锁定无痕标签页」，开启后切走再回来要用指纹或 PIN 验证。菜单名与是否出现以你的版本为准。
- **挡住第三方 Cookie**：无痕页面里可直接开启「阻止第三方 Cookie」，减少跨站跟踪。
- **网站的通知请求也不会弹**：无痕期间网站发不出「允许发送通知」的询问框，被某站点的通知缠上时，处理办法见 [网站通知怎么关掉.md](网站通知怎么关掉.md)。

## 五、无痕的另一个用途：当排查工具

普通窗口打不开的网页、登录状态异常的网站，先用无痕开一次——无痕下一切正常，基本可以锁定是缓存或 Cookie 的问题，随后按 [打不开网页怎么办.md](打不开网页怎么办.md) 第三节清理即可；无痕下同样打不开，就别在 Chrome 的数据上浪费时间，去查网络。相关清理步骤见 [闪退卡顿怎么修.md](闪退卡顿怎么修.md)。

另外，无痕不会同步：退出登录或换设备都不会把无痕记录带过去，这正是它与普通标签的根本区别——同步规则见 [书签和密码怎么同步.md](书签和密码怎么同步.md)。
