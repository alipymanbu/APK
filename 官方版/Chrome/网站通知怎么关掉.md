# 网站通知怎么关掉

> 网站老弹「允许发送通知」、关了弹窗却还收得到消息——分清通知和弹窗两件事，再各关各的。

## 一、先分清两件事

| 名字 | 长什么样 | 归哪管 |
| --- | --- | --- |
| 通知请求 | 页面顶部弹「允许 xx 向您发送通知吗」 | 通知设置 |
| 弹出式窗口 | 广告窗、新窗口乱跳 | 弹出式窗口和重定向设置 |

两套开关是独立的：官方帮助明确说过，停用了弹出式窗口却仍收到某网站的消息，多半是**之前点过「允许」订阅了它的通知**——该去关的是通知，不是继续调弹窗。

## 二、让请求框永远不再弹

1. 三点菜单 → 设置 → 网站设置（部分版本在「隐私和安全」下）。
2. 点「通知」。
3. 关掉顶部那个「询问是否允许网站发送通知」的开关，该项显示为**已阻止**即可。

这一步之后，任何网站都弹不出询问框，你也不用再每次纠结点允许还是拒绝。位置、相机、麦克风的请求框在同一页面里逐项处理（第四节）。

## 三、已经点过「允许」的网站怎么撤回

- **路径 A**：设置 → 网站设置 → 通知 → 找到「允许」列表里的该站点，移除或改为阻止。
- **路径 B**：直接打开那个网站 → 点地址栏旁的站点信息图标（锁形或设置图标）→ 通知 → 选「禁止」。

撤回后它的推送立刻停止。列表里其他眼熟的站点顺手一并清一遍。

## 四、位置、相机、麦克风的请求同理

第二步那个页面往下滚，位置、摄像头、麦克风各有各的开关，处理方式完全相同——关掉总开关后，**所有网站都弹不出对应请求**。代价是真需要定位、扫码付钱的网页也用不了这些权限，届时回到同一处对单个站点放行即可。

## 五、两个补充

- **无痕下不会弹通知请求**：正在用无痕浏览时网站发不出通知询问，这也是临时躲开骚扰的办法，操作见 [无痕模式怎么用.md](无痕模式怎么用.md)。
- **关了还在乱跳、消息照来**：官方帮助提示这可能与设备感染恶意软件有关，可按 [Chrome 帮助：清除恶意软件](https://support.google.cn/chrome/answer/2765944?hl=zh-Hans) 排查；若是某个网页本身排版怪异，则转 [打不开网页怎么办.md](打不开网页怎么办.md)。

外文网站的翻译提示条属于另一套机制，见 [网页翻译怎么用.md](网页翻译怎么用.md)。
