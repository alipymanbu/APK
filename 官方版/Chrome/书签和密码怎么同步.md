# 书签和密码怎么同步

> 登录 Google 账号开启同步后，书签、密码、标签页怎么在手机与电脑之间流转，以及退出同步的代价。

## 一、开启同步：三步

1. 打开 Chrome，点地址栏右侧的三点菜单 → 设置。
2. 点「登录并开启同步」（或「开启同步功能」），选择你要用的 Google 账号。
3. 点「立即开启」。

没账号先去 Google 账号注册页注册一个再回来。官方步骤见 [Chrome 帮助：登录并开启同步](https://support.google.com/chrome/answer/185277?hl=zh-Hans&co=GENIE.Platform%3DAndroid)。

## 二、同步都带了什么

| 数据 | 说明 |
| --- | --- |
| 书签 | 手机加的书签，电脑上也在 |
| 密码 | 在哪存的密码，登录别的设备时都能用 |
| 历史记录与标签页 | 「在其他设备上继续浏览」就是靠它 |
| 自动填充 | 地址、付款方式等表单信息 |
| 阅读列表、设置项 | 偏好设置跟着账号走 |

默认是全部同步；想只同步某几类，进 设置 → 同步（或账号名 → 同步），关掉「同步所有内容」后逐项勾选。

**前提条件**：手机要能保存/同步密码和付款信息，设备必须先设有锁屏（PIN、图案、密码或指纹）。找不到「保存密码」的开关时，先去系统设置把锁屏配上再回来看。

## 三、多设备怎么接上

在电脑、平板上同样打开 Chrome、登录**同一个** Google 账号并开启同步，几秒到几分钟内数据就会推齐。判断同步是否在跑：设置顶部你的账号名旁若有同步状态提示或上次同步时间，照着它核对；两台设备各检查一遍开关有没有开着。

## 四、退出同步前先想清楚

路径：设置 → 点账号名 → 「退出账号并关闭同步功能」。三个后果要提前知道：

1. 退出时会**连带退出该账号在其他 Google 服务的登录**（如 Gmail），不只是 Chrome；
2. 关闭同步后，设备上已同步的数据可能被移除——**没同步到账号的本机密码、书签会跟着没**；
3. 只关同步、不退账号，或只在这台设备上退出，都可以按页面提示单独选择。

所以重装、清数据、换手机之前（操作见 [闪退卡顿怎么修.md](闪退卡顿怎么修.md) 与 [下载与安装教程.md](下载与安装教程.md)），先回头确认同步是开着的、数据已经上到账号里。

## 五、两个常见的「同步了却看不到」

- **只有这台设备有，别的设备没有**：大概率是别的设备没登录同一账号，或登录了但同步开关没开——两边都检查一遍。
- **新设备上要求输入口令短语**：如果你以前给同步设过自定义口令短语（用来加强隐私的一种可选设置），在新设备登录时必须输入它才能解开数据；忘了就只能重置，重置后旧的同步数据将无法读取。没设过的人不会遇到这一步。

最后提醒：无痕标签页**不参与同步**，退出登录也不会把无痕记录带走，两者的行为边界见 [无痕模式怎么用.md](无痕模式怎么用.md)。
