## 一、先分清是 Chrome 的事还是手机的事

下面任意一条成立，问题多半不在浏览器，先解决环境再折腾 Chrome：

- 手机存储快满了：Chrome 要靠本地空间存缓存，空间见底时 App 会卡甚至闪退，进设置 → 存储看一眼余量；
- 手机发烫降频：机身烫的时候所有 App 都慢，先让它凉下来；
- 其他 App 也卡：重启手机通常比修单个 App 有效；
- 最近装了省电、清理、杀毒类工具：这类工具会限制后台与网络，可先关掉它们再试；
- 拿不准是不是第三方应用在干扰：多数机型在电源键菜单里能进安全模式（常见触发方式是长按「关机」后确认进入，入口因机型而异），该模式下第三方应用全部停用——安全模式里 Chrome 正常，基本可锁定是某个第三方应用的问题。

判断顺序上，还可以先看**是不是只有网页开不了**——那是另一类问题，见 [打不开网页怎么办.md](打不开网页怎么办.md)。

## 二、阶梯处理：从代价最小的开始

| 阶梯 | 操作 | 会丢什么 |
| --- | --- | --- |
| 1 | 彻底关掉 Chrome 再重开（从最近任务里划掉） | 什么都不丢 |
| 2 | 强制停止：设置 → 应用 → Chrome → 强制停止 | 什么都不丢 |
| 3 | 清缓存：设置 → 应用 → Chrome → 存储 → 清除缓存 | 什么都不丢，只删临时文件 |
| 4 | 清除数据：同一页面点「清除存储空间 / 清除数据」 | 本机保存的密码、书签、登录态全没（**先开同步**，见 [书签和密码怎么同步.md](书签和密码怎么同步.md)） |
| 5 | 卸载更新：Chrome 页面右上角菜单里若有「卸载更新」 | 回到出厂预装版本，浏览数据一般保留；之后可再装新包 |
| 6 | 卸载后重装最新包 | 所有本机数据清空，务必先同步 |

**清缓存 vs 清数据别搞混**：缓存只是临时文件，清了最安全；「清除数据」会把 Chrome 恢复成刚装好的状态，已保存但没同步的密码和书签会跟着没。拿不准就只做第 3 步。

## 三、Chrome 卸不掉是正常的

多数安卓机把 Chrome 作为预装应用放在系统分区里，应用信息页没有「卸载」只有「卸载更新」——这是系统设计，不是出了故障。卸载更新只是把它退回出厂时那个版本；想回到新版本，重新安装更高版本的安装包即可，入口与授权步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 四、卡顿但不闪退的三个常见原因

1. **标签页开太多**。移动端标签攒到几十个会明显吃内存，点标签计数器把不用的关掉。
2. **系统省流量模式 / 数据节省开关**。部分机型的省流量功能会让页面加载变慢，进系统设置确认是否开着。
3. **缓存积压**。长期不清，缓存目录越来越大，页面反而更慢——每隔一段时间做一次第二阶梯的第 3 步即可。

## 五、什么时候该重装

前面五步都试过还闪退，才值得重装：先确认同步是开着的（[书签和密码怎么同步.md](书签和密码怎么同步.md)），再从 [Chrome 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2a033d8d0af0) 取安装包，按 [下载与安装教程.md](下载与安装教程.md) 重装一遍。装完若问题依旧，多半是该版本本身的问题，等官方下一次更新即可（Stable 通道每两到三周一次小更新）。
