# 打不开网页怎么办

> 页面报错、一直转圈、提示「无法访问此网站」时，先定位问题在哪一层，再按顺序动手。

## 一、第一步永远是定位：问题在哪一层

在乱改设置之前，先用下面这张表花半分钟判断方向——不同结论对应的排查路径完全不同：

| 你观察到的现象 | 更可能的问题在 |
| --- | --- |
| 所有网站都打不开，别的 App 也连不上网 | 手机网络本身 |
| 只有个别网站打不开，别的都正常 | 那个网站或它的域名解析 |
| Chrome 打不开，换别的浏览器能开 | Chrome 的数据或设置 |
| 无痕窗口能开，普通窗口不能 | 缓存、Cookie 或已保存的站点数据 |
| Wi-Fi 下不行，流量下正常 | 路由器、DNS 或宽带线路 |
| 别人也打不开同一个网址 | 网站自己挂了 |

## 二、错误码对照表

Chrome 报错时会在小字里带一个 `ERR_` 开头的代码，它直接指向连接链条断在哪一环：

| 错误码 | 含义 | 优先检查 |
| --- | --- | --- |
| `ERR_NAME_NOT_RESOLVED` | 域名解析失败，网址没换成 IP | DNS、网址拼写、网络 |
| `DNS_PROBE_FINISHED_NXDOMAIN` | 同上，域名找不到 | 网址拼写、DNS |
| `ERR_CONNECTION_TIMED_OUT` | 等服务器回应超时 | 网络质量、网站是否卡死 |
| `ERR_CONNECTION_REFUSED` | 服务器拒接 | 网站本身 |
| `ERR_INTERNET_DISCONNECTED` | 手机当前没有可用网络 | Wi-Fi / 流量开关 |
| `ERR_TOO_MANY_REDIRECTS` | 重定向循环，常因 Cookie 损坏 | 清除 Cookie |
| `NET::ERR_CERT_DATE_INVALID` | 证书日期与本机时间对不上 | 系统日期时间 |

## 三、按顺序动手

1. **检查网址拼写**。少个字母、错个后缀是最常见的原因（官方排查第一步）。
2. **换一条网络试**。Wi-Fi 和移动数据互切一次；只有 Wi-Fi 不行就重启路由器。
3. **公共 Wi-Fi 先过门户**。机场、酒店的 Wi-Fi 常要先登录才能上网，随便打开一个以 `http://` 开头的网址通常会弹出登录页（官方建议的触发方式）。
4. **用无痕窗口打开同一网址**。无痕下正常，说明问题在缓存或 Cookie，直接跳到第 5 步；不开无痕怎么操作见 [无痕模式怎么用.md](无痕模式怎么用.md)。
5. **清缓存和 Cookie**：三点菜单 → 设置 → 隐私和安全 → 清除浏览数据，先勾「缓存的图片和文件」+「Cookie 和网站数据」，时间范围选「所有时间」。清 Cookie 会让你在部分网站重新登录。
6. **关掉 VPN / 代理，检查私人 DNS**。VPN 隧道可能拖垮连接；设置里的「私人 DNS」如果填了一个不可达的主机名，会表现为**一批网站集体打不开**——先改回自动或关闭再测。
7. **核对系统日期时间**。时间偏差过大会让 HTTPS 证书校验失败，报 `NET::ERR_CERT_DATE_INVALID`；打开设置把日期时间改成自动。
8. **换个浏览器或换台设备打开同一网址**。别的浏览器也失败、别人也打不开，那就是网站侧的问题，只能等或联系网站所有者。

更完整的错误码释义可对照官方页面：[Chrome 帮助：修正连接错误](https://support.google.cn/chrome/answer/6098869?hl=zh-Hans)。

## 四、什么时候该怀疑是 Chrome 本身

清了缓存、换了网络仍然只在 Chrome 里失败，才轮到动 Chrome 自己：强制停止后重开、清除数据恢复默认，参见 [闪退卡顿怎么修.md](闪退卡顿怎么修.md)。若问题从安装某个版本之后才出现，可以回退到出厂预装版本（卸载更新）再重新升级，安装包入口见 [下载与安装教程.md](下载与安装教程.md)。
