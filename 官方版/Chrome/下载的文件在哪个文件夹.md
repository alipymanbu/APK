# 下载的文件在哪个文件夹

> 下载完却找不到文件、点了下载没反应、下到一半停住——三种情况分别怎么处理。

## 一、先看 Chrome 自己的下载列表

点右上角三点菜单 → 「下载」，这里是按时间排的下载记录：点条目直接打开文件。**列表只是记录**——就算清了记录、或记录里没有，文件本身还躺在存储里，用第二节的办法找。

## 二、文件实际存在哪

安卓上 Chrome 默认把文件存进系统级的 Download（或 Downloads）文件夹：

1. 打开手机的文件管理应用——各家叫法不同：Files、我的文件（三星）、File Manager，抽屉里搜「文件」或「Downloads」即可。
2. 进入内部存储 → Download / Downloads 文件夹。
3. 按日期从新到旧排序，刚下的文件就在最上面。
4. 不记得文件名就搜文件名里的几个关键词（比如 `invoice`），别整串去搜。

图片类文件通常还会额外出现在相册里；文档、压缩包、APK 只在 Download 文件夹。

## 三、点了「下载」却像没反应

多数时候是**下载确认条出现在页面底部，没滑到底根本看不见**，于是你以为没开始、又点了好几次。点完下载链接先往页面底部滑，找带「显示详情」字样的下载条，确认一下。

嫌每次找文件麻烦，可以开「保存前询问每个文件的位置」：三点 → 设置 → 下载 → 打开该开关，以后每下一次都会让你选目录，文件去哪一目了然。下载目录显示为 SD 卡而卡已拔出时，也会下不进去，把它切回内部存储再试。

## 四、下载失败或一直暂停

按代价从小到大查：

| 检查 | 怎么做 |
| --- | --- |
| 网络 | 先确认网页能正常打开，不能就按 [打不开网页怎么办.md](打不开网页怎么办.md) 处理 |
| 存储空间 | 设置 → 存储，确认剩余空间大于文件体积 |
| 文件权限 | 设置 → 应用 → Chrome → 权限，确认「文件和媒体」没被禁止 |
| 后台数据 | 设置 → 应用 → Chrome → 移动数据，确认允许后台使用，否则一切后台就停 |
| 省流量 / 数据节省 | 系统省流量模式开着时部分下载会异常，先关掉测一次 |
| VPN | 有开就先关，隧道中断会让下载停在一半 |
| 缓存 | 上述都正常仍失败，按 [闪退卡顿怎么修.md](闪退卡顿怎么修.md) 清一次缓存 |

卡在半路的下载：进 三点 → 下载，点条目旁的「继续」；提示失败的，删掉这条记录，回原网页重新发起（对方服务器不支持续传时只能重来）。
