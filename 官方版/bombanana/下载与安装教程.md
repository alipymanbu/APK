## 一、先分清你要装的是哪一版

BOMBANANA! 目前有两个不同的东西，别混在一起：

| | Steam PC 版 | 安卓安装包（本篇讲的这份） |
| --- | --- | --- |
| 来源 | 官方在 Steam 发售的正版，开发 Lefto Studio、发行 TARK | 第三方安卓渠道流传的 APK 包 |
| 平台 | Windows 电脑 | 安卓手机 |
| 版本 | 随官方更新 | 1.0 |
| 怎么拿 | [Steam 商店页](https://store.steampowered.com/app/4656000/BOMBANANA/)，2026-09-02 发售 | 夸克网盘（见下方） |

如果你和朋友都想在电脑上玩，走 Steam 买正版是最直接的路；想在手机上体验，就用下面这份安卓包。

## 二、获取安卓安装包

安装文件放在夸克网盘里，按这个流程取：

1. 打开 [BOMBANANA! 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8d6f18590ece)；
2. 把文件转存到自己的网盘（夸克分享链接需先转存才能下载）；
3. 在夸克网盘客户端里把 APK 下载到手机本地存储。

## 三、安装步骤

拿到 APK 之后：

1. 在手机文件管理器里找到下载好的 APK，点它开始安装；
2. 系统如果提示「禁止安装未知来源应用」，按提示允许该文件管理器或浏览器安装应用（不同品牌手机入口不同，一般在弹窗里点「设置」→「允许此来源」）；
3. 等安装完成，桌面出现图标即可打开。

安装完成后，联机玩需要凑齐三个人，角色怎么分工看 [三不猴角色分工.md](三不猴角色分工.md)。

## 四、装之前核对一下文件

安卓包来自第三方渠道，装之前花十秒核对文件信息，能避免装错包：

| 项目 | 数值 |
| --- | --- |
| 版本 | 1.0 |
| 包名 | `com.zdh.game` |
| 大小 | 2.70 MB |
| MD5 | `241A6328492C0A66AC16D81832ABB952` |

核对方法：用文件管理器或第三方工具查看 APK 的属性/详情，多数工具支持显示 MD5。数值对得上，说明文件完整；对不上就不要装。

## 五、装好之后

打开游戏如果碰到问题（闪退、进不去联机等），先看 [新手常见问题.md](新手常见问题.md)；确定能进了，就研究三个猴子的分工——这游戏的全部难点都在「怎么把话说清楚」上。
