## 一、两条路怎么选

用 AIaW 之前，你得先让它连上一个模型。有两条路：

| 路线 | 你要做什么 | 适合谁 |
| --- | --- | --- |
| 内置模型服务 | 登录官方账号，不用配置 | 不想折腾 Key 的人 |
| 自己配 API | 在设置页填服务商的 API Key | 已有 OpenAI / Anthropic / Google / DeepSeek 等账号或中转 Key 的人 |

内置模型服务是官方（aiaw.app）随账号提供的：登录即可用，不用自己找 Key，按所用模型对应的官方 API 原价从额度里扣，额度随用随充（截至本文整理时的规则，以官方页面为准）。自部署版本没有这项服务。

自己配 API 则是你直接向模型服务商付费、拿 Key 填进来，AIaW 本身开源且免费，不在这条路上加价。

## 二、自己配 Key：单个服务商的步骤

1. 打开应用的**设置**页面；
2. 在服务商列表里选中你要用的那家（OpenAI、Anthropic、Google、DeepSeek、xAI、Azure 等）；
3. 核对**服务商类型**、**API 地址**，填入你的 **API Key**；
4. 回到对话，发一条消息测试能不能正常回复。

最容易踩的坑是 **API 地址末尾要带 `/v1`**：填 `https://api.xxx.com/v1` 而不是 `https://api.xxx.com`。这是官方常见问题清单里点名的第一类「服务商用不了 / 回复为空」的原因。

另外，服务商类型要选对家：例如用 DeepSeek 官方或硅基流动时，类型要选 DeepSeek 而不是 OpenAI，否则像 `deepseek-reasoner` 的推理内容（思维链）不会显示出来——OpenAI 原版格式里没有这个字段。

## 三、多服务商并行：自定义服务商

如果你同时在用几家服务商、想让不同模型走不同的家，就用「自定义服务商」：

1. 在设置里新建一个自定义服务商；
2. 给不同的模型名指定不同的上游（比如 `gemini-2.0-flash` 走 Google，`qwen-2.5-7b` 走某个 OpenAI 格式的中转站）；
3. 设置一个兜底服务商，其余模型都走它。

建好的自定义服务商是一个普通选项，你可以把它设为默认服务商，也可以只给某个助手用（助手与模型怎么搭配，见[助手配置与分享方法](助手配置与分享方法.md)）。

**模型名重映射**用 `::` 写：左边是你在对话里用的名字，右边是实际请求发的名字。比如 `qwen-2.5-7b::Qwen/Qwen2.5-7B-Instruct`，表示你对话时只写 `qwen-2.5-7b`，实际请求发给服务商的是完整名。中转站的模型名常带前缀，这个写法能省很多手动改名。

## 四、网页版和客户端的差别

- **网页版**（aiaw.app）：受浏览器跨域规则限制，少数服务商的 API 调不通；能不能通取决于服务商有没有放开跨域。
- **Android / 桌面本地客户端**：没有跨域限制，个别不允许跨域调用的服务商也能用。这也是「同样的 Key 在网页版报错、在客户端正常」时最常见的原因。

配好之后，你可以去[功能入门与使用技巧](功能入门与使用技巧.md)看怎么把不同模型分配给不同的助手；发消息报错时，按报错原文在[常见报错与解决办法](常见报错与解决办法.md)里对号入座，最快。
