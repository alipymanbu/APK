# AIaW 数据备份与云同步

> AIaW 的对话数据默认只存在你设备本地，本篇讲它怎么同步、怎么导出备份、换机或卸载前该做什么。

## 一、数据先存在本地

工作区、助手、对话、消息、设置，这些都先存在你设备本地。由此带来的使用体验是：切换对话不用等加载、断网也能翻历史记录。

这也意味着一件你要放在心上的事：**卸载应用或清掉应用数据，本地数据就没了**。要么开云同步，要么在动这些操作之前先导出一份（见第三节）。

## 二、云同步：登录即可开，付费功能

登录账号后云同步自动开启，同一账号的多台设备之间数据实时同步。计费规则（截至本文整理时，以官方页面为准）：

- 注册后先给 **30 天试用**；
- 之后继续用需要付费，**约 ¥1.8 / 月**（英文页口径为 $0.4 / 月）；
- 这项服务只由官方站（aiaw.app）和官方客户端提供；自部署版本有没有云同步取决于部署时的配置，不由官方运营。

不登录、不开同步也能一直用，只是数据只在那一台设备上。

## 三、导出与导入：自己动手备份

位置在应用的**设置页面底部**，「用户数据」一栏：

- **导出**：得到一个 JSON 文件，里面是工作区、助手、对话、设置等全部内容，可以存到网盘或任何地方留底；
- **导入**：选一个之前导出的 JSON 还原，也可以用来把数据搬到另一个站点（比如从官方客户端搬到自部署的站）。

两条边界要知道：

1. 导入导出**不能**用来在同一站点的两个已登录账号之间转移数据，会有主键冲突；
2. 导出的 JSON 是某一时刻的快照，重要对话建议阶段性导一次，别等到要卸载了才想起。

只想把单个助手发给别人（或自己留档），不用全量导出——助手设置页底部有单独的导出入口，见[助手配置与分享方法](助手配置与分享方法.md)。

## 四、项目已停更：迁移到 Nya AI

AIaW 已经停止维护，作者的新项目是 **Nya AI**（网页版 [https://nyaai.cc](https://nyaai.cc) ，开源仓库 [https://github.com/NitroRCr/nyaai](https://github.com/NitroRCr/nyaai)）。官方给了现成的迁移路子：

1. 在 AIaW 的**设置**页底部，用「用户数据 → 导出」导出 JSON；
2. 打开并登录 [https://nyaai.cc](https://nyaai.cc) ；
3. 在 Nya AI 的**设置**页底部点「导入数据」，选中刚导出的 JSON；
4. 等导入完成，数据会出现在当前工作区根目录下一个名为「AIaW Import」的文件夹里。

要不要现在就搬，取决于你：AIaW 作为本地客户端短期内仍可正常使用，但不会再有更新；Nya AI 那边需要登录使用、数据以服务器为中心，定位和 AIaW 不同。两边口径不同这一点，官方迁移文档里写得很直白。

## 五、换机 / 卸载前的动作清单

1. 确认云同步开着（要继续用官方同步），**或者**导出一份 JSON 存好；
2. 新设备装好后登录同一账号，或导入 JSON；
3. 核对新设备上历史对话都在，再动旧设备。

装应用本身见[下载与安装教程](下载与安装教程.md)；数据搬完想恢复日常使用，看[功能入门与使用技巧](功能入门与使用技巧.md)。
