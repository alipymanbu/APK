## 一、这是个什么应用

AIaW（全称 AI as Workspace）是一个开源的 AI 对话客户端。你可以在同一个界面里使用 OpenAI、Anthropic、Google、DeepSeek、xAI、Azure 等服务商的模型（截至本文整理时，以官方页面为准），对话数据默认存在本地，换设备可以开云同步。

它有 Windows、Linux、macOS、Android 本地客户端和一个网页版（PWA），各平台功能基本一致。本篇对应的是 Android 安装包。

版本与体积以本文整理时网盘里那份包为准：**版本 1.7.11，安装包约 5.85M，包名 `app.aiaw`**。官方后来有没有发新版，以 GitHub Releases 页面显示为准。

有一件事你需要提前知道：AIaW 项目已经停止维护，作者建议老用户迁移到后续的新项目 Nya AI。这不妨碍你现在把这份包装上、正常使用，但如果你打算长期存大量对话数据，建议顺手把导出备份的做法也了解一遍，见[数据备份与云同步](数据备份与云同步.md)。

## 二、从哪里获取安装包

两条路，差别只在版本号新旧：

1. **本篇配套的 AIaW 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/8d1a1eee1c36](https://pan.quark.cn/s/8d1a1eee1c36) —— 打开链接转存到自己的夸克网盘，再从网盘下载，拿到的是本文整理时的 1.7.11 版。
2. **官方渠道 GitHub Releases**：[https://github.com/NitroRCr/AIaW/releases/latest](https://github.com/NitroRCr/AIaW/releases/latest) —— 版本随官方更新，在资产列表里找文件名带 `android` 的 `.apk` 文件下载。

如果你只想要「能装、能用」，两条路随便选；如果你在意版本号，以 Releases 页面为准。

## 三、安卓手机安装步骤

1. 把 APK 下载到手机存储（从网盘下载，或用手机浏览器打开 Releases 页下载）；
2. 在文件管理器里点开这个 APK；系统大概率会提示「禁止安装未知来源应用」，在弹窗里选择允许本次安装（不同品牌的手机叫法略有差别，一般在弹窗里直接给开关）；
3. 等待安装完成，打开应用。

装完之后第一件事是配置模型来源（没有模型它没法对话），做法见[API服务商配置方法](API服务商配置方法.md)。

## 四、不想装 App：网页版与 PWA

浏览器直接访问 [https://aiaw.app](https://aiaw.app) 就能用，数据同样存在本地、登录后可云同步。两点差别你需要了解：

- **跨域限制**：网页版受浏览器跨域规则约束，少数服务商的 API 在网页版里调不通，装本地客户端则没有这个限制；
- **安装成 PWA**：手机浏览器（建议较新版本的 Chrome 之类 Chromium 内核浏览器）菜单里通常有「安装应用」选项，装完桌面会多一个独立图标，从独立窗口打开，体验接近本地应用。

## 五、确认装的是什么版本

打开应用后，点左侧边栏顶部的 Logo，会显示当前版本号。你可以用它核对拿到的包是不是 1.7.11。
