## 一、切换引擎是 Yeardx 最常用的操作

同一个关键词换个引擎搜，结果常常完全不同 —— 冷门问题、资源找不着时，换引擎比重写关键词更管用。Yeardx 把五个引擎放进同一个搜索框，切换不用退出、不用重新打字。本篇讲清切换的完整动作和几个提高效率的技巧。

## 二、一键切换搜索引擎（五步）

1. 打开 Yeardx，主页正中是搜索框。
2. 看搜索框**左侧**显示的引擎名（比如「百度」），这就是当前激活的引擎。
3. 轻触这个引擎名，下方弹出引擎选择菜单。
4. 点你要用的引擎（如「夸克」「必应」），搜索框左侧的名称与图标立刻变更。
5. 输入关键词搜索，结果就由新引擎返回。

关键点：**已输入的搜索词在切换后会保留**，不用二次打字 —— 所以可以先打好词，再换引擎对比结果。

## 三、五个引擎怎么选

| 引擎 | 相对更适合搜什么 |
| --- | --- |
| 百度 | 中文综合内容、百科、国内站点 |
| 搜狗 | 中文综合、公众号等微信生态内容 |
| 夸克 | 简洁结果页、网盘与移动端资源 |
| 360 | 中文综合、国内站点 |
| 必应 | 英文内容、国外站点 |

这张表是按各家引擎的一般特性整理的使用参考，不是谁优谁劣的结论 —— 实际以你搜同一个词的返回结果为准，哪个引擎对你有用就固定用哪个。

**同一关键词建议至少换两个引擎对比**，尤其这三类搜索：找官网（有用户反馈百度结果里官网常被推广位挤到后面，必应的官网链接更常排在首位）、找技术/教程贴（各引擎收录的社区不同，A 引擎没有的 B 引擎可能有）、找国外资料（走必应）。这类差异是多个论坛用户共同反馈的共性体验，不是每词必现 —— 你自己的两次对比结果才是准绳。

截至 2026 年初的第三方统计，百度仍占国内搜索市场约五成以上份额、必应在桌面端增速明显（数据会随时间变化，以统计方当时口径为准）。份额只说明「多数人在用哪个」，不决定「哪个对你这个关键词好用」。

## 四、首页不止有搜索框

- **常用网站导航**：搜索框下方有一排网站卡片（拼多多、B站、抖音、爱奇艺等直达入口），点一下直接进，不用先搜再点。
- **实时热搜**：首页带热搜榜，点「换一换」可以刷新一批，适合不知道搜什么的时候找线索。
- **书签卡片**：你保存过的书签会以小卡片排在搜索框下方，下次启动一键直达（管理方式见 [书签与浏览记录管理.md](书签与浏览记录管理.md)）。

## 五、浏览手势与页内操作

| 操作 | 动作 | 作用 |
| --- | --- | --- |
| 返回 | 页面边缘向右滑 | 回上一页 |
| 前进 | 页面边缘向左滑 | 去下一页 |
| 刷新 | 页面顶部用力下拉 | 重新加载 |
| 放大文字 | 双击文本块 | 自动缩放到适合屏宽的阅读比例 |
| 页内查找 | 底部菜单里的查找功能 | 在长页面里定位关键词 |
| 分享 | 底部菜单里的分享 | 把当前页面发给别人 |

单手滑动返回/前进是用得最多的两个手势，习惯之后比找返回按钮快。老站点排版错乱时，双击缩放配合下面第六节的自适应排版最有效。

## 六、老网站在手机上排版乱怎么办

不少学术站点、老论坛没有做移动端适配，在手机上会文字超宽、图片错位。Yeardx 会自动重排这类页面的图文宽度；如果个别页面仍然挤，先双击文本区域放大到合适比例，再配合 [常见问题排查与解决.md](常见问题排查与解决.md) 里的清理步骤刷新一次，多数情况能恢复正常阅读。
