## 一、pikapika 和 pic2acg 是什么关系

一句话：同一个开源项目，先后两个名字。项目在 GitHub 上的仓库一直叫 pikapika（[github.com/ComicSparks/pikapika](https://github.com/ComicSparks/pikapika)），而安卓应用名与包名后来换成了 pic2acg、包名 `opensource.pic2acg`。所以你会同时看到两个名字：谈仓库、源码时用 pikapika，谈手机上装的那个 App 时用 pic2acg。

## 二、对使用者的三个实际影响

| 场景 | 怎么判断 |
| --- | --- |
| 搜教程搜到 pikapika 的文章 | 核心操作可以对照着用，按钮文案随版本可能略有出入 |
| 应用商店里看到旧包 | 认准包名 `opensource.pic2acg` 再装；包名对不上就不是这一个 |
| 网上说「pikapika 更新了」 | 说的是同一个项目，新版本以仓库 Releases 页为准 |

## 三、下载时别装错

- 你手里这份安装包的核对信息：版本 1.8.17、包名 `opensource.pic2acg`、大小 20.90M、MD5 487B3E9F54F64C0135CD9716AEF900F8；
- 获取入口见 [下载与安装教程.md](下载与安装教程.md) 的第二节；
- 包名对不上的「同名」安装包来历不明，不要装。

## 四、旧教程还能照着做吗

解锁计算器、注册登录、下载缓存这些核心操作的思路是一致的，可以照做；按钮文案随版本略有差异，以应用内显示为准。账号相关步骤见 [账号注册与登录.md](账号注册与登录.md)。
