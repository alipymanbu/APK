## 一、先进入应用再注册

pic2acg 连接的是对应的漫画平台，内容需要登录账号后使用。前提是先完成首次解锁：打开应用看到计算器界面时，按 [打开是计算器怎么办.md](打开是计算器怎么办.md) 里的方法进入。

## 二、注册一个新账号

1. **选一条能连上的线路**：登录页一般会给出多个分流线路，选一个当前能连通的（连不上就换下一条，排查思路见 [图片加载失败怎么办.md](图片加载失败怎么办.md)）；
2. **点注册入口**：在登录页找到注册按钮，不同版本的文案略有差异，以应用内显示为准；
3. **填写注册资料**：账号（登录 ID）、密码、昵称、生日等——生日需要年满 18 周岁，这是平台的注册门槛，填小了过不了；
4. **提交并返回登录**：注册成功后回到登录页，用刚注册的账号密码登录。

两个第三方建议：登录 ID 和密码不要照搬你常用网站的那套；昵称想好再填，社区评论发出去之后删不掉。

## 三、登录 ID 的几个规则

用这类客户端，坑最集中的地方是登录 ID，整理如下（以应用内实际提示为准）：

- 登录 ID 里的英文字母需要**全部小写**，混入大写容易触发「重复」类报错；
- 忘记登录 ID 基本找不回来，只能换个 ID 重新注册一个新账号；
- 忘记密码时按应用内的找回或更新流程处理，前提是你还记得登录 ID；
- 想更新登录 ID 的，平台常见解答是先用电邮登录，再按账号设置里的提示更新，字母保持全小写（入口以应用内显示为准）。

所以注册时把 ID 和密码记在只有你自己能看到的地方，比什么都管用。

## 四、注册与登录报错对照

| 报错/现象 | 处理 |
| --- | --- |
| 提示登录 ID 重复 | 确认字母已全部小写；仍重复就换一个 ID |
| 提示昵称重复 | 换一个昵称再提交 |
| 生日无法通过 | 按年满 18 周岁填写出生日期 |
| 一直转圈、连不上 | 多半是线路问题，换分流线路或按 [图片加载失败怎么办.md](图片加载失败怎么办.md) 排查 |

## 五、换设备与账号数据

换了新手机不需要重新注册，直接在新设备上登录同一账号即可，收藏等数据跟随账号（以实际使用为准）。之前设备上下载好的漫画想搬过去，看 [离线缓存与导入导出.md](离线缓存与导入导出.md)。

另外一种「收藏变少」与设备无关：作品下架后，对应的收藏找不回来（这是社区常见解答）。所以换机后先联网刷新一次收藏，少的那几部再对照判断是不是作品本身下架了，别急着怀疑账号出了问题。
