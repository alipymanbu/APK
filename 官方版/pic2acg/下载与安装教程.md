## 一、pic2acg 是什么，安装前先核对什么

pic2acg 是一款开源的漫画阅读客户端，界面里没有广告，支持分类浏览、搜索、排行榜、离线下载与评论互动，安卓上以应用名 pic2acg、包名 `opensource.pic2acg` 发布，前身是开源项目 pikapika。适合想用手机追漫画、同时在意界面干净与隐私的人。

动手装之前，建议先核对下面这几项——这是网盘里那份安装包的实际信息，网上搜到的可能是更新的版本号，两者不是一回事：

| 项目 | 数值 |
| --- | --- |
| 应用名 | pic2acg |
| 版本 | 1.8.17 |
| 包名 | `opensource.pic2acg` |
| 安装包大小 | 20.90M |
| MD5 | 487B3E9F54F64C0135CD9716AEF900F8 |
| 系统要求 | 安卓 5.2 以上（以安装时实际检测为准） |
| 收录时间 | 2026-09-23 |

想知道有没有比 1.8.17 更新的版本，可以看官方源码仓库的 Releases 页：[github.com/ComicSparks/pikapika](https://github.com/ComicSparks/pikapika)，以页面当时显示为准。

还有一个搜资料时的高频困惑：大量教程、讨论区和商店页面里出现的 pikapika，其实就是这个项目的曾用名——仓库至今还叫 pikapika，应用名与包名已换成 pic2acg（`opensource.pic2acg`）。两者的对照关系与避坑方法见 [为什么搜到的是pikapika.md](为什么搜到的是pikapika.md)。

## 二、获取安装文件

pic2acg 安装文件资源（夸克网盘）在 [https://pan.quark.cn/s/4c730e42c2cd](https://pan.quark.cn/s/4c730e42c2cd)，拿包路径：

1. 打开上面的链接，把文件先转存到自己的夸克网盘；
2. 手机上装好夸克 App 并登录同一账号；
3. 在网盘里找到刚转存的 apk 文件，下载到手机本地存储。

如果你是在电脑上转存下载的，可以用一条命令核对文件完整性，输出应与第一节表格里的 MD5 一致（不一致多半是没下载完整）：

```text
certutil -hashfile pic2acg_v1.8.17.apk MD5
```

## 三、安装步骤

1. 在手机文件管理里找到下载好的 apk，点它；
2. 系统第一次会提示「不允许安装未知来源应用」，按提示允许本次安装（不同品牌叫法略有差异，一般在弹窗里点「设置」→ 打开「允许安装」再返回）；
3. 回到安装界面，点「安装」，等待完成；
4. 装完点「打开」，你会看到一个计算器界面——这不是装错了，进入方法见 [打开是计算器怎么办.md](打开是计算器怎么办.md)。

两处系统级适配顺带知道一下：安卓 10 及以上会跟随系统切换深色模式；90/120/144Hz 这类高刷新率屏幕有专门适配。

## 四、安装失败的常见提示

| 提示 | 可能原因与处理 |
| --- | --- |
| 解析包时出现问题 | 安装包没下载完整（重新下载并核对 MD5），或手机系统版本低于要求 |
| 签名不一致 / 存在冲突 | 手机里装过同包名的其他版本，先卸载旧的再装（卸载会清掉它自己的本地数据） |
| 存储空间不足 | 清理出足够空间（安装包本身 20.90M，安装过程还需要额外余量） |
| 安装按钮置灰 | 部分手机管家拦截了安装，到系统设置里允许该来源后再试 |

装好并进入应用之后，接下来两件事是解锁计算器界面和登录账号，分别见 [打开是计算器怎么办.md](打开是计算器怎么办.md) 与 [账号注册与登录.md](账号注册与登录.md)。
