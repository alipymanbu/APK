## 一、安装阶段

| 症状 | 原因与处理 |
| --- | --- |
| 点 APK 提示「解析包出错」 | 系统低于 Android 6.0，或安装包下载不完整 —— 重下（MD5 校验方法见 [下载与安装教程.md](下载与安装教程.md)） |
| 提示「应用未安装」 | 手机里已有同包名但签名不同的旧包（比如别处下的改包），先卸载再装 |
| 提示「禁止安装未知来源」 | 去设置给文件管理器/浏览器开「安装未知应用」，返回继续安装 |
| 安装后图标打不开、闪退 | 多为系统厂商的「纯净模式/安全守护」在拦截，临时放行或加入白名单 |

## 二、没声音 / 节拍不准

1. 先分清是媒体音量还是铃声音量 —— 节拍声走媒体通道，把媒体音量调大；
2. 看设置里的节拍音色是否被切到了静音组合，重音/弱音音量差是不是被拉到了 0；
3. 连着蓝牙耳机时声音可能路由到了另一台设备，断开蓝牙再试；
4. 手机开了静音模式/勿扰的，先把媒体静音关掉。

若声音发闷或有爆音，切一套官方音色包（内置 7 套）对比，能快速判断是音色问题还是手机扬声器问题，详见 [节拍器功能使用指南.md](节拍器功能使用指南.md)。

## 三、调音器取不到音频 / 指针不动

最快的定位法：先用系统录音机录 5 秒 —— 录音机有波形就只查 Chronal 的麦克风权限，没波形就是系统总开关或硬件的事。完整的分层排查（二分测试、应用权限三处、Android 12 麦克风总开关、麦克风被独占、版本差异对照）已单独成篇：[调音器取不到声音怎么办.md](调音器取不到声音怎么办.md)。

## 四、耗电、后台存活与权限

- 调音器开着会持续占麦克风，不用时手动关掉。v1.1.1 加了「组件不活动自动停止」，0.2.1 请自己记得关；
- 节拍器要后台出声，就保留通知栏的常驻通知（前台服务）—— 手动划掉通知 = 节拍停；
- 电池优化把 Chronal 设为「不优化」，否则系统会在锁屏后掐断音频。

首次运行时它会要几项权限，各自对应你正在用的功能（清单来自 F-Droid 商店页，以官方页面当时显示为准）：

| 权限 | 你用到它的场景 |
| --- | --- |
| 麦克风 / 录音 | 调音器拾音、麦克风实时测 BPM |
| 前台服务 + 显示通知 | 切后台、锁屏后节拍继续出声（通知栏常驻条就是它） |
| 控制振动 | 跟拍时的节拍振动 |
| 防止手机休眠 | 练习过程中不让屏幕/音频被系统掐掉 |
| 开机启动、精确闹钟 | 官方未说明具体用途，不需要可在系统里拒绝；用到对应功能（如练习提醒类）再放行 |

拒绝麦克风不会影响节拍器，只影响调音与测速；拒绝通知则后台出声会被系统掐。

## 五、某个功能找不到：版本差异对照

网盘里的包是 0.2.1，官方最新已到 1.1.x —— 界面和入口对不上时先看这张表（完整日志见 [GitHub releases](https://github.com/cognitivitydev/Chronal/releases)）：

| 功能 | 首次出现版本 | 说明 |
| --- | --- | --- |
| 音频播放器 | 0.2.0 加入，1.1.0 移除 | 新版找不到播放器入口是正常的 |
| 3 个桌面小部件 | 0.2.0 | 预设列表 / 单个预设 / 调音器 |
| 展开式调音曲线 | 0.2.0 | 大屏、横屏布局下显示 |
| `.chp` 预设分享导入 | 0.2.1 | 网盘版本就有 |
| BPM 上限提高到 800 | 1.0.1 | 0.2.1 的上限低于此值，以界面可输入范围为准 |
| 手势自定义、练习提醒 | 1.0.1 | 0.2.1 没有 |
| 节拍轨道（替代双节拍器）、Grid 显示 | 1.1.0 | 入口名称变了，0.2.1 是两个同步节拍器 |
| 调音器自动停、取音失败警告 | 1.1.1 | 0.2.1 没有 |
| 弦乐调弦模式、Pie 显示、语言切换 | 1.1.2 | 0.2.1 没有 |

**怎么升级**：F-Droid 客户端装的用客户端更；Google Play 装的走商店；直接下 APK 的（含网盘这份）需重新下载覆盖安装，包名相同即可覆盖，但**签名必须一致**，签名不同就得先卸载（自定义预设会丢，`.chp` 导出的不受影响）。
