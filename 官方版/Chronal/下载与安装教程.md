## 一、这是什么应用

Chronal 是一款面向乐器学习者与演奏者的安卓节拍器 + 调音器二合一应用，开发者是 GitHub 上的 `cognitivitydev`，完全免费、无广告、无需注册登录，也不需要 root。它的两个核心用途：练节奏时给你稳定的节拍与可视化提示，练音准时用麦克风帮你校音。

本篇只讲获取与安装；装好之后怎么用，见 [节拍器功能使用指南.md](节拍器功能使用指南.md) 与 [调音器使用教程.md](调音器使用教程.md)。

## 二、先确认手机能不能装

| 项目 | 要求 |
| --- | --- |
| 系统 | Android 6.0 及以上（官方从 v0.2.0 起支持 SDK 23+，具体以安装包实际提示为准） |
| 架构 | 通用 APK，主流 arm64 / arm 手机都能装 |
| 账号 | 不需要注册、不登录就能用全部功能 |
| 联网 | 使用本身可离线，只有更新、反馈时需要联网 |

如果安装时提示「解析包出错」或「应用未安装」，多半是系统版本过低或存储空间不足，处理办法见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 三、安装包从哪拿

你有四个选择，装的都是同一个应用（包名 `dev.cognitivity.chronal`）：

1. **夸克网盘（推荐先用这个）**：[Chronal 安装文件资源（夸克网盘）](https://pan.quark.cn/s/220545991af0) —— 转存后直接下载 APK。
2. **Google Play**：[Chronal - Google Play](https://play.google.com/store/apps/details?id=dev.cognitivity.chronal) —— 装完自动收更新，国内网络可能访问不稳定。
3. **F-Droid**：[Chronal - F-Droid](https://f-droid.org/packages/dev.cognitivity.chronal/) —— 开源仓库，用 F-Droid 客户端安装才会收到更新提醒；直接下载 APK 安装则不会有任何更新通知。
4. **GitHub 发布页**：[cognitivitydev/Chronal releases](https://github.com/cognitivitydev/Chronal/releases) —— 每个版本的更新日志都在这里。

### 网盘里那份包的事实信息

网上各处能搜到的多是官方最新版，而网盘里那份是固定留档的一版，两者常常不是同一个版本。凡涉及版本号、包名、大小，以网盘这份的实测信息为准：

| 项目 | 值 |
| --- | --- |
| 版本 | 0.2.1 |
| 包名 | dev.cognitivity.chronal |
| 大小 | 15.21M |
| MD5 | `E30659311B28E2E0B853C7289408F12A` |
| 记录于 | 2026-09-23 |

官方版本号是三段式（如 `0.2.1`、`1.1.3`），最新版以官方页面当时显示为准。你想要最新功能（比如 1.1.x 的多节拍轨道、语言切换），装官方渠道的最新版即可；想和本套文档的截图、步骤完全对得上，就用网盘里的 0.2.1。

## 四、安装步骤

1. 从上面任一渠道把 APK 下载到手机（或先下到电脑再传过去）。
2. 下载完成后点击文件，系统会弹「禁止安装未知来源应用」—— 这是正常的，点去设置，给你的文件管理器或浏览器打开「安装未知应用」权限，再返回安装。
3. 装完打开，首页就是节拍器，点播放按钮直接能响，没有引导页、不索要登录。
4. 第一次用调音器时会弹麦克风权限申请，点允许 —— 不允许的话调音器与麦克风测速都不可用，详见 [调音器使用教程.md](调音器使用教程.md)。

### 校验安装包没被改过（可选）

下载后可在电脑上核对 MD5 是否与上表一致。Windows PowerShell：

```powershell
Get-FileHash -Algorithm MD5 .\Chronal_v0.2.1.apk
```

输出的哈希值应为 `E30659311B28E2E0B853C7289408F12A`（不区分大小写）。对不上就重新下载，别装来路不明的改包。

## 五、装完能立刻做什么

- 首页中间调一个合适节拍，点下方播放键开始打拍；
- 进设置把音色、振动按习惯调好；
- 想从桌面快速开关节拍器，可以加它自带的桌面小部件（需要的版本见 [常见问题与故障排查.md](常见问题与故障排查.md) 的版本差异表）。
