# LockMyPix 假保险箱与伪装模式

这三项都在 LockMyPix 的设置（Settings）里，各自解决一个不同的问题：

| 功能 | 解决的问题 | 入口 |
| --- | --- | --- |
| 假保险箱（Fake Vault） | 被人逼着输密码，输完也不能露馅 | 设置 → *Fake Vault* |
| 伪装模式（Disguise Mode） | 不让任何人发现手机里装着这个应用 | 设置 → *Disguise Mode* |
| 入侵者自拍（Intruder Selfie） | 有人偷翻你的手机时留下对方照片 | 设置 → *Intruder Selfie* |

## 一、假保险箱：输另一组密码进另一个空间

做法是预先准备一个「能见人」的第二保险箱：

1. 打开设置，选 *Fake Vault*；
2. 给它设一个与主保险箱**不同**的密码；
3. 退出登录。之后输入这个新密码，打开的就是假保险箱，里面是一个完全独立的空间。

官方给的使用建议：往假保险箱里放几张普通、不敏感的照片或文件，这样别人翻看时不会起疑。真被要求当面打开手机时，你输假密码即可——对方看到的是一个普通的相册应用。

注意两点：

- 假保险箱密码也要记牢，两个密码你自己要分得清哪个对应哪个空间；
- 两个空间互不相通，主保险箱里的内容不会出现在假保险箱里。

## 二、伪装模式：图标和登录界面都能换

伪装模式让整个应用从桌面上「消失」：

1. 打开设置，选 *Disguise Mode*；
2. 在列表里挑一个想伪装成的图标（比如计算器、购物应用之类的日常图标）；
3. 部分图标还支持把**登录界面一起伪装**（官方标注仅安卓版支持），选带此扩展的图标并在设置里启用伪装登录页，效果最完整。

**伪装状态下怎么进入真身**：在伪装出来的登录界面上，**长按任意元素一秒**；如果伪装成了计算器，就长按等号。正常登录界面随后出现，照常输密码即可。

伪装模式配合假保险箱是官方推荐组合：图标先藏起来，万一被翻到还能用假保险箱兜底。

## 三、入侵者自拍：谁动过你的手机，留照片为证

开启后，只要有人在登录界面输错密码尝试闯入，应用会悄悄拍一张前置照片：

1. 打开设置，选 *Intruder Selfie*；
2. 打开开关，确认弹出的相机权限；
3. 权限作用域选「仅在使用中允许」（*while using the app*）——官方特别提醒用其他作用域的话功能可能受限。

**在哪看拍到的照片**：还是设置 → *Intruder Selfie*，列表里就是抓拍到的入侵者，每张都带日期和时间。

## 四、优先级建议

如果只开一项，先开入侵者自拍（零成本、随时生效）；担心应用图标本身引人注意，再上伪装模式；需要应对「当面被迫打开」的场景，才配置假保险箱。三项互不冲突，可以同时开启。相关的基础设置（指纹解锁、SD 卡等）见 [指纹解锁与SD卡设置.md](指纹解锁与SD卡设置.md)。
