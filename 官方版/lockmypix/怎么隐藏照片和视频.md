# LockMyPix 怎么隐藏照片和视频

> 本篇讲 LockMyPix 的核心操作：把照片、视频、文档导入保险箱、在保险箱里播放与导出，以及从其他应用直接分享进来。

## 一、先记住一个入口

保险箱内所有「往里放东西」的操作都从右下角的 **+ 号**开始：点开它，再选「Hide photos and documents」（隐藏照片和文档），就能进入手机相册的选择界面。视频没有单独入口，在同一个界面里切到 Videos 标签页即可。

## 二、导入照片

1. 用密码登录保险箱；
2. 点右下角 **+** → 选 *Hide photos and documents*；
3. 界面会列出你手机公共相册里的全部相册，点进任意相册，勾选要藏的照片；
4. 点底部的 *Import* 按钮确认导入。

几个省事的小技巧（官方帮助中心列出的）：

- **导入整个相册**：打开某个相册后一张都不选，直接点 *Import*，整册全部进保险箱；
- **批量多选**：长按某张照片或某个相册进入拖选模式，滑动即可连选多个；
- **导进指定文件夹**：先在保险箱里建好文件夹，再从那个文件夹里点 **+**，照片会直接落到当前文件夹，不用导入后再挪。

## 三、导入视频

流程与照片一致，只是入口不同：

1. 点右下角 **+** → *Hide photos and documents*；
2. 向右滑动或点 **Videos 标签页**；
3. 勾选视频 → 点底部 *Import*。

视频没有数量或体积上的档位限制，官方页面称大体积视频（最高 8K）也能放进保险箱。实际能不能流畅播放，更多取决于手机本身的解码能力。

## 四、文档也能收进来

证件照、扫描件、合同这类文件走同一个 **+** 入口选择即可。文档与照片、视频可以混放在同一个保险箱里，按你自建的文件夹归类。

另外保险箱里还能建私密笔记（官方帮助中心有 *Create Private Notes* 专篇），文字内容同样受密码保护。

## 五、从聊天应用直接分享进来

不用先存相册再导入：在 WhatsApp、Snapchat 等应用里看到想藏的图片或视频，直接用系统的「分享」菜单发送给 LockMyPix，文件就会进入保险箱。这个方式对「聊天里临时收到、不想留在公共相册」的内容最省事。

## 六、导入之后的管理

- **建文件夹**：保险箱里可以建任意多层级的文件夹和子文件夹，没有数量限制，按人物、事件、类型随意组织；
- **排序整理**：设置里有排序与整理相关的选项，可按自己的习惯调整展示方式；
- **重复文件**：导入多了难免重复，设置里的 *Find duplicates* 可以帮你找出重复项（见 [指纹解锁与SD卡设置.md](指纹解锁与SD卡设置.md) 的设置项速览）。

## 七、导入后，公共相册里的原件还在吗

在——导入动作本身不会删公共相册里的原件，这是设计使然（付费版专门有一个「导入时粉碎原件」的 Shredder 功能，反过来说明默认行为是保留）。所以导入完想彻底清掉痕迹，还需要你自己回到系统相册把原件删掉。两种途径的差别见 [免费版与付费版区别.md](免费版与付费版区别.md) 的 Shredder 一节。

删掉的保险箱文件会先进入回收站（设置页右上角进入），回收站里的文件**不计入任何备份**，恢复方法见 [卸载重装与文件丢失自救.md](卸载重装与文件丢失自救.md)。

## 八、在保险箱里播放视频

保险箱内的视频边解密边播，不用先导出来：

- 系统原生支持的格式默认用内置播放器打开；不支持的类型会自动唤起外部播放器（比如 MX Player）；
- 想全部改用外部播放器：设置 → *Videoplayback*，关掉第一项 *Videoplayer*；
- 播放有问题先换一个外部播放器试试。

内置播放器的手势：

| 操作 | 手势 |
| --- | --- |
| 缩放画面 | 双指捏合 / 张开 |
| 快进快退 10 秒 | 双击屏幕右侧 / 左侧 |
| 音量 / 亮度 | 左侧上下滑动调音量，右侧上下滑动调亮度 |
| 循环播放 | 工具栏的循环按钮（默认对当前文件夹整个列表循环） |

**改视频缩略图**：导入时缩略图自动截取，想换的话播放该视频 → 单击屏幕中间呼出菜单 → 点左上角快门按钮，把当前画面存为新缩略图（重启应用后生效）。

## 九、把文件移出保险箱

两条路，按「只是临时看一下 / 彻底拿回原文件」选：

**临时分享给其他应用**（文件仍留在保险箱里）：多选模式选中文件或文件夹 → 点顶部菜单的分享按钮 → 在弹出的应用列表里选目标应用 → 在目标应用里确认操作。官方设计了三道确认，每一步都能取消，防止误发。注意**别把文件和文件夹混在一次分享里**，否则目标应用可能读不出内容。

**彻底解锁导出**（解密后放回手机存储）：在文件列表长按进入选择模式 → 逐个点选要导出的文件 → 点顶部菜单的解锁按钮 → 用解锁菜单里的蓝色箭头指定导出目标路径，或保留原目录结构。导出后的文件就是普通文件，不再有加密保护，谁能拿到手机谁就能看。

文档类文件还有第三种「打开」方式：在保险箱里点开文档 → 选一个能处理它的应用。要留意的是，在保险箱外对文件做的修改不会自动同步回来——改完把新版本重新导入一次，保险箱里存的才是改后的内容。

导入完成后，最重要的下一步是把备份做好——保险箱文件只存在你这台手机上，换机或丢失前没有备份就没了，操作见 [备份与换机迁移.md](备份与换机迁移.md)。
