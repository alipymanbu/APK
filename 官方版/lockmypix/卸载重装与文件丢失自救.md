## 一、卸载后文件还在不在：安卓与 iOS 答案不同

官方帮助中心对两个平台的说明不一样：

| 平台 | 卸载后 |
| --- | --- |
| 安卓 | **文件保留**。LockMyPix 在安卓上用持久化存储，卸载重装后用原密码登录，保险箱原样回来 |
| iOS | **文件默认随卸载删除**。系统弹出删除警告时不要确认，除非已经做过备份（方法见 [备份与换机迁移.md](备份与换机迁移.md)） |

所以「重装一下应用试试」这个常见操作：安卓上安全，iOS 上会清空保险箱。

## 二、你的文件存在哪

安卓上保险箱的数据集中在一个隐藏文件夹里：**`.LockMyPix`**，位于手机存储的根目录（也有机型在 DCIM 文件夹内），完整路径即 `Storage/.LockMyPix`。

这一条直接决定了两个日常动作的红线：

- **手机清理工具**：清理前确认不会删到 `.LockMyPix` 下的任何文件——官方特别提醒清理工具并不聪明，不看清单一键清理可能把保险箱数据带走；
- **文件管理器**：不要移动或重命名这个文件夹，保险箱靠固定路径找文件。

## 三、登录进去了，但保险箱是空的

官方对此的第一句话是：文件不会自己消失，先回想你最近对手机做过什么。对照这张表逐条排查：

| 你做过的事 | 后果与出路 |
| --- | --- |
| 恢复出厂设置 | 存储被清空（SD 卡也可能波及），只能靠云备份或备份文件恢复 |
| 用过清理工具 | 联系那个清理工具的客服，有些工具有自己的恢复兜底 |
| 拔出过 SD 卡（保险箱在卡上） | 把卡插回去，按官方帮助中心「Use the SD-Card」页的 reimport 指引重新关联 |
| 用文件管理器删过或改名过文件夹 | 删掉的可能是 `.LockMyPix`，没有备份的话要设法找回那个文件夹 |

**内置搜索自救**（适用于 `.LockMyPix` 文件夹被挪动过位置、文件本身还在的情况）：

1. 在登录界面**长按数字 0** 一秒（用密码方式登录的话，长按登录按钮）；
2. 选 *search for files*；
3. 应用会扫描存储里所有关联文件并自动重新挂回保险箱。

前提是文件本身没被手动删除或被清理工具清掉——这个功能只是「重新找到」，不是「凭空恢复」。

**恢复数据文件夹**：如果你另外留有 `.LockMyPix` 文件夹的副本（或其子文件夹 `.encrypt` / `.encrypt_prev`），把它放回手机存储**根目录**（不要放进任何子文件夹，位置相同可直接覆盖），然后用原密码登录。

## 四、删掉的文件先去回收站

在保险箱内删除的文件会先进回收站：设置页右上角的垃圾桶图标进入，可整体恢复或按文件单独恢复（右上角的恢复按钮恢复全部，每个文件右下角的小恢复按钮恢复单个）。

两个必须知道的点：

- 回收站里的文件**不计入云备份，也不计入备份文件**——官方原话提醒。也就是说「回收站里还有」不等于「备份里还有」；
- 回收站无限期保留文件属于付费功能（详见 [免费版与付费版区别.md](免费版与付费版区别.md)）。

## 五、想清空重来了

**能登录**：进设置拉到底，用 *reset* 重置保险箱。官方提醒操作前先备份，删掉的文件没有备份就找不回来。

**登录不进去**：用文件管理器（先在它的设置里打开「显示隐藏文件」），删掉存储根目录或 DCIM 里的 `.LockMyPix` 文件夹。官方建议的更稳妥做法是**改名成 `.LockMyPix-old`** 而不是直接删——万一里面还有你要的东西，改名等于留了一手。

无论哪种清空方式，动手前都建议先把备份文件挪出手机（见 [备份与换机迁移.md](备份与换机迁移.md)）。如果只是密码想不起来了，先别急着清空——找回密码的路子见 [忘记密码怎么找回.md](忘记密码怎么找回.md)。
