## 一、免费版已经有什么

免费版的核心能力与付费版是同一套：照片、视频、文档的 AES 加密隐藏，PIN / 密码 / 图案三种登录方式，不限数量的文件夹与子文件夹，手动生成的加密备份文件，GIF 支持。日常「把照片视频藏起来」这一个诉求，免费版就能完成。

代价是**有广告**：官方说明免费版的广告用于维持开发，Premium 则去掉全部广告。

## 二、Premium 多了什么

下面这张表综合了官方帮助中心「Get Premium」页与 Google Play 商店文案两处说明（截至 2026-09，功能划分以应用内升级页实际显示为准）：

| 功能 | 免费版 | Premium |
| --- | --- | --- |
| 加密隐藏照片 / 视频 / 文档 | 有 | 有 |
| PIN / 密码 / 图案登录 | 有 | 有 |
| 手动加密备份文件 | 有 | 有 |
| 文件夹与子文件夹 | 有 | 有 |
| 广告 | 有 | **无** |
| 假保险箱（Fake Vault） | 无 | **有** |
| 伪装模式（隐藏整个应用） | 无 | **有** |
| 入侵者自拍 | 无 | **有** |
| 云备份（自动更新的加密副本） | 无 | **有** |
| 翻转手机锁定（Flip Lock） | 无 | **有** |
| 粉碎器 Shredder（导入时粉碎公共相册原件） | 无 | **有** |
| 面部 / 虹膜解锁（支持的机型） | 商店文案列为 Pro 独占 | 有 |
| SD 卡存储 | 商店文案列为 Pro 独占 | 有 |
| 回收站文件无限期保留 | 无 | **有** |

两处官方清单的**出入**要留意：帮助中心的升级页没有把面部解锁和 SD 卡列入，而商店文案把它们标为 Pro 独占；回收站无限期保留则只在帮助中心标注了 Premium。你的手机上某项功能点不开时，大概率就是它属于付费范围。

## 三、Shredder 顺带回答了「导入后相册原图还在吗」

导入照片时，LockMyPix 并不会自动删掉公共相册里的原件——否则就不需要 Shredder 这个功能了。所以：

- **免费版**：导入后公共相册里的原件仍在，想彻底移除需要你在系统相册里自行删除；
- **Premium**：开启 Shredder 后，文件从公共存储导入的瞬间原件就被安全粉碎，事后无法用恢复工具找回。

## 四、订阅怎么管理

- **绑定与多机**：升级绑定的是你的 Google 账号或 Apple ID，同一账号下的多台手机都能用；
- **换机后 Premium 没生效**：确认手机登录了购买时用的那个账号；安卓上还不行就重装一次应用（安卓重装不丢数据，原因见 [卸载重装与文件丢失自救.md](卸载重装与文件丢失自救.md)），仍不行可按官方指引从电脑端商店页面远程安装，最后重启手机；
- **价格**：官方未公布统一金额，按国家与渠道而定，以应用内升级页显示为准；
- **退款与取消**：都走 Google Play 或 App Store 的订阅管理，退款资格按商店政策。

## 五、要不要升级的判断

按需判断，不按功能多少：只用来自藏照片视频、不介意广告 → 免费版够用；需要假保险箱 / 伪装这类防窥手段，或想要云备份自动兜底 → 这些恰恰都是 Premium 范围，升级才有。免费版用户别忽略手动备份——没有云备份的免费版，备份文件是唯一的兜底（做法见 [备份与换机迁移.md](备份与换机迁移.md)）。
