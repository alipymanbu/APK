> 密码之外，LockMyPix 还能用指纹、面部解锁开箱，把保险箱搬到 SD 卡，以及用摇一摇、翻转这类动作快速上锁，本篇把这些设置项一次讲清。

## 一、设置项速览

下面这些选项都在 LockMyPix 的设置（Settings）里，按用途分了类：

| 设置项 | 作用 |
| --- | --- |
| Fingerprint（指纹） | 用指纹代替手动输密码 |
| Face / Iris（面部 / 虹膜） | 支持的机型上用面容识别开箱 |
| SD-Card（SD 卡） | 把整个保险箱迁到 SD 卡 |
| Find duplicates（查找重复） | 找出保险箱里重复导入的文件 |
| Design（外观） | 调整界面配色与样式 |

## 二、开启指纹解锁

1. 先在系统里录好指纹；
2. 打开 LockMyPix 设置，选 *Fingerprint* 并开启；
3. 之后登录时直接验证指纹即可，密码仍作为兜底方式保留。

指纹数据不归 LockMyPix 管理也不上传：官方说明验证走安卓系统的可信执行环境（TEE），也就是手机芯片里独立的硬件区域，应用本身拿不到指纹信息。

## 三、面部 / 虹膜解锁

支持面部或虹膜识别的机型上，设置里会出现对应的 *Face / Iris* 选项，开启逻辑与指纹相同。不同品牌、不同系统版本对这类生物识别的支持程度不一致，你的手机上找不到这一项时，以应用内实际显示为准。要注意 Google Play 商店文案把面部 / 虹膜解锁列为 Pro 独占功能（帮助中心升级页未列入），见 [免费版与付费版区别.md](免费版与付费版区别.md)；iOS 版则对应 Face Unlock。具体机型的适配问题可以到官方帮助中心（[https://docs.lockmypix.com](https://docs.lockmypix.com)）查询。

## 四、把保险箱搬到 SD 卡

保险箱默认占内部存储，照片视频多了会很吃空间：

1. 插好 SD 卡；
2. 打开设置里的 *SD-Card* 选项激活；
3. 激活后整个保险箱（含已加密的文件）整体迁到 SD 卡，内部存储随之释放；
4. 想迁回来随时可以，再点一次切回内部存储即可。

两个提醒：

- 搬移前确保 SD 卡质量可靠、读写稳定；保险箱在卡上，卡不在或损坏时自然就打不开；
- 结合备份使用更稳妥——SD 卡上的加密文件同样应该有云备份或备份文件兜底（见 [备份与换机迁移.md](备份与换机迁移.md)）。

## 五、查找重复文件

照片反复导入后容易产生重复项，占空间还不方便整理。设置里的 *Find duplicates* 用于找出保险箱里的重复文件，具体操作以应用内界面为准。建议每次大批量导入（比如整册导入，见 [怎么隐藏照片和视频.md](怎么隐藏照片和视频.md)）之后留意跑一次。

## 六、离开时怎么锁

默认行为是**离开应用就锁**（AutoLock，默认开启）。围绕「上锁」还有一排可调项，全在设置里：

| 方式 | 行为 | 说明 |
| --- | --- | --- |
| 点左上角 Logo | 立即上锁 | 登录后左上角就是 Logo，点一下即锁 |
| ShakeLock 摇一摇锁 | 摇动手机立即上锁 | 同时会把应用从最近任务列表里移除 |
| FlipLock 翻转锁 | 手机翻扣即上锁 | 官方升级页列为 Premium 功能 |
| 息屏 | 强制上锁 | 同时把应用从最近任务里隐藏 |
| Logout Delay（后台延时） | 关闭 AutoLock 后生效 | 后台停留 5~60 秒后上锁，滑块拉到头等于关闭 |

两个官方特别提醒：

- **关闭 Logout Delay 的话，保险箱会一直开着**，直到你手动用上面任何一种方式上锁——不建议关；
- **Quick Logout**（默认关闭）开启后，上锁瞬间不再显示登录界面，直接黑掉，适合想立刻「装作没事」的时刻。

配合伪装模式使用效果更好，见 [假保险箱与伪装模式.md](假保险箱与伪装模式.md)。

## 七、外观与登录方式的关系

设置里的 Design 分区可以改界面主题与样式。提醒一点：如果你开启了伪装模式（图标换成计算器之类），登录界面可能与主界面风格不同——这是伪装功能的一部分，属于正常现象，进阶用法见 [假保险箱与伪装模式.md](假保险箱与伪装模式.md)。

日常建议的组合是：密码保底 + 指纹提速 + 备份兜底（免费版用手动备份文件，Premium 可开自动云备份），三者互不冲突。
