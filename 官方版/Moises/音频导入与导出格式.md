## 一、六种常见导入方式

在曲库页点加号（+）后，按文件的来源选入口：

| 方式 | 适用场景 | 注意点 |
| --- | --- | --- |
| 本机文件 | 手机里已下载的歌 | 首次使用需允许存储权限 |
| 公开 URL | 歌在某个可直接访问的网页上 | 链接必须公开可访问，带登录态的私密链接会失败 |
| Google Drive / Dropbox / iCloud | 文件在网盘里 | 需登录对应云盘账号授权 |
| 其他应用分享 | 微信、WhatsApp 等聊天工具里的音频 | 用系统的「分享/打开方式」选 Moises |
| iTunes 购买曲目（iOS） | 在 Apple 生态里买了歌 | 仅 iOS 端有此入口 |
| 视频文件 | 只有 MV 或现场视频 | 支持上传视频，应用提取其中的音频来分轨 |

音频与视频格式都收，常见的 MP3、M4A、MP4 等都能直接用；个别冷门容器格式如果导入失败，先用格式工具转成 MP3 再试。

## 二、URL 导入失败的三个常见原因

官方帮助中心专门有「My URL isn't working」的条目，实际排查按这三条走：

1. **链接不是直链**：页面地址不等于文件地址，要给的是指向音频文件本身、点开就能播放/下载的那个链接；
2. **需要登录或有时效**：网盘私密分享、带 token 且会过期的链接都不行，改成先下载到本机再导入；
3. **地区或防盗链限制**：有些站点拒绝非浏览器请求，这类链接换本机导入最省事。

## 三、导出：格式与范围怎么选

处理完成后在歌曲的设置/导出页操作，两个维度要选：

**导出范围**：

- 单轨导出：只要人声或只要伴奏时选这个；
- 整轨混音导出：把你调好的音量关系合成一个完整文件（伴奏带通常是这种）。

**格式**（以导出页实际显示为准）：

| 格式 | 特点 | 适合 |
| --- | --- | --- |
| MP3 | 体积小、通用 | 日常听、发聊天工具 |
| M4A | 同码率下比 MP3 略小 | 手机本地收藏 |
| WAV | 无损、体积大 | 进 DAW 二次制作（桌面端支持，手机端以应用内显示为准） |

免费版的导出格式有限制，对照见 [免费版限制与订阅功能对照.md](免费版限制与订阅功能对照.md)；节拍器轨能否一并导出，同样以导出页实际选项为准。

## 四、导出后文件去哪了

- 默认保存在应用可见的下载/导出目录，可在系统文件管理器按文件名搜到；
- 导出页也可以直接分享到其他应用或云盘；
- 建议处理完当天就导出到本地：云端曲目存在过期问题，只留在应用里不保险（免费版尤其如此，见 [常见登录与处理问题排查.md](常见登录与处理问题排查.md) 的「曲目不见了」条目）。
