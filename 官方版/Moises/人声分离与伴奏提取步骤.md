> 本篇讲 Moises 最核心的用法：把一首歌拆成人声、鼓、贝斯等独立音轨，做出伴奏或清唱，再导出。

## 一、先看清自己能分出哪几轨

分轨选项与账号版本直接挂钩（截至 2026-09 的官方帮助中心口径，以应用内实际显示为准）：

| 账号版本 | 可选分轨方案 |
| --- | --- |
| 免费版 | 2 轨：人声 / 伴奏；4 轨：人声 / 鼓 / 贝斯 / 其他 |
| Premium | 增加 3 轨、5 轨、6 轨组合：人声+和声、吉他细分（原声/电、主音/节奏）、钢琴、弦乐、管乐等 |
| Pro | 自定义多轨组合，可选声部更多（鼓组还能细分开镲、军鼓等） |

免费版只有「人声+伴奏」和「人声+鼓+贝斯+其他」两种固定方案，想单独抠出吉他或钢琴就得用付费版。免费与付费的完整对照见 [免费版限制与订阅功能对照.md](免费版限制与订阅功能对照.md)。

## 二、上传并开始分离

1. 打开应用，进底部 **Library（曲库）** 页；
2. 点 **加号（+）**，选择文件的进入方式（本机文件、云盘、公开链接均可，详见 [音频导入与导出格式.md](音频导入与导出格式.md)）；
3. 选好文件后，选**分轨数**（2 轨或 4 轨，付费用户可见更多选项）；
4. 点 **Submit** 提交，等待处理，通常几分钟内完成，曲目越长等待越久；
5. 处理完成后在曲库里点开这首歌，就进入混音器界面。

免费版每月只能上传 5 个文件、单个文件最长 5 分钟，别拿整张专辑一次铺开，先分清哪几首是真要用的。

## 三、在混音器里做伴奏或清唱

进入混音器后，每一轨都有独立的音量推子和静音开关，按目的操作：

| 你想要的效果 | 操作 |
| --- | --- |
| 做伴奏（卡拉OK用） | 把「人声」轨音量拉到 0 或直接静音，其余轨保持不动 |
| 做清唱/学唱 | 把鼓、贝斯、其他几轨全部静音，只留人声 |
| 听清某件乐器 | 只留那一轨，其余全部静音（扒谱常用） |
| 边放原曲边练琴 | 把你自己负责的那一轨静音，跟着其余声部演奏 |

播放时随时可以切，不需要重新处理。建议戴耳机操作，分轨的细节差异在小音量下更明显。

## 四、导出成品

点界面右上角的设置（或导出）按钮：

- **单轨导出**：只下载某一轨；
- **整轨混音导出**：按你当前调好的音量关系合成一个文件；
- **格式**：手机端常见导出为 MP3、M4A，WAV 支持情况随版本调整，以应用内导出页显示为准；
- 导出的文件可以保存到手机、传到云盘，或直接分享。

做完记得尽快导出。免费版处理出的曲目在云端有过期时间，只留在应用里可能过阵子就没了；用订阅账号处理的读者还要注意一点 —— 订阅到期回到免费版后，订阅期处理的云端文件无法再访问，导出要趁早（详见 [取消订阅与退款流程.md](取消订阅与退款流程.md) 第三节）。

## 五、分出来的效果不满意怎么办

- 某一轨里混进了别的乐器：这是分离模型的固有局限，翻唱混音多、乐器密度大的歌更容易出现，换个分轨方案重跑一次往往有改善；
- 高频发闷：付费版有「保留高频」选项与更高音质的分离模型；
- 文件没处理完就卡住：去 [常见登录与处理问题排查.md](常见登录与处理问题排查.md) 查对应条目。
