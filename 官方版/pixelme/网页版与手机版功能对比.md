## 一、两个版本分别在哪

- **网页版**：浏览器打开 [pixel-me.tokyo](https://pixel-me.tokyo/) 就能用，无需注册账号，电脑和手机浏览器都可以。
- **手机 App**：iOS 在 App Store，安卓在 Google Play（[https://play.google.com/store/apps/details?id=sato.tokyo.pixel_me](https://play.google.com/store/apps/details?id=sato.tokyo.pixel_me)）；安装包也可以走本文的网盘资源，见 [下载与安装教程.md](下载与安装教程.md)。

两个版本的基础能力一样：上传照片，AI 识别人脸生成像素画。

## 二、功能对照

| 功能 | 网页版 | 手机 App |
| --- | --- | --- |
| 人脸识别转像素画 | 有 | 有 |
| 风景模式（风景 / 宠物 / 建筑等） | 有 | 有 |
| 颜色调整 | 有 | 有 |
| 分享到社交平台 | 有 | 有 |
| 拼豆图纸（Perler / Hama） | 有 | 无 |
| 十字绣图纸 | 有 | 无 |
| 手机壁纸制作 | 有 | 无 |
| AI Magic 高质量转换 + 滤镜分类 | 无 | 有 |
| 像素级编辑器 | 无 | 有 |
| 减色 / 背景去除 | 无 | 有 |
| Aseprite 导出（带图层与调色板） | 无 | 有 |
| 作品库 | 无 | 有 |

对照依据官方功能页整理，功能随版本更新会变，以官方页面当时展示为准。

## 三、按需求选版本

- **做拼豆图纸、十字绣图**：图纸生成在网页版，App 出底稿与精修，两边怎么配合见 [拼豆与十字绣图纸制作方法.md](拼豆与十字绣图纸制作方法.md)。
- **要最高质量的 AI 转换、要精修**：装 App，网页版没有编辑器和 AI Magic 模式。
- **做游戏素材、用 Aseprite**：装 App。
- **偶尔做一张头像、不想装 App**：网页版够用。

两边也可以混着用：App 里精修完，再到网页版生成拼豆图纸，是常见的搭配。

## 四、上传的照片安全吗

官方说明：上传的照片在像素画转换完成后会自动从服务器删除，不会存储、也不会提供给第三方。这是官方渠道的口径；通用习惯仍然适用——涉及证件、住址这类隐私的照片，不要拿来试效果。

## 五、账号与付费

网页版完全免费、无需注册。App 基础功能免费，AI Magic 模式免费次数有限；Pro 订阅解锁不限次使用，并去除广告与水印，价格以 App 内展示为准。
