## 一、票价之外会有哪些费用

按官方帮助中心的说明，你在 Omio 上可能遇到两笔平台侧费用：

| 费用 | 说明 |
| --- | --- |
| 服务费（service fee） | 部分订单收取，对应平台运营、多语言客服、代客改退等服务 |
| 订票费（booking rate） | 与服务费是两回事，可能与服务费并存，随线路与承运公司而变 |

官方明确的两条口径：**付款确认前会完整展示票价与全部费用的总额**；平台同时从承运方拿佣金（写在使用条款里），这部分不出现在你的账单上。

所以实操上一句话：**别只看列表页标的价格，拉到结账页看最终总额再决定。**

## 二、同一张票，为什么在 Omio 上可能更贵

三个原因叠加，按确定性从高到低排：

1. **平台费用叠加**：第一节那两笔费用直接加在最终总价上。
2. **促销票渠道差异**：有第三方测评与用户反馈提到，部分承运公司把自己最便宜的促销票只放在自家官网 / 自家 App 上卖——这种票 Omio 的搜索结果里压根不出现，或者起步价就更高。这一点官方没有正面回应，以你实际搜索比价的结果为准。
3. **币种与支付通道**：不同地区站点展示的货币不同，汇率折算后观感上有差异（见[支付方式与币种.md](支付方式与币种.md)第四节）。

「具体贵多少」没有统一数字：有用户反馈过区域火车票比承运方直购高约一成的例子，也有人碰到的价差只有一笔小额服务费。规律是**行程越简单、票价越便宜，平台费用的相对占比越高**——一张几欧元的短途大巴票，加一笔服务费后比例就很显眼。

## 三、什么情况用它买、什么情况直购

| 场景 | 建议 |
| --- | --- |
| 跨国行程、要对比多家承运方（火车 vs 大巴 vs 廉航） | 适合 Omio：一次搜索全对比，界面语言统一 |
| 在语言不通的国家临时查车次、买票 | 适合 Omio：省去注册当地铁路官网的麻烦 |
| 单一承运方的简单点对点票（如德铁德国境内、西班牙境内 Renfe） | 值得先比价：承运方官网常有 Omio 没有的促销价，且售后少一层中转 |
| 对价格敏感、愿意多花十分钟逐家核对 | 承运方官网与应用先查一遍，再回头对比 Omio 总价 |
| 想要集中管理多段行程、中文界面下单 | 适合 Omio：车票集中在应用里（见[订票流程与取票.md](订票流程与取票.md)） |

## 四、出问题时的中间商属性

在 Omio 买票，出票方是 Omio、承运方是交通公司，**退改与赔偿常要经过中间这一层**：

- 承运方退款通常先退给 Omio，再由 Omio 退给你——所以退款到账比直购多一道等待（时限见[支付方式与币种.md](支付方式与币种.md)第五节）。
- 2025 年有用户反馈过承运方称已把取消列车的票款退给平台、而平台侧迟迟未到账的纠纷案例（单一来源，列在这里供你预留心理预期）。遇到这种情况，保留双方沟通记录与承运方的退款凭证，向 Omio 客服出示。
- 罢工、晚点赔偿多数要向承运方申请（见[改签与退票.md](改签与退票.md)第六节），平台客服的作用是帮你对接。

这些不是「别用」的理由，而是「用之前知道代价在哪」：它换来的是一站式比价与统一售后入口，代价是每张票可能贵一点、出问题时多一道中转。
