## 一、支持哪些付款方式

Omio 是代售平台，支付通道随地区与承运公司略有差异，下表是官方长期列出的主流方式（以结账页实际显示为准）：

| 类别 | 支持的方式 |
| --- | --- |
| 信用卡 / 借记卡 | Visa、MasterCard、maestro、Diners Club/Discover、American Express、Carte Bancaire、JCB、UnionPay（银联） |
| 电子钱包 | PayPal、Apple Pay、Google Pay、支付宝（Alipay）、微信支付（WeChat） |
| 银行转账 | Sofort、iDEAL、Dotpay、Bancontact |
| 其他 | Klarna、Revolut Pay 等部分地区可选 |

对国内用户来说最实际的两个信息：**银联卡**与**支付宝 / 微信支付**都在列表里，订票时可以直接选，省去换汇的步骤。具体某个班次结账时显示哪些通道，取决于票对应的承运公司——同一应用里，德国铁路的票和意大利大巴的票出现的支付选项可能不同，这是正常现象。

## 二、付款被拒的常见原因

1. **卡未开通境外线上支付**：欧洲公司的扣款方多在境外，用卡前先在发卡行 App 里确认境外无卡支付已开启。
2. **3D 验证超时**：Visa/MasterCard 结账会弹出银行验证页，停留太久或切出去接电话都可能中断，重新走一次结账即可。
3. **钱包余额或限额不足**：支付宝、微信支付走的是跨境扣款，会受你自己的单笔限额影响。
4. **反复失败后先停一停**：连续被拒几次就换一种方式或隔段时间再试，不要短时间连续刷——部分银行会把连续小额尝试当风险交易临时冻结。

付款环节的顺序与注意事项见[订票流程与取票.md](订票流程与取票.md)第五节。

## 三、折扣卡与通票

- 如果持有**铁路通票**（如欧铁 Eurail/Interrail 一类）或当地折扣卡，在**搜索阶段**就选上持卡类型，结果价会按折扣显示。
- 通票持有者订的常常是「占位票」（reservation）：票价远低于全价，但票面规则不同——这类票的改签退票条款要单独看确认邮件里的说明，不要按普通票经验处理。
- 各家承运公司认哪些卡不一样，搜出来的结果里会标注是否适用你的卡。

## 四、结账币种

- 币种跟随你选择的国家 / 地区站点，也支持在支付前切换显示货币（如美元、人民币等，以页面可选项为准）。
- 银行按当日汇率折算入账，**账单金额与你结账页看到的金额可能有一点汇率差**，这是发卡行行为，与平台无关。
- 用支付宝 / 微信支付时，扣款金额按各自支付时的汇率折成人民币显示，你在付款页看到多少就是多少。

## 五、退款怎么回来

退款一律**原路退回**你付款用的那张卡 / 那个钱包。到账时间差距很大——卡类通常要几个到十几个工作日，钱包类相对快一些。你取消订单前，应用里会先显示含手续费的退款总额。取消与改签的具体操作见[改签与退票.md](改签与退票.md)；退款迟迟没到账的处理思路见[常见问题与排查.md](常见问题与排查.md)。
