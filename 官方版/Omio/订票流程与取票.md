## 一、整体流程一览

在 Omio 上订一张票，完整走下来是这六步：

```
搜线路 → 比结果 → 选票加购 → 填乘客 → 付款 → 出票取票
```

它是代售平台：你在上面买的是各家交通公司（铁路、大巴、航空、轮渡）的票，Omio 负责搜索、比价、出票与售后入口，实际承运还是那家公司。明白这一点，很多规则（比如改签费谁收、票能不能退）就都好理解了。

## 二、搜线路：把条件一次填全

首页搜索框依次填：

- **出发地 / 目的地**：支持城市名，也支持具体车站、机场。填城市时注意选对国家的同名城市（欧洲重名城镇不少，结果页会列出来让你确认）。
- **出行日期与人数**：单程或往返在同一入口切换。
- **折扣卡**：如果你持有欧洲铁路通票或某些国家的折扣卡（如欧洲青年卡一类），在这一步就能选上，价格会直接按折扣显示。

点搜索后，火车、大巴、航班、轮渡四类结果会混排在一起，顶部图标可以在四类之间快速切换。

## 三、比结果：四个排序维度够用

结果列表按推荐排序，你可以手动切换排序方式：

| 排序 | 适合场景 |
| --- | --- |
| 最便宜 | 预算优先，能接受慢车或多次换乘 |
| 最快 | 赶时间，跨城当天往返 |
| 出发 / 到达时间 | 卡准会议、酒店入住或接驳航班 |
| 直达 | 行李多、带老人小孩，不想换乘 |

筛选维度除了价格区间，还有交通类型与出发时段。跨国的长途行程（比如巴黎到阿姆斯特丹）同一时段往往同时有高铁与廉航，价格差可能不小，两类都点开看一眼再决定。

## 四、下单：乘客信息要与证件逐字一致

选中车票后进入预订页，这一步有几处容易出错：

1. **乘客姓名、证件号**：按你出行时**实际携带的证件**（护照 / 身份证 / 居留卡）填写，字母拼写逐字核对。欧洲检票时会核对车票与证件，名字对不上可能被拒载。
2. **舱位与附加项**：部分公司支持选座、加行李、升级舱位或加购灵活退改，按需勾选——每加一项价格都会变。带大件行李、自行车或宠物出行时，这一步有没有对应加购入口，规则见[行李自行车与宠物规定.md](行李自行车与宠物规定.md)。
3. **联系方式**：邮箱一定要填你**能立刻收到信的**，出票确认与车票都发到这里。

## 五、付款与确认

支付方式列表（卡、钱包、银行转账等）在[支付方式与币种.md](支付方式与币种.md)里有完整表格。付款成功后：

- 确认邮件几分钟内到，里面有权重最高的信息——**票号、取票方式、该票的退改条款**。建议把这封邮件留着别删。
- 车票同时出现在应用底部的 **Your Bookings（你的预订）** 里。

## 六、取票：多数是手机票，扫二维码上车

绝大多数票是**电子票**，不需要打印：

1. 打开 Omio → **Your Bookings** → 点对应行程 → **Open ticket(s)** 打开车票。
2. 检票时把屏幕上的二维码出示给检票员，或刷闸机上的扫码口。
3. 部分车票支持添加到 Google Wallet，信号差的车站直接从钱包调出更快。

两个例外要留意：

- **需要打印的票**：少数承运公司要求纸质票，而且多卡在国际线上——按官方帮助中心的承运公司页面，Renfe 国际线需打印（可在主要车站的紫色自助取票机上打，售票窗口不给打），ÖBB 国际行程需提前用 A4 纸打印。这种票在**下单过程中**就会明确提示，出票后再补打印可能来不及——见到提示当场处理。
- **离线可用性**：Your Bookings 里的票在无网络时也能打开，进隧道、地下站台前建议先把票打开再放回后台。

## 七、上车前最后核对三件事

1. 票面日期、车次/班次、出发站台（应用与车站大屏不一致时以车站为准，或咨询站台工作人员）。
2. 行程提醒已开启（设置里的通知别关，晚点、换站台会推给你）。
3. 证件带在身上。

票临时要改或要退，看[改签与退票.md](改签与退票.md)；出票失败、邮件没收到之类的问题见[常见问题与排查.md](常见问题与排查.md)。
