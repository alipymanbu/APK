# ZeroTermux Linux发行版安装与容器切换

> 本篇讲怎么在 ZeroTermux 里一键安装 Ubuntu、Kali、Debian 等 Linux 发行版，装好的容器怎么切换、恢复包怎么变成一个新容器。

## 一、先分清：你要的是发行版还是虚拟机

ZeroTermux 里两条「在手机上用 Linux」的路线，选错了会白折腾：

| 路线 | 入口 | 特点 |
| --- | --- | --- |
| PRoot 容器 | 发行版本 / 备份恢复 | 装的是 ARM 架构的 Linux 发行版（Ubuntu、Kali、Debian 等），启动快、性能损耗低，不要求 root |
| QEMU 虚拟机 | QEMU | 模拟整台机器，可以跑 x86 的 Windows 镜像，性能开销大、对设备要求高 |

绝大多数「手机上要个 Linux 命令行环境」的需求走 PRoot 容器就够；只有明确要跑 Windows 或别的架构系统才碰 QEMU。QEMU 的用法见 [QEMU虚拟机使用入门](QEMU虚拟机使用入门.md)。

## 二、用「发行版本」入口安装

官方 Wiki 给出的流程：

1. 确认 ZeroTermux 已完成首次启动（bootstrap 装好了）。
2. 打开左侧栏，「常用功能 > 发行版本」。点击后应用会把内置的安装脚本写入家目录并向终端发送运行命令。
3. 等终端里出现脚本菜单或安装提示。
4. 按提示选择你要的发行版，例如 Ubuntu、Kali 等。
5. 安装期间保持应用在前台，避免系统清理后台导致中断。

安装前尽量连稳定网络——发行版 rootfs 下载动辄几百 MB 到数 GB。相关数据会用到这些目录：

| 目录 | 用途 |
| --- | --- |
| `/sdcard/xinhao/online_system/` | 在线/离线系统包 |
| `/sdcard/xinhao/data/` | 备份或恢复包 |
| `/sdcard/xinhao/system/` | 多系统相关数据 |

另外两条官方建议：初次使用先只装一个系统，确认能正常启动后再折腾多环境；对已有重要环境的容器，升级或替换之前先做一次备份（见 [环境备份与恢复方法](环境备份与恢复方法.md)）。

「MOE全能」入口也能拉起一套装系统的集成脚本，但官方 Wiki 已注明其基础 TMOE 被归档、脚本可能改动当前环境，**优先用上面这条「发行版本」路线**；坚持用 MOE 的话先备份，入口说明见 [界面菜单与常用功能入门](界面菜单与常用功能入门.md)。

## 三、用恢复包部署环境

「发行版本」是从零安装；另一条路是用别人打包好的**一键恢复包**直接还原出一个配置好的环境（比如网友做好的 Kali 工具环境）。流程：

1. 从内置下载站或官方资源站拿到恢复包，先确认它确实是给 ZeroTermux 用的。
2. 把恢复包放进 `/sdcard/xinhao/data/`。
3. 打开「备份/恢复」，在恢复列表里选中这个数据包（包多的时候按包名找，别猜）。
4. 给它取一个新的容器名——这个名字会出现在「容器切换」的列表里，取个好认的，比如 `Kali Linux`、`Ubuntu 24.04`，别取无意义乱码。
5. 确认恢复，等终端把文件铺完，出现「系统恢复完成，请在切换系统」的提示。

恢复操作的完整细节与注意事项在 [环境备份与恢复方法](环境备份与恢复方法.md) 的恢复一节。

## 四、容器切换

装好或恢复好之后，环境不会自动顶上来，要在「容器切换」里选你刚命名的那个容器进入。装了多个容器后，日常流程就是：左侧栏「容器切换」→ 选容器 → 进入该容器的命令行。想回 ZeroTermux 自己的终端，退出容器会话即可。

## 五、容器内使用的几个注意点

- **别把容器内和 Termux 内的换源搞混**：Termux 本体的软件源在「切换源」面板管理（见 [切换国内镜像源步骤](切换国内镜像源步骤.md)）；容器内部是发行版自己的 `apt`，改的是发行版的源，两套互不相干。
- **没有 systemd**：PRoot 环境里 `systemctl` 用不了，容器内管理服务用发行版的 `service` 命令或直接执行启动命令。想开 SSH 这类服务，装好后用 `service ssh start` 这类方式启动；从电脑连 **ZeroTermux 本体**的 SSH 则是另一套流程，见 [手机当服务器SSH远程连接](手机当服务器SSH远程连接.md)。
- **资源占用**：容器内跑编译、扫描等重活时，关注手机发热与电量；干完活记得退出会话，别让长驻进程挂着。
