## 一、X11 是干什么的

X11 是在安卓上跑**图形界面程序**的入口：终端里装好带图形界面的 Linux 软件（比如桌面应用、GUI 工具）后，靠 X11 把画面显示出来。命令行用得好好的就不需要碰它；你想跑带窗口的程序，才需要这一篇。

官方 Wiki 在 X11 名下给了几个入口：安装X11、X11设置、显示/隐藏终端、显示/隐藏键盘、修复环境错误，都在左侧栏的 X11 功能区里。

## 二、安装 X11

官方 Wiki 给出的流程：

1. 完成 ZeroTermux 首次启动（bootstrap 装好）。
2. 确保网络可用、软件源可用——源不通的话先按 [切换国内镜像源步骤](切换国内镜像源步骤.md) 换源，X11 组件也要从软件源下载。
3. 打开「X11 功能 > 安装X11」，保持应用在前台等它装完。

装完做两个验证：

- 状态检查命令：

```bash
zt x11status
```

- 装个最简单的图形程序试试：

```bash
pkg install x11-repo
pkg install xterm
xterm
```

能弹出 xterm 的窗口，说明 X11 通道是通的。

## 三、X11 出问题怎么修

典型症状（官方 Wiki「修复环境错误」页列的适用情况）：

- X11 启动后黑屏；
- 菜单里的「显示/隐藏终端」点了没反应；
- `termux-x11` 相关文件缺失；
- 图形应用提示**无法连接显示**。

处理顺序：

1. 打开「X11 功能 > 修复环境错误」，让应用自己恢复一次。
2. 不行就在终端手动检查这几个文件在不在：

```bash
ls $PREFIX/usr/bin/termux-x11
ls $PREFIX/usr/bin/termux-x11-preference
ls $PREFIX/usr/libexec/termux-x11/loader.apk
ls $PREFIX/usr/lib/libXlorie.so
```

哪个报「No such file」就说明组件缺了，回到「安装X11」或「修复环境错误」补装。

3. 仍然失败按官方给的顺序来：重启 ZeroTermux → 重新安装 X11 组件 → 换源后更新包 → 截图错误信息反馈给项目维护者。

## 四、几个使用提示

- 「显示/隐藏终端」「显示/隐藏键盘」是 X11 运行图形程序时的两个开关：终端叠在画面上时可以收起来看全屏，键盘挡住内容时可以收起。
- X11 里跑的图形程序吃资源不比 QEMU 少多少，低内存设备同样建议一次只开一个程序。
- X11 相关报错如果伴随 `pkg` 不可用，先解决软件源（见 [常见报错与问题排查](常见报错与问题排查.md) 的终端环境异常一节），再修 X11。
