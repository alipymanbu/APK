## 一、首次启动就失败：目录创建失败

首次启动会在内部存储创建 `xinhao` 数据目录，提示创建失败时：

1. 进系统设置，确认 ZeroTermux 已拿到**文件和媒体（内部存储）权限**——很多品牌会默认只给一部分。
2. 给完权限后**重新打开应用**，它会接着把目录建完。
3. 还不行就完全退出应用再开一次；仍失败则卸载重装一遍（注意先备份已下载到 `xinhao` 里的东西）。

目录建好后里面会有 `data/`、`apk/`、`command/`、`font/` 等子目录，用途见 [界面菜单与常用功能入门](界面菜单与常用功能入门.md)。

## 二、Bootstrap 安装失败

症状：卡在基础环境安装界面，或提示引导程序安装失败。官方 Wiki 列出的常见原因与对应处理：

| 可能原因 | 处理 |
| --- | --- |
| 安装期间应用被切后台或被系统清理 | 首次启动期间全程保持前台，关掉一键清理/省电后台限制 |
| 手机空间不足 | 确认内部存储有足够余量（见 [下载与安装教程](下载与安装教程.md) 的准备一节） |
| 不是 Android 主用户（手机分身/子用户里安装） | 切回主用户再装 |
| 旧版 Termux、ZeroTermux 或同签名应用残留 | 完全卸载旧版后重装（Termux 与 ZeroTermux 同包名，必须先卸 Termux） |

都试过仍失败，截图报错信息到项目 GitHub 或社群反馈。

## 三、左右菜单打不开

菜单手势与首次引导时选的「使用习惯」直接相关：

- Termux 使用习惯：按键逻辑接近原版，没有边缘双击唤出菜单。
- ZeroTermux 使用习惯：双击左侧边缘、按音量上键唤出菜单。

发现手势和预期不一样，进左侧栏 **ZT 设置** 换使用习惯，改完重启应用。若 ZT 设置本身也进不去（比如菜单完全唤不出），用音量键多试几个方向，或重新安装一遍。

## 四、终端环境异常：pkg update 报错

`pkg update` 报错、源连不上、基础命令缺失时按顺序来：

```bash
pkg update
pkg upgrade
```

1. 连接超时类报错：先换国内镜像源再试，步骤见 [切换国内镜像源步骤](切换国内镜像源步骤.md)——这一步能解决绝大多数「装不了包」。
2. 提示列表不一致 / hash 错误：把 `apt update && apt upgrade` 完整跑一遍。
3. 换了源还是失败：对比换 Wi-Fi 与流量，排除网络本身的问题；再检查存储是否已满（写不了缓存也会报错）。
4. 基础命令突然缺失（比如 `pkg` 都不认）：可能是环境文件被误删，用图形化恢复（见 [环境备份与恢复方法](环境备份与恢复方法.md)）还原一个正常的备份包最快。

## 五、后台被杀、长任务中断

备份、安装发行版、跑虚拟机这类长任务对后台存活敏感：

- 任务运行期间保持 ZeroTermux 在前台，屏幕别锁太快；系统设置里可把 ZeroTermux 加入电池优化白名单（各品牌入口不同，搜「电池优化」或「后台运行」）。
- 部分新系统会严格限制后台进程，长任务被中途清掉不是应用本身的问题，重新执行即可，别反复重装。

## 六、装不上 / 升级后闪退

- **安装报冲突**：先彻底卸载 Termux（同包名问题，见 [下载与安装教程](下载与安装教程.md) 第一节），再装。
- **升级后闪退**：官方发布页曾提示个别版本存在启动类问题并随后发布修复版；遇到闪退先去 GitHub 发布页看有没有更新的版本，换新版覆盖安装。
- **重装丢数据**：`/sdcard/xinhao/` 在卸载后不会自动删除，重装前先确认要不要保留；`Android/data` 下的数据则会随卸载清掉。

## 七、X11 相关故障

图形界面打不开、X11 启动黑屏、「显示/隐藏终端」开关无效、图形应用提示**无法连接显示**——这些是 X11 组件的问题，不走本篇的通用排查。先试「X11 功能 > 修复环境错误」入口，具体的手动检查与恢复步骤见 [X11图形桌面安装使用](X11图形桌面安装使用.md) 的修复一节。
