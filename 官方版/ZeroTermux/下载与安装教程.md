## 一、先弄清楚：这是哪个 ZeroTermux

ZeroTermux 是基于 Termux 项目开发的第三方分支，官方项目托管在 GitHub（[github.com/hanxinhao000/ZeroTermux](https://github.com/hanxinhao000/ZeroTermux)），提供完整的中文界面，并在 Termux 的终端能力之上加了图形化的功能面板（换源、备份、装 Linux 发行版等，见 [界面菜单与常用功能入门](界面菜单与常用功能入门.md)）。

有一点必须提前知道：**它和 Termux 官方版用的是同一个包名 `com.termux`**。Android 不允许两个同包名的应用共存，所以官方 Wiki 把「彻底卸载 Termux」列为安装的第一步。如果你设备上装过 Termux（包括主程序），先全部卸载再继续，否则安装会失败或相互冲突。

本篇对应的安装文件信息（以 2026-09 采集的这份为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 0.119.1 |
| 包名 | `com.termux` |
| 安装包大小 | 107.23M |
| MD5 | `2BC5C89D4E11C6989629DE0615BE1DBE` |

官方更新较频繁，最新版本以 GitHub 发布页为准；网盘里这份 0.119.1 就是本篇各处事实对应的版本。

## 二、装之前的准备

1. **设备架构**：ARM64（aarch64）。官方 Wiki 安装教程对系统版本的要求是 Android 7.1 或更高（官网首页标的是 7.0+，两处以官方页面为准）。
2. **存储空间**：安装包 107.23M 只是起点，首次启动还要装基础环境（bootstrap），之后装 Linux 发行版、跑虚拟机都会持续占空间，建议预留几 GB。空间不足是首次启动失败的常见原因之一。
3. **允许安装未知来源应用**：这个包不在应用商店里，安装时系统会拦一道。在系统设置里搜「安装未知应用」，给浏览器或文件管理器授权即可，各品牌入口叫法略有差异。
4. **卸载 Termux**：再强调一次，包括 Termux 主程序在内的所有相关应用都要卸干净。

## 三、获取安装文件并安装

1. 从 **ZeroTermux 安装文件资源（夸克网盘）** 进入，转存到自己网盘后把 apk 下载到手机。
2. （可选但建议）校验完整性：用文件管理器或校验工具算一下 apk 的 MD5，与上表的 `2BC5C89D4E11C6989629DE0615BE1DBE` 一致说明文件没损坏、没被改动。
3. 点击 apk，按提示允许「来自此来源的应用」，确认安装。
4. 装完先不要急着卸载下载器：如果首次启动出了问题需要重装，文件还在手边省事。

## 四、首次启动引导

第一次打开会走一段引导，按官方 Wiki 的描述共四步：

1. **选择使用习惯**：Termux 使用习惯更接近原版 Termux 的按键逻辑；ZeroTermux 使用习惯会启用屏幕边缘双击、音量键唤出左右菜单。选错了后面可以在左侧栏的 ZT 设置里改。
2. **授予内部存储权限**：不给权限，后面的数据目录创建不出来。
3. **选择创建数据目录**：推荐选「内部存储」方案，它会在内部存储根目录创建 `xinhao` 数据目录。
4. **等待基础环境安装**：这一步会安装 bootstrap（基础运行环境），期间保持应用在前台，不要切后台、不要用一键清理。装完就进入主终端界面。

这四步里任何一步卡住（目录创建失败、一直停在安装界面、菜单打不开），按 [常见报错与问题排查](常见报错与问题排查.md) 逐项处理。

## 五、装完先做这两件事

- **换国内镜像源**：默认源在国外时 `pkg update` 会很慢甚至超时，图形化换源只要半分钟，步骤见 [切换国内镜像源步骤](切换国内镜像源步骤.md)。
- **认识菜单**：左侧栏集中了换源、备份、发行版、QEMU 等图形化入口，先逛一遍 [界面菜单与常用功能入门](界面菜单与常用功能入门.md)，知道每个功能在哪，后面用起来才顺。

## 六、更新与卸载

- ZeroTermux 没有 Android 应用商店的推送更新渠道，新版本从 GitHub 发布页获取；直接装新 apk 覆盖即可（注意覆盖安装同样要求签名一致，别混装来路不明的包）。网盘里的 0.119.1 对应本篇，之后的版本以官方发布页显示为准。
- 卸载走系统「设置 → 应用管理」。注意：卸载应用本身**不会**删除内部存储里的 `xinhao` 数据目录（备份包、恢复包、镜像都在那），确认不要了再去文件管理器手动删掉。
