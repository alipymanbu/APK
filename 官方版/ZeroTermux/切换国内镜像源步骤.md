## 一、什么时候需要换源

ZeroTermux 基于 Termux，软件包用 `pkg` / `apt` 管理，包源默认指向 Termux 官方源。你装完第一次跑 `pkg update` 如果长时间卡在 `Reading package lists` 前的连接阶段、或直接超时报错，基本都是源连不上。这时把源换成国内镜像（清华、中科大等）通常立刻见效。

刚装好就顺手换一次源，后面装任何包都省心。换源入口在左侧栏的「切换源」，全程图形化，不用手改配置文件。

## 二、图形化换源步骤

按官方 Wiki 的流程走：

1. 打开 ZeroTermux。
2. 双击屏幕左侧边缘（或按音量上键）唤出左侧栏菜单。
3. 选择「切换源」。
4. 在列表里选一个国内镜像源，例如清华大学、中科大等。
5. 弹窗警告会提示你确认，点确认后应用开始切换软件源并自动更新软件包列表。
6. 更新过程中如果终端要你确认（会出现一堆 `Do you want to continue?` 之类提示），推荐全部输入 `Y` 回车。
7. 跑完后手动执行一次刷新确认列表是最新的：

```bash
apt update
```

8. 没有报错就完成了，之后 `pkg install` 之类命令都会走新源。

## 三、镜像参考与手动改源

- 清华大学开源软件镜像站的 Termux 镜像使用帮助：[https://mirrors.tuna.tsinghua.edu.cn/help/termux/](https://mirrors.tuna.tsinghua.edu.cn/help/termux/)
- 校园网联合镜像站的 Termux 帮助页：[https://help.mirrors.cernet.edu.cn/termux/](https://help.mirrors.cernet.edu.cn/termux/)

官方 Wiki 的推荐路径就是上面的图形化切换。如果你想手动改源（编辑 `sources.list`），参考镜像站帮助页里的写法即可——但注意 Termux 的源地址格式与普通 Debian 系统不同（前缀是 Termux 自己的仓库路径），照抄网上 Ubuntu 教程里的地址会失败。不确定就老老实实用「切换源」面板。

## 四、换完还是报错

- `apt update` 输出里有个别条目 404 或 hash 不匹配：先跑一次 `apt update && apt upgrade` 让包列表完全对齐，多数会自愈。
- 换了几个镜像都超时：检查手机网络本身（换个 Wi-Fi / 流量对比一下），再回 [常见报错与问题排查](常见报错与问题排查.md) 的「终端环境异常」一节按顺序排查。
- 想回到默认源：同样在「切换源」面板里选回官方源即可。
