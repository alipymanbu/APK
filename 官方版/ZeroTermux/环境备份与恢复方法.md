## 一、两种方式怎么选

| | 图形化备份/恢复 | termux-backup 命令 |
| --- | --- | --- |
| 入口 | 左侧栏「常用功能 > 备份/恢复」 | 终端里敲命令 |
| 备份内容 | 当前容器/环境整体 | 只有 `$PREFIX` 安装目录，**不备份家目录** |
| 适合谁 | 所有人，尤其是要还原成容器用的 | 熟悉 GNU/Linux 基本操作的用户 |

拿不准就用图形化那个。命令行方式备份范围不含家目录，不了解「家目录」是什么的话，直接跳过第四节。

## 二、图形化备份

1. 打开左侧栏「常用功能 > 备份/恢复」，选择备份。
2. 选压缩格式：

| 格式 | 压缩/解压速度 | 压缩后体积 |
| --- | --- | --- |
| tar.gz | 快 | 一般 |
| tar.bz2 | 中 | 较小 |
| tar.xz | 慢 | 最小 |

一般选 `tar.gz`；对体积敏感（要传给别人、手机空间紧张）再选 `tar.xz`。

3. 确认后开始打包。备份期间**保持应用在前台、保持设备不休眠**。
4. 中途输出停顿或变慢是正常的——设备正在压缩大文件（比如 `libLLVM.so` 这类），等它跑完。
5. 完成后会显示备份文件位置，通常在 `/sdcard/xinhao/data/` 下。

## 三、图形化恢复

1. 把恢复包放进 `/sdcard/xinhao/data/`。从下载站或别人那里拿来的包，**先确认它确实是给 ZeroTermux 用的**，不通用。
2. 打开「备份/恢复」，在恢复列表里按**数据包名称**找到目标包——包很多的时候靠名字找，不要靠猜。
3. 点选后要求输入一个新的系统盘名称：这个名字会用在容器切换的列表里（见 [Linux发行版安装与容器切换](Linux发行版安装与容器切换.md)），取个好记好认的，比如 `Debian forky`、`Kali Linux`。
4. 确认后开始恢复，终端会滚动输出恢复出来的文件。
5. 出现「系统恢复完成，请在切换系统」提示后，去「容器切换」选中刚命名的容器进入。

## 四、termux-backup / termux-restore 命令

新版 ZeroTermux 已内置这对工具，没有的话先装：

```bash
pkg install termux-tools
```

备份（压缩格式由输出文件扩展名决定）：

```bash
termux-backup ~/storage/shared/xinhao/data/backup.tar.gz
```

想换压缩算法，改扩展名即可（`.tar.xz` 体积最小但最慢，`.tar.zst` 速度与体积比较均衡）。恢复用配套的 `termux-restore`：

```bash
termux-restore ~/storage/shared/xinhao/data/backup.tar.gz
```

恢复完成后输入 `exit` 退出应用，再重新打开，恢复才算完成。

**两条必须记住的警告**（官方 Wiki 原文口径）：

- `termux-restore` 会**不经过询问**清空 `$PREFIX` 里现有一切再写入，恢复前确认里面没有未备份的独有内容。
- `termux-backup` **不备份家目录**，家目录里有东西要另想办法搬走。

备份期间终端几乎不输出内容，不代表它停了；跑完回到命令提示符后，去你指定的路径确认备份文件存在。

## 五、折腾前先备份

给容器升级、换发行版、跑来历不明的脚本之前，都先花几分钟做一次图形化备份——还原一个备份包远比重新配一遍环境省事。备份包建议再复制一份到电脑或网盘，手机存储坏了也能救回来。
