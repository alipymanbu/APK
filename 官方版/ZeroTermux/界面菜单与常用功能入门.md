## 一、主界面与菜单怎么唤出

打开应用后看到的就是终端界面，和原版 Termux 一样可以直接敲命令。ZeroTermux 的差别在于两侧的图形化菜单：

- **左侧栏（功能菜单）**：在 ZeroTermux 使用习惯下，双击屏幕左侧边缘或按音量上键唤出。换源、备份、装 Linux、跑虚拟机这些图形化功能都排在这里。
- **右侧栏**：存放文件管理等内容；较新的版本还把 AI 智能体放在这里——它能读写终端、下发命令、代改字体背景换源等多数功能，官方更新记录注明主要在 DeepSeek 上做过测试，其他模型的效果以你实际体验为准。
- **唤出方式不对？** 这些行为跟首次引导时选的「使用习惯」绑定：选 Termux 使用习惯时按键逻辑接近原版 Termux，菜单可能不出现在你预期的手势上。进左侧栏的 **ZT 设置** 重新调整即可。

第一次没走完引导或菜单行为怪异，先看 [常见报错与问题排查](常见报错与问题排查.md) 里的「左右菜单打不开」一节。

## 二、左侧栏常用功能一览

各入口的名称与作用如下（个别入口的可用性可能随版本变化，以你界面上实际显示的为准）：

| 入口 | 作用 | 详细说明 |
| --- | --- | --- |
| 切换源 | 一键把软件包源换成清华、中科大等国内镜像 | [切换国内镜像源步骤](切换国内镜像源步骤.md) |
| 备份/恢复 | 把当前环境打包备份、或从恢复包还原环境 | [环境备份与恢复方法](环境备份与恢复方法.md) |
| 发行版本 | 内置脚本一键安装 Ubuntu、Kali、Debian 等发行版 | [Linux发行版安装与容器切换](Linux发行版安装与容器切换.md) |
| 容器切换 | 在已安装的多个 Linux 容器之间切换 | [Linux发行版安装与容器切换](Linux发行版安装与容器切换.md) |
| QEMU | 虚拟机入口，含 Win7/WinXP 模拟脚本 | [QEMU虚拟机使用入门](QEMU虚拟机使用入门.md) |
| 定时任务 | 图形化配置周期执行的脚本任务 | 本页第四节 |
| MOE全能 | 集成式脚本工具集入口，**会改动当前环境** | 本页第四节末的警告 |
| ZT 设置 | 使用习惯、语言、菜单等 ZeroTermux 自身设置 | 本页第四节 |
| X11 | 在安卓上跑图形界面程序的入口 | [X11图形桌面安装使用](X11图形桌面安装使用.md) |

先把「切换源」和「备份/恢复」这两个摸熟：前者决定你装东西快不快，后者决定你折腾坏了能不能救回来。

## 三、`xinhao` 数据目录

首次启动时应用会在内部存储根目录创建 `xinhao` 目录，之后的功能大多围绕它工作。常见子目录：

| 目录 | 用途 |
| --- | --- |
| `/sdcard/xinhao/data/` | 备份包、恢复包 |
| `/sdcard/xinhao/apk/` | 临时 APK |
| `/sdcard/xinhao/command/` | 自定义命令 |
| `/sdcard/xinhao/font/` | 字体文件 |
| `/sdcard/xinhao/iso/` | ISO 镜像 |
| `/sdcard/xinhao/qemu/` | QEMU 相关文件 |
| `/sdcard/xinhao/server/` | 服务相关文件 |
| `/sdcard/xinhao/share/` | 分享与临时文件 |
| `/sdcard/xinhao/web_config/` | Web 配置 |

两个实用结论：

- 想换字体、想给备份包挪位置、想放 ISO，都进对应子目录操作，别散落在 Download 里。
- 官方 Wiki 特别提醒：**不建议把主要数据放进 `Android/data` 路径**，卸载应用或系统清理时那里的数据更容易被连带删除。数据目录建议留在内部存储方案下。

## 四、定时任务与 ZT 设置

- **定时任务**（入口在 ZT 功能 > 定时任务）：图形化管理周期执行的 Termux / Shell 脚本，不用自己写 crontab。相关文件集中在家目录的 `~/.timerdir/` 下（`termux_timer.sh`、`shell_timer.sh`，日志在 `~/.timerdir/log/`）。三条实用建议：脚本先在终端手动跑通一次再挂定时；脚本里写文件用绝对路径；任务没按时跑先看日志目录。后台不执行多半是省电策略杀了进程，给 ZeroTermux 关电池优化、允许后台运行。
- **ZT 设置**：ZeroTermux 自身设置的集中地，包括使用习惯（菜单唤出手势）、语言切换、实验功能等。你改过使用习惯后菜单还是老样子，重启应用再看。
- **MOE全能 的警告**：官方 Wiki 明确标注其基础（TMOE）**已被归档**，且运行可能改动当前环境——没有折腾与恢复 ZeroTermux 环境经验的话别乱点；真要用，先按 [环境备份与恢复方法](环境备份与恢复方法.md) 做一次备份再动手。

## 五、下载站与在线资源

ZeroTermux 内置了资源下载站入口，官方也有独立的资源站（[https://d.icdown.club/](https://d.icdown.club/)），内容以网友上传的 Linux 一键恢复包和插件为主。用的时候记住两条：

1. 从下载站或第三方渠道拿到的恢复包，**先确认它确实是给 ZeroTermux 用的**（不同 Termux 分支的恢复包不通用），不确定就问包的作者。
2. 恢复包的放置位置与还原操作见 [环境备份与恢复方法](环境备份与恢复方法.md)。
