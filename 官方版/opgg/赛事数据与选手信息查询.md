## 一、手机 App 里的赛事板块

主 App 的赛事（Esports）板块能满足轻量观赛需求：翻赛程、看战队与选手资料。进入一场比赛的详情页可以看到双方选手，点选手名字进入其个人资料页；部分场次提供比赛视频入口，回放更新快慢以你打开时的界面为准。

想追得更细（预测、榜单、开赛提醒），用下一节说的官方电竞应用。

## 二、官方电竞应用：专看职业比赛

OP.GG 把电竞数据单独做了一个移动应用（OP.GG 电竞 / OP.GG Esports，官网入口 [esports.op.gg](https://esports.op.gg/)），和主 App 分工明确，功能包括：

| 功能 | 内容 |
| --- | --- |
| 比赛赛程 | 选定想看的联赛，翻该联赛的赛程；可对单场比赛设置开赛推送 |
| 比赛结果 | 赛后数据回顾，能看到双方选手当场的出装和符文 |
| 胜负预测 | 赛前预测胜负、查看投票比例（官方标注目前仅限全球总决赛和 LCK 联赛） |
| 战队 / POG / 英雄排名 | 各联赛战队排名、每场最佳选手（POG）榜、英雄选取禁用榜 |
| 战队与选手信息 | 选手数据、战队成绩与历史 |

注意两点时效性：胜负预测的覆盖范围以官方当前说明为准；OP Score 选手榜目前官方说明只对 LCK 联赛提供。

## 三、怎么查某个职业选手的战绩

两条路，最后都落到同一个地方 —— 选手的召唤师资料页：

1. **顺着比赛找**：在赛事板块进入一场比赛详情，点选手名字进入个人资料页，看他的联赛数据和历史成绩。
2. **直接搜 Riot ID**：职业选手的 Riot ID 是公开信息，在主 App 的搜索栏选对区服、输入「选手名称#标语」就能查，和查普通玩家一样，方法见 [战绩查询与多人搜索.md](战绩查询与多人搜索.md)。查排名赛战绩用这条路，查联赛官方数据用赛事板块。

## 四、和普通战绩查询的分工

- **排位 / 大乱斗的普通对局数据**：主 App 的战绩查询。
- **职业联赛的官方对局数据**：赛事板块或电竞应用 —— 联赛数据有独立的统计口径，混在普通战绩里搜不到。

两者结合的典型用法：看比赛时在电竞应用里翻选手 POG 榜，再去主 App 搜这名选手的排位战绩，看他最近在练什么英雄，见 [英雄数据与出装查询.md](英雄数据与出装查询.md)。
