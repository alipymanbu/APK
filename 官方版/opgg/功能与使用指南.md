## 一、这个 App 是干什么的

一句话：在手机上查《英雄联盟》对局数据的工具 —— 查自己或别人的战绩、看英雄强度榜、翻热门出装和符文。它不改游戏、不替你打游戏，所有数据都是给你**打之前和打完后**看的。安卓手机版以《英雄联盟》数据为主，云顶之弈、无畏契约等其他项目的数据主要在 op.gg 网页端看。

## 二、首页放什么，可以自己挑

新版首页支持自定义模块，常用的几块：

| 模块 | 里面是什么 |
| --- | --- |
| 我的召唤师 | 绑定 Riot 账号后，自己账号的段位、胜率、近期表现入口 |
| 收藏 | 你收藏过的召唤师，点开直接看战绩 |
| T1 英雄 | 当前版本各位置的顶级强度英雄 |
| 版本说明（Patch Notes） | 最近一次游戏版本改了什么 |
| 轮换英雄 | 本周免费轮换名单 |

编辑首页模块的方式：长按或进入首页编辑入口（不同版本叫法略有差别，认准「编辑 / Edit」字样），把不看的模块去掉、把常看的加上。版本说明和轮换名单这类内容有时效性，以打开当时的显示为准。

## 三、查战绩的入口在哪

底部或顶部的搜索栏就是查战绩入口：先选对区服，再输入「玩家名称#标语」。完整步骤、Riot ID 是什么、多人一次查五个人的方法，都在 [战绩查询与多人搜索.md](战绩查询与多人搜索.md)。

## 四、看英雄强度和出装的入口

首页的英雄榜或底部导航的排行榜进英雄列表，点任意英雄看该英雄的胜率、登场率、推荐符文与出装。具体怎么读这些数据、出装推荐怎么照抄进游戏，见 [英雄数据与出装查询.md](英雄数据与出装查询.md)。

## 五、登录、收藏与账号绑定

- **不登录能用吗**：能。查任何公开数据都不需要登录。
- **登录 OP.GG 账号**（邮箱 + 密码）：解锁收藏、个性化首页等功能。
- **绑定 Riot 账号**：绑定后首页一键直达自己的召唤师页，不用每次手输 Riot ID。绑定入口在「我的资料 / My Profile」页面。

## 六、赛事板块

赛事（Esports）板块能看到赛程、战队与选手资料：进入一场比赛的详情后，可以看参赛选手的数据，点选手名字进入其个人资料页；部分场次提供比赛视频入口，能否回放、回放更新快慢以你打开时的界面为准。想追联赛、看战队排名和选手 POG 榜，OP.GG 另有专门的电竞应用，详见 [赛事数据与选手信息查询.md](赛事数据与选手信息查询.md)。

## 七、深色模式与其他设置

深色模式在设置里开启，夜间看数据不刺眼。其他值得顺手看的设置项：语言（改中文，见 [下载与安装教程.md](下载与安装教程.md)）、通知开关（赛事提醒类）、缓存清理（数据加载异常时用，进一步排查见 [常见问题解答.md](常见问题解答.md)）。
