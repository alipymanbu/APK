# OP.GG 手机版与电脑版的区别

> 搜「opgg」时经常同时冒出手机 App 和电脑版，两者名字一样、能做的事不一样。本篇用一张表讲清区别，帮你不装错、不白找功能。

## 一、一张表看清分工

| 能力 | 手机版 App | 电脑版 Desktop |
| --- | --- | --- |
| 查战绩、查英雄数据、看出装符文 | 有（主要用途） | 有 |
| 对局内悬浮窗（实时出装、对手信息、技能计时） | 没有 | 有，默认快捷键 Shift + Tab |
| 选人阶段自动设符文 / 召唤师技能 | 没有 | 有 |
| 当游戏启动器用（识别已装游戏、一键开局） | 没有 | 有，覆盖英雄联盟、云顶之弈、无畏契约等 |
| 整合搜索快捷键 | 没有 | Ctrl + Space 一步搜功能或玩家 |
| 随时随地查（赛前翻一眼、赛后查复盘） | 有 | 只在电脑前 |

一句话分工：**电脑版管「打游戏的时候」，手机版管「不打游戏的时候」** —— 对局里的实时辅助（悬浮窗、自动符文）只有电脑版有；躺在沙发上翻战绩、看榜单、查对位，手机版更顺手。

## 二、怎么选

- 只想赛前查对面战绩、赛后复盘、翻英雄出装：手机版够了，不需要装电脑版。
- 想在对局里实时看出装推荐、对面召唤师技能计时：装电脑版，游戏和 OP.GG 一起开着打。
- 两边都支持登录 OP.GG 账号，账号体系是同一个。

## 三、各自的获取方式

- 手机版：安装包获取与安装步骤见 [下载与安装教程.md](下载与安装教程.md)。
- 电脑版：从官网下载页获取（[op.gg/desktop](https://op.gg/desktop/)），装在打游戏的 Windows 电脑上；它会自动识别机器上已装的游戏。

## 四、容易搞混的两件事

1. **在手机上找悬浮窗**：找不到是正常的，那不是手机版的功能，详见 [常见问题解答.md](常见问题解答.md) 里「游戏里悬浮窗」一节。
2. **以为电脑版就是个网页**：电脑版是独立安装的客户端程序，不是浏览器里的 op.gg 网页；网页版数据与两者同源，但功能是第三套（查数据为主，无对局辅助）。
