## 一、先弄清 Riot ID

现在查《英雄联盟》战绩用的是 Riot ID，不是旧的召唤师名。它由两部分组成：

```text
玩家名称#标语
例：Hide on bush#KR1
```

搜人时必须带完整格式，`#` 后面的标语（tagline）不能省，大小写和空格也要一致。三个查看自己 Riot ID 的地方：

| 位置 | 操作 |
| --- | --- |
| 英雄联盟客户端 | 个人资料页里直接显示 |
| Riot 账号管理页 | 打开 [account.riotgames.com](https://account.riotgames.com/) 登录后查看或修改 |
| OP.GG 里 | 用 Riot 账号登录后，搜索栏下拉列表顶部点「查看 Riot ID」，直达自己的战绩页 |

## 二、选对区服再搜人

搜索栏旁边先切换区服，再输入 Riot ID。常见区服对照：

| 区服 | 缩写 |
| --- | --- |
| 韩服 | KR |
| 北美 | NA |
| 欧洲西部 / 东部 | EUW / EUNE |
| 日本 | JP |
| 台服 | TW |
| 东南亚 | SEA |
| 越南 | VN |
| 土耳其 / 俄罗斯 | TR / RU |
| 巴西 / 拉美 | BR / LAS、LAN |
| 大洋洲 / 中东 | OCE / ME |

**列表里没有国服** —— 国服（腾讯代理）的数据不在收录范围内，想查国服战绩只能用国服官方渠道，在 OP.GG 上怎么搜都是搜不到的。

## 三、战绩页里看什么

搜到人之后，战绩页从上到下一般是这几块：

- **段位与胜率**：当前赛季段位、排位胜率、场次；往下滑还能看历史赛季的段位记录。
- **常用英雄**：最近使用最多的英雄及各自胜率。
- **近期对局列表**：每局的英雄、KDA、补刀、经济、胜负；点进单局看完整数据。
- **OP Score**：单局表现的 0~10 分评分，表现突出的会带 MVP / ACE 类徽章和一句话点评 —— 看队友这局是不是在划水，直接看这个数比翻 KDA 快。

两个好用的筛选：

1. **按对局模式过滤**：排位单双排、灵活组排、大乱斗、斗魂竞技场等可以分开看（可选哪些模式以当前版本显示为准）。看「他大乱斗玩得多还是排位玩得多」就靠这个。
2. **细分标签页**：资料页里除了总览，一般还有按英雄细分的数据页、英雄熟练度页，有的版本还有「正在进行的对局」入口 —— 对方挂着游戏时能直接看他这局在玩什么。

## 四、多人搜索：开黑前一次查五个

- 在搜索栏用**英文逗号**把多个 Riot ID 隔开，一次提交，所有人在同一屏对比段位、胜率、常用英雄。
- op.gg 网页端的「多重搜索」页还支持把聊天框里整段队伍信息直接粘贴进去自动识别；手机 App 内以逗号分隔输入为准。

排位前查一遍对面的常用英雄和胜率，再看 [英雄数据与出装查询.md](英雄数据与出装查询.md) 里对位数据那一节，就知道这把该防谁。

## 五、搜不到人或数据不对时

按顺序排查：

1. **刚打完的局查不到**：数据同步有延迟，等一会儿再刷新。
2. **区服选错了**：先确认对方在哪个服，再切换。
3. **对方刚改过名**：按新的 Riot ID 搜；旧名字搜不到是正常的。
4. **只输名称没输标语**：带上 `#标语` 重搜。
5. 还是不行：见 [常见问题解答.md](常见问题解答.md) 的「搜不到某个玩家」一节。
