## 一、装之前先弄清楚：这是哪个 wallhaven

wallhaven.cc 是一个壁纸分享网站（入口：[https://wallhaven.cc/](https://wallhaven.cc/)），内容全部由社区上传，官方在 FAQ 里明确说明**目前没有官方手机 App**，并且提醒用户警惕任何索要登录信息的应用。

你手里这个 wallhaven 安卓客户端是**第三方开发**的中文界面应用，内容通过 wallhaven.cc 的公开接口获取，界面与官网数据基本同步。因为"没有官方 App"，搜索引擎里搜 wallhaven 会同时撞见多个第三方客户端（例如 Google Play 上的 Wallhaven Walpapers、以及中文界面的这一款），它们功能相近但**不是同一个安装包**。

判断你装的是不是本篇对应的包，看这几项（以 2026-09 核对的安装文件信息为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 7.7.7 |
| 包名 | `www.wallhaven.top` |
| 安装包大小 | 7.84M |
| MD5 | `0805EFB11E7C8C8733DB729480639B33` |

装完后在系统「设置 → 应用管理」里打开它的应用信息，核对包名一栏即可。

## 二、安装前的三件事

1. **系统版本**：安卓 5.2 及以上，低于这个版本装不上。
2. **存储空间**：安装包只有 7.84M，但之后下载的壁纸原图（常见 2K、4K）会持续占用存储，建议预留几百 MB 以上。
3. **允许安装未知来源应用**：这个包不在应用商店里，安装时系统会拦一道。入口各品牌叫法不同，在系统设置里搜「安装未知应用」，给浏览器或文件管理器授权即可。

## 三、获取安装文件并安装

1. 从上面的 **wallhaven 安装文件资源（夸克网盘）** 进入，转存到自己网盘后把 apk 下载到手机。
2. （可选）校验文件完整性：用文件管理器或校验工具算一下 apk 的 MD5，与上表的 `0805EFB11E7C8C8733DB729480639B33` 对得上说明文件没损坏、没被改过。
3. 点击 apk，按提示允许「来自此来源的应用」，确认安装。
4. 装完点打开，或回桌面找图标。

## 四、首次打开

- App 不需要注册登录，打开后**直接进入壁纸大厅**，看到的就是最新上传的图流，上下滑动翻页。
- 涉及账号能力的只有一处：API 密钥。它决定你能看到哪些级别的内容、搜索是否跟随你账号的默认筛选，获取与填入方法见 [API密钥获取与设置](API密钥获取与设置.md)。
- 想快速找到适配自己屏幕的图，先看 [搜索与筛选技巧](搜索与筛选技巧.md) 里的分辨率与比例筛选。
- 装好后如果列表一直转圈、图刷不出来，多数不是安装的问题，按 [常见问题与加载失败排查](常见问题与加载失败排查.md) 走一遍。

## 五、更新与卸载

- 这个客户端没有应用商店的推送更新渠道，网盘里的 7.7.7 就是本篇对应的版本；之后是否有新版本以你获取安装包的地方为准。
- 卸载走系统「设置 → 应用管理」。注意卸载会清掉你在 App 里填过的 API 密钥与本地记录；密钥可以随时在官网重新复制或重新生成，方法见 [API密钥获取与设置](API密钥获取与设置.md)。
