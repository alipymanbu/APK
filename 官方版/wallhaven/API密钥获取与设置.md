## 一、密钥能多做什么

API 密钥（API Key）是 wallhaven.cc 官方发放的访问凭证：你在官网账户设置里生成，免费，可随时重新生成（旧的立即失效）。它不是会员码，也不收费。

有没有密钥的差别：

| | 没有密钥 | 填了密钥 |
| --- | --- | --- |
| 可见级别 | 默认前两级（SFW / Sketchy） | 按你账号在官网设置的浏览级别返回 |
| 搜索行为 | 通用默认筛选 | 跟随你账号的默认筛选条件 |
| App 内的级别开关 | 「需 API 密钥」的选项无效 | 打开后列表才会出现对应内容 |

App 里「壁纸等级选择」中标着「设置API可开启」的那一档，靠的就是这个密钥。官方文档对它的解释：带密钥的请求等同于以你的账号身份查询，内容范围完全由你账号在官网的设置决定。

## 二、获取步骤（官网，免费）

1. 浏览器打开 [https://wallhaven.cc/](https://wallhaven.cc/)
2. 注册一个免费账号并登录（注册入口在页面右上角）。
3. 点右上角头像，进 **Account Settings（账户设置）**。
4. 找到 **API Key** 一栏，把那串字符完整复制下来。

这一串就是密钥。之后想换，回到同一页面点重新生成即可。

## 三、填进 App（以 7.7.7 为准）

1. 打开 App，右上角**三个点 → 设置**（部分版本的入口在侧边菜单的「功能设置」里）。
2. 往下滑，找到「**API 密钥设置**」。
3. 点「设置 API 密钥」，把复制的密钥粘贴进去，点确定。
4. 有「检测密钥有效性」按钮的版本点一下，确认通过。
5. **重启 App** 生效；再到「壁纸等级选择」里打开带「设置API可开启」标记的级别。

不同版本的菜单叫法略有差异（「功能设置」「API密钥」「密钥设置」都出现过），认准 **API 密钥** 这个关键字即可，位置都在设置页里。

## 四、检测不通过 / 填了没反应

按顺序排查：

1. **复制带了空格或换行**——最常见。重新复制一次，确认首尾干净。
2. **密钥被重置**——你在官网重新生成过的话，旧密钥立即失效，拿新的再填。
3. **网络不通**——检测请求要连官网，连不上自然失败，见 [常见问题与加载失败排查](常见问题与加载失败排查.md)。
4. **重启没做**——部分版本填完不重启不生效。
5. **级别开了但列表没变化**——带密钥的搜索跟随你**账号在官网的默认筛选**。去官网 Account Settings 里检查你账号的浏览级别设置，那里没开，App 里开了也没用。

## 五、安全边界（官方的提醒）

- 官方 FAQ 原话大意：**目前没有官方 App**，警惕任何要求你输入 wallhaven 登录信息的应用；**API 密钥就足以访问你的设置**。
- 落到实处就是一条：**只填密钥，不填账号密码**。任何 App 或网页要你的 wallhaven 账号密码，直接关掉。
- **不要用别人分享的密钥**：密钥随时可被持有人重置，失效是常态；而且它关联的是别人的账号筛选设置。
- 密钥泄露（比如发错过、贴错过）就去官网重新生成一次，旧的作废，一分钟的事。
