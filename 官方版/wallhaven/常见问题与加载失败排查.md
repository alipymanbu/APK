## 一、列表一直转圈 / 图刷不出来

**第一步永远是：先分清是不是源站的问题。** App 的全部内容来自 [wallhaven.cc](https://wallhaven.cc/)，这个网站由一个小团队维护，**偶发停机维护是常态**（官方在 BlueSky 账号 [@wallhaven.bsky.social](https://bsky.app/profile/wallhaven.bsky.social) 和 Discord 服务器发状态公告，官网 [FAQ](https://wallhaven.cc/faq) 也留有入口）。

| 现象 | 结论 |
| --- | --- |
| 浏览器直接打开官网也打不开 | 源站停机，等恢复即可，App 没坏 |
| 浏览器能开官网，App 刷不出来 | 继续往下排查 |

浏览器能开、App 不行时按顺序试：

1. 换网络：Wi-Fi 和流量互切一次。
2. 关代理 / VPN / 加速器再试（这类工具经常挡掉图片域名的请求）。
3. 系统设置里清除 App 的**缓存**（不是数据），重开。
4. 还不行就清除**数据**重进——注意清数据会把你填过的 API 密钥清掉，先按 [API密钥获取与设置](API密钥获取与设置.md) 把密钥复制一份存好。

## 二、图能刷出来但下载失败

1. 重试一次；点开同标签下的其他图试试——个别文件可能在源站已被移除（上传者删除或内容被下架），换一张即可。
2. 检查存储空间：原图常见 2K、4K，单张几 MB 到十几 MB，空间不足会静默失败。
3. 大图连下多张失败，多半又是网络路径问题，参照第一节第 2、3 步。

## 三、密钥检测不通过 / 填了没反应

这是单独一个话题，排查清单在 [API密钥获取与设置](API密钥获取与设置.md) 第四节，最常见的三个原因是：复制带了空格、密钥在官网被重新生成过、填完没重启 App。还有一个容易忽略的：带密钥的搜索跟随**你账号在官网的默认筛选**，官网那边没开对应级别，App 里开了开关也看不到内容。

## 四、App 打不开 / 闪退

按顺序：

1. 重启手机。
2. 清除 App 缓存。
3. 清除数据（记得先备份密钥）。
4. 卸载重装：安装包获取方式见 [下载与安装教程](下载与安装教程.md)。
5. 重装后仍闪退，对照安装篇核对包名与版本——装到同名不同包的另一个客户端时，出的问题不一样。

## 五、第三方客户端要知道的一件事

这个 App 不是官方产品，它的功能范围由它自己实现，与官网网页版并不一一对应：网页版有的收藏合集、评论、上传等社区功能，App 里未必有，以 App 内实际提供的为准。其中收藏合集（collections）是官网的账号功能：在网页端登录后可以把收藏的图整理成合集，公开的合集任何人都能浏览，这个体系在官网侧不受客户端影响。数据源（wallhaven.cc）的接口或策略一旦变动，客户端的表现也可能跟着变——遇到"昨天还好好的、今天就不行"的情况，先按第一节的顺序排查，再等客户端更新。
