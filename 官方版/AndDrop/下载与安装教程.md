## 一、先弄清楚你要装的是什么

AndDrop 是一个装在**安卓手机**上的应用，用途是把手机里的照片、视频、文档等文件通过局域网直接传到电脑，不走数据线。它在手机应用列表里显示的名字是**「隔空传送」**——你装完找不到「AndDrop」这个图标时，先按「隔空传送」找，是同一个应用。

本文涉及的具体版本信息如下，均为安装包本身的实际参数：

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.0.2 |
| 包名 | `com.neure.anddrop` |
| 安装包大小 | 约 19.94 MB |
| MD5 | `CF648C5DAEB38D326D934541F6744BF1` |
| 开发者 | 合肥神经网络科技有限公司 |

如果你之后在别处看到更高的版本号，那通常是官方后来发布的新版；装哪一版取决于你手上的安装包，功能层面差异以实际使用为准。

## 二、获取安装文件资源

安装包通过夸克网盘分享获取：[AndDrop 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d47f1104cbc4)——打开后把文件**转存到自己的网盘**再下载，或者直接在网盘页面下载。

拿到的是 `.apk` 文件，文件名里会带版本号（如 `AndDrop_v1.0.2.apk`）。下载到手机存储或先用电脑中转再传给手机都可以——如果你打算用「电脑传给手机」的方式装，反而会碰上「手机上还没有传输工具」的死循环，所以更顺的做法是：

1. 电脑上打开网盘链接，下载 `.apk` 到电脑；
2. 用数据线或者你现有的任意方式（微信文件传输助手、QQ、邮箱附件等）把这个 `.apk` 弄进手机存储；
3. 在手机上点开它进入安装。

当然，直接用手机浏览器打开网盘页面下载，一步到位，通常更快。

## 三、安装步骤

1. 在手机上点开下载好的 `.apk` 文件，系统会提示「是否安装这个应用」；
2. 部分手机会先弹「禁止安装未知来源应用」的提示——在弹窗里选「设置」或「仍要安装」，允许本次安装即可。各品牌入口不同：小米在「安装」弹窗里直接勾选，华为/荣耀可能要求你到「设置 > 安全 > 更多安全设置」里临时允许，装完建议把开关改回去；
3. 等进度条走完，点「完成」或「打开」；
4. 到桌面找**「隔空传送」**图标，能打开就说明装好了。

安装本身不需要登录账号，也不需要注册。

## 四、装完后的两件小事

- **核对包名**：在「设置 > 应用管理」里搜「隔空传送」，详情里的包名应显示 `com.neure.anddrop`。这是确认你装的是本文所述应用的可靠依据，避免与同名应用混淆。
- **权限**：首次使用时它会请求文件/存储相关权限，这是传输文件必须的，允许即可。传文件的具体操作见 [手机与电脑互传文件步骤.md](手机与电脑互传文件步骤.md)。

如果装好了却发现手机和电脑互相找不到，直接跳到 [连不上设备怎么办.md](连不上设备怎么办.md) 按清单排查；其他使用疑问（能不能传大文件、收不收费等）看 [常见问题解答.md](常见问题解答.md)。

## 五、对文件不放心时：核对 MD5

如果你是在电脑上下载的安装包，想确认下载过程中没有损坏或被替换，可以核对 MD5 值（应为 `CF648C5DAEB38D326D934541F6744BF1`）。Windows 自带工具就能算：

```powershell
certutil -hashfile "C:\Users\你\Downloads\AndDrop_v1.0.2.apk" MD5
```

把路径换成你的实际存放位置，回车后输出的第二行就是 MD5 值（忽略大小写和空格，逐位一致才算对）。对不上就重新下载一次，别拿存疑的包去装。
