# PokeHub 卡牌交换与好友添加方法

> 本篇讲怎么用 PokeHub 找到交换对象、发布求换信息、复制好友 ID 加好友，以及谈妥之后回游戏里完成交换。

先说清楚一件事：PokeHub 本身不完成交易。它是《Pokémon TCG Pocket》的第三方配套工具，负责「找人」——你在上面发布自己多余的卡和想要的卡，它把供需对上、给你对方的好友 ID，真正的交换动作要回游戏里完成。所以整个流程分三段：找对人、加好友、回游戏换卡。

## 一、找对人：查卡与匹配

1. **先查缺什么**：卡牌库覆盖游戏里可交换的卡牌，含各语言版本，可以按稀有度、属性、卡包、系列筛选。换卡前先把你缺的卡搜出来，看有多少人在出。
2. **把自己的信息挂出去**：把多余的卡和想要的卡分别填进库存与求换清单，别的玩家搜卡时就能搜到你。信息填得越全，被匹配命中的概率越高。
3. **让匹配替你跑**：匹配机制会把「有你缺的卡、又要你多余的卡」的玩家排到前面，并参考对方在线状态与历史交换记录，省去一页页翻人肉筛选的功夫。

## 二、加好友：复制好友 ID 就行

- 游戏内的好友位有限，PokeHub 上加好友没有数量上限——先把人攒起来，需要换卡时再去游戏里加。
- 进对方个人主页，一键复制好友 ID，回游戏用好友码加人，不用对着屏幕手输一长串字符（游戏内好友码是一串 16 位数字，点头像就能看到自己的）。
- 加上之后可以互赞、互相帮「奇缘抽卡」（wonder pick）、约对战，攒住一批常联系的卡友比每次现找人快得多。

## 三、回游戏完成交换

1. 在 PokeHub 上和对方谈好换哪几张、什么条件。
2. 回《Pokémon TCG Pocket》的好友列表，把对方加成游戏好友后发起交换。
3. 高稀有度的卡要消耗游戏内交换资源（2025 年 7 月底起是 Shinedust，旧版叫「交易代币」），谈之前先确认自己付得起，具体费用与交换体力规则见 [游戏内换卡规则与资源消耗.md](游戏内换卡规则与资源消耗.md)。
4. 不是所有系列都开放交换，个别系列在游戏内暂不支持，谈单前先查一下（哪些系列换不了也写在上面那篇里）。

## 四、让对方更快找到你

- 把库存与求换清单填全，空着的项目等于把主动搜索的人挡在门外。
- 求换门槛别定太高。有老玩家总结过：清单里全是顶级稀有卡，基本没人主动来搭；搭几张平价卡进去，成交率明显更高。
- 想收外文版卡，跨语言找人正是这类工具的主场——同一张卡在不同地区的保有量差很多，海外玩家手里的版本可能正是你这边难见的。
- 保持在线。匹配结果会优先考虑在线玩家，挂着不登录就轮不到你。
- 想在社区里刷存在感，可以做几张自定义卡发出去，做法见 [自定义卡牌制作与分享.md](自定义卡牌制作与分享.md)。
