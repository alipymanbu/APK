## 一、先说结论：账号相通，入口不同

两端是同一个产品的两个入口：网页端上线在先，手机 App 是 2025 年才推出的（第三方报道的时间线）。用同一个账号分别登录两端，会员状态、灵感值余额、作品记录是共用的——**不存在「App 的灵感值」和「网页的灵感值」两套账**。所以选哪端只看顺手，不影响资产。

## 二、入口与平台覆盖

| 设备 | 怎么用 | 说明 |
| --- | --- | --- |
| 安卓 / iOS 手机 | 应用商店搜「可灵AI」下载 App，或用本文网盘里的安装包 | 安装包核对方法见 [下载与安装教程.md](下载与安装教程.md) |
| Windows 电脑 | 浏览器打开网页版 | 官方没有 Windows 桌面客户端，网传「PC 安装包」别下，风险高 |
| Mac 电脑 | 浏览器开网页版；国际站有原生 App，第三方渠道资料标注要求 M1 芯片起 | 以 App Store 页面当时标注为准 |

网页版入口：国内站在 [app.klingai.com/cn](https://app.klingai.com/cn/)，国际站在 [kling.ai](https://kling.ai/)。两站账号体系独立，国内手机号注册的账号登国际站不是同一个账户，价格体系也不一样（见 [灵感值与会员价格说明.md](灵感值与会员价格说明.md) 第三节）。

## 三、功能侧重差异

核心生成能力（文生视频、图生视频、图片、数字人、对口型）两端都有，但侧重不同：

- **网页端更全**：网页端上线在先，有用户整理的对比里提到运镜画笔这类精细控制在网页端更完善；网页端还上线过灵动画布这类多人协同工作台，移动端未必同步提供。
- **移动端更快**：App 胜在碎片时间提交任务、后台排队（排队机制见 [生成排队与失败处理.md](生成排队与失败处理.md)），以及直接调相机拍照、选相册图喂给图生视频——手机上做这一步比网页传图快。
- **入口排布不同**：同一功能在两端的菜单位置、名称可能不一样，教程截图对不上时以你手上一端的实际界面为准。

## 四、什么场景用哪端

| 场景 | 建议 |
| --- | --- |
| 通勤路上随手生成、发社交平台 | App |
| 写长提示词、反复改稿对比参数 | 网页（键盘与大屏改字效率高得多） |
| 在电脑前处理照片素材再生成 | 网页 |
| 蹲热点抢时效、多任务并行排队 | 网页提交 + App 收通知，两端一起盯 |

两端来回切换没有任何成本，同一批任务换个设备继续盯即可。
