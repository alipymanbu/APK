## 一、四段结构：主体、动作、环境、镜头

一条稳定的视频提示词，通常按这个顺序写四样东西：

```
[主体是谁/是什么] + [做什么动作] + [在什么环境] + [镜头怎么动]
```

对照一个例子：「一位穿米色风衣的老人，慢慢走过落满银杏叶的胡同，午后侧光，镜头从背后缓缓推进」。四段各占一处，模型每段都有明确的东西可抓。

几条写法上的分寸：

- **动作写「看得见的」**：写「转身、抬头、伸手、镜头推近」这类可成像的动作，不写「开心地回忆往事」这类拍不出来的心理活动。
- **一段话一个场景**：想换场景就拆成多镜头分镜（见第四节），别在一条提示词里塞进三个时空，模型会把它们糊在同一帧里。
- **形容词够用就停**：「宁静唯美的梦幻氛围」这类堆砌对成片帮助有限，光影和天气（侧光、黄昏、薄雾）比抽象词管用。
- 官方另有提示词指南与「灵感学院」视频教程，想系统学可以去看：[灵感学院](https://courses.klingai.com/)。

## 二、常用运镜词

镜头语言是拉开成片质感差距最便宜的一招——同一句主体描述，换个镜头词就是两支片子。常见的运镜词有这些（以生成页提供的选项与官方教程为准）：

| 想要的效果 | 可以写 |
| --- | --- |
| 靠近主体 | 镜头缓缓推进 / 推近 |
| 拉开视野 | 镜头逐渐拉远 |
| 左右扫视 | 水平摇镜 / 水平运镜 |
| 上下扫视 | 垂直摇镜 / 垂直运镜 |
| 环绕主体 | 旋转运镜 / 环绕镜头 |
| 视角变化 | 俯视、仰视、第一人称视角 |

一次别堆太多：一条提示词里放一两个镜头动作，模型执行得最稳；「推进同时环绕再拉远」这种连环调度很容易互相打架。

## 三、图生视频的提示词重点

图生视频里，图已经定死了「主体和环境」，你的提示词只负责一件事——**让它动起来**：

1. 先看图里有什么，再写「谁做什么」，不要重画这张图的内容（写了也白写，画面以你的图为准）。
2. 动作幅度由小到大试：先写「头发被风吹动、人物眨眼」这类微动作，稳定后再加大到走动、转身。一上来就写剧烈动作，肢体崩的概率高。
3. 要精确落点就上**首尾帧**：给起点图和终点图，中间过渡交给模型，比纯文字描述「最后转过头来」可靠得多。
4. 进阶玩法是**动作控制**：上传一段 3~30 秒的参考视频，把里面的动作迁移到你图上的角色——适合舞蹈复刻、表情包二创这类「动作比画面重要」的场景。

## 四、多镜头分镜怎么写

3.0 系列支持在一次生成里编排多个镜头（官方介绍最多 6 个镜头切换）。写法上把每个镜头拆开描述：

```
镜头1：中景，老人推门走进书房，镜头跟随平移。
镜头2：特写，桌面上的旧照片被风掀起一角。
镜头3：远景，镜头拉远，窗外的雨落在玻璃上。
```

要点：

- 每个镜头单独给「景别 + 主体动作 + 镜头运动」，别把两个镜头的内容写进同一行。
- 想要人物跨镜头保持长相一致，用主体参考类功能喂参考图，光靠文字描述「同一个人」是保不住的。
- 多镜头单次消耗的灵感值比单镜头高，先用单镜头把每个画面磨定，再合成多镜头版本。

## 五、会被拦下的内容

内容审核是这类工具的硬边界，写进去直接生成失败。有用户整理的反馈里，以下几类最容易触发：

- **真人肖像**：点名真实人物（明星、政要）的描述；
- **政治相关**：政治人物、政治事件的场景化描写；
- **血腥暴力**：明确的暴力、血腥画面描述。

被拦的典型信号是提交后很快报失败、且换设备换时间照样失败——那就是描述本身的问题，不是排队问题（排队类故障见 [生成排队与失败处理.md](生成排队与失败处理.md)）。改法是把指向具体真人的描述换成「一个穿着相似的人」这类场景化写法，把叙事重心放到环境与动作上。具体审核尺度以平台当时的规则为准。
