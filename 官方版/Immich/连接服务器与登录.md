## 一、服务器地址怎么填

App 首屏要求填的就是服务器地址，默认格式：

```text
http://<服务器IP>:2283
```

`2283` 是 Immich 服务器的默认端口，浏览器访问网页端用的也是同一个地址。举例：服务器局域网 IP 是 `192.168.1.10`，就填 `http://192.168.1.10:2283`。

两个常见误区：

- **填成公网 IP**：在家里 Wi-Fi 下应该填服务器在局域网里的内网地址（一般是 `192.168.x.x`、`10.x.x.x` 或 `172.16.x.x` 开头）。有人在服务器上执行 `ip a` 后把第一个显示的公网地址抄了进去，结果怎么都连不上——内网地址通常排在后面。
- **漏掉端口**：只填 `http://192.168.1.10` 不带 `:2283`，等于访问 80 端口，同样连不上。

手机和服务器要在同一网络里（或已按本文第四节打通外网）才能连通。

## 二、登录步骤

1. 打开 App，在服务器地址一栏填入上面的 URL；
2. 输入账号密码——这个账号就是你在网页端首次注册的那个（第一个注册的用户是管理员）；
3. 登录成功后 App 会开始同步时间线，第一次会先构建缩略图索引，图库大时需要等。

全家共用一台服务器时，每个家人用自己的账号登录各自的手机，账号由管理员在后台添加，账号划分与共享方式见[家人共享与多用户](家人共享与多用户.md)。

账号是否可用，可以先在浏览器里用同样的账号登录网页端验证一遍，能登进网页端就说明账号本身没问题。

## 三、登录失败的几种典型情况

### 更新之后登录不上

先核对**客户端与服务器的大版本是否一致**（major.minor，比如都是 3.0.x）。官方 FAQ 明确把「版本不匹配」列为更新后无法登录的首要原因。服务器端升级了、手机端还停在旧版本（或反过来），就会出现这种情况；应用商店的上架审核有时会让新版晚几天才刷出来。

### 状态栏显示 Server Offline / Version Unknown

服务器实际上在跑，但反向代理没有放行 **WebSocket**——把反向代理配置里的 WebSocket 升级头（`Upgrade` / `Connection`）加上即可。

### 用了自签证书或 Basic Auth

自签证书、Basic Auth、自定义请求头、双向 TLS 在手机端都属于实验性支持，官方文档明确说它们**经常无法配合视频播放、资源上传和下载使用**，而且官方不再主动开发这些特性。想让手机端稳定工作，官方 FAQ 给的替代路子有三条：用 App 的服务器地址切换功能（内网、外网各存一套地址）、直接走 VPN，或给域名配一张免费受信证书（如 Let's Encrypt）；再不然先在局域网里用 HTTP 直连。

### 地址本身就不通

按这个顺序查：服务器上执行 `docker compose ps` 确认容器都在跑 → 服务器本机 `curl -I http://127.0.0.1:2283` 确认服务有响应 → 检查系统防火墙有没有放行 2283 → 确认手机填的是内网地址。更完整的排查表在[常见问题排查](常见问题排查.md)。

## 四、人不在家怎么连

默认情况下 Immich 只在局域网内可用，出门后想让手机还能备份，常见两条路：

- **端口转发**：在路由器上把外网端口映射到服务器的 2283。前提是宽带本身有公网可达性（部分运营商不给公网 IPv4），而且要配好 HTTPS，否则流量明文跑公网不安全。
- **虚拟组网（VPN）**：用 WireGuard、Tailscale 这类工具把手机「拉回」家庭网络，手机上填服务器的组网地址即可。社区里自托管用户普遍偏好这条，因为不用在路由器上开洞。

无论哪种，都不改变登录方式——变的只是那个 IP/域名填谁。外网走反向代理时别忘了 WebSocket 那一条；证书如果自签，会撞上第三节说的实验性支持限制。

连上并登录之后，下一步就是挑相册开备份，见[照片备份设置](照片备份设置.md)；服务器还没搭好的先回[服务器搭建入门](服务器搭建入门.md)。
