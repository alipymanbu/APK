# 从 Google 相册迁移到 Immich

> 把 Google 相册里的存量照片视频搬进自己的 Immich 服务器。最大的坑：Takeout 导出的压缩包把拍摄时间等元数据拆进了 JSON 文件，直接上传会让所有照片时间错乱——要用 immich-go 把元数据拼回去再传。
> **相关文档**：[服务器搭建入门.md](服务器搭建入门.md) · [照片备份设置.md](照片备份设置.md) · [常见问题排查.md](常见问题排查.md)

## 一、为什么不能直接拖进去

Google Takeout 导出的照片包里，每张照片旁边都躺着一个同名 JSON 文件——拍摄时间、地点这些信息被从照片里抽出来放进了 JSON。你在网页端或手机端直接上传这些照片，服务器读不到 EXIF 里的时间，整批照片会全显示成「今天上传」。

社区工具 **immich-go** 就是为这个准备的：它直接读 zip 包（不用你手动解压），把 JSON 里的元数据拼回照片，再按正确的相册结构、时间信息上传到服务器。多个独立教程的结论一致：迁移 Google 相册，用它是最省事的路。

## 二、第一步：申请 Google Takeout 导出

1. 打开 [takeout.google.com](https://takeout.google.com/) 并登录；
2. 点「全部取消选择」，只勾选 **Google 相册**；
3. 一路「下一步」，交付方式选「通过电子邮件发送下载链接」；
4. 文件类型选 `.zip`、分卷大小选 **50 GB**（分卷越大、文件数越少）；
5. 点「创建导出」。

图库大的话，Google 生成导出要几小时到几天，链接会发到邮箱。把所有分卷 zip 都下载到电脑上，**不要解压**，immich-go 直接吃 zip。另外注意：每个下载链接的下载次数有限制，用完了要重新生成导出（具体次数以 Google 当时规则为准）。

## 三、第二步：用 immich-go 上传

immich-go 从 [github.com/simulot/immich-go/releases](https://github.com/simulot/immich-go/releases) 下载对应系统的版本（Windows 下解压出 `immich-go.exe`），放到 zip 文件同一目录。

1. 先在 Immich 网页端生成 API 密钥：**Account Settings → API Keys → 新建**，权限给全，密钥只显示一次，保存好；
2. 在该目录打开终端，先空跑一遍验证连接和权限：

```bash
immich-go upload from-google-photos --server=http://服务器IP:2283 --api-key=你的密钥 --dry-run takeout-*.zip
```

3. 没有报错，去掉 `--dry-run` 正式上传：

```bash
immich-go upload from-google-photos --server=http://服务器IP:2283 --api-key=你的密钥 takeout-*.zip
```

Windows 用户把命令里的 `immich-go` 换成 `.\immich-go.exe`。这个工具迭代较快，参数名可能随版本变化，以它仓库 README 当时的说明为准；用它上传时服务器会自动按内容去重，跟手机备份用的是同一套校验和机制。

## 四、给磁盘留足余量

两个官方口径叠加起来算：

- 缩略图与转码视频平均会让图库体积再涨 **10%~20%**；
- immich-go 的最佳实践建议导入前预留约 **1.5 倍源数据**的空闲空间。

几百 GB 的图库迁移到一半磁盘写满是很难受的事，动手前先算清楚。数据库目录的摆放要求见[服务器搭建入门](服务器搭建入门.md)：本地 SSD、原生 Linux 文件系统，绝不放网络共享盘。

## 五、迁移期间先别开手机备份

immich-go 上传完只是「文件进了服务器」，后台还要跑缩略图、人脸识别、智能搜索索引——图库越大这一步越久（几万张照片以天计是正常的），期间服务器 CPU 拉满是正常现象，去网页端 Jobs 页面看任务跑完即可。

这个过程别让手机备份同时灌进来：两批数据一起处理会把服务器压得很慢，出问题也难定位。等 Jobs 页面全部跑完、时间线里的日期和相册都对上了，再去[设置手机备份](照片备份设置.md)。

## 六、迁移完成后核对什么

- 抽查几个时间段的照片，拍摄日期是否正确（JSON 元数据拼回成功的标志）；
- 相册结构是否按 Google 相册原来的相册建出来了；
- 视频能不能正常播放——个别老视频格式可能需要服务器转码后才流畅。

之后手机端日常备份、腾空间的用法分别见[照片备份设置](照片备份设置.md)与[释放手机空间](释放手机空间.md)；迁移中或迁移后遇到异常，先翻[常见问题排查](常见问题排查.md)。
