# Immich 常见问题与报错排查

## 一、照片格子上几种云朵角标的含义

开启存储角标（设置 → Photo Grid → Show storage indicator on asset tiles）后，三种状态对应三种图标：

| 状态 | 含义 |
| --- | --- |
| 云朵（仅服务器） | 只在服务器上有：从别的设备传的，或本机删掉了 |
| 云朵（仅本地） | 只在手机上，还没备份 |
| 云朵（本地+服务器） | 本机传上去的，服务器已有，本机文件还在 |

想确认某张照片到底备份成功没有，看这个角标最快。

## 二、登录不上去

按顺序核对：

1. **版本匹配**：客户端与服务器的大版本要一致（major.minor，如都是 3.0.x）。官方 FAQ 把版本不匹配列为更新后无法登录的头号原因；商店版 App 的更新可能因审核晚几天到，等一等或先用 APK 渠道对齐；
2. **账号本身**：同一账号先登录网页端验证，网页端也进不去就是账号问题，不是 App 问题；
3. **还不行**：看手机端 App 内的日志（设置里有日志入口），把报错和服务器端 `docker compose logs immich-server` 的输出对照。

地址、端口填法与内网/公网 IP 的坑见[连接服务器与登录](连接服务器与登录.md)。

## 三、状态栏显示 Server Offline / Version Unknown

服务器在跑但手机端读不到状态，通常是反向代理没有放行 **WebSocket**。在反代配置里补上 WebSocket 升级头即可。局域网直连（不经过反代）一般不会遇到这条。

## 四、服务器地址完全打不开

在服务器上按顺序执行：

```bash
docker compose ps                        # 容器是否都在 Up
curl -I http://127.0.0.1:2283            # 本机是否有 HTTP 响应
```

- 本机有响应、外部没有 → 查系统防火墙和路由器端口规则；
- 本机也没响应 → 看容器日志定位；
- 手机端连不上但浏览器能开 → 多半是 IP 填错（把公网 IP 当内网地址填了）。

## 五、后台备份一直不动

- 到 [dontkillmyapp.com](https://dontkillmyapp.com/) 按品牌关闭对 Immich 的电池优化，这是 Android 版后台失效的最常见原因；
- 检查备份设置里「仅充电时后台执行」是否误开；
- 明白机制：前台备份切后台就停是正常的，前后台是两套互不相通的机制，后台由系统调度器说了算；
- v3 起后台调度已改为周期任务机制，会主动提示电池优化、通知权限的干扰，老版本升级后再观察。

## 六、只有照片上传，视频传不上

典型原因是服务器前面挂了反向代理（Nginx、Cloudflare Tunnel 之类）没有放行大体积 POST 请求：Nginx 里把 `client_max_body_size` 调大（官方 FAQ 给的示例是 `50000M`），另外检查反代所在机器的磁盘剩余空间——有些代理会先把请求缓存到磁盘再转发，磁盘满了上传同样会失败。不走反代、局域网直连 2283 时一般不会遇到。

## 七、文件名变成随机字符串 / 想恢复原文件名

存储模板（Storage Template）默认关闭时，服务器把文件以随机字符串命名落盘，防止重名冲突——文件内容没坏，只是磁盘上看到的文件名不是原名。想让文件名恢复原样：开启 Storage Template，再跑一次存储模板迁移任务；模板只对开启后的新文件生效，历史文件靠迁移任务补。开启前先读官方对 Storage Template 的说明，它改的是服务器上所有文件的存放路径。

顺带回答一个常被一起问的问题：Immich 不会改动你的原始文件，编辑产生的数据存在伴随的 `.xmp` 边车文件和数据库里；只有回收站被清空时，原文件才会真的被删除。

## 八、管理员密码忘了

在服务器上用官方命令行重置：

```bash
docker exec -it immich_server immich reset-admin-password
```

（容器名以你实际部署为准。）想列出全部用户，把子命令换成 `list-users`。

## 九、升级注意

- 服务器更新：`docker compose pull && docker compose up -d`；
- 客户端与服务器**一起**升到大版本一致的版本线，避免登录问题；
- 升级前照例确认数据库与媒体目录的备份都在——这部分是服务器侧的事，见[服务器搭建入门](服务器搭建入门.md)。

官方文档在 [docs.immich.app](https://docs.immich.app/)，FAQ 页有更多条目；再往上还有问题可以到 [github.com/immich-app/immich/issues](https://github.com/immich-app/immich/issues) 搜同类 issue。手机端日常用的两个高频入口——[备份设置](照片备份设置.md)与[释放手机空间](释放手机空间.md)——都有各自的功能详解篇。
