> Immich 的手机端只是一个客户端，装好后要连上你自己部署的 Immich 服务器才能用。本篇讲从哪里拿安装包、不同渠道的差别、怎么安装，以及第一次打开之前要准备什么。

## 一、先确认你要装的是哪一端

Immich 是一套「服务器 + 客户端」的自托管照片视频备份方案，手机上装的这个 App（包名 `app.alextran.immich`）负责浏览时间线、自动备份相册；照片真正存放的位置是你自己用 Docker 跑起来的 Immich 服务器。也就是说：

- 只装手机 App、没有服务器 → 打开后没有可登录的地址，用不了；
- 只搭服务器、不装客户端 → 可以用浏览器访问网页端，但没有手机自动备份。

第一次接触建议先看[服务器搭建入门](服务器搭建入门.md)，把服务器跑起来再装手机端。

## 二、官方下载渠道

官方在以下渠道发布 Android 版（iOS 另有 App Store 版本）：

| 渠道 | 说明 |
| --- | --- |
| Google Play | 商店页搜索 Immich，开发者 FUTO |
| GitHub Releases | [github.com/immich-app/immich](https://github.com/immich-app/immich) 的 Releases 页直接下 APK |
| FUTO F-Droid | 官方合作渠道 [get.immich.app/fdroid](https://get.immich.app/fdroid) |
| Obtainium | 在服务器网页端 Utilities 页面可以拿到订阅链接，适合自动跟进更新 |

### 不同渠道的签名不一样，别混着升级

官方对三个渠道的 APK 用了三张不同的签名证书，签名指纹（SHA-256）各不相同，其中 GitHub Releases 渠道为：

```text
86:C5:C4:55:DF:AF:49:85:92:3A:8F:35:AD:B3:1D:0C:9E:0B:95:7D:7F:94:C2:D2:AF:6A:24:38:AA:96:00:20
```

Google Play 与 F-Droid 渠道的指纹见官方 Mobile App 文档页（[docs.immich.app/features/mobile-app](https://docs.immich.app/features/mobile-app/)）。这带来一个实际问题：**从 A 渠道装的应用，不能直接被 B 渠道的更新包覆盖安装**——签名不一致，系统会拒绝。想换渠道就要先卸载再重装，重新登录一次即可，照片本体在服务器上，不会丢。

## 三、从网盘获取安装包

如果你不方便访问上面的渠道，可以用这份 **[Immich 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7fdb2b5d5cfb)**，转存后直接下载 APK 安装。

网盘内这份安装包的基本信息（校验用）：

| 项目 | 值 |
| --- | --- |
| 包名 | `app.alextran.immich` |
| 版本 | 3.0.3 |
| 大小 | 167.73 MB |
| MD5 | `d5282264d3f90dd42cbf9374423169ba` |

手机上核对 MD5 可以借助带校验功能的文件管理器；不核对也不影响安装，只是多一道确认。版本号会随时间推移变旧，官方最新版以 [GitHub Releases](https://github.com/immich-app/immich/releases) 页面显示为准。

## 四、安装步骤

1. 把 APK 下载到手机存储；
2. 在文件管理器里点开它；系统第一次会提示「允许从此来源安装」，同意一次即可；
3. 等安装完成，打开 App。

商店之外的 APK 触发「未知来源应用」风险提示是系统对所有侧载安装包的统一行为，与这个包本身无关。

## 五、首次打开之前

打开 App 后第一屏就是让你填服务器地址。此刻你需要已经有一台跑着 Immich 服务器的机器（NAS、家里的小主机、云服务器都行），并且知道它的地址和端口——默认是 `http://服务器IP:2283`。

还没搭服务器的，先看[服务器搭建入门](服务器搭建入门.md)；已经搭好、卡在登录这一步的，看[连接服务器与登录](连接服务器与登录.md)。装好后照片备份不出来、后台不跑之类的状况，多半能在[常见问题排查](常见问题排查.md)里找到对应条目。
