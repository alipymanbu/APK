# 升级系统后怎么保住Root

> 管理器更新、系统 OTA 之后怎样让 Root 继续可用，以及小米机型升级前必须多做的一步。

## 一、先分清你要升级的是什么

「升级」在 APatch 这里是两件事，混着做最容易丢 root：

- **只升级 APatch 管理器**：不动手机系统，风险最低。
- **升级手机系统（OTA）**：系统分区变了，原来的修补镜像不再对应新版本，需要按 OTA 流程重新落位。

## 二、只升级管理器

直接在应用内更新即可；也可以下载新版本安装包后，点右上角按钮选 `Patch and install`（修补并安装）。要装的那份新版安装包在这里：[APatch 安装文件资源（夸克网盘）](https://pan.quark.cn/s/97a3e4130374)。更新后如有必要，按提示重新确认一次超级密钥。

注意两条官方提示：

- 文档里描述的按钮**以最新版管理器为准**，找不到对应按钮说明你的管理器版本太旧。
- 旧版本已不再支持，官方明确提示旧版本**存在超级密钥被泄露的风险**——长期不更新不是稳妥选择。

**有一类升级不能直接跳版本**：官方在模块开发文档的升级须知里写明，新版本已不再强制用 SuperKey 认证，改为验证**管理器签名**；如果你的实例还是 SuperKey 认证的老版本，**必须先升到官方指定的过渡版本，再升到最新版**，跳过过渡版本可能造成卡开机或丢失 root。以官方文档当时给出的路径为准；拿不准就按 [下载与安装教程.md](下载与安装教程.md) 用原厂镜像重来一遍。

## 三、系统 OTA 之后保住 Root

官方把这套流程与 Magisk 的 OTA 方式对齐，步骤是：

1. 正常走系统更新，下载并开始安装 OTA。
2. 安装完成、**出现「重启」提示但先别点**，打开 APatch 管理器，点右上角按钮。
3. 选择 `Install to inactive slot (After OTA)`（安装到非活动槽 / OTA 后）。
4. 再重启完成更新。

**官方对这条路线的警告写得很直白**：OTA 更新功能目前不稳定，可能出问题；真出了问题就去官方仓库提 issue。也有少量用户反馈槽位切换不生效，遇到就手动重新安装一次。

## 四、小米 / MIUI / HyperOS 要多做一步

这是官方单独拎出来强调的一段：**APatch 目前在修补时不会像 Magisk、KernelSU 那样自动备份原厂 `boot.img`**。如果你在系统更新前没有手动把原厂 `boot.img` 刷回去，系统更新的校验会失败，结果是你只能用完整刷机包来完成这次更新。

所以用 MIUI / 小米 HyperOS（尤其是开发版）的建议动作是：**系统更新前先手动恢复原厂 `boot`**，更新完再按前面的 OTA 流程或重新修补装回去。

## 五、升级后 Root 直接没了怎么办

官方说明过两种情形：

1. **认证方式换了版本**：SuperKey 认证的老实例直升最新版，没走过渡版本——表现就是卡开机或丢 root，见第二节。
2. **大版本更新时 KernelPatch 不兼容**：部分大版本更新里新版与旧版不兼容会直接丢 root，release notes 若专门提到过这一点，处理方式就是**用原厂 `boot.img` 按安装流程重来一遍**。

对应的完整步骤在 [下载与安装教程.md](下载与安装教程.md)；万一重装过程中卡在开机界面，转到 [刷入后开不了机怎么救砖.md](刷入后开不了机怎么救砖.md)。升级后模块全没了属于另一类问题，见 [模块装不上和重启后丢授权怎么办.md](模块装不上和重启后丢授权怎么办.md) 第二节。

## 六、几个时间点上的口径

- 各功能对应的管理器版本、支持情况会随版本变化，**以官方文档与 release notes 当时显示为准**。
- 修补产物不要跨系统版本复用：系统更新之后，旧的 `apatch_xxx.img` 对应的是旧系统，重新取原厂镜像修补才是安全做法。
- 与 Magisk、KernelSU 的支持范围差异，见 [和Magisk与KernelSU的区别.md](和Magisk与KernelSU的区别.md)。
