# 刷入后开不了机怎么救砖

## 一、先分清你是哪种开不了机

处理路径完全不同，先对号入座：

| 症状 | 大概率原因 | 走哪条路 |
| --- | --- | --- |
| 刷了某个模块之后卡在开机第一屏反复重启 | 模块冲突或坏模块 | 触发 APatch 安全模式（下第二节） |
| 刷完修补镜像就进不去系统 | 镜像版本不符、刷错分区 | 刷回原厂 `boot.img`（第四节） |
| 升级管理器或系统之后开始卡开机 | 认证方式跨版本直升、KernelPatch 不兼容 | 按 [升级系统后怎么保住Root.md](升级系统后怎么保住Root.md) 第五节处理 |
| 手机被清空数据、进不了系统 | 不是模块问题 | 安全模式帮不了你，只能线刷整包 |

**APatch 的安全模式只处理第一行那种情况**——官方原话是它「帮助你在刷入了错误模块或模块冲突等导致的无法开机时」禁用全部模块，**不能解决被格机、被清空数据的问题**。

## 二、音量键触发安全模式（首选）

操作时机很关键：**长按电源键、屏幕亮起后，连续按下—松开音量键，直到第一屏亮起来**。这样 APatch 内置的安全模式就会启用，所有模块被禁用。

几个官方说明的细节：

- 监听窗口比你想象的宽：即便 `post-fs` 阶段已经执行过，只要检测到安全模式信号，APatch 会把该阶段做的修改**撤回**。换句话说，**在 `sys.boot_completed=1` 之前这条路径一直有效**，不用抢在某个精确毫秒。
- 进入安全模式后，管理器的系统模块页面里所有模块都是禁用状态，此时你可以对可疑模块执行「卸载」，把有问题的那个摘掉。
- 摘完模块，重启设备正常开机，确认能进系统后再逐个恢复其他模块，定位是哪一个的问题。

## 三、从 Recovery 进安全模式

部分 ROM（官方点名 MIUI / 小米 HyperOS）的 Recovery 自带安全模式入口。重启到 Recovery，打开 ROM 自带的安全模式，同样会拉起 APatch 的安全模式。

**如果进去后发现 APatch 管理器不见了，这是正常现象**：Android 安全模式的规则是禁用一切非系统应用，而 APatch 管理器没有把自己注册成系统应用，所以会被一起禁掉。处理办法是**再重启一次**——Android 会退出安全模式、管理器恢复，而 APatch 仍停在安全模式里，这时你就能进去禁用问题模块了。

## 四、安全模式也救不回来时

- **安全模式下仍然崩溃**：官方解释是撤回 `post-fs` 修改失败了，**再强制重启一次**通常就能解决。
- **反复尝试仍进不去系统**：直接刷回原厂 `boot.img`，这是最彻底的兜底：

  ```sh
  adb reboot bootloader
  fastboot flash boot PATH/TO/original-boot.img
  fastboot reboot
  ```

  前提是你在动手前已经把原厂镜像备份到了电脑上——没备份的话，需要去官方刷机包里提取与当前系统版本完全一致的那一份，见 [下载与安装教程.md](下载与安装教程.md) 第一节。

  **不要用 `init_boot`**，APatch 全程只碰 `boot` 分区，刷错分区只会让情况更糟。

## 五、把翻车概率降下来的习惯

1. **每次刷模块前先记下模块名**，出事时不用猜是谁的锅——升级后模块被清空或装不上的处理另见 [模块装不上和重启后丢授权怎么办.md](模块装不上和重启后丢授权怎么办.md)。
2. **原厂 `boot.img` 永远留一份在电脑上**，不只留在手机里——开不了机时手机里的文件是拿不到的。
3. 修补用的镜像与当前系统版本严格一致，系统 OTA 之后不要直接用旧的修补产物，处理办法见 [升级系统后怎么保住Root.md](升级系统后怎么保住Root.md)。
4. 来路不明的模块与镜像不要刷，官方对「刷入他人修补的内核」专门发过警告；超级密钥相关的风险另见 [超级密钥忘了怎么办.md](超级密钥忘了怎么办.md)。
