## 一、装之前先确认这几点

JJT 是 360 旗下的 AI PPT 工具（网页端工作台在 `https://ultrappt.cn`），安卓版是它的手机端入口。动手安装前，先对一下这份清单：

| 检查项 | 说明 |
| --- | --- |
| 手机系统 | 安卓手机，本包要求安卓 5.2 及以上（以安装包实际提示为准） |
| 安装包大小 | 约 36.73M，手机留出至少 100M 空余空间比较稳妥 |
| 网络 | 首次启动要联网登录，建议用 Wi-Fi |
| 存放位置 | 安装包下载后一般在「通知栏 / 文件管理 / Download」里能找到 |

本页对应的安装包信息（网盘里那一版）：

- 版本：1.0.0
- 包名：`com.jjt.app.android`
- 大小：36.73M
- MD5：`41ADD972584A2F6667EC81D63F825465`

网上能搜到的官方最新版往往已经往前走了几个版本，**版本号以你实际拿到的安装包为准**，不必强求和官网一致。

## 二、拿到安装包并安装

1. 打开上面的 [JJT 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8dd0567c342a)，把 APK 文件转存到自己的网盘后下载到手机（夸克网盘的常规转存流程，转存后才能下载）。
2. 下载完成后点开 APK；如果手机提示「禁止安装未知来源应用」，按提示去系统设置里允许对应来源安装（各家叫法不同：MIUI 叫「安装未知应用」，部分机型叫「外部来源应用下载」）。
3. 授权后回到安装页点「安装」，等待完成。
4. 装完点「打开」，进入登录页。

如果点开 APK 提示「解析包出现问题」，通常是下载中断导致文件不完整——重新从网盘下载一次，再核对文件大小是否仍约 36.73M。登录这一步没有账号的话先看 [注册登录与账号.md](注册登录与账号.md)；已有 360 账号就直接登录，跟着 [一键生成PPT的流程.md](一键生成PPT的流程.md) 走第一份 PPT。

## 三、装完怎么核对装的是哪一版

想确认手机上这份是不是网盘里那一版，两条路：

- **在系统里看**：设置 → 应用管理 → 找到 JJT → 版本号处显示 `1.0.0`；
- **在应用里看**：启动后进「我的 / 设置」类页面，多数应用会标出版本号。

包名 `com.jjt.app.android` 可以用来确认来源正规：手机上同时装了多个名字相近的应用时，包名对得上才是同一款。开始生成前如果想先弄清额度怎么扣，翻 [J分与会员计费.md](J分与会员计费.md)，免得反复试错白花 J分。
