## 一、六个编辑功能，各自解决什么问题

编辑器里的功能不少，按「你这页有什么毛病」对号入座：

| 页面的问题 | 用哪个功能 | 做什么 |
| --- | --- | --- |
| 文字挤、间距乱、看着糙 | 智能排版 | AI 调整图文对齐、间距与视觉层次，一键把乱页变整齐 |
| 有一段数据很干 | 数据转图表 | 直接粘贴表格数据，AI 识别字段含义，推荐柱状 / 折线 / 饼图并嵌入页面 |
| 整套配色不搭场合 | 全套风格换新 | 输入「商务 / 学术 / 极简」等关键词，整套配色、字体、版式一次重构 |
| 图和内容不搭 | 页面精准配图 | AI 读懂页面语义后推荐或生成匹配的图 |
| 章节切换生硬 | 电影级转场 | 章节之间插入 AI 生成的动态过渡视频，偏路演、发布会场景 |
| 要上台念稿 | AI 演讲稿 | 按演讲时长、场合、受众生成配套讲稿，可导出 Docx |

另外还有一个容易忽略的能力：图表、文字框、形状这类**单个元素可以独立修改或重新生成**，不用整页推倒重来。只想改一个数字、换一张图时，走元素级编辑最省。

两个上手前的体感参考（来自公开评测）：智能排版对「文字密、间距紧」的页面改善最明显，点一次它会重排标题层级和图文穿插位置；数据转图表对规整表格的识别通常几秒内完成——评测里贴一段季度销量数据，AI 直接认出时间列和数值列并推荐了折线图。反过来，**复杂设计仍要人工收尾**：公开资料汇总的限制包括复杂动画支持有限、大型演示文稿往往需要手动优化、AI 排版结果有一定随机性——把它当「快速把底子做整齐」的工具，最后一成的精修留给自己。

手上有多套风格各异的旧 PPT 要统一成一套视觉规范时，不用逐份调整：把文件导进编辑器用**风格重构**整批处理，几次操作就能让部门几十页月报配色统一。

## 二、动手顺序建议

同样一份初稿，顺序不同省的消耗不同：

1. **先定结构**：页面增删、章节顺序调整——纯手动操作，不产生 AI 消耗；
2. **再排版**：全篇用一次智能排版，把底子理顺；
3. **然后局部精修**：哪页空补哪页的图表与配图，哪页乱修哪页——按页处理，避免整篇反复跑 AI；
4. **风格最后定**：内容基本不变之后再做全套风格换新，否则前面配好的图可能又被换掉；
5. **要演讲的临走前生成讲稿**：定稿之后按最终时长生成演讲稿，改稿会作废讲稿。

## 三、导出：选对格式再点导出

导出格式的选择不多，按用途挑：

| 格式 | 适合场景 | 备注 |
| --- | --- | --- |
| PPTX | 交给别人继续改、要上台用 PowerPoint / WPS 放 | 最常用的交付格式 |
| PDF | 只发不改、打印、防止对方设备字体缺失 | 版式最稳定 |
| HTML | 想在浏览器里直接演示、保留动态转场效果 | 动态效果保留得最完整 |

两点提醒：

- 电影级转场这类**动态效果，导出成 PPTX / PDF 后会丢失或退化**——演示时想保留运镜感，用浏览器直接演示或 HTML 方式；要交静态文件就用 PDF / PPTX。
- 有第三方资料提到图片类导出（PNG / JPG）可能属于会员权益，免费额度下以 PPTX / PDF 为主——**这类权益边界以 APP 内导出页当时显示为准**。

导出之前在手机上顺手预览一遍，重点看两处：标题有没有溢出、图表数字与你的原始数据是否一致——AI 生成与转换的内容仍需要你自己核对一遍事实。对这次编辑过程的消耗心里没底就看 [J分与会员计费.md](J分与会员计费.md)；想回头换一种结构重做初稿，回 [一键生成PPT的流程.md](一键生成PPT的流程.md) 调整大纲再来；在电脑上接着精修时，登录方式见 [注册登录与账号.md](注册登录与账号.md)，同一账号下作品两端都在。
