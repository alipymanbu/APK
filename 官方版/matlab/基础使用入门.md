## 一、界面里有什么

登录连上云端后，常用入口集中在四块：

| 区域 | 用来做什么 |
| --- | --- |
| 命令行窗口 | 敲一行命令、回车立即执行，适合短计算与随手试验 |
| 编辑器 | 查看、新建、编辑 MATLAB 文件（.m），可整段运行 |
| 工作区浏览器 | 查看当前会话里的变量与取值 |
| 图窗 | `plot` 之类绘图命令的结果在这里展示，支持 2D/3D 绘图输出 |

## 二、跑通第一条命令

在命令行输入并回车：

```matlab
x = 0:0.01:2*pi;
y = sin(x);
plot(x, y)
```

正常情况下会出现一条正弦曲线。数据变量留在云端会话的工作区里，可以接着用。

顺手记几条整理命令，在手机小屏上尤其常用：

```matlab
clc      % 清空命令行窗口的显示
clear    % 清空工作区变量
who      % 列出当前有哪些变量
```

## 三、手机专属键盘

触屏敲代码很别扭，所以应用自带一块面向 MATLAB 语法的键盘：常用运算符、括号、注释号、行尾分号都排在顺手的位置，省去在系统键盘各面板间来回切换。不同版本的键位细节略有差异，以你手里的版本为准。

## 四、文件从哪来、到哪去

- 手机上新建与修改的文件保存在 MATLAB Drive（云端），换设备登录同一账号能接着用，机制见 [云端文件存储与同步.md](云端文件存储与同步.md)；
- 电脑上已有的 .m 脚本，通过 MATLAB Drive 同步过来最省事；
- 想把手机的加速度计、GPS、摄像头当数据入口，走的是另一条线，见 [传感器与摄像头数据采集.md](传感器与摄像头数据采集.md)。

## 五、手机端做不了的事

官方应用商店页明确列出四项不支持：

- 使用 MATLAB 交互式 App（例如曲线拟合这类图形界面工具）；
- 用 App Designer 创建应用；
- 与三维图形交互（旋转、缩放等操作）；
- 通过图形环境打开或创建 Simulink 模型。

需要这些功能时，回到电脑桌面版，或用浏览器打开 [MATLAB Online](https://matlab.mathworks.com)（同一账号直接登录，无需安装）。

## 六、你的版本里可能没有的功能

官方在 2026 年把 MATLAB Copilot（对话式 AI 辅助与代码解释）带到了安卓端；本文收录的 6.8.0 早于这次更新，界面上没有相应入口属正常，想用需升级到较新版本并关联有效许可（许可要求见 [账号注册与云端登录.md](账号注册与云端登录.md)）。另外，第三方版本记录提到 6.3.0 起可以指定应用内容的语言——你的系统设置里若有「应用语言」一项，可以为它单独切换。
