## 一、能采到哪些数据

官方支持的传感器数据通道：

| 数据 | 具体内容 |
| --- | --- |
| 加速度 | 三轴加速度 |
| 角速度 | 三轴陀螺仪 |
| 磁场 | 三轴磁力计 |
| 方位 | 偏航角、俯仰角、横滚角（azimuth / pitch / roll） |
| 位置 | 经纬度、海拔、水平精度、速度、航向（来自 GPS） |

## 二、两种采集方式

1. **在线采集**：登录云端后，在应用里打开传感器采集，数据直接流入云端会话，可立即用 MATLAB 命令处理或画图；
2. **离线记录**：没有网络时先把数据存成本地日志文件，之后再同步上去分析。

## 三、配套支持包

要在 MATLAB 侧完整读取这些数据，需要安装「MATLAB Support Package for Android Sensors」（官方 File Exchange 提供，免费）：[支持包下载页](https://www.mathworks.com/matlabcentral/fileexchange/47618-matlab-support-package-for-android-sensors)。

装好后可以在脚本里订阅手机传感器、按采样率读数据流。常见的玩法：记录一段步行加速度数据后做频谱分析、用 GPS 轨迹画路线、拿陀螺仪数据验证姿态算法。

## 四、摄像头与麦克风

应用可以调用手机相机拍照、录制视频与音频，把文件交给 MATLAB 做后续处理（比如配合图像处理工具箱做图像分析）。第一次使用时系统会弹出相机/麦克风权限申请，允许后才能继续。

## 五、拍好的素材怎么进 MATLAB

从相册或其他应用的「分享」菜单里，可以直接把图片等内容发到 MATLAB Drive；进入 MATLAB 后按文件路径读取即可。Drive 的容量与同步机制见 [云端文件存储与同步.md](云端文件存储与同步.md)。
