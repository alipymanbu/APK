## 一、能采到哪些数据

官方支持的传感器数据通道：

| 数据 | 具体内容 |
| --- | --- |
| 加速度 | 三轴加速度 |
| 角速度 | 三轴陀螺仪 |
| 磁场 | 三轴磁力计 |
| 方位 | 偏航角、俯仰角、横滚角（azimuth / pitch / roll） |
| 位置 | 经纬度、海拔、水平精度、速度、航向（来自 GPS） |

## 二、在应用里怎么采

不需要写代码的那条路，官方博客给的操作路径是：

1. 点左上角三条线的菜单图标，进入「Sensors」（传感器）界面；
2. 把「Stream to」设为 **Log**：数据会记录成 MAT 文件，存到 MATLAB Drive 的 `MobileSensorData` 文件夹；
3. 打开要采的传感器开关；采样率可调，教学资料里示例默认 10 Hz（以应用内显示为准）；
4. 点 Start 开始记录、点 Stop 停止并保存；开着 Auto Upload 时，日志自动传到 Drive。

把「Stream to」指向 MATLAB 会话则是实时流式传输：数据直接进云端工作区，适合边采边画图。

## 三、配套支持包

要在 MATLAB 侧完整读取这些数据，需要安装「MATLAB Support Package for Android Sensors」（官方 File Exchange 提供，免费）：[支持包下载页](https://www.mathworks.com/matlabcentral/fileexchange/47618-matlab-support-package-for-android-sensors)。

装好后可以在脚本里用 `mobiledev` 对象订阅传感器、按采样率读数据流，官方帮助有完整示例（比如读取角速度与方位数据后绘图）：[MATLAB Mobile 帮助文档](https://www.mathworks.com/help/matlabmobile/ug/acquire-and-plot-angular-velocity-and-orientation-data.html)。常见的玩法：记录一段步行加速度数据后做频谱分析、用 GPS 轨迹画路线、拿陀螺仪数据验证姿态算法。

注意网上还有一批「手机与电脑连同一局域网、直连桌面 MATLAB 采集」的老教程——那条工作流 2019 年 9 月起已停止支持，现在统一走云端，详见 [连接云端失败的排查清单.md](连接云端失败的排查清单.md) 第三节。

## 四、摄像头与麦克风

应用可以调用手机相机拍照、录制视频与音频，把文件交给 MATLAB 做后续处理（比如配合图像处理工具箱做图像分析）。第一次使用时系统会弹出相机/麦克风权限申请，允许后才能继续。

## 五、拍好的素材怎么进 MATLAB

从相册或其他应用的「分享」菜单里，可以直接把图片等内容发到 MATLAB Drive；进入 MATLAB 后按文件路径读取即可。Drive 的容量与同步机制见 [云端文件存储与同步.md](云端文件存储与同步.md)。
