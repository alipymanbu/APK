# VLC 网络流媒体播放方法

> 想在手机上看直播源、摄像头流、家庭 NAS 里的电影，VLC 不用装任何插件就能接。本篇讲怎么打开一个网络地址、怎么浏览局域网共享，以及网络播放卡顿时的调法。

## 一、打开一个网络地址

主界面侧边菜单里有「打开网络串流」（Open MRL / 网络流）入口，把地址粘进去就能播：

```text
https://example.com/live/index.m3u8
rtsp://192.168.1.10:554/stream
http://192.168.1.5:8080/video
```

支持的协议以官方说明为准：HLS（也就是常见的 `.m3u8` 直播源）和 DASH 是明确支持的，普通的 http/https 视频直链直接贴地址就能放，局域网设备的 rtsp 地址（摄像头、监控流常用）也在能力范围内。地址失效、协议不对这类问题在服务端，应用这边调不出来。

粘贴的地址要完整，协议头（`http://` 这类）不能少。播放 IPTV 类的 `.m3u` 频道列表时，把列表文件当本地文件打开即可，VLC 会按播放列表逐个频道切。

## 二、浏览局域网共享和 NAS

侧边菜单的「本地网络」里能直接浏览同一路由器下的共享设备，官方支持的协议包括：

| 协议 | 典型设备 |
| --- | --- |
| SMB | Windows 电脑的共享文件夹、多数 NAS |
| SFTP / FTP | NAS、路由器挂载的硬盘、树莓派 |
| NFS | Linux 主机、部分 NAS |
| UPnP / DLNA | 媒体服务器、智能电视的共享 |
| Plex | Plex 媒体服务器 |

点进设备后如果要求登录，填对方设备的账号密码（Windows 共享就是那台电脑的登录账号）。常用服务器可以存成书签，下次从「收藏」直接进。

连不上时按这个顺序查：手机和 NAS 是否在同一个 Wi-Fi 下、电脑端防火墙是否拦了、NAS 那边对应协议的服务开没开。这几步都正常还连不上，多半是路由器开了 AP 隔离，去路由器设置里关掉。

## 三、投到电视上看（Chromecast / 渲染器）

VLC 支持把正在播的画面投给局域网里的 Chromecast 等接收设备：播放页点开「渲染器」（Renderer）图标，选中同网络下的电视设备即可。投出去之后手机只当遥控，视频画质由电视端设备决定，个别格式电视端解不动时会由手机转码，费电是正常现象。想让电视画面和手机完全同步（克隆屏幕而不是遥控），用设置里「副屏优先克隆」一项，见 [播放手势与画面控制.md](播放手势与画面控制.md) 第五节。

## 四、网络播放卡顿的调法

直播源缓冲大、NAS 播 1080P 转圈，通常不是解码问题（那是 [支持的格式与解码方式.md](支持的格式与解码方式.md) 里的事），而是缓存不够：

1. 设置里搜「网络缓存」（不同版本叫「网络缓存值」或以毫秒为单位的一项）；
2. 默认值偏小，直播源容易断流，把它往上调（比如调到 1000 毫秒上下，越大越稳但起播越慢）；
3. Wi-Fi 信号差时优先换 5GHz 频段或靠近路由器，这一步比任何设置都管用。

外挂字幕在网络播放里同样有效：把字幕文件和视频放在同一个共享目录、名字对应好就行，具体规则见 [字幕加载与设置.md](字幕加载与设置.md)。播放还是报错的话，按 [播放问题排查.md](播放问题排查.md) 的清单过一遍。
