## 一、Personal 分区是干什么的

Orbitv 除了内置频道，还留了一个 Personal 分区给「自己手里已有的源」。如果你有合法可用的直播列表或直链，加进去之后它们会跟内置频道出现在同一个目录里，照常收藏、搜索，不用切换应用。

## 二、支持哪些格式

按官方说明，Personal 区接受这些类型：

| 类型 | 说明 |
| --- | --- |
| M3U 播放列表 | 一份列表里带多个频道，适合批量加入 |
| m3u8 直链 | 常见的 HLS 流媒体地址 |
| mpd 直链 | DASH 流媒体地址 |
| mp4 直链 | 直接的视频文件地址 |

具体入口与按钮名称随版本可能略有差异，以你设备上的 Personal 页面实际显示为准。

## 三、添加步骤（三种输入方式）

按官方商店页的说明，M3U 支持三种载入方式，先判断你手上的源属于哪一种：

| 你的源 | 用哪种方式 |
| --- | --- |
| 手机里已存好的 `.m3u` 列表文件 | 从文件加载 |
| 一条 M3U 列表地址（URL，一批频道） | 从列表地址加载 |
| 单个 m3u8 / mpd / mp4 直链 | 直接贴地址 |

通用流程（入口与按钮名称随版本略有差异，以你设备上的 Personal 页面为准）：

1. 准备好上面任意一种源；
2. 打开 Orbitv，进入 Personal 分区，点添加；
3. 按源类型选「文件 / 列表地址 / 单条地址」对应的入口，粘贴或选取；
4. 保存后回到频道目录，你加的条目会与内置频道一起出现，可照常收藏、搜索。

## 四、来源与合法使用

官方口径明确：Orbitv 只索引开放网络上的公开流，不提供付费频道或订阅频道；你在 Personal 里自己添加的源，合法性由你自己负责——只添加你有权使用的来源。这条既是官方条款的要求，也是这类应用唯一稳妥的用法。

## 五、加了但不显示或播不动

按顺序检查：

1. **地址粘对没有**：地址要以 `http(s)://` 开头，前后多余的空格会导致识别失败；
2. **格式对不上**：列表内容要是 M3U 结构，普通网页地址播不了；
3. **源本身失效**：把同一个地址丢到别的播放器里验证——能播说明源没问题，是你这边的添加方式问题；不能播就是源已经失效；
4. **源服务器限流或有地区限制**：这种情况下配置再正确也播不了，只能换源。

播放能出画面但卡顿、黑屏等更常见的问题，集中放在 [常见问题与播放排查.md](常见问题与播放排查.md)。
