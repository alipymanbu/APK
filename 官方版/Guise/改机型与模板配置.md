## 一、改机型四步

前提：已在 LSPosed 启用 Guise 并勾选目标应用（安装与激活步骤见[下载与安装教程.md](下载与安装教程.md)）。

1. 打开 Guise，点进已勾选应用的配置页，找到「品牌」「型号」等字段。
2. 选机型，两种方式：
   - **手动填**：品牌填实际 Build 值（如 `samsung`、`OnePlus`），型号填具体型号代号（如三星 `SM-G991B`、红米 `M2101K9G`）。注意界面里的显示名与写入 Build 的值是两回事 —— 「一加」只是显示名，实际写入的是 `OnePlus`。
   - **从机型目录选**：内置机型目录按品牌分组，覆盖手机、平板等常见设备（目录规模随版本更新，以应用内实际可选为准），选中后品牌、型号等字段自动填入。
3. 需要连系统版本一起伪装时，把 Android 版本、SDK、Fingerprint 设成与机型配套的值，别各填各的。
4. 保存。目标应用正在运行时按提示停止或重启它；没在运行就不用管，下次打开自动生效。

## 二、一键随机

不想挑机型就用一键随机：它从同一组设备与版本数据里生成一整套互相配套的值（品牌、型号、Android 版本、SDK、Build ID、Fingerprint 等），避免出现「品牌是 A 家、Fingerprint 是 B 家」这种对不上的组合。官方说明里，新版本的随机值会按常见平台形态生成（Android ID 为 16 位十六进制、IMEI 带校验位、MAC 为本地管理地址、坐标在全球有效范围内）；旧版本随机值的形态以应用内实际为准。只想换个别字段时，用字段旁边的独立随机按钮。

## 三、模板：一次配置，多处套用

同一套参数要给多个应用用，别逐个应用抄：

- **保存**：把当前应用的配置存成模板，可存为「通用模板」（任何应用都能套）或「应用专属模板」（只给指定的应用用）。
- **套用**：在模板列表选择目标应用批量套用；会覆盖已有配置时，应用内会先让你确认。
- **导入导出**：模板可导出成文件备份，也能再导入。当前版本支持从 JSON 文件、HTTPS 链接、相机扫码或相册二维码导入，并能把模板导出为 JSON 或二维码；旧版本支持的导入方式少一些，以你手上的版本界面为准。

模块自带「空白通行证」「允许强制截图」两个常用模板（旧版本未必内置，没有也不影响手动配置）。

## 四、生效范围就是勾选

Guise 没有「全局伪装」总开关 —— 对哪个应用生效，取决于你在应用列表里勾了谁，勾选状态会同步为 LSPosed 作用域。想让某应用恢复读到真实参数：取消勾选 → 强制停止该应用 → 重新打开。取消勾选不会删配置，下次勾上还能接着用。

## 五、保存之后没变化

多半是应用没被真正停止（从最近任务划掉不算），用系统「应用信息 → 强制停止」。还不行就按[配置不生效排查.md](配置不生效排查.md)逐条对。
