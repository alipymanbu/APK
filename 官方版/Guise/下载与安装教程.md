## 一、装之前先确认环境

Guise 是 Android 端的 Xposed 模块（系统工具类），作用是在你勾选的目标应用内，替换品牌、型号、Android ID、IMEI、网络与定位等设备参数的读取结果。原项目由 Houvven 开发，2.0.0 起由大侠阿木（daxiaamu）接手维护，后续版本以 Guise Reborn 的名义发布，包名一直是 `com.houvven.guise`。

它不是装上就能独立生效的应用，依赖框架环境。开始前逐项确认：

| 前提 | 说明 |
| --- | --- |
| 已解锁 Bootloader 并刷入 Magisk | LSPosed 框架的运行基础；KernelSU 搭配 Zygisk Next 也是常见组合，Magisk 26.0 以上是社区普遍建议的版本，以框架官方说明为准 |
| Magisk 设置里已开启 Zygisk | 开启后需重启手机，LSPosed 依赖它运行 |
| 已安装 LSPosed 框架 | 通过 Magisk 模块方式刷入；Guise 需要 LSPosed 或兼容 Modern Xposed API 的框架 |
| 64 位设备（arm64-v8a） | 当前主线版本只提供 arm64-v8a 架构的安装包，32 位设备装不上（官方说明） |
| 系统版本 | 主线要求 Android 10（API 29）及以上，以官方发布页标注为准 |

没有这套环境的话，模块装上也激活不了 —— 先把框架搭好再回来。还没 Root、拿不准这套环境值不值得搭，先看[没有Root能用吗.md](没有Root能用吗.md)，里面有完整的依赖链。另外提醒一句：刷入框架与模块阶段有「无法开机」的风险（模块不兼容或操作失误都可能），动手前先查清你的机型怎么解锁、怎么救砖。

## 三、安装与激活五步

1. 从 [Guise 安装文件资源（夸克网盘）](https://pan.quark.cn/s/690562d910b8)转存下载 APK，或从官方发布页获取，安装到手机。
2. 打开 LSPosed 管理器，在「模块」页找到 Guise 并启用。
3. 打开 Guise，在应用列表里**勾选**要伪装参数的目标应用。勾选就是启用开关，并会同步为 LSPosed 的作用域；只保存配置不勾选，模块对该应用不生效。
4. 进入该应用的配置页，设置要改的参数并保存 —— 能改哪些见[可伪装参数清单.md](可伪装参数清单.md)，改机型的具体操作见[改机型与模板配置.md](改机型与模板配置.md)。
5. 按提示**强制停止目标应用**再重新打开（一般不必重启手机），参数替换才开始生效。

模块启用后如果 Guise 的桌面图标被隐藏，可以从 LSPosed 的模块页面重新进入。顺带一提：LSPosed 自己的管理器入口有时也不在桌面 —— 可以从它的常驻通知进入，部分版本支持在拨号盘输入 `*#*#5776733#*#*` 唤出（随框架版本可能不同）。

## 四、使用前两条注意

- **环境会被看见**：Guise 以 Xposed 模块形式加载，带 Root/Xposed 检测的应用可能因此表现异常（功能受限、提示环境异常等）。给金融、游戏这类带风控的应用做参数伪装前，自己权衡账号层面的风险。
- **改完没反应别急着重装**：多数情况是勾选或重启环节漏了，按[配置不生效排查.md](配置不生效排查.md)从上往下对一遍，比卸载重装快得多。
