## 一、六类参数一览

Guise 按应用勾选生效，可配置项覆盖设备与系统、唯一标识、网络与 SIM、定位、运行环境、隐私数据六大类，合计约 40 项，每项独立开关，不填就保持设备原值。

| 类别 | 可配置项 |
| --- | --- |
| 设备与系统 | 品牌、制造商、型号、设备代号、产品名、主板、硬件/CPU 代号、Build ID、Fingerprint、Android 版本、SDK 版本、显示密度（DPI） |
| 唯一标识 | Android ID、IMEI、手机号、应用版本信息（目标应用查询自身版本时读到的值） |
| 网络与 SIM | 网络类型、Wi-Fi SSID、BSSID、Wi-Fi MAC、SIM 运营商代码/名称、国家代码、基站 LAC/CID |
| 定位 | 经纬度（可加随机偏移）、隐藏 Wi-Fi 定位信息、隐藏基站定位信息 |
| 运行环境 | 语言/地区、时区、电池电量（可指定或随机）、截图开关（允许强制截图 / 禁止截图） |
| 隐私与空白通行 | 联系人、图片、视频、音频查询返回空结果；应用列表可见性过滤（目标应用只能看到自身与系统应用） |

操作形态上：品牌与型号从内置机型目录里选，运营商从内置的全球 MCC/MNC 数据中搜索；数值类字段（Android ID、IMEI、经纬度、电量等）多带独立的随机按钮，不必逐个手填。目录规模供参考：当前主线版本内置 26 个品牌、8,533 个可选机型，运营商数据覆盖 226 个国家/地区 —— 目录随版本更新，以应用内实际可选为准。

## 二、每类改不到的地方

配置生效不等于目标应用一定看到新值 —— 取值途径不同，结果就不同。对照下表：

| 你改的 | 覆盖不到的地方 |
| --- | --- |
| 品牌/型号等 Build 字段 | 只替换目标应用进程内 Java 层读到的结果；对比 Java Build 与系统原生属性的应用仍能看出差异 |
| 经纬度 | 只替换 Android 定位接口（`Location`）返回的坐标；IP 定位、厂商私有定位接口、服务端推断的位置不受影响 |
| 时区 | 只改目标应用读取与格式化时间用的默认时区；系统时钟不变 |
| 显示密度（DPI） | 只影响目标应用读到的显示参数；系统设置里的「显示大小」不变 |
| IMEI | 配置是单值：双卡设备上卡槽 1 / 卡槽 2 读到的是同一个值 |
| Wi-Fi 信息 | 「隐藏 Wi-Fi 定位信息」开关优先于自定义的 SSID/BSSID/MAC —— 隐藏开着时，自定义值不生效 |
| 基站信息 | 「隐藏基站定位信息」开关优先于 LAC/CID 自定义值 |
| 允许强制截图 | 对 DRM 保护内容、厂商私有渲染层不保证有效；应用自行遮挡的部分照样截不到 |
| 应用列表过滤 | 覆盖常用的 PackageManager 查询路径；原生代码、厂商私有接口仍可能绕过 |

两条全局事实：Guise 只影响你勾选的应用，不改系统全局设置、不动其他应用的数据；「制造商」留空时该字段不注入，目标应用继续读到设备原始值。

## 三、按需组合，不必全填

- 只想换一台「机型」：填品牌 + 制造商 + 型号，其余留空；
- 只想减少真实标识暴露：随机 Android ID / IMEI + 打开「隐藏基站定位信息」，设备与系统字段不动；
- 只想解决某个应用禁止截图：单独开「允许强制截图」，或直接套用内置的同名模板。

改完保存后要停止/重启目标应用才生效，操作见[改机型与模板配置.md](改机型与模板配置.md)；想先确认注入是否成功，用靶应用验证，方法见[用靶应用验证伪装效果.md](用靶应用验证伪装效果.md)。
