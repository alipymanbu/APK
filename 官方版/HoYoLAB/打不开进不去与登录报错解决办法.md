## 一、先对号入座：你是哪种打不开

| 现象 | 更可能的原因 |
| --- | --- |
| 一直停在加载页 / 转圈不停 | 网络不通或服务端在维护 |
| 登录时报 1001、400_0 之类错误码 | 网络连接问题（官方口径） |
| 登录时报 Too many requests / 安全风险 | 短时间操作太频繁，被限流（不是网络问题，另见 [登录提示Too many requests怎么办.md](登录提示Too many requests怎么办.md)） |
| 应用打开就闪退、黑屏 | 系统过旧、存储不足、安装包损坏 |
| 首页能进，但帖子/地图刷不出来 | 单个页面加载失败，清缓存重进 |

后面对应的排查步骤按这个顺序做，前一类没排除前别跳到后一类。

## 二、网络排查（官方给的顺序）

官方帮助中心对 1001、400_0 和卡加载页给的排查清单，照做一遍：

1. 重启路由器；
2. 重启手机；
3. 切换网络 —— Wi-Fi 换成移动数据，或反过来；
4. 关掉正在开着的 VPN、代理等第三方网络软件；
5. 把 DNS 设置改成自动。

做完还报错，就带信息找客服（见最后一节）。

## 三、国内网络环境：两种说法都试

这里有个明显的口径分歧，两边都写给你，自己实测：

- **官方说法**：关掉 VPN / 代理等第三方网络软件再试；
- **部分用户反馈**：直连时打不开、挂上网络工具后能正常进。

所以别只信一边 —— 先按官方的关掉代理试一遍；连不上再开代理试一遍。你的网络环境下哪种能进，就用哪种。同理，Wi-Fi 和移动数据也各试一次，运营商线路不同结果可能相反。

## 四、缓存、安装与闪退

1. **清缓存**：`设置 → 应用管理 → HoYoLAB → 存储 → 清除缓存`，然后重启应用。缓存损坏是加载失败的常见原因。
2. **清数据**：清缓存无效再点「清除数据」—— 代价是本机登录态没了，重新登录即可（账号数据在服务端）。
3. **重装**：清数据还不行，卸载后重新安装。从 [HoYoLAB 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1cf76d0d9e28) 重新拿包，或用商店版，别装来路不明的修改包。
4. **闪退/黑屏的额外检查**：
   - 手机系统是否过旧、存储是否快满了；
   - 部分机型缺 Google 服务框架会表现异常（有用户反馈），装好框架再试；
   - 安装包是否完整（对照 [下载与安装教程.md](下载与安装教程.md) 里的 MD5 核对）。

## 五、服务端维护时段

版本更新前后，官方会安排维护，期间所有人都进不去、登录会失败。这种情况不是你的问题：等维护结束再进，维护公告在 HoYoLAB 首页与官方社交账号会提前发。

## 六、还不行就找客服

带上这些信息联系官方客服，排查效率高很多：

- 你的服务器与所玩游戏；
- 平台（Android / iOS / PC）、国家或地区；
- 网络运营商、当前是 Wi-Fi 还是移动数据；
- 问题截图或录屏。

账号本身的问题（登不上、找回密码）按 [注册登录与绑定角色教程.md](注册登录与绑定角色教程.md) 里的方式处理；装不上、装完打不开，先回 [下载与安装教程.md](下载与安装教程.md) 核对安装步骤。
