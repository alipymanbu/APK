# SoundCloud 常见问题与解决方法

> 本篇按「症状 → 先查什么 → 再查什么」整理安卓端最常遇到的问题：闪退、放不出、登不上、离线失效、耗电。

## 一、先做三个通用检查

碰到任何异常，先花一分钟排掉这三类「非应用本身」的原因：

1. **服务端是否故障**：打开 SoundCloud 官方状态页，看服务是否正常。状态页显示异常就只能等，装什么版本都没用。
2. **网络是否通**：换 Wi-Fi / 流量试；能开别的网页但 SoundCloud 转圈，再往下查。
3. **版本是否过旧**：旧版与服务端接口不兼容会冒出各种怪问题，先更新到最新版再复测。

## 二、闪退 / 一打开就卡死

按顺序试，做到哪步好了就停：

1. 强制停止应用后重开；
2. **清缓存**：设置 → 应用 → SoundCloud → 存储 → 「清空缓存」。这一步不丢账号数据，优先做；
3. 手机重启一次；
4. 检查剩余存储空间，空间吃紧会导致启动失败；
5. 仍闪退再「清除数据」（会退出登录、清掉本地设置，收藏与歌单在云端不受影响）；
6. 更新或重装（重装会丢离线保存的内容，见 [离线收听设置与限制.md](离线收听设置与限制.md)；从头装的步骤见 [下载与安装教程.md](下载与安装教程.md)）。

另注意：如果你刚更新完才开始闪退，可能是新版本本身的问题，留意后续修复更新；省电模式/后台限制过严的手机，把 SoundCloud 加进电池白名单也会明显改善。

## 三、歌放不出来（一直转圈 / 停在 0:00）

1. **先换一首**：单曲不动就换别的歌试 —— 只有一首坏，是那首音轨或版权限制，不是你的问题；
2. 清缓存（路径同上），缓存损坏会让波形加载失败；
3. 关掉 VPN/代理类工具再试，这类工具的节点异常经常表现为「列表能刷、播放失败」；
4. 换网络重试；
5. 都不行，等几分钟再开 —— 区域性播放故障通常会自行恢复。

## 四、登录不上去

- 密码错就走「忘记密码」重置；
- 第三方（Google/Facebook）授权过期时改用邮箱密码登录，方法见 [注册账号与登录方法.md](注册账号与登录方法.md)；
- 登录页反复转圈：清缓存 + 换网络 + 确认状态页，三件套之后再试。

## 五、搜索 / 首页刷不出来

搜索框无结果、探索页空白，通常是网络问题或缓存问题：先换网络，再清缓存。若只是推荐内容变少，那是使用记录还没积累起来，与故障无关。

## 六、离线保存听不了

逐条对 [离线收听设置与限制.md](离线收听设置与限制.md) 第四节的清单查：订阅是否有效 → 同步是否完成 → 是否曾退出登录/卸载 → 单曲是否被版权方关闭离线。多数情况是前三条之一。

## 七、耗电与后台异常

- 系统的电池优化会限制后台播放，把 SoundCloud 设为「不优化/允许后台运行」；
- 关掉手机自带的「结束后台运行应用」对它的限制；
- 长期不用时手动清一次缓存，避免临时文件越积越大。

## 八、流量跑得太快

多半是音质档位或后台下载设置的问题：对照 [流量消耗与音质设置.md](流量消耗与音质设置.md) 的第二节调音质、第三节关掉后台偷跑的开关，再用系统的流量统计页核对。
