## 一、为什么需要一个账号

不登录也能打开 SoundCloud 听一部分内容，但你只要想做下面任何一件事，就需要账号：关注创作者、点赞收藏、创建歌单、评论、上传自己的音频、购买订阅。账号是免费的，注册几分钟就能完成。

装应用这一步如果还没做，先看 [下载与安装教程.md](下载与安装教程.md)。

## 二、创建账号的四种方式

在 App 启动页点「创建账户」（Create account），可以选四种途径：

| 方式 | 特点 |
| --- | --- |
| Google 账号 | 一键授权，最快 |
| Facebook 账号 | 一键授权 |
| Apple 账号 | iOS 设备上常见 |
| 邮箱注册 | 不依赖任何第三方，最独立 |

**邮箱注册的完整步骤**（App 内）：

1. 选「用邮箱注册」，输入邮箱地址与密码，点「用邮箱注册」；
2. 过人机验证（如有）；
3. 阅读使用条款与隐私政策，点「接受并继续」；
4. 填写年龄、性别，点「继续」；
5. 设置显示名（Display Name）—— 这是别人看到的名字，之后可在设置里改。

电脑端流程相同：打开 [www.soundcloud.com](https://www.soundcloud.com)，右上角「注册」，邮箱 → 密码 → 人机验证 → 接受条款 → 年龄性别 → 显示名。

## 三、别漏掉邮箱验证

注册完成后，SoundCloud 会往你的邮箱发一封确认邮件。**不完成邮箱验证，账号的上传功能用不了**（也无法发某些类型的互动内容）。所以注册完第一件事是去收件箱找 SoundCloud 的确认邮件、点里面的链接；没找到就查垃圾邮件夹。

一个邮箱只能注册一个 SoundCloud 账号；邮箱本身不会展示给其他用户。

## 四、日常登录

- **App 内**：启动页点登录，用注册时的方式进 —— 邮箱密码直接登；第三方账号走授权页。
- **记住登录方式**：如果你当初用 Google 注册，之后却输邮箱密码，会提示凭据不对 —— 登录方式要和注册方式一致。

## 五、登录不上的常见情形

1. **密码错误**：走「忘记密码」重置，重置邮件同样查一下垃圾夹。
2. **第三方授权过期**：用 Facebook / Google 登录报错时，多半是授权被收回了。可以先改用邮箱密码登录，再回第三方平台（如 Facebook 的「已连接的应用」）检查 SoundCloud 是否还在授权列表里。
3. **一直转圈或报「发生错误」**：先确认不是服务端故障 —— 打开 SoundCloud 官方状态页看服务是否正常，再按 [常见问题与解决方法.md](常见问题与解决方法.md) 清缓存、换网络重试。
4. **换了手机**：账号是云端的，装好应用重新登录即可，收藏与歌单会跟着账号走。

密码建议用独立的强密码（8 位以上、大小写数字混用），不要与邮箱密码相同。
