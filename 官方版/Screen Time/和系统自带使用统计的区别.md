## 一、先把三个「Screen Time」分清

Screen Time（Atharok 版）与手机系统自带的使用时长统计是两回事：前者是只做统计、不联网的开源应用，后者各品牌都带、通常还带限额与拦截功能。本篇把两者的能力差异与共存关系摆清楚。先认人，同名的东西有三个：

1. **本文说的 Screen Time**：Atharok 开发的开源安卓应用，包名 `com.atharok.screentime`；
2. **苹果设备设置里的「屏幕使用时间」（Screen Time）**：iOS/iPadOS 的系统功能，与本文这个应用无关；
3. **同名商业亲子控制产品**：另一家公司的服务，也叫 Screen Time。

安卓各品牌自己的那套则各有各的名：华为叫「健康使用设备」，OPPO/realme 叫「应用使用时间 / 屏幕限时」，入口都在系统设置里。

## 二、能力对照

下表只列事实，选哪个取决于你要什么（数据源头都是系统记录的使用情况，两边读的是同一套底层数据）：

| 能力 | 系统自带统计 | Screen Time（本文应用） |
| --- | --- | --- |
| 总时长与分应用时长 | 有 | 有 |
| 按天 / 按周图表 | 有 | 有 |
| 给应用设每日限额 | 有（华为、OPPO 官方文档均列此功能） | **没有**——官方功能清单里只有统计，不做任何限制 |
| 停用时段 / 到点拦截 | 有 | 没有 |
| 断网可用 | 有 | 有（应用未申请联网权限） |
| 开源、可自行审计 | 否 | 是（GPL-3.0-or-later，[源码仓库](https://gitlab.com/Atharok/ScreenTime)） |
| 界面与操作 | 各品牌不同，换机要重新熟悉 | 各机型一致 |
| 费用 | 免费 | 免费、无广告、无内购 |

## 三、能不能同时开

能。系统自带的统计与 Screen Time 互不冲突——它们不争抢同一份数据，各自读取系统记录后自行汇总。常见的搭配是：限额、停用时段交给系统自带功能管；想要一份开源、不联网、界面统一的统计视图时打开 Screen Time 看数字。

注意两点：

- 两边都在「使用情况访问 / 应用使用情况」这类特殊权限里出现，排查权限问题的方法是同一套，见 [统计不到数据怎么排查.md](统计不到数据怎么排查.md)；
- Screen Time 的图表怎么读、各版本差异在哪，见 [每日与每周使用时长怎么看.md](每日与每周使用时长怎么看.md)；它不联网、权限各管什么，见 [不联网与隐私保护说明.md](不联网与隐私保护说明.md)。
