## 一、先查权限：九成问题出在这

Screen Time 读不到数据的最常见原因，是没拿到系统的**使用情况访问权限**（部分机型叫「应用使用情况」「使用情况访问」）。核对方法：

1. 打开 Screen Time，首页点【授权】，会跳转到系统的权限设置页；
2. 在列表里找到 **Screen Time**，确认开关是打开的；
3. 返回应用，下拉或重新进入首页刷新。

跳转没生效、或你在设置里找不到这个入口时，手动按机型走（路径随系统版本变化，以实际显示为准）：

| 机型 | 已核实的路径 |
| --- | --- |
| realme UI 6.0/7.0 | 设置 → 隐私 → 权限管理 → 权限 → 其他权限 → 特殊应用权限 → 使用情况访问权限（官方客服文档） |
| realme UI 3.0~5.0 | 设置 → 应用 → 特殊应用权限 → 使用情况访问权限（官方客服文档） |
| 小米 MIUI | 设置 → 隐私保护 → 特殊权限设置 → 使用情况访问权限（社区用户反馈，不同版本叫法略有出入） |
| 华为 EMUI 旧版 | 安全和隐私 → 更多安全设置 → 使用情况访问权限（网友反馈，新机型入口位置有变动） |
| 任何机型的兜底办法 | 在系统设置顶部的搜索框直接输「使用情况」，从结果跳进去 |

开关明明打开了却还是没数据？按「权限已开」继续往下走下面几条。

## 二、权限已开仍无数据

按顺序试，任一步奏效就停下：

1. **完全退出应用再重新打开**——统计数据在打开时读取，不是实时刷新的；
2. **重启手机**后再打开应用；
3. 确认装的是不是这个包：设置 → 应用列表里查包名，应为 `com.atharok.screentime`（装错同名应用是最容易被忽略的坑，辨认方法见 [下载与安装教程.md](下载与安装教程.md) 第一节）；
4. 卸载重装后**重新授权**——重装会把权限状态打回默认。

## 三、选的日期查不到数据

- **日期在安装/授权之前**：有用户反馈装好之前的时间段查不到数据；遇到这种情况从装好那天起往后看即可。
- **日期太久远**：系统自己保留使用数据也有期限，安卓官方开发者文档给出的上限是——每日数据 7 天、每周数据 4 周、每月数据 6 个月、年度数据 2 年；周视图往前翻不动、更早的日子查不到，多半是碰到了这个边界（以系统实际行为为准）。
- **那天设备确实没怎么用**：熄屏闲置的日子本来就没有多少可统计的时长。
- **刚过零点**：新一天刚开始，柱子接近零是正常的，过几小时再看。

## 四、数据对不上、感觉偏少

先明确口径再判断是不是 bug：

- 它统计的是**屏幕亮屏使用**的时间，不是「后台运行时长」；
- 应用列表会随系统上报的应用变化，个别应用的归属可能与你直觉不同；
- 若怀疑是版本问题，先升级到最新版再对比——官方在 1.3.1、1.4.0 的更新说明里都提到过统计计算的调整（细节见 [版本更新记录与升级方法.md](版本更新记录与升级方法.md)）。
