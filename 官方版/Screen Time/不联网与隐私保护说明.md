## 一、官方对隐私的口径

开发者在项目页与隐私声明里写得很直接：Screen Time **不收集任何统计、个人信息或分析数据**；应用的网络权限被禁用，即它没有联网能力，统计数据不会离开你的手机。这一点也可以自己验证——安装时系统列出的权限里没有互联网权限，飞行模式下功能照常。

- 隐私声明：[atharok.gitlab.io/site/privacy-policy/screen-time/](https://atharok.gitlab.io/site/privacy-policy/screen-time/)
- 项目主页：[atharok.gitlab.io/site/projects/screen-time/](https://atharok.gitlab.io/site/projects/screen-time/)

## 二、权限清单：每项权限对应你得到什么

下面是该应用声明的权限与它们对你的实际意义（以安装时系统列出的清单为准）：

| 权限 | 干什么用 |
| --- | --- |
| 使用情况访问（`PACKAGE_USAGE_STATS`） | 读取各应用的使用时长，是本应用的核心数据来源 |
| 查询已安装应用（`QUERY_ALL_PACKAGES`） | 把时长拆到具体是哪个应用 |
| 前台服务 | 让统计相关任务在后台不被随意中断 |
| 开机启动 | 设备重启后自动恢复运行 |
| 防止手机休眠 | 读取数据时不被休眠打断 |
| 查看网络连接 | 只能「看到」网络状态，不能联网传输 |

其中需要你**手动去设置里给的只有第一项**——第一次打开时点【授权】给的就是它，具体操作见 [下载与安装教程.md](下载与安装教程.md)；其余随安装自动带上，你在日常查看中感知不到它们的存在。

## 三、断网、飞行模式下能用吗

能。统计与图表全部在本机完成：数据来自系统记录，读取、绘图、存储都不经过网络。把它装在不插卡的备用机、或长期开飞行模式的设备上，功能没有任何残缺。

## 四、这类应用要不要留后台

不需要为它做特殊设置。使用时长由**系统侧记录**，Screen Time 只负责在你打开时去读——就算你把它从后台划掉，已经发生过的使用时间不会丢。真正必须保持的只有第二节里的使用情况访问权限。

## 五、它靠什么维持开发

Screen Time 免费、无广告、无内购，许可证为 GPL-3.0-or-later 的开源软件。开发者接受捐赠（渠道见项目主页的 Liberapay、Ko-fi 链接，以页面当时显示为准），也接受翻译与代码贡献——想出力可以从 [源码仓库](https://gitlab.com/Atharok/ScreenTime) 提合并请求开始。
