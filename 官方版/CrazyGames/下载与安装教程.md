## 一、装之前：确认手机满足两个条件

| 条件 | 说明 |
| --- | --- |
| 系统版本 | 安卓 5.2 及以上（按本地采集记录） |
| 存储空间 | 安装包 20.66M，加上安装后的占用，建议预留 100M 以上空闲 |

CrazyGames 手机版是一个小游戏平台的客户端，游戏内容在打开时在线加载，所以日常使用还需要可用的网络连接，Wi-Fi 或流量均可。

## 二、获取安装包

安装包通过夸克网盘分享：打开 [CrazyGames 安装文件资源（夸克网盘）](https://pan.quark.cn/s/189a61ad368f)，先转存到自己网盘，再下载到手机。

具体顺序：

1. 手机上装好夸克 App（没有就先装一个，注册并登录）。
2. 点开上面的网盘链接，在页面里选「保存到网盘」。
3. 打开夸克 App 的「我的网盘」，找到刚转存的文件，点下载。
4. 下载完成后在下载列表里点这个 apk 文件，进入安装。

## 三、安装步骤与「未知来源」授权

从网盘拿到的 apk 不经过应用商店，安卓会拦一道「未知来源应用」，这是正常流程：

1. 点 apk 后系统弹出「是否允许安装」时，选「设置」→ 打开「允许此来源安装」→ 返回继续装。
2. 不同品牌入口略有差别：小米在「安装未知应用」里按应用授权；华为在「更多安全设置 → 外部来源应用下载」；找不到入口时，直接在安装弹窗里点「设置」跟着提示走。
3. 装完点「打开」，或在桌面找到 CrazyGames 图标启动。

安装失败时按报错对号入座：

- 提示「解析失败 / 包有问题」：多半是下载中断导致文件不完整，删掉重下一次；这份安装包的 MD5 为 `ECF7F20DE133DC68AB9B4B4CC96DC824`，可用于核对文件是否完整。
- 提示「系统版本过低」：手机安卓版本低于安装包要求，只能升级系统或换设备。
- 提示空间不足：清出足够空间后重试。

更多报错场景整理在 [常见问题排查.md](常见问题排查.md) 的安装一节。

## 四、第一次打开

1. 启动后进入首页，顶部轮播大图与「NEW / UPDATED / TOP RATED」分组就是游戏入口，点图块即进入游戏。
2. 界面全是英文，不影响玩：认图标、认分组就够了，词义对照见 [界面与玩法入门.md](界面与玩法入门.md)。
3. 打算换手机或重装系统的，建议先花一分钟了解进度保存机制再开始玩：[游戏进度保存与账号.md](游戏进度保存与账号.md)。
