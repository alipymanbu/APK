## 一、先认清它是什么

CrazyGames 是 2014 年上线的免费网页游戏平台，收录了数千款即点即玩的小游戏，覆盖动作、益智、赛车、射击、多人对战等类型。你装的这个 App 是平台配给安卓手机的一个入口：游戏本体不单独下载安装包，点开图块就在应用内直接开玩，这也是首页横幅里「No install needed」的意思。

游戏总量官网写 4500+ 款，App 首页标的是「5000+ games」——两个数字会随上架节奏一直变，以你打开时看到的为准。

## 二、首页怎么读

| 你看到的 | 意思 | 怎么用 |
| --- | --- | --- |
| 5000+ games | 平台游戏总量 | 只是个规模标注，不用点 |
| No install needed | 单个游戏免安装 | 同上，说明它的玩法形态 |
| Play with friends | 多人/联机游戏入口 | 想和朋友或真人对手玩就点这里 |
| NEW | 新上架的游戏 | 想尝鲜从这里翻 |
| UPDATED | 近期有更新的游戏 | 老游戏出了新内容会出现在这 |
| TOP RATED | 评分靠前的游戏 | 不知道玩什么，先逛这一档 |

顶部一栏左边是 logo 与搜索，右边几个图标分别对应多人游戏、通知、收藏与个人中心；首页往下就是一排排横向滑动的游戏图块，不同图块左上角挂着 NEW / UPDATED / TOP RATED 标签。不同版本的界面元素可能微调，认分组和图标就行。

## 三、找游戏的三条路

1. **首页分组**：NEW / UPDATED / TOP RATED 三档直接翻，适合没有明确目标的碎片时间。
2. **搜索**：点放大镜图标输入英文关键词。应用没有中文界面，中文词搜不出东西，英文关键词命中率才高：

   | 想玩什么 | 搜什么 |
   | --- | --- |
   | 赛车 | car / racing |
   | 麻将 | mahjong |
   | 双人同屏 | 2 player |
   | 放置挂机 | idle / clicker |
   | 跑酷 | run / parkour |
   | 射击 | shooter / gun |
   | 三消 | match 3 |
   | 生存建造 | survival / craft |

3. **按类型逛**：平台常用的类型包括 .io（多人竞技）、Action（动作）、Puzzle（益智）、Driving（赛车）、Word（文字）、Sports（体育）等，认这些英文词就能定位到对应大类。想找人一起玩的，多人玩法专门整理在 [和朋友联机与双人游戏.md](和朋友联机与双人游戏.md)。

常驻热门款认名字也能快速找到熟面孔：Shell Shockers（多人射击）、Moto X3M（摩托闯关）、Smash Karts（卡丁车混战）、Uno Online（牌类）、Geometry Dash（节奏跳跃），这批在各端都常年排在前列。

## 四、进一局游戏

1. 点图块进入游戏页，等它加载——游戏是在线加载的，第一次进会慢一点，之后会快。
2. 按游戏内提示操作，手机上以点按、拖动这类触屏操作为主。
3. 玩完直接返回大厅换下一个就行，不存在「卸载某个游戏」这回事。

游戏画面里常见的几个词：Play（开始）、Restart（重来）、Score（得分）、Time（计时）、Round（回合）。看到 SCORE / TIME / ROUND 三件套基本就是计分闯关类玩法。

## 五、玩久了该关心的一件事

你在某个游戏里攒出的关卡与高分，默认只存在这台手机上——清除应用数据或卸载重装就没了。想让进度跟着自己走，看 [游戏进度保存与账号.md](游戏进度保存与账号.md)；用着遇到加载不出、看不懂之类的问题，翻 [常见问题排查.md](常见问题排查.md)。
