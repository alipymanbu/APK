## 一、滤镜：先套再调强度

1. 编辑界面底部选「滤镜」，一排缩略图会滑动展开；
2. 点一个滤镜立刻套到图上，**再点一次**会出现强度滑杆，左右拖能减淡或加重 —— 大多数图不需要拉满，中段往往更自然；
3. 官方标称滤镜总数 130+，从自然风格到复古感都有；列表里部分带标记的是订阅专属，点下去会弹订阅提示，不想订阅就换下一个免费的用。

滤镜同样能加到视频上，操作一样。

## 二、参数微调：滤镜之外的手动项

滤镜只是预设，细调在「调整」类工具里，常用的几项：

| 参数 | 动它会怎样 |
| --- | --- |
| 亮度 / 曝光 | 整体变亮变暗，欠曝的图先动这个 |
| 对比度 | 明暗反差，拉高更有层次，过高暗部会死黑 |
| 饱和度 | 颜色浓淡，降一点更耐看 |
| 锐度 / 清晰度 | 轮廓更清楚，过高会出噪点 |
| 颗粒 | 加胶片噪点感，复古滤镜常配合它 |

调坏了不用撤销重来，找「重置」把该项归零即可。

## 三、边框与背景

1. 底部选边框工具（图标是一个方框里套小方框）；
2. 滑杆调边框厚度；
3. 背景可选纯色、图案库、或用另一张图当背景 —— 图案与边框包官方是按月更新的，看到「需下载」的先下再用；
4. 图案边框特别适合给拼贴收边，见 [拼贴制作教程.md](拼贴制作教程.md)。

边框厚度调到 0 就等于无边框，直接导出原比例。

## 四、文字与水印

1. 选「文字」工具，输入内容；
2. 字体、颜色、对齐、描边都能改 —— 官方标称 20+ 款字体；
3. 想做水印就把自己 ID 输进去，缩小放到角落，每张图统一位置；
4. 部分字体带标记，属订阅内容，免费字体也够日常用。

## 五、免费版与订阅的边界

- 免费版覆盖：基础裁剪、白边、相当一部分滤镜与边框、文字、拼贴；
- 订阅（InstaSize Premium）解锁：全量 130+ 滤镜、标注为高级的编辑工具（美白、祛痘这类人像项）、部分字体与边框包；
- 订阅是**自动续费**制，官方条款写明需在周期结束前 24 小时关闭才会停止续费。点了「免费试用」记得看清楚扣费周期，不想要就尽早去应用商店的订阅管理里取消 —— 事后扣费的投诉在应用商店评论里很常见，别忽略那一步确认。

不确定某项是不是要订阅时，直接点：能用就是免费的，弹订阅页的就不理它。相关困扰归到 [常见问题与解决方法.md](常见问题与解决方法.md)。
