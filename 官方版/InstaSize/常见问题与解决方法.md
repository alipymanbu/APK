## 一、点 APK 提示「禁止安装」

安卓默认不允许浏览器/文件管理器装包。按弹窗进「安装未知应用」或「未知来源」设置，给**你用来点这个 APK 的那个应用**开权限，再回到安装界面点一次。品牌菜单名不同（MIUI「安装未知应用」、ColorOS「外部来源应用安装」），照系统提示走即可，授权是一次性的，装完可关。

## 二、装不上或装完打不开

按顺序排查：

1. **系统版本**：本地记录标注需要安卓 5.2 以上（不同渠道对该应用最低版本的标注不一，有的标 7.0+），系统低于要求会直接装不上；
2. **包冲突**：手机里若装过另一渠道的 InstaSize 且签名不同，会提示「安装失败 / 应用未安装」。先卸载旧的再装 —— 注意卸载会丢掉旧应用里未导出的草稿；
3. **包不完整**：下载中断会装到一半报错。用 [下载与安装教程.md](下载与安装教程.md) 里的 MD5（`46AD3887838736718410DA0BAC9009AD`）核一遍文件完整性。

## 三、打开闪退、或进去是白屏

- 机器内存紧张时修图应用容易被系统杀掉，先关掉后台再重开；
- 只在某类图上崩（特别大的图、特殊格式），换一张小图试：能复现就是这版对这类文件处理有问题，等更新或改用别的导出尺寸；
- 系统刚升级后的首次启动偶发异常，强行停止应用再进（系统设置 → 应用 → InstaSize → 强行停止）。

## 四、相册是空的 / 读不到照片

存储权限没给。到系统「设置 → 应用 → InstaSize → 权限」打开「照片和视频 / 存储」；有的系统还有「后台弹出界面」「读取媒体」这类附加开关，一并打开。给完权限重进应用，选图列表就会刷新。

## 五、保存失败或导出闪退

1. 先看**剩余空间**：导出高分辨率图很占空间，清理后再试；
2. 保存权限（同上一节）没开时，分享页能出来但写不进相册；
3. 导出到一半闪退，把目标尺寸调小一档（例如不选最高分辨率）通常能过；
4. 拼贴格数多 + 高分辨率的组合最吃内存，分两次导出或降低单图尺寸。

## 六、订阅弹窗太频繁 / 想取消续费

免费版在保存、试用高级滤镜等位置会弹订阅提示，点关闭或返回即可，不影响免费功能使用。已经点了「免费试用」想退：

- 经 Google Play 订阅的：Play 商店 → 头像 → 付款和订阅 → 订阅 → 选中 InstaSize → 取消；
- 官方条款写明需在**周期结束前 24 小时**关闭自动续费才不会扣下一期，取消后当前周期内仍可继续用到期。

不要通过来路不明的链接「代取消」，一切以商店的订阅管理页为准。完整的取消步骤、退款时间窗与找谁申请，见 [取消订阅与退款方法.md](取消订阅与退款方法.md)。

## 七、找不到某个滤镜 / 边框 / 字体

列表里带标记（PREMIUM 之类）的是订阅专属，点下去弹订阅页属正常，不是 bug。免费资源也够日常用；另有部分边框包需先下载素材，看到「下载」按钮先下再选。免费与订阅的边界详见 [滤镜边框与文字添加教程.md](滤镜边框与文字添加教程.md)。

## 八、版本号对不上

商店页写的是最新版（已到 5.x、7.x 一代），而 [下载与安装教程.md](下载与安装教程.md) 对应的安装包是 **4.5.9**（包名 `com.jsdev.instasize`，55.03M，记录日期 2026-09-23）。功能布局大体一致，个别新功能（新的滤镜包、AI 类工具）在这版里不会有 —— 版本号、包名、大小一律以本地这份安装包为准。

## 九、拼贴或裁剪的操作找不到入口

功能入口问题不在本篇展开，按需求直接跳：裁尺寸看 [照片尺寸调整与裁剪教程.md](照片尺寸调整与裁剪教程.md)，滤镜边框文字看 [滤镜边框与文字添加教程.md](滤镜边框与文字添加教程.md)，多图拼合看 [拼贴制作教程.md](拼贴制作教程.md)。

## 十、导出的图发虚、不够清晰

按顺序找原因，每条都有对应的处理：

1. **裁剪框拉太小**：框内像素就那么多，导出再放大必然发虚。裁剪时框尽量少切，宁可用白边（[照片尺寸调整与裁剪教程.md](照片尺寸调整与裁剪教程.md) 第四节）；
2. **源图本身质量低**：手机拍的时候就糊，后期救不回全部 —— 进「调整」用锐度滑杆补一点（底部左起第二个菜单，见 [滤镜边框与文字添加教程.md](滤镜边框与文字添加教程.md)），拉过头会出噪点，宁低勿高；
3. **导出分辨率选得低**：保存前看一眼导出选项，有高一档的就选高的；
4. **滤镜 + 颗粒叠太重**：颗粒本来就是加噪，弱光图再叠高颗粒会显脏，颗粒滑杆压到 50 以下观察（数值参考见 [滤镜边框与文字添加教程.md](滤镜边框与文字添加教程.md) 第二节）。

还有一种情况不是图的问题：拼贴单格被切得太碎、每格分到的像素太少，减少格数或换大图再来。
