## 一、五类工程，按你写什么来选

新建项目时的类型列表就是 AIDE 的能力边界。选错类型不是小事——工程结构不同，AIDE 认不出来就编译不了。

| 类型 | 你写什么 | 典型场景 |
| --- | --- | --- |
| Android App（Java/XML） | Java + 布局 XML，走安卓 SDK | 绝大多数安卓 App、入门练手 |
| C/Java/Xml（NDK） | Java + C/C++，走 JNI 或纯 Native Activity | 想用 C/C++ 写逻辑、图形运算 |
| Java Console App | 纯 Java，`main` 入口 | 学 Java 语法、跑算法练习 |
| PhoneGap/Cordova | HTML5 + CSS + JavaScript | 用网页技术做跨平台 App |
| 打开已有工程 | Eclipse / Android Studio 默认结构 | 把电脑上的项目搬进手机继续写 |

前三类在 AIDE 本体里直接可建，自带示例模板；PhoneGap 需要另外安装 AIDE 的 PhoneGap 组件（付费项，价格以 Google Play 页面当时显示为准）。

## 二、NDK 工程的两个注意点

- **NDK 不随 AIDE 一起装**：第一次建/开 NDK 工程时它会提示安装，同意即可（详见 [常见报错与解决办法.md](常见报错与解决办法.md) 第五节）。
- **只有 ARM 设备受支持**：官方教程标注 AIDE 的 NDK 开发支持 ARM 架构机型。写法上有两条路：Java 侧通过 JNI 调 C/C++ 的接口，或者整个 Activity 用 C/C++ 写——两种都有示例工程可直接建。

## 三、纯 Java 控制台工程能干什么

不装安卓 SDK 组件也能用：建 **Java Console App / Hello World**，写标准 `main` 方法，点「运行」会弹出一个模拟控制台窗口显示输入输出。适合练算法、验证一段逻辑，程序在独立进程里跑，不影响 AIDE 本身。Java SE 的编辑是完整支持的。

## 四、和电脑上的工程互相搬

AIDE 用的是 Eclipse 的 `.classpath` 工程格式，同时兼容 Android Studio 的默认目录结构，所以两条搬运路径都通：

1. **直接拷文件**：把电脑工程整个文件夹复制到手机存储，用 AIDE 的文件浏览器打开它。Eclipse 工程原样能开；Android Studio 工程要符合默认结构（`app/src/main/...` 那套）。
2. **Git 同步**（推荐）：AIDE 内置 Git，支持提交、丢弃改动、推送、拉取、分支、合并与 SSH——电脑上 push 一下、手机上 pull 下来，反向也一样。仓库交互在文件浏览器里操作，键位见 [外接键盘快捷键对照表.md](外接键盘快捷键对照表.md)。
3. **Dropbox 同步**：AIDE 集成 Dropbox，可以把工程放在网盘目录里双向同步，省去手动拷贝。

反向（手机 → 电脑）同理：Git 推上去，或者把文件夹拷回电脑，用 Android Studio / Eclipse 继续打开。

## 五、本体之外的几个可选组件

以下都是独立于 AIDE 本体的可选项，价格与可用性以 Google Play 页面当时显示为准：

| 组件 | 作用 | 说明 |
| --- | --- | --- |
| 调试器 | 断点、单步、查看局部变量与对象字段 | 能调 Android Java 应用与控制台应用 |
| App UI Designer | 可视化拖拽编辑布局 XML | 也集成进 AIDE，装了两者就能在「设计」里直接可视化编辑 |
| 进阶课程 | 交互式 Java / Android / 游戏开发课程 | 应用内的学习路线，入口见 [内置互动课程怎么进.md](内置互动课程怎么进.md) |

免费版足够完成「写代码 → 编译 → 运行」的完整闭环；付费项买的是便利（调试、可视化编辑、应用内课程），不是基础功能的开关。用不上就不必买。

## 六、选型一句话

- 想学安卓开发 → Android App（Java/XML），从 [第一个安卓应用怎么写.md](第一个安卓应用怎么写.md) 开始；
- 只想练 Java → Java Console App；
- 已有电脑工程 → Git 或文件夹直接搬进来；
- 装不上或跑不起来 → 先看 [常见报错与解决办法.md](常见报错与解决办法.md)。
