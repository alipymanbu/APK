## 一、启动时那两个入口

第一次打开 AIDE，你会看到 **Learn（学习）** 与 **Code（编程）** 两个入口，这是两条不同的用法：

- **Code**：走「专家模式」直接进工程环境，就是 [第一个安卓应用怎么写.md](第一个安卓应用怎么写.md) 里走的那条路；
- **Learn**：进互动课程——一门课边讲边让你改代码，改完当场运行看效果。

当时没选也不要紧，**从菜单里能再次进入课程列表**。

## 二、有哪些课

按官方公布过的课程设置（发布于官方博客，后续是否新增以应用内列表为准），课程覆盖这几条线：

| 课程 | 教什么 |
| --- | --- |
| Java 编程 | 语言基础：语法、面向对象、练习 |
| Android 开发 | 安卓专项：控件、界面、Activity 等 |
| 游戏开发 | 场景搭建、贴图渲染、物理与交互（v2.6 加入） |
| Android Wear | 穿戴设备应用开发 |
| JavaScript / 网页开发 | 配合 PhoneGap 方向的 HTML/CSS/JS |

一门课分若干小课，每课标注**预计完成时间**，可以开提示音与语音讲解。官方的说法是课程总量有数小时的素材，且一直在扩充（该公告发布于 2014 年，当前实际数量以应用内显示为准）。

## 三、课程怎么用才有用

1. 从课程列表选一门，按小课顺序往下走——每一课都要求你亲手改几行代码再运行，不是纯阅读。
2. **每课可以直接切进 IDE**：以课程的示例代码为基础继续开发，这是课程和 [支持哪些项目类型.md](支持哪些项目类型.md) 里那些工程模板打通的地方——学完一课，手里的代码就是一个能继续长的工程。
3. 学到的新写法，回头在自己的 Hello World 工程里再做一遍，比在课程里做完就忘记得牢。

## 四、课程要不要钱

官方口径是：**互动课程的访问权限包含在 AIDE Prime 订阅里**（官方博客 2014 年公告的表述）。也就是说本体免费、课程属于付费项的一部分——具体价格与是否仍以订阅形式提供，**以 Google Play 页面当时显示为准**。

要注意的边界：**写代码、编译、运行这些核心功能不依赖课程**，免费版就能跑通完整闭环（见 [支持哪些项目类型.md](支持哪些项目类型.md) 第五节）。你已经有自己要写的工程，不买课程也完全不影响；课程对你是「系统过一遍基础」的价值，买不买按需。

装完还没进过工程的，先按 [下载与安装教程.md](下载与安装教程.md) 确认环境没问题，再回本篇从 Learn 进门。
