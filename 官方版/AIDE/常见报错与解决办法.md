## 一、先分清是哪一层坏了

AIDE 的一次完整流程有三个环节，报错先归位，别跨层乱试：

| 环节 | 典型现象 | 去哪一节 |
| --- | --- | --- |
| 装 AIDE 本身 | 点 APK 提示已阻止、解析包失败 | 第二节 |
| 编译自己的代码 | 编辑器标红、构建进度条走到一半报错 | 第三节 |
| 运行/安装自己的 App | 编译成功，但装到手机时被拦 | 第四节 |
| App 直接打不开 | 一点图标就闪退 | 第六节 |

## 二、装 AIDE 时被系统拦

**现象**：点安装包提示「已阻止安装来自此来源的应用」「为您的安全，手机不允许安装未知应用」。

这不是安装包的问题，是安卓 8.0 之后按应用授予的安装权限——**你用哪个应用打开 APK，就要给哪个应用开权限**：

- 原生/近原生系统：设置 → 安全 → 安装外部来源应用 → 选中你的浏览器或文件管理器 → 允许；
- OPPO/一加/Realme（ColorOS 12+）：设置 → 密码与安全 → 系统安全 → 外部来源应用；
- 华为/荣耀：设置 → 安全 → 更多安全设置 → 安装外部来源应用；
- 三星：设置 → 安全与隐私 → 更多安全设置 → 安装外部来源应用；若开关是灰的，先临时关掉系统的「自动拦截程序（Auto Blocker）」，装完再打开。

**「解析包时出现问题」或安装到一半失败**：多半是 APK 没下完整。删掉重新下载，用 [下载与安装教程.md](下载与安装教程.md) 里的 MD5（`6B5C94CE4F54AE8D005DCEE116E59B42`）核对，体积也应接近 40.07M。另外检查剩余存储，建议至少留 1~2 GB。

**提示「本机版本高于下载版本」**：手机里已装的 AIDE 版本更新，属正常提示；要坚持装这份就先卸载已有的（工程文件在 SD 卡上，不会随卸载删除，但卸载前最好确认工程目录不在应用私有数据里）。

## 三、编译报错（代码这一层）

AIDE 是**边写边检查**的：语法错误会在编辑器里用下划线标出，构建前就能看到。

- **长按报错处**，会弹出该错误的可选修复建议，能自动修的直接选；
- 报错定位到具体行，先读错误信息的第一行——`cannot find symbol` 多半是控件 id 或类没引对，`expected` / `unexpected` 是括号或标签没闭合；
- XML 布局报错时切到「设计」标签看预览断在哪一层，点红框控件可跳回对应节点；
- 修改后重新「运行」即可，增量编译只重编改动部分。

如果错误只在你从别处拷来的工程里出现，先对照 [支持哪些项目类型.md](支持哪些项目类型.md) 确认工程格式（Eclipse / Android Studio 默认结构）是否被 AIDE 认出来。

## 四、编译成功但安装自己的 App 被拦

**现象**：构建进度走完，系统弹「已阻止安装」或「出于安全考虑，手机不允许安装未知应用」。

和第二节同一类授权问题，但这次的安装来源是 **AIDE**——去设置里给 AIDE 开「安装外部来源应用」权限，再点一次运行。部分品牌的「纯净模式」「支付保护」也会额外拦一道，按提示临时放行即可。

装完后想清理授权，可以再把这个开关关掉（推荐），下次运行时再开。

## 五、NDK 项目提示要装 NDK

AIDE 本体不内置 NDK。新建或打开带 C/C++ 的工程时，它会提示安装移动端 NDK——**同意安装即可**，也可以在设置里手动开始安装。没装 NDK 就运行这类工程，构建会直接失败。NDK 什么时候才需要、哪些项目类型用它，见 [支持哪些项目类型.md](支持哪些项目类型.md)。

## 六、一点图标就闪退 / 新机型上用不了

AIDE 最后一次公开版本更新停留在 2021 年前后，此后没有跟上新的安卓平台（截至 2026 年的公开资料）。实际表现：

- **Android 11 及以下**：多位教程作者反馈可以正常使用；
- **Android 12 及以上**：没有官方兼容声明，有用户反馈在新系统上打不开或运行不稳——先确认装的是不是完整包（第二节排查法），仍打不开就说明是机型兼容问题，不是你操作错了；
- 你写出的 App 同样受这条影响：把 `targetSdkVersion` 设在 30 或以上，装到新旧手机上的兼容性都更好。

另外，多位维护安卓教程的作者仍然用 AIDE 练习基础 Java/XML 代码（截至 2026 年）——把它当作手机上的练习环境，正式发布用的工程再拿到电脑上继续，是更省心的分工。

## 七、不报错但结果不对：看日志

编译装上了、也没闪退，就是点了没反应或者数值不对——这类问题靠读代码猜很慢，用日志定位：

1. 在怀疑的代码路径上插一行调试输出：

```java
Log.d("MYTAG", "按钮被点了, x=" + x);
```

2. 点工具栏的运行，让 App 跑起来，走到你怀疑的位置；
3. 打开 AIDE 内置的 **LogCat 面板**（接键盘可用 `Ctrl + 4`，见 [外接键盘快捷键对照表.md](外接键盘快捷键对照表.md)），按标签过滤 `MYTAG`；
4. 面板里打出了你的输出 = 代码执行到了这里；没打出 = 根本没走到，问题在更前面。一层层往前提，断点都不用设。

面板同时会显示系统抛出的异常堆栈——App 闪退却不知道为什么时，先翻 LogCat 里最后一条红色错误，往往直接给出出错的类和行号。过滤、暂停、清屏的快捷键都在快捷键对照表那篇里。
