## 一、为什么值得接个键盘

AIDE 的编辑器支持键盘输入与**可配置的键位绑定**（官方特性列表原文如此）。在手机屏幕上点按改代码效率有限，接上蓝牙或有线键盘后，跳定义、格式化、运行构建这些高频动作都能一键完成——下面这张表按用途分组，接上键盘就能照着按。

## 二、编辑与选择

| 按键 | 作用 |
| --- | --- |
| `Ctrl + C` / `Ctrl + V` / `Ctrl + X` | 复制 / 粘贴 / 剪切 |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做 |
| `Ctrl + S` | 保存当前文件 |
| `Tab` | 采纳代码补全建议 |
| `Ctrl + /` | 注释掉当前行（再按一次取消，`Shift + Ctrl + /`） |
| `Ctrl + Backspace` | 删除光标前一个单词 |
| `Shift + Ctrl + F` | 格式化代码 |
| `Ctrl + O` | 整理 import（自动补全引用） |
| `Shift + Ctrl + T` | 用 try-catch 包裹选中代码 |

## 三、跳转与查错

| 按键 | 作用 |
| --- | --- |
| `Ctrl + Enter` | 跳到定义处 |
| `Ctrl + T` | 跳到指定类 |
| `Ctrl + G` | 跳到指定符号 |
| `Ctrl + N` | 跳到指定行 |
| `Ctrl + Down` / `Ctrl + Up` | 跳到下一个 / 上一个错误 |
| `Ctrl + 2` | 显示错误列表 |
| `Ctrl + F` | 当前文件内搜索 |
| `Shift + Ctrl + Alt + H` | 在整个工程里搜索 |
| `Shift + Ctrl + Alt + G` | 查找某处被谁引用（Find usages） |
| `Alt + Left` / `Alt + Right` | 后退 / 前进（在跳转历史里移动） |

## 四、运行、构建与设计视图

| 按键 | 作用 |
| --- | --- |
| `Ctrl + E` | 运行（等同菜单里的「运行」） |
| `Shift + Ctrl + E` | 强制重新构建 |
| `Shift + Ctrl + P` | 发布项目（生成可分发的包） |
| `Ctrl + D` | 打开「设计」预览 |
| `Ctrl + 4` | 打开 LogCat 日志面板 |

## 五、LogCat 面板的过滤键

程序跑起来不对劲、又不报编译错时，日志面板是你的眼睛（用法见 [常见报错与解决办法.md](常见报错与解决办法.md) 第七节）：

| 按键 | 作用 |
| --- | --- |
| `Ctrl + F` | 按进程过滤 |
| `Ctrl + T` | 按标签（Tag）过滤 |
| `Ctrl + R` | 恢复滚动 |
| `Ctrl + X` | 清空日志 |
| `Ctrl + G` | 清除过滤器 |

## 六、键位对不上怎么办

上表整理自开发者社区的公开分享（2015 年前后），**个别键位随版本可能有出入**——AIDE 的键位是可配置的，以你手机上「设置 → 键盘/键位绑定」里显示的为准，改键也在那里。先按本表试，试不到再打开设置核对。

触摸屏上没有键盘也能用：编辑器的上下文动作条（长按/菜单键呼出）承担了其中一部分功能，[第一个安卓应用怎么写.md](第一个安卓应用怎么写.md) 里「长按报错处」就是这类触控操作。
