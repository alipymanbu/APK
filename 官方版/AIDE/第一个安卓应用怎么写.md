## 一、本篇讲什么

装好 AIDE 之后，第一个目标是完整跑通一遍「写代码 → 编译 → 装到手机 → 看到界面」。官方自带的 Hello World 模板已经把工程骨架搭好，你只需要改两处、点一次运行。全程不需要电脑，也不需要另外装安卓 SDK——AIDE 自带一份移动端 SDK。

## 二、新建工程

1. 首次以专家模式启动 AIDE，会直接弹出「新建项目」对话框；如果当时没弹，打开 AIDE 的内置文件浏览器，选「在此处创建新项目…」。
2. 项目类型选 **Android App / Hello World**。
3. 填两个信息：
   - **应用名称**：你这个 App 显示在桌面上的名字；
   - **包名**：全设备唯一，惯例是用你自己的域名倒写（如 `com.example.myapp`）。
4. 点「创建」。AIDE 会把工程文件生成到 SD 卡上，并自动打开两个关键文件：`main.xml`（界面布局）和 `MainActivity.java`（逻辑代码）。
5. 默认会给工程初始化一个 Git 仓库，不想用可以在设置里关掉。

## 三、看懂这两个文件在干什么

| 文件 | 作用 | 你会怎么改它 |
| --- | --- | --- |
| `main.xml` | 用 XML 描述界面层级：有哪些控件、怎么排 | 加按钮、改文字、调边距 |
| `MainActivity.java` | 页面逻辑，`onCreate` 里加载布局、绑定事件 | 让按钮被点后做点什么 |

界面上的每个控件都是一个 View；XML 里写一个节点，运行时就是屏幕上一个真实控件。编辑器会实时补全属性名，写错的标签会即时标红。

## 四、加一个按钮

1. 切到 `main.xml`，在布局里加一个 `<Button>` 节点，三个属性最关键：
   - `android:layout_width`、`android:layout_height` 设为 `wrap_content`（控件大小跟文字走）；
   - `android:text` 写按钮上显示的字；
   - `android:layout_margin` 留点边距，别让按钮贴着屏幕边。
2. 点工具栏的「设计」标签看预览——预览图里控件会用红线框出层级，点哪个控件，编辑器就跳回 XML 里对应的节点。
3. 切到 `MainActivity.java`，在 `onCreate` 里拿到这个按钮、设置点击监听。比如让点按钮等于退出当前页面：

```java
Button btn = (Button) findViewById(R.id.button);
btn.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        finish();
    }
});
```

4. 写错时编辑器会用下划线标出来；**长按报错处**，AIDE 会给可选的自动修复建议。

## 五、运行起来

先认清顶栏右侧那一排图标（从左到右大致是）：**运行（三角形）**、**设计预览（画廊样式）**、**编辑（笔形）**、**菜单**——运行和看预览是用得最多的两个，点错了就回来重新点。

1. 点运行图标（或菜单里选「运行」）。AIDE 先编译，弹出构建进度，生成一个 APK。
2. 构建完成会自动安装并启动。**没 root 的手机**上，系统会拦截「安装来自此来源的应用」——按提示去开启「允许来自此来源的应用」（就是 AIDE 这个应用的安装授权），再运行一次即可。
3. 系统弹出安装确认框时选「安装」，装完点「打开」，屏幕中间出现 Hello World，这一轮就成了。

改一处代码就重复第 1 步：AIDE 是增量编译，二次构建比首次快很多。

## 六、几个新手最容易卡住的点

- **看不到「新建项目」对话框**：先确认切到了专家模式（设置里可切换）。
- **安装自己的 App 被系统拦住**：不是编译失败，是手机的「未知来源」授权问题，见 [常见报错与解决办法.md](常见报错与解决办法.md)。
- **想写 C/C++ 或纯 Java 控制台程序**：新建项目时换一个类型就行，各类型的区别见 [支持哪些项目类型.md](支持哪些项目类型.md)。
- **想把电脑上的工程拿进来**：AIDE 兼容 Eclipse 与 Android Studio 的默认工程结构，做法也在项目类型那篇里。

还没装 AIDE 的话，先按 [下载与安装教程.md](下载与安装教程.md) 装好再回来。
