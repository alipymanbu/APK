## 一、装之前先确认：这是哪款应用

Meimodu AI 是一款安卓端的 AI 角色聊天应用，主要玩法是跟预设的 AI 角色做文字对话和语音通话，也可以自己从零搭建专属角色。它在不同渠道还有几种叫法——`meimoduai`、`meimodu`、「妹魔都」等，搜资料时都可能撞到；判断看到的是不是同一款，先核对版本号和安装包体积。

本篇配套的安装包信息如下：

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.4.1 |
| 安装包大小 | 14.84 MB |
| MD5 | `a3b629d762af170b4d8ea89f4b567848` |
| 系统要求 | Android 手机（具体系统版本门槛以安装时的提示为准） |

这款应用官方迭代较快，你在别处看到的版本号跟 1.4.1 不一致很正常——上表是安装文件资源里这一版的事实，网上的最新版信息不代表你装到的这份。

## 二、获取安装包

安装包通过夸克网盘分享获取，流程是「转存 → 下载」：

1. 复制上面的网盘链接，在手机或电脑上打开夸克网盘；
2. 把分享里的安装包转存到自己的网盘空间；
3. 从自己的网盘把 APK 文件下载到手机本地存储。

转存之后文件就在你自己账号里，以后随时能重新下载。下载完建议顺手核一下 MD5（文件管理器或校验工具都能算）：与第一节表格里的值一致，说明文件没有在传输中损坏。

## 三、安装步骤

1. 在文件管理器里找到刚下载的 APK 文件，点它；
2. 系统第一次会提示「允许安装未知来源应用」，按提示去授权（路径一般是 设置 → 应用 → 特殊权限 → 安装未知应用，授予你所用文件管理器的权限）；
3. 回到安装界面点「安装」，等进度走完；
4. 点「打开」直接进入应用——第一次打开怎么挑角色、怎么发第一条消息，看[新手入门与角色对话.md](新手入门与角色对话.md)。

## 四、装不上时的排查顺序

按命中率从高到低排：

| 现象 | 先查什么 |
| --- | --- |
| 提示「解析包错误」 | 文件下载不完整，删掉重下，再核 MD5 |
| 点安装没反应 | 是不是刚拒绝过「未知来源」授权，重新允许一次 |
| 提示空间不足 | 清一点存储空间——安装需要的空间比安装包本身大 |
| 提示与已装应用冲突 | 手机上装过其他渠道的同名应用，先卸载旧的再装 |
| 安全软件拦截 | 在安全软件里放行本次安装，或暂时关闭后再装 |

以上都排完仍装不上，换一条网络环境重新下载安装包再试；还是不行的话，把现象对照[常见问题与解决方法.md](常见问题与解决方法.md)里的安装类条目再核一遍。
