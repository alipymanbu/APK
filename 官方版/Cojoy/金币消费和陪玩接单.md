## 一、金币：充值档位一览

Cojoy 的虚拟货币是金币（Cojoy 币），用于送礼、绑定关系等消费。第三方软件站收录的充值档位如下，实际档位与价格以 App 内充值页当时显示为准：

| 价格（人民币） | 金币 |
| --- | --- |
| 6 | 60 |
| 30 | 300 |
| 108 | 1080 |
| 288 | 2880 |
| 518 | 5180 |
| 1498 | 14980 |
| 3000 | 30000 |
| 6000 | 60000 |
| 10000 | 100000 |
| 20000 | 200000 |

规律是 1 元兑 10 金币，大额档没有额外赠送的公开说明，所以没必要为「划算」一次充大额。

## 二、金币花在哪

- **房间送礼**：在语音房给上麦的人刷礼物；
- **绑定关系**：处 CP、提升亲密度这类关系玩法普遍要花金币或礼物。有用户反馈过「绑定 CP 花 52 元」这样的具体花销，金额以你实际操作时的页面为准；
- **会员**：第三方站点提到有约 30 元/月的会员订阅，具体权益以 App 内会员页为准。

基础的开黑、连麦、进派对房、K歌不需要花钱，先白玩几天确认自己真的会长期用，再决定要不要消费。

## 三、想接单陪玩：四步起步

1. 把个人主页往「技能展示」方向收拾：常玩游戏、段位、擅长位置写清楚；
2. 通过发布说说发接单信息，写明服务内容和你的在线时段；
3. 用私信窗口和意向玩家谈细节（价格、时长、玩法），谈拢再进游戏；
4. 多留意平台内的接单活动位，配合时段在线能提高曝光。

提醒一句：陪玩收入的结算规则、提成比例属于平台政策，以 App 内的创作者/接单说明为准，接单前先看清结算方式，别先垫钱接「高价单」——这类话术在各类语音平台都是常见骗局开场。

## 四、消费避坑：用户反馈集中在这几点

以下来自 App Store 与应用宝的多条用户评价（2024~2026 年间），属于「有用户反馈」级别，供你参考：

- 多条评价反映房间麦上存在「托」，目的是引导刷礼物、诱导充值；
- 有评价反映用网图冒充本人、以处 CP 为名要礼物，绑关系后催着提升亲密度；
- 对应的自保做法：绑关系或大额送礼前先视频确认对方是本人；只小额充值试水；不因对方的情绪话术追加消费；感觉被骗时保留聊天记录并向平台投诉，必要时向反诈中心反映。

已经充了、事后想追回的也要知道现实：第三方投诉平台上有多条针对 Cojoy 的退款投诉，有用户反馈退款金额会被打折处理（「说退 100 元只退了 2 元」这样的投诉内容），追回金额与到账时间都没有保证。真要投诉，先把订单账单、聊天记录、对方资料截图留全，再按渠道顺序走，具体操作见[客服投诉和账号注销指引.md](客服投诉和账号注销指引.md)。
