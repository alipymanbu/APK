## 一、先确认你拿的是哪个包

同一个名字的安装包在网上有好几个版本，装之前先把手上这份核对清楚，能省掉一半「装不上 / 装错版本」的麻烦。下面这几项以**这份本地留存的安装文件**为准（官网与应用商店上的最新版可能是另一个版本号）：

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.0.53 |
| 包名 | `com.shututek.original` |
| 安装包大小 | 90.53M |
| MD5 | `A50BDA3B4AF5193A53789CA42D040CDA` |
| 开发者 | 合肥术图信息科技有限公司 |
| 留存日期 | 2026-09-23 |

核对包名最直接：安装包文件名或应用商店详情页里都会写 `com.shututek.original`，只要这一串对得上，就是同一个应用。MD5 可以在电脑上用校验工具算一遍，一致说明文件在传输过程中没有损坏。

**[AI写作猿 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b66d544a1140)** 就放在网盘分享里，转存到自己的网盘后，在手机上直接点 APK 就能进入安装流程。

## 二、安卓安装步骤

1. 把 APK 转存到手机（网盘 App 内直接下载，或先下到电脑再传过去）。
2. 点击 APK 文件开始安装。如果你之前没装过第三方来源的 APK，系统会弹「禁止安装未知应用」——到设置里给当前来源（浏览器或网盘 App）打开「允许安装未知应用」，再回来继续。
3. 安装过程需要一点解压空间，安装包本身 90.53M，安装时系统还会额外占用一份空间，手机剩余存储最好留出几百 MB。
4. 装完首次打开，会陆续弹网络、存储、相机、录音等权限申请。这些权限各有用途，逐项说明在 [常见问题与权限说明.md](常见问题与权限说明.md)。

装不上时最常见的三个原因：存储不足、来源权限没开、下载的包不完整（MD5 对不上就重新下）。排查细节同样看 [常见问题与权限说明.md](常见问题与权限说明.md)。

## 三、除安卓 APK 外的官方入口

不想手动装 APK，或者还想在别的设备上用，官方这边有这么几个入口（地址以官方页面当时显示为准）：

- **官网下载页**：[www.xiezuoyuan.com](http://www.xiezuoyuan.com) 的下载栏目提供 Windows 客户端、安卓 APK、苹果版与微信小程序的入口，页面上标着「开发者名称：合肥术图信息科技有限公司」。
- **应用商店**：小米应用商店等安卓商店能搜到同包名的条目（详情页可对照包名确认是同一个应用）。商店里的版本通常比网盘里这份更新，介意版本差异就以商店为准。
- **华为 / 鸿蒙**：华为应用市场也能搜到这款应用（开发方母公司官网曾公布其入选华为应用市场 2024 年度影响力应用，截至 2026-09）。用 HarmonyOS 5 及以上系统的手机若在应用市场搜不到，按华为官方支持文档的做法：先把系统与应用市场都更新到最新版再搜；仍没有，就走官网下载页的安卓包。
- **苹果与小程序**：iOS 走 App Store，另外还有微信小程序版本，适合不想装客户端的场景。
- **Windows**：官网提供电脑客户端下载，与手机版是同一套产品线的不同形态。

## 四、版本差异怎么理解

网盘里留存的是 **1.0.53**（90.53M），而应用商店上能看到 1.1.x 的版本、体积也更大（小米商店显示 131.27M，更新时间 2026-09-10，以官方页面为准）。这类差异是正常的：商店版持续迭代，网盘里留存的是较早上架的那一版。

- 你想用最新功能 → 去应用商店或官网下载页拿最新版；
- 你想用手上这份已经转存好的包 → 按第一节核对后直接装；
- 两者包名相同，覆盖安装时版本号高的会直接升级，数据通常保留，但升级前把重要作品收藏或导出一份更稳妥（作品管理方式见 [一键创作与伪原创怎么用.md](一键创作与伪原创怎么用.md)）。

版本号会随时间变化，具体以官方页面当时显示为准。
