## 一、安装与启动类

**提示「安装失败」**
按顺序排查：① 存储空间够不够——安装包 90.53M，安装时还要额外占一份，剩余空间最好留几百 MB；② 「允许安装未知应用」的来源权限开了没；③ 包是否下完整——核对 MD5（方法见 [下载与安装教程.md](下载与安装教程.md)），对不上就重新下。

**装完打不开 / 一闪就退**
多数是包与系统不匹配，或后台有残留。先重启手机再开一次；仍闪退就卸载后换应用商店的同包名版本装（包名核对同样是 `com.shututek.original`）。反复闪退时留意系统版本要求——各商店详情页会标注最低系统要求，以官方页面当时显示为准。

**提示版本过旧**
部分功能会随版本下线或改版。到应用商店检查更新，或用官网下载页的最新包覆盖安装；覆盖前把重要作品收藏/导出一份更稳妥。

## 二、权限都用在哪

首次运行会连续申请权限，逐项对上用途，心里有底再点「允许」：

| 权限 | 用在哪个功能 |
| --- | --- |
| 网络 / WLAN | 全功能依赖联网，断网什么都生成不了 |
| 相机（拍摄照片和视频） | 拍照提取文字、拍摄素材 |
| 录音 | 语音输入、音频相关功能 |
| 读写文件与文档、管理所有文件 | 保存生成的图片/视频到手机、读取你选的文件 |
| 读取图片（READ_MEDIA_IMAGES） | 从相册选图做素材或提取文字 |
| 防止手机休眠、前台服务 | 生成长视频等耗时任务时，切到后台不被系统中断 |
| 修改系统设置、振动等 | 消息提示与应用内偏好 |

用不上的权限可以拒绝，但对应功能会不可用——比如拒了相机就用不了拍照提取，拒了存储就存不下生成结果。权限与功能的对应关系，以官方权限列表为准。

## 三、功能使用类

**点了生成一直转圈**
先查网络（这是最常见的原因），再看是不是内容被拦（表述涉及平台敏感内容时会停住），长视频本身也慢，别中途退出。反复如此，对照 [AI绘画与视频生成怎么用.md](AI绘画与视频生成怎么用.md) 的排查顺序过一遍。

**生成的内容不能直接用**
机器初稿都要人工过一遍：事实、数据、称谓最容易错。用应用内的「AI校对」扫一轮，再用改写/续写调整语气，流程见 [一键创作与伪原创怎么用.md](一键创作与伪原创怎么用.md)。

**找不到之前生成的内容**
去个人中心的创作记录与收藏里翻；高频使用时养成随手收藏的习惯，比事后翻记录快得多。

**会员开了没生效 / 被重复扣费**
先确认登录的是不是开通时那个账号；扣费与续订问题按 [会员套餐与自动续费取消.md](会员套餐与自动续费取消.md) 的入口核对订阅状态，处理不了就联系客服。
