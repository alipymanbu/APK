## 一、会员是什么、怎么计费

应用采用免费下载 + 内购会员的模式，会员权益是解锁应用内的功能。订阅周期分三档：**月度（1 个月）、季度（3 个月）、年度（12 个月）**，另有带「连续」字样的自动续费套餐——价格随渠道与活动变动，**以你开通时官方页面实际显示的价格为准**，本文不写死具体金额。

先弄清两件事再点开通：

1. **这套会不会自动扣**：名字里带「连续包月 / 连续包季 / 连续包年」的，到期会自动扣下一期；支付页没有「自动续费」字样的，就是固定周期、到期即止。点付款前把这行字看清楚，比事后去关省事。
2. **在哪开的就在哪管**：通过 App Store 开的走苹果订阅管理，通过安卓应用内支付开的在应用或对应支付渠道里管理——两边的关闭入口不通用。

## 二、关闭自动续费的入口

### iOS（App Store 扣款）

官方说明要求：如需取消续订，**在当前订阅周期到期前 24 小时以前**，手动在 iTunes / Apple ID 设置里关闭自动续订。落到手机操作上就是：

1. 打开「设置」→ 点顶部你的 Apple ID；
2. 进「订阅」，在列表里找到 AI写作猿；
3. 点「取消订阅」并确认。

取消后当前周期仍可用到期，到期不再扣费。

### 安卓（应用内支付）

开通时用的是哪种支付，就回对应的管理处关（路径为央视新闻、光明网等公开报道的通用口径，界面以你的手机版本为准）：

| 支付方式 | 关闭路径 |
| --- | --- |
| 微信 | 我 → 服务 → 钱包 → 支付设置 → 扣费服务 → 找到该项目 → 关闭扣费服务 |
| 支付宝 | 我的 → 设置 → 支付设置 → 免密支付/自动扣款 → 找到该项目 → 关闭服务 |
| 应用内 | 「个人中心 / 会员中心」里的订阅管理入口 |

找不到入口就联系客服（联系方式见 [常见问题与权限说明.md](常见问题与权限说明.md)）。取消自动续费**不影响已付费部分**：当前周期的会员权益照常用到期，只是到期后不再扣下一笔。

### 一个省心的做法

不确定关没关成功时，关完去支付渠道的扣费列表再确认一眼——**列表里已经没有该条自动扣费协议，才算真正关掉**；只在应用里点过「取消」但协议还在，到期照样扣。还有一招：开通后就把自动续费关掉，权益保留到到期日，既体验了会员也不会被扣下一期。

## 三、已经被扣了不想要，怎么追回

按市场监管部门公开的消费提示，被无故扣费时按这个顺序走（据公开报道整理）：

1. **先联系平台客服**，说明扣费前没有收到显著提醒，要求退还该笔续费款项；
2. **平台拒绝就留证据**：扣费截图、开通页面截图、自动续费协议内容、客服沟通记录；
3. **协商不成再投诉**：拨打 12315，或通过全国 12315 平台在线投诉举报。

能不能退，关键看两点：平台是否以显著方式提示过自动续费与扣费金额、扣费前是否做了到期提醒。你开通时截的图，就是这几条最直接的证据——所以第一次开通时顺手截一张，成本为零。

## 四、账号规则要注意的几条

依据官方用户协议，这几条与你的使用直接相关：

- 登录方式可以是手机号、邮箱或官方后续增加的方式；
- **账号不得转让、出借、出租或售卖**，账号密码要自己保管好——因保管不当造成的损失由用户承担；
- 发现账号被异常使用，应立即通知官方；
- 协议修订会在平台公布，不接受修订可以停止使用服务。

换手机或卸载重装前，先确认自己记得登录方式：作品记录与会员权益都挂在账号上（作品在哪看，见 [一键创作与伪原创怎么用.md](一键创作与伪原创怎么用.md)）。

## 五、先免费用，还是直接开会员

建议先装上把常用功能过一遍，再对照会员权益决定要不要开：确认免费状态下的额度能否覆盖你的使用频度，覆盖不了、又确实高频要跑长文本和出视频，再考虑订阅。安装与版本核对见 [下载与安装教程.md](下载与安装教程.md)；对功能本身还没概念，先看 [一键创作与伪原创怎么用.md](一键创作与伪原创怎么用.md)。
