通勤、坐高铁、流量不够的时候，提前缓存是最实在的办法。本篇讲清缓存的完整流程，以及缓存文件出了问题时怎么处理。

## 一、缓存一集的步骤

1. 进入那部番的**详情页**（不是直接开播）；
2. 找到页面里的**下载按钮**，点开后会弹出集数选择窗口；
3. 勾选要缓存的集数 —— 可以一次勾多集；
4. 确认后开始下载。

下载进度可以在应用内的下载管理 / 我的下载里看。缓存期间建议保持 Wi-Fi，用流量下一整季的体量会很快把套餐吃光。

## 二、缓存在哪、怎么找到它

看已缓存的内容走**应用内的下载管理入口**，一般是「我的」页面下的下载管理或离线缓存列表。从这里进入播放的是本地文件，不消耗流量。

有一点要提前知道：**缓存文件通常不在手机相册或普通的下载文件夹里，而是放在应用自己的数据目录下**。所以用系统的文件管理器去翻，常常找不到能直接播放的视频文件。想管理它们，走应用内的下载管理。

## 三、占用空间与清理

缓存一整季番剧占几个 GB 很正常，尤其是高清档。清理分两种：

- **按条删**：在下载管理里长按或侧滑单集 / 整部番，删掉不看的；
- **整个清空**：卸载应用，或者到手机「设置 → 应用管理 → AnimeCat → 存储」里清除数据。**注意后者会同时清掉你的收藏、追番列表和观看历史**（游客状态下的记录尤其会全丢），做之前先确认已登录并且备份过，见 [注册登录与数据备份.md](注册登录与数据备份.md)。

想省空间还有一个更省事的做法：缓存时只勾**还没看的几集**，看完一集删一集，而不是一次下满一季。

## 四、缓存下来的集数播不了

按可能性从高到低试：

1. **先确认下载是不是真的完成了**。下载中途被中断、进度停在一半的集数会显示已存在，但播放时打不开。删掉这一集，联网重下。
2. **检查剩余存储空间**。空间不足时下载会被截断，表现和上一条一样。
3. **确认缓存的来源线路还在**。缓存与在线播放走的是同一套线路，某条线路本身失效时，从这条线路下的内容也可能播不出来 —— 换一条线路重新缓存。
4. 以上都排除了还是播不了，删掉重下是最快的解法，不必在文件本身上继续排查。

## 五、缓存速度慢、中途停住不动

按顺序试：

1. **让应用留在后台别被系统掐掉**。安卓的省电模式与电池优化会限制后台下载，表现为进度条长时间不动。到手机「设置 → 应用管理 → AnimeCat → 电池 / 耗电管理」里改成**不受限制 / 允许后台活动**，再重试。下载时把应用切到后台也尽量别让系统把它清掉。
2. **换一条线路再下**。缓存走的是与在线播放同一套线路，某条线路当时慢或不稳定，换一条往往就好了。
3. **Wi-Fi 与移动数据互换一次**，判断是不是当前网络本身的问题。
4. **清出存储空间**。剩余空间不足时下载会停在某一进度不动，这不是应用的问题。

## 六、换手机之后缓存能带走吗

**不能。** 缓存文件只存在本机，不跟账号走 —— 登录同一账号换到新手机，观看历史、收藏、追番列表会同步过来（前提是登录状态且做过备份），但已下载的番剧一集都不会过去，需要在新手机上重新缓存。

想知道哪些设定和记录能跟着账号走，看 [注册登录与数据备份.md](注册登录与数据备份.md)。缓存和播放之间的关系（比如缓存用哪条线路）在 [播放设置与线路切换.md](播放设置与线路切换.md) 里有说明。
