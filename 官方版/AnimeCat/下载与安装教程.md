AnimeCat 是安卓手机上的动漫追番应用，前身叫「动漫屋」。本篇只解决一件事：把网盘里这份包装进手机，并确认自己装的是哪一版。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本号通常是下载站当时挂着的编号，而网盘里这份是制作文档时核对过的那一个，两者未必相同。本文所有版本号、包名、体积以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | AnimeCat（前身：动漫屋） |
| 版本号 | 2.0.5 |
| 包名 | `com.anime.cat` |
| 安装包体积 | 111.27 MB |
| MD5 | `df26cdc14be1f2db2788949f6da8a3d3` |
| 适用平台 | 安卓手机 |

有三件事先说清楚：

- **下载站的版本号标注不可信**。同一个文件（MD5 一致）在不同站点会被写成 2.0.5、2.0.7 等不同编号，体积也常被四舍五入成「111.3M」。判断是不是同一个包，看**包名 + MD5**，不看名字旁边的数字。
- **同名的东西很多**。「动漫猫」「animecat」「动漫屋」在下载站里混在一起，其中不少是仿名壳子，包名完全不同（例如 `com.tfhs.gallery` 那个也叫动漫屋，但跟这份不是同一个应用）。名字对上不算数，包名对上才算。
- **这份包只有一个入口**，就是上面的网盘链接。别去第三方站下所谓「最新版」，那不是本文核对过的文件。

## 二、装之前要核对的两件事

**第一，确认是安卓手机。** AnimeCat 只发安卓包，iPhone 与 iPad 上装不了；想在电脑上看，只能借助安卓模拟器，把 APK 拖进模拟器安装即可，装法与手机一致。

**第二，别纠结最低系统版本。** 这份包的资料里没有登记最低系统要求，各下载站的标注也从 Android 4.3 到 5.2 都有，互相矛盾，不能当准数。实际操作上，装上能正常打开就说明你的设备可以；停在很老安卓版本（Android 5 以下）的设备，装上打不开的概率较高，这类机器没必要反复折腾。

## 三、安装步骤

1. **转存再下载**：打开 [AnimeCat 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7dfbc45c29d3)，把 APK 转存到自己的网盘后再下载到手机。转存这一步别省，否则链接失效后文件就找不回来了。
2. **允许安装未知来源应用**：手机「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器、浏览器或网盘客户端）打开开关，然后再点 APK。
3. **签名冲突就先卸载旧的**：手机里若已装着同包名、但签名不同的版本（常见于从别的下载站装过），覆盖安装会直接失败并提示「应用未安装」。先把旧的那个卸掉，再装这份。
4. **别急着从旧版升级**：如果你只想留着旧版，直接装这份会覆盖它。想两个都留是做不到的，包名相同，系统只认一个。

## 四、第一次打开：选登录还是直接体验

打开后会停在带两个按钮的页面：**「立即登录」**和**「立即体验」**。不注册也能用，点「立即体验」以游客身份进入首页即可。

游客身份与登录后的差别只有一处：**追番进度、收藏这类要跟账号绑定的记录，游客状态下不归你所有**。所以如果你打算长期追番，建议在 [注册登录与数据备份.md](注册登录与数据备份.md) 里走一遍注册，再开始攒记录。

## 五、装完做一次最小验证

挑一部常见的动漫，走一遍「搜索 → 点进详情页 → 开始观看」，能正常出画面并播起来，就说明安装没问题。

如果这一步卡住了，按下面分情况走：

- 搜索框里什么都搜不出来 → 先按 [常见问题与排查.md](常见问题与排查.md) 的「搜不到想看的番」一节排查；
- 能搜到、点开却播放失败或一直转圈 → 多半是播放线路的问题，看 [播放设置与线路切换.md](播放设置与线路切换.md)；
- 装不上、提示「解析包错误」或装上就闪退 → 直接翻 [常见问题与排查.md](常见问题与排查.md)。
