本篇按「你看到的症状」组织，不按功能分类 —— 从装不上、打开就退，到搜不到番、播放卡顿、投屏连不上、缓存打不开，都能在这里找到处置顺序。每条都从最省事的一步开始，先做完再往下走。

## 一、装不上 / 提示解析包错误

1. **确认文件下完整了**。从网盘下载时中断，会得到一个体积明显偏小的 APK（这份包完整是 111.27 MB），点开就报「解析包错误」。删掉重下。
2. **确认手机是安卓**。这份是安卓安装包，iOS 设备上没有能打开它的方式。
3. **先卸掉旧版本**。手机里已有同包名但签名不同的 AnimeCat（常见于之前从别的下载站装过），覆盖安装会提示「应用未安装」。卸载旧的再装。
4. **确认下载的是这份包**。第三方站点上挂着多个同名应用的包（例如包名为 `com.tfhs.gallery` 的另一个「动漫屋」），那些和本文这套不是同一个应用。核对包名 `com.anime.cat`；需要重新取包时，从 [AnimeCat 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7dfbc45c29d3) 转存下载。

## 二、打开就闪退，或卡在启动页

- **第一次打开就退**：先看是不是装在了老旧安卓版本上。这份包在很老的系统上打不开，属于设备与包的匹配问题，换设备或换版本更实际，别反复重装。
- **用一段时间后开始退**：到手机「设置 → 应用管理 → AnimeCat → 存储」里**清除缓存**（注意是清缓存，不是清数据 —— 清数据会连收藏和历史一起删掉），然后重开。
- **清缓存后仍退**：卸载后重新装一次这份包。这一步会清掉游客状态下的记录，动手前先看 [注册登录与数据备份.md](注册登录与数据备份.md)。

## 三、搜不到想看的番

按顺序排查：

1. **换关键词**。只留番名里最有辨识度的两三个字，繁简写法各试一次。
2. **换入口找**。搜索找不到时，去分类里按「地区 + 年份」翻一遍，或者看排行榜里有没有 —— 分类与排行能看到的内容范围，有时比搜索结果更全。
3. **确认是网络问题还是内容问题**：随便搜一个很常见的番名。如果连它都搜不出来，是网络或应用这一侧的问题，切 Wi-Fi / 移动数据分别试一次，再重启应用。
4. **确认版本**。装在手机上的是不是本文这套包，见第一节第 4 条。

## 四、能搜到但播放不了

先做一个判断，它决定你接下来往哪边查：**换一部完全不相干的番试一次**。

- **只有原来那一部播不了** → 是这部番的片源或线路问题，往下按「换线路」处理；
- **换成别的番也一样播不了** → 不是你选的那部番的问题，先查网络（Wi-Fi 与移动数据互换一次），再查应用本身（重启应用、清缓存）。

分两种表现，处置不同：

**提示「播放失败」「播放错误」**：换播放线路。详情页片名旁的「播放源」入口，或播放页里的线路按钮，选另一条确认重播，多数情况立刻就好。一部番至少挂两条线路，一条挂了不代表看不了。细节见 [播放设置与线路切换.md](播放设置与线路切换.md)。

**没有报错、一直转圈加载不出来**：先点下一集、再点回来，相当于重新发起一次请求；仍然不行就换线路；换线路还不行，降低画质档位再试。若所有线路都播不了，通常是这一时段服务端压力大，换个时间再来。

## 五、播放卡顿、频繁缓冲

按代价从低到高：

1. 把画质档位降一档 —— 这是见效最快的一步；
2. 关掉弹幕，低配机器上能立竿见影；
3. 切换网络：Wi-Fi 与移动数据互换一次，判断是不是当前网络的带宽问题；
4. 关闭后台占带宽的应用（网盘同步、系统更新、其他视频）；
5. 确认不是投屏导致的 —— 投屏比手机小屏更吃带宽，投屏卡顿见 [投屏到电视与盒子的步骤.md](投屏到电视与盒子的步骤.md) 的「投屏之后出现问题」一节。

## 六、投屏搜不到电视

1. 关掉手机移动数据，确认手机和电视连的是**同一台路由器**（访客 Wi-Fi 与主网络若被隔离，互相看不见）；
2. 确认电视端的投屏接收功能是开着的；
3. 重启电视端接收功能，或把电视与路由器断电重开；
4. 电视端换一个通用投屏接收应用再试。

投屏按钮在**播放页**里（小电视图标），不在详情页 —— 找不到按钮先确认自己所在的位置。完整步骤见 [投屏到电视与盒子的步骤.md](投屏到电视与盒子的步骤.md)。

## 七、缓存下来的番播不了

1. 确认那一集**下载真的完成了**（中途中断的会显示存在但打不开），删掉重下；
2. 检查手机剩余存储空间，空间不足会让下载被截断；
3. 换一条线路重新缓存 —— 缓存和在线播放走同一套线路，线路失效时缓存的内容也可能播不出来；
4. 删掉重下是最快的解法，不用在文件本身上继续查。

缓存不跟账号走，换手机后需要重新下载，这一点的说明在 [离线缓存与本地看番.md](离线缓存与本地看番.md)。

## 八、关于更新与版本

- **别用第三方站的「最新版」覆盖安装**。包名相同会直接覆盖你现在的版本，而那个包未必是同一个来源的文件。要更新就取本文核对过的这份包，或用应用内的更新提示。
- **更新后收藏和历史会保留吗**：登录状态下不受影响，会跟着账号走；游客状态下，只要不是「清除数据」或卸载重装，一般也还在，但不保险。
- **要不要升级**：遇到上面第四、五、六节里反复调不好的问题，升级到较新版本再试是合理的；如果当前版本用着没问题，不升级也完全可行。
