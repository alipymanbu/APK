## 一、先核对你要装的是哪个版本

Watoo 的开发商是深圳七七五九网络科技有限公司，安卓版包名 `com.tian.watoo`。应用商店里能搜到的最新版版本号会更靠后，但本篇配套的安装包信息如下，装之前可以先对一遍：

| 项目 | 信息 |
| --- | --- |
| 版本 | 2.1.8 |
| 包名 | com.tian.watoo |
| 安装包大小 | 6.18M |
| MD5 | 7D8D1AAED9EF073D8E0174E36DB2889B |

几点说明：

- 这是一款体量很小的应用，安装包只有 6M 出头，装完几乎不占空间，对手机配置要求也不高。
- 2.1.8 不是官网当前的最新版。新版主要在细节体验上做了优化，核心玩法（表情待办、双击操作、番茄钟）没有变化；如果你只关心"能不能正常用"，这一版完全够用。
- 想验证安装包是否完整，可以用手机文件管理器或电脑上的工具核对 MD5 值，与上表一致即说明文件没有损坏。
- 公开渠道能查到的后续更新记录大致是：v2.2.0 引入用户反馈功能，v2.2.1 与 v2.2.5 先后增强对安卓 6.0 以下版本的兼容，v2.2.7 优化体验细节——与本文的说法一致：新版改的是兼容性与细节，玩法没有变（以官方发布说明为准）。

## 二、从夸克网盘转存安装包

安装包放在夸克网盘里，你需要先把它转到自己的网盘账户，再下载到手机：

1. 在手机或电脑上打开 [Watoo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4d86d596b50a)。
2. 勾选分享里的 APK 文件，点「转存」，选择一个你自己的目录保存。
3. 转存完成后，打开手机上的夸克 App（或网页版），在「我的网盘」里找到刚转存的文件。
4. 点下载，等文件落到手机本地存储。

如果只是自己装一次，直接下载也行；转存的好处是文件永久留在你的账户里，不怕原分享链接以后失效。

## 三、安装步骤

1. 下载完成后，在夸克 App 的下载列表里点开 APK 文件，或在文件管理器里找到它手动点开。
2. 系统会提示「是否允许安装」，如果是首次从夸克或文件管理器安装应用，可能还会要求你授权「安装未知应用」的权限，按提示允许即可。
3. 点「安装」，几秒钟就能装完。
4. 打开 Watoo，首次进入一般会请求存储、通知等权限——通知权限关系到提醒功能能不能正常弹出来，建议允许，理由见 [提醒与桌面小组件设置.md](提醒与桌面小组件设置.md)。

## 四、安装失败的常见原因

| 现象 | 多半是 | 处理办法 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 文件没下载完整 | 重新下载一次，或核对 MD5 |
| 提示「应用未安装」 | 手机上已装了不同签名的同名应用 | 先卸载旧的 Watoo 再装 |
| 点开 APK 没反应 | 存储权限没给文件管理器 | 到系统设置里给对应 App 授权 |
| 安装按钮置灰 | 系统禁止了「安装未知应用」 | 去设置里给来源 App 开授权 |

装好之后如果打不开、闪退，或者对权限弹窗有疑问，翻 [常见问题与故障排查.md](常见问题与故障排查.md)，里面按现象列了排查顺序。装好想先学会记录待办，去 [表情待办用法.md](表情待办用法.md)；想顺手把专注模式和作息打卡也用起来，看 [番茄钟与睡眠打卡.md](番茄钟与睡眠打卡.md)。
