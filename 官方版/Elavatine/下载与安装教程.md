## 一、动手前先对上这张表

Elavatine 是一款饮食记录与营养管理应用：你把每天吃的东西记进日志，它按权威食物库换算成热量与三大营养素，再跟你自己设定的营养目标对照。它面向的是认真练、也认真吃的人——增肌减脂期要盯住蛋白质和碳水的人，以及要带学员的教练。安装本身不复杂，容易出问题的是**拿到的是不对的包**：同一个应用在网上有多个来源的安装文件，版本号和体积都不一样，所以先把事实核对清楚。

| 项目 | 值 |
| --- | --- |
| 应用名称 | Elavatine |
| 开发者 | 深圳力冠实业有限公司 |
| 版本号 | 2.1.7 |
| 包名 | `com.elavatine.app` |
| 安装包大小 | 39.02M |
| 文件校验值（MD5） | `818a485f02c69b5eba8eb7aa791091b9` |

其中**包名**最该看：`com.elavatine.app` 是应用在系统里的身份，这一串对上了，才说明你装的是同一个应用，而不是同名的别的软件。**版本号**决定你看到的功能与本文描述的是不是同一套——官方发布页上的版本通常已经比 2.1.7 更新，两边的数字不要混着用，一切以你手上这份文件为准。

至于系统要求，官方没有对 Android 最低版本给出一个统一数字，以官方发布页当时显示为准。真低于要求时不用你去猜：安装入口会直接把这一步拦下来。

## 二、把安装包取到手机里

1. 在手机上打开 [Elavatine 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c3ec45dd1553)，进入分享页。
2. 还没有网盘账号的先按提示注册或登录；已有账号的直接点「保存到网盘」，把文件转存进自己的空间，再从自己的网盘里下载。转存之后下载比在分享页里直接打开稳，分享页刷新或网络波动都不会把下载打断。
3. 下载完的文件名形如 `Elavatine_v2.1.7.apk`。**别在网盘里直接点「打开」**，那只会触发在线预览；要选「下载」，等文件完整落到手机的下载目录再动手。
4. 想确认文件有没有下坏，拿上一节那串 MD5 对一遍：`818a485f02c69b5eba8eb7aa791091b9`。不少文件管理器自带校验入口，算出来的字符串与这串完全一致，说明文件是完整的。

如果是通过电脑下载再传到手机，同样先转存到自己网盘、避开分享页直开；传输过程中断过一次的文件，也按第 4 步重新校验一遍再装。

## 三、允许从浏览器或网盘安装

Android 默认不允许安装来自浏览器、网盘这类来源的文件，第一次装通常会弹「已阻止安装」。开关位置按系统版本分两种：

| 系统版本 | 操作路径 |
| --- | --- |
| Android 8.0 及以上 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 → 选中你下载用的浏览器或网盘 App → 打开开关 |
| Android 7.x 及以下 | 设置 → 安全 → 打开「未知来源」 |

开关打开后回到文件管理器，点 `Elavatine_v2.1.7.apk` 继续。装完建议把开关关回去，以后需要临时再开。

## 四、安装过程中可能出现的提示

| 提示 | 含义与处理 |
| --- | --- |
| 「解析软件包时出现问题」 | 文件没下完或已损坏。删掉重新下载，并按第二节的方法再校验一次 MD5 |
| 「应用未安装」 | 手机上已存在同一个包名的其他版本。先在设置里卸载旧的，再装这一份 |
| 「您的设备与此版本不兼容」 | 系统版本低于应用要求。对照官方发布页确认你的 Android 版本 |
| 安全软件提示风险 | 非应用商店来源的常规提醒。确认文件来自你信任的渠道后继续 |
| 装完桌面上找不到图标 | 部分启动器刷新慢，回桌面下拉一次，或在应用列表里搜索「Elavatine」 |

## 五、第一次打开要做的几件事

1. **注册或登录账号**。日志、营养目标、身体数据都挂在账号上，不登录进不了主界面，注册环节要手机号，细节见 [注册登录与账号数据.md](注册登录与账号数据.md)。
2. **按提示授予权限**。相机和相册权限是拍食物、拍身体照片时用的；通知权限用于提醒你记录。这两项现在拒绝也不影响安装，之后随时能在系统设置里补开。
3. **设定营养目标**。注册引导会依次问你性别、年龄、健身目标、当前体重、日常活动量和期望效果，然后给出一套初始目标。这一步可以手动输入，也可以先跳过——跳过的后果与两种设法的区别见 [营养目标怎么设定与调整.md](营养目标怎么设定与调整.md)。

走完这三步，底部「日志」页就是你的主界面。接下来怎么把吃的东西记进去，看 [怎么记录每天吃了什么.md](怎么记录每天吃了什么.md)。
