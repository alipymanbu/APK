## 一、一餐能怎么记进去

Elavatine 的日常用法很单一：每吃一顿，就在「日志」里把这一顿的食物和份量补上。真正需要你决定的只是**用哪种方式把食物找出来**——四种方式的适用场景不一样，选错了会多花几分钟。

| 方式 | 适合什么情况 | 你要做的事 |
| --- | --- | --- |
| 食物库搜索 | 大多数家常食材、常见品牌食品 | 在搜索框输入食物名，从结果里选中，填份量 |
| 扫码 | 包装食品，包装上有条形码 | 用相机扫包装上的码，带出对应条目后填份量 |
| 拍照识别 | 盛在碗盘里、不方便逐个称的成品菜 | 拍一张照片，让应用先估出食物与份量，你再核对修改 |
| 新建自定义食物 | 食物库里确实没有的自制菜、小品牌 | 自己填食物名称与营养成分，存下来以后可复用 |

最省事的是搜索——常吃的食物记过几次之后会沉到「常用食物」里，下次不必再搜。拍照和扫码解决的是「懒得逐个称」的问题，代价是估算值需要你过一眼。

## 二、份量怎么填

同一个食物，热量对不对几乎全看份量这一栏。填的时候注意三件事：

- **单位要对上**。食物库里的条目常同时给了「每 100 克」和「每份」两套数值，你按哪种填，就选对应的单位，别把「1 份 = 50 克」的条目当成 100 克用。
- **生熟要分清**。米面、肉类在生重和熟重下每百克的热量差得很多，食物库里也分「生」「熟」两类条目，按你实际称的状态选。
- **混合菜要么拆要么整体估**。一盘青椒炒肉可以按食材拆成两三条记，也可以直接搜现成的菜品条目整体记；前者准、后者快，选一种坚持用，别一顿拆一顿整体估，统计口径才可比。

## 三、记完之后在哪看

- **日志页**：按餐次（早餐、午餐、晚餐、加餐）列出当天每一条记录，页面上下部分同时显示当天的营养素合计与你设定的目标，缺口或超标一眼能看出。
- **概览页**：把体重、身体围度和摄入数据放在一起看趋势，适合按周回顾，不是每天都要点。
- **日志标签**：给某一天或某一条记录打标签，用来区分「训练日 / 休息日」「正常饮食 / 外食」这类特殊情况，事后复盘时能按标签把同类日子拎出来对比。

想改口径、想让某一餐少算，直接在日志里删掉或改份量即可，改完的合计数会立刻跟着变。

## 四、常用食物与最近添加

你通过「日志」添加过的食物，会被记成常用食物并展示在食物页面，用来缩短下次的记录路径。用得久了会得到两个好处：一是常吃的那几样排在最前面，二是只需要改份量，不用重新搜。自定义食物的用法也一样——建一次、之后每次都能直接调出来，营养成分按你当初填的算。

如果常吃的食物列表被塞得太乱，最直接的办法是把已经不再吃的那几条自定义食物删掉，而不是重建。

## 五、漏记和记错怎么补

- **整餐漏了**：点开对应日期的日志，补一条即可，日期可以往前选，补前一天、补一周前的都行。
- **份量记错了**：改那条记录的份量，不要删掉重加，免得把餐次也弄乱。
- **一整天都没记**：不建议凭印象一天补全。饮食记录的价值来自当时的准确度，隔几天凭记忆补的数字误差很大，补完反而会误导你对目标完成度的判断。
- **记重了**：同一条重复出现时，删掉多出来的那条，合计会自动回落。

## 六、几个常见的卡点

| 现象 | 原因与处理 |
| --- | --- |
| 搜不到要吃的食物 | 换更短的关键词，或按通用名（而不是品牌名）搜；仍未收录就用「新建自定义食物」自己加一条 |
| 拿不准该选哪条 | 同名食物常有多条（不同品牌、不同生熟状态），优先选带品牌或注明生熟的条目，再核对每份克重 |
| 拍照识别出的食物不对 | 拍的时候让主体食物占满画面、避开多个菜品混在一起的场景；识别结果先核对再保存 |
| 扫码扫不出来 | 包装上的码有反光或褶皱时会扫不到，改成手动搜索；海外商品条码常不在库里 |
| 合计与包装标签对不上 | 先看份量单位与生熟状态，其次看是不是漏掉了油、酱料这类配料 |

要是记录到一半应用与网络断开，已提交的记录不会丢；等网络恢复再补后面的即可。中餐、食堂菜和外卖这类搜不到、也称不了的饭菜怎么记，单独整理在 [中餐和外卖怎么记才准.md](中餐和外卖怎么记才准.md)。关于账号与数据同步的问题，见 [注册登录与账号数据.md](注册登录与账号数据.md)。
