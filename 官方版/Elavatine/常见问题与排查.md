## 一、装不上、装完打不开

这一篇不按功能分章，而是按**你看到的现象**归类：安装与启动、食物查询与份量、识别不准、登录与账号、换机后的数据、目标数值偏差、设置类问题与会员订阅。遇到问题时先在下面对应的小节里找现象，再按给出的顺序查——多数情况排查两三个点就能定位到底是包不对、账号不对还是设置不对。

先分清是哪一步卡住，两类问题的处理完全不同。

| 现象 | 排查顺序 |
| --- | --- |
| 点安装包没反应 / 提示已阻止 | 还没放行安装来源。到设置里给浏览器或网盘 App 打开「安装未知应用」，再点一次安装包 |
| 提示「解析软件包时出现问题」 | 文件没下完或已损坏。删掉重下，并核对 MD5 是否为 `818a485f02c69b5eba8eb7aa791091b9` |
| 提示「应用未安装」「与已有应用冲突」 | 手机上已有同包名的其他版本。先在设置里卸载旧的 Elavatine，再装这一份 |
| 提示「与此版本不兼容」 | 系统版本低于应用要求。对照官方发布页确认你的 Android 版本 |
| 装完点图标闪退 | 先重启一次手机再看；仍闪退就卸载后重新安装一遍完整包。若只在某台设备上出现，多半是系统版本或机型适配问题 |
| 装完找不到图标 | 回桌面下拉刷新一次，或在应用列表里搜「Elavatine」 |

很多时候问题就出在包本身不完整。确认无误后还是装不上时，重新取一遍资源最省事：[Elavatine 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c3ec45dd1553)。

## 二、搜不到食物、份量对不上

- **搜不到**：换更短、更通用的关键词。搜「全麦吐司」比搜某个品牌的具体产品名命中率高；如果确认库里没有，用「新建自定义食物」自己加一条，填名称和营养成分，存下来以后能反复调用。
- **同名好几条，不知道选哪个**：优先选带品牌名或注明生熟状态的条目，再进详情页看每份克重是否与你实际吃的一致。
- **合计跟包装标签差得多**：按顺序查三处——份量单位是不是选错、生重熟重是不是弄反、是不是漏记了油和酱料这类配料。
- **份量记错想改**：直接改那一条的份量，不要删掉重加，避免打乱餐次归属。

## 三、扫码或拍照识别不准

扫码和拍照都属于「先识别、你再核对」的方式，识别结果保存前都有机会改。

| 问题 | 处理 |
| --- | --- |
| 条码扫不出来 | 擦一下包装、避开反光和褶皱；海外商品的条码常常不在库里，直接改用手动搜索 |
| 拍照认出了错误的食物 | 让主体食物占满画面、光线均匀，避开一碗里混着好几样的场景；识别后手动替换成正确条目 |
| 拍出来的份量明显偏大或偏小 | 拍照给的是估算值，尤其对形状不规则、汤汁多的菜偏差更大；这种菜建议按食材逐个记，而不是整体拍 |
| 拍配料表能读出内容但数值不对 | 配料表上的数值是按每 100 克标的，读出来之后注意把份量换算成你实际吃的重量再确认 |

## 四、登录、验证码、账号相关

- **收不到短信验证码**：先看是否被拦截软件归入垃圾短信；换一个网络环境（WiFi 与流量互切）后重发；短时间内反复请求可能被限流，等几分钟再试。
- **换了手机号怎么办**：手机号是账号的基础，换号应先在应用内完成换绑，再注销旧号或弃用旧号，别直接卸装应用了事。
- **第三方登录后仍被要求手机号**：这是实名认证的要求，不是登录失败。
- **想彻底不用这个账号**：走注销流程，注销需要验证码确认，且不可恢复，操作前先把要留的数据自己存一份。细节见 [注册登录与账号数据.md](注册登录与账号数据.md)。
- **换了手机数据是空的**：先确认新机登录用的是旧机同一个账号方式；再确认旧机上当时确实处于登录状态——未登录状态下记的内容不跟随账号。两者都确认过仍不对，再核对是不是登成了另一个账号。

## 五、目标和实际对不上

登录没问题、记录也在，但数字看着不对时，按这个顺序查：

1. **目标本身是不是被改过**。改过的目标从改动那天生效，拿新目标去衡量旧日期的记录，当然对不上。
2. **训练日与休息日有没有设反**。两天的目标值本来就不一样，设反了会天天显示缺口或超标。
3. **运动消耗有没有重复记**。活动量已按「经常训练」设过，又在训练后单独记一笔大额消耗，净结果会被高估。
4. **份量单位口径是否一致**。同一份食物一会按每 100 克记、一会按每份记，周统计就失去了可比性。

排查完还是觉得偏差大，可以先连续记满一周再看——单日的数据受水分、排便、称重时间影响很大，不足以判断目标是否合适。

## 六、设置类问题

| 想做什么 | 路径 |
| --- | --- |
| 换主题颜色 | 底部导航「我的」→「个性化」→「主题颜色」，可选跟随系统、深色或浅色 |
| 改碳循环周期 | 「我的」→「我的目标」→「碳循环/欺骗日」，用滑块调循环周期 |
| 收不到记录提醒 | 到系统设置里给 Elavatine 放开通知权限，并确认没被系统的省电策略限制后台 |
| 相册/相机用不了 | 到系统设置里给 Elavatine 打开相机与相册权限，拍照识别和身体照片都依赖它们 |

设置改完通常立即生效；如果界面没跟着变，退出应用重新进入一次即可。记录本身的方法与口径问题，见 [怎么记录每天吃了什么.md](怎么记录每天吃了什么.md)。

## 七、会员与自动续费

应用内有一层叫 **ELA PRO 的会员订阅**，属于按期自动续费的付费项。这里最需要提前知道的一点是：**iOS 端的取消入口不在应用里**。卸载应用、退出登录都不会停掉扣费，必须去 App Store 的订阅管理里关掉自动续订。

| 项目 | 说明 |
| --- | --- |
| 订阅形式 | 连续包月、连续包年两种 |
| 费用 | 包月 28 元、包年 168 元（价格可能调整，以 App Store 与应用内当时显示为准） |
| 扣费时机 | 确认购买后即扣费；此后在当前周期到期前 24 小时内自动扣费，并顺延一个周期 |
| 取消续订 | 在当前订阅周期到期前至少 24 小时，到 Apple ID 的订阅管理中关闭自动续订 |
| 取消后 | 不再扣费，当前已付费周期不受影响 |
| 不订阅会怎样 | 饮食记录、营养目标、计划分享这些主要功能都能继续用；订阅具体包含哪些权益，以应用内说明为准 |

**几件容易踩的事**：

- **想停就早点停**。只在到期前 24 小时内才算「提前」，卡在最后一天再操作，很容易刚好错过扣费节点。
- **换了平台要重新确认**。以上的价格与取消路径按 iOS 端（App Store 订阅）说明；如果你用的是 Android 版，收费形式与取消入口以应用内和对应应用商店当时显示为准。
- **想彻底不用这个账号**，走注销流程而不是只退订——注销会一并处理账号数据，两者不是同一件事，区别见 [注册登录与账号数据.md](注册登录与账号数据.md)。
