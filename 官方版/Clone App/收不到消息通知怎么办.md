# Clone App 收不到消息通知怎么办

> 分身退到后台后收不到消息、来电不弹窗、通知没声音，按本篇逐项设置即可，全部是手机系统侧的开关。
> **相关文档**：[常见问题与解决方法.md](常见问题与解决方法.md) · [多开与账号管理.md](多开与账号管理.md)

## 一、先明白消息是怎么断的

分身应用的消息要经过两层才能到你眼前：**分身把消息交给 Clone App 主程序，主程序再以通知的形式转发给你**。所以断流只有两类原因：

1. **通知权限没给够**——消息其实到了，但主程序没资格弹给你；
2. **后台被系统杀掉**——分身或主程序被省电机制清理，消息根本没走到转发那一步。

先给 Clone App 和分身应用把下面四个通用开关都打开，再按你手机的品牌做专属设置：

| 通用开关 | 位置 |
| --- | --- |
| 自启动 | 设置 → 应用管理 → Clone App 与分身 → 自启动 |
| 电池优化不限制 | 设置 → 电池 → 应用耗电管理（省电策略选「不优化 / 无限制」） |
| 通知全部允许 | 设置 → 通知 → Clone App 与分身 |
| 最近任务上锁 | 最近任务界面，把两张卡片下拉锁定 |

## 二、华为 / 荣耀

1. **通知中心**：设置 → 通知，找到 Clone App 和分身应用，每一项通知形式都打开，「允许打扰」按需处理；
2. **自启动**：设置 → 应用和服务 → 应用启动管理 → 找到 Clone App → 关掉「自动管理」改为手动 → 允许后台活动；
3. **电池**：设置 → 电池 → 应用耗电详情 → Clone App → 启动管理改为手动并全部允许；
4. **电池优化**：设置 → 隐私 → 权限管理 → 特殊访问权限 → 电池优化 → 把 Clone App 和分身设为「不允许」；
5. **悬浮通知**：设置 → 隐私 → 权限管理 → 特殊访问权限 → 显示在其他应用上层 → 允许 Clone App。

华为的纯净模式只影响安装环节（见[下载与安装教程.md](下载与安装教程.md)），与消息接收无关，不用动。

## 三、小米 / Redmi（MIUI / 澎湃 OS）

1. 分别打开 Clone App 与分身的「应用信息」，开启**自启动**；
2. 省电策略选**无限制**；
3. 通知管理里打开**悬浮通知**权限，并把页面最底部「通知类别」下的每一项都开悬浮通知；
4. 收到消息没声音的：通知管理里开启发声权限，进「新消息通知」选一个提示音；
5. 没有桌面角标的：通知管理里打开「桌面图标角标」权限（部分机型不支持角标，无此项就跳过）。

## 四、vivo

1. 设置 → 通知与状态栏 → 打开「桌面角标」「悬浮通知」「锁屏通知」；
2. 应用通知管理里找到 Clone App 和分身，打开「允许通知」并选提醒方式；
3. 设置 → 应用和权限 → 权限管理，依次进「自启动」「悬浮窗」「锁屏显示」「后台弹出界面」，把 Clone App 和分身的开关都打开；
4. 设置 → 电池 → 后台耗电管理 → 找到这两个应用 → 允许后台高耗电。

## 五、OPPO

1. 设置 → 通知与状态栏 → 通知管理 → 找到 Clone App 和分身 → 打开「允许通知」；
2. 设置 → 其他设置 → 最近任务管理，把两个应用锁定；
3. 设置 → 电池 → 应用耗电管理 → 两个应用 → 允许完全后台行为；
4. 权限管理里补上「悬浮窗」与「后台弹出界面」。

## 六、设置完还是收不到

1. **测试链路**：让分身里的应用给自己发条消息，确认分身本体活着——分身被杀时图标还在但进程已停，先手动打开一次分身再看；
2. **语音视频来电不弹窗**单独卡在「后台弹出界面 + 悬浮通知」这两项上，回到品牌小节重点检查；
3. **清一次后台再锁定**：被管家类软件「一键加速」清掉是常见断流原因，锁定卡片后管家就不会碰它；
4. **版本不同步**：本体应用刚升级、分身没跟上的阶段也会消息异常，按[多开与账号管理.md](多开与账号管理.md)第五节同步或修复分身；
5. 以上都无效时，用软件内「意见反馈」把机型和系统版本报给开发方，兼容性问题他们才有条件跟进。

各品牌菜单名称随系统版本略有出入，找不到对应入口时在设置里直接搜索关键词（「自启动」「电池优化」「后台弹出」）最快。
