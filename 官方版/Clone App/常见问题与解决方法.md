## 一、分身打不开或闪退

按顺序排查，多数闪退出在前两步：

1. **补权限**：进入系统「设置 → 应用管理」，找到 Clone App 和出问题的分身应用，把存储、设备识别码、显示悬浮窗这几项权限补全。国产品牌系统升级后经常默认关掉这些权限，分身就会启动失败；
2. **清缓存**：在分身应用的「应用信息 → 存储」里先清缓存。注意「清除数据」会清空分身里已登录的账号和记录，动手前先确认里面没有要保的数据；
3. **看内存**：同时挂多个游戏分身时内存不够，系统会直接杀掉后台分身。关掉不用的后台应用再试；
4. **重建分身**：以上都无效时，删掉这个分身重新克隆一个。重建只影响该分身自身，其他分身不受影响；
5. **核对本体版本**：本体应用刚升级过而分身没跟上时也会闪退，按[多开与账号管理.md](多开与账号管理.md)第五节的方式同步版本；部分情况下打开分身会直接提示「请修复分身」，按提示进 Clone App 点该分身选「修复分身」等它装完即可。

## 二、分身退到后台收不到消息

这是所有分身类工具的头号问题：**分身的消息要靠 Clone App 主程序在后台活着才能转发给你**，主程序或分身被系统省电机制杀掉，消息就断了。最小检查是四项——自启动、电池优化不限制、通知全部允许、最近任务上锁；华为、小米、vivo、OPPO 各自的完整设置路径已单独整理在[收不到消息通知怎么办.md](收不到消息通知怎么办.md)里，照着设置一遍基本都能解决。

## 三、安装环节被拦截

- **提示「禁止安装未知来源」**：按[下载与安装教程.md](下载与安装教程.md)第三节给浏览器或文件管理器授权；
- **华为 / 荣耀提示「纯净模式」**：到「设置 → 系统和更新 → 纯净模式」关闭后再装；
- **安全软件报毒**：开发方官方说明过，安卓虚拟化特性会让安全软件出现误报警告；如果确定安装包来源可靠（MD5 对得上），可以选择放行。不确定来源时不要放行；
- **装到一半失败**：确认存储空间够用，删掉旧版本重下。

## 四、哪些应用不适合多开

官方明确说「并非所有应用都可以克隆」。实际使用里，下面几类失败率明显高：

| 类型 | 常见表现 | 原因 |
| --- | --- | --- |
| 银行、支付类应用 | 闪退、拒绝运行 | 对运行环境校验严格，属敏感应用 |
| 加固保护的应用 | 打开即退 | 加固机制与分身环境冲突 |
| 大型 3D 游戏 | 崩溃、掉帧、无法进服 | 资源占用大，且部分游戏检测运行环境 |
| 鸿蒙原生应用 | 无法克隆 | 原生鸿蒙应用不走安卓安装体系 |

社交、工具类常规应用的成功率高得多。某个应用反复克隆失败时，换个思路：这个应用改用手机系统自带的「应用分身」试试（各品牌入口见[双开方案对比.md](双开方案对比.md)）。

## 五、其他已知的兼容性限制

- 官方说明 Clone App 及其生成的分身**与安卓模拟器、部分机型 ROM 不兼容**——模拟器用户别指望在里面再套分身；
- 分身里的海外应用（WhatsApp、Line、Instagram 等）登录不上或报缺失组件时，进该分身的设置把「谷歌服务」开关打开再试；不需要谷歌服务的分身则建议关掉，少一层负担；
- 系统大版本升级（如安卓 12 以上对后台和隐私权限收紧更严）之后，之前建好的分身可能需要重新给一遍权限才能恢复正常；
- 分身应用在系统应用管理里是独立条目，清理存储时别把分身当成「不认识的垃圾应用」删掉，删了里面的账号数据就没了；
- 排查不出来的克隆失败，用软件内「意见反馈」把机型、系统版本和应用名报给开发方——官方主页也写明这是他们收集兼容性问题的渠道。
