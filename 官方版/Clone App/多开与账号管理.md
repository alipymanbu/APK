## 一、先弄清它的分身形态

Clone App 给应用做分身的方式是：**为分身单独生成一个安装包，装到桌面上成为一个独立应用**。所以你会看到：

- 桌面上出现带徽标的独立图标，可以直接点开，不需要每次先打开 Clone App；
- 分身与本体数据完全隔离，各自登录各自的账号；
- 分身依赖主程序运行——卸载 Clone App 主程序，所有分身一起失效；
- 系统应用管理里能看到这些分身应用，占各自独立的存储。

官方在主页明确写过一条限制：**并非所有应用都能克隆**，克隆出来的应用可能崩溃、报错或功能异常，与模拟器及部分机型的系统也存在不兼容。游戏和加固过的应用失败率偏高，具体见[常见问题与解决方法.md](常见问题与解决方法.md)的「哪些应用不适合多开」。

## 二、创建第一个分身

1. 打开 Clone App，在应用列表里找到要分身的应用（支持社交、游戏等常见应用）；
2. 点该应用旁的「克隆 / 制作分身」；
3. 需要的话先做配置（改名、改图标、设备伪装、虚拟位置等，条目见[设备伪装与虚拟定位.md](设备伪装与虚拟定位.md)）；
4. 确认生成——软件会生成一个分身安装包并请求安装；
5. 允许「安装未知应用」权限，点安装，完成后桌面出现分身图标；
6. 打开分身，登录你的第二个账号即可。

这个流程每次创建分身都要走一遍安装环节，属正常现象，不是安装出了问题。

## 三、能开几个分身

| 状态 | 数量限制 |
| --- | --- |
| 免费使用 | 每个应用 1 个分身 |
| VIP | 不限制克隆数量 |

数量限制是官方明确的规则，免费版试着克隆第二个时会看到对应的会员提示。另外官方说明 Clone App 与 Clone App(lite) 的 VIP 身份互通，买过任意一边的会员另一边同时生效（两个版本的差别见[双开方案对比.md](双开方案对比.md)）。

想先试试会员功能再决定买不买：开发方官网主页提供 **7 天 VIP 体验码（F 码）**，领取后打开 Clone App 进「菜单 → F码」输入即可。官方注明体验码有效期 72 小时、超时作废需重新领，同一台手机要间隔 30 天才能再领；软件内活动中心还有其他免费获得 VIP 的活动。以上是官方主页说明的规则，以领取页面当时显示为准。

## 四、分身的日常管理

- **改名 / 换图标**：在分身列表里进入该分身的设置，可以改显示名称、换自定义徽标，方便区分大号小号；
- **应用锁**：给单个分身设密码锁，防止别人点开你的工作号或游戏小号；
- **窗口模式**：分身可以以悬浮窗口形式运行，边聊微信边挂游戏时不用来回切换；桌面还有悬浮框入口，从任何界面都能快速打开分身；
- **批量克隆**：支持一次勾选多个应用一起做分身，换新手机迁移多开环境时省时间；
- **一键加速**：主界面里的一键加速会关闭所有后台运行的分身，手机发烫或卡顿时用它统一收尾，比逐个清理快。

## 五、分身需要跟着本体更新

分身是跟着本体应用的版本走的：**本体应用升级后，分身才会需要更新**。如果分身的应用本体在应用市场里升级了，而分身还是旧版，可能出现登录异常或功能错乱。两个处理办法：

- 在 Clone App 里对分身做更新操作；打开分身时若直接提示「请修复分身」，按提示点「修复分身」等它装完即可；
- 或者关闭应用市场的自动更新，统一手动控制升级节奏——官方也建议这么做，避免本体悄悄升到分身跟不上的版本。

版本同步完发现还是收不到消息，先去[收不到消息通知怎么办.md](收不到消息通知怎么办.md)检查系统侧的通知与保活设置。

## 六、用第三方账号登录分身的注意点

分身应用里点「Facebook 登录」「Google 登录」这类第三方授权时，容易卡在授权环节。同类分身工具的通用做法是：

1. 把对应的第三方应用（Facebook、Google 服务框架相关应用等）本身也做一个分身；
2. 确认 Clone App 拿到了「读取应用列表」权限；
3. 重新打开分身，在登录页选择刚才分身出来的那个第三方应用完成授权。

如果照做之后授权还是失败，多半是该应用本身克隆不成功（见[常见问题与解决方法.md](常见问题与解决方法.md)），而不是登录步骤的问题。
