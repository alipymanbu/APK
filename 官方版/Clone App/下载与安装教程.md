## 一、开始前先确认三件事

1. **系统版本**：这份安装包要求安卓 5.2 及以上（按安装包信息标注；实际能否安装以手机安装时的提示为准）。
2. **存储空间**：安装包约 35M，装完后每个分身还会各自占一份存储——给多开留够空间，尤其是游戏分身。
3. **认准版本**：本篇对应的是网盘里的 **3.6.1** 版，包名 `com.py.cloneapp.huawei`——这正是开发方 Pengyou Tech（深圳鹏优科技）官方完整版使用的包名，三星 Galaxy Store 等官方渠道上架的同一版本用的就是它。开发方官网主页是 [www.cloneapp.net](http://www.cloneapp.net/homepage/index_cn.html)，网上的官方版本会持续更新，但都不是网盘里这一份；版本号、包名、体积一律以你手上这份安装包为准。

## 二、获取安装文件

安装文件放在夸克网盘里，需要先转存再下载：

1. 打开 **[Clone App 安装文件资源（夸克网盘）](https://pan.quark.cn/s/66eedfd91fc2)**；
2. 登录夸克账号，点「保存到网盘」转存到自己名下；
3. 在自己的网盘里找到该 APK 文件，下载到手机；
4. 下载完成后从通知栏或「文件管理 → 下载」目录里找到这个 `.apk` 文件。

MD5 为 `8A9069F627F356B6E08DC9C5402CC34C`。如果你想核对拿到的文件是否完整，可以用文件管理器自带的校验功能或第三方校验工具算一下 MD5，两者一致说明文件没在传输中损坏。

## 三、安装步骤

分身类工具生成的分身要以独立应用的形式安装，所以系统默认会拦一下，需要你先放开「未知来源安装」：

1. 手机进入 **设置 → 安全**（不同品牌叫法略有差异：小米是「隐私保护 → 特殊权限」，华为要在「设置 → 系统和更新 → 纯净模式」里先处理，见下）；
2. 找到「安装未知应用」或「允许安装未知来源应用」，给你用来打开 APK 的那个应用（浏览器 / 文件管理）授予权限；
3. 回到文件管理，点开刚下载的 APK，点「安装」；
4. 如果弹出「此应用可能有害」之类的确认框，选择「仍要安装」——这类提示在分身类工具上很常见，开发方在官方主页也说明过：安卓虚拟化特性可能导致安全软件显示警告，属于误报提示。

**华为 / 荣耀手机额外一步**：系统默认开启「纯净模式」时，只允许从应用市场安装应用。先到「设置 → 系统和更新 → 纯净模式」选择关闭，再执行上面的安装步骤。

安装过程中被拦截、报错的处理办法集中在[常见问题与解决方法.md](常见问题与解决方法.md)里。

## 四、首次启动要给的权限

第一次打开 Clone App 会连续要几个权限，都属于分身工具的正常需求：

| 权限 | 用途 | 建议 |
| --- | --- | --- |
| 存储 | 读写安装包、分身数据 | 必须允许 |
| 电话 / 设备信息 | 生成和管理分身的设备信息 | 允许，否则部分应用无法分身 |
| 通知 | 把分身应用的消息转发给你 | 允许，不然收不到分身消息 |
| 自启动 / 后台运行 | 保证分身在后台不被杀 | 建议允许，涉及消息接收 |

按品牌关掉电池优化的具体路径（华为 / 小米 / OPPO / vivo）在[收不到消息通知怎么办.md](收不到消息通知怎么办.md)里有整理，装完就顺手设置好，能省掉之后「分身收不到消息」的麻烦。

## 五、装好之后记住一条

**不要卸载或清理 Clone App 主程序**——分身依赖主程序运行，删了主程序，桌面上那些分身图标会全部失效。分身应用的日常使用（创建、改名、加锁、窗口模式）见[多开与账号管理.md](多开与账号管理.md)。

如果你还在犹豫要不要用它、跟手机系统自带的「应用分身」有什么区别，先看[双开方案对比.md](双开方案对比.md)再决定装不装。
