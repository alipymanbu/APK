## 一、设置在哪里

这些配置都在**单个分身的设置页**里——创建分身时可以预先配置，建好的分身也能进它的设置随时改。改完只影响这一个分身，不影响本体应用和其他分身。下面条目来自开发方官方主页的功能清单，个别条目是否可用以你手上的版本实际显示为准。

## 二、设备伪装能改什么

给分身一个与真机不同的设备信息，主要用途是让多个分身在应用看来是「不同设备」：

| 类别 | 可改条目 |
| --- | --- |
| 机型信息 | 伪装品牌 / 型号 |
| 设备标识 | 更改 Android ID、更改 IMEI / IMSI、更改谷歌广告 ID |
| 网络标识 | 更改 WebView 代理、更改 WiFi / 蓝牙 MAC |
| 隐藏类 | 隐藏 SIM 卡和运营商、隐藏 GPU 信息 |

配合「开启 / 关闭谷歌服务」「虚拟 SD 卡」这两个通用开关，可以按分身逐个调整运行环境。这些条目只在分身内部生效——你的本体应用和系统读到的仍是真实信息。

## 三、虚拟位置怎么用

分身内置虚拟位置功能，可以给这个分身设定一个与实际 GPS 不同的位置；高级玩法支持在设定范围内模拟移动轨迹，而不是钉死在一个坐标点上。需要模拟真实移动时，把范围和移动开关都打开即可。

典型使用场景是打卡类、社区类应用里不想暴露真实位置的场合。注意下一节的风险说明——**收不收这条虚拟位置，决定权在目标应用的服务器**。

## 四、隐私保护相关条目

设备伪装之外，分身里还有一组虚拟信息开关：

- 虚拟相册、虚拟通讯录、虚拟短信、虚拟日程、虚拟通话记录——分身应用读到的都是空壳数据，真实相册和通讯录不会进入分身；
- 阻止后台录音——分身应用退到后台后不允许它调用麦克风。

这几个开关配合使用，可以把「工作号分身能看到的东西」压缩到你愿意给的范围。介意输入法记录输入内容的，还可以启用虚拟键盘（属会员功能），启用后分身内不再调用任何外部输入法。

## 五、使用边界与风险，先看再开

1. **可能违反目标应用的条款**：给微信、游戏等账号配上伪造设备信息或虚拟位置，一旦被对方检测识别，轻则触发验证、重则限制或封禁账号——和[双开方案对比.md](双开方案对比.md)第四节说的第三方多开风险是叠加关系；
2. **考勤与监管场景的后果是实打实的**：公开判例里已有员工因用虚拟定位软件考勤造假被认定违反劳动纪律、公司解除劳动关系获法院支持；最高人民检察院也公布过社区矫正对象用虚拟定位逃避电子监管、最终被撤销缓刑收监的案例。企业微信、钉钉这类办公打卡工具的防作弊检测还在持续升级，不要拿工作和自由去试；
3. **游戏对位置与设备信息同样敏感**：公开讨论里，用虚拟位置玩 LBS 类游戏被检测出后封号甚至封设备的反馈不少，且普遍难以申诉；
4. **只对自己的设备和账号用**：这些功能的设计场景是保护你自己的隐私，拿来冒充他人设备身份、伪造他人位置参与需要真实位置的活动（考勤、赛事等），属于欺骗行为，后果自负；
5. **杀毒软件的提示**：设备伪装能力会触发部分安全软件的警告，开发方称这类警告为误报；是否信任、是否继续，取决于你对安装包来源的判断（来源核对见[下载与安装教程.md](下载与安装教程.md)）。
