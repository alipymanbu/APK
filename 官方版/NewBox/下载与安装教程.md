## 一、安装前先了解的三件事

NewBox 是一款安卓影视聚合播放应用，装好后首页提供电影、剧集、综艺等内容浏览，另有直播、历史收藏等板块。动手机之前，先确认这几点：

| 事项 | 说明 |
| --- | --- |
| 版本 | 本文以网盘里的 1.1.5 版为准（安装包 37.34M，包名 `com.github.tvbox.osc`）。2026 年 9 月检索时网上已可见更新的版本，界面细节以你手上的那份为准 |
| 设备 | 手机、平板可直接安装；智能电视、电视盒子同样用这份 APK 侧载安装（它属于 TVBox 体系的影视应用，电视上用遥控器操作，也有按大屏习惯设计的界面） |
| 装完的样子 | 第一次打开不等于马上有片看 —— 这类应用的内容靠「订阅」加载，不配置订阅源时首页可能没有内容或部分功能不可用。配置方法见 [订阅源配置指南.md](订阅源配置指南.md) |

## 二、获取安装包

安装包从上面的 NewBox 安装文件资源（夸克网盘）获取：打开分享链接，转存到自己网盘后下载 `NewBox_v1.1.5.apk` 到设备即可。

如果你要在电视上安装，而下载工具在手机或电脑上，有两个常见转法：

1. **先下到手机，再传到电视**：用 U 盘中转，或通过电视自带的「文件快传 / 远程推送」类功能传过去。
2. **电脑下载后拷进 U 盘**：把 APK 文件放到 U 盘根目录（方便电视文件管理器里找到），插到电视或盒子的 USB 口上。

## 三、手机上安装

1. 点开下载好的 APK 文件。系统会提示「不允许安装未知来源应用」，按提示允许「来自此来源的应用」后再继续。
2. 等安装进度走完，点「打开」。
3. 首次启动如弹出存储、网络等权限请求，按需允许 —— 本地视频播放、历史记录这些功能依赖存储权限。

部分手机厂商（如小米、华为）会额外弹一道「风险应用」确认，属于对侧载 APK 的通用提醒，确认继续安装即可；如果安装中途失败，多半是包没下完整，重新下载一次再试（详见 [常见问题排查.md](常见问题排查.md) 第一节）。

## 四、电视 / 盒子上安装

电视上没有浏览器也没有应用商店入口，常规做法是 U 盘侧载：

1. 把 APK 文件拷进 U 盘，插入电视或盒子的 USB 口。
2. 打开电视上自带或另装的「文件管理」，找到 U 盘里的 APK 文件，选中确认。
3. 弹出「禁止安装未知来源」提示时，到「设置 - 安全」里允许「未知来源 / 允许安装未知应用」，再回来继续。
4. 装完在「我的应用 / 全部应用」里找到 NewBox 图标打开。

遥控器操作提示：界面按上下左右 + 确认的方式导航，「我的」页里的订阅管理、设置等入口都在同一层级，按方向键移动焦点、按 OK 键进入即可。

部分运营商定制盒子（系统版本老、且锁定权限）不允许侧载，这种情况下装不上属于设备限制，不是安装包问题。

## 五、装完先做什么

打开应用后，底部是「首页 / 直播 / 历史收藏 / 我的」四个板块。如果首页一片空白或点了影片没反应，先别急着删应用 —— 到「我的 - 订阅管理」里把订阅配置好，内容才会加载出来，具体步骤见 [订阅源配置指南.md](订阅源配置指南.md)。配好订阅之后，直播板块和本地视频的用法见 [直播与本地播放.md](直播与本地播放.md)。
