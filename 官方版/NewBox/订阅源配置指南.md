## 一、为什么装完打开是空的

NewBox 属于 TVBox 体系的影视应用，这类应用（包名带 `tvbox.osc` 的都是同一血统）本身只负责「壳」的部分：界面、搜索、播放器。片源数据来自一个叫「订阅 / 接口 / 配置」的文本文件（通常是 JSON 格式的网络地址），应用按这个地址去拉取影视分类和播放线路。

所以装完看到的情况一般是：

| 现象 | 原因 |
| --- | --- |
| 首页没有分类、没有影片 | 还没配置订阅 |
| 有分类但点开是空的、转圈报错 | 订阅里的部分线路失效了 |
| 换了个订阅后内容完全变了 | 订阅就是内容入口，换订阅等于换了一套片源目录 |

订阅源是第三方维护的，哪条还活着、质量如何会随时间变化，应用本身不附带长期有效的片源。你需要自己找一个订阅地址填进去 —— 通常是影视相关论坛、社区里有人持续更新的那种，本文不代找、不推荐具体地址。

从社区的使用反馈看，这类订阅地址的形态与寿命有两条普遍规律，找订阅前先有预期：

- **它就是一个文本文件的地址**：内容通常是 JSON 或 TXT 格式的配置，应用打开时整个拉下来解析。所以判断一条地址死没死，最直接的办法是手机浏览器里打开它 —— 能看到一大段文本就是活的，404 或超时就是死的。
- **用的人越多死得越快**：这类地址是个人服务器在供，访问量一上来就容易挂（有长期玩 TVBox 的用户反复提到这一点）。所以社区里订阅地址会一批批换，你的应用跟着换就行，这属于正常维护，不是应用出了毛病。

## 二、添加订阅的步骤

以 1.1.5 版的界面为准（手机竖屏布局，电视版路径相同、焦点操作）：

1. 打开 NewBox，进底部「我的」页。
2. 点「订阅管理」。
3. 按界面提示新增订阅，把你的订阅地址（一条 `https://` 开头的链接）粘贴进去，确认。
4. 回到首页等它加载，出现电影 / 剧集 / 综艺等分类即表示订阅生效。

几个实操建议：

- **地址要复制完整**：订阅链接通常很长，少一个字符就加载失败。手机上用复制粘贴，不要手打；电视上输入最省力的三个办法，按靠谱程度排：① 在手机端先把地址发给自己（微信文件传输助手、备忘录都行），需要用时复制粘贴；② 给电视或盒子外接一个 USB 键盘（百元盒子大多留了 USB 口，键盘插上就能输），比遥控器戳输入法快一个量级；③ 部分电视输入法支持「扫码输入 / 手机推送」，在配对后用手机代输。
- **一次配一条常用的**：多条订阅会混在一起展示，找片时容易乱；先跑通一条，觉得覆盖不够再加第二条。
- **配完不生效先刷新或重启应用**：订阅是打开时拉取的，改完不刷新会维持旧状态。

## 三、订阅失效的判断与更换

订阅是第三方文件，会失效。出现下面这些信号，基本可以判定当前订阅有问题：

1. 首页分类还在，但点开任何分类都是空的或一直转圈。
2. 搜索任何片名都没有结果。
3. 影片详情能打开，所有播放线路都报错。

处理顺序：先确认家里网络正常、其他应用能上网，然后回「订阅管理」把旧订阅删掉或禁用，换一条新地址，回首页重新加载。换了订阅后内容目录会整个换掉，之前的收藏如果还挂着旧订阅的线路，可能播不出来 —— 这不是应用坏了，重新在当前订阅里找同一部片即可。

「我的」页里还有一个「搜索线程」入口，它控制聚合搜索同时查询的线路数量：调高搜得全但吃网络和性能，搜不动或卡顿时调低一些。这个设置跟着订阅走，订阅换了记得顺手核一眼。

## 四、能不能不配订阅直接用

直播板块（底部第二个 tab）通常也依赖订阅里的直播源；「本地视频」和「播放链接」这两个功能不依赖订阅 —— 前者播设备里已有的视频文件，后者粘贴一条视频直链就能放。也就是说，即使暂时没配订阅，你仍可以用它当本地播放器用，方法见 [直播与本地播放.md](直播与本地播放.md)。但要用它的聚合点播和直播，订阅这一步绕不开。
