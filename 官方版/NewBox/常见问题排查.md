# NewBox 常见问题排查

> 本篇按现象归类 NewBox 使用中的高频问题：装不上、打开空白、播不出来、投屏搜不到，逐条给排查顺序。

## 一、安装失败 / 解析包出错

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 安装到一半报「安装失败」 | APK 下载不完整 | 删掉重下。手机浏览器断点续传偶尔会截断文件，重下一次是第一反应 |
| 「解析包时出现问题」 | 安装包损坏，或电视安卓版本太老跑不动这个包 | 先重新下载核对一遍；电视上报这个错且确认包没问题，多半是系统版本低于应用要求，这类老设备只能放弃或换设备 |
| 提示「禁止安装未知来源」 | 系统默认拦侧载 | 手机：允许「来自此来源的应用」；电视：「设置 - 安全 - 未知来源」放开后再装 |
| 运营商定制盒子上完全装不了 | 系统锁定安装权限 | 设备限制，不是包的问题 |

如果你在电视上反复装不上，可以先把 APK 装在手机上确认包本身是好的 —— 手机装得上、电视装不上，问题就在电视那头。

## 二、打开后首页空白、没有内容

这是被问得最多的一类，九成不是故障：

1. **还没配订阅**。NewBox 只是播放器外壳，内容靠订阅加载，不配就是空的。去「我的 - 订阅管理」添加订阅地址，步骤见 [订阅源配置指南.md](订阅源配置指南.md)。
2. **配了订阅但没生效**。回首页下拉刷新，或彻底杀掉应用重开。
3. **订阅本身挂了**。分类还在但全是空目录、搜索无结果，就是订阅失效，换一条地址。

## 三、影片点开播不了 / 黑屏有声音

按顺序试：

1. **换线路**：影片详情页通常给多条播放线路，一条挂了换下一条，这是最快的判断办法。
2. **确认其他应用能上网**：有时候是家里网络抖了，不是源的问题。
3. **换片再试**：个别片子全线路报错 = 该片源失效，应用层面无解，等订阅更新或换订阅。
4. **本地视频黑屏**：属于解码不支持那个文件，换播放器播同一个文件对比即可确认。

## 四、投屏搜不到设备

按出现概率排序：

1. 手机和电视不在同一个 Wi-Fi（双频路由器拆成两个名字、访客网络、连了移动数据都会中招）。
2. 路由器开了「AP 隔离」，设备之间不互通，到路由器后台关掉。
3. 电视端应用被杀到后台了，保持前台再搜。
4. 老电视不支持投屏协议，这种只能借助外接盒子解决。

具体投屏操作见 [直播与本地播放.md](直播与本地播放.md) 第四节。

## 五、电视上遥控器操作别扭

- 列表切不动：确认焦点在哪个区域，先按「返回」回到分组层再移动。
- 输入订阅地址太痛苦：三个省力办法（按靠谱程度排）：① 手机端把地址发给自己，用时复制粘贴；② 外接 USB 键盘，插上盒子直接打字，安卓电视对 USB 键盘的兼容普遍很好；③ 部分电视输入法自带「扫码 / 手机推送」代输。订阅地址务必粘贴不要手打，见 [订阅源配置指南.md](订阅源配置指南.md)。
- 想用手机当遥控器：商店里那类「WiFi 遥控」应用大多针对系统级遥控协议，能不能控到侧载装的 NewBox 因设备而异，不保证行；真要省事，一个十几块的 USB 小键盘比反复试遥控应用更稳。
- 焦点看不见：部分电视系统对第三方应用的高亮焦点显示较弱，凑近看当前项的边框即可。

## 六、历史与收藏相关

「历史收藏」页分「历史」「收藏」两个标签，右上角垃圾桶图标用于清空记录。看过一片、回头找不到时先确认自己还在同一套订阅下 —— 换订阅后收藏可能失效（见第二节），这不是记录被清了。
