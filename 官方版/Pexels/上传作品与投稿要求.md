# Pexels 上传作品与投稿要求

> 本篇面向想把自己的照片、视频投稿到 Pexels 的人：官方的硬性门槛、上传步骤、每日数量限制，以及最常见的落选原因。

## 一、投稿的硬性门槛（官方要求，截至 2026-09）

| 项目 | 要求 |
| --- | --- |
| 版权 | 必须是你自己拍摄的作品，你是版权持有者 |
| 第三方权利 | 画面中出现的人物、商标、作品等，你需要持有相应授权（肖像权、商标权等） |
| 文件格式 | 仅 JPEG（不接受 RAW、PNG、GIF） |
| 最低分辨率 | 400 万像素以上（最小 2592 × 1520） |
| 内容 | 无露骨、暴力内容；**不允许生成式 AI 内容** |

手机拍摄的照片可以投稿，官方有专门说明——门槛在像素和画质，不在设备。

## 二、每日上传上限

- 普通投稿者每天最多上传 **50 个**文件，每天 UTC 00:00 重置；
- 无上限投稿只对官方「Pexels Heroes」计划开放；
- 滥用上传权限会被下调限额。

一天批量投稿超过 50 张会被拦下，分几天传即可。

## 三、上传步骤

**网页端（桌面和手机浏览器相同）：**

1. 登录 Pexels 账号（注册见[界面语言与账号.md](界面语言与账号.md)）；
2. 点页面右上角的 **Upload** 按钮；
3. 在上传页把照片或视频文件拖入指定区域，或点 Browse 选取文件；
4. 填写标题、标签、位置——都是可选项，但填了更容易被搜到；
5. 点 **Submit Content** 提交。

**iOS 应用：** 登录后点底部中间的 **+** 号 → 勾选「媒体权利确认」→ 选文件 → 加标签 → 提交。安卓端应用以应用内实际显示的上传入口为准。

## 四、提交之后

- 官方团队人工审核，通常需要几天；被收录会收到邮件通知；
- 收录后作品以 Pexels License 发布（含义见[素材商用与授权规则.md](素材商用与授权规则.md)）——意味着任何人都可以免费使用你的作品，投稿前想清楚这一点；
- 你可以在个人资料里绑定 PayPal，读者可以向你打赏；作品页的浏览量、下载量也能看到；
- 想撤稿：在个人资料里点开作品，下方有删除链接；已被收进首页或搜索的作品需发邮件给官方处理。

## 五、最常见的落选原因

官方列出的高频技术原因，提交前自查一遍能省很多往返：

- 画面模糊、跑焦、主体不明确；
- 横竖方向不对、构图歪斜；
- 过曝或欠曝；
- 后期过重（夸张的 HDR、极端饱和度、明显暗角）；
- 加了文字、图形覆盖、边框、水印；
- 非照片类内容（海报、传单、拼贴、插画等）。

被拒的文件可以处理后重新提交，没有次数惩罚；但低质量批量投稿会影响账号信誉，宁缺毋滥。
