## 一、把界面切换成简体中文

新装的 Pexels 默认是英文界面，改中文只要三步：

1. 打开应用，点**右上角的菜单**；
2. 点 **Change Language（更改语言）**；
3. 在语言列表里选**简体中文**，界面立即切换。

如果列表里没看到简体中文，说明该版本的语言包不含中文，更新到较新版本后再试；改错了想换回英文，走同一条路径选 English 即可。

## 二、不注册能用什么、注册后多什么

| 功能 | 不登录 | 登录后 |
| --- | --- | --- |
| 搜索、浏览、下载图片和视频 | 可用 | 可用 |
| 点赞、收藏到合集 | 仅本地有限保留 | 云端保存，换设备不丢 |
| 下载历史（Your Downloads） | 无 | 有，可随时重新下载 |
| 关注摄影师 | 无 | 有 |
| 上传自己的作品 | 无 | 有 |

结论很直接：**偶尔下两张图可以不注册；要长期收集素材，注册一个能省很多事**——收藏和下载历史都在云端，换手机不掉。

## 三、注册与登录

1. 点右上角菜单里的登录 / 注册入口；
2. 用邮箱注册账号，或直接使用应用内提供的第三方登录方式（以应用当前显示的选项为准）；
3. 登录一次后会保持登录状态，之后[素材下载与保存.md](素材下载与保存.md)里说的「Your Downloads」下载历史就开始生效。

## 四、上传自己的作品（可选）

Pexels 允许任何人投稿照片和视频，被收录的素材会以 Pexels 许可发布（含义见[素材商用与授权规则.md](素材商用与授权规则.md)）：

1. 在个人页面找到上传入口，选择手机里的作品提交；官方网页端也可上传；
2. 官方团队会筛选，通常需要几天；被选中发布的会收到邮件通知；
3. 每天最多上传 50 个文件，批量投稿要分几天进行；
4. 想撤下已上传的照片：在个人资料里点开那张照片，照片下方有删除链接；若照片已被收进首页或搜索结果，则需把照片链接发给官方邮箱处理。

投稿有格式与内容上的硬性门槛（仅 JPEG、分辨率下限、不允许 AI 生成内容等），完整清单与常见落选原因见[上传作品与投稿要求.md](上传作品与投稿要求.md)。上传不是必需的，不投稿也完全不影响下载使用。遇到登录不上、收不到验证邮件等问题，先看[常见问题与解决.md](常见问题与解决.md)。
