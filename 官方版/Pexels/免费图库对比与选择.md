## 二、风格与搜索体验的差异

- **Pexels**：内容偏「商业干净」风——打光规整、构图清楚，放进演示文稿、官网、广告页不违和；搜索支持按颜色、方向筛选，找图效率高；
- **Unsplash**：偏「编辑摄影」风，艺术感和氛围感强，常被用作博客头图和品牌视觉；短板是视频几乎没有；
- **Pixabay**：种类最全（含矢量、插画、音乐），适合需要非照片素材的场合；代价是质量参差，需要多翻几页筛选。

三家的许可条款都很宽松且互有细节差异（比如对转卖原素材的限制表述），商用前逐条对照各自许可页，见[素材商用与授权规则.md](素材商用与授权规则.md)。

## 三、按用途选

| 你的情况 | 优先考虑 |
| --- | --- |
| 一个库同时要照片和视频（社媒、短视频配素材） | Pexels |
| 只要高质量照片、不关心视频 | Unsplash |
| 要矢量图、插画、图标、背景音乐 | Pixabay |
| 用 Canva 做设计 | Pexels / Pixabay——两家 2019 年起都在 Canva 旗下，Canva 编辑器里可直接调用其素材 |
| 程序里批量取图（API） | 三家都有免费 API；第三方资料提到 Pexels 免费档约每小时 200 次调用、Unsplash 约 50 次，以各自官方文档为准 |

## 四、实际用法建议

三家账号互不通用，但注册都是免费的。常见做法是把 Pexels 和 Pixabay 都装上或都收藏：照片和视频从 Pexels 拿，缺矢量或音乐时去 Pixabay 补。同一主题在一个平台搜不到理想结果时，换一家往往立刻有货——各家收录的摄影师圈子不同，重合度没有想象中高。

选定之后的具体操作（搜索、筛尺寸、下载、找下载历史）都在[素材下载与保存.md](素材下载与保存.md)里，Pexels 的流程在其他平台也基本通用。
