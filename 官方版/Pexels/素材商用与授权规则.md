## 一、Pexels License 的核心结论

Pexels 上所有图片和视频都采用 **Pexels License**，官方口径是三句话：

1. **免费**，个人和商业用途都可以；
2. **不需要署名**（attribution 不是强制项）；
3. 下载后可以自由修改、编辑、用于你的项目。

所以网站配图、公众号封面、演示文稿、书籍封面、YouTube 视频素材这些常见用途，官方都明确允许。完整的许可条款以官方许可页为准：[https://www.pexels.com/photo-license/](https://www.pexels.com/photo-license/)。

## 二、不允许的三类用法

| 用法 | 官方态度 |
| --- | --- |
| 把素材**原样转卖**（如打包卖图、上架素材市场） | 不允许——可以卖你的创意成品，不能卖素材本身 |
| 用于**政治竞选** | 不允许 |
| 暗示图中人物 / 品牌为你的产品**背书** | 不允许——图里的商标、Logo、可识别人物仍受隐私、版权、商标权保护 |

第二条的典型场景：你给产品做广告页，图里出现了明显的人物或品牌，页面文案不能写成「XX 品牌推荐使用本产品」。涉及可识别人物的敏感场景（如暗示其健康状况、宗教立场），可能需要另行取得当事人授权。

## 三、要不要署名：不强制，但有标准写法

不署名完全合规。但如果你愿意署名（官方也鼓励），标准格式是：

```text
Photo by John Doe on Pexels
```

并附上该图片在 Pexels 的页面链接；实在放不了链接，用文字标注 `Powered by Pexels` 也可以。这样做对你是零成本，对贡献者是实际激励——他们靠这些反馈知道自己的作品被用在了哪。

## 四、开发者相关的 API 口径（可选了解）

除了手动下载，Pexels 还提供免费 API 供程序调用（需要先申请 API key）。第三方资料提到免费档约每小时 200 次调用（截至 2026-09，具体以官方文档为准）；**要提升到不限量，官方要求同时在成品里署名 Pexels 和素材贡献者**。这一条对做应用、做网站聚合的开发者是硬要求，写代码前先读官方 API 条款。
