## 一、开播前必须满足的条件

少一样都开不出去，先逐条核对：

| 条件 | 怎么满足 |
| --- | --- |
| 有账号且已登录 | 见 [注册与登录账号.md](注册与登录账号.md) |
| 邮箱已验证 | 网页端 设置 里确认绑定邮箱收过验证邮件（以官方要求为准） |
| 两步验证已开启 | 网页端 设置 → 安全和隐私 里开 2FA；官方对广播账号有验证要求 |
| 摄像头与麦克风权限 | 首次点开播时按提示允许；被拒绝过就去 设置 → 应用 → Twitch → 权限 里补开 |
| 网络上行够用 | 上行带宽建议 10 Mbps 起步、至少 5 Mbps（第三方教程经验值，以实测为准） |

## 二、开播步骤

1. 打开 Twitch 应用，点左上角**头像**。
2. 点 **Go Live / 开始直播**（有的版本是相机图标）。
3. 选**分类**：游戏、Just Chatting（闲聊）、IRL 等——分类决定观众在哪个列表里刷到你。
4. 填**直播标题**：写清这一场播什么，观众搜关键词时先看到它。
5. 选**摄像头**（前置/后置）与麦克风，确认画面预览正常。
6. 点开始，倒计时结束后正式推流，画面右上角会出现观看人数。

开播过程中保持 App 在前台；切到后台或锁屏容易被系统暂停推流。

## 三、画质与码率怎么定

手机开播的可选档位以 App 内实际列表为准，常见取值是 720p 与 1080p：

| 分辨率 | 参考码率 | 适用场景 |
| --- | --- | --- |
| 1080p30 | 4500~6000 Kbps | 上行稳定、画面静止为主的闲聊/展示 |
| 720p30 | 2500~3500 Kbps | 走动、游戏画面等高动态内容，更稳 |

（码率为多个第三方教程的经验值，具体以推流时 App 给的反馈为准。）

选档原则：**网络撑得住再往上调**。第一场先用 720p 开，画面不糊不卡再尝试 1080p；上行不够时高码率只会换来观众端的缓冲。

## 四、直播中怎么管理

- **看聊天**：画面下方或侧边的聊天窗实时滚动，你以主播身份发言带特殊标识；权限操作（禁言、慢速）在观众长按菜单里。
- **换标题/分类**：直播中可进仪表盘（View Dashboard / Edit Stream Info）修改，观众端即时生效。
- **结束**：点**结束直播按钮**退出，别直接杀进程或锁屏——那样推流可能挂起，观众会看到卡住的最后一帧。
- **留回放**：结束后回放（VOD）是否保留、保留多久，取决于你账号的设置与频道权限（以页面当时显示为准）。

## 五、开播常见故障

| 现象 | 先查什么 |
| --- | --- |
| 点开播没反应 / 权限弹窗 | 摄像头、麦克风权限是否被拒；去系统设置补开 |
| 推流一开始就不稳 | 上行带宽不够 → 降档到 720p；关掉同网的大流量任务 |
| 手机发烫、掉帧 | 关闭后台应用、摘掉厚壳；发热降频是移动端直播最常见的限速点 |
| 观众说黑屏有声音 | 观众端硬解码问题，让他们降画质（见 [看直播卡顿黑屏怎么排查.md](看直播卡顿黑屏怎么排查.md) 第三、五节） |
| 直播中突然掉线 | 先按排查篇第二节确认网络；恢复后重新点开播即可 |

直播画面里的视角、界面操作等观众侧的看直播技巧，在 [怎么看直播与聊天互动.md](怎么看直播与聊天互动.md)。
