## 一、先判断：是 Twitch 挂了，还是你这台设备的问题

改任何设置之前先做这三步定位，能省掉一半无用功：

1. **查平台状态**：浏览器打开 `https://status.twitch.com/`，看有没有与你症状吻合的故障公告；有公告就等它恢复，本地怎么折腾都没用。
2. **换一个频道试**：只有单个频道坏 = 主播推流故障，等他重连；所有频道都坏 = 继续往下走。
3. **换一台设备 / 换一个网络试**：手机不行但电脑网页版行 = 问题在手机侧；所有设备都不行 = 问题在网络侧。

## 二、网络侧排查

按命中率从高到低：

1. **关掉代理 / 加速类工具再试**：这类工具本身是播放失败的常见诱因，退出后重开 App 测一次。
2. **Wi-Fi 与移动数据互切一次**：能立刻分辨是哪条链路坏。只有移动数据不行时，问运营商是否对视频限速。
3. **确认不是整机断网**：同一 Wi-Fi 下打开别的视频网站，也不行就重启光猫和路由器（断电 30 秒再通电）。
4. **网页版做基准**：浏览器能打开 `https://www.twitch.tv` 而 App 不行，说明网络通、问题在手机侧，直接跳到第四节。

## 三、播放器侧排查（卡顿、缓冲、画质崩）

1. **降画质**：齿轮 → Quality → 先降到 480p，能顺畅播放说明带宽撑不住原画，固定用低档位即可。
2. **关低延迟**：齿轮 → Advanced → 关掉 Low Latency，低延迟模式对网络抖动更敏感。
3. **掐掉同网抢带宽的活动**：后台下载、网盘同步、其他设备看 4K 都会让直播缓冲——暂停后再试。

## 四、应用侧排查（闪退、黑屏、一直加载）

按顺序做，做到哪一步好了就停：

1. **强制停止 + 清缓存**：设置 → 应用 → Twitch → 强制停止，再进「存储」→ 清除缓存。这一步解决大部分更新后的异常，且**不会掉登录**。
2. **退出重进账号**：会话过期会导致内容加载不全，登出再登入刷新一次。
3. **清数据（更深一层）**：上一步无效再点「清除存储/清除数据」——会退出登录并重置偏好，需要重新登录（见 [注册与登录账号.md](注册与登录账号.md)）。
4. **关电池优化**：设置 → 应用 → Twitch → 电池 → 选「不受限制」。系统的省电策略会杀掉直播所需的后台服务，表现为看一会儿就卡死。
5. **更新系统组件**：应用商店里把 Android System WebView、Google Play 服务、Chrome 更新一遍再重启手机——聊天层与登录页靠 WebView 渲染，它过期时 Twitch 常在打开聊天时崩。
6. **重装**：卸载后重新安装（包与步骤见 [下载与安装教程.md](下载与安装教程.md)），用**最初那种登录方式**登回，避免触发循环验证。

## 五、常见报错对照表

| 现象 / 报错 | 更可能的原因 | 第一动作 |
| --- | --- | --- |
| Error 2000 一直重连 | 网络不稳或代理干扰 | 关代理 → 切网络 → 降画质 |
| Error 5000「内容不可用」 | 会话过期、地区限制、拦截工具 | 退出重登 → 换网络 → 查该频道在别的设备能否播 |
| 只有画面黑、有声音 | 硬解码不兼容该画质 | 降到 480p 或纯音频，能放就固定低档位 |
| 打开就闪退 | 缓存损坏或 WebView 过期 | 清缓存 → 更新 WebView → 仍崩则清数据 |
| 反复弹登录页 | 登录会话失效 / 混用登录方式 | 退出重登 → 固定一种登录入口 |
| 聊天打不开、页面残缺 | WebView 版本不同步 | 更新 Android System WebView 后重启 |

## 六、什么时候该放弃排查

同一网络下**所有**视频平台都卡 → 是网络本身的问题，Twitch 这侧无解；同一台手机**所有**应用都闪退 → 是系统的问题，先解决系统。反过来说，只有 Twitch 坏、别的都好，才值得把上面六节走完——通常走到第二节或第四节第 1 步就好。
