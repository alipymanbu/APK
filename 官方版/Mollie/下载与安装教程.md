## 一、装之前先核对这几点

Mollie 是一款 AI 角色聊天类应用，当前这份安装包的信息如下（网上商店显示的最新版本号可能与此不同，凡涉及版本号、体积以这份包为准）：

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.0.5 |
| 安装包体积 | 约 57.03 MB |
| 包名 | `com.roleplaychatwithme.mollie` |
| MD5 | `355E3C5B86C97926AA5C92CA3DD8AB0E` |
| 系统要求 | 安卓（安装包标注 5.2 及以上，以安装时的实际提示为准） |
| 界面语言 | 中文 |

两点提醒：

1. **留出存储空间**。安装包本身不到 60 MB，但应用运行后聊天记录与缓存会持续增长，建议手机剩余空间在 1 GB 以上。
2. **这个包不在应用商店里**。它通过夸克网盘分发，所以安装流程比「应用商店一键装」多一步手动确认，下面按顺序做即可。

年龄门槛、联网要求、付费口径这几个「装之前值得知道」的点，单独整理在 [数据安全与使用注意.md](数据安全与使用注意.md) 里，不急的话先扫一眼再动手装。

## 二、从网盘获取安装包

1. 点开上面的 **Mollie 安装文件资源（夸克网盘）** 链接；
2. 手机上装了夸克 App 的话会直接跳到分享页，没有的话按页面提示先装一个（应用商店搜「夸克」即可，免费）；
3. 点「保存到网盘」把文件转存到自己网盘（转存后文件就是你的了，不怕原分享失效）；
4. 在自己网盘里找到这个 APK 文件，点它，选择「下载」到手机本地存储。

下载完成后通知栏一般会出现「下载完成」提示，点开就能进安装；错过了就去夸克的下载目录或手机 `Download` 文件夹里找。

## 三、允许安装并完成安装

APK 不经过应用商店安装时，安卓会拦一道，这是系统安全机制，放行一次即可：

1. 点开下载好的 APK，系统弹出「为了手机安全，禁止安装未知来源应用」之类的提示；
2. 按提示进入设置页，找到「允许此来源安装应用」的开关并打开（不同品牌叫法略有差别：小米叫「安装未知应用」，华为叫「允许安装未知应用」，路径都在 `设置 → 安全` 或安装弹窗直接跳转的页面里）；
3. 返回安装界面点「安装」，等进度条走完；
4. 点「打开」直接进入应用，或回桌面找到 Mollie 图标再点。

**安装被拦的两种常见情况**：

- 手机管家 / 病毒扫描提示「风险应用」：这类 AI 聊天应用不在主流商店上架时容易被误报，确认包名与 MD5 与上表一致后，可选择「仍要安装」；如果你不放心，那就不要装，风险自负的判断自己做。
- 提示「解析包错误」：多半是下载不完整，删掉重新从网盘下载一次；换网络环境（比如换 Wi-Fi 或用流量）再试也常见效。
