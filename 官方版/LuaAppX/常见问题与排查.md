## 一、先归层：问题出在哪一环

LuaAppX 的使用链路是「装 App → 走首次启动 → 建项目 → 写代码 → 打包」，报错先归位，别跨层乱试：

| 环节 | 典型现象 | 去哪一节 |
| --- | --- | --- |
| 装 App 本身 | 点 APK 提示已阻止、解析包失败 | 第二节 |
| 首次启动 | 卡在协议页、权限点不了 | 第三节 |
| 建项目 | 点「+」没反应、模板选不了 | 第四节 |
| 写代码 / 打包 | 编辑器标红、打包失败、结果不对 | 第五节 |
| App 直接打不开 | 一点图标就闪退 | 第六节 |

## 二、装的时候被系统拦 / 解析包失败

**「已阻止安装来自此来源的应用」**：不是安装包的问题，是安卓 8.0 之后按应用授予的安装权限——**你用哪个应用打开 APK，就给哪个应用开权限**：

- 原生/近原生系统：设置 → 安全 → 安装外部来源应用 → 选中你的浏览器或文件管理器 → 允许；
- OPPO/一加/Realme（ColorOS 12+）：设置 → 密码与安全 → 系统安全 → 外部来源应用；
- 华为/荣耀：设置 → 安全 → 更多安全设置 → 安装外部来源应用；
- 三星：设置 → 安全与隐私 → 更多安全设置 → 安装外部来源应用；开关是灰的先临时关掉系统的「自动拦截程序」，装完再打开。

**「解析包时出现问题」或装到一半失败**：多半是 APK 没下完整。删掉重新下载，用 [下载与安装教程.md](下载与安装教程.md) 里的 MD5（`F45A6CDAB8F9CDEB7FC359CEB9095B8A`）核对，体积应接近 11.46M；再检查剩余存储。

**提示与已装版本冲突**：先确认手机里那个是不是同包名（`com.load.LuaAppX`）的旧版；若装的是别的应用（如 LuaAppXPro，包名 `com.luaappx`），两者可以共存，不会互相覆盖——但功能与工程不通用，别在错的那个里找你的项目，见第七节。

## 三、首次启动卡住：协议页与权限页

- **协议页「下一步」点不动**：先勾选「我已阅读并同意」再点，没勾选的同意项是点不动的；
- **权限页点「完成」没反应**：按页内提示逐项把权限设完，有未处理项时不会放行；
- **权限被拒了怎么办**：去 设置 → 应用 → LuaAppX → 应用权限，把存储/文件相关权限改为允许，再重进 App。你写程序要读写项目文件，权限不给就建不了项目、存不了代码；
- 卡死不动时先强行停止再打开（设置 → 应用 → LuaAppX → 强行停止），还不行就清缓存（不清数据，避免项目被删）。

## 四、建项目环节的问题

- **点右下角「+」没反应**：先确认存储权限已允许（见第三节），权限被拒时新建页常常打不开或保存失败；
- **模板列表是空的 / 想选的模板没有**：模板随版本增减，以新建项目页实际列出的为准；拿不准就选 `Default`，它永远是可用的兜底项（模板选择详见 [第一个Lua项目怎么建.md](第一个Lua项目怎么建.md)）；
- **项目包名填错了**：新建时就把包名想好；已经建错的项目，与其改旧的，不如新建一个包名正确的更省事；
- **列表里找不到项目**：回想是否用过「清除数据」——清除数据会连项目一起删掉，先别清数据，见第六节的替代步骤。

## 五、代码报错与打包失败

- **编辑器把某行标红**：先读错误信息第一行——`unexpected` / `expected` 这类是括号、`end` 没配对；`attempt to call a nil value` 这类是名字打错或函数未定义。**每条报错的完整解读与改法**（含行号怎么读、nil 类错误逐条对照）单独整理在 [Lua常见报错怎么改.md](Lua常见报错怎么改.md)；
- **利用补全少犯错**：输入时的候选列表会推荐你项目里已有的函数与变量，优先从中选而不是手敲全名（详见 [代码高亮与自动补全怎么用.md](代码高亮与自动补全怎么用.md)）；
- **打包前先检测**：打包失败多半是还有没清的标红——先跑一遍代码执行与检测，把问题清干净再打包；
- **不报错但结果不对**：在可疑位置加一行输出打印，跑一遍看有没有打出来；没打出来说明代码根本没走到那里，问题在更前面。

## 六、一点图标就闪退 / 打不开

按出现概率排：

1. **系统版本不够**：本篇这份包要求安卓 5.2 以上，先在 设置 → 关于手机 里核对系统版本；
2. **包没装完整**：按第二节用 MD5 与体积核对，对不上就重新下载安装；
3. **权限或数据异常**：设置 → 应用 → LuaAppX → 存储占用，**先清缓存试**；确认项目已不需要或已备份后，才用「清除数据」——注意清数据会删掉本地项目；
4. **机型兼容问题**：以上都排除还闪退，就是这台机型与这个版本不兼容（公开资料没有官方兼容机型清单），换台手机验证一下即可定位，不是你操作错了。

清理类操作都可能碰到「数据被删」，动手前先确认项目文件是否需要保留。

## 七、和 LuaAppXPro 有什么区别（别装错）

检索资料时会同时撞见这两个名字，对照如下：

| | LuaAppX（本篇这套文档） | LuaAppXPro |
| --- | --- | --- |
| 包名 | `com.load.LuaAppX` | `com.luaappx` |
| 体积 | 11.46M | 第三方页面标注约 11.7M（单一来源，以实际下载为准） |
| 关系 | 网盘里发的、本篇讲的都是它 | 另一个包，功能细节与本篇不可照搬 |

两者名称相近但**包名不同、工程不通用**。核对方法：设置 → 应用 → 应用信息，看包名是哪一个——你手机里存的项目属于谁，就只在那个应用里找。
