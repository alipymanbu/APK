# Wallpaper Engine 手机版连接电脑配对教程

> 本篇讲把 Wallpaper Engine 手机版和电脑版配对的完整步骤，以及搜不到电脑时的排查办法。

## 一、配对前要满足的条件

配对的本质是**手机和电脑在局域网里互找**，所以先确认这三条：

1. **同一个局域网**：手机连的 Wi-Fi 和电脑连的网络来自同一个路由器。电脑插网线也算同一个网络；手机开流量、或路由器开了访客网络/AP 隔离，都会找不到；
2. **电脑上已装 Windows 版 Wallpaper Engine 且正在运行**：它要在 Steam 里购买安装（价格以 Steam 页面为准），手机版不能脱离它工作；
3. **两边都关掉 VPN / 代理**：这类软件会干扰局域网设备互发现，是配对失败的高频原因。

## 二、电脑端：生成配对 PIN

1. 打开 Windows 版 Wallpaper Engine 主界面；
2. 点右上角的**移动设备（Mobile）**按钮；
3. 在弹出的设备概览底部点**连接新设备（Connect new Device）**；
4. 界面会显示一个 **4 位数 PIN**，给下一步用（一个 PIN 配对一台设备）。

## 三、手机端：搜索并连接

1. 打开手机上的 Wallpaper Engine，点右下角的**添加（Add）**；
2. 选**与计算机配对（Pair with Computer）**；
3. 应用开始搜索同一网络里正在运行的电脑版，几秒后你的电脑会出现在列表里，点它；
4. 首次连接会要求输入上一步电脑上显示的 **4 位 PIN**，输入确认。

配对成功的标志：手机版顶部状态栏**变绿**并显示所连的电脑名，电脑版右上角的移动设备按钮也变绿。之后只要手机和电脑又在同一网络里、两边都开着 Wallpaper Engine，就会**自动重连**，不用每次重新输 PIN。

## 四、搜不到电脑怎么办

按出现概率从高到低逐条试：

| 排查项 | 具体做法 |
| --- | --- |
| 防火墙拦了 | 首次运行电脑版时弹过"允许访问网络"的窗口，点了取消就会拦。到 Windows 防火墙的**允许应用通过防火墙**里找 `ui32` / **Wallpaper Engine UI** 条目，把**专用和公用**都勾上，重启 Wallpaper Engine。另外电脑版检测到连接问题时会自动弹出防火墙修复建议，可先按它的提示修复再试 |
| 端口被拦 | 电脑版用 **UDP 7884** 和 **TCP 7889** 两个端口，确认防火墙或安全软件没有屏蔽 |
| VPN / 代理 | 手机和电脑上的 VPN、代理都关掉再试 |
| 路由器隔离 | 进路由器设置打开 **UPnP**，关闭"AP 隔离 / 访客网络隔离" |
| 版本太旧 | 电脑版和手机版都更新到较新版本（手机版可用 [Wallpaper Engine 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a1394a670828) 那份或应用商店版） |

**手动输 IP 兜底**：电脑一直不出现时，多半只是"发现广播"被拦、直连其实能通。在手机版的连接概览点右上角**三个点 → 手动输入 IP**，填电脑的局域网 IP（电脑上 `ipconfig` 看 IPv4 地址）。注意电脑版必须开着、且**连接新设备**那个概览还停在那里，否则连不上。

**配对成功但总断线**：这类多是手机省电机制在后台清理了应用——锁屏几分钟或切走一会儿就掉，回桌面又不自动重连。把 Wallpaper Engine 加入电池优化白名单、允许后台运行与自启动（各品牌路径不同，具体见[壁纸消失或被重置怎么办](壁纸消失或被重置怎么办.md)第二节，是同一套设置）。省电模式开着时掉线也更频繁，属于应用内的省电联动，介意的话去应用设置里关掉。

## 五、还是连不上：走导入路线

配对不是唯一入口。电脑版可以把壁纸导出成 `.mpkg` 文件，用 USB、网盘等任何方式传到手机再导入，效果一样，只是不能自动同步。具体步骤见[壁纸传输与导入方法](壁纸传输与导入方法.md)。配对成功后想传壁纸，也看那一篇。
