## 一、无线传输（配对成功后）

手机和电脑配对成功后（步骤见[连接电脑配对教程](连接电脑配对教程.md)），在电脑版里传壁纸：

1. 在电脑版 Wallpaper Engine 的**已安装**列表里选中一张壁纸；
2. 点右侧的**发送到移动设备（Send to Mobile Device）**，或右键壁纸选同一项；
3. 在设备列表里选你的手机；
4. 等传输完成，手机版里就会出现这张壁纸。

两个省事技巧：

- **批量传**：按住 Ctrl 逐张点选多张壁纸，一次全部发送；
- **场景壁纸会先转换**：Scene 类型的动态/交互壁纸发送时会先针对手机硬件做一轮优化转换，高分辨率壁纸会等一会儿，属正常现象。

## 二、画质选项怎么选

发送场景壁纸时会弹画质选择。判断依据很简单：

| 你的情况 | 选哪个 |
| --- | --- |
| 旗舰机、想看满效果 | 高画质先试，卡了再降 |
| 中端机、或高分辨率壁纸出现卡顿 | **均衡（Balanced）**，官方对性能问题的推荐档 |
| 老机器、想省电 | 低画质档，再到手机版设置里压 FPS 上限 |

传完不满意可以删掉换一档画质重传，同一张壁纸允许多次发送覆盖。

传好后在手机版里点开壁纸 → 应用为壁纸即可。手机端的 FPS 上限、省电模式暂停等设置见[常见问题解答](常见问题解答.md)的卡顿与耗电两节。

## 三、连不上电脑：导出 .mpkg 手动导入

配对总也修不好（排查见[连接电脑配对教程](连接电脑配对教程.md)末节）时，用官方内置的导出功能绕过局域网：

**电脑端导出**：

1. 右键要导出的壁纸 → **发送到移动设备** → **导出 .mpkg**；
2. 等它生成一个 `.mpkg` 文件，记下保存位置。

**传到手机**（任选）：USB 数据线拷贝、SD 卡中转、任何网盘或文件分享服务、甚至邮件附件自己发自己——`.mpkg` 就是个普通文件，怎么方便怎么来。

**手机端导入**：

1. 打开手机版 Wallpaper Engine，用**导入文件**功能选中这个 `.mpkg`；
2. 导入完成后它和无线传输来的壁纸一样，直接应用即可。

一个关键注意点：Android 对应用读文件的限制很严，**把 `.mpkg` 放进手机的 Downloads（下载）文件夹最稳**，放别的目录如果导入时找不到，就挪到 Downloads 再试。

## 四、为什么外部壁纸都要从电脑中转

手机版不能自己连 Steam 创意工坊，所以所有"外部"壁纸（工坊订阅的、自己制作的）都得经电脑版中转——这也是本文两条路存在的意义。还没有电脑版时，先把手机版装上试试自带壁纸：安装方式见[下载与安装教程](下载与安装教程.md)。
