# Wallpaper Engine 手机壁纸消失或被重置怎么办

> 本篇解决一个高频故障：设好的动态壁纸过几小时或几天自己消失、退回默认壁纸，以及想主动取消壁纸时的正确做法。

## 一、先对号入座：你是哪种"消失"

| 现象 | 原因 | 去哪一节 |
| --- | --- | --- |
| 用几小时/几天后桌面变回默认壁纸或黑屏，无任何报错 | 被手机省电机制误杀 | 第二节 |
| 只是暂时不动了（开着省电模式时） | 应用内"省电模式暂停"功能在起作用，不是故障 | 第三节 |
| 不想用了，想换回普通壁纸 | 正常更换 | 第四节 |

先说明一点：壁纸文件本身不会丢。消失的只是"当前应用中的壁纸"这一设置，壁纸还在应用列表里，重新应用一次就回来。

## 二、壁纸自动消失：关闭电池优化

官方对这个现象的定性：正常情况下 Android 不会因省电终止动态壁纸，但确有用户反馈会被某些厂商的省电功能误杀——表现就是几小时、几天或几周后壁纸无声无息地消失。处理办法：

1. 打开系统**设置 → 应用**，找到 Wallpaper Engine（找不到就先在应用列表里搜）；
2. 进**电池**（或"耗电管理/省电策略"这类名字）；
3. 把电池策略从"优化/受限"改成**无限制/不优化**（各品牌叫法不同）；
4. 观察几天，不再消失即生效。

两个补充：

- **三星机型**有独立的"深度休眠应用"名单，有用户反馈应用进了这个名单后壁纸会被停用，需要到电池设置里把它移出；
- 各品牌关闭路径差异很大，找不到入口时，直接搜"**你的机型 + 关闭应用电池优化**"，按具体机型操作。

有用户反馈顺手把**自启动**权限也打开后更稳定，可以一并设置。

## 三、省电模式时壁纸暂停是功能，不是坏了

应用内置了"省电模式时暂停壁纸"的开关：系统进入省电模式后壁纸主动停止渲染，退出省电模式就恢复。如果你发现"一开省电就黑/停"，去应用的设置里把这个联动关掉即可。主动要省电时反过来可以利用它，见[常见问题解答](常见问题解答.md)的耗电一节。

## 四、想换掉或取消壁纸

- **换壁纸**：直接在 Wallpaper Engine 里换一张应用，或者到系统**设置 → 壁纸**里选别的壁纸应用——Wallpaper Engine 对系统来说只是一种壁纸，换掉即可，没有"取消设置"这个独立操作；
- **彻底不用**：卸载 Wallpaper Engine，手机自动回到系统默认壁纸。

另外注意：安卓版**不支持壁纸声音**，所有壁纸在手机上自动静音、也没有开关可开，这是官方说明的行为，别当作故障去排查。
