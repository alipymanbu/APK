## 一、先弄清楚：这是哪个 Wallpaper Engine

你在手机商店或安装包里看到的 Wallpaper Engine，是它的 **Android 伴侣应用（companion app）**，和 Windows 上那个付费桌面软件不是同一个东西，分工也不同：

| | 手机版（本篇要装的） | Windows 版（电脑上的） |
| --- | --- | --- |
| 获取渠道 | Google Play 或官方 APK | Steam（付费买断） |
| 费用 | 免费 | 付费，价格以 Steam 页面为准 |
| 自带内容 | 少量内置动态壁纸可直接用 | 完整编辑器 + 创意工坊海量壁纸 |
| 主要用途 | 把电脑上的壁纸库搬到手机上当动态壁纸 | 在电脑上订阅、制作、管理壁纸 |

两件事建议提前知道，免得装完发现"怎么没有海量壁纸"：

- 手机版**不能直接连 Steam 创意工坊下载壁纸**（官方说明受技术与授权限制），海量壁纸要先在电脑版里订阅，再传到手机；
- 所以完整玩法 = **电脑版（Steam 付费）+ 手机版（免费）** 组合。如果你只是想试试，手机版自带的少量内置壁纸不连电脑也能用。

## 二、安装前的准备

- **系统要求**：Android 8.1 及以上（手机与平板均可，以官方页面为准）；
- **存储空间**：安装包本身 138.85M，装好后再留出传壁纸的空间，动态壁纸单张可能几十到上百 MB；
- **后续想连电脑**：手机和电脑最好先连上**同一个路由器**（配对靠局域网，详见[连接电脑配对教程](连接电脑配对教程.md)）。

网盘里这份安装包的信息如下，装完后可对照核对：

| --- | --- |
| 版本 | 2.8.8 |
| 包名 | io.wallpaperengine.weclient |
| 大小 | 138.85M |
| MD5 | 646258065ACD788DD7F2E583610AA553 |

> [!NOTE]
> 官方最新版本号会随更新变化，本文以网盘内这份 2.8.8 为准；新版本功能差异以 [官方 Android 页面](https://www.wallpaperengine.io/android/) 说明为准。

## 三、获取安装文件

两种装法任选：

1. **Google Play**：搜 Wallpaper Engine 直接安装（能自动更新，官方推荐）；
2. **APK 安装包**：从 [Wallpaper Engine 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a1394a670828) 转存后下载到手机安装。适合手机没装 Google Play、或想固定用某个版本的情况。官方建议只从官网或应用商店等可信渠道获取 APK。

## 四、安装步骤

以网盘 APK 为例，在其他渠道装的话第 2~3 步可跳过：

1. 把 APK 文件下载或转存到手机存储里；
2. 点开 APK 时系统会提示"不允许安装未知来源应用"，点**设置**，给你用的文件管理器或浏览器开**允许安装未知应用**，返回后继续；
3. 等待安装完成（包比较大，别中途清后台）；
4. 打开应用，首次进入会看到自带的内置壁纸列表，此时不连电脑也能选一张设为壁纸。

如果安装时报"解析包出现问题"，常见原因是下载不完整——重新下载后先对一下上表的 MD5 再装。

## 五、装完先做什么

想用创意工坊那类海量动态壁纸，下一步就是把手机和电脑连起来：在电脑版 Wallpaper Engine 里点**移动设备**按钮生成 4 位 PIN、手机上点**与计算机配对**，几步就完成，具体操作见[连接电脑配对教程](连接电脑配对教程.md)；连不上时也有备用导入方案，见[壁纸传输与导入方法](壁纸传输与导入方法.md)。
