# DroidCamX 卸载与清理虚拟摄像头

> 本篇讲不想再用时怎么把电脑端客户端、手机端应用和系统里残留的 DroidCam 虚拟摄像头设备清理干净。以后想重装，步骤在[下载与安装教程](下载与安装教程.md)。

## 一、先卸载电脑端程序

1. 按 `Win + R`，输入 `appwiz.cpl` 回车，打开「程序和功能」（或走 设置 > 应用 > 安装的应用，以你的 Windows 版本为准）。
2. 在列表里找到 **DroidCam Client**，点卸载。
3. 手机端的 DroidCamX 就是一个普通应用，在系统设置的应用列表里直接卸载即可。

## 二、删掉残留的虚拟摄像头设备

程序卸载后，「相机」设备列表里可能还留着 DroidCam Video 这个虚拟摄像头，会议软件里还能看到它。清掉的方法：

1. 右键开始按钮，打开**设备管理器**。
2. 菜单栏点 **查看 > 显示隐藏的设备**（不勾这个，已停用的虚拟摄像头可能不显示）。
3. 展开「照相机」或「图像设备」分类。
4. 右键 **DroidCam Video**，选「卸载设备」；弹窗里勾选「删除此设备的驱动程序软件」再确认。
5. **重启电脑**，让驱动残留彻底清掉。

另外建议顺手检查 任务管理器 > 启动 标签，把 DroidCam 相关的开机自启项关掉（如果还有残留的话）。

## 三、检查残留文件夹

默认安装位置在 `C:\Program Files (x86)\DroidCam`，卸载后如果文件夹还在，手动删除即可。个别情况下 `AppData` 里也可能有配置残留，按需清理，不删也不影响系统运行。

## 四、卸载后摄像头列表还显示旧设备

会议软件的摄像头列表是启动时枚举的，卸载后旧条目还在的话：

1. 先把会议软件完全退出再重开。
2. 列表还在，说明虚拟摄像头设备没删干净，回到第二节用设备管理器处理。
3. 重启电脑后再确认一次。

反过来，如果你只是设备列表乱了（比如想用笔记本自带摄像头却总跳到 DroidCam），也可以在 设置 > 隐私和安全性 > 相机 里检查应用级开关，不一定要走到卸载这一步。

## 五、哪类情况建议直接卸载重装

- 摄像头列表里有 DroidCam 但画面一直是绿的，File > Exit 重开和重启电脑都试过没用。
- 系统大版本更新（如 Windows 功能更新）之后虚拟摄像头彻底失效。
- 设备管理器里出现带感叹号的重复 DroidCam 条目。

这些情况下，与其反复排查，不如按第二节清干净再重装一遍，通常几分钟就能解决。
