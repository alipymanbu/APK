## 一、症状对照表

| 你看到的现象 | 最可能的原因 | 先做哪一步 |
| --- | --- | --- |
| Connect failed. Check IP and Port | 不在同一网络 / VPN / 防火墙 | 见第二节，逐项过 |
| 手机上 IP 显示 0.0.0.0 | 手机没连上 WiFi | 重新连 WiFi，别用流量 |
| 客户端搜不到设备（No Devices Found） | 自动发现失败 | 连点 3 次 Refresh 出手动添加，见第三节 |
| 选了摄像头但画面是纯绿色 | 虚拟摄像头没同步 | 客户端 File > Exit 重开，不行重启电脑 |
| USB 模式下识别不到手机 | 驱动 / USB 模式 | 手机换 PTP 或仅充电模式，见第四节 |
| 能连但过一会儿自己断 | 系统电池优化杀后台 | 见第五节 |

## 二、Connect failed：按这张清单逐项过

这是最常见的报错，官方 FAQ 给的排查顺序，命中率最高的在前：

1. **确认手机和电脑在同一网络**。电脑插网线也可以，但必须和手机连的是同一路由；有 2.4G 和 5G 两个 WiFi 时，把两台设备放到同一频段。
2. **重启路由器**：拔电，等 30 秒放完电再插回去，等它启动完成。
3. **有 VPN 先关**：先连 DroidCam 再开 VPN；或者干脆改用 USB 连接，USB 不走 VPN。
4. **防火墙拦截**：公司或校园网络常见，这种网络环境官方给的建议就是改走 USB 或手机开热点。
5. **Windows Defender 的「网络保护」**（公司管理电脑常见）：它可能拦掉 DroidCam 的连接。是否关闭由你自己权衡，官方给出的关闭命令是在管理员 PowerShell 里执行：

```powershell
Set-MpPreference -EnableNetworkProtection Disabled
```

另外官方 FAQ 里还提到两类少见情况：杀毒软件挡 USB 连接；开了 WiFi Calling 的机型在 WiFi 连接一段时间后掉线。

## 三、搜不到设备（No Devices Found）

自动发现依赖组播，很多路由器默认把它拦了。处理顺序：

1. 在客户端里**连续点 3 次 Refresh Device List**，会出现手动添加设备的入口。
2. 手动添加时填手机上显示的 WiFi IP（手机端应用首页就有）。
3. 电脑有多个网卡（比如同时有网线和无线）时，去客户端设置 Advanced 里的 **Bind IP** 选项，选对应 WiFi 网卡的那一个，重启客户端。
4. 加上设备后画面仍然不出来，回到第二节把网络项过一遍。

## 四、USB 识别不到手机

1. 手机下拉通知栏，把 USB 用途从「传输文件（MTP）」改成 **PTP（传输照片）** 或「仅充电」，回客户端重新刷新。
2. 手机上应该弹出「允许 USB 调试」——没弹说明调试授权还没建立，重插一次数据线。
3. Windows 装的驱动可能不对或过旧，手动装对应品牌驱动：
   - Google Pixel / Nexus / OnePlus：[Google USB 驱动](https://developer.android.com/studio/run/win-usb)
   - 三星：[Samsung USB 驱动](https://developer.samsung.com/mobile/android-usb-driver.html)
   - 其他品牌：[Android 开发者厂商驱动索引页](http://developer.android.com/tools/extras/oem-usb.html)
4. 换端口号再试：手机端和客户端两边都改，用 4848、5050、5151 这类。
5. 以上都无效，官方还提供一个备用 USB 设置工具（`usb_setup_windows.zip`，地址以 [dev47apps.com/droidcam/connect](https://www.dev47apps.com/droidcam/connect/) 页面为准），它会为所有已连接设备自动建端口转发，用工具里的 adb 文件夹替换客户端安装目录下 `Program Files (x86) > DroidCam` 里的同名文件夹。

## 五、连上了但过一会儿自己断

安卓各厂商对后台应用的限制越来越严，应用拿不到「唤醒锁」就会被系统掐掉，传输中断是这个原因的典型表现：

1. **插上电源**再连，多数系统对充电状态下的应用限制会放宽。
2. 在系统设置里找到电池优化，把 DroidCamX 设为不优化/不受限制（入口各家叫法不同，一般在应用信息 > 电池里）。
3. 你的机型没有对应设置时，去 [dontkillmyapp.com](https://dontkillmyapp.com/) 按品牌查，这个站点按厂商整理了各家「杀后台」的关闭办法。
4. 三星机型要单独点名：官方 FAQ 明确提过三星从 Android 11 起限制了应用的唤醒锁，典型表现就是屏幕一熄传输就断——处理方式同上（插电或关电池优化），三星专页见 [dontkillmyapp.com/samsung](https://dontkillmyapp.com/samsung)。

WiFi 使用中偶发掉线还可以顺手排除一下路由器过热和信道拥堵，这类问题换个时间段或换个信道就能验证。
