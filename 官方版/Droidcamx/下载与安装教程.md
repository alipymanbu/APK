## 一、先弄清它是什么、需要装几样

DroidCamX 是 Dev47Apps 出品的 DroidCam 系列里的安卓专业版应用，作用是把你的安卓手机变成电脑的摄像头：手机负责拍画面，电脑端把这份画面当成一个普通摄像头设备，供视频会议、直播软件调用。

关键点：**手机端单独装了没法用**，它必须和电脑端配合。所以完整的安装是两步：

| 设备 | 要装的东西 | 作用 |
| --- | --- | --- |
| 安卓手机 | DroidCamX 应用 | 提供画面，显示连接用的 IP 和端口 |
| 电脑（Windows 或 Linux） | DroidCam Client 客户端 | 接收画面，虚拟出一个摄像头设备 |

电脑端客户端不区分免费版和专业版，装官方最新版即可；手机端装 DroidCamX 之后，画面传输上限和可调参数都比免费版 DroidCam 多（比如 1080p 高清模式）。

算出的值与上表一致，说明包没被改动过。文件名以网盘内实际显示为准。

## 三、手机端安装步骤

1. 从 **DroidCamX 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/7548e738eed4](https://pan.quark.cn/s/7548e738eed4) 转存后把 APK 传到手机上安装。
2. 手机上直接点开 APK 安装时，系统一般会提示「禁止安装未知来源应用」，按提示允许你用的浏览器或文件管理器安装即可（不同品牌入口不同，一般在设置里搜「未知来源」或「安装未知应用」）。
3. 装完先别急着点开，电脑端还没装的话先看下一节。对安卓版本的要求不高，旧款机型大多能装，具体以官方应用页面标注为准。

## 四、电脑端客户端安装（Windows）

1. 打开官方 Windows 客户端页面 [droidcam.app/windows](https://www.droidcam.app/windows/)，下载 `DroidCam.Client.Setup.exe`（撰写本文时是 v7.2、约 98MB，支持 Windows 10 / 11，x64 与 arm64 都有，具体以官网当时显示为准）。
2. 双击安装，默认装进 `Program Files (x86)`，一路下一步即可。
3. 装完从开始菜单或桌面启动 DroidCam Client。启动后在界面中间点一下、或右键选 Add > DroidCam，就能进入添加设备的界面。

Linux 用户走官方 Linux 页面 [droidcam.app/linux](https://www.droidcam.app/linux/)，按页面给出的命令安装，以页面为准。

## 五、装完先做一次连通测试

两端都装好后，最直接的验证方式：

1. 手机连上 WiFi，打开 DroidCamX，屏幕上会显示 WiFi IP 和端口（默认 4747）。
2. 电脑客户端连接方式选 WiFi/LAN，输入手机上显示的 IP 和端口，点 Start。
3. 电脑客户端里出现手机画面，就说明两端都正常了。

详细的连接步骤（含 USB 数据线连接、浏览器网页看画面）在[手机连接电脑方法](手机连接电脑方法.md)一篇里；如果这一步报 Connect failed 或者搜不到设备，直接翻[连接失败问题排查](连接失败问题排查.md)。连上了但画面卡，看[画面卡顿与画质优化](画面卡顿与画质优化.md)。
