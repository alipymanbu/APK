# DroidCamX 手机连接电脑方法

> 本篇讲手机端 DroidCamX 和电脑端客户端的三种连接方式：WiFi 无线、USB 数据线、浏览器网页。前提是两端都已安装，没装的先看[下载与安装教程](下载与安装教程.md)。

## 一、三种方式怎么选

| 方式 | 前提 | 适合 |
| --- | --- | --- |
| WiFi/LAN | 手机和电脑在同一个局域网 | 日常用，不用插线，随放随用 |
| USB | 数据线 + 手机开 USB 调试 | 画面要求稳、WiFi 拥挤或连不上的场合 |
| 浏览器网页 | 手机和电脑同网，无需电脑客户端 | 只想快速看一眼画面、调机位 |

同一个手机端应用三种都支持，端口都是同一个（默认 4747）。

## 二、WiFi 无线连接（最常用）

1. 手机打开 WiFi，连到你家/办公室的正常网络。
2. 打开 DroidCamX，屏幕上会显示 **WiFi IP** 和 **Port**（默认 4747）。如果 IP 显示的是 `0.0.0.0`，说明手机根本没连上 WiFi，不是应用的问题。
3. 打开电脑端 DroidCam Client，连接方式选 **WiFi/LAN**，把手机上显示的 IP 和端口填进去，点 Start。
4. 手机画面出现在电脑客户端里，连接完成。之后在 Zoom、Discord 这类软件里就能选到 DroidCam 的虚拟摄像头（详见[视频会议与OBS怎么用](视频会议与OBS怎么用.md)）。

连不上的情况很常见，多数是「不在同一个网」造成的：电脑插了网线也行，但路由器要同一台；有 2.4G 和 5G 两个频段时，尽量让手机和电脑在同一频段。公司或校园这类受限网络连不通时，官方给的绕行办法是让手机开个人热点、电脑连上热点再走 WiFi（热点是一张独立的小网络，天然绕开限制）。逐项排查见[连接失败问题排查](连接失败问题排查.md)。

## 三、USB 数据线连接（更稳）

USB 方式需要两个前提：手机开启 **USB 调试**，电脑上装好手机的驱动。

1. 解锁开发者选项：设置里搜「版本号」（通常在关于手机里），连续点击 7 次；回到设置搜「USB 调试」，打开。
2. 数据线把手机接到电脑。Windows 通常会自动装驱动。
3. 电脑客户端里选 USB 连接方式，点刷新按钮。识别到手机时，手机上会弹出「允许 USB 调试」的对话框，点确定。
4. 点 Start 建立连接，之后的用法和 WiFi 一样。

识别不到手机的补救顺序：

1. 手机下拉通知栏，把 USB 的用途从「传输文件」改成 **PTP（传输照片）** 或「仅充电」，再回客户端刷新。
2. 还不行就是驱动没装对，手动装：Google Pixel/Nexus/OnePlus 用 [Google USB 驱动](https://developer.android.com/studio/run/win-usb)，三星用 [Samsung USB 驱动](https://developer.samsung.com/mobile/android-usb-driver.html)，其他品牌从 [Android 开发者的厂商驱动索引页](http://developer.android.com/tools/extras/oem-usb.html)找对应厂家。
3. 顽固情况下换个端口号再试（4848、5050、5151……），手机端和客户端两边改成一样的。

连接过程中报 connection reset / connect lost 这类错误，先确认手机端应用开着，再按上面第 1 条换 USB 模式，其余处理见[连接失败问题排查](连接失败问题排查.md)。

## 四、浏览器网页看画面（不装客户端也行）

手机端开起来之后，在电脑浏览器地址栏直接输入：

```text
http://手机IP:4747/video
```

想指定清晰度，在后面带上尺寸，合法尺寸是 640x480、1280x720、1920x1080：

```text
http://手机IP:4747/video/1280x720
```

这条路走的是网页直播流，适合确认角度和取景；要当成摄像头给会议软件用，还是得走第二节或第三节的连接。

## 五、改端口

默认端口 4747 被占用或连不上时可以换：手机端在设置里改 DroidCam Port，合法范围 1024–65536；电脑端在设备源属性里改——先点 Deactivate 停掉源，改端口，再 Activate。两边必须一致。

## 六、前后摄像头切换

连接**之前**在手机端应用里点 Camera Swap 按钮切换前后摄像头。双摄以上的机型，多出来的镜头不一定全部出现在可选项里，取决于具体机型和系统版本。
