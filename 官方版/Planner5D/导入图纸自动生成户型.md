# Planner 5D 导入图纸自动生成 3D 户型

> 手里有现成户型图（扫描件、照片、CAD 图）时，可以交给 AI 识别直接生成可编辑的 3D 户型，不用逐面墙画。这是付费功能（Premium 起），本篇讲格式要求、上传步骤和等待时间。

## 一、支持哪些格式

| 类别 | 格式 |
| --- | --- |
| 常见图像与文档 | `.jpg` / `.jpeg`、`.png`、`.pdf`、`.bmp`、`.tif` / `.tiff`、`.jp2` |
| CAD 与技术图 | `.dwg`、`.dxf`、`.pxm` |
| 其他位图 | `.pbm`、`.pgm`、`.ppm`、`.pnm`、`.ras`、`.sun`、`.sr`、`.cmu`、`.dib` |

以上格式各平台通用。手机上最常用的就是相册里的 JPG/PNG 和文件里的 PDF。

## 二、什么样的图纸识别成功率高

识别引擎要的是一张干净的「俯视图」：

| 这样给 | 别这样给 |
| --- | --- |
| 高分辨率的平面扫描件或电子图 | 透视角度拍的图纸照片（斜拍、侧拍） |
| 墙线深、背景浅，对比清晰 | 模糊、阴影重、光线差的照片 |
| 一张图只放一层 | 一张图塞进多层或多个标高 |
| 规整的电子图或印刷图 | 手绘草图、装饰性过强的艺术图 |

## 三、安卓手机上的操作步骤

1. 打开 Planner 5D，点「新建项目」（Create Project / New Project）。
2. 选「上传平面图 / Upload a floor plan」。
3. 从相册或文件里选中图纸文件。
4. 启动识别，等通知——识别在云端跑，期间可以退出界面干别的。
5. 收到完成通知后打开项目，对照原图微调。

手机端按单张图纸处理；一次要导入多页 PDF、逐页分配楼层（比如两层别墅的整套装图纸），目前是网页版的功能：在 My spaces → Dashboard → Import a Plan 里上传后选页、给每页指定楼层再启动识别。

## 四、要等多久

官方口径是 10 分钟到 24 小时，取决于图纸复杂度。超过 24 小时还没出结果，从应用内联系官方支持问进度（联系方式见 [账号同步与常见问题.md](账号同步与常见问题.md)）。

## 五、识别结果别直接用

AI 生成的是「接近」的户型：墙位、开门位置、尺寸都可能偏。打开项目后先做三件事：

1. 抽查几处关键尺寸（开间、进深、层高），和原图对；
2. 核对门窗的位置和开向；
3. 有偏差就回 2D 手动调，调法见 [户型设计入门.md](户型设计入门.md)。

调完再出效果图：见 [渲染出图与分享.md](渲染出图与分享.md)。
