## 一、先定位你属于哪一类

| 现象 | 跳到 |
| --- | --- |
| 手机 App 列表里根本没有你的电脑 | 第二节 |
| 列表里能看到电脑，点连接却失败/一直转 | 第三节 |
| Wi-Fi 正常，USB 方式连不上或授权弹窗不弹 | 第四节 |
| 能连上但画面黑的、花的 | 不是连接问题，看 [画面黑屏卡顿怎么解决.md](画面黑屏卡顿怎么解决.md) |

## 二、手机找不到电脑

按顺序过，走到哪一步通了就停：

1. **Windows 防火墙放行**：控制面板 → Windows Defender 防火墙 → 「允许应用通过防火墙」，找到 iVCam，「专用/公用」都打勾。安装时通常会自动加进去，但经常加失败，这一步要手动确认。iVCam 用的是 TCP/UDP 5898 端口。
2. **第三方安全软件**：火绒、360 这类如果拦了网络访问，把 `iVCam.exe` 加白；搞不清就先退出它们试一次。
3. **VPN / 代理**：电脑上开着的话先关掉，它们会把局域网发现搅乱。
4. **手机确实在用 Wi-Fi**：蜂窝数据状态下永远找不到电脑；同时确认 App 有 Wi-Fi/本地网络权限（iOS 在「设置 → iVCam」里）。
5. **同一个路由器**：手机别连别的网（比如邻居的、访客网）；电脑插网线与手机连 Wi-Fi 只要在同一局域网就算同网。
6. **别接信号放大器的访客网络**：路由器的「AP 隔离」「访客模式」开着会让设备互相看不见，去路由器后台关掉。
7. **频段一致**：手机和电脑都走 Wi-Fi 时，尽量连同一个频段（都 2.4G 或都 5G）。
8. **Bonjour 服务在跑**：`services.msc` 里找 `Bonjour Service`，状态要是「正在运行」，被禁用了就改成自动并启动。它没起来时 iVCam 会退化到 UDP 广播发现，所以路由器的 UDP 广播也得允许。
9. **终极绕过**：上面全试过还不行，直接[手动输入电脑 IP](手机连接电脑教程.md#三手动输入-ip自动发现失灵时)，或改用 USB。

## 三、能看到电脑但连不上

1. 还是先查防火墙（第二节第 1 条）——「能发现」只说明广播通了，「连得上」要求 5898 端口真的放行。
2. **不同网段**：手机 IP `192.168.0.x`、电脑 `192.168.1.x` 这种就是被路由器分到了两个网段，前三段必须一致。这种情况下手动输 IP 也没用，要么去路由器后台把两台设备划到同一网段，要么直接走 USB。
3. 在电脑上 `ping` 一下手机 IP，能通说明链路没问题，问题在软件层；ping 不通就回到路由器设置。
4. 临时验证时可以关掉防火墙——**确认是它拦的之后要把放行规则加上再开回来**，别长期裸奔。
5. 还不行就换 USB 线直连，先让链路成立再回头查网络。

## 四、USB 连不上 / 授权弹窗不弹

**安卓侧：**

- USB 调试没开、USB 用途选成了「充电」——重选「传输文件（MTP）」。
- **数据线只能充电不传数据**：插上手机有反应但设备管理器里什么都不出现，换一根确认支持数据传输的线再说。
- 手机里撤销 USB 调试授权（开发者选项 → 撤销 USB 调试授权），拔线重插；弹窗出来记得勾「始终允许来自此计算机」。
- 弹窗一直不出现：重插数据线 → 重启手机 → 关闭再打开 USB 调试 → 关闭再打开开发者模式，按这个顺序来。
- 电脑缺手机驱动：装各品牌手机助手或 OEM 驱动，设备管理器里能认出手机再说。

**iPhone 侧：**

- 装**桌面版 iTunes**（商店版不算），确认「Apple Mobile Device USB Driver」在设备管理器里正常。
- 被 `libusb-win32 devices` 一类驱动占用时，按官网说明卸载该驱动后重连。
- Apple Mobile Device Service（苹果移动设备服务）没启动的话，启动它。

线材与接口也占一半嫌疑：换原装或 MFi 认证线、插主板后置 USB 口、拔掉集线器上的其他设备。

## 五、还连不上时

把这些变量都归零再试一次：重启路由器、重启电脑客户端、关掉 VPN 和安全软件的网络拦截。多数卡死的现场是 Bonjour 服务被禁用 + 防火墙没放行这两条叠加。排查完能连上了，去看 [在Zoom和OBS里怎么用.md](在Zoom和OBS里怎么用.md) 把摄像头用起来。
