## 一、iVCam 是什么

iVCam 是 e2eSoft 出的一款「把手机摄像头变成电脑摄像头」的工具。你要装两部分：手机上的 App 负责拍、电脑上的客户端负责收，装好后电脑的所有视频软件（Zoom、OBS、钉钉这类）都会多出一个名为 `e2eSoft iVCam` 的摄像头，选中它就能用手机的画面开会、直播。

适合你的情况：笔记本自带摄像头画质太差、台式机压根没摄像头，或者你想把手机当高位机位、当桌面俯拍设备用。整套东西免费能用，画面带水印，购买许可可去掉。

## 二、系统要求

装之前先对一下，两边缺一不可：

| 端 | 要求 |
| --- | --- |
| 电脑端 | Windows 7 SP1 / 8 / 10 / 11，32 位与 64 位都支持；**没有 Mac 桌面客户端** |
| 手机端 | Android 或 iOS；本次网盘里的安卓包要求 **Android 5.2 以上** |
| 网络 | Wi-Fi 连接时手机与电脑在同一个路由器下；或者用 USB 线直连 |

另外两条按需了解：背景替换（虚拟背景）功能需要 Windows 10 及以上、且显卡支持 DirectX 12；1080p 及以上分辨率想跑得顺，显卡支持硬件解码会好很多（官方给出的参考下限是 NVIDIA GTX 750 Ti / AMD Radeon R9 285 一类）。

## 三、安装电脑端客户端

1. 到官网下载页 `https://www.e2esoft.com/ivcam/` 下载 Windows 客户端，64 位系统选 x64、老机器选 x86（页面上的版本号会随更新变化，以当时显示为准）。
2. 运行安装包，一路下一步。安装过程中 Windows 可能弹「是否信任 e2eSoft 的驱动程序」——这是虚拟摄像头驱动，点安装/允许，**不装它电脑端就认不到摄像头**。
3. 客户端还会顺带装一个 Bonjour 服务，用来让手机自动发现电脑。装完可以在「服务」（`services.msc`）里确认 `Bonjour Service` 处于「正在运行」，后面连不上时这一项会用到。
4. 杀毒软件如果弹拦截，给安装程序和 `iVCam.exe` 加信任；否则摄像头画面可能出不来（排查见 [连不上电脑怎么排查.md](连不上电脑怎么排查.md)）。

装好后先打开电脑客户端，它会停在等待连接的界面——这一步做完，电脑侧就绪。

## 四、安装手机端 App

手机端有两条获取途径，任选其一：

- **Google Play / App Store**：搜 `iVCam` 安装，版本以商店当时显示为准；
- **安卓 APK 直装**：从 [iVCam 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5a660170e8ca) 转存安装包到手机后安装。

网盘里这一份包的实际信息（与官方商店的最新版可能不是同一版，以它为准）：

| 项 | 值 |
| --- | --- |
| 版本 | 7.2.1 |
| 包名 | `com.e2esoft.ivcam` |
| 大小 | 6.13M |
| MD5 | `10FDFDA519F1A80CD7860B631BA3F536` |
| 记录时间 | 2026-09-23 |
| 系统要求 | Android 5.2 以上 |

安装来源不明的 APK 时，先核对一下 MD5 与上表一致再装。首次打开会连续弹权限申请：**摄像头、麦克风、Wi-Fi（本地网络）三个都允许**，少一个都会导致后面连不上或没声音。

## 五、装完后的第一件事

两端都装好后，先按 [手机连接电脑教程.md](手机连接电脑教程.md) 把手机和电脑连起来；如果列表里找不到电脑，直接跳到 [连不上电脑怎么排查.md](连不上电脑怎么排查.md) 逐项过一遍。
