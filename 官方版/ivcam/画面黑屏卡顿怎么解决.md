# 画面黑屏卡顿怎么解决

> 连上了但黑屏、卡顿、闪烁、画质差：先判断是传输问题还是解码问题，再按对应方向调。

## 一、先分清是「传坏了」还是「解不出」

画面卡顿只有两种根因：**传输跟不上**（网络/USB 带宽不够，丢帧）或**解码跟不上**（CPU/GPU 撑不住）。iVCam 客户端里有个现成的判别法：

1. 在 iVCam 里点录制，录十几秒你正看着卡的画面。
2. 拿播放器放这段文件：**播放也卡** → 传输问题；**播放流畅** → 解码问题。

方向找对了再动手，否则调半天参数都是在猜。

## 二、黑屏但连接显示正常

1. 换个软件看画面：用别的摄像头查看工具确认 `e2eSoft iVCam` 这个设备本身有没有输出。别的软件里有画面，说明只是 iVCam 客户端窗口的显示问题，功能没坏。
2. 客户端 `Settings → Miscs`（或右键菜单）里把 **Hardware Decoding** 开关切一下——开着不行就关，关着不行就开。
3. 同一页换一个 **Hardware Decoder**，再不行换 **Options → Miscs** 里的 **Video Renderer**。
4. 安全软件的「摄像头保护」会把画面整个挡掉：火绒、360 里关掉该功能，或给 `iVCam.exe` 放行摄像头访问。

## 三、卡顿、拖影、花屏

**判定为传输问题时（录制文件也卡）：**

- Wi-Fi 场景：手机靠近路由器；**电脑强烈建议插网线**，电脑也走 Wi-Fi 时先重启电脑再试。
- 路由器本身性能不够是高发原因（卡顿有固定节奏时尤其像它），重启路由器；长期用建议换个性能好点的。
- 把 App 设置里的**视频质量**降到中或低，**分辨率与帧率**降一档——会议场景 `1280×720 / 30fps` 通常就够，不必追 4K 60fps。
- 手机支持就选 **HEVC 编码**，压缩效率更高、占的带宽更小。
- 实在不行换 USB 有线（见 [手机连接电脑教程.md](手机连接电脑教程.md) 第四节）。

**判定为解码问题时（录制文件流畅）：**

- 客户端开启 **Hardware Decoding**，或换一个 Hardware Decoder（需要显卡支持）。
- 任务管理器里看 iVCam 的 CPU/GPU 占用：很高就降分辨率与帧率，别让 4K 60fps 硬顶。
- 多显卡机器可在 `Settings → Miscs → Preferred GPU` 指定用哪张卡解码。
- 关掉同时在吃 GPU 的程序（推流软件、游戏），显卡驱动更新到新版。

## 四、画面闪烁

闪烁多半是摄像头快门速度和室内照明的交流电频率打架。处理办法：

- 帧率调到低于市电频率：**50Hz 供电的地区用 25fps**（国内是 50Hz）。
- 长按画面锁定 AE/AF，再上下滑动调曝光时间（快门速度）；电脑端的 Camera Settings 窗口里也能调。
- 有些情况是**美颜**引起的，关掉美颜再看。

## 五、画面抖动

- 自动对焦来回「拉风箱」：对着主体长按锁定 AE/AF，让它别再反复对焦。
- 手持不稳或桌面震动：上支架/云台；手机放在震动面上时，OIS 会把高频震动放大成波纹。
- 快速横摇时的顿挫：帧率调到 60fps 会顺滑很多。

## 六、画质看着不如手机上

先确认你的电脑显示器本身是不是 4K——手机屏幕 DPI 高，同一画面在小屏上显得更锐。判断真实传输质量只看一个标准：**iVCam 自己录制下来的文件**，不要看窗口显示效果。另外下游软件也有自己的上限：推流软件不支持 4K，你把摄像头设成 4K 它也会降级输出。

设置里把视频尺寸、质量、帧率往上调可以换更清晰的画面，代价是吃更多网络与 GPU 资源——按你机器和网络的实际情况取平衡。调完参数怎么用到会议和直播里，见 [在Zoom和OBS里怎么用.md](在Zoom和OBS里怎么用.md)。
