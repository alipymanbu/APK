# 在Zoom和OBS里怎么用

## 一、前提：摄像头设备已就位

手机连上电脑客户端后，系统里就多了一个名为 `e2eSoft iVCam` 的虚拟摄像头。**任何认摄像头的软件都能直接选它**，不需要装各家的插件。若列表里还没有它，回 [下载与安装教程.md](下载与安装教程.md) 确认虚拟摄像头驱动装上了。

## 二、在会议软件里选中它

各软件入口大同小异，都是在设置里把「摄像头」换成 `e2eSoft iVCam`：

| 软件 | 操作路径 |
| --- | --- |
| Zoom | 设置 → 视频 → 摄像头 → 选 `e2eSoft iVCam` |
| Microsoft Teams | 设置 → 设备 → 摄像头 → 选 `e2eSoft iVCam` |
| Google Meet | 设置 → 视频 → 摄像头 → 选 `e2eSoft iVCam` |
| 钉钉 / 腾讯会议 / 飞书 | 视频会议设置里的「摄像头」下拉框里选它 |
| Skype、Discord 等 | 同样在音视频设置的摄像头列表里选 |

开会前先做一次自检：打开目标软件的视频预览，能看到手机画面才算接通；黑的先看 [画面黑屏卡顿怎么解决.md](画面黑屏卡顿怎么解决.md)。

注意一点：如果你用的是免费版，画面左上角的 `iVCam` 水印会跟着视频流进到每一个软件里（Zoom 预览、OBS 录像都一样），想去掉只能购买许可，细节见 [免费版和付费版有什么区别.md](免费版和付费版有什么区别.md)。

## 三、把手机当麦克风用

iVCam 在电脑上还会注册一个同名音频设备。想用手机麦克风收音（手机麦通常比笔记本内置麦好），在软件的「麦克风」选项里也选 `e2eSoft iVCam`——视频和音频可以分别选，不必绑死。手机记得别静音、别被别的 App 占用麦克风。

## 四、在 OBS / 推流软件里添加

1. OBS 里点「来源」的 `+` → **视频捕获设备**。
2. 设备选 `e2eSoft iVCam`，确定。
3. 分辨率/帧率选「自定义」，按 [画面黑屏卡顿怎么解决.md](画面黑屏卡顿怎么解决.md) 里定好的档位填（比如 `1280×720`、`30 fps`）。

推流时 OBS 和 iVCam 抢同一张显卡，同推高分辨率容易互相拖垮：一边把 iVCam 降档，或按上面那篇的「Preferred GPU」把解码分给另一张卡。

## 五、几个值得开的选项

- **背景替换**：客户端里可选模糊、散景、马赛克、绿幕等效果，不用真绿幕。需要 Windows 10+ 且显卡支持 DirectX 12；开启后 GPU 占用上升，卡了就降档。
- **前置/后置切换与变焦**：画面里直接切广角/长焦、放大缩小，开会中途换机位不用动电脑。
- **拍照与录制**：电脑客户端窗口上就有拍照、录像按钮，录下来的文件直接存电脑——手机空间不够时，等于把录制负担转到电脑上。
- **多机位**：一台电脑可以同时接多部手机（多开客户端实例），直播时当多个角度用。

## 六、用之前没连上的话

这些功能全部以「手机画面已进到电脑」为前提。列表里没设备、连上就断，按 [连不上电脑怎么排查.md](连不上电脑怎么排查.md) 处理；还没装两端程序，先看 [下载与安装教程.md](下载与安装教程.md)。
