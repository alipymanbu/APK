## 一、连接前的两个前提

不管用哪种方式，先把这两条满足了，否则后面积累的排查功夫全是白费：

1. **先开电脑客户端，再开手机 App**。电脑端不开，手机扫不到东西。
2. 手机首次打开时弹的权限（摄像头、麦克风、Wi-Fi/本地网络）全部允许。iOS 在「设置 → iVCam」里能看到「本地网络」开关，安卓在应用权限里确认 Wi-Fi 没被禁。

## 二、Wi-Fi 连接（默认方式）

最省事的一条路，日常用这个：

1. 手机和电脑连**同一个路由器**的 Wi-Fi（电脑插网线也可以，只要在同一个局域网）。
2. 打开电脑端 iVCam，停在等待界面。
3. 打开手机 App，几秒内它会自动列出可用的电脑，点一下就连上了，画面立刻出现在电脑窗口里。

连不上的情况不用硬试，直接按 [连不上电脑怎么排查.md](连不上电脑怎么排查.md) 走一遍——最常见的是 Windows 防火墙没放行（端口 TCP/UDP 5898）和服务没起来。

## 三、手动输入 IP（自动发现失灵时）

自动列表里没有电脑，不代表网络不通，可能是发现机制被挡了。手动指过去照样能连：

1. 查电脑 IP：电脑上 `Win+R` 输入 `cmd` 回车，运行 `ipconfig`，记下「IPv4 地址」（形如 `192.168.1.10`）。
2. 手机 App 里点连接区域的 `+`（或长按），输入这个 IP，确认连接。
3. 反过来也行：手机的 IP 显示在 App 设置界面底部，在电脑客户端里输入它，让电脑主动连手机。

要求手机与电脑 IP 的**前三段一致**（都是 `192.168.1.x` 这种）。一段是 `192.168.0.x`、另一段是 `192.168.1.x` 就属于不同网段，互相看不见，这类问题在排查篇里单独讲。

## 四、USB 有线连接（最稳）

画面要长时间稳定（长时间会议、推流）时用线，延迟也更低。

**安卓手机：**

1. 手机设置里连点 7 次「版本号」打开开发者选项，然后在「开发者选项」里打开 **USB 调试**。
2. 用数据线连电脑，USB 用途选 **传输文件（MTP）** 或 **传输照片（PTP）**，不要只选「充电」。
3. 第一次连，手机会弹「是否允许 USB 调试」，勾选**始终允许来自此计算机**后点允许。这个弹窗不点，iVCam 就走不了 USB。
4. 打开电脑客户端，识别到后自动切到 USB 传输，不用手动切模式。

**iPhone：**

1. 电脑上装**桌面版 iTunes**（Microsoft 商店版不行），确认手机能在 iTunes 里看到。
2. 连线后打开 iVCam，正常会自动走 USB。
3. 设备管理器里要能看到「Apple Mobile Device USB Driver」；如果被别的 libusb 类驱动占了，按官网说明卸载那个驱动再重连。

USB 老掉线时的常用动作：换根线、换主板后面的 USB 口、拔掉同口的其他设备。另外三点也常踩：

- **线要支持数据传输**——很多线只能充电，插上手机有反应、电脑却认不出，基本就是线的问题。
- iPhone 15 Pro 及之后的机型支持 **USB 3.0**，用 USB 3.0 口和线带宽更足；USB 2.0 的带宽跑到 `1080p/60fps` 会吃紧，掉线就把分辨率降到 `720p/30fps` 试试。
- 安卓在开发者选项里打开 **Stay awake（充电时屏幕不休眠）**，避免手机一黑屏就被系统断流。

## 五、没有路由器时的兜底

两边没有共同的 Wi-Fi（比如酒店、办公室隔离网络），可以拿手机开**个人热点**：手机开热点 → 电脑连这个热点 → 再按第二节的 Wi-Fi 流程连。这相当于自己造了一个两台设备共处的局域网。

## 六、连上之后

画面出现在电脑窗口里，就可以去 [在Zoom和OBS里怎么用.md](在Zoom和OBS里怎么用.md) 把它选成摄像头了。想让画质更好、更稳，参数调整看 [画面黑屏卡顿怎么解决.md](画面黑屏卡顿怎么解决.md)。
