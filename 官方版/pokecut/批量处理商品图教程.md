网店上新一次要处理几十张图：逐张抠图、逐张换白底、逐张改成平台要求的尺寸，重复劳动量很大。Pokecut 的批处理把这几步合并成一次操作。

## 批处理能一次做什么

| 批量动作 | 用途 |
| --- | --- |
| 批量去背景 | 整组商品图一次抠掉背景 |
| 批量换背景 | 统一套用白底、纯色或同一张场景背景 |
| 批量调尺寸 | 按预设尺寸出图，适配不同平台的规格 |
| 批量导出 | 格式支持 png 和 jpg，可控制导出大小 |

官方网页端的批量编辑一次最多处理 50 张；应用商店的官方功能列表里，App 端把这项能力叫「批量白底图」（批量出商品主图，配合每日上新）。App 内批量功能的入口位置随版本调整，找不到时先更新到较新版本再看。

## 操作思路

批量处理的价值在于「同一组设置打一批图」，所以先把单张的流程跑通，再批量套用：

1. 先用一张图确认抠图效果、背景选择、目标尺寸都对，单张操作见[智能抠图与换背景怎么做.md](智能抠图与换背景怎么做.md)；
2. 在批量入口选中整组商品图；
3. 一次性套用去背景 + 目标背景 + 目标尺寸；
4. 预览整组结果，个别边缘有问题的图再单独修；
5. 统一导出 png 或 jpg。

## 各平台的尺寸要求会变

不同电商平台对主图尺寸、白底、留白的规定不一样，而且会调整。做图前先去平台当时的规定页面核对一遍，再用应用里的预设尺寸或自定义尺寸出图，避免整批返工。

## 阴影与倒影

商品图质感不只靠换背景：主体贴上去之后，给商品加阴影或倒影，是「贴纸感」和「实拍感」的主要差别。做白底主图时尤其明显。这一步可以只用一张测试图调到满意，再整批套用同样的参数。
