## 一、这篇讲什么

安卓版在 2026 年 5 月 8 日起推送 4.0（从 2.22 直接跳到 4.0，与 iOS 用同一套版本号），是一次界面与功能都有改动的大版本。你手上这一份是 `4.0.3.919885048`。**截至 2026 年 9 月**，官方商店的更新说明里又出现过 4.1（扩大 RAW 格式支持）——具体推到你设备没有、以及各项功能的完整清单，以 Google Play 页面当时显示为准。本篇只写公开报道能互相印证的改动，找不到入口的先看[新手使用指南.md](新手使用指南.md)。

## 二、界面改动（先找到东西在哪）

| 位置 | 4.0 之后的样子 |
| --- | --- |
| 主页 | 已修照片按网格排列，相当于图形化的历史记录；底部有「添加照片」按钮 |
| 编辑器底部 | 仍是 Looks / Tools / Export 三块 |
| Tools 内部 | 按「精修 / 修复 / 风格 / 全部」分组，**找不到工具时去「全部」里翻** |
| 右上角 | 深色/浅色主题切换，旁边可开直方图 |
| 工具收藏 | 常用工具可钉到顶栏，**数量不再限于原来那 4 个** |

## 三、内置相机（Snapseed Camera）

主页上的**浮动按钮**进相机，这是 4.0 最显眼的新增：

1. 点浮动按钮进拍摄界面。
2. 开 **Pro 模式**可手动调 ISO、快门速度、对焦。
3. 选胶片效果：官方公布的是**11 种胶片预设**，覆盖柯达、富士、宝丽来、依尔福、爱克发、特艺色等常见片型（如 Kodak Portra、Fujifilm Superia、Polaroid SX-70、Ilford HP5）。
4. 取景器另有 **6 种配色主题**可切（编辑器、黄昏、负片、钢青、雾霭、深度这类命名，以界面实际显示为准）。
5. 拍完照样能编辑：效果不是「拍死」的，回编辑器能改、能撤。

对你的意义是：喜欢某个色调时，可以拍的时候就带上，省掉后期那一步；要更大发掘空间就仍拍 RAW/JPG 再进编辑器。

## 四、批量编辑

同一次拍摄的一组照片要统一调子时用它：

1. 修好一张、调出你要的效果。
2. 进批量入口，把这套调整（或存好的自定义 Looks）应用到选中的多张照片。
3. 逐张仍可单独微调——批量只负责「套同一套起点」。

一组照片单独修十遍，和批量套完再修两遍，出来的观感一致性完全不同；这也是 4.0 相对老版本最实用的一处。

## 五、一键智能蒙版

在局部类工具里选中**主体**或**背景**，选区自动算好，后续调整只作用在选中的那部分，省掉手刷。主体和背景反差大时很准，反差接近时会选错——那时退回控制点或画笔，见[局部调整与蒙版怎么用.md](局部调整与蒙版怎么用.md)。

## 六、新增的几个工具

| 工具 | 干什么 | 什么时候用 |
| --- | --- | --- |
| **Color HSL** | 按颜色分别调色相、饱和度、明度 | 只想让天空更蓝、肤色不跟着变 |
| **去雾（Dehaze）** | 压掉雾气、灰霾，提对比与细节 | 隔着雾拍的风景、玻璃反光 |
| **光晕（Halation）** | 在亮部边缘加一圈暖红光晕 | 模拟胶片高光的溢出感 |
| **泛光（Bloom）** | 让光源向外柔化扩散 | 夜景灯光、逆光氛围 |
| **颗粒（Grain）** | 加胶片颗粒 | 配合胶片效果收尾，别加多 |

加上原有的 30 来个工具（调整、修复、局部、曲线、镜头模糊、双重曝光、人像等），全部免费开放，应用内没有订阅、内购、广告与水印。

## 七、和旧版不一样的操作习惯

- 老版本的界面细节（工具排列、菜单位置）在 4.0 里变了，**以你界面上看到的为准**，本篇的入口描述仅供参考。
- 更新后发现「某个功能不见了」，多半是被分进了 Tools 的某个分组，去「全部」里找；仍找不到的，见[常见问题与解决办法.md](常见问题与解决办法.md)第七节。
- 编辑逻辑没变：手势还是上下滑切参数、左右滑调值，步骤仍堆在修改列表里，见[新手使用指南.md](新手使用指南.md)。
