## 一、这篇讲什么

Snapseed 是一款全手动取向的手机修图应用：它不替你下结论，每个参数都交给你自己拖。你花五分钟把手势模型摸熟，后面的工具就都是同一套动作。本篇按「打开照片 → 选风格 → 调工具 → 存出来」的顺序走一遍，并解释每个手势。具体某个工具怎么用，拆在[局部调整与蒙版怎么用.md](局部调整与蒙版怎么用.md)和[修复工具去路人与瑕疵.md](修复工具去路人与瑕疵.md)里。

## 二、导入照片

打开应用后，两种进法：

1. 主页点「添加照片」按钮，弹出系统文件选择器，可以从相册、Google 相册或任意文件夹里挑图；
2. 在手机相册里选中照片 → 分享 → 选 Snapseed，直接带进编辑器。

支持的输入是 JPG 与 RAW（手机拍的 DNG 之类）。照片进编辑器后，原图不会被改动——所有调整都以可回看的步骤堆叠着，你随时能撤销或改某一步。

## 三、底部三个标签

进入编辑器后，底部分三块，对应修图的三个阶段：

| 标签 | 作用 | 什么时候用 |
| --- | --- | --- |
| **Looks**（风格） | 预设滤镜，一点就套上整套效果 | 想快速出个调子，或当调整的起点 |
| **Tools**（工具） | 30 多个单项工具，手动调 | 绝大多数时间都在这里 |
| **Export**（导出） | 存图、另存、分享 | 修完之后 |

4.0 起 Tools 里按「精修 / 修复 / 风格 / 全部」分了组，工具多了也不至于翻半天；你常用哪几个可以钉到顶栏，钉的数量没有上限。主页右上角还能切深色/浅色主题，需要看曝光分布时点开直方图。

## 四、手势模型（学会这一套，所有工具通用）

几乎每个工具都是同一套动作，只是一次只作用于当前工具：

- **上下滑** —— 切换当前工具里的参数（比如亮度 → 对比度 → 饱和度 → 结构）。屏幕顶部会显示参数名。
- **左右滑** —— 调当前参数的数值，往右加、往左减，顶部有进度条显示幅度。
- **长按画面** —— 临时看原图，松手回到编辑后效果，用来对比「我到底改了多少」。
- **双指张合** —— 放大/缩小，看细节；放大后用两根手指拖动来平移画面（放大状态下用单指拖是在调参数，别搞混）。
- **左下角的撤销键** —— 点开是「查看修改内容」，里面列出你做过的每一步，点任一步可以重新调参数、用画笔改蒙版，或单独删掉。

顺序也有讲究：同一套工具，先裁剪还是先加效果，结果不一样——比如先加了模糊再裁剪，裁掉的区域外就没有可补的内容了。一般的次序是**先校正（曝光、白平衡、几何）→ 再局部 → 最后风格化（暗角、边框、颗粒）**。

## 五、一条完整的修图流程

1. **导图**：按第二节把照片带进来。
2. **定基调**：进 Tools → 调整图片（Tune Image），上下滑切参数，左右滑调值。常用的四个是亮度、对比度、饱和度、氛围——「氛围」是 Snapseed 特有的平衡型滑块，会同时照顾到亮部和暗部，拉一点常比单独加对比自然。
3. **修瑕疵**：明显的脏点、路人、电线，交给修复工具，做法见[修复工具去路人与瑕疵.md](修复工具去路人与瑕疵.md)。
4. **做局部**：只提亮人脸、只压暗天空这类「只改一块」的需求，用局部或画笔，见[局部调整与蒙版怎么用.md](局部调整与蒙版怎么用.md)。
5. **收尾**：需要的话加一点结构/锐化，最后加暗角或边框（这类要放在最后）。
6. **存图**：去 Export，三个选项的差别直接影响「相册里看不看得到」，先读[保存导出与相册看不到怎么办.md](保存导出与相册看不到怎么办.md)再点。

## 六、用直方图判断曝光（进阶，可选）

右上角能打开直方图，它是「这张图亮暗分布」的横条图，比肉眼在手机屏上判断准：

- **小山整体贴左顶边** —— 暗部已经压死，阴影里没细节；进「调整图片」把**阴影**往右拉一点试试，拉不回来说明现场就没拍到，别硬拉。
- **小山整体贴右顶边** —— 高光溢出，天空、白墙一片死白；用**高光**往回收，通常先试 -30 上下，不够再加。
- **小山居中、两端不顶边** —— 曝光正常，可以往下走局部了。

拿不准时的笨办法：调完点一下长按看原图，再看直方图有没有顶边——两边对照着调，两三次就有手感了。

## 七、几个新手最容易卡住的点

- **放大后手指拖不动画面**：放大状态下要两指拖动才能平移，单指拖是在调参数。
- **点 Looks 套了滤镜就没法细调了**：预设只是起点，套完仍可以进 Tools 继续改，各步骤照样堆在修改列表里。
- **参数一拉就过头**：Snapseed 的默认步进不小，小幅来回拖比一次拉到底好控制；拿不准就长按看原图。
- **修到一半想从头来**：左下角撤销 → 查看修改内容，逐条删，不用退出重开。
- **更新后找不到某个工具**：4.0 把工具分了组，去 Tools 的「全部」里翻，改动明细见[4.0新功能与内置相机怎么用.md](4.0新功能与内置相机怎么用.md)。
- **修完导出发糊**：多半是导出设置在压画质，见[导出后画质变模糊怎么办.md](导出后画质变模糊怎么办.md)。
- 打不开、闪退、存不下，见[常见问题与解决办法.md](常见问题与解决办法.md)；刚装上还没核对安装包，见[下载与安装教程.md](下载与安装教程.md)。
