## 一、这篇讲什么

整张图一起调，很快就会调「脏」：脸提亮了天空也白了。局部这一层就是解决这个的——把改动限制在你圈出来的那块。Snapseed 给了三条路：**局部（控制点）**、**画笔**、**一键智能蒙版**；再加一个事后反悔的入口：**修改步骤里的蒙版刷**。本篇讲清楚各选哪条、具体怎么操作。

（前提是你会那套手势：上下滑切参数、左右滑调值，见[新手使用指南.md](新手使用指南.md)。）

## 二、局部（控制点）：点哪改哪

适合「形状不规则、但中心明确」的目标，比如一张脸、一块招牌、一片天。

1. Tools → 局部（Selective）。
2. 在想改的位置点一下，出现一个控制点。
3. **双指张合**调影响范围：缩放时那个虚线圈就是作用半径，圈到哪改到哪。
4. **上下滑**选参数：亮度 / 对比度 / 饱和度 / 结构。
5. **左右滑**调数值。
6. 同一张图可以放**多个控制点**，各自管各自的参数——压天空一个点、提脸一个点，一步完成。
7. 点右下角对勾应用；想删某个点，进左下角「查看修改内容」→ 该步 → 编辑，点中控制点后删。

控制点会按画面内容自动扩散到相近区域，所以边缘处常会「溢」到隔壁物体上；溢出去了就把范围缩小一点，或改用画笔自己刷。

## 三、画笔：自己刷，最可控

适合边界清楚、或要按走向擦的情况，比如只给地面加曝光、只给某块加饱和度。

1. Tools → 画笔（Brush）。
2. 选要刷的项：加减曝光 / 加减饱和度 / 加减暖色 / 暗化亮化。
3. 底部的上下箭头调笔刷强度（0 是擦除，即把已刷掉）。
4. 手指直接在图上涂；放大后涂得更准。
5. 涂多了就用橡皮擦掉，或用撤销键回退。

画笔的强度是累加的：同一处反复涂会越来越重，宁可强度低一点多涂两遍，也别一上来就拉满。

## 四、一键智能蒙版：先选主体，再调

4.0 加的 Smart Masking，省掉手动圈选的功夫：

1. 进任一局部类工具后点蒙版/选区入口，选区会自动落到**主体**或**背景**上。
2. 选中主体 → 你后续的调整只作用在人身上；选中背景 → 只作用在环境上。
3. 选完再调参数，效果和普通局部一致。

它对主体清晰、背景干净的照片很省事；主体和背景颜色接近时会选不准，这时退回控制点或画笔更稳。

## 五、事后反悔：修改步骤里的蒙版刷

这是 Snapseed 最容易被忽略、也最有用的一招——**任何一步都能回头限定作用范围**：

1. 左下角撤销图标 → **查看修改内容**。
2. 列表里点你要改的那一步（比如「调整图片」「复古」）。
3. 中间弹出三个按钮：调参数、**蒙版刷**、删除这一步。
4. 进蒙版刷，直接用手指涂抹「这一步该生效的地方」，底部箭头可以把强度调成 0 来擦除。

典型用法：先给整张图拉了很强的对比，再用蒙版刷只让脸部保留这个效果。改完点右下角保存这一步的蒙版，回到主界面看到的就是限定后的结果。

## 六、局部之后的收尾

- 局部改动会作为独立步骤堆在修改列表里，和全局调整互不干扰；导出时才压成一张图，见[保存导出与相册看不到怎么办.md](保存导出与相册看不到怎么办.md)。
- 局部提亮容易把噪点一起提上来，脸上的皮肤纹理会变重，之后可以用细节工具的「结构」往回收一点，别再叠一层锐化。
- 局部只管「亮度颜色」，不管「东西在不在」——要抹掉路人、去除污点，用的是修复工具，见[修复工具去路人与瑕疵.md](修复工具去路人与瑕疵.md)。
