# Uptodown 自动更新与版本回退

> 本篇讲用 Uptodown 管理已装应用的更新：自动更新怎么开、怎么只更一部分、以及不满意新版时怎么退回旧版本。

## 一、先说结论

用 Uptodown 装的应用不用你盯着更新：它检测你装过的应用有没有新版，可以开自动更新，也可以逐个挑着更；每个应用的历史版本都留在详情页里，新版不合意就下载旧 APK 覆盖装回去。「更新可挑、版本可退」是它和只能跟随最新版的渠道最实际的差别。

## 二、更新怎么管

- **自动更新**：在设置里开启后，装过的应用出新版会自动下载安装，不用逐个点。
- **手动挑选**：不想全自动的话，在已装应用管理页逐个决定更与不更——官方对它的描述就是「自己挑要更新哪些」。某个应用旧版本用得好好的，把它的自动更新单独关掉即可。
- **更新前想留旧版**：应用管理里有备份功能，更新前把当前版本先留档；就算没留，详情页的历史版本列表也能把旧版装回来（见第三节）。
- **更新提醒**：通知提醒按需开关；只想安静用着、自己想起来再更的，把提醒关掉就行。

## 三、回退到旧版本（rollback）

1. 打开 Uptodown，搜到对应应用进详情页；
2. 往下翻到历史版本区域，那里列出可下载的旧版本和发布时间；
3. 选一个版本下载 APK，点开覆盖安装。

要注意的三点：

- **覆盖安装要求签名一致**：同一渠道下载的版本之间回退一般没问题；如果手机上装的是从别的渠道来的、签名不同的同名应用，要先卸载再装，应用数据会清空，先备份。
- **不是所有应用都留全了所有历史版本**：能退到哪一版，以详情页当时列出的为准。
- **回退后关掉该应用的自动更新**，否则很快又被更回新版，等于白退。

## 四、什么场景用得上

| 场景 | 做法 |
| --- | --- |
| 新版改版不习惯、常用功能被移走 | 回退到上一个版本，并单独关掉该应用的自动更新 |
| 新版在老手机上卡顿、发热明显 | 从历史版本里挑一个更早的轻量版本装回 |
| 想确认某个应用是否还在维护 | 看详情页的版本更新记录，隔多久发一版一目了然 |

版本号与可下载的历史版本列表会随时间变化，以应用内当时显示为准。
