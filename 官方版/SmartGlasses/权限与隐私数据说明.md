## 一、App 申请的权限清单与用途

以下是安卓商店公示的权限列表，按用途归组（完整原文以商店页面为准）：

| 用途 | 涉及权限 |
| --- | --- |
| 连接眼镜 | 蓝牙扫描/广播/配对连接、附近 Wi-Fi 设备、开关蓝牙 |
| 蓝牙搜索的底层依赖 | 大概位置、精确位置、后台位置 |
| 语音类功能 | 录音（麦克风） |
| 状态与内容提示 | 发送通知、悬浮窗显示、控制媒体音量 |
| 保持后台连接 | 忽略电池优化、运行前台服务、防止休眠 |
| 文件与记录 | 读/写文件与文档（会议记录、导出、图库相关） |
| 其他 | 获取手机信息、更改网络连接性、访问网络 |

两点提醒：

- **后台位置是敏感权限**，系统会单独弹窗。如果你的使用场景不涉及「边走边导航」，可以在权限管理里把它收成「仅使用期间允许」，搜设备不受影响；真被影响时再回来看 [连接失败与常见问题排查.md](连接失败与常见问题排查.md)。
- 「获取手机信息」这类权限是商店公示的原始清单，App 是否真的每次都用到、用于什么，以官方隐私政策的说明为准（见下一节）。

## 二、官方对数据收集的口径

- **App Store 隐私标签**：开发者在苹果 App Store 的隐私栏声明为「**未收集数据**」。注意这是开发者自行声明、Apple 页面也标注「未经 Apple 验证」，它代表声明时点的口径。
- **隐私政策原文**：挂在官网下 —— [www.jueyuantech.com/agreement/smartglasses_policy.html](https://www.jueyuantech.com/agreement/smartglasses_policy.html)。想弄清楚某条数据怎么处理，以这份政策当时的文本为准，别只看商店简介。
- **安卓端**没有像苹果那样的统一隐私标签，安卓用户想核实数据口径，直接读上面这份政策是唯一的官方途径。

## 三、你可以自己做的收口

装完 App 后，按「先给齐、再收紧」的顺序处理，比一上来全拒绝省事得多：

1. 先按 [下载与安装教程.md](下载与安装教程.md) 第四节把连接与语音必需的权限给齐；
2. 用几天确认眼镜连接、转写翻译都正常；
3. 再进系统设置逐条收紧不敏感的项：位置收成「仅使用期间」、文件权限收成「仅允许访问选中的媒体文件」（部分系统支持）、不需要通知提示就关通知；
4. 收紧后立刻连一次眼镜验证，哪个功能坏了就恢复哪条权限 —— 这比查文档猜快得多。

麦克风与蓝牙这两条别收：前者管语音转写/翻译/AI 助手，后者管眼镜连接本身，收掉它们等于 App 白装。
