# Google Keep 同步故障排查

> 本篇解决「手机上记了、电脑上没有」「记事反复转圈」「编辑后不保存」这类同步故障，按从简到繁的顺序给排查步骤。

## 一、先分清是哪种不同步

症状不同，原因往往不同：

| 症状 | 多半说明 |
| --- | --- |
| 手机记的内容电脑上看不到 | 单向同步断了：先查这台「看不见」的设备的网络与账号 |
| 编辑后过一会儿又弹「重新加载」，光标乱跳 | 本地缓存与云端状态打架，走下面第五步清缓存 |
| 记事打开空白，等一会才出内容 | 应用被系统后台限制掐断，还没来得及拉完数据 |
| 只有某几条记事异常（多为大图、长清单） | 单条内容过大，同步超时，先把大图移出该记事再试 |
| 所有 Google 应用都不正常 | 服务端故障或网络整体不通，不一定是 Keep 的问题 |

动手改设置之前，先做两个零成本动作：开一次飞行模式等 20 秒再关（重建网络连接）；把 Wi-Fi 和流量互换试一次（判断是某个网络的问题还是设备的问题）。

## 二、第一查：账号登对了吗

Keep 按账号隔离数据，手机上登了两个 Google 账号时，最容易发生的事就是「记在了 A 账号，却打开着 B 账号」：

1. 打开 Keep，点右上角头像，看当前账号；
2. 切到另一个账号看记事是否「回来」了；
3. 确认所有设备登录的都是同一个账号——同步的前提是同账号，跨账号不会合并。

## 三、第二查：账号同步开关有没有被关

安卓上 Keep 的同步跟着账号的总开关走，位置大致是「设置 → 账号 → Google →（你的账号）→ 同步」，找到 **Keep** 一项：

- 开关是关的 → 打开，并点「立即同步」；
- 开关本来就开着 → 先关掉再打开（重置一次同步状态）。

不同品牌 ROM 的菜单路径叫法略有差异（「账户与备份 → 管理账户」等），认准「同步」里的 Keep 开关即可。

## 四、第三查：后台权限与电池优化

多数「刚才还好好的、过会儿就不同步」的案例根源在这里——系统为省电把 Keep 的后台同步掐了：

| 设置项 | 位置（大致路径） | 应设为 |
| --- | --- | --- |
| 后台数据 | 设置 → 应用 → Keep → 流量使用 | 允许后台数据 |
| 电池优化 | 设置 → 电池 → 应用耗电管理 → Keep | 不优化 / 无限制 / 允许后台活动 |
| 自启动（部分国产 ROM） | 设置 → 应用管理 → Keep | 允许自启动 |

iPhone/iPad 对应的是「设置 → 通用 → 后台 App 刷新」里 Keep 的开关要打开，否则改动要等你下次手动打开应用才上传。

## 五、第四查：清缓存（注意不是清数据）

缓存是出问题概率最高、代价最小的重置手段，清掉不会丢任何记事：

1. 设置 → 应用 → Keep → 存储；
2. 点「清除缓存」；
3. 重新打开 Keep，等一两分钟让它重新拉数据。

如果清缓存无效再考虑「清除数据」——这会重置应用状态并要求重新登录，云端记事不会丢，但**没同步上去的本地改动会丢**，所以动这一步之前先确认其他设备上有完整数据，或先照第七节做一次交叉验证。

## 六、第五查：系统时间与账号重置

两个容易被忽略的收尾手段：

- **系统日期时间**：时间不准会让安全校验失败、同步静默中断，开启「自动确定日期和时间」后重试；
- **重新添加账号**：设置 → 账号里把该 Google 账号移除，重启手机后重新登录。这是账号会话层面的重置，对「怎么都不同步」的顽固案例有效；
- **更新应用**：旧版本 App 与新版服务端不兼容也会同步失败，去商店把 Keep 更新到最新。

## 七、用网页版做交叉验证

拿不准问题在哪台设备时，用电脑浏览器打开 [keep.google.com](https://keep.google.com) 看云端真实状态：

- **网页里有、App 里没有** → 云端数据完好，是那台设备的问题，按二到六的顺序走；
- **网页里也没有** → 改动根本没上传成功，回到发起编辑的那台设备排查网络与账号；
- **两边都没有** → 内容真的没保存过，翻[常见问题与解决方法.md](常见问题与解决方法.md)第二节的找回顺序（归档 → 回收站 → 版本记录）。

各端的正常同步行为、离线编辑规则见[多设备同步与数据导出.md](多设备同步与数据导出.md)；如果你用的是语音转写记事，转写失败与网络有关的部分在[语音转文字规则与限制.md](语音转文字规则与限制.md)。
