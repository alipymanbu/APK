# OKK云电脑好友联机方法

## 一、先选哪条路

「联机」在这应用里其实是几件不同的事，先分清你要哪种：

| 你想干的事 | 走哪条路 |
| --- | --- |
| 你俩在**同一台云电脑**上协同操作、一起看同一个画面 | 方法 A：多设备协作（机器码邀请） |
| 你俩**各玩各的**，在某款游戏里同房间对战/开黑 | 方法 B：游戏内多人模式 |
| 一个房间里**轮流接管**同一局游戏 | 方法 C：接力开黑（上麦接力） |

## 二、方法 A：多设备协作（共享一台云电脑）

本质是把你的云电脑画面共享给对方，两台设备连同一台机器协同操作。**需要主账户发起邀请**：

**主账户这边：**

1. 登录 OKK云电脑主账户；
2. 找到「好友邀请」或「远程协作」入口；
3. 选择「复制机器码及验证码」；
4. 通过微信、QQ 之类把机器码和验证码发给朋友。

**朋友那边：**

1. 在自己的设备（手机、电视、投影仪都行）上打开 OKK云电脑，或兼容的云游戏平台；
2. 输入你发过去的机器码与验证码，完成登录与协作连接。

连接成功后，对方设备上会显示你这台云电脑的画面，两边共用同一份算力资源，可以协同操作或一起玩。

注意：这等于把你的云电脑借出去用，操作权是共享的——连着的时候对方动什么你这边都能看到，反之亦然。

## 三、方法 B：游戏内多人模式

如果只是想在游戏里和朋友同房间对战，不需要共享电脑，按游戏自己的联机机制走：

1. 在游戏库里挑一款**支持多人联机/在线对战**的游戏；
2. 启动游戏，进入多人模式，按提示创建房间或加入已有房间；
3. 用游戏内好友系统或第三方社交软件，把好友拉进房间；
4. 好友同样要在 OKK云电脑上登录自己的账号并接受邀请；
5. 所有人准备就绪后开始联机。

这条路的前提是**游戏本身支持联机**，以及双方都登着 OKK云电脑账号。进不去房间、连不上，多半出在这两点，排查见 [常见问题排查.md](常见问题排查.md)。

## 四、方法 C：接力开黑（上麦接力）

除了共享整台电脑和游戏内联机，应用内还有一种「接力」玩法：形态类似直播的连麦房间，你可以参与上麦接力——轮到你时接管这局游戏，玩完再交回。官方商店文案里也把「组队接力开黑」列为联机场景之一。

这个入口在应用内的具体位置与规则（谁能上麦、怎么轮换）没有公开的详细说明，进应用后在房间/连麦类入口里找「接力」相关按钮，以界面当时显示为准。规则不清楚时别按别家直播平台的习惯硬套。

## 五、联机稳不稳看这里

联机卡、掉线通常不是「联机功能坏了」，而是网络到云端那条链路不顺。先做三件事：

1. 在游戏画面的设置弹窗里把画质往低一档调；
2. 确认应用自带的免费加速处于开启状态；
3. 换个网络试试（Wi-Fi 与流量对比一下），排除当前网络本身的问题。

还不行看 [常见问题排查.md](常见问题排查.md) 的卡顿章节。第一次用、还没装好，先回 [下载与安装教程.md](下载与安装教程.md)。
