# Flud 用移动流量下载：排队与被限制的处理

## 一、先确认是不是 Wi-Fi only 在起作用

Flud 首次启动时「只在 Wi-Fi 下载与上传」默认勾选，这是最多人踩的一层：连上流量后所有任务集体排队，不是坏了，是它按设置在等你回 Wi-Fi。改法在 设置 → 电源管理（Power management） 里关掉 Wi-Fi only；关掉后任务立刻开始跑，说明原因就这一层。若关了还是没速度，往下看。

## 二、Wi-Fi 正常、流量为 0：运营商限制 BT

现象很典型：同一批任务在家庭 Wi-Fi 上速度正常，切到移动流量就长期 0 KB/s。不少运营商会用流量识别技术盯 BT 协议的特征并掐断连接，这类限制在流量网络上比家宽更常见。可以做的：

- **把加密档位调到强制**：设置 → 网络（Network） → 加密（Encryption），默认档是「启用」（对方支持才加密），「强制」会让全部传输走加密。有用户反馈这样能绕过只认明文 BT 特征的基础限制——不一定对所有运营商有效；强制的代价是可连节点变少，速度可能反而下降，两头都试一下。
- **换网络对照**：换个 Wi-Fi 或热点再测一次，能区分「资源没人传」和「当前网络不让传」这两种完全不同的问题。
- 限流是网络侧行为，Flud 里的设置解决不了所有情况，长期在流量网下载大文件本来也不现实。

## 三、流量下别忘了上传也在耗额度

BT 是双向的：下载的同时 Flud 会把已拿到的部分传给别人（做种）。流量网关掉 Wi-Fi only 后，上传同样走你的套餐额度。控制办法：

- 任务详情或全局设置里限制上传速度，给下载留带宽、给套餐留额度；
- 不需要继续做种的任务下完就删（删任务时可选择保留文件）；
- 系统自带的流量统计里可以给 Flud 单独设流量警告或上限，超出提醒。

## 四、给挂机下载立个规矩

大文件放在流量网挂机下载，额度消耗是按 GB 计的。更稳的组合是：白天用 Wi-Fi 下载、流量网只做应急小文件；Wi-Fi only 开关留在默认开启，需要临时用流量时再手动关。速度问题的完整排查见 [下载慢与常见问题排查.md](下载慢与常见问题排查.md)，连接层面的设置见 [Tracker添加与连接设置.md](Tracker添加与连接设置.md)。
