## 一、速度为 0 或个位数

BT 的下载速度取决于「能连上多少有文件的人」，按顺序过一遍：

| 现象 | 先查什么 | 处理 |
| --- | --- | --- |
| 做种数（Seeds）为 0 | 任务是不是太冷门 | 给任务补 Tracker（方法见下）；确认资源确实还有人传 |
| 有做种但连不上 | 端口不通 / UPnP 没生效 | 看 [Tracker添加与连接设置.md](Tracker添加与连接设置.md) 的端口部分 |
| 只有 Wi-Fi 能下 | Wi-Fi only 开关 | 设置 → 电源管理 里关掉 Wi-Fi only（走流量注意套餐额度） |
| Wi-Fi 正常、流量为 0 | 运营商限制 BT 流量 | 见 [流量下载被限制怎么办.md](流量下载被限制怎么办.md) |
| 速度被压着 | 设了限速 | 任务与全局的限速设置里确认没有手动上限 |

给任务补 Tracker 是冷门资源最有效的一招：任务详情 → Trackers → 粘贴存活的公开 Tracker 地址，几分钟后回来看节点数有没有涨。多个任务同时抢带宽时，把设置里的最大同时下载数调成 1，集中带宽跑完一个再跑下一个，往往比并行更早见到速度。

## 二、任务加不上 / 一直排队

- **存储权限没给**：首次启动跳过了授权的话，任务加进去也不动。到系统「设置 → 应用 → Flud → 权限」里把存储 / 文件权限打开；Android 11 及以上如果普通存储权限解决不了，在应用信息的权限页找「文件与媒体 / 允许管理所有文件」这类特殊访问入口授予。
- **存储位置不可写**：Storage Path 指到外置卡受限目录时任务会停着，先改到内置存储验证一次，能跑通再逐步排查位置。
- **Wi-Fi only 生效中**：没连 Wi-Fi 时任务全部排队属于正常行为，不是故障。

## 三、锁屏就停 / 后台被杀

省电策略激进的品牌 ROM 容易杀掉 BT 这种长时间后台任务，典型表现是亮屏有速度、一锁屏就归零。处理路径：

1. 系统设置里给 Flud 关掉电池优化（选「不受限制」一类选项）；
2. 在最近任务里给 Flud 加锁，防止一键清理杀掉它；
3. Flud 自己的 设置 → 电源管理 里确认没有开启限制后台传输的选项。

国产 ROM 还有两层容易被忽略的开关：应用信息里的「允许后台活动 / 后台弹出界面」，以及 Android 12 及以上的「暂停不活跃的应用」（应用详情页里看 Flud 有没有被标成受限）。不同品牌的入口名称差异大，认关键词「电池优化 / 后台运行 / 自启动」。

## 四、下载完成后没动静 / 文件找不到

- **通知**：系统通知权限没给就收不到完成通知；Android 13 及以上通知是单独的运行时权限，要在应用权限里手动打开；
- **找文件**：下载位置以添加任务时的 Storage Path 为准，任务详情里可以直接打开所在目录；
- **文件缺**：多文件种子里没勾选的文件本来就不会出现，回任务详情的 Files 页签核对勾选。

## 五、卸载 / 重装前的提醒

外置存储上 `Android/data/com.delphicoder.flud.paid/` 目录会随卸载一起删除（旧系统把外部写入限制在该目录时的行为），重装或清理前把还要的文件先移出去。装好之后按 [下载与安装教程.md](下载与安装教程.md) 的首次启动流程重新过一遍授权。
