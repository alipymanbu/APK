## 一、三种添加任务的方式

| 方式 | 操作 |
| --- | --- |
| 本地种子文件 | 点主界面左下角的「+」按钮，在文件选择器里找到 `.torrent` 文件 |
| 磁力链接 / URL | 点顶部的磁铁图标，粘贴 `magnet:` 链接或 `.torrent` 的 HTTP(S) 地址；剪贴板里已有合适链接时会自动带出 |
| 浏览器接管 | 在浏览器里点磁力链接，系统会让你选择用哪个应用打开，选 Flud 即可 |

确认前会进入添加确认页：**Storage Path** 决定文件存到哪，**Files** 页签决定这个种子里哪些文件要下。

开始前留意两点：任务的做种数（seeders）越多，通常越快连上人；剩余空间要留得比种子体积大——下载过程的临时数据同样占地方。

## 二、只下种子里的一部分文件

多文件种子（比如整季剧集、合集包）没必要全下：

1. 添加任务时切到 **Files** 页签，取消不想要的文件再确认；
2. 已经加进去的任务，打开任务详情 → Files，同样可以改勾选。

配合优先级用更顺手：把想先拿到的文件设为高优先级，其余保持默认，先设的先下完。

## 三、顺序下载：边下边看的前提

普通下载是各数据块乱序抓取，视频文件没下完就没法正常播放。顺序下载（Sequential download）按从头到尾的顺序抓块，前段先完成就能先播。开关在单个任务自己的选项里（以实际界面为准），对视频类大文件有用；代价是上传做种的效率会差一些，看完记得关掉或删任务。

## 四、下载中也能做的事

- **暂停 / 恢复 / 删除**：在任务列表里对单个任务操作；删除时会问要不要连已下载的文件一起删。
- **下载中移动文件**：任务进行中可以把文件挪到别的目录甚至另一块存储，不用停任务——内置空间不够想把大文件挪去外置卡时用得上。
- **分类查看**：主界面按 All / Queued / Finished 分栏，没排上队的任务去 Queued 找，下完的在 Finished。

## 五、大文件与存储卡的限制

- FAT32 格式的 SD 卡单个文件最大 4GB，超了写不进去；把卡格成 exFAT 或改存内置存储可解。
- 想下到外置 SD 卡时，Android 对应用写外部存储有目录限制，遇到「无法写入」多半是所选位置不可写：先把 Storage Path 换到内置存储跑起来，再按 [下载慢与常见问题排查.md](下载慢与常见问题排查.md) 里的存储部分排查。

BT 只是一种传输方式，内容能否获取取决于来源与授权，下载前自行确认对相应文件有使用权限。
