# Shuna 怎么搜索和找漫画

> 本篇讲清在 Shuna 里怎么把想看的漫画找出来 —— 搜关键词、翻分类、看首页推荐这三条路各适合什么情况，以及搜不到时往哪儿使劲。

Shuna 找漫画有三条入口：首页推荐（不知道看什么时用）、顶部搜索框（知道名字时用）、分类页（只记得题材或地区时用）。三条路的操作都很浅，难点通常在「搜不到」这一步，本篇把能试的办法按顺序列出来。

## 一、首页：不知道看什么就从这里进

打开应用落在首页，页面主体是推荐位，通常按热度或更新节奏滚动排布。这里适合两种情况：

- 没有明确目标，只想找点能看的；
- 想追最近更新的连载，看看有没有新章节。

首页只是入口，挑到感兴趣的封面后，点进去就是详情页，后面走的是同一套流程。

## 二、搜索框：知道名字时最快

搜索框在首页顶部（部分版本在「搜索」标签页里）。输入名称或关键词后提交，结果以列表形式给出，点封面进详情页。

搜索有几个实际的注意点：

| 现象 | 可能原因 | 怎么处理 |
| --- | --- | --- |
| 搜全名没结果 | 关键词与库里登记的写法不一致 | 只留作品名里最有辨识度的两三个字再搜 |
| 简繁或别名对不上 | 同一部作品在不同库里有不同译名 | 换另一种译名、或换用分类页翻 |
| 结果里混入同名作品 | 同名不同作者的情况常见 | 点开详情页看简介与封面再定 |
| 输入后没反应 | 网络没通或页面卡住 | 见 [打不开与加载失败怎么排查.md](打不开与加载失败怎么排查.md) |

搜索是匹配作品名，不是匹配作者或剧情，所以别拿剧情关键词去搜 —— 用作品名里最独特的字最有效。

## 三、分类页：只记得题材或地区时用

分类页把库里的作品按几个维度分开，常见的切法是：

| 维度 | 常见取值 |
| --- | --- |
| 题材 | 热血、恋爱、悬疑、科幻、日常、治愈、仙侠等 |
| 地区 | 国漫、日漫、韩漫、欧美漫画 |
| 连载状态 | 连载中、已完结 |
| 排序 | 按人气、按更新时间 |

用法上有个顺序建议：**先定地区，再用题材收窄**。同一部作品在不同地区分类下的归属可能不一样，先按地区切一刀，结果集会小很多，再挑题材就不容易翻到不相关的作品。

排序默认按人气的话，头部作品基本都是热门连载；想找已经完结、可以一口气看完的，把状态切到「已完结」，再按人气排，效果比盲翻好。

## 四、详情页：确认是不是你要的那一部

点开封面后是详情页，这里要看的几项：

- **封面与简介**：同名作品靠这一步区分，简介对不上就返回换一个；
- **章节列表**：看有多少话、是否在更新，决定要不要追；
- **收藏按钮**：确定要看就顺手收藏，下次从收藏列表直接进，不用再搜一遍；
- **开始阅读**：从这里进阅读界面，翻页方式与画面设置见 [翻页方式与阅读设置.md](翻页方式与阅读设置.md)。

## 五、搜不到时，按这个顺序试

1. **换关键词**：去掉修饰词，只留作品名里最独特的两个字；
2. **换译名**：日漫、韩漫常有多套译名，把可能的名字依次试一遍；
3. **走分类页**：按地区 + 题材人工翻，适合你知道大概是什么类型但名字记不准的情况；
4. **过一段时间再搜**：新作品入库、章节更新都有延迟，今天搜不到不代表明天没有。

如果连首页推荐都是空的、搜索也一直转圈，那就不是「找不到作品」的问题，而是应用本身没连上，转 [打不开与加载失败怎么排查.md](打不开与加载失败怎么排查.md)。

挑好作品之后，想把它固定下来方便下次接着看，做法见 [收藏追漫与阅读记录备份.md](收藏追漫与阅读记录备份.md)。
