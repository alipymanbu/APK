# Shuna 打不开与加载失败怎么排查

> 本篇按从轻到重的顺序，讲清 Shuna 打不开、转圈、白屏、某一章出不来这几种情况分别怎么查。

Shuna 是打开就能翻看的安卓漫画应用，「打不开」时的表现其实分成好几种：闪退进不去、首页空白、某一部作品白屏、某几章加载不出来。这几类的成因与处理办法完全不同。本篇按从轻到重的顺序，帮你先判断属于哪一类，再决定是动网络设置还是动应用数据 —— 先分清现象，能省掉一大半无用操作。

| 现象 | 大概率是什么 |
| --- | --- |
| 打开应用就闪退、停在启动页 | 安装或系统版本问题，见第一节 |
| 首页空白、搜索一直转圈 | 网络连不上，见第二节 |
| 别的作品正常，只有某一部点开白屏 | 这部作品本身的资源问题，见第四节 |
| 某几章加载不出来，其它章正常 | 单章资源问题，见第四节 |

## 一、应用本身打不开

如果连首页都进不去，先按安装那条线查：

1. 确认手机系统版本是否够 —— 这份包标注要求安卓 5.2 以上，系统太旧会出现装不上或装上打不开；
2. 确认是不是覆盖安装了旧版 —— 同包名 `com.holecomic` 但签名不同的版本互相覆盖会失败，先把旧版卸载干净再装；
3. 确认安装包完整 —— 重新下一遍再装，下载中断的包会表现为「解析包错误」。

具体核对项见 [下载与安装教程.md](下载与安装教程.md)。

## 二、首页空白、搜索转圈

这是最常见的「打不开」，成因几乎都在网络侧。按这个顺序试，每一步都比上一步重：

1. **切换网络**：WiFi 换移动数据，或换另一个 WiFi。地下车库、老小区路由器、公共 WiFi 的限速都可能造成这种情况，换一条路往往就好了；
2. **换漫画地址 / 站点**：Shuna 整合了多个来源，部分作品在不同来源下可用性不一样。应用内有切换漫画加载地址的入口时，切一个再试；
3. **重启应用**：把应用从后台彻底划掉再打开，清掉这一次运行的临时状态；
4. **清除应用缓存**：到手机「设置 → 应用 → Shuna → 存储 → 清除缓存」，然后重新打开。

**第 4 步放到最后做，不要一上来就按。** 清除缓存有把已下载章节一起清掉的可能，能不动就不动，清之前先想清楚里面有没有还没看完的缓存内容，相关说明见 [离线缓存与本地阅读.md](离线缓存与本地阅读.md)。

## 三、换了网络还是不行

走到这一步，基本可以判断不是你这边的网络问题：

- **换个时间段再试**：来源侧偶发波动很常见，隔几小时再来往往自己就好了；
- **确认是不是只有自己这台有问题**：同一网络下换另一台设备试同一个作品，能区分是设备问题还是普遍问题；
- **部分资源有地域访问限制**：多个公开页面都提到过这一点，某些作品在特定地区访问不稳定，属于来源侧的限制，不是你手机设置的问题。

## 四、只有某一部作品 / 某一章出不来

这在漫画类应用里很常见，处理原则也最简单：**这不是你的设备坏了，也不是应用装错了。**

- 换同一部作品的其它章节试试，能出来说明是单章资源的问题；
- 换另一部作品试试，能出来说明应用本身完全正常；
- 遇到这种情况的合理做法就是换一部看，或者过一段时间再回来点这一章。反复重装应用、清数据，都解决不了来源侧缺资源的问题。

如果整部作品都打不开、而且换来源后依然如此，把它从收藏里挪开，换别的作品即可。

## 五、翻页或缩放时卡住

单独说一下这个现象：图片能出，但翻页卡顿、缩放没反应。这多半和阅读设置或缓存状态有关，不是网络问题：

- 条漫用下拉式、页漫用左右翻页，混着用容易在切页时顿一下，翻页方式怎么选见 [翻页方式与阅读设置.md](翻页方式与阅读设置.md)；
- 已缓存的章节连播比在线加载稳，网络不稳时优先看缓存内容，见 [离线缓存与本地阅读.md](离线缓存与本地阅读.md)；
- 缩放没反应时，先看是不是被系统的三指截屏、手势返回抢走了触点，换个位置再试。

按上面四节排查下来还没解决的，基本都落在来源侧资源上，换作品或换时间即可，不必反复重装。
