# Shuna 离线缓存与本地阅读

在线看漫画吃网络，地铁、电梯、乡下老家的信号都靠不住。Shuna 支持把章节提前缓存到本机，存好之后断网也能接着看。本篇讲的就是「什么时候该存、存了之后会怎样」这两件事。

## 一、什么样的场景值得先缓存

| 场景 | 为什么值得存 |
| --- | --- |
| 通勤路上要看 | 地下段没信号，在线翻到一半会卡住 |
| 长途出行 / 无 WiFi | 用移动数据看图流量消耗大，提前在 WiFi 下存好更划算 |
| 追更到关键章节 | 怕内容下架或章节变动，先留一份在本机 |
| 网络时段不稳 | 家里晚上网速差，白天存好晚上看 |

反过来，随手翻两页、看完就过的作品没必要存 —— 缓存白占空间，还要手动清理。

## 二、怎么缓存

入口通常有两处：

1. **漫画详情页**：章节列表旁边一般有缓存或下载的按钮，可以按章存，也可以在支持的情况下整部勾选；
2. **阅读界面**：唤出操作栏后也能对当前章节执行缓存，适合看到一半决定「后面几章也留着」。

章节较多的作品，建议先存最近要看的那十几章，而不是一次全勾 —— 全本缓存体积大、耗时长，中途切换网络还容易中断。

## 三、缓存下来的内容什么时候能看

缓存的本质是把图片存到了手机里，所以：

- 断网、飞行模式下，已缓存的章节照常打开；
- **没缓存过的章节，断网时一定打不开**，这不是故障；
- 缓存好的作品不会因为退出应用而消失，只要不卸载不清数据，下次打开还在。

缓存在哪、占多大空间，通常在应用内的存储或缓存管理里能看到明细。手机上空间紧张时，优先清掉已经看完的旧作品，而不是清整个应用的数据。

## 四、两个容易吃亏的地方

**第一，缓存不跟着账号走。** 这些文件存在本机，所以卸载重装、换手机之后，缓存全部要重新存一遍。想在换机后接着看，靠的是阅读记录和收藏的备份，做法见 [收藏追漫与阅读记录备份.md](收藏追漫与阅读记录备份.md)。

**第二，分清「清除缓存」和「清除数据」。** 在手机的「应用信息 → 存储」里有这两个按钮：

- **清除缓存**：清的是临时文件，相对轻；
- **清除数据**：会把应用的设置、阅读记录一起重置，已缓存的章节也可能被一并清掉。

两个按钮的具体影响每个系统版本提示不同，**动手前先看清系统给的那行说明**。真遇到缓存异常导致的打不开，可以按 [打不开与加载失败怎么排查.md](打不开与加载失败怎么排查.md) 的顺序来，把清缓存放在最后一步，别一上来就按。

## 五、和阅读体验配合着用

缓存好之后，翻页方式也顺手换一下：条漫作品缓存下来后用下拉式一路刷，中途不会因为加载而停顿；页面模式的作品缓存后直接左右翻页，一屏一页节奏更稳。两种模式的差别和切换位置见 [翻页方式与阅读设置.md](翻页方式与阅读设置.md)。
