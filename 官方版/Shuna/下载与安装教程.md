Shuna 是安卓手机上的漫画阅读应用，包名 `com.holecomic`，装完不用注册账号就能直接翻看，内容以国漫、日韩漫和欧美漫为主。本篇讲的是把网盘里这份包装进手机、确认自己装的是哪一版，以及装之前值得先知道的两件事。

## 一、先确认网盘里这份包是哪一版

网上搜到的版本号通常是当时的最新发布版，网盘里这份是做文档时核对过的那一版，两者不一定是同一个。本文出现的版本号、包名、体积，一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Shuna |
| 版本号 | 9.0.12 |
| 包名 | `com.holecomic` |
| 安装包体积 | 70.71 MB |
| MD5 | `FAFD8D7ABEF915D7E4BA6DA4601D45EF` |

核对办法：把下载好的 APK 放到电脑上，用任意一个能算哈希的工具算一遍 MD5，与上表对照。值一致就说明文件完整、和文档里描述的是同一份；对不上就是下载过程中断了包，重新下一遍。

顺带提醒一句：这个名字在网上会被写成好几个变体（Shuna 漫画、Shuna 下拉式漫画之类），判断是不是同一个应用要看**包名**，不要看名字。详见 [同名应用与版本怎么认.md](同名应用与版本怎么认.md)。

## 二、装之前要核对的两件事

**第一，系统版本。** 这份包的运行要求标注为「需要支持安卓系统 5.2 以上」。安卓并没有 5.2 这一档公开版本号，这类标注多半来自打包工具的编译口径，所以别拿它当精确门槛，直接装上试最快：

- 安装时弹「应用未安装」「解析包错误」；
- 或者装完一打开就闪退、停在启动页不动；

出现这两种情况，基本就是手机系统版本太低，不是包坏了。

**第二，设备类型。** 这是安卓应用，只有安卓安装包，iPhone 与 iPad 装不了。想在电脑上看，只能借助安卓模拟器，装法与手机一致。

## 三、安装步骤

1. **转存并下载**：从 [Shuna 安装文件资源（夸克网盘）](https://pan.quark.cn/s/039b9703db75) 把 APK 转存到自己的网盘，再下载到手机上；
2. **允许安装未知来源的应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关，否则点安装包不会有反应；
3. **先卸掉签名不同的旧版**：手机里若已装过同包名 `com.holecomic`、但来源不同的版本，安装会直接失败。先把旧的那个卸载掉再装新的，别覆盖安装；
4. **跟随系统提示走完**：国产手机会在安装过程中弹「安全检测」「外部来源应用」之类的提醒，选择继续安装即可，不要中途返回。

## 四、第一次打开会看到什么

打开后直接进首页，**没有登录页，也不用注册** —— 应用会在本地生成一个账号直接用。首页顶部是搜索框，下面是推荐位。

第一次打开尽量联网，先把首页数据拉下来，再去搜索或翻分类。搜索、分类筛选、进详情页看章节的具体走法，都在 [怎么搜索和找漫画.md](怎么搜索和找漫画.md) 里。

## 五、要不要付费、有没有广告

公开的软件页在这个问题上口径不一致，两类说法都有：

| 说法 | 出现在哪一类页面 |
| --- | --- |
| 免费阅读，无需付费或订阅 | 部分下载页的简介文字 |
| 免费使用，但含应用内购买项目 | 部分下载页的软件信息栏 |

也就是「能不能完全免费看」这件事，各页面写法不统一，此处不替它们选边。实际判断办法很简单：装上后进「我的」页面，看有没有充值、会员、订阅这类入口 —— 有就说明存在付费项，没有就可以当纯免费版本用。

广告方面口径比收费一致一些：多个公开页面都提到阅读过程没有广告干扰。这条同样以你实际使用时看到的为准。

另外，部分软件页把内容分级标为「年满十六周岁以上」。给小孩装之前，这条值得留意一下。

## 六、装完做一次最小验证

1. 在顶部搜索框输入一部漫画的名字；
2. 从搜索结果里点开封面，进详情页；
3. 点「开始阅读」，能正常出图就说明安装没问题。

如果一直转圈、白屏、或提示加载失败，先转到 [打不开与加载失败怎么排查.md](打不开与加载失败怎么排查.md) 按顺序排一遍；如果是某部作品点开才有问题、别的作品正常，那更可能是这部作品本身的资源问题，换一部作品试试即可。
