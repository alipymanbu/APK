## 一、先说结论

装好模块与管理器后，你日常要做的就两件事：**给手机定一个全局模式**，以及**给个别应用（典型是游戏）单独指定模式**。前者在管理器里点一下就切，后者既可以在管理器里配，也可以直接改文本文件。切换本身是实时生效的（改文件那条路需要重启，见下文）。

## 二、五种模式分别是什么

管理器里能选的模式与 `cur_powermode.txt` 里的英文名一一对应：

| 管理器里的名字 | 文件里的值 | 特点 |
| --- | --- | --- |
| 动态/自动 | `auto` | 根据你正在使用的应用动态响应，每个应用走它自己的配置 |
| 均衡 | `balance` | 官方定位是日用推荐：比原厂略流畅的同时略省电 |
| 省电 | `powersave` | 保守调度，保证基本流畅的同时尽可能降低功耗 |
| 性能 | `performance` | 不做性能限制，比较激进，耗电明显 |
| 极速 | `fast` | 类似性能模式，但升降频速度更快 |

（另有「v3 专用版」一类的切换项，是给 uperf v3 配置用的；管理器从 v1.0.1 起只适配 uperf v3 与 dfps v1，不再适配旧的 uperf v2。）

几点使用口径：

- **没特殊需要就停在均衡**。模块刷入后的默认就是均衡，绝大多数人不需要改。
- **模式越激进越费电**：性能、极速是为「马上要打游戏」准备的，不是日常档。
- **`auto` 是动态调度的总开关**：只有把它设为当前模式，分应用配置才会被真正调用（见第四节）。

## 三、切换全局模式的三种方式

### 方式 1：在管理器里点（最常用）

打开 YC调度管理器，首页第一栏是 uperf 调度设置，直接选目标模式，改完即生效——无需重启。切换后可以用管理器里的状态显示、或读回文件确认。

### 方式 2：改配置文件（决定开机后默认用哪个）

用文件管理器打开 `/sdcard/Android/yc/uperf/cur_powermode.txt`，把内容改成目标模式名（如 `powersave`），保存后**重启手机**生效。这个文件里的值就是开机启动时使用的默认模式。

### 方式 3：命令行（适合脚本化）

```sh
echo "powersave" > /sdcard/yc/uperf/cur_powermode
```

或：

```sh
sh /data/powercfg.sh balance
```

其中 `balance` 换成你想切的模式名。uperf 监听该文件的写入，写完即切换。

## 四、按应用单独分配模式（分应用调度）

场景：平时省电，一进游戏就拉满。这靠 `perapp_powermode.txt` 实现。

1. 用文件管理器打开 `/sdcard/Android/yc/uperf/perapp_powermode.txt`；
2. 按「**包名 空格 模式**」的格式一行一条，例如：

```text
# 注释行以 # 开头
com.example.game fast
com.example.reader powersave
```

3. 文件末尾还有两个特殊行：`-` 是**息屏后**要用的模式，`*` 是**默认模式**（没单独配置的应用用它）。两者都可以改成你想要的值；
4. 保存后，把 `cur_powermode.txt` 的值改成 `auto`（见方式 2），**重启**生效。

分应用配置只有在全局模式为 `auto` 时才会被调用——你把它留在 `balance`，配了也不会生效。这条是最常见的「设置了没反应」的原因，排查见 [常见问题与故障排查.md](常见问题与故障排查.md)。

管理器的底栏里也有按应用设置的入口（用户应用与系统应用分开两栏），可以逐个应用点选，不必手敲文件；两种方式写的是同一套规则，选顺手的用。

## 五、几个会遇到的实际问题

- **改完没生效**：改文件这条路都要重启；在管理器里切是即时的。分应用配置还要额外满足「全局 = auto」。
- **游戏锁了高频但还是卡/烫**：先确认不是温控在限制——系统温控是硬件保护，多数情况不用关；若游戏时 CPU 被压在很低的频率（例如 1.4GHz），是温控介入了，处理思路见 [常见问题与故障排查.md](常见问题与故障排查.md)。
- **想知道当前到底是什么模式**：读 `/sdcard/Android/yc/uperf/cur_powermode.txt`，或看管理器首页显示的状态。

另外提醒一句：如果你还装了别的调度工具箱（例如 Scene），它也能切性能模式、写同一批节点——两边同时管，效果会互相覆盖。它们并非不能共存（uperf 官方说明两者独立运作、无依赖），但**同一时间只让一个当「切换者」**，免得来回拉扯。
