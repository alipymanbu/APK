# 刷入模块后无法开机怎么办

> 刷 uperf / dfps 模块后卡在开机动画、反复重启时，三条不用清数据的恢复路径（ADB / 安全模式 / Recovery）。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [常见问题与故障排查.md](常见问题与故障排查.md) · [性能模式切换教程.md](性能模式切换教程.md)

## 一、先明确：这不是变砖，别急着恢复出厂

刷 Magisk 模块后卡开机动画（bootloop），说明系统起来了一半、只是被模块的启动脚本挡住——**数据分区没坏，不需要恢复出厂、不需要清数据**。恢复出厂是最后手段而不是第一步，先走下面三条路，按「由省事到麻烦」的顺序试。

处理思路只有一个：**把刚刷的模块禁用或删掉，先让手机能开机**，再回头排查是哪个文件的问题（排查入口见 [常见问题与故障排查.md](常见问题与故障排查.md)）。

## 二、方法 1：ADB 一条命令删掉所有模块（需提前开过 USB 调试）

如果你之前在开发者选项里打开过 USB 调试，这是最快的一条：

1. 手机连电脑，确认设备在（电脑上执行 `adb devices` 能看到它）；
2. 执行：

```sh
adb shell magisk --remove-modules
```

命令会删除全部 Magisk 模块并自动重启手机——**注意是全部模块，不只这一个**。能开机后再把需要的模块逐个装回去，一次装一个，装完重启确认，就知道是哪个有问题。

## 三、方法 2：进安全模式，让 Magisk 自动禁用模块（无需电脑）

多数现代 Android 设备都支持这个紧急入口：

1. 强制关机（长按电源键 10 秒左右）；
2. 开机，在开机画面出现后**立即长按音量下键**不放，直到进入锁屏；
3. 看到屏幕角上出现「安全模式」字样即可——Magisk 检测到安全模式后会**自动禁用所有模块**；
4. 正常重启回普通模式，模块保持禁用状态；
5. 打开 Magisk App，在模块列表里把出问题的模块卸载（或先留着禁用状态，去查原因）。

各机型进安全模式的按键时机略有差异，进不去就换下面的方法 3。

## 四、方法 3：Recovery 里删掉模块目录（通用兜底）

只要手机还能进 Recovery（TWRP、OrangeFox 或厂商自带的都行），就能直接删文件：

1. 关机，用组合键进 Recovery（常见是电源键 + 音量上，因机型而异）；
2. 打开文件管理，进入 `/data/adb/modules/`；
3. 找到刚刷的模块目录（uperf 模块就是其中的 `uperf` 文件夹）删掉；
4. 重启回系统。

TWRP 自带文件管理器（Advanced → File Manager）就能完成；OrangeFox 的菜单里还有现成的 Magisk Manager 页可以勾选「下次启动移除模块」。这条**不动数据分区**，删完即开机。

## 五、卡开机前其实有预兆，装的时候避开

- **下载的平台文件不匹配**：刷入时 Magisk 就会提示 `not supported`（这颗 SoC 没有预制配置），见 [常见问题与故障排查.md](常见问题与故障排查.md)；
- **一次刷太多**：刚刷完 uperf 又叠别的内核/调度模块，出问题就分不清是谁——有用户反馈过与其他内核模块同装导致异常的情况。一次只动一个变量，重启确认正常再动下一个；
- **刷完先看日志再下结论**：正常启动后 `/sdcard/Android/yc/uperf/uperf_log.txt` 会存在，见 [下载与安装教程.md](下载与安装教程.md) 的验证清单。

以上恢复步骤的依据是 Magisk 官方 FAQ（「装了模块后卡开机动画」一节），各机型表现以实际为准；处理完回头定位根因，再按 [性能模式切换教程.md](性能模式切换教程.md) 重新配置。
