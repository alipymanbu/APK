## 一、管理器读不到调度状态 / 什么也做不了

按顺序查，通常问题在第 1、2 步：

1. **模块刷了吗**：没刷 uperf，管理器就是个空壳。装它本身不需要 Root，但用它必须有 Root + 模块，前置步骤见 [下载与安装教程.md](下载与安装教程.md)；
2. **刷完重启了吗**：模块刷入后必须重启才生效，验证 `/sdcard/Android/yc/uperf/uperf_log.txt` 是否存在；
3. **Root 授权给了吗**：首次打开时允许管理器的 Root 请求；
4. **APK 与模块版本配吗**：管理器从 v1.0.1 起只适配 uperf v3 + dfps v1，配旧的 uperf v2 读不到东西。

## 二、Magisk 刷入时提示 not supported

这个硬件平台**没有预制的配置文件**——不是你操作错了，是模块没为你这颗 SoC 出预调参配置，需要自行适配。没有把握适配的话，这台机器就别硬上，见官方仓库说明：[github.com/yc9559/uperf](https://github.com/yc9559/uperf)。

另外下载调度文件时对号入座：`sdm` 高通、`Helio` 联发科 P/G 系列、`dimensity` 天玑、`exynos` 三星猎户座，下错平台的包装不上是正常的。

系统版本上，官方标注 uperf 支持 **Android 6.0 - 12**（arm64-v8a）；管理器的更新日志里出过「修复高安卓版本写入」，说明更新的系统被碰到过——**超出官方标注范围的系统版本，能不能正常工作以你的实测为准**，动手前先想好 [刷入模块后无法开机怎么办.md](刷入模块后无法开机怎么办.md) 的退路。

## 三、刷完重启就卡在开机动画

不算罕见，处理办法单拆了一篇：[刷入模块后无法开机怎么办.md](刷入模块后无法开机怎么办.md)。核心是三条不用清数据的恢复路径（ADB 一条命令删模块 / 进安全模式让 Magisk 自动禁用 / Recovery 里删 `/data/adb/modules/` 下的模块目录），**先恢复开机，再回头查原因**。别一上来就恢复出厂。

## 四、模式设了没效果

最常见的四个原因，按命中率排：

1. **分应用配置配了，但全局不是 `auto`**——`perapp_powermode.txt` 只在全局模式为 `auto` 时被调用，把它留在 `balance` 配了也白配。改 `cur_powermode.txt` 为 `auto` 后重启，详见 [性能模式切换教程.md](性能模式切换教程.md)；
2. **改完没重启**：直接改文件的路径都要重启才生效；在管理器里切是即时的；
3. **保存没成功**：编辑后确认文件内容真的变了（有些文件管理器会因权限保存失败）；
4. **别的调度工具在抢**：装了 Scene 之类的工具箱且也在切模式，两边会互相覆盖，留一个当切换者即可；系统自带的「性能模式」、游戏空间/游戏模式里的性能档同理——**同一时间只留一层在管性能**（有用户反馈，玩机社区里常见的做法就是把系统与游戏空间都放回均衡，只让 uperf 说话）。

改完可用读回 `cur_powermode.txt` 或看管理器首页状态来确认当前模式。

顺带一提：如果你在 uperf 之外还叠了别的内核模块或锁频模块，也有用户反馈过装在一起出异常的案例——排查这类问题时，把非官方/三方修改的模块逐个卸掉试，是最省时间的定位法。

## 五、用了 uperf 还是很费电

官方口径：uperf 只控制性能释放、改进频点选择，**后台应用的计算量它管不了**——后台狂跑，续航不会有明显改善。定位办法是用工具箱类应用的进程管理器看谁在烧 CPU，把元凶清掉。

另外两条相关判断：

- **待机功耗**：uperf 自身开销很低，待机模式还减少了唤醒核心数；待机省电主要靠减少唤醒时长比例，不要指望它单独解决后台唤醒问题；
- **是否要关温控**：多数情况不用。温控是硬件保护；若性能被压得异常（如游戏时 CPU 锁在 1.4GHz 左右），思路是调高温控阈值或在确认散热安全的前提下关闭温控，而不是默认关。

## 六、动态刷新率不生效 / 生效后丢失

- **先开管理器里的「启用 Backdoor」**——刷了 dfps 却完全不动、或重启后刷新率丢失时，这个开关一开立竿见影，说明见 [动态刷新率设置教程.md](动态刷新率设置教程.md)；
- **模块版本太旧**：分应用配置在 Android 13、刷新率设置在 MIUI 14 上失效的问题已在较新版本修复，去 [github.com/yc9559/dfps](https://github.com/yc9559/dfps) 更新模块；
- **配置没指对**：确认息屏/默认规则里的值与你屏幕实际支持的刷新率档位一致，设了屏幕没有的档位不会生效；
- **观察手段**：开着 FPS 显示开关，改一项看一眼，先确认「触摸切高刷、松手超时长降低刷」这条主链路通不通，再查分应用。

## 七、系统层的怪毛病（官方列出的已知故障）

这些是 uperf 测试阶段收集到的已知问题，各有明确处理办法：

| 症状 | 处理 |
| --- | --- |
| 桌面启动器不响应触摸（目前仅见于 MIUI 12） | 删除 `/data/adb/modules/uperf/enable_sfanalysis` |
| 触摸屏报点间断丢失 | 检查是否装了「自动跳过」这类模拟坐标点击的应用，卸掉或关掉它的坐标点击 |
| 睡死/无故重启 | 用户态程序理论上不影响系统稳定性，建议换回官方内核与 ROM 再判断 |

## 八、还有问题时的求助顺序

1. 先翻官方文档：[github.com/yc9559/uperf](https://github.com/yc9559/uperf) 的 README（含常见问题与配置文件说明）、[github.com/yc9559/dfps](https://github.com/yc9559/dfps) 的更新说明；
2. 求助时带上三样信息：机型与处理器、Android 版本、`/sdcard/Android/yc/uperf/uperf_log.txt` 的日志内容——有这三样别人才能判断；
3. 确认是管理器本身装不上/打不开的问题（而非模块侧），再回头核对 [下载与安装教程.md](下载与安装教程.md) 的验证清单。
