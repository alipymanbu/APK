## 一、这是个什么软件，先想清楚再装

YC调度管理器是一个**管理端 APK**，它自己不调频——真正干活的是手机里刷入的两个 Magisk 模块：`uperf`（动态性能调度）与 `dfps`（动态刷新率）。你装这个 APK，是为了用图形界面去切换性能模式、按应用分配调度、配置刷新率规则，而不必每次都用文件管理器改文本。

这意味着两件事：

- **没有 Root、没刷模块，装上它也做不了任何事**（网上有些下载页写着「免 root 版」，那不符合它的实际工作方式）；
- 装它之前，先把模块侧准备好，顺序是：解锁 BL → 拿 Root → 刷模块 → 装这个 APK。

## 二、前置准备：三步都绕不开

### 1. 解锁 Bootloader（BL 锁）

以小米/Redmi 为例：到官网下载官方解锁工具，用电脑完成解锁。其他品牌各有各的解锁通道。解锁会清空数据，先备份。

### 2. 获取 Root：刷入 Magisk

解锁后把 Magisk 刷进系统（通常也需电脑配合）。刷完重启，打开 Magisk 确认已正常工作——后面所有模块都靠它。

### 3. 刷入调度模块

- **uperf（性能调度）**：到官方仓库 [github.com/yc9559/uperf](https://github.com/yc9559/uperf) 的 releases 页下载与你处理器对应的调度文件，刷入后重启。文件名按平台区分：`sdm` 是高通、`Helio` 是联发科 P/G 系列、`dimensity` 是天玑、`exynos` 是三星猎户座。
- **dfps（动态刷新率，可选）**：官方仓库 [github.com/yc9559/dfps](https://github.com/yc9559/dfps) 的 releases 页下载刷入。只关心性能调度的可以不装。

刷入是否成功，重启后看日志文件是否存在：`/sdcard/Android/yc/uperf/uperf_log.txt`。存在即 uperf 已正常自启动。

系统范围（官方仓库标注，截至其公开说明，以官方页面为准）：**Android 6.0 - 12**、arm64-v8a；dfps 是 **Android 10-13**。超出范围的系统不一定跑不起来，但动手前先想好退路——真卡在开机动画了，照 [刷入模块后无法开机怎么办.md](刷入模块后无法开机怎么办.md) 恢复，不用清数据。

> 官方 README 标注 Magisk 方式安装要求版本不低于 20.4+，具体以官方仓库页面当时显示为准。若你的机型刷入时提示 `not supported`，说明这个硬件平台没有预制配置文件，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 三、安装 YC调度管理器 APK

1. 从 [YC调度管理器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/39a49f489b19) 下载安装包；
2. 下载完成后可核对 MD5 是否为 `EEFB753FA29820061CE8356E2C2571FA`（文件管理器或电脑端工具均可校验），对不上说明文件在传输中损坏，重新下载；
3. 手机上点击 APK 安装，允许「安装未知应用」权限；
4. 装完先别急着改设置——打开它确认能读到当前调度状态。读不到，通常是模块没刷或没重启，回上一节检查。

## 四、装完后的验证清单

按顺序过一遍，任何一步不过就别往下走：

1. Magisk 模块列表里 uperf 已启用（官方模块生效后在列表中显示为绿色）；
2. `/sdcard/Android/yc/uperf/uperf_log.txt` 存且有内容；
3. 打开 YC调度管理器，能显示当前性能模式（默认是均衡模式）；
4. 在管理器里切换一次模式（比如切到省电），再读回 `cur_powermode.txt` 确认值真的变了。

第 4 步通了，说明 APK ↔ 模块这条链是活的，接下来就可以按自己的习惯配置了：

- 想调模式、按应用分配调度 → [性能模式切换教程.md](性能模式切换教程.md)
- 想让屏幕自动切换刷新率 → [动态刷新率设置教程.md](动态刷新率设置教程.md)
