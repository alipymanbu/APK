## 一、先分清是哪种打不开

| 现象 | 多半是哪类问题 | 从哪节开始 |
| --- | --- | --- |
| APK 装不上，提示解析失败或禁止安装 | 系统版本不够、包没下完整、安装来源未授权 | 第二节 + [下载与安装教程.md](下载与安装教程.md) |
| 一点图标立刻退回桌面（闪退） | 缓存/数据异常、存储不足、系统太旧 | 第二、三节 |
| 卡在启动画面或登录页转圈 | 网络、代理、登录服务 | 第四节 |
| 能打开但一编辑就卡顿无响应 | 内存不足、文稿过长、后台过多 | 第五节 |

## 二、通用四步（按顺序做，多数到第三步就好）

这几步是各大手机厂商支持页通用的安卓应用异常处理法，对 Effie 同样适用：

1. **重启手机**：清掉临时故障，成本最低，先做这个；
2. **检查更新**：系统「设置 → 系统更新」升到最新，Effie 设置页最底部点版本号看有没有新版本；
3. **强行停止后重开**：系统「设置 → 应用管理 → Effie → 强行停止」，再点开；
4. **看存储空间**：手机可用空间长期低于 10% 时，应用容易闪退无响应，先清理出空间。

## 三、清缓存 vs 清数据（关键区别）

路径：系统「设置 → 应用管理 → Effie → 存储」。

- **清除缓存**：只删临时文件，**不动你的文稿和登录状态**，闪退优先试这个；
- **清除数据**：会把登录态、本地缓存全部清掉 —— 做之前必须确认**云端已同步完**（文稿在别的设备上能看到，或已导出备份），清完要重新登录、重新拉取文稿。清除后仍异常，再考虑卸载重装。

## 四、卡在登录页 / 点登录没反应

这不是闪退，是网络与登录服务的问题，排查步骤（关代理、换热点、重启应用、确认系统允许 Effie 联网）写在 [常见问题与故障排除.md](常见问题与故障排除.md) 的登录一节，照着走即可。另外确认一下：Effie 分国内版和海外版，**装错版本登录后是空文稿**，也会被误当成「打不开数据」。

## 五、卸载重装的三个注意

1. **先保底**：卸载会删掉本地未同步的内容 —— 重装前在还能打开时导出文稿，或确认所有设备上都已同步；
2. **装回同一个版本**：登录原来那个账号（微信或已绑定的邮箱），且仍是国内版的 Effie，否则看不到旧文稿；
3. **包从哪来**：用 [Effie 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f2c41b82b739) 里那份 4.2.3，或官方下载页的最新版（截至 2026-09，系统要求以官方页面当时显示为准）；系统低于要求的机型会装不上或反复闪退。

## 六、排除以上仍然异常

- 机型系统本身不适配有先例：魅族系统上 Effie 目前**只能只读**，编辑功能不可用属预期；
- 手机系统版本长期不更新、与新版应用不兼容时，等应用下次更新推送是常规解法；
- 以上都不匹配，把「机型 + 系统版本 + 具体现象（在哪一步卡住）」发给客服：微信 `EffieCares` 或邮件 `contact@effie.co`。
