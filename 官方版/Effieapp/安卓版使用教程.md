## 一、先记住四个操作

Effie 安卓版的按钮大多被藏了起来，操作靠四个动作触发。官方教程把它们归纳成四条，日常九成操作都在里面：

1. **长按**文件夹或文稿卡片，顶部会出现操作工具栏；
2. **设置**里的自定义项（外观、字体、高级选项都在这）；
3. 点编辑区**右上角的 …**，展开文稿详情面板（字数、导出、历史版本都在里面）；
4. 点**键盘上方工具栏**的图标（插入、标记、AI 都在这排）。

## 二、文件夹管理（首页）

首页就是文件夹列表。在这里你可以：新建文件夹、移动文件夹（改顺序和层级）、展开/收起子文件夹、全局搜索文稿、打开设置、新建文稿。

**长按文件夹卡片**进入编辑状态后，可以：

- 创建子文件夹、改文件夹名称和图标；
- 设置文件夹内文稿的排序方式（手动排序 / 按标题 / 按修改时间 / 按创建时间）；
- 文件夹加锁、解锁（加锁属于 Pro 功能，见 [试用版与Pro会员区别.md](试用版与Pro会员区别.md)）；
- 删除文件夹 —— 删除是进回收站，可恢复，也可以在回收站里彻底删除；
- 隐藏【Effie 介绍】和【收藏夹】。

## 三、文稿管理（卡片页）

一个文件夹里，每篇文稿显示为一张卡片。卡片有三种状态：

- **常规状态**：在文件夹内搜索文稿、进入排序；
- **排序状态**：文件夹设为手动排序时，按住卡片拖动即可换顺序；
- **编辑状态**（长按卡片触发，顶部出工具栏）：加到收藏夹、置顶、移动到其他文件夹、导出、删除到回收站。

回收站里的文稿可多选批量恢复或彻底删除。收藏夹和置顶是 Pro 功能。

## 四、文稿编辑（编辑区）

编辑区是 Effie 的主体，键盘上方那排工具栏集成了主要操作：

| 操作 | 怎么做 |
| --- | --- |
| 排版 | 直接输入标记符（`# ` 标题、`**粗体**` 等），或打开标记面板点选 |
| 插入 | 超链接、图片、表格，都从工具栏插入 |
| 大纲 | 输入 `- ` 加空格进大纲模式；大纲项可左右缩进调整层级 |
| 查找 | 文稿内查找关键词 |
| 撤销/重做 | 工具栏上的撤销、重做按钮 |
| AI | 工具栏的 AI 写作助手（需订阅 AI 套餐） |
| 一键排版 | 工具栏里（Pro 功能） |
| 目录跳转 | 打开目录列表，点条目直接跳到文稿对应位置 |
| 滚动定位 | 右侧上下滚动小把手，快速拖到任意位置 |

### 标记语法对照

不想点面板就直接敲符号，效果即时呈现。安卓版支持的标记：

| 想要的效果 | 怎么敲 |
| --- | --- |
| 一至六级标题 | 行首 `# ` 加空格是一级，`## ` 是二级，以此类推，最多六级 |
| 粗体 / 斜体 | 文字前后各 `**` / 各 `*` |
| 标注（高亮） | 文字前后各加两个冒号 |
| 删除线 | 文字前后各加两个波浪线 `~~` |
| 评论 | 文字前后各加两个加号 |
| 引用 | 行首 `> ` 加空格 |
| 注释 | 行首 `%% ` 加空格 |
| 分隔线 | 行首输入三个减号后回车 |
| 行内代码 | 文字前加一个重音符（数字 1 左边那个键） |
| 代码块 | 行首两个重音符加空格 |

三种施加方式：敲字时顺手输标记符、打开标记面板点选、**选中文字后**用面板批量设置。列表模式下输入 `- ` 或 `+ ` 加空格进入，层级用工具栏的左右缩进按钮调（电脑端是 Tab / Shift+Tab），点列表左侧的圆点可以整组展开或收起。

点**右上角 …** 打开的详情面板里有：创建时间、修改时间、字数、复制全文、导出、**历史版本**（可查看并恢复最近版本，恢复时可选择覆盖原文稿或另存为新文稿）。

大纲和导图的专门用法见 [大纲与思维导图怎么用.md](大纲与思维导图怎么用.md)；导出格式与限制见 [文稿导出与导入.md](文稿导出与导入.md)。

## 五、小组件

安卓版有三个桌面小组件，长按桌面进入添加方式：

- **新建文稿**：直接进入新文稿编辑界面，快速记录；
- **问 AI**：直接进 AI 对话界面；
- **头脑风暴**：让 AI 从多个角度生成想法。

## 六、设置里有什么

- **常规**：外观与主题配色、字体、行高、首行缩进、标题与正文字体大小；
- **高级**：插入图片默认大小与存储质量、括号引号自动配对、导出图片设置、导出文件页脚等（部分项为 Pro 权限）；
- **隐私**：修改文件夹加锁密码；
- **订阅**：查看与购买 Pro、AI 套餐；
- **账号**：改账号名称、绑定/换绑邮箱、换绑手机；
- 页面最底部点 Logo 和版本号可检查更新。

字体、行高、首行缩进这些显示设置都在「常规」里调，改完全局生效，不需要逐篇调格式。
