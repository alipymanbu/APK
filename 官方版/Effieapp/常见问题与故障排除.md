## 一、登录相关

**点登录或扫码后没反应**

按顺序排查：确认网络正常 → 关掉代理软件 → 重启 Effie → 手机端检查系统设置里是否允许 Effie 用网络 → 公司局域网的话换手机热点再试。

**登录页没有微信登录选项**

在登录页**长按空白处**会跳到微信扫码页；或者在已登录的设备上进「设置 → 账号」绑定邮箱，改用邮箱登录。

## 二、同步相关

**多设备文稿不同步、或同步成空白**

1. 确认两端登录的是同一个账号（设置 → 账号）；
2. 确认两端是**同一个版本的 Effie** —— 国内版与海外版数据不互通，图标一致但版本不同的组合最容易出这问题；
3. 升级到最新版（电脑端：文件 → 检查更新；安卓版：设置页最底部点版本号）；
4. 网络正常且无代理，重启应用；
5. 还不行：**先把文稿导出到本地保底**（见 [文稿导出与导入.md](文稿导出与导入.md)），再退出账号重新登录。

**离线会不会丢**

支持离线写作，恢复联网后自动同步。所以写的时候断网不用管，但长期离线前最好手动导出一份备份。

## 三、图片相关

- 试用版图片容量有限，Pro 有 10G；
- 单账号**每天图片上传次数超限会触发防护**，一段时间后自动恢复；触发期间新图不会上传到服务器，先把图片存本地，恢复后再传；
- 插入图片的默认大小与存储质量在「设置 → 高级」里调。

## 四、其他高频问题

| 现象 | 处理 |
| --- | --- |
| 手机上导不出长图那么长 | 长图受像素限制约 2700 字，长文改导 PDF |
| 导出的 Word/PDF 样式和 Effie 里不一样 | 正常，导出不保留 Effie 字体与渲染，见 [文稿导出与导入.md](文稿导出与导入.md) |
| 找不到字数 | 编辑区右上角 **…** 详情面板里有字数；数字和英文在没加空格/回车前计入字符数，中文标点算字数 |
| 文稿误删了 | 回收站可恢复；内容改坏了可用详情面板里的**历史版本**回退 |
| 想搜一篇旧文 | 卡片页有文件夹内搜索；编辑区内查找定位关键词 |
| 魅族手机用不了 | 魅族系统上目前只能只读 |
| 会员功能点不了 | 多为未订阅或套餐不含该项，见 [试用版与Pro会员区别.md](试用版与Pro会员区别.md) |

## 五、隐私与客服

官方口径：上传的数据加密保存，不通过数据盈利、不分析创作内容、无智能推荐算法、无广告系统。

需要人工支持时，联系客服微信 `EffieCares`，或发邮件到 `contact@effie.co`；官方帮助汇总在 [blog.effie.co](https://blog.effie.co) 的常见问题页，官网入口是 [www.effie.co](https://www.effie.co)。
