# Spark Mail 邮箱账号添加与设置教程

> 本篇讲怎么把你的各类邮箱接进 Spark Mail：注册 Spark 账号、逐个添加 Gmail / Outlook / iCloud / Exchange / IMAP 邮箱，以及多账户统一收件箱的管理方式。

## 一、先分清两种「账号」

用 Spark Mail 之前，你要先搞清楚它有两层账号，别混了：

| 层级 | 是什么 | 干什么用 |
| --- | --- | --- |
| Spark 账号 | 注册 Spark Mail 时用的那个邮箱+密码（或直接用 Google / Apple 账号登录） | 在你的多台设备之间同步设置、已添加的邮箱、订阅状态 |
| 邮箱账户 | 你真正收发信的邮箱，比如 Gmail、公司邮箱 | 一个 Spark 账号下可以挂多个邮箱账户，统一收信 |

官方建议一个 Spark 账号下添加的邮箱账户不超过 10 个，超了之后同步会变得不可靠。

## 二、注册 / 登录 Spark 账号

刚装好第一次打开时，应用会先让你注册或登录 Spark 账号：

1. 输入一个邮箱地址，设置密码；或点「Sign in with Google / Apple」用现有账号一键登录。
2. 输入验证码（会发到你填的那个邮箱）完成验证。
3. 进入应用后，这个邮箱就成了你的「Email for Sync」——以后在别的设备（电脑版、iPad 等）登录 Spark Mail，用同一个地址登录，所有设置和邮箱账户会自动带过去。

如果你有多台设备要一起用，注册时就选你日常最常用的邮箱，之后不用重复配置。

## 三、添加邮箱账户（按服务商分）

登录后进入「设置 → 邮箱账户 → 添加账户」，选对应的服务商。各家流程差别不小，分开说：

### Gmail

1. 选 Gmail，弹出 Google 登录页，输入账号密码完成登录。
2. 在授权页勾选允许 Spark Mail 读取和管理邮件的权限，点允许。
3. 回到应用，收件箱开始拉取邮件。

Gmail 拉取通常最快，授权一次长期有效。如果你开了 Google 两步验证，这一步走的是 OAuth 授权，不需要单独生成应用专用密码。想收回授权时，在 Google 账号的安全设置页（`https://myaccount.google.com/permissions`）把 Spark Mail 的访问权限删掉即可，客户端会立刻失去访问能力。

### Outlook / Hotmail / Office 365

1. 选 Outlook，弹出微软登录页。
2. 登录你的微软账号；个人邮箱（outlook.com / hotmail.com）和 Office 365 工作账号走同一个入口。
3. 若你的公司租户开了条件访问策略，管理员可能需要批准第三方客户端访问——公司邮箱加不进来的常见原因就在这一步，需要找 IT 开通。

### iCloud

1. 选 iCloud，输入你的 Apple ID 邮箱。
2. 关键点：**这里要填的不是 Apple ID 密码，而是「App 专用密码」**。你需要在苹果官网的 Apple ID 管理页（`appleid.apple.com`）登录后，在「登录与安全 → App 专用密码」里生成一个专用密码，再填进 Spark Mail。
3. 生成专用密码需要你的 Apple ID 已开启双重认证。

### Exchange / 企业邮箱

1. 选 Exchange，填邮箱地址和密码。
2. 如果服务器自动识别失败，手动填服务器地址、域名、用户名——这些信息要找你的邮件管理员拿，每家公司不一样。

### 其他邮箱（IMAP / POP3）

QQ 邮箱、163 邮箱、自家域名邮箱这类，选「Other / 其他」走 IMAP：

1. 先去邮箱网页版的设置里**开启 IMAP 服务**——QQ 和 163 邮箱默认是关的，并且开启时要短信验证。
2. 大部分国内邮箱还会要求你生成「授权码」（不是登录密码）：QQ 邮箱在「设置 → 账户」里开启 SMTP/IMAP 后生成授权码，163 类似。
3. 回到 Spark Mail 填：邮箱地址、**授权码**（不是密码）、IMAP 服务器地址和端口（QQ 是 `imap.qq.com:993`，163 是 `imap.163.com:993`，以各邮箱官方帮助页为准）、SMTP 发信服务器和端口。
4. 保存后应用会做一次连接测试，通过即添加成功。

## 四、多账户的日常管理

全部加进来之后：

- **统一收件箱**：默认所有账户的邮件混在一个收件箱里按时间排；你也可以在收件箱顶部切换到单个账户查看。
- **发信身份**：写新邮件时点发件人一行可以切换用哪个邮箱发出去，回复某账户收到的信默认用它自己的地址回。
- **签名按账户区分**：每个邮箱账户可以配各自的签名，在「设置 → 签名」里逐个设置。
- **删账户**：设置 → 邮箱账户 → 选中某个账户 → 删除。删掉只影响 Spark Mail 里的显示，邮箱本身的邮件不受影响。

多账户加完后，接下来最值得花时间的是把智能收件箱的分组调顺——不同账户的信混在一起，全靠它帮你分层，具体见[智能收件箱使用技巧.md](智能收件箱使用技巧.md)。

账户加不上、一直转圈、报密码错误（尤其 IMAP 授权码场景），按[常见问题排查.md](常见问题排查.md)里的对应条目处理。
