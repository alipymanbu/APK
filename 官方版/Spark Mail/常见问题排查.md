## 一、安装环节

**Q：点 APK 提示「解析包出现问题」或安装到一半失败？**

按顺序查三样：

1. 确认安装包完整——3.8.10 版的完整体积约 485.92 MB，文件明显偏小就是没下完，重新下载；有条件的核对 MD5 是否等于 `6883C2CDAF8AB33CFC125F787AD80041`。
2. 确认安卓版本不低于 10（官方要求，以官方页面为准）：设置 → 关于手机。
3. 存储空间剩余至少留 2 GB，接近 500 MB 的包在安装时还需要额外的解压空间。

**Q：装好了，图标点开没反应或闪退？**

先重启一次手机再试；仍闪退的，检查是否装了「应用冻结/省电管控」类工具把它冻住了。还有一类闪退出在系统 WebView 极旧的老设备上，更新系统 WebView 后再开。

## 二、收信与同步

**Q：邮箱加进来了，但一直收不到新邮件？**

1. 先确认手机其他应用能正常联网——代理/VPN 断开是最常见的假故障。
2. 进「设置 → 邮箱账户」，点该账户看有没有红色报错提示。报「密码错误」或「认证失败」的，按下面第四节的登录问题处理。
3. 下拉收件箱手动刷新一次；自动同步依赖应用在后台存活，被系统杀后台的厂商 ROM（小米、华为的部分机型默认激进省电）需要在系统设置里给 Spark Mail 开「允许后台运行 / 自启动」。
4. 都不行就删掉该账户重新添加，注意 IMAP 类邮箱的授权码可能已过期，需要重新生成。

**Q：手机上已读的邮件，电脑上又显示未读（或反过来）？**

已读状态通过 Spark 账号在各设备间同步。两台设备登录的不是同一个 Spark 账号时状态各记各的——检查「设置」顶部的账号邮箱是否一致，不一致就退出后用同一个账号重新登录。

**Q：某封邮件彻底找不到，但确定收到过？**

用搜索时把范围放宽：点搜索框 → 加时间范围或附件过滤再试。搜不到的话去网页版邮箱（或电脑版客户端）确认原信还在不在——Spark Mail 里被误删的邮件在对应邮箱的已删除文件夹里能找回，超出保留期就没了。

## 三、通知

**Q：来信不响铃/不弹横幅？**

1. 检查应用内「设置 → 通知」：每个账户的推送档位是单独设的，档位在 Smart/Priority 时订阅和系统通知默认静音——这不是坏了，是设计如此，想全收就把该账户改成 All。
2. 检查系统层：手机设置 → 应用 → Spark Mail → 通知，确认总开关和各渠道（横幅、声音、锁屏）都开着。
3. 国产 ROM 还要确认没有把应用禁了后台：省电策略改成「无限制」或至少「智能」。

通知问题改了设置还是不灵的（延迟几小时、挂 VPN 收不到、杀后台补送），完整排查清单在[收不到新邮件通知怎么办.md](收不到新邮件通知怎么办.md)，那里按「应用内 → 系统 → 厂商省电 → 网络」四层展开，本文不重复。

**Q：一封邮件手机响了两次？**

那是旧客户端（系统邮件、Gmail 官方应用等）还在管同一个邮箱。把旧客户端的该账户通知关掉，或直接从旧客户端移除该账户，只留一处推送。

## 四、登录与授权报错

**Q：Gmail 登录页一直打不开或卡在授权？**

Google 登录页加载异常时，先确认设备能访问 Google 服务；账号开了两步验证不影响——Spark Mail 走的是标准 OAuth 授权页，不需要生成应用专用密码。

**Q：iCloud 邮箱总报密码错误？**

这里填的不是 Apple ID 密码，是「App 专用密码」：到苹果 Apple ID 管理页生成一个专用密码再填。前提是你的 Apple ID 开了双重认证。

**Q：QQ / 163 邮箱加不上？**

两步都不能省：先在邮箱网页版设置里开启 IMAP 服务（要短信验证），再用**授权码**（不是邮箱登录密码）填进 Spark Mail。授权码生成入口和服务器地址见[邮箱账号添加与设置.md](邮箱账号添加与设置.md)的 IMAP 一节。

**Q：公司邮箱报「无法连接服务器」？**

企业 Exchange 邮箱可能被公司安全策略拦了第三方客户端。自己排不了，把报错截图发给公司邮件管理员，让他确认是否允许第三方客户端访问。

## 五、其他

**Q：想把它设成系统默认邮件应用？**

安卓的「默认应用」机制主要管 `mailto:` 链接的跳转。到系统设置 → 应用 → 默认应用 → 邮件应用，选 Spark Mail；之后点网页上的邮箱链接就会跳进它。部分国产 ROM 没有这一项，跳过即可。

**Q：怎么查当前装的是哪个版本？**

应用内「设置 → 关于/帮助」里能看到版本号；核对是不是 3.8.10，可以帮你判断这份安装包是否被覆盖更新过。

**Q：换新手机怎么迁移？**

新手机装好 Spark Mail 后，用原 Spark 账号登录，邮箱账户、设置、订阅状态会自动同步过来，不需要逐个重加邮箱。若原设备有本地草稿未同步，先在旧设备上联网等它同步完成再注销。
