# 收不到新邮件通知怎么办（安卓端排查清单）

> Spark Mail 明明收到了信、手机却不响？本篇按「应用内 → 系统层 → 厂商省电 → 网络环境」四层给出排查清单，从最常见的原因排起。

## 一、先确认不是「设计如此」

Spark Mail 的推送分三档，每个邮箱账户单独设置。如果你用的是智能（Smart）或优先（Priority）档，订阅邮件、系统通知类的来信**本来就不推送**，这不是故障：

1. 打开应用，点左上角菜单进入「设置」。
2. 选「通知」。
3. 在通知类型（Notification Type）里逐个点开你的账户。
4. 每个账户在三档里选一个：**All**（全部来信都推）、**Priority**（只推标记为重要的）、**Smart**（只推真人来信，官方默认）。

想全部都响，把对应账户改成 All 即可。改完可以给自己发一封测试邮件验证。

## 二、系统层：通知开关与权限

应用内没问题，再查系统侧（路径以你手机的安卓版本为准）：

1. 系统设置 → 应用 → 找到 Spark Mail → 通知：确认总开关开着，且各渠道（横幅、声音、锁屏显示）没有被单独关掉。
2. 确认没有开着全局「勿扰模式」——勿扰会把横幅和声音一起静掉。
3. 装完应用后如果第一次弹「允许发送通知」时你点了拒绝，通知权限就是关的，到上面第 1 步的页面重新打开。

## 三、国产 ROM 的省电机制（延迟通知的最大来源）

三星、小米、华为、OPPO、vivo 等厂商定制系统的省电策略会杀后台应用——应用被杀后推送就收不到，直到你手动打开应用才补进收件箱。这是国产安卓上「邮件延迟一大截才到」的头号原因。逐项处理：

| 设置项 | 怎么改 |
| --- | --- |
| 电池优化 | 系统设置 → 电池 → 电池优化（各厂商叫法不同），把 Spark Mail 改成「不优化 / 无限制」 |
| 后台运行权限 | 应用信息 → 电池/耗电管理 → 允许后台运行、允许自启动 |
| 后台联网 | 应用信息 → 流量使用 → 允许后台数据 |
| 任务卡片锁定 | 最近任务列表里长按 Spark Mail 卡片，选「锁定」（锁定的应用不会被一键清理杀掉） |

改完之后别再用「一键加速 / 内存清理」类功能清它，清一次等于白设一次。各品牌的菜单名称差异较大，找不到对应入口时搜「你的品牌 + 应用杀后台」，设置思路是通用的。

## 四、网络环境

- **挂了 VPN / 代理 / 公司网络**：推送可能被网络层拦下。官方对这种情况的建议是联系网络管理员，确认推送服务没有被服务器层面屏蔽——公司 Wi-Fi 里收不到、回家 4G 正常，基本就是这一类。
- **省电模式开着**：部分机型的超级省电会直接断掉应用同步，测试通知时先退出省电模式。
- **谷歌服务框架**：推送通道依赖设备上的谷歌服务框架。framework 缺失或被禁用的国产机型上，推送要么不达、要么延迟严重；确认「Google Play 服务」在正常运行（未被停用、未被省电冻结）。

## 五、以上都试过还不行

1. 清一次应用缓存：系统设置 → 应用 → Spark Mail → 存储 → 清除缓存（先别清数据，清数据要重新登录）。
2. 重启手机——别嫌简单，推送服务卡住时重启是最快的解法。
3. 还不行就删掉应用重装：登录同一个 Spark 账号，配置会自动同步回来，操作见[常见问题排查.md](常见问题排查.md)的迁移条目。

顺带说明：通知的推送原理决定了邮件主题和部分内容会经 Spark 的服务器中转（加密存储、发送后短时删除），介意的话可以看[隐私与数据安全说明.md](隐私与数据安全说明.md)再决定推送档位怎么选。
