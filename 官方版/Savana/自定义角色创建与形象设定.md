## 一、两条路：先用现成的，还是自己捏

Savana 里的角色分两类：

- **官方角色库**：内置高冷御姐、阳光学长、霸道总裁、甜宠女友、温柔小奶狗等预设角色，题材覆盖校园、都市、古风、玄幻、女性向等分类，官方会定期上新。首页点开角色即可直接开聊；角色多时，可以用关键词搜索或随机匹配来挑（以实际版本为准）。
- **自定义角色**：自己设定姓名、性别、年龄、性格、声线与背景故事，从零创建一个专属角色。

想马上开聊就选前者；想要贴合自己偏好的陪伴对象，就走自定义。创建入口在首页的「创作 / 创建角色」一类入口（不同版本的叫法略有差异，位置一般比较显眼）。

## 二、自定义角色能设哪些项

| 设定项 | 可调内容 | 说明 |
| --- | --- | --- |
| 姓名 / 性别 / 年龄 | 自由填写 | 决定角色的基础称呼与语气 |
| 性格标签 | 傲娇、腹黑、温柔等风格维度可选（第三方介绍称细分达 16 类） | 决定回复的整体风格，选 1~3 个即可 |
| 性格倾向 | 滑杆式调节，如「毒舌 ↔ 温柔」「理性 ↔ 感性」 | 比标签更细，直接影响语气冷暖 |
| 声线 | 多种声音风格 | 影响语音交互时的听感 |
| 外貌细节 | 发型、瞳色、服装风格等可逐项调整 | 影响形象生成与剧情描写 |
| 标志性台词 | 自定义角色常挂在嘴边的话 | 让角色更快「像那么回事」 |
| 背景故事 | 自由填写人生经历 | 写得越具体，角色越不容易「出戏」 |
| 形象 | 手动导入图片，或用文字描述生成 | 见下一节 |

背景故事是最值得花时间的一项：与其写「温柔的大学生」，不如写清对方的专业、说话习惯、和你是什么关系——角色的回复会围绕这些设定展开，写得笼统，回复就容易空洞。性格倾向的滑杆也一样：调到极端值（全毒舌、全理性）对话会很带感，但也容易把天聊死，建议留一点中间地带。

## 三、角色形象的两种做法

1. **手动导入图片**：在创建流程的形象一步从相册上传本地图片。
2. **文字描述生成**：按「特征 + 细节」的句式描述，例如「蓝瞳精灵少女，裙摆缀满星光元素」这类写法，应用会据此生成形象；描述越具体，结果越接近预期。

不想动手的话，创建时还有一批预设头像可以直接选。

## 四、捏好之后

- 想让角色「记住」你的称呼、喜好和设定，靠的是长期记忆，用法见 [记忆管理怎么用.md](记忆管理怎么用.md)。
- 创建好的角色可以直接进闲聊，也可以进剧情演绎，玩法见 [剧情模式与对话模型切换.md](剧情模式与对话模型切换.md)。
