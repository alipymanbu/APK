## 一、入口在哪

打开与某个角色的聊天页 → 右上角「…」菜单 → **「记忆管理」**。进去看到的就是**当前这个角色**对你的长期记忆列表。

两个关键口径（来自官方更新日志的描述）：

- 记忆按「登录账号 + 角色」分开存：你跟角色 A 说的事，角色 B 并不知道；
- 不同账号之间互不可见，换账号登录看到的记忆列表也不同。

## 二、能做的五件事

| 操作 | 用途 |
| --- | --- |
| 查看 | 翻这个角色记住了你哪些事 |
| 新增记忆 | 主动让它「记住这个」：你的称呼、喜好、禁忌话题等 |
| 置顶 / 取消置顶 | 把重要条目固定住，减少被后续对话冲淡的可能 |
| 纠错编辑 | 角色记错了直接改条目内容，不用靠反复解释 |
| 删除 | 不想被记住的条目直接删掉 |

这些操作是 iOS 端 1.0.43 版本更新日志里明确列出的功能；安卓端入口一致，个别叫法可能略有差异，以界面为准。

## 三、什么时候值得手动维护

- 角色总叫错你的称呼 → 新增一条记忆写明称呼；
- 角色老提无关的旧话题 → 翻记忆列表，把过时条目删掉或纠错；
- 想让剧情长期延续（如设定过的关系背景）→ 新增后顺手置顶。

比在聊天里反复纠正省事得多：聊天里说的话只是对话存档，而记忆列表里的条目才是角色后续回复的直接依据。

还有一个容易混淆的点：**记忆条目和聊天记录是两套东西**。删掉一条记忆，聊天记录还在；想让角色「忘记」的是对你的印象，动记忆列表就够。想让角色彻底从头开始，清空记忆之外，也可以直接新建一个同类角色重新聊。

## 四、换设备 / 卸载后记忆还在吗

对话历史与记忆都挂在登录账号下，第三方介绍提到对话支持云端备份——换设备登录**同一个账号**一般能找回（以实际为准）。卸载前先确认自己记得账号与密码，避免找回时卡在登录环节——登录相关问题的处理见 [对话卡顿与登录问题排查.md](对话卡顿与登录问题排查.md)。

另外，自定义角色本身的设定与记忆是两回事：角色的人设改动要去编辑角色资料，操作思路见 [自定义角色创建与形象设定.md](自定义角色创建与形象设定.md)。
