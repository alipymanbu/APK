## 一、装之前先确认这几件事

NavStar 不是独立应用，它是三星官方个性化套件 **Good Lock** 的一个模块，出品方是 Good Lock Labs。它改的是系统导航栏（屏幕底部那三个键或手势条），所以：

- 你得有一台**三星 Galaxy 手机**，且系统是三星的 One UI —— 其他品牌手机装上也没有作用对象；
- 手机上要能打开 **Galaxy Store**（三星应用商店），Good Lock 及其模块从这里分发；
- 系统版本：官方商店页标注需要 **Android 8.1 及以上**（以官方页面当时显示为准）。

如果你只是想把现成的安装包装到手机上，跳到第二节的方式二。

## 二、两种安装方式

### 方式一：通过 Good Lock 安装（官方推荐路径）

1. 在 Galaxy Store 里搜索并安装 **Good Lock**，图标是四块彩色拼图。
2. 打开 Good Lock，切到 **Make up**（装饰）标签页。
3. 在列表里找到 **NavStar**，点右侧的下载图标，等它装完。
4. 装好后直接从 Good Lock 里点开 NavStar 就能用 —— 桌面上通常不会出现独立图标。

以后升级也在这个位置：Good Lock 里 NavStar 旁边显示更新提示时点一下即可。

### 方式二：手动安装 APK（不走商店）

1. 取得 NavStar 的 APK 安装包。想直接用现成的包，从这里拿：[NavStar 安装文件资源（夸克网盘）](https://pan.quark.cn/s/426b24fd8335)。
2. 把 APK 传到手机（数据线、聊天工具发文件、网盘下载都行）。
3. 在文件管理器里点这个 APK，系统会提示「禁止安装未知来源应用」—— 按提示允许本次安装（一般在设置里搜「安装未知应用」）。
4. 装完注意：**手动装的 NavStar 仍然需要 Good Lock 在场**才能正常打开，缺 Good Lock 就先按方式一把它装上。
5. 安装时如果提示「已安装更高版本」，说明商店版比这份新，属正常现象，按需选择即可。

## 三、首次启动要做的两件事

装好后从 Good Lock 里打开 NavStar，头两次进入会碰到：

1. **点「开始 / Start」**进入主界面；
2. **允许存储权限** —— 官方说明里写得很清楚，这个权限用来保存你选的导航栏图片与设置项。拒绝了会导致自定义图标存不下来，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

进主界面后把顶部的总开关打开，下面的选项才可编辑。之后按你的用途选一条路：改按钮外观去 [导航栏按钮外观怎么自定义.md](导航栏按钮外观怎么自定义.md)，改手势条去 [全面屏手势提示与手势条设置.md](全面屏手势提示与手势条设置.md)。

## 四、版本说明

- NavStar 的商店版本号会随时间变化，具体几版以 Galaxy Store 页面当时显示为准（官方更新日志注明 v8.x.x 系列支持 One UI 8 设备）。
- 系统刚推送大版本更新（如新的 One UI 大版本）后，模块可能短暂不兼容，等 Good Lock 与 NavStar 跟进更新即可，处理办法见 [常见问题与故障排查.md](常见问题与故障排查.md)。
- 用网盘里这份 6.1.05.45 覆盖安装商店旧版、或反过来用商店版覆盖它，都属于同一包名的正常覆盖安装，配置数据不会因此丢失。
