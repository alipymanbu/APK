## 一、Alook 的「油猴」其实就是 JavaScript 扩展

Alook 没有独立的「油猴插件商店」，它的等价物叫 **JavaScript 扩展**（设置 → 自定义设置 → JavaScript 扩展）。你在 Greasy Fork、ScriptCat 这类脚本站复制来的用户脚本代码，粘进去就能跑——这就是大家说的「Alook 装油猴」。

支持两类扩展：

| 类型 | 什么时候跑 | 适合装什么 |
| --- | --- | --- |
| 主动扩展 | 按你设定的匹配条件，在对应网页上执行 | 去水印、页面增强、自动翻页这类脚本 |
| 被动扩展 | 不主动注入页面，只在被调用时执行 | 中转/助手类脚本（如让 Alook 识别 `.user.js` 链接自动弹安装） |

## 二、手动导入一个脚本（最常用）

1. 在电脑或手机浏览器打开脚本站（如 Greasy Fork），进入脚本页，点「安装此脚本」，**全选复制页面上的代码**（从 `// ==UserScript==` 到结尾）；
2. 打开 Alook → 首页三横线菜单 → **设置**；
3. 进 **自定义设置 → JavaScript 扩展**，点右上角 **+**；
4. 选 **主动扩展**；
5. 名字随便填（方便自己认）；匹配类型选「链接网址」或按脚本说明填匹配值（通常写网站域名，如 `https://www.example.com/*`）；
6. 把复制的代码粘进 JavaScript 代码框，**保存**。

回到目标网站刷新页面，脚本即生效。脚本头部的 `// @match`、`// @run-at` 等元数据决定它在哪些页面、什么时机运行 —— 照脚本作者写的填，一般不会错。

## 三、用「脚本直装」省掉手动粘贴

手动粘贴每次都要开脚本站复制，麻烦。社区有个常用做法：装一个**被动扩展**当直装助手，让 Alook 恢复识别 `.user.js` 链接的能力，之后在脚本站点安装链接就直接弹安装窗：

1. 打开 Alook → 设置 → 自定义设置 → JavaScript 扩展 → **+**；
2. 选 **被动扩展**；
3. 匹配类型选 **链接网址**，匹配值填 `http.*://.*/.*.user.js`；
4. 粘贴助手脚本的代码（可在 ScriptCat 搜「ALook 浏览器 脚本直装助手」取码，其代码页注明 MIT 许可），保存。

之后访问任何 `.user.js` 安装链接，Alook 会直接弹出安装确认。注意代码要与脚本站上的一字不差 —— JavaScript 是严格匹配，多一个字符都不执行。

## 四、脚本不生效时按这四条查

1. **匹配值写错了**：匹配的是「这个脚本该在哪些网址跑」，写错域名它就永远不触发。对照脚本的 `@match` 改。
2. **扩展类型选错**：需要注入页面的脚本放进了「被动扩展」，它不会自动跑。
3. **没刷新页面**：扩展是页面加载时注入的，改完设置要重开网页。
4. **网站自己的 CSP 拦了**：个别站点禁止外挂脚本，这是站方策略，换不掉。

仍无效的具体报错排查，见 [常见问题排查.md](常见问题排查.md)。

## 五、管理与备份

- 已装脚本在 JavaScript 扩展列表里可停用、编辑、删除；
- 脚本存在本地，**卸载 Alook 会一起清掉** —— 重要的脚本代码建议在扩展里复制出来留一份底；
- 装太多脚本会拖慢页面加载，只留常用的。
