## 一、无痕浏览开了之后会发生什么

无痕（私人）模式下，浏览历史、缓存、Cookie **都不落盘** —— 官方隐私政策写明：私人浏览模式只把 Cookie 存在内存里，退出即消失。适合查敏感信息、登录临时账号这类「不想留痕」的场景。

开启路径：菜单里选无痕/隐私窗口（新开了一个不带历史的窗口），或在设置里切。注意无痕只管**浏览记录**，不管搜索框的历史词 —— 那个要单独关，见下一节。

## 二、搜索历史与浏览数据怎么清

1. **关掉搜索历史记录**：设置 → 隐私设置 → 关闭「记录搜索历史」。这一步多个渠道的教程写法一致，是最常被问的「怎么不留痕迹」答案。
2. **清 Cookie 与缓存**：设置 → 清除数据，可选清 Cookie、缓存、历史。网页登录态丢了要重新登录，清之前想清楚。
3. **只清某个站的数据**：长按网址 → 站点设置 → 清除该站数据，不用全清。

## 三、账号、书签同步与注销

- 书签同步用的是**微信登录**：官方隐私政策写明只从微信取一个 `globalToken` 当唯一标识，不拿你的其他信息。
- **注销账号**：设置 → 账号与同步 → 登录账号选择 → 注销账号。注销后官方按政策删除对应信息（微信授权 ID 与书签）。
- 书签、历史这类数据存哪、存多久，以官网 [alookweb.com/privacy.html](https://www.alookweb.com/privacy.html) 当前版本为准。

## 四、官方隐私政策里值得知道的几条

以下摘自官方隐私政策（生效日期 2021-07-01，以官网当前版本为准）：

| 项目 | 口径 |
| --- | --- |
| 数据分析 | 集成友盟 SDK，记录使用次数、使用时长、崩溃日志；官方声明收集的信息不与具体用户绑定 |
| 剪贴板 | 只用于快速打开你拷贝的链接/搜索拷贝的文本，不存储剪贴板内容 |
| 传感器 | 只用于自动旋转屏幕，不存储 |
| 位置 | 网页要定位时才触发，Alook 本身不取位置（与安装篇权限表一致） |
| 儿童 | 服务不针对 13 岁以下儿童 |

拿不准的地方直接读原文：[alookweb.com/privacy.html](https://www.alookweb.com/privacy.html)。

## 五、跟「少看点东西」相关的另外两件事

隐私的另一半是别让网站追着你跑：

- **广告拦截**能挡掉大部分跟踪类广告位，规则与手动标记见 [广告拦截与阅读模式使用.md](广告拦截与阅读模式使用.md)；
- **无图模式**减少第三方图片请求（菜单里开），流量与加载面都更小。

装完应用后默认给哪些权限、位置权限要不要拒绝，见 [下载与安装教程.md](下载与安装教程.md) 第四节；清完数据出问题（打不开、丢书签）的补救在 [常见问题排查.md](常见问题排查.md)。
