## 一、这是个什么应用，装之前先对上号

Alook浏览器 是保定乐活网络科技有限公司出的手机浏览器，安卓版与 iOS 版都有。它在各家应用市场的信息一致：包名 `alook.browser`，分类是系统工具里的浏览器。你在装之前可以先核对这三项，装错包或装了来路不明的同名包就麻烦了。

| 核对项 | 值 |
| --- | --- |
| 包名 | `alook.browser` |
| 官方写法 | Alook浏览器（全小写 `alook` 是市场与网盘里的写法，官方页面用 `Alook`） |
| 开发商 | 保定乐活网络科技有限公司 |
| 系统要求 | Android 8.0 以上（以下载页当时显示为准） |

官方唯一的网站入口是 [alookweb.com](http://alookweb.com/)，iOS 版在 App Store 里搜索即可（应用页 [apps.apple.com/cn/app/id1261944766](https://apps.apple.com/cn/app/id1261944766)）。安卓版在官网也有下载入口，价格方面 iOS 版是付费应用、安卓版免费，具体价格以商店页面当时显示为准。

## 二、拿安装包

你有两条路，按自己情况选：

1. **从上面的夸克网盘转存**：打开 [alook浏览器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6f2c026cdc23)，把文件夹转存到自己的网盘后再下载。转存的好处是链接失效了也能在自己网盘里找到，适合长期留存。
2. **从官网下最新版**：打开 [alookweb.com](http://alookweb.com/)，点安卓版下载。官网拿到的永远是当前最新版。

两者的差别只在版本：网盘里那一份是采集当时（2026-09-22）的 11.0 版、85.81M；官网那一份会随更新变化。版本号以包的实际属性为准，别拿网上的介绍文对照。

下载 APK 时注意看文件大小，与 85.81M 差得离谱（比如只有几 MB）多半是下载站的引导页而不是安装包本身。

拿不准包有没有被换过，可以核对 MD5：网盘里 11.0 版那份的 MD5 是 `4e030507da65813d15766860c28cdddf`（用任意 MD5 校验工具算一下，一致即同一份文件）。官网下载的新版以官方当时公布的数值为准。

## 三、安装步骤

1. 把 APK 传到手机：网盘客户端里下载、浏览器直接下载、数据线拷贝都行。
2. 点 APK 开始安装。系统若弹出「禁止安装来自此来源的应用」，是让你给**当前这个安装来源**（比如浏览器或网盘）开一次「允许安装未知应用」，确认后返回继续装。
3. 装完打开，首次启动会让你选主页风格：**经典**（接近传统浏览器的网址导航页）或**现代**（搜索框居中的极简页）。选哪个都能随时在设置里改。
4. 进入后先看一眼菜单里的设置，把后面几节提到的权限按需打开。

低版本系统装不上时，先核对是不是系统低于 Android 8.0 —— 这是安装失败最常见的原因，更多排查见 [常见问题排查.md](常见问题排查.md)。

## 四、它会要哪些权限，给不给

安装后系统或应用会逐项要权限。对照下表处理即可，前两项之外都可以先拒绝，用到再开：

| 权限 | 用在哪 | 建议 |
| --- | --- | --- |
| 存储 | 下载文件、管理压缩包 | 要用下载/文件管理就给 |
| 悬浮窗 | 视频悬浮播放 | 想边聊边看就给，见 [视频倍速与悬浮播放设置.md](视频倍速与悬浮播放设置.md) |
| 摄像头 | 扫二维码 | 用到扫码再给 |
| 通知 | 显示下载与播放进度 | 可给可不给 |
| 位置 | 网站自己要定位时用，Alook 不主动取位置 | 一般拒绝，不影响浏览器本身使用 |

位置这一项官方与应用市场的说明一致：是网页要地理位置时才触发的可选项，拒绝后浏览器功能不受影响。

## 五、升级与回退

- **升级**：官网下载新版 APK 直接覆盖安装，数据（书签、脚本、设置）会保留。
- **回退**：安装低版本前要先卸载，卸载会清掉书签与脚本 —— 有回退需求先在设置里导出书签备份。
- 版本号规则是「大版本 + 小数点迭代」（如 10.9 → 11.0），每次更新内容可以在应用市场的历史版本页看到，以官方页面当时显示为准。
