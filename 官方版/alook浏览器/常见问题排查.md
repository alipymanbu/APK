## 一、安装失败或装不上

按顺序排除，走到能装为止：

1. **系统版本太低**：要求 Android 8.0 以上（以下载页当时显示为准），在 设置 → 关于手机 里查版本。
2. **安装来源没授权**：弹「禁止安装」时，去给当前来源开「允许安装未知应用」，见 [下载与安装教程.md](下载与安装教程.md) 第三节。
3. **安装包不完整**：下载中断过、文件比 85.81M 小一截，删掉重下；拿不准就重新转存一份 [alook浏览器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6f2c026cdc23)。
4. **存储空间不足**：85.81M 的包安装时还要解压空间，先清出几百 MB。
5. **与已装的同名包签名冲突**：手机上如果有别的渠道版 `alook.browser`，先卸载再装。

## 二、打不开 / 闪退

- **先重启再定位**：重启手机后还闪退，才往下查。
- **清缓存**：长按图标 → 应用信息 → 存储占用 → 清理缓存（清数据会删书签与脚本，先在设置里导出书签）。
- **查权限**：应用信息 → 权限，把存储等核心权限打开。
- **查空间与内存**：后台开太多、机身存储见底都会让应用起不来。
- **升级或重装**：覆盖安装最新版；仍闪退则卸载重装（**会丢书签与脚本**，先备份）。

## 三、悬浮窗点了没反应

九成是没给悬浮窗权限：设置 → 应用 → Alook浏览器 → 权限 → 允许「在其他应用之上显示」（有的系统叫「悬浮窗」「显示在其他应用上层」）。给完权限重新点悬浮按钮。仍不行见 [视频倍速与悬浮播放设置.md](视频倍速与悬浮播放设置.md)。

## 四、视频没声音 / 投屏找不到设备

- 没声音：先查媒体音量；再看是否被浏览器静音（播放器里有音量键）；切后台后没声属部分网站限制，见播放那篇第四节。
- 投屏找不到电视：手机与电视必须在**同一个 Wi-Fi**；电视的 DLNA/投屏功能要开着；路由器开了「AP 隔离」会挡住设备互见，去路由器设置里关掉。

## 五、脚本装了不生效

四条最常见原因（匹配值、扩展类型、没刷新、站点 CSP）在 [油猴脚本安装方法.md](油猴脚本安装方法.md) 第四节逐一列了。补充一条：脚本代码粘贴时缺了头尾（`// ==UserScript==` 块没复制全），扩展会静默不执行 —— 对照脚本站的代码重粘一遍。

## 六、广告拦不住 / 页面显示错乱

单个广告位漏掉用手动标记；整站错乱说明规则对该站误伤，按站点关拦截 —— 处理路径在 [广告拦截与阅读模式使用.md](广告拦截与阅读模式使用.md) 第二、三节。

## 七、下载失败或找不到下载的文件

1. 存储权限没开 → 应用信息里补开；
2. 个别链接下载失败（有用户反馈遇到过）→ 重试一次，或在设置里接第三方下载器（ADM、IDM）接管；
3. 文件位置 → 菜单 → 下载/文件管理里找，下载路径在设置里可改；
4. 下载的是分段流（M3U8）时，最终会合成一个视频文件，合成期间别杀后台。
