## 一、谁需要执照

- 操控**小型、中型、大型**民用无人驾驶航空器，需要取得操控员执照；
- 操控**轻型**无人机不需要执照，但你应当熟练掌握操作方法、了解管理制度；打算飞非适飞空域的执照持有人，还有配套的**非适飞空域飞行理论培训**要完成。

考试相关的新规以民航局发布的文件为准，官网政策法规区可查《民用无人驾驶航空器操控员执照考试管理办法》《民用无人驾驶航空器操控员执照考试点管理办法》《民用无人驾驶航空器操控员执照考试委任代表管理办法》（均为 2024 年发布）。

## 二、App 里的执照相关功能

「办事」里的操控员资质板块包含这些功能：

| 功能 | 谁在用 |
| --- | --- |
| 飞行记录本 | 自学考生、执照持有人 |
| 飞行记录确认 | 教员 |
| 签注申请 / 签注审批 | 前者面向自学考生与执照持有人，后者由教员操作 |
| 理论考试申请 | 自学考生、执照持有人 |
| 实践考试申请 | 自学考生、执照持有人 |
| 成绩查看 | 执照持有人 |
| 执照申请 | 自学考生 |
| 我的执照 | 执照持有人 |
| 非适飞空域飞行理论培训 / 理论合格证 | 执照持有人 |
| 考次链接 / 机构密码 / 实践成绩录入 | 考试员、考试方 |

## 三、自学考生的大致顺序

1. 先在官网 [https://uom.caac.gov.cn](https://uom.caac.gov.cn) 的信息查询区查「培训机构查询」「考试地点及时间查询」，确认考点与考次安排，决定自学还是报班；
2. App 里提交**理论考试申请**；
3. 理论通过后提交**实践考试申请**；
4. 在「成绩查看」里确认成绩；
5. 提交**执照申请**，通过后在「我的执照」里查看执照。

期间用「飞行记录本」记录飞行时间；教员一侧通过「飞行记录确认」「签注审批」配合你完成对应环节。

## 四、培训与考试的查询入口

官网首页的信息查询区里与执照有关的入口还有：考试服务方查询、培训机构查询、考试地点及时间查询。报名缴费前先把这些查清楚，再排自己的时间；执照拿到手之后，飞管制空域还要走飞行活动申请，见 [飞行活动申请与空域规定.md](飞行活动申请与空域规定.md)。
