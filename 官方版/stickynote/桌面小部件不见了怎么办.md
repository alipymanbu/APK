# Sticky Notes 桌面小部件不见了怎么办

> 本篇专讲一类高频故障：桌面上的 Sticky Notes 便签部件消失了，或者小部件列表里根本找不到它。先按第一节判断你属于哪种情况，再对号入座。恢复后重新贴部件的步骤见[主屏幕小部件设置.md](主屏幕小部件设置.md)。

## 一、先分清三种情况

| 现象 | 说明 | 看哪节 |
| --- | --- | --- |
| 桌面上原来贴着的部件没了，但长按桌面 → 小部件列表里还能找到 Sticky Notes | 部件被移除了，应用本身还在 | 第二节、第三节 |
| 桌面部件没了，小部件列表里也找不到 Sticky Notes 这一项 | 系统层面认定应用「不可用」了，多数是应用位置或状态问题 | 第三节、第四节 |
| 部件还在但显示空白/加载失败 | 内容层问题 | 第五节 |

## 二、最常见也最容易被忽视的原因：应用在 SD 卡上

应用装在（或被移动到）SD 卡上时，Android 经常无法创建或维持它的小部件 —— 开机时 SD 卡挂载慢或未挂载，桌面就会把部件丢掉。这是多个独立来源都证实过的平台行为，不是这个应用独有的毛病。

处理：把应用移回内部存储。

1. 打开手机「设置」→「应用」（或「应用管理」）。
2. 找到 Sticky Notes，进「存储」。
3. 有「更改存储位置」选项且当前是 SD 卡的，改回「内部存储」。
4. 重启手机，重新添加部件。

部分新系统已经没有「移到 SD 卡」选项，那这一条可以跳过，说明应用本来就在内部存储。

## 三、桌面与系统层面的排查

按顺序试，每做完一步回桌面看看部件是否回来：

1. **重启手机**。桌面（launcher）负责加载部件，重启会让它重新拉一遍所有部件，多数「莫名消失」到这一步就好了。
2. **确认应用还在**：桌面图标还能点开、应用列表里还在，说明应用没被卸载；图标没了就去重新安装（装之前先看[备份恢复与密码保护.md](备份恢复与密码保护.md)，确认有没有备份可救）。
3. **检查是否锁了桌面布局**：部分系统开了「锁定桌面布局」后，被清掉的部件不会自动恢复，也不会让你重新拖放，先把这个开关关掉再操作。
4. **清桌面的缓存**：设置 → 应用 → 找到当前桌面（名字通常是「系统桌面」「XX 桌面」「launcher」）→ 存储 → 清除缓存，然后重启。注意是清「缓存」不是清「数据」，清数据会重排你的桌面图标。
5. **换个桌面试试**：装一个第三方桌面（如 Niagara、Nova 这类），看部件列表里能不能找到。能找到，说明问题出在原桌面的兼容性上，不能找到，问题在应用或系统层。

## 四、国产系统的两个额外拦截点

MIUI、EMUI/HarmonyOS、ColorOS 这类深度定制系统，还有两道闸会「弄丢」部件：

- **省电策略**：进系统的电池/省电设置，找到 Sticky Notes，允许它「自启动」「后台运行」，取消深度省电限制。后台被杀虽不至于删部件，但会导致部件长时间不刷新、点开没反应，看起来像坏了。
- **应用被「深度清理」卸载或停用**：有些系统的清理工具会把不常用应用停用甚至卸载。在设置的「应用」里确认它的状态是「已启用」，被停用的重新启用即可。

## 五、部件在但内容不对

- **空白**：先打开应用本体确认便签还在。应用里有便签而部件空白，重启手机；应用里也没了，看[备份恢复与密码保护.md](备份恢复与密码保护.md)第二节用备份恢复。
- **内容不更新**：改了便签桌面不跟着变，同样是后台被杀的典型表现，按第四节把省电限制放开。
- **手写便签显示异常**：确认是小部件规格问题还是绘制内容问题，把这张部件删掉重贴一次最快。

## 六、都试过还不行

把应用卸载重装是最后的常规手段，重装前务必先完成两件事：确认应用还能打开（能打开就先备份一次），以及把之前留过的备份文件复制到手机之外。重装后按[主屏幕小部件设置.md](主屏幕小部件设置.md)重新贴部件。若重装后小部件列表里仍然没有它，多半是当前系统版本与这个 2022 年的包不兼容，可以到[常见问题解答.md](常见问题解答.md)看看新旧版本的取舍再决定。
