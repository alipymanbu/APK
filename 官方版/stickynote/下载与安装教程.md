## 一、安装包基本信息

先对一下参数，确认你拿到的是这份包（这些数值以安装包本身为准，网上商店列的是官方最新版，数字对不上不奇怪）：

| 项目 | 数值 |
| --- | --- |
| 应用名称 | Sticky Notes（当时官方名 Sticky Notes + Widget，现已更名 WeeNote） |
| 版本 | 4.3.4 |
| 包名 | `com.symcoding.widget.stickynotes` |
| 安装包大小 | 6.26M |
| MD5 | `5A3B0F601CEBF7F8964CEA35C46DA5F9` |
| 系统要求 | 安装包标注需 Android 5.2 以上 |
| 开发者 | SYM Coding |

几条要提醒的：

- 4.3.4 是 2022 年初的版本，那时候应用还叫 Sticky Notes + Widget，界面语言为英文（商店资料标注语言为 English）。
- 这是直接安装 APK 的侧载方式，不走应用商店，过程中不需要登录任何账号。
- 装完它就是一个普通应用 + 一个桌面小部件，没有账号注册环节。

## 二、获取安装包

从 [stickynote 安装文件资源（夸克网盘）](https://pan.quark.cn/s/473575336b7d)转存到自己账号后下载即可。如果不放心文件完整性，下载后可以核对 MD5：手机上用带校验功能的文件管理器，或把文件传到电脑上用 `certutil -hashfile 文件名.apk MD5` 这类命令比对，结果应与表中的 MD5 一致。

## 三、安装步骤

1. 把 APK 文件放进手机存储（网盘 App 直接下载，或电脑传过去）。
2. 在文件管理器里点这个 APK。首次安装侧载应用时，系统会提示「禁止安装未知来源应用」，按提示允许该文件管理器「安装未知应用」的权限再继续（不同品牌入口不同，一般在弹窗里点「设置」→ 打开开关 → 返回继续）。
3. 点「安装」，等进度走完。
4. 装完点「打开」直接进应用，或回到桌面找图标。

部分品牌（如小米/华为）还会额外询问「是否允许查看联系人/媒体」之类的权限确认，属于系统安装流程的一部分，按需允许即可。

## 四、安装失败怎么办

按提示对号入座：

| 系统提示 | 原因 | 处理 |
| --- | --- | --- |
| 「应用未安装」且手机里已有同名便签应用 | 已装过同包名的其他版本（比如从 Google Play 装的新版 WeeNote），签名不一致 | 先卸载已有的那个再装；卸载会连带删掉它里面的便签数据，重要内容先按[备份恢复与密码保护.md](备份恢复与密码保护.md)做一次备份 |
| 「解析包时出现问题」 | 文件没下完整，或传输中被改坏 | 重新下载一次，再核对 MD5 |
| 提示系统版本过低 | 手机系统低于安装包要求 | 换更高版本的包（官方新版要求 Android 11 以上，见[常见问题解答.md](常见问题解答.md)里的版本说明） |
| 提示存储空间不足 | 剩余空间不够 | 清出至少几百 MB 再装 |

不知道自己手机是什么系统版本的，进「设置 → 关于手机」看「Android 版本」一行，拿这个数去和表里的要求对。

## 五、装完先做什么

先打开应用建一两张便签（打字或手写都行，怎么用见[便签与手写功能.md](便签与手写功能.md)），再回到桌面把小部件加上 —— 小部件显示的就是应用里的便签，里面没内容时桌面上的部件是空的。添加小部件的步骤在[主屏幕小部件设置.md](主屏幕小部件设置.md)里逐条写了。
