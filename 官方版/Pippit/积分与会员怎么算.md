## 一、免费账号能做什么

Pippit 有一个长期免费的档位，不需要绑卡就能开始用。免费档能用的功能包括：

| 能用的 | 说明 |
| --- | --- |
| 每日／周期性免费额度 | 官方资料里提到免费账号每周约有 150 点额度，大致够生成约 2 分钟视频或 75 张图片；**这个数值会调整，以官方页面当页标注为准** |
| 视频智能体 | 用提示词、链接或素材生成视频 |
| 参考爆款视频 | 参考热门视频的结构与风格做同款 |
| 说话照片 | 上传照片让它开口说话 |
| 图片智能体 | 用描述生成商品图、海报 |
| 数字人视频 | 用库里的角色生成口播视频 |
| 免费照片数字人 | 免费档可做 3 个照片数字人，覆盖 30 种以上语言 |

需要注意最后一条注脚：**免费档里「部分功能会消耗点数」**——不是所有操作都免费，用之前看清该功能旁边有没有标消耗。

关于免费额度什么时候发，有**两种口径**，都列出来供你对照：官方价格页写的是「每日领取免费点数」，多篇第三方评测与整理文章则说免费额度是**每周一发一次、约 150 点**。两边说的可能是同一套机制的两个侧面（每天有可领的小额、外加每周的额度包），也可能其中一个已经过期。**以 App 内的账户页与官方价格页当页显示为准**，不要以任何一篇第三方文章的数字为准。

免费档到底能用哪几个模块，同样存在口径差：官方价格页把视频智能体、参考爆款视频、说话照片、图片智能体、数字人视频都列在免费档内；而部分第三方评测称免费档实际只开放「链接转视频」和「数字人」这两块。**两边并列，以 App 内当页能否点开为准。**

## 二、额度是按什么扣的

点数不是按「点一次扣一次」这么简单，同一条视频的消耗和这几项直接相关：

- **分辨率**：480p 和 1080p 的消耗差好几倍，2K／4K 更高；
- **时长**：秒数越长扣得越多，这是最容易失控的一项；
- **模型**：越新、越高质量的模型单次消耗越高，快速档明显便宜；
- **任务类型**：视频比图片贵，数字人与说话照片又各有一套计价。

所以省额度的思路很明确：**先用快速档和低分辨率出草稿定内容，定稿之后再换高质量档重出一次**。反过来先上最高档再反复微调，是浪费最快的方式。

## 三、付费档差在哪

付费分若干档（官方在用的是 Starter、Plus、Pro 这几档，Promo 期间还会出现更高的档位），按月或按年订阅。相较免费档，付费档主要买到这些：

| 付费才有的能力 | 说明 |
| --- | --- |
| 去水印 | 免费账号导出的成品带平台水印，去水印是付费能力。**操作位置在导出弹窗里**：导出 → 下载 → 选「不带 Pippit 水印」这一项，账户有会员权益时才可选 |
| 放大到 2K／4K | 免费档在分辨率上有上限 |
| 高级模型 | 部分新模型只在付费档开放 |
| 更快的生成 | 同样的模型，付费档出片更快 |
| 更多并发生成 | 一次能同时跑的任务数更多 |
| 定制数字人数量 | 免费档 3 个照片数字人，付费档放开到更多，视频数字人也按档给名额 |
| 存储空间 | 付费档给到数百 GB，最高档给无限存储 |

**各档的具体价格、点数与权益会随活动变化**，官方价格页有月付／年付切换，且标注「自动续订、随时可取消」。下单前请直接看 [官方价格页](https://www.pippit.ai/pricing) 当页显示的数字，不要以别处的转述为准。

## 四、点数与货币符号怎么读

官方价格页上的点数配了一个专用的货币符号（页面里带星形标记的那个数就是点数）；同一笔钱在不同区域的页面换算出来的点数不一样（美元、新加坡元等区域各自计价）。**换区之后价格与点数都会变**，看价格时先确认左上角选的区域和币种是不是你要付的那个。

## 五、几个容易踩的坑

- **以为免费额度是无限续的**：免费额度按周期发放，用完了要等下个周期或升级，不是随时补；
- **在不知道会扣点的功能上反复试**：先看清按钮附近有没有消耗标注；
- **订阅了忘记取消**：付费档默认自动续订，不用了要在账户里主动取消，取消后仍在当前周期内有效；
- **拿别处的报价当准**：价格与权益变动频繁，任何第三方的转述都可能过期，只认官方价格页。

额度明明够却提示不足、或者被重复扣点，先看 [常见问题与排查.md](常见问题与排查.md) 的额度一节。
