## 二、安装步骤

安装包还没转存到手机的话，先从 KillApps [安装文件资源（夸克网盘）](https://pan.quark.cn/s/727bef67e262)把文件下到手机存储里，然后按下面的顺序做：

1. 在文件管理器里找到下载好的 `.apk` 文件，点它。
2. 系统会弹出「是否允许安装未知应用」之类的提示——这不是错误，因为这个包不是从应用商店装的。选「仍要安装」或「设置」继续。
3. 如果进了设置页，把你用来下载的来源（浏览器、网盘客户端）里的「允许安装未知应用」开关打开，返回重试。
4. 点「安装」，等进度条走完，点「打开」或回桌面找图标。

装完先别急着清理后台——KillApps 首次打开必须先开无障碍权限，否则主界面那个按钮点了也不会动，具体走一遍 [无障碍权限开启教程.md](无障碍权限开启教程.md)。

## 三、想核对安装包是不是这一版

网盘转存、多次中转之后，如果你怀疑文件损坏或被换过，可以核对 MD5：

- **在电脑上（Windows）**：打开 PowerShell，执行下面这行，把输出的值和第一张表里的 MD5 对一下：

  ```powershell
  Get-FileHash "C:\下载目录\KillApps_v1.48.3.apk" -Algorithm MD5
  ```

- **在电脑上（macOS / Linux）**：

  ```bash
  md5sum KillApps_v1.48.3.apk
  ```

- **在手机上**：不少文件管理器（如 MT 管理器、Mixplorer）长按文件就有「属性 / 校验」入口。

两边一致说明文件完整。对不上就别装了，重新下载一份再核对。

## 四、升级与覆盖安装

- **从小版本升上来**：直接用新 `.apk` 覆盖安装即可，签名一致时系统会原地升级，已开的无障碍权限和例外列表一般会保留。
- **覆盖后权限被重置**：部分厂商系统在大版本升级或覆盖安装后会把无障碍权限收回去，表现是打开应用后点了没反应，回到 [常见问题与权限失效排查.md](常见问题与权限失效排查.md) 重新开一遍就行。
- **卸载重装**：设置会被清空，例外列表需要重新加，不建议为了「清干净」随便卸载。
- **不建议同时留两个来源的版本**：比如商店装一份、安装包再覆盖一份，签名或渠道不一致时会出现安装冲突，留一份就好。
