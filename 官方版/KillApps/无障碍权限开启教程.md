## 一、这个权限到底用来干什么

KillApps 替你做的事，本质上是把你本来要手动走的流程自动化了：一个一个进系统设置 → 应用信息 → 点「强行停止」。系统不允许普通应用替你点别的应用的按钮，但允许「无障碍服务」读取屏幕内容并模拟点击——所以它需要这个权限才能干活。

按官方说明，这个权限在 KillApps 里干两件事：

- 读取当前窗口内容，在系统设置界面里找到「强行停止」那个按钮，模拟一次点击；
- 观察界面之间的跳转，好知道上一个应用关完了、该关下一个了。

另外它还会申请「显示在其他应用上层」的权限，用来在关闭过程中盖一层等待画面，防止你中途误点。

理解了机制你就明白两件事：**权限一关，应用立即失去关闭其他应用的能力**（界面还在，按钮点下去没效果）；关闭过程中屏幕会自己跳来跳去，那是它在替你操作，别碰。

## 二、开启步骤（通用路径）

1. 打开 KillApps，首次进入一般会直接弹出权限引导页，点引导里的开关会自动跳到系统设置；没弹的话走下面手动路径。
2. 打开系统「设置」。
3. 找到「无障碍」（有的系统叫「辅助功能」）。
4. 进「已下载的应用」「已安装的服务」或「更多下载的服务」这一类子菜单。
5. 在列表里找到 KillApps，点进去。
6. 打开开关，在确认弹窗里点「允许」。
7. 回到 KillApps，把「显示在其他应用上层」的弹窗提示也一并允许。

开完主界面顶部一般会显示就绪状态，这时再去做一次完整关闭试试：[一键关闭后台应用教程.md](一键关闭后台应用教程.md)。

## 三、各厂商系统的菜单位置差异

上面的通用路径在不同系统里入口藏的位置不一样，常见几种（菜单名以你手机实际显示为准）：

| 系统 | 大致路径 |
| --- | --- |
| 小米 MIUI / 澎湃 OS | 设置 → 更多设置 → 无障碍 → 已下载的应用 |
| 华为 / 荣耀 | 设置 → 辅助功能 → 无障碍 → 已下载的应用 |
| OPPO / ColorOS、一加 | 设置 → 其他设置（或「密码与安全」下）→ 无障碍 |
| vivo / OriginOS | 设置 → 快捷与辅助 → 无障碍 |
| 三星 One UI | 设置 → 辅助功能 → 已安装的服务 |
| 原生类系统（Pixel 等） | 设置 → 无障碍 → 已下载的应用 |

找不到就干脆用设置首页顶部的搜索框，直接搜「无障碍」两个字。

还有一项容易被漏掉：小米 MIUI / 澎湃 OS 上有一个独立的「后台弹出界面」权限，默认是拒绝的。KillApps 清理时要从后台跳转系统设置页面逐个操作，这项不开，关闭流程会被系统拦住、跑一半就停。入口在 应用管理 → KillApps → 其他权限 里，允许即可。

## 四、开完总被关掉，是系统干的

很多手机会主动「清理」后台里的无障碍服务——尤其是国产定制系统，省电策略激进时，无障碍开关会被直接拉回关闭。表现就是：昨天还好好的，今天打开 KillApps 又要你重新开权限。

这类问题有固定的处理套路（电池不优化、允许自启动、后台加锁），各品牌的逐条设置路径在 [保持后台运行不被系统清理的设置.md](保持后台运行不被系统清理的设置.md)，出了症状再按 [常见问题与权限失效排查.md](常见问题与权限失效排查.md) 排查。

## 五、这个权限安全吗，能随时收回吗

- 官方说明里写明应用不收集数据，无障碍权限只用于完成「代替你点强行停止」这一个动作。是否信任由你自己判断；介意的话不用这个功能就好。
- 你随时可以在系统设置的无障碍列表里把开关关掉，收回权限后 KillApps 只是不能替你关后台，其他不受影响。
- 想彻底移除权限，卸载应用即可，系统不会留残留授权。
