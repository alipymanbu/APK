## 一、症状速查表

| 症状 | 最可能的原因 | 先做什么 |
| --- | --- | --- |
| 点了关闭按钮毫无动静 | 无障碍权限没开或被系统收回 | 回到 [无障碍权限开启教程.md](无障碍权限开启教程.md) 重新开 |
| 开关开着但过两天又关了 | 系统省电策略杀掉服务 | 见下面第二节，逐条做 [保活设置](保持后台运行不被系统清理的设置.md) |
| 关闭到一半停了 | 流程被你切走或弹窗打断（小米系统先查「后台弹出界面」权限） | 回前台重跑一轮，过程中别碰手机 |
| 某些应用怎么都关不掉 | 厂商限制或应用立刻自启 | 见第四、五节 |
| 桌面小组件点不动 | 权限失效或应用被系统杀掉 | 见第三节 |
| 清理后更卡更耗电 | 关停的应用被反复唤醒重启 | 见第六节 |
| 收不到消息 / 闹钟没响 | 目标应用不在例外列表里 | 见 [白名单与自动清理设置.md](白名单与自动清理设置.md) |

## 二、无障碍权限总被自动关闭

这是这类工具在国产系统上最常见的问题，根源是省电策略把无障碍服务连同后台一起清了。处理顺序：

1. **重新开权限**：系统设置 → 无障碍 → KillApps，重新打开开关。
2. **电池放行**：系统设置 → 应用管理 → KillApps → 电池（耗电管理），选「不优化」「无限制」或「允许后台运行」。
3. **允许自启动**：应用信息里的「自启动」开关打开，不然重启手机后服务起不来。
4. **后台加锁**：在最近任务卡片上长按或下拉，选锁定，防止手动划掉时被一并清理。
5. **重启验证**：重启手机后再看权限是否还开着。某些系统重启会收回无障碍权限，那就只能每次重启后检查一遍，这类行为由系统决定，应用侧改不了。

如果这些做了仍然频繁失效，查一下系统更新日志或社区——部分厂商系统版本会主动回收无障碍权限，属于已知系统行为。各品牌的完整保活路径（含小米的「后台弹出界面」）单独整理在 [保持后台运行不被系统清理的设置.md](保持后台运行不被系统清理的设置.md)。

## 三、桌面小组件点不动

小组件只是主界面那个按钮的快捷方式，自己不带权限，它失灵的原因和主按钮失灵是一回事。按这个顺序过一遍：

1. 打开 KillApps 本体，确认无障碍权限还开着、主按钮还能用。主按钮好使、只有小组件不好使，才往下走。
2. 确认 KillApps 没被系统杀掉：按 [保活设置](保持后台运行不被系统清理的设置.md) 做一遍，特别是电池不受限和后台加锁。
3. 把桌面上的小组件删掉，重新从小组件列表里拖一次。
4. 重启手机再加一次。桌面启动器（桌面程序）偶发抽风时，这一步能解决。

## 四、点了关闭但有的应用关不掉

分三种情况：

- **个别应用关不掉**：厂商系统保护的组件（比如系统桌面、输入法、电话相关）不允许被强行停止，这是系统限制，不是操作问题。
- **关掉了马上又活**：见下一节。
- **全部都关不掉**：基本就是权限问题，回第二节。

另外注意，列表里的系统应用别乱关。KillApps 把用户应用和系统应用分开了，清理时优先只处理你认识的那部分，核心系统进程被强行停止可能造成桌面卡顿、功能异常，重启才能恢复。

## 五、应用刚清掉就自己复活了

强行停止只是终止当下，很多应用有自启动机制：收到推送、开机事件、其他应用唤醒时会被系统重新拉起。所以「清完 10 分钟又冒出来」是正常现象，不是清理失败。

想让它安静，要到系统设置里做，不是反复清：

- 系统设置 → 应用管理 → 该应用 → 关闭「自启动」；
- 通知管理里收紧它的通知权限，削弱它唤醒自己的理由；
- 部分系统有「关联启动」开关，一并关掉。

反复强停又反复被唤醒的应用，清理收益是负的（见下一节），不如直接断掉它的自启动。

## 六、清理后手机反而更热、更耗电

有一种情况确实会发生：应用被强行停止后，系统或推送通道很快把它重新拉起，冷启动比保持后台更耗资源。如果你每隔几分钟清一次、应用每隔几分钟被唤醒一次，总开销反而上升。

合理的用法是：

- **时机**：在感觉明显变卡、变热时清一轮，或配合锁屏自动清理一天几次，而不是隔几分钟点一次；
- **对象**：重点处理那些长期驻留、持续联网但你并不在用的应用；把聊天工具这类需要实时推送的放进 [例外列表](白名单与自动清理设置.md)；
- **根治**：对反复复活的应用，按第五节断自启动，比每天手动清有效。

## 七、隐私与数据安全

- 按官方说明，KillApps 不收集数据；无障碍权限的用途限定为「代替你完成强行停止的操作」。是否采信由你自己决定，权限也随时可以在系统设置里收回。
- 强行停止会丢未保存的进度：清理前确认没有正在输入的草稿、进行中的下载或上传。
