# 保持后台运行不被系统清理的设置

> 用 KillApps 做自动清理，前提是它自己不被系统杀掉。本篇按品牌给出「允许后台运行、不被省电策略清理」的具体设置路径——这些设置对任何需要常驻后台的应用都适用。

## 一、为什么会被系统清理

省电策略激进、功能权限默认收紧，这是各家系统共同的思路：对普通应用，后台能杀就杀。而 KillApps 的自动清理要靠无障碍服务常驻，锁屏自动清理更要在后台自己跑起来——它偏偏就是被清理逻辑针对的那类应用。所以要在系统里给它开三样东西：**自启动、电池不受限、任务不被划掉**。权限本身的开法见 [无障碍权限开启教程.md](无障碍权限开启教程.md)，本篇只管「开了之后怎么让它活下去」。

## 二、按品牌设置（菜单名以你的系统实际显示为准）

**小米 MIUI / 澎湃 OS**

1. 设置 → 应用设置 → 应用管理 → KillApps → 自启动：打开。
2. 同一页 → 省电策略 → 无限制。
3. 同一页 → 其他权限 → 「后台弹出界面」：允许。这项默认是拒绝的，不开的话自动清理从后台跳转系统设置页面的动作会被拦住，清理会卡住或无效。
4. 最近任务界面，长按 KillApps 卡片 → 加锁。

**华为 / 荣耀**

1. 设置 → 应用 → 应用启动管理 → KillApps：关掉「自动管理」，手动管理里把「允许自启动」「允许关联启动」「允许后台活动」三项都打开。
2. 电池 → 更多电池设置里若有「休眠时始终保持网络连接」类选项，按需开启。
3. 最近任务界面下拉 KillApps 卡片加锁。

**OPPO / ColorOS、一加**

1. 设置 → 应用 → 应用管理 → KillApps → 电池使用 → 允许完全后台行为（或「不优化」）。
2. 应用信息 → 其他权限里留意「后台弹出界面 / 后台弹窗」类开关，打开。
3. 最近任务卡片下拉加锁。

**vivo / OriginOS**

1. 设置 → 应用 → 权限管理 → KillApps → 自启动：允许。
2. 电池 → 后台高耗电：允许 KillApps。
3. 最近任务卡片下拉加锁，防止一键清理时被顺手划掉。

**三星 One UI**

1. 设置 → 电池 → 后台使用限制 → 深度休眠 / 让未使用的应用进入休眠：把 KillApps 从限制列表里排除。
2. 设置 → 应用 → KillApps → 电池 → 不受限制。
3. 最近任务卡片右下角图标 → 保持在此应用（加锁）。

**原生类系统（Pixel 等）**

1. 设置 → 应用 → KillApps → 电池 → 不受限制（Unrestricted）。
2. 原生系统对无障碍服务相对宽容，一般做到这一步即可。

## 三、设置完怎么验证

1. 锁屏放 10 分钟以上，解锁后打开 KillApps，看 [自动清理](白名单与自动清理设置.md) 是否执行过、无障碍开关是否仍处于打开状态。
2. 重启手机，再看权限和设置是否都还在。部分系统重启后会收回无障碍权限，这个行为改不了，只能每次重启后补开一次。
3. 还是不行，按症状查 [常见问题与权限失效排查.md](常见问题与权限失效排查.md)。

这些设置做完受益的不只是 KillApps——所有需要常驻的应用（手环连接、天气、日历提醒）被误杀的概率都会明显下降。
