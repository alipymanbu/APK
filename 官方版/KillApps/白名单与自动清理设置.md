## 一、先想清楚谁不能被关

清理按钮不认人，列表里的都会被强行停止。所以在第一次点「关闭所有应用」之前，先把你需要它一直活着的应用加进例外列表（也叫忽略列表）。判断标准就一条：**这个应用需要随时给你推送、或者一被停止你就麻烦，那它就该进例外列表**。常见的有：

| 类型 | 例子 | 关掉的后果 |
| --- | --- | --- |
| 聊天 / 邮件 | 微信、QQ、Telegram、邮箱 | 收不到新消息通知，打开才刷新 |
| 闹钟 / 日程 | 系统时钟、提醒类应用 | 闹钟不响，这是最不该省的一项 |
| 音乐 / 播客 | 后台放歌的应用 | 歌直接停 |
| 导航 | 地图导航 | 路线引导中断 |
| 下载 / 同步 | 网盘同步、下载器 | 任务停在中途 |
| 手环 / 智能家居 | 蓝牙连接类应用 | 断连，要重新配对或打开 |

吃内存的大头（游戏、购物、短视频）恰恰是清理的主要目标，别加进例外就行。例外列表控制的是 KillApps 关谁，和系统自己杀不杀后台是两回事，后者要去系统设置里管。

## 二、怎么加、怎么移除

1. 打开 KillApps，进「设置」或主界面的例外列表入口（不同版本叫法可能是「例外」「忽略」「白名单」）。
2. 点「添加应用」，在弹出的应用列表里勾选要保住的那些，确认。
3. 之后每次执行关闭，列表内的应用会被自动跳过。
4. 想移除就回到同一个列表，取消勾选即可，立即生效。

例外列表是随应用数据存着的：覆盖升级会保留，卸载重装会清空。所以没到万不得已别卸载重装。

## 三、锁屏自动清理

不想手动点的话，设置里通常有「屏幕关闭时自动关闭应用」（或类似字样）的开关，打开后手机一锁屏，它就自动跑一轮清理，你解锁亮屏时后台是干净的。

配置时注意两点：

- **例外列表同样生效**：锁屏自动清理也是全量动作，微信这类应用不在例外列表里，睡一晚消息就断一晚。
- **间隔选项**：有的版本可以选「立即」或「锁屏后若干分钟」，选个延迟比锁屏立刻杀更稳，给后台正在收尾的下载、同步留点时间。

免费与付费的边界提醒一句：第三方页面介绍的说法是——一键清理、内存监控、白名单、桌面小组件这类基础功能免费，部分高级的自动清理规则属于付费项；具体哪些功能要付费，以你应用内实际显示为准。

## 四、自动清理要持续生效，得先保住两件事

自动清理是个后台动作，它自己也会被系统杀。想让它天天都跑，两个前提缺一不可：

1. **无障碍权限要一直开着**。权限被系统收回，自动清理就名存实亡。各品牌「电池不优化、允许自启动、后台加锁」的逐条路径见 [保持后台运行不被系统清理的设置.md](保持后台运行不被系统清理的设置.md)；权限本身的开法与排查见 [无障碍权限开启教程.md](无障碍权限开启教程.md) 和 [常见问题与权限失效排查.md](常见问题与权限失效排查.md)。
2. **应用本体要活着**。有些系统直接把整个进程冻掉，自动清理自然跑不了。上面三件套（电池 + 自启动 + 后台锁定）同时覆盖了这个问题。

设置完可以自测一下：锁屏等几分钟再解锁，打开 KillApps 看后台列表是否变短、设置里的自动清理记录有没有更新，有就是跑成了。
