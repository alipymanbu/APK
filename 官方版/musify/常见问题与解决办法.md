# Musify 常见问题与解决办法

> 安装失败、搜索找不到歌、播放加载不动、更新出问题——这几类是 Musify 用户问得最多的。本篇按现象给排查方向，多数问题两分钟内能定位。

## 一、装不上或装完闪退

| 现象 | 排查方向 |
| --- | --- |
| 提示「应用未安装」 | 手机里已有另一个渠道的版本（GitHub 版包名 `com.gokadzev.musify`、F-Droid 版 `com.gokadzev.musify.fdroid`），签名不同不能覆盖，先卸载再装；卸载前先导出数据 |
| 提示禁止安装 | 「安装未知应用」权限没给到位，授权对象必须是**你用来打开 APK 的那个应用**（浏览器或文件管理器） |
| 安装进度条走一半失败 | 存储空间不足，或安装包下载不完整，重下并核对 MD5 |
| 装完点开就退 | 重启手机再试；系统版本过旧也会导致，应用对系统有最低版本要求，太老的设备装不动 |

安装步骤细节在 [下载与安装教程.md](下载与安装教程.md) 第三节。

## 二、搜索结果不对或找不到某首歌

- 换个搜法：直接搜歌名结果乱时，先搜歌手名进歌手主页，再从作品列表里找。
- 在线曲库依赖外部平台，**平台上没有或已下架的歌，这里也搜不到、播不了**——这不是你操作的问题。
- 个别地区直连时搜索可能转圈很久，见第四节。

## 三、播放卡住、加载失败

- 先确认网络正常：切一下 Wi-Fi/流量，或用浏览器随便开个网页验证。
- **离线可用的内容不受影响**：断网时能稳定播放的只有你下载过的歌，在线播放断网就停，属于正常边界（见 [下载歌曲与离线收听.md](下载歌曲与离线收听.md)）。
- 长期加载慢或频失败：设置里提供「代理」开关（官方源码里有配套的代理服务实现），受限网络下可以尝试开启代理后重试；设置里找不到这一项说明版本偏旧，可考虑更新。
- 清一次缓存再试：设置里的缓存管理，清完重进。

## 四、更新相关

- **应用内更新**：设置或关于页里检查更新，按提示走完即可。
- **更新失败**：直接去 GitHub 发布页手动下新 APK 覆盖安装：[github.com/gokadzev/Musify/releases](https://github.com/gokadzev/Musify/releases)。
- **F-Droid 版更新慢半拍**：F-Droid 打包有延迟，比官方发布页晚几天属正常；着急就手动装 GitHub 版（注意两渠道包名不同，切换等于重装，先备份数据，见 [歌单导入与数据备份.md](歌单导入与数据备份.md)）。

## 五、其他常见疑问

- **后台播放耗电快**：后台播放 + 在线流是耗电大户，能离线听的场景就播下载好的歌；安卓系统的电池优化对应用限制过狠时，后台播放可能被杀，把 Musify 加进「不限制后台/电池优化白名单」更稳。
- **有没有电脑版、iOS 版**：官方目前只有安卓应用，别下第三方号称同名的桌面软件——存在名称相近但完全不相干的其他产品，认准官方仓库。
- **哪里有官方答疑**：官方仓库的 FAQ 讨论区：[github.com/gokadzev/Musify/discussions/728](https://github.com/gokadzev/Musify/discussions/728)。
- **图标/界面和网上截图不一样**：版本迭代快，旧版截图对不上当前界面很正常，以你手上版本的实际界面为准。
