# 下载的歌存在哪个文件夹

> 在文件管理器里翻不到 Musify 下载的歌？这是正常现象。本篇讲下载文件实际存在哪、为什么找不到，以及想把文件拿出来时有哪些办法。

## 一、官方源码里的答案

Musify 是开源软件，下载逻辑直接写在源码里：下载完成的歌以 `.m4a` 格式存进应用数据目录下的 `tracks/` 文件夹，封面图存到 `artworks/`（`.jpg`），在线播放的临时缓冲放在 `stream_buffer/`。

| 子目录 | 里面是什么 |
| --- | --- |
| `tracks/` | 下载完成的歌曲，`.m4a` 格式 |
| `artworks/` | 对应歌曲的封面图，`.jpg` |
| `stream_buffer/` | 在线播放时的临时缓冲，用完即弃 |

以上以官方主分支源码为准，你手上的版本目录结构可能略有差异。

## 二、为什么文件管理器里找不到

- 这些目录在**系统私有存储**里（路径形如 `data/user/0/<包名>/app_flutter/`，机型不同写法略有差异），普通文件管理器没有权限浏览。
- `Android/data/` 下面也翻不到它，不用在那儿白找。
- 想浏览它得有 root 权限——但没必要，媒体库界面就是看这些文件的正规入口，「下载」一栏列出的就是 `tracks/` 里的全部内容。

## 三、文件名为什么是一串编号

- 文件名用的是歌曲的内部编号，不是歌名，就算翻到了也对不上号。
- 找某首歌有没有下载，直接在应用媒体库里搜，比对着文件名猜快得多。

## 四、想把歌文件拿出来怎么办

- 官方没有提供「把音频文件导出到公共目录」的选项，这些文件也只在应用内能播放。
- 数据导出/备份覆盖的是歌单、收藏与设置偏好，**不含音频文件本身**（见 [歌单导入与数据备份.md](歌单导入与数据备份.md)）。
- 所以卸载前要保住的是「歌单与收藏」（先导出数据），而不是去拷音频文件；新设备上按 [下载歌曲与离线收听.md](下载歌曲与离线收听.md) 重新下载一遍即可。

## 五、stream_buffer 里的东西能当离线歌用吗

不能。它是你在线听歌时落下的临时缓冲，官方源码注释里也写明是临时文件，应用启动时会自动清掉上次残留——断网后它救不了场，稳定离线还得靠 `tracks/` 里正式下载的那份。
