## 三、安装步骤

系统没有拦截时，安装只要几步：

1. 把 APK 文件下到手机存储里（浏览器或文件管理器下载均可）。
2. 在文件管理器里点开这个 APK，系统会弹「是否安装」的确认框，点安装。
3. 第一次侧载会先拦一道「禁止安装未知来源应用」——不是报错，是权限没开。
4. 按弹窗指引进入「安装未知应用」的授权页，给你**用来下载或打开这个 APK 的那一个应用**（浏览器或文件管理器）勾上「允许安装未知应用」。
5. 返回文件管理器重新点开 APK，等安装完成。

不同品牌手机的这个开关藏的位置不一样，找不到时直接在系统设置顶部的搜索框里搜「未知」或「安装未知」二字，比翻菜单快。

## 四、装好之后第一次打开

- 默认界面是英文。进设置（Settings）里的语言项，切换成「简体中文」即可，不用重装。
- 想让它管理手机里已有的本地音乐，需要授予「音乐和音频」/「文件」类权限。
- 不需要注册账号，打开就能用；在线播放依赖网络。

装完先做什么、每个界面是什么，见 [功能与使用入门.md](功能与使用入门.md)。

## 五、更新方式与两个渠道的区别

- 应用内置了更新检查，弹出新版本提示后按提示下载安装即可；也可以隔段时间去 GitHub 发布页手动下新 APK 覆盖安装。
- 注意渠道差异：**GitHub 发布页 / 网盘这份安装包的包名是 `com.gokadzev.musify`**；**F-Droid 版的包名是 `com.gokadzev.musify.fdroid`**。两个包名不同、签名也不同，装了其中一个再装另一个，会作为两个独立应用共存，而不是互相覆盖升级。
- 想从 F-Droid 版换成 GitHub 版（或反过来），先卸载旧的再装新的；歌单和收藏想留着，就在卸载前做一次数据导出，装完再导入，步骤见 [歌单导入与数据备份.md](歌单导入与数据备份.md)。

## 六、安装失败的常见原因

| 提示/现象 | 多半是什么 | 处理 |
| --- | --- | --- |
| 卡在「无法安装」「应用未安装」 | 之前装过另一渠道的包，签名对不上 | 卸载旧版再装（先备份数据） |
| 点开 APK 没反应或提示禁止安装 | 未知来源权限没给对应用 | 按第三节第 4 步给浏览器/文件管理器授权 |
| 安装到一半失败 | 存储空间不足或下载不完整 | 清出空间、重新下载并核对 MD5 |
| 装完点开就闪退 | 系统版本过低，达不到应用的最低系统要求 | 先重启手机；仍闪退去 [常见问题与解决办法.md](常见问题与解决办法.md) 对着排查 |

其他安装类问题，也可以去官方仓库的 FAQ 讨论区查：[github.com/gokadzev/Musify/discussions/728](https://github.com/gokadzev/Musify/discussions/728)。
