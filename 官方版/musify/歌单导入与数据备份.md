# Musify 歌单导入与数据备份

> 你在 Musify 里建的歌单、点的收藏、调的设置，都存在本机。本篇讲怎么自建歌单、把别处的歌单搬进来，以及怎么导出数据——换手机、卸载重装前都该先做这一步。

## 一、自建歌单

- 在媒体库的歌单区新建一个歌单，起名即可。
- 加歌的入口在每首歌的长按/三点菜单里：播放时随手把喜欢的歌加进去，搜索结果里也可以批量加。
- 歌单多了可以收进**文件夹**分组整理，媒体库清爽不少（较新版本支持）。
- 歌单可以重命名、调整顺序、删除；日常维护就是「听到好的就加」，不用专门留时间整理。

## 二、把别处的歌单搬进来

不想一首首重建的话，有两条捷径：

- **用链接添加歌单**：官方支持直接粘贴歌单链接来添加，应用会自动把歌单内容拉进来。
- **导入 Spotify 歌单**：官方 README 列了 Spotify 歌单导入能力，从 Spotify 换过来时先试这条路，能省掉大量手动活。

两种方式的入口都在歌单相关界面里，找不到时在设置或歌单页找「导入/添加链接」字样。不同版本支持的范围可能扩大，以你手上的版本实际界面为准。

## 三、备份：导出与恢复

数据导出是这个应用明确提供的能力，导出的是一份你自己的数据文件：

- **导出**：设置里找「导入与导出/备份」入口，导出的文件包含歌单、收藏与偏好设置这类内容。
- **恢复**：换机或重装后，把导出文件放进新环境，用同一入口选择导入即可。
- 导出文件放手机存储里、或顺手传到网盘/电脑一份，双保险。

## 四、换新手机怎么搬

完整流程串起来是：

1. 旧手机：设置里**导出数据**。
2. 把导出文件传到新手机（聊天工具、网盘、数据线都行）。
3. 新手机：装好 Musify（渠道与包名注意事项见 [下载与安装教程.md](下载与安装教程.md)），设置里**导入**这份文件。
4. 之前下载过的离线歌曲**不会**自动跟过去——数据导入恢复的是歌单与收藏这类信息，离线文件需要在新手机上按 [下载歌曲与离线收听.md](下载歌曲与离线收听.md) 的方法重新下一遍。

## 五、常见误区

- **只卸载不导出 = 歌单清零**：数据存在本机，卸载即清空，重装前务必先导出。
- **换渠道安装也算重装**：从 F-Droid 版切到 GitHub 版（或反过来）是两个独立应用，数据不会自动带过去，同样按上面四步走。
- **备份文件别只存一份**：手机丢了一起丢，导出后多放一个地方。
