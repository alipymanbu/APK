## 一、一次基本转换的完整流程

以「把一个 DOCX 转成 PDF」为例，其他格式的流程完全一样：

1. 打开应用（界面名称是「文件转换器」），主页是一列按类别分的转换器入口：图像转换器、音频转换器、视频转换器、电子书转换器、文件转换器、演示转换器、电子表格转换器等；顶部还会显示最近用过的「转换成 PDF / JPG / MP4」快捷组合，正好要转这几种的话直接点；
2. 点进你要的那一类，用右下角的「+」从手机里选文件；这一页同时列出该类能转的输出格式，往下翻找到你要的（比如 PDF）点选；
3. 需要调整细节的话，展开高级设置。不同类型的可调项不同，常见的有：
   - 文档 / 表格：OCR 文字识别开关；
   - 图片：输出质量、尺寸（苹果版商店页还提到滤镜与 DPI 设置）；
   - 音频：比特率、采样频率、裁剪（trim，只保留一段）；
   - 视频：编码器、旋转、裁剪、防抖，另有按目标设备优化的配置（官方页提到 iPad、iPhone 与游戏主机等配置档案）；
   - 电子书：书名元数据、目标阅读器型号（Kindle、Kobo、Nook 等）；
4. 点转换按钮提交任务。除音频和视频外，这一步是把文件传到云端转换，需要保持网络畅通；
5. 转换完成后回应用里取结果文件，可以保存到手机目录，也可以直接通过系统分享发给微信、邮箱等。

整个过程中你可以切出去干别的，转换在后台进行。进度与结果都收在左上角三条横线的侧栏里：「忙」是进行中，「已转换」是成功，「失败的」是没转成的。常用组合长按一下就能加进主页的「收藏夹」，下次免翻列表。

## 二、批量转换

一堆文件要转同一个格式时，不用一个个来：

1. 在选择文件那一步，长按或用多选入口把要转的文件一次勾上（支持跨目录勾选）；
2. 选一个共同的目标格式，批量提交；
3. 任务会排队依次处理，侧栏「忙」组里能看到每一条的进度。

20.1.12 版的更新说明里专门提到「更高的批量转换上限」，也就是说这一版允许一次挂起的文件数比老版本多。如果你的文件特别多（比如几十上百个图片），分几批提交更稳妥，具体上限以应用内实际提示为准。

## 三、从网址转换（Convert from URL）

这个入口有两种用法，对应「文件在网上、不在手机里」的两种情况：

1. **转换网上的文件**：粘贴指向具体文件的直链（比如某个 PDF 的下载地址），应用会把那个文件抓下来再走正常转换流程。要的是**指向具体文件的直链**，不是随便一个网页地址；
2. **把网页本身转成文件**：官方列出的用法还包括把一个网址（普通网页）转成图片或电子书，用来存一份离线可看的版本。

转换结果同样回应用里取。

## 四、跨类别转换

类别可以交叉，几个常用组合：

| 想做的事 | 操作路径 |
| --- | --- |
| 视频转 GIF 动图 | 视频类源文件 → 选 GIF 输出 |
| 提取视频里的音频（视频转 MP3） | 视频类源文件 → 选 MP3（音频类输出） |
| 文字转语音（听电子书） | 文本 / 电子书源文件 → 选音频输出 |
| PDF 转 Word | PDF 源文件 → 选 DOCX |
| 相机 RAW 照片转 JPG | RAW 源文件 → 选 JPG |

视频转 GIF 和提取音频这两条路线最常用、参数也最多，单独写在了 [视频转GIF与提取音频.md](视频转GIF与提取音频.md)。

选不到某个目标格式时，多半是源文件的类别下官方没提供那个输出方向，先去 [支持的转换格式清单.md](支持的转换格式清单.md) 对一下有没有这一条路线。

## 五、转换之后

- **结果文件的位置**：从侧栏「已转换」组点开对应任务取回最直接；取不到时先看「失败的」组，别在文件管理器里盲翻；
- **分享**：每条完成的任务旁有分享按钮，直接把结果发给其他应用；
- **对 PDF 加密码**：文档类转换里带 PDF 加密选项，转出的 PDF 打开需要密码；
- **删掉照片的位置信息**：元数据工具可以把图片的 EXIF（含 GPS）提取出来看或整条清掉，发图前想去掉拍摄位置信息的话用这个。

哪一步报错了，直接去 [转换失败与常见问题.md](转换失败与常见问题.md) 对着报错信息找原因。
