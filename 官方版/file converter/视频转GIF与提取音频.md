## 一、视频转 GIF 动图

操作路径：视频转换器 → 「+」选视频 → 输出格式选 GIF。视频转 GIF 是官方商店页列明的示例用法，走视频类的离线转换，不用上传。

GIF 是出了名的「容易转、容易超大」，控制体积的办法按优先级：

1. **先裁时长**：GIF 没有压缩率可言，10 秒的动图比 3 秒大好几倍。高级设置里先剪掉不要的段落，只留要表达的那几秒；
2. **降尺寸**：发聊天工具的话，宽度降到 320~480 像素足够看清，1080P 的源视频直接转会得到一个谁都发不出去的文件；
3. **别指望转完再压**：GIF 转出来就是最终体积，想要小就得在转换前把源视频剪短、缩小。

有用户反馈 GIF / MP4 这条路线偶尔产出打不开或表现异常的文件，转完先自己播一遍再发出去；不正常就重转一次，还不行参考 [转换失败与常见问题.md](转换失败与常见问题.md)。

## 二、提取视频里的音频

同一个视频源文件，输出选 MP3 / M4A / AAC 等音频格式，就是提音轨。这条也走本地离线转换，文件不出手机。

音频高级设置里能调的三样（官方商店页口径）：

| 参数 | 作用 | 怎么选 |
| --- | --- | --- |
| 比特率 | 决定音质与体积 | 音乐选 192kbps 以上；人声、讲座 96~128kbps 够用 |
| 采样频率 | 高频细节 | 常规内容保持默认即可，源是老磁带转录才需要纠结 |
| 裁剪（trim） | 只保留一段 | 提取高潮片段、做铃声前先在这里剪 |

转出的音频质量上限就是源视频里的音轨质量——源视频本身是低码率的，调高输出比特率不会变好，只会变大。

## 三、做手机铃声

铃声就是一段剪好的音频文件，用上面的提取 + 裁剪两步就能做：

1. 从视频或音频源文件转到音频格式，裁出想要的段落（安卓铃声建议控制在 40 秒以内，太长系统会自动截断）；
2. 给 iPhone 做铃声的话，输出格式选 M4R（苹果商店页列明的输出格式之一），转完通过电脑导入；
3. 安卓直接用 MP3 / M4A，在系统声音设置里指定成铃声。

想要纯人声朗读而不是提取原声——比如把一篇电子书变成「听书」——那是文字转语音的路线，走法不一样，见 [文件格式转换操作步骤.md](文件格式转换操作步骤.md) 的跨类别对照表。
