## 一、提交转换就报错 / 一直转不完

按出现概率从高到低排查：

1. **网络不通或受限**：除音频视频外的转换都要上传云端。先确认浏览器能打开网页；公司、校园网常拦外部请求，切手机流量再试一次；
2. **文件本身是加密的**：带密码的 PDF / ZIP 官方明确不支持转换，先解密（比如 PDF 用密码打开后另存一份无密码版本）；
3. **DRM 保护的内容**：部分商店买的电子书、音乐带版权保护，这类文件转换必然失败，没有绕开的办法；
4. **文件太大**：云端转换对单个文件的体积有上限，超大文件要么换 Wi-Fi 分段处理，要么先压缩源文件（比如大视频先降分辨率）；
5. **服务器临时故障**：同一文件反复失败但网络正常，可能是转换服务当时不可用，隔一段时间再试。有用户反馈过典型症状：上传完成后进度停在 33% 附近，等二十来分钟以失败收场，换网络、开关 VPN 都没用——这基本可以判定是服务端的问题，压缩源文件或换个时段重试是仅有的办法。

## 二、转换完成了，但找不到结果文件

- 打开侧栏（主页左上角三条横线），先看「失败的」组、再看「已转换」组——所有任务都归在「忙 / 已转换 / 失败的」这三组里，别先去文件管理器里翻；
- 结果文件默认存应用自己的目录，文件管理器里要看 `Android/data` 对应目录（安卓 11 以上系统限制访问这个目录，从应用内分享出去是最省事的取法）；
- 历史记录是本地数据，卸载重装会清空。卸载前把还要的结果分享或复制出来。

## 三、目标格式列表里没有我要的那个

- 先对照 [支持的转换格式清单.md](支持的转换格式清单.md)：每个类别只有固定的输出方向，比如视频只能输出到 MP4 / MKV / WebM 等那几样，不存在「视频转成任意格式」；
- 类别判断错误也会导致列表不对：同一文件有时能归到不同类别（比如带文字的图片既是图片也算扫描件），换个入口进去选，输出列表可能就多了；
- 确实不支持的路线（比如音频输出 MP4 视频）就别找了，这个应用不做这个方向。

## 四、转出来的东西不对劲

| 症状 | 原因与处理 |
| --- | --- |
| 扫描件转 Word 出来是图片不是文字 | 没开 OCR。重新转，在高级设置里勾上 OCR 文字识别 |
| 视频转完是倒的 / 转了方向 | 高级设置里有旋转选项，先设好再转 |
| 音频转完音质明显变差 | 比特率设太低。音频高级设置里调高比特率再转 |
| 电子书在阅读器里排版乱 | 高级设置里可以指定目标阅读器型号（Kindle、Kobo 等），选对型号再转 |
| 图片转出来体积太大 / 太糊 | 图片高级设置里有质量与尺寸两项，质量降一档、尺寸按需求设 |
| GIF 动图太大发不出去 | 减少源视频时长（裁剪），或降低输出尺寸 |
| EPUB、SRT、GIF 转完打不开或内容不对 | 用户评价里反馈较集中的几条路线，转完先自己打开检查一遍；异常就重转一次，仍不行说明这条路线上转换服务不稳定，换电脑上的工具处理 |

## 五、批量任务里某几个失败了

批量转换是排队逐个处理的，前面成功不代表后面都能成。失败的那几条单独重转一次，往往就是文件本身的问题（加密、损坏、格式识别错）。侧栏「失败的」组里列着所有没转成的条目，按条目提示处理，或对照本篇第一、三节排查。应用自带的帮助在侧栏「经常问的问题」里，官方口径可以两边对照。

## 六、广告与免费版边界

File Converter 免费下载使用，免费版带广告；侧栏里有「保费」（Premium）入口，部分能力或额度涉及付费，具体哪些受限以应用内提示为准。两个用户反馈过的点提前知道：

- **看广告解锁有时不生效**：看完广告没解锁的，重试一次或过一会儿再试，多数能自己恢复，不用反复点；
- **收费方式调整过**：老用户评价里提过收费模式变更带来的落差；涉及付费前先看清当前是按订阅扣费还是一次性买断，再决定要不要掏钱。

## 七、重装与版本

反复失败且排除了以上所有原因，重装一次可以排除安装包损坏的可能——用 [下载与安装教程.md](下载与安装教程.md) 里的同一份安装包重装即可。用户评价里也有人靠重装解决了更新后的异常状态。装好后先试一个小文件（几百 KB 的图片），通了再处理大文件，能把「环境问题」和「文件问题」分开。
