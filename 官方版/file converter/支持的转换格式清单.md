## 一、先说总量和边界

官方口径：源格式超过 2000 种，覆盖视频、音频、图片、文档、电子书、表格、演示文稿、3D 模型、CAD 图纸、字体、GPS 轨迹、字幕等类别。下面列的是**输出格式**——也就是「转成什么」；输入方向比这宽得多，你手机里常见的文件基本都能当源。

两条硬边界，碰到直接省力气：

- **加密的 PDF / ZIP 转不了**——带打开密码或权限限制的文件，转换前先在电脑上解密；
- **DRM 保护的内容转不了**——带数字版权保护的电子书、音乐（比如部分商店购入的电子书）不在支持范围。

## 三、挑格式的几个实用参照

- **给别人看排版固定的文件** → PDF；
- **给 Kindle 传书** → AZW 或 MOBI；给手机阅读器 → ePub；
- **要继续编辑的文档** → DOCX（Word）或 ODT（LibreOffice）；
- **图片要透明背景** → PNG；要照片兼容性 → JPG；要动图 → GIF；要网页小体积 → WebP；
- **视频要全平台能播** → MP4；要在浏览器里免插件播放 → WebM；
- **音乐要无损** → FLAC；要体积小兼容广 → MP3；语音内容想要更小 → OPUS；
- **表格给程序读** → CSV；给人看 → XLSX 或 PDF；
- **做手机铃声** → 安卓用 MP3 / M4A，iPhone 用 M4R，具体做法见 [视频转GIF与提取音频.md](视频转GIF与提取音频.md)。

## 四、和操作相关的能力

- **跨类别输出**：表格里各列不是孤立的，视频源文件可以选音频输出（提音轨）、图片可以转 PDF、文字可以转语音，操作见 [文件格式转换操作步骤.md](文件格式转换操作步骤.md)；
- **转换时可调参数**：图片的质量与尺寸、音频的比特率与频率、视频的编码与裁剪、文档与表格的 OCR 开关，都在选完目标格式后的高级设置里；
- **OCR**：把图片或扫描件转成可编辑文档时勾上 OCR，识别的是图里的文字；
- **元数据工具**：提取或删除图片的 EXIF 信息（拍摄时间、机型、GPS），这是独立于格式转换的一个入口；
- **文件修复**：独立于转换的「修复」入口，官方商店页列出的可修对象包括 PDF、RAR、ZIP、STL 和音频、视频文件，文件损坏打不开时可以一试，修不修得好以实际结果为准。

## 五、哪类转换在本地跑、哪类要联网

音频和视频的转换可以离线完成，其余类别大多要传云端处理。这一区别直接决定你用的时候要不要管网络，展开写在这篇里：[云端转换与离线转换的区别.md](云端转换与离线转换的区别.md)。
