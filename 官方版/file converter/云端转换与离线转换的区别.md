## 一、两种转换方式怎么分工

File Converter 的大部分转换**不在手机上算**，而是把你的文件上传到云端服务器转换、再把结果下载回来。音频和视频是例外，官方商店页说明这两类支持离线转换，也就是直接在手机上完成，不联网也能转。

| | 云端转换 | 离线转换 |
| --- | --- | --- |
| 覆盖类别 | 文档、电子书、图片、表格、3D、CAD 等大多数类别 | 音频、视频 |
| 网络要求 | 全程要联网，断了会失败 | 不需要 |
| 速度 | 服务器算，通常比手机本地转快 | 取决于手机性能，大视频要等 |
| 耗电 | 手机只负责上传下载，省电 | 手机 CPU 全程参与，更耗电 |
| 文件去向 | 上传 → 转换 → 下载回手机，服务器上的副本用完删除 | 始终只在手机里 |

同样的视频转 MP3，用离线方式意味着文件不出手机；而把一张照片转 PDF，文件就要走一趟云端。需要哪种方式不是选项，是由你要转的类别决定的。

## 二、云端那趟意味着什么

把文件交给云端处理，有三件事你该心里有数：

1. **隐私敏感的文件自己掂量**：身份证照片、合同扫描件这类内容，转换意味着它们会经过第三方服务器。官方的说明很明确：文件安全传输，**转换完成或失败后立即删除，不留副本、不留日志**（官方商店页原话是 "We don't keep any copies or logs"）。介意的话，音频视频本来就不上传；图片和文档类可以先用电脑上的本地工具处理完再传手机。
2. **等待时间由网络决定**：上传大文件（比如几十 MB 的扫描 PDF）在移动网络下会明显慢，Wi-Fi 下体验好得多。转换进行中可以切出去干别的，完成后有通知。有用户反馈过大文件在上传阶段就卡住、进度长时间停在三分之一附近、最后超时失败——这类情况换网络未必有用，更像是转换服务端当时的问题，把源文件压缩小一点或换个时间段重试更有效，排查清单见 [转换失败与常见问题.md](转换失败与常见问题.md)。
3. **失败先查网络**：云端转换报错时，第一件事是确认网络能通。公司 Wi-Fi 或校园网拦外网请求的情况不少见，切手机流量再试一次是最快的排查方法。

## 三、离线转换的使用建议

音频和视频走本地，注意两点：

- **别在转换中途杀掉应用**：本地转换占 CPU，进程被系统或你手动清掉，任务就得重来。大文件转换时给应用留在后台的权利（部分品牌手机要在设置里允许它后台运行）；
- **体积与电量**：一个两小时的视频重新编码，中端手机可能要跑几十分钟且明显发热，插着电转更稳妥。急用结果、又不介意文件走云端的话，可以先压缩视频体积再转；要「文件不出手机」，就得接受本地转换的时间成本。

## 四、转换结果从哪取、存多久

两类转换的结果都回应用里取：侧栏的「忙」「已转换」「失败的」三个分组就是全部任务的去向。云端转换的结果下载回手机后就与服务器无关了；任务记录是本地数据，卸载应用会清掉，重要的转换结果建议当场分享或复制到你自己的目录。取不到结果文件的排查步骤在 [转换失败与常见问题.md](转换失败与常见问题.md)。
