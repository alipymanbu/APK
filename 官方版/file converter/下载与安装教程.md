## 二、从网盘拿安装包

File Converter 安装文件资源放在夸克网盘里，转存步骤：

1. 点开 [https://pan.quark.cn/s/c606bc8d65b1](https://pan.quark.cn/s/c606bc8d65b1)，登录你的夸克账号；
2. 勾选里面的 APK 文件，点「保存到网盘」，选一个你找得到的位置；
3. 在夸克网盘的手机客户端里找到这份 APK，点下载；
4. 下载完成后直接点文件，系统会弹出安装确认。

没有夸克账号的先注册一个，转存和下载都需要登录。

## 三、安装步骤与「允许安装未知应用」

APK 不是从应用商店下载的，安卓默认会拦一道，处理方式：

1. 点开下载好的 APK，系统提示「出于安全考虑，已禁止安装未知来源应用」时，点「设置」；
2. 找到「允许此来源安装应用」的开关（不同品牌的叫法略有差别，小米叫「安装未知应用」，华为在「更多安全设置」里），打开后返回；
3. 回到安装界面，点「安装」，等进度走完；
4. 点「打开」或回桌面点图标启动。

装好之后这个来源的开关可以留着也可以关掉，不影响已装好的应用运行。

## 四、首次打开

第一次启动是应用自己选语言、看主界面，没有强制的注册或登录流程。两件事值得先确认：

- **网络**：除音频和视频外，大部分转换是把文件传到云端处理的（细节见 [云端转换与离线转换的区别.md](云端转换与离线转换的区别.md)），所以第一次用之前确认手机能上网，没开 VPN 的话注意部分网络环境下访问海外服务器可能偏慢；
- **存储权限**：转换要读你手机里的文件、把结果存回去，如果应用弹出存储权限请求，允许它，否则选不到要转换的文件。

这套安装包的界面带中文本地化：主界面、侧栏、分类名都是中文，个别条目翻译得比较生硬（比如返回按钮被译成「背部」），不影响使用。官方商店信息里标的语言是英语，你装到的版本实际以界面显示为准。

装完就可以去试第一次转换了，具体流程在 [文件格式转换操作步骤.md](文件格式转换操作步骤.md)。
