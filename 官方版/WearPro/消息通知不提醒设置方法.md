# 消息通知不提醒设置方法

> 手表收不到微信、短信提醒，通常是链路上某一环没打开 —— 本篇把三层设置逐个过一遍，并给出安卓后台保活的品牌路径。

## 一、先理解链路：一条提醒要过三关

手表上的每条提醒，都要完整走过这条线，断在哪一环，消息就停在哪一环：

```
手机通知栏出现消息  →  WearPro 读到通知并转发  →  手表震动亮屏
```

- **第一关（手机）**：消息必须先在手机的通知栏里出现。手机上都没弹的通知，手表不可能凭空收到。
- **第二关（App）**：WearPro 的通知访问权限 + App 内各个应用的提醒开关，都得打开。
- **第三关（手表）**：连接正常、提醒开关没被关掉。

排查时**从第一关往第三关走**，别一上来就怀疑手表坏了。

## 二、App 内的开关在哪

绑定后进**设备**页，相关的开关都在这里：

| 想要的提醒 | 开关位置 |
| --- | --- |
| 微信、QQ 等应用消息 | 设备 → 应用通知 → 打开对应应用的开关 |
| 短信提醒 | 设备 → 短信通知 → 打开 |
| 来电提醒 | 设备 → 来电提醒 → 打开 |

安装时如果没给通知访问权限，这些开关点了也不生效 —— 去系统设置 → 应用 → WearPro → 通知，把「允许通知」打开；安装时漏授权限的补救办法见 [下载与安装教程.md](下载与安装教程.md) 第三节。

## 三、手机侧：让源应用的通知栏里真的有内容

官方 FAQ 特别强调「手表读的是手机通知栏」，所以这些也得开：

- **微信**：我 → 设置 → 新消息通知 → 打开「通知显示消息详情」。只显示「你收到了一条消息」不显示内容的话，手腕上也只能看到一句提示。
- **QQ**：设置 → 消息通知 → 打开「通知显示消息内容」。
- **手机系统**：设置 → 通知与状态栏 → 确认微信、QQ、电话、短信这些应用的允许通知是开着的。

iOS 侧对应的是：设置 → 通知 → 对应 App → 允许通知，逻辑一样。

## 四、安卓后台保活（断连与漏提醒的头号原因）

安卓的省电策略会把后台的 WearPro 杀掉，杀掉之后**连接断、提醒也停**。分品牌把这几项都开了：

| 品牌 | 要动的设置 |
| --- | --- |
| 华为 / 荣耀 | 设置 → 应用启动管理 → WearPro → 关掉「自动管理」，打开允许自启动、允许关联启动、允许后台活动；再到电池设置里关掉针对它的省电 |
| 小米 / Redmi | 设置 → 应用设置 → WearPro → 省电策略 → 无限制；再在安全中心里允许自启动 |
| OPPO / realme | 设置 → 电池 → 耗电保护 → WearPro → 关闭「后台冻结」与「异常时自动优化」 |
| vivo / iQOO | 设置 → 电池 → 后台高耗电 → 打开 WearPro；同时在后台界面把卡片下拉锁定 |
| 三星 | 设置 → 应用 → WearPro → 电池 → 选「不限制」；最近任务里锁定卡片 |

通用兜底动作（任何品牌都适用）：在最近任务界面把 WearPro 卡片**下拉锁定**（或点锁图标），避免一键清理把它清掉；系统省电模式开着时它更容易被限流，长时间挂着连接时建议关掉省电模式。

另有第三方手表品牌的售后资料提示：关掉系统里的「闲置时自动清理 / 智能省电」对 WearPro 同样适用（这类说法属单一来源，路径以你自己手机上实际出现的菜单为准）。

## 五、三个容易误判的边界

1. **来电只能拒接不能接听** —— App 里的来电提醒只负责震铃与拒接；要在手表上接听，必须先把音频蓝牙连上（步骤在 [手表绑定连接失败排查.md](手表绑定连接失败排查.md) 第五节）。
2. **手表最多存 10 条消息** —— 这是手表侧的固定缓存条数，来第 11 条就覆盖最旧的一条。所以「手表上只剩最新几条」不是故障；要看完整的，回手机通知栏里翻。
3. **长消息只显示前半截** —— 手表屏幕能放的字符有限，官方说明里明确这是显示限制，全文要看手机。

按第一节到第四节走完，绝大多数「不提醒」都能定位到具体某一环；如果连「断开连接」一起出现，优先处理第四节的保活设置。
