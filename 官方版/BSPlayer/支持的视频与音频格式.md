## 一、官方标注的格式清单

下面是官方页面上点名的格式，实际覆盖范围比这张表更宽，表里没列的容器也值得直接丢进去试：

| 类型 | 官方点名的格式 |
| --- | --- |
| 视频 | AVI、WebM、FLV、MKV、MOV、MPG、MTS、MP4、M4V、RMVB、WMV、3GP |
| 音频 | MP3（官方描述把音视频播放放在同一个清单里，音频同样支持多格式） |
| 流媒体 | HTTP、RTSP 地址 |

几个实际使用上的对照：

- **MKV / RMVB / AVI** 这三类是系统自带播放器最容易打不开的，也是这类第三方播放器的主要用武之地。
- **多音轨文件**（比如 MKV 里同时带原声和国配两条音轨）可以在播放中切换音轨，不用换文件。
- **MTS / M2TS**（摄像机原始素材）官方说明里点了 MTS 的名，摄像机导出的这类片子可以直接播。

## 二、流媒体与在线地址

- 播放界面支持直接输入 URL 播放 HTTP / RTSP 地址，摄像头、网络机顶盒的直播流通常走这两种协议。
- 也支持直接填 YouTube 地址播放，清晰度偏好可以在设置的 Network/Streaming 一节里选；播完后地址会进入「最近播放」列表。
- 直播源能不能播取决于源本身是否有效：播不出来时先用同一个地址在电脑上验证，电脑也打不开就是源过期了，与播放器无关。

## 三、RAR 压缩包与外接存储

- **未加密的 RAR**：不用先解压，直接在应用里打开 RAR 文件选里面的视频即可播放。压缩包必须是「仅存储 / 低压缩」的普通压缩包，带密码或分卷的不适用。
- **USB OTG**：通过 OTG 线接 U 盘、读卡器，媒体库能扫到外接存储里的文件；部分系统会先弹授权确认，允许后才能访问。

## 四、某个文件播不出来时按这个顺序排查

1. **换解码方式**：进播放设置把硬件解码切换成软件解码（或反之）再试。硬件加速依赖机型解码器能力，个别文件在硬解下会黑屏或卡顿，软解通常能救回来，代价是更耗电、老机型可能掉帧。黑屏、花屏、截不了图这些画面异常的完整排查在[黑屏花屏与卡顿排查](黑屏花屏与卡顿排查.md)。
2. **查文件本身**：把文件拷到电脑上播一次，电脑也播不了就是文件损坏，不是播放器的问题。
3. **查音轨**：画面正常没声音时，先在播放界面切换一次音轨——多音轨文件有时默认选中的轨是无效轨。
4. 字幕相关的异常（乱码、不显示）不在本篇范围，看[字幕设置与自动匹配](字幕设置与自动匹配.md)。

## 五、从别的设备拿文件来播

手机存储放不下的大体积收藏，可以不拷贝直接播局域网里电脑或 NAS 共享的内容，设置方法见[局域网与网络播放](局域网与网络播放.md)；安装包本身从[下载与安装教程](下载与安装教程.md)获取。
