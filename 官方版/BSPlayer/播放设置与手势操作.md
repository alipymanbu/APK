## 一、弹出小窗与后台播放

这是这个播放器用得最顺手的形态：视频缩成悬浮小窗，你同时去刷别的应用。三个入口：

- **临时弹窗**：播放中**长按返回键**，当前视频收进悬浮窗继续播；**双击悬浮窗**恢复全屏。
- **默认弹窗**：设置里走 **Preferences → Playback → Background playback**，选 **Audio and video files – pop up video**，之后所有视频默认以弹窗方式后台播放。
- **只要声音**：同一处设置里如果只选音频后台，视频就退成纯声音播放，适合拿它当音乐播放器听演唱会资源。

悬浮窗可以拖到屏幕任意位置；不用了双击悬浮窗回到全屏，或直接关掉。

## 二、锁屏防误触

播放界面里有个**锁形图标**，点一下进入锁定：触屏和手势全部失效，只锁播放画面、不锁手机系统。两个典型场景：

- 口袋里或给孩子拿手机看动画，防止碰到屏幕跳出播放。
- 蓝牙耳机误触按键时同样有效。

解锁就是再点一次锁形图标。

## 三、倍速与音轨

- **播放速度 50%–200%** 连续可调：听课录屏、播客用 1.5 倍以上，学动作用 0.5 倍逐段看。倍速下声音会跟着变速，条理不清的语音素材建议别超过 2 倍。
- **多音轨切换**在播放界面直接选，MKV 双语轨、解说轨都能切，切换过程不打断播放。

音画不同步（尤其蓝牙耳机）的修正不在这里，见[字幕设置与自动匹配](字幕设置与自动匹配.md)第四节的音频延迟设置。

## 四、手势、按键与画面

- **手势可自定义**：进退、音量、亮度这类屏幕手势在设置里能按习惯改；忘了有什么手势，首次启动的开屏页展示过全部手势，随时可以进 **Preferences → Show instructions** 再看一遍。改完先用一部短片验证一遍，避免正片里试错。
- **外接键盘**：蓝牙键盘的部分键位（播放 / 暂停、音量加减）可以直接控制播放，趴床上把手机架起来用键盘操作比伸手指舒服。
- **画面比例**：除了常用的适应屏幕、拉伸、裁剪，还支持自定义比例，看老电影压扁的画面时用得上。
- **屏幕方向**：横竖屏策略在 **General → Screen orientation** 里选，可以固定横屏。

## 五、媒体库扫描与历史

| 想做什么 | 去哪设置 |
| --- | --- |
| 不让应用自动扫描全盘媒体 | **General → Auto scan for media files** 关掉，之后只播你手动指定的目录 |
| 文件排序按名称 / 大小 / 日期 | 媒体列表的排序入口 |
| 播放列表重启后还在 | **Library 标签 → Menu → Add new Play List**，把文件加进去；随手建的临时列表退出就没了 |
| 列表里不想出现音频文件 | 设置里把音频类扩展名从媒体扫描里移除，它就只当视频播放器用 |
| 清掉播放历史 | **Preferences → Other → Clear history** |

自动扫描关掉后，局域网共享目录（见[局域网与网络播放](局域网与网络播放.md)）不受影响，还是能手动进目录播放。

安装文件还没装上的话，从[下载与安装教程](下载与安装教程.md)开始；免费版界面里会出现的广告与付费版差异，见[免费版与专业版区别](免费版与专业版区别.md)。
