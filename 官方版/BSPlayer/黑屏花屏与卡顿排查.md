# BSPlayer 黑屏花屏与卡顿排查

> 本篇汇总 BSPlayer 播放时最常见的一批「画面不对劲」：黑屏、花屏、卡顿、截不了图、电视上没字幕——多数不是文件坏了，是解码方式的问题。

## 一、先按症状对号入座

| 你看到的 | 多半是什么 | 去哪节 |
| --- | --- | --- |
| 黑屏 / 大块绿色或紫色画面，但声音正常 | 硬件解码不支持这个编码 | 第二节 |
| 截图功能截出来是黑的、或干脆没反应 | 硬解模式下截图本来就不行 | 第三节 |
| HDMI 接电视，手机有字幕、电视上没有 | 安卓系统层的限制 | 第四节 |
| 画面上有一条随声音跳动的绿线 | 不是故障，是音量表开着 | 第五节 |
| 高分辨率片子卡顿、设备发热 | 老机型硬解吃不下新编码 | 第六节 |

## 二、黑屏、花屏但有声音：切软件解码

声音正常而画面出不来或出乱码，几乎都是硬件解码这条路走不通——机型的解码芯片只认它支持的编码和规格，超出范围就交不出画面。处理：

1. 进 **Preferences（设置）→ Decoding mode（解码模式）**。
2. 从硬件解码切换成 **Software decoding mode（软件解码）**，重开这个文件。

软件解码靠 CPU 干活，什么编码都吃得下，代价是耗电增加、老机型可能掉帧。看正常之后再决定这一类文件是固定用软解，还是看一部切一次。

## 三、截图截不出来：只有软解模式能截

官方 FAQ 明确说：视频截图只在**软件解码模式**下可用，硬件解码模式下截不了。想截画面，先按第二节的方法切到软解再截。这也是「有时能截有时不能」的原因——能截的那次用的恰好是软解。

## 四、HDMI 接电视后电视上没字幕

手机屏幕上有字幕、用 HDMI 线连到电视或显示器后字幕消失了——官方 FAQ 把这归为安卓系统层的问题：大多数设备在硬解输出到第二块屏幕时就不显示字幕。目前唯一的绕法同样是**切到软件解码**。

## 五、画面上的绿色线条：那是音量表

随声音上下跳动的绿线不是花屏，是**音频 VU 电平表**。关掉：**Preferences → Playback settings → Visualization**，音频与视频的显示是分开的两个开关，都关上画面就干净了。

## 六、高分辨率片子卡顿：机器上限，不是设置错了

4K、高码率或较新编码的文件在老设备上卡顿，说明硬件解码这条路吃不下；此时切软解通常更卡——CPU 也追不上。可做的只有：

- 播低分辨率或低码率的版本（同一部片常有 1080p / 720p 两版）。
- 升级到官方最新版再试一次，排除旧版本的兼容问题；但机器解码芯片本身的上限不会因升级应用而突破。
- 判断到底是文件坏还是设备跟不上：把同一个文件拿另一台设备或电脑播一次，那边也卡是文件问题，那边流畅就是你这台机器的上限。

网络播放的卡顿是另一类问题，先调缓冲再查网络，见[局域网与网络播放](局域网与网络播放.md)第三节；字幕本身的乱码、不显示，看[字幕设置与自动匹配](字幕设置与自动匹配.md)。安装文件还没装上的，从[下载与安装教程](下载与安装教程.md)开始。
