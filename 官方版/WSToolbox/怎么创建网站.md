## 一、先想清楚你要跑什么样的网站

创建站点前先对号入座，决定要开哪几个服务：

| 你要跑的网站 | 需要启动的服务 |
| --- | --- |
| 纯静态页（HTML/CSS/JS） | Nginx |
| PHP 程序（WordPress、Typecho 这类） | Nginx + PHP |
| 还要存数据（文章、用户、订单） | 再加 MariaDB |
| 缓存加速（可选） | Redis |

不确定就先只开 Nginx 跑通静态页，之后再按需加。

## 二、把服务开起来

1. 打开 WSToolbox，首页上每个服务右侧都有控制按钮，点一下把 Nginx（以及你需要的 PHP、MariaDB）开起来；
2. 切到「服务」界面确认状态：Nginx、MariaDB、PHP、Redis 各自显示运行状态，都亮了才算就绪；
3. 起不来的情况直接查 [常见问题排查.md](常见问题排查.md) 第二节。

## 三、创建站点：主机名、端口、网站路径

服务就绪后，在站点管理里点「添加」，填三个信息，然后点右下角「创建」：

| 字段 | 填什么 | 注意 |
| --- | --- | --- |
| 主机名 | 这个站点的标识，浏览器访问时对应它 | 用小写字母、数字或点，别用中文 |
| 端口 | 浏览器访问时要带的端口号 | 避开已被占用的端口；换过端口的见 [服务启动与配置文件修改.md](服务启动与配置文件修改.md) |
| 网站路径 | 网页文件存放的目录 | 记住这个目录，第四节的文件就放这里 |

## 四、把网页文件放进去

在第三节填的「网站路径」目录下放一个首页文件。先跑通最简单的：

```html
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>test</title></head>
<body><h1>hello from my phone</h1></body>
</html>
```

存为 `index.html` 放进网站路径。要验证 PHP 是否正常，再放一个 `test.php`：

```php
<?php phpinfo();
```

## 五、在浏览器里访问

- **手机自己访问**：浏览器打开 `http://localhost:端口`（端口换成第三节你填的数字）；
- **同一 Wi-Fi 下的电脑访问**：先查手机 IP（设置 → WLAN → 点当前网络，IP 一栏），电脑浏览器打开 `http://手机IP:端口`；
- **打不开**：先在手机本地用 `localhost` 自测——本地能开而电脑开不了，问题在局域网链路（不在 WSToolbox），按 [常见问题排查.md](常见问题排查.md) 第三节排查。

以上都是同一 Wi-Fi 内的访问。要让不在你家网络里的人也打开，见 [外网访问与内网穿透.md](外网访问与内网穿透.md)。

## 六、想装 WordPress 这类现成程序

1. 把 Nginx、PHP、MariaDB 三个服务都开起来；
2. 把程序文件解压放进「网站路径」目录；
3. 数据库部分需要一个库名和账号——用能连接 MariaDB 的方式建好，连接信息以应用内显示为准；
4. 浏览器打开站点地址，按程序自己的安装向导走完。

手机上的站点适合测试和小范围访问，稳定运行的大站仍然建议放在正经服务器上。
