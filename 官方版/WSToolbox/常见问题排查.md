## 一、装不上 / 打开就闪退

- 先核对安装包 MD5 是否与 [下载与安装教程.md](下载与安装教程.md) 第二节的表格一致，不一致就是包损坏，重新下载；
- 确认安卓版本满足要求；版本太老装不上是系统限制，换新系统或新设备；
- 闪退则卸载后换官网最新版再试一次。

## 二、服务点了没反应 / 启动失败

按顺序查：

1. **存储空间**：数据库这类服务写盘失败最常见的原因就是手机存储满了，先清出几个 GB；
2. **看日志**：WSToolbox 支持查看系统日志和访问记录，启动失败时先看日志里报了什么；
3. **重启服务**：停一次再开一次；还是不行就把应用整个关掉重开；
4. **改过配置**：刚改完配置起不来，多半是配置改错了，按 [服务启动与配置文件修改.md](服务启动与配置文件修改.md) 第六节回滚。

## 三、电脑打不开手机上的网站

先在手机浏览器里用 `http://localhost:端口` 自测，再按结果分两边：

- **手机本地也打不开**：服务或站点本身的问题，回到第二节查；
- **手机本地能开、电脑打不开**：是局域网链路的问题，逐条查：
  1. 电脑和手机是否连的**同一个 Wi-Fi**（访客网络经常隔离设备）；
  2. 电脑访问的是**手机 IP**，不是 `localhost`（手机 IP 在「设置 → WLAN → 当前网络」里看）；
  3. 端口是否写对——建站时填的端口是多少，地址里就带多少；
  4. 路由器开了 **AP 隔离**（无线设备之间不能互访）的话，到路由器后台把这个选项关掉。

本地与局域网都排查过没问题、想进一步给外网的人访问，那是另一套方案，见 [外网访问与内网穿透.md](外网访问与内网穿透.md)。

## 四、息屏或切走一会儿，网站就打不开

安卓的省电机制会杀后台应用，手机上跑服务都会受影响，逐项处理：

1. **关电池优化、允许后台运行**：不同品牌路径不同——以华为/鸿蒙为例：手机管家 → 启动管理，关掉 WSToolbox 的「自动管理」，打开允许自启动、允许关联启动、允许后台活动；其他品牌在「设置 → 应用管理 → WSToolbox → 电池」里找类似选项；
2. **多任务里加锁**：最近任务界面找到 WSToolbox，下拉或点锁图标锁定，防止一键清理把它杀掉；
3. **关省电模式**：设置 → 电池，测试期间先关掉；进阶可在设置里搜「电池优化」，把 WSToolbox 设为不允许优化；
4. **休眠保持联网**：在设置里搜「休眠时始终保持网络连接」并打开，防止锁屏后断网。

测试期间最稳的组合：插着充电 + 保持亮屏。以上设置项名称与入口以你的机型实际显示为准。

## 五、手机 IP 每天都在变

手机 IP 是路由器 DHCP 随机分配的，重启路由器或手机后常会变。两个办法：

- 到路由器后台把这台手机的 MAC 地址绑定一个固定 IP（DHCP 静态分配 / 地址保留），一劳永逸；
- 或者每次要访问时现查一遍手机 IP（设置 → WLAN → 当前网络）。

## 六、网站文件与数据库怎么备份

- **网站文件**：都在你建站时填的「网站路径」目录里，用文件管理器整目录复制出来就是备份；
- **数据库内容**：用能连接 MariaDB 的客户端连上后导出，连接地址和端口以应用内显示为准；
- 稳妥的做法是定期导出到手机存储以外（电脑、网盘），手机丢失或损坏时才有得恢复。
