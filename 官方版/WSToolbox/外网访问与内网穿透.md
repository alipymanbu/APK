## 一、先分清：局域网访问和外网访问

按 [怎么创建网站.md](怎么创建网站.md) 装好的站点，默认只有连同一个 Wi-Fi 的设备能打开——手机在路由器后面，而运营商分给家庭宽带的大多不是真正的公网 IP，外部的请求根本找不到你这台手机。想让外网的人访问，常见三条路线，按你手头的条件选。

## 二、路线一：路由器端口转发（家里有公网 IP 才可行）

1. **先确认有没有公网 IP**：登录路由器后台看 WAN 口 IP，再在浏览器搜「我的IP」对比——两者一致就是公网 IP；不一致（WAN 口是 192.168.x.x、100.x.x.x 这类内网段）说明你在运营商内网，这条路走不通，直接看路线二；
2. **加端口转发规则**：路由器的「端口转发 / 虚拟服务器」里新增一条——外部端口定一个高位端口（如 8080），内部地址填手机 IP，内部端口填建站时用的端口；之后外部访问地址就是「公网IP:外部端口」；
3. **IP 会变的问题**：家庭宽带 IP 动态变化，路由器大多自带 DDNS 功能，绑一个动态域名后用域名访问即可（各品牌入口不同，以路由器说明为准）；
4. **端口封禁**：国内不少宽带封了 80、443 的入站端口，站点换高位端口发布是常态。

## 三、路线二：内网穿透工具（没有公网 IP 的主流做法）

原理：手机（或局域网里任一台电脑）跑一个客户端，它与服务商的云端服务器保持一条隧道，外部访问一个固定域名，流量经云端转发进你的站点。有公网 IP 与否都能用，手机也不用直接暴露在公网上。

以花生壳为例（截至 2026-09 的流程，以官方页面为准）：

1. 在官网注册账号；
2. 客户端里「添加映射」，映射类型选「网站应用」（HTTP/HTTPS）；
3. 内网主机填手机 IP，内网端口填建站时的端口；
4. 保存后得到一个外网访问地址，发给要访问的人即可。

免费版有限制（截至 2026-09：约 1Mbps 转发带宽、2 条映射、10 并发），跑测试站够用，正式服务要考虑付费或自建。另一条路是自建 [frp](https://github.com/fatedier/frp)（开源）：需要一台有公网 IP 的服务器跑服务端，手机这边跑客户端，配置以 frp 官方文档为准——手头有服务器资源时这条最灵活。

## 四、对外开放前先做三件事

1. **只映射网站端口**：MariaDB、Redis 这些数据库端口绝不要映射到公网；网站管理后台（如 WordPress 的后台页）也要加一层访问限制；
2. **改掉弱密码**：数据库账号、网站后台账号都用长密码——公网上的扫描是全天候的；
3. **上 HTTPS**：穿透工具大多能自动部署证书（如花生壳的网站应用映射），没加密的站点在公网上是明文传输。

另外，手机 24 小时开机当服务器记得插着电、关掉电池优化（步骤见 [常见问题排查.md](常见问题排查.md) 第四节）。
