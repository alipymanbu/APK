## 一、WSToolbox 是什么

WSToolbox 是一款把安卓手机变成服务器的工具（开发者为景德镇小江计算机科技有限公司）：内置 Nginx、PHP、MariaDB、Redis、Crontab 这一套 Web 服务，你可以在手机上直接托管静态网站、跑 PHP 程序、开数据库，同时实时查看内存、存储等资源占用和访问记录。适合想在手机上搭测试站点、跑小型 Web 服务的开发者和服务器爱好者。这篇讲怎么把安装包装到手机上。

## 二、安装前先核对两件事

**1. 安卓版本**：本地这份安装包的采集记录标注「需要安卓系统 5.2 以上」；官网页面没有明确标注最低系统版本，**以官网说明为准**。查自己的系统版本：手机「设置 → 关于手机 → 版本号」。

**2. 存储空间**：安装包本身 110.64M，装好后再加上 Nginx、数据库这些服务运行起来还要占空间，建议手机至少留出 1GB 以上的富余。

这份网盘安装包的事实信息（以本地采集为准，官网最新版可能不是同一版）：

| 项 | 值 |
| --- | --- |
| 版本 | 2.0.5 |
| 包名 | com.xiaojiangi.wstoolbox |
| 大小 | 110.64M |
| MD5 | 0E49568CDFD399773B5FD8B6C2082B69 |
| 采集时间 | 2026-09-23 |

下载后想核对文件没损坏，可用文件管理器或电脑算一次 MD5，与上表一致即为同一份包。

## 三、安装包从哪拿、怎么装

**方式一：网盘安装包（本文入口）**

1. 打开 [WSToolbox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0f7b9613c343)，把 APK 转存到自己的网盘后下载到手机；
2. 点开 APK 安装，若系统弹出「禁止安装未知来源应用」，按提示给你的浏览器或文件管理器开一次「允许安装未知应用」；
3. 装完打开，下一步见第四节。

**方式二：官网**

到 [WSToolbox 官网](https://wstoolbox.cn/) 下载。截至 2026-09，官网标注最新版为 2.0.10（148.65MB，2026-05-17 更新），以页面当时显示为准。两个渠道装的是同一个应用，差别只在版本新旧：官网给的是最新版，网盘这份是 2.0.5。

## 四、装完第一次打开

按公开的走查记录，打开后直接就是主界面，没有注册登录环节：

1. **首页看资源**：内存、存储、网络状态，以及 Nginx 等服务的开关，一眼都在首页上；
2. **服务页看状态**：切到「服务」界面，能看到 Nginx、MariaDB、PHP、Redis 各自的运行状态，配置文件也从这里进；
3. **想跑网站**：把要用到的服务开关打开，然后按 [怎么创建网站.md](怎么创建网站.md) 的步骤添加站点。

## 五、安装常见问题

- **提示「应用未安装」**：多为包不完整或系统版本不够。先核对 MD5 是否与第二节表格一致，再确认安卓版本；
- **打开就闪退**：先确认系统版本满足要求，仍闪退可卸载后换官网最新包装一次；
- **装好了但服务起不来**：见 [常见问题排查.md](常见问题排查.md)。
