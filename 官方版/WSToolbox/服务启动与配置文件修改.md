## 一、五个服务各自管什么

| 服务 | 用途 | 什么时候需要开 |
| --- | --- | --- |
| Nginx | Web 服务器，托管静态网站、反向代理 | 只要跑网站就开 |
| PHP | 运行 PHP 程序，支撑动态网站 | 跑 WordPress 等PHP程序才开 |
| MariaDB | 兼容 MySQL 的关系型数据库 | 程序要存数据才开 |
| Redis | 内存数据库，做缓存和高速读写 | 程序明确用到才开 |
| Crontab | 定时任务 | 要定时执行脚本才用 |

只跑静态页的话，光开 Nginx 就够——服务开得越少，手机越省电。

## 二、启动与停止

- **首页开关**：首页上每个服务右侧有控制按钮，点一下切换启停；
- **服务页确认**：切到「服务」界面，看每个服务的运行状态；配置文件的编辑入口也在这里。

停服务同理：不用的时候顺手把 Nginx、MariaDB 关掉，省电也省内存。

## 三、改配置文件

「服务」界面里选中某个服务就能编辑它的配置文件，编辑器带语法高亮。改之前先复制一份留底——改坏了能立刻换回来。

常见要改的参数（具体字段名以你手机里的配置文件实际内容为准）：

| 想做的事 | 大致位置 | 注意 |
| --- | --- | --- |
| 换网站端口 | Nginx 配置里的监听端口 | 改完同步改站点设置里的端口，两边要一致 |
| 换网站根目录 | Nginx 配置里的网站目录 | 新目录要先建好、文件先放进去 |
| 放大上传限制 | PHP 配置里的上传与提交大小两项 | 两处一起改，只改一处不生效 |
| 数据库端口 | MariaDB 配置 | 改错可能起不来，务必先留底 |

## 四、改完一定要重启服务

配置文件是启动时读的，改完把对应服务停一次再开一次，然后用浏览器验证：网站端口改动就重新访问一次站点地址，上传限制改动就重新传一次文件。没生效就先检查服务是否真的重启了。

## 五、Crontab 定时任务

Crontab 的写法与 Linux 的 crontab 一致，一行一条，前五段是时间（分 时 日 月 周），后面是要执行的命令：

```text
0 3 * * * 你的命令      # 每天凌晨 3 点执行
*/10 * * * * 你的命令   # 每 10 分钟执行一次
```

定时任务适合做周期性的事情，比如定时备份数据库内容到手机存储。

## 六、改坏了起不来怎么办

1. 用留底的原始配置换回去，再重启服务；
2. 没留底的话，能想起改了哪几行就手工改回；想不起来，就先把网站路径里的文件和数据库内容导出备份，然后卸载重装 WSToolbox，重新按 [怎么创建网站.md](怎么创建网站.md) 建站。
