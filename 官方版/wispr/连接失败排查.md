# Wispr 连接失败排查

> Wispr 一直转圈连不上、消息发不出去、通话接不通时，按本篇的顺序排查网络与账号，多数情况几分钟内能定位。

## 一、先判断是哪一类「连不上」

症状不同，根因不同。先对号入座：

| 症状 | 大概率原因 |
| --- | --- |
| 首次发消息后对方一直收不到 | 对方还没接受你的首次联系请求（不是网络问题） |
| 完全连不上服务器、一直转圈 | 当前网络限制了 P2P 端口或出网 |
| 消息能发但通话总失败 | P2P 握手成功但媒体通道被网络挡住 |
| 只在某个 Wi-Fi 下出问题 | 该网络做了端口/协议限制 |

第一种情况不需要排查网络——Wispr 的加密设计要求双方设备先完成密钥交换，对方接受请求之前，你的消息内容无法被解密送达，机制见[加密与隐私机制](加密与隐私机制.md)。剩下的才是网络问题，往下看。

## 二、按这个顺序试（官方给出的基础步骤）

官方 FAQ 给出的应对很朴素，按顺序执行：

1. **切换 Wi-Fi 与移动数据**：用流量再连一次。多数「家里连不上、流量秒连」的情况，都是路由器或运营商网络对 P2P 的限制。
2. **重启手机后再打开应用**：清掉挂起的后台连接与异常的网络状态。
3. **持续无法连接就换网络环境**：换个 Wi-Fi、换个地点。如果换了网络立刻正常，基本可以确认是原先那个网络对 P2P 端口的限制较为严格，这种情况只能换网或与网络管理方沟通，应用侧无解。

## 三、P2P 直连为什么容易被网络「卡住」

Wispr 默认在设备之间直接建立连接，不走中心服务器转发。这对隐私有利，但也意味着：

- 你的网络必须允许两端设备互相「找到」对方，这个过程（握手）涉及特定端口与协议；
- 公司网络、校园网、部分公共 Wi-Fi 常年封禁这类流量，握手直接失败；
- 网络确实挡死时，Wispr 会尝试借助中继（relay）建立连接——内容仍然加密，但连接质量与成功率会打折。

所以「昨天还好好的、今天连不上」时，先想想是不是换了网络环境，而不是急着重装应用。

## 四、重装与更新前先做两件事

如果上面的步骤都试过仍不行：

1. **确认版本不是太旧**：旧版本的连接组件可能与当前服务端不兼容。到官网 `https://wispr.chat` 下载页核对最新版本号；手里的安装包是哪个版本，参考[下载与安装教程](下载与安装教程.md)里的说明。
2. **记住重装的代价再动手**：卸载应用会**永久删除本地的加密密钥**，聊天数据随之无法恢复。重装前务必确认没有需要保留的记录，或已按[聊天记录备份与迁移](聊天记录备份与迁移.md)另行备份。

重装后要重新走一遍注册/登录，入口与账号类型的选择见[注册与账号类型](注册与账号类型.md)。

## 五、还不行就找官方

以上都试过仍然连不上，用官方支持邮箱联系：发送邮件到 `support@cryptodata.com`，描述清楚「什么网络环境、什么操作、什么提示」，附上应用内看到的具体报错文字，能显著加快处理。

日常功能的使用问题（消息模式怎么设、通话怎么打）不属于连接故障，先翻[消息与通话功能](消息与通话功能.md)。
