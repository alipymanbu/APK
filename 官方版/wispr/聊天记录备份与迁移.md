# Wispr 聊天记录备份与迁移

> Wispr 的聊天记录不自动上云，换手机、重装、登出都可能丢数据。本篇讲清各操作下数据会怎样、换机前该做什么。

## 一、先记住结论：没有云端同步

Wispr 的设计里，聊天内容只存在你的设备上，云端不存一份可恢复的副本。这意味着三件事：

- **换手机**：旧手机上的本地记录不会自动跟到新手机；
- **卸载应用**：本地记录随密钥一起删除，重装后是全新开始；
- **恢复出厂/重置设备**：与卸载同效，记录不可找回。

这不是故障，是加密设计的代价——官方服务器没有你的密钥，也就没有能力帮你恢复任何内容。把「重要内容自己备份」当成使用 Wispr 的前置习惯，而不是出事后的补救。

## 二、多设备登录时，每台各存各的

如果你把同一账号同时登在手机和桌面端（桌面版支持 Windows 7+ 与 macOS 10.6+），每台设备会**各自维护一份本地数据副本**。官方隐私公告里对此有明确说明：

- 在手机上登出或卸载，删除的是**手机这一台**上的数据；
- 之前已经同步到桌面端本地的部分消息和文件，**可能仍留在那台电脑上**，不会跟着手机一起消失。

这个特性有两面：对你来说，桌面端等于一份「意外备份」，手机丢了还能从电脑上翻到历史消息；从隐私角度想，清理痕迹时也要**逐台处理**，只删手机不等于删干净。

## 三、换机前的操作清单

按这个顺序做，能把损失降到最低：

1. **先在旧手机上翻一遍需要保留的对话**，把里面的文档、图片等重要文件**另存到应用外**（相册、文件管理器、你自己信任的存储位置）；
2. **在应用内找导出/备份入口**，把需要留档的聊天记录手动导出——入口位置随版本可能调整，以你手机上的实际界面为准；
3. 导出的文件走你自己选的通道传到新手机（网盘、数据线均可），**不要依赖重装后找回**；
4. 新手机装好并登录后，再处理旧手机：确认没有遗漏，然后登出或卸载。

第 2 步如果找不到导出入口，说明当前版本可能不提供记录迁移，那就把第 1 步做扎实——至少文件类内容都能手动救出来。

## 四、卖旧手机前的逐台清理

换机出二手时，只恢复出厂旧手机还不够，按官方口径逐项过：

| 操作 | 清掉了什么 | 没清掉什么 |
| --- | --- | --- |
| 手机登出/卸载 | 该手机的本地记录与密钥 | 桌面端的本地副本 |
| 电脑端登出/卸载 | 该电脑的本地副本 | 其他设备的副本 |
| 恢复出厂 | 该设备全部数据 | 云端服务器上你提供的账号信息（按官方流程另行处理） |

有账号注销需求的，在应用内找账号移除入口（对应官方的 Remove Account 能力），或按官方支持渠道办理——账号层的数据（手机号、用户 ID、有限元数据）在官方侧，只能走官方流程。

理解了「为什么数据不自动同步」，回头看[加密与隐私机制](加密与隐私机制.md)会顺很多；装机与登录步骤见[下载与安装教程](下载与安装教程.md)和[注册与账号类型](注册与账号类型.md)。
