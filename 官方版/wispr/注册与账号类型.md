## 一、三种注册入口

Wispr 支持用不同身份连接账号，官网首页列出的三种方式是：

| 方式 | 适合谁 | 说明 |
| --- | --- | --- |
| 手机号（Phone） | 个人日常使用 | 注册时提交手机号，接收验证码短信或电话完成验证 |
| 邮箱（Email） | 不想暴露手机号的人 | 用邮箱作为联系方式注册 |
| Matrix ID | 组织内用户 | 由使用 Wispr 的组织分配 ID，通过组织提供的专门认证方式登录，不走手机号注册 |

用手机号注册时，你需要拥有这个号码的使用权；验证码由官方或其第三方服务商以短信、电话形式发给你。这一步是账号创建的必经流程，跳不过去。

注册完成后可以选填昵称、头像等资料。这两类的存储位置不一样：按官方隐私政策，昵称等可选资料走端到端加密，只有你和你的联系人能看到；**头像则存储在官方服务器上，供其他用户查看**——介意这一点的，可以不放头像或用与本人无关的图片。

## 二、账号分档与费用

官网把个人/组织账号分成三档（价格为检索时官网显示，随时可能调整，以官方页面为准）：

| 档位 | 价格 | 定位 |
| --- | --- | --- |
| Basic | 免费 | 基础通讯，中等强度保护 |
| Matrix ID | 每年 49 美元 | 在 Basic 基础上启用 Matrix ID 连接方式，官方标注为强保护 |
| Enterprise | 按需报价 | 面向组织，提供私有组织 ID 等定制能力 |

选哪档取决于你的用途：只是日常加密聊天，免费档够用；需要以组织身份接入或要更强的账号保护，再考虑付费档。付费前先到官网核对当期价格与权益清单，本篇不代替官方页面承诺任何权益。

## 三、注册时常被问到的几件事

- **验证码收不到**：先确认手机号区号选对、信号正常；换 Wi-Fi 与移动数据再试一次。仍收不到就等几分钟重发，频繁点击重发反而会被限流。
- **换了手机号怎么办**：账号绑定的是注册时的号码，换号前先在应用内更换绑定或迁移账号；具体入口以应用内设置为准。
- **组织用户登录不上**：Matrix ID 用户由所在组织管理账号，登录问题先找组织管理员，而不是按个人注册流程重新注册。
- **聊天功能用不了**：注册只是第一步，联系人之间的加密会话还需要对方接受你的首次请求，机制见[加密与隐私机制](加密与隐私机制.md)。

## 四、支付相关服务是独立运营的

Wispr 官方还提供配套的账户与支付服务（官方称覆盖一百九十多个国家/地区的转账与账户能力）。按官方隐私政策的说明，这类支付/金融服务由独立公司 WISPR PAY CO., LTD 提供，适用其单独的条款与隐私政策，与本篇讲的通讯账号不是同一套协议。是否使用、如何开通，以应用内与官方页面展示为准。

注册过程中遇到安装层面的问题（装不上、打不开），回到[下载与安装教程](下载与安装教程.md)对照检查；注册好之后，先看看[消息与通话功能](消息与通话功能.md)里有哪些你能用上的能力。
