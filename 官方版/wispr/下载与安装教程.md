## 一、装之前先确认系统版本

Wispr 是一款加密通讯应用，支持手机与桌面端。各平台的最低要求如下（以官方下载页当时显示为准）：

| 平台 | 最低要求 |
| --- | --- |
| Android | Android 5.0 或更高 |
| iOS | iOS 12.0 或更高 |
| Windows | Windows 7 或更高 |
| macOS | Mac OS X 10.6 或更高 |

本篇针对安卓用户。网盘里这份安装包的版本是 1.3.2，安装包大小 63.57M，包名 `com.cryptodata.wispr`。官方会持续发新版本，装好后可以在应用内查看是否有更新提示，版本号以你实际拿到的那份为准。

## 二、安装包从哪来

两条路：

1. **官方渠道**：访问 Wispr 官网 `https://wispr.chat`，在 Download 页面按平台选择下载。把上面反引号内的地址复制到浏览器打开，避免通过搜索引擎点到仿冒站点。
2. **已备好的安装包**：如果你已经拿到 [Wispr 安装文件资源（夸克网盘）](https://pan.quark.cn/s/dda86d31d2ee) 的分享，转存到自己网盘后下载 APK 到手机即可，适合不方便当场联网下载的情况。

无论哪条路，拿到 APK 后都可以核对一下包名是否为 `com.cryptodata.wispr`，确认装的是这个应用本身。

## 三、安卓安装步骤

1. 把 APK 文件传到手机存储（网盘客户端直接下载、或电脑复制过去均可）。
2. 在文件管理器里点开这个 APK。系统会提示「未知来源应用」，按提示允许该来源安装——不同品牌手机的入口名称略有差异，一般在弹窗里点「设置」→「允许此来源安装」即可。
3. 回到安装界面，点「安装」，等待完成。
4. 点「打开」进入应用。

如果安装中途报「解析包错误」，常见原因是下载不完整：重新下载一次安装包再试。安装完成后若打不开或卡在启动界面，参见[连接失败排查](连接失败排查.md)。

## 四、首次启动会看到什么

第一次打开 Wispr 会进入注册/登录引导，需要先创建账号才能使用聊天功能。注册支持手机号、邮箱、Matrix ID 三种方式，账号也分免费与付费两档，具体差别与操作见[注册与账号类型](注册与账号类型.md)。

注册完成进入主界面后，你可以先熟悉聊天与通话入口，功能概览见[消息与通话功能](消息与通话功能.md)。如果暂时没有联系人，也可以先看一下[加密与隐私机制](加密与隐私机制.md)——Wispr 的首次联系人请求需要对方接受后才能开始加密会话，了解这一点能省掉不少困惑。

## 五、桌面版与多设备

手机之外，官方还提供 Windows（Win 7+）与 macOS（10.6+）桌面版，从官网 Download 页按平台下载。同一账号可以在手机与电脑上同时使用，但要注意：**每台设备各自保存一份本地聊天数据**，登出或卸载只影响当前这一台——换机或清理设备前先弄清这个机制，见[聊天记录备份与迁移](聊天记录备份与迁移.md)。
