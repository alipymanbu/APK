## 一、WiFi 列表是空的，或一个网络都扫不出来

按命中率排四步：

1. **位置权限**：系统设置 → 应用 → IP Tools → 权限 → 位置，改成「使用应用时允许」。安卓 12 以上建议给精确位置，只给「大致位置」可能列表不全（为什么必须要这个权限，见 [下载与安装教程.md](下载与安装教程.md) 第五节）；
2. **系统定位总开关**：安卓的 WiFi 扫描结果依赖「位置服务」总开关，关了它，权限给了也扫不出来。下拉通知栏确认定位图标是亮的；
3. **是不是在用流量**：关掉 WiFi、只连蜂窝时，扫描类功能没有局域网可扫；
4. **刚改过权限**：部分机型改完权限要杀掉应用重开才生效，从后台划掉再打开；
5. **刷新太快**：安卓限制扫描频率，连着点刷新会被限流，拿回的还可能是上一次的旧结果——停半分钟再刷。

权限与系统的这几条限制在 [WiFi分析仪和局域网扫描怎么用.md](WiFi分析仪和局域网扫描怎么用.md) 里有更细的说明；列表出来了但某台设备 ping 不到，判断它和你是否同网段见 [子网掩码和IP计算器怎么用.md](子网掩码和IP计算器怎么用.md)。

## 二、局域网扫描结果比实际设备少

先对照 [WiFi分析仪和局域网扫描怎么用.md](WiFi分析仪和局域网扫描怎么用.md) 确认扫的是自家网络，再看这几条：

- 设备休眠会漏扫：夜里闲置的摄像头、笔记本断电离线，本来就扫不到；
- 路由器开了「AP 隔离 / 访客网络」：同一 WiFi 下的设备互相不可见，扫描只列出没被隔离的那部分，去 [路由器设置页](路由器设置页打不开怎么办.md) 关掉隔离即可；
- 手机省电策略杀后台：扫描中途切走导致列表不完整，留在前台重扫一次；
- 扫的网段和设备不在一段：静态 IP 的设备可能被配到别的网段，用 [ping和路由追踪怎么用.md](ping和路由追踪怎么用.md) 单独 ping 它的地址验证。

## 三、安装时被系统拦下

「安装未知应用」拦截是安卓对侧载安装的默认限制，不是病毒报警——授权步骤在 [下载与安装教程.md](下载与安装教程.md) 第四节。若给了权限仍装不上，依次核对：包名是否为 `com.ddm.iptools`、MD5 是否与下载页表格一致、手机剩余空间是否大于 7.08M、系统版本是否高于包内声明的下限。厂商系统的「纯净模式」会额外拦截，按提示选「仍要安装」。

## 四、改完 WiFi 密码后手机连不上

密码是在路由器后台改的，改完手机上保存的旧密码立即失效：

1. 在手机 WiFi 列表里长按该网络 → 忘记此网络；
2. 重新选择它，输入新密码连接；
3. 家里其他设备（电视、音箱、平板）同样要逐个忘记再重连，它们不会自动同步新密码；
4. 连回来之后重开 IP Tools 扫一遍，确认设备列表恢复正常，说明网络已回到正常状态。

## 五、ping 或扫描的结果和电脑上不一致

两边的网络路径不同，结果本来就可能不同：手机连的是 5GHz、电脑插网线，延迟与可达设备都会有差别。排查时先用 [首页 IP 信息页](WiFi分析仪和局域网扫描怎么用.md) 把两边的网关、网段对齐——网关相同才说明在同一个局域网里。仍不一致时，用 [ping和路由追踪怎么用.md](ping和路由追踪怎么用.md) 的三步链在两台设备上各测一遍，差异会落在具体某一跳上。

## 六、广告、内购与版本差异

应用免费，商店页标注含广告与内购（是否有去广告档、价格多少，以商店当时显示为准，本文不给具体数字）。另外，网盘安装包与商店版本常常不同步：

| 来源 | 版本 | 说明 |
| --- | --- | --- |
| 本文与网盘 | 9.4.6（7.08M，2026-09-23 记录） | 与本套文档的截图、字段对应 |
| 官方商店（截至 2026-09 查询） | 9.6.1、9.8 等，体积已涨到十几 MB 以上 | 各商店推送节奏不同，以商店当时显示为准 |

升级到商店新版后，个别菜单的位置可能变化，但工具种类与本文的排查思路不受影响。装不上旧包或想换版本，回 [下载与安装教程.md](下载与安装教程.md) 重新取包核对。

## 七、权限想收回、应用想卸载

不用了就到系统设置里把位置权限改成「拒绝」，扫描类功能随即停用，其余查询功能不受影响；彻底卸载则在设置 → 应用里直接卸载，它不会留下常驻服务。有产品问题需要反馈，官方渠道是官网 [ip-tools.app](https://ip-tools.app/) 与商店页面留的客服邮箱（以商店当时显示为准）。
