## 一、先把位置权限给到位

这三个功能都依赖系统的位置授权，没给就出不了结果（原因与安卓 API 的关系见 [下载与安装教程.md](下载与安装教程.md) 第五节）。开扫描前确认两件事：系统「定位服务」总开关是开着的，IP Tools 拿到的是「使用应用时允许」。安卓 12 以上若只给了「大致位置」，周边网络列表可能不完整，建议给精确位置。权限被拒后的补救步骤见 [常见问题与排查.md](常见问题与排查.md)。

## 二、首页 IP 信息：一张屏先回答「我的网络现在什么状态」

打开应用的首屏就是连接信息页，它把一次判断所需的字段全摆在一起。你按「谁的问题」这个顺序读：

| 字段 | 你读它干什么 |
| --- | --- |
| 外网 IP | 你的公网出口地址。换 Wi-Fi 和用流量时它不同——两次不一样说明出口换了 |
| 内网 IP | 手机在当前局域网里的地址，通常形如 `192.168.x.x` |
| 网关 | 数据出门必经的第一跳，就是你的路由器；[路由器设置页](路由器设置页打不开怎么办.md) 通常就开在它上面 |
| DNS | 域名解析服务器。能上网但网页打不开时，先怀疑这里 |
| SSID / BSSID | 当前连的 WiFi 名与路由器热点的物理地址 |
| 信号强度、WiFi 速度 | 判断「离路由器远了」还是「路由器本身有问题」的第一手证据 |
| 掩码、广播地址 | 你这台设备所在的网段，局域网扫描按它决定扫哪一段；怎么读见 [子网掩码和IP计算器怎么用.md](子网掩码和IP计算器怎么用.md) |
| 国家 / 城市 / ISP、经纬度 | 公网 IP 的归属地，能核对出口是否走了代理或公司网络 |

判断套路：网关 ping 不通（见 [ping和路由追踪怎么用.md](ping和路由追踪怎么用.md)）说明问题在你和路由器之间；网关通、外网 IP ping 不通说明问题在路由器之外。先有这张表，后面的扫描和 ping 才有参照。

## 三、WiFi 分析仪：换信道前先看这张图

WiFi 分析仪列出周边所有能收到的网络，逐个给出信号强度、信道与加密方式。它最常见的用途是给自己的路由器挑信道——旁边邻居的 WiFi 都挤在同一个信道上时，你会感觉「路由器没坏但就是慢」。

读图方法：

- **2.4GHz 频段**只有 1、6、11 三个互不重叠的信道。你在列表里数一下，哪个信道上叠的强信号最少，就把路由器调到哪个；
- **5GHz 频段**信道多、互不重叠，一般不用刻意避让，看信号强度即可；
- 信号强度的量级参考：-30 ~ -50dBm 很强，-60 ~ -70dBm 可用，低于 -80dBm 就基本掉线边缘了（各机型显示口径可能略有差异）；
- 加密方式一栏看清是 WPA2/WPA3 还是「开放」——连到开放网络时，别在里面输账号密码。

改信道要进路由器管理页操作，入口见 [路由器设置页打不开怎么办.md](路由器设置页打不开怎么办.md)。分析仪只负责告诉你「该改到哪」，不替你改。

刷新时注意：安卓对 WiFi 扫描有频率限制，短时间内连续点刷新会被系统限流，而且返回的可能是上一次扫描的旧结果。列表和你记忆对不上时，隔半分钟再刷一次，以最新一屏为准。

## 四、局域网扫描：找出连进你 WiFi 的陌生设备

局域网扫描会按手机所在的网段，把当前在线的设备逐台列出来——手机、笔记本、电视、摄像头、音箱都在其中。它的典型用途是排查蹭网：把你自家已知设备的 IP 或 MAC 地址对一遍，多出来的那个就是陌生设备。

操作顺序：

1. 连着自家 WiFi 运行扫描（用流量扫不出局域网）；
2. 对照结果：先认你自己的手机、电脑、电视，剩下的逐个看主机名；
3. 发现陌生设备 → 打开 [路由器设置页打不开怎么办.md](路由器设置页打不开怎么办.md) 进管理后台，在「已连设备 / DHCP 客户端列表」里把它踢掉，并给 WiFi 换一个密码；
4. 换完密码再扫一次，确认只剩自家设备。

两个边界要记住：**扫描只应该对你自己有权限的网络做**——扫公司、公共 WiFi 里的其他用户设备越界了；另外，设备不在线时扫不到，晚上摄像头、闲置笔记本休眠了会「漏」，这不代表它不在。

## 五、结果和预期对不上时

扫出来比实际设备少、信号忽有忽无、列表一直转圈，这些多数是权限与系统限制导致的，不是应用坏了，逐条对照 [常见问题与排查.md](常见问题与排查.md)。想进一步定位某台设备是否真的在线，用 ping 单独敲它，方法在 [ping和路由追踪怎么用.md](ping和路由追踪怎么用.md)。
