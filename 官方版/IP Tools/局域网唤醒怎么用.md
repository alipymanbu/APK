## 一、这个功能在干什么、你要准备什么

局域网唤醒（Wake on LAN，简称 WoL）的原理一句话：电脑关机或睡眠后，网卡仍带电待命，手机往局域网里发一个指定格式的数据包，网卡认出这个包就通知主板开机。官方功能列表里的「Wake on LAN」就是干这个的。

你这边只需要两个信息，都能在 [局域网扫描](WiFi分析仪和局域网扫描怎么用.md) 里拿到：

- **目标电脑的 MAC 地址**——发包只认它，不认 IP；
- **广播地址**——把包撒到整个网段，一般是「你的内网 IP 所在网段的最后一个地址」（如网段 `192.168.1.x` 就填 `192.168.1.255`），[IP 计算器那一套](子网掩码和IP计算器怎么用.md) 里能算出来。

三个前提缺一不可：电脑**插着网线**（无线唤醒的支持很不稳定，别指望 WiFi）、主板和网卡**支持并打开了 WoL**、**电脑和手机在同一个局域网**。从外面（移动网络）唤醒要额外在路由器上开转发，家用场景不建议折腾——出门前让电脑开着待命更省事。

## 二、电脑侧：三处设置

按顺序做，少一处都唤不醒：

1. **BIOS/UEFI**：开机按 `Del`/`F2` 进设置，在 Power Management 或 Advanced 里找 `Wake on LAN`、`Power On by PCI-E`、`Resume by LAN` 之类选项（各厂商标法不同），打开并保存。同一页若有 `ErP Ready` / `Deep Power Off` 这类深度节能选项，**关掉它**——它会在关机后切断网卡待机供电；
2. **Windows 网卡设置**：设备管理器 → 网络适配器 → 你的有线网卡 → 属性：
   - 「电源管理」页勾选「允许此设备唤醒计算机」，同时勾「只允许魔术数据包唤醒计算机」（后者能防止网络杂讯误触发开机）；
   - 「高级」页把 `Wake on Magic Packet` 设为 Enabled；
3. **确认关机方式**：按机箱电源键硬关机会跳过正常断电流程，WoL 通常失效——用系统里的「关机」或「睡眠」。

台式机三步做完基本就绪。笔记本还有额外限制：不少机型只用电池时会禁用 WoL，插电状态下更稳（截至 2026 年的公开资料口径，具体以机型手册为准）。

## 三、路由器侧：给电脑固定一个地址

唤醒包虽然靠 MAC 定位，但不少实现仍要求目标 IP 有效。进 [路由器设置页](路由器设置页打不开怎么办.md)，做两件事之一：

- **IP 与 MAC 绑定**（部分品牌叫「静态地址分配」）：把电脑的 MAC 和一个固定 IP 绑死；
- **DHCP 地址保留**：在 DHCP 服务器里为该 MAC 保留同一地址。

不绑的后果是：电脑下次开机拿到新 IP，你存在手机里的旧地址对不上，唤醒就时灵时不灵。绑定后，把这个 IP 一并记进手机里的唤醒目标。

## 四、手机上怎么发

1. 手机连上与电脑相同的 WiFi（用流量发不出局域网包）；
2. 打开 IP Tools 的 Wake on LAN 功能，填目标 MAC、广播地址与端口（默认端口即可，界面给了什么就用什么）；
3. 点发送，等 10~30 秒看电脑是否启动；
4. 发之前可以先用 [ping](ping和路由追踪怎么用.md) 试一下目标 IP——电脑若本来就没在待机状态，ping 通说明网络路径没问题，之后唤醒不灵就只可能是 WoL 设置。

## 五、唤不醒时逐条排

| 现象 | 最可能的原因 | 处理 |
| --- | --- | --- |
| 完全没反应 | BIOS 没开，或 ErP/深度节能把网卡断电了 | 回第二节第 1 步核对 |
| 完全没反应 | 电脑插的是 WiFi，或网线没插好 | 换有线、换网口试试 |
| 时灵时不灵 | 电脑 IP 变了，或手机与电脑不在一个网段 | 按第三节做 IP/MAC 绑定 |
| 以前能用，突然不行 | 电脑是被硬关机的 | 改用系统「关机」再试 |
| 扫描能看见电脑，但发包无效 | 路由器开了 AP 隔离，广播到不了电脑 | 到 [路由器设置页](路由器设置页打不开怎么办.md) 关闭隔离 |
| 全部检查过仍不行 | 主板或网卡本身不支持 | 查主板说明书的 WoL 条目再判断 |

先用 [局域网扫描](WiFi分析仪和局域网扫描怎么用.md) 确认电脑的 MAC 与网络状态，再回上面这张表对号入座，多数情况能在两轮内定位。
