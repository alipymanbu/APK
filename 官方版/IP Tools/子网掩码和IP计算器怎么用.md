## 一、什么时候你真的需要算这些

家用场景里，下面这几件事都会逼你碰掩码：

1. **两台设备连着同一个 WiFi 却 ping 不通**——先确认它们是不是真的在同一网段（[ping 那篇](ping和路由追踪怎么用.md) 的第一步就是干这个）；
2. **给设备配静态 IP**——配错网段，设备直接从局域网里「消失」，[局域网扫描](WiFi分析仪和局域网扫描怎么用.md) 里看不到它；
3. **在路由器上设 DHCP 地址池、端口转发、AP 隔离范围**——填的全是网段；
4. **发[局域网唤醒](局域网唤醒怎么用.md)包**——广播地址要按网段算。

`192.168.1.100/24` 这样的写法里，斜杠后面的数字就是前缀长度（CIDR）：前 24 位固定是「网络」，剩 8 位给「主机」。掩码只是同一件事的另一种写法——`/24` 就是 `255.255.255.0`。

## 二、常见前缀对照表

| 前缀 | 掩码 | 总地址数 | 可用主机数 |
| --- | --- | --- | --- |
| `/16` | `255.255.0.0` | 65536 | 65534 |
| `/24` | `255.255.255.0` | 256 | 254 |
| `/25` | `255.255.255.128` | 128 | 126 |
| `/26` | `255.255.255.192` | 64 | 62 |
| `/27` | `255.255.255.224` | 32 | 30 |
| `/28` | `255.255.255.240` | 16 | 14 |
| `/30` | `255.255.255.252` | 4 | 2 |

可用主机数 = `2^(32−前缀) − 2`，减掉的两个是**网络地址**（主机位全 0）和**广播地址**（主机位全 1），它们不能分给设备。家用路由器默认给你的就是 `/24`：254 个可用地址，对家庭绰绰有余。

## 三、拿一个真实地址算一遍

你在 [IP 信息页](WiFi分析仪和局域网扫描怎么用.md) 上看到自己是 `192.168.1.100`、掩码 `255.255.255.0`，把结果算出来是：

- 网络地址：`192.168.1.0`——你属于这个网；
- 广播地址：`192.168.1.255`——[局域网唤醒](局域网唤醒怎么用.md)的包就发往这里；
- 可用范围：`192.168.1.1` ~ `192.168.1.254`——路由器一般占 `.1`，其余分给设备。

判断「两台设备通不通」的口径随之明确：两台设备的地址在同一个网络地址下（这里就是前 3 段相同）、且掩码一致，才算同网段，可以直接互通；否则数据会先交给网关绕路，ping 不通是常态。

IP Tools 里的 IP 计算器就是替你做这套换算的：输入 IP、掩码（或前缀），它给出网络地址、广播地址、可用范围与主机数。不想打开应用时，心算前缀也够用——掩码每段是 255 就是「整段固定」，出现 128/192/224/240 这类数才需要落到最后一个段里去算。

## 四、为什么你家和邻居家都是 192.168 开头

`10.x.x.x`、`172.16.x.x`~`172.31.x.x`、`192.168.x.x` 三段是**私有地址**（RFC 1918 规定），只在内部网络里用、公网不路由。所以两家路由器可以都发 `192.168.1.x` 而不冲突——这也解释了 [IP 信息页](WiFi分析仪和局域网扫描怎么用.md) 上「内网 IP」和「外网 IP」为什么是两套：内网地址只在你家里有意义，出了路由器就换成公网地址了。

顺带一个判读技巧：手机显示的内网 IP 如果是 `10.` 或 `172.16~31.` 开头，说明你连的可能是公司、校园或运营商级大网，网段规划不再是家用的 `/24`，静态 IP 和端口转发这类操作更要按实际掩码来，别照抄家用教程。

## 五、两个易错点

- **掩码不能随便填**：静态 IP 配置里掩码与同网段其他设备不一致，设备会「看似连着却谁也 ping 不通」；照 [IP 信息页](WiFi分析仪和局域网扫描怎么用.md) 上读到的填即可；
- **别按「设备数量」凑整**：需要 50 个地址时最小的合适前缀是 `/26`（62 个可用），子网大小只能按 2 的幂切分，没有「正好 50 个」的网段。

遇到算不准的场合，直接把数字丢进 IP 计算器核对一遍，比心算可靠。
