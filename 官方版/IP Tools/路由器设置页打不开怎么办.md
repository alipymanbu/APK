## 一、路由器设置页入口是怎么工作的

IP Tools 里那个「路由器设置页 / Router Setup」按钮做的事很简单：它读出你当前网络的网关地址（[首页 IP 信息页](WiFi分析仪和局域网扫描怎么用.md) 上就有），然后在浏览器里打开这个地址。多数家用路由器的管理后台就挂在网关上，常见地址是 `192.168.1.1`、`192.168.0.1` 或 `192.168.31.1`——但**以你在 IP 信息页读到的网关为准**，不同品牌不一样，别照抄别人教程里的地址。

也有绕开按钮手动开的办法：把网关地址整段复制进浏览器地址栏，回车即可。改 WiFi 名称密码、换信道（配合 [WiFi 分析仪](WiFi分析仪和局域网扫描怎么用.md) 挑好的信道）、踢掉蹭网设备，都在这个后台里完成。

## 二、设置页打不开的五种常见原因

按命中率从高到低逐条排：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 完全打不开、转圈 | 手机没连这家路由器的 WiFi（连着流量或别人家的网） | 切回自家 WiFi 再点一次；关掉蜂窝数据避免自动切换 |
| 提示无法访问 | 地址猜错了 | 回 [IP 信息页](WiFi分析仪和局域网扫描怎么用.md) 读「网关」，照那个地址进 |
| 一直转圈超时 | 路由器禁止从无线侧访问管理页，或路由器正异常 | 手机连网线/重启路由器；仍不行用电脑直连试 |
| 页面样式错乱、登录框不显示 | 浏览器强制 HTTPS 或缓存了旧页面 | 地址前手动写 `http://`，或换个浏览器、开无痕窗口 |
| 打开了但登录页反复刷新 | 手机开了代理/VPN，请求没走到路由器 | 关掉代理与 VPN 后重试 |

先用 ping 把网关通不通验一遍会更快：网关 ping 不通，说明你和路由器之间就断了，问题不在管理页本身，排查路线见 [ping和路由追踪怎么用.md](ping和路由追踪怎么用.md)。

## 三、进得去但忘了管理员密码

管理密码是路由器自己的登录口令，与 WiFi 密码是两回事（有的品牌允许两者同名，但默认不是）。找回顺序：

1. 先试路由器底部标签上印的默认地址与默认密码——很多出厂贴纸就写着；
2. 家里有人改过、没人记得 → 找到路由器上的 `Reset` 小孔，通电状态下长按约 10 秒恢复出厂，之后用标签上的默认密码重新登录；
3. 恢复出厂会清掉你改过的拨号、WiFi 名、密码、端口转发等全部设置，**重设前先把宽带账号密码准备好**（问运营商或看原设置页），否则恢复完连不上网。

## 四、进去之后最常动的三处设置

- **WiFi 名称与密码**：改完所有设备要重连，见 [常见问题与排查.md](常见问题与排查.md) 里「改完密码连不上」那条；
- **无线信道**：按 [WiFi分析仪和局域网扫描怎么用.md](WiFi分析仪和局域网扫描怎么用.md) 挑出的信道填入，2.4GHz 只在 1、6、11 里选；
- **已连设备 / DHCP 列表**：对照局域网扫描结果，把陌生设备踢掉并拉黑 MAC；给自家电脑做 IP 与 MAC 绑定（固定地址），是 [局域网唤醒](局域网唤醒怎么用.md) 稳定生效的前提；

改完设置页面若突然断连，那是改到了正在生效的参数（最典型是信道与加密方式），等 30 秒重连 WiFi 即可；重连后仍异常，按 [常见问题与排查.md](常见问题与排查.md) 处理。
