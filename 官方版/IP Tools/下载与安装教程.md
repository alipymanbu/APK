## 一、IP Tools 是什么

IP Tools 是一款安卓网络工具箱，应用商店里的完整标题是「IP Tools: Network Utilities」，包名 `com.ddm.iptools`，商店页面显示开发者为 AmazingByte，官网是 [ip-tools.app](https://ip-tools.app/)（有俄文、英文等多语版本）。它把平时要在电脑上敲命令才能做的事——ping、路由追踪、DNS 查询、端口扫描、局域网设备列表、子网计算——做成了手机上的图形界面，还带 WiFi 信道分析与路由器管理页直达入口。

典型使用场景就三类：家里网速变慢时先自己判断问题出在路由器、运营商还是对方服务器；连了陌生 WiFi 时看清这个网络的网关、DNS 与信号状况；以及排查「是不是有人在蹭我的网」。装好之后按 [WiFi分析仪和局域网扫描怎么用.md](WiFi分析仪和局域网扫描怎么用.md) 走一遍，就能看懂首页那一屏网络参数。

应用本身免费，商店页标注含广告与内购（是否值得开付费版、各档价格，以商店当时显示为准）。

## 四、安装步骤

1. 把 APK 从网盘下载到手机存储（用系统自带的「文件管理」打开下载目录即可）。
2. 点击 APK 文件，系统会弹出「安装未知应用」拦截——这是安卓对侧载安装的默认限制，不是病毒报警。
3. 按提示给浏览器或文件管理器授予「允许安装此应用」，返回继续安装。
4. 装完打开，首屏会直接显示当前连接的网络参数，无需注册账号。
5. 首次使用扫描类功能时会弹位置权限请求，按下一节说明授权。

部分厂商系统（MIUI、ColorOS 等）还会额外弹一次「纯净模式」或安全确认，选继续安装即可；若安装按钮始终置灰，见 [常见问题与排查.md](常见问题与排查.md)。

## 五、为什么一上来就要位置权限

官方在应用说明里写得很直接：检测附近的 WiFi 网络需要位置权限，这是 Android 系统 API 的要求，不是这个应用自己加的。安卓从 6.0 起把位置权限改成了运行时授权，从 10.0 起又限制了后台与模糊定位的用法——只要涉及「列出周边 SSID、信号强度、信道」，系统就要求应用拿到位置授权。

你授不授予，影响范围是清楚的：

- 授予 → WiFi 分析仪、局域网扫描这类功能能正常出结果；
- 拒绝 → 这类功能会拿不到周边网络列表，但 IP 信息、ping、DNS 查询、WHOIS 这些不依赖位置的工具照常能用。

只想看「我的 IP 和网关是什么」的话，可以先拒绝，用到扫描时再在系统设置里打开。权限管理的具体做法见 [常见问题与排查.md](常见问题与排查.md)。

## 六、装完先看哪几个功能

官方列出的工具包括：Ping、WiFi 与局域网扫描、端口扫描、DNS 查询、WHOIS、路由器设置页直达、路由追踪、WiFi 分析仪、我的 IP、连接日志、IP 计算器、IP 与主机名换算、Netstat 统计、局域网唤醒（Wake on LAN）。你上手时按这个顺序最有用：

1. 首页把外网 IP、网关、DNS、信号强度看一遍——这是后续一切判断的基准，字段含义见 [WiFi分析仪和局域网扫描怎么用.md](WiFi分析仪和局域网扫描怎么用.md)；
2. 网速不对劲时，用 ping 与路由追踪定位问题段，见 [ping和路由追踪怎么用.md](ping和路由追踪怎么用.md)；
3. 要改 WiFi 名称、密码、信道时，从路由器设置页入口进管理后台，打不开就照 [路由器设置页打不开怎么办.md](路由器设置页打不开怎么办.md) 排查；
4. 想用它把家里电脑叫醒，先按 [局域网唤醒怎么用.md](局域网唤醒怎么用.md) 把电脑侧三处设置做完；
5. 碰到掩码、网段、广播地址这些词卡住了，[子网掩码和IP计算器怎么用.md](子网掩码和IP计算器怎么用.md) 有对照表和实例。
