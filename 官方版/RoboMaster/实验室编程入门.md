## 一、实验室在哪，能做什么

手机连上机器人后，在 App 里进入「实验室」（Lab）就是编程入口。它的定位是：不装任何开发环境，在手机上直接给机器人写程序。官方给了两条路线：

| 路线 | 形态 | 适合谁 |
| --- | --- | --- |
| Scratch 图形化编程 | 拖拽积木块拼接逻辑，图形化模块超过百个 | 编程零基础的新手 |
| Python | 写代码，可调用更底层的接口 | 有一定基础，想做 PID 控制、机器视觉这类进阶功能 |

两条路线用的是同一套机器人能力，图形化玩熟了转 Python 是官方设计的进阶路径，不用推倒重来。想越过 App、直接在电脑上用 Python 控制机器人，就轮到 SDK 出场，接入方式和端口见 [Python与SDK连接参数](Python与SDK连接参数.md)。

## 二、大师之路：跟着教程走

实验室里内置了官方的阶梯式项目教程（大师之路），把编程知识拆成一个个小任务，按难度逐级往上走。官方手册对它的定位是「通过阶梯型项目式教程逐步掌握编程理论和机器人系统知识」，官方更新日志里出现过的任务就包括漂移、闪电打击这类驾驶与操控练习。

用法上的建议只有一条：按顺序做，别跳关。后面的任务默认你已掌握前面教过的模块，跳关卡住的概率很高。官方编程指南（[www.dji.com/robomaster-s1/programming-guide](https://www.dji.com/robomaster-s1/programming-guide)）是配套文字资料，图形化界面里找不到某个积木的用法时去那里查。

## 三、我的程序：写完装到机器人上

在「我的程序」里新建程序、拼积木或写代码，写完的成果分两种用法：

1. **在实验室里直接运行**：连着机器人，点运行就能看效果，适合调试。
2. **装配成自定义技能**：官方支持把写好的程序一键装配到机器人上，之后在单机驾驶或多人竞技中当技能用——比如把一套固定走位加开火的逻辑做成技能，对战中一键触发。

程序成果可以分享给其他 RoboMaster 用户，App 内操作即可，不需要导出文件。

## 四、六大智能识别模块

编程和玩法里能用上的机器视觉与感知能力，官方一共列了六个：

| 模块 | 干什么用 | 编程里怎么用 |
| --- | --- | --- |
| 线路识别 | 认出地面上贴的引导线 | 让机器人沿线行驶 |
| 视觉标签识别 | 认出贴纸式的视觉标签 | 触发动作：看到某标签就转向/开火 |
| 行人识别 | 认出画面里的人 | 做跟随、躲避类程序 |
| 掌声识别 | 听到掌声触发事件 | 声控启动、掌声接力 |
| 姿势识别 | 认出特定人体姿势 | 对镜头做动作触发程序 |
| S1 机器人识别 | 认出另一台 S1 | 多机对战里识别对手 |

这些模块在图形化编程里都以积木形式出现，直接拖进程序就能用；识别条件（比如标签编号、掌声次数）在积木参数里设。视觉标签、引导线这类道具的规格和用法，以官方编程指南的说明为准。

## 五、先看视频再动手

官方教学视频有两个入口：App 内的指引页，或官网 [www.dji.com/robomaster-s1/video](https://www.dji.com/robomaster-s1/video)，里面有从组装到图形化编程的系列课程。第一次进实验室建议先把图形化编程那一集看完再动手，比盲试省时间。

写出来的程序在对战里怎么用得更好，衔接 [操控与对战玩法](操控与对战玩法.md)；机器人还没激活的话，先回 [连接机器人与激活步骤](连接机器人与激活步骤.md) 把设备跑起来。
