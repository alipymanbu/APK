## 一、四种操控方式

App 对机器人的操控不只有触屏一种，按场景选：

| 操控方式 | 怎么用 | 适合场景 |
| --- | --- | --- |
| 触屏 | 虚拟摇杆 + 屏上按键，默认方式 | 日常练习、没有外设时 |
| 体感 | 用手机的姿态变化控制云台指向 | 想要「指着哪打到哪」的直觉操作 |
| 游戏手柄 | 蓝牙手柄连接手机，官方列为选配件 | 长时间对战、想要实体摇杆手感 |
| 键盘鼠标 | 需要装 Windows 版 RoboMaster，在电脑上操控 | 追求精准瞄准和走位 |

手柄是选配的，官方包装里不含；键鼠方式走的是电脑端软件，手机端没有这个入口。另外 App 与机器人之间还支持对讲（官方 v1.0.8 更新加入）：你可以在 App 里录音、由机器人扬声器播放出来，反过来录机器人的声音到 App 里收听也行。

## 二、单机驾驶：一个人也能练

不连路由器、手机直连机器人就能玩单机模式。官方手册把单机玩法归为竞速、乱斗、移动射击等几类，你可以把它当成训练场：

- **熟悉底盘**：S1 底盘前进最快 3.5 m/s、横移 2.8 m/s、原地旋转最高 600°/s（官方规格值），麦克纳姆轮支持横移和斜走，先用竞速类玩法把方向感练出来。
- **练瞄准**：云台俯仰可控范围 -20° 到 +35°，配合图传画面练定点射击。
- **看数据**：App 里能查行驶里程、操控时长、编写程序行数、编程用时，以及大师之路的习得等级这类统计，练到哪一步有数可看。

满电连续驾驶官方标称约 35 分钟（按平整路面 2.0 m/s 匀速测得），练车前看一眼电量，别练到一半没电。

## 三、多人竞技：必须走路由器模式

多台机器人联网对战只有路由器模式支持，直连模式只能单机玩。所以想对战，先按 [连接机器人与激活步骤](连接机器人与激活步骤.md) 把所有机器人和手机都接到同一路由器下，路由器要满足那四个条件（WPA/WPA2-PSK 加密、设备数没满、允许设备间互访、无二次登录认证），少一条就组不起来。

对战中机器人靠装甲上的击打检测模块判「掉血」，也支持用掌声、手势这类互动方式触发动作（官方列的智能识别包括掌声识别、姿势识别、行人识别等，具体哪些玩法用到哪些识别，以 App 内玩法说明为准）。对战的具体规则由建房的人定，官方更新日志里加入过「占领基地」这类占点玩法：两队靠图像识别争夺基地，结束时占得多的一方获胜。

## 四、图传与延时的官方参考值

画质和延时会直接决定操控手感，官方在无干扰、无遮挡环境下测得的参考值如下，实际家里有墙、有别的 Wi-Fi 时会差一些：

| 指标 | 官方参考值 |
| --- | --- |
| 实时图传画质 | 720p @ 30fps |
| 图传最大码率 | 6 Mbps |
| 延时（直连模式） | 80-100 ms |
| 延时（路由器模式） | 100-120 ms |
| 工作频段 | 2.4 GHz / 5.1 GHz / 5.8 GHz |
| 最远传输距离 | 直连约 140 m（2.4 GHz，FCC）；路由器模式约 300 m（5.8 GHz，FCC） |

距离是 FCC 标准下的实验室值，国内 SRRC 等不同认证地区的数值不同，且实际距离受遮挡和干扰影响很大。画面卡、延时忽高忽低时，优先排查距离、遮挡和同频段干扰，排查思路见 [常见问题与故障排查](常见问题与故障排查.md)。

## 五、发射器与击打检测

发射器有两种「弹药」逻辑：红外光束（无实体弹丸，由机器人上的红外收发模块判定命中）和水晶弹（实体弹丸，装甲上的击打检测模块按物理命中判定）。用水晶弹时，官方对「算不算击中」给了一组硬性条件：

| 条件 | 官方要求 |
| --- | --- |
| 水晶弹直径 | 不小于 6 mm（官方配套弹为 5.9-6.8 mm） |
| 击中时弹速 | 不小于 20 m/s |
| 命中角度 | 弹道与检测模块平面夹角不小于 45° |
| 检测频率 | 最高 15 Hz |

打不中判定先核对这三条：弹的直径够不够、距离太远导致弹速掉下来、命中角度太偏。都满足还不判定，再查装甲模块本身。

安全上只说三条官方反复强调的：只在合适的场地玩、不对着人和动物发射、按官方指引佩戴护目镜。水晶弹是实体弹丸，别在室内对着易碎物练枪。
