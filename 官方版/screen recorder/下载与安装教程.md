## 二、安装步骤

1. 在网盘里把安装包下载到手机（或先下到电脑再传过去）。
2. 点开 APK 文件，系统会弹「禁止安装来自此来源的应用」——这是正常的拦截，因为这个应用不是从手机自带商店装的。
3. 按提示进入「允许来自此来源的应用」（不同品牌叫法不同：有的叫「安装未知应用」，有的叫「外部来源应用安装」）开关，打开后返回。
4. 回到安装界面点「安装」，等进度走完。
5. 装完先别急着点开，可以在 设置 → 应用 → 应用信息 里确认包名是 `com.kimcy929.screenrecorder`，避免装到同名的仿品上。

## 三、首次运行要授的权限

官方给的新手流程只有三步：点蓝色按钮 → 把弹出来的权限全部允许 → 再点一次蓝色按钮就开始用了。实际会遇到这几类授权：

1. **悬浮窗（显示在其他应用上层）**：录屏的控制按钮要浮在别的应用上面，不给这个权限就点不到开始/停止。系统一般会直接把你带到开关页，打开后返回即可。
2. **屏幕录制 / 截图权限**：安卓系统在开始录制时会弹一次确认框，点「立即开始」（有的系统叫「允许」）。
3. **存储 / 媒体权限**：用于把视频和截图写进相册或你指定的目录。
4. **通知权限**：用于在通知栏里显示录制状态与快捷控制，建议允许。

如果你的手机是安卓 6.0 这类老系统，官方特别提示要手动把悬浮窗权限打开，否则应用界面会停在第一步走不下去。装完授权后，就可以按 [录屏分辨率与帧率设置.md](录屏分辨率与帧率设置.md) 先调好参数再开录。
