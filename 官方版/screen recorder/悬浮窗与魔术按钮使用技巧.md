## 一、悬浮窗：录屏时真正好用的控制入口

给应用授予悬浮窗权限后（首次启动的引导里就会要），屏幕上会出现一个小的控制浮标。它的价值在于**不用切回录屏应用就能操作**：

- **开始 / 停止**：直接在当前画面结束录制，不会把「退出应用」的过程录进去。
- **暂停 / 继续**：中间要接电话、查资料时用，暂停段落不会出现在成品里。
- **显示录制时长**：录长内容（网课、演示）时随时瞄一眼录了多久。

官方把这个快捷控制叫 **Magic Button（魔术按钮）**，并在设置里提供了简化形态（Simple Magic button）：浮标只保留停止、暂停和时长显示，占用屏幕面积更小。游戏这类画面紧张的场景，建议切简化形态，避免浮标挡住操作区。

如果录制中悬浮窗整个消失了，通常是系统把悬浮窗权限回收了（省电策略会这么做），去 [录屏常见问题排查.md](录屏常见问题排查.md) 看权限那一节。

## 二、录制时在屏幕上写字画画

应用带**编辑叠加（Edit overlay）**功能：录制进行中可以直接在屏幕上画线、写字、圈重点，画的内容会一起进视频。做操作讲解时，这比后期加字幕省事——你指哪打哪，观众跟得上。

同理还有**水印（Logo text / Logo image）**：在设置里预置文字或图片，录制时自动打在画面上。想标个 ID 或标题，录之前设一次就行，不用每条都后期加。

## 三、前后摄像头同框（Facecam）

游戏解说、真人教学会用到摄像头叠加：

1. 录制前在设置里开启 facecam，可选前置或后置摄像头；
2. 录制中**双击摄像头预览画面**即可切换前后摄；
3. 拖动预览窗可以换个不挡 UI 的位置。

摄像头小窗录进视频后无法单独摘除，所以录之前先摆好位置、确认光线，比录完返工强。

## 四、通知栏快捷开关（安卓 7.0+）

安卓 7.0 及以上支持**快速磁贴（quick tiles）**：下拉通知栏，把录屏、截屏做成快捷开关，点一下直接开始录制，不必先打开应用。对「临时要抓一段」的场景，这是最短路径——先开应用再点录制，往往已经错过要录的画面了。

录制开始后，通知栏里常驻录制状态，暂停和停止也在那里，随手可点。

## 五、录完之后：剪辑与分享

结束录制后视频会自动存进相册或你设定的目录，在应用的视频列表里点右侧三点菜单，可以做这几件事：

- **修剪（Trim）**：掐头去尾，去掉开始时点错、结束时手忙脚乱的那几秒；
- **重命名**：多录几段之后按内容改名，回看时不用逐个播放辨认；
- **分享**：直接发出去。

应用本身只做修剪这类轻编辑，要合并多段、混音（比如内部声音 + 麦克风的双音轨）就得用正经剪辑软件，见 [怎么录制内部声音.md](怎么录制内部声音.md)。录完的画质是否符合预期，参数层面的复盘在 [录屏分辨率与帧率设置.md](录屏分辨率与帧率设置.md)。
