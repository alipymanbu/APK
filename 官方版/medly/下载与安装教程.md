## 一、动手前的三件事

1. **确认手机系统**：这款应用要求安卓 5.2 及以上，近几年的手机基本都满足；在「设置 → 关于手机」里能看到你的安卓版本。
2. **留出存储空间**：安装包本身 108.08M，加上安装后的数据与素材文件，建议预留 300M 以上。
3. **准备允许安装未知来源应用**：安装包不是从应用商店下的，首次安装时系统会提示授权。路径一般在「设置 → 安全 → 安装未知应用」，不同品牌叫法略有差别，把权限授给浏览器或文件管理器即可。

## 二、获取安装文件

medly 安装文件资源放在夸克网盘：[https://pan.quark.cn/s/c26bcf2663e8](https://pan.quark.cn/s/c26bcf2663e8)

1. 打开链接，选中安装包，先转存到自己的网盘，再下载到手机；
2. 也可以在电脑上下载后，用数据线把 APK 文件传进手机存储。

## 三、安装步骤

1. 在文件管理器里找到下载好的 APK 文件，点开；
2. 系统询问是否允许安装时，选「允许 / 仍要安装」；
3. 等进度走完，点「打开」或回桌面点图标。

第一次启动时应用一般会申请存储权限（读写本地音频要用到），建议允许，否则后面导入本地音乐会找不到文件。

## 四、核对安装包（可选）

想确认手里的包和资源页描述的是同一个文件，可以校验 MD5。电脑上（Windows）：

```bat
certutil -hashfile medly_v6.3.5.apk MD5
```

比对结果应为 `1558670FB92C648F85CDCA30944F51E5`（字母大小写不敏感）。对不上说明文件在传输中损坏或被替换过，重新下载一份再装。

## 五、装不上怎么办

| 现象 | 常见原因与处理 |
| --- | --- |
| 提示「解析包出现问题」 | 下载不完整或传输中断，重新下载一遍再看 |
| 提示「与已安装应用签名不一致 / 冲突」 | 手机里装过其他渠道的同包名版本，先卸载旧版再装 |
| 提示存储空间不足 | 清出足够空间后重试 |
| Play Protect 弹出拦截提示 | 自己判断来源后选「仍要安装」即可 |
| 安装卡在某个百分比 | 关掉省电模式与后台清理，让安装过程跑完 |
