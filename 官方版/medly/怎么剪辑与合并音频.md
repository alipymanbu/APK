# medly 怎么剪辑与合并音频

## 一、先把素材导进来

打开应用，在首页找「音频剪辑」入口，进去后从手机本地音乐库选要处理的音频；列表里没有的话，翻一下存放音频的文件夹。第三方教程描述的路径大致如此，不同版本的入口命名可能稍有出入，认准「剪辑 / 导入」这类字眼就行。

除了本地音频文件，还有两个素材来源：

- **从视频里抽音频**：用「视频提取音频 / 音频提取」入口，选一段视频，把里面的声音变成可编辑的音频；
- **直接录音**：用「录制音频」入口现场录一段，录完同样可以剪、可以降噪。第一次录音时系统会要麦克风权限，允许即可。

## 二、剪出你要的那一段

1. 选中导入的音频，进入剪辑界面；
2. 拖动起止点粗选区间；起点终点也可以手动输入精确时间点，适合掐准副歌或某句台词；
3. 试听确认后保存这一段。

顺手可用的辅助操作：删除选中区间、复制粘贴片段、在片段之间插入静音、给首尾加淡入淡出。

## 三、合并与混音是两回事

- **合并（拼接）**：把 A、B 两段音频首尾相接成一条，用「音频拼接 / 合并」入口，选多段、排顺序、导出。做串烧就是把几首歌按这个流程接起来。
- **混音**：两段音频同时叠着播放，用「混音」入口，分别调整各自的音量与起止位置。给一段念白垫背景音乐用的就是它。

两个入口名字接近、做的事完全不同：合并改变的是「顺序」，混音改变的是「叠加」。

## 四、调效果

各渠道介绍里提到过的可调项：变速、变调、淡入淡出、回声、变声、降噪（针对风声、电流声、摩擦声这类连续背景噪声）。降噪建议处理完先整段试听，人声听起来发闷就回退，从原始文件重来再调轻一点；反复压噪的素材宁可少调。

以第三方教程里对变速功能的描述为例，节奏大致是：选中音频 → 进「变速」功能 → 拖进度条调速度 → 点播放试听 → 确认后选导出格式、给文件重命名 → 右上角导出保存。变调、淡入淡出这类效果的入口也在同一片功能区，试听按钮就在旁边，调一步听一步。

## 五、导出成品

1. 在「音频拼接」等对应功能页里点「导出」；
2. 选格式：MP3 最通用，发微信、传电脑都不挑播放器；WAV、FLAC 这类格式体积大，留给还要二次处理的场景；M4A、AAC、CAF 也在支持列表里；
3. 导出完成后，用文件管理器按文件名搜一般能找到成品；不同版本的保存路径可能不同，应用内通常也会有提示。

碰到导出失败、找不到文件的情况，翻[常见问题与解决.md](常见问题与解决.md)；剪出来的片段要设成铃声的话，接着看[怎么制作手机铃声.md](怎么制作手机铃声.md)。
