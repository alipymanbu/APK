先挑一首你最熟的歌再开始调 —— 调音效是「听着改」的事，同一首歌来回对比，比任何参数说明都直观。本篇按「先用现成预设 → 手动动滑块 → 存成自己的方案」的顺序写。

## 一、从现成预设开始

应用内置 10 种按曲风划分的预设（官方商店页列出的清单）：

| 预设 | 适合的音乐 |
| --- | --- |
| Acoustic（原声） | 不插电、人声清唱 |
| Classical（古典） | 交响、器乐 |
| Dance（舞曲） | 电子舞曲、混音串烧 |
| Electro（电子） | 电音 |
| Flat（平直） | 不做渲染，原样输出 |
| Hip-Hop（嘻哈） | 说唱 |
| Jazz（爵士） | 爵士 |
| Pop（流行） | 主流流行歌 |
| R&B | 节奏布鲁斯 |
| Rock（摇滚） | 摇滚 |

预设列表就在均衡器页面上，点一下立即生效。边放歌边逐个切，一半的时间就能确定自己常用的那两三个。界面只有英语和法语，这几个预设名都是英文，其他高频界面对照表见[常见问题与解决方法.md](常见问题与解决方法.md)第五节。

## 二、手动调各频段

- 滑块从左到右对应低音到高音：最左管鼓点与低音，中间几段管人声，最右管镲片、齿音这类高频细节；
- 常见症状对应的调法：觉得「闷」拉高右侧，觉得「刺」压低右侧，觉得「人声远」抬中段，觉得「轰头」压最左段；
- 每次只动一段，动完听十几秒再决定留不留 —— 一次动三四段，基本听不出是哪一段起的作用；
- 官方商店页标称均衡器有 7 个频段，部分中文资料按 5 段介绍，两个口径都有来源，以你手里这个版本的实际界面为准。

## 三、低音增强（Bass Booster）

- 独立开关，打开后整体低音量感更足，与均衡器叠加生效；
- 力度调整的官方路径：Settings（设置）→ Bass Boost → 拖动滑条调强度；
- 从最小档往上试，大音量下低音容易失真，出现「破」声就往回退一档 —— 这是提示你到了这副耳机/音箱的极限，不是调得不对。

## 四、把调好的方案存成自定义预设

1. 手动调完后，按软盘形状的保存按钮（官方帮助页口径，界面以实际为准）；
2. 给方案起个能对上场景的名字，比如「入耳耳机」「通勤外放」；
3. 自定义预设排在预设列表的最末尾，与内置预设同栏切换，随时可以编辑或删除。

换耳机就换预设，比每次现场调快得多，这也是内置 10 种预设之外的实用空档。

## 五、DJ 模式（淡入淡出）

- 打开后两首歌的衔接处自动淡出接淡入，歌单连播不会再出现生硬的「啪」一下切歌；
- 官方帮助页描述的用法：在主屏勾选 ON，沿圆环滑动光标调过渡时长，滑动专辑封面也能切换 —— 界面以你手里版本为准；
- 派对连播、睡前循环这两个场景差异最明显，单曲听不太用得上。

## 六、调了没反应怎么办

先确认正在放歌的是本应用自己（它的音效作用在自己播的内容上，后台用别的播放器放歌时听不到变化），确认预设不是 Flat；仍无变化就去[常见问题与解决方法.md](常见问题与解决方法.md)第二节对照排查。想先拿到安装包，回[下载与安装教程.md](下载与安装教程.md)。
