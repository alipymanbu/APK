这里的歌全部来自手机存储，曲库的导入与整理都在应用内完成。本篇按「导入 → 整理 → 日常播放 → 附加功能」的顺序过一遍，每一节都是你在界面上能直接找到的入口。

## 一、把歌读进来

- 首次打开会自动扫描本地音频，按歌曲 / 艺术家 / 专辑 / 流派分类列出；
- 扫不出来先查权限：系统设置 → 应用 → 权限，把存储 / 音乐音频类权限全部允许（详见[常见问题与解决方法.md](常见问题与解决方法.md)第一节）；
- 支持指定本地文件夹，把分散在多个目录里的歌收进来；
- 封面自动匹配（cover arts）选项打开后，缺封面的歌会自动补图。

## 二、播放列表与队列

- 在应用内直接新建播放列表，把歌加进去，不用借助别的工具；
- 队列（queue）用来临时排要听的顺序，排完自动走下一首；
- 搜索结果按歌曲 / 艺术家 / 专辑 / 播放列表分别归类，库大了以后找歌快很多；
- 歌曲的元数据（标题、艺术家）可以在应用里直接改，改完分类跟着走，来源标错的歌不用连电脑。

## 三、日常播放的几个开关

| 功能 | 说明 |
| --- | --- |
| 随机播放（shuffle） | 打乱播放顺序 |
| 三态循环 | 单曲循环 / 整列表循环 / 不循环，按钮循环点击切换 |
| 后台播放 | 切到其他应用或锁屏后音乐继续 |
| 进度条 | 拖动定位，听长音频找段落用 |

## 四、睡眠定时器

睡前听歌用：设定一个倒计时，时间一到自动停止播放，不用起手关掉。时长按你平时的入睡速度定，先从短往长试，别一上来就定过夜。

## 五、桌面小部件

有 2 种小部件可加：一种直接切预设，一种放播放控制按钮。放到桌面后不用进应用就能换音效或暂停，通勤时单手操作够了。

## 六、可视化与投到电视

- 播放时有 5 种可视化效果（visualizer）随节拍变动，样式可以换着配心情；
- 双屏（Dual Screen）功能能把可视化效果投到电视等第二块屏幕上，放歌时电视上跳画面。

## 七、同一 WiFi 下共享音乐库

网络可见性（network visibility）选项打开后，同一 WiFi 下的其他 Equalizer+ 用户可以直接访问你的音乐库做本地串流，不走下载。这个功能只在互信的家庭网络里开，公共 WiFi 下建议保持关闭；用完随手关掉即可。

## 八、车机与手表

官方商店页标注兼容 Android TV、Android Wear 与 Android Auto。以你的设备实际支持为准：车机连上蓝牙后直接放歌单即可，手表端主要作用是控制播放。

## 九、先调音效还是先整歌单

顺序随意，但整完歌单再调音效，能拿整张歌单做对比对象，比单曲试更准。调节入口见[预设与音效调节指南.md](预设与音效调节指南.md)。
