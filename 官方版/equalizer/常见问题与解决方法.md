按现象对号入座。官方帮助页在 [equalizerpl.us/help](http://equalizerpl.us/help)（英文），本篇是中文环境下的常用排查路径，两者可以对照着用。

## 一、打开后曲库是空的

1. 查权限：系统设置 → 应用 → Equalizer+ → 权限，把存储 / 音乐和音频类权限全部允许 —— 这是最常见的原因；新版安卓把媒体权限拆成了「音乐和音频」「照片和视频」分开授权，确认「音乐和音频」这一项是允许；
2. 歌存在 SD 卡上的机型，确认 SD 卡已正常挂载；散落在系统曲库之外的歌要走文件夹入口，见[支持的音乐格式与导入方式.md](支持的音乐格式与导入方式.md)第三节；
3. 文件是不常见格式时可能扫不出来，先放一首 MP3 验证流程，格式支持清单见[支持的音乐格式与导入方式.md](支持的音乐格式与导入方式.md)第一节；
4. 歌在网盘或流媒体云端、没下载到本机的，它读不到 —— 先落成本地文件；
5. 权限补过还是空的：强制停止应用再打开，或清一次应用缓存（设置 → 应用 → 存储 → 清除缓存），再不行重启手机。

## 二、调节均衡器没有听感变化

- 确认正在用本应用自己播放：它的音效作用在自己播的内容上，切到后台用别的播放器放歌是听不到变化的；
- 关掉其他可能在后台占音频的应用再试 —— 官方帮助页专门提到后台应用会互相干扰；
- 换个有自带均衡器的播放器放过歌的话，把那个播放器的均衡器关掉，两套音效叠加会互相抵消；
- 戴耳机或接音箱对比 —— 官方也写明效果感知因设备而异，耳机和音箱会放大各频段的变化；
- 确认当前预设不是 Flat（平直），平直档等于不改声音；
- 检查音量本身：媒体音量太低时，各频段滑块的相对变化会被压缩。

## 三、能给 Spotify、YouTube 等其他应用调音效吗

不能。网上流传的中文介绍里有「兼容 Spotify、YouTube」的说法，但官方帮助页（[equalizerpl.us/help/android](http://equalizerpl.us/help/android)）写得很明确：它只处理你设备上自己的歌曲，不能搭配其他音乐播放器（Spotify、SoundCloud 等）、网络电台或 YouTube 使用。两边口径放在一起看，结论取官方：想给流媒体调音效，需要的是流媒体应用自带的均衡器或系统级音效工具，不是这一款。

## 四、广告与去广告

- 免费版带广告，官方的帮助页与商店页对「付费解锁什么」说法不一致：帮助页把淡入淡出、低音增强、可视化列为需解锁的附加效果，商店页则称全部功能免费、唯一内购是去广告 —— 两处官方口径并存，你手里这份 2.26.00 实际解锁了哪些，打开界面看一眼最准；
- 官方的去广告途径是应用内购买（no-ad 选项），官方介绍称每周有折扣，价格以应用内当时显示为准；
- 不购买也能正常使用，广告只是使用过程中的横幅或插页。

## 五、界面语言只有英语和法语

官方帮助页写明应用目前只提供法语和英语界面，没有中文。不认识英文的话，认这几个高频词就够日常操作：

| 界面词 | 意思 | 用途 |
| --- | --- | --- |
| Preset | 预设 | 切换音效方案 |
| Equalizer | 均衡器 | 手动调各频段 |
| Bass Boost | 低音增强 | 低音力度开关与等级 |
| Fade / DJ mode | 淡入淡出 | 歌曲间平滑过渡 |
| Settings | 设置 | 入口在菜单里 |
| Queue | 队列 | 当前要播的歌单 |
| Shuffle / Repeat | 随机 / 循环 | 播放模式 |

## 六、耳机与蓝牙音箱上的表现

- 有线耳机差异最明显，低音增强在入耳式上容易过头，从小档开始加；
- 蓝牙音箱 / 耳机按官方帮助页的做法：先在系统里把蓝牙设备连上，再打开应用，顺序反了有时不发声；
- 蓝牙耳机受编码压缩影响，可调空间比有线小；高增益下出现断连或杂音，先把均衡器增益拉回中间再试；
- 车载蓝牙连上后直接放歌单即可，预设切到 Dance 或 Rock 的差异在车里反而更明显。

## 七、耗电与后台被杀

- 挂后台连续播放属于正常耗电场景；如果音乐放着放着自己停了，多半是系统把应用杀了 —— 在系统设置的电池项里给它关掉电池优化（国产 ROM 常在「省电策略」里设为「无限制」）；
- 锁屏后控制条不见了，查通知权限是否被关；
- 上面两条都确认过仍然停，重启手机再放一次，排除系统临时故障。

## 八、版本与更新

- 网盘里这份是 2.26.00（2026-09 保存），官方商店版本在持续更新，两者界面可能略有差异；
- 想换商店新版直接从商店更新即可；卸载重装前，自定义预设建议截图留底，丢了得重调；
- 官方版本号、系统要求这类会随时间变化的信息，以[官方商店页面](https://play.google.com/store/apps/details?id=com.djit.equalizerplusforandroidfree)当时显示为准；
- 应用内解决不了的问题，可以写信给官方支持邮箱 support@equalizerpl.us（英文）。
