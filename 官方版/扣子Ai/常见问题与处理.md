## 一、换了设备，对话怎么没跟过来

网页端、桌面端、移动端登录**同一账号**后，项目、对话、文件和设置会自动同步。但**渠道之间不打通**：你在微信里跟它的对话，飞书里看不到那段记录——不过记忆是打通的，它记得你在微信交代过的事。想接着改文档、动本地文件，换到电脑上登录同一账号继续即可。

## 二、想删聊天记录，或者重置扣子

官方答复：出于隐私保护和数据安全，**暂不支持删除**你和扣子的聊天记录，也不支持重置或清空对话。两个替代办法：

1. 2.5 版本以前的独立对话收在「对话 > 已归档对话」里，旧记录去那里找；
2. 想换个风格重新开始，就新建一个扣子 Agent，给它全新的身份和记忆。

## 三、创建的 Agent 不用了，能删掉吗

目前**暂不支持删除**已创建的 Agent（扣子 Agent、云端 Agent、本地 Agent 都一样）。官方说明：不使用 Agent 时不会产生扣子任务费用——放着不调用不花钱，不用担心闲置扣费。

## 四、本地 Agent 掉线了怎么连回来

1. 点 Agent 的设置图标，单击**重新连接**；
2. 复制页面给出的连接地址；
3. 在本地终端执行连接命令；
4. 回到扣子页面单击**我已执行**，等系统完成重连。

断线多半是终端关了或网络切换，按这四步走就能接上，不用重建 Agent。

## 五、终端报 npm not found / npx not found

npm 和 npx 随 Node.js 一起安装，报这个错通常是没装 Node.js 或路径没生效。先验证：

```bash
node -v
npm -v
npx -v
```

三条都返回版本号 → 重启终端重试；提示找不到命令 → 用 nvm 安装并启用 Node.js：

```bash
nvm install --lts
nvm use --lts
```

装完重新跑一遍版本检查，三条都能出版本号即可。

## 六、云端 Claude Code 要不要自己的账号

不需要，也**不能登录你自己的 Claude 账号**：扣子的云端 Agent 是基于 Claude Code 开源框架搭建的，模型由扣子统一提供，不动你的 Claude 订阅配额。云端 Codex CLI 同理，不需要 OpenAI 账号或 API Key。想用自己的账号，走「本地 Agent」——把你电脑上已经运行的 Claude Code 接入扣子。

## 七、积分用完了，任务中途停了

个人版积分为 0 时服务直接停止（不扣现金）。当天登录可领 1500 积分应急；经常跑重任务就升档或增购，算法见 [收费标准与积分规则.md](收费标准与积分规则.md)。

## 八、安装包装不上、校验不过

先别急着重装：按 [下载与安装教程.md](下载与安装教程.md) 里的 MD5 校验方法核对文件是否完整，不一致就重新下载；一致仍装不上，再换官方商店渠道获取安装包。

## 九、上面都没答上来的，去哪问

按官方「获取帮助」文档，求助入口分三档：

- **扣子助手（所有人，优先用这个）**：App 内左上角**头像 > 帮助中心 > 意见反馈**即可唤起——它是官方的产品知识问答 Agent，能答使用问题、分析报错信息；网页端与桌面端是左下角**头像 > 帮助与反馈 > 帮助中心**；
- **扣子工单（个人付费版、团队版）**：同在帮助中心底部的**意见反馈**提交，适合疑似产品故障、功能建议这类要留记录的问题；
- **在线客服（个人尊享版）**：帮助中心底部**在线客服**，人工实时支持，工作日 10:00-12:00、13:00-19:00；移动端暂未上线。

提工单前把报错原文、操作路径、截图备齐，定位会快很多。
