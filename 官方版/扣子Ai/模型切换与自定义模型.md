## 一、先搞清楚：换模型影响什么

模型决定回答质量、响应速度和复杂任务的处理能力，也**直接决定积分花得快慢**——各模型 Token 单价不同，单价高的模型每次对话扣的积分更多。同一个任务换两个模型对比效果和花费，是常规操作。

## 二、默认是「自动」，想指定就手动切

扣子提供两种模式：

- **自动（默认）**：后台按任务复杂程度和各模型负载灵活调度，不想研究模型就用它；
- **指定模型**：自己挑，每个 Agent 可指定**一个大语言模型 + 一个多模态模型**。

切换入口（App 与电脑端一致）：点目标 Agent → 对话输入框的**模型**下拉列表 → 选其他模型。截至 2026 年 9 月官方文档所列的可选模型包括大语言模型 Deepseek-V4-Pro、GLM-5.3、Doubao-Seed-2.1-pro、Kimi K3 等，多模态模型 Seedream 5.0 Pro、Seedream 5.0 Lite、Seedream 4.5、Seedance 2.5 等——列表随版本增减，以你界面上实际出现的为准。

部分模型会有限时折扣活动，活动期用折扣模型能省积分。

## 三、想省积分就接自己的模型

除了官方模型，你还能添加自定义模型、接自己的模型 API（自部署或第三方在线模型）。限制与好处都很明确：

| 项 | 规则 |
|---|---|
| 套餐门槛 | 个人**进阶版及以上**才支持添加 |
| 哪些 Agent 能用 | Coze Agent、云端 Agent、编程项目；其他类型不支持 |
| 在哪操作 | **仅网页端和桌面端**可添加和管理，手机 App 暂不支持 |
| 计费变化 | 用自定义模型的 Agent **不再收扣子对话费用**，改耗你自己的 Token |

接入方式两种：

1. **服务商接入**：填服务商、API Key、选模型即可，当前支持火山引擎方舟、Kimi、DeepSeek、智谱 GLM、MiniMax、智谱 GLM（Coding Plan）；
2. **自定义接入**：填模型展示名称、模型 ID、协议（支持 Chat API、Responses API、Anthropic Messages）与 API URL，适合自有模型服务或兼容 OpenAI 协议的第三方服务。

已经有在用的模型 API、且对话量大，走自定义接入通常比按对话扣积分划算；只是日常轻度用，官方模型的自动模式就够。积分侧的规则见 [收费标准与积分规则.md](收费标准与积分规则.md)，做 PPT、视频时指定哪个模型合适，见 [PPT与视频制作教程.md](PPT与视频制作教程.md)。
