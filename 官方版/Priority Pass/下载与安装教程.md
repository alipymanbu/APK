网盘里这份是安卓手机版。它本身不卖会籍，装好打开后第一件事是让你登录或激活会籍 —— 没有会籍也能浏览贵宾室列表，但进不了门。本篇按「先弄清它是什么 → 核对安装包 → 安装 → 首次打开验证 → 用之前要留意什么」走一遍。

## 一、先弄清这个 APP 是干什么的

Priority Pass 是机场贵宾室使用计划的官方手机应用。它管的是三件事：

| 你打开 APP 想做的事 | 对应功能 |
| --- | --- |
| 查某个机场有没有能用的贵宾室、在哪个航站楼 | 贵宾室检索（Lounge Finder）与室内机场地图 |
| 到门口怎么证明自己有权益 | 电子会员卡（出示二维码/条码给前台扫描） |
| 我这个月还能进几次、上次去了哪 | 会籍与到访记录 |

**它不是买会籍的地方。** 会籍要么来自你手里某张银行卡的权益，要么在官方站点上自己购买，APP 只负责使用与管理。所以装完先别急着找「注册新会员」，第 0 步是确认你会籍的来路，见 [会籍怎么获得与账户激活.md](会籍怎么获得与账户激活.md)。

## 三、装到安卓手机上

1. 在手机上打开网盘分享链接，把安装包**先转存**到自己的网盘，再下载到手机本地（夸克分享页常要求先转存，直接点下载有时会失败）。
2. 打开手机的「文件管理」，找到刚下好的 `.apk` 文件，点击安装。
3. 系统弹出「是否允许安装未知来源的应用」时，允许当前这个文件管理器或浏览器安装即可。Android 8 及以上是逐应用授权的，装完可以关回去。
4. 如果手机装了安全类软件，可能提示「该应用未经验证」，选择继续安装。
5. 若提示与已装应用冲突，说明手机里已有 **同包名**（`com.prioritypass3`）的版本，先卸载旧的再装，或者继续用旧的那份。

安装过程不需要付费，也不强制当场注册 —— 但要真正用起来，登录这一步绕不过去。

## 四、系统与设备要求

这一版附带的系统要求写的是「需要支持安卓系统 5.2 以上」。这句话按字面理解是 Android 5.2，而安卓官方并没有 5.2 这个版本号，所以把它当作「安卓 5.x 这一代及以上」的参考即可；准确门槛以官方应用商店页面当时显示为准，你手机实际能不能装，以安装时的系统提示为准。

另外两处和「能不能用」有关，但和系统版本无关：

- **必须能联网**。查贵宾室、加载电子会员卡都要走网络，出发前在机场 Wi-Fi 或漫游网络下先打开一次，确认卡能正常显示。
- **室内机场地图只在部分机场提供**，官方页面写的是目前 10 座主要机场。地图里没有你要去的机场，说明该机场还没上线这个功能，不影响进贵宾室。

## 五、第一次打开会遇到什么

首次启动的流程取决于你会籍的来路：

| 你的情况 | APP 会怎么要求 | 你要做什么 |
| --- | --- | --- |
| 会籍是通过银行卡/信用卡权益拿到的 | 要求激活或登录网上账户 | 见 [会籍怎么获得与账户激活.md](会籍怎么获得与账户激活.md) 第三节 |
| 已经在官方站点买过会籍并有网上账户 | 直接登录 | 用注册时的用户名和密码；若已启用，可用指纹或 Face ID |
| 完全没有会籍 | 可以浏览贵宾室列表 | 只能看，进不了贵宾室 |

登进去之后建议先做三个验证动作，别等到站在贵宾室门口才发现问题：

1. 打开「卡」选项卡，确认电子会员卡已经出来（不出来不是网络问题，多是会籍类型或激活状态问题，见 [电子会员卡怎么激活与出示.md](电子会员卡怎么激活与出示.md)）；
2. 搜一个你常去的机场，确认能搜到贵宾室条目、能看到航站楼与位置说明；
3. 手机锁屏再解锁，确认指纹或 Face ID 登录能用。

## 六、装完之后的几个注意点

- **别急着换商店里的最新版**。网盘里这份 6.71.0 和你搜到的版本可能相差若干版，界面与入口都会变；要升级就自己决定，升之前先确认新版本没有把你常用的入口挪走。
- **手机没电时电子会员卡打不开**。官方明确说过这种情况需要用实体卡进场，所以长途出行建议把实体卡带着，见 [电子会员卡怎么激活与出示.md](电子会员卡怎么激活与出示.md) 第六节。
- **卸载 APP 不会注销会籍**，但电子会员卡与到访记录在 APP 外就看不到，门口只能靠实体卡。
- 装不上、登录不上、卡不显示，按 [常见问题与排查.md](常见问题与排查.md) 里对应的现象顺序排查。
