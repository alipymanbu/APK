# Priority Pass 会籍怎么获得与账户激活

很多人卡在这一步：APP 装好了，打开却只看到登录框，翻遍界面也找不到「注册会员」。原因是会籍不在 APP 里买，你手里得先有一份会籍 —— 它通常来自你的银行卡。本篇把「会籍从哪来」和「拿到会籍之后怎么把账户激活」两件事分开讲。

## 一、先分清会籍和账户

这两个概念是分开的，混在一起就会出现「我明明有卡，为什么 APP 说没有」：

- **会籍（membership）**：你在 Priority Pass 计划里的身份，由一串会员编号标识，决定你能进哪些贵宾室、一年能进几次、带人要付多少钱。
- **网上账户（online account）**：你在官方站点的登录凭据，用来登录 APP 和网站。同一个会籍只能绑一个网上账户。

会籍发给你的时候并不自动附带网上账户，所以第一步永远是「激活账户」。

## 二、会籍从哪来

常见三条来路，激活方式不一样：

| 来路 | 说明 | 你需要注意 |
| --- | --- | --- |
| 银行卡 / 信用卡权益 | 最常见的一种。你的发卡行把 Priority Pass 会籍作为卡的权益赠送，实体卡通常由发卡行寄出 | 到访与携伴费用往往**直接记在你的付款卡**上；权益细则、能否带人、一年几次，以发卡行的权益说明为准 |
| 在官方站点自行购买 | 官方提供三档会籍：Standard（按次付费）、Standard Plus（含一定次数免费，超出后按次）、Prestige（会员本人到访不限次） | 年费与每次到访费用随地区和币种不同、也会调整，**以官方页面当时显示为准** |
| 酒店 / 航空等合作方活动 | 合作方常有限时折扣或赠会籍活动 | 活动有期限与条款，是否仍有名额以官方活动页为准 |

先确认自己是哪一条来路，再去激活 —— 因为后面「激活时输什么」「费用记在哪张卡上」都由它决定。不确定的话，直接问发卡行或对应合作方的客服，比在 APP 里试快。

还有一点容易误会：Priority Pass 只是机场贵宾室渠道中的一种。机场里还有机场自营、航司自营以及其它贵宾室计划运营的贵宾室，**它们和你手里的 Priority Pass 会籍不是一回事** —— 能进哪一家取决于那家贵宾室接不接受你手里的这份权益，而不是看你有没有实体卡。所以到了机场别把「Priority Pass 会员」当成通用通行证，先在 APP 里确认那家贵宾室在 Priority Pass 网络内。

如果你选的是**在官方站点自行购买**，官方使用条款里还列着几项和你钱包直接相关的内容，值得在付款前读一遍：首次加入的冷静期、计划续期、自动续会与非自动续会、费用、取消以及未付费用。具体天数、退订条件与当期价格以官方条款页当时显示为准，这里不写死。另外提醒一句：**未结清的费用会影响你在贵宾室门口能否进场**，这条的排查见 [被拒绝入场是怎么回事.md](被拒绝入场是怎么回事.md)。

## 三、激活网上账户

官方站点上有一个「激活您的账户」入口，从这里开始：

1. **输入身份**。两种任选其一：你的**会员编号**（注意是会员编号，不是银行卡号），或者与 Priority Pass 权益关联的那张**付款卡卡号**。
2. **输入 4 位验证码**。如果你还没注册过网上账户，系统会要一个 4 位验证码。可用的来源有两个：付款卡卡号的**后 4 位**，或者欢迎包 / 续期包上印的 4 位验证码。
3. **设置登录方式并验证邮箱或手机**。注册时填的邮箱或手机号就是你的主登录方式，之后要收一次性验证码（OTP）也是发到这里。
4. 注册完成后，APP 和网站都能用**用户名 + 密码**登录；网站上还可以用**会员编号 + 密码**登录。

有三个坑提前说：

- **主登录方式创建后不能改**。官方帮助里写明，账户建好后主登录方式就固定了。所以别用一个随手编的邮箱注册，后面想换成常用邮箱是不行的。
- **注册时用的邮箱/手机号要一直用下去**。换号之后仍要用原来那个登录，否则原有的会籍信息会找不回来。
- **OTP 收不到**时，先确认邮箱或手机号拼写、格式都对，再去垃圾邮件文件夹翻一遍。

## 四、为什么会籍要对应多个账户

这一点在同时持有两张带权益的卡时最容易踩：

- 一个会籍对应一个网上账户；
- 如果你有**两个不同的会籍**（比如两张卡各送一份），就得**分别创建两个网上账户**，不能合并到同一个账户里；
- 每张电子会员卡都绑定到具体那张实体卡上，所以换会籍就得换账户，见 [电子会员卡怎么激活与出示.md](电子会员卡怎么激活与出示.md)。

另外，官方 FAQ 里也提醒了：**并非所有会籍都支持电子会员卡**。发卡行在发放实体卡时通常会说明，你可以在激活流程里看到具体步骤；如果激活时提示该选项不可用，就是这份会籍不支持。

## 五、激活之后你能拿到什么

激活网上账户是使用数字功能的前提，做完之后这些才可用：

- APP 里的**电子会员卡**（不用带实体卡也能进贵宾室）；
- **到访记录**与会员专享礼遇；
- 收藏贵宾室与体验、跟踪剩余次数；
- 提前预约贵宾室、预订机场快速通道等服务。

不用网上账户也能进场 —— 拿实体卡就行。但少了这些，等于把「还剩几次」「上次什么时候来的」这类信息全押在记忆上。

## 六、注销账户之前要清楚代价

删除网上账户不是「解绑 APP」这么轻：官方帮助里写明，删除网上账户会让你**不再能使用贵宾室以及会籍附带的其他权益**。如果你只是想清掉手机上的登录记录，卸载 APP 或退出登录就够了，不要走注销账户这一条。

会籍本身的有效期由发卡行或你购买时的条款决定；账户激活和会籍有效期是两件事，账户注销了，会籍能不能恢复要问对应的会籍提供方。
