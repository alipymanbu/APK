# Priority Pass 电子会员卡怎么激活与出示

> 本篇讲电子会员卡与实体卡的区别、卡不显示时怎么激活、到门口怎么出示，以及换卡后为什么必须重新激活。

电子会员卡（官方叫 Digital Membership Card）就是实体卡在 APP 里的那一份，两者权益完全一样。它的好处是不用等邮寄、不会忘带；代价是手机得开机、有电、屏幕够亮。本篇把激活流程和门口出示这两件事讲清楚。

## 一、电子卡和实体卡的区别

| 对比项 | 电子会员卡 | 实体会员卡 |
| --- | --- | --- |
| 在哪 | APP 的「卡」选项卡里 | 发卡行或官方邮寄的塑料卡 |
| 权益 | 无差别，可用于计划内全部贵宾室与体验 | 同左 |
| 有效期 | 与实体卡**完全相同** | 由发卡行或官方决定 |
| 怎么进场 | 前台扫手机屏幕 | 前台刷卡 |
| 失效场景 | 手机没电、屏幕太暗扫不出、未联网 | 忘带、丢失、被盗 |
| 可用范围 | 绝大多数贵宾室接受，以贵宾室条目「设施」里是否标注接受电子会员卡为准 | 全部 |

## 二、把电子卡弄出来

按这个顺序做，多数人在第二步就结束了：

1. **先激活网上账户并登录 APP**。没登录不会有卡，这一步的前置在 [会籍怎么获得与账户激活.md](会籍怎么获得与账户激活.md) 第三节。
2. **登录后先看有没有自动出现**。官方说明：部分会籍登录后会自动获得电子会员卡。
3. **没自动出现就手动激活**。进入「卡」选项卡，按页面上的说明操作，流程中会要求你**手上有一张现有的实体会员卡**：
   - 用手机摄像头**扫描实体卡**，或
   - 按提示**手动输入实体卡上的部分信息**。
4. 完成后电子卡立即可用。

两件需要注意的事：

- **并非所有会籍都支持电子会员卡。** 官方 FAQ 里明确写了这一点。如果你在第 3 步发现「手动输入」这个选项也没有，且发卡行那边也确认不支持，那就是这份会籍只能用实体卡，不是操作错了。
- **激活网上账户 ≠ 电子卡自动生成。** 有些人以为账户激活完就万事大吉，其实还要在「卡」选项卡里把卡做出来。

## 三、哪些贵宾室接受电子卡

官方的口径是「几乎所有 Priority Pass 贵宾室都接受电子会员卡」，但没有说全部。判断方法很直接：

- 在 APP 里搜到你要去的贵宾室，打开它的详情，看**「设施」一栏里有没有标注「接受电子会员卡」**；
- 没有这个标注，就带上实体卡，或者先看该贵宾室的入场方式说明。

## 四、在门口出示电子卡

进场时顺序大致是这样：

1. 在前台说明你是 Priority Pass 会员，打开 APP 的「卡」选项卡，把屏幕递给工作人员扫码；
2. 同时出示**当日有效的登机牌** —— 持卡人和同行的宾客都要出示，且**姓名要与登机牌一致**；
3. 如果带了人，工作人员会当场确认人数并登记；
4. 工作人员操作完成后即可入场。

如果前台说扫不出来，**先把手机屏幕亮度调到最高再试一次** —— 这是官方 FAQ 里给出的第一条建议，读卡器对暗屏识别率确实低。亮度拉满还是不行，就改用实体卡进场。

## 五、有效期与换卡

- **电子卡和实体卡同有效期**：实体卡到期，电子卡也一起到期，不是各算各的。
- **收到新实体卡后必须重新激活电子卡**。每张电子会员卡都绑定在具体那一张实体卡上，换卡后旧的那份失效，要在 APP 里重做一遍第二节的步骤。
- **实体卡丢失或被盗**：按官方说明要报告给发卡行（会籍是通过官方直接购买的就联系官方会员服务团队）。补发期间，只要会籍还在有效期内，你仍可用 APP 里的电子会员卡进场。
- **实体卡过期、新卡又没寄到**：实体卡由发卡行发放，催卡和补发都要找发卡行；官方不直接管通过发卡行获得的实体卡。

## 六、手机没电或没带手机

只能靠实体卡。官方 FAQ 里对这个场景的说法很直接：移动设备没电时，**需要用实体卡进场**。

另外有一个容易被忽略的限制：**不能拿别人手机里的会员卡照片、或者手抄的卡号代替**。官方使用条款写明了，会员卡或电子会员卡的**照片与卡号都不能替代有效的进入凭证**。所以别指望靠截图兜底，长途出行老老实实把实体卡放进钱包。

出场前还想确认「这次出来还剩几次、上次去哪家」的，见 [携带宾客与到访次数怎么算.md](携带宾客与到访次数怎么算.md)。
