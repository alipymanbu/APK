# Priority Pass 被拒绝入场是怎么回事

> 本篇讲门口被拒的几类真实原因、哪些是自己出发前就能排除的、高峰期怎么选时间，以及被拒之后该找谁。

拿着有效会籍还是被拦下来，通常落在四类原因里：贵宾室满了、你的会籍或付款卡状态有问题、你和这家贵宾室的旅客类型对不上、或者这家贵宾室有额外的收费与航司限制。前三类能提前排除，最后一类要先读条目。

## 一、贵宾室满员

这是最常见也最没办法的一类。官方使用条款里写明，入场可以**按容量情况被拒绝或延后**；具体贵宾室条目里也常写着「贵宾室可能因座位有限而限制进入」「贵宾室保留因容量约束限制入场或预留座位的权利」。

需要知道两点：

- **这不是针对你**。容量条款是贵宾室的权利，前台按的是当场的上座情况，不看你是什么会籍；
- **可以等，也可以换**。中转类枢纽的客流是波峰式来的，同一家贵宾室在高峰过后往往明显松动；更稳的做法是提前记下同航站楼的第二家备选。

## 二、会籍或付款卡状态有问题

这一类有第三方分析指出，官方帮助中心提到过两种具体情形：**与账户关联的付款卡存在付款问题**，以及**存在未结清的会员费用**。也就是说，账单层面的问题会直接影响你进门。

自检顺序：

1. 确认会籍**还在有效期内**（电子会员卡过期就是会籍层面的问题，见 [电子会员卡怎么激活与出示.md](电子会员卡怎么激活与出示.md)）；
2. 如果你是**换过付款卡**的，回想一下有没有在官方站点「我的资料」里更新账单资料并重新验证 —— 新卡没验证，贵宾室设备可能识别不了；
3. 会籍来自银行卡的，账单与费用问题**直接问发卡行**，官方那边也看不到你发卡行的账单状态。

## 三、你和这家贵宾室的旅客类型对不上

这一类完全是出发前能排除的，但现场最容易变成争执。典型情形：你拿着国内航段登机牌，走到的是国际出发侧的贵宾室；或者航站楼在安检后不互通，你根本到不了那家。判定方法与自查清单见 [国内机场有哪些贵宾室能用.md](国内机场有哪些贵宾室能用.md)。

还有两个常被忽略的细节：**持卡人姓名必须与登机牌一致**，**登机牌必须是当天出行**。拿家人的卡、或者用后一天的登机牌，都会被拒。

## 四、这家贵宾室有自己的额外规则

网络里的贵宾室由不同运营方经营，规则并不统一。入场前值得在条目里确认这几项：

| 可能出现的额外规则 | 在哪看 |
| --- | --- |
| 对 Priority Pass 会员额外收取一笔入场费 | 条目顶部「重要信息」或位置说明 |
| 限定必须乘坐某家航司或伙伴航司的航班 | 条目的相关规定 |
| 最长逗留时间短于 3 小时（常见还有 2 小时） | 条目的相关规定 |
| 同行宾客人数上限（有的写明不限制，多数限 1 位） | 条目的相关规定 |
| 部分饮品或服务需另外付费 | 「重要信息」栏 |

这些规则会随时调整，**以条目当时显示为准**，不要按记忆里的旧规定去。

## 五、高峰期怎么选时间

贵宾室的拥挤程度大致跟着出发航班的波峰走 —— 这是第三方分析与旅客反馈中反复出现的规律，官方并不发布这类提示，所以当作参考而不是规律：

- **以本地出发为主的机场**：早班和傍晚两段最挤；
- **中转枢纽**：一天里有多轮波峰，波峰过后通常较快松动；
- **国际长航线集中的机场**：傍晚到晚上那一波最挤。

由此可以做的几件事：

1. **出发前一晚在 APP 里确认营业时间与宾客政策**，别到现场才研究；
2. **提前记下同航站楼的第二家**，第一家满员直接换，不必原地等；
3. **能预约就预约** —— 部分贵宾室支持提前预约以保证入场，是否可预约写在条目里；
4. **把「一定进得去」当作前提**。座位是受容量约束的，行程紧的时候不要把休息、洗澡、吃饭都押在贵宾室里。

## 六、被拒之后按这个顺序处理

1. **先自查三件事**：卡是否过期、姓名是否与登机牌一致、旅客类型与航站楼是否对得上；
2. **换同航站楼的第二家**，这是最快能解决问题的做法；
3. **当场问清拒入的理由**，是满员还是规则问题，两者的后续动作完全不同；
4. 如果理由涉及**付款卡、费用、会籍状态**，找发卡行；会籍是通过官方直接购买的，找官方会员服务团队；
5. 保留好当次的登机牌与相关信息，便于后续核对。

涉及扫码失败、卡不显示、登录异常这几类，不属于本篇范围，按 [常见问题与排查.md](常见问题与排查.md) 对号处理。
