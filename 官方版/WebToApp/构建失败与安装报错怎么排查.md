打包出问题，先别急着改配置，先定位问题落在哪一段。这四段的成因几乎不重叠，混在一起调只会越调越乱。下面每一节都从「你屏幕上看到什么」出发。

## 一、先分清卡在哪一步

| 你看到的现象 | 卡在哪 | 看哪节 |
| --- | --- | --- |
| 点构建后立刻弹出一串错误，没开始跑 | 构建前预检 | 第二节 |
| 构建进度跑到一半停住或报错 | 构建过程 | 第三节 |
| APK 出来了，装的时候报错 | 安装环节 | 第四节 |
| 装上了，打开是空白、闪退或功能缺失 | 运行环节 | 第五节 |

## 二、构建前预检不过

构建对话框点下去之后，会先跑一次**预检**，把阻塞性问题直接列出来。这一段的错误基本都是配置本身的问题，按提示逐条改就行，常见来源：

- **必填项没填**：目标 URL 为空、应用名为空；
- **运行时类型的环境没准备好**：选的是 PHP / Node / Python / Go / WordPress 这类，但设备端工具链还没装，需要先进「Linux 环境」把对应环境装好再回来；
- **选了 GeckoView 但内核没下载**：这个内核不是随应用一起来的，首次使用要先在浏览器内核下载处取一次；
- **图标或素材路径失效**：之前选过的图片被删了或移动了，重新选一次即可。

预检不过不要反复硬点构建，它拦的正是会让你跑到一半才失败的那类问题。

## 三、构建过程中断

**进度长时间不动**
构建要在设备本地生成并签名安装包，比在电脑上慢是正常的。判断是不是真卡住，看两点：进度百分比是否还在变、手机上是否还在持续写入（文件管理里产物目录的大小是否增长）。长时间完全没动静时，再考虑清后台重来。

**中途报错退出**
先打开**构建日志**看最后一段（入口在第七节），日志末尾的报错通常直接说明缺什么。若是选了加密或隔离这类会强制全量重建的选项，失败后重试一次；仍然失败就先关掉这些选项构建一版，确认基础流程通了再逐项加回来。

**构建成功但产物找不着**
产物统一落在「⋮ → 文件管理」里，按 APK 构建分类查看；如果这一栏是空的，说明构建其实没有走到落盘那一步，回到日志确认。

## 四、产物装不上

安装会调起系统安装器，失败时系统会给出报错。按报错原文对照：

**「已阻止安装 / 未经过安全检测」**
安装来源权限没给到位。到「设置 → 应用 → 特殊应用权限 → 安装未知应用」，给正在打开这个 APK 的应用打开开关。部分国产系统另有「纯净模式」或安装监控，一并放行。

**「应用未安装」**
三种常见成因，按顺序排：

1. 手机里已有**同包名但签名不同**的应用 —— 先卸载旧版；
2. 装的是**比已装版本更低**的包，安卓不允许降级覆盖 —— 提高版本号重构建，或先卸载；
3. 安装被安全软件拦下 —— 暂时关闭拦截后重试。侧载的安装包被安全软件标记为可疑是常见现象（有用户反馈过被报毒），从自己构建或可信来源拿到的包，确认来源无误后放行即可。

**「解析包时出现问题 / 应用包似乎已损坏」**
产物没写完就中断了，或者传输过程中受损。重新构建一次；通过微信、QQ 之类工具转发 APK 时的改后缀行为也会导致解析失败，改用文件管理器直接拷贝。

**「与你的设备不兼容」**
目标系统版本低于产物要求。检查手机上安卓版本，以及打包时设定的最低支持版本是否过高。

**「存储空间不足」**
安装需要「安装包 + 解压后占用」两份空间，留出明显余量再装。

## 五、装上了但打开不对

这类不是安装问题，是**产物内容与预期不符**：

- **打开是空白页 / 一直转圈**：先在手机上用浏览器打开同一个网址确认网络，再回来看是不是网页本身的问题；
- **点开就闪退**：多为目标系统版本或设备架构不匹配，也可能是网页里用到了当前 WebView 不支持的能力；
- **功能比预览时少了**：配置没有完整带到导出产物，逐项核对见 [预览正常但导出后失效怎么办.md](预览正常但导出后失效怎么办.md)；
- **定位、摄像头、上传按钮用不了**：权限没有开给导出应用，或目标站点不是 HTTPS；
- **配好的广告拦截、注入脚本、扩展一个都没生效**：构建时选了 GeckoView 内核，这些能力在该内核下不提供，见 [浏览器内核选WebView还是GeckoView.md](浏览器内核选WebView还是GeckoView.md)。

## 六、服务端运行时类型的额外故障

如果你打包的是 PHP、WordPress、Node.js、Python、Go 这五类，故障点会比网页类多一层：**设备端运行环境本身**。有用户反馈过环境安装失败、运行时下载失败、依赖版本过旧这几类问题。按下面的顺序排：

1. **确认环境装成了**：这五类需要先在「Linux 环境」里把对应工具链装好，装完再回来创建或构建应用。环境没装成时，构建阶段的预检会直接拦住；
2. **环境下载失败就重试**：下载中断是网络原因，换个网络或稍后重试，不要反复点构建；
3. **核对依赖版本**：项目里声明的运行时版本如果高于设备端装的那一版，会出现「装上了但起不来」，把项目依赖降到设备端支持的版本，或先升级设备端环境；
4. **注意设备架构**：运行环境要跟手机 CPU 架构匹配，架构不符时表现为环境装不上或启动即退出；
5. **先跑内置示例**：内置的示例项目是已验证可用的配置，先用示例跑通，再换成自己的项目，能快速分清是环境问题还是项目问题。

这类应用的排查成本明显高于网页类，只为验证效果时建议先用「网页」类型跑通链路，见 [十二种应用类型怎么选.md](十二种应用类型怎么选.md)。

## 七、构建日志在哪看

「我的应用」右上角 **⋮ → 文件管理** 里带一个**只读的构建日志查看器**，按构建记录查看。日志很长时会被截断显示，所以要看**最后一段**而不是开头。出问题时把最后几行记录下来，比截图整个进度界面有用得多。文件管理里同时也能查看、打开、复制、分享、删除产物，并支持多选批量清理。

## 八、求助前先备好这些信息

要把问题说清楚，至少记下四项：手机型号与安卓版本、应用类型与版本号（本文档对应构建器 2.5.5）、报错原文（抄一行或截图，别转述）、以及当时用的构建选项（是否开了加密、隔离、后台运行）。同一句「应用未安装」，成因可能完全不同，报错原文和选项清单直接决定处理路径。

如果怀疑是构建器本身的问题，可以从 [WebToApp 安装文件资源（夸克网盘）](https://pan.quark.cn/s/98da99a44c60) 重新取一份安装包覆盖安装 —— 覆盖前确认包名与签名未被改动过。安装步骤见 [下载与安装教程.md](下载与安装教程.md)。
