# WebToApp 浏览器内核选 WebView 还是 GeckoView

> 打包对话框里的「浏览器引擎」不是换个外观那么简单：选了 GeckoView，广告拦截、用户脚本、脚本注入、资源加密会一起失效。本篇给出对照表与选型判断。

构建 APK 时要你在系统 WebView 与 GeckoView（Firefox 内核）之间二选一。选错最典型的后果，是配好的广告拦截和注入脚本装上后全都不生效 —— 这两者是相互独立的完整引擎，一部分依赖系统 WebView 机制的能力在 GeckoView 下没有对应实现。

## 一、先看结论

| 你的需求 | 选哪个 |
| --- | --- |
| 要广告拦截、用户脚本、Chrome 扩展 | 系统 WebView |
| 要自定义脚本注入、设备伪装、页面翻译、长按菜单 | 系统 WebView |
| 打包的是 HTML / 前端离线包，且开了资源加密 | 系统 WebView（必须） |
| 只做最基础的网页封装，不加任何扩展能力 | 两者都可以 |
| 需要站点看到真实的 Firefox 指纹 | GeckoView |

**一句话判据**：只要你的配置里出现了拦截、注入、脚本、扩展、加密这几类字眼，就用系统 WebView。

## 二、GeckoView 下不可用的功能

以下能力在 GeckoView 内核下**不生效**，不是设置遗漏，是引擎本身不提供：

- **广告拦截** —— 网络规则过滤与元素隐藏都不起作用；
- **用户脚本（`GM_*` API）与 Chrome MV3 扩展** —— 含规则型接口；
- **扩展 JS API** —— 只有部分请求相关接口可用，剪贴板、通知、震动、分享、屏幕常亮、屏幕方向等不可用；
- **全部 JS 注入类功能** —— 浏览器指纹伪装、设备伪装、内核伪装、页面翻译、自定义注入脚本、弹窗拦截、滚动位置记忆、图片修复、隐藏链接预览等；
- **资源加密加载、静态资产包、PWA 离线（Service Worker 注入）** —— 所以**开着资源加密的 HTML / 前端离线包类应用必须用系统 WebView**；
- **长按菜单**（保存图片 / 视频、复制链接）、**状态栏自动取色**、**跟随系统深色模式**、**Hosts 映射**、**页面缩放设置**（只保留双指缩放）、**Cookie 策略**（固定接受全部 Cookie）；
- **新窗口策略** —— 弹窗一律在当前窗口加载；
- **WebView 状态保存 / 恢复** —— 进程被系统杀掉后无法还原会话；
- **代理的用户名 / 密码认证**、**控制台消息回传**（脚本会执行，但面板收不到输出与返回值）。

另有几项属于设计取舍：使用 GeckoView 时，**TLS 指纹伪装**与**强制 HTTP/3** 不适用（改用 GeckoView 本身携带的 Firefox 指纹，效果更彻底）；**不允许忽略 SSL 证书错误**；悬浮窗模式固定使用系统 WebView，不跟随应用的内核选择。

## 三、两个内核都完整支持的能力

换内核不必担心的部分：加密 SNI（ECH）、DoH、静态 / PAC / SOCKS5 代理、防抓包（强制直连、忽略系统代理）、UA 模式与自定义 User-Agent、桌面模式、JavaScript 开关、自动播放策略、视口模式、启动时清除浏览数据、HTTP 下载、全屏视频、文件上传（含拍照）、摄像头 / 麦克风 / 地理位置授权策略、mTLS 客户端证书、页面加载错误提示、前进 / 后退历史导航、自动刷新、页内查找、媒体会话与锁屏播放控制。

## 四、切换与下载步骤

引擎选择在**构建对话框**里做，引擎本身在 **⋮ → 浏览器内核** 里管理：

1. 在 **⋮ → 浏览器内核** 里下载 GeckoView 运行时，界面上会显示下载大小与进度；
2. 下载完成后，构建对话框才允许选择 GeckoView —— **没下载就选不了**；
3. 构建器里预览时如果运行时缺失，会**自动回退到系统 WebView**，所以预览正常不代表导出后用的是 GeckoView，这一点要和 [预览正常但导出后失效怎么办.md](预览正常但导出后失效怎么办.md) 一起看；
4. 构建时引擎判定以你在对话框里的选择为准。

同一个界面里还能查看本设备的系统 WebView 版本、切换系统 WebView 提供者（带开发者选项步骤指引），以及查看主流浏览器内核的参考信息。

## 五、选错内核的典型现象

| 现象 | 多半是 |
| --- | --- |
| 广告拦截配了但页面照旧有广告 | 用了 GeckoView |
| 注入的脚本完全不执行 | 用了 GeckoView |
| PWA 离线内容、静态资产包不工作 | 用了 GeckoView |
| 开了资源加密，构建或运行异常 | 加密要求系统 WebView，内核选错 |
| 想忽略证书错误继续访问，做不到 | GeckoView 不接受忽略证书错误 |
| 切到后台再回来页面被重置 | GeckoView 无状态保存 / 恢复 |

确认内核后重新构建即可生效，完整打包流程见 [把网站打包成APK的完整步骤.md](把网站打包成APK的完整步骤.md)；如果构建阶段就报错，见 [构建失败与安装报错怎么排查.md](构建失败与安装报错怎么排查.md)。
