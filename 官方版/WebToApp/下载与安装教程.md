WebToApp 是一个安卓应用，能在你自己的手机上把网页、前端项目或媒体素材打包成可安装的 APK，整个过程在设备本地完成，不需要电脑。用它的人大多是手里已有一个网址或一份前端项目，想快速得到一个能点开图标的安装包。本篇只做一件事：把网盘里这份装进手机并正常打开。

## 一、先确认它装在哪台设备上

它是**手机上的应用**，不是电脑软件，也不是在线服务。以下几点先对齐，避免装错地方：

| 事项 | 说明 |
| --- | --- |
| 运行平台 | Android 设备，官方要求 **Android 6.0（API 23）或更高版本** |
| 电脑的作用 | 电脑只能用来下载、传输安装包，构建本身在手机上完成 |
| 产物归属 | 打包生成的新 APK 也存在这台手机上，由构建器的文件管理统一存放 |
| 联网需求 | 创建应用、抓取图标、下载浏览器内核、拉取模块时需要联网 |

系统版本低于 Android 6.0 的机型不要尝试，即使装上也无法完成构建。模拟器上可以安装并试跑流程，但真机更接近实际使用环境。

## 二、网盘里这份包是哪一版

网上搜到的通常是官方发布页当时的最新版，而网盘里这份是制作文档时核对过的版本，两者未必同一个版本号。本文涉及的版本号、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | WebToApp |
| 版本号 | 2.5.5 |
| 包名 | `com.webtoapp` |
| 安装包体积 | 58.83 MB |
| MD5 | `86cf7938ada05fa7d9917d5d9bbda148` |
| 记录时间 | 2026-09-23 |

官方发布页的版本号后续可能已经高于 2.5.5，具体数字以官方发布页当时显示的为准，这里不预判后续编号。要校验下载有没有传坏，可以在电脑上算一遍 MD5，结果应当与上表一致：

```cmd
certutil -hashfile WebToApp_v2.5.5.apk MD5
```

（文件名随版本变化，以资源里当时提供的为准。）

## 三、下载与安装步骤

1. **转存并下载**：从 [WebToApp 安装文件资源（夸克网盘）](https://pan.quark.cn/s/98da99a44c60) 把 APK 转存到自己的网盘，再下载到手机。手机端直接下载最省事；在电脑下载的话，用数据线或传输工具拷进手机存储。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统这项常收在「安全」或「隐私」分类下，部分系统还有「纯净模式」，一并放行。
3. **点击 APK 完成安装**：系统提示「应用未经过安全检测」或「来自未知来源」时，选择继续安装即可，这是侧载安装包的常规提示。
4. **确认存储余量再装**：安装包本身 58.83 MB，构建产物还会另外占用空间。手机剩余空间紧张时先把空间清出来，避免构建到一半因写入失败中断。
5. **包名冲突时先卸载**：如果你手机上已有一个包名为 `com.webtoapp`、但签名不同的版本，直接覆盖会报「应用未安装」，需要先卸载旧的那份。

## 四、第一次打开会看到什么

启动后直接落在 **我的应用** —— 这是列出你创建过的全部应用的主页，此时是空的。

- **底部「创建」**：点开是 12 种应用类型的网格，从这里开始建第一个应用；
- **右上角「⋮」**：文件管理、批量导入、浏览器内核下载、语言等全局功能都收在这后面；
- **顶栏语言按钮**：构建器界面本身提供 10 种语言，在这里切换；界面语言跟着构建器走，**不影响**你生成的应用里配置的语言。

各入口的用途可以对照 [十二种应用类型怎么选.md](十二种应用类型怎么选.md)。真正的打包流程见 [把网站打包成APK的完整步骤.md](把网站打包成APK的完整步骤.md)。

## 五、装完做一次最小验证

先别急着配一堆功能，按下面四步确认这套环境是通的：

1. 打开 WebToApp，能看到「我的应用」空列表和底部的「创建」按钮；
2. 点「创建」能展开类型网格，说明界面与本地数据正常；
3. 随便选「网页」类型，填一个能正常访问的网址并保存，应用卡片出现在列表里；
4. 点一次卡片做预览，页面能在构建器里正常加载，说明网络与网页本身都没问题。

四步都通过，再进入实际构建。构建对话框里选项较多，第一次用默认值即可；如果构建报错或产物装不上，按报错原文对照 [构建失败与安装报错怎么排查.md](构建失败与安装报错怎么排查.md) 逐项处理。
