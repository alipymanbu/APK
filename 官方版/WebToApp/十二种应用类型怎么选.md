在「我的应用」点「创建」，弹出的网格里有 12 种类型。类型选错是新手最常见的返工来源 —— 用「网页」去包一份本地 HTML 目录，或者用「离线包」指望它带服务端逻辑，都会白折腾。本篇按输入形态把它们分成三类，帮你三十秒内选对。

## 一、12 种类型一览

| 类型 | 输入 | 产物形态 | 适用场景 |
| --- | --- | --- | --- |
| 网页 | 一个 URL | WebView 应用 | 落地页、工具站、仪表盘、文档站 |
| 多站点 | 多个 URL | 标签 / 卡片 / 信息流 / 抽屉式导航 | 链接枢纽、导航门户 |
| HTML | 本地 HTML 文件或 zip 包 | 可切本地托管的文件型应用 | 静态站点、离线 Web 应用 |
| 离线包 | 一个 URL（抓取归档） | 自包含的离线应用 | 把网站整站归档后离线看 |
| 前端 | 已构建的前端项目产物 | 可切本地托管的文件型应用 | React、Vue、Vite 的构建结果 |
| PHP | PHP 项目 | 应用 + 设备端 PHP 运行环境 | 小型 PHP 应用 |
| WordPress | WordPress 站点 | 应用 + PHP + SQLite | 便携站点 |
| Node.js | Node 项目 | 应用 + 设备端 Node 运行环境 | Express、Fastify、Koa、API |
| Python | Python 项目 | 应用 + 设备端 Python 运行环境 | Flask、Django、FastAPI |
| Go | Go 项目 | 应用 + 设备端 Go 运行环境 | Gin、Echo、Fiber |
| 媒体 | 一张图片或一段视频 | 全屏媒体播放应用 | 单张作品、单段视频 |
| 画廊 | 一个媒体集合 | 画廊浏览应用 | 相册、作品集 |

## 二、普通用户优先试这三类

对没有开发背景的人，只有这三类值得先上手：

1. **网页** —— 已经有网址的，直接抄网址就能出包，配置最全，也是问题最容易排查的一类；
2. **HTML** —— 手上是一堆 HTML / CSS / JS 文件（含 zip），不需要服务器的那种；
3. **前端** —— 已经用 React、Vue 或 Vite 构建出 `dist` 目录，想把它变成安装版。

这三类的共同点是**不依赖设备上的服务端运行环境**，少了一整层出错的可能。建议先用「网页」把一条链路完整跑通（步骤见 [把网站打包成APK的完整步骤.md](把网站打包成APK的完整步骤.md)），再换其他类型。

## 三、需要技术底子的五类

PHP、WordPress、Node.js、Python、Go 这五类会把对应的运行环境放到设备上，WebView 指向设备本地端口来提供服务。它们**确实能跑**，但真正用起来还要面对依赖、端口、权限、设备架构和性能这一整套问题，出问题时的排查难度也明显高一档。

- 第一次接触时**不要**从这五类入手；
- 这五类通常需要在「Linux 环境」里先把工具链装好，装完再创建应用；
- 官方内置了各类的示例项目（React、Vue、Vite、Node/Express、PHP/Laravel、Python/Flask、Go/Gin、WordPress 等），用它先验证你的技术栈能不能跑通，再换自己的项目。

## 四、媒体、画廊与多站点

- **媒体**：输入是单一的图片或视频，产物是全屏查看器。适合交付一张海报、一段样片这类单件内容。
- **画廊**：输入是一组媒体，产物是带浏览界面的相册。适合作品集、活动图集。
- **多站点**：输入是多个网址，产物带标签、卡片、信息流或抽屉式导航，用来把几个站点收进一个应用入口。
- **离线包**：它抓取的是**一个网址下的内容快照**，适合把资料站归档成不联网也能看的形式。注意网页里依赖实时数据、登录态或服务端接口的部分，离线后不会跟着工作。

## 五、按手上素材直接查

| 你手上有什么 | 选哪个类型 |
| --- | --- |
| 一个能打开的网址 | 网页 |
| 几个网址，想合成一个入口 | 多站点 |
| 一堆 HTML / CSS / JS 文件或 zip | HTML |
| React / Vue / Vite 构建后的目录 | 前端 |
| 想离线保存一个网站 | 离线包 |
| 单张图片或单段视频 | 媒体 |
| 一批图片或视频 | 画廊 |
| 一个能跑的 PHP / Node / Python / Go 项目 | 对应语言类型 |
| 一份 WordPress 站点 | WordPress |

类型定下来之后，创建流程的形态是统一的：**类型专属表单 → 基本信息（名称与图标）→ 保存**。图标来源与包名规则见 [包名图标与签名怎么设置.md](包名图标与签名怎么设置.md)；打包好的应用行为不对时，先看 [预览正常但导出后失效怎么办.md](预览正常但导出后失效怎么办.md)。
