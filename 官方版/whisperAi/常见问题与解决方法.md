## 一、消息旁边出现红色感叹号

红色感叹号表示这条消息没发成功，常见的三类原因按顺序排查：

1. **网络不稳定**——先切一下 Wi-Fi 和流量，用浏览器开个网页确认网是通的；
2. **服务器在维护**——网络没问题、别的人也发不出去时，等一会儿再试；
3. **当前这个角色的接口出故障**——换一个角色发一条，能发出去就说明是单个角色的问题，等它恢复即可。

发失败的消息一般可以重新发送，不用整段重打。

## 二、AI 不回应 / 发出去石沉大海

先区分两种情况：

- **有红色感叹号**：走上面第 1、2 条；
- **没有感叹号、就是不回**：按下面的顺序来——
  1. 更新到最新版本（旧版的服务接口可能已失效）；
  2. 检查机型与系统是否满足要求（安卓 5.2 及以上）；
  3. 检查网络状态，换网络重试；
  4. 都试过仍不回应，可能是服务端临时故障，隔一段时间再开对话试。

若怀疑是自己装的包不对（版本异常、功能缺失），对照 [下载与安装教程.md](下载与安装教程.md) 里的版本与大小重装一份正确的包。

## 三、界面语言不对 / 怎么切换语言

菜单显示的语言可以在应用内改：

1. 点左上角的**个人中心**；
2. 选**语言**选项；
3. 切到想要的语言，点**保存**。

注意这里改的是**界面语言**；聊天内容用哪种语言说的是另一回事，由 [聊天功能使用技巧.md](聊天功能使用技巧.md) 里的聊天翻译开关控制。

## 四、角色记忆重置 / 性格不稳定

聊了一段时间的角色突然不记得之前的设定、或人设变淡，有教程给的经验是：**每天与该角色互动 10 分钟以上，它的「性格」和「记忆」会更稳定**；已经重置的，直接去编辑角色信息把设定重新填一遍即可（编辑入口在角色资料里，字段与创建时相同，见 [自定义角色创建教程.md](自定义角色创建教程.md)）。此条来自单一教程来源，效果因账号而异。

## 五、装不上或装完打不开 / 闪退

安装阶段的拦截与解析失败先按下表处理：

| 现象 | 处理 |
| --- | --- |
| 弹「禁止安装来自此来源的应用」 | 按提示进入设置，允许本安装来源后重装 |
| 安装包解析失败 | 文件没下完整，重新下载；或系统版本低于要求 |
| 装完一点就闪退 | 先按下面的通用排查走一遍 |

闪退、无响应的通用排查顺序（安卓三方应用的常规做法，逐步执行、每步试一次）：

1. **强行停止后重开**：设置 → 应用 → WhisperAI → 强行停止，再打开；
2. **重启手机**：清掉临时故障，最省事的一步；
3. **清缓存**：设置 → 应用 → WhisperAI → 存储 → 清缓存（清缓存不丢聊天数据；「清除数据」会清空本地记录，确认要重置再点）；
4. **检查权限**：麦克风、存储等权限被禁会影响语音与图片功能，在应用权限里放行；
5. **确认系统达标**：系统版本低于要求会直接闪退；
6. **卸载重装**：装一份完整的安装包（清数据会丢失本地记录，先想清楚再卸）。

核对版本与包名可以避免反复下错包：版本 1.3.72、包名 `com.bytejourney.and.whisper`、大小 31.15M、MD5 `ED7D6A8FF5B841721CC2A4FC7317A240`（网盘里这份包的实测值）。从别处下到的包 MD5 对不上就别装了。

## 六、角色列表或图片加载不出来

加载类问题基本都是网络侧的：确认网络通畅、把应用切到后台再回来刷新一次。持续加载不出去时，多半是服务端波动，隔段时间再开。其余聊天异常对照本篇第一、二节处理。
