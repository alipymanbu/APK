Paperize 是一款开源的 Android 动态壁纸更换器，作者是开发者 Anthony La，源码以 GPL-3.0 许可公开。你如果在找「定时自动换壁纸、主屏和锁屏分开设置」这类工具，本篇先帮你把装上这一步走完：确认手机版本、选获取渠道、完成安装。

## 一、先确认你的手机能不能装

安装前核对两点：

| 项目 | 要求 |
| --- | --- |
| 系统版本 | Android 12 及以上（Paperize 3.x 与 4.x 的安装包都按这个门槛构建） |
| 安装包体积 | 约 6.81 MB |

本篇对应的安装包信息：版本 3.2.1，包名 `com.anthonyla.paperize`，体积 6.81 MB，MD5 为 `ABCFDFCADA18A30AE6F90FFFA618A1EE`。装完如果想核对文件是否完整，可以用文件管理器或校验工具比对 MD5。

低于 Android 12 的手机装这个包时，安装器会直接提示无法安装，这种情况只能升级系统或另寻支持旧系统的旧版本（官方渠道不提供旧版下载入口，旧版本仅在历史发布记录里）。

## 二、获取 Paperize 安装文件资源

获取渠道有两条路，任选其一即可：

**渠道一：夸克网盘资源**

转存 [Paperize 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c51ad3cad86c) 后取出里面的 APK 安装包，适合不方便访问境外渠道的场景。网盘里这份是 3.2.1 版，与上面列出的 MD5 对应。

**渠道二：官方发布渠道**

- GitHub 发布页：`https://github.com/Anthonyy232/Paperize/releases`，每个版本附签名 APK；
- F-Droid：`https://f-droid.org/en/packages/com.anthonyla.paperize/`，开源应用仓库，可自动接收更新；
- IzzyOnDroid：`https://apt.izzysoft.de/fdroid/index/apk/com.anthonyla.paperize`，同为 F-Droid 系仓库。

三个官方渠道的包体相互对应（F-Droid 会用官方签名密钥校验后再上架）。注意版本节奏：GitHub 发布页更新最快，F-Droid 通常要等构建审核后才上架新版本，两边显示的"最新版本"可能短暂不一致，以官方发布页为准。

## 三、安装步骤

无论从哪个渠道拿到 APK，安装流程相同：

1. 把 APK 传到手机存储（网盘 App 内直接下载即可）；
2. 在文件管理器里点开这个 APK；
3. 系统提示「不允许安装未知来源应用」时，按提示跳转到设置页，允许**当前文件管理器/网盘 App** 这一来源安装（不必全局放开）；
4. 回到安装页，点安装，等进度走完；
5. 打开 Paperize。

首次打开会出现一段引导流程，按提示授予「设置壁纸」等权限——这类权限是换壁纸类应用的必要权限，缺了就无法写入壁纸。装完后就可以直接按 [壁纸自动更换设置方法.md](壁纸自动更换设置方法.md) 配置相册与自动更换；如果想先弄清网盘这份 3.2.1 与官方最新 4.x 的差异、升级会不会丢配置，先看 [版本历史与升级注意事项.md](版本历史与升级注意事项.md) 再决定装哪版；主屏和锁屏想用不同壁纸的，配置时参考 [主屏与锁屏分开设置壁纸.md](主屏与锁屏分开设置壁纸.md)。
