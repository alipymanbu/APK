# Paperize 壁纸不自动更换的排查方法

> 本篇讲 Paperize 设好之后壁纸却不自动换的排查顺序：先分清是「没应用上」还是「被系统拦了」，再按权限、省电策略、厂商后台限制逐层排查。

「设好了却不换」是换壁纸类应用最常见的故障，而且原因大多不在应用本身——Android 的省电机制天生喜欢拦后台定时任务。本篇把排查拆成两层：先确认配置真的生效了，再处理系统拦截。按顺序走完，绝大多数情况都能定位。

## 一、先分清两种「不换」

排查前先做一个区分，两种情况的原因和对策完全不同：

| 现象 | 性质 | 看哪节 |
| --- | --- | --- |
| 应用设置完成后，一次都没换过 | 配置或权限问题 | 第二节 |
| 换过几次，之后停住了 | 后台任务被系统杀掉 | 第三、四节 |

区分方法：手动把间隔调到最短档，锁屏放一会儿再点亮，看是从来不动还是中途停摆。

## 二、一次都没换过：先查配置与权限

按这三步核对，每步都能当场验证：

1. **手动应用一次相册**：在 Paperize 里对目标屏幕重新应用一次相册，立刻看桌面或锁屏有没有变。变了说明写入壁纸的能力没问题，问题出在定时环节；
2. **确认「设置壁纸」权限在位**：系统设置 → 应用 → Paperize → 权限，逐项核对。这一项若是缺的，上面第 1 步的手动应用也会失败；
3. **只设了锁屏的场景**：锁屏效果不生效的 bug 在 3.2.1 才修复，确认你装的版本不低于 3.2.1（版本核对见 [版本历史与升级注意事项.md](版本历史与升级注意事项.md)）。

配置层面相册有没有真的指定到屏幕上、两种屏幕怎么拆开设，见 [主屏与锁屏分开设置壁纸.md](主屏与锁屏分开设置壁纸.md)。

## 三、中途停摆：关掉对 Paperize 的电池优化

Paperize 的自动更换靠前台服务加定时任务驱动，省电优化一收紧，定时就会被推迟甚至停掉。Android 12 以上的通用路径：

1. 系统设置 → 应用 → Paperize → 电池（或「电池优化」）；
2. 把优化策略从「优化」改为「不允许优化 / 无限制」；
3. 顺手确认 Paperize 的常驻通知还在不在——前台服务的通知被关掉，往往意味着服务也被一并限制了；
4. 改完观察一个完整间隔周期。

不同厂商的菜单名称略有差异，但都能在「应用信息 → 电池」里找到对应开关。

## 四、国产 ROM 还要多开两道开关

小米、华为/荣耀、OPPO/vivo 这类系统的后台管理比原生更激进，除电池优化外通常还要：

| 厂商 | 额外要开的位置 |
| --- | --- |
| 小米 | 安全中心/手机管家 → 应用管理 → Paperize：打开「自启动」，省电策略设为「无限制」 |
| 华为 / 荣耀 | 设置 → 应用 → 应用启动管理 → Paperize：改为手动管理，允许自启动、关联启动、后台活动 |
| OPPO / vivo | 应用信息 → 耗电管理：允许后台运行/后台高耗电；多任务界面把 Paperize 加锁 |
| 三星 | 设置 → 电池 → 后台使用限制：把 Paperize 移出休眠应用，加入「不进入休眠的应用」 |

以上路径以各品牌当前系统版本的实际菜单为准，名称随版本会变。另外，如果你装了清理类、加速类应用，它们可能定期杀掉 Paperize 的后台服务——把 Paperize 加进这类工具的白名单，或直接卸载。

## 五、小米用户反馈过的两个已知冲突

有小米用户长期实测后反馈过两个系统层面的冲突（单一用户记录，供参考；截至 2026 年的 Hyper OS 3 已修复）：

- **全屏 AOD 与换壁纸冲突**：Hyper OS 2 上，Paperize 切换壁纸后，全屏息屏显示会短暂黑屏、点亮屏幕才恢复，导致息屏期间大部分时间看不到壁纸；
- **换壁纸触发系统取色重载**：切换壁纸后系统重新取色，部分正在运行的应用被强制停止（桌面重载、音乐暂停）。这是小米系统自身的取色实现问题，换用系统自带的轮播功能同样会触发，不是 Paperize 独有的问题。

遇到这两类现象，先升级到 Hyper OS 3 再观察；排除不了再按第三、四节检查 Paperize 自身的后台权限。

## 六、全部试过仍不行的兜底

1. 卸载后重装 Paperize（重装会清掉应用内配置，原图不受影响，重装后需重新导入相册）；
2. 换一个渠道的安装包再试（渠道清单见 [下载与安装教程.md](下载与安装教程.md)），排除个别渠道包的问题；
3. 官方仍在持续修调度相关的 bug（4.x 各版的更新日志里多次出现），如果 3.2.1 在你的机型上始终不稳，升级到 4.x 是最后手段——注意 3 升 4 会重置相册与设置，见 [版本历史与升级注意事项.md](版本历史与升级注意事项.md)。
