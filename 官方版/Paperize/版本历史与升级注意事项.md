Paperize 按 `v主版本.次版本.修订号` 的节奏发布，官方发布页长期维护更新日志。本文写作时，网盘资源里的是 3.2.1 版，官方最新已进入 4.x 线——两个大版本之间有「升级会重置配置」的坑，先看清楚再决定升不升。具体最新版本号以官方发布页为准。

## 一、3.2.x 线修了什么

3.2.x 是 3.x 线的收尾阶段，两个修订都冲着相册与效果的实际问题去的：

| 版本 | 修复内容 |
| --- | --- |
| v3.2.0 | 修复大体积壁纸导入失败；修复添加的图片没有保存进相册；更新依赖与翻译 |
| v3.2.1 | 修复「只使用锁屏相册时，亮度/模糊效果不作用在锁屏壁纸上」 |

如果你正在用 3.2.0 或更早的 3.x 版本，且遇到过导入大图失败、加图不保存、锁屏效果不生效这三个问题中的任何一个，升级到 3.2.1 就能解决，配置不受影响（同为 3.x，无重置）。

## 二、4.x 是一次重写，升级前必读

官方对 4.0.0 的定位是**完全重写**，从这版起：

- 界面整体换新，并新增了静态/动态（live）两种壁纸模式；
- 效果项大幅扩充：缩放、模糊、暗化、晕影、灰度、自适应亮度、视差、双击换壁纸、随机与间隔控制等；
- 快捷设置（Quick Settings）磁贴、手动换壁纸控制、大图与整文件夹导入的进度提示；
- 最低系统要求保持 Android 12 及以上。

**关键的升级警告**：官方在 4.0.0 发布说明中明确写了——从 Paperize 3 升级到 4，本地的相册与设置会被重置一次（4.x 改用了新的存储模型）。也就是说，你精心分好的相册、指定的屏幕对应关系、调好的效果参数，升级后都要重新配一遍。

升级前建议做两件事：

1. 把各相册对应的图片文件夹在手机里的位置记录下来（4.x 重建相册时要重新指向）；
2. 截图保存当前的主屏/锁屏指定关系与效果参数。

不急着用 4.x 新功能的，停在 3.2.1 完全没问题，它是 3.x 线的稳定收尾版。

## 三、各渠道的版本节奏

| 渠道 | 更新节奏 | 说明 |
| --- | --- | --- |
| GitHub 发布页 | 最快 | 每个版本随发随挂签名 APK |
| F-Droid | 滞后数天不等 | 需经仓库构建审核后才上架 |
| IzzyOnDroid | 与 F-Droid 系接近 | 同为第三方仓库 |

在 F-Droid 上看到「最新版」比 GitHub 发布页旧一截属正常现象，不是渠道出了问题。无论哪个渠道，升级前都先看一眼官方发布页的更新日志，确认没有类似「3 升 4 重置配置」这类一次性影响，再动手。

## 四、升级操作

- 3.x 内部升级（如 3.2.0 → 3.2.1）：直接安装新 APK 覆盖，配置保留；
- 3.x → 4.x：直接覆盖安装也可以，但按上文预期相册与设置会被重置，装完重新导入即可；
- 降级（4.x 退回 3.x）：Android 对覆盖安装要求新版本号不低于旧版本，降级需要先卸载再装——卸载会清掉应用数据，同样按「配置会丢」预期。

安装包获取方式见 [下载与安装教程.md](下载与安装教程.md)。
