## 一、装之前先核对三件事

1. **系统版本**：这份安装包对应的系统要求为 Android 5.2 以上（应用信息页的标注口径）。近几年的手机基本都满足，老设备装不上多半是这一条不达标。
2. **存储空间**：安装包本身 66.02 MB，安装后还会展开出缓存与数据文件，给应用留出几百 MB 以上的余量比较稳。
3. **来源核对**：安装包下载完成后，可以核对下面这份本地事实，确认你拿到的是同一份文件。

| 项目 | 数值 |
| --- | --- |
| 应用名称 | Stardom（官方商店拼写为 STARDOM） |
| 版本 | 2.0.18 |
| 包名 | `com.comwithus.stardom` |
| 安装包大小 | 66.02 MB |
| MD5 | `46549BC4AB69ECF7CED23D4ABE0FE489` |
| 开发者 | ComWithUs |

版本号、包名、大小都以这份本地记录为准——应用商店里展示的是官方最新版，和你实际安装的这份不一定相同。

## 二、获取安装包

转存 **[Stardom 安装文件资源（夸克网盘）](https://pan.quark.cn/s/26d415300603)** 到自己的网盘，再从网盘下载到手机即可。下载得到的是一个 `.apk` 文件，文件名里会带版本号（`Stardom_v2.0.18.apk` 这样的形式），一眼能认出来。

用文件管理器或网盘客户端的下载列表都能找到它；下载中断的话重进下载列表续传即可。

## 三、安装步骤

1. 点开下载好的 `.apk` 文件，系统会弹出「是否安装」的确认框。
2. 第一次装会提示「不允许安装未知来源应用」——这是安卓的默认保护，不是文件坏了。处理路径：系统设置里找到「安装未知应用」权限（各品牌位置不同，一般在「应用 → 特殊权限」下），给**你用来打开安装包的那个应用**（浏览器或文件管理器）授权。
3. 部分国行系统（小米、华为等）有「纯净模式」一类的开关，拦截外部安装包时需要先按系统提示关闭或验证，再回到步骤 1 重试。
4. 安装完成点「打开」，或回桌面点 Stardom 图标。

装不上、提示解析失败这类情况，优先重新下载一遍安装包再核对 MD5，具体排查见[常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、装完第一屏会看到什么

- **选偶像**：首次进入会先让你挑选喜欢的偶像或感兴趣的领域，选完之后首页的资讯、榜单内容会围绕你的选择来组织。
- **登录引导**：想投票、参与活动就需要先登录，Stardom 用第三方账号授权进入，没有独立的站内注册流程，具体见[账号注册与登录指南.md](账号注册与登录指南.md)。
- **语言**：界面以英文、韩文为主，商店页面上的中文描述多为机器翻译。遇到看不懂的菜单，可以对照[投票与打榜玩法入门.md](投票与打榜玩法入门.md)和[常见问题与解决方法.md](常见问题与解决方法.md)里的功能说明。

## 五、用 iPhone 怎么办

这份安装包只适用于安卓。iOS 设备直接在 App Store 搜「STARDOM」（认准开发者 ComWithUs），应用为免费下载、含应用内购买：[App Store 页面](https://apps.apple.com/app/id6479585038)。iOS 版由官方商店渠道更新，版本号与安卓这份安装包不通用，以商店当时显示为准。
