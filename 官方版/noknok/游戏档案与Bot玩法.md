## 一、档案卡：先绑定，再展示

游戏档案卡相当于你的个人名片：绑定 Steam、NS 这类平台后，你的游戏数据会显示在档案里，别人点开就能看到你在玩什么、玩到什么程度。在这个靠群聊交朋友的社区里，这是别人快速认识你的主要途径。

绑定的具体路径：

1. 打开 NokNok，进入个人中心；
2. 打开「我的档案」界面；
3. 选择要绑定的平台账号，按提示完成授权。

公开介绍里明确提过的可绑定平台有 Steam、NS、PS；能绑定哪些游戏与平台，以内测期间的实际上线列表为准——早期介绍里就写明「能绑定的还比较少、后续会增加」，你绑定时以界面里给出的选项为准。

## 二、展示范围自己控制

档案信息支持隐私设置：哪些数据公开、哪些只给自己看，可以分开勾。不想暴露游戏库细节的话，把库存类信息设为私密、只保留在玩的游戏，是常见的折中做法。

## 三、房间里的 Bot

Bot 是挂在房间里的互动工具，房主按需添加。公开介绍过的几类：

| Bot | 玩法 |
| --- | --- |
| 扭蛋恋人 | 自选卡池收集角色，带徽章升级与收录排行 |
| 卡片人世界 | 抽卡、PK、排行榜一体的互动游戏 |
| 签到 / 抽奖 / 投票 | 房间活动的现成模板，配置好就能用 |
| 陪聊机器人 | 迎新、送别、活跃气氛 |

## 四、什么场合派什么用场

- 刚建房间想留人：先上**签到、抽奖**，低成本维持日活；
- 游戏向房间：**扭蛋恋人、卡片人世界**这类带收集与排行的，适合围绕游戏版本节点搞活动；
- 话题冷清的频道：用**投票**起话头，比干聊容易开张。

Bot 的具体玩法与开放情况在内测期间变动频繁，以房间内实际可用为准。还没进房间的话，先看 [房间与频道使用指南.md](房间与频道使用指南.md)。
