## 一、有哪些登录方式

`Pokémon GO` 不自建一套独立密码体系，你用的是外部平台的账号。可选的登录方式（以游戏内实际显示为准）：

| 登录方式 | 说明 |
| --- | --- |
| Google 账号 | 安卓上最常见，有 Google 账号即可直接登 |
| Facebook 账号 | 安卓与 iOS 都可用 |
| Apple ID | 仅 iOS 提供「通过 Apple 登录」 |
| 宝可梦训练家中央站（PTC） | The Pokémon Company 的账号体系，可与其他宝可梦作品通用 |
| Niantic Kids | 儿童账号，需要家长邮箱确认授权 |

两条硬规则：

- **儿童生日只给儿童登录方式**。首次启动填了未成年生日，界面上只会出现 Niantic Kids / PTC，Google、Facebook、Apple 都不显示；填错生日只能删应用重装重填。
- **一个外部账号只能绑定一个 `Pokémon GO` 账号**。同一 Google 账号不能绑到两个游戏账号上。

## 二、注册与绑定

1. 首次启动按提示输入生日 → 点「新玩家」→ 选择一种登录方式登入，即完成注册。
2. 登录成功后，进入 设置 → 账号，可以把**额外的**登录方式绑到同一个游戏账号上（比如原本用 Google 登的，再绑一个 PTC 或 Facebook）。绑完之后，任一已绑定平台都能登进同一个角色。
3. 记住你用的是哪个平台 —— 换手机重装后，用同一个平台登录，角色进度就还在。

## 三、密码与账号找回

- **游戏不保存你的密码**，密码归登录平台管。要改密码请去对应平台改：[Google 账号帮助](https://support.google.com/accounts/answer/41078)、[Facebook 帮助](https://www.facebook.com/help/213395615347144)、[Apple 支持](https://support.apple.com/HT201487)、[PTC 找回](https://recover.pokemon.com/)。
- **不记得用哪个邮箱注册的**：用官方账号恢复页面 [my.nianticlabs.com/account-recovery](https://my.nianticlabs.com/account-recovery) 取回提醒。
- **角色等级突然变回 1 级**：不是进度丢了，是你这次登到了另一个平台的空账号上。退出后换回原来的登录方式即可。

## 四、「无法验证 / 登录失败」怎么办

出现 “Unable to authenticate” 或 “Failed to log in” 时，按官方排障顺序做：

1. 确认网络稳定，等几十秒再试一次。
2. 强制关闭游戏重开（安卓：设置 → 应用 → `Pokémon GO` → 强行停止），再登录。
3. 只用 Google 登录的安卓设备还不行：到系统 设置 → 账号 里把该 Google 账号移除再重新添加，然后重试。
4. 以上都无效，说明可能是服务器侧问题，稍后再试或通过游戏内设置菜单提交工单。

若你怀疑账号被停权：违反服务条款会导致停权，官方提供申诉入口（联系支持时问题类型选 “Ban Appeal”）。这里只提醒一句 —— 使用外挂、定位伪造等第三方辅助必然触线，账号风险自负，本文不提供任何绕过方法。

## 五、把游戏语言改成中文

游戏默认跟随系统语言。想只改游戏语言、不动系统语言：

1. 在地图界面点 **主菜单**；
2. 右上角点 **设置**；
3. 点 **一般设置（General）**；
4. 在 **语言** 一栏点下拉菜单，选 `简体中文`（或你要的语言）；
5. 点 **确定**，再点 **保存更改** —— 游戏会自动重启并应用新语言。

另一条路是直接改手机系统语言，效果一样，但会影响手机上所有应用。改完语言若界面仍是英文，说明你在系统里改的没生效，回到游戏内按上面五步再走一遍。

## 六、登录后打不开地图

登录成功但地图空白、人物不动，那是定位问题，不是账号问题：[GPS定位与闪退排查.md](GPS定位与闪退排查.md)。安装环节本身有问题则回到 [下载与安装教程.md](下载与安装教程.md)。
