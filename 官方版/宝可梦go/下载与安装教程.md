## 一、先确认手机能不能装

`Pokémon GO` 是一款走真实地图的 AR 手游，靠 GPS 定位，对设备有硬性门槛。官方帮助中心给出的安卓要求（截至 2026 年 9 月，以官方页面为准）：

| 项目 | 要求 |
| --- | --- |
| 系统 | 安卓 9 及以上 |
| 内存 | 2GB 或更多 |
| 定位 | 必须有 GPS 与定位服务 |
| Root | 不支持 Root 设备 |
| 分辨率 | 首选 720 x 1280（未针对平板优化） |
| 网络 | 稳定联网（Wi-Fi 或 5G） |

两条容易踩的坑：

- 官方已停止支持 32 位安卓设备，安卓 8 也从 0.305 版起不再支持 —— 老机型装不上或装上打不开，多半是这两条。
- 旧设备或低端机可能无法完整渲染地图，地平线位置会显示成一片雾背景，这属于设备性能问题，不是安装坏了。

装之前先看一眼自己的「关于手机」里系统版本与架构；已经装了但打不开的，直接去看 [GPS定位与闪退排查.md](GPS定位与闪退排查.md)。

## 二、安装包从哪来

两条正规获取途径：

1. **Google Play 商店**：在商店里搜 `Pokémon GO` 直接安装。手机里没有 Google 服务框架的设备走不了这条。
2. **手动安装 APK**：把安装文件下载到手机后点开安装。本文开头网盘给出的就是这种方式用的安装文件。

网盘里这份安装包的本地事实（与网上搜到的官方最新版可能不是同一版，以这份为准）：

| 字段 | 值 |
| --- | --- |
| 版本 | 0.403.1 |
| 包名 | com.nianticlabs.pokemongo |
| 大小 | 253.85M |
| MD5 | E2E1F2A296DBAF20E64C6E044F74D76A |
| 包信息记录于 | 2026-09-21 |

游戏本体免费游玩，部分道具与功能通过应用内购买提供（官方口径：基本游玩免费、部分内购）。

## 三、手动安装 APK 的步骤

1. 从 [宝可梦go 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0a61473b7d77) 把安装文件转存并下载到手机。
2. 用文件管理器点开该 `.apk` 文件。系统若弹出「禁止安装来自此来源的应用」，按提示进入设置打开「允许安装来自此来源的应用」，再返回继续安装。
3. 等安装进度走完，桌面会出现 `Pokémon GO` 图标。
4. 已经装过旧版本的，直接覆盖安装即可，游戏数据不会丢（登录的是同一个账号就都在）。

## 四、首次启动要做的三件事

1. **输入生日**：这一步决定你能看到哪些登录方式 —— 如果填成未成年人的生日，后面只会提供 Niantic Kids 与宝可梦训练家中央站（PTC）两种儿童向登录方式，Google、Facebook 等都不出现。填错了要删掉应用重装才能重填。
2. **选择登录方式并登录**：详见 [注册登录与中文设置.md](注册登录与中文设置.md)。
3. **创建训练家形象与昵称**：昵称全服唯一，起名时加点数字或字母组合更容易通过；形象之后随时能改。

接下来系统会引导你抓第一只宝可梦、设定昵称，然后就能自由行动了。玩法本身见 [新手入门玩法指南.md](新手入门玩法指南.md)。

## 五、装完打不开、闪退、定位不动

按症状排查，都在这一篇里：[GPS定位与闪退排查.md](GPS定位与闪退排查.md)。最常见的三类原因：系统版本低于安卓 9、定位权限没给、手机开启了「模拟位置」。
