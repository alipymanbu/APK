# ASKI 写作与文案生成

> 本篇讲 ASKI 写作相关功能的实际用法：能写哪些类型、社媒帖子生成器怎么用、初稿怎么改到能发。

---

写作是 ASKI 里问答之外用得最多的一块：官方介绍里列了邮件、信件、文章、诗歌、剧本、代码片段等文本类型，更新日志还加入过面向 Instagram、Facebook、LinkedIn 和 TikTok 的社媒帖子生成器。本篇按「写什么、怎么交代、怎么改」三步讲。

## 一、写作能覆盖的类型

| 类型 | 典型用途 | 交代需求时要给的信息 |
| --- | --- | --- |
| 邮件 / 信件 | 工作沟通、请假、投诉、感谢信 | 收件人是谁、你的身份、想达成什么、正式还是随意 |
| 文章 / 文案 | 公众号推文、产品介绍、活动说明 | 主题、字数、目标读者、语气 |
| 社媒帖子 | Instagram、Facebook、LinkedIn、TikTok 配文 | 平台、主题、想要的情绪（种草 / 专业 / 搞笑） |
| 诗歌 / 剧本 | 生日祝福、短视频脚本、表演串词 | 场合、长度、风格 |
| 代码片段 | 小脚本、函数示例 | 用的语言、要完成的事、运行环境 |

需求交代得越具体，第一稿的可用度越高——这条跟[问答与对话技巧.md](问答与对话技巧.md)里的提问套路是同一个道理。

## 二、社媒帖子生成器

这是后期版本加入的独立工具，进入后选平台、贴上主题或产品信息，它会按平台习惯出几条帖子文案。两点经验：

- 不同平台的调性差异大，LinkedIn 偏专业、TikTok 偏口语，选对平台再生成，比生成后手动改省事；
- 出的帖子带话题标签是常规操作，不合口味可以让它重出，或直接说「不要标签」。

## 三、把初稿改到能用

第一稿通常只是「差不多」，收尾靠三招：

1. **换写法**：让它换一种语气（更正式 / 更轻松）、换长度（压缩到一半 / 展开细节），一稿多版里挑；
2. **逐段改**：只指出不满意的那一段让重写，别整篇重来，保住已经能用的部分；
3. **给例子**：贴一段你自己写过的文字让它模仿风格，比形容词描述「专业一点」有效得多。
