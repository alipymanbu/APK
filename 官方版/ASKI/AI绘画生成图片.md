# ASKI 绘画生成图片

> 本篇讲在 ASKI 里用文字生成图片的操作路径、提示词怎么写，以及出图不理想时怎么调整。
> **相关文档**：[写作与文案生成.md](写作与文案生成.md) · [问答与对话技巧.md](问答与对话技巧.md) · [改名与版本变动.md](改名与版本变动.md)

---

除了文字，ASKI 也能把一段描述变成图片：输入提示词、选好风格，应用生成对应的画作——官方介绍里把这个能力写作「把提示词变成艺术作品」。本篇讲操作流程与提示词写法，帮你少废几张图。

## 一、生成一张图的基本流程

1. 在应用里找到绘画（AI Art）入口；
2. 输入提示词，也就是用一句话描述你想要的画面；
3. 选择风格（官方说明里提到可选风格与配色）；
4. 点生成，等出图，满意就保存到手机。

一个跟版本有关的提醒，先看再找入口：更新记录显示 1.4.4 移除过「AI Art」标签页，到 1.5.5 才修复 Image Generator 的问题。你手上若是网盘里的 1.4.7，找不到绘画入口多半是这一版本身没有这个功能，不是你操作错了——各版本的具体差别在[改名与版本变动.md](改名与版本变动.md)里有一张时间线表。

## 二、提示词怎么写更容易出效果

一段够用的提示词通常包含四层：**主体 + 动作/场景 + 风格 + 细节**。

| 层次 | 差的写法 | 好的写法 |
| --- | --- | --- |
| 主体 | 一只猫 | 一只橘色的短毛猫 |
| 场景 | （不写） | 蹲在洒满阳光的窗台上 |
| 风格 | （不写） | 水彩画风格 |
| 细节 | （不写） | 暖色调，背景虚化 |

另外三条经验：

- 提示词直接用中文写没问题，应用本身支持多语言输入；
- 想要特定画风，就把画风名明明白白写进提示词，别指望默认风格恰好猜中；
- 一次只改一个变量——先改主体，再改风格，最后调细节，否则你不知道是哪个改动起了作用。

## 三、出图不理想时怎么调

| 问题 | 对应的调整 |
| --- | --- |
| 主体不像 | 把主体的特征写得更具体（颜色、形态、数量） |
| 风格跑偏 | 显式写风格名，如「赛博朋克」「扁平插画」 |
| 画面太乱 | 减少元素数量，一张图只放一两个主体 |
| 细节糊 | 补充光影、色调、构图角度这类限定词 |

## 四、生成的图能用来做什么

配图文、做头像、当参考稿都行——文字配图的思路在[写作与文案生成.md](写作与文案生成.md)里有讲；描述拿不准怎么写时，也可以先在对话里让 AI 帮你把想法扩写成一段画面描述，再拿去生成。
