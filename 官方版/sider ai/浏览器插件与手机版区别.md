# Sider 浏览器插件与手机版的区别

> 同一个 Sider 在电脑上是浏览器插件、在手机上是独立 App，两端的定位与功能并不相同。本篇讲清楚差别，帮你决定在哪台设备上用它做什么。

## 一、两端各自管什么

官方帮助中心对分工的说法是：插件端主要用于处理复杂任务，让 AI 在你浏览网页时协助；手机应用则提供不同的 AI 聊天机器人，让你随时聊天。落到日常动作上：

| 端 | 你在上面做的事 |
| --- | --- |
| 浏览器插件 | 边看网页边总结、翻译当前页面、分析 PDF 与截图、让 AI 沿着搜索结果作答 |
| 手机 App | 随时打开聊天、悬浮球调出侧边栏、识屏提问、把文件丢进去问 |

手机版的悬浮球与识屏是 App 独有的交互，电脑端没有对应物，用法见 [悬浮球与识屏聊天用法.md](悬浮球与识屏聊天用法.md)。

## 二、覆盖哪些平台

官网与多个第三方资料口径一致：浏览器插件支持 Chrome、Edge（另有 Safari 的第三方口径）、网页版 `https://sider.ai`，桌面端有 Windows 与 macOS 应用，移动端有 iOS 与 Android App。你在哪端用，装对应客户端即可；安卓 App 的安装说明见 [下载与安装教程.md](下载与安装教程.md)。

## 三、账号、记录与积分是共用的

- 两端登录同一个账号，会员与积分跟着账号走，不在设备上单独计费；
- 官方帮助中心的口径：多设备间的聊天记录**自动同步，始终开启、无法关闭**——在插件里问过的对话，手机上打开「聊天记录」能看到；
- 有用户反馈过两端积分显示偶尔不同步的情况（单一来源），发现数字对不上时以「我的账户 → 计费」页为准，核对方法见 [模型选择与积分消耗.md](模型选择与积分消耗.md)。

要注意的另一面：官方同一份 FAQ 里也写明「卸载后历史记录将被删除且无法恢复」。同步的口径以官方说明为准，稳妥做法是重要对话先复制保存，再动卸载，见 [登录与账号问题.md](登录与账号问题.md)。

## 四、按设备选用法

| 你的场景 | 建议 |
| --- | --- |
| 电脑上查资料、读长文、对比信息 | 用浏览器插件，AI 直接贴着网页工作 |
| 手机上随手问、翻译别处看到的文字 | 用 App，悬浮球随时调出 |
| 同一个任务想在两台设备接着做 | 同一账号登录，聊天记录自动同步 |
| 想省积分 | 先搞清不同模型的扣分档位再下手，见 [模型选择与积分消耗.md](模型选择与积分消耗.md) |

两端混用中碰到的高频问题集中列在 [常见问题解答.md](常见问题解答.md)。
