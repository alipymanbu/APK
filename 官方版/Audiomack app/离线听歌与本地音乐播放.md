## 一、两条路线，先分清

| | 平内下载（离线缓存） | 本地文件播放 |
| --- | --- | --- |
| 歌从哪来 | Audiomack 曲库内点「Download」 | 你自己拷进手机的 MP3 等文件 |
| 存在哪 | 应用私有缓存目录，文件管理器里看不到散装音频 | 还在你原来的文件夹里 |
| 无网能不能听 | 能（官方口径 data-free，离线播放不耗数据流量） | 能 |
| 限额 | 免费账号有限制，Audiomack+ 无限量 | 无 |

两条路线用的入口不一样：平内下载在歌曲/专辑菜单里，本地音乐在资料库（Library）的本地文件区块。

## 二、平内下载怎么操作

1. 找到想离线的歌曲、专辑或歌单；
2. 点条目旁的菜单（通常是竖排三点）或下载图标，选「Download」；
3. 下载任务在后台进行，完成的条目会带离线标记，之后在 Library 的下载区集中管理；
4. 想腾空间时，在同一位置选删除下载即可，只删缓存不删你的收藏。

注意事项：

- **免费账号的下载限额**是官方用来区分订阅的门槛之一，碰到「下载按钮被锁、提示订阅」就是到了限额或该内容不在免费下载范围内，对照 [免费与付费区别.md](免费与付费区别.md) 处理；
- 离线缓存属于应用数据，**卸载重装会全部清空**，换机时靠登录同一账号恢复收藏，但离线缓存需要重新下载；
- 长期不联网登录，应用可能要求你重新上线验证一次账号才继续允许离线播放（流媒体通用做法），隔三差五连一次网即可；
- **离线内容也可能「消失」**：官方条款保留了随时下架、调整内容的权利，所以艺人删歌或内容可用性调整后，已下载的缓存会跟着失效——这不是你手机的问题，对照 [登录与播放问题排查.md](登录与播放问题排查.md) 第四节判断。

## 三、播放手机里的本地音乐

Audiomack 内置了本地文件播放器，支持的常见格式包括 **MP3、AAC、M4A、WAV** 等安卓系统原生音频格式。使用路径：

1. 把音频文件用数据线、网盘或文件传输工具放进手机存储（任意可读目录都可以，`Music`/`Download` 目录最常规）；
2. 打开 Audiomack，进入 Library（资料库），找到本地音乐（Local）区块；
3. 首次进入它会扫描手机存储里的音频文件，扫出来的文件按艺人/专辑归组后即可直接播；
4. 个别文件没被扫到时，检查格式是否在上表范围内，或换一个目录重新扫描。

它承担的是「顺便帮我把本地歌也播了」的角色——扫描速度与整理能力不如专门的本地播放器，但省得你再装一个应用；如果你的本地歌单很大、讲究标签管理，可以把它当应急播放器。

## 四、离线听歌时的省流量建议

- 出发前在 Wi-Fi 环境把要听的专辑/歌单批量下载，比在蜂窝网络下现点现播省得多；
- 应用设置里的「仅 Wi-Fi 下载」类开关（以应用内设置项为准）建议打开，避免自动更新缓存偷跑流量；
- 离线内容和在线内容会互相顶替缓存空间，手机存储紧张时优先删听过一遍的下载项。
