## 一、注册与登录

第一次打开应用会引导你完成注册或登录：新账号用邮箱按提示填邮箱、设密码、验证即可；已有 Google 或 Apple 账号的话，应用内一般也提供对应的快捷登录入口（以应用内当前显示的按钮为准）。

注册这一步绕不开：不登录的话，收藏、歌单、下载这些功能都无法使用。验证邮件收不到、登录一直转圈这类情况，直接按 [登录与播放问题排查.md](登录与播放问题排查.md) 第二节处理。

## 二、认识主要页面

装好后底部导航大致是这几块（版本不同措辞可能略有差异，以应用内实际界面为准）：

| 页面 | 你在这里做什么 |
| --- | --- |
| Home / 首页 | 看平台推荐与你关注艺人的更新 |
| Trending / 热门趋势 | 平台热度榜，分歌曲、专辑、艺人几个维度，是发现新歌的主要入口 |
| Search / 搜索 | 按歌名、艺人名、专辑名找内容 |
| Favorites / 我的收藏 | 收藏过的歌曲、专辑、歌单集中在这里 |
| Library / 资料库 | 你的下载内容、本地音乐、播放历史 |

界面默认是英文，应用内没有完整的中文本地化，用的时候需要适应一些英文词汇（Favorite 收藏、Download 下载、Playlist 歌单、Follow 关注）。

## 三、找歌与关注艺人

- **搜索**：顶部搜索框输入艺人名或歌名，结果分 All / Songs / Albums / Playlists 几类；搜不到的歌多半是不在曲库里，换关键词或拼音、英文别名再试；
- **关注**：进艺人主页点「Follow」，之后该艺人的新发布和动态会出现在你的首页与关注流里；热门艺人（如官方运营的 Audiomack Africa、Audiomack Hip-Hop 等频道账号）也值得关注，相当于订阅了一个选歌编辑；
- **收藏**：歌曲或专辑右侧的星星/加号图标点一下即入收藏，收藏内容在 Favorites 页可整组随机播放（shuffle）。

## 四、歌单

- **用现成的**：首页与 Trending 里有官方按心情、流派整理的歌单（mood / genre curated playlists），点开直接播；
- **建自己的**：在任意歌曲或专辑的菜单里选「Add to Playlist」，第一次会要求新建歌单并起名；歌单数量没有上限，建多少个都行。

## 五、下载与播放设置

点歌曲或专辑菜单里的「Download」就能把内容存到手机离线听，免费账号有下载限制，具体规则和本地音乐导入在 [离线听歌与本地音乐播放.md](离线听歌与本地音乐播放.md) 里展开。播放界面支持后台播放与锁屏控制，切歌、暂停都能从通知栏操作。

免费版播放时会插广告，想去广告可以看 [免费与付费区别.md](免费与付费区别.md)。
