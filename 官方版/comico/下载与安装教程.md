## 一、comico 是什么

comico 是 NHN comico（NHN comico 株式会社，总部东京）运营的漫画阅读 App，2013 年上线，主打竖向滚动的全彩条漫，也有横排阅读的单行本作品。官方公布的数字是日本国内累计下载超 2300 万、原创作品 600 部以上（数字会随官方页面变动，以 [NHN comico 官网](https://www.nhn-comico.com/) 当时显示为准）。它同时提供 iOS、Android 与网页三个版本，并按地区分过日本、台湾、韩国、泰国、越南等版本。

你要装的是其中的 **Android 台湾版**，包名 `tw.comico`，界面语言为中文。它和日本版（包名 `jp.comico`）是**包名不同的两个应用**：装了其中一个再装另一个，系统会当成两个独立应用，互不覆盖、互不共用数据 —— 两版的完整差异见 [台版和日版有什么区别.md](台版和日版有什么区别.md)。

## 二、这份安装包的参数

下面这行是**这份安装文件本身的事实**，与官方渠道正在分发的版本未必是同一个版本（版本号会一直往上走）：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.4.5 |
| 包名 | `tw.comico` |
| 大小 | 15.74M（16,499,919 字节） |
| MD5 | `367AD5E11C2E0E866CBB3AFAD65E7750` |
| 最低系统 | 安卓 5.2 及以上 |
| 记录时间 | 2026-09-23 |

两点先说清楚：

- **版本以这份为准**。你在别处搜到的「最新版」可能是另一个版本号、甚至另一个包名（比如日版），与网盘里这份不是同一个文件；装哪个由你决定，本文其余部分讲的都是这份包。
- **别拿日版的版本号来比**。日版商店页显示的版本号远高于 2.4.5，两者的更新节奏完全独立，对不上是正常的。

## 三、安装包从哪拿

[comico 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2fdd4d992eb4) 就是这份 2.4.5 安装包的入口，打开后转存到自己的网盘再下载。文件夹里通常还带一个 `先保存再下载避免失效.txt` 的说明文件：先转存、再下载，链接失效时分享者可以原地更新文件而分享链接不变。

想确认下到的是同一份文件，用 MD5 比对。Windows 上在安装包所在目录开个命令行：

```powershell
certutil -hashfile comico_v2.4.5.apk MD5
```

输出与上表的 MD5 一致，就是同一个文件。

## 四、安装步骤

1. 手机上先确认有空间：这份包 15.74M，安装后实际占用比包体更大，给系统留出余量。
2. 用文件管理器打开下载好的 `.apk`，点安装。系统若弹出「禁止安装未知来源应用」，按提示给当前这个文件管理器（或浏览器）打开「安装未知应用」权限，装完可以关掉。
3. 安装时如果提示「已安装同名应用」且签名不一致，先卸载旧的再装 —— 这种情况多见于你手机上已有来自其他渠道的 `tw.comico`。
4. 装完打开，**首次启动需要联网**：作品列表、封面与章节图都在线加载，断网状态下首页出不来。

## 五、第一次打开之后

- 界面语言与作品库跟随这个台湾版本身的设定，不用额外选地区。
- 想直接开始翻，先看 [新手使用指南.md](新手使用指南.md)；想弄清楚哪些话要等、哪些能马上看，看 [免费看漫画的机制说明.md](免费看漫画的机制说明.md)。
- 装不上、闪退、图不出来这类问题，按 [常见问题与故障排查.md](常见问题与故障排查.md) 的顺序处理。
- 这个服务目前处于特殊时期（日版已公告停止服务时间表），付费或囤币之前先读 [服务停止时间与后续安排.md](服务停止时间与后续安排.md)。
