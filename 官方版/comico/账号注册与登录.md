## 一、不登录也能用，但这些事必须登录

游客状态可以浏览作品库、读免费话 —— 你装完就能直接翻。但以下几类必须有账号：

- **付费代币**：游客账号用不了自己充值的点数，充之前要先登录；
- **票券与代币的持有**：这类资产挂在账号上，账号没了就没了；
- **换机延续**：书架与阅读记录跟账号走，重装或换手机后登录同一账号才接得上（具体同步范围以应用内说明为准）。

结论：只是随手翻翻可以不注册；打算长期追、甚至打算花钱，先注册再用。

## 二、注册与登录入口

入口在应用内，一般在**菜单/账号**那一栏里（不同版本叫法不同，找「登录」「注册」或头像图标即可）。注册流程按应用内的引导走：填写账号信息、设密码、完成验证，几步就能建好。

具体支持哪些注册方式（邮箱、第三方登录等）**随版本与地区不同，以应用内实际列出的为准** —— 别照别处教程里的按钮位置硬找，那是别的地区版本的界面。

## 三、常见账号问题

| 现象 | 怎么处理 |
| --- | --- |
| 收不到验证邮件 | 先查垃圾邮件箱；确认邮箱地址没拼错；隔几分钟再点一次「重新发送」 |
| 登录反复失败 | 确认账号归属地区版本（台版与日版是分开的账号体系，别拿日版账号在台版登）；改用重设密码走一遍 |
| 忘记密码 | 用登录页的「忘记密码」重设，按邮件里的链接操作 |
| 换了手机 | 装好应用后先登录再翻，书架和记录才接得上 |

台版与日版**账号体系互相独立**这一点最容易踩：包名不同（`tw.comico` / `jp.comico`）、服务与运营安排也各自发布，账号不通用（详细对照见 [台版和日版有什么区别.md](台版和日版有什么区别.md)）。

## 四、遇到问题找谁

- **应用内**：账号 → 帮助 → 联系我们（咨询表单），这是官方给的咨询通道。
- **日版网页表单**：[https://www.comico.jp/inquiry](https://www.comico.jp/inquiry)（日版页面，台版用户优先走应用内通道）。
- **官方社媒**：[comico 官方 Facebook](https://www.facebook.com/comico.jp) 与 [comico 官方 X 账号](https://twitter.com/comico_jp)，服务公告会先发在这里。

咨询前准备好：账号邮箱、应用版本（这份包是 2.4.5，见 [下载与安装教程.md](下载与安装教程.md)）、问题截图，能省一轮来回。

## 五、网页版要不要用

官方另有网页版，日版官方页面标注的支持环境是：浏览器 Google Chrome / Safari / Microsoft Edge 的最新版，推荐系统 Windows 8 以上、macOS、iOS 15 以上、Android 7.0 以上（以 [comico 网页版](https://www.comico.jp/) 当时显示为准）。网页版与手机端是同一批账号体系下的两个入口，日常追更在手机上更顺手，网页版适合手边没手机时应急。
