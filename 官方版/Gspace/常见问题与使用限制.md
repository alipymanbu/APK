## 一、初始化与登录阶段的问题

| 现象 | 怎么处理 |
| --- | --- |
| 卡在「下载必要 Kit」不动 | 确认手机能访问谷歌服务器，然后耐心等 —— 整个安装可能要几分钟，中途别强退 |
| 登录 Google 账号时闪退 | 退出应用重开一次；还不行见下方「闪退的排查顺序」 |
| 登录页提示 cookie 设置有问题 | 这是 Google 登录页的通用报错：退出重进再试一次，再不行到 设置 → 应用管理 → Gspace → 存储 → **清空缓存**（选「清空缓存」，别点「删除数据」），回到空间重新登录 |
| 商店里搜不到 Gspace | 大陆区商店的问题，把商店的「国家/地区」改到中国香港等地区，步骤见 [下载与安装教程.md](下载与安装教程.md) |
| 安装 APK 时被安全提示拦下 | 系统纯净模式在拦侧载包，到 设置 → 系统和更新 → 纯净模式 → 增强防护 关闭后验证安装，见 [下载与安装教程.md](下载与安装教程.md) |
| 一直转圈、页面加载不出来 | 网络没到谷歌那侧，先解决网络再重试，Play 页面搜索加载慢是常态，别连点 |

### 闪退的排查顺序

按这个顺序试，走到哪步解决就停：

1. **强行停止再重开**：设置里搜「应用管理」→ 找到 Gspace → 强行停止 → 重新打开。
2. **看存储还剩多少**：可用空间低于两成时应用容易闪退（各类应用通病），先清理出空间。
3. **清缓存/清数据**：同一位置进「存储」→ 先试**清空缓存**；还不行再**删除数据**（会清掉空间里的登录状态与数据，Google 账号要重新登，操作前想清楚）。
4. **卸载重装**：长按桌面图标卸载 → 重新装（安装包见 [下载与安装教程.md](下载与安装教程.md)）。

## 二、日常使用的坑

- **桌面找不到刚装的应用**：它们本来就不进系统桌面，要么从 Gspace 主界面进，要么建一次快捷方式，见 [桌面快捷方式与会员订阅.md](桌面快捷方式与会员订阅.md)。
- **收不到消息推送**：Gspace 被系统清出后台后，里面的应用也跟着收不到通知。要保住后台，华为手机上按这几项逐个设（路径以系统当时显示为准）：
  1. 多任务界面下拉 Gspace 的卡片**加锁**，防止被一键清理掉；
  2. 设置里搜「应用启动管理」→ 找到 Gspace → 关掉「自动管理」→ 勾选**允许后台活动**；
  3. 设置里搜「电池优化」→ 找到 Gspace → 设为**不允许**；
  4. 关掉系统的省电模式（设置 → 电池），并打开「休眠时始终保持网络连接」。
- **个别谷歌应用第一次打开异常**（如地图）：先打开一次再退出，重启手机，再从 Gspace 里进，通常就正常了。
- **克隆的应用打不开**：被克隆的那个原应用不能卸载，见 [谷歌应用下载与账号双开.md](谷歌应用下载与账号双开.md)。

## 三、明确用不了的场景

这几类不是你操作的问题，空间里跑不起来：

- **Netflix**：在 Gspace 内用不了。不过华为/荣耀这类 HMS 手机本身可以直接装 Netflix 用，不依赖谷歌服务，不必从 Gspace 走。
- **Google Pay 这类线下支付应用**：空间里用不了，出门用手机刷卡这类场景别指望它。

## 四、版本与包的差异

网盘里那份是 2.3.3（`com.gspace.android`，14.70M），与你从官网 [gspaceteam.com](https://gspaceteam.com/) 或应用商店拿到的最新版界面可能略有差别（右上角图标样式、菜单措辞都可能不同），但操作路径一致。包的实测信息见 [下载与安装教程.md](下载与安装教程.md)。
