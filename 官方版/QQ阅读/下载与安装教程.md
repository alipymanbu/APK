## 二、安装包从哪拿

**QQ阅读安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/0be2f6d5d368](https://pan.quark.cn/s/0be2f6d5d368)

打开链接后先转存到自己的网盘，再下载到手机（或先下到电脑再拷过去）。装之前顺手核对两处：

- 文件大小应为 106.94M 左右，差得多说明下载不完整；
- 想精确核对可以用任意 MD5 校验工具算一下，应与上表一致。

## 三、安卓安装步骤

1. 在手机上打开这个 APK（用系统文件管理器点它，或在网盘 App 里下载后从下载目录打开）。
2. 系统会拦一道「禁止安装未知来源应用」——点提示里的**设置**，对当前来源打开**允许**。各品牌叫法不同，常见的有「安装未知应用」「允许来自此来源的应用」，按你手机上的字眼点即可。
3. 回到安装界面点**安装**，等进度走完。
4. 首次启动会弹权限申请：**存储 / 文件权限**用于导入本地书，建议允许；通知权限可按需选择。
5. 登录：支持 QQ、微信一键登录。**云书架同步依赖同一账号**——你在手机、平板、电脑之间同步书架和进度，靠的就是都登同一个号，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、装不上、装完打不开

按提示语对号入座：

| 提示 / 症状 | 处理 |
| --- | --- |
| 「解析包时出现问题」 | 安装包下载不完整，回到第二节重新下，再核对大小 |
| 「应用未安装」 | 手机里已有同包名的旧版本残留，先卸载再装。卸载会丢本地书架数据，先确认云同步是开着的 |
| 安装按钮点了没反应 | Android 13 起授权是**按来源单独授予**的，回到第 2 步确认当前来源的开关确实打开了 |
| 装完一打开就闪退 | 按 [常见问题与故障排查.md](常见问题与故障排查.md) 的闪退一栏处理，不用急着重装 |

## 五、电脑上想用这个应用

QQ阅读 **没有官方独立的 Windows 安装包**（软件站常见问答的口径），电脑上实际是两条路：

1. **网页版**：浏览器打开阅文的 PC 门户 [book.qq.com](https://book.qq.com)，登录同一账号可延续书架与进度；
2. **安卓模拟器**：在电脑装一个安卓模拟器，再把本篇这份 APK 丢进去装——适合想在大屏上用完整 App 界面的人，电脑上闪退卡顿先查模拟器本身的版本与内存分配。

两条路都以**登同一个账号**为前提，同步细节见 [账号切换与书架同步.md](账号切换与书架同步.md)。
