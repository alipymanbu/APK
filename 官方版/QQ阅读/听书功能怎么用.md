## 一、两个入口，取决于你的版本

QQ阅读的「用耳朵读书」有两种入口，界面层级随版本变化过，先试第一个：

1. **听书按钮（较新的客户端）**：打开一本书进入阅读页 → 顶部工具栏里找**听书**按钮 → 点它切到听书模式。官方应用商店简介里的口径也是这个路径。
2. **人声朗读插件（旧版路径）**：点左上角头像 → **设置** → **我的插件** → **人声朗读** → 先点**下载**把插件装上；装好后回到阅读页，屏幕中间点一下 → **设置** → **人声朗读**，开始朗读。

你手里那份安装包是 8.3.8.888（见 [下载与安装教程.md](下载与安装教程.md)），找不到对应按钮时先按这两条路径各试一遍；两条都没有，就到应用内检查更新或换官方最新版。

## 二、听书时你会用到的三个控制

进入听书状态后，再点屏幕（或听书面板上的设置）会出来这几个开关：

| 控制 | 作用 |
| --- | --- |
| 语速 | 调快调慢朗读速度 |
| 定时关闭 | 睡前听的标配：设 N 分钟后自动停 |
| 朗读声音 | 旧版路径里，声音选择旁的 `+` 号可下载更多音色，选一个下载后应用 |

## 三、自动阅读：屏幕自己滚，和听书是两回事

「自动阅读」是**眼睛看**的自动翻页，不是听书：阅读页中间点一下 → **设置** → **自动阅读** → 再点一次屏幕，用**减速 / 加速**调滚动速度。速度档位是 1~10，1 最慢、10 最快。

## 四、听不出声音时按这个顺序查

1. 手机媒体音量是不是调到 0 了、有没有开静音；
2. 你走的是旧版路径的话，「人声朗读」插件**必须先下载完成**才会有声音；
3. 两条路径都找过、按钮确实不存在，多半是客户端版本旧了——按 [常见问题与故障排查.md](常见问题与故障排查.md) 升级到最新版再看。
