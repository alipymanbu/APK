## 一、先做这三件通用事

查具体症状前先过一遍这三步，多数情况到这就解决了：

1. **强停重启**：长按 QQ阅读 图标 → **应用信息** → **强行停止**，再重新打开；
2. **清缓存**：同一页面进**存储占用** → **清除缓存**（清缓存不丢书架；「清除数据」会丢本地数据，非必要不点）；
3. **升级**：App 内或应用商店检查更新。系统刚升大版本（如 Android 15）后出的问题，优先把 App 升到最新。

## 二、按症状查表

| 症状 | 按这个顺序处理 |
| --- | --- |
| 打开就闪退 / 无响应 | 强停重启 → 清缓存 → 检查存储与通知等权限是否被禁 → 升级到最新版 → 仍不行再卸载重装（**重装前先确认云同步开着**，见下一条） |
| 登录失败 | 换网络（Wi-Fi 与流量互切）→ 确认账号密码，忘了就走找回流程 → 清缓存后重试 → 卸载重装最新版 |
| 书架里的书突然不见了 | ① 确认登的是原来那个 QQ 账号；② **我的 → 设置 → 云同步**，把「书架同步」「阅读进度同步」都打开；③ 书架页找**导入书籍 → 云书架**手动恢复；④ 本地导入的书用**导入本地书**重新扫描 |
| 换设备后进度不同步 | 两台设备登**同一账号**；设置里确认两个同步开关都开；书架页**下拉刷新**强制触发一次同步，等它转完 |
| 装的版本旧、找不到新功能 | 网盘里那份是 8.3.8.888（2026-09-22 整理），早于官方最新版；要新功能就升官方最新版——升级入口见 [下载与安装教程.md](下载与安装教程.md) 第一节的官方页面，升级前同样先确认云同步 |
| 下载书籍失败 | 切换网络重试；存储空间不足时先用系统清理工具清出空间再下 |
| 听书没有声音 | 不是故障也先查这条：媒体音量、旧版的人声朗读插件是否已下载，详见 [听书功能怎么用.md](听书功能怎么用.md) 第四节 |
| 想隐藏的书还显示在书架 | 移入私密书架没生效，重走一遍批量设私密，见 [私密书架设置教程.md](私密书架设置教程.md) |

## 三、什么时候该卸载重装

前三步都做了还不好，才走到这一步。两个前提：

1. **先确认云同步是开着的**——重装会清掉本地数据，书架、进度靠同账号云端恢复（本地导入的书要自己留着原文件，见 [私密书架设置教程.md](私密书架设置教程.md) 第三节的代价表）；
2. 重装的包要完整——大小核对与安装步骤复用 [下载与安装教程.md](下载与安装教程.md)。
