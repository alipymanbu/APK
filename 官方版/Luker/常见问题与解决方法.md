## 一、界面是英文，怎么换成中文

首次启动的「Welcome to Luker!」对话框顶部就是语言选择器，切到「简体中文」即可。如果当时直接关掉了对话框，欢迎向导只在首次启动（或清空应用数据后）出现——清数据前先把重要聊天记录导出，操作见 [酒馆数据迁移.md](酒馆数据迁移.md) 里的备份提醒。

## 二、用不用花钱

Luker 本体免费开源，源代码在 [https://github.com/funnycups/Luker](https://github.com/funnycups/Luker)。真正花钱的地方只有模型调用：API 用的是按量计费的商业服务（OpenAI、Claude 等）就按它的账单走，用本地模型或免费额度的服务则可以零成本跑。开了记忆图、多 Agent 编排之后每轮的模型调用会变多，费用跟着涨，控制方法见 [记忆图与多Agent编排.md](记忆图与多Agent编排.md)。

## 三、发消息没有回复或一直报错

绝大多数情况是 API 没配好，按顺序查：

1. **有没有配 API**——Luker 自己不带模型，没接 API 时发消息不会有任何回复。没配的先看 [API连接与模型配置.md](API连接与模型配置.md)；
2. **密钥对不对**——多复制一个空格、少粘贴一段都会失败；顺手确认账户还有没有额度；
3. **模型选了没有**——连接通了还要在模型列表里选一个具体模型；
4. **看请求检查器**——设置里有内置的请求检查器（Request Inspector），能看到每次发给 API 的完整请求和返回内容。报错原因（401 密钥错、429 限流、超额）都在返回里，比猜快得多。

用中转站的话，检查代理地址是否填成了中转站给的 URL、密码是否填对，这类报错同样在请求检查器里看最直接。

## 四、安装失败或打开就闪退

对照这张表排查：

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 解析包出错 / 应用未安装 | 下载不完整，文件损坏 | 重新下载；2.1.2 这份包的 MD5 是 `31E96EF5D9B1EDA533A46AA3F428B554`，可核对 |
| 安装按钮点不动 | 存储空间不足 | 安装包 402.65M，装完占用更大，清出 1GB 以上余量再试 |
| 提示禁止安装 | 未授权未知来源应用 | 在弹窗或系统设置里允许你的文件管理器安装应用 |
| 打开就闪退 | 系统版本过低 | 要求安卓 5.2 及以上，过低只能换设备 |

仍有问题可以去官方仓库的 Issues 区搜同类反馈：[https://github.com/funnycups/Luker/issues](https://github.com/funnycups/Luker/issues)。

## 五、聊天记录和角色卡怎么备份

值得备份的东西都在 Luker 的数据目录里：角色卡、聊天记录（`.jsonl`）、世界书、预设。两个层面的做法：

- **单件导出**：角色卡能逐张导出成 `.png` / `.json`，聊天记录在聊天设置里导出，适合日常顺手存；
- **整目录备份**：把数据目录整个复制一份存到电脑或网盘，重装、换手机时直接放回去。从酒馆迁过来的用户应该已经熟悉这个套路，见 [酒馆数据迁移.md](酒馆数据迁移.md)。

备份频率的建议：剧情写到舍不得丢的时候手动存一份，别等出事才想起来。

## 六、记忆图、多 Agent 编排这些要先开吗

不用。先跑通「配 API → 选角色 → 正常聊天」这条主线，日常闲聊和单人剧情完全用不到高级功能。等你有明确需求了再回头看 [记忆图与多Agent编排.md](记忆图与多Agent编排.md)：角色聊久了记不住前面的事对应记忆图，多角色互相搭戏、群聊推进剧情对应多 Agent 编排，开启步骤和省 token 的配法都在那一篇里。

卡里人物太扁平的话，用内置的角色卡编辑助手让 AI 帮你补设定，见 [角色卡导入与创建.md](角色卡导入与创建.md)。

这些功能各有学习成本，官方文档里有专门章节，用到时再查不迟：[https://luker.cups.moe/zh-CN/](https://luker.cups.moe/zh-CN/)。

还没装好的从这里开始：[下载与安装教程.md](下载与安装教程.md)。
