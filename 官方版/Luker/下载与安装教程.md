## 一、装之前先知道这几件事

- **它是独立的安卓应用**。Luker 的 APK 版打开就是完整界面，不需要另配服务器，也不用先装 Termux，更不用在浏览器里输地址——这些是 PC 或 Docker 部署方式才需要做的事。
- **它本身不能聊天**。Luker 是角色扮演聊天平台，实际生成回复靠你接入的大语言模型 API（OpenAI、Claude、Gemini 或本地模型都行）。装完的第一件事是配 API，见 [API连接与模型配置.md](API连接与模型配置.md)。
- **要花钱的地方只有模型调用**。软件本体免费开源，费用来自你接入的 API 服务按量计费，账目明细见 [常见问题与解决方法.md](常见问题与解决方法.md) 第二节「用不用花钱」。
- **安装包不小**。本文对应网盘里的这份包为 2.1.2 版，体积 402.65M，安装后在手机上还会占用更多空间，建议预留 1GB 以上余量。系统要求为安卓 5.2 及以上（以安装包信息页标注为准）。
- **版本会一直更新**。官方在 GitHub 上持续发新版本，你拿到的这份网盘包是 2.1.2；想追最新版可以去官方发布页 [https://github.com/funnycups/Luker/releases/latest](https://github.com/funnycups/Luker/releases/latest) 查看，版本号以官方页面显示为准。

## 二、从哪里拿安装包

两个入口，任选其一：

1. **夸克网盘**：本文开头的「Luker 安装文件资源（夸克网盘）」就是这份 2.1.2 安装包的入口。打开链接转存到自己网盘后，从网盘客户端下载 APK 到手机即可。如果你正需要拿包，直接点 [Luker 安装文件资源（夸克网盘）](https://pan.quark.cn/s/60ed690e3f09)。
2. **官方 GitHub 发布页**：地址是 `https://github.com/funnycups/Luker/releases/latest`，在 Assets 里下载 APK 文件。国内直连 GitHub 速度不稳定，下载慢时可以等一等或换个网络环境。

两者装出来的都是 Luker 本体，区别只在版本新旧。

## 三、安装步骤

1. 把 APK 文件传到手机存储（网盘客户端直接下载的已经在手机上了）。
2. 在文件管理器里点这个 APK。系统会提示「禁止安装未知来源应用」，按提示允许你的文件管理器（或浏览器）安装应用；不同品牌手机的入口略有差异，一般在 设置 → 安全 或弹窗里直接给授权。
3. 等安装进度走完，点打开。
4. 如果安装中途报「解析包出错」或「应用未安装」，多半是下载不完整——重新下载一次，安装前可核对文件 MD5：`31E96EF5D9B1EDA533A46AA3F428B554`（这是 2.1.2 这份包的值，换版本号后 MD5 会不同）。

## 四、第一次打开：语言与迁移向导

装完首次启动，会出现「Welcome to Luker!」欢迎对话框，这里有两个要操作的地方：

1. **选语言**：对话框顶部有语言选择器，切换到「简体中文」后界面即刻变中文。
2. **要不要迁移数据**：对话框中间有「Migrate from SillyTavern」区块。你如果之前在 Termux 或电脑上跑过酒馆（SillyTavern），角色卡、聊天记录、世界书都能搬过来，具体操作见 [酒馆数据迁移.md](酒馆数据迁移.md)；全新用户直接关掉这个对话框，跳过即可。

这个欢迎向导只在首次启动（或清空应用数据后）出现，错过语言选择又没备份数据的话，清除应用数据重开会再次看到它——操作前先把聊天记录导出备份。

## 五、装好之后的第一步

按顺序做两件事就能开聊：

1. **配一个 API 连接**——没有它发消息不会有回复，步骤见 [API连接与模型配置.md](API连接与模型配置.md)；
2. **选一个角色卡**——可以导入现成的 `.png` / `.json` 角色卡，也可以自己捏一个，见 [角色卡导入与创建.md](角色卡导入与创建.md)。
