# Luker 酒馆数据迁移（SillyTavern → Luker）

> 本篇讲怎么把原来酒馆（SillyTavern）里的数据搬到 Luker：哪些能搬、手机上怎么搬、错过迁移向导怎么办，以及后悔了怎么搬回去。

## 一、哪些数据能直接搬

Luker 与 SillyTavern 数据格式完全兼容，以下内容都能原样使用，搬过去不需要转换：

| 数据类型 | 兼容情况 |
| --- | --- |
| 角色卡（PNG / JSON） | 直接可用，支持 V1 / V2 规范 |
| 聊天记录（.jsonl） | 直接可用 |
| 世界书（World Info） | 条目格式不变，直接可用 |
| 预设 | 直接可用（Luker 会自动分离其中的连接参数） |
| 用户人设（Persona） | 直接可用 |
| 群聊 | 直接可用 |
| 扩展设置 | 第三方扩展照常工作 |
| API 密钥（secrets） | secrets.json 格式不变，直接可用 |

两个注意点：

- Luker 独有功能（记忆图、多 Agent 编排等）产生的数据在酒馆里读不了，但它们是额外生成的状态文件，不会破坏你的原始数据；
- 迁移是双向的，以后不想用了随时能搬回酒馆，见本文第四节。

## 二、手机上搬：Termux 酒馆 → Luker APK

安卓的沙盒机制让两个应用之间不能直接互拷文件，所以要走一次「打包 ZIP → 首启向导导入」的流程。官方推荐路径不需要你碰 `Android/data` 私有目录：

1. **在 Termux 里把数据打成 ZIP**：

   ```bash
   pkg install zip
   termux-setup-storage
   cd ~/SillyTavern/data
   zip -r ~/storage/shared/Download/sillytavern-data.zip default-user
   ```

   开了多用户模式就把 `default-user` 换成 `*`；自定义过 `config.yaml` 的话也一并复制到 Download 目录。

2. **安装 Luker 并打开**：首次启动会出现「Welcome to Luker!」对话框，中间的「Migrate from SillyTavern」区块就是迁移入口。

3. **完成向导**：点「Import Data ZIP」，选刚才那个 ZIP，等导入结束。角色卡、聊天记录、世界书、预设、人设、扩展设置会各归各位。

ZIP 里的目录层级不用纠结——`characters/`、`chats/`、`worlds/` 这类子目录无论放在 ZIP 根目录还是 `data/default-user/` 下面，导入器都能自动识别。

## 三、错过了首启向导怎么办

向导只在首次启动出现。错过后的办法取决于你原来的酒馆跑在哪：

- **原数据在电脑 / 服务器 / Docker 上**：直接把酒馆的 `data/` 目录内容复制进 Luker 的数据根目录（默认 `./data`），首次启动时会自动识别加载。这是官方迁移指南的主路径。
- **原数据在 Termux、目标是手机 APK**：最省事的做法是清除 Luker 的应用数据重开，让欢迎向导再次出现（先确认没有值得保留的聊天记录，清除是全清）。之后按本文第二节走 ZIP 导入。
- **只想搬一部分**（比如几张角色卡）：不用走迁移，直接在 Luker 里逐个导入 `.png` / `.json` 文件，见 [角色卡导入与创建.md](角色卡导入与创建.md)。

如果必须手动往 `Android/data` 私有目录里拷文件，系统自带文件管理器通常进不去，需要支持该路径的第三方文件管理器，具体路径与排错可以查官方文档的迁移章节：[https://luker.cups.moe/zh-CN/guide/migration-from-termux.html](https://luker.cups.moe/zh-CN/guide/migration-from-termux.html)。

## 四、想搬回酒馆

Luker 不修改酒馆的原始数据格式，搬回去就是把数据目录复制回酒馆即可。Luker 运行时会生成一些自己的状态文件（如 `.luker-state.*.json`、角色绑定状态等），酒馆不认识这些文件，忽略它们就行，不会因为它们存在而出错。

唯一要注意的：记忆图、编排这类 Luker 独有功能里积累的内容，在酒馆里没有对应物，搬回去就看不到了。

## 五、动手前先备份

任何迁移动手之前，先把原数据完整复制一份（酒馆的 `data/` 目录整体拷走）。数据兼容性虽然标着「完全兼容」，但「随时能回退」的前提是原数据没被动过。备份文件的存放和导出习惯，可以参考 [常见问题与解决方法.md](常见问题与解决方法.md) 里的备份一节。
