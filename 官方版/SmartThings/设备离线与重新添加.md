## 一、设备为什么会显示离线

官方支持文档把离线归到这几类原因，按出现频率大致是：

| 原因 | 典型表现 |
| --- | --- |
| 电池耗尽 | 电池供电的传感器、门磁之类长时间没连过，电池彻底用光 |
| 距离远 / 有障碍物 | 设备离网关隔了几堵墙，信号衰减 |
| Wi-Fi 频段不兼容 | 路由器或热点只开了 5GHz，很多智能设备只认 2.4GHz |
| 应用或固件过旧 | 应用版本老、设备固件没更新 |
| 中继被挪动 | 某个充当信号中继的设备被断电或移走，连累别的设备掉线 |

## 二、官方的排障顺序

按下面顺序做，从软到硬，别一上来就拆设备：

1. **确认设备有电**。电池设备先充电或换电池；插电设备确认插头没松。
2. **缩短距离**。把离线的设备搬到离网关/路由器近的地方，中间不要有障碍物，再看状态是否恢复。
3. **重启应用并检查更新**。应用菜单 → 设置 → 关于 SmartThings，有更新就装，装完重启应用。
4. **给设备断电重启**。插电设备拔掉电源等 2 分钟再插回；电池设备取出电池等 30 秒再装回。
5. **重启路由器或网关**。多台设备同时离线时，这一步的命中率最高。
6. **还不行，删除后重新注册**（步骤见下一节）。

## 三、Wi-Fi 频段：最容易被忽略的一条

不少智能家电和传感器**只支持 2.4GHz 频段**。如果你的路由器或随身热点只开了 5GHz，设备要么连不上，要么频繁离线。处理办法：

- 进路由器管理页，把 2.4GHz 频段打开（多数路由器可以把两个频段并存）。
- 用运营商送的光猫/热点的话，可以直接让宽带运营商帮你改配置。
- 改完后把设备断电重上电，让它重新连 2.4GHz。

搜不到设备（而不是离线）时频段隔离也是常见原因，两边的排查在 [常见问题与解决办法.md](常见问题与解决办法.md) 第一节有对照。

## 四、中继设备的连带影响

如果你家设备多，部分插座类设备会自动充当信号中继，帮远处的设备转发信号。这意味着：

- 挪走或断电一台中继设备，可能让**原本不直接连网关的另一批设备**集体离线。
- 排查时先想一下最近有没有搬动过插座、灯泡这类设备，把它们放回原位再看。

## 五、删除后重新添加

排障全部无效，官方给的兜底方案就是把设备删掉重新注册一遍：

1. 打开 SmartThings，在设备或收藏页签里找到那台设备。
2. **长按设备**，点「移除设备」（部分版本是：点进设备 → 编辑 → 删除，或设备设置最底部的「解除绑定」——不同版本入口叫法略有差异，认「移除/删除/解绑」这类字样即可）。
3. 按第一次添加的流程重新注册：加号 → 设备 → 自动发现或按品牌，完整步骤见 [设备添加与配对方法.md](设备添加与配对方法.md)。
4. 重加完成后做个动作验证，比如用应用开关一次插座。

一个判断标准：如果设备重新注册后过几天又离线，问题多半在设备本身（固件或硬件）或它的摆放位置，而不是应用——先更新设备固件，再考虑挪位置。
