## 二、从哪里获取安装文件

三条路，按方便程度排：

1. **夸克网盘**：打开 [MeGrow 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c2411727c2e1)，转存后把里面的 apk 下载到手机就能装，版本即上表那份。
2. **官方渠道**：官网 [luxifakj.cn](http://luxifakj.cn/) 的 MeGrow 页面提供安卓安装包下载；vivo 等安卓应用商店搜「MeGrow」也能装（商店名显示为「MeGrow-日程计划打卡」）。
3. **iOS**：App Store 搜「MeGrow」，认准上述开发者。

不同渠道拿到的版本号可能不一样，功能上有细微差别属正常。

## 三、安卓安装步骤

1. 把 apk 文件下载到手机存储（网盘转存后下载，或浏览器下载）。
2. 在文件管理器里点开这个 apk，系统询问「是否允许安装未知应用」时，允许来源应用安装。
3. 等安装进度走完，点「打开」。
4. 第一次进入会有一段新手引导，跟着走完再开始建目标，别急着跳。

## 四、装之前把安装包核对一遍（MD5 校验）

如果你担心下载过程中文件损坏，可以在电脑上算一次 MD5，和上表的 `06ACD1793A7E509669CCD09D1C206EAA` 比对：

```powershell
certutil -hashfile "MeGrow_v1.3.2.apk" MD5
```

macOS / Linux 用：

```bash
md5sum MeGrow_v1.3.2.apk
```

算出的值一致就说明文件完整；不一致说明下载不完整或被改动过，重新下载即可。

## 五、装不上时按这几条排查

| 现象 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包出错」 | 文件是否完整 | 对 MD5，不一致就重下；重下还不行换一条下载途径 |
| 点安装没反应或闪退 | 存储空间 | 98.49M 的包安装后占用更大，留出 1G 以上余量再试 |
| 提示禁止安装 | 未知来源权限 | 在系统「安装未知应用」设置里，允许你用来打开 apk 的那个应用（文件管理器/浏览器）安装 |
| 装完打不开 | 安卓版本过低 | 换新一点系统的设备，或改用商店版试试 |
| 提示与已有应用冲突 | 同包名旧版本 | 先卸载旧版 MeGrow 再装 |
