## 一、这是个什么应用

MeGrow 是一款综合自律类应用，官方的定位是「拒绝内耗，做自律行动派」：你把想坚持的事、要办的事、要专注的时间都放进这一个应用里记。开发者是重庆路西法科技有限公司，官网 [luxifakj.cn](http://luxifakj.cn/)。免费下载使用，应用内有付费项目（以内购页面实际显示为准）；vivo 应用商店将其标注为「安全 无广告」（以商店页面为准）。

它还有个曾用名「菜菜计划」——搜资料、找账号时两个名字都试，改名经过见[菜菜计划改名与版本差异.md](菜菜计划改名与版本差异.md)。

它不强制你完成计划——官方自己的说法是「不会强制你必须完成这些计划」，断了就是断了，第二天接着来。

## 二、功能总览

| 功能 | 干什么用 | 什么时候你会用到 |
| --- | --- | --- |
| 习惯打卡 | 给目标定频率，每天到点打一次卡 | 想养成早睡、喝水、运动这类每日习惯 |
| 舒适计划 | 按你当前状态生成一份日常计划模板 | 不知道该定什么目标、想要现成方案时 |
| 待办清单 | 归纳生活、学习、家庭里的事 | 事情多而杂，怕漏 |
| 番茄专注 | 计时专注一段时间 | 学习、写东西时坐不住、爱摸手机 |
| 结伴自习 | 线上自习室，和大家一起学 | 一个人学不进去，想找个氛围 |
| 存钱记账 | 快速记一笔花销 | 想看钱花哪儿去了 |
| 纪念日 | 记重要的日子 | 生日、还款日这类怕忘的日期 |
| 睡眠记录 | 白噪音助眠，记录睡眠质量 | 想知道自己睡得怎么样 |
| 心情记录 | 用表情记每天的心情，可回顾 | 情绪起伏大，想留个轨迹 |
| 种菜（田园） | 打卡和专注的成果换成蔬果图鉴、升级田园 | 想给坚持这事加点看得见的反馈 |
| 签到盆栽 | 每日签到让小盆栽成长，往期肯定语也在这里翻 | 想要一个轻一点的每日仪式感 |
| 每日肯定语 | 一句肯定自己的话，配温馨画面 | 打卡顺手看一眼；想回顾往期的去签到盆栽 |
| 数据分析 | 看完成度、坚持天数 | 阶段性回顾自己做到什么程度 |

具体怎么把打卡和种菜这条线玩起来，单独写在[打卡计划与种菜玩法.md](打卡计划与种菜玩法.md)；番茄钟和自习室的用法写在[番茄专注与自习室.md](番茄专注与自习室.md)。

## 三、第一次打开按什么顺序设

1. **走完新手引导**，别跳——后面少摸索很多。
2. **建 1~2 个打卡目标**就够了，先挑你每天本来就在做的（比如喝水），别一上来建十个，三天后全断。
3. **挂一件明天要办的待办**，体会一下它和打卡的区别：打卡是重复的事，待办是一次的事。
4. **试一次 5~10 分钟的番茄钟**，看看计时过程中手机会怎么处理通知。
5. 想换界面观感，去设置里找皮肤/风格选项，有多种样式可选；功能模块本身也能按自己的习惯调整——官方版本记录里说过「选择你喜欢的功能就好」，把不用的模块收起来，首页会清爽很多（具体入口以你手上版本为准）。

权限方面：睡眠记录、步数/健康数据这类功能需要对应系统权限才出数，不给权限其余功能照常能用；你只打算打卡记心情的话，一样权限都不用给。

## 四、一天下来怎么配合用

一个常见的节奏供参考：早上扫一眼待办清单定当天重点；学习/工作时段用番茄钟；晚上回来把今天的打卡逐个点掉、记一条心情；睡前开睡眠记录。周中抽空去数据分析页看一眼完成度和坚持天数，决定下周目标是加还是减。

## 五、你手上这版和商店最新版的差别

本文按安装包 1.3.2 写，官方渠道在售版本更新更快，新版本可能调整了界面入口或加了新东西。按上面顺序找不到某个入口时，先在「我的/设置」里翻一圈，再对照[菜菜计划改名与版本差异.md](菜菜计划改名与版本差异.md)里的版本差异说明。
