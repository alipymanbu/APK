## 一、底部四个页面

| 页面 | 管什么 |
| --- | --- |
| 应用列表 | 手机上已装的全部应用，点任意一个进详情 |
| 统计 | 全机维度的汇总图表 |
| 快照 | 保存与对比应用信息的历史状态 |
| 设置 | 语言、主题、规则仓库、APK 分析等 |

应用列表支持按默认、按更新时间、按 Target API 排序；列表项上直接能看到架构标签，怎么看标签见 [怎么看应用是32位还是64位.md](怎么看应用是32位还是64位.md)。

还没安装的话，先从 [LibChecker 安装文件资源（夸克网盘）](https://pan.quark.cn/s/83661a3a849c)获取安装文件，装好再往下看。

## 二、应用详情页：标签从上往下看

点开任意应用后，详情页按标签分组，常见的有：

- **原生库**：应用里每个 `.so` 文件及其架构，知名库会带标记。
- **服务 / 活动 / 广播接收器 / 内容提供器**：应用注册的四大组件，逐条列出。
- **权限 / 元数据 / 签名 / 安装来源**：包信息类条目。

带「标签」的条目（比如某个 SDK 的名字）点开能看到简介与参考链接。这些标记来自官方维护的规则仓库，识别不到的条目就不带标签。

「进一步操作」菜单里还有跳转应用商店、打开文件管理器之类的入口，具体项随版本有差异。

## 三、统计页能看什么

统计页把你手机上的应用汇总成图表：应用的架构（ABI）分布、Android 版本分布、库引用排行。库引用排行能看到哪些第三方库在你手机上的应用里出现得最多，可按引用次数排序，适合看某个 SDK 的覆盖面。

## 四、规则仓库与云端规则

知名库标记依赖官方维护的规则库（LibChecker-Rules），覆盖面不止 SDK 名字：原生库、四大组件、权限、元数据、包名、共享 UID、签名、Intent Action 都在规则范围内。设置里有「云端规则」相关的开关：

- 开着：规则库更新更及时，新出现的 SDK 能更快被识别。
- 关掉：基础查看功能不受影响，只是新的知名库标记可能识别不到。

详情页里还有一类「16 KB」对齐标签，含义单开了一篇：[16KB对齐标签是什么意思.md](16KB对齐标签是什么意思.md)。

## 五、分析安装包文件（APK / APKS）

不装进手机也能看：设置里提供 APK 分析入口，选中本地的 APK 文件就能出同样的详情页；Split APKs（`.apks` 之类的分包安装包）同样支持。入口的具体位置随版本略有不同，找不到就在设置页里找带「APK」字样的项。

## 六、浏览器版 WebUI

官方还有配套网页 [lc.absinthe.life](https://lc.absinthe.life/)：把安装包放进页面在浏览器里分析，分析与对比都在本地完成，手机、电脑都能打开。这是较新版本配套的功能，你手上这版能否导出对应文件、以实际菜单为准。
