## 一、官方下载渠道

LibChecker 按 Apache License 2.0 开源，官方在以下渠道发布，任选其一即可：

| 渠道 | 入口 | 特点 |
| --- | --- | --- |
| Google Play | [打开商店页](https://play.google.com/store/apps/details?id=com.absinthe.libchecker) | 商店渠道，随商店自动更新 |
| F-Droid | [打开 F-Droid 页面](https://f-droid.org/packages/com.absinthe.libchecker/) | 由 F-Droid 构建并签名 |
| GitHub 发布页 | [打开 Releases](https://github.com/LibChecker/LibChecker/releases) | 直接下 APK，同一版本提供 foss 与 market 两种包 |
| IzzyOnDroid 仓库 | [打开仓库页](https://apt.izzysoft.de/fdroid/index/apk/com.absinthe.libchecker) | 第三方 F-Droid 仓库，官方 README 列出的下载渠道之一 |

同一版本会有 `foss-release` 与 `market-release` 两种 APK：foss 版不带商店统计组件，market 版对应 Google Play 渠道。两者还有一点检测能力上的差异——官方曾在 FOSS 渠道移除个别检测项。日常使用没有操作上的差别，介意内置统计的选 foss 版即可。

如果你所在网络访问上述渠道不便，可以改走 [LibChecker 安装文件资源（夸克网盘）](https://pan.quark.cn/s/83661a3a849c)，转存到自己的网盘后下载安装。

## 二、安装步骤

1. 从任一渠道拿到 APK 文件，安装包只有几 MB。
2. 在文件管理器里点开 APK；系统提示「未知来源应用」时，按提示允许对应的文件管理器或浏览器安装应用。
3. 等安装完成，点「打开」。
4. 首次启动建议先到「设置」里把语言切换成熟悉的语种，它内置了多语言界面。

覆盖升级：直接安装新版即可，设置与数据会保留。用商店渠道装的走商店更新，F-Droid 客户端装的走客户端更新，手动装的重新下载新版覆盖安装。

## 三、装之前核对一下版本

网盘资源里这一版的本地信息如下，它和官方最新版不一定是同一个版本：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.5.1.dev.4109a56d |
| 包名 | com.absinthe.libchecker |
| 安装包大小 | 4.24M |
| MD5 | F63D61C91B7C3B50208DD671015A3D59 |

版本号里的 `dev` 表示这是 2.5.1 系列的开发快照构建。包名与官方发布一致，可以直接覆盖安装到官方渠道装的那份上面（同包名升级）。官方正式版迭代较快，最新版本号与功能以 [官方发布页](https://github.com/LibChecker/LibChecker/releases) 为准。

## 四、系统要求

- 官方当前版本要求 Android 7.0 及以上，README 标注适配到 Android 17；Android 6 设备官方另维护了 marshmallow 分支。
- 以上为官方最新口径，旧版本对系统的要求以官方文档当时标注为准。
- 不需要 root，普通权限即可使用；个别进阶信息可搭配 Shizuku 获取，见 [常见问题解答.md](常见问题解答.md)。
