## 一、先核对你要装的是哪个包

NMTV 是一款安卓影视点播类应用，按其介绍聚合电影、电视剧、综艺、动漫等内容，提供 360P 到 1080P 的画质选择。它不走应用商店分发，而是以 APK 安装包的形式流通，所以安装方式与普通应用略有不同。动手之前，先对照下表确认手里的安装包：

| 项目 | 值 |
| --- | --- |
| 应用名 | NMTV |
| 版本 | 1.1.3 |
| 包名 | nm.tv |
| 安装包大小 | 63.40 MB |
| MD5 | 49432A99EE6491471F1E9631274151D6 |
| 系统要求 | 安卓 5.2 及以上（按安装包标注） |
| 语言 | 中文 |
| 授权方式 | 免费 |

其中版本号、包名、大小这几项，网上各下载站列的数字可能对不上（原因见[版本区别与更新方式.md](版本区别与更新方式.md)），以你实际拿到的安装包为准。

## 二、从夸克网盘拿到安装包

安装包放在夸克网盘里，按下面的步骤取：

1. 打开 [NMTV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4a742376cb30)，进入分享页；
2. 勾选里面的 APK 文件，点「转存」存到自己的网盘，再从自己网盘里下载（转存后文件在你自己账户下，不怕原分享失效）；
3. 在手机上打开夸克 App，进入转存的目录，点 APK 开始下载；
4. 下载完成后，夸克会弹出安装提示。

手机上没装夸克 App 也能用浏览器打开链接直接下载，但大文件走 App 转存后下载更稳，不容易中途断掉。下载完可以顺手核对一下文件大小是否为 63.40 MB，对不上就重新下一次。

## 三、安装步骤

1. 点下载完成的 APK，系统会提示「禁止安装未知来源应用」，这是安卓对商店外安装包的默认拦截；
2. 进入「设置 → 应用管理 →（刚才用来下载的应用，如夸克或浏览器）→ 安装未知应用」，把允许安装的开关打开。不同品牌手机菜单位置不同，一般在「安全」或「更多设置」里；
3. 返回下载目录，重新点 APK，完成安装；
4. 装完建议把「安装未知应用」权限关回去，避免以后误装来路不明的包。

如果安装时提示失败、被拦截或「解析包出错」，按 [安装失败排查与解决办法.md](安装失败排查与解决办法.md) 的原因对照表逐条处理。

## 四、装完第一次打开

- 首次启动如果弹出存储、网络等权限请求，按需允许即可；不确定的可以先拒绝，之后在系统「应用信息 → 权限」里单独开启；
- 内容列表需要联网加载，第一次打开时网络不好会白屏或转圈，属于加载问题而不是安装失败；
- 进首页后如果播放卡顿或画质不合适，看[播放画质与缓存设置.md](播放画质与缓存设置.md)怎么调。
