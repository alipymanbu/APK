# Feem 传输失败与找不到设备的排查

Feem 的问题绝大多数出在「连接」而不是「传输」上：设备列表空着、或者传着传着断掉。先照第一节的清单过一遍，能解决大半。

## 一、先过一遍基本检查

按顺序核对，每条都别跳：

1. 两端是否连着**同一个 Wi-Fi**？（手机连了流量、电脑连 Wi-Fi，是最常见的乌龙）
2. 两端的 Feem 是否都**开着并停在设备列表**界面？
3. 安卓端的**定位权限**是否允许了？（不给权限，扫描不到附近设备）
4. 把两端的 Wi-Fi 关掉重连一次，或把 Feem 完全退出再打开；
5. 还不行就把两端都重启一次，局域网里的陈旧连接状态经常靠重启清掉。

## 二、设备列表里看不到对方

基本检查过了还不行，通常是这两类原因：

- **不在同一个子网**。双频路由器把 2.4G 和 5G 分成两个名字时，一般不影响互访；但访客网络（Guest Network）默认把设备互相隔离，连访客网络的设备发现不了主网络的设备。把两端都挪到同一个主网络里再试；
- **路由器开了 AP 隔离（无线隔离）**。部分路由器、尤其公司网络和酒店网络会开启这个选项，禁止无线设备之间直接互访——这正好掐断了 Feem 的工作前提。家用路由器进管理后台（一般是 `192.168.1.1` 或 `192.168.0.1`，以路由器背面标签为准）找到「AP 隔离 / 无线隔离 / 访客网络隔离」关掉；公司网络你动不了设置，换手机热点最直接。

某个环境里始终发现不了对方时，别反复重试，直接开热点绕过它（见 [没有路由器也能用的连接方法.md](没有路由器也能用的连接方法.md)），传输本身不受影响。

电脑端还有一个专属嫌疑：**Windows 防火墙拦了局域网通信**。首次运行 Feem 时弹出的「是否允许访问网络」框如果点了取消，电脑就收不到局域网里的发现请求——到 Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙，把 Feem 勾上（专用网络一栏）。

## 三、传输中断或失败

- **手机切后台 / 锁屏导致中断**：Feem 在移动端需要停留在前台，切走后系统可能冻结它。重发即可，传输期间留在当前界面；
- **中断后不必从头传**：重新发起同一文件的传输，接着断点继续，不用删了重传；
- **一端在充电口旁、信号满格却频繁断**：试试把设备靠近路由器，弱信号下大文件传不完是常态；
- 反复失败时，先用一张小照片试传：小文件能过、大文件不行，就是信号或休眠问题；小文件也不行，回到第二节查连接。

## 四、速度比预期慢

Feem 的速度上限由你的 Wi-Fi 环境决定，可以按这两条改善：

- 连到路由器的 **5 GHz 频段**（名字里带 5G 的那个），比 2.4G 快得多；
- 传输时别让两端同时干别的重活（比如电脑在下载、手机在云端备份），它们抢的是同一条无线带宽。
