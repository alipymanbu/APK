## 一、先决定用哪套界面

菜单里有一项 **「UI 模式的切换」**，在两套界面之间来回切：

| 界面 | 适合的屏幕 | 特点 |
| --- | --- | --- |
| 标准 UI | 6~7 英寸及以上的平板 | 左侧一列工具栏 + 两侧面板，默认全部面板展开 |
| 手机用 UI | 屏幕较小的手机 | 按钮收到屏幕底部一排，面板改成弹出式 |

官方手册的原话是：标准界面按 6~7 英寸以上设备设计，画面较小的设备建议改用手机用界面。刚装好觉得按钮挤成一团、点不准，多半是界面没切 —— 这是你随时能改的设置，不影响作品。

## 二、标准 UI 的分区

从上到下、从左到右认这几块：

- **工具栏（竖排在左侧）**：最上面两个是开关，下面八个是工具。点图标即切换当前工具，你此刻选了哪个工具，决定了手指触到画布时发生什么。
  1. 颜色面板开闭
  2. 选项面板 / 图层面板开闭
  3. 笔刷工具
  4. 橡皮工具
  5. 移动工具（拖动当前图层）
  6. 矩形填充工具（拖出的范围填前景色）
  7. 油漆桶工具
  8. 渐变工具
  9. 选择工具（矩形 / 套索）
  10. 自动选择工具（点哪里选中哪块封闭区域）
- **颜色面板**：取前景色、背景色、透明色，还能把常用色存进调色板 —— 各区域怎么点见 [笔刷与压感设置.md](笔刷与压感设置.md)。
- **选项面板**：当前工具的参数。选笔刷时显示笔刷列表、直径、不透明度。
- **图层面板**：图层的增删、混合模式、剪贴、锁定 —— 见 [图层混合模式与选区.md](图层混合模式与选区.md)。
- **中间的画布区**：棋盘格背景代表这块是透明的，白色代表不透明底色。背景显示成透明还是白，在菜单里切换。

面板全开会把画布挤得很小：颜色面板用工具栏最上面的按钮关，选项 / 图层面板用上数第二个按钮关，关掉后中间的作画区会宽出一大截。

## 三、手机用 UI 的底部一排

切到手机用界面后，屏幕底部从左到右是七个按钮：

| 按钮 | 作用 |
| --- | --- |
| color | 开闭颜色面板 |
| undo | 撤销上一步 |
| redo | 重做 |
| flip | 画面左右翻转（只翻显示，不改图像数据） |
| layer | 开闭图层面板 |
| option | 开闭工具选项面板 |
| brush | 开闭工具 / 笔刷列表 |

顶部那条是状态栏：左边的菜单按钮进出主菜单，中间显示当前缩放比例、画布尺寸（`宽 * 高` 形式）与翻转状态，右侧是当前画布的操作入口（中文界面下能看到「清理图层」这样的按钮）。

## 四、画布手势（最该先练的两个）

- **两指拖动**：平移画布显示。
- **两指捏合 / 张开**：放大缩小显示。

这两步只改变「看起来的远近」，**不会**改变图像本身的像素尺寸 —— 想导出高分辨率图，靠的是建画布时把宽高设大，不是靠放大后再保存。

另外两个手指快捷操作（1.12.8 起加入）：**两指轻点 = 撤销，三指轻点 = 重做**，不用去点底部按钮。

## 五、浮动栏：显示与取色的常用操作

画布附近会浮着一条可拖动的工具条，各键作用：

- **撤销 / 重做**：回到上一步、恢复下一步；做不了时图标变灰。
- **100%**：按 1:1 显示；**适应屏幕**：整张画布收进当前画面。
- **左右翻转**：只把显示镜像，图像数据不动 —— 画脸时用来检查画歪没。
- **旋转模式**：进旋转状态后拖动画布转角度，可确认或归零。
- **吸管取色**：按住吸管图标不放，拖到画布上目标颜色处再松手，那个颜色就变成前景色。

## 六、新建画布时的两个决定

菜单里新建画布，你要填宽、高，并选背景：

- **尺寸**：数值旁的纸张按钮可以选常见预设。官方手册的建议是从 `2000 × 2000` 像素起步 —— 画布开得过大，应用的稳定性会下降（表现为卡顿甚至闪退）。
- **背景**：选透明时画布显示为棋盘格，导出带透明底的图（贴纸、头像框素材）必须用它；选白则底色为纯白。
