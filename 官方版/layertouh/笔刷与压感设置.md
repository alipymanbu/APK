## 一、选项面板：选中笔刷后你能调的东西

工具栏选中笔刷工具、打开选项面板后，从上到下是这些：

| 区域 | 作用 |
| --- | --- |
| 直径滑杆 | 拖动改笔刷粗细，单位是像素 |
| 不透明度滑杆 | 拖动改浓淡；**默认不显示**，要在设置里打开才出现 |
| 笔刷列表 | 点列表里某一项即选中它，高亮那行就是当前笔刷 |
| 详情按钮 | 进入当前笔刷的详细参数 |
| 添加 / 删除 | 新增一支笔刷、删掉当前笔刷 |
| 上移 / 下移 | 调整笔刷在列表里的顺序 |

改完参数立刻能在画布上试，不满意用两指轻点撤销。

## 二、七种笔刷类型

点添加按钮后可选的笔刷类型（括号内是中文界面下的常见叫法）：

| 类型 | 特点 |
| --- | --- |
| 钢笔（pen） | 边缘硬，画线稿的主力 |
| 喷枪（airbrush） | 边缘软，做过渡 |
| 水彩（watercolor） | 颜色之间会互相混开 |
| 手指（finger） | 把已有的颜色拖开、抹匀 |
| 位图（bitmap） | 用素材图案当笔头 |
| 散布（scatter） | 素材颗粒状撒开 |
| 散布水彩 | 颗粒之间还会互相混色 |

列表里预置的笔刷在中文界面下显示为「钢笔」「钢笔（出入锋）」「铅笔」「喷枪」这类名字，直接点选就能用；想要起笔收笔带粗细变化的线条，选名字里带「出入锋」的那支。

散布类笔刷另有两条官方更新记录：1.12.12 改进了散布笔刷、滚轮笔刷的绘制质量，1.12.13 修复了散布笔刷的问题 —— 网盘这份 1.12.15 都已包含；换用明显更旧的包时遇到散布笔刷画出来不对，先怀疑版本。

## 三、颜色：前景色、背景色、透明色

打开颜色面板，你会用到三种「笔的颜色」：

- **前景色**：笔刷、矩形、油漆桶用的就是它。拖色相环定大方向，再在渐变条里点具体色。
- **背景色**：主要给渐变工具当另一端的颜色用。
- **透明色**：选中它之后，笔刷画过的地方会被擦成透明，等于「用当前笔刷形状的橡皮」—— 笔头是什么形状，擦出来就是什么形状。

面板里还有前景 / 背景色互换按钮，以及把颜色存进调色板、删除调色板的按钮，常用色存进去比每次重调快。

## 四、防手抖与抗锯齿

笔刷浮动选项里有两个开关直接影响线条质量：

- **防手抖（手振れ補正）**：`OFF` 到 `5` 共六档，`5` 最强。手指画线发抖、想画干净线稿时往上调；调太高笔尖会明显「跟不上手」，画短线反而别扭。
- **抗锯齿**：开则线条边缘平滑，关则边缘硬。像素画、要精确对齐格子时关掉。

## 五、Snap 辅助线：把线画直

Snap 是「临时进入只能画某类线」的模式，画平行线、放射线时不用手稳：

1. 点浮动选项里的**设置按钮**，在画布上拖一下定方向（平行线）或定中心（放射线）。
2. 这之后笔刷只会沿该方向的线走。
3. 画完在下拉里选 **OFF** 退出。

可选的 Snap：**平行线**（可调角度）、**垂直 / 水平**、**放射线**、**消失点**（消失点在画面外的集中线，需要拖两次定两条方向线，两线交点即中心）。

## 六、压感与数位笔

官方功能清单写明：**笔压支持需要在设置里启用** —— 没开的话，S Pen、触控笔画出来全是同一粗细。所以：

1. 进应用的设置项，找到笔压相关开关打开。
2. 系统侧同时确认没把该应用的触控笔输入禁用。
3. 画一笔试轻重：轻画细、重画粗才算生效；不生效的排查见 [常见问题与解决方法.md](常见问题与解决方法.md)。

官方功能清单里还列有 **Wacom 数位板支持**，接板子画是它明确支持的用法。

## 七、笔刷商店

菜单里有笔刷商店，可以下载新笔刷（官方说明是每周更新）。两点实情：

- 官方 2023 年停止开发时明确表态：**应用不再更新，但笔刷商店会继续运营**。
- 曾有「Android 12 上笔刷商店不显示」的故障，官方在 1.12.8 版修复。你手上的版本若低于它且商店打不开，先确认版本号（见 [下载与安装教程.md](下载与安装教程.md) 的核对表）。

## 八、外接键盘快捷键

接键盘时可以直接敲快捷键（官方注明**不支持自定义**）：

| 按键 | 功能 |
| --- | --- |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` 或 `Ctrl+Shift+Z` | 重做 |
| `B` | 笔刷工具 |
| `E` | 橡皮工具 |
| `D` | 恢复默认色 |
| `X` | 前景色与背景色互换 |
| `↓` | 画面左右翻转 |
