## 一、图层面板按钮逐个认

| 按钮 | 作用 |
| --- | --- |
| 不透明度滑杆 | 拖动调当前图层的透明程度 |
| 模式下拉 | 选当前图层与下方图层的合成方式（见第三节） |
| clipping | 把当前图层剪贴到它下面那一层 |
| 锁定 | 官方功能清单里对应 `Lock Alpha`（锁定透明区域）；日文手册的表述是「锁定当前图层的不透明度」—— 两处说法并列在此，具体以你实测的效果为准 |
| 缩略图 | 显示该层内容；有多层时点它即切换「当前图层」 |
| 显隐开关 | 关掉后该层不参与显示，但内容还在 |
| `+` / `−` | 新增图层（加在当前层上方）/ 删除当前层 |
| 上移 / 下移 | 调整图层顺序 |

**当前图层只有一个**：你画的每一笔都落在它身上，改之前先看缩略图确认自己在哪一层。

## 二、图层是怎么叠出来的

图层像一叠透明纸，**从下往上依次合成**：下层先画进画面，上层后画，所以上层的内容会盖住下层。

这个顺序决定了分层的意义 —— 举个实际例子：

1. 上层画黑色线稿。
2. 下层随便涂红色，怎么涂都在线稿**下面**，不会盖住线。
3. 想把红改成蓝：只清掉下层重涂即可，线稿层完全不用碰。

如果线稿和颜色在同一层，改色就得小心翼翼绕开线，费时还容易擦坏。所以常见分法是：线稿一层、上色一层、特效再一层。

## 三、混合模式清单

官方功能清单列出的模式（括号是常见中文叫法，界面译名以实际显示为准）：

| 官方写法 | 常见中文叫法 |
| --- | --- |
| Normal | 正常 |
| Add / Emit | 相加 / 发光 |
| Multiply | 正片叠底 |
| Overlay | 叠加 |
| Screen | 滤色 |
| Lighten | 变亮 |
| Darken | 变暗 |
| Difference | 差值 |
| Dodge | 减淡 |
| Burn | 加深 |
| Soft Light | 柔光 |
| Hard Light | 强光 |
| Hue | 色相 |
| Color | 颜色 |
| Saturation | 饱和度 |
| Luminosity | 明度 |

用法上最常动的两个：上阴影层选 **Multiply**，画发光 / 高光层选 **Add（发光）**。选中模式后改的是「当前层与它下面那层」的关系，把模式层挪到别的位置，效果会跟着变。

## 四、剪贴与锁定透明

- **clipping（剪贴）**：把当前层裁进它下面那一层的形状范围内 —— 下层先画好一块颜色，上层开剪贴后再怎么涂，都只会显示在下层那块颜色的范围内，不会溢出去。
- **锁定透明**：在当前层上画时，只有已有内容的区域能着色，空白处画不上，适合在不改变形状的前提下改色、加渐变。

另外，官方功能清单还列有一项**水彩边缘效果（Watercolor Edge Effect，图层效果）**，给图层加上类似水彩颜料积边的边缘，入口在图层效果相关的设置里（不同版本位置以实际界面为准）。

## 五、选区工具：矩形、套索与变形

选中选择工具后，浮动选项里提供：

- **矩形选区 / 套索选区**：拖出要处理的范围。
- **清除选区**：取消当前蚂蚁线。
- **剪切 / 复制**：把选区内容存进应用内的剪贴板。
- **粘贴**：把剪贴板内容贴回画布。
- **TRANSFORM（变换）**：拖角点缩放，按住角点**内侧**拖动是移动、拖到**外侧**是旋转。
- **FREE TRANSFORM（自由变换）**：四个角各拖各的做透视类变形，同样内侧移动、外侧旋转。

选区存在时的显示：选区边界是流动的蚂蚁线，选区外盖一层淡蓝 —— 看到淡蓝就说明「现在画什么都不会出这个圈」。

## 六、油漆桶与渐变的行为

- **油漆桶**：点封闭区域一次填满。浮动选项里的**扩展**可以填色后向外多扩 `0 / 1 / 2` 像素 —— 线稿边缘总留一圈白边时，开 `1` 或 `2` 就能压进去。旁边还有抗锯齿开关。官方手册特别提醒：**油漆桶最好用在线稿下方的独立图层上**，别直接对着线稿层点。
- **渐变**：默认对整层生效；**先建了选区，就只在选区内拉**。两种模式：前景色半透明渐变，或前景色到背景色的不透明渐变，在浮动选项里切。
- **自动选择**：点一下自动选中那块封闭区域，等于「选区版的油漆桶」。

先想清楚要填哪一层，再点 —— 填错层用两指轻点撤销即可，步骤见 [界面布局与手势操作.md](界面布局与手势操作.md)。

## 七、分层习惯与文件的关系

图层信息会一起存进作品文件：保存成 MDP 格式才会把图层、画布信息全留住，导出 PSD 则是为了拿到别的软件里继续用 —— 两条路的区别在 [保存与导出PSD教程.md](保存与导出PSD教程.md)。
