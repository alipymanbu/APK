## 一、字幕支持哪些语言

Viu 的内容来自十几个市场，字幕不是全站统一一套，而是按剧集和你的所在市场给。常见的字幕语言：

| 语言 | 说明 |
| --- | --- |
| 英语 | 几乎所有内容都配，最稳的选择 |
| 中文（简/繁） | 华语剧原配，部分韩剧、泰剧也有 |
| 印尼语 / 马来语 | 东南亚市场主配 |
| 泰语 | 泰语市场 |
| 菲律宾语 | 菲律宾市场部分内容 |
| 阿拉伯语 | 中东市场主配，热门剧还有阿语配音 |

同一条字幕「有没有」取决于版权方给到了哪些语言，同一部剧在不同市场可切的语言可能不同。

## 二、在播放页怎么切

1. 点剧集封面进入全屏播放；
2. 点一下屏幕唤出控制条，找字幕按钮（通常在右上角，形如 CC 或对话框图标）；
3. 在弹出的列表里选字幕语言，或选「关闭」；
4. 同一个面板里如果有「音频/配音」选项，还能切换配音音轨。

你上次选的字幕语言，App 一般会记住并应用到之后的剧集；换剧后发现字幕不对，多半是那部剧没配这门语言，重新进面板看一遍可选项即可。

## 三、切不出来时先查这三样

- **这部剧有没有**：字幕列表里压根没有的语言就是版权方没给，多等也没用；各市场主配语言见 [是什么软件.md](是什么软件.md) 的内容构成一节；
- **那一集上没上**：有的剧头几集先配好字幕，后面的集数陆续补齐；
- **地区对不对**：部分语言字幕只对特定市场开放，你在哪个市场就看到哪个市场的配置。

其他播放类问题（卡顿、黑屏、下载失败）不在本篇范围，见 [常见问题与播放故障排查.md](常见问题与播放故障排查.md)。
