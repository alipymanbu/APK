## 一、投屏的前提只有一个：手机和电视在同一个网络里

投屏走的是局域网，手机和电视必须连在**同一台路由器下的同一网段**，能做到这一条，后面基本就顺了。

容易踩的三种「看起来连了同一个 WiFi」：

- 手机连 5 GHz、电视连 2.4 GHz —— 同一台路由器时通常算同一网段，可以投；但如果路由器把两个频段拆成了不同网段，就会搜不到设备；
- 手机连的是**访客网络**，电视连主网络 —— 访客网络一般开了隔离，投屏一定失败；
- 电视走的是有线、手机走 WiFi —— 只要还在同一台路由器下就没问题，这点不用担心。

判断方法很直接：路由器上如果开着「AP 隔离」「访客网络隔离」这类开关，先关掉再试。

## 二、投屏步骤

1. 手机连上家里 WiFi，确认电视也在同一台路由器下（开机并连好网即可）。
2. 在 cilicili 里打开要看的番剧，进入播放页。
3. 点播放页**右上角的投屏按钮**。
4. 应用会自动搜索同一网络里的电视设备，在列表里选中你的电视，画面即转到电视上。
5. 播放过程中手机可以继续当遥控器用：换集、切画质、调进度都在手机上操作。

## 三、搜不到电视设备，按这个顺序排

| 排查项 | 具体做法 |
| --- | --- |
| 电视侧的投屏功能没开 | 智能电视要在设置里开启「投屏 / 多屏互动 / 无线显示」这类开关，不同品牌位置不同，一般在「网络」或「通用」菜单下；电视盒子同理 |
| 手机连错网络 | 确认不是访客网络、不是手机热点，热点下投屏一定找不到设备 |
| 路由器隔离 | 关掉 AP 隔离 / 访客网络隔离后，重启电视的投屏开关再搜一次 |
| 电视没网 | 电视必须联网，仅在待机状态下搜索不到 |
| 双方都在线但仍搜不到 | 把 cilicili 完全退出后重开再搜；仍有问题就走下面的备选方案，不必在这个入口上反复折腾 |

## 四、投出去了但很卡、或者突然断

- **先降画质**：投屏是把视频流推给电视，链路压力比手机本地播放更大。画质从超清降到高清或标清，多数卡顿会立刻缓解。
- **检查是否有人抢带宽**：同一路由器下有大文件下载、其他设备在看 4K 时，投屏最容易先被拖慢。
- **手机别切走太远**：投屏期间手机和电视保持在同一 WiFi 覆盖范围内更稳。
- **弹幕先关掉**：投屏时弹幕会一起上大屏，既影响观感，也额外增加一点渲染压力，客厅观看建议关闭。
- **缓存过的内容更稳**：提前缓存到本地再投屏，能把「片源线路不稳」这一层变量排除掉，做法见 [离线缓存无网观看.md](离线缓存无网观看.md)。

## 五、投屏按钮点了没反应时的备选方案

投屏入口依赖电视支持的协议（常见的是 DLNA / 无线显示）。电视不支持、或者路由器环境不允许时，不用卡在应用里，换下面的办法：

1. **系统级无线投屏**：安卓系统自带「无线投屏 / 投射屏幕」功能（路径多在 设置 → 连接与共享 里），把整个手机画面镜像到电视。缺点是大屏上是竖屏画面，且手机亮屏耗电。
2. **电视/盒子自带的应用**：电视上装了同一类客户端时，直接在电视端打开观看，手机只负责找片。
3. **有线连接**：电视有 HDMI 接口时，用 Type-C 转 HDMI 线连手机，画质和延迟都优于无线，适合固定位置看。
4. **不要为了「投屏更流畅」去装来路不明的加速器或修改版**。投屏失败基本是网络环境问题，不是应用能力问题，装第三方工具解决不了，反而多一层风险。

## 六、和画质有关的两点期待管理

- 投屏到大屏后，画质上限由**片源本身**决定，应用里把选项拉到「超清」并不会让 720P 的片源变清楚。
- 手机上流畅不代表大屏流畅：电视的芯片解码能力、HDMI 线的规格都会成为新的瓶颈，老电视投高清卡、投标清正常，是设备侧的正常现象。
