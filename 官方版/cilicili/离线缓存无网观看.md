## 一、缓存的是什么，和投屏是两回事

离线缓存是从片源把某一集下载到手机本地；下载完成后，播放不再依赖网络，所以地铁、飞机上用得上。它和投屏是两条互不依赖的路线：投屏要求手机和电视同时在同一个局域网里，缓存则完全不需要电视参与。

缓存的存在形式是手机存储里的一批文件，**卸载应用或被「清除数据」时会被一起删除**，这一点在清理手机空间时要留意。

## 二、缓存的步骤

1. 打开要缓存的作品，进入**剧集详情页或播放页**；
2. 点**下载**图标，进入选集界面；
3. 勾选要缓存的集数。选集支持一次多选，部分版本可以按住选集拖动快速圈定范围；
4. 确认后开始缓存，进度在**下载管理**里能看。

几个实操建议：

- **在 WiFi 下缓存**。一集高清剧集的体积按清晰度和时长浮动，流量下缓存很容易超量；
- **先用一集试水**。不同清晰度的体积差别不小，先下一集看清占多少空间，再决定整季要不要下；
- **别边看边下整季**。缓存和在线播放会同时抢带宽，容易出现「播放卡 + 缓存慢」两头不讨好，想离线看就先让它安静地下完。

## 三、下载管理：看进度、删缓存

入口在【我的】下的**下载管理**，这里能看到已缓存和缓存中的列表：

| 操作 | 说明 |
| --- | --- |
| 查看进度 | 下载中/已完成状态、已占用体积 |
| 删除单集 | 看完就删，是控制占用体积最有效的做法 |
| 清理整部 | 整季看完后一次删掉，比逐集删省事 |
| 检查失败项 | 卡在「等待中」「失败」的条目，参考下一节处理 |

存储占用会随着追的番数量累加。手机空间紧张时，按「追完的整季 → 看完的单集」的优先级清理，比随手清应用缓存安全——后者容易连带清掉还没看完的内容。

顺带回答一个高频疑问：**「下载管理」是唯一能对上「哪一集占多少空间」的地方**，缓存文件本身存在应用的专属目录里，新系统上文件管理器基本看不到、也拷不出来，详见 [缓存的视频存在手机哪里.md](缓存的视频存在手机哪里.md)。

## 四、缓存失败或总是「等待中」

| 现象 | 原因与处理 |
| --- | --- |
| 立刻提示失败 | 当前该作品的播放源不可用，先在播放页切换播放源，再回来重新缓存 |
| 一直排队等待 | 同时排队的集数太多，减少批次，一次先下 3~5 集 |
| 下到一半停住 | 网络切换过（WiFi 与流量互切）。保持网络不变重新下载该集 |
| 提示空间不足 | 清理手机存储后重试，缓存前留出安装包体积之外的富余空间 |
| 新出的集数下不了 | 新集刚上线时源尚未就绪，隔一段时间再试，或先换源再缓存 |

如果同一部作品的所有集都下不动，但它在线上能正常播放，说明是缓存通道的临时问题，不必删应用处理；换一集或换个时间再试通常就恢复了。

## 五、没网的时候，什么能用什么不能用

- **能用**：已缓存完成的剧集播放、进度记录、播放列表浏览。
- **不能用**：搜索、未缓存作品的播放、弹幕、更新提醒推送。其中弹幕是实时服务，离线状态下不会出现；重新联网后，该集已缓存的内容依然可看。
- **容易误判的一点**：`cilicili` 打开时会尝试连接（栏目、推荐等），完全断网时首页可能停在空白或加载状态，**这不代表缓存失效**。直接从【我的】→ 下载管理进入已缓存列表，照样能播。

## 六、什么时候不建议靠缓存

- **只看一遍就过去的作品**：缓存一次占用空间几百 MB 起，看完即删才划算；
- **还没确定要追的番**：先用在线播放试两集，确定要追再整季缓存；
- **经常换手机的人**：缓存在本机，不会跟着账号同步，换机后要重新缓存。账号能带走的是收藏与观看进度，不是离线文件。
