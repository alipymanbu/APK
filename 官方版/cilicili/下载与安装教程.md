## 一、开始之前，先认清你要装的是哪一份

`cilicili` 这个名字在各类下载页里被反复使用，网上能搜到好几个包名不同、体积不同的安装包，它们互相之间并不是同一个应用。装错版本最直接的后果是：旧数据读不出来，或者手机上出现两个图标。

本篇说的这份，是下面这一版。核对包名和体积，就能确认你手里的是不是同一份：

| 项目 | 值 |
| --- | --- |
| 应用名称 | cilicili |
| 版本号 | 3.49.04 |
| 包名 | `com.denim.figurative.glower` |
| 安装包体积 | 26.10 MB |
| MD5 | `3133FAB3D12BD418FEFF1D77164BD5A7` |
| 适配系统 | 安装包标注为 Android 5.2 及以上 |

体积对不上基本就是换了版本或下载被截断。MD5 是整包的指纹，想更严格一点就自己算一遍比对：把安装包放到电脑上，在它所在目录打开终端执行

```text
certutil -hashfile cilicili.apk MD5
```

算出来的 32 位十六进制串要和上表一致。手机上也有带校验功能的文件管理器，操作类似。

## 二、安装步骤（安卓手机）

1. **把安装包存到手机**。用 [cilicili 安装文件资源（夸克网盘）](https://pan.quark.cn/s/153861006662) 转存并下载后，安装包通常在夸克的下载目录里；如果你想用系统文件管理器安装，先把它移动到 `Download` 或任意你能找到的目录，再点击安装。
2. **允许「安装未知来源应用」**。这个开关不在设置的一级菜单里，一般路径是：设置 → 应用管理 → 找到你用来点击安装包的那个应用（文件管理器 / 夸克 / 浏览器）→ 安装未知应用 → 允许。不同品牌的叫法略有差别，华为叫「外部来源应用下载」，小米叫「安装未知应用」，OPPO、vivo 在「应用管理 → 特殊应用权限」下。
3. **点击安装包完成安装**。系统会先解析安装包再写入，体积小、步骤少，一般十秒内结束。
4. **首次打开**。安装完成后图标就出现在桌面，直接点开即可。这一版打开即用，不注册也能浏览和播放；需要收藏和更新提醒时再考虑登录。

## 三、装不上时的提示与对应处理

安装失败的提示文案各厂商不一样，但原因就那么几类，按提示对号入座：

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 解析包时出现问题 / 安装包损坏 | 下载没下完，或网盘取回时被截断 | 重新取一次，装前按第一节核对体积与 MD5 |
| 应用未安装 | 已装过同名但签名不同的版本，系统拒绝覆盖 | 先在设置里卸载旧版，再装这一份 |
| 应用签名不一致 | 同上，两个安装包来自不同构建 | 卸载旧版；卸载前留意本地缓存会一起删除 |
| 存储空间不足 | 手机剩余空间小于安装包体积的 2~3 倍 | 清理后重试，安装和解压都需要临时空间 |
| 系统版本过低 | 系统低于安装包标注的 Android 5.2 | 换用支持低系统版本的设备，或找匹配的旧版本 |
| 安装被安全中心拦截 | 系统把「未知来源」当成风险行为 | 在拦截弹窗里选择「继续安装」，或临时关闭安全扫描 |

有一点要提前知道：网上部分下载页把系统要求写成 Android 4.0 或 4.3 以上，与安装包标注的 5.2 不一致。这种口径冲突通常是因为同名应用有多个构建版本，**以你实际安装时的提示为准**，装不上就是装不上，改成低版本反而容易遇到播放异常。

另外，如果你手机里已经装过另一个包名的 cilicili，这一份会**并排装上**，桌面出现两个图标，而不是覆盖更新。这是包名不同导致的正常现象，不是安装出错；决定留哪个之后，把另一个卸掉即可。

## 四、装好之后建议先做的三件事

1. **给通知权限**。收藏的番剧更新提醒依赖通知，首次打开时如果顺手点了拒绝，可以到 设置 → 应用管理 → cilicili → 通知 里补上。
2. **确认缓存目录**。离线缓存会占用手机存储，缓存体积随集数与清晰度上涨，起步留出 1~2 GB 比较稳妥。缓存位置与清理方式见 [离线缓存无网观看.md](离线缓存无网观看.md)；这些文件存在应用专属目录里，卸载或「清除数据」会被系统一并删除，具体路径见 [缓存的视频存在手机哪里.md](缓存的视频存在手机哪里.md)。
3. **试一次投屏**。手机上能看到画面不代表投屏能连上，电视侧的投屏开关、路由器设置都会影响结果，提前试一次，省得追番到一半才发现投不出去。具体步骤见 [投屏到电视怎么看.md](投屏到电视怎么看.md)。

## 五、更新与卸载

- **更新**：新版本仍然是同一个包名 `com.denim.figurative.glower` 时，直接安装即可覆盖，观看记录与缓存一般会保留；包名变了就是另一个应用，装完等于从零开始。
- **卸载**：设置 → 应用管理 → cilicili → 卸载。这一步会**连同离线缓存一起删除**，如果缓存里有没看完的剧集，先看完或备份再卸。
- **重装**：卸载重装能解决一部分「页面显示不全、栏目加载不出来」的问题，但更轻的做法是先切线路，做法见 [番剧播放不了怎么办.md](番剧播放不了怎么办.md)。
