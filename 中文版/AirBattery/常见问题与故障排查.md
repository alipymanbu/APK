## 安装时该认哪个包

认准包名 `friedrich.georg.airbattery`、版本 1.5.2、体积约 4.71 MB 这一套信息（对应 2023 年 4 月官方发布的那一版）。获取入口用 **AirBattery 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/26cd6408583f](https://pan.quark.cn/s/26cd6408583f)。安装与授权流程在[下载与安装教程](下载与安装教程.md)里逐步讲过。

## 为什么安卓上看 AirPods 电量要靠这类应用

AirPods 的弹窗、电量面板是苹果自家生态里的东西，安卓系统原生不提供同等界面，所以要在安卓上读这类耳机的精确电量，得由应用通过蓝牙低功耗接口去取。这也是应用需要位置权限的原因——系统规定 BLE 扫描必须带位置权限。

## 免费版和 Pro 差在哪

| | 免费版 | Pro |
| --- | --- | --- |
| 打开应用看电量 | 有 | 有 |
| 连接自动弹窗 | 有（需开设置） | 有（需开设置） |
| 自动刷新的常驻电量通知 | 无 | 有 |
| 状态栏图标直接显示电量 | 无 | 有（取电量较低那只） |
| 广告 | 有 | 无 |

Pro 通过应用内购买解锁，价格与内容以购买页当时显示为准。

## 双击、长按能不能自定义

安卓上改不了。官方给的办法是：先用 iPhone 或 Mac 在系统设置里改好 AirPods 的触控行为，改完之后安卓这边会沿用。AirBattery 里没有直接调这个的入口。

## 电量准不准

- 准确性：耳机只按 10% 档位上报（满电 | 95% | 85%…），任何工具读到的都是这个粒度，跳档不等于不准；
- 充电盒电量：盒内有耳机才读得到，这是盒子硬件特性，不是应用问题；
- 常驻通知、后台刷新会带来额外耗电，在意续航就少开几项后台功能。

## 电量彻底读不到

先走一遍[电量读不出来排查步骤](电量读不出来排查步骤.md)：位置权限 → 型号核对 → 弹窗权限 → 后台保活 → 重装。多数情况卡在位置权限这一步；型号不在支持列表、或用的是官方明说不保证兼容的国产机型，属于硬性限制，设置解决不了——国产机型具体能试什么见[国产手机读不到电量怎么办](国产手机读不到电量怎么办.md)。

## 入耳检测不生效

它是实验性功能，且主要配合 Spotify 这类官方测过的应用，其他播放器没反应属正常。开关位置与已测过的播放器名单见[弹窗与入耳检测设置](弹窗与入耳检测设置.md)。
