## 一、官方列出的支持型号

下面这八款是官方页面上逐一列出的设备，共同点是都带苹果的 W1 或 H1 芯片：

| 型号 | 系列 |
| --- | --- |
| AirPods（第一代） | AirPods |
| AirPods（第二代） | AirPods |
| AirPods Pro | AirPods |
| BeatsX | Beats |
| Powerbeats3 | Beats |
| Powerbeats Pro | Beats |
| Beats Solo3 | Beats |
| Beats Studio3 | Beats |

官方的口径是「所有当前的 Apple 与 Beats 无线耳机都在支持范围内」，上表是官方页面上逐一列出的型号；后续新出的型号（比如 AirPods Pro 之后的换代产品）是否被支持，以官方页面的最新说明为准。

有一处设置值得单独提：**AirPods 二代与 Powerbeats Pro 需要在应用设置里打开「AirPods 2 support」开关**才能读到电量，一代用户反而要把它关掉；二代耳机的电量读数最多还会迟到 10 秒。开关位置与完整排查见[电量读不出来排查步骤](电量读不出来排查步骤.md)。

## 二、列表之外的耳机行不行

其他品牌的蓝牙耳机（比如安卓厂商自家的真无线耳机）不在官方支持范围里，官方也没有给出它们能读电量的说明。能不能读到电量，以你手上的实际连接测试为准——连上后打开应用，有读数就是能用，没读数就是不支持，没有更多可调的空间。

给应用内置的设备图标是按型号定制的，你在界面上看到的图案能帮你区分连的是哪一副耳机。

## 三、手机这一头：官方点名的风险品牌

电量是耳机通过蓝牙上报给手机的，手机蓝牙硬件的实现方式直接决定能不能收到。官方说明里明确点名：

> 华为、小米、vivo、OPPO 及其他中国品牌手机可能无法使用本应用，这些厂商不一定使用标准蓝牙硬件。

这是官方原文的意思，不是猜测。也就是说，如果你用的是这些品牌的手机，装上之后读不到电量属于已知情况，换一台标准实现蓝牙的手机（例如 Pixel、三星等国际机型）再试才有意义。其他品牌官方没有点名，同样以实测为准。

## 四、双击/轻触功能怎么改

AirPods 的双击（或 Beats 的轻触）动作无法在 AirBattery 里修改。目前已知的唯一途径：把耳机连到一台 iPhone 或 MacBook 上改好双击功能，改完之后回到安卓手机上，改过的功能照样生效。这是设备端的行为，与用什么手机无关。
