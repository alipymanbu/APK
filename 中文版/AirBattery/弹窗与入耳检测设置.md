## 哪些功能要自己去设置里开

应用装好后，默认只在你手动打开它时才显示电量。官方说明里带星号的功能都需要在设置里手动激活：

- 耳机连接手机时自动打开 / 弹窗
- 自动刷新的通知（属 Pro 内容）
- 状态栏通知图标显示电量较低那只耳机的电量（属 Pro 内容）
- 入耳检测自动暂停播放
- 只显示离你最近的耳机

装好后先进一遍设置，把这些开关按自己的习惯打开，比装完直接用顺手得多。

## 连接时自动弹窗

开关打开后，耳机一连上手机，电量面板会自动弹出来，类似 iPhone 上开盖的效果。三个前提：

1. 应用内设置里开了对应开关；
2. 系统层面允许它「显示在其他应用上层」，否则开关开了也弹不出来——去「设置 → 应用 → AirBattery」把这个权限给上；
3. 后台别被系统杀掉：把应用从电池优化里排除，国产系统再开「后台自启动」——进程被杀，开关全开也不会弹。

弹窗一直不出现的话，按[电量读不出来排查步骤](电量读不出来排查步骤.md)查一遍权限。

## 常驻通知与 Pro 的区别

| | 免费版 | Pro |
| --- | --- | --- |
| 打开应用看电量 | 有 | 有 |
| 连接自动弹窗 | 有（需开设置） | 有（需开设置） |
| 自动刷新的常驻电量通知 | 无 | 有 |
| 状态栏图标直接显示电量 | 无 | 有（取电量较低那只） |
| 广告 | 有 | 无 |

Pro 通过应用内购买解锁，具体价格与内容以购买页当时显示为准。只想在想起来时看一眼电量，免费版够用；想不解锁手机、扫一眼状态栏就知道还剩多少电，用到的就是 Pro 的常驻通知。

## 入耳检测：摘下自动暂停

这是实验性功能，需要在设置里手动开。行为是：摘下一只耳机，正在播放的应用自动暂停，戴回去继续播。官方说明里以 Spotify 为主，另外在 Netflix、YouTube、Google Play Music、Deezer、Apple Music、BeyondPod 上测过；你的播放器不在名单里，开了没反应属正常。

顺带一提：AirPods 双击、长按这类触控操作的自定义，安卓这边改不了——官方给的办法是先用 iPhone 或 Mac 改好，之后安卓上会沿用改过的行为。

## 开了还是不弹、不暂停
