## 一、这份安装包是什么

Magic Poser（中文常称「魔法人形师」）是 Wombat Studio, Inc. 出的 3D 人偶摆姿参考工具，画师用它在下笔前把人体动态、镜头角度和光影先搭出来。下面这份是安卓安装包，包信息以本地留存的记录为准（网上能搜到的多是应用商店里的最新版，未必是同一份）：

| 项目 | 值 |
| --- | --- |
| 应用名 | Magic Poser |
| 版本 | 3.1 |
| 包名 | `com.magicposernew.kbinstaller` |
| 安装包大小 | 145.41M |
| MD5 | `2AC63E390572C13F6E9E478ABDBFBA36` |
| 最低系统要求 | 安卓 5.2 以上 |
| 包信息记录时间 | 2026-09-23 |

版本号会随官方更新变化，以官方发布页当时显示为准。

## 二、从网盘拿到安装包

1. 打开 [Magic Poser 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3d77f823b1a9)，点「保存到我的网盘」转存。
2. 在夸克网盘里找到 `MagicPoser_v3.1.apk`，下载到手机本地（或先下到电脑再传手机）。
3. 文件夹里带一个 `先保存再下载避免失效.txt`，那是转存说明，不用管它，别把 apk 当垃圾删了。

网盘里的文件夹分享链接不变；官方更新后换了新文件名，也只是文件夹里多一个文件，你的转存入口照旧。

## 三、安装步骤

1. 点开下载好的 apk。系统会弹「禁止安装来自此来源的应用」——这是因为你不是从应用商店装的，属正常拦截。
2. 按提示进入「允许来自此来源」的开关（不同厂商的安卓路径略有差异，一般在 设置 → 应用 → 特殊权限 → 安装未知应用 里，给夸克或文件管理器授权）。
3. 授权后返回，确认安装，等进度走完。
4. 装完可以选择「打开」，也可以先回桌面找图标。

注意：升级时直接用新包覆盖安装，**先别卸载旧的**：官方帮助中心明确提醒，删除应用会让手机里的本地场景文件一起被清掉，且无法找回。先装上新版、确认文件都在，再考虑清理旧包。

## 四、校验文件有没有下完整

大小对不上或下到一半中断，安装时会报错。拿到文件后可以先核一遍 MD5：

Windows（命令行）：

```powershell
certutil -hashfile MagicPoser_v3.1.apk MD5
```

把输出的 32 位十六进制和上表的 `2AC63E390572C13F6E9E478ABDBFBA36` 比对，一致即文件完整。手机上可用任意带 MD5 校验的文件管理器做同样的比对。不一致就重新下载，别硬装。

## 五、与应用商店版的关系

Google Play 上的商店版包名是 `com.magicposernew`，这份安装包是 `com.magicposernew.kbinstaller` —— 包名不同，系统会把它们当成两个独立应用：**并存安装、互不覆盖、图标各留一个**。你手机上如果已经装过商店版，装完后会出现两个 Magic Poser，场景文件也不共享；只想留一个的话，装完确认新包能正常打开、文件都在，再删另一个。

商店版的更新走 Google Play，这份包的更新靠网盘换新文件，两条路各自独立。

## 六、首次启动做这几件事

1. 进入后会有引导教程（官方在 1.51.0 版重做过一轮上手教学），跟着走一遍能学到摆姿、套预设、导出这三件最基本的事。
2. 界面语言一般是中文，可在设置里改。
3. 建议顺手注册/登录一个账号（邮箱密码或 Facebook 都行）：作品要备份到云端、要在多台设备间同步、要恢复购买，都挂在账号上。详见 [常见问题与解决方法](常见问题与解决方法.md)。
4. 第一个场景只有一个人偶是免费版的限制，不是故障；想加第二个就要升级，见 [常见问题与解决方法](常见问题与解决方法.md) 里的版本差异表。

装好之后，从 [摆姿势入门教程](摆姿势入门教程.md) 开始上手。
