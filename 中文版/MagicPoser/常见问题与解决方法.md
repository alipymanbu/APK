## 一、闪退 / 打不开

按命中率从高到低依次试：

1. **别卸载重装，先覆盖安装**：官方升级说明明确写了，删除应用会把本地场景文件一起清掉且无法恢复。正确姿势是直接用新安装包覆盖安装（步骤见 [下载与安装教程](下载与安装教程.md)）。
2. **清缓存，不清数据**：设置 → 应用 → Magic Poser → 存储 → 只点「清缓存」。点「清数据」会把本地未备份的作品和登录态一起抹掉。
3. **确认系统版本**：本包要求安卓 5.2 以上，低于要求的机型装上也跑不稳。
4. **重启手机再开**：内存被占满时大型 3D 应用最容易被系统杀掉。
5. 仍不行，卸载前**先把本地文件导出图片或云备份**（见 [导出图片与3D文件教程](导出图片与3D文件教程.md)），再重装。

官方更新日志里多次修过「启动崩溃」「打开特定场景崩溃」这类问题，遇到莫名闪退也可以对照官方渠道看是否已有修复版本。

## 二、更新后作品 / 姿势不见了

- **本地文件**：只要没删应用，更新不会动你的本地文件。找不到多半是文件列表没刷新或你存在另一台设备上 —— 登录同一账号再看一遍。
- **旧版多人场景打不开**：免费版每个场景只允许 1 个人偶，含多个人偶的旧文件在免费状态下无法打开。官方为此给老用户留过 1 个月的 Pro 试用期，建议在试用期内把这类文件**导出成图片**留底（导出方法见 [导出图片与3D文件教程](导出图片与3D文件教程.md)）。
- **云端文件**：上传到云端（公开或私有）的作品不受版本与升级影响，随时可再下载。
- 有用户反馈某些版本更新后打不开旧姿势、甚至应用崩溃 —— 这是单一渠道的反馈，尚未见官方集中确认；遇到时优先走上面的「覆盖安装 + 云备份恢复」两条路，别急着清数据。

## 三、为什么加不了第二个人偶 / 为什么一堆功能点不了

不是故障，是免费版的功能边界。截至官方定价页（价格以应用内显示为准）：

| 功能 | Free（$0） | Pro（$9.99 一次性） | Master（$14.99/月） |
| --- | --- | --- | --- |
| 场景内人偶数 | 1 | 无限 | 无限 |
| 灯光 | 1 盏方向光 | 无限盏、3 种类型 | 同 Pro |
| 预设姿势 | 50 | 600+ | 3000+ |
| 道具 / 发型服饰 | 10+ / 4 | 38 / 26 | 500+ / 100+ |
| 体型形变（健壮/偏胖/偏瘦） | 无 | 有 | 有 |
| 导出 OBJ / .mp 文件 | 无 | 无 | 有 |
| 私有云备份 | 无 | 50 份 | 无限 |
| 本地保存、导出 PNG、社区分享 | 有 | 有 | 有 |

三个要点：

- **Pro 是一次性买断，不是订阅** —— 付一次永久有效；Master 才是按月订阅。
- Pro/Master 都有 7 天试用，**试用结束不会自动扣费**，到期只是回到免费版，只有你手动点「购买」才会收钱。
- Master 取消订阅后，首次付费期内获得的 Pro 功能保留。

## 四、账号、恢复购买与多设备

- **登录方式**：邮箱密码或 Facebook，同一账号在手机、平板间同步文件与购买记录。
- **换了手机买不回来**：先在新设备装应用、登录**原来那个账号**，再在账号页点恢复购买；用不同账号注册就查不到旧购买。
- **账号页在哪**：应用内 Account 页面，「Upgrade」按钮就在里面，也是查看当前版本状态的入口。
- 旧版的袋熊币（Wombat Coins）已随新定价取消，官方为消费过的老用户提供了 Pro/Master 权益回馈，具体以官方帮助中心说明为准。

## 五、其他零散问题

- **明明在拖人偶，动的却是镜头**：对象被锁定了。锁定状态下拖它 = 转镜头，解锁后才能挪，见 [移动旋转与缩放教程](移动旋转与缩放教程.md)。
- **找不到删除 / 复制 / 落地按钮**：动作菜单要**向右滑到底**才露出来，见 [移动旋转与缩放教程](移动旋转与缩放教程.md)。
- **导出 OBJ 时主菜单不显示**：先升级版本，详见 [导出图片与3D文件教程](导出图片与3D文件教程.md) 的失败原因一节。
- **道具摆完姿势又对不上手**：改用道具附着功能挂到手上，见 [场景与灯光设置教程](场景与灯光设置教程.md)。
