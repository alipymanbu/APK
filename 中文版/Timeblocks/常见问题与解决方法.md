# TimeBlocks 常见问题与解决方法

> 本篇收 TimeBlocks 最常问的几类问题：安装失败、待办打不了勾、提醒不响、小组件不刷新、账号与数据。

## 一、安装失败 / 打不开

| 现象 | 处理 |
| --- | --- |
| 解析包错误 / 应用未安装 | 安装包多半没下完整，重新下载一遍；需要重新拿包时用 Timeblocks 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/df28857c4fce](https://pan.quark.cn/s/df28857c4fce)，重下后核对 MD5（方法见 [下载与安装教程.md](下载与安装教程.md)） |
| 点 APK 没反应 | 给文件管理器开「安装应用」权限 |
| 装好闪退 | 重启手机再开；仍不行确认系统版本是否满足官方要求 |

## 二、待办不能在过去的日期打勾

这不是故障，是规则：待办只能勾「今天」。想把待办记到过去某天，先在今天打勾，再长按拖到那天；拖到未来则会变回未完成。完整规则见 [日程与待办使用技巧.md](日程与待办使用技巧.md)。

## 三、贴纸 / 日期高亮删不掉

按官方帮助中心的步骤：点应用了装饰的那个日期 → 打开日程列表弹窗 → 点右上角缩略图 → 点「x」。同一天贴了多个的，逐个删。删除入口不在编辑页里，所以很多人找不到。

## 四、提醒不响

按顺序查：

1. 系统设置里 TimeBlocks 的通知权限是否开着。
2. 是否开了勿扰 / 专注模式，提醒被静音。
3. 国产系统（EMUI、MIUI、ColorOS 等）常会拦后台：把 TimeBlocks 设为不受电池优化限制、允许后台自启与后台弹出，否则到点不弹提醒。
4. 应用内的提醒设置是否只对部分记录生效（部分提醒相关设置属于高级版，功能与价格对照见 [高级版订阅与免费版差异.md](高级版订阅与免费版差异.md)）。

## 五、桌面小组件不显示 / 不刷新

- 添加方式：长按桌面空白处 → 「小组件 / 窗口小工具」→ 找 TimeBlocks，可选月历、周历、今日清单、待办清单、习惯清单等样式。
- 数据不动：多数是系统限制了后台刷新，给应用后台运行权限后等一个刷新周期。
- 多数小组件用于查看，改动还是要进应用里完成。

## 六、账号与数据

- 忘了登录 ID：侧边栏 → 账号菜单 → 注册信息里的 e-mail。
- 卸载重装前先登录并确认同步完成：没登录时数据只存在手机本地，卸载就没了（详见 [日历同步与多设备使用.md](日历同步与多设备使用.md)）。
- 换手机、换邮箱、退出共享分类的注意事项，见 [日历同步与多设备使用.md](日历同步与多设备使用.md)。
- 自己解决不了时走官方渠道：客服邮箱 `support@timeblocks.com`（官网页脚与应用商店客服信息里列的），帮助中心 [https://day2life.zendesk.com](https://day2life.zendesk.com)（有中文页面），或用应用内反馈入口；联系时写清账号邮箱与问题现象。
