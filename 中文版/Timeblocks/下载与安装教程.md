## 一、安装前先确认

这份安装包的基本信息如下，装好后可在系统「应用信息」里对照：

| 项目 | 值 |
| --- | --- |
| 应用 | TimeBlocks（时间积木），开发者 TimeBlocks, inc. |
| 版本 | 6.3.10 |
| 安装包大小 | 约 70 MB（70.15 MB） |
| 包名 | `com.hellowo.day2life` |
| MD5 | `926fbe762c5f51cd93159661c82f0f51` |

- 手机剩余空间建议留 200 MB 以上：安装包约 70 MB，安装后还要写入数据，实际占用会更大。
- 想核对官方信息，可访问官网 [www.timeblocks.com](https://www.timeblocks.com)。
- 需要校验安装包是否完整时：手机上用带「文件校验」功能的文件管理器算 MD5；电脑上在 PowerShell 里执行：

```powershell
certutil -hashfile "Timeblocks_v6.3.10.apk" MD5
```

算出的值与上表一致，说明文件没坏。

## 二、获取安装包

Timeblocks 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/df28857c4fce](https://pan.quark.cn/s/df28857c4fce)

1. 打开链接，把分享内容转存到自己的网盘（没装夸克 App 时按页面提示操作）。
2. 在手机端夸克 App 里找到转存后的 `Timeblocks_v6.3.10.apk`，下载到手机。
3. 记住下载位置，一般在「Download」或「Quark」目录。

用电脑下载也行：先在电脑端下载 APK，再通过数据线或其他方式传到手机，后续步骤相同。

## 三、安装步骤

以 Android 8 及以上系统的常见流程为例，不同品牌的菜单名称略有差异：

1. 在文件管理器里点开下载好的 APK。
2. 弹出「不允许安装未知来源应用」时，点「设置」→ 打开「允许来自此来源」（只针对你的文件管理器），返回后继续。
3. 点「安装」，等待完成后选「打开」或「完成」。

## 四、首次启动

首次打开会依次申请权限。官方对各项权限的用途说明如下，按需允许即可：

| 权限 | 用途（官方说明） |
| --- | --- |
| 通知/闹钟 | 日程提醒与推送通知 |
| 日历 | 导入系统日历里的日程 |
| 通讯录 | 日程里的参与人 |
| 位置 | 日程地点；日历里显示当前位置的天气 |
| 提醒事项 | 与系统提醒事项同步 |
| 照片 | 「当日信息」里展示当天拍的照片 |
| 相机 | 拍摄账号头像 |
| 生物识别 | 生物识别登录 |

- 拒绝某项后对应功能不可用（Android 13 及以上部分权限会以「照片/媒体」形式出现），之后可在「系统设置 → 应用 → TimeBlocks → 权限」里补开。
- 要用云同步、共享分类，需要注册或登录账号；邮箱就是你的登录 ID（见 [日历同步与多设备使用.md](日历同步与多设备使用.md)），登录方式以应用内当前提供的为准。
- 界面语言以应用内实际显示为准；若默认不是中文，通常可在设置里找到语言选项切换。

## 五、装不上时

- 「解析包错误 / 应用未安装」：多为安装包下载不完整，回到网盘重新下载一遍，再按第一节的方法核对 MD5。
- 点 APK 没反应：检查文件管理器自身是否有「安装应用」权限。
- 装好但打不开：先重启手机再试；仍不行则确认系统版本满足官方要求（以官方页面标注为准）。

更多问题排查见 [常见问题与解决方法.md](常见问题与解决方法.md)；装好之后从 [日程与待办使用技巧.md](日程与待办使用技巧.md) 开始上手。
