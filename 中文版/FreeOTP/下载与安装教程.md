## 一、FreeOTP+ 和原版 FreeOTP 是什么关系

应用市场里有两个名字很像的应用，装之前先分清：

| 名称 | 包名 | 出品方 | 说明 |
| --- | --- | --- | --- |
| FreeOTP | `org.fedorahosted.freeotp` | Red Hat | 老牌开源验证器，实现 TOTP 与 HOTP 两种公开标准 |
| FreeOTP+（FreeOTP Plus） | `org.liberty.android.freeotpplus` | 社区分支 | 在原版基础上用 Kotlin 重写并增强功能 |

本篇写的是 FreeOTP+：核心功能与原版一致（扫二维码添加令牌、本地生成动态验证码），在此之上补了导出/导入备份、令牌搜索与分类、深色主题、启动时生物识别或 PIN 锁、离线网站图标等能力。它是开源软件（Apache-2.0 许可），源码在 GitHub 上可查。

两者包名不同、可以共存，但令牌数据互不相通 —— 你在哪个应用里绑的账号，就只能用哪个出码。装之前确认一下包名，别绑了一半发现装的是另一个。

## 三、安装步骤

从应用商店装的点安装即可，不用看这节。从网盘或 GitHub 拿到的是 APK 文件，手动安装：

1. 把 APK 传到手机上（网盘 App 里直接下载即可）；
2. 在文件管理器里点开 APK；系统提示「禁止安装未知来源应用」时，按提示允许你的文件管理器（或浏览器）安装应用，不同品牌的叫法略有差异；
3. 回到文件管理器继续安装，完成后打开。

系统要求：Android 5.0 及以上（官方 README 口径）。

## 五、首次启动

- 首次添加令牌时会申请**相机权限**，用于扫描网站上的二维码；如果你只打算手动输入密钥，这个权限可以拒绝。
- 建议先到设置里开启启动验证（生物识别或 PIN），再开始绑定账号 —— 验证器打开就能看到所有动态码，不加上应用锁等于多开一道门。具体见[功能设置与隐私保护.md](功能设置与隐私保护.md)。
- 绑定账号前最好先看一遍[令牌备份与换机迁移.md](令牌备份与换机迁移.md)：验证器类应用的规矩是密钥只存本机一份，卸载或换机前不导出，绑过的账号就得走各网站的恢复流程重绑。

装好之后账号怎么绑定、验证码怎么用，见[两步验证绑定与验证码生成.md](两步验证绑定与验证码生成.md)。
