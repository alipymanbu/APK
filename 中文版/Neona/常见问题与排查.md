# Neona 常见问题与排查

> 装不上、登不上、列表空的、角色不回应、语音没声音、记忆像丢了——按症状对号入座,每条都给到能动手的步骤。

## 一、按顺序自查（先做这三步）

大多数问题都能被这三步解决掉，先做完再往下查具体症状：

1. **换网络**：从 Wi-Fi 切到移动数据，或反过来，重试一次；
2. **彻底重启应用**：从后台清理里划掉 Neona，再重新打开；
3. **确认已登录**：菜单里能看到账号相关入口，说明登录状态正常。

## 二、装不上或装完打不开

| 症状 | 处理 |
| --- | --- |
| 解析包错误 | 安装包没下完整，删掉重新下载，别用体积对不上的文件 |
| 提示已阻止安装 | 打开「未知来源 / 安装外部应用」权限，见 [下载与安装教程.md](下载与安装教程.md) |
| 提示与设备不兼容 | 系统版本低于应用要求，这类限制无法绕过 |
| 安装成功但一点就闪退 | 先在系统设置里清除该应用的数据再打开；仍闪退，卸载后重新安装 |
| 想在电脑上运行 | 官方有浏览器网页版，打开官方站点的网页入口即可；想用应用客户端形态再装安卓模拟器，见 [在电脑上用模拟器运行.md](在电脑上用模拟器运行.md) |

## 三、登录相关

**授权页打不开**：换网络重试；如果换网络仍然打不开，多半是设备缺少 Google 服务框架，见 [注册登录与账号设置.md](注册登录与账号设置.md)。

**点了登录没反应**：先关掉后台的 Google 相关页面再试；部分机型需要在系统里先登录一个 Google 账号。

**登录成功但提示信息没填完**：年龄、昵称、性别这几项要依次确认完才会进入正常使用状态。

**想换账号**：先在菜单里退出，再重新登录。注意原账号的对话进度不会迁移到新账号。

## 四、角色列表空白或加载不出

角色列表来自服务器，空白通常是网络问题，而不是账号被限制：

- 换网络后下拉刷新；
- 检查手机时间是否准确——系统时间偏差过大会导致请求失败；
- 关掉 VPN 或代理后重试（部分代理会让请求被拒）。

如果只有个别角色打不开、列表本身正常，那是该角色页面的偶发问题，过一会儿再看。

## 五、角色不回应或回应很慢

先说结论：这几乎都是网络或额度问题，不是角色「坏了」。

1. **确认点数**：点数不足时对话会走不下去，按 [点数和内购怎么算.md](点数和内购怎么算.md) 看一下余额；
2. **换网络重试**：同样一句发两遍没反应，先换网络；
3. **看是不是长对话**：同一条剧情线聊得很长时，回复变慢属于正常现象，新开一段或换个话题通常更快；
4. **确认没在等选项**：Neona 没有选项菜单，你不发言它就不会往下走，别把它当成在加载。

## 六、语音相关

语音问题的处理集中在 [语音通话与音色怎么设置.md](语音通话与音色怎么设置.md)，这里给最快的三步：

- 没有声音：按音量键确认媒体音量，检查是否连着蓝牙耳机；
- 麦克风没反应：到系统设置里确认 Neona 的麦克风权限为允许；
- 通话卡顿：实时语音对网络更敏感，优先用 Wi-Fi。

## 七、角色「好像忘了」之前的事

先排除两种情况：

- 你换了账号或换了设备用另一个账号登录——进度跟着账号走；
- 你换了一个角色，却按上一个角色的剧情去说。

都不是的话，说明是长对话里设定漂了，而不是记忆被清空。处理办法见 [角色记忆怎么保持长期连贯.md](角色记忆怎么保持长期连贯.md)：就地纠正比退出重开更有效，因为重开等于放弃已有的关系进展。

## 八、换手机怎么把进度带走

换机前确认一件事：原来的对话是在**已登录**状态下进行的。然后在新手机上装好应用，用**同一个账号**登录，对话进度、自建角色和点数余额都会回来。

如果原来一直没登录，这些内容无法找回，只能重新开始。自建角色的设定建议在别处留一份文字备份，以免换账号时丢失。

## 九、仍然解决不了

官方提供了两条公开的联系渠道：

- 客服邮箱：`help@neonachat.io`
- 官方社区：官方站点上给出的 Discord 服务器

联系时把下面信息一起发过去，能省一轮来回：手机型号与系统版本、Neona 的版本号（本地这份是 `v2.2.2`）、包名 `ai.neona.app`、问题的具体表现与出现时间。涉及扣费的，附上应用内购的订单信息。
