# LetsView 搜不到设备与连接失败排查

## 一、第一步永远是：确认两台设备在同一个网络

八成的「搜不到」都栽在这里。按顺序检查：

1. **手机关掉流量**，只留 Wi-Fi。手机一旦插着 SIM 卡，有些系统会优先走数据，导致你在蜂窝网络里投屏。
2. **看两台设备连的 Wi-Fi 名字是否一字不差**。路由器常见的坑：2.4G 与 5G 分成了 `xxx` 和 `xxx-5G` 两个名字——严格说这两个通常也互通，但部分路由器把它们隔离开，就会出现「名字像但搜不到」。
3. **电视确认真的连上了网**：电视待机久了 Wi-Fi 会假连接，遥控器进设置里看一眼网络状态。
4. 还拿不准，用官方的检测教程对照：[如何检测手机和电脑是否在同一网络](https://letsview.com/tw/faq/check-phone-pc-same-ip.html)——对比两台设备的 IP 前缀是否一致。

确认同网之后还是搜不到，就别耗在搜索连接上了，直接换**扫码或设备码连接**（步骤都在 [手机投电脑连接步骤.md](手机投电脑连接步骤.md) 和 [手机投电视连接方法.md](手机投电视连接方法.md) 里），这两种不依赖设备发现，多数情况能直接连上。

## 二、设备列表刷不出来 / 搜不到目标

按命中率从高到低逐条试：

| 排查动作 | 说明 |
| --- | --- |
| 下拉刷新设备列表 | 发现列表不是实时的，先手动刷新 |
| 两端 App 都彻底关掉重开 | 后台挂久了广播会停；电视端尤其要退出重进 |
| 重启路由器 | 路由器开久了会丢组播，投屏发现恰好依赖它 |
| 关掉手机上的 VPN / 代理 | VPN 会把流量引走，设备发现直接失效 |
| 路由器关「AP 隔离」 | 开了隔离的 Wi-Fi 里设备互相不可见，常见于公司网络和酒店 |

在公司或校园网络里反复搜不到，多半就是网络策略禁了设备间互访——这种环境换手机热点自组一个小网络最快。

## 三、兜底路线：电脑开热点，手机连热点再投

Wi-Fi 环境实在没救（公司网络隔离、路由器设置动不了）时，官方教程给了一条绕开路由器的路——让电脑自己当热点：

1. 手机端连接失败后，点电脑端 LetsView 里的**「Connection failed?」**（连接失败？）入口。
2. 在「Using a hotspot」（使用热点）一栏点 **Enable now**（立即启用），电脑开始共享热点。
3. 手机打开 WLAN 设置，搜到电脑共享的热点，输入密码连上。
4. 重新打开手机端 LetsView，改用**扫码或设备码**连接。

这条路上手机和电脑其实在同一个「热点网络」里，设备发现与投屏带宽都不经过路由器，会议室、酒店这类受限网络里特别管用。代价是手机连着电脑热点就没法同时上网，投完记得切回原来的 Wi-Fi。

## 四、点了连接但投屏失败 / 黑屏

- **授权弹窗一闪而过或被拒**：到系统设置 → 应用 → LetsView → 权限里，手动允许「显示在应用上层 / 投射屏幕」类权限，再重连。
- **电脑端要求 Miracast 提示**：从系统层面无线投到 Windows 时，部分老电脑会提示「不支持 Miracast」。这不影响 LetsView App 内的三种连接方式（它们走 App 通道，不走系统 Miracast）；如果确实碰到了这个提示，官方有一篇专门的解决方案：[当提示"您的电脑不支持Miracast功能"](https://letsview.com/tw/faq/solve-miracast-issues.html)。
- **手机端 WiFi 连接 Windows 一直失败**：官方针对这个问题单独出了排查教程 [无法使用WiFi连接的解决方法](https://letsview.com/tw/faq/cant-connect-via-wifi.html)，里面含 Windows 防火墙放行等步骤，照做一遍。
- **电视端连上但黑屏**：先退出电视端 App 重开；仍黑屏则重启电视——电视盒子的解码进程卡死很常见。

## 五、连得上但卡顿、延迟高

1. **两端都切到 5G 频段 Wi-Fi**（名字带 5G 的那个），并离路由器近一点。
2. **暂停大流量任务**：同一网络里有人在下东西、看 4K 视频，投屏立刻变幻灯片。
3. **降低投屏分辨率**：画质调低一档，流畅度立竿见影。安卓与 iOS 端的调法官方有专文：[投屏分辨率的调整方法](https://letsview.com/tw/faq/change-letsview-resolution.html)。
4. **游戏投屏**：对延迟敏感的场景，别指望完全无感，能接受 0.1~0.5 秒级延迟再玩；更稳的路线是有线（需要电脑端配套软件支持 USB 连接的版本）。

## 六、以上全部试过还不行

1. 手机端 App 里找到**网络环境检测**（设置里），把检测页截图留好，里面有 IP、端口、服务器信息，是判断问题位置的关键证据。
2. 带着截图和「两端设备型号 + 系统版本」联系官方：support@letsview.com，或从 App 内「我 → 反馈」入口提交；官方 FAQ 汇总页在 [letsview.com/tw/faqs/faq](https://letsview.com/tw/faqs/faq)，发邮件前可以先搜一遍有没有现成答案。
3. 如果是刚从旧版本升级后出现的连接异常，卸载重装一次两端 App（手机端安装包获取见 [下载与安装教程.md](下载与安装教程.md)），升级残留导致的假死不少见。
