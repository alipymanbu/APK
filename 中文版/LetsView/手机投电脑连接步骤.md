> 本篇讲把安卓手机画面投到 Windows / Mac 电脑上的三种连接方式，以及连接之后用手机反控电脑的操作。

## 一、连接前的一次性检查

三件事确认完，后面不管用哪种方式连，成功率都高得多：

1. **两端都装好 LetsView**：手机端可从 [LetsView 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b37812fc5736) 转存安装；电脑端从官方站 [letsview.com](https://letsview.com/) 获取 Windows 或 Mac 版。
2. **同一个 Wi-Fi**：手机别用流量，电脑别插网线走另一个网络——两者必须在同一路由器下。判断方法见 [搜不到设备与连接失败排查.md](搜不到设备与连接失败排查.md) 第一节。
3. **两端 App 都打开**：电脑端保持在主界面（能看到设备名和投屏码），手机端第一次使用先点下方的「+屏幕镜像」。

## 二、方式一：搜索连接（最省事）

同一 Wi-Fi 下，双方会自动出现在对方的设备列表里：

1. 打开手机端 LetsView，等设备列表刷新。
2. 点选名字形如「LetsView+你的电脑名」的那一项。
3. 选「共享本机屏幕」。
4. 系统弹「是否允许 LetsView 录制/投射您的屏幕」→ 点允许 → 再点「立即开始」。
5. 手机画面出现在电脑窗口里，连接完成。

首次连接之后再用，通常直接从列表点电脑名即可，不用重新授权。

## 三、方式二：扫码连接

搜索列表刷不出来电脑时的第一备选：

1. 电脑端 LetsView 进入「屏幕镜像」页，主界面右侧会显示**投屏二维码**。
2. 手机端 LetsView 点右上角的扫一扫图标（形似「-」的扫码入口）。
3. 对准电脑屏幕上的二维码扫描。
4. 手机弹出授权窗，点「立即开始」，投屏即开始。

## 四、方式三：设备码连接

同样适合搜不到设备的场景，尤其适合教室里多台手机要投同一台电脑时逐台输入：

1. 电脑端「屏幕镜像」页右侧有一串**我的设备码**（数字 PIN）。
2. 手机端 LetsView 点右上角「**」图标，调出输入框。
3. 输入电脑上的设备码，点下方的「→」图标。
4. 弹窗授权（允许录制/投射屏幕 → 立即开始）后完成连接。

## 五、连接之后：用手机控制电脑

手机与电脑连上后，不只是「手机画面上墙」这一个方向：

- **手机控制电脑**：连接建立后，手机可以当成一套临时的键鼠——直接在手机屏幕上点按、滑动，就能操作电脑上的窗口，翻 PPT、开关程序都可以。
- **电脑画面投到手机**：在电脑端选择投到你的手机设备，电脑屏幕就会镜像到手机上，适合把电脑上的文档拿在手里看。

## 六、投屏中断开与切换

- 断开：手机端投屏浮窗里点断开，或直接关掉手机端 App；电脑端关窗口也能结束会话。
- 换一个接收设备：回手机端设备列表，点另一个目标即可，不需要重启 App。
- 反复掉线的情况，按 [搜不到设备与连接失败排查.md](搜不到设备与连接失败排查.md) 的清单过一遍，多数是网络环境而不是 App 本身的问题。
- 画面正常但没有声音（包括想把手机的声音、麦克风话音传给电脑），单独看 [投屏没声音排查.md](投屏没声音排查.md)，那条通路有自己的开关和设置。
