# LetsView 投屏没声音排查

> 画面投上去了、声音还在手机上——本篇按官方教程把声音通路一步步打开，包括系统声音、麦克风声音与个别游戏无声三种情况。

## 一、先做官方的三步快速排查

手机投电脑/投电视没声音，官方教程给的排查顺序是：

1. **检查各端音量**：手机、接收端（电脑或电视）有没有被静音，逐一打开——最傻的原因排第一，因为它最常见。
2. **打开 App 内的喇叭按钮**：投屏成功后，需要在手机端 LetsView 界面里点选**喇叭图标**打开声音开关。这个开关独立于系统音量，不少人卡在这一步。
3. **唯独某个游戏没声音**：如果投其他 App 都有声音、只有某个游戏不出声，先用别的应用（视频、音乐）验证投屏音频通路正常，再判断是不是该游戏自身对音频通路的处理限制——这不是投屏设置能解决的。

## 二、手机端「投射音频」设置

声音往哪走、传什么，在手机端 App 的设置里定：

1. 打开手机端 LetsView，进**设置**（主界面左上角）。
2. 找到**投射音频 / Cast audio**。
3. 二选一：
   - **系统声音**——手机里播放的媒体声音跟着画面走；
   - **麦克风声音**——把手机麦克风收到的话音传出去。

设置完回到主界面重新连接一次投屏，声音设置才会按新选择生效。

## 三、想把说话声传给电脑（麦克风传声）

远程讲解、帮人调手机时，用手机麦克风传声：

1. 手机端设置里开启 **Cast microphone audio**。
2. 回主界面，搜索并连接电脑（连接步骤见 [手机投电脑连接步骤.md](手机投电脑连接步骤.md)）。
3. 系统弹授权窗，点**允许**。

官方教程特别提醒了一句：开启麦克风传声后，**手机和电脑离远一点**，否则声音在两个麦克风之间循环放大，就是刺耳的啸叫声。

## 四、要传系统声音：Miracast 路线

普通投屏通道在部分手机上传不了系统声音，官方给的替代路线是走手机系统自带的「无线投影」（基于 Miracast）。这条路对电脑有硬件门槛，先核对再折腾：

| 检查项 | 怎么查 | 达标线 |
| --- | --- | --- |
| Windows 版本 | `Win + R` 输入 `winver` | Windows 8.1 及以上 |
| 显卡支持 | `Win + R` 输入 `dxdiag`，保存全部信息后在 txt 里搜 Miracast | 显示 Available / 已受支持 |
| 无线网卡支持 | PowerShell 跑 `Get-NetAdapter \| Select Name, NdisVersion` | WLAN 的 NdisVersion ≥ 6.40 |

三项都达标后：手机和电脑连同一 Wi-Fi → 手机设置里找「无线投影」（各品牌叫法不同：华为在「设备连接」里，小米在快捷设置里叫「投屏」）→ 选你的电脑 → 这样连出来的画面才带同步的系统声音。显卡或网卡不达标，先去更新驱动。

## 五、投屏时想让电脑闭嘴

看视频投到电脑、电脑又外放出自己声音的场合：投屏成功后，点手机端（或电脑端）界面底部的 **Sound: On**，切成 **Sound: Off**，电脑端就静音了，手机端继续出声。
