## 一、安装器对照表

这些安装程序都是装在 Switch 主机上的自制软件，手机这侧只负责配合它们发送文件。你能用哪种传输方式，取决于主机上装的是哪一个。

| 主机端安装程序 | USB 传输 | WiFi 网络传输 | 备注 |
| --- | --- | --- | --- |
| Awoo Installer（Huntereb） | 支持 | 支持 | 资料最多、最常被拿来跑通流程，第一次用优先选它 |
| TinFoil（Adubbz） | 支持 | 支持 | 手机版 0.2 起才支持它的网络方式 |
| GoldLeaf（XorTroll） | 支持 | 不支持 | 手机版只配合 v0.5，且一次只能传一个文件 |

手机上选错安装程序类型是连不上的常见原因，两种方式的操作入口分别在[USB连接传输完整步骤.md](USB连接传输完整步骤.md)和[WiFi网络传输设置.md](WiFi网络传输设置.md)里。

另外一个官方口径要记住：Awoo Installer 用的是和 TinFoil 完全相同的一套命令集（协议），两者对 NS-USBloader 来说几乎是同一个东西。手机应用菜单里如果找不到 Awoo 这个名字，按 TinFoil 配合主机上的 Awoo 使用即可。

## 二、能传的文件格式

NSP（标准安装文件）、NSZ（压缩过的安装文件）、XCI（卡带镜像）、XCZ（压缩过的卡带镜像）都可以加进传输列表。4.0 版起，在系统文件管理器里点这些文件可以直接选「用 NS-USBloader 打开」，不用先进应用再找文件。

格式支持是「主机端说了算」的：手机把文件送过去，装得上装不上、认不认这个格式，由主机上的安装程序决定。遇到主机端不认的情况，先确认主机上那个安装程序的版本和它支持的格式清单。

## 三、5.0 这版一路攒下的东西

从 2019 年首个公开版到 2020 年 12 月的 5.0，对日常使用有影响的变化：

| 版本 | 变化 |
| --- | --- |
| 5.0（2020-12） | 界面翻译补充；中文界面在更早版本已具备 |
| 4.0（2020-10） | NSP / NSZ / XCI / XCZ 文件关联 |
| 3.0（2020-10） | 深色主题，主题可选手动或跟随系统；曲面屏机型边距修正 |
| 2.0（2020-09） | 增加简体中文界面 |
| 1.0（2020-08） | 增加繁体中文界面；修复老系统启动闪退；支持分屏 |
| 0.2（2020-03） | 网络传输可用（首版不可用）；新增设置页 |
| 0.1（2019-07） | 首个公开版本 |

之后作者没有再发手机版更新，项目重心转回 PC 桌面版；手机版要装的就是[下载与安装教程.md](下载与安装教程.md)里那份 5.0。

## 四、开源信息与桌面版的区别

项目按 GPL-3.0 协议开源，作者是 Dmitry Isaenko（developersu）。手机版源码在 `https://github.com/developersu/ns-usbloader-mobile`，桌面版源码在 `https://github.com/developersu/ns-usbloader`。桌面版（Windows / macOS / Linux）比手机版多出文件分割合并等能力，需要在电脑上操作时可以去项目页看；两个版本的安装包互不通用。
