# NS-USBloader 用 USB 线把手机连 Switch 传文件

> 本篇讲 USB 方式的完整流程：要备什么线、两端各做什么、传输过程中别做什么。

## 一、先备齐三样东西

1. **一根能传数据的 USB 线，加一个 OTG 转接头**。手机端一般是 Type-C 或 Micro-USB，Switch 主机端是 Type-C。常见接法是：普通手机数据线的 Type-C 一头插 Switch，USB-A 一头插 OTG 转接头，转接头再插手机。方向不能反——转接头插 Switch、数据线插手机这个方向是行不通的。线短一点更稳。
2. **主机上已经装好并打开安装程序**（Awoo Installer / TinFoil / GoldLeaf）。手机这侧的 NS-USBloader 只是发送方，主机上得先有处于等待状态的接收方。
3. **要传的文件已经放在手机存储里**。放哪个目录都行，后面在应用里手动选。

只有 OTG 这条最容易翻车：转接头质量差、或者线本身只支持充电，插上之后手机毫无反应，看起来像软件坏了，其实根本没接通。线和转接头怎么挑、怎么先用 U 盘验证通路，单看[OTG转接头与数据线怎么选.md](OTG转接头与数据线怎么选.md)。

## 二、完整步骤（以 Awoo Installer 为例）

1. 在 Switch 上打开 Awoo Installer，进入「USB 安装」之类的入口，让主机进入等待连接状态；
2. 按第一节的接法，用线把 Switch 和手机连起来；
3. 手机上会弹出「允许应用访问 USB 设备」之类的请求，点允许；
4. 打开 NS-USBloader，点左上角的菜单（三条横线），在列表里选你主机上实际打开的那个安装程序（Awoo / TinFoil / GoldLeaf）——这里选错类型是连不上的常见原因；
5. 点「选择文件」（SELECT FILES），把要传的文件加进列表，一次选一个，可以分多次加；
6. 点「上传到 NS」（UPLOAD TO NS）；
7. Switch 端收到文件列表后，在主机上选安装位置，安装随即开始。

GoldLeaf 的差异单独记住：手机版只配合 GoldLeaf v0.5，且只支持 USB 一种方式（没有网络传输），传输时一次只能传一个文件。

## 三、传输过程中别做的事

- **两台设备都别息屏**。息屏是传输中断最常见的原因，开始传输前把手机和主机的自动休眠暂时调长或关掉；
- **三星手机尤其别旋转屏幕、别切出去最小化**。有用户反馈在部分机型上这样做会直接让应用崩掉；
- 别中途拔线。中断了就重新把这一批再传一遍。

## 四、传完了怎么算成功

应用列表里出现「Uploaded / 已上传」只代表文件从手机这侧发送完毕、没有出错，不代表主机已经装好——安装这一步由主机上的安装程序负责，它们不会向手机回传结果。所以最终确认装没装上，要看 Switch 屏幕上那个安装程序的界面显示。

哪一步卡住了，按现象对照[传输失败常见问题排查.md](传输失败常见问题排查.md)处理；主机上没装安装程序、或不确定该用哪个，先看[支持的安装器与文件格式.md](支持的安装器与文件格式.md)。
