## 一、先确认这是不是你要装的东西

NS-USBloader 是一个运行在安卓手机上的文件传输工具：把手机里存的游戏安装文件（NSP / NSZ / XCI / XCZ 等格式）通过 USB 数据线或 WiFi 发送到 Nintendo Switch 主机，配合主机上的 Awoo Installer、TinFoil、GoldLeaf 等安装程序完成安装。项目按 GPL-3.0 协议开源，同一作者在 Windows / macOS / Linux 上还有一套桌面版——手机版和桌面版是两个独立的安装包，别混着下。

适合装它的场景：手机里已经存好了要传的文件，手边有 OTG 转接头，或者手机和主机能连进同一个 WiFi，不想为了传文件专门开电脑。

前提要说清楚：它只负责手机这一侧的发送，主机上必须已经装好上面提到的那些安装程序才能接收。主机那一侧怎么准备，不属于手机版能解决的范围，本篇也不展开。

## 三、从哪里获取安装文件

用开头网盘提示块里的 **NS-USBloader 安装文件资源（夸克网盘）** 即可：把分享内容转存到自己网盘，再下载到手机存储。下载完建议先核对 MD5——很多文件管理器都带「计算 MD5」功能，算出来和第二节表格里的值一致，说明文件完整。

## 四、安装步骤

1. 把 apk 文件下载到手机存储；
2. 用文件管理器点开它。如果系统提示「禁止安装未知来源应用」，按提示允许「来自此来源的应用」再继续（不同品牌手机的叫法略有差异，一般在弹窗里直接给入口）；
3. 装完打开，首次启动会请求存储访问权限，必须允许，否则应用读不到你要传的文件；Android 11 及以上的系统如果装完在应用里看不到手机里的文件，到「系统设置 → 应用 → NS-USBloader → 权限」里允许「文件与媒体 / 管理所有文件」；
4. 能看到主界面（左侧是抽屉菜单、主区域是文件列表），就算装好了。

界面提供简体中文与繁体中文，都是早期版本就加进去的；深色主题在应用内可以切，也可以跟随系统。

## 五、对手机与系统的要求

官方资料标注手机版最低支持 Android 4.0，最高标注到 Android 11；在更新的系统上表现如何，官方没有给出明确清单，以官方发布页说明为准。硬件上二选一：要走 USB 方式，手机得支持 OTG（线和转接头怎么挑见[OTG转接头与数据线怎么选.md](OTG转接头与数据线怎么选.md)）；要走 WiFi 方式，手机得能和主机连进同一个局域网。

装完打不开、闪退，或者连不上主机，直接看[传输失败常见问题排查.md](传输失败常见问题排查.md)；想马上开始传文件，USB 方式看[USB连接传输完整步骤.md](USB连接传输完整步骤.md)，WiFi 方式看[WiFi网络传输设置.md](WiFi网络传输设置.md)。
