## 一、按现象对号入座

| 现象 | 最可能的原因 | 处理 |
| --- | --- | --- |
| 插上线手机毫无反应，只在充电 | 线或转接头不支持数据传输，或方向插反了 | 换一根确认能传数据的线；确认接法是「转接头接手机、数据线 Type-C 头接主机」 |
| 手机弹不出 USB 访问请求 | 主机端没先进安装程序的 USB 等待界面 | 先在 Switch 上打开安装程序并进入 USB 安装入口，再连线 |
| 允许了 USB 权限仍然识别不到 | 手机 OTG 功能被系统关闭，或转接头质量差 | 到系统设置里搜「OTG」确认开关是开的（部分品牌默认关闭） |
| 传到一半失败或卡死 | 手机或主机息屏；三星机型旋转 / 最小化了应用 | 关掉两台设备的自动休眠重传；三星手机传输期间别旋转、别切出去 |
| WiFi 方式怎么填 IP 都连不上 | 两台设备不在同一个网段，或路由器开了 AP 隔离 | 确认连同一个 WiFi；关掉访客网络 / AP 隔离再试；逐位核对 IP |
| 应用里选文件时列表是空的 | Android 11 及以上系统的存储权限没给全 | 系统设置 → 应用 → NS-USBloader → 权限，允许「文件与媒体 / 管理所有文件」后重进应用 |
| 网络方式速度很慢 | 2.4GHz 频段拥挤、距离远 | 手机换连 5GHz、离路由器近一点；大文件优先走 USB 有线 |
| 提示存储空间不足 | 手机剩余空间小于待传文件 | 清出比文件本身更大一些的空间再传 |
| 显示已上传，主机上却没有游戏 | 不是故障——「已上传」只代表手机侧发送完成 | 去主机上安装程序的界面看安装结果 |

## 二、三个最容易误判的点

**「已上传」不等于「已安装」。** 应用列表里显示成功，只是说文件从手机发出去、传输过程没出错；装没装上、装到哪一步，全部以 Switch 屏幕上安装程序的界面为准。主机端报的错（比如文件校验不通过）手机上是看不到的。

**息屏是头号杀手。** 大部分「传着传着就断了」最后都归结到某台设备息屏了。开始传输前把两台设备的自动休眠暂时关掉，是成本最低的预防措施。

**进度慢不等于卡死。** GB 级文件的 USB 直传通常要几分钟（有用户实测速度在每秒 30 MB 上下，受主机端接口限制），进度条走得慢是正常现象，别当成卡死去拔线，一拔就前功尽弃。

## 三、都试过还不行

先换线、换 OTG 转接头——这条链路上线材的嫌疑远大于软件设置，怎么挑、怎么验证见[OTG转接头与数据线怎么选.md](OTG转接头与数据线怎么选.md)。软件侧能核对的有两处：一是应用左上角菜单里选的安装程序类型，必须和主机上实际打开的那个一致（主机开的是 Awoo，手机里就不能选 GoldLeaf）；二是用 GoldLeaf 时确认主机上装的是 v0.5，手机版只认这一个版本。

排查完确认是文件本身的问题（比如主机端提示文件不完整），重新准备一份源文件再传，比反复重试更省时间。
