## 一、适用范围先划清

网络方式只对 Awoo Installer / TinFoil 这一类支持「网络安装」的安装程序有用；GoldLeaf 不支持网络方式，要用 GoldLeaf 就走 USB 线。

前提只有一条：手机和 Switch 在同一个局域网里。连同一个路由器的 WiFi 即可；如果手边没有路由器，让 Switch 连手机开的热点也满足「同一个网」这个条件，传输走的是局域网通道。

## 二、设置与传输步骤

1. 手机和 Switch 连进同一个 WiFi；
2. 在 Switch 上打开 Awoo Installer，选「通过局域网或互联网安装」（Install over LAN or internet）这类入口，屏幕上会显示主机的 IP 地址，把它记下来；
3. 手机上打开 NS-USBloader，从左上角菜单进设置，把刚才记下的 IP 填进「NS IP」一栏；
4. 回到主界面，选择要传的文件；
5. 点上传，主机端确认后开始安装。

填 IP 时逐位核对。如果应用开着「始终校验 NS IP 输入」之类的选项，格式不对它会当场提醒。

## 三、连不上或速度慢时的几个变量

- **确认两台设备真的在同一个网段**。有些路由器的 2.4G / 5G / 访客网络互相隔离，设备分别连在不同子网里就互相找不到；
- **路由器开了 AP 隔离或访客网络**时，设备之间无法互访，怎么填 IP 都连不上，关掉再试；
- 手机连 5GHz 频段、离路由器近一点，速度会明显好于 2.4GHz 或隔墙使用；
- 传大文件时，USB 有线通常比 WiFi 稳。环境差、又赶时间的话，直接换[USB连接传输完整步骤.md](USB连接传输完整步骤.md)里的有线方式。

传输结果同样以主机端安装程序的界面为准——手机侧显示发送完成，主机上可能还在写数据。各种「看起来不对劲」的现象，统一对照[传输失败常见问题排查.md](传输失败常见问题排查.md)排查。
