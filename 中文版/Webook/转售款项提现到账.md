## 一、钱先落在钱包里

票在平台内卖出后，钱不会直接打进你的银行卡，而是先进你账号的**钱包（Wallet）**。想拿回银行卡，要再做一步**提现（claim）**。这两步是分开的：**卖出 ≠ 到账**，忘了第二步钱就一直躺在钱包里。

## 二、提现的硬性条件

官方帮助中心列了几条，提不出来基本都是踩了其中一条：

- **受益人姓名**要按银行账户上的写法、**用英文**填；
- **IBAN（银行账号）数字之间不要留空格** —— 这是被卡住的高频原因；
- 应用要**更新到最新版本**，旧版可能没有该功能或提交失败；
- **最低提现金额 50 沙特里亚尔（SAR）**，低于这个数提交不了；
- 提现需要**沙特境内银行账户**；到账时间官方口径约 **14～21 个工作日**（以页面当时显示为准）。

## 三、哪些钱提不出来

一条容易踩的规则：**你自己用银行卡充进钱包的钱不能提现** —— 那部分余额只能用来买票。能提的只有**转售票卖出后进来的钱**。所以别为了「凑提现」往里充钱，充进去就只能消费掉。

## 四、卖票到拿钱的完整链路

1. 挂票出售（步骤见 [门票转售与退款规则.md](门票转售与退款规则.md)）；
2. 有人买下 → 原票作废、买家拿新票 → 款项进你的钱包；
3. 到钱包里发起提现，按第二节填受益人姓名、IBAN、金额；
4. 等待到账，着急或超过时限没到 → 拿投诉编号找客服，见 [联系客服与投诉处理.md](联系客服与投诉处理.md)。

## 五、提不出来时按这个顺序排查

| 现象 | 先检查 |
| --- | --- |
| 提交按钮提交不了 | 金额是否 ≥ 50 SAR；应用是否最新版 |
| 提示受益人信息不对 | 姓名是否按银行账户英文写法填 |
| 一直失败 | IBAN 数字间是否混进了空格 |
| 想提的其实是自己充的钱 | 那部分提不了，只能买票 |
| 以上都对还是没到账 | 带上时间与截图走投诉，24～48 个工作小时回复 |
