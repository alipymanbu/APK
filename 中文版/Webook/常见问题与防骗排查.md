## 一、高频问题速查

| 问题 | 原因与处理 |
| --- | --- |
| 买了票但账户里没有 | 退出重登，确认用的是**购票时那个邮箱**；仍没有就别重复付款，去帮助中心提问 |
| 活动显示售罄 | 走活动页的**转售市场入口**（订票按钮下方），或隔段时间刷新等回流票 |
| 转赠的票对方收不到 | 让发送方核对填写的邮箱；接收方进「预订 → 右上角三点 → 发送/接收记录」查看 |
| 付款后多久出票 | 正常情况下付款完成即进账户；长时间没有按上一行处理 |
| 转售按钮是灰的/没有 | 该活动未开启转售，票面上不会有 Resell 选项 |
| 想退票 | 退款资格取决于活动与主办方，看活动页条款，详见 [门票转售与退款规则.md](门票转售与退款规则.md) |

官方帮助中心在 [wbk.zendesk.com](https://wbk.zendesk.com)，有按「预订 / 门票 / 退款与改期」分类的文章，支持英文与阿拉伯文。

## 二、买票只认三个入口

官方对「从哪买票」的口径很绝对 —— 只有三个地方，别处买的票平台不担责：

1. **官网** [webook.com](https://webook.com) —— 地址栏必须是它，建议存书签从书签进，别用搜索结果点；
2. **官方应用** —— App Store / Google Play / 华为应用市场的官方上架（装法见 [下载与安装教程.md](下载与安装教程.md)）；
3. **主办方、艺人、场馆发的官方链接** —— 最终会跳回 [webook.com](https://webook.com)，跳到别处一律当未经验证处理。

## 三、这些卖票方式都是坑

- **社交账号卖票**：Instagram、X、TikTok、Snapchat、Facebook 上「加我出票」的私信 —— 平台验不了、也管不了；
- **聊天群交易**：WhatsApp、Telegram 群里承诺「保真」「有内部票」「能升 VIP」的；
- **仿冒网站**：域名只差一两个字符、页面做得像模像样的假站；
- **「先付款后转票」**：发截图、发 PDF、说「你付了我再转给你」—— 截图谁都能做；
- **付费搜索广告冒充官网**：搜出来的第一条未必是真站，自己敲地址更稳；
- **站外高价转卖**：把票价炒到数倍的第三方转售站，没有任何票源验证。

## 四、付款前三十秒自查

1. 地址栏就是 `webook.com`，没有多余字符、没有连字符、没有奇怪子域；
2. 这场活动在**官方应用或官网里能搜到** —— 平台上没有的 listing 就不是真的；
3. 价格与官方标价差不多 —— 大跳水和大加价都是信号；
4. 对方在**催你**：「只剩一张」「5 分钟内决定」「马上转」—— 典型话术；
5. 没有人要求你**在平台外付款**：银行转账、加密货币、礼品卡都不该出现在买票里；
6. 对方**拒绝走平台的转赠/转售工具** —— 不肯走平台，本身就是理由。

## 五、这些东西永远不该给

任何自称卖家、主办方或平台客服的人，只要开口要下面任何一项，立刻停止对话并举报：

- 手机或邮箱收到的**一次性验证码（OTP）**；
- 你的**账号密码**；
- 身份证、护照的**照片**；
- 付款截图、**完整卡号、CVV**；
- 邮件或短信里的**验证代码**。

补充两条常识：**截图不是票**（票只存在于你的账户里）；**入场可能要核对证件姓名**，所以注册时姓名要按证件填，见 [注册登录与账号要求.md](注册登录与账号要求.md)。

## 六、感觉不对劲时

怀疑遇到假站或假卖家，先把链接、账号、listing 截下来，别付款；已经付了钱的，保留记录并尽快通过官方渠道求助。规则性的提醒可以记这一条：**五分钟的犹豫，比五个月的后悔便宜**。
