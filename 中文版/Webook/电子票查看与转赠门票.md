## 一、票在哪

付款成功的票不会以「附件」形式发给你 —— 邮件只是确认，**真正的票在应用里**：

1. 用购票时那个邮箱登录应用；
2. 点底部的「预订 / Bookings」图标；
3. 找到对应的订单，票就在里面。

入场当天提前打开这一页出示即可。特别提醒：**邮件确认不等于票，截图也不等于票** —— 官方口径是票只存在于你的账户里，验票时以应用内打开的票为准。

## 二、把票转赠给朋友

同行的人没买着票、或者你想把票给家人，用应用内的发送功能，不要发截图：

1. 登录后进入底部「预订 / Bookings」；
2. 选中要送出的那张票，点 **send（发送）**；
3. 填收件人的信息：**姓名 + 邮箱**，一个字都别错；
4. 点 **Send Ticket** 确认发送。

对方必须用**你填的那个邮箱**注册/登录的账号才能收到 —— 这是最常见的失败原因：邮箱拼错一个字母，票就进了查不到的地址。

## 三、对方怎么接收

收到票的一方这样操作：

1. 用自己（也就是你填写时用的那个）邮箱登录应用；
2. 进入底部「预订 / Bookings」；
3. 点右上角的**三点图标**，选择 **sending/receiving history（发送/接收记录）**；
4. 在记录里对收到的票选择**接受或拒绝**。

如果按上面走完还是看不到票，先让发送方核对一下填写的邮箱是否与你登录的邮箱完全一致 —— 官方帮助中心对这种情况给的排查建议就是这一条。

## 四、发出去的票想撤回

官方帮助中心有一篇「如何取消已发送门票」的条目，撤回入口就在同一块发送/接收记录里。具体按钮位置以你应用内的实际界面为准；如果已经显示被对方接受，就走转赠之外的另一条路 —— 转售，规则见 [门票转售与退款规则.md](门票转售与退款规则.md)。

## 五、几个容易混淆的点

| 情况 | 正确理解 |
| --- | --- |
| 收到了确认邮件 | 邮件是订单确认，票仍要在应用里看 |
| 把票的截图发给朋友 | 截图不能当票用，必须走应用内发送 |
| 对方说没收到 | 核对邮箱 → 让对方登录后看发送/接收记录 |
| 活动去不了了 | 能转赠就转赠，活动开了转售就转售，见 [门票转售与退款规则.md](门票转售与退款规则.md) |

转赠和转售的区别一句话：**转赠是送人（不涉及钱），转售是卖掉（平台内交易、原票作废新票重签）**。选哪个看你需不需要把钱拿回来。
