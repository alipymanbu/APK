## 一、先核对这份安装包的信息

GDevelop 是一款免费开源的无代码游戏引擎，手机版让你直接在安卓设备上做 2D/3D 游戏并导出成品。下表是网盘里这份安装包的实际信息，与网上官方商店展示的最新版本号可能不同：

## 二、从哪里拿到安装包

官方渠道是 [Google Play](https://play.google.com/store/apps/details?id=io.gdevelop.ide)，国内设备多数装不了 Play 商店，这时走网盘转存更省事：

1. 复制本篇头部的 GDevelop 安装文件资源链接；
2. 在夸克网盘 App 或电脑客户端里打开该链接；
3. 把文件**转存到自己的网盘**，再从网盘下载到手机存储。

转存后文件归你自己，后续不会再受分享链接变动影响。

## 三、安装步骤

1. 在手机上找到下载好的 APK 文件，点它开始安装；
2. 系统若提示「禁止安装未知来源应用」，按提示允许该来源后继续（不同品牌设置入口不同：小米在「更多设置 - 开发者选项」附近，原生系统在安装弹窗里直接给开关）；
3. 等待安装完成，首次启动需要联网加载内容。

## 四、安装前校验 MD5（可选但建议）

校验能确认文件在传输中没损坏。两种常用做法：

- **在电脑上校验**：把 APK 复制到电脑后打开 PowerShell 或 CMD，执行：

  ```powershell
  certutil -hashfile "GDevelop_v1.0.257.apk" MD5
  ```

  输出的哈希与上面表格里的 MD5 逐字一致即可。

- **在手机上校验**：用支持哈希计算的文件管理器查看 APK 的 MD5 值再比对。

## 五、装不上或打不开怎么排查

| 现象 | 处理办法 |
| --- | --- |
| 提示「解析包出错」 | 文件多半没下完整，重新从网盘下载一次，或先核对 MD5 |
| 安装到一半失败 | 确认手机剩余存储大于 200M；关掉安全类软件的「安装拦截」再试 |
| 打开就闪退 | 安卓版本过低的设备可能不被这版支持，确认系统满足上面的要求 |
| 打开后一直加载 | 界面内容需要联网获取，检查网络或换网络环境再开 |
| 转存时提示链接失效 | 分享链接可能被更新，从本篇头部重新复制最新链接 |

装好后先做的事是注册或登录账号——云项目、导出打包都挂在账号上，具体见[注册登录与云同步](注册登录与云同步.md)。
