## 一、哪些功能离不开账号

不登录也能打开应用看界面，但下面这些操作都要求登录：

- 新建项目并保存为**云项目**（手机版的项目默认存云端）；
- 导出打包（安卓 APK/AAB、桌面版、网页版都在线完成）；
- 发布游戏到官方平台 [gd.games](https://gd.games)；
- 同一个项目在手机、电脑、浏览器之间接力编辑。

账号免费注册，注册入口在应用内首次启动的欢迎页或个人页。

## 二、注册与登录步骤

1. 打开 GDevelop，点「注册 / Sign up」；
2. 输入邮箱并设置密码（部分时期也提供第三方登录按钮，以应用内当时显示为准）；
3. 到邮箱里点验证链接完成激活；
4. 回到应用登录，右上角头像显示你的账号即成功。

已有账号直接点登录，手机与电脑用同一账号，云项目会自动出现。

## 三、云项目怎么同步

| 场景 | 你需要做的 |
| --- | --- |
| 电脑上做到一半，想在手机上继续 | 电脑端保存为云项目，手机端打开项目列表即可看到 |
| 手机上新建的项目想在电脑上改 | 手机保存后，在电脑版或网页版 [editor.gdevelop.io](https://editor.gdevelop.io) 登录同一账号打开 |
| 改动没出现在另一台设备 | 确认另一端刷新了项目列表；云端保存需要联网，离开页面前等保存完成 |

免费账号的云项目数量有限制（截至 2026-09 为 3 个），更多额度见[免费版限制与订阅方案](免费版限制与订阅方案.md)。

## 四、注册或登录异常的处理

| 现象 | 处理办法 |
| --- | --- |
| 收不到验证邮件 | 检查垃圾邮件与广告邮件分类；等 5 分钟再试；换一个常用邮箱重新注册 |
| 提示邮箱已被注册 | 说明之前注册过，直接走「忘记密码」重置后登录 |
| 登录一直转圈 | 切换网络环境（Wi-Fi 与流量互换）再试；部分网络对海外服务访问不稳定 |
| 密码总是不对 | 用「忘记密码」重置；注意输入法是否自动首字母大写 |
| 登录成功但项目列表为空 | 确认登录的是同一个注册邮箱，换错账号是最常见原因 |

登录成功后建议从官方示例新建一个项目练手，路线见[新手做第一个游戏](新手做第一个游戏.md)。
