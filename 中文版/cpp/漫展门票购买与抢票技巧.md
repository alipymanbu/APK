## 一、结论先说

COMICUP 的门票基本靠抢：开票时间一到，热门票种几分钟内售罄，现场不售票。你要做的准备就三件——**提前装好 CPP 并完成注册答题、提前录入购票人实名信息、开票前 10~15 分钟进到购票页面等**。这三件任何一件没做，抢到的概率都会大幅下降。

## 二、票在哪买

| 渠道 | 说明 |
| --- | --- |
| CPP 客户端 | 官方主渠道，票种最全；往届经验是 VIP 票、双日套票这类特殊票种只在 CPP 上卖 |
| 无差别同人站官网 [`www.allcpp.cn`](http://www.allcpp.cn) | 网页端同一套账号体系，可以作为备胎 |
| 哔哩哔哩会员购 | 部分届次的门票同时在 B 站发售，普通票居多 |

具体哪届在哪些渠道放票、几点开抢，以当届官方公告为准（官方会通过应用内公告与官方微博发布）。一个常用策略是分兵：一个人守 CPP、一个人守 B 站，哪个崩了另一个还活着——开票高峰把服务器挤爆是常事。

## 三、开票前几天：把弹药备齐

1. **注册 + 答题成为正式会员**（流程见 [下载与安装教程.md](下载与安装教程.md) 第四节）。没完成答题的账号在购票环节会被卡住。
2. **录入购票人信息**：「我的」→「票单」→ 右上角「购票人管理」→ 点「+」逐个添加姓名与身份证号。
   - 一个账号可以同时买多份票（往届规则常见为最多 4 人份），但**必须把每个同行人的身份信息都提前录进去，并在下单时逐一勾选**——只勾了你自己的信息，多买的票别人也用不了。
   - 购票需要实名，下单后不支持更换身份证信息，同一票种通常按身份证限购，录错等于白抢。
3. **确认支付方式可用**：微信/支付宝余额或银行卡限额提前检查，别卡在最后一步。
4. **登录状态保持**：开票前重新打开一次应用，确认还登着、验证码能正常收到。

## 四、开票当天：抢票流程

1. 提前 10~15 分钟进入该展会的购票页面，别掐点进——进场本身就要加载。
2. 界面上先预选好购票人。
3. 时间一到，点「立即购票」，选中目标票种与日期，果断提交进入支付。
4. 高峰期常见两种表现：
   - **一直点「立即支付」没反应**：只要购票人信息刷出来了，就留在当前页反复点，别退出去重进——退出去队列就没了。
   - **提示「请求过于繁忙」或通道拥挤**：这往往说明你已经挤进去了，继续重试，跳到支付页就算抢到。
5. 没跳转也不要放弃，去「票单」→「待付款」里刷订单。开票高峰订单生成有延迟，几分钟后再进去可能就看到一张待付款订单了。
6. **看到订单立刻付款。** 待付款订单超时会自动取消（往届规则是 10~40 分钟不等，以页面提示为准），很多人票抢到了、忘了付，白忙一场。
7. 付款成功后订单可能短暂显示「待付款」，系统状态更新慢，稍等刷新即可，以实际支付记录为准。

**几条提高命中率的细节**：

- 开抢前把支付方式绑好免密/指纹支付，输密码比刷脸慢几秒，高峰时几秒就是有票和没票的差别。
- 提前进到购票页后每隔几分钟在页面里做一次轻交互（切一下标签），防止会话过期被踢出；但**不要高频疯狂刷新**，可能触发风控验证反而更慢。
- 首轮没抢到别走：**没付款的订单会在开票后 5~15 分钟集中超时释放**，这是第一波捡漏窗口；开展前 1~3 天的退票高峰是第二波，隔几分钟刷一次票单页。

## 五、防骗：抢票焦虑是最好的钓鱼饵

- 只在官方渠道购票（CPP、官网、当届公告写明的平台）。任何「内部票」「代抢成功再付钱」都不要碰——实名制下票绑身份证，代抢拿走你的身份证号和验证码，风险远大于收益。
- **验证码永远不发给任何人**：那是你账号的最后一道锁。
- 支付环节若页面突然跳去要你输银行卡密码或短信验证码的陌生页面，直接关掉。
- 付款异常（扣了款却查不到订单）先截图保存支付记录，再走应用内客服申诉，处理路径见 [门票退票规则与手续费.md](门票退票规则与手续费.md) 第四节。

## 六、入场那天注意什么

- **带身份证原件**：往届均要求刷身份证 + 人脸识别入场，证件信息必须与购票实名信息一致。
- **特殊装扮（Cos 等）要提前在应用内登记**，逾期未登记或未过审只能常服入场——着装要求、登记截止与禁带道具单独一篇讲透：[特殊装扮登记与入场须知.md](特殊装扮登记与入场须知.md)。
- 电子票在应用内「票单」里查看，进场馆前把票单页提前打开，现场网络拥挤时打不开就尴尬了（提前收藏/离线的用法见 [逛展清单与离线场地图用法.md](逛展清单与离线场地图用法.md)）。
- 现场不售票，线上售罄后官方会发公告、一般不再增售，别抱现场捡漏的期望；停止检票时间以当届公告为准。
