## 一、先分清三个概念

在 CPP 里摆摊要走三步，各是什么：

| 概念 | 是什么 |
| --- | --- |
| 新刊 | 你创作的一本同人本（漫画、画集、小说册子等），是被审核的最小单位 |
| 社团 | 摊位的主体，一个社团申一个摊；你创建社团，或加入别人创建的社团 |
| 申摊 | 社团对某届展会提交摊位申请，被主办方审摊通过后才能参展 |

关键规则：**摊位申请是以社团为单位提交的，而作品要先成为「参展本子」才能被勾进申请里**。所以顺序永远是：发新刊 → 关联本子到社团 → 勾选本子申摊。

## 二、发新刊：把作品传上去

1. 应用内上排导航栏选择「发新刊」。
2. 完善本子信息：书名、作者、简介、封面与内页图片、定价等，按页面要求填全。
3. 提交后本子进入你的名下，等待后续关联。

如果你**就是社团创建者**：到「活动管理」→「可申摊活动」，直接勾选这本新刊参与该展会即可。

如果你**不是社团创建者**（在别人的社团里搭摊）：要走「寄卖」把本子寄到你参展的社团——

1. 在本子列表勾选需要参展的本子，选「批量寄卖」；
2. 输入社团名或社团 ID 搜索并勾选目标社团，「确认发送寄卖请求」后在弹窗里点「确定」；
3. 等社团创建者处理：对方在「寄卖管理」→「收到的寄卖委托」里勾选并确认；
4. 确认后本子关联到该社团，本子页面会显示参展信息，社团主催就能把它勾进申摊了。

寄卖这一步卡在对方确认上是常见堵点——提交完请求记得去催一下社团主催，别等到申摊截止才发现没关联上。

## 三、申摊：提交摊位申请

**先过资料关**。往届规则里，社长的【个人信息】必须完成四件事：**实名认证、绑定手机号、绑定邮箱、填写 QQ 号**。缺任何一项，点申请摊位时系统都会提示「您的个人资料尚未完善」——所以开申前先把这四样补齐，别卡在第一步。

**再过数量关**。能申请几个摊位，取决于你关联到本社团的同人志数量（往届 CP30 规则）：

| 申请摊位数 | 关联同人志至少需要 |
| --- | --- |
| 第 1 个摊 | 1 本 |
| 第 2 个摊 | 3 本 |
| 第 3 个摊 | 6 本 |
| 第 4 个摊 | 10 本 |

每个摊位含 2 张参展证；申请数与最终过审数可能不一致，以过审结果为准。所有展品须遵守社区规则与《零盗版宣言》，每个摊位至少提交一件完整作品集（具体以当届《活动参展说明》为准）。

**然后正式提交**：

1. 展会开申后，进入该展会页面的摊位申请入口（全部由 CPP 在线申请，社团创建者操作）。
2. 勾选本社团要参展的本子，按要求填写摊位名、专区意向、连摊意向等信息并提交。
3. 等待主办方**审摊**——审核你的本子是否符合该展会的参展标准（同人创作、非盗版等）。
4. 过审后按公告要求缴费，缴费完成摊位才算锁定。

**小心熔断机制**。热门届次会因申请数量过多**提前截止申摊**：往届 CP32 的熔断线是单期申请社团达 5500 个时 48 小时内关闭、6500 个时 1 小时内关闭、7000 个时即刻关闭。通道一关无法补申，有意向就开申第一天提交。申摊通道关闭后摊位名会被锁定，无法自行修改。

费用没有统一价，每届不同：往届实例是 **220 元/摊/天**，且过审摊位需另缴押金（CP30 实例为摊位费的 50%）。**具体金额、押金、缴费截止时间一律以当届申摊公告为准。**

## 四、摊主的几个注意点

- **身份前提**：和买票一样，申摊操作也需要完成注册与正式会员答题，先把 [下载与安装教程.md](下载与安装教程.md) 第四节做完。
- **赶早不赶晚**：申摊和寄卖都有截止时间，审摊也有周期，压线提交一旦被退回没有补救窗口。
- **售罄与备货**：展会当天热门摊位开馆半小时内售罄很常见，本子页面的收藏数（游客点收藏）可以帮你估需求——游客侧的收藏玩法见 [逛展清单与离线场地图用法.md](逛展清单与离线场地图用法.md)。
- **摊位号在哪看**：审摊通过、出摊位图后，社团页面与本子详情页会显示摊位编号，游客也是按这个编号来找你的。
- **摊主证严禁出租、转让、买卖**：证件绑定了你的实名信息，往届规则是一经查实没收证件、不退押金、取消参展资格甚至公示违规信息；临时无法参展要走官方指定渠道退摊，别私下转手。摊主证的补证与实名绑定都有截止时间，开申后一并留意。
- **你自己也要买票**：摊主不等于免票，往届均需购票入场，抢票流程见 [漫展门票购买与抢票技巧.md](漫展门票购买与抢票技巧.md)；如果当天还要 Cos，着装登记见 [特殊装扮登记与入场须知.md](特殊装扮登记与入场须知.md)。
