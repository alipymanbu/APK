## 一、CPP 是什么，先确认你要装的就是它

CPP（全称「CPP 无差别同人」）是 COMICUP 同人创作交流展的官方客户端，由上海摩都文化传播有限公司开发。你用它做四件事：买漫展门票、提前收藏同人本生成逛展清单、摊主在线申摊、逛展当天用离线场地图找摊位。它同时收录全国各地同人展会信息，不只是 COMICUP 一个展。

装之前核对这三个事实，避免装错应用：

| 项目 | 值 |
| --- | --- |
| 包名 | `cn.comicup.apps.cppub` |
| 开发商 | 上海摩都文化传播有限公司 |
| 本文对应的安装包 | 版本 3.26.4，大小 68.90M，MD5 `992a24914a2fb52277f7fa287706e9c8` |

同一台手机上如果已经装过一个「CPP」，先到系统设置的应用详情里看包名是不是 `cn.comicup.apps.cppub`——搜「CPP」会搜出一堆名字相近的社交软件，包名对不上就不是这个。

## 二、安装包从哪拿

三个来源，按情况选：

1. **夸克网盘**：[CPP 安装文件资源（夸克网盘）](https://pan.quark.cn/s/625d01af9f70)，转存后下载 `cpp_v3.26.4.apk` 即可。这份包是 3.26.4 版（68.90M），下载后可对照上面表格的 MD5 核对文件是否完整。
2. **官方网站**：无差别同人站 [`www.allcpp.cn`](http://www.allcpp.cn)，页面上通常有客户端下载入口，版本以官网当时显示为准。
3. **苹果手机**：App Store 搜索「CPP 无差别同人」，应用是免费的，iOS 版与安卓版功能对齐。

网上第三方下载站给的版本号常常比 3.26.4 新（检索时能看到 3.26.9），那是官方后续更新，与网盘里这份不是同一版；你需要哪一版自己定，本文涉及版本号的事实一律以上表为准。

## 三、安卓安装步骤

1. 把 `cpp_v3.26.4.apk` 从网盘下载到手机（或先下到电脑再传过去）。
2. 点击文件开始安装。系统若弹出「禁止安装来自此来源的应用」，是安装未知来源应用的常规提示——到设置里允许本次安装即可，装完可以再关掉。
3. 装完打开，首次启动会请求网络、通知等常规权限，按需授予。
4. 安装失败先查三样：存储空间是否够（安装包 68.90M，安装后占用更多）、下载的文件是否完整（对照 MD5）、手机系统版本是否过旧。仍然失败就重新下载一次包再装。

## 四、注册与答题：成为正式会员

CPP 的账号体系有一道门槛：注册完还要**答题**才能成为正式会员，购票、申摊等操作都建立在正式会员身份上。

1. 打开应用，首屏点「注册」，用手机号加验证码注册。
2. 注册完成后点「答题」，题目是关于同人圈与平台规则的常识题。
3. 答完点「提交」，通过后即成为正式会员。
4. 以后登录同样走手机号 + 验证码，换手机登录不受限制。

答题本身不难，但别随便乱填——这是你后面抢票、申摊的前置条件，正式会员身份没生效，开票当天再想起来就晚了。建议装好应用的当天就把注册和答题做完。

## 五、装好之后先做两件事

- **录购票人信息**：「我的」→「票单」→ 右上角「购票人管理」，把你自己（姓名 + 身份证号）先填进去；要帮朋友买票，朋友的信息也要提前录。这一步直接决定抢票当天的速度，详见 [漫展门票购买与抢票技巧.md](漫展门票购买与抢票技巧.md)。
- **逛一遍收藏功能**：看到心仪的同人本点收藏，展会当天的采购清单就靠它，用法见 [逛展清单与离线场地图用法.md](逛展清单与离线场地图用法.md)。

## 六、打不开、闪退、收不到验证码

| 现象 | 排查顺序 |
| --- | --- |
| 打不开 / 白屏 | 先确认网络能正常上网；再看手机存储是否快满（缓存写不进去会卡在启动页） |
| 闪退 | 清理后台重试；到系统设置里清一次应用缓存；再不行就卸载重装（账号数据在服务端，重装不丢） |
| 验证码收不到 | 检查手机短信拦截；换网络环境重试；确认手机号没输错 |
| 安装包解析失败 | 文件没下完整，重新下载并核对 MD5 |

以上都试过仍不正常，用应用内客服入口反馈，或发邮件到官方客服邮箱 `cpp@comicup.cn`（邮箱地址以官方页面显示为准）。
