# Touchie 打不开、闪退、连不上怎么排查

## 一、先分清你遇到的是哪种

Touchie 的回复由服务器实时生成，所以它的故障面比普通本地应用多一层：除了应用本身的问题，还有网络与服务端。按下表对号入座：

| 症状 | 更可能的原因 | 直接跳到 |
| --- | --- | --- |
| 安装时被拦、提示解析错误 | 权限或安装包不完整 | 第三节 |
| 打开就闪退、白屏 | 应用数据异常、系统过旧、存储不足 | 第三节 |
| 能打开，但页面一直转圈 | 网络不通、服务端故障 | 第四节 |
| 能聊天，发消息后一直等不到回复 | 网络不稳、服务端繁忙 | 第四节 |
| 以上全试过都不行 | 版本问题或个案 | 第五节 |

## 二、先做这两步（最常见）

1. **完全关闭再打开**：从后台划掉 Touchie 再启动，别只是按 Home 键退回桌面 —— 应用其实还在后台挂着旧状态。
2. **重启手机**：清掉临时故障，官方支持文档（realme、vivo、华为）都把它列在最前。

多数「突然打不开」到这一步就好了；不行再往下。

## 三、闪退 / 装不上的排查

按顺序做，每做一步试一次：

1. **清缓存**：长按 Touchie 图标 → 应用信息 → 存储占用 → **清除缓存**。注意先只清缓存 —— 「清除数据」会把登录状态和本地数据一起抹掉，缓存没用再考虑。
2. **检查权限**：设置 → 应用管理 → Touchie → 应用权限，把存储、设备信息等所需权限打开。
3. **清出空间**：手机存储快满时应用容易异常，删掉不用的大文件再试。
4. **升级系统**：设置 → 系统升级，保持系统为最新；官方未公布 Touchie 的最低安卓版本，系统过旧是闪退的常见原因。
5. **卸载重装**：最后一招。卸载会清掉本地数据 —— 在意聊天记录的话，重装前先确认记录是否随账号恢复，重要对话自己留存一份。安装包重新拿一份即可：[Touchie 安装文件资源（夸克网盘）](https://pan.quark.cn/s/52301487fef1)，装完核对版本 1.2.2、包名 `com.touchie.ai`（见 [下载与安装教程.md](下载与安装教程.md) 第二节）。
6. **是不是版本的问题**：如果闪退是更新后才出现的，很可能是新版本引入的异常 —— 换回手头可用的旧包先用着，等新版再升。

## 四、连不上 / 回复等不到的排查

- **换网络试**：Wi-Fi 切移动数据（或反过来）。家里路由异常而手机没事，是最常见的一种。
- **关掉省流量与后台限制**：部分手机的「省流量模式」「禁止后台联网」会掐掉应用的请求。
- **关掉 VPN / 私人 DNS 再试**：它们有时会让请求发不出去或超时。
- **看是不是全体故障**：你自己网络没问题、页面一直转圈 —— 可能是服务端临时故障。隔十几分钟再开一次，恢复了就不用折腾手机。
- **咖啡店、机场这类 Wi-Fi**：要先在浏览器完成门户认证，没认证前应用连不出去。

## 五、都不行时找官方

发邮件到 **support@touchieai.com**，把这些信息一次给全，能省一轮来回：

- 机型与安卓系统版本；
- Touchie 版本号（设置 → 应用管理里看，网盘这份是 1.2.2）；
- 具体症状：闪退发生在哪一步、连不上时的报错原文；
- 你已经试过上面哪些步骤。

客服邮箱与入口见 [账号注销与常见问题.md](账号注销与常见问题.md)。另外，找角色、聊天过程中的操作类疑问（不是故障），看 [怎么找角色开始聊天.md](怎么找角色开始聊天.md) 和 [自定义角色与主控设定.md](自定义角色与主控设定.md)。
