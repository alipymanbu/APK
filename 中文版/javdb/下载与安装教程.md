## 一、先确认你要装的是哪一份

javdb 是安卓端的移动观影应用：手机、平板、电视盒子这类安卓设备都能装，iPhone 装不了。公开渠道页对这个应用的写法不统一（有写「javdb」的，也有写「JavDB影视」的，版本号标得也各不相同），你手里要对的始终是**网盘里这一份**。

网盘里这份包的参数（记录日期 2026-09-23），装之前先对一遍：

| 项目 | 数值 |
| --- | --- |
| 版本号 | 2.1 |
| 包名 | `com.aiyouxiba.wzzc` |
| 安装包大小 | 12.63M |
| MD5 | `811492776C42105AA3451B7CD2091439` |
| 系统要求 | 记录标注「安卓 5.2 以上」（公开版本号里没有 5.2 这个节点，实际以能否装上为准） |

包名 `com.aiyouxiba.wzzc` 是安卓系统识别应用的唯一标识，比显示名可靠 —— 核对时认包名，别只看图标和名字。

## 二、从网盘拿到安装包

1. 打开 [javdb 安装文件资源（夸克网盘）](https://pan.quark.cn/s/edf25c10b159)，把分享内容转存到自己的网盘（转存后不怕分享失效；不转存也能直接下载）。
2. 网盘里的应用文件夹名是 `javdb（先保存再下载）`，APK 文件名形如 `javdb_v2.1.apk`，旁边还有一份说明 txt。
3. 用手机上的夸克 App 登录同一账号直接下最顺手；想装电视盒子，在电脑上下载再传过去也可以。
4. 下载完看大小是否接近 12.63M，明显偏小说明没下完整，重下一次。要校验完整性，把 APK 传到电脑算一遍 MD5，结果应当是 `811492776C42105AA3451B7CD2091439`；对不上就别装。

转存完找不到文件、提示空间不足，或者下载速度让人着急的，一般是网盘端的问题：换个网络重试、或先在电脑端下载再传，都能绕过去。

## 三、手机上安装步骤

1. 用文件管理器点开 `javdb_v2.1.apk`，系统会弹「禁止安装来自此来源的应用」—— 这是标准安全拦截，不代表文件有问题。按提示进入设置，允许安装来自此来源（有的机型叫「未知来源」）。
2. 部分机型还会弹 Play Protect 扫描提示，包是你自己从网盘拿的，选「仍然安装 / 继续安装」即可。
3. 返回继续安装，等进度走完点「打开」。
4. 首次启动按提示同意用户协议与隐私政策后进首页；首页列表要联网加载，建议第一次在 Wi-Fi 下进。

电视盒子上装法相同：把 APK 拷进 U 盘插到盒子，用自带文件管理器或当贝市场这类工具的「本地安装」打开即可。装不上、报「解析包出问题」「安装失败」的，按文案分型处理，见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 四、装完核对：确认没装错

到 **设置 → 应用 → 找到 javdb → 应用信息**，看三项：

- 版本号应显示 `2.1`；
- 包名应为 `com.aiyouxiba.wzzc` —— 部分机型在这一屏或「更多」里直接显示包名，不显示的机型就跳过这条，改用版本号 + MD5 判定；
- 来源是你自己网盘里下的文件，而不是来路不明的应用商店。

三项都对，装的就是网盘这一份。装好之后怎么搜片、怎么调画质，接 [怎么搜索与播放影片.md](怎么搜索与播放影片.md)；想看电视直播，看 [电视直播怎么看.md](电视直播怎么看.md)。

## 五、以后有新版怎么更新

javdb 是侧载装的应用，**没有应用商店那套自动提示更新**，升级就三步：

1. 回到网盘分享拿最新一份 APK（链接不变，还是同一个；网盘里文件名带的版本号就是当前这份的版本）。
2. 直接点新 APK 覆盖安装 —— 同一个包名（`com.aiyouxiba.wzzc`）覆盖装不用先卸载，观看记录会保留；先卸载再装则会把本机记录清掉。
3. 装完到 设置 → 应用 → javdb → 应用信息 看版本号，变了就是升上去了。

判断「有没有新版」没有固定周期：网盘这份的记录日期是 2026-09-23、版本 2.1，之后是否有新版本以网盘里当时显示的文件为准。装完打开就闪退、或升级后播放异常的，处理见 [常见问题与故障排查.md](常见问题与故障排查.md)。
