# Oopz 网页版麦克风权限设置

> 网页版进语音频道别人听不见你，多半是浏览器把麦克风权限拒了。本篇按浏览器给出重新打开权限的路径。

第一次进 [Oopz 网页版](https://web.oopz.cn/)的语音频道时，浏览器会弹麦克风权限请求；点了「不允许」，之后你在频道里就没有声音。重新打开的入口按浏览器分列如下，路径整理自官方帮助中心；浏览器更新后菜单可能微调，对不上时就进浏览器设置的「站点权限」里找「麦克风」。

## Edge

1. 点地址栏左侧的小锁，把「麦克风」改为「允许」。
2. 没有这一项就点小锁 → 「此网站的权限」 → 麦克风 → 允许。

## Chrome

1. 点地址栏左侧的设置按钮，打开「麦克风」开关。
2. 看不到就点设置按钮 → 「网站设置」 → 「隐私和安全」 → 麦克风 → 允许。

## Firefox

1. 点地址栏左侧小锁 → 「安全连接」。
2. 点「更多信息」 → 「权限」一栏 → 找到「使用麦克风」，取消勾选「使用默认设置」，再勾选「允许」。

## 360 极速 / 360 安全浏览器

进任意一个语音频道，网址栏右侧会出现一个**带红叉的摄像头图标**，点它 → 选「始终允许」 → 点「完成」。

## QQ 浏览器

1. 右上角三条横线 → 「设置」 → 「高级 > 安全与隐私」 → 「内容设置」。
2. 找到「麦克风」，选「当网站要求使用您的麦克风时询问您」。
3. 点「管理例外情况」，若有禁止 Oopz 网站的条目，点「X」删掉 → 完成。
4. 刷新 Oopz 页面重进语音频道，弹窗点「允许」。

## 搜狗浏览器

1. 右上角三条横线 → 「选项」 → 「安全设置」里的「安全与隐私」 → 「管理内容设置」。
2. 「麦克风」选「当网站要求使用您的麦克风时询问您」 → 「管理例外情况」，删掉对 Oopz 的禁止条目。
3. 刷新页面重进语音频道，点「允许」。

## Safari

右键地址栏 → 进入设置 → 点「麦克风」 → 改为「允许」（若选「询问」，下次进入语音频道时在弹窗里点允许）。

改完权限后刷新网页版再进频道试麦；还是没声音的话，按桌面端同一套思路继续查，见[麦克风没声音怎么解决](麦克风没声音怎么解决.md)和[调音台与语音设置](调音台与语音设置.md)。
