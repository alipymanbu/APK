# Oopz 麦克风没声音怎么解决

> 队友听不见你、试麦没反应、电流声、回声——本篇按现象给排查顺序，均对照电脑客户端操作。

语音没声音的原因无非四类：麦克风被关、模式不对、设备选错、硬件或驱动问题。先按第一节五步走，大部分情况当场解决；调音台各开关的位置见[调音台与语音设置](调音台与语音设置.md)。

## 一、队友听不见你：按这五步查

1. **麦克风开着吗**：看客户端左上角调音台的麦克风图标，关着就点开。
2. **音量是 0 吗**：鼠标悬浮到麦克风图标上出现音量条，确认没被拉到 0。
3. **是不是按键说话**：调音台上显示键盘图标 = 按键说话模式，必须按住快捷键麦克风才采集；右键调音台可切换为自由发言。
4. **设备选对了吗**：右键调音台 → 「语音设置」，检查麦克风下拉框选的是不是你正在用的设备；客户端启动后才插拔过设备的，重启客户端再试。
5. **试麦**：语音设置 → 「麦克风测试」 → 「开始试麦」，对着麦克风说话，看音量条动不动。

## 二、试麦音量条完全不动：输入断了

- 在语音设置里换其他输入设备试。
- 重新插拔麦克风，或换一个接口。
- 关闭 Windows 麦克风独占模式：控制面板 → 硬件和声音 → 声音 → 「录制」选项卡 → 双击你的麦克风 → 「高级」 → 取消「独占模式」。个别程序申请独占后，其他应用就用不了麦。
- 去 Windows「开始 → 设置 → 声音」，在输入设备里点「开始测试」，确认系统层面收得到声音；系统里就收不到，问题在驱动或硬件，不在 Oopz。

## 三、试麦有波动但队友听不到：输出断了

采集正常、播放有问题，按顺序查：

1. 输出设备列表里别选错扬声器 / 耳机。
2. 重新插拔耳机或换接口。
3. Windows「设置 → 声音」里对输出设备点「测试」，确认耳机出声。
4. 换一副耳机排除硬件问题。

## 四、电流声、声音糊

1. **先确认 AI 智能降噪开着**：右键调音台菜单里勾选。用声卡的注意：部分声卡自带降噪，与 AI 降噪冲突——关掉其中一个再听。
2. **把麦克风采样率降到 48000 Hz**：Oopz 目前最高支持 48000 Hz，声卡或高端麦克风常默认更高采样率，超出就会出电流声。路径：系统「设置 → 声音 → 更多声音设置 → 声音」，「录制」选项卡双击你的麦克风 → 「高级」 → 采样率选「2 通道， 16 位， 48000 Hz（DVD 音质）」，然后**重启 Oopz 客户端**。
3. 还不行，让对方检查**扬声器**采样率，方法与上面相同，调低后同样重启客户端。
4. 以上都试过仍不行，可能是耳机兼容问题，把「耳机型号 + 现象」发给客服反馈。

## 五、有回声

1. 右键调音台，确认「回声消除」是开启状态。
2. 检查频道里是否有人用**音响外放**：外放的声音会被他的麦克风再收一遍传回来。开黑全员用耳麦是最稳的做法。

## 六、系统声音被收进语音里

- 先看是不是自己用音响外放——改耳麦多数直接解决。
- 尝试启用 Windows「立体声混音」：桌面右键 → 个性化 → 主题 → 「高级声音设置」，在「录制」选项卡里右键「立体声混音」选启用。
- 用了带耳返的声卡：去声卡设置里关掉耳返再试。

## 七、还没解决

网页端用户先确认浏览器麦克风权限已允许（Edge / Chrome / Firefox / 360 / QQ / 搜狗 / Safari 的重新打开路径见[网页版麦克风权限设置](网页版麦克风权限设置.md)），再重复上面五步；桌面端仍不行的，去 [Oopz 帮助中心](https://help.oopz.cn/)按现象找对应专篇，或从里面联系客服。网络引起的卡顿、延迟是另一条线，见[语音卡顿延迟高怎么解决](语音卡顿延迟高怎么解决.md)。
