# Oopz 语音卡顿延迟高怎么解决

> 本篇讲 Oopz 语音卡、延迟高、屏幕共享不跟手时的排查顺序：先查本机网络，再查加速器冲突，最后调频道音质档位。

卡顿类问题九成出在网络：先确认是不是网络本身，再排加速器，最后才是频道档位。杂音、没声音属于另一条线，见[麦克风没声音怎么解决](麦克风没声音怎么解决.md)。

## 一、先确认是不是网络本身

用浏览器随便开几个网页看加载速度：

- 网页也慢 → 本机网络问题，跟 Oopz 无关，先修网络（重启路由、切换 Wi-Fi 与有线、手机端切 Wi-Fi 与流量对比）。
- 网页正常、只有 Oopz 卡 → 继续往下查。

## 二、加速器冲突

少数情况下，游戏加速器会把 Oopz 的连接强制代理，导致语音卡顿：

1. 关掉加速器后**重启电脑**，看延迟是否恢复正常。
2. 恢复后可以继续正常使用加速器；再开加速又卡，就找加速器软件的客服反馈，让他们把 Oopz 加进不代理的名单。
3. 装了多个加速器的，先卸载不用的——不同加速器并存本身就可能互相打架，把网速拖异常。

要给游戏本身加速时，可以不装第三方加速器：Oopz 电脑客户端自带游戏加速面板，入口、防掉线模式与校园网 / 网吧环境的开法见[内置游戏加速器怎么用](内置游戏加速器怎么用.md)。

## 三、把频道音质 / 延迟档位调低

频道档位对**全频道所有人**生效：音质越高、延迟越低，对每个人的网络要求就越高。有「管理频道」权限的人可以这样调：

1. 右键语音频道 → 「编辑频道」。
2. 点「编辑信息」进入编辑模式。
3. 把「语音质量」调低一档，或放宽「语音延迟」。
4. 「保存更改」生效。

队伍里有人网络一般时，这一步比大家各自折腾设备有效；具体入口与权限要求见[怎么创建域和频道](怎么创建域和频道.md)第四节。

## 四、不同端的小差异

- **网页版**卡：先确认浏览器麦克风权限给过（缺权限表现为没声音而不是卡，见[调音台与语音设置](调音台与语音设置.md)第五节），再换个浏览器对比。
- **手机端**卡：切一次网络（Wi-Fi 与流量互换）、关掉后台大流量应用再看；画面共享卡顿先保证发起方电脑的上行带宽够。
- **电脑端**卡：排除加速器（第二节）后，看看是否同时在跑大流量任务（下载、云盘同步）。

## 五、还不行

[Oopz 帮助中心](https://help.oopz.cn/)有网络卡顿、语音延迟、屏幕共享延迟的专篇，按现象对号入座；仍解决不了就从帮助中心联系客服，反馈时带上「网络环境 + 具体现象」。
