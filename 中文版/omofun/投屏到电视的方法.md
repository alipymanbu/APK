# OmoFun 投屏到电视的方法

> 本篇讲怎么把 OmoFun 正在播的番剧投到电视或盒子上，包括投屏前提、具体步骤，以及搜不到设备、投屏卡顿的排查办法。

## 一、投屏前确认三件事

1. **手机和电视连的是同一个 Wi-Fi**：这是投屏的必要前提，手机用移动数据、电视用宽带的情况投不了；
2. **电视端支持投屏协议**：设备需支持 DLNA 或 AirPlay 协议，近几年的智能电视和电视盒子基本都支持；特别老的设备可以先装一个第三方投屏应用（如乐播投屏）来做适配；
3. **番剧正在播放中**：投屏入口在播放页里，不进播放页找不到按钮。

## 二、投屏步骤

1. 在 OmoFun 里打开想看的番剧，进入播放页面；
2. 点播放界面**右上角的电视图标**（部分版本显示为「TV」字样按钮）；
3. 等它搜索同一网络下的设备，搜到后点对应的设备名称；
4. 连接成功后画面就到电视上了，手机变成遥控器，可以继续选集、调进度。

投屏界面下方一般自带使用说明，连接遇到问题时可以点开看一眼。

## 三、搜不到设备怎么办

| 现象 | 处理办法 |
| --- | --- |
| 搜不到任何设备 | 重启路由器，确认手机和电视连的是同一个 Wi-Fi，并关闭手机的移动数据 |
| 搜得到别的设备、搜不到电视 | 确认电视的投屏或「多屏互动」开关已打开（电视设置里找）；部分电视要先进对应的投屏待机界面 |
| iPhone 投不了 | 检查系统设置里是否给应用开了「本地网络」权限 |
| 反复搜索都没有 | 换一次 Wi-Fi 重连（手机和电视都重连），再试 |

设备列表是搜出来才出现的，第一次没搜到就多触发几次重新搜索，别急着下结论投不了。

## 四、投屏卡顿、频繁断开

- 手机和路由器之间隔了几堵墙时信号会明显变差，把手机挪到离路由器近的位置；
- 家里其他设备在大流量下载、看视频时先停一停，投屏对带宽的占用不小；
- 把播放清晰度调低一档再试，先保证画面连续，网络空了再拉回去；
- 断开后不用重新进剧，回到播放页再点一次电视图标重连即可，进度还在。

## 五、投屏和手机端播放的关系

投屏只是把画面送到电视上，选集、进度、清晰度这些控制在手机上操作。退出投屏后回到手机小屏继续播，进度是接着的。想把某一集带到没有网络的地方看，那走的是缓存功能，见[番剧缓存与离线观看.md](番剧缓存与离线观看.md)。

播放页里除了投屏按钮，还有弹幕开关、倍速、线路切换这些常用设置，见[弹幕倍速与线路切换.md](弹幕倍速与线路切换.md)；投屏反复失败之外的其它问题，见[常见问题与故障排查.md](常见问题与故障排查.md)。
