# OmoFun 番剧缓存与离线观看

> 本篇讲怎么把 OmoFun 里的番剧缓存到手机、怎么管理已缓存的内容，以及缓存后离线看不了时的处理办法。

## 一、缓存之前先确认两件事

1. **登录状态**：缓存功能在部分版本里要求登录后才能用，进不去下载入口就先去[注册登录与账号找回.md](注册登录与账号找回.md)把账号弄好；
2. **剩余空间**：一集番剧几十到几百 MB 很常见，整季缓存前在手机设置里看一眼剩余存储，不够就少勾几集或者先清空间。

缓存一般在 Wi-Fi 环境下进行更划算，流量紧张的话留意一下应用内是否有「仅 Wi-Fi 下载」之类的开关。

## 二、缓存单集或整季的步骤

1. 打开想缓存的番剧，进入播放或剧集列表页；
2. 在剧集列表里勾选要缓存的集数——可以只勾一集，也可以点全选把整季带上；
3. 点下载按钮，开始缓存；
4. 想看进度就点底部的「查看下载列表」（部分版本叫「缓存管理」），里面能看到每一集的缓存状态。

下载速度整体比较流畅，同时缓存多集时后面的会排队，不着急的话让它在后台慢慢跑。

## 三、管理已缓存的内容

- **看缓存了什么**：「查看下载列表」或「我的」页里的缓存入口，列出所有已缓存剧集；
- **删掉看完的**：在缓存列表里选中要删的条目删除即可，视频文件占的空间会释放出来；收藏和观看进度不受删除缓存影响；
- **导出到相册**：部分版本的更新日志里出现过「把已缓存的视频导出到相册」的功能，在缓存条目的长按菜单或操作按钮里找，你的版本有没有这个入口以实际界面为准；
- **空间不够时先删缓存**：缓存文件是应用里最占空间的部分，清理空间优先从它下手。

看完一季删一季是个省心的习惯——视频文件体积大，留着也基本不会再看第二遍。

## 四、离线观看

缓存完成的剧集在没有网络时也能直接播放：断网状态下打开应用，进入「查看下载列表」点开已缓存的集数即可。通勤、出差路上这一招最实用，出门前把当天要看的几集缓存好就行。

注意离线能看的只有**已缓存**的那部分，没缓存的集数断网时加载不出来。

## 五、缓存完成后看不了怎么办

按顺序排查：

1. **确认缓存真的完成了**：进「查看下载列表」看状态，还在下载中或暂停的就等它跑完；
2. **重新缓存一次**：缓存完成却播放失败，删掉这一集重新缓存；
3. **清理应用缓存后重试**：手机长按 OmoFun 图标 → 应用信息 → 存储占用 → 清理缓存（注意是「清缓存」，不是「清数据」——清数据会把本地收藏和记录一起抹掉）；
4. **还不行就重装**：重装前先看[注册登录与账号找回.md](注册登录与账号找回.md)的账号恢复方法，保住收藏和进度。

播放过程本身的问题（卡顿、画质、弹幕）与缓存无关，见[投屏到电视的方法.md](投屏到电视的方法.md)和播放设置相关的篇章；其他故障统一见[常见问题与故障排查.md](常见问题与故障排查.md)。
