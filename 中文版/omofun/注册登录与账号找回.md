## 一、游客模式和登录后的区别

不登录也能用 OmoFun 看番：搜索、在线播放、把番剧加进收藏都可以。区别在于这些数据只存在本机——重装应用、清数据或换手机后，游客状态下的收藏和观看记录不会跟着走。

登录之后多出这几样：

| 功能 | 游客 | 已登录 |
| --- | --- | --- |
| 搜索、在线看番 | 可以 | 可以 |
| 本地收藏 | 可以（仅本机） | 可以（云端同步） |
| 发评论、回复 | 不行 | 可以 |
| 追番更新提醒 | 不行 | 可以 |
| 换设备接续进度 | 不行 | 可以 |

要不要注册看你的用法：只是偶尔点开看一集，游客够了；打算长期追番、要评论、或会在多个设备之间切换，建议注册一个。

## 二、注册步骤

1. 打开 OmoFun，点右下角「我的」；
2. 点顶部的「登录 / 注册」；
3. 在登录页点「立即注册」（有的版本显示为「尚无账号」）；
4. 按页面要求填写用户名或邮箱、密码、验证码，勾选同意用户协议；
5. 点「注册」完成，返回登录页用刚注册的账号登录。

注册不强制绑定手机号，用用户名加密码即可注册（部分版本的页面会提供邮箱注册选项，以你手上的页面实际显示为准）。两个建议：

- 用户名和密码自己记好。这套账号体系不依赖手机号，忘记密码后的重置方式取决于你注册时填的内容；
- 不同注册方式（用户名、邮箱）注册的是相互独立的账号，找回时要用注册时的那一种。

注册并登录后，部分版本会要求完成一组「入站答题」才能解锁评论等社区功能，流程和准备思路见[入站答题与转正.md](入站答题与转正.md)。

## 三、忘记密码怎么重置

1. 进入「我的 → 登录」；
2. 在登录页点「忘记密码」；
3. 页面会提供手机号重置和邮箱重置两种方式，选你注册时绑定的那一种；
4. 按提示验证后设置新密码。

如果两种方式都没有绑定过，密码就重置不了，只能靠下一节的账号恢复思路，或者重新注册一个新号。

## 四、换版本或换机后找回账号

OmoFun 的版本迭代中有过账号体系变更，官方在新版应用里留了一条「账号恢复」通道，把旧账号打包成一串文本带走：

1. 打开**旧版**应用的「我的」页面，找到「分享好友」功能；
2. 点它会生成一串较长的文本信息——这就是你账号的凭据，可以分享发给自己（发到文件传输助手、备忘录都行）；
3. 打开**新版**应用的「我的」页面，点右上角的「设置」图标；
4. 在设置里找到「账号恢复」，把刚才那串文本粘贴进去，确认后账号就回来了。

两个注意点：

- 这串文本等于密码，别发到公开群聊里；
- 如果你已经卸载了旧版、又没保存过这串文本，这条通道就走不通了，只能尝试密码重置或重新注册。

## 五、追番更新提醒的开关

登录后默认可能推送更新提醒，不想被打扰就关掉：

1. 进入「我的 → 设置」；
2. 找到「追番设置」（部分版本叫「推送设置」）；
3. 把「更新提醒」开关关掉，以后想追新番随时可以再打开。

提醒和更新表怎么配合着用，见[新番更新表与追番提醒.md](新番更新表与追番提醒.md)。

## 六、登录相关的小问题

- **验证码收不到**：稍等重发一次，检查是否被短信或邮件拦截；邮箱注册的去垃圾箱翻翻；
- **提示账号或密码错误**：确认注册方式没搞混（用户名注册的账号不能用邮箱登录入口），再核对大小写；
- **登录后收藏没跟过来**：先确认登录的是同一个账号；账号恢复见第四节；
- **评论发不出去**：评论功能要求登录，游客状态点评论会引导你先注册。

缓存和离线观看与登录状态的关联，见[番剧缓存与离线观看.md](番剧缓存与离线观看.md)；遇到加载失败、闪退等问题，见[常见问题与故障排查.md](常见问题与故障排查.md)。
