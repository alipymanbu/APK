先记住一个规律：**绝大多数播放报错都是「网络、缓存、版本」三件事**，官方客服给的答复也基本是重启、更新、重登这一套。先跑一遍下面的通用流程，再看具体代码。

## 一、通用处理顺序（多数报错到第二步就好了）

1. 完全关闭应用再打开（不是切后台，是杀掉进程）。
2. 重启手机或电视。
3. 重启路由器：拔电等一分钟再插回。
4. 更新应用与设备系统：旧版本在新片播放上容易出错。
5. 退出账号再重新登录。
6. 清应用缓存（安卓路径：系统设置 → 应用 → Prime Video → 存储 → 清除缓存；「清除数据」会把登录状态一起清掉，慎点）。
7. 都不行就卸载重装——网盘里的 [Prime Video 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b7a0359b05e5) 可以留作重装时的备用包。

## 二、错误代码对照

| 代码 | 常见含义 | 先做什么 |
| --- | --- | --- |
| 1060 | 带宽不足或网络不稳（最常见） | 测速；重启路由；换一个网络试 |
| 1007 / 1022 / 7031 / 7135 / 7202~7207 / 7230 / 7250 / 7251 / 7301~7306 / 8020 / 9003 / 9074 | 播放与流媒体类错误 | 全部按第一节通用顺序走 |
| 5004 | 应用缓存或数据损坏、登录态异常 | 清缓存 → 退出重登 |
| 2063 | 支付或订阅问题 | 检查绑定的支付方式是否有效、会员是否过期 |
| 7235 | 浏览器缺视频组件（网页端 Chrome 常见） | 更新浏览器到最新版 |
| 7279 | 内容保护校验失败（电脑端） | 换浏览器；关掉录屏 / 投屏类软件再播 |

错误代码的含义可能随版本调整，拿不准时以官方帮助页面为准。

## 三、网速够不够，先对着这张表测

| 内容档位 | 官方建议网速 |
| --- | --- |
| 标清 | 1 Mbps 以上 |
| 高清（HD） | 5 Mbps 以上 |
| 4K 超高清 | 25 Mbps 左右（不同来源在 15~25 Mbps 之间，以官方帮助页面为准） |

测速要**在播放出问题的那台设备上**测，家里 Wi-Fi 快不代表电视角落信号快。多台设备同时抢带宽（别人打游戏、下载、视频通话）时，单独看每一路都不达标。

## 四、同时播放的上限

一个 Prime Video 账号最多**3 路同时播放**，其中**同一部影片最多 2 路**。家里有人在看 A 片、你在电视上看 B 片、第三个人在看 C 片——到顶了，第四路会报错或拒绝播放。报错时先想想是不是家里哪台电视还挂着没关的片子。

## 五、卡顿、画质突然变差

- 画质是自动适配的：网络一抖，4K 立刻掉到低清。把播放器设置里的画质手动锁在「较好」反而更稳。
- 手机流量下看视频卡：在应用设置里把移动数据下的流媒体画质调低一档。
- 电视棒 / 老电视卡顿重灾区：先重启设备；连着几天不关机的电视，应用挂在后台久了会越跑越卡。
- 开着 VPN 或代理时播放经常直接失败——测速再准也没用，先把这类工具关了再试。
