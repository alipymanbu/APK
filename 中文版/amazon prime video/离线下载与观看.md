# Prime Video 离线下载与观看

> 本篇讲怎么把 Prime Video 的影片下载到手机离线看：哪些设备能下、下载占多少空间、有效期多久、下不了时是什么原因。还没装应用的话先看 [下载与安装教程.md](下载与安装教程.md)；下载和订阅状态有关，账号问题见 [账号注册与登录.md](账号注册与登录.md)。

出差、通勤、坐飞机时没网也能看——前提是出发前把片子下好。安卓手机和平板都支持离线下载，但并不是所有影片都能下，规则也不少，先把限制弄清楚再规划行程。

## 一、哪些设备能下载，哪些只能在线看

| 设备 | 离线下载 |
| --- | --- |
| 安卓手机 / 平板 | 支持 |
| iPhone / iPad | 支持 |
| Fire 平板 | 支持 |
| Windows 10/11（Microsoft Store 版应用） | 支持 |
| 电脑浏览器（网页版） | 不支持，只能在线看 |
| 电视 / 电视盒子 / 投屏 | 不支持，只能在线看 |

手里有电视端的话，离线内容只能在手机或平板上看，下载这一步别指望在电视上完成。

## 二、下载步骤

1. 打开应用，登录后找到想看的影片或剧集。
2. 在详情页找**向下箭头**的下载图标；剧集可以单集下，也可以整季一起下。
3. 点下载时会让你选画质（见下表），选完开始下。
4. 下载进度和应用底部的「下载」入口里能看到，完成后在「下载」页直接点开播放。

## 三、画质、体积与有效期

| 画质档 | 大约占用 | 适合 |
| --- | --- | --- |
| 较好（标准） | 每小时约 0.5 GB | 手机小屏、设备空间紧张 |
| 最佳（高画质） | 每小时约 1.5~2 GB | 平板、外接屏幕、在意画质 |

以上是官方帮助文档给出的参考值，实际以你下载时应用内显示为准。

三条硬性时限要记住：

- **30 天**：下载完成后 30 天内有效，过期需要重新下载或联网续期。
- **48 小时**：一旦开始播放，通常有 48 小时看完，倒计时和 30 天互不延长。
- **随时可能失效**：影片下架或授权到期，已下载的也会跟着失效；这是版权方的要求，不是设备问题。

另外，同一账号同时保有的下载影片数量有上限，多数账号在 15~25 部之间（因影片和地区而异），超了就得先删掉一些再下新的。离线影片还需要你定期联网一次，让应用核验订阅状态，长期断网后影片会拒绝播放。

## 四、两个建议先调的设置

- **仅 Wi-Fi 下载**：设置里把「仅通过 Wi-Fi 下载」打开，避免用流量下整季剧集把流量跑光。
- **下载画质默认值**：常用手机看的话，默认档选「较好」，同样一集占用能差出三倍多。

设置入口在应用「设置」页的下载相关选项里，不同版本的叫法略有差异。

## 五、下载不了或下载消失

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 详情页没有下载图标 | 该片没开放离线下载（版权限制） | 只能在线看，换别的影片 |
| 提示下载已达上限 | 同账号下载影片数到顶 | 在「下载」页删掉不看的再下 |
| 下载到一半停住 | 网络中断或切到了流量（开了仅 Wi-Fi） | 恢复网络后点继续 |
| 下载列表空了 | 超过有效期或影片已下架 | 重新下载当前还能下的内容 |
| 播放提示需要联网 | 应用要核验订阅状态 | 连一次网打开应用，验证通过后再离线看 |

下载好的影片被应用加密管理，文件管理器里搜不到可直接拷走的视频文件，也不能导出到别的设备播放——想在哪个设备离线看，就在那个设备的应用里下。

下载正常但一播放就报错，那是播放环节的问题，对照错误代码去查 [播放报错与卡顿排查.md](播放报错与卡顿排查.md)；想在电视上看（电视端不能离线下载，只能在线播），途径见 [投屏到电视.md](投屏到电视.md)。
