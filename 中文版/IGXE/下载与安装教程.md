## 一、安装前先知道这几件事

IGXE 是电竞饰品交易平台（CS2、DOTA2 等游戏的饰品买卖、求购、租赁）的手机客户端，你在手机上就能完成下单、收发 Steam 报价、提现等操作。动手安装前，先核对下面几条：

| 项目 | 信息 |
| --- | --- |
| 安装包版本 | 4.5.1 |
| 包名 | cn.igxe |
| 安装包大小 | 87.68M |
| MD5 | CA54A5B814DB3BE2E40310D33675D462 |
| 系统要求 | 安卓 5.2 以上（来自安装包信息，供参考） |

- 官方会持续更新版本，上面这份是 2026-09-27 核对过的安装包信息，**未必是官方最新版**；要最新版去官方下载页：[www.igxe.cn/app/download/page](https://www.igxe.cn/app/download/page)（安卓直链为 [www.igxe.cn/app/download/android](https://www.igxe.cn/app/download/android)，iOS 在 App Store 搜 IGXE）。
- 收发 Steam 报价、访问 Steam 社区这类操作，在国内网络下通常需要先开加速器，装机时可以顺手准备好。

## 二、两种获取途径

1. **夸克网盘**：打开上面的「IGXE 安装文件资源（夸克网盘）」链接，把文件转存到自己的网盘后下载到手机（夸克的分享文件需要先转存再下载，这是网盘的常规流程）。
2. **官方渠道**：访问 [www.igxe.cn/app/download/page](https://www.igxe.cn/app/download/page)，安卓机型直接点「下载 IGXE APP」；iPhone 走 App Store。

两种途径装出来的都是同一个应用（包名 `cn.igxe`），选顺手的即可。

## 三、安装步骤

1. 把 APK 文件下载到手机存储。
2. 点开 APK，系统首次会提示「不允许安装未知来源应用」，按手机品牌去设置里放行：
   - 小米 / Redmi：设置 → 隐私保护 → 特殊权限 → 安装未知应用；
   - 华为 / 荣耀：设置 → 安全 → 更多安全设置 → 安装外部来源应用；
   - OPPO / vivo / 一加：设置 → 安全（或「其他设置」）→ 安装未知应用。
   放行对象选你用来打开 APK 的那个应用（浏览器或文件管理器），不必全局放开。
3. 回到文件管理器重新点开 APK，点「安装」，等进度走完。
4. 打开 App，用手机号注册或直接登录（登录与 Steam 绑定见 [账号注册登录与steam绑定.md](账号注册登录与steam绑定.md)）。

想核对下载到的安装包是否完整，可以在电脑上用系统自带命令校验 MD5（PowerShell 示例）：

```powershell
certutil -hashfile "IGXE_v4.5.1.apk" MD5
```

输出的哈希与第一节表格里的 MD5 一致，说明文件没有下载损坏（文件名以你实际下载到的为准）。

## 四、装不上时的排查

- **提示「解析包出现问题 / 无法安装」**：多半是下载不完整，重新下载一次；或安装包与系统版本不兼容，确认安卓版本满足要求，再考虑换官方最新版。
- **点开没反应**：部分手机要先在文件管理器里长按 APK 选择「安装」，而不是直接点预览。
- **安装成功但打不开**：重启一次手机再试；仍不行就卸载后换官方渠道的安装包重装。
- **收不到验证码**：换网络环境重试，或检查是否装了拦截短信的应用。
