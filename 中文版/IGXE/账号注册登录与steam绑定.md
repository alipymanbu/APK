## 一、注册与登录

- **注册**：在 App 内用手机号注册即可。
- **App 登录**：支持账号密码登录与手机验证码登录。
- **官网登录**：官网登录页提供三种方式——账号密码、验证码，以及「打开 IGXE APP 扫码登录」（网页出二维码，用 App 扫码确认）。

如果你还没装 App，先看 [下载与安装教程.md](下载与安装教程.md)。

## 二、先设置好账号安全项

注册完别急着交易，先按官方流程把这几项补齐：进入「个人中心 → 账号安全」，设置邮箱、验证手机号、设置支付密码。支付密码在上架出售、发布求购等涉及资金的环节都会用到，忘了它后面会反复卡住。

## 三、绑定 Steam 账号：交易链接与 API Key

IGXE 的饰品收发走 Steam 报价体系，所以你要让平台知道「饰品往哪发、谁能发」：

1. **公开 Steam 个人资料与库存**：登录 Steam 官网 → 点自己的名字 → 「库存」→ 「库存隐私设置」，把库存和个人信息设为公开。不公开的话平台读不到你的库存，买卖都会被卡住。
2. **填写交易链接**：交易链接在 Steam 里生成——打开 Steam 客户端或网页版 → 「库存」→ 「交易报价」→ 「谁能给我发交易报价」页面里能找到自己的交易链接，复制后填进 IGXE 的个人中心。官方特别提示：查询交易链接需要登录 Steam 社区，**国内网络先开加速器**再操作。
3. **绑定 API Key**：API Key 在 Steam 官方的 API 页面（`https://steamcommunity.com/dev/apikey`）注册获取，注册时随便填一个网址即可，然后把 Key 填到 IGXE 的「我的 → 设置 → 账号安全 → Steam 账号管理」。App 内「买家要货报价」等模式要求绑定了正确的 API 才能用。
4. **Steam 侧的前提**：账号要绑定手机令牌，且没有交易暂挂、交易锁、VAC 封禁、社区禁令，否则报价发不出去。特别注意：**手机令牌启用要满 15 天**才能正常交易，重置密码（5 天）、新设备登录（7 天）也会临时限制交易——新号规划好时间，详见 [steam交易限制与暂挂.md](steam交易限制与暂挂.md)。

API Key 等同于你 Steam 交易身份的钥匙：**除了 Steam 官网和 IGXE 官方 App，不要把它填进任何别的地方**；任何人（包括自称客服的）向你要 API Key、密码或令牌验证码，都可以直接按骗局处理，详见 [常见问题与交易安全.md](常见问题与交易安全.md)。

## 四、检查清单

动笔买或卖之前，对照下面这张表过一遍：

| 检查项 | 在哪确认 | 不满足会怎样 |
| --- | --- | --- |
| 邮箱 + 手机已验证 | IGXE 个人中心 → 账号安全 | 收不到订单与发货提醒 |
| 支付密码已设置 | 同上 | 无法付款、上架、发求购 |
| Steam 资料与库存公开 | Steam → 隐私设置 | 平台读不到库存 |
| 交易链接已填且有效 | IGXE 个人中心 | 报价发送失败 |
| API Key 已绑定 | 设置 → 账号安全 → Steam 账号管理 | 买家要货报价等模式不可用 |
| 手机令牌满 15 天、无暂挂/交易锁 | Steam 交易报价页提示 | 报价收发被 Steam 拦下（见 [steam交易限制与暂挂.md](steam交易限制与暂挂.md)） |

这几项都绿了之后，买家看 [购买饰品流程.md](购买饰品流程.md)，卖家看 [出售饰品与提现教程.md](出售饰品与提现教程.md)。
