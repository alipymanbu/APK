## 一、报价发不出去 / 收不了饰品

绝大多数「卡在报价」的问题出在 Steam 侧，按顺序排查：

1. **加速器**：IGXE 官方教程反复强调，查交易链接、绑 API、发报价、确认收货前都要先开加速器——国内网络直连 Steam 社区经常超时，这是最高频的原因。
2. **交易暂挂**：Steam 对新绑定的手机令牌、新设备等情形会设置交易暂挂期，暂挂期间任何饰品都收不了。IGXE 的买家要货报价模式明确要求账号「无交易暂挂、交易锁、VAC 封禁、社区禁令」。暂挂还剩多久以 Steam 交易报价页面的提示为准。
3. **交易链接失效**：Steam 改过用户名或设置后交易链接可能变化，回 IGXE 个人中心重新填一次。
4. **API Key 不对**：确认 Steam 官方 API 页面的 Key 与 IGXE 里绑的一致；不确定就在 Steam 侧重新生成后重新绑定。
5. **库存不公开**：Steam 个人资料与库存设为公开（见 [账号注册登录与steam绑定.md](账号注册登录与steam绑定.md)）。

限制类型、触发原因与等待时长单独成篇：[steam交易限制与暂挂.md](steam交易限制与暂挂.md)；报价失效、订单取消与退款时效单独成篇：[订单时限与取消退款.md](订单时限与取消退款.md)。

## 二、提现与资金

- 支付宝提现：服务费 0.8%，单笔限额 10000 元，单笔服务费最低 2 元向上取整（官方公示口径，以平台当前页面为准）。
- 提款入口在「卖家中心 → 提款」，卖 CDK 的 1000 元保证金退出时另收 1% 手续费。
- 求购单的冻结金额随时可申请原路退款，官方口径 0 手续费。
- 到账时效：官方介绍过「全自动打款系统」；多个第三方资料称单笔提现通常 1 分钟内到账（第三方口径，供参考，以实际到账为准）。
- 支付宝提现不时有平台侧的优惠活动（如免手续费时段），以官方公告为准，不要轻信第三方转述。

## 四、账号安全：这几条能省掉大部分损失

- **API Key、密码、令牌验证码，谁都不给**：官方客服不会向你要这些。索要三者中任何一个的，无论话术多真，一律按骗局处理。手机令牌更不能交给任何人代管，官方帮助中心原话是「强烈建议保管好自己的令牌」。
- **知道骗子拿 API Key 干什么**：API Key 能查询和拒绝报价，但接受不了报价——骗子拿到它之后，会先把卖家收到的真实报价**自动拒绝**，再假冒交易对象重发一个自己的报价，等你把饰品发过去。所以接受任何报价前，**先核对报价里对方的 Steam 加入日期是否与订单里买家的加入日期一致**，不要在 Steam 里看到报价就点接受。
- **只在官方 App 与官网操作**：客服入口用 App 内的在线客服或官网页脚的「联系我们」，不要加来路不明的「客服」好友。
- **站外交易没有保障**：任何「加 QQ/微信私下走、便宜 X 折、代充值」的话术，都绕开了平台的赔付体系，出问题无从追责。
- **核对域名**：认准 `www.igxe.cn`，仿冒站点常用形近域名。
- **发现 Steam 侧异常立即检查 API**：如果发现收不到报价、库存异常变动，第一时间去 Steam 官方 API 页面查看 Key 是否被换，被换就重置，并修改 Steam 密码。
