## 一、先定位卡在哪一步

装不上和用不了是两类问题，排查路径不同：

| 现象 | 属于 | 从哪节开始 |
| --- | --- | --- |
| 点安装包无反应 / 提示解析错误 | 安装阶段 | 第二节 |
| 系统弹「禁止安装」拦截 | 安装阶段 | 第三节 |
| 装好了但一点开就退 | 闪退 | 第四节 |
| 打开了但导出/保存报错 | 运行中权限 | 第五节 |

## 二、安装包本身：先证明文件没坏

从网盘下载的 105.19M 安装包，先做两件事再怪手机：

1. **校验 MD5**：用任意校验工具比对文件哈希是否等于 `486799b290e6b00178d6297460315ad6`（这是网盘里 `众影AI_v3.1.2.apk` 的原始值）。不等说明下载不完整或文件被改，回 [下载与安装教程.md](下载与安装教程.md) 重新转存下载。
2. **看文件大小**：完整文件应接近 105.19M，明显偏小就是断点没下完。

MD5 对得上还报「解析错误」，才是系统侧的问题 —— 看下一节。

## 三、系统拦截：三个常见开关

不同品牌手机拦的位置不一样，按你机型对号入座：

- **未知来源**：设置 → 安全/隐私 → 允许安装未知应用，为下载所用的浏览器或文件管理器打开；
- **纯净模式 / 增强防护**（华为、荣耀等）：设置 → 系统和更新 → 纯净模式，关掉增强防护后再装，装完可以再打开；
- **存储空间**：安卓安装时需要解压空间，建议在手机剩余空间大于安装包体积 3 倍（约 320M）时再装，空间不足会直接失败。

系统版本要求存在两个口径：渠道页标注 **Android 4.0 以上**，分发平台历史页标注 **Android 7.0 以上** —— 以你的机型实装结果为准，装的时候报「与设备不兼容」就说明这台机器版本过低，只能换设备或升系统。

## 四、闪退：从轻到重四步

按代价从小到大试，每步之间重启一次再看：

1. **清后台 / 重启**：内存紧张时新装应用最先被挤掉；
2. **清缓存**：长按图标 → 应用信息 → 存储占用 → 清理缓存（清缓存不丢账户数据，清「清除数据」才需要重新登录）；
3. **核对权限**：设置 → 应用 → 众影AI → 应用权限，把存储、麦克风等权限打开（官方声明的权限清单及用途见下一节）；
4. **卸载重装**：以上都无效时，卸载后回网盘重下一份再装。你的账户额度与贝壳跟手机号走，卸载不丢。

同一台手机别的应用也一起闪退，问题多半在系统或内存，不在这个应用。

## 五、权限清单：每个权限是干什么的

众影AI 在应用商店声明的权限与用途，遇到「拒绝后功能报错」可对照这里补开：

| 权限 | 用途（官方声明口径） |
| --- | --- |
| 存储 | 把生成的视频保存到本地 |
| 电话（读取手机号） | 手机号登录 |
| 麦克风 | 录制自己的声音做配音/声音克隆 |
| 摄像头 | 拍照作为视频背景 |
| 读取听觉媒体 | 编辑视频时读取音频素材 |
| 位置 | 给视频添加地理位置标签 |
| 系统设置写入 | 按设备性能调整渲染参数 |

只开你用得到的即可：不拍照就不用给摄像头，导出报错优先检查存储。权限说明以应用内首次询问时的描述为准。

## 六、还是装不上时

- 换一个下载渠道验证：应用商店能搜到「众影AI」的话，先装商店版确认手机本身没问题，再回来装网盘版本；
- 手机厂商官方支持页对「安装失败」的通用排查（清理下载任务、删除安装器缓存、检查是否被隐私空间/多用户占用）也适用，入口在你手机品牌的支持网站搜「无法安装应用」；
- 到这一步还没解决，多半是机型系统过低或被厂商安全策略持续拦截，见 [常见问题与导出发布.md](常见问题与导出发布.md) 的其他排查项。
