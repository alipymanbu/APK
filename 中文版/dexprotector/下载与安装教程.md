## 一、安装前先核对包体信息

拿到安装包先对一眼版本和校验值，确认是不是你要的那一份。以下信息以包体实测为准，网上搜到的"最新版"版本号未必和这份相同：

| 项目 | 值 |
| --- | --- |
| 应用名称 | DexProtector |
| 版本 | 6.3.0 |
| 包名 | `mph.trunksku.apps.dexpro` |
| 安装包大小 | 6.26 MB |
| MD5 | `0590D4F9E9FD31184AF3977600AF534B` |
| 系统要求 | 安卓 5.2 以上（来自包体信息，低版本系统可能装不上） |
| 界面语言 | 中文（包体信息） |
| 开发者署名 | Sand Studio（包体信息） |

有第三方渠道的更新说明提到，6.3.0 这一版移除了应用内的购买项；以你实际装出来的界面为准。

这款 DexProtector 是装在手机上、直接给 APK 做混淆加密的安卓应用；它和同名的桌面端开发者工具不是一回事，别拿错了教程，区别见 [与桌面版同名工具的区别.md](与桌面版同名工具的区别.md)。

## 二、获取安装文件资源

1. 打开 [DexProtector 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5bf10f90e7d4)，把里面的安装包**转存到自己的网盘**；
2. 在网盘客户端（手机或电脑都行）里找到转存后的文件，下载到手机存储；
3. 下载完先别急着点开，建议按下一节的方法核对一遍 MD5。

## 三、核对 MD5

电脑上用 `certutil`（cmd 里执行）：

```text
certutil -hashfile dexprotector_v6.3.0.apk MD5
```

输出的哈希值和第一节表格里的 MD5 一致，说明包没下坏。文件名以你实际下载到的为准。

## 四、安装步骤

1. 点开下载好的 APK，系统提示"禁止安装未知来源应用"时选择仍要安装；
2. 如果被拦，去 设置 → 安全/隐私 里给文件管理器（或你用的浏览器）开"允许安装未知应用"权限，再回来继续装；
3. 装完在桌面看到 DexProtector 图标就算完成，接下来的操作见 [混淆加密怎么用.md](混淆加密怎么用.md)。

## 五、装不上时先看这几条

- 手机上已经装过同包名的应用且签名不同 → 先卸载旧的再装（记得先备份应用数据）；
- 提示解析包出错 → 多数是下载不完整，重新下载一遍；
- 更多现象和处理顺序单独整理在 [加密后无法安装怎么办.md](加密后无法安装怎么办.md)。
