## 一、同名，两样东西

| 对比项 | 安卓版（本套文档写的） | 桌面版（Licel 公司的开发者工具） |
| --- | --- | --- |
| 形态 | 装在手机上的 App | 跑在电脑构建流程里的工具（CLI、Gradle 插件、Studio 界面） |
| 操作对象 | 手机里的 APK 安装包 | APK、AAB、AAR，以及 iOS 的 IPA 等产物 |
| 使用场景 | 在手机上直接给安装包做混淆加密 | 集成进 Android Studio、CI/CD 的发布流程 |
| 输入与输出 | 给一个 APK，得到一个处理后的新 APK | 输入 APK/AAB/AAR（iOS 为 IPA 等），输出保护并签名后的发布包 |
| 运行方式 | 全程在手机本地完成 | 在你自己的电脑上离线运行，不上传云端 |
| 能力档位 | 界面里勾选 | 分 Standard 与 Enterprise 两档，功能清单以官方页面为准 |
| 版本号 | 6.x（安卓版自己的体系） | 16.x（桌面版自己的体系，以官方页面为准） |
| 获取 | 网盘安装包 | 官方渠道申请试用或购买授权 |

两边版本号各自独立，安卓版的 6.x 和桌面版的 16.x 不能互相换算。

## 二、各自适合谁

- **安卓版**：想在手机上快速把一个 APK 处理一遍、不上电脑、不碰构建环境——个人开发者验证想法、小工具快速处理，用这个顺手；
- **桌面版**：正式发布的应用、团队协作、需要证书锁定和运行时防护这类企业级能力——它要在构建流程里跑，[licelus.com](https://www.licelus.com/products/dexprotector) 是它的官方站点，功能清单和授权方式以官方页面为准。

## 三、怎么判断自己该用哪个

问自己三个问题：

1. 要处理的是不是**自己或自己团队**的应用？正式产品建议走桌面版进构建流程，安卓版适合快速验证；
2. 手头有没有电脑构建环境和签名文件？都没有的话，只有安卓版能干活；
3. 需不需要运行阶段的防护（防调试、防注入这类）？需要的话桌面版才有对应能力，安卓版做的是处理阶段的保护。

## 四、查资料时注意

搜功能名和报错时，先确认文章讲的是哪一边：出现 Gradle、CI、配置 XML 字样的都是桌面版；讲手机上加号添加、勾选项的才是安卓版。两边选项名称相近但不一一对应，照抄配置会出错。
