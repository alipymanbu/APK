# AView 摄像头换网后重新配网教程

## 一、什么情况需要重新配网

WiFi 摄像头记住的是当初配网时那一套 WiFi 名称与密码，所以：

- 换了新路由器 → 离线；
- 只改了 WiFi 密码（名称没变）→ 离线；
- 运营商换光猫、光猫自带新 WiFi → 离线；
- 搬家接了新网络 → 离线。

判断方法：手机连上家里**新的** WiFi 能正常上网，App 里设备却一直「离线」，基本就是它还揣着旧网络的凭据。走网线的 PoE 摄像头与 NVR 录像机不受 WiFi 变更影响，它们离线先查网线与电源（见 [常见问题排查](常见问题排查.md)）。

## 二、第一步：把摄像头恢复出厂

恢复出厂后，设备才会重新进入配对状态：

1. 保持设备通电。
2. 找到复位（reset）键 —— 不同型号位置不同，常见在尾线上、机身侧面或底部，以你的设备说明书为准。
3. 长按十几秒，听到提示音或看到指示灯闪烁即成功（不同型号时长略有差异）。
4. 松手，等设备重启完毕。

复位只清网络配置；SD 卡里已录的录像一般不受影响。

## 三、第二步：重新配网（热点配对）

设备复位后，流程与首次添加一致，走「设备自己发热点」的路子：

1. 手机保持连着**新的**家里 WiFi，打开 App 添加设备，选热点连接（部分界面叫「设备作为 WiFi 路由器 / Working as WiFi router」）。
2. 输入新 WiFi 的名称与密码。有摄像头厂商为 AView 写的接入文档特别提醒：多数型号只认 **2.4GHz** 频段，连不上 5GHz；双频路由器先把手机切到 2.4GHz 那一路再操作。
3. 按提示让手机去连设备发出的热点：热点名一般是 `HSIPC-XXXXXX` 这类形式，默认密码常见为 `12345678`（以机身上标注为准）。
4. 连上后 App 会把新 WiFi 凭据传给设备，设备自动重启并连上路由器。
5. 回到 App 给设备重新起名保存，等设备列表里的画面出来。

两个容易失败的点，同样来自厂商接入文档的口径：

- **配对有时限**：设备通电后约 15 分钟内要完成配对，超时就断电重启一次、重新计时。
- **等待节奏不同**：网线 / PoE 款通电后等约 5 分钟再扫码（等 P2P 就绪）；纯 WiFi 款等约 1 分钟等热点出现。热点一直不出现，就回到上一步再按一次复位。

具体细节各型号有差异，以设备说明书与 App 当时的界面提示为准。

## 四、不想复位的两条替代路

同类监控产品厂商的客服口径里给过两种替代做法，可以先试、不行再复位：

1. **把新路由器改成旧网络**：把新路由器的 WiFi 名称与密码改成和原来一模一样，设备断电再通电会自动连上。缺点是受路由器限制，不一定成功。
2. **先用网线救回来**：拿网线把摄像头接到路由器上，等它上线后，在 App 的设备设置里找「切换 WiFi / 有线配置」一类入口，输入新 WiFi 密码，让设备重启连接。

## 五、配完之后别忘了三件事

- 报警推送、云存储这类绑在账号与设备上的服务一般还在；不放心就在摄像头前走动一下，到消息中心确认推送还通（见 [报警推送与云存储](报警推送与云存储.md)）。
- 复位后设备昵称回到默认，顺手改回「客厅」「店门口」这类好认的名字。
- 反复配不上时，把设备挪到离路由器近的地方再试一次，成功后再装回原位；仍不行的按 [常见问题排查](常见问题排查.md) 的离线一节逐项查电源与信号。
