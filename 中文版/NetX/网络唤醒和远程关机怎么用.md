## 一、本篇解决什么

人不在电脑跟前，却想让它开机干活；或者反过来，出门了才想起电脑没关。这里有两条路：**网络唤醒（WOL）**把关机的机器叫醒，**SSH** 让它休眠或关机。两条路的前提条件完全不同，本篇分别列清楚 —— 前提不满足，点了按钮也不会有反应。

## 二、网络唤醒（WOL）：把关着的电脑叫醒

**原理一句话**：往局域网里发一个特殊数据包，开了「网络唤醒」的网卡收到就开机。所以条件全部落在**目标电脑**和**网络**两侧：

| 前提 | 在哪开 |
| --- | --- |
| 主板与网卡支持 WOL | 开机进 BIOS / 主板设置，找 `Wake on LAN`、`Power on By PCI` 之类选项打开 |
| 系统里允许网卡唤醒 | 网卡属性 → 电源管理，勾选「允许此设备唤醒计算机」；Windows 还要在「唤醒魔术包」上打勾 |
| 机器处于关机/睡眠而非断电 | 完全拔电源、彻底断电的机器叫不醒 |
| 你的手机和它在同一个局域网 | 走同一台路由器；跨网段、被访客网络隔开都不行 |

**在 NetX 里怎么发**：扫出那台电脑（列表里能看到它，说明至少此前在同一网段）→ 选中它 → 选网络唤醒（WOL，以实际菜单文字为准）。官方说明称在 Wi-Fi 或移动数据下都能发起 —— 实际能不能叫醒，取决于目标是否满足上表，先按上表逐条核对再试。

**叫不醒时**：先看上表前三条，尤其「BIOS 里没开」和「机器是彻底断电」这两种，与手机上的操作无关。三条都确认过还是没反应，就按 [网络唤醒叫不醒怎么排查.md](网络唤醒叫不醒怎么排查.md) 逐层查 —— Windows 的快速启动、主板的 ErP 节能这两项最常被漏掉；手机侧的排查见 [扫描不到设备怎么排查.md](扫描不到设备怎么排查.md)。

## 三、SSH：让开着的电脑休眠或关机

SSH 这条路要求**目标电脑上装着并运行着 SSH 服务端**，NetX 通过它下指令：

1. **在电脑上开启 SSH 服务**。Windows 10 / 11 可通过「可选功能」安装 OpenSSH Server 并启动该服务；Linux 一般自带 `sshd`，启动即可。具体入口随系统版本略有差别，以系统为准。
2. **让电脑可被访问**：确认防火墙放行 SSH 端口（默认 22），且手机与它同处一个局域网。
3. **在 NetX 里选中该设备** → 选休眠或关机（以实际菜单文字为准），按提示填入电脑的登录凭据。
4. 执行后电脑进入睡眠或关机状态；下一次要再操作，得先按上一节把它唤醒或等它开机。

**官方还提到**：通过 SSH 能看到远程设备装的是什么操作系统版本 —— 前提同样是 SSH 服务端已开、能连上。连不上时这一栏自然是空的。

## 四、CPU / 内存 / 磁盘占用读不到

NetX 的功能清单里还有「远程设备监控」：显示目标的 CPU 使用率、内存占用、磁盘剩余空间。这几项能否读到取决于目标设备是否响应查询（官方说明没有展开具体条件），所以：

- 读不到时，先按 [扫描不到设备怎么排查.md](扫描不到设备怎么排查.md) 确认设备可见、Ping 得通；
- 再确认目标侧的服务与防火墙（同第三节）；
- 仍然读不到，就把它当成「这台设备不提供这项数据」，Ping 与端口扫描这两项不受影响，照样能用。

## 五、一张对照表

| 你想要的效果 | 用哪个功能 | 关键前提 | 没反应先查 |
| --- | --- | --- | --- |
| 关着的电脑开机 | 网络唤醒 WOL | BIOS 与系统里开了 WOL、没彻底断电 | 目标侧三项前提（第二节表格） |
| 开着的电脑睡眠/关机 | SSH | 电脑装好并启动了 SSH 服务端、放行端口 | SSH 服务与防火墙（第三节） |
| 看它装的什么系统 | SSH | 同上 | 连不上就没结果 |
| 看它 CPU/内存/磁盘 | 远程监控 | 目标响应查询 | 先保证设备可见、Ping 得通 |
| 确认它到底在不在线 | Ping | 同网段 | 见 [扫描不到设备怎么排查.md](扫描不到设备怎么排查.md) |

动手前先在 [局域网设备扫描结果怎么看.md](局域网设备扫描结果怎么看.md) 里认准 IP 和 MAC —— 叫醒或下指令的对象错了，比功能不生效更麻烦。还没装应用的话，先看 [下载与安装教程.md](下载与安装教程.md)。
