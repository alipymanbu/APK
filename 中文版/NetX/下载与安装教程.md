## 一、装之前先对一下这份包的信息

NetX 的官方名是 **NetX Network Tools**，开发者是 NetGEL，包名 `com.tools.netgel.netx`，免费版。下面这几项是**网盘里这一份**的事实，装之前或装完之后都能拿来核对：

| 项目 | 值 |
| --- | --- |
| 版本 | 10.2.4.0 |
| 包名 | `com.tools.netgel.netx` |
| 安装包大小 | 4.53 MB |
| MD5 | `E997625925A55C27B566905687DE1294` |

网上搜到的多是官方最新版，**版本号未必和上表一致** —— 涉及版本、包名、体积，以上表为准。

系统要求这一项各处标注不一致：网盘里这份的记录写的是 **Android 5.2 以上**，而各应用商店页面普遍标 **Android 7.0 / 7.1 及以上**。你的手机能不能装，以安装时系统的提示为准。

## 二、从网盘拿安装文件

打开 [NetX 安装文件资源（夸克网盘）](https://pan.quark.cn/s/66c548d8fd0e)，在分享里找到 `NetX_v10.2.4.0.apk`（所在文件夹名为 `NetX（先保存再下载）`），转存到自己的网盘后再下载到手机。文件夹里有一份 `先保存再下载避免失效.txt`，照它的意思先把资源存下来，分享链接过期就拿不到了。

下载到手机的是一个 `.apk` 文件，点它即可进入安装流程。

## 三、安装步骤

1. 用手机浏览器或文件管理器找到刚下载的 `NetX_v10.2.4.0.apk`，点一下。
2. 系统若提示「不允许安装未知来源应用」，按提示进入该来源（浏览器或文件管理器）的授权开关，打开后返回继续安装。
3. 装完选择「打开」，或在桌面找到 NetX 图标。
4. 首次启动时按提示把网络、通知这些权限给它 —— 设备列表要联网扫，新设备接入提醒靠通知。

**核对装的是不是这一份**：系统「设置 → 应用 → NetX → 应用信息」里能看到版本号与存储占用；想核对包名，用任意应用信息工具查看 `com.tools.netgel.netx` 即可。要更严格地核对安装包本身，可在电脑上对 APK 文件算 MD5，与上表比对。

## 四、权限：哪些该给，哪些可以不给

- **网络 / 附近设备**：必须给。不给就扫不了局域网。
- **通知**：给。开启后有新设备或未知设备接入 Wi-Fi 时能收到提醒（用法见 [局域网设备扫描结果怎么看.md](局域网设备扫描结果怎么看.md) 第六节）。
- **定位**：安卓系统把「扫描附近 Wi-Fi 列表」归在定位权限下。社区用户的实际经验是：**拒绝定位权限后，局域网设备扫描照样能用**，只有 Wi-Fi 列表那一块可能拿不到数据。所以你可以先拒绝，等 [WiFi信号与信道拥堵怎么看.md](WiFi信号与信道拥堵怎么看.md) 里那一栏为空时，再回头把定位权限放开试试。
- NetX 是本地网络工具，不需要通讯录、短信、相册这类与扫描无关的权限；对弹出来的无关权限一律拒绝即可。

## 五、界面语言

官方说明列出的语言里有中文，另支持英、德、法、意、西、俄、捷、葡、波、希腊等。装完若是英文，在应用的设置或侧边菜单里找语言项切换；找不到就保持英文用，功能名不长。

## 六、免费版和 PRO 版的区别

开发者有两个包：

| | 免费版 NetX Network Tools | 付费版 NetX Network Tools PRO |
| --- | --- | --- |
| 包名 | `com.tools.netgel.netx` | `com.tools.netgel.netxpro` |
| 形态 | Google Play 免费 | Google Play 上的付费版本 |
| 本篇这份 | 网盘里这份就是它，10.2.4.0 | 不在网盘分享里 |

PRO 版在设备扫描、WOL、SSH、Wi-Fi 分析这些基础能力之上，另列了 Traceroute、IP 计算器、DNS 查询与反查、IP 地理定位、测速、IPv6 支持、数据备份恢复、地图展示等条目。**免费版已经覆盖本套文档讲的全部用法**，缺的只是后面这几项 —— 需要用到再考虑付费版即可。

广告这一点，有第三方下载页把 10.2.4.0 标为「无广告」，但这是单一来源的说法，**以你装上后界面上实际看到的为准**；两个包的价格与功能划分随时可能调整，以 Google Play 页面当时显示为准。

两个包可以装在同一台手机上，互不覆盖。

## 七、装完下一步

打开应用后它会开始扫描当前网络，出来一台台设备。第一次看列表可能不知道那些缩写是什么意思，直接看 [局域网设备扫描结果怎么看.md](局域网设备扫描结果怎么看.md)；一台设备都没扫出来，翻 [扫描不到设备怎么排查.md](扫描不到设备怎么排查.md)。
