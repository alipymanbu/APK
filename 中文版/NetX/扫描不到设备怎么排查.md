# 扫描不到设备怎么排查

> 只扫出自己一台、少了几台、或者明明 Ping 得通却不在列表：按哪几条顺序查，每条对应的修法是什么。

## 一、先做这三件最省事的检查

大多数「扫不到」都出在这三种，先按顺序排除一遍：

1. **是不是连着同一个 Wi-Fi**。手机连 5G、电视连访客网络、笔记本插着网线走有线口，都会让彼此互相看不见。看一眼各自的网络就知道。
2. **下拉重扫一次**。手势在 [局域网设备扫描结果怎么看.md](局域网设备扫描结果怎么看.md) 第二节 —— 很多时候只是上一次扫的时候目标刚好在休眠。
3. **手机没开 VPN**。VPN 会把手机的网络流量引到别处，局域网发现随之失效。关掉 VPN 再扫。

做完还有问题，继续往下。

> 补一条分界：设备**稳定地不出现**走本篇；**时有时无、连上了却上不了网**多半是地址被抢了，见 [设备反复上下线与IP冲突怎么查.md](设备反复上下线与IP冲突怎么查.md)。

## 二、看子网掩码，确认「同一网段」

回到应用的网络信息页，记下**子网掩码**和**网关**（含义见 [WiFi信号与信道拥堵怎么看.md](WiFi信号与信道拥堵怎么看.md) 第二节）：

- 子网掩码 `255.255.255.0` → IP 前三段相同的才和你在同一网段。
- 用它对照目标设备的 IP：前三段不同，就说明两者被路由器分到了不同的网段，扫不到是正常的。

**修法**：把两台设备连到同一台路由器的同一网络下；或者反过来，在 [局域网设备扫描结果怎么看.md](局域网设备扫描结果怎么看.md) 第七节里**手动添加那台设备的 IP**，之后 Ping、端口扫描照样能用。

## 三、路由器侧的隔离设置（最常见真凶）

同一个 Wi-Fi 名下也未必彼此可见，挨个核对：

| 路由器设置 | 现象 | 怎么处理 |
| --- | --- | --- |
| 访客网络 | 目标连的是访客 Wi-Fi，和你不同网络 | 把它并入主网络，或你也连访客网络去扫 |
| AP 隔离 / 无线隔离 | 连的是同一个 SSID，却互相看不见 | 在路由器管理页关掉「AP 隔离」「客户端隔离」 |
| 子母路由 / Mesh 分网 | 主路由和子路由下设备分属不同段 | 关掉子路由的独立网段，或按第二节手动添加 |
| 中继器 / 信号放大器 | 能上网、能 Ping 通，就是不出现 | 中继常挡住设备间的直接通信，改用有线或 Mesh 回程 |
| VLAN 划分 | 办公/智能家居网络被逻辑切开 | 没有管理权限就别折腾，按第二节手动添加兜底 |

路由器管理页地址一般就是应用里显示的网关那一项，登录账号密码多在机身标签上（如何核对网络参数见 [WiFi信号与信道拥堵怎么看.md](WiFi信号与信道拥堵怎么看.md) 第五节）。

## 四、两种「对不上」的细分

**Ping 得通，却不在列表里** —— 网络是通的，只是发现阶段没问到它（跨了段、走了中继、目标屏蔽了名字广播）。处理办法就是第二节说的：按 IP 手动添加，列表里就有了。

**在列表里，却 Ping 不通 / 端口扫不开** —— 反过来，是目标那一侧挡的：

- 电脑开了防火墙或第三方安全软件，拦了探测与端口响应 → 在目标电脑上放行，或临时关掉验证一次。
- 目标休眠、断网、IP 已被 DHCP 换掉 → 在目标侧确认它真在线，必要时下拉重扫。
- 手机侧 VPN、私有 DNS 打开 → 关掉再试。

能 Ping 通不代表能扫到，能扫到也不代表能 Ping 通 —— 这两条走的是不同的关卡，排查时别互相替代。

## 五、权限与系统侧

- **Wi-Fi 列表为空**：这是定位权限的问题，不是设备扫描的问题，放开定位即可（[下载与安装教程.md](下载与安装教程.md) 第四节）。
- **设备能扫到但提醒不响**：通知权限与后台豁免没给（[局域网设备扫描结果怎么看.md](局域网设备扫描结果怎么看.md) 第六节）。
- **换网络后列表是旧的**：下拉重扫，历史设备是被主动载入的，不代表当前在线（[局域网设备扫描结果怎么看.md](局域网设备扫描结果怎么看.md) 第二节）。
- **能上网但扫描异常**：先确认本机网络正常（[WiFi信号与信道拥堵怎么看.md](WiFi信号与信道拥堵怎么看.md) 第二、三节）。

## 六、什么时候该放弃排查

这几种情况不是设置问题，别白费时间：

- 目标本身就不在同一局域网（在公司、在别人家）；
- 网络由管理员做了访问控制而你无权修改；
- 老旧设备真的不响应任何发现协议。

这时候直接走**手动添加 IP**（[局域网设备扫描结果怎么看.md](局域网设备扫描结果怎么看.md) 第七节），把要管的那几台固定下来，比追求「列表自动完整」更省心。

排查前还没把应用装好、或者想确认装的是哪一份，见 [下载与安装教程.md](下载与安装教程.md)。
