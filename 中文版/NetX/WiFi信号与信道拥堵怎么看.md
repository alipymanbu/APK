## 一、本篇解决什么

网速卡的时候，你多半想知道两件事：**我现在连的这个网络到底什么状况**，以及**是不是信道太挤**。NetX 的网络分析部分把当前连接的参数、附近的 Wi-Fi 列表和一张信道重叠图放在一起，本篇讲这三块分别怎么看、看完能做什么。设备为什么扫不到不在本篇，见 [扫描不到设备怎么排查.md](扫描不到设备怎么排查.md)。

## 二、当前 Wi-Fi 连接信息

在应用的网络信息页（以实际入口为准）能看到当前 Wi-Fi 这几项：

| 项目 | 含义 | 常见用途 |
| --- | --- | --- |
| 外部 IP | 你当前出口的公网地址 | 换了网络、怀疑连的是不是同一个出口时核对它 |
| 信号强度 | 手机到路由器的强弱 | 换位置、换频段前后的对比依据 |
| 下载 / 上传速度 | 当前连接的实测速率 | 判断是「带宽不够」还是「延迟高」 |
| 子网掩码 | 决定哪些 IP 算「同一网段」 | 排查扫不到设备时，用它算出你这次能扫到的 IP 范围 |
| 网关 | 数据出去的那台设备，通常就是路由器 | 登录管理页的地址一般就是它 |
| DNS | 解析域名的服务器 | 打不开网页但能上 QQ 这类情况，改它试试 |

两点注意：

- **信号满格不等于网速好**。满格只说明手机到路由器这一段强，出口带宽、信道拥挤、对方服务器都会影响速率，要结合上面的上下行速率一起看。
- **子网掩码是排查利器**。`255.255.255.0` 意味着前三段相同的 IP 才和你在同一网段 —— 扫不到设备时先核对这个，见 [扫描不到设备怎么排查.md](扫描不到设备怎么排查.md)。

## 三、移动网络信息

切到蜂窝数据时，同一块会显示运营商侧的项目：外部 IP、信号强度、上下行速率，以及 `CID`、`LAC`、`MCC`、`MNC` 这四个基站标识。前两项和 Wi-Fi 那边含义相同；后面四个是运营商定位基站用的编号，普通用户拿来确认「我连的是不是同一个基站/小区」即可，不需要深究。热点共享状态下用它看手机热点这一段的连接状况也一样。

## 四、扫附近的 WiFi

入口在左上角菜单里选「WiFi 扫描」（以实际菜单文字为准）。开始后列出周围能搜到的网络，每个显示四项：

- **SSID**：网络名。列表里冒出一串你没见过的名字，通常只是邻居的路由器。
- **信号强度**：越靠前越强。同一个 SSID 出现两次（2.4G 和 5G 各一条）时，强度差就是选频段的依据。
- **信道**：这个网络占的频道号。
- **加密方式**：WPA2 / WPA3 / 无加密等。看到「无加密」的网络，别在上面输密码、登账号。

> 这一块会弹**位置信息**授权（安卓把 Wi-Fi 扫描归在定位下），不给就读不到列表。列表为空时，去系统设置给 NetX 放开定位再回来，见 [下载与安装教程.md](下载与安装教程.md) 第四节；设备扫不到的问题不在这块，见 [扫描不到设备怎么排查.md](扫描不到设备怎么排查.md) 第五节。

## 五、信道重叠图怎么读

图上每一根柱子是一个网络，柱子的宽度和位置表示它占用的信道范围。读法两条：

1. **柱子叠在一起，就是互相干扰**。同一信道上的网络要抢同一个「说话机会」，你家的延迟和速率会跟着抖。
2. **2.4 GHz 只有 1、6、11 三个信道互不重叠**。你家的柱子若和邻居几根挤在同一段，就去路由器管理页把信道固定到 1、6、11 中最空的那一个；5 GHz 可用信道多得多，重叠少，能用 5G 就优先用 5G。

换完信道回来再扫一次，柱子分开了、速率稳了，就说明改对了。路由器管理页的地址通常是网关那一项（见第二节），登录账号密码在路由器机身标签上。

## 六、和设备扫描的关系

信道拥挤影响的是**质量**，设备扫不扫得出来影响的是**可见性**，两者别混着排查：

- 设备列表里少了几台 → 走 [扫描不到设备怎么排查.md](扫描不到设备怎么排查.md)。
- 设备都在、但网页开得慢、视频卡 → 看本篇的信道图和上下行速率。
- 想知道这台设备本身在网里表现如何 → 回列表点它，用 Ping 测延迟，见 [局域网设备扫描结果怎么看.md](局域网设备扫描结果怎么看.md) 第四节。
