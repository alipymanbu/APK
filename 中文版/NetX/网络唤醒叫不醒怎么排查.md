## 一、本篇解决什么

前提条件都照着 [网络唤醒和远程关机怎么用.md](网络唤醒和远程关机怎么用.md) 第二节勾过了，手机上点了网络唤醒，电脑纹丝不动 —— 这时候问题多半出在**电脑关机后网卡还有没有电、认不认唤醒包**。本篇按「先看现象 → 再查哪一层」的顺序给判据，每一步都能当场验证。

## 二、先做两个当场能验的检查

1. **关机后看网口指示灯**。电脑彻底关机后，网线插口上的灯还亮着（或有规律闪烁），说明主板关机后仍在给网卡供电，WOL 才有可能；灯全灭，说明网卡已经断电，手机发什么都叫不醒 —— 直接跳到第三节查主板节能设置。
2. **改用「睡眠」再试一次**。在开始菜单里选「睡眠」而不是「关机」，然后用 NetX 唤醒。
   - 睡眠能唤醒、关机不能 → 问题就是第四节说的**快速启动**，这是 Windows 上最常见的一种。
   - 睡眠也唤不醒 → 继续往下查网卡与网络两侧。

## 三、主板侧：关机后网卡有没有电

进 BIOS / UEFI（开机时按 `Del`、`F2` 或 `F10`，具体看主板提示），核对这三项：

| 选项 | 该设成 | 说明 |
| --- | --- | --- |
| `Wake on LAN` / `Resume by LAN` / `Power on By PCI-E` | 开启 | 不同主板叫法不同，在「电源管理」「高级」里找 |
| `ErP` / `ErP Ready` / 深度节能 | **关闭** | 开着时关机会把网卡供电切掉，网口灯灭，WOL 必然失败 |
| `PCI-E/PCI Power On` | 开启 | 保证关机后插槽仍有待机供电 |

改完保存重启，回第二节再看一次网口灯。

## 四、Windows 侧：快速启动（最常被漏掉的一项）

Windows 10 / 11 默认开启「快速启动」，此时的「关机」其实是混合关机，网卡**不进入可被唤醒的状态**，唤醒包发过去就是石沉大海。关掉它的路径：

1. 控制面板 → 电源选项；
2. 左侧「选择电源按钮的功能」；
3. 点上方「更改当前不可用的设置」（需要管理员权限）；
4. 取消勾选底部的「启用快速启动（推荐）」，保存。

> 这条在微软官方支持文档与社区答复里是同一口径：混合关机状态下网卡不为 WOL 做准备，所以要么关掉快速启动，要么改用「睡眠」状态来唤醒。上面第二节的第 2 步就是拿它当判据。

顺带核对两处：

- **设备管理器 → 网络适配器 → 网卡属性**：「电源管理」页勾上「允许此设备唤醒计算机」；「高级」页把 `Wake on Magic Packet` 设为 `Enabled`。有的网卡还有 `WOL & Shutdown Link Speed`，设为 `Enabled` 或 `Auto`。
- **高级电源设置 → 睡眠 → 允许唤醒定时器**：设为启用（微软答复里列的检查项之一）。

## 五、网络与手机侧

| 现象 | 判断 | 处理 |
| --- | --- | --- |
| NetX 列表里根本没有这台电脑 | 手机和它不在同一网段，或被隔离 | 走 [扫描不到设备怎么排查.md](扫描不到设备怎么排查.md) |
| 列表里有，点了唤醒没反应 | 电脑侧没准备好 | 回到第三节、第四节 |
| 电脑在别的路由器/网段 | 唤醒包发不到它那一段 | 同一局域网内再试，或在路由器上做转发 |
| 有防火墙拦 UDP | 唤醒包被丢弃 | 防火墙为 WOL 放行（常见为 UDP 9），或临时关掉验证一次 |
| 装了 VPN | 手机的包根本没走局域网 | 关掉 VPN 再发 |

## 六、都试过还不行的两种情况

- **特定网卡的固件问题**：有用户反馈个别有线网卡在 Windows 下不吃唤醒包，需要主板/网卡厂商后续固件修复 —— 这类问题不在你的设置范围内，先更新网卡驱动与 BIOS 到最新版再判断。
- **家里设备多、由别人管理的网络**：路由器侧做了隔离或转发限制，没有管理权限就改不动，见 [扫描不到设备怎么排查.md](扫描不到设备怎么排查.md) 第六节。

排查前如果连设备都看不见，先解决可见性，别在唤醒上耗时间（[局域网设备扫描结果怎么看.md](局域网设备扫描结果怎么看.md) 第二节可下拉重扫）。还没装应用的话，见 [下载与安装教程.md](下载与安装教程.md)。
