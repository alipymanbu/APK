## 一、本篇解决什么

你连上家里的 Wi-Fi，打开 NetX，屏幕上来了一排图标和数字 —— 哪台是电视、哪台是邻居的手机、哪个 IP 是路由器，看懂这张表就能回答「我家 Wi-Fi 上到底连着什么」。本篇按「怎么刷出结果 → 每个字段什么意思 → 点开一台能干什么」的顺序讲，扫不出东西的情况不在本篇，去 [扫描不到设备怎么排查.md](扫描不到设备怎么排查.md)。

## 二、怎么发起和刷新扫描

- 打开应用即开始扫当前连着的网络，进度走完就是一份设备列表。
- **重新扫描的手势**：在列表界面按住屏幕中间往下拉，出现刷新按钮后松手，就会重新扫一遍（等价于点那个刷新按钮）。
- 换了 Wi-Fi（比如从家里的网切到公司网）后，记得重新扫一次，否则列表里还是上一个网络的设备。
- 扫完后，之前发现过、现在没在线的设备仍会被载入列表 —— 看起来「多出来的设备」可能只是历史记录，不是有人在蹭网，注意看在线状态再下结论。

## 三、字段逐个认

| 字段 | 是什么 | 你能用来干什么 |
| --- | --- | --- |
| IP 地址 | 该设备在这个网络里的编号 | Ping、端口扫描、登录路由器后台核对都靠它 |
| MAC 地址 | 网卡的物理地址，出厂固定 | 和路由器后台的「已连设备」逐条对上号，是最可靠的认人方式 |
| 厂商（Vendor） | 按 MAC 前缀查到的网卡/设备品牌 | 粗判设备类型（苹果、小米、三星的网卡前缀都能查出来） |
| Bonjour 名 | 苹果设备及部分智能硬件广播出的名字 | 认 iPhone、Mac、Apple TV、智能音箱特别准 |
| NetBIOS 名 / 域 | Windows 电脑广播出的计算机名与所在域 | 认办公室里的 Windows 主机，认人靠它 |
| 图标 | 按识别结果归类的设备类型 | 一眼扫过去区分手机、电脑、电视、路由器 |

几点边界，先说清楚免得误判：

- **厂商名 ≠ 设备名**。路由器、电视盒子常用白牌网卡，厂商一栏可能只写一串你没听过的牌子，甚至为空。
- **名字类字段是「问出来的」，不是「必有的」**。目标设备没开响应、被防火墙挡了，Bonjour / NetBIOS 就会空着 —— 空着不代表是陌生设备，只代表没问出来。
- **Android 10 起，普通应用拿到的 MAC 常是随机值**，你在手机「设置 → 关于手机」里看到的也可能不是真实地址，做比对请以 NetX 列表和路由器后台里的为准。

## 四、点开一台设备能做什么

在列表里选中一台设备，可以进入它的详情/操作菜单（以实际界面为准），常见动作有：

1. **Ping**：对这台设备的 IP 或主机名发探测，看通不通、延迟多少。判断「它是离线了还是只是不让人扫」，Ping 一下最快。
2. **端口扫描**：对这台设备扫最常用的一批端口，看哪些开着。发现电视盒子上开着不该开的服务，或者确认 NAS 的管理口活着，都用它。
3. **网络唤醒（WOL）**：让一台关机但联网待命的电脑开机，前提条件多，见 [网络唤醒和远程关机怎么用.md](网络唤醒和远程关机怎么用.md)。
4. **SSH 休眠 / 关机**：目标电脑开了 SSH 服务时，可以从手机上让它睡眠或关机，同样见 [网络唤醒和远程关机怎么用.md](网络唤醒和远程关机怎么用.md)。

想确认这台设备的网络质量（信号强度、网关、DNS、当前速率），返回上一层看 Wi-Fi 分析那一块，见 [WiFi信号与信道拥堵怎么看.md](WiFi信号与信道拥堵怎么看.md)。

## 五、列表里少了台设备、或者多了台不认识的

- **少了**：先下拉重扫一次；再确认那台设备真的连着同一个 Wi-Fi（手机连的是 5G 频段、电视连的是访客网络，都会扫不到）。逐条排查见 [扫描不到设备怎么排查.md](扫描不到设备怎么排查.md)；**时有时无、反复掉线**的属于另一类问题，见 [设备反复上下线与IP冲突怎么查.md](设备反复上下线与IP冲突怎么查.md)。
- **多了**：先看它的厂商与名字，多半是家里某个智能硬件自己冒出来的（扫地机器人、智能灯、摄像头常常不在你印象里）。确认是陌生设备再去路由器后台把它踢掉并改 Wi-Fi 密码 —— 这一步在路由器管理页做，NetX 只负责让你看见它。
- **设备类型识别错了**：图标只是按名字和 MAC 猜的，猜错不影响任何功能，以 IP 与 MAC 为准。

## 六、新设备接入时提醒你

开启之后，网络里出现**新设备或未知设备**时手机会收到一条通知，等于给家里 Wi-Fi 装了个「来人了」的门铃：

1. 首次启动时允许通知权限（拒绝过就去「设置 → 应用 → NetX → 通知」打开）。
2. 在应用的网络/安全相关设置里开启接入监控（以实际界面里的开关为准）。
3. 之后每次有没记录过的设备连进来，状态栏会有一条提示，点进去看它是谁。

提醒依赖手机本身别把 NetX 的后台杀掉：多数国产系统还要在「后台运行 / 自启动」里给它豁免，否则锁屏后就不推了。设备频繁重连时提醒会不会重复、隔多久重复，以你手机上的实际表现为准。

## 七、手动添加扫不到的设备

有些设备被路由器隔离、藏在中继后面，扫描时的广播问不到它 —— 但你只要知道它的 IP，就能手动把它加进列表，之后 Ping、端口扫描、唤醒这些功能一样能对它用：

1. 找到设备 IP：登录路由器后台看「已连设备」，或在该设备自身的网络设置里查。
2. 在 NetX 里选择手动添加网络 / 手动添加设备，填入 IP 等信息保存。
3. 它就出现在列表里了，后续操作与自动扫出来的设备一致。

这条也是排查时的兜底手段：**能 Ping 通却不在列表，就手动加**（详见 [扫描不到设备怎么排查.md](扫描不到设备怎么排查.md) 第四节）。

## 八、把列表导出成 CSV

扫描结果可以整份导出为 CSV 文件（在应用菜单里找导出项，以实际界面为准）。导出后你能干三件事：

1. **留档比对**：过一周再导一份，两份一 diff，哪些设备新增、哪些从此消失一目了然 —— 这比记在脑子里可靠。
2. **和路由器后台对账**：把 CSV 里的 MAC 逐条对照路由器「已连设备」，对不上的那条就是需要盯的对象；对不上号的原因见 [设备反复上下线与IP冲突怎么查.md](设备反复上下线与IP冲突怎么查.md) 第二节。
3. **交给别人排查**：网络出问题时，直接把 CSV 发给管网络的同事，省去口述 IP 和 MAC。

CSV 里包含 IP、MAC 这类内网信息，发出去之前确认收信人是自己人。
