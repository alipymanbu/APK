## 一、装不上

先分清是哪种提示，两种的处理方式完全不同。

**情况 A：提示「不允许安装未知来源的应用」**

这是系统的默认拦截，不是文件有问题。按 [下载与安装教程.md](下载与安装教程.md) 第三节放行一次即可。

**情况 B：提示「解析包时出现问题」「应用未安装」**

| 原因 | 怎么判断 | 处理 |
| --- | --- | --- |
| 安装包没下完整 | 文件大小明显小于 29.27 MB | 删掉重下，别续传；在电脑上下一份再用数据线拷过去更稳 |
| 系统版本过低 | 手机系统低于安装包标注的要求（这一版标的是安卓 5 系及以上） | 装不上就只能换设备 |
| 签名冲突 | 手机上装过别的渠道的同名包（包名同为 `net.ai.mimu`） | 先卸载旧版本再装；卸载会清掉本地学习记录，动手前先确认账号状态 |
| 存储空间不足 | 到设置里看剩余空间 | 至少留出安装包体积两倍以上的空闲空间 |
| 包本身不对 | 包名或 MD5 与这一版对不上 | 按 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 第四节核对，换一个包再装 |

**情况 C：提示「应用与你的手机不兼容」「此应用无法安装」**

这类提示是系统层面的拦截，跟包完不完整没关系，通常是下面两种原因之一：

| 原因 | 怎么判断 | 处理 |
| --- | --- | --- |
| 系统拒绝旧安装包 | 手机是新系统（安卓 14 及以上），要装的包是很久以前编译的 | 安卓从 14 起会拦下编译目标过旧的应用。改到应用商店装官方最新版 |
| 系统版本低于包的要求 | 手机系统很老 | 换设备，或用系统要求更低的版本 |

两份安装包怎么取舍，见 [旧版本和新版本该装哪个.md](旧版本和新版本该装哪个.md)。

反复失败时，最省时间的做法是重新取一份安装包，先把「手里的包坏了」这个可能性排掉，入口见本篇开头那条网盘链接。

## 二、打开闪退、用起来卡

按顺序试，前三步能解决大部分情况：

1. **重启应用**：从最近任务里划掉，重新打开。
2. **重启手机**：系统级的网络或存储服务出错时，这一步往往最有效。
3. **清缓存**（不是清数据）：`设置 → 应用 → mimu → 存储 → 清除缓存`。清缓存一般不动你的学习记录。
4. **覆盖安装新版本**：不要先卸载，直接装一次新包覆盖，能修掉一部分文件损坏类的问题，同时保住本地数据。
5. **看是不是特定操作才崩**：只在进某个页面、或只在聊天时才崩，说明是那条功能路径的问题，先绕开，等新版本修。

有用户在评价里提到过偶发卡顿和一些 bug。只要不是每次都复现，一般等版本更新即可；每次必现则值得去应用内的反馈入口提一次。

各家手机厂商的支持页里也给了同类问题的排查路径，照着找比在设置里瞎逛快：

| 机型 | 应用信息入口 |
| --- | --- |
| 华为 / 荣耀 | 设置里搜「应用管理」→ 找到 mimu → 强行停止；HarmonyOS 4.x 及以下还能在「权限管理」里补齐权限 |
| 小米 / Redmi | 设置 → 应用设置 → 应用管理 → mimu → 强行停止 / 清除缓存 |
| OPPO / realme / 一加 | 长按桌面图标 → 应用信息 → 存储占用 → 清理缓存 |
| vivo / iQOO | 长按桌面图标 → 应用信息 → 存储 → 清除缓存 |

厂商支持页里反复强调的一条是**存储空间**：可用空间长期紧张时，应用更容易出现闪退与卡顿，华为的支持页给的口径是**至少留出 20% 可用空间**。这一项排查成本最低，也最容易被忽略。

## 三、朗读没声音

按「从最简单到最麻烦」排：

1. **先看音量**：安卓的音量分档，媒体音量和铃声音量不是一回事。按音量键时展开那个齿轮图标，确认调的是**媒体**那一路。
2. **看是不是接了外设**：蓝牙耳机、车机、有线耳机还连着时，声音会走那边去。断开再试。
3. **看是不是免打扰**：下拉快捷设置里开了免打扰，部分机型会压低或静音媒体声音。
4. **换一个词试**：只有某一个词没声音，是那条内容的问题；全都没声音，是设备或权限问题。
5. **强制停止再打开**：`设置 → 应用 → mimu → 强制停止`，然后重开。
6. **确认网络**：朗读是联网生成的，断网时点朗读不会出声。能刷出别的网页，再回来查应用。

## 四、跟读、语音功能不识别

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 一进去就报错或直接跳过 | 麦克风权限被拒 | `设置 → 应用 → mimu → 权限` 里把麦克风打开 |
| 录得进去但识别结果很乱 | 环境噪声大、离麦克风远 | 换安静的位置，或用耳机上的麦克风；说话时别捂住手机底部 |
| 录完没有任何反馈 | 网络不稳，识别请求没发出去 | 换网络重试 |
| 提示麦克风被占用 | 通话、录音、会议类应用正在占用 | 关掉那些应用再试 |

## 五、找不到想要的角色

有用户反馈过这种情况：某一版更新之后，原来的角色入口位置变了，翻不到以前用的角色，只能自己新建一个。可以按这个顺序处理：

1. 先确认应用已经更新到商店里的最新版——角色相关入口在不同版本之间调整过。
2. 把主界面各标签页翻一遍，重点找「角色 / 我的 / 设置」里的相关入口，入口名称也可能改过。
3. 确实找不到，就自己创建一个角色顶着用；学习计划和词表不受影响。
4. 能进角色页、但某个具体角色不见了，属于内容侧的调整，只能通过应用内的反馈入口提。

## 六、换手机之后记录不在、登录不上

- **换手机**：先用原来的账号在新手机上登录。学习记录以账号为单位保存，具体能恢复到什么程度以应用内说明为准。**换机前不要在旧手机上手滑点「清除数据」**，那一步会删掉还没同步的本地记录。
- **登不上**：先确认网络正常，再用当初注册时的那个第三方账号授权登录。授权页打不开，多半是网络或第三方应用的问题，过一会儿再试。
- **退出登录前想清楚**：退出会回到登录页，重新登录一般能拉回记录；但如果之前一直处在未登录状态，退出可能就直接丢数据了。

## 七、清缓存和清数据，删的到底是什么

这两个操作长得像，后果差得远，动手前对着这张表确认：

| 操作 | 会删掉 | 不会删掉 | 什么时候用 |
| --- | --- | --- | --- |
| 清除缓存 | 临时文件、图片缓存，部分情况下包括离线内容 | 学习记录、登录状态、设置 | 闪退、界面显示异常、列表过期 |
| 清除数据 / 清除存储 | 全部本地数据：学习记录、设置、登录状态 | 账号云端已同步的部分（重新登录后可拉回） | 应用状态彻底异常，且已确认数据在账号里 |

**卸载重装等同于清除数据。** 所以遇到问题的处理顺序应该是：重启应用 → 清缓存 → 覆盖安装 → 最后才考虑卸载重装。真要整装一遍，安装包入口见本篇开头那条网盘链接，步骤见 [下载与安装教程.md](下载与安装教程.md)。

如果问题出在付费相关（扣了钱没生效、重复扣费、想退款），看 [会员怎么订阅与在哪里取消.md](会员怎么订阅与在哪里取消.md) 第四节，那里按渠道给了处理路径。
