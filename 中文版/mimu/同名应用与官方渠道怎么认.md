## 一、认这三样就够了

| 核对项 | 这一款 mimu 的值 |
| --- | --- |
| 应用名 | mimu；应用商店里的完整名是「mimu - 你推陪你背单词练口语」 |
| 包名（安卓） | net.ai.mimu |
| 开发者 | 成都快乐一点科技有限公司 |

- **安卓上最可靠的凭据是包名。** 应用名可以改、图标可以换，包名改不了。装完之后在「设置 → 应用 → mimu → 应用信息」里能看到包名，对不上就不是同一款。
- **iOS 上「开发者」和「提供者」两栏写法不一样**：App Store 页面的开发者一栏写的是 `HappyBit Tech Co., Ltd.`，提供者一栏写的是成都快乐一点科技有限公司。同一个产品在两个平台上架的主体写法不同属于正常情况，不代表遇到了假货。

## 二、几个容易认错的同名 / 近名产品

名字撞车在这款应用上特别严重。下面这些是写这篇时（2026-09）公开渠道里都能搜到的同名或近名产品，但都不是背单词的 mimu：

| 名字 | 实际是什么 | 一句话区分 |
| --- | --- | --- |
| MiMo（小米） | 小米的大模型与 API 开放平台，`mimo.mi.com` 下是模型与接口文档 | 给开发者调模型用的平台，不是手机上背单词的应用 |
| Mimu（Remosia） | 日本一家公司做的 AI 日记应用 | 功能是记录心情、自动生成日记，条款主体是 `Remosia Co., Ltd.` |
| The Mimir | 面向学校的语言教学平台，站点是 `www.themimir.com` | 老师上课用的网页平台，不是手机应用 |

同名产品以后还会增加，所以**「名字像就下」这个方法不可靠，认包名才可靠**。

## 三、别从第三方下载站拿安装包

第三方下载站的问题不是「一定有病毒」，而是**你无法确认拿到的是不是原包**：

- 有的站替换成自己打包的版本，装上之后推送、弹窗跟着来；
- 有的站上传的是旧版本，页面文案写的却是新功能；
- 有的站提供的是被改过的包，包名一样、签名不同。

第三种有一个明确的后果：**安卓只允许签名一致的安装包覆盖安装。** 如果你先装了改过的包，之后想换回来，会提示「应用未安装」——这时只能先卸载，而卸载会清掉本地学习记录（见 [常见问题与排查.md](常见问题与排查.md) 第七节）。

这一版安装文件的入口：[mimu 安装文件资源（夸克网盘）](https://pan.quark.cn/s/666001e26225)；具体安装步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 四、判断「我手机上这个是不是我要的那一款」

按顺序看四步：

1. **包名是不是 `net.ai.mimu`**（安卓）。
2. **应用信息里的版本号**和你打算装的版本对不对得上：网盘里发出去的是 2.0.1，而商店里的线上版本会更新，两者本来就常常不同（取舍见 [旧版本和新版本该装哪个.md](旧版本和新版本该装哪个.md)）。
3. **安装包来源**：如果是从别人手里转发来的一个包，装之前先比大小和 MD5 —— 这一版是 29.27 MB、`5F757E4159C7F10832746D3EDF2CA725`，对不上就别装。
4. **iOS 上不折腾**：正常安装渠道只有 App Store，所谓「苹果签名包 / 企业包」不是给普通用户用的，不要装。

拿不准时最省事的做法是：先卸载来路不明的那一份，再从网盘取一份重新装。**注意卸载会清掉本地学习记录**，动手前先确认账号状态。
