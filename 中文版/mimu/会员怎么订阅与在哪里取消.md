## 一、免费和会员的分界在哪

官方在应用商店的订阅说明里写的原话是：成为会员期间，可以自由使用 mimu 的所有功能，官方会持续对功能做更新与维护。按这个口径理解：

- **不付费也能用到一部分功能。** 有用户在评价里提到自己靠免费额度背单词，但这是个人说法，不能当成功能清单；
- **订阅会员解锁的是「全部功能」**，某一项具体要不要会员，点开时的提示最准。

写这篇的时候（2026-09），公开渠道里没有官方的「免费版 / 会员版」逐项对照表，所以别拿第三方站点的说法当依据。想知道某个功能要不要钱，最直接的办法是在应用里点一下：弹出订阅页就是要。

## 二、周期与价格

App Store 的内购列表里挂的是这几档（人民币，写这篇时的标价，实际以你付款页面显示为准）：

| 商品 | 标价 |
| --- | --- |
| 1 个月会员 | ¥28.00 |
| 3 个月会员 | ¥78.00 |
| 12 个月会员 | ¥268.00 |
| 能量礼包 | ¥6.00 / ¥18.00 / ¥88.00 |

三点说明：

1. **同一档可能出现不止一个商品条目。** iOS 的内购列表里就有「1 个月会员」和「月度会员」都标 ¥28 的情况，下单前看清周期：是不是自动续费、是不是首期优惠价。
2. **「能量礼包」是消耗型商品，不是会员周期。** 买它不等于开通会员、也不等于延长会员时长，买之前看清商品名和说明。
3. **上面这组是 iOS 侧的价格。** 安卓版在各自应用商店里的档位和定价可能不同，以你手机上付款页显示为准；同一个会员，在 iPhone 和安卓手机上看到的价格不一样，是正常的。

## 三、自动续费：分别在哪关

**iOS：订阅挂在 Apple 账号下**

官方文案给的规则是：确认购买并支付后，通过 Apple 账号自动续订，**到期前 24 小时内扣费**；要停，就得在当前订阅周期**到期前 24 小时以前**把自动续费关掉。

关闭路径：`设置` → 顶部你的 Apple 账户 → `订阅` → 找到 mimu → `取消订阅`。

**安卓：看你当初走的是哪条付款渠道**

安卓侧没有统一入口，按付款方式对号入座：

| 付款渠道 | 关闭入口（各厂商叫法略有差异） |
| --- | --- |
| 华为 / 小米 / OPPO / vivo 等应用商店 | 商店 App 里的「我的 → 订阅管理 / 自动续费」 |
| 微信内支付、应用宝 | 微信：`我 → 服务 → 钱包 → 支付设置 → 自动续费` |
| 支付宝 | 支付宝：`我的 → 设置 → 支付设置 → 免密支付 / 自动扣款` |

**取消之后，当前周期剩下的时间一般还能用到周期结束**（iOS 上是这个规则），安卓以对应渠道的说明为准。稳一点的做法是：取消完回到该渠道，确认订阅状态已经变成「已取消」，而不是停在「取消中」。

## 四、扣了钱没生效、重复扣费、想退款

| 现象 | 大概率原因 | 处理 |
| --- | --- | --- |
| 已扣费但会员功能没开 | 登录的账号和付款的账号不是同一个 | 退出后用付款时那个账号重新登录；仍不行就带订单号找应用内的帮助与反馈入口 |
| 同一周期被扣了两次 | 在 iOS 和安卓各订了一份，或在同一渠道重复下单 | 分别到两个渠道查订阅状态，退掉多出来的那一份 |
| 想退款 | —— | iOS 订单只能走 Apple 的退款流程（Apple 的「报告问题」页面），开发者没有权限直接退款；安卓订单走对应应用商店或支付渠道的退款入口 |

退款规则不是 mimu 特有的，所有上架应用都受各自商店的规则约束。**订单号要提前留好**：iOS 在 `设置 → Apple 账户 → 购买记录` 里，安卓在对应商店的订单 / 账单页里。

付费和登录相关的问题，从这里分流：

- **扣了钱但会员功能没开** —— 先按本篇第四节第一行查「登录账号与付款账号是不是同一个」；
- **应用本身打不开、闪退** —— 看 [常见问题与排查.md](常见问题与排查.md) 第二节；
- **换手机后学习记录不在** —— 看 [常见问题与排查.md](常见问题与排查.md) 第六节；
- **还没装上、不确定要装哪一版** —— 看 [下载与安装教程.md](下载与安装教程.md) 第一节的核对表，两份包的取舍见 [旧版本和新版本该装哪个.md](旧版本和新版本该装哪个.md)。
