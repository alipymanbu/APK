## 一、动手前先确认这一版是什么

mimu 是一款手机端的英语学习应用：你先挑一个陪伴角色（官方文案里叫 MJG，应用商店标题里叫「你推」），由它带你读单词、练口语，用英文小故事的写法跟你聊天，学习计划也按你的情况生成。公开渠道里只有手机版，没有 Windows 或 macOS 客户端。

| 项目 | 这一版（2.0.1）的情况 |
| --- | --- |
| 适用设备 | 安卓手机 / 安卓平板 |
| 系统要求 | 安装包标注「需要支持安卓系统 5.2 以上」 |
| 包名 | net.ai.mimu |
| 版本号 | 2.0.1 |
| 安装包大小 | 29.27 MB |
| 安装包 MD5 | 5F757E4159C7F10832746D3EDF2CA725 |
| 是否必须联网 | 是。首次打开、AI 聊天、朗读、语音相关功能都要联网 |

三点先说明：

1. **「安卓 5.2」按「安卓 5 系及以上」理解就行** —— 安卓的公开版本号是 5.0、5.1，之后直接跳到 6.0，并没有对外的 5.2。真正能不能装，以你手机点下去之后的提示为准。
2. **网上搜到的是官方最新版，通常比这一版新。** 判断「我装的对不对」，看的是包名和版本号能不能对上，不要拿某篇介绍里的版本号来比。下面提到的界面位置，各版本之间调整过，以你手机上看到的为准。
3. **手机系统越新，旧安装包越容易装不上或者装上后闪退。** 这一版是 2.0.1，如果你的手机是近两年的新系统，装的时候提示「应用与你的手机不兼容」或「此应用无法安装」，先别急着认定包坏了 —— 是系统把这一版拦下来了。这种情况的取舍见 [旧版本和新版本该装哪个.md](旧版本和新版本该装哪个.md)。

本篇针对的是安卓安装包。**如果你用的是 iPhone**，安装入口只有 App Store，下面第二、三节的取包与「未知应用」步骤都不适用；从 App Store 装完之后的用法与排查，本套其余几篇同样可以参考。

## 二、把安装包取到手机

安装包通过夸克网盘分享，转存到自己的账号后再下载，比从第三方站点点「立即下载」稳：链接中途失效、或下载被替换成别的东西的风险更低。

1. 在手机上打开 [mimu 安装文件资源（夸克网盘）](https://pan.quark.cn/s/666001e26225)。用手机浏览器或夸克 App 都行，建议在夸克 App 里打开，浏览器下载大文件容易被打断。
2. 点「保存到我的网盘」，先转存到自己账号下。之后再下载就不看原分享的状态了。
3. 进入自己的网盘找到这个文件，点下载，等它落到手机的「下载」目录。
4. 下载完核对两件事：文件名以 `.apk` 结尾；大小在 29.27 MB 左右。差得多的多半没下完整，删掉重下，别续传。

习惯在电脑上操作的：先在电脑端网盘把这个文件下载下来，再用数据线（USB）拷到手机的 `Download` 目录，之后在手机上从「文件管理」里点它安装，效果一样。

## 三、安装：需要放行一次「未知来源」

你手上这个安装包是从网盘取来的，不是从应用商店下载的，所以安装时系统会拦一下。这是默认行为，不代表文件有问题。

1. 打开「文件管理」，进入 `Download`（下载）目录，找到刚下好的安装包，点它。
2. 系统弹出「为了安全，你的手机不允许安装来自此来源的应用」这类提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 有的机型要自己去「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，找到你刚才用来打开文件的那个 App（文件管理或浏览器），逐个放行。
3. 回到安装界面点「安装」，等进度条走完，出现「打开 / 完成」。
4. 先点「完成」，不要马上点「打开」——首次启动前把权限一次给对，省得进去之后反复弹窗。

安装完成后，桌面或应用列表里会出现 mimu 的图标。

## 四、首次打开会要的权限

对照下表处理。应用商店公布的权限清单里，与使用体验直接相关的是这几项：

| 权限 | 用途 | 建议 |
| --- | --- | --- |
| 麦克风（录音） | 口语跟读、语音评测要收音 | 要练口语就给；不打算用可以先拒绝，之后按需再开 |
| 存储 / 文件与媒体（读取与写入） | 缓存学习资源、保存录音与文件 | 建议给，拒了相关功能可能报错 |
| 通知 | 学习提醒、复习推送 | 想要提醒就给，不想被打扰可以拒绝 |
| 网络与 WLAN 状态 | 登录、AI 聊天、朗读、资源加载 | 必须给 |
| 防止手机休眠 | 朗读或录音过程中不让系统休眠 | 可以给 |
| 开机自动启动 / 前台服务 | 提醒与后台任务 | 按需；这两项被系统限制时，提醒可能不来 |
| 蓝牙 | 连接蓝牙耳机 | 用耳机时给 |
| 振动 | 交互反馈 | 可给可不给 |

清单里也会出现读取媒体图片之类的权限，属于安卓版本适配带来的写法，一般不影响背单词本身。**拒绝某项权限之后功能报错，先回到权限页把它补上，比反复重装省事。**

## 五、装完先做三步自检

别急着开始背，先花一分钟确认这三件事：

1. **能打开、不闪退**：图标点进去能进主界面。反复闪退看 [常见问题与排查.md](常见问题与排查.md) 第二节。
2. **能走到选角色 / 看计划那一步**：首次打开会先让你同意用户协议与隐私政策，然后走登录流程（登录入口以应用内实际显示为准）。能看到角色或学习计划，说明账号这一环通了。
3. **朗读有声音**：让角色读一个词，能出声。没声音先确认媒体音量（安卓的音量分档，按音量键时展开，确认调的是媒体那一路），再看是不是连了蓝牙耳机。

三步都过，就可以按 [背单词和练口语怎么用起来.md](背单词和练口语怎么用起来.md) 里的安排开始了。

## 六、升级与卸载

- **升级**：新版本会换一个安装包文件名，直接覆盖安装即可。**不要先卸载** —— 卸载会连同应用本地数据（学习记录、设置、登录状态）一起删掉。
- **卸载**：换机或重装前，先确认自己已经登录过账号；学习记录能恢复到什么程度，以应用内的说明为准。
- **安装包丢了**：回到本篇开头那条网盘链接重新取一次即可，已经转存过的版本不受原分享状态影响，取包与安装步骤同上。
- **手机系统升级之后打不开了**：先用覆盖安装试一次；还是不行，说明是旧版和新系统的兼容问题，改到应用商店装最新版更省事，两边怎么选见 [旧版本和新版本该装哪个.md](旧版本和新版本该装哪个.md)。

装完之后如果发现手机上这一款和搜索到的介绍对不上（名字像、功能不一样），先核对包名和开发者，方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
