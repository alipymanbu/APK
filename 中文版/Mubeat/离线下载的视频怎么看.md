# Mubeat 下载的视频在哪、订阅到期还能看吗

Mubeat 的离线下载是为网络不稳、流量有限的场景准备的，但它有两条容易被忽略的规则：**下载能力属于 Mubeat+，且下载好的内容只有在订阅有效期内才能播放**。本篇把这两条讲清楚，顺便说清下载的文件在手机里到底放在哪。

## 一、动手下载之前先确认两件事

1. **账号要有 Mubeat+ 订阅**。全高清与无限下载都是 Mubeat+ 的权益，免费账号的下载额度以应用内提示为准，权益对照见 [看视频与字幕设置.md](看视频与字幕设置.md)。
2. **订阅剩余时间要够长**。官方 FAQ 的口径是：已下载的视频只有 Mubeat+ 订阅用户才能观看，订阅到期的用户不再适用「观看此前下载的视频」。换句话说，订阅一过期，那些已经躺在手机里的离线内容就打不开了，续费之后才恢复。打算靠离线包熬一段没网的日子，先把到期日记下来。

## 二、下载入口与能下到什么

在视频播放页找下载 / 保存图标，点它开始离线保存。一条内容能不能下、能下哪几档清晰度，以播放页实际给出的选项为准；1080P 全高清只在 Mubeat+ 下开放。

## 三、下载的文件在手机里为什么找不到

很多人下完就想进文件管理器把视频拷出来，通常找不到。这不是你路径搜错了，而是安卓对应用私有目录做了限制：

| 你的预期 | 实际情况 |
| --- | --- |
| 能在「下载 / Download」目录里看到视频文件 | 一般看不到，离线内容保存在应用自己的私有目录里 |
| 能拷到电脑上、用别的播放器打开 | 通常拷不出来，也不保证是第三方播放器能识别的格式 |
| 卸载应用后文件还在 | 卸载或「清除数据」会一起删掉离线内容，且无法恢复 |

结论很直接：**这些离线视频是给 Mubeat 自己播的，不适合当成本地收藏来管**。想回看就在订阅有效期内在应用里看。

## 四、想清掉占用的空间怎么做

1. 优先在应用内的下载管理里删掉不看的条目，删单条比清空整个应用数据安全得多。
2. 还不够，再去「设置 → 应用 → Mubeat → 存储」清缓存。**清数据会退出登录并删掉全部离线内容**，只在确定不要了的时候做。
3. 顺手看一眼剩余空间。安卓在播放和缓存时还需要额外临时空间，剩余太少会让清晰度自动降档。

## 五、几种现象对照

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 找不到下载按钮，或点了没反应 | 当前账号没有 Mubeat+，或这条内容本身不提供下载 | 确认订阅状态，换一条内容试 |
| 之前能看，现在提示无权观看 | 订阅到期 | 续费后恢复，另见 [常见问题与排查.md](常见问题与排查.md) |
| 离线列表空了 | 清过应用数据、重装过，或登录了另一个账号 | 离线内容找不回，需要重新下载 |
| 在文件管理器里搜不到文件 | 离线内容在应用私有目录 | 属正常情况，不必反复搜 |

离线下载解决的只是「看的时候不走流量」，使用范围仍以官方服务条款为准。装包与校验那一段见 [下载与安装教程.md](下载与安装教程.md)。
