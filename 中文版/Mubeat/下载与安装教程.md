Mubeat 是韩国 MBC 音乐节目《Show! Music Core》的官方投票平台，同时把 K-POP 打歌舞台、成员直拍、综艺片段、MV 与站内原创内容汇总在一起供点播。本篇只走「装」这一段：先核对网盘里那份包的信息，再取包、校验、放行安装权限，最后完成首次启动，并说明哪几项权限值得给。

## 一、装之前先对一遍版本和要求

网盘里那份包的实际信息如下。网上搜到的往往已是更新的版本号，两者不是同一版，装之前以这张表为准。

| 项目 | 值 |
| --- | --- |
| 应用名 | Mubeat |
| 包名 | `com.vlending.apps.mubeat` |
| 版本 | 02.28.00 |
| 安装包大小 | 66.50M |
| 安装包 MD5 | `C8946679D8009F3A270975C3C283DE91` |
| 系统要求 | 安卓 5.2 及以上 |
| 开发商 | Vlending Co., Ltd.（服务条款里的公司实体写作 OGQ Vlending Co, Ltd） |

三条判断：

- 这是手机端应用；网盘里放的这份是**安卓安装包**（`.apk`），iPhone 装不了。用 iPhone 的话走 App Store 的官方渠道，本仓库这份安装文件用不上。
- 手机存储要留出 70M 以上空闲空间，安装包 66.50M，安装和首次运行还会再占一点。
- 系统要求这一项，应用商店当前页面对较新版本标注的门槛比表格里高。能不能装，以**应用商店页面对你机型的要求**为准，表格里这条只代表网盘里那一版的标注。

## 二、从网盘把安装包取到手机

1. 打开 [Mubeat 安装文件资源（夸克网盘）](https://pan.quark.cn/s/be44ffae262a)。
2. 先点「保存到我的网盘」，再从自己的网盘里下载。直接下载也能用，但转存之后，即使原分享链接失效，文件还在你自己的网盘里。
3. 等下载完成，记住文件位置，多数浏览器和夸克会放在「下载」或「Download」目录。
4. 文件名形如 `Mubeat_v02.28.00.apk`，以网盘里实际显示的名字为准。

打开链接提示失效或需要提取码时，说明这条分享已不是当前状态，换最新的一条。

## 三、动手装之前校验一下包

安装包从网络传到手机，中途出差错时，安装界面会直接报「解析包错误」。花半分钟校验，能省掉后面一串排查。

把 APK 拷到电脑上，在文件所在目录执行：

```powershell
certutil -hashfile "Mubeat_v02.28.00.apk" MD5
```

输出的十六进制串去掉空格后，应与第一节表里的 `C8946679D8009F3A270975C3C283DE91` 完全一致（大小写不敏感）。手机上也可以用带 MD5 校验功能的文件管理器做同样的事。对不上就重新下载一次，别将就着装。

## 四、先去系统里放行「未知来源」

网盘里的包不是从应用商店装的，安卓默认会拦一次。要先给下载它的那个应用（浏览器或夸克）开安装权限，各品牌路径不一样：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 权限管理 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装外部来源应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 生物识别和安全 → 安装未知应用 |
| 原生安卓 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

路径记不住没关系，在设置顶部的搜索框里直接搜「未知应用」或「外部来源」，基本都能跳到同一页。找到负责下载的那个应用，把开关打开。

## 五、安装与第一次打开

1. 从通知栏点刚下载完的文件，或打开文件管理器找到那个 `.apk` 点它。
2. 弹出安装界面点「安装」，等进度走完，桌面出现图标。
3. 桌面图标名称通常就是 Mubeat。要确认装的是不是同一个应用，认包名 `com.vlending.apps.mubeat` 更可靠，安装后在「设置 → 应用 → Mubeat」的应用信息页里能看到。
4. 首次启动会依次弹权限申请。真正影响功能的是这几项：

| 权限 | 用途 | 不给会怎样 |
| --- | --- | --- |
| 设备信息 | 识别设备、判断网络状态 | 官方标为必需项，拒绝可能影响正常使用 |
| 照片 / 视频 / 文件 | 设置头像、展示墙图片 | 换头像、上传图片用不了 |
| 通知 | 关注的艺人更新、投票与活动提醒 | 收不到更新提醒，其余照常 |
| 麦克风 | 录制视频时收音 | 录视频没有声音 |
| 相机 | 录制视频 | 录视频用不了 |
| 通讯录 | 核对设备相关信息 | 影响面很小，可以不给 |

具体会弹哪几项、叫什么名字，以你手机上实际弹出的为准，上面只是它们各自的用途。

5. 启动后一般会直接要求选择账号登录。正常，关注艺人、攒 Heart Beats、投票都要先有账号，见 [注册登录与账号设置.md](注册登录与账号设置.md)。登进去之后先关注几个艺人，首页和投票页才会出内容，操作方法见 [看视频与字幕设置.md](看视频与字幕设置.md)。

## 六、装不上或者装完打不开

按这个顺序自查，比反复重装有效：

- 提示「解析包错误」「应用未安装」→ 回到第三节重新校验 MD5，文件多半没下完整。
- 提示「已被阻止安装」→ 第四节的未知来源权限没开，或开了但给错了应用。
- 装好后点图标闪一下退回桌面 → 先看手机系统版本是否过低；仍不行，到 [常见问题与排查.md](常见问题与排查.md) 按「闪退」一条排查。
- 装到一半提示空间不足 → 先清出不小于安装包大小的空间再试，安卓在安装时需要额外留余量。
- 提示签名冲突、与已有应用不兼容 → 手机上已经装过同包名但来源不同的 Mubeat，先把旧的那个卸载，再装网盘里这份。
