## 一、先记住一件事：导出去的是「死」模型

官方帮助明说：导出的数据**不含特征和参数化历史**。你拿到的是那一个时刻的几何体 —— STEP、STL 也好，Parasolid 也好，别人（包括你自己）打开后只能在这个「死」实体上继续，改不了你原来的草图尺寸和特征顺序。要交接可编辑的设计，靠的是共享 Onshape 文档本身，不是导出文件。

另外两个导出时的行为提前知道：复合零件（composite part）导出会拆成一个个独立零件；STL 和 Parasolid 格式可以选「一个文件」还是「每个零件一个文件」，选后者会打成一个 zip 包。文件名里带 `` \ / * : | > < ? " `` 这类字符时，导出会自动替换成连字符。

## 二、导出成 STEP、STL 的操作

入口在页签和零件上，浏览器端与手机端都在：

1. **导出整个页签**：右键（触屏：长按调出上下文菜单）Part Studio 或装配体的页签 → Export；
2. **只导一个零件**：在零件列表或图形区选中零件 → 上下文菜单 → Export；
3. 起文件名、选格式、确认 —— 浏览器端默认下到浏览器的下载目录（位置跟浏览器设置走），也可以导到你先授权过的 Google Drive / Dropbox。

两个端能选的格式不完全一样（官方帮助口径，截至 2026-09）：

| 端 | 可选格式 |
| --- | --- |
| 浏览器 | PARASOLID、ACIS、STEP、IGES、PVZ、JT、RHINO、GLTF、GLB、OBJ、3MF、STL（URDF 仅装配体导出时可选） |
| 手机（安卓 / iOS） | Parasolid、ACIS、STEP、IGES、PVZ、JT、GLTF、OBJ、3MF、STL |

按用途挑格式：给 3D 打印切片用 **STL**；发给其他 CAD 软件接着改用 **STEP**（通用性最好）；和 SolidWorks 互传，**Parasolid** 是同内核直通、最稳的一条路（原因见下一节）。草图和平面还能单独导成 **DWG / DXF**，钣金件的展开图也是走 DWG / DXF。

手机端导出是支持的：页签上长按 → Export → 选格式，之后文件经系统下载或分享面板交给你，落在哪里以你设备为准。安卓端还能导出「链接文档」（linked documents），这点官方标注与浏览器端一致。

## 三、把别的 CAD 文件导入 Onshape

导入分两种落点，效果不同：

- **从文档页（Documents 页）导入**：每个文件生成一个新 Onshape 文档，文件名就是文档名，导入后自动建一个版本；
- **在打开的文档里导入**：文件变成当前文档里的新页签。

硬性限制和事实，导入前过一遍：

- 单文件上传上限 **4 GB**；
- 导入的 CAD **没有特征树** —— Onshape 只提供对「哑实体」做参数化操作的工具。想继续改草图历史的，源头文件里就改好再导；
- 大多数系统的数据走通用格式：**ACIS、JT、STEP、IGES、Parasolid、OBJ、STL**；AutoCAD 实体首选 ACIS，二维数据走 DWG / DXF；
- **STL / OBJ 导入时要选单位**（厘米 / 英尺 / 英寸 / 米 / 毫米 / 码）—— 网上下载的 STL 常见尺寸差十倍，多半是单位选错，不是模型坏了；
- SolidWorks 装配体可以打包成 zip 导入（SOLIDWORKS、Inventor、Creo、NX、Catia、Parasolid 都支持装配 zip）：压缩前「展开到单一文件夹」、zip 名与顶层装配体同名、文件名不带特殊字符；更省事的替代是直接存成 **Parasolid（.x_t）**，两边同一个建模内核，官方也推荐这条通道；
- 有用户在官方论坛反馈把多个 STL 打包成 zip 导入会直接报「不支持 zip 的 STL 转换」—— STL 要一个一个单独导，别打包（单帖经验，供参考）。

## 四、导入进来的网格文件还能改多少

STL 这类网格体导进来后是「哑」的：没有草图、没有特征树，Onshape 能做的只是网格级别的有限操作 —— 有资深用户在官方论坛的说法是可以切割、往上面加东西，但远不如原始参数化模型顺手。所以**别把 STL 当备份格式用**：原始设计永远留在 Onshape 文档（有版本历史可回溯，见[常见问题与解决办法.md](常见问题与解决办法.md)），STL 只在你真要交切片或展示时才导出。

免费版做这些操作没有任何格式阉割，限制只在文档公开与商业用途那两条上，见[免费版和付费版区别.md](免费版和付费版区别.md)。手机上画图的流程与手势回顾见[手机上怎么画图.md](手机上怎么画图.md)。
