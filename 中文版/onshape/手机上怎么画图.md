## 一、先理解「文档」和「页签」

从桌面 CAD 过来的人最容易在这里犯迷糊：Onshape **没有本地文件**。你建的不是「一个 .xxx 文件」，而是一个**文档（Document）**——它是项目级的容器，里面可以放任意多个**页签（Tab）**，每个页签是一种工作区：

| 页签类型 | 干什么 |
| --- | --- |
| Part Studio（零件工作室） | 画草图、建零件、做曲面，建模主要在这里 |
| 装配体（Assembly） | 把零件装到一起、定义运动关系 |
| 工程图（Drawing） | 出带标注的二维图纸 |

所有改动自动保存到云端，没有「保存」按钮可按；每次大改前可以手动建「版本」，改砸了能回到任意版本。你在手机上建的文档，回头在电脑浏览器打开 [cad.onshape.com](https://cad.onshape.com) 登录同一账号，能接着改，反过来也一样。

免费版建的文档是**公开的**，任何人都能搜到、查看、复制 —— 动手前先确认这条限制你能接受，细节见[免费版和付费版区别.md](免费版和付费版区别.md)。

## 二、草图到拉伸的最短路径

第一个零件的完整动作，在 Part Studio 里从头到尾是这样：

1. 新建文档 → 添加 **Part Studio** 页签，进去后已经有一个默认的草图平面（Top 等基准面）。
2. 点「草图（Sketch）」，选一个平面，开始画：直线、矩形、圆这些基础工具就够画第一个零件。
3. 给草图加**尺寸标注** —— Onshape 是参数化建模，尺寸定死之后形状才稳定。
4. 点绿勾结束草图，然后点「拉伸（Extrude）」，选刚画的轮廓、给深度，再点绿勾。
5. 想在草图上开孔、加圆角，就回到同一张草图继续画，或再加特征；特征列表在屏幕一侧，按顺序排着，点错了可以就地改参数。

两个来自触摸屏的实操提醒：绿勾（确认）和红叉（取消）是每一步特征的开关，画完草图**必须点绿勾**，拉伸才有轮廓可选；屏幕小的时候先把视图转正再下笔，比边转边画省事得多。

输尺寸时有个免换算的技巧：任何数值栏都接受带单位的输入，比如文档默认单位是英寸，你直接键 `10mm`，系统会自动换算 —— 官方默认单位是英寸、度、磅（改法见[常见问题与解决办法.md](常见问题与解决办法.md)），中文用户第一次建模几乎都会在这里愣一下。

## 三、触摸手势表

没有鼠标，视图操作全靠手势，这批动作在 iOS、安卓上通用（官方帮助的口径，截至 2026-09）：

| 动作 | 手势 |
| --- | --- |
| 选中 | 单指点一下 |
| 清除选中 | 单指双击 |
| 3D 旋转 | 单指按住拖动 |
| 上下文菜单 | 双指点一下 |
| 框选 | 双指长按 |
| 缩放 | 双指捏合 / 张开 |
| 2D 平移 | 双指按住拖动 |
| 2D 旋转 | 双指转动 |
| 等轴测视图 | 点视图立方 → 选 Trimetric |
| 标准视图（俯 / 前 / 左等） | 点视图立方 → 选对应面 |

刚登录时应用会主动演示一遍手势，错过了也不用翻文档背 —— 界面里随时能调出上下文菜单，常用的旋转、平移练两三个零件就形成肌肉记忆了。

## 四、视图立方与观察姿势

屏幕角落那个小立方体（视图立方）是定向视图的开关：点它的一个面直接跳到俯视、前视这类正交视角，点一条棱跳等轴测。画草图前先点一下对应平面视图，草图不会因为透视变形而画歪。

设备不给力时视图操作也会跟着遭罪：老 GPU 打开 Part Studio 可能白屏或画面破碎，症状与对策单独列在[常见问题与解决办法.md](常见问题与解决办法.md)第一节。实在觉得手机屏太小，插上鼠标和键盘也能用 —— Onshape 对外接外设支持键盘快捷键和鼠标操作，平板加外设的体验已经接近轻薄本。

画完想接着做别的事：把模型导出成 STEP / STL 拿去打印或交接，操作与格式选择见[怎么导出和导入文件.md](怎么导出和导入文件.md)；文档默认公开、藏不住这件事，见[免费版和付费版区别.md](免费版和付费版区别.md)。

## 五、AR 视图：安卓端没有这个选项

查资料时会看到 Onshape 宣传 AR（增强现实）视图：把零件或装配体放进摄像头拍到的真实环境里摆放、旋转、测量，还能截图存到相册。它是视图专用模式，不能编辑模型，入口在视图立方菜单里。

但官方帮助写得很明确：**AR view 目前只在 iOS 平台支持**（Part Studio 和装配体里可用），安卓端的视图立方菜单里不会有这一项 —— 安卓用户在设置里翻不到它不是自己操作错了，是功能没开放到这个平台。想在实体场景里摆摆模型，只能换 iOS 设备登录同一账号。
