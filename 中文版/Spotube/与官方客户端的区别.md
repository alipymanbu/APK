## 一、根本差异：取数方式不同

两者最底层的差别只有一句话：Spotify 官方客户端从 Spotify 自己的服务器取一切内容；Spotube 是开源第三方客户端，曲目信息与歌单结构来自公开数据接口，实际声音从公开音频源（YouTube 一类）取。官方项目页明确声明 Spotube 与 Spotify 及其子公司没有任何隶属关系。

这个差别决定了下面表格里的每一行。

## 二、能力对照

下表汇总多个第三方来源的对比结论（截至 2026-09 检索，具体行为以你手头版本为准）：

| 对比项 | Spotube | Spotify 官方客户端 |
| --- | --- | --- |
| 免费档广告 | 官方特性列表写明无广告 | 免费档有音频/展示广告 |
| 免费档跳歌 | 第三方对比未列出跳歌限制 | 免费档有跳歌限制（规则以 Spotify 官方为准） |
| 离线下载 | 下载的是带标签的普通音频文件 | Premium 专属，文件为加密格式、只能在官方应用内播放 |
| 播客与有声书 | 多个第三方来源指出不支持，只覆盖音乐 | 完整支持 |
| Spotify Connect（设备间投射） | 第三方对比指出没有 | 支持 |
| 资源占用 | 第三方评测给出的内存占用约为官方的几分之一（约 100–150MB 对 300–800MB，仅供参考） | 官方桌面端基于 Electron，占用更高 |
| 隐私 | 开源、官方声明不收集遥测数据 | 有账号体系与个性化数据收集 |
| 账号要求 | 可匿名使用；关联 Spotify 免费账号即可 | 免费档功能受限，完整功能需订阅 |

## 三、音质与版本匹配：最常被感知的两个差距

- **音质**：声音来自公开音频源，码率取决于源本身，多个第三方来源指出通常达不到 Spotify Premium 的 320kbps 档；同一首歌在不同源下的音质也可能不同。在意音质的先在设置里调高音质选项，再决定是否满足需求。
- **版本匹配**：音频按歌名去音频源里匹配，第三方文章指出匹配算法偏向热度而非精确度，偶有把 Live 版、翻唱版当成录音室版的情况。遇到版本不对，用播放页的替代音源入口手动换（见 [搜索播放与歌单管理.md](搜索播放与歌单管理.md) 第二节）。

这两个差距的根源都是「音频来自公开音频源」这件事本身，属于用 Spotube 要接受的边界。

## 四、维护与法律状态：选版本前必读

- **官方声明**：Spotube 下载页写明 4.0.2 及更早版本已停止与 Spotify 接口配合工作、无法再使用或下载；5.0 起改为插件架构来提供元数据（缘由见 [下载与安装教程.md](下载与安装教程.md) 第五节）。
- **第三方报道**：有第三方文章提到 2025 年初项目曾收到 Spotify 方面的停止侵权函，随后才有架构重构。此说法出自单一第三方来源，官方发布说明只确认了「法律及其他问题导致长期不可用」，细节以官方口径为准。
- **持续性预期**：Spotube 依赖公开接口与公开音频源，这些接口的变化可能影响可用性——第三方对比文章也把这点列为风险。换句话说，它能用多久取决于外部接口的稳定度，这是与官方客户端在稳定性预期上的本质不同。

## 五、按需求对号入座

把上面的对照收拢成几条判断依据，结论由你自己下：

- 需要**播客、有声书、Spotify Connect、设备间无缝切换**这些官方功能 → 对照表里 Spotube 对应的行都是空白，用官方客户端。
- 现有账号是**免费档**、在意广告与跳歌限制、想要**能拿走的普通音频文件** → 这些正是 Spotube 对照表里占优的行。
- 设备老旧、在意内存占用 → 差距最大的场景，第三方评测数据可供参考。
- 想两边都用：两者并不互斥，歌单可以在两边共存，账号关联方式见 [登录与账号设置.md](登录与账号设置.md)。

装法与版本选择见 [下载与安装教程.md](下载与安装教程.md)；用起来遇到问题按 [播放失败与常见问题排查.md](播放失败与常见问题排查.md) 的症状表走。
