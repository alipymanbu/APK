## 一、5.0 起曲库信息改由插件提供

这是从旧版本升级到 5.0 后最需要知道的一件事：Spotube 5.0 把「曲库信息从哪来」改成了插件制。曲目搜索结果、歌手专辑、歌单这些元数据，不再内置固定来源，而是由你装的元数据插件提供——官方首页对此的表述是「自带音乐元数据（bring your own music metadata）」。背景是旧版直接对接 Spotify 接口的方案已终止（官方下载页写明 4.0.2 及更早已停用，来龙去脉见 [下载与安装教程.md](下载与安装教程.md) 第五节），插件制正是 5.0 为此重写的架构。

对你的直接影响：

- **全新安装 5.0 后，不装插件就没有完整的搜索与曲库浏览**，界面上会提示缺少元数据源。这不是故障，按下一节装上官方插件即可。
- 装哪个插件，决定了曲库信息的来源与覆盖面。想搜冷门曲目、古典乐、原声带，开放数据源的收录往往更全。
- 听歌记录（scrobbling）也走插件：装了 ListenBrainz 插件后，你听过什么可以记录到开放的听歌统计服务，在网页端看历史。

注意插件与登录的关系：账号关联解决「你的歌单收藏从哪来」，插件解决「曲库信息从哪来」，两者独立配置。

## 二、官方提供的两个插件

5.0 发布时官方同步提供了两个元数据插件：

| 插件 | 对应服务 | 用它能做什么 |
| --- | --- | --- |
| MusicBrainz | 开放音乐元数据库，社区维护、免费 | 提供曲目、专辑、歌手的结构化信息，是搜索与曲库浏览的数据来源 |
| ListenBrainz | MusicBrainz 体系下的开放听歌记录服务 | 记录你播放过的曲目（scrobbling），在网页端回看统计 |

只在意听歌本身的话，装 MusicBrainz 一个就够了；ListenBrainz 属于可选的记录功能，不装不影响使用。

## 三、安装与更新插件

5.0 支持从 GitHub 与 Codeberg 上的插件仓库自动获取插件（来自官方发布说明）。大致流程（具体界面文案以你手头版本为准）：

1. 进设置里的插件（Plugins）区域。
2. 浏览已收录的插件仓库，找到 MusicBrainz 或其他想装的插件。
3. 安装并启用；插件若需要自己的账号（如 ListenBrainz），按它的说明登录。
4. 有新版本时应用会弹更新提示，在插件管理里确认即可。

想自己开发插件的，官方文档（[docs.spotube.cc](https://docs.spotube.cc)）有插件系统说明与开发指南，接口基于 Kotlin/JS；普通用户只需要看安装相关的那几页。

## 四、装了插件反而出问题时

插件是第三方代码，出问题时按这个顺序处理：

- **装了插件仍搜不到、或曲库显示异常**：先停用刚装的插件再启用官方 MusicBrainz 插件，看问题是否消失——这能分清是插件的问题还是网络的问题。网络侧的排查见 [播放失败与常见问题排查.md](播放失败与常见问题排查.md)。
- **插件列表加载不出来**：插件仓库托管在 GitHub 与 Codeberg，仓库页打不开时列表自然是空的，属于网络可达性问题。
- **插件长期没更新**：5.0 起应用带插件更新检查，久未维护的插件可以停用或卸载，不影响本体其他功能。

日常搜索与播放的主线操作（不涉及插件的部分）在 [搜索播放与歌单管理.md](搜索播放与歌单管理.md)。
