## 一、Spotube 是什么形态的应用

Spotube 是一个开源的跨平台音乐客户端，作者是 Kingkor Roy Tirtho（GitHub 用户 KRTirtho），项目托管在 [github.com/KRTirtho/spotube](https://github.com/KRTirtho/spotube)。它的曲目信息与声音分别取自公开的数据源与音频源（5.0 起数据源由插件决定，见 [插件系统与音乐源配置.md](插件系统与音乐源配置.md)），界面基于 Flutter 构建，官方特性列表里还写明不收集遥测数据。截至 2026-09 检索时，项目在 GitHub 上约有 2.9 万 star（以仓库页面实时数据为准）。

同一个名字有桌面版和手机版，别搞混：Android / Windows / macOS / Linux / iOS 都有官方包，本文网盘里给的是 Android 的 APK。

## 三、Android 安装步骤

1. 从上面的 **Spotube 安装文件资源（夸克网盘）** 转存并下载 APK 到手机。
2. 在文件管理器里点开这个 APK。系统会提示「未知来源应用」，按提示允许该来源安装即可（不同品牌手机的入口名称略有差异，一般在弹窗里直接给「仍要安装 / 允许」的选项）。
3. 装完点开应用。首次启动会进引导页，让你选「匿名使用」或「关联 Spotify 账号」，两条路分别能做什么见 [登录与账号设置.md](登录与账号设置.md)，不确定就先选匿名，之后随时可以再关联。
4. 进入主界面后如果显示的是英文，去设置里把语言切成简体中文，具体入口见 [中文语言设置方法.md](中文语言设置方法.md)。

这份包标注的系统要求为 Android 5.2 以上（具体最低版本以官方下载页说明为准）；装不上时先确认系统版本，再核对下载的 APK 是否完整（体积应接近 124.70M）。

## 四、其他平台的获取渠道

Spotube 在每个平台的安装形式不一样，下表汇总官方下载页（[spotube.cc/downloads](https://spotube.cc/downloads)）列出的渠道，具体入口以该页面当时显示为准：

| 平台 | 安装形式 |
| --- | --- |
| Windows 10 / 11 | EXE 安装器，或用 winget / Scoop / Chocolatey 安装 |
| macOS | DMG（区分 Intel 与 Apple Silicon），或 Homebrew |
| Linux | Flatpak（应用 ID 为 com.github.KRTirtho.Spotube）、Debian/Ubuntu 包、Arch 系 AUR、Fedora/openSUSE 包、tar 压缩包 |
| Android | APK（官方页）或 F-Droid 商店 |
| iOS / iPadOS | IPA，需配合 AltStore / Sideloadly 侧载，不走 App Store |

iOS 那条路对普通用户门槛最高：IPA 要靠侧载工具装，证书有有效期，过期需要重新签。没有折腾意愿的话，桌面端和 Android 端才是顺手的选项。

## 五、为什么强调用 5.x：旧版本已整体不可用

Spotube 曾经长时间停更，作者在 5.0 的发布说明里明确写过：应用此前因法律及其他问题一度处于不可用状态，5.0 是回归版本。官方下载页目前还挂着一条醒目提示：**4.0.2 及更早版本已停止与 Spotify 接口配合工作，这些版本无法再使用、也无需再下载**。所以：

- 你手上如果还留着 4.x 或更早的安装包，装上也是整体不可用的状态，直接换 5.x。
- 5.0.0 除了恢复可用，还修复了一个局域网 WebSocket 相关的远程路径穿越漏洞（CVE），这是把旧版清掉的另一个理由。
- 截至 2026-09 检索时，官方已发布更新的 5.1.x 系列（新增音频源插件等能力）。网盘里是 5.0.0，是否追新自己决定，最新版本号以 [官方发布页](https://github.com/KRTirtho/spotube/releases) 为准。

它和 Spotify 官方客户端各自的边界（音质、播客、Connect 等），装之前可以先看 [与官方客户端的区别.md](与官方客户端的区别.md)。装好之后用着不顺利的，去 [播放失败与常见问题排查.md](播放失败与常见问题排查.md) 按症状对号入座。
