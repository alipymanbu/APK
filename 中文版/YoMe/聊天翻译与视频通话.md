## 一、支持哪些聊天形式

匹配成功后，聊天界面支持：

- 文字消息（最常用，翻译功能主要作用于此）；
- 语音消息与图片；
- 表情；
- 视频通话（见第四节）。

从轻到重的顺序大致是：文字 → 语音 / 图片 → 视频。刚认识就走视频的拒绝率不低，先文字聊几轮再约视频更顺。

## 二、实时翻译怎么用

按应用介绍，YoMe 内置即时翻译，聊天时自动转换文字内容，覆盖上百种语言；官方列举的支持语言包括英语、日语、韩语、西班牙语、法语、中文（普通话与粤语）、葡萄牙语、德语、意大利语、俄语、阿拉伯语等，具体以应用内实际支持列表为准。

用翻译聊天的几个实际注意点：

- 翻译是辅助不是替代：机翻长句容易丢语气，重要内容拆成短句发，翻译结果更稳；
- 网络俚语、缩写、双关语翻不准是常态，看不懂直接问对方，比猜快；
- 译文与原文存在差别，想学语言就多看原文那一行，下一节接着说。

关于收费与限量：官方介绍与第三方应用收录均称 YoMe 的聊天、使用与翻译不限次数，安装本身免费（以应用内实际为准）。但要留意场景变化——任何「充值才能继续聊」的门槛都不是这款应用的正常形态，遇到就按 [充值陷阱识别.md](充值陷阱识别.md) 的判断标准处理。

## 三、边聊边学：语言交换场景

YoMe 的定位是语言交换社区，聊天可以顺便把语言练了：

- 双方互为「母语者」：你教对方你的母语，对方陪你练你正在学的语言，各取所需；
- 按应用介绍，聊天里提供纠错工具，可以改正文中的错误表达——这比纯机翻多一层反馈，对学语言的人有用；
- 想系统练口语就约视频通话，文字阶段能聊开，视频才不冷场。

## 四、视频通话注意事项

| 事项 | 说明 |
| --- | --- |
| 网络 | 视频对带宽要求高于文字聊天，Wi-Fi 环境下体验更稳 |
| 时差 | 跨国好友的在线时段可能与你相反，约通话前先对好双方时间 |
| 隐私 | 通话中画面与声音实时传给对方，背景里别出现门牌、证件等敏感信息 |
| 安全 | 对方提出转账、借贷或让你做不舒服的事，直接挂断并举报，止损步骤见 [充值陷阱识别.md](充值陷阱识别.md) |
