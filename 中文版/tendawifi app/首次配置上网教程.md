## 一、开始前：接线与连信号

1. 把宽带线（光猫出来的网线，或入户网线）插到路由器的 **WAN 口**；不少腾达型号是 WAN/LAN 复用口，插上即可；
2. 给路由器上电，等指示灯亮起；
3. 打开手机 Wi-Fi，连接路由器的**默认信号**——名称和密码印在路由器底部贴纸上。

两个容易踩的点：

- 刚连上路由器信号时手机显示「无法上网」是**正常的**，这时候路由器还没配置，App 向导会带你走完；
- 家里如果买的是 nova（穿墙宝 / Mesh）多只装，**先只给一只上电**，等第一只配好上网了，再给其余的上电，顺序反了容易识别混乱。

## 二、App 设置向导

手机连上路由器信号后，打开 Tenda WiFi App（还没装的话先看[下载与安装教程](下载与安装教程.md)）：

1. App 会自动出现设置向导页面，点「开始设置」；
2. App 自动检测你的上网方式，按检测结果填对应信息后点「下一步」；
3. 检测结果不对时，点「其他上网方式」手动选；
4. 设置这个网络的 Wi-Fi 名称和密码，点「完成」；
5. 完成后 App 会提示后续步骤（比如 nova 系列会接着引导你放第二只的位置）。

**注意**：如果你改了 Wi-Fi 名称或密码，点完成后手机会自动断开与路由器的连接，需要用新名称、新密码重新连一次，再继续后面的操作。

## 三、三种上网方式怎么选

App 检测完一般会落在下面三种之一，对应关系：

| 上网方式 | 什么时候选 | 要填什么 |
| --- | --- | --- |
| 宽带拨号上网（PPPoE） | 运营商给了你一个宽带账号和密码，多数家庭宽带是这种 | 宽带账号、宽带密码 |
| 动态 IP 上网 | 光猫已经替你拨号，或入户线直接能自动拿到地址 | 不用填，直接下一步 |
| 静态 IP 上网 | 运营商给了固定的 IP、子网掩码、网关、DNS | 按运营商给的参数逐项填 |

不确定自己属于哪种时，找办宽带的合同或问运营商要「宽带账号密码」；填错宽带账号密码是首次配置失败最常见的原因。

## 四、设置失败的快查表

按 App 报的提示对照处理：

| App 提示 | 先查什么 |
| --- | --- |
| 「好像没插网线」 | 宽带线是否插在 WAN 口（或 WAN/LAN 复用口）、插紧没有；确认这台是主路由器而不是子节点 |
| 宽带账号密码错误 | 重新输入；注意区分大小写、别多打空格；实在不确定找运营商核对 |
| 无法连接互联网 | 光猫是否工作正常、光猫到路由器的网线是否插对；可以重启光猫再试；跳过路由器直接用电脑测一下宽带本身通不通 |
| 识别不到路由器（提示连接 Tenda 设备的 WiFi） | 手机是否连的是这台路由器的信号、有没有被切到别的 Wi-Fi；重启 App 再试 |
| 配完了但设备还是上不了网 | 先看指示灯颜色定方向：橙色闪 = WAN 没识别到网线，红色闪 = 联网失败（试光猫断电 5~10 分钟、MAC 地址克隆），对照[路由器指示灯怎么看](路由器指示灯怎么看.md)的排查链走 |

这些排查项展开的版本在[常见问题排查](常见问题排查.md)里。

## 五、不想用 App：浏览器向导也能配

腾达路由器同时支持浏览器配置：手机或电脑连上路由器网络后，浏览器地址栏输入 `tendawifi.com` 进入管理页面，跟着向导走即可，填的东西和 App 向导一样。两种方式配的是同一台路由器，配完之后 App 与网页管理页面都能管它。

配好上网、能正常联网之后，建议顺手把路由器**绑定到 App 账号**——这样人不在家也能远程查看和设置，步骤见[绑定与远程管理教程](绑定与远程管理教程.md)。
