# 路由器管理密码忘了怎么找回

> 本篇讲腾达路由器的管理密码（登录密码）忘了的处理办法：先试哪几个默认密码、为什么最后只能复位、复位的具体做法与复位之后要重做哪些事。

## 一、先说结论：没有找回，只有重置

按官方帮助中心的口径，腾达路由器的登录密码**忘了就只能恢复出厂设置**——没有邮箱找回、没有客服重置这类机制。复位前可以先试两组常见值：

| 试什么 | 说明 |
| --- | --- |
| `admin` | 老款腾达路由器的默认管理密码（新款多为一码通用或见贴纸） |
| Wi-Fi 密码 | 部分新款在首次配置时会把管理密码设成与 Wi-Fi 密码相同 |

都提示错误，就走复位。复位是「清空所有配置重来」，不是找回旧密码。

## 二、复位的三种做法

**做法 1：管理页面软复位**（还能登进管理页面时用）
浏览器输入 `tendawifi.com` 登录后，进「系统设置 > 恢复出厂设置」执行。

**做法 2：App 里复位**（路由器在线时用，人在外面也能操作）
打开 Tenda WiFi App > 首页点这台路由器 > 「网络拓扑图」> 点要复位的节点 > 右上角 > 恢复出厂设置。已绑定账号的话，远程也能做。

**做法 3：机身复位键硬复位**（登不进管理页面、App 也管不到时的兜底，也是忘记密码时最常用的）
1. 路由器保持**通电**；
2. 用针状物按住机身的 RESET 键（有的是小孔）**8~10 秒**——新款 Mesh 设备按到**指示灯红色快闪**再松手；
3. 指示灯先绿色长亮、再变慢闪，复位成功。

## 三、复位后恢复成什么

| 项目 | 复位后 |
| --- | --- |
| 管理密码 | 恢复默认，印在机身底部贴纸上 |
| 登录地址 | 默认 `192.168.0.1`（改过 LAN IP 的也会变回来） |
| Wi-Fi 名称密码 | 恢复出厂默认（贴纸上的那个） |
| 上网配置 | 全部清空，要重新走一遍设置向导 |

复位过程中别断电，断电可能把路由器刷成半初始化状态。复位成功后，重新配置上网的流程照[首次配置上网教程](首次配置上网教程.md)走一遍即可。

## 四、App 账号记得重新绑定

复位会解除路由器与 App 账号的绑定关系：复位后你在 App 里会看到这台路由器「离线」或干脆消失，这不是账号问题，是绑定没了。重新配置完上网、手机连上新 Wi-Fi 后，App 会重新提示「发现一台未绑定的路由器」，再绑一次就恢复远程管理，步骤见[绑定与远程管理教程](绑定与远程管理教程.md)。

另外两点提醒：

- 复位前如果还能登进管理页面，官方建议先**备份配置**，能省去重新逐项设置；
- 复位后如果你不确定设备上的灯该是什么状态，对照[路由器指示灯怎么看](路由器指示灯怎么看.md)判断有没有复位成功。
