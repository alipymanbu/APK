## 一、App 提示「请连接到 Tenda 设备的 WiFi 下」

意思是 App 没能发现你的路由器。按顺序查：

1. 手机是不是连着**这台路由器**的信号——配置和本地管理时，手机必须连路由器自己的 Wi-Fi，不能是邻居的、公司的或流量；
2. 连上后有没有被系统自动切到别的可上网 Wi-Fi（安卓常见），到 WLAN 设置里确认当前连接；
3. 路由器的**位置权限**给了没有（要「仅在使用中允许」那一级）；
4. 完全杀掉 App 重开一次；
5. nova 多只装的话，确认只有一只（主节点）上电，其余还没插电。

路由器那头也要查：网线是否插在 WAN 口、是否上电、指示灯状态正常——灯的颜色怎么读、对应查什么，见[路由器指示灯怎么看](路由器指示灯怎么看.md)。

## 二、远程管理连不上 / 看不到路由器

远程管理失效基本是前提条件缺了一环：

| 现象 | 缺的前提 | 处理 |
| --- | --- | --- |
| 首页没有这台路由器 | 还没绑定 | 回家连上路由器 Wi-Fi，按[绑定与远程管理教程](绑定与远程管理教程.md)绑定一次 |
| 绑过但显示离线 | 路由器自己断网了 | 在家看光猫、路由器指示灯；重启光猫和路由器 |
| 登录后设备不显示 | 登错了账号 | 远程管理认的是绑定时那个账号，换号登录试试 |
| 一切正常但操作没反应 | 临时网络问题 | 稍后重试；路由器重启期间管理会短暂失联 |

## 三、`tendawifi.com` 打不开

`tendawifi.com` 是腾达路由器的**浏览器管理入口**，和 App 管理的是同一台设备。打不开时按这条链查：

1. 你用的设备（手机 / 电脑）必须连着**这台路由器**的网络——它不是个公网网站，人不在家、设备不在这个路由器下是打不开的；
2. 地址输全：`tendawifi.com`，或直接输默认管理 IP `192.168.0.1`；
3. 如果你或别人改过局域网 IP（比如改成了 `192.168.2.1`），旧地址就失效了，用改过的新地址；
4. 还不行就用 App 管——本地 Wi-Fi 下 App 与网页入口功能基本对等，多数设置两边都能做。

## 四、App 里某些功能是灰色的

灰色表示**你这台型号不支持或不可修改**这个功能——官方配置指南里明确写了这条约定，不是 App 坏了也不是你装错版本。不同型号、不同固件版本的功能支持本来就有差异，遇到灰色选项直接跳过即可；个别设置可以试试从浏览器入口（`tendawifi.com`）找，两边功能清单不完全一样。

## 五、WPS 连接失败

用 WPS 免密连 Wi-Fi 时注意三条官方写明的限制：

- 协商窗口 **2 分钟（120 秒）**超时，超时要重按 WPS 键再来一遍；
- 协商期间 WPS 按钮不可用；
- **WPA3 加密的网络不支持 WPS**——如果你的 Wi-Fi 开了 WPA3，老设备走 WPS 是连不上的，改用密码连接，或把加密方式换成 WPA2/WPA3 混合（在 App 的 Wi-Fi 设置里改）。

## 六、想恢复出厂设置

忘记管理密码时，复位同样是唯一的出路——先试常见默认密码不行就直接复位，完整流程见[忘记管理密码怎么办](忘记管理密码怎么办.md)。常规复位方法：

- 单台路由器：上电状态下用卡针按住 **Reset** 键约 8~10 秒，指示灯快闪后松开即复位（不同型号的秒数和灯效略有差异，以机身说明为准）；
- nova / Mesh 套装：长按主节点的 Reset 或 MESH 键 8 秒左右，**整套节点**都会恢复出厂。

恢复出厂后所有配置清空，等于重新走一遍[首次配置上网教程](首次配置上网教程.md)；之前绑定的 App 账号关系也随之解除，要远程管理就在配置完之后重新绑定。

## 七、老设备（摄像头等）连不上 Wi-Fi

不少智能家居设备只支持 2.4GHz。App 里有「智能助手」之类的辅助入口，开启后手机会临时切到 2.4GHz 网络，方便你在设备的配套 App 里完成配网；也可以在 Wi-Fi 设置里把 2.4GHz 与 5GHz 分开命名，专门给这类设备连 2.4GHz 那个名字。

如果上面这些都不是你遇到的问题，或怀疑安装包本身有问题（比如装不上、闪退），先核对一下安装包版本与 MD5，重下一份再看，获取入口见[下载与安装教程](下载与安装教程.md)。
