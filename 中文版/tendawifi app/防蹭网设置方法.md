# Tenda WiFi 防蹭网设置方法

> 本篇讲用 Tenda WiFi App 查出谁在蹭你家的网、再把他们挡出去的具体做法：黑名单 / 白名单、改密码、隐藏 Wi-Fi、访客网络、限速与定时断网。

## 一、第一步：看清现在连着谁

手机连上路由器 Wi-Fi（绑定了账号的话在外网用远程管理也行），打开 App 进入「我的 Wi-Fi」，点页面下方「X 台终端」就能看到当前所有接入设备：

| 你能看到的 | 说明 |
| --- | --- |
| 设备名称 | 部分设备显示为 MAC 地址；不认识的可以先下线观察家里哪台东西没网了 |
| 接入的节点 | 多只 nova 组网时能看到它连在哪一只上 |
| 接入方式与时间 | 有线还是 Wi-Fi、什么时候连上的 |
| 上传 / 下载速率 | 判断谁在占带宽的依据 |

点任意一台设备可以进一步改备注（比如标成「客厅电视」）、限制速率、加入黑名单。

## 二、把陌生设备挡出去：黑名单与白名单

**黑名单**（点对点封禁）：发现陌生设备，点它 > 加入黑名单，它就连不上了。适合偶尔混进一两个陌生设备的情况。

**白名单**（只放行名单内的设备）：把家里自己的设备全加进白名单后，名单之外的一律上不了网。适合设备固定的家庭，一劳永逸，代价是新买的每台设备都要记得先加进去。

两种方式二选一即可；有蹭网迹象时，先改 Wi-Fi 密码再配合名单，比只拉黑更彻底——因为对方拿到旧密码后密码不改永远能再连。

## 三、改 Wi-Fi 密码与隐藏网络

- **改密码**：App 里进 Wi-Fi 设置 > 修改 Wi-Fi 名称和密码。改完家里所有设备（包括智能音箱、摄像头这类）都要重连一次；
- **隐藏 Wi-Fi**：隐藏后任何设备都搜不到这个名字，想连的人要在手机上手动「添加网络」并输入名称和密码。挡住的是随手蹭网的路人，对存心盗用的人只是增加一步，配合强密码使用；
- **信号强度**：够用的房间没必要开最大发射功率，信号出了自家门，蹭网的人也更容易够到。

## 四、访客网络：给客人单独开个门

家里来客人要上网，不用把主网络密码告诉对方：

1. App 里找到「访客 Wi-Fi」（访客网络）设置；
2. 单独设一个名称和密码，客人连这个；
3. 客人走后直接关掉。

访客网络与主网络隔离，客人看不到你主网络里接的设备，主网密码也不用外传。

## 五、限速与定时断网

- **给单台设备限速**：点设备 > 设置最大上传 / 下载速率。适合有人长时间挂下载、看直播拖慢全家的场景；
- **定时断网（家长控制）**：给孩子设备的设规则，比如 23 点之后该设备断网，作业时间不用抢手机。规则在 App 里建，到点路由器自己执行，你不在家也生效。

这几项都依赖 App 能管到路由器——本地 Wi-Fi 下直接管，人不在家就需要先完成账号绑定，步骤见[绑定与远程管理教程](绑定与远程管理教程.md)。设置过程中 App 报错、识别不到设备之类的问题，去[常见问题排查](常见问题排查.md)对号入座。
