## 一、扫不到想要的文件

按这个顺序排查，前面的概率大：

1. **是不是删太久、被覆盖了**。删除的文件随时可能被新数据顶掉——删除后又拍照、下视频、装应用，都会加速覆盖。这是最常见的原因，无解，只能下次删完立刻扫。
2. **是不是恢复出厂过**。官方 FAQ 明确：恢复出厂后没有任何工具能恢复，别再试了。
3. **权限给了吗**。文件/存储权限被拒，扫描等于空转。去系统设置 → 应用 → UltData → 权限，确认存储权限是允许；部分机型还要开「所有文件访问」。
4. **入口选对了吗**。聊天记录要走 WhatsApp 专用入口（见[WhatsApp聊天记录恢复方法.md](WhatsApp聊天记录恢复方法.md)），照片走图片入口；回收站里的东西用回收站恢复更快（见[回收站与最近删除文件怎么找回.md](回收站与最近删除文件怎么找回.md)）。
5. **换个筛选维度再看**。结果列表默认可能只显示部分条目，用「仅显示已删除项」+ 日期/大小筛选再过一遍，别急着下「没扫到」的结论。

## 二、恢复出来的照片很糊

删掉的文件留下的往往只是**缓存缩略图**，不是原图——原图区块被新数据覆盖后，能捞到的只有小图。处理办法：

1. 导出时开**星星图标 → 导出增强**，能明显改善观感（流程见[误删照片与视频怎么恢复.md](误删照片与视频怎么恢复.md)）；
2. 增强后还是糊，说明原图确实没了，缩略图就是能拿到的全部；
3. 想避免这种情况，只能在删除后第一时间扫、期间不往手机写东西。

## 三、扫描中途卡住或手机异常

- **扫描时间长是正常的**：耗时主要看存储容量、文件数量和手机性能——通用经验是快速扫描几分钟、全量深扫可能要半小时以上（非官方数字，仅作心理准备），期间别操作手机、别切应用；
- **电量保持充足**：扫到一半没电关机等于白扫，长扫描前把电充到 50% 以上或插着电扫；
- **正在扫图片时停不下来**：扫描图片要先从手机传缓存文件，当前文件传完才能中断，属正常行为；进度条走得慢不等于卡死，看计数器还在不在动；
- **手机重启后界面点不动**：重启后一堆应用在后台抢资源，先关掉网络再操作；
- **权限框弹不出来**：检查系统设置里 UltData 的权限有没有给全（存储、后台弹出界面等），给全后重新扫一次；个别机型还要允许它「安装未知应用」，扫描涉及应用重装时会用到。

## 四、其他常见疑问

| 问题 | 答案 |
| --- | --- |
| 需要 root 吗 | 不需要，全程免 root |
| 要连电脑吗 | 手机版不用，装在手机上直接扫；连电脑的是另一套（电脑版）流程 |
| 扫描要联网吗 | 扫描和恢复都在本地完成，不依赖网络 |
| 恢复的文件存哪 | 导出后点「查看」直接跳转保存路径，具体见[误删照片与视频怎么恢复.md](误删照片与视频怎么恢复.md) |
| 能保证全找回来吗 | 不能。官方口径是不保证 100%，越早用成功率越高 |
| 要付费吗 | 扫描和预览免费，导出恢复要付费版；判断值不值得买见[免费版能用到哪一步.md](免费版能用到哪一步.md) |
| 导出时提示空间不足 | 手机剩余空间要装得下导出的文件，先清理出几百 MB 再导，或导到 SD 卡 |
| 装不上/提示解析错误 | 多半是下载不完整或系统版本低于安卓 5.2，重下一遍；包的信息见[下载与安装教程.md](下载与安装教程.md) |

版本号、包名这类事实一律以[下载与安装教程.md](下载与安装教程.md) 里的本地采集记录为准；官方功能说明以官网当时显示为准。
