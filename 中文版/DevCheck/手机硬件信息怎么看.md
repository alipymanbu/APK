# 手机硬件信息怎么看

## 一、仪表盘：先扫这一页

仪表盘是总览页，实时刷新这几项：CPU 频率、内存占用、电池统计、深度休眠时长、开机时长，另外还放了一批进系统设置的快捷入口。

两个可以点的地方：

- **点 CPU 频率**：进一份可排序的频率统计，能看到各核心在每个频率上待了多久、深度休眠累计多久 —— 判断「这台机子是不是一直跑在高频」就看它。
- **点温度**（这台机子读得到温度的话）：列出机身内全部温度传感器的实时读数。读不到温度是常见情况，原因与解法见 [Pro功能与常见问题.md](Pro功能与常见问题.md)。

## 二、硬件页：这台机子的底子

硬件页是配置清单，从上到下大致是：

| 分区 | 你会看到 |
| --- | --- |
| SoC / CPU | 芯片型号与厂商、架构、核心数与大小核配置、制造工艺、当前频率、调速器 |
| GPU | 型号、OpenGL 版本、当前频率 |
| 内存 | 容量、类型、带宽（能否识别双通道也在这里看） |
| 存储 | 容量与实际可用空间 |
| 显示 | 分辨率、刷新率、面板类型、密度 |
| 蓝牙等 | 版本、已配对设备信息 |

最值得逐项对照宣传页的是三处：**SoC/GPU 型号、内存容量、存储容量** —— 这三样最容易在翻新机、扩容机上露馅。完整验机流程见 [二手手机验机教程.md](二手手机验机教程.md)。

部分字段（某些频率、调速器、每应用内存占用）只在给了 root 权限后才完整，没给时显示为空属于正常。

## 三、系统页：软件层面的底细

这一页给的是系统身份信息：设备代号、品牌、制造商、bootloader、基带、Android 版本、安全补丁级别、内核版本，另外还能查 **root、BusyBox、KNOX 状态**。

二手机到手先翻这页：Android 版本、安全补丁日期如果明显落后于卖家宣传，或者 root 状态与描述不符，后面就该多留个心眼（展开见 [二手手机验机教程.md](二手手机验机教程.md)）。

## 四、网络页怎么看

网络页分 Wi-Fi 与移动网络两部分：IPv4 / IPv6 地址、连接详情、运营商、网络类型、公共 IP，双卡手机还会把两张卡的信息分别列出。排查「连不上网」「IP 不对」这类问题时，先截这一页的图再找原因。

## 五、传感器页：能实时画图的硬件

传感器页列出全部传感器：类型、厂商、功耗、分辨率，其中加速度计、陀螺仪、接近、光线、计步等支持实时曲线。气压计（压力传感器）也在这一页，很多人拿它做密封性参考测试，方法见 [气密性检测教程.md](气密性检测教程.md)。

## 六、读不到的项目怎么办

Android 不会把所有硬件细节开放给应用，各厂商上报的口径也不一致；DevCheck 对「几台机器报得对不上」的字段宁可空着也不猜，所以少几项、空几项是常态。装 Shizuku 或给 root 权限能多解锁一批读数（温度、电池循环次数与健康度、CPU 负载、GPU 频率等），具体做法见 [Pro功能与常见问题.md](Pro功能与常见问题.md)。
