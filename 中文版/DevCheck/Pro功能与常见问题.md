## 一、免费版和 Pro 的分界

先说结论：**看信息全免费，也要花钱的是「加料功能」**。全部硬件与系统信息、实时监控都不收费，应用也没有广告；Pro 解锁的是下面这些：

| 类别 | 免费版 | Pro |
| --- | --- | --- |
| 硬件 / 系统 / 电池 / 网络 / 传感器信息 | 有 | 同左 |
| 硬件测试（手电筒、振动、按键、多点触控、屏幕等） | 部分 | 全部 |
| 工具（Root 检查、蓝牙扫描、CPU 分析等） | 部分 | 含完整性检查、权限汇总、Wi-Fi 扫描、网络映射、GPS、USB 检查等 |
| 跑分 | 基础跑分 | Benchmark Labs |
| 电池监控（亮屏/灭屏统计） | 无 | 有 |
| 悬浮监视窗（切到别的应用也实时显示） | 无 | 有，可调大小、透明度、位置 |
| 桌面小组件 | 无 | 有 |
| 配色方案 | 默认 | 多套明暗主题与配色 |

日常「看参数、验机、查电池」，免费版已经够用；要跑完整测试、挂悬浮窗盯频率与温度，才需要 Pro。

## 二、Pro 怎么买、怎么恢复

Pro 通过应用内购买（Google Play 渠道）提供**月订阅、年订阅、买断**三种，解锁的功能完全一样，价格按各国区服显示；订阅在 Google Play 的「付款与订阅」里管理。Pro 绑定你的 Google 账号，同一账号登录的多台设备都能用，不用每台买一次。

买了却仍显示免费版时，按这个顺序排查：

1. 确认手机登录 Google Play 用的是**购买时那个账号**；
2. 还不行就清一次 Play 商店的数据：设置 → 应用 → Google Play 商店 → 存储 → 清除数据，然后重启手机；
3. 依旧没恢复，直接发邮件给开发者，别重复购买。

## 三、看不到温度读数

很多手机把温度传感器对应用屏蔽了，**联发科平台尤其普遍**。两条解法：

- 装 **Shizuku** 后再开 DevCheck，多数机型就能读到温度；
- 已经 root 的机器，直接给 DevCheck root 权限。

同一个原因也解释了为什么你的电池页缺循环次数、CPU 负载是空的 —— 都是同一道权限门槛，见 [电池健康度查看教程.md](电池健康度查看教程.md)。

## 四、Shizuku 是什么、怎么开

Shizuku 是个免费开源工具，让普通应用用上系统级权限：**它不 root、不改动你的手机**。启动方式两种 —— Android 11 及以上用「无线调试」配对启动，或在电脑上用 adb 启动一次（之后自持运行）。Google Play 装不到的话，去它的 [GitHub 发布页](https://github.com/RikkaApps/Shizuku/releases) 下载。

Shizuku 运行时打开 DevCheck，你能多看到：温度、电池循环次数与健康度、CPU 负载等。它在大多数机型上有效，不保证每一台都行。DevCheck 这边不需要额外设置，检测到 Shizuku 在跑就会自动多读。

## 五、root 权限怎么给它

DevCheck **不要求你为了它去 root**：Shizuku 能覆盖大部分需求。确实已经 root 的话，点右上角菜单 → Root access → 在弹出的授权框里同意即可，之后能多出 CPU 负载、温度、GPU 频率、每应用内存占用这些细项。

## 六、跑分是怎么算的

跑分测 CPU、内存、磁盘、GPU 四个部分共 27 个子项：每个子项对固定基准打分，先在各部分内取几何平均，再对四部分取等权几何平均 —— 这样单一部分拉高拉低都不至于左右总分。磁盘成绩反映的是「装好系统、开着加密之后」的实际读写，所以同款芯片的两台机器分数也可能不同。

分数是否上传由你决定，提交的会进官网[跑分排行榜](https://devcheck.app/benchmarks)，可按机型、芯片、GPU 对照。

## 七、找不到网传的「帧数显示」按钮

网上一些第三方教程把「主界面点帧数显示 → 悬浮窗看游戏帧率」写成 DevCheck 的固定功能，你照着找却看不到这个入口 —— 两种可能并存：官方的功能清单里，悬浮监视窗列出的是 CPU 频率、温度、GPU 频率、电池、网络活动、内存与系统负载，并没有点名帧率；而部分教程描述的界面与你的版本对不上（版本差异，或文案在站与站之间转抄）。**以你手里 6.49 的实际界面为准**，找不到就是没有，不必硬找。

要边玩边看帧率，更稳的路子是手机自带的游戏工具箱 / 游戏模式（Android 官方的游戏信息中心里就有 FPS 计数器），不用依赖第三方应用的悬浮窗。

## 八、隐私与反馈

DevCheck 不收集姓名、账号、联系人、文件、位置这类个人信息，你在界面上看到的数据只从本机读取。它会发送**匿名的硬件校验请求**，新机型会按机型聚合提交一份匿名规格（用来完善公开硬件库）；跑分上传则是可选项，只有你主动提交才发生。
