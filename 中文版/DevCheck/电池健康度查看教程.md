## 一、电池页有哪些字段

进 DevCheck 的电池页，从上到下能看到这些实时数据：

| 字段 | 含义 |
| --- | --- |
| 状态 | 充电中 / 已充满 / 放电中 |
| 电量、技术 | 当前百分比、电池化学类型 |
| 温度、健康 | 电池温度、健康状态 |
| 电压、电流、功率 | 实时电气参数，充电时看这三个 |
| 容量 | 当前可用电量的估算值 |

这些数值全部来自手机电池驱动上报的原始读数，DevCheck 只负责把它们显示出来，不做换算。

## 二、循环次数在哪看

循环次数（充放电周期数）不在电池页的主列表里，而在电池页的设置里：进入电池页 → 点右上角**齿轮图标** → 进入电池设置，循环次数与相关选项就在其中（不同版本入口可能略有差别，以你的界面为准）。

**前提是你这台手机肯把这个数给应用** —— 看不到时先读下一节，别急着以为版本不对。

## 三、为什么你看不到循环次数和健康度

这是问得最多的一类问题，原因基本固定：

1. **厂商对应用隐藏了这些字段**。很多手机不把循环次数、健康度开放给普通应用，DevCheck 只能显示「手机给它的」。
2. **装 Shizuku 或给 root 权限能解开一大半**：这两种方式都能让 DevCheck 读到更多底层数据，包括循环次数、健康度、估算容量。Shizuku 是免费工具、不用 root、不改你的手机，怎么开见 [Pro功能与常见问题.md](Pro功能与常见问题.md)。
3. **健康度常常要充满一次才出现**：不少机型在电池充到 100% 之后，健康度才会显示出来。
4. **双电芯机型可能永远不给**：小米、POCO 这类双电池方案的手机，如果 DevCheck 读不到准确数据，会干脆不显示容量估算 —— 显示一个错的比不显示更糟，这是它的取舍。
5. **少数机型对任何应用都不开放**：这种情况下换哪个工具都读不到，不是 DevCheck 的问题。

## 四、充电电流、电压看起来「不对」是正常的

快充时你常会发现电流或功率远低于充电器标称值，这不是数据错了，而是各手机上报口径不同：

- 有的机型测的是**电池端**而非充电端的电流；
- 双电芯机型可能只上报其中一格的数值；
- 有的机型刷新很慢，你看到的是几秒前的读数。

所以这三个数用来**看趋势**（插电后电流是否上来、拔电后是否归零）比用绝对值较真更靠谱。
