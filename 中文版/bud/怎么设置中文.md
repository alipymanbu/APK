## 一、先说结论：入口在设置里的 Language

BUD 面向全球发行，官方商店列出英语之外还有 15 种以上语言，简体中文在列。应用不一定默认跟随手机系统语言，不少用户装完看到的是英文界面。社区教程（2024 年版本）给出的换中文路径是：

1. 进入主界面后，点**右上角三条横线**的菜单图标；
2. 选 **Settings**（设置）；
3. 选 **Language**（语言）；
4. 在列表里找到 **简体中文**，选中后点 **Done** 确认。

设置一次就会记住，之后再进应用仍是中文（社区教程口径）。也有版本把语言入口放在主界面下方的地图图标菜单里 —— 路径可能因版本不同而不同，但找的东西都一样：**设置页里的「Language / 语言」**。按上面路径没找到的话，就在设置页里翻一下带「Language」字样的那一项。

还有一条更早的入口：有第三方教程（2026 年 8 月，配 2.3.5 版本截图）演示过在**登录界面**右下角的图标里直接选 **Language**，下滑找到「中文（简体）」，点 **Done** —— 也就是不用先进主界面，装完第一次打开就能把语言切好。

## 二、界面全是英文时的对照

| 你想找的 | 屏幕上显示的 |
| --- | --- |
| 设置 | Settings |
| 语言 | Language |
| 简体中文 | Chinese (Simplified) / 简体中文 |
| 确认 | Done / OK |

选完语言如果界面没立刻变，把应用完全退出（从后台划掉）再重新打开一次。

## 三、设置完中文还要知道的

- 换的只是**界面语言**：世界标题、聊天内容、别人写的简介是其他用户创作的内容，不会跟着翻译；
- 商城里的部分活动道具名可能仍以英文显示，属于正常现象；
- 想换回英文或其他语言，走同一条路径再选一次即可。

还没装应用的话，安装包与系统要求见 [下载与安装教程.md](下载与安装教程.md)；进去之后该玩什么，见 [新手入门玩法指南.md](新手入门玩法指南.md)。
