## 一、加好友：搜名字或搜 ID

社区图文教程（2024 年版本，配截图）给出的路径：

1. 在首页点**左下角的箭头**，展开好友栏；
2. 点**添加好友**；
3. 输入对方的**名字或 ID**，点搜索，找到后发送好友请求。

两个实用点：

- **ID 比名字准**。社区攻略对 ID 的描述是「字母和数字混合」的一串；重名的人不少，能拿到 ID 就用 ID 搜；
- 输入前先跟对方核对一遍拼写与大小写，错一个字符就搜不到人。

同一个世界里遇到的玩家，也是加好友最自然的来源 —— 先玩几局跑酷再互加，比凭空搜人容易，玩法入口见 [新手入门玩法指南.md](新手入门玩法指南.md)。

## 二、改名字 / 改 ID

同一场社区教程给出的入口：

1. 点**编辑个人资料**（教程原文写作「编辑配置文件」，英文界面下是 Edit Profile 一类字样）；
2. 在资料页里选**更改名称（ID）**或**更改用户名**。

教程里把「名称（ID）」与「用户名」并列成两项 —— 一个是别人看到的称呼，一个是加好友时搜的那串字母数字组合；具体到你的版本，以资料页实际显示的字段为准。改之前想好：朋友搜你靠的就是这两样，频繁改名会让人找不到你。

## 三、搜不到人时按这个顺序排

1. 换 **ID** 搜，不要只用名字；
2. 核对大小写、多打或漏打的字符；
3. 还不行就让对方在资料页把 ID 复制发你，照着输入。

菜单还没切成中文的话，先按 [怎么设置中文.md](怎么设置中文.md) 把界面换掉再操作，省得对着英文找按钮。
