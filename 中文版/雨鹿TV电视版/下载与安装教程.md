## 一、雨鹿TV电视版是什么

雨鹿TV电视版是一款装在智能电视、电视盒子上的安卓影视应用，打开后直接浏览影片、搜索点播，不需要注册登录。它的资源接口是内置的，装好就能用，不用自己另外配置。你在下载站和介绍页上也会看到「雨鹿TV」这个简称，指的是同一个应用。

| 安装包大小 | 48.26M（约 50,606,008 字节） |

网上下载站标着的版本号和体积常常和上表对不上——那是它们自己渠道的版本，**你实际要装的以上表为准**（也就是网盘里那份）。核对U盘里拷的是不是同一份文件，比对 MD5 即可。另注：部分下载站把系统要求标成 Android 4.0，与这份包说明的 5.2 不一致，装不上时以 5.2 这条线为准排查。

## 二、安装包从哪拿

从 [雨鹿TV电视版 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6a035fdffa4c) 转存或下载 APK 文件。文件名形如 `雨鹿TV电视版_v2.5.1.apk`，下载完先确认后缀是 `.apk`、体积约 48.26M，再进行下一步。

在电脑上下最顺手——反正最终要通过U盘送进电视，电脑下载后直接拷盘少一道中转。

## 三、U盘安装步骤（电视 / 盒子）

1. 准备一个U盘，在电脑上把下载好的 `.apk` 文件拷进U盘根目录（放根目录最好找）。
2. 电视或盒子上找到设置里的安全项，把「允许安装未知来源的应用 / 安装未知应用」设为允许。不同品牌叫法不同，常见位置是 `设置 → 账号与安全`、`设置 → 安全`、`设置 → 通用 → 外部来源应用`。
3. 把U盘插进电视的 USB 接口。部分电视会自动弹出检测到U盘的提示；没弹的话，打开系统自带的「文件管理 / U盘 / 媒体中心」找到U盘。
4. 点那个 `.apk` 文件，弹出安装界面后确认安装，等进度走完。
5. 装完先别急着拔盘——打开应用确认能进首页（能出影片列表就算成功），再退出、拔盘。

手机上装法完全一样：设置里允许安装未知来源，然后用文件管理器点 APK 安装。

## 四、没有U盘时的其他送包方式

- **手机/电脑直装**：把 APK 传到手机（微信文件传输、数据线均可），手机上允许未知来源后用文件管理器点装。装法与第三节第 5 步相同。
- **局域网传输工具**：电视和手机/电脑连同一个 Wi-Fi，用电视品牌自带的「投屏助手 / 文件投送」类功能，或第三方局域网传输应用把 APK 推到电视，再从电视的文件管理器里点装。
- **读卡器 + SD卡**：老电视没有USB口但有SD卡槽时，等同U盘流程。

不论走哪种方式，最终都要回到「允许未知来源 → 文件管理器点 APK → 确认安装」这三步。

## 五、装完第一次打开注意什么

- **需要联网**。影片列表和播放都走网络，没连 Wi-Fi 或网线时进去只有空界面。
- 第一次启动会加载资源列表，转一会儿圈是正常的。
- 遥控器是主要输入设备，装完先看 [怎么看剧与搜索影片.md](怎么看剧与搜索影片.md) 熟悉浏览、搜索与播放。
- 同一部片某个线路放不出来、或者转圈卡住，按 [怎么换源与切换线路.md](怎么换源与切换线路.md) 换线路；换了还不行，走 [播放卡顿与打不开排查.md](播放卡顿与打不开排查.md) 逐条排查。

## 六、安装时的报错对照

| 提示 | 原因 | 处理 |
|---|---|---|
| 「解析包时出现问题 / 包损坏」 | 拷贝不完整，或下载中断 | 核对体积是否约 48.26M、MD5 是否为 `70FA3BC0B20A4F8EA90D2BAC0FF80ADA`，不对就重新下、重新拷 |
| 「禁止安装未知来源应用」 | 系统安全开关没开 | 回到第三节第 2 步，允许未知来源后再点一次 APK |
| 「安装失败 / 应用未安装」 | 存储空间不足，或残留旧版冲突 | 清出几百 MB 空间；仍失败就先卸载旧版再装 |
| 「解析错误 / 设备不兼容」 | 系统版本低于要求 | 这份包要求安卓 5.2 及以上，先在 `设置 → 关于` 里确认系统版本 |
| 装完桌面找不到图标 | 部分系统不给第三方应用建快捷方式 | 到 `系统设置 → 应用 → 已安装应用` 里找，或用文件管理器再点一次 APK 选择「打开」 |

## 七、覆盖安装与卸载

同一个包名（`com.ylttv.vip`）的新版本 APK 可以直接覆盖安装，观看历史和追剧列表一般会保留在本地。若覆盖后打不开，先在系统设置的应用管理里给它清一次缓存；还不行就卸载重装——历史记录会清掉，见 [播放卡顿与打不开排查.md](播放卡顿与打不开排查.md) 的重装一节。

卸载直接在 `系统设置 → 应用` 里卸载即可，不会影响电视上其他应用。
