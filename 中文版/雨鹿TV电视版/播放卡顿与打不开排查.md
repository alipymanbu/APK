## 一、先判断问题出在哪一层

排查前先花一分钟定位范围，能省掉一堆无用功：

| 症状 | 更可能的原因 | 直接跳到 |
|---|---|---|
| 只有某一部片转圈，别的都正常 | 这条线路的问题 | [怎么换源与切换线路.md](怎么换源与切换线路.md) |
| 所有片都卡、首页图都加载慢 | 网络 | 第二节 |
| 有画面没声音，或黑屏但有声音 | 解码方式 | 第四节 |
| 应用打不开、点图标闪一下就退 | 系统版本 / 缓存 / 存储 | 第五节 |
| 搜索结果里没有想看的片 | 线路资源覆盖 | 第六节 |
| 装都装不上 | 安装环节 | [下载与安装教程.md](下载与安装教程.md) |

## 二、全都卡：从网络查起

1. **先测速**：用电视自带浏览器或盒子的测速功能看带宽。标清要 3M 以上、高清建议 10M 以上、4K 建议 30M 以上（经验值，以实际流畅度为准）。
2. **能插网线就插**：电视离路由器近时，有线比 Wi-Fi 稳，尤其 5GHz 穿一堵墙衰减就很明显。
3. **减负**：同一网络里手机在下大文件、别人在看别的平台 4K，都会抢带宽——停掉再试。
4. **错峰**：晚上八到十点是小区宽带高峰，同样的卡法换个时段不卡，说明是运营商拥堵，应用侧无解。
5. **换个网络试**：让电视连一次手机热点（或用盒子的网线口插网线）。热点下正常、自家 Wi-Fi 下不正常，问题在路由器这一侧——重启光猫路由器，或检查是不是有人在占带宽。
6. **重启链路**：光猫和路由器断电 30 秒再通电，电视也重启一次，很多「突然变卡」到这一步就好了。

网络正常但仍旧全盘卡，进入第三节。

## 三、网络正常却还是卡

1. **清缓存**：`系统设置 → 应用 → 找到雨鹿TV电视版 → 存储 → 清除缓存`（注意只点「清除缓存」，别点「清除数据」，否则观看历史和追剧列表会被清掉）。
2. **重启应用**：从最近任务里把应用彻底划掉再重开。
3. **换线路**：清完缓存先按 [怎么换源与切换线路.md](怎么换源与切换线路.md) 换一条线路再试——有时卡的是单一源的服务器，与你家网络无关。
4. **看设备温度**：盒子长时间运行会发烫降频，摸一下烫手就断电放凉再开。

## 四、黑屏、有声无画、画面卡住

1. **先换线路**：单线路的视频流损坏会造成黑屏有声，换源往往直接解决。
2. **找解码选项**：若播放控制条或设置里有「解码方式 / 软解硬解 / 播放器内核」这类选项，切换一次再播——有画面没声音、或画面定住声音正常，多数是解码方式与该片源不匹配。
3. **确认不是电视输出问题**：用电视自带播放器放个本地视频试试；本地也黑，问题在电视信号设置，不在应用。

## 五、打不开、闪退、点图标没反应

按顺序做，做到哪步好了就停：

1. **查系统版本**：`设置 → 关于`，这份包要求安卓 5.2 及以上，低于它装上了也跑不起来。
2. **查存储**：`设置 → 存储`，可用空间低于几百 MB 时应用容易起不来——48.26M 的包装不进去或开一下就退，多半是空间耗尽，按 [电视盒子存储不足怎么清理.md](电视盒子存储不足怎么清理.md) 从缓存开始清。
3. **清缓存**：按第三节第 1 步操作。
4. **强停再开**：`系统设置 → 应用 → 雨鹿TV电视版 → 强行停止`，再从桌面重新打开。
5. **重启设备**：别只用遥控器待机——直接拔掉电源等 30 秒再插上通电，让盒子彻底软重启一次。
6. **重装**：以上都无效就卸载，重新按 [下载与安装教程.md](下载与安装教程.md) 装一遍。重装会清掉本机的观看历史与追剧列表，介意的话在卸载前确认没有别的备份方式可选。

## 六、搜索找不到想看的片

- **换线路再搜**：各线路资源覆盖不同，一条线路没有不代表没有——退出搜索，先切线路（[怎么换源与切换线路.md](怎么换源与切换线路.md)）再搜一次。
- **换关键词**：只输片名里最有辨识度的两三个字；记不住片名时改输演员名。
- **确认网络正常**：搜索结果本身也是联网拉取的，网络不通时搜索页会是空的，这时按第二节查网络。

## 七、还是没解决

逐条做完仍异常时，记录两件事再去求助或反馈：一是**设备型号与安卓版本**，二是**具体症状**（哪个环节、报什么字、从什么时候开始）。有这两条信息，问题基本能被复现——比笼统说「看不了」有用得多。
