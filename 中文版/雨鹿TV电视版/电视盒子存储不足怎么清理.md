# 电视盒子存储不足怎么清理

> 这篇讲电视/盒子提示存储空间不足时怎么清：先确认剩多少，再按「缓存 → 不用的应用 → 残留安装包 → 扩容」的顺序清，最后才是恢复出厂。

## 一、先确认是不是存储问题

盒子和电视的存储满了，症状很固定，对上任意两条基本就能定位：

- 装 APK 时提示「存储空间不足」「应用未安装」——48.26M 的雨鹿TV电视版都装不进去，说明空间已经非常紧张；
- 应用打开就退、用一会儿自动关闭；
- 系统整体变慢、转圈变多，应用更新老是失败；
- 桌面提示「可用空间不足」。

先看数：`设置 → 存储`（有的叫「设备偏好 → 存储」），记下剩余可用空间。**剩余低于几百 MB 就按下面的顺序开清**；还有好几 GB 却依然报错，那不是空间问题，走 [播放卡顿与打不开排查.md](播放卡顿与打不开排查.md)。

## 二、清理顺序：从无损到有损

按这个顺序做，做到哪步空间够了就停：

1. **清应用缓存**（无损，先做）。`设置 → 应用 → 查看全部应用`，逐个进入占用大的应用，选「存储」→「清除缓存」。缓存是临时文件，清掉不丢任何东西。只点「清除缓存」，**别点「清除数据」**——后者会把该应用的登录、历史、配置全部清空。
2. **卸载不用的应用**。同一个列表里，凡是装完没再打开过的，直接卸载。卸载比停用释放得更彻底。
3. **删掉残留的安装包**。以前侧载装应用留下的 `.apk` 文件还躺在 `文件管理 → Download / 下载` 目录里，装成功后它们就没用了，删掉能腾出几十到几百 MB。
4. **停用预装应用**。厂商预装的应用往往没有「卸载」按钮，但有「停用 / 禁用」——停用后它不再占数据、也不在桌面显示，等同于清掉。
5. **把文件挪到外接存储**。电视上有 U 盘/SD 卡插着的话，用文件管理器把视频、安装包等大文件挪过去；部分设备还支持把应用装到外置存储（`设置 → 应用 → 选择应用 → 存储 → 更改存储位置`，有这个选项才可用）。
6. **恢复出厂设置——最后手段**。以上全做完还不够，才考虑 `设置 → 系统 → 恢复出厂设置`。它会清空设备上**全部**数据与设置，做完等于新机器，所有应用都要重装，动手前先把能接受的损失想清楚。

## 三、清缓存和清数据的区别

| 操作 | 删掉什么 | 会丢什么 |
|---|---|---|
| 清除缓存 | 应用运行产生的临时文件 | 什么都不丢，随时可清 |
| 清除数据 / 存储 | 登录状态、观看历史、追剧列表、配置 | 全部归零，等于刚装好的状态 |

排查 [播放卡顿与打不开排查.md](播放卡顿与打不开排查.md) 时反复用到第一步，就是只清缓存这个动作——它便宜、无损，理应排最前面。

## 四、清完之后

1. 重启设备（断电 30 秒再通电，比待机重启彻底）。
2. 回 `设置 → 存储` 确认可用空间已经上来。
3. 还装不上雨鹿TV电视版，重新走一遍 [下载与安装教程.md](下载与安装教程.md)；装上了但应用行为异常，回 [播放卡顿与打不开排查.md](播放卡顿与打不开排查.md) 继续定位。

## 五、两条注意

- 清理时别在来路不明的「一键清理大师」类应用里点授权——这类应用本身就在占空间、要权限，清理工具用系统自带的 `设置 → 存储` 就够。
- 清理不是一次性动作：盒子存储普遍只有 8~32G，系统本身要占去一大块，隔几个月回来看一眼剩余空间，能避免下次又在安装时卡住。
