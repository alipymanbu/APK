## 一、先说结论

雨鹿TV电视版打开就能看，不需要注册、不需要登录、也不用另外配置资源接口——装好、联网、进首页，用遥控器选片或搜片，点进去等加载完就能播。这篇把每一步的入口和操作讲清楚，首次上手照着走一遍即可。

## 二、首页与分类浏览

进应用后直接落在首页，首页会按电影、电视剧、综艺、动漫、纪录片等分类陈列影片（具体栏目名以你手上版本的界面为准）。遥控器方向键在海报之间移动，选中后按确定键进详情页。

详情页里能看到剧集列表（电视剧是分集排列的）、简介和线路信息。想看哪集就移动到哪一集按确定。

部分介绍页还提到可按类型、地区、演员、评分做筛选——如果你的版本界面上有筛选入口，一般在分类页或搜索页，找带「筛选」字样的选项即可；找不到这组入口也不影响正常看剧，搜索一样能定位片子。

## 三、搜索影片

1. 在首页找到搜索入口（通常是顶部的放大镜图标或「搜索」字样），按确定进入。
2. 用遥控器方向键在屏幕键盘上选字，输入片名。片名越短越好输，比如只输两个核心字。
3. 输入过程中结果通常会实时刷新，看到目标就直接移过去按确定，省得输全。
4. 搜演员名也能出作品列表，想不起片名时换个思路输人名。

输错了用屏幕键盘上的退格键删；整个输入界面按遥控器的返回键可退回首页。

## 四、播放界面操作

点进影片后等加载，缓冲完成自动开始播。播放中常用的几个操作：

| 想做什么 | 怎么操作 |
|---|---|
| 暂停 / 继续 | 遥控器确定键或播放/暂停键 |
| 快进 / 快退 | 方向键左右（按住加速） |
| 调出进度条与菜单 | 按确定键或上方向键唤出控制条 |
| 全屏 / 退出全屏 | 播放器里的全屏按钮；部分片源默认就是全屏 |
| 换集 | 调出菜单后选集数，或退出到详情页另选一集 |
| 换线路 | 见 [怎么换源与切换线路.md](怎么换源与切换线路.md) |

具体按键映射随遥控器型号和应用版本略有差异，按屏幕上弹出的提示为准。

## 五、追剧列表与观看历史

- **观看历史 / 记录**：看过的片子会留在历史入口里，下次进去从上次的进度续看，不用重新找。
- **追剧列表 / 收藏**：在详情页可以把剧加入追剧或收藏，之后从对应入口直达，追更时省去重复搜索。
- **更新提醒**：介绍页提到新集上线会有提醒；若你的版本里有通知开关，可在设置里决定开不开。

这几项数据默认存在本机：卸载或清数据会把它们清掉，重装前想保留就别点「清除数据」，只清缓存即可（见 [播放卡顿与打不开排查.md](播放卡顿与打不开排查.md)）。

## 六、第一次上手的推荐动线

1. 按 [下载与安装教程.md](下载与安装教程.md) 装好并确认联网。
2. 首页随便点一部热片区的片子，把暂停、快进、全屏这三个键位摸熟。
3. 退出来试一次搜索：输两个字找到目标影片。
4. 把正在追的剧加进追剧列表，退出重进验证能续播。
5. 遇到某个片子转圈放不出来，直接跳到 [怎么换源与切换线路.md](怎么换源与切换线路.md) 换线路。
