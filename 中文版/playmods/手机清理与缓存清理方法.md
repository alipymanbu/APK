# PlayMods 手机清理与缓存清理方法

> 本篇讲怎么用 PlayMods 内置的「手机清理」功能清掉缓存与下载残留，以及清理前要注意什么。

## 一、清理入口在哪

1. 打开 PlayMods，点底部导航栏的**「我的」**；
2. 在功能列表里找到**「手机清理」**，点进去。

## 二、清理步骤

1. 进入手机清理，等它把垃圾扫描完；
2. 核对扫描出来的项目（缓存、内存垃圾、安装包残留这几类）；
3. 点**「清除」**完成。

多个独立教程对这一流程的记录一致，均为「我的 → 手机清理 → 扫描 → 清除」；分类名称以你手机上的实际界面为准。

## 三、能清掉什么

| 类别 | 说明 |
| --- | --- |
| 缓存垃圾 | 应用与游戏运行积累的缓存 |
| 内存垃圾 | 运行残留的临时文件 |
| 安装包残留 | 游戏下载安装后留下的安装文件，通常是占空间的大头 |

## 四、清理前注意两件事

1. **游戏数据可能要重下**：清掉缓存后，部分游戏的资源数据会需要重新下载；
2. **先备份存档**：托卡世界这类依赖存档的游戏，清理前先把存档上传云端，具体见 [托卡世界工具与云存档.md](托卡世界工具与云存档.md)，存档覆盖的代价那里写得很清楚。

## 五、清完空间还是不够

1. 到系统设置的存储页看占用大头在哪，别只盯着缓存；
2. 下载过但不打算再玩的游戏，可以在 PlayMods 里删掉，需要时再下；
3. 装游戏时提示空间不足、安装失败的排查清单在 [常见问题与解决方法.md](常见问题与解决方法.md)。
