## 一、它和「纪念日倒计时」不是一类东西

搜「倒计时」出来的绝大多数是**自己建事件**的工具：生日、考试、假期，填个日期就往回数。本篇说的这个不一样 —— 你建不了任何事件，打开就是它给你的五组数字。

| 对照项 | 本篇这个（电影同款） | 常见的纪念日倒计时 |
| --- | --- | --- |
| 包名 | `com.rbcd.countdownapp` | 各家不同，常见的如 `com.roc.dreamdays` |
| 开发者 | Ryan Boyling（个人） | 各厂商 |
| 商店类别 | 娱乐 | 效率 / 生活 |
| 打开后 | 五组数字自己跑，你只能看 | 先建事件，日期你定 |
| 声光震特效 | 有，且是主要卖点 | 无 |
| 广告 | 有，且会插进倒计时过程 | 视应用而定 |
| 能不能当真用 | 不能，见[和电影倒忌时是什么关系.md](和电影倒忌时是什么关系.md) | 能 |

**先想清楚你要哪一类**：想数「还有几天放假」，装错了会很失望；想看电影里那个道具，装到纪念日工具同样失望。

## 二、认包名，别认名字

应用名可以随便改、可以撞名，**包名是唯一的**（安卓系统就是靠它区分应用的）。核对自己装的是哪个，两步就够：

1. 手机上打开「设置 → 应用 → （找到那个图标）」，应用信息页里找「应用包名 / 存储」一类的条目，看是不是 `com.rbcd.countdownapp`；
2. 不确定装的包本身对不对，对照体积与 MD5：本地这一份是**版本 19 / 43.26M / MD5 `2DF6A74139E9B5BA109B12D1FFD4DC28`**，安装包的核对方法在[下载与安装教程.md](下载与安装教程.md) 第二节。

电脑上想批量看，装了 adb 的话：

```bash
adb shell pm list packages | grep countdown
```

输出里只有 `package:com.rbcd.countdownapp` 才是它。

## 三、同一包名也有不同体积，别按大小判断好坏

公开的版本归档记录显示，同一个 `com.rbcd.countdownapp` 的体积差得很大：

| 版本 | 体积 | 标注的系统要求 |
| --- | --- | --- |
| 19（**本地这一份**） | 约 43 MB | 安卓 8.0+ |
| 27（较新版本） | 约 163 MB | 安卓 7.0+，需带 Google 服务 |

体积涨是因为后续版本往里加了素材与新玩法，**不是多出来的东西不干净**。反过来也一样：见到两三百 KB 的「同名包」，那多半是另一个应用或者残包，别下。具体装哪个体积的，以你实际拿到的那份为准，见[下载与安装教程.md](下载与安装教程.md) 第二节的清单。

## 四、下载站的描述常常张冠李戴

这是实际会踩的坑：**不少下载站把好几个同名、近名的倒计时应用写在同一页**，功能列表东拼西凑。检索时能看到这样的错配 —— 页面顶着 `com.rbcd.countdownapp` 的包名，功能却写「日期计算器、世界时钟、语音备忘录、锁屏密码」，**这些本篇这个应用一个都没有**，它们属于另一款纪念日倒计时工具。

判断口径：**描述与你打开后看到的界面对不上，就以界面为准**。本篇这个打开后是五组数字 + 声光特效，没有事件列表、没有世界时钟、没有语音备忘录 —— 见到那些功能介绍，那一页讲的不是它。

顺带：不同渠道给的系统要求也常互相矛盾（5.2 / 7.0 / 8.0 各说各的），**以你手机实际能否装上为准**，别按某个页面的数字去改系统，口径说明见[下载与安装教程.md](下载与安装教程.md) 第四节。
