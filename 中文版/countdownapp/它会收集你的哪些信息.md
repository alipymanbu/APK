## 一、先说结论

它是**免费带广告**的应用，所以要靠广告和统计养活，收集范围落在「设备与使用情况 + 广告标识」这一档，属于这类应用的常规做法。**没有看到要求填手机号、身份证、支付信息这类内容** —— 你在里面只输过一个姓名。介意的话，第二节列了能直接关掉的开关。

## 二、开发者自己写的政策里有哪些项

开发者的隐私政策挂在个人站点上（[https://boyling.co/privacy/](https://boyling.co/privacy/)，页面标注最后更新 2026-02-16），列的收集项是：

| 类别 | 具体内容（政策原文所列） |
| --- | --- |
| 设备与使用数据 | 应用活动、崩溃日志、设备类型、系统版本、语言、大致位置 |
| 分析数据 | 交互、会话事件、性能数据 |
| 广告数据 | 广告展示、广告效果事件，以及在允许情况下的标识符 |
| 用户主动提交的内容 | 反馈、举报、客服请求这类你在功能里主动发的内容 |

用途也写在同一份政策里：改进功能、安全与防滥用、性能诊断与分析、投放并衡量广告效果、回复客服与履行法务义务。

两点要留意：

- **这份政策覆盖的是该开发者站点与其名下应用**，不是单独为这个应用写的，具体到本应用以商店页面与应用内当时显示的为准；
- **第三方 SDK 是分开算的** —— 政策写明可能用到分析、崩溃上报、广告、订阅、后端托管等第三方服务，它们各自按自己的政策处理数据。

## 三、商店页隐私标签说了什么

iOS 商店页的「App 隐私」区块由开发者自报，这个应用标注的口径是：**「用于追踪你的数据」里包含标识符**，也就是会用广告标识符做跨公司追踪；此外有用于第三方广告与分析的标识符。苹果的标签是自报的、未经验真，可以当作下限看，不当作全部。

## 四、你能关掉的四个开关

按顺序做，每关一项都会少一路数据外发：

1. **iOS 关追踪授权**：设置 → 隐私与安全性 → 跟踪 → 关掉「允许 App 请求跟踪」；或直接对这个应用单独关。政策也写明，跟踪与通知权限可以在系统设置里随时改。
2. **安卓关广告个性化**：设置 → Google → 广告 → 打开「删除广告 ID」或关闭「广告个性化」（不同系统版本入口略有差别）。
3. **权限按需给**：不玩自拍就不给相机，见[下载与安装教程.md](下载与安装教程.md) 第四节的权限清单；把用不到的权限逐个撤掉。
4. **不主动提交内容**：反馈、举报这类入口你不点，就没有「用户主动提交的内容」这一路。

## 五、跟「它是不是病毒」不是一回事

数据收集是**写了政策的常规行为**，可以核对、可以关；「是不是病毒」是另一个问题，判断方法在[常见问题与排查.md](常见问题与排查.md) 第二节 —— 看权限有没有超出闪灯、震动、相机、存储这个范围。两者别混着谈：**政策里有的不等于可疑，政策里没有的才值得追问**。

怕下错应用、拿不准自己装的是哪个，见[和其他倒计时应用怎么区分.md](和其他倒计时应用怎么区分.md)。
