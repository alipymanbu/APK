## 一、App 里能用哪些支付方式

下单页的支付方式会随地区、币种变化，常见的有这几类：

| 支付方式 | 说明 |
| --- | --- |
| 信用卡 / 借记卡 | 最常用，支持 Visa、万事达、JCB、银联、美国运通、Discover、大莱等卡组织 |
| PayPal | 跳转 PayPal 登录后确认付款，不用反复输卡号 |
| Google Pay | 安卓端可用，调用 Google 账号里已绑定的卡 |
| Apple Pay | 仅 iOS 端 |
| Trip Coins | 平台积分，可按比例抵扣订单金额（见下节） |
| 礼品卡 | 输卡号和 PIN 抵扣，余额不足可叠加其他支付方式补齐 |
| 到店支付 / 先住后付 | 部分酒店订单支持，以支付页实际显示为准 |

一个订单能不能用某种方式、能不能组合支付，以你付款那一步页面上实际列出的选项为准。

## 二、Trip Coins：怎么攒、怎么用

Trip Coins 是 Trip.com 的积分体系，用法要点：

- **获取**：完成酒店/机票订单、写酒店或景点点评、在 Trip Moments 发帖互动等；会员等级越高攒币越快，各等级的加成比例见 [会员等级与权益一览.md](会员等级与权益一览.md)。
- **抵扣**：支付页选择使用 Trip Coins，按比例抵扣订单金额；官方参考比价约为 100 Trip Coins 抵 1 美元，实际随汇率与活动浮动。
- **到账**：订单相关的积分一般要在行程完成、点评通过审核后到账，不是下单即到。
- 没有最低使用门槛的说法以官方页面为准，抵扣入口就在订单支付页。

## 三、付款失败先查这几处

1. **卡没开通境外/线上支付**：国内银行发行的卡默认可能关闭境外无卡支付，在发卡行 App 里打开，或换一张卡。
2. **发卡行风控拦截**：大额、跨境交易容易被拦，先给银行打个电话确认放行。
3. **币种或卡组织不支持**：换一个币种（设置里的 Currency）或换支付方式再试。
4. **高峰期拒付率升高**：节假日大促期间，有用户反馈境外卡更容易被拒，这种时候多试一张卡或换 PayPal。

反复失败时，订单可能处于「待支付」状态被保留一小段时间，过一会儿重下即可，不用重复扣款。

## 四、退款走到哪一步了

机票退票、酒店取消后，退款不是一步到账，官方把流程拆成四个阶段，你可以在订单详情里逐段对号：

| 阶段 | 含义 |
| --- | --- |
| 1. 已提交退票申请 | 你这边操作完成，等平台接收 |
| 2. 退票处理 | 平台按订单的退改政策核实是否可退、退多少 |
| 3. 操作退款 | 平台发起退单，机票还需航司审核放款 |
| 4. 银行退款 | 款项退回你的支付卡，到账时间由发卡行决定 |

几点实际经验：

- **到账时间**主要卡在第 4 步，各银行差别很大，国际卡通常比国内卡慢，几天到数周都有可能。
- **可能分批到账**：机票款与附加服务（选座、行李、保险）的退款可能分开退回。
- **退款形式**：个别航司的退款会以代金券形式返回，是否如此以订单页的退款说明为准。
- 退款金额与方式最终以航司/供应商的审核结果为准，和下单时的促销、优惠使用情况也有关。

## 五、付款凭证去哪找

订单详情页里有电子凭证/收据入口，可以查看或保存付款凭证；需要报销的用户在这里截图或导出即可（入口位置以当前版本 App 显示为准）。

付款方式的选择也受下单币种影响，改币种的入口见 [注册登录与初始设置.md](注册登录与初始设置.md)。订单改期、取消的具体操作步骤在 [酒店机票预订流程.md](酒店机票预订流程.md)；收不到确认邮件之类的问题看 [常见问题解答.md](常见问题解答.md)。
