## 一、先说结论

先免费用，别急着开。应用本体免费，聊天倾诉、回忆卡片、微光行动这些主线玩法都能直接用；会员值得考虑的时机是你用了一两周、确认自己会长期来，再按周期挑档位。

## 二、App Store 公开的内购价目

下面是 App Store 页面列出的内购项目（iOS 商店标价，以商店与应用内当时显示为准）：

| 档位 | 价格 |
| --- | --- |
| 特惠月卡 | ¥19.90 |
| 优惠季卡 | ¥98.00 |
| 普通季卡 | ¥128.00 |
| 优惠年卡 | ¥360.00 |
| 普通年卡 | ¥498.00 |

几点说明：

- 同一个周期有「优惠 / 普通」两档、标价不同，购买前看清页面上的具体名称；
- 这份价目出自 iOS 商店页；安卓端是否有同样档位、价格是否一致，以应用内购买页为准；
- 价格属于会调整的信息，付款前以你手机上实际显示的为准。

## 三、怎么判断自己要不要开

- 先把主线完整跑一遍（见[新手上手指南.md](新手上手指南.md)），确认聊天回应、记录、计划这些你都用得上，再谈付费；
- 按上面的价目折算，周期越长单价越低，但前提是你确定几个月后还会打开它；
- 情绪陪伴类应用的使用频率容易起伏，从月卡、季卡这类短周期试水，比一上来买年卡稳。
