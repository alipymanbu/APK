## 一、Lorebook 是什么

Lorebook 是角色创建侧的一个附加设定库：你把设定条目存进去，对话里**出现对应关键词时**，AI 才把这条设定取出来参考。可以把它理解成一个保险柜 —— 暂时用不到的设定锁进去，需要时凭关键词取。

## 二、为什么需要它

把所有设定全堆在角色描述里，token 会膨胀。社区用户的共同反馈是：在基础模型下 token 超限后，角色会**忘掉之前的剧情走向、无视秘密设定**。解法就是把不是每轮都用到的低频设定挪进 Lorebook，给对话本体腾空间。

## 三、创建与挂载

1. **创建**：创作 → Lorebook → 创建，逐条写关键词与内容；
2. **挂载**：编辑角色 → 打开**专家模式**开关 → 基本信息里的 Lorebook 设定 → 选中刚建好的那本。

Lorebook 是专家模式里的功能，不开专家模式看不到挂载入口。

## 四、关键词怎么写

- 触发方式是**精确字符串匹配**：对话文字里必须逐字出现关键词，条目才会生效。角色名、专有名词建议原样作为关键词；
- 关键词字段有长度上限（官方指南口径为 50 字符）；
- 用竖线 `|` 把多语言写法与别名连成一串，是社区通行的防漏触发做法，例如：`魔女|Witch|마녀|ウィッチ` —— 无论对话用哪种语言提到「魔女」都能命中。

## 五、什么该放进去

| 设定类型 | 放哪 |
| --- | --- |
| 每轮对话都用到的人设、语气 | 角色描述 / 文风提示词 |
| 低频信息：配角、地点、历史背景、物品 | Lorebook |
| 剧情里埋的悬念 | 秘密设定 |
| 你的身份与剧情进度备忘 | 用户笔记（见 [对话记忆与用户笔记设置.md](对话记忆与用户笔记设置.md)） |

判断标准一句话：这条设定**现在这轮对话用不到**，就进 Lorebook。

## 六、验证有没有生效

挂好后开一段对话，在消息里直接提到关键词（角色名、地名等），看角色是否按对应设定回应。没生效的，先检查对话文字与关键词是否逐字一致 —— 精确匹配对错字、繁简差异都敏感。
