## 一、先分清三个入口，别装混

DMM GAMES 平台由三部分组成（官方访谈里就是这么划分的），各自管一摊：

| 入口 | 跑在哪 | 干什么 |
| --- | --- | --- |
| 浏览器版 [games.dmm.com](https://games.dmm.com/) | 任意浏览器 | 网页直接玩浏览器游戏，不用装东西 |
| DMM GAMES PLAYER | **仅电脑**（Windows / Mac） | 购买、下载、启动 PC 游戏；也能启动下载型网游与浏览器游戏 |
| DMM GAMES STORE | 仅安卓 | 手机上浏览、下载、更新应用游戏——就是本套文档讲的这个 |

还有一个同名陷阱：官方帮助写明，商店里有些游戏详情页会让你装「DMM ゲームプレイヤー」，那是**手机上的另一个应用**，跟电脑上的 DMM GAMES PLAYER 不是一回事，从该游戏的详情页里下载即可。

## 二、电脑版（DMM GAMES PLAYER）怎么装

官方下载页：[player.games.dmm.com](https://player.games.dmm.com/)。要求与步骤（截至 2026-09，以该页当时显示为准）：

- **Windows**：Windows 10（64bit）或 Windows 11。下载 exe → 双击 → 用户账户控制弹窗点「是」→ 安装自动进行 → 出现登录画面即装完。
- **macOS**：macOS 14 Sonoma 以上。把 dmg 里的程序拖进「应用程序」文件夹 → **按住 Control 键点程序图标选「打开」**。官方特别提示：直接双击会弹对话框且起不来，必须走 Control + 「打开」这一步。

手机与平板打不开这个客户端——官方页面明确标注它仅限电脑访问。

## 三、账号是同一套

电脑版和手机商店用的是**同一个 DMM 账号**，两边各自登录互不影响。如果你当初是用 LINE / Google 之类的外部账号注册的，在客户端里登录失败时，改用「注册邮箱 + 密码」登录即可（官方帮助给的兜底办法）；具体注册与找回见 [注册账号教程.md](注册账号教程.md)。

## 四、手机商店里买的游戏能去电脑玩吗

不能直接搬。商店是安卓专用的发行渠道，电脑上没有对应的安装路径；反过来，电脑客户端里的 PC 游戏也不出现在手机商店里。想在电脑上玩 DMM 的游戏，走上面第二节那条线，以那款游戏在 PC 侧页面的标示为准。手机端的安装问题照 [下载与安装教程.md](下载与安装教程.md) 处理，两边起不来的问题都汇总在 [常见问题与解决办法.md](常见问题与解决办法.md)。
