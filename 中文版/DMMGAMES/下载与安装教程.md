## 一、这是个什么应用

DMMGAMES 是日本 DMM 旗下游戏平台 DMM GAMES 的安卓端商店应用（官方名称写作 DMM GAMES STORE，包名 `com.dmm.app.store`），你在手机上浏览、下载、更新 DMM 平台的游戏都靠它。它没有 iOS 版本，是安卓专用应用。本篇只讲「怎么把它装到手机上」；装好之后怎么注册、怎么调中文，见另外三篇。

## 二、先确认设备条件

| 项目 | 数值 |

| 系统要求 | 安卓 5.2 以上（网盘这份包标注；官方帮助页写「日本国内发售的 Android 5.0 以上机型」，以官方页面当时显示为准） |
| 安装包大小 | 70.72M |

| 包名 | `com.dmm.app.store` |
| MD5 | `DC4D63E05E44D6446D01E346EF905624` |

上面这几项就是网盘里那份安装包的实际信息，网上应用市场标的「最新版」常常和它对不上。下载完想核对文件有没有损坏，用任意 MD5 校验工具算一遍，结果应与表中一致。另外给游戏本体预留几个 GB 的空间——商店本体只有 70 多 MB，游戏是装完之后再单独下的。

## 三、拿到安装包

打开 [DMMGAMES 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1f654bb339a1)，把里面的 APK 转存到自己的网盘后下载到手机；在电脑上下载再传过去也行。文件名是 `DMMGAMES_v4.5.0.apk`，认准版本号，别拿到旧包。

## 四、安装步骤（Android 8.0 及以上）

1. 用手机浏览器或文件管理器点这个 APK；
2. 系统会提示「不允许安装来自此来源的应用」——这是安卓对非应用商店安装的统一拦截，点「设置」进入该来源的授权开关；
3. 打开「允许来自此来源的应用」，返回；
4. 点「安装」，等进度走完点「完成」。

安装到一半系统还会再向 DMMGAMES 本身索取一次「安装未知应用」权限（它之后替你装游戏要用），同样点「设置」→ 打开开关 → 返回继续。这一步授权一次，以后更新、装游戏都不会再问。

如果你的系统还是 Android 8.0 以下的老版本，路径是「设置」→「应用」或「安全」→ 勾选「允许安装未知来源应用」，其余步骤相同。

## 五、第一次打开

装完从桌面点开，首屏会让你登录或注册。没账号的先按 [注册账号教程.md](注册账号教程.md) 注册一个（免费，邮箱即可）；想先把它变成中文界面再折腾账号，也可以照 [设置中文界面.md](设置中文界面.md) 操作。

装不上、安装按钮按不动、打开闪退这类问题，统一在 [常见问题与解决办法.md](常见问题与解决办法.md) 里排查。
