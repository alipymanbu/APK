## 一、先说结论

手机端的 DMMGAMES 支持中文，但**只到繁体中文为止，没有简体中文**；而且不是全站中文——不同分区的翻译进度不一样，免费游戏那边中文覆盖得比较全，付费游戏那边不少页面仍是日文。所以下面的设置做完，你会看到一个中日混合的界面，这是正常状态，不是你设错了。

## 二、在哪儿设置

1. 打开 DMMGAMES，进入侧边栏菜单（左上角三条横杠）；
2. 找「设置」一项进入；
3. 在设置列表里找「语言 / 表示言語」之类的选项；
4. 选中文（繁体）对应的那一项，返回或重启应用生效。

不同版本的菜单叫法和层级会有出入（4.5.0 的更新日志里就写明「APP 画面 UI 变更」），照「菜单 → 设置 → 语言」这个思路找即可。如果设置里压根没有语言选项，先确认你装的是不是当前版本，可回到 [下载与安装教程.md](下载与安装教程.md) 核对版本号。

## 三、中文覆盖不到的地方怎么办

- **付费游戏区**：多数页面仍是日文。认页面上的汉字词和应用名即可，购买相关按钮的日文写法很固定（「購入」「支払」「カート」这几个词反复出现）；
- **游戏详情页**：以各家发行商提供的文案为准，DMM 不统一翻译，日文原版介绍很常见；
- **通知与活动推送**：新作预告、活动公告基本是日文，第一时间的消息通常也只有日文版。

想先把界面日文的生疏感降下来，可以先把系统语言调成日文再调回来，或者直接按 [注册账号教程.md](注册账号教程.md) 把账号注册完，再慢慢熟悉界面。

## 四、网页版的中文是另一套

如果你同时用电脑上的 DMM GAMES 网页版（[games.dmm.com](https://games.dmm.com/)），它的语言选项和手机端不通用：网页版把鼠标悬停在昵称上会出现语言入口，可选繁体中文。两边设置各管各的，手机端改了不影响网页版。
