## 一、先确认文件格式

你收到的文件结尾必须是 `dwg`、`dxf`、`PDF` 三种之一，这才是 CAD快速看图 认的图纸格式。几个常见变形：

| 收到的样子 | 怎么处理 |
| --- | --- |
| `xxx.dwg` / `xxx.dxf` / `xxx.pdf` | 直接打开，见下一节 |
| `xxx.zip` / `xxx.rar` / `xxx.7z` | 压缩包里含图纸，见第三节 |
| `xxx.bak` | 这是 CAD 的自动备份，把结尾改成 `dwg` 再打开 |
| `xxx.jpg` / `xxx.png` / `xxx.doc` | 不是图纸，图片用相册看、文档用 WPS 看 |
| 结尾看不出来 | 微信里常把真实后缀藏掉，先把文件保存到手机，用文件管理器看真实扩展名 |

## 二、从微信、QQ 直接打开

1. 在聊天窗口点开图纸文件。若是预览页，先保存到手机或点右上角「用其他应用打开」。
2. 选「其他方式打开 / 打开方式 / 用以下应用打开」——不同手机叫法不一样。
3. 在应用列表里点 **CAD快速看图**。第一次会弹确认，勾上「始终」以后这类文件就自动用它开。
4. 图纸打开后会出现在应用内的图纸列表里，下次不用再走微信，直接打开应用搜索文件名就能找到。

如果列表里压根没有 CAD快速看图：先确认应用已装好（见 [下载与安装教程.md](下载与安装教程.md)）；个别手机的文件管理器调不起第三方应用，换个文件管理器、或改走第四节的「在应用内搜索」兜底。

## 三、对方发的是压缩包

文件是 `zip`、`rar`、`7z` 而里面的图纸被打包时，不用先手动解压：点这个压缩包 → 选「其他方式打开」→ 点 CAD快速看图，包内的 `dwg`/`dxf`/`PDF` 会自动解压，随后从图纸列表点名称即可打开。手机系统自带解压工具先手动解一遍，再从文件管理器点图纸，效果一样。

## 四、兜底办法：进应用里搜

不管从哪个入口打开失败，都可以直接启动 CAD快速看图，点右下角的搜索按钮，输入图纸文件名（或其中几个字）——只要这张图之前被收录过，搜到就能直接点开。日常找图也推荐用这个方式，比翻文件夹快。

图纸打开后怎么测量、怎么关图层，见 [图层开关与看图技巧.md](图层开关与看图技巧.md)；点了却开不了，按 [图纸打不开怎么排查.md](图纸打不开怎么排查.md) 查。
