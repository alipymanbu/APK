## 一、免费能干什么

装好就能看图：打开各版本 DWG、天正图纸与 PDF，缩放平移、搜索与整理本地图纸，这些日常看图动作不付费也能走通。图层、测量、标注这类工具是否要求会员，取决于具体功能——你点到付费项时应用内会弹会员提示，照提示走即可，不会悄悄扣费；哪些属于付费项见第三节。

## 二、官方购买页的价格

官网会员购买页（[cad.glodon.com/user/index](http://cad.glodon.com/user/index)）列出的档位：

| 档位 | 页面标价 |
| --- | --- |
| 1 个月 | 48 元（48 元/月） |
| 3 个月 | 138 元（46 元/月） |
| 1 年 | 228 元（19 元/月） |

价格与档位会调整，**以下单时官网/应用内显示为准**，上表只记录查询当时的样子。会员与账号绑定，购买后用同一账号登录即可使用（官方视频教程里有「购买会员后如何使用会员功能」一节）。

## 三、付费功能清单（据官方购买页整理）

| 类别 | 功能 |
| --- | --- |
| 导出与转换 | 批量导出 PDF、PDF 转 CAD、图纸版本转换、天正转 T3、图纸分割导出、布局转模型 |
| 测量进阶 | 测量填充面积、面积（含弧线）、连续测量、测量角度/半径/圆/弧长、侧面积、面积偏移、测量统计并导出表格 |
| 标注 | 云线标注、引线标注、多行文字、标注分类、标注复制移动跨图粘贴 |
| 编辑 | 编辑助手（删图元、改文字、炸开图块、镜像旋转、跨图复制并保存） |
| 识别与对比 | 提取文字、提取表格到 Excel、图形识别数个数、图纸对比、区域查找文字并导出 |
| 图纸管理 | 图层管理、外部参照管理（绑定+另存）、导入导出 kkf、快看云盘全平台同步 |
| 其他 | 网页版看图、离线 VIP、快捷键设置 |

清单横跨电脑端与手机端；同一功能在你手机上的入口与是否弹会员提示，**以应用内实际提示为准**——比如你在手机上量填充面积弹了提示，就属于上面这类付费项（对应 [手机测量面积与长度教程.md](手机测量面积与长度教程.md) 里的表格）。

## 四、要不要开的判断

只在手机上看图、翻图、找图，免费范围通常够用；要出统计表、批量导出、图纸对比、天正转 T3 这类生产动作，才会持续撞到会员边界。官方功能说明可对照官网 [cad.glodon.com](http://cad.glodon.com/)，买之前先把要常用的功能在应用里点一遍，弹不弹提示比看清单准。
