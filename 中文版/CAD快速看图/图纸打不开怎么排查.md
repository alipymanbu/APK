## 一、先过格式这关（最多人卡在这）

1. 文件结尾必须是 `dwg`、`dxf`、`PDF`。是 `jpg`/`png` 就是图片、`doc`/`xls` 就是文档，别硬塞给看图软件。
2. 结尾是 `bak`：这是 CAD 自动备份，改成 `dwg` 再开。
3. 结尾看不出真实格式：保存到手机后用文件管理器看真实扩展名；微信常把后缀藏掉。
4. 是压缩包（`zip`/`rar`/`7z`）：点包选 CAD快速看图 自动解压，或先手动解压再点里面的图纸，见 [微信QQ收到的图纸怎么打开.md](微信QQ收到的图纸怎么打开.md)。
5. 文件名里带标点符号：安卓上有的文件管理器会把标点后的内容当后缀，导致认不出——把图纸重命名成纯中文/字母名再试。

## 二、格式对了还是开不了

| 现象 | 排查方向 |
| --- | --- |
| 点开卡住、进度走一半就退 | 图纸太大、手机运行内存吃紧：先关掉后台应用再试；还不行让发图方把图分割成几张小图（电脑端的图纸分割属会员功能，见 [会员价格与会员功能清单.md](会员价格与会员功能清单.md)） |
| 打开后一片空白、构件缺一块 | 图纸引用了**外部参照**：参照文件没跟图纸放在同一目录就会显示不全——让发图方把图纸「绑定参照后另存」再发，或把参照文件和图纸一起发过来且放同一文件夹 |
| 提示文件无效 / 打开即报错 | 图纸本身损坏：让发图方重新导出一份，或要备份文件 |
| 布局里看到空白 | 先切到模型空间看看（见 [图层开关与看图技巧.md](图层开关与看图技巧.md)），布局常只放图框 |
| 部分文字变成问号或线条 | 天正构件与特殊字体，CAD快速看图 已兼容天正全专业格式与常见字体；仍异常时先升级到最新版 |

## 三、应用侧的几种情况

- **「打开方式」列表里没有它**：确认应用没被卸载；换个文件管理器再点一次；或直接启动 CAD快速看图 用右下角搜索找图（兜底最有效）。
- **以前能开、突然全开不开**：先到手机自带的应用商店把 CAD快速看图 更新到最新版本，不要卸载重装（卸载可能连本地图纸列表一起清掉）；更新后仍异常再到官方社区 [cadclub.glodon.com](https://cadclub.glodon.com/) 搜同款问题。
- **重装系统或换机后列表是空的**：列表只是「本机收录记录」，图纸文件还在原来的位置；把图纸重新从应用里浏览到、或从微信重发一次即可重新收录。

## 四、还不行就定位到源头

逐项做完仍打不开，基本可以断定是这张图本身的问题：用电脑上的 CAD 软件开一下，能开说明问题在手机侧（回看第二、三节），开不了就是图纸坏——找发图方重新出图。安装包或版本本身有疑问，核对 [下载与安装教程.md](下载与安装教程.md) 里的版本与包名信息。
