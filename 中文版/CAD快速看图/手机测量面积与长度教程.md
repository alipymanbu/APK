## 一、量之前先校比例（最常被跳过的一步）

图纸如果按 `1:100` 之类比例出图，你直接量到的只是图上距离。测量前先在测量菜单里找到**比例**功能，按图纸标注的比例校好，之后量出的才是实际尺寸——这一步没做，后面所有数据都差一个倍数。校完比例拿图上一个已知尺寸（比如标注写 3000 的墙）反量核对一遍；量出来对不上、或布局与大样图里的数不对，完整排查见 [测量结果不准怎么校准比例.md](测量结果不准怎么校准比例.md)。

## 二、测长度

- **单段长度**：打开测量菜单，选「测量长度」，点线段的起点和终点，结果直接弹出。
- **连续测量**：量多段折线（含弧线）总长用「连续测量」——依次点各段端点，累加总长随点随出，适合量管线、道路、周长这类一拐一拐的线。
- **平行线间距**：选对应工具后分别点两条平行线，得它们的间距，量墙体厚度、管线间距用它。
- **弧长与半径**：点圆弧可取弧长、半径；不规则弧用三点（起点、终点、弧上一点）取值。
- **坐标**：点图上任意一点读出该点坐标，定位放线时用。

手机上点选容易飘，把图纸放大到能看清端点再点，误差能小很多；拿不准读数时量一段已知长度反核一下（步骤见 [测量结果不准怎么校准比例.md](测量结果不准怎么校准比例.md)）。

## 三、测面积

| 场景 | 怎么做 |
| --- | --- |
| 规则矩形 | 点对角两个点（或沿边点选），自动出面积和周长 |
| 带弧线的异形 | 用「面积（含弧线）」，沿着轮廓依次点线段，点完自动闭合 |
| 填充图案 | 用「测量填充面积」，一键识别填充区域出面积和周长 |
| 想要外扩/内缩 | 量完平面面积后用「面积偏移」，按偏移距离放大或缩小一圈 |
| 侧墙、展开面 | 平面面积量完后用「计算侧面积」，把墙面这类立面展开算 |

面积结果的显示单位可以在标注设置里切换（比如显示成 `㎡`）。

## 四、标注与结果管理

量完的数据可以**标注**的形式留在图上：方框、椭圆、任意线、文字等标注工具都在标注测量菜单里，下次打开这张图标注还在——现场核对、和同事对图时比口头报数可靠。单条标注的颜色、文字大小、位置都可再改。

标错了要删，官方社区给的两条路：

- **删单条**：点一下那条标注，右上角出现红色叉号（有的版本是小叉按钮），点它即删；
- **全清**：图纸页右上角三横线菜单里有「清空标注」，一键去掉这张图上的全部标注。

**删除不可恢复**——批量清空前先确认没有要留的。

连续多次测量后，可到结果列表里统一查看；需要出表格统计的（按颜色汇总、导出 Excel）属于会员功能，边界见 [会员价格与会员功能清单.md](会员价格与会员功能清单.md)。

## 五、拍照与录音留痕

现场对着图纸拍照时，可以给照片加时间、地点、内容的水印，或在图上某个位置挂一段录音、一张现场照片，把「当时看到的」和「图纸上的位置」对上，验收、签证这类要留痕的场合用得上。相关操作入口在标注测量菜单里，不同版本界面略有差异，以你手机上的为准。

量完想把图和标注带到电脑上继续用，走云盘同步或 kkf 互传，步骤见 [图层开关与看图技巧.md](图层开关与看图技巧.md)。
