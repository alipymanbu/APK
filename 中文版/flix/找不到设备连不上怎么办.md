## 一、先确认是不是「同一网络」这个问题

flix 的设备发现全靠局域网，「连不上」大多出在这里。逐项过：

| 检查项 | 怎么判断 |
| --- | --- |
| 是不是同一个 WiFi | 手机和电脑连的 SSID 要一样；手机连了「访客网络」或蜂窝数据，和电脑不在一个网段 |
| 是不是被隔离了 | 路由器开了「AP 隔离 / 客户端隔离」时，同 WiFi 下的设备互相不通，需要在路由器后台关掉 |
| 热点场景 | 一台设备开热点、另一台连上去，也算同一网络；连不上就试下一条「新设备发现方式」 |
| 网络类型 | Windows 把当前网络标成「公用网络」时更严格，先在系统设置里改成「专用网络」 |

这些都对，再往下走软件层面的排查。

## 二、Windows 收不到文件：把 flix 加进防火墙白名单

这是官方 FAQ 里给的标准步骤，Windows 端收不到东西时先做它：

1. 在开始菜单搜索「允许应用通过 Windows 防火墙」并打开；
2. 点「更改设置」；
3. 点「允许其他应用」；
4. 添加 flix 的可执行文件路径，常见位置是 `C:\Users\<你的用户名>\AppData\Roaming\Flix\Flix\flix.exe` 或 `C:\Program Files\Flix\flix.exe`（以你机器上实际安装位置为准）；
5. 点「添加」回到列表；
6. 找到列表里的 flix 项，把「专用」和「公用」两个勾都打上；
7. 保存。

装了第三方安全软件的，同样要在它的防火墙/网络拦截里给 flix 放行 —— 系统自带的过了，第三方拦着照样收不到。

## 三、开关「启用新的设备发现方式」

有用户反馈开热点时怎么都发现不了对方设备，这时候去设置里把「启用新的设备发现方式」打开再试；开完如果出现连接不稳、兼容性问题，同一个开关关回去即可（官方更新日志里说明过这个开关的用途与可回退性）。手动添加过但刷新后消失的设备，也建议改用扫一扫或输 IP 端口的方式重连。

## 四、能连上但传输中途断了

按可能性从高到低：

1. **有一台设备休眠/切了后台** —— 手机端把 flix 放行后台运行与电池不限制，锁屏后才不会被系统杀掉连接；
2. **热点自动切换** —— 手机在 WiFi 和数据之间自动跳，会把局域网连接带走，固定到一个网络再传；
3. **大文件中断** —— 支持断点续传，重新发一次会接着传，不必从头来；
4. **两边版本差太多** —— 老版本与新版的连接协议偶有不兼容，把两端都升到官网当前版本再试（[下载与安装教程.md](下载与安装教程.md) 有各平台入口）。

## 五、还是不行：拿日志去反馈

软件里点「帮助」→ 进入「关于我们」→ **双击版本号**，可以导出/分享日志。带上日志、两台设备的系统版本和网络环境（家用路由 / 热点 / 公司网）去官方渠道反馈，比空口描述「连不上」有用得多。

投屏、远程控制连不上时，同样先回到本篇把连接打通 —— 它们依赖的是同一条局域网链路，见 [投屏与远程控制怎么用.md](投屏与远程控制怎么用.md)。
