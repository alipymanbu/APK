## 一、能装在哪、不能装在哪

| 平台 | 情况 |
| --- | --- |
| 安卓手机/平板 | 主平台，见 [下载与安装教程.md](下载与安装教程.md) |
| Windows 11 | 可以，通过 Amazon Appstore 安装（官方博客 2023 年已宣布上架） |
| iPhone / iPad | 没有 iOS 版，官方明确表示没有开发计划 |
| 其它电脑系统 | 可以用安卓模拟器跑安卓版（见第三节） |

## 二、Windows 11 安装步骤（Amazon Appstore 路线）

1. 在 Microsoft Store 里安装 **Amazon Appstore**。如果商店里找不到它，微软官方有一篇「Windows 上移动应用的疑难解答与常见问题」支持文档可照着排查（以微软页面当时显示为准）。
   - 官方开发者自述：他本人是**把 Windows 系统区域改成美国（US）**之后，Amazon Appstore 就能装了 —— 遇到商店不给装时，先试这一招。
2. 打开 Amazon Appstore，搜索 **Reasily**，安装。
3. 装好后，Windows 11 版与安卓版用**同一个 Google 账号**登录，即可在两端同步高亮与笔记（官方 2023 年博客明确说明 Android 与 Windows 11 之间可同步 highlights 和 notes）。

存书方式与安卓版一致：底部 `+` 添加 EPUB 文件，操作说明见 [下载与安装教程.md](下载与安装教程.md)。

## 三、用安卓模拟器跑

不想折腾 Amazon Appstore 的话，官方 FAQ 给出的模拟器路线是：**Remix**、**BlueStacks**、**Android Studio AVD**（安卓虚拟设备）。任选一个装好后，把安卓版 APK 装进模拟器即可，用法与手机上完全一样。

## 四、跨端同步的两个前提

- 两端登录**同一个 Google 账号**（多账号场景的坑见 [常见问题与解决办法.md](常见问题与解决办法.md)）；
- 两端打开的是**同一个版本的 EPUB** —— 版本不同，注释数据不会互通。

同步的具体操作与排查见 [数据同步与备份方法.md](数据同步与备份方法.md)。
