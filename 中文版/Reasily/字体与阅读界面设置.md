## 一、显示选项都在哪

打开书后进设置菜单，与阅读页相关的选项有：

| 选项 | 作用 |
| --- | --- |
| 主题 | 羊皮纸（sepia）/ 夜间（night）等配色 |
| 自定义字体 | 换正文字体（可加自己下载的字体，见第三节） |
| 边距、行距 | 调页面留白与行与行的疏密 |
| 文字对齐 | 左对齐 / 两端对齐 |
| 弹出脚注位置 | 点脚注时弹窗出现在哪 |
| Original 开关 | 关掉它 = 禁用 EPUB 自带的 CSS，用应用默认排版 |

字号不用进菜单：阅读页上**双指捏合**即可缩放文字。

## 二、图片与翻页

- 点正文里的图片会放大显示，并展示图片的说明文字；放大后同样能双指缩放。
- 左右滑动翻到上一/下一章或上/下一页。
- Android 7 及以上可以用系统的**悬浮窗 / 分屏**边读边干别的；三星设备同样支持。

## 三、用自己的字体文件（TTF / OTF）

Reasily 支持 TTF 与 OTF 格式的字体，管理入口在 **Typeface → Folder**：

1. 选中放字体的文件夹，里面所有字体（含子目录）都会出现在 Typeface 菜单里；
2. 字体按**字族**列，不按文件名 —— 同族多个字重会归到一起；
3. 字体文件改动后，点菜单里的刷新按钮重新扫描列表；
4. 想强制把一批字体归成一个字族：放进子目录，把**目录名末尾加一个 `@`** —— Google Noto 系列字体这样整理最有效。

小技巧：如果正文里的英文撇号显示成很宽的全角符号，通常是当前字体把 `’` 按全角渲染了，换一个 Serif / Sans-serif 或自己下载的字体即可，详见 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 四、自定义 CSS（Pro）

设置的高级选项里有「CSS 自定义」，可以把一段 CSS 注入页面，常见的两种用法：

- 英文书自动断词连字符：

```css
body { hyphens: auto !important; }
```

- 把横排书强制改竖排（排版本身复杂的书可能乱，乱了就把上面说的 Original 选项关掉再试）：

```css
body { writing-mode: vertical-rl; }
```

自定义 CSS 属于 Pro 功能，点到时会弹购买对话框。

## 五、两个场景开关

- **电子墨水屏设备**：高级设置里有「Animation off」（关闭动画）选项，打开后应用会尽量禁用动画，翻页更跟手。
- **夜间模式不生效**：这不是设置问题，多半是系统 WebView / Chrome 版本太旧，处理办法见 [常见问题与解决办法.md](常见问题与解决办法.md)。

另外，长按返回键或点菜单最后一项「Close」可以关闭当前这本书 —— 关掉的书不占内存，也从最近任务列表里消失。
