# 新手使用教程

> 装好 Simple Live 后的前十分钟怎么用：认界面、切平台、搜直播间、加关注、翻观看记录。

## 一、第一次打开

启动后直接进首页，**不用注册、不用登录**。首页按平台组织内容：虎牙、斗鱼、哔哩哔哩、抖音四个入口，每个平台下面展示人气直播间列表，封面上带实时观看人数。上下滑动浏览列表，左右滑动（或点顶部平台名）在四个平台之间切换。

点任意直播间封面就直接开播，没有开屏广告和等待页。播放界面是横竖屏自适应的，竖屏时画面上方是直播流、下方是弹幕和聊天区。

## 二、找直播间：搜索比翻列表快

顶部搜索框支持三类输入，按你手头的信息选：

| 你知道的 | 怎么搜 |
| --- | --- |
| 主播名字 | 直接输名字，结果覆盖四个平台 |
| 直播间号 / 房间号 | 直接输数字 |
| 内容关键词 | 输「LOL」「户外」这类词，按直播主题匹配 |

搜索结果里会标明每条结果属于哪个平台。也可以不走搜索：每个平台下有网游竞技、颜值星秀、户外、娱乐天地等分区，点分区逐级往下翻。

还有一条捷径：如果你是在聊天软件里收到别人发来的直播间链接，不用照着搜 —— 应用自带的链接解析能直接跳进那个房间，用法见 [链接解析与直播间跳转.md](链接解析与直播间跳转.md)。

## 三、关注主播，开播不用再找

进直播间后点「关注」（或收藏按钮），这位主播就进了你的关注列表。之后在「我的」页面看关注列表，列表会区分**直播中**和**未开播**两种状态，开播的排前面，点了直接进房间。

关注列表是 Simple Live 里最值得先攒的数据 —— 它和观看记录都是后面 TV 端同步要搬的东西，见 [TV版与多端同步.md](TV版与多端同步.md)。

## 四、观看记录、定时关闭与夜间模式

- **观看记录**：看过的直播间自动留档，在「我的」里能找回最近看过的房间，不用重新搜。
- **定时关闭**：设置里可以选倒计时（如 30 分钟、1 小时），到点停止播放，适合睡前挂着听的情况。
- **夜间模式**：设置里切换深色界面，关灯看直播不刺眼。
- **截图与分享**：部分版本支持在直播间内截图、把当前房间分享出去，对方点开链接（或走链接解析）就能进同一个房间。你手头版本有没有这个按钮，以播放界面的工具条实际显示为准。

弹幕嫌吵、想调大小或屏蔽某类词，都在播放界面的弹幕设置面板里，具体逐项说明见 [弹幕与画质设置.md](弹幕与画质设置.md)。

## 五、哪些功能需要登录账号

| 平台 | 不登录能看吗 |
| --- | --- |
| 虎牙 | 能看 |
| 斗鱼 | 能看 |
| 抖音 | 能看 |
| 哔哩哔哩 | 多数内容需要登录 B 站账号后才能观看 |

也就是说：不用注册任何新账号，Simple Live 本身没有账号体系；只有看 B 站直播时需要在应用里登录一次你自己的哔哩哔哩账号。登录入口在「我的」或设置里按平台分项，各平台登录后能解锁的画质档位以直播间实际提供为准。
