## 一、弹幕开关与样式

进入直播间后，点一下画面调出控制层，弹幕设置面板就在里面。你能调的几样：

| 设置项 | 作用 |
| --- | --- |
| 弹幕总开关 | 一键关闭全部弹幕，画面只剩直播流 |
| 字体大小 | 调大调小，小屏手机建议别超过中档 |
| 透明度 | 调低后弹幕不挡画面主体 |
| 滚动速度 | 觉得弹幕刷太快就降速 |
| 显示区域 | 限制弹幕只占屏幕上半部分（最高约八成屏），底部留白看主播操作 |

设置是全局生效的，改一次四个平台的直播间都按这套来，不用每个房间重调。

**发送弹幕是另一回事**：显示弹幕不用登录，但发弹幕、点赞这类互动通常要求先登录对应平台账号，而且各平台开放程度不同 —— 直播间里有没有输入框、点了能不能发，以你登录后的实际情况为准。只看不想发的话，上面这些显示设置就够用了。

## 二、屏蔽词：把不想看的词挡掉

弹幕设置里有关键词屏蔽，把不想看到的词加进列表，命中该词的弹幕整条不显示。常见用法是屏蔽刷屏的口令词、吵架关键词。列表可以随时增删，加完即时生效，不用退出直播间。

另外，斗鱼直播间的机器人弹幕（系统自动刷的那种）在较新版本里已被过滤；如果你用的版本还看得到大量重复的机器人弹幕，多半是版本偏旧，见文末的版本说明。

## 三、画质切换

播放界面右上角（横屏时）有画质按钮，点开是当前直播间提供的档位列表，从流畅到原画。几个平台常见的高档位，供对照：

| 平台 | 常见高档位 |
| --- | --- |
| 虎牙 | 蓝光、2K |
| 斗鱼 | 1080P、60 帧档 |
| 抖音 | 蓝光 |
| 哔哩哔哩 | 原画（高档位通常需登录 B 站账号） |

几点实际经验：

- 档位由**直播间那一边**决定，Simple Live 只是把平台提供的档位列出来 —— 所以有的房间只有 720P，有的有蓝光原画，同一平台不同房间也不一样。
- 网络波动时先降一档再观察，比反复进出直播间管用。
- B 站直播间的高档位画质可能需要已登录 B 站账号，登录说明见 [新手使用教程.md](新手使用教程.md) 第五节。

## 四、小窗播放与横竖屏

- **小窗 / 悬浮窗**：安卓端支持把直播间缩成悬浮小窗，边聊微信边看。第一次开小窗时系统会要「显示在应用上层」权限，允许一次即可。个别深度定制系统（如部分品牌的省电策略）会把悬浮窗进程杀掉，表现为小窗闪一下就消失，可把 Simple Live 加入后台白名单。另有用户反馈某些版本没有悬浮窗入口、只有退到后台后继续播声音 —— 悬浮窗能力因版本而异，以你手头版本的播放界面实际显示为准。
- **横竖屏**：点画面调出控制层后手动切换，也可以跟随系统自动旋转。游戏直播建议横屏，弹幕区域和画质按钮位置都会重排。

## 五、调了没反应怎么办

先确认改的是**播放界面里**的弹幕面板，而不是「我的」页面里的全局设置 —— 两处入口有重叠项，播放界面里的优先级更高。弹幕整体不出现、画质列表是空的这类异常不属于设置问题，多半是那一时刻对应平台的接口波动，处理思路见 [看不了直播的常见问题.md](看不了直播的常见问题.md)。

另有一句要提前说的：直播类应用对平台接口的依赖重，旧版本最容易「突然某天某平台不行」，把版本保持在与官方发布页接近的水平能省掉大部分玄学问题。
