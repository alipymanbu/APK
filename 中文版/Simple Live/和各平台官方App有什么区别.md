# 和各平台官方App有什么区别

> 同样是看虎牙、斗鱼、B站、抖音的直播，Simple Live 和装四个官方客户端差在哪、各自适合谁。

## 一、一张表看清差异

| 对比项 | Simple Live（聚合） | 各平台官方 App |
| --- | --- | --- |
| 占用的应用数 | 一个应用看四个平台 | 一家一个，各装各的 |
| 广告与推送 | 界面里没有广告位，无推送打扰 | 有开屏广告、活动弹窗、推送等常规运营位 |
| 登录要求 | 多数内容不登录就能看；B 站内容需登录 | 各自账号体系，功能往往与登录绑定 |
| 画质档位 | 列出各平台直播间提供的档位，最高原画 | 同一直播流，档位本身一致 |
| 互动（发弹幕、送礼） | 以观看为主，发送类互动按平台与登录状态而定 | 完整互动，送礼、粉丝团、活动都在 |
| 获取与更新 | APK 自行安装，更新要自己跟进（见文末） | 应用商店一键更新 |
| 稳定性 | 依赖各平台接口，平台一调整可能某平台临时失效 | 平台自营，出问题平台自己修 |
| 开源 | 项目以 GPL-3.0 开源，源码公开 | 不开源 |

一句话概括：**官方 App 的优势在互动与稳定，聚合应用的优势在少装几个 App、界面干净**。两边并不互斥 —— 只看直播的人用聚合，追直播活动、要送礼互动的人还是得用官方。

## 二、几个你大概率会问的点

- **画质会缩水吗**：不会。直播间推的是同一路流，Simple Live 列出的就是平台提供的档位；区别只在你这边登录与否（B 站高档位可能要登录）。
- **官方会管聚合工具吗**：Simple Live 的项目声明写明其功能基于互联网公开资料实现、不涉及对平台接口的逆向行为，仅供学习交流。第三方聚合工具与平台之间没有官方合作关系，平台接口调整导致功能临时失效是常态，这一点心理预期要有。
- **它要收费吗**：应用本身开源免费、无内购；各平台直播间里的付费内容（如付费赛事）在哪个 App 看都一样要按平台规则付费。

## 三、更新的现实情况

这是和官方 App 差异最大的一条。官方 App 在商店里点一下就升级；Simple Live 的更新要自己跟进：

- 项目在 GitHub 开源（[github.com/xiaoyaocz/dart_simple_live](https://github.com/xiaoyaocz/dart_simple_live)），仓库 README 已声明**不再随版本提供现成的安装包**，想拿官方构建需要去看仓库的构建产物或自行编译。
- 各下载站流传的版本号五花八门，且互不同步；有用户反馈项目的更新节奏也已经放缓。**别迷信版本号，以手上这版四个平台是否都能正常看为准** —— 能正常看就不必折腾升级。
- 你网盘里这份是 1.7.6（2026-09-23 记录），升级相关的现实渠道与判断方法写在 [看不了直播的常见问题.md](看不了直播的常见问题.md) 第六节。

## 四、适合谁用、谁不该装

| 适合 | 不适合 |
| --- | --- |
| 同时看两个以上平台、不想装一排官方 App | 主要在某一个平台追主播、参加活动 |
| 想给家里电视配个简单直播应用（另有 TV 版） | 重度送礼、粉丝团、弹幕社交用户 |
| 手机存储紧张、嫌官方客户端臃肿 | 对单一平台的推荐流、榜单功能有依赖 |
