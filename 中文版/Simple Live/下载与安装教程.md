## 一、装之前先确认三件事

- Simple Live 是一个**开源的聚合直播应用**，把虎牙、斗鱼、哔哩哔哩、抖音四个平台的直播整合到一个界面里。项目在 GitHub 上以 GPL-3.0 协议开源（[github.com/xiaoyaocz/dart_simple_live](https://github.com/xiaoyaocz/dart_simple_live)），你可以在项目页查看源码与问题反馈。
- 它不是任何一家直播平台的官方客户端，应用商店里不一定搜得到，一般通过 APK 安装包安装。它和四个官方客户端的取舍对比，见 [和各平台官方App有什么区别.md](和各平台官方App有什么区别.md)。
- 手里这个包的规格：**版本 1.7.6、包名 `com.xycz.simple_live`、大小 17.39M**（2026-09-23 记录），MD5 为 `DDE7062867F73ECCBA94AC3AF1DE3BFD`。系统要求为安卓 5.2 及以上。

## 二、获取安装文件

打开 [Simple Live 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2070fa00662f)，转存到自己网盘后下载 `Simple Live_v1.7.6.apk` 到手机。在手机上用夸克 App 打开时，点文件一般会直接调起安装；如果是电脑上下载再传到手机，用手机自带的「文件管理」找到它点击即可。

官方项目本身持续在更新，网盘里是 1.7.6 这一版；想看官方最新版本号与更新说明，以 GitHub 项目页的发布信息为准。

## 三、安装步骤

1. 点击 APK 文件。系统若提示「禁止安装来自此来源的应用」，按提示跳到**设置 → 允许来自此来源 / 安装未知应用**，给当前用的浏览器或文件管理器打开开关。
2. 返回安装界面点「安装」，等进度走完。
3. 装完点「打开」。首次启动如果弹出权限申请（如存储、悬浮窗），按你自己的需要选择，不给也不影响基本观看。

## 四、装完核对：确认装的确实是 Simple Live

打开**设置 → 应用 → 应用管理**，找到刚装的应用点进「应用信息」：

| 核对项 | 应该是 |
| --- | --- |
| 应用名 | Simple Live |
| 包名 | `com.xycz.simple_live` |
| 版本 | 1.7.6 |
| 大小 | 约 17.4 MB |

包名不对说明装成了别的同类型应用；装不上、装完闪退、能装但看不了，按 [看不了直播的常见问题.md](看不了直播的常见问题.md) 逐条排查。装好后的第一次使用（切平台、搜主播、加关注）见 [新手使用教程.md](新手使用教程.md)；想在电视上看，另有独立的 TV 版，见 [TV版与多端同步.md](TV版与多端同步.md)。
