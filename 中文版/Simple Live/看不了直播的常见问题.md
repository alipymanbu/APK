## 一、直播间点开是黑的 / 播放中断

按这个顺序查，大多数情况在前两步就解决：

1. **换一个直播间试试**。只是一个房间不行 → 是那一场直播本身的问题（主播卡了或下播了），不是应用的问题；换房也黑屏 → 往下走。
2. **换平台试试**。四个平台只有某一个黑屏 → 该平台的接口或线路临时波动，过段时间重试；四个平台全黑 → 查手机网络，或把应用切到后台重开。
3. **降画质**。原画档在弱网下最容易出现缓冲黑屏，切到流畅档再看。
4. **升级版本**。历史上有过整类播放问题靠版本更新修复的记录：比如虎牙播放中断、B 站分类加载失败都曾在更新日志里出现并修复。你网盘里这版是 1.7.6，如果某平台的播放长期异常而其他平台正常，先到官方项目页确认最新版本号，更新后问题多数随之消失。

播放中断反复出现且集中在同一平台、别的观众同时段正常，基本可以判定是版本与该平台接口不匹配，等更新或立即更新，自己这边没有更多可操作的。

## 二、弹幕不出来 / 弹幕连接失败

- **只有弹幕没有画面**：按第一节先修画面，画面正常后弹幕一般自动恢复。
- **有画面没弹幕**：先看弹幕总开关是不是被你关了（见 [弹幕与画质设置.md](弹幕与画质设置.md)）；再确认不是屏蔽词误杀 —— 清空屏蔽词列表试一次。
- **弹幕连着连着就断了**：抖音直播间出现过弹幕连接失败一类的问题，在更新日志里有对应修复记录。遇到某一平台弹幕批量失联而画面正常，升级到新版本是最省事的路。
- **弹幕飘走不消失、重叠**：这类显示异常同样在后续版本修过，属于版本问题不是设置问题。
- **链接解析跳转进来的房间黑屏**：先回原处确认那条链接还能打开（直播间可能已下播），链接本身没问题再按第一节排查，解析环节的更多情况见 [链接解析与直播间跳转.md](链接解析与直播间跳转.md) 第三节。

## 三、B 站相关：要登录、加载失败

- **B 站直播间提示需要登录**：B 站多数内容要登录哔哩哔哩账号后才能观看，这是四个平台里唯一对登录有硬要求的（其余三家不登录也能看）。登录入口在「我的」或设置里，登录的是你自己的 B 站账号。
- **B 站分类 / 推荐加载失败、一直转圈**：这类失败在项目更新日志里多次出现并被修复（加载失败 → 修复 → 新版本又因平台调整再出 → 再修）。先杀进程重开一次；仍然失败且持续半天以上，去官方项目页看有没有对应修复版本。
- **登录后画质还是上不去**：高档位由直播间那侧决定，不是每个房间都提供原画。

## 四、安装与启动类问题

| 现象 | 处理 |
| --- | --- |
| 提示「禁止安装未知应用」 | 给你用来打开 APK 的应用（浏览器/文件管理器）开「允许安装未知应用」，步骤见 [下载与安装教程.md](下载与安装教程.md) |
| 提示系统版本过低 | 设备安卓版本低于 5.2，这台设备装不了，换设备 |
| 安装包解析失败 | 下载不完整，重新从网盘下载一次，核对 MD5 为 `DDE7062867F73ECCBA94AC3AF1DE3BFD` |
| 装完点开闪退 | 重启手机再试一次；仍闪退则清一次应用数据；还是不行属于机型兼容问题，去官方项目页提 issue 或看已有关联 issue |

## 五、什么时候该怀疑是版本太旧

Simple Live 这类聚合应用的工作方式决定了它的通病：**平台接口一变，旧版本就出问题**。给你三条判断线：

- 问题集中在**某一个平台**、且是「以前好好的突然不行」→ 大概率接口变动，等/求更新；
- 官方项目页的修复记录里正好有你遇到的现象关键词 → 直接升级；
- 四个平台全坏、且换网络也一样 → 不是版本问题，查你自己的网络环境。

升级前注意保留关注数据：按 [TV版与多端同步.md](TV版与多端同步.md) 里的 WebDAV 备份路子先备份一份，再覆盖安装新版本。

## 六、升级的现实情况：不是点一下就完

先说官方现状：Simple Live 的 GitHub 仓库 README 已声明**不再随版本提供现成的安装包**，所以不存在「应用商店点更新」这条路；各下载站流传的版本号五花八门、互不同步，也有用户反馈项目的更新节奏已经放缓。落到操作上：

| 你的处境 | 建议动作 |
| --- | --- |
| 手上这版四个平台都还能看 | 不折腾，正常用；版本号不是目的 |
| 某一个平台长期异常、确认是接口变动 | 去官方项目页（[github.com/xiaoyaocz/dart_simple_live](https://github.com/xiaoyaocz/dart_simple_live)）看 issue 与构建产物，能拿到新包就换 |
| 什么都拿不到、又急需用 | 有动手能力可按仓库说明自行编译；否则回退用商店里的官方客户端过渡 |

与官方 App 在更新机制上的完整对比，见 [和各平台官方App有什么区别.md](和各平台官方App有什么区别.md) 第三节。
