# 链接解析与直播间跳转

> 在微信、群里收到一条直播间链接，不想手动搜房间号 —— Simple Live 的链接解析可以直接跳进那个房间。

## 一、这个功能在哪、解决什么问题

应用里有一个「直播间跳转 / 链接解析」入口（不同版本的叫法略有出入，常见位置在**工具箱**页面）。它解决的是一种很具体的场景：你在聊天软件里收到朋友发来的直播间分享链接，或短视频里刷到一个直播间想直接看 —— 不用再打开应用去搜主播名，把链接粘进去，应用自动识别出是哪个平台、哪个房间，直接跳进直播间。

## 二、怎么用，三步

1. **复制直播间链接**。来源随意：聊天消息里的分享链接、短视频 App 的直播间分享口令或网址，复制后留在剪贴板。
2. **打开 Simple Live 的链接解析入口**，粘贴进输入框。
3. 确认后应用会解析出对应平台与房间，点结果直接进直播间。

四个聚合平台（哔哩哔哩、斗鱼、虎牙、抖音）的直播间链接都在支持范围内；能不能识别成功取决于链接里有没有带房间信息，纯文字描述、不带链接的分享是解析不出来的。

## 三、什么情况下会跳不过去

| 现象 | 原因与处理 |
| --- | --- |
| 提示解析失败 | 链接不完整或被聊天软件截断，回原处重新复制完整链接再试 |
| 解析出了房间但进去黑屏 | 那是播放问题不是解析问题，按 [看不了直播的常见问题.md](看不了直播的常见问题.md) 第一节排查 |
| 分享的是「口令」不是链接 | 有些平台分享出来是一串文字口令，不含网址的口令无法解析，先让对方发链接形式 |
| 直播间已下播 | 解析能成功，进去后没画面，属于正常情况 |

## 四、和直接搜索比，什么时候用哪个

| 场景 | 用哪个 |
| --- | --- |
| 知道主播名字 / 房间号 | 搜索框直接搜（见 [新手使用教程.md](新手使用教程.md)） |
| 手里有现成的直播间链接 | 链接解析，一步直达 |
| 只是想逛逛、没目标 | 按平台分区翻列表 |

调整直播间里的弹幕和画质，进房之后的事，见 [弹幕与画质设置.md](弹幕与画质设置.md)。
