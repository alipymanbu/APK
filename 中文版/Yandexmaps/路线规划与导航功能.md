## 一、起点：把终点输进去

在搜索框输入地址或地点名 → 点路线按钮 → 顶部按出行方式切换：**驾车 / 公共交通 / 骑行 / 滑板车 / 步行**。同一起终点每种方式给出的路线和耗时都不同，切换对比一眼就能看完。起点默认用当前定位，也可以手动改成其他地点；还能设置多个途经点，让应用按顺序串起来。

## 二、五种出行方式各自的要点

- **驾车**：按实时路况算路线并给预估时间，避开拥堵路段；导航中会提示电子眼、限速、事故与施工，还会报最近的停车场和加油站。需要路况和电子眼数据联网才有，离线导航的行为见 [离线地图下载与使用.md](离线地图下载与使用.md)。
- **公共交通**：给出公交/地铁方案的换乘与候车时间；地图上能直接看到公交车、有轨电车此刻开到哪了（实时位置，需联网）。常用的线路和站点可以收藏，之后在「My transport」里一键查看；点站点可查完整时刻表，甚至按日期查未来某天的班次。在莫斯科等大城市，地铁方案还会提示坐哪节车厢下车离出口最近。
- **出租车**：路线对比里会有出租车方案与预估价，实际叫车一般跳转到专门的打车应用进行。
- **骑行**：路线会标注自行车道与禁行路段，偏好设置里可以选「少过天桥/地下通道」之类的选项。
- **滑板车**：与骑行类似，按滑板车可通行路段计算。
- **步行**：路线会穿过公园、广场、楼间通道这些步行区；官方说明算法会把红绿灯、上坡、楼梯对速度的影响算进耗时里，给出的到达时间比较贴近实际。

## 三、路况怎么看

开启路况图层后，道路按拥堵程度着色，右上角有个 1~10 的分值，数字越大越堵：

| 分值 | 含义 |
| --- | --- |
| 1~2 | 畅通 |
| 3~4 | 部分路段拥堵 |
| 5 | 车流密集 |
| 6 | 车辆排长队 |
| 7 | 严重拥堵 |
| 8 | 拥堵绵延数公里 |
| 9 | 完全停滞 |
| 10 | 不如步行 |

除了「现在」的路况，还能看预报：按统计数据推算明天某时段的拥堵情况，选日期查看；保存「家」「公司」地址后，面板会直接给出两点间的预估通勤时间。道路事件（事故、封路、施工、吊桥升起）以图标形式标在图上，点图标看说明。

## 四、导航中的辅助功能

- **语音播报**：转向、电子眼、限速都有语音提示；语音语言跟随应用设置（无中文，见 [语言设置与中文界面说明.md](语言设置与中文界面说明.md)）。
- **屏幕防烧屏**：长时间导航时界面元素会自动降低亮度，可在 Settings → Map and interface → Burn-in protection 里改成「行驶 40 分钟后开启」或关闭。
- **音量键缩放地图**：安卓专属设置项，导航时不用伸手摸屏幕就能放大缩小。
- **地图类型**：示意图 / 卫星图 / 混合图三种，导航中一般用示意图最清晰。

## 五、找地方的辅助信息

- **地点详情**：营业时间、电话、服务项目、照片、用户评价都在地点页里，餐厅类地点可以直接预订座位。
- **街景全景**：多数道路旁可以拉起街景看现场，到陌生路口前先「云看一眼」能少走错路。
- **停车场图层**：部分城市（如莫斯科）可显示官方停车场位置与收费信息。
- **商场楼层图**：莫斯科大型商场的室内平面图，进了 mall 找店用得上。

以上信息类功能的可用范围随城市差异很大：俄罗斯境内城市最全，其他国家逐项递减，以你在地图上实际能看到的内容为准。
