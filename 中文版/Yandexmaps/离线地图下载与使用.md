## 一、什么情况需要离线地图

地图数据下到本地后，没网也能搜地址、规划路线。典型场景：

- 地下停车场、地铁里等没有信号的地方；
- 出国漫游不便或漫游流量贵，提前把目的地城市下好；
- 在网络受限的地区，入境初期手机长时间连不上网，离线包就是你的兜底。

## 二、下载离线地图的步骤

1. 点左下角**头像**进入个人页（未登录也能操作）。
2. 点 **Offline maps**（离线地图）。
3. 在搜索框输入国家、城市或地区名，从候选里选中。
4. 点下载图标开始下载；空间不足时先删掉不需要的应用、照片或视频。

几点注意：

- 部分国家不支持整国下载，只能按城市或地区分块下载；
- 一条路线跨多个地区时，**途经的每个地区地图都要下载**，缺一段那段就查不了；
- 给没下图的目的地规划路线时，界面会给出「Plan download（计划下载）」按钮，点一下，等你回到有网的环境地图会自动补下，不用记着这事；
- 下载进行中别把应用从后台划掉，下完再说（大城市的包有上百 MB，中断就得重来）。

## 三、更新与删除

**更新**：进入 Offline maps 后点更新设置，二选一：

| 选项 | 行为 |
| --- | --- |
| Auto update | 联网时自动更新 |
| Download via Wi-Fi only | 只在 Wi-Fi 下更新，省流量 |

**删除**：在 Offline maps 里可以逐个删除（点地图名旁的删除），也可以一键删掉全部已下载地图。取消进行中的下载：点地图名并确认取消。

## 四、离线状态下能做什么、不能做什么

- **能做**：搜索地址、规划驾车/公交/骑行/滑板车/步行路线；2026 年 9 月官方更新后，公交线路查询（含站点、换乘、时刻）也能离线使用，时刻数据随离线包保存并每周联网刷新。
- **不能做**：离线时地图只有示意图模式，卫星图/混合图不可用；路况、电子眼、道路事件这些来自网络的数据全部没有。
- **怎么触发**：不需要手动开关——把 Wi-Fi 和移动数据都关掉，应用自动进入离线模式；信号弱不会触发切换。开始导航后，路线信息栏上方出现「Route built offline」字样就说明当前是离线路线。
- **途中断网**：已经开始的导航会继续；但如果你中途改路线，新路线会按离线数据重新算，等网络恢复后再自动切回在线模式重算一遍。

## 五、离线包有多大

以官方商店页给的参考值，莫斯科的离线地图约 187 MB（按「最小占用」方式打包）。实际体积随地区和版本变化，下载前以应用里显示的大小为准。

## 六、常见问题

- **换 SIM 卡、换系统语言、拔插 SD 卡后地图不见了**：官方说明这几种操作都可能导致已下载地图丢失。处理办法：重装应用，或在「头像 → Settings → Clear search and route history」清空搜索与路线历史后重新下载地图。
- **同一段路在线和离线算出的路线不一样**：正常现象。在线模式会参考实时路况挑最优路线，离线模式没有路况数据，只能按地图本身计算。
- **离线时突然要上网**：地图上可以查到附近的 Wi-Fi 热点位置，按图索骥找网。
