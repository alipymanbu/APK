## 一、装之前先对一下这张表

公开渠道里放出的安装包只有安卓一种，没见到 iOS 版，也没见到 Windows / macOS 原生客户端。动手之前，先对着下面这张表确认自己设备合不合适：

| 项目 | 这一版的情况 |
| --- | --- |
| 软件名 | LeapMusic |
| 版本号 | 5.5.1 |
| 包名 | com.leapmusic.leapmusic |
| 安装包大小 | 4.37 MB（4,583,537 字节） |
| 安装包 MD5 | 2FA8E13BF85EFDE2E0FB63EF2D23F83E |
| 适用设备 | 安卓手机 / 安卓平板 / 安卓车机 |
| 系统要求 | 整理这一版时记录到的是「需要支持安卓系统 5.2 以上」 |

有两件事值得先说明：

1. **「安卓 5.2」这个写法不必纠结。** 安卓官方并没有对外的 5.2 版本（公开版本是 5.0、5.1，之后直接跳到 6.0），这句话按「Android 5 系及以上」理解就行。另有第三方介绍页把它写成 Android 4.3 以上，两边口径并不一致 —— 真正能不能装，以你设备上点下去之后的提示为准。
2. **版本号以本页表格为准，别跟网上介绍里的数字比。** 应用商店里能搜到 LeapMusic 的条目，但那条目上挂的版本号（5.1.1）落后于这份资源（5.5.1）；网上各种介绍页写的多半是官方某个时点的最新版。它们和你手上这个包不一定是同一版。各页面数字为什么差这么多、怎么核对，见 [官方渠道与版本号怎么认.md](官方渠道与版本号怎么认.md)。

## 二、从网盘把安装包取出来

1. 打开 [LeapMusic 安装文件资源（夸克网盘）](https://pan.quark.cn/s/58fe19cdecd3)。手机、电脑上都可以操作，用夸克 App 打开更稳。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存之后，下载就不再依赖原分享链接是否还在。
3. 分两种情况取包：
   - **装到手机上**：直接在网盘 App 里下载，落到手机的「下载」目录即可。
   - **装到车机上**：更省事的做法是在电脑端网盘下载，再用 U 盘拷进车机（车机上操作网盘 App 麻烦，也不容易确认下载是否完整）。
4. 下完核对两件事：文件名结尾是不是 `.apk`；MD5 是不是 `2FA8E13BF85EFDE2E0FB63EF2D23F83E`。对不上就删掉重下 —— 安卓装到一半报「解析包错误」，绝大多数是包没下完整或被传坏。

## 三、手机上的安装步骤

这个安装包不是你从手机自带的软件商店里下下来的，安装时系统会拦一下，属于正常现象，不代表文件有问题。

1. 打开手机的「文件管理」，进 `Download`（下载）目录，找到刚下好的安装包，点它。
2. 系统弹出「不允许安装来自此来源的应用」之类的提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要绕一层：设置 → 应用 → 特殊应用权限 → 安装未知应用，在里面找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」，别急着打开 —— 先把下面的权限一次性给对，进去之后就不会反复弹窗。

装完桌面或应用列表里会出现 LeapMusic 的图标。

## 四、车机上的安装步骤

安卓车机基本没有上架这个应用，靠本地安装包装。通用流程是这样的：

1. 把 U 盘格式化成 `FAT32` 或 `exFAT`。很多车机不认 `NTFS`，插上去根本不显示 U 盘内容，这一步是白折腾的头号原因。
2. 把 `.apk` 文件放到 U 盘的**根目录**（不是子文件夹里）。
3. 车辆挂 P 档、拉手刹，再把 U 盘插到前排的**数据** USB 口。部分车型后排或扶手箱里的接口只供电不读数据。
4. 打开车机的「文件管理」或「本地媒体」，切到 USB 设备，找到这个 apk 点安装。
5. 如果提示不允许安装：进车机的安卓原生设置 → 安全 → 打开「未知来源」；有的车机要先切到能进原生设置的模式才能找到这一项。
6. 装完拔掉 U 盘，在车机的应用列表里找图标。

三点提醒：

- **不同品牌车机的入口差别很大**，有的在应用列表直接装，有的需要拨号键输入工程代码才开放第三方安装。上面写的是通用路径，具体以你车机的实际界面为准。
- 车机存储空间紧张时，安装会直接失败。装前留出几十 MB 余量。
- 部分车机系统本身限制第三方应用安装，这种情况绕不过去，别在车机上硬试。

## 五、装完第一次打开要做的几件事

1. **不用注册、不用登录**，打开就直接进主界面。
2. **先挑一个主题色**。首次进入会让你选，这个选择会影响之后整个界面的配色，之后在设置里还能改，见 [主题外观与音效调节.md](主题外观与音效调节.md)。
3. **首页本身就是播放界面**，上下滑动可以在曲目之间切换，不用先进列表再点播放。
4. **别急着找歌**：这是一个本地播放器，装完库里是空的，歌要自己放进去后再扫描，见 [导入本地音乐与歌单管理.md](导入本地音乐与歌单管理.md)。
5. 想开桌面歌词的话，还要额外给一次「显示在其他应用上层」的权限，这一项在 [歌词显示与桌面歌词设置.md](歌词显示与桌面歌词设置.md) 里说。

## 六、装不上时先查哪几处

- 提示「解析包错误」→ 包没下完整，回网盘重下，用 MD5 核对。
- 提示「应用未安装」→ 设备上可能已经装了同包名的旧版，且签名对不上；先卸载旧版再装。
- 车机提示禁止安装、或装了但图标不出现 → 看 [常见问题与排查.md](常见问题与排查.md) 里车机相关的两条。
