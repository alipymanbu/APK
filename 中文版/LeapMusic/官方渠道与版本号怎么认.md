## 一、先认开发者和包名

应用商店里 LeapMusic 的详情页上，开发者与运营者写的是同一个人：**夏培胜**；包名是 `com.leapmusic.leapmusic`。这两样合起来才是判断「是不是同一个应用」的锚点：

- **开发者看名字，包名看字符串。** 目前能见到的 4.x 到 5.x 各个版本，包名都是 `com.leapmusic.leapmusic`。名字一样、包名不一样，那就是另一款应用，而不是同一份东西换了版本。
- **包名在哪看。** 装完之后：设置 → 应用管理 → 找到 LeapMusic → 应用信息，里面能看到包名和版本号。

## 二、版本号对不上是常态

同一款应用，在不同页面上写出来的数字往往完全不同：

| 你看到的地方 | 可能写的数字 |
| --- | --- |
| 应用商店详情页 | 5.1.1 |
| 本地这份安装包 | 5.5.1 |
| 各种第三方介绍页 | 5.0、5.5，也有明显来自别的软件的 9.8.6 |
| 安装包大小 | 4.37M、4.4M、7.3M、7.9M，甚至 20M 以上 |
| 系统要求 | Android 4.0、4.3、5.2、8.0 都出现过 |

原因不难理解：应用商店里挂的是开发者自己上传的那一版，更新有滞后；而第三方介绍页多为自动拼装的整理稿，数字经常没有跟着源文件走，也就对不上了。

**所以核对的办法不是比版本号，而是比包名和 MD5。** 版本号会被人随便写，包名和一个具体文件的 MD5 不会。

## 三、三类描述可以直接跳过

翻资料时，下面三类内容看不出与这份安卓包有关，不要拿来当判断依据：

1. **把安卓应用写成桌面软件的。** 提到音频引擎、独占输出、系统热键、任务栏缩略图预览、深色/浅色主题切换这类桌面播放器特性的页面，基本都是套了别的软件的说明模板。
2. **写到「注册 / 登录 / 账号」的。** 这一版打开就能用，没有登录流程。写账号问题的页面同理。
3. **功能清单堆得又多又全的。** 在线曲库、智能推荐、社交分享、跨平台同步、云同步一口气列全的清单，与官方简介里只提本地播放、主题、歌词、可视化这几项对不上，属于模板式文案。

## 四、核对用的几个锚点

| 项目 | 这一版的值 |
| --- | --- |
| 包名 | com.leapmusic.leapmusic |
| 版本号 | 5.5.1 |
| 安装包大小 | 4.37 MB（4,583,537 字节） |
| 安装包 MD5 | 2FA8E13BF85EFDE2E0FB63EF2D23F83E |

核对走两步：

1. **装之前**：拿到 `.apk` 后用任意文件校验工具算一遍 MD5，与上表比对。不一致就重下，不要接着装。
2. **装之后**：在应用信息里看包名和版本号。包名对不上，说明装的不是这一款；包名对、版本号是 5.x 的相近版本，那是同一款应用的另一个版本。

只要包名和 MD5 都对得上，就是同一份安装文件；对不上，页面标题写得多像都不算。取包与校验的步骤在 [下载与安装教程.md](下载与安装教程.md) 第二节。

## 五、看到「另一个更好用的版本」时

- **新版会换 apk 文件名，包名不变。** 所以升级判断看包名，不看文件名里带的版本字样。
- **同一版本的两次下载，MD5 应当一致。** 同一个版本号却算出两个不同 MD5，说明至少有一份是被重新打包过的，别装。
- 遇到宣称更快、更全、能额外提供什么能力的版本，回到第四节那张表核对一遍，对不上就跳过。
