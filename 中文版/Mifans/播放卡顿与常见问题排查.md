## 一、播放卡顿：先换线路，再降画质

Mifans 的详情页通常带多条播放线路，一条卡就换另一条，这是见效最快的办法（第三方问答里也是这么建议的）。换完还卡，按顺序做：

1. 降一档清晰度；
2. 开个网页测一下网速，确认不是网络本身的问题；
3. 杀掉应用重开，或重启手机；
4. 晚高峰（八点到十一点）才卡、白天流畅，多半是线路负载的事，错峰看或先缓存后看。

另外留意一种情况：**画面不是卡、是变糊**——那不是网络问题，多半是省流模式开着把清晰度压低了，去「离线缓存与播放设置」里把它关掉再切回高清。

## 二、播放进度不保存

常见原因有两个：

- **没登录账号**：进度只存在本机，清缓存、卸载重装都会丢；登录后进度可同步，换设备也能接上（以实际版本为准）；
- **非正常退出**：直接杀后台有时来不及记位置，从播放界面正常退出更容易保住进度。

## 三、投屏搜不到电视

这不是播放问题，是网络问题，按「投屏到电视的方法」里的排查清单逐项核对，重点先确认两台设备在同一个局域网。

## 四、装完打不开 / 闪退

1. 先确认安装包完整，会校验的比对 MD5，方法见「下载与安装教程」；
2. 安卓版本太低会闪退，检查系统是否达到安装包要求的版本；
3. 给应用必要的存储权限（首次启动时弹的权限别全部拒绝，缓存与离线功能依赖它）；
4. 还不行就卸载重装一次；仍闪退说明这份安装包与你的机型不兼容，换一份别的版本再试。

## 五、几个高频小问题

| 问题 | 结论 |
| --- | --- |
| 要不要登录才能看 | 第三方页面的说法是不登录也能直接看；登录主要影响进度同步，注册入口在主页顶部，见「离线缓存与播放设置」 |
| 更新提醒收不到 | 先开系统通知权限再重启应用，做法见「追番时间表与找番方法」 |
| 画面发糊 | 查省流模式并手动切高清档位重新加载，不是网络问题，见「离线缓存与播放设置」 |
| 是不是只能看动漫 | 是，它是一款追番应用，不提供别的节目类型 |
| 免费还是收费 | 各渠道描述不一，以应用内实际展示为准，别轻信任何「免费看全部」的宣传 |
| 网上的版本号怎么和我的不一样 | 不同渠道在售版本差异很大（1.x 到 4.x 都有标注），以你手上安装包的信息为准 |
| 缓存的视频存在哪 | 存在应用私有目录里，文件管理器一般看不到，清理走应用内或系统的存储管理 |
