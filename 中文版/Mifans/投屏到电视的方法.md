## 一、投屏入口：播放界面右上角的 TV 按钮

先在手机上正常播放一集，进入播放控制界面后，**右上角有一个 TV 图标**，那就是投屏入口。它不在设置里，也不在首页——必须先进入播放界面才能看到。

## 二、投屏步骤

1. 确认手机和电视（或电视盒子）连的是**同一路由器下的同一个网络**；
2. 在 Mifans 里打开想看的番剧，进入播放界面；
3. 点右上角的 TV 图标，应用会自动搜索同一局域网里的可投屏设备；
4. 搜到后点设备名称，连接成功后画面转到电视上播放。

投屏走的是局域网连接，不消耗手机流量；连接中断时重新点一次 TV 图标再连即可。

## 三、搜不到设备：按这个清单挨个查

| 检查项 | 说明 |
| --- | --- |
| 是否同一网络 | 手机用流量、电视用 WiFi 的组合投不了，两台设备必须在同一局域网 |
| 路由器 AP 隔离 / 访客网络 | 部分路由器默认隔离设备间互访，关掉 AP 隔离，或让两台设备都离开访客网络 |
| 电视的投屏服务没开 | 在电视设置里确认投屏 / DLNA 开关已打开（不同品牌入口不同，可直接在电视设置里搜「投屏」） |
| 双频路由器分段 | 2.4G 与 5G 两个频段互相搜不到时，先把两台设备都连到同一频段试试 |
| 老电视没有智能系统 | 非智能电视接不到投屏，需要一个电视盒子 |

排查完仍搜不到，多数是网络环境问题而不是应用问题；换一集视频再连一次，可以排除单集视频源的因素。

投屏成功后画面在电视上，清晰度跟随手机端的播放设置；若电视端卡顿，回手机端把清晰度调低一档，详见「播放卡顿与常见问题排查」。
