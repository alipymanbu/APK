## 一、安装前先核对这几件事

Mifans 是一款安卓端追番应用，中文名常写作「五号动漫」。各应用商店里同名或近名的应用很多，版本与包名未必对得上，认准安装包的文件信息比认名字更稳。这份安装包的信息如下：

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.3.0 |
| 包名 | com.cyxxcg.shark |
| 体积 | 约 27.2 MB |
| MD5 | `75B24338BC512B8B195EC892FAD8B2A0` |
| 系统要求 | 安卓 5.2 以上（按安装包记录；部分第三方页面标注 4.0 以上即可安装，以实际安装提示为准） |

两点提醒：

- **不同渠道的版本号差异很大**。网上搜这个名字，能看到 1.x 到 4.x 各种版本号、几十 MB 到一百多 MB 的安装包，渠道在售的版本并不统一，不用纠结谁对谁错，以你手上这份安装包为准。
- **侧载安装的应用一般不会自动更新**。想换新版就重新拿一份新安装包覆盖安装，同包名覆盖不会丢观看记录与收藏。

## 二、从夸克网盘拿安装包

文章头部的链接就是 Mifans 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/875fe80aeca6](https://pan.quark.cn/s/875fe80aeca6)

转存与下载步骤：

1. 点开链接，选择「保存到网盘」（没有夸克账号会先要求登录，手机号验证即可）；
2. 打开夸克网盘 App 或网页版，找到刚保存的文件；
3. 把 APK 文件下载到手机存储。

在电脑上也可以先把 APK 下到电脑，再通过数据线或微信、QQ 的文件传输功能传到手机安装。

## 三、安装步骤

1. 在手机上点开下载好的 APK 文件；
2. 系统提示「禁止安装未知来源应用」时，按手机品牌处理：
   - 小米 / 红米：设置 → 应用设置 → 授权管理 → 特殊应用权限 → 安装未知应用，给浏览器或文件管理器授权；
   - 华为 / 荣耀：设置 → 安全 → 更多安全设置 → 安装外部来源应用；
   - OPPO / vivo / 一加：安装弹窗里选「允许本次安装」，或在设置里搜「安装未知应用」逐项授权；
3. 回到安装界面点「安装」，等进度走完；
4. 点「打开」进入应用，首次启动弹出的权限请求建议放行存储权限，缓存与离线功能要用。

## 四、装不上 / 安装失败怎么排查

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示「解析包出现问题」 | 下载不完整或传输损坏 | 重新下载一次；会校验的可以比对 MD5 是否为上表值 |
| 提示「应用未安装」 | 同包名但签名不同的旧版本残留 | 先卸载旧版再装 |
| 提示系统版本过低 | 安卓版本低于安装包要求 | 升级系统，或换一份要求更低的版本 |
| 提示存储空间不足 | 剩余空间小于包体加缓存 | 清出至少几百 MB 再装 |
| 装好后点图标没反应 | 系统对未知来源应用做了二次限制 | 在系统设置里允许该应用运行，或重启手机再试 |
