AfuseKt 不是纯本地应用，账号是使用门槛之一；另外它有免费与订阅两档，TV 端与订阅绑定较深。本篇把账号相关的事和散落在各处的高频问题集中说清。

## 一、注册账号

首次打开应用会要求注册，邮箱即可完成：按提示填邮箱、密码并确认，注册后直接登录进入主界面。注册这一步绕不开——不注册无法使用任何功能。

注意注册入口只在手机版里：TV 版（AfuseKtV）打开后直接是登录界面，没有注册功能，必须先在手机端注册，再用同一账号登录电视端，详见 [TV版安装与手机同步教程.md](TV版安装与手机同步教程.md)。

两点提醒：

- 账号绑定的是官方账号系统，涉及你资源库里的网盘与媒体服务器凭据，密码不要与其他平台复用。
- 想彻底删除账号的话，官方 README 给出的渠道是联系作者本人并按要求提供账号信息与验证截图，通过后账号与数据会从系统中移除。

## 二、订阅与 TV 版

手机端的基础功能（添加资源库、刮削、播放）免费可用；官方另提供月费、年费、永久几档订阅，解锁同步等扩展能力。关键差异在 TV 端（AfuseKtV）：多个渠道转述的官方手册口径为 TV 端仅永久订阅可用，具体以官方购买页当时说明为准；手机版则可以先免费用起来再决定。

购买入口在官方渠道（GitHub 发布页 README 与官网 [www.afusekt.cn](https://www.afusekt.cn)），价格与档位以购买页当时显示为准。需要提醒的是 TV 端资源库不能独立添加，必须先在手机端配好再同步——所以就算只为电视用，也要先有一部能装手机版的设备。

## 三、常见问题排查

**提示「网络貌似无法连接服务器，请尝试关闭代理」**：多个用户反馈过这个提示。按这个顺序排查：

1. 关掉手机上的代理、VPN、网络加速类应用——这是该提示字面点的名，命中率也最高；部分加速工具退出后仍会残留代理设置，彻底重启一次手机再试。
2. 换网络：WiFi 与流量互切，或换个热点，用来区分是网络环境问题还是账号服务问题。
3. 核对系统时间：设备时间不准会导致安全连接建立失败，把日期时间设成自动获取。
4. 以上都无效时，清除应用的缓存再重新登录；再不行就卸载重装（资源库配置跟账号走，重装不会丢）。

确认网络正常后仍反复出现，多半是官方服务波动，隔段时间再登录。

**注册或登录一直转圈**：与上一条同源，先排除代理环境；邮箱收不到验证类邮件时检查垃圾箱。

**添加资源库后没有内容**：不是账号问题，是扫描刮削还没完成或文件命名不合规，见 [刮削与海报墙设置.md](刮削与海报墙设置.md)。

**阿里云盘添加不了**：安卓 11 以下系统不支持该功能，属于系统版本限制。

**播放黑屏或花屏**：与账号无关，切换内置播放核心解决，见 [内置播放器对比与播放设置.md](内置播放器对比与播放设置.md)。

**长期不更新版本会怎样**：有论坛用户反馈停留在旧版过久可能被要求重新注册账号（单方反馈，官方没有明文口径）。升级本身只是覆盖安装，片源配置不受影响，不放心就保持正常更新。

**TV 端安装哪个包**：官方发布页分 32 位与 64 位两个包，对应不同盒子的芯片；装错架构会直接无法安装，不确定就两个都试。
