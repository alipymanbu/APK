# AfuseKt 资源库添加与配置

AfuseKt 本身不带片源，所有影视内容都来自你添加的「资源库」。资源库分两类：媒体服务器类（Emby、Jellyfin）直接读取服务器整理好的数据；存储类（WebDAV、SMB、Alist、网盘）则由 AfuseKt 自己扫描并刮削。本篇按类型给出添加步骤与各自的注意点。

## 一、支持的资源库类型

官方发布页当前列出的移动端支持范围如下（随版本更新会增减，以发布页为准）：

| 类型 | 形式 | 说明 |
| --- | --- | --- |
| Emby / Jellyfin / Plex | 媒体服务器直连 | 直接使用服务器端已整理好的媒体数据 |
| Alist | 存储聚合 | 挂 Alist 即可覆盖其下挂的各家网盘 |
| WebDAV | 存储协议 | 各类支持 WebDAV 的网盘、NAS 目录 |
| SMB | 局域网共享 | NAS、路由器挂载的硬盘 |
| 阿里云盘 / 115 / OneDrive / 123 等 | 网盘直连 | 需在应用内授权登录 |
| Local | 本地存储 | 设备本地或 U 盘里的文件 |

TV 端（AfuseKtV）的协议清单与移动端接近，但资源库只能通过移动端同步过去，无法在电视上独立添加，装电视端前先看 [TV版安装与手机同步教程.md](TV版安装与手机同步教程.md)。

## 二、通用添加步骤

不同类型的入口一致，都在「资源库」里：

1. 登录后进入资源库页面，点右上角的加号。
2. 选择资源库类型。
3. 按类型填地址、账号、密码（或走授权登录）。
4. 确定后等扫描完成，选择要纳入的文件夹。
5. 存储类资源库会自动开始刮削，稍等几分钟海报墙就出来了。

## 三、各类型的填写要点

**Emby / Jellyfin / Plex**：填服务器地址、用户名、密码即可，地址要含端口（如 `http://192.168.1.10:8096`）。直连成功后不会重新刮削，直接显示服务器端的媒体库结构，包括剧集的片头信息。媒体服务器版本较旧时个别字段可能显示不全。

**WebDAV**：需要服务器地址、账号、密码三件套，路径一般留默认。很多人用它挂 Alist 转出来的 WebDAV，此时账号密码就是 Alist 后台设置的那组。

**SMB**：填局域网设备的 IP、共享名、账号密码。SMB 对设备与网络环境要求高，连不上时优先检查手机与 NAS 是否在同一网段。

**阿里云盘**：不走地址，点类型后在应用内完成授权登录，再选择要挂载的文件夹即可。有教程提示该功能需要安卓 11 及以上系统。

**Alist**：填 Alist 站点地址与登录凭据，挂上后 Alist 里挂了哪些网盘就都能浏览，是覆盖面最广的一种接法。

**Local**：直接浏览设备本地目录，适合看下载到本地的零散视频。

## 四、添加成功但列表是空的

存储类资源库加完不是立刻有内容——它要先扫描再刮削，这个过程在后台进行，量大的话要等几分钟。长时间没动静时按顺序检查：

1. 进 [刮削与海报墙设置.md](刮削与海报墙设置.md) 核对文件命名是否符合要求，命名不合规是扫不出来的最常见原因。
2. 确认地址、账号、密码没有多余空格。
3. 手机开了代理或 VPN 时，可能出现「网络貌似无法连接服务器」的提示，详见 [注册账号与常见问题.md](注册账号与常见问题.md)。
