## 一、先明确一个前提

Moddroid 是资源目录型客户端：它自己不生产内容，而是把一个个游戏/应用条目组织起来，每个条目对应一份安装包。所以你的动作永远是三步——**找到条目 → 看详情 → 点下载**。找到入口有两种：翻分类，或者直接搜。

## 二、翻分类：不知道名字的时候用

首页按热门与专题组织，往下有按类型划分的分类（动作、竞速、体育、音乐、工具等）。适合「想找个这类游戏但没想好具体哪个」的场景：

- 热门榜单是按下载关注度维护的，隔段时间会换血，适合扫一眼看看最近大家在装什么；
- 每个条目卡片上会标名字、版本号和一句特征说明，扫卡片比点进去逐个看快得多。

## 三、搜索：知道名字的时候用

首页顶部有搜索框，输入游戏或应用的名字，结果会自动匹配相关条目。三个实用细节：

1. **用英文名搜**。这个平台的条目以国际应用与游戏为主，虽然部分海外游戏的介绍做了中文整理，但条目名基本是原文，用英文名或原名搜命中率更高，中文名往往搜不到；
2. 搜出来多个结果时，对一下**详情页里的版本号和大小**再下——同名条目可能对应不同版本；
3. 搜不到时先检查拼写，还是找不到就说明目录里暂时没有这个条目，可以等平台后续更新，或通过官方的反馈渠道（Telegram、Discord 社区）提交需求。

## 四、详情页：下单之前看这几样

| 看什么 | 为什么看 |
| --- | --- |
| 版本号 | 确认是不是你要的那一版；条目更新后版本号会跟着变 |
| 安装包大小 | 对照手机剩余存储，几十 MB 到几百 MB 都有 |
| 系统要求 | 对照你手机的安卓版本（「设置 → 关于手机」里看），不满足的包装不上，下了也白下 |
| 权限列表 | 条目页会列这份包要哪些权限，装前扫一眼，与用途明显对不上的多留个心眼（官方的安全建议） |
| 介绍与说明 | 部分海外游戏有中文介绍，能帮你确认是不是同一个东西 |
| 截图 | 直观看界面长什么样，比文字介绍快 |

## 五、点下载之后发生了什么

详情页底部有「Download」按钮，点下去之后：

1. 下载作为**后台任务**进行，你可以退出到桌面或开别的 App，不耽误；
2. 进度显示在**系统通知栏**里，随时下拉就能看，不用回到 App 里等；
3. 下载中途断网、锁屏导致的中断，恢复后是**从断点继续**而不是从头重来——这对移动网络下下大体积安装包差别很大，浏览器里下载经常一断就得重下；
4. 下载完成后从通知栏点进去，或在 App 里直接进入安装。

安装环节卡住了（解析包错误、被系统拦截等）不要反复点同一个按钮，先去 [下载失败与安装报错排查.md](下载失败与安装报错排查.md) 对一遍症状，多数情况几分钟内能解决。
