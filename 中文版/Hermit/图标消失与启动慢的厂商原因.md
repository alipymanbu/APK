# Hermit 图标消失与启动慢的厂商原因

> 本篇讲两类看起来像「Hermit 坏了」、其实出在手机厂商那一侧的问题：桌面图标重启后消失或变样、应用启动慢或后台被杀。装机环节见 [下载与安装教程.md](下载与安装教程.md)。

## 一、先分清锅在谁身上

**图标类问题**：安卓的桌面图标由启动器（Launcher，就是你桌面那个界面）负责创建和维持。流程是 Hermit 把图标和名字交给启动器，之后双方不再交互，图标归启动器管。所以这些症状——

- 重启后图标消失；
- 所有图标都变回 Hermit 的应用图标，而不是你挑的图标；
- 所有图标名字都变成「Hermit」，而不是你起的名字；

——都是启动器没把它那半件事做好，问题在启动器或厂商系统，不在 Hermit，重装 Hermit 也没用。

**启动慢类问题**：部分厂商在系统层面激进杀后台，官方点名这类改动的实际省电效果有限，但会把正常应用的后台活动一起杀掉。

## 二、官方列出的已知问题启动器

| 启动器 / 系统 | 症状 |
| --- | --- |
| 小米 / Redmi 内置启动器 | 用内置启动器时启动明显变慢，换任意第三方启动器即恢复 |
| 华为 EMUI 启动器 | 默认禁止应用创建桌面快捷方式，需要去权限管理放行 |
| 一加 OxygenOS 启动器 | 设置正常，重启后所有图标名字变回「Hermit」 |
| CM / Nano / Tap2 / SF 启动器 | 图标随时或重启后消失 |
| Z Launcher | 只显示第一个图标 |

EMUI 的具体处理：进系统的「应用权限管理」，允许 Hermit 创建桌面快捷方式。

## 三、图标问题的变通做法

1. 在启动器里按它自己的方式「添加快捷方式 / 小部件」；
2. 从列表里选「Hermit — Create a Lite App」；
3. 挑对应的 Lite App。

这是让启动器反过来向 Hermit 要图标，官方说在有问题启动器上不保证成功，但值得先试。换用第三方启动器（官方推荐免费的 Nova Launcher）是另一条路——注意 2021 年起 Nova 也出现过同类丢图标问题，Google 已确认，暂时无解，所以换了也不算一劳永逸。

图标丢了不要紧：Lite App 本体和全部配置都还在 Hermit 里，重新添加一次桌面图标即可，不丢任何数据。

## 四、启动慢与后台被杀

华为、三星、一加、小米、魅族、OPPO、华硕、联想、诺基亚、索尼等品牌的系统都被记录有不同程度的杀后台行为。按品牌看具体解法，官方指向第三方开发者维护的站点 [https://dontkillmyapp.com/](https://dontkillmyapp.com/)（按品牌列出各家系统的关闭方法）。

通用动作就三件，做完启动和通知都会明显正常：

- 给 Hermit 关闭电池优化；
- 允许后台活动 / 自启动；
- 把 Hermit 加进系统的启动管理白名单（不同品牌入口名字不同，以你手机实际设置为准）。

这组设置同样影响 Feed 通知能不能按时到达，通知排查的完整清单见 [常见问题与使用注意.md](常见问题与使用注意.md)。
