## 一、先分清：观影应用需要哪些权限

从应用介绍看，Free HD 不强制索取通讯录、短信这类敏感权限。对一款影视点播应用，你心里可以有一张「合理权限」的底表：

| 权限 | 是否合理 | 理由 |
| --- | --- | --- |
| 网络 | 必要 | 在线点播、更新片库全靠它 |
| 存储 / 媒体 | 必要 | 缓存视频要写到手机里（见 [缓存下载与离线观看.md](缓存下载与离线观看.md)） |
| 通讯录、短信、通话记录 | 不合理 | 看视频用不上 |
| 精确定位 | 不合理 | 按片源选内容不需要知道你在哪 |
| 麦克风、相机 | 警惕 | 看视频用不上；弹出这类请求先拒绝 |

中消协与反诈民警多次提醒：影视类应用是过度索权和恶意程序的高发区，对要求通讯录、短信、麦克风、摄像头、定位的应用要格外警惕——这条提醒针对的是整个品类，不针对某一款。所以不管用什么观影应用，装完先按下面第二节的路径查一遍它拿了什么权限。

## 二、各品牌手机在哪查和关权限

路径因品牌和系统版本略有差异，通用兜底办法：**打开系统「设置」，在顶部搜索框输入「权限管理」或「应用权限」**，直接跳到对应页面。

| 品牌 / 系统 | 参考路径 |
| --- | --- |
| 华为 / 鸿蒙 | 设置 → 应用 → 权限管理；或 设置 → 隐私和安全 → 应用和元服务权限管理 |
| OPPO / ColorOS | 设置 → 安全 → 应用权限 |
| 原生 Android | 设置 → 隐私 → 权限管理器 |
| 其他品牌 | 设置内搜索「权限管理」，找到 Free HD 逐项查看 |

检查动作就三步：找到 Free HD → 看它已获得的权限 → 对照第一节的底表，把「看视频用不上」的权限关掉。关权限可能导致个别功能不可用（比如不给存储就缓存不了），按需取舍即可。

## 三、遇到索权弹窗怎么处理

按轻重顺序来：

1. **正常索权**（网络、存储）：按需允许；
2. **可疑索权**（通讯录、短信、定位、麦克风、相机）：直接拒绝。拒绝后应用还能正常看片，说明这权限本来就不必要；
3. **不授权就不让用**：这种「捆绑索权」本身就值得警惕，稳妥的做法是停止使用并卸载，别为了看片交出敏感数据；
4. **装完后行为异常**（流量暴涨、频繁弹通知、自动装别的应用）：先关后台权限，再考虑卸载，处置顺序见 [卡顿闪退问题排查.md](卡顿闪退问题排查.md)。

## 四、应用内的自保动作

权限之外，应用内部也有几处要留神，都是防诈提醒里点过名的场景：

- **广告横幅别乱点**：免费应用靠广告维持，但「领现金」「中奖」这类诱导横幅点进去常是钓鱼页，看到了直接关；
- **不输入支付信息**：不要在应用里填银行卡、密码、验证码；如果应用弹「屏幕共享」「粘贴密钥」之类的请求，一律拒绝；
- **登录从简**：遇到登录入口优先用正规第三方账号授权，别为了多看几部片填手机号、身份证这类真实信息。

## 五、顺手做一次流量自查

这类应用「后台偷跑流量」是被反复曝光的坑，自查花不了一分钟：

1. 打开系统「设置 → 移动网络 → 流量使用情况」（路径各品牌略有差异，可搜「流量」）；
2. 看流量排行里 Free HD 的用量正不正常——正常应该和你实际看片的时长对得上；
3. 用量明显对不上时，进应用详情页关掉「后台数据 / 允许后台使用」，再观察两天；
4. 关了后台还在涨，就清缓存或卸载重装（重装前确认手里的安装包还在，可从 Free HD 安装文件资源（夸克网盘）重新获取）。
