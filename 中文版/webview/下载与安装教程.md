## 安装前先弄清楚三件事

**它是系统组件，装的是「覆盖更新」。** Android System WebView 本来就在系统里，你手动装 APK 等于把现有版本覆盖成这个版本，应用数据不会丢，已登录的应用不受影响。

**包名必须对得上。** 正规的 Google 版 WebView 包名是 `com.google.android.webview`。安装包信息如下（本文档核对时间 2026-09-27）：

| 项目 | 内容 |
| --- | --- |
| 版本 | 127.0.6533.64 |
| 包名 | `com.google.android.webview` |
| 大小 | 219.60M |
| MD5 | `BCBA9BC2CE0116F7B2079E9B11834B5C` |

你的手机上如果正被另一个 WebView 实现接管（部分机型由浏览器或厂商自有组件承担），系统会拒绝同包名覆盖以外的替换，此时别硬装，先在开发者选项里确认当前实现，见[版本查看与更新方法](版本查看与更新方法.md)。

**装完别关它的自动更新。** 手动装的版本只是一个时间点的快照，安全修复仍在持续推送，装完后保留应用商店的自动更新即可。

从 [Android System WebView 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2bcd67297307)拿到安装包后，转存到自己的网盘再下载到手机本地，就可以开始装了。

## 安装步骤

1. **允许安装未知来源应用。** 打开手机的「设置 → 应用」，找到你用来打开安装包的文件管理器（或浏览器），在它的应用详情里打开「允许安装未知应用」开关。不同品牌的叫法略有差异，有的在「设置 → 安全」里，有的在安装时弹窗引导你开。
2. **找到安装包。** 用文件管理器进入下载目录，点 APK 文件。安装包较大（约 220M），点开后可能要等一两秒才出现安装按钮。
3. **确认包名与版本。** 安装界面会显示应用名与版本号，确认与你拿到的信息一致再按「安装」。
4. **等待安装完成。** 系统组件的覆盖安装一般比普通应用快，期间不要锁屏或清理后台。
5. **装完重启一次。** WebView 被大量应用共用，重启能让所有应用下次启动时挂上新版本。

如果安装按钮是灰的、或提示「与已有应用冲突」，多半是你设备上的 WebView 由 Chrome 承担（Android 7~9 常见），这种情况装不进也不需要装，说明在[是什么有什么用](是什么有什么用.md)的版本关系表里。

## 校验文件完整性

下载、转存的环节越多，文件出问题的概率越高。装之前花一分钟校验 MD5，确认文件没有损坏：

| 环境 | 命令 |
| --- | --- |
| Windows（PowerShell） | `certutil -hashfile 文件路径 MD5` |
| macOS / Linux | `md5sum 文件路径` |
| 安卓手机 | 用文件管理器自带校验功能，或装一个支持 MD5 校验的文件工具 |

算出来的值对照上表：`BCBA9BC2CE0116F7B2079E9B11834B5C`。不一致就重新下载，不要带着侥幸装一个损坏的系统组件——装失败是小事，装了个半损件进去，受影响的是所有用网页内容的应用。

## 装完之后

打开「设置 → 应用 → Android System WebView」，版本号应显示为 127.0.6533.64。想确认当前生效的 WebView 实现与更新渠道，见[版本查看与更新方法](版本查看与更新方法.md)；如果装完反而出现应用闪退，按[应用闪退怎么修复](应用闪退怎么修复.md)从第一步开始排查。
