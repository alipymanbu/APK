# Snaptube 常见问题与排查

> 实际使用中高频出现的故障与对应处理：下载失败、没有下载按钮、搜索失效、安装被拦、闪退卡顿。

## 一、下载类问题

| 现象 | 按顺序试这几步 |
| --- | --- |
| 点了下载但一直不开始 / 中途失败 | ① 换个稳定的 Wi-Fi 或网络试；② 完全退出 Snaptube 再打开；③ 确认用的是最新版（设置 → 关于）；④ 看设置里是否开了「仅 Wi-Fi 下载」而你正在用流量 |
| 提示下载失败 | 多半是这条内容本身受限：地区限制、年龄限制，或平台近期改了接口。先换一条视频验证 —— 别的能下、只有这条不行，就不用折腾应用本身 |
| 手机流量下不了 | 设置 → 下载设置里确认「移动数据下载」开关是开着的（部分版本默认只在 Wi-Fi 下下载） |
| 下载速度很慢 | 速度取决于你的网络和平台服务器响应，先测自己的网速；同一时段换平台上的其他内容对比，若都慢，等网络低峰或换网络 |
| 下载到一半断了 | 在下载管理页点继续，支持断点续传，不会从头下 |

## 二、界面与搜索类问题

| 现象 | 处理 |
| --- | --- |
| 视频页没有下载按钮 | 常见原因：该内容的下载服务在你所在地区不可用（有用户反馈过美、英、法等地区出现过此情况）。换一条同类内容验证，若全部没有，则是地区/版本问题，不是你操作错了 |
| 应用内搜索没结果 / 转圈 | ① 确认网络正常；② 升级到最新版（旧版常有兼容问题）；③ 如果你开了 VPN / 代理，先关掉再试 —— 代理可能干扰搜索；④ 换个关键词，部分受版权约束的内容在某些区域就是搜不到 |
| 首页推荐打不开 | 与搜索同理，先查网络与代理，再考虑升级版本 |

## 三、安装与启动类问题

| 现象 | 处理 |
| --- | --- |
| 安装被系统拦截 | 去 **设置 → 安全 / 隐私 → 安装未知应用** 给文件管理器或浏览器授权，详见 [下载与安装教程.md](下载与安装教程.md) 第三节 |
| 安装包打不开（解析错误） | 重新完整下载一次，下载中断会产生损坏的包 |
| 装完闪退 / 卡顿 | 设置 → 应用 → Snaptube → 存储 → **清除缓存**；仍异常就卸载后重装（重装不会丢你已经下载到本地的文件，它们在内部存储的 Snaptube 文件夹里） |
| 播放或下载位置不对 | 检查存储权限是否被系统回收（安卓会自动收回长期不用的权限），重新授予 |

## 四、文件与存储类问题

- **找不到下载的文件**：默认在内部存储的 **Snaptube 文件夹**；也可在应用的「我的文件」里直接查看，见 [视频与音乐下载方法.md](视频与音乐下载方法.md) 第四节。
- **文件误删**：设置 →「恢复已删除文件」里找回（以应用内实际界面为准）。
- **存储满了**：把保存路径改到 SD 卡（机型支持的话），或用设置里的清理功能清缓存；下载时选更低档位也能少占空间。

## 五、什么时候该升级、什么时候该重装

1. **先升级**：设置 → 关于 检查新版本。下载失败、搜索失效、闪退这三类问题里，相当一部分是旧版本与平台接口脱节造成的，升级是最先该试的一步；
2. **再清缓存**：升级无效 → 清除缓存；
3. **最后重装**：前两步都无效 → 卸载重装。重装前记下想要的文件（它们在 Snaptube 文件夹里，卸载应用不会删掉，但保险起见可以先备份到别处）。

升级用的新 APK 直接覆盖安装即可，不需要先卸载；拿包方式见 [下载与安装教程.md](下载与安装教程.md)。
