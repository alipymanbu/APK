## 一、装之前先确认这几件事

Snaptube 是安卓应用，只发 APK 安装包，不走应用商店的自动更新。装之前对一下：

| 项目 | 说明 |
| --- | --- |
| 系统 | 安卓。网盘里这份安装包标注需要安卓 5.2 以上；官方页面的口径是 Android 5.0+，以官方页面当时显示为准 |
| 安装权限 | 手机必须允许「安装未知来源应用」（见第三节，这是安卓对非商店安装的标准校验） |
| 存储空间 | 安装包本身约 30.19M，装完再留几百 MB 给下载的视频、音乐 |
| 账号 | 不需要注册登录就能用 |

顺带说明两个平台事实，避免你白找：

- **没有 iPhone 版**：官方确认 iOS 版已下架，目前只有安卓版。
- **没有官方电脑版**：官方不提供 Windows/Mac 客户端；网上说的「电脑版」都是让你先装安卓模拟器，那是另一套玩法，本篇不展开。

## 二、拿到安装包

网盘里存的安装包信息如下（以这份包为准，网上搜到的官方最新版常常不是同一版）：

| 字段 | 值 |
| --- | --- |
| 版本 | 7.63.1.76301301 |
| 包名 | com.snaptube.premium |
| 大小 | 30.19M |
| MD5 | A5CB3DD90AC4C41501F7CF56D5029A63 |

从 **Snaptube 安装文件资源（夸克网盘）** [https://pan.quark.cn/s/8547bf590d7b](https://pan.quark.cn/s/8547bf590d7b) 转存到你自己的网盘后，在手机上用夸克打开该文件夹，点 APK 文件选择下载（或下载到手机再用文件管理器点开）。

下载完成后可以核对一下 MD5 是否一致（用任意「MD5 校验」类工具打开文件查看），一致说明文件在传输过程中没有损坏。

另外几条拿包渠道的事实，供对照：

- **厂商应用商店**：官方页面列出 Xiaomi GetApps、OPPO 应用市场、vivo 应用商店、华为应用市场、荣耀应用市场等渠道上架过正版包；
- **Google Play 上没有**：因为谷歌政策不允许提供 YouTube 下载类应用，所以商店里搜不到，只能装 APK；
- 除网盘外的其他下载渠道质量参差不齐，装之前用上表的 MD5 核对一遍最稳妥。

## 三、安装步骤（关键在「未知来源」权限）

1. 在手机上点开下载好的 APK 文件；
2. 系统弹出「禁止安装来自此来源的应用」之类提示 —— 这是安卓对非商店安装的标准拦截，不代表包有问题；
3. 按提示进入 **设置 → 安全 / 隐私 → 安装未知应用**，给发起安装的那个应用（文件管理器或夸克）打开权限；部分机型路径是 **设置 → 安全 → 未知来源**；
4. 返回后继续点「安装」；
5. 装完首次启动时，按提示授予**存储权限** —— 没有它 Snaptube 无法把下载的文件写进手机存储；
6. 桌面找到黄色图标打开即可用。

**装完可以把「安装未知应用」权限关掉**，下次要装别的 APK 再开即可，平时关着更省心。

## 四、装不上 / 装完打不开，按这里查

| 现象 | 处理 |
| --- | --- |
| 一直提示「禁止安装」 | 第三节的权限没给到**真正发起安装的那个应用**，重新进设置确认开关是开的 |
| 提示「解析包时出现问题」 | 安装包下载不完整，重新下载一遍（网络中断最常导致这个） |
| 提示存储空间不足 | 先清理出几百 MB 再点安装；安装包本身 30.19M，但安装过程需要额外空间 |
| 装完一点就闪退 | 先清缓存：设置 → 应用 → Snaptube → 存储 → 清除缓存；仍闪退就卸载后按本篇步骤重装 |
| 手机报「发现病毒/风险」 | 商店外安装的 APK 都会触发这类提示；可先用 MD5 核对文件完整性，再决定是否继续 |

更细的下载、搜索类故障在 [常见问题与排查.md](常见问题与排查.md)。
