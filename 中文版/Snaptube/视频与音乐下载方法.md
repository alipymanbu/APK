## 一、三种下载入口，按场景选

你在不同场景下可以用不同的入口，结果是一样的，都是把文件存进手机：

| 入口 | 操作 | 适合场景 |
| --- | --- | --- |
| 分享转发 | 在 YouTube / Instagram / Facebook / WhatsApp 等应用里点「分享」→「更多」→ 选 Snaptube | 已经在别的 App 里刷到了想存的内容 |
| 粘贴链接 | 复制内容链接 → 打开 Snaptube，顶部搜索框会自动识别剪贴板里的链接 → 点下载按钮 | 链接在网页、聊天窗口里 |
| 应用内搜索 | 直接在 Snaptube 顶部搜索框输入关键词，或用首页按平台浏览 | 还没锁定具体哪一条，想找同主题内容 |

实际用下来「分享转发」最快：以 Instagram / Facebook 视频为例，在应用里点分享 → 更多 → Snaptube，就会直接弹出下载入口；WhatsApp 状态（Status）是先在 WhatsApp 里把状态看一遍，再打开 Snaptube 即可下载。

## 二、点下载之后：格式与清晰度怎么选

点下载按钮后会弹出格式选择窗，默认给几个常用项；不够就点「更多格式」看完整列表。选型可以这么定：

| 你的目的 | 选什么 |
| --- | --- |
| 只要听歌、省空间 | 音乐分类下的 MP3 或 M4A，码率选 128k 一般够用；对音质有要求再上 320k |
| 手机上看剧、刷视频 | MP4 720p / 1080p，清晰度与体积比较平衡 |
| 投电视、大屏看 | 源视频有多高就选多高（最高 4K），前提是原视频本身支持 |
| 流量紧张 | 视频选 360p 以下，或干脆只下音频 |

几条实用细节：

- **下载音乐直接选音频格式即可**，不用先把视频下下来再转，Snaptube 会在下载时只抓音频流；
- **字幕**：点下载 →「更多格式」→「字幕/CC」，选语言即可；源视频没有字幕时会显示「无字幕」；
- **播放列表批量下**：打开一个播放列表，点下载按钮可整批加入队列，不用一条条点；
- 每个格式选项旁会显示预估文件大小，选之前扫一眼就不会超存储预算。

完整的分辨率与码率清单见 [支持平台与格式说明.md](支持平台与格式说明.md)。

## 三、下载过程中的控制

- 下载在应用内有独立的下载管理页，可以看进度、**暂停 / 继续 / 取消**；
- 网络断了恢复后点重试，会**从断点续传**，不会从零开始；
- 下载可以退到后台进行，你切去聊微信、锁屏都不影响（锁屏后是否继续取决于你手机的省电策略，把 Snaptube 加进「后台不限制」名单更稳）；
- 想只在 Wi-Fi 下下载：进设置打开「仅 Wi-Fi 下载」，误点下载键也不会烧流量；反之要在流量下下载，需确认设置里「移动数据下载」开关是开着的。

## 四、文件存哪了、怎么管理

- 默认保存在手机内部存储的 **Snaptube 文件夹**，视频和音乐会分文件夹归类；
- 在 Snaptube 的「我的文件」里可以直接播放、分享、删除；用系统文件管理器或相册也能找到；
- 存储紧张时，可在设置里**把保存路径改到 SD 卡**（机型支持插卡的话）；
- 误删的文件可以尝试在 设置 →「恢复已删除文件」里找回；
- 设置里还有清理功能，能清掉缓存和不再需要的文件。

下载卡住、找不到按钮等问题，转到 [常见问题与排查.md](常见问题与排查.md)。
