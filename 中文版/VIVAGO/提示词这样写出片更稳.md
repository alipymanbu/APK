## 一、同一句话，为什么别人出片比你好

提示词决定出片上限。生成模型不认识「好看」「震撼」这类词，它只回应具体的画面信息：谁、在做什么、在哪里、什么风格、什么光线。描述越具体，结果越可控——这不是玄学，就是把信息喂够。

对比一下同一想法的两种写法：

| 弱描述 | 强描述 |
| --- | --- |
| 一只猫在跑步 | 一只橘猫在雨后的青石板小巷里奔跑，水花溅起，清晨薄雾，写实电影感 |
| 女生回头微笑，很美 | 一位穿红裙的长发女生在傍晚的海边回头微笑，夕阳逆光，发丝随风飘动 |
| 酷炫的城市 | 赛博朋克风格的未来城市夜景，霓虹灯反射在湿地面上，镜头缓缓推进 |

差距不在文笔，在于右边的句子每一条信息都能被画出来。

## 二、把一句话扩成一段话的骨架

写描述时按这六个槽位填，填满三四个就够用，全填更稳：

| 槽位 | 作用 | 常用写法示例 |
| --- | --- | --- |
| 主体 | 画面的主角 | 一只橘猫 / 穿校服的女孩 / 一杯冒着热气的咖啡 |
| 动作 | 主体在做什么 | 追蝴蝶 / 回头 / 热气盘旋上升 |
| 场景 | 事情发生的地方 | 雨后小巷 / 傍晚海边 / 深夜便利店门口 |
| 风格 | 整体画风 | 写实电影感 / 日系动漫 / 3D 卡通 / 水彩 |
| 光线氛围 | 决定情绪 | 夕阳逆光 / 霓虹夜景 / 清晨柔光 / 烛光 |
| 镜头 | 摄像机怎么动 | 缓缓推进 / 环绕主体 / 俯拍 / 跟随奔跑 |

镜头那一栏是视频特有的：**镜头词写得越明确，运镜越像你想象的**。常用词就那几个——推近（画面向前压）、拉远（主体变小露出环境）、环绕（绕主体一圈）、跟随（镜头跟着主体走）、俯拍与仰拍（视角高低）。

## 三、三种典型的坏提示词

出片离谱时回头检查，多半踩了这三种：

- **形容词堆砌**：「超级无敌震撼美丽的大片」——模型无从下手。把形容词换成能画出来的具体信息。
- **多主体打架**：一只猫、两个女孩、三辆车、还在下雨还在放烟花——元素超过两三个，画面必乱。一条视频聚焦一两个主体。
- **全是抽象概念**：「表现时间的流逝」「孤独的感觉」——先翻译成画面：枯叶从绿变黄落地、一个人坐在空荡的长椅上。

另外，描述里**强调你想要的**，比罗列你不想要的更有用；个别版本如有「负向提示词」输入框，才专门用来排除元素。

## 四、出片之后怎么迭代

一次到位是运气，迭代是常态。两个原则：

1. **一次只改一处**。不满意光线就只换光线，不满意运镜就只换镜头词，其余原样保留——这样你能明确知道哪个改动起了作用，不会越改越乱。
2. **先图后视频**。出图比出视频快得多：先用同一段描述出图确认画面方向，对了再拿去出视频，省下的等待时间非常可观。

## 五、接受随机性

同一段描述多次生成，结果每次都不一样，这是生成式模型的正常表现，不是操作错误。想要某个效果，常用的做法是同一描述多生成几次「抽卡」，从结果里挑最接近的，再按第四节的方法微调。生成排队慢或报错不属于提示词问题，排查见[生成卡住与失败怎么办.md](生成卡住与失败怎么办.md)。
