## 一、模板是最省事的出片方式

不想自己想提示词、调参数，就直接套模板：挑一个喜欢的效果，丢进一张照片或一段文字，其余交给它。据官方介绍，VIVAGO 提供数百个持续更新的热门特效模板（具体数量与更新频率以应用内为准），覆盖当下短视频平台容易火的那几类玩法。

模板和自由生成各适合什么：

| 场景 | 用哪种 |
| --- | --- |
| 蹭热点、追潮流玩法 | 模板 |
| 有明确画面想法 | 自由生成（文字或图片） |
| 零基础、第一次玩 | 模板 |
| 想要独一无二的画面 | 自由生成 |

## 二、套用模板的流程

以 2.0.4 版为参考（界面以你手机上为准）：

1. 首页进「模板」或「特效」类入口，按分类或热度浏览。
2. 点开感兴趣的模板，先看别人用这个模板出的成品示例，判断是不是你想要的效果。
3. 点「制作同款」或类似按钮，按要求上传照片（有的模板要正脸照，有的要全身照，按要求来成功率最高）。
4. 提交生成，等待出片，保存或分享。

两个提高成功率的细节：

- **按要求选图**。模板提示要「清晰的正面照」就别用侧脸、戴口罩的照片，人脸类模板对输入很挑剔。
- **一张照片一个模板**。想对比效果，同一张照片分别套两三个模板，比来回改一个模板快。

## 三、常见模板类型

从官方介绍看，模板大致分这几类（名称以应用内为准）：

- **形象变换**：把照片变成另一种画风或形象，如 3D 卡通、古风、科幻装扮。
- **情感互动**：拥抱、牵手一类的双人或单人情感向动效。
- **记忆修复**：老照片上色、清晰化，再让照片里的人动起来。
- **潮流手办**：把人像做成手办、潮玩质感的展示画面。

部分版本还提供口播类玩法（上传头像与声音生成口型同步的视频），有需要的在功能列表里找，以实际界面为准。

模板库随时上新、也会下架旧模板，你在别处教程里看到的模板名找不到属于正常现象。蹭节庆、热点类的模板要抓紧：热点过了模板就凉了，出片也就没了发布价值。

## 四、借社区的同款

VIVAGO 内有创作者社区：刷到别人发布的作品，多数模板类内容可以一键「做同款」。这比在模板库里翻更快——你先看到成品效果，再决定要不要做，出片预期更准。遇到喜欢的创作者也可以关注，跟进新的玩法。
