## 二、从网盘获取安装包

安装包放在夸克网盘里，按下面步骤取：

1. 打开 [VIVAGO 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cf6813fb2092) 的链接。
2. 选择文件后点「转存」，把它存到自己的网盘账号里（直接下载也可以，转存后文件长期有效，不怕原分享失效）。
3. 在网盘里找到这个 APK 文件，点「下载」到手机本地存储。

如果你习惯在电脑上操作，也可以先转存到网盘、在电脑端下载，再通过数据线或聊天工具传到手机。

## 三、安装步骤

1. 在手机文件管理器里找到刚下载的 APK（文件名类似 `VIVAGO_v2.0.4.apk`），点它。
2. 第一次安装时会弹「禁止安装未知来源应用」的提示，按提示允许你的文件管理器或浏览器「安装未知应用」，然后再回来点安装。常见品牌的设置入口（系统版本不同菜单名略有差异，最稳的办法是在系统设置里直接搜「未知」）：

   | 品牌 | 大致路径 |
   | --- | --- |
   | 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
   | 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
   | OPPO / 一加 / realme | 设置 → 安全 → 安装未知应用 |
   | vivo / iQOO | 设置 → 安全 → 更多安全设置 |
   | 三星 | 设置 → 应用 → 特殊权限 → 安装未知应用 |

3. 等待安装完成，点「打开」。应用图标会出现在桌面或应用列表里。

安装前建议确认手机剩余空间：安装包约 81 MB，加上运行缓存，预留 500 MB 以上比较稳妥。

## 四、首次启动注意

- **联网**：打开后应用需要联网加载资源，首次启动在弱网下可能停在加载页，换个网络环境重进即可。
- **权限**：生成或保存视频时会请求存储（保存作品）、通知等权限，按需允许即可；拒绝存储权限会导致作品存不到相册。
- **登录**：如启动后提示登录或注册，按界面指引操作；具体方式以你手上版本的界面为准。
- **校验安装包**（可选）：想确认文件没坏，可以在电脑上用命令核对 MD5 是否等于上表中的值：

```powershell
certutil -hashfile "VIVAGO_v2.0.4.apk" MD5
```

对不上就重新下载一遍，多半是传输中断导致的损坏。

## 五、装不上或装完打不开

按现象对号入座，详细排查在[生成卡住与失败怎么办.md](生成卡住与失败怎么办.md)里：

- 提示「解析包出错」：安装包没下完整，重新下载后核对 MD5。
- 提示空间不足：清理存储后再装。
- 装完闪退：先重启手机再试；仍闪退就卸载后重装一遍。
- 想换成官方最新版：先卸载旧版再装新版，避免版本混杂导致的数据异常。

装好后，可以先从[文字生成视频怎么用.md](文字生成视频怎么用.md)上手第一条视频，或者拿一张旧照片去[照片变成动态视频的方法.md](照片变成动态视频的方法.md)试试效果。
