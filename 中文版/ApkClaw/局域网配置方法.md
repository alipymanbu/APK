## 一、这个页面解决什么问题

API Key、Bot Token 这类凭据动辄一大串，在手机触屏上逐字敲既慢又容易错，错一位就要重来。ApkClaw 内置了一个局域网 HTTP 配置服务：手机和电脑连同一个 WiFi，用电脑浏览器打开它，就能在网页上把[模型配置](AI大模型配置教程.md)和[通道凭据](消息通道绑定方法.md)一次填对。

## 二、怎么打开

1. 手机连上 WiFi，确认电脑也连在**同一个** WiFi / 局域网下；
2. 手机上打开 ApkClaw → 设置，开启「局域网配置」（LAN Config）；
3. 在手机的 WiFi 详情页查到本机 IP（形如 `192.168.x.x`）；
4. 电脑浏览器访问 `http://<手机IP>:9527`，例如 `http://192.168.1.23:9527`，回车即出配置页。

## 三、页面上能改什么

| 地址 | 作用 |
| --- | --- |
| `/` | 配置网页本身，模型与通道都在这页填 |
| `/api/channels` | 读 / 改各通道凭据 |
| `/api/llm` | 读 / 改模型配置（Key、Base URL、模型名） |

两个实用细节：

- **读取时凭据是打码的**：通过接口读配置只显示后 4 位，不用担心凑近的人一眼看全；
- **调试版多一个控制台**：如果你装的是 debug 构建，页面还会多出 `/debug.html` 工具执行台，正式安装版没有属正常。

## 四、注意与收尾

- 这个服务**只在局域网内可达**，但同一 WiFi 下的其他设备也能访问它 —— 公共 WiFi 下建议别开，填完就关；
- 配置改完保存后回到 App 即可；不确定有没有写成功时，给通道发条测试消息验证一下。
- 打不开页面时，先核对手机 IP 有没有输错、两台设备是不是同一个网（访客网络常会隔离设备），再确认设置里的开关确实开着；其余「发消息没反应」的问题与这页无关，见[常见问题排查](常见问题排查.md)。
