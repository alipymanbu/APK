## 一、通道是干什么的

ApkClaw 装在闲置手机上，你人不在旁边，指令从哪进来？靠消息通道：你在钉钉 / 飞书 / QQ / Discord / Telegram 里给绑定的机器人发一句话，这句话就是一条任务，它执行完再把结果回到同一个会话里。所以「远程操控手机」的入口，就是你平时用的聊天工具。

## 二、支持哪些通道，各要什么凭据

在**设置 → 通道**里选一个通道，填上对应凭据（凭据在各平台的机器人 / 开放平台创建应用后获得，具体申请入口以各平台的开发者文档为准）：

| 通道 | 需要的凭据 | 适合谁 |
| --- | --- | --- |
| 钉钉 | Client ID + Client Secret | 已有钉钉账号，想在钉钉里下任务 |
| 飞书 | App ID + App Secret | 团队用飞书，想接进工作流 |
| QQ | App ID + App Secret | 个人日常用 QQ，配置较简单 |
| Discord | Bot Token | 有 Discord 账号，跨平台用 |
| Telegram | Bot Token | 有 Telegram 账号，Bot 申请最省事 |

只需要绑一个就能用；其余通道想换着用时，随时在设置里再加。

## 三、绑定的基本流程

1. 打开 ApkClaw → 设置 → 通道，选中你要用的通道；
2. 到该平台的机器人开放平台创建应用 / 机器人，拿到上表里的凭据；
3. 把凭据填进设置页（长串凭据建议用[局域网配置方法](局域网配置方法.md)在电脑上填）；
4. 保存后，在该平台里给这个机器人发一条测试消息 —— 手机有反应就说明通了。

发指令前记得先确认[大模型已配好](AI大模型配置教程.md)，否则消息进来了也跑不动。

## 四、发指令的几个实际约定

- **自然语言直接说**：「打开抖音搜索科技评测并关注第一个博主」这种整句就行，它自己拆步骤。
- **一次只跑一个任务**：它用任务锁保证同一时间只执行一条，上一条没结束前别连发催它。
- **它会先回桌面再开工**：每次接到任务会先按 Home 把屏幕重置到桌面，避免停在半截界面上执行错 —— 所以执行期间别手动玩这台手机。
- **结果回到原会话**：完成摘要、中途的异常截图都发回你发指令的那个会话。

## 五、微信里用（据公开报道）

有公开报道称（2026 年），ApkClaw 接入了微信官方 ClawBot 插件：安卓微信更新到 8.0.69 及以上，在「我 → 设置 → 插件」里找到 ClawBot 入口，扫码即可关联 ApkClaw，之后在微信里发消息（含语音）就能下发任务。此为单一来源说法，入口与版本要求**以微信内实际显示与官方页面为准**；没有该插件入口时，用上表任意一个通道即可，功能等价。
