## 一、ApkClaw 是什么

ApkClaw 是一款安卓端的 AI 智能体应用：你在聊天工具里发一句自然语言指令，它像人一样看屏幕、拆步骤、点界面，把签到、搜索、整理信息这类重复操作自动做完。它开源（Apache License 2.0），官方入口是 [apkclaw.ai](http://apkclaw.ai)，代码在 [github.com/apkclaw-team/ApkClaw](https://github.com/apkclaw-team/ApkClaw)。本篇只讲安装，装完后的模型配置与通道绑定见文末指路。

## 二、系统要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Android 9 及以上（官方给出的最低要求） |
| 截图能力 | 需要 Android 11 及以上，9 / 10 截不了图（见[常见问题排查](常见问题排查.md)） |
| 网络 | 手机需联网，模型调用与消息通道都走网络 |
| 机型 | 不限品牌，旧的闲置安卓机也能装 |
| 内存 / 存储 | 官方未公布具体数字；公开部署经验普遍建议 4GB 内存起、留出几 GB 空闲空间，装不上或闪退时先想到这条 |

本套文档对应的安装包信息（以本地保存的那份为准，官网可能已经出更新版）：

- 版本：0.0.1
- 包名：`com.android.apk.claw`
- 大小：30.46M

## 三、获取安装包并安装

1. 打开 [ApkClaw 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ed32ee691d47)，把 APK 转存到自己的网盘后下载到手机。
2. 手机上点开 APK 安装，若系统提示「禁止安装未知来源应用」，按提示允许本次安装（各品牌入口不同，一般在安装拦截页有「去允许」按钮）。
3. 装完先别急着发指令 —— 它的核心能力全靠无障碍服务，权限不开等于白装。

## 四、首次启动要开的权限

装完打开 ApkClaw，首页会列出待授权项，逐个点开开启：

| 权限 | 不开的后果 |
| --- | --- |
| 无障碍服务 | 完全不能操作界面，任何指令都执行不了 |
| 通知 | 收不到状态提醒 |
| 悬浮窗（显示在其他应用上层） | 悬浮按钮出不来，部分界面看不到运行状态 |
| 电池白名单（后台运行） | 手机一省电就把它杀了，远程指令收不到 |
| 文件访问 | 截图保存、传文件给你的通道会失败 |

其中电池白名单各家叫法不同（「电池优化」「不受限后台」「自启动」），在手机的设置里搜「电池」就能找到；这一步没做，闲置手机放一晚上就容易收不到消息，排查方法见[常见问题排查](常见问题排查.md)。

## 五、装完之后

权限开完，ApkClaw 还不能干活 —— 它需要一个大模型来思考，还需要一个聊天通道来接收你的指令。按顺序做两件事：

1. 去[AI大模型配置教程](AI大模型配置教程.md)填 API Key 与模型名；
2. 去[消息通道绑定方法](消息通道绑定方法.md)绑一个聊天工具，发第一条指令。
