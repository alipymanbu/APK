# Liaobots 在电脑上怎么用

> 网盘里这份 Liaobots 是安卓包，电脑装不了。本篇把电脑上的两条路——官方网页版与安卓模拟器——按「什么情况选哪条」讲清，并给出模拟器装包的具体步骤。
> **相关文档**：[下载与安装教程.md](下载与安装教程.md) · [聊天记录与本地存储.md](聊天记录与本地存储.md) · [常见问题与排查.md](常见问题与排查.md)

---

> [!IMPORTANT]
> **Liaobots 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/f58bcebbb65a](https://pan.quark.cn/s/f58bcebbb65a)

电脑上想接着用，先别急着装模拟器——大多数情况下浏览器更快。两条路的区别只在「要不要一个安卓环境」，选错方向会多绕不少弯路。

## 一、先选一条路

| | 官方网页版 | 安卓模拟器 |
| --- | --- | --- |
| 要装什么 | 什么都不用装，浏览器打开 | 先装模拟器，再装 APK |
| 上手速度 | 立刻能用 | 装完模拟器 + 配好环境才用得上 |
| 界面 | 网页版自己的界面 | 和手机上一模一样的界面 |
| 适合谁 | 只想在电脑上问问题、写东西 | 想在电脑上看到跟手机完全一致的操作方式 |
| 主要代价 | 界面与手机版不同，部分功能位置要对一遍 | 吃内存与磁盘，老电脑跑不顺 |

**结论一句话**：目的是「在电脑上用起来」→ 走网页版；目的是「在电脑上看手机版界面」→ 才装模拟器。

## 二、走官方网页版

1. 用浏览器打开官方主站 [liaobots.work](https://liaobots.work/)；
2. 站点入口会变，打不开时改用官方导航页上列出的其他线路（同一套服务的不同入口）；
3. 进去之后的操作逻辑和手机版一致：先选模型，再在底部输入框提问。

两点提醒：

- **网页版没有安装包这回事**，所以网盘里那份 APK 跟这条路无关，别把两者混在一起排查；
- **网页版与手机版的记录是否互通，取决于你有没有用同一个账号登录**，规则与 [聊天记录与本地存储.md](聊天记录与本地存储.md) 第二节讲的是同一件事。

## 三、用安卓模拟器装这份包

适合必须在电脑上看到手机版界面的场景。步骤：

1. **装一个安卓模拟器**：选支持安卓 5.x 及以上系统版本的模拟器，装完后按提示创建一个安卓实例；
2. **确认模拟器的系统版本**：网盘这份包的登记适用系统是「安卓系统 5.2 以上」，实例的系统版本别低于这个量级；
3. **把 APK 放进模拟器**：用模拟器的「安装 APK」入口直接选文件，或把包拖进模拟器窗口；
4. **取包**：[Liaobots 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f58bcebbb65a) 里那份就是，先在电脑浏览器里转存下载到本地；
5. **安装与首次打开**：安装提示与手机上一模一样，权限相关处理见 [下载与安装教程.md](下载与安装教程.md) 第三节；
6. **进去之后调网络**：模拟器默认走电脑的网络，电脑能上网它就能用；连不上时先看电脑本身的网络，再看模拟器的网络设置。

模拟器上的常见卡点：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 包没下完整 | 核对体积约 3.43 MB，重新取一份 |
| 提示系统版本过低 | 模拟器实例的安卓版本太高或太低，与包不匹配 | 换一个合适的安卓版实例重建 |
| 装进去打不开、闪退 | 模拟器缺少依赖组件或实例内存给得太小 | 调大实例内存，或换一个模拟器重试 |
| 能开但发不出消息 | 电脑网络不通，或模拟器被限制了联网 | 先在模拟器里用浏览器确认能上网 |
| 电脑风扇狂转 | 模拟器本身开销大 | 不常用的话，改用网页版 |

## 四、两条路都别忘了这一件事

**跨端接着聊的前提是「同一个账号 + 同步已打开」。** 默认状态下记录只留在产生它的那台设备上：电脑上聊的内容想在手机上看，两边得登录同一个账号并开启同步；没开同步时，各端各记各的。具体怎么开、导出怎么留底，见 [聊天记录与本地存储.md](聊天记录与本地存储.md)。

两边用的账号是否共用、积分怎么算，以官方页面与应用内的说明为准——这类规则会调整，不要按第三方页面上的说法操作。
