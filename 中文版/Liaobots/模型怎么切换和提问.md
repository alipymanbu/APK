# Liaobots 模型怎么切换并提问

> 本篇讲 Liaobots 里模型在哪切、提问怎么发、每次对话的积分是怎么算的，以及什么情况下该打开联网搜索。

进到 Liaobots 的对话页，能看到它就一个聊天界面：当前用哪个模型写在这一页的顶部，提问写在底部。整篇只回答三个问题——模型怎么换、话怎么发不浪费积分、什么时候该联网。界面上的入口名称可能随版本微调，以应用内当时显示为准。

## 一、进入对话界面

1. 打开应用，首页中间有一个「点击进入」按钮，点它进到对话页；
2. 进到对话页后，**顶部中间显示的是当前模型名**，底部是输入框，中间是消息流；
3. 直接开始打字就行——这一步不需要注册账号，聊天记录默认也只留在本机（见 [聊天记录与本地存储.md](聊天记录与本地存储.md) 第一节）。

## 二、模型怎么换

**入口是顶部中间那一行模型名**：点一下会弹出模型列表，在列表里点另一个模型即完成切换，当前会话立刻改用新模型回话。

换模型时值得注意的几点：

| 关注点 | 说明 |
| --- | --- |
| 切换只对新消息生效 | 已经聊过的内容不会重算，同一个会话里可以前面用 A 模型、后面换 B 模型 |
| 不同模型单价不同 | 同样的长度，旗舰模型和轻量模型的积分消耗能差出数倍，换之前先看单价 |
| 能力侧重不同 | 需要长文档理解、推理、联网的，选支持这些能力的模型；只是日常问答用轻量款更省 |
| 可选清单会变 | 应用内的模型清单会随官方上下架调整，以列表里当时显示的为准 |

模型清单覆盖国内外常见的大模型系列（如 GPT、Claude、Gemini、Grok、DeepSeek 等），具体有几款、叫什么名字、各是什么单价，以你打开列表时看到的为准——这份清单与价格会随官方调整变动，不宜记死。

## 三、按任务挑模型

挑不准的时候按这张表对号入座，比在列表里逐个试快：

| 你要做的事 | 怎么挑 | 为什么 |
| --- | --- | --- |
| 翻译、改写、日常问答 | 挑便宜的轻量款即可 | 这类任务对模型能力要求低，多花的积分换不来更好的结果 |
| 长合同、长文档里找要点 | 挑标注长上下文的型号 | 上下文短的模型塞不进整篇材料，只能靠你切段贴 |
| 数学、逻辑、复杂推理 | 挑带思考/推理档位的型号 | 普通模式在推理题上容易漏步骤 |
| 要查刚发生的事 | 挑支持联网的型号，并打开联网开关 | 模型自带的知识停在训练时间点 |
| 生成图片 | 挑标注支持生图的型号 | 不是所有模型都能出图，选错会直接报不支持 |

**一个判断技巧**：同一条问题先发给轻量款，答得能用了就别换；只有在明显答偏、答漏的情况下才切旗舰款，积分花在真需要的那几次上。

## 四、怎么提问更省积分

积分按对话长度计，不同模型有各自的标准，所以「省」的关键不是少说话，而是别让上下文无谓地变长。

- **发送前会显示本次预估消耗。** 输入框附近会给出这条消息预计扣多少积分；**如果不显示，说明这次消耗小于 0.01 积分**，属于可忽略的量级。
- **长会话比新会话贵。** 同一个会话里越往后聊，附带的历史上下文越多，单条消息的消耗通常会随之上升；一个话题聊完就新开一个会话，比在一个会话里连轴转更省。
- **别把大段材料反复贴。** 同一份文件需要多次提问时，贴在一条消息里问清楚，比分开几轮各贴一遍省得多。
- **先想好再发。** 消息发出去就是一次消耗，改口重发等于付两次。
- **积分不够时按应用内提示处理。** 充值入口、面额与到账方式都以应用内当时显示与官方页面为准，别按第三方页面上的说法操作。

## 五、联网搜索什么时候开

应用里带联网搜索的开关，开了之后模型能去取实时信息；不开则只靠模型自身已有的知识回话。

- **该开**：问新闻、股价、赛事结果、某个软件的最新版本、刚发布的产品参数这类「答案会随时间变」的问题。
- **不必开**：写文案、翻句子、解释概念、改代码这类不依赖当下信息的问题，开了只是白花一份联网的消耗。
- **开了还是答错**：联网只保证模型能拿到网页，不保证它一定引用对了。涉及关键数字与条款时，点开它给出的链接自己核一遍。

## 六、发不出去时先看这几处

| 现象 | 先检查 | 下一步 |
| --- | --- | --- |
| 输入框发出去没反应 | 手机是否真的联网（切一次 Wi-Fi / 移动数据试试） | 换网络后仍无反应，见 [常见问题与排查.md](常见问题与排查.md) |
| 当前模型报错或不可用 | 换一个模型再发同一句话 | 换模型正常，说明是那个模型侧的问题，稍后再试 |
| 回复中途断掉 | 是否切了后台或锁屏 | 重新发一次；反复断见 [常见问题与排查.md](常见问题与排查.md) |
| 提示额度/积分不足 | 看当前模型的单价与剩余积分 | 按应用内提示处理，或先换轻量模型继续用 |

想让角色带固定人设再聊，做法见 [智能体与角色怎么用.md](智能体与角色怎么用.md)。
