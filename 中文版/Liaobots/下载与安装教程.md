Liaobots 是一款手机端的 AI 对话工具，把多个大模型收在同一个聊天界面里，切换模型不用换应用；它也带智能体玩法，可以按喜好设定角色的身份与性格。本篇只做一件事：把网盘里这份安卓包装进手机并正常问出第一句话。

## 一、先确认网盘里这份包是哪一版

应用商店与下载站上挂的是官方当时的最新版，跟网盘里这份未必是同一个版本号。本篇出现的版本号、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Liaobots |
| 版本号 | 1.0 |
| 包名 | `com.liaobots.work` |
| 安装包体积 | 3.43 MB |
| MD5 | `09A565D8D448C46B0519B953C3DE5E40` |
| 适用平台 | Android（手机端 APK） |
| 登记的适用系统 | 需要支持安卓系统 5.2 以上 |

装之前先弄清三件事：

- **认包名，别只认图标和名字。** 搜「Liaobots」会出来若干同名或近名条目，装错的话应用内的数据互相不认。装好后进「设置 → 应用 → 应用管理」点进 Liaobots，在应用信息页核对包名是否与上表一致（以系统显示为准）。
- **体积小是正常的。** 这份包只有 3.43 MB，只是客户端本身；对话内容都在联网后由服务端返回，所以安装包小不代表功能被删。
- **最低系统版本以真机为准。** 登记信息写的是「需要支持安卓系统 5.2 以上」，按安卓 5.x 级别理解即可；能不能装以安装时的系统提示为准。

网盘这份是安卓 APK，iPhone 装不了。想在电脑上用，先看 [在电脑上怎么用.md](在电脑上怎么用.md)，再决定是走网页版还是装模拟器。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [Liaobots 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f58bcebbb65a)，在手机夸克 App 里打开最省事。
2. **先转存再下载**：选中安装包，转存到自己的网盘目录，再下载到本机。分享链接以后可能失效，转存过的那份不受影响。
3. **核对体积**：下载完成后看一眼文件体积，应当约 3.43 MB。中途断网重连导致文件偏小，安装时会直接报「解析包错误」。
4. **想校验完整性**：在电脑上把包算一遍 MD5，结果应与上表一致（大小写不敏感）。

```cmd
certutil -hashfile Liaobots_v1.0.apk MD5
```

文件名随版本变化，以实际拿到的那个为准。

## 三、安装步骤

1. **给文件管理器开「安装未知应用」权限**：进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把用来打开 APK 的那个应用（文件管理器或浏览器）的开关打开。国产定制系统这项常收在「安全」或「隐私」分类下。
2. **点击 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续，这是侧载安装包的常规提示。
3. **手机上已有更高版本时先卸载**：安卓不允许用低版本覆盖高版本，会直接报「应用未安装」。卸载会一并清掉本机数据，动手前确认对话记录是否还要留。
4. **报「签名不一致」说明包名撞了**：手机里已装过同包名、另一个来源的版本，处理办法见本篇第五节的表。
5. **留出安装空间**：安装过程中系统还要展开一份文件，建议预留 200 MB 以上可用空间。

## 四、第一次打开要确认的三件事

1. **有网络**：模型回复全部来自服务端，应用本身不能离线对话。打开后一直停在加载状态，就先用浏览器确认手机能正常上网。
2. **走完首页的进入动作**：应用打开后停在中间带「点击进入」的首页，点进去才到对话界面。进去之后顶部中间显示当前模型名，底部是输入框，界面构成见 [模型怎么切换和提问.md](模型怎么切换和提问.md)。
3. **能发出一句并收到回复**：在输入框敲一句「你好」发出去，正常收到回复就算装好了。这一步不需要注册账号；想换模型、想知道每次对话扣多少积分，接着看 [模型怎么切换和提问.md](模型怎么切换和提问.md)。

## 五、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整 | 核对体积与 MD5，按第二节重新取一份 |
| 提示「应用未安装：签名不一致」 | 手机里已有同包名、不同来源的版本 | 先在应用管理里卸载旧包，再装这份 |
| 安装被安全中心拦下 | 侧载包被系统安全策略拦了 | 在安全中心的拦截记录里选「继续安装」 |
| 点安装没反应 | 「安装未知应用」权限没给 | 回到第三节第 1 步补上权限 |
| 装完打开就闪退 | 系统版本过低、存储不足或包残缺 | 见 [常见问题与排查.md](常见问题与排查.md) |

装好之后如果第一句话就发不出去，先别怀疑安装包——那多半是网络或模型侧的问题，同样在 [常见问题与排查.md](常见问题与排查.md) 里排。
