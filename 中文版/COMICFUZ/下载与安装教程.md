COMIC FUZ 是日本芳文社做的日文漫画应用，2019 年 3 月上线，收录《まんがタイムきらら》系列与《週刊漫画TIMES》等杂志的连载，以及只在这家平台上连载的原创作品。界面与漫画正文都是日文。这篇只管「把它装进手机」这一件事。

## 一、先核对网盘里是哪一版

网上搜到的版本号是官方最新发布版，网盘里这份是做文档时核对过的那一版，两者不一定相同。本文出现的版本、包名、体积，一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 版本号 | 2.33.0 |
| 包名 | `com.comic_fuz` |
| 安装包体积 | 10.01 MB |
| MD5 | `02FCE508AC6D0F118A8D3B4022237CD4` |
| 核对日期 | 2026-09-24 |

核对办法很简单：把下载好的 APK 放到电脑上，用任意一个能算哈希的小工具算一遍 MD5，与上表对一下。值一致，说明文件完整、和你手里这份是同一个；对不上就是下载中断了，重新下一遍。手机上也可以装一个带校验功能的文件管理器来核对。

## 二、装之前要确认的三件事

**第一，这是安卓包。** 网盘里给的是 APK，只能在安卓手机、平板上装；iPhone 与 iPad 用不了，iOS 版本得去苹果应用商店的日本区找，渠道不同、版本号也不会一致。

**第二，系统版本别照字面理解。** 这份包被标注为「需要支持安卓系统 5.2 以上」，而安卓并没有 5.2 这一档公开版本号——这类标注多来自打包工具的编译口径，当个参考就好。真正判断能不能用的办法是装上试：安装时弹「应用未安装」「解析包错误」，或装完一打开就闪退、停在启动页，多半是手机系统太旧。

**第三，先卸掉签名不同的旧版。** 如果手机里已经装过包名为 `com.comic_fuz`、但来源不一样的版本，直接覆盖安装会失败。先把旧的干净卸载，再装这份。

## 三、安装步骤

1. 从 [COMIC FUZ 安装文件资源（夸克网盘）](https://pan.quark.cn/s/22ede0a2de34) 进入分享页，选中其中的文件夹点「转存」，把它存进你自己的夸克网盘；
2. 在手机上打开夸克网盘 App，找到刚转存的那份，进入 `COMICFUZ（先保存再下载）` 文件夹，点 `COMICFUZ_v2.33.0.apk` 下载到手机本地；
3. 打开「设置 → 应用 → 特殊应用权限 → 安装未知应用」，给用来点开安装包的那个应用（文件管理器或浏览器）打开开关。不打开这个开关，点安装包不会有任何反应；
4. 从文件管理器里点开 APK，跟随系统提示走完安装。国产手机会中途弹「安全检测」「外部来源应用」之类的提醒，选继续即可，别在此时返回。

如果中途卡在某一环，对照下一节。

## 四、装不上时的对照表

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | 下载不完整，APK 被截断 | 清掉残缺文件，重新下载，并按第一节核对 MD5 |
| 「应用未安装」/ 安装直接失败 | 手机里已有同包名、来源不同的旧版 | 先把旧版卸载干净再装 |
| 点安装包毫无反应 | 没给当前应用「安装未知应用」权限 | 回到第三节第 3 步补上权限 |
| 安装按钮灰色点不动 | 系统的「纯净模式」类开关拦着 | 关掉该开关，或换文件管理器再试 |
| 装完桌面没有图标 | 桌面缓存没刷新 | 重启手机再看 |

## 五、第一次打开要先做三件事

**先联网。** 首页、作品列表、漫画正文都是实时从服务器拉的，断网打开只会一直停在加载状态。

**再决定要不要注册账号。** 不注册也能先翻一翻，但阅读进度、看广告或做任务拿到的奖牌、收藏夹全都挂在账号上，换手机或卸载重装就找不回来。只要打算长期看，建议早点注册——入口在应用右下角的「マイページ」（我的页面），具体走法见 [注册登录与换机迁移.md](注册登录与换机迁移.md)。

**顺手把安装奖励领了。** 官方对安装官方应用的账号有奖牌赠送（登录页写的是「最大 600 Silver メダル」这类说法），装好后留意应用内的活动或通知提示，标准的领取入口与能领多少以应用内当时显示为准。

## 六、装完做一次最小验证

1. 在首页或搜索框里搜一部作品，比如 `ゆるキャン△`；
2. 从结果里点开作品页，再点开第 1 话；
3. 能正常出图，说明安装没问题。

如果一直转圈、白屏或提示加载失败，按 [闪退打不开怎么排查.md](闪退打不开怎么排查.md) 里的现象分类排一遍。要是只有某一部作品点开有问题、换一部就正常，那多半是那部作品当时的资源问题，不必怀疑安装包。装好后想弄清一话要花多少、免费的部分在哪，接着看 [奖牌怎么获得与怎么用.md](奖牌怎么获得与怎么用.md)。
