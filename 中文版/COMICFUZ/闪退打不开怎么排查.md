# COMIC FUZ 闪退打不开怎么排查

出问题时最先要做的不是重装，而是分清卡在哪一层：应用根本没打开、打开了但登不上、登上去了但正文出不来、还是付费状态不对。这几类的成因完全不同，混在一起试只会浪费时间。本篇按这个顺序分头排查。

## 一、先花一分钟定位

| 你看到的 | 大概率的原因 | 跳到哪一节 |
| --- | --- | --- |
| 应用点不开、闪退、停在启动页 | 系统版本或安装包问题 | 第二节 |
| 能打开，但登录报错 | 账号或网络 | 第三节 |
| 登录正常，作品页能开，正文一直转圈或白屏 | 网络、存储、单部作品资源 | 第四节 |
| 提示要奖牌 / 订阅后还是看不了 | 消耗机制或订阅状态 | 第五节 |
| 更新了但不提醒 | 系统通知权限 | 第六节 |
| 手机空间被撑满 | 本地数据 | 第七节 |

## 二、打不开、卡在启动页

按这个顺序排：

1. **先重启一次手机**再打开应用——启动阶段的偶发失败多数这一步就没了；
2. **确认系统版本**。这份包被标注为「需要支持安卓系统 5.2 以上」，这个数字来自打包口径、不能当精确门槛；真正的现象是安装时报「应用未安装」「解析包错误」，或装完一打开就闪退。出现这两种，基本就是系统太旧，换台新一些的设备再试（安装相关的完整对照表见 [下载与安装教程.md](下载与安装教程.md)）；
3. **确认包是完整的**。把 APK 算一遍 MD5，和 [下载与安装教程.md](下载与安装教程.md) 里那张表对一下，对不上就重新下一遍——下载中断的包经常表现为「装得上但一开就崩」；
4. **卸掉同包名的旧版重装**。手机里若同时存在来源不同的 `com.comic_fuz`，会互相干扰，卸载干净再装；
5. 以上都做过还是打不开，把应用完全卸载、重启手机后再装一次。

## 三、登录不上

- **先确认邮箱与密码**：密码区分大小写，检查输入法有没有把符号打成全角；邮箱别把注册时用的那个记混；
- **换网络试一次**：这家平台在日本，跨境链路不稳时登录握手容易超时，从移动数据换到 Wi-Fi（或反过来）常常直接就好；
- **判断是不是账号问题**：同一账号若在网页版 `https://comic-fuz.com/` 能登进去，说明密码没错，问题在手机这条链路上；
- **确认没开代理类工具**：部分代理会让请求落到异常出口，导致登录反复失败，先关掉再试；
- 排完仍不行，在应用内找咨询 / 客服入口提交，写清注册邮箱与大致注册时间。账号相关的完整说明在 [注册登录与换机迁移.md](注册登录与换机迁移.md)。

## 四、作品页能开、正文出不来

漫画正文是逐页拉取的图片，所以这类问题几乎都出在「网络」或「资源」上：

1. **只在某一部作品上出现** → 多半是那部作品当时的资源问题。换一部作品验证一下；确认是单部作品，就过一段时间再看，不用折腾手机；
2. **所有作品都一样** → 先检查网络：换 Wi-Fi、关掉省流量模式（省流量模式可能拦截大图请求）、确认手机剩余存储空间足够；
3. **清了应用缓存再试**（不是清数据，清数据会连带清掉本地登录状态）；
4. **用网页版对照**：在电脑浏览器打开同一部作品同一话。网页版正常，问题就在手机端的网络或本地状态上。

顺带说明一种「看起来像故障、其实是设计」的情况：**话数上标着需要的奖牌，点开会提示你先获取奖牌**，这不是坏了，是那话要消耗。哪几话免费、哪几话要花、花哪种颜色，都在 [奖牌怎么获得与怎么用.md](奖牌怎么获得与怎么用.md) 里。

## 五、付费与订阅对不对

- **订阅了但状态没变**：订阅由 App Store 或 Google Play 托管，付款后回到应用里，状态有时需要重开一次应用才刷新；重开还不生效，就去商店的订阅列表确认这笔订阅是不是真的生效了；
- **提示无法完成购买**：应用商店按账号所属地区决定能买什么。真碰上「搜不到」或「购买无法完成」，那是商店的地区与支付判定在生效，不是应用故障——换一个符合该服务地区的商店账号，或在原账号里补全支付方式，是常规处理方向；
- **退订后还提示订阅中**：取消自动续订不会立刻失效，当期剩余时间仍然有效，到期才停止，这是正常的；
- **没想买却被扣了钱**：有用户在评论区反馈，购买金牌这类内购点一下就直接成交，误触也会扣款。所以**读的时候别乱点带价格的按钮**，尤其在话数列表里翻页时。真误购了，先走商店的退款渠道（App Store / Google Play 各自的「购买记录 → 报告问题 / 申请退款」），不要先去卸载应用；
- **想彻底停掉**：退订路径在 [订阅怎么退订与费用说明.md](订阅怎么退订与费用说明.md) 里逐条写了。**只卸载应用并不会取消订阅**，这一点要特别注意。

## 六、更新了却不提醒

按顺序查：

1. **系统层权限**：手机设置里给 COMIC FUZ 打开通知权限；
2. **省电与后台限制**：国产系统的「电池优化」「后台智能省电」会掐掉推送，把应用加入「不受限」名单；
3. **应用内的开关**：确认要追的作品已加收藏，且更新通知是开着的（做法见 [作品怎么找与更新怎么看.md](作品怎么找与更新怎么看.md)）；
4. **只是延迟**：推送慢几分钟到几十分钟都算正常，不是故障。

## 七、空间被撑满怎么办

**存储增长来自阅读过程**：读过的作品会在手机上留下本地数据（图片缓存一类），读得越多、追的作品越多，占的空间越大。有用户反馈过，读过之后除了卸载重装，找不到按作品或整片删除本地数据的地方；也有人反馈占用增长偏快。这些是单一来源的用户反馈，不代表所有版本都如此——先在应用设置里找一遍与缓存 / 存储相关的项。

找不到清理入口时，按代价从小到大处理：

| 做法 | 清掉什么 | 会丢什么 |
| --- | --- | --- |
| 系统设置里清应用**缓存** | 图片缓存 | 一般只丢缓存；个别系统会连带清掉登录态 |
| 清应用**数据**（不是缓存） | 缓存 ＋ 本地登录状态 | 需要重新登录；未登录时读的进度会丢 |
| 卸载重装 | 全部本地数据 | 同上，且要重新走一遍安装 |

建议顺序：**先把系统设置里那一项「清除缓存」试掉**（只清缓存、不动数据的那一项）。清完打开常看的作品确认还能正常出图；如果被连带登出了，重新登录即可——奖牌和订阅都挂在账号上，不会因为清缓存而消失（见 [注册登录与换机迁移.md](注册登录与换机迁移.md)）。能在大屏上看的就切网页版，网页版的缓存由浏览器管理、可以单独清。

## 八、都排完了还是不行

写清楚这三样再去联系官方支持，能省掉几轮往返：

- **你的设备与系统版本**（比如安卓多少、机型）；
- **具体现象与出现时间**（哪个页面、点了什么、报什么提示）；
- **你的注册邮箱**（涉及账号与订阅时必给）。

咨询入口在应用内的客服 / 咨询页面，网页版里也有对应入口。不要只写「用不了」三个字——这类工单基本都会被退回要求补充信息。
