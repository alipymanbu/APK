## 一、播放页手势速查

进入全屏播放后，这些手势都直接可用：

| 手势 | 作用 |
| --- | --- |
| 左侧上下滑 | 调亮度 |
| 右侧上下滑 | 调音量 |
| 水平滑 | 快进 / 快退 |
| 双击左侧 / 右侧 | 快退 / 快进 |
| 双击中间 | 播放 / 暂停 |
| 上滑全屏、下滑退出全屏 | 竖屏与全屏之间切换 |
| 长按屏幕 | 临时 2 倍速（松手恢复） |
| 点弹幕（移动端） | 弹幕悬停，可直接点赞、复制、举报这条弹幕 |

长按 2 倍速是很多人用顺之后回不去官方客户端的一个功能：UP 主语速慢的段落按住屏幕就加速，松开恢复，不用进菜单调倍速。

## 二、画质、音质、解码三项在哪调

播放页右上角进设置面板（全屏状态下点齿轮），有三项和画面直接相关：

1. **画质**：跟着视频本身和你的账号权限走 —— 部分高画质档位需要 B 站账号的大会员，客户端侧无法改变这一点。
2. **音质**：视视频而定，有 Hi-Res 档位的视频才出现选项。
3. **解码格式**：一般保持默认（硬解）即可。遇到画面发绿、花屏、拖影这类渲染异常，把解码从硬解切到软解通常立刻好转，代价是耗电略增。

画质和音质还能在「设置 → 播放设置」里设为**预设**，之后每个视频默认就用你选的档位，不用每次手动切。想在电视大屏上看，画质由投屏选档决定，步骤见 [投屏与电视观看.md](投屏与电视观看.md)。

## 三、值得先改的几个默认设置

下面这几项不是必须改，但改过之后体验差异明显：

- **全屏方向**：横屏视频可以自动转全屏，也可以设为手动控制方向，按自己习惯选。
- **记忆播放**：开了之后视频会从上次退出的位置继续；想每次都从头看就关掉它。
- **视频比例**：高度适应 / 宽度适应 / 填充 / 包含几档，全面屏手机看 16:9 老视频时「宽度适应」能消掉两侧黑边。
- **高帧率**：机型支持时打开，滑动进度条和弹幕滚动会更顺。
- **高能进度条**：进度条上标出互动高峰的段落，长视频找精彩部分直接跳标记处。
- **滑动预览缩略图**：拖动进度条时画面上方跟着显示对应时间点的缩略图，拖准确了再松手。
- **震动反馈**：手势操作时轻微震动，觉得烦可以关。

## 四、超分辨率与 SponsorBlock

两个进阶功能都藏在播放设置里：

- **超分辨率**：对低清晰度视频做实时放大处理，老视频、低清投稿看着会舒服一些。它吃性能，中低端机型开了可能掉帧，卡就关。
- **SponsorBlock**：社区维护的「跳过片段」数据，能在播放到 UP 主恰饭、转场、片头片尾等段落时自动跳过。国内视频的覆盖密度不如 YouTube，遇到标注多的 UP 主才有感；不想要自动跳转的话保持关闭即可。

另外「跳过番剧片头 / 片尾」是独立开关（默认跳过一次），追番党建议开着。

## 五、倍速、播放顺序与听视频

- **倍速**：0.5 到 3.0 之间选，配合长按临时 2 倍速基本够用；倍速选择可以在设置里自定义常用的几档。
- **播放顺序**：列表类内容支持「播放全部 / 继续播放 / 倒序播放」，教程合集倒着看复习很好用。
- **听视频**：锁屏当播客听，也支持定时关闭和 SponsorBlock 跳过，通勤场景适合。

## 六、播放卡顿先调什么

卡顿按这个顺序排查，多数在前两步就能解决：

1. 切软解（见第二节第 3 条）—— 排除硬解兼容问题。
2. 关超分辨率、关高帧率 —— 排除性能不够。
3. 画质降一档 —— 排除带宽不足（卡顿伴随画质糊、进度条走画面不走就是带宽问题）。

都不行的话看 [常见问题与故障排除.md](常见问题与故障排除.md) 的播放一节。弹幕密度太高造成的卡顿属于另一类，去 [弹幕设置与字幕调节.md](弹幕设置与字幕调节.md) 调弹幕屏蔽与合并。
