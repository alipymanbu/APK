## 一、安装类问题

**Q：提示「应用未安装」怎么办？**
按顺序查三点：① 手机上是否已有不同签名的旧版本 —— 卸载后重装；② 存储是否够 —— 至少留 200M；③ 系统版本是否过低 —— 需 Android 7.0 以上。展开的步骤在 [下载与安装教程.md](下载与安装教程.md) 第四节。

**Q：能不能和哔哩哔哩官方客户端同时装？**
能。PiliPlus 包名是 `com.example.piliplus`，与官方客户端不冲突，两者共存互不影响，收藏、历史等数据都从同一个 B 站账号同步。

**Q：装完打不开、闪退？**
先重启手机试一次；仍闪退的话，确认下载的 APK 完整（对比 MD5，见下载篇的版本信息表）；再不行清一次应用数据。个别机型闪退与系统 WebView 或厂商定制系统有关，去项目 GitHub 的 Issues 区搜机型关键词。

## 二、登录类问题

**Q：登录时验证码图片显示不出来？**
换网络环境再试（开 / 关代理都试一次）；仍然不行就改用扫码登录，用官方 App 扫码绕开验证码环节。

**Q：登录成功过几天又变回未登录？**
Cookie 失效或应用数据被手机清理工具清掉了。重新登录一次，并把 PiliPlus 加入清理工具的白名单，详细说明见 [登录与账号管理.md](登录与账号管理.md) 第五节。

**Q：在第三方客户端登录安全吗？会不会盗号？**
扫码登录全程不经过密码；密码登录走的是 B 站官方登录接口。项目代码开源（GPL-3，仓库 `https://github.com/bggRGjQaUbCoE/PiliPlus`），不放心可以自行审阅。账号风险与项目存续的两面事实在 [登录与账号管理.md](登录与账号管理.md) 第六节有完整讨论。

## 三、播放类问题

**Q：播放卡顿 / 掉帧？**
按三步排查：切软解 → 关超分辨率和 / 或高帧率 → 画质降一档。具体入口在 [播放设置与手势操作.md](播放设置与手势操作.md) 第六节。仍卡顿的低端机型，试试关闭弹幕确认是否为弹幕渲染压力。

**Q：画面发绿、花屏、颜色异常？**
典型的硬解兼容问题，播放设置里把解码格式从硬解切到软解即恢复。

**Q：某些视频提示无法播放？**
会员视频需要对应的大会员账号；付费内容、地区限制内容第三方客户端与官方端规则一致，客户端侧无解。

**Q：投屏列表里搜不到电视 / 投屏卡顿？**
先查「同一局域网 + 电视端 DLNA 开关」，再查路由器 AP 隔离；卡顿优先让手机连 5GHz Wi-Fi。完整排查顺序见 [投屏与电视观看.md](投屏与电视观看.md)。

## 四、弹幕与其他问题

**Q：弹幕完全不显示？**
先查弹幕总开关，再查是否开了「无痕 / 游客」以外的过滤项：屏蔽词列表里是不是误加过宽的规则（比如空格或正则写错会把全部弹幕屏蔽掉）。设置方法见 [弹幕设置与字幕调节.md](弹幕设置与字幕调节.md)。

**Q：怎么更新到新版？**
应用内没有应用商店通道，更新 = 下载新 APK 覆盖安装：从项目 GitHub Releases 或 [PiliPlus 安装文件资源（夸克网盘）](https://pan.quark.cn/s/26b111c3bf54) 拿新版，直接安装，数据不会丢。频繁遇到「某功能坏了」的话先更新再排查 —— 这个项目迭代快，很多问题在新版里已经修掉。

**Q：项目会不会跑路 / 停更？**
有过先例：同类前作 PiliPala 在 2025 年 7 月收到 B 站侵权告知函后停止更新（公开报道）。PiliPlus 是这条开源分支的延续，截至 2026 年 9 月仓库仍在更新，现状如何看仓库活跃度即可判断 —— 提交记录、Release 频率和 Issues 区的响应都公开可见，自行到 `https://github.com/bggRGjQaUbCoE/PiliPlus` 查看。这个风险点的完整讨论（含对个人账号的影响）在 [登录与账号管理.md](登录与账号管理.md) 第六节；若某天确实停更，你已缓存的视频与账号数据不受影响，只是应用不再更新。

## 五、反馈问题的正确姿势

到 GitHub Issues 提问题时带上四样东西：应用版本号（设置里能看到，本文对应的版本是 2.1.0-c1aeaca09）、机型与系统版本、复现步骤、必要的截图。缺信息的 issue 基本不会有人回。

日常使用的其他疑问，先回对应功能篇查一遍：账号相关的在 [登录与账号管理.md](登录与账号管理.md)，缓存与备份的在 [离线缓存与收藏管理.md](离线缓存与收藏管理.md)。
