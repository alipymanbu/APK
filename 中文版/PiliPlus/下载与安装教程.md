## 二、从哪获取安装包

两个入口，任选其一：

1. **夸克网盘**：本篇头部的「PiliPlus 安装文件资源（夸克网盘）」链接，转存到自己的网盘后下载 APK 文件即可。适合不方便直连 GitHub 的网络环境。
2. **GitHub Releases**：打开项目仓库右侧的 Releases 页（`https://github.com/bggRGjQaUbCoE/PiliPlus/releases`），每个版本下面挂有编译好的 APK。想追新版从这里拿。

Releases 页的版本号形如 `2.1.x`，本文这份 `2.1.0-c1aeaca09` 里的后半段是构建时的代码提交号 —— 同一个 `2.1.0` 基础版本可能对应多个提交号构建，功能基本一致，不必纠结后缀，装哪个版本以你实际拿到的文件为准。

如果你拿到的 APK 文件名、体积和上面的表对不上，多半是另一版 —— 功能大同小异，但个别设置项的位置可能不同，遇到对不上的时候以你手上那版的实际界面为准。

## 三、安装步骤（安卓 8.0 及以上通用）

1. 把 APK 文件下载到手机存储里（网盘 App 下载的文件一般在 `Download` 或网盘 App 自己的目录）。
2. 用文件管理器点开这个 `.apk` 文件。系统会提示「出于安全考虑，已禁止安装未知来源应用」，点「设置」。
3. 在跳出的页面里，给**你刚才用来打开 APK 的那个应用**（文件管理器或网盘 App）勾选「允许安装未知应用」。只需要给这一个应用授权，不用全局放开。
4. 返回重新点 APK，点「安装」，等进度走完。
5. 点「打开」直接进应用，或者回桌面找 PiliPlus 的图标。

系统要求方面，这类 Flutter 构建的安装包一般要求 Android 7.0 及以上；安装报「不兼容」时先确认系统版本，再看是不是架构对不上（见下一节）。

## 四、装不上时的三个常见原因

安装失败时，按出现频率从高到低排查：

1. **签名冲突**：手机上已经装过一个不同签名的同名应用（比如之前从别处装的版本），系统会直接拒绝覆盖。先在「设置 → 应用」里卸载旧的再装。因为包名是 `com.example.piliplus`，和哔哩哔哩官方客户端的包名不同，所以它和官方 App 可以**共存**，互不覆盖。
2. **存储不足**：安装过程需要数倍于安装包的临时空间，23.84M 的包建议留出至少 200M 空余。
3. **系统版本或架构过低**：老机型（Android 7 以下）装不了；个别 release 会按 CPU 架构拆分文件（arm64-v8a / armeabi-v7a），2018 年以后的手机基本都是 arm64，选错架构会报不兼容。

更完整的排查清单（包括装好了但打不开的情况）写在 [常见问题与故障排除.md](常见问题与故障排除.md)。

## 五、装完之后先做什么

1. 首次启动会有权限请求（存储、通知等），按需给。不给存储权限会影响离线缓存功能。
2. 不登录也能直接看推荐、热门、直播和番剧；想要收藏、历史记录、发弹幕这些功能，需要先登录 B 站账号 —— 步骤在 [登录与账号管理.md](登录与账号管理.md)。
3. 播放器默认设置对多数人够用，但手势、画质、弹幕这几类设置值得按自己习惯过一遍，见 [播放设置与手势操作.md](播放设置与手势操作.md) 和 [弹幕设置与字幕调节.md](弹幕设置与字幕调节.md)。
