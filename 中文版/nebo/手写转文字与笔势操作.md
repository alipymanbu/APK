## 先分清四种笔记类型

新建内容时要先选类型，四种类型的版面和手写转文字的触发方式都不一样：

| 类型 | 版面 | 适合 | 手写转文字的触发方式 |
| --- | --- | --- | --- |
| 笔记本 | 固定尺寸页，页数不限 | 日常课堂笔记、日记 | 套索圈选后转换 |
| 文档 | 无限纵向滚动，内容自动重排 | 长文、要导出 Word 的稿子 | 双击转换 |
| 白板 | 无限画布，可缩放平移 | 头脑风暴、思维导图 | 套索圈选后转换 |
| PDF | 导入的文件逐页批注 | 试卷、合同、文献批注 | 套索圈选后转换 |

创建任一类型时都要选「书写语言」，选定后这一篇不能改。英语和设备语言默认已装好，其他语言按需在应用内下载。写中文的话有三个变体可选：简体中文、繁体中文（香港）、繁体中文（台湾），按你的书写习惯选，选错变体也会影响准确率。

PDF 类型不只收 PDF 文件：官方功能页列过 Word 文档和 PowerPoint 演示可以输入成 PDF 再批注，你那版应用支不支持以应用内导入选项为准。

## 手写转文字

- **文档**：写完**双击**那段字，整段变成打字文本；再双击还能变回手写继续改。
- **笔记本 / 白板 / PDF**：用**套索**圈住要转的手写内容，选择「转换为文本」。

转换是可逆的，转换结果可编辑、可搜索。准确率的前提是书写语言选对——一篇笔记只认一种语言加英语，详见下文「识别不准先查这四点」。

## 顺手记下来就够用的笔势

| 动作 | 做法 |
| --- | --- |
| 删除 | 在文字上横向划掉 |
| 强调 | 在文字下方画下划线 |
| 图形成形 | 画完图形后笔尖停住不抬，直线、圆、箭头自动变标准形 |
| 选择 | 用套索圈住内容，可整体移动、复制、改色、转文字 |
| 高亮 | 换马克笔书写，或用马克笔涂抹 |

## 数学公式

- 直接手写公式，分数、根号、上下标、矩阵都能识别，还可以跨多行书写；
- 6.3 版起，可以用套索选中手写公式转成可编辑的数学对象，改完再转换；
- 转换后的公式能**拷贝为 LaTeX 或图片**，粘到支持 LaTeX 的编辑器或聊天工具里。

## 图形与插图

白板和文档里可以插入照片、手绘简图；手绘的流程图、结构图在笔尖停住后转成标准图形。按官方商店页的说明，转好的图表粘到 PowerPoint 里仍保持可编辑。

## 识别不准先查这四点

1. **书写语言**选对没有：建篇时选的，选错了只能重新建一篇；
2. 字是不是太小、行距太密：写大一点、按行写，连笔和印刷体都认，越潦草准确率越低；
3. 套索圈选时有没有把无关的图形、涂鸦圈进去；
4. 是不是用了不支持的语言：从右往左书写的语言（阿拉伯语、希伯来语等）不支持。

更系统的排查与语言支持清单见 [常见问题与笔记管理.md](常见问题与笔记管理.md)；写好的笔记要带走，导出步骤见 [云同步与导出格式.md](云同步与导出格式.md)。
