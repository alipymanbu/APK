# Seedance 2.0 提示词写法与参考素材用法

> 同一个模型，提示词写得好坏直接决定出片能不能用。本篇给出经过验证的提示词结构、@ 引用语法、运镜词汇表和参考素材的搭配上限，照着写就能明显减少废片。

## 一、文生视频：五要素公式

一段能用的提示词，把下面五样说清楚就够了，顺序不必死板：

```
主体 + 动作 + 场景 + 镜头 + 风格
```

| 要素 | 写什么 | 示例 |
| --- | --- | --- |
| 主体 | 谁或什么，外观写具体 | 一位扎马尾的年轻女生，穿白色连衣裙 |
| 动作 | 主体在干什么，写缓慢明确的动作 | 缓慢漫步，抬手拂过飘落的花瓣 |
| 场景 | 环境加光线 | 春日樱花林，柔和的午后阳光 |
| 镜头 | 机位与运动 | 中景，镜头缓慢向前推进 |
| 风格 | 画面质感 | 温暖电影色调，浅景深 |

新手最容易犯的两个错：动作写太剧烈（奔跑打斗类容易画面崩，先用走路、转身这类慢动作试），以及一股脑堆形容词（「大师级」「极致画质」这类词没有信息量，删掉不影响结果）。

## 二、@ 引用：告诉模型每份素材干什么用

往参考框里传了多个素材后，在提示词里用 `@` 加素材编号点名，模型才知道哪份素材负责什么 —— 这是 Seedance 2.0 全能参考模式的核心用法：

```
@图片1 里的女孩在 @图片2 的星空场景中回头微笑，
运镜模仿 @视频1 的环绕镜头，配乐节奏跟随 @音频1
```

写法要点：

- 每份素材在提示词里**点名一次、说明一次用途**：这张当角色、那张当场景、这段视频管运镜、这段音频管节奏；
- 没被点名的素材模型会自行猜测用途，结果不可控 —— 传了就写，不打算用就删掉。

## 三、参考素材的配额上限

单次生成能带的素材量有明确上限（以生成界面实际可传为准）：

| 素材类型 | 上限 |
| --- | --- |
| 图片 | 9 张 |
| 视频 | 3 段 |
| 音频 | 3 段 |
| 混合总数 | 12 个文件 |
| 生成时长 | 最长 15 秒 |

素材不是越多越好：每多一份，模型要多分一份注意力。常规做法是「一张角色图 + 一张场景图 + 一段运镜参考视频」三件套，够用了再加。

## 四、运镜词汇表

镜头语言直接写进提示词即可，这些词模型认得：

| 你写的词 | 画面效果 |
| --- | --- |
| 跟踪镜头 / 跟拍 | 镜头跟着主体移动 |
| 环绕镜头 | 绕着主体转一圈 |
| 推近 / 拉远 | 镜头向主体靠近或离开 |
| 希区柯克变焦 | 背景拉伸压缩的眩晕感变焦 |
| 手持感 | 带轻微晃动的纪实画面 |
| 摇臂 / 升降 | 从高处俯冲或升起的大幅度机位运动 |

还有一招：把别人一条你喜欢的视频整段传上去当**参考视频**，让模型复刻它的镜头切换和剪辑节奏，再用你自己的角色和场景演一遍。

## 五、声音：不用后期，直接写进提示词

Seedance 2.0 生成的是带原生音频的视频（双声道，含对白、音效、配乐），所以提示词里可以直接安排声音：

- 要对白就写对白内容：「女孩回头说：走吧」；
- 要环境音就写场景声：雨声、菜市场嘈杂声、冰刀刮冰声；
- 传一段音频当参考，可以要求卡点或复现声音风格。

## 六、真人素材的两条红线

- 上线初期官方公告曾**暂停真人图片/视频作为主体参考**的能力，期间用真人照片会被拦截 —— 现在是否放开以 App 内当期提示为准，被拦就换非真人素材；
- 能传真人素材时，只传**你本人**的或**拿到授权**的：上传界面的安全提示写明，因素材侵权造成的责任由使用者承担。

素材传了但生成结果不认、声音对不上画面这类问题，见[常见问题排查.md](常见问题排查.md)；想先跑通全流程再回来打磨提示词，回[怎么用.md](怎么用.md)。
