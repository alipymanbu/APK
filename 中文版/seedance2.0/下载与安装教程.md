## 一、先弄清楚：要装的是即梦AI，不是「Seedance 2.0」

搜「seedance2.0」的人，想用的其实是字节那个能生成 4~15 秒带声音视频的 AI 模型。这个模型没有自己的独立安装包，它被集成在几个平台里：

| 平台 | 形态 | 说明 |
| --- | --- | --- |
| 即梦AI | 手机 App / 网页版 | 功能最全的创作端，本篇要装的安装包就是它的安卓版 |
| 豆包 | 手机 App / 网页版 | 在对话框里选 Seedance 2.0 模型即可生成 |
| 火山方舟 | API | 面向开发者，普通用户用不到 |

即梦AI 由深圳市脸萌科技有限公司（字节跳动旗下）开发。你手里这份安装包的基本信息：

| 项目 | 内容 |
| --- | --- |
| 版本 | 2.1.6 |
| 安装包大小 | 198.39M |
| 包名 | com.bytedance.dreamina |
| 系统要求 | 安卓 5.2 及以上（以安装时手机给出的提示为准） |

## 二、获取安装文件资源

安装包通过夸克网盘分享，按下面三步走：

1. 打开 [Seedance 2.0 安装文件资源（夸克网盘）](https://pan.quark.cn/s/334ba0c47abf)，选择**转存到我的网盘**（夸克网盘的分享必须先转存，转存不要钱）；
2. 手机上打开夸克网盘 App，在「我的文件」里找到刚转存的 APK 文件；
3. 点它下载到手机本地，下载完成后直接在通知栏或下载列表里点开安装。

没有装夸克网盘 App 的话，先在手机应用商店搜「夸克」装一个，用手机号登录即可，转存和下载都不需要会员。

## 三、安装步骤与权限设置

安卓手机默认不允许安装应用商店之外的安装包，第一次装会卡在「未知来源」这一步：

1. 点开下载好的 APK，系统弹出「不允许安装未知应用」时，选择**设置 → 允许来自此来源的应用**（不同品牌手机入口略有差异，一般在弹窗里点「设置」就能跳过去）；
2. 回到安装界面点「继续安装」，等待完成；
3. 打开即梦AI，用抖音账号或手机号登录 —— 登录后积分、作品都在这个账号下，换手机登录同一账号可以找回。

两个提醒：

- 如果手机里已经装过应用商店下载的即梦AI，再装这份安装包可能提示「签名不一致」导致安装失败。想换成这一版，先把已装的那个卸载（作品存在云端账号里，卸载不会丢，重新登录即可看到）。
- 安装包接近 200M，加上生成缓存，建议手机至少留出 2~3G 空间。

## 四、这份安装包和官方最新版的关系

网盘里这份是 2.1.6 版本。即梦AI 迭代很快，官方应用商店里的版本通常更新。两种装法按需选：

- **就想用这一份固定版本** → 按上面的网盘步骤装，装完在 App 内**关闭自动更新**（各手机应用市场会提示升级，不理会即可保持版本）；
- **想用最新版** → 直接在手机应用商店搜「即梦AI」安装，版本号和体积以商店页面当时显示为准，功能上基本一致，越新的版本模型入口越多。

装好之后去哪、怎么生成第一条视频，看[怎么用.md](怎么用.md)；生成要花积分，先去[积分与会员收费.md](积分与会员收费.md)弄清免费额度再动手，能少走弯路。

## 五、安装失败对照表

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 点 APK 没反应或提示「解析包错误」 | 下载不完整，或手机安卓版本低于要求 | 删掉重下；确认系统版本满足上表要求 |
| 提示「签名不一致 / 存在冲突」 | 手机里已有商店版即梦AI | 卸载已装版本后再装（云端作品不丢） |
| 安装中断提示空间不足 | 存储不够 | 清出 2~3G 空间再装 |
| 装完打不开、闪退 | 系统版本过旧或安装包损坏 | 重装一次；仍闪退则改用应用商店版本 |

装好了但生成时出问题（排队久、失败、素材被拦），直接翻[常见问题排查.md](常见问题排查.md)。
