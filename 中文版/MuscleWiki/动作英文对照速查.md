## 一、先看懂命名规则

它的动作名基本是固定语序：**修饰 + 器械 + 动作 + 部位**，例如 `Incline Dumbbell Press` = 上斜 + 哑铃 + 推 = 上斜哑铃推举。认出每一截的词根，生词名就不用一个个查了。

## 六、整名试读三个

- `Seated Cable Row` = 坐姿 + 绳索 + 划船 → 坐姿绳索划船（练背）；
- `Cable Triceps Pushdown` = 绳索 + 三头 + 下压 → 绳索三头下压；
- `Incline Dumbbell Fly` = 上斜 + 哑铃 + 飞鸟 → 上斜哑铃飞鸟（练胸上部）。
