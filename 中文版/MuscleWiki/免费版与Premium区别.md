## 一、功能对照表

依据官方付费页（`musclewiki.com/gopremium`）整理，具体权益随版本调整，以官方页面为准：

| 功能 | 免费版 | Premium |
| --- | --- | --- |
| 动作库（视频 + 说明） | 可用（基础范围） | 完整 |
| 交互肌肉地图 | 基础 | 完整 |
| 个性化计划 | 最多 3 个 | 不限 |

## 二、关于「无广告」的两个口径

官方商店页写的是「100% 无广告」，而官网付费页又把「无广告体验」列在 Premium 权益里——两处官方口径不一致，本篇不替你选边。实际结论很简单：装上免费版用一会儿，广告是否影响你就清楚了；多数用户查动作、记训练的主线路径不受影响。

## 三、价格与试用

截至 2026-09，官网标注的价格：

| 方案 | 价格 | 说明 |
| --- | --- | --- |
| 月付 | $4.99 / 月 | 按月续费 |
| 年付 | $49.99 / 年 | 约 $4.17 / 月；官网页面上价格档位与折扣标注有过变动 |

试用规则（以结账页面实际显示为准）：

- 官网挂出的 **7 天免费试用**绑定在年付方案上，试用开始当天不扣款；
- 试用结束前不取消，第 7 天起按年付价格扣款；取消入口在账号设置里，一步操作，取消后仍可用到试用期满；
- 网页端的扣款由第三方支付服务商（Paddle）处理，支持信用卡、PayPal 等常见方式，具体以结账页为准；
- 取消入口跟着订阅渠道走：在官网订的，去网站账号设置里取消；如果你是从 Google Play 内订阅的，则在 **Play 商店 → 付款与订阅**里管理。找错渠道会看不到取消按钮。

价格会随时间和地区变化，付款前以官方页面显示为准；第三方评测里出现过 $5.99/月 的旧价格信息，不要当作当前价格。

## 四、按用法判断要不要付费

| 你的用法 | 建议 |
| --- | --- |
| 只查动作、看视频、学姿势 | 免费版完全够，不必付费 |
| 胸 / 腿 / 背三分化，长期固定课表 | 3 个例程上限刚好够，免费版可长期用 |
| 多套课表轮换、要看容量与进步曲线 | 3 个上限会卡住，这才值得考虑 Premium |
| 想要 AI 按器械与目标生成计划 | 属于付费功能 |

先免费跑一个月再决定，路径见[训练计划与动作记录](训练计划与动作记录.md)。安装包本身免费，从[下载与安装教程](下载与安装教程.md)取；装不上或界面疑问看[常见问题解答](常见问题解答.md)。
