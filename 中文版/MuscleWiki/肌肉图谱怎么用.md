## 一、三步找到你要的动作

1. **选视图**：打开应用就是一张人体图，先在正面 / 背面之间切换，再选男性 / 女性示范（动作演示的视频会跟着换人）。
2. **点部位**：直接点图上发亮的区域——胸、背、肩、手臂、腹、腿、臀等大肌群；多数大肌群下还有子部位（比如胸分上中下、背分背阔肌与斜方肌），继续点更细的那块。
3. **挑动作**：点完会出现这个部位对应的动作列表，每个动作配短视频和步骤说明，点开看演示即可。

整套逻辑就是「部位 → 子部位 → 动作」，不用记肌肉的学名，看到图点上去就行。

## 二、按手头器械筛选

动作列表可以按器械过滤，居家用户主要靠它把范围缩到现有器械——家里只有哑铃，就只看哑铃动作。官方给出的器械分类包括：

| 分类 | 对应场景 |
| --- | --- |
| 徒手（Bodyweight） | 什么器械都没有，居家、出差 |
| 哑铃 / 杠铃 / 杠铃片 | 家庭小型器械、商用健身房 |
| 壶铃 / 药球 / Bosu 球 | 功能性训练 |
| 器械 / 史密斯机 / 绳索 | 商用健身房固定器械区 |
| 弹力带 / TRX | 便携器械、悬挂训练 |
| 瑜伽 / 拉伸 | 热身、放松、恢复日 |

健身房间被占用时的典型用法：本来想练杠铃卧推，凳子被占了，切到「哑铃」或「绳索」分类，同一个部位马上能换替代动作。

## 三、看懂一个动作页

点进单个动作后，重点看这几块：

- **视频演示**：多角度循环播放，男女示范可切换；
- **步骤说明**：文字分步讲怎么做（以英文为主，句子短，配合视频看没有阅读障碍）；
- **目标肌群**：标出主练肌与协同肌，用来确认这个动作是不是真练你想练的那块；
- **难度标记**：从新手到进阶分级，刚开始挑初级动作。

动作名与步骤说明以英文为主，常见的器械、动作、肌群英文词根见[动作英文对照速查](动作英文对照速查.md)，认词根就能拼出动作名的意思。

## 四、两个常见场景

- **完全新手第一次进健身房**：先点「今天想练的部位」，从初级动作里挑 4~5 个，每个对着视频把姿势过一遍再上重量，比在场地上瞎猜器械快得多。
- **居家徒手训练**：直接锁「徒手」和「拉伸」两个分类，配合[训练计划与动作记录](训练计划与动作记录.md)里说的计划功能排成一周课表。

手机之外，官网 [https://musclewiki.com](https://musclewiki.com) 用的是同一套身体地图与动作库：电脑大屏上先把动作挑好、视频看熟，到健身房照着练，比在现场低头刷手机省事。

## 五、动作库规模与边界

官方口径是超过 1700 个实拍动作（不同页面写过 1800+、2000+，以官方页面为准），覆盖常见大肌群。想精准练某个很冷门的小肌群（如前锯肌）时，颗粒度可能不够细，这是它分类方式的边界；这类需求往往要靠子部位下的变式动作凑。
