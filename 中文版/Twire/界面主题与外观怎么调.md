Twire 的外观调整集中在「设置 → 外观」和「设置 → 一般」两处：前者管配色与卡片，后者管开始页面、图像代理与账号。本篇按这两处逐项说明，并给出每项的适用场景。

## 一、五套主题怎么选

在「设置 → 外观」里点主题，会弹出五个选项：

| 主题 | 配色特征 |
| --- | --- |
| 蓝 | 以蓝色为主色的彩色主题 |
| 紫 | 以紫色为主色的彩色主题 |
| 黑 | 深灰底色的深色主题 |
| 夜间模式 | 深色主题，强调色偏红 |
| 纯黑模式 | 底色为纯黑的深色主题 |

选择建议：

- 白天用得多、喜欢亮一点，选蓝或紫；
- 夜里看得多、想减少屏幕刺眼，从黑、夜间模式里挑一个；
- 用 OLED 屏的手机，纯黑模式在暗环境下更省电，因为纯黑像素不发光。

主题是全局的，换完所有页面的配色一起变，不需要重启应用。

## 二、卡片样式与卡片大小

同一个「外观」页里还有两项，控制直播封面列表的排版：

| 设置项 | 可选值 | 效果 |
| --- | --- | --- |
| 卡片样式 | 精简 / 正常 / 详细 | 决定每张卡片上显示多少信息，越详细占的高度越大 |
| 卡片大小 | 小 / 中 / 大 / 最大 | 决定封面缩略图的尺寸 |

两项是搭配着用的：**平板或大屏手机**可以把卡片调到「大」甚至「最大」，一屏少放几张但封面更清楚；**手机竖屏**想一屏多看几个直播间，把卡片调小、样式选精简更实用。

改完回到列表页立刻可见，不满意再调回去即可，不影响任何播放设置。

## 三、开始页面

「设置 → 一般」里的开始页面决定打开应用时先落在哪一页，选项对应侧栏里的几个入口：直播中、热门直播、已关注、热门游戏、搜索。

- 主要看固定几个主播：设成「已关注」；
- 想随手发现新内容：设成「热门直播」或「热门游戏」；
- 挑你实际最常停留的那一页设成开始页面，改完下次启动生效。

## 四、图像代理

同一页里还有「使用图像代理」。打开后填一个代理地址，应用会通过它加载封面与头像图片。

| 什么时候用 | 效果 |
| --- | --- |
| 列表里封面大量显示成灰色占位图、头像加载不出来 | 换成可用的图片代理地址后通常恢复 |
| 一切正常 | 不要开，多一层转发只会更慢 |

应用里给的示例地址长这样：`https://external-content.duckduckgo.com/iu/?u=`，填好后点保存生效。地址要填「前缀」形式（末尾带 `?u=` 这类参数），而不是一个完整图片链接。填错的表现是封面依旧不显示，不会影响直播播放本身。

## 五、界面语言

Twire 的界面语言跟随系统语言，中文系统下菜单与提示就是中文，不需要在应用里单独切换。应用内置了多套语言翻译（含简体中文与繁体中文），由社区在翻译平台上维护，个别新功能的文案偶尔会保留英文原文，属于翻译滞后，不影响功能。

## 六、外观相关的常见误解

- **改了主题不影响播放**，画质、代理、聊天设置都在各自的分组里，互不牵连。
- **卡片大小只改列表排版**，不会减少能看到的直播数量，能看到的还是同一批内容。
- **图像代理管的是封面图片**，与视频流是两条独立通道；视频卡顿时调它没用，该去 [画质与播放设置.md](画质与播放设置.md) 处理。
