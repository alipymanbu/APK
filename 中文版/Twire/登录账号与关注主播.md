Twire 不登录也能浏览和播放直播，登录后才能拿到关注列表、进聊天室。本篇把「登录能多得到什么」「关注到底存在哪」这两件事说清楚，避免换了手机发现关注列表对不上。

## 一、不登录和登录，差在哪

| 功能 | 未登录 | 已登录 |
| --- | --- | --- |
| 热门直播、热门游戏、搜索后播放 | 可用 | 可用 |
| 看直播回放（VOD） | 可用 | 可用 |
| 进直播间聊天室 | 不可用 | 可用 |
| 「已关注」列表 | 只显示在本机添加的关注 | 叠加账号上原有的关注 |
| 订阅、礼物等聊天通知 | 不可用 | 可用 |

侧栏顶部那一行会直接写明状态，未登录时显示「未登录」。点这一行就进入账号页。

## 二、登录步骤

1. 打开左侧侧栏，点顶部的登录状态那一行。
2. 点登录，应用会跳到 Twitch 的官方授权页面。这一步在应用内的浏览器组件里完成，**账号密码只输给 Twitch**，Twire 只拿到一个授权令牌。
3. 授权成功后自动跳回 Twire，侧栏顶部换成你的昵称与头像。
4. 首次登录后应用会拉一次你在 Twitch 上的关注列表，稍等几秒再切到「已关注」，不要刚登录就断言列表是空的。

登录用哪种方式由 Twitch 决定：邮箱密码、第三方账号登录都可以。Twire 属于第三方客户端，无权也无需知道你的密码。

## 三、什么时候要重新登录

- 长时间不打开、在别处改过 Twitch 密码、或者在 Twitch 官方设置里撤销了对 Twire 的授权，都会让当前登录失效。
- 失效的表现是应用提示需要重新登录，或侧栏退回「未登录」。
- 重新走一遍上面的授权流程即可，**本地设置与本机关注列表不会因为重新登录而丢失**。

如果授权页始终打不开（多见于网络受限），处理办法见 [常见问题与排查.md](常见问题与排查.md)。

## 四、怎么关注、怎么取关

- 在主播的频道页或直播间的信息区点关注，之后就能在侧栏「已关注」里看到谁正在直播。
- 取消关注在原位置再点一次即可，列表会同步移除。
- 「已关注」里的条目会区分「正在直播」和「未开播」，优先看开着的那些就行。
- 也可以在搜索里找到主播后直接关注，不必先进直播间。

## 五、本地关注和 Twitch 关注的区别

这是最容易踩的一点：**在 Twire 里点关注，默认只写在本机，不会同步到 Twitch 账号**，也不会改变你在 Twitch 官网的关注列表。官方把这种称为「本地关注」，界面里单独用一栏「本地关注」表示。

| 你做的操作 | 实际影响 |
| --- | --- |
| 在 Twire 里关注 / 取消关注 | 只改本机列表 |
| 登录后自动拉取 | 把 Twitch 账号上的关注读进本机 |
| 导出全部关注 | 把本机列表与账号关注一起导出成一个文件 |
| 导入关注 | 把导出文件读回本机，**不会反向加到 Twitch 账号** |
| 清空全部关注 | 只清本机，不动 Twitch 账号上的关注 |

换手机时，先在新旧设备上各登录一次账号，再用「导出全部关注」和「导入关注」搬运，比一个个重新关注省事。注意导入是合并，清空前想清楚是否还要保留这份列表。

## 六、换账号与退出登录

- 账号页里可以「退出登录」或「登录新账号」，换账号会重新走一次 Twitch 授权。
- 退出登录**不会**删除本机的关注列表；要让本机列表也清干净，用「清空全部关注」。
- 退出后聊天室会立刻断开，直播间里的聊天面板变空，属于正常现象。

## 七、登录还卡着的话

登录相关的问题几乎都集中在授权跳转这一段：页面打不开、授权后没跳回来、跳回来仍是未登录。逐条排查见 [常见问题与排查.md](常见问题与排查.md)；如果是登录成功但聊天室一直连不上，先看 [聊天与第三方表情怎么用.md](聊天与第三方表情怎么用.md) 里的连接状态说明。
