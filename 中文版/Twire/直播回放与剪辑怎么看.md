# Twire 直播回放与剪辑怎么看

错过直播之后，回放（VOD）和剪辑是把内容补回来的两条路。本篇说明它们在 Twire 里从哪进、能控制什么，以及回放的聊天为什么有时是空的。

## 一、在哪找直播回放

1. 进主播的频道页（从「已关注」列表点进去，或用搜索找到主播）。
2. 频道页里能看到该主播留下的回放列表，点任意一条即开始播放。
3. 主播如果关闭了回放保存，这里就是空的——回放由主播在 Twitch 侧的设置决定，不是应用限制。
4. 回放不是永久存在的。平台只保留一段时间，到期或主播手动删除后就找不回来了（保留时长由平台的规则决定，以官方页面为准）。想长期留存，趁还在的时候自己录一份最稳妥。

未登录也能看回放，不需要账号。

## 二、回放和直播看法的区别

| 维度 | 直播 | 回放（VOD） |
| --- | --- | --- |
| 进度控制 | 只能跟当前时间点 | 可自由拖进度、快退快进 |
| 观看起点 | 就是现在 | 可以从上次中断的位置继续 |
| 聊天 | 实时聊天室 | 按时间轴同步回放当时的聊天 |
| 画质档位 | 看主播开了哪些转码 | 通常提供更多档位，包括源画质 |
| 结束后 | 结束即结束 | 可反复回看，直到主播删除或到期 |

回放的聊天是「重放」不是「直播」：你在回放里发不出消息，但能看到当时观众的发言，用来还原当时的气氛。

## 三、回放的续播

从上次退出的位置继续，对长回放很实用。有两点要注意：

- 续播位置是按单个回放记的，换另一个回放不会沿用。
- 如果续播位置明显不对（比如一跳就到结尾），在画质菜单换一档再拖到想看的位置试试。

## 四、回放的画质怎么选

回放的画质菜单比直播更全，通常能选到源画质。选档原则和直播一致：流量环境选 480p 或 720p，Wi-Fi 下想看细节就选源。详细取舍见 [画质与播放设置.md](画质与播放设置.md)。

回放是点播而非实时流，对带宽波动比直播宽容一些：卡顿时代价只是等待缓冲，不会错过内容。

## 五、剪辑（Clips）怎么看

剪辑是 Twitch 上由观众或主播剪出来的短视频片段，2.12.1 起 Twire 支持播放。入口在主播频道页里与回放并列的位置，点开直接播放。

剪辑的两个特点：

- **通常没有聊天**。应用会直接提示这条剪辑的聊天回放已不可用，属于正常状态，不是加载失败。
- **时长很短**，一般几秒到几十秒，画质固定为剪辑上传时的版本，没有多档可选。

## 六、回放放不出来怎么处理

回放或直播播放失败时，应用会提示「播放失败，试试其他画质」这类文字。按这个顺序试：

1. 在画质菜单里换一档（优先试 720p 一档，再试最低档）；
2. 退出直播间重进，让它重新取一次播放地址；
3. 换网络试，判断是不是当前线路的问题；
4. 同一主播的其他回放能不能播——能播说明是那一条回放本身的问题。

以上都无效时，排查步骤见 [常见问题与排查.md](常见问题与排查.md)。回放里的聊天不显示则多半与登录状态有关，先看 [聊天与第三方表情怎么用.md](聊天与第三方表情怎么用.md)。
