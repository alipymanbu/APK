Twire 的聊天室需要登录 Twitch 账号才会出现，这一点和官方客户端一样。本篇把聊天的前置条件、消息操作、三套第三方表情的开关位置，以及聊天窗口在手机上的排版讲清楚。

## 一、聊天要先登录

未登录状态下进直播间，聊天面板是空的——不是加载失败，是根本没连上聊天室。登录流程见 [登录账号与关注主播.md](登录账号与关注主播.md)。

登录后再看「设置 → Twitch 聊天室」里的两项连接相关的开关：

| 开关 | 作用 |
| --- | --- |
| 用你的账号连接聊天 | 打开时以登录账号身份进聊天室；关掉后以匿名方式连接，适合只看不想露身份 |
| 为连接启用 SSL | 加密连接聊天服务器，保持开启 |

匿名连接主要用于看聊天内容，日常想发言还是保持用账号连接。

## 二、在直播间发言与操作消息

- 打开直播间下方的聊天面板，底部输入框输入内容回车发送。
- 长按任意一条消息会弹出操作菜单：**提及**（把对方昵称填进输入框）、**复制消息**（把内容复制出来）、**屏蔽**（屏蔽该用户的消息）。
- 面板顶部会显示连接状态：连接中 / 可以聊天 / 正在重连 / 连接失败。停在「连接失败」时的处理见下文第六节与 [常见问题与排查.md](常见问题与排查.md)。

## 三、三套第三方表情怎么开

Twitch 官方表情之外，Twire 支持三套社区表情集，在「设置 → Twitch 聊天室」里各自有独立开关：

| 表情集 | 内容 |
| --- | --- |
| BetterTTV（BTTV） | 社区使用最广的一套，覆盖大量频道自定义表情 |
| FrankerFaceZ（FFZ） | 频道自定义表情与徽章 |
| 7TV | 包含动画表情 |

几点实际体会：

- 三套可以同时打开，互不冲突。
- 全开之后聊天面板的首次加载会略慢一点；网络不好时先只留常用的一套。
- 输入框里打一个 `:` 会弹出表情补全，按提示选就行，不用背表情代码。
- 刚进直播间那几秒看到表情显示成代码（例如 `Kappa` 这样的纯文字），是表情数据还没拉完，等一会儿会变成图。
- 某个表情看不到，先确认那个主播本身有没有配这套表情：很多频道只用官方表情加 BTTV，本来就没有 7TV 的表情可显示，这不是故障。
- 桌面浏览器上这三套表情靠各自扩展往页面里注入，扩展之间会互相覆盖；Twire 由应用自身解析这三套表情，不用装任何扩展，表情开关也只有下面这几项。

## 四、字号、横屏与聊天通知

同样在「设置 → Twitch 聊天室」里：

| 设置项 | 作用 |
| --- | --- |
| 表情大小 | 聊天里表情的显示尺寸（小 / 中 / 大） |
| 消息字体大小 | 文字消息的字号（小 / 中 / 大） |
| 横屏时显示聊天窗口 | 横屏看直播时是否把聊天放出来 |
| 横屏时横向拖动以显示聊天窗口 | 横屏下用手指拖动来临时调出聊天，不占常驻空间 |
| 横屏时聊天窗口宽度 | 聊天占屏幕宽度的比例 |
| 聊天通知 | 订阅、礼物这类事件要不要在聊天里提示 |

手机上聊天和画面注定要抢空间。竖屏就按字号调小一点；横屏建议打开「横向拖动以显示聊天窗口」，需要看的时候拖一下、看完收回，画面不被长期压窄。

## 五、聊天自己停住了是怎么回事

聊天面板里会出现「因滚动而暂停聊天」之类的提示，意思是：你正在往上翻历史消息，面板主动停止了自动滚动，免得新消息把你顶回底部。滑回底部就恢复跟随，可以继续正常看。

## 六、发不出去、一直是空白的排查顺序

1. 确认已登录，且连接状态不是「连接失败」；
2. 关掉再打开一次聊天面板，让它重新连；
3. 换一个直播间试——只有某个频道不行，多半是对方把聊天设成了仅订阅者发言等限制；
4. 仍不行时看 [常见问题与排查.md](常见问题与排查.md) 的聊天空白一节。
