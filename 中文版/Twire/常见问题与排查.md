Twire 的绝大多数「故障」其实分三类：网络不通、没登录、装的是另一个签名的同包名版本。本篇按你看到的现象组织，每节先给最可能的原因，再给处理顺序。

## 一、装不上、提示解析包错误或应用未安装

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 下载的文件不完整，或被存成了网盘页面 | 重新从 [Twire 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a9a3cd40a634) 下载完整 APK，核对体积约 9.30 MB |
| 提示「应用未安装」，反复重试都一样 | 手机上已有同包名但签名不同的版本 | 先卸载旧版，再装这一版 |
| 安装按钮是灰的、点不动 | 没给当前应用「安装未知应用」权限 | 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里放行 |
| 提示「与你的设备不兼容」 | 系统版本低于 5.0 | 这套包需要 Android 5.0 及以上 |

安装相关的整体流程见 [下载与安装教程.md](下载与安装教程.md)。

## 二、打开后首页空白、一直转圈

按顺序判断，能快速定位是哪一层：

1. **先确认落在哪一页**。侧栏「已关注」在未登录或没关注任何人时本来就是空的，切到「热门直播」看有没有内容。
2. **有网但全是空白**：换 Wi-Fi 与移动流量互换试一次。一边能出一边不能出，说明是当前线路到 Twitch 的连接问题，不是应用问题。
3. **视频能播但封面全灰**：这是图片加载的问题，不是网络全断，去「设置 → 一般」打开「使用图像代理」并填一个可用地址，说明见 [界面主题与外观怎么调.md](界面主题与外观怎么调.md)。
4. **所有页面都空、下方也没有任何提示**：退出应用重进；仍空则卸载重装，装完先别急着登录，确认未登录状态下「热门直播」有内容。
5. **所有直播间同时打不开、封面也不刷新**：先别怀疑手机。用浏览器打开 Twitch 官网看直播能不能播——官网也播不了，说明问题在平台侧或当前线路，等一段时间再试，重装应用没有用。

第三方客户端依赖平台的接口。平台侧一调整接口，客户端在更新到新版本之前可能整体播不动。遇到「昨天还好好的、今天所有频道都不行」，先确认官网是否正常，再去官方发布页看有没有可更新的版本，不必反复卸载重装。

## 三、登录相关

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 点登录后授权页一直转圈 / 打不开 | 到 Twitch 的连接不通 | 换网络再试；确认系统时间准确（时间偏差过大授权会失败） |
| 授权完跳回来还是「未登录」 | 授权过程被中断，令牌没拿到 | 再走一次登录；期间不要切走应用 |
| 用着用着突然要求重新登录 | 令牌失效（改过密码、在 Twitch 侧撤销过授权） | 重新登录即可，本地设置与本地关注不会丢 |
| 登录后「已关注」是空的 | 关注列表还在拉取，或账号本身没关注 | 等几秒再刷新；确认 Twitch 账号上确实有关注 |
| 想换一个账号 | — | 账号页先退出登录，再点登录新账号 |

细节见 [登录账号与关注主播.md](登录账号与关注主播.md)。注意在 Twire 里点关注默认只存本机，不会出现在 Twitch 官网的关注列表里。

## 四、聊天室空白或一直连不上

1. 未登录时聊天室本来就是空的，先登录。
2. 面板顶部若显示连接失败或一直在重连：关掉聊天面板再打开，触发一次重连。
3. 换一个直播间试。只有个别频道不行时，多半是对方把聊天权限设成了仅订阅者或仅关注者发言。
4. 仍不行就退出应用重进一次。聊天相关设置与状态说明见 [聊天与第三方表情怎么用.md](聊天与第三方表情怎么用.md)。

## 五、第三方表情不显示

| 现象 | 处理 |
| --- | --- |
| 表情显示成纯文字代码 | 等几秒，表情数据还在拉取；长时间不变再往下查 |
| 只有一部分表情不显示 | 检查「设置 → Twitch 聊天室」里对应表情集的开关（BTTV / FFZ / 7TV）是否打开 |
| 7TV 表情全都不显示 | 7TV 侧接口变动会导致失效，等官方更新版本；也可先关掉 7TV 只用另外两套 |
| 换频道后表情对不上 | 退出直播间重进，让它重新拉这个频道可用的表情集 |

## 六、封面与头像不显示

这类问题只影响图片，不影响直播播放。处理办法是在「设置 → 一般」里启用图像代理并填入可用地址。填写要点与示例格式见 [界面主题与外观怎么调.md](界面主题与外观怎么调.md)。

## 七、直播卡顿、播不动、播放失败

按这个顺序试，通常前三步就能解决：

1. **降画质**：手动选 720p 或 480p，别用「自动」。
2. **换线路**：Wi-Fi 与移动流量互换，排除当前网络的问题。
3. **换频道**：只有某一个主播卡，问题在其推流或转码，与你无关。
4. **清应用缓存**：系统设置里清一次 Twire 的缓存（不要清数据），再重进。
5. **换播放器**：在播放菜单里用「使用外部播放器」交给别的播放器播，用来判断是流的问题还是内置播放器的问题。

画质档位的取舍见 [画质与播放设置.md](画质与播放设置.md)。回放播不出来可对照 [直播回放与剪辑怎么看.md](直播回放与剪辑怎么看.md)。

## 八、锁屏或切后台后断播

- 先确认系统的电池优化没有把 Twire 限制掉：在系统设置的应用详情页把 Twire 的电池策略设为「不受限制」。
- 播放中通知栏应有一条播放控制条，它是锁屏继续播放的前提；如果被系统通知设置屏蔽了，锁屏播放也可能一起被掐断，把 Twire 的通知放回来。
- 画中画不出现时，注意「暂停状态下不进画中画」这个前提——先让画面在播，再切后台。

## 九、换版本或换机后的数据问题

- **卸载重装后本地关注没了**：本地关注存在应用数据里，卸载即清空。之前导出过关注列表的话，重装并登录后用「导入关注」恢复。
- **换手机想搬关注**：旧机「导出全部关注」，新机「导入关注」。导入不会反向写回 Twitch 账号。
- **同一个包名换版本**：直接覆盖安装时会保留数据；卸载再装则数据清空。数据重要就先导出。

数据相关的操作说明集中在 [登录账号与关注主播.md](登录账号与关注主播.md)。
