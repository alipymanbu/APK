Twire 是给 Android 用的 Twitch 第三方客户端，开源、免费、不带广告，看直播不登录也能用。本篇只解决一件事：把网盘里这份包装进手机，并把第一次打开要遇到的几个提示处理掉。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本信息通常是当时的最新发布版，而网盘里这份是制作文档时核对过的版本，两者未必是同一个版本号。本文出现的版本号、包名、体积都以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Twire |
| 版本号 | 2.12.1 |
| 包名 | `com.perflyst.twire` |
| 安装包体积 | 9.30 MB |
| MD5 | `0F7207DF80B1BE925851DDCF6206FB1C` |
| 平台 | Android |
| 授权方式 | 开源免费（GPL-3.0） |

装之前可以顺手核对两件事：**包名**必须是 `com.perflyst.twire`，**体积**应该在 9.30 MB 上下。对不上就说明拿到的不是这份文件。

关于版本号：Twire 的版本号形如 `2.12.1`，前两段是功能版本，最后一位是修订号，小版本更新多是修 bug。官方后续版本号可能已经高于 2.12.1，具体以官方渠道当时显示的为准。

关于系统要求：Android 5.0 及以上可以安装这一版；不同渠道的页面标注可能不一致，以官方页面当时显示的为准。系统提示「应用与你的设备不兼容」时，基本就是这个原因。

## 二、把安装包取到手机上

1. 打开 [Twire 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a9a3cd40a634)，先转存到自己网盘再下载——直接下载的临时文件，链接失效后就找不回来了。
2. 在手机网盘里找到 `Twire_v2.12.1.apk` 下到本地。手机直接下载最省事，免得再从电脑传一遍。
3. 下载完成后核对文件大小约 9.30 MB。只有几十 KB 的多半是网盘页面被存成了文件，别拿去安装。

## 三、安装步骤

1. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统的这项开关常收在「安全」或「隐私」分类下。
2. **点开 APK 安装**：系统提示「应用未经过安全检测」时选择继续安装，这是第三方渠道安装包的常规提示。
3. **签名冲突要先卸载**：如果你手机里已经装过从别的渠道获取的 Twire（同样是 `com.perflyst.twire`），覆盖安装可能报「应用未安装」，原因是两个包的签名不同。先卸载旧版再装这一版。
4. **别和官方渠道的同包名版本共存**：包名相同就是同一个应用，装了这份就等于替换掉之前那份，本地设置与关注列表会被新装的版本接管。

## 四、首次打开会遇到什么

- **界面语言跟随系统**，中文系统的菜单与提示就是中文（应用内置简体与繁体中文翻译，由社区维护）。
- **会先引导你登录 Twitch**。登录不是必须的：可以先跳过，直接看热门直播与热门游戏。登录后才有的功能（聊天、关注同步）见 [登录账号与关注主播.md](登录账号与关注主播.md)。
- **默认落地页可以改**。设置 → 一般 里的「开始页面」可以设成侧栏里的某个入口，比如「已关注」。常看关注列表的话，改成它比每次从默认页切过去省事。
- **首页是空的、只有侧栏**属于正常现象：没登录时「已关注」是空的，切到「热门直播」就有内容了。

## 五、它会申请哪些权限

| 权限 | 用途 | 不给会怎样 |
| --- | --- | --- |
| 网络访问、查看网络连接与 Wi-Fi 连接 | 拉取直播列表、播放视频流、连接聊天室 | 首页一直转圈，直播打不开 |
| 前台服务（含媒体播放类型） | 切到后台或锁屏时继续播放，并在通知栏保留播放控制 | 锁屏就断播，通知栏没有控制条 |
| 读取与写入共享存储 | 保存导出的关注列表等本地文件 | 导出与导入关注列表会失败 |

Twire 的权限清单里没有联系人、位置、相机、麦克风这类项目，装的时候不会弹这些提示。

## 六、官方渠道与这份包的关系

Twire 是开源项目，官方发布渠道是 F-Droid（[f-droid.org/packages/com.perflyst.twire](https://f-droid.org/packages/com.perflyst.twire/)）和项目在 GitHub 上的发布页（[github.com/twireapp/Twire/releases](https://github.com/twireapp/Twire/releases)）。想拿最新版、并希望后续能自动收到更新提示，从这两个渠道装更合适。

这里提供的这份 2.12.1 是制作文档时核对过的版本，适合访问上述渠道不便的情况。它不是官方最新版，也不会自己更新——需要新版本时，重新走一遍本文的取包与安装流程即可。

## 七、换版本与卸载

- 同一个包名在系统里只能存在一个，换版本就是「卸载旧的、装新的」或者「用同签名的新包覆盖」。
- 卸载会一并清掉应用数据，包括在 Twire 里关注的本地列表。之前如果导出过关注列表，重装后可以导入回来，做法见 [登录账号与关注主播.md](登录账号与关注主播.md)。
- 装完先别急着调设置，先确认能打开一个直播间、画面与声音正常。打不开的话接着看 [常见问题与排查.md](常见问题与排查.md)。
