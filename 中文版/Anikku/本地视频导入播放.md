# Anikku 本地视频导入播放

> 不想装扩展、手上已有视频文件？Anikku 支持把本地视频当成一个「源」直接管理播放。本篇讲目录怎么摆、支持什么格式、以及放进去之后为什么「看不见」。

## 一、本地源是什么、适合谁

本地动画源（Local anime source）是 Anikku 内置的一个特殊源：它不联网、不依赖任何扩展，直接读取你手机存储里的视频文件。官方把它归为「进阶功能」，适合两类场景：

- 你自己收藏的视频文件（电脑里拷来的、录制的、之前下载好的）想在 Anikku 里统一管理；
- 扩展源失效或不方便联网时，离线环境里照样能播。

它和你从源站下载的剧集是两回事：下载的剧集由应用的下载管理维护，本地源是你手动摆文件的目录。

## 二、目录结构：摆对了才认得出来

Anikku 对本地源的目录结构有硬性要求，摆错了应用里就是空。以应用默认存储位置 `Anikku/` 为例：

```text
Anikku/
└─ localanime/
   └─ 番剧名称/
      ├─ cover.jpg
      ├─ ep01.mp4
      └─ ep02.mkv
```

逐层拆解：

| 层级 | 要求 |
| --- | --- |
| 存储位置根目录 | 即你在应用里设置的存储位置（默认形如 `Anikku/`），下面的 `localanime` 文件夹名固定 |
| `localanime/番剧名称/` | 每部番一个文件夹，文件夹名就是应用里显示的番名 |
| `cover.jpg` | 可选，封面图；不放就用默认占位图 |
| 视频文件 | 只认 `.mp4` 和 `.mkv` 两种格式，文件名会显示为剧集名 |

两个实用建议：

- 在 `localanime` 目录下放一个名为 `.nomedia` 的空文件（官方推荐），相册应用就不会把这些封面和视频扫出来重复展示；
- 文件名建议保持 `ep01`、`ep02` 这类带序号的规律写法，剧集列表排序才不会乱。

## 三、在哪里看到、怎么刷新

1. 文件摆好后，打开 Anikku，进 **Browse → Sources**，找到 **Local anime source**；
2. 点进去就能看到你的番；没有就核对目录结构（最常见的失败原因：多套了一层文件夹，或视频放错了层级）；
3. **后补的剧集不会自动出现**——官方明确说明加新集需要手动刷新：在剧集列表下拉刷新即可。

如果你改过应用的存储位置（下载设置里），本地源根目录跟着存储位置走，`localanime` 要放在**新的存储位置**下面，不是放在旧位置。

## 四、本地视频的播放与常见问题

播放操作与在线源一致：选剧集进播放器，画质、字幕、手势这些设置都在播放页调（见 [追番与播放设置](追番与播放设置.md)）。本地文件不经过网络，播放失败的排查方向和在线源不同：

- 视频完全不出现在列表里 → 目录结构问题，回第二节对照；
- 出现了但播放黑屏/报错 → 多半是视频编码格式手机硬解不了，换一个编码版本或用工具转成 H.264 的 `.mp4` 再试；
- 播放中卡顿 → 文件在存储卡上而读取慢，把常用番移到手机内部存储；
- 涉及在线源的问题（验证码、源失效）与本篇无关，去 [常见问题排查](常见问题排查.md)。

本地源与扩展机制的关系：本地源是内置能力，**不需要装任何扩展**；要不要走扩展路线看你的内容来源，两条路不冲突，扩展的配置见 [扩展与内容源配置](扩展与内容源配置.md)。
