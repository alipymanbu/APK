## 一、先理解「扩展」这套机制

Anikku 沿用 Tachiyomi/Aniyomi 系的设计：**应用本体不内置、也不托管任何内容**，每个具体站点（内容来源）由一个独立的「扩展（Extension）」接入，扩展本身也是一个个小 APK，装进应用后才会出现对应的源。

这带来三个你一定会碰到的现象：

- 刚装完应用，浏览页里什么源都没有——需要先添加扩展仓库、再装扩展；
- 某个源突然看不了/搜不出东西——通常是那个站改了页面或加了防护，等扩展更新即可，不是你手机的问题；
- 扩展不在 Google Play 里，更新节奏跟着扩展仓库走，与应用更新无关。

官方立场也写在项目说明里：应用与内容提供方没有任何关系、托管内容为零。你装什么扩展、用它访问什么站，由你自己决定并自负其责。

## 二、添加扩展仓库（第一次必须做）

扩展仓库（repository）是一个集合地址，添加后应用才知道去哪里找扩展列表。步骤：

1. 底部导航进 **Browse（浏览）**，切到 **Extensions（扩展）** 标签。
2. 点右上角的设置图标（齿轮），选 **Add repository（添加仓库）**。
3. 粘贴你要用的仓库地址，确认。应用会拉取该仓库的扩展列表。
4. 回到扩展列表，在想用的扩展上点「安装（Install）」，装完它对应的源就会出现在 **Anime Sources（动画源）** 标签里。

仓库地址从哪来：Anikku 官方不内置任何仓库。第三方社区维护着各自的扩展仓库列表，你按自己想看的站点去对应社区的发布页找地址即可；官方文档 [Getting started](https://anikku-app.github.io/docs/guides/getting-started) 与项目 [GitHub 仓库](https://github.com/komikku-app/anikku) 是确认这些机制的入口。本文不代抄具体第三方仓库地址——这类列表更新频繁，而且你需要自己对它的内容负责。

仓库管理相关的几个实用操作（官方已做进界面）：

- 仓库可以**启用/禁用**并带图标显示，暂时不想看到某仓库的扩展时不用删掉重加；
- 扩展列表支持**搜索**，另有快速过滤 NSFW 源的开关，不喜欢这类源的可以一键隐藏；
- 删除仓库不会卸载已装的扩展，但该仓库的扩展以后不再收到更新。

## 三、手动安装扩展（绕过仓库）

如果某个扩展只有 APK 文件（比如某仓库挂了、或你想装的扩展还没进任何仓库），可以直接装 APK：

- 路径：Browse → Extensions → 右上角菜单里的 **Install APK**，选文件即可。

注意两点：手动装的扩展同样只在你信任来源时才该装；扩展的 API 版本要与应用匹配，应用大版本更新后旧扩展可能被迫下线，一般过几天就有兼容版。

## 四、不想装扩展：用本地源

Anikku 继承了 Aniyomi 的本地源能力，你自己的视频/漫画文件可以不经过任何扩展直接导入播放：

- 动画：按官方 [本地动画源指南](https://anikku-app.github.io/docs/guides/local-anime-source/) 的目录结构，把视频文件放进手机存储里 Anikku 指定的本地源文件夹，刷新后即可在源列表的 Local source 里看到——完整的目录摆放、格式要求与排障见 [本地视频导入播放](本地视频导入播放.md)；
- 离线下载的剧集也归这条链路管理——下载位置、删除已看剧集等设置在 **More → Settings → Downloads** 里调，具体见 [追番与播放设置](追番与播放设置.md)。

本地源适合两类人：已有本地视频收藏的，以及想在没有网/不想折腾扩展的环境里给小孩放片的。

## 五、源太多时的整理

装了多个扩展后，浏览页会拥挤，官方给了这些整理手段：

| 操作 | 位置 |
| --- | --- |
| 只显示启用/禁用某仓库 | Extensions 页仓库开关 |
| 隐藏 NSFW 源 | Extensions 页快速过滤 |
| 固定常用源到顶部 | 源列表长按或源的「Pin」操作 |
| 建自定义源分类（如「常用」「备用」） | Browse 里给源建 custom categories |
| 保存搜索条件与筛选器，做成 Feed 页 | 搜索结果页里保存，之后在 Feed tab 一次看多个站的更新 |

跨源搜索不用一个个点进源：Browse → Sources 标签页右上角的搜索就是**全局搜索**，一次搜所有已启用源。搜不到想看的番时，先试日文罗马字写法（例如搜 `Boku no Hero Academia` 而不是 `My Hero Academia`），不同源的命名习惯差异很大——这条经验来自官方文档，也确实是最常见的「搜不到」原因。

## 六、源配置好了之后

加完源、把番加进书架只是开始：进度追踪、播放器画质与字幕、离线下载这些日常设置在 [追番与播放设置](追番与播放设置.md)；源打不开、一直转验证码的问题在 [常见问题排查](常见问题排查.md)。
