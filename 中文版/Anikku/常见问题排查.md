## 一、源打不开 / 一直转 Cloudflare 验证

**先分清是谁的问题。** Cloudflare 是不少站点挂的防机器人机制，有的站防护等级故意调得很高，专门对付 Anikku 这类应用。判断顺序：

1. 只有某一个源不行、别的源正常 → 该源站点的问题，等扩展更新或换源；
2. 所有源都不行 → 是你设备的 WebView 或网络问题，往下看。

**处理 Cloudflare 循环**（验证页一过又弹回来，无限循环）：

1. 用应用内 WebView 手动过一次验证：进到对应源或番详情页，从右上菜单（Overflow）选 **WebView**（或直接点 WebView 图标），在弹出的网页里完成 CAPTCHA，然后点左上角 X 关闭；
2. 还循环就清一次 WebView 数据：**More → Settings → Advanced**，先 **Clear cookies**，再 **Clear WebView data**，然后重试第一步；
3. 再不行就换 User-Agent：**More → Settings → Advanced** 里改 **Default user agent string**，可参考 [whatismybrowser 的最新 UA 列表](https://www.whatismybrowser.com/guides/the-latest-user-agent/)，换完重启应用再过一次 WebView 验证；
4. 以上全无效 → 官方给的说法就是等该源降低防护，或者换别的源。

**WebView 版本与选择**：Android 10 及以上默认用 Android System WebView，可以在开发者选项里查看/更换实现。注意官方明确提醒：非标准 WebView（如 Firefox 系）可能导致 Anikku 功能异常甚至崩溃，建议保持标准 [Android System WebView](https://play.google.com/store/apps/details?id=com.google.android.webview) 或 [Google Chrome](https://play.google.com/store/apps/details?id=com.android.chrome) 并保持更新。

## 二、扩展装不上 / 应用更新装不上

扩展和应用本体都是 APK，安装失败的排查思路相同：

1. 用 [Split APK Installer](https://play.google.com/store/apps/details?id=com.aefyr.sai) 重试安装——它能把真实报错显示出来（注意：不支持 Android 13+）；
2. 看它报的具体错误，对照 [下载与安装教程](下载与安装教程.md) 的报错对照表处理（签名冲突→卸载重装；`NO_MATCHING_ABIS`→换架构包；`DISPLAY_NAME column is null`→重新下载）；
3. 扩展安装卡在「Pending」不动，或 Shizuku 相关安装报错——这类问题在更新日志里有修复记录，先把应用更新到最新稳定版再试。

## 三、搜索不到想看的番

按命中率排序的检查顺序：

1. **换拼写**：很多源用日语罗马字命名，`Boku no Hero Academia` 而不是 `My Hero Academia`、`3-gatsu no Lion` 而不是 `Sangatsu no Lion`——这是官方文档里第一条，也是最常见的；
2. **确认源还在工作**：去该源的网页版确认番还在、站没挂；
3. **全局搜索确认范围**：Browse → Sources 标签右上角的搜索是一次搜全部启用源；个别源自己的搜索框只搜它自己；
4. 该源刚更新过扩展的话，重进一次源页刷新缓存。

## 四、应用崩溃 / 行为异常时怎么取证

别只截图，官方要的是日志：

1. **崩溃日志**：**More → Settings → Advanced → Dump crash logs**，导出的日志提交 issue 时附上；
2. **异常行为日志**：装一个 [Logcat Reader](https://play.google.com/store/apps/details?id=com.dp.logcatapp) 之类的工具录一段设备日志；
3. 提交 issue 前先做三件事（官方流程）：带上版本号（**More → About → Version**）、先更新到最新版看是否已修复、翻一遍[已有 issue](https://github.com/komikku-app/anikku/issues) 别重复提。

## 五、已下载的剧集播放失败

下载过的番离线打不开，按这个顺序查：

1. **先更新应用**：官方更新日志里有过「已下载视频无法播放」的修复记录（0.2.0），旧版本踩到的这类问题可能已修，更新前先手动备份一次（方法见 [备份与数据迁移](备份与数据迁移.md)）；
2. **查下载位置**：如果你挪动或清理过下载目录，应用的下载位置设置还指着旧路径，剧集自然找不到——把 **More → Settings → Downloads** 的位置改回实际目录；
3. **确认是下载内容还是本地源内容**：本地源里的视频播放失败是另一条排查路径（编码格式、目录层级），见 [本地视频导入播放](本地视频导入播放.md) 第四节；
4. 单集失败、其余正常 → 那一集的文件可能下载不完整，删掉重新下载。

## 六、应用里的数据丢了 / 书架空了

书架数据只会因为三种情况丢：卸载应用（数据清空）、预览版崩溃（异常状态）、误操作删除。对应的恢复路径：

- 有备份文件 → 按恢复流程导回，步骤见 [备份与数据迁移](备份与数据迁移.md)；
- 开过自动备份 → 备份位置里找最近一份 `.tachibk` 恢复；
- 没有任何备份 → 数据无法找回，恢复后第一件事就是把自动备份开起来；
- 只是「书架显示为空但源正常」→ 先检查是不是切到了空分类或开了筛选（追踪筛选、已看筛选都可能把条目藏掉）。

## 七、更新的两个口径

- **应用本体**：稳定版去 [GitHub Releases](https://github.com/komikku-app/anikku/releases) 下载新 APK 覆盖安装（数据不丢，但养成先手动备份的习惯）；开启应用内「自动安装应用更新」后可以省掉手动步骤。预览版（Preview）更新频繁、更容易出问题，不用预览版就别碰它的更新提示。
- **扩展**：扩展更新跟着扩展仓库走，与应用更新无关；源集体失效时第一反应是去 Extensions 页检查有没有扩展更新待装。

以上措施都无效、且影响多个源的话，先去项目的 [Discord 社区](https://discord.gg/85jB7V5AJR) 或 issue 区确认是不是共性问题，再决定等待还是动手。
