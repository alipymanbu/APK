## 一、Anikku 是什么，先确认你要装的是它

Anikku 是一款开源的安卓动画（番剧）观看应用，由 Komikku 团队在 Aniyomi 与 Komikku 的代码基础上继续开发，项目 lineage 可以追溯到 Tachiyomi → Mihon → Aniyomi 这条线，采用 Apache-2.0 许可证发布。它本身不提供任何内容，内容全部通过你自己安装的「扩展」接入，应用本体不带账号注册环节。

几个基本事实，装之前先对一下：

| 项目 | 事实 |
| --- | --- |
| 安卓系统要求 | Android 8.0 及以上（以[官方下载页](https://anikku-app.github.io/download/)当时显示为准） |
| 应用包名 | `app.anikku` |
| 本文对应安装包 | 版本 0.1.5，约 83.85 MB |
| 官方最新版 | 已更新到更高版本（截至本文检索时官方稳定版为 0.2.0），以[官方下载页](https://anikku-app.github.io/download/)为准 |
| 是否上架 Google Play | 不上架，只有 APK 安装包这一种形式 |
| iOS / 电脑版 | 没有 iOS 版，官方明确表示暂无计划；任何标着「Anikku for iOS」的都不是官方的 |

为什么不进应用商店：官方 FAQ 的解释是 APK 形式的扩展机制与 Google Play 内容政策冲突，开发者不想承担下架风险，所以只通过 GitHub 发布安装包。这意味着你要习惯「允许安装未知来源应用」这个系统弹窗。

## 二、从哪个渠道拿安装包

Anikku 的官方发布渠道只有两个，都是免费、不需要注册的：

1. **GitHub Releases**：稳定版在 [github.com/komikku-app/anikku/releases](https://github.com/komikku-app/anikku/releases)，测试版（Preview）单独放在 [github.com/komikku-app/anikku-preview/releases](https://github.com/komikku-app/anikku-preview/releases)。
2. **官方网站下载页**：[anikku-app.github.io/download/](https://anikku-app.github.io/download/)，页面同时给出稳定版与预览版两条链接。

如果你手上没有能直接访问 GitHub 的网络环境，或者想要一份已经核对过版本与体积的安装包，可以用这份 **[Anikku 安装文件资源（夸克网盘）](https://pan.quark.cn/s/53acf4c08143)**：网盘里这份是 0.1.5 版（文件名 `Anikku_v0.1.5.apk`），转存到自己网盘后下载即可。它和你从 GitHub 下载的同一版本安装包是同一个东西，只是获取途径不同。

稳定版和预览版怎么选：

- **稳定版**：日常使用就选它。版本号形如 `v0.1.5`。
- **预览版（Preview）**：供测试新功能用，官方自己都提醒它更容易出 bug 和崩溃；如果用预览版，官方强烈建议打开自动备份（见 [备份与数据迁移](备份与数据迁移.md)），防止书架数据丢失。版本号形如 `r8814`。

## 三、安装步骤

1. 从上面任一渠道拿到 `.apk` 文件（网盘版转存后下载；GitHub 版直接点 release 附件）。
2. 在手机上点开这个 `.apk`。第一次装会弹「不允许安装未知应用」，按系统提示允许你所用文件管理器/浏览器的「安装未知应用」权限，再回来继续。
3. 等系统装完，打开 Anikku。此时应用里没有可看的内容——这不是坏了，内容源需要单独配置，直接看 [扩展与内容源配置](扩展与内容源配置.md)。
4. 想确认装的是哪个版本：应用内 **More → About** 里能看到版本号。

体积和权限提示：0.1.5 版安装包约 83.85 MB，装完后应用数据会再占一些空间；后面你下载的离线剧集也会计入存储占用（下载位置可以在应用内改，见 [追番与播放设置](追番与播放设置.md)）。

## 四、装不上时的报错对照

安装阶段最常见的几类报错，官方排查文档（[Troubleshooting](https://anikku-app.github.io/docs/guides/troubleshooting/)）里给了对应解法，整理成表：

| 你看到的报错 | 原因 | 处理 |
| --- | --- | --- |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE`（签名不匹配） | 设备上已有另一个签名的同包名应用（常见于覆盖安装来源不同的版本） | 先备份 → 卸载旧版 → 重新安装 → 恢复备份；备份方法见 [备份与数据迁移](备份与数据迁移.md) |
| `INSTALL_FAILED_NO_MATCHING_ABIS` | 安装包与手机 CPU 架构不匹配 | 重新下载对应架构的包；分不清就选 GitHub release 里体积最大的那个（通常是全架构通用包） |
| `DISPLAY_NAME column is null` | 安装包文件损坏（多半是下载中断） | 删掉重新下载一遍 |
| 点开 apk 没反应 / 安装按钮置灰 | 系统限制或安装器问题 | 装一个 Split APK Installer 之类的第三方安装器再试（注意它不支持 Android 13 及以上） |

如果你是从 Aniyomi、Tachiyomi 或它们的其它分支换过来的：Anikku 的包名（`app.anikku`）与它们不同，所以**可以共存安装**，不用先卸载旧的；数据用备份文件互导即可，具体见 [备份与数据迁移](备份与数据迁移.md)。

装好了但用起来出问题的（比如源打不开、验证码转圈），不在本文范围，去 [常见问题排查](常见问题排查.md) 对照处理。
