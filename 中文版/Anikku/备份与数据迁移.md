# Anikku 备份与数据迁移

> 换手机、重装应用、从 Aniyomi 换到 Anikku，都要靠备份文件搬家。本篇讲备份里有什么、没什么、怎么开自动备份、怎么在新设备上把书架和已下载剧集完整接回来。

## 一、手动备份：三步

先把两种「迁移」分清：本篇讲的是**应用间搬家**（换手机、从 Aniyomi 等旧应用搬进 Anikku），靠备份文件；同一部番在应用内从 A 源换到 B 源是另一回事，见 [换源迁移指南](换源迁移指南.md)。

1. 进 **More → Data and storage（数据与存储）**；
2. 选 **Create backup（创建备份）**；
3. 选一个保存位置，生成 `.tachibk`（或 `.proto.gz`）格式的备份文件。

这个格式是 Mihon 系（Mihon、Aniyomi、Komikku 及各分支）通用的备份格式，Anikku 生成的备份可以在这些应用之间互导——这是从 Aniyomi 等旧分支换到 Anikku 时的标准搬家路径。

## 二、备份里有什么、没什么

恢复前先知道边界，避免「恢复完发现少东西」：

| 包含 | 不包含 |
| --- | --- |
| 书架条目、分类 | 书架之外的观看/阅读历史 |
| 已看集数/章节记录（限书架内条目） | 已下载的剧集和章节文件本体 |
| 追踪服务的设置 | 本地源（Local source）内容 |
| 观看/阅读历史（限书架内条目） | 自定义封面 |
| 番的资料（作者、加书架时间、所选播放器、观看时长等） | |
| 用过的扩展列表（恢复时会提醒你重装） | |
| 应用设置与各源独立设置 | |

注意两个易漏项：**下载的剧集不在备份里**（它们是独立文件，迁移靠第三节的办法）；**追踪服务要重新登录**（备份只带设置不带登录态）。

## 三、转移已下载的剧集

已下载内容不进备份文件，但迁移并不难，关键是**下载位置**：

1. 旧设备上把下载目录整个拷出来（手机间用数据线/局域网传输均可）；
2. 新设备装好 Anikku 并恢复备份；
3. 在 **More → Settings → Downloads** 里把下载位置指向拷贝过来的那个目录；
4. 应用识别到目录结构后，已下载剧集会自动接回对应条目。

所以换机前顺手记一下自己当前的下载路径，能省一次试错。

## 四、自动备份：强烈建议开着

官方把自动备份列为强烈建议项（尤其预览版用户，预览版更容易崩溃丢数据）。开启方式：

1. **More → Data and storage**；
2. 设置**备份频率**（Backup frequency），按天/按周等自选；
3. 到点后应用自动在指定位置生成备份。

配合云盘可以实现跨设备备份文件同步：官方文档给的思路是用 Autosync for Google Drive 这类自动同步工具把备份文件夹同步到云端，换机时从云端取最新备份恢复即可；熟悉 FolderSync 或 Tasker 的用户也可以用它们搭同样的链路。另据官方更新说明，较新的版本加入了 WebDAV 同步服务，你的版本有没有这个选项以应用内设置为准（本文对应版本为 0.1.5）。

## 五、从 Aniyomi / 其它分支迁移到 Anikku

Anikku 与 Aniyomi、Mihon、Komikku 等分支的包名不同，可以共存安装，不需要卸载旧的。迁移路径：

1. 在旧应用里按第一节创建备份（`.tachibk` 文件）；
2. 装好 Anikku（安装事项见 [下载与安装教程](下载与安装教程.md)）；
3. 恢复前先做两件事：登录你用过的追踪服务、把备份里列出的扩展先装好；
4. **More → Data and storage** 里选恢复，选中备份文件。

跨分支恢复的已知限制（官方文档明示）：各分支有自己的专属设置，备份里存的这些分支特有设置在 Anikku 里恢复不了，会丢失；核心数据（书架、进度、分类、历史）不受影响。

## 六、恢复后核对清单

恢复完成不代表搬家结束，逐项确认：

- [ ] 书架条目数与旧设备一致；
- [ ] 追踪服务已重新登录并同步一次进度；
- [ ] 扩展全部重装、源能打开（打不开去 [常见问题排查](常见问题排查.md)）；
- [ ] 下载位置指向正确、已下载剧集能离线播放；
- [ ] 立即手动做一次新备份（确认新设备上的备份链路是通的），然后按第四节开自动备份。
