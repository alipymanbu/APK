# JuicyChat 常见问题与故障排除

> 本篇汇总 JuicyChat 实际使用中最常碰到的几类故障：回复重复、空白消息、角色拒答、角色看不到、图片找不到，以及出问题时该去哪找官方。

## 一、回复总是重复

官方给的处置顺序：

1. **从重复开始的地方往后删消息**，别让重复句留在上下文里；
2. **换模型**试，优先试 16K 的那批；
3. 换了模型还重复，就**手动编辑**回复里重复的字句；
4. **主动把话题引开**，别用很短的回复应付——你的回复越短，越容易被带进循环。

## 二、角色突然回空白消息

按顺序试：

1. **保存记忆再重新加载**，让对话重启一遍；
2. 换一个模型聊几句，再换回原来的；
3. 检查上下文里有没有问题内容（违规或异常格式的内容会影响后续生成质量）；
4. 安卓设备上这可能与格式兼容性 bug 有关——以上都无效就通过官方渠道反馈，附上机型。

## 三、角色拒绝聊某些话题

分两种情况，处理方式完全不同：

| 情况 | 原因 | 能不能解 |
| --- | --- | --- |
| 标了 SFW 的角色拒绝敏感内容 | SFW 角色被严格限制，AI 和用户双方都绕不过 | 解不了，这是设定 |
| 未标 SFW 的角色也拒答 | 模型状态问题 | 可解，见下 |

未标 SFW 的角色无故拒答时，官方给的解法：

1. 把聊天里那句拒绝的话**删掉**；
2. **换一个模型**（比如从 Mango Tango 换到 Passion Fruit），聊几句；
3. 再换回原模型。

## 四、为什么别人的角色列表很长，我只看到几个

四种原因，逐一对照：

1. 你看不到的角色被作者设成了 **Unlisted（不公开列出）或 Private（私密）**——本来就看不见，正常；
2. 你的 **NSFW 开关没开**——去个人主页的设置里打开；
3. 这些角色**被你拉黑过**——黑名单里还挂着；
4. **你没登录**——未登录能看的内容范围小得多。

## 五、聊天里生成的图片去哪看

分两类，位置不同：

- 角色作者**设计添加**的图片：只出现在**聊天记录**或**记忆**里；
- **你自己生成**的图片：在该角色的「My Photos」里。

找不到图先想清楚是哪一类，再去找对应位置。

## 六、角色记不住前面说过的事

先把官方给的手段用满：

1. **把你的关键信息写进 Persona 卡**（名字、身份、重要设定）——这比指望对话记忆可靠得多；
2. 重要剧情节点**保存记忆**，下个会话加载回来接着聊；
3. 长对话换 **16K 模型**，上下文更长，丢前文的概率低一些；
4. 回复别只用「嗯」「然后呢」应付，信息量太小的对话最容易被模型带偏。

有用户反馈会话拉得特别长时记忆会漂移（聊过的事再问就忘了），这类情况解法是**开新会话、开场把关键设定复述一遍**，别在一条越拉越长的会话里硬续。
