## 一、安装前先确认三件事

JuicyChat（官方写作 JuicyChat.AI）是一款 AI 角色聊天应用，你可以在里面和预设角色对话，也可以自己创建角色，支持文字与语音聊天。它有网页版和手机 App 两套，本篇只讲安卓 App 的安装。

动手前先核对这三件事：

| 事项 | 说明 |
| --- | --- |
| 安装包版本 | 本页网盘里的版本为 v1.5.2（2026-09-23 采集），安装包约 15.59M |
| 安卓版本 | 官方 wiki 未标明最低系统要求，安装失败时先确认系统不是过老的安卓版本，以官方页面为准 |
| 存储空间 | 预留至少 100MB 空闲空间，给安装包本体与安装过程产生的缓存 |

安装包核对信息（下载后可与下表对照，确认拿到的是同一份文件）：

| 字段 | 值 |
| --- | --- |
| 版本 | v1.5.2 |
| 包名 | com.headphone.latency |
| 大小 | 15.59M |
| MD5 | D209D263CB0B5E90243A37C005A316BD |

## 二、从夸克网盘拿安装包

安装包放在夸克网盘里，获取步骤：

1. 打开 [JuicyChat 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2d3429c91dd6)；
2. 把文件**转存到自己的夸克账号**（不转存直接下载会受限）；
3. 在自己的网盘里找到转存后的 APK 文件，下载到手机。

## 三、安装步骤

安卓默认不允许安装应用商店之外的安装包，所以第一次装要先放开权限：

1. 在手机上点开下载好的 APK 文件；
2. 系统弹窗提示「不允许安装未知应用」时，选择**允许来自此来源的应用**（不同品牌手机入口名称略有差异，一般在 设置 → 安全 或 安装界面的弹窗里）；
3. 回到安装界面，点「安装」，等进度条走完；
4. 装完点「打开」，或回到桌面点 JuicyChat 图标。

如果你的手机装完点开没反应，先重启一次再试；仍不行看文末的排查指引。

## 四、首次启动：年龄验证与偏好选择

第一次打开 JuicyChat，会先经过两步：

1. **年龄验证**：确认你已满 18 周岁（这是一款面向成人的 AI 聊天应用，未满龄不该使用）；
2. **选择你感兴趣的对象性别**：这一步影响推荐给你的角色。

过完这两步就到了登录界面。注册方式有四种、且不同方式注册的账号互不相通，建议先看 [注册登录与账号管理.md](注册登录与账号管理.md) 再动手注册，免得选错方式后两边数据对不上。

## 五、装不上或打开就闪退

按出现顺序排查：

1. **安装被拦**：回到「允许来自此来源的应用」检查开关是否真的打开；
2. **提示解析失败**：多半是下载不完整，删掉安装包重新下载一遍，再核对一次 MD5；
3. **存储不足**：清出空间后重试；
4. **打开就闪退**：重启手机后单独开这一个应用试一次；仍闪退则记录手机型号与系统版本，去官方渠道反馈（渠道列表见 [常见问题与故障排除.md](常见问题与故障排除.md)）。

想先在浏览器里体验、不急着装 App，也可以直接访问官网 `https://www.juicychat.ai/` 用网页版，账号体系与 App 是同一套（但登录方式要选同一个，原因见注册那篇）。
