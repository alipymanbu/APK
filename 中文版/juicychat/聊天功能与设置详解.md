## 一、聊天设置面板里有什么

在对话里打开 Chat Settings，能调的项目包括：聊天模型、回复语言、Temperature（温度）、单条回复最大长度、JuicyCoin 余额显示、场景卡（Scene Card）。下面逐项说清楚每一项改了之后会有什么体感差别。

## 二、模型怎么选

JuicyChat 提供多种模型，官方的分类大致是：通用对话、深度推理、创意写作三类，不同模型的回复风格、能力与支持的语言都不一样。

选择思路给你一张对照表：

| 你的场景 | 适合的模型方向 |
| --- | --- |
| 沉浸式角色扮演 | 官方标注适合 roleplay 的模型 |
| 长篇故事创作 | 创意写作向 |
| 追问细节、讲逻辑 | 深度推理向 |
| 要快、回复短平快 | 轻量快速向 |

两个实用细节：

1. 部分模型有具体的代号（如官方 FAQ 里出现的 Mango Tango、Passion Fruit），切模型是解决「重复回复」「无故拒答」的第一手段（见 [常见问题与故障排除.md](常见问题与故障排除.md)）；
2. 官方还有标注 16K 的模型，上下文更长，长对话出现重复时值得先换它试。

注意：模型不同，支持的语言与功能也不同，切换后如果某项设置失效，先回到设置面板确认一遍。

## 三、让角色说中文

两条路：

1. **设置里选**：在 Chat Settings 的回复语言（Response Language）里直接选中文。官方称目前支持最多 16 种语言，但具体某个模型支持哪些语言要以该模型实际可选列表为准；
2. **对话里直接说**：发一句「请用中文回复我」，角色一般会照做。

推荐先用第一种；遇到切了语言仍夹英文的模型，两种方法叠加使用。

## 四、Temperature（温度）怎么调

温度控制回复的「随机程度」，调高调低的差别如下：

| 温度 | 回复倾向 | 适合 |
| --- | --- | --- |
| 调高 | 更有创意、更多变化、更难预测 | 想要天马行空的角色扮演 |
| 调低 | 更稳定、更一致、更有逻辑 | 想要可控、不跑偏的对话 |

拿不准就先不动它，遇到「回复总是出戏」再往低调，遇到「对话越来越无聊」再往高调。

## 五、Persona 卡与场景卡

- **Persona 卡（Persona Card）**：定义「你是谁」——名字、背景、说话风格。填了之后 AI 会记住这个身份来跟你对话，避免每次都从零自我介绍。多角色多剧本的玩家建议每个剧本配一张。
- **场景卡（Scene Card）**：聊天背景图。可以用系统默认图、角色作者做的图，也可以换成你自己生成的图，在 Chat Settings 里开关。

另外设置里还有一个「JuicyCoin 余额显示」开关，打开后聊天界面会直接显示余额，方便盯着消耗（JuicyCoin 的用途与获取见 [JuicyCoin与会员订阅指南.md](JuicyCoin与会员订阅指南.md)）。

## 六、聊天里能做什么

| 功能 | 说明 |
| --- | --- |
| 多轮对话 | 常规连续聊天，上下文随对话累积 |
| 消息编辑 | 你和角色的消息都可以改，改完对话从那里重新往下走——修「写崩了」的剧情就靠它 |
| 图片 / 视频 / 语音生成 | 聊天内可直接生成，官方提供动作与姿势模板，也可以自己写描述 |
| 历史记录保存 | 会话可以回看、继续 |

生成后的图片去哪找，官方口径分两类：

1. **角色作者设计添加的图**：只出现在聊天记录或记忆里；
2. **你自己在聊天中生成的图**：在该角色的「My Photos」里查看。

改消息、删消息除了修剧情，也是排障手段：回复开始重复时，从重复处删起（完整步骤见 [常见问题与故障排除.md](常见问题与故障排除.md)）。

## 七、评测里提到、官方文档着墨不多的功能

有第三方评测提到两个进阶功能，官方 wiki 的聊天篇没展开写，是否可用取决于你的版本与档位，以应用内实际界面为准：

- **Thought Bubble（内心独白）**：在角色回复之外，额外显示角色「没说出口」的情绪反应与想法，评测称有多种情绪模式可切换——喜欢揣摩角色心理的玩法值得找找这个开关；
- **多角色群聊**：让多个 AI 角色同时参与一个对话，跑群像剧情用。

找不到入口的话，先确认自己的额度与档位，再去官方 Discord 问一句，比瞎翻设置快。
