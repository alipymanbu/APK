## 一、JuicyCoin 是干什么用的

JuicyCoin 是平台内的消耗货币，官方列出的用途：聊天消耗、生成图片、解锁图片、生成语音、抽奖、兑换道具等。简单说，你在聊天里用的每一项生成类功能，背后大多要扣它。

先花完免费额度再考虑充值，是省钱的正确顺序。

## 二、不花钱怎么攒 JuicyCoin

官方给的免费获取途径：

| 途径 | 说明 |
| --- | --- |
| 每日登录 | 每天登录签到有奖励 |
| 任务奖励 | 完成平台任务 |
| 邀请好友 | 拉新有奖励 |
| 内容分成 | 你发布的内容被消费，可获分成 |

前三项是人人可做的日常动作；第四项只对发布内容的创作者有意义。

## 三、会员档位与升降级规则

会员按月付 / 年付分档，官方文档里出现过的档位名包括 Premium、Deluxe、Diamond（具体在售档位与价格以官网订阅页为准，这里只讲规则；各档价格与权益的对照见 [免费额度与付费档位对比.md](免费额度与付费档位对比.md)）。

**官方明确支持的差价升级路径**：

| 从 | 到 | 是否支持 |
| --- | --- | --- |
| 年付会员 | 更高档年付 | 支持 |
| 年付会员 | 同档年付（续费） | 支持 |
| 月付会员 | 同档年付 | 支持 |
| 月付会员 | 更高档年付 | 支持 |
| 月付会员 | 更高档月付 | **不支持** |
| 任意 | 更低档 | **不支持降级** |

两条实操结论：

1. 月付想换个月付的高档位：官方给的解法是先取消当前订阅，等本期到期后再重新订高档位；
2. 在网页端买更高级月付套餐会**立即生效**（不是下个月），改档尽量放在订阅期末尾操作，避免重复扣费。

## 四、怎么退订

按你订阅的渠道分两条路：

**App Store（iOS）订阅的**：

1. 打开 iPhone / iPad 的「设置」；
2. 点顶部你的 Apple ID；
3. 进「订阅」；
4. 找到对应订阅，点「取消订阅」并确认。

**网页端订阅的**：进个人主页（profile）→ 点 Manage subscription → 按提示操作。

取消后不会立刻失去权益：**本期计费周期结束前你仍能用会员功能**，到期后不续费、权益停止。

有评测站汇总的用户反馈提到过「取消后仍被扣费」的情况，所以取消完多一步：确认拿到了取消成功的提示，并在下个账单日核对一次扣费记录；有异常带收据去 Discord 开工单（详见 [免费额度与付费档位对比.md](免费额度与付费档位对比.md) 第四节）。

## 五、支付失败的常见原因

官方排查清单：

1. 你所在的国家 / 地区限制了该支付方式；
2. 开着 VPN（关掉再试）；
3. 支付信息填错或漏填关键字段。

都试过仍不行，去官方 Discord 开工单（渠道见 [常见问题与故障排除.md](常见问题与故障排除.md)）。

## 六、付了钱还是显示免费版

按顺序处理：

1. 等几分钟再刷新页面——部分订阅生效有延迟；
2. 仍不行就是出了 bug，去 Discord 开工单，**附上注册邮箱与购买收据**，客服按这两样核对。
