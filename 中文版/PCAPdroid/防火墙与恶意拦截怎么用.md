## 一、三个付费功能是什么

抓包解决「看见」，这三个解决「挡住」。它们都是**付费功能**，基础抓包不受影响：

| 功能 | 做什么 | 关键限制 |
| --- | --- | --- |
| Firewall（防火墙） | 按应用 / 域名 / IP 建规则，拦掉不想让它联网的流量 | **root 抓包模式下不可用** |
| Malware detection（恶意检测） | 用第三方黑名单识别恶意连接，VPN 模式下还会直接阻断 | root 模式下只报不拦；抓包停止即失效 |
| Pcapng format | 把解密密钥嵌进抓包文件，Wireshark 打开即见明文 | 与 TLS 解密配合才有意义 |

恶意检测那一条官方自带免责声明：它**不是完整的设备安全方案**，检测能力与准确率不做保证。当成「多一双眼睛」用，别当成杀毒软件。

## 二、付费功能怎么激活

**从 Google Play 装的**：左侧抽屉 → **Paid Features**，直接内购，授权绑定 Google Play 账号，一次购买全设备可用。

**从 F-Droid 或 GitHub Releases 装的**（也就是非商店版），官方流程是四步：

1. **在 Google Play 版里买一个 unlock token**（v1.5.5 起提供）。**记下这个 token**——它不绑定设备，可以借别人的手机买，一个 token 最多生成 **3 个**授权码；
2. 装好非商店版，进左侧抽屉 **About（关于）** 页，抄下本机的 **installation ID（安装 ID）**；
3. 到 [pcapdroid.org/getlicense](https://pcapdroid.org/getlicense) 用 token + installation ID 生成授权码；
4. 回到 About 页，把授权码粘进 installation ID 下方的输入框，完成。

**哪些操作会让授权失效**：卸载重装、恢复出厂、刷机——这些都会让 installation ID 变化，变了就得用 token 重新生成一个授权码（token 本身不会失效，但一个 token 一共只能生成 3 个授权码）。另外**装测试版（beta 渠道）不需要单独买**：只要官方正式版还在设备上、且已购买，beta 版可直接用这些付费功能。

## 三、防火墙：建规则、看拦截、撤规则

**建规则**：在 Connections 列表**长按一条连接 → 选 block**，可以按应用、按 IP、按域名拦。域名规则的边界要记清：

- 拦 `example.org` 这种**二级域名**，会连带拦掉它的全部子域（`some.example.org`、`img.example.org`）；
- 但拦 `another.example.org` 这种**更深层的域名**，不会连带 `yet.another.example.org`——子域连带只对二级域名生效。

在 **Apps 视图长按某个应用**也能直接拉黑它，被拦的应用图标旁会带 ban 标识。

**看拦截**：右上角漏斗 → **Blocked by firewall**，只看被拦的连接；左侧抽屉的防火墙页有两个标签：

- **Status**：拦截总数、最后一次拦截时间；点卡片看拦截明细；顶部开关可**运行时一键开/关**整个防火墙；菜单里还有 **block newly installed apps**——新装的应用自动进黑名单、立刻拦；
- **Blocklist**：当前生效的全部规则，长按多选删除，也能**导出成文件**备份或分享给别人。

**撤规则**：长按被拦的连接 → **unblock**，可以永久移出黑名单，也可以给个**宽限期**（几小时后自动重新拦）——这个设计适合「暂时放开、过会儿再关」的场景。

**拦了不等于没网**。安卓上这几件事拦不住，别指望防火墙全包：

1. **DNS 解析仍然会发生**——名字解析由系统 `netd` 代做，分不清是哪个应用问的；
2. **可能仍能走 Google 服务通道**（进程间通信），比如照常收推送、照常显示广告；
3. **仍会展示本地缓存内容**（缓存过的网页、图片）；
4. **仍可能通过系统的下载管理器发起下载**。

另外防火墙还有个**白名单模式**（1.6.0 起）：默认全拦、只放行自己列过的应用——适合想把某个应用的联网能力限制成「只留我明确放行的那几个」的场景。

## 四、恶意检测：黑名单与误报

开了之后，抓包运行期间它会拿连接去对**第三方恶意域名/IP 黑名单**，命中就通知你；默认 VPN 模式下还会**直接阻断**这次通信（root 模式只报不拦）。

**状态页**（左侧抽屉 → Malware Detection）能看到：

- 绿勾 = 本次抓包没发现恶意连接，红标 = 发现了；
- **Updated blacklists**：黑名单更新成功数 / 总数——**黑名单每天自动更一次**，个别下载失败可在 Blacklists 标签手动刷新；
- **IP / Domain rules**：实际生效的规则条数（重复规则只算一次，所以有的黑名单显示 0 条是正常的）。

**自测**：开着抓包访问 `www.internetbadguys.com`（一个专门用来触发安全告警的测试站），正常应该弹出通知，点通知能看到是哪个应用、哪个域名/IP 触发的。

**误报处理**：长按那条被误判的连接 → 加入 **Whitelist**，可以放行单个 IP、单个域名，也可以整个应用放行。误报清单在 Whitelist 标签里管理。

**注意数据是易失的**：恶意连接的记录**停止抓包就没了**，要留证据得当场导出（见[抓包结果怎么看.md](抓包结果怎么看.md)）。

## 五、Pcapng 格式：给解密分析省一步

普通的 `.pcap` 抓包解完密，密钥要单独存一份 `.keylog`，Wireshark 里还得先配路径再开文件（步骤在[导出PCAP并用Wireshark分析.md](导出PCAP并用Wireshark分析.md)）。买了 Pcapng 格式后，密钥**直接嵌进 `.pcapng` 文件**，Wireshark 打开就是明文，不用配任何东西；同时还能存应用 UID、包方向这类元数据，配合官方的 `pcapdroid.lua` 插件在 Wireshark 里按应用过滤。

购买后在 PCAPdroid 的偏好设置里开启。
