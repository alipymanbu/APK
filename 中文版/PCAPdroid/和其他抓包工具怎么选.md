## 一、先确定你要看的是哪一层

选工具前先问自己要什么，不同答案对应完全不同的路线：

| 你想知道的事 | 该走的路线 |
| --- | --- |
| 手机上**哪个应用连了哪里、传了多少** | 本机 VPN 类工具（PCAPdroid 属于这一类） |
| 某个接口**请求和返回的具体内容** | 能解密的方案：本机 VPN 类 + 解密，或电脑上的代理工具 |
| 网络层的**原始包、包长、时序、TCP 行为** | 电脑上用 Wireshark 抓网卡，或手机 root 抓包模式 |
| **别的设备**（电脑、摄像机、另一台手机）的流量 | 抓它所在的网络出口（电脑 Wireshark / 路由器镜像），手机工具管不到 |

一个顺手的组合是**手机抓 + 电脑分析**：PCAPdroid 负责在手机上采，导出 PCAP 后拿到电脑的 Wireshark 里细看——这条链路官方文档直接支持（做法在[导出PCAP并用Wireshark分析.md](导出PCAP并用Wireshark分析.md)）。

## 二、几条路线的硬差异

| | PCAPdroid 这类本机 VPN 工具 | 电脑代理工具（Charles / Fiddler 一类） | 电脑 Wireshark |
| --- | --- | --- | --- |
| 要不要 root | 不要 | 不要 | 不要（但要能碰到那块网卡） |
| 要不要电脑 | 不要，手机上就能干完 | 要，手机和电脑得在同一网络 | 要 |
| 手机侧怎么配合 | 只需授权一次 VPN | 要在 Wi-Fi 设置里填代理地址与端口 | 手机要么连电脑热点、要么同一 Wi-Fi 抓镜像 |
| 抓到什么 | 本机所有应用的连接与流量 | 走代理的那部分流量 | 网卡上经过的所有包 |
| 看明文 | 要开解密，且受证书限制 | 要装证书，同样受证书限制 | 要 keylog / 明文流量 |
| 导出 | PCAP / Pcapng / HAR | 会话文件、HAR | 原生 PCAP |

几个容易混淆的点：

- **代理工具改的是「流量往哪走」**——应用不认代理、或绕开代理直连时，代理那边就是空的；本机 VPN 类改的是系统路由，应用没法绕开它，所以「抓得到连接」这件事上更稳。
- **两条路线在「看明文」上是同一堵墙**——安卓 7 以上的目标应用默认不认用户装的证书，谁来抓都一样，差别只在后续给不给得出应对办法（见[HTTPS加密流量怎么解密.md](HTTPS加密流量怎么解密.md)）。
- **安卓上没有官方 Wireshark**——手机端工具都做不到 Wireshark 那种网卡级视角，要那份视角就得回到电脑（或用 root 抓包模式，代价见[导出PCAP并用Wireshark分析.md](导出PCAP并用Wireshark分析.md) 第六节）。

## 三、同类手机工具的差别

都是「免 root + 本地 VPN」的手机抓包 App 之间，差别主要在两处：

- **落不落盘**：PCAPdroid 默认 No Dump（只在内存里分析，进程一停数据就没了），要文件得先选导出模式；另一些同类 App 默认就保存会话。**选型时把「我会不会需要回头再看」当成第一个问题。**
- **出口在哪**：PCAPdroid 的定位是把流量导出给 Wireshark 做进一步分析（有评测把它归为「最接近免 root 版 Wireshark 方案」的一类）；有的同类工具界面更简单、只做手机上看一眼十六进制或文本，胜在上手快、败在没法把数据拿去电脑深挖。

差别不是功能多少，而是**你的数据最终停在哪**：只在手机上瞄一眼，简单工具就够；要把会话存档、导出、在电脑上交叉验证，就得选能出 PCAP 的那类。

## 四、什么时候该换工具

出现这几种情况，说明问题不在工具而在路线：

1. **要改包、断点、把请求改了重发** —— 这是代理工具的活，PCAPdroid 只做观测，不改写流量。
2. **要抓的是一台不装 App 的设备** —— 换成在电脑上抓它所在的网络。
3. **要分析 TCP 握手、包长分布、重传这类细节** —— 非 root 抓出来的包头是改写过的（[导出PCAP并用Wireshark分析.md](导出PCAP并用Wireshark分析.md) 第六节列了偏差清单），上电脑或开 root 抓包。
4. **解密反复失败、目标应用也跟着打不开** —— 先按[HTTPS加密流量怎么解密.md](HTTPS加密流量怎么解密.md) 判断是哪一类原因，判断不了就先停下，别反复装证书折腾（应用本身可能因为检测到代理而拒绝工作）。
5. **只是想知道「谁在联网」** —— 那根本不需要抓包，系统设置里的流量统计与权限页就能给个大概，抓包是给更具体的问题用的。

工具选对之后，真正花时间的是过滤与验证（[抓包结果怎么看.md](抓包结果怎么看.md)），不是把包抓下来这一步。
