## 一、添加步骤

1. 在桌面**长按空白处** → 选「小组件 / Widgets」。
2. 在列表里找到 Windy，挑一个样式。
3. 长按拖到桌面，松手后按提示完成配置（选地点、给权限）。不同品牌手机的小组件入口略有差异，找不到时在小组件列表里直接搜「Windy」。

## 二、权限按官方社区的口径给全

官方社区置顶的小组件问题帖里，工作人员给出的完整前置条件是：

1. **开启 GPS**（定位总开关）；
2. 位置权限设为**「始终允许」**，不要只选「仅使用期间」；
3. 系统设置 → 应用 → Windy → 电池，设为**「无限制 / 不受限制」**；
4. 添加小组件的过程中若弹出权限设置页，把开关全部打开，再点添加按钮。

四步里任何一步没做，小组件都可能一直转圈不刷新。

## 三、不刷新时的修复顺序

按代价从小到大来，前一步有效就停：

1. **点小组件上的菜单手动刷新** —— 小组件右上角有三点菜单，点开刷新一次；
2. **重启手机**，重启后先打开一次 Windy 主程序再看小组件；
3. 系统设置里对 Windy **清缓存**后重开；
4. **卸载重装**（官方工作人员给过的完整顺序）：卸载 → 重新安装 → 开 GPS → 重新添加小组件并给全权限；
5. 仍不刷新：带上**机型 + 系统版本**到官方社区的小组件置顶帖反馈（[community.windy.com](https://community.windy.com/)）。

## 四、小组件异常耗电的取舍

有用户在社区反馈「小组件长期转圈 + 耗电明显升高」，卸载后耗电恢复正常 —— 这是单一用户的反馈，官方未就此给出结论。你可以这样处理：添加小组件后留意一两天耗电统计，异常就先把小组件移除观察；**Windy 本身不依赖小组件运行**，移除不影响 app 内功能。

## 五、iOS 端的对应情况

iPhone/iPad 也有 Windy 小组件；按官方 v49 公告，iOS 小组件已支持更多高分辨率本地模型（北美 HRRR/HRDPS/NAM、欧洲 UKV/AROME/ICON/ALADIN、亚洲 MSM、澳洲 ACCESS）。CarPlay 上则可以加雷达与预报小组件（v47 公告口径）。
