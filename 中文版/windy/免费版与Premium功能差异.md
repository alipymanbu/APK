## 一、免费版能用的部分

Windy 的主干功能不需要付费，装完即用（按官方公告整理）：

1. **全球预报模型**：ECMWF、GFS、ICON 等全球模型都能看，点预报、时间轴、图层切换全部开放。
2. **飓风追踪（Hurricane Tracker）**：官方明确「对所有人免费、无限制」，各模型的飓风情景都看得到。
3. **雷达与卫星**：Radar+ 的 1 小时影像免费；6 小时、12 小时影像与 365 天回放档案属 Premium（官方 v43 公告）。
4. **风详情**：单点风预报免费看 6 天。
5. **实况警报（Live Alerts）**：雷暴、降雨、热带气旋、CAP 官方警报等提醒在免费版可用（见[预警提醒设置教程.md](预警提醒设置教程.md)）。
6. **区域模型**：HRDPS、ALADIN 等区域模型免费可用，但更新频率较低（每天 2 次）。

## 二、Premium 解锁的部分

以下功能需要订阅（按官方 v43/v47/v49 公告与官方文章整理，具体以应用内当时说明为准）：

| 功能 | 免费 | Premium |
| --- | --- | --- |
| 15 天延长预报（AIFS，第 11~15 天） | 无 | 有 |
| 风详情天数 | 6 天 | 10 天 |
| 雷达/卫星回放档案 | 1 小时影像 | 6h/12h 影像 + 365 天档案；卫星历史滑块可回看 24 小时 |
| 模型更新频率（部分区域模型） | 每天 2 次 | 每 6~7 小时 |
| 潮汐预报 | 无 | 有 |
| 路线规划 Route Planner | 无 | 有（支持 ICAO/IATA 代码搜航线） |
| 3D 地球（Premium 3D globe） | 无 | 有 |

## 三、订阅渠道与价格

1. **两个正规入口**：应用内订阅，或在 [www.windy.com](https://www.windy.com/) 官网订阅。官方社区工作人员解释过，不同渠道（应用商店、官网支付）的价格不完全一致，与各渠道费率和地区税费有关。
2. **价格以当时显示为准**：订阅价随平台、地区、时间变化，本文不写死金额 —— 以你打开订阅页时界面显示的金额为准。
3. **警惕第三方标价**：第三方应用商店页面上的价格、促销信息不一定代表官方定价，不要以它作为购买依据。
4. **网盘安装包与订阅的关系**：订阅能力依赖官方结算渠道。你装的是网盘里这份直接下载的包时，应用内购买入口能否正常走通以实际界面为准；走不通就用官网渠道订阅，订阅绑定到哪个账号、如何与应用内登录对应，以官方说明为准。

## 四、要不要开，按这几个判据

1. 你只看未来 1~2 天的天气、用全球模型做判断 —— 免费版已覆盖。
2. 你需要回放过去 6 小时以上的雷达/卫星、看 11~15 天趋势、查潮汐、跑航线规划 —— 这几项才真正需要 Premium。
3. 拿不准值不值，先用免费版把[天气图层与预报模型使用教程.md](天气图层与预报模型使用教程.md)里的功能用一遍，确认哪些是自己天天要看的，再决定订阅。
