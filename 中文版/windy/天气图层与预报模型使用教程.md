## 一、先建立一个基本认知：地图上显示的是预报，不是实测

你在 Windy 地图上看到的风、雨、温度等彩色图层，来自数值天气预报模型的计算结果，不是传感器的实时读数（实况另有卫星、雷达图层）。官方也专门解释过这一点：比如风图层显示的是离地 10 米高度的**平均风速**，从图上读不到阵风峰值，要看瞬时极值得切到阵风图层。

操作上的对应关系：

1. **拖底部时间轴** —— 每一帧对应一个未来时刻，逐帧看天气系统往哪走。
2. **点地图任意位置** —— 直接打开那个点的详细预报（点预报），不用先搜地名。
3. **对照色标读数** —— 颜色只在同一图层内有意义，换图层后重新看色标。

## 二、常用图层速查

下表是日常最常切的几个图层及其数据口径（列出的来源与时效以官方说明为准）：

| 图层 | 你能看到什么 | 口径说明 |
| --- | --- | --- |
| 风 / 阵风 | 风向、风速的预报场 | 模型预报值；阵风是短时极大风，通常比平均风高 |
| 卫星 | 云图实况 | 全球合成图来自 NOAA 与 EUMETSAT，约 5~15 分钟一帧（因地区而异）；自 v47 起，Radar+ 雷达叠加在卫星图层里用开关打开 |
| 雷达 / 降水 | 实况降水回波与降水预报 | 雷达覆盖欧洲、美洲、亚洲、澳大利亚的大部分地区；官方在 v47 提到中国等地的雷达覆盖有改善，无雷达覆盖处以卫星为准 |
| 气温 / 气压 / 云量 | 对应要素的预报场 | 模型预报值，气压图层可看等压线形势 |
| 空气质量（Air Quality index） | NO₂、PM2.5、PM10、O₃ | 全球用 CAMS 40 km 分辨率，欧洲区域有 CAMS 10 km |
| 花粉与空气（点预报内） | 某地点未来几天的花粉与污染水平 | 在点预报里把「Display as」切到 Pollen&AirQ |
| 天气预警（Weather warnings） | 政府发布的官方警报 | 与提醒通知点开后看到的是同一处（见[预警提醒设置教程.md](预警提醒设置教程.md)） |
| 飓风追踪（Hurricane tracker） | 热带气旋路径与各模型情景 | 对所有人免费、无功能限制（官方口径） |
| 机场 | 跑道信息、风、METAR/TAF/NOTAM | 全球 5 万+ 机场，可按 ICAO/IATA 代码搜 |

v50.1 起每个图层带**说明气泡**（Layer description tooltips），不确定某个图层是什么时点一下就有解释。

## 三、预报模型怎么选

Windy 把多个国家和机构的模型放在同一点预报里切换，覆盖范围与更新频率各不相同（按官方商店介绍与 v43/v49 版本公告整理）：

| 模型 | 覆盖区域 | 出处 / 特点 |
| --- | --- | --- |
| ECMWF | 全球 | 欧洲中期天气预报中心；第 11~15 天的延长预报由 AIFS（AI 模型）补足，属 Premium 功能 |
| GFS | 全球 | 美国 NOAA |
| ICON / ICON EU / ICON-D2 | 全球 / 欧洲 | 德国气象局；欧洲有更高分辨率的区域版本 |
| NEMS | 全球 | 商店介绍中列出的全球模型之一 |
| AROME | 法国及周边 | 法国气象局的高分辨率区域模型 |
| UKV | 英国 | 英国区域高分辨率模型 |
| NAM / HRRR | 美国 | 美国本土的区域模型 |
| ACCESS | 澳大利亚 | 澳大利亚区域模型 |
| HRDPS | 加拿大与美国北部 | 加拿大气象局提供，2.5 km 分辨率，预报时效 48 小时 |
| ALADIN | 中欧 | 捷克水文气象局提供，2.3 km 分辨率 |

选模型的实际依据：

1. **看覆盖**：模型只在自己覆盖区内有值，跨区就换全球模型（ECMWF / GFS / ICON 三选一做基线）。
2. **看时效**：高分辨率区域模型通常只报未来 1~2 天，出门计划超过两天就以全球模型为准。
3. **看更新频率**：同一个模型，免费用户与 Premium 用户的更新频率可能不同 —— 例如 HRDPS、ALADIN 免费用户每天更新 2 次，Premium 每 6~7 小时一次（官方 v43 公告口径）。
4. **对比着看**：点预报里的「Forecast models」下拉可在多个模型间切换对照，别只信一个模型（v47 扩充了可选模型）。

## 四、点开一个位置之后能做什么

- **看该点的完整预报**：温度、风、降水、云、气压沿时间轴排开；风详情免费用户可看 6 天，Premium 可看 10 天（官方 v43 公告）。
- **换显示视图**：「Display as」里除常规预报外还有 Pollen&AirQ（花粉与空气质量）等视图。
- **搜索**：可以直接搜城市名，机场可以用 ICAO/IATA 代码（如 `KLAX`、`LAX`）。
- **收藏**：点星标把该位置加入收藏，下次从收藏直接进。
- **装插件**：Menu → Extend your Windy → Install Windy Plugin。v49 起手机端也能安装插件（需要登录账号，插件随账号云端同步）；同一路段下还能上传 KML、GPX、GeoJSON 路线文件在地图上显示。
- **航线规划**：Route Planner 支持在搜索栏直接输入起降机场的 ICAO/IATA 代码打开航线，该功能属 Premium（官方 v49 公告）。

## 五、v50.1 的几个顺手改进

网盘里这份 50.1.1 已包含这些改动：Home 按钮会记住你的缩放级别；Wind Trajectories 插件会记住上次的设置；图层说明气泡上线。升级到更新版本前，这些行为可直接照本节使用。
