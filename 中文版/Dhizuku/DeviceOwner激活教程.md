## 一、先明白「激活」到底在做什么

Android 只允许把「设备所有者」这一个位置交给一个应用，而且只在设备**没有账号、没有其他用户**时才允许设置。你做的激活，就是用一条 adb 命令把 Dhizuku 填进这个位置。填进去之后它就长期有效，**重启手机不会掉**，这是它和 Shizuku 最大的差别（见 [和Shizuku的区别.md](和Shizuku的区别.md)）。

激活完成后，你再登录账号、开分身都行 —— 前提是激活那一刻设备是干净的。

## 二、前置条件清单

逐条过一遍，任何一条不满足都会直接失败：

1. 设备上**一个账号都没有**（Google、小米、华为、企业邮箱、同步账号全算）；
2. **没有第二个用户**（应用分身、手机分身、访客都会创建）；
3. 设备所有者位置**没有被别的应用占着**（冰箱、小黑屋、Island 这类工具如果之前用 adb 激活过，就占着位置）；
4. 手机已开启**开发者选项 → USB 调试**；
5. 电脑装好 platform-tools（提供 `adb` 命令）并用数据线连上手机，弹出「允许 USB 调试」时点允许。

账号清不干净是最常见的卡点，包括「设置里看着空了、实际还残留」的情况，处理办法见 [激活失败报错怎么解决.md](激活失败报错怎么解决.md)。

## 三、方式 A：用电脑 adb 激活（通用）

1. 手机连电脑，在 platform-tools 目录打开命令行，先确认连上了：

```bash
adb devices
```

输出里有你的设备序列号、状态是 `device` 才继续。

2. 执行激活命令：

```bash
adb shell dpm set-device-owner com.rosan.dhizuku/.server.DhizukuDAReceiver
```

3. 看到这样的输出就是成功：

```text
Success: Active admin and device owner set to com.rosan.dhizuku/.server.DhizukuDAReceiver for user 0
```

4. 打开 Dhizuku，首页显示已激活 / 已取得设备所有者状态，即完成。

**多用户删不掉时的变体**：个别机型删不掉分身用户，可以试试把权限范围限定到主用户：

```bash
adb shell dpm set-device-owner --user 0 com.rosan.dhizuku/.server.DhizukuDAReceiver
```

这条路在部分设备上已经失效，报错就说明系统不放行，回到「先删掉其他用户」的正路（删除方法见 [激活失败报错怎么解决.md](激活失败报错怎么解决.md)）。删除的用户空间里装的应用会被卸载，动手前先想清楚。

**关于连接方式的两个补充**：

- 命令必须在一条 adb 会话里执行，所以 Android 11+ 的设备也可以走**无线调试**（开发者选项 → 无线调试 → 配对后 `adb connect`），不必用数据线；
- 手边没有电脑时，可以用**另一部手机 + OTG 线 + 任意 adb 客户端应用**执行同一条命令，效果与电脑一致。

## 四、方式 B：通过 Shizuku 激活

如果你已经跑着 Shizuku（无线调试或 root 启动都行），可以不连电脑：

1. 确认 Shizuku 本身处于运行状态；
2. 打开 Dhizuku，在激活方式里选择 **Shizuku** 选项，按提示授权；
3. 回首页确认激活状态。

找不到 Shizuku 选项时，先按 [shizuku.rikka.app](https://shizuku.rikka.app/) 的手册把 Shizuku 本身启动起来，再回到 Dhizuku 重进一次。这条路径依赖 Shizuku 正常运行，而 Shizuku 重启后需要重新启动 —— 激活**成功之后**则不再依赖它，Dhizuku 的设备所有者身份是持久的。

## 五、激活后该做什么

1. **双重验证再加账号**：除了打开 Dhizuku 首页看状态，再到 设置 → 安全 → 设备管理员 里确认 Dhizuku 在列表中**且无法停用** —— 关不掉才是设备所有者（判据细节见 [怎么停用和卸载.md](怎么停用和卸载.md)）。两处都对，再去设置里登录账号、重建分身 / 多用户。
2. **给应用授权**：打开需要它的应用（如冻结类工具），把工作模式切成「Dhizuku」，弹出授权框时点允许，具体见 [能配合哪些应用使用.md](能配合哪些应用使用.md)。
3. **别急着卸载 Dhizuku**：那些应用是向它借权限的，卸掉它，依赖它的功能会一起失效；部分占用设备所有者位置的应用，也要先移除身份才能卸载（见 [怎么停用和卸载.md](怎么停用和卸载.md)）。

## 六、想撤销时

设备所有者没有常规的「一键移除」入口，但 Dhizuku 应用内提供了撤销入口（Deactivate 停用）与关闭选项，走应用内撤销最省事；完整顺序与卸载前的依赖处理见 [怎么停用和卸载.md](怎么停用和卸载.md)。恢复出厂是最后手段，会清空数据，动手前先备份。
