## 一、解绑与撤回授权是两件事

- **删除好友（解绑）**：断开两人的绑定关系。关系没了，对方所有查看入口自然失效；
- **撤回授权**：不动好友关系，只在系统或应用里关掉某项权限——对方还在你的好友列表里，但对应数据立即断更。

只想暂时停掉位置共享时，撤回定位权限就够了，不必删好友。

## 二、删除好友的路径

官方隐私政策（2026 年 1 月版）标注的路径是：**我的 → 我的好友 → 好友详情 → 删除**。要更换匹配对象时，也是先在这里把旧好友删掉，再走新的匹配流程。

菜单位置随版本可能不同，找不到就按两个关键词在「我的」页里找：好友、删除。

## 三、撤回授权的四个入口

按力度从小到大排（路径取自官方隐私政策，菜单名以你那版界面为准）：

| 入口 | 路径 | 效果 |
|---|---|---|
| 应用内按好友调权限 | 我的 → 我的好友 → Ta 的权限 | 对单个好友收窄可见范围 |
| 应用内系统权限 | 我的 → 系统权限设置 | 跳到系统设置页关对应权限 |
| 系统权限管理 | 手机设置 → 隐私 → 权限管理 | 从系统层关掉定位等权限 |
| 清数据 | 手机设置 → 应用管理 → LinkUp → 存储 → 删除数据 / 清空缓存 | 本地数据清空（安卓通用行为，会退出登录） |

## 四、关掉之后对方会看到什么

- 定位关掉后，对方的地图上停留在你最后一次上报的位置，不再刷新；
- 若你们开了自动报备，「关定位」这类操作本身就在报备范围内（7 类事件里包含它）——对方可能会收到一条提醒，这一点心里要有数（这类提醒的机制见 [自动报备与手机使用报告.md](自动报备与手机使用报告.md)）；
- 通话统计、App 使用记录等依赖各自权限的项目，同步停止更新。
