## 一、耗电

定位共享要持续用 GPS，切到后台也保持连接，官方在应用介绍里自己就提示这比普通操作更耗电。几个降低影响的做法：

- 只在需要盯位置的时段保持共享，平时可以暂停定位共享；
- 把 LinkUp 加入电池优化白名单，避免系统杀后台导致轨迹断线；
- 想高频查看时插着电看。

## 二、权限与功能的对应

| 权限 | 不给 / 被收回会怎样 |
|---|---|
| 位置（建议始终允许） | 实时定位、轨迹、到达 / 离开提醒全失效 |
| 电话 | 通话统计拿不到 |
| 通知 | 收不到对方的动态提醒 |
| 悬浮窗 / 系统设置 | 锁机、锁屏提醒可能不生效 |
| 摄像头 / 麦克风 | 水印相机、实时语音不可用 |
| 通讯录 | 通讯录邀请好友不可用 |
| 传感器（计步） | 运动状态识别精度下降 |
| 自启动 / 关联启动（安卓） | 小组件与后台定位更新不及时，其余功能不受影响（官方隐私政策口径） |
| 日历写入 | 与通知权限一起用于接收消息推送，拒绝后推送不可用 |

系统升级、省电模式都可能悄悄收回权限，功能突然失灵先来这张表排查。

## 三、双向授权与隐私

- 官方在多处强调：所有定位、行程、手机使用记录功能都需要对方知情并明确同意，全程双向授权；
- 对方随时可以在自己手机上收回授权（关掉位置权限或解除绑定），你这边相应数据立即断更；
- 用户协议与隐私政策在官方渠道可见：[用户协议](https://link.tttick.com/business/protocol/user.html)、[隐私政策](https://link.tttick.com/business/protocol/privacy.html)（以官方站点当前内容为准）；
- 想主动停掉共享：删除好友与四个撤回授权入口的完整路径见 [解除绑定与撤回授权.md](解除绑定与撤回授权.md)。

## 四、订阅与付费

- 两端下载都免费，高级功能走订阅。iOS 端简介页标注过 1 个月 38 元 / 3 个月 68 元 / 12 个月 128 元的订阅价，内购列表里则出现过 ¥9.90、¥38、¥48、¥88、¥98 等档位——两处口径不完全一致，以购买页实时显示为准（截至 2026 年 9 月）；应用商店的用户评论里有「部分功能要会员」的反馈，付费前先确认自己要用的功能是否在免费范围内；
- iOS 自动续订要在到期前至少 24 小时手动关闭，入口在「账户设置 → 订阅」；
- 安卓端的付费形式以应用内提示为准。

## 六、功能没反应的通用排查

1. 先看绑定状态还在不在（对方可能已解绑）；
2. 再对照第二节的权限表逐项检查；
3. 权限都在就重启 App；
4. 版本差异：网上教程演示的可能是新版本界面，你那版（1.5.5）的菜单位置可能不同——先确认自己的版本号再照着找。
