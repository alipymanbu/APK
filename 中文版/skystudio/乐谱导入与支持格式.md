## 一、谱子从哪来

Sky Studio **本身不含在线谱库**——官方说明里明确写着它不提供分享谱子的网站。你手里的谱子通常来自这几个途径：其他玩家发给你的文件、玩家社区/交流群里共享的谱子文件，或者你自己照着视频扒下来编的（见 [编写乐谱与保存分享.md](编写乐谱与保存分享.md)）。

拿到的文件先看扩展名：`.txt`（JSON 或 ABC 文本）或 `.mid`，这两种是它认的。

## 二、导入步骤（应用内操作）

1. 首页点「打开乐谱」，进入后点右边的**文件夹按钮**；
2. 在文件浏览界面里找到你存放谱子的文件夹（比如「下载」目录）；
3. 点中要导入的谱子文件；
4. 选「练习」进入跟练，或选「编写」进入编辑；右上角播放键可先试听。

导入后谱子会出现在乐谱列表里（较新版本默认按时间排序，还带搜索栏），下次不用重新找文件，直接从列表加载。谱子攒多了就用搜索栏按名字捞，比翻目录快。

打开时一直转圈、卡在 Loading 不出来，多半是谱子与软件版本不一致——处理办法见 [常见问题与排查.md](常见问题与排查.md)。

## 三、谱子文件放哪个目录

应用在安卓上的专属目录是：

```text
Android/data/com.Maple.SkyStudio/files/Sheet        乐谱文件
Android/data/com.Maple.SkyStudio/files/Instruments   乐器音色文件
```

想手动把谱子放进 `Sheet` 目录再导入，需要文件管理器有该目录的访问权限——**较新的安卓版本对 `Android/data` 限制很严**，很多文件管理器进去是空的。碰上这种情况别硬找路径，直接用第二节的应用内文件选择，从「下载」等常规目录里选文件即可。

## 四、三种支持格式

| 格式 | 扩展名 | 特点 |
| --- | --- | --- |
| JSON | `.txt` | 与不少同好做的谱子工具互通，保留双层信息，**支持加密** |
| ABC1/5 | `.txt` | 纯文本、肉眼能读：`A1`~`C5` 共 15 个键，`.` 表示停顿延时 |
| MIDI | `.mid` | 音乐软件的通用格式，从别处导出的曲子多半是它；也能把谱子存成它交给 DAW 等音乐软件继续处理 |

几个实际会碰到的点：

- **想看懂或手改文本谱，读 [ABC1-5谱子格式怎么读写.md](ABC1-5谱子格式怎么读写.md)**——15 键记号、延时点、和弦与连按的写法都在那篇；
- **同名 `.txt` 可能是两种格式**：JSON 是一串结构化字符，ABC 是一行行音符字母，用文本编辑器打开看一眼就能分辨；
- **旧版 `.csst` 谱子仍能打开**：应用对乐谱格式向下兼容，早年流传的 `.csst`（加密）谱子在新版本里照样加载，不必先转换；
- **ABC 的音高体系与别的工具不同**：Sky Studio 按 `C4`~`C6` 的范围理解音名，跨工具转换谱子时如果整首高低不齐，在编写模式里用移调（transpose）功能拉回来（细节见 [ABC1-5谱子格式怎么读写.md](ABC1-5谱子格式怎么读写.md)）；
- **认不了的文件就转格式**：MIDI 与 JSON/ABC 互转靠谱子工具，别改扩展名硬骗应用——打开只会乱码，处理办法见 [常见问题与排查.md](常见问题与排查.md)。

## 五、分享谱子时的加密选项

保存时可以把 JSON 谱子加密。官方说明了这个功能的用途：**防止别人拿你的谱子去写自动化脚本、在游戏里自动演奏**。所以在社区、群里分享自己的谱子时建议打开加密；自己平时练习用的谱子开不开都行，打开后自己再加载需要输入密码，别把密码忘了。

加密的谱子在别的同好工具里同样读不了明文——分享前先想清楚对方用什么工具。
