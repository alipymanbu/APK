## 一、什么时候值得自己编

想弹的曲子网上没现成谱子、或者拿到的谱子错音一堆改不动，就自己编：跟着原曲听一句、按一句，谱子是你的，错没错你自己最清楚。编完直接进练习模式开练，全流程都在同一个应用里。

## 二、进入编写与录入音符

1. 首页「打开乐谱」→ 点右边的**编写**按钮进入编辑界面；
2. 用下方的琴键键盘按出音符，按完一个后点**右箭头**进到下一行继续；
3. 录的过程中随时点播放试听，不对就回去改。

没头绪时可以先导入一份别人的谱子当参照（见 [乐谱导入与支持格式.md](乐谱导入与支持格式.md)），照着改比从空白开始快。短曲、单声部的谱子也可以直接写文本——用 ABC 记法在记事本里敲，边听边改，流程见 [ABC1-5谱子格式怎么读写.md](ABC1-5谱子格式怎么读写.md)。

## 三、编辑工具

编写模式的工具集中在菜单里，都是片段级操作：

| 工具 | 用途 |
| --- | --- |
| 撤销 / 重做 | 改错了按撤销回退，不必手动补音 |
| 复制 / 剪切 | 副歌段落反复出现时，复制一段粘到后面，省得重录 |
| 擦除 / 删除 | 删掉打错的几个音或整段重来 |
| 双层系统 | 谱子分两层：主旋律一层、伴奏一层，叠着播放听和声效果 |
| 移调（transpose） | 较新版本的编辑工具里带移调，整段音高偏了直接拉齐（旧版没有，用 Pitch 参数代替试听） |

录入时还有两个能省力的设置：

- **作者与记谱人字段**：较早版本起谱子里就能填 author / transcriber（三个格式都支持），发谱子时标上自己或原扒谱人的名字，谱子传开了也带着出处；
- **物理键盘输入**：较新版本支持外接键盘，手机连蓝牙键盘或用平板的实体键盘敲音符，比手指点快——有键盘就开。

配合这些参数一起用：**BPM**（定全曲速度）、**音调（Pitch）**、**乐器**（换音色试听）、**节拍器**（边录边对节奏）。

## 四、保存与另存为

1. 录完点界面上的**三横线菜单**；
2. 选「保存」存回原文件，或「另存为」存成新文件——**编到一半先另存一份**，改崩了还能回退；
3. 保存后谱子进入乐谱列表，练习模式里直接加载。

保存的 JSON 格式会保留双层信息；另存为其他格式（ABC/MIDI）前想清楚：转出去再转回来，双层等信息可能有损失。

## 五、把谱子发给别人

谱子文件在应用目录里（`Android/data/com.Maple.SkyStudio/files/Sheet`，详见 [乐谱导入与支持格式.md](乐谱导入与支持格式.md)）。分享流程：

1. 保存后从列表或目录里拿到谱子文件；
2. **发布到社区、群里时打开 JSON 加密**——官方说明这个功能就是为防止别人拿你的谱子写自动化脚本、在游戏里自动演奏；
3. 加密谱子附上密码发给对方；对方需要装 Sky Studio 或兼容的谱子工具才能打开。

自己小范围传给朋友练习、不打算公开发的，开不开加密都行。

## 六、编完之后

谱子的用处最终落在弹熟：进练习模式，用 [练习模式使用技巧.md](练习模式使用技巧.md) 里的段落循环与隐藏按键把它啃下来，再回游戏里对着同样的键位演奏。
