## 一、什么时候需要看懂它

你收到的谱子文件如果用文本编辑器打开是一行行字母数字（不是一串花括号开头的结构化字符），那它就是 ABC1/5 格式。会读它有三个直接好处：拿到谱子不用导入就能**通读全曲**；发现个别错音**直接改文本**，比在编写模式里翻找快；甚至可以**从零手打一份**简单曲子。JSON 与 MIDI 也能导入，但都得靠工具才能看清内容。

## 二、记号基础

官方对这个格式的说明只有一句核心规则：`A1`、`A2`、…、`C4`、`C5` 这类记号**共 15 个，对应游戏里的 15 个按键**；`.` 表示**延时**（这一拍不弹、空过去）。

也就是说：

```text
A1 . C4 B2
```

读作：按 `A1`，空一拍，按 `C4`，按 `B2`。

## 三、同好工具通行的书写约定

Sky Studio 生态里的谱子工具（如 sky-music 的 Sheet Maker，其产物可导入 Sky Studio）在上述基础上还通行几条写法，读别人的谱子时会遇到：

| 写法 | 含义 |
| --- | --- |
| `B3 B4 B5`（空格分隔） | 三个独立的拍子，依次弹 |
| `A1A3A5`（连写无空格） | 和弦：同一拍同时按下这几个键 |
| `B4 . B5` | 中间空一拍 |
| `A3-B1-B3`（短横连接） | 快速连按，按键颜色从浅到深依次触发 |
| `C1C3 *2` | 这一小节重复 2 次 |
| `# …` | 歌词行，不影响弹奏 |

这些约定来自同好工具的文档与实际流通的谱子；Sky Studio 官方说明只规定了 15 键记号与 `.` 延时。**遇到读不懂的符号，以你手头这份谱子的来源说明为准**，别照别的工具硬套。

## 四、音高编号的两套约定（跨工具转换必看）

同一条音名，不同工具对八度编号的起点理解不同：

- **Sky Studio** 按 `C4`~`C6` 理解音域；
- sky-music 系工具默认从 `C1` 起算（`C1`~`C3`）。

后果：同一份谱在两个工具间来回转，**整首会整体错开几个八度**——听着不是偏高就是偏低。sky-music 的转换流程里对此有对应处理（导入时问是否整体移调，按 Sky Studio 的约定回答 `-3`）。在 Sky Studio 里补救更直接：把谱子放进练习或编写模式，用**移调（transpose）/ Pitch 参数**整体上下拉，拉到与游戏内乐器音域对上为止。

## 五、手打一份简单谱子

1. 手机或电脑上建一个纯文本文件（记事本即可）；
2. 按上面的约定敲音符，一拍一拍写，停顿用 `.`；
3. 存成 `.txt`（扩展名别带别的）；
4. 按 [乐谱导入与支持格式.md](乐谱导入与支持格式.md) 的步骤导入试听；
5. 听到错音就改文本再导，直到对上原曲。

适合短曲、单声部；多声部、带伴奏的曲子还是进编写模式用**双层系统**录更顺手，见 [编写乐谱与保存分享.md](编写乐谱与保存分享.md)。

## 六、ABC 与 JSON 怎么选

| | ABC1/5（`.txt`） | JSON（`.txt`） |
| --- | --- | --- |
| 人眼可读 | 是，一行行音符 | 否，结构化字符 |
| 手改成本 | 低，记事本直接改 | 高，容易改坏结构 |
| 双层信息 | 2.2.7 起支持 | 一直保留 |
| 加密 | 不支持 | 支持 |
| 适用场景 | 自己手写、快速校对 | 分享成品、需要加密时 |

自己练的谱、要反复改的谱用 ABC；定稿后要发到社区的，转存一份 JSON 并开加密（见 [编写乐谱与保存分享.md](编写乐谱与保存分享.md)）。
