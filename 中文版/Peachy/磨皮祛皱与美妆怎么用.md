## 一、这一篇解决什么问题

人像照的观感大半在皮肤与妆容上，但这类工具恰恰最容易修过头——磨皮磨到塑料感、美白白到失真。本篇按官方功能分类（Retouch 皮肤修饰、Makeup 虚拟妆容、Hairstyling 发型、Eye Enhancer 眼部）给出**先修瑕疵、再统一肤质、最后上妆**的顺序和力度判据。身体轮廓的调整在 [瘦身塑形效果怎么调.md](瘦身塑形效果怎么调.md)。

## 二、推荐顺序

```
选图 → 局部祛瑕疵（祛痘/祛皱/去黑眼圈）→ 整体磨皮与提亮 → 牙齿美白
     → 上妆 → 染发/发量 → 眼部调整 → 滤镜与调色 → 保存
```

顺序的道理：**局部瑕疵要在磨皮之前点掉**——先磨皮会把痘痘的边缘糊掉，祛疤工具反而对不准；妆容要等肤质稳定后再盖上去，否则底妆会盖住还没修的瑕疵。

## 三、皮肤修饰各工具怎么选

| 工具 | 官方定位 | 用法要点 |
| --- | --- | --- |
| 磨皮（Smooth Skin） | 模糊毛孔、纹理与肤色不均 | 强度从低档起，保留鼻梁与脸颊的高光颗粒 |
| 祛痘/祛瑕疵（Remove Blemishes） | 点掉痘印、斑点、泛红 | 逐点点击，不要整片刷 |
| 祛皱（Fix Wrinkles） | 淡化细纹与岁月痕迹 | 只压淡、不清零，全抹平会显假 |
| 去黑眼圈（Remove Dark Circles） | 消除眼下阴影 | 配合亮度调整，别只靠一层遮盖 |
| 牙齿美白（Whiten Teeth） | 精准提亮牙齿 | 对着笑容区域单独刷，别带到嘴唇 |
| 哑光（Matte Finish） | 去掉油光反光 | 只刷额头、鼻翼、下巴这三处出油区 |
| 群组人像（Group Photo Editing） | 一张合照里多张脸分别修 | 逐张脸选中再修，避免只修了前排 |

**力度判据**：把图放大到 100% 看鼻翼两侧——毛孔完全消失、皮肤像瓷面就是过了；留一点纹理、只把肤色修匀，才是耐看的档位。

## 四、虚拟上妆（Makeup）

官方提供两套入口：

- **妆容模板（Makeup Templates）**：一键套整套妆，适合快速出图；套完仍可逐项减淡。
- **单项工具**：粉底/遮瑕、修容、腮红、眼妆、唇膏分开调，唇形（Lip Shaping）还能单独改位置、比例与大小。

用法要点：**先选贴合原照片光线的模板，再把过浓的项往回拉**——唇膏与眼影是最容易显假的两项，默认档位偏浓时就减一档，以放大看不浮在皮肤上为准。

## 五、发型与发色

| 功能 | 作用 | 注意 |
| --- | --- | --- |
| 发量增加（Hair Volume Boost） | 增加头发蓬松度与自然回弹 | 与发际线调整一起做，效果连贯 |
| 发量密度（Hair Density Optimization） | 把稀疏处补厚 | 头顶分缝处最容易看出真假，强度宁低勿高 |
| 发际线修整（Hairline Refinement） | 微调发际线形状 | 每次只挪一点，边挪边缩小看整体 |
| 换发色（Hair Color Changer） | 试色、渐变与多色混合 | 先在发尾试色再上全头，浅色发上深色更稳 |

## 六、眼部增强（Eye Enhancer）

四个可单独调的项：**眼睛提亮、去黑眼圈、眼距调整、眼皮与眉弓控制**。眼距与眼皮属于结构改动，改完务必缩回整图看左右是否对称——单看局部容易越调越歪。眉弓高度与眼妆是联动的，先定眉形再上眼妆更省事。

## 七、收尾：滤镜与基础调整

妆面完成后用 **Adjust**（亮度、对比度、色温、阴影、锐化、暗角、HSL）与滤镜做统一。两条经验：

1. 滤镜放在最后，避免它把前面的妆色再叠一层偏色；
2. 肤色被滤镜带偏时，优先动 HSL 里的橙色通道，而不是回去重修妆面。
