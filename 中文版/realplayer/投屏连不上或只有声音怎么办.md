# RealPlayer 投屏连不上或只有声音怎么办

> Chromecast 投屏的三种失败形态：列表搜不到设备、连上了投不动、投出去只有声音没画面，逐条排查。

## 一、先把三个前提过一遍

投屏失败里有一大半不是故障，是前提没满足。开查之前先确认：

1. 手机和投屏设备（Chromecast / 电视）**接在同一个 Wi-Fi**，且不是「访客网络」——很多路由器的访客网络与主网络互相隔离；
2. 投屏设备已通电、已完成配网，电视信号源切到了对应 HDMI 口；
3. 手机上的 RealPlayer 与手机系统都是最新版。

投屏的基本操作（怎么点、怎么选设备）在 [手机与电脑互传与投屏教程.md](手机与电脑互传与投屏教程.md) 第四节，本篇只讲卡住之后怎么查。

## 二、设备列表里搜不到投屏设备

按成本从低到高：

1. **重启投屏设备**：把 Chromecast 从 HDMI 口拔下 → 拔掉它的电源线 → 等几秒插回。官方支持文档把这一步（power-cycle）列为连接类问题的首选办法。
2. **手机退出投屏入口再进一次**，让应用重新扫描网络。
3. **重启路由器**：设备长时间运行后组播（multicast）转发异常，手机就发现不了投屏器；重启后仍不行，进路由器管理页确认「组播 / IGMP」相关开关是开着的，AP 隔离（也叫「无线客户端隔离」）必须关掉。
4. **换一个网络验证**：用另一部手机开热点，手机和投屏设备都接这个热点——能搜到，说明原路由器的网络策略是根因，就在路由器上找隔离类设置。

## 三、连上了但投不出去，或一直转圈

- 电视端长时间运行会卡在「已连接但不收数据」的状态，处理办法同上：**拔电重启投屏设备**。
- **先排除其他应用干扰**：官方社区收到过多例反馈，装了广告拦截、杀毒类联网应用后投屏失效，卸掉或停用它们再试。
- 手机端确认 RealPlayer 是最新版，再重新发起一次投屏。
- 都无效时，到官方支持社区 [customer.real.com](https://customer.real.com/) 提新帖，把机型、系统版本、投屏设备型号写清楚。

## 四、投出去只有声音、没有画面

这是格式问题，不是连接问题：**Chromecast 对视频格式与码率有自己的支持范围**。官方给出的口径是——码率高于 **14 Mbps**、或编码不在 Chromecast 支持列表内的视频，直接投会出问题，需要先把视频传到云端，再从云端库投出去（云端会转成可投的格式）。

另有两条官方注明的边界（以支持页面当时说明为准，后续版本可能放开）：

- 存放在**外置 SD 卡**里的视频，官方明确说过目前无法直接投屏；
- 竖屏拍摄的视频投上去方向不对，官方称新版本已修复，且画面方向取决于拍摄时手机的握持方向。

想避开这些坑，最省事的路径是：**先把视频传到云端，再从云端投**——牺牲一点上传时间，换来格式确定能被接受。

## 五、什么时候该怀疑网络本身

投屏对家里 Wi-Fi 的状态很敏感，这些情况与应用无关：路由器连续运行多天未重启、同一网络下设备数量很多、手机离路由器太远信号弱。先把路由器重启一次、让手机靠近一点再试，能省掉大量无谓的应用侧排查。投屏恢复后怎么用，回到 [手机与电脑互传与投屏教程.md](手机与电脑互传与投屏教程.md) 第四节；其他播放类问题在 [常见问题与解决方法.md](常见问题与解决方法.md)。
