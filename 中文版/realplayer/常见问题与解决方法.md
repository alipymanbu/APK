## 一、播放时提示「格式不支持」或「无法解码」

按这个顺序排：

1. 换一个视频文件播——别的文件能播，说明是**这一个文件**的问题（编码太新、文件损坏、下到一半）；
2. 同一个文件换个播放器播——其他播放器也播不了，就是文件本身坏了，重新获取原文件；
3. 别的都能播、只有某种格式不行，就是**缺这种编码的支持**：把文件转成 MP4（H.264）再看，或换支持该编码的播放器。

安装包过旧也会漏掉新格式，先确认版本是不是最新（本篇系列对应的这一版是 1.6.0，官方商店页有更新就升）。

## 二、播放卡顿、频繁缓冲

- **在线内容**：先看网络——同一时间其他视频 App 流畅吗？都不流畅是你网络的问题；只有这里卡，试试切换 Wi-Fi 与流量，或等一会儿。
- **本地大文件**：高码率、高分辨率视频对手机性能要求高，只有某个文件卡，多半是文件规格超了手机解码能力；同一文件**固定时间点**卡，则是文件损坏或没下完整。
- **通用**：清一下后台、给手机腾点运行内存，再重开应用。

## 三、登录时提示「网络错误」或反复让你核对邮箱密码

**先分清是哪一类**：

- 报「网络错误」→ 按下面三步走：
  1. 先用手机浏览器开一个网页，确认网络通不通——浏览器都打不开，先修网络；
  2. 浏览器正常但登录仍报错，切换 Wi-Fi / 流量各试一次（有的网络会拦境外服务）；
  3. 还不行，稍后重试：服务端波动时登录会间歇失败。
- 提示**核对邮箱和密码** → 是凭据问题，官方列的几条都出在输入上：邮箱拼错、漏了 `@` 及其后缀、密码大小写不对（邮箱通常不区分大小写，密码区分）。核对完再试，还不行点登录界面的**忘记密码**，用注册邮箱收重置链接。
- 手机端报 `Authorization keyword missing` 这类授权错误（**有用户反馈**，官方回复的排查方向）：先确认同一账号在电脑端或网页端 [realtimes.real.com/account](https://realtimes.real.com/account) 能不能登录——网页能登、只有手机端报错，问题在手机端这一侧（重装应用、检查系统时间）；网页也登不上，就是账号本身的问题。

收不到账号确认邮件，先翻垃圾邮件文件夹再重发一次。

## 四、手机连不上电脑（Failed to connect to PC）

官方给的原因里最常见的一条：**电脑上的防火墙在安装 RealPlayer 时拦掉了它的组件**（例如某些安全软件默认拒绝），手机端就永远发现不了电脑。

1. 到 [www.real.com](http://www.real.com/) 重新安装电脑端 RealPlayer，安装过程中所有组件请求都选**允许**；
2. 确认电脑端偏好设置里 Mobile Access 已开启；
3. 确认两端登录同一账号、在同一网络（核对见 [手机与电脑互传与投屏教程.md](手机与电脑互传与投屏教程.md) 第一节）；
4. 仍失败：官方支持社区可以提交问题继续排查（[customer.real.com](https://customer.real.com/)）。

## 五、报「invalid DATE header value format」

这是与服务端通信时返回了格式异常的响应头，通常**不是手机端操作问题**：检查系统日期时间是否准确（设置为自动对时），切网重试；持续出现则等官方修复或到支持社区反馈。

## 六、应用闪退、无响应

按成本从低到高：

1. 清后台、重启手机；
2. 长按应用图标 → **应用信息 → 存储占用** → 清除缓存（**清数据会删掉应用内的登录与本地记录**，先想清楚）；
3. 检查存储空间，剩余空间太少应用容易异常；
4. 检查权限（存储、显示在其他应用上层）是否被系统自动收回；
5. 卸载后重新安装——安装包可用 [RealPlayer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/af3bea76212d)，装回后用同一账号登录即可恢复云端内容，本地已下载的视频若在手机存储里不会被卸载清掉。

## 七、列表是空的、找不到我的视频

不是故障，是权限或路径问题：存储权限没给（见 [下载与安装教程.md](下载与安装教程.md) 第四节），或视频不在手机内部存储。授权后回**手机**页重新进入，让应用重扫一次。

## 八、下载的任务一直挂在「下载到电脑」不动

这条对应电脑端：电脑没开、不在同一网络、或下载目标电脑已下线，任务就会停在那儿。把电脑唤醒、开 RealPlayer、确认网络后再重新发起一次；下载结果去哪找，见 [在线视频下载与云备份.md](在线视频下载与云备份.md) 第三节。

## 九、投屏搜不到设备 / 投出去只有声音

三步快速排查：手机与投屏设备是否同一 Wi-Fi → 拔电重启投屏设备 → 只有声音没画面说明码率或编码超了投屏端的支持范围（官方口径：高于 14 Mbps 或编码不支持的视频要先传云端再投）。完整步骤见 [投屏连不上或只有声音怎么办.md](投屏连不上或只有声音怎么办.md)。
