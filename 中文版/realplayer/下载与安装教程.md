## 一、先确认手机能不能装

RealPlayer 是 RealNetworks 出品的视频播放与媒体管理工具，手机端的官方应用名是 **RealPlayer Mobile**，安卓包名 `com.real.RealPlayerMobile`。装之前先把这几项对一遍：

| 项目 | 本篇这一版的值 |
| --- | --- |
| 版本 | 1.6.0 |
| 包名 | `com.real.RealPlayerMobile` |
| 安装包大小 | 17.76 MB |
| MD5 | `546B9B130960A067BFEEAB689FEEDA95` |
| 系统要求 | 记录标注为安卓 5.2 及以上 |

系统要求这一栏会随版本变化，装之前以官方应用商店页面当时显示的为准。包名是判断「装的是不是同一个应用」最可靠的依据——你从别处下的包，装之前先看包名是否一致。

## 二、获取安装包

两个来源，你按自己的情况选：

1. **官方渠道**：Google Play 商店搜 `RealPlayer Mobile`；或打开 [www.real.com](http://www.real.com/) 从官网入口进入移动端页面。官方渠道拿到的永远是当时的最新版，可能与本篇记录的 1.6.0 不是同一版。
2. **离线安装包**：[RealPlayer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/af3bea76212d) —— 网盘里存的就是本篇第一节表格里那一版，版本号、大小、MD5 都能对上。想要「装完就是记录里这个版本」，用这份。

下载完先核对大小是否接近 17.76 MB，差得多就说明下到一半断了，重新下。

## 三、安装步骤

1. 把 APK 文件拷到手机上（数据线、网盘 App 转存、浏览器下载都行），在文件管理器里点它。
2. 系统会提示「禁止安装未知来源的应用」——这是安卓对非商店来源的默认拦截。点提示里的**设置**，允许本次安装（不同品牌手机这一项叫「允许来自此来源的应用」或「安装未知应用」）。
3. 回到安装界面点**安装**，等进度走完。
4. 装完可以选择**打开**，也可以先回桌面。安装来源授权可以在装完后关掉，不影响已装的应用。

如果你的手机在安装时直接报「解析包出错」或「应用未安装」，多半是包没下完整，回到第二节重新下载；反复失败的处理办法见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、首次启动要做的两件事

1. **登录账号**：欢迎界面输入邮箱和密码登录。这一步不是可选项——你要用手机访问电脑上的视频库、投屏、云备份，全靠同一个账号把两端对上，跳过登录后面的功能都用不了。
2. **授予存储权限**：应用要扫描手机里的视频文件，会请求读取媒体与存储的权限，选**允许**。不给的话本地视频列表是空的，看起来就像「应用找不到我的视频」。注意权限名随系统版本变：老系统叫「存储」或「文件和媒体」，Android 13 起拆成「照片和视频」「音乐和音频」等项——认准带**视频/媒体**字样的那一项给。

登录之后进底部的**手机**页，能列出手机本地的视频，就说明基础功能正常了。

## 五、和电脑配合前的准备

RealPlayer 的完整用法是手机端 + Windows 端配合：电脑装 [RealPlayer for Windows](http://www.real.com/)，手机和电脑**登录同一个账号**，两边才能互相看到内容。只想在手机上播本地视频的话，可以跳过这一步。
