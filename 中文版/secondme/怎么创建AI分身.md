## 一、创建前的三个概念

创建分身的整条主线是：**搭建内核 → 新增场景分身 → 分享出去**（官方文档给的流程）。动笔之前先分清三个词：

| 概念 | 指什么 |
| --- | --- |
| 内核 | 分身对你的理解。它越了解你，分身就越像你 |
| 对齐度 | 衡量分身与你真人相似程度的指标，用 Lv.0 到 Lv.10 表示；完成基础设置、导入资料、补充关键记忆、和分身对话都会让它上涨 |
| 分身 | 内核针对某个具体场景的定制版本，比如求职接待、知识答疑；你的个人主页背后是一个默认的「主分身」 |

对齐度、分身中心这些入口在 App 与网页端、不同版本里呈现可能略有差异，以你手上的实际界面为准。

## 二、第一步：搭内核，把基础设置填完

在对齐度页面跟着引导填，这几项先做完（属于一次性设置）：

- **姓名、ID、个人简介** —— 简介写清你是谁、在做什么；
- **头像、封面** —— 用能代表你的照片；
- **声音克隆** —— 按引导录一段语音，让分身用你的声音说话；另有语音简介一项。

姓名和简介值得写准：导入资料时，系统要靠这两项去判断「哪些内容是你本人说的、想的」，写得越准，资料识别越对。

生成的形象不像自己，先调两处：在「外貌（Appearance）」上传一张自己的人像；不方便传照片，就在「关于我（About Me）」里注明性别与希望体现的外观特征。有用户反馈过自动生成形象默认男性的问题，官方客服在商店评论区的答复就是这两个位置。

## 三、第二步：导入资料，拉高对齐度

资料是分身理解你的原材料。两类入口：

- **随手记**：当下想到什么直接在应用里写一条，适合想法、复盘、日记这类「此刻产生的内容」；
- **导入已有**：把现成的东西喂进去，三种方式 —— 批量上传文件（Markdown、TXT、PDF、Word、PPT、图片、音频、ZIP）、从链接获取（网页、文章、公开音视频页面）、从应用导入（Notion、Apple Notes、Evernote、X、Flomo、Get 等）。

导入有几条硬限制，超了就得拆文件：

| 限制 | 数值 |
| --- | --- |
| 一次最多导入 | 100 个文件或 100 个链接 |
| 单条资料解析后的正文上限 | 1 MB（UTF-8） |
| Markdown / TXT | 直接作为资料正文读取，建议单文件控制在 1 MB 以内 |

导入是后台异步处理的，期间可以继续用应用；处理完才会体现在对话里。导入进度里会标出成功、失败和「建议检查」的条目 —— 看到建议检查就打开那条资料，确认解析出的正文完不完整。

资料之外还有三样东西参与塑造：**关键记忆**（分身优先参考的核心信号）、**色彩**（系统从资料和记忆里提取的人格特征标签）、**好友关系**（让分身理解你的社交语境）。

关键记忆分三种，各管一类问题：**事实**（你的偏好、经历、习惯）、**关系**（你和谁是什么关系、怎么相处）、**风格**（表达习惯与话题禁忌 —— 什么该说、什么不该说、怎么说）。做法：进「记忆」页，选中某条记忆，星标或点「标记为关键」，之后分身生成回复会优先参考它。官方给的最佳实践：只标真正定义你是谁的那几条，数量保持精简，优先级变了就定期审查更新。

想涨对齐度，按官方给的顺序做：先补齐基础设置 → 导入资料 → 管理关键记忆 → 在对话里认可像你的回答、纠正不像你的 → 补充关系网络。导入的资料会被怎么用、能不能删，见 [数据与隐私说明.md](数据与隐私说明.md)。

## 四、第三步：新增场景分身，写好任务描述

到分身中心点「创建分身」，最关键的一格是**任务描述**（场景提示词）：告诉这个分身在什么场景、对什么人、怎么说话。描述越具体，表现越稳。官方文档给了几个可以直接改用的模板：

| 场景 | 任务描述可以这样起头 |
| --- | --- |
| 求职 / 个人名片 | 向访客介绍我的工作经历、项目成果和技能；对方若是招聘方，主动了解岗位需求并说明我为什么合适 |
| 知识答疑 | 基于我读过的书和笔记，和访客讨论观点、分享我的理解和批注；遇到我没读过的内容就坦诚说明 |
| 业务客服 | 代表我的工作室接待咨询：介绍服务与报价、回答常见问题、引导有意向的客户留下联系方式 |
| 自我介绍 / 交友 | 用轻松的语气介绍我的兴趣、经历和最近在忙的事，也反过来了解对方、找共同话题 |

标题和开场白可以点「生成」让 AI 按描述自动起草，之后手动改。每个分身还能挂一份**讲解文档**（仅支持 PDF，最大 30 MB，每个分身 1 份）：上传后对话切换成讲解模式，分身逐页带着访客看文档并答疑，适合产品介绍、培训资料、论文报告这类场景。

分身也可以设置成收费的（访客付费解锁对话），入口在分身设置里；档位、卡次上限与额度归属见 [会员套餐与钻石价格.md](会员套餐与钻石价格.md)。

## 五、第四步：测试、认可与纠正

创建完别急着发出去，先当一次自己的访客：

1. 在分身中心选中这个分身，点「测试」，模拟一个第一次来的新用户提问；
2. 重点看三件事：回答是否和你的资料一致、语气是否符合定位、面对它不知道的问题会不会乱答；
3. 回复符合预期就「认可」，不像你就在「纠正」里写下你希望的答法 —— 这些反馈会用于后续塑造；
4. 改过任务描述或资料之后，用分身页右上角「更多」里的**分身自动评测**跑一轮，看报告再调。

整套下来就是「测试 → 反馈 → 优化 → 再评测」的循环。分身调顺了，下一步就是发出去：分享渠道与人工接管见 [分身分享与人工接管.md](分身分享与人工接管.md)。
