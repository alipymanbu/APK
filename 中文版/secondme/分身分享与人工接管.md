## 一、四种分发渠道

每个分身都能通过下面这些渠道发出去，对方怎么接、要不要装 App，差别在表里：

| 渠道 | 访客怎么用 | 特点 |
| --- | --- | --- |
| 微信小程序 | 在微信里直接打开 | 访客不用装 App，适合发给微信群、朋友圈场景 |
| 网页链接 | 浏览器打开链接 | 不需要注册账号，点开就能和分身聊 |
| 海报二维码 | 生成一张海报，微信里长按识别 | 适合发社交平台，海报自带入口 |
| API Key | 开发者把分身接进自己的应用、网站或工作流 | 每个分身可生成多个 Key，各自能单独启用 / 停用 |

渠道入口都在分身中心；App 与网页端的具体位置以实际界面为准。另外官方还提供一个面向 Agent 工具的 Skill 入口（`https://second-me.cn/skill.md`），适合让自动化工具引导你完成创建，属于可选方式。

## 二、访客对话都会回流到分身中心

发出去之后你不用盯着，所有和分身的对话都汇集在分身中心：

- **看记录**：浏览所有分身的全部对话，谁在什么时候互动过都有数据；
- **看详情**：分身说了什么、访客怎么回的，逐条能看；
- **人工接管**：想在某个对话里亲自回，直接在对话里输入消息发出去就行，你的回复直接到访客那边，不需要先开什么模式。

你的个人主页（主分身）背后收到的对话也在这里，和普通分身一样管理。

## 三、发出去之前先测一轮

渠道只是出口，访客体验好不好取决于分身本身：任务描述是否具体、资料是否够、语气是否对。官方建议的节奏是「测试 → 反馈 → 优化 → 再评测」，具体操作见 [怎么创建AI分身.md](怎么创建AI分身.md) 的测试一节。分身答不上来的问题多集中在资料没覆盖的地方，回头补资料比改话术有用。

## 四、分享出去能收到什么

- 访客的使用情况会沉淀在分身中心，包括互动数据与对话内容；
- 如果分身设置了收费卡（体验卡 / 月卡 / 年卡），访客需要付费解锁对话，价格与可用回复次数在创建分身时自行设定，上限规则见 [会员套餐与钻石价格.md](会员套餐与钻石价格.md)；
- 免费分身的对话额度由访客自己的账户承担，不消耗你作为分身所有者的钻石额度（钻石机制见 [会员套餐与钻石价格.md](会员套餐与钻石价格.md)）。

## 五、粉丝勋章与亲密度

访客和你的分身长期互动会攒出一枚「粉丝勋章」：打卡、发有效消息、付费都会加亲密度，累计亲密度决定勋章等级（最高展示 Lv.100）。同一个访客对你所有分身共享一份亲密度与等级，打卡状态则按分身分别计算。三种行为的加成规则（官方规则）：

| 行为 | 亲密度 |
| --- | --- |
| 打卡 | 第 1 天 +1，连续每天递增 1，单次最高 +7；中断一天后从 +1 重新开始 |
| 发送有效消息 | 每条 +5，无每日上限 |
| 为分身付费 | 每实付 1 元 +20（退款会按金额扣回） |

几个对你有用的细节：

- 勋章名称可以自定义（中文 3–6 个字符），不设置时默认叫「同频者」；
- 每个分身可以单独开关每日打卡；关闭只是隐藏打卡体验，已有的亲密度、等级和记录不删，重新开启接着算；
- 本期打卡入口只在微信小程序里提供，网页链接、App 端没有打卡页；
- 官方给的量级参考：连续打卡 30 天约到 Lv.11，实付约 100 元约到 Lv.27 —— 等级曲线是指数型的，越高越慢。
