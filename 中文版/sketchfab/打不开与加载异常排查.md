# Sketchfab 打不开与加载异常排查

> 按现象分类排查：客户端闪退打不开、模型只显示转盘图、查看器空白、提示拦截脚本、模型发白没贴图。

## 一、先分清你是哪种坏法

四种现象的原因完全不同，对号入座再动手：

| 现象 | 大概率问题在 |
|---|---|
| 客户端点不开、闪退、卡死 | 手机上的应用本身 |
| 模型变成一张 360° 转盘图，不能拖 | 设备的 WebGL 渲染环境 |
| 查看器整块空白，或提示拦截脚本 | 浏览器设置 / 脚本拦截 |
| 模型整体发白、没有贴图 | 模型本身（作者上传时的文件问题） |

## 二、客户端闪退、打不开

按顺序做，做到哪步好了就停：

1. 强制停止后重开：**设置 → 应用 → Sketchfab → 强制停止**，再启动。
2. 清缓存：同一位置选**清除缓存**（只删临时文件，不影响登录状态）。
3. 还不行再**清除存储空间**（会让 app 回到初次安装状态，登录与设置会被清掉，介意就先记住账号）。
4. 重启手机再试；确认系统版本在**安卓 5.2 以上**（这份 2.22.0 的要求）。
5. 卸载重装：安装包从 [Sketchfab 安装文件资源（夸克网盘）](https://pan.quark.cn/s/81d552001b14) 重新取，装前核对 MD5（见 [下载与安装教程.md](下载与安装教程.md) 第二节）。
6. 仍无解 → 客户端已从应用商店下架、不再更新，按官方公告**改用手机浏览器**打开 [sketchfab.com](https://sketchfab.com) 是最终方案。

## 三、模型只显示一张转盘图（360° 环视），拖不动

这不是加载失败，是**当前环境跑不了 WebGL**，官方查看器自动降级成图片模式（[官方兼容性说明](https://help.sketchfab.com/en/articles/16152700-browser-and-os-compatibility)）。恢复实时渲染：

- 先自检：<https://get.webgl.org/> 能正常出图，说明 WebGL 是通的；出不来就是渲染环境的问题。
- Chrome / Edge：设置里确认**"尽可能使用硬件加速"**开着；仍不行可开 `chrome://flags/#ignore-gpu-blacklist`（覆盖软件渲染列表）后重启浏览器。
- Firefox：`about:config` 里把 `webgl.force-enabled` 设为 `true`。
- 顺手把显卡驱动与浏览器升到当前版本 —— 这一步解决的案例最多。

## 四、查看器整块空白 / 提示拦截脚本

- **Microsoft Edge 特有**：Edge 默认的"增强安全模式"不支持 WebAssembly，而查看器必须要它。把站点移出增强安全模式，或对 [sketchfab.com](https://sketchfab.com) 关闭该模式。
- **提示 "blocking some scripts or cookies"**：有扩展或站点设置在拦脚本/cookie。关掉脚本拦截类扩展、允许该站点的 cookie 后刷新。
- **嵌在别的网页里不显示**：那是 iframe 被加了 `sandbox` 限制，需要站方放开 `allow-scripts`、`allow-same-origin`、`allow-popups`、`allow-forms` —— 你这边改不了，换直接打开模型页即可。

## 五、模型整体发白、看不到贴图

看到的白模是**模型作者上传时的问题**，不是你的设备：贴图没跟模型一起打包、用了不被支持的渲染器材质、或材质数量超过单模型 100 个的上限，都会这样（[官方说明](https://help.sketchfab.com/en/articles/16152595-why-does-my-model-upload-white)）。你没有任何操作能修好它 —— 换一个模型看，或留言提醒作者重新上传。

## 六、加载慢、加载到一半失败

加载分两段，看你在哪一段卡住：

- **"Loading 3D Model" 画面与顶部蓝色进度条**：这一段在下载模型的面数数据与贴图。贴图越大越慢 —— 一张 4096×4096 的贴图光渲染就要吃掉约 50MB 显存（[官方性能说明](https://help.sketchfab.com/en/articles/16152043-improving-viewer-performance)），手机尤其吃亏；蓝条走完后头几秒还会有一次高清贴图的补充加载，此时拖动卡顿属正常，等它稳定。
- **加载完成后一直卡**：是这个模型对你的设备太重。官方的口径是：材质数量（单模型上限 100 个）、贴图分辨率（8K 以上与非 2 的幂次贴图直接不渲染）、网格面数都会拖帧率，作者建模时就该按网页实时渲染来控量。你这边能做的只有等它加载完、或换个轻量些的模型。

排查顺序：先换一个明显面数小的模型，确认不是全站性慢 → 切换 Wi-Fi 与流量重试 → 关掉后台占带宽的应用。单个模型反复加载不出来而别的模型正常，就是这个模型本身太重，等页面完整加载或换配置更高的设备再看。
