## 一、装之前先知道这几点

- HoYoGet 只有安卓版，没有 PC 版和 iOS 版（官方的说明是其他平台已有成熟的获取方案，所以没有做）。系统要求**安卓 7.0 及以上**，低于这个版本装不上。
- 它没有上架任何应用商店，只能通过 apk 安装包安装。安装时手机提示「风险」「不受信任的应用」是系统对所有商店外安装包的统一提示，与包本身有没有问题无关。
- 网盘资源里的安装包信息如下（写作时检索到网上已有更新的版本发布记录，要装新版请以[官网](https://www.wyylkjs.com/HoYoGet/)当时显示为准）：

| 项目 | 信息 |
| --- | --- |
| 版本 | 2.1.0 |
| 包名 | com.playerdeveloper.yuanshenget |
| 大小 | 5.13M |
| MD5 | 68F903D78D6BCE0617AD9621BBF0568D |

想核对拿到手的安装包是否与上表一致，可以算一下它的 MD5 再比对；官网首页也提供校验值查询。

## 二、从哪拿安装包

两个渠道任选：

1. [HoYoGet 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d38997cf5725)，转存后下载 apk 即可，网盘里就是上面表格中这一版。
2. 官网：[https://www.wyylkjs.com/HoYoGet/](https://www.wyylkjs.com/HoYoGet/)。官网打不开多半是在维护，过段时间再试。

## 三、安装步骤

1. 在手机上打开下载好的 apk（用网盘 App 或文件管理器都行）。
2. 系统询问「是否允许安装未知应用」时，给刚才用来打开安装包的那个应用（浏览器 / 网盘 / 文件管理器）授权。
3. 若提示「检测到风险」「风险应用」，各机型放行位置不同，搜「你的机型 + 安装不受信任的应用」能找到对应开关，放行后继续装。
4. 桌面上出现 HoYoGet 图标即为安装成功。

小米 / 红米（MIUI / 澎湃OS）多一道「纯净模式」：它会拦下未经小米商店审核的安装包。处理位置在安装页面右上角「设置」>「纯净模式」，选「授权单次安装」放行这一次，或直接关闭纯净模式（需输入锁屏密码）；未备案应用还会弹「了解风险」的勾选确认。入口名称与路径以你机型系统当时显示为准。

## 四、装好之后先做什么

第一次打开不用注册账号，直接进主界面。接下来分两条路：

- 想最快拿到链接：看 [抽卡链接获取方法.md](抽卡链接获取方法.md)，里面有三种获取方式和每种游戏适用哪种的对照表。
- 想先登录米游社账号、或玩的是 B 服：看 [账号登录与B服绑定.md](账号登录与B服绑定.md)。

## 五、装不上或闪退

| 现象 | 处理 |
| --- | --- |
| 下载失败 | 换另一个渠道重新下（网盘 / 官网互为备份） |
| 安装失败 | 确认系统是安卓 7.0 及以上；老系统没有替代办法 |
| 打开就闪退 | 多为该机型兼容性问题，只能换设备或向开发者反馈 |
| 被「纯净模式」拦下（小米 / 红米） | 见第三节的纯净模式说明，单次授权或关闭后重装 |
| 校验值对不上 | 安装包可能被改动过，换渠道重新下载 |

装上了但使用中报错，去 [常见问题与错误码.md](常见问题与错误码.md) 对照错误码查处理办法。
