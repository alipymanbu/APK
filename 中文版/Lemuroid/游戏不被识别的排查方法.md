# Lemuroid 游戏不被识别的排查方法

> 本篇讲 Lemuroid 扫描游戏文件的识别规则，以及扫不出游戏、列表为空时按什么顺序排查。

列表里没有游戏、或某几个游戏死活扫不出来，是 Lemuroid 新手最常碰到的坎。原因几乎都能归结到「文件不符合识别规则」。先按第一节把游戏文件挪进对应的主机文件夹，这是最有效的一步；还不行再逐节往下查。

## 一、第一招：按主机建文件夹

把游戏放进以主机命名的文件夹里（一个文件夹一类主机），然后让 Lemuroid 扫描这些目录。可用的文件夹名（小写）：

| 文件夹名 | 对应主机 |
| --- | --- |
| `nes` | NES（红白机） |
| `snes` | SNES |
| `gb` | Game Boy |
| `gbc` | Game Boy Color |
| `gba` | Game Boy Advance |
| `n64` | Nintendo 64 |
| `psx` | PlayStation |
| `psp` | PSP |
| `fbneo` | FinalBurn Neo 街机 |
| `sms` | Sega Master System |
| `genesis` | Sega Genesis/Mega Drive |
| `gg` | Game Gear |
| `atari2600` | Atari 2600 |

放在这类文件夹**直接子层**（不套更深的子目录）的文件，只要扩展名属于该主机（如 `.bin` `.iso` 之类通用格式），即使数据库里查不到也会被归进去。Nintendo DS 等有专属扩展名（`.nds`）的文件不依赖文件夹，任意位置都能认出。

## 二、识别规则：文件是怎么被认出来的

了解这五条规则，就能判断自己的文件为什么没被认出：

1. 文件的 CRC 校验值与内置数据库条目对上了；
2. `.iso` 文件的游戏序列号与数据库对上了；
3. 文件名与数据库里的游戏名对上了；
4. 扩展名能唯一确定主机（如 `.nds` `.gba` `.n64`）；
5. 扩展名是该主机支持的通用格式，且文件在对应主机名文件夹的直接子层。

五条一条都不占，文件就会被无视。所以乱改过的文件名（如 `游戏123.bin`）既对不上数据库、又没放在主机文件夹里，是扫不出来的最常见原因。

## 三、压缩包问题

- **只支持 zip，且包里只能有一个文件**。`rar`、`7z` 一律不认；一个 zip 里塞了不止一个文件也会被整个跳过。
- 排查动作：把压缩包解压成原始文件再扫；要压缩就保证「一个 zip = 一个游戏文件」。

## 四、FBNeo 街机游戏的特殊处理

FBNeo 只认**非整合（non-merged）romset**，且文件的 CRC 必须与数据库一致，这是街机游戏扫不出来的头号原因。

- 正规做法：下载 non-merged 版本的 FBNeo romset。
- 你手头只有整合（merged）版时，把它复制到应用内部目录：`/sdcard/Android/data/com.swordfish.lemuroid/files/roms/fbneo`（用文件管理器手动放进这个路径，文件管理器需要「显示 Android/data」的权限）。

## 五、PSX 多碟游戏的处理

多碟游戏（如最终幻想 9 四碟版）直接扫碟文件会当成几个独立游戏，正确做法是配一个 `.m3u` 播放列表文件：

1. 新建一个文本文件，扩展名改为 `.m3u`，名字随意（建议与游戏同名）；
2. 每行写一个碟的 `.cue` 文件名，碟文件与 m3u 放在同一目录；
3. 扫描时认这个 m3u，游戏内换碟用它管理。

示例（来自官方 FAQ 的 Final Fantasy IX 写法）：

```text
Final Fantasy IX (USA) (Disc 1) (Rev 1).cue
Final Fantasy IX (USA) (Disc 2) (Rev 1).cue
Final Fantasy IX (USA) (Disc 3) (Rev 1).cue
Final Fantasy IX (USA) (Disc 4) (Rev 1).cue
```

另外，PSX 游戏扫出来了但进去报错、花屏，有可能不是文件问题而是 BIOS 缺失，个别游戏对固件有要求，见[哪些主机需要 BIOS 文件](哪些主机需要%20BIOS%20文件.md)。

## 六、逐条排查清单

按顺序过一遍，命中哪条改哪条：

1. 授权过存储权限吗？（首次启动时拒绝过授权的话，一个游戏都扫不到，去系统设置的应用权限里补）
2. 给扫描指定的目录对吗？游戏文件真的在那个目录里？
3. 是不是 rar/7z 压缩包？解压再试。
4. zip 里是不是不止一个文件？拆开再试。
5. 文件名是不是改得面目全非？改回接近原名再试。
6. 同类主机文件没分文件夹？按第一节建文件夹归类。
7. FBNeo 是整合版？按第四节处理。
8. 以上全对还认不出？把应用更新到最新版再试——官方更新日志里常出现「更新内核与数据库」的条目，识别不准的老游戏正是这类更新修的对象。

游戏都认出来之后，第一次进入游戏前不妨先看一眼[存档备份与云同步](存档备份与云同步.md)，确认存档目录位置，避免以后换机丢档；想接手柄、在电视上玩的，看[手柄与安卓电视使用](手柄与安卓电视使用.md)。
