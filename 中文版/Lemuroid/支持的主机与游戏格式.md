Lemuroid 一个应用整合了二十多类经典主机的模拟，游戏文件需要你自己提供。先对照下面的清单确认你的游戏属于哪类主机、对设备有什么要求，再按格式要求整理文件；扫不出来时去看[游戏不被识别的排查方法](游戏不被识别的排查方法.md)。

## 一、支持的主机清单

按厂商分组列出（截至本地记录的 1.16.2 版本，新版本可能增补，以官方页面为准）：

| 厂商 | 主机 |
| --- | --- |
| 任天堂 | NES（红白机）、SNES（超级任天堂）、Game Boy、Game Boy Color、Game Boy Advance、Nintendo 64、Nintendo DS、Nintendo 3DS |
| 索尼 | PlayStation（PSX）、PlayStation Portable（PSP） |
| 世嘉 | Master System、Genesis/Mega Drive、Game Gear、Sega CD（Mega CD） |
| 雅达利 | Atari 2600、Atari 7800、Atari Lynx |
| SNK | Neo Geo Pocket、Neo Geo Pocket Color |
| 万代 | WonderSwan、WonderSwan Color |
| NEC | PC Engine（PCE） |
| 街机 | FinalBurn Neo（FBNeo） |

同一类主机的游戏文件后缀常见如下（举例）：GB/GBC/GBA 用 `.gb` `.gbc` `.gba`，NDS 用 `.nds`，N64 用 `.n64` `.z64` `.v64`，PSX 用 `.bin`+`.cue` 或 `.iso`，PSP 用 `.iso` `.cso`，世嘉系用 `.sms` `.md` `.gg`，FBNeo 用 `.zip`。

一个例外要提前知道：清单里的 **Sega CD 需要额外的 BIOS（固件）文件**才能运行，其它主机基本放好游戏就能玩，具体情况见[哪些主机需要 BIOS 文件](哪些主机需要%20BIOS%20文件.md)。

## 二、性能预期：哪类主机吃配置

官方明确提示：不是每台设备都能跑所有主机，越新的主机越吃性能。可以按这个梯度预估：

| 梯度 | 主机 | 预期 |
| --- | --- | --- |
| 几乎都能跑 | 8/16 位主机：NES、SNES、GB/GBC/GBA、世嘉系、雅达利、Neo Geo Pocket、WonderSwan、PC Engine | 老手机也基本满速 |
| 中等 | N64、PSX、FBNeo 街机 | 近十年的中端机一般没问题 |
| 吃性能 | PSP、Nintendo DS | 需要较强的处理器，弱机可能掉速 |
| 最吃性能 | Nintendo 3DS | 需要高性能旗舰机，低端机不建议尝试 |

弱机想跑 PSP/DS/3DS，实际能拧的旋钮有这几个，从见效快的开始：

1. **关掉 HD 模式**：设置里的高分辨率渲染选项（1.16.x 有），开着很吃性能，关掉立刻轻松不少；
2. **关掉屏幕仿真**：LCD/CRT 这类画面效果有额外开销，弱机关掉；
3. **关掉省电模式**：省电模式会压 CPU 频率，模拟器正好是吃 CPU 的；
4. **散热**：手机发烫会自动降频，越烫越卡；摘掉手机壳、放凉再玩。

以上设置项的具体名称随版本略有差异，以你手上的界面为准。

## 三、游戏文件的格式要求

整理文件时记住这几条，扫描成功率会高很多：

1. **压缩包只认 zip，且一个包里只能有一个游戏文件**。rar、7z 不支持；一个 zip 里塞了多个文件也会被跳过。不压缩、直接放原始文件最容易过。
2. **文件名尽量和游戏原名一致**。扫描时会把文件与内置数据库对照（CRC 校验、序列号、文件名都参与匹配），改成自己看得懂的乱起名可能就认不出来了。
3. **PSX 多碟游戏要配 m3u 播放列表**：建一个 `.m3u` 文本文件，每行写一个碟的文件名，和碟文件放同一目录，扫描时选这个 m3u。示例（Final Fantasy IX 三碟）：

   ```text
   Final Fantasy IX (USA) (Disc 1).cue
   Final Fantasy IX (USA) (Disc 2).cue
   Final Fantasy IX (USA) (Disc 3).cue
   ```

4. **FBNeo 街机只认非整合（non-merged）romset**，且文件要与数据库 CRC 一致；整合版要放到应用内部目录才能玩，路径见[游戏不被识别的排查方法](游戏不被识别的排查方法.md)。

## 四、按主机分文件夹是最稳的整理方式

如果你的游戏很多、或文件名比较乱，把游戏按主机分目录存放（如 `gba/`、`psx/`、`snes/` 各一个文件夹），再把目录交给 Lemuroid 扫描，识别率最高。具体文件夹名与排查步骤在[游戏不被识别的排查方法](游戏不被识别的排查方法.md)里有完整清单。

文件都认出来之后，就可以开始玩了；存档相关的事（自动存档放在哪、怎么备份换机）见[存档备份与云同步](存档备份与云同步.md)。
