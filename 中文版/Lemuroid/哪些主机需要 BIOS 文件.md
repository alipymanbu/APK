# 哪些主机需要 BIOS 文件

> 本篇讲 Lemuroid 各主机对 BIOS（系统固件）文件的要求：哪些不用管、哪些必须要、文件从哪来、放在哪。

「要不要下个 BIOS 才能玩」是模拟器新手的经典疑问。在 Lemuroid 里，绝大多数情况不用操心这件事——大部分主机放好游戏文件就能直接玩。只有个别系统例外，这篇按「不用 / 必须 / 可选」三档讲清。

## 一、不用 BIOS 就能玩的

下面这些系统开箱即玩，放好游戏文件即可，不需要任何额外固件：

- NES、SNES、Game Boy / Color / Advance；
- 世嘉 Master System、Genesis/Mega Drive、Game Gear；
- PSP、Nintendo DS；
- Atari 2600 / 7800 / Lynx、Neo Geo Pocket / Color、WonderSwan / Color、PC Engine、FBNeo 街机。

如果你玩的就是上面这些，这篇看到这里就够了；游戏认不出来与 BIOS 无关，去查[游戏不被识别的排查方法](游戏不被识别的排查方法.md)。

## 二、明确需要 BIOS 的：Sega CD

Sega CD（Mega CD）是清单里的例外：Lemuroid 官方更新日志在加入该主机支持时明确标注「需要 BIOS」。没有 BIOS 文件，Sega CD 游戏跑不起来。

- 文件名与版本要求以你应用的提示与官方文档为准，不同地区机型对应的固件不同；
- BIOS 属于主机固件，请从自己合法拥有的主机上提取，本篇不提供也不会指引任何下载渠道。

## 三、PSX：多数游戏不用，个别游戏建议备好

PSX 的情况介于两者之间：多数游戏没有 BIOS 也能正常运行；但确有玩家反馈个别游戏不备 BIOS 会出错或画音异常。所以：

- 想先随便玩玩：什么都不用做，直接扫游戏；
- 想长期玩 PSX 库：从自己的主机提取一份 BIOS 备着，兼容性更稳。

## 四、BIOS 文件放在哪

- 新版 Lemuroid 的设置里有系统文件（BIOS）相关的条目，可以指定 BIOS 所在目录，应用会自行检测各系统的固件是否就位；不同版本的入口叫法可能不同，以你手上的界面为准；
- 放好后重启应用或重新扫描一次再进游戏；
- BIOS 文件不改名、不压缩（个别系统对文件名敏感，改名会导致识别失败）。

## 五、两句提醒

1. BIOS 与游戏文件是两回事：BIOS 是主机固件，游戏文件是游戏本身；游戏文件的自备与格式要求见[支持的主机与游戏格式](支持的主机与游戏格式.md)。
2. 从网上下载他人打包的 BIOS 涉及固件版权，来源也不可靠（文件可能被改过），自己提取才是稳妥做法。

设置好之后，存档相关的事（自动存档、备份、与 RetroArch 互通）见[存档备份与云同步](存档备份与云同步.md)。
