## 一、整体流程一览

整个过程是五步：新建机器 → 配硬件 → 挂镜像 → 选启动顺序 → 开机。第一次先把轻量系统跑通，再按同一套流程换 Windows 镜像（选型与参考配置见[轻量系统与参考配置.md](轻量系统与参考配置.md)）。每一步的选项细节往下看。

## 二、新建机器

1. 打开 Limbo Plus，点右上角虚拟机配置旁边的下拉框（初始显示 None），选「新建」；
2. 给机器起个名字，建议用简短英文（如 `win7`、`win10`），点创建；
3. 部分版本会弹出预设系统列表（Windows、Linux 等），点进去是对应的安装指引；你已经有自己的镜像就直接选「自定义」。

建好之后再遇到选镜像无反应或文件管理器空白，多半是存储权限没给，处理方法见[下载与安装教程.md](下载与安装教程.md)第四节。

## 三、配置硬件

配置界面的主要分区及常用取值：

| 配置项 | 建议取值 | 说明 |
| --- | --- | --- |
| 机器类型 | `pc-i440fx-5.1`（列表里有多个 i440fx 版本号时选相近的） | 常规 Windows 与多数 Linux 用 i440fx 芯片组即可；q35 面向较新的系统 |
| CPU 型号 | `qemu32`（32 位系统）或 `qemu64`（64 位系统）；部分教程也用 `SandyBridge` | 遇到不兼容启动不了，先退回 qemu32 / qemu64 这类通用型号 |
| CPU 核心数 | 与手机实际核心数接近，一般 4~8 | 没开多线程加速时，多核基本没有收益 |
| 内存（RAM） | 不超过手机运行内存的 1/3；Windows 7 想跑起来建议 1024~2048 MB | 给得太大系统会拒绝分配或直接闪退，参见常见问题篇 |
| 指令集优化 | 追求稳定可先关掉；追求速度可打开试 | 开了反而卡或不稳就关回去，只留 1 核 |

另外几项常规默认即可：显示选 `std`，鼠标选 `usb-tablet`（触屏操作桌面更准），音频在没有特殊需要时选无（声音输出只在部分用户界面模式下有效）。

## 四、挂载镜像

- **硬盘 A**：点开后弹两个入口。「新建」是在手机存储里创建一块空白虚拟磁盘（选 qcow2 或 img 格式、定容量），适合配合 ISO 从零装系统；「打开」是调用文件选择器选一个已有镜像文件（vmdk / qcow2 / img），适合直接引导装好的整盘镜像。
- **可移动设备（CDROM）**：挂 ISO 安装镜像用的，同样选「打开」再挑文件。
- **启动顺序**：在引导设置里选。用整盘镜像引导就选 `Hard Disk`；全新安装时选从 `CD-ROM` 启动，装完系统再改回 `Hard Disk`。

镜像建议放在手机内置存储里、路径别太深，文件选择器里好找。

## 五、额外 QEMU 参数与配置保存

如果你在「额外 QEMU 参数」里填了内容（比如 `-smp 4,cores=4`，这两个数字必须与上面 CPU 核心数一致，否则会卡顿、闪退甚至进系统后蓝屏），填完要回到顶部，把虚拟机配置先切回 `None`、再切回你的机器名，配置文件才会落盘。不这样做，下次打开参数可能就丢了。

## 六、启动与首次等待

1. 回到主界面点启动（播放键），Limbo Plus 会进入虚拟机画面；
2. 纯软件模拟下开机等待明显比真机长，Windows 尤其慢，黑屏或停在 logo 几分钟到十几分钟都属常见，别急着关——判断是真失败还是正常慢，见[常见问题与报错处理.md](常见问题与报错处理.md)；
3. 进入桌面后，画面默认竖屏显示、字偏小，可以用悬浮球调出键盘操作，外接键鼠体验更好（见[文件互传与外设操作.md](文件互传与外设操作.md)）。

## 七、Windows 7 参考配置与 vmdk 转换

社区教程里跑 Windows 7 的一组经过验证的配置，可直接对照：

```text
CPU 型号：qemu32      TSC：开启
内存：2048 MB（部分手机不允许给这么大，报错就降到 1024）
鼠标：usb-tablet     显卡：std
音频：无             网络：user 模式，网卡 e1000
```

拿到的是 vmdk 整盘镜像（比如微软官方评估版虚拟机解出来的 `xxx-disk1.vmdk`），Limbo 里引导不稳时，可以先在电脑上用 qemu-img 转成 qcow2 再放进手机：

```bash
qemu-img convert -p -f vmdk -c -O qcow2 "镜像名.vmdk" win7.qcow2
```

转换在电脑上做，可能要等一阵；转完把 qcow2 文件传到手机，按第四节挂到硬盘 A、引导选 Hard Disk 即可。

机器类型、指令集这些选项与速度的关系，展开在[性能优化设置建议.md](性能优化设置建议.md)；虚拟机里怎么和手机互传文件，见[文件互传与外设操作.md](文件互传与外设操作.md)。
