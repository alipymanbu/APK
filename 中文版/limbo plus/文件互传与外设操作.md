## 一、文件中转站：真机与虚拟机互传

Limbo Plus 内置文件中转功能，不需要第三方工具就能在手机与虚拟机之间双向传文件：手机里的文档、图片、安装包可以送进虚拟机，虚拟机里生成的文件也能取回到手机存储。传大文件或整目录时，优先用下面第二节的镜像挂载法，速度和稳定性都更好。

## 二、把手机文件打包成 ISO 挂进虚拟机

虚拟机里「插 U 盘」并不方便，社区常用做法是换个思路——把要传的文件做成光盘：

1. 在手机上用打包工具（如 ISOCraft 这类能从文件生成 ISO 的应用）把目标文件打成 ISO；
2. 在虚拟机配置里把这个 ISO 挂到 CDROM（操作见[新建虚拟机与运行Windows教程.md](新建虚拟机与运行Windows教程.md)第四节）；
3. 进系统后打开「我的电脑 / 文件管理器」，光盘里就是你的文件，拷出来即可。

一次性传多个文件、或者要往全新系统里塞安装包时，这招最省事。

## 三、FTP 互传：虚拟机直接访问手机存储

虚拟机的网络默认是用户模式（NAT），手机本机在这个网络里的固定地址是 `10.0.2.2`。利用这一点可以搭一条常驻通道：

1. 手机上装一个 FTP 服务器应用并开启；
2. 虚拟机里打开资源管理器或 FTP 客户端，地址填 `ftp://10.0.2.2`；
3. 连上后就能像访问局域网电脑一样在手机存储与虚拟机磁盘之间对拷。

前提是虚拟机配置里网络为 user 模式、网卡能正常工作；网卡选型见[性能优化设置建议.md](性能优化设置建议.md)第三节。

## 四、悬浮球：竖屏操作的入口

进入虚拟机画面后，屏幕上有悬浮球，承担三件事：切换窗口与界面、调出虚拟键盘（桌面系统没有手机输入法可依赖，敲什么全靠这个键盘）、调音量。竖屏下 Windows 画面偏小、字很密，养成先用悬浮球调键盘再操作的习惯，比在画面里精准点小按钮现实得多。

## 五、按键映射器

按键映射器负责把手机上没有的键补齐。v2.0.6-x86 这一版在按键映射器的高级按钮列表里新增了 Windows 徽标键、退格键、Del 键、大写锁定键，并且修复了此前鼠标事件不生效的问题——如果你从旧版升级，这两个变化直接影响操作手感：徽标键能呼出开始菜单，Del 键配合文件操作是刚需。

屏幕键盘还有个背景事实：虚拟键盘默认只提供美式布局，要敲其他布局，在「额外 QEMU 参数」里加 `-k de` 这类参数指定（de 换成你要的布局代码）。输入量大就装 Hacker's Keyboard 这类带 Ctrl / Alt / F1~F12 的输入法，桌面系统里的组合键全靠它补；外接键鼠则不受此限，语言切换跟随系统内设置。

## 六、外接键盘鼠标

- **OTG 有线**：手机插 OTG 转接头接 USB 键鼠，进虚拟机后直接生效，是操控桌面系统体验最好的方式；
- **蓝牙**：蓝牙键鼠同样可用，注意先在安卓侧完成配对；
- **没外设时**：触屏被映射为鼠标指针（配置里鼠标选 `usb-tablet` 时定位最准），配合悬浮球键盘能覆盖大部分操作；
- **触屏手势**：社区教程整理的 SDL 界面手势映射——单击是左键、双击是双击、音量上键当鼠标中键、音量下键当右键、按住拖动就是拖拽；手势不灵时把设置里的鼠标按键延迟调大一点。音量键被占用后，SDL 模式下调音量要走悬浮球；
- **指针撞墙**：VNC 界面下指针走到一半停住的「隐形墙」，也是换 `usb-tablet` 解决，排查见[常见问题与报错处理.md](常见问题与报错处理.md)第七节。

## 七、息屏挂机与分辨率

虚拟机支持后台运行，配合改分辨率可以降低功耗长时间挂机：分辨率调低后渲染负担小、发热也轻。挂机前还要选对用户界面——SDL 界面切到后台虚拟机会主动暂停，真正能息屏继续跑的是 VNC（两种界面的取舍见[性能优化设置建议.md](性能优化设置建议.md)第三节），切换后要重启虚拟机才生效。要注意的是息屏后台不等于保险箱——安卓的电池优化仍可能杀掉进程，把 Limbo Plus 加入电池白名单再挂（相关行为见[常见问题与报错处理.md](常见问题与报错处理.md)）。传文件之外如果还想知道哪些配置影响速度，看[性能优化设置建议.md](性能优化设置建议.md)。
