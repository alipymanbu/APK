## 一、装之前先核对三件事

| 项目 | 说明 |
| --- | --- |
| 系统要求 | 安卓 5.2 及以上（以安装时系统弹出的提示为准） |
| 安装包 | v2.0.6-x86 版，约 32.43M，包名 `com.limbo.emu.plus`，MD5 为 `13C06D006D7A4B388232D98021C1F3D5` |
| 系统镜像 | 安装包里不含任何电脑系统，Windows 的 ISO 安装镜像或 vmdk / qcow2 磁盘镜像要另外准备 |

版本号里的 x86 指这份构建用于运行 x86 架构的客户系统（Windows、常见的桌面 Linux 都属于这一类）。装在普通 ARM 手机上就是这份 x86 版，模拟 x86 硬件靠软件翻译指令完成，这也是后面性能表现的根源。

## 二、下载安装包

1. 打开上面的链接，把 [limbo plus 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c655df56cdaf)先转存到自己的网盘账号下；
2. 在网盘里找到 apk 文件（文件名以网盘内显示为准），下载到手机本地；
3. 下载完成后核对一下文件大小在 32M 左右，明显偏小说明没下完整。

## 三、安装步骤

1. 点开下载好的 apk；首次安装时系统会提示「禁止安装未知应用」，按提示允许来自当前来源的安装即可；
2. 安装过程正常会很快完成；装完先不急着点开，往下看第四节，先补一个权限。

## 四、装完第一件事：补存储权限

Limbo Plus 不会在首次启动时主动弹窗申请文件读取权限，而它后续选镜像、建虚拟磁盘都要读文件。没给权限的典型症状：选镜像时点「打开」没反应、内置文件管理器一片空白。

处理路径：系统设置 → 应用管理 → Limbo Plus → 权限 → 存储（或「文件和媒体」）→ 允许。安卓 11 及以上可能显示为「所有文件访问权限」开关，同样打开。个别系统的权限页按应用分组，找不到就搜索应用名。

装好权限之后再去新建虚拟机，选镜像那一步才能正常弹出文件选择界面。

## 五、装完第二件事：准备系统镜像

装完的 Limbo Plus 只是一台「空的电脑」，接下来要给它一个系统：

- **ISO 安装镜像**：全新安装用。比如 Windows 7 / Windows 10 的安装光盘镜像，挂到虚拟光驱里走一遍安装流程；请使用自己持有正版授权的镜像。
- **vmdk / qcow2 整盘镜像**：已经装好系统的磁盘映像，挂上后直接引导开机，不用走安装流程。微软官方为开发者提供带使用时限的 Windows 评估版虚拟机镜像（vmdk 格式，有效期以官方页面为准），地址见 `https://developer.microsoft.com/en-us/microsoft-edge/tools/vms`。
- **轻量系统**：第一次建议先拿 FreeDOS、KolibriOS 或小体积 Linux 的 Live ISO 练手，几分钟就能开机，先把流程跑通再上 Windows；各系统的参考配置见[轻量系统与参考配置.md](轻量系统与参考配置.md)。

镜像文件放手机存储里即可，选大容量、读写正常的位置；存放与挂载的具体操作见[新建虚拟机与运行Windows教程.md](新建虚拟机与运行Windows教程.md)。

如果安装或首次使用时遇到别的状况，直接查[常见问题与报错处理.md](常见问题与报错处理.md)。
