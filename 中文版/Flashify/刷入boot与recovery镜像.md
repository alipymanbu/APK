# Flashify 刷入 boot 与 recovery 镜像教程

> 本篇讲怎么用 Flashify 在系统内直接刷入 boot.img 和 recovery.img，不用重启进 recovery 模式，以及刷之前怎么把原厂 recovery 备份好。

## 一、什么场景用得上这一篇

刷入 boot 或 recovery 镜像是刷机流程里最常见的两步：

- **刷 recovery 镜像**：把原厂 recovery 换成 TWRP、CWM 或 Philz 这类自定义 recovery，是后续刷 zip 包、做完整备份的前提；
- **刷 boot 镜像**：更换内核（kernel），比如换第三方内核调电压、调调度，或刷回原厂内核解决问题。

做这两件事的前提只有一个：**设备已 root**。与刷 zip 不同，刷 img 镜像不需要你已经装好自定义 recovery——Flashify 是直接把镜像写进对应分区。

镜像文件必须与你的机型完全匹配。同一品牌不同型号的 boot 镜像互刷，轻则无法开机，重则变砖。拿不准就去你机型的官方发布页或对应机型的开发者社区找确认过的文件。

## 二、先备份，再动手

刷 recovery 之前，先把原厂 recovery 备份一份——万一新 recovery 有问题，你还能刷回去：

1. 打开 Flashify，切到 **Backup** 标签；
2. 分别备份当前的 **Boot image** 和 **Recovery image**；
3. 备份文件默认存到手机存储，建议再复制一份到电脑或网盘。

完整的多设备备份方案（含云端同步）见[备份与恢复教程.md](备份与恢复教程.md)。

## 三、从应用内直接下载 recovery

如果只是想装 TWRP 这类常见 recovery，不用自己去找镜像文件，Flashify 内置了下载源：

1. 在 **Flash** 标签里选 **Recovery image**；
2. 应用会列出可直接下载的 recovery（TWRP、CWM、Philz 等）和部分内核（如 Franco Kernel）；
3. 选对应你机型的条目下载并刷入。

注意两点：

- 列表里的条目按机型提供，找不到你的机型就别硬选相近的，改走下一节手动刷入；
- 部分下载条目属于付费解锁的范围，免费版能做的刷入操作本身不受影响（免费版的每日次数限制见[常见问题与失败处理.md](常见问题与失败处理.md)）。

## 四、去哪找放心的镜像文件

镜像来源的可靠性直接决定刷机成败，按可信度排：

1. **TWRP 官方支持页** `twrp.me/Devices`：按厂商、型号列出官方适配的 recovery 镜像，找 TWRP 首选这里；
2. **机型开发者社区**（如 XDA 对应机型板块）：找经过多方确认、有持续维护的帖子，注意看回帖里的反馈；
3. **原厂固件包**：从官方固件包里提取的 boot.img / recovery.img，用来刷回原厂最稳。

无论哪个来源，下载完先核对文件的哈希值（方法见[下载与安装教程.md](下载与安装教程.md)第二节），来源再正也挡不住下载不完整。型号核对同样不能省——同一个品牌里型号差一个字母就是不同硬件。找不到对应机型的镜像时，参考[需要先装TWRP吗.md](需要先装TWRP吗.md)第五节的做法，别拿相近型号的凑数。

## 五、手动选择 img 文件刷入

镜像文件已经在手机里时（比如从机型社区下载的 twrp.img）：

1. 把 img 文件复制到手机存储，记下路径；
2. 打开 Flashify → **Flash** 标签 → 选 **Boot image** 或 **Recovery image**；
3. 点 **Choose a file**，在文件选择器里找到那个 img；
4. 确认页面上会显示目标分区和文件信息，核对无误后点 **Yup** 开始刷入；
5. 提示完成后，可以选择立即重启进入 recovery 验证。

整个过程通常几秒到十几秒。刷 recovery 后建议立刻重启进一次 recovery，确认能正常进入再用它做后续操作。

## 六、从其他应用直接调起刷入

img 或 zip 文件在文件管理器、邮件附件里时，不用先挪位置：在原应用里对这个文件用「打开方式」，选 Flashify，它会接管后续的确认与刷入流程。适合临时刷一个刚下载好的文件，少一步复制。

## 七、部分老机型的 Loki 补丁

个别老机型（如早期 LG 部分机型）的引导方式特殊，直接刷入会被拒绝。Flashify 对这类机型会在刷入时自动打 Loki 补丁，不需要你额外操作；如果你的机型不在受支持列表里，刷入会直接报错，而不是把机器刷坏——遇到报错就停下来去机型社区确认方案，别反复重试。

## 八、刷完怎么进 recovery

刷入新 recovery 后重启，用机型的按键组合进入：

- 大多数机型：关机后按住「音量减 + 电源键」（部分机型是音量加）；
- 小米部分机型：关机后按住「音量加 + 电源键」。

具体组合各机型不同，以你机型的官方说明为准。注意一个常见的坑：部分机型首次重启进系统时会把自定义 recovery 换回原厂的，所以刷完先直接进 recovery 确认还在，再回系统——详细说明见[需要先装TWRP吗.md](需要先装TWRP吗.md)第三节。进得去、界面正常，这一步就算完成了，接下来可以按[刷入zip包与刷机流程.md](刷入zip包与刷机流程.md)刷 zip 包了。
