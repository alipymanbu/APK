> 本篇汇总 Flashify 使用中的高频问题：每日刷入次数限制、应用商店搜不到、Root 授权不弹窗、刷完卡开机画面、zip 刷入报错等，逐条给排查路径。

## 一、每天只能刷 3 次？

免费版有**每天 3 次刷入**的次数限制，刷 boot、recovery 或 zip 都计入。当天额度用完只能等次日重置；有长期需求可以在应用内付费解除限制。这是官方设定的免费额度，没有别的正规绕开方式——如果只是偶尔刷一次，免费额度通常够用；刷机当天要连续刷多个包的话，提前把队列排好（见[刷入zip包与刷机流程.md](刷入zip包与刷机流程.md)的多文件队列），把次数用在刀刃上。

## 二、Google Play 里搜不到

这类需要 Root 的刷机工具近年陆续从 Play 商店下架，搜不到或显示不可用属于正常情况，以商店当时显示为准。解决办法就是走 APK 安装：从[下载与安装教程.md](下载与安装教程.md)里的网盘资源获取安装包，允许「安装未知来源应用」后正常安装即可，不影响功能。

## 三、Root 授权窗口没弹出来

打开应用没有 Root 授权弹窗，依次检查：

1. 确认手机确实 root 过——没 root 的设备上 Flashify 刷不了任何东西；
2. 打开 Magisk（或 SuperSU）的授权管理，看日志里有没有 Flashify 的请求记录：
   - 有且被拒绝 → 手动改成允许；
   - 什么记录都没有 → 检查 root 本身是否失效（系统更新后 root 常被冲掉，重刷 Magisk 即可）；
3. 授权时误点了「拒绝」且勾了记住选择 → 在 Magisk / SuperSU 里找到 Flashify 的授权条目删除，重开应用会重新询问。

## 四、刷完卡在开机画面（bootloop）

刷机后超过十分钟还停在开机画面，按这个顺序处理：

1. **进 recovery**：关机后用按键组合进入（多数机型是音量减 + 电源键，小米部分机型是音量加 + 电源键）；
2. **恢复 nandroid 备份**：刷 ROM 前做过的备份在这里派上用场，恢复后手机回到刷机前的状态；
3. **没做过备份**：在 recovery 里执行双清（wipe cache + wipe data）后重刷 zip，或直接重刷原厂镜像；双清会清掉全部用户数据；
4. **recovery 也进不去**：属于「变砖」范畴，需要用电脑走线刷（fastboot 或各品牌线刷工具），具体查你机型的官方线刷教程。

预防永远比补救便宜：刷之前照[刷入zip包与刷机流程.md](刷入zip包与刷机流程.md)的检查清单过一遍，尤其是 nandroid 备份那一项。

## 五、zip 刷入失败或签名校验报错

常见原因按出现频率排：

| 原因 | 表现 | 处理 |
| --- | --- | --- |
| zip 包与机型不匹配 | 刷入报错或刷完必 bootloop | 核对机型后重新找对应包 |
| 包下载不完整 | 安装初期就报错 | 校验 MD5 后重新下载 |
| recovery 版本过老 | 新格式 ROM 包装不上 | 先升级 TWRP（见[刷入boot与recovery镜像.md](刷入boot与recovery镜像.md)） |
| 机型有引导锁（如部分 MIUI 机型） | 反复刷入失败 | 需先按该机型流程解锁引导，查机型社区确认 |

同一件事提前做能省掉大半麻烦：**在「设置 → 关于手机」核对自己机型的准确型号**，再去下载对应的包——型号差一个字母就是不同硬件。

## 六、recovery 刷完重启就没了

明明刷成功了，重启进系统一次之后，再进 recovery 发现又变回原厂界面——这是部分机型的引导机制干的：首次启动系统时会把 recovery 分区重写回原厂。处理办法：

1. 刷完 recovery 后**不要先回系统**，直接用按键组合重启进 recovery，确认自定义界面还在、能操作；
2. 确认无误后再进系统；如果进完系统又被换回去，查你机型社区有没有对应的「防还原」处理方案，这是按机型而定的老问题；
3. 判断自己是否踩了这个坑很简单：重启进系统 → 再重启进 recovery → 界面变回原厂即中招。

详细成因与两条安装路径的取舍见[需要先装TWRP吗.md](需要先装TWRP吗.md)第三节。

## 七、付费项有哪些

免费版能完成刷 img、刷 zip、镜像备份这些核心操作；付费解锁的主要是：云端备份里的 Box 与 Google Drive（Dropbox 免费）、应用内直接下载部分内核与 recovery、以及解除每日 3 次限制。是否付费取决于你的使用频率，具体范围以应用内当时显示为准。

## 八、同类工具参考

如果你的机型 Flashify 覆盖不好，或需求更专门，还有几款同类工具方向：

- **Rashr**：轻量的镜像刷入工具，功能单一但体积小；
- **TWRP Manager**：围绕 TWRP 的管理工具；
- **OrangeFox / SHRP**：第三方 recovery 本体，适配机型与 TWRP 不完全重叠，支持列表以各自官方页面为准；
- **各品牌线刷工具**（fastboot、Odin、SP Flash Tool 等）：recovery 都进不去时的最后手段，走电脑。

方向参考而已，具体支持情况以各工具当前版本为准。刷机相关的基础问题（比如 recovery 怎么进、备份怎么恢复）先回到[备份与恢复教程.md](备份与恢复教程.md)和[下载与安装教程.md](下载与安装教程.md)核对流程。
