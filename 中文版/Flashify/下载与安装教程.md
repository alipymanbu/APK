## 一、安装前先确认三件事

Flashify 是一款安卓刷机辅助工具，功能是直接在系统里刷入 boot 镜像、recovery 镜像和 zip 刷机包，不用手动重启进 recovery 模式。它不是普通应用，装之前先核对三件事：

| 检查项 | 要求 | 不满足的后果 |
| --- | --- | --- |
| Root 权限 | 必须已获取（Magisk 或 SuperSU 均可） | 应用无法刷入任何镜像，基本不可用 |
| 自定义 recovery | 可选（刷 zip 包时需要 TWRP / Philz / CWM） | 只影响刷 zip，刷 boot 和 recovery 镜像不受影响 |
| 电量与数据 | 电量充足（建议 70% 以上），重要数据已备份 | 刷机中途断电可能导致设备无法启动 |

如果你还没 root，先去查自己机型的 root 教程；root 本身有各自的风险与解锁流程，不在本篇范围内。

系统版本方面，有第三方教程以安卓 7.0 为参考门槛，也有更宽松的说法，没有统一口径；真正的硬门槛是上面表里的 Root 权限，你的设备能不能跑，装上试一次最快。

另外提醒一句：刷错机型的镜像可能让手机无法启动。动手前在「设置 → 关于手机」里核对自己的准确型号，一个字母之差就是两种硬件。

## 二、获取安装包

安装包从上面的 Flashify 安装文件资源（夸克网盘）转存下载即可。转存方法：打开链接 → 选择要转存的文件 → 转存到自己的网盘 → 从网盘下载到手机。

下载完成后建议核对一下安装包信息，确认拿到的是这一份：

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.9.2 |
| 包名 | com.cgollner.flashify |
| 安装包大小 | 约 12.27 MB |
| MD5 | 36194D35CF8030A36D1713B94CDF03F0 |

MD5 核对方法：在电脑上用 `certutil -hashfile 文件名.apk MD5`（Windows）或 `md5sum 文件名.apk`（macOS / Linux）算出哈希值，与表中比对；不放心就重新下载一份。

## 三、安装步骤

1. 把 APK 文件传到手机存储（或直接在手机上从网盘下载）。
2. 在文件管理器里点开这个 APK。首次安装外部应用时，系统会提示「不允许安装未知来源应用」，按提示允许对应文件管理器安装应用即可（路径一般在「设置 → 应用 → 特殊应用权限 → 安装未知应用」）。
3. 点「安装」，等待完成。
4. 安装完先不要急着点开，确认手机上已有能授 Root 的管理器（Magisk 或 SuperSU）。

## 四、首次启动与 Root 授权

第一次打开 Flashify 时：

1. 应用会请求 Root 权限，Magisk / SuperSU 会弹出授权窗口，选择「允许」（建议勾选记住选择，免得每次刷入都要确认）。
2. 授权通过后进入主界面，主要分为三个标签页：
   - **Flash**：刷入 boot 镜像、recovery 镜像或 zip 文件；
   - **Backup**：备份当前内核与 recovery；
   - **Restore**：恢复之前备份的内容。
3. 如果授权窗口没弹出来，先确认你确实 root 过，再到 Magisk / SuperSU 的日志里看是否有被拒绝的记录，手动放行即可。

装好后下一步通常有两件事要做：先把当前的 recovery 和内核备份一份（见[备份与恢复教程.md](备份与恢复教程.md)），再按需求刷入 recovery 或 zip 包（见[刷入boot与recovery镜像.md](刷入boot与recovery镜像.md)和[刷入zip包与刷机流程.md](刷入zip包与刷机流程.md)）。

## 五、搜不到这个应用怎么办

在 Google Play 里可能搜不到 Flashify 或显示不可用——这类需要 Root 的老牌刷机工具近年陆续从商店下架，以商店当时显示为准。所以走 APK 安装是现在更常见的方式，也就是本篇第二节的路径。

安装或启动遇到其他问题（闪退、授权失败等）时，先看[常见问题与失败处理.md](常见问题与失败处理.md)。
