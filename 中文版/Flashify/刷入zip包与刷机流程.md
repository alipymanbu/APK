## 一、刷 zip 和刷 img 不是一回事

zip 刷机包（ROM 整包、内核包、Gapps、各种补丁）和 img 镜像走的是两条路：

| 对比项 | img 镜像（boot / recovery） | zip 刷机包 |
| --- | --- | --- |
| 是否需要已装自定义 recovery | 不需要 | **需要**（TWRP / Philz / CWM） |
| 是否需要重启完成 | 不需要，系统内直接写入 | 需要重启进 recovery 完成安装 |
| 典型用途 | 换内核、换 recovery | 刷 ROM、刷补丁、刷 Gapps |

所以动手前先确认：手机上已经装好自定义 recovery（装法见[刷入boot与recovery镜像.md](刷入boot与recovery镜像.md)，两条安装路径见[需要先装TWRP吗.md](需要先装TWRP吗.md)第三节），zip 包是从可信渠道拿的、确认适配你的机型。

## 二、刷入步骤

1. 把 zip 包复制到手机存储；
2. 打开 Flashify → **Flash** 标签 → **Zip file**；
3. 点 **Choose a file** 选中 zip 包；
4. 确认页会列出可勾选的清除选项（仅 TWRP / Philz 下可用）：
   - **Wipe cache**：清缓存分区，安全，一般都勾；
   - **Wipe dalvik**：清虚拟机缓存，安全，换 ROM 时建议勾；
   - **Wipe data**：**清空所有用户数据**，等于恢复出厂，只在跨版本刷机或系统出问题时才考虑，勾之前确保已备份；
5. 点 **Yup**，Flashify 会把文件复制过去并重启进入 recovery 自动完成安装；
6. 安装过程在 recovery 界面上跑，结束后手机自动重启进新系统。

首次开机比平时慢是正常的——新系统在初始化应用，等它自己进桌面，别在这个阶段强制重启。

## 三、多个文件排队刷

要一次刷多个包（比如 ROM + Gapps + 补丁）时，不用等每个包刷完再操作下一个：把文件逐个加入刷入队列，Flashify 会按顺序在 recovery 里依次安装。顺序按依赖关系排——先 ROM，再 Gapps 和补丁。

## 四、刷机前后的检查清单

照着这张表过一遍，能避开绝大多数翻车场景：

| 时机 | 检查项 |
| --- | --- |
| 刷机前 | 电量 70% 以上 |
| 刷机前 | 已做完整备份（见[备份与恢复教程.md](备份与恢复教程.md)） |
| 刷机前 | zip 包与机型完全匹配，来源可信 |
| 刷机前 | 记下当前系统版本，方便描述问题或回滚 |
| 刷机后 | 首次开机耐心等，不强制重启 |
| 刷机后 | 先观察半小时：能不能进桌面、耗电与发热是否正常 |

## 五、刷完进不了系统怎么办

刷完后卡在开机画面（bootloop）是最常见的失败形态，处理思路：

1. 按键组合进 recovery（方法见[刷入boot与recovery镜像.md](刷入boot与recovery镜像.md)）；
2. 能进 recovery 就恢复刷机前做的 nandroid 备份，或双清后重刷；
3. recovery 也进不去的话，走线刷救砖，那是另一个流程，具体看你机型的官方线刷教程。

各情况的具体排查步骤整理在[常见问题与失败处理.md](常见问题与失败处理.md)，先把备份做足再动手，是这个流程里最值钱的一句话。
