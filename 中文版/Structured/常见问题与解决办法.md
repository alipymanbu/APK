# Structured 常见问题与解决办法

> 本篇汇总 Structured 安卓版用起来最常碰到的几类故障：提醒不响、小组件空白、预设任务自己复制、日历事件异常，逐条给出排查顺序。

## 一、设了提醒却不响

按顺序过一遍这张清单：

| 检查点 | 位置 | 要确认的状态 |
| --- | --- | --- |
| 系统通知开关 | 系统设置 → 应用 → Structured → 通知 | 允许通知已开，锁屏、角标、弹窗已勾选 |
| 应用内开关 | Structured 设置 → Notifications & Alerts | 本设备通知已启用 |
| 闹钟权限（Android 13+） | 设置 → Notifications & Alerts → Allow Alarms | 已开启（对应系统「闹钟和提醒」里的 Structured） |
| 勿扰模式 | 系统快捷面板或设置 | 勿扰/专注模式开着时提醒会被拦下 |
| 应用版本 | 应用商店或安装来源 | 应用与系统都更新到较新版本 |
| 设备音量 | 侧键或设置 | 不是静音状态 |

还有一个容易被忽略的上限：官方说明 Structured 最多只会**安排 100 条通知**。日程排得非常满、提醒设得非常密时，排在后面的任务可能就分不到通知了，删掉一些旧任务的提醒可以腾出名额。

从日历导入的事件要单独开提醒：设置 → Notifications & Alerts → Imported Tasks → 打开 Calendar Events，见[提醒与小组件设置.md](提醒与小组件设置.md)第三节。

## 二、小组件空白、模糊或不刷新

按顺序试：

1. 把小组件**删掉，重启手机，重新添加**——多数情况到这一步就好了；
2. 确认 Structured 应用是较新版本；
3. 在应用里随便改动一个任务（比如勾掉再取消），触发小组件刷新；
4. 检查省电与后台限制：系统设置 → 应用 → Structured → 电池，选「不受限制 / 允许后台运行」；省电模式开启时小组件也常会停更，关掉再试——各品牌安卓的省电策略不同，这是小组件类应用的通病，Structured 也不例外；
5. 实在不行，先做备份（见[多设备同步与账号管理.md](多设备同步与账号管理.md)第四节），再删除重装应用。

另外再确认一次显示规则：Timeline 小组件只显示**正在进行和即将开始**的任务，今天早些时候已结束的任务不会出现在里面，这不是故障。

## 三、预设任务自己不停复制

新装的 Structured 会预置 Rise & Shine 和 Wind Down 两条示例任务（旧版本叫 Wake up! 和 Sleep well!）。如果你一点它们就多出一条副本，或者开启同步后它们无限自我复制，官方给出的处理路径是恢复旧备份：

1. 设置 → Advanced → Backups，选一份较早的备份恢复；
2. 如果是新用户、没有备份可用，只能 Advanced → **Reset App** 重置——这会清空全部数据，有重要日程先 Backup now。

## 四、导入的日历事件不对劲

| 现象 | 先查什么 |
| --- | --- |
| 事件没出现在时间线 | Structured 设置 → Calendars 里该日历是否仍勾选；网页版里点一次 resync |
| 删掉的事件还显示 | 在原日历里确认已删，回网页版点 resync 同步删除结果 |
| 共享日历整个没进来 | 部分 Google 共享日历默认不给第三方应用同步；企业账号可能直接禁止访问 |

导入功能本身的步骤与边界（单向同步、只导入前后各三个月等）在[导入谷歌日历教程.md](导入谷歌日历教程.md)第五节有完整列表。

## 五、同步一直转不完成

1. 确认所有设备登录的是**同一个邮箱**——这是最常见的原因；
2. 每台设备都要单独完成一次验证码登录，某台没登就不会同步；
3. 点 **Sync now** 手动推一次，等状态到 Fully Synced；
4. 验证码邮件迟迟不来：先翻垃圾邮件文件夹，再等一两分钟重发一次；
5. 还不行就退出登录重新走一遍登录流程，见[多设备同步与账号管理.md](多设备同步与账号管理.md)第二节。
