## 一、必须注册账号吗

不需要。Structured 不强制注册，单机使用时数据就存在设备本地。账号只在一件事上是必需的：**跨设备同步**（手机之间、手机与网页版之间），以及安卓端通过网页版导入日历的场景。

同步走的是官方自家的 **Structured Cloud**，免费。苹果设备上还有老一代的 iCloud 同步可选，但两种同步方式不能混用；安卓设备只有 Structured Cloud 一条路。

## 二、注册并登录 Structured Cloud

1. 打开 Structured 设置，在 Sync 区块点 **Structured Cloud**；
2. 在 Email 一栏填入你的邮箱，点 **Continue**；
3. 去邮箱里收登录邮件，点其中的链接，或把邮件里的 6 位验证码抄回来填进应用的 One Time Code 一栏；
4. 点 **Submit**，等同步状态变成 **Fully Synced** 就完成了。

换第二台设备时，重复上面的步骤，**必须用同一个邮箱**。两点提醒：

- 6 位验证码只对当前正在登录的这台设备有效，每台设备都要重新收一次码；
- 平时数据自动同步，急用时可以点同步状态下方的 **Sync now** 手动推一次。

## 三、网页版登录

在电脑浏览器打开 [web.structured.app](https://web.structured.app/)，输入邮箱（已在手机上用过 Structured Cloud 就填同一个），点 **Get Started**，同样通过邮件链接或 6 位码验证后即可进入时间线。网页版账号与 Structured Cloud 是同一个账号。网页版独有的批量编辑功能，专门用来一次性调整一堆任务，见[网页版批量编辑任务.md](网页版批量编辑任务.md)。

## 四、备份、恢复与重置

设置里的 **Advanced**（General 区块）集中了数据安全相关的选项：

| 操作 | 位置 | 效果 |
| --- | --- | --- |
| 手动备份 | Advanced → Backups → **Backup now** | 把当前数据存成一份备份 |
| 恢复备份 | Advanced → Backups → 点选某份旧备份 | 数据回退到备份时点 |
| 重置应用 | Advanced → **Reset App** | 清空应用内的全部数据 |

重置应用前先做一次 Backup now，否则数据找不回来。删除应用这类大动作之前，也建议先手动备份一次。

## 五、删除账号与隐私选项

- **删 Structured Cloud 账号**：设置 → Structured Cloud → **Delete Account**。这一步不可逆，云端数据随之删除，做之前确认不再需要。
- **匿名统计**：官方说明 Structured 不收集个性化数据，服务器只存匿名的使用统计；不想共享的话，在设置 → **Privacy & Permissions** 里关掉 **Anonymous Analytics**。

## 六、换手机了怎么办

新旧手机各做一步即可：旧手机确认同步状态是 Fully Synced；新手机安装 Structured 后用**同一个邮箱**登录 Structured Cloud，等状态显示 Fully Synced，日程就搬过来了。登录或同步卡住的应对办法见[常见问题与解决办法.md](常见问题与解决办法.md)。
