# Structured 网页版批量编辑任务

> 本篇讲怎么用 Structured 网页版一次性改一批任务：顺延、换日期、换颜色、转全天或移回收件箱，改动会自动同步回你的安卓手机。

## 一、为什么安卓用户也用得上网页版

手机上一次只能改一个任务；计划大乱的时候（比如整个上午的安排要往后推两小时），逐条点开改效率很低。批量编辑目前只在网页版提供，官方也建议手机用户用网页版做批量调整，改完经 Structured Cloud 同步回手机。

前提只有一个：网页版和手机登录**同一个 Structured Cloud 邮箱**，登录方法见[多设备同步与账号管理.md](多设备同步与账号管理.md)第三节。

## 二、进入批量编辑模式

1. 浏览器打开 [web.structured.app](https://web.structured.app/) 并登录；
2. 点时间线右上角、设置旁边的**对勾图标**，或直接按键盘 **B** 键；
3. 逐个点任务图标上的对勾来选，或点屏幕下方的 **select all** 全选；
4. 选完后底部会弹出一排操作按钮。

## 三、批量操作能做什么

| 操作 | 效果 |
| --- | --- |
| Reschedule | 把选中的任务整体前移或后移指定的分钟数 / 小时数 |
| Date | 把选中任务挪到另一个日期 |
| Color | 给选中任务统一换颜色 |
| Mark as Complete | 全部标为已完成 |
| Delete | 全部删除 |
| Make All-Day（三点菜单里） | 转成全天任务 |
| Move to Inbox（三点菜单里） | 撤回收件箱，等以后再排时间 |

改完点 **Done** 退出批量模式。习惯键盘操作的话，**Esc** 也能退出。

## 四、批量编辑快捷键

以下快捷键只在批量编辑模式下生效：

| 动作 | 快捷键 |
| --- | --- |
| 进入批量编辑 | B |
| 退出批量编辑 | Esc |
| 全选任务 | Cmd + A |
| 删除选中任务 | Delete / Backspace |
| 标记完成 | E |
| 移入收件箱 | I |
| 转为全天 | A |
| 换颜色 | Shift + X |
| 换日期 | Shift + D |
| 整体顺延 | Shift + R |
| 撤销 | Cmd + Z |

## 五、网页版的能力边界

网页版和手机端共享同一条时间线，但不是所有功能都有网页版：

- Structured AI、桌面小组件、能量监控、专注计时器都**没有**网页版；
- 日历导入在网页版反而可用（安卓端暂不支持、网页版支持），是安卓用户接入 Google 日历的官方替代路径，见[导入谷歌日历教程.md](导入谷歌日历教程.md)；
- 批量编辑是网页版独有功能，手机端没有对应入口。

单个任务的常规增删改，还是以手机上的操作为主，方法见[时间线排日程方法.md](时间线排日程方法.md)。
