## 一、先说结论

Structured 可以**永远免费**用下去，官方说明应用不带广告、也不卖用户数据；日常把任务排上时间线、设提醒、挂小组件、多设备同步，这些都不花钱。需要 Pro 的是几类进阶能力：连接外部日历、重复任务、自定义通知、AI 助手、高级图标与配色。

## 二、安卓端功能清单：免费还是 Pro

按官方帮助中心对安卓端的标注整理（功能可用性随版本更新变化，以你应用内实际显示为准）：

| 功能 | 免费 / Pro |
| --- | --- |
| 时间线任务、全天任务 | 免费 |
| 收件箱 | 免费 |
| 图标 | 免费图标可用，高级图标包要 Pro |
| [能量监控（Energy Monitor）](能量监控怎么用.md) | 免费 |
| 桌面小组件 | 免费 |
| 多设备同步（Structured Cloud） | 免费 |
| 重复任务 | Pro |
| 自定义通知 | Pro |
| 日历导入 | Pro |
| Structured AI（自然语言建任务、重排日程） | Pro |

## 三、各平台差异：同一份 Pro 在不同设备上能用多少

Pro 按**账号**生效，可以跨操作系统用在你的个人设备上。但同一功能并非每个平台都做到了，官方的功能对照表当前是这样：

| 功能 | iOS | 安卓 | 网页版 |
| --- | --- | --- | --- |
| Structured AI | 有 | 有 | 无 |
| 日历导入 | 有 | 暂不支持* | 有 |
| 提醒事项导入 | 有 | 无 | 无 |
| 重复任务 | 有 | 有 | 有 |
| Replan（自动重排错过任务） | 有 | 无 | 无 |
| 自定义通知 | 有 | 有 | 无 |
| 自定义配色 | 有 | 有 | 有 |
| 高级图标 | 有 | 有 | 有 |

\* 官方给安卓用户的替代路径：在网页版导入日历，再经 Structured Cloud 同步回手机，见[导入谷歌日历教程.md](导入谷歌日历教程.md)第三节。

另外两个「苹果有、安卓没有」的点，宣传页上看不出来，动手前值得知道：

- **专注计时器（番茄钟）**：只有 iPhone、iPad、Mac 可用，官方明确安卓与网页版还在路线图上。安卓端要番茄钟得另配一个计时工具；
- **锁屏小组件与实时活动**：同样只在苹果生态里。

## 四、价格与订阅方式

官方列出的美元定价（实际价格按地区、货币与购买力调整，以你应用内订阅页显示为准）：

| 周期 | 价格（美元区） |
| --- | --- |
| 月订阅 | US$ 6.99 |
| 年订阅 | US$ 29.99 |
| 买断（终身） | US$ 99.99 |

几点规则：

- 部分地区给安卓用户提供**周订阅**档位；
- 订阅随时可取消，至少在自动续期前 24 小时操作；
- 查本地价格：打开应用 → 设置 → 点 **Get Structured Pro** 横幅进订阅页；或在 Google Play 的 Structured 页面看内购价目。

## 五、怎么升级

1. 打开 Structured 设置；
2. 点 **Get Structured Pro** 大按钮；
3. 选月付、年付或买断，付款走 Google Play（或网页版里的网页支付）。

买断与订阅都跟着你的账号走，换设备后登录同一账号即可继续用；账号与同步的设置见[多设备同步与账号管理.md](多设备同步与账号管理.md)。要是只想先把免费功能用顺手，直接看[时间线排日程方法.md](时间线排日程方法.md)就够了。
