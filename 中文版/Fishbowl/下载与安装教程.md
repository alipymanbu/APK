## 一、先说清这份包是哪一个版本

Fishbowl 是一个面向在职人士的社交应用：你按自己的行业、公司或话题进入一个个叫 Bowl 的群组，看同行在聊什么，也可以自己发帖提问，部分内容允许用不署名的身份发。它免费，装机这一步本身不复杂，真正容易卡住的是打开之后那一关——先过职业身份验证才能正常用，流程见 [注册与工作邮箱验证.md](注册与工作邮箱验证.md)。

动手前先对着下表确认手上这份包对不对：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | Fishbowl（应用商店里的全名是 Fishbowl: Professional Network） |
| 开发者 | Fishbowl Media LLC |
| 包名 | com.fishbowlmedia.fishbowl |
| 版本号 | 6.27.1 |
| 安装包大小 | 91.85 MB |
| 安装包 MD5 | 4C3DE9F0FF8AB699C5EF96D14E81847D |
| 适用设备 | 安卓手机、安卓平板 |
| 界面语言 | 英文 |
| 离线可用 | 否。注册、看帖、发帖、私信全程要联网 |

**别拿别处的版本号来对。** 搜索结果里看到的 Fishbowl 版本号是官方当前最新版，官方一路都用 `6.xx.x` 这种编号，现在商店里的版本已经比 6.27.1 高出不少；两者不是同一个版本，界面入口也可能不一样。判断"我装的这份对不对"只看两项：包名是不是 `com.fishbowlmedia.fishbowl`，版本号是不是 6.27.1。

**最低系统版本这里不写死。** 第三方页面写的"最低支持到安卓几"互相矛盾，都不是官方口径。最省事的判断办法：先用手机浏览器打开 [Google Play 上的 Fishbowl 页面](https://play.google.com/store/apps/details?id=com.fishbowlmedia.fishbowl)，页面提示"此应用与你的设备不兼容"就是装不了；能点"安装"，你的系统版本就够用。真不兼容时安卓会在安装环节直接拦下来，不会装到一半坏掉。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享。相比在搜索结果里随手点一个"立即下载"，从网盘转存再下载的好处是文件来源固定，不会被下载站中途换成别的东西。

1. 在手机上打开 [Fishbowl 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d7973899d779)。手机浏览器或夸克 App 都能打开，**建议用夸克 App**——浏览器下大文件容易被切到后台打断。
2. 点"保存到我的网盘"转存到自己账号下。转存之后，即使原分享链接以后失效，你手上这份也不受影响。
3. 进自己的网盘找到这个文件，点下载，等它落到手机存储里。
4. 下完核对两件事：文件名结尾是不是 `.apk`（这一份的名字形如 `fishbowl_v6.27.1.apk`，以你实际看到的为准）；大小是不是 91.85 MB 左右。差得多的多半是没下完整，删掉重来。

习惯在电脑上操作也行：电脑端网盘下载后，用数据线把文件拷到手机的 `Download` 目录，再从手机"文件管理"里点它安装，效果一样。

有校验工具的话可以顺手算一遍 MD5，和上表的 `4C3DE9F0FF8AB699C5EF96D14E81847D` 比一比。一致说明传输过程没出错，不一致就重新下一遍。不算也不影响安装，只是多一层保险。

## 三、安装：系统会拦一次，放行即可

这份包是手动安装的，不是从手机自带商店点"安装"装上的，所以点安装包时系统会拦一下，提示"不允许安装来自此来源的应用"之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开"文件管理"，进 `Download`（下载）目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的"设置"，打开**允许安装此来源的应用**开关。
   - 部分机型要去"设置 → 应用 → 特殊应用权限 → 安装未知应用"里，找到你刚才用来打开文件的那个应用（文件管理或浏览器），单独给它放行。
3. 回到安装界面点"安装"，等进度条走完。
4. 出现"打开 / 完成"时先点"完成"，别急着进去——先把下面两件事想清楚。

装完如果桌面出现两个 Fishbowl 图标，说明你手机上原来就装过一个。同名不同来源的包不要并存，先卸载旧的再装这一份，否则进去的可能是旧版本。

## 四、首次打开会遇到的权限与那道验证关

第一次打开时，系统会弹权限申请，然后应用会停在登录/注册页面——**Fishbowl 不给未验证身份的人开放内容**，官方商店文案写得很直接：必须用 LinkedIn 账号或工作邮箱。所以这一节的重点不是"点哪个按钮"，而是**先确认你有没有这两样东西**，没有的话装了也进不去。

| 会出现的东西 | 用途 | 建议 |
| --- | --- | --- |
| 通知权限 | 有人回复你、有人私信你的提醒 | 建议给。不给的话这些提醒不会主动弹出来，只能自己进去翻 |
| 麦克风权限 | 参加应用里的语音活动时才用到 | 可以等到第一次想进语音房间时再给，平时看帖发帖用不上 |
| 登录方式选择 | LinkedIn 账号，或工作邮箱 | 两条路的差别与卡点写在 [注册与工作邮箱验证.md](注册与工作邮箱验证.md) |

一个常见的误判：装完打不开、卡在启动画面，就以为包有问题。先在手机浏览器里打开 [www.fishbowlapp.com](https://www.fishbowlapp.com) 试试——如果网页也打不开，说明是网络连不上服务，不是安装包的问题，换网络再试。

## 五、装完先做三步自检

不用急着注册，先花一分钟确认这三件事：

1. **能打开、不闪退**：点图标能进到界面。反复闪退的看 [常见问题与排查.md](常见问题与排查.md) 里"打开就闪退，或者卡在启动画面"那一节。
2. **能连上服务**：停在登录页而不是卡在启动图或转圈，说明网络通了。停在启动图的话，按上面那条先用浏览器验证一遍网络。
3. **包名对得上**：想更稳妥，可以在"设置 → 应用 → Fishbowl"里看应用信息，包名应当是 `com.fishbowlmedia.fishbowl`。名字里带 fishbowl 的应用不止一个，怎么区分见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

三步都过，就可以去走注册流程了。

## 六、升级与卸载要注意的

- **升级**：新版本会换一个安装包文件名，直接装新包覆盖即可，一般不用先卸载。Fishbowl 更新比较勤，官方更新记录里近一两年大致每一到两个月推进一个新版本号（以商店更新记录为准），覆盖安装不会影响你已登录的账号。
- **卸载**：卸载只清掉本机的应用数据，你发过的帖子和账号都还在服务端，换设备重新登录即可找回。真要清账号，得走应用内的注销入口，而不是卸载。
- **旧安装包**：这一份 6.27.1 装好之后可以删掉 apk 文件省空间；以后想重装，回到文首那条 Fishbowl 安装文件资源的链接再取一份就行，已经转存过的不受原分享影响。
