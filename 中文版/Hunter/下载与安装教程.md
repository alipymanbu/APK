## 一、这是什么、你拿它做什么

Hunter 是一款安卓端的设备环境检测工具，你在手机上打开它，它就把当前设备的 Root 状态、框架痕迹、模拟器环境、设备指纹等逐项扫一遍，给出一份带结论的报告。典型的两类用法：

- 你的手机做过 Root 或刷过机，想知道自己改动之后的环境到底「干净」到什么程度；
- 你在两台设备之间换机、或者刚刷完机，想快速确认这台机器的基础环境有没有异常提示。

它本身在普通手机上就能跑，**不需要先给它 Root 权限**。检测在哪一篇讲，见 [检测结果怎么看.md](检测结果怎么看.md)。

## 三、下载与安装步骤

1. 从 [Hunter 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0dd64a52bba0) 下载 `Hunter_v6.65.apk` 到手机（或先下到电脑再传过去）。
2. 用手机自带的文件管理器点开这个 APK。系统会弹「允许安装未知来源应用」的提示，对该来源放行一次即可（不同品牌路径略有差异，一般在 设置 → 安全/隐私 → 安装未知应用 里）。
3. 装完打开，首次启动会请求读取设备信息一类的基础权限，授予后才跑得了检测。
4. 进入首页就能看到本次检测的结论，具体怎么看见 [检测结果怎么看.md](检测结果怎么看.md)。

**校验文件是否完整**：下完可以在电脑上比对 MD5，与上表一致就说明文件没传坏。Windows PowerShell 里执行：

```powershell
Get-FileHash -Algorithm MD5 .\Hunter_v6.65.apk
```

输出应为 `0AAAE2F92DC6DCFFB1F39970C882B26E`（哈希值大小写不区分）。

**装的时候留个心眼**：Hunter 这类环境检测工具要读大量系统信息，装之前确认你下的是哪个渠道的包 —— 同名包被替换过就失去意义了。体积也随版本明显变化（6.58 时约 12M，6.65 涨到 20.07M，之后的版本更大约 22M，均以各下载页当时显示为准），**体积对不上就是拿错了包**。

## 四、装不上或装完打不开时

先按顺序排除这三条最常见的原因，多数安装问题到这里就结束了：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点击 APK 无反应或提示「禁止安装」 | 未对该来源放行未知安装 | 按第三步第 2 条放行后重试 |
| 提示「解析包时出错」/「应用未安装」 | 系统低于安卓 5.2，或包下载不完整 | 确认系统版本；重新下载并校验 MD5 |
| 装完闪退 | 手机的省电策略清理了后台 | 关掉对该应用的强制后台清理，重新打开 |

装好之后如果检测报出一串异常，先别急着重装 —— 见 [黑灰设备提示是什么原因.md](黑灰设备提示是什么原因.md) 逐条对照。

## 五、从旧版升上来要注意什么

- Hunter 是覆盖安装：直接装新版即可，检测历史记录是否保留取决于新版，不能保证。
- 如果你装它是为了验证某个 Root 隐藏方案的效果，**升级后建议重测一遍** —— 检测项会随版本增加（6.65 就新增了 SOTER 与 IFAA 指纹检测、内存信息显示），新版本可能查出旧版本没查的项目。这类验证场景的操作见 [隐藏Root后检测不通过怎么办.md](隐藏Root后检测不通过怎么办.md)。
