## 一、先核对版本信息

MChat 是一款即时聊天社交应用，支持文字、图片、语音、视频通话等多种沟通方式，消息可以在多个设备之间同步。本篇讲的安装包是下面这一版：

| 项目 | 信息 |
| --- | --- |
| 版本号 | 2.9.16 |
| 包名 | com.mcmsgbangong.mc |
| 安装包大小 | 90.56 MB |
| MD5 | b74412ad14b421dd434a05291b78169f |

三点说明：

- 这是安卓 APK 安装包，只能装在安卓手机或安卓平板上，iPhone 装不了 APK；
- 网上搜到的官方最新版版本号可能更高，与你实际拿到的包不一定是同一个版本，功能细节以你手上这版为准；
- 安装前确认手机剩余存储明显大于 90.56 MB，空间不足会在安装中途失败。

## 二、安装文件从哪里拿

这份 MChat 安装文件资源放在夸克网盘：[MChat 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ea59ce4d06a7)。操作顺序：

1. 用手机浏览器或夸克 App 打开上面的链接；
2. 把资源转存到自己的网盘（不转存无法下载）；
3. 在夸克 App 里把 APK 下载到手机本地，文件名形如 `mchat_v2.9.16.apk`。

## 三、安装步骤（安卓）

1. 打开手机「文件管理」，找到刚下载的 APK 文件，点它；
2. 系统弹出「是否允许安装未知来源应用」时选择允许——这是安卓对所有应用商店之外 APK 的统一提示，不代表包有问题；
3. 等安装完成后，桌面上会出现 MChat 图标；
4. 首次打开时系统会逐条询问权限，几条参考：
   - 麦克风、相机：语音通话和视频通话依赖这两个权限，拒绝后通话功能用不了，可以先只聊天、之后再按需开；
   - 存储/照片：发图片、保存图片会用到；
   - 通知：不开启的话，收到消息不会有提醒；安卓 13 起新装应用的通知权限默认就是关闭的，首次弹询问时直接选允许；
5. 进应用后按界面提示注册或登录账号，就能开始聊天了。聊天功能怎么用见[聊天与群聊功能上手.md](聊天与群聊功能上手.md)。

部分国产系统（MIUI、HarmonyOS、ColorOS 等）在安装时还会额外弹一道「风险应用」确认，属于系统对商店之外 APK 的常规拦截，确认继续即可；被直接拦下装不上的，看下一节。

## 四、安装被拦或失败

| 现象 | 处理 |
| --- | --- |
| 提示「禁止安装未知来源应用」 | 在系统设置里找到「安装未知应用」列表，给你用来打开 APK 的那个应用（浏览器或文件管理器）授权，再回去点 APK |
| 提示「解析包出错」 | 多半是包没下完整，删掉本地文件重新下载，下完按第五节核对 MD5 |
| 安装到一半失败 | 清出存储空间后重装；空间够还失败就重启手机再装一次 |

装好之后用着还有别的状况，汇总在[常见问题与解决.md](常见问题与解决.md)。

## 五、下载后核对安装包（MD5）

想确认拿到的 APK 与第一节表格一致，在电脑上用 PowerShell 执行：

```powershell
Get-FileHash .\mchat_v2.9.16.apk -Algorithm MD5
```

输出的哈希应等于 `b74412ad14b421dd434a05291b78169f`。对不上说明文件在传输中损坏或被改动过，不要安装，重新下载一份再核。
