## 一、安装前先核对这几项

| 项目 | 信息 |
| --- | --- |
| 版本 | 1.0 |
| 安装包大小 | 10.50M |
| 包名 | com.wY8Games_8931045 |
| MD5 | A4395A316D67D1CF20FBB802BDE82FAF |
| 系统要求 | 安卓 5.2 以上（按安装包标注） |

这是网盘里那份安装包的实际信息。网上搜到的"最新版"与它不一定相同——你手机里装的是哪一版，以你手里这份安装包为准。

Y8Games 本体很小（10.50M），因为它只是个"入口"：游戏本身不装进手机，点开就在线玩。所以不用担心空间问题，真正的开销在玩的时候产生的网络流量。

## 二、拿到安装包

1. 打开 [Y8Games 安装文件资源（夸克网盘）](https://pan.quark.cn/s/7771e381ec79)；
2. 建议先把文件转存到自己的网盘，再从网盘下载到手机（分享链接失效时，转存过的那份不受影响）；
3. 下载完成后，APK 文件会出现在手机的"下载"目录或通知栏里。

## 三、安装步骤

1. 在通知栏或文件管理器里点开刚下载的 APK；
2. 如果系统提示"禁止安装未知来源应用"，按提示去设置里放行——常见路径是「设置 → 应用 → 特殊权限 → 安装未知应用」，给你用来点开 APK 的那个应用（文件管理器或浏览器）勾上允许；
3. 回到安装界面，点"安装"，等进度走完；
4. 点"打开"，或者回到桌面找 Y8Games 的图标。

不同品牌的手机放行路径叫法略有差异（有的叫"安装未知应用"，有的藏在"安全"里），认准"允许此来源安装"这个开关就行。

## 四、首次打开

- 首屏是游戏分类和推荐位，不注册账号也可以直接浏览、直接玩大部分游戏（要不要注册，见 [要不要注册账号.md](要不要注册账号.md)）；
- 如果界面不是中文，按 [怎么切换中文.md](怎么切换中文.md) 的三步改成中文；
- 想知道怎么找游戏、怎么开始玩，看 [在线玩游戏入门.md](在线玩游戏入门.md)。

## 五、装不上或打开就闪退

安装中断、提示"解析包出错"、打开即闪退，多数和安装包完整性或系统版本有关。先按 [游戏打不开怎么办.md](游戏打不开怎么办.md) 第四节核对 MD5 再重新下载，通常能解决。
