# 要不要注册账号

> Y8 平台的账号管的是聊天、分数、成就和跨设备进度，不注册也照样玩。本篇讲账号能干什么、怎么注册、以及什么情况下值得注册。

## 一、先说结论：不注册能玩吗

能。平台多数游戏不登录就能直接玩——免费、免安装、免注册是它的默认状态。账号影响的是"玩之外"的那一层：社交、记录和跨设备接续。装完 App 直接开玩完全没问题，账号可以等真需要了再注册。

## 二、账号能干什么

按平台官方口径，账号覆盖这几件事：

| 能力 | 说明 |
| --- | --- |
| 保存分数 | 游戏成绩记录在账号下，换设备不丢 |
| 解锁成就 | 大量游戏内置成就，完成挑战后记录在账号上 |
| 聊天与互动 | 和其他玩家交流、留言 |
| 一次登录多处通用 | 一个账号可用于平台旗下多个站点与游戏 |

不注册时，进度依赖游戏自身的保存机制（详见 [在线玩游戏入门.md](在线玩游戏入门.md) 第三节）。

## 三、怎么注册

截至本文写作时，平台的注册入口在 `account.y8.com`（也可以在 [www.y8.com](https://www.y8.com) 页面里找账号入口）：

1. 打开注册页，填**邮箱**和**密码**（两遍确认）；
2. 通过页面上的人机验证；
3. 提交后账号即生效，登录一次可在平台旗下多处使用。

几点注意：

- 账号支持短信等方式做二次保护，在意安全就在设置里开启；
- App 内注册或登录的入口位置以你手上版本的界面为准，找不到时去网页端注册，再回 App 登录试试；
- 卸载 App 不等于注销账号，账号本身仍留在平台侧，删除账号等操作以官方页面为准。

## 四、判断要不要注册的三条依据

1. **随手玩玩、打发时间** → 不用注册，装上就玩；
2. **在意高分记录、成就、和人对战聊天** → 注册，这些功能都挂在账号上；
3. **换手机频繁、想跨设备接续进度** → 注册，并确认常玩的那些游戏支持云存档（不是每个游戏都支持）。

## 五、安全注意

- 注册邮箱用自己常看的，密码不要与常用密码相同；
- 账号开通短信保护后再存重要进度；
- 在公共设备上登录后记得退出。
