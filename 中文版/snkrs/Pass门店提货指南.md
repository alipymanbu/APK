## 一、Pass 和普通抽签差在哪

普通抽签中签后是邮寄到家，Pass 则是：你在应用里参与抽选，中签后拿到一张电子凭证（Pass），按上面标注的时间和店铺，**自己去门店付款提货**。它只对附近一定范围内的门店开放，所以和你的位置直接相关。Pass 与其他三种发售形式的对比表在[发售形式与登记规则.md](发售形式与登记规则.md)里。

官方的说明页在 [www.nike.com.cn/help/a/nike-snkrs-pass](https://www.nike.com.cn/help/a/nike-snkrs-pass)，下面的要点整理自官方口径，细节以该页当时内容为准。

## 二、参与前的两个前提

1. **开启定位（GPS）**：Pass 靠定位来判断你附近有哪些可参与的门店；附近没有提货点时，你连参与资格都没有；
2. **开启推送通知**：抽选结果通过通知告知。

这两项都在手机系统设置里允许即可，位置权限建议设为「使用应用期间允许」。

## 三、完整流程

1. 在应用的「动态」里找到进行中的 Pass，进入活动页；
2. 在抽选时间内选择尺码提交（每个人的参与资格只有一次，也不能同时在多家店参与同一款）；
3. 抽选时间结束后等通知，中签的话，Pass 页面会显示「预约详情」：鞋款、尺码、可提货的店铺、提货日期范围；
4. 在提货期内本人到店，出示 Pass 上的提货二维码和证件，现场付款拿鞋。

## 四、到店要带什么

- **手机上的 Pass 与提货二维码**（注意：Pass 只在参与抽选的那台设备上有效，换设备无效）；
- **带照片的有效身份证件原件**，官方列举包括：驾驶证、学生证、护照、军人证等；
- 证件上的姓名必须与 Pass 上的姓名**完全一致**——参与前先去账号资料里核对姓名，对不上店里有权不给提。

几个官方明确说「不行」的地方，提前知道省得白跑：

| 问题 | 官方口径 |
| --- | --- |
| 能让家人朋友代提吗 | 不能，只有 Pass 上显示的姓名本人有资格购买 |
| 能让门店快递寄给我吗 | 不能，必须本人到店 |
| 提交后能改尺码或换门店吗 | 不能，姓名、尺码、门店一经提交不可更改 |
| 错过提货期会怎样 | Pass 过期作废，无法再购买该鞋款 |
| 付款在应用里完成吗 | 不行，Pass 中签者到店支付货款 |

## 五、中签后可以不去吗

可以。Pass 是到店才付款，中签不等于强制消费——这一点和邮寄类抽签不同（邮寄类中签会自动扣款，见[抽签购买流程详解.md](抽签购买流程详解.md)）。只是决定不去的话别拖到提货期结束，也不影响你参加之后的发售。

到店提货少不了账号信息正确，姓名、鞋码这些资料的核对方法见[账号注册与会员设置.md](账号注册与会员设置.md)。
