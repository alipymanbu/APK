## 一、什么样的鞋会走抽签

普通款在应用里直接买即可；限量、热门的特别版鞋款参与人数远超货量，官方就会把这场发售做成抽签——每人在规定时间内提交一次参与，时间截止后系统随机抽选，中签的人获得按原价购买的资格。是否采用抽签、开放时间、付款时限，都以那双鞋的发售页面说明为准。

注意抽签不是唯一的发售机制：边登记边抽选的普通发售、需要官方邀请的专属抽签、到店提货的通行证各有各的规则，四种形式对比见[发售形式与登记规则.md](发售形式与登记规则.md)。

## 二、参与步骤

1. **找到场次**：即将发售的鞋款会出现在应用的「预告 / Upcoming」动态里，心仪的鞋款点「通知我」；
2. **在开放时间内提交**：抽签只在限定时间窗口内接受参与，页面上有倒计时；进入页面，选鞋款和尺码，确认提交；
3. **等结果**：窗口关闭后系统随机抽选，一般会在 24 小时内通过推送和邮件通知你是否中签（以页面说明为准）；
4. **中签后**：按你账号里预存的支付方式自动扣款，并收到订单确认；之后就是等收货。

支付方式必须在提交参与之前就存好——中签靠它扣款，这也是[账号注册与会员设置.md](账号注册与会员设置.md)里反复强调提前保存付款信息的原因。

发售开始后如果先看到「排队」提示，别关页面、别反复重进：官方把同一时刻涌入的人放进数字队列按顺序处理，排到你且还有货才会生成订单，没排到不扣款。排队时的正确做法见[发售形式与登记规则.md](发售形式与登记规则.md)第二节。

## 三、规则速查表

下面这些是官方抽签规则里的关键条目，参与前过一遍：

| 规则 | 内容 |
| --- | --- |
| 参与次数 | 每人每场发售只能提交一次；同一场多账号、同地址参与只认可一份 |
| 尺码 | 提交之后不能更改，提交前想清楚 |
| 资格转让 | 不可以，中签资格只属于提交参与的账号本人 |
| 未中签 | 不扣款，也无法购买该款，只能等下一场 |
| 不想要了 | 中签即视为同意购买；不想要可以按官方退货政策退回 |
| 违规后果 | 违反发售规则的参与会被取消，情节严重的会影响后续参与资格 |

## 四、中签之后的付款时间

中国区的口径：特别版或排队抢购类产品，订单生成后付款有效期一般为 **10 分钟**（以产品详情页标注为准），超时订单会被取消。所以发售当天别到时候再填地址、绑卡——这些都应该提前做完（见[账号注册与会员设置.md](账号注册与会员设置.md)第二节）。

付款、取消订单和退款的时限与到账周期，另见[付款时限与退款周期.md](付款时限与退款周期.md)。

## 五、没中签正常吗

正常，而且是最常见的结果。中签概率取决于有效参与总数和货量，官方没有公布比例。能做的只有：把推送通知开好、关注官方预告渠道（见[账号注册与会员设置.md](账号注册与会员设置.md)第四节）、下一场按时参与。不要使用多账号或第三方代抢——这类操作违反官方规则，被判定后参与会被取消，账号也可能失去后续资格。

除了线上邮寄的抽签，SNKRS 还有「线上抽选 + 到店提货」的形式，流程和证件要求见[Pass门店提货指南.md](Pass门店提货指南.md)。
