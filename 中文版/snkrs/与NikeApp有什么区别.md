# SNKRS 与 Nike App 有什么区别

## 一、一句话分清

按官方帮助页（[www.nike.com.cn/help/a/nike-snkrs-app-difference-cn](https://www.nike.com.cn/help/a/nike-snkrs-app-difference-cn)）的口径：**Nike App 是会员中心加全品类商店**，官网上的鞋款和装备它都有售；**SNKRS 是专门围绕球鞋发售的应用**，热门鞋款的消息提醒、发售日历、抽签、到店提货都发生在这里。

两个 App 用的是**同一个 Nike 会员账号**，注册一次两边都能登录，会员身份、收货地址、支付信息互通。

## 二、逐项对照

| 你要做的事 | 用哪个 |
| --- | --- |
| 抢限量/热门球鞋（抽签、排队） | SNKRS |
| 看发售日历、订阅新品提醒 | SNKRS |
| 线上抽选、到店提货（Pass） | SNKRS |
| 日常买服装、配件、普通鞋款 | Nike App |
| 找会员专属福利、活动 | 两个都有，Nike App 更全 |
| 了解球鞋背后的设计与故事 | SNKRS |

如果只装一个：想抢热门鞋款就装 SNKRS；只是日常买买运动装备，Nike App 就够。两个同时装不冲突，地址和支付方式共享。

## 三、周边还有几个容易混淆的入口

- **Nike 微信小程序与官网**（[www.nike.com.cn](https://www.nike.com.cn)）：与两个 App 同属一套线上体系，账号通用；
- **Nike Run Club / Nike Training Club**：跑步与训练两个独立应用，与购物无关，不需要的话可以不装；
- **官方微信公众号（nikejdi）与 Jordan 中国公众号**：发售信息的推送渠道，见[账号注册与会员设置.md](账号注册与会员设置.md)第四节。

分清之后，回到你装这个应用的最初目的：装好、登录、把信息存好，流程从[下载与安装教程.md](下载与安装教程.md)开始；想抢鞋的直接看[抽签购买流程详解.md](抽签购买流程详解.md)。
