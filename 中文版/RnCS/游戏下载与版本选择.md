# Rn:CS 启动器游戏资源下载与版本选择

> 本篇讲在 Rn:CS 启动器里怎么把 CS 游戏资源下到手机：版本怎么选、下载按钮在哪、下载卡住怎么办。启动器本身装好只是第一步，游戏资源要在这里单独下载；下完之后的联机步骤见 [服务器连接与开始游戏.md](服务器连接与开始游戏.md)。

## 一、支持哪些版本

启动器面向 CS 系列游戏，多个来源一致的说法是兼容 CS1.6、CS:GO、CS2 三个主流版本。另有渠道列出了 csmos、csso 等分支版本（如 csmos 8.0、6.5 等，此说法来自单一来源）——你以启动器「游戏」板块里实际列出的版本为准，界面列表会随资源更新变化。

版本选择的实际考量：

| 你的情况 | 建议先下的版本 |
| --- | --- |
| 想重温老版经典对战 | CS1.6 |
| 想玩接近现代 CS 的手感 | CS:GO 或 CS2 |
| 手机配置一般、存储紧张 | 从体积小的版本下手，别一次全下 |

注意一点：版本列表是「游戏资源」的清单，不是启动器功能清单。列表里没有的版本，说明当前没有对应资源可下，等启动器内更新即可。

## 二、下载步骤

游戏资源的下载入口在启动器的「游戏」板块，流程是固定的四步：

1. 打开 Rn:CS，点底部的「游戏」板块，弹出版本列表。
2. 在列表里勾选你要下的版本（比如 CS1.6）。
3. 点「下载」，启动器开始拉取资源并自动完成安装。
4. 等进度条走完再操作下一步，中途退出可能留下不完整的资源。

下载期间注意两点：

- **别急着退出**。资源下载到一半就切后台或杀进程，容易产出损坏的文件，之后进服务器时会报错。
- **用稳定的网络**。几个版本的资源加起来体积不小，尽量在 Wi-Fi 下进行。

## 三、下载完成后的确认

下载完成后切到「服务器」板块：如果你刚才下载的版本出现在弹窗列表里、能被选中并确认版本信息，说明资源安装完整，可以直接进入选服环节。列表里找不到刚下的版本，多半是下载中断留下的残缺资源——删掉重下一次，比反复重试连接省时间。

进入服务器、输昵称、开始游戏的具体操作在 [服务器连接与开始游戏.md](服务器连接与开始游戏.md)。

## 四、游戏资源的自动更新

启动器自带更新检测：游戏资源出新版本时，它会自动发现并提示一键下载补丁，你不需要自己去别处找补丁包。收到更新提示时直接在启动器里更新即可，更新后原有服务器列表和自定义房间入口不受影响。

启动器自身的版本更新（比如从 r13.3 到更新的 r 版本）不在这套机制里，需要重新获取新安装包覆盖安装，见 [下载与安装教程.md](下载与安装教程.md)。

## 五、插件与 MOD 管理

两个独立来源都提到启动器带插件 / 模组管理能力，可以安装、卸载、启用趣味武器、特色地图这类 MOD，并且启动器会处理兼容性、做冲突检测。注意这部分描述都来自渠道介绍页而非操作手册，**具体入口以你手上版本的界面为准**——通常在游戏板块的资源管理区域附近找「插件」「模组」「MOD」字样的入口。

用 MOD 的两条实际建议：

1. **一次只改一个变量**。装 MOD 后出问题（闪退、进不了图），先把 MOD 全部停用回到原状，再逐个启用定位冲突源。
2. **MOD 与游戏资源是两套东西**。更新游戏资源版本后，之前装的部分 MOD 可能失效，重新启用或删除即可，不用重下游戏。

## 六、下载卡住或速度慢

下载卡在某个百分比或速度特别慢时，按这个顺序处理：

1. 检查网络：切一次 Wi-Fi / 流量，很多时候是当前网络到资源服务器的链路不稳。
2. 完全退出启动器再重开，刷新资源链接后重新下载。
3. 还不行就换时段再试，避开晚间高峰。

多次重试都失败的话，见 [常见问题排查.md](常见问题排查.md) 里的下载类问题汇总。
