## 一、先说清这份包是哪一个版本

Hilton Honors 是希尔顿酒店集团的官方 App，中文名「希尔顿荣誉客会」，用来搜酒店、订房、在线入住、用手机开房门，以及查积分和会员等级。它适合会入住希尔顿旗下品牌酒店的人；如果你基本不住希尔顿，这个 App 装了也用不上。装机本身不复杂，容易卡住的只有两处：包从哪来，以及首次打开要把哪几项配好。

动手前先对着下表确认手上这一份是不是对的：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | Hilton Honors（希尔顿荣誉客会） |
| 开发者 | 希尔顿酒店集团（Hilton） |
| 包名 | com.hilton.android.hhonors |
| 版本号 | 2025.7.22 |
| 安装包大小 | 140.49 MB |
| 安装包 MD5 | 82CE81AD16EC07A78B91C7D475C5A926 |
| 适用设备 | 安卓手机、安卓平板 |
| 是否需要联网 | 订房、在线入住、手机开门、查积分都要联网；断网时连酒店列表都刷不出来 |

**版本号要对得上，但别拿别处的版本号来对。** 你在网上看到的 Hilton Honors 版本号，一般是官方当前最新版，和这一份未必是同一个。判断「我装的对不对」只看两项：包名是不是 `com.hilton.android.hhonors`，版本号是不是 `2025.7.22`。

**这里不写死最低系统版本。** 各家第三方页面标注的最低安卓版本互相矛盾，都不是官方口径。判断办法是：先在手机上打开 [Google Play 上的 Hilton Honors 页面](https://play.google.com/store/apps/details?id=com.hilton.android.hhonors)，如果显示「此应用与你的设备不兼容」，那就是装不上；能点「安装」，说明你的系统版本够用。系统版本不够时系统会自己拦下来，不会装到一半坏掉。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享。相比在搜索结果里随手点一个「立即下载」，从网盘转存再下载的好处是这一份链接固定，文件不会被中途换成别的东西。

1. 在手机上打开 [Hilton Honors 安装文件资源（夸克网盘）](https://pan.quark.cn/s/b2b5ad598627)。手机浏览器或夸克 App 都能打开，**建议用夸克 App** —— 浏览器下大文件容易被切后台打断。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存之后，之后下载就不再依赖原分享链接还在不在。
3. 进自己的网盘找到它，点下载，等它落到手机存储里。
4. 下完核对两件事：文件名结尾是不是 `.apk`（这一份形如 `Hilton Honors_v2025.7.22.apk`）；大小是不是 140.49 MB 左右。差得多的多半没下完整，删掉重来。

习惯在电脑上操作的话：电脑端网盘下载好，用数据线拷进手机的 `Download` 目录，效果一样；再从手机「文件管理」里点它安装即可。

有校验工具可以顺手算一遍 MD5，和上表的 `82CE81AD16EC07A78B91C7D475C5A926` 比一比。一致说明传输没出错，不一致就重下一遍。不查也不影响安装，这只是多一层保险。

## 三、安装：系统会拦一次，放行即可

这一份是从网盘分发、手动安装的，不是从手机自带应用商店点「安装」装的，所以点安装包时系统会拦一下，提示「不允许安装来自此来源的应用」之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开「文件管理」，进 `Download`（下载）目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要去「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，找到你刚才用来打开文件的那个 App（文件管理或浏览器），单独给它放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时，先点「完成」—— 首次启动前把几项配置一次性理顺，比进去之后反复弹窗省事。

## 四、首次打开要处理的几项

装完第一次打开，按下面顺序过一遍。这几项直接决定「在线入住、选房、手机开门」能不能用：

| 项目 | 作用 | 建议 |
| --- | --- | --- |
| 通知权限 | 房间准备好、数字钥匙下发、入住提醒都靠它推送；不给就只能自己反复刷 | 必须给 |
| 蓝牙 | 手机开门（数字钥匙）靠蓝牙与门锁通信，关着就开不了门 | 必须给 |
| 位置 | 用来定位你附近的酒店、给出入住提示 | 建议给，拒绝只影响附近推荐 |
| 生物识别（指纹 / 人脸） | 免去站在房门口输密码 | 建议开 |
| 登录 / 注册 | 不登录只能搜索，订房、积分、数字钥匙都要账号 | 见 [注册登录与账号设置.md](注册登录与账号设置.md) |

一个实际会遇到的情况：手机开门最先要查的就是蓝牙。不少人习惯性把蓝牙关着，到了房门口才发现按不开，回来看设置才知道原因 —— 首次打开时顺手把蓝牙打开，能省一次返工。

## 五、装完先做三步自检

不用急着订房，先花一分钟确认这三件事，后面出问题也好定位：

1. **能打开、不闪退**：点图标能进到首页，看得到搜索酒店的入口。反复闪退的话看 [常见问题与排查.md](常见问题与排查.md) 里「打开就闪退」那一节。
2. **能搜到酒店**：在搜索框输入一个城市名（例如「上海」），能看到酒店列表和价格。这一步同时验了网络与账号状态。
3. **能进到预订页**：随便点一家酒店、选一个日期，能看到房型和价格。走到这一步为止不付款也不会产生订单，走一遍能把「卡在哪一步」提前定位出来。

三步都过，就可以正常用了。接下来先注册或登录账号，见 [注册登录与账号设置.md](注册登录与账号设置.md)。

## 六、升级与卸载要注意的

- **升级**：新版会换一个安装包文件名，直接装新包覆盖即可，一般不用先卸载。**先卸载再装反而可能把没同步走的本地设置清掉** —— 安卓默认连应用私有目录一起删。
- **卸载**：卸载不影响你账号里的订单、积分和会员等级，那些数据在希尔顿服务器上，重装后重新登录就能看到。会丢的只是本机缓存的登录状态和 App 内的偏好设置。
- **安装包删了**：任何时候都能回文首那条 Hilton Honors 安装文件资源的链接重新取一份；已经转存过的不受原分享影响。
