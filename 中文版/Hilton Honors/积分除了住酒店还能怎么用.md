# 积分除了住酒店还能怎么用

## 一、兑换住宿只是其中一种花法

积分最常用、也最好算账的用法当然是换房（规则见 [积分怎么赚怎么用.md](积分怎么赚怎么用.md) 第三节）。但官方还提供另外几条路：竞拍体验、把积分池起来一起用、换购物或打车的抵扣。这几条各有各的限制条件，**先看清楚哪条对你有用，再决定积分是留着换房还是拿去花**。

## 二、竞拍特色体验：用积分换独家名额

官方的「希尔顿荣誉客会体验」平台会把演唱会、赛事、餐饮、目的地行程这类独家名额放出来，会员用积分**竞拍或直接兑换**。中文入口是 [希尔顿荣誉客会体验](https://experiences.hilton.com.cn/)，用会员编号和密码登录即可参与。

规则里这几条最容易踩到，动手前先看：

| 规则 | 具体内容 |
| --- | --- |
| 参与资格 | 所有希尔顿荣誉客会会员都能竞拍与兑换，没有等级门槛 |
| 年度次数上限 | 一个日历年内最多兑换 **5 次**体验 |
| 竞拍时的积分要求 | 同时竞拍多个体验时，账户积分要**大于等于全部中标积分之和**，不是中一个算一个 |
| 积分不够怎么办 | 可以在竞拍前购买积分，或接受他人的积分转赠来补足 |
| 中标之后 | **不可转让、不可修改、不可取消、不可退款** |
| 想送人 | 可以赠送给亲友，但要事先取得书面同意并遵守该体验的适用条款 |

「中标后不可退」这一条决定了**竞拍要当付款来对待** —— 行程还可能变的话，别拿大额积分去赌一个不可退的名额。

## 三、Points Explorer：先看积分能走多远

官方有个叫 **Points Explorer** 的工具，作用很直白：告诉你手上的积分大概能换到哪些酒店、什么标准。适合在「今年攒的分够不够一趟旅行」这种问题上先有个底，再决定要不要参与促销冲分。

它的结论是估算性质，实际可用酒店与所需积分随日期浮动，**以搜索时的实际显示为准**。

## 四、积分池：一家人把分凑到一起

如果你的家人都各自有账号、每人攒了几万分但都换不到一整晚，官方提供的**积分池（Points Pooling）**就是把分合起来用的机制：

- 最多可有 **10 位会员**共用一个积分池（连发起人算在内共 11 人）；
- **没有手续费**；
- 池起来的积分用于住宿兑换。

它和「一对一转赠」是两套不同的机制，两者共用年度额度与笔数上限（具体数字见 [积分怎么赚怎么用.md](积分怎么赚怎么用.md) 第五节）。**要长期一起用分的，走积分池；只是偶尔帮人补一点，走转赠**，别把额度浪费在同一件事上。

## 五、购物与打车抵扣：先确认你所在地区支持

下面这两项都是**按地区开放**的，中国大陆的账号不一定能用，看到入口后再操作：

| 用法 | 说明 |
| --- | --- |
| 购物抵扣 | 在美国可关联账号后用积分抵扣购物消费；另有把积分捐给合作公益机构的渠道 |
| 打车抵扣 | 与美国/加拿大地区的打车平台合作，乘车按消费赚分，也可用积分抵车费，起步门槛为数千分一档 |

因为这两项的开放范围、合作方和折算比例都可能调整，**以官方页面当时公布为准**，别按旧帖子的说法推断。

## 六、办活动也能赚积分

会员在参与活动的酒店举办婚礼、会议、聚会这类活动时，官方给出的口径是相关消费可**按双倍比例**赚积分。金额通常比单纯住宿大，适合公司团建、婚宴这类有大额场地与餐饮支出的场景。参与酒店名单与细则以官方活动页面为准。

## 七、怎么选：一句话对照

| 你的情况 | 建议走哪条 |
| --- | --- |
| 就差一点分能凑够一晚 | 看积分池或积分+现金，别硬攒到过期 |
| 想找机酒之外的独家体验 | 体验平台竞拍，但先接受「不可退」 |
| 一家几口各自有分 | 建积分池合并使用 |
| 在大陆以外地区旅行 | 顺手看看购物/打车抵扣是否可用 |

无论走哪条，积分都有 24 个月无活动即失效的规则（见 [积分怎么赚怎么用.md](积分怎么赚怎么用.md) 第四节），用它比攒着更安全。
