# 模型设置与参数调节

## 一、入口在哪

聊天界面下方有「模型设置」按钮，点开就是全部参数。模型设置同时对当前角色生效，不需要每个角色单独配一遍——但你可以在角色卡里给某个角色指定默认模型（见[创建自己的角色卡.md](创建自己的角色卡.md)）。

## 二、可以调的参数

| 参数 | 作用 | 什么时候动它 |
| --- | --- | --- |
| 聊天模型 | 决定回复的质量与风格 | 回复太敷衍、太啰嗦、不贴人设时换一个 |
| 语音模型 | 决定语音输出的音色 | 用到语音互动时选 |
| 创意（温度） | 越高越发散跳跃，越低越稳妥贴原文（默认 0.7） | 剧情推进想更有想象力就调高；要贴人设就调低 |
| 最大回复字数 | 单条回复的长度上限（默认 800） | 觉得回复太短说不完、或太长刷屏时调 |
| 对话记忆 | 保留多少轮上下文（默认 20 轮） | 角色「健忘」就调高；话题换代了就调低重开 |
| 流式输出 | 回复逐字显示 vs 全部生成完再显示 | 打字机效果看着累就关掉 |
| 自定义（beta） | 手动填世界书、对话预设等高级项 | 有明确的高级需求再碰 |

默认值为公开资料所列（温度 0.7、回复字数 800、记忆 20 轮），以你应用内实际显示为准。

内置模型不止一款，公开资料列出过的有雪梦、灵犀、Kimi、智谱、Gemini 等，**其中几款免费**——免费与付费的划分以应用内标注为准（见[钻石与免费资源获取.md](钻石与免费资源获取.md)）。不同模型在理解能力、输出风格上差别明显：同一个角色换模型，聊起来可能是两个人。

## 三、自定义选项里的「世界书」

自定义 beta 选项里可以手动设置「世界书」——把世界观、专有名词、角色关系这类背景资料写进去，模型回答时会参考它。适合角色背景复杂、或剧情有特定设定的情况；普通闲聊用不上，不用一上来就研究它。

同在自定义里的还有预设类选项。需要注意：**部分大模型带强制风控，这类预设在某些模型上会失效**——表现为填了没反应。这不是设置错了，是模型侧的限制，换免费模型或换一个模型再试，详见[常见问题与解决办法.md](常见问题与解决办法.md)。

## 四、参数没生效时的排查顺序

1. 确认改动后点了保存；
2. 确认当前用的是哪个模型——风控严格的模型会让部分参数失效，先切到免费模型验证参数本身是否起作用；
3. 换模型后仍不对，重开对话让新配置完全生效；
4. 还不行，检查网络：模型请求失败时参数看起来就像「没生效」，其实请求根本没发出去。

改参数的更多场景与故障处理，配合[常见问题与解决办法.md](常见问题与解决办法.md)一起看。
