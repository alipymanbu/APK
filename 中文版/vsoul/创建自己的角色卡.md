## 一、什么时候需要自己建角色

角色广场里的现成角色能覆盖大部分需求，但两类情况下你自己建更省事：一是广场上没有你想要的人设（比如特定性格、特定关系、特定说话方式）；二是现成角色的回复风格怎么调都不对味，不如自己写清楚。建角色在底部的「创意工坊」里完成，不依赖任何付费功能。

先说找现成角色的路子，省得白建：顶部可以**关键词搜索**，也有**热搜榜、排行榜**（按点赞、收藏、聊天量等维度排）和**标签筛选**；你的浏览偏好还会影响推荐。这几条路都翻过确实没有，再自己动手。

## 二、创建步骤

1. 点底部「创意工坊」；
2. 找到「创建角色」入口；
3. 选择是否导入一张图片作为角色卡的底图（**支持 PNG 格式角色卡一键导入**——网上分享的角色卡多是这个格式，导入后会自动生成设定，不用手动重输；从零写就跳过这一步）；
4. 逐项填写角色参数：姓名、显示名、性别、性格、衣着外貌、背景、对话场景，并选择这个角色用哪个模型；
5. 点保存，角色卡创建完成，可以在角色列表里找到它开始聊天。

保存后角色卡就是你的了：保持私有自己用，还是公开分享出去，由你在角色的发布设置里决定。

**改完设定要重开对话才完全生效**：公开资料多次提到，修改角色设置后需要重新进入聊天界面，新设置才会应用——改完直接接着聊，很可能还是旧的表现。

## 三、角色卡里该填什么

能自定义的维度大致这几类，写得越具体、聊天时越不容易跑人设：

| 维度 | 写什么 |
| --- | --- |
| 基础信息 | 名字、称呼、关系设定（朋友/恋人/知己/树洞等） |
| 性格 | 脾气、说话习惯、口头禅、边界感 |
| 背景故事 | 人设的来龙去脉，给 AI 提供语境 |
| 开场白 | 你发起聊天时对方的第一句话 |
| 外貌描述 | 形象设定（影响展示与剧情描写） |
| 对话风格 | 温柔/直球/简短/文学化等回应方式 |
| 剧情节点 | 故事分支的触发条件与走向 |

**关系设定与开场白是最影响体验的两项**——开场白决定了第一句话的氛围，关系设定决定对方用什么口吻跟你说话。

## 四、角色偏离设定时怎么修

聊了几轮发现角色「不像自己写的那个人」，按这个顺序处理：

1. 在对话里用明确指令当场纠正，比如「请用温柔的语气回应」；
2. 还不对，回角色编辑页补充更详细的性格描述和**对话示例**（给几个你期望的问答样本，比形容词管用）；
3. 涉及剧情节点的，检查触发条件：关键词是否打错、逻辑有没有互相矛盾；**部分复杂剧情要保存后重新加载角色（重开对话）才生效**；
4. 改完仍不生效的，先看是不是选错模型了——不同模型对人设的贴合度差别很大，见[模型设置与参数调节.md](模型设置与参数调节.md)。

创建或编辑过程中遇到报错、内容保存不了，多与网络或内容审核有关，处理办法见[常见问题与解决办法.md](常见问题与解决办法.md)。

## 五、两个实用提醒

- **退出前记得保存**：有用户反馈过聊天与编辑内容偶发丢失，退出角色编辑或对话界面前点右上角的保存按钮，养成习惯能省掉很多麻烦。
- **角色卡底图不是必须**：导入图片只是为了快速还原一个已有角色的设定，从零创作完全可以跳过这一步，后续所有参数照样能改。
