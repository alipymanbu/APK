# 时间规划局提醒通知不响怎么设置

> 事件到点了手机没反应？按本篇顺序排查：先确认事件里设了提醒，再查系统通知权限和后台限制。

## 一、先分清是「没设提醒」还是「没收到」

时间规划局的提醒分两层：**事件里开了提醒**，以及**系统允许它推送**。前者没开，后者查遍了也白搭；前者开了后者拦着，事件就静默错过。按下面从 1 到 4 的顺序走，九成问题出在第 3、4 步。

## 二、确认事件本身开了提醒

1. 打开应用，点开那个「没响」的事件，进编辑页；
2. 查看提醒 / 通知相关开关是否打开，提醒时间是否设了（比如提前一天、提前一小时）；
3. 如果是会重复的日子（每周例会、每年生日），把**重复提醒**设为对应的频率 —— 时间规划局支持按**每日、每周、每月、每年**重复，设一次全年都会响；
4. 保存后再看一眼开关状态，确认没有保存失败。

## 三、系统通知权限

- 进**手机设置 → 通知管理（应用管理里找到时间规划局 → 通知）**，确认「允许通知」打开，横幅、锁屏、声音这几项按你的喜好勾上；
- 安装时如果拒绝过通知权限，所有提醒都会静默消失，必须在这里补开；
- 检查手机是否处于**勿扰模式 / 会议模式**，勿扰会把普通通知全部压掉。

## 四、后台与省电限制（国内品牌重点查）

国内安卓系统对后台应用管得很严，被系统「冻住」的应用到点发不出通知。逐项检查：

| 检查项 | 在哪改（路径因品牌而异） |
| --- | --- |
| 自启动 | 手机设置 → 应用管理 → 时间规划局 → 允许自启动 |
| 后台运行 | 同上，允许后台活动 / 允许完全后台行为 |
| 省电策略 | 电池 → 应用耗电 → 时间规划局 → 无限制 |
| 锁定后台 | 最近任务里下拉卡片加锁，防止被一键清理杀掉 |

改完建议做个验证：新建一个**两分钟后**的测试事件并开提醒，锁屏等它响 —— 响了说明配置到位，不响就回头核对上面哪一项漏了。

## 五、还是不响的兜底

确认前四步都做过后仍不响，按这个顺序处理：重启手机（让权限配置生效）→ 卸载重装（重装时一律点允许，别再拒绝任何权限，安装包见 [下载与安装教程.md](下载与安装教程.md)）→ 重装后重新建一条测试事件验证。重装前注意记下要保留的事件，重装会清掉应用内数据。
