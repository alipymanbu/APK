## 一、安装前先核对这份包的信息

MyACG 是安卓应用，官方没有可确认的网站或应用商店上架渠道，一般通过 APK 安装包安装。下面是网盘里这份安装包的实测信息，装之前可以先核对一遍，确认你拿到的是这一版：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.5.1.2_beta |
| 包名 | yx.myacg.plus |
| 安装包大小 | 11.80 MB |
| MD5 | `3fa69fedca659779be0a0b2efdbd9da7` |

安装包只有 11.80 MB，手机上随手就能存下。网上各下载页对系统要求的标注不一（有的写 Android 4.0，有的写 5.2 以上），以你手机安装时系统的实际提示为准——近几年主流的安卓机型基本都能装。

## 二、从网盘把安装包转存并下载

1. 用夸克网盘 App 或网页版打开 [MyACG 安装文件资源（夸克网盘）](https://pan.quark.cn/s/fdb08b557b26)；
2. 把资源转存到自己的网盘账号，再从网盘里下载 APK 文件到手机存储。

先转存再下载，资源就一直在你自己账号里，比直接点开临时链接拿包更稳妥。

## 三、安装步骤

1. 在手机文件管理器里找到刚下载的 APK 文件（文件名一般是 `myacg_v1.5.1.2_beta.apk` 这样的形式，以你实际下载到的为准），点它开始安装；
2. 第一次装 APK 时系统会弹「不允许安装未知来源应用」之类的提示，按系统引导去开启对应权限：
   - 原生安卓：设置 → 应用 → 特殊应用权限 → 安装未知应用，给文件管理器或浏览器授权；
   - 国产系统（MIUI、ColorOS、HarmonyOS 等）：路径各有差异，弹窗里一般有「仍要安装 / 设置」按钮，点进去开就行；
3. 回到安装界面点「安装」，等进度走完；
4. 装完点「打开」，或者从桌面图标进入。

## 四、装不上 / 装完打不开怎么排查

| 现象 | 常见原因 | 处理办法 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 下载不完整或文件损坏 | 重新下载一遍，核对 MD5 是否为上表的值 |
| 提示存储空间不足 | 手机剩余空间太小 | 清出至少几百 MB 空间再装 |
| 安装按钮灰色 / 点了没反应 | 系统版本低于应用要求 | 换一台系统较新的手机试，或看系统提示的具体原因 |
| 被手机管家拦截 | 未知来源 APK 的常规拦截 | 在安全软件里选择「允许 / 信任」后再装 |

装上之后还有别的问题（搜索没结果、打开是空壳等），直接翻[常见问题解答](常见问题解答.md)。

## 五、第一次打开是空的，不是装坏了

MyACG 首次打开界面上几乎什么内容都没有，这是它的正常状态——应用本身不带内容，需要你自己添加搜索源之后才有东西可看。具体怎么加源、怎么搜，看这一篇就够了：[搜索源添加与使用.md](搜索源添加与使用.md)。

如果你之前在别的手机上用过、有配置要迁移，先别急着加源，看[备份与恢复教程](备份与恢复教程.md)把旧数据恢复过来更快。
