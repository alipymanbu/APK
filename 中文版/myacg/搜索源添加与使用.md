## 一、先弄明白：为什么打开什么都没有

MyACG 本身不带任何内容，它是一个按规则去别的站点检索内容的聚合工具。内容全靠「搜索源」——每条搜索源对应一类站点、一组检索规则。你添加了多少条源，它就能从多少个站点帮你找东西。所以刚装完打开是空的，属于正常现象，不是安装出了问题。

另外要清楚一点：源对应的都是第三方站点，站点上的内容与站点本身是否可用，与 MyACG 无关。添加源时你自己留意站点内容是否合适、是否符合当地的法规要求。

## 二、添加软件内置的搜索源

MyACG 自带了一批搜索源，覆盖漫画、小说、动漫、音乐、轻小说、图片、网盘搜索等类别，直接添加就能用：

1. 在主界面底部导航点「浏览」；
2. 进入「网络搜索」；
3. 点右上角的「搜索源管理」；
4. 列表里就是内置的各个资源站，点每一条后面的「添加」按钮，把你要的加上。

添加的源越多，之后搜索能覆盖的站点就越多。不想一条条点的话，在搜索源管理页点右上角选项 → 「当前分组操作」 → 「全部添加」，可以把整组源一键加齐。

**入口名称对不上怎么办**：不同版本的界面叫法不一样。有的版本走的是「右上角搜索 → 搜索框左侧『搜索源』→『添加搜索源 - 在线搜索源仓库』→ 每条源后面点『安装』，右下角『+』全部安装」的路径。名称虽然不同（「网络搜索 / 搜索」「搜索源管理 / 搜索源」「添加 / 安装」「网络发现 / 发现」），指的都是同一组功能——找不到本篇写的名称时，在相邻位置找同义的叫法即可。

## 三、导入自己的搜索源

除了内置的，搜索源管理页的右上角选项里还提供了三种外部导入方式：

| 导入方式 | 适用场景 | 操作 |
| --- | --- | --- |
| 本地导入 | 你手里有下载好的源文件 | 从手机存储里选中源文件 |
| 网络导入 | 拿到的是一条源订阅链接 | 把链接填进去，让应用自动拉取 |
| 剪贴板导入 | 源内容以文本形式复制在剪贴板里 | 复制后直接选剪贴板导入 |

MyACG 的搜索规则支持 JsonPath 与 CSS Query 两种写法，网上找第三方源时看到的规则文件基本就是这两种。别人分享的源质量参差不齐，加之前先确认来源可靠。

## 四、添加完了，怎么找内容

加完源回到底部导航的「浏览」，有两个入口：

**网络搜索**——按关键词聚合搜索：

1. 进入「网络搜索」，在顶部搜索框输入书名、番剧名等关键词；
2. 搜索范围可以选「全部」，也可以只选动漫、漫画、小说等某一类；
3. 结果出来后，点按可以打开阅读，长按可以把该资源订阅下来，方便后续追更新。

**网络发现**——不指定关键词，按分类闲逛：进入「网络发现」后能看到各源站点的内容流，左上角菜单可以切换动漫、漫画、小说等分类，适合还没想好看什么的时候翻一翻。注意要先加了源这里才有内容。发现页里还能翻到一份各源站的网址导航，逐个站点去逛效率不高，明确想看什么的时候还是直接用关键词搜索快。

搜到的内容具体来自哪个站点，结果里会列出多个源站供你选择，同一个资源在不同源站上的画质、加载速度、更新进度都可能不一样，哪个用得顺手就用哪个。想离线看的话，多个公开下载页都提到 MyACG 支持缓存下载、无网观看，具体入口在阅读界面里，以你版本实际显示为准。

## 五、日常管理建议

- **源不用贪多**：几十条源里真正顺手的往往就几条，把加载慢、结果差的源删掉，搜索速度和结果质量都会更好；
- **定期备份**：花时间调好的源列表和配置，重装或换机时不想重来一遍，就用备份功能保存，方法见[备份与恢复教程](备份与恢复教程.md)；
- **搜不到东西先查源**：搜索没结果多数是「一条源都没加」或「源失效了」，排查思路见[常见问题解答](常见问题解答.md)。
