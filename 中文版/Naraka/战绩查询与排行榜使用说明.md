## 一、先确认数据到了你名下

战绩页展示的是你绑定角色的数据。看之前先满足两个条件：已登录、已绑定游戏角色（怎么装怎么登见 [下载与安装教程.md](下载与安装教程.md)）。两个都齐了数据还是空的，按 [常见问题与故障排查.md](常见问题与故障排查.md) 里的「看不到战绩」那条处理。

## 二、战绩页看什么

战绩模块把你的对局数据拆成几块，常用的看法：

| 想知道什么 | 去哪看 |
| --- | --- |
| 最近打得怎么样 | 历史对局列表，逐场看击杀、伤害等明细 |
| 我擅长／生疏的英雄 | 常用英雄统计，看使用频率与胜率 |
| 我顺手的武器 | 常用武器统计，看哪把武器的场次与表现高 |
| 段位进度 | 生涯数据里的赛季段位展示 |

复盘时有个省事的用法：先看常用英雄的胜率——如果某个你常玩的英雄胜率明显低于其他，比重开一局回忆细节更快地定位问题；再翻那几场输掉的对局明细，看伤害与击杀是否掉在同一种场景上。

## 三、排行榜怎么用

排行榜按区服与赛季给出全服排名：你能查到自己在当前赛季排在什么位置、各段位的玩家分布。赛季更迭后榜单会重置，开赛初期排名波动大，以应用内当时显示为准。

榜上的段位名从青铜到无量梵天怎么排序、积分大概什么口径、结算时为什么会变，单独拆在 [排行榜段位顺序怎么看.md](排行榜段位顺序怎么看.md)，看榜前对不上号就先翻那篇。

组队前顺手看一眼对方战绩是常见做法——打开队友的个人页，比只看段位更能判断打法是否合得来，具体入口见 [资讯公告与组队功能怎么用.md](资讯公告与组队功能怎么用.md)。

## 四、数据什么时候刷新

对局结束后，数据需要一点时间同步到助手里。正常情况下等一会儿、下拉刷新就能看到新对局；有用户反馈偶发同步较慢的情况，如果一整局过去很久还没出现，先确认这局是不是用绑定的那个角色打的，再参考 [常见问题与故障排查.md](常见问题与故障排查.md) 的排查顺序。

## 五、不想让别人看战绩：隐藏开关

你的战绩默认展示在个人页上，别人打开你的主页就能看到。要关掉，按这个路径操作：

1. 点击首页**左上角**的头像／入口；
2. 在功能栏里进入**个人主页**；
3. 点击**编辑**；
4. 找到**显示战绩**开关，关掉即隐藏。

之后别人访问你的个人页就看不到战绩明细了；你自己在战绩页查数据不受影响。想恢复展示，回同一位置把开关打开即可。

## 六、国际版多出来的「动态地图」

官方国际版页面 [NARAKA+](https://www.narakathegame.com/narakaplus/) 介绍了一项「动态地图」功能：对局结束后回看你和队友整局的移动轨迹，以及击杀、被击杀、复活、获取高级装备等关键事件，还能把录像保存到手机相册。你手上的版本是否有该入口，以应用内实际界面为准。
