## 一、先确认你的设备能不能用

HyperCeiler 是一个依赖 LSPosed 框架工作的系统增强模块，改的是小米系统界面与系统应用的细节。装它之前，先对一遍这张清单：

| 条件 | 说明 |
| --- | --- |
| 小米 / 红米手机，系统为 MIUI 或 HyperOS | 修改较多的第三方 ROM、部分国际版系统不在支持范围 |
| 已解锁 Bootloader 并获取 Root | 模块生效需要重启作用域，这一步要 Root 权限，常用 Magisk 或 KernelSU |
| 已刷入 LSPosed 框架 | 在 Magisk/KernelSU 里刷入 LSPosed 模块，重启后 LSPosed 显示「已激活」才算就绪 |

三样都齐了再往下走。系统版本偏老的设备（Android 11~13 时期的 MIUI、HyperOS 1.0）对应的不是最新版，先看 [版本分支怎么选.md](版本分支怎么选.md) 再决定装哪个系列。

## 二、下载安装包

安装包从这里拿：[HyperCeiler 安装文件资源（夸克网盘）](https://pan.quark.cn/s/acc270a8a5ca)，转存到自己的网盘后即可下载。

这份包的基本信息如下，装之前可以核对一下：

- 版本：2.5.154
- 包名：`com.sevtinge.hyperceiler`
- 大小：6.74M
- MD5：`1122C000E892CE5E86EEDD1544C7489D`

网上能搜到更高的版本号（官方仍在持续更新），但网盘里这份是 2.5.x 系列的 2.5.154，两者不一定相同——版本分支的选择依据见 [版本分支怎么选.md](版本分支怎么选.md)。

渠道上多留个心眼：官方在下载页明确提醒过「非官方发布的安装包可能存在恶意代码」。认准官方发布渠道（官网下载页、GitHub 仓库的 Releases 页、LSPosed 模块仓库）或本文给的这份网盘资源，来路不明的包不要装。

## 三、安装步骤

1. 把下载好的 APK 传到手机（直接在手机上下载，或用数据线/局域网从电脑传）；
2. 在文件管理里点开 APK，按提示完成安装；系统可能询问「是否允许安装未知应用」，允许即可；
3. 装完先**不要急着打开**——此时模块还没有被框架接管，直接打开也不会有作用。

安装环节出错的概率不高，常见只有两种：存储空间不足导致装不上；下载中断导致包不完整。换一次网络重新下载基本都能解决。

## 四、装完之后的两步

1. 打开 LSPosed，在「模块」页找到 HyperCeiler，打开开关；
2. 勾选作用域（勾哪些、为什么要重启，都在 [LSPosed激活与作用域设置.md](LSPosed激活与作用域设置.md) 里），然后重启手机。

重启完打开 HyperCeiler 应用，里面会按功能分类列出可开的选项。开启后如果界面没变化，按 [启用后没有效果怎么办.md](启用后没有效果怎么办.md) 的顺序排查一遍，多数情况是作用域漏勾或没重启。
