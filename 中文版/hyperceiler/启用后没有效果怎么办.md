# HyperCeiler 启用后没有效果怎么办

> 模块装了、开关也开了，界面却一点变化没有——本篇按「从最常见到最少见」的顺序给出排查路径，多数人在前三步就能找到原因。

## 一、按这个顺序查，别跳步

| 顺序 | 检查什么 | 怎么确认 |
| --- | --- | --- |
| 1 | LSPosed 里模块开关开了没 | LSPosed → 模块 → HyperCeiler 开关为打开状态 |
| 2 | 作用域勾了没 | 模块详情页里作用域列表非空，且勾的是对应应用 |
| 3 | 重启了没 | 勾完作用域、开完功能后有没有按提示重启（作用域重启或手机重启） |
| 4 | 应用内功能开了没 | 打开 HyperCeiler 应用，对应功能开关是打开状态 |
| 5 | 系统版本在不在支持范围 | 系统设置里看 HyperOS/MIUI 版本号，对照 [版本分支怎么选.md](版本分支怎么选.md) |

五步里中招最多的是第 2、3 步：作用域漏勾、或者开了功能忘了重启。模块的一切改动都要等重启后才生效，这是 LSPosed 类模块的通用规则，不是 HyperCeiler 的毛病。

## 二、前四步都过了还是没反应

按下面两个方向再查：

**版本与系统是否匹配。** 官方对 HyperOS 2 / HyperOS 3 / 老 MIUI 各有不同的版本线，装错系列就会出现「开了没反应」。网盘里这份 2.5.154 属于 2.5.x 系列，对应关系见 [版本分支怎么选.md](版本分支怎么选.md)。

**系统刚升级完才失效的。** 大版本升级后，之前装的模块版本可能不再匹配新系统——先别反复折腾设置，按 [系统升级前要关模块吗.md](系统升级前要关模块吗.md) 的恢复顺序来。

**系统是否属于「不支持」范围。** 官方明确说明不支持修改较多的第三方 HyperOS ROM、修改较多的系统软件，以及部分国际版 ROM。刷过第三方包、或厂商深度改造的海外版系统，部分功能天生不生效——这不是设置问题，换官方 ROM 才是出路。

## 三、个别功能没效果、其他功能正常

这种多半是**作用域**的问题，而不是模块本身：

1. 在 HyperCeiler 应用里打开那个没效果的功能，看它标注需要的作用域；
2. 回 LSPosed 模块详情页，把缺的作用域补勾上；
3. 重启手机（或重启对应作用域）再看。

还是不行的话，先去官方 GitHub 仓库的 Issues 区搜一下有没有相同反馈（开源项目的已知问题通常有人报过）；要自己提的话，官方建议先确认没有重复帖再发，官网 Support 页也列了交流群入口。
