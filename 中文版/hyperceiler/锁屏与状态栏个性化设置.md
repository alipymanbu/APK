## 一、功能入口长什么样

打开 HyperCeiler 应用，主界面按功能分类排列，每类点进去是具体开关列表。应用内置搜索框，直接搜「锁屏」「状态栏」这类词定位最快，不用一层层翻。

功能分布没有统一模板——不同版本、不同系统下可见的分类不完全一样，以你应用内实际显示的为准。

## 二、常改的几项在哪

下面这些是大家装完最常动的几类，对应关系按常见布局整理：

| 想改什么 | 一般在哪个分类 |
| --- | --- |
| 锁屏时钟显示秒数 | 锁屏 |
| 状态栏时钟样式（显示位置、双排时钟等） | 状态栏 |
| 状态栏图标：网速、电池样式、运营商名称显示 | 状态栏 |
| 控制中心细节 | 控制中心 |
| 桌面图标、文件夹、动画效果 | 桌面 |
| 通知的屏蔽与提醒方式 | 通知 |

分类名称在不同版本间叫法略有出入，找不到就用搜索框搜关键词。

## 三、开了之后必须做的一步

改任何一项，退出应用前留意界面底部的提示——HyperCeiler 会在你改动后提示需要重启的作用域或直接要求重启手机。

漏掉重启是「开关开了没变化」的第一原因。如果重启后还是没有效果，先回到 [启用后没有效果怎么办.md](启用后没有效果怎么办.md) 把作用域那几步过一遍。

## 四、为什么有的选项我这里没有

两种常见情况：

1. **系统版本不支持**：部分功能只在特定的 HyperOS 版本上可用，老系统上直接不显示。想换版本线先看 [版本分支怎么选.md](版本分支怎么选.md)（此篇的入口在 [下载与安装教程.md](下载与安装教程.md) 的下载环节）；
2. **机型差异**：官方是按主流机型适配的，覆盖不完整，个别小众机型上部分选项缺失属于正常现象。

同一个选项开了之后显示异常的，直接关掉它恢复原状即可。整个模块都不想用了，按 [卸载与恢复原状.md](卸载与恢复原状.md) 的顺序干净地卸掉。
