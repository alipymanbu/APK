## 一、为什么要考虑先关

官方按系统大版本拆分支维护：OS2 分支只对应 HyperOS 2.0 系列（Android 15），OS3 分支只对应 HyperOS 3.0 系列（Android 15/16），停维护的老版本线不再适配（官方已声明停止维护 Android 11~13 的 MIUI ROM 与 Android 13 的 HyperOS 1.0 ROM）。

这意味着：你装的模块版本是照某个系统版本做的，系统换大版本后，这套适配不一定还成立。升级前建议按这个顺序处理：

1. 把你在 HyperCeiler 里开过的功能记下来（截图或列个清单，升级后恢复用）；
2. 到 LSPosed → 模块 → HyperCeiler，关掉开关；
3. 重启手机，确认系统一切正常，再执行系统升级。

## 二、升级完之后怎么恢复

1. 先看官方有没有发布支持新系统的版本——GitHub Releases、LSPosed 模块仓库、官网下载页都会写明支持范围；
2. **有适配新版**：装对应分支的新版本（分支怎么挑见 [版本分支怎么选.md](版本分支怎么选.md)），回 LSPosed 勾作用域、开功能、重启；
3. **还没有适配版**：继续关着等，别急着开——没适配的功能轻则开了没反应，重则系统界面异常；
4. 恢复功能时用上第一步记的清单：一批一批开，开一批重启一次，确认界面正常再开下一批。出了问题按 [启用后没有效果怎么办.md](启用后没有效果怎么办.md) 排查。

## 三、怎么判断新系统有没有适配

三个核对点，全对得上再装：

| 核对点 | 在哪看 |
| --- | --- |
| 支持范围说明 | 官方发布页更新日志（如「仅支持 HyperOS 2.0/2.0.100/2.0.200 Android 15」这类表述） |
| 分支前缀 | 新版安装包名里的 `OS2_` / `OS3_` 前缀对应系统大版本 |
| 你的系统版本 | 系统设置 → 我的设备，版本号对不上就先别装 |

升级后实在不想再折腾，就按 [卸载与恢复原状.md](卸载与恢复原状.md) 干净地关掉，等哪天想用了再装回来。
