## 一、组件放上去了但一片空白

按这个顺序排，能覆盖绝大多数情况：

1. **先打开一次应用**。组件的数据要靠应用联网拉，打开一次就是手动触发一次刷新，等一两分钟再回桌面看。
2. **确认你保存过这个组件**。桌面那一格选的必须是「我的」里已保存的那一个，选成空槽位就是白的。
3. **检查网络**。距离、状态、步数这些都要联网；断网时组件会停在上一次的值或直接空白。
4. **检查后台限制**。安卓的省电策略会拦住后台刷新：`设置 → 应用 → Widgetable → 省电策略/电池优化` 改成「允许后台活动」，厂商桌面再给它开自启动。省电模式开着时也容易被限。
5. **确认应用没被装到 SD 卡**。安卓上一旦把应用移到 SD 卡，系统就可能读不到它的组件条目——表现是小组件列表里**整个 Widgetable 都不见了**。去 `设置 → 应用 → Widgetable → 存储` 看，如果位置是 SD 卡，改回「内部存储」，再重新添加组件。
6. **移除再加回来**。长按组件移除，重新按[桌面与锁屏小组件添加方法.md](桌面与锁屏小组件添加方法.md) 添加一次——组件缓存坏了时这一步比重启管用。
7. **还不行再清缓存**：`设置 → 应用 → Widgetable → 存储 → 清除缓存`。**先别点「清除数据」**，那会把登录状态一起清掉，得重新登录。

## 二、数值一直在跳、更新很慢

不是坏了，是这类组件的刷新机制本身有限制：安卓受后台调度限制、iOS 受系统对小组件的刷新限制，公开的使用说明提到同步间隔大约是 20 分钟一级。**想要准数就打开一次应用**，这比在桌面上等有效。把第一节第 4 步的后台限制放开之后，桌面端的自动刷新也会顺畅一些。

## 三、加不上好友 / 组件显示不了对方

| 现象 | 原因与处理 |
| --- | --- |
| 输了代码提示无效 | 代码可能是旧的或抄漏了字符，让对方重新打开「个人资料和好友」页，把最新的整串发你 |
| 只发了自己的码 | 双方要**互相各输一次**，只发不收连不上 |
| 加上了但组件还空着 | 你保存了组件，**对方没保存/没放到锁屏**——共享组件两边都要做一遍 |
| 突然读不到对方了 | 对方可能解除了好友关系、卸载了应用，或关掉了位置权限 |

## 四、距离 / 步数 / 睡眠读不出数

这三个都靠权限活着，缺一个就空一个：

- **距离**：需要位置权限。弹窗时选「使用期间允许」；当时点了拒绝就去 `设置 → 应用 → Widgetable → 权限 → 位置` 补开。只在前台允许时，组件刷新会依赖应用被打开过。
- **计步**：需要读取健康/身体活动数据的权限，同样在系统权限页开。
- **睡眠**：需要读取睡眠数据的权限——官方在应用说明里明确写了会为睡眠组件申请这项权限，没给就读不到。

另外对方那一侧也得给权限：共享组件读的是**对方上报的数据**，他那边关了，你这边永远是空的。

## 五、界面是英文怎么改中文

Widgetable 会跟随系统语言：系统语言设成中文，进去一般就是中文。不是的话在应用里走 `更多 → 语言 → 中文` 手动切一次。改完如果某个页面还是英文，把应用从后台杀掉重开一次。

## 六、iOS 和安卓能一起用吗

公开的使用说明里给的说法是**可以**：两边装同一个应用、互相输入对方的代码加好友，共享组件就能同步。前提是同一套好友关系在两边都成立——你换设备后要重新登录、重新添加组件，见[下载与安装教程.md](下载与安装教程.md) 第五节。锁屏的添加入口两边不同，见[桌面与锁屏小组件添加方法.md](桌面与锁屏小组件添加方法.md)。

## 七、要不要花钱

应用本身免费下载，内购分两类：

- **订阅制高级会员**：开通后可用全部功能。App Store 中国区页面截至 2026-09-26 标的价是 **¥8/月、¥148/年**（安卓端的对应价格没有查到官方公开说明，以应用内实际显示为准）。订阅会在到期前 24 小时自动续费，要关就去系统账号的订阅管理里取消。
- **单买的道具**：宠物蛋、宠物食物、许愿罐、钻石这类，按需买，不影响基础功能。

**不订阅也能玩**：宠物、植物、共享组件这些核心玩法免费就能用，付费主要是加快节奏。只装官方渠道的包最省心——来历不明的包最容易出现的就是账号登不上、组件失效。

## 八、装了之后手机更费电了

桌面上的联网组件本来就要定时唤醒去拉数据，放得越多、动得越多，耗电越明显——这是这类应用的共性，不是坏了。按这个顺序收敛：

1. **先看是不是它**：`设置 → 电池 → 电池用量`（各品牌叫法不同），找到 Widgetable 看占比。占比不高就先别管。
2. **减少在桌面的组件数量**：装饰类、纯趣味类的先撤，留两三个真正要看的。移除组件即可，不用卸载应用。
3. **关掉用不上的权限**：位置、睡眠、计步这三项只在对应组件需要时才留，见第九节。
4. **别同时开系统的省电模式又要求组件实时刷新**——省电模式会压后台，组件就变成「永远不刷新」，你只会觉得它坏了。要么放开后台让它正常刷，要么接受它刷得慢。

真要极致省电，把共享类组件都撤掉、只留静态的图标与文字便签，是影响最小的一种取舍。

## 九、隐私上要注意什么

你交出去的主要是这几样：位置（距离组件）、健康/睡眠数据（对应组件）、好友关系与你发的留言。官方给了两份文档，装之前值得花五分钟翻一遍：

- 隐私政策：[https://widgetable.net/privacy](https://widgetable.net/privacy)
- 服务条款：[https://widgetable.net/terms](https://widgetable.net/terms)

只想用宠物和植物的话，**位置、睡眠、计步这三项权限都可以不给**——不给只是对应组件不工作，其余功能不受影响。要撤回就去系统权限页关掉，比在应用里找开关直接。

## 十、出问题找谁

官方联系邮箱 `service@widgetable.net`，官网 [widgetable.net](https://widgetable.net/)。写邮件时把这几项带上，对方排查会快很多：手机品牌与系统版本、应用版本号（在 `设置 → 应用 → Widgetable` 里看）、问题组件的名字、出问题的时间点。
