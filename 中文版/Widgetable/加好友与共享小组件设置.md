## 一、共享组件的前提：两边都装、互加好友

距离、状态、心情、留言、想你、计步、睡眠这类组件**都要两个人配合才能生效**——你这边保存了组件，对方没装应用、或者没互相加上好友，组件放上去也是空的或者一直读不出数据。所以顺序是：两边都装好 → 互加好友 → 你这边保存组件 → 双方各自把组件放到自己的桌面/锁屏。

## 二、互加好友（用代码）

1. 你打开 Widgetable，底部菜单进「更多」→「个人资料和好友」。
2. 这一屏上能看到**你自己的代码**，把它发给对方（微信/QQ 都行）。
3. 同一屏底部点「添加新朋友」，输入对方发来的代码，确认。
4. 对方重复同样的操作：看到他的代码发给你，再把你的代码输进去。

**关键是两边都要输一次**——只发自己的码、等对方来加，是连不上的，双方互相录入之后才算建立好友关系。加完之后在好友列表里能看到对方，后面选组件时才选得到他。

## 三、保存一个共享组件

1. 底部菜单进「探索」，挑一个组件，比如**矩形距离**。
2. 在配置页选「要一起使用的好友」，列表里点你刚加的那个人。
3. 按需要选单位（距离组件可选公里 / 英里 / 码）等选项。
4. 点**保存**。保存过的都在「我的」里能翻到。

之后按[桌面与锁屏小组件添加方法.md](桌面与锁屏小组件添加方法.md) 把它放到桌面或锁屏。**对方也得做一遍同样的事**：他要装应用、加上你、保存同一个组件、放到自己的锁屏上——两边都放好之后才会自动同步。

## 四、常用共享组件都能看什么

先给一组好认的名字：官方与行业媒体在介绍这批功能时常用的中文叫法是**朋友距离、朋友步数、朋友状态、想念你、一键联系人**——和应用里你实际看到的名称大体对得上，找不到时按这几个词找。

| 组件 | 显示什么 | 你要做什么 |
| --- | --- | --- |
| 距离 | 你和对方的实时距离，见面时会变成「在一起」类提示 | 双方都要给位置权限；你选好单位和好友 |
| 状态 / 心情 | 对方最新设的状态与心情 | 对方在应用里更新状态；不需要额外权限 |
| 留言板 | 你在对方锁屏上留的短文字 | 你发，对方亮屏就能看到 |
| 想你 | 对方给你送心的累计次数 | 对方点一下送心，你这边计数上涨 |
| 计步 | 双方当日步数与目标完成度 | 需要读取健康/计步数据的权限 |
| 睡眠 | 彼此的睡眠情况 | 需要读取睡眠数据的权限 |

注意两点：

- **权限不给就跑不起来**。距离组件在配置时会弹位置权限申请，选「使用期间允许」基本够用；如果当时点了拒绝，去 `设置 → 应用 → Widgetable → 权限` 里补开。睡眠、计步组件同理，对应权限在系统设置里手动开。
- **刷新不是实时的**。公开使用说明里提到这类组件大约每 20 分钟同步一次（受系统对后台与小组件的限制），所以看到的距离和步数是「最近一次同步」的值；要立刻拿最新数据就打开一次应用。

## 五、自己一个人也能用的部分

不想拉人也能用：宠物小组件、植物小组件、情绪泡泡（自己的泡泡）、图标与文字便签、动态图标、应用快捷方式、快捷联系人、壁纸这些都不需要好友，装好就能配。只有上面第四节那批「共享」组件才必须两个人。玩法见[养宠物与植物玩法.md](养宠物与植物玩法.md)，一键开应用/一键联系人那几个见[锁屏快捷与互动功能怎么用.md](锁屏快捷与互动功能怎么用.md)。

## 六、再往深一层：Pin It 和位置共享的边界

加了好友之后还有两个动作值得先想清楚：

- **Pin It 是「贴到对方屏幕上」**：照片、涂鸦、文字会直接出现在对方的锁屏组件位上。发之前挑内容——对方亮屏就看到，贴错了比发消息难撤回。玩法见[锁屏快捷与互动功能怎么用.md](锁屏快捷与互动功能怎么用.md)。
- **距离组件等于持续共享你的位置**：这是功能本身的前提，不是可以关掉的开关。有第三方评测明确提醒过这一点——只要组件在跑，你的位置就在持续上报。给伴侣、亲子用没问题，随手加不太熟的人之前先掂量一下；不想要了按下面第七节的最后一条（收回位置共享）关掉。

## 七、不想再共享了怎么办

- **停止某个组件**：在「我的」里删掉那个组件，再把桌面上的那个移除，同步就断了。
- **解除好友**：在「个人资料和好友」列表里对这个人做删除/解除操作。解除后对方立刻读不到你的新状态，已经放在你桌面上的旧组件需要手动移除。
- **收回位置共享**：直接在系统权限里把位置改成「拒绝」，距离组件就不再上报位置——代价是这个组件对你也没法用了。
