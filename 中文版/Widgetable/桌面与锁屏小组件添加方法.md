## 一、先分清两件事：组件列表里放的，和桌面上显示的

Widgetable 的用法是两段式的，很多人卡住就是因为把这两步当成了一步：

1. **在应用里「保存」一个组件**——去「探索」里挑一个（比如矩形距离），选好要绑定的好友，点保存。保存过的都在「我的」里。这一步只是把它存进你的清单，桌面上还不会出现。
2. **在系统桌面上「添加」这个组件**——长按桌面，走系统的小组件入口，找到 Widgetable，把刚才保存的那个放上去。

只做完第一步就去找桌面图标，是找不到的；反过来，直接长按桌面添加但应用里没保存过，也选不出内容。

## 二、添加到安卓桌面

各品牌桌面的措辞略有差别，路径基本一致：

1. 长按桌面**空白处** 2~3 秒（部分机型是双指捏合），底部弹出菜单。
2. 点「小组件」/「Widgets」。
3. 往下翻到 Widgetable，点开看尺寸（小 / 中 / 大，以及圆形、矩形之分）。
4. 长按你要的那个尺寸，拖到桌面空位上松手。
5. 首次放上去一般会让你选内容——从「我的」里挑之前保存的那个组件，确认即可。

**如果小组件列表里翻不到 Widgetable**，按顺序查两件事：

- 应用是不是被移到了 SD 卡——移到 SD 卡后系统可能读不到它的组件条目，改回内部存储即可；
- 是不是桌面本身的组件列表被裁剪了（部分极简桌面/第三方启动器只显示常用几个），换回系统桌面再看。

两条都对还是没有，见[常见问题与排查.md](常见问题与排查.md) 第一节的完整排查顺序。

放好之后还能调：

- **改大小**：长按组件，边缘出现拖拽点，拖动即可（不是所有机型、也不是所有尺寸都能改）。
- **移动位置**：长按拖走，或拖到另一页。
- **移除**：长按组件选「移除」，只是从桌面拿掉，应用与已保存的配置都还在。

## 三、添加到安卓锁屏

安卓这边锁屏组件的开放程度看系统版本与厂商：原生 Android 12 及以后、以及部分国产 ROM 支持在锁屏上放第三方组件，路径一般是**在锁屏界面长按 → 进入自定义/锁屏设置 → 添加小部件**，在列表里找到 Widgetable 再选尺寸与内容。

如果你的机型在锁屏自定义列表里**根本没有 Widgetable 这一项**，说明这块系统没开放给第三方，只能放到桌面用——这不是应用坏了，换机型之前不用反复重装（排查顺序见[常见问题与排查.md](常见问题与排查.md)）。

## 四、iOS 的锁屏怎么放

iPhone 的锁屏从 iOS 16 起支持自定义组件，流程是：

1. 锁屏状态下长按，进入自定义，点「自定义」下方的**小部件区域**。
2. 在应用列表里找到 Widgetable，它会列出**圆形**和**矩形**两种槽位。
3. 点空槽位，从你保存过的组件里选一个（矩形能显示更多信息，比如距离加两颗心；圆形只显示一个数值）。
4. 点完成保存。

也可以走 `设置 → 壁纸 → 锁屏预览 → 自定义` 这条路进去，效果一样。

## 五、组件的外观怎么改

应用里内置的组件编辑器能改这些：

| 可改项 | 说明 |
| --- | --- |
| 颜色 | 组件文字、底色的配色方案 |
| 字体 | 文字样式 |
| 背景 | 纯色、渐变，或从本地相册上传一张图 |
| 透明背景 | 生成透明底，叠在壁纸上不遮画面 |
| 组件组合 | 把几个小组件拼成一个大组件，一次放上去 |

透明背景的用法是先按目标位置的壁纸出一张透明图，再把它设成该位置的背景——这样组件看起来像直接浮在壁纸上。嫌麻烦的话直接开「透明背景」开关也够用。

## 六、放上去了但看着不对

三种最常见的表现，处理办法各不相同：

- **组件是空白 / 转圈**：多半是内容还没同步，先打开一次应用，让数据刷一遍；再等一两分钟看。持续空白见[常见问题与排查.md](常见问题与排查.md)。
- **数值不是最新的**：这类组件靠系统定时刷新，安卓上受后台限制、iOS 上受系统对小组件的刷新限制，公开的使用说明提到刷新间隔大约是 20 分钟一级，不是秒级实时。想立刻看准的，打开一次应用手动刷。
- **位置摆得别扭**：长按拖动即可；桌面组件之间留出空隙，系统才放得下更大的尺寸。
- **放了五六个之后发现更费电**：联网组件每多一个就多一份后台唤醒，桌面上留两三个主力的就够；省电的具体收敛步骤见[常见问题与排查.md](常见问题与排查.md) 第八节。想往桌面加「一键开应用、一键打电话」这类不联网的，做法见[锁屏快捷与互动功能怎么用.md](锁屏快捷与互动功能怎么用.md)。
