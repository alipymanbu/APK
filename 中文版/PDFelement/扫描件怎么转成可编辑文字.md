# 扫描件怎么转成可编辑文字（OCR）

> 拍照或扫描得到的 PDF 是整页图片，改不了字也搜不到。本篇讲怎么用 PDFelement 的文字识别（OCR）把它变成可搜索、可复制、可编辑的文件。

## 一、什么文件需要 OCR

先确认你手里的是不是扫描件，别白跑一遍识别：

- **来源判断**：用相机拍的、扫描仪扫出来的、聊天工具里收到的「图片转 PDF」，基本都是整页图片；
- **操作判断**：进编辑模式点一下文字选不中；放大后文字边缘发虚、带扫描噪点，就是图片型页面；
- **反例**：从 Word、网页导出的 PDF 自带文字层，不需要 OCR，直接编辑就行（见 [怎么编辑PDF文字和图片.md](怎么编辑PDF文字和图片.md)）。

## 二、识别步骤

1. 打开这份扫描件；
2. 在工具区找到「OCR」或「文字识别」入口；
3. 选识别语言 —— 语言要与文件正文一致，选错语言是识别出乱码最常见的原因；
4. 等识别完成，应用会生成一层可搜索的文字层；
5. 之后这份文件就能全文搜索、复制文字、直接改字。

OCR 属于付费能力，没开通会员时点进去会提示升级，差别见 [免费版和会员版有什么区别.md](免费版和会员版有什么区别.md)。

## 三、识别质量怎么保证

识别效果七分在原件、三分在操作：

| 环节 | 做法 |
| --- | --- |
| 拍摄 | 光线均匀、对焦清晰、页面拍正、整页入镜，四角不要缺 |
| 原件 | 打印体识别好于手写体；字号太小的先放大复印再扫 |
| 语言 | 与正文一致；混排文件选主语言 |
| 识别后 | 通读一遍再交付，重点核对数字、人名、金额这类易错内容 |

## 四、识别完能做什么

- **复制**：把识别出的文字粘到微信、备忘录里用；
- **搜索**：全文搜索关键词，快速定位条款；
- **编辑**：直接改识别后的文字，操作同文字层 PDF；
- **转格式**：转成 Word、Excel 继续处理，方向见 [PDF转换与页面整理.md](PDF转换与页面整理.md)。

## 五、识别不出来或效果差怎么排查

- **手写内容**：识别效果普遍不好，重要手写件建议人工誊录；
- **模糊、歪斜**：重拍比反复识别有用，先解决原件质量；
- **语言不在列表里**：识别语言以应用内可选列表为准，列表里没有的语言识别结果不可靠；
- **识别后仍是图片**：确认选的是「识别」而不是「扫描成 PDF」——后者只是把照片变成 PDF，不做文字识别。

改字与复制的前置判断见 [常见问题与解决方法.md](常见问题与解决方法.md) 的编辑与识别一节。
