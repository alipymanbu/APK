## 一、免费就能用的部分

装好后不付费，这些可以直接用：

- 打开和阅读 PDF；
- 基础批注：高亮、便签这类标注（做法见 [批注签名与表单填写.md](批注签名与表单填写.md)）；
- 本地文件管理：文件列表、打开、另存。

## 二、要开会员的部分

按官方商店页面的说明，下面这些属于付费能力（以应用内实际提示为准）：

| 功能 | 用途 |
| --- | --- |
| 编辑 PDF 文字与图片 | 直接改文件内容，见 [怎么编辑PDF文字和图片.md](怎么编辑PDF文字和图片.md) |
| 格式转换 | PDF 与 Word、Excel、图片互转 |
| OCR 文字识别 | 扫描件变可编辑文字，见 [扫描件怎么转成可编辑文字.md](扫描件怎么转成可编辑文字.md) |
| 合并、页面管理 | 多文件拼接、批量整理页面 |
| 设置密码 | 给文件加打开或编辑密码 |
| AI 工具 | AI 摘要、与 PDF 对话、翻译 |
| 流式阅读（Liquid Mode） | 把固定版式重排成适合手机屏幕的流式版面，读长文和扫描件更省力 |

## 三、为什么保存的文件上有水印

官方商店页面的口径：**未注册的试用版在保存时会给文件加水印**；Liquid Mode、编辑、签名等部分功能可以通过看广告临时解锁，官方说明的时限为 3 天。也就是说：

- 试用状态下保存 → 文件带水印；
- 开通会员后保存 → 不带水印。

判断自己处在什么状态：保存一次看结果，或在应用的账号页查看订阅状态。

## 四、订阅方案的大致形态

官方一般提供几档期限（不同时期、不同地区的方案与价格会调整，以官方页面当时显示为准）：

- **短期档**：按周或按月，适合临时处理一批文件；
- **年度档**：自动续订、可取消，适合长期使用；
- **买断档**：一次付费长期可用，适合确定长期用的人。

选档思路：一年用不上几次就短期或买断看价格差；每周都要处理 PDF，年度档摊下来通常更划算——但最终以你自己的使用频率算。

## 五、不想付费的替代思路

- 只是阅读和标重点 → 免费功能足够；
- 偶尔转一次格式 → 可以用网页端的免费转换工具，但敏感文件（合同、证件扫描件）不要传第三方网站；
- 扫描件改字 → 只有 OCR 这条路，它属于付费能力；
- 编辑文字 → 免费 App 里普遍做不好这件事，这也是 PDFelement 这类付费工具存在的理由。

拿不准就先用免费部分跑一阵，等真的被某个付费功能卡住再决定，见 [常见问题与解决方法.md](常见问题与解决方法.md) 的功能与会员一节。
