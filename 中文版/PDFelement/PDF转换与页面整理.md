## 一、PDF 转成别的格式

把 PDF 交给别人继续改，转成 Office 格式最常用。PDFelement 支持的转换方向（以应用内实际提供的列表为准）：

| 转换方向 | 典型用途 |
| --- | --- |
| PDF → Word（.docx） | 拿到电脑上继续改文档 |
| PDF → Excel（.xlsx） | 提取报表里的数据 |
| PDF → PPT（.pptx） | 恢复演示文稿 |
| PDF → 图片（JPEG / PNG） | 发到只收图片的地方 |
| PDF → Epub / HTML / TXT | 在阅读器或网页里看 |

操作路径：打开文件后在工具区选「转换为 Word」之类的条目，选好输出位置，等转换完成。扫描件转 Word 前要先做文字识别，否则转出来是整页图片。

## 二、把别的文件变成 PDF

反方向也常用：

- 从相册选一张或多张图片合成 PDF（截图、拍照件常用）；
- 从 Word、Excel、PowerPoint 文件生成 PDF；
- 用相机直接拍纸质文件生成 PDF；
- 建一个空白 PDF 从头开始写。

## 三、扫描与文字识别（OCR）

拍纸质文件时会用到：

1. 在工具区选扫描入口，用相机对准纸质文件拍摄，或从相册导入照片；
2. 应用把照片整理成 PDF 页面；
3. 需要改字或复制文字时，对这份文件执行文字识别，识别结果可搜索、可复制。

识别质量与拍摄直接相关：光线均匀、页面拍正、文字清晰，结果才可用。完整步骤、拍摄要领与识别不出来的排查，单开了一篇：[扫描件怎么转成可编辑文字.md](扫描件怎么转成可编辑文字.md)。

## 四、页面整理

多页文件的操作集中在页面整理类工具里：

| 操作 | 用法 |
| --- | --- |
| 合并 | 把多个 PDF 拼成一个文件 |
| 拆分 | 按页把一个文件拆成几份 |
| 提取 | 只留需要的几页另存 |
| 删除 | 去掉空白页或不要的页 |
| 旋转 | 把横倒的扫描页转正 |
| 重排 | 拖动调整页面顺序 |
| 插入空白页 | 加一页白纸补内容 |

整理完记得保存；只发某几页给别人的场景，先提取再分享最省事。

## 五、转换失败时看什么

- 文件本身是加密 PDF：先输密码打开，或解除限制后再转；
- 转换卡在进度条：大文件耗时与页数相关，别在转换中途杀掉应用；
- 转出来的 Word 排版乱了：多栏、嵌套表格这类复杂排版的还原度有限，效果以官方页面的说明为准，必要时改用提取文字的方式。
