## 一、批注：标重点、写备注，不动原文

批注和编辑的区别：批注是叠在页面上的标记层，不改 PDF 原来的内容，适合审阅、做读书笔记、给别人标意见。常用工具：

| 工具 | 用法 |
| --- | --- |
| 高亮 | 选中一段文字涂色标重点 |
| 下划线 / 删除线 | 标记待核对的句子，或划掉不用的内容 |
| 便签（sticky notes） | 在页面任意位置贴一个带文字的注释框 |
| 自由手绘 | 用手指或触控笔直接在页面上圈画 |

操作路径：打开 PDF 后点「+」图标选「注释」，底部会展开注释工具条，先选工具再点页面位置。批注会随文件一起保存，重新打开还在。

手绘相关还有几件常用工具：

- **铅笔**：有铅笔、马克笔两种笔迹，颜色、粗细、透明度都能调；
- **橡皮擦**：分「部分」和「整笔」两种擦法，前者擦掉一段笔迹，后者一笔全消；
- **形状**：矩形、圆形、直线、箭头，边框色、填充色、粗细可调，用手指直接摆放和调整大小；
- **便签外观**：便签框颜色、页面上图标的显示颜色都能在设置里换。

批注是免费能力，装好直接用；哪些功能要开会员，见 [免费版和会员版有什么区别.md](免费版和会员版有什么区别.md)。

## 二、填写 PDF 表单

合同、申请表这类带输入框的 PDF：

1. 打开表单文件，可填写的输入框会有底色提示；
2. 点一下输入框，弹出键盘直接输入；
3. 勾选框点一下切换勾选状态；
4. 填完保存。

遇到没有表单域的「死」表格（整页是图片或无输入框的排版），也可以用添加文本的方式把内容写上去，做法见 [怎么编辑PDF文字和图片.md](怎么编辑PDF文字和图片.md) 的添加文字一节。

## 三、签名、印章与密码保护

- **手写签名**：用手指或触控笔在屏幕上写一次，保存为签名样式，之后拖到需要签字的位置；同一份签名可以反复使用；
- **图章 / 印章**：给文件盖常用标记；
- **密码保护**：给 PDF 加上打开或编辑密码，防止别人翻看或改动。

## 四、批注文件怎么给别人

- 直接把带批注的 PDF 原文件发出去（微信、邮件均可），对方用任何 PDF 阅读器都能看到标注；
- 只想发其中几页，用 [PDF转换与页面整理.md](PDF转换与页面整理.md) 里的提取功能先抽出那几页再发。

## 五、两个常见状况

- 批注保存后不见了：确认保存的是同一份文件；从聊天工具里直接打开的文件可能存在临时目录，先另存一份再标注更稳妥；
- 高亮选不中文字：这份是扫描件，见 [常见问题与解决方法.md](常见问题与解决方法.md) 里关于扫描件的说明。
