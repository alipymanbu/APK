## 二、设备要求

| 位置 | 要求（官方口径，以官方页面当时显示为准） |
| --- | --- |
| 安卓手机 / 平板 | Android 8 或更高 |
| iPhone / iPad | iOS 9 或更高、iPadOS 9 或更高 |
| 电脑 | 有 WLAN / Wi-Fi；Cubase 11 或更高；Windows 另需 Bonjour；另装 Steinberg SKI Remote 1.1 |
| 电脑系统（SKI Remote 1.1） | Windows 10 / 11 64 位；macOS 12~15（Intel 与 Apple 芯片） |

一个差异值得知道：网盘这份安装包的采集信息里标的是「需要安卓 5.2 以上」，比官方商店页面写的 Android 8 低。两个口径并列放在这儿 —— 装之前以**自己设备上的实际安装结果**为准，别只看任何一边的数字。

Cubase 各版本（AI / LE / Elements / Artist / Pro）都能被遥控；但 [耳机返送怎么设置.md](耳机返送怎么设置.md) 里的 Cue Mix 依赖 Control Room，只在完整版里有。

## 三、版本号一路怎么走的

时间与内容取自官方发布信息，价格与上架状态会变，一律以官方商店页面当时显示为准：

| 版本 | 时间 | 主要变化 |
| --- | --- | --- |
| 1.1 | —— | 专门的全屏模式 |
| 1.2.6 | —— | 迭代版本（官方论坛有发布帖） |
| 1.2.7 | 2025-09-08 | 兼容更新的安卓版本；修搜索无响应；性能与稳定性改进。发布时官方同时说明：部分设备搜索仍异常、正在调查 Galaxy Tab S9 FE+ |
| 1.2.0.69 | 采集于 2026-09-24 | **网盘里这份**，早于下面的 1.3.x |
| 1.3.0 | 2026-03-31 | 大号走带视图；走带条上的撤销 / 重做；字体渲染改进；修掉部分安卓平板的图形噪点 |
| 1.3.1 | 2026-04-10 | 轨道总览与混音台支持 Drum Track |

所以「装了 app 却没有撤销按钮」「工程里有 Drum Track 而 app 不显示轨道」这两件事，都是版本没到 1.3，不是你操作错了。安卓平板上界面消失、花屏的，也在 1.3 那次修复范围内，处理办法见 [平板花屏和界面错乱怎么办.md](平板花屏和界面错乱怎么办.md)。

官方商店是**付费下载**，会做限时折扣（官网曾显示过 4 折促销），具体价格以商店当时显示为准。**已买过的账号升级是免费的**（官方对 1.2.7 的答复口径），不必重新购买。iOS 与 Android 是各自商店单独购买，两边的购买记录不通用（官方论坛答复口径）。

## 四、这个应用的支持状态

Steinberg 官网的产品说明里注明 Cubase iC Pro **不在其产品支持范围内**（截至本次检索，以官方页面为准），问题不走常规工单，走官方论坛的 Mobile apps 版块：[https://forums.steinberg.net/c/mobile-apps/10](https://forums.steinberg.net/c/mobile-apps/10)。

装不上或连不上，先看 [下载与安装教程.md](下载与安装教程.md) 的电脑端清单，再按 [手机连不上电脑怎么排查.md](手机连不上电脑怎么排查.md) 逐条过。
