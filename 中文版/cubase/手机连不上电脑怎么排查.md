## 一、先确认前置条件

九成的连不上是前置没齐，先花一分钟对这四条，都对了再往下查：

1. **Cubase 正在运行**，而且左侧 Remote Devices 列表里已经加了 **Steinberg SKI Remote**（加法见 [下载与安装教程.md](下载与安装教程.md) 第五节）。Cubase 关着或没加设备，手机那侧不会出现可点的电脑。
2. **手机和电脑在同一个 Wi-Fi** 下。电脑插着网线、手机走 Wi-Fi 属于两个网络，见第三节第 3 条。
3. **电脑端三件套装齐了**：Cubase 11+、Bonjour（仅 Windows）、SKI Remote。
4. 电脑防火墙没有拦 Cubase / Bonjour / SKI Remote（第二节第 4 条）。

## 二、逐条排查

| 现象 | 查什么 | 怎么做 |
| --- | --- | --- |
| 连接页完全看不到电脑 | 两个设备是否同一网络 | 手机连的 Wi-Fi 和电脑连的必须是同一个；换个网络再试 |
| 看不到电脑（Windows） | Bonjour 是否安装 | 没装就装：[https://support.apple.com/kb/dl999](https://support.apple.com/kb/dl999)，装完重启 Cubase |
| 看不到电脑（Windows） | 防火墙 | 放行 Cubase、Bonjour、SKI Remote 三者；Windows 防火墙的操作指南见 [https://support.microsoft.com/windows/risks-of-allowing-apps-through-windows-defender-firewall-654559af-3f54-3dcf-349f-71ccd90bcc5c](https://support.microsoft.com/windows/risks-of-allowing-apps-through-windows-defender-firewall-654559af-3f54-3dcf-349f-71ccd90bcc5c)，Bonjour 自己的防火墙配置见上面那个 Apple 页面 |
| 看不到电脑（Windows） | 电脑同时用了两个网络 | 有线与 Wi-Fi 同时接着时，两套 IP 不能一起用 —— **拔掉网线，只走 Wi-Fi** |
| 列表里有电脑但点不进去 | 密码认证 | Cubase 的 SKI Remote 页开了 Enable Authentication，手机上要输你设的那个密码 |
| 列表里一直空 | 手动填 IP | IP 写在 Cubase 的 Studio Setup → Steinberg SKI Remote 页底部；在 app 的连接页点手动输入 IP 的按钮，直接填进去 |
| 电脑名看得见，一点就报 `host not found` | 名字解析没走通 | 论坛里高频出现的报错（安卓端尤多）。跳过名字，直接用手动输入 IP 的方式连；Bonjour 是否装好也在这里再查一遍 |
| 反复试还是不行 | 重启一遍 | 路由器断电重插，手机和电脑都重启，再从头来一遍 |
| 连上就断 / 越试越不稳 | 连接被反复拉扯 | 官方口径：一次会话里断开重连多次会导致连接不稳，**重启 Cubase 和 app 两边**即可恢复 |

补充两条：

- 官方给 iOS / iPadOS 设备的建议是：连不上时**临时关掉手机蓝牙**再试。安卓端官方没有给这条，但试一次也没有副作用。
- 安卓端如果一选电脑就闪退，先看设备是不是只能跑 32 位应用的老机器（官方答复过的崩溃原因），详见 [平板花屏和界面错乱怎么办.md](平板花屏和界面错乱怎么办.md) 第五节；连是连得上、只是画面烂的，直接去那篇。
- 第二台、第三台设备连不上，或想知道上限是多少，见 [几台手机能同时连一台电脑吗.md](几台手机能同时连一台电脑吗.md)。
- **电脑要连互联网吗**：不用。这是一条局域网连接，手机和电脑挂在同一个路由器下就能通，外网断了也不影响（论坛里有用户实测断开外网照样连）。要处理的是**局域网内的互相发现**，也就是上面那几条。
- **防火墙该放行还是该关**：一律按「放行 Cubase / Bonjour / SKI Remote」处理。有用户反馈把防火墙、杀软整个关掉后反而连不上、重新打开才通 —— 这是个例，不构成「关掉防火墙」的做法。

## 三、连上了但操作不对劲

这些是官方列出的已知行为，不是你装错了：

| 你观察到的 | 官方给的说法与处理 |
| --- | --- |
| 在 Cubase 里改了工程总长度，app 上没变 | 需要**重启 Cubase iC Pro** 才会应用新长度 |
| 改了编排轨（Arranger），app 上更新很慢 | 先在 app 之外把编排做完，**关掉 app 再重开**；编排轨里没有事件时，app 上的编排按钮点不动是正常的 |
| 节拍器、预拍切不动 | Cubase 那边**有对话框开着**（比如工作室设置窗口）时切不了，先关掉对话框 |
| app 连着的时候关掉 Cubase 工程，之后 Cubase 行为不正常 | 官方建议**先退出 app、再关工程** |
| app 连着的时候切换工程，画面错乱或状态异常 | 连接期间别切工程，先断开再换 |
| 平板上个别通道的 VU 表显示不对 | 官方标注为暂无解决办法的已知问题 |

## 四、查不到答案时去哪问

Steinberg 官网的说明里注明该应用不在其产品支持范围内（截至本次检索，以官方页面为准），问题反馈走官方论坛的 Mobile apps 版块：[https://forums.steinberg.net/c/mobile-apps/10](https://forums.steinberg.net/c/mobile-apps/10)。提问前先搜一遍同名帖子，连接类问题基本都有人贴过。
