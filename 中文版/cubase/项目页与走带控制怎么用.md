## 一、界面的骨架

app 连上后是几个页面之间切换，先认三个常驻控件：

- **Overview（总览）按钮**：左上角，回总览页；那里也有断开连接的入口。
- **关闭按钮**：右上角，从设置类页面退回主页面。
- **走带按钮**：左下角，随时呼出走带面板。

手势只有三种，全 app 通用：**滑动**（拖推子、翻页、滚动工程）、**点按**（开关选项、选中条目）、**双指捏合**（项目页缩放）。

## 二、项目页看工程

项目页显示的就是电脑上那个 Cubase 工程的全貌，而且**两边实时同步** —— 你在 Cubase 里增删轨道、增删标记，这一页会自动刷新跟着变。

能做的事：

- **单指上下滑动**翻轨道，**左右滑动**在时间线上移动。
- **双指捏合**缩放时间线；标尺按时间显示当前位置。
- **定位器**：设定左、右定位器，并在它们之间跳转。
- **标记（Marker）**：设定标记、在标记之间跳转 —— 一段一段过录音时靠它。
- **节拍器**：开关节拍器、开关预拍。
- **Tap tempo**：用手指连续点几下，把速度敲成你点的节奏。

一个实用场景：你在棚里给乐手放伴奏，走到哪一段要重来，直接在手机上点标记跳过去，不用喊一嗓子让人家在键盘上找。

## 三、走带面板

左下角呼出的走带面板负责播放、停止、录音、循环这些基本动作。位置固定，翻工程翻到哪儿都能一把按到。

关于版本差异，两条要留意：

- **大号走带视图、以及走带条上的撤销 / 重做按钮**是 1.3.0 起加入的（iOS 与 Android 同步，2026-03-31 发布）。网盘里这份 1.2.0.69 没有这两样 —— 要用就得到官方商店升到 1.3 或更高（以商店当时显示为准）。
- 官方 1.3.1（2026-04-10）另外把 Drum Track 的显示补进了轨道总览与混音台。工程里有 Drum Track 而 app 上看不到对应轨道时，多半就是版本太旧。

## 四、用的时候会碰到的限制

| 情况 | 说明 |
| --- | --- |
| 工程很长、拖定位器变卡 | 官方已知问题：大工程里拖定位器可能拖慢 app，暂无解决办法 |
| 想让屏幕自动熄灭省电 | app 默认**不自动锁屏**（免得录一半黑掉）。要开：系统设置 → 应用 → Cubase iC Pro → 打开 Auto-Lock（自动锁定） |
| 想全屏操作 | 1.1 起有专门的全屏模式 |
| 只想控制混音、返送 | 切到混音台页，见 [耳机返送怎么设置.md](耳机返送怎么设置.md) |
| 想把常用命令做成按钮 | 切到快捷键命令页，见 [快捷键命令页怎么自定义.md](快捷键命令页怎么自定义.md) |

工程要保存时注意：**先退出 app，再在 Cubase 里关工程或切工程**，顺序反了会出现官方列出的异常状态（详见 [手机连不上电脑怎么排查.md](手机连不上电脑怎么排查.md) 第三节）。
