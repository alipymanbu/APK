## 一、这是个什么应用

Cubase iC Pro 是 Steinberg 出的**遥控器应用**，装在安卓手机或平板、iPhone、iPad 上，通过 Wi-Fi 控制电脑上的 Cubase（Cubase 是电脑上的编曲/录音软件）。你在录音棚里人不必凑到电脑前，拿起手机就能走带、录音、推推子、调耳机返送。

要分清两件事：**它本身不是编曲软件**，不能脱离电脑独立做音乐；它只是电脑上那个 Cubase 的远程面板。没有电脑端的 Cubase，这个 app 装上也连不了。想在手机上独立做音乐的是另一款应用 Cubasis，两者不是一回事。

官方名称是 **Cubase iC Pro**，开发者是 Steinberg Media Technologies GmbH。

## 三、手机端安装步骤

1. 打开 [Cubase iC Pro 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d460dabf8923)，转存到自己的网盘，再下载到手机。
2. 点开 APK 安装时，系统会拦一次，提示不允许安装未知来源的应用 —— 按提示给浏览器或文件管理器开一次「允许」，装完可以再关掉。
3. 装完先别急着打开：这个 app 打开后第一屏就是连接页，而连接需要电脑端先准备好（下面两节）。电脑那三样没装齐，手机上是选不到电脑的。
4. 想确认包没下残，用带 MD5 校验的文件管理器比对第二节表格里的值。
5. 官方渠道是 Google Play 与 App Store（Apple 应用商店），需要 iOS 9 或更高、Android 8 或更高；网盘这份包的系统门槛见 [版本与系统要求说明.md](版本与系统要求说明.md)。

## 四、电脑端要装的三样东西

缺一样就连不上，装之前先对一遍清单。

| 东西 | 作用 | 要求 |
| --- | --- | --- |
| Cubase | 被遥控的宿主软件 | Cubase 11 或更高（AI / LE / Elements / Artist / Pro 都可以） |
| Bonjour | 电脑与手机互相发现用的网络协议 | 只有 Windows 需要单独装；macOS 自带 |
| Steinberg SKI Remote | 让 Cubase 能被这个 app 控制的官方扩展 | 免费，1.1 版（2022-12-15 发布） |

下载地址：

- Bonjour for Windows：[https://support.apple.com/kb/dl999](https://support.apple.com/kb/dl999)
- SKI Remote macOS 版（macOS 12~15，Intel 与 Apple 芯片）：[https://download.steinberg.net/downloads_additional_content/Steinberg_SKI_Remote/1.1/Steinberg_SKI_Remote_1.1_Installer_mac.dmg](https://download.steinberg.net/downloads_additional_content/Steinberg_SKI_Remote/1.1/Steinberg_SKI_Remote_1.1_Installer_mac.dmg)
- SKI Remote Windows 64 位版（Windows 10 / 11）：[https://download.steinberg.net/downloads_additional_content/Steinberg_SKI_Remote/1.1/Steinberg_SKI_Remote_1.1_Installer_64bit_win.zip](https://download.steinberg.net/downloads_additional_content/Steinberg_SKI_Remote/1.1/Steinberg_SKI_Remote_1.1_Installer_64bit_win.zip)

地址以官方页面当时显示为准。装 Bonjour 时留意安装程序对防火墙的提示；Windows 上如果你用的不是系统自带防火墙，还要手动放行（见 [手机连不上电脑怎么排查.md](手机连不上电脑怎么排查.md)）。

## 五、在 Cubase 里添加远程设备

SKI Remote 装好后，还要在 Cubase 里把它挂上，否则 Cubase 不知道有东西要遥控它：

1. 确认手机和电脑连在**同一个 Wi-Fi** 网络下。
2. 启动你的 Cubase。
3. 打开菜单「Studio（工作室）→ Studio Setup…（工作室设置）」。Cubase 老版本里这个窗口叫「Devices → Device Setup（设备 → 设备设置）」，同一个东西。
4. 窗口左上角点「+（Add Device / 添加设备）」。
5. 在下拉菜单里选 **Steinberg SKI Remote**，它会出现在左侧 Remote Devices（远程设备）列表里。
6. 选中 SKI Remote 那一页，能看到这台电脑的 IP 地址显示在页面底部 —— 手机上找不到电脑时要手动填它，先记一下。

如果想给连接加密码：同一页上有 Enable Authentication（启用认证）开关，打开并设一个密码，手机连过来时要输。

## 六、第一次连接

1. 手机与电脑同一个 Wi-Fi，Cubase 正在运行（必须开着，DAW 关了就选不到电脑）。
2. 手机上打开 Cubase iC Pro，首次启动直接进 Connections（连接）页。
3. 列表里点你的电脑名。若第五节设了密码，输密码后回车。
4. 连上后进的是 Overview（总览）页，左下角是走带按钮，各页面怎么点见 [项目页与走带控制怎么用.md](项目页与走带控制怎么用.md)。

以后随时可以断开：在 Overview 页点 Disconnect，会回到连接页。

连不上不是这一步的问题，按顺序查 [手机连不上电脑怎么排查.md](手机连不上电脑怎么排查.md)。

一台电脑配多台手机/平板同时用（最多四台）不用重复做这节配置，见 [几台手机能同时连一台电脑吗.md](几台手机能同时连一台电脑吗.md)。
