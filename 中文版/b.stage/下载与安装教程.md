b.stage 是 bemyfriends 运营的粉丝社区应用，一个应用里能进不同艺人、球队或品牌的官方社区，看帖、看直播、买会员和周边都在里面。本篇只解决一件事：把网盘里这份安装包装进安卓手机，并把第一次打开要处理的提示过一遍。

## 一、先确认网盘里这份是哪一版

网上搜到的版本信息通常是官方当时的最新发布版，而网盘里这份是制作文档时核对过的那一版，两者未必是同一个版本号。本文出现的版本号、包名、体积以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | b.stage |
| 版本号 | 16.3.0 |
| 包名 | `com.bmf.bstage.browser` |
| 安装包体积 | 85.06 MB |
| 安装包文件名 | `b.stage_v16.3.0.apk` |
| MD5 | `ABF47253923205E48D7C911340D55666` |
| 适用平台 | Android |
| 开发者 | bemyfriends |

装之前顺手核对两件事：**包名**必须是 `com.bmf.bstage.browser`，**体积**应该在 85.06 MB 上下。对不上就说明拿到的不是这份文件。

关于版本号：官方没有公开成文的版本号递增规则，商店页面上的版本号会随发布更新，具体以官方页面当时显示的为准。

关于系统要求：官方帮助文档里曾标注 Android 9.0 以上、iOS 14.0 以上。这个门槛可能随版本调整，安装时如果系统提示「应用与你的设备不兼容」，基本就是当前版本要求的系统版本高于你的手机。

## 二、把安装包取到手机上

1. 打开 [b.stage 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9b7c49808b42)，先转存到自己网盘再下载——直接下载的临时文件，链接失效后就找不回来了。
2. 在手机网盘里找到 `b.stage_v16.3.0.apk` 下到本地。手机直接下载最省事，免得再从电脑传一遍。
3. 下载完成后核对体积约 85.06 MB。只有几十 KB 的多半是把网盘页面存成了文件，别拿去安装。

## 三、安装步骤

1. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统的这项开关常收在「安全」或「隐私」分类下。
2. **点开 APK 安装**：系统提示「应用未经过安全检测」时选择继续安装，这是非商店渠道安装包的常规提示。
3. **同包名版本要先卸载**：手机里如果已经装过其它渠道获取的同一个包名版本，覆盖安装可能报「应用未安装」，原因是两个包的签名不同。先把旧的那份卸载，再装这一版。
4. **装完先别急着调设置**：能正常打开、能看到首页，就说明包本身没问题。后面的注册、搜索社区、加会员都在应用内完成。

## 四、第一次打开会遇到什么

- **首页是一排「入口」，不是一个内容流**。顶部有收藏位、官方推荐的社区、活动横幅和正在热的内容几块，看起来元素多属正常，日常要用的两个动作是搜索和收藏，见 [搜索与收藏想追的社区.md](搜索与收藏想追的社区.md)。
- **不登录也能浏览公开社区，但收藏需要账号**。点收藏时会把你带到登录页，注册方式与账号规则见 [注册登录与账号设置.md](注册登录与账号设置.md)。
- **界面语言跟着手机系统走**。手机是中文系统，应用界面就是中文；某个社区的内容语言要在该社区里单独设，见 [界面语言怎么设置成中文.md](界面语言怎么设置成中文.md)。
- **首次启动会问是否允许通知**。这一项与你在某个社区里做的通知设置是两码事，拒绝之后应用内的推送开关会失效，见 [通知设置与收不到推送怎么排查.md](通知设置与收不到推送怎么排查.md)。
- **需要能连到海外服务器**。网络到不了服务器时，表现是一直转圈、列表刷不出来或登录失败，这与安装包本身无关，见 [常见问题与排查.md](常见问题与排查.md)。
- **会申请四类权限，且都可选**（官方商店页面的说明）：

| 权限 | 用途 | 不给会怎样 |
| --- | --- | --- |
| 照片 | 上传图片与多媒体文件 | 发帖时不能选图 |
| 相机 | 拍照或录像 | 不能直接拍素材 |
| 麦克风 | 语音消息、录像 | 语音类功能不可用 |
| 电话 | 直播通话期间控制音频 | 直播中的音频处理可能异常 |

b.stage 的权限清单里没有联系人、短信、通话记录这类项目。

## 五、这份包和官方渠道是什么关系

- 官方发布渠道是 **Google Play**（[play.google.com/store/apps/details?id=com.bmf.bstage.browser](https://play.google.com/store/apps/details?id=com.bmf.bstage.browser)）和 **App Store**（[apps.apple.com/app/id1643063288](https://apps.apple.com/app/id1643063288)）。平台的官网是 [bstage.in](https://bstage.in/)，官方帮助中心是 [support.bstage.in](https://support.bstage.in/)，遇到应用内解决不了的问题时这两处是权威出处。
- 网盘里这份 16.3.0 是文档制作时核对过的版本，**不是官方最新版**，也不会自己弹更新提示。需要新版本时，重新走一遍本文的取包与安装流程即可。
- **网盘里这份只有 Android 版**。iPhone 装不了 APK，要去 App Store 装 iOS 版。
- 想确认拿到的是不是原版包，看两项就够：**包名 `com.bmf.bstage.browser`、开发者 bemyfriends**，两项都对就是原版。

## 六、卸载与换版本

- 同一个包名在系统里只能存在一个，换版本就是「卸载旧的、装新的」，或者用同签名的新包覆盖。
- 卸载会一并清掉应用数据与登录态。账号本身在服务器上，用原来的邮箱与密码重新登录就能回到原来的社区；但**本机的登录态、缓存与系统通知授权会一起清掉**，重装后可能要重新允许一次通知。社区里的会员资格、订单与已加的收藏按账号恢复，收藏位在部分版本里要按设备重新登记。
- 装完先确认能打开首页、能搜到一个社区，再谈注册和会员的事。打不开就接着看 [常见问题与排查.md](常见问题与排查.md)。
