# b.stage 注册登录与账号设置

> 每个社区的账号是各管各的，不是一份账号通吃；本篇讲清注册怎么走、密码忘了怎么找、以及注销账号会连带失去什么。

b.stage 的账号体系是「一个社区一份账号」：你在 A 艺人的社区注册了，去 B 球队的社区还要再注册一次，两边互不相通。第一次用这个应用的人最容易在这里踩空，所以本篇把注册、登录保持、找回密码和注销四件事讲全。

## 一、先理解账号是怎么分的

| 层级 | 说明 |
| --- | --- |
| 应用本身 | 不用账号也能打开、能浏览公开社区；收藏时必须登录 |
| 单个社区 | 每个社区的会员（粉丝）各自独立，不能从一个社区转到另一个社区 |
| 会员资格 | 挂在某个社区之下，换社区不会跟着走 |

也就是说，一个邮箱在多个社区各注册一次是完全正常的，不算重复注册。

## 二、注册一个社区的账号

1. 在应用里搜到并进入目标社区，点底部的收藏按钮，或直接点社区里的登录入口。
2. 进入登录页后选择注册，按表单填邮箱与密码。**密码要求：英文、数字、特殊符号混合，至少 8 位**。
3. 提交后去邮箱点验证链接。如果没收到，先翻垃圾箱；仍没有就核对自己填的邮箱有没有大小写、空格或特殊符号写错——官方明确把「邮箱写得不准」列为收不到验证信的首要原因。
4. 注册完成后可以设昵称与头像。这两项在发帖和评论时对外可见，填之前想一下要不要用真名。

## 三、登录状态怎么保持

- 首次登录之后状态会保持，不用每次打开都重登。
- **超过 30 天没有打开过这个应用，会被自动登出**，需要重新登录一次。这是官方帮助文档里写明的规则，不是账号出问题。
- 换手机或卸载重装，都要重新登录；登录后社区里的会员资格、订单这些跟着账号走。

## 四、忘记密码与修改资料

| 想做的事 | 在哪做 |
| --- | --- |
| 找回密码 | 登录页点「忘记密码」，填注册时用的邮箱，官方会发重置邮件（注意看垃圾箱） |
| 改密码 | MY → 账号信息 → 修改密码，新密码同样要满足 8 位混合字符的要求 |
| 改昵称或头像 | MY 顶部资料区，或 MY → 账号信息 → 编辑资料 |
| 联系客服 | MY → 客服中心 → 常见问题；非会员直接提问不方便，官方建议先注册账号再问 |
| 查提问进度 | MY → 客服中心 → 我的提问记录 |

## 五、注销账号要付出的代价

注销入口在 MY → 账号信息 → 注销账号，但官方要求先同意下面这份清单，逐条都有实际影响：

- **昵称不会释放**：注销后其他成员也用不了这个昵称。
- **已发的内容和评论不会跟着删**：要删得自己在注销前逐条删掉。
- **在有效期内的券、会员权益、积分全部作废**，不能赎回。
- **已下单未发货的订单仍会发货**，但服务里查不到物流。
- **会员信息一并删除，不可恢复**；只有法律或公司内部规章要求留存的部分会按隐私政策保留一段时间。

一句话：**先处理掉要留的东西，再注销**。尤其是会员还有剩余周期时，注销等于把剩余周期直接扔掉。

## 六、常见卡点

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示账号已存在 | 这个邮箱在这个社区已经注册过 | 直接走登录，不用再注册 |
| 换个社区登录说没有账号 | 每个社区账号独立 | 在那个社区重新注册一次 |
| 收不到验证或重置邮件 | 邮箱填错，或被丢进垃圾箱 | 核对邮箱写法；翻垃圾箱；换邮箱重试 |
| 登录后又变成未登录 | 超过 30 天没打开应用，被自动登出 | 重新登录即可 |
| 想改语言但找不到入口 | 语言是**按社区**设置的，不在应用总设置里 | 见 [界面语言怎么设置成中文.md](界面语言怎么设置成中文.md) |

登录不上去又排查不出来时，按 [常见问题与排查.md](常见问题与排查.md) 的顺序走一遍；那份排查的终点是官方帮助中心。
