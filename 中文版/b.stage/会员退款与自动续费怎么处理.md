# b.stage 会员退款与自动续费怎么处理

> 买错了、不想续了、买完没用后悔了——这几件事的规则不一样。本篇讲清「购买确认」这条线在哪、自己怎么取消、以及取消之后还能用到哪天。

在 b.stage 上买会员或 POP 订阅，能不能退、怎么停，取决于三件事：**买的是哪一类商品、订单到哪一步了、有没有点开看过内容**。本篇把这三条拆开讲，最后给一句最省事的操作顺序。

## 一、先看你买的是哪一类

| 商品类型 | 典型例子 | 能不能退/停 |
| --- | --- | --- |
| 一次性买断的数字商品 | 一次性数字通行证、票 | 确认前可自己取消；确认后不能 |
| 定期付款的会员 | 按月/按周期扣款的会员 | 随时可关掉定期付款，已扣的钱不退 |
| 定期付款的 POP 订阅 | 实时聊天与直播订阅 | 同上，另有几条专属规则 |
| 实体商品 | 周边、会员 KIT | 订单进入「商品准备中」后不能取消 |

## 二、那条关键的分界线：「购买确认」

数字类商品有一条统一的分界线，官方把它叫**购买确认**：

- **只要点开看过内容**，订单立刻转为购买确认；
- **哪怕一次没看，付款满 7 天也会自动转为购买确认**；
- 一旦进入购买确认，**就不能再自行取消、也不能退款**了。

这条规则对「买了放那儿没动」的情况最不友好——很多人以为没用过就能退，实际上 7 天一过就自动确认。所以**想退货的窗口只有一个：付款后到确认前这段时间**。

## 三、确认前怎么自己取消

入口是 **MY → 订单历史**，找到那一笔订单点进去，用里面的取消按钮。

顺手对一下订单状态，决定还有没有戏：

| 订单状态 | 含义 | 能否自行取消 |
| --- | --- | --- |
| 处理中 | 已下单，尚未完成支付/确认 | 可以 |
| 已完成 | 支付成功、但还没到购买确认 | 可以 |
| 购买确认 | 看过内容，或付款满 7 天 | 不可以 |
| 已过期 | 使用期到了 | 不可以 |
| 已取消 | 你或社区已经取消 | 无需再操作 |

实体商品另有一条：订单一旦进入「商品准备中」阶段，取消按钮就没了。

## 四、定期付款（自动续费）怎么关

这是问得最多的一件事。路径是：

**MY → 订单历史 → 会员 → 找到要停的那件商品 → 点「取消定期付款」**

要点有三条：

1. **随时可以关**，不用等扣款日。
2. **关掉不可恢复**，想再续要重新买一次。
3. **关掉之后不是马上断**，本期的使用期到期才终止，这期间你照常能用。

**已经扣掉的那一期不退**。所以正确做法是：不想续就在下一个扣款日之前关掉，而不是等扣完再申诉。

取消或退款完成后，这笔订单的支付状态会变成「已退款」，同样在 **MY → 订单历史** 里能看到。

## 五、POP 订阅多出来的几条规则

POP 是订阅制、且内容当次即消耗，所以另有几条，买之前值得先看：

- **通行证在你首次进入 POP 的那一刻就算已使用**，不是从你「开始聊天」算。
- **首购后 7 天即购买确认**，之后不退。
- **首购之后每次续费的扣款一律不退**，与是否使用、与扣款日无关——所以想停只能提前关自动续费。
- **到期后 7 天内重新订阅，订阅期连续计算**，中间断掉的那几天也算进去。想接着看就别拖过这个窗口。
- **买的是「Early-Bird」这类指定艺人的套餐时，订阅期内不能更换艺人，也不能改订阅的艺人数**；要调整只能等本期到期后重新买一份。

## 六、按这个顺序操作最省事

1. 先看订单状态：是「处理中/已完成」还是「购买确认」。
2. 还在确认前 → 在 MY → 订单历史 里直接取消，等支付状态变成已退款。
3. 已经是购买确认 → 这笔钱退不了，但**定期付款仍然可以关**，先把自动续费停掉，避免下一期继续扣。
4. 是要停实体商品的订单 → 尽早操作，别等它变成「商品准备中」。

## 七、卡在这些地方就找客服

- 取消了但状态一直没变成已退款；
- 被重复扣款，或扣款金额与购买页不符；
- 订单归属的账号和你现在登录的不是同一个；
- 商品下架、社区停止运营这类平台层面的事。

走社区内的客服入口提交（MY → 客服中心），把**订单号、扣款日期与金额、订单页截图**一起给出去，比只描述现象快得多。其他类型的问题见 [常见问题与排查.md](常见问题与排查.md)。
