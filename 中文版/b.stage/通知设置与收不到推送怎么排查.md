# b.stage 通知设置与收不到推送怎么排查

> 收不到艺人发帖提醒，八成是两级开关里的某一级没开。本篇讲清两级开关分别在哪、通知项怎么细分到单个艺人，以及按现象排查的顺序。

b.stage 的推送有**两级开关**：一级是手机系统层面的通知权限，二级是你在各个社区里分别设的通知项。只开一级、不开另一级，就会「明明订阅了艺人却一条提醒都收不到」。这是最常见的投诉，先按下面的顺序分清。

## 一、第一级：系统通知权限

应用**第一次打开时会问你是否允许通知**。这一项和你后来在每个社区里做的设置互不相干——系统这一级关掉，社区里开得再全也没用。

- 当时点了「不允许」：去手机「设置 → 应用 → b.stage → 通知」，手动把允许通知打开。
- 国产系统还有额外的自启/后台限制，如果通知时有时无，顺手把 b.stage 加进后台白名单、关掉省电限制。

## 二、第二级：每个社区里的通知项

进目标社区，打开 **MY → 通知设置**，这里是按社区生效的。官方列出的推送项有四类：

| 通知项 | 内容 |
| --- | --- |
| 艺人活动通知 | 艺人的新帖、艺人的评论与回复、艺人的点赞/回应 |
| 新帖通知 | 社区里的新帖子 |
| 直播/聊天通知 | 开播与聊天相关提醒，POP 的提醒也走这里 |
| 营销信息通知 | 活动与推广类信息 |

**艺人活动通知可以细到单个艺人**：点这一项的「设置」，会展开艺人清单，可以逐个开关，也可以用「全部关闭 / 全部开启」批量处理。单个艺人的设置里还分两组——艺人活动（新帖、评论/回复、点赞）和**与你有关**的活动（你帖子下的评论/回复、你帖子收到的回应）。只想收回复、不想被新帖刷屏，就按这个分层调。

**通知角标的辨认方式**：收到推送时，左侧显示社区图标，右侧显示该社区的图标或艺人的头像，据此判断是哪条消息。

## 三、按下不响的排查顺序

| 现象 | 先查哪一级 | 具体做法 |
| --- | --- | --- |
| 一条推送都没有 | 系统级 | 手机设置里确认 b.stage 的通知权限开着，并且没被「勿扰模式」或省电策略拦掉 |
| 有的社区响、有的不响 | 社区级 | 逐社区进 MY → 通知设置，确认对应项是开的 |
| 新帖有提醒、艺人的没有 | 艺人级 | 进「艺人活动通知 → 设置」，看这个艺人是不是被单独关了 |
| 只有回复没提醒 | 分组设置 | 检查「与你有关的活动」那一组 |
| 直播开播时没提醒 | 社区级 | 开「直播/聊天通知」；卖 POP 的社区尤其要靠这一项 |
| 换了手机后全都不响 | 系统级 + 社区级 | 新机权限要重开，社区设置跟随账号，通常还在 |

通知项实际生效还与各社区的运营设置有关，**某个社区可能压根没开某一类通知**，这种时候列表里看不到那一项，不是设置丢了。

## 四、邮箱通知

官方 FAQ 里提到，艺人活动这类提醒**同时提供邮件通知与 App 推送两种渠道，且可以分别设置**。如果推送正常、邮件收不到，去邮箱的垃圾箱与推广箱找一遍，并把发信域名加进白名单。

## 五、其他值得知道的推送行为

- 首次启动时问的那次系统通知授权，和你后来在社区里做的通知设置互不影响，它是按设备问一次的。
- 首页的推荐与热门内容按设备区分，所以两台手机收到的非定向推送可能不同。
- 换设备后如果 30 天内没打开过应用会被自动登出，登出状态下收不到需要账号的提醒，见 [注册登录与账号设置.md](注册登录与账号设置.md)。

推送之外还有别的问题（打不开、白屏、登录失败）时，走 [常见问题与排查.md](常见问题与排查.md)。
