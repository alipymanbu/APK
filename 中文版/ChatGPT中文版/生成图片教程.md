## 一、能不能画，先看这三点

生成图片不是应用自带的本地功能，而是**账号背后的服务提供的**，所以开不开得了取决于：

1. **账号是否有生图能力** —— 免费与付费账号可用的模型、每日额度不同，以页面当时显示为准；
2. **当前对话用的模型** —— 有的模型默认不带生图，出图前先确认模型选择；
3. **网络能连上服务** —— 连不上就一张也出不来，排查见 [常见问题与解决办法.md](常见问题与解决办法.md)。

判断方法很直接：发一句「画一只戴帽子的猫」，能回图就是能用；回的是纯文字说明，就是当前模型/账号没开生图，换个模型再试。

## 二、最简操作：一句话出图

1. 打开应用进到对话页（见 [界面与基本用法.md](界面与基本用法.md)）。
2. 在输入框写清你要什么，例如：`画一张海报：深蓝背景，中间一个奔跑的人影，标题"夜跑"，16:9`。
3. 发送，等图生成，通常几十秒。
4. 点开大图 → 保存到手机。

**改图不用重开**：在同一对话里接着说「背景换成红色」「标题字大一点」，它记得上一张的内容，会基于原图改。

## 三、提示词怎么写才出得准

官方的图片提示词指南（[Image prompting](https://platform.openai.com/docs/guides/image-generation)，以页面当时显示为准）建议把这几件事一次说清 —— 按优先级抄作业：

| 要素 | 写什么 | 例 |
|---|---|---|
| 用途 | 这图给谁看、放哪用 | 朋友圈封面 / 商品主图 |
| 主体 | 画面里有谁、在干嘛 | 一只戴毛线帽的橘猫趴在键盘上 |
| 构图与视角 | 主体占多大、什么角度 | 特写、居中、4:5 竖图 |
| 风格与光线 | 摄影还是插画、什么光 | 水彩插画 / 影棚白底 |
| 文字 | 要出现的字，精确到标点 | 标题"夜跑"，只出现一次 |

三条实测好用的规矩：

- **文字要用引号包住**并注明「只出现一次」—— 这是文字渲染不出错的关键；
- **先定主体再改细节**：第一版满意后，把描述留着只换场景，能保持角色一致（做系列图靠这个）；
- **不要的东西也写明**：「不要水印、不要多余文字」比不说更干净。

## 四、拿现成图当素材

- **基于照片改**：在输入框点附件图标上传照片，再说要求 ——「把这张照片变成手绘水彩风格，保留人物五官和衣服」。
- **参考风格**：上传一张你喜欢的图，说「参考这张的风格画一个……」，比用形容词描述风格稳。
- **草图定构图**：随手画个布局再配一句「按这张草图出成品图，保留构图」，比纯文字描述更贴合你的想法。

上传的照片会进入对话上下文，涉及隐私的照片（证件、聊天记录截图）想清楚再传。

## 五、出图不满意的常见处理

| 现象 | 处理 |
|---|---|
| 文字写错 / 多出字 | 把要的字用引号重发，加「这行字只渲染一次」 |
| 人物每张长得不一样 | 把第一张满意的图留在对话里，后续要求「沿用同一角色：发型、服装、配色」 |
| 画面太乱 | 删掉修饰词，只留主体+背景+构图三项 |
| 直接不出图、只回文字 | 换模型、检查账号额度，见第一节；网络问题见常见问题篇 |
| 生成到一半断了 | 点重新生成；反复断见 [常见问题与解决办法.md](常见问题与解决办法.md) |

## 六、边界在哪

- 生成能力、可用模型、每日额度都会随官方调整变化，**以你页面当时显示为准**；
- 生成的内容要遵守官方使用规则，别拿去伪造他人身份、材料或误导性信息；
- 一次生成多张时，挑一张点开保存即可，不用全下载。
