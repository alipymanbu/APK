## 一、先分清是谁的问题

这应用没有自己的服务器，出问题时先定位责任方，能少走一半弯路：

| 现象范围 | 多半是 | 下一步 |
|---|---|---|
| 全系统的网页都打不开 | 你的网络 | 查网络、换 Wi-Fi ⇄ 移动数据 |
| 只有它打不开，浏览器开 [chatgpt.com](https://chatgpt.com) 也不行 | 服务端或地区限制 | 看 [status.openai.com](https://status.openai.com/) 是否在故障；地区限制见注册篇 |
| 浏览器能开、就应用卡 | 应用缓存/本地状态 | 清应用数据重进 |
| 打字能发、回复总失败 | 账号或模型 | 重新登录、换模型 |
| 安装阶段就失败 | 包或系统 | 见第四节 |

官方状态页：[https://status.openai.com/](https://status.openai.com/) —— 显示故障时所有人都一样，等它恢复即可。

## 二、卡在加载页 / 空白 / 无响应

加载页（`Loading the chat`）长时间不动，或进去后一片空白，按顺序试，一般前两条就能解决：

1. **杀掉应用重开** —— 上拉清掉后台再点图标。
2. **切换网络** —— Wi-Fi 和移动数据互换一次；很多连不上的问题出在当前网络出口上。
3. **清应用数据**：设置 → 应用管理 → 该应用 → 存储 → **清除数据**（会退出登录，账号在服务端，重登即可，对话不丢）。
4. **换浏览器验证**：手机浏览器直接打开 [chatgpt.com](https://chatgpt.com)，能开说明服务正常、问题在应用本地；开不了就是网络/服务侧问题。
5. **登录态过期**：能进起始页但一点就弹登录，重新登一次（[注册与登录教程.md](注册与登录教程.md)）。

官方同款排查（[响应慢与卡死条目](https://help.openai.com/zh-hans-cn/articles/9047779-%E4%B8%BA%E4%BB%80%E4%B9%88%E6%88%91%E7%9A%84-chatgpt-%E5%93%8D%E5%BA%94%E8%BF%99%E4%B9%88%E6%85%A2)）：先等 30–60 秒 → 停止生成再重新生成 → 开新对话 → 重新登录。

## 三、能进对话但消息发不出去

| 报错/现象 | 处理 |
|---|---|
| 「出了点问题」 | 刷新/重启应用；看状态页；清缓存；换网络 |
| 「发生网络错误」「WebSocket 连接错误」 | 换网络重试；关掉网络层的代理/过滤类工具再试（官方条目原文建议） |
| 回复发到一半断掉、一直转圈 | 点停止生成 → 重新生成；还不行开新对话重发 |
| 「生成回复时出错」 | 多半一次性故障，直接重新生成 |
| 提示频率限制 / 可疑活动 | 停下来等一段时间（官方建议最多等 1 小时），别连续重试；确认账号没与他人共享 |
| 提示额度用完 / 达到上限 | 按 24 小时滚动周期等恢复即可，期间退回打字不占语音额度；图片、文件的额度与文本额度分开算，文本没限不等于图片能无限出（见生成图片篇第一节） |
| 对话越来越慢、越聊越卡 | 开新对话，长上下文是变慢的常见原因 |

完整对照表在官方文档 [排查 ChatGPT 错误消息](https://help.openai.com/zh-hans-cn/articles/7996703-troubleshooting-chatgpt-error-messages)，以页面当时内容为准。

## 四、装不上 / 装完闪退

| 现象 | 处理 |
|---|---|
| 「解析包时出现问题」 | APK 没下完整，回 [下载与安装教程.md](下载与安装教程.md) 重新下载（大小约 20.97 MB） |
| 「禁止安装未知来源应用」 | 按弹窗进入设置，允许该来源安装（安装篇第三节） |
| 「应用未安装」 | 存储空间不足先清空间；若装过旧版本且签名不同，先卸载旧的再装（会退出登录，对话在账号里） |
| 装完一点就闪退 | 清应用数据；仍闪退则重新下载安装包覆盖安装 |
| 提示系统版本过低 | 以安装时的系统提示为准；第三方页面标注需要安卓 5.2 以上 |

装完核对包名 `com.jhsoft.aibot`、版本 `1.1.1.5`，和 [下载与安装教程.md](下载与安装教程.md) 第一节表格一致即为正确安装。

## 五、登录相关

「已有用户使用此电子邮件」「身份验证方法错误」「地区不支持」这几类，全部按 [注册与登录教程.md](注册与登录教程.md) 第三、四节处理 —— 核心两条：**登录方式与注册方式保持一致**、**网络位置要在官方支持地区**。

## 六、还没解决怎么办

按这个顺序收尾，每一步都把信息留好：

1. 换一台设备或换一个网络试一次 —— 能区分账号问题和设备问题；
2. 打开 [status.openai.com](https://status.openai.com/) 确认不是全局故障；
3. 记下报错原文、发生时间、当时用的模型，去官方帮助中心提交：[联系支持团队](https://help.openai.com/zh-hans-cn/articles/6614161-how-can-i-contact-support)；
4. 涉及账号本身（登不上、被判异常）的，只能由官方支持处理，应用侧没有重置入口。
