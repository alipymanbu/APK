# OpenBOR 打不开游戏、闪退：常见问题排查

> 游戏列表是空的、选了 pak 就闪退、存档没了——本篇按症状给出排查顺序，多数问题两分钟内能定位。

> **OpenBOR 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/fe784313ee54](https://pan.quark.cn/s/fe784313ee54)

## 一、游戏列表是空的

按这个顺序查：

1. **重启应用再说**。列表在启动时读取，刚复制进去的 pak 不重启不显示——这是最高频的原因。从最近任务彻底划掉再打开。
2. **位置对不对**。pak 必须在 `OpenBOR/Paks/` 这一层，放在 `OpenBOR` 根目录、或 `Paks` 里又套了一层文件夹，引擎都看不到。目录结构见[下载与安装教程](下载与安装教程.md)。
3. **文件后缀对不对**。确认是 `.pak` 结尾；有的网盘/下载工具会把文件改名，比如变成 `.pak.1` 或带 `(1)` 这种尾巴，改回 `.pak` 再试。
4. **权限给了没**。首次运行时拒绝文件访问权限的，去系统设置里给 OpenBOR 补上存储权限。

## 二、选了游戏就闪退或黑屏

先去看日志：`OpenBOR/Logs/OpenBorLog.txt`。每次启动、加载模块的完整过程都写在里面，出错的最后一两行就是答案。常见的几类：

| 日志里出现 | 大概率原因 | 处理 |
| --- | --- | --- |
| `NO MODS IN PAKS FOLDER!` | Paks 目录里没有有效 pak | 回到上一节查位置与后缀 |
| `Error loading level list from data/levels.txt` | 模块数据不完整（多见于解包过的模块） | 重新下载完整的 pak，不要手工拼装目录 |
| 启动横幅显示的 build 号与你预期不符 | 引擎 build 与模块要求不匹配 | 看下一节 |
| 日志很短、刚加载就中断 | pak 本体损坏（下载不完整） | 校验文件大小后重下 |

向社区求助时直接把 `OpenBorLog.txt` 全文贴出来，比描述「闪退」有效得多。

## 三、版本不匹配：引擎不是越高越好

再强调一次[引擎与模拟器有什么区别](引擎与模拟器有什么区别.md)里的结论：**每个模块锁定它开发时的引擎 build**。两个方向都会出问题——

- 引擎比模块老：模块用到了新版本才有的指令，跑不起来。
- 引擎比模块新：老模块（尤其大量 V3 时代的作品）在新引擎上可能因脚本行为变化而闪退。

排查动作：打开 `OpenBorLog.txt` 看启动横幅里的 `OpenBoR v3.0 Build xxxx` 字样确认手上引擎的版本，再对照模块作者标注的要求。差得远就换对应 build 的引擎 APK——这也是为什么同一台手机上有人会留不止一个 OpenBOR 版本。

## 四、存档不见了

存档在 `Saves` 目录、按模块隔离，丢失通常是这几种情况：

- 上次是杀应用退出的，本来就没写进存档——退出前走暂停菜单 Quit，见[退出游戏与存档方法](退出游戏与存档方法.md)。
- 覆盖安装/更换了不同 build 的引擎，旧存档格式对不上。
- 清理类操作（清空 `Saves`、重装应用）把存档一起带走了。

重装或换引擎前，先把 `Saves` 目录复制一份留在别处，出问题还能还回去。

## 五、还没解决时

带着 `OpenBorLog.txt` 去官方社区 [chronocrash.com](https://chronocrash.com/) 的求助板块发帖，注明设备型号、Android 版本、引擎 build 与出问题的模块名。另外确认一下基本盘：本套文档对应的安装包标注系统要求 Android 5.2 及以上（以安装包标注为准），过老的设备不在支持范围。

手柄没反应、按键错乱这类输入问题与日志无关，排查路径见[手柄没反应与按键错乱怎么办](手柄没反应与按键错乱怎么办.md)。
