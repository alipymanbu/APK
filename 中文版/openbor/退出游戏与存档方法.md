# OpenBOR 怎么退出游戏与保存进度

> 本篇讲两个最常被问的操作：玩到一半怎么退出当前游戏回到引擎菜单，以及退出前后怎么把进度存下来、存档放在哪。

## 一、退出当前游戏：走暂停菜单，不是杀应用

游戏进行中呼出**暂停菜单**（Android 上通常按返回键或点触屏上的暂停按钮，具体以当前模块的按键说明为准），选择 **Quit**（退出）——这样会正常结束当前模块、回到引擎菜单或游戏列表，引擎和游戏都会把该收尾的事情做完。

直接从最近任务里把 OpenBOR 划掉属于杀进程：能退出，但正在进行的关卡进度来不及落盘，下次只能从头来。除非应用彻底卡死，否则优先走暂停菜单。

## 二、存档怎么打

OpenBOR 的存档挂在模块自己的存档槽上，流程是：

1. 玩到想停的位置，呼出暂停菜单，选 **Quit** 时会提示选择存档槽（slot），选一个确认。
2. 下次进同一个模块，在标题界面选 **Start → Continue**，再选刚才那个槽位，接着上次的位置玩。

只有「通过 Quit 正常退出」这个动作才会写存档——直接杀应用、断电式的退出不产生存档。另外存档是**按模块隔离**的，A 游戏的槽位与 B 游戏互不相干。

## 三、存档放在哪、能不能搬

存档数据在安装时生成的 `OpenBOR/Saves` 目录里（目录结构见[下载与安装教程](下载与安装教程.md)）。两点提醒：

- 存档格式对引擎版本敏感，**换引擎 build 后旧存档不保证能读**；清空 `Saves` 目录等于清档，动手前想清楚。
- 如果你要重装应用或换设备，想把进度带走，备份的对象就是这个 `Saves` 目录；放进 `Paks` 的游戏包另算。

## 四、锁屏与后台时先暂停

社区里反复出现的教训：锁屏或切后台前先把游戏暂停。有些设备上引擎会在锁屏后继续维持运行，画面停了逻辑没停，解锁回来角色可能已经被打倒。养成「离开先暂停」的习惯，顺带也省电。
