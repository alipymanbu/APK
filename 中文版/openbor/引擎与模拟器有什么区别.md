# OpenBOR 是什么：引擎还是模拟器？

> 你搜 OpenBOR 时大概率会同时看到「模拟器」「引擎」两种说法，本篇讲清它到底是什么、能跑什么类型的游戏、支持哪些平台，以及版本号怎么认。

## 一、一句话定位

OpenBOR（Open Beats of Rage）是一个开源、免授权费的 2D 横版动作游戏引擎，2005 年从 Senile Team 的 Beats of Rage（一个致敬《怒之铁拳》的项目）开源衍生而来，采用 BSD-3-Clause 许可证，官方代码托管在 [github.com/DCurrent/openbor](https://github.com/DCurrent/openbor)，官方社区与资料站是 [chronocrash.com](https://chronocrash.com/)。

## 二、它不是模拟器，这一点直接影响你怎么用它

模拟器模拟的是某台主机的硬件，装上后跑的是那台主机的 ROM。OpenBOR 完全不碰这套逻辑：**每个 OpenBOR 游戏是一个独立的软件包（.pak 模块），并且锁定它开发时所用的引擎 build 版本**。

这带来两个实际后果：

- 引擎本身装完是空的，游戏包要另外获取、放进指定目录——所以别按「装模拟器 → 找 ROM」的旧经验来，先看[下载与安装教程](下载与安装教程.md)和[添加游戏包的步骤](添加游戏包的步骤.md)。
- 游戏包不是「放进去就能跑」的通用文件：同一个 pak 在 A 版引擎跑得好好的，换到更高或更低的 build 上可能直接闪退。社区反复强调的一条就是**用游戏作者指定的引擎版本**，别随手把 Windows 上很老的 pak 扔给手机上的新引擎。

## 三、能跑什么类型的游戏

它为横版清版动作（beat 'em up，就是《双截龙》《快打旋风》《怒之铁拳》那一类）做了整套默认行为：走位、连段、抓投、协作出招、关卡推进，作者准备好素材和配置就能出游戏。但引擎的能力不止这一类，社区里也有用它做的平台跳跃、飞行射击、角色扮演、解谜等类型，且原生支持本地多人同屏。

对你的实际意义：在游戏列表里看到风格迥异的作品很正常，玩法差异来自模块作者，而不是你装错了引擎。具体有哪些成品可下，社区榜上的入门清单见[值得先玩的模块有哪些](值得先玩的模块有哪些.md)。

## 四、支持哪些平台

OpenBOR 是跨平台引擎，截至本文整理时（以官方页面显示为准）：

| 状态 | 平台 |
| --- | --- |
| 活跃维护 | Android、Windows、Linux、macOS、Wii、PSP、PS3 |
| 已停止更新（旧版本仍流传） | Dreamcast、GP2X、GP2X Wiz、OpenDingux 等 |

Android 版是本套文档的对象；掌机固件（如各种开源掌机）里内置的 OpenBOR 同样吃「pak 要配对版本」这条规则。

## 五、版本号怎么认

官方社区习惯用 **build 号**标识引擎版本（例如 Build 6391、Build 7760 这类数字），大版本则常被称作 V3、V4。build 号越高不代表越「兼容」——很多老模块只在 V3 上能跑。

网盘里这份 Android 安装包标的是 **1.0.0**（包名 org.openbor.engine，约 2.32 MB），这是安装包自身的版本标注，与官方 build 号是两套记法；你想确认手上引擎的真实 build，看 `Logs/OpenBorLog.txt` 里的启动信息，具体见[常见问题与排查](常见问题与排查.md)。
