## 一、先学会挑，再抄清单

官方社区 [chronocrash.com](https://chronocrash.com/) 的资源区里，Games 分类下有二百多个游戏资源（截至 2026-09，数字还在涨）。在清单之外自己挑时，看三个信号：

1. **帖子状态**：Modules 版块每个帖子标着 Complete（完结）或 In Progress（制作中）。制作中的模块版本变动大，遇到 bug 先看是不是还没做完。
2. **引擎版本要求**：模块锁定开发时的引擎 build，作者帖子顶上一般会写。对照方法见[引擎与模拟器有什么区别](引擎与模拟器有什么区别.md)。
3. **更新日期**：近期还在更新的模块，说明作者还在维护、报错有人管。

## 二、社区榜上常见的入门模块

下表条目与作者信息取自社区资源页与 Modules 版块（截至 2026-09，排名与状态会变动，以社区页面当时显示为准）：

| 模块 | 作者 | 看点 |
| --- | --- | --- |
| Streets of Rage X（Windows / Android） | Kratus | 怒之铁拳 2X 的续作，把历代怒之铁拳重制进同一个游戏；仍处 beta，更新幅度大 |
| Streets of Rage 2X | Kratus | 怒之铁拳题材重制，社区评价长期位居资源榜前列 |
| Ultimate Double Dragon | Mr.Q! | 双截龙题材，招式量大，格斗风格可实时切换 |
| Golden Axe Returns | ZVitor | 战斧题材，最多四人同乐，武器可实时组合更换 |
| Double Dragon Reloaded Alternate | magggas | 双截龙与职业摔跤元素的混搭重制 |
| Street Fighter 89 | danno | 以快打旋风为底子的街霸题材清版 |
| Marvel Infinity War | ZVitor | 漫威角色清版，已完结 |

这些模块的 pak 下载都在各自的社区资源页里，下载后放进 Paks 目录的方法见[添加游戏包的步骤](添加游戏包的步骤.md)。

## 三、版权与下架风险

这些多是爱好者基于既有 IP 做的致敬之作，**个别项目可能因版权方要求停止分发**——社区讨论里就提到过战斧题材模块遇到过这种情况。某个模块突然找不到时，先去作者的社区主页看有没有替代项目或新地址，不要去来路不明的第三方站碰运气。
