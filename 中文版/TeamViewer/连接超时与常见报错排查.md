## 一、报错对照表

| 现象 / 报错 | 最可能的原因 | 处理 |
| --- | --- | --- |
| 反复「连接超时」 | ID 被疑似商业用途标记 | 走官方重置申诉，见第三节 |
| 弹「检测到商业用途」 | 同上 | 同上 |
| 提示 ID 不存在 / 一直连不上 | 对方 App 没开、ID 抄错、对方断网 | 核对 ID 数字，确认对方在线 |
| 密码错误 | 临时密码已刷新 | 抄屏幕上**当前显示**的密码，或改用固定个人密码 |
| 能看到手机画面但点不动 | 缺厂商插件 / 机型只支持屏幕共享 | 装 AddOn 或通用插件，见第四节 |
| 「此设备仅支持屏幕共享」 | 该机型无远程控制兼容插件 | Android 7+ 可试通用插件 |
| 每次连手机 5 分钟就断 | 免费个人用户连接移动设备的时长限制 | 重连即可，见第五节 |

## 二、密码总是错的几种情况

- 电脑端的**临时密码**在应用重启后就会变，别用上一次记的旧密码。
- 输错对象：ID 是不变的，变的是密码；两者填反了会一直验证失败。
- 电脑端如果设了固定个人密码，优先用它；没设的话，在电脑端「选项 → 安全性」里可以设（以你所装版本界面为准）。
- 无人值守场景连安卓 Host 设备不需要密码验证，走账号分配即可，设置方法见 [电脑控制安卓手机的设置方法.md](电脑控制安卓手机的设置方法.md)。

## 三、连接超时：先想到商业用途判定

官方知识库明确：「连接超时」报错与疑似商业用途有关，不是软件 Bug。也就是说，如果你频繁帮不同的人连不同的机器，哪怕自认是私人用途，也可能被自动判定标记。处理路径：

1. 对照 [免费个人用途与商业用途判定.md](免费个人用途与商业用途判定.md) 第二节，先自查用途是否真的越线。
2. 确认无误后走 [teamviewer.com/reset](https://teamviewer.com/reset) 申诉，把自己的 ID 和对方的 ID 都填上（每个表单最多 10 个）。
3. 等审核邮件（官方口径 72 小时内回复，量大时可能一周），期间卸载重装不会清除标记。

## 四、被控安卓端：能看不能点 / 黑屏

电脑连安卓手机时，画面出来了却操作不了，几乎都是插件问题：

1. **先装品牌插件**：被控手机上 QuickSupport 连接时会自己提示下载对应品牌的 AddOn，装完按提示去「设置 → 辅助功能（无障碍）」启用插件服务。
2. **没有品牌插件就用通用插件**：Android 7 及以上可装 Universal add-on，同样要在辅助功能里启用。机型兼容性的完整判断方法（含插件直链与「仅支持屏幕共享」的处理）见 [哪些手机能被远程控制.md](哪些手机能被远程控制.md)。
3. **插件被系统关了**：部分省电策略会自动停用辅助功能服务，重新开启即可；这属于系统行为，隔三差五要回头看一眼。
4. 都不支持时，App 会明示「此设备仅支持屏幕共享」，此时只能看画面、用语音或聊天指导对方操作。

## 五、5 分钟断开不是故障

免费个人用户连接**移动设备**（安卓手机、平板）时，官方限制每次连接最长 5 分钟，到点自动断开。判断方法很简单：如果每次都是固定 5 分钟左右断、重连又能用，就是这个限制，不是被风控。手机连手机同样受限，而且不支持文件传输和设备面板。

真正的风控（连接超时、商业用途提示）不遵守这个规律，随时可能断，且重连无解——两者的区分见第三节。

## 六、以上都对还是连不上

逐项过一遍：

- 两端 App 都在前台运行，被控端没被系统杀后台（国产 ROM 尤其常见，把 TeamViewer 加进自启动白名单）。
- ID 数字逐位核对，中间别混入空格。
- 换一个网络试试（手机切流量 / Wi-Fi），个别网络环境会拦截连接。
- 两端版本都升级到各自平台能拿到的较新版本，旧版本之间偶有协议不兼容。
- 电脑端根本是关机状态的话，先远程唤醒再连，见 [远程唤醒关机的电脑.md](远程唤醒关机的电脑.md)。
