## 一、被控端要先装对 App

电脑控制安卓手机时，你网盘里这份全功能客户端**不是**装在被控手机上的。被控端按使用场景二选一（两个也可以同时装）：

| 被控端 App | 连接方式 | 适合场景 |
| --- | --- | --- |
| QuickSupport | 输它显示的 ID，手机上点确认才能连 | 远程帮爸妈修手机、当场指导操作 |
| Host | 把设备分配到你的账号，无需确认直接连 | 自己的备用机、平板长期照看 |

区别一句话：QuickSupport 每次都要人在手机旁点「允许」，Host 是无人值守访问，但只允许被分配到的那个 TeamViewer 账号连入。

## 二、有人值守路线：装 QuickSupport

1. 在被控手机上安装 QuickSupport（Google Play 搜 TeamViewer QuickSupport，官方也提供直链 APK：`https://download.teamviewer.com/download/TeamViewerQS.apk`，以官网当时提供为准）。
2. 打开 App，同意协议后，屏幕上会显示一串 **ID**。
3. 电脑端 TeamViewer 在「伙伴 ID」里输入这串 ID，点连接。
4. 手机上会收到连接请求，点「允许访问」，再在系统弹窗里点「立即开始」允许录制屏幕。
5. 如果要远程操作（不只是看画面），手机上可能提示下载对应你手机品牌的**插件（AddOn）**，装完按提示开启辅助功能服务，见第四节。

## 三、无人值守路线：装 Host

1. 在被控手机上安装 TeamViewer Host，并允许它「显示在其他应用上层」。
2. 在 Host 里登录你的 TeamViewer 账号，给设备起个别名，点「分配」——设备就进了你账号的设备列表。
3. 之后从电脑（或另一台登录同账号的手机）的设备列表里点连接，不再需要手机端确认。
4. 如果连接时手机仍然弹确认框，说明**这台机型不支持无人值守访问**，退回 QuickSupport 路线即可。

Host 只认账号：通过 ID 直连、服务台通道都连不进 Host 设备，这是官方设计而不是故障。

## 四、插件（AddOn）是怎么回事

安卓各厂商系统差异大，TeamViewer 控制安卓屏幕需要每个品牌一个专门的插件：

- 有专用插件的品牌：连接时 App 会自己提示下载安装，装完去**设置 → 辅助功能（无障碍）**里启用对应插件服务。
- 没有专用插件的品牌：用 **Universal add-on（通用插件）**兜底，仅支持 Android 7 及以上且配合 QuickSupport 使用；官方直链为 `https://download.teamviewer.com/mobile/addon/TeamViewerAddon-Universal.apk`（以官方页面当时提供为准）。
- 都装不了或机型不在支持列表里时，连接会提示「此设备仅支持屏幕共享」——你能看到画面，但点不动。

插件装完没生效时，最常见的原因就是辅助功能服务没开或被系统自动关掉了，回设置里再开一次即可。怎么判断你的机型有没有插件、通用插件怎么装、无人值守的机型门槛，单独整理在 [哪些手机能被远程控制.md](哪些手机能被远程控制.md) 一篇里；其他连不上的情况统一看 [连接超时与常见报错排查.md](连接超时与常见报错排查.md)。

## 五、连上之后电脑端能做什么

从电脑连安卓手机（装 QuickSupport 或 Host）时，除了远程控制本身，官方知识库列出的可用功能包括：

- **设备信息面板**：查看对方手机的 CPU、内存、电池（含温度）、存储、系统版本、分辨率等。
- **文件传输**：电脑和手机之间互发文件。
- **聊天与剪贴板**：两边打字沟通；电脑上复制一段文字能推进手机的剪贴板。
- **截图**：向手机发起截图请求。
- **提醒（Nudge）**：让手机端弹出提示吸引注意。

## 六、个人用户的 5 分钟限制

按官方知识库口径，**免费个人用户连接移动设备时，每次连接最长 5 分钟**，到点自动断开，需要时重新连一次即可。两条经验：

- 断开是正常现象，不是被风控，直接重连就行。
- 如果你是从手机连手机（两端都是移动设备），同样受这个限制，而且这类会话只有纯远程控制，不支持文件传输和设备面板；条件允许时改从电脑发起连接。

频繁遇到「连接超时」这类报错则属于另一回事，是疑似商业用途判定，处理方式见 [免费个人用途与商业用途判定.md](免费个人用途与商业用途判定.md)。
