## 一、前提：电脑端先准备好

手机只是控制端，真正要被控制的那台电脑上也得运行 TeamViewer：

1. 在电脑上装 Windows / macOS 版 TeamViewer（官网 [www.teamviewer.com/cn/download/windows/](https://www.teamviewer.com/cn/download/windows/)）。
2. 打开后主界面会显示两组东西：**您的 ID**（一串数字）和**密码**。密码每次重启应用会变。
3. 如果你经常要连这台电脑，可以在电脑端设置里给它设一个固定的个人密码（以你所装版本的「选项 → 安全性」界面为准），省得每次去抄临时密码。

电脑端保持运行、别锁屏休眠到断网，手机这边才能连上。电脑已经被关机或睡眠了？可以用 Wake-on-LAN 先远程唤醒，见 [远程唤醒关机的电脑.md](远程唤醒关机的电脑.md)。

## 二、方式一：输 ID 和密码直连（不用账号）

适合临时帮别人、或者不想注册账号的情况：

1. 手机上打开 TeamViewer，切到底部的「连接」选项卡。
2. 在「伙伴 ID」里输入电脑上显示的那串数字 ID。
3. 点「远程控制」。
4. 弹出验证框时输入电脑上显示的密码（或你设好的固定个人密码），确认后开始连接。

连接速度取决于两端网络，首次连接电脑端可能还会弹一个确认框，点允许即可。

## 三、方式二：登录账号从设备列表连（适合长期用）

1. 在 App 底部切到「计算机」选项卡，用你的 TeamViewer 账号登录（没有账号就在登录页免费注册一个）。
2. 电脑端也登录同一个账号，并把这台电脑添加进你的设备列表。
3. 之后手机上的「计算机」页会直接列出这台电脑，点设备旁的双箭头图标就能发起连接，不用再手输 ID 和密码。

两种方式怎么选：偶尔帮一次用方式一最省事；自己的电脑要天天连，用方式二，设备列表还能看到对方在不在线。

## 四、连上之后的常用操作

- **操作方式**：手指点按就是单击，拖动指针、滚轮等手势以连接后 App 内的工具提示为准——不同版本略有差异。
- **调出键盘**：连接界面底部有键盘按钮，点开可以打字输入到远程电脑。
- **切换显示器**：电脑接着多台显示器时，会话工具栏里可以选择看哪一块屏幕，也能切换显示模式。
- **聊天**：工具栏里有聊天入口，可以和电脑前的人打字沟通。
- **传输文件**：会话里可以切换到文件传输模式，在手机和电脑之间互传文件；小文件（文档、图片）走这个通道比较方便，大文件还是建议走网盘或数据线。

## 五、画面卡了怎么调

远程桌面卡顿多半是网络带宽跟不上画质，按下面的顺序调：

1. **画质选项**：会话的设置里有「自动选择 / 优化速度 / 优化画质」三档——优化速度会让画面变糙但跟手，优化画质则相反；网络差时选优化速度，看文字、写代码这类场景损失不大。选项位置在不同版本里不完全一样，以你会话界面上实际显示的为准。
2. **降低远程分辨率**：把被控电脑的显示分辨率调低一档，画面数据量直接变小，手机上观感几乎不受影响。
3. **换网络**：手机从 Wi-Fi 切到流量（或反过来）对比一下；公共 Wi-Fi 拥堵时远不如 4G/5G 稳。
4. **关掉对方屏幕上「费带宽」的东西**：视频播放、动态壁纸、高帧率游戏都会占满会话带宽。

调完还是卡，先测两端各自的网速，再考虑是不是被控电脑本身负载高。

## 六、连不上时先查什么

- 电脑端 TeamViewer 是否在运行、ID 是否抄对（ID 是固定的一串数字，密码才是会变的那个）。
- 密码报错的话，确认用的是**屏幕上当前显示**的那个密码。
- 免费个人用途在连接频率、连接对象上有官方判定口径，触发限制会直接报「连接超时」，这类报错的处理在 [免费个人用途与商业用途判定.md](免费个人用途与商业用途判定.md)。
- 其余报错对照表见 [连接超时与常见报错排查.md](连接超时与常见报错排查.md)。
