# TeamViewer 远程唤醒关机的电脑

> 电脑已经关机或睡眠，手机这边连不上？本篇讲怎么用 Wake-on-LAN（WoL）先把电脑叫醒再连，包括硬件设置、TeamViewer 端配置和两种唤醒方式的取舍。

## 一、Wake-on-LAN 能做什么

电脑处于睡眠、休眠甚至软关机状态时，网卡仍带电待命，收到特定的「魔术包」网络信号就会开机。TeamViewer 内置了这个功能，你可以在手机上的 TeamViewer App 里向家里的电脑发起唤醒，等它开起来后再按 [手机控制电脑的连接步骤.md](手机控制电脑的连接步骤.md) 正常连接。

官方知识库列出的前提条件：

- 电脑接通电源；
- 网卡支持 WoL（绝大多数台式机和多数笔记本都支持）；
- **用网线联网**——很多无线网卡不支持 WoL，这是最常见的翻车点；
- 操作系统侧按第三节做好设置。

## 二、两种唤醒方式怎么选

| 方式 | 原理 | 适合谁 |
| --- | --- | --- |
| 经局域网内另一台电脑中转 | 一台常开的电脑（如家里的小主机、NAS）代为转发唤醒信号 | 家里有第二台常开设备，配置最省事 |
| 经公网地址直发 | 直接向电脑的公网 IP / 域名发魔术包 | 有固定公网 IP 或给路由器配了动态域名（DDNS），且路由器支持端口转发 |

判断口诀：家里有常开的第二台设备就走中转；没有、但有公网地址就走公网；两者都没有的话，WoL 配不起来，换个思路——别把电脑彻底关机，改用「睡眠 + 按需唤醒」或让它常驻。

## 三、先把电脑端的硬件与系统条件打开（Windows）

1. **BIOS 里启用 WoL**：开机按 F2（或对应按键）进 BIOS，在 Power（电源）选项卡里打开 Wake-on-LAN，保存退出。不同主板叫法可能是「Power On by PCI-E」「网络唤醒」等。
2. **网卡属性**：设备管理器 → 网络适配器 → 右键网卡 → 属性：
   - 「电源管理」选项卡勾选**允许此设备唤醒计算机**（有的驱动还多一项「只允许魔术包唤醒」，一并勾上）；
   - 「高级」选项卡里若有 Wake on Magic Packet / Wake-on-LAN 之类条目，设为启用。
3. **关闭快速启动**：控制面板 → 电源选项 → 「选择电源按钮的功能」→ 更改当前不可用的设置 → 取消勾选「启用快速启动」。快速启动会让部分机器收不到唤醒包，官方手册明确要求关掉。

macOS 的话：系统设置 → 节能（电池/电源适配器）→ 勾选「唤醒以供 Wi-Fi 网络访问」。注意官方口径的差别——**Mac 完全关机状态无法被唤醒，只能从睡眠唤醒**；Windows 和 Linux 在硬件支持时，睡眠、休眠、软关机都能被唤醒。

## 四、TeamViewer 端怎么配

1. 被唤醒的电脑上装好 TeamViewer，并把它**分配（Assign）到你的 TeamViewer 账号**。
2. 在该电脑的 TeamViewer 设置里找到网络类目下的 **Wake-on-LAN**：
   - 选「局域网内的其他 TeamViewer」→ 填中转电脑的 TeamViewer ID 并添加；
   - 或选「公共地址」→ 填这台电脑的公网地址（配了 DDNS 就填域名）。
3. 手机发起唤醒：登录同一账号，在你的设备列表里找到这台电脑，用唤醒入口发起（入口名称与位置以 App 内实际显示为准）。唤醒成功后设备会从离线变在线，再正常连接即可。

## 五、授权范围要先看清

官方知识库把 Wake-on-LAN 这篇说明标注为适用于 Remote Access、Business、Premium、Corporate、Tensor 等授权用户；免费个人用户的版本里这个功能入口不一定可用。所以动手配置前，先在你的 TeamViewer 设置里确认有 Wake-on-LAN 这一栏——没有的话就不用折腾第三节了，省下的时间直接改成「电脑不关机、只睡眠」更实际。

## 六、唤醒失败逐项排查

- 电脑是不是**插着网线**——无线唤醒大部分硬件不支持；
- BIOS 的 WoL 开关是否真的保存生效；
- 网卡「电源管理」勾选是否还在（部分驱动更新后会被重置）；
- Windows 快速启动是否已关闭；
- 中转方式下，中转电脑是否常开、TeamViewer 是否随系统自启；
- 公网方式下，路由器端口转发规则是否指向这台电脑，公网 IP 是否变了。

逐项都对还醒不了，先回到电脑旁本地测试一遍网卡魔术包唤醒，把 TeamViewer 因素摘出去再定位；连接环节的问题则回到 [连接超时与常见报错排查.md](连接超时与常见报错排查.md) 处理。
