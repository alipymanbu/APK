> 本篇整理官方对「免费个人用途」的界定口径：什么算商业用途、被标记后会出现什么现象、以及被误判后怎么通过官方表单申诉重置。

## 一、什么算个人用途（免费）

按官方口径，以下情况免费使用没有问题：

- 在**你自己的设备之间**建立连接（手机控自己的电脑、电脑看自己的平板）。
- **帮助家人和朋友**，且不因此获得任何报酬。

## 二、什么算商业用途（要许可证）

官方知识库把「直接或间接收费的用途」都算作商业用途，明确列出的情形包括：

- 给**客户或同事**提供支持——哪怕对方是你认识的熟人；
- **居家办公**连公司电脑——官方明确「即使人在家也算」；
- 在组织内部用于工作目的，或任何产生收入的活动（监控业务设备、维护客户机器等）。

判断口径可以概括成一句话：只要连接行为和工作、报酬沾边，就不在免费范围内。这与软件装在哪台设备上无关，与你**用它干什么**有关。

## 三、被判定后会出现什么

- 弹出「**检测到商业用途**」提示，或反复出现「**连接超时**」（官方确认这个报错同样与疑似商业用途有关，不是软件故障）。
- 标记可以落在 **TeamViewer ID** 上，也可以落在**账号**上，两者独立。
- **卸载重装没用**：官方明确说明，嫌疑只有通过官方申诉流程解除，卸载软件不会清除 ID 上的标记。

## 四、被误判了怎么申诉重置

官方提供专门的重置表单，流程如下：

1. 打开 [teamviewer.com/reset](https://teamviewer.com/reset)，点开始按钮。
2. 填姓名、你的 TeamViewer 账号邮箱，并简要说明你是怎么使用 TeamViewer 的。
3. 填入**所有涉及的 TeamViewer ID**——包括你自己的 ID 和你连接的设备的 ID。官方提示每个表单最多提交 10 个 ID，务必两边都填。
4. 勾选隐私政策后提交。官方承诺 72 小时内审核并邮件回复。

申诉结果有两种：确认是个人用途会重置 ID；仍疑似商业用途时会让你补交一份个人用途声明（按官方要求用**英文**填写）。补充几个实测要点：

- 审核量大时可能要一周左右，期间记得翻垃圾邮件文件夹。
- 解锁只对**提交过的 ID** 生效，对账号无效——所以涉及的所有 ID 都要报。
- 同一个 ID 不要重复申诉，重复提交会按最新时间重新排队。
- 表单入口：[teamviewer.com/reset](https://teamviewer.com/reset)（中文说明页见官方「TeamViewer ID 个人用户被判断为商业用途解决方法」页面）。

## 五、怎么降低被误判的概率

- 保持用途与第一节一致：只连自己和家人的设备。
- 长期固定用一个账号、连固定的几台设备，避免账号与大量陌生 ID 频繁互连。
- 工作需求（连公司电脑、帮同事装机）老老实实走商业授权，免费版被限制是按协议执行的，反复申诉也不会放行这类用途。

被标记期间连接会一直失败，别急着重装系统或换号——先走第四节申诉，报错本身的现象与区分方法见 [连接超时与常见报错排查.md](连接超时与常见报错排查.md)。
