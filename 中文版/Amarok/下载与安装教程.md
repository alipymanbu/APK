## 一、安装包基本信息

先对一下参数，确认你拿到的是这份包（数值以安装包本身为准；官方后来还在更新，商店或 GitHub 上的版本号比这新是正常的）：

| 项目 | 数值 |
| --- | --- |
| 应用名称 | Amarok |
| 版本 | 0.9.2 |
| 包名 | `deltazero.amarok` |
| 安装包大小 | 6.19M |
| MD5 | `A54D62AD9E1101ED730BADBF427E223A` |
| 系统要求 | 安装包标注需 Android 5.2 以上 |
| 开发者 | deltazefiro |
| 开源协议 | Apache-2.0 |

几条要提醒的：

- 0.9.2 不是官方最新版。官方仓库 [github.com/deltazefiro/Amarok-Hider](https://github.com/deltazefiro/Amarok-Hider) 后续又发了 0.10.x，加了桌面小组件、深色主题等（差异见[常见问题与解决方法.md](常见问题与解决方法.md)里的版本对照）。核心的文件与应用隐藏功能 0.9.2 都有。
- 这份包走的是侧载安装，不走应用商店，过程中不用注册登录任何账号。
- 官方还有一条 F-Droid 分发渠道，包名是 `deltazero.amarok.foss`，与 GitHub 等渠道的包**签名不同、不能互相覆盖升级**。如果你之前从 F-Droid 装过，直接装这份包会失败，得先卸载旧的（见第四节）。

## 二、获取安装包

从 [Amarok 安装文件资源（夸克网盘）](https://pan.quark.cn/s/3fe5276d0e12)转存到自己账号后下载即可。想确认文件没被改坏，可以核对 MD5：手机上用带校验功能的文件管理器，或传到电脑上执行 `certutil -hashfile 文件名.apk MD5`，结果应与第一节表里的 MD5 一致。

## 三、安装步骤

1. 把 APK 放进手机存储（网盘 App 直接下载，或电脑传过去）。
2. 在文件管理器里点这个 APK。首次侧载时系统会提示「禁止安装未知来源应用」，按弹窗指引允许你的文件管理器「安装未知应用」权限（各品牌入口不同，一般在弹窗里点「设置」→ 打开开关 → 返回继续）。
3. 点「安装」，等进度走完。
4. 装完点「打开」进应用，或回桌面找图标。Amarok 不需要注册账号，打开就是主界面。

## 四、安装失败怎么办

按系统提示对号入座：

| 系统提示 | 原因 | 处理 |
| --- | --- | --- |
| 「应用未安装」，手机里已有 Amarok | 装过同包名但签名不同的版本（比如 F-Droid 渠道的 `-foss` 版） | 先卸载已有的那个再装。卸载前确认它当前没有处于「已隐藏」状态，否则文件和应用会留在隐藏态，处理办法见[隐藏文件的恢复与数据安全.md](隐藏文件的恢复与数据安全.md) |
| 「解析包时出现问题」 | 文件没下完整，或传输中被改坏 | 重新下载一次，再核对 MD5 |
| 提示系统版本过低 | 手机系统低于安装包要求 | 进「设置 → 关于手机」查「Android 版本」，与第一节表里的要求对 |
| 提示存储空间不足 | 剩余空间不够 | 清出至少几百 MB 再装 |

## 五、装完先做什么

别急着把整个相册藏进去。先把两件事弄明白：

1. 想隐藏**应用**，得先在「更多设置」里选好应用隐藏模式（免 Root 也能用，但要装辅助工具），选法和差别在[应用隐藏模式怎么选.md](应用隐藏模式怎么选.md)。
2. 隐藏状态下**不要卸载 Amarok**、也不要中途强杀它的后台——文件在隐藏态时表现为「损坏」，没有 Amarok 就没人帮你还原，具体原因和补救都在[隐藏文件的恢复与数据安全.md](隐藏文件的恢复与数据安全.md)。
