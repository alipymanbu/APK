# Dhizuku 激活失败的原因与处理

> 给 Amarok 配 Dhizuku 模式时，激活（把 Dhizuku 设为设备所有者）这一步最容易卡住：要么提示已有账号、要么提示已有用户。本篇把失败原因和处理办法列全。还没装 Dhizuku 的话，先看[应用隐藏模式怎么选.md](应用隐藏模式怎么选.md)里的模式对比。

## 一、先明白激活在要求什么

Dhizuku 的激活就是把 Dhizuku 设成系统里唯一的「设备所有者」（Device Owner）。系统硬性规定：设设备所有者时，**设备上不能存在任何账号，也不能存在其他用户**。所以大多数激活失败，不是 Dhizuku 坏了，而是这两样没清干净。

以下处理办法整理自 [Dhizuku 官方激活指南](https://github.com/iamr0s/Dhizuku/discussions/19)，以该页面为准。

## 二、失败提示：设备上已有账号

手机里各种登录过的应用（邮箱、云服务、第三方登录）都算账号。处理：

1. 先找出哪些应用带账号： Dhizuku 指南推荐用开源的 [Accounts 工具](https://github.com/iamr0s/AndroidAccounts/releases)列出全部账号。
2. 把带账号的应用**卸载**，或用 Hail 这类冻结工具（配合 Shizuku）暂时冻结——冻结不用卸载，激活完再解冻。
3. 全部清掉后重新执行激活。
4. **激活成功后，把冻结的应用解冻回来。** 官方特别提醒：冻结状态维持到重启，可能导致设备无法正常开机。

## 三、失败提示：设备上已有其他用户

应用分身、手机克隆、访客模式、隐私空间，都会被系统当成「其他用户」。处理（按省事程度排）：

1. **在设置里删除**：设置 → 多用户/特色功能里找到分身或访客空间，删除。各系统入口不同。
2. **用 ADB 删**：电脑连手机后 `pm list users` 列出所有用户（ID 0 是主空间，别动），对其他 ID 执行 `pm remove-user ID`。注意：分身空间里装的应用会随删除被卸载，里面有东西先备份。
3. **不删用户碰运气**：部分设备支持把设备所有者限定在主空间：

   ```bash
   adb shell dpm set-device-owner --user 0 com.rosan.dhizuku/.server.DhizukuDAReceiver
   ```

   这条命令是官方指南给出的备选，不保证在所有系统上成功。

## 四、失败提示：设备所有者已存在

以前给别的应用设过设备所有者（比如冰箱类工具），系统只认一个。处理按顺序试：

1. 强制停止 Dhizuku 后重新打开，有时它会识别出自己已是设备所有者。
2. 把现有设备所有者的权限转移给 Dhizuku（用原来那个应用自带的移交功能）。
3. 停用非 Dhizuku 的设备所有者应用，再重新激活。

## 五、特定品牌的坑

OPPO 系系统（含一加、真我部分机型）只允许白名单应用成为设备所有者，Dhizuku 默认签名不在名单里，可能怎么都激活不了。官方指南里虽有对应的处理办法，但操作门槛和风险都不低——你的机型属于这类的话，建议直接改走 Shizuku 模式（见[无线调试激活Shizuku的步骤.md](无线调试激活Shizuku的步骤.md)），效果同样能达到。

## 六、激活成功之后

回到 Amarok，「更多设置 → 应用隐藏模式」选 Dhizuku，弹出授权时允许。Dhizuku 模式重启不用重新激活，Amarok 的应用隐藏随用随点，不像 Shizuku 模式每次重启都要先去拉一下服务。

之前冻结过的账号应用记得解冻，再正常登录使用。
