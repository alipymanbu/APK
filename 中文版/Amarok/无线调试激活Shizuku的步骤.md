# 无线调试激活 Shizuku 的步骤

> Amarok 免 Root 隐藏应用走 Shizuku 模式时，得先把 Shizuku 激活。Android 11 及以上的手机可以用系统自带的「无线调试」完成激活，全程不用电脑。配不好或总失败，看[应用隐藏模式怎么选.md](应用隐藏模式怎么选.md)里有没有你那种模式问题，或直接翻本篇最后的排查表。
> **相关文档**：[应用隐藏模式怎么选.md](应用隐藏模式怎么选.md) · [Dhizuku激活失败的原因与处理.md](Dhizuku激活失败的原因与处理.md)

## 一、先确认你的手机能不能走这条路

| 条件 | 要求 |
| --- | --- |
| 系统版本 | Android 11 及以上（无线调试是系统功能，10 及以下没有） |
| Shizuku | 从 [Shizuku 官网](https://shizuku.rikka.app/download/)或官方渠道安装 |
| 网络 | 手机连着 Wi-Fi（配对过程在本地网络里完成） |

Android 10 及以下没有无线调试，只能连电脑用 ADB 激活；已 Root 的设备更简单，Shizuku 里点一下「通过 Root 启动」就行。

## 二、开启无线调试

1. 先打开「开发者选项」：设置 → 关于手机 → 连续点「版本号」7 次（各品牌入口略有差异，不确定就搜「你的机型 + 开发者选项」）。
2. 进开发者选项，打开「USB 调试」。
3. 在开发者选项里找到「无线调试」，打开开关。

## 三、配对（只需要做一次）

1. 打开 Shizuku，选择「通过无线调试启动」流程里的**配对**。
2. 手机的无线调试界面里，点「使用配对码配对设备」，屏幕会弹出一组配对码。
3. Shizuku 的常驻通知里会要你填配对码，把屏幕上那串数字填进去。
4. 提示配对成功即可。**配对记录会保留，以后重启不用重新配对。**

## 四、启动 Shizuku

配对成功后，在 Shizuku 里点「通过无线调试启动」，状态变成「运行中」就成了。这时回到 Amarok，在「更多设置 → 应用隐藏模式」里选 Shizuku 模式，弹出的授权提示点允许，就能勾应用开始隐藏了。

**每次重启手机后**，Shizuku 服务会被系统停掉——不用重新配对，只需再点一次「通过无线调试启动」，然后 Amarok 的应用隐藏就恢复可用。嫌麻烦的话，把「重启后先开 Shizuku」当成和「重启后连 Wi-Fi」一样的固定动作。

## 五、配不上或频繁掉线怎么排查

| 现象 | 处理 |
| --- | --- |
| Shizuku 一直显示「正在搜索配对服务」 | 把「无线调试」关掉再重新打开，重试配对 |
| 点「输入配对码」后立刻提示失败 | 同上；确认填码动作要快，配对码有时效，超时了就重新点「使用配对码配对设备」取新码 |
| 提示 adb 权限受限 | 重新走一遍配对流程 |
| Shizuku 运行一段时间后自己停了 | 多半被省电策略杀掉了：在系统设置里把 Shizuku 设为「不受电池优化限制」/允许后台运行（各品牌叫法不同） |
| 重启后 Amarok 隐藏应用报「Shizuku 服务不可用」 | 正常现象，先去 Shizuku 点一次「通过无线调试启动」再回 Amarok |

以上排查项整理自 [Shizuku 官方用户手册](https://shizuku.rikka.app/zh-hans/guide/setup/)，界面文案的确切叫法以你手机系统为准。
