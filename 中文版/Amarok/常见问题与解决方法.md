## 一、取消隐藏后桌面图标位置全乱了

这是机制决定的，不是故障。Amarok 靠「停用应用」来隐藏，在桌面（启动器）看来，停用≈卸载、恢复≈重装，图标只能按启动器的规则重新排。官方文档明确说除非去改桌面本身，否则无解——桌面种类太多，不可能都适配。

能做的缓解：把常一起用的应用收进桌面文件夹，乱位时范围小；或者记住图标排列截图，乱了照着摆回去。

## 二、隐藏了图片，某个应用里还能看到

那个应用自己缓存了缩略图。杀掉它的后台再打开，或直接重启手机。Amarok 隐藏后会自动刷新系统媒体缓存，但管不到各个应用「自己记住的那份」。

## 三、Amarok 和加密 App 怎么选

判断依据就一条：你要挡的是谁。

- 防家人、朋友、同事随手翻手机：隐藏类够了。文件名和签名被混淆后打不开也搜不到，恢复又是一键的事，日常没有等待。
- 防失窃、防刻意提取数据：隐藏类不行。文件内容原封不动躺在原处，官方文档自己都标注了「不是加密工具，别用来存高价值机密」。这类需求用加密方案，接受加解密的耗时。

两个思路也能混用：日常用 Amarok 隐藏，真正的机密单独加密。

## 四、0.9.2 和官方最新版差在哪

你手上这份 0.9.2 是官方 0.9 时期的稳定版，核心功能都在；官方后来持续迭代，下面是对照（以官方 [README](https://github.com/deltazefiro/Amarok-Hider) 与 [Releases](https://github.com/deltazefiro/Amarok-Hider/releases) 页面为准，引入版本未逐一考证的归入右列）：

| 0.9.2 已有 | 官方后续版本陆续加入 |
| --- | --- |
| 文件/应用一键隐藏与恢复（混淆方式，免 Root 可用） | 快捷开关反色选项（0.9.3 起） |
| 四种应用隐藏模式（Shizuku / Dhizuku / Root / DSM） | 桌面小组件、点通知直接隐藏的增强（0.10.0 起） |
| XHide：Root + Xposed 下彻底隐藏 | 从桌面彻底隐藏 Amarok 自己的图标、从最近任务隐藏（0.10.0 起） |
| 控制中心快捷开关、通知栏「隐藏」按钮 | 深色主题选择、紧急按钮自定义（0.10.1 起） |
| 在 Amarok 界面内阻止截屏、禁用隐藏时的 Toast 提示 | 伪装图标（如日历）、密码/指纹锁定等（以官方页面为准） |

版本差异带来的两个实际影响：

- **升级要认渠道**：GitHub/酷安等渠道的包与 F-Droid 的 `-foss` 包签名不同，不能互相覆盖升级。要升级先确认当初从哪装的。
- **0.9.2 缺少对 Root 工具的保护**：官方 0.9.3 才加「隐藏 Root 相关应用时警告」，0.10.1 起直接阻止隐藏 Root 管理器和 Shizuku/Dhizuku 这类权限工具。0.9.2 里这些全靠你自己留意——别把 Amarok 依赖的工具藏掉（见[怎么隐藏应用与文件.md](怎么隐藏应用与文件.md)第三节）。

## 五、其他零散问题

| 现象 | 说明 |
| --- | --- |
| 打开 Amarok 没反应或启动即闪退 | 用了 Dhizuku 模式的话，0.9.x 有已记录的崩溃案例，换 Shizuku 模式；其他情况先重启手机 |
| 隐藏按钮按了没效果 | 检查应用隐藏模式是否失效（重启后 Shizuku 要重新激活）；文件隐藏不依赖模式，若文件也藏不了，重新勾选路径再试 |
| Shizuku 配对不上、服务频繁掉线 | 配对步骤与省电策略的排查见[无线调试激活Shizuku的步骤.md](无线调试激活Shizuku的步骤.md) |
| 想一次全部恢复 | 主界面取消隐藏按钮就是干这个的；应用出不来时按[隐藏文件的恢复与数据安全.md](隐藏文件的恢复与数据安全.md)处理 |
| 担心数据安全 | 记住三件事：卸载前先取消隐藏、过程中别杀后台、重要数据另做备份，细节见[隐藏文件的恢复与数据安全.md](隐藏文件的恢复与数据安全.md) |
