# Amarok 应用隐藏模式怎么选

> Amarok 隐藏应用要先选一种「工作模式」，不同模式要求的权限和工具不同。本篇给你一张对照表加每种模式的激活步骤，照着选一个配好就能用。文件隐藏不用选模式，装完即用（Root 设备另有 chmod 方式可选）。

## 一、为什么文件能直接藏，应用要先选模式

文件隐藏只改文件本身，Amarok 自己就能做。应用隐藏靠「停用应用」实现，停用是系统级操作，Amarok 一个普通应用没这个权限，得借力：借 ADB 权限（Shizuku）、借设备所有者权限（Dhizuku）、借 Root，或借别的设备管理员应用（DSM）。所以先选模式，就是先决定「向谁借权限」。

模式切换入口：**更多设置 → 应用隐藏模式**。四种模式配一种即可。

## 二、四种模式对照

| 模式 | 需要什么 | 重启后 | 配置难度 | 备注 |
| --- | --- | --- | --- | --- |
| Shizuku | 装 Shizuku 并激活 | **要重新激活** | 简单 | 免 Root 首选的「快速方案」 |
| Dhizuku | 装 Dhizuku 并用电脑 ADB 激活 | 依然生效 | 复杂 | 激活时要登出设备上的所有账号 |
| Root | 设备已 Root | 依然生效 | 最简单 | 有 Root 就选它 |
| DSM | 装冰箱/小黑屋并以设备管理员激活 | 依然生效 | 复杂 | 官方已弃用，建议改用 Dhizuku |

官方文档给的选择建议：未 Root 用 **Dhizuku**（一劳永逸，但配置麻烦）或 **Shizuku**（几分钟配好，但每次重启要重新激活）；已 Root 直接 **Root** 模式。

另有 **XHide**：在 Root + LSPosed（Xposed 环境）下可用，把应用从系统菜单和其他应用的检测里也抹掉，比单纯停用更彻底。属于进阶玩法，普通需求用不到。

## 三、各模式激活步骤

### Root 模式

1. 确认设备已 Root。
2. 在「更多设置 → 应用隐藏模式」选 Root。
3. Root 管理器（如 Magisk）弹出授权提示时，允许 Amarok。

### Shizuku 模式

1. 安装 [Shizuku](https://shizuku.rikka.app/download/)。
2. 按 [Shizuku 官方设置指南](https://shizuku.rikka.app/guide/setup/)激活。Android 11 及以上可以全程在手机上用「无线调试」激活，不用电脑，逐条步骤见[无线调试激活Shizuku的步骤.md](无线调试激活Shizuku的步骤.md)。
3. 在 Amarok 里选 Shizuku 模式。
4. Shizuku 弹出授权提示时，允许 Amarok 使用。
5. **每次重启手机后，先重新激活 Shizuku**（配对只需一次，重启后要做的只是重新启动服务），再按隐藏按钮，否则应用隐藏会报「服务不可用」。

### Dhizuku 模式

1. 安装 [Dhizuku](https://github.com/iamr0s/Dhizuku/releases)。
2. 按其 [激活教程](https://github.com/iamr0s/Dhizuku/discussions/19)操作：需要一台装了 [ADB](https://www.xda-developers.com/install-adb-windows-macos-linux/) 的电脑，并且**先登出手机上的所有账号**。激活被账号、应用分身等挡住时的处理见[Dhizuku激活失败的原因与处理.md](Dhizuku激活失败的原因与处理.md)。
3. 在 Amarok 里选 Dhizuku 模式，弹出授权时允许。

注意：0.9.x 时期官方文档记录过 Dhizuku 模式下偶发启动崩溃的问题，新版已修复。你这份 0.9.2 用 Dhizuku 时如果遇到 Amarok 启动即闪退，换 Shizuku 模式绕开。

### DSM 模式（不建议新配）

需要装冰箱（IceBox）或小黑屋，并用**设备管理员（Device Owner）模式**激活它们，然后在 Amarok 里选 DSM 并授权。官方已停止维护这套依赖，且「必须设备管理员模式激活，其他方式激活不可用」——出错概率高，能不用就不用。

## 四、报错对照

| 报错 | 出在哪 | 处理 |
| --- | --- | --- |
| 无法获取 Root 权限 | Root 模式 | 确认设备已 Root；在 Root 管理器里检查是否给 Amarok 授了权 |
| Shizuku 版本过低 | Shizuku 模式 | 升级 Shizuku 到 v11 以上 |
| Shizuku 服务无效 | Shizuku 模式 | 设备上没装 Shizuku（或 Sui），装好再试 |
| Shizuku 服务不可用 / 未运行 | Shizuku 模式 | 重启手机后没重新激活 Shizuku，激活一次 |
| 隐藏应用失败：DSM 管理员未激活 | DSM 模式 | 冰箱/小黑屋没激活，或不是用设备管理员模式激活的 |
| DSM 服务不可用 | DSM 模式 | 没装冰箱/小黑屋，或版本过低 |

配好模式后回主界面勾选应用、按隐藏即可，操作细节在[怎么隐藏应用与文件.md](怎么隐藏应用与文件.md)。万一之后模式失效、应用藏在里面出不来，恢复方法在[隐藏文件的恢复与数据安全.md](隐藏文件的恢复与数据安全.md)。
