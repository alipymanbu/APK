## 一、免费版的实际边界

免费版能用的是**核心工具本身**：扫描、合并、拆分、压缩、常见格式转换、基础的标注与签名。日常一两次的活，免费额度一般够用。

边界集中在三处，具体数值官方会调整，以你操作时页面弹出的提示为准：

| 边界 | 表现 | 什么时候会撞上 |
| --- | --- | --- |
| 单个文件体积上限 | 超过上限的文件传不上去或处理到一半失败 | 几十页的扫描件、带大量图片的册子 |
| 单次任务数 / 频率限制 | 连着做几件事会被提示稍后再试或升级 | 一次要整理很多份文件时 |
| 部分工具不开放 | 点进去直接提示需要高级版 | 文字识别（OCR）、批处理这类较重的处理 |

具体数值各家工具并不一样。以文字识别为例，官方工具页上标注的是免费档 15 MB、付费档到 4 GB（截至 2026-09，**以你打开工具时页面显示的数值为准**）。

另外免费使用过程中界面里会有广告位，这属于官方的免费模式，不影响功能。

## 二、高级版多出哪些

以下按官方公开说明整理，具体权益项以官方定价页当时显示为准：

| 权益 | 说明 |
| --- | --- |
| 解除体积与任务数限制 | 单个文件能到更大，连续处理不再被拦 |
| 批处理 | 一次对多份文件做同一件事，不用一份份点 |
| 文字识别（OCR） | 扫描件变可搜索文字，也能直接转成 Office 文档 |
| 多端使用 | 网页、手机、桌面三端的高级权益都打开，桌面版可离线处理 |
| 更完整的编辑能力 | 批量编辑、更精细的页面与图片处理 |
| 更清爽的工具页面 | 工具页里的广告位不再显示 |

桌面版能在本机离线处理文件，这一点对不方便把文件上传的场景有用，而且官方说明它不设文件数量与体积上限；手机端本身是在线处理，没有离线这一说。三端各自多出什么能力，见 [手机版和电脑版有什么区别.md](手机版和电脑版有什么区别.md)。

## 三、在手机 App 里怎么订阅

1. 打开 App，进「设置 → 账号」或直接点界面上的升级入口；
2. 选择按月或按年（按年通常折算下来更便宜，具体差价看页面）；
3. 付款由应用商店完成——Android 走 Google Play 的结算，会从你绑定的支付方式扣款；
4. 订阅成功后，同一账号下权益立刻生效，不用重启 App。

**价格会变，以你付款页面上显示的数字为准**，本文不列具体金额。看到「首月优惠」这类活动时，注意读清楚优惠期结束后的价格。

## 四、怎么取消自动续费

订阅默认是**自动续费**的，取消要到你付款的那个商店里操作，不是在 App 里删掉账号：

- **Android（Google Play）**：打开 Google Play → 点右上角头像 → 付款和订阅 → 订阅 → 找到 iLovePDF → 取消订阅。取消后当期剩余时间仍可用，到期不再扣款。
- **如果当初在官方网页端付款**：到官网的账号设置里管理套餐与账单。

取消后如果 App 里还显示高级版权益，属于缓存的旧状态，下拉刷新或重新登录一次即可看到变化。

## 五、订阅在哪些端生效

高级版权限**跟着账号走**：手机上订阅成功，用同一个账号登录官方网页端、桌面端，权益同样生效，不需要重复购买。

两点例外要记住：

- **换账号就没了**：权益绑定的是付款时用的那个账号，换邮箱注册的新账号是空的。
- **家人共享不一定覆盖**：能否通过应用商店的家庭共享让其他账号共享这份订阅，取决于商店自己的规则，别默认它一定生效。

## 六、不想付费时的几条路

| 情形 | 可行做法 |
| --- | --- |
| 只是文件太大 | 先用压缩工具把体积压到限额以内，再处理；压到什么程度见 [合并拆分与压缩怎么用.md](合并拆分与压缩怎么用.md) |
| 要一次处理很多份 | 拆成几次做，间隔一段时间；单次限制是防滥用的，隔一会儿会恢复 |
| 需要文字识别 | 只对必须要用到文字的那几页做，减少处理量；或者先在本机上把扫描件拍清楚、拍整齐，提高一次成功的概率 |
| 只是想试高级功能 | 官方时常有短期试用，入口在升级页面上；试用同样默认自动续费，不打算续就提前按第四节取消 |

## 七、别买错的两件事

- **不要为了「更大的文件」买完发现处理不了的其实是格式问题**。有些文件在免费版处理失败不是因为体积，而是原文件本身损坏或加密，这种情况付费也解决不了，先照 [常见问题与排查.md](常见问题与排查.md) 排查一遍再决定要不要付费。
- **不要在多个账号上各买一份**。先确认自己手机里登录的是哪个账号，再决定在哪付款，重复订阅要分别去各自的商店退款，流程很麻烦。
