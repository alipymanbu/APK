## 一、装不上、打开就退

手机上用 iLovePDF 遇到的问题集中在几类：装不上、处理卡住、转换结果不对、扫描件发灰、生成的文件找不到。本篇按现象分类给出原因与处理办法，并附一张官方失败原因对照表——照着查，大多数问题不用找人问。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 「解析软件包时出现问题」 | 安装包没下完或已损坏 | 删掉重下；下完按 [下载与安装教程.md](下载与安装教程.md) 第二节对一遍 MD5 |
| 「应用未安装」 | 手机上已有同包名的其他版本，或版本比现有更旧 | 先在设置里卸载旧版本，再安装这一份 |
| 「您的设备与此版本不兼容」 | 系统版本低于应用要求（官方要求 Android 8.0 及以上） | 确认系统版本；确实过低就只能换设备或用官方网页版 |
| 点安装没反应、一直在转 | 系统在后台校验安装包 | 等 1~2 分钟；仍无反应就重启手机再试一次 |
| 打开后立刻回到桌面 | 权限没给，或系统省电策略把进程杀了 | 到设置里给相机、存储权限；把 App 加进「电池不受限制」名单 |
| 装完桌面没有图标 | 启动器缓存没刷新 | 回桌面下拉一次，或在应用列表里搜索「iLovePDF」 |

## 二、文件处理不动

| 现象 | 先查什么 | 处理 |
| --- | --- | --- |
| 一直卡在「处理中」 | 网络是否稳定 | 换 Wi-Fi 或流量重试；大文件在弱网下会卡很久 |
| 提示文件过大 | 文件兆数 | 先压缩再处理，档位选择见 [合并拆分与压缩怎么用.md](合并拆分与压缩怎么用.md) |
| 提示任务次数用尽 | 是不是连着做了好几件事 | 间隔一段时间再试；额度规则见 [免费版和高级版有什么区别.md](免费版和高级版有什么区别.md) |
| 提示需要登录或升级 | 该工具是否要求账号或更高档位 | 文字识别（OCR）、批处理这类较重处理会要求登录账号；官方工具页对 OCR 另标了免费体积上限，见 [扫描件文字识别怎么用与识别不准怎么办.md](扫描件文字识别怎么用与识别不准怎么办.md) |
| 上传到一半失败 | 文件是不是带密码 | 带打开密码的 PDF 通常处理不了，先用你已知的密码在本地解除保护 |
| 提示文件损坏 | 原文件本身 | 换一份能正常打开的副本再试；损坏的文件一般工具都处理不了 |

## 三、转换结果不对

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 转出来还是一堆图片 | 原件是扫描件，文字只是像素 | 先做 OCR 文字识别，再转，顺序见 [PDF转Word与图片格式怎么转.md](PDF转Word与图片格式怎么转.md)；识别本身的问题见 [扫描件文字识别怎么用与识别不准怎么办.md](扫描件文字识别怎么用与识别不准怎么办.md) |
| 表格线没了、列全并在一起 | PDF 里的表格是画出来的线条 | 属于解析限制，需在表格软件里手工重建列结构 |
| 中文变乱码、变方框 | 字体映射问题 | 换方向试：先转成 JPG 拿到图片，再重新做 PDF |
| 页码、页眉位置跑了 | 复杂版式在重建时对不齐 | 简单文档概率低；复杂排版难以完全还原，能接受就继续用 |
| 出来的 PDF 比原件大很多 | 转换过程中图片被重新编码 | 用压缩工具压一份再存档 |

## 四、扫描件不清晰

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 字发灰、看不清 | 拍摄时光线不足或反光 | 靠窗自然光或侧向台灯，不开闪光灯直射；详细对照表见 [手机扫描纸质文件转PDF.md](手机扫描纸质文件转PDF.md) |
| 边缘被裁掉 | 纸角出框 | 重拍，四周留出桌面 |
| 背景是花的、有阴影 | 手挡住了光源 | 调整站位，让光源在侧面 |
| 自动识别框不到纸 | 白纸放在浅色桌面上 | 换深色桌面，或手动调整裁剪框 |
| 页数顺序乱了 | 拍摄顺序 | 在缩略图里拖动调整，不用重拍 |

## 五、找不到文件

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 处理完在相册里找不到 | 结果存在 App 自己的文件区，不写进系统相册 | 打开 App 底部的「文件」页签，「本机文件」里就是刚生成的那几份 |
| 存进了云盘，但在电脑上看不到 | 云端同步有延迟 | 在云盘网页端刷新一次 |
| 之前能打开的分享链接失效了 | 在线处理生成的是临时链接，会过期 | 要长期分享，用云盘自身的分享功能重新生成 |
| 换了手机，文件全没了 | 存在本机文件区、没上传云盘 | 本机文件不跟着账号走；换机前先导出或存云盘 |

## 六、账号与云盘

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 注册后收不到确认邮件 | 邮件延迟或被归入垃圾邮件 | 查垃圾邮件夹；官方说明 30 分钟后仍没有可联系支持 |
| 云盘授权页打不开、一直转圈 | 网络环境访问不到该云盘 | 换网络重试；企业账号被管理员限制的，需找 IT 开通 |
| 忘了密码、又记不清注册邮箱 | 账号按邮箱绑定 | 先用「忘记密码」在常用邮箱里找；实在找不到只能重新注册 |
| 提示已有同邮箱账号 | 之前注册过 | 直接用那个邮箱登录或重设密码，别重复注册 |
| 换了账号，高级版权益没了 | 权益绑定原付款账号 | 登录回原账号；订阅管理见 [免费版和高级版有什么区别.md](免费版和高级版有什么区别.md) |

## 七、官方给出的失败原因，对到你的文件上

处理失败时页面会给出一个原因，官方把这些原因分成了固定的几类。看懂它就不用乱试：

| 官方原因 | 实际含义 | 你这边能做什么 |
| --- | --- | --- |
| 文件损坏 / 无法读取 | 文件本身有问题 | 先用阅读器打开确认能不能看；能看就另存一份再传，不能看就找回原件 |
| 文件为空 | 传了个 0 字节或没内容的文件 | 回文件管理器看大小，重新导出 |
| PDF 里没有文字 | 纯图片型 PDF 跑了依赖文字的操作（比如转 Word） | 先做文字识别，见 [扫描件文字识别怎么用与识别不准怎么办.md](扫描件文字识别怎么用与识别不准怎么办.md) |
| PDF 里没有表格 / 没有图片 | 你要提取的东西原件里确实不存在 | 换工具，别在这个方向上耗 |
| 密码错误 | 文件带打开密码，且没提供或给错 | 用你知道的密码先在本机解开保护再处理 |
| 处理时间过长 | 文件大、页数多，或服务器当时很忙 | 压小体积、拆成几份分开做，或换个时段 |
| 服务器繁忙 / 不可用 | 官方侧的临时状况 | 等几分钟重试；连续失败就是对方在忙，不用改文件 |
| 连接或浏览器问题 | 传输中断 | 换网络重试；手机端换 Wi-Fi 与流量各试一次 |
| 额度不足 | 免费额度用完 | 隔一段时间再做，或按 [免费版和高级版有什么区别.md](免费版和高级版有什么区别.md) 的路径处理 |
| 文件已修复 | 原文件有问题但被工具修好了 | 直接下载修复后的版本用，不用再处理一次 |
| 无法转 PDF/A | 文件里有不符合长期存档标准的内容 | 属于格式限制，换个存档方式或保留原样 |
| URL 找不到 / 服务器已过期 | 用网页转 PDF 时地址失效，或临时链接过期 | 换成能正常打开的新地址；过期链接重新生成 |

## 八、两个高频误解

- **「装了 App 就能离线用」**：手机端的处理是在线完成的，要联网。能离线处理的是官方桌面版，两者不是一回事，三端的能力差异见 [手机版和电脑版有什么区别.md](手机版和电脑版有什么区别.md)。
- **「移除 PDF 密码」这个工具该用在哪**：它的用途是处理**你自己**设置过密码、并且你知道密码的文档（例如自己加密后想另存一份不带密码的副本）。它不能用来打开你不知道密码的文件；不属于你的文件，请先取得原作者授权后再处理。

## 九、还是解决不了怎么办

按这个顺序往上找：

1. 先确认是最新版本——旧版本的问题常常已经在新版本修掉，本文对应的版本号见 [下载与安装教程.md](下载与安装教程.md) 第一节；
2. 到官方帮助中心翻对应工具的使用说明与常见问题；
3. 官方没覆盖的，通过官方联系入口提交问题，附上你的手机型号、系统版本、出问题的文件类型和具体提示文字，比只说「用不了」有效得多。
