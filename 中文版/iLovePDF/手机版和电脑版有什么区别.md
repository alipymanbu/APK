## 一、先分清这是三个端，不是一个的三种皮肤

平时说的「电脑版」其实包含两个不同的东西：打开浏览器就能用的**网页端**，和装在 Windows / macOS 上的**桌面端**。加上手机 App，一共三套入口，功能并不完全重合。后文统一用「手机端 / 网页端 / 桌面端」来指这三者。

| | 手机端（App） | 网页端 | 桌面端 |
| --- | --- | --- | --- |
| 怎么打开 | 装 App | 浏览器访问官网 | 装 Windows / macOS 应用 |
| 处理位置 | 官方服务器上 | 官方服务器上 | 你自己的电脑上 |
| 要不要联网 | 要 | 要 | 不要（可离线） |
| 文件体积与数量 | 受免费额度限制 | 受免费额度限制 | 官方说明不设数量与体积上限 |
| 适合 | 扫描、随手转换 | 临时用一次、不想装东西 | 大批量、敏感文件 |

## 二、网页端多出来的

- **HTML 转 PDF**：把网页地址转成 PDF，这个工具网页端才有。
- **签名请求与签署跟踪**：不只是你自己签，还能发给别人签、查看签到哪里了。
- **账号与账单管理**：套餐、发票、企业信息都在网页端看。
- **串联任务**：处理完一份文件可以顺手接着跑下一个工具，不用重新上传。
- **团队工作区**：企业向的多人协作、角色分配、统一计费。

## 三、桌面端多出来的

桌面端的核心差别是**在本机处理**：官方说明它支持离线处理大部分工具，文件不用上传，也不设文件数量与体积上限。此外还有几项手机与网页端没有的：

| 能力 | 有什么用 |
| --- | --- |
| 离线处理 | 网络差、或文件不方便上传时可用 |
| 不设数量与体积上限 | 一次处理几十份、单个几百兆都不必拆 |
| 输出目录设置 | 固定保存位置，找结果不用翻 |
| 默认密码设置 | 批量给输出文件加密码、或自动处理带密码的文件 |
| PDF/A 合规检查 | 归档前确认文件符合长期存档标准 |
| 元数据编辑 | 改作者、关键词、创建者这类文档属性 |
| 右键菜单转换 | 在文件管理器里直接对着 PDF 右键处理 |

## 四、手机端多出来的

- **扫描仪**：把手机变成扫描仪，多页合成一份 PDF，这是手机端最不可替代的一项，操作见 [手机扫描纸质文件转PDF.md](手机扫描纸质文件转PDF.md)。
- **云存储直连**：官方博客明确推荐用手机端接云盘处理文件，好处是不必先把大文件整份下载到手机再上传，能省移动流量，接入方法见 [文件管理与云盘对接.md](文件管理与云盘对接.md)。
- **从模板创建 PDF**：用简历、发票这类模板或空白页直接做一份 PDF，不用先有文件再转换。

## 五、账号权益怎么算

高级版是按账号生效的：在手机端订阅成功，用同一个账号登录网页端、桌面端，权益同样打开，不需要重复购买。反过来也成立。这一点的细节与取消续费的路径见 [免费版和高级版有什么区别.md](免费版和高级版有什么区别.md)。

两处例外值得记住：

- **手机上保存在 App 文件区、没有上传到云端的文件**，不会自动出现在电脑上——三端之间传文件要靠云盘或手动导出；
- **桌面端的「不设上限」是本机处理的特性**，不是买了会员就让网页端也变成无限。

## 六、什么活该换到哪一端做

| 你要做的事 | 用哪端 | 原因 |
| --- | --- | --- |
| 拍纸质合同、发票、证件 | 手机端 | 相机就在手边，扫完能直接接着处理 |
| 把网页存档成 PDF | 网页端 | HTML 转 PDF 是网页端独有的工具 |
| 一次整理几十份文件 | 桌面端 | 免上传、不限数量、批量更省事 |
| 单个文件几百兆 | 桌面端 | 免上传，不受在线额度限制 |
| 不方便外传的内部资料 | 桌面端 | 在本机处理，文件不离开你的电脑 |
| 请同事或客户签字 | 网页端 | 签名请求与签署跟踪在网页端 |
| 临时用一次、不想装任何东西 | 网页端 | 打开浏览器就能用 |

## 七、文件在三端之间怎么流转

最省事的路径是**让云盘当中间站**：手机端拍的、改的，存进你已接入的云盘；电脑上打开同一个云盘账号就能接着做。手机端自己文件区里的文件，要靠导出或分享功能才能离开手机。

需要「手机扫、电脑继续改」这条链路时，用云盘比用聊天软件传更稳——聊天软件会压缩、还会把文件名改掉。

## 八、价格上的差别

三端共用同一个订阅，但官方在不同入口展示的价格会不一样。官方桌面版页面（截至 2026-09）显示的是按月与按年两档，按年折算更便宜；手机端则按应用商店的内购价显示。**具体金额以你当下付款页面上显示的数字为准**，别拿一端看到的价格去对另一端的账单。

需要多端同时用，直接在任意一端订阅同一个账号即可，不必分开买。各档权益的边界见 [免费版和高级版有什么区别.md](免费版和高级版有什么区别.md)。
