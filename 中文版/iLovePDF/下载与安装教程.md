## 一、先对上这张表

iLovePDF 是一套围绕 PDF 的工具集合，官方同时提供网页端、桌面端和手机 App。这套文档讲的是 **Android 手机 App**：扫描纸质文件、转换格式、合并拆分、加注释、签名，都能在手机上直接做完，不必把文件倒到电脑。三端的能力差异与选择见 [手机版和电脑版有什么区别.md](手机版和电脑版有什么区别.md)。

安装本身不难，容易踩的是**拿到不对的包**——同一个应用在网上有多个来源，版本号、体积、甚至包名都不一样。先核事实。

| 应用名称 | iLovePDF |
| 开发者 | iLovePDF SL（西班牙巴塞罗那） |
| 版本号 | 4.0.2 |
| 包名 | `com.ilovepdf.www` |
| 安装包大小 | 143.60M |
| 文件校验值（MD5） | `22b795badde7834af920353c685181a8` |
| 系统要求 | 官方页面列出的要求是 Android 8.0 或更高版本（截至 2026-09，以官网为准） |
| 本文版本核对时间 | 2026-09-23 |

三项值得展开说：

- **包名**是应用在系统里的身份，`com.ilovepdf.www` 这一串对上了，才说明你装的是同一款应用。手机上如果已经装着同一个包名的其他版本，系统会直接拒装，处理办法见 [常见问题与排查.md](常见问题与排查.md)。
- **版本号 4.0.2** 是你手上这份包的事实。应用商店里的号通常更高，两边不要混着看——本文描述的操作以 4.0.2 为准。
- **MD5** 用来判断文件有没有下坏，用法见下一节。

## 二、把安装包取到手机里

1. 在手机上打开 [iLovePDF 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e82436f251b1)，进入分享页。
2. 没有网盘账号的先按提示注册或登录；已有账号的点「保存到网盘」，把文件转存进自己的空间，再从自己的网盘里下载。转存之后再下载比在分享页里直接打开稳——分享页刷新、网络抖动都不容易把下载打断。
3. 下载完的文件名形如 `iLovePDF_v4.0.2.apk`。**不要在网盘里点「打开」**，那只会触发在线预览；要选「下载」，等文件完整落到手机的下载目录再动手。
4. 想确认没下坏，就拿上一节那串 MD5 对一遍：`22b795badde7834af920353c685181a8`。不少文件管理器自带校验入口，算出来的字符串与这串完全一致即为完整。

这一步要是卡在「网盘打不开」或者速度特别慢，通常与安装包本身无关，换个网络或换个时段再试。

## 三、允许从浏览器或网盘安装

Android 默认不允许安装来自浏览器、网盘这类来源的 APK，第一次装一般会弹「已阻止安装」。开关位置按系统版本分两种：

| 系统版本 | 操作路径 |
| --- | --- |
| Android 8.0 及以上 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 → 选中你下载用的浏览器或网盘 App → 打开开关 |
| Android 7.x 及以下 | 设置 → 安全 → 打开「未知来源」 |

开关打开后回到文件管理器，点 `iLovePDF_v4.0.2.apk` 继续。装完建议关回去，以后需要临时再开。

## 四、安装过程中的提示

| 提示 | 含义与处理 |
| --- | --- |
| 「解析软件包时出现问题」 | 文件没下完或已损坏。删掉重下，再按第二节的方法校验一次 MD5 |
| 「应用未安装」 | 手机上已有同包名的其他版本。先在设置里卸载旧的，再装这一份 |
| 「您的设备与此版本不兼容」 | 系统版本低于应用要求。对照第一节的系统要求，确认你的 Android 版本 |
| 安全软件提示风险 | 非应用商店来源安装时的常规提醒。确认文件来自你信任的渠道后继续 |
| 装完桌面上找不到图标 | 部分启动器刷新慢，回桌面下拉一次，或在应用列表里搜索「iLovePDF」 |

## 五、第一次打开要做的几件事

1. **看界面语言**。App 的界面语言跟随手机系统语言，系统是中文就是中文界面。装完发现全英文，先回头确认手机的系统语言设置，细节见 [界面语言与账号登录.md](界面语言与账号登录.md)。
2. **按提示给权限**。相机权限是扫描和拍照转 PDF 用的，存储（部分系统叫「照片和视频」）权限是读写你手机里已有文件用的，通知权限用于处理完成的提醒。现在拒绝不影响安装，之后随时能在系统设置里补开。
3. **决定要不要登录**。免费的基础工具一般可以先不登录直接试；要接云存储、要管理订阅、要在多台设备间同步，才需要账号。注册流程与常见卡点见 [界面语言与账号登录.md](界面语言与账号登录.md)。
4. **认一下首页结构**。首页是各类工具的入口（扫描仪、格式转换、编辑等），底部还有一个「文件」页签，那里放你本机和云端的 PDF，细节见 [文件管理与云盘对接.md](文件管理与云盘对接.md)。

装好之后最常用的入口是扫描仪，把它用顺，这套工具就算入门了——具体操作看 [手机扫描纸质文件转PDF.md](手机扫描纸质文件转PDF.md)。
