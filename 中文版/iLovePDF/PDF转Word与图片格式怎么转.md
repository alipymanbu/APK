## 一、先分清你要的方向

转换是分方向的，两个方向的效果差别很大：

| 方向 | 常见用途 | 效果特点 |
| --- | --- | --- |
| Office / 图片 → PDF | 把简历、表格、演示稿、照片固定成一份不乱版的文件 | 版式基本忠实于原文件，字体没装的会替换 |
| PDF → Office / 图片 | 从收到的 PDF 里取回可编辑的文字、表格、图片 | 需要对原文件解析重建，复杂版式会有偏差 |

PDF 里如果本来就是图片（扫描件、拍照件），无论往哪个方向转都先要过文字识别这一步，见第四节。

## 二、支持哪些格式

官方列出的主格式如下（以你打开工具时页面显示的为准）：

| 转换方向 | 涉及格式 |
| --- | --- |
| PDF → 文档 | Word（DOC / DOCX）、PowerPoint（PPT / PPTX）、Excel（XLS / XLSX） |
| 文档 → PDF | Word、PowerPoint、Excel |
| PDF ↔ 图片 | JPG、PNG |
| 网页 → PDF | HTML（把网页地址转成 PDF） |

## 三、在手机 App 里怎么操作

转换工具的操作路子基本一致，都是三步：

1. 在首页找到要用的转换入口（比如「PDF 转 Word」），点进去。
2. 选文件。可以从本机存储里挑，也可以从已接入的云存储里挑——这一步的差别见 [文件管理与云盘对接.md](文件管理与云盘对接.md)。
3. 点开始，等处理完成后把结果保存到本机或存回云端。

处理是在官方服务器上完成的，所以要联网。网快的时候几十页的文档几十秒就回来；卡住不动的情形与排查见 [常见问题与排查.md](常见问题与排查.md)。

## 四、扫描件要先做文字识别

拍照或扫描出来的 PDF，里面是没有文字的图片。这时直接转 Word，拿到的可能还是一堆图。正确顺序是：

1. 先对这份 PDF 跑 OCR（文字识别），并**选择文档实际的语言**；
2. 识别完成后，PDF 里就有了可搜索的文字层；
3. 再拿这份带文字层的 PDF 去转 Word 或 Excel。

识别质量取决于原件的清晰度。拍歪、有阴影、字迹太淡的，先重拍一版再转，比事后修补省事。扫描原件的方法见 [手机扫描纸质文件转PDF.md](手机扫描纸质文件转PDF.md)；语言选错导致整篇变成乱码、识别完文件变大这类问题，见 [扫描件文字识别怎么用与识别不准怎么办.md](扫描件文字识别怎么用与识别不准怎么办.md)。

## 五、转完排版走样，先判断是哪一类

| 现象 | 常见原因 | 能否补救 |
| --- | --- | --- |
| 字体变了、行距变了 | 原文件用了你手机或电脑上没有的字体 | 换回原字体即可；这类偏差不影响文字内容 |
| 表格线没了、列错位 | PDF 里的表格是画出来的线条而非真实表格结构 | 通常需要手工在表格软件里重建列结构 |
| 图文位置错乱 | 原 PDF 版式复杂（分栏、多图层、页眉页脚叠放） | 简单文档概率低，复杂版式难以完全还原 |
| 出来的是一堆图片 | 原 PDF 本身是扫描件，没做文字识别 | 按第四节先做 OCR 再转 |
| 中文变成方框或乱码 | 转换时字体映射出了问题 | 换一个转换方向试（比如先转 PDF→JPG 拿到图片版内容） |

同一份文件，PDF 转 Word 与 PDF 转 Excel 的结果可能差很多：正文用 Word、数据表格用 Excel，挑对方向比反复调参数有效。

## 六、输出文件去哪了

转换完成后的结果通常有三种去处：直接保存到手机本地存储、存回你已接入的云盘、或者分享给其他 App（微信、邮件等）。**如果保存完在文件管理器里找不到**，先看是不是存进了 App 自己的文件区——那个入口在底部「文件」页签里，见 [文件管理与云盘对接.md](文件管理与云盘对接.md)。

## 七、体积与额度的边界

转换属于在线处理，免费版对单次任务数和文件体积设了上限，具体数值官方会调整，以你操作时页面上的提示为准。文件特别大或者要一次转很多份时，页面会提示升级或稍后再试，取舍见 [免费版和高级版有什么区别.md](免费版和高级版有什么区别.md)。

OCR 属于较重的处理，官方把它放在付费权益里。手里只有免费额度时，可以先在本机上把扫描件拍清楚、控制页数，减少需要识别的量。
