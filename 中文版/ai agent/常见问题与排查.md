## 一、客户端打不开或闪退

按顺序试：

1. **重装一遍**：安装包下载不完整是最常见原因，删掉后重新从网盘下载（安卓端安装包获取见[下载与安装教程.md](下载与安装教程.md)）；
2. **查系统版本**：安卓 5.2 是底线，太老的系统装上也容易闪退；
3. **清理存储**：手机剩余空间不足百兆时，应用启动异常并不少见；
4. **先用网页版过渡**：浏览器打开 [manus.im](https://manus.im) 登录就能用，任务在云端跑，换入口不丢进度。

## 二、登录后积分和记录不见了

这不是丢号，九成是**换了登录方式**：当初用 Google 注册，这次用邮箱密码登录，系统会给你开一个全新的空账号，积分、订阅、历史记录全都不在里面。处理办法：换回当初注册时用的那种登录方式重新登录。详细步骤和找回思路见[注册登录与账号问题.md](注册登录与账号问题.md)第二节。

## 三、积分消耗比预期快

先搞清消耗逻辑，再对症：

| 症状 | 原因 | 对策 |
| --- | --- | --- |
| 跑一个任务吃掉大半额度 | 任务太重（深度研究、建站这类 10~30 分钟的活） | 大任务留给付费额度，免费额度跑轻任务 |
| 纯问答也扣不少 | 开的是 Agent 模式 | 只问问题、要文字时用 Chat Mode |
| 同一件事反复扣分 | 指令不清导致返工重跑 | 一次把目标、范围、格式说全 |
| 隔天积分为 0 | 每日积分当天有效、不累积 | 正常现象，别攒着用 |

更细的省法见[免费额度与订阅价格.md](免费额度与订阅价格.md)第五节。

## 四、定时任务到点没跑

1. **先看运行记录**：侧边栏和日历视图里有「即将执行」和「已执行」两类记录，先分清是没触发还是跑了没结果；
2. **跑了但没收到结果**：查输出那一头——邮箱垃圾箱、Slack 频道权限、连接器应用的授权过期，都是常见原因；
3. **显示失败**：失败会自动重试最多 3 次；3 次都失败进运行记录看错误日志，或让 Manus 自己修（网页应用的定时动作点 Investigate）；
4. **免费版定时名额只有 2 个**：建第三个会被挡，数量限制见[定时任务与自动化设置.md](定时任务与自动化设置.md)第三节。

## 五、任务失败或卡住

1. **免费版同时只能跑 1 个任务**——连着发第二个会排队，看起来像「没反应」，等第一个跑完即可；
2. **跑一半卡住**：先等几分钟（复杂任务本来就要 10~30 分钟，见[新手第一次跑任务指南.md](新手第一次跑任务指南.md)第五节的时间参考），确认不是正常耗时再动手；
3. **确实失败了**：直接重发一次；连续失败就把任务拆小——「研究并产出 30 页报告」拆成「先列提纲」「先查这 3 家公司」分步跑；
4. **网络切换**：手机上 Wi-Fi 和流量来回切有时会中断页面刷新，任务本身在云端跑，刷新或换设备再打开通常还在。

## 六、生成的网站打不开

Manus 部署的站点挂在 `*.manus.space` 的子域名上，打不开时按这条线查：

1. **看任务里的部署状态**——还没部署完，链接自然 404；
2. **域名输对没有**——从会话里直接点链接，别手抄；
3. **回滚看看**——如果你后来让它改过版本，让 Manus 回滚到上一个正常版本（它支持任意历史版本回滚）；
4. **还是不行**——在原会话里直接说「站点打不开」，让它在沙盒里自查重部。

## 七、成果文件在手机上打不开

PPTX、PDF、电子表格这类文件下载到手机后，需要装了对应应用才能打开；表格和数据文件更建议在电脑上处理。找不到已生成的文件时，去会话内的 Library（资料库）里翻——所有产出文件都集中放在那里，可随时重新下载。

## 八、以上都不是

去官方[帮助中心](https://help.manus.im/)按分类搜关键词；查版本变化看[更新日志](https://manus.im/zh-cn/updates)。账号类问题（备份恢复、注销）先读[注册登录与账号问题.md](注册登录与账号问题.md)第四、六节再动手。
