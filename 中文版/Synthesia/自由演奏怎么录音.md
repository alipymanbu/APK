# Synthesia 自由演奏怎么录音

> "自由演奏"（Free Play）界面里内置一个多轨录音机，弹完能存成 MIDI 歌，直接出现在歌曲列表里。本篇讲录音入口、限制与保存。

## 一、入口与前提

1. 标题界面点 "Free Play"（自由演奏）
2. 屏幕顶部的红色圆形按钮就是录音键

注意：官方指南写明，录音按钮**要在已激活的版本里才出现** —— 试用版没有这个入口，这也是试用版与正式版的差别之一（对比见 [试用版与正式版有什么区别.md](试用版与正式版有什么区别.md)）。

## 二、怎么录

- 点录音后节拍器先响，小节线向上滚动，照着弹即可
- 每录一轨多一条，各轨的音色与颜色单独调；官方指南口径：**最多 6 轨**
- 不在录音中时，顶部 + / - 按钮统一调所有轨的速度
- 删单轨：菜单栏垃圾桶图标 → 在要删的那轨下面再点一次确认 —— 删除永久生效，不能撤销
- 录到一半退出界面甚至关掉应用都没关系：官方指南写明进行中的录音会保留，下次回来还在

## 三、保存成歌

1. 录完点菜单栏的分享按钮
2. 首次保存会先要求选保存位置：设置 → 歌曲 → 勾选 "Songs you create will be saved here" 并选一个文件夹
3. 保存对话框里给歌起名；**Snap to Nearest** 选项会把音符起止自动对齐节拍（相当于保存时顺带做了一遍量化），想保留原样就选 Off
4. 保存后离开自由演奏，新歌自动出现在歌曲列表

之后这首录出来的歌和你导入的 MIDI 待遇完全一样：指法、循环、进度分照常可用（模式见 [练习模式怎么选.md](练习模式怎么选.md)，列表管理见 [怎么导入MIDI歌曲.md](怎么导入MIDI歌曲.md)）。它的标题、作曲者默认也是空的，想补齐见 [MIDI文件信息怎么编辑.md](MIDI文件信息怎么编辑.md)。
