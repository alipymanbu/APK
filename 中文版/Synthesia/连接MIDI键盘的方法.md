# Synthesia 怎么连接 MIDI 键盘（安卓平板 / 手机）

## 一、不接键盘也能用

屏幕本身就是键盘：安卓版在触屏上直接显示虚拟琴键，跟着下落音符按即可。只是触屏没有琴键的手感与力度反馈，打算认真练琴的话，接键盘更接近真实练习。

## 二、USB 有线连接（最通用）

1. 看键盘的输出口：电钢琴 / MIDI 键盘常见 USB-B 方口，老设备可能是 5 针 DIN 口（这种要经 MIDI 转 USB 线）
2. 用 OTG 转接线（安卓口转 USB-A）+ 对应数据线，把键盘接到手机或平板
3. 接上后打开 Synthesia，在设置里的输入设备 / 键盘选项里选到你的键盘
4. 按一个键，界面有反应就是通了

官方在 10.5 版本更新日志里明确写过"改进了 Android 的 MIDI 兼容性"，连不上的先升级应用版本再试。Chromebook 在兼容机型上也能显示 MIDI 设备（官方 10.5 更新日志口径）。

## 三、蓝牙 MIDI

部分电钢琴支持蓝牙 MIDI。安卓 6.0 起系统层面支持 BLE MIDI 设备，Synthesia 对安卓 MIDI 的支持随版本一直在改。你的键盘能不能走蓝牙，以键盘说明书和实际配对结果为准；现场练习要稳、要延迟低，优先用 USB 线直连。

## 四、带灯键盘

官方功能列表里有 "Lighted Keyboard Support" 一条：旋律练习时，即将要弹的键直接在带灯键盘上亮起来，找和弦位置更容易。前提是键盘本身带灯功能，并且已经按上面的方式连上。

## 五、连上之后

- 延迟明显（按下键、声音晚半拍才出）：换 USB 直连、关掉后台大应用、不要同时开多个音频应用 —— 这些是通用排查思路，不是官方参数
- 平板架到谱架上用真琴键弹，是这套组合最常见的用法
- 连好之后进入练习，模式怎么选见 [练习模式怎么选.md](练习模式怎么选.md)；键盘认不出来时先看 [常见问题与解决办法.md](常见问题与解决办法.md)
