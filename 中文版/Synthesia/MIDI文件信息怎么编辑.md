# MIDI 文件信息怎么编辑：标题、作曲者、分组一次弄好

## 一、为什么导入的歌"没头没脸"

MIDI 文件本身可以不带任何标题、作曲者信息。不带这些信息的文件导进 Synthesia 后，列表里标题作曲者都是空的，`composer:` `tags:` 这类搜索语法也筛不到它 —— 这些字段不是应用自动识别出来的，而是要写进文件里。

## 二、官方工具：Synthesia Metadata Editor

- 免费小工具，官方下载页 "More Apps" 一栏给出，也可以直接去 GitHub 发布页下载，有 Windows / macOS 版：[Synthesia Metadata Editor](https://github.com/Synthesia-LLC/metadata-editor/releases/latest)
- 能填的：标题、副标题、作曲者（composer）、编配者（arranger）、标签（tags）、难度，还能自定义歌曲分组
- 保存后信息写进 MIDI 文件本身 —— 所以工作流是：电脑上编辑保存 → 把文件传回安卓设备 → 重新出现在列表里，信息就齐了

## 三、把你在设备里标的指法带出来

你在安卓设备里给某首歌手动加过指法提示、指定过左右手？这些默认只存在设备本地，换设备就没了。元数据编辑器的 File 菜单里有 "Import data from Synthesia"，可以把本机 Synthesia 里录入的指法与手部分配提取出来、写进文件随文件走（官方内容创作指南口径）。

## 四、文件本身也得"干净"

官方内容创作指南对文件准备有两条硬建议，直接决定导入后的体验：

1. **左右手分轨**：左手、右手用不同的轨道 / 通道 / 乐器，Synthesia 才能把两只手拆开。只有一两轨的文件它自己能猜对手；轨道多的文件，要在歌曲设置的高级视图里用小手图标手动指定哪轨归左手、哪轨归右手
2. **量化（quantize）**：实录进来的音符如果不对齐节拍，和弦会被判成"没同时按"、循环可能漏掉音、乐谱显示也会乱 —— 导入前用 MIDI 编辑器做一遍量化，别把量化强度拉满（快速三十二分音符可能被对折）

这两步做完，[练习模式怎么选.md](练习模式怎么选.md) 里的分手练、循环、乐谱显示才会正常；列表里找不到改完的歌时，回 [怎么导入MIDI歌曲.md](怎么导入MIDI歌曲.md) 检查文件夹设置。
