# Synthesia 安卓版怎么导入自己的 MIDI 歌曲

> 内置歌曲之外，Synthesia 支持加载你自己的 MIDI 文件来练任意曲子。本篇讲支持的格式、安卓上的导入路径，以及导入后的歌曲管理。

## 一、支持哪些文件

| 格式 | 说明 |
| --- | --- |
| `.mid`（MIDI） | 官方功能页口径：包含的 150 首内置歌、Music Store 的歌、你找到或做出的任意 MIDI 文件都能弹 |
| MusicXML | 10.8 版本起支持加载 MusicXML 文件（官方更新日志口径），导入方式与 MIDI 相同 |

只认标准 MIDI / MusicXML 这类乐谱数据，MP3 之类的音频文件导不进来。

## 二、导入步骤（安卓）

1. 先把 `.mid` 文件放进设备上一个你能找到的文件夹：浏览器直接下载、网盘转存、电脑数据线拷贝都行
2. 打开 Synthesia → **设置** → **歌曲**
3. 点右下角的 **+** 号，选到存 MIDI 的那个文件夹，添加
4. 回到歌曲列表，新歌出现在内置歌曲组的下方

以后往同一个文件夹里再放新歌，也会被扫出来；不想让某个文件夹继续出歌，回这个页面把它移出列表即可。

## 三、导入之后的管理

**分组与进度**：内置歌按组排列，每首歌左侧的数字是当前进度（满分 100），组左侧的数字是组内平均进度。

**排序与搜索**：可以按分数、标题、最近播放、播放次数、星级、难度排序；搜索框还认高级语法，比如 `composer:Mozart`、`arranger:某人`、`tags:videogame`，按作曲者、编配者、标签过滤。

**星级与难度**：点星星标星级、手动调难度，方便组织自己的练习清单。

**删除**：导入的歌可以删，安卓上确认之后是永久删除，没有回收站。内置歌曲删不掉，只能隐藏（设置 → 歌曲 → 内置歌曲 → 隐藏它们）。

**信息补全**：标题、作曲者、标签默认是空的，用官方的元数据编辑器把信息写进文件即可，步骤见 [MIDI文件信息怎么编辑.md](MIDI文件信息怎么编辑.md)。

**来源不限**：除了外部导入的文件，自由演奏里录出来的歌也会自动进这个列表，录制方法见 [自由演奏怎么录音.md](自由演奏怎么录音.md)。

## 四、导入失败先查这三处

- 文件夹加了但列表没出现新歌：确认扩展名是 `.mid`，不是被改名成 `.mid.txt` 之类
- 导入后乐谱显示乱：MIDI 文件本身的轨道信息有问题，换一份别的来源的文件对比
- 仍然无声、闪退之类的通用问题：统一见 [常见问题与解决办法.md](常见问题与解决办法.md)

导进来就该练了，旋律、节奏、独奏三种模式怎么选见 [练习模式怎么选.md](练习模式怎么选.md)。
