## 一、安装与启动

| 现象 | 先查 | 处理 |
| --- | --- | --- |
| 提示无法安装 | 剩余存储空间、系统版本 | 官方下载页标 Android 5.0+，各市场口径有出入；安装包损坏就重新下载，文件核对见 [下载与安装教程.md](下载与安装教程.md) |
| 装完点开就闪退 | 设备后台占用、安装中断 | 重启设备再开；仍然闪退就卸载重装一遍 |
| 弹"未知来源"被拒 | 系统安全设置 | 在安装弹窗里给该来源授权，或在系统设置里允许对应文件管理器安装应用 |

## 二、没声音 / 声音小

1. 先按媒体音量键 —— 很多人调的是铃声音量，媒体音量是另一条
2. 关掉蓝牙再试：连过的蓝牙耳机 / 音箱会把声音"悄悄"路由走（通用排查思路）
3. 应用内的播放设置里看输出选项是否正常
4. 官方 10.5 版本给 Windows 和 Android 换了新合成器（更新日志口径），老版本无声可以先升级应用再试

## 三、识别不到 MIDI 键盘

1. OTG 转接线是最大嫌疑：不少转接线只能充电、不能传数据，换一根确认支持数据传输的
2. 按顺序接：键盘开机 → 插 OTG 线 → 插手机/平板 → 再打开应用
3. 系统版本：安卓 6.0 起 MIDI 支持才比较完善（官方 10.5 更新日志明确改进过 Android MIDI）
4. 换数据线：部分 USB 线只供电不传数据
5. 详细的连接步骤见 [连接MIDI键盘的方法.md](连接MIDI键盘的方法.md)

## 四、歌曲相关问题

- 导入后列表里没有新歌：回 设置 → 歌曲，确认文件夹还在列表里；扩展名必须是 `.mid`
- 手滑删了导入的歌：安卓上确认删除后是永久删除，没有回收站，重要的 MIDI 文件先留好备份
- 内置歌太多想藏：设置 → 歌曲 → 内置歌曲 → 隐藏它们
- 导入步骤本身见 [怎么导入MIDI歌曲.md](怎么导入MIDI歌曲.md)

## 五、延迟高

按琴键到出声慢半拍，排查顺序：

1. 改用 USB 有线直连（蓝牙 MIDI 的延迟普遍高于有线）
2. 关掉后台的大应用，尤其是同时在占用音频的
3. 避免边充电边连键盘（部分设备充电时 USB 数据不稳定）

这些是通用排查顺序，具体延迟数值因设备而异，没有统一的"正常值"可给。模式与指法相关的问题不在本篇，见 [练习模式怎么选.md](练习模式怎么选.md)。
