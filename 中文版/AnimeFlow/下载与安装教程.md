## 一、先搞清楚你要哪个版本

AnimeFlow 是一款跨平台的看番软件与动漫播放器，官方在 GitHub 仓库 `openAnimeFlow/AnimeFlow` 持续更新，Android、iOS、Windows、macOS、Linux 都有对应的包。对你来说要先分清两种「版本」：

| 版本 | 说明 | 适合谁 |
| --- | --- | --- |
| 官方最新版（2.x 系列） | 从 [官方 Releases 页面](https://github.com/openAnimeFlow/AnimeFlow/releases) 下载，随官方更新节奏变化，以页面当时显示为准 | 想要最新功能的人 |
| 本篇收录的 1.7.6 | 较早的稳定版本，安装包 50.41 MB，包名 `com.ligg.anime_flow` | 想用固定版本、不喜欢频繁变动的人 |

本文讲解以收录的 1.7.6 版为基准；官方 2.x 新增的功能（如视频资源下载、社区页面）在 1.7.6 里没有，文中会单独标注。

## 二、获取安装文件

最直接的入口是这份 **[AnimeFlow 安装文件资源（夸克网盘）](https://pan.quark.cn/s/54264c09c1f3)**，转存到自己的网盘后即可下载安装包 `AnimeFlow_v1.7.6.apk`。

如果你更想跟进官方的每一次更新，官方渠道是 GitHub 仓库的 Releases 页面：`https://github.com/openAnimeFlow/AnimeFlow/releases`；GitHub 访问不动时的替代入口见 [GitHub打不开怎么下载.md](GitHub打不开怎么下载.md)。注意官方的安卓包按 CPU 架构拆分：

| 包后缀 | 适用设备 |
| --- | --- |
| `arm64` | 近几年的主流安卓手机，一般选这个 |
| `v7a` | 32 位架构的旧手机或电视盒 |
| `x86` | 模拟器 |

选包前有一条官方边界值得知道：开发者在 Issue 里说明过，只保证 iOS、安卓 arm64（v8）与 Windows x86 三类包正常可用，v7a 和安卓 x86 包没有对应的真机可以调试测试。所以旧设备装 v7a 包出问题时，先考虑回退旧版本再排查，不要默认新版一定兼容。

## 三、安装步骤

安卓上安装非应用商店的 apk，首次需要允许「安装未知来源应用」：

1. 从网盘把 `AnimeFlow_v1.7.6.apk` 下载到手机存储；
2. 点开安装包，系统若提示「禁止安装未知来源应用」，按提示去设置里允许你的浏览器或文件管理器安装应用；
3. 回到安装界面点「安装」，等待完成；
4. 打开应用，首次启动会请求存储权限（读取本地视频/字幕等需要），允许即可。

想核对拿到的安装包是否完整，可以对照这组参数：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.7.6 |
| 包名 | `com.ligg.anime_flow` |
| 大小 | 50.41 MB |
| MD5 | `EF46E801E76907C5B9AB4515EFFCE098` |

## 四、装完先做什么

1. **添加数据源**：AnimeFlow 本体不带内置视频源，能搜到什么内容取决于你在「设置 → 数据源管理」里配置的数据源，具体见 [数据源添加与XPath配置.md](数据源添加与XPath配置.md)；
2. **登录 Bangumi（可选）**：有 Bangumi 账号的话登录后可以同步收藏与观看进度，见 [Bangumi收藏同步教程.md](Bangumi收藏同步教程.md)；
3. **调弹幕**：默认弹幕可能密得看不清画面，按 [弹幕设置调整方法.md](弹幕设置调整方法.md) 调透明度、速度和显示区域。

安装或首次启动遇到问题（比如安装包解析失败、启动后搜不到内容），先翻 [播放卡顿与常见问题.md](播放卡顿与常见问题.md)。
