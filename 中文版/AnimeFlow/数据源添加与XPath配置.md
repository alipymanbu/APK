## 一、先明白数据源是怎么回事

AnimeFlow 是播放器 + 追番管理的形态，本体不自带片源：你搜一部番、选一条线路、播一集，实际内容都来自你配置的数据源。官方也明确说明项目仍在持续开发中，**部分功能和数据源可能会发生变化**——某个数据源今天能用、过阵子失效，属于这类应用的常态，不是你装错了。

添加入口在 **设置 → 数据源管理**，右上角有添加按钮。支持多数据源并存、随时切换，也可以对数据源排序（排序功能为官方 2.x 版本新增，网盘收录的 1.7.6 是否有此项以实际界面为准）。

## 二、添加一个数据源

官方给出的添加流程：

1. 进入 **设置** → **数据源管理**；
2. 点击右上角添加按钮；
3. 逐项填写配置信息（下表）；
4. 保存配置。

| 配置项 | 填什么 | 说明 |
| --- | --- | --- |
| 版本号 | 数据源配置的版本 | 随数据源提供方的说明填 |
| 名称 | 唯一标识 | 同名会冲突，起个能区分的名字 |
| 图标链接 | 一个图片地址 | 列表里显示用，可留空 |
| 网站链接 | 数据源对应网站的首页地址 | — |
| 搜索链接 | 搜索页地址 | 用 `{keyword}` 作为关键字占位符，例如 `https://example.com/search/{keyword}` |
| 搜索内容列表 XPath | 定位搜索结果列表的规则 | — |
| 搜索列表名称 XPath | 从结果里取番剧名称 | — |
| 搜索列表链接 XPath | 从结果里取详情页链接 | — |
| 线路名称 XPath | 取播放线路名称 | 同一部番有多条线路时用 |
| 剧集列表 XPath | 取剧集列表 | — |
| 剧集链接 XPath | 取每集的链接 | — |

## 三、XPath 是什么、怎么对付

XPath 就是一种「按路径挑网页元素」的写法，AnimeFlow 用它从数据源网站的结构里把番剧名、链接、线路、剧集一项项抠出来。你不需要从零学：这类数据源配置通常由提供方整包给出（一段段 XPath 直接粘贴进对应输入框），你要做的只是**逐项对应、别填错位**。

实操建议：

- **对照来源粘贴**：拿到一份数据源配置后，照着它的字段名逐项填，名称对名称、链接对链接；
- **填完先搜索验证**：保存后回首页搜一个你确定存在的番剧名，搜得到、点得进、列得出剧集，说明配置生效；
- **搜不到先查占位符**：搜索链接里的 `{keyword}` 少了或写成别的，搜索就会落空，这是最常见的填错点。

## 四、多数据源的日常管理

- **切换**：播放页的数据源弹窗里可以直接换源；同一部番在 A 源失效时切 B 源是日常操作；
- **增删**：数据源管理页里可随时添加、编辑、删除；
- **失效排查**：如果所有数据源都搜不到东西，多半是网络问题或整体失效，见 [播放卡顿与常见问题.md](播放卡顿与常见问题.md) 的排查清单。

数据源配好后，接下来一般会调播放体验——弹幕见 [弹幕设置调整方法.md](弹幕设置调整方法.md)，画质增强见 [超分辨率怎么开.md](超分辨率怎么开.md)。
