## 一、Bangumi 账号在这款应用里管什么

AnimeFlow 接入了 [Bangumi](https://bangumi.tv/) 的开放 API，登录后你能用到这些能力：

| 功能 | 说明 |
| --- | --- |
| 收藏同步 | Bangumi 收藏列表与应用内收藏互通，换设备不用重新标 |
| 追番列表管理 | 在看、想看、看过的状态跟着账号走 |
| 每日放送 | 每周番剧更新日历，哪天更哪集一目了然 |
| 排行榜 | 支持多种排序方式和时间筛选 |
| 时间胶囊 | 动态时间线，看别人的观看动态 |
| 条目详情 | 角色介绍、评论、相关推荐、标签分类 |

Bangumi 是自由注册的番剧数据库社区，没有账号的话去它官网注册一个即可，登录入口在应用内账户设置。

## 二、登录与同步

1. 打开 **设置** → 账户相关页面，选 Bangumi 登录；
2. 授权后应用会拉取你的收藏列表与用户信息；
3. 之后你在应用内收藏一部番，Bangumi 那边也会同步（双向）。

几条边界情况：

- **收藏冲突**：官方 2.6.0 的更新说明提到，收藏不再强制绑定 Bangumi 账号，账户设置页面可以手动双向同步，两边数据冲突时可以手动选择以哪边为准——收录的 1.7.6 是较早版本，同步行为以你实际界面为准；
- **云端播放记录**：同样是 2.3.0 起的功能（登录后自动开启），1.7.6 观看进度主要存在本地；
- **登录状态过期**：官方后期版本修过登录状态频繁过期的问题，旧版遇到反复要求登录，重新授权一次即可；
- **升级后同步异常**：官方 Issues 里出现过「更新到某个新版本后收藏同步不工作」的反馈（随后版本已修复）。升级后如果收藏突然不同步，先退出账号重新授权，再确认更新日志里没有相关的已知问题；登录相关异常不止安卓端有，桌面端也有过登录授权无响应的反馈，处理思路相同。

## 三、不登录也能用

登录不是硬门槛。不连 Bangumi 你依然可以：搜番、选数据源线路、播放、调弹幕与超分辨率。区别在于收藏和观看进度只存在本机，换机要重来；每日放送、排行榜这类基于 Bangumi 数据的页面能否匿名浏览，以实际界面为准。

看番之外想让画面更清楚，见 [超分辨率怎么开.md](超分辨率怎么开.md)；碰到播放异常，见 [播放卡顿与常见问题.md](播放卡顿与常见问题.md)。
