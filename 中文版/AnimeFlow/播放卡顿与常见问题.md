## 一、播放卡顿

按顺序排查，多数情况走不完四步就解决：

1. **关超分**：超分辨率对 GPU 要求不低，质量档尤其如此。先把档位降到效率档或直接关闭，见 [超分辨率怎么开.md](超分辨率怎么开.md)；
2. **降弹幕负担**：关密集模式、缩小显示区域，弹幕全屏铺的时候卡顿会被放大；
3. **换线路**：播放页数据源弹窗里换一条线路，慢线路本身就会缓冲；
4. **换网络再试**：Wi-Fi 与流量互换一次，排除本地网络波动。

如果不开超分、弹幕也关了还卡，那基本是数据源到不了货，看下一节。

## 二、搜不到想看的番

- **换关键词**：先搜番剧的常用中文译名，再试原名或简称；
- **换数据源**：单个数据源收录有限，同一部番在不同源里有无结果很正常；
- **确认数据源没失效**：拿一部热门番当测试样本——热门番都搜不到，说明是数据源问题，去数据源管理里检查配置或换源，参照 [数据源添加与XPath配置.md](数据源添加与XPath配置.md)。

官方 README 明确写着「项目仍在持续开发中，部分功能和数据源可能会发生变化」，所以某个源突然全空是这类应用的常态，先换源再怀疑软件坏了。

## 三、视频能播但进度、收藏不对

- **观看进度本地为准**：收录的 1.7.6 没有云端播放记录同步（官方 2.3.0 起才有），卸载重装或换设备进度会丢，重要进度手动记一下集数；
- **收藏想跟着账号走**：登录 Bangumi 后收藏双向同步，见 [Bangumi收藏同步教程.md](Bangumi收藏同步教程.md)。

## 四、版本相关问题

- **1.7.6 与官方 2.x 差在哪**：官方更新日志里 2.x 系列陆续加了视频资源下载、多播放器内核、社区页面、云端同步等能力。收录的 1.7.6 不含这些功能，日常看番、弹幕、超分、Bangumi 同步这些主干能力不受影响；
- **要不要升级**：想要新功能就去 [官方 Releases 页面](https://github.com/openAnimeFlow/AnimeFlow/releases) 下对应架构的包（手机一般选 arm64）；想保持现状就继续用网盘收录的这版，两不冲突；
- **会不会加广告或收费**：有用户在官方 Issues 里问过这个问题，开发者的答复是「开源免费的软件会持续更新，完全免费」——截至写这篇时没有收费或广告计划，后续变化以官方仓库为准；
- **升级后闪退**：先核对你装的架构包。官方只保证 iOS、安卓 arm64（v8）、Windows x86 三类包的可用性，有电视盒子用户反馈过 v7a 新版闪退，当时的处理办法是完全卸载后重装旧版本，等官方修复再升级；
- **报错看日志**：官方 2.4.0 起在设置里加了错误日志页面，旧版没有这个入口，遇到报错只能截图记录。

## 五、看到不认识的番想认领

AnimeFlow 集成了 trace.moe 的截图识番能力：播放或浏览时对陌生画面截图识别，能反查出番剧条目，再顺着条目看详情、加收藏。

以上排查都无效时，可以去官方仓库的 Issues 区（`https://github.com/openAnimeFlow/AnimeFlow/issues`）搜一下是否有人报过同样的问题。
