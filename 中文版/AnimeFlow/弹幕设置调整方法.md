## 一、弹幕从哪来

AnimeFlow 自己不产弹幕，播放时你看到的弹幕是从外部弹幕源匹配来的，官方支持：

- Bilibili
- Gamer
- 弹弹Play

也就是说同一集番剧的弹幕量取决于这些平台上有没有对应内容。冷门番弹幕少甚至没有，换弹幕源也不一定有，这是正常现象。官方更新日志里提到弹幕搜索接口后续有优化过匹配效率，旧版本匹配不上时未必是你配置的问题。

还有一种情况官方在 Issue 里答复过：热门番的**先行版**（还没正式播出的集数）也可能匹配不到弹幕——你比弹幕源先看了一步。过几天等正式播出后再打开，弹幕通常会补上。

## 二、能调哪些项

播放界面打开弹幕设置后，官方列出的可调项如下，每项都给你一个「什么时候动它」的参考：

| 设置项 | 作用 | 什么时候调 |
| --- | --- | --- |
| 透明度 | 弹幕整体深浅 | 弹幕抢戏看不清画面时调低 |
| 字体大小 | 弹幕字号 | 手机小屏建议调小一档 |
| 弹幕速度 | 弹幕滚动的快慢 | 觉得眼花就放慢 |
| 显示区域 | 弹幕占屏幕的比例 | 只想留半屏弹幕就调小区域 |
| 弹幕类型筛选 | 滚动 / 顶部 / 底部分开开关 | 不想被顶部底部刷屏就只留滚动 |
| 边框 | 字体描边 | 画面亮、白字看不清时开 |
| 颜色 | 弹幕文字颜色 | 按喜好 |
| 密集模式 | 弹幕铺多满 | 全屏弹幕太吵就关掉 |

另外两项在官方较新版本（2.x 系列）更新日志里出现，收录的 1.7.6 未必有：弹幕简繁体转换（2.3.0）和字体描边粗细调节（2.6.0）。

## 三、弹幕不显示时按这个顺序查

1. **确认剧集匹配到了弹幕**：先换个热门番（平台上弹幕多的那种）试，热门番有、冷门番没有，就是匹配问题不是设置问题；
2. **检查类型筛选**：如果你只开了「顶部」而当前弹幕都是滚动型，画面上就会一片干净；
3. **检查显示区域和透明度**：区域调到最小、或透明度调到接近全透明，都会「看起来像没有弹幕」；
4. **换网络环境**：弹幕源服务器连不上时弹幕列表为空，换个网络再试。

弹幕之外的播放问题（卡顿、画质）分别见 [超分辨率怎么开.md](超分辨率怎么开.md) 与 [播放卡顿与常见问题.md](播放卡顿与常见问题.md)。
