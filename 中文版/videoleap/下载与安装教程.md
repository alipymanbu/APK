## 一、安装前先确认这几件事

Videoleap 是 Lightricks Ltd. 出品的手机视频剪辑应用，安卓端包名为 `com.lightricks.videoleap`。你手里的这份安装包信息如下（以安装包实测为准，官方商店的版本号会更新得更快）：

| 项目 | 数值 |
| --- | --- |
| 版本 | 1.39.1 |
| 包名 | `com.lightricks.videoleap` |
| 安装包大小 | 117.94 MB |
| MD5 | `045489F8E02587179662E22CCACB86E3` |

两点提醒：

1. **存储空间**：安装包约 118 MB，安装后应用本体加上缓存通常会占到安装包的数倍。剪辑应用还会在项目里引用你的原视频，导出前建议让手机剩余空间保持在 2 GB 以上，空间不足是导出失败最常见的诱因之一。
2. **系统版本**：这个版本对安卓系统版本有要求，不同渠道的标注略有差异。安装时如果提示系统版本过低，以手机弹出的提示为准，这类提示没法绕过。

## 二、从夸克网盘拿到安装包

安装文件资源在这里：[Videoleap 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5454e354c4bb)。获取步骤：

1. 点开链接，在夸克网盘里看到 `videoleap_v1.39.1.apk`；
2. 选择「保存到我的网盘」（转存到自己账号后才能下载）；
3. 在夸克网盘 App 或网页版里把这个 APK 下载到手机存储。

下载完成后文件会出现在手机的通知栏下载记录或 `Download` 目录里，后续安装都以这份文件为准。

## 三、安装步骤

1. 点开下载好的 `videoleap_v1.39.1.apk`；
2. 如果系统弹出「是否允许此来源安装应用」，选择允许（不同品牌手机的入口名称略有差异，有的叫「安装未知应用」）；
3. 等待安装完成，点「打开」直接进入，或回到桌面点 Videoleap 图标。

首次启动时应用会申请存储、照片与视频访问等权限，你同意后它才能读到相册里的素材；拒绝的话进编辑器会看到空素材列表，去系统设置的应用权限里补开即可。

## 四、校验安装包是否完整

如果你在电脑上转存、传输过这份 APK，担心文件在传输中损坏，可以在 Windows 上用系统自带的工具核对 MD5：

```powershell
certutil -hashfile "videoleap_v1.39.1.apk" MD5
```

输出的哈希值与第一节表格里的 MD5 一致，说明文件完整；不一致就重新下载一次再装。不校验直接装也可以，装不上或启动闪退时再回来核对这一步。

## 五、装不上或报错怎么处理

按报错提示对号入座：

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | 下载不完整或传输损坏 | 重新下载一遍，核对第四节里的 MD5 |
| 提示与已安装应用冲突 | 手机里已有同包名的旧版本，签名不同 | 先卸载手机里原有的 Videoleap 再装；注意卸载会连同其项目数据一起清掉，有未导出的项目先导出 |
| 「存储空间不足」 | 剩余空间不够 | 清出至少 1~2 GB 再装 |
| 提示系统版本过低 | 安卓系统版本不满足要求 | 只能升级系统或改用系统自带商店里的对应版本 |

安装这类从商店以外渠道拿到的 APK，手机管家类应用有时会弹安全提醒，这是对非商店来源的通用提示，与安装包本身无关；装完后建议在系统设置里确认包名为 `com.lightricks.videoleap`，与你预期的应用一致。
