## 一、导出失败或一直卡住

这是被提及最多的一类问题。按顺序排查，绝大多数在前三步就能解决：

1. **看剩余存储**：导出是先把成品写进手机存储，空间不足会直接失败。清出至少 2 GB 再试，别把希望寄托在云空间上——本地空间才是导出写入的地方；
2. **更新应用**：应用商店里看有没有待更新的版本，导出相关的缺陷通常靠更新修复；
3. **清理应用缓存**：系统设置 → 应用 → Videoleap → 存储 → 清除缓存（注意是缓存，不是清除数据，清除数据会连项目一起清掉）；
4. **重启应用或手机**：后台驻留太久导致渲染中断时有效；
5. **都不行再重装**：重装前确认所有项目都已导出或不再需要，重装会丢本地项目数据。

另外注意时间线上的「问题素材」：从聊天工具转发来、或其他剪辑应用加工过的视频文件偶尔无法被正确处理，导出卡住时可以试试把可疑片段删掉再导，用来定位是哪个素材引起的。导出成功但成品带了角标、或对「免费导出带不带水印」有疑问，是另一类问题，见 [导出水印怎么办.md](导出水印怎么办.md)。

## 二、预览卡顿、拖动时间线掉帧

- 图层数量与特效叠加是卡顿的主因，先把不关键的特效临时关掉对比一下；
- 4K 原素材直接剪在低端机上容易吃力，可以把素材先压缩到 1080p 再剪（成品要求不高时可行）；
- 关掉后台其他应用再试，剪辑应用对可用内存敏感；
- 预览卡顿不代表导出一定失败，但连续卡到时间线失去响应，就先保存退出重进。

## 三、项目找不到了 / 素材带感叹号

- Videoleap 的项目会自动保存，进主页的项目列表翻找即可；卸载应用、清理应用数据或恢复出厂会让本地项目消失，且没有云端找回的通用办法；
- **手动删除的项目同样找不回来**——官方帮助中心明确说项目一经删除无法恢复。删除入口在主页项目列表：缩略图上的三点图标 → 删除。所以清理项目列表时别连着删，删之前先确认成品已经导出到相册；
- 素材缩略图上出现感叹号，一般是原文件被移动、删除或还在云端没下载到本地：把原视频/图片放回手机相册原位置，或重新下载到本地后再在项目里重选该素材；
- 拍摄后开启过手机厂商的「相册云同步并清理本地」功能的话，最容易出感叹号——被清理的那部分素材要先把原图从云相册取回本机。

## 四、声音问题

| 现象 | 先检查什么 |
| --- | --- |
| 导出的成品没有声音 | 时间线上对应音轨是否被静音或音量拉到 0；导出设置里是否有音量相关选项 |
| 预览有声音、导出没有 | 多半是某条音轨的音量/淡出设置只在预览时生效，逐轨核对音量数值 |
| 内置音乐列表是空的或加载不出 | 素材库需要联网加载，换网络环境再试 |
| 加了本地音乐却听不到 | 确认该音轨被拖到与画面重叠的时间段上，音轨摆在空白时间段等于没加 |

音频的正常用法（淡入淡出、EQ、多轨音量）见 [特效滤镜与音频使用.md](特效滤镜与音频使用.md)。

## 五、订阅了但 Pro 没生效

1. 确认当前登录/结算账号就是购买时用的那个 Google 账号（或 Apple ID）；
2. 在应用内找「恢复购买」点一次；
3. 到应用商店的订阅列表里确认这项订阅状态正常（有没有被取消、有没有扣款失败）；
4. 还不行就通过应用内帮助入口联系官方支持，附上购买凭证截图。

购买、取消、退款的完整路径都在 [免费版与Pro订阅区别.md](免费版与Pro订阅区别.md)。

## 六、应用闪退、打不开

- 重启手机后再开一次；
- 检查存储剩余空间，空间接近满时应用启动都容易崩；
- 核对安装包 MD5 后重新安装（方法见 [下载与安装教程.md](下载与安装教程.md)），安装文件损坏引起的闪退重装即可解决；
- 闪退发生在打开特定项目时，多半是该项目数据损坏，只能放弃该项目重建。

以上未覆盖、且带报错弹窗的情况，截图后走应用内帮助中心反馈，比在商店评论区留言更容易得到处理。
