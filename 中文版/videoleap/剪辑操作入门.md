## 一、新建项目与画幅选择

打开应用后点底部加号，从相册里选一段视频或一张图片加入项目，随后会让你确认两件事：

1. **编辑模式**：普通剪辑直接选默认即可；
2. **纵横比**：竖屏短视频选 9:16，朋友圈/方块图选 1:1，横屏视频选 16:9。选错也没关系，剪辑过程中随时能点「画布」（Canvas）改回来。

Videoleap 内置的比例预设不止这三档，还有 4:5、2.35:1 等适配不同平台画幅的选项，做片头或电影感封面时会用到。

## 二、认识时间线与图层

进入编辑器后你面对的是一条横向时间线：

- **主轨**：你加入的第一段视频在这里，选中它后底部会出现修剪、分割、变速等工具；
- **图层轨**：主轨下方还能叠加视频、图片、文字、音频，各层可以独立移动、缩放、调不透明度；
- **缩放**：双指捏合可以缩放时间线，放大到逐帧级别后再修剪，切点会准得多。

图层的叠放顺序可以调整，配合混合模式（正片叠底、滤色、柔光等）能做出双重曝光一类的效果，具体玩法在 [特效滤镜与音频使用.md](特效滤镜与音频使用.md)。

## 三、基础剪辑动作

你日常最常用到的就是下面这几个动作，都在选中片段后的底部工具栏里：

| 你想做的 | 操作路径 |
| --- | --- |
| 去掉开头结尾多余部分 | 选中片段，拖动两端的手柄向内修剪 |
| 去掉中间一段 | 移动播放头到切点，点分割，选中不要的那段点删除 |
| 一段视频拆成多段 | 同上，分割可以在一条片段上做多次 |
| 调整顺序 | 长按片段拖到目标位置 |
| 复制一份接着播 | 选中片段，点复制 |
| 镜像或翻转 | 选中片段，在变换类工具里选翻转/镜像 |
| 慢动作或快放 | 选中片段，点速度工具调整倍率 |

所有操作都支持不限次数的撤销/重做，剪乱了往回退就行。项目会自动保存，中途退出下次打开还能接着剪。

## 四、加文字与转场

- **文字**：点图层轨的添加入口选文本，输入内容后可以换字体、调颜色、加阴影、改不透明度，拖动文字层在时间线上的位置来控制它出现的时间段；
- **转场**：两段片段的衔接处有一个小标记，点它就能在列表里挑转场效果，做成片头或卡点视频时常用来衔接两个镜头。

字幕、台词说明一类的内容都走文字图层；如果只是想让视频「有字」，先加好再调时间范围，比反复改样式省事。

## 五、滤镜与调色

选中片段后进滤镜/调整面板：滤镜是整套风格一键套用，大多数滤镜还能拖动滑块调浓淡；想自己动手就切到调整，改亮度、对比度、饱和度。同一条片子里给不同片段套同一款滤镜并统一浓淡，成片色调才不会一截一截地跳。

## 六、导出成片

剪完点右上角的导出，在导出设置里选分辨率与帧率，确认后等待渲染，成品会存进手机相册。几个经验值：

- 导出面板会列出可选的分辨率档位（常见的有 720p、1080p 等，具体档位以你的版本显示为准），发社交平台选 1080p 足够，再高只是文件更大、上传更慢；
- 导出速度取决于项目里图层数量与特效复杂度，层数多、特效多就耐心等；
- 导出卡住或失败时，先看 [常见问题与解决方法.md](常见问题与解决方法.md) 里的导出一节；成品带了不想要的角标，看 [导出水印怎么办.md](导出水印怎么办.md)。
