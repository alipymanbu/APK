## 一、先查网络（最常见原因）

官方帮助中心明确：下载与使用 Photomath 都需要**稳定的网络连接**——解题计算在云端完成，不是全部在手机本地跑。所以：

1. 断网或弱网时扫描拿不到步骤，先确认手机能正常上网。
2. 检查系统设置里 Photomath 的联网权限没有被限制（安卓注意省流量模式；iOS 用蜂窝数据时，到「设置 → 蜂窝网络」确认已允许）。
3. 用热点时连不上，官方的说法是该热点的 IP 可能被屏蔽——换一个热点，或按官方建议改用 VPN。
4. 网络正常仍拿不到结果，可以发邮件给官方支持：`photomath-help@google.com`（官方帮助中心给出的反馈邮箱）。

## 二、再查识别

识别错是「答案异常」最常见的来源：

1. 点等式旁的**铅笔图标**，逐字符核对识别结果——l / 1、O / 0、上标、分数横线是重灾区。
2. 调整取景框只框住**一道题**；两道题挤在同一个框里会串。
3. 光线、对焦、手写连笔的问题对照[拍照扫描与手写识别技巧](拍照扫描与手写识别技巧.md)第二节处理。
4. 拍不准就换**手动输入**（计算器图标），直接绕开识别环节。
5. 超长题整道扫总失败，拆成几段分别扫、中间结果手动衔接；手写题的具体处理见[手写识别不准怎么办](手写识别不准怎么办.md)第四节。

## 三、识别没错，结果还是不对？

- 换一张解法卡片对照：同一道题常有多种解法，某一种的展开有疑问时，看另一种的步骤是否一致。
- 排除「约定不同」：定义域、单位、保留位数不同的题，答案本来就不一样，先确认你和应用解的是同一问。
- 仍对不上，带上题目与步骤反馈到 `photomath-help@google.com`。

## 四、其他卡死情形

| 情形 | 处理 |
| --- | --- |
| 相机黑屏 / 对不上焦 | 系统设置里确认相机权限；重启应用再试 |
| 应用闪退 | 清后台重开；反复闪退就卸载重装，安装包见[下载与安装教程](下载与安装教程.md) |
| 步骤显示不全 | 确认网络；部分深度讲解属于 Plus，见[免费版与Plus订阅区别](免费版与Plus订阅区别.md) |
| 某类题一直解不了 | 可能超出当前覆盖范围，见[支持的题型与学科范围](支持的题型与学科范围.md) |

## 五、官方帮助入口

Google 帮助中心有 Photomath 专区，含中文页面：[https://support.google.com/photomath](https://support.google.com/photomath)。技术问题、Plus 计费问题都从这里查，上面的邮箱反馈也在其帮助页里列出。
