## 一、官方覆盖的学科

官网列出的范围从小学算术延伸到大学低年级：

| 学科 | 典型题目 |
| --- | --- |
| 小学算术 | 四则运算、分数、小数、长除法 |
| 代数 | 线性方程、方程组、不等式、因式分解 |
| 几何 | 角度、面积、勾股定理、圆 |
| 三角函数 | 正弦余弦、恒等变换 |
| 统计与概率 | 平均数、排列组合 |
| 微积分 | 极限、导数、积分 |
| 应用题（word problems） | 文字题也能扫，识别后转成算式求解 |

关于应用题多说一句：官方宣传里写「应用题也能扫」；有第三方评测则认为它实际解的是「式子」，长文字题需要你先自己转成算式再扫。两种说法并列放在这，不替你选边——遇到长文字题，最稳的做法是先把数量关系写成算式，再扫描或手动输入。

## 二、能用到什么学段

官方定位是「elementary through college」（小学到大学）。按国内学段粗略对应：小学高年级到大学理工科低年级的常规数学题基本都在覆盖范围内；竞赛题、考研数学这类超出常规教材的题目不保证有完整解法。官方帮助中心还提到，解题已迁往云端、正在向「覆盖绝大多数数学领域直至大学数学」扩展——也就是说覆盖面会持续变化，同一道题隔一段时间再试可能有不同结果。

## 三、两类「解不出来」

1. **真的超范围**：应用会给「暂不支持」类提示。官方也承认存在还解不了的题，团队在持续补充。遇到时先别急着放弃，见第 2 条。
2. **识别失败的「假性不会」**：题目本身在范围内，但拍照识别错了，导致解不了或解错。先点铅笔图标核对、修改识别出的算式再试（做法见[拍照扫描与手写识别技巧](拍照扫描与手写识别技巧.md)第三节），或者换手动输入绕开识别环节。

## 四、版本对题型的影响

网盘里这份安装包是 **8.40.0**，官方最新版可能已加入更多题型与解法。你手上这一版能解什么，以它的实际表现为准；旧版解不了、新版能解是正常现象。由于解题在云端完成，题型覆盖会随服务端更新而变化——联网状态下有时不升级安装包也能看到覆盖范围扩大。
