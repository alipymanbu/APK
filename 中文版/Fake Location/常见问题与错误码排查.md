## 一、点「启动模拟」一直转圈

按出现频率排：

1. **在等 root 授权**（ROOT 模式最常见）——去 Magisk 看有没有弹授权框；**别在 Magisk Hide / Zygisk DenyList 里勾选 Fake Location**，勾了它永远等不到授权；部分机型还要保持 Magisk 在后台；
2. **网络不通**——软件要连自己的服务器拉数据，网络差就一直转；换网络或重启软件；
3. **系统 Root 失效**——个别机型（如魅族 FlymeOS 自带 root）更新系统后 root 会失效，需要关闭再重新启用 root。

官方还有一条经验：转圈时模拟**可能已经生效**，切到后台打开地图看一眼坐标即可判断。

## 二、启动了但目标应用里还是真实位置

这是问得最多的一类，按顺序排查：

1. **你在用免 ROOT 模式**——它只能模拟 GPS 这一路，目标应用若用 WiFi/基站混合定位就拦不住。官方说法是免 ROOT 只对极少数应用有效，换 ROOT 模式；
2. **目标应用走的是基站定位**——在位置模拟页把「基站」开关打开；
3. **系统混合定位没被覆盖**——ROOT 模式下打开 GPS 信号模拟，必要时再开 WiFi 模拟；
4. **系统 WiFi/蓝牙扫描在透底**——GPS 被模拟了，系统后台的 WiFi 扫描与蓝牙扫描仍在提供真实位置来源，去 `设置 → 位置 → 位置服务` 把两项扫描关掉，完整检查顺序见 [定位不生效系统设置检查.md](定位不生效系统设置检查.md)；
5. **该应用在官方屏蔽名单里**——打卡、签到、网约车、校园跑、配送这类场景官方明确不开放模拟，开再多开关也没用，详见 [专业版与使用限制.md](专业版与使用限制.md)；
6. **改完没重启目标应用**——先彻底划掉目标应用再重开，让它重新取一次位置。

## 三、ROOT 模式报错速查

| 报错 | 含义 | 怎么办 |
| --- | --- | --- |
| System 分区不可写 | 旧版本（1.2.0 前）的分区写入检查 | 1.5.2 已无此检查；若你装的是老版本，直接升级 |
| 错误码 103 | 系统分区空间不足 | 清理 `/system` 下无用文件腾空间（小米可删 `/system/data-app` 等）；不确定删什么就先别动 |
| 错误码 104 | 内核不允许关闭 SELinux | 华为较新 EMUI 内核禁了 ptrace、三星部分机型受 KNOX 限制——这类设备 ROOT 模式跑不通，只能刷解除限制的第三方内核 |
| 虚拟位置服务连接失败 | 运行环境异常 | ① 确认是正版最新版；② 不要在多开/虚拟空间里运行；③ 升级后出现的，先重启手机再进设置清理运行环境；④ 仍不行，打开「日志记录」复现后把日志发开发者（`lerist.5@gmail.com`） |

## 四、系统提示「定位不可用，正在使用模拟位置」

免 ROOT 模式下部分机型会弹这条。它的意思是**系统自带 GPS 拿不到真实信号，正在用模拟位置**——属于正常提示，不是故障。要判断模拟是否真的生效，去地图应用里看坐标，别看这条提示。

## 五、用一会儿就跳回真实位置 / 摇杆消失

典型原因是**进程被系统杀掉了**，不是软件坏了。逐项检查：

- 允许后台运行并锁定该应用（最近任务里加锁）；
- 关闭省电优化：小米把「省电策略」设为无限制并打开自启动；华为/OPPO/vivo 各自给「允许后台运行」+「忽略电池优化」；
- **MIUI 上摇杆罗盘失效**：多个来源指向同一处理——把 Fake Location 的省电策略关掉（设为无限制），摇杆罗盘会恢复随手机朝向旋转；
- 摇杆整个不显示：先查悬浮窗权限，见 [定位不生效系统设置检查.md](定位不生效系统设置检查.md) 第四节；
- 省电模式（低电量模式）开着时更容易被杀，测试期间先关掉。

## 六、没 root 的手机想用 ROOT 模式功能

官方 FAQ 给的路子是**在虚拟机类应用里跑**：装光速虚拟机、VMOS Pro 之类，把 Fake Location 和目标应用**都装进虚拟机**，在虚拟机内用 ROOT 模式。官方同时标注了「不保证所有虚拟机都能正常运行，自行测试」。这条路只适合临时验证，别指望它当长期方案。

## 七、专业版支付相关

- 支付用的**订单码**是单次有效的临时码，不是支付宝订单号，充值完成后即失效，下次充值会重新生成；
- 支付完成但专业版没开通：确认订单是否自动附带了订单码；没带的话在开通页重新「提交订单」，或把支付截图发 `lerist.5@gmail.com` 处理。

其余支付细节与功能边界见 [专业版与使用限制.md](专业版与使用限制.md)。
