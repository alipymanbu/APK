# 定位不生效系统设置检查

> 启动模拟后位置还是不动，多半不是软件坏了，而是系统侧某一项没配对。本篇按检查顺序列系统设置。

## 一、先分清是哪种「不生效」

检查之前先做个区分，两条路的排查方向完全不同：

| 症状 | 更可能的原因 | 去哪查 |
| --- | --- | --- |
| 全机所有应用看到的位置都是真实位置 | 模拟根本没启动（授权/模式问题） | [ROOT与免ROOT模式设置.md](ROOT与免ROOT模式设置.md) 与 [常见问题与错误码排查.md](常见问题与错误码排查.md) 第一节 |
| 地图应用里已经是虚拟位置，**个别应用**还是真实位置 | 目标应用走了别的位置来源，或系统扫描在透底 | 按本篇第二节往下逐项查 |

第二种情况最常见，下面五项按「性价比」排序，逐项做完再下结论。

## 二、关掉 WiFi 扫描与蓝牙扫描

**这是最容易被漏掉的一项。** 安卓的定位不只读 GPS：系统会在后台持续扫描周边 WiFi 热点与蓝牙设备来推算位置（Google 自己的说明也是这么写的——即使 WiFi 没连，扫描照样进行）。GPS 被你模拟了，这两路如果还在喂真实数据，混合定位就可能把真实位置露出来。

关闭路径（Android 12 及以后，各品牌略有差异）：

```
设置 → 位置 → 位置服务 → WiFi 扫描 → 关闭
设置 → 位置 → 位置服务 → 蓝牙扫描 → 关闭
```

- 三星机型在 `设置 → 位置 → 改进准确度` 下；
- 找不到的话，在设置搜索框里直接搜「扫描」。

顺带一提：美国国家安全局（NSA）的公开指南《Limiting Location Data Exposure》也常年建议在不用 WiFi/蓝牙时关掉这两项扫描——对隐私本身也有好处，不是只为模拟定位服务。

## 三、系统定位模式选「高精度」

部分机型上「位置模式」设成仅限设备（只用 GPS）时，地图与目标应用拿不到完整位置，表现为地图不更新。检查：

```
设置 → 位置 → 位置服务 → 定位模式 → 高精度（部分机型叫「准确度」）
```

多个第三方教程都把「定位模式不是高精度」列为地图不更新的第一检查项；与你机器上的实际菜单名对上即可，叫法各品牌不同。

## 四、授予悬浮窗权限（摇杆要用）

摇杆、罗盘是**悬浮在其他应用上面**显示的，没拿到悬浮窗权限它就出不来，你会以为「摇杆消失 / 功能没了」。检查：

```
设置 → 应用 → Fake Location → 权限 → 悬浮窗（部分机型在「其他权限」里）
```

有的机型装完首次启动会弹这个授权，点了拒绝之后就得手动回设置里开。

## 五、个别应用还是真实位置时

系统侧查完都正常、就某一个应用不动，按这个顺序：

1. **彻底杀掉目标应用再重开**——很多应用只在启动瞬间取一次位置，不重启它永远读的是旧值；
2. **有用户反馈**（V2EX 讨论）：微信这类应用对开发者选项下的模拟位置不敏感，免 ROOT 模式改不动，ROOT 模式才稳定生效；同一帖里也有用户提出「断开 WiFi 再试」，与第二节的扫描问题是同一个来源。这两条是**用户实测反馈，不是官方结论**——官方的口径始终是「免 ROOT 模式只对极少数应用有效」；
3. **WiFi 场景单独试一次**：连着 WiFi 时目标应用可能拿到 WiFi 定位结果，关 WiFi + 关第二节的扫描，再看目标应用；
4. 还不行，回 [常见问题与错误码排查.md](常见问题与错误码排查.md) 第二节走完整清单（基站模拟、GPS 信号模拟、屏蔽名单）。

## 六、查完仍不生效的边界

把上面全做完还是老样子，剩下两种可能：目标应用在官方屏蔽名单里（见 [专业版与使用限制.md](专业版与使用限制.md)），或它用了比系统模拟更底层的检测手段——这已经超出「调设置」能解决的范围，别再无限加开关。官方反馈渠道列在 [专业版与使用限制.md](专业版与使用限制.md) 第五节。
