## 一、三步走：选点 → 启动 → 验证

**第一次用，按这个顺序走一遍最不容易踩坑**（前提是运行模式已配好，见 [ROOT与免ROOT模式设置.md](ROOT与免ROOT模式设置.md)）：

1. **选点**：主界面点右侧 `+` 号，弹出的菜单里有「选择位置 / 采集位置 / 导入位置」三种入口。选「选择位置」进大地图，搜到目标地点后点右下角的对勾确认；
2. **启动模拟**：回到主界面点「启动模拟」，按你的环境选 **NOROOT** 或 **ROOT** 模式。有的手机这一步会先弹 root 授权框，点允许；
3. **验证**：先随便打开一个地图类应用，看左下角坐标是否已经变成你选的点；确认生效后再去目标应用里看。

一个小现象：点「启动模拟」后界面可能一直转圈，**但模拟其实已经生效了**——把软件切到后台，直接去地图应用里看位置即可。一直转圈的其他原因（root 授权、网络）在 [常见问题与错误码排查.md](常见问题与错误码排查.md) 里列了。

关于系统定位开关，网上常见的经验是：先开着定位让系统刷新一次、确认模拟生效后再关掉系统 GPS，能减少真实位置干扰；不同机型表现不一，自己试一次就知道哪种稳。这是用户经验，不是官方结论。

## 二、摇杆与移动控制

选完点不是就结束了——想让位置「动起来」，主要靠这几个功能：

| 功能 | 怎么用 | 你可能会用在 |
| --- | --- | --- |
| 摇杆移动 | 主界面呼出摇杆，拖动即移动位置 | 需要微调站位、沿着街道走两步 |
| 朝向联动 | 摇杆罗盘随手机朝向旋转 | 拿着手机转身、方向跟着人走 |
| 多级速度 | 点速度值切换步行 / 跑步 / 骑车 / 驾车 / 飞机，也可点数值自定义 | 路线模拟时控制推进快慢 |
| 位置快速切换 | 在已保存的多个地点间一键跳转 | 常用地点来回切 |
| 保存当前位置 | 记下当前点，方便随时跳回来 | 怕找不回去自己的真实位置 |

## 三、路线模拟与采集

- **路线模拟**：设定起点和终点，软件按路线自动移动，配合速度档位就是一段「走过去」的轨迹；
- **路线采集**（1.5.2 新增）：沿你走过的实际路径采集一条路线，之后可回放；
- **导入经纬度 / 导入地图 App 分享的地点**：从高德、百度等地图 App 分享出来的地点链接可以直接粘贴进来，省去手动搜索。

## 四、步频、基站、WiFi 这些增强项

这几个功能属于「让位置更像真的」，按目标应用的反应决定开不开：

- **步频模拟**：累计计步器步数，微信运动、支付宝步数这类读计步数据的应用会跟着变；
- **基站模拟**：自动搜索目标位置附近的基站；目标应用报「定位失败」时优先开它；
- **WiFi 模拟**：模拟周边 WiFi 列表，补上混合定位里 WiFi 这一路；
- **GPS 信号模拟**：给目标应用喂一份可控的 GPS 信号，检测严格的应用用得上；
- **独立模拟**：对指定应用单独生效，其余应用照常显示真实位置——只想改一个 App 时用它，影响面最小。

## 五、位置更新频率怎么设

官方给的参考值是按场景分的：

- 社交类应用：**100 毫秒**；
- 部分游戏：**1000 毫秒**。

原理不用管，记结论就行：刷新太快费电且可能引起怀疑，太慢则位置会「一顿一顿」。默认值先用，目标应用里位置跳变明显再往快调，卡顿就往慢调。

## 六、用完之后

停止模拟后，位置会回到真实坐标。ROOT 模式下若开了「SELinux 自动恢复」，SELinux 也会同步恢复。想让状态干净，养成顺手点「关闭模拟」的习惯，别直接杀后台。
