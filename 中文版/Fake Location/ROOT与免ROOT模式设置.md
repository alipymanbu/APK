# ROOT 与免 ROOT 模式设置

> 本篇讲两种运行模式各自怎么配：免 ROOT 要在开发者选项里选「模拟位置信息应用」，ROOT 模式要处理 Magisk、SELinux 这些前置条件。

## 一、先选哪条路

| | 免 ROOT（NOROOT）模式 | ROOT 模式 |
| --- | --- | --- |
| 前置条件 | 无需 root，只需开发者选项 | 设备已获取 root，SELinux 可切换到宽容模式 |
| 能模拟什么 | 只能模拟 **GPS 定位** | GPS、WiFi、基站等混合定位都能模拟 |
| 有效性 | 官方原话：只对极少数应用有效 | 官方主打方式，成功率高 |
| 适合谁 | 想先快速试一下的人 | 需要在地图、社交等应用里稳定生效的人 |

官方在介绍页里写得很直白：免 ROOT 模式「只对极少数应用有效」。如果你按 [虚拟定位怎么用.md](虚拟定位怎么用.md) 启动模拟后，在目标应用里看到的还是真实位置，多半就是命中了这种情况，见 [常见问题与错误码排查.md](常见问题与错误码排查.md) 的对应条目。

**一个前提提醒**：ROOT 模式需要把 SELinux 切到宽容模式，官方声明里明确写着这会降低设备安全性、非专业人士请勿尝试。日常主力机不建议折腾 root；确实要测，用备用机。

## 二、免 ROOT 模式设置步骤

不同品牌的开发者选项路径略有差别，通用流程是：

1. 开启开发者模式：**设置 → 关于手机 → 连续点击「版本号」7 次**，直到提示「已处于开发者模式」；
2. 回到 **设置 → 系统 → 开发者选项**（有的在「更多设置」里）；
3. 找到 **「选择模拟位置信息应用」**（有的手机写作「选择模拟位置应用」）；
4. 在列表里选中 **Fake Location**；
5. 打开 Fake Location，点 `+` 选好位置后启动模拟，模式选 **NOROOT**。

几个容易卡住的点：

- 找不到开发者选项 → 版本号没点够次数，或菜单藏在「全部参数」里（小米等机型需在「全部参数」里点 MIUI 版本）；
- 列表里没有 Fake Location → 应用没装好或列表要刷新，重开一次开发者选项；
- 选完仍不生效 → 免 ROOT 只改 GPS 这一路，目标应用若走 WiFi/基站混合定位就拦不住，转 ROOT 模式。

## 三、ROOT 模式设置要点

ROOT 模式没有统一的「下一步」，因为它取决于你用哪套 root 方案，但流程骨架一致：

1. 确认设备已获取 root 权限（Magisk 是目前最常见的方案）；
2. 允许 Fake Location 请求 root 授权；
3. 确认 **SELinux 可以被切到宽容模式**——部分品牌（典型如华为较新的 EMUI 内核、三星带 KNOX 限制的机型）内核层面禁掉了这个能力，这类设备 ROOT 模式跑不通，只能换第三方内核/ROM；
4. 在 Fake Location 里把运行模式切到 ROOT，再启动模拟。

用 Magisk 的话有两个实测高频的坑（官方 FAQ 明确列过）：

- **不要在 Magisk Hide（现多写作 Zygisk DenyList）里勾选 Fake Location**——勾了它拿不到 root，表现就是启动模拟后一直转圈在等授权；有的机型还要保持 Magisk 在后台运行；
- 部分机型需要在 Magisk 设置里暂时关闭 Hide/DenyList 才能正常授权。

老版本（1.2.0 以前）ROOT 模式还要求 System 分区可写，需要 Syslock 或 Magisk 解锁分区；**1.5.2 已不需要这一步**，不用照老教程折腾。

## 四、跟模式相关的开关

配好模式后，ROOT 模式下还有几个开关会影响表现（位置在软件的设置页与位置模拟页）：

- **GPS 信号模拟 / 增强位置模拟**：目标应用检测较严时开；
- **基站模拟**：目标应用报「定位失败 / 获取位置信息失败」时，多半在用基站定位，去位置模拟页把「基站」打开；
- **Xposed 兼容**：内核是 6.1.x 或与其他 Xposed 模块冲突导致重启时打开；
- **SELinux 自动恢复**：关闭模拟时自动把 SELinux 切回强制模式，建议开着，减少长期处于宽容模式的风险。

这些开关的具体使用场景，展开在 [虚拟定位怎么用.md](虚拟定位怎么用.md) 与 [常见问题与错误码排查.md](常见问题与错误码排查.md)。
