## 一、这是什么软件

Fake Location 是一款安卓平台上的位置模拟工具，开发者是 Lerist（官方站点为 [lerist.github.io/FakeLocation](https://lerist.github.io/FakeLocation/)，代码发布在 GitHub 的 [Lerist/FakeLocation](https://github.com/Lerist/FakeLocation)）。官方把它定位为给开发人员做位置相关功能调试用的工具，同时也被大量普通用户用来在社交、地图类应用里测试虚拟位置。

你需要知道的三件事：

- 它**不是装上就能用**：首次启动后还要给系统授权（免 ROOT 模式要在开发者选项里选「模拟位置信息应用」），见 [ROOT与免ROOT模式设置.md](ROOT与免ROOT模式设置.md)；
- 它分**免 ROOT 与 ROOT 两种运行模式**，效果差别很大，官方说明免 ROOT 模式只对少数应用有效；
- 部分高级功能（GPS 信号模拟、基站模拟、反检测等）挂在 ROOT 模式或专业版上，见 [专业版与使用限制.md](专业版与使用限制.md)。

## 三、从网盘获取安装包

1. 打开 [Fake Location 安装文件资源（夸克网盘）](https://pan.quark.cn/s/008346c4c4f0)；
2. 转存到你自己的网盘后，找到 `Fake Location_v1.5.2.apk`；
3. 下载到手机（或先下到电脑再传手机），**不要用下载站的「高速下载器」**，那类下载器会先装一个应用市场。

想校验文件没下坏，可以在电脑上算一次 MD5，与上表的 `45cf4234779663de36daae775a320285` 比对；不一致说明文件不完整或被替换过。

## 四、安装步骤

1. 在手机上点击 APK 文件开始安装；
2. 系统会弹出「是否允许安装未知应用」，给浏览器或文件管理器授予该权限后继续；
3. 安装完成后先**不要**急着打开，先按 [ROOT与免ROOT模式设置.md](ROOT与免ROOT模式设置.md) 把运行环境配好，再回来启动。

若安装阶段就报错（解析包失败、安装包损坏），一般是下载不完整——重新下载一次即可；若报「应用未安装」，先确认手机剩余空间与是否已装过同包名的不同签名版本（卸载旧版再装）。

## 五、首次启动

1. 打开 Fake Location，首次运行会请求**位置权限**与（部分机型上的）后台运行权限，建议都允许——位置权限是它工作的前提，后台权限决定模拟会不会被系统中途杀掉；
2. 允许「修改系统设置」类权限（ROOT 模式会用到）；
3. 回到主界面，你会看到位置列表与右侧的 `+` 号按钮，说明可以开始选点了，接下去见 [虚拟定位怎么用.md](虚拟定位怎么用.md)。

如果一启动或一点「启动模拟」就卡住不动，先看 [常见问题与错误码排查.md](常见问题与错误码排查.md)。
