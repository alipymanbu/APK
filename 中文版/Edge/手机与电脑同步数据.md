## 一、登录微软账户，开启同步

同步的前提是**手机端和电脑端登录同一个微软账户**：

1. 手机上打开 Edge，点底部菜单 →「**设置**」→ 顶部「**帐户**」（或直接点设置页顶部你的头像位置）；
2. 登录微软账户（outlook/hotmail/live 邮箱即可，没有可以现注册）；
3. 进入「**同步设置**」→ 打开「**同步**」，在「**数据项**」里按需勾选：收藏夹、密码、地址等。

电脑端（Windows 上的 Edge）同样用这个账户登录并保持同步开启即可。两边数据项都勾上后，手机上收藏一个网页，电脑收藏夹里几秒到几分钟内出现；电脑上存过的密码，手机登录表单里可以直接填充。

## 二、能在设备间同步什么

| 数据 | 手机 ↔ 电脑同步 | 说明 |
| --- | --- | --- |
| 收藏夹 | 支持 | 最常用的同步项 |
| 密码 | 支持 | 手机上可调用电脑端已存的密码 |
| 打开的标签页 | 支持 | 电脑端可在「标签页」里看到手机当前开着的页面 |
| 集锦（Collections） | 支持 | 需在同步设置里单独勾选「集锦」数据项 |
| 主页、搜索引擎等本机设置 | 不同步 | 换设备需重设，见[主页与搜索引擎设置.md](主页与搜索引擎设置.md) |

同步报错或长时间不刷新时，官方建议的诊断入口是 `edge://sync-internals`——在地址栏输入后回车，可以查看同步状态与出错原因，排查步骤见[常见问题排查.md](常见问题排查.md)。

## 三、用 Drop 在手机与电脑之间传文件

Edge 里有个叫 **Drop** 的功能，位置一般在底部菜单侧栏或「…」菜单里，作用类似一个挂在你账户下的中转站：

- 手机端把图片、文件丢进 Drop → 电脑端 Edge 的 Drop 面板里直接取；
- 反过来，电脑传给手机也一样；
- 还支持随手记几条文字便签。

对偶尔传一张截图、一段链接的场景，它省去了微信文件传输助手那一步；大文件走的是云端中转，速度受网络影响。Drop 属于账户功能，两端都登录同一账户才可见。

## 四、集锦的用法

集锦是 Edge 特有的整理工具，比收藏夹更适合「按主题打包一堆网页」：

1. **新建**：菜单 →「**集锦**」→ 右上角「+」→ 起名 →「创建」；
2. **加内容**：浏览到某网页时，菜单 →「**添加到集锦**」→ 选目标集锦；或在集锦抽屉打开时点「+」把当前页存进去；
3. **边看边对照**：把集锦抽屉往下拖到半屏，点集锦里的条目，右侧页面照常浏览，集锦不收起——做调研、比价、凑资料时这个形态最顺手；
4. **同步**：设置 → 帐户 → 同步设置 → 数据项里开启「集锦」，手机加进集锦的网页电脑上也能看到。

集锦里的条目可以拖动重新排序（长按或点条目上的「…」→「重新排序」），配合同步用，可以做到「电脑上收集资料、路上手机接着看」。

## 五、换手机时怎么搬数据

旧手机登录了账户且同步正常的情况下，新手机装好 Edge（安装步骤见[下载与安装教程.md](下载与安装教程.md)）→ 登录同一账户 → 开同步 → 等待数据拉取完成。收藏夹、密码、集锦会自动到位；微信、支付宝这类第三方应用的数据不在浏览器同步范围内，与 Edge 无关。
