## 一、先知道现状：手机端扩展和电脑端不是一回事

Edge 是 Chromium 内核，理论上桌面扩展都能兼容，但**安卓版目前走的是「官方筛选白名单」的路子**：内置一个精选扩展列表，数量只有二三十个量级，你在列表里选装即可，跟电脑端动辄上千个商店不能比。这个数量与名单随版本推进会有变化，以你浏览器里实际显示的为准。

已支持的功能方向大致有：广告拦截类、深色模式类、翻译类、油猴脚本管理类等。广告拦截不用扩展也能开（内置内容阻止程序，见[主页与搜索引擎设置.md](主页与搜索引擎设置.md)），装扩展是为了更强的规则或更多功能。

## 二、正式版装扩展：内置扩展页

1. 打开 Edge，点底部菜单按钮（三条横线）；
2. 找到「**扩展**」入口（不在首屏时左右滑动菜单页找一下）；
3. 列表里浏览，点目标扩展 →「获取」安装；
4. 装完回到同一页面可以管理开关。

就这么多——安卓版只认这个内置入口，不用也不需要登录账户即可装扩展。

## 三、「与你的浏览器不兼容」是怎么回事

在手机浏览器里打开微软 Edge 扩展商店网页（`microsoftedge.microsoft.com/addons`），点扩展详情页的「获取」按钮时，会弹出「与你的浏览器不兼容」——**这不是故障**。那个「获取」按钮面向的是电脑端 Edge；安卓版不允许从商店网页直接拉起安装，只认第二节说的内置扩展页。

换句话说：你在商店网页上看到某个扩展手机上装不了，不代表它坏了，只代表它不在移动端白名单里。

## 四、想装白名单之外的扩展

社区里流传的变通路线都需要**另一个渠道版本**（Beta 或 Canary，微软官方的测试版应用，与正式版是两个独立应用、可并存），且用到的开关属于实验功能，随时可能变动：

- **扩展搜索开关**：在地址栏输入 `edge://flags`，搜索 `edge-extensions-search` 并启用，重启后扩展页顶部会出现搜索框，可以搜到并安装商店里几乎全部桌面扩展。据公开报道该开关出现在 2025 年 11 月前后的 Beta 版本中，后续版本是否保留、何时进正式版，以官方发布为准。
- **开发者选项按 ID 安装**：在「设置 → 关于 Microsoft Edge」里连续点击版本号数次开启开发者选项；回设置页进入「开发人员选项」，用「Extension install by id」填入扩展 ID（扩展商店网址最后一段字符串）安装。同样仅部分渠道版本可用。

两条路线都写在这里只作为「现状说明」，请注意两点：一是实验功能可能导致浏览器不稳定，主力机谨慎尝试；二是移动端对扩展的兼容参差不齐，装上能用不等于用起来和电脑端一样。

## 五、装完不生效、找不到入口

- 部分扩展装完**不会**在浏览界面挂可见按钮，管理要看「扩展」页里的开关是否已开；
- 扩展崩溃或页面异常时，先在扩展页把它关掉再刷新页面；仍异常就卸载后重装；
- 官方会自动禁用试图篡改浏览器默认设置的扩展，被禁用时在「扩展」管理页重新打开开关即可；
- 白名单内都装不上的极端情况，对照[常见问题排查.md](常见问题排查.md)检查版本与存储空间。
