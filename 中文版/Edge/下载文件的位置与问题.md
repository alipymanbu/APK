## 一、默认下载位置：Download 文件夹

未做任何改动的情况下，Edge 安卓版下载的文件保存在手机存储根目录的「**Download**」文件夹（不是「Downloads」，很多手机两个都有，注意区分）。用手机自带的文件管理器进入内部存储，第一层目录里就能看到它。

验证方法（顺便应对个别机型路径不同的情形）：下载一个小文件，记住文件名，在文件管理器里搜这个名字，从文件属性里看到的路径就是你这台设备的实际下载位置。个别机型（部分三星、MIUI 用户有过反馈）默认路径会有出入，用这个办法一次就能定准。

## 二、找不到文件？检查应用私有目录

有些情况下，文件会被下进应用自己的私有目录而不是公共 Download 文件夹：

```text
内部存储/Android/data/com.microsoft.emmx/files/download
```

判断特征：下载列表里能看到文件、进度也正常，但在相册或文件管理器第一层看不到它。用户反馈里出现这个路径的常见背景是历史版本选择了 SD 卡作为存储位置，或该目录已存在。处理办法：

1. 在文件管理器里按上面的路径找到文件，**移动**到公共的 Download 文件夹（相册、文档类应用只扫公共目录）；
2. 之后新下载的文件如果恢复正常，就不用再管；仍进私有目录的话，把 Edge 更新到最新版再看。

顺带一提：这个目录对相册不可见，等于天然的「不在相册里出现」——如果这是你想要的，留着即可；不想要就移动出来。

## 三、「文件已存在，阻止下载」的排查

下载一个从未下过的文件，却提示文件已存在——这是社区里反复出现的反馈，按下面的顺序处理通常能解决：

1. **删掉同名残留**：进 Download 文件夹（或上一节的私有目录）找同名文件，删掉再下一次；
2. **改下载文件名**：Edge 下载时一般可以重命名，换一个名字能绕开冲突判断；
3. **清缓存**：系统设置 → 应用 → Microsoft Edge → 存储 → 「清除缓存」（只清缓存，不要清数据——清数据会连登录态、收藏夹本地缓存一起抹掉）；
4. **更新或重装**：应用商店里检查更新；仍然复现就卸载重装（重装前确认账户同步已开，见[手机与电脑同步数据.md](手机与电脑同步数据.md)）。

如果同样的链接用别的浏览器下载正常、只有 Edge 出问题，多半是站点对同一文件名反复生成所致，换浏览器或改文件名是当下最省事的出路。

## 四、下载列表里打不开文件

Edge 的下载列表（菜单 → 下载）只是个索引，个别机型上点它没反应。不必纠结这个入口：

- 直接去文件管理器的 Download 文件夹里点文件，用对应应用打开；
- PDF、Office 文档装好相应的查看应用后再点开即可。

下载 APK 安装包也是一样的路径：文件落到 Download 后在文件管理器里点它安装，完整流程见[下载与安装教程.md](下载与安装教程.md)。下载记录本身在历史里可查，误关了下载页也不用慌，找回办法见[恢复关闭的标签页.md](恢复关闭的标签页.md)。
