## 一、按键速查表

MATVT 的设计前提是「电视边上的遥控器足够大」。各键分工如下（表里的键名按官方说明）：

| 遥控器按键 | 作用 |
| --- | --- |
| 方向键（DPAD） | 移动光标；中间的确认键 = 鼠标单击（长按也能触发，但官方说明「不太可靠」） |
| 红 / 绿键 | 上滑 / 下滑 |
| 黄 / 蓝键 | 左滑 / 右滑 |
| Info 键 | 立即显示 / 隐藏鼠标指针 |
| BossKey（默认静音键） | 在「方向键模式 → 鼠标模式 → 滚动模式 → 方向键模式」之间循环切换 |

彩色键和 Info 键不是每把遥控器都有 —— 没有的话，BossKey 一个人扛下切换的活，见第三节。

## 二、三种模式分别做什么

- **方向键模式**：光标隐藏，方向键按系统原样响应（选菜单、翻列表），也就是电视本来的用法。
- **鼠标模式**：方向键改成驱动光标 —— 上下左右移动光标，确认键单击。光标停一会儿会自动消失，再按任意相关按键又会出现。
- **滚动模式**：方向键改成滚动页面（上下滑、左右滑对应彩色键的功能）。

每次切换模式，**光标位置会回到起点重置** —— 这是设计行为，不是故障。

## 三、你的遥控器按键不够怎么办

1. **没有彩色键、没有 Info 键**：用 BossKey 切换模式即可。它默认占用**静音键**，可在设置里换到别的键（「覆盖激活键」选项）或让程序自动检测（见[鼠标指针设置与调整.md](鼠标指针设置与调整.md)）。Chromecast、Google TV 这类小遥控器按键本来就少、没有 Info 键，官方把默认值设成静音键就是冲着它们去的 —— 你的遥控器静音键若有别的用途（比如电视直接响应它），就换一个，见[遥控器失灵与故障排除.md](遥控器失灵与故障排除.md)。
2. **遥控器不支持长按**：打开「BossKey 循环切换」选项，每按一次就按顺序换到下一个模式，不依赖长按。
3. **按键充足的全尺寸遥控器**：可以直接关掉 BossKey（「禁用 BossKey」选项），只用 Info 键 + 彩色键操作。

## 四、移动光标的几个手感细节

- **移动带惯性**：按住方向键不放，光标会越走越快 —— 长按一次就能横穿屏幕，不用连按。
- **光标会从屏幕边缘「绕过去」**：光标走到电视右边出去、从左边进来（上下同理），想快速从屏幕一头到另一头直接穿过去就行。这个「穿边」行为可以在设置里关掉（Bordered Window）。
- **鼠标碰到屏幕边缘可以触发滚动**：这个开关也在设置里，打开后光标顶到边缘就开始滚页面。

操作不顺手、想换指针样式或调速度，去[鼠标指针设置与调整.md](鼠标指针设置与调整.md)；按了键完全没反应，则按[遥控器失灵与故障排除.md](遥控器失灵与故障排除.md)逐项排查。

## 五、几点补充

- 官方在项目页放了一个演示视频（[youtu.be/UC7bPw2tG4c](https://youtu.be/UC7bPw2tG4c)），键位不熟可以先看一遍再上手。
- 部分按键（电源、音量、静音这类红外键）是直接发给电视的，不经过安卓系统 —— 应用收不到这些键。这不是 MATVT 的毛病，Chromecast 等设备上尤其明显，处理办法见[遥控器失灵与故障排除.md](遥控器失灵与故障排除.md)。
