## 一、设置界面在哪

MATVT 自带一个图形设置界面（companion GUI）：在电视的应用列表里打开 MATVT 本体，先看到的就是它 —— 改完设置即时生效，不需要重启。键位与模式的含义在[遥控器按键怎么用.md](遥控器按键怎么用.md)，这篇只讲「调什么、调了会怎样」。

## 二、可调的选项一览

| 选项 | 作用 | 什么时候动它 |
| --- | --- | --- |
| 鼠标指针大小（Mouse Size） | 改光标尺寸 | 电视大、坐得远看不清光标时调大 |
| 滚动速度（Mouse Scroll Speed） | 改滚动模式下页面滚动的快慢 | 滚动要么太肉要么刹不住时 |
| 指针图标（Mouse Icon） | 换光标样式，自带亮色与全透明两款 | 背景亮导致看不清指针时换一款 |
| 边框窗口（Bordered Window） | 打开后光标不再从屏幕边缘绕出去 | 你总把光标滑出屏幕找不着时 |
| 禁用 BossKey（Disable Boss Key） | 关掉那个「一键切换」键 | 全尺寸遥控器，靠 Info 键 + 彩色键就够用 |
| BossKey 循环切换（Will Boss Key Toggle） | 每按一次依序切模式：方向键 → 鼠标 → 滚动 | 遥控器不支持长按时 |
| 覆盖激活键（Override Activation Key） | 把 BossKey 指到自定义按键码 | 静音键被电视占用、或你想换个键 |
| 边缘触发滚动（Scrolls when mouse touches the edges） | 光标顶到屏幕边缘自动滚页 | 希望光标「推着页面走」时打开 |
| BossKey 按键码自动检测（Automatically detect boss key code） | 自动找出适合当 BossKey 的键 | 不知道该指定哪个键时先跑它 |

## 三、哪些选项会「缺席」

同一份安装包在不同设备形态下，能看到的选项不完全一样：

- **BossKey 循环切换**：翻盖手机版没有。
- **滚动速度**：Android 6 的翻盖手机上没有。

看不到上表里的某一项，先确认你装的是不是电视版、设备系统版本，别当成安装坏了。

## 四、调不动时的常见原因

设置界面本身用遥控器方向键操作 —— 如果在设置界面里方向键都没反应，多半是授权没做完（指针出不来时同理），按[遥控器失灵与故障排除.md](遥控器失灵与故障排除.md)核对两步授权的顺序；还没装上的话，先走[下载与安装教程.md](下载与安装教程.md)。

改完设置想立刻验证效果：按 Info 键唤出光标，试着横穿一次屏幕 —— 光标从右边出去、左边进来就说明「穿边」还开着；顶到边缘就滚页说明边缘滚动开着。效果和预期相反，回到上表核对对应开关的状态即可。
