# 遥控器失灵与故障排除

> 指针不出现、遥控器按键没反应、部分按键唤不出鼠标时，按场景逐项排查与恢复。

## 一、最凶险的一种：遥控器整体失灵

**症状**：装完后按什么键都没动静，指针也不出现，界面像卡死。

**原因**：授权顺序做反了 —— 先开了辅助功能、后给「显示在其他应用上层」。此时 MATVT 在拦截你的按键，却画不出指针。

**恢复步骤**（官方 FAQ 给的路子）：

1. 找一把**物理鼠标**接上电视（蓝牙鼠标或带接收器的无线鼠标都行）。用键盘也能操作，但步骤繁琐得多。
2. 用鼠标进「设置 → 辅助功能」，**关闭** MATVT 的服务。
3. 回到「特殊应用权限 / 显示在其他应用上层」，确认 MATVT 的开关是打开的。
4. 顺序理顺后再重新启用辅助功能服务 —— 这次先给权限、后开服务，见[下载与安装教程.md](下载与安装教程.md)第四节。

官方特别提醒：装完**先给权限、再开辅助功能**，就是为了避开这一幕。真中招了也有救，别慌。

## 二、指针不出现（但遥控器正常）

按这个清单核对：

1. 「显示在其他应用上层」是否已给 MATVT 打开；
2. 「辅助功能」里 MATVT 的服务是否已启用；
3. 唤出方式对不对 —— 按 **Info 键**，或按你指定的 BossKey（默认静音键）。没有这两个键的遥控器，先去[鼠标指针设置与调整.md](鼠标指针设置与调整.md)把 BossKey 指到一个有的键上；
4. 指针可能只是**自动隐藏了**：闲置一会儿它会消失，按任意相关按键会再次出现 —— 这不是故障。

## 三、某个键唤不出鼠标

典型场景是 Chromecast 这类设备：电源、音量、静音这些键走的是**红外通道，直接控制电视**，根本不进安卓系统，MATVT 收不到。这不是应用坏了，而是按键压根没送到它手上。

- Chromecast 里有一项「控制 Chromecast 音频而非电视音频」的设置，改过去后部分按键就能被系统收到（以设备当时界面为准）；
- 只要方向键、确认键这类走系统通道的键还灵，就用它们 + 你设定的 BossKey 操作，不必执着于某个红外键。

## 四、看着像 bug、其实是设计的几件事

| 现象 | 说明 |
| --- | --- |
| 切换模式后光标跳回原点 | 每次切换都会重置光标位置，正常 |
| 按一下光标不动、长按才行 / 长按点击时灵时不灵 | 官方说明方向键长按触发点击「不太可靠」，点按优先用确认键单击 |
| 光标从屏幕边缘消失了 | 「穿边」开着 —— 它会从另一侧绕回来；不想要就打开 Bordered Window（见[鼠标指针设置与调整.md](鼠标指针设置与调整.md)） |
| 静音键被系统或别的应用先响应 | BossKey 默认占静音键，被占用就换个键（覆盖激活键 / 自动检测） |
