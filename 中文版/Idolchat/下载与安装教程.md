Idolchat 是一款 AI 角色扮演聊天应用，登录账号后与设定好的角色持续对话。本篇面向拿到安装包、准备在安卓手机上装起来的人：先对清这份包对应哪个版本与包名，再走一遍安装和首次启动，最后给一张装不上时的排查表。

## 一、先对一遍这几个值

搜「Idolchat」能看到不止一个版本号，商店里显示的是官方最新版，而这份文档所配的安装包是另一版。装之前先把下面这张表对一遍，**认包名和体积，版本号不用纠结**：

| 项目 | 值 |
| --- | --- |
| 应用名 | Idolchat |
| 版本 | 2.0.5 |
| 包名 | `com.aiidolchat.app` |
| 安装包体积 | 60.76 MB |
| 安装包 MD5 | `A95DEB435D064990009A49887FCDD5D6` |

同一款应用在 iOS 与安卓上的安装包体积不一样（App Store 页面显示约 70.5 MB），所以「商店写着 70 MB、你下到的是 60 MB」不是下错了包。iOS 与安卓怎么区分，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

还有一处版本差要提前说清：官方在 2026 年 8~9 月答复用户时提到的版本已经到 2.0.59，其间陆续加过角色语音、应用锁、界面自定义、聊天指南这些功能。**本文所配的这份是 2.0.5，不含后来加入的这些功能** —— 打开后找不到某个设置，不是包坏了，是这个版本还没有。想要新功能去官方商店更新；网盘那份不会跟着变。

三条结论先记住：

- 认包名 `com.aiidolchat.app`，别只看版本号；
- 安卓这份 60.76 MB，iOS 那份约 70.5 MB，体积不同是正常的；
- 装完先过一遍应用内的聊天指南，界面里的设置项一次就清楚了（见 [界面外观与聊天设置怎么调.md](界面外观与聊天设置怎么调.md)）。

## 二、把安装包拿到手机

安装包在 [Idolchat 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6d5eb4605fcd) 里，文件名形如 `Idolchat_v2.0.5.apk`。两种取法：

1. **手机端**：在夸克 App 里打开这个分享链接 → 先转存到自己网盘 → 再从网盘下载到手机；
2. **电脑端**：先下载到电脑，用数据线或聊天软件把 `.apk` 传到手机。

不要边下边装。下载过程中断过、或者被浏览器拦过，安装时大概率报「解析包错误」，只能重下。

## 三、安装步骤（安卓）

1. 下载完成后，在「文件管理 → 下载」里找到那个 `.apk` 文件；
2. 点它安装。如果系统弹「出于安全考虑，已阻止安装」，去「设置 → 应用 → 特殊应用权限 → 安装未知应用」，把刚才点开的那个应用（浏览器或文件管理器）的权限打开，再回去点一次；
3. 小米、OPPO、vivo 这类系统还会额外过一次自家安全检查，按提示选择继续安装即可；
4. 装完回桌面找图标，首次打开需要联网。

安装过程要临时解包，**手机可用空间建议留到安装包体积的两倍以上**（这份包约 60.76 MB，留 200 MB 以上更稳）。

## 四、装之前核对一下安装包

不怕麻烦的话，比对一次 MD5，能提前排掉「下载被截断」和「拿到了别人改过的包」两种情况。

Windows 上打开 PowerShell，把路径换成你实际的下载位置：

```powershell
certutil -hashfile "D:\下载\Idolchat_v2.0.5.apk" MD5
```

输出应当与下面一致（大小写不敏感）：

```text
a95deb435d064990009a49887fcdd5d6
```

手机上装一个哈希校验类应用，对着第 1 节表里的 MD5 比一遍，效果相同。

## 五、第一次打开要做三件事

| 顺序 | 做什么 | 说明 |
| --- | --- | --- |
| 1 | 看语言 | 界面默认多为中文；若是外文，进设置找语言（Language）项切成「简体中文」 |
| 2 | 登录 | **不登录无法进入聊天**。登录方式以应用内实际提供的为准，官方隐私政策里登记的账号信息是邮箱、昵称与头像 |
| 3 | 看年龄提示 | 官方在 App Store 把本应用标为 18+，未成年人不要使用 |

登录与账号相关的细节（换手机、注销、聊天记录归属）单独写在 [账号登录与聊天记录隐私.md](账号登录与聊天记录隐私.md)。

## 六、装不上、装完打不开：按顺序查

| 现象 | 大概率原因 | 处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整 | 删掉重下，下完再按第四节比一次 MD5 |
| 提示「应用未安装」或「与已有应用冲突」 | 手机上已装过同包名的版本，签名不一致 | 先卸载旧版再装。**卸载会清掉本机聊天记录**，确认不心疼再动手 |
| 点安装没反应、没有反应窗口 | 未知来源安装权限没开 | 见第三节第 2 步 |
| 装完一点图标就退回桌面 | 系统版本过低或系统组件过旧 | 先把系统更新到当前机型可用的最新版 |
| 提示空间不足 | 可用空间不够解包 | 清理空间后重装，不要求助各种「清理大师」 |
| 装上了、一进就提示连接错误 | 网络或线路问题 | 见 [常见问题与排查.md](常见问题与排查.md) |

装的过程顺利、用起来出问题的，直接跳到 [常见问题与排查.md](常见问题与排查.md)；装完不知道该干什么的，从 [怎么找角色和开始聊天.md](怎么找角色和开始聊天.md) 开始看。
