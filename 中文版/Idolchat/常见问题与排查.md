装完之后真正卡住人的，多数是登录、消息发不出去、订阅没生效这几类问题。本篇按「现象 → 先查什么 → 怎么办」组织，适合已经装上、某个功能不按预期工作的人，也适合准备向官方反馈前先自查一遍。

## 一、先按现象对号

| 现象 | 属于哪一类 | 跳到哪一节 |
| --- | --- | --- |
| 登不上去、登录后又被退回登录页 | 账号 | 第二节 |
| 消息发不出去、提示连接错误、一直转圈 | 网络 | 第三节 |
| 界面变成外文，找不到中文在哪 | 语言 | 第四节 |
| 扣了钱但会员没生效、订阅状态显示不对 | 订阅 | 第五节 |
| 角色答非所问、忘了设定、人设漂移 | 角色表现 | 第七节 |
| 头像、壁纸、语音加载不出来 | 界面元素 | 第六节 |
| 装不上、装完闪退 | 安装 | [下载与安装教程.md](下载与安装教程.md) 第六节 |

排查的通用原则：**先重启应用 → 再换网络 → 再更新版本 → 最后找官方**。绝大多数一次性的报错，前两步就能消掉。

## 二、登录相关

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 点登录没反应、界面不动 | 登录页依赖网络，弱网下会静默失败 | 换到稳定的 Wi-Fi 再点一次 |
| 登录成功了，进下一屏又被弹回登录页 | 应用没能把登录态保留下来 | 应用内退出登录 → 重新登录；仍不行就清一下应用缓存（不是清数据） |
| 换手机后登进去是空的 | 登的账号与原来不是同一个 | 回旧手机确认原来用的登录方式，再用同一种方式登 |
| 第三方登录页打不开 | 该登录方式的页面被网络环境影响 | 换网络；或换用应用内提供的其他登录方式 |

登录必须做——这个应用没有游客模式，登不上就等于用不了。

## 三、网络与连接错误

「连接错误」是这个应用里被用户公开点过名的现象（App Store 评论里有人专门提过），特点通常是**时好时坏**，而不是彻底不通。按顺序试：

1. **换网络**：Wi-Fi 与移动数据互换一次。这一步通常最有效；
2. **关掉代理类工具**：VPN、加速器、以及手机里的全局代理，都可能导致请求被中间环节截断。这条对「能刷列表、但一发消息就报错」的情况尤其有效；
3. **彻底重开应用**：从后台把应用划掉再进，而不是只按返回键；
4. **换时段用**：如果连续几天都在同一时段出错，错开半小时再试，多半是那一侧拥堵；
5. **换个模型或角色试**：只在一个角色上出错，问题可能在那一侧的设定或会话数据，而不是你的网络——这种情况下新建一个会话通常能恢复。

消息卡在"发送中"不动的，先别连点发送键，连点容易产生多条重复消息，也会让后续几轮更容易乱。

**官方对「发消息报错 / 连接错误」的正面答复**（比第三方猜测可靠）：一是中国大陆地区的网络环境会拦截部分海外服务，导致偶发连接不稳定；二是请用户先更新到最新版本，若仍然报错，把**报错截图**发到客服邮箱 `tangerinlabs@gmail.com`。按这个口径反馈最快，比在商店评论区描述有效。

## 四、界面语言不对

界面默认多为中文。如果你看到的是外文：

1. 打开应用内的设置（通常在侧边栏或底部导航里）；
2. 找语言 / Language 这一项；
3. 选「简体中文」，返回后确认首页已经变过来。

装在安卓机上首次启动就是中文的居多；如果你装的那份进去是英文，可能是安装包的默认语言跟系统语言不一致，手动切一次即可，不影响使用。

## 五、订阅与内购相关

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 扣款了但会员没生效 | 商店回执有延迟，或登录的应用账号与购买账号不一致 | 先重启应用；确认应用内登录的账号就是购买时用的那个；等 10 分钟后仍未生效，走商店申诉 |
| 不想续费但已经扣了下一期 | 自动续费没在到期前 24 小时关掉 | 先按 [会员订阅和语音金币怎么算.md](会员订阅和语音金币怎么算.md) 第四节关掉续费，再走平台退款申请 |
| 语音金币买了没到账 | 同"扣款没生效" | 同上，退款与到账问题都归商店渠道管 |
| 想降到便宜档 | 改档一般在下一周期生效 | 在商店的订阅管理里改，当期不退差价 |

## 六、界面元素加载不出来（头像、壁纸、语音）

官方更新说明里出现过这几个修复项：「修复了角色头像和壁纸无法加载的问题」「修复角色语音卡顿问题」「修复角色语音切换设置」，同时也上线过「角色语音」功能。所以碰到这几类问题，顺序是：

1. **先更新版本**——这些都是官方修过的老问题，在旧版本上折腾没意义；
2. 换网络再进一次（成因和第三节一致，多为资源请求被拦）；
3. 语音相关：进聊天设置确认语音没被关掉、也没有落在空音色上；
4. 更新到最新版仍不正常，按第八节把版本号、机型和截图一起发给客服邮箱。

头像、壁纸、气泡外观这些设置项在哪一层，见 [界面外观与聊天设置怎么调.md](界面外观与聊天设置怎么调.md)。

## 七、角色表现不对

| 现象 | 一般不是 bug，而是 | 处理 |
| --- | --- | --- |
| 忘了称呼、忘了之前聊过的事 | 会话上下文已经滚出记忆范围 | [长对话久了角色失忆怎么办.md](长对话久了角色失忆怎么办.md) 第三、五节 |
| 人设突然飘了、语气变了 | 角色卡写得含糊，或中途换过模型 | 回 [怎么创建自己的AI角色.md](怎么创建自己的AI角色.md) 第四节对照检查 |
| 回复越来越短、越来越敷衍 | 会话里负面或重复的指令攒多了 | 新建会话，开场重新交代关系与场景 |
| 只在一个角色上出问题 | 那一份角色卡本身有冲突 | 换一个同题材的角色对比，确认为角色卡问题就改卡 |

## 八、什么时候该找官方，反馈要带什么

上面几步都试过仍不行的，用官方邮箱 `tangerinlabs@gmail.com` 反馈。为了让对方一次就能定位，把这几项一次写全：

- **版本号**：本文所配的安装包是 2.0.5；
- **包名**：`com.aiidolchat.app`；
- **机型与系统版本**：例如「小米 14，Android 15」；
- **发生的具体时间**：几点几分，方便对方查日志；
- **复现步骤**：从哪一步开始、点了什么、出现什么；
- **报错原文**：把提示文字照抄一遍，不要只写"报错了"。

如果你拿到的版本号和上面不同，先确认装的是不是同一个应用，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
