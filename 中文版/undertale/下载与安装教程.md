## 一、这份安装包是什么

动手前先对一遍信息，确认你下对了文件：

| 项目 | 内容 |
| --- | --- |
| 包名 | `com.jockeholm.undertale` |
| 版本号 | 2.0.0 |
| 安装包大小 | 144.10M |
| MD5 | `8588624b5a7482c3f399950d0b139cf5` |
| 界面与对白语言 | 中文 |
| 系统要求 | Android 5.2 及以上（下载页标注，以实际安装提示为准） |

两个容易混淆的点：

- 这里的 **2.0.0 是这个安卓安装包的版本号**，不是游戏本身的版本号。原作由 Toby Fox 开发，官方信息以 [undertale.com](http://undertale.com) 为准，PC 与主机端各有自己的版本节奏。
- 这个包不在 Google Play 上架，`com.jockeholm.undertale` 就是它在安卓系统里的唯一身份；装完后在「设置 → 应用」里看到的名称也以包信息为准。

## 二、下载安装包

1. 打开 [Undertale 安装文件资源（夸克网盘）](https://pan.quark.cn/s/601844ac005a)。
2. 把里面的应用文件夹**转存到自己的网盘**（手机上装了夸克会更顺手），或者直接下载。
3. 下载得到一个 `.apk` 文件，文件名形如 `undertale_v2.0.0.apk`（以网盘内实际显示为准）。

建议用 Wi-Fi 下载：安装包 144.10M，装进手机后占用还会更大，动手前先确认设备有几百 MB 的余量。

## 三、安装

1. 在文件管理器里点这个 `.apk`。
2. 如果系统弹出「禁止安装未知来源应用」这类提示，按它给的入口授权（一般是「设置 → 安全/隐私 → 允许安装未知来源」，不同品牌路径略有差别，跟着提示走即可）。
3. 装完点「打开」进游戏。首次启动若询问存储相关权限，建议允许 —— 存档要往手机里写数据，拒绝了可能存不上（见[常见问题与排查.md](常见问题与排查.md)）。

## 四、核对文件完整性（可选）

如果你是在电脑上下载的，可以在 PowerShell 里算一遍 MD5：

```powershell
certutil -hashfile undertale_v2.0.0.apk MD5
```

输出与上面表格里的 `8588624b5a7482c3f399950d0b139cf5` 一致，说明文件完整、没有下残；对不上就重新下载一次。

## 五、装好之后

第一次进游戏会有语言、按键透明度之类的可调项，接着就是起名开局。这些连同屏幕上的摇杆、按钮各管什么，都在[新手入门与操作指南.md](新手入门与操作指南.md)里讲。
