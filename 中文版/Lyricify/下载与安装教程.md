## 二、从哪获取安装包

两个来源，按需选：

- **本文配套的安装包**：Lyricify 安装文件资源（夸克网盘）：[https://pan.quark.cn/s/769f074badf4](https://pan.quark.cn/s/769f074badf4)，即 1.4.3 版。下载后可以用第一节表格里的 MD5 值核对文件完整性。
- **官方渠道**：[lyricify.app/download](https://lyricify.app/download/)，安卓平台下载得到的是 `.apk` 安装包，想用最新版从这里拿。

## 三、安装步骤

1. 从上面任一来源拿到 `.apk` 文件，在手机上点开。
2. 系统可能提示「允许安装未知来源应用」，按提示允许一次即可（不同品牌手机的入口名称略有差异，一般在弹窗里直接给开关）。
3. 等待安装完成，打开应用。

安装本身没有额外依赖，不需要先装别的运行库。

## 四、装完第一件事：登录 Spotify 账号

Lyricify Mobile 打开后进不了歌词界面，会先要求你完成 Spotify 账号的登录授权——它显示的歌词跟着你的 Spotify 播放走，没有授权就拿不到播放信息。正常流程和几种报错的处理方法写在 [Spotify账号登录授权.md](Spotify账号登录授权.md)。

另外提醒一句：Spotify 在中国大陆没有服务，账号、网络访问条件都需要你自行准备，这不是安装能解决的问题。

## 五、1.4.3 与更新版本的差别

你不需要立刻追求最新版，但下面这个差异要知道：

- 官方文档提到，由于 Spotify 调整了登录机制，「跳转浏览器登录」需要 1.5.0 或更新版本才支持；旧版的内嵌网页登录在新机制下可能失效（以官方文档的最新说明为准）。
- 所以如果你在 1.4.3 上登录时反复遇到 `INVALID_CLIENT: Invalid Redirect URI` 这类报错，先考虑去[官方下载页](https://lyricify.app/download/)换最新版，再回来试一次。

登录走通了但日常用着被限流（429 报错、切歌迟钝），那是另一类问题，处理方法见 [429错误与自定义API配置.md](429错误与自定义API配置.md)；其他日常小毛病汇总在 [常见问题排查.md](常见问题排查.md)。

## 六、认准官方渠道，避免装到同名仿冒

在应用商店或搜索引擎里搜「lyricify」，会出来一批名字相近的应用（比如 Lyrify、LyrifyAI 等），它们是**别的开发者**的作品，与本文说的 Lyricify 无关。安装前核对两点：

- **安卓侧看包名**：本文这款的包名是 `com.wxriw.lyricifymobile`，对不上就不是它；
- **只从官方发布渠道拿**：[官方下载页](https://lyricify.app/download/) 和官方的 GitHub Releases 页面是官方的发布入口。

如果你还想同时了解电脑版（Lyricify 4）与手机版的差别再决定装哪个，见 [电脑版与手机版怎么选.md](电脑版与手机版怎么选.md)。

## 七、想升级到新版本时

网盘里这份固定是 1.4.3。想换新版：去[官方下载页](https://lyricify.app/download/)或 GitHub Releases 下载新的 `.apk`，一般可直接覆盖安装（同名应用的新版安装包，系统按升级处理）。装完如果要求重新登录，按 [Spotify账号登录授权.md](Spotify账号登录授权.md) 再走一遍授权就行。
