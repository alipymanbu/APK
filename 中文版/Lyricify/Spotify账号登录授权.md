## 一、为什么必须登录 Spotify 账号

Lyricify Mobile 没有内置播放器，它显示的是你 Spotify 账号「正在播放」的那首歌的歌词。没有授权，它就拿不到你的播放信息，停在欢迎界面进不了歌词页。所以顺序是：先装好应用（见 [下载与安装教程.md](下载与安装教程.md)），再在这里完成授权，然后才有后面的一切使用。

## 二、正常登录流程

1. 打开 Lyricify Mobile，会弹出 Spotify 的登录网页。
2. 在网页里输入你的 Spotify 账号密码并同意授权。
3. 回到应用，进入歌词界面，登录完成。

大部分设备按这三步就能走通。走不通时，对照第三节的表找原因。

## 三、登录报错对照表

| 你看到的提示 | 直接原因 | 处理 |
| --- | --- | --- |
| 糟糕！出了点问题 | 网络访问不到 Spotify | 解决网络访问问题（Spotify 在中国大陆没有服务，需自备可用的国际网络环境，这也是官方文档给出的方向） |
| INVALID_CLIENT: Invalid Redirect URI | 授权跳转地址对不上，或版本过旧 | 见下方说明 |
| connection closed | 网络中断 | 检查网络后重试 |
| invalid_grant | 授权凭据失效 | 重新走一遍登录 |

关于 `INVALID_CLIENT: Invalid Redirect URI`，按顺序排查：

1. 如果你配置过自定义 API Client，检查两条 Redirect URI 是否都正确填写（完整要求见 [429错误与自定义API配置.md](429错误与自定义API配置.md)）。
2. 没配置过 Client 仍报这个错，多半是版本与 Spotify 新机制的兼容问题：官方文档要求 1.5.0 或更新版本并使用「跳转浏览器登录」。你如果用的是 1.4.3，先去官方下载页换新版再试。

## 四、网页登录走不通时的手动 Token 方式

授权页怎么都打不开或授权完回不来时，可以手动填 Token。Lyricify Mobile 在「登录中」页面下方留了入口：

1. 出现「登录中」页面时，点下方的「取消」按钮，界面会出现 3 个文本框。
2. 如果你电脑上装着 Lyricify 4 且已登录：打开它的主菜单（左上角 `···`），进入「高级」，点「复制 Refresh Token」，把复制到的内容粘贴到第 3 个文本框（Spotify Refresh Token），点「继续」。
3. 如果你手头有另一台已登录的 iPhone、iPad 或安卓设备：在那台设备上打开 Lyricify Mobile，同样点「取消」调出 3 个文本框，把三个框的内容一一对应复制到这台设备上，点「继续」。

两个前提别搞混：手动填 Token 的内容来自「已经完成过授权的设备」，没有任何一个框是让你现场凭空填账号密码的。

## 五、多设备的授权

同一个 Spotify 账号可以在多台设备上登录 Lyricify Mobile，互相不影响。但如果你在多台设备上高频使用，后续可能更容易撞上 Spotify 的请求限流（429），到时可以为每台设备单独配一个 API Client，做法见 [429错误与自定义API配置.md](429错误与自定义API配置.md)。

## 六、还没有 Spotify 账号

Lyricify Mobile 只认 Spotify 账号，没有账号的话先去 [Spotify 官网](https://www.spotify.com/) 注册一个（注册环节以 Spotify 官方页面为准）。两件事要提前有数：

- Spotify 在中国大陆没有服务，注册和使用都需要自备可用的国际网络环境；
- 免费账号与 Premium 订阅在使用体验上的差别，见 [电脑版与手机版怎么选.md](电脑版与手机版怎么选.md) 第三节——看歌词不受影响，但撞上限流想配自定义 API Client 时需要 Premium。
