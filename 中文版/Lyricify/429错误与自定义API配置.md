## 一、429 是什么、算谁的锅

429 是 Spotify 服务器返回的「请求过多」错误——你的请求被限流了。这不是你操作错了，也不是 Lyricify 坏了：所有走公共入口的用户共享同一份请求配额，用的人多时就会撞上。

它的两种典型表现：

| 形态 | 现象 | 直接原因 |
| --- | --- | --- |
| 普通 429 | 偶尔弹出 429 报错，过一会儿自己好了 | 短时请求量超了配额 |
| 超长 429 | 报错提示的等待时长达到几千甚至几万秒 | 连续使用时间过长，或没放歌时长时间挂着 |

## 二、两条处理路径

**路径一：等。** 普通 429 等一会儿就恢复，代价最小，适合偶尔撞一次的人。

**路径二：配置自定义 API Client。** 配好之后你用的是自己的请求配额，不再和公共入口抢，官方文档明确说这能消除 429 对使用的影响。配置方法在第三节，但它有几个前提（Premium 订阅要求、近期的兼容性问题），先读完第三节再决定要不要做。

你的 Spotify 账号如果没有 Premium 订阅：自定义 Client 这条路你走不了，借用有 Premium 的朋友的 Client 是唯一替代（官方口径）。借不到的话，就只剩「等」这一条路。两个版本在免费账号上的完整差异对照见 [电脑版与手机版怎么选.md](电脑版与手机版怎么选.md) 第三节。

超长 429 另有专门处理：等它结束，或者新建一个 Client 重新登录授权。预防它的三条建议放在第四节。

## 三、自定义 Spotify API Client 配置

### 配之前先看这三条限制

1. **需要 Spotify Premium 订阅**。官方口径：自 2026 年 3 月 9 日起，此前已完成配置的用户同样必须持有 Premium，否则不能继续使用自定义 Client。没有 Premium 但朋友有，可以借用对方创建的 Client（一个 Client 最多供 5 位用户使用，见本节末尾）。
2. **兼容性提示（截至 2026-09 的官方文档口径）**：2026 年 2 月 11 日之后创建的 Client 会导致 Lyricify Mobile 异常，官方建议暂时不要用新建的 Client，等后续更新适配。这条与「推荐自定义 Client」同出于官方文档，两边并列给你，动手前以官方文档的最新说明为准。
3. **Redirect URI 必须逐字正确**，这是配错最多的地方，写在步骤里。

### 创建步骤（在电脑浏览器里做）

1. 浏览器登录 [Spotify](https://www.spotify.com/)。
2. 打开 [Spotify Developer Dashboard](https://developer.spotify.com/dashboard)。第一次打开需要先同意开发者条款：勾选同意项，点 `Accept the terms`。
3. 点页面右上方的 `Create app`。如果提示需要先验证邮箱，先去把 Spotify 账号的邮箱验证做了。
4. 在创建页填写：
   - App name：`Lyricify`
   - App description：`Lyricify Custom API Client`
   - Website：留空
   - Redirect URI：**逐条添加以下两条**，每条填完点 `Add`：
     - `http://127.0.0.1:766/callback`
     - `lyricify://callback`
5. 勾选 `Web API`，勾选同意开发者条款与设计准则，点 `Save`。
6. 页面会显示 `Client ID`；点 `View client secret` 显示 `Client Secret`。两个都记下来。

注意第 4 步：如果你看过旧教程，里面写的可能是 `http://localhost:766/callback`——Spotify 已不接受 `localhost` 写法，必须用 `127.0.0.1` 这个等效地址（2025 年 4 月前创建的老 Client 也需要回 Dashboard 补上这条）。

### 在 Lyricify Mobile 里启用

1. 打开 Lyricify Mobile；如果已经登录过，重新进入登录界面时点「取消」。
2. 在欢迎界面的「自定义 API Client」区域填入 `Client ID` 和 `Client Secret`。
3. 点「登录（获取 Token）」，重新完成一次授权。登录环节遇到报错时回 [Spotify账号登录授权.md](Spotify账号登录授权.md) 对照处理。

### 借用朋友的 Client

对方（持有 Premium 的人）创建好 Client 后，在 Dashboard 进入该 Client 的 `User Management` 页面，填入你的 Spotify 账户姓名与邮箱并点 `Add user`；然后把 `Client ID` 和 `Client Secret` 给你，你在应用里按上面的步骤填入即可。对方的名额满了（5 人）需要先移除一个不再使用的用户。

## 四、日常使用建议（避免再触发 429）

- **没在放歌时，关掉 Lyricify**。挂着不放歌也会持续发请求，几个小时（最短 1~3 小时）就可能触发超长 429。安卓设备要从后台清掉；iOS 和部分安卓设备可以不清。
- **避免连续使用 10 小时以上**，这会明显推高超长 429 的出现概率。
- **多台设备高频使用时，给每台设备单独配一个 Client**，把请求分散开。这节没覆盖到的其他日常现象，去 [常见问题排查.md](常见问题排查.md) 找。
