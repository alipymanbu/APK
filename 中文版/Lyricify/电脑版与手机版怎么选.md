## 一、先分清：你要装的是哪一个

Lyricify 系列面向 Spotify 用户有两个常用版本，都由同一开发者维护（截至 2026-09 的官方页面口径，以官方页面为准）：

| | Lyricify 4（电脑版） | Lyricify Mobile（手机版） |
| --- | --- | --- |
| 平台 | 仅 Windows（64 位 / 32 位 / arm，要求 Windows 7 SP1 或更新） | Android 5.0+ / iOS 8.0+ / iPadOS / visionOS / macOS；Windows 版为测试性质，不建议日常使用 |
| 运行依赖 | 需要先装 .NET Desktop Runtime 6.0 | 安装包即装即用 |
| 定位 | 完整的歌词体验、管理与高级功能 | 在手机、平板、Mac 上看歌词 |

两者不冲突：电脑装 4、手机装 Mobile，用同一个 Spotify 账号登录即可。

## 二、功能差异对照

| 功能 | Lyricify 4 | Lyricify Mobile |
| --- | --- | --- |
| 滚动歌词 | 有 | 有 |
| 逐字歌词（精确到音节） | 有 | 没有，官方无加入计划 |
| 桌面歌词 | 有 | 没有 |
| 界面 | 多套，含 1:1 还原的 Apple Music 样式 | 只有 Apple Music 风格一套 |
| 歌词源 | QQ 音乐、网易云音乐、酷狗音乐、MusixMatch、Apple Music 等平台的歌词 | 与 Lyricify 4 共用歌词库，来源相同 |
| 导入 / 修改歌词 | 有（歌词管理、歌词标记） | 没有，只能依赖电脑端改完同步过来 |
| 自定义 Spotify API Client | 有 | 有 |

关键点在「共用歌词库」：你在电脑端导入或修正的歌词，手机端直接生效。所以两端并用的人，遇到歌词问题都回电脑端解决，具体见 [常见问题排查.md](常见问题排查.md)。

## 三、账号要求的差异（免费账号看这里）

Spotify 免费账号和 Premium 订阅在两个版本上的差别不一样：

- **看歌词**这个核心功能，官方文档对两端都没有设置 Premium 门槛，登录授权流程见 [Spotify账号登录授权.md](Spotify账号登录授权.md)。
- **电脑端（Lyricify 4）**，官方列了明确的 Premium 独占功能：智能引擎、任意点歌、控制播放、控制音量、添加到播放列表、内置播放；免费账号在 Media Session 连接正常时也能控制本机客户端的播放。
- **手机端（Lyricify Mobile）**，撞上 429 想配自定义 API Client 时需要 Spotify Premium；没有 Premium 只能借用他人的 Client 或干等。这一点与电脑端文档对非 Premium 用户的口径一致（限流是 Spotify API 侧的限制），细节见 [429错误与自定义API配置.md](429错误与自定义API配置.md)。

## 四、按场景对号入座

- 只在 Windows 上用 Spotify，想要逐字歌词、桌面歌词和完整管理能力 → 装 Lyricify 4，从[官方下载页](https://lyricify.app/download/)拿。
- 主要在手机上看歌词 → 装 Lyricify Mobile，安卓安装步骤见 [下载与安装教程.md](下载与安装教程.md)。
- 电脑手机都用 → 两个都装，同一账号登录，歌词库自动互通。
- 用的是 iPhone、iPad 或 Mac → 只有 Mobile 可选；iOS 端未上架 App Store，需要按官方的自签教程安装，Mac 端直接用 `macOS.pkg`（以官方文档为准）。
- 手机上的歌词功能满足不了你（想要逐字歌词、桌面歌词）→ 官方给的出路就是回到 Windows 上用 Lyricify 4；逐字歌词官方明确没有加入移动端的计划，桌面歌词则是「暂不加入」，后续动向以官方文档为准。

手机版日常使用的功能边界，见 [歌词显示与播放控制.md](歌词显示与播放控制.md)。
