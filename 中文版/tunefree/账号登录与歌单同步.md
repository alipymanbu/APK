## 一、登录能带来什么、不登录会缺什么

TuneFree 不登录也能搜歌、听歌，但以下几件事只有登录后才完整：

- **歌单同步**：你在账号里建的歌单、收藏的歌单，换设备登录后原样出现；
- **收藏与云盘**：红心歌曲、云盘里存的曲目跟着账号走；
- **听歌记录**：历史与偏好跨端延续，每日推荐、私人 FM 的结果也更贴你口味。

也就是说：只在这台手机上听，可以不登录；一旦换手机、或还想在 Windows/网页端接着听，就值得登一次。

## 二、怎么登录

TuneFree 支持网易云音乐账号的两种登录方式：

1. **扫码登录**：登录页出示二维码，用网易云音乐 App 扫一扫并确认 —— 最省事，不输密码；
2. **手机号登录**：输入绑定的手机号走验证码流程。

建议优先扫码：验证码环节受网络与频率限制影响更大，扫码失败率通常更低。登录态会保留一段时间，不必每次打开都重登；掉登了重新走一遍即可。

## 三、同步的边界在哪

把「同步」想清楚，能省掉很多「歌单怎么没了」的疑惑：

| 数据 | 是否随账号同步 | 说明 |
| --- | --- | --- |
| 我建的歌单、收藏的歌单 | 是 | 跨端登录后可见 |
| 红心（喜欢）列表 | 是 | 对应「喜欢」栏目 |
| 云盘上传的歌曲 | 是 | 云端存的跟着账号走 |
| 听歌历史 | 是 | 各端合并 |
| 手机本地的音频文件 | 否 | 只存在设备上，换机要自己拷 |
| 应用设置（主题、音质档） | 否 | 存在本机，换机要重设 |

两个常见落差：**A 手机加的红心在 B 手机没立刻出现** —— 同步发生在登录与刷新时，退出重登或下拉刷新通常即可；**本地歌曲列表换机后是空的** —— 本地栏目读的是设备文件，见 [新手使用指南.md](新手使用指南.md)，把音频文件拷过去重新扫描就行。

## 四、登错了、想换号怎么办

在设置或个人页里退出登录即可切号。退出只影响云端数据的读取，不会删你手机里的本地文件；但退出后不同步的那部分（歌单、红心）会暂时不可见，换账号登录后显示的是新账号的内容 —— 换号前想清楚哪边是主用账号。登录遇到验证码收不到、扫码一直失败的问题，见 [常见问题与解决方法.md](常见问题与解决方法.md)。
