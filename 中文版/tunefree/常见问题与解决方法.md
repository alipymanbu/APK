# TuneFree 常见问题与解决方法

> 白名单过不去、启动闪退、播不出声音、歌词不同步这类高频问题的排查顺序。

## 一、能打开但播不了：先查白名单

最常见的一类是**界面能进、歌曲一点就不出声或提示需验证** —— 十有八九是白名单没绑好。按这个顺序查：

1. 是否已加入官方 QQ 频道 [pd.qq.com/s/fylbrjbly](https://pd.qq.com/s/fylbrjbly)，并按频道提示完成绑定（步骤见 [下载与安装教程.md](下载与安装教程.md) 第四节）；
2. 绑定的设备与你当前这台是否一致 —— 换手机后要按频道指引重新绑定；
3. 绑定完成后**完全退出应用再打开**（不是切后台），让验证状态刷新。

都做了还是不行：等几分钟再试（验证服务偶有延迟），或看频道内当时有没有维护公告。

## 二、装不上或打开就闪退

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 安装时被拦截 | 安卓对未知来源的默认限制 | 按系统提示允许该来源安装，装完可关 |
| 提示解析错误/装不上 | 安装包下载不完整或损坏 | 重新下载，核对包名 `com.sayqz.tunefree` 与体积 4.89M |
| 打开即闪退 | 系统版本低于要求（需安卓 5.2 以上） | 确认系统版本；老机型可试装后再看 |
| 打开即闪退 | 与旧版本数据冲突 | 先清除应用数据或卸载重装（会丢本机设置，云端歌单不受影响） |

下载入口固定在 [下载与安装教程.md](下载与安装教程.md) 头部那条 TuneFree 安装文件资源链接，别从来路不明的渠道再拿一个互相打架的版本。

## 三、有界面没声音、或放几秒就断

逐条排，先易后难：

1. **媒体音量**：按音量键看调的是不是媒体通道（很多「没声音」就是铃声音量调了、媒体静音了）；
2. **单曲还是全部**：只有一首没声 = 该资源的播放地址失效，切下一首或重搜一遍；全部都没声 = 往下查；
3. **白名单**：见第一节；
4. **音频焦点与后台权限**：一有通知就断、退后台几秒就停，去设置看音频焦点，再确认系统里给了 TuneFree 后台运行/自启动权限，选项含义见 [音质与歌词设置.md](音质与歌词设置.md) 第四节；
5. **网络**：换 Wi-Fi 与流量对比一次，排除当前网络拦了音频域名。

## 四、歌词不同步或对不上

- **逐字歌词卡顿、错位**：先关掉逐字再开一次；仍不同步就切回普通滚动歌词（设置见 [音质与歌词设置.md](音质与歌词设置.md) 第二节）；
- **本地歌曲没歌词**：开「自动匹配网络歌词」；文件名是乱码或只有文件编号的，匹配基本不会命中，得自己找歌词文件；
- **翻译空着**：该曲没有翻译资源，不是开关问题；
- **时快时慢**：多发生在低性能机型上高码率曲目，降一档音质试试。

## 五、登录、同步相关

- **验证码收不到**：改用扫码登录（见 [账号登录与歌单同步.md](账号登录与歌单同步.md) 第二节），多数情况下换个方式就登进去了；
- **扫码一直失败**：确认手机与二维码页网络通畅，刷新二维码重扫（二维码有时效）；
- **歌单/红心换了设备不见了**：确认两台登录的是同一账号，然后退出重登触发同步；
- **本地歌曲换机后为空**：本地栏目不随账号同步，把音频文件拷到新机再扫描。

## 六、装之前就搞混了：TuneFree 与 TuneFreeNext

搜这个应用时你会撞见 TuneFreeNext —— 包名 `com.sayqz.tunefreenext`、体积几十 M，与本篇的 TuneFree（`com.sayqz.tunefree`，4.89M）是不同应用，账号与数据不通用。判别就看安装包的包名与体积，对照表在 [下载与安装教程.md](下载与安装教程.md) 第一节。你手上这个是哪份、以什么为准，那篇里写清楚了。
