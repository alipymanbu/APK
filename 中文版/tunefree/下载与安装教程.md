## 一、先确认你要装的是哪一个

TuneFree 是一款免费开源的音乐播放器，官方出过 Windows、安卓、网页三个端。你在装之前先分清两件事，装错包名后面会白折腾：

| 项目 | 本篇对应的安装包 | 容易混淆的另一个 |
| --- | --- | --- |
| 应用名 | TuneFree | TuneFreeNext |
| 包名 | `com.sayqz.tunefree` | `com.sayqz.tunefreenext` |
| 体积 | 4.89M | 体积明显更大（几十 M） |

两个包名不同，可以同时装在一台机器上，但它们是两条不同的产品线、数据也不互通。你从网盘拿到的这份是上表左列那一份，版本 **1.0.6**、MD5 `7A410734148E39460F9113F3E4C87F69`（2026-09-23 存的包），装之前可以核对一下文件大小与包名，别下成别家改名再传的包。

版本号会随时间变化，网上搜到的「最新版」常常不是网盘里这一版；凡涉及版本、包名、体积，以你手上这个安装包为准。

## 二、从哪拿安装包

最省事的入口就是本篇头部那条 [TuneFree 安装文件资源（夸克网盘）](https://pan.quark.cn/s/eecfcf4ae14f) 链接：进去转存后找到 `tunefree（先保存再下载）` 文件夹，里面的 `tunefree_v1.0.6.apk` 就是本篇对应的安装包。

官方渠道方面，项目曾有一个官网 [tunefree.fun](https://tunefree.fun/) 与 GitHub 仓库 [github.com/GSQZ/TuneFree](https://github.com/GSQZ/TuneFree)。需要注意：该 GitHub 仓库页面当前已声明停止维护与公开分发，源码与安装包已从仓库移除 —— 你去官网或仓库找下载入口时，**以页面当时实际显示为准**，打不开或找不到下载属于正常情况，这时用头部的网盘资源即可。

## 三、安装步骤

1. 把 APK 从网盘下载到手机（或先下到电脑再传过去）。
2. 点击 APK 开始安装。若系统弹出「禁止安装来自此来源的应用」，这是安卓对未知来源安装的默认拦截 —— 按提示进入该来源（文件管理器或浏览器）的安装许可开关，允许一次即可，装完可以再关掉。
3. 安装完成打开应用，首次启动会进入白名单验证（见下一节）。

系统要求：安卓 5.2 及以上（以本地记录的这份安装包信息为准）。低于该版本的老机型可能装不上或闪退，先别急着卸载，见 [常见问题与解决方法.md](常见问题与解决方法.md)。

## 四、首次启动：白名单验证

为防止项目被滥用，TuneFree 启用了白名单验证，**必须先完成绑定才能正常使用**，没绑定前只能浏览界面、不能播放。步骤：

1. 加入官方 QQ 频道：[pd.qq.com/s/fylbrjbly](https://pd.qq.com/s/fylbrjbly)。
2. 按频道里的置顶提示操作，完成设备绑定。
3. 绑定通过后回到应用，刷新或重启应用即可正常播放。

白名单是开发者做的使用资格管控，绑定一次即可，换设备通常需要重新绑定。频道入口与操作提示可能随官方调整变化，以频道内当时说明为准；验证一直过不去的处理办法写在 [常见问题与解决方法.md](常见问题与解决方法.md)。

装完之后，你可以先把音质、歌词这些选项调成你的习惯（见 [音质与歌词设置.md](音质与歌词设置.md)），再按 [新手使用指南.md](新手使用指南.md) 熟悉界面；想在多台设备间同步歌单与收藏，看 [账号登录与歌单同步.md](账号登录与歌单同步.md)。
