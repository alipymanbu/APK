## 一、三个端分别是什么

TuneFree 出过三个端，你先对号入座，别拿安卓包去装电脑、也别把网页入口的失效当成手机坏了：

| 端 | 形态 | 现状（截至 2026-09 的公开信息） |
| --- | --- | --- |
| 安卓版 | APK 安装包 | 可用，本目录 [下载与安装教程.md](下载与安装教程.md) 对应的就是它 |
| Windows 版 | 电脑安装程序 | 有公开的第三方介绍，但获取入口随官方渠道收缩而不稳定 |
| 网页版 | 浏览器打开即用 | 地址几经变更，曾有官方公告下线停运，别指望它长期稳定 |

判断某篇网上介绍讲的是哪一端，最可靠的是包名与体积：安卓版是 `com.sayqz.tunefree`、4.89M（本文对应这份）；电脑版安装包是百 M 量级的安装程序，两者不是一个文件。

## 二、Windows 版：能装，但入口要自己核

公开介绍里 Windows 版的功能与安卓版对得上（搜索、榜单、音质选择、本地管理），但有两点你要有预期：

1. **获取入口不稳定**。官方 GitHub 仓库 [github.com/GSQZ/TuneFree](https://github.com/GSQZ/TuneFree) 已声明停止维护与公开分发，官网下载也可能落空（现状见 [下载与安装教程.md](下载与安装教程.md) 第二节）。看到第三方下载站标着「TuneFree 电脑版」时留个心眼：下载站页面之间常互相套用信息、体积与版本号常常对不上，拿不准就核对发布方，或干脆等官方渠道恢复。
2. **老文章提示过接口风险**。2024 年的一篇使用介绍提到，Windows 版依赖的某开源接口项目当时已停止维护、部分功能可能不稳定 —— 那是文章发布时的情况，**以你现在实际打开的表现为准**：个别功能加载不出来先试刷新与重登，见 [常见问题与解决方法.md](常见问题与解决方法.md)。

电脑上只想听歌的话，优先级是：网页版能开就先用网页版（下一节）→ 找得到可信的 Windows 安装包再装客户端。同一账号在各端的歌单同步规则是一样的，见 [账号登录与歌单同步.md](账号登录与歌单同步.md)。

## 三、网页版：地址变过多次，别背死一个

网页版不用安装，但它的入口是三个端里最不稳的 —— 公开材料里至少出现过两个地址，还伴随过停运公告：

- 2024 年 6 月的一则公开视频说明给出的网页端是 `pt.sayqz.com`，并公告「TuneFree for Web 将于 9 月 8 日中午 12 点下线停运」（即 2024-09-08）；
- 2026 年初的介绍文章给出的 Web 入口是 [ins-music.netlify.app](https://ins-music.netlify.app/)。

两个地址隔了约一年半，**都不保证现在能开**。用之前的心理建设：网页版打不开 ≠ 你操作错了，可能就是入口下线或换了地方。它现在的实际入口以当时还能打开的官方公布为准；彻底开不了就回安卓端 —— 本篇头部的 [TuneFree 安装文件资源（夸克网盘）](https://pan.quark.cn/s/eecfcf4ae14f) 随时可用。

## 四、官网进不去，属于已知情况

官方社区侧的公开帖子显示：2026 年 1 月就有成员在官方 QQ 频道的社区里反馈「官网都进不去了」，再叠加 GitHub 仓库停止公开分发 —— 官网打不开不是你网络的问题，是渠道现状。这意味着：

- 别反复刷新官网找下载，安卓安装包走 [下载与安装教程.md](下载与安装教程.md) 头部的网盘入口；
- 想问「什么时候恢复」，走官方 QQ 频道（绑定白名单用的那个频道，[pd.qq.com/s/fylbrjbly](https://pd.qq.com/s/fylbrjbly)），社区里也能看到别人的反馈；
- 版本会变、渠道会变，本文写的是截至 2026-09 的公开情况，之后以官方页面当时显示为准。

## 五、怎么选，一张表收尾

| 你的情况 | 建议 |
| --- | --- |
| 只在手机听 | 直接装安卓版，见 [下载与安装教程.md](下载与安装教程.md)，不需要折腾电脑端 |
| 想在电脑听 | 先试网页版地址（能开最省事），再考虑 Windows 安装包 |
| 手机电脑都要、歌单要一致 | 两端登同一账号，同步规则见 [账号登录与歌单同步.md](账号登录与歌单同步.md) |
| 官网/网页全都打不开 | 属正常现状，回安卓端用网盘资源，别耗时间反复试 |
