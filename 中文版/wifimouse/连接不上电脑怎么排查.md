## 一、先照官方清单过一遍（顺序别乱）

官方 FAQ 给的连接失败排查一共五条，绝大多数「搜不到、连不上」都出在这里：

1. 电脑上确实**安装了 Mouse Server**（没装的话先看[下载与安装教程.md](下载与安装教程.md)第三节）；
2. Mouse Server **正在运行**——任务栏或窗口里能看到它在跑，光装不运行等于没装；
3. 电脑装了防火墙或安全软件的，**放行 Mouse Server，或放行 TCP 1978 端口**；
4. 确认**手机和电脑在同一个网络**（连的同一个 WiFi/路由器）；
5. 以上都满足后，手机端重新点 AutoConnect 或输入电脑 IP 连接。

这五条里最常被忽略的是第 3 条和第 4 条，下面分开说细的。

## 二、防火墙与端口：TCP 1978

Mouse Server 用的是 **TCP 1978 端口**。Windows 自带防火墙在服务端第一次运行时通常会弹「允许访问」的确认框——点过「取消」或者压根没弹出来，手机就连不进来。手动放行的方法：

1. 打开「Windows 安全中心 > 防火墙和网络保护 > 允许应用通过防火墙」；
2. 点「更改设置 > 允许其他应用」，把 Mouse Server 加进去并勾选专用和公用网络；
3. 或者不改程序，只在入站规则里放行 **TCP 1978** 端口，效果一样。

装了第三方安全软件的电脑，对应地在它的联网管控里放行这个程序或端口。

Linux 上用自带防火墙的话，对应命令（以 Ubuntu/Debian 的 UFW 和 Fedora/RHEL 的 firewalld 为例）：

```bash
# UFW
sudo ufw allow 1978/tcp

# firewalld
sudo firewall-cmd --add-port=1978/tcp --permanent
sudo firewall-cmd --reload
```

注意这个端口只对局域网开放就好，别在路由器上把它映射到公网，原因见[电脑端会共享流量吗.md](电脑端会共享流量吗.md)第三节。

## 三、连上了但电脑光标不动：用管理员身份运行

官方 FAQ 明确写过这个现象：手机显示已连接，电脑上的鼠标指针却不动或干脆看不见。原因是 Windows 上 Mouse Server **没有以管理员身份运行**。处理：

1. 在 Mouse Server 的程序图标上右键，选「以管理员身份运行」；
2. 想一劳永逸的话，右键 > 属性 > 兼容性 > 勾选「以管理员身份运行此程序」，以后双击就直接带权限。

## 四、Mac 上远程启动应用没反应：加辅助功能白名单

macOS 从 Mojave 开始要求应用进入「辅助功能」白名单才能代替人操作电脑。没加白名单时，鼠标键盘的基本操作可能正常，但**远程启动应用**这类动作会没反应。按官方 FAQ 的步骤加：

1. 点屏幕左上角苹果图标，打开「系统偏好设置」；
2. 进入「安全性与隐私」；
3. 在「隐私 > 辅助功能」里；
4. 把 Mouse Server 添加进列表。

## 五、之前连得好好的，突然连不上了

先试最简单的一招：**把手机倒过来拿几秒**——这是官方写的重连手势，应用会重新尝试连接。还不行再逐项查：

- 电脑是不是睡眠了、或者 Mouse Server 被关掉了；
- 手机是不是切到了**移动数据**，或者开着 **VPN**——VPN 会把手机的流量整个接管，手机就"看不到"局域网里的电脑了，连这类应用时先断开 VPN 再试；
- 路由器是不是**双频分开命名**（2.4G 和 5G 两个名字）：手机连了一个、电脑连了另一个，部分路由器下两组设备互相不可见，让两端连同一个名字即可；
- 路由器开了 **AP 隔离 / 访客网络隔离**：访客网络和开了客户端隔离的主网络里，设备之间互相不可见，这是路由器层面的限制，不是应用的问题——进路由器后台把 AP 隔离关掉，或者把两端都挪到主网络；
- 电脑换了网络（比如从有线换到另一个 WiFi），IP 变了而手机里存的还是旧 IP——重新 AutoConnect 一次即可。

身边没有可用路由器时有个应急办法：**手机开热点、电脑连这个热点**，两端就处在同一个网络里了——这个场景不需要外网，热点不开数据流量也能完成遥控。

## 六、都排查过了还是不行：重装服务端

Windows 上卸载 Mouse Server 的官方步骤：按 Windows 键，进「设置 > 应用 > 应用和功能」，找到 Mouse server 点卸载。卸载后重装一遍，装完记得两件事：**以管理员身份运行**，以及重新放行防火墙（第二节）。
