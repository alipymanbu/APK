## 一、手势对照表

连接成功后，鼠标/键盘界面屏幕**中部**就是触摸区。官方 FAQ 列出的手势一共六种：

| 你在手机上的动作 | 电脑上的效果 |
| --- | --- |
| 单指移动 | 移动鼠标光标 |
| 双指上下滑动 | 滚动页面（滚轮） |
| 双指捏合 / 张开 | 缩小 / 放大 |
| 单指轻点 | 鼠标左键单击 |
| 双指轻点 | 鼠标右键单击 |
| 三指移动 | 拖动窗口、移动文件 |

日常用得最多的是前五种。翻网页、看文档靠双指滚动；需要把文件拖进文件夹时，用三指移动比「按住-移动-松开」更稳。

## 二、旋转手机切换全屏界面

竖屏下鼠标区和键盘区挤在一块屏幕上，真正好用的是横屏的两个全屏界面：

- **往右横过来** → 全屏鼠标/触摸板界面，触控面积最大，光标好控；
- **往左横过来** → 全屏键盘界面，打字输入用这个，细节见[键盘与语音输入怎么用.md](键盘与语音输入怎么用.md)；
- **把手机倒过来** → 应用会重新尝试连接，这是官方设计的重连手势，断线时先想到它。

## 三、灵敏度与左右键

把手机当鼠标用时，有两个设置值得先调：

- **灵敏度**：光标移动速度跟手感直接相关，触屏滑动和实体鼠标的阻尼感不一样，建议开全屏鼠标界面后按自己的习惯调一档；
- **左右键交换**：习惯左手操作、或者右手鼠标左手触屏的场景，把左右键功能对调后顺手得多。

这两项都在模拟鼠标的设置里，各版本入口位置可能略有差异，找不到时在界面上找设置图标即可。

## 四、手势不跟手时先查三件事

- **手指数量**：滚动手势是双指，单指滑只会移动光标——这是新手最常见的「滚轮失灵」；
- **触控区位置**：只在屏幕中部的触摸区内操作，点到边缘的按键区就不算手势；
- **连接质量**：路由器负载高、信号差时光标会一顿一顿的，这不是灵敏度问题，先确认手机和电脑连的是同一个 WiFi 且信号良好，还不行就按[连接不上电脑怎么排查.md](连接不上电脑怎么排查.md)查一遍。

想让光标跟手，网络侧有几个被反复验证有效的做法：**让手机和电脑都连 5GHz 频段**（同一路由器下 5GHz 通常比 2.4GHz 延迟低、干扰少）；**缩短离路由器的距离**；条件允许的话**电脑走有线**，比无线稳得多；周围 WiFi 密集的老小区/办公楼，进路由器后台换一个不拥挤的信道也有改善。
