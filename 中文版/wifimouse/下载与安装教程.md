## 一、装之前先看清两端的分工

WiFi Mouse 不是手机上装一个就完事的应用：它分**手机端 App** 和**电脑端 Mouse Server** 两部分，手机通过它们所在的同一个网络把鼠标、键盘操作发给电脑，两端**缺一不可**。所以安装要分三步走：装手机端 → 装电脑端 → 连接。

网盘里这份手机端安装包的信息如下，装完可以按这几项核对：

| 项目 | 内容 |
| --- | --- |
| 版本 | 5.6.9 |
| 包名 | `com.necta.wifimouse` |
| 安装包大小 | 39.73 MB |
| MD5 | `4F96FB91499A4E287FBD732A5344FAD0` |

说明：官方渠道后来还发布过更新的版本（截至 2026-09 检索到的最新为 6.0.8，以官方页面为准），网盘里这份是 5.6.9。手机端的系统要求，不同渠道的标注并不一致（本份安装包标注需安卓 5.2 以上，官方商店页对最新版标注的是安卓 11 以上），实际以你手机能装能跑为准；iPhone、iPad 另有独立版本，在 App Store 搜索 WiFi Mouse 即可。

关于包名再说一句，免得你在商店里对不上号：`com.necta.wifimouse` 对应商店里的 **WiFi Mouse Pro**（付费买断版，媒体遥控、文件管理、远程桌面等 Pro 功能内置，无广告）；商店里的**免费版**包名是 `com.necta.wifimousefree`，Pro 功能靠应用内购买解锁。两版的基础连接方式和电脑端服务端是同一套。

## 二、手机端安装包从哪拿

1. 从 **WiFi Mouse 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/c5cf68027555](https://pan.quark.cn/s/c5cf68027555) 进入，先把安装包转存到自己的网盘，再下载到手机；
2. 在手机上点开下载好的 APK 文件；
3. 系统提示「未知来源应用」时，选择允许从该来源安装（不同品牌手机的入口叫法略有差异，有的在「设置 > 安全」里单独开启）；
4. 等安装完成，先别急着点开，电脑端还没装。

首次启动时应用会申请**完整网络访问权限**，这是它连接电脑端服务端所必需的；另外两项常见权限——**振动**（按键操作的反馈）和**红外发射**（在带红外发射的机型上遥控电视用）——不给也不影响鼠标键盘的基本使用。

## 三、电脑端 Mouse Server 怎么装

电脑端程序叫 **Mouse Server**，从官网 [wifimouse.necta.us](https://wifimouse.necta.us) 的下载区获取。下载区提供 Windows、Windows（Pro）、Mac（.pkg）、Linux（.deb）几种安装包，具体名单以官网当时显示为准。

- **Windows**：安装后**以管理员身份运行** Mouse Server——这是官方明确要求的，普通权限运行会出现手机连上了但电脑光标不动的问题；
- **macOS / Linux**：按对应安装包安装并运行即可。

有一点提前说清楚：官网下载页的小字条款写明，Mouse Server 免费使用的条件，是它会在**设备空闲时**安全地使用该设备的一部分网络资源（WiFi 和很少量的蜂窝数据），你可以在服务端的设置菜单里把这项关掉。介意的话装完就先去设置里看一眼。

## 四、第一次连接怎么做

前置条件只有一条：**手机和电脑连的是同一个 WiFi**（同一个路由器）。

1. 电脑上运行 Mouse Server（Windows 用管理员身份）；
2. 手机打开 WiFi Mouse，点 **AutoConnect** 自动搜索；搜不到时，手动输入电脑的 IP 地址再点 Connect（官方更新日志显示 6.0.x 起新增了扫电脑屏幕上的二维码连接，本份 5.6.9 以实际界面为准）；
3. 连上后，你就能用屏幕当触摸板控制电脑光标了——把手机往**右横过来**是全屏鼠标界面，往**左横过来**是全屏键盘界面。

连不上不要反复重试，按[连接不上电脑怎么排查.md](连接不上电脑怎么排查.md)的清单从上往下过一遍，大多数情况是防火墙没放行或者两端不在同一个网络。连上之后想先练手势，看[触摸板手势与鼠标设置.md](触摸板手势与鼠标设置.md)。
