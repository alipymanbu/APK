## 一、官方条款的原文口径

官网下载页在服务端下载入口旁边挂着一段容易错过的小字：Mouse Server 免费使用的交换条件，是**安全地使用该设备的一部分资源（WiFi 和很少量的蜂窝数据），且只在你没有在用这台设备的时候**。也就是说，服务端在你空闲时会参与某种网络资源共享，这是条款写明、你安装时就算同意了的行为——但它同时给了出口：**可以在设置菜单里关掉**。

条款全文在官网的 TOS / EULA 页面（从 [wifimouse.necta.us](https://wifimouse.necta.us) 页脚可进入），以页面原文为准。

## 二、不想参与：在哪里关

官方那句小字里写明了出口——**Mouse Server 的设置菜单**。建议装完第一件事就是进设置看一眼，把相关开关关掉再开始用。另有个别用户反馈，即使是付费的 Pro 版，这项也是默认参与、需要自己手动关闭的（单一用户反馈，仅供参考，以你设备上的实际设置为准）。

判断不了当前状态时，最直接的做法：关掉设置里的共享开关，之后观察电脑空闲时的网络活动是否归零；或者在干脆不用遥控功能时，直接退出 Mouse Server。

## 三、把暴露面收到最小

Mouse Server 监听 **TCP 1978** 端口等手机来连。这个端口面向的是局域网，你要防的是「不希望别人连进来」和「端口被暴露到外网」：

- **不要做端口映射**：路由器上不要把 1978 转发到公网。第三方技术资料给出的建议一致——只对本地网络开放这个端口，绝不暴露到互联网；
- **公共 WiFi 上不开服务端**：咖啡馆、会议室这类你不控制接入设备的网络里，同网段谁都能尝试连你的 1978 端口，能不开就不开；
- **设置密码保护**：应用内提供密码保护开关（官方功能列表里列了这一项），开启后其他设备没有密码连不上你的电脑。家里人多、路由器下设备杂的，建议开；
- **访客网络当隔离用反了**：访客网络通常禁止设备互访——反过来这也是一种保护，但你要用它控制电脑时得让两端都在主网络，见[连接不上电脑怎么排查.md](连接不上电脑怎么排查.md)。

## 四、哪些行为算正常

- 电脑空闲时后台有**轻量的网络活动**——条款覆盖的范围内属于正常；
- 手机连接、操作时端口 1978 有往来流量——这就是遥控本身的工作方式；
- 服务端运行时以托盘/后台进程形式常驻、等手机来连——它的本职就是常驻服务，正常。

超出这些范畴、你自己判断不了的行为，先做第二节的两步（关共享、退出服务端）再观察；确认有问题的版本可以卸载重装旧版或换用其他方案。
