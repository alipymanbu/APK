## 一、它在视觉上做了什么

Mineradio 播放时会把「听」延伸到「看」：画面随歌曲节奏实时变化——粒子密度、镜头角度、色彩与光影跟着鼓点走，专辑封面会被粒子解构再重组，也有体素地形随音乐起伏、踩鼓点泛光的场景。切歌时还有类似电影运镜的转场。这些全是**可调、可关**的，不是强制特效。

## 二、切换视觉预设

进入**视觉控制台**（播放界面内可找到入口），官方内置多套预设，一键切换，常见的几类：

| 预设类型 | 大致效果 |
| --- | --- |
| 封面粒子 | 以专辑封面为素材，粒子快速聚散入场 |
| 频谱方块 | 频谱以方块形态反应，偏科幻工业感 |
| 壁纸粒子 | 在背景壁纸上叠加随律动漂浮的粒子 |
| 唱片 | 圆形封面如黑胶唱片旋转 |
| 星球 / 隧道 | 雕塑感星球、沉浸式隧道视角 |
| 虚空 | **无粒子**，只留自定义背景——低配手机的省电档 |

预设之外还支持 **360° 自由旋转**镜头（拖动即可换视角）与**手势控制**（用摄像头识别手掌动作操控画面，推开粒子、捏合旋转等；不用时关掉即可）。

## 三、自己调参数并保存

视觉控制台同时是 DIY 面板，可调项包括：

- **粒子密度与运动速度**——数值越低越省电；
- **画面配色与背景**——背景可换成自己的图片或视频（桌面/网页端支持导入 MP4 壁纸）；
- **歌词样式**——位置、字号、色彩可调，歌词层可跨窗口悬浮、逐行高亮；
- **专辑封面**——支持自定义上传与裁剪。

调完可以**保存为自己的预设档**，下次打开直接调用，不会被后续改动覆盖。

## 四、特效、耗电与发热怎么平衡

粒子特效是这套界面主要的性能消耗来源。实测口径与官方 FAQ 一致：

- **中高端机**正常播放时，开特效对电量的影响不明显；
- **低配机或长时间挂机**，特效会让耗电和发热明显上升；
- 处理办法按优先级：调低粒子密度 → 切到无粒子的「虚空」预设 → 关闭动态背景。**基础播放功能不受影响**，歌词照常显示。

放在后台听歌时建议切低配档，前台看演出时再开满。其他常见症状（卡顿、耗电、发热）的完整排查见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、天气电台：另一种「氛围」

首页的**天气电台**读取你所在城市的实时天气、温度与阴晴状态，自动生成匹配当下氛围的播放队列。它需要**联网 + 位置权限**才能工作；拒绝授权或断网时，其余播放功能不受影响，只是这个入口不出结果。权限相关问题见 [常见问题与故障排查.md](常见问题与故障排查.md)，首页各入口的含义见 [界面导览与基本操作.md](界面导览与基本操作.md)。

## 六、播放时特效一个都没有

画面完全没特效时按三步查：① 视觉控制台里的**特效开关**是否被误关；② 当前预设是否是「虚空」（它本来就不含粒子）；③ 切换一次预设再重新播放。三步都正常仍无特效，去系统设置查应用权限后重启播放页，见 [悬浮歌词与系统权限设置.md](悬浮歌词与系统权限设置.md)。
