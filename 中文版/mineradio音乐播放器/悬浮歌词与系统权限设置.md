## 一、先对症状：这是权限问题还是歌词本身的问题

两个现象要分开：

| 现象 | 原因方向 |
| --- | --- |
| 播放界面里歌词也不出来 | 歌词数据或歌词层开关的问题，见 [常见问题与故障排查.md](常见问题与故障排查.md) 第四节 |
| 应用内歌词正常，**切出去后悬浮歌词不出现** | 多半是**悬浮窗权限**没给，按下面步骤开 |

悬浮歌词要画在其他应用之上，安卓把它单列为「悬浮窗 / 显示在其他应用上层」权限，安装时默认不授予，必须手动开一次。

## 二、开启悬浮窗权限的步骤

不同品牌手机菜单名略有差异，通用路径：

1. 打开手机**设置 → 应用管理（应用）→ 找到 Mineradio**；
2. 进**权限**（或「权限管理」），找到**悬浮窗**（有的手机叫「显示在其他应用上层」「后台弹出界面」）；
3. 设为**允许**；
4. 回到 Mineradio，**退出再重新打开播放页面**（有的实现要重启一次播放页才生效）。

开完仍不显示时，按顺序再查：系统是否把「锁屏后显示悬浮歌词」这类开关单独关了；省电策略是否把这个应用的后台限制成了「严格」（设置 → 电池 → Mineradio → 允许后台运行）。

## 三、Mineradio 申请的权限都管什么

装完首启时弹的那一串授权，逐项用途与拒绝后果如下（各项可随时在系统设置里改）：

| 权限 | 用在哪 | 拒绝后的表现 |
| --- | --- | --- |
| 网络 | 搜索、在线播放、账号同步 | 基本功能全不可用 |
| 悬浮窗 | 悬浮（桌面）歌词跨应用显示 | 应用内歌词正常，切出去看不到歌词 |
| 位置 | 天气电台按所在城市生成队列 | 天气电台不出结果，其余不受影响 |
| 相机 | 手势控制（摄像头识别手部动作操控画面） | 手势功能不可用，可主动拒绝 |
| 存储 | 扫描手机里的本地音频 | 「本地音乐」扫不到文件 |
| 通知 | 后台播放时的媒体控制 | 锁屏控制可能不显示（以机型为准） |

原则：**只开你用得上的**——只听在线歌、不用悬浮歌词和天气电台的话，位置、相机、悬浮窗都可以拒绝，核心播放不受影响。

## 四、改了权限没生效怎么办

权限分两处开关：**系统设置里的授权**决定能不能用，**应用内的功能开关**决定当前开不开（比如视觉控制台里的特效开关、歌词层的悬浮显示开关）。两处都开了才出效果。改完系统权限后，把应用从后台杀掉重开一次再验；仍不行，清一次缓存（设置 → 应用 → Mineradio → 存储 → 清除缓存——**只清缓存不会丢登录状态和自定义预设**，别点「清除数据」，那会把账号登录与自定义档一起清掉）。其余症状对照见 [常见问题与故障排查.md](常见问题与故障排查.md)。
