## 一、首页：打开就有安排

首页用卡片式布局把常用入口摆在一级，你不用进多层菜单：

| 入口 | 作用 |
| --- | --- |
| 我的歌单 | 你同步进来和自建的全部歌单 |
| 每日推荐 | 按你的听歌口味生成的当日推荐 |
| 推荐歌曲 | 更宽的推荐池 |
| 继续听 | 接着上次没听完的内容 |
| 听歌画像 | 你的收听偏好统计 |
| 本地音乐 | 手机存储里扫描到的音频文件 |
| 天气电台 | 按你所在城市的实时天气匹配的播放队列 |

首页上方是**搜索框**：输入歌名、歌手或专辑关键字，结果出来后点任意一条即开始播放。搜索是**跨音源聚合**的，一次能查网易云、QQ 音乐、酷狗等多个平台，详见 [歌单同步与多音源使用.md](歌单同步与多音源使用.md)。

## 二、底部控制条：播放都在这一条上

播放、切歌、进度、队列、歌词全部集中在屏幕底部，单手能够到：

- **播放 / 暂停**在正中，两侧切上一首 / 下一首；
- **进度条**实时走动，拖动可快进快退；
- **队列**按钮查看与调整接下来要放的曲目，可拖动排序；
- **歌词**按钮打开歌词层，歌词逐行高亮跟唱，外文歌会尽量配双语对照；
- 部分界面下**音乐窗口可以随意拖动**，歌词层也能旋转调整角度。

## 三、歌单：3D 立体书架式管理

Mineradio 的歌单不是纯文字列表，而是以 3D 立体书架的形式陈列，浏览时有专门的过渡动画。你日常要做的几个动作：

1. **看歌单**：进「我的歌单」，点开任意一个进入曲目列表；
2. **建歌单**：在歌单页新建，把搜到的歌加进去；
3. **整理**：长按曲目可执行编辑、移动、删除；
4. **下一首放什么**：往队列里加歌，或直接点列表任意一首。

同步来的云端歌单也出现在同一个「我的歌单」里，和本地建的没有使用上的区别。账号绑定方式见 [歌单同步与多音源使用.md](歌单同步与多音源使用.md)。

## 四、睡眠定时与后台播放

睡前听歌用**睡眠定时**：在播放界面找到定时入口，设定时长，到点自动暂停，不会放一夜。播放器支持后台持续播放，锁屏后仍可通过系统媒体通知控制切歌。

## 五、视觉控制台入口

播放时画面上的粒子、镜头、色彩效果由**视觉控制台**统一管理，可一键切换预设、也可自己调参数存档，具体调节项放在 [视觉特效与个性化设置.md](视觉特效与个性化设置.md) 讲。

## 六、卡顿时先做的一件事

粒子特效是主要的性能消耗来源。手机发烫、掉帧时，先去视觉控制台**调低粒子密度或切到「虚空」这类无粒子预设**，播放本身不受影响。完整调节项见 [视觉特效与个性化设置.md](视觉特效与个性化设置.md)，其他疑难见 [常见问题与故障排查.md](常见问题与故障排查.md)。
