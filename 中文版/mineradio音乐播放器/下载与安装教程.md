## 一、装之前先确认这几项

Mineradio 是一款开源（GPL-3.0 协议）、免费、无广告无内购的沉浸式音乐播放器，官方提供 Windows、macOS、Android 四端与网页版。你手上这台手机要装安卓版，先对一下条件：

| 项目 | 值 |
| --- | --- |
| 包名 | `com.mineradio.app` |
| 版本 | `2.1.0.0` |
| 安装包大小 | 136.90M（约 143,552,813 字节） |
| MD5 | `10412B41C8930A8C41ACA049108089DC` |
| 系统要求 | 官方下载页标注 Android 8.0+；装不上时以官方页面当时显示为准 |

这份安装包的版本、包名、大小以上表为准；网上各软件站的同名条目常挂多个历史版本（1.1.x 时代只有几十 MB），别拿旧包覆盖装——版本号对不上就以这份 2.1.0.0 为准。

## 二、从网盘拿到安装包

1. 打开 **mineradio音乐播放器 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/2958c569b83a](https://pan.quark.cn/s/2958c569b83a)
2. 在分享页里把文件夹**转存到自己的网盘**（不转存没法下载）。
3. 在手机上用夸克打开你网盘里的这个文件夹，文件名形如 `mineradio音乐播放器_v2.1.0.0.apk`，直接下载到手机。
4. 也可以先在电脑上下载，再通过数据线 / 局域网传到手机。

## 三、核对文件没有下坏

APK 是打包文件，网络中断最容易下出一个残包（安装时会报「解析包出错」）。下载完先校验一次：

- **电脑上（Windows PowerShell）**：

```powershell
Get-FileHash .\mineradio音乐播放器_v2.1.0.0.apk -Algorithm MD5
```

- **手机上**：装一个校验类 App 打开这个 APK 看 MD5，或传回电脑用上面的命令查。

输出应为 `10412b41c8930a8c41aca049108089dc`（大小写无关）。对不上就重新下载，别硬装。

## 四、安装步骤

1. 把 APK 放到手机任意目录（下载目录即可）。
2. 用文件管理器点它开始安装。
3. 系统弹出「禁止安装来自此来源的应用」时，按提示进入**设置 → 允许安装未知应用**，给该文件管理器（或浏览器）开一次权限，再返回继续安装。
4. 安装完成后打开。

首次启动的注意事项：

- 会请求**网络**权限（搜索与在线播放必须）；
- **位置**权限用于天气电台按你所在城市生成歌单，不给也能正常听歌，只是天气电台不准；
- **相机**权限用于手势控制画面，不用这个功能可以拒绝；
- **存储**权限用于扫描手机里的本地音频文件，想导入本地音乐再允许。

权限的用途与排查见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、装完打不开怎么办

最常见的两种：一是残包（回到第三节重新校验），二是系统版本过低（官方标注 Android 8.0+，老系统会直接闪退或拒绝安装）。逐条对照 [常见问题与故障排查.md](常见问题与故障排查.md) 里的「安装与启动」一节处理；界面认识与第一首歌怎么放，接着看 [界面导览与基本操作.md](界面导览与基本操作.md)。
