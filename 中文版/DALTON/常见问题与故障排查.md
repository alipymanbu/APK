# DALTON 常见问题与故障排查

## 一、安装阶段

**提示解析错误 / 版本不兼容**
先看系统版本：这份包要求 Android 5.2 及以上，低于它就换设备或改用商店里的新版。系统版本够还报解析错误，多半是 APK 下载中断损坏了 —— 回 [下载与安装教程.md](下载与安装教程.md) 重新下一次。

**装上了但打不开、一点就退**
按顺序试：① 确认装的包名是 `dalton.x`，别装成名字相近的其他应用；② 手机「纯净模式」「支付保护」这类功能会拦第三方 APK，在系统设置里对本次安装放行；③ 仍闪退就把应用卸掉，重新下一次包再装（先确认账号能重新登上去）。

**不知道装的到底是哪个版本**
系统「应用信息」里能看到版本号。网盘里这份是 1.0.1，Google Play 上的当前版本是 1.0.3，两者是同一应用的不同版本，界面细节可能略有差异，不影响本文档里的入口位置。

## 二、配网与开锁

**搜索不到锁 / 一直添加失败**
逐项对照：① 手机的蓝牙与位置权限给了没有（没给就搜不到附近设备）；② 路由器是不是 2.4GHz —— Wi-Fi 型号的锁不认 5GHz，手机先连对频段再配；③ 人站到锁跟前再操作，别隔着门；④ 锁那侧确实进了配网 / 系统设置状态（部分型号要按 `*`、`#` 进菜单，见 [添加门锁与远程开锁.md](添加门锁与远程开锁.md)）；⑤ 锁没电了也会配不上，先换电池或应急充一下。

**按「长按开锁」没反应**
按住不放要持续到开锁动作完成，点一下就松手不会执行。仍然无效时看设置里的 **远程开锁** 开关是不是被关了，再看设备页左上角的 Wi-Fi 图标是否正常。

**设备页显示的电量很低**
电量数值由门锁上报，低电量会让锁掉线、事件报不上来。先换电池或用应急充电口补电；锁平时装在户外要避开直晒和雨淋，说明书对安装位置的要求以随附说明书为准。

## 三、通知与联动

**门锁告警 / 门铃提醒收不到**
按 [智能联动与门铃通知.md](智能联动与门铃通知.md) 第五节的四处顺序查：系统通知权限 → 场景里的联动开关 → 设置里的门铃电话短信开关 → 锁的在线状态。电话短信那条属于运营商通道，还要看号码是否验证通过。

**联动配了但不触发**
先自己制造一次触发（按一下门铃）验证链路；不触发时确认条件和动作两头都配对了，再确认锁此刻在线、有电。自定义联动开放哪些条件，跟锁型和固件有关，以界面列出的选项为准。

**视频监控是灰的、点不开**
按这个顺序排除：① 应用的相机与麦克风权限是否给了（安装时拒绝过，去系统「应用信息 → 权限」里补开）；② 这把锁本身带不带摄像头 —— 不带摄像头的型号这个入口没有内容；③ 手机网络不通或锁离线。权限补开后回到设备页重新进一次。

## 四、账号与多设备

**一台手机能管几把锁**
可以，应用商店的应用介绍里写明支持多锁控制：首页「所有设备」里每把锁一张卡，点哪张进哪把，添加新锁点右上角「+」。

**iPhone 上找不到叫 DALTON 的应用**
iOS 的名字是 **DALTON LOCK**，在 App Store 中国区上架，需 iOS 13.0 或更高，入口见 [下载与安装教程.md](下载与安装教程.md) 第五节。安卓与 iOS 是同一个品牌的两端，账号体系是否互通以登录界面提供的选项为准。

**忘记登录账号 / 换手机了怎么办**
登录页提供的找回与验证码方式是最权威的入口，按界面提示走；换手机前先确认老账号还能登录，否则设备绑定关系会跟着账号走，登不上就等于看不到已绑定的锁。
