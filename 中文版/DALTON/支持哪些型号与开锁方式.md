## 一、先确认你手上是哪一款

DALTON 品牌下的锁型号很多（P80、P90、T29、T2811、D03、D14、D05、Z07、Z10 等），功能差异也大。认型号看两处：**锁体上的铭牌 / 说明书封面的 MODEL 字样**，以及包装盒上的型号。型号对上了，本篇的参数才有参考价值；对不上就以你那本说明书为准。

## 二、开锁方式全景

官方 FAQ 与产品页给出的方式汇总如下，**同一把锁不会全占**，具体看你型号的说明书：

| 方式 | 说明 |
| --- | --- |
| 指纹 | 主流型号都带，容量随型号不同 |
| 密码 | 6~12 位不等，部分支持一次性与限时密码 |
| RFID 卡 | 配套门卡，适合老人小孩 |
| App | 手机端开锁，Wi-Fi 型号可远程 |
| 机械钥匙 | 每把锁配 2 把，独立于电路的兜底 |
| 人脸 / 掌静脉 | 只有高配型号带（如 P90、Z10 这类带摄像头的） |

不用手机也能开门：密码、指纹、卡片、钥匙四样都不依赖 app —— 这一点官方 FAQ 明确写了，家里老人不必非得用手机。

## 三、能录多少人（对照表）

容量按型号分档，官方 FAQ 给的通用范围是**每种方式 50~100 个用户**，具体产品页的数字如下（截至官网当时页面，以官方为准）：

| 型号 | 官方产品页标注的容量 |
| --- | --- |
| 通用范围（FAQ） | 50~100 个指纹 / 密码 / 卡 |
| D14 | 每种方式 100 个用户、10 个管理员 |
| D05 | 100 个密码、100 个指纹、1000 张卡、3 个管理员 |
| P90 | 100 个密码、100 个指纹、9 个管理员 |
| Z10 | 最多 150 个用户，掌静脉 + 指纹 + 密码 + 卡合计 90 个 |

## 四、联网方式决定你能做什么

- **Wi-Fi 直连型号**：连上路由器就能在 app 里远程开锁、收推送，不需要额外设备。
- **蓝牙型号**：人在锁跟前才能用手机操作；**要远程，官方 FAQ 说需要配网关**。
- **远程开锁的前提**：官方 FAQ 写的是锁接入 Wi-Fi 或网关之后才谈得上远程；部分型号的产品页还注明**要访客先按门铃，app 才给远程开锁入口** —— 这也是 [智能联动与门铃通知.md](智能联动与门铃通知.md) 里门铃那条联动存在的原因。

## 五、你的锁该用哪个 app

官方 FAQ 的说法是：**多数锁兼容 Tuya 与 TTLock 这类通用 app**，同时品牌自己有配套的 DALTON 应用（本套文档讲的就是它，安卓叫 DALTON、iOS 叫 DALTON LOCK）。两个方向都可能遇到：锁说明书让你装通用 app，或者反过来。判据是**你那款锁的说明书**，别混着绑 —— 同一把锁被别的 app 绑走，你这边就会显示离线，处理办法见 [常见问题与故障排查.md](常见问题与故障排查.md)。

## 六、能不能接入智能音箱

官方 FAQ 的答复是：**不支持 Alexa、Google Home 这类智能家居集成，只有少数型号可以通过网关接入**。也就是说，指望「小爱同学开锁」这类玩法前先看型号是否属于那少数几个，并以官方答复为准。国内生态（米家、天猫精灵等）没有官方支持说法，不作承诺。

## 七、安装与环境参数（选购 / 换锁时用）

官方产品页给的硬件口径，各型号不同，这里列常见范围，具体以该型号页面当时显示为准：

| 项目 | 常见范围 |
| --- | --- |
| 门厚 | 35~50 mm 最常见，厚门型号到 120 mm；玻璃门款只吃 10~12 mm |
| 供电 | 干电池（AA）或可充电锂电池 |
| 续航 | 6~12 个月（Wi-Fi / 摄像头型号耗电更快） |
| 工作温度 | 前面板 -30℃ ~ 60℃，后面板 -10℃ ~ 60℃ |
| 防护等级 | IP54 居多，室外款到 IP65 |
| 安装 | 官方说明书要求专业安装，自行拆装影响保修 |

买锁芯、换锁体前先量门厚与开门方向；锁体装反、锁舌方向不对是最常见的安装翻车点，详见 [添加门锁与远程开锁.md](添加门锁与远程开锁.md)。
