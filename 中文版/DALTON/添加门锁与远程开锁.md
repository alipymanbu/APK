## 一、先认识首页

打开应用落在「首页」标签：页面标题位置写着「所有设备」，下面一张卡一台设备，绑好的门锁会显示成 `SMART LOCK` 这样的设备名；页面右上角是「+」，用来添加新设备。底部固定三个标签：**首页**、**场景**、**我的** —— 设备操作在首页，联动规则在场景（见 [智能联动与门铃通知.md](智能联动与门铃通知.md)）。

点任意一张设备卡就进入这把锁的设备页。

## 二、把门锁添加进来

1. **先把网络环境准备好**：Wi-Fi 型号的锁只认 2.4GHz 频段的路由器信号（同厂 P80 说明书明确写了只支持 2.4GHz）；手机这侧把蓝牙、位置权限给上，否则搜不到设备。
2. 在首页右上角点「+」，按类型选到门锁。同厂 P80 说明书给的路径是「摄像头与门锁 → 门锁(Wi-Fi)」，供你对照，具体分类名以你这个版本界面上列出的为准。
3. **在门锁那侧进入配网 / 系统设置**：部分型号（如 P80）的说明书是先按 `*` 再按 `#`，输入管理员密码（默认 `123456`）后进系统设置，选远程管理相关项。你那款锁的按键和菜单可能不同，照它随附的说明书操作。
4. 手机上按提示选 Wi-Fi 并输入密码，等进度走完，设备出现在「所有设备」列表里就算加成功。

平台侧的通用添加逻辑是同一套：把锁调到**待配网状态**后回首页点「+」，app 会自动搜附近的蓝牙 / 双模设备，搜到就直接点添加；没搜到再手动进分类按通讯方式（Wi-Fi / 蓝牙 / 网关）选。锁怎么进待配网状态、怎么选分类，以你那款的说明书为准。

**锁之前被别的 app 绑过**（比如装过通用的 Tuya / TTLock 类应用），要先在那个 app 里解绑再添加 —— 同一把锁通常只归一个账号、一个 app 管（以添加时的提示为准），硬加只会报设备已存在，处理流程见 [常见问题与故障排查.md](常见问题与故障排查.md)。

添加失败、一直搜不到，按 [常见问题与故障排查.md](常见问题与故障排查.md) 里的配网一节逐条排查；锁怎么选型、支持哪些联网方式，见 [支持哪些型号与开锁方式.md](支持哪些型号与开锁方式.md)。

## 三、设备页上都有什么

进设备页后，从上到下是这些：

| 位置 | 内容 | 你要做的 |
| --- | --- | --- |
| 标题栏 | 当前设备名，右侧铅笔图标 | 点铅笔进设置（摄像头设置、门铃通知、远程开锁、权限、手势密码） |
| 左上角 | Wi-Fi 信号图标 | 看锁的联网状态 |
| 中间大圆钮 | **长按开锁** | 按住不放直到开锁动作完成，松手太早不会执行 |
| 圆钮下方 | 电池电量 | 数值由门锁上报，低了要及时换电池或充电 |
| 相册 / 日志 | 门锁侧拍下的画面与进出记录 | 没有记录时显示「暂无日志」，用法见 [成员与临时密码怎么设置.md](成员与临时密码怎么设置.md) |
| 视频监控 | 实时画面入口 | 锁本身带摄像头才有内容；灰色点不动时见排查篇 |
| 成员管理 | 家庭成员与权限 | 见 [成员与临时密码怎么设置.md](成员与临时密码怎么设置.md) |

## 四、远程开锁的开关在哪

点设备页右上角的铅笔图标进设置，里面有一项 **远程开锁**，界面里默认是打开的。这一项控制你能不能从手机端发起开锁 —— 关掉它，设备页的开锁入口就不再执行开锁；哪天发现按了没反应，先回这里看看是不是被关了。

开关开着也不代表随时能按，官方 FAQ 与产品页给的两个前提要记住：**锁得接上 Wi-Fi（或配了网关）才谈得上远程**；部分型号还要求**访客先按门铃**，app 才会给出远程开锁入口 —— 那种设计下门铃不是可有可无的提醒，而是开锁链路的一环，见 [智能联动与门铃通知.md](智能联动与门铃通知.md)。

同一层的设置里还有「权限设置」（界面显示「仅管理员可以使用」）和「手势密码」，属于成员与安全范畴，见 [成员与临时密码怎么设置.md](成员与临时密码怎么设置.md)。锁那侧的菜单按键、恢复出厂在哪，见 [恢复出厂设置与锁上的按键菜单.md](恢复出厂设置与锁上的按键菜单.md)。

## 五、家里不止一把锁怎么办

首页「所有设备」是全部已绑定设备的列表，再点右上角的「+」继续加下一把；管多把锁这个能力应用商店的应用介绍里也写明了（多锁控制）。哪天换锁或搬走，把旧设备从设备列表里删掉再重新添加即可，删除入口一般在设备页的编辑 / 设置里，以界面列出的选项为准。
