## 一、这是个什么软件

Luna 是一款安卓上的设备检测工具，安装后打开就能自动跑一轮检测，把手机的硬件参数、系统状态、Root 与 Bootloader 状态、是否翻新机、是否跑在模拟器或虚拟机里等信息一次性列出来。它只有安卓版，界面是简体中文，安装包体积不到 5M，装完不占多少空间。

适合两类人：一是准备买新机或二手机，想在付款前自己动手验一遍；二是平时折腾过系统、改过设置，想随时确认设备当前处于什么状态。拿到结果之后怎么读，见 [检测项目与结果解读.md](检测项目与结果解读.md)。

## 二、先确认手机能不能装

| 项目 | 情况 |
| --- | --- |
| 系统 | 安卓。本包采集时记录的最低要求是安卓 5.2 以上；各下载站标注不一（有的写 4.3，有的写 6.0），以你手机上实际能否装上为准 |
| 机型 | 未见品牌限制，公开资料里主流品牌均有使用记录 |
| iOS | 没有苹果版，App Store 里搜不到对应应用 |
| 语言 | 简体中文 |
| 资费 | 各渠道标注不一（有的写免费，有的写含应用内购买项目），以安装后界面上实际显示为准 |

版本号是四段式写法（如 `1.4.3.5`），每一段的含义与怎么自己核对，见本文第五节。

## 三、获取安装包

安装文件从 Luna 安装文件资源（夸克网盘）取：[https://pan.quark.cn/s/4520c7580e9f](https://pan.quark.cn/s/4520c7580e9f)

打开链接 → 转存到你自己的网盘 → 在网盘里下载 `.apk` 文件到手机（或先下到电脑再传过去）。网盘里那一份是固定的某一个版本，与官方渠道随时在推的最新版不一定相同；本文涉及版本号、包名、体积的地方都以网盘里那份为准，见第五节。

## 四、安装与第一次运行

1. 在手机上点击下载好的 `.apk`。系统若弹出「禁止安装来自此来源的应用」，是安装未知来源应用的常规拦截 —— 去设置里允许本次安装（不同品牌路径略有差异，一般在 设置 → 安全/隐私 → 安装未知应用）。
2. 装完打开，首次启动会弹权限申请。检测要读取设备信息，权限给全才能出完整结果；只拒绝一两项时，对应的检测项会空白或报失败。
3. 进主界面后检测会自动开始，等进度走完即可，不需要手动点什么。个别版本会让你点一下「开始检测」才启动，照屏幕提示走。
4. 结果用图表加文字展示，逐项看懂它，见 [检测项目与结果解读.md](检测项目与结果解读.md)。

装不上、闪退、卡在中途，见 [常见问题与排查.md](常见问题与排查.md)。

## 五、装完核对一下版本

打开软件在设置或关于页能看到版本号；也可以在手机的 设置 → 应用 → Luna → 应用信息里看到包名与版本。核对三样：

- **包名**：`luna.safe.luna` —— 装完显示的包名对得上，说明装的是这个应用而不是同名的别的东西；
- **版本**：网盘里这份是 `1.4.3.5`；
- **大小**：约 `4.69M`。

想再严格一点，可以把安装包的 MD5 算出来跟这份对一遍：

```
DDF56D215051426782464859F65FF926
```

公开下载站上同为 1.4.3.5 的页面标注的 MD5 与上面一致；不同版本的 MD5 必然不同，别拿别的版本的值来比。体积、MD5 这类会随后续版本变化的数字，以你手上这份文件的实际计算结果为准。
