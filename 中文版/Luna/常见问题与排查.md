# Luna 装不上、跑不动、结果不对怎么办

> 安装被拦、启动闪退、检测中断、结果与预期不符这几类问题的排查顺序。

## 一、点安装包没反应或提示禁止安装

这是「未知来源应用」的常规拦截，不是安装包坏了：

1. 系统弹窗里若有「继续安装 / 允许本次」，直接点；
2. 没有该选项时，去 设置 → 安全（或 隐私 → 特殊权限）→ 安装未知应用，给你的文件管理器或浏览器临时开权限，装完可以关掉；
3. 提示「解析包时出现问题」说明文件不完整 —— 重新下载一遍，别接着断点续传的那份装。

## 二、装上了但打不开 / 闪退

按成本从低到高试：

1. **确认系统版本**：本包要求安卓 5.2 以上（各渠道标注不一，以实际能否运行为准）。系统过旧时先升级系统再试。
2. **确认装的是它**：应用信息里的包名应为 `luna.safe.luna`。同名应用不少，包名不对就卸载掉装正确的那份。
3. **清缓存重开**：设置 → 应用 → Luna → 清除缓存，再启动。
4. **重装**：卸载后重新安装（未付费的免费应用卸载无成本），安装包从 [下载与安装教程.md](下载与安装教程.md) 里那处重新取。

## 三、检测跑一半停住或某些项空白

- **权限没给全**：检测靠读取设备信息，权限被拒的项必然空白。去应用信息 → 权限，全部允许后重跑。
- **中途弹了系统对话框**：有询问类弹窗没点，流程就停在那。回应用看有没有被遮住的弹窗，点掉再等。
- **卡住不动**：杀掉应用重开，第二次通常能走完。反复卡在同一项时，记下是哪一项 —— 那一项对应的检测在你这台机器上失效了，那一栏的结论不要采信。

## 四、结果与你的认知对不上

先区分是哪种对不上：

| 现象 | 更可能的原因 | 处理 |
| --- | --- | --- |
| 显示已 Root / 已解锁，但你确实动过 | 正常如实上报 | 属实，不是故障 |
| 显示异常，但你确定没动过 | 误报，或系统自带的特殊状态 | 重跑一次；再用另一款检测工具交叉验证 |
| 硬件参数与标称不符 | 读取接口差异，或机器真被换件 | 换工具复核读数（见 [检测结果不准怎么复核.md](检测结果不准怎么复核.md)），仍不符就按 [买二手机怎么用它验机.md](买二手机怎么用它验机.md) 的口径处理 |
| 版本号 / MD5 与记录不一致 | 拿到了别的版本的包 | 按 [下载与安装教程.md](下载与安装教程.md) 第五节重新核对 |

误报最集中的两处是翻新机判定与硬件参数显示，公开渠道的常见问题里也把它们列为已知现象。复核之后仍确认是 Luna 这边判错了，可以通过你下载该应用的渠道页提交反馈 —— 公开资料里没有可查的官方联系方式，各下载站的「反馈/报错」入口是目前唯一见得到的通道。

## 五、检测时要不要联网、数据会不会上传

公开资料在这一点上口径不一，两边都摆出来：有下载站的应用信息标注「需要联网」，另有多处介绍称检测全部在本地完成、不上传用户数据。两边说法冲突，本文不替你选边。

想知道自己手上这版的实际行为，最直接的办法是实测：开飞行模式跑一遍 —— 能出完整结果，说明核心检测不依赖网络；若某些项直接失败或一直转圈，那一项就需要网络。用这个结果判断要不要在断网环境下用它。

## 六、卸载与重装注意

卸载会清掉应用内的历史结果，所以想留底就先截图。重装后需要重新授权一遍权限，其余无影响；安装包仍在你手上的话不必重新下载。
