## 一、先分清：你装的是手机客户端，不是服务器面板

搜「1Panel」找到的教程，绝大多数讲的是装在 Linux 服务器上的 1Panel 运维面板本身。而你手里这份安装包是它的**配套手机客户端 1Panel App**：装在安卓手机上，用来远程查看和管理你服务器上已经装好的 1Panel 面板。

也就是说，App 本身不提供面板功能——装完它，你的服务器不会有任何变化；它只是把面板的常用操作搬到了手机上。服务器端怎么装面板，见[连接服务器教程](连接服务器教程.md)。

## 三、核对安装包信息

通过网盘资源拿到 APK 后，建议先核对这几项（为本文所附安装包的信息）：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.1.5 |
| 包名 | `cn.lxware.onepanel` |
| 大小 | 约 48.5 MB |
| MD5 | `2A6F59F32E002F5FD1769FF95213EF95` |
| 开发者 | 凌霞软件（LXware） |

核对方式：安卓自带文件管理器一般能看到 MD5；安装后在系统「设置 → 应用管理」里能看到包名与版本。包名 `cn.lxware.onepanel` 是凌霞软件（1Panel 官方商业化团队）的命名，认准它可以从根源上避开来路不明的同名安装包——应用商店里的官方开发者主体显示为「凌霞（深圳）软件有限公司」（Lingxia (Shenzhen) Software Co., Ltd.），从商店安装时可以顺带核对。

## 四、安装步骤（APK 方式）

1. 打开 [1Panel App 安装文件资源（夸克网盘）](https://pan.quark.cn/s/83fcafc7e9d0)，转存后把 APK 下载到手机；
2. 点开下载好的 APK，系统若提示「禁止安装未知来源应用」，按提示允许你的文件管理器或浏览器「安装未知应用」（各品牌入口不同，可在系统设置里直接搜「未知」）；
3. 回到安装界面点「安装」，完成后打开。

从应用商店（小米 / 华为 / vivo / Google Play）安装的，没有第 2 步，装完直接打开。

## 五、装好之后还差两步

1. **服务器端要有 1Panel 面板**：App 是客户端，服务器上什么都没装的话它无事可做；
2. **面板要激活专业版许可证**：官方版本对比表中「移动端 App」是专业版独占内容，社区版面板无法被 App 接入——这是新手最常撞上的门槛，原因与处理见[专业版授权与常见问题](专业版授权与常见问题.md)。

这两点都确认后，回到[连接服务器教程](连接服务器教程.md)把 App 和你的服务器连起来。
