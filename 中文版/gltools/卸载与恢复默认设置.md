# GLTools 卸载与恢复默认设置

## 一、只想把某个游戏调回原样

按程度从轻到重选一种：

1. **关掉该游戏的自定义设置** —— 进 GLTools 点开该游戏，取消「为此应用启用自定义设置」。这是最干净的做法，配置还在、随时能再开。
2. **清掉单项改动** —— 只把降采样、16 位渲染这些开关复位，其他保留。改完重启游戏验证。
3. **清空 GLTools 数据** —— 系统设置 → 应用 → GLTools → 清除数据，再重启手机。所有游戏的配置一起清掉，GLTools 本体还在。

顺带记一条：以后要**卸载某个被改过的游戏，先回到 GLTools 关掉它的自定义设置**再删，否则可能把残留配置留在 GLTools 里，下次装回来会莫名其妙带着旧设置。

## 二、彻底卸载 GLTools

正常路径：打开 GLTools → 右上角三点菜单 → **Uninstall GLTools**，按提示执行。有用户反馈「出问题就卸载重装一次能解决」，这一步就是那个入口。

卸载前后注意：

- 卸载**前**确认组件能被正常移除——安装时如果勾选了生成备份（Install 对话框里的 backup 选项），卸载才有回滚依据；
- 部分版本的卸载/安装流程伴随**自动重启**，属正常现象，别在重启过程中强行断电；
- 用卸载还清不干净时，走下面的 recovery 方案。

## 三、最后的退路：recovery 恢复包

开发者的设计是：只要你有自定义恢复环境（TWRP 之类），并且安装时没关掉备份，GLTools 就是「100% 安全」——出任何问题都有得救：

- 安装组件时，程序会在存储卡根目录生成一个卸载恢复包（`/sdcard/uninstall_gltools.zip`）；
- 手机进不去系统、或卸载残留导致异常时，进 recovery 刷这个 zip，即可把 GLTools 写入的改动撤掉；
- 没有自定义恢复环境的机器没有这层保护——这也是安装篇坚持把「有 recovery 再折腾」列为前提的原因。

找不到这个文件，或刷完仍异常，参照[常见问题与解决方法.md](常见问题与解决方法.md) 的排查结论确认问题来源，再决定是否需要更彻底的系统恢复手段（如刷回完整固件——这一步因机型而异，以你机型的官方教程为准）。

## 四、卸载后的收尾清单

1. 重启手机一次，确认游戏回到原始画面与帧率；
2. 检查之前伪装过 GPU 的游戏——设置随 GLTools 移除后，游戏会重新按真实硬件给档位，画质档位变回去是正常的；
3. 清掉不再需要的恢复包文件；
4. 以后想再装，回到[下载与安装教程.md](下载与安装教程.md) 从头走一遍即可，配置不会自动恢复，需要重新调（推荐照[画质与帧率设置教程.md](画质与帧率设置教程.md) 的组合重新来，反正也就几个开关）。
