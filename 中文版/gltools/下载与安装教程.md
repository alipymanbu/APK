## 一、装之前先确认：这不是个装上就能用的普通应用

GLTools 是一个挂在系统图形接口前面的自定义 OpenGL 驱动代理，它要改的是 `/system` 分区里的库文件，所以官方说明把前提写得很直白：**需要 root 权限 + 可写的 `/system` 分区**。你手上没有 root，装完 APK 也做不了任何事。

装之前对照这几条：

| 条件 | 要求 | 说明 |
| --- | --- | --- |
| Root | 必须 | 常见的 Magisk、SuperSU 等授权方式都可以，装组件那一步会弹超级用户授权请求 |
| 系统分区 | 可写 / 有自定义恢复环境 | 有 custom recovery（TWRP 之类）时，官方明确说「100% 安全」——出问题能直接刷恢复包 |
| 系统版本 | 以官方页面为准 | 这份 4.02 的包标注需要安卓 5.2 以上；旧教程覆盖安卓 2.3+，新系统上的表现见问题篇 |
| 处理器 | ARM 或 x86 | 这两类 GPU 都在支持范围内 |
| 网络 | 使用本身不需要 | 只有下载纹理解压插件时才联网（见设置篇） |

一个容易踩的坑：网上有些页面宣称「免 root 版」，而开发者在官方描述里明确写了 root 与可写 `/system` 是硬性要求。两边说法并列在这里，你自己判断——但按官方口径准备，不会白准备。

顺带交代渠道背景：GLTools 早年在 Google Play 上架过（开发者 n0n3m4，旧版本为付费应用），Play 商店现已不再提供它，版本更新也停留在维护状态——所以现在拿安装包基本靠第三方分发，拿到哪一版、包是否完整，要自己核对（见下一节的校验表）。

## 三、首次安装组件的流程

装好 APK 只是第一步，GLTools 还要把自己的组件写进系统才生效。老版本的通用流程如下（不同机型界面略有差异，以你手机上实际显示的为准）：

1. 打开 GLTools，主界面下方有几个复选框，按需勾选后点 **Install**；
2. 弹出超级用户授权请求时点允许——没弹授权请求，说明 root 没给到它，见[常见问题与解决方法.md](常见问题与解决方法.md)；
3. 等界面返回桌面，部分机型在这一步会自动重启；
4. 重新打开 GLTools，应用列表里点你要调的游戏，勾上「为此应用启用自定义设置」，从这一步起设置才对该游戏生效。

有教程建议安装前先关掉 Wi-Fi 与移动数据，也有的版本提示安装组件失败时改用 recovery 刷入安装包——这些变通做法都整理在[常见问题与解决方法.md](常见问题与解决方法.md) 里，正常一次装成功就不用管它们。

## 四、装完之后做什么

首次安装成功后，按[画质与帧率设置教程.md](画质与帧率设置教程.md) 给一个游戏开自定义设置，先只动一两个开关、进游戏看效果，确认没问题再逐项加。改系统图形库这类操作，一次只改一处才好判断哪一项起了作用、哪一项出了问题；真改坏了，退路写在[卸载与恢复默认设置.md](卸载与恢复默认设置.md)。玩上之后如果发现手机发热、帧数越玩越低，那是另一类问题，处理办法在[游戏玩久了发热掉帧怎么办.md](游戏玩久了发热掉帧怎么办.md)。
