## 一、设置是按游戏生效的，不是全局开关

打开 GLTools，你会看到已安装应用的列表。点进某个游戏后，第一件事是勾上「为此应用启用自定义设置」（Enable custom settings for this app）——**不勾它，下面所有开关都不起作用**。设置写入后只对这个游戏生效，别的游戏不受影响；同一个手机上你可以给每个游戏留一套完全不同的配置。

改完设置后重启游戏才生效（部分改动需要重启手机），验证效果时用应用内的 FPS 计数器看数字，不要只凭肉眼感觉。

## 二、常用选项逐项说明

下表是你会最常动的几项。所有开关都只作用于当前选中的这个游戏：

| 选项 | 作用 | 什么时候开 |
| --- | --- | --- |
| 强制 16 位渲染（Force 16-bit rendering） | 把渲染位深降到 16 位 | 追求帧数时开——画面的光照和色彩过渡会变差，换来负载下降 |
| 优化 GLSL 着色器（Optimize GLSL shaders） | 实时优化着色器代码 | 一般开着；着色器编译造成的卡顿会减轻 |
| 降采样纹理（Downscale texture） | 按比例缩小纹理分辨率 | 低配机优先项，`0.5x` 是多数教程给的折中值 |
| 抗锯齿 MSAA / CSAA | 强制开启边缘平滑 | 只在你的 GPU 支持时有效；费帧，追帧数时关掉 |
| 屏幕 FPS 计数器 | 在画面上显示实时帧率 | 调试期开着，配好后可关 |
| 伪装 GPU 信息（Use fake GPU info） | 向游戏上报一个假的 GPU 型号 | 游戏按 GPU 型号限制画质档位、或拒绝某些机型时用 |
| 纹理解压 / 重压缩 | 转换纹理格式 | 仅在游戏因纹理格式报错时按需开，平时别动 |

纹理区是新手最容易翻车的地方：有教程明确建议「纹理部分什么都别动，可能会出问题」——不知道自己在改什么时，这一整块保持默认就是正确操作。纹理解压功能还需要额外装插件（要联网下载），用不到就不碰。

## 三、两套推荐组合

没有一组万能参数，先想清楚这一局你要什么。下面两套是教程与用户反馈里最常出现的组合，按目标选一套，进去试，再微调：

**A. 低配求稳（保帧数优先）**

1. 勾「为此应用启用自定义设置」
2. 开 Force 16-bit rendering
3. 开 Optimize GLSL shaders
4. Downscale texture 设为 `0.5x`
5. 抗锯齿设为 Disable
6. 纹理区其余选项不动

**B. 画质优先（机器带得动再上）**

1. 勾「为此应用启用自定义设置」
2. 保持 24/32 位渲染，不开 16 位
3. 开 Optimize GLSL shaders
4. 纹理保持原始分辨率
5. GPU 支持时开 MSAA
6. FPS 计数器留着，盯着温度

每次只改一项、重启游戏看 FPS 与温度，是唯一可靠的调法。帧数上不去先降分辨率和纹理，画面撕裂花屏再回头关刚开的那项——逐项试出来的结论比照抄配置可靠。改动会增加耗电与发热，长时间游戏留意机身温度。

## 四、伪装 GPU 型号怎么用

部分游戏按 GPU 型号开画质档位（比如只给旗舰 GPU 开高帧率），或直接不认某些小众 GPU。GLTools 的做法是：勾上 Use fake GPU info，再从模板里选一个游戏认的型号（教程里常见的是选 Adreno 系列的高端型号）。

两点提醒：

- 伪装只是让游戏「以为」你有这块 GPU，实际渲染还是你手机的真实硬件——它能解锁档位，不能凭空变出性能；
- 选的模板太高端，游戏可能反而把画质开到你的机器扛不住的档位。解锁之后配合第二节的组合 A 把分辨率压回来，才是完整做法。

如果开了伪装游戏仍不认账，或改完直接闪退，转到[常见问题与解决方法.md](常见问题与解决方法.md) 按症状排查。
