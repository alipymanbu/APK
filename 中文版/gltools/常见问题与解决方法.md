## 一、先看这几条硬边界（不满足就别折腾了）

有些「用不了」不是你操作错了，是设计如此。开发者与用户反馈里明确列过这些情况：

| 情况 | 结论 |
| --- | --- |
| 没有 root 的手机 | 不支持，装了也做不了任何事 |
| 模拟器（各种安卓模拟器、电脑上的安卓环境） | 明确不支持 |
| 游戏走 Vulkan 渲染 | GLTools 管的是 OpenGL 路径，Vulkan 游戏不受它影响 |
| Mali GPU 的部分游戏 | 有失败反馈；Adreno 的适配明显更好 |
| 官方点名失败的环境 | Nexus 6 刷 Android 6.0.1、Nvidia Shield 官方固件 |
| RemixOS | 明确不支持 |
| 厂商深度定制的系统 | 部分皮肤系统文件命名不同，可能直接跑不起来 |

对照表里命中任意一条，游戏没变化就属于预期结果，不用继续试参数。

反过来说，开发者点名**测试过**的环境包括 HTC One X、Nexus 7（2013）、LG G2、Acer A500、LG L7、小米 Redmi Note 5（名单来自开发者描述，非最新）。名单里的机型是「确定能跑」的参照，不在名单里不等于不行——只是没人为它背书。

## 二、症状：组件装不上 / 安装那步失败

按出现频率排：

1. **没弹超级用户授权** —— 打开 root 管理器（Magisk、SuperSU 等），确认 GLTools 没被拒绝、没被静默忽略；有的授权弹窗藏在通知栏里没点。
2. **教程里的老办法** —— 有教程建议装组件前关掉 Wi-Fi 与移动数据再点 Install；也有版本会提示改用 recovery 刷入安装包。
3. **系统分区不可写** —— 这是安卓 12/13 之后最常见的卡点：新版系统的 `/system` 默认挂成只读，普通安装写不进去。有两条公开可查的出路：
   - 用 Magisk 的 overlayfs 类模块先让 system 分区可写，再回来点 Install（有用户在安卓 13 + MIUI 上按此流程跑通）；
   - 用 KernelSU 时注意：它的模块挂载方式与直接改 system 文件不是一回事，需要改 `/system` 的模块要额外配 metamodule，否则挂不上。
   两条都属于「先解决分区可写，再装组件」的同一思路，具体以你机型 + root 方案的实际反馈为准。
4. **装完记得重启** —— 组件写进系统后不重启不会加载，很多「装了没用」只是少了一次重启。

## 三、症状：设置开了，游戏里没变化

逐条排除：

- **没勾总开关** —— 「为此应用启用自定义设置」没勾上，下面全是摆设（见设置篇第一节）。
- **改完没重启游戏** —— 先完全关闭游戏再进；还不行重启手机。
- **游戏根本没走 OpenGL** —— 新游戏很多默认 Vulkan，GLTools 对它无效。判断方法：把伪装 GPU 关掉、只开 FPS 计数器，若计数器不出数字，这条路多半没经过 GLTools。
- **装的时候联了网** —— 老版本有「使用时保持断网，否则可能失效」的说法，联着网仍不生效时可断网重进游戏验证一次。
- **root 掉了** —— 系统更新、Magisk 更新之后 root 可能失效，先用 root 检测类工具确认权限还在。

## 四、症状：游戏闪退、花屏、纹理异常

这类问题基本都出在「开得太狠」或动了纹理区：

1. 回到设置页，**先把纹理区的改动全部还原**——纹理相关是重灾区，教程普遍建议不动它；
2. 关掉刚开的 16 位渲染或降采样，恢复原始分辨率进游戏试；
3. 还闪退就逐项关闭本次新增的开关，找出是哪一项触发的；
4. 伪装 GPU 的模板与实际硬件差太远时，部分游戏会崩溃——换一个更接近真实机型的模板，或直接关掉伪装。

改崩了想整体回到没折腾过的状态，走[卸载与恢复默认设置.md](卸载与恢复默认设置.md) 里的恢复流程，比一项项猜快得多。

## 五、几个容易误会的点

- **帧数没变不代表没生效**：帧率上限是游戏自己锁的，GLTools 解锁的是画质档位与渲染负载；该看的是同画质下的帧数稳定性。
- **开局正常、越玩越卡不是参数坏了**：多半是机身过热触发热节流，处理办法在[游戏玩久了发热掉帧怎么办.md](游戏玩久了发热掉帧怎么办.md)。
- **它不管理网络**：延迟高、丢包是网络问题，任何渲染设置都救不了。
- **别用备份工具备份 GLTools** —— 开发者明确警告过，用 Titanium Backup 之类工具备份会把设置搞乱；要备份设置等官方的导出功能。
- **卸载游戏前先关它的自定义设置** —— 直接卸载被改过的游戏，可能把残留配置留在 GLTools 里，下次装回来会带着旧设置。
