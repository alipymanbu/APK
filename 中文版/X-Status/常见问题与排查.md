# X-Status 常见问题与排查

## 一、装不上：提示「应用未安装」或「解析包出现问题」

按可能性从高到低查：

1. **包没下完整**。回头核对文件大小是不是 25.08 MB 左右（对照表在 [下载与安装教程.md](下载与安装教程.md) 第一节）。差得多就重新下一遍，这是最常见的原因。
2. **系统版本偏低**。系统会直接拦下来，不会装到一半坏掉。
3. **装过签名不同的同名应用**。之前从别处装过同一个应用，签名不一致时系统会拒绝覆盖，只能先卸载再装这一份——卸载会清掉已经调好的状态栏设置。
4. **存储空间不够**。安装包本身 25.08 MB，装完还要加缓存，装之前给手机留出明显富余的可用空间。
5. **安装来源没放行**。「允许安装此来源的应用」要单独给你用来打开文件的那个 App 开权限，只给文件管理器开不够。

## 二、打开后状态栏一点没变

这是最常见的一类，九成是无障碍服务没开上或没开成功：

1. 进系统「设置 → 辅助功能 / 无障碍 → 已安装的服务」，找到 X-Status，看开关是不是开着；
2. 关掉再打开一次，重新授权；
3. 回到桌面看状态栏。**只在应用界面里看是不够的**，要退到桌面或其他应用里看。

部分机型还需要额外给「悬浮窗 / 显示在其他应用上层」权限，覆盖层才画得出来。

## 三、样式切了，某些界面还是不跟着变

- **先看是不是被别的同类应用压住了**。同时装两个改状态栏的应用，两层覆盖互相打架，表现就是「有的界面是新的、有的界面是旧的」。建议只留一个。
- **看设置里有没有「强制覆盖」之类的选项**，打开它再试一次。
- **定制系统（MIUI、EMUI、ColorOS 等）可能自己也在画状态栏**，需要在系统设置里把原生的沉浸式或状态栏美化项关掉，别两边同时改。

## 四、状态栏透明设置没效果

1. 确认「应用内状态栏透明」这个开关真的打开了；
2. 确认没有限定只在某几个应用里生效——想全局透明就取消应用范围限制；
3. 部分机型系统自带的沉浸式状态栏会抢同一个位置，先关掉系统的再试。

## 五、滑动调亮度或音量不管用

- **无障碍被系统收回了**：清后台或重启后容易发生，回「设置 → 无障碍」重新确认。
- **和系统手势冲突**：全面屏手势、侧边返回都抢状态栏附近区域，关掉系统侧的冲突项。
- **和另一个美化应用的悬浮层重叠**：一次只留一个。

具体的手势设置与逐条排查见 [状态栏手势与快捷操作.md](状态栏手势与快捷操作.md) 第五节。

## 六、通知标语不显示，或者显示了两次

- **完全不显示**：检查通知标语的开关是否打开，以及有没有给「通知使用权」这类权限。
- **显示了两次**（系统横幅一次、状态栏标语一次）：在通知标语那组里打开「替换抬头通知」；或者进系统「设置 → 应用 → 通知」，把对应应用的通知样式改成静默。
- **样式乱掉或重复**：清一次应用缓存（见第十一节），再重启手机。

## 七、锁屏一会儿、或者过一阵子就失效

表现是刚装好一切正常，过几个小时或重启后状态栏又变回系统原样。**这多半不是应用坏了，是系统在后台把它清掉了。** 无障碍服务一旦随应用一起被清，开关状态在系统里就会显示为关闭。

处理就三件事，各品牌入口不同，照关键词在系统设置里搜：

| 要做的事 | 关键词 |
| --- | --- |
| 允许后台运行 | 「应用启动管理」「自启动」「后台活动」 |
| 取消电池优化 | 「电池优化」「省电策略」「后台耗电管理」 |
| 锁定后台卡片 | 多任务界面下拉应用卡片加锁 |

另外，部分机型（华为等）在重启后本来就会把第三方应用的无障碍开关识别为关闭，需要重新打开一次。这是系统的机制，不是应用的问题。

## 八、耗电变快或发热

状态栏要一直刷新，确实有代价。按顺序处理：

1. 关掉「灵动岛」这类动态提示（见 [通知标语与通知中心.md](通知标语与通知中心.md) 第五节）；
2. 通知标语、电池条这类常驻显示，不用的时候关掉；
3. 在系统电池用量排行里核对它的位置；关掉上述几项之后它还排在前列，再考虑清缓存、覆盖安装。

## 九、截图里看不到仿 iOS 状态栏

系统截图默认可能把状态栏排除在外，所以截出来是干净的、不带状态栏的图。状态设置里有一项专门管这个（名字大意是「从屏幕截图中排除状态栏」），把它关掉，截图就会带上仿 iOS 的状态栏。不同版本开关的叫法略有差异，在「状态设置」里找带「截图」字样的那一项即可。

## 十、版本号和别处看到的不一样

在搜索里看到 X-Status 是更高的版本号（4.4、4.5、4.7 都有人写），这不是出错：

- 那些页面写的一般是**当前较新的版本**，而这一份包里是固定的某个版本，两者未必相同；
- 判断手上这份是不是本套文档对应的版本，只看两项：包名 `com.inoty.ioscenter.status`、版本号 `4.3`。

## 十一、缓存越用越大，找不到一键清理

有用户反馈过这一点：用一段时间后应用占用涨到几百兆，而应用本身没有自带的一键清理。可以自己动手：

- 进系统「设置 → 应用 → X-Status → 存储」，里面有「清除缓存」和「清除数据」两个按钮；
- **清缓存**只删临时文件，已经调好的状态栏设置还在；
- **清数据**会把设置一起清掉，清完等于回到刚装好的状态，需要重新配一遍。

要清就点「清除缓存」那个。

## 十二、安装包删了、找不到了

随时回文首那条 [X-Status 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6461f6d9633e) 重新取一份。已经转存到自己网盘里的，不受原分享是否还在影响；这一份的版本、包名、大小与 [下载与安装教程.md](下载与安装教程.md) 第一节的对照表一致。

想确认手机上装的是不是同一份，在应用里进设置，看「关于」里显示的版本号。
