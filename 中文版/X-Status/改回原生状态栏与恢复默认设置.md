# X-Status 改回原生状态栏与恢复默认设置

> 本篇讲三种不同含义的「恢复」：只想临时看看原生样式、把调乱的设置恢复到初始、以及彻底不用了要卸载干净；顺带说清卸载之后状态栏没变回来该怎么处理。

## 一、先说清你要的是哪一种「恢复」

三件事经常被混成一句「怎么恢复」，但做法完全不同，先对号入座：

| 你的诉求 | 用哪种做法 | 设置会不会丢 |
| --- | --- | --- |
| 临时看一眼原生状态栏 | 把样式切回安卓原版 | 不丢，随时切回来 |
| 参数调乱了，想回到刚装好的样子 | 清一次应用数据 | 会丢，等于重装 |
| 彻底不用了，要卸载干净 | 先关无障碍开关，再卸载 | 全丢，属正常 |

## 二、只是临时切回原生样式

进**右上角菜单 → 状态设置**，把样式那一项从 iOS 风格切回安卓原版，状态栏立刻回到系统原样；想改回来，同一个位置切回 iOS 风格即可。调过的时间格式、透明度、电池条这些参数都还在，不会被清掉。

这是最轻的一种「恢复」，适合临时截图、给别人演示，或者某个应用里仿 iOS 状态栏显示不正常时，先用它排除「是不是样式本身的问题」。

## 三、参数调乱了：回到初始状态

样式类参数一项套一项，调到最后自己都记不清改过什么时，最省事的办法是清一次应用数据：

1. 进系统「设置 → 应用 → X-Status → 存储」；
2. 点「清除数据」（不是「清除缓存」）；
3. 重新打开应用，按首次启动的流程走一遍——系统里的无障碍开关通常还在，语言和样式要重新选。

**两个按钮的区别要记清**：

- **清除缓存**：只删临时文件，已经调好的样式、手势、标语设置都保留；
- **清除数据**：连设置一起清掉，等于回到刚装好的状态。

部分版本的设置列表里还有一项恢复默认（不同版本叫法不一，有的写作 `Set default settings`），位置一般在设置列表偏下处。有这个入口就用它，比清数据精准；找不到就按上一条清数据。

## 四、彻底不用了：卸载的顺序

1. **先关无障碍**：进系统「设置 → 辅助功能 / 无障碍 → 已安装的服务」，把 X-Status 的开关关掉；
2. **再卸载**：长按图标卸载，或进「设置 → 应用 → X-Status → 卸载」；
3. 卸载完回到桌面看一眼，状态栏应该已经回到系统原生样式。

先关开关再卸载是有必要的：直接卸载时，无障碍列表里偶尔会留下一个指向已删除应用的条目，看着别扭，还得手动清。

## 五、这类工具到底动了系统的什么

一个常见的担心是「会不会把系统改坏」。这类状态栏美化工具的做法是在界面上叠一层自己的绘制，**不替换系统文件、不改系统底层设置**。所以取消设置或卸载之后，状态栏会自动回到原生样式，不需要额外做「修复」。第三方下载页对这一点说法一致。

## 六、卸载了、关了却还是没恢复

按顺序往下排：

1. **重启一次手机**。覆盖层是随进程存在的，进程被强杀或卸载后偶有残留，重启能清干净。
2. **回无障碍列表再看一眼**，有没有还留着 X-Status 的条目，有就关掉（就是第四节说的那种残留）。
3. **检查有没有装别的同类应用**。同时装过两个改状态栏的应用时，卸载一个，另一个还在继续画——表现就是「卸载了却没变化」。
4. **检查系统主题**。部分定制系统允许用主题混搭状态栏，之前套过带状态栏的主题，要恢复原生外观得去主题里换回来，这一步与应用无关。
5. **确认你要的到底是哪种「恢复」**。如果系统状态栏本身工作正常（时间、电量、通知都在），那卸载/关闭其实已经生效，只是你期待的是别的效果，回到第一节重新对号入座。

## 七、卸载之后还想再用

回文首那条 X-Status 安装文件资源的链接重新取一份装上，设置需要重配一遍。想以后少折腾：**升级时走覆盖安装、不要先卸载**，设置就能保住（做法见 [下载与安装教程.md](下载与安装教程.md) 第六节）。
