## 一、手势设置在哪

手势相关的开关和状态栏外观通常不在一组，位置是：**右上角菜单 → 设置中心 → 手势控制**（有的版本归在「状态设置」下面当子项）。

前提同样是无障碍服务已开启——手势要「看见」你在状态栏上的动作，靠的就是这项权限。

## 二、滑动状态栏调亮度与音量

这是最常用的一组：

- **左右滑动 → 调屏幕亮度**；
- **上下滑动 → 调音量**，而且会先看你正在干什么：听音乐时滑的是媒体音量，通话时滑的是通话音量，来提醒时滑的是铃声音量。不用先想「我现在要调的是哪一路」，直接滑就行。

刚上手容易误触，两个调节方向：

- 觉得太灵敏，把手势的生效区域调小、或灵敏度降一档（在同一个设置页里）；
- 干脆只留一个方向，比如只保留调亮度、关掉音量滑动。

## 三、点按、双击、长按、左右滑动分别能干什么

除了滑动调节，状态栏本身可以当作一排快捷键用，常见的动作和对应手势：

| 手势 | 常见用途 |
| --- | --- |
| 单次点按 | 打开快捷开关面板，或跳回某个界面 |
| 双击 | 截屏 |
| 长按 | 启动指定的应用，或呼出电源菜单 |
| 向左 / 向右滑动 | 切换静音、勿扰等状态 |

每一项都能自己指定绑哪个动作。**建议先绑两三个真正常用的**（比如双击截屏、长按呼出电源菜单），绑多了反而记不住，也更容易和系统手势撞车。

## 四、把下拉通知栏锁掉（防误触）

状态栏被重画之后，有些人的诉求正好相反：不想再从顶部下拉出系统通知栏或控制中心，因为游戏、看视频时很容易误触。

做法是在「控制中心 / 通知中心」那一组里找「锁定状态栏」或「禁用下拉」的开关，打开后按提示确认无障碍权限，之后从顶部下拉就不再调出系统的通知面板。**想恢复就在同一个位置关掉这个开关**，不需要卸载。

这种锁定只是禁用了入口，不动数据：关掉开关以后系统通知面板立刻回来，之前积攒的通知也都在。

## 五、手势不管用、或者跟系统手势打架

按出现频率从高到低查：

1. **无障碍被关掉了**：系统清理后台或重启后，开关可能被收回，回「设置 → 无障碍」重新确认一次。
2. **和系统手势重叠**：全面屏手势、侧边返回手势都会抢状态栏附近的手势区域，关掉系统手势里的冲突项，或换个手势绑同一个动作。
3. **和另一个美化类应用的悬浮层重叠**：同时装两个改状态栏的应用，谁在上层谁说了算，建议只留一个。
4. **手势本身绑错了**：进手势设置核对一遍绑定关系，绑重了就改掉。

更多排查项见 [常见问题与排查.md](常见问题与排查.md)。
