## 一、先说清这一份是哪个版本

X-Status 是一款把安卓顶部状态栏改成 iOS 观感的工具：装上并授权之后，状态栏的样式、时间与电量图标的排布会按 iOS 的样子呈现，还可以直接在状态栏上滑动调亮度、调音量。它不需要 root，代价是把整套功能挂在一项系统权限上——这也是「装了没反应」最常见的原因。

动手前先对一下手上这份包：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | X-Status |
| 开发者 | PUBLISH-APP.LTD |
| 包名 | com.inoty.ioscenter.status |
| 版本号 | 4.3 |
| 安装包大小 | 25.08 MB |
| 安装包 MD5 | F10A35ACBE2B2CA701291FF7E61F97B7 |
| 系统要求 | 安卓 5.2 及以上 |
| 是否需要联网 | 下载安装包、取部分主题资源要联网；调状态栏样式本身不依赖网络 |

**版本号别拿别处的来对。** 各下载页现在挂的多半是更高的版本（4.4、4.5、4.7 都有人写），看到比 4.3 新的版本号属正常——这一份是固定的某一个版本，不是「当前最新版」。判断手上这份对不对只看两项：包名是不是 `com.inoty.ioscenter.status`，版本号是不是 `4.3`。

**最低系统版本以实际安装为准。** 第三方页面标注的最低安卓版本互相矛盾（4.4、5.0、5.2 都有人写），这一份记录的是「需要支持安卓系统 5.2 以上」。真装不上时安卓会直接拦下来，不会装到一半坏掉。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享。相比在搜索结果里随手点一个「立即下载」，从网盘转存再下载的好处是文件固定，不会被下载站中途换成别的东西。

1. 在手机上打开 [X-Status 安装文件资源（夸克网盘）](https://pan.quark.cn/s/6461f6d9633e)。手机浏览器或夸克 App 都能开，**建议用夸克 App**——浏览器下大文件容易被切到后台打断。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存之后就不再依赖原分享链接还在不在。
3. 进自己的网盘找到这个包，点下载，等它落到手机存储里。
4. 下完核对两件事：文件名结尾是不是 `.apk`（这一份形如 `X-Status_v4.3.apk`）；大小是不是 25.08 MB 左右。差得多就是没下完整，删掉重来。

习惯在电脑上操作也行：在电脑端网盘下载，再用数据线拷到手机的 `Download` 目录，之后从手机「文件管理」里点它安装，效果一样。

手上有校验工具的话可以顺手算一遍 MD5，和上表的 `F10A35ACBE2B2CA701291FF7E61F97B7` 比一比：一致说明传输没出错，不一致就重新下一遍。不查也不影响安装。

## 三、安装：系统会拦一次，放行即可

这一份是手动安装的，不是从手机自带应用商店点「安装」装的，所以点安装包时系统会拦一下，提示「不允许安装来自此来源的应用」之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开「文件管理」，进 `Download` 目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，找到你刚才用来打开文件的那个 App 单独放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」。首次启动前把权限一次性理顺，比进去之后反复弹窗省事。

## 四、首次打开：先开无障碍，再选语言

**这一节是整个安装里最关键的一步。** 状态栏的显示与交互都靠安卓的「无障碍服务」实现，不开这项权限，应用能打开、能翻设置，但屏幕上什么都不会变。

开启路径（各品牌菜单叫法略有差异，照关键词找）：

1. 进手机「设置」；
2. 找到「辅助功能」或「无障碍」；
3. 进「已安装的服务 / 下载的服务」列表，找到名字里带 X-Status（有的机型显示为 XStatus）的那一项；
4. 打开它的开关，弹窗里确认允许。

首次启动时应用一般会自己把引导页推到前面，页面上会有「出现在顶部」这类开关和指向无障碍设置的入口，按提示点进去就行。

界面语言默认未必是中文。要切成中文：点右上角的菜单按钮（`≡` 或三个点）→ 进设置 → 下拉找到 `language` → 进去后拖到最下面，选 `Chinese`。选完界面文字会立刻变。

其余权限按提示给：

| 权限 | 用途 | 建议 |
| --- | --- | --- |
| 无障碍服务 | 状态栏样式的显示与手势交互都挂在这上面 | 必须给，否则整套功能形同虚设 |
| 悬浮窗 / 显示在其他应用上层 | 部分机型需要它，覆盖层和快捷面板才弹得出来 | 提示就给它 |
| 通知使用权 | 状态栏通知标语、部分快捷开关需要 | 用到通知相关功能时给 |
| 允许后台运行 | 被系统清掉后状态栏会退回原生样式 | 建议放行，做法见 [常见问题与排查.md](常见问题与排查.md) |

需要说明的是：无障碍权限在安卓里属于高权限，能看到屏幕上的内容，这也正是它能改写状态栏的原因。给之前确认这份包的来源是可信的；不需要它的时候，去同一处把开关关掉即可，不会留下残余。

## 五、装完先做三步自检

不用急着调样式，先花一分钟确认这三件事：

1. **状态栏有没有变样**：退出应用回到桌面，看顶部状态栏。没有变化就回去检查第四节的无障碍开关——十有八九是没开上，或者被系统关掉了。
2. **滑动有没有反应**：在状态栏上左右滑动试试亮度。这一步验的是「无障碍 + 覆盖层」这条链路通没通。
3. **设置能不能改到实处**：进右上角菜单 → 状态设置 → 随便改一项，看能不能立刻看到变化（各项设置的做法见 [状态栏样式怎么设置.md](状态栏样式怎么设置.md)）。

三步都过就可以正常用了。哪里卡住，对照 [常见问题与排查.md](常见问题与排查.md) 里的对应一节排查。

## 六、升级与卸载要注意的

- **升级**：新版本会换一个安装包文件名，直接装新包覆盖即可，一般不用先卸载；先卸载再装会把已经调好的状态栏设置一起清掉。
- **卸载**：卸载前建议先进系统「无障碍」里把 X-Status 的开关关掉，避免残留一个指向已卸载应用的开关；卸载后状态栏会自动回到系统原生样式。
- **安装包删了**：任何时候都能回到文首那条 X-Status 安装文件资源的链接重新取一份；已经转存过的不受原分享是否还在影响。
