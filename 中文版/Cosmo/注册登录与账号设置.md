## 一、注册流程：邮箱验证

Cosmo 的账号体系以邮箱为核心：按服务条款的表述，注册是把你的邮箱账号与 Cosmo 关联起来，验证也走邮箱完成。流程：

1. 打开 App，点「Start」。
2. 选「注册」，填一个你能正常收信的邮箱。
3. 去邮箱收验证邮件，完成验证。
4. 设密码，勾选同意服务条款与隐私政策。
5. 挑选想关注的艺人团体（tripleS / ARTMS / idntt），进主界面。

三条硬性规则要知道：

- **未满 14 周岁不能注册**——服务条款明确写了「无论是否取得监护人同意」，14 岁以下都不受理会员注册。
- **一个邮箱一个号**。用别人的邮箱注册属于条款禁止的情形，被查到会限权。
- **19 岁以下未成年人买付费内容**，按条款需要监护人同意，否则监护人有权撤销这笔消费合同。涉及花钱的板块见 [会员订阅与商城购买.md](会员订阅与商城购买.md)。

## 二、验证邮件收不到

按顺序排查：

1. 翻垃圾邮件文件夹，搜发件人里的 `cosmo` 或 `modhaus`。
2. 确认邮箱地址没打错（最常见的翻车点）。
3. 换一个主流邮箱再试，个别小众邮箱域名的拒收率高。
4. 还不行就是官方侧的问题，发邮件到客服邮箱 `cs@mod-haus.com`（英文或韩文描述问题，附上注册邮箱），见 [常见问题与解决办法.md](常见问题与解决办法.md) 的客服段落。

## 三、登录失败的一般原因

同一个邮箱反复登不上，常见原因按概率排：

| 现象 | 先查什么 |
| --- | --- |
| 提示密码错误 | 大小写、输入法全角；忘记密码走「找回」流程重置 |
| 卡在验证/加载界面 | 网络对 Cosmo 服务器的连通性，换网络环境对比 |
| 提示账号不存在 | 确认邮箱拼写；确认这个邮箱之前真的注册成功过（收到过验证邮件） |

从公开的用户评价看，有相当比例的「登不上」发生在网络链路上，而 App 本身的功能多数不受影响。排查思路展开在 [常见问题与解决办法.md](常见问题与解决办法.md)。

## 四、切换关注的艺人

主界面左上角显示的是当前艺人团名称，点它会看到「切换艺人」入口。你在注册时选过的团体之间切换不需要重新关注；切换后 Home、Rekord、Collect 的内容都会跟着换组。三组艺人的 Objekt、COMO 相互独立——在 tripleS 攒的 COMO 不能拿去投 ARTMS 的 Gravity，这点在 [COMO与Gravity投票指南.md](COMO与Gravity投票指南.md) 里会再强调。

## 五、资料、书签与账号安全

- **改头像、ID、简介**：在 Profile（最后一个标签页）里改。ID 是你在社区里的展示名。
- **书签小卡**：在 Collect 里把某张 Objekt 设为 Bookmark，之后每次打开 App 都会先显示这张卡。
- **改密码**：在 Settings 里操作。账号借给他人使用是条款明确禁止的，出问题官方不兜底。
- **注销**：可以随时在设置里申请退出会员，官方即时处理。注意注销前想清楚——你的 Objekt 收藏、COMO 余额、会员订阅关系都会随之失去，COMO 在条款里被定义为「无财产价值的虚拟数据」，不退现金。
- **收货地址等个人信息变更**：涉及实体周边发货的信息改动，条款要求通过客服渠道告知，光改 App 内资料可能不够。

## 六、账号出问题找谁

账号被盗、购买漏发、注册被拒这类需要官方介入的事，统一走客服邮箱 `cs@mod-haus.com`。写邮件时带上注册邮箱、遇到的问题、大概发生时间，能截图就附截图。更完整的排查清单在 [常见问题与解决办法.md](常见问题与解决办法.md)。
