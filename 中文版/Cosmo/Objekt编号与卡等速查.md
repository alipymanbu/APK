## 一、先记住两条通用规则

不管哪组艺人，每张 Objekt 的标注都遵循两条：

1. **结尾字母分实体与数字**：**A 结尾是实体卡**（随专辑、线下活动发放），**Z 结尾是数字卡**（商城购买、活动发放、扫码入库后的实体卡也归为你名下的数字收藏）。
2. **卡面还有一组 # 号流水号**：数字卡按铸造顺序编号，实体卡按印刷顺序编号——同款卡越多，这个号越大。

## 二、tripleS / ARTMS：Class（等级）体系

tripleS 与 ARTMS 的卡按「Class」分级，等级名与编号段的对应关系（以社区长期整理的口径为准，个别卡有例外）：

| 编号段 | Class | 特征 |
| --- | --- | --- |
| 1xx | FCO（First Class） | 每季的基础拍摄卡，1 COMO；其中 **100 号固定是 WCO（Welcome）**，新账号注册关注后自动获得 |
| 编号不规则 | ZCO（Zero Class） | 预注册、早期活动等场合发放的随机卡 |
| 2xx | DCO（Double Class） | 成员自拍风格的特别卡，**2 COMO** |
| 3xx | SCO（Special Class） | 特别活动卡，来自实体专辑或 Grid 合成 |
| 另有 | PCO / UCO / MCO | Premier、Unit、Motion 等更高级别 |

FCO 的两个值得知道的量：**一名成员一季约有 21 张 FCO（含 WCO）**；同一季的 FCO 分**三个 edition**（第一版/第二版/第三版）分波放出，同一成员不同 edition 的造型不同——收全套的人要对 edition 数量有概念。

## 三、idntt：Type 体系

idntt 不叫 Class，改叫「Type」，编号段的划分也不一样：

| 编号段 | Type | 特征 |
| --- | --- | --- |
| 10x | WTO / BTO | Welcome 卡（编号恒为 100 起）与 Basic 卡；BTO 一季每成员 8 张（101Z–108Z），1 COMO |
| 2xx | ETO | Event 卡（节日、纪念日、线下活动等） |
| 30x | STO | Special 卡，合成可得 |
| 40x | UTO | Unit 卡，更高一级 |
| 50x | MTO | Motion 卡，带动态效果 |

idntt 的 WTO 有两条专属限制：**不可赠送（Send），也不能拿来玩 Spin**。

## 四、季节名怎么对时间

卡面标注的季节名是「季名 + 年份后两位」，按季度滚动（例：**Spring26 = 2026 年第 2 季，覆盖 4–6 月**）。同一季内发行的所有卡共享这个季名，所以看季名就知道这张卡大概什么时候发的。

## 五、拿一张卡练手

以「SeongJun Spring26 213Z」为例拆一遍：

| 片段 | 含义 |
| --- | --- |
| SeongJun | 成员名 |
| Spring26 | 2026 年第 2 季 |
| 2xx | ETO（idntt 体系） |
| x13 | 该季第 13 张 ETO |
| Z | 数字卡 |

再看一个 tripleS 的：「KMY CREAM01 202Z」——KMY 是成员代号，CREAM01 是季名，2xx 开头按 tripleS 体系读作 DCO，Z 是数字卡。

## 六、三个实用提醒

1. **编号只当线索，不当判决**。社区整理的编号表偶有出入、官方也会随赛季调整规则，判定一张卡的确切类型与产量，以 App 内卡片详情页为准。
2. **查卡表有第三方工具**。社区做的 Objekt 追踪站（如 Apollo、Objekt Tracker）收录了 tripleS / ARTMS / idntt 历季发行的全部卡，查「某张卡是哪次活动发的、全季有哪些」比在 App 里翻快——它们是粉丝自建站，数据以官方 App 为准。
3. **想清楚编号背后的玩法**：编号决定等级，等级决定 COMO 产量与 Grid 合成路线，这两条主线分别写在 [COMO与Gravity投票指南.md](COMO与Gravity投票指南.md) 和 [Objekt小卡收集与合成.md](Objekt小卡收集与合成.md)。
