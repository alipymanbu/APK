## 一、Cosmo 本身免费，收费的是三块

App 免费下载、免费注册，基础功能（看动态、逛社区、收卡、攒 COMO）不花钱。涉及付费的有三块：

1. **Membership 订阅**——tripleS / ARTMS / idntt 各一套，解锁互动权益；
2. **Shop 买 Objekt**——直接补卡；
3. **Point 充值**——服务条款里的付费点数，用来购买内容，免费赠送的 Point 有效期一年。

## 二、Membership 订阅：买的是什么

三套会员对应三组艺人，权益的重心在 **Room 板块**：

| 权益 | 不订阅 | 订阅后 |
| --- | --- | --- |
| 成员帖子下留言 | 可以 | 可以 |
| 看成员直播 | 可以进入 | 可以在直播里发评论互动 |
| 直播回放 | 看不了 | 可以看 |

换句话说：只看不说话，免费账号够用；想被成员翻牌、想补看错过的直播，才需要为对应团体开会员。

订阅口径（截至本文所依据的官方商店信息，价格与权益以 App 内订阅页当时显示为准）：

- 订阅周期 **一个月**，到期**自动续订**，不想续要在到期前手动取消；
- 美国区定价 **每月 1.99 美元起**，三套会员价格不同，国区/其他区按各自商店结算；
- 具体到每套会员的价格与包含内容，**以 App 内会员订阅页为准**——这是官方唯一承诺的口径。

## 三、取消订阅在哪操作

订阅走的是应用商店的扣款渠道，取消也在商店侧：

- **Google Play**：Play 商店 → 右上角头像 → 付款与订阅 → 订阅 → 找到 Cosmo → 取消。取消后当期权益保留到已付费周期结束。
- **App Store（iOS）**：设置 → 点你的名字 → 订阅 → 取消。
- 只在 App 里删应用不叫取消，续订照扣。扣款争议直接找商店客服，比找 Cosmo 客服快。

## 四、Shop 与 Web Shop 的区别

买 Objekt 有两个入口，**同样的东西价格不同**：

- **App 内 Shop**：顺手，点开就买；
- **Cosmo Web Shop**：官方网页端商城，地址是 `https://shop.cosmo.fans`（官方在各艺人宣传渠道统一给出的入口），**折扣力度更大**——从第三方整理的攻略到社区讨论，这一点被反复提到。

买卡还分两种下单方式（以 idntt 的 BTO 为例）：**开季首发**时买的是「随机成员、指定序号」，**季中常驻**买的是「指定成员、随机序号」——先想好你要的是凑齐某张序号还是收某个成员，再选下单时机。

批量补卡前先比一次价，长期收集的差价可观。买卡前想好用途——是为了补 Grid 缺口（见 [Objekt小卡收集与合成.md](Objekt小卡收集与合成.md)）还是为了攒 COMO 投 Gravity（见 [COMO与Gravity投票指南.md](COMO与Gravity投票指南.md)），两种目的该买的卡不一样；卡等与编号怎么读见 [Objekt编号与卡等速查.md](Objekt编号与卡等速查.md)。

## 五、付费前确认四件事

1. **未成年人付费**：条款规定 19 岁以下买付费内容需监护人同意，否则监护人可撤销该笔合同。
2. **数字内容退款口径**：数字内容一经消费、进入不可撤销范围的，条款允许商家在格式化提示后排除撤回权——买之前看清楚购买页的说明，别默认「能退」。
3. **漏发怎么办**：付费后 Objekt 没到账，带订单信息发邮件给 `cs@mod-haus.com`，这类问题官方回复口径就是走这个邮箱（公开的用户评论里开发者也是这么答复的）。
4. **扣款渠道**：订阅走商店内购、Web Shop 走网页支付，两者的账单主体不同，对账时注意区分。

## 六、免费玩家能玩到哪一步

不开会员、不买卡的免费账号：可以关注艺人、刷 Home 与 Rekord、在成员帖子下留言、参与社区互动、领取登录奖励的 WTO 卡（每张产 1 COMO）、用每 24 小时恢复的 Spin 票抽卡（见 [Objekt小卡收集与合成.md](Objekt小卡收集与合成.md)）。够感受整个产品，但投票权有限、直播互动缺席——要不要付费取决于你追的深度。
