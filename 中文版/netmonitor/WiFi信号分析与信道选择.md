## 一、WiFi 页签能看到什么

切到 WiFi 页签，表盘显示当前连的 WiFi 的 dBm，下方是一张信息卡，字段包括：

| 字段 | 说明 |
| --- | --- |
| Name（SSID） | WiFi 名称 |
| Channel / Frequency | 信道号与频率，如信道 8 对应 2447 MHz |
| MAC address | 接入点标识（BSSID） |
| IP address | 你手机拿到的内网 IP |
| Link speed | 当前连接速率（会浮动） |
| Distance | 到路由器的估算距离（如 ~3 m，仅供参考） |

周边其他 WiFi 也会列出来：名称、频段、信道、信号强度之外，还能识别**路由器厂商**（按 MAC 前缀判断）。

## 二、给路由器挑个不挤的信道

2.4 GHz 频段只有 **1、6、11** 三个互不重叠的信道，周边邻居的 WiFi 基本都挤在这三档上。做法：

1. 打开 Netmonitor 的 WiFi 列表，看你家周边每个 WiFi 各占哪个信道；
2. 数一数 1、6、11 哪个被占得最少、哪些同信道的信号比你强；
3. 登录自家路由器后台，把信道改成最空的那档。

5 GHz / 6 GHz 频段信道多、互相干扰少，设备支持的话直接切过去通常比任何 2.4 GHz 信道都省心。

## 三、拿着手机找覆盖死角

1. 手机连上自家 WiFi，停在表盘页看 dBm 和信号曲线。
2. 从路由器旁出发，走到家里每个常用位置停几秒，记下数值。
3. 对照 [信号强度与参数怎么看.md](信号强度与参数怎么看.md) 的 WiFi 对照表：走到哪降到 -70 以下，哪里就是死角。

处理顺序：先挪路由器位置（居中、离地、避开金属与承重墙），不行再考虑加一个节点。**先测量再买设备**，省得白花钱。

## 四、能上网但打不开网页时看什么

信息卡里的连接参数这时才用得上：

| 现象 | 优先看 |
| --- | --- |
| WiFi 连着但网页打不开 | DNS 是否异常（换 223.5.5.5 / 119.29.29.29 一类公共 DNS 试试） |
| IP 是 169.254.x.x | 没从路由器拿到有效地址，重启 WiFi 或路由器的 DHCP |
| 网关能 ping 通但外网不通 | 问题在宽带出口，不在 WiFi 本身 |

## 五、看看谁连着你的网

WiFi 分析部分能检测连接到网络的设备。怀疑被蹭网时：先数一下自己名下的手机、电视、音箱有几台，再对照路由器后台的在线设备列表，对不上的就是蹭网者 —— 处理办法是改密码，而不是在 Netmonitor 里。

## 六、顺带认识一下加密方式与 WiFi 代际

列表里会显示每个网络的加密与代际，遇到这几个词对照下表：

| 条目 | 含义 |
| --- | --- |
| WEP / WPA | 老加密，安全性早已不够；自家路由还是这两档就赶紧升级成 WPA2/WPA3 |
| WPA2 / WPA3 | 现行标准，WPA3 更新更安全 |
| OWE | 开放网络（无密码）的加密形态，商场公共 WiFi 常见 |
| 802.1x / EAP | 企业级认证，公司网络常见 |
| WiFi 4 / 5 / 6 / 6E | 对应 802.11n / ac / ax / ax(6GHz)；代际越高，理论速率与抗干扰越好，前提是你手机也支持 |
