## 一、打开后先看表盘

主界面是一个表盘：指针指到当前信号强度，中间大字显示 dBm 数值，下面配一个评级词（比如 -50 dBm 标着 Great）。表盘顶部有 **WiFi / SIM1** 两个切换页签 —— 同一个表盘，既能看 WiFi 信号，也能看蜂窝信号，双卡机型还能切到 SIM2。

先记住一条：**dBm 是负数，越接近 0 信号越强**。-60 比 -90 强，不要看绝对值大小。

## 二、dBm 数值对照（经验参考值）

**蜂窝信号（RSRP 口径）**，行业通用的经验划分：

| RSRP | 信号感受 |
| --- | --- |
| -85 以上 | 很强，满格体验 |
| -85 ~ -95 | 良好，正常使用 |
| -95 ~ -105 | 一般，室内开始吃力 |
| -105 ~ -115 | 差，容易掉线 |
| -115 以下 | 基本失联 |

**WiFi 信号**，口径略有不同：

| dBm | 信号感受 |
| --- | --- |
| -30 左右 | 贴着路由器 |
| -50 左右 | 很好 |
| -60 左右 | 良好 |
| -70 左右 | 开始吃力，网页变慢 |
| -80 以下 | 掉线边缘 |

这些是通用经验值，不是官方给死的标准，够你日常判断用。

## 三、RSRP、RSRQ、SINR 三个指标的区别

蜂窝页签的列表里每个小区都带三个数值，含义不同：

| 指标 | 全称 | 回答的问题 |
| --- | --- | --- |
| RSRP | 参考信号接收功率 | 信号有多强 |
| RSRQ | 参考信号接收质量 | 信号干不干净 |
| SINR | 信噪比 | 有用信号比噪声强多少 |

实际判断时两个数一起看：RSRP 还有 -85 但 SINR 是负的（比如 -2），说明基站离你不远、但周边干扰重，网速照样上不去。**「信号强但网速慢」多数就是这种** —— 排查思路见 [常见问题与权限说明.md](常见问题与权限说明.md)。

## 四、小区参数逐项解释

蜂窝页签除了当前小区，还会列出邻近小区，每行大致长这样：`3025 | B7: 2600 | -99`，字段含义：

| 字段 | 含义 |
| --- | --- |
| PCI | 物理小区标识，同一片区域里区分不同小区的编号 |
| EARFCN | 载波频点号，代表这个小区工作在哪个频率上 |
| B7 / B3 | 频段编号；B7 对应 2600 MHz、B3 对应 1800 MHz，数字不同就是不同频段 |
| 15+15 FDD | 上下行各 15 MHz 载波带宽（FDD 双工）；带宽越宽，理论峰值速率越高 |
| IN SERVICE | 当前小区处于服务状态 |
| LTE-A / 5G NSA | 聚合载波或非独立组网的 5G 标识 |

看邻区列表的用处：往窗外或路口走几步，观察哪个邻区的 RSRP 在变强 —— 数字持续上爬的方向，通常就是最近的那座基站的方向。想把塔落在地图上看，翻 [基站定位与地图功能.md](基站定位与地图功能.md)。

## 五、顶部状态行与信号曲线

当前小区上方有一行状态，例：`260 03 (Orange) | LTE-A + 5G NSA | IN SERVICE`。`260 03` 是运营商编码（MCC-MNC，260 是波兰、03 是 Orange），你手机上显示的就是自己运营商对应的编码。状态里出现 5G NSA 还是 5G SA，两者的差别与影响单独成篇：[5G NSA与SA怎么区分.md](5G NSA与SA怎么区分.md)。下面的曲线是信号随时间的变化图：原地不动看着平缓，走动时起伏大 —— 用它对比不同位置的接收稳定性最直观。

## 六、通知栏常驻与双卡

- 设置里可以打开**通知栏常驻**，不用进应用就能瞄到当前网络类型和信号。
- 双卡机型在表盘页 WiFi / SIM1 旁边切换另一张卡；两张卡分属不同运营商时，正好用来对比哪家在你常待的位置信号更好。个别机型读不到第二张卡，这取决于机型而非设置，见 [常见问题与权限说明.md](常见问题与权限说明.md)。

还没装的话，安装文件在开头网盘链接里；装好后的数据怎么落到地图上，接着看 [基站定位与地图功能.md](基站定位与地图功能.md)。
