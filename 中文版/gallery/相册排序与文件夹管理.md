## 一、主界面按文件夹组织

打开 Gallery，第一屏是文件夹网格：每个格子代表手机里的一个图片目录，左下角标注文件夹名和里面的媒体数量，点进去就是该目录的照片网格。顶部工具栏有三个入口：

| 顶部入口 | 作用 |
| --- | --- |
| 排序按钮 | 打开排序方式对话框 |
| 相机图标 | 快捷拍摄入口 |
| 三点菜单 | 本篇第四节的管理入口都在这里 |

进入单个文件夹后，顶栏换成返回箭头、文件夹名、搜索、视图切换与三点菜单，找图和整理都在这一层做。

## 二、五种排序方式

点顶栏的排序按钮（或文件夹内三点菜单里的「排序方式」），会弹出排序对话框：上面一组选依据，下面一组选方向。

| 排序依据 | 什么时候用 |
| --- | --- |
| 名称 | 文件名有规律（如 IMG_2024 这类）时按名字找 |
| 路径 | 同名文件多，想按所在目录区分 |
| 大小 | 清空间时先揪出占地方的大文件 |
| 修改日期 | 找最近动过、刚保存的图 |
| 拍摄日期 | 按拍摄时间线翻照片、找回忆 |

方向选「递增」或「递减」，点「确认」生效，点「取消」放弃改动。日常最常用的是「修改日期 + 递减」，新照片永远排最前面；整理旧照片时换「拍摄日期」更直观。

## 三、调列数、换视图与搜索

- **增加一栏 / 减少一栏**：在三点菜单里，一键把网格调密或调疏。找批量截图用密一点，给家人翻照片用疏一点，全凭手感。
- **更改视图类型**：切换缩略图的排列样式，配合列数把界面调到顺手为止。
- **搜索**：文件夹内顶栏的搜索入口，按名字定位文件，图片多的目录里比一页页翻快得多。

这三项都是即调即生效，不满意随时改回来。

## 四、不想看到的目录：隐藏、排除与缓存

三点菜单里管「看什么、不看什么」的入口有三个：

| 入口 | 干什么用 |
| --- | --- |
| 隐藏文件夹 | 把选中的目录从相册列表里藏起来 |
| 排除 | 让应用不把某个目录当相册扫出来，适合截图缓存这类不断生成新图的目录 |
| 显示／隐藏缓存内容 | 决定扫出来的缓存缩略图目录要不要显示 |

「隐藏」与「排除」效果相近、影响面不同：前者往往连其他相册应用里也看不到该目录，后者一般只影响本应用自己扫不扫它。不同版本的实现有出入，操作完换别的相册应用翻一下确认，别误藏了重要照片；藏完又想找回或找不到了，按[照片不显示或目录不见了的排查.md](照片不显示或目录不见了的排查.md)走一遍。

## 五、只看图片还是只看视频

三点菜单里的「要显示的媒体文件」用来筛选列表里显示的媒体类型。想让相册里只有照片、把视频先藏起来，或者反过来只翻视频，都在这里调；筛选只影响显示，不会动文件本身。
