# UBox 添加摄像头设备教程

> 这篇讲怎么把一台新摄像头绑进 UBox：WiFi 设备怎么配网、4G 设备怎么添加、配不上时逐条排查，最后是把设备共享给家人。

## 一、先让设备进入配网状态

不管是 WiFi 款还是 4G 款，第一步都是把摄像头切到「配置模式」：

1. 给摄像头通电（电池机先充够电，运输状态下电池一般只有一半左右的电）。
2. 等设备发出进入配置状态的提示。**WiFi 产品的指示灯会蓝灯闪烁**，部分型号还会带一句语音提示。
3. 灯没闪就先按一下机身的**电源/呼叫键**唤醒；还是不闪，长按复位键不放、直到蓝灯亮起松手，设备重启后即进入配网状态。各灯态分别代表什么，见 [设备指示灯状态与4G设置.md](设备指示灯状态与4G设置.md) 的灯语表。

## 二、添加 WiFi 摄像头

1. 手机连上 2.4GHz 的 WiFi，打开 UBox，点主界面的**「添加智能设备」**（或右上角「+」），进入设备安装界面。
2. 选 **「WiFi 设备安装」**。
3. 按屏幕提示完成配网 —— 应用支持**二维码**与**声波**两种方式：二维码方式是让摄像头扫应用生成的码（手机举到**离镜头约 10 厘米**处，太近太远都扫不上），声波方式是手机发出一段声音把 WiFi 账号密码传给设备。二维码扫不上就换声波，反过来也一样。
4. 等进度走完，设备列表里出现这台机器，点播放键就能看到画面。

## 三、添加 4G 摄像头

1. 装好 SIM 卡并开机，同样等设备进入配置状态（蓝灯常亮/闪烁，以型号说明为准）。
2. 在 UBox 主界面点「添加智能设备」，进入安装界面后选 **「4G 设备安装」**。
3. 按提示一路走到安装完成。4G 设备走的是流量网络，配网阶段不需要你填 WiFi，但要确认卡已激活、有信号。**扫设备二维码之前先等蓝灯常亮**；灯态不对、SIM 卡与 APN 的排查整体在 [设备指示灯状态与4G设置.md](设备指示灯状态与4G设置.md)。

## 四、添加失败时按这四条查

| 现象 | 处理 |
| --- | --- |
| 一直搜不到设备 | 确认设备真的在配置模式（蓝灯在闪）；部分产品配置模式才有语音提示 |
| 配到一半失败 | 手机与摄像头距离拉近到 1~2 米，避开蓝牙、微波炉等干扰源后重试 |
| 应用里不显示当前连着的 WiFi 名称 | 这是**位置权限**没给 —— 新版安卓只有拿到位置权限才能读到已连接的 WiFi 名，去手机的应用设置里允许 UBox 的位置权限 |
| 老是配不上路由器 | 确认连的是 2.4GHz 网络；把 2.4G 与 5G 改成不同名称再试；路由器别开访客网络 |

配网成功后建议立刻进 [报警推送与PIR设置.md](报警推送与PIR设置.md) 把通知打开，否则摄像头绑了也只会「静静地录」。

## 五、换地方安装要不要重新配网

- 换的位置 **WiFi 名称和密码都没变**：直接挪过去通电就行，不用重置。
- **名称或密码变了**：先唤醒设备，长按复位键约 5 秒、听到复位提示后进入配置状态，删掉旧 WiFi 信息，再按第二节重新配一次。

## 六、把设备共享给家人

对方也需要装 UBox 并注册一个账号，然后你在设备列表里进这台设备的**设置（齿轮图标）→ 共享权限 → 共享**，输入对方账号发出去；对方在自己的设备列表里就能看到这台摄像头了。共享出去的账号看不了你的账号设置，要收回权限也是在同一个入口取消。

装好之后想看画面怎么操作，见 [实时预览与双向对讲.md](实时预览与双向对讲.md)；录像从哪回放，见 [录像回放与云存储.md](录像回放与云存储.md)。
