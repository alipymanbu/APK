## 一、画面卡顿

摄像头这套东西依赖三段：摄像头端 WiFi、互联网、手机端网络，任何一段不够都会卡。先对着门槛量：

- 720P 需要约 **512 Kbps 上行**，1080P 需要约 **1024 Kbps 上行** —— 注意是**上行**，很多宽带套餐上行远低于下行，跑 1080P 会吃紧。
- 不够就把画质切到 720P（见 [实时预览与双向对讲.md](实时预览与双向对讲.md)），或换个信号强的位置看。
- 摄像头自身 WiFi 弱也会卡：手机先到安装位置连一下那个 WiFi，信号两三格以下就考虑加中继或换装位。

## 二、在家能看，出门看不了

两种典型情况：

1. **摄像头连上了家里 WiFi，但路由器没外网** —— 家里局域网通，云端不通，人一离开就摸不到设备。先用手机关掉 WiFi 用流量访问路由器后台，确认宽带有信号。
2. **手机端网络受限** —— 出门用的这个网络（公司 WiFi、某些流量卡）访问不了云服务，换 4G/5G 流量或另一个网络对比一下，能立刻定位是哪一端。还有一种是**手机没给 UBox 联网授权**：应用同时拿不到移动数据与 WiFi 的使用许可时，它连不到摄像头，画面自然是黑的 —— 去手机的应用联网管理里把 UBox 的 WiFi 与移动数据都放开。
3. **缓存顶满** —— 少数情况下是手机或路由器缓存满了导致取不到画面，重启（注意是重启不是重置）手机与路由器即可，摄像头不用动。

## 三、设备离线 / 掉线

- 看设备电源：电池机低电会主动下线，先充电（见下节）。
- 看路由器：重启路由器，确认摄像头连的还是原来的 2.4G WiFi。
- 挪过位置或改过 WiFi 密码的，按 [添加摄像头设备教程.md](添加摄像头设备教程.md) 第五节重新配网；**设备端灯态、4G 卡与信号的排查**（蓝灯闪不停、红蓝交替、APN）在 [设备指示灯状态与4G设置.md](设备指示灯状态与4G设置.md)。
- 离线期间卡里的录像 App 里读不到，**要取卡用读卡器读**；云上的片段不受影响，仍可回放。
- 低功耗机型休眠时本来就不在线，被 PIR 或你点预览唤醒后才上线 —— 看到「离线」先点一下预览试试，别急着重启。

## 四、电池几天就没电

低功耗机型靠「休眠 + 被叫醒」省电，耗电快基本都是**被唤醒太频繁**：

1. **运输电量只有约 50%**，第一次用之前先充满。
2. 把 PIR 灵敏度调低、减少无谓触发 —— 路边位置尤其明显，处理办法见 [报警推送与PIR设置.md](报警推送与PIR设置.md)。
3. 常插电使用的场景，直接接 USB 供电（充电电流约 500~800mAh，两块电池充满约 8 小时）。
4. 太阳能款靠板子补电，**阴雨连着超过一个月**或频繁唤醒，就该取下来用 USB 充一次。
5. 频繁进 App 看实时画面也在耗电，看一眼就退出来。

## 五、对讲有刺耳噪音

手机扬声器与摄像头喇叭互相收声形成的自激（类似在 KTV 靠近音箱的啸叫），把手机拿远、松开对讲键即可，远程对讲不会出现。细节见 [实时预览与双向对讲.md](实时预览与双向对讲.md)。

## 六、其他高频小问题

| 症状 | 处理 |
| --- | --- |
| 收不到通知 | 按 [报警推送与PIR设置.md](报警推送与PIR设置.md) 第三节开三个开关 |
| 注册邮件没来 | 去垃圾邮件箱找，部分邮箱会把注册信判成垃圾 |
| 配网时选不到当前 WiFi | 给 UBox 位置权限（新版安卓读 WiFi 名要它） |
| TF 卡满了 | 自动覆盖最早的片段；想留的尽早下载到手机 |
| 门铃与室内响铃配合使用 | 长按室内机按钮到 LED 亮，再按门铃键完成配对 |
| 安装包版本对不上 | 版本以 [下载与安装教程.md](下载与安装教程.md) 里那张表为准 |
