## 一、选了英文（或中文），视频还是另一种语言

这是用户反馈里最集中的一条：语言偏好选了英文，播放出来的仍是中文配音，只能靠字幕。出现这种情况，通常是这部剧本身只做了中文字幕的译制，而不是你的设置没生效。可以按这个顺序处理：

1. 换一部同类型的剧试试，确认是个别剧集的问题还是整片库的问题；
2. 找片方标注了多语言字幕的剧——热门榜上的剧一般译制版本更全；
3. 想看某部只有中文版的剧，就当「看画面 + 读字幕」用；
4. 问题持续出现在所有剧上，用应用内的反馈或客服入口提交，附上剧集名和语言设置截图。

## 二、某部剧点开提示不可用

有用户反馈部分剧集存在地区限制：点开直接报错，广告倒是照常加载。遇到这种情况：

1. 先换两三部别的剧确认范围——只有个别剧不行，就是这部剧在你所在地区没上架；
2. 如果整片库都打不开，更可能是网络问题，见下一节；
3. 地区限制没有用户端的开关可解，换别的剧是最直接的办法。

## 三、视频一直转圈、加载慢

| 可能原因 | 处理 |
| --- | --- |
| 网络波动 | 在 Wi-Fi 和移动数据之间切一次，或开关飞行模式 |
| 高峰时段服务器拥堵 | 隔一会儿再看，或先把后面几集缓存下来 |
| 应用长时间运行累积缓存 | 完全退出应用重开；手机系统的存储管理里清一次应用缓存（不清数据，观看记录还在） |
| 后台占满带宽 | 关掉正在下载/同步的其他应用再试 |

缓存入口和用法见[离线缓存与追剧技巧](离线缓存与追剧技巧.md)，提前在 Wi-Fi 下缓存是绕开高峰卡顿最稳的办法。

## 四、安装失败

按现象对症处理，完整安装步骤见[下载与安装教程](下载与安装教程.md)：

- **提示签名冲突 / 已存在同名应用**：卸载旧的 RapidTV 再装；
- **安装到一半失败**：多半是安装包损坏，用下一节的 MD5 方法核对，不一致就重新下载；
- **点安装没反应**：检查「允许安装未知应用」授权给了你实际用来打开安装包的那个应用（文件管理器或浏览器）；
- **系统版本过老**：安卓 5.2 以下装不了这份安装包。

## 五、核对安装包是否完整（MD5）

下载中断会让安装包缺斤短两，安装失败时值得先核对一次。安装包的正确 MD5 是 `5144EBBE1B03A4D97EF1BD44940B5DE6`（对应版本 4.2.0，32.83M）。

Windows 上在 PowerShell 里执行：

```powershell
certutil -hashfile "C:\Downloads\RapidTV_v4.2.0.apk" MD5
```

把输出与上面的值逐位比对（不区分大小写）。不一致或命令报错找不到文件，就重新从 [RapidTV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/40d11a0a99fc)转存下载一次。

安卓手机上也可以用带「文件校验」功能的文件管理器做同样的核对。

## 六、字幕不同步、中途换了语言

有用户反馈个别剧集字幕滞后几秒、或播到一半字幕从英文变成西班牙文。这类问题出在剧集的译制版本上，你能做的有限：

1. 退出该集重新进，有时会重新加载字幕轨；
2. 仍然不同步就换集看，确认是不是个别集的问题；
3. 用应用内反馈报给片方，附上剧名、集数和现象描述——译制问题只有官方能修。

## 七、金币看完广告没到账

1. 完全退出应用（从后台任务里划掉）再重新打开，金币一般会补发；
2. 查看金币流水（如果有这个入口），确认到账延迟了还是真的没发；
3. 还是不行就走应用内客服或反馈渠道，把看广告的时间点写清楚。
