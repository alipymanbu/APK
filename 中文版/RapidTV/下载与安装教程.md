## 一、安装前先了解 RapidTV

RapidTV 是一款竖屏短剧应用：一部剧拆成几十集，每集只有 1~5 分钟，竖屏全屏播放，适合通勤、排队这类碎片时间。题材以情感、逆袭、穿越、霸总这类强情节短剧为主，界面和应用内内容有多语言版本。它在 Google Play 上的完整名称是 RapidTV - Short Dramas，开发者为 Kennedyy，2024 年 11 月上架。

网上搜到的版本号可能比这里的更新——那是官方后续发的新版。本篇按下面这份安装包来写：

| 项目 | 信息 |
| --- | --- |
| 安装包版本 | 4.2.0（2026-09 整理） |
| 包名 | `com.rapid.short.tv` |
| 安装包大小 | 32.83M |
| MD5 | `5144EBBE1B03A4D97EF1BD44940B5DE6` |
| 系统要求 | 安卓 5.2 以上（安装包标注）；第三方收录页对较新版本标注安卓 7.0 起 |

安卓 7.0 及以上的手机装这份包没有问题；系统更老的手机可以先试，装不上多半是系统版本限制（见[常见问题与解决办法](常见问题与解决办法.md)）。

另外提醒一句：搜「RapidTV」这个名字会同时撞见好几个互相无关的同名应用（连应用商店里都有），装错、卸错的事时有发生，核对方法见[同名应用与下载避坑](同名应用与下载避坑.md)。

## 二、下载安装包

1. 打开 [RapidTV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/40d11a0a99fc)；
2. 把里面的安装包**转存到自己的夸克网盘**（分享链接里的文件通常要先转存才能下载）；
3. 在夸克网盘手机端找到 `RapidTV_v4.2.0.apk`，下载到手机存储。

手机存储空间建议至少留出 200M：安装包 32.83M，安装过程中还需要临时空间。

## 三、安装步骤

1. 在手机的文件管理或通知栏里点刚下载好的 `RapidTV_v4.2.0.apk`；
2. 第一次装这类安装包时，系统会提示「不允许安装未知来源应用」。按提示跳到设置页，找到你刚才用的文件管理器（或浏览器），打开「允许安装未知应用」。安卓 8 及以上是按来源逐个授权的，不用开全局开关；
3. 回到安装页点「安装」，等进度走完；
4. 点「打开」，或从桌面图标进入。

## 四、第一次打开要做的三件事

1. **选语言偏好**：启动后应用会让你选界面语言，想看中文字幕就在这里选中文（Chinese）；
2. **同意用户协议**：勾选同意后才能进入推荐流；
3. **认识两个入口**：首页一般是「为你推荐」的信息流和「热门」榜单，往下刷就会自动连播。金币、解锁这些看剧规则见[免费看剧与金币规则](免费看剧与金币规则.md)。

有用户反馈语言偏好在部分剧集上不完全生效（比如选了英文，视频仍是中文配音）——这多是因为剧集本身没有对应译制版本，不是你操作错了，处理思路见[常见问题与解决办法](常见问题与解决办法.md)。

## 五、装不上时的常见原因

| 现象 | 原因与处理 |
| --- | --- |
| 提示「存在签名冲突」或安装被中断 | 手机里已经装过另一个渠道的 RapidTV（包名相同、签名不同）。先卸载旧的再装这份 |
| 提示存储空间不足 | 清出至少 200M 再试 |
| 安装到一半失败 | 下载中断导致安装包不完整。用 MD5 值核对（方法见[常见问题与解决办法](常见问题与解决办法.md)），不一致就重新下载 |
| 点安装没反应或直接退出 | 系统版本低于安装包要求，或手机禁用了未知来源安装，回第三步检查授权 |
