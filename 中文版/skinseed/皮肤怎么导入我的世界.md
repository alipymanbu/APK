# Skinseed 的皮肤怎么导入我的世界

> 本篇讲皮肤做完之后怎么送进《我的世界》：一键导出到国际服手机版和 PC 版、保存到相册后在游戏里手动选图，以及网易国服为什么不能直接导出。

## 一、两条路线，先看你是哪个版本

| 你玩的是 | 走哪条路线 |
| --- | --- |
| 国际服手机版（基岩/PE） | 路线一：App 内一键导出；不行再走路线二手动选图 |
| 国际服 PC Java 版 | 导出后得到皮肤 png，在官方渠道上传 |
| 网易国服 | 两条路线都不适用，见第四节 |

## 二、路线一：一键导出

Skinseed 支持一键把当前皮肤直接导出到 Minecraft：在皮肤详情页点 Export（导出）按钮，选目标版本（手机版或 PC 版），剩下的交给游戏——下次进游戏角色就换上新皮肤了。这是官方宣传的核心卖点，多数情况下也是最省事的走法。

导出没反应、或者进了游戏皮肤没变，先看[常见问题排查.md](常见问题排查.md)的第三节。

## 三、路线二：保存到相册再手动导入

一键导出不好使时，手动路线一定走得通，Skinseed 能把皮肤存成手机相册里的图片，而国际服手机版本身就支持从相册选图换肤：

1. 在 Skinseed 里选中要用的皮肤，点右上角三个点，选「保存至照片」；
2. 打开《我的世界》国际服，进主界面的皮肤设置页；
3. 切到「经典皮肤」分类；
4. 点已有皮肤栏里的空白槽位，选「选择新皮肤」；
5. 从手机相册里选中刚导出的那张皮肤图片，等加载完成即可使用。

第 1 步得到的图片就是一张标准皮肤 png，所以这条路线同样适用于 PC Java 版：把图片传到电脑后，通过官方启动器或官网账号页的皮肤上传入口加载（入口位置以官方页面当前显示为准）。在手机上用第三方启动器（如 PojavLauncher 这类）玩 Java 版的，多数启动器的皮肤设置里也能直接选这张图片，入口位置随启动器各异。

导入时如果游戏报"请导入 64×64 的 png"（而你的文件明明就是 64×64），或者皮肤装上又被变回去，先看[皮肤尺寸与模型怎么选.md](皮肤尺寸与模型怎么选.md)第四节——问题多半出在游戏端而不是你的文件。

还没装 Skinseed 的，从文首的 Skinseed 安装文件资源（夸克网盘）取安装包，安装步骤见[下载与安装教程.md](下载与安装教程.md)。

## 四、网易国服：导出不适用

网易代理的国服没有开放外部皮肤文件的直接加载，Skinseed 的导出目标里也不包含国服——多个来源的口径一致：这款工具面向的是 Minecraft 国际服。想在国服换形象，只能走国服自己的组件中心获取皮肤；你在 Skinseed 里画的皮肤，可以先「保存至照片」留档，等在玩国际服时再用。

## 五、导入成功后动一下角色确认

换肤后主界面预览有时不刷新，进一张地图走两步、或者切换一次第三人称视角再看，确认皮肤真的上身了；多人联机时如果出现你和队友的皮肤互相"串"了的情况，处理办法写在[常见问题排查.md](常见问题排查.md)。
