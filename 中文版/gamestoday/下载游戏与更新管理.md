## 一、先认识四个入口

GamesToday 的主界面就几个常用位置，先分清它们省得来回找：

| 位置 | 你在这里做什么 |
| --- | --- |
| 首页推荐 | 看编辑挑出来的热门与新游，直接点进去 |
| 顶部搜索栏 | 输入游戏名精确定位，最快路径 |
| 下载中心 | 看正在下载的任务、进度、装完的游戏 |
| 下载中心里的「更新」页签 | 列出手机里已装游戏的新版本，一键升级 |

首次使用建议先让 App 拿到存储权限（`设置 → 应用 → GamesToday → 权限`，把存储给上），否则下载的包可能落不了地。

## 二、搜到并下载一个游戏

1. 在顶部搜索栏输入游戏名 —— 用中文俗称搜通常也能命中（公开教程里用「鹅鸭杀」这类俗称搜，下面直接出结果）。
2. 点开结果，能看到评分、开发商、体积等信息，确认是你要的那个再动手。
3. 点「一键下载」，任务进下载中心，进度实时显示。
4. 下载速度与你的网络直接挂钩：公开实测在常规网络下能到 10MB/s 量级，但前提是你的网络到它的服务器这段是通的（服务器不在内地，网络不稳就先看 [打不开与加载失败的解决办法.md](打不开与加载失败的解决办法.md)）。
5. 下载完成后，一部分游戏会自动进入安装流程；另一部分会停在下载中心等你手动点开安装 —— 后者走系统的安装确认页，需要你已授权「安装未知应用」。

**下载中断了怎么办**：它支持后台下载与断点续传，切出 App、锁屏都不会取消任务；网络恢复后回到下载中心点继续即可，不用从头再来。另外有资料提到大型游戏会**连同资料包一并下载安装**、自动适配机型 —— 你不用自己另外找资料包（以实际下载界面为准）。

## 三、更新已装的游戏

下载中心上方的「更新」是专门管这件事的：有新版本的游戏会列在那里，点一下就升级，不用你去原渠道重新找包。注意区分两个「更新」：

- **「更新」页签**：更新的是**你手机里已装的游戏**；
- **App 自身的更新**：装好之后新版本由官方另行发布，有下载站提到更新慢的问题时，多半是渠道同步延迟 —— 自己去官网比对版本号最直接。

## 四、下载中心还能做什么

- **看进度**：每个任务的当前体积、速率、剩余时间；
- **管安装包**：下完的 APK 留在本地，可以从这里打开、安装，或者按 [安装失败与安装包位置.md](安装失败与安装包位置.md) 里的路径自己去找；
- **删任务**：下错的、不想要的直接移除，避免占存储。

## 五、让下载更稳的三个习惯

1. **先清空间再下**：游戏包普遍几百 MB 到几 GB，下载前至少留出「包体积 + 解压安装」的余量，否则下完也装不上。
2. **保持网络一致**：下载中途在 Wi-Fi 与流量之间来回切，是断流最常见的原因。
3. **别同时开多个下载器抢同一个包**：多线程工具叠加不会更快，反而容易触发限流。
