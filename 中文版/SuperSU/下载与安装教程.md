# SuperSU 下载与安装教程（APK 安装 / TWRP 卡刷两种方式）

> 本篇讲 SuperSU 的两种安装形态怎么选、分别怎么装：已经 root 的设备直接装 APK，还没 root 的设备用 TWRP 刷入 ZIP 拿到 root。

## 一、先分清两种形态：APK 和卡刷 ZIP

SuperSU 向来是"两个包走两条路"，装错形态是新手最常见的弯路：

| 形态 | 文件 | 适合谁 | 装在哪 |
| --- | --- | --- | --- |
| APK | `.apk` 安装包 | 设备**已经 root**，想装或重装管理器 | 系统里直接安装 |
| 卡刷 ZIP | `.zip` 刷机包 | 设备**还没 root**，第一次拿 root | TWRP / CWM 等 recovery 里刷入 |

判断依据很简单：你手机现在用 root 类工具（整机备份、卸载器之类）时，会不会弹出授权窗口？

- 会弹 → 设备已有 root，你只缺一个管理器，走下面的「方式一」。
- 从没弹过、也没刷过任何 root 包 → 走「方式二」，用 ZIP 连 root 一起装。

本篇对应网盘里安装包的信息：版本 **2.82.1**，大小约 **5.91 MB**，包名 `eu.chainfire.supersu`，MD5 `6475E8EC2B286BE78AB1D10CAE466E40`。官方版本线到 v2.82 为止（含 SR1~SR5 修补版），此后不再有新版本——遇到"要不要升级"的问题时心里要有这个数。

## 二、装之前备好三样东西

不管走哪条路，这几样先备齐，能省掉大部分翻车：

1. **备份**：多数机型解锁 bootloader 会清空数据，刷入失败也可能要靠 recovery 还原。相册、聊天记录先导出；会玩 TWRP 的建议再做一份 Nandroid 整机备份。
2. **电量**：50% 以上再动 recovery，别在 10% 电量的时候刷机。
3. **渠道预期**：SuperSU 在 2018 年已从 Google Play 下架，之后没有应用商店渠道，都是通过 APK 安装包侧载安装。开头的夸克网盘里那份就是可用的安装包，下载后先别急着点。

## 三、方式一：设备已 root，直接装 APK

1. 下载 [SuperSU 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ae57de1aba73)，把 APK 传到手机（或手机上直接转存后下载）。
2. 点开 APK 安装。Android 8 及以上会问"是否允许来自此来源的应用"，允许一次即可。
3. 首次打开 SuperSU，多数情况会弹"需要更新 SU 二进制文件"：
   - 点「继续（Continue）」；
   - 方式选 **Normal（常规）**；
   - 等它跑完，按提示重启手机。
4. 重启后再打开 SuperSU，主界面能正常列出「应用」页，管理器就位了。

装好之后，root 请求的批准、拒绝、日志都归它管，具体玩法见 [root权限授权与日常管理.md](root权限授权与日常管理.md)。

## 四、方式二：设备未 root，用 TWRP 卡刷 ZIP

前提：bootloader 已解锁、TWRP（或 CWM）已刷入。这两样还没搞定的，先按你机型的教程处理好，本篇不展开。

安卓模拟器（BlueStacks、官方 AVD 等）没有 recovery，这条走不通，配置方法单独成篇：[安卓模拟器root配置指南.md](安卓模拟器root配置指南.md)。

**步骤：**

1. 把 ZIP 包放进手机内置存储（`Download` 目录就行，路径别太深）。
2. 关机，按住「电源 + 音量上」（组合键因机型而异，以你的机型为准）进入 TWRP。
3. 首次刷 root 前建议先备份：TWRP 里选 **Backup**，勾选 System、Data、Boot，滑块确认。
4. 回主界面选 **Install**，找到 ZIP 文件。
5. 选中后**滑动滑块确认刷入**（Swipe to Confirm Flash）。
6. 等底部日志出现 **Successful**。整个过程一般几十秒，中途别强制重启。
7. 可顺手 Wipe cache/dalvik（可选，不清也行）。
8. 选 **Reboot System**。第一次开机会明显比平时慢，等它跑完，别慌。

ZIP 在电脑上不方便拷进手机时，TWRP 还有 sideload 这条路：

```bash
# 手机端：TWRP → Advanced → ADB Sideload → 滑动开始
# 电脑端（ZIP 放在 adb 同目录）：
adb sideload SuperSU-v2.82.zip
```

刷完开机后，手机里会出现 SuperSU 应用。个别 TWRP 版本会在刷完时问"要不要顺便安装 SuperSU 应用"，选不装即可；APK 侧的安装按「方式一」来。

## 五、装完花一分钟验证

随便挑一个需要 root 的工具（文件管理器、卸载器都行），做一次会触发 root 的操作：

- 弹出 SuperSU 的授权窗口 → 点「允许（Grant）」→ 工具正常干活，说明 root 和管理器都正常。
- 工具直接报"没有 root / 无 SU 二进制" → root 没到位，多半是只装了 APK 没刷 ZIP，回「方式二」。

对不上号的情况，基本都能在 [常见问题与报错处理.md](常见问题与报错处理.md) 里找到对应条目。

## 六、几个容易踩的点

- **SR 修补版只能靠刷 ZIP 升级**，装 APK 升不动 SR 系列的底层文件。不过这条如今意义不大——2.82 之后官方就没再发过新版。
- **三星 Nougat 时期的机型**有加密分区的兼容坑，刷之前先查你这个机型怎么处理加密，拿不准就搜"机型名 + SuperSU"。
- **系统版本支持范围**：官方口径从 Android 2.3 起支持，社区实测大约可用到 Android 9；Android 10 及以后基本没有保障，直接看 [与Magisk的区别及怎么选.md](与Magisk的区别及怎么选.md)。
- 哪天想取消 root，**别直接在系统设置里卸载 SuperSU**，正确姿势在 [完整卸载与取消root方法.md](完整卸载与取消root方法.md)。
