## 一、先确认你要装的是哪一个

CorelDRAW 这个名字最出名的，是 Corel 公司面向专业设计场景的桌面图形设计套件（Windows / macOS / 网页版），那是付费软件，安装包体积以 GB 计。

本篇讲的是安卓手机上的同名应用：一个轻量的绘图与设计工具，安装包只有 1.14M，中文界面，功能围绕画笔绘图、形状与模板拼搭、图片编辑和成品导出。**两者不是同一个软件**。如果你想在手机上随手画一画、做点简单设计，装这份手机版就够用；如果你要的是桌面级的完整设计套件，请通过官方渠道去找桌面版，别拿这份安卓包混淆。

## 三、转存与下载步骤

1. 打开 [CorelDRAW 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ce1adf6415da)；
2. 登录你的夸克账号，把安装包**转存到自己的网盘**（不转存，链接失效后就没有了）；
3. 打开夸克网盘 App（或网页版），找到刚才转存的 APK 文件，点下载；
4. 下载完成后，在通知栏或手机「文件管理」的下载目录里点开这个 APK，进入安装。

## 四、安装时被系统拦一下，是正常现象

安卓对非应用商店来源的安装包都会拦一道，处理方式：

- 安装时弹出「不允许安装未知来源应用」提示 → 点提示里的「设置」，**允许本次来源安装**即可，装完可以再把开关关回去，不必长期开放；
- 部分机型在夸克 App 内点开 APK 就能直接跳转安装，不用自己找文件；
- 想核对文件完整性（可选）：算一下 MD5，与上面表格里的值一致，说明包没有下坏。电脑上用 PowerShell 敲：

  ```powershell
  certutil -hashfile "下载的apk文件名.apk" MD5
  ```

  手机上多数文件管理器长按文件 →「详情 / 属性」里就能直接看到 MD5，不用装额外工具。

## 五、装不上时，按这个顺序查

1. **安装包没下完整** —— 重新下载一次，换稳定的网络，再核对 MD5；
2. **系统版本过低** —— 上表两条系统要求记录不一致，老设备装不上多半是这个原因，先看自己手机的安卓版本；
3. **存储空间不足** —— 包本身只有 1.14M，但安装过程要解压，建议留出几百 MB 余量；
4. **包名冲突** —— 手机里如果装过同包名的旧版本，先卸载再装；
5. 装上了但打不开、闪退 —— 翻 [常见问题与解决.md](常见问题与解决.md)，那里按「装不上 / 打不开 / 用不明白」分类列了处理办法。
