## 一、装不上

| 现象 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| 提示「未知来源应用」 | 系统安装拦截 | 按提示去设置里允许本次安装，见[下载与安装教程.md](下载与安装教程.md)第四节 |
| 提示「解析包出错」 | 包没下完整 | 重新下载，核对 MD5 为 `F5C3F92B7E24A616B47F87E612952D30` |
| 提示系统版本不符 | 手机安卓版本 | 老设备升级系统，或换一台系统更新的手机 |
| 点了没反应 / 卡在安装中 | 存储空间 | 清出几百 MB 余量再装 |
| 提示已存在同名应用 | 包名冲突 | 先卸载旧版本（`com.coreldrawdesign.app`）再装 |

## 二、打不开或闪退

1. **先重启手机再开**，排除一次性的内存不足；
2. **确认安装包来源**：如果装的不是完整包，应用可能一开就崩，回到网盘重新转存下载一遍；
3. **清后台再试**：后台挂的绘图、修图类应用多了，低内存设备容易被系统杀掉进程；
4. 反复闪退且重启无效，卸载后用完整安装包重装一次。

## 三、用不明白

- **新建画布找不到入口**：走「底部 Tools → Graphic Editor → Create Blank」这条路径，按钮名以界面实际显示为准，详细步骤见[界面与基础操作入门.md](界面与基础操作入门.md)第二节；
- **文字加不上**：进编辑器后要点的是画布右下角的 **+ 号**，选 Text、输入内容后点 Insert，文字才会上画布；
- **模板在哪**：应用内置模板与素材库，新建时或编辑器里可以直接调用，选一个现成框架改内容；
- **导出的图去哪了**：在手机「相册」或「文件管理」里按图片找，具体落点以你导出时选择的目录为准。

## 四、它和桌面版 CorelDRAW 是什么关系

| | 手机版（本篇讲的应用） | 桌面版 CorelDRAW |
| --- | --- | --- |
| 形态 | 安卓 App，安装包 1.14M | Windows / macOS / 网页版软件，付费 |
| 定位 | 手机上画笔绘图、形状模板拼搭、图片编辑与导出 | 专业矢量插图、排版、照片编辑套件 |
| 适合 | 随手画、做简单设计图 | 印刷级、专业设计产出 |

名字相同，**不是同一款软件**。另外留意一个常见误会：桌面版 CorelDRAW 的工程文件是 `.cdr` 格式，这份手机版没有公开说明支持打开 `.cdr` 文件 —— 如果你拿到的是别人发的 `.cdr` 源文件，手机上有哪些看与改的途径，单独整理在 [CDR文件怎么打开.md](CDR文件怎么打开.md)里。
