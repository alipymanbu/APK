# Pixaloop 烟雾特效怎么做

烟雾是 Pixaloop 里被问得最多的效果之一，做法比想象中简单：它不在动画菜单里，而是「叠加（Overlay）」分类下的一层现成素材，选上就有，调一个强度参数基本就能用。本篇给出中文界面的完整路径，以及三个把雾调自然的技巧。

## 一、四步加上烟雾

1. 打开应用，新建项目并选好照片。
2. 点底部工具栏的「**叠加**」（Overlay；部分版本显示为「覆层」，是同一个菜单）。
3. 左右滑动分类，找到「**天气**」一组，选其中的烟雾 / 雾气款（分类里靠前的一两款就是）。
4. 照片上出现烟雾后，用**上方的强度进度条**调浓淡，最后点右上角分享 / 导出图标出片。

这四步在不同时期的中文教程里描述一致，1.8.1 这类较旧版本同样适用；差异主要在素材款式多少。

## 二、把烟雾调自然的三个手法

- **强度别拉满**：进度条拉到中段以下，雾感若隐若现最像实拍；一拉满就是明显的「贴上去」。
- **给雾一个方向**：想要雾飘起来的动感，回「动画」菜单在雾的位置画一两根 Path 箭头，方向和雾的形态一致（箭头画法见[让照片动起来的操作步骤](让照片动起来的操作步骤.md)）。
- **别让雾盖住主体**：人物、建筑上不小心叠到雾时，用冻结或遮罩把主体护住，或整体降强度。

适合叠雾的照片：山林、湖面、清晨街道、夜景灯光——画面里有空气感的位置，雾才放得住。

## 三、找不到烟雾素材时

- 素材列表需要**联网加载**，先确认网络可用再回菜单刷新；
- 你装的 1.8.1 与官方最新版的素材库不完全一致，新教程里的某款烟雾素材旧版可能没有，换同类款效果相近；
- 带皇冠 / Pro 标的款要点订阅才能用，免费款里也有烟雾类可选。

雾叠好之后想再加工（换天空、加光斑、调色），看[天空替换与特效叠加](天空替换与特效叠加.md)；出片时格式怎么选，看[导出保存与格式选择](导出保存与格式选择.md)。
