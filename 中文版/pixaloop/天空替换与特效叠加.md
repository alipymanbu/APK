除了手动画路径，Pixaloop 更省事的路子是套现成素材：一键换天空、往照片上叠雨雾光效。本篇讲这几类效果菜单的用法和素材选择上的注意点。

## 一、Sky：把天空换掉并让它动

Sky 菜单做的事是「识别原照片的天空区域，替换成会动的天空素材」：

1. 选一款天空素材（晚霞、流云、星空等），应用自动识别并替换原天空。
2. **双击素材**可以调参数：不透明度、流动方向等；不同素材可调项不一样。
3. 地平线识别不准时，用 Horizon（地平线）工具手动调整替换区域的高度。
4. 替换边缘有残留（比如树叶缝里露出原天空）时，用边缘清除工具把漏掉的地方补进替换区。

对天空大面积留白的风景照，这一步比手画路径快得多，效果也更完整。

## 二、Overlay：天气与氛围特效层

Overlay 是一层层往照片上叠的动态素材，常见类型：

| 类型 | 适合的画面 |
| --- | --- |
| 雨 / 雪 | 街景、窗户、人物侧影 |
| 雾气 / 烟雾 | 山林、湖泊、夜景灯光 |
| 光斑 / 光线（Light Rays） | 树荫、逆光人像、教堂窗 |
| 火花 / 星星 / 光点 | 夜景、篝火、节日场景 |
| 落叶 / 花瓣 | 秋景、花园、唯美风人像 |

用法：进 Overlay 菜单选一款素材，它会以独立图层叠在照片上；**双击素材**调密度、方向、速度、透明度。多个 Overlay 可以叠加，比如「雾气 + 光斑」做清晨氛围。其中问得最多的烟雾效果单独写了一篇：[烟雾特效怎么做](烟雾特效怎么做.md)。

操作习惯上有个通用规律：**选中素材后双击，就能进它的参数面板**，这在 Sky、Overlay、相机运动里都一样。

## 三、相机运动：Tilt / Zoom / Dolly

Animate 菜单之外还有一组镜头效果，给整张照片加摄影机式的运动：

- **Tilt（倾斜）**：画面朝一个方向倾斜流动；
- **Zoom（变焦）**：向内推近或向外拉远；
- **Dolly（推拉）**：模拟镜头前后移动的纵深感。

这类效果作用于整张照片，适合做「照片在呼吸」的感觉，常与 Path 动画配合：局部流水用箭头驱动，整体再叠一层缓慢的 Zoom。

## 四、滤镜与参数微调

导出前最后统一调色：亮度、对比度、饱和度、色温都在调整菜单里，按需微调即可。动效照片调色的意义和修图一样——多张成片风格统一时尤其值得调。

## 五、素材上的订阅标识

部分 Sky 和 Overlay 素材带 Pro / 皇冠标识，选中就会弹订阅提示，这些**必须订阅才能用**；不带标识的素材免费直接用，天气类的基础效果（雨、雾、光斑）免费可用的款不少。素材库随版本更新，你装的 1.8.1 与官方最新版的素材列表不会完全一致，找不到某款素材多半是这个原因。
