## 一、这些游戏是给谁玩的

Pata 的小游戏全是**多人局**，设计上偏熟人局：你和你拉进来的好友组队，靠文字和动作表达，不需要全程开语音。官方介绍里反复提「社恐也能玩」——所有玩法都能只打字参与。下面的清单是截至 2026-09 各版本公开介绍里出现过的，**你装的版本里有哪几款，以游戏界面上实际列出的为准**。

## 二、玩法清单

| 玩法 | 一句话说明 | 人数感受 |
| --- | --- | --- |
| 谁是卧底 | 经典描述与投票局，人人拿到不同的词，找出说得最可疑的那个 | 多人局，最常被官方更新提到 |
| 你演我猜 | 一人比划一人猜，考的是好友之间对彼此脑回路的了解 | 至少两人配合 |
| 默契猜词 / 默契问答 | 出题后各选各的答案，答案对不上就说明「最好的默契就是没默契」 | 多人对比作答 |
| 画画拼图（传画拼图） | 每人画一笔往下传，看最后变成什么离谱东西 | 多人轮流 |
| 谁最有可能 | 投票类题目局，互相投「最有可能做这件事的人」 | 多人投票 |
| Pata 猜词 | 宠物出题考你，偏知识向的猜词 | 单人也能玩 |
| 专注花园 | 和好友比拼专注时长，赛博种花，谁坐得住谁的花长得好 | 好友榜对比 |
| 寻宝冒险 | 拼运气的出门冒险，开出来的宝藏看脸 | 好友间比运气 |

另外还有两个跟游戏相关的小功能：

- **观战模式**（2.2.0 起）：好友正在对局时你可以围观，不参与只看；
- **派对房语音**：渠道介绍里提到过支持多人实时语音的派对房，是否在你版本里可用，进界面看。

## 三、怎么加入一局

公开介绍与更新日志里能确认的入口是这几条：

1. 打开 Pata，进**游戏界面**（主界面下方的功能区），列出的就是当前版本有的玩法；
2. 选一个玩法 → 进匹配，系统把同局的人凑齐后开局；
3. 也可以直接拉好友一起玩——2.3.0 的更新日志提到「可以更快速地找到正在对局中的游戏房间」，说明对局是以**房间**形式存在的，好友的房间你能从房间列表里找到并加入；
4. 不想下场就用观战，站在旁边看朋友互相怀疑。

匹配的具体规则（每局几个人、怎么分队、能否自建房间）没有查到公开的详细说明，**以游戏界面里给的提示为准**——进任何一个玩法，它都会先展示规则说明再让你确认。

## 四、玩之前值得知道的三件事

- **对局不直接产出星星币**。有用户在应用商店评论里提议「玩游戏赢了可以增加星星币」，反过来说，目前赢对局并不是星星币的获取途径，想攒币走签到和任务，见[星星币怎么获得与用途.md](星星币怎么获得与用途.md)。
- **有人物形象的地方就能换装**，装扮要用星星币买，先进试穿预览（2.2.0 起装扮间支持预览未拥有的物品），别看上头直接下单。
- **玩不动 / 匹配不到人**：先看是不是好友都在线时段不对，再查网络；卡在匹配界面的排查见[常见问题与故障排查.md](常见问题与故障排查.md)。

## 五、和养成部分怎么串起来

小游戏不是独立一块——对局里的表现会被写进宠物的观察日记，成了你们几个共同经历的一部分。上手顺序建议：先按[新手入门与领养教程.md](新手入门与领养教程.md) 把宠物领了、好友加了，再回来开局，否则只有你一个人，很多玩法根本凑不齐。
