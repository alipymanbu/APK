## 一、安装阶段

**症状：提示「解析包时出错」/「安装包已损坏」**

1. 多半是下载中断导致文件不完整——重新下一次这份 [Pata 安装文件资源（夸克网盘）](https://pan.quark.cn/s/282ff2d3a943)，别在弱网下断点续传凑合；
2. 下完核对大小应为 103.22M、版本 2.12.0；
3. 还是不行就换个下载工具或浏览器重新拉一次。

**症状：点了安装没反应 / 显示「已阻止安装」**

- 这是系统在拦「未知来源应用」：`设置 → 安全/隐私 → 安装未知应用`，给你下载所用的浏览器或文件管理器勾上允许，再回到安装包点一次。各品牌路径略有差异，在设置里搜「安装」两个字最快。

**症状：显示「与其他应用冲突」或签名不一致**

- 手机上已装的 Pata 来自另一个渠道（比如商店版与这份包的签名不同）。先确认你装它是为了什么——**要保留数据**就别卸载，改用同渠道的新版本覆盖；**可以重来**才卸载后重装，装完用同一手机号登录把记录拉回来。

## 二、登录阶段

**症状：收不到短信验证码**

1. 先核对手机号有没有输错；
2. 看手机的骚扰拦截/短信过滤，验证码经常被归进垃圾短信；
3. 隔一会儿再点一次获取（频繁点会触发频率限制）；
4. 换网络（Wi-Fi 与流量互切）再试——验证码下行本身依赖网络请求；
5. 一直收不到，用应用内提供的联系方式或渠道客服反馈，别反复轰炸重试把账号限制住。

**症状：登录后宠物、家具不见了**

- 先确认登录的手机号是不是原来那个——数据挂在账号上，登错号就是空的。确认是同一个号还缺，再看是否为版本差异导致的展示变化（各渠道版本跨度很大，见[下载与安装教程.md](下载与安装教程.md) 第三节）。

## 三、运行阶段

**症状：闪退 / 打不开 / 白屏**

按命中成本从低到高排：

1. **清缓存**：`设置 → 应用 → Pata → 存储 → 清除缓存`（**别点清除数据**，那会把本地记录一起清掉），再打开试；
2. **看网络**：Pata 需要联网，先确认别的应用能上网，弱网下它可能停在加载页；
3. **查系统版本**：系统太旧会装得上但跑不起来，官方介绍标注的系统要求以商店页为准（iOS 侧公开说法是 15.5 及以上）；
4. **重装**：前三步都没用，再走覆盖安装一遍新包。

**症状：桌面心情组件不显示**

按命中成本从低到高排（这套是安卓小组件的通用排查，三星等厂商支持文档里给的也是这个顺序）：

1. **先删掉重新添加**：长按桌面上的组件移除 → 桌面长按空白处 → 小组件 → 重新找 Pata 加一次；
2. **重启手机**：组件数据没刷出来时，一次重启就能解决大半；
3. **确认应用是最新版**：旧版本可能没带这个组件，或组件有 bug 已在新版修掉；
4. **清一次缓存**：`设置 → 应用 → Pata → 存储 → 清除缓存`（别点清除数据）；
5. **查权限与后台**：组件要靠应用在后台拉数据，在「省电/后台管理」里给 Pata 放行（各品牌路径不同，一般在 `设置 → 电池 → 后台耗电管理`），同时确认通知、网络等权限没被禁；
6. **看桌面有没有锁**：部分手机的「锁定布局/主屏幕布局已锁定」开着时组件加不上去，先在桌面设置里解锁；
7. **检查存储空间**：存储快满时系统会限制组件加载，腾出空间再试。

另外有个前置条件别漏：**先在应用里把心情状态设置并确认过一次**，组件显示的是应用内的状态，应用里没设过它就没内容可渲染，设置路径见[宠物心情状态怎么设置.md](宠物心情状态怎么设置.md)。

**症状：小游戏卡在匹配 / 加不进好友房间**

- 先确认网络与好友是否同版本——版本差太多可能对不上房间；
- 匹配长时间无响应就退出重进一次对局入口；
- 玩法本身怎么进，见[小游戏玩法与怎么加入对局.md](小游戏玩法与怎么加入对局.md)。

## 四、账号与数据

**换手机，记录还在吗？**

在新手机装好 Pata，用**同一个手机号**收验证码登录即可，养成记录挂在账号上。换机前建议先在旧机确认能正常登录，别把号锁在旧设备的号码上（尤其是用他人号码注册的）。

**想注销账号 / 换绑手机号**

应用内的账号设置里有相关入口（不同版本位置不同）；换绑属于会丢失数据的操作，动手前先确认新号已能收到验证码。隐私相关的条款见官方站点 [www.pipimiaomiao.top](http://www.pipimiaomiao.top) 上公示的隐私政策页面。

## 五、还是解决不了怎么办

带上这几样信息去问，效率最高：

- 包名 `com.ppcat.pata`、版本号 2.12.0（或你实际装的版本）；
- 手机品牌与系统版本；
- 具体症状 + 报错原文截图；
- 你从哪个渠道装的（网盘这份 / 应用商店）。

官方站点 [www.pipimiaomiao.top](http://www.pipimiaomiao.top) 公示了运营方联系方式（重庆皮皮喵喵科技有限公司，联系邮箱 `pipicat023@qq.com`），也可在应用商店该应用的详情页里提交反馈。
