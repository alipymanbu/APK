## 一、先说结论

Pata 的玩法可以压成一句话：**登录 → 领养一只宠物 → 摆你们的小屋 → 拉好友进来 → 没话聊时开一局小游戏**。它的互动全是围绕「你」和「你认识的人」展开的，没有陌生人匹配、没有广场信息流，所以上手成本很低，但前提是你得先拉到一两个一起玩的人。本篇按这个顺序走一遍。

## 二、登录：手机号 + 验证码

1. 装好打开，先在「欢迎使用 Pata」页点同意（不同意进不去，协议全文可在应用内查看）。
2. 进登录界面后输入手机号 → 获取短信验证码 → 填入 → 登录。

账号就是这个手机号，换手机后用同一个号登录即可拉回养成记录（见第五节）。收不到验证码的处理在[常见问题与故障排查.md](常见问题与故障排查.md)。

## 三、领养你的第一只 Pata

登录进主界面后，按公开教程的说法，流程是这样的：

1. 点击页面上的 Pata 形象，触发对话、选中并领养它；
2. 它会主动找你说话，你直接回就行，聊什么都行；
3. 它会让你喂它——**按住它（长按）就是喂食**，喂饱之后它会开始跟你互动；
4. 之后每天点它、跟它说几句，它会慢慢形成自己的性格与爱好。

喂食这一操作的具体手势来自公开教程的描述，不同版本界面可能有调整，以你屏幕上出现的提示为准。

主界面上你能做的事大致三类：

- **互动**：点击宠物触发对话、喂食、清洁、换装；
- **装修**：进小屋区域给宠物换装扮、挪家具、换房间布局；
- **看状态**：宠物的心情、日记入口、你的星星币余额。

## 四、把好友拉进来：共创小屋

Pata 的核心不是单机养宠，而是「和好朋友住一起」：

- 在消息界面可以添加好友、跟好友单聊，2.2.0 起也支持**群聊**；
- 邀请亲友共同布置那间虚拟小屋——挑家具、摆装饰、换风格，是几个人共用一个空间；
- 你去好友那儿「串门」、好友也来你这儿，互动会被自动记进宠物的日记里；
- 小屋在 2.1.0 之后升级成了多房间格局（官方更新日志里的说法是「四室一厅」），具体几间看你版本。

拉人方式就是站内加好友，没有查到支持站外链接直接进屋的公开说明，加不到就让对方用同一个手机号注册再搜你。

## 五、观察人类日记与桌面心情组件

- **观察人类日记**：宠物以它的视角写下的互动记录，你在它的日记页翻看，等于一份共同生活流水账。
- **桌面心情组件**：把状态显示在手机桌面上，不用打开应用就能看到自己和好友的动态。添加方式是系统的「添加小组件」操作（桌面长按空白处 → 小组件），列表里找 Pata；如果列表里没有，多半是版本还没带上这个功能或被系统限制了后台，排查见[常见问题与故障排查.md](常见问题与故障排查.md)。

## 六、数据存在哪、换手机怎么办

应用商店里的功能说明写着「数据云端自动同步，换机登录原账号即可完整恢复所有养成记录」——也就是说，**认的是手机号，不是这台手机**。换机流程：旧机不删也能用，在新手机装好 Pata（[下载与安装教程.md](下载与安装教程.md)），用同一个手机号收验证码登录，养成记录跟着账号走。

这条是渠道介绍里的说法，没有查到官方对同步范围（比如家具摆放、日记内容是否全量同步）的详细说明，换机后自己核对一眼，缺了什么以应用内实际显示为准。

## 七、第一天的推荐动线

1. 登录 → 领养 → 喂饱它；
2. 进小屋随便挪两件家具，感受下装修怎么操作；
3. 加一两个真实会玩的朋友进来；
4. 没话题的时候去游戏界面开一局——玩法与加入方式见[小游戏玩法与怎么加入对局.md](小游戏玩法与怎么加入对局.md)；
5. 顺手把每日签到点了，星星币是买装扮的硬通货，攒法见[星星币怎么获得与用途.md](星星币怎么获得与用途.md)。
