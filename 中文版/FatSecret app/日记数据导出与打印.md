## 一、为什么要导出

日记数据存在账号里，日常看趋势在应用里就够了；但有两类场景你需要拿到文件：换设备前留一份离线备份、或把一段时间的记录发给营养师 / 医生看。应用内置的导出功能一次能出一个时间段的报告，格式有 **PDF** 和 **CSV** 两种——PDF 适合直接看和转发，CSV 可以丢进表格软件自己算。

## 二、导出步骤（iOS）

1. 进入**食物日记**页，向下滚动找到**导出图标**，点击它。
2. 点**期间（Period）**调整报告的日期区间。
3. 点**报告类型（Report Type）**选择明细程度。
4. 点**格式（Format）**选 **PDF** 或 **CSV**。
5. 点**分享（Share）**把报告发出去（系统分享面板里可存文件、发邮件、传社交应用）。

## 三、导出步骤（Android）

Android 端入口相同，只是选项换成了图标：

1. 进入**食物日记**页，滚动到**导出图标**并点击。
2. 点**日历图标**调整日期区间。
3. 点**图表图标**选择报告的明细程度。
4. 点**文档图标**选 **PDF** 或 **CSV**。
5. 点**导出（Export）**发送报告。

图标样式随版本可能有调整，认不准时按「日期 → 明细 → 格式 → 导出」这个顺序逐个点一遍即可；界面以你装的版本当时显示为准。

## 四、导出前值得知道的几点

- **先定区间再导**：导出是按日期范围出报告的，想只要一周就先把期间调成一周，别导完整年再手工裁。
- **明细程度影响文件大小**：选得越细，逐条记录都进报告，PDF 会明显变长；给外人看汇总，选粗一档就够。
- **CSV 是给计算用的**：要自己做统计（比如按食物类别汇总）就导 CSV，用表格软件打开；只给人读就用 PDF。
- **导出前先把记录补全**：报告只反映已记入日记的内容，漏记的不会出现在文件里——补录方法见 [食物日记记录方法.md](食物日记记录方法.md)。
- **体重数据的去向**：这份食物报告以日记条目为主，体重曲线的查看与说明在 [体重变化趋势怎么看.md](体重变化趋势怎么看.md)。

## 五、报告深度与免费版的关系

报告功能本身在免费版里可用（免费档为有限深度、Premium 为深入档，对照见 [免费版与Premium功能对比.md](免费版与Premium功能对比.md)）。你导出的内容取决于当前档位里能看到的报告层级，以应用内实际显示为准。
