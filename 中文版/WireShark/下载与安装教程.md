## 一、装之前先核对这几件事

先说结论：WireShark 安卓版是一个装在手机上的网络抓包分析工具，安装包体积小（5.14M），对系统要求不高，多数安卓手机都能装。本篇按「转存 → 下载 → 安装 → 首次启动」的顺序走一遍，最后附上装不上时的排查思路。

安装前建议先核对：

| 项目 | 本文采用的口径 |
| --- | --- |
| 版本 | 1.2.1 |
| 安装包大小 | 5.14M |
| 包名 | com.cool.wireshark |
| 系统要求 | 安卓 5.2 及以上 |
| 界面语言 | 简体中文 |

这套版本信息来自对这份安装包本身的核对（记录于 2026-09-23）。网上搜到的版本号可能更高，那是官方后来发的新版，与你实际装上的不一定是同一版；版本号、包名、体积一律以你手里这份安装包为准。

## 二、从网盘拿到安装包

WireShark 的安装包通过夸克网盘分享，入口：[WireShark 安装文件资源（夸克网盘）](https://pan.quark.cn/s/dd8cd3811a06)。

1. 打开链接，把分享内容转存到自己的网盘（不转存直接下载，部分文件可能受限）；
2. 在夸克网盘客户端里找到转存后的 APK 文件，下载到手机本地存储；
3. 记住文件位置，通常在 `Download` 目录或网盘客户端的下载目录里。

想核对文件完整性：安装包的 MD5 为 `FA213789356B159498DCB3784E7AF57F`（大小写不敏感），可用文件管理器或校验工具比对，对得上说明文件没在传输中损坏。

## 三、安装步骤

1. 在文件管理器里点开下载好的 APK；
2. 系统提示「不允许安装未知来源应用」时，按提示允许文件管理器（或你用来打开 APK 的应用）安装——各品牌入口不同，有的在安装弹窗里直接给「仍要安装」，有的要跳到设置里单独开权限；
3. 回到安装界面，点「安装」，等进度走完；
4. 点「打开」或回桌面点图标启动。

首次启动时如果弹出网络、存储等权限申请，按需允许即可——抓包类工具读取网络状态是正常要求，不给权限大概率抓不到数据。

## 四、装不上怎么办

按出现频率从高到低排查：

- **提示解析失败 / 安装包损坏**：重新下载一遍，顺手核对 MD5；下载中断是最常见的原因。
- **提示与设备不兼容**：确认系统版本不低于安卓 5.2。1.2.1 版本针对「部分机型因兼容性无法使用」的问题做过修复，个别老机型或深度定制系统仍可能装不上，这类情况没有通用的绕法。
- **存储空间不足**：5.14M 的包本身不大，但安装过程需要额外空间，清出几百 MB 再试。
- **之前装过同包名的应用**：包名相同（com.cool.wireshark）的旧版本会挡住新安装，先卸载再装。

装好之后怎么用，直接看[抓包教程.md](抓包教程.md)；安装环节之外的问题，去[常见问题排查.md](常见问题排查.md)找。
