## 一、先确认你拿到的是哪一版

网上能搜到的通常是官方最新版，而网盘里这份安装包的信息如下，写文档、核对文件都以它为准：

| 项目 | 值 |
| --- | --- |
| 应用名称 | Image Toolbox（开源项目名 ImageToolbox） |
| 版本 | 3.5.0 |
| 安装包大小 | 31.93M |
| 包名 | `ru.tech.imageresizershrinker` |
| 文件 MD5 | `9B9B19D2A8B6BB2EC7904F411E6F8675` |

包名带 `imageresizershrinker` 字样，是这个应用早期项目名（Image Resizer/Shrinker）留下的痕迹，属于正常现象——识别一款应用时，包名比界面标题更可靠。

如果你想要官方最新版，可以去项目发布页 [github.com/T8RIN/ImageToolbox](https://github.com/T8RIN/ImageToolbox) 查看；但要注意新版的界面与功能比 3.5.0 多，操作细节与本套文档可能对不上。

## 二、从夸克网盘拿到安装文件

1. 打开 [Image Toolbox 安装文件资源（夸克网盘）](https://pan.quark.cn/s/81f454d19e99)，把里面的安装包**转存到自己的夸克网盘**（分享内容可能随时间失效，转存后才是你自己的）；
2. 在夸克网盘客户端里找到这份 APK，下载到手机存储；
3. 下载完成后直接在通知栏或「下载管理」里点开安装。

## 三、安装步骤与「未知来源」授权

安卓不允许应用商店之外的程序直接安装，第一次装会碰到授权提示：

1. 点开下载好的 APK，系统会问「是否允许此来源安装应用」；
2. 选择**允许**（不同厂商的叫法略有差异：有的叫「安装未知应用」，在设置的「安全」或「应用管理」里授权）；
3. 回到安装界面，点「安装」，等进度条走完；
4. 装完点「打开」，首次启动会请求读写存储的权限，建议同意——否则选不了相册里的图。

常见的两个拦路提示：

- **「解析包时出现问题」**：多数是文件没下完整，重新下载一次再装；
- **「应用未安装」**：如果手机里已经装过同包名的其他来源版本，签名不一致会拒绝覆盖安装，先卸载旧版再装。

## 四、安装前想核对文件，可以看这几样

- **MD5**：用手机或电脑上的校验工具算一下 APK 文件的 MD5，和第一节的表格对得上，说明文件没有损坏或被替换；
- **签名证书**：官方在项目 Wiki 里公布了 GitHub 版的签名证书指纹（SHA-256 以官方 Wiki 当时显示为准），有验证习惯的读者可以用 `apksigner` 的 `--print-certs` 参数核对。注意 Google Play 和 F-Droid 渠道的包由渠道方用自己的证书重新签名，指纹不同属正常。

## 五、GitHub 版与商店版的差别

Image Toolbox 是开源应用，同一个包名在不同渠道发的东西略有差别。官方说明的差异主要有这些：

| 项目 | GitHub 直接下载版 | Google Play / F-Droid 版 |
| --- | --- | --- |
| 二维码扫描 | 基础实现 | MlKit 实现 |
| 自动抠图 | 可用（含 U2Net 模型，3.5.0 起） | MlKit 实现 |
| 文档扫描 | OpenCV 实现 | MlKit 实现 |
| 统计与崩溃报告 | 无 | 有（Google 渠道版） |

对普通读者来说，日常修图这些差异几乎感知不到；纠结的话，选与本文对应的这份安装包即可。两套版本的其他功能完全一致。

## 六、系统要求与语言

- 官方各版本对最低安卓版本的要求随版本递增，3.x 时期的安装包一般要求 Android 6.0 上下的机型，最新版要求更高，装之前以官方发布页的标注为准；
- 应用内置中文界面：首次启动或设置里把语言（Language）切到「简体中文」即可，翻译覆盖主界面与大部分工具页。
