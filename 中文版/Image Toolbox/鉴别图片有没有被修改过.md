# 鉴别图片有没有被修改过

> 怀疑一张图被 P 过、被拼接过时，可以用 Image Toolbox 3.5.0 新增的几个取证滤镜做初步检查——结论只能当线索，不能当证据。

## 一、先用对工具：这四个滤镜是干这个的

3.5.0 的更新日志里新增了四个偏「图片取证」的滤镜，装好这一版就能在滤镜列表里找到：

| 滤镜名称 | 查什么 |
| --- | --- |
| Error Level Analysis（误差水平分析） | 图内不同区域的压缩痕迹是否一致，被改动过的区域常与周围不一致 |
| Copy Move Detection（复制移动检测） | 同一张图内「复制一块贴到另一处」的拼接 |
| Luminance Gradient（亮度梯度） | 呈现亮度变化，肉眼辅助查看边缘异常 |
| Average Distance（平均距离） | 辅助查看局部像素差异 |

用法与普通滤镜一样：打开图片 → 滤镜工具 → 在列表里找到对应名称应用即可。前两个用来「下判断」，后两个用来「看细节」，配合缩放逐块看。

## 二、每种滤镜看懂什么

**Error Level Analysis 是流传最广的检查思路**：JPEG 图片保存时整个画面按统一规则压缩，被后来贴上去或修改过的区域会多经历一次「保存」，压缩痕迹与原图区域不同。应用滤镜后，视觉上「某块特别亮或特别暗、与周围不协调」的位置就值得怀疑——尤其是人物边缘、文字、Logo 附近。

**Copy Move Detection 针对同图拼接**：把图里某个部分复制过来盖住另一处（比如抹掉一个人）是常见改法，这个滤镜会把相似度异常的区块标出来。

**两个亮度类滤镜**本身不直接给结论，它们把肉眼难察觉的过渡差异放大，让你看清楚边界与纹理是不是自然延续。

## 三、解读结果的几条纪律

- **正常操作也会留痕**：转发、截图、二次压缩、社交平台转码都会造成压缩不均，ELA 亮一块不等于一定被改过；
- **横竖都要交叉看**：单滤镜异常只算线索，两三个滤镜指向同一处、且位置在语义上可疑（比如恰好盖住车牌），才值得认真对待；
- **改得干净或重存的图会漏**：改完整体重新压缩、或对无压缩源图（PNG 直出）做检查时，痕迹可能很弱——查不出来不等于没改过；
- **别拿它下最终结论**：这是初筛工具，真要定论需要原图比对，滤镜只能告诉你「往哪看」。

## 四、顺手把元数据也看一眼

修改痕迹看画面，来路看元数据：EXIF 里的拍摄时间、机型、软件字段能提供旁证（比如「软件」字段写着另一款编辑器的名字）。查看与清空 EXIF 的操作在[使用教程与常用操作.md](使用教程与常用操作.md)第五节；更完整的工具地图见[功能一览与适用场景.md](功能一览与适用场景.md)。
