## 一、批量处理怎么进、能批什么

在选取图片时多选（长按进入多选、或点选多张，以你手上版本的界面为准），应用会进入批量模式，把同一步操作套到每张图上。

两点先说清楚，免得走弯路：

- **不是所有工具都支持批量**。官方在问答里明确提过这一点，批量缩放、批量转换、批量压缩、批量加水印这类「规则明确」的操作支持得好；抠图、局部绘制这类每张图都要单独动手的操作批不了；
- **批量前先拿一张试参数**。同一条参数压在几十张图上，画质落差比单张明显，先用一两张试出合适值再放大批量。

批量任务跑完统一输出到保存目录，文件名可以在保存设置里指定命名规则，避免几十个文件覆盖同名。

## 二、格式转换：支持哪些格式

转换入口可以单张进，也可以批量进。常见格式覆盖如下（以实际版本的转换列表为准）：

| 目标格式 | 适合场景 |
| --- | --- |
| JPG | 通用照片格式，兼容性最好 |
| PNG | 需要透明背景、或要求无损时 |
| WEBP | 体积比 JPG 小一截，社交与网页场景通用 |
| HEIF / HEIC | 苹果设备生态常用 |
| JXL / TIFF / QOI / ICO | 归档、印刷、图标等特定用途 |
| GIF（静态） | 把单帧输出为静态 GIF |

注意两点：

- **转格式不等于压缩**。PNG 转 JPG 体积会明显变小（因为有损），JPG 转 PNG 体积反而可能变大（无损格式装下了压缩痕迹）；
- 带透明通道的图转成 JPG 后，透明部分会按你选的背景色填充，想要白底还是黑底在这一步选。

## 三、压缩：把体积降下来

两个思路，按用途选：

- **按质量压缩**：拉低 JPG/WEBP 质量参数，肉眼几乎看不出差别的区间一般在 75~90，保存前有预览可对比；
- **按尺寸缩小**：直接把分辨率降到目标宽高，适合「传微信群不糊就行」的场景——聊天场景下 1280 宽通常够用，比单靠降质量更有效。

压缩和转换可以叠在一起做：转 WEBP + 降质量，通常是同画质下体积最小的组合。

## 四、图片转 PDF、PDF 转图片

- **图转 PDF**：多选图片 → 转 PDF，顺序可以拖动调整，扫描页合成一份文档就靠这个；
- **PDF 转图片**：把 PDF 每页导出成图，方便在只认图片的场合使用；
- **文档扫描**：对着纸面拍照，应用辅助裁边，再走转 PDF 的流程，纸面文件就转成了电子文档。

需要把 PDF 里的文字提取出来，转图片后走 OCR，步骤见[抠图与文字识别教程.md](抠图与文字识别教程.md)；安装、保存路径一类的基础问题集中在[常见问题解答.md](常见问题解答.md)。
