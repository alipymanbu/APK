## 一、把图片导进来

主界面点加号或「选取图片」，来源可以是：

- 相册与文件管理器（第一次会请求存储权限）；
- 直接拍一张（调起相机）；
- 从网络链接加载图片（粘贴图片地址）；
- 别的应用「分享」过来的图——在微信、浏览器里点分享、选 Image Toolbox，也能直接进编辑器。

选完图进入编辑器，底部或侧边的工具栏切换不同功能。以下操作都针对单张图；几十张图一起处理的方式写在[批量处理与格式转换.md](批量处理与格式转换.md)。

## 二、裁剪与调整尺寸

- **裁剪**：拖动边框定范围，可以锁定固定比例（1:1、4:3、证件照比例等），也能自由拖拽；拖动时双指可旋转画面；
- **缩放**：按宽、高或百分比改尺寸，改之前确认「保持宽高比」开关的状态，否则图会被拉变形；
- 先裁剪再缩放，比反过来做少一次画质损失。

## 三、调色与滤镜

滤镜页把效果一条条列出来，可叠加成「滤镜链」：比如先加对比度、再套一个胶片色调、最后压一层暗角，一条链上按顺序生效。

- 调色类（亮度、对比度、饱和度、色温）适合先把底子调正；
- 风格类（胶片、黑白、油画、复古等）数量很多，用列表里的预览缩略图挑比挨个点快；
- 链条建好之后可以保存成自己的模板，下次直接套用；
- 参数宁少勿多：叠的层数越多，细节损失越明显，屏幕上看到合适就停手；
- 滤镜不全是用来美化：3.5.0 新增了四个取证类滤镜（误差水平分析、复制移动检测等），用于检查一张图有没有被改过，用法与判读见[鉴别图片有没有被修改过.md](鉴别图片有没有被修改过.md)。

## 四、写字、打码与标注

进绘制 / 标注工具后常用的几支笔：

| 笔刷 / 工具 | 用途 |
| --- | --- |
| 画笔 | 自由涂画，可选粗细、颜色、样式 |
| 文字 | 插入文字框，改字体字号，双指可缩放旋转 |
| 像素化 / 模糊笔刷 | 涂过的地方打码，适合遮挡头像、车牌、验证码 |
| 贴纸 / 图片笔刷 | 往图上盖贴纸或另一张图 |
| 形状与箭头 | 圈重点、画指示线 |

打码建议用像素化笔刷多涂一遍，比半透明马赛克更保险——半透明的涂层遇到高对比背景仍可能被推断出内容。

## 五、查看与修改 EXIF

EXIF 是照片里藏的拍摄信息（时间、机型、GPS 位置等）。Image Toolbox 可以查看、编辑和清空这些字段：

- 发图给外人之前，把 GPS 位置相关的字段清掉是好习惯；
- 给图加上自定义的作者或备注字段，也在这里改。

## 六、保存与导出

点保存后按需设置：

- **格式**：JPG / PNG / WEBP / HEIF 等按需选；无透明需求选 JPG 或 WEBP 更省空间；
- **质量**：JPG/WEBP 拉质量滑条，一般 80~90 之间体积与画质的平衡点比较合适；
- **保存位置**：默认输出到存储里名为 `ImageToolbox` 的文件夹，也可以每次自选目录和文件名；
- 保存成功后通知栏会提示文件路径，找不到文件时先按这个路径去翻，更多排查见[常见问题解答.md](常见问题解答.md)。

单张流程走熟之后，两件事最值得接着学：一是把主体抠出来，见[抠图与文字识别教程.md](抠图与文字识别教程.md)；二是批量与格式转换，见[批量处理与格式转换.md](批量处理与格式转换.md)。
