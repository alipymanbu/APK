## 一、为什么你的语言包下不下来

OCR 语言包不在安装包里，首次使用时才从服务器下载，所以「装完发现没有语言」是正常起点，不是故障。真正下不动，常见原因按顺序排查：

1. **网络环境**：语言包托管在外网仓库，Wi-Fi 与移动数据互换着试，是最快的排除法；
2. **旧版本的托管变更**：官方在后续版本的更新说明里提过，AI 模型更换了托管位置，**旧版本以后可能下载不到模型与数据**——如果你装的是较早的版本（比如 3.5.0），应用内下载一直失败时不用反复重试，直接走第三节的手动导入；
3. **应用没有网络权限**：少数定制系统会默认收回联网权限，到系统设置里确认。

## 二、三档语言包怎么选

手动导入前先知道下哪一档。官方用 Tesseract 的三套数据仓库，同一门语言有三档：

| 档位 | 仓库特征 | 适合 |
| --- | --- | --- |
| fast | 体积小、速度快 | 日常截图、清晰文本，够用 |
| standard | 精度与体积折中 | 一般拍摄件 |
| best | 精度优先、体积大 | 模糊、字体复杂的图 |

三套仓库都在 Tesseract 官方的 GitHub 上（`tessdata_fast` / `tessdata` / `tessdata_best`），进入仓库找到对应语言的 `.traineddata` 文件下载即可；文件名按 `{语言代码}.traineddata` 命名规则来，中文相关的代码以仓库内实际列表为准。

## 三、手动导入的完整步骤

官方 Wiki 给出的流程如下（以 Wiki 当时说明为准）：

1. **下载**：从上表任一仓库下载你需要的 `.traineddata` 文件，可以一次下多个语言；
2. **打包**：把文件按下面的目录结构压成一个 ZIP——至少要有一个档位文件夹：

   ```text
   你的压缩包.zip
   ├─ standard/
   │   └─ tessdata/
   │       ├─ xxx.traineddata
   │       └─ xxx.traineddata
   ├─ best/
   │   └─ tessdata/
   │       └─ xxx.traineddata
   └─ fast/
       └─ tessdata/
           └─ xxx.traineddata
   ```

3. **导入**：打开 OCR 工具的语言选择器，从里面发起导入，选中刚做的 ZIP；
4. **验证**：导入完成后语言列表里出现对应条目，选它跑一次识别确认可用。

最容易翻车的是第 2 步的**层级**：必须是 `档位文件夹 / tessdata / .traineddata` 三层，`.traineddata` 直接裸放在压缩包根目录是识别不到的，这是手动导入失败的第一大原因。

## 四、导入成功后识别还是不准

- 源图质量占大头：截图比拍摄的纸面准，糊图先找原图；
- 中英混排要同时勾选两种语言；
- 有用户反馈手机端 OCR 整体与桌面工具有差距，识别别抱「百分百还原」的预期，长段文字建议识别后人工校一遍。

基础识别操作（框选、导出、批量）在[抠图与文字识别教程.md](抠图与文字识别教程.md)第二节；如果连应用本身都装不上，先回[下载与安装教程.md](下载与安装教程.md)排查，别在语言包上空耗。
