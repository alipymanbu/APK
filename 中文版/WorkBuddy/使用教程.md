## 一、发起第一个任务

打开 App，主页底部就是输入栏。用大白话把需求写进去，点发送即可，不需要任何指令格式。描述时把四件事交代清楚，结果质量差别很大：

1. **目标**：要生成什么、处理什么（「生成一份分析报告」「整理这些照片」）。
2. **输入**：数据或参考文件在哪（后面第三节的附件方式）。
3. **输出格式**：Word、Excel、PPT 还是 Markdown。
4. **约束**：风格、字数、截止时间。

发送后它会自动把任务拆成多个步骤，每个步骤以卡片形式展示，点右侧箭头可展开看它具体干了什么，完成的步骤会打上绿色标记。任务创建后出现在左侧任务列表里，点顶部「+」可以再开新任务，多个任务并行跑互不影响。

## 二、选模型：默认 Auto，看图才换

点输入栏里的模型名称（默认显示「Auto」）弹出选择面板。模型列表随版本更新会变，以 App 内实际显示为准，常见的一批如下：

| 模型 | 能力标签 | 参考用途 |
| --- | --- | --- |
| Auto | 推理 + 视觉 | 系统自动匹配，拿不准就用它（默认） |
| Hy3 | 推理 + 视觉 | 高性能推理与视觉理解 |
| GLM-5.2 | 推理 + 视觉 | 长上下文，适合长程任务 |
| GLM-5.1 | 推理 | 多步骤复杂任务的深度推理 |
| MiniMax-M3 | 推理 + 视觉 | 原生多模态，代码与智能体任务 |
| Kimi-K3 | 推理 + 视觉 | 长程自主任务、前端开发 |
| DeepSeek-V4-Flash | 推理 + 视觉 | 快速响应，兼顾视觉理解 |
| DeepSeek-V4-Pro | 推理 + 视觉 | 高性能推理与分析 |

两条实用规则：

- **能力标签里没有「视觉」的模型看不懂图片**。要拍照识别、发截图，先确认选的模型带「视觉」标签，否则 AI 读不到图的内容。
- **积分倍率不同**。面板里每个模型下方标着倍率（如 x0.80、x1.00），数字越低消耗越少。日常简单任务用性价比高的，需要理解图片再切到带视觉的，没把握就保持 Auto。

免费能用到哪、积分用超了怎么补，见[积分与免费额度](积分与免费额度.md)。

## 三、加附件：拍照、相册、文件与腾讯文档

点输入栏左侧「+」展开工具面板，六种入口按需选：

| 入口 | 能加什么 | 数量限制 |
| --- | --- | --- |
| 拍照 | 现场拍纸质文档、白板、发票、名片 | 每次拍 1 张，多张要重复操作 |
| 照片/视频 | 从相册选已有图片 | 一次最多 5 张 |
| 手机文件 | 表格、文档、PDF、图片 | 常见格式见下表 |
| 腾讯文档 | 已连接账号的腾讯文档文件 | 授权后读取 |
| 定时任务 | 不加附件，用来设周期任务 | 见第四节 |
| 专家 | 浏览各领域专家并发起对话 | 按行业分类浏览 |

手机文件支持的常见格式：

| 类型 | 格式 |
| --- | --- |
| 表格 | .xlsx、.xls、.csv |
| 文档 | .docx、.doc、.txt |
| PDF | .pdf |
| 图片 | .jpg、.png、.gif |

一个省操作的习惯：要多张图时先用手机自带相机拍完，再从「照片/视频」一次选 5 张，比一张张「拍照」快得多。腾讯文档如果还没连接，首次点进去按提示授权一次即可。

## 四、定时任务：把周期性的事设一次

两条创建路径都在自动化页面：

- **表单创建**：点「+」图标，填标题、提示词、执行频率（每天、每周、每月）与执行时间，点「创建」。
- **对话创建**：点「对话创建」，直接用大白话描述，比如「每天早上 9 点推送昨日行业新闻摘要」「每周五下午 5 点生成本周工作总结」，它解析后自动建好。

建好之后的管理动作都在任务卡片上：点右上角「...」可以编辑、**测试运行**（立即执行一次，先验证再上线）、暂停/恢复或删除；点卡片本身进入任务详情，能看到每一次执行的历史记录。执行结果靠通知推送，所以通知权限要保持开启（权限申请见[下载与安装教程](下载与安装教程.md)第四节）。

一个边界要注意：这套配置是「云端工作」环境下的玩法；切到「连接电脑」环境时，自动化页面用于接收电脑端自动化任务的执行结果，而不是在手机上新建定时任务。

适合交给定时任务的需求举例：每日资讯摘要、周报初稿、定期数据汇总。付费档位对自动任务数量有限额（免费版 3 个，限免期间 99 个），额度口径见[积分与免费额度](积分与免费额度.md)。

## 五、执行中：追问、中断与重新生成

- **追问**：任务跑完在同一对话里继续打字，比如「把表格按销售额排序」「再加一个饼图」「导出成 PDF」，上下文保留，不用重新交代背景。
- **中断**：任务进行中输入栏会出现停止按钮（方块图标），点它随时打断；打断后可以补充说明或改需求重发，已执行的部分不浪费。
- **重新生成**：长按某条 AI 回复，在弹出菜单里点「重新生成」，它会按同样的输入重跑一遍。

## 六、把产物拿走

任务完成后，产物文件直接出现在对话里，支持预览 PDF、DOCX、Markdown 等格式。两个去向：

1. **存到手机**：点开产物进预览页，点右上角「分享」，导出为 PDF、DOCX、Markdown，或直接导出到腾讯文档。
2. **发给别人**：点产物右上方的分享按钮，确认后生成分享链接，可转发到微信、QQ 等渠道。

对结果不满意时不必推翻重来——直接在对话里说改哪里（见第五节的追问），它会保留上下文重新生成。完整操作走通之后，可以读[是什么与能干什么](是什么与能干什么.md)把更多场景用起来；想在电脑上跑任务、手机上下指令的，去看[连接电脑与远程操控](连接电脑与远程操控.md)。
