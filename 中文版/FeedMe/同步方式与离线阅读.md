## 一、四种同步方式，先分清再设

官方文档把同步分成四种，做的事不一样：

| 方式 | 怎么触发 | 做什么 |
| --- | --- | --- |
| 完整自动同步 | 按设定间隔自动跑 | 上传已读/加星/标签 → 抓未读 → 抓加星 → 下载图片和全文 → 下载播客 |
| 快速自动同步 | 打开应用时自动跑 | 上传已读/加星/标签 → 抓未读 |
| 完整手动同步 | 侧栏右上角的同步按钮，或列表页菜单里的「同步」 | 与完整自动同步相同 |
| 快速手动同步 | 列表页下拉 | 上传已读/加星/标签 → 抓未读，且只同步当前列表对应的内容 |

两个要点：

- 完整同步才会下载图片、全文和播客，这是离线阅读的前提；快速同步只是「把新文章的标题和摘要拿回来」；
- 下拉刷新（快速手动同步）按当前列表算范围：列表是「所有条目」就同步全部源，是某个类别或单个源就只同步它；而加星条目列表只同步加星文章。

设置入口：

- 完整自动同步的间隔：设置 → 同步 → 自动同步 → 同步间隔（安卓有休眠机制，间隔到了未必立刻执行，通常有延迟）；
- 打开应用时自动同步：设置 → 同步 → 自动同步 → 打开「打开应用时自动同步」；
- 下拉刷新：设置 → 操纵 → 打开「下拉刷新」；
- 每次手动选同步内容：设置 → 同步 → 打开「显示同步方式」，之后点同步按钮会弹出选项框。

## 二、同步未读条数：控制本地留多少

入口：设置 → 缓存 → 未读条目。

- 设 500 条而服务端未读超过 500：每次同步只拉最新的 500 条；
- 服务端未读不足 500：全量拉取；
- 本地已有 500 条未读、服务端又来了 10 条新的：本地最旧的 10 条会在 FeedMe 里标成已读，但这个「本地标已读」不会上传到服务端。

订阅量大的人把这里调小，同步更快、占用更少；想精读存档的人调大，代价是每次同步更久。

## 三、同步模式：整体、类别、订阅源

设置 → 同步 里可以选按什么范围下载：

| 模式 | 下载逻辑 | 能禁止谁不同步 |
| --- | --- | --- |
| 整体 | 只按文章发布时间倒序拉，速度最快 | 不能禁止任何类别或订阅源 |
| 类别 | 按类别拉，未读少的类别优先 | 可禁止某类别，不能禁止单个订阅源；未分类的订阅源同步不到 |
| 订阅源 | 按订阅源拉，未读少的源优先 | 可禁止单个订阅源，不能禁止类别 |

想跳过更新很勤但你不想看的源，选「订阅源」模式再去禁用它。

## 四、中国模式是什么

- 它是给国内网络环境用的开关：安装时设备国家设为中国会默认启用；用了 VPN 可以关掉；
- 启用后，下载图片和全文时会自动放弃不可访问域名的链接，整体下载速度会快一些（域名清单写死在应用内，随应用更新）；
- 代价：同步模式设置失效，强制按「整体」方式跑，没法自定义某些源不更新。

## 五、流量与已读行为

- 默认所有自动联网动作只在 WiFi 下进行；用移动数据同步要去 设置 → 同步 → 流量 里改；
- FeedMe 从服务端只拉未读条目，已读状态本身会上传（随完整同步上传已读/加星/标签），但「已读的文章内容」不会重新拉回来——所以在手机上读完的文章，换台设备登录同一账号也不会把全文带过来；
- 列表里「已读文章不见了」不是丢了，是默认隐藏已读：点文章列表页操作栏上的圆圈图标，可以在「未读文章」和「全部文章」之间切换，这个切换同时影响侧栏（未读模式下只显示还有未读的源）。

## 六、离线阅读的正确姿势

1. 连上 WiFi；
2. 手动点一次完整同步（侧栏同步按钮），或者把自动同步间隔设短一点让它自己跑完；
3. 等图片和全文下载完，之后飞机、地铁上打开就能读；
4. 播客想离线听的话，同样靠完整同步下载，收听玩法见 [播客与TTS朗读.md](播客与TTS朗读.md)。

自动同步一直不生效的（设置了间隔却从不在后台跑），基本是系统电池优化把应用杀了，处理办法见 [常见问题排查.md](常见问题排查.md)。
