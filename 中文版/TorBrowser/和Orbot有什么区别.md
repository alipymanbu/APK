# Tor Browser（安卓版）和 Orbot 的区别

> 两个都是 Tor Project 生态里的安卓应用，但分工完全不同：一个只管浏览器里的流量，一个管全局。本篇讲清楚什么时候只需要装浏览器、什么时候两个都要。

## 一、一句话分工

- **Tor Browser**：一个浏览器，只有在这个浏览器里打开的网页走 Tor；
- **Orbot**：一个系统级代理应用，让设备上其他应用的流量经过 Tor。

两者包名不同：浏览器是 `org.torproject.torbrowser`，Orbot 是 `org.torproject.android`。装一个不等于装了另一个，也没有谁包含谁。

## 二、对照表

| | Tor Browser | Orbot |
| --- | --- | --- |
| 形态 | 浏览器 | 代理应用 |
| 作用范围 | 仅浏览器内的流量 | 可代理设备上其他应用 |
| 典型用法 | 匿名浏览网页 | 让聊天、邮件等应用走 Tor |
| 网桥配置 | 在浏览器设置里配 | 在 Orbot 应用里配 |
| 获取 | 官网 apk、商店 | Google Play、F-Droid |

## 三、什么时候两个都要

- 只想匿名看网页：装 Tor Browser 就够；
- 想让某个即时通讯或邮件应用也走 Tor：装 Orbot，再把那个应用接进去；
- 两个都装时互不替代：浏览器和 Orbot 各自独立配置网桥，浏览器不会自动借道 Orbot；
- 用 Orbot 的 VPN 模式时，社区经验是按应用勾选、只把确实需要的接进来，银行、办公类应用不接入能少踩坑；它和手机上其他 VPN 的撞车问题单独立了一篇，见[和VPN一起用会冲突吗](和VPN一起用会冲突吗.md)。

## 四、iOS 用户

iOS 上没有官方 Tor 浏览器。官方推荐的开源替代是 Onion Browser，但受平台要求限制（iOS 浏览器必须使用 WebKit 引擎），它提供不了与安卓版 Tor Browser 同等的隐私保护 —— 这是苹果平台的约束，不是开发者的取舍。

## 五、两句常见误区

- Tor 不会让设备上所有应用自动匿名，没接进 Orbot 的应用照常直连；
- 走 Tor 的网页浏览明显更慢，部分网站会拒绝 Tor 出口节点的访问，这是网络结构的代价，不是安装出了问题 —— 排查思路见[连接失败排查方法](连接失败排查方法.md)。
