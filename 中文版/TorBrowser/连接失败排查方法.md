# Tor Browser（安卓版）连接失败排查方法

> 进度条卡住、反复报错连不上 Tor 时，按本篇从易到难排查：看日志、对错误、换网络、换网桥、更新重装。
> **相关文档**：[网桥配置方法.md](网桥配置方法.md) · [下载与安装教程.md](下载与安装教程.md) · [安全级别设置.md](安全级别设置.md)

## 一、先看 Tor 日志

连接页点「配置连接」（或启动后进 设置 → 连接），拉到底部点「Tor 日志」，看完点「复制」可把整段日志拷出来对照。官方支持门户列了几类最常见的报错，对应关系如下：

| 日志里的特征 | 含义 | 处理 |
| --- | --- | --- |
| `general SOCKS server failure`、连 SOCKS 代理失败 | 你的网络需要代理，或代理参数填错 | 不需要代理就去掉代理设置；需要就核对地址与端口 |
| `Failed to find node for hop 0`（连不上第一跳） | 所在网络把 Tor 入口拦了 | 配网桥，见[网桥配置方法](网桥配置方法.md) |
| `Failed to complete TLS handshake`、握手反复失败 | 与目录服务器的加密握手被干扰 | 同上，配网桥 |
| `clock is behind / skewed time`（时钟偏差） | 设备时间不准 | 校准系统时间与时区，然后重启浏览器 |

## 二、换个网络再试

手机流量与 Wi-Fi 走的是不同出口，一个被拦另一个未必；公司网、校园网常有额外限制，家用宽带和 4G/5G 的结果也可能不同。换网后重开浏览器再连一次，这是成本最低的一步。

## 三、两个容易忽略的坑

- **应用被移到了 SD 卡**：安卓版的已知问题 —— 移到 SD 卡后无法连接，装回内置存储即可恢复；
- **手机时间不准**：时间偏差太大会导致握手失败，开启「自动确定日期与时间」再重连。

## 四、更新或重装

过旧的版本可能因证书更新、节点目录变更而连不上。更新方式任选其一：应用商店内更新；或按[下载与安装教程](下载与安装教程.md)重新拿 apk 覆盖安装。覆盖装不上就先卸载再装 —— 注意卸载会清空应用数据，装好后要重新走一次首次连接流程。

确认版本的办法：设置 → 关于 Tor 浏览器，页面会列出版本号；或在系统「设置 → 应用 → Tor Browser」底部查看。

## 五、连上了，但网页一直弹验证码

这是另一类问题：Tor 本身已经通了，卡你的是目标网站。大量网站会把 Tor 出口节点的访问当成可疑流量，于是出现验证码刷不完、反复要求人机验证、甚至直接拒绝访问。处理思路：

- 用菜单里的「新线路」换一个出口节点再刷新（[安全级别设置](安全级别设置.md)第三节），多换几次常能碰到不弹验证码的出口；
- 换出口没用还一直拦，说明这个站对 Tor 出口是整段拉黑的，换浏览器时间或换站访问；
- 验证码一直过不去时不要反复硬刷，等一段时间再试，出口节点分配会变化。

## 六、安卓版的已知限制（不是故障）

以下几条来自官方手册的已知问题清单，遇到时不用当成手机坏了去排查：

- 无法查看当前 Tor 线路的节点构成（桌面版可以）；
- 没有「新建身份」功能，只有「新线路」；
- 需要客户端授权的 onion 服务地址打不开；
- 移到 SD 卡后无法连接（见第三节）。

## 七、都不行时的检查顺序

1. 确认设备本身能上网（浏览器随便开一个普通网页）；
2. 内置三种传输逐个换：obfs4 → meek-azure → snowflake；
3. 重新索取一批新网桥填入，旧的可能已下线；
4. 核对版本号，确认不是过旧版本；
5. 把 Tor 日志复制下来，带着版本号一起到官方支持渠道（[forum.torproject.org](https://forum.torproject.org/)）提问，别人才能帮你定位。
