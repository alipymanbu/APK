## 一、先确认装的是哪一版

安卓版 Tor Browser 是 Tor Project 官方开发与维护的移动版浏览器，官方安装包的包名固定为 `org.torproject.torbrowser`。安装完成后在系统「设置 → 应用」里核对这一串，能帮你确认手机上这个应用对应的是官方包。

网盘里这份安装包的本地信息如下：

| 项目 | 值 |
| --- | --- |
| 版本 | 10.0.1688.1.3-Release |
| 包名 | `org.torproject.torbrowser` |
| 大小 | 77.96M |
| MD5 | `DE4FA766E0F65E579CAEB1AF0A3AA097` |
| 信息核对时间 | 2026-09-23 |

官方版本号更新较频繁，你之后从官网看到的版本号与上表不同属于正常现象；网盘里这一份以表内信息为准。系统要求方面，官方手册写的是 Android 5.0 及以上，支持 Aarch64、Arm、x86_64、x86 四种架构。

## 二、官方获取渠道

| 渠道 | 适合谁 | 入口 |
| --- | --- | --- |
| Google Play 商店 | 设备带 Play 服务 | [Tor Browser 商店页](https://play.google.com/store/apps/details?id=org.torproject.torbrowser) |
| F-Droid | 不用 Play 商店 | 先装 [F-Droid](https://f-droid.org/)，再添加 [Guardian Project 官方仓库](https://guardianproject.info/fdroid/) |
| Tor Project 官网 apk | 想直接拿安装包 | [官网安卓下载页](https://www.torproject.org/download/#android) |
| 官方镜像 | 官网打不开时 | [EFF 镜像](https://tor.eff.org/download/#android) 或 [Calyx Institute 镜像](https://tor.calyxinstitute.org/download/#android) |
| GetTor | 以上都不方便 | 发邮件给 `gettor@torproject.org`（正文写 android），或 Telegram 联系 `@GetTor_Bot`，会回复下载链接与签名 |

官方手册的建议是：不确定设备架构类型时，优先从应用商店装，商店会自动匹配对应架构的包。

## 三、用网盘里的 apk 安装

从 [Tor Browser 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f55ca4777221) 转存并下载 apk 到手机后，按下面步骤装：

1. 在文件管理器里点开下载好的 apk；
2. 系统首次会提示「不允许安装未知来源应用」，按提示允许本次安装；
3. 等待安装完成，桌面出现 Tor Browser 图标。

装之前想核对文件完整性的话，用文件管理器或校验工具算一遍 MD5，与第一节表格里的值比对，一致再继续。已装过旧版本时，直接覆盖安装通常就能升级；覆盖失败再卸载重装。

## 四、第一次打开怎么连

1. 点开图标，首次启动先选显示语言（默认跟随系统语言，之后可在 设置 → 语言 里改）；
2. 进入连接页后有两组选择：
   - 直接点「连接」—— 大多数网络环境下等进度条走完就能用；
   - 打开「始终自动连接」，以后每次启动跳过询问，直接按已保存的连接方式上线；
3. 连接页还内置「连接助手」：直连失败时点「尝试网桥」，它会自动套用适合你所在地区的方式再试一次；
4. 如果进度条长时间卡住或最终报错，先看[连接失败排查方法](连接失败排查方法.md)定位原因 —— 多数情况要到[网桥配置方法](网桥配置方法.md)里配一个网桥才能上线。

连上之后建议顺手核对一遍[安全级别设置](安全级别设置.md)，三档级别对网页显示的影响差别不小。
