## 一、这份权限清单从哪来

下表来自对 **QingTalk 4.94.31**（包名 `com.senmessage.cosunpdogf.intl`）安装包内 `AndroidManifest.xml` 清单的直接读取，其中 `android.permission.*` 系统权限共声明 30 项——这是「应用自己说我要这些」的原始事实；你手机设置里看到的运行时权限（会弹窗问你的那批）是它的子集。装其他版本时以那个包的清单为准。

## 二、权限分组与对应功能

| 权限组 | 清单里的条目（节选） | 对应你要用的功能 |
| --- | --- | --- |
| 网络 | `INTERNET`、`ACCESS_NETWORK_STATE`、`CHANGE_NETWORK_STATE`、`CHANGE_WIFI_STATE` | 收发消息、传文件、登录——**不给就完全离线** |
| 麦克风 | `RECORD_AUDIO`、`MODIFY_AUDIO_SETTINGS` | 发语音消息、语音/视频通话 |
| 摄像头 | `CAMERA` | 视频通话、拍照发送 |
| 拨号 | `CALL_PHONE` | 从会话直接发起语音通话 |
| 存储 | `READ_EXTERNAL_STORAGE`、`WRITE_EXTERNAL_STORAGE`、`MANAGE_EXTERNAL_STORAGE` | 从相册发图、接收并保存对方发来的文件 |
| 悬浮窗 | `SYSTEM_ALERT_WINDOW` | 通话小窗、悬浮界面类能力 |
| 唤醒与提醒 | `WAKE_LOCK`、`VIBRATE`、`FOREGROUND_SERVICE` | 通话/传输期间不熄屏、消息振动提醒、后台保活 |
| 蓝牙 | `BLUETOOTH`、`BLUETOOTH_CONNECT`、`BLUETOOTH_SCAN` 等 | 用蓝牙耳机接听通话、切音频输出 |
| 安装 | `REQUEST_INSTALL_PACKAGES`、`INSTALL_PACKAGES` | 应用内更新时拉起安装流程 |
| 其他 | `FLASHLIGHT`、`REORDER_TASKS`、`READ_PHONE_STATE` 等 | 清单里还声明了这些较少见的条目，具体触发场景以实际使用为准，不作推测 |

## 三、在哪看、在哪收回

1. **设置 → 应用 → QingTalk → 权限**——逐项查看「已允许 / 仅在使用中 / 禁止」；
2. 按上表**只收回你确定不需要的**；收回前先看下表的代价，别一刀切全关。

## 四、关掉哪个会废掉什么

| 收回的权限 | 你会立刻遇到的后果 |
| --- | --- |
| 网络（禁用联网） | 消息收发全断，等于装了个单机应用 |
| 麦克风 | 语音消息录不了、通话没声音 |
| 摄像头 | 视频通话打不开、拍照发送失败 |
| 存储 | 发不了图、收到的文件保存不下来 |
| 通知（另一层开关，非本表权限） | 消息进应用才看得到，见 [收不到新消息通知怎么设置.md](收不到新消息通知怎么设置.md) |
| 悬浮窗 | 通话小窗一类的界面出不来，主流程不受影响 |

原则：**权限按功能给，功能不用了再关**。全部拒绝的装法会让这套客户端失去它存在的意义——你要的是通话和传文件，网络、麦克风、摄像头、存储这四组是绕不开的。

装不上、被拦截的处理见 [下载与安装教程.md](下载与安装教程.md)；装完能干什么见 [主要功能与使用场景.md](主要功能与使用场景.md)。
