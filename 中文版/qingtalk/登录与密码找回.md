## 一、登录

打开 QingTalk，进入登录页，输入账号与密码后进入主界面。要点就三条：

- 登录靠已有的账号与密码：账号输错一位就登不上，先核对账号再怀疑密码。
- 密码框通常有显示/隐藏切换，第一次登不上时点开明文核对一遍大小写与键盘布局。
- 具体按钮文案与勾选项以你装的版本界面为准，版本之间略有差异。

装包、系统要求、装不上怎么处理，见 [下载与安装教程.md](下载与安装教程.md)。

## 二、忘记密码怎么办

官方帮助中心给的自助路径是「找回密码」，前提是这个账号绑过手机号或邮箱：

1. 在登录页选择**找回密码**；
2. 用账号**已绑定的手机号、邮箱或其他验证方式**完成身份验证；
3. 验证通过后按提示**设置新密码**；
4. 回到登录页用新密码登录。

两个边界要清楚：

- 找回密码**依赖账号已绑定的验证方式**。如果手机号、邮箱都收不到验证码，自助这条路就到头了 —— 官方帮助中心没有给出其他自助途径，接下来只能找你所在组织的 QingTalk 管理员，或走官方支持渠道。
- 重置成功后，其他设备上的登录状态不一定自动失效；如果你在别人的设备上登过，按第三节的建议把它退掉。

## 三、官方给的账号安全建议

帮助中心「如何保护 QingTalk 账号安全」一节，四条都是可直接执行的：

| 建议 | 具体怎么做 |
| --- | --- |
| 不外泄凭证 | 密码、短信验证码、登录凭证不告诉任何人；有人以「客服」「管理员」身份来要，一律不给 |
| 定期更新客户端 | 官网下最新版装上，旧版本的已知问题不会替你修 |
| 用强密码 | 长度优先，别用生日、手机号、连续字符；别与其它网站共用同一个密码 |
| 别长期挂陌生设备 | 在网吧、借用的电脑上登完就退出，不要保持长期登录 |

## 四、登不上的排查顺序

按这个顺序走，每一步都便宜，能省掉无谓的重装：

1. 核对账号、密码（含大小写）—— 输错是最常见的原因；
2. 走一遍 [第二节](#二忘记密码怎么办) 的找回流程，能重置就直接解决；
3. 检查网络：登录请求发不出去时界面表现和密码错误很像，切一下 Wi-Fi/移动数据再试；
4. 仍旧不行，按官网重新装最新版（见 [下载与安装教程.md](下载与安装教程.md)），排除安装包损坏这一层。

登录已经正常、只是消息发不出去的话，问题不在这一层，转到 [消息发不出去怎么排查.md](消息发不出去怎么排查.md)。
