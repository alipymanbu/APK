## 一、它是什么、适合谁

QingTalk 是一款安全即时通讯软件（官网定位），面向的是**团队与组织内部的日常沟通**：文字消息、语音视频通话、文件传送都收在一个客户端里，Windows、MacOS、iOS、Android 四端可用。你要的是「找人说话、开会、传文件」这条链路顺畅，它就是干这个的；如果你要的是社交广场、陌生人匹配这类玩法，它不是那个东西。

## 二、主要功能

以下功能在官方定位、公开渠道的产品介绍里反复出现，属于这套客户端的常规能力；你装的版本里具体入口叫什么、摆在哪，以实际界面为准。

| 功能 | 你能拿它做什么 |
| --- | --- |
| 单聊 / 群聊 | 一对一说话，或拉一个组讨论；消息实时推送，会话记录保留下来随时回查 |
| 消息类型 | 文字、语音、图片、文件都能发，不必为传个文件另开邮箱 |
| 语音通话 | 直接拨给某个联系人，比打字快的场合用 |
| 视频会议 | 多人视频，开会、异地对齐用 |
| 文件传送 | 文档、表格、PPT 这类文件在线发给对方，对方点开就能看 |
| 通讯录 | 按联系人列表找人，不用记号码 |

## 三、典型使用场景

| 场景 | 走哪条路 |
| --- | --- |
| 跟同事确认一件小事 | 单聊发文字，急了直接语音通话 |
| 组内同步进度 | 群聊里发消息，把结论留在会话记录里 |
| 开会 | 视频会议，人不到场也能对齐 |
| 交接文件 | 聊天窗口直接发文件，替代邮件附件来回 |
| 找某个部门的人 | 通讯录里按人/组织查找，再发起会话 |

发送遇到故障（转圈、发不出、对方收不到）按 [消息发不出去怎么排查.md](消息发不出去怎么排查.md) 处理；账号问题见 [登录与密码找回.md](登录与密码找回.md)。
