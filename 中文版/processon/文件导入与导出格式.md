## 一、这篇给谁看

你手上有一堆别的软件导出的文件（XMind 脑图、Visio 流程图、Excel 表），想搬进 ProcessOn 继续画；或者画完了要交出一个对方能打开的文件。这两件事分别对应「导入」和「下载导出」，这篇把两条路各自的格式列清楚，省得你一个个试。

## 二、导入：ProcessOn 支持收哪些格式

在「我的文件」用「导入文件」入口上传本地文件，ProcessOn 官方帮助中心列出的支持格式如下：

| 格式 | 来源软件 / 用途 |
| --- | --- |
| `.xmind` | XMind 思维导图 |
| `.mmap` / `.mm` / `.km` | FreeMind、MindManager 等脑图格式 |
| `.pos` | ProcessOn 自己的格式，再次编辑用 |
| `.vsd` / `.vsdx` | Visio 流程图 |
| `.txt` | 纯文本大纲 |
| `.opml` | 大纲交换格式 |
| `.csv` / `.xls` / `.xlsx` | 表格数据（Excel） |

另外，官方知识社区提到**幕布文档链接**也能导入内容（把链接贴进新建入口），手上有幕布大纲的人不用先导出再传。

注意三点：

1. **导入入口在网页端**（[www.processon.com](http://www.processon.com) 登录后「我的文件 → 导入」），不是手机客户端里——手机端为什么不提供这个入口，见 [手机端与网页端功能差异.md](手机端与网页端功能差异.md) 第二节；
2. 导入后的文件和手建文件一样**计入你的文件数**，免费版额度紧张时先看 [免费版文件数上限怎么解决.md](免费版文件数上限怎么解决.md)；
3. XMind 官方本身不提供导出成 ProcessOn 格式的通道，走上面的 `.xmind` 导入这条路就行。

## 三、导出：ProcessOn 能吐哪些格式

以流程图为例，官方使用手册列出的下载格式是：

| 格式 | 适合干什么 |
| --- | --- |
| PNG / JPG | 发群、插文档，谁都能打开 |
| 高清 PNG / 高清 PDF | 打印、正式文档，放大不糊 |
| SVG | 二次编辑、网页里当矢量图用 |
| POS | 存档后再传回 ProcessOn 继续编辑 |

- 部分格式选项带**会员标识**，需要个人版才能选，具体以你下载页当时显示为准；
- **水印两件事别混**：页面上那个水印是你自己在「页面样式」里勾选的，随时可以取消勾选去掉，且官方标注带会员标识的水印能力为会员特享；另有用户反馈**免费版导出的图片会自动带上 ProcessOn 半透明水印**——这是单一来源的说法，以你实际导出的结果为准，去掉它的正当途径是开通个人版；
- 思维导图同样有「下载」入口，另支持把当前主题单独导出为图片；
- 除了导出当前文件，**历史版本也能单独下载**：在「历史记录」里选中某个版本直接下载（找回旧内容的完整动作见 [登录与常见问题排查.md](登录与常见问题排查.md) 第四节）；
- 导出操作位置：编辑器右上角按钮，或上方「文件」菜单里的「下载」。

## 四、POS 是什么、什么时候用它

POS 是 ProcessOn 的开放格式（`.pos`），你可以把它理解成这个平台的「源文件」：

- **要长期存档**：导一份 POS 存本地，比只存 PNG 放心——PNG 只是画面，POS 保留可编辑结构；
- **要腾免费文件位**：旧文件导出 POS 到本地后删掉，既不丢内容又释放了文件数；
- **要在账号间搬**：导出 POS 再用导入功能传进另一个账号，结构原样带过去。

一句话：交给别人看用 PNG/PDF，留给自己以后改用 POS。

## 五、和其它脑图软件互转

- **XMind → ProcessOn**：直接在「导入文件」里传 `.xmind`；
- **ProcessOn → XMind**：导出 XMind 类格式属于带会员标识的能力，没有会员时的替代做法是先导出 POS 或 PDF 再另行转换；
- 往手机上看：任何导出的 PNG/PDF 手机都能开，但要**继续编辑**就得在手机上登录 ProcessOn 客户端，云端文件会同步过去——安装方式见 [下载与安装教程.md](下载与安装教程.md)。
