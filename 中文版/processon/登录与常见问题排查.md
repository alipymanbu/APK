## 一、先选对登录方式

登录页提供四种入口，按你注册时用的方式选：

| 入口 | 适合谁 |
| --- | --- |
| 手机验证登录 | 注册时绑了手机号 |
| 验证码登录 | 忘记密码、或不想输密码 |
| 账号登录 | 邮箱 + 密码的老账号 |
| 微信扫码登录 | 用微信注册过的 |

ProcessOn 支持手机号、微信号、QQ 号等方式注册账号。**同一个账号 = 同一批文件**：手机客户端、电脑客户端、网页端登录一致才能看到彼此的文件，画到一半不见了先怀疑登录错了账号。

## 二、登录不上：三个最常见的坑

**1. 登录提示「未注册」**

ProcessOn 的邮箱账号**区分大小写**，输入的邮箱必须和注册时完全一致（`Abc@xx.com` 与 `abc@xx.com` 是两个账号）。用验证码登录可以绕开大小写问题直接进。

**2. 收不到短信验证码**

官方帮助中心有「接收不到短信验证码怎么办？」一整条解答，在 [www.processon.com/support](https://www.processon.com/support) 搜标题看官方给的步骤；改绑手机或邮箱的入口在：头像 → 账户中心 → 账户安全。

**3. 忘记密码**

用上面的「验证码登录」进去即可，不需要先找回密码。

## 三、文件找不到了：按这个顺序查

官方给出的找回顺序，照做一遍基本能定位：

1. **所有文件都看不见** → 多半登错了账号，回第一步核对邮箱大小写后重新登录；
2. **部分文件看不见** → 依次查：回收站（含彻底删除过没有）、各个文件夹、小组及其回收站；
3. **是别人邀请你改的文件** → 去「与我协作」里找，它不在你自己的「我的文件」列表；
4. 以上都排除了 → 找官方客服：在「我的文件」页面点右下角问号图标 → 选在线客服 → 输入「转人工」。

排除法的关键是分清三种归属：**自己建的、协作来的、小组里的**，它们分别在三个地方（协作文件的入口细节见 [协作与权限设置.md](协作与权限设置.md)）。

关于回收站，官方手册有三条规则直接影响你能不能找回：

- 删除的文件先进回收站，**回收站里的文件无法直接查看内容**，要看只能先恢复；
- **误删 → 选「恢复」**，文件回到我的文件；**选了「彻底删除」就再也找不回来**；
- 回收站**不会定期自动清理**，里面的文件可以一直躺着（但一直占文件数，见 [免费版文件数上限怎么解决.md](免费版文件数上限怎么解决.md)）。

## 四、内容疑似没保存 / 断网

官方使用手册给的事实与动作：

- **数据实时保存**；编辑过程中系统**每隔几分钟自动保存**一次，正常不需要你手动点保存；
- **断线有兜底**：临时断线时内容进离线缓存，**网络恢复后自动同步**到服务器；想保险，断网前可先把文件导出 POS 格式（格式说明见 [文件导入与导出格式.md](文件导入与导出格式.md)）；
- **内容缺了一段 → 用历史版本找回**：编辑器里打开「历史记录」（网页端在画布右上角入口附近），列表里可以**恢复某一个历史版本**（选中版本 → 恢复此版本），也可以不恢复、直接**下载**那一个版本；手机端在顶部菜单里有「历史版本」，支持查看并恢复思维导图的历史版本；
- 历史版本本身也可以删除——动手前先确认要删的是不要的那版。

## 五、卡顿、打不开

通用处理顺序，从便宜到贵：

1. 关掉多余的文件标签页，只留正在画的那张；
2. 手机客户端重启应用；网页端刷新页面；
3. 客户端在设置里清理缓存后再试；
4. 换网络（蜂窝 ↔ Wi-Fi）试一次，绘图类页面对网络质量敏感；
5. **App 和网页端看到的内容对不上**：按官方四步排查（同账号 → 最新版本 → 下拉刷新 → 网页端把文件挪到根目录重登），详见 [手机端与网页端功能差异.md](手机端与网页端功能差异.md) 第四节；
6. 都不行时确认应用是否为旧版本，可回到 [下载与安装教程.md](下载与安装教程.md) 对照官方渠道更新。
