## 一、先选对登录方式

登录页提供四种入口，按你注册时用的方式选：

| 入口 | 适合谁 |
| --- | --- |
| 手机验证登录 | 注册时绑了手机号 |
| 验证码登录 | 忘记密码、或不想输密码 |
| 账号登录 | 邮箱 + 密码的老账号 |
| 微信扫码登录 | 用微信注册过的 |

ProcessOn 支持手机号、微信号、QQ 号等方式注册账号。**同一个账号 = 同一批文件**：手机客户端、电脑客户端、网页端登录一致才能看到彼此的文件，画到一半不见了先怀疑登录错了账号。

## 二、登录不上：三个最常见的坑

**1. 登录提示「未注册」**

ProcessOn 的邮箱账号**区分大小写**，输入的邮箱必须和注册时完全一致（`Abc@xx.com` 与 `abc@xx.com` 是两个账号）。用验证码登录可以绕开大小写问题直接进。

**2. 收不到短信验证码**

官方帮助中心有「接收不到短信验证码怎么办？」一整条解答，在 [www.processon.com/support](https://www.processon.com/support) 搜标题看官方给的步骤；改绑手机或邮箱的入口在：头像 → 账户中心 → 账户安全。

**3. 忘记密码**

用上面的「验证码登录」进去即可，不需要先找回密码。

## 三、文件找不到了：按这个顺序查

官方给出的找回顺序，照做一遍基本能定位：

1. **所有文件都看不见** → 多半登错了账号，回第一步核对邮箱大小写后重新登录；
2. **部分文件看不见** → 依次查：回收站（含彻底删除过没有）、各个文件夹、小组及其回收站；
3. **是别人邀请你改的文件** → 去「与我协作」里找，它不在你自己的「我的文件」列表；
4. 以上都排除了 → 找官方客服：在「我的文件」页面点右下角问号图标 → 选在线客服 → 输入「转人工」。

排除法的关键是分清三种归属：**自己建的、协作来的、小组里的**，它们分别在三个地方。

## 四、内容疑似没保存 / 断网

- ProcessOn 的编辑是**实时同步到云端**的，并带历史版本记录；正常情况下你不需要手动点保存；
- 发现内容缺了一段，先别继续猛敲：在编辑器里找「历史记录」（网页端在「文件」菜单附近）回看历史版本，把缺的部分恢复回来；
- 断网时的编辑行为以官方 FAQ「网络断了没有保存内容怎么办？」给出的说明为准，同样在帮助中心搜标题。

## 五、卡顿、打不开

通用处理顺序，从便宜到贵：

1. 关掉多余的文件标签页，只留正在画的那张；
2. 手机客户端重启应用；网页端刷新页面；
3. 客户端在设置里清理缓存后再试；
4. 换网络（蜂窝 ↔ Wi-Fi）试一次，绘图类页面对网络质量敏感；
5. 都不行时确认应用是否为旧版本，可回到 [下载与安装教程.md](下载与安装教程.md) 对照官方渠道更新。
