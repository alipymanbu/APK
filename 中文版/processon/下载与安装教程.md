## 一、这份安装包是什么

下面这些数字是这份安装包本身的事实，网上搜到的官方最新版未必是同一版，装包、核对、报版本时以这张表为准：

| 项目 | 值 |
| --- | --- |
| 应用名称 | ProcessOn |
| 版本 | 3.1.1 |
| 包名 | `com.processon` |
| 安装包大小 | 86.36M |
| MD5 | `92169EB092406F8FA6C7933EDC5EA70B` |
| 系统要求 | 安卓 5.2 以上 |
| 开发者 | 北京大麦地信息技术有限公司 |

ProcessOn 本身是一个在线绘图平台，画布和文件都存在云端，手机客户端、电脑客户端、网页端登录同一账号看到的是同一批文件。所以装客户端只是给手机加一个入口，不是把数据锁在手机里。

## 二、从网盘拿到安装包

1. 打开上面的 **ProcessOn 安装文件资源（夸克网盘）** 链接：[https://pan.quark.cn/s/e0aa4ecb2a16](https://pan.quark.cn/s/e0aa4ecb2a16)，转存到你自己的网盘；
2. 在手机上用夸克打开转存后的文件夹，里面是 `processon_v3.1.1.apk` 与一个说明 txt，直接点 APK 下载到手机；
3. 下载完先别急着装，想核对文件是否完整时，在电脑上对下载的 APK 执行：

```powershell
certutil -hashfile processon_v3.1.1.apk MD5
```

输出与表格里的 MD5 一致就说明包是完整的、和这里描述的是同一份。

## 三、手机上安装

安卓默认会拦下「应用商店之外」的安装包，首次装要手动放行：

1. 点开 APK 后系统弹出「禁止安装来自此来源的应用」之类的提示，点进设置，给当前来源（文件管理器或夸克）打开「允许安装未知应用」；
2. 返回继续安装，等进度走完点「打开」；
3. 系统版本低于安卓 5.2 时安装会被系统直接拦下，这种情况换台手机或用后面的官方渠道装。

系统要求另有第二处口径：腾讯会议侧的 ProcessOn 使用手册标注「安卓客户端需 Android 9.0 以上」。两处口径并列、不替你选边——先按 5.2 试装，进不去或运行异常再对照 9.0 换设备，完整对照见 [手机端与网页端功能差异.md](手机端与网页端功能差异.md) 第五节。

装完后包名是 `com.processon`，应用列表里的名字是 ProcessOn，和网页版是同一个账号体系。

## 四、官方渠道的其他下载方式

除了网盘里这份包，你还有两条官方获取路径：

- 各手机应用商店直接搜 **ProcessOn** 安装（官方帮助中心的答复就是「应用商店搜索 ProcessOn 进行下载」）；
- 官网 [下载中心](https://www.processon.com/download) 提供 Android 客户端下载入口，也一并提供 iOS、Windows、Mac 与微信小程序版本。

应用商店与官网拿到的版本号通常比 3.1.1 新。你只是想装上就用，选哪条都行；要复现网盘里那一版的界面与行为，就用第二节那份包。

## 五、首次打开要做的事

1. 首次启动会到登录页，支持手机验证登录、账号登录、验证码登录、微信扫码登录，注册支持手机号、微信号、QQ 号等方式；
2. 登录成功后你在这个账号下（含网页端画的）文件会同步出现在手机上；
3. 登录遇到「提示未注册」「收不到验证码」这类问题，排查步骤在 [登录与常见问题排查.md](登录与常见问题排查.md)。

登录之后就可以直接开画了：思维导图看 [思维导图制作教程.md](思维导图制作教程.md)，流程图看 [流程图制作教程.md](流程图制作教程.md)。
