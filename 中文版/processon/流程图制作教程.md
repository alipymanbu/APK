## 一、新建与认识画布

登录后新建「流程图」进入编辑器，你会碰到三个区域：

- **左侧图形区**：标准图形库。默认带常用图形，缺的类别在「更多图形」里勾选（比如跨职能泳道、网络设备、电路元件）；
- **中间画布**：画图的地方，支持缩放与画布自动延伸；
- **右侧样式面板**：选中图形/连线后在这里改颜色、字体、线型。

官方使用手册列的可画范围：流程图类（Flowchart、BPMN、EVC、EPC、维恩图）、UML 图（实例图、部署图、类图等）、UI 设计图（WEB、iOS、Android 三端）。画之前先确认你要的类型在不在这个清单里。

不想从零画时，从 [模板库](https://www.processon.com/template) 克隆一张同类型的改，比对着空白画布强。

## 二、把图形摆上去

1. 从左侧图形区拖图形到画布；
2. 双击图形输入文字（流程名、判断条件）；
3. 选中图形拖边框可以调大小，拖图形本体挪位置；
4. 判断分支用菱形，起止用圆角矩形——这是读流程图的人的默认预期，别反着用。

## 三、连线：流程的灵魂

- 选中图形后点它边框外的「+」，再点目标图形，一条连接线就建好了；
- 连线默认走直角，拖连线中间的控制点可以改走向，避免线穿过别的图形；
- 判断菱形出去的每条线要标注条件（如「是 / 否」），不标的流程图别人读不懂；
- 画错的线选中后删除重连即可，线是附着在图形上的，挪图形线会跟着走；
- **连完线箭头方向会自动弹出提示图形**（官方叫 Autoprompt），点一下就把下一个形状接上，顺着往下画比每次去左侧拖快；
- 挪图形靠近另一个图形的中心线时，会自动出现对齐标识线并轻微吸附——靠它把一列图形排齐，不用手动微调。

## 四、样式与排版

| 你想要的效果 | 怎么做 |
| --- | --- |
| 统一改一批图形的颜色 | 格式刷，或框选后批量设置 |
| 整张图换个配色 | 「图形风格配色」/ 一键美化，自动排版 + 换色 |
| 图形对不齐 | 框选后用对齐分布 |
| 局部复用 | 框选 → 复用，拷到别处继续用 |
| 加页面水印 | 网页端按 `Shift+I` 调出样式 → 页面样式 → 勾选显示水印 |

插入类操作在菜单里：图片、链接、方程式、备注、评论都可以往图形上挂。需要按部门分工的流程，用「创建泳道图」把横向泳道拉出来，每个泳道一个责任方。

## 五、导出与分享

- 右上角或「文件」菜单里的「下载」提供导出：流程图支持 **PNG、高清 PNG、JPG、SVG、高清 PDF、POS** 格式，其中带会员标识的选项需要个人版才能用，各格式的用途对照见 [文件导入与导出格式.md](文件导入与导出格式.md)；
- SVG / 高清 PDF 适合插进文档或打印，普通 PNG 适合发群里直接看；
- 给别人看或一起改：右上角「分享协作」开启公开分享复制链接；要给对方限定「只能看」或「能改」，用邀请协作并选权限，操作见 [协作与权限设置.md](协作与权限设置.md)；
- **手机上开到流程图时按查看处理**——据腾讯会议侧的使用手册，移动端对流程图仅支持查看、不支持编辑，改图请回 [www.processon.com](http://www.processon.com) 或桌面客户端，两端差异汇总在 [手机端与网页端功能差异.md](手机端与网页端功能差异.md)。

画完一版想换题材练手，可以把这张图导出 POS 存档后删掉，腾出免费版的文件位，办法见 [免费版文件数上限怎么解决.md](免费版文件数上限怎么解决.md)。
