## 一、邀请协作：三个入口

官方使用手册给出的邀请方式，任选一个顺手的：

1. **文件列表里**：鼠标移到文件上点右键（或三点图标）→ 分享协作；
2. **编辑器里**：流程图编辑页左下角「邀请协作者」按钮，思维导图编辑页左侧的邀请协作按钮；
3. **输入对象**：直接敲对方的邮箱或手机号，回车确认账号，可以连续加多个；也可以用**链接或二维码**批量邀请，链接的时效可以自己改。

给对方发的是「协作邀请」，不是把文件转给他——文件还在你账号里，对方按权限进来干活。

## 二、两种权限：编辑者还是查看者

| 权限 | 对方能做什么 | 什么时候给 |
| --- | --- | --- |
| 编辑者 | 直接编辑文件内容 | 要一起画、一起改 |
| 查看者 | 只能浏览查看 | 只需要给人过目、评审 |

拿不准时先给查看者，需要再升级——反过来（先给编辑再收回）往往已经被人改过了。

## 三、协作来的文件在哪看

别人邀请你的文件**不在你自己的「我的文件」里**，在文件管理页的「**与我协作**」列表。你的文件突然「找不到」时，第三步排查就是来这里看，完整顺序见 [登录与常见问题排查.md](登录与常见问题排查.md)。

## 四、团队空间与小组：两套分层权限

同一个「协作」概念，在团队空间和小组里展开成了不同的角色表（均来自官方 FAQ）：

**团队空间（4 级，按权限大小排列）**

| 角色 | 能做什么 |
| --- | --- |
| 拥有者 | 创建者；赋权、增删成员、删除/交接空间、文件增删改查 |
| 可管理 | 仅次于拥有者；可赋权、增删成员、文件增删改查 |
| 可编辑 | 普通成员；不能动成员，只有文件的新建、修改、删除、查看 |
| 可查看 | 只能查看文件 |

**小组（5 种角色）**

| 角色 | 能做什么 |
| --- | --- |
| 创建者 | 设置每人身份权限、对文件做所有操作、移除成员 |
| 管理员 | 赋权限、移除成员、创建/编辑/删除小组文件与文档 |
| 编辑者 | 创建、编辑小组文件与文档 |
| 作者 | 创建、编辑**自己的**文件，可查看其他成员的文件 |
| 订阅者 | 仅查看小组内容 |

判断你在哪个体系里：文件挂在团队空间下看团队那张表，挂在小组下看小组那张表——两套角色名有重叠（都有「编辑者」），但权限范围不一样，别混着理解。

## 五、免费版的协作边界

按第三方整理的版本对照（以 [官网](https://www.processon.com/) 会员页当时显示为准），免费版协作人数上限是 **3 人**，个人版不限。所以：

- 三个人以内的小协作，免费版直接开；
- 要拉第四个人进来，要么升级个人版，要么改用「公开分享」链接让不需要改的人只看（分享的开法见 [思维导图制作教程.md](思维导图制作教程.md) 第五节）；
- 团队多人协作看团队版，权限分层就是上面第四节那张表。
