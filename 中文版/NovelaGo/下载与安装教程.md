## 一、这是个什么应用

NovelaGo 是一款面向海外市场的英文、西文网文阅读应用，内容以欧美流行的言情、狼人、黑手党、霸总、奇幻等连载题材为主，章节每日更新。你装的是安卓版 APK，安装包参数如下（以本地保存的那一份为准，网上各处标注的最新版可能不是同一个版本）：

| 项目 | 数值 |
| --- | --- |
| 版本 | 2.0.4 |
| 包名 | `com.novelago.android.app` |
| 安装包大小 | 62.41M |
| MD5 | `D8857F19F346FA7AE7A46472296D700C` |
| 记录时间 | 2026-09-23 |

装之前可以核对一下 MD5：文件名对得上但大小差得离谱（比如只有几 MB），说明下载中途断了，重新下一次即可。

## 二、系统要求

本地记录标注**需安卓 5.2 以上**；另有渠道页标注 Android 7.0 或更高。两个数字并列在这里，装不上的时候以你的设备实际反应为准 —— 系统版本太旧时安装器会直接提示，不会装到一半失败。手机存储空间至少留出 200MB（安装包 62.41M 解压后更大，再加上后续的书架缓存）。

## 三、安装步骤

1. 打开 [NovelaGo 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ed57d54a226b)，把 APK 转存/下载到手机；
2. 点开 APK 文件，系统会弹「不允许安装来自此来源的应用」——这是正常的，安卓对非应用商店来源的默认拦截；
3. 按提示进入设置，打开「允许安装此来源」（不同品牌手机叫法略有差别，小米叫「安装未知应用」、华为叫「外部来源应用下载」）；
4. 返回继续安装，等进度条走完；
5. 装完先别急着打开，把安装器页面关掉，回到桌面找图标启动。

如果安装时提示「解析包出错误」或「应用未安装」，多半是 APK 没下完整，回第一步重新下载；提示「与已有版本冲突」则是手机里装过另一个渠道的同包名版本，先卸载旧的再装。

## 四、第一次打开

首次启动会请求网络权限与存储权限（用来缓存章节与封面），建议都允许 —— 拒绝网络权限会导致书库加载不出来。应用的默认界面语言跟随系统，如果你的系统是中文环境，有些版本会直接显示中文；没有的话按 [怎么设置中文与字体背景.md](怎么设置中文与字体背景.md) 里的步骤手动切一次。

进主界面后，你看到的是按题材分区的书库与每日推荐，任意点开一本书的前几章可以免费试读（每本书的免费章节数不完全一样）。想先弄清楚章节怎么解锁、金币从哪来，接着看 [金币怎么获取与章节解锁.md](金币怎么获取与章节解锁.md)。

## 五、以后怎么升级到新版本

应用官方更新较密（版本历史显示基本保持每 1~2 周修一次，以官方页面当时为准），拿到新版本后这样升级：

1. 从网盘下载新版 APK（版本号以文件名与本篇表格的对比为准，比 2.0.4 新就可装）；
2. 直接点开安装 —— **同包名、同签名，覆盖安装即可，不用先卸载**，书架与本地设置都会保留；
3. 只有在覆盖安装被提示「签名不一致」时才先卸载再装，卸载前确认书架是账号云同步的（见 [搜索小说与书架使用.md](搜索小说与书架使用.md) 第三节）；
4. 装完后在应用的设置页里找「关于 / 版本」入口核对版本号（各版本路径略有差异，以界面实际显示为准）。

覆盖安装失败、或升级后开始闪退，按 [闪退打不开或加载慢怎么办.md](闪退打不开或加载慢怎么办.md) 的顺序排查。
