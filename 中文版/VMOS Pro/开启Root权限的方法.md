## 一、这里的 Root 指什么

VMOS Pro 的 Root 是**虚拟机内部的 Root**：你开的是虚拟系统里的超级用户权限，真机的 Bootloader 不解锁、系统不动、保修不受影响。Root 的作用范围也只在虚拟机里 —— 虚拟机内的应用拿得到 root，真机上的应用一切照旧。

这条边界是它和传统一键 Root 工具的本质区别：你拿它练手、测试需要 root 的工具、在隔离环境里折腾，搞坏了删掉虚拟机重开即可。

## 二、开启步骤

1. 按 [下载与安装教程.md](下载与安装教程.md) 建好一台虚拟机并进入。
2. 打开虚拟机内的「设置」（VMOS 的虚拟机设置项，不是安卓原生设置），找到「**超级用户**」开关，打开。
3. 回到虚拟机桌面，启动一个需要 Root 的应用 —— 首次调用时会弹超级用户授权窗，勾选允许即可。授权记录可以在超级用户管理界面里查看、撤销。
4. 验证是否生效：装一个 Root 检查类应用，或在终端里执行 `su`，能拿到 `#` 提示即为成功。

部分镜像（如内置 Root 环境的 ROM）开箱即带超级用户，装进去就能授权，无需手动开开关 —— 以你所选镜像的实际情况为准。

## 三、Root 能用来做什么

官方资料里列出的典型用途：

- 卸载或冻结虚拟机里预装的应用；
- 用需要 root 的系统工具改配置、调音效（如蝰蛇音效类工具）；
- 在虚拟机内挂载 Xposed 框架与模块；
- 测试 APK 的高危行为 —— 中招也只污染虚拟机，删掉重建即可。

注意所有这些操作都发生在虚拟机内。想动真机的系统分区，这套办法做不到，也不该那样用。

## 四、授权不生效怎么办

开了开关但应用还是拿不到 root，按出现频率排查：

1. **重启虚拟机**。第三方开发者的经验是 superuser 守护进程没在运行时授权必失败，虚拟机关机再开机基本能解决 —— 这也是最常见的一招。
2. **确认开关在正确的虚拟机上**。如果你建了多台虚拟机，Root 开关是按台生效的，进错台就看不到授权。
3. **免费镜像可能限制 Root**。有第三方资料指出，部分版本的免费虚拟机不开放 Root 权益、表现为超级用户应用闪退或重启后丢授权。遇到这种表现，对照下一节的收费口径确认自己的账号状态。
4. **重装授权应用**。超级用户管理应用本身损坏时，表现为一授权就闪退，重装可恢复。

## 五、收费口径（两边说法并列）

这一条官方与第三方口径不一致，如实列出：

- **官方 FAQ** 对「VMOS 收费吗」的回答是「承诺对用户永久免费」，指的是基础虚拟机功能。
- **第三方资料** 则称 Root、Xposed 属于 VMOS Pro 的会员付费功能，需开通会员（有月/季/年档位）后使用，具体价格以官方购买页当时显示为准。

也就是说：基础的创建虚拟机、多开、挂机是免费的，Root 相关权益是否要付费，取决于你用的版本与账号状态 —— 以你应用内实际看到的提示为准，本篇不给结论。

## 六、两个进阶限制

- **不支持 Magisk**。有第三方开发者明确说明：VMOS 没有 `boot.img` 与 recovery 模式，Magisk 无法在其中初始化，Root 走的是 Superuser 方案。你要装的是 Magisk 模块，这条路走不通。
- **Xposed 视镜像而定**。部分镜像自带 Xposed 环境，装好模块即用；没有的镜像需要自行在虚拟机内安装框架 —— 框架版本需与镜像的安卓版本对应，装错版本会起不来。

Root 相关的启动失败、闪退问题，先回 [卡99%进不去与常见问题.md](卡99%进不去与常见问题.md) 排除基础故障，再定位权限本身。
