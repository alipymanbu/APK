## 一、先让悬浮球出现

悬浮球是 VMOS Pro 的总操控入口，但它依赖真机的「悬浮窗权限」—— 权限没给，悬浮球根本不显示。装完应用第一件事就该去真机设置里把 VMOS Pro 的悬浮窗权限打开（常见路径：设置 → 应用管理 → VMOS Pro → 权限，具体以机型而定）。

悬浮球有**两种颜色，代表你当前在哪一侧**：

| 颜色 | 你在哪 | 菜单偏向 |
| --- | --- | --- |
| 绿色 | 真机环境 | 控制虚拟机整体（开关悬浮窗、全屏、关机） |
| 蓝色 | 虚拟机环境 | 虚拟机内的系统键与工具（返回、主页、截图） |

分不清自己在哪一侧时，看颜色就够了 —— 这也是官方设计双色的本意。

## 二、悬浮球菜单：按环境分

菜单**上半部分是功能开关**，两侧环境能用的项不同。

**真机环境（绿色）点开：**

- **悬浮窗** —— 把虚拟机切成小窗模式，实现真机与虚拟机同屏同时操作；
- **声音** —— 响铃 / 静音一键切换；
- **全屏** —— 全屏进入虚拟机；
- **关机** —— 彻底关闭 VMOS 并杀掉进程（比从真机后台划掉更干净）。

**虚拟机环境（蓝色）点开：**

- **关机 / 返回真机** —— 关闭，或把虚拟机转入后台继续跑；
- **多任务 / 返回 / 主屏幕 / 通知栏** —— 等同三个虚拟导航键加通知栏；
- **重置分辨率** —— 恢复为真机分辨率，需重启生效；
- **截图** —— 把当前虚拟机画面存为图片。

菜单**下半部分是快捷应用**，两个环境一致，点一下直接在 VMOS 里打开对应应用。长按图标或点「+」进入编辑模式，可以增删项目、拖动排序 —— 把常用的钉在前面，少翻一页。

## 三、悬浮窗：手势对照表

从真机环境的悬浮球菜单打开「悬浮窗」后，虚拟机变成一个可拖动的小窗口。所有手势都由**左上角图钉的颜色**决定：

| 图钉颜色 | 状态 | 可以做什么 |
| --- | --- | --- |
| 白色 | 未激活操作 | 双指缩放窗口；单指拖动窗口移动；点右下角旋转按钮转横向；点左下角静音按钮切换响铃/静音 |
| 绿色 | 正在操作虚拟机 | 直接点按、滑动虚拟机内部；此时**不能**缩放 |

几个细节：

- **图钉绿色时想挪窗口**：抓上方「VMOS」黑色头栏拖动，别抓窗口内容区；
- **想转横屏看**：先保证图钉是白色，再点右下角旋转按钮；
- **关小窗**：点右上角最小化按钮，窗口收起，虚拟机继续在后台跑。

## 四、典型用法：边聊边挂

悬浮窗最实用的场景是**双线并行**：真机上正常用微信回消息，VMOS 小窗里让游戏或任务自己跑，互不打断。要长时间这样用，注意三点：

1. 真机必须给足后台（电池优化白名单），否则小窗一收虚拟机就被杀了 —— 见 [卡99%进不去与常见问题.md](卡99%进不去与常见问题.md) 后台被杀一节；
2. 内存吃紧的手机上，两侧同时跑大型应用会互相挤，关掉不用的真机应用；
3. 想更省电更流畅，可以在虚拟机设置里调低分辨率（路径见下节）。

## 五、配套：分辨率怎么调

虚拟机画面卡顿时，降分辨率是最直接的一招。路径：虚拟机内「设置 → 分辨率 → 添加分辨率」，输入分辨率参数与 DPI，保存使用后**重启虚拟机生效**。分辨率越低越流畅，代价是画面发糊 —— 挂机场景调低没影响，要看画面的场景酌情。

调乱了想还原：悬浮球菜单里点「重置分辨率」，恢复为真机原生分辨率，同样需要重启。

## 六、系统设置里的其他运行开关

虚拟机的系统设置里还有一组与日常使用直接相关的开关（选项名随版本变化，以界面当时显示为准）：

| 开关 | 作用 |
| --- | --- |
| 后台锁定 / 运行保护 | 降低虚拟机被真机系统清理的概率，挂机前建议打开 |
| 画中画 | 让虚拟机以小窗形式浮在真机应用之上，与悬浮窗模式互补 |
| 剪切板同步 | 真机复制、虚拟机粘贴（或反向），来回倒文字不用再发文件 |
| SD 卡共享 | 把真机存储挂给虚拟机用，缓解虚拟机存储不足 |
| 相机访问 | 虚拟机内应用调用真机摄像头的总开关，不用就关 |
| 全屏启动 | 进虚拟机直接全屏，跳过窗口态 |

这组开关按需开：挂机保后台的打开「后台锁定」，倒文件的开「剪切板同步」与「SD 卡共享」，其余默认即可。虚拟机提示存储不足时，「SD 卡共享」配合清理虚拟机内不用的应用（见 [卡99%进不去与常见问题.md](卡99%进不去与常见问题.md) 第六节）一起处理。
