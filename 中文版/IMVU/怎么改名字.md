## 一、先分清：头像名和显示名是两回事

注册时填的那个昵称是**头像名（Avatar Name）**，它是你在聊天室里被搜索、被加好友用的唯一身份；**显示名（Display Name）**是挂在头像上方的显示用名字，可以随时随便改。很多「改名字」的需求其实只需要改显示名：

1. 点主页右上角你的头像图标；
2. 在头像名旁边的编辑按钮里填新的显示名；
3. 保存即可，免费、无次数限制。

显示名改了，别人搜的还是你的头像名。要让搜索和好友关系跟着变，就得动头像名——那是下一节的事。

## 二、改头像名需要「改名令牌」

头像名不是免费改的：你需要一枚**改名令牌（Name Change Token）**，规则都写在官方说明里：

- 令牌用**真金白银**买（信用卡、PayPal 等），积分买不了；
- 每枚**一次性使用**，买了可以囤着以后用；
- 改名**不可撤销**——新名字立即使旧名字作废，反悔只能再买一枚改回去；
- 连**只改大小写**也要消耗一枚令牌。

购买路径：商店（网页端或手机应用内）。改名的操作在网页端完成：进入官方的改名页面，页面会显示你现有几枚令牌，输入新名字两遍、验证账号密码，点 Change Avatar Name 提交。

## 三、新名字要过这几条规则

| 规则 | 具体要求 |
| --- | --- |
| 长度 | 至少 6 个字符 |
| 构成 | 不能全数字（必须含字母）、不能含特殊字符 |
| 占用 | 不能与现有活跃账号重名 |
| 内容 | 必须符合全年龄内容规范——用违规名字会被**永久停号** |

想用的名字提示不可用、但看起来又符合规则时，官方不给解释具体原因（涉及隐私），只能换一个。

## 四、5 个字符以内的短名字是「Premium Name」

5 个字符以内的短名字（含 4、5 字符）单独走「Premium Name」渠道，不用改名令牌，买了立即生效，按名字长度定价：

| 名字长度 | 价格 |
| --- | --- |
| 2 字符 | 500,000 Credits |
| 3 字符 | 300,000 Credits |
| 其余可选短名 | 150,000 Credits |

注意：这里必须用**充值的 Credits**，推广积分（注册送、转盘转的那种）不算数——价目和积分口径的细节见 [Credits与VCOIN的区别.md](Credits与VCOIN的区别.md)。Premium Name 同样不能全数字、不能带特殊字符。

## 五、改名前的三个检查

1. **确认密码能登录**：改名操作要验证账号密码，密码忘了先走找回（步骤在 [常见问题与账号安全.md](常见问题与账号安全.md) 第二节）。
2. **结清积分任务**：改名前留意有没有没领完的「赚积分」任务，改了名字第三方可能没法给你打款。
3. **想好再改**：名字一旦改了，好友、链接、别人对你的印象都指向新名字，改错只能再花一枚令牌。

## 六、长期不上线，名字可能被收回

官方规则：账号连续 **12 个月**不登录，你的头像名有权被回收给申请它的其他用户。想保住名字（尤其是个性名），定期登录一次即可——顺便把每日转盘转了。

## 七、Facebook 注册的账号改名卡住了怎么办

有用户反映 Facebook 关联的账号在改名流程里卡壳。官方支持社区给出的解法是把登录方式转回常规账号：先到 Facebook 设置的「应用与网站」里移除 IMVU 的授权，再用 IMVU 登录页的忘记密码入口给账号设一个密码，之后就能用「用户名 + 密码」登录并走改名流程。这是社区答复整理的操作路径，做不成的话直接给官方提工单（有 VIP 也可以走在线客服）。

改名说到底是一次账号身份变更，相关的新手注册背景和登录方式差异见 [注册与登录步骤.md](注册与登录步骤.md)。
