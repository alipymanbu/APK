## 一、装之前先确认这四件事

| 检查项 | 要求 | 不满足会怎样 |
| --- | --- | --- |
| 系统版本 | 安卓 5.2 以上 | 打不开或闪退 |
| 剩余空间 | 至少留出安装包体积的两倍（约 250 MB） | 安装中途失败 |
| 网络 | 能正常联网 | 能装上但进不去、加载不出房间 |
| 安装渠道 | 用同一来源的完整安装包，不要装来源不明的精简版 | 反复报解析错误 |

IMVU 是一款以 3D 化身为核心的社交应用：你创建一个虚拟形象，进各种主题聊天室和人交流、换装、拍照。手机版覆盖安卓和 iOS，这篇只讲安卓包的安装。

## 二、获取安装包并安装

1. 从上面的 **IMVU 安装文件资源（夸克网盘）** 把安装包转存到自己的网盘，再下载到手机本地。
2. 下载完成后，在通知栏或文件管理器里点开这个 `.apk` 文件。
3. 系统第一次会提示「不允许安装未知来源应用」，点设置进入后允许「此来源安装应用」（不同品牌叫法略有差异：小米叫「安装未知应用」，华为叫「允许安装外部来源应用」）。
4. 回到安装界面点「安装」，等进度条走完。
5. 点「打开」进入应用，或稍后从桌面图标进入。

## 三、这份安装包的版本信息

网盘里的包是信息核对当天的那一版，和官网最新版可能不是同一个版本号。装之前可以用下面的信息核对：

| 项目 | 值 |
| --- | --- |
| 版本号 | 11.15.0.111500001 |
| 包名 | gg.com.imvu.mobilecordova |
| 安装包大小 | 121.39M |
| MD5 | E174CE60CE201E7B1F28BA6E762D444D |
| 信息核对时间 | 2026-09-23 |

核对 MD5 的办法：安卓文件管理器多数自带「计算 MD5」（如 MT 管理器、ES 文件浏览器），算出来和表中一致就说明包没下坏。

## 四、首次打开会发生什么

1. 出现登录界面。还没有账号的话，直接跟着引导选形象、填资料就能注册，注册完会送 150 个推广积分，具体每一步见 [注册与登录步骤.md](注册与登录步骤.md)。
2. 第一次进 3D 聊天室时资源加载会慢一些，等进度走完即可；配置较低的手机这一步会更久。
3. 应用会请求存储权限，用于保存你拍的照片。不给也能玩，但拍化身照片、往 Feed 发图会受影响。

## 五、安装失败对照表

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 包下载不完整或中途被改过 | 删掉重下，装完核对 MD5 |
| 进度条走到一半失败 | 剩余空间不足 | 清出至少 250 MB 再装 |
| 安装成功但一点开就闪退 | 系统版本低于要求，或 ROM 裁剪过组件 | 换系统 5.2 以上的设备试 |
| 一直停在启动画面 | 网络不通或被拦截 | 换网络环境再试 |
| 提示「存在风险无法安装」 | 手机自带安全检测拦截非商店包 | 在安全中心把这个提示标记为信任 |

## 六、装好之后怎么更新

用安装包装的版本不会自己更新。应用内弹出更新提示、或想升到新版时，重新获取一份新安装包覆盖安装即可；覆盖安装沿用同一包名时，账号数据和本地记录会保留。重装前把「自己能登上账号」确认一遍——万一重装后登不上，找回步骤在 [常见问题与账号安全.md](常见问题与账号安全.md) 第二节。

装好并能进入主界面后，下一步就是把账号建起来：流程和注意点都在 [注册与登录步骤.md](注册与登录步骤.md)。装完想直接看有什么玩法，可以跳到 [聊天室与交友玩法.md](聊天室与交友玩法.md)。
