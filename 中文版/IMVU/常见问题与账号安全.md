## 一、登录失败，按这个顺序查

| 症状 | 先查什么 | 处理 |
| --- | --- | --- |
| 提示用户名或密码错误 | 是不是把邮箱当用户名输了 | 密码方式登录输的是**用户名（昵称）** |
| 一直转圈进不去 | 网络 | Wi-Fi 和流量互切一次再试 |
| 验证码说不对 | 是不是用了旧验证码 | 两步验证的验证码每条只用一次，取当前那条 |
| Facebook 登录失败 | Facebook 本身的状态 | 先把 Facebook 登录正常再回 IMVU |
| Apple 登录失败 | Apple ID 换没换过 | 第三方注册的账号必须走原 ID |

以上都排除还登不上，走密码找回（下一节）。密码找不回且邮箱也丢了，只能给官方客服提工单，能不能找回取决于你当初填的资料够不够多。

## 二、密码找回

1. 登录页点忘记密码（Forgot Password）。
2. 输注册邮箱，收重置邮件。
3. 点邮件里的链接设新密码。

重置链接有时效，收到邮件尽快处理。如果邮件没到：先翻垃圾箱，再确认注册时填的邮箱拼写没错——临时邮箱收不到就真没了。

## 三、两步验证（2FA）

账号绑过支付方式或持有 VCOIN 的话，2FA 值得开：

- 在账号设置（网页端 Account Settings）里开启；
- 开启后每次新设备登录都要多输一条动态验证码；
- **转出 VCOIN 的前提就是开了 2FA**，不开连提现入口都走不通。

验证码生成器换手机前，记得先把 2FA 解绑或迁移，不然自己把自己锁在门外。

## 四、账号被停用 / 被封

常见触发原因和对应关系：

| 原因 | 典型情形 | 能否申诉 |
| --- | --- | --- |
| 年龄未满 13 岁 | 注册时填了真实年龄且不满 13 | 立即停用，基本无解 |
| 谎报年龄 | 未成年改成成年或反过来 | 算重大违规，申诉成功率低 |
| 支付纠纷 | 信用卡 chargeback（拒付） | 还清款项后可能解封 |
| 违反社区条款 | 刷屏、骚扰、发布违规内容 | 看情节，可提工单申诉 |
| 异地异常登录触发风控 | 换了国家或常用设备登录 | 换回常用环境通常自行恢复 |

申诉入口是官方支持站的工单系统，提交时写清用户名、触发时间、你认为误判的理由。别在聊天室里刷「我被封了」，解决不了还容易被当广告再处理一次。

## 五、日常防骗清单

1. **官方不会要你的密码**。任何私信、房间消息索要密码的都是骗子。
2. **「免费送积分/会员」的外部链接不要点**，那类站点钓的是你的账号。
3. **买二手账号有风险**：卖家随时可以用注册邮箱把号找回，钱号两空。
4. **代充服务慎用**：盗卡充值会连坐封你的号。
5. **客户端只从官方渠道和可信来源装**，装完核对包信息（见 [下载与安装教程.md](下载与安装教程.md) 第三节的 MD5 核对方法）。

## 六、拉黑与举报骚扰

被骚扰时的完整处置路径，三步走：

1. **拉黑**：交友分区进 Online Friends，搜对方头像名进个人页，点右上角「…」选 Block。拉黑后对方无法再联系你。
2. **举报**：不用先认识对方也能举报——
   - **举报私信**：长按那条消息选 Report Message，点 REPORT 提交，弹窗里勾选左侧方框可以顺手把人拉黑；
   - **举报 Feed 评论**：长按评论选 Report Comment，同样可勾选拉黑；
   - **举报个人主页**：对方头像卡片右上角「…」里选 Report，选一个举报理由提交。
3. **管理黑名单**：主页右上角头像图标进 Settings，点 Blocked Users 查看和解除拉黑。

拉黑解决的是「不再被打扰」，举报才触发官方处理。情节严重（威胁、诈骗）的，两边都做，再把聊天截图留好。

## 七、改资料与删号

- **改邮箱、改密码**：网页端账号设置页都能自助完成。
- **改生日**：成年用户可在账号设置直接改成 18 岁以上；填成未成年的要提交证件走人工，见 [注册与登录步骤.md](注册与登录步骤.md) 第一节。
- **改名字**：显示名免费随便改，头像名要买改名令牌，规则与步骤见 [怎么改名字.md](怎么改名字.md)。
- **注销账号**：需要通过官方客服提工单处理，应用内没有自助删除入口。

## 八、问题不在账号而在应用本身时

闪退、房间加载失败、商店打不开这类属于客户端问题：先彻底退出重开，再试重启手机，仍不行就换网络环境。安装环节的问题回 [下载与安装教程.md](下载与安装教程.md) 第五节对照表。账号之外的功能问题（积分不到账、物品丢失）走官方工单，报上用户名和消费时间，客服能查到流水。
