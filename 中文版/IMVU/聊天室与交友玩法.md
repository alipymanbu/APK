## 一、先认识首页的四个分区

手机版主界面按功能分了四块，找任何功能都从这四块下手：

| 分区 | 里面有什么 |
| --- | --- |
| 装扮（Dress Up） | 商店、换装、往 Feed 发帖、买积分 |
| 交友（Friendship） | 聊天室、Hangout 匹配、Discover 动态、关注者、找人、送礼、邀请好友 |
| 约会（Dating） | 专门的约会聊天室、直播房间、给约会对象送礼 |
| 奖励（Rewards） | 每日转盘、每日登录奖励、赚积分入口、VIP |

## 二、进聊天室的正确姿势

1. 在交友分区点 Start Chatting，进入房间列表。
2. 用顶部的筛选器缩小范围，三个维度都可用：
   - **语言**：筛出说中文或英语的房间，沟通顺畅度差别很大；
   - **人数**：满员房间进不去，可按当前人数筛；
   - **分级（Rating）**：普通级（GA）与 18+ 级别（需要年龄验证和 Access Pass）分开。
3. 点 See All 能看全量列表，点房间名即进入。
4. 进房后你的化身会出现在 3D 场景里，说话以气泡形式显示在化身头顶。

挑房间的经验：想练口语就进标注英语的房，想安静聊天就挑人数适中的房——几十人的大房消息刷得很快，你的话很容易被淹没。

## 三、在房间里怎么互动

- **换动作**：点自己的化身可以选动作（挥手、跳舞、坐下等），3D 形象会直接做出来，不用打字描述。
- **表情与心情**：气泡聊天可切换化身当前的情绪状态。
- **亲密动作**：握手、拥抱这类互动动作需要走到对方化身附近才能触发。
- **语音**：Live 房间支持语音，但语音功能与会员（VIP）绑定，非会员进 Live 房主要是围观。

## 四、认识人之后的几步

- **加好友**：点对方头像进个人页，从那里发起关注或好友请求。
- **Hangout 匹配**：交友分区里的 IMVU Hangout，点 Chat Now 由系统给你匹配一个人开聊，不想自己挑房间就用它。
- **找人**：Search People 按条件搜人；Discover 流里也能看到陌生人的动态，从动态进入对方主页更自然。
- **送礼**：好友页面点 Send Gift，可以送愿望清单里的物品、积分或 VCOIN。送礼前先看对方公开的愿望清单，命中率比自己瞎挑高得多。
- **邀请站外朋友**：Invite Friends 生成你的链接，发给还没玩的朋友。

## 五、约会分区和普通房间有什么不同

约会分区（Dating）里的聊天室和直播房以认识对象为目的，进入目的性更强。你的化身和资料页会被频繁查看，所以进约会房之前先把装扮弄好、资料填完整。给约会对象送礼走同一套送礼入口，只是对象变了。

## 六、发帖与拍照

- **Feed 发帖**：装扮分区里的 Post to Feed，把化身照片发到动态流；拍照时能换姿势、加滤镜。
- **社区规则**：发帖内容受服务条款约束，擦边内容即使你有 Access Pass 也可能被处理，别把分级内容发到公开流里。

## 七、几个容易踩的坑

1. **别用同一句话刷屏**：在房间里重复发言会被当广告处理，轻则禁言重则封号。
2. **陌生人发的外部链接不要点**：IMVU 里也有骗号行为，凡是索要密码、让去别的网站登录的都是骗子。
3. **不满 18 岁别进 18+ 房间**：分级门槛靠年龄验证卡，绕过的后果是封号，规则写在 [注册与登录步骤.md](注册与登录步骤.md)。
4. **被人骚扰用举报**：长按对方头像或消息有举报入口，官方靠玩家举报处理违规。

进房间后想要自己的化身和别人不一样，就得花积分买东西——商店怎么逛、衣服怎么换见 [化身装扮与商店购物.md](化身装扮与商店购物.md)；积分和 VCOIN 的账怎么算见 [Credits与VCOIN的区别.md](Credits与VCOIN的区别.md)。
