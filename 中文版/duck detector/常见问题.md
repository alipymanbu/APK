## 一、界面是英文，怎么换成简体中文

1. 在主界面点**右下角的齿轮图标**进设置页。
2. 在配置项目里找到**「语言」**，点它右侧区域。
3. 在弹出的语言列表里勾选**「简体中文」**，点确定。

改完界面文案即刻变中文；个别检测项名（如 TEE Status）即使在中文界面下也常保留英文，不影响使用。

## 二、停在首页不扫描 / 反复回到首页

多半是首次启动三关里有一关没过，对照[下载与安装教程.md](下载与安装教程.md)第四节重走一遍：

- 协议没滑到底、或没点「完成所有条件」→ 进不了主界面；
- 权限弹窗点了拒绝 → 扫描起不来。权限请求里给**「始终允许」**；当初点错的话，去系统「设置 → 应用 → Duck Detector → 权限」里把网络权限补上，再重开应用。这个权限具体用来做什么、能不能关，见[需要Root权限吗和隐私说明.md](需要Root权限吗和隐私说明.md)第二节。

## 三、检测后显示「风险报告」，要紧吗

通常**不影响手机正常使用**。它报的是系统状态类结论（Root、解锁、注入痕迹、TEE 等），不是病毒查杀结果；检测结果不是绝对标准，仅供参考，请以实际使用中的表现为准，不必对着某一项数值焦虑。你没做过相关改动却看到风险项，把报告导出来求证（下一节讲怎么发）；你本来就在玩机，那报出对应项就是如实反映。

## 四、求人帮忙看结果时，该发什么

只发一张截图往往不够 —— 别人看不到完整上下文，很容易给错判断。按这个清单准备：

1. **导出的完整报告文本**（Export Report 落盘的那个文件），里面有版本、构建时间与逐项证据；
2. **模块列表与设备信息**：装了哪些模块、什么系统、什么机型；
3. **你的配置与已经试过的操作**：改过什么、为了达到什么目的、卡在哪一步。

信息给全了，别人才好判断；只丢一句「我这个红了怎么办」通常只会得到反问。

## 五、安装时提示解析失败 / 装不上

按出现频率排查：

1. **包没下完整**：传输或下载中断会直接导致解析失败。重新从 [Duck Detector 安装文件资源（夸克网盘）](https://pan.quark.cn/s/8f1d4debf0d5)取一次，核对大小约 8.75M。
2. **系统版本不够**：本地记录标注需要 Android 5.2 以上，低于它装不上。
3. **来源没允许**：没允许当前来源安装未知应用时会直接被拦，路径见[下载与安装教程.md](下载与安装教程.md)第三节。
4. **同包名旧版残留**：装过被改坏的同包名应用时，先卸载再装。

## 六、网上有两个包名，装哪个

你手上这份（本地记录）是 **`com.studio.duckdetector`，版本号 1.9.8-beta**。网上还能看到另一条线：包名 `com.eltavine.duckdetector`、版本号是日期形式（如 `2026.09.18-xxxx`），体积也更大，其源码在 GitHub 的 `eltavine/Duck-Detector-Refactoring` 仓库公开。

两者**包名不同，不能互相覆盖安装**，会当成两个应用并存。凡涉及本套文档里的版本、包名、体积，一律以[下载与安装教程.md](下载与安装教程.md)开头那份本地记录为准；要去装另一条线，那是另一份安装包，别拿这份的口径去核对它。

## 七、不 Root 的手机能用吗

能用，装上就扫，装它不需要先 Root，也不需要解锁 Bootloader —— 它恰恰是拿来查这些状态的。联网用途与隐私边界也一并写在[需要Root权限吗和隐私说明.md](需要Root权限吗和隐私说明.md)里。
