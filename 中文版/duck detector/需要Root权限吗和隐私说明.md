## 一、不需要 Root，普通手机直接装

公开的使用教程从头到尾没有任何 Root 授权步骤：装上 → 过启动引导 → 扫描，就走完了。它本身就是**用来查你有没有 Root** 的工具，检查的是系统状态信号，不需要自己先拿到 Root。

所以这两类人都能用：

- 原厂系统、从没动过的手机：直接装，扫描照样出结果；
- 已经 Root / 改过系统的手机：同样直接装，它会如实报出检出项。

也不需要解锁 Bootloader、不需要连电脑执行命令、不需要给它「显示在其他应用上层」这类特殊权限 —— 启动引导里只会出现网络访问与（可能的）通知相关请求。

## 二、联网是干嘛的、能不能关

它的检测主体在本机完成，联网只用在少数几处。以开源仓库 README 与其公开说明列出的范围为准，网络功能限于：

1. **TEE 证书吊销状态刷新**：默认用内置的本地快照核对，只有你主动开启「在线刷新」才去请求证书服务器；
2. **更新元数据与更新日志检查**：看看有没有新版本；
3. **你自己点开的链接**：结果页或说明里的外链，点了才会访问。

启动引导里的「网络访问」弹窗点「始终允许」即可；有资料提到该页带一个**「使用代理服务器」开关**，在访问证书服务器不畅的网络环境下可以打开（截至该版本界面，以你实际看到的为准）。拒掉网络权限的后果见[常见问题.md](常见问题.md)第二节。

## 三、你的设备信息会不会被传出去

按其公开口径，**扫描在设备本地完成，硬件签名与安全数据不上传到外部服务器**；导出的报告是落到你自己选的文件夹里的文本文件，发不发、发给谁，由你决定 —— 这也是[检测结果怎么看.md](检测结果怎么看.md)里建议「要求助就发报告」而不是「应用会自动上报」的原因。

你需要留意的只有两点：一是启动引导里的协议本身（点「完成所有条件」即表示你已阅读）；二是你**主动**把报告、截图发到论坛或聊天里时，那些内容会离开你的设备 —— 报告里带模块列表与设备信息，发之前自己过一眼。

## 四、结果的可信度边界

开源仓库 README 自己就把话说明白了，三条值得记住：

- **结果是启发式的**：可能误报、可能漏报，也可能存在没覆盖到的检查项；
- **不承诺「所有被改的环境都能查出来」**：项目没有做这个保证；
- 某些检查在特定机型 / 厂商 ROM 上会因权限受限而降级或跳过，这属于正常现象，不是你装错了。

所以别把某一项红绿当成判决 —— 具体怎么读、怎么交叉验证，见[检测结果怎么看.md](检测结果怎么看.md)与[和Momo、Ruru有什么区别.md](和Momo、Ruru有什么区别.md)。
