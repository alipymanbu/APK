## 一、文件列表能做什么

在**「打开导图」页面**（文件列表）里：

| 操作 | 手势 |
| --- | --- |
| 删除 / 移动 / 重命名 | **左划文件**，在出现的选项里选 |
| 创建文件夹 | 点页面**右上角的加号**按钮选择创建 |

导图攒多了就按用途建文件夹（工作、学习、待办各一个），找起来快得多。

## 二、一打开就想先挑文件

默认启动直接进编辑，想让它先停在文件列表，去**「应用设置」页面勾选「启动显示选择文件页面」**。经常同时管好几张图的人建议打开这个设置。

## 三、删掉的文件还能找回吗

分两种情况：

- 开过云同步、删除前文件已经上过云端：重新登录云同步，点「从云端下载文件」看能不能拉回来（云同步用法见[云同步与换手机迁移.md](云同步与换手机迁移.md)）；
- 从没同步过：本地删除后没有回收站可捞，所以重要文件建议定期手动「同步文件到云端」一次。

## 四、高频问题速查

一两句话能答完的都收在这，点击「详见」去看对应篇章：

| 问题 | 一句话答案 | 详见 |
| --- | --- | --- |
| 怎么加分支 | 点分支末端的加号加子分支；长按主干可「向左添加分支」 | [分支添加与编辑操作.md](分支添加与编辑操作.md) |
| 怎么改字体大小和颜色 | 编辑文字时点键盘上方工具栏中间的「Aa」按钮 | [分支添加与编辑操作.md](分支添加与编辑操作.md) |
| 怎么撤销误删 | 双击导图空白处，菜单里选撤销 | [分支添加与编辑操作.md](分支添加与编辑操作.md) |
| 分支太多想移动 | 长按分支文字，菜单里选移动，再点目标分支 | [分支添加与编辑操作.md](分支添加与编辑操作.md) |
| 想换导图布局 | 长按主干根支改样式，或去「应用设置」的「导图样式选择」 | [导图样式与文字大纲.md](导图样式与文字大纲.md) |
| 导出图片 / PDF 在哪 | 进「导图快照」页面，点右上角「导出」 | [导出与分享方法.md](导出与分享方法.md) |
| 怎么发给别人看 | 右侧菜单「导图分享」，发文件或生成链接都行 | [导出与分享方法.md](导出与分享方法.md) |
| 换手机文件怎么办 | 同一账号登录云同步，点「从云端下载文件」 | [云同步与换手机迁移.md](云同步与换手机迁移.md) |
| 电脑上能用吗 | 官网下客户端，或直接开网页版 | [电脑客户端与网页版.md](电脑客户端与网页版.md) |
| 要不要付费 | 基础功能免费，专业版走内购，档位以应用内为准 | [下载与安装教程.md](下载与安装教程.md) |
| 安装失败 | 先看 MD5 与存储空间，逐项排查 | [下载与安装教程.md](下载与安装教程.md) |
