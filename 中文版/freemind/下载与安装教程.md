## 一、先对清名字：freemind 是哪款应用

你从搜索引擎搜 freemind 找到这篇，多半是因为部分第三方下载站把一款安卓思维导图应用标成了 freemind。它的正式名称是 **MindLine 思维导图**（应用商店里显示的名字是「思维导图」），开发者是深圳市小棕熊科技有限公司。

核对是不是同一款，看两条就够了：

| 核对项 | 值 |
| --- | --- |
| 包名 | `czh.mindnode` |
| 开发者 | 深圳市小棕熊科技有限公司 |

另外别和另一款混淆：开源软件 FreeMind 是运行在电脑上的 Java 程序，和这款手机应用不是同一个东西。搜 freemind 时，安卓相关的结果基本都指向 MindLine 这款手机版。

## 二、从哪获取安装包

两条路：

1. **夸克网盘**：转存本文头部的 freemind（MindLine 思维导图）安装文件资源（夸克网盘）到自己网盘，下载里面的 APK 直接安装。适合不方便登录应用商店的设备。
2. **应用商店 / 官网**：在应用商店搜「思维导图」，认准开发者名；或到官网 [mindline.cn](https://mindline.cn) 下载。

## 三、要不要花钱

应用本体免费下载、免费画图；官方在 App Store 的 MindLine 产品页标着「专业版」内购，检索时的档位为 3 个月 ¥25、一年 ¥65、永久 ¥165（截至 2026-09 检索；安卓端的档位与权益以应用内购买页实际显示为准）。

先装来把基础功能用顺，等真的碰到需要专业版才能解锁的能力再考虑买不买，不用一上来就掏钱。想在电脑上一起用的，客户端与网页版见[电脑客户端与网页版.md](电脑客户端与网页版.md)。

## 四、安装步骤

1. 从上面任一渠道拿到 APK 文件；
2. 点开 APK，系统第一次会问「是否允许安装未知应用」，允许当前文件管理器或浏览器安装即可（应用商店装的没有这一步）；
3. 等安装完成，打开应用，首次启动会提示服务协议与隐私政策，同意后进入。

安装包只有 12MB 出头，对安卓版本要求不高，旧一些的手机也能装；具体系统要求以安装页提示为准。装好后应用会用到网络、本地文件读写、拍照、录音等权限，分别对应云同步、插图、录音备注这些功能，属正常范围。

## 五、安装失败怎么办

| 现象 | 常见原因与处理 |
| --- | --- |
| 提示「未知来源」被拦 | 在系统设置的安装权限里，允许当前下载来源（浏览器 / 文件管理器）安装应用 |
| 解析包出错 | 多半是下载不完整，重新下载一次，并核对上面给出的 MD5 |
| 存储空间不足 | 清出至少几百 MB 空间再装 |
| 安装后打不开 | 重启手机再试；仍不行就换应用商店版安装 |

装好之后建议先把云同步打开，换手机时文件能跟着走，具体见[云同步与换手机迁移.md](云同步与换手机迁移.md)；第一次画导图不知道从哪下手，看[分支添加与编辑操作.md](分支添加与编辑操作.md)。
