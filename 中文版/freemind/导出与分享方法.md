# MindLine 思维导图导出与分享方法

> 本篇讲做好的导图怎么拿出去：从哪里导出、选什么格式、怎么把文件或链接发给别人，以及导图社区是什么。

## 一、导出入口在哪里

打开要导出的那张导图，进入**「导图快照」页面，点右上角的「导出」按钮**，即可选择导出为图片、PDF、文字大纲等格式的文件。找不到入口时，先在导图界面找快照 / 预览相关的菜单。

## 二、选哪个格式

导出格式不多，按用途对号入座：

| 格式 | 适合场景 | 注意点 |
| --- | --- | --- |
| 图片 | 发微信、插进聊天或文档 | 分享最省事的一种，对方不用装任何软件 |
| PDF | 打印、正式提交、存档 | 版式固定，不怕对方设备上显示错乱 |
| 文字大纲 | 只想要层级文字、再加工成提纲或笔记 | 导出的就是分支层级文本，方便贴到别处继续编辑 |
| HTML | 想把导图放进网页、或在浏览器里直接打开看 | 官方在 iOS / Windows 渠道的描述里提到过 HTML 导出，安卓端以导出菜单实际显示为准 |
| 其他导图软件格式 | 对方用的是别的思维导图软件 | 手机端支持的范围以导出菜单实际显示为准；**电脑客户端**里可导出图片、PDF、文字大纲、纯文本、XMind 等格式，选择更多（客户端怎么装见[电脑客户端与网页版.md](电脑客户端与网页版.md)） |

拿不准就先导图片，兼容性最好；对方要继续改，优先发文字大纲，或者让对方也用 MindLine 打开源文件。

## 三、直接分享：发文件或发链接

不想走导出，可以在**右侧菜单栏里点「导图分享」**，两种方式：

1. **直接发送文件**：把导图文件通过微信、QQ 等渠道发出去，对方用 MindLine 打开后可继续编辑；
2. **生成链接分享**：生成一条分享链接发出去，对方点开就能看，适合发群里让多人查看。

给领导看进度用链接，给同事协作改内容发文件。

## 四、导图社区

右侧菜单里还有**导图社区**入口：你可以把自己的导图上传到社区，也可以浏览别人分享的作品找灵感。上传属于自愿行为，不想公开的导图不碰它即可。

## 五、导出去之前，先把图存好

导出解决的是「给出去」，备份解决的是「丢不了」。开启云同步后，导图文件会自动保存到云端，换设备也在，见[云同步与换手机迁移.md](云同步与换手机迁移.md)。还没装应用的话，从头看[下载与安装教程.md](下载与安装教程.md)。
