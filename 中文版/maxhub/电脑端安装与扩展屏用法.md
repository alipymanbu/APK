## 一、电脑端去哪装

手机装的是安卓安装包（见 [下载与安装教程.md](下载与安装教程.md)），电脑端是另一套安装包，别拿手机 APK 装到电脑上。桌面版从官方渠道获取：[MAXHUB 下载中心](https://www.maxhub.com/share/index.html)，覆盖三个平台：

| 平台 | 系统要求（官网当前标注） |
| --- | --- |
| Windows | Win10 及以上 |
| macOS | 10.13 及以上 |
| Linux | UOS、麒麟（KylinOS），已通过厂商认证 |

公司电脑装不了软件时，直接找 IT 部门要安装包或请他们远程安装。

## 二、连接方式与手机端一致

打开电脑端传屏助手后，连接方法与手机相同（细节见 [连接会议平板的步骤.md](连接会议平板的步骤.md)）：

- 输入大屏上显示的连接码；或
- 电脑与设备在同一网络时直接发现设备。

连不上时排查思路也一样，先试设备热点连法，再按 [常见问题与连接失败排查.md](常见问题与连接失败排查.md) 逐项过。

## 三、复制屏、扩展屏、应用投屏怎么选

这三种模式是电脑端的能力（手机端只有整屏镜像）：

| 模式 | 大屏上出现什么 | 适合场景 |
| --- | --- | --- |
| 复制屏 | 与电脑屏幕一模一样 | 演示时看着大屏讲，观众看你看到的一切 |
| 扩展屏 | 平板变成 Windows 的第二块显示器 | 大屏放讲稿备注或数据，电脑屏留私聊窗口 |
| 应用投屏 | 只投某个窗口 | 只展示 PPT，微信弹窗不上大屏 |

选扩展屏后，平板会出现在 Windows「设置 → 系统 → 屏幕」的显示器列表里，可以像接了第二台显示器那样拖动窗口、调整主副屏排列。应用投屏在演示前先选好目标窗口，中途切换应用时确认投的窗口跟着换了。

## 四、电脑端独有的两个能力

官方产品页对这两项能力标注了机型门槛（截至 2026-09 官网页面，以官方页面为准）：

| 能力 | 说明 | 前置条件 |
| --- | --- | --- |
| P2P 点对点传屏 | 不依赖路由器，电脑与设备直连传屏 | Windows 10 及以上 + 接收端为标准款 V7 及以上机型 |
| 超声波发现设备 | 电脑靠近设备即可被识别，免扫码 | 电脑需授予麦克风权限 + 接收端为标准款 V7 及以上机型 |

如果你的设备是 V6 或更早，这两项不会出现，属于正常现象，用常规的连接码方式即可。机型怎么看，见 [传屏模式与反向控制.md](传屏模式与反向控制.md) 第五节的说明。

## 五、会议室里电脑手机混用

同一间会议室允许多台设备同时上屏：电脑投 PPT、手机传现场照片，两路画面分屏同显（分屏路数以机型为准，操作见 [传屏模式与反向控制.md](传屏模式与反向控制.md) 第三节）。后加入的一路按同样方式连接后选择加入分屏即可，不需要把先连的那路断开。
