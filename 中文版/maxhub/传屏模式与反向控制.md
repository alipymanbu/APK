## 一、手机端的核心动作：整屏镜像

手机端的传屏以「屏幕镜像」为主：点开始传屏后，你手机屏幕上的一切（包括 App 内的操作）实时出现在大屏上，停止传屏或断开连接即结束。演示前建议：

- 先把要展示的 App 提前打开、登录好，避免当众输密码；
- 手机关掉消息弹窗（或开勿扰），防止微信内容投到会议室大屏上；
- 竖屏内容会居中显示、两侧留黑边，横屏内容铺满，投视频前先把手机横过来。

## 二、复制屏、扩展屏是电脑端的事

官方宣传里的「复制屏 / 扩展屏 / 应用投屏」多模式，是**电脑客户端**的能力：扩展屏指把会议平板当成 Windows 的第二块显示器。手机端没有「扩展屏」概念，不要在手机 App 里找这个开关。电脑端的下载安装与各模式怎么选，见 [电脑端安装与扩展屏用法.md](电脑端安装与扩展屏用法.md)。

## 三、多设备分屏同显

同一个会议室里允许多台设备同时传屏，大屏分成几块并排显示，适合对比两份方案、或者多人轮流讲。分屏路数常见为四路（以机型与固件为准）。操作要点：

- 第二个人按同样方式连接后选择「加入传屏 / 分屏」即可，不用把第一个人踢下线；
- 分成几块、怎么排布，取决于设备型号与当前固件，以你设备屏幕上实际出现的选项为准。

## 四、反向控制：用手机操作平板

连接后可以把手机当成平板的遥控器：

| 你在手机上做的动作 | 大屏上的效果 |
| --- | --- |
| 滑动、点按 | 等同于直接触控平板屏幕 |
| 翻页键 | PPT、PDF 翻页 |
| 返回 / 主屏 | 平板回到上一级或主界面 |

演讲者不用一直站在屏幕边上，站在讲台翻页即可。注意官方对这一功能标注了机型门槛：需要接收端为 MAXHUB 会议平板标准款 V7 及以上机型，老机型上看到没有这个入口属正常。

## 五、功能与机型对照

下表整理自官方产品页对各功能的机型说明（截至 2026-09 官网页面，后续可能调整，以官方页面为准）：

| 功能 | 前置条件 |
| --- | --- |
| 基础无线传屏 | 常规机型均可，手机与设备同一网络或连设备热点 |
| BYOM（把平板当会议外设调用） | 接收端为经典款 V6 及以上机型 |
| 设备控制（反向触控） | 接收端为标准款 V7 及以上机型 |
| P2P 点对点传屏（不依赖路由器） | Windows 10 及以上电脑端 + V7 标准款及以上机型 |
| 超声波发现设备 | 电脑端需授予麦克风权限 + V7 标准款及以上机型 |

手机端不涉及 P2P 传屏与超声波发现这两项（它们是电脑端的能力），但对照表能帮你判断「为什么同事电脑有某功能而我的手机没有」。功能对不上号时，先查你会议室的设备是哪一代：通常在平板的设置 → 关于本机里能看到型号。
