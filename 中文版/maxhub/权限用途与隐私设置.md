## 一、先说结论：哪些权限是核心

传屏这件事本身只依赖两类权限：**发现设备**（位置 / 附近设备 / WLAN 信息）与**传输内容**（存储）。其余权限都挂在具体功能上，不用那个功能就可以拒绝。安装或首次使用时被弹窗吓到的话，按这个原则给即可。

## 二、七个敏感权限逐项说明

下表整理自应用商店对近期版本安装包（R.6.6.x，2025-10 发布）的权限标注；你手里这份 R.6.4.8.0 大体一致，个别项可能不同，**以你手机安装时实际弹出的请求为准**。两个位置权限、两个存储权限性质相同，各并成一行，七项共五行：

| 权限 | 实际用途 | 拒绝的后果 |
| --- | --- | --- |
| 精确位置 / 大致位置 | 安卓系统把 Wi-Fi 信息归入位置权限，搜到同一网络里的设备需要它 | 搜不到设备，只能靠扫码或手输连接码 |
| 相机 | 扫码连接；扫描文档上屏（见 [手机遥控与文件共享.md](手机遥控与文件共享.md)） | 不能扫码，改手输连接码；扫描文档不可用 |
| 读取 / 写入存储卡 | 把手机里的照片、视频、文档传到平板 | 文件共享与照片、音视频上屏全部不可用 |
| 显示在其他应用上面 | 商店权限说明为「显示弹框、全屏界面到其他应用上面」，对应传屏时的悬浮类界面元素 | 悬浮类入口可能不出现，核心传屏不受影响 |
| 读取通话状态和移动网络信息 | 官方未说明具体用途；安卓应用常用它感知来电 | 暂未发现影响核心传屏功能，介意可拒绝后实测 |

位置权限被拒绝后设备列表会一直是空的——这是传屏助手「搜不到设备」的常见原因之一，排查方法见 [常见问题与连接失败排查.md](常见问题与连接失败排查.md) 第二节。

## 三、其他权限与它们的用途

安装包还带一批非敏感权限，各自对应明确的动作：

| 权限 | 对应动作 |
| --- | --- |
| 控制近距离通信（NFC） | 靠近老款机型的 NFC 标签触发连接（见 [连接会议平板的步骤.md](连接会议平板的步骤.md) 方式 3） |
| 接收 WLAN 多播 | 在局域网里发现设备 |
| 录音（麦克风） | 语音相关功能与部分连接方式 |
| 与蓝牙设备配对 | 蓝牙相关的设备发现 |
| 防止手机休眠 | 传屏期间保持屏幕活动，避免中途断开 |
| 控制闪光灯 | 扫码时补光 |

这些权限不涉及个人数据读取，保持默认即可。

## 四、在系统里怎么改权限

1. 打开手机「设置 → 应用管理」，找到传屏助手；
2. 进入「权限管理」，逐项查看当前状态（允许 / 仅使用时允许 / 拒绝）；
3. 把需要的功能对应的权限改为允许，或把不想要的改为拒绝。

各品牌手机路径略有差异（小米在「隐私保护」、华为在「权限管理」），搜应用名都能到同一页面。

## 五、改完权限后要做什么

权限改动不会即时生效到正在运行的进程：**把传屏助手从后台完全划掉，再重新打开**，新权限才被读到。改了位置权限后搜不到设备、改了存储权限后传不了文件，多半就是没重启 App；重开后还不行，再按 [常见问题与连接失败排查.md](常见问题与连接失败排查.md) 的清单继续查。
