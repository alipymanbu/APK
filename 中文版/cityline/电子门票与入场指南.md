## 一、电子票什么时候到手

电子门票按主办方指定的日期发放，通过电子邮件传送，或直接在 Cityline Ticketing 应用里展示。买完票不等于马上有票，等发放即可；一直没等到的，先在会员服务的交易纪录里核对订单状态，再按 [常见问题与客服渠道.md](常见问题与客服渠道.md) 的思路排查。

选实体票邮寄的注意两点：送递服务一般只提供到演出前 7 天左右（个别节目以自己的条款为准），购票时要另付送递费；送递停了之后仍能买票，只是改去售票处或自助服务站取票。

## 二、入场可以出示的票型

| 票型 | 入场时出示什么 |
| --- | --- |
| 实体票 | 提前领好的实体门票 |
| 电子票（打印） | A4 白纸打印的电子门票 |
| 电子票（手机展示） | 移动设备出示电子门票，二维码要完整显示、不小于 3cm × 3cm |
| 电子票（应用内） | 登录 Cityline Ticketing 应用，出示应用里的电子门票 |
| 电子票（钱包） | 已存入 Samsung Wallet / Google Wallet / Apple Wallet 的电子门票 |
| 动态电子票 | 必须提前装好应用并登录，入场时出示应用内的动态二维码 |
| 实名制票 / 优惠票 | 上述票型之外，另备与购票资料相符的有效身份证明 / 年龄证明 |

注意动态电子票的特殊性：它凭「动态二维码」进场，二维码大约每 10 秒自动刷新一次，且展示页面会阻止截屏，所以应用是唯一入口、截图不能当票用。进场前手机要充满电、提前登录好账号；还没装应用的看 [下载与安装教程.md](下载与安装教程.md)。

## 三、自助服务站取实体票

节目允许自助取票的，任意一部 Cityline 自助服务站都能取，两种方式任选其一：

1. 出示应用内的「交易二维码」；
2. 报确认邮件里的「取票编码」和「取票密码」。

实施「延后取票」方案的节目，要在主办方指定的日期和时间之后才能取，别提前白跑一趟。

## 四、把票转送给朋友

需要凭「动态二维码」进场的节目，你可以在应用里用「转送朋友」（Transfer）按钮，把单张门票转到朋友的 Cityline 账户。流程是：点「转送」→ 填对方的邮箱地址 → 对方收到邮件后点链接接受。两个时限要注意：

- 接受链接只有 1 小时有效，超时没点，票会自动退回你的账户；
- 转送成功后，你的应用里这张票会显示为已转出。

前提是对方也有 Cityline 账户，没有的话先按 [会员注册与登录教程.md](会员注册与登录教程.md) 注册一个。

## 五、线上节目与票务杂项

- **Cityline Digital Theatre**：买这类线上节目票的，确认邮件里有点播链接，在指定时间内观看；
- **报失门票**：按个别节目主办方指定的程序处理，购票平台本身不受理报失；
- **恶劣天气**：留意主办方与场馆的社媒公告，或直接向场馆查询特别安排。

票还没买成的，回 [购票流程与选座技巧.md](购票流程与选座技巧.md)；证件核对、退款相关的问题见 [常见问题与客服渠道.md](常见问题与客服渠道.md)。
