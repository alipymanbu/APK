## 一、安装前先确认这几件事

- **系统版本**：安卓 5.1 及以上。商店收录页对当前版本标注的是 Android 5.1+，实际以你安装时手机给出的提示为准。
- **存储空间**：本篇对应的安装包约 50.86 MB，加上运行缓存，建议至少留出 300 MB 空闲空间。
- **网络**：听歌识曲、歌词、播放这些功能都要联网才能用；识别结果会先存在本机，网络恢复后可重试（见 [识别失败常见原因与解决办法.md](识别失败常见原因与解决办法.md)）。

本文涉及的安装包信息如下（这是网盘里那一版的实际记录，官方商店可能已发布更新的版本，以官方页面为准）：

| 项目 | 值 |
| --- | --- |
| 版本 | 10.4.5 |
| 包名 | com.melodis.midomiMusicIdentifier.freemium |
| 安装包大小 | 约 50.86 MB |
| MD5 | BBE90844DFD5CF6FE1FEB1EAD75C1495 |

核对 MD5 的作用：转存下载完成后，如果担心文件在传输中损坏，可以用校验工具比对一下这个值，一致就是完整的原包。

## 二、从哪里获取安装包

两个渠道，按你设备的情况选：

1. **Google Play 商店**（官方渠道）：在手机上的 Play 商店搜索 `SoundHound`，开发者显示为 SoundHound, Inc.，商店页地址为 [https://play.google.com/store/apps/details?id=com.melodis.midomiMusicIdentifier.freemium](https://play.google.com/store/apps/details?id=com.melodis.midomiMusicIdentifier.freemium)。设备有完整 Google 服务框架时，这是最省事的方式。
2. **网盘安装包**：如果你的设备没有预装 Google 服务、或者商店里搜不到，可以转存 [SoundHound 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2093eded3be4) 里的 APK 文件，下载后手动安装。

两个渠道是同一个包名（`com.melodis.midomiMusicIdentifier.freemium`），安装其中之一后不要再重复装另一个，避免互相覆盖或共存出问题。

## 三、安装步骤

1. 从上面任一渠道拿到 APK 文件，点开它。
2. 系统第一次会提示「不允许安装未知来源应用」，按提示进入设置，允许你的浏览器或文件管理器「安装未知应用」。
3. 回到安装界面，点「安装」，等待完成。
4. 装完点「打开」，首次启动会有权限请求弹窗，见下一节。

## 四、麦克风权限（这个应用的必选项）

SoundHound 的核心操作是把周围的声音或你的哼唱交给服务器比对，没有麦克风权限整个应用等于没有主功能：

- **安装后首次打开**：直接在弹窗里选「允许」。建议选「仅在使用中允许」，不需要「始终允许」。
- **弹窗被误点了拒绝**：再到系统设置里手动补开，路径一般是 `设置 → 应用 → SoundHound → 权限 → 麦克风`（不同品牌手机的菜单名略有差异，国产系统多在「应用管理」里）。
- **顺带确认**：部分系统还会单独管「麦克风访问总开关」（下拉快捷面板里那个），装完后如果一直识别不出声音，先看看这个总开关是不是关了。

权限相关的疑问（比如为什么要这些权限），官方在商店页附有说明入口，安装前可以到 [Google Play 页面](https://play.google.com/store/apps/details?id=com.melodis.midomiMusicIdentifier.freemium) 的「关于此应用」里查看。

其他权限在应用帮助里的官方解释，装完看到弹窗心里有数：

| 权限 | 官方给出的用途 |
| --- | --- |
| 麦克风（硬件控制） | 录音以识别歌曲、语音搜索；识别后的震动提醒可在应用选项里关闭 |
| 电话 | 检测来电，让你接电话时识别中断、不抢通话 |
| 存储 | 在手机存储里存数据，加快应用加载 |
| 网络通信 | 完成搜索、获取歌词与播放内容 |
| 系统工具 | 应用退到后台时帮助省电 |

## 五、装不上或打不开时的对照检查

| 现象 | 先检查什么 |
| --- | --- |
| 提示「无法安装 / 解析包出错」 | 安装包是否下载完整（比对 MD5）；系统版本是否达到安卓 5.1；文件是否在传输中被改名或截断 |
| 点安装没反应 | 存储空间是否不足；是否同时残留了另一个来源的同包名版本 |
| 打开就闪退 | 手机系统过旧；先重启一次手机再试，仍闪退则说明该版本与你的系统不兼容，换官方商店的当前版本 |
| 装好后识别一直转圈 | 多半不是安装问题，是网络或麦克风权限，见 [识别失败常见原因与解决办法.md](识别失败常见原因与解决办法.md) |

装好之后，从 [听歌识曲使用方法.md](听歌识曲使用方法.md) 开始上手最快；免费版和付费版的差异在 [免费版与付费版区别.md](免费版与付费版区别.md)。另外商店里还有个同名但完全不同的订阅制语音助手，别装混了，见 [ChatAI语音助手与音乐应用的区别.md](ChatAI语音助手与音乐应用的区别.md)。
