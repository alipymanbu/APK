## 一、先按这个顺序排查

识别失败九成出在「声音没送出去」或「结果没传回来」，按顺序过一遍：

1. **麦克风权限**：`设置 → 应用 → SoundHound → 权限`，确认麦克风是「允许」状态（首次安装时误点拒绝最常见）。
2. **网络**：识别必须联网。先随便刷一个网页确认手机当前网络是通的；公司 Wi-Fi、校园网有时会拦这类音频上传，切移动数据再试一次。
3. **音源条件**：手机靠近扬声器、音量别太小；识别过程中不要说话、不要跟唱。
4. **重启识别**：退出结果页回到主界面，重新点橙色按钮，换一段音乐再试（每次只采样几秒，某几秒可能正赶上间奏）。

## 二、常见失败场景对照表

| 场景表现 | 原因 | 处理 |
| --- | --- | --- |
| 一直转圈，最后提示没有结果 | 网络不通或上传被拦 | 换网络（4G/5G 与 Wi-Fi 互换）重试 |
| 提示无麦克风权限 / 进度条完全不动 | 麦克风权限被拒 | 见上文第 1 步 |
| 哼唱识别永远不中 | 唱的时长不够、多人齐唱、开着背景音乐 | 一个人清唱 10 秒以上，唱副歌部分 |
| 电台/节目里那段音乐识不出 | 音源上叠了主持人的说话声 | 等纯音乐片段出现时再识 |
| 现场演出、合唱怎么都识不出 | 官方明确说明现场合唱类表演无法匹配 | 录下来后回家放录音识，或换用录屏/录音内容 |
| 短视频 BGM 识出的歌名和视频标注不一致 | 视频标注本身是错的，识别结果反而更接近原曲 | 以结果页列出的多个候选为准，试听确认 |
| 识出来是另一个歌手的版本 | 原曲是翻唱或被采样，库里收录的是改编版 | 在结果页的版本列表里找原版 |

## 三、断网时识别的结果不会丢

这是很多人不知道的一个机制：**网络不通时发起的橙色按钮搜索会被保存为「处理中」**，在「历史」页的「搜索」分类下以红色标记，「搜索」按钮上还会出现数字角标。等网络恢复后，点开那条记录重试即可，不用举着手机重新等音乐响起。

所以遇到「刚才那首歌没识出来」时，先别急着重放，打开历史页看看是不是已经躺在「处理中」里了。

## 四、哼唱识别的命中率问题

哼唱识别走的是社区人声录音库，命中率取决于「你唱的这段有没有人唱过」，所以：

- **热门歌曲**：哼几句就中，甚至调不准也能匹配上。
- **冷门歌曲 / 小语种 / 纯器乐**：社区里没人唱过就搜不到，这不是你唱得不好。纯器乐曲可以试着哼主旋律，也可以改用文字搜索歌名。
- **跑调很严重**：匹配对节奏和旋律走向有一定容错，但整段跑偏就没办法了，建议哼得慢一点、清晰一点。
- **说唱**：旋律能分辨出来的说唱段落可以试，纯念白基本不行。

判断技巧：同一首歌**换三段不同位置**（主歌、副歌、尾奏）各哼一次，三次都不中基本可以确定是曲库覆盖问题，而不是你的唱法问题。确认是覆盖问题后，还有两条路：去 [midomi.com](https://www.midomi.com/) 用网页版再试一次（曲库与手机版同源），或者换支持哼唱的其他工具——各工具的曲库互有差异，见 [和Shazam怎么选.md](和Shazam怎么选.md)。
