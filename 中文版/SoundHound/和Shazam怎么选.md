# 和 Shazam 怎么选

> SoundHound 和 Shazam 都能「放歌识曲」，真正的差别在「没有声音、只有记忆」的时候。本篇按输入方式和场景给出选择依据。

## 一、一句话分清

- **手机旁边正放着歌**：两个都行，都能在几秒内给出歌名、歌手、专辑。
- **脑子里有旋律、说不出歌名**：只能用 SoundHound。多个独立测评一致确认 Shazam 不支持哼唱或清唱识别，它必须要听到原始录音。

这个差别源于两家不同的产品思路：Shazam 的比对对象是录音库，SoundHound 除了录音库还维护着 midomi 社区的人声录音（你自己哼的段落就是和这些录音比的），所以它接得住「清唱 + 跑调 + 只记得副歌」这类输入。

## 二、能力对照

| 能力 | SoundHound | Shazam |
| --- | --- | --- |
| 识别播放中的音乐 | 支持 | 支持 |
| 哼唱 / 清唱找歌 | 支持 | 不支持 |
| 说话搜索（念歌名） | 支持 | 不支持（安卓端靠文字输入，iOS 端可由 Siri 代劳） |
| 实时滚动歌词 | LiveLyrics | 有歌词显示 |
| 绑定流媒体平台 | Spotify / Apple Music | 以 Apple Music 为主 |
| 开发方 | SoundHound, Inc.（独立上市公司） | 2018 年起归苹果所有 |
| 免费使用 | 免费，有横幅广告，另有付费版 SoundHound∞ 去广告 | 免费 |

几点说明：

- **识别速度与准确率**：第三方测评的结论并不统一——有测评把识别播放音乐的速度优势归给 Shazam，也有测评测出相反结果；对常规录音曲目的准确率，有的测出 Shazam 略高，有的认为两者相当。这类结论随版本与测试曲目变化，看个大概就行，不值得作为唯一依据。
- **歌词**：两家都有歌词能力，SoundHound 的 LiveLyrics 是逐句滚动、可以点歌词跳播（见 [歌词与播放功能.md](歌词与播放功能.md)）。
- **生态**：手机是 iPhone 且订阅了 Apple Music，Shazam 的联动更顺；同时用 Spotify 的，SoundHound 的绑定更深。

## 三、按场景选

| 场景 | 选谁 |
| --- | --- |
| 咖啡店、商场、电台听到歌，想马上知道名字 | 随便，两个都行 |
| 只记得旋律、不记得任何歌词 | SoundHound |
| 记得一句歌词，想反查歌名 | 两个都可以用文字/歌词搜索 |
| 开车想免手操作识曲 | SoundHound（Hey SoundHound 语音指令） |
| iPhone + Apple Music 重度用户 | Shazam 联动更省事 |
| 在意广告 | 免费版内容页有横幅广告：预算为零选 Shazam，已习惯 SoundHound 的可升级 SoundHound∞ 去广告 |

## 四、一起装着用，不冲突

两个应用包名不同、功能不重叠，同时安装没有任何问题，实际这也是不少人的用法：

- 平时识「正在放的歌」，谁顺手点谁；
- 哼唱场景切 SoundHound；
- 一个识不出时换另一个再试——两家的曲库覆盖不完全相同，[识别失败常见原因与解决办法.md](识别失败常见原因与解决办法.md) 里的排查流程走完还没结果时，换工具是合理的最后一步。

顺带一提，Google 搜索 App 里也有「搜索歌曲」功能（哼唱入口，安卓和 iOS 都能用），作为第三个备选。各工具对冷门歌、纯器乐的覆盖都不一样，全都试一遍仍是目前最有效的笨办法。

## 五、结论

两个都装，按输入方式分工：**有声音就放给它们听，没声音只有记忆就交给 SoundHound 哼**。还没装 SoundHound 的话，[SoundHound 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2093eded3be4)里有完整安装包，安装步骤见 [下载与安装教程.md](下载与安装教程.md)。
