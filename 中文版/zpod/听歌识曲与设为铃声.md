## 一、听歌识曲：三步走完

听歌识曲和设为铃声，是 zpod 里两个跟“听歌”不直接相关的功能：前者用来在店里、车里听到一段不认识的旋律时当场查出歌名；后者把手机里的某首歌变成来电铃声。本篇把两个功能各自的操作步骤、常见失败原因和排查顺序讲完。

先说识曲。这个功能解决的问题很具体：你在外面听到一首歌、不知道名字，想当场知道它是什么。

1. **给麦克风权限。** 第一次用会弹窗申请，同意后才收得到声音。如果之前拒绝过，去系统的“设置 → 应用 → zpod → 权限”里把麦克风打开。
2. **点播放界面上的话筒图标**，进入识别界面，再点“启动识别”。
3. **把手机靠近音源**——音箱、电视、别人手机的外放口都行。保持 10~15 秒，让周围安静一点，识别速度会明显变快。

识别成功后，界面会给出歌曲信息，通常包括歌名、歌手、专辑，并允许你直接去播放、加入收藏或歌单。**识别出来的歌，后面该怎么用就怎么用**——加歌单见 [歌单收藏与账号同步.md](歌单收藏与账号同步.md)，下载离线见 [搜索歌曲与离线下载.md](搜索歌曲与离线下载.md)。

## 二、识别不出来，按这四条依次排查

识曲是个“听环境”的功能，失败大部分是环境问题，不是应用坏了：

| 排查项 | 具体做法 |
| --- | --- |
| 环境太吵 | 挪到安静处，或把手机贴近音箱；酒吧、地铁、商场里失败率天然高 |
| 声音太小 | 提高音源音量；手机别贴在桌面等会共振的平面上，会有杂音 |
| 识别的段落没代表性 | 避开前奏、间奏和纯鼓点，挑人声或主旋律进来的那一段 |
| 录的声音太短 | 保持 10 秒以上，别听到结果还没出来就松手 |

如果试了几次都认不出，建议把这段旋律记住，换个识曲工具（系统自带的识曲功能，或别的应用）再试一次。**识别率本来就是同类工具都拿不稳的地方**——同一段旋律，在这个工具认不出、换个工具认出来，是常有的事，不必因此怀疑手机或应用坏了。

**点话筒没反应、或者一进去就闪退**，那属于应用异常而不是识别算法的问题——先按 [常见问题与排查.md](常见问题与排查.md) 里的“打开就闪退”处理；确认不是缓存问题后，回到 [zpod 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bf5368ab3afb) 取一份完整的安装包覆盖安装，能排掉“安装包本身不完整”这个变量。

补一句实话：冷门曲目、翻唱、纯器乐的识别率，任何识曲工具都会明显下降。**一段旋律认不出来，通常说明它本身就不好认，不等于应用有问题。**

## 三、把歌设为来电铃声

入口在歌曲的更多操作里，流程是：

1. 在播放界面或歌曲列表里点该歌曲的更多操作。
2. 选择“设为铃声”一类的选项。
3. 系统会问你要设成哪一类：来电铃声 / 通知铃声 / 闹钟，按需要选。
4. 确认后，用它给手机打个电话验证一下效果。

要注意机型差异：**部分安卓系统不弹这个选择框，而是要求你去系统“设置 → 声音与振动”里手动挑选。** 遇到这种情况，先在系统铃声列表里找找有没有多出来的这一首；找不到就说明这一步被系统拦下了，往下看第四节。

## 四、铃声设了不生效怎么办

按成功率从高到低排：

1. **权限没给够。** 回到应用权限页，确认“存储 / 文件与媒体（写入）”和“修改系统设置”都给上了。这两项缺一项，写入铃声就可能无声失败。
2. **系统的声音设置没刷新。** 去“设置 → 声音与振动 → 来电铃声”，手动选中新出现的那一首。手动选一次之后通常就记住了。
3. **把音频本身的问题排掉。** 换一首常规长度的热门歌再设一次。如果换歌就好，那是个别文件的问题，不是功能坏了。
4. **换掉旧安装包。** 上面三条都试过还不生效，就排除掉安装包这个变量：到 [zpod 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bf5368ab3afb) 取当前这份 2.1.5 覆盖安装（升级不用先卸载，卸载会丢掉本地歌单和已下载的歌）。**这一步是排除法，不是断言旧版必然有问题**——排掉它之后，原因就只剩系统侧了。
5. **系统级限制。** 部分定制系统（主要是一些国产 ROM）会限制第三方应用改动铃声，这属于系统策略，应用侧改不了，只能走系统自带的方式手动挑选。

最后提醒一句：把整首流行歌当来电铃声，来电话时其实只会响前十几秒，而且音量一开大，前奏经常听不清是谁打来的。**真正好用的做法是裁一段副歌高潮做铃声**——裁剪用手机自带的音频工具或任意剪辑应用都行，裁完再按上面的步骤设一遍。
