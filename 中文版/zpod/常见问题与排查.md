## 一、装不上：安装被拦截、提示解析包错误

从装到用，zpod 上遇到的问题基本集中在下面这九类：装不上、打开闪退、搜不到歌、点播放没声音、下载卡住、离线歌消失、本地歌扫描不出来、后台播放中断，以及分不清清缓存和清数据。每一节都给出判断依据和处理动作，遇到问题时直接跳到对应小节。

先分清是哪种失败，两条路的处理完全不同。

**情况 A：提示“不允许安装未知来源的应用”**
这不是错误，是系统的默认拦截。按 [下载与安装教程.md](下载与安装教程.md) 第三节放行一次即可。

**情况 B：提示“解析包时出现问题”“应用未安装”**

| 原因 | 判断方法 | 处理 |
| --- | --- | --- |
| 安装包没下完整 | 文件大小明显小于 55.20 MB | 删掉重下，别续传；在电脑上下一份再用数据线拷过去更稳 |
| 系统和应用不兼容 | 手机系统版本过低 | 手机系统太旧时无法安装，这种情况只能换设备 |
| 与已安装的旧版本签名冲突 | 之前装过别的渠道的同名包 | 先卸载旧版本再装；但卸载会清掉本地歌单，先登录账号同步一次 |
| 存储空间不足 | 设置里看剩余空间 | 至少留出安装包体积两倍以上的空闲空间 |

反复失败时，最省时间的做法是回到 [zpod 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bf5368ab3afb) 重新取一份，把“手里的包坏了”这个可能性一次性排掉。

## 二、打开就闪退

按顺序试，前三步能解决大部分情况：

1. **重启应用**：从最近任务里划掉，重新打开。
2. **重启手机**：系统级的音频服务或存储挂载出问题时，这一步最有效。
3. **清缓存**（不是清数据）：设置 → 应用 → zpod → 存储 → 清除缓存。清缓存不会动你的歌单和离线歌。
4. **覆盖安装**：从 [zpod 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bf5368ab3afb) 取一份新包装上，**不要先卸载**，覆盖安装能修掉文件损坏类的问题，同时保住本地数据。
5. **看是不是特定操作才崩**：只在切音质、只在识曲时崩，说明是那条功能路径的问题，绕开它用，等新版本修。

如果清完缓存、覆盖安装后依然一打开就退，那基本是设备兼容性问题，换台设备验证一次就能确认。

## 三、搜不到想听的歌

搜不到通常不是应用故障，按这个顺序查：

1. **换关键词**：歌名里的括号内容、`Live`、`Remix`、`翻唱`去除后再搜；或者改用“歌手名 + 歌名里的两个关键词”。
2. **换输入方式**：歌名搜不到就用歌手名搜，进歌手页翻。
3. **确认网络正常**：能打开别的网页就说明网络没问题，跳到下一条。
4. **确认是资源本身没有**：换成另一首热门歌搜一次。热门歌能搜到、这首搜不到，就是这一首的资源问题——**应用只是个入口，它没有的东西，换关键词也搜不出来。**
5. **清一次缓存后重试**，排除本地列表过期。

一个常被忽略的点：不同来源的同名歌曲质量差别很大。**一首歌搜不到，试试搜这个歌手的其他歌，往往能顺着歌手页找到那一张专辑里的这首。**

## 四、点播放没声音

按“从最简单到最麻烦”排：

1. **先看音量**：安卓的音量是分档的——媒体音量和铃声音量不是一回事。按音量键时点开那个齿轮图标，确认调的是**媒体**那一路。
2. **看是不是接了外设**：蓝牙耳机、车机、有线耳机还连着的时候，声音会走到那边去。断开再试。
3. **看是不是免打扰**：下拉快捷设置里如果开了免打扰，部分机型的媒体声音会被压低或静音。
4. **换一首歌试**：只有某一首没声音，是那首资源的问题；全都无声，是设备或权限问题。
5. **强制停止再打开应用**：设置 → 应用 → zpod → 强制停止，然后重开。

## 五、下载卡住、进度不动或者失败

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 进度停在某一格不动 | 应用被系统清理了后台 | 把应用切回前台；去电池设置里把它加进“不受限制 / 不优化”的名单 |
| 批量下载时后面几首一直失败 | 短时间内请求太密集，被限速 | 隔几分钟重试，或改为一次下 5~10 首 |
| 移动数据下几乎下不动 | 流量管控或信号弱 | 换 Wi-Fi，并在系统里确认没有对这个应用单独限速 |
| 提示下载成功但播不出来 | 文件没写完整 | 删掉这首重新下一遍 |
| 每次都失败、从没成功过 | 存储写入权限缺失 | 去应用权限里补上“存储 / 文件与媒体（写入）” |

下载功能对网络稳定性的要求比在线播放高：**在线播放靠缓冲能扛住波动，下载扛不住。** 网络差的时候，先保证能听，再挑网络好的时候批量下载。

## 六、下载好的歌不见了、离线播放没反应

先分清是“列表里没了”还是“列表里有但播不出来”：

- **列表里没了**：多半是换了登录账号，或者歌单同步还没完成。见 [歌单收藏与账号同步.md](歌单收藏与账号同步.md) 的最后一节。
- **列表里有、断网播不出来**：离线文件被清掉了。常见的原因有三个——应用内清缓存时连带清了离线文件、系统清理工具把应用的缓存当垃圾清了、手机存储空间不足时系统自动回收。

对应的预防做法：

1. 清理时看清楚提示，**涉及“清除数据 / 清除存储”的，先确认歌单已同步到账号**。
2. 在系统的“存储 / 手机管家”里把这个应用的缓存排除掉。
3. 始终保持至少 1 GB 空闲存储，空间长期告急的机器，系统会主动回收各类缓存。

顺带说清一个容易被误判成故障的现象：**离线文件在文件管理器里翻不到是正常的**——从 Android 11 起，系统不再允许第三方文件管理器浏览 `Android/data` 这类目录，离线歌曲正躺在里面。要在电脑上查看或把这些文件导出去，做法见 [下载的歌曲导出与备份.md](下载的歌曲导出与备份.md)。

## 七、本地音乐扫描不出来

你自己拷到手机里的歌没有出现在列表里，按顺序查：

1. **权限**：安卓 13 及以上需要“音乐和音频”这一项权限，只给“照片和视频”是不够的。
2. **文件位置**：把音乐放在公共的 `Music` 目录下，别放在以 `.` 开头的隐藏目录里——隐藏目录一般不会被扫描到。
3. **格式**：`MP3`、`FLAC`、`AAC`、`WAV` 这类主流格式支持得好；少见的容器格式（如部分 `WMA`）可能扫不到。
4. **让系统重新扫一次**：用数据线（USB/MTP）拷进来的文件，系统的媒体库有时不会自动感知。重启一次手机是最省事的办法；重启后还看不到再考虑用第三方工具触发重新扫描。
5. **文件名**：去掉文件名里的特殊符号和过长的中文括号串，个别情况下会影响识别。

补两条来自厂商支持文档的说明：应用界面里写的 `/storage/emulated/0`，对应的就是文件管理器里的“内部存储 / 我的手机”根目录，查找时从它的下一级开始；另外，如果连 `Music` 目录都看不到，去文件管理器自己的“设置”里把“显示隐藏文件”和“显示系统隐藏文件”打开。

## 八、后台播放一会儿就断、耗电快

**断播**几乎都是系统的后台管理造成的，而不是应用内开关的问题。最快的两招先用上：

1. **在多任务界面给应用加锁**：打开应用后进入最近任务，把它的卡片下拉（或点锁形图标）加锁。加锁后的卡片不会被“一键清理”清掉——这是各品牌通用、且最快的办法。
2. **再去系统设置里放行后台**。各家叫法和路径不一样，对照下表找：

| 机型 / 系统 | 后台保护的入口（各厂商官方支持页在撰写时的口径） |
| --- | --- |
| 华为 / 荣耀（HarmonyOS 4.x 及以下） | 设置里搜索“应用启动管理”，关掉该应用的自动管理，勾选“允许后台活动”；再搜索“电池优化”，选“所有应用”，把该应用设为“不允许”；设置 → 电池 → 关闭省电模式；设置 → 电池 → 更多电池设置 → 打开“休眠时始终保持网络连接” |
| 华为（HarmonyOS 5 及以上） | 官方给出的可调项变少，主要靠“多任务界面下拉卡片加锁”＋关闭省电模式 |
| realme / OPPO（realme UI 7.0 / 6.0） | 设置 → 电池 → 省电设置 → 应用耗电管理 → 选择应用 → 选“完全允许后台行为” |
| realme UI 5.0 / 4.0 | 设置 → 电池 → 更多设置 → 耗电异常优化 |
| ColorOS 7 及以后 | 设置 → 电池 → 智能耗电保护 |
| 其他机型 | 按同样的思路找四个关键词：应用启动管理 / 电池优化 / 省电模式 / 后台限制 |

各厂商的路径会随系统版本变动，上表帮你定位入口，**以你手机上实际看到的路径为准**。此外，第三方“手机管家 / 清理大师”这类应用也会强杀后台，装了的话先卸载再观察。

**耗电快**的排查顺序则相反，先看自己用了什么档：

| 影响因素 | 影响程度 | 省电做法 |
| --- | --- | --- |
| 音质档位 | 高 | 在线播放降到标准档 |
| 屏幕常亮 / 亮屏看歌词 | 很高 | 锁屏听，别一直亮着看播放页 |
| 长时间处于信号差的网络下 | 较高 | 弱网环境下改用已下载的离线歌 |
| 蓝牙输出 | 中等 | 无法避免，属于设备特性 |

## 九、清缓存和清数据，删的到底是什么

这两个操作长得很像，后果差得远。动手前对着这张表确认：

| 操作 | 会删掉 | 不会删掉 | 什么时候用 |
| --- | --- | --- | --- |
| 清除缓存 | 临时文件、图片缓存，**部分情况下包括离线歌曲** | 歌单、账号登录状态、设置 | 闪退、界面显示异常、列表过期 |
| 清除数据 / 清除存储 | 全部本地数据：歌单、设置、登录状态、离线歌曲 | 账号云端已同步的内容（重新登录后可拉回） | 应用状态彻底异常，且已确认歌单同步过 |

两条硬建议：**清数据之前先登录一次账号并确认歌单已经在云端**；**卸载重装等同于清数据**，别把卸载当成一次普通的“重置”。做完这两步以后如果要从头装一遍，安装包在 [zpod 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bf5368ab3afb)，安装步骤见 [下载与安装教程.md](下载与安装教程.md)。
