## 一、装之前先确认的三件事

zpod 是一款安卓端的音乐播放器：用歌名、歌手或专辑名搜歌，在线播放，也可以把歌曲下载到手机里离线听，同时带歌单、歌词、定时关闭这些常见的播放功能。公开渠道里目前只有安卓版，没见到 Windows 或 macOS 客户端，想在电脑上用要装安卓模拟器。

动手之前，先对着下面这张表确认自己的设备合不合适：

| 项目 | 这一版（2.1.5）的情况 |
| --- | --- |
| 适用设备 | 安卓手机 / 安卓平板 |
| 系统要求 | 这一版标注的是“安卓 5.2 以上” |
| 包名 | ga.vmomov.zpod |
| 版本号 | 2.1.5 |
| 安装包大小 | 55.20 MB |
| 安装包 MD5 | 0AF2B63257112D4365F592F209024DEA |
| 需要联网 | 首次打开、搜索、在线播放需要；已下载的歌曲可以离线播放 |

两点值得先说明：

1. **“安卓 5.2”这个写法值得留意。** 安卓官方并没有对外的 5.2 版本（公开版本是 5.0、5.1，之后直接跳到 6.0）。这句话按“Android 5 系及以上”理解就行，不必为这个数字纠结；真正能不能装，以你手机点下去后的提示为准。
2. **网盘里发出去的那一版，与你在别处看到的线上最新版未必是同一个版本。** 所以判断“我装的对不对”，看的是包名和版本号能不能对上，而不是跟某篇介绍里写的版本号去比。

如果以上都符合，接着走下面的取包与安装。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享，转存到自己的网盘之后下载，比直接从第三方站点点“立即下载”更稳，也不会被下载器中途替换成别的东西。

1. 在手机上打开 [zpod 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bf5368ab3afb)。用手机浏览器或夸克 App 都行，但**建议在夸克 App 里打开**——浏览器里下载大文件容易被打断。
2. 点“保存到我的网盘”，把文件转存到自己账号下。之后再下载就不依赖原分享是否还在。
3. 进入自己的网盘找到这个文件，点下载，等它落到手机的“下载”目录里。
4. 下载完成后**核对两件事**：文件名结尾是不是 `.apk`；大小是不是 55.20 MB 左右。大小差得多的，多半是没下完整或者被换成了别的东西，删掉重下一次。

如果你更习惯在电脑上操作：先在电脑端网盘里把这个文件下载下来，再用数据线（USB）拷到手机的 `Download` 目录，效果一样，之后从手机的“文件管理”里点它安装即可。

## 三、安装：需要放行一次“未知来源”

这个应用不在手机自带的应用商店里，所以安装时系统会拦一下，这是正常现象，不代表文件有问题。

1. 打开手机的“文件管理”，进入 `Download`（下载）目录，找到刚下好的安装包，点它。
2. 系统会弹出“为了安全，你的手机不允许安装来自此来源的应用”之类的提示。点提示里的“设置”，打开**允许安装此来源的应用**开关。
   - 部分机型在“设置 → 应用 → 特殊应用权限 → 安装未知应用”里逐个体检，找到你刚才用来打开文件的那个 App（文件管理或浏览器）再放行。
3. 回到安装界面，点“安装”。等进度条走完，出现“打开 / 完成”。
4. 先点“完成”，不要马上点“打开”——首次启动前先把权限一次性给对，省得进去之后反复弹窗。

安装完成后，桌面或应用列表里会出现 zpod 的图标。

## 四、首次打开要给的权限

打开后会依次弹权限申请。哪些该给、为什么给，对照下表处理：

| 权限 | 用途 | 建议 |
| --- | --- | --- |
| 存储 / 文件与媒体（读取） | 扫描手机里已有的音乐文件，离线播放已下载的歌曲 | 必须给，否则本地歌曲和下载的歌都看不到 |
| 存储 / 文件与媒体（写入） | 把下载的歌曲存到手机、设为铃声时写入铃声文件 | 必须给 |
| 麦克风 | 听歌识曲功能要收音才能识别 | 只在你打算用识曲时给；不用可以先拒绝，之后按需再开 |
| 网络（含 WLAN 状态） | 搜索、在线播放、下载 | 必须给 |
| 修改系统设置 | 部分与铃声、播放相关的系统项需要 | 可以给，也可以先拒绝，功能受限时再开 |

**一个常见坑**：安卓 13 及以上把存储权限拆成了“音乐和音频”“照片和视频”“文件”几类，弹窗里可能只让你勾其中一项。如果你只勾了“照片和视频”，本地音乐就扫不出来——回去把“音乐和音频”也勾上。

## 五、装完先做三步自检

不用急着搜歌，先花一分钟确认这三件事，出了问题也好定位：

1. **能打开、不闪退**：图标点进去能正常进首页。如果反复闪退，看 [常见问题与排查.md](常见问题与排查.md) 里的“打开就闪退”一节。
2. **搜得到、放得出声**：随便搜一个歌手名，能出结果，点进去能出声。这一步同时验证了网络权限和媒体音量。
3. **本地歌曲认得出**：进“本地音乐”或扫描入口，能看到手机里原有的音乐文件。

三步都过，就可以正常用了。接下来你大概会先去找歌——见 [搜索歌曲与离线下载.md](搜索歌曲与离线下载.md)。

## 六、升级与卸载时要注意的

- **升级**：新版本会换一个安装包文件名，覆盖安装不会动你的歌单和已下载歌曲。升级前不必先卸载——直接装新包覆盖即可；**先卸载再装反而会丢掉本地歌单和下载记录**（安卓默认删掉应用私有目录）。
- **卸载**：卸载会清掉应用私有目录里保存的歌单、设置和缓存的歌曲。要换机、要保留歌单，先在应用里登录账号（见 [歌单收藏与账号同步.md](歌单收藏与账号同步.md)），别指望卸载重装后数据还在。
- **找不到安装包了**：任何时候都可以回到 [zpod 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bf5368ab3afb) 重新取一次，转存过的版本不受原分享影响。
