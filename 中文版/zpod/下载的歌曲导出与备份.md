## 一、先说结论：找不到是设计如此

本篇解决一个很具体的问题：把 zpod 下载到手机里的离线歌曲弄出来——导到电脑存档，或者搬到别的设备上听。先讲清为什么按常规路径翻不到，再给三条可行的导出路线，最后说明哪些内容其实不值得导。

你在文件管理器里能翻到的公共目录只有 `Music`、`Download`、`Pictures` 这几个。而 zpod 这类音乐应用的离线歌曲，通常落在**应用自己的目录**里，路径形如 `Android/data/ga.vmomov.zpod/`。

从 **Android 11 开始，系统不再允许第三方文件管理器直接浏览 `Android/data` 和 `Android/obb`**（Android 10 及以前还可以）。所以：

- 你打开文件管理器点进 `Android/data`，看到的是空的、或者提示“无法访问”——**系统在按设计拦截，不是你的手机坏了，也不是歌没下下来。**
- 反过来，判断下载有没有成功，正确做法仍然是断网播一次：能播就是下好了。

下面三节是三条可行的导出路线，按“省事程度”从高到低排。

## 二、动手之前先想清楚值不值得导

导出的成本不低（要连电脑或开调试），所以先按目的分流：

| 你的目的 | 更省事的做法 | 要不要走导出 |
| --- | --- | --- |
| 换新手机继续听 | 登录账号同步歌单，在新手机上重新下载 | **不用导出**，重新下载比搬文件快 |
| 手机存储快满了，想挪到电脑存档 | 走 USB 导出 | 要 |
| 想把这些歌放到别的播放器 / 车机里听 | 走 USB 导出，注意格式 | 要 |
| 只是想知道文件到底下没下下来 | 断网播一次 | 不用导出 |

一句话：**导出只在“文件要离开这个应用生态”时才必要。** 如果只是换设备继续用同一个应用，直接重新下载更省事。

## 三、方法一：USB 连电脑（最稳）

1. 用支持数据传输的 USB 线把手机连到电脑（只能充电的线不行）。
2. 手机下拉通知栏，把 USB 用途从“仅充电”改成**“文件传输 / MTP”**。
3. 电脑上打开手机存储，依次进入 `内部存储` → `Android` → `data`。
4. 找到以包名命名的文件夹 `ga.vmomov.zpod`，把里面需要的文件**先复制到电脑**。
5. 复制完成后，再在电脑上整理、重命名。

两个容易卡住的点：

- **电脑上看不到 `Android/data`**：先把手机屏幕解锁（锁屏状态下部分目录不显示），再把 USB 模式切回“仅充电”后重新选“文件传输”；还不行就换线、换 USB 口。
- **读得出、写不回**：从电脑往 `Android/data` 里写文件，很多机型会直接拒绝。**所以顺序永远是“先复制出来”，别指望原地改。**

## 四、方法二：手机上用系统文件选择器

不想连电脑时，可以借系统的文件选择器单独授权一个文件夹：

1. 打开任意一个提供“选择文件夹”功能的应用（备份类、笔记类应用常见此入口）。
2. 在弹出的系统选择器里，从侧栏切到**内部存储**。
3. 依次进入 `Android` → `data` → `ga.vmomov.zpod`。
4. 点“使用此文件夹 / 允许”，完成对这一层的授权，然后在这个应用里对文件进行操作。

这条路的成功率取决于机型：部分系统直接禁掉了对受限目录的授权，点“使用此文件夹”是灰的。遇到这种情况就回到方法一。

## 五、方法三：ADB（进阶，但最不受限制）

电脑上用 ADB 可以把整目录拉下来，适合文件多、要整批备份的场景。前提是手机已开启“开发者选项”里的 **USB 调试**。

```bash
# 确认电脑已识别到设备
adb devices

# 把该应用的整个目录拉到电脑当前目录下
adb pull /sdcard/Android/data/ga.vmomov.zpod ./zpod-backup
```

说明两点：ADB 对 `Android/data` 的**读取**一般能成功，**写入**（`adb push`）在多数机型上会被拒绝，所以它同样是“拿去备份”的工具；另外，官方的 Android Studio「Device Explorer」也能浏览设备文件、把文件同步到电脑，但它同样要求开启 USB 调试，且不可调试的应用目录依然打不开。

## 六、导出失败时的两条退路

| 卡在哪 | 原因 | 怎么办 |
| --- | --- | --- |
| 电脑里根本看不到 `data` 目录 | USB 模式没切、手机锁屏、线材不支持 | 逐项排除；仍不行改用 ADB（第五节） |
| 能读不能写 | 系统限制向别的应用目录写入 | 改成“只导出”，不要试图写回 |
| 导出的文件在别的播放器里不认 | 编码或容器不兼容 | 在电脑上转成通用格式（如 `MP3`）再用 |
| 应用本身已经打不开，连导出都没法做 | 应用异常 | 先把安装包换成完整的一份覆盖安装（**不要先卸载**，卸载会清掉私有目录），再重试；安装包在 [zpod 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bf5368ab3afb) |

还有一条常被忽略的退路：**导出这一步本身不是必须的。** 已经在线听得到的歌，换台设备重新下一遍就行；把精力花在“让歌单不丢”（登录账号）比花在“把文件搬来搬去”回报高得多。

## 七、哪些东西真的值得备份

按“丢了有多心疼”排个序，你大概会得出跟下面一样的结论：

| 内容 | 丢了能恢复吗 | 备份方式 | 值不值得专门导 |
| --- | --- | --- | --- |
| 自建歌单、收藏 | 登录账号后可从云端拉回 | 登录账号 + 截图留底 | 值得（成本极低） |
| 播放历史 | 登录后跟着账号走 | 无需额外操作 | 顺带 |
| 离线歌曲文件 | 重新下载即可 | USB / ADB 导出 | 只有在“要挪到别的播放器”时才值得 |
| 应用内的显示设置 | 重设一遍即可 | 无 | 不值得 |

最后提醒一句：导出的音频文件请只用于你自己的设备与个人收听。需要重装或换机时，安装包始终可以从 [zpod 安装文件资源（夸克网盘）](https://pan.quark.cn/s/bf5368ab3afb) 取到同一份，不必从别处找来源不明的包。
