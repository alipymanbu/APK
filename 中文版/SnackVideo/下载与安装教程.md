## 一、安装前先弄清三件事

SnackVideo 是快手（Kuaishou Technology）旗下面向海外市场的短视频应用，开发者主体为 Joyo Technology Pte. Ltd.，主要服务巴基斯坦、印度尼西亚等南亚与东南亚地区的用户。它只提供安卓版安装包，没有官方 PC 版；如果你在手机应用商店里搜不到它，用 APK 安装包手动安装是最直接的办法。

本文以网盘里这一版为例，它的基本信息如下（版本/包名/大小以此为准，应用商店里的最新版编号可能更高，属于正常现象）：

## 二、把安装包拿到手机上

1. 把上面的网盘链接复制到手机浏览器地址栏打开（或先用电脑打开、转存到自己网盘后再用手机取）。
2. 网盘页面里选择 SnackVideo 那个文件夹，把 `SnackVideo_v13.3.30.544507.apk` 下载到手机存储。
3. 下载完成后，文件通常在手机「文件管理」的 Download（下载）目录里。部分浏览器会弹出「此类文件可能有害」的提示，这是对 APK 的常规提醒，确认来源是自己主动保存的即可继续。

如果你习惯先在电脑上操作，也可以在电脑端转存、下载，再用数据线或局域网传输把 APK 传到手机——效果一样，APK 本身不区分传输方式。

## 三、安装步骤

安卓默认不允许安装应用商店之外的程序，所以第一次装会要求你先放开「未知来源」权限：

| 手机品牌 | 设置路径（大致） |
| --- | --- |
| 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全与隐私 → 更多设置 → 安装未知应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 允许安装未知应用 |
| 三星 | 设置 → 生物识别和安全性 → 安装未知应用 |
| 原生安卓 / 其他 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

然后按这个顺序操作：

1. 在「文件管理」里点开刚才下载的 `SnackVideo_v13.3.30.544507.apk`。
2. 系统询问「是否允许此应用安装」时，选「设置」→ 打开「允许来自此来源的应用」→ 返回。
3. 点「安装」，等进度条走完。
4. 提示「应用已安装」后点「打开」，也可以回桌面从图标进入。

注意，第 2 步授权的是「文件管理器」这个来源，不是给 SnackVideo 本身授权；以后装别的 APK 一般不用再设置。装完如果担心权限开着不放心，可以在同一个设置页里把它关回去。

## 四、首次启动要做的事

第一次打开 SnackVideo，通常会连续碰到这几步：

1. **选语言**：界面支持多种语言，选你习惯的即可；界面语言和应用内容是两回事，内容推荐以你的互动为准。
2. **权限申请**：应用会依次请求存储（保存视频、缓存）、相机与麦克风（拍摄用）、通知（接收互动提醒）。想先随便看看的话，权限可以逐项拒绝或选「仅在使用中允许」，用到拍摄再补授权也一样。
3. **挑感兴趣的内容**：开屏会让你勾选喜欢的题材（搞笑、影视、体育等），勾选只影响初始推荐，后面随时可以通过「不感兴趣」来纠正。

到这里安装就算完成了。接下来注册账号可以看 [注册登录方法.md](注册登录方法.md)；如果不想用流量刷视频，先去 [省流量与离线观看设置.md](省流量与离线观看设置.md) 把省流选项打开。

## 五、装不上或装完打不开

常见原因按出现频率排：安装包没下完整（对一下上面表格里的 MD5）、存储空间不足、系统版本低于 5.2、旧版本残留未卸载干净。对应的处理办法在 [打不开与加载失败排查.md](打不开与加载失败排查.md) 里有完整清单，那里也附了重装时取安装包的入口。
