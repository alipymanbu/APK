## 一、先分清症状，再动手

同一个「用不了」，原因差很远。先对号入座：

| 症状 | 大概率原因 | 直接跳到 |
| --- | --- | --- |
| 点图标没反应 / 开屏卡死 | 版本过旧、存储不足、系统兼容 | 第二节 |
| 能打开但视频一直转圈 | 网络不通、省流限制过紧 | 第三节 |
| 用着用着闪退 | 缓存损坏、内存紧张 | 第四节 |
| 登录时报错 | 验证码/授权问题 | 第五节（详见注册登录篇） |

## 二、应用打不开

按顺序试，一般前两步就能解决大半：

1. **彻底关掉再开**：从最近任务里划掉应用（不是返回桌面），再点图标。后台残留的卡死进程是「点了没反应」最常见的原因。
2. **重启手机**：一句话的老办法，解决临时性的系统资源问题，尤其是长时间没重启过的设备。
3. **查存储**：到系统设置看剩余空间，低于 1GB 时大应用经常起不来。清掉相册大视频与不用的应用再试。
4. **确认系统版本**：Android 5.2 以下的系统跑不动现在这版应用，系统设置 → 关于手机里能看到安卓版本。
5. **重装**：以上都无效时再走重装，见第六节。

## 三、视频加载不出来（一直转圈）

1. **先确认不是网络问题**：随便开个网页或别的应用试试。别的也加载不动，就是网络本身的问题，重启路由器或切换 Wi-Fi/移动数据。
2. **检查省流设置**：如果你按 [省流量与离线观看设置.md](省流量与离线观看设置.md) 开过省流或禁了后台流量，限制过紧会挡住正常加载。把该应用的后台数据限制临时放开试一次，立刻见效的话把阈值调松一档。
3. **关掉代理/加速类工具**：走代理或加速器的连接常被内容平台拒绝，表现为永远转圈。关掉再试。
4. **应用内刷新**：下拉刷新推荐流，或在设置里清缓存（见第四节），清完回首页重新加载。

## 四、闪退与卡顿

1. **清应用缓存**：设置 → 应用 → SnackVideo → 存储 →「清除缓存」。注意是「清除缓存」不是「清除数据」——后者会把你没发布的草稿和登录状态一起抹掉，除非准备重装，否则别点。
2. **给系统减负**：同时开的应用太多时，低端机型容易把短视频应用挤掉。清一下后台再进。
3. **更新应用**：能联网打开应用商店的话，搜一下有没有新版本；没有商店渠道的，用安装包重装到新版本也能达到同样效果。

## 五、登录相关报错

验证码收不到、Google/Facebook 授权失败这类问题，具体对策已经写在 [注册登录方法.md](注册登录方法.md) 的第四、五节，那里有区号、拦截短信、换注册方式三条路线，此处不重复。

## 六、重装：最后的办法

重装能解决「应用文件本身损坏」这一类问题，代价是本地草稿与登录状态清零（发布过的作品在云端，不受影响）。顺序：

1. 系统设置里卸载 SnackVideo。
2. 重启一次手机（跳过这步偶尔会遇到重装后同样的问题）。
3. 重新取安装包并安装：**SnackVideo 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/1e5268106c77](https://pan.quark.cn/s/1e5268106c77)，安装步骤与首次启动事项见 [下载与安装教程.md](下载与安装教程.md)。
4. 用原方式重新登录，方法在 [注册登录方法.md](注册登录方法.md)。

如果重装后问题依旧，且别的网络环境下也一样，那就是该版本与你机型的兼容问题，只能等下一个版本，或先用应用内（如果还打得开）的反馈入口上报。
