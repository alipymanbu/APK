## 一、先分清两类效果

Voloco 的效果器（FX）绝大多数落在两类里，选之前先想清楚要哪种声音：

- **修音（Pitch Correction）**：检测你唱出的音高，把它拉到当前 Key & Scale 里最近的音上。Hard Tune 是典型的「数码修音」声；Natural Tune 更含蓄；Modern Rap、P-Tain、Jazz 这些主题包也都基于它。
- **声码器（Vocoder）**：把你声音的特征「喂」给一个合成器音色，出来的是机器人感。Super Vocoder 是免费预设里的代表。

大多数效果都依赖项目的 Key & Scale 设置 —— 修音往哪些音上拉、和声按哪些音叠，全由它决定。

## 二、免费五件套怎么选

Starter 包不订阅也能全用，选法如下：

| 效果 | 听感 | 什么时候用 |
| --- | --- | --- |
| Hard Tune | 明显的电子修音感，现代说唱与流行里最常见的那种 | 就要「听得出来的修音」 |
| Natural Tune | 同样是修音，动作更轻、音色更圆润 | 想修音但不想太机械：流行、R&B、抒情歌 |
| Super Vocoder | 机器人声 | 电子乐、创意段落 |
| Big Chorus | 把你的声音按 Key & Scale 复制成多个音，形成宽厚的大合唱 | 副歌要大场面，又不想录多轨 |
| Clean | 不修音、不加工，只做滤波降噪 | 环境吵，或只想保留原声 |

拿不定主意就先录 30 秒，把这 5 个挨个套一遍听差别 —— 效果随时能换，不用重录（见第四节）。

## 三、Key & Scale：修音准不准的关键

- 加载伴奏后 Voloco 会自动检测调性并设好 Key & Scale，多数情况不用手动管；
- 要改的话：打开项目，点右上角「音谱号 + 齿轮」图标，在 Project Settings 里选 Key 和 Scale；
- 这组设置只影响人声的自动修音与和声，不会改动伴奏本身；
- 修音听着「跑调」或与伴奏打架，先回这里查设置，再排查别的。

更深的理论解释（调式、音阶与各参数原理）官方有一份用户手册 PDF：[resonantcavity.com/assets/docs/voloco-user-manual.pdf](https://resonantcavity.com/assets/docs/voloco-user-manual.pdf)，[帮助中心首页](https://help.voloco.com/hc/en-us)也能找到入口。

## 四、录完之后还能换效果

录完不是定死的：进 Edit View，点选一段人声 → FX & Volume → 换任意效果，新效果只作用于选中的那段。整段录音能随时重听不同预设，也可以把某段的效果 Bypass 掉做 A/B 对比。所以第一阶段放心试，选错代价很低。

## 五、Premium 效果包一览

订阅后解锁的是按风格组织的主题包（包内预设名进应用试听最直观）：

| 包 | 方向 |
| --- | --- |
| Modern Rap I / II | 说唱与陷阱：多声部、低八度衬底、轻失真 |
| P-Tain | 极限修音 + 七和弦，R&B / 说唱 |
| Jazz | 爵士和声，柔软的七和弦堆叠 |
| Talkbox | 经典电放克的 talkbox 声 |
| Spooky / LOL | 实验向：诡异系与搞笑系 |
| Sitar Hero / 8 Bit Chip / Wormhole / Bon Hiver / Duft Pank | 印度古典、8-bit 游戏机、异星声码器、氛围和声、法式电子 |

订阅本身包含哪些权益、值不值，见[免费与会员功能对比](免费与会员功能对比.md)。

## 六、修完音再挂的四件套

FX 之外还有 Compressor、EQ、Echo、Reverb 四个通道条工具，免费版各带一组「拿来就用」的预设：

- **Compressor**：Rap 让人声更冲、Pop 均衡亮泽、Moderate 最百搭、Parallel 压了但保留动态、Blasted 火力全开（吵的段落慎用）；
- **EQ**：Mid-range Scoop 挖中频、Brightness 提亮、Vocal Clarity 提清晰度、Telephone 电话感；
- **Echo**：8th Note Bounce 的八分音符回弹是说唱里最常见的用法，Right to Left / Slinky 偏氛围；
- **Reverb**：按空间大小挑 —— Medium Room 最日常，Small Club / Large Hall / Cathedral 依次更大更空。

每个预设都是定值；要拧参数（Attack / Release、频段、干湿比这类）需要订阅 Premium。把调好的组合存成自己的预设（自定义预设）同样是 Premium 能力：入口在效果面板顶部的 Preset 按钮 → Save As。

## 七、常见的两个坑

- **修音效果打架**：多数修音和和声效果跟着 Key & Scale 走，换了伴奏没换设置就会「跑到别的调上去」；先回第三节的位置核对调性。
- **Clean 录出来还是吵**：Clean 只是滤波降噪，不隔噪音 —— 麦克风收进来的底噪它救不干净，安静环境比任何预设都管用。
