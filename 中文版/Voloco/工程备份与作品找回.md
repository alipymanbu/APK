## 一、先知道坏消息：工程默认只在本机

Voloco 的工程文件保存在设备本机的应用数据里，不带自动上云。官方帮助中心对几种常见场景的口径是一致的：

- **卸载重装**：工程随应用数据一起删除，**删了就是没了**，官方无法从后台帮你找回；
- **换新手机**：新设备上登录同一个账号，旧工程的库也是空的，原因同上；
- **系统自带的整机备份**：救不回 Voloco 工程 —— 官方明确说项目无法通过设备备份恢复。

所以「重要的东西别只存应用里」这条在这里格外硬。云端备份（9.13 版起提供）就是官方给的正解，见下一节；还没开备份的话，先把已有作品导出一份音频（见第五节）。

## 二、云端备份怎么开

云备份功能在 9.13 版引入，订阅门槛如下：

| 订阅状态 | 云备份容量 |
| --- | --- |
| 无订阅 | 无（可单独购买 Project Backup 附加订阅） |
| Voloco Premium | 20 个工程 |
| Project Backup 附加订阅 | 1000 个工程 |

开启与设置路径：**Settings → Projects → Auto Backup** 打开开关；**Backup on Cellular** 是「用流量也备份」，默认关闭省流量。打开后备份在应用打开和后台时自动跑，最近改动的工程优先；**录音过程中不会跑备份**，不会打断你录。

各订阅档位包含什么，对照[免费与会员功能对比](免费与会员功能对比.md)的功能表看更快。

## 三、备份覆盖什么、不覆盖什么

- **覆盖**：Projects（完整工程）—— 人声轨与伴奏轨、已挂的效果、工程设置、封面都在内；
- **不覆盖**：Quick Recordings（快录）和视频。这两类不进云端备份，想保住它们只能导出成文件自己存（第五节）。

每个工程在库里会显示云端状态图标：云+对勾 = 当前版本已备份；云+斜杠 = 还没备份过；云+感叹号 = 备份或恢复出错。

## 四、配额满了会怎样

20 个（或 1000 个）位子用满后：

- 已备份的工程照常安全可恢复；
- 新工程**不再自动备份**；
- 想继续备新的：删掉一些旧备份，或升级订阅档位。

手动备份走 Library 里工程旁的「⋮」菜单 → **Back up project**，手动操作优先于自动备份。当前用量在 Settings → Projects → Backups Used 里看；配额是**跨设备共享**的。

## 五、恢复与三层兜底

**从云端恢复：**

- 恢复单个：Library → 工程旁「⋮」→ **Restore backup**。注意恢复会用云端版本**覆盖**设备上的本地版本，恢复前确认云端那份是你要的；
- 全部恢复：Settings → **Restore your backups**，所有云端工程排队逐个恢复，同样存在覆盖。

**没有备份时的三层兜底（也是日常最稳的习惯）：**

1. **发布到 Voloco 主页**：Publish 之后成品曲目挂在你自己的主页上，换设备登录还能回听 —— 注意这只是保存成品，不是可编辑的工程，而且发布不等于把文件存到手机里；
2. **导出音频文件**：Library → 工程旁「⋮」→ **Download as Audio**，选存储位置。默认出 MP3；要 WAV 得开 Premium 后在工程的 Project Settings → App Audio Settings → **Export WAV files** 打开，之后导出的曲目都是 WAV。导出的文件再转存一份到 Google Drive / iCloud / Dropbox 这类云端网盘；
3. **从官网下载已发布的曲目**：在 [voloco.com](https://voloco.com/) 右上角 Sign In 登录 → 左侧 **Tracks** → 曲目旁「⋮」→ Download。工程不在本地库里了，只要发布过，从网页还能拿回音频。

- 想把作品发去别的平台，分享的两种方式（15 秒切片 / 整轨视频）见[节拍导入与多轨录音流程](节拍导入与多轨录音流程.md)第五节；
