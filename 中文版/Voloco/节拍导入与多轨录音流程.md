## 一、伴奏的三个来源

1. **应用内 BeatStars 曲库**：新建项目 → Add Beat → 按流派 / BPM / 调性浏览试听，选中后伴奏直接进工程，Voloco 会自动检测它的调性并把修音的 Key & Scale 一并设好；
2. **导入自己做好的伴奏**：Add Beat → Import，支持 WAV / MP3；免费版每天限 1 次（限额详见[免费与会员功能对比](免费与会员功能对比.md)）；
3. **在别的应用里做 beat 再带进来**：比如用 GarageBand、FL Studio Mobile 做完导出成音频文件，再走第 2 条导入。

曲库里的 beat 可以在应用内直接授权使用，不用跳出应用去找伴奏文件。

### 用曲库的 beat 发出去要注意什么

beat 归上传它的制作人所有，官方的口径分两档：

- **在 Voloco 里录、发到社交平台**：一般没问题 —— 官方说制作人对作品发社媒通常不介意；
- **上能产生收益的平台**（YouTube、Spotify、iTunes 等）：需要向制作人**购买 beat 授权**，这条绕不开。

购买有两条路：播放界面上方有 **Buy License** 按钮的，点它跳到 beat 市场按条款购买；没有按钮的，点制作人名字进主页，通过主页留的社交渠道直接联系。另外，发布到 Voloco 社区本身不能变现（官方明确说不行），要变现就是把成品曲拿到 YouTube、Spotify 这类平台上，而这正好触发上一条的授权要求 —— 两个事实连起来看，打算正经发歌的人买 license 是必须的。人声本身（你自己录的部分）官方允许任意用途，包括商业用途。

## 二、从空项目到录完第一轨

1. 新建项目，加载伴奏（上面三种来源任选）；
2. 选效果：说唱选 Hard Tune 或 Modern Rap 系，R&B 旋律向选 Natural Tune 或 P-Tain；每个预设的听感差别见[效果器与调音预设怎么选](效果器与调音预设怎么选.md)；
3. 插上有线耳机（外放会让伴奏漏进麦克风），检查输入电平不出爆音；
4. 录 lead vocal（主轨）；
5. 有不稳的小节就设一个 Loop Zone 循环窗口，反复过那一小节直到录稳，不用整段重来。

## 三、叠第二轨开始的多轨玩法

免费版每个项目只有 1 层人声；Premium 能到 8 层。到了多轨，官方帮助中心给的三件套配置是常见的起步结构：

- **lead**：主轨，挂最干净的效果；
- **double**：同旋律再录一遍的双轨，厚度来源，可以挂更重的效果；
- **ad-lib**：语气词与即兴填充单独一层，随便挂夸张效果。

每层可以分别设置效果：点选那一轨的人声段 → FX & Volume 单独调；同一层里的所有段落也能用「Edit All」一次套同一个自定义预设。改主轨的效果不会影响其他层。

## 四、不用乐器也能补的料

- **Lyrics Pad**：歌词贴进去对着唱；自动生成歌词免费版每天 5 次，手打不受限；
- **人声分离**：把任何一首歌或视频拆成人声 + 伴奏两条轨，拆出来的伴奏直接当 beat 用；
- **视频录制**：新建时选 Video，摄像头与修好音的人声同时录，中途可以切前后摄像头，导出即是能直接发抖音 / Instagram / YouTube 的成片，不需要后期对轨。

## 五、导出与备份

导出音频的具体操作：Library 里工程旁「⋮」→ **Download as Audio** → 选存储位置。配套细节：

- **MP3**：默认导出格式，免费版就能用，发社交平台够用；
- **WAV 无损**：Premium 专属。开关在工程的 **Project Settings → App Audio Settings → Export WAV files**，打开后所有导出都变 WAV；要交给电脑上的 Logic Pro / Pro Tools / FL Studio 继续混音，用这个格式；
- **分轨导出**：人声一条轨、伴奏一条轨分开导，进 DAW 自己再平衡；
- **Auto Master**（Premium）：一键母带，30 个预设按响度 / 声场宽度 / 频段组织。

发社交平台有两条路：一是分享已发布曲目的 **15 秒切片**（9.4 版起，主页曲目旁「⋮」→ Share，Clip Editor 里框选片段，可直接分享或下载后手动传）；二是对整个工程用「⋮」→ **Download as Video** 导出成视频再上传。

备份别指望应用本身：工程只存本机，卸载或换机就没了。云端备份（9.13 版起，Premium 20 份 / 附加订阅 1000 份 / 免费无）、恢复方法与三层兜底，见[工程备份与作品找回](工程备份与作品找回.md)。
