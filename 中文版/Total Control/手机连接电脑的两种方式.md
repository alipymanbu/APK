# 手机连接电脑的两种方式

> USB 与 TCP（局域网）两条连接路线的完整步骤，以及多台手机批量连时的 Easy Connect 用法。

## 一、两条路线怎么选

| 方式 | 适合场景 | 硬性前提 |
| --- | --- | --- |
| USB | 首次连接、长期固定工位、多台设备批量连接 | 数据线 + 手机已开 USB 调试 |
| TCP（IP 连接） | 桌面想清爽、手机可以放旁边 | 手机与电脑**同一局域网**；首次必须先用 USB 连过一次 |

关键规则只有一条：**每一台手机的第一次连接（或手机重启后）都必须先走 USB**，成功之后才能拔线改用 TCP。没做过 USB 首连就直接上 TCP，是连不上的最常见原因。

## 二、USB 连接步骤

1. 手机打开「开发者选项」→「USB 调试」（没开的话按 [下载与安装教程.md](下载与安装教程.md) 第五节操作）。
2. 数据线连手机与电脑（优先机箱后置 USB 口）。
3. 手机弹出「允许 USB 调试吗？」的授权框 → 勾选「始终允许」→ 确定。**这一步不点，后面全卡住**。
4. PC 端连接页识别到机型后，自动推送安装手机端 APK；手机若弹安装确认，手动点安装。
5. 出现连接按钮后点连接，画面进窗口即可。

## 三、TCP 连接的两种打开方式

USB 首连成功、拔线之后，手机和电脑连同一个 WiFi（或同一网线网段），二选一：

**扫码连接**
1. PC 端打开「连接帮助」，选 **TCP**，界面给出一个二维码。
2. 手机上打开 Total Control 应用，点 **Scan（扫一扫）**，扫电脑上的码。

**手动输 IP**
1. 手机端 Total Control 会显示本机 IP 地址。
2. PC 端「连接帮助」→ TCP → 输入 IP；手机端设过密码的话把密码也填上（没设就留空），点确定。

> 如果在设置里开启了密码认证，走 TCP 时只需输密码，**手机上不再弹确认框** —— 批量连接时这一点能省掉逐台点确认的麻烦。

## 四、多台手机：用 Easy Connect 批量连

需要同时用 TCP 连多台设备时，官方推荐 Easy Connect（支持 ATA / ATS 两种模式）：

1. **准备**：每台设备先用 USB 连过一次并断开（ATA 模式）；或在设备上装 TC ATS 应用并授予无障碍权限（ATS 模式）。
2. 所有手机与电脑在同一网络。
3. 在手机端 Total Control「设置」里给设备**设同一个密码** —— 后面按密码批量筛。
4. PC 端「连接助手」→ **Easy Connect** → 输入那个密码，列表会列出所有同密码的设备（已连的置灰）。
5. 勾选要连的设备 → 点「Connect」，一次全连上。

## 五、连安卓模拟器

除了真机，官方从 10.0 (Update 31) 起支持连安卓模拟器，目前明确支持三款：**雷电模拟器（LDPlayer）、BlueStacks、MuMu 模拟器**。模拟器相当于一台虚拟安卓，走的还是同一条连接链路；具体开法官方有专门的设置说明页，按机型指引操作即可。真机上的 adb 冲突规则对模拟器同样适用 —— 电脑上同时装着多款模拟器时，先只留一款在跑。

## 六、连接相关的两个小工具

- **TC Connect**：装在电脑上的小工具，作用是批量准备 —— 连上设备后快速装好手机端、拿到 shell 权限，还能给多台设备**批量设密码**，这样走 TCP 时就不用逐台在手机上点确认。
- **ATS 模式**：手机端一个可选的连接方式，只要给无障碍权限就能连，**不需要开开发者选项和 USB 调试**；代价是它脱离 Total Control 独立跑脚本的玩法和普通模式不同，普通用户先按上面 USB / TCP 走即可。

## 七、连上之后先确认这几件事

- 画面进了窗口、鼠标能点、键盘能打字 → 连接正常。
- 只有串号没有机型名，通常是驱动没到位；一直转圈或报错，见 [连不上手机的排查方法.md](连不上手机的排查方法.md)。
- 想让以后插上就自动连，PC 端设备设置里有 **USB 自动连接** 与 **TCP 自动连接** 两个开关，打开后省掉每次手动点连接。

日常怎么操作手机画面、怎么传文件，见 [电脑上操作手机的日常用法.md](电脑上操作手机的日常用法.md)。
