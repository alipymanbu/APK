## 一、这套软件由两部分组成，别只装一半

Total Control 是「电脑端 + 手机端」配对使用的工具：你在电脑上操作，手机屏幕显示在电脑窗口里，鼠标键盘直接点按手机。你只在手机上装一个 APK 是跑不起来的，两端都到位才能连上。

| 部分 | 装在哪 | 作用 |
| --- | --- | --- |
| Total Control 客户端（PC 端） | Windows 电脑 | 主程序：显示手机画面、接收键鼠操作、跑脚本 |
| Total Control（手机端 APK） | Android 手机 / 平板 | 被控端：负责推画面、接收指令 |

一个省事的细节：**PC 端装好后，手机端不用单独找** —— 手机第一次用 USB 连上时，PC 端会自动把配套的手机端 APK 推送安装到手机上。所以最短路径是：先装 PC 端 → 连手机 → 让它自己装。

## 二、电脑和手机要满足什么条件

以下要求摘自官方 FAQ 与官网说明，**以官方页面当时显示为准**：

| 项目 | 要求 |
| --- | --- |
| 电脑系统 | Windows XP / 7 / 8 / 10（32 位与 64 位均支持） |
| 手机系统 | Android 6.x ~ 16；不支持 iOS、Windows Phone |
| 手机性能 | 建议 CPU 1GHz 以上、内存 1GB 以上 |
| Root 权限 | 不需要 Root，Root 过的手机也能正常用 |
| 连接线 | 尽量用手机原装数据线；单个 USB 口供电建议 1A 以上 |

多开设备时电脑配置要跟着涨（官方口径：普通家用 / 办公电脑接 4 台以内没问题；接 10 台建议 i3 以上、30 台 i5 以上、50 台 i7 以上，内存 8G 起、支持 USB 3.0）。官方还特别提醒：**这个软件吃 CPU 主频而不是线程数**，Intel E 系列至强类处理器不合适，选 Intel i 系列更稳。

## 三、安装顺序

1. **装 PC 端**：到 Total Control 中文官网的下载页拿 Windows 客户端安装包（[www.sigma-rt.com.cn/tc/download/](https://www.sigma-rt.com.cn/tc/download/)），按向导装完。官网当前标注的版本号与更新内容，以下载页当时显示为准。
2. **手机打开 USB 调试**（见下一节），用数据线连电脑。
3. 首次连接时，PC 端会向手机推送安装手机端 APK；手机上若弹出安装确认，**手动点一次安装**（下面第五节的坑就在这）。
4. 连接按钮出现后点连接，手机画面出现在电脑窗口里，就算装好了。

驱动问题一般不用你操心：Windows 10 能识别大多数机型；Windows 7 若认不出手机，PC 端安装目录里带了通用 adb 驱动（`C:\Program Files\Sigma-RT\Total Control\driver\universal_adb_driver`，路径以你实际安装位置为准），装不上再考虑去手机厂商官网下驱动。

## 五、第一次连接前必开的开关

1. 手机「设置」→「关于手机」→ 找到「版本号」，连点 5~7 次，直到提示已进入开发者模式。
2. 返回「设置」，进入「开发者选项」，打开 **USB 调试**。
3. 小米 / Redmi / vivo 机型还要额外打开 **USB 安装** 与 **USB 调试（安全设置）**，否则电脑能看画面却点不动。
4. USB 插法有讲究：优先插**机箱后面**的 USB 口（前置口供电弱），用集线器就选带独立电源的。

开关打开后怎么把手机真正连上，见 [手机连接电脑的两种方式.md](手机连接电脑的两种方式.md)；连不上先翻 [连不上手机的排查方法.md](连不上手机的排查方法.md)。
