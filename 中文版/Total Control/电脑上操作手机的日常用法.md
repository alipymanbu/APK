## 一、鼠标键盘直接上手

手机画面出现在电脑窗口后，你不需要再碰手机：

- **鼠标左键** = 点按屏幕；**拖拽** = 翻页滑动；
- **鼠标滚轮** = 上下滑动屏幕；
- **鼠标右键** = 模拟双指缩放（图片、地图开合用这个）；
- **电脑键盘** = 直接往手机输入框里打字，中文也能输（走 Sigma 输入法）；
- **Esc 键** = 手机的「返回」；
- 全屏模式下菜单收起时，点屏幕左缘的箭头能把菜单叫回来。

手机的物理键（音量、Home 等）在窗口里也有对应按钮；「短键映射」还能把键盘按键绑到指定应用、脚本或文件管理路径上，做重复操作时省鼠标。

## 二、设备窗口菜单里都有什么

点手机窗口上的三条横线，弹出的菜单按用途分四类：

| 类别 | 菜单项 | 说明 |
| --- | --- | --- |
| 画面采集 | 截图到 PC / 截图到设备 / 录制视频 / 捕捉 PC 画面 | 后面第四个能把电脑屏幕裁一块存进手机 |
| 视图 | 放大、缩小、最大高度、左转、右转、全屏 | 横竖屏自动识别不灵时手动转 |
| 数据 | 备份与恢复、文件管理、暂停画面 | 暂停后画面冻结，点「>」跳到最新帧 |
| 系统 | 设备设置、更换键盘、Runner | Runner 是跑脚本的入口 |

截图和录像的保存路径在「设置 → 截图 / 录像保存路径」里改，**建议开工前先设成你找得到的目录**，不然默认路径翻起来费劲。

## 三、文件在电脑和手机之间怎么倒

- **电脑 → 手机**：从 Windows 资源管理器把文件直接**拖进手机窗口**，存到 `/sdcard/Total Control/files`；**拖的是 APK 就自动安装**（手机有外置 SD 卡时会问你装到哪）。
- **手机 → 电脑**：打开窗口菜单里的「文件管理」，进到目标路径，把文件往外拖即可。
- **截图类**：菜单里的「捕捉 PC」把电脑屏幕裁一块存到手机 `/sdcard/Total Control/screenshots`；反向的「分享」链路是手机上选中图片 → 系统分享 → 选 Total Control，图就进剪贴板或文件。

## 四、剪贴板与复制粘贴

前提是要装 Sigma 输入法（装了它才能在两端之间剪贴板互通）：

- 电脑上 `Ctrl+C` 复制的文本，到手机窗口的输入框里 `Ctrl+V` 粘贴；要图省事可在系统设置里打开 **「直接粘贴到设备」**（不勾的话容易误粘贴）。
- 手机里选中文字后窗口会冒出一个小图标，点它把文本送进 Windows 剪贴板；每次都点太烦，就开 **「剪贴板自动同步到 PC」**。

## 五、画面卡、延迟高怎么调

画面流畅度和「画质设置」直接挂钩，按这个顺序降级：

1. 设备设置 → **画质 / 模式**：先降画质档位，牺牲清晰度换帧率；
2. 设备设置 → **分辨率**：把投屏分辨率调低，CPU 和带宽立刻轻下来；
3. 检查是不是网络问题：TCP 连接时有丢包必然延迟，改用 USB 直连对比一下；
4. 官方 FAQ 的口径是**电脑端开「加速」相关选项**（设备加速 / PC 加速）来改善流畅度，具体档位以你机器上的实际表现为准。

另外，「设置」里还有几个值得一开的开关：**老板键**（一键隐藏窗口）、**设备自动休眠**（不用时让手机自己熄屏省电）、**开机自动启动**、**连接时显示**。设备名想改，在设备设置里改，不影响连接。
