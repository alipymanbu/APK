# 精简版和专业版的区别

> 两版在设备数上限、多控中心、脚本能力上的实际差异，激活码怎么用，换电脑时许可怎么迁。

## 一、你装上就是精简版

PC 端装好默认是精简版（Lite），不花钱就能用核心链路：连接设备、键鼠控制、截图录像、文件与剪贴板传输。升级到专业版是在**客户端内**完成的，不在网页上单独买。

## 二、两版差异一览

| 能力 | 精简版 | 专业版 |
| --- | --- | --- |
| 同时连接设备数 | 官网首页写 1~2 台；官方 FAQ 写普通版最多 4 台 —— 两处口径不一致，**以官方页面当时显示为准** | 按购买档位 10 / 20 / 30 / 50 台，官网首页另标「最多 100 台」，同样以页面显示为准 |
| 用途限制 | 非商业用途免费 | 商业 / 多机场景 |
| Windows 桌面模式（WDM，一窗一机） | 支持 | 支持 |
| 多控中心（MDCC，一块大屏管多机同步） | 不支持 | 支持 |
| 捕捉 PC 画面、语音控制等标注 [Pro] 的功能 | 不支持 | 支持 |
| 脚本与 API（JavaScript / REST / FindNode） | 可用 | 可用，多机同步场景才真正吃满 |

多控中心是两版最大的分水岭：精简版只能一窗一机摆开；专业版能把鼠标、键盘、Fn 操作**同步到所有勾选的设备**，还能按组保存（组一设好，快捷键一键选组），分辨率不同的机器也能同步 —— 因为同步发的是「找哪个界面元素」的查询，不是坐标。

## 三、设备数上限到底信哪个

官方两处说法不同，这不是抄错：

- 官网首页宣传语写「管理 1~100 台」；
- 官方 FAQ 的问答写「普通版 4 台、商业版最高 50 台，可按 10 / 20 / 30 / 50 购买」。

两边口径并列摆出来，你自己判断：**实际能连几台，以你客户端里激活后的显示为准**，买之前先在客户端内确认档位。价格与促销随时间变，本文不写死，以客户端内购买通道显示为准（支持微信支付、支付宝、Paypal）。

## 四、激活码与许可迁移

- **激活码是什么**：升级专业版时输入的一串码，绑定到你的电脑（TC ID）上。TC ID 在主窗口右上角「i」图标打开的关于窗口里，底部就是，可复制也可显示二维码。
- **提示「id 不存在」**：多半是激活码与当前客户端的 TC ID 对不上，先确认复制的 TC ID 是这台机器的，再重新输入。
- **换电脑 / 重装系统**：专业版降回精简版后需要做许可迁移，官方 FAQ 有专门条目说明流程 —— 迁移前先记下 TC ID，换机后用同一账号通道把许可挪过去，别在两台机器上同时激活。
- **从精简版升专业版、或加购更多设备数**：都在客户端内操作，买过的服务可补差价升级。

## 五、哪些功能两版都能用

别因为没升级就觉得少了半套软件 —— 单机场景下精简版已经完整：键鼠控制、截图录像、文件拖拽、剪贴板互通、画质与分辨率调节、自动连接、脚本 Runner，一个不少。真正需要专业版的是「同时管多台手机 + 要同步操作」这类需求，见 [电脑上操作手机的日常用法.md](电脑上操作手机的日常用法.md) 里的日常操作是否够你用；打算批量部署的，先读完 [下载与安装教程.md](下载与安装教程.md) 的配置要求再决定机器配置。
