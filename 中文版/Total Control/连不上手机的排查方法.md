# 连不上手机的排查方法

## 一、先看现象，再动手指

把故障按现象归类，能省掉一大半乱试的时间：

| 你看到的现象 | 大概率原因 | 跳到 |
| --- | --- | --- |
| 设备列表空的 / 检测到 0 台 | USB 调试没开、驱动没装、数据线只供电 | 第二节 |
| 电脑一直响「叮咚」插拔声、窗口反复弹文件管理器 | 线 / 口 / 集线器接触不良 | 第二节 |
| 卡在「正在安装 / 启动服务」出不来连接按钮 | 别家助手类软件的 adb 抢占冲突 | 第三节 |
| adb 里显示 offline 或 unauthorized | 授权没点、驱动或供电不稳 | 第三节 |
| USB 能连，TCP 老失败 | 没做过 USB 首连、不在同一网段 | 第四节 |
| 连上几分钟就掉 | 供电不足、手机杀后台、省电模式 | 第五节 |
| 报「获取屏幕失败」 | PC 端权限不够、手机端没起来 | 第六节 |

## 二、检测不到设备

按顺序查，查到哪步修哪步：

1. **USB 调试开了没**：设置 → 开发者选项 → USB 调试。小米 / vivo 还要开「USB 安装」和「USB 调试（安全设置）」。
2. **USB 模式对不对**：手机通知栏把 USB 用途从「仅充电」改成「文件传输 / MTP」—— 有些机型仅充电模式下电脑根本不认。
3. **换线换口**：用原装线，插机箱后面板口；先把集线器摘掉直连，能认了就是集线器供电问题。
4. **驱动**：连接页显示的是一串串号而非机型名，就是驱动没到位 —— 装 PC 目录自带的通用 adb 驱动，或去手机厂商官网下。
5. **自查 adb**：命令行里执行

```cmd
cd "C:\Program Files\Sigma-RT\Total Control\adb"
adb devices
```

列表里能看到设备串号 = 驱动正常；显示 `offline` / `unauthorized` = 往下走第三节。

## 三、卡在安装服务，或 adb 状态异常

**「adb 服务与 XXX 冲突」弹窗 / 一直循环安装**：电脑上装过手机助手、模拟器、带 adb 的播放器类软件，它们各自带的 adb 版本互相打架。处理原则是让 Total Control 独占 adb：

- 退出冲突的助手类软件（360 手机助手、酷狗、鲁大师、各种模拟器都上过这个坑名单）；
- 只是退出不够，就把该软件的 adb 进程杀掉，或改掉它的「自动连接手机」设置；
- 实在不行卸载该软件。

**`adb devices` 显示 unauthorized**：手机上那次「允许 USB 调试」的授权框没点，或勾选记录被清了 —— 拔线重插，手机弹框时勾「始终允许」。

**`adb devices` 显示 offline**：换后置 USB 口、换线、更新 USB 驱动；多台设备里单独一台 offline，优先怀疑这台的线和口。

**反复安装 APK 失败（小米 / 红米常见）**：手机上打开「允许安装未知来源应用」，安装弹窗出来时**手动点一次安装**，别让它在后台被拒。

## 四、TCP 连不上的三件事

1. **必须先 USB 首连过**：全新设备或重启后的设备没做过一次 USB 连接，TCP 不认。
2. **同网段**：手机和电脑要在同一局域网；路由器开了「AP 隔离 / 访客网络」会互相看不见，得在路由上关掉。
3. **手机端要有 IP 与密码**：连接帮助 → TCP → 填手机上显示的 IP；设了密码就填密码。华为 Android 8.0 以上机型对 TCP 有额外限制，官方 FAQ 有专门条目，连不上时去查对应机型说明。

**TCP 老掉线**：WiFi 质量问题居多 —— 有延迟或丢包就拖慢传输甚至断开，官方建议用好一点的 AP、手机连 5G 频段。

## 五、用着用着掉线

掉线原因九成在供电、驱动冲突、手机杀后台这三类：

- **物理层**：电脑反复插拔声 + 设备管理器不停刷新 = 换线、换口、摘掉集线器逐个排除。
- **供电**：从集线器上减掉几台就不掉了 → 换带独立电源的集线器，单口供电 2A 及以上，接口数控制在 10 口左右，插后置 USB；笔记本 / 一体机多开别超过 5 台。
- **驱动互斥**：两个品牌手机的驱动打架，单独插都正常、一起插全掉 —— 避免混用驱动冲突的机型，或换官方驱动。
- **手机杀后台**：给 Total Control 自启动权限、锁后台；电量设置里把它加入「不限制后台」。小米关掉省电模式 / 神隐模式，华为打开「仅充电模式下允许 adb 调试」。
- **同类软件冲突**：手机上另外装着投屏、直播类工具时，两个抢同一套能力会互踢，别同时开。

## 六、「获取屏幕失败」与程序本身的问题

- PC 端**右键 → 以管理员身份运行**（权限不够是最常见一条）；
- 手机端程序关掉重开，重新拔插 USB 或重启手机后再连，**连接过程中手机别熄屏**；
- 仍失败时按官方 FAQ 的做法补齐运行库：`%temp%` 目录里找到 `d3dx9_43.dll`，复制到 Total Control 安装目录的 `jre\bin` 下，重启程序；
- 双击图标没反应、或提示「TC 正在启动，请勿重复运行」→ 任务管理器里把残留的进程结束掉再启动。

排查走完还是连不上，把你卡在哪一步（现象 + `adb devices` 输出）记下来，去官网支持页反馈即可。连接成功之后的操作，见 [电脑上操作手机的日常用法.md](电脑上操作手机的日常用法.md)。
