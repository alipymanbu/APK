## 一、界面骨架：顶部找片、底部切大区

打开后的首页分三层，先认结构再找片会快很多：

| 位置 | 内容 | 你能做什么 |
| --- | --- | --- |
| 顶部 | 三横线菜单 + 搜索框（占位文字「搜索影片、演员、导演」） | 直接搜片名、演员、导演 |
| 中部 | 频道标签：精选 / 电影 / 连续剧 / 综艺 / 动漫 / 短剧；下方轮播大图；再下方是快捷入口与榜单 | 按类型横滑切换频道 |
| 底部 | 四个入口：首页 / 短剧 / 排期表 / 我的 | 在四大区之间跳转 |

「我的」在右下角，注册登录、账号相关操作都从这里进，详见 [注册登录与收藏同步.md](注册登录与收藏同步.md)。

## 二、搜索：知道名字就直接搜

点顶部搜索框，输入片名、演员或导演名中的任一项即可。搜索适合这几种情况：

- 你已经知道要找什么，不想一层层翻频道；
- 某部剧在首页轮播里刷不到（轮播位有限，不等于库里没有）；
- 想按演员把 TA 的作品一次找齐。

搜到后点进播放页就开看；某条线路放不出来时换线路，操作见 [播放线路切换与卡顿排查.md](播放线路切换与卡顿排查.md)。

## 三、频道与快捷入口：不知道看什么时的两条路

频道标签下面是四个快捷入口：

- **全部分类**：把类型、地区、年份这些筛选条件摊开，适合「只看某类」时收窄范围；
- **排期表**：按日期看每天更新了哪些剧，追连载的主入口（第五节细讲）；
- **排行**：热度榜单，想知道「最近大家在看什么」从这里进；
- **片单广场**：按主题打包好的片单，适合整组地挑。

再往下是**实时热门榜**，提供「日榜 / 周榜 / 月榜」三个时间维度切换，点「更多」进完整榜单。日榜看当下热度，月榜适合找一段时间里持续在播的剧。

## 四、精选页的「粉丝4K求片专区」

切到「精选」频道，热门榜上方会出现「粉丝4K求片专区」。这是按 4K 画质需求整理的推荐位，海报右上角带评分。画质要求高的片可以从这里先翻；专区里没有的，回搜索或换线路试，见 [播放线路切换与卡顿排查.md](播放线路切换与卡顿排查.md)。

## 五、排期表：按日期追连载

排期表是追连载剧最省事的入口，底部导航点「排期表」即可进入：

1. **先选日期**：顶部一排日期可横滑，从「昨天 / 今天 / 明天」到前后几天，点哪天就看哪天的更新列表。追剧时每天点进「今天」，更新过的剧直接出现在列表里。
2. **再看条目**：每部剧一行，左侧封面带评分角标，右侧写着「年份 · 地区」和类型标签（如「动作 / 动画 / 奇幻」），方便你在点进去之前先筛掉不合口味的。
3. **顺手收藏**：每行最右侧的心形按钮点一下即收藏，之后从收藏里直接找回。收藏会随账号同步的前提是先登录，说明见 [注册登录与收藏同步.md](注册登录与收藏同步.md)。

排期表只列「当天有更新」的剧，找老剧、完结剧不走这里 —— 那种用搜索或频道翻更直接。

## 六、找到片之后

点海报进播放页即可播放。开局卡一下、或者一直转圈，先别急着退出，多半是线路问题：按 [播放线路切换与卡顿排查.md](播放线路切换与卡顿排查.md) 换一条线路通常就能放出来；播放页压根打不开、或应用闪退，走 [常见问题与排查.md](常见问题与排查.md)。
