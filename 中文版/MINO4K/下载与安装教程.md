## 一、先认清这份安装包

网上能搜到好几个叫「MINO4K」的包，版本号和体积各不相同。你从本文对应网盘拿到的这一份，事实如下（用于装完后核对，避免装错包）：

| 项目 | 值 |
| --- | --- |
| 版本号 | 2.2.6 |
| 包名 | `com.mjyx.jhxq` |
| 安装包大小 | 91.34M |
| MD5 | `A22D201CAAC54716A74769161EF447E4` |
| 系统要求 | 安卓 5.2 及以上 |

装完后想核对包名：手机「设置 → 应用 → 找到 MINO4K → 应用信息」，页面里会显示包名，应为 `com.mjyx.jhxq`。网上另有包名不同的同名应用，区分方法见 [常见问题与排查.md](常见问题与排查.md)。

## 二、从网盘取安装包

1. 点开 [MINO4K 安装文件资源（夸克网盘）](https://pan.quark.cn/s/80317e09be50)。
2. 在打开的分享页里选「保存到我的网盘 / 转存」，存进你自己的夸克账号（不转存直接下也可能可以，但转存后文件长期在你名下，源分享失效也不受影响）。
3. 手机装夸克 App 登录同一账号，在网盘里找到该文件夹，点下载，等进度走完。
4. 也可以在电脑浏览器打开链接转存，再从夸克 PC 客户端下载到本地，用数据线拷到手机。

文件夹里除 APK 外还有一个说明 txt，是防止分享失效的备份提示，不用运行。

## 三、安装

1. 在手机文件管理器里点刚下载的 `.apk`。
2. 系统若弹出「禁止安装来自此来源的应用」，这是「未知来源」开关没开：按提示进入「安装未知应用」页面，给文件管理器或夸克开权限，再返回重试。各品牌路径略有差异：
   - 小米/红米：设置 → 隐私保护 → 特殊权限 → 安装未知应用
   - 华为/荣耀：设置 → 安全 → 更多安全设置 → 安装外部来源应用
   - OPPO/realme/一加：设置 → 安全 → 安装外部来源应用
   - vivo/iQOO：设置 → 安全与隐私 → 更多安全设置 → 安装未知应用
3. 安装页会显示应用名与图标，确认后点「安装」，进度条走完点「打开」。
4. 若提示「解析包时出现问题」或「安装包损坏」：重新下载一次，下载中断是最常见原因；也可对照第一节的 MD5 核对文件是否完整。

## 四、系统要求与安装失败的常见原因

- **系统版本**：需要安卓 5.2 及以上。系统过旧会在安装页直接提示失败，没有绕开的办法，只能换设备。
- **存储空间**：安装包 91.34M，安装后占用会翻倍以上，机身剩余空间建议至少留 500M。
- **同名覆盖**：手机里若已装包名不同的另一款「MINO4K」，两个可以共存（图标名相同，注意区分）；若包名相同但版本更低，会提示「安装包冲突 / 版本降级」，先卸载旧版再装（会丢本机观看记录，注意先看 [注册登录与收藏同步.md](注册登录与收藏同步.md) 里的同步说明）。
- 其余安装与启动阶段的报错，统一走 [常见问题与排查.md](常见问题与排查.md)。

## 五、第一次打开

首次进入是首页：顶部有搜索框，下面一排频道（精选 / 电影 / 连续剧 / 综艺 / 动漫 / 短剧），底部四个入口（首页 / 短剧 / 排期表 / 我的）。不用登录也能直接找片看，界面各区域怎么用、排期表怎么看当天更新，见 [找片与排期表使用教程.md](找片与排期表使用教程.md)。
