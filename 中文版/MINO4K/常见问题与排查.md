## 一、装不上 / 安装时提示错误

按提示信息对号入座，详细步骤在 [下载与安装教程.md](下载与安装教程.md)：

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 解析包时出现问题 / 安装包损坏 | 下载不完整 | 重新下载，下完对照 MD5 核对 |
| 未安装应用 / 安装未知应用被禁止 | 「未知来源」没开 | 给文件管理器或夸克开安装权限 |
| 应用未安装 / 存储空间不足 | 机身空间不够 | 清出至少 500M 再装 |
| 版本降级 / 冲突 | 本机已有同包名旧版 | 卸载旧版再装（先确认已登录同步，见 [注册登录与收藏同步.md](注册登录与收藏同步.md)） |
| 与系统版本不兼容 | 系统低于安卓 5.2 | 需换设备，无绕开办法 |

## 二、打开就闪退 / 点图标没反应

按顺序做，做到哪步好了就停在哪步：

1. **强停重开**：设置 → 应用 → MINO4K → 强行停止，再打开；
2. **清缓存**：同页面 → 存储 → 清除缓存（不丢收藏与账号数据）；
3. **重启手机**：一次即可，能清掉卡死的后台进程；
4. **清数据**：同页面 → 清除数据（**会清掉本机未同步的记录**，未登录过的先想清楚）；
5. **重装**：卸载后从 [MINO4K 安装文件资源（夸克网盘）](https://pan.quark.cn/s/80317e09be50) 重新取包安装。

若闪退从某次安装后开始，且本机还装过同名应用，优先怀疑两个包打架，见下一节。

## 三、同名应用分不清：三个「MINO4K」不是一回事

搜索时你会撞见至少三款叫 MINO4K 或米诺影视的应用，包名完全不同，装错会出现「图标一样但界面不对」「覆盖安装失败」：

| 应用 | 包名 | 形态 |
| --- | --- | --- |
| 本文这一款（网盘里的 2.2.6） | `com.mjyx.jhxq` | 在线追剧：首页频道 + 排期表 + 多线路播放 |
| 应用宝上架的同名款 | `com.minuo.wyfourknb` | 本地播放与视频剪辑（厂商介绍为本地媒体播放/剪辑工具） |
| 另有「米诺影视」等同系列名 | 如 `com.taojingshop.qujiubu.mino` | 同为追剧类，但不是同一个包 |

**核对方法**：设置 → 应用 → 点开对应应用 → 应用信息，看包名。你装的应是 `com.mjyx.jhxq`。核对与安装口径统一在 [下载与安装教程.md](下载与安装教程.md) 第一节。

## 四、网上版本号和网盘里的对不上

同名页面能看到 6.0.x、v6.0.2 等版本号，体积 70M 上下，与网盘里的 2.2.6 / 91.34M 不一致 —— 它们不是同一个包（包名、体积都不同）。装哪个的建议：

- **以网盘这份为准**：文档里的界面、操作路径都是按它写的，跟着本目录的教程走不会错位；
- 别把两个包来回覆盖安装：包名不同的能共存但图标同名易点错，包名相同的会触发降级提示；
- 网页上标注的更新时间、评分类信息随对方页面变化，不作为你手上版本的依据。

## 五、怎么更新到新版本

这个应用不上应用商店，更新路径只有一条：**重新取网盘里的 MINO4K 安装文件资源（获取步骤见 [下载与安装教程.md](下载与安装教程.md) 第二节），下载后覆盖安装**。要点：

- 网盘文件夹里的包更新后，同名文件覆盖安装即可，收藏与账号数据（已登录同步的）不受影响；
- 装之前对一下新包的版本号与体积，确认不是又下到了别的同名应用（第三节的包名核对法）；
- 应用内若弹出更新提示，以提示为准；但没有官方商店做背书，来源不明的「更新包」不要装，一律回到上面这条路径取包。

## 六、搜不到某部片 / 播放页打不开

1. 先换关键词：片名、演员、导演各试一次（搜索框三类都收）；
2. 换线路：进播放页换播放源，多数「放不出来」到这一步解决，见 [播放线路切换与卡顿排查.md](播放线路切换与卡顿排查.md)；
3. 播放页整体打不开：该资源可能已下架，过段时间再访问，或去「精选」频道的求片专区、排期表找替代（见 [找片与排期表使用教程.md](找片与排期表使用教程.md)）；
4. 都不行就先看当天排期表里更新的剧，回头再搜。

## 七、还没解决？

先确认问题属于哪一层：**装不上** → [下载与安装教程.md](下载与安装教程.md) 第三、四节；**打得开但放不出来** → [播放线路切换与卡顿排查.md](播放线路切换与卡顿排查.md)；**账号与记录丢失** → [注册登录与收藏同步.md](注册登录与收藏同步.md)。分层判断本身比逐条试错更快。
