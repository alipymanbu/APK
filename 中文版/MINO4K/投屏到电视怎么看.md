# MINO4K 投屏到电视怎么看

> 手机上的片怎么放到电视上：先看应用内有没有投屏按钮，没有就走系统镜像，搜不到设备按排查表走。

## 一、两条路，先分清你要哪种

| 方式 | 原理 | 适合 |
| --- | --- | --- |
| 应用内投屏 | 电视自己去拉片源，手机当遥控器，可以锁屏、退到微信 | 长时间看剧（首选） |
| 手机镜像 | 整个手机屏幕原样投到电视 | 播放页没有投屏按钮时的兜底 |

两条路的共同前提：**手机和电视连在同一个 Wi-Fi 下**。这一步没做对，后面全白搭。

## 二、先看播放页有没有投屏按钮

进播放页，看播放器控制条右上角有没有 **TV 图标** 或「投屏」字样：

- **有** → 直接点它选电视，跳到第三节；
- **没有** → 说明这个版本或这条片源不提供应用内投屏（官方支持文档对这种情况的解释是：应用或视频源本身不支持，可能受版本限制），不用再找，直接走第四节的镜像方案。

不同线路的投屏支持可能不同：这条源没有按钮，换条线路进播放页再看一眼（换线路见 [播放线路切换与卡顿排查.md](播放线路切换与卡顿排查.md)），是成本最低的二次确认。

## 三、应用内投屏的步骤

1. 手机和电视连**同一个 Wi-Fi**（连的是同一个路由器，不是一个连光猫、一个连路由器）；
2. 播放页点 TV 图标；
3. 在设备列表里选你的电视，连上后画面转到电视，手机变遥控器（暂停、选集、音量都在手机上操作）；
4. 电视端若从没投过，先在电视设置里把「多屏互动」「DLNA 服务」这类开关打开（海信、康佳、乐视等品牌在电视设置里有此开关，找不到就查电视说明书或问品牌客服）。

## 四、没有按钮时：用系统镜像

镜像会把整个手机屏幕（包括通知、聊天窗口）投到电视，注意隐私。

**安卓手机侧**：

1. 下拉快捷开关面板，找「无线投屏」「投屏」「Smart View」「屏幕镜像」这类磁贴（找不到就进 设置 → 连接与共享 / 更多连接 → 投屏）；
2. 点开后选中你的电视，电视端确认连接；
3. 连上后打开 MINO4K 播放，手机横过来电视即全屏。

**电视侧**：老设备需要先打开 Miracast / 无线显示（一般在「我的应用」或设置里的「投屏」「多屏互动」）；只有 DLNA 的设备投不了镜像，只能走第三节的应用内投屏。

## 五、搜不到电视设备，按这张表查

| 检查点 | 具体动作 |
| --- | --- |
| 是否同一个 Wi-Fi | 手机和电视都连**同一个路由器**；一个连光猫、一个连路由器就不在同一局域网 |
| 中继设备 | 手机连放大器、电视连路由器（或反过来）也算不同网，统一连路由器 |
| 电视开关 | 电视的「多屏互动」「DLNA」「Miracast」是否已打开 |
| 路由器隔离 | 登录路由器管理页 → 设备管理，关掉「AP 隔离」（设备之间互相隔离时谁也发现不了谁），改完重启路由器 |
| 华为手机 | 设置里搜索「WLAN+」并关闭（该功能自动切换网络会打断投屏；HarmonyOS 5 及以上无此项，跳过） |
| 还不行 | 重启电视/机顶盒/路由器，关掉视频 App 重开，再搜一次 |

以上任一项修好后重新搜索设备列表，多数「搜不到」到这一步就解决了。

## 六、兜底：一根线连过去

手机和电视死活连不上无线，用 **Type-C 转 HDMI 线**：转接头插手机、HDMI 端插电视，电视信号源切到对应 HDMI 口即可。有线没有延迟、不受 Wi-Fi 干扰，代价是手机被线拴住。适合无线方案全部试过仍不行的场合。

投过去之后如果画面卡，问题回到播放侧，按 [播放线路切换与卡顿排查.md](播放线路切换与卡顿排查.md) 排查。
