# 扩展列表空白与源失效排查

> 装完发现扩展页一片空白，或昨天还能用的源今天报错——这是原版扩展仓库下架后所有 Tachiyomi 系用户都会撞上的问题。本篇按「先分清现象 → 补仓库 → 逐项排查」的顺序处理。

## 一、先把「空」分成三种

| 你看到的 | 实际问题 | 对应章节 |
| --- | --- | --- |
| 扩展标签页空白，或提示「无法获取扩展列表」 | 没有可用的扩展仓库 | 第三节 |
| 扩展页有内容，但「源」标签是空的 | 没装扩展，或装了没信任 | 第四节前两条 |
| 装了扩展、源也在，点开却报错 | 扩展过期 / 源站变更 / 人机验证 | 第四节后三条 |

## 二、背景：为什么大家的列表都空了

2024 年初原版 Tachiyomi 停止开发时，官方扩展仓库也一并下架。此后**任何新装的 Tachiyomi 系应用（含 TachiyomiJ2K）扩展页默认都是空的**，必须手动添加社区仓库才能装扩展。这不是你装错了，也不是安装包有问题——换成哪个衍生版都一样。

社区接管后通行的仓库是 GitHub 上由志愿者维护的 Keiyoushi 仓库（截至 2026-09；地址以 [其 GitHub 页面](https://github.com/keiyoushi/extensions) 当前公布的为准）。

## 三、添加扩展仓库（一次配置，长期有效）

1. 设置 → 浏览 → 扩展仓库；
2. 把列表里已有的旧仓库地址删掉——`tachiyomi.org` 结尾的旧地址已全部失效，留着只会报「无法获取扩展列表」；
3. 点右上角「+」，填入仓库地址：

   ```text
   https://raw.githubusercontent.com/keiyoushi/extensions/repo/index.min.json
   ```

4. 保存后回到「浏览 → 扩展」页点刷新；列表没出来的话，**完全退出应用再打开一次**。

地址只要错一个字符就加不上，加不上时先检查是不是复制带了空格或换行。

## 四、装了扩展还是不行，逐条对

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 在扩展页点「安装」没反应 | 阅读器自己没拿到「安装未知应用」权限 | 系统设置 → 应用 → TachiyomiJ2K → 安装未知应用，打开后再试 |
| 扩展装完，源列表里没有它 | 没点「信任」 | 扩展页里的盾牌图标点一次信任；扩展每次更新后可能要重新信任 |
| 源能打开，加载内容时提示过不了验证（Cloudflare） | 源站开了人机验证 | 在源或扩展的操作菜单里选「在 WebView 中打开」，在网页里人工完成一次验证，再回到应用刷新 |
| 只有某个源持续报错 / HTTP 404 | 源站改版或下架，扩展没跟上 | 更新该扩展；没有更新就卸载重装一次；还不行就在书架里给对应条目换源 |
| 所有源突然都连不上 | 手机网络环境变化（代理、DNS、流量限制） | 切换网络后重试 |

## 五、升级后闪退：先怀疑扩展

应用启动时会自动加载全部扩展，其中一个不兼容就可能把整个应用带崩（这是用户反馈里最常见的闪退原因）。排查路子：逐个禁用 / 卸载扩展后重启应用，卸掉哪个不闪退就是它；应用本体的书架数据不受卸载扩展影响，不用先备份。

## 六、清缓存可以，清数据要想清楚

系统应用信息页里的两个按钮效果完全不同：

- **清除缓存**：只删临时数据，随时可做，书架无损；
- **清除数据**：应用恢复出厂——书架、进度、设置、下载记录一起没，效果等同卸载重装。

动「清除数据」之前先做一次备份（见 [备份与数据迁移.md](备份与数据迁移.md)）。
