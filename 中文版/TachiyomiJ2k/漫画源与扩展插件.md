## 一、为什么装完是空的

TachiyomiJ2K 的定位是**阅读器**：书架管理、下载、翻页、追踪同步这些能力在应用里，而「漫画从哪个网站来」这件事交给扩展。官方仓库的免责声明也写明：应用与内容提供方没有任何关联。所以：

- 第一次打开，浏览页里没有任何源，是正常状态，不是坏了；
- 想接入什么来源，就去装对应的扩展；
- 扩展由社区维护，某个来源失效是常态，换源或更新扩展属于日常操作。

## 二、装扩展的通用步骤

1. 侧边栏进入「浏览」页，切到「扩展」标签；
2. 列表按语言分区，找到你要的条目点「安装」；
3. 装完第一次用，会弹一个「信任此扩展」的确认（盾牌图标），点信任——之后扩展每次更新，都可能要重新点一次；
4. 回到「浏览」页的「源」标签，新装的源就出现了。

## 三、扩展仓库

应用内置列表之外，还可以添加社区维护的扩展仓库：设置里找到「扩展仓库」，填入仓库地址，保存后新仓库的扩展会合并进扩展列表。仓库地址去哪找、怎么评估一个仓库，官方 FAQ 有说明：[mihon.app 的扩展 FAQ](https://mihon.app/docs/faq/browse/extensions)。

两点提醒：

- 仓库地址会随社区变动，以官方 FAQ 当时的说明为准；
- 来源网站的可用性不由 TachiyomiJ2K 控制，某部作品在一个源上没有，换个源搜是常规做法。

截至 2026-09，社区通行的仓库是 GitHub 上志愿者维护的 Keiyoushi 仓库（原版扩展仓库的后继者），地址 `https://raw.githubusercontent.com/keiyoushi/extensions/repo/index.min.json`（以其 GitHub 页面当前公布为准）。加完仓库扩展列表没刷出来、或报「无法获取扩展列表」，按 [扩展列表空白与源失效排查.md](扩展列表空白与源失效排查.md) 的步骤逐项处理。

## 四、源加载不出来 / 封面空白，往哪查

| 现象 | 先查什么 | 怎么处理 |
| --- | --- | --- |
| 源列表是空的 | 是否没装任何扩展 | 按第二节装扩展 |
| 源装了但点开报错 | 扩展是不是刚更新完还没信任 | 扩展页里看盾牌提示，点信任 |
| 封面全部转圈 / 加载失败 | 系统 WebView 是否太旧 | 应用商店里把「Android System WebView」和 Chrome 更新到最新 |
| 某个源一直连不上 | 来源网站自身在维护或已失效 | 隔段时间再试，或给书架里的对应条目换源 |
| 所有网络请求都失败 | 手机网络 / 代理环境变化 | 切一下网络再试 |

## 五、扩展的更新与移除

- 扩展有新版本时，扩展页会标出来，逐个点更新；Android 12 及以上系统上，应用支持扩展自动更新。
- 不用的扩展在扩展页点「卸载」移除。书架里依赖该源的条目不会跟着删，但更新时会提示来源缺失——把书从书架移除，或给它换源。
