# 书架更新与下载失败排查

> 书架不自动更新、章节下载到一半停住——问题大多出在三处：更新开关没开对、扩展过期、系统省电策略把后台拦了。本篇按这个顺序排查。

## 一、先确认更新开关

手动更新：书架页下拉刷新，或点工具栏的全局更新按钮。自动更新在 设置 → 书架（库） 里，先看这几个开关：

- 自动更新的频率与时间段；
- 「启动时更新书架」：每次打开应用就查一遍新章节；
- 「仅在 Wi-Fi 下更新」：开着的时候，移动网络下不会自动更新。

开关名称在不同版本里措辞略有差异，以你手机上实际显示的为准。

## 二、拉不到新章节，按这张表查

| 现象 | 先查什么 | 处理 |
| --- | --- | --- |
| 只有某几本不更新 | 那部漫画的源是否失效 | 进详情页手动刷新看报错；源失效就换源（扩展问题见 [漫画源与扩展插件.md](漫画源与扩展插件.md)） |
| 全部书都不更新 | 扩展是否集体过期 | 更新全部扩展；扩展列表空的先按仓库配置处理 |
| 手动刷新报 HTTP 403 / 404 | 源站侧变更或临时故障 | 过段时间再试，或换个源搜同一部作品 |
| 更新一直转圈不结束 | 网络不稳 / 应用长时间没重启 | 切网络、重启应用再试 |

## 三、后台自动更新不跑：省电策略拦的

各手机厂商的默认省电策略会清理后台应用，自动更新经常死在这里。厂商官方支持文档给的通用做法（具体路径以你的机型为准）：

1. **电池优化白名单**：系统设置里搜「电池优化」，找到 TachiyomiJ2K 设为「不允许（优化）」；
2. **允许后台活动**：华为 / 荣耀在「应用启动管理」里关掉自动管理并勾选允许后台活动；小米对应「省电策略 → 无限制」一类；
3. **多任务卡片加锁**：最近任务里给应用卡片加锁，防止一键清理误杀；
4. **关闭省电模式**：低电量模式开启期间，后台任务基本不跑。

另查系统「流量节省程序」：它开启时后台应用不用移动数据，自动更新只在 Wi-Fi 下能跑。

## 四、下载失败与找不到章节文件

- **下载到一半停住**：先看存储空间。空间紧张时安卓会限制后台任务，下载会悄悄停住（有用户反馈的经验）；清出几个 G 空间再试。
- **下载队列全部失败**：多半跟着源走——源打不开，下载也不会成功，回到第二节的表逐条查。
- **找不到已下载的章节文件**：设置 → 下载 里看「下载位置」，章节图片按「作品名 / 章节名」分文件夹放在那个目录里；换机搬运的做法见 [备份与数据迁移.md](备份与数据迁移.md)。

## 五、把更新调到不烦人

- 更新频率不必太密：一天查一到两次足够追更，频繁的全局更新只会增加失败率与耗电；
- 「仅在 Wi-Fi 下更新」按自己的流量情况开关；
- 各项的具体位置以你手上版本的设置页为准。
