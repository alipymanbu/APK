## 一、安装前先确认三件事

1. **手机系统版本**：官方要求 Android 6.0 及以上。
2. **它只是个阅读器**：TachiyomiJ2K 本体不带任何漫画源，装完打开书架是空的，要靠装「扩展插件」接入来源，这部分见 [漫画源与扩展插件.md](漫画源与扩展插件.md)。
3. **网盘里这份是哪个版本**：安装包信息见下表，版本与体积以它为准（官方发布页会持续出新版本，想装别的版本去 [官方 Releases 页面](https://github.com/Jays2Kings/tachiyomiJ2K/releases) 看当前最新）。

| 项目 | 值 |
| --- | --- |
| 版本 | 1.7.4 |
| 包名 | `eu.kanade.tachiyomi.j2k` |
| 安装包大小 | 50.38M |
| MD5 | A311ED36158CACD84BBDCA4B8EDC5C68 |
| 适用系统 | Android 6.0 及以上 |

包名末尾的 `.j2k` 意味着它和原版 Tachiyomi（包名 `eu.kanade.tachiyomi`）不冲突，可以装在同一台手机上并存，互不覆盖。

## 二、获取 TachiyomiJ2K 安装文件资源

从 [TachiyomiJ2K 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c26c5183473b) 进去后，按这个顺序操作：

1. 选中里面的 APK 文件，点「转存」把它存到自己的夸克网盘；
2. 在手机上打开夸克网盘 App，找到刚转存的文件，点「下载」；
3. 下载完成后直接点开 APK，系统会跳到安装确认页。

在电脑上操作也可以：网页版先转存，再用手机 App 下载——APK 必须落到手机本地存储才能安装。

## 三、安装步骤

1. **允许安装未知来源应用**。从网盘下载的 APK 不经过应用商店，系统默认拦一道。不同品牌的开关位置不一样，常见路径：

   | 品牌 | 路径（供参考） |
   | --- | --- |
   | 原生 / Pixel | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |
   | 小米 / Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 |
   | 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
   | 三星 | 设置 → 应用程序 → 右上角菜单 → 特殊权限 → 安装未知应用 |

   给「夸克网盘」或你用来打开 APK 的文件管理器勾上「允许安装」即可，不用全局打开。

2. **点开 APK 安装**。安装页会列出它申请的权限，点「安装」等进度走完。
3. **首次打开给存储权限**。第一次启动会要「访问存储 / 照片和视频」权限，同意它——下载到本地的章节、备份文件都放在这个空间里，不给的话下载和备份功能用不了。

## 四、装不上时的对照表

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 「解析包时出现问题」 | 下载不完整（APK 被截断） | 清掉残缺文件重新下载 |
| 同上 | 手机系统版本低于要求 | 确认系统是 Android 6.0 及以上 |
| 「应用未安装」/ 签名冲突 | 之前装过同包名的其他渠道包 | 先卸载旧的那份再装（卸载会清掉它的数据，见下一节） |
| 安装按钮灰色点不动 | 系统级「纯净模式」类开关拦着 | 关掉该开关，或按第三节的路径补权限 |
| 装完但桌面没有图标 | 桌面缓存问题 | 重启手机再看 |

## 五、升级、覆盖安装与卸载

- **覆盖安装保留数据**：直接用新版本 APK 覆盖安装，书架、分类、阅读进度、已下载章节都会保留，不需要先卸载。
- **升级前先做一次备份**：书架和进度存在应用数据里，万一升级出问题可以靠备份恢复，做法见 [备份与数据迁移.md](备份与数据迁移.md)。
- **卸载会一起删掉下载的章节**：从桌面卸载 TachiyomiJ2K 时，下载到本地的漫画文件也一并清除；换手机不想丢的话，用「备份文件 + 拷贝下载目录」两步整体搬走。
