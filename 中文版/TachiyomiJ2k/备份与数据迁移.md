# TachiyomiJ2K 备份与数据迁移

> 换手机、重装、或想换一个漫画阅读器时，书架和阅读进度都能带走。本篇讲 TachiyomiJ2K 的备份怎么建、恢复怎么做、下载的章节文件怎么搬。

## 一、备份里有什么

备份文件（扩展名 `.tachibk`，本质是个压缩包）装的是**元数据**：

- 书架里的每部漫画条目与分类归属；
- 阅读进度、历史记录；
- 追踪绑定（MyAnimeList、AniList、Kitsu、Shikimori、Manga Updates 的同步状态）；
- 设置项（可选）。

**不含**已下载到本地的章节图片——那部分是实体文件，要单独拷，见第四节。

顺带分清系统设置里的两个按钮：「清除缓存」只删临时文件，随时可做；「清除数据」等同于恢复出厂，书架会被一起清掉，两者的区别见 [扩展列表空白与源失效排查.md](扩展列表空白与源失效排查.md)。

## 二、手动备份

侧边栏 → 设置 → 数据与备份 → 创建备份。可以勾选备份内容（书架、分类、进度、设置等），生成一个带日期的 `.tachibk` 文件，默认存在手机的下载目录附近——具体位置以备份完成时的提示路径为准，记一下这个路径，恢复时要找它。

## 三、自动备份

同一设置页里有「自动备份」：设定间隔（每天 / 每周等）与备份内容，到点自动生成备份文件。想把备份存到云端的话，备份目标可以选择你手机上登录的、支持系统存储框架的云盘应用（装了哪个就选哪个）。

建议至少开每周一次的自动备份：书架数据只存在本机，手机丢了就没了。

## 四、下载的章节怎么搬

下载的章节是普通文件夹形式的图片，**备份文件不带它们**，迁移时分两步：

1. 在 设置 → 下载 里看「下载位置」，确认路径；
2. 用文件管理器把整个下载目录拷到新手机的对应位置（或先拷到电脑中转），再在新设备上把应用的下载位置指向这个目录。

顺序建议：先恢复备份（书架先回来）再放下载文件，进度和文件对得上。

## 五、换设备 / 换应用的整体流程

1. 旧设备：手动备份一次，拷出 `.tachibk` 文件与下载目录；
2. 新设备：装好 TachiyomiJ2K（装法见 [下载与安装教程.md](下载与安装教程.md)）；
3. 新设备：设置 → 数据与备份 → 恢复备份，选中 `.tachibk` 文件；
4. 重新装好需要的扩展（扩展不进备份，见 [漫画源与扩展插件.md](漫画源与扩展插件.md)），把下载目录放回去。

## 六、和其他 Tachiyomi 系应用互迁

`.tachibk` 是整个 Tachiyomi 家族通用的备份格式——原版 Tachiyomi、Mihon 以及各衍生版之间，书架备份文件可以直接互相恢复。从原版或别的衍生版换到 TachiyomiJ2K：旧应用里导出备份 → 新应用里恢复，几分钟的事，反过来同理。要注意的只有两点：扩展不在备份里，恢复完要重装一遍；个别追踪服务恢复后可能要求重新登录，以恢复完成后的提示为准。
