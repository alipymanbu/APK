## 一、五件最常用的事

| 你想做的事 | 怎么做 |
| --- | --- |
| 问个问题、查最新消息 | 直接在输入框打字。涉及近期事件时，它检索到的来源会附在回答附近，点开可核对 |
| 让它读文件 | 点输入框附近的附件入口，上传 PDF、表格、文档或代码文件，再用一句话说明你要它做什么（总结、找数据、改错） |
| 让它看图片 | 上传照片后提问，比如「这张图里写了什么」「把图里的表格转成文字」 |
| 不想打字 | 切到语音模式，直接开口聊；适合边做别的事边问。入口、打断、换声音的细节见[语音模式与实时对话.md](语音模式与实时对话.md) |
| 生成图像 | 用文字描述画面让它生成（Grok Imagine）；部分版本还支持把已有图片改风格或生成带声音的短视频，以你当前版本的按钮为准 |

## 二、几个场景下的具体问法

**查资料 / 做决定**

- 「对比一下 A 和 B 这两款手机的口碑差异，列出主要槽点」
- 「过去一周这个领域有什么值得注意的动态？按时间列」

**写东西**

- 「把这段话改得更口语化：……」
- 「根据下面几点写一封请假邮件：时间、原因、工作交接安排」

**学习 / 读懂长内容**

- 「把这份 PDF 按章节各总结三句话」
- 「用高中生能听懂的方式解释这个概念，再举一个生活例子」

**图像与视频**

- 描述越具体效果越稳：主体、场景、风格、构图都说到位，比「画个好看的图」强得多
- 不满意就基于上一张继续提修改要求，不必每次重写整段描述

## 三、让回答更好用的五个习惯

1. **一句话把背景说全**：用途、篇幅、语气、受众写进同一条提问里，比来回追问省额度——免费档额度有限（见[免费额度与订阅套餐对比.md](免费额度与订阅套餐对比.md)），这一点尤其重要；
2. **复杂任务让它分步走**：「先列提纲，我确认后再展开」，中间能纠偏；
3. **重要事实点开来源**：它给出的引用与链接才是核对依据，回答正文只是转述；
4. **长对话及时开新会话**：任务切换时另开会话，避免前文干扰，也让历史记录更整洁；
5. **图像和视频先想好再生成**：这两类在额度体系里消耗最快，免费档用户先把需求在文字里确认清楚（风格、比例、要素），再动手生成，避免反复重试把额度烧光。
