## 一、三十秒上手

1. 打开 App，进入一个对话（新的旧的都行）；
2. 点输入框旁的**话筒 / 语音图标**；
3. 系统第一次会弹麦克风权限，选「允许」；
4. 直接开口说，它会用语音回答，同时屏幕上显示文字转写。

找不到语音图标：先把 App 升级到较新版本；再不行去设置里找语音（Voice）相关选项，部分旧版本把入口收在里面。

## 二、说话时的四个实用细节

| 细节 | 说明 |
| --- | --- |
| 随时打断 | 它说到一半你直接开口，它会停下来听你的——不用等它说完，也不用手忙脚乱找按钮 |
| 追问不用重新铺垫 | 「再举个例子」「说简单点」这类短追问它会接住，上下文还在 |
| 重要信息回头核对 | 语音回答同时有文字转写，涉及数字、日期、地址的，之后按文字版核对一遍 |
| 嘈杂环境 | 麦克风收音会明显变差，换打字更快；降噪耳机能改善 |

## 三、换声音与语速

语音设置里提供多种声音角色可选（不同版本名单不同，常见的有 Ara、Eve、Rex 等，以你 App 内实际列表为准），并支持调整语速。手机上选好的声音会跟着账号同步，换到网页版也生效。

## 四、语音模式里的相机

在语音模式界面里有个相机图标：点开后它一边听你说话、一边「看」摄像头画面。典型用法：

- 对着英文菜单问「帮我看看有什么推荐的」；
- 对着设备铭牌/接口问「这个怎么接」；
- 对着植物或商品问「这是什么」。

用完记得退出相机画面，避免持续占用摄像头。

## 五、语音很耗额度，先知道再放开聊

语音对话消耗的额度比打字多——文字、图像、视频、语音在一个额度体系里共享消耗（机制见[免费额度与订阅套餐对比.md](免费额度与订阅套餐对比.md)）。免费档用户建议：先用打字把问题理清楚，需要展开聊时再切语音。中文语音对话没有额外门槛，直接说中文即可（见[中文界面与中文对话设置.md](中文界面与中文对话设置.md)）。
