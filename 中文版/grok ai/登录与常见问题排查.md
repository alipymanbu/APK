## 一、四种登录方式，选一种用到底

| 方式 | 适合谁 | 注意 |
| --- | --- | --- |
| X 账号 | 本来就玩 X 的人 | 可在 Settings → Account 里连接 X 账号，让 xAI 读取你的 X 会员状态以同步权益 |
| Google 账号 | 安卓用户（大多数手机已登录） | 手机上装的 Google 服务不可用时此路不通 |
| Apple 账号 | iPhone 用户 | 对应 App Store 的「通过 Apple 登录」 |
| 邮箱 | 前几种都没有的人 | 走验证邮件，收不到看第三节 |

两条铁律：**换设备也用同一种方式登录**（不同方式会被当作不同账号，聊天记录互不相通）；**订阅绑在哪个账号上就一直在哪个账号上**，换手机不丢。

## 二、独立 App 和 X 里的 Grok 不是一回事

你会在两个地方碰到「Grok」这个名字：

- **独立应用 / 网页版**：Grok App 与 [grok.com](https://grok.com/)，用 xAI 侧的账号体系，适用 xAI 的隐私政策，订阅即 SuperGrok 系列；
- **X 里的 Grok**：X 应用内的入口，用 X 账号，适用 X 的条款与隐私控制，权益可能随 X 会员档位变化。

两边**账号管理、聊天历史、隐私设置互不相通**——在 App 里删了历史，X 里的不受影响，反之亦然。想让两边产生关联，走 App 内「连接 X 账号」那一步。

## 三、常见问题速查

| 现象 | 处理 |
| --- | --- |
| 邮箱验证码收不到 | 翻垃圾箱；等 1~2 分钟再点重发；确认邮箱地址没拼错；换常用邮箱再试 |
| 登录后一直转圈 / 加载不出来 | 先看同设备浏览器能不能打开 [grok.com](https://grok.com/)；服务可用性因地区与网络环境而异，该服务未在中国大陆官方上架，能否访问以你所在网络环境的实际情况为准 |
| 提示额度用尽 | 付费档的对话、语音、图像共用一份按周重置的额度（机制见[免费额度与订阅套餐对比.md](免费额度与订阅套餐对比.md)第二节）：等本周重置，或购买加量额度（目前仅网页端可买），或升级套餐；免费档等各自限额恢复即可 |
| 想知道还剩多少额度 | 进 **Settings → Usage**：有总用量进度条、按产品的占比、本周额度的重置时间（每个账号的重置时间点不同，以那一页为准） |
| APK 装不上 / 装完打不开 | 回[下载与安装教程.md](下载与安装教程.md)第三节检查安装授权；仍失败则重新下载一次安装包，排除传输损坏 |
| 想核对装上的应用是不是官方版 | 官方 Android 版包名为 `ai.x.grok`（Google Play 页面可见）；在系统「应用信息」里可查到包名，对得上即同源应用 |
| 订阅后权益没生效 | 确认登录的是当初购买时的同一账号、同一种登录方式；再试恢复购买；仍无效找商店订阅凭证联系支持 |

## 四、两个建议先检查的开关

登录完成后（尤其在公共设备或工作设备上使用前）：

1. **训练开关（Improve the model 一类）**：设置的数据控制区里可以选「是否允许你的对话用于模型训练」；处理工作或客户内容前先关掉它；
2. **历史记录**：聊天历史默认留存，涉及隐私的内容可在会话里手动删除，别只靠卸载应用。

## 五、年龄与地区

按 xAI 消费者条款，使用门槛为 13 岁以上（13~17 岁需监护人同意）；商店分级可能更高，以你所在商店的标注为准。地区层面：独立 App 与网页版在部分地区提供免费或付费使用，X 里的 Grok 随 X 的可用范围走——都以官方页面与 App 内提示为准。
