AiPPT 是一个「给个主题就出 PPT」的办公工具：你输入演示主题，或者丢一份现成文档进去，它先出大纲，再套模板生成整套幻灯片。本篇只解决一件事 —— 把网盘里这份包装进手机，并确认它真的能生成。

## 一、先弄清网盘里这份包是哪一版

官方渠道（应用商店、官网）放出的版本一直在更新，与本文档对应的这份不是同一个包。本文里凡涉及版本号、包名、体积，都以下表为准：

| 版本号 | V3.3.0 |
| 包名 | `aippt.com.mm` |
| 安装包体积 | 43.38 MB |
| MD5 | `86B5AD207B198603945ADAE693BD50A8` |
| 系统要求 | 见第二节（第三方标注互相矛盾，本文给了结论） |

安装包本体在 [AiPPT 安装文件资源（夸克网盘）](https://pan.quark.cn/s/fefac330e3cc) 里，转存到自己网盘后下载即可。

**一个容易踩的坑：认包名，不要认名字。** 这个产品叫 AiPPT，而网上叫「AiPPT」或名字只差一两个字母的站点、同名应用有一大把 —— 光在 iOS 的 App Store 里就能搜到不止一个叫 AiPPT 的应用，开发者还不是同一家。**包名相当于应用的身份证号**（同一个名字下可以有多个包名不同的应用），本文这份是 `aippt.com.mm`。能确认「不是同一家」的同名产品清单、以及官方渠道的核对方法，单独写在 [同名产品与官方渠道怎么认.md](同名产品与官方渠道怎么认.md) 里。

另外，表里的 **MD5 相当于文件的指纹**：下载完自己算一遍，与上面的值一致就说明文件完整、没被替换过。

## 二、装之前要核对的两件事

**第一，系统版本。** 这里的公开标注是矛盾的：分发页面上写的是「需要支持安卓系统 5.2 以上」，但安卓从来没有 5.2 这个版本号，这条标注本身不可信；而应用市场里同一个包名的记录显示最低支持到 Android 8.0（minSDK 26）。**按 Android 8.0 及以上准备即可**，8.0 以下的设备能不能装、装了能不能用，本文不下结论。

**第二，手机号或微信。** 这个工具的 AI 功能**必须登录后才能用**（官方服务协议里写明了这一点），所以装之前先想好要用哪种方式登录，并且提前知道一件事：**手机号和微信在国内是两套独立账户**，充会员只会充到当时登录的那一套上（详见 [注册登录与会员计费.md](注册登录与会员计费.md)）。

## 三、安装步骤

1. 在上面的网盘入口里把 APK 转存到自己网盘，再下载到手机；
2. 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给打开安装包的那个应用（文件管理器或浏览器）打开开关；
3. 点击 APK 完成安装。系统提示「应用未经过安全检测」时选择继续安装即可，这是第三方渠道安装包的常规提示；
4. 如果手机里已经装过同名但签名不同的版本，安装会失败，先卸载旧的那个再装。

## 四、第一次打开要做的事

打开后会要求登录，登录方式与账户关系写在 [注册登录与会员计费.md](注册登录与会员计费.md) 里。这里只提醒登录后立刻看一眼的两处：

| 看什么 | 为什么 |
| --- | --- |
| 剩余免费次数 | 免费额度是有限的，心里有数才知道什么时候该停手 |
| 当前登录的是手机号还是微信 | 后面买会员、看订单，都只认这一个账户 |

## 五、装完做一次最小验证

1. 应用能正常打开，登录能走通；
2. 随便输一个主题，能生成出大纲 —— 走到大纲这一步，说明**登录与网络这两关都过了**（后面能不能生成完，还要看额度够不够、模板能不能用）；
3. 生成出来的东西能预览。

装完打不开、或者卡在登录，按 [常见问题与排查.md](常见问题与排查.md) 里的现象逐条排除。安装包与后续版本更新，统一从上面的网盘入口取用。
