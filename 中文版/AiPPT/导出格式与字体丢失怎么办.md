生成得再顺，卡在导出上也是白做。这一篇专门讲「拿不走」和「拿走之后变了样」这两类问题。

## 一、能导出什么

支持的导出格式有：**PPTX、PDF、PNG、JPEG**，另外可以生成在线分享链接（直接发给别人看，不必下载）。

选择逻辑很简单：

| 你的目的 | 选哪个 |
| --- | --- |
| 还要自己继续改内容 | PPTX |
| 只要别人看到最终样子 | PDF 或图片 |
| 让对方直接在浏览器里看 | 在线分享链接 |
| 发朋友圈、贴到聊天里 | PNG / JPEG |

**免费状态能导出哪些格式**：公开资料里只明确了「下载可编辑的 PPTX 需要订阅」，**PDF 与图片是否同样受限，没有找到明确说法** —— 以导出时页面的提示为准。

## 二、可编辑文件通常要会员

**免费用户能生成、能预览，但下载可编辑的 PPTX 一般需要订阅**。免费状态下你看到的是成品长什么样，能不能带走是另一回事。

这不是「试用期不能用」，而是「试用期不能导出源文件」—— 所以判断要不要买会员，最直接的测试就是**用免费额度把一次完整流程走到导出那一步**，看看限制卡在哪儿，再决定。会员档位与价格见 [注册登录与会员计费.md](注册登录与会员计费.md)。

**导出时怎么选才能改**：官方帮助里的口径是「支持二次编辑」，前提是**下载类型选 PPT**（而不是 PDF 或图片）—— 选错格式，拿到的是不可编辑的成品，这和要不要买会员是两件事，别混在一起判断。

拿到文件之后，先做三步自查确认它是可编辑的还是图片化的，方法见 [生成的PPT能不能直接用.md](生成的PPT能不能直接用.md) 第一节。

## 三、下载到本地后字体变了、元素错位了

这是官方自己列进常见问题的一条，不是你操作错了。成因有二：

- **字体没能嵌进文件**；
- 或者**你的电脑上没装 PPT 里用到的那款字体**。

字体一缺，系统就换一款替代字体渲染 —— 字宽不一样，原本排好的一行字就会挤出去或者断开，看起来就是「元素错位」。

**两种修法：**

1. **用工具里的「一键替换字体」**，把成品里用到的字体统一换成你电脑上有的；
2. **在本机装上那款字体**，再打开文件。

顺带一条经验：如果你的 PPT 要在别人的电脑上放（比如拿去会议室、发给客户），**导出前就把字体换成最通用那几款**，比到了现场再发现缺字体强。

## 四、在 PowerPoint 或 WPS 里打开要注意什么

官方**没有承诺**导出文件在别的软件里版式绝对不变化。所以：

- 导出后**先在自己电脑上打开一遍**，重点看标题行、图表、带底色的文本框这几处；
- 需要跨软件使用的场合，**PDF 通常比 PPTX 稳**（PDF 只保版式，不保留可编辑性）。

## 五、下载失败的排查顺序

官方给出的口径是：下载一般**两分钟内**能完成。超过这个时间还没下来，按下面顺序处理：

1. **重试一次**，先别急着换网络；
2. **刷新页面**（或在应用里退出重进）；
3. **换网络**：从 Wi-Fi 切到移动数据，或反过来；
4. 仍然失败，**发邮件给官方支持邮箱 `support@aippt.com`，附上截图**（这是官方 FAQ 里建议的方式）。

如果是「生成到一半卡住」，处理方式不同（合成一般三分钟内完成），见 [常见问题与排查.md](常见问题与排查.md) 第二节。

## 六、导出前建议做的两件事

1. **看一眼用了哪些字体**，该换的换掉，别把字体问题留到打开时才暴露；
2. **看一眼页数和备注**：页数决定了打印与演示的节奏，备注是给自己讲的，导出前顺手清一遍更省事。
