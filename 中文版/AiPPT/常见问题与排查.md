## 一、现象速查

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 生成半天没反应 | 合成需要时间，也可能网络中断 | 见第二节 |
| 下载一直转圈或失败 | 网络不稳、页面状态异常 | 重试 / 刷新 / 换网络；仍失败发邮件给官方支持 |
| 上传文档失败 | 超字数、含图表、导图层级过深、格式不支持 | 见 [导入文档和链接转PPT.md](导入文档和链接转PPT.md) 第三节 |
| 提示次数用完 | 免费额度有限 | 等额度刷新，或考虑会员 / 积分 |
| 生成失败但额度被扣了 | 失败会退额度（退的是额度，不是钱） | 先看额度有没有回来，再决定是否重新生成 |
| 会员到期后作品打不开 | 到期**可能**无法再访问线上内容（海外条款明确，国内未见明文） | 到期前把要留的成品导出到本地 |
| 买了会员却还是受限 | **会员买在另一个账户上**（手机号与微信是两套） | 见第三节 |
| 导出后字变了、图错位 | 字体缺失 | 一键替换字体，或本机安装字体 |
| 编辑器点了没反应 | 页面状态异常 | 刷新页面或退出重进 |
| 想退款 | 不支持无理由退款 | 见 [注册登录与会员计费.md](注册登录与会员计费.md) 第六节 |
| 装不上、装上打不开 | 系统版本、安装包不完整、同名应用冲突 | 见第四节 |

## 二、生成和下载到底要等多久

这两个动作各有官方给出的时间参考，**先按这个预期等，不要提前反复点**：

- **生成**：合成一份 PPT 通常**三分钟内**完成；
- **下载**：通常**两分钟内**完成。

超过这个时间还没结果，处理方式是按「网络 → 页面状态 → 官方支持」的顺序：换一次网络、刷新一次页面，仍不行就把**卡住时的截图**发到官方支持邮箱 `support@aippt.com` —— 官方 FAQ 里明确要求附截图，因为定位问题靠的就是这个。

**一个常见误判**：生成慢不等于失败。反复刷新并不能加快生成，还可能把页面状态弄乱 —— 先按三分钟的预期等一等，再动手。

## 三、会员明明买了，功能还是不可用

这是这个产品最容易踩、也最容易被当成「系统故障」的一条：**手机号与微信在国内是两套独立账户，会员权益只跟购买时的那一套走。**

处理顺序：

1. **回想买的时候用的是哪种登录方式**，然后用同一种方式登录；
2. 换回那种方式后仍然没有权益，**再找客服**（官方帮助里也提到账户合并的处理）；
3. 以后固定用一种方式登录，别再切。

顺便记两条与"钱"有关的现象，别当成系统故障：**生成失败被扣的额度是会退的**（合规未通过、系统异常、配图失败三种情形，见 [注册登录与会员计费.md](注册登录与会员计费.md) 第三节）；**会员到期后线上内容可能就打不开了**，要留的成品请在到期前导出。

## 四、装不上、打不开

- **先核对安装包完整性**：拿本文的 MD5 `86B5AD207B198603945ADAE693BD50A8` 与本地文件比对，对不上就重新下载；
- **卡在安装过程**：设备里若已有同名但签名不同的版本，先卸载再装；
- **打开就退回桌面**：多为系统版本偏低（建议 Android 8.0 及以上），换设备或换版本试；
- **重装或换手机**：安装包始终从 [AiPPT 安装文件资源（夸克网盘）](https://pan.quark.cn/s/fefac330e3cc) 取用，别用来源不明的安装包 —— 这个名字下的仿冒站点和应用很多，认包名 `aippt.com.mm`。

上面几条都排除后仍装不上，剩下的原因基本就两种：**系统版本低于要求**（建议 Android 8.0 及以上），或者**手里这份不是同一份包**（用 MD5 核对）。这两条确认过就不必再往外找了，换设备或换一台来源再试。
