叫 AiPPT 的东西不止一个。名字相近、界面相似、都宣称能生成 PPT 的产品有一大把，**付了钱才发现买的不是同一家**是真实会发生的事。这一篇只做一件事：让你能自己确认手里的到底是哪一个。

## 一、官方入口只有这几个

官方渠道（协议里写明的主体是**北京饼干科技有限公司**）在用的域名：

| 用途 | 入口 | 说明 |
| --- | --- | --- |
| 国内站 | `aippt.cn` | 面向国内用户的主站 |
| 海外站 | `aippt.com` | 海外版，独立计费与协议 |
| 企业 / 开放平台 | `open.aippt.cn` | API 接入、企业相关能力 |

**认法：看域名，也看页面上写的运营主体。** 官方主入口就是上面这几个；如果一个站点不在这几个域名下、页面上的运营主体也对不上，就**不要在上面付费或上传材料**。（官方有时会另开活动页或短链，所以判断时以页面标注的主体为准，别只盯域名。）

## 二、能确认「不是同一家」的同名产品

下面这些都已经能确认**不是**同一家公司（判断依据是应用或域名背后的开发者主体不同）：

| 名称 / 域名 | 背后主体 | 结论 |
| --- | --- | --- |
| iOS 上的另外两个同名 AiPPT | Mge Information Technology（合肥米格信息科技）、Megadreams LIMITED | 不是同一家 |
| 另有个人开发者上架的「AI PPT」等 | 个人开发者 | 不是同一家 |
| `pptai.cc` | 指向 `logomaker.com.cn`，卖的是 LOGO / 图标素材 | 不是同一家 |
| `aipptmaker.ai`、`ppt.ai` | DeepOpen, LLC 等独立产品 | 不是同一家 |
| 博思 AIPPT | 独立品牌 | 不是同一家 |

## 三、主体没核实清楚、建议回避的

以下域名与官方名字高度相似，但**主体未能核实**，在确认之前建议不要在上面付费或上传材料：

`aipptgenerator.io`、`aippt365.com`、`www-aippt.cn`、`aippt.中国`（punycode 域名）等。

判断标准很朴素：**主体不明 = 你的订单、作品和付款去向都不明。**

## 四、安卓侧怎么自查

三处一核对，基本不会错：

1. **包名**：本文档对应的这份是 `aippt.com.mm`（在应用管理的应用详情里能看到）；
2. **应用商店里的开发者**：官方安卓应用的开发者主体应与国内站一致（深圳像素绽放科技有限公司）；
3. **下载页的域名**：任何让你在非官方域名上付费的入口，都停下先核对。

本文档提供的这套安卓包放在网盘入口 [AiPPT 安装文件资源（夸克网盘）](https://pan.quark.cn/s/fefac330e3cc) 里，装之前可以用包名与 MD5（见 [下载与安装教程.md](下载与安装教程.md) 第一节）核对一遍 —— **认包名而不是认名字**，这条在安卓上尤其管用。

## 五、万一已经买错或付错了

处理顺序：

1. **先确认付款时的订单是在哪个平台**（App Store、微信支付、支付宝、某网站），退款路径跟着付款平台走，不跟着名字走；
2. **App Store 内购**按苹果的退款流程走，和 AiPPT 官方是否退款是两件事；
3. 如果确认是在官方渠道买的，退款与发票的口径见 [注册登录与会员计费.md](注册登录与会员计费.md) 第六节。

一句话总结：**名字人人能取，域名、运营主体和包名却是要长期用下去的 —— 按这三样核对，比按名字靠谱得多。** 遇到任何「AiPPT 便宜会员」「AiPPT 破解版」之类的说法，先回到第一节那张表核对。
