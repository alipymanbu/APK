## 一、哪些题型有分步解

官方口径里，下列题型除给最终答案外还能给出完整的分步过程（以 App 实际显示为准）：

- 解方程与方程组
- 求极限、导数、积分
- 因式分解
- 矩阵运算：求逆、求特征值

其他运算类型可以先出结果，再试着点步骤入口：出不来，就是该题型暂无分步支持。

### 分步解要不要钱

两边口径并列摆在这，你自己判断：

- **官方产品页**的说法是 App 免费、带分步解；
- **官方 2026 年的新功能文档**同时写明：付费会员（EMP）可解锁「不限次分步解」与 AI 文字题支持 —— 言下之意是免费档的分步解**有次数上限**；第三方评测（2026-05）也提到免费档有每日步骤限制。

落到操作上：碰到「次数用完 / 解锁更多」这类提示，说明你正处在免费档的限制上，等次日重置再用，或以官方页面当时的付费口径为准。最终答案本身不受这个限制影响的部分，可以先看结果再决定要不要步骤。

## 二、怎么调出解题步骤

1. 输入题目（拍照或键盘都行，见 [拍照识题输入技巧.md](拍照识题输入技巧.md)）。
2. 选择要做的运算（求积分、解方程组等），得到结果。
3. 在结果页点「步骤」（Steps），展开逐步过程。

输入的表达式不同，App 给出的可选运算也不同，菜单里只出现对当前式子有意义的操作。

## 三、拿分步解检查作业

典型用法不是抄步骤，而是对答案：

1. 自己先做完一道题。
2. 用 App 解同一道题，点开步骤。
3. 逐步对比，定位从哪一步开始和你的过程不一样。App 的推导路径和课本教法可能不同，重点看「分叉点」之后你的推导是否还成立，而不是形式是否一致。

## 四、没出步骤时的几种情况

| 现象 | 先查什么 |
| --- | --- |
| 结果出来了但没有步骤入口 | 该题型不在分步支持范围内，换相近题型试 |
| 识别结果和你想解的不是同一道题 | 回到输入环节重拍或改式子（见 [拍照识题输入技巧.md](拍照识题输入技巧.md)） |
| 一直转圈不出结果 | 部分运算要联网，检查网络后重试（见 [常见问题排查.md](常见问题排查.md)） |

## 五、运算能力覆盖范围

按官方列出的能力清单（截至 2026-09，以官方页面为准）：

| 类别 | 能做什么 |
| --- | --- |
| 基础运算 | 算术、分数、小数、整数、因数、平方根、幂 |
| 代数 | 线性方程与方程组的求解和作图、多项式、二次方程与函数、对数与指数函数、三角函数与恒等式 |
| 预科微积分 | 作图、分段函数、绝对值、不等式、隐函数 |
| 微积分 | 导数、极限、定积分与不定积分 |
| 线性代数 | 矩阵乘法、逆、行列式、转置、特征值与特征向量、高斯消元 |
| 微分方程 | 常微分方程 |

作图相关怎么用见 [函数绘图与三维图形操作.md](函数绘图与三维图形操作.md)。
