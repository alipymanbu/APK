## 一、任务一动不动，速度是 0

按命中率从高到低查：

1. **仅限 Wi-Fi 开关**：开着时切到移动网络，任务会停住等 Wi-Fi。去设置里确认；
2. **限速被调成了 0 或很低**：设置里的下载 / 上传限速看一眼；
3. **资源本身没人做种**：任务详情里看连接人数，人数为 0~1 的冷门资源等多久都慢，换资源比调设置有用；
4. **网络拦了 BT 流量**：校园网、公司网常见。切手机热点重试，立刻见分晓；
5. **存储满了**：剩余空间小于待下文件体积时任务会卡住，清理后再继续；
6. **并发的任务太多**：带宽被排队任务分光，急的那个反而慢。暂停其他任务只留一个试试。

## 二、磁力链接一直停在「连接中」

磁力链接要先从网络收集文件清单才能开始下载，这一步依赖能连上同行者。长时间停在这一步，通常是网络对 BT 协议不友好（同上第 4 条），或者这条磁力太冷门。换个网络环境试，是判断最快的办法。

## 三、锁屏或切后台就停

国产 ROM 的省电策略杀后台是重灾区，按顺序试：

- 系统设置里把 BitTorrent 加入**电池优化白名单**（路径一般在「设置 → 应用 → 特殊应用权限 → 电池优化」）；
- 在最近任务界面把应用**锁定**（下拉任务卡片有锁图标的机型）；
- 在自带安全应用里允许**后台运行 / 自启动**（小米、华为、vivo 等各家开关位置不同）。

大文件建议插着电、连着 Wi-Fi 挂机下完。

## 四、提示没有存储权限或文件找不到

- 第一次启动拒绝过存储权限的话，去「设置 → 应用 → BitTorrent → 权限」把它补上；
- 下载位置以任务详情里显示的路径为准，找不到文件时先核对这里，不要靠猜目录。

## 五、免费版与 Pro 的差别

| | 免费版 | Pro |
| --- | --- | --- |
| 广告 | 有 | 无 |
| 下载速度与大小 | 官方说明均不限制 | 同左 |
| 电池功能 | 无 | 电量低于设定值自动暂停下载 |
| 下载完成后自动关闭 | 无 | 有（省电、省流量） |
| 获取方式 | 商店 / 网盘安装包（见[下载与安装教程.md](下载与安装教程.md)） | 商店独立应用（包名 `com.bittorrent.client.pro`） |

要不要为无广告和省电功能买单，看你自己的使用频率；功能与价格以官方商店页面为准。

## 六、重装与求助渠道

- 升级后出问题想回退：先卸载再装旧版安装包（本仓库收录的 8.3.5-DEV 获取入口见 [下载与安装教程.md](下载与安装教程.md)），卸载不会带走公共目录里已下载的文件；
