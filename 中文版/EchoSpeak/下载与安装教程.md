## 一、安装前你要确认的三件事

| 事项 | 说明 |
| --- | --- |
| 存储空间 | 安装包 274.50M，加上安装过程中的解压占用，建议手机剩余空间留出 1GB 以上再动手 |
| 系统版本 | 网盘内这份安装包标注「安卓 5.2 及以上」；部分应用市场页面标的是 4.3 以上，两处口径不一致，以你安装时系统弹出的提示为准——目前主流在用的安卓版本都高于这两个门槛 |
| 版本 | 网盘内这份为 1.0.0（截至 2026-09），版本更新情况以应用市场页面为准 |

## 二、获取安装包

1. 打开 **EchoSpeak 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/3e6617ead8a0](https://pan.quark.cn/s/3e6617ead8a0)
2. 把文件**转存到自己的夸克网盘**，再从网盘下载到手机存储。
3. 下载完成后得到 `EchoSpeak_v1.0.0.apk`（文件名以网盘内实际显示为准）。

## 三、核对安装包（可选但建议）

如果你在乎拿到的是不是同一份文件，可以在文件管理器里看属性，或用校验工具算 MD5 后与下表比对：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.0 |
| 包名 | com.echoo.spdddfd |
| 大小 | 274.50M |
| MD5 | 80C0B656C0DA00737FBE9C8003A06823 |

## 四、安装步骤

1. 在文件管理器里点开下载好的 APK。
2. 第一次安装会弹「不允许安装未知来源应用」，按系统提示允许你的文件管理器（或浏览器）安装应用，返回重试。
3. 点「安装」，等进度走完，点「打开」或回桌面点图标。

第一次打开会用到录音、存储这类权限的，跟着功能走，用到时系统会来要，详见 [常见问题解答.md](常见问题解答.md) 第三节。

## 五、装不上时先查这几种情况

- **提示空间不足**：按第一节的建议清出足够空间再试。
- **提示解析失败 / 安装包损坏**：多半是下载没完成，重新下载一次，再对一遍第三节的 MD5。
- **只报「应用未安装」没给原因**：先重启手机再装一次；还不行就换一条路径重新下载（先转存、再下载，别用缓存的半截文件）。

照这三种情况查完还装不上，去 [常见问题解答.md](常见问题解答.md) 看更多情况；装好之后从 [使用入门与板块导览.md](使用入门与板块导览.md) 开始上手。
