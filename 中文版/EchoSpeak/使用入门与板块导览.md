## 一、先认名字

你在应用商店搜到它时，显示的名字多半是「EchoSpeak学习」——是同一个应用，开发者是深圳市创远界软件技术有限公司。本文按安装包里的名字 EchoSpeak 来叫。

顺带提醒：苹果 App Store 上还有一款同名的看剧练英语应用，和这个不是同一个产品。安卓版认包名 com.echoo.spdddfd 就不会拿错。

## 二、第一次打开建议这么做

1. 把首页各入口点一遍，对照下面的表知道自己有什么可用的。
2. 按你的目标选定一个主力板块（下一节给了对号入座的建议）。
3. 把每日学习目标设成一个忙的时候也能完成的量，开了提醒才有意义——目标定得太大，提醒很快就会被你关掉。

## 三、首页各板块能做什么

| 板块 | 你在里面做的事 |
| --- | --- |
| 学习计划 | 定目标、看进度，配合提醒把每天的学习固定下来 |
| 单词词汇 | 跟着词库记单词，可加进单词本定时复习（见 [听力训练与单词记忆.md](听力训练与单词记忆.md)） |
| 英语配音 | 给美剧、英剧片段配音练口语，是除跟读外另一个开口的入口 |
| 谚语故事 | 读英语谚语与小故事，适合当碎片时间的轻内容 |
| 英语字帖 | 临摹英文字母与句子，要练书写时用 |
| 翻译 / 拍照识别 | 输入或拍下文本看翻译，读课本碰到生句时顺手用 |
| 绘本点读 / 电子课本 | 点读绘本与课本内容，低年级孩子或跟教材走的人用得多 |
| 笔记编辑 | 记自己的生词与句子，配合课文学习 |

## 四、按你的情况选入口

- **学生、跟课堂同步**：从电子课本进，先找到自己这学期的教材，再配单词板块（教材覆盖的细节见 [教材覆盖与适用人群.md](教材覆盖与适用人群.md)）。
- **备考四六级、考研**：单词板块加听力训练组合着来，见 [听力训练与单词记忆.md](听力训练与单词记忆.md)。
- **想练开口**：直接去配音板块，或走跟读那条线，见 [口语跟读与AI评测.md](口语跟读与AI评测.md)。

## 五、别忘了离线

教材与听力素材可以下载后离线用，通勤、课间没网也能学。出发前在 Wi-Fi 下把要用的内容缓存好，比到了地方再找网省事得多。
