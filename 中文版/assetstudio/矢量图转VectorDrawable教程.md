## 一、这个功能跟资源提取是两回事

打开手机版 AssetStudio，你会在资源解析之外碰到一套独立的矢量图工作流：它内置了 Android Studio 附带的一大批矢量图标（上千个量级），你选好图标、调好参数，它直接帮你生成安卓项目里能用的资源与代码，不用开电脑上的 Android Studio。

适合的场景：你在手机上写点小项目、临时要一个标准图标并转成 VectorDrawable，或者想先在手机上把图标资源配好，回头再到电脑上接着写。

## 二、完整操作流程

1. **导入图标资源**：进入矢量图功能区，导入 material 矢量图标资源（也可以从内置图标库里选）；
2. **配置参数**：
   - 选择 Asset 类型；
   - 填图标名称、类别；
   - 设置颜色、大小等外观参数；
   - 点「下一步」；
3. **出口模式**：这一步可以按需输入自定义内容，没有特殊要求就直接点「完成」；
4. **拿结果**：稍等片刻，页面会生成一段矢量图相关代码，复制走就能用在你的安卓项目里。

生成的结果是安卓标准的 VectorDrawable 体系，代码和资源可以直接进工程，不需要再手动改写。

## 三、几个实际使用建议

- **命名趁早规范**：图标名称和类别在第二步就定，生成后资源名就跟着走了，起得随意后面在项目里对不上号；
- **颜色和大小一次配好**：VectorDrawable 对颜色的表达靠配置而不是重画，先在预览里确认效果再生成，比生成后返工快；
- **内置库找不到想要的图标**：说明目标图标不在 Android Studio 自带那批里，用导入功能喂进你自己的 SVG 类资源再走同样流程；
- **生成内容看不懂**：它生成的是 XML 资源加对应的引用代码，会一点安卓开发就能看懂；纯小白可以直接整段复制，别手改。

## 四、常见疑问

**和电脑端 Android Studio 的 Vector Asset 工具是什么关系？**
功能定位相同——把矢量图标变成工程可用的资源。区别是这套跑在手机上，参数配置是可视化点选的，不依赖电脑环境。

**转换效果还原度怎么样？**
它移植了与 Android Studio 相同的 SVG 转换库，常规图标（线性、填充、多路径）还原度稳定；特别复杂的 SVG 特效类图标建议生成后先预览确认再入库。

**生成的代码能直接编译吗？**
能。这是它和「只是看图」类工具的差别：产物是工程级资源，不是贴图截图。

图标之外的 Unity 资源解析、导出是另一条工作流，看 [Unity资源提取教程.md](Unity资源提取教程.md)；装不上应用的先走 [下载与安装教程.md](下载与安装教程.md)。
