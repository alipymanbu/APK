## 一、三类文件分别在哪

| 文件 | 常见路径 | 长什么样 |
| --- | --- | --- |
| 安装包本体（APK） | 下载目录；或系统应用目录 | `.apk` 文件，资源藏在内部的 `assets`、`bin/Data` 里 |
| 扩展资源包（OBB） | `Android/obb/<包名>/` | `main.<数字>.<包名>.obb` 这类命名，几百 MB 到几个 GB |
| 热更新 / 运行时资源 | `Android/data/<包名>/` 下的缓存目录 | 一堆带 hash 或版本号的文件，没有统一命名 |

先复制到一个你方便访问的目录（比如 Download），再喂给 AssetStudio。文件搬完后的加载、提取操作见 [Unity资源提取教程.md](Unity资源提取教程.md)。

## 二、先查包名，再对号入座

`Android/data` 和 `Android/obb` 下面都是按包名分文件夹的，你得先知道目标游戏的包名：

1. 系统「设置 - 应用管理」里找到该游戏，进应用信息页；
2. 包名一般直接显示在页面上（形如 `com.xxx.yyy`）；部分系统要进「应用详情」二级页或点「高级」才看得到。

对上包名，再去 `Android/data/<包名>`、`Android/obb/<包名>` 里翻对应文件夹就快了。

## 三、安卓 11 以后进不去 Android/data 怎么办

从安卓 11 起，系统把 `Android/data` 和 `Android/obb` 对第三方应用锁了，普通文件管理器点进去要么空白要么报无权限。不动 root 的常见绕行办法有三条，按省事程度排：

1. **系统自带文件管理器的特殊入口**：部分机型的自带「文件管理」点进 `Android/data` 时会弹「使用此文件夹查看」的授权确认，确认后能看。能不能行因机型和系统版本差异很大，先试这条，成本最低。
2. **USB 连电脑**：手机连电脑选「文件传输（MTP）」，在电脑的资源管理器里展开手机存储进 `Android/data`。电脑侧的访问规则和手机内不同，不少机型上这条路能直接看到内容，复制出来也方便。
3. **Shizuku + 支持的文件管理器**：开发者选项里开「无线调试」，按 Shizuku 应用的引导完成配对启动，再在授权列表里放行你的文件管理器（ZArchiver、FV 文件管理器这类都支持），之后就能在手机上直接浏览和复制这两个目录。

以上是社区里普遍验证过的做法，但各家系统收紧程度不同（安卓 13、14 上明显更严），某条路在你机器上走不通属正常，换下一条试。

## 四、XAPK 与资源包的补充说明

- **XAPK**：本质是个压缩壳，里面装着 APK（可能还有 OBB）。文件管理器把它当 zip 解开，取出里面的 APK 和 OBB 分别处理即可；
- **分包安装（商店渠道常见）**：主包拆成多个小 apk 的形式不影响你找资源——资源大头仍在 OBB 或 `Android/data` 目录；
- **APK 内部资源**：用支持解压的文件管理器把 APK 当 zip 解开，就能看到里面的 `assets`、`bin/Data` 目录，把这些目录整体解出来用 Load folder 加载最顺手。

找不到文件、找到了却加载异常这类后续问题，去 [常见问题排查.md](常见问题排查.md) 对号入座。
