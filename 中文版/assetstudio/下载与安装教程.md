## 一、你要装的是哪个 AssetStudio

搜「AssetStudio」时你会碰到两样东西：一个是 Perfare 发布在 GitHub 上的电脑端开源工具（[github.com/Perfare/AssetStudio](https://github.com/Perfare/AssetStudio)），用来浏览和导出 Unity 资源；另一个就是本文要装的**手机版**——把前者的资源解析能力搬到安卓上，包名 `coyamo.assetstudio`，界面尽量保留了原版的布局。两者不是同一个安装包，别装混。

手机版适合的场景：手边没有电脑、或者文件就在手机里，想直接在手机上翻 Unity 资源包、导出贴图音频，或者临时把图标转成安卓能用的矢量资源。

## 二、安装前的准备

先核对你要装的包（下表是本篇对应安装文件资源的实际信息）：

| 项目 | 信息 |
| --- | --- |
| 版本 | 0.2 |
| 安装包体积 | 6.28 MB |
| 包名 | `coyamo.assetstudio` |
| MD5 | `A9A7CB9A308E80260D5DB8E19A125417` |
| 系统要求 | 安卓 5.2 及以上（以实际安装环境为准） |

工具类应用迭代较快，你之后拿到的新版本号、体积可能与此不同，以安装文件资源内实际文件为准。

## 三、从夸克网盘获取安装文件

网盘分享里的文件需要先**转存到自己网盘**才能下载：

1. 打开 [AssetStudio 安装文件资源（夸克网盘）](https://pan.quark.cn/s/336e1a44fb5d)；
2. 勾选里面的 APK 文件，点「转存」，存到自己网盘的任意目录；
3. 打开夸克网盘 App，找到刚转存的文件，下载到手机本地存储。

## 四、安装步骤

1. 打开手机文件管理器，进入下载目录，点刚下好的 APK；
2. 系统弹出「未知来源应用」提示时，选择允许本次安装（国产系统一般在弹窗里直接给开关；部分品牌要进「设置 - 安全」里单独开）；
3. 等待安装完成，桌面出现 AssetStudio 图标即可打开。

安装包只有 6.28 MB，几秒钟就能装完。首次打开不需要注册账号，也不会强制要一堆权限，主要用到的是存储访问（选文件、存导出结果）。

## 五、核对拿到的包

在意文件对不对的话，装之前可以核对两点：

- **MD5**：用文件管理器自带的「校验」功能或任意文件校验工具算一下，0.2 版应为 `A9A7CB9A308E80260D5DB8E19A125417`；
- **包名**：装完后在系统「设置 - 应用管理」里看 AssetStudio 的应用信息，包名应为 `coyamo.assetstudio`。

对得上，说明你拿到的就是本篇描述的这份安装文件资源。

## 六、装不上怎么办

| 提示 | 原因与处理 |
| --- | --- |
| 解析包错误 / 安装包已损坏 | 下载中断导致文件不完整，删掉重下，核对 MD5 后再装 |
| 与设备不兼容 | 确认安卓版本满足第二节的要求；个别深度定制系统可能拒绝安装 |
| 安装到一半卡住 | 清理后台、重启手机后重试；存储空间不足也会卡住 |
| 安装被拦 / 提示禁止安装 | 国产系统的「纯净模式」或安全拦截在起作用，在弹窗里选允许，或到系统设置里临时关闭纯净模式再装 |
| 装上了但打不开 | 见 [常见问题排查.md](常见问题排查.md) 的启动类问题 |

装好之后，第一件事可以按 [Unity资源提取教程.md](Unity资源提取教程.md) 把一个资源包加载进去试试流程是否跑通。
