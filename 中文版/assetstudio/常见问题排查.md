# AssetStudio 常见问题排查

> 本篇把 AssetStudio 手机版最常见的几类问题——加载崩溃、内存吃满、导出异常、MonoBehaviour 打不开——集中给出判断与处理办法。

## 一、加载大包就闪退 / 手机发烫

原因：AssetBundle 是在内存里解压读取的，包越大内存峰值越高，系统内存不足时直接杀进程，表现就是闪退。

处理顺序：

1. 别直接 Load，先走 **File - Extract 文件 / Extract 文件夹** 把包解压到本地目录；
2. 再用 **Load folder** 加载解压后的文件夹；
3. 还是大 → 按「游戏 + 资源类型」分目录，一小批一小批加载，别一个文件夹塞几百个包。

内存小的机型（4GB 以下）加旧款游戏大包，第三步基本是必须的。

## 二、文件加载后列表是空的

按下面顺序查：

- **喂错文件了**：它吃 Unity 体系产物（AssetBundle、`.assets`、APK 内部资源），普通 zip、图片文件夹不认；
- **文件不完整**：从手机里复制出来的包中途断了，重拷一遍，先比文件大小；
- **资源类型被筛掉了**：Asset List 顶部的类型筛选栏是不是只勾了某一类，全选再刷新。

## 三、MonoBehaviour 资源看不了

MonoBehaviour 里存的是脚本挂载的数据，要看懂它需要对应的程序集（dll）：

- 选中 MonoBehaviour 时如果应用提示你选程序集目录，说明这份资源需要外挂 dll 才能还原成可读 JSON；
- 程序集得从游戏包里单独取（Mono 游戏是 `Managed` 目录）；
- **Il2Cpp 打包的游戏**在电脑端也要先用配套工具生成 dummy dll 才行，手机上整套流程走不通——这类需求建议放回电脑端处理，手机上别耗着。

判断自家目标游戏是哪种：看包里有没有 `libil2cpp.so`（Il2Cpp）还是 `libmono.so` + `Managed` 目录（Mono）。

## 四、导出结果不对劲

| 现象 | 原因与处理 |
| --- | --- |
| 导出的 PNG 黑底 / 发灰 | 贴图带 alpha 通道，部分查看器不认；换支持透明的看图软件确认，别急着重导 |
| 贴图是模糊马赛克 | 部分贴图在包里就是低分辨率缩略图（mipmap 或占位图），不是导出坏了，找同名高清变体 |
| 音频导出只有部分格式 | FSB 封装的音频按应用内可转格式导出（可转 WAV），以导出菜单实际显示为准 |
| 模型导出没动画 | 导出时没带上 AnimationClip，按 [导出模型与动画教程.md](导出模型与动画教程.md) 第二节重导 |
| 导出的文件找不到 | 先确认导出时选的目录；再查应用私有目录（`Android/data/coyamo.assetstudio/` 下面），进不去这类目录的绕行办法见 [游戏资源文件在哪找.md](游戏资源文件在哪找.md) |
| 批量导出中途停了 | 存储空间不足或目录权限被收回，清空间、重新授予存储权限后接着导 |

## 五、启动与权限类

- **打开就闪退**：先重启手机排除偶发；不行就卸载重装（安装包核对见 [下载与安装教程.md](下载与安装教程.md)）；
- **选不了文件 / 存不了导出结果**：系统设置里把「文件与媒体」权限给到，国产系统的「照片和视频」权限有时也拦文件选择器；
- **目录里看不到游戏数据**：安卓 11 以后 `Android/data` 目录受限制，没 root 时部分目录要用系统文件管理器的特殊入口、USB 连电脑或 Shizuku 授权，具体三条路的走法见 [游戏资源文件在哪找.md](游戏资源文件在哪找.md)。
