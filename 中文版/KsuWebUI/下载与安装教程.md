## 一、KsuWebUI 是什么

KsuWebUI 是 KernelSU 模块 WebUI 的独立 App 实现（官方仓库：[KsuWebUIStandalone](https://github.com/5ec1cff/KsuWebUIStandalone)），适用于 Magisk、KernelSU 和 APatch 三种 Root 环境。

不少 Root 模块除了执行脚本，还带一个网页做的配置界面，用来点开关、改选项、看状态。这个网页需要一个「宿主」来打开：KernelSU、APatch 较新的管理器自带入口，Magisk 则没有 —— 这时你就可以用 KsuWebUI（或同类应用 WebUI X）来充当宿主。

## 二、你需不需要装它

先对照下面三种情况：

| 你的情况 | 建议 |
| --- | --- |
| 用 Magisk，模块带网页配置界面 | 需要装一个独立宿主，KsuWebUI 或 WebUI X 都能充当 |
| 用 KernelSU / APatch，管理器版本较新 | 管理器自带界面入口，不一定需要单独安装 |
| 模块运行时提示需要 KsuWebUI、或提示找不到 WebUI 应用 | 按提示装上即可 |

另外，个别模块在 Magisk 下点「操作」按钮时会自动检查并安装 KsuWebUI，这种情况你不用手动下载。

如果想知道 KsuWebUI 与另一款同类宿主 WebUI X 有什么差别、该装哪个，见 [WebUI X 与 KsuWebUI 怎么选.md](WebUI%20X%20与%20KsuWebUI%20怎么选.md)。

## 三、安装前确认三件事

1. 手机已经 Root，且装了 Magisk / KernelSU / APatch 之一的管理器，Root 权限正常；
2. 你要配置的那个模块已经装好；
3. 系统 WebView 处于可用状态 —— 模块界面就是网页，WebView 被停用时页面会加载不出来。

## 四、下载安装包

从 KsuWebUI 安装文件资源（夸克网盘）下载：[https://pan.quark.cn/s/8ac294b7da5c](https://pan.quark.cn/s/8ac294b7da5c)，转存后即可取出安装包。

本文对应的是 1.0 版安装包，基本信息如下，拿到手后可以核对是不是同一份：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0 |
| 包名 | `io.github.a13e300.ksuwebui` |
| 大小 | 约 1.62 MB |
| MD5 | `1D37F54C22C9612F62D6580C14DAFCE8` |

官方仓库迄今只发布过 v1.0 一个版本（截至 2026 年 9 月），所以你搜到的 KsuWebUI 基本都是这一个版本，不存在「旧版」「新版」之分。另据官方仓库页面：仓库已于 2025 年 7 月归档为只读，也就是不再有后续版本 —— 归档影响的是「没有更新」，不影响你安装和使用手头的 v1.0。如果更在意持续维护，可以对比另一款宿主 WebUI X，见 [WebUI X 与 KsuWebUI 怎么选.md](WebUI%20X%20与%20KsuWebUI%20怎么选.md)。

## 五、安装与首次启动

1. 在系统允许「安装未知来源应用」的前提下，安装刚下载的 APK；
2. 打开 KsuWebUI，管理器会弹出 Root 授权请求，选择允许（顺手勾选「永久允许」之类的长期放行选项，避免以后每次打开都要确认）；
3. 授权通过后，主界面会列出当前带网页界面的模块。
