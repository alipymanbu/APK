## 一、带界面的模块长什么样

按 KernelSU 的模块规范，模块可以在自己目录里放一个网页入口（`webroot` 目录加 `index.html`），页面里可以执行命令、弹提示。带这套东西的模块，你就不需要手动改配置文件 —— 打开网页界面点几下即可。Magisk 社区的模块沿用了同一套习惯，只是 Magisk 本身不带显示网页的宿主，这也是 KsuWebUI 这类独立宿主存在的原因。

## 二、常见的带界面模块

下面这些模块，在它们的官方文档或社区教程里都出现过网页配置界面（截至本文写作整理，具体以各模块官方说明为准）：

| 模块 | 网页界面用来做什么 |
| --- | --- |
| Zygisk Next | 配置排除列表策略等选项 |
| Mountify | 调整挂载相关的配置 |
| PlayIntegrityFix（社区维护版） | 获取与更新设备指纹配置、开关相关选项 |
| Tricky Addon（Tricky Store 的附加模块） | 管理验证目标应用列表 |

同一个模块在不同教程里的入口叫法不一样：有人从管理器卡片上的按钮进，有人从独立宿主里进，打开的是同一个页面。

## 三、这些界面分别靠什么打开

| 环境 | 打开途径 |
| --- | --- |
| KernelSU / APatch（较新管理器） | 管理器模块卡片上的界面按钮 |
| Magisk | 独立宿主（KsuWebUI 或 WebUI X）；部分模块的「操作」按钮会自动唤起 |
| 按模块自己的指定走 | 个别模块在文档里指定了首选宿主，安装脚本甚至会自动下载宿主 |

## 四、宿主不止一个选择

KsuWebUI 之外，WebUI X（包名 `com.dergoogler.mmrl.wx`）是另一款同类宿主，多数带界面的模块在两者里都能打开。要注意的是：这类网页的设置通常存在宿主应用里，换一个宿主打开，之前配好的选项可能要重新配一遍 —— 所以装了一个之后就固定用它，别来回换。两款宿主的维护状态也不同：KsuWebUI 的官方仓库已于 2025 年 7 月归档（v1.0 后不再更新），WebUI X 仍在持续发布新版本；完整对比与选择判据见 [WebUI X 与 KsuWebUI 怎么选.md](WebUI%20X%20与%20KsuWebUI%20怎么选.md)。

还没装宿主的话，从 [下载与安装教程.md](下载与安装教程.md) 开始；装好后的进入步骤见 [怎么打开模块的网页界面.md](怎么打开模块的网页界面.md)；界面打不开再翻 [常见问题与解决办法.md](常见问题与解决办法.md)。
