# 怎么打开模块的网页界面

## 一、先分清界面和宿主

网页界面是模块自己带的一份网页文件，KsuWebUI 只是负责把它显示出来的那个应用。所以「打开界面」有两个方向：从 KsuWebUI 里进（找模块列表），或者从模块那边唤起（点模块的操作按钮）。

## 二、三种 Root 环境下的入口差别

| 环境 | 管理器自带界面入口 | 常见打开方式 |
| --- | --- | --- |
| Magisk | 没有 | 用 KsuWebUI / WebUI X 之类的独立宿主；或点模块的「操作」按钮，由脚本唤起 |
| KernelSU | 较新版本有 | 管理器里模块卡片上的界面按钮；老版本管理器用独立宿主补足 |
| APatch | 较新版本有 | 同 KernelSU |

判断你自己属于哪种情况最简单的办法：打开管理器看模块卡片上有没有进界面的按钮，没有就装一个独立宿主。

## 三、在 KsuWebUI 里打开的步骤

1. 打开 KsuWebUI，首次使用时允许 Root 授权；
2. 在模块列表里找到要配置的模块 —— 列表只显示带网页界面的模块；
3. 点进去，等页面加载完成，之后就是在网页里点选操作。

## 四、从模块那边直接唤起

部分模块在 Magisk 下提供「操作 / 执行」按钮：点了之后脚本会先检查设备上有没有 KsuWebUI，有就直接跳到该模块的界面。以 [Tricky Addon](https://github.com/KOWX712/Tricky-Addon-Update-Target-List) 为例，它的官方文档写明会优先找 KsuWebUI，找不到再找 WebUI X，个别模块在两者都没有时还会自动下载安装 KsuWebUI。

这种自动安装需要设备能联网（脚本会先检查网络连通性，再去下载安装包），失败时你可以自己手动装好宿主，再重新点一次操作按钮。装哪个宿主更合适，见 [WebUI X 与 KsuWebUI 怎么选.md](WebUI%20X%20与%20KsuWebUI%20怎么选.md)。

所以如果你还没装任何宿主，也可以先点一次模块的操作按钮，让模块自己把宿主带起来。

## 五、为什么列表里看不到某个模块

模块要在包里带了 `webroot` 网页目录，才会在这类宿主里出现入口；纯脚本模块（只有开机脚本、没有配置页）本来就没有界面，不出现是正常的。某个模块到底有没有界面，以它自己的说明为准，常见带界面的模块例子整理在 [哪些模块会用到网页界面.md](哪些模块会用到网页界面.md)。

界面打开了却白屏、或点开没反应，直接翻 [常见问题与解决办法.md](常见问题与解决办法.md)；还没装 KsuWebUI 的话，先看 [下载与安装教程.md](下载与安装教程.md)。
