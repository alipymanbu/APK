## 一、两款宿主是什么关系

KsuWebUI 和 WebUI X 干的是同一件事：显示 Root 模块自带的网页配置界面。模块在哪个宿主里都能打开，区别在宿主本身的维护状态和功能面。

| 维度 | KsuWebUI（KSU WebUI Standalone） | WebUI X |
| --- | --- | --- |
| 出自 | [5ec1cff/KsuWebUIStandalone](https://github.com/5ec1cff/KsuWebUIStandalone) | [MMRLApp/WebUI-X-Portable](https://github.com/MMRLApp/WebUI-X-Portable) |
| 维护状态 | 官方仓库 2025 年 7 月起归档为只读，v1.0 就是最后一个版本（截至 2026 年 9 月） | 仍在持续发布新版本（以官方 Releases 页为准） |
| 适用环境 | Magisk、KernelSU、APatch（官方 README 口径） | 官方文档称支持 KernelSU Next、SukiSU Ultra、Magisk、APatch，甚至无 Root 设备 |
| 功能面 | 单一：列出带界面的模块并打开它 | 除打开模块界面外，官方文档还列了插件、调试控制台、缓存等增强功能 |
| 模块唤起顺序 | 部分模块（如 Tricky Addon）的脚本优先找它 | 同类模块的次选宿主 |

## 二、按情况选

| 你的情况 | 判据 |
| --- | --- |
| 模块文档指定了宿主 | 按模块要求装，别自由发挥 |
| 在意后续还有没有更新 | 看官方仓库是否归档：KsuWebUI 已停止更新，WebUI X 仍在维护（以官方页面为准） |
| 设备上模块只认某一个包名 | 装「No WebUI app found」提示里要的那个 |
| 已经配好一套在用 | 不换。两边设置不互通，换宿主等于重新配一遍 |

## 三、还没装宿主的话

先明确你要打开哪些模块的界面（带界面的常见模块见 [哪些模块会用到网页界面.md](哪些模块会用到网页界面.md)），再挑宿主；装哪个、怎么装、装完怎么进界面，见 [怎么打开模块的网页界面.md](怎么打开模块的网页界面.md) 和 [下载与安装教程.md](下载与安装教程.md)。

## 四、换宿主之前要记住的一件事

这类模块网页的开关、选项通常存在宿主应用里（KernelSU 官方文档对这类页面的说明是：页面用的本地存储随宿主应用走，卸载宿主数据就没了）。所以：

1. 卸载宿主前，先把界面里配好的内容抄下来或截图；
2. 换宿主后重新配一遍，别指望自动迁移；
3. 部分模块会把配置写进自己的目录，这类模块换宿主不受影响 —— 以各模块自己的说明为准。

配好了但界面打不开、或者打开是白屏，处理办法见 [常见问题与解决办法.md](常见问题与解决办法.md)。
