# Mirror 镜像不显示怎么排查

> 桌面端选了 Frame、手机 Mirror 标签却一直空着或画面不对时，按本篇的顺序逐条过一遍，多数情况能在前四步内解决。

## 一、先核对四个最常见的漏项

按命中概率排序，逐条确认：

| 步骤 | 检查什么 |
| --- | --- |
| 1. 设备支持 | 手机系统达到 Android 8.0（iOS 侧为 iOS 16+），测试版系统不在支持范围 |
| 2. 选中了顶层 Frame | 桌面端必须选中**顶层 Frame** —— 只框选 Frame 里面的图层、或选中的是 Group，Mirror 都不会显示 |
| 3. 两端同一账号 | 桌面端和手机登录的是同一个账号；不确定就两端都退出重登一次 |
| 4. 权限够不够 | Mirror 需要你对文件有 `can edit` 权限，只有 `can view` 时镜像不了 |

## 二、还不行就重启三件套

官方支持团队给的排查顺序走到这里还没解决，按这个顺序来：

1. **强退重开 App**：从后台彻底划掉再打开，不是回到桌面；
2. **更新或重装**：把 App 升到最新版；问题依旧就卸载重装；
3. **换网络试一次**：两端走不同网络也能连（不需要同一 Wi-Fi），所以镜像不出来时换一下手机的网络环境，可以排除是网络策略拦了连接。

仍无解就走官方支持渠道（`https://help.figma.com` 里提交），描述里带上 App 版本号和两端系统版本。

## 三、一个已知的现象：镜像里图片不显示

有用户反馈过一种情况：镜像里文字、形状都正常，唯独图片类素材整批不显示，换文件、换手机都复现。这类渲染问题属于服务端或版本缺陷，你这边能做的就是第一节和第二节的清单过完之后等版本更新；自己删包重装解决不了它。

## 四、别和演示视图搞混

Mirror 依赖桌面端**当前选中**的 Frame —— 桌面上没选、或者你切走了文件，手机上就会空。如果你要的是「不连桌面、自己播放一个原型」，那是演示视图的事，操作在 [原型预览与镜像投屏.md](原型预览与镜像投屏.md)；账号不确定是不是同一个，先看 [登录与账号.md](登录与账号.md) 的多账号切换。
