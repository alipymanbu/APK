## 一、先说定位：它主要是个「看」的工具

你在手机上装的这个 App，用途是随时随地查看设计稿、提评论、演示和测试原型、配合桌面端做实时镜像。它不是完整的设计编辑器 —— 官方帮助中心明确说明手机 App 不能编辑 Figma Design 设计文件和 Figma Slides 演示文稿。想从零画图、改图层，还是要回到桌面端或浏览器。

## 二、你在手机上能做的事

| 你想干的事 | 在手机上怎么做 |
| --- | --- |
| 找文件 | 首页 **Recents** 看最近打开的文件和原型；**Search** 按名字搜，也能看到你在桌面端加过星标的文件 |
| 看设计稿 | 手指拖动平移画布，双指捏合缩放 |
| 看 Slides 幻灯片 | 点底部缩略图翻页，双指缩放当前页，横屏全屏看；同样只能看不能改 |
| 提评论 | 在画布上长按要评论的位置；通知与快速回复都走 Activity 标签，细节见 [评论回复与通知管理.md](评论回复与通知管理.md) |
| 演示原型 | 打开文件后在菜单里选 View prototypes，按设定好的流程起点播放 |
| 镜像桌面画面 | 桌面端选中一个顶层 Frame，手机切到 **Mirror** 标签实时看；镜像不出来先过一遍 [Mirror镜像不显示怎么排查.md](Mirror镜像不显示怎么排查.md) |
| 看 FigJam 白板 | 手机上可查看白板内容；官方把 FigJam 的编辑能力放在 iPad 版 App 里（配合 Apple Pencil 画画、贴便签、连流程图） |
| 预览 Figma Make | 从 Recents 打开 Make 文件可预览运行效果、看和回评论、分享给同事；创建和编辑 Make 目前不在手机 App 里（官方注明） |
| 管理通知 | 推送通知默认开启，右上角组织 logo 进 Notifications 调整；见 [评论回复与通知管理.md](评论回复与通知管理.md) |

原型演示和 Mirror 镜像的逐步操作单独写在 [原型预览与镜像投屏.md](原型预览与镜像投屏.md)，这两条是手机端最常用的路径。断网时这些事哪些还能干，见 [离线与弱网使用.md](离线与弱网使用.md)。

## 三、你在手机上做不了的事

- 编辑 Figma Design 设计文件的图层、组件 —— 能看、能评、能测，改不了；
- 编辑 Figma Slides 幻灯片（浏览没问题）；
- 编辑 FigJam 白板和创建 / 编辑 Figma Make（分别要去 iPad App 和桌面端）；
- 给文件加星标或取消星标 —— 只能浏览桌面端已经加过的（官方帮助页注明）。

## 四、和桌面端怎么分工

| 场景 | 用哪个 |
| --- | --- |
| 画图、改稿、搭组件库 | 桌面端或浏览器 |
| 通勤路上看稿、回评论 | 手机 App |
| 给同事或客户演示原型 | 手机 App 的演示视图（真机手感） |
| 边改边看真机上的效果 | 桌面端 + 手机 Mirror 镜像 |

## 五、权限门槛

- `can view`：可以看文件、看原型、发评论 —— 别人只读分享给你的文件，这些操作都够；
- `can edit`：才能用 Mirror 镜像桌面端选中的 Frame。

也就是说，你在手机上能干多少活，取决于文件主人给你的权限，跟装哪个版本无关。
