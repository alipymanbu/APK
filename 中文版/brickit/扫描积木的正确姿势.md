## 一、扫描前把积木摆好

识别质量八成取决于拍照前的准备，按这四步来：

1. **平铺成一层**：把积木摊在平整的台面上，彼此不叠、不靠。叠在一起的积木是被挡住的那面拍不到，识别就会漏；
2. **大块挪到边上**：大底板、大颗粒最容易盖住旁边的小零件，先把它们单独放一边或放最外圈；
3. **选对背景**：纯色、与积木颜色反差大的台面最好用；浅色地毯、花纹桌布会明显拉低识别率；
4. **光线要匀**：白天靠窗的自然光最稳；晚上补光时避免手机自己的影子罩住积木，硬阴影会被当成积木边缘。

## 二、拍的时候

1. 打开应用进入扫描界面，把整摊积木框进取景框；
2. 从正上方拍，离得太近反而拍不全；
3. 按下拍照后等几秒，应用会数出这一堆里识别到了哪些零件、各多少个；
4. 对结果不满意就**把积木重新搅一搅再拍一张**——同一堆积木换个朝向，常常能多认出不少。多扫几次、取最好的一次是常规操作。

## 三、识别主要看什么

- 官方说明算法能认约 1600 种常见零件形状，从很小的一角就能认出来；
- **识别刻意不看颜色**：它按形状配对，你手里的红色零件可以搭出方案里的蓝色位置。所以别因为颜色对不上就以为识别错了；
- 太少见、太特殊、带印刷图案的零件常常认不出来，这些不影响主流程——方案会基于认出来的那部分来推荐。

## 四、识别不准时按顺序查

| 现象 | 先查什么 |
| --- | --- |
| 认出的零件明显偏少 | 有没有叠放？大块有没有挡住小块？搅一搅重拍 |
| 整堆几乎全没认出 | 光线是不是太暗/反光太强？背景是不是太花？ |
| 每次结果都不一样 | 正常现象，多扫几次选零件数最多的一次 |
| 点拍照没反应 | 相机权限是否被拒了，去系统设置里打开 |

识别这一步需要联网：照片会上传到服务端处理，断网时扫描基本跑不动。照片传上去之后会发生什么、想少留痕迹怎么拍，见[照片上传与隐私说明](照片上传与隐私说明.md)；网络相关的异常处理集中在[常见问题排查](常见问题排查.md)里。

## 五、认出来之后干嘛

扫描只是第一步。识别结果会变成一份「你有什么」的清单，应用据此给出能搭的方案——选方案、跟步骤、找零件的做法都在[搭建建议与步骤指导](搭建建议与步骤指导.md)里。还没装的话，从[下载与安装教程](下载与安装教程.md)开始。
